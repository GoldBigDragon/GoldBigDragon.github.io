## 2. 下準備の工程: 皮剥ぎ、脱毛、脱肉、中和
&nbsp;&nbsp;&nbsp;下準備の目的は、真皮のコラーゲン繊維だけを残し、薬剤が通る道を開くことです。鞣しの失敗の多くは、鞣しの工程ではなく、これらの工程を急いで済ませることから生じます。

---
### 2-1. 皮剥ぎ
&nbsp;&nbsp;&nbsp;皮は、体から外した瞬間から腐り始めます。処理できる限度は、夏の気温では数時間、涼しい日でも1日です。

- ナイフの使用は最小限にします。ナイフを使うほど真皮に傷が付き、その傷が仕上がった革の穴や薄い部分になります。
- 皮下組織と真皮の間には、簡単に開く面があります。拳や先の丸い棒で押し込むと、ナイフを使わなくてもかなりの部分が剥がれ、損傷もほとんど残らないため、大型動物で有利です。

&nbsp;&nbsp;&nbsp;すぐに処理できないときは、細菌が増えないように水分を抜き、時間を稼ぎます。

| 方法 | 原理 | 条件と限界 |
| --- | --- | --- |
| 塩漬け | 塩が浸透圧で組織から水分を引き出す | 皮の重さの30~50%の塩を肉面に均等にすり込む。塩が少ないと中から腐る |
| 乾燥 | 水分を蒸発させて水分活性を下げる | 風通しのよい日陰で張って乾かす。直射日光で乾かすと表面だけが硬くなり、内側が腐る |
| 冷凍 | 温度を下げて細菌と酵素を止める | 冬にしかできない。凍結と解凍を繰り返すと繊維が傷む |

&nbsp;&nbsp;&nbsp;乾燥させた皮は、後で水に浸けて元に戻さなければなりません(浸水)。乾燥期間が長い皮ほど水が染み込むまでの日数がかかり、その間に水温が高いと腐敗が始まります。浸水中は、水を少なくとも1日1回交換します。

---
### 2-2. 脱毛
&nbsp;&nbsp;&nbsp;毛根は真皮の奥深くに埋まっているため、毛を無理に引き抜くと真皮ごと裂けてしまいます。そこで、毛根を固定しているタンパク質(ケラチン)をアルカリで溶かし、毛が自然に抜け落ちるようにします。強いアルカリは、ケラチンをつなぎ止めているジスルフィド結合を切断するためです。

- 灰汁: 木灰を水に浸したものです。主成分は炭酸カリウムです。
- 水酸化カルシウム: 貝殻や石灰石を焼いて水と混ぜたものです。アルカリ性が強く、より長く持続するため、脱毛に向いています(工業工程で生石灰が使われる理由です)。

| 項目 | 内容 |
| --- | --- |
| 目標pH | 11~13。これより低いと毛が抜けない |
| 所要時間 | 温度により3~10日。寒いときはさらに長くかかる |
| 完了の見分け方 | 手でこすると毛がひとつかみずつ滑り落ちる |
| やりすぎた場合 | アルカリがコラーゲンまで加水分解し、皮がぬるぬるになって、引くと裂ける |
| 副作用 | 繊維束が膨潤して開き、薬剤が入る道ができる |

&nbsp;&nbsp;&nbsp;この副作用は、実は二つ目の目的であり、結果に与える影響もより大きいものです。真皮がアルカリで膨潤すると、繊維束の間の隙間が広がり、繊維を結び付けていた非コラーゲン物質が溶け出します。この工程を経ていない皮は、鞣し液にいくら長く浸けても、表面しか染み込まず、内側は元のままです。

&nbsp;&nbsp;&nbsp;アルカリを使わない代替法は、自然発酵です。皮をぬるま湯に数日浸けて、細菌にまず表皮を分解させると、毛が抜けます。材料は要りません。ただし、止めどきの判断が非常に難しく、少し遅れるだけで真皮まで分解されて皮が駄目になり、臭いもひどいものです。アルカリが手に入るなら、この方法は使わないでください。

---
### 2-3. 脱肉
&nbsp;&nbsp;&nbsp;皮の肉面に付いている脂肪、皮下組織、薄い膜を削り取る作業です。下準備の中で最も骨が折れ、最も急いで済ませがちな工程であり、失敗の原因として最も多いものです。

| 残した場合に起きること | 理由 |
| --- | --- |
| 鞣剤が浸透しない | 脂肪は水をはじくため、水溶性の薬剤が通らない |
| その部分だけが硬くこわばる | 薬剤が届かなかった繊維が、乾燥時に融合する |
| 時間がたつと酸敗する | 残った脂肪が酸化して悪臭を放ち、皮が変色する |
| カビが生える | 栄養豊富な皮下組織がカビのえさになる |
| 乾燥むらが出る | 厚さの異なる部分で乾く速さが違い、反る |

- 方法: 皮を丸太や丸い杭にかけ、体で押さえて、鈍い道具で押しのけるように削ります。
- 道具: 鋭い刃は真皮を切るため、鋭いナイフよりも、鈍い骨や鈍い鉄の方が適しています。
- 杭が丸い理由: 接触面が狭く、圧力が集中するためです。平らな板では力が分散し、組織が取れません。
- 毛側の表皮層も除去します。脱毛後に表面に残る薄くて滑りやすい膜は水を通さず、薬剤の浸透を妨げます。残すと、その面だけがつやつやして硬くなります。

---
### 2-4. 中和
&nbsp;&nbsp;&nbsp;脱毛を終えた皮はアルカリを含んでおり、どの鞣し方も効きません。タンニンはアルカリで酸化され、色が付くだけで結合しません。脳鞣しの乳濁液も、アルカリ条件では安定した膜を作れません。残ったアルカリはコラーゲンを分解し続けます。

1. 水を何度も替えて洗い、アルカリの大部分を取り除きます。
2. 残ったアルカリを弱酸で中和します。酢、酸味のある果汁、発酵させた穀物の水で十分です。強酸はコラーゲンを加水分解するため使いません。

| 判断 | 方法 |
| --- | --- |
| アルカリが残っているか | 手で触って石けんのようにぬるぬるするなら残っている |
| 膨潤が引いたか | 膨らんで張っていた皮が、柔らかく薄くなる |
| 洗う回数 | 気温が低ければ1日1回、高ければ2~3回交換する |
| 完了のしるし | 皮が水の中でぐったりと垂れ、手で絞ると澄んだ水が出る |

&nbsp;&nbsp;&nbsp;中和が終わったら、皮を絞って水分をしっかり抜きます。繊維の間が水で満たされていると、鞣剤が入る余地がありません。水が滴らなくなるまでねじるか、棒にかけて押さえてから、鞣しの工程に進みます。
