## 2. 剥皮から中和まで、準備工程が結果を左右する理由
&nbsp;&nbsp;&nbsp;鞣しで失敗する人の大部分は、鞣しの段階そのもので失敗するわけではありません。その前の準備工程のどこかを疎かにしたために失敗するのです。準備工程の目的は、真皮のコラーゲン繊維のみを残し、その隙間を薬液が通過できるように通り道を確保することにあります。

---
### 2-1. 剥皮
&nbsp;&nbsp;&nbsp;皮は生体から剥ぎ取った瞬間から腐敗が始まります。体から分離されると血流が絶たれて組織が死滅し、表面には屠殺過程で移行した細菌がすでに存在し、真皮は温かく湿潤な状態にあります。夏季の気温下では数時間、涼しい日であっても1日が限度となります。

&nbsp;&nbsp;&nbsp;剥皮において重要なのは、刃物による切削を最小限にとどめることです。刃物を多用するほど真皮に傷が入り、その傷は完成した革において孔や薄肉部となって現れます。皮下組織と真皮の間には比較的容易に剥離する面が存在するため、拳や鈍角な棒で押し込むように作業すれば、刃物を用いずとも相当部分を剥離できます。この手法は傷をほとんど残さないため、大型動物において特に有効です。

&nbsp;&nbsp;&nbsp;直ちに処理できない場合は、細菌が繁殖できない環境を形成して時間を稼ぐ必要があります。2つの方法が存在しますが、原理は同一であり、水分を奪うことです。

| 方法 | 原理 | 条件と限界 |
| --- | --- | --- |
| 塩蔵 | 食塩の浸透圧により組織の水分を抽出し細菌の利用可能水分を奪う | 皮の重量の30-50%の食塩を肉面に均一に擦り込みます。食塩が不足すると中心部から腐敗が進行します |
| 乾燥 | 水分を蒸発させて水分活性を低下させる | 日陰で通気を確保し張力をかけて乾燥させます。直射日光下で乾燥させると表面のみ硬化し内部が腐敗します |
| 凍結 | 低温により細菌および酵素の活動を停止させる | 冬季のみ可能であり、凍結融解の反復は繊維を損傷させます |

&nbsp;&nbsp;&nbsp;乾燥させた皮は後工程で水に浸漬して復元させる必要があり、この工程を水戻し（漬水）と呼びます。長期乾燥させた皮ほど水分の浸透に数日を要し、その間に水温が上昇すると槽内で腐敗が開始されます。水戻し期間中は最低1日1回以上の換水が必要です。

---
### 2-2. 脱毛
&nbsp;&nbsp;&nbsp;毛は物理的に引っ張っても抜くことは不可能です。毛根は真皮の深部まで達しているため、無理に引っ張ると真皮ごと引き裂かれます。したがって脱毛は力学の問題ではなく化学の問題であり、毛根を保持しているタンパク質を溶解させることが解決策となります。

&nbsp;&nbsp;&nbsp;毛および表皮を構成するケラチンにはシスチンと呼ばれるアミノ酸が豊富に含まれ、シスチン同士が形成するジスルフィド結合がケラチンを強固に架橋しています。強力なアルカリはこのジスルフィド結合を切断します。アルカリ性条件下で水酸化物イオンが結合を攻撃すると、ジスルフィド結合がチオール基へと開裂し、ケラチン構造が崩壊して毛が毛包から自然に脱落します。

| 項目 | 内容 |
| --- | --- |
| 目標pH | pH 11-13。これより低いと脱毛が進行しません |
| 所要期間 | 気温に依存し3日から10日。低温下では長期化します |
| 完了の目安 | 手で表面を擦った際、毛がまとまって滑脱すれば完了です |
| 過剰反応時 | アルカリがコラーゲンをも加水分解し、皮がぬめりを帯びて引張により破断します |
| 副次効果 | 繊維束が膨潤・開繊し、薬液の浸透経路が形成されます |

&nbsp;&nbsp;&nbsp;この副次効果は単なる付随的現象ではなく、実質的に第2の主目的です。アルカリにより真皮が膨潤すると繊維束間の空隙が拡張し、繊維同士を結合させていた非コラーゲン性物質が溶出します。この工程を経ない皮は、どれほど長期間鞣し液に浸漬しても表面のみ浸透し内部は未処理のまま残留します。

> **脱毛の目的は、毛の脱落と繊維間の通り道形成の2点であり、後者が最終品質をより強く左右します。**

&nbsp;&nbsp;&nbsp;アルカリを使用しない代替案として自然発酵（スウェッティング）が存在します。皮をぬるま湯に数日間浸漬させると、細菌が表皮を優先的に分解して脱毛が進行します。薬剤を必要としない長所がある反面、作業停止のタイミングの判別が極めて困難であり、僅かな遅延により真皮まで分解が進み皮が破棄処分となります。悪臭も極めて深刻です。アルカリが入手可能な環境下では避けるべき手法です。

---
### 2-3. フレッシング（肉削ぎ）
&nbsp;&nbsp;&nbsp;フレッシングとは、皮の肉面に付着した脂肪、皮下組織、薄膜を削り落とす作業です。準備工程の中で最も肉体的負担が大きく、最も疎かにされやすい段階であり、同時に失敗の最大の要因となります。

| 残留時に発生する不具合 | 理由 |
| --- | --- |
| 鞣し剤が浸透しない | 脂肪は疎水性を示すため、水溶性薬剤の通過を阻害します |
| 該当部位のみゴワゴワと硬化する | 薬剤が行き渡らない繊維が乾燥に伴い直接融着します |
| 経時変化により酸敗する | 残留脂肪が酸化して異臭を放ち皮を減色・変色させます |
| カビが発生・繁殖する | 皮下組織は栄養素に富みカビの好適な培地となります |
| 乾燥が不均一となる | 厚みの異なる部位が異なった速度で乾燥し歪みが発生します |

&nbsp;&nbsp;&nbsp;フレッシングは、丸太や曲面状の台の上に皮を覆いかぶせ、体重をかけて固定した上で、刃の付いていない具で押し出すように削り落とします。鋭利な刃物を使用すると真皮を切断してしまうため、良く切れるナイフよりも鈍角な骨や鈍利な金属器具が適しています。台が曲面状である理由は、接触面積を小さくして切削圧力を集中させるためです。平坦な板の上では力が分散し、組織の削ぎ落としが不可能です。

&nbsp;&nbsp;&nbsp;肉面のみならず、毛側の表皮層も除去する必要があります。脱毛が完了した皮の表面には薄く滑らかな膜が残留しますが、この膜は透水性が低く薬剤の浸透を遮断します。鞣し後もこの膜が残留していると、該当面のみ光沢を帯びて硬化します。

---
### 2-4. 中和
&nbsp;&nbsp;&nbsp;脱毛を完了した皮には多量のアルカリが残留・浸透しています。この状態ではいかなる鞣し方式も正常に機能しません。タンニンはアルカリ下で酸化して発色するのみで結合を形成できず、脳鞣しにおける乳化液はアルカリ性条件下で安定な皮膜を形成できません。残留アルカリは時間の経過と共にコラーゲンの加水分解を継続させます。

&nbsp;&nbsp;&nbsp;脱灰・中和は2段階で進行します。まず数回の換水洗浄により過半のアルカリを溶出させ、続いて弱酸を用いて残留アルカリを中和します。食酢、酸性の果汁、発酵させた穀物液等の弱酸で十分であり、強酸を使用すると酸自体がコラーゲンを加水分解させてしまいます。

| 判定 | 方法 |
| --- | --- |
| アルカリ残留の確認 | 官触にて石鹸のようなぬめりが感知される場合は残留しています |
| 膨潤度低下の確認 | 膨らみ張っていた皮が柔軟化し厚みが減少します |
| 洗浄頻度 | 低温下では1日1回、高温下では1日2-3回の換水を実施します |
| 完了の徴候 | 皮が水中でしなやかに垂れ下がり、手で絞った際に澄んだ水が排出されます |

&nbsp;&nbsp;&nbsp;中和完了後、皮を絞って水分を十分に除去する必要があります。繊維間が水分で満たされていると、鞣し剤が浸入する空隙が存在しないためです。絞り上げるか棒に掛けて加圧し、水滴が垂れなくなる状態まで脱水した上で鞣し工程へと移行します。
