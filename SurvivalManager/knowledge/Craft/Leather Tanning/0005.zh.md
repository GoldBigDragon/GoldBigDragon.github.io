## 4. 拉软、熏制、工具与作业环境
### 4-1. 拉软
&nbsp;&nbsp;&nbsp;拉软是在皮干燥的全过程中不断拉伸、加工和揉搓。即使鞣剂已经渗入，在干燥过程中纤维之间的水分蒸发，表面张力也会把相邻纤维拉到一起。放任不管，药剂的膜会在某些点被挤开，纤维直接粘连。拉软在粘连刚形成时就用机械方式把它拉开。

| 要素 | 内容 |
| --- | --- |
| 开始时间 | 表面水分消失、手上不再沾东西的时候 |
| 结束时间 | 直到皮完全干燥且摸起来温热。通常需几小时至一天 |
| 频率 | 不间断。哪怕放置15分钟，那个部位也会开始变硬 |
| 最先变硬的位置 | 颈部、腿部等薄的部位以及边缘 |
| 跳过时 | 无论药剂涂得多好，都会得到像木板一样的皮 |

&nbsp;&nbsp;&nbsp;跳过拉软会使之前的所有工序都失去意义。决定鞣制成败的不是药剂，而是干燥期间的劳动。

- 完全干燥后如果还有发硬的部位，是可以挽回的。把该部位重新弄湿，浸入鞣液，然后从头重新拉软。如果长时间完全硬着不管，粘连就会固定，难以恢复。
- 利用杠杆会很容易。在竖起的柱子顶端把钝刃朝上固定好，将皮搭在上面，双手拉拽，比手工加工大得多的力量集中在一条窄线上。
- 在树与树之间绑一根绳子，像拉锯一样来回拉皮摩擦，原理相同，一个人处理大张皮时很有效。

### 4-2. 熏制
&nbsp;&nbsp;&nbsp;即使经过拉软，脑鞣的皮在湿了再干后还是会再次变硬。这是因为油膜不与胶原结合，只是附着在表面，水进来时会重新排列或被洗出，纤维又粘在一起。

&nbsp;&nbsp;&nbsp;木材不完全燃烧时产生的烟中含有甲醛、乙二醛等醛类以及各种酚类化合物。醛类与胶原侧链上的氨基发生共价结合，把相邻的两条链连接起来。这样固定的胶原在水进入时也不会失去结构，所以干湿反复后仍保持柔软。酚类化合物能抑制霉菌和细菌，并驱避昆虫。

| 项目 | 内容 |
| --- | --- |
| 所需条件 | 有烟，无明火 |
| 好的燃料 | 腐朽易碎的木头、湿的阔叶树木片、松果、干苔藓 |
| 应避免的燃料 | 绿色针叶树枝。树脂会作为烟灰附着 |
| 温度 | 手能承受。过热的话，皮会被煮熟而皱缩 |
| 时间 | 一面20分钟至1小时，然后翻面重复 |
| 完成的标志 | 颜色从黄褐色均匀变为深褐色 |

- 最有效的方法是把皮缝成袋状，只留底部开口，在下方放置阴燃的炭火，让烟充满袋子。如果漏烟，到达皮上的烟变少，只会拉长时间。
- 一旦冒出火焰，皮会瞬间烧焦或因热而皱缩。用灰盖住炭火，熄灭火焰，只保留烟。
- 用单宁鞣制的皮已经发生了化学结合，所以熏制不是必需的。不熏制就无法完成的是脑鞣和油鞣一类。

### 4-3. 工具与作业环境
&nbsp;&nbsp;&nbsp;所有工具都可以用天然材料制作。它们的共同点是不锋利。锋利的工具会割破皮。

| 工具 | 形态 | 作用 |
| --- | --- | --- |
| 去肉桩 | 剥去树皮、斜着立起的圆木 | 把皮搭在上面，用身体压住。圆形表面使压力集中 |
| 去肉刮刀 | 刃钝的铁片，或劈开的大型动物胫骨 | 推掉脂肪、皮下组织和表皮层 |
| 绷皮框 | 用粗树枝编成的方形框架 | 沿皮的边缘打孔，用绳子绷紧捆扎 |
| 拉软桩 | 顶端磨圆变钝的木桩 | 把皮挂在上面拉拽，拉开纤维的粘连 |
| 浸泡容器 | 掏空的原木、大缸，或铺了皮的坑 | 盛放碱液和鞣液 |
| 熏袋 | 用皮缝成的筒 | 把烟困住，使其均匀接触皮 |

&nbsp;&nbsp;&nbsp;作业场地要远离住所。脱毛用的桶会散发强烈的硫化物和氨的气味，去肉时产生的脂肪和组织会招来大量苍蝇，腐臭味还会吸引捕食动物。如果把碱液和用过的鞣液直接排走，水生生物会死亡，下游取水的人也会受害。

| 项目 | 标准 |
| --- | --- |
| 与住所的距离 | 至少几十米，并位于下风向 |
| 与水的距离 | 距水源50m以上。不要直接倒入流水 |
| 废液 | 收集到坑里，用土覆盖。碱液用灰和土中和 |
| 残渣 | 脂肪和碎肉掩埋或焚烧 |
| 皮肤防护 | 用长棍处理碱液，沾到后立即冲洗 |

> **注意：** 氢氧化钙和草木灰水会溶解皮肤中的脂肪并造成灼伤，进入眼睛则会导致永久性损伤。疼痛出现得晚，人们往往没有意识到自己已经受伤，所以一旦接触，无论是否疼痛，都应立即长时间冲洗。

### 4-4. 毛皮与皮革在工序上的差异
&nbsp;&nbsp;&nbsp;带毛成品的毛皮必须保留毛，所以有些工序不能使用。

| 工序 | 皮革（去毛） | 毛皮（留毛） |
| --- | --- | --- |
| 脱毛 | 用碱去除毛 | 不做 |
| 使用碱 | 必需 | 不能使用。毛会脱落并受损 |
| 松开纤维 | 靠碱膨胀解决 | 以反复加工和弱酸代替 |
| 去肉 | 肉面和毛面都做 | 只做肉面。毛面不动 |
| 鞣制方法 | 所有方法均可 | 主要用脑、油、明矾。单宁会给毛染色 |
| 干燥与拉软 | 整个表面 | 只加工肉面，注意不要使毛缠结 |
| 熏制 | 两面 | 只熏肉面。气味会强烈渗入毛中 |

- 由于不能使用碱，缺少了松开纤维的步骤，药剂渗透较差。靠反复加工和多次涂油来弥补。同样大小的情况下，毛皮要费劲得多。
- 毛的状态因季节而异。晚秋到冬季捕获的动物毛最密，不容易脱落。春夏两季因换毛，毛变稀，用手一搓就掉。处理毛皮要选好季节。
- 平时，获取或加工野生动物的皮和毛皮受《野生生物保护及管理法》的监管。请确认所在国家的相关法律，并仅在法律范围内行动。
