## 4. 铲软（Staking）与熏烟，工具与作业环境
&nbsp;&nbsp;&nbsp;成功将鞣剂渗入生皮内部，并不意味着就能直接获得柔韧的皮革。最后还有铲软（Staking）与熏烟这两道工序，它们绝非可有可无的选项，而是将先前所有努力转化为最终成品的决定性阶段。

---
### 4-1. 铲软（Staking）
&nbsp;&nbsp;&nbsp;铲软是指在皮革干燥的全过程中，不断进行拉伸、揉搓和摩擦的强体力劳动。既然鞣剂已经渗入纤维之间，为何还需要这项极其繁重的体力活，只要观察干燥过程中作用于纤维间的物理力便能一目了然。

&nbsp;&nbsp;&nbsp;当残留在纤维之间的水分蒸发时，水的表面张力会将相邻的纤维相互拉拢。这种力在单个位点上看似微不足道，但由于结合点的数量极其庞大，累加起来的合力相当惊人。即便鞣剂已包覆在纤维表面，若在干燥过程中听之任之，表面张力依然会将纤维拉紧贴合，在某些局部甚至会挤开鞣剂膜，导致纤维之间直接粘连。铲软的本质，就是在这类粘连刚一发生时，就通过机械外力将其强制剥离。

| 评估要素 | 具体内容 |
| --- | --- |
| 何时开始 | 当表面的水渍消退、手摸上去不再发湿黏手时即可开始 |
| 持续至何时 | 直至皮革彻底干燥且摸上去带有体温微热感（通常需要数小时至一整天） |
| 操作频率 | 连续不间断；即便仅搁置15分钟，该部位就会开始结硬 |
| 何处最先结硬 | 颈部、腿部等较薄部位以及边缘地带 |
| 若跳过该工序 | 无论先前鞣剂渗透得有多完美，成品都会变成像木板一样板硬 |

> **若跳过铲软工序，先前所有的工序都将变得毫无意义。最终决定鞣制成败的绝非化学药剂，而是干燥过程中的体力劳动。**

&nbsp;&nbsp;&nbsp;若皮革彻底晾干后依然残存板硬部位，此时仍有补救余地：将该部位重新打湿，浸入鞣制溶液中，随后从头重新进行铲软即可。反之，若听任其彻底硬化并长期搁置，纤维间的粘连就会固定下来，届时将极难修复。

&nbsp;&nbsp;&nbsp;简化铲软操作的方法是借用杠杆原理。在直立立起的木桩顶端固定一把钝刃朝上的工具，将皮革搭在上面并用双手用力下拉，这比单靠双手揉搓能将大得多的力量集中在极窄的线条上。在树木之间拉紧绳索，将皮革搭在上面像锯木头一样来回摩擦也是同样的原理，在单人处理大张皮革时尤为有效。

### 4-2. 熏烟
&nbsp;&nbsp;&nbsp;脑鞣皮革即便完成了铲软工序，依然留有一处致命短板：一旦浸水晾干，就会重新变硬。这是因为油膜仅仅是附着在纤维表面而非与胶原蛋白建立了化学结合，水分渗入后油膜会被冲刷或重新分布，导致纤维再次粘连。

&nbsp;&nbsp;&nbsp;熏烟从化学层面根治了这一问题。木材不完全燃烧时产生的烟雾中含有甲醛、乙二醛等醛类化合物以及多种酚类化合物。醛类能与胶原蛋白侧链上的氨基发生化学反应建立共价交联，将相邻的两条分子链连接起来。以此方式固定的胶原蛋白即便有水分渗入，结构也不会崩溃，因而经历浸水晾干后依然能保持最初的柔韧性。酚类化合物此外还能抑制霉菌和细菌滋生，并起到驱虫作用。

| 项目 | 具体内容 |
| --- | --- |
| 核心条件 | 仅产生浓烟而绝无明火的状态 |
| 优质燃料 | 腐烂发酥的朽木、湿润的阔叶树木屑、松果、干苔藓 |
| 应避免的燃料 | 针叶树的鲜枝（树脂会转化为黑烟烟灰附着在皮革上） |
| 温度 | 手放在上方能够忍受的温度；若过热，皮革会被烫熟发生剧烈收缩 |
| 时间 | 单面熏蒸20分钟至一小时，随后翻面重复 |
| 完工标志 | 色泽均匀转变为黄褐色至深褐色 |

&nbsp;&nbsp;&nbsp;熏烟最有效率的操作方式是将皮革缝制成仅底部开口的袋状/圆锥状，下方置放散发浓烟的烟灰余烬，使烟雾充满袋内。若烟雾漏散，接触皮革的烟量就会减少，耗时也会随之拉长。由于明火会在数秒内烧毁皮革或导致热收缩，因此必须用灰烬盖住余烬压灭明火，维持仅冒浓烟的状态。

&nbsp;&nbsp;&nbsp;用单宁鞣制成的皮革由于内部已建立了强固的化学结合，因而熏烟并非必选项。未经过熏烟就不能算作完工的，特指脑鞣法与油脂鞣法体系。

### 4-3. 工具与作业环境
&nbsp;&nbsp;&nbsp;鞣制所需的工具均可以从自然界中取材制造。所有工具的共同特征在于“绝不锋利”，锋利的工具会切伤真皮层。

| 工具 | 形式构造 | 作用 |
| --- | --- | --- |
| 刮脂台 | 将剥去树皮的圆木斜向立起 | 搭挂皮革并用身体重压固定，圆弧面可集中刮削压力 |
| 肉刮刀 | 钝刃铁器、大型动物割开的胫骨 | 刮除脂肪、皮下组织以及表皮层 |
| 鞣制框 | 用粗树枝搭成的方形框架 | 在皮革边缘打孔，用绳索将其拉紧绷平 |
| 铲软桩 | 顶端打磨得光滑圆钝的立桩 | 挂搭皮革并下拉拉伸，切断纤维间的粘连 |
| 浸泡槽 | 掏空的圆木、大型陶罐、垫有皮张的土坑 | 盛装碱液与单宁液 |
| 熏烟袋 | 用皮革缝制而成的筒状袋 | 锁住烟雾，使其均匀接触皮革全貌 |

&nbsp;&nbsp;&nbsp;作业场地出于恶臭与废水的考量，必须远离日常生活居住区。处于脱毛阶段的容器会散发出剧烈的硫化合物与氨气恶臭；刮脂产生的脂肪与组织会招来大量苍蝇；腐烂恶臭还会引来捕食性野生动物。碱液与鞣制废液若直接排放会毒害水生生物，并对下游取水者造成伤害。

| 评估项目 | 规范标准 |
| --- | --- |
| 与居住区的距离 | 至少数10米以上，且处于下风向 |
| 与水源的距离 | 距离饮用水源50米以上，绝不可直接排入流动水体 |
| 废液处理 | 收集于土坑中用土掩埋，碱液需用草木灰和泥土中和 |
| 残渣处理 | 脂肪与肉渣应予掩埋或焚烧 |
| 皮肤防护 | 碱液会灼伤皮肤，应使用长木棒操作，若接触应立即冲洗 |

&nbsp;&nbsp;&nbsp;处理碱液时的防范措施与手工制皂一致。氢氧化钙与草木灰水会溶解皮肤脂肪造成化学灼伤，溅入眼睛会导致永久性损伤。由于痛感往往延迟出现，很多时候已造成伤害却浑然不知，因此一旦接触，无论当时是否感到疼痛，都必须立即用大量清水长时间冲洗。

### 4-4. 毛皮与皮革的工序差异
&nbsp;&nbsp;&nbsp;保留体毛进行加工的毛皮（Far）无法采用上述工序中的某些步骤。所有的差异均源于“必须保留体毛”这一限制条件。

| 工序 | 皮革（去毛） | 毛皮（带毛） |
| --- | --- | --- |
| 脱毛 | 用碱液脱去毛发 | 完全不进行 |
| 碱液使用 | 必需工序 | 绝对禁用（会导致脱毛与毛质损伤） |
| 撑开纤维 | 通过碱液膨胀解决 | 替换为反复揉搓与弱酸处理 |
| 刮脂 | 肉面与毛面均需处理 | 仅处理肉面；毛面绝不触碰 |
| 鞣制方式 | 所有方式均适用 | 以脑鞣、油脂鞣、明矾鞣为主；单宁会染污毛发 |
| 干燥与铲软 | 覆盖整张皮革 | 仅揉搓肉面，防止压塌体毛 |
| 熏烟 | 双面进行 | 仅在肉面进行；毛发会吸收剧烈的烟臭味 |

&nbsp;&nbsp;&nbsp;毛皮加工中无法使用碱液是最大的限制。由于缺少了撑开纤维间隙的工序，鞣剂渗透性变差，必须通过反复揉搓以及多次浸涂油脂来进行弥补。这也是为何相同面积的毛皮要比普通皮革耗费多得多的手工精力的原因。

&nbsp;&nbsp;&nbsp;体毛的品相极度依赖于季节。深秋至冬季捕获的动物体毛最为密实且不易脱落；春季至夏季处于换毛期，体毛稀疏且用手轻搓就会脱落。用于制备毛皮的生皮必须挑选季节。此外，在日常状况下获取或加工野生动物的生皮与体毛，同样受到《野生生物保护及管理相关法律》的约束，务必确认所在国家的相关法律法规，并在法律许可的范围内行事。
