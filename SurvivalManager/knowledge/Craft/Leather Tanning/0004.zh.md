## 3. 鞣制方式
&nbsp;&nbsp;&nbsp;完成准备工序的生皮中填入何种物质，将直接决定成品皮革的物理性质。利用自然界中可获取的材料，可行的鞣制方式主要有三种，每种方式所充填的物质以及该物质与胶原蛋白建立的化学/物理结合性质均有所不同。

---
### 3-1. 脑鞣法
&nbsp;&nbsp;&nbsp;动物脑髓重量的一半以上为脂质，其中相当一部分是以卵磷脂为主的磷脂。磷脂分子的结构一端亲水、另一端亲油，溶于水后可作为乳化剂，将油脂包裹并悬浮为微小液滴。

&nbsp;&nbsp;&nbsp;之所以将这一特性用于鞣制，是因为水分扮演了载体的角色。纯油脂是无法渗入湿润生皮内部的。然而将脑髓溶于水制成的乳化液，却能随水分一同渗入至纤维间隙的每一个角落；随着生皮晾干、水分蒸发，唯有磷脂和脂肪留存于纤维表面形成一层薄膜。这层薄膜阻断了纤维之间的直接接触，从而防止发生粘连。

| 项目 | 细节内容 |
| --- | --- |
| 溶液温度 | 40-50°C。温度过高会损伤胶原蛋白，过低则脂肪凝固无法渗透 |
| 重复次数 | 浸泡、拧干、揉搓反复执行二至三次以上。仅操作一次无法渗入中心 |
| 结合性质 | 属于物理包覆而非化学结合，因而可以被冲洗洗去 |
| 必需后续工序 | 铲软（Staking）与熏烟。二者缺一不可，否则皮革会重新变硬 |

&nbsp;&nbsp;&nbsp;有一条广为流传的经验法则：“每只动物的脑髓都恰好足够鞣制它自己的皮”。实际上，体型越大的动物生皮面积越大、脑髓也越大，因此大体上确实符合，但并非严格的成比例关系。有些物种（如人类和猪）相对于体重脑髓偏大，而有些物种（如肉牛）生皮过于厚重，仅凭一个脑髓是不够用的。

&nbsp;&nbsp;&nbsp;当无法获取脑髓时，有替代材料可用。核心在于提供磷脂或可被乳化的脂肪。

| 替代材料 | 作用成分 | 备注 |
| --- | --- | --- |
| 蛋黄 | 卵黄素（卵磷脂）与脂肪 | 成分与脑髓最为接近，替代效果极佳 |
| 肝脏 | 磷脂与脂肪 | 研磨捣碎后溶于水中使用 |
| 骨髓 | 以脂肪为主 | 乳化能力较弱，需配合肥皂或蛋黄一同使用 |
| 动物脂肪 + 肥皂 | 脂肪与表面活性剂 | 由肥皂承担乳化剂的作用 |
| 植物油 + 鸡蛋 | 脂肪与卵磷脂 | 应避免使用容易酸败变质的油类 |

### 3-2. 植物单宁鞣法
&nbsp;&nbsp;&nbsp;单宁是存在于树皮、树叶和果实中的多酚类化合物。单一单宁分子上带有多个酚羟基，能够与胶原蛋白分子表面的肽键部位在多个位点同时建立氢键。当一个单宁分子跨接在两条相邻的胶原蛋白链上时，就相当于在它们之间架起了一座桥梁；当无数座桥梁建立起来后，胶原蛋白结构本身就被永久固定了下来。

&nbsp;&nbsp;&nbsp;如果说脑鞣法是在纤维表面包覆油膜的物理处理，那么单宁鞣法则是与胶原蛋白建立化学结合，从而改变了蛋白质本身的性质。因此，用单宁鞣制成的皮革即便浸水，鞣质成分也不会被洗去，细菌也极难分解胶原蛋白。收缩温度能够大幅提升至75-85°C，正是源于这种强固的化学结合。

| 材料 | 单宁含量 | 特征 |
| --- | :---: | --- |
| 橡树（栎树）树皮 | 8-16% | 最为通用，呈现优雅淡雅的棕褐色 |
| 栗树树皮与木材 | 10-13% | 与橡树相似，萃取效率高 |
| 漆树科植物叶片（如漆树、盐肤木） | 25-30% | 含量极高且色泽明亮，但漆过敏者应避免使用 |
| 松树与云杉树皮 | 5-18% | 极易获取，但呈红褐色且混有树脂 |
| 桤木树皮 | 变幅较大 | 幼树萃取效果良好 |
| 柳树树皮 | 中等 | 极易在水边采集 |
| 橡子壳（橡斗） | 25-35% | 秋季可大量收集 |

&nbsp;&nbsp;&nbsp;单宁溶液必须严格从稀薄浓度开始，随后循序渐进地提高浓度。若从一开始就浸泡在高浓度溶液中，单宁会瞬间与表层的胶原蛋白结合并使其密实化，阻断单宁向内部的进一步渗透。这会导致只有表层被鞣制而内部依然是生皮的状态；一旦晾干，中间层就会硬化断裂。相反，从稀溶液开始能让单宁缓慢而深入地渗透至内部，随后提升浓度即可完成彻底交联。

> **在单宁鞣制中操之过急，会导致外表被鞣制而内部依旧是生皮。提升浓度的节奏直接决定了品质。**

&nbsp;&nbsp;&nbsp;所需时间与生皮厚度成正比。纤薄的兔子或山羊皮需要数周，鹿皮需要一至两个月，而厚重的牛皮则需要半年至一年之久。当生皮首次放入时，溶液中的单宁在一天之内就会被消耗殆尽，因此初期需频繁更换鞣液，后期可拉长间隔。判定进度的方法是切开生皮，观察截面颜色是否已均匀渗透至正中心。

### 3-3. 明矾鞣法
&nbsp;&nbsp;&nbsp;明矾是铝和钾的复盐，溶于水后会释放出铝离子。这些离子与胶原蛋白的羧基建立配位键，从而固定纤维。该方法仅需数日即可完成，且成色洁白柔韧，传统上常用于制造手套和纤薄皮革。

&nbsp;&nbsp;&nbsp;然而，该方法存在着致命的局限。铝离子与胶原蛋白的结合是可逆的，一旦再次淋水浸泡，铝离子就会脱落并被洗掉。淋一次雨就会导致鞣制效果失效，晾干后皮革会重新变硬。因此严格来说，它有时不被归为真正意义上的“鞣制”，而被划为单独的类别（拟鞣/Tawing）。在明矾鞣制的皮革中浸透充足的油脂以阻隔水分，可在一定程度上弥补这一缺陷。

| 方式 | 所需时间 | 材料 | 成品皮革性质 | 耐水性 |
| --- | :---: | --- | --- | :---: |
| 脑鞣法 | 数日 | 脑髓、蛋黄、肝脏、油脂 | 极度柔韧亲肤且有弹性 | 经熏烟后可获得保证 |
| 植物单宁 | 数周至一年 | 树皮、橡子壳 | 坚硬定型且厚重 | 良好 |
| 明矾 | 数日 | 明矾 | 洁白柔韧且纤薄 | 极差 |
| 仅熏烟 | 一至两天 | 烟雾 | 仅作为其他方式的收尾工序才有意义 | 起辅助补充作用 |
| 未鞣制（生皮） | 仅需 drying 时间 | 无 | 极其坚硬僵直 | 遇水即软化 |

&nbsp;&nbsp;&nbsp;这三种方式各有其适用场景。对于衣服以及鞋里等贴身且需频繁折叠的部位，脑鞣法最为适宜；对于鞋底、腰带以及刀鞘等需要保持形态的部位，单宁鞣法最为匹配。明矾则仅受限用于绝不接触水分的纤薄皮革。在实际操作中，人们常将多种工序叠加使用（例如先用单宁鞣制皮革，随后再浸透油脂），从而同时获得单宁的结构稳定性与油脂的柔韧性。
