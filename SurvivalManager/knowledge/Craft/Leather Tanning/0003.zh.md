## 2. 从剥皮到中和，准备工序决定最终成败的原因
&nbsp;&nbsp;&nbsp;在鞣制中遭遇失败的人，绝大多数并非败在最后的鞣制步骤上，而是因为敷衍对待了先前的某道准备工序。准备工序的宗旨在于仅保留真皮层的胶原蛋白纤维，并打通纤维间让鞣剂得以穿透的通道。

---
### 2-1. 剥皮
&nbsp;&nbsp;&nbsp;生皮自脱离母体的那一刻起，腐烂便已悄然开始。一旦离开躯体，血液循环停止导致组织死亡；屠宰过程中转移至表面的细菌早已存在；而真皮层又处于温热且湿润的状态。在夏季气温下，几小时便是极限，即便在凉爽的天气里，一天也是绝对的上限。

&nbsp;&nbsp;&nbsp;剥皮时的核心要领在于将刀具的使用切割量降至最低。刀具使用得越多，真皮层受到的割伤就越多，而这些割伤在成品皮革上就会变成空洞或薄弱处。在皮하组织与真皮层之间存在着一层相对容易剥离的自然间隙，用拳头或钝木棒进行顶推，无需用刀便能剥下相当大一部分。这种方法几乎不会留下割伤，在处理大型动物时尤为有利。

&nbsp;&nbsp;&nbsp;当无法立即进行后续处理时，必须创造细菌无法滋生的条件以争取时间。有两种主要方法，其原理完全一致：剥夺水分。

| 方法 | 原理 | 条件与局限 |
| --- | --- | --- |
| 盐渍 | 盐依靠渗透压抽出组织中的水分，剥夺细菌可利用的水分 | 在肉面均匀涂抹相当于生皮重量30-50%的盐。若用盐不足，会从中心部位开始腐烂 |
| 干燥 | 蒸发水分以降低水分活性 | 在阴凉通风处拉紧绷平晾干。若在阳光下直射暴晒，仅表层硬化而内部会发生腐烂 |
| 冰冻 | 降低温度以抑制细菌与酶的活性 | 仅在冬季可行；反复冻融会损伤胶原蛋白纤维 |

&nbsp;&nbsp;&nbsp;晾干的生皮日后必须通过浸泡在水中进行复原，这一步骤被称为“浸水（浸泡）”。晾干时间越长的生皮，水分渗透所需的天数就越多；在此期间若水温偏高，容器内部就会引发腐烂。在浸水过程中，每天必须换水一次以上。

---
### 2-2. 脱毛
&nbsp;&nbsp;&nbsp;单纯依靠物理拔拽是无法将毛发拔除干净的。毛根深扎于真皮层内部，强行拔拽会将真皮层一并撕裂。因此，脱毛并非力学问题，而是化学问题：将固着毛根的蛋白质予以溶解才是解法。

&nbsp;&nbsp;&nbsp;构成毛发与表皮的角蛋白中富含一种名为胱氨酸的氨基酸，胱氨酸之间形成的二硫键将角蛋白紧紧交联在一起。强碱能够断裂这种二硫键。在碱性条件下，氢氧根离子攻击该交联键，使二硫键裂解为巯基，角蛋白结构随之崩溃，毛发便会从毛囊中自然脱落。

| 项目 | 细节内容 |
| --- | --- |
| 目标pH值 | pH 11-13。若低于此范围，毛发将无法脱落 |
| 所需时间 | 视气温而定，约需三至十天。天气寒冷时耗时更长 |
| 完工判定 | 用手搓拭表面时，毛发成把滑动脱落即告完成 |
| 若反应过度 | 强碱会进一步水解胶原蛋白，导致生皮发滑且一拉即撕裂 |
| 副次效应 | 纤维束膨胀撑开，打通了鞣剂渗入的通道 |

&nbsp;&nbsp;&nbsp;这一副次效应绝非可有可无，本质上是第二大主要目的。生皮在碱液中发生膨胀后，纤维束之间的间隙随之扩大，原本将纤维相互粘结的非胶原蛋白物质被溶解洗去。未经过此道工序的生皮，无论在鞣制液中浸泡多久，都只能渗透表层而内部依旧保持生生状态。

> **脱毛的目的有两个：一是脱去毛发，二是打通纤维间隙的通道；而第二个目的对最终成败的影响更为深远。**

&nbsp;&nbsp;&nbsp;不使用碱液的替代方案是自然发酵（发汗法）。将生皮浸泡在温水中数日，细菌会优先分解表皮层从而使毛发脱落。该方法虽然具备无需添加化学试剂的优势，但极难精准把握终止时机，稍有延误就会分解至真皮层导致生皮报废。恶臭也极其剧烈。只要能获取碱液，就应尽量避免使用该法。

---
### 2-3. 刮脂（Fleshing）
&nbsp;&nbsp;&nbsp;刮脂是指刮除附着在生皮肉面上的脂肪、皮下组织以及薄膜的工序。这是准备工序中最耗费体力、也最常被敷衍对待的步骤，同时也是导致鞣制失败的最常见诱因。

| 若有残留会导致的后果 | 根本原因 |
| --- | --- |
| 鞣剂无法渗入 | 脂肪具有疏水性，阻挡水溶性鞣剂穿透 |
| 仅该部位板硬硬化 | 未接触到鞣剂的纤维在干燥时会直接融合粘连 |
| 随着时间推移发生酸败 | 残留脂肪发生氧化，散发恶臭并导致皮革变色 |
| 滋生霉菌 | 皮下组织营养丰富，是霉菌的绝佳温床 |
| 干燥不均匀 | 厚度不同的部位干燥速率不一，导致皮革扭曲变形 |

&nbsp;&nbsp;&nbsp;刮脂的操作方法是将生皮搭在圆木或圆柱台架上，用身体压紧固定，随后用钝刃工具向上推挤刮除。使用锋利的刃口会切伤真皮层，因此相比锋利的刀具，钝骨或钝金属器具反而更为合适。台架呈圆弧形的原因在于缩小接触面积以集中刮削压力；若在平整的板上操作，力量会分散开来而无法剥离组织。

&nbsp;&nbsp;&nbsp;除了肉面外，毛面的表皮层也必须予以去除。脱毛完成后的生皮表面会残留一层薄而滑腻的膜，该膜透水性极差，会阻碍鞣剂滲透。若鞣制完成后该膜依然残留，该表面就会发亮且板硬。

---
### 2-4. 中和
&nbsp;&nbsp;&nbsp;完成脱毛的生皮内部饱含碱液。在此状态下，任何鞣制方式都无法正常发挥作用。单宁在碱性环境下会发生氧化而仅显色却无法建立化学结合，脑鞣工艺中的乳化液在碱性条件下也无法形成稳定的薄膜。残留的碱液随着时间推移还会持续水解胶原蛋白。

&nbsp;&nbsp;&nbsp;脱碱与中和分为两个阶段进行。首先通过多次换水清洗洗去绝大部分碱液，随后使用弱酸中和剩余的碱。食醋、酸性果汁或发酵谷物水等弱酸即已足够；若使用强酸，酸本身又会水解胶原蛋白。

| 判定项目 | 操作与现象 |
| --- | --- |
| 检查是否有碱残留 | 用手触摸时若依然像肥皂般滑腻，说明仍有碱残留 |
| 检查膨胀是否消退 | 原本膨脹绷紧的生皮变得柔软塌软，厚度明显减薄 |
| 清洗换水频率 | 气温较低时每天换水一次，气温较高时每天换水二至三次 |
| 完工标志 | 生皮在水中自然软垂，用手挤压时排出清澈的水 |

&nbsp;&nbsp;&nbsp;中和完成后，必须挤压生皮以排出相当一部分水分。若纤维间隙充盈着水分，鞣剂就无处容身。拧干或挂在木棒上加压至不再滴水后，方可进入鞣制阶段。
