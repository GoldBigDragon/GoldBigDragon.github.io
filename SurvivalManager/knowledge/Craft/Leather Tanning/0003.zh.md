## 2. 准备工序：剥皮、脱毛、去肉、中和
&nbsp;&nbsp;&nbsp;准备工序的目的是只留下真皮的胶原纤维，并为药剂打开通路。鞣制失败大多不出在鞣制工序，而是出在草草带过这些工序。

---
### 2-1. 剥皮
&nbsp;&nbsp;&nbsp;皮一经剥离就开始腐烂。可处理的时限在夏季气温下为数小时，即使天气凉爽也不超过一天。

- 尽量少用刀。刀用得越多，真皮上的划痕越多，这些划痕会成为成品皮革上的孔洞或薄弱处。
- 皮下组织与真皮之间有一个容易分开的层面。用拳头或钝木棍向里推，不用刀也能剥下相当大的一部分，而且几乎不留损伤，这对大型动物有利。

&nbsp;&nbsp;&nbsp;如果不能立刻处理，就把水分去掉，使细菌无法繁殖，争取时间。

| 方法 | 原理 | 条件与限制 |
| --- | --- | --- |
| 盐腌 | 盐通过渗透压把组织中的水分吸出 | 把皮重30~50%的盐均匀搓在肉面上。盐太少会从中间开始腐烂 |
| 干燥 | 蒸发水分以降低水分活度 | 绷紧后在通风的阴凉处晾干。在阳光直射下晾，只有表面变硬，里面会腐烂 |
| 冷冻 | 降低温度使细菌和酶停止活动 | 只有冬季才能做到。反复冻融会损伤纤维 |

&nbsp;&nbsp;&nbsp;晾干的皮之后必须泡水复原（浸水）。皮晾干的时间越长，水渗入所需的天数越多，在此期间如果水温偏高，就会开始腐烂。浸水期间每天至少换一次水。

---
### 2-2. 脱毛
&nbsp;&nbsp;&nbsp;毛根深深扎在真皮里，所以硬拔毛会连真皮一起撕裂。因此要用碱溶解固定毛根的蛋白质（角蛋白），让毛自行脱落。这是因为强碱会破坏维系角蛋白的二硫键。

- 草木灰水：把木灰泡在水里制成。主要成分是碳酸钾。
- 氢氧化钙：把贝壳或石灰石烧过后与水混合而成。碱性强且持续时间更长，更适合脱毛（这就是工业工艺中使用生石灰的原因）。

| 项目 | 内容 |
| --- | --- |
| 目标pH | 11~13。低于此值，毛脱不下来 |
| 所需时间 | 视温度为3~10天。天冷时更久 |
| 判断完成的方法 | 用手一搓，毛成把地滑落 |
| 过度时 | 碱也会水解胶原，皮变得黏滑，一拉就破 |
| 副作用 | 纤维束膨胀松开，为药剂打开渗入的通路 |

&nbsp;&nbsp;&nbsp;这个副作用其实是第二个目的，而且对结果的影响更大。真皮在碱中膨胀时，纤维束之间的缝隙变宽，把纤维粘在一起的非胶原物质也被溶解掉。没有经过这一步的皮，无论在鞣液里泡多久，药剂也只渗入表面，里面原样不变。

&nbsp;&nbsp;&nbsp;不用碱的替代方法是自然发酵。把皮泡在温水中几天，让细菌先分解表皮，毛就会脱落。不需要任何材料。但是很难判断何时停止，稍有延误真皮也会被分解，整张皮就废了，而且气味极其难闻。如果能弄到碱，就不要用这种方法。

---
### 2-3. 去肉
&nbsp;&nbsp;&nbsp;这是刮掉粘在皮的肉面上的脂肪、皮下组织和薄膜的工作。它是准备工序中最辛苦、最容易被草草了事的一步，也是最常见的失败原因。

| 残留时的后果 | 原因 |
| --- | --- |
| 鞣剂无法渗入 | 脂肪排斥水，水溶性药剂无法通过 |
| 只有该部位变硬发挺 | 药剂没有到达的纤维在干燥时熔合 |
| 随时间推移而酸败 | 残留的脂肪氧化，产生异味并使皮变色 |
| 长霉 | 营养丰富的皮下组织会滋生霉菌 |
| 干燥不均 | 厚度不同的部位干燥速度不同，导致翘曲 |

- 方法：把皮搭在圆木或圆柱上，用身体压住，用钝工具像推开一样刮。
- 工具：锋利的刃会割破真皮，所以比起锋利的刀，钝的骨头或钝铁器更合适。
- 柱子要圆的原因：接触面窄，压力集中。在平板上力量会分散，组织刮不下来。
- 毛面的表皮层也要去除。脱毛后残留在表面的薄而滑的膜不透水，会阻挡药剂渗入；若不去除，只有那一面会发亮变硬。

---
### 2-4. 中和
&nbsp;&nbsp;&nbsp;脱毛完成的皮浸透了碱，任何鞣制方法都对它无效。单宁会被碱氧化，只上色而不结合，脑鞣的乳液在碱性条件下也无法形成稳定的膜。残留的碱还会继续分解胶原。

1. 用大量清水多次冲洗，去除大部分碱。
2. 用弱酸中和剩余的碱。醋、酸味果汁或发酵谷物水即可。不要用强酸，因为它会水解胶原。

| 判断 | 方法 |
| --- | --- |
| 是否残留碱 | 手摸起来像肥皂一样滑，就说明还有残留 |
| 膨胀是否消退 | 膨胀绷紧的皮变软变薄 |
| 冲洗次数 | 气温低时每天换一次，气温高时换两三次 |
| 完成的标志 | 皮在水中软软地垂下，用手攥时流出清水 |

&nbsp;&nbsp;&nbsp;中和完成后，要把皮攥干，去除大量水分。如果纤维之间的空隙充满水，鞣剂就没有进入的余地。拧绞，或者搭在杆子上按压，直到不再滴水，然后进入鞣制工序。
