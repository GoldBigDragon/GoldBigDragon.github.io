## 4. ステーキングと燻煙、道具と作業環境
&nbsp;&nbsp;&nbsp;鞣し剤を浸透させることに成功したからといって、直ちに柔軟な革が得られるわけではありません。最終段階であるステーキングと燻煙の2工程が残されており、これらは単なる選択的工程ではなく、これまでのすべての努力を結果として結実させる工程です。

---
### 4-1. 스テーキング（揉みほぐし）
&nbsp;&nbsp;&nbsp;ステーキングとは、革が乾燥する過程において終始引っ張り、揉み、擦り合わせる重労働です。鞣し剤がすでに繊維間に存在するにもかかわらず、なぜこの過酷な作業が必要となるかは、乾燥中に作用する物理力を観察すれば理解できます。

&nbsp;&nbsp;&nbsp;繊維間に残留した水分が蒸発する際、水の表面張力が隣接する繊維同士を引き寄せます。この力は単一の接点では極小に見えますが、接点数が天文学的数値であるため総和は絶大なものとなります。鞣し剤が繊維表面を被覆していても、乾燥中に放置すれば表面張力が繊維を密착させ、一部の箇所では薬剤の皮膜が押し退けられて繊維同士が直接固着してしまいます。ステーキングとは、この固着が発生する度に機械的に引き剥がす作業に他なりません。

| 要素 | 内容 |
| --- | --- |
| 開始タイミング | 表面の水気が引き、手への付着がなくなった時点から |
| 終了タイミング | 革が完全に乾燥し、触感に温もりが感じられるまで（通常数時間から丸一日） |
| 作業頻度 | 絶え間なく実施。15分間放置しただけでも該当部位の硬化が開始します |
| 硬化の先発部位 | 首や足などの薄肉部位、および周縁部 |
| 省略した場合 | どれほど良好に鞣し剤を浸透させても、板のように硬い革となります |

> **ステーキングを省略すれば、それ以前のすべての工程が無意味化します。鞣しの成否を最終的に決定づけるのは薬剤ではなく、乾燥過程における物理的労働です。**

&nbsp;&nbsp;&nbsp;革が完全乾燥した後に硬化部位が残留した場合でも、未だ修復は可能です。該当部位を再湿潤させて鞣し液に浸漬し、初期段階からステーキングを再実施すれば解決します。逆に放置して完全硬化させた状態で長期放置すると、繊維の固着が固定化されて復元が困難となります。

&nbsp;&nbsp;&nbsp;ステーキングの作業効率を高める手法はてこの原理の活用です。直立させた支柱の先端に鈍利な刃を上方に向けて固定し、革を引っ掛けて両手で牽引すれば、手で揉みほぐすよりもはるかに強大な力が狭小な線上に集中します。樹木間にロープを緊結し、革を引っ掛けて鋸引きのように摩擦させる手法も同一の原理であり、単独で大型の革を処理する際に極めて有効です。

### 4-2. 燻煙
&nbsp;&nbsp;&nbsp;脳鞣し革はステーキングを完了した段階であっても、一つの致命的弱点が残留します。水に濡れた後に乾燥すると、再度硬化するという点です。油膜はコラーゲンと化学的に結合しているわけではなく表面に付着しているに過ぎないため、水分の侵入に伴い再配置・溶出が起こり、繊維が再固着するためです。

&nbsp;&nbsp;&nbsp;燻煙はこの問題を化学的に解決します。木材の不完全燃焼時に発生する煙には、ホルムアルデヒドやグリオキサール等のアルデヒド類、および各種フェノール化合物が含まれています。アルデヒドはコラーゲン側鎖のアミノ基と反応して共有結合を形成し、隣接する2本の分子鎖間に架橋を形成します。このように固定化されたコラーゲンは、水分の侵入を受けても構造が崩壊しないため、濡れた後に乾燥しても初期の柔軟性を維持します。フェノール化合物はこれに加え、カビや細菌の繁殖を抑制し害虫を忌避させます。

| 項目 | 内容 |
| --- | --- |
| 必要条件 | 有炎燃焼を伴わない濃煙状態 |
| 好適な燃料 | 朽ちて脆化した木材、湿潤な広葉樹チップ、松かさ、乾燥苔 |
| 回避すべき燃料 | 針葉樹の生枝（樹脂分がすすとなって付着します） |
| 温度 | 手をかざして耐えられる程度。高温だと革が変性・収縮します |
| 時間 | 片面につき20分から1時間、反転させて反復 |
| 完了の目安 | 色彩が一様に黄褐色から濃褐色へ変化します |

&nbsp;&nbsp;&nbsp;燻煙の最も効率的な構造は、革を筒状（袋状）に縫い合わせて下部のみを開放し、その下部に燻熱発煙体を配置して煙を内部に充満させる方式です。煙が漏出すると革への接触効率が低下して作業時間が長期化します。炎が立ち上ると革が瞬時に焼失または熱収縮するため、熾火の上に灰を被せて消炎し、発煙状態のみを維持する必要があります。

&nbsp;&nbsp;&nbsp;植物タンニンで鞣した革は、すでに化学結合が完了しているため燻煙は必須ではありません。燻煙が未完了の段階で完成とみなせないのは、脳鞣しおよび油脂鞣し系統の革です。

### 4-3. 道具と作業環境
&nbsp;&nbsp;&nbsp;鞣しに必要な道具はすべて自然界の材料から製作可能です。共通する要件は鋭利でないことであり、鋭利な道具は真皮を切断して損傷を与えます。

| 道具 | 形状 | 役割 |
| --- | --- | --- |
| フレッシング台 | 皮を剥いだ丸太を斜めに設置したもの | 革を覆いかぶせて体重で固定し、曲面が切削圧力を集中させます |
| 肉削ぎ具 | 鈍利な金属、大型動物の脛骨を割ったもの | 脂肪、皮下組織、表皮層を押し出すように削ぎ落とします |
| 鞣し枠 | 太い枝で組んだ四角枠 | 革の周縁部に孔を穿ち、紐で均一に張力をかけて固定します |
| ステーキング杭 | 先端を滑らかな球状・鈍角に加工した杭 | 革を引っ掛けて牽引し、繊維の固着を切断します |
| 浸漬槽 | 丸太をくり抜いたもの、大型の甕、敷物を敷いた土坑 | アルカリ液およびタンニン液を保持します |
| 燻煙袋 | 革を筒状に縫い合わせた構造 | 煙を密閉して革全域へ均一に接触させます |

&nbsp;&nbsp;&nbsp;作業場所は悪臭および排水の問題から、居住区から隔離された場所を選定する必要があります。脱毛工程の槽からは硫黄化合物やアンモニア臭が強力に発生し、フレッシングで排出された脂肪や組織はハエを大量誘引し、腐敗臭は captured 肉食獣を誘引します。アルカリ液および鞣し廃液はそのまま放流すると水生生物を致死させ、下流での取水者に被害を及ぼします。

| 項目 | 基準 |
| --- | --- |
| 居住区との距離 | 最低数十メートル以上、風下の方角 |
| 水源との距離 | 飲用水源から50m以上離隔し、流動水系へ直接破棄しないこと |
| 廃液処理 | 土坑に回収して土砂で覆い、アルカリ液は灰や土で中和処理 |
| 残渣処理 | 脂肪および肉片は埋設または焼却 |
| 皮膚保護 | アルカリ液は化学火傷を引き起こすため長棒で操作し、接触時は即座に洗浄 |

&nbsp;&nbsp;&nbsp;アルカリ液を取り扱う際の注意事項は石鹸製造と同等です。水酸化カルシウムや灰汁は皮膚の脂質を溶解させて化学火傷を引き起こし、眼球に入ると永久的な視覚障害をもたらします。痛みが遅延して発生するため、損傷が進行していても自覚できないケースが多発します。接触した場合は痛みの有無にかかわらず、即座に長時間の水洗を実施する必要があります。

### 4-4. 毛皮と皮革の工程上の差異
&nbsp;&nbsp;&nbsp;体毛を保持したまま仕上げる毛皮（ファー）は、前술した工程のうち複数の段階を採用できません。相違点はすべて「体毛を残留させる」という制約に起因します。

| 工程 | 皮革（脱毛革） | 毛皮（毛付き革） |
| --- | --- | --- |
| 脱毛 | アルカリにより毛を脱落させます | 行いません |
| アルカリの使用 | 必須工程です | 使用不可（毛が脱毛・損傷します） |
| 繊維の開繊 | アルカリ膨潤により解決 | 反復的な揉みほぐしと弱酸により代替 |
| フレッシング | 肉面および毛面双方で実施 | 肉面のみ実施。毛面は非接触 |
| 鞣し方式 | 全方式適用可能 | 脳、油脂、明礬主体。タンニンは毛を着色させます |
| 乾燥とステーキング | 全面で実施 | 肉面のみ揉みほぐし、毛の圧ぶされを防止 |
| 燻煙 | 両面実施 | 肉面のみ実施。毛に強力な煙臭が残留します |

&nbsp;&nbsp;&nbsp;毛皮においてアルカリが使用不可であるという制約が最大となります。繊維間を開繊させる工程が欠落するため薬剤浸透が悪化し、これを反復的な揉みほぐしと複数回の加脂作業により補完する必要があります。同一面積の革であっても、毛皮の方がはるかに多大な労力を要求される理由はここにあります。

&nbsp;&nbsp;&nbsp;体毛のコンディションは季節に強く依存します。晩秋から冬季にかけて捕獲した動物の毛が最も密生しており脱落しにくく、春季から夏季にかけては換毛期が進行して毛が疎らとなり、手で擦るだけで脱落します。毛皮として利用する革は季節を選定する必要があります。なお、平時における野生動物の捕獲や皮・毛の取得および加工行為は、野生生物の保護及び管理に関する法律の適用を受けるため、該当国の関連法令を確認し、その枠 l 内部でのみ実行しなければなりません。
