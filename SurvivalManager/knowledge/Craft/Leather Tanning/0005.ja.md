## 4. 揉みと燻煙、道具と作業環境
### 4-1. 揉み(ステーキング)
&nbsp;&nbsp;&nbsp;揉みは、皮が乾く間ずっと、引っ張り、加工し、揉み続ける作業です。鞣剤がすでに入っていても、乾燥の過程で繊維の間の水分が蒸発し、表面張力が隣り合う繊維を引き寄せます。放っておくと、鞣剤の膜がところどころで押しのけられ、繊維が直接くっつきます。揉みは、このくっつきを、できたそばから機械的に引き離します。

| 要素 | 内容 |
| --- | --- |
| 始める時期 | 表面の水分がなくなり、手に何も付かなくなってから |
| 終える時期 | 皮が完全に乾き、触ると温かく感じるまで。通常は数時間から1日 |
| 頻度 | 休まず続ける。15分放置するだけで、その部分は硬くなり始める |
| 最初に硬くなる場所 | 首や脚などの薄い部分と縁 |
| 省いた場合 | 鞣剤をどれだけうまく塗っても、板のような皮になる |

&nbsp;&nbsp;&nbsp;揉みを省くと、それまでのすべての工程が無意味になります。鞣しの成否を決めるのは鞣剤ではなく、乾く間の労力です。

- 完全に乾いた後にこわばった部分が残っても、取り戻せます。その部分を再び濡らし、鞣し液に浸けて、最初からもう一度揉みます。完全に硬くなったまま長く放置すると、くっつきが固定されて回復が難しくなります。
- てこを使うと楽になります。立てた杭の上に鈍い刃を上向きに固定し、皮をかけて両手で引くと、手作業よりはるかに大きな力が細い線に集中します。
- 木と木の間に縄を渡し、皮を鋸のように前後に擦りつける方法も同じ原理で、一人で大きな皮を扱うときに有効です。

### 4-2. 燻煙
&nbsp;&nbsp;&nbsp;揉んだ後でも、脳鞣しの皮は、濡れて乾くと再び硬くなります。これは、油膜がコラーゲンと結合せず表面に載っているだけなので、水が入ると並び方が変わったり流れ出たりして、繊維が再びくっつくためです。

&nbsp;&nbsp;&nbsp;木が不完全燃焼するときに出る煙には、ホルムアルデヒドやグリオキサールなどのアルデヒド類と、さまざまなフェノール化合物が含まれます。アルデヒドはコラーゲンの側鎖にあるアミノ基と共有結合し、隣り合う2本の鎖をつなぎます。こうして固定されたコラーゲンは、水が入っても構造を失わないため、濡れと乾燥を繰り返しても柔らかさを保ちます。フェノール化合物はカビや細菌を抑え、虫を寄せ付けません。

| 項目 | 内容 |
| --- | --- |
| 必要な条件 | 煙は出るが炎は出ない |
| よい燃料 | 腐ってもろくなった木、湿った広葉樹の木片、松ぼっくり、乾いたコケ |
| 避けるべき燃料 | 緑の針葉樹の枝。樹脂がすすとして付着する |
| 温度 | 手で耐えられる程度。熱いと皮が煮えて縮む |
| 時間 | 片面20分から1時間。その後、裏返して繰り返す |
| 完了のしるし | 色が黄褐色から濃い茶色へ均一に変わる |

- 最も効率的な方法は、皮を底だけを開けた袋状に縫い、その下にくすぶる熾火を置いて、煙を袋に満たすことです。煙が漏れると皮に届く煙が減り、時間が延びるだけです。
- 炎が上がると、皮は一瞬で焦げたり、熱で縮んだりします。熾火を灰で覆って炎を消し、煙だけを残します。
- タンニンで鞣した皮はすでに化学結合しているため、燻煙は必須ではありません。燻煙をしないと仕上がらないのは、脳鞣しや油鞣しの系統です。

### 4-3. 道具と作業環境
&nbsp;&nbsp;&nbsp;道具はすべて天然素材で作れます。共通点は、鋭くないことです。鋭い道具は皮を切ってしまいます。

| 道具 | 形 | 役割 |
| --- | --- | --- |
| 脱肉杭 | 樹皮を剥いで斜めに立てた丸太 | 皮をかけ、体で押さえる。丸い面が圧力を集中させる |
| 脱肉用スクレーパー | 刃の鈍い鉄片、または大型動物の脛骨を割ったもの | 脂肪、皮下組織、表皮層を押しのける |
| 張り枠 | 太い枝で編んだ四角い枠 | 皮の縁に穴をあけ、紐で張って結ぶ |
| 揉み棒 | 先端を丸く鈍くした杭 | 皮を引っかけて引き、繊維のくっつきを切る |
| 浸漬容器 | くり抜いた丸太、大きな甕、皮を敷いた穴 | アルカリ液と鞣し液を入れる |
| 燻煙袋 | 皮を縫って作った筒 | 煙をためて、皮に均一に触れさせる |

&nbsp;&nbsp;&nbsp;作業場は、住まいから離します。脱毛に使う桶は硫黄化合物とアンモニアの強い臭いを放ち、脱肉で出る脂肪や組織はハエを大量に呼び寄せ、腐敗臭は捕食動物を引き寄せます。アルカリ液や使い終えた鞣し液をそのまま流すと、水生生物が死に、下流で水を汲む人々にも害が及びます。

| 項目 | 基準 |
| --- | --- |
| 住まいからの距離 | 少なくとも数十m、風下 |
| 水からの距離 | 水源から50m以上。流水に直接捨てない |
| 廃液 | 穴に集めて土をかぶせる。アルカリ液は灰と土で中和する |
| 残渣 | 脂肪と肉片は埋めるか燃やす |
| 皮膚の保護 | アルカリ液は長い棒で扱い、触れたらすぐに洗い流す |

> **注意:** 水酸化カルシウムと灰汁は、皮膚の脂肪を溶かして化学熱傷を起こし、目に入ると永久的な損傷につながります。痛みが出るのが遅く、すでに傷を負っていることに気づかない人が多いため、触れたときは痛みの有無にかかわらず、すぐに長時間洗い流してください。

### 4-4. 毛皮と革の工程上の違い
&nbsp;&nbsp;&nbsp;毛を付けたまま仕上げる毛皮は毛を残さなければならないため、使えない工程があります。

| 工程 | 革(毛を除く) | 毛皮(毛を残す) |
| --- | --- | --- |
| 脱毛 | アルカリで毛を除去する | 行わない |
| アルカリの使用 | 必須 | 使えない。毛が抜けて傷む |
| 繊維を開く | アルカリによる膨潤で解決する | 繰り返しの加工と弱酸で代替する |
| 脱肉 | 肉面と毛面の両方 | 肉面のみ。毛面には手を付けない |
| 鞣しの方法 | すべての方法が可能 | 主に脳、油、ミョウバン。タンニンは毛を染める |
| 乾燥と揉み | 表面全体 | 肉面のみを加工し、毛が絡まないよう注意する |
| 燻煙 | 両面 | 肉面のみ。臭いが毛に強く染み込む |

- アルカリを使えないため、繊維を開く工程が欠け、薬剤の浸透が悪くなります。繰り返しの加工と、数回に分けた油入れで補います。同じ大きさなら、毛皮にはるかに多くの手間がかかります。
- 毛の状態は季節によって変わります。晩秋から冬に捕れた動物は毛が最も密で、抜けにくいです。春と夏は換毛で毛が薄くなり、手でこするだけで抜けます。毛皮では、季節を選ぶ必要があります。
- 平時には、野生動物の皮や毛皮を入手したり加工したりすることは、「野生生物の保護及び管理に関する法律」で規制されています。お住まいの国の関連法令を確認し、その範囲内でのみ行ってください。
