## 4. 스테이킹과 훈연, 도구와 작업 환경
&nbsp;&nbsp;&nbsp;무두 약제를 침투시키는 데 성공했다고 해서 부드러운 가죽이 나오는 것은 아닙니다. 마지막 두 단계인 스테이킹과 훈연이 남아 있고, 이 둘은 선택 사항이 아니라 앞의 모든 공정을 결과로 바꾸는 단계입니다.

---
### 4-1. 스테이킹
&nbsp;&nbsp;&nbsp;스테이킹은 가죽이 마르는 내내 잡아당기고 주무르고 비벼 주는 작업입니다. 무두 약제가 이미 섬유 사이에 들어가 있는데도 왜 이 고된 작업이 필요한지는, 건조 중에 작용하는 힘을 보면 알 수 있습니다.

&nbsp;&nbsp;&nbsp;섬유 사이에 남은 물이 증발할 때 물의 표면장력이 인접한 섬유를 서로 끌어당깁니다. 이 힘은 매우 작아 보이지만 접점의 수가 천문학적이라 합계는 상당합니다. 무두 약제가 섬유 표면을 덮고 있어도, 건조 중에 아무 방해 없이 두면 표면장력이 섬유를 밀착시키고 일부 지점에서는 약제 막이 밀려나 섬유끼리 직접 붙어 버립니다. 스테이킹은 이 붙음이 일어나는 족족 기계적으로 떼어 내는 일입니다.

| 요소 | 내용 |
| --- | --- |
| 언제 시작하는가 | 표면의 물기가 가시고 손에 묻어나지 않을 때부터 |
| 언제까지 하는가 | 가죽이 완전히 마르고 온기가 느껴질 때까지. 대개 몇 시간에서 하루 |
| 얼마나 자주 | 쉬지 않고. 15분만 방치해도 그 부분이 굳기 시작합니다 |
| 어디가 먼저 굳는가 | 목과 다리처럼 얇은 부분, 가장자리 |
| 건너뛰면 | 무두 약제를 아무리 잘 먹여도 나무판 같은 가죽이 됩니다 |

> **스테이킹을 건너뛰면 앞의 모든 공정이 무의미해집니다. 무두질의 성패를 최종적으로 결정하는 것은 약제가 아니라 마르는 동안의 노동입니다.**

&nbsp;&nbsp;&nbsp;가죽이 다 말랐는데도 뻣뻣한 부분이 남았다면 아직 되돌릴 수 있습니다. 그 부분을 다시 적셔 무두 용액에 담갔다가 처음부터 스테이킹을 다시 하면 됩니다. 반대로 방치해 완전히 굳어 버린 뒤 오래 두면 섬유의 유착이 굳어져 회복이 어려워집니다.

&nbsp;&nbsp;&nbsp;스테이킹을 쉽게 만드는 방법은 지레의 힘을 빌리는 것입니다. 세워 둔 기둥 끝에 무딘 날을 위로 향하게 고정하고 가죽을 걸쳐 양손으로 잡아당기면 손으로 주무르는 것보다 훨씬 강한 힘이 좁은 선에 집중됩니다. 밧줄을 나무 사이에 매어 놓고 가죽을 걸어 톱질하듯 문지르는 방법도 같은 원리이며, 혼자서 넓은 가죽을 다룰 때 특히 유효합니다.

---
### 4-2. 훈연
&nbsp;&nbsp;&nbsp;뇌 무두질한 가죽은 스테이킹까지 마쳐도 한 가지 약점이 남습니다. 물에 젖었다가 마르면 다시 뻣뻣해진다는 점입니다. 기름막은 콜라겐과 화학적으로 결합한 것이 아니라 표면에 얹혀 있을 뿐이라, 물이 들어오면 재배치되거나 씻겨 나가고 섬유가 다시 붙기 때문입니다.

&nbsp;&nbsp;&nbsp;훈연은 이 문제를 화학적으로 해결합니다. 나무가 불완전 연소할 때 나오는 연기에는 포름알데히드와 글리옥살 같은 알데히드류, 그리고 여러 페놀 화합물이 들어 있습니다. 알데히드는 콜라겐 곁사슬의 아미노기와 반응해 공유결합을 만들고, 인접한 두 사슬을 이어 다리를 놓습니다. 이렇게 고정된 콜라겐은 물이 들어와도 구조가 무너지지 않으므로, 젖었다 말라도 처음의 유연함을 유지합니다. 페놀 화합물은 여기에 더해 곰팡이와 세균을 억제하고 벌레를 쫓습니다.

| 항목 | 내용 |
| --- | --- |
| 필요한 것 | 연기만 나고 불꽃은 없는 상태 |
| 좋은 연료 | 썩어 부슬부슬해진 나무, 젖은 활엽수 조각, 솔방울, 마른 이끼 |
| 피할 연료 | 침엽수의 생가지. 수지가 그을음으로 달라붙습니다 |
| 온도 | 손을 대 견딜 수 있을 정도. 뜨거우면 가죽이 익어 오그라듭니다 |
| 시간 | 한쪽 면에 20분에서 한 시간, 뒤집어 반복 |
| 완료의 신호 | 색이 고르게 황갈색에서 짙은 갈색으로 변합니다 |

&nbsp;&nbsp;&nbsp;훈연은 가죽을 자루 모양으로 꿰매어 아래쪽만 열어 두고, 그 아래에 연기가 나는 불씨를 두어 연기가 자루 안을 채우게 하는 방식이 가장 효율적입니다. 연기가 새어 나가면 가죽에 닿는 양이 줄어 시간만 길어집니다. 불꽃이 올라오면 가죽이 순식간에 타거나 열로 오그라들므로, 불씨 위에 재를 덮어 불꽃을 죽이고 연기만 나게 유지해야 합니다.

&nbsp;&nbsp;&nbsp;탄닌으로 무두질한 가죽은 이미 화학적 결합이 이루어져 있어 훈연이 필수는 아닙니다. 훈연이 없으면 완성이 아닌 것은 뇌 무두질과 기름 무두질 계열입니다.

---
### 4-3. 도구와 작업 환경
&nbsp;&nbsp;&nbsp;무두질에 필요한 도구는 모두 자연에서 만들 수 있습니다. 공통점은 날카롭지 않다는 것이며, 날카로운 도구는 가죽을 베어 버립니다.

| 도구 | 형태 | 하는 일 |
| --- | --- | --- |
| 플레싱 기둥 | 껍질을 벗긴 통나무를 비스듬히 세운 것 | 가죽을 걸치고 몸으로 눌러 고정하며 둥근 면이 압력을 집중시킵니다 |
| 살긁개 | 무딘 날의 쇠, 큰 동물의 정강이뼈를 쪼갠 것 | 지방과 피하조직, 표피층을 밀어냅니다 |
| 무두질 틀 | 굵은 가지로 짠 사각 틀 | 가죽 가장자리에 구멍을 내어 끈으로 팽팽히 매답니다 |
| 스테이킹 봉 | 끝을 둥글고 무디게 다듬어 세운 말뚝 | 가죽을 걸고 당겨 섬유의 유착을 끊습니다 |
| 담금 통 | 통나무를 파낸 것, 큰 항아리, 구덩이에 가죽을 깐 것 | 알칼리액과 탄닌액을 담습니다 |
| 훈연 자루 | 가죽을 꿰매어 만든 통 | 연기를 가두어 가죽에 고르게 닿게 합니다 |

&nbsp;&nbsp;&nbsp;작업 장소는 냄새와 오수 때문에 거처에서 떨어뜨려야 합니다. 탈모 중인 통에서는 황화합물과 암모니아 냄새가 강하게 나고, 플레싱에서 나온 지방과 조직은 파리를 대량으로 불러들이며, 부패 냄새는 포식자를 유인합니다. 알칼리액과 무두 폐액은 그대로 흘려보내면 물속 생물을 죽이고, 아래쪽에서 물을 뜨는 사람에게 피해를 줍니다.

| 항목 | 기준 |
| --- | --- |
| 거처와의 거리 | 최소 수십 m, 바람이 불어 가는 쪽 |
| 물과의 거리 | 상수원과 50m 이상, 흐르는 물에 직접 버리지 않습니다 |
| 폐액 처리 | 구덩이에 모아 흙으로 덮고, 알칼리액은 재와 흙으로 중화합니다 |
| 잔해 처리 | 지방과 살 조각은 묻거나 태웁니다 |
| 피부 보호 | 알칼리액은 피부를 상하게 하므로 긴 막대로 다루고 닿으면 바로 씻습니다 |

&nbsp;&nbsp;&nbsp;알칼리액을 다룰 때의 주의는 비누 제조와 같습니다. 수산화칼슘과 잿물은 피부의 지방을 녹여 화상을 입히며, 눈에 들어가면 영구 손상으로 이어집니다. 통증이 늦게 나타나 이미 상했는데도 모르는 경우가 많으므로, 닿았다면 통증과 무관하게 즉시 오래 씻어야 합니다.

---
### 4-4. 모피와 가죽의 공정 차이
&nbsp;&nbsp;&nbsp;털을 붙인 채로 마무리하는 모피는 앞의 공정 중 몇 단계를 쓸 수 없습니다. 차이는 전부 털을 남긴다는 제약에서 나옵니다.

| 공정 | 가죽(털 제거) | 모피(털 유지) |
| --- | --- | --- |
| 탈모 | 알칼리로 털을 뺍니다 | 하지 않습니다 |
| 알칼리 사용 | 필수적입니다 | 쓸 수 없습니다. 털이 빠지고 상합니다 |
| 섬유 열기 | 알칼리 팽윤으로 해결 | 반복적인 주무름과 약산으로 대신합니다 |
| 플레싱 | 살 쪽과 털 쪽 모두 | 살 쪽만. 털 쪽은 손대지 않습니다 |
| 무두 방식 | 모든 방식 가능 | 뇌와 기름, 명반 위주. 탄닌은 털을 물들입니다 |
| 건조와 스테이킹 | 전면에 걸쳐 | 살 쪽만 주무르며 털이 눌리지 않게 합니다 |
| 훈연 | 양면 | 살 쪽만. 털에 냄새가 강하게 뱁니다 |

&nbsp;&nbsp;&nbsp;모피에서 알칼리를 쓸 수 없다는 제약이 가장 큽니다. 섬유 사이를 열어 주는 공정이 빠지므로 약제 침투가 나쁘고, 이를 반복적인 주무름과 여러 차례의 기름 먹이기로 보완해야 합니다. 같은 크기의 가죽이라도 모피 쪽이 손이 훨씬 많이 가는 이유입니다.

&nbsp;&nbsp;&nbsp;털의 상태는 계절에 좌우됩니다. 늦가을에서 겨울 사이에 잡은 동물의 털이 가장 빽빽하고 잘 빠지지 않으며, 봄에서 여름 사이에는 털갈이가 진행되어 털이 성글고 손으로 문지르기만 해도 빠집니다. 모피로 쓸 가죽은 계절을 골라야 합니다. 평상시 야생동물의 가죽과 털을 취득하거나 가공하는 행위 역시 야생생물 보호 및 관리에 관한 법률의 규율을 받으므로, 소속 국가의 관련 법령을 확인하고 그 안에서만 행해야 합니다.
