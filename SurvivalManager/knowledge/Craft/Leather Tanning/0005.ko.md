## 4. 스테이킹과 훈연, 도구와 작업 환경
### 4-1. 스테이킹
&nbsp;&nbsp;&nbsp;스테이킹은 가죽이 마르는 내내 잡아당기고 주무르고 비비는 작업입니다. 무두 약제가 이미 들어가 있어도 건조 중에는 섬유 사이의 물이 증발하면서 표면장력이 인접한 섬유를 끌어당깁니다. 가만히 두면 일부 지점에서 약제 막이 밀려나 섬유끼리 직접 붙습니다. 스테이킹은 이 붙음을 생기는 족족 기계적으로 떼어 냅니다.

| 요소 | 내용 |
| --- | --- |
| 시작 시점 | 표면의 물기가 가시고 손에 묻어나지 않을 때부터 |
| 종료 시점 | 가죽이 완전히 마르고 온기가 느껴질 때까지. 대개 몇 시간에서 하루 |
| 빈도 | 쉬지 않고 합니다. 15분만 방치해도 그 부분이 굳기 시작 |
| 먼저 굳는 곳 | 목과 다리처럼 얇은 부분, 가장자리 |
| 건너뛰면 | 약제를 아무리 잘 먹여도 나무판 같은 가죽이 됨 |

&nbsp;&nbsp;&nbsp;스테이킹을 건너뛰면 앞의 공정이 모두 무의미해집니다. 무두질의 성패는 약제보다 마르는 동안의 노동이 결정합니다.

- 다 마른 뒤에도 뻣뻣한 부분이 남았으면 되돌릴 수 있습니다. 그 부분을 다시 적셔 무두 용액에 담갔다가 스테이킹을 처음부터 다시 합니다. 완전히 굳은 채 오래 두면 유착이 굳어져 회복이 어렵습니다.
- 지레를 이용하면 쉽습니다. 세워 둔 기둥 끝에 무딘 날을 위로 향하게 고정하고 가죽을 걸쳐 양손으로 당기면, 손으로 주무르는 것보다 훨씬 큰 힘이 좁은 선에 집중됩니다.
- 밧줄을 나무 사이에 매고 가죽을 걸어 톱질하듯 문지르는 방법도 같은 원리이며, 혼자서 넓은 가죽을 다룰 때 유효합니다.

### 4-2. 훈연
&nbsp;&nbsp;&nbsp;뇌 무두질한 가죽은 스테이킹을 마쳐도 물에 젖었다 마르면 다시 뻣뻣해집니다. 기름막이 콜라겐과 결합하지 않고 표면에 얹혀 있어, 물이 들어오면 재배치되거나 씻겨 나가고 섬유가 다시 붙기 때문입니다.

&nbsp;&nbsp;&nbsp;나무가 불완전 연소할 때 나오는 연기에는 포름알데히드·글리옥살 같은 알데히드류와 여러 페놀 화합물이 들어 있습니다. 알데히드는 콜라겐 곁사슬의 아미노기와 공유결합해 인접한 두 사슬을 잇습니다. 이렇게 고정된 콜라겐은 물이 들어와도 구조가 무너지지 않아 젖었다 말라도 유연함을 유지합니다. 페놀 화합물은 곰팡이와 세균을 억제하고 벌레를 쫓습니다.

| 항목 | 내용 |
| --- | --- |
| 필요한 것 | 연기만 나고 불꽃은 없는 상태 |
| 좋은 연료 | 썩어 부슬부슬해진 나무, 젖은 활엽수 조각, 솔방울, 마른 이끼 |
| 피할 연료 | 침엽수의 생가지. 수지가 그을음으로 달라붙음 |
| 온도 | 손을 대 견딜 수 있을 정도. 뜨거우면 가죽이 익어 오그라듦 |
| 시간 | 한쪽 면에 20분에서 한 시간, 뒤집어 반복 |
| 완료 신호 | 색이 고르게 황갈색에서 짙은 갈색으로 변함 |

- 가죽을 자루 모양으로 꿰매 아래쪽만 열어 두고, 그 아래에 연기가 나는 불씨를 두어 연기가 자루 안을 채우게 하는 방식이 가장 효율적입니다. 연기가 새면 가죽에 닿는 양이 줄어 시간만 길어집니다.
- 불꽃이 오르면 가죽이 순식간에 타거나 열로 오그라듭니다. 불씨 위에 재를 덮어 불꽃을 죽이고 연기만 나게 유지합니다.
- 탄닌으로 무두질한 가죽은 이미 화학적으로 결합되어 있어 훈연이 필수가 아닙니다. 훈연 없이는 완성이 아닌 것은 뇌 무두질과 기름 무두질 계열입니다.

### 4-3. 도구와 작업 환경
&nbsp;&nbsp;&nbsp;도구는 모두 자연 재료로 만들 수 있습니다. 공통점은 날카롭지 않다는 것입니다. 날카로운 도구는 가죽을 벱니다.

| 도구 | 형태 | 하는 일 |
| --- | --- | --- |
| 플레싱 기둥 | 껍질을 벗긴 통나무를 비스듬히 세운 것 | 가죽을 걸치고 몸으로 눌러 고정. 둥근 면이 압력을 집중 |
| 살긁개 | 무딘 날의 쇠, 큰 동물의 정강이뼈를 쪼갠 것 | 지방, 피하조직, 표피층을 밀어냄 |
| 무두질 틀 | 굵은 가지로 짠 사각 틀 | 가죽 가장자리에 구멍을 내 끈으로 팽팽히 매닮 |
| 스테이킹 봉 | 끝을 둥글고 무디게 다듬어 세운 말뚝 | 가죽을 걸고 당겨 섬유의 유착을 끊음 |
| 담금 통 | 통나무를 파낸 것, 큰 항아리, 구덩이에 가죽을 깐 것 | 알칼리액과 탄닌액을 담음 |
| 훈연 자루 | 가죽을 꿰매어 만든 통 | 연기를 가두어 가죽에 고르게 닿게 함 |

&nbsp;&nbsp;&nbsp;작업 장소는 거처에서 떨어뜨립니다. 탈모 중인 통에서는 황화합물과 암모니아 냄새가 강하게 나고, 플레싱에서 나온 지방과 조직은 파리를 대량으로 불러들이며, 부패 냄새는 포식자를 유인합니다. 알칼리액과 무두 폐액을 그대로 흘려보내면 물속 생물이 죽고 아래쪽에서 물을 뜨는 사람이 피해를 봅니다.

| 항목 | 기준 |
| --- | --- |
| 거처와의 거리 | 최소 수십 m, 바람이 불어 가는 쪽 |
| 물과의 거리 | 상수원과 50m 이상. 흐르는 물에 직접 버리지 않음 |
| 폐액 처리 | 구덩이에 모아 흙으로 덮음. 알칼리액은 재와 흙으로 중화 |
| 잔해 처리 | 지방과 살 조각은 묻거나 태움 |
| 피부 보호 | 알칼리액은 긴 막대로 다루고 닿으면 바로 씻음 |

> **주의:** 수산화칼슘과 잿물은 피부의 지방을 녹여 화상을 입히고, 눈에 들어가면 영구 손상으로 이어집니다. 통증이 늦게 나타나 이미 상했는데도 모르는 경우가 많으므로, 닿았다면 통증과 무관하게 즉시 오래 씻습니다.

### 4-4. 모피와 가죽의 공정 차이
&nbsp;&nbsp;&nbsp;털을 붙인 채 마무리하는 모피는 털을 남겨야 하므로 일부 공정을 쓸 수 없습니다.

| 공정 | 가죽(털 제거) | 모피(털 유지) |
| --- | --- | --- |
| 탈모 | 알칼리로 털을 뺌 | 하지 않음 |
| 알칼리 사용 | 필수 | 쓸 수 없음. 털이 빠지고 상함 |
| 섬유 열기 | 알칼리 팽윤으로 해결 | 반복적인 주무름과 약산으로 대신함 |
| 플레싱 | 살 쪽과 털 쪽 모두 | 살 쪽만. 털 쪽은 손대지 않음 |
| 무두 방식 | 모든 방식 가능 | 뇌·기름·명반 위주. 탄닌은 털을 물들임 |
| 건조와 스테이킹 | 전면에 걸쳐 | 살 쪽만 주무르며 털이 눌리지 않게 함 |
| 훈연 | 양면 | 살 쪽만. 털에 냄새가 강하게 뱀 |

- 알칼리를 쓸 수 없어 섬유를 열어 주는 공정이 빠지므로 약제 침투가 나쁩니다. 반복적인 주무름과 여러 차례 기름 먹이기로 보완합니다. 같은 크기라도 모피 쪽이 손이 훨씬 많이 갑니다.
- 털 상태는 계절에 좌우됩니다. 늦가을에서 겨울 사이에 잡은 동물의 털이 가장 빽빽하고 잘 빠지지 않습니다. 봄에서 여름에는 털갈이로 털이 성글어 손으로 문지르기만 해도 빠집니다. 모피용 가죽은 계절을 골라야 합니다.
- 평상시 야생동물의 가죽과 털을 취득하거나 가공하는 행위는 야생생물 보호 및 관리에 관한 법률의 규율을 받습니다. 해당 국가의 관련 법령을 확인하고 그 안에서만 행합니다.
