## 4. 其他粘合剂与选择标准
### 4-1. 酪蛋白胶（酪素胶）
&nbsp;&nbsp;&nbsp;牛奶中包含着一种名为酪蛋白的蛋白质。这种蛋白质在酸性环境中会失去电平衡并发生凝集，沉淀为块状物；牛奶变质凝块正是这一现象。加入食醋或酸味果汁也会引发同样的反应。

&nbsp;&nbsp;&nbsp;将凝集的块状物用布过滤，用水冲洗数次以去除酸味并彻底拧干，即可得到酪蛋白凝块。在其中混合消石灰（熟石灰），钙离子就会在蛋白质链之间建立交联，形成几乎不溶于水的网状结构。这正是其与动物胶的决定性区别：酪蛋白胶凝固后不会再次溶解，因而具备相当出色的耐水性。

| 配料 | 比例 | 备注 |
|:---|---:|:---|
| 酪蛋白凝块 | 5 | 挤压沥干水分的状态 |
| 消石灰 | 1 | 由生石灰加水反应制得 |
| 水 | 适量 | 调制至粘稠粥状即可 |

&nbsp;&nbsp;&nbsp;混合后的酪蛋白胶会在数小时内开始凝固，因此必须随用随配。凝块本身晾干成粉末后可长期保存。其局限在于并非完全防水、长期处于潮湿状态会发霉，以及其碱性成分会在橡木（栎木）等木材上留下黑色斑痕。

---
### 4-2. 淀粉糊
&nbsp;&nbsp;&nbsp;将从大米、小麦、土豆、橡子中获取的淀粉溶于水并加热，淀粉颗粒就会吸水膨胀破裂，分子链随之解开溶出。这些相互缠绕变粘稠的分子链即为淀粉糊，在干燥过程中会渗透进纸张或布料的纤维之间并凝固。

&nbsp;&nbsp;&nbsp;其优势在于不会损伤基材。涂抹于纸张和布料上既不会使其发硬变脆，也不会导致变色，且用水很容易重新剥离清洗。反之，它完全无法用于承受重载的木材或骨骼接合，遇水会立即溶解，且会成为霉菌和害虫的食物。加入少许明矾或食盐可适度延缓发霉。

---
### 4-3. 树脂、橡胶、漆、沥青
| 材料 | 获取途径 | 性质与注意事项 |
|:---|:---|:---|
| 天然橡胶 | 橡胶树、乳草或蒲公英的白色乳胶 | 弹性大且耐水，但粘接强度较低 |
| 漆（生漆） | 漆树树液 | 在湿热环境中凝固，具备极强的完全防水性。未凝固的树液会引发严重皮肤炎 |
| 沥青 | 天然沥青、石油渗出露头 | 防水性能卓著，但受热流淌、受冷脆裂 |
| 蜂蜡 | 蜂巢 | 粘接力微弱，用作防水剂和塑化剂 |
| 树脂 | 冷杉、云杉、樱桃树 | 使用方式与松脂相同；凝固速度有所差异 |

&nbsp;&nbsp;&nbsp;漆在天然材料中性能最为卓越，但操作最为危险。若接触未凝固的树液，数日后会爆发严重的皮疹和水疱，根据体质不同甚至会影响呼吸道。采集与涂刷时严禁裸露皮肤，且需在通风良好处操作，避免暴露于凝固过程中产生的蒸气中。

### 4-4. 性能比较与按用途选择
| 粘合剂 | 耐水性 | 耐热性 | 强度 | 可逆性 | 保存性 |
|:---|:---|:---|:---|:---|:---|
| 松脂胶 | 中 | 低 | 中 | 高 | 极佳 |
| 桦木焦油 | 高 | 低 | 中 | 高 | 极佳 |
| 动物胶 | 低 | 低 | 高 | 高 | 晒干后良好 |
| 鱼胶 | 低 | 低 | 极高 | 高 | 晒干后良好 |
| 酪蛋白胶 | 高 | 中 | 高 | 无 | 粉末状态良好 |
| 淀粉糊 | 极低 | 中 | 低 | 高 | 差 |
| 漆 | 极高 | 高 | 高 | 无 | 密封状态良好 |
| 沥青 | 极高 | 极低 | 低 | 高 | 极佳 |

| 用途 | 推荐粘合剂 | 选择理由 |
|:---|:---|:---|
| 箭头与箭羽固定 | 松脂胶 + 缠绕筋腱 | 野外只要有火源即可现场修复 |
| 室内木工家具接合 | 动物胶 | 强固，且日后可拆卸修复 |
| 弓等层压叠层结构 | 鱼胶 | 在保持涂层纤薄的同时承受剪切力 |
| 船只、木桶、屋顶防水 | 沥青、桦木焦油 | 排斥水分，且基材发生微位移也不会开裂 |
| 纸张与布料 | 淀粉糊 | 不会使材料发硬或变色 |
| 陶瓷与器皿修复 | 漆、松脂胶 | 填补缝隙的同时固化 |
| 接触水的接合部位 | 酪蛋白胶、漆 | 凝固后不会再次溶解 |

### 4-5. 当绑缚比粘接更强固时
&nbsp;&nbsp;&nbsp;从自然界获取的粘合剂，没有一种能达到现代合成粘合剂那样的绝对强度。因此传统工艺绝不会将所有外力完全托付给粘合剂。

> **外力由缠绕绑缚的纤维承受，粘合剂则固定纤维使其不致松脱，并阻止水分渗入。天然材料接合的标准并非在粘接与绑缚之间二选一，而是将二者叠加使用。**

&nbsp;&nbsp;&nbsp;这种方式之所以强固，原因有三：第一，筋腱或植物纤维具备极高的抗拉强度，能代为承受作用于接合部位的拉伸载荷。第二，湿润的筋腱在干燥过程中会发生显著收缩，使得缠绕部位自动紧固。在凝固过程中持续施加压力的夹紧装置实际上已内置于接合部本身。第三，缠绕的纤维覆盖了接合部位的边缘，从而消除了最脆弱的载荷模式——剥离的起始点。

&nbsp;&nbsp;&nbsp;操作顺序通常为：先薄薄涂抹一层粘合剂，在其上紧密缠绕筋腱或纤维，最后再次涂抹粘合剂覆盖纤维。缠绕时不应仅顺着单一方向，而应交叉缠绕以抵御扭转外力。榫卯、楔子、木钉等机械结构接合也是基于同样逻辑配合使用。其宗旨在于构建出即使粘合剂失效、物件也不会瞬间坍塌的结构。
