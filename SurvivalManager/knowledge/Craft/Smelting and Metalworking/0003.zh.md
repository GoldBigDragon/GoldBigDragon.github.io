## 2. 燃料与还原的化学
### 2-1. 冶炼为什么需要木炭
- 清洁：木炭中的硫通常不到0.1%。煤因产地不同，含硫0.5-3%甚至更多。
- 强度：在炉内，燃料必须承受矿石的重量并保持气体通道畅通。碎裂的燃料会堵塞通道，使鼓风失效。栎木、桦木这类硬木烧成的木炭比松木炭更适合冶炼。

&nbsp;&nbsp;&nbsp;进入铁中的硫会变成硫化铁，像一层薄膜一样夹在晶界上。硫化铁的熔点比铁低得多，在锻造温度下会变软或熔化。锤打烧红的铁时，晶界会裂开，铁像纸片一样被撕裂（热脆）。冷却后看起来完好无损，所以很难找到原因。

| 杂质 | 进入途径 | 表现的症状 |
|:---|:---|:---|
| 硫 | 煤、混有黄铁矿的矿石 | 热脆。热态锤打时开裂 |
| 磷 | 沼铁矿、部分褐铁矿 | 冷脆。冷态下受冲击断裂 |
| 硅 | 矿石中的脉石、炉壁的泥土 | 形成炉渣。适量是必要的，过多会降低产率 |
| 灰分 | 燃料中的无机物 | 堆积在炉底，堵塞通风 |

---
### 2-2. 焦炭
&nbsp;&nbsp;&nbsp;焦炭是把煤在无空气的密闭空间里加热到1,000℃左右，赶走挥发分和焦油后得到的碳块。原理与干馏木材制成木炭相同。一部分硫以气体形式逸出，煤熔化后再凝固，成为坚硬而多孔的块。

&nbsp;&nbsp;&nbsp;木炭堆得高了，底部会被自身重量压碎，因此炉子的大小受到限制。焦炭受压也能撑住，所以炉子可以建到数十米高，这成为大规模炼铁的起点。灾难情况下，很难稳定地获得煤。除非在露天煤层或废弃矿井附近，否则木炭实际上是唯一的选择，而木炭已经足够。

---
### 2-3. 一氧化碳还原
&nbsp;&nbsp;&nbsp;在炉内夺走氧化铁中的氧的，不是固体碳，而是气体一氧化碳（CO）。气体能钻进矿石颗粒的细微孔隙里。

1. 在风口正前方，碳与氧相遇变成二氧化碳，放出大量的热。
2. 这股热的二氧化碳穿过上方烧得通红的木炭层，与碳相遇，变成两分子一氧化碳。这是吸热反应，大体上在700℃以上活跃。
3. 一氧化碳与矿石相遇，夺走其中的氧。

| 阶段 | 反应 | 热的方向 |
|:---|:---|:---|
| 燃烧 | C + O₂ → CO₂ | 强放热 |
| 再生 | CO₂ + C → 2CO | 吸热，700℃以上进行 |
| 还原1 | 3Fe₂O₃ + CO → 2Fe₃O₄ + CO₂ | 弱放热 |
| 还原2 | Fe₃O₄ + CO → 3FeO + CO₂ | 弱吸热 |
| 还原3 | FeO + CO → Fe + CO₂ | 弱放热 |

- 风口上方的木炭层要堆得足够厚。二氧化碳需要时间变回一氧化碳。如果把矿石放得太低，它不会被还原，反而会被二氧化碳重新氧化。
- 把矿石破碎成豆粒到橡子大小。块太大，气体进不到里面，只有表面被还原，内部原封不动。

### 2-4. 块炼铁冶炼
&nbsp;&nbsp;&nbsp;纯铁的熔点是1,538℃，用木炭和风箱建造的块炼炉，内部最多只有1,200-1,400℃。被还原的铁无法变成液体，以小颗粒的形态留下，相互粘结聚成一团，成为像海绵一样布满孔洞的块。这就是块炼铁。

- 炉渣：矿石中的硅石与未被还原的氧化铁结合，变成硅酸铁。其熔点约为1,170℃，比铁低得多，所以在炉内只有炉渣熔化流下。流下时，它覆盖在铁颗粒表面，防止再氧化，并为颗粒相互粘合提供场所。
- 温度区间：达不到炉渣熔点，铁颗粒就会散着收场。温度太高、铁吸收大量碳，就会熔化流下，成为又软又脆的生铁。块炼冶炼是把这个狭窄的温度区间保持几个小时的技术。
- 精炼：从炉中取出的块炼铁，近一半是炉渣。趁烧红反复锤打，把炉渣挤出来。最终只有最初投入矿石重量的15-30%留作可用的铁。锻造首先是精炼，然后才是成形。
