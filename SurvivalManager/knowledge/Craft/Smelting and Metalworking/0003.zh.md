## 2. 燃料与还原化学
### 2-1. 冶炼为何需要木炭
&nbsp;&nbsp;&nbsp;木炭之所以成为冶炼的首选燃料，首要原因在于其洁净度。树木在生长过程中几乎不积聚硫元素，因此木炭中的残余硫含量通常低于0.1%。相比之下，根据产地的不同，煤炭中含有0.5%至3%、甚至更高的硫。

&nbsp;&nbsp;&nbsp;硫之所以会引发严重问题，是因为渗入铁中的硫会与铁结合生成硫化铁，而硫化铁会像一层薄膜般夹杂在晶粒之间的界面上。硫化铁的熔点远低于铁，在锻造温度下就已经软化或熔化。结果就是，当击打烧红的铁块时，晶界会瞬间裂开，导致铁块像纸张一样撕裂。这就是红热脆性，由于它仅在高温下表现出脆性、冷却后外观看似正常，因而更加难以查明原因。

| 杂质 | 引入途径 | 表现症状 |
|:---|:---|:---|
| 硫 | 煤炭、混有黄铁矿的矿石 | 热脆性（红热脆性）。在烧红状态下锻打会裂开 |
| 磷 | 沼铁矿、部分褐铁矿 | 冷脆性。在冷却状态下受到冲击会折断 |
| 硅 | 矿石的脉石、炉壁的粘土 | 形成炉渣。适量是必需的，过量会导致出铁率下降 |
| 灰分 | 燃料本身的无机物 | 堆积在炉底并阻碍通气 |

&nbsp;&nbsp;&nbsp;木炭的第二个优势在于其物理强度。在炉内，燃料需要承受矿石的重量，同时维持气体流通的通道。破碎的燃料会堵塞通道并导致送风失效。这就是为什么像柞树或檀木这类材质坚硬的木炭比松木炭更适合冶炼的原因。

### 2-2. 焦炭
&nbsp;&nbsp;&nbsp;焦炭是将煤炭置于隔绝空气的密闭空间内，加热至1000℃左右以驱赶挥发分和煤焦油后留下的碳块。其原理与通过木材干馏制取木炭完全一致，只是原料由木材换成了煤炭。

&nbsp;&nbsp;&nbsp;在此过程中，部分硫元素会作为气体逸出，更重要的是煤炭熔化后再凝固时会相互粘结，形成坚硬且多孔的块状物。木炭质地较软，堆高后底部会被自身重量压碎，因此使用木炭的炼铁炉无法扩张到一定尺寸以上。焦炭能够承受高压而不被压碎，使得炼铁炉的高度可以提升至几十米，这成为了大规模炼铁的起点。

&nbsp;&nbsp;&nbsp;然而在灾难生存状况下，稳定获取煤炭十分困难。除非身处露天煤层或废弃矿井周边，否则木炭实际上是唯一的选择，且完全够用。

### 2-3. 一氧化碳
&nbsp;&nbsp;&nbsp;人们常解释为碳夺取了氧化铁中的氧，但在炉内真正起作用的并非固体碳，而是气态的一氧化碳。这是因为固体与固体的接触面积微乎其微，而气体却能深入渗透到矿石颗粒的微孔内部。

&nbsp;&nbsp;&nbsp;反应分为三个阶段进行。首先，在风口正前方，碳与氧气接触生成二氧化碳并释放出巨大热量。这种高温二氧化碳穿过上方烧红的木炭层时，再次与碳接触并转化为两分子的一氧化碳。该反应吸收热量，通常在700℃以上剧烈进行。随后，一氧化碳与矿石接触并剥离氧元素。

| 阶段 | 反应 | 热量方向 |
|:---|:---|:---|
| 燃烧 | C + O₂ → CO₂ | 强放热 |
| 再生 | CO₂ + C → 2CO | 吸热，在700°C以上进行 |
| 还原 1 | 3Fe₂O₃ + CO → 2Fe₃O₄ + CO₂ | 弱放热 |
| 还原 2 | Fe₃O₄ + CO → 3FeO + CO₂ | 弱吸热 |
| 还原 3 | FeO + CO → Fe + CO₂ | 弱放热 |

&nbsp;&nbsp;&nbsp;从这一顺序可以得出两个实践性结论。第一，风口上方必须堆叠足够厚的木炭层，以争取将二氧化碳重新转化为一氧化碳的时间。如果矿石放置位置过低，矿石不仅无法被还原，反而会被二氧化碳重新氧化。第二，必须将矿石打碎至豌豆到橡子大小的细小颗粒。由于气体必须渗透进颗粒内部，若块头过大，则会导致外表被还原而内部依旧残留。

### 2-4. 炼铁炉（Bloomery）中的铁不会熔化
&nbsp;&nbsp;&nbsp;纯铁的熔点为1538℃，而靠木炭和风箱维持的炼铁炉（Bloomery）内部温度充其量在1200-1400℃之间。因此，还原出的铁无法成为液体，而是以微小颗粒的形式留在原地。这些颗粒相互粘结凝聚，形成像海绵一样布满孔洞的块状物，这被称为海绵铁（海绵块）。

&nbsp;&nbsp;&nbsp;在此过程中，炉渣发挥着核心作用。混在矿石中的硅石与未被还原的氧化铁结合生成硅酸铁，该物质的熔点约为1170℃，远低于铁。因此在炉内只有炉渣会熔化并流下，流下的炉渣覆盖在铁颗粒表面以防止其再次氧化，并为颗粒间的接合提供场所。

> **如果炉温未能达到炉渣的熔点，铁颗粒就会保持分散状态而失败；若温度过高导致铁吸收过多的碳，则会熔化成脆弱易碎的生铁。炼铁炉冶炼的技术精髓，就在于将这一狭窄的温度区间维持数小时之久。**

&nbsp;&nbsp;&nbsp;从炉中取出海绵铁时，其中仍有将近一半是炉渣。因此必须在烧红状态下反复锻打，像挤水一样将炉渣挤出。每锻打一次，炉渣就会像火花般飞溅而出，铁块也会随之变得日益紧密。在此过程中，最初投入的矿石重量中仅有15-30%左右能作为可用之铁保留下来。这就是锻造在成为成型工序之前首先是精炼工序的原因。
