## 3. 温度与鼓风决定炉子的极限
### 3-1. 各种金属的熔化温度
&nbsp;&nbsp;&nbsp;能加工的金属取决于炉子能达到的温度。熔点以纯金属为准，大多数合金在低于纯金属的温度下熔化。

| 金属 | 熔点 | 沸点 | 备注 |
|:---|---:|---:|:---|
| 锡 | 232℃ | 2,602℃ | 在篝火的灰烬中也能熔化 |
| 铅 | 327℃ | 1,749℃ | 约500℃起产生蒸气 |
| 锌 | 420℃ | 907℃ | 沸点低于铜的熔点 |
| 铝 | 660℃ | 2,470℃ | 木炭火能熔化，但由于氧化膜，外面变软后塌陷 |
| 银 | 962℃ | 2,162℃ | 鼓风的木炭火可以 |
| 金 | 1,064℃ | 2,856℃ | 鼓风的木炭火可以 |
| 铜 | 1,085℃ | 2,562℃ | 需要强制鼓风 |
| 铸铁 | 1,150-1,300℃ | - | 含碳2.1%以上。比纯铁低得多 |
| 纯铁 | 1,538℃ | 2,862℃ | 原始的炉子难以达到 |

- 铸铁的熔化温度比纯铁低近400℃。掺入碳会使熔点下降，所以铁在炉内吸收大量碳后会变成液体流下。这是高炉出铁水的原理，而在块炼炉中则被视为失败。
- 锌的沸点（907℃）低于铜的熔点（1,085℃）。这是熔炼黄铜时产生危险的起点。

### 3-2. 火的温度
| 热源 | 大致温度 |
|:---|---:|
| 柴火篝火 | 600-900℃ |
| 自然通风的木炭火 | 800-1,000℃ |
| 用风箱鼓风的木炭火 | 1,100-1,300℃ |
| 块炼炉风口前 | 1,200-1,400℃ |
| 强制鼓风坩埚炉 | 1,200-1,400℃ |
| 现代高炉 | 1,500-2,000℃ |

&nbsp;&nbsp;&nbsp;通过颜色读取温度，没有温度计也能判断。在暗处观察才准确。

| 颜色 | 大致温度 |
|:---|---:|
| 暗红色 | 550-700℃ |
| 鲜红色 | 800-900℃ |
| 橙色 | 950-1,050℃ |
| 黄色 | 1,100-1,250℃ |
| 近白的黄色 | 1,300℃以上 |

### 3-3. 鼓风
&nbsp;&nbsp;&nbsp;把木炭堆成两倍，温度也不会升高。温度取决于产热速度与散热速度之差，而热量是碳与氧相遇时才产生的，所以产热速度受氧气供应速度的制约。

&nbsp;&nbsp;&nbsp;炉子的设计原则有三条。

1. 强制送入空气。
2. 减少热量逃逸的地方（厚土墙、狭窄的炉口）。
3. 把燃烧发生的位置集中在一处。大范围散开的火，烧得再猛也无法把一个点烧热。

&nbsp;&nbsp;&nbsp;不能一味增加空气。空气中78%是不参与反应的氮气，它只带着热量从烟囱逸出。过量的空气会使炉子变冷，并使炉内变成氧化性气氛，把好不容易还原的铁重新氧化。好的鼓风不是强劲的鼓风，而是不间断的稳定鼓风。

---
### 3-4. 自然通风炉
&nbsp;&nbsp;&nbsp;非洲多个地区留有不用风箱进行冶炼的实例。原理是烟囱效应。炉内的热气体比外面的空气轻，向上浮起，从下方孔洞进入的冷空气填补它的位置。通风强度与内外温差和炉子高度成正比，所以炉子建得越高，通风越强。

- 把炉子建得高一些，2-3m，并在下方开几个小孔。比一个大孔的空气流速更高，因此能把空气送到炉子中心。
- 建在风稳定吹拂的山脊或山谷入口处。
- 局限：得到同样数量的铁，需要多得多的时间和木炭。作为回报，不必连续几个小时拉风箱，在人手不足时有利。

---
### 3-5. 风箱
&nbsp;&nbsp;&nbsp;鼓风一中断，风口前的温度就会下降，炉内会短暂出现氧化性气氛。这种短暂的中断累积起来，产率会明显下降，所以风箱必须不间断。

| 类型 | 工作方式 | 特点 |
|:---|:---|:---|
| 单皮囊风箱 | 压皮囊送风 | 容易制作，但风会中断 |
| 双风箱 | 两个皮囊交替挤压，轮流送风 | 几乎没有中断。非洲和古埃及的标准 |
| 箱式风箱 | 活塞和阀门使推和拉时都送风 | 一个人就能连续送风。在东亚广泛使用 |
| 脚踏风箱 | 用脚踩压大皮囊 | 双手自由，能持久 |

&nbsp;&nbsp;&nbsp;风口应穿过炉壁并稍微伸进去一点，但如果伸到火焰中央就会烧毁。使用用黏土捏成的管子，或者用黏土包住金属管的末端。角度朝下，让风吹过炉底附近最热的区域。
