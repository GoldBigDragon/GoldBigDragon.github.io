## 3. 温度与送风决定炉温极限
### 3-1. 各类金属的熔化温度
&nbsp;&nbsp;&nbsp;能够加工何种金属，取决于手中炼炉所能达到的温度。以下熔点均以纯金属为基准，而合金的熔点大多低于纯金属。

| 金属 | 熔点 | 沸点 | 备注 |
|:---|---:|---:|:---|
| 锡 | 232°C | 2,602°C | 即便在篝火灰烬中也能熔化 |
| 铅 | 327°C | 1,749°C | 约自500°C起散发有毒蒸气 |
| 锌 | 420°C | 907°C | 沸点低于铜的熔点 |
| 铝 | 660°C | 2,470°C | 可用木炭火熔化，但因氧化膜导致表皮软化而坍塌 |
| 银 | 962°C | 2,162°C | 送风木炭火即可达到 |
| 金 | 1,064°C | 2,856°C | 送风木炭火即可达到 |
| 铜 | 1,085°C | 2,562°C | 需要强制送风 |
| 铸铁 | 1,150-1,300°C | - | 碳含量2.1%以上，远低于纯铁 |
| 纯铁 | 1,538°C | 2,862°C | 原始炼炉极难达到 |

&nbsp;&nbsp;&nbsp;从表格中需要读出两点关键信息。其一是铸铁的熔点比纯铁低近400℃。由于融入碳会降低熔点，若铁在炉内吸收了过多碳，就会化为液体流出。这既是高炉排放铁水的原理，同时也是炼铁炉（Bloomery）中被视为失败的现象。其二是锌的沸点907℃低于铜的熔点1,085℃，这正是熔炼黄铜时必须铭记的危险起点。

### 3-2. 实际火焰产生的温度
&nbsp;&nbsp;&nbsp;燃料在理论上所能达到的最高温度与炼炉实际产生的温度完全是两回事。

| 热源 | 大致温度 |
|:---|---:|
| 柴火篝火 | 600-900°C |
| 自然通风木炭火 | 800-1,000°C |
| 风箱送风木炭火 | 1,100-1,300°C |
| 炼铁炉风口前方 | 1,200-1,400°C |
| 强制送风坩埚炉 | 1,200-1,400°C |
| 现代高炉 | 1,500-2,000°C |

&nbsp;&nbsp;&nbsp;学会通过颜色判断温度，可以在没有温度计的情况下做出准确判断。不过，必须在昏暗处观察才能保证准确。

| 颜色 | 大致温度 |
|:---|---:|
| 暗红色 | 550-700°C |
| 鲜红色 | 800-900°C |
| 橙色 | 950-1,050°C |
| 黄色 | 1,100-1,250°C |
| 接近白色的黄色 | 1,300°C以上 |

### 3-3. 提升温度的是空气而非燃料
&nbsp;&nbsp;&nbsp;堆叠双倍的木炭并不能提升温度。温度并不取决于积聚了多少热量，而取决于单位时间内热量产生的速度与散失速度之间的差值。只有当碳与氧气接触时才会产生热量，因此热量的产生速度完全受限于氧气的供应速度。

&nbsp;&nbsp;&nbsp;由此引申出设计炼炉的三项原则。第一是强制推入空气。第二是减少热量散失的通道，厚重的泥墙与狭窄的炉口即属于此类。第三是将发生燃烧的位置集中在一处。散开的火焰无论燃烧得多么剧烈，都无法有效加热单点。

&nbsp;&nbsp;&nbsp;然而，盲目过量送风并非解决之道。空气中78%是不参与反应的氮气，这些氮气穿过炉内时只会带走热量并从烟囱逸出。超出必要的空气不仅不能提升温度，反而会冷却炼炉，同时使炉内形成氧化性气氛，导致辛苦还原出的铁再次被氧化。良好的送风并非强劲的送风，而是不间断的稳定送风。

---
### 3-4. 自然通风炉基于烟囱效应工作
&nbsp;&nbsp;&nbsp;无需风箱即可进行冶炼的实例在非洲多个地区广泛留存。其原理是烟囱效应。炉内的高温气体比外界空气轻因而向上浮升，为了填补这一空隙，冷空气便从下方的孔洞被吸入。这种力量与内外温差及炼炉高度成正比，因此炼炉建造得越高，通风就越强。

&nbsp;&nbsp;&nbsp;因此，自然通风冶炼炉通常建造至2-3米高，并在底部开设多个小孔。不开单个大孔而开设多个小孔的原因，是为了提高开进空气的风速，使其能推入至炼炉中心部位。在风向稳定的山脊或谷口常能发现炼炉遗址，也是出于同样的原因。

&nbsp;&nbsp;&nbsp;自然通风的局限在于速度。为了获得等量的铁，需要耗费长得多的时间与多得多的木炭，但无需人力连续拉动风箱数小时。在人力匮乏的状况下，这是一种有利的选择。

---
### 3-5. 送风必须保持连贯
&nbsp;&nbsp;&nbsp;最简单的风箱形式是通过手挤压皮袋口开合来排出风力。虽然制作简单，但在重新鼓起皮袋的过程中风力会中断。风力中断的瞬间，风口前方的温度就会下降，炉内会短暂产生氧化性气氛。这种微小的反复累积起来，会导致出铁率明显下降。

| 形式 | 运作方式 | 特征 |
|:---|:---|:---|
| 单皮袋风箱 | 挤压皮袋产生风力 | 制作简单，但风力会中断 |
| 双皮袋风箱 | 交替挤压两个皮袋实现轮流送风 | 几乎无中断。非洲与古埃及的标准形式 |
| 箱式风箱 | 依靠活塞与阀门在推拉时均可送风 | 单人即可实现连续送风。在东亚被广泛使用 |
| 脚踏风箱 | 用脚踩踏挤压大型皮袋 | 解放双手，能够持久作业 |

&nbsp;&nbsp;&nbsp;风口应穿透炉壁稍稍深入内部，但如果深入到火心中央则会被烧毁。使用粘土烧制的管道或用粘土包裹金属管末端正是出于这一原因。风口角度通常朝下，使风力能够穿过炉底附近最炽热的区域。
