## 2. 燃料と還元の化学
### 2-1. 製錬に木炭が必要な理由
- 清浄さ: 木炭の硫黄は、多くの場合0.1%未満です。石炭は産地によって、硫黄が0.5-3%以上入っています。
- 強度: 炉の中で燃料は、鉱石の重さを支え、ガスの通り道を保たなければなりません。砕けた燃料は通り道をふさいで送風を殺します。ナラやカバのような硬い木の木炭のほうが、松の木炭より製錬に適しています。

&nbsp;&nbsp;&nbsp;鉄に入った硫黄は硫化鉄になり、結晶粒の境界面に薄い膜のように入り込みます。硫化鉄は融点が鉄よりはるかに低く、鍛造温度で軟らかくなったり溶けたりします。赤熱した鉄を叩くと、結晶粒界が割れて、鉄が紙のように裂けます(赤熱脆性)。冷めると問題なく見えるため、原因を見つけにくくなります。

| 不純物 | 入り込む経路 | 現れる症状 |
|:---|:---|:---|
| 硫黄 | 石炭、黄鉄鉱が混ざった鉱石 | 赤熱脆性。熱した状態で叩くと割れる |
| リン | 沼鉄鉱、一部の褐鉄鉱 | 低温脆性。冷えた状態で衝撃を受けると折れる |
| ケイ素 | 鉱石の脈石、炉壁の土 | スラグを作る。適量は必要で、多すぎると歩留まりが下がる |
| 灰分 | 燃料の無機物 | 炉底にたまって通気をふさぐ |

---
### 2-2. コークス
&nbsp;&nbsp;&nbsp;石炭を空気のない密閉した部屋で1,000℃前後まで加熱し、揮発分とタールを追い出した炭素の塊です。木を乾留して木炭を作るのと原理は同じです。硫黄の一部がガスとなって抜け、石炭が溶けて固まる間に、硬くて穴の多い塊になります。

&nbsp;&nbsp;&nbsp;木炭は高く積むと下のほうが自分の重みでつぶれて砕けるため、炉の大きさに限界がありました。コークスは押されても耐えるので、炉を数十mまで高くでき、大量製鉄の出発点になりました。災害時には、石炭を安定して確保するのは困難です。露天の炭層や廃坑の周辺でなければ、木炭が事実上唯一の選択肢であり、木炭で十分です。

### 2-3. 一酸化炭素による還元
&nbsp;&nbsp;&nbsp;炉の中で酸化鉄から酸素を取り除くのは、固体の炭素ではなく、気体の一酸化炭素(CO)です。気体は鉱石の粒の微細な穴の中まで入り込めます。

1. 羽口のすぐ手前で炭素が酸素と出会って二酸化炭素になり、大きな熱を出します。
2. この熱い二酸化炭素が、上の赤々と熱した木炭の層を通り抜けるときに炭素と出会い、一酸化炭素2分子に変わります。熱を吸収する反応で、おおむね700℃以上で活発になります。
3. 一酸化炭素が鉱石と出会って酸素を奪います。

| 段階 | 反応 | 熱の方向 |
|:---|:---|:---|
| 燃焼 | C + O₂ → CO₂ | 強い発熱 |
| 再生 | CO₂ + C → 2CO | 吸熱、700℃以上で進行 |
| 還元1 | 3Fe₂O₃ + CO → 2Fe₃O₄ + CO₂ | 弱い発熱 |
| 還元2 | Fe₃O₄ + CO → 3FeO + CO₂ | 弱い吸熱 |
| 還元3 | FeO + CO → Fe + CO₂ | 弱い発熱 |

- 羽口の上の木炭層を十分に厚く積みます。二酸化炭素が一酸化炭素に戻る時間が必要です。鉱石を低い位置に入れすぎると、還元される代わりに二酸化炭素によって再び酸化されます。
- 鉱石は豆粒からドングリ大に細かく砕きます。塊が大きいとガスが中まで入れず、表面だけが還元されて内部はそのまま残ります。

### 2-4. ブルーマリー製鉄
&nbsp;&nbsp;&nbsp;純鉄の融点は1,538℃で、木炭とふいごで作ったブルーマリー(Bloomery)炉の内部は、せいぜい1,200-1,400℃です。還元された鉄は液体になれず、小さな粒として残り、互いにくっついて固まり、スポンジのように穴のあいた塊になります。これが塊錬鉄です。

- スラグ: 鉱石中のケイ石が、還元されなかった酸化鉄と結合してケイ酸鉄になります。融点は約1,170℃と鉄よりはるかに低く、炉の中ではスラグだけが溶けて流れ落ちます。流れ落ちながら鉄の粒の表面を覆って再酸化を防ぎ、粒どうしがくっつく場所を作ります。
- 温度域: スラグの融点に届かなければ、鉄の粒がばらばらのまま終わります。高すぎて鉄が炭素を多く吸い込むと、溶け落ちて、もろくて割れやすい銑鉄になります。ブルーマリー製錬は、この狭い温度域を数時間保つ技術です。
- 精錬: 炉から取り出した塊錬鉄は、半分近くがスラグです。赤熱させたまま繰り返し叩いて、スラグを絞り出します。最初に入れた鉱石の重さの15-30%だけが、使える鉄として残ります。鍛造は成形の前に、まず精錬作業です。
