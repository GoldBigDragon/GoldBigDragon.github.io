## 2. 燃料と還元化学
### 2-1. 製錬に木炭が必要な理由
&nbsp;&nbsp;&nbsp;木炭が製錬の燃料となった第一の理由は清浄さにあります。樹木は成長過程で硫黄をほとんど蓄積しないため、木炭に残る硫黄は通常0.1%を下回ります。一方、石炭には産地によって0.5%から3%、時にはそれ以上の硫黄が含まれています。

&nbsp;&nbsp;&nbsp;硫黄がなぜ問題になるかというと、鉄に入り込んだ硫黄は鉄と結合して硫化鉄を作り、この硫化鉄が結晶粒の境界に薄い膜のように挟まるからです。硫化鉄の融点は鉄よりはるかに低く、鍛造温度で既に軟化または熔融します。その結果、赤く熱した鉄を叩いた瞬間、結晶粒界から亀裂が入り、鉄が紙のように引き裂かれます。これが赤熱脆性であり、熱いときだけ脆くなり冷めると正常に見えるため、原因の特定がより困難になります。

| 不純物 | 混入経路 | 現れる症状 |
|:---|:---|:---|
| 硫黄 | 石炭、黄鉄鉱が混ざった鉱石 | 赤熱脆性。加熱した状態で叩くと割れます |
| リン | 沼鉄鉱、一部の褐鉄鉱 | 冷間脆性。冷えた状態で衝撃を加えると折れます |
| 珪素 | 鉱石の脈石、炉壁の土 | スラグを形成します。適量は必要ですが過剰だと歩留まりが落ちます |
| 灰分 | 燃料自体の無機物 | 炉の底に溜まり通気を阻害します |

&nbsp;&nbsp;&nbsp;木炭が持つ第二の長所は物理的強度です。炉の中で燃料は鉱石の重量を支えつつ、ガスが通る通路を維持しなければなりません。粉砕された燃料は通路を塞ぎ送風を死ませます。クヌギやカシのように硬い木で作った木炭が松炭よりも製錬に適している理由がここにあります。

### 2-2. コークス
&nbsp;&nbsp;&nbsp;コークスとは、石炭を空気のない密閉された室に入れ、1,000℃前後に加熱して揮発分やタールを追い出した後に残る炭素の塊です。木材を乾留して木炭を作るのと原理は全く同じであり、原料が木材の代わりに石炭であるだけです。

&nbsp;&nbsp;&nbsp;この過程で硫黄の一部がガスとして抜け、何より石炭が熔解した後に固まることで互いに付着し、硬く多孔質な塊となります。木炭は脆いため高く積み上げると下部が自重で潰れてしまい、そのため木炭を使う炉は一定の大きさ以上に大型化できませんでした。コークスは圧力がかかっても耐えるため、炉の高さを数十メートルまで高くすることが可能となり、大量製鉄の出発点となりました。

&nbsp;&nbsp;&nbsp;ただし災難状況において石炭を安定的に確保することは困難です。露天炭層や廃坑の周辺でない限り、木炭が事実上唯一の選択肢であり、それで十分に足ります。

### 2-3. 一酸化炭素
&nbsp;&nbsp;&nbsp;一般に炭素が酸化鉄から酸素を奪うと説明されますが、炉の中で実際に機能しているのは固体炭素ではなく気体である一酸化炭素です。固体と固体が接触する面積は極めて小さいですが、気体は鉱石の微小な孔の内部まで浸透できるためです。

&nbsp;&nbsp;&nbsp;反応は3段階で進行します。まず送風口の直前で炭素が酸素と出会い二酸化炭素となり、大きな熱を発生させます。この熱い二酸化炭素が上部の赤熱した木炭層を通過する際、再び炭素と出会い2分子の一酸化炭素へと変化します。この反応は吸熱反応であり、主に700℃以上で活発化します。そしてこの一酸化炭素が鉱石と接触して酸素を奪い取ります。

| 段階 | 反応 | 熱の移動 |
|:---|:---|:---|
| 燃焼 | C + O₂ → CO₂ | 強い発熱 |
| 再生 | CO₂ + C → 2CO | 吸熱、700°C以上で進行 |
| 還元 1 | 3Fe₂O₃ + CO → 2Fe₃O₄ + CO₂ | 弱い発熱 |
| 還元 2 | Fe₃O₄ + CO → 3FeO + CO₂ | 弱い吸熱 |
| 還元 3 | FeO + CO → Fe + CO₂ | 弱い発熱 |

&nbsp;&nbsp;&nbsp;この順序から2つの実践的結論が導き出されます。第一に、送風口の上部に十分な厚さの木炭層が積み上がっていなければ、二酸化炭素が一酸化炭素に戻る時間を稼げません。鉱石を低すぎる位置に投入すると、鉱石は還元されるどころか二酸化炭素によって再酸化されます。第二に、鉱石は豆粒からドングリほどの大きさに細かく砕かなければなりません。ガスが粒の内部まで侵入する必要があるため、塊が大きいと表面のみが還元され内部はそのまま残ってしまいます。

### 2-4. ブルーマリー（製鉄炉）で鉄は溶けない
&nbsp;&nbsp;&nbsp;純鉄の融点は1,538℃ですが、木炭と鞴で作るブルーマリー（Bloomery）炉の内部はせいぜい1,200〜1,400℃程度です。したがって還元された鉄は液体になれず、小さな粒の状態でその場に残ります。この粒同士が付着・凝集し、スポンジ状に穴の開いた塊となります。これを海綿鉄（塊鉄）と呼びます。

&nbsp;&nbsp;&nbsp;ここで決定的な役割を果たすのがスラグ（鉱滓）です。鉱石に混ざった珪石は還元されなかった酸化鉄と結合して珪酸鉄を作りますが、この物質の融点は約1,170℃と鉄より大幅に低いです。そのため炉内ではスラグのみが熔解して流れ落ち、流れ落ちながら鉄の粒の表面を覆って再酸化を防ぎ、粒同士が接合する場を提供します。

> **炉の温度がスラグの融点に達しない場合、鉄の粒は分散したまま終わってしまい、温度が高すぎて鉄が炭素を吸収しすぎると、熔融して脆く割れやすい銑鉄となってしまいます。ブルーマリー製錬の技術とは、この狭い温度領域を何時間も維持することにあります。**

&nbsp;&nbsp;&nbsp;炉から取り出した海綿鉄は、未だ半分近くがスラグです。そのため赤熱した状態のまま繰り返し叩き、スラグを水分のように搾り出します。叩くたびにスラグが火花のように飛び散り、塊は次第に緻密になっていきます。この工程で、最初に投入した鉱石の重量の15〜30%程度のみが使用可能な鉄として残ります。鍛造が成形作業である以前に精錬作業である理由がここにあります。
