## 3. 温度と送風が炉の限界を決めます
### 3-1. 金属ごとの融点
&nbsp;&nbsp;&nbsp;扱える金属は、炉が出せる温度で決まります。融点は純金属を基準としたもので、合金の大半は純金属より低い温度で溶けます。

| 金属 | 融点 | 沸点 | 備考 |
|:---|---:|---:|:---|
| スズ | 232℃ | 2,602℃ | たき火の灰の中でも溶ける |
| 鉛 | 327℃ | 1,749℃ | 約500℃から蒸気を出す |
| 亜鉛 | 420℃ | 907℃ | 沸点が銅の融点より低い |
| アルミニウム | 660℃ | 2,470℃ | 炭火で溶けるが、酸化皮膜のため外側が軟らかくなって崩れる |
| 銀 | 962℃ | 2,162℃ | 送風した炭火で可能 |
| 金 | 1,064℃ | 2,856℃ | 送風した炭火で可能 |
| 銅 | 1,085℃ | 2,562℃ | 強制送風が必要 |
| 鋳鉄 | 1,150-1,300℃ | - | 炭素2.1%以上。純鉄よりはるかに低い |
| 純鉄 | 1,538℃ | 2,862℃ | 原始的な炉では到達しにくい |

- 鋳鉄は純鉄より400℃近く低い温度で溶けます。炭素が混ざると融点が下がるため、炉の中で鉄が炭素を多く吸い込むと、液体になって流れ落ちます。高炉が溶けた鉄を取り出す原理であり、ブルーマリーでは失敗とみなします。
- 亜鉛の沸点(907℃)は、銅の融点(1,085℃)より低いです。真鍮を溶かすときに危険が生じる出発点です。

### 3-2. 火の温度
| 熱源 | おおよその温度 |
|:---|---:|
| 薪のたき火 | 600-900℃ |
| 自然通風の炭火 | 800-1,000℃ |
| ふいごで送風した炭火 | 1,100-1,300℃ |
| ブルーマリー炉の羽口の前 | 1,200-1,400℃ |
| 強制送風のるつぼ炉 | 1,200-1,400℃ |
| 近代の高炉 | 1,500-2,000℃ |

&nbsp;&nbsp;&nbsp;色で温度を読めば、温度計がなくても判断できます。暗い場所で見ると正確です。

| 色 | おおよその温度 |
|:---|---:|
| 暗い赤 | 550-700℃ |
| 鮮やかな赤 | 800-900℃ |
| オレンジ | 950-1,050℃ |
| 黄色 | 1,100-1,250℃ |
| 白に近い黄色 | 1,300℃以上 |

### 3-3. 送風
&nbsp;&nbsp;&nbsp;木炭を2倍に積んでも、温度は上がりません。温度は、熱が出る速さと逃げる速さの差で決まり、熱は炭素が酸素と出会って初めて出るため、発熱の速さは酸素の供給速度に縛られます。

&nbsp;&nbsp;&nbsp;炉の設計原則は3つあります。

1. 空気を強制的に送り込みます。
2. 熱が逃げる場所を減らします(厚い土壁、狭い焚き口)。
3. 燃焼が起きる場所を1か所に集めます。広く散らばった火は、どんなに激しく燃えても、一点を熱することができません。

&nbsp;&nbsp;&nbsp;空気をむやみに増やしてはいけません。空気の78%は反応に参加しない窒素で、熱だけを運んで煙突から抜けていきます。過剰な空気は炉を冷まし、炉内を酸化性の雰囲気にして、苦労して還元した鉄を再び酸化させます。よい送風とは、強い送風ではなく、途切れない一定の送風です。

---
### 3-4. 自然通風炉
&nbsp;&nbsp;&nbsp;ふいごなしで製錬した例が、アフリカの複数の地域に残っています。原理は煙突効果です。炉内の熱いガスは外の空気より軽いので上に昇り、その場所を下の穴から入る冷たい空気が埋めます。通風は内外の温度差と炉の高さに比例するため、炉を高く積むほど強くなります。

- 炉を2-3mと高く建て、下側に小さな穴をいくつかあけます。大きな穴1つよりも空気の速度が高いので、炉の中心部まで空気を送り込めます。
- 風が一定して吹く尾根や、谷の入り口に建てます。
- 限界: 同じ量の鉄を得るのに、時間と木炭がはるかに多くかかります。その代わり、何時間もふいごを押す必要がなく、人手が足りないときは有利です。

---
### 3-5. ふいご
&nbsp;&nbsp;&nbsp;風が途切れると、羽口の前の温度が下がり、炉内に一時的に酸化性の雰囲気が生じます。この短い繰り返しが積み重なると歩留まりが目立って下がるため、ふいごは途切れてはなりません。

| 形式 | 動作方式 | 特徴 |
|:---|:---|:---|
| 単一の革ふいご | 袋を押して風を出す | 作りやすいが、風が途切れる |
| 双子ふいご | 2つの袋を交互に押して、交代で送風する | ほとんど途切れない。アフリカと古代エジプトの標準 |
| 箱ふいご | ピストンと弁で、押すときも引くときも送風する | 1人で連続送風できる。東アジアで広く使用 |
| 足ふいご | 足で踏んで大きな袋を押す | 手が自由で、長く続けられる |

&nbsp;&nbsp;&nbsp;羽口は炉壁を貫いて内側に少し入れますが、炎の真ん中まで入ると燃え尽きてしまいます。粘土で成形した管を使うか、金属管の先端を粘土で包みます。角度は下向きにして、風が炉底付近の最も熱い区域を通るようにします。
