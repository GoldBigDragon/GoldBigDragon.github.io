## 3. 温度と送風が炉の限界を決める
### 3-1. 金属別の熔融温度
&nbsp;&nbsp;&nbsp;どの金属を扱えるかは、手元にある炉が出せる温度によって決まります。以下の融点は純金属を基準としたものであり、合金はほとんどの場合、純金属よりも低い温度で溶けます。

| 金属 | 融点 | 沸点 | 備考 |
|:---|---:|---:|:---|
| 錫（スズ） | 232°C | 2,602°C | たき火の灰の中でも溶けます |
| 鉛（ナマリ） | 327°C | 1,749°C | 約500°Cから蒸気を発生させます |
| 亜鉛 | 420°C | 907°C | 沸点が銅の融点より低いです |
| アルミニウム | 660°C | 2,470°C | 炭火で溶けますが、酸化膜のため表面が軟化して崩れ落ちます |
| 銀 | 962°C | 2,162°C | 送風した炭火で可能です |
| 金 | 1,064°C | 2,856°C | 送風した炭火で可能です |
| 銅 | 1,085°C | 2,562°C | 強制送風が必要です |
| 鋳鉄 | 1,150-1,300°C | - | 炭素2.1%以上、純鉄より大幅に低いです |
| 純鉄 | 1,538°C | 2,862°C | 原始的な炉では到達困難です |

&nbsp;&nbsp;&nbsp;表から読み取るべき点は2つあります。1つは、鋳鉄が純鉄より400℃近く低い温度で溶けるという事実です。炭素が混ざると融点が下がるため、炉内で鉄が炭素を多く吸収すると液体となって流れ落ちます。これが高炉で湯（ molten metal ）を排出する原理であり、同時にブルーマリーにおいては失敗とみなされる現象です。もう1つは、亜鉛の沸点907℃が銅の融点1,085℃より低いという事実であり、これが真鍮を溶かす際に必ず記憶しておくべき危険の出発点となります。

### 3-2. 実際の火が出す温度
&nbsp;&nbsp;&nbsp;燃料が理論上出し得る最高温度と、炉が実際に発生させる温度は全く異なります。

| 熱源 | 大まかな温度 |
|:---|---:|
| 薪のたき火 | 600-900°C |
| 自然通風の炭火 | 800-1,000°C |
| 鞴で送風した炭火 | 1,100-1,300°C |
| ブルーマリー炉の送風口前 | 1,200-1,400°C |
| 強制送風るつぼ炉 | 1,200-1,400°C |
| 近代高炉 | 1,500-2,000°C |

&nbsp;&nbsp;&nbsp;色で温度を読み取る方法も身につけておけば、温度計なしで判断できます。ただし、暗い場所で観察しなければ正確ではありません。

| 色 | 大まかな温度 |
|:---|---:|
| 暗い赤色 | 550-700°C |
| 鮮やかな赤色 | 800-900°C |
| 橙色 | 950-1,050°C |
| 黄色 | 1,100-1,250°C |
| 白に近い黄色 | 1,300°C以上 |

### 3-3. 温度を上げるのは燃料ではなく空気です
&nbsp;&nbsp;&nbsp;木炭を2倍に積み上げても温度は上がりません。温度は熱がどれだけ蓄積されているかではなく、単位時間あたりにどれだけ素早く発生し、どれだけ素早く逃げていくかの差によって決まります。炭素が酸素と出会って初めて熱が発生するため、熱の発生速度は酸素が供給される速度にそのまま拘束されます。

&nbsp;&nbsp;&nbsp;ここから炉を設計する3つの原則が導き出されます。第1に、空気を強制的に押し込むことです。第2に、熱が逃げる場所を減らすことであり、厚い土壁や狭い焚き口がこれに該当します。第3に、燃焼が起こる場所を一箇所に集中させることです。広く広がった火は、どんなに激しく燃えても一点を強力に加熱することはできません。

&nbsp;&nbsp;&nbsp;ただし、空気を無暗に大量に投入すれば良いというわけではありません。空気の78%は反応に関与しない窒素であり、この窒素は炉内を通過しながら熱だけを奪って煙突から排出されます。必要以上に投入された空気は温度を上げるどころか炉を冷却し、同時に炉内を酸化性雰囲気に変えて苦労して還元した鉄を再酸化させてしまいます。優れた送風とは、強い送風ではなく途切れることのない一定の送風です。

---
### 3-4. 自然通風炉は煙突の原理で作動します
&nbsp;&nbsp;&nbsp;鞴なしで製錬を行った事例は、アフリカの多くの地域に広く残されています。原理は煙突効果（スタック効果）です。炉内の熱いガスは外気より軽いため上方へ浮上し、その隙間を埋めるように下部の穴から冷たい空気が引き込まれます。この力は内外の温度差および炉の高さに比例するため、炉を高く構築するほど通風が強くなります。

&nbsp;&nbsp;&nbsp;そのため、自然通風製錬炉は2〜3mに達するよう高く建設し、下部に複数の小さな穴を設けます。穴を大きく1つ開けずに小さく複数設ける理由は、流入する空気の速度を高めて炉の中心部まで押し込むためです。風が一定に吹く尾根や谷の入り口に炉の遺構が多く見られるのも同じ理由によります。

&nbsp;&nbsp;&nbsp;自然通風の限界は速度にあります。同じ量の鉄を得るのにはるかに長い時間と多くの木炭を消費しますが、人間が何時間も鞴を漕ぎ続ける必要がありません。人手が不足している状況では有利な選択肢となります。

---
### 3-5. 送風は途切れさせてはなりません
&nbsp;&nbsp;&nbsp;最も単純な鞴は、革袋の口を手で開閉しながら押し潰して風を送り出す形状のものです。製作は容易ですが、袋を膨らませている間は風が途切れます。風が途切れるとその瞬間、送風口前の温度が低下し、炉内に一時的な酸化性雰囲気が生じます。この短い中断の積み重ねにより、歩留まりは著しく低下します。

| 形式 | 作動方式 | 特徴 |
|:---|:---|:---|
| 単一革鞴 | 袋を押して風を出す | 製作は容易ですが風が途切れます |
| 双子鞴 | 2つの袋を交互に押して交互に送風 | 途切れがほぼありません。アフリカおよび古代エジプトの標準 |
| 箱鞴 | ピストンと弁により押すときも引くときも送風 | 1人で連続送風が可能です。東アジアで広く用いられました |
| 足踏み鞴 | 足で踏んで大型の袋を押す | 手が自由になり長時間の作業に耐えられます |

&nbsp;&nbsp;&nbsp;送風口は炉壁を貫通して内側へ少し突き出させますが、火の真ん中まで達すると焼失してしまいます。粘土で成形した localized 管を用いたり、金属管の先端を粘土で覆う理由はここにあります。角度は概ね下方へ向け、風が炉底付近の最も高温な領域を通過するように設置します。
