## 4. 一氧化碳、副产物与非燃料用途
### 4-1. 一氧化碳中毒
&nbsp;&nbsp;&nbsp;台风、停电之后，在室内点炭火导致一家人丧生的事故，在世界各地以同样的形式反复发生。原因是一氧化碳（CO）。

- 产生：氧气不足时，碳只结合一个氧原子，变成CO。炭火在表面燃烧，会迅速消耗周围的氧气，所以在密闭空间里CO必然增加。
- 危险：CO与血液中的血红蛋白的结合力比氧气强200倍以上，阻碍氧气运输。虽然在呼吸，氧气却到不了组织。没有窒息感、咳嗽、气味这类警告信号。最初的症状是头痛和乏力，当成累了躺下，就这样失去意识。

| 空气中浓度 | 接触时间 | 出现的症状 |
|---:|:---|:---|
| 50 ppm | 8小时 | 健康成年人无明显症状 |
| 200 ppm | 2-3小时 | 轻微头痛、疲劳、恶心 |
| 400 ppm | 1-2小时 | 严重头痛。3小时后有生命危险 |
| 800 ppm | 45分钟 | 头晕、呕吐、抽搐。2小时内丧失意识 |
| 1,600 ppm | 20分钟 | 头痛和头晕。1小时内可能死亡 |
| 6,400 ppm | 1-2分钟 | 抽搐和呼吸停止。15分钟内死亡 |

> **注意：**即使没有火焰和烟，炭火也会持续产生CO。没有火焰、红红地暗燃的状态下，CO产生得最多。不要在帐篷、车内、关了窗的房间、地下室里点炭火。把窗户稍微开一点是解决不了的。

- 通风：相对的两处要开着，让空气真正流过。只开一侧窗户一手掌宽，不会形成气流。
- CO的密度与空气几乎相同，会均匀地扩散到整个房间。压低身体也躲不开。
- 怀疑中毒时，先把人转移到室外的空气中。没有症状的人也要一起出来。CO从血红蛋白上脱离，即使在新鲜空气中也需要几个小时。
- 进去救人的人成为第二个受害者，是这类事故的典型形态。

### 4-2. 木醋液与焦油
&nbsp;&nbsp;&nbsp;炭化时逸出的烟经过冷却会变成液体。放几天后分成三层。最上面是较轻的油分，中间是褐色的水溶液（木醋液），最下面沉着黑色黏稠的焦油。

| 副产物 | 主要成分 | 用途 | 注意事项 |
|:---|:---|:---|:---|
| 木醋液（粗液） | 水、乙酸、甲醇、酚类 | 刚收集后不直接使用 | 混有可能致癌的物质 |
| 木醋液（精制） | 以乙酸为主的水溶液 | 改良土壤、驱避病虫害、去除异味 | 必须沉淀6个月以上，分离上层油分和下层焦油 |
| 木焦油 | 酚类、杂酚油 | 木材防腐、绳索防水、填补船缝、粘合剂原料 | 对皮肤刺激强，易燃 |
| 沥青（Pitch） | 把焦油熬浓后固化而成 | 防水密封、箭头粘合剂的基料 | 加热时容易起火 |

- 灾难情况下副产物的价值在于防腐和防水。涂了木焦油的木桩，即使埋在地里，腐烂速度也会大大变慢，浸入绳索和布料可以拒水。把焦油继续熬浓得到的沥青，是粘合剂的基本材料。
- 木醋液不要饮用，也不要涂在伤口上。未经精制的木醋液混有多环芳烃等可能致癌的物质，在家里没有可靠的分离方法。

### 4-3. 不烧而用的木炭
&nbsp;&nbsp;&nbsp;炭化过程中，木头的细胞结构原样保留，只有内容物逸出，所以木炭内部密密麻麻地留着原来的导管和细胞壁形成的细微通道。这种结构赋予木炭非常大的表面积。

| 用途 | 作用原理 | 局限 |
|:---|:---|:---|
| 除臭 | 气味分子物理性地附着在孔隙表面 | 孔隙填满后效果消失。晒太阳可以部分恢复 |
| 除湿 | 孔隙吸收水蒸气，干燥时释放 | 容量小，对大空间不够用 |
| 改善水的味道和气味 | 吸附溶解的有机物和氯 | 几乎抓不住细菌和病毒 |
| 改良土壤 | 孔隙保持水分和养分，成为微生物的栖息地 | 直接放入的话，初期会夺走养分。与堆肥混合后使其腐熟 |
| 火药原料 | 向作为氧气来源的硝酸钾提供作为燃料的碳 | 适合用低密度木材低温烧成的木炭 |
| 书写、标记 | 碳颗粒留在表面 | 遇水会被擦掉 |
| 辅助处理伤口 | 通过吸附减少渗出液 | 没有消毒效果。对感染的伤口有害 |

- 活性炭和木炭是不同的。活性炭是把木炭再用800-1,000℃的水蒸气或药剂处理，使孔隙扩大而成，表面积每克有几百到1,500平方米。普通木炭的表面积比它小几十倍。有关净水、除臭的数值大多以活性炭为基准，不能直接套用于自己烧的木炭。
- 吸附不是分解。木炭只是抓住，并不消除。孔隙填满后吸附就停止，在水中长期使用的木炭，会以抓住的有机物为食，滋生细菌。净水用的木炭层要定期更换。

### 4-4. 保管
&nbsp;&nbsp;&nbsp;木炭不会腐烂变质，但怕潮湿和冲击。

- 潮湿：由于孔隙结构，会不断吸收空气中的水分。梅雨季节，重量的10%以上可能变成水，这种状态下不易点燃，会冒烟，火力下降。受潮的木炭晾几天就能恢复。放进密闭容器或厚袋子里，离地保管。
- 冲击：搬运中互相碰撞会碎裂，变成粉末后空气不通，作为燃料的价值下降。粉末可用作粘合剂的填料、土壤改良剂和火药原料。

> **注意：**刚烧好的木炭，看起来凉了，内部也可能还有热量。制炭火灾中相当一部分，是以为已经凉透而装袋、放进棚屋的木炭几个小时后起火。从窑里取出的木炭，要在室外不可燃的地面上摊放至少一天以上，用手摸确认完全冰凉后再保管。
