# 肥皂
---
## 1. 原理
### 1-1. 肥皂的作用原理
&nbsp;&nbsp;&nbsp;数千年来，人类一直通过组合动物脂肪或植物油以及木灰来制造肥皂，这一工艺在漫长的历史中不断得到精炼。肥皂作为一种表面活性剂，其工作原理是使油脂乳化，从而能够被水冲洗干净。

&nbsp;&nbsp;&nbsp;肥皂分子与水混合时，会自发形成一种名为微泡（米氏胶束/Micelles）的球形结构。其亲水性头部与水接触，而亲油性尾部则隐藏在内侧。当遇到油污时，微泡会将油滴包裹在其内部空间中，使其与水隔离，从而让油脂稳定地分散（处于胶体状态）在水中并被洗发冲刷掉。

---
### 1-2. 化学理解
&nbsp;&nbsp;&nbsp;肥皂是由动植物脂肪的主要成分——甘油三酯（Triglycerides）与强碱发生反应制成的。这种反应被称为皂化反应。  

&nbsp;&nbsp;&nbsp;作为脂肪储存分子的甘油三酯由一个甘油骨架和三个脂肪酸尾部组成，它们通过酯键连接在一起。如果在其中加入强碱（如氢氧化钠），酯键就会断裂，从而形成甘油和脂肪酸盐（Fatty Acid Salts），这种脂肪酸盐就是肥皂。

&nbsp;&nbsp;&nbsp;用于制造肥皂的碱的种类决定了最终肥皂的特性。构成肥皂的脂肪酸碳链越长，肥皂越难溶于水、质地越硬，且往往不易起泡。氢氧化钠（Sodium Hydroxide, NaOH，烧碱）会形成坚硬且难溶于水的钠脂肪酸盐，适合制作固体肥皂；而氢氧化钾（Potassium Hydroxide, KOH）则会形成柔软且易溶于水的钾盐，适合制作液体肥皂。

&nbsp;&nbsp;&nbsp;将 1g 猪脂（Lard）完全皂化所需的氢氧化钠（NaOH）量约为 0.138g。因此，在使用 1kg 猪脂制造肥皂时，理论上需要 138g 氢氧化钠。（以 0% 超脂为基准）

## 2. 肥皂制造常识
### 2-1. 安全守则
&nbsp;&nbsp;&nbsp;在制造肥皂时，必须佩戴护目镜 and 手套。诸如氢氧化钠和氢氧化钾等强碱性溶液具有强烈的腐蚀性，一旦溅入眼中可能会造成严重的损伤。  

&nbsp;&nbsp;&nbsp;如果不慎接触到皮肤或眼睛，应立即用流动的水冲洗 15 分钟以上，并在必要时采取医疗措施。在强碱灼伤时使用食醋是非常危险的，因为中和过程中产生的热量反而会加重灼伤。  

&nbsp;&nbsp;&nbsp;必须严格遵守混合顺序，将氢氧化钠加入水中。如果将水倒入氢氧化钠中，可能会导致危险的喷溅或剧烈沸腾。

&nbsp;&nbsp;&nbsp;将氢氧化钠溶解于水中时会释放出大量的热并可能产生烟雾。由于该溶液极度炽热且危险，必须将其放置在远离儿童 and 宠物的地方。

---
### 2-2. 冷制法与热制法
&nbsp;&nbsp;&nbsp;制造肥皂的主要方法有冷制法（Cold Process） and 热制法（Hot Process）两种，它们各自具有明显的优缺点。

| 区分 | 冷制法 | 热制法 |
| :---: | --- | --- |
| 温度 | 无需外部加热（利用反应热） | 在约 90°C 下进行 |
| 固化时间 | 需 4~6 周（反应完成 and 水分蒸发） | 约需 1 天（较快） |
| 优点 | 易于浇筑成各种形状，可使用多种添加剂 | 快速 |
| 单点 | 固化时间长 | 粘度极高导致只能制作基本形状，无法使用不耐热的添加剂 |
| 用途 | 固体肥皂（如猪脂皂、橄榄油/椰子油皂） | 液体肥皂（使用氢氧化钾时） |

---
### 2-3. 痕迹阶段与添加剂的影响
&nbsp;&nbsp;&nbsp;搅拌肥皂混合物时，其表面开始留下搅拌痕迹的时间点被称为痕迹（Trace）阶段。痕迹阶段的浓稠度会影响肥皂的设计 and 添加剂的混合。虽然传统上猪脂皂可以不添加任何添加剂、以纯净状态制作，但在制造其他肥皂时可以灵活利用各种添加剂。

| 痕迹浓度 | 特点 | 适用用途 |
| --- | --- | --- |
| 轻度痕迹 (Light Trace) | 非常稀薄，呈液体状 | 渲染设计、混合液体添加剂 |
| 中度痕迹 (Medium Trace) | 稠度适中 | 易于使固体添加剂（如种子、咖啡粉）均匀悬浮 |
| 厚重痕迹 (Thick Trace) | 粘度极高，可保持形态 | 纹理质感设计、制作多层肥皂 |

&nbsp;&nbsp;&nbsp;添加剂的种类可能会对肥皂的粘度 and 固化时间产生影响。由于特定添加剂（如肉桂醛或苯甲醛）对强碱高度敏感，因此必须在氢氧化钠大部分被消耗掉的痕迹阶段之后加入，以防其遭到破坏。  
  
&nbsp;&nbsp;&nbsp;超脂（Super-fatting）是指在制造肥皂时，添加比理论所需量略多一点的脂肪。这可以在肥皂中留下多余的油脂，从而起到减少皮肤干燥、使其更加温和滋润的效果。

---
## 3. 利用氢氧化钠制造肥皂
&nbsp;&nbsp;&nbsp;利用猪脂（Lard）制造肥皂是最传统的方式，仅需最少限度的材料（水、猪脂、氢氧化钠）即可制成保湿效果极佳的肥皂。

&nbsp;&nbsp;&nbsp;猪脂皂通常以纯白色、坚硬的块状形态完成，质地极其温和且保湿效果出色。这是猪脂中所含的油酸（Oleic acid）、皂化反应中自然生成的甘油，以及由于超脂效果而保留的残余脂肪共同作用的结果。  

&nbsp;&nbsp;&nbsp;由于传统猪脂皂中不含有专门起泡的油脂，因此其泡沫较少，富有浓郁的奶油感。相反，一旦肥皂成型，它就可以保存数年之久；并且它还具有一项优点：与普通肥皂不同，即便接触到水它也不会持续融化糊化，而是能够保持干爽。

| 材料 | 容量 | 说明 |
| :---: | ---: | :--- |
| 猪脂 | 500g | 猪脂肪。可直接精炼或购买成品。 |
| 氢氧化钠 | 67g | 分子式为 NaOH 的食品级强碱。食品级是指其纯度标准，并不意味着可以食用。67g 是为了降低腐蚀风险、按约 5% 的超脂率计算得出的数值。 |
| 蒸馏水 | 130ml | 通过加热水产生的蒸气经冷却后去除杂质 and 矿物质的纯净水，必须使用精确的量。 |
| 精密天平 | 1个 | 准确称量材料是至关重要的。 |
| 搅拌工具 | 1个 | 手动搅拌会耗费极长时间，使用手持搅拌棒可以明显更快地达到痕迹（Trace）阶段。 |
| 模具 | 1个 | 可使用硅胶模具或塑料盒等。 |

| 步骤 | 方法 |
| :---: | :--- |
| 1 | 用天平准确称量蒸馏水 and 氢氧化钠。 |
| 2 | 将氢氧化钠缓缓加入装有水的容器中，搅拌直至完全溶解。 |
| 3 | 将氢氧化钠溶液放在一旁冷却。溶液的目标温度约为 38°C。 |
| 4 | 将固体状态的猪脂加热熔化，直至其完全呈现液体状态。 |
| 5 | 将熔化的猪脂倒入搅拌碗中并冷却。猪脂的目标温度约为 27°C。 |
| | ! 合理调节氢氧化钠与猪脂的温度，对于肥皂良好地固化至关重要。 |
| 6 | 将温度适宜的氢氧化钠溶液缓缓地、小心地倒入猪脂中。混合后皂化反应会立即开始，可以观察到混合物变得浑浊。 |
| 7 | 使用搅拌工具，每次短促搅拌 20~30 秒。猪脂皂达到痕迹阶段所需的时间可能比其他植物油皂更长。（如果使用手动搅拌，耗时会明显更久） |
| | ! 搅拌混合物时在其表面留下痕迹的状态被称为痕迹（Trace）。这一时间点意味着油脂与氢氧化钠已实现稳定乳化，不再发生分离。进入痕迹阶段后如果搅拌时间过长，混合物会变得过于稠厚，导致难以倒入模具中。 |
| 8 | 将达到痕迹阶段的肥皂混合物倒入模具中。（在这一阶段，肥皂中可能仍残存有氢氧化钠或氢氧化钾，依然带有危险性） |
| 9 | 用毯子或厚毛巾将模具包裹起来以保持热量。这种热量会促进皂化反应。 |
| 10 | 24 小时后，将肥皂从模具中取出，用刀或切皂器切成所需的尺寸。 |
| | ! 由于猪脂皂会固化得非常坚硬，如果在模具中放置时间过长（例如一周），切皂就会变得极其困难。 |
| 11 | 将切好的肥皂块摆放在通风良好的塑料网垫或层架上，每周至少翻面一次进行熟化。  |
| | ! 肥皂在切块后，使用前必须经过熟化（Curing）过程。冷制皂通常需要经过 4 到 6 周的熟化期，在此期间残余的水分会蒸发，使肥皂变得更硬、更温和。 |

## 4. 传统方式肥皂制造
&nbsp;&nbsp;&nbsp;现代肥皂制造法使用精炼的高纯度氢氧化钠（NaOH），而在古代至中世纪，人们则是通过组合从自然界中获取的材料来直接制造强碱。这种方式制成的是以氢氧化钾（KOH）为主要成分的软质肥皂。

&nbsp;&nbsp;&nbsp;氢氧化钾肥皂不会呈现出坚硬的固体形态，而是成为软性肥皂，即液体或凝胶状。此外，与使用精炼碱的现代方式不同，传统的草木灰提取法极其难以确保获得准确的碱浓度。生成的溶液并非纯净的氢氧化钾（KOH），而是混有碳酸钾及其他杂质的形态。由于其碱浓度测量并不完全，因此最好将其用于洗涤餐具及洗涤衣物，而非用于洁面/沐浴。

---
### 4-1. 传统方式肥皂制造方法
| 步骤 | 方法 |
| :---: | :--- |
| 1 | 将贝壳或石灰石在约 1000°C 下煅烧，准备好氧化钙（CaO，生石灰）。 |
| 2 | 向焚烧阔叶树得到的草木灰中倒水浸泡并过滤，提取出浓草木灰水（碳酸钾，K₂CO₃ 水溶液）。 |
| 3 | 向生石灰粉末中分次少许加水，调制成熟石灰（氢氧化钙，Ca(OH)2）调和物（浆料）。 |
| 4 | 将熟石灰浆料加入草木灰水中，一同加热煮沸。 |
| 5 | 混合溶液在煮沸过程中，下层会沉积出白色的碳酸钙沉淀，而上层则会生成强碱性溶液（氢氧化钾，KOH）。单独将上层的清液过滤提取出来。 |
| 6 | 将制得的氢氧化钾溶液与熔化的猪脂混合，随后边加热边持续搅拌，直至其变得浓稠。 |

---
### 4-2. 灰水碱液强度试验方法
&nbsp;&nbsp;&nbsp;利用传统方法制造肥皂时，由于无法精确称量灰水溶液的浓度，人们通常使用经验性的试验方法。

#### 4-2-1. 鸡蛋试验法
&nbsp;&nbsp;&nbsp;通过将鸡蛋放入灰水溶液中，观察鸡蛋的一部分浮出水面的程度来判断碱浓度。如果鸡蛋完全下沉，则说明碱度过弱，难以发生皂化；如果浮出一半以上，则说明碱度过强，可能会破坏脂肪。因此，顶端（直径 2cm 左右）微微浮出水面的灰水溶液最为合适。

#### 4-2-2. 羽毛试验法
&nbsp;&nbsp;&nbsp;通过将羽毛浸入灰水溶液中，观察羽毛的熔化程度来判断碱浓度。浸入羽毛时它不应立即熔化，而是在几秒到几十秒内，其边缘开始变软并发生分解。如果羽毛没有发生任何变化，则说明碱度不足；如果立即熔化消失，则说明浓度过高。使羽毛缓慢受损的灰水溶液最为合适。
