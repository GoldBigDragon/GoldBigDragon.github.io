# 비누
---
## 1. 원리
### 1-1. 비누의 작용 원리
&nbsp;&nbsp;&nbsp;비누는 수천 년 동안 동물성 지방이나 식물성 기름, 그리고 재를 조합하여 만들어져 왔으며, 이 과정은 오랜 시간에 걸쳐 정제되었습니다. 비누는 계면활성제로서 기름을 유화시켜 물에 의해 씻겨 내려가게 하는 방식으로 작동합니다.
  
![image](./media/Micelles.png)  
&nbsp;&nbsp;&nbsp;비누 분자는 물과 섞일 때 스스로 구형 구조인 미셸(Micelles)을 형성합니다. 친수성 머리 부분은 물과 접촉하고, 친유성 꼬리 부분은 안쪽으로 숨습니다. 기름때가 있으면, 미셸은 기름방울을 내부 공간에 가두어 물로부터 격리하고, 이에 따라 기름이 물에 안정적으로 분산(콜로이드 상태)되어 씻겨 나갑니다.

---
### 1-2. 화학적 이해
&nbsp;&nbsp;&nbsp;비누는 동식물성 지방의 주성분인 트리글리세리드(Triglycerides) 와 강염기 가 반응하여 만들어집니다. 이 반응을 비누화 반응이라고 합니다.  

&nbsp;&nbsp;&nbsp;지방 저장 분자인 트리글리세리드는 글리세롤 백본과 세 개의 지방산 꼬리로 이루어져 있으며, 이들은 에스터 결합으로 연결되어 있습니다. 여기에 강염기(예: 수산화나트륨)를 첨가하면 에스터 결합이 끊어지면서 글리세롤과 지방산 염(Fatty Acid Salts)이 형성되는데, 이 지방산 염이 바로 비누입니다.

&nbsp;&nbsp;&nbsp;비누 제작에 사용되는 염기의 종류에 따라 최종 비누의 특성이 결정됩니다. 비누를 구성하는 지방산의 사슬 길이가 길수록 비누는 물에 덜 녹고 더 단단해지며, 거품이 잘 나지 않는 경향이 있습니다. 수산화나트륨(Sodium Hydroxide, NaOH, 양잿물)은 단단하고 물에 덜 녹는 나트륨 지방산 염을 형성하여 고체 비누를 만드는 데 적합하며, 수산화칼륨(Potassium Hydroxide, KOH)은 부드럽고 물에 잘 녹는 칼륨염을 형성하여 액체비누를 만드는 데 적합합니다.

&nbsp;&nbsp;&nbsp;라드(돼지 지방) 1g을 완전히 비누화하는 데 필요한 수산화나트륨(NaOH)의 양은 약 0.138g으로, 라드 1kg으로 비누를 만들 때, 수산화나트륨은 이론적으로 138g이 필요합니다. (슈퍼패팅 0% 기준)

## 2. 비누 제조 상식
### 2-1. 안전 수칙
&nbsp;&nbsp;&nbsp;비누 제조시 고글과 장갑을 반드시 착용해야 합니다. 수산화나트륨과 수산화칼륨 같은 강알칼리성 용액은 부식성이 강하며, 눈에 튀면 심각한 손상을 입힐 수 있습니다.  

&nbsp;&nbsp;&nbsp;만약 피부나 눈에 닿으면 즉시 흐르는 물로 15분 이상 세척하고 필요 시 의료 조치를 취해야 합니다. 강염기 화상 시 식초를 사용하는 것은 중화 과정에서 열이 발생하여 오히려 화상을 악화시킬 수 있으므로 위험합니다.  

&nbsp;&nbsp;&nbsp;혼합 순서를 엄수하여 반드시 수산화나트륨을 물에 넣어야 합니다. 물을 수산화나트륨에 넣으면 위험하게 튀거나 끓어오를 수 있습니다.

&nbsp;&nbsp;&nbsp;수산화나트륨을 물에 녹일 때 많은 열이 발생하며 연기가 날 수 있습니다. 이 용액은 매우 뜨겁고 위험하므로, 아이들과 반려동물로부터 멀리 떨어진 곳에 두어야 합니다.

---
### 2-2. 콜드 프로세스와 핫 프로세스
&nbsp;&nbsp;&nbsp;비누를 만드는 주요 방법은 콜드 프로세스(Cold Process) 와 핫 프로세스(Hot Process) 두 가지가 있으며, 각각 장단점이 뚜렷합니다.

| 구분 | 콜드 프로세스 | 핫 프로세스 |
| :---: | --- | --- |
| 온도 | 외부 가열 없이 진행 (반응열 이용) | 약 90°C에서 진행 |
| 경화 시간 | 4~6주 소요 (반응 완료 및 수분 증발) | 약 1일 소요 (빠름) |
| 장점 | 다양한 모양으로 몰딩이 용이하며, 다양한 첨가물 사용 가능 | 빠름 |
| 단점 | 경화 시간이 김 | 점성이 매우 높아 기본적인 모양만 가능, 열에 약한 첨가물 사용 불가 |
| 용도 | 고체 비누 (예: 라드 비누, 올리브/코코넛 오일 비누) | 액체 비누 (수산화칼륨 사용 시) |

---
### 2-3. 트레이스 단계와 첨가물의 영향
&nbsp;&nbsp;&nbsp;비누 혼합물을 저을 때 표면에 자국(흔적)이 남는 시점을 트레이스(Trace) 단계라고 합니다. 트레이스 단계의 농도는 비누의 디자인과 첨가물 혼합에 영향을 미칩니다. 라드 비누는 전통적으로 첨가물 없이 순수한 상태로 만들기도 하지만 , 다른 비누 제조 시에는 첨가물을 활용할 수 있습니다.

| 트레이스 농도 | 특징 | 적합한 용도 |
| --- | --- | --- |
| 라이트 트레이스(Light Trace) | 매우 묽고 액체 같음 | 소용돌이 디자인, 액체 첨가물 혼합 |
| 미디엄 트레이스(Medium Trace) | 적당히 걸쭉함 | 고체 첨가물(예: 씨앗, 커피 가루)을 분산시키기 좋음 |
| 틱 트레이스(Thick Trace) | 점성이 매우 높고 모양을 유지함 | 질감 디자인, 다층 비누 제작 |

&nbsp;&nbsp;&nbsp;첨가물의 종류에 따라 비누의 점도와 경화 시간에 영향을 미칠 수 있습니다. 시나몬알데하이드나 벤즈알데하이드 같은 특정 첨가물은 강염기에 민감하므로, 수산화나트륨이 대부분 소모된 트레이스 단계 이후에 넣어야 파괴되지 않습니다.  
  
&nbsp;&nbsp;&nbsp;슈퍼패팅(Super-fatting)은 비누를 만들 때 필요한 양보다 지방을 약간 더 많이 첨가하는 것을 말합니다. 이는 비누에 잔여 기름을 남겨 피부를 덜 건조하게 하고 부드럽게 만드는 효과가 있습니다.

## 3. 수산화나트륨을 이용한 비누 제조
&nbsp;&nbsp;&nbsp;라드(Lard, 돼지 지방)를 이용한 비누 제조는 가장 전통적인 방식이며, 최소한의 재료(물, 라드, 수산화나트륨)만으로 보습력이 뛰어난 비누를 만들 수 있습니다.

&nbsp;&nbsp;&nbsp;라드 비누는 보통 순백색의 단단한 바 형태로 완성되며, 매우 부드럽고 보습력이 뛰어납니다. 이는 라드에 포함된 올레산(Oleic acid), 비누화 반응 중 자연 생성된 글리세린, 그리고 슈퍼 패팅 효과로 남은 잔여 지방의 복합적인 결과입니다.  

&nbsp;&nbsp;&nbsp;전통적인 라드 비누는 거품을 내는 기름이 없기 때문에 거품이 약하고 크림 같은 느낌이 강합니다. 대신 일단 비누가 되면 수년 동안 보관할 수 있으며 , 일반 비누처럼 물에 닿아도 계속 녹아내려 끈적해지지 않고 건조하게 유지되는 장점이 있습니다.

| 재료 | 용량 | 설명 |
| :---: | ---: | :--- |
| 라드 | 500g | 돼지 지방입니다. 직접 정제하거나 구매할 수 있습니다. |
| 수산화나트륨 | 67g | 분자식 NaOH의 식품 등급 강염기입니다. 식품 등급은 순도 기준을 의미하며, 섭취 가능하다는 뜻은 아닙니다. 67g은 부식 위험을 줄이기 위해 약 5%의 슈퍼패팅을 계산한 값입니다. |
| 증류수 | 130ml | 물을 가열해 발생한 수증기를 냉각시켜 불순물과 미네랄을 제거한 순수한 물로, 정확한 양을 사용해야 합니다. |
| 정밀 저울 | 1개 | 재료를 정확하게 계량하는 것이 매우 중요합니다. |
| 믹싱 도구 | 1개 | 수동으로 저으면 시간이 매우 오래 걸리며, 핸드 블렌더를 사용하면 트레이스(Trace) 단계에 훨씬 빠르게 도달할 수 있습니다. |
| 성형판 | 1개 | 실리콘 판이나 플라스틱 상자 등을 사용할 수 있습니다. |

| 순서 | 방법 |
| :---: | :--- |
| 1 | 증류수와 수산화나트륨을 저울로 정확하게 계량합니다. |
| 2 | 물이 담긴 용기에 수산화나트륨을 천천히 넣고 완전히 녹을 때까지 저어줍니다. |
| 3 | 수산화나트륨 용액을 한쪽에 두고 식힙니다. 용액의 목표 온도는 약 38°C입니다. |
| 4 | 고체 상태의 라드를 액체 상태가 될 때까지 녹입니다. |
| 5 | 녹인 라드를 믹싱 볼에 붓고 식힙니다. 라드의 목표 온도는 약 27°C입니다. |
| | ! 수산화나트륨과 라드의 온도를 적절하게 맞추는 것이 비누가 잘 굳는 데 중요합니다. |
| 6 | 온도가 맞춰진 라드에 수산화나트륨 용액을 천천히, 조심스럽게 부어줍니다. 혼합 직후부터 비누화 반응이 시작되어 혼합물이 뿌옇게 변하는 것을 볼 수 있습니다. |
| 7 | 믹싱 도구를 사용하여 20~30초씩 짧게 끊어 저어줍니다. 라드 비누는 다른 오일 비누보다 트레이스에 도달하는 데 시간이 오래 걸릴 수 있습니다. (수동으로 저으면 훨씬 더 오래 걸립니다) |
| | ! 혼합물을 저을 때 표면에 자국이 남는 상태를 트레이스(Trace) 라고 합니다. 이 시점은 오일과 수산화나트륨이 안정적으로 유화되어 더 이상 분리되지 않는 상태를 의미합니다. 트레이스 단계에 접어든 이후 너무 오래 저으면 과도하게 두꺼워져 성형판에 붓기 어려울 수 있습니다. |
| 8 | 트레이스 단계에 도달한 비누 혼합물을 성형판에 부어줍니다. (이 단계에서도 비누는 아직 수산화나트륨 혹은 수산화칼륨이 남아있어 위험할 수 있습니다) |
| 9 | 성형판을 담요나 두꺼운 타월로 감싸 열을 보존합니다. 이 열은 비누화 반응을 촉진합니다. |
| 10 | 24시간이 지나면 성형판에서 비누를 꺼내 칼이나 커터로 원하는 크기로 자릅니다. |
| | ! 라드 비누는 매우 단단하게 굳기 때문에, 몰드에 너무 오래(예: 일주일) 두면 자르기가 매우 어려워집니다. |
| 11 | 비누 조각들을 공기가 잘 통하도록 플라스틱 시트나 선반 위에 세워 일주일에 한 번 이상 뒤집어 주며 경화합니다.  |
| | ! 비누는 자른 후에도 사용하기 전에 반드시 경화(Curing) 과정을 거쳐야 합니다. 콜드 프로세스 비누는 보통 4주에서 6주 동안 경화 과정을 거쳐야 하며, 이 기간 동안 남은 수분이 증발하여 비누가 더 단단해지고 순해집니다. |

## 4. 전통 방식 비누 제조
&nbsp;&nbsp;&nbsp;현대적인 비누 제조법이 정제된 수산화나트륨(NaOH)을 사용하는 반면, 고대부터 중세까지는 자연에서 얻은 재료를 조합하여 강염기를 직접 만들어 사용했습니다. 이 방식은 수산화칼륨(KOH)을 주성분으로 하는 연성 비누를 만듭니다.

&nbsp;&nbsp;&nbsp;수산화칼륨 비누는 단단한 고체 형태가 아닌 연성 비누, 즉 액체 또는 젤 형태가 됩니다. 또한 전통적인 잿물 추출법은 정제된 염기를 사용하는 현대 방식과 달리, 정확한 알칼리 농도를 확보하기 매우 어려워 생성된 용액은 순수한 수산화칼륨(KOH)이 아니라, 탄산칼륨 및 기타 불순물이 혼합된 형태여서 알칼리 농도 측정이 불완전하므로, 세안/목욕용보다는 식기 세척 및 세탁용으로 사용하는 것이 좋습니다.

---
### 4-1. 전통 방식 비누 제조 방법
| 순서 | 방법 |
| :---: | :--- |
| 1 | 조개껍데기나 석회석을 약 1000°C에서 구워 산화칼슘(CaO, 생석회)을 준비합니다. |
| 2 | 활엽수를 태운 재에 물을 붓고 우려내어 진한 잿물(탄산칼륨, K₂CO₃ 수용액)을 거릅니다. |
| 3 | 생석회 가루에 물을 조금씩 부어 소석회(수산화칼슘, Ca(OH)2) 반죽(슬러리)을 만듭니다. |
| 4 | 잿물에 소석회 반죽을 넣고 함께 끓입니다. |
| 5 | 혼합 용액이 끓으면서 하층부에는 흰색 탄산칼슘 앙금이 가라앉고, 상층부에는 강알칼리 용액(수산화칼륨, KOH)이 생성됩니다. 상층부의 맑은 용액만 따로 걸러냅니다. |
| 6 | 제조된 수산화칼륨 용액을 녹인 라드와 섞은 뒤, 걸쭉해질 때까지 가열하며 꾸준히 저어줍니다. |

---
### 4-2. 잿물 알칼리 강도 시험 방법
&nbsp;&nbsp;&nbsp;전통적인 방법으로 비누를 제조할 때는 잿물 용액 농도를 정밀히 계량할 수 없어서 경험적인 시험법을 사용했습니다.

#### 4-2-1. 계란 시험법
&nbsp;&nbsp;&nbsp;잿물 용액에 계란을 띄워 계란의 일부가 수면 위로 뜨는 정도를 보고 알칼리 농도를 판단할 수 있습니다. 계란이 완전히 가라앉으면 알칼리가 너무 약하여 비누화가 어려웠고, 반 이상 뜨면 알칼리가 과도하여 지방을 손상시킬 수 있었기에, 윗부분(지름 2cm 정도)이 조금 뜨는 잿물 용액이 적합합니다.

#### 4-2-2. 깃털 시험법
&nbsp;&nbsp;&nbsp;잿물 용액에 깃털을 담가 깃털이 녹는 정도를 관찰하여 알칼리 농도를 판단할 수 있습니다. 깃털을 담갔을 때 즉시 녹지 않지만, 몇 초에서 수십 초 내에 끝부분이 흐물거리며 분해되어야 합니다. 깃털에 변화가 없으면 알칼리가 부족한 상태이며, 즉시 녹아 사라지면 과한 농도입니다. 천천히 손상되는 잿물 용액이 적합합니다.
