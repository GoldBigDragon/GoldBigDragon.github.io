## 引言
&nbsp;&nbsp;&nbsp;本文介绍如何自行获得消毒用酒精（乙醇）。酒精用于伤口处理和工具消毒，也可用作燃料、萃取溶剂和保存液。灾难持续时间一长，它是最先耗尽的物资之一。

&nbsp;&nbsp;&nbsp;制作过程伴随两种危险。

- 物理危险：酒精蒸气在较低温度下就会起火，密闭的装置会因压力而爆裂。
- 甲醇：在味道和气味上与乙醇无法区分，喝下后半天以上没有症状，随后导致失明和死亡。这就是蒸馏最初流出的液体（酒头）必须丢弃的原因。

> **注意：**以饮用为目的酿造酒类，在包括韩国在内的大多数国家都是违法的。本文是在无法获得医用消毒剂和燃料的情况下对原理的整理，不建议也不指导以饮用为目的的制作。饮用未经精确测量而制成的蒸馏液，是在赌甲醇中毒的概率。

---

## 1. 酒精杀灭微生物的原理与浓度
&nbsp;&nbsp;&nbsp;酒精通过两种作用消毒。它溶解构成微生物细胞膜的脂质，使膜崩溃；它还使细胞内外的蛋白质变性，使酶和结构失效。两种作用叠加，几十秒内就能见效。

---
### 1-1. 60-90%最强的原因
&nbsp;&nbsp;&nbsp;看起来越浓越强，其实不然。美国CDC将最佳杀菌浓度定为与水混合的60-90%，并明确指出无水酒精的杀菌力低于酒精与水的混合物。

- 蛋白质变性是折叠的链被解开，而解开需要水。水分子钻进链之间，代替原有的结合，使结构崩溃。没有水时，酒精起的不是使其变性的作用，而是夺走水分的脱水剂作用，而脱水的蛋白质反而会变硬。
- 无水酒精接触到微生物时，表面蛋白质先硬化，形成壳一样的一层，这一层阻止酒精渗入。外面硬化了，里面却留着完好的细胞，酒精挥发后它们又会复活。

| 浓度 | 效果 | 原因 |
| --- | --- | --- |
| 95%以上 | 低 | 水不足，不发生变性，只有表面硬化 |
| 70-90% | 最高 | 同时具备变性所需的水和渗透力 |
| 60-70% | 足够 | 实际中广泛使用的区间 |
| 50%以下 | 急剧下降 | 溶解力不足以使膜崩溃 |
| 40%以下 | 不适合作消毒剂 | 可用于保存，但消毒不可靠 |

&nbsp;&nbsp;&nbsp;用水稀释消毒用酒精，不是省着用的窍门，而是调到70%所必需的工序。直接使用95%的酒精，反而更弱。

&nbsp;&nbsp;&nbsp;稀释要用消过毒的水（煮沸后放凉的水、蒸馏水）。酒精会立即挥发，而水会留下，所以用被污染的水稀释的话，那些水中的微生物会在消毒液里存活。

---
### 1-2. 酒精的局限
| 局限 | 内容 |
| --- | --- |
| 对芽孢无效 | 破伤风杆菌和肉毒杆菌的芽孢不会被酒精杀死 |
| 没有残留效果 | 挥发的瞬间保护就结束，无法抵御再次污染 |
| 对有机物效果差 | 有血和油脂时无法渗入，所以要先清洗 |
| 对部分病毒效果差 | 对没有脂质包膜的病毒效果相对较差 |
| 对原虫包囊效果差 | 对隐孢子虫之类无法指望 |
| 无法消毒饮用水 | 能让水变得可饮用的浓度，起不到消毒作用 |

- “把酒兑进水里水就被消毒了”的想法不成立。消毒所需的浓度在60%以上，而这个浓度的液体不是能喝的水。酒精是用来消毒表面、手和工具的手段。
- 需要接触时间。表面保持湿润的时间就是消毒时间，大致在30秒左右。涂在手上后不要马上擦掉，要等它自己干。

---
### 1-3. 酒精的种类
| 种类 | 消毒效果 | 能否制作 | 毒性 |
| --- | --- | --- | --- |
| 乙醇 | 强 | 可通过发酵和蒸馏制得 | 相对较低 |
| 异丙醇 | 强 | 无法通过发酵制得 | 口服毒性比乙醇大 |
| 甲醇 | 能消毒，但不能使用 | 作为副产物混入 | 导致失明和死亡 |

&nbsp;&nbsp;&nbsp;甲醇会经皮肤吸收，仅吸入蒸气也可能中毒，因此禁止用作消毒剂。通过发酵和蒸馏制作酒精时，真正要处理的问题不是如何得到乙醇，而是如何把甲醇分离出来丢掉。

## 2. 发酵：原料与酒精度的极限
&nbsp;&nbsp;&nbsp;制造乙醇的是酵母。在没有氧气的条件下，酵母吃糖，释放出乙醇和二氧化碳。人要做的是给酵母提供糖和合适的温度，并防止杂菌。

---
### 2-1. 酒精度的天花板
&nbsp;&nbsp;&nbsp;乙醇对酵母自身也是毒物。它扰乱细胞膜的脂质、妨碍酶，所以发酵液的酒精浓度上升后，酵母的活动会变慢直至停止。普通酿酒酵母大致在12-15%、耐酒精能力强的菌株在18%左右达到极限。

> **仅靠发酵无法达到消毒所需的浓度。** 发酵的上限大约是12-18%，消毒的下限是60%。中间这段一定要靠浓缩来补上。

&nbsp;&nbsp;&nbsp;多加糖也不会提高酒精度。酵母会先停下来，超过极限的糖以甜味留下，剩下的糖成为杂菌的食物，使发酵液变质。糖只加酵母能吃完的量。

---
### 2-2. 原料
&nbsp;&nbsp;&nbsp;酵母只吃单糖和双糖。像淀粉这样以长链连接的糖要先切断，这个过程就是糖化。

| 原料 | 是否需要糖化 | 特点 |
| --- | --- | --- |
| 水果（葡萄、苹果、柿子、梨） | 不需要 | 果皮上有野生酵母，有时会自行发酵 |
| 蜂蜜 | 不需要 | 必须用水稀释。原液浓度太高，酵母无法生存 |
| 树液（枫、桦）、甘蔗 | 不需要 | 糖浓度低，产量低 |
| 谷物（大米、大麦、小麦、玉米） | 需要 | 须把淀粉切成糖 |
| 土豆、红薯 | 需要 | 淀粉含量高，产量好 |
| 橡子、葛根等野生淀粉 | 需要 | 须先泡掉涩味成分 |

&nbsp;&nbsp;&nbsp;糖化的工具是麦芽和酒曲（nuruk）。

- 麦芽：让大麦发芽后晒干。利用种子发芽时自身产生的淀粉酶。
- 酒曲：让霉菌在谷物上繁殖而成。霉菌分泌的酶分解淀粉。其中也含有酵母，所以糖化和发酵同时进行。

| 阶段 | 条件 | 原因 |
| --- | --- | --- |
| 糊化 | 把谷物与水一起充分煮成糊状 | 淀粉颗粒要吸水松开，酶才能接触到 |
| 糖化 | 60-65℃下一到两个小时 | 淀粉酶工作效果最好的温度区间 |
| 冷却 | 冷却到20-30℃ | 趁热加入酵母，酵母会死 |
| 发酵 | 20-30℃，隔绝空气 | 有氧气时，生成的是醋酸而不是酒精 |

&nbsp;&nbsp;&nbsp;酶是蛋白质，所以温度低时反应慢，超过75℃就会变性而停止工作。

---
### 2-3. 发酵失败的原因
&nbsp;&nbsp;&nbsp;失败大多是杂菌污染。最常见的醋酸菌在有氧时吃掉乙醇，把它变成乙酸。辛辛苦苦做出的酒精变成了醋。

| 问题 | 原因 | 结果 |
| --- | --- | --- |
| 有醋味 | 醋酸菌、接触空气 | 酒精转化为乙酸 |
| 发酵没有开始 | 温度低或酵母死亡 | 糖原样留下并腐败 |
| 发酵中途停止 | 温度骤变、营养不足、达到酒精极限 | 带着剩余的糖结束 |
| 腐臭味 | 腐败菌污染 | 废弃 |
| 霉膜 | 产膜酵母、接触空气 | 即使撇掉，风味和产量也会下降 |

- 发酵容器需要的不是完全密闭，而是只朝一个方向敞开的通路。发酵时会不断释放二氧化碳，完全堵住会因压力升高而使容器爆裂，敞开则会让氧气和醋酸菌进入。把管子插进盛水的碗里，让气泡只出不进。
- 消毒用的不必在意味道和香气，所以管理很简单。但不要用被污染的水或腐烂的原料开始。发酵不会杀死微生物，原料中的许多病原体在蒸馏前都活着。

## 3. 浓缩：蒸馏、冷冻、吸湿剂
&nbsp;&nbsp;&nbsp;要把发酵液的12-18%提高到消毒所需的60%以上，就要去除水。方法有三种，物理原理和残留的杂质各不相同。这个差别决定了安全。

---
### 3-1. 蒸馏
| 物质 | 1个大气压下的沸点 |
| --- | --- |
| 甲醇 | 约64.7℃ |
| 乙醇 | 约78.3℃ |
| 水 | 约100℃ |

&nbsp;&nbsp;&nbsp;加热混合液体时，沸点低的一方更多地进入蒸气。把蒸气收集起来冷却，就能得到比原来酒精更浓的液体。并不是在78.3℃只出乙醇、在100℃只出水。混合状态下，两者会在中间温度一起蒸发，温度越高，蒸气中水的比例越大。蒸馏不是完全分离，而是比例的转移。

> **乙醇和水在约95.6%时形成共沸混合物。** 在这个浓度下，蒸气的组成与液体相同，所以无论蒸馏多少次，都不会再往上升。

- 用简单的装置蒸馏一次，根据原液浓度得到40-60%，再蒸馏一次会再高一点。70%通常需要蒸馏两三次，每蒸馏一次体积都会大幅减少。

| 装置部分 | 作用 | 决定性能的因素 |
| --- | --- | --- |
| 加热部分 | 加热发酵液产生蒸气 | 把温度缓慢保持在78-90℃之间的能力 |
| 蒸气管 | 把蒸气送到冷凝部分 | 长度和坡度。越长，较重的成分越会在途中回落 |
| 冷凝部分 | 把蒸气冷却回液体 | 冷却面积、温差、蒸气停留的时间 |

- 冷凝效率低，酒精蒸气来不及变成液体就逃逸，造成损失，还会在周围积聚易燃蒸气。把管子泡在冷水中，或在管子外面淋冷水来冷却。让冷却水沿着与蒸气前进方向相反的方向流动，全程都能保持温差，效率会大幅提高。

> **注意：**蒸馏装置的任何地方都不要完全密封。蒸气出口被堵住，内部压力会急剧升高，装置爆裂，热酒精会洒到火上。蒸气管弯折导致液体积存、冷凝部分堵塞、接缝封得太紧，也会造成同样的事故。蒸气必须始终有出路。

- 乙醇闪点低，温度只比常温高一点就会起火。蒸气比空气重，会沿着地面流动，遇到远处的火星而引燃。
- 避免明火加热，改用隔水加热。在室外或通风充分的地方进行，并让火与装置之间保持距离。

---
### 3-2. 冷冻浓缩
&nbsp;&nbsp;&nbsp;水在0℃结冰，而乙醇要在低得多的温度才结冰。把发酵液冻起来，水会先变成冰，把这些冰捞出去，剩下液体的浓度就升高了。既不需要火，也不需要装置。

> **注意：**蒸馏按沸点把成分分开，而冷冻只是把水取出，什么也分不开。甲醇和杂醇油不会随水结冰，而是和乙醇一起留下，原样被浓缩。

- 冷冻浓缩会把杂质也一起浓缩。蒸馏时丢弃酒头可以去掉相当一部分甲醇，但冷冻时没有可丢弃的区段。只有在确定只用于消毒、绝不饮用的前提下才考虑。
- 浓度越高，冰点越低，需要更低的温度。在现实的自然低温下，很难超过30%左右，达不到消毒所需的浓度。

---
### 3-3. 吸湿剂
&nbsp;&nbsp;&nbsp;由于共沸，蒸馏最高只能到95.6%，但如果用化学方法把水抓住，就能再往上提。灾难情况下现实可行的吸湿剂是生石灰。生石灰与水反应变成熟石灰，抓住水，而且不与乙醇反应。

| 方法 | 达到的浓度 | 性质 |
| --- | --- | --- |
| 单次简单蒸馏 | 40-60% | 装置简单，可以丢弃酒头 |
| 反复蒸馏 | 70-90% | 体积损失大，耗费燃料多 |
| 冷冻浓缩 | 30%左右 | 杂质也一起浓缩，饮用时尤其危险 |
| 吸湿剂处理 | 95%以上 | 能超过共沸点，但有污染材料的风险 |

&nbsp;&nbsp;&nbsp;出于消毒目的，几乎没有理由超过共沸点。消毒用70%最合适，95%反而更弱。用吸湿剂浓缩对需要燃料或无水溶剂的用途才有意义，灾难情况下通常用不到。

## 4. 酒头与甲醇、酒精度确认、用途
&nbsp;&nbsp;&nbsp;蒸馏液从头到尾并不是同一种物质。沸点不同的化合物按顺序流出，所以成分随接取液体的时间大不相同。区分这些区段并丢弃前面的部分，是蒸馏中最重要的工序。

---
### 4-1. 酒头必须丢弃的原因
| 区段 | 主要成分 | 处理 |
| --- | --- | --- |
| 酒头 | 丙酮、乙醛、乙酸乙酯、甲醇 | 全部废弃 |
| 酒心 | 以乙醇为主 | 接取使用 |
| 酒尾 | 杂醇油（高级醇）、水 | 毒性低，但会引起头痛，浓度也下降 |

- 甲醇的来源：植物细胞壁中的果胶被酶分解时，会释放出甲醇。富含果胶的原料，尤其是水果的皮和籽、苹果和李子之类的核果，会产生很多，谷物发酵相对较少。把皮和籽一起发酵，风险会增大。
- 毒性机制：甲醇本身毒性不太强。肝脏中的酶把甲醇变成甲醛，再变成甲酸，这种甲酸使细胞的能量生产陷于瘫痪、破坏视神经，并使血液酸化。

> **注意：**甲醇在味道和气味上都无法与乙醇区分。刚喝下去时没有异常，12-24小时后视线开始模糊，到那时已经无法逆转。10毫升就可能失明，30毫升就可能死亡。

- 同时喝乙醇，潜伏期会更长。这是因为肝脏的酶先处理乙醇，使甲醇的分解被推迟。群体性甲醇中毒事件就是按这种机制反复发生的，治疗需要解毒剂和血液透析，而这在灾难情况下是无法获得的治疗。
- 丢弃的量要保守估计。没有精确的计量设备时，比觉得可惜的量多丢一些，是唯一安全的判断。
- 丢弃的酒头标明为燃料或清洗用，另外保管，不要放进食用容器。

---
### 4-2. 酒精度确认
&nbsp;&nbsp;&nbsp;不到60%就无法作为消毒剂依赖，所以要确认所制酒精的浓度。

| 方法 | 原理 | 准确度 |
| --- | --- | --- |
| 酒精比重计 | 乙醇比水轻，通过密度读出浓度 | 最准确。需要温度校正 |
| 测量体积和重量 | 与等体积的水比较重量 | 秤足够精密时可用 |
| 泡沫持续时间 | 根据摇晃后泡沫保留的时间估计 | 依赖经验的粗略估计 |
| 勺子燃烧试验 | 根据能否点着来判断 | 不准确，且危险 |

- 燃烧试验不适合用来判定消毒浓度。酒精大约从50%左右开始能点着，但随温度、容器、火焰条件变化很大。点着只意味着超过了50%，并不能证明已经达到消毒所需的60-70%。酒精的火焰在明亮处几乎看不见，容易造成烧伤和火灾。
- 比重计假定液体只由乙醇和水组成。如果残留糖分或其他溶质，会增加重量，读出的酒精度会比实际偏低。不要直接用在发酵液上，要用在蒸馏结束后的液体上。

---
### 4-3. 消毒以外的用途与法律问题
| 用途 | 内容 |
| --- | --- |
| 消毒 | 调到60-90%，用于手、工具和表面 |
| 燃料 | 用于酒精炉。几乎没有烟灰 |
| 萃取溶剂 | 制作提取草药有效成分的酊剂 |
| 保存 | 保存标本、种子表面消毒等 |
| 清洗 | 溶解油污和树脂 |

- 用作萃取溶剂时，要求与消毒相反。易溶于水的成分适合低酒精度，接近油脂的成分适合高酒精度。燃料则水越少火力越好，所以酒精度越高越有利。

> **注意：**在包括韩国在内的大多数国家，未经许可制造酒类，尤其是制造蒸馏酒，是违法的。用于消毒并不会自动成为例外，销售或转让还会被更严厉地处理。本文是以物流中断、无法获得药品和燃料的情况为前提对原理的整理，不是平时可以应用的知识。

&nbsp;&nbsp;&nbsp;无法通过测量确认该丢弃多少酒头，无法凭感官知道是否残留甲醇，中毒了也没有解毒的手段。用这种方法制成的液体只用于消毒和燃料，不要饮用。这首先是概率问题，其次才是法律问题。
