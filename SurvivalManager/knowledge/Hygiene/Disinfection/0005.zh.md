## 4. 天然材料消毒与按对象应用
&nbsp;&nbsp;&nbsp;没有工业品消毒剂也能消毒。大多依靠强碱和低水分活度这两个原理。要知道每一种管用到哪里、在哪里止步，才能避免错误的安心。

---
### 4-1. 草木灰水
&nbsp;&nbsp;&nbsp;往烧阔叶树得到的灰里倒水浸泡，会得到以碳酸钾为主要成分的溶液。pH一般是11-12，这种碱同时做三件事。分解微生物细胞膜的脂质，使蛋白质变性，并使表面的油垢皂化而被冲走。优点是清洗和消毒一次完成。

| 项目 | 内容 |
| --- | --- |
| 原料 | 阔叶树灰的钾含量比针叶树灰高，所以合适 |
| 提取 | 往灰里倒水，沉淀后倒出上面的清液使用 |
| 判断浓度 | 把羽毛浸进去，几十秒内末端变软，说明浓度足够 |
| 适合的用途 | 餐具、炊具、洗衣、地面、手（稀释得淡一些） |
| 局限 | 对芽孢弱，浓度高会损伤皮肤和金属 |

- 一定要冲洗。残留的碱会刺激皮肤，接着用氯消毒时，还会降低氯的效果。
- 灰中的细小颗粒起的是研磨作用，而不是消毒。洗手时用灰代替肥皂，更接近靠摩擦洗掉，而不是化学消毒。即便如此，也比只用水好。

---
### 4-2. 生石灰与熟石灰
&nbsp;&nbsp;&nbsp;把石灰石或贝壳在900℃以上烧制，二氧化碳逸出，剩下氧化钙（生石灰）。往生石灰上浇水会放出大量热，变成氢氧化钙（熟石灰），这种溶液的pH超过12。用于粪便、尸体、畜舍这类有机物多、难以用氯处理的对象。

&nbsp;&nbsp;&nbsp;氯会被有机物消耗而消失，但碱不会被消耗，而是把环境本身的pH提高并维持住。往粪坑里撒石灰，pH保持在高位，病原体无法存活，臭味和苍蝇也会减少。

| 用途 | 方式 | 注意 |
| --- | --- | --- |
| 粪坑 | 薄薄地撒在排泄物上盖住 | 用太多会连分解菌也杀死，稳定化变慢 |
| 畜舍、地面 | 把熟石灰调成水浆涂抹或喷洒 | 防止干粉飞扬进入眼睛和呼吸道 |
| 被水淹过的泥土地面 | 撒上后翻耕 | 作业时需要手套和护目 |
| 尸体周围 | 掩埋时一起放入 | 不能阻止腐败。目的是消毒和抑制臭味 |

> **注意：** 生石灰遇水会放热。沾到湿的皮肤或眼睛，会同时发生碱烧伤和热烧伤，即使冲洗掉，损伤也会继续发展。

&nbsp;&nbsp;&nbsp;生石灰要干燥保存。调水时，不要往生石灰上倒水，而要把生石灰一点点放进水里。不遵守顺序，会因急剧发热而沸腾飞溅。这与“肥皂”文档中处理强碱的原则相同。

### 4-3. 盐、醋、木炭
| 材料 | 实际作用 | 误解 |
| --- | --- | --- |
| 盐 | 靠渗透压降低水分活度，阻止增殖 | 是阻止而不是杀死，溶于水后微生物会复活 |
| 醋 | 靠酸性抑制或杀灭部分微生物 | 必须接近原液使用，对芽孢和很多细菌效果弱 |
| 木炭 | 吸附气味、部分溶解物质和余氯 | 无法滤除微生物，反而可能在表面繁殖 |

&nbsp;&nbsp;&nbsp;木炭不是消毒剂而是吸附剂。它改善水的味道和气味，让人产生已经干净的错觉，但细菌和病毒依然存在。湿木炭的多孔表面很适合细菌生长，所以长期使用的木炭过滤层反而可能成为污染源。木炭只用在消毒后调整味道的最后一步，不要让它代替消毒。

### 4-4. 按对象消毒
| 对象 | 优先方法 | 替代方法 | 应避免的 |
| --- | --- | --- | --- |
| 饮用水 | 煮沸1分钟（高海拔3分钟） | 氯2mg/L 30分钟，晴天日光消毒6小时 | 只过一遍木炭就喝、浑浊水的日光消毒 |
| 炊具、餐具 | 清洗后用沸水 | 用草木灰水清洗后冲洗并晒干 | 不洗就只喷消毒液 |
| 伤口 | 用干净的水充分冲洗 | 煮沸后放凉的水，消毒剂只用在周围皮肤 | 在伤口里反复使用过氧化氢、酒精 |
| 手 | 肥皂和流水，摩擦 | 用灰、沙子搓洗后冲洗，70%酒精 | 只用水草草冲一下 |
| 衣物、寝具 | 60度以上洗涤或煮沸 | 洗涤后完全晒干 | 没干透就叠起来放着 |
| 厕所、粪便 | 用石灰或灰覆盖 | 0.5%氯 | 只往有机物上喷稀氯溶液 |
| 表面、地面 | 清洗后用0.05-0.2%氯 | 草木灰水、肥皂水 | 把漂白剂与其他洗涤剂混用或接连使用 |
| 处理尸体 | 阻断接触并洗手 | 石灰、0.5%氯 | 仓促焚烧或省略身份确认 |

- 几乎在所有情况下，都是先清洗、后消毒。
- 消毒不能代替隔离和阻断。如“污物处置”文档所述，先建立第一道屏障，消毒则是减少漏过屏障之物的第二手段。资源越匮乏，这个顺序越决定结果。
