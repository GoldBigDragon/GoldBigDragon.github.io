## 4. 換気と除湿
&nbsp;&nbsp;&nbsp;これまでのすべての章が1つの結論へと向かいます。カビを防ぐ取り組みは、結局のところ**「水分をどこへ排出・移動させるか」**の問題です。電気で作動する除湿機や送風機が存在しない状況下で利用できる力は、空気の流れ、温度差、그리고水分を結合・吸着する物質の3つのみです。

---
### 4-1. 対立通風（対向換気）
&nbsp;&nbsp;&nbsp;窓を1箇所のみ開放することと、向き合う2箇所を開放することでは極めて大きな効果の差が生じます。空気は流入した量と同量しか排出できないため、**出口が存在しなければ入口も機能しません。** 窓を1箇所のみ開けた場合、その窓の周辺の空気のみがわずかに移動するのみで、部屋の奥の空気はほぼ停滞したまま残留します。

| 設置・開放条件 | 流動効果・現象 |
| --- | --- |
| 片側の窓のみ開放 | 窓際周辺のみ空気交換され、室内空気の大半は停滞 |
| 向き合う2箇所を開放 | 部屋を貫通する気流が形成され、空間全体の空気が入れ替わる |
| 入口を狭く、出口を広く | 流入風速が上昇し、部屋の隅々まで風が到達 |
| 高低差を設置 | 暖気が上方へ抜け、下方から冷気を引き込む（煙突効果） |

&nbsp;&nbsp;&nbsp;高低差を設置する手法は、燃料を一切消費せずに利用できる最も強力な手段です。暖められた空気は比重が軽いため上方へ浮上し、高所に出口が存在すれば自然に排出され、それと同時に低所の入口から外部の空気を吸引します。風が全く存在しない無風の日であっても、内外温度差が存在する限りこの気流は発生します。したがって換気口は**「低所と高所に1箇所ずつ」**配置することが原則となります。

&nbsp;&nbsp;&nbsp;冬季の換気に関する代表的な誤解も整理しておく必要があります。冷気は保持できる水蒸気量（飽和水蒸気量）自体が小さいため、外気が湿っているように見えても、その絶対水蒸気量は室内よりも大幅に小さくなります。この外気が室内で加温されると相対湿度が大幅に低下するため、**寒冷な日の換気はむしろ室内を乾燥させます。** 逆に初夏の多湿な日の換気は湿気を流入させるため、雨の日に地下室の窓を開放する行為は逆効果となります。

---
### 4-2. 結露
&nbsp;&nbsp;&nbsp;空気に含まれ得る水蒸気量は、気温が低下するほど減少します。空気が冷却され水蒸気を保持できなくなる温度を露点（露点温度）と呼び、**露点よりも低い表面に接触すると gardens その場で水分が凝結・付着します。** 結露は単なる湿度の問題ではなく、湿度と表面温度が交差する物理的ポイントの問題です。

&nbsp;&nbsp;&nbsp;そのため、結露とカビはその空間の中で**「最も冷たい表面」**から必ず発生を開始します。

| 発生しやすい部位 | 発生理由・メカニズム |
| --- | --- |
| 北側の外壁、隅角部（コーナー） | 日照が得られず2面へ熱が逃げるため最も冷え込む |
| 窓枠・サッシおよびガラス面 | 断熱性能が最も脆弱な部位であるため |
| 家具と壁の隙間 | 空気循環が遮断され壁面温度がさらに低下するため |
| 壁と床が接する巾木ライン | 地盤からの冷気と湿気が上昇して伝わるため |
| 壁付けクローゼット内部 | 密閉され空気交換が存在しないため |

&nbsp;&nbsp;&nbsp;極めて単純でありながら絶大な効果を発揮する処置が**「家具を壁から5〜10cm離して設置すること」**です。壁と家具の間に空気の流れが生まれると、壁面温度が周囲の空気温度に近づき露点以下へ低下しなくなります。クローゼットの扉を定期的に開放しておくことや、布団を床に敷きっぱなしにせず畳んで上げおくことも同一の物理原理に基づきます。

---
### 4-3. 自然材料を利用した除湿
&nbsp;&nbsp;&nbsp;空気中の水分を捕集する物理化学的アプローチは2つに大別されます。水分と化学反応を起こして**不可逆的**に結合・捕集する手法と、表面へ物理的に**吸着**させておき乾燥させることで再利用する手法です。

| 材料 | 作用メカニズム | おおよその除湿容量 | 物理化学的性質 |
| --- | --- | --- | --- |
| 生石灰（酸化カルシウム） | 化学反応により消石灰へ変化 | 自重の約3分の1まで | 不可逆的。発熱反応を伴い失明・火傷危険あり |
| 塩化カルシウム | 潮解性により吸湿し液化 | 自重以上 | 漏出・流出した液体が金属や布を著しく損傷 |
| 木炭・竹炭 | 多孔質表面への物理吸着 | 自重の数%程度 | 日光乾燥で反復再利用可能。消臭効果も発揮 |
| 木灰（草木灰） | 吸湿 | 低い | どこでも入手可能。穀物保存へ併用 |
| 食塩 | 吸湿 | 低い | 相対湿度が高い環境でのみ作動する補助手段 |
| 乾燥米・乾燥豆 | 吸湿 | 低い | 小物の乾燥に使用。使用後の食用は回避 |

&nbsp;&nbsp;&nbsp;生石灰は自然材料の中で最も強力な吸湿力を持ちます。石灰石や貝殻を高熱で焼成して製造され、水と接触すると激しい反応熱を発して消石灰へ変化します。この化学反応は不可逆的であるため一回使い切りとなり、**反応熱と強アルカリ性のため皮膚や眼粘膜へ深刻な化学火傷を引き起こします。** 麻袋や蓋付き容器に納め、人間が直接触れないよう配置しなければなりません。使用済みの消石灰は廃棄せず、便所や畜舎の消毒へ転用することが可能です。

&nbsp;&nbsp;&nbsp;木炭は除湿性能自体は穏やかですが、災害状況下において最も実用的です。化学反応ではなく表面吸着であるため、飽和状態に達しても日光下で乾燥させれば何度でも再生利用が可能であり、接触しても危険性がなく、同一の材料を水ろ過や消臭にも流用できます。クローゼット、書棚、穀物袋の脇に木炭を詰めた袋を配置し、**天候の良い日ごとに取り出して日干し乾燥させること**が、電力なしで維持可能な除湿サイクルとなります。

### 4-4. 穀物・種子・衣類・書籍の保管
&nbsp;&nbsp;&nbsp;保管作業は、これまでのすべての原理が集約される実践領域です。共通する鉄則はただ1つ、**「完全に乾燥させた後に密閉し、未乾燥의 ものは絶対に密閉しないこと」**です。乾燥が不十分な物品を密閉すると、閉じ込められた水分が内部で循環しカビの爆発的繁殖を誘導します。

| 対象物品 | 管理の要点・鉄則 | 失敗・カビ発生の原因 |
| --- | --- | --- |
| 穀物・種子 | 水分含有率13%以下まで乾燥後密閉。木炭や灰を同封 | 高温のまま密閉し冷却プロセスで容器内部に結露が発生 |
| 衣類・寝具 | 完全乾燥後に保管。通気性を確保し床直置きを回避 | 折りたたみ部や縫い目内部が未乾燥のまま収納 |
| 書籍・紙類 | 立てて配置しページ間に空気が通るよう壁から離す | 平積みにすると下部が圧迫され乾燥が阻害される |
| 種子（種） | 低温・低湿・暗所。紙袋に収納後密閉容器へ | ビニール袋へ直接収納し内部に水滴が凝結する |
| 皮革・木製品 | 通気性を維持し直射日光を回避 | 完全密閉により表面へカビが繁殖・浸透する |

&nbsp;&nbsp;&nbsp;最後に、保管品は**「定期的に取り出して目視・確認すること」**が必須です。カビは目視できるようになるまでに数日を要し、カビ臭が先行して発生します。晴天の日ごとに袋を開けて匂いを確認し、手を差し入れて発熱や湿り気が存在しないか点検し、日干しした木炭を戻す作業が最も低コストな点検手順となります。カビ対策における決定的な失敗とは、常に**「点検を行わずに冬や梅雨を過ごすこと」**です。
