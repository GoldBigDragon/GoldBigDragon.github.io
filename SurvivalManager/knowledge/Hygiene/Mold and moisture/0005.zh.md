## 4. 通风与除湿
&nbsp;&nbsp;&nbsp;防止霉菌，是把水送往哪里的问题。没有电动除湿机和鼓风机时，能用的力量有三种：空气的流动、温差、能抓住水的物质。

---
### 4-1. 对流通风
&nbsp;&nbsp;&nbsp;空气只能出去与进来一样多，所以没有出口，入口也不起作用。只开一扇窗，只有那扇窗周围的空气稍微进出一点，房间里面的空气几乎原封不动。

| 条件 | 效果 |
| --- | --- |
| 只开一侧的窗 | 只有窗边周围得到置换，室内空气几乎停滞 |
| 打开相对的两处 | 形成贯穿房间的气流，整体空气得到置换 |
| 缩小入口、放大出口 | 进入的流速提高，风能到达角落 |
| 设置高度差 | 暖空气向上排出，向下吸入冷空气 |

- 高度差是无需燃料就能使用的最强手段。暖空气上升，高处有出口的话会自行排出，同时通过低处的入口吸入外面的空气。没有风的日子，只要有室内外温差也会发生。通风口低处和高处各设一个。
- 冬季通风：冷空气能容纳的水蒸气量本身就少，外面的空气看起来潮湿，绝对水蒸气量也比室内少得多。这种空气在室内被加热后相对湿度会大幅下降，所以寒冷日子的通风会使室内变干燥。
- 盛夏潮湿日子的通风可能把湿气带进来。下雨天打开地下室的窗没有帮助。

---
### 4-2. 结露
&nbsp;&nbsp;&nbsp;空气能容纳的水蒸气量随温度降低而减少。空气冷却到再也容纳不了水蒸气的温度就是露点，接触到比露点更冷的表面时，水会当场凝结。结露是湿度与表面温度交汇之处的问题。结露和霉菌总是从该空间最冷的表面开始。

| 常发生的位置 | 理由 |
| --- | --- |
| 北侧外墙、墙角 | 照不到阳光，热量从两个面散失，最冷 |
| 窗框和玻璃 | 隔热最弱的位置 |
| 家具与墙之间 | 空气不流通，墙面温度进一步下降 |
| 墙与地面相接的线 | 地面的冷气和湿气上升 |
| 嵌入式衣柜内侧 | 封闭，没有空气交换 |

&nbsp;&nbsp;&nbsp;把家具离墙5-10cm，虽然简单但效果很大。墙与家具之间有空气流动，墙面温度就接近周围空气的温度，不会降到露点以下。偶尔打开衣柜门，被子不一直铺在地上而是收起来，也是同样的原理。

---
### 4-3. 利用天然材料除湿
&nbsp;&nbsp;&nbsp;抓住空气中水分的方式有两种。与水发生化学反应、不可逆地抓住的，以及物理吸附在表面、晾干后可再次使用的。

| 材料 | 方式 | 大致容量 | 性质 |
| --- | --- | --- | --- |
| 生石灰（氧化钙） | 经化学反应变成熟石灰 | 最多约自身重量的三分之一 | 不可逆。反应时放热，有烧伤危险 |
| 氯化钙 | 靠潮解性吸收而变成液体 | 自身重量以上 | 流下的液体会损坏金属和布 |
| 木炭 | 物理吸附在多孔表面 | 约为重量的百分之几 | 晒干后可反复使用，还能吸附异味 |
| 草木灰 | 吸湿 | 低 | 到处都能得到，储存谷物时一起使用 |
| 盐 | 吸湿 | 低 | 只在相对湿度高时起作用的辅助手段 |
| 干米、干豆 | 吸湿 | 低 | 用于晾干少量物品，之后避免食用 |

- 生石灰：天然材料中最强。把石灰石或贝壳用高温烧制而成，遇水放热变成熟石灰。这个反应不可逆，用一次就结束，反应热和强碱会使皮肤和眼睛受到严重烧伤。装在袋子或有盖的容器里，不让人直接触摸。用完的熟石灰不要扔掉，可以转用于厕所和畜舍消毒。
- 木炭：性能弱，但在灾难情况下最实用。是表面吸附而不是化学反应，所以饱和后可以晒干，反复使用很多次，摸了也不危险，还可用于水过滤和除臭。在衣柜、书架、谷物袋旁边放装炭的袋子，天气好的日子拿出来晒干，是不用电也能维持的除湿循环。

---
### 4-4. 谷物、种子、衣物、书的保管
&nbsp;&nbsp;&nbsp;共同原则只有一个。完全晾干后再密封，没能晾干就不要密封。把没干透的东西密封，困住的湿气会在里面循环并滋养霉菌。

| 对象 | 要点 | 失败的原因 |
| --- | --- | --- |
| 谷物、种子 | 晾到水分13%以下再密封。同时放入木炭或灰 | 趁热密封，冷却时里面结露 |
| 衣物、被子 | 完全干燥后保管，但留出通风。不要直接接触地面 | 折叠处和缝线内侧没干透就叠起来 |
| 书、纸 | 立着放，让书页之间通风。离墙放置 | 平放堆叠，下面被压住而干不了 |
| 种子 | 低温、低湿、暗处。装在纸袋里放进密封容器 | 直接装进塑料袋，里面凝出水珠 |
| 皮革、木材 | 保持通风，避免阳光直射 | 完全密封，霉菌在表面蔓延 |

&nbsp;&nbsp;&nbsp;保管的东西要定期拿出来看。霉菌要几天才会肉眼可见，气味会先出现。每个晴天打开袋子闻一闻，把手伸进去确认有没有暖意或潮湿，把炭晒干再放回去，是最廉价的检查。应对霉菌的失误，总是没有检查就过冬。
