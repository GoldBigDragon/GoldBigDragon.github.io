## 4. 通风与除湿
&nbsp;&nbsp;&nbsp;前面所有章节均指向同一个核心结论：阻止霉菌滋生，归根结底是**“将水分排放与引导至何处”**的问题。在缺乏电力驱动的除湿机与送风机的前提下，能够利用的力量唯有空气对流、温差，以及能够锁住水分的物质这三种。

---
### 4-1. 对流通风 (穿堂风)
&nbsp;&nbsp;&nbsp;仅打开一扇窗户与打开两扇相对的窗户，在物理效果上存在着天壤之别。空气遵循“流入多少才能排出多少”的流体力学原理，**若没有出口，入口也无法发挥作用。** 仅打开单侧窗户，仅能使窗户周边的空气发生微弱对流，房间深处的空气则几乎原封不动滞留原地。

| 开启条件 | 物理流体效果 |
| --- | --- |
| 仅开启单侧窗户 | 仅窗边区域发生局部交换，室内空气大体处于停滞状态 |
| 开启相对的两侧窗户 | 形成贯穿房间的强劲气流，实现整座空间的气体置换 |
| 缩小入口、扩大出口 | 提升进风流速，使风力能够直达房间死角 |
| 制造高低落差 | 暖空气向上排出，顺势将下方冷空气吸入 (烟囱效应) |

&nbsp;&nbsp;&nbsp;制造高低落差是无需消耗任何燃料即可使用的最为强效的通风手段。受热膨胀的暖空气比重变轻因而向上浮升，若高处设有出口，暖空气便会自然排出，同时顺势从低处入口将室外冷空气吸入室内。即便是毫无风力的无风之日，只要室内外存在温差，这一气流就会持续发生。因此，通风口配置的基本原则是**“高处与低处各设一处”**。

&nbsp;&nbsp;&nbsp;对于冬季通风的普遍误解也有必要予以厘清。冷空气能够包含的水蒸气总量 (绝对湿度) 本身极低，因而即便是室外看起来十分潮湿，其绝对含水量也远低于室内空气。当这一冷空气进入室内被加温后，其相对湿度会剧烈下降，因而**寒冷天气的开窗通风反而会让室内变得更为干燥。** 相反，盛夏闷热潮湿天气的通风则会引入大量湿气，因而在阴雨天打开地下室窗户不仅毫无帮助，反而会加剧潮湿。

---
### 4-2. 凝结水 (结露)
&nbsp;&nbsp;&nbsp;空气所能包含的水蒸气上限随着温度降低而锐减。当特定空气冷却至无法继续容纳水蒸气的临界温度被称为露点 (露点温度)，**一旦接触到低于露点的物体表面，水蒸气便会瞬间凝结成水滴。** 结露绝非单纯的湿度问题，而是湿度与物体表面温度相交交汇的物理问题。

&nbsp;&nbsp;&nbsp;正因如此，结露与霉菌永远始于该空间内**“温度最低的表面”**。

| 高发部位 | 物理成因与机制 |
| --- | --- |
| 朝北外墙、墙角拐角 | 缺乏阳光照射且向两个方向散热，因而温度最低 |
| 窗框与玻璃 | 属于保温隔热性能最为脆弱的物理薄弱点 |
| 家具与墙壁之间的缝隙 | 空气无法对流循环，导致墙面温度进一步剧降 |
| 墙壁与地面交接的踢脚线 | 地面的冷气与湿气沿此向上传导 |
| 壁橱/嵌入式衣柜内部 | 处于封闭状态，缺乏任何气体交换 |

&nbsp;&nbsp;&nbsp;一项极其简单却具备绝佳效果的措施是**“将家具搬离墙面 5-10 厘米”**。让空气能够在墙壁与家具之间自由流动，可使墙面温度接近环境空气温度，从而避免其跌落至露点温度以下。定期打开衣柜门通风、以及不将被褥长期平铺在地面上而是收起叠放，均基于完全相同的物理原理。

### 4-3. 利用自然材料进行除湿
&nbsp;&nbsp;&nbsp;捕获空气中水分的物理化学途径分为两条：通过与水发生化学反应实现**不可逆**锁水，以及在多孔表面实现物理**吸附**并可经晾干后重复循环使用。

| 材料 | 作用机制 | 大致吸湿容量 | 理化属性 |
| --- | --- | --- | --- |
| 生石灰 (氧化钙) | 化学反应转化为消石灰 | 可达自身重量的约 1/3 | 不可逆；剧烈放热，存在灼伤与失明风险 |
| 氯化钙 | 潮解吸湿并融化为液体 | 可达自身重量以上 | 漏出的液体具备强烈腐蚀性，损坏金属与织物 |
| 木炭 / 竹炭 | 多孔表面的物理吸附 | 自身重量的百分之几 | 可晒干重复循环使用；兼具吸附异味功能 |
| 草木灰 (木灰) | 吸湿 | 较低 | 易于就地取材；常与粮食储存混用 |
| 食盐 | 吸湿 | 较低 | 仅在极高相对湿度环境下生效的辅助手段 |
| 干燥大米 / 大豆 | 吸湿 | 较低 | 用于干燥微型物品；使用后切勿食用 |

&nbsp;&nbsp;&nbsp;生石灰是自然材料中吸湿能力最强的品类。通过高温煅烧石灰石或贝壳制得，遇水后会释放剧烈热量并转化为消石灰。由于该反应完全不可逆，属于一次性消耗品，且**反应热与强碱性会对皮肤和眼睛造成极其严重的化学灼伤。** 必须将其装入麻袋或有盖容器中，防止人体直接接触。使用过的消石灰切勿直接抛弃，可转用于厕所与畜舍的杀菌消毒。

&nbsp;&nbsp;&nbsp;木炭虽然除湿效能相对温和，却是灾难状况下最为实用的品类。由于其基于物理表面吸附而非化学反应，吸附饱和后只需置于阳光下曝晒即可无限次重复循环使用，直接接触毫无危险，且同一材料还可兼用于水质过滤与除臭。在衣柜、书架、粮袋旁摆放装有木炭的麻袋，并**在每个晴朗的日子里将其拿至户外晒干**，便构成了无需消耗电力的可持续除湿循环。

### 4-4. 粮食、种子、衣物与书籍的储存
&nbsp;&nbsp;&nbsp;储存是前面所有物理原理集大成汇聚的应用环节。通用核心铁律唯有一条：**“彻底晾干后方可密封，未干透者绝不可密封。”** 将未干透的物品强行密封，被困住的水分会在内部循环蔓延，剧烈催化霉菌的爆发。

| 储存对象 | 核心要点与铁律 | 失败与发霉原因 |
| --- | --- | --- |
| 粮食 / 种子 | 晾干至含水量 13% 以下后密封，同封木炭或草木灰 | 在尚存余温时密封，冷却过程中容器内壁结露 |
| 衣物 / 被褥 | 彻底晒干后存放并保留通气，避免直接接触地面 | 摺叠内部与缝隙深处未干透即折叠收纳 |
| 书籍 / 纸张 | 竖立摆放并使页码间通气，保持与墙壁的距离 | 平铺堆叠导致下层受压，湿气无法散发 |
| 种子 (种籽) | 低温、低湿、暗处；装入纸袋后再放入密封容器 | 直接装入塑料袋导致内部凝结水滴 |
| 皮革 / 木制品 | 保持通气对流，避免阳光直射 | 完全密闭导致霉菌在表面大面积滋生 |

&nbsp;&nbsp;&nbsp;最后，储存的物资**必须定期翻动检查**。霉菌从萌发到肉眼可见需要数日，而刺鼻的霉味则会率先散发。在每个晴朗的日子里打开粮袋闻一闻气味，将手伸入内部感知是否有发热或潮湿感，并将晒干的木炭重新放入，是最为低成本且高效的日常检查程序。在防霉应对中，最致命的错误永远是**“不加检查地盲目度过冬季或雨季”**。
