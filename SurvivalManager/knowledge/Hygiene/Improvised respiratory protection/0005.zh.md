## 4. 气体与烟雾，以及判断标准
&nbsp;&nbsp;&nbsp;以上均为关于颗粒物的内容。本章将讨论过滤在物理原理上失效的临界点——即“气体”。同时梳理在灾难中致死人数最多的呼吸危险——火灾烟雾，为何绝非可以通过佩戴口罩解决的问题。

---
### 4-1. 活性炭能捕获与无法捕获的物质
&nbsp;&nbsp;&nbsp;活性炭并非进行物理过滤，而是通过吸附来**捕获**气体分子。将木炭进行高温处理，使其内部形成无数微孔，表面积即可呈现极端膨胀，经过的气体分子便会粘附在这些表面上。

&nbsp;&nbsp;&nbsp;然而，并非所有气体都能被等同吸附。**分子越大、越重、沸点越高的物质**，越容易留存附着在表面；而微小、轻盈、沸点极低的气体分子即便粘附也会迅速脱附逸散。

| 类别 | 目标气体 | 原因与机制 |
| --- | --- | --- |
| 良好捕获 | 有机溶剂蒸气、苯、甲苯、恶臭物质、部分农药蒸气 | 分子较大且沸点较高 |
| 需特殊处理 | 氨气、氯气、二氧化硫、氰化氢 | 需添加化学试剂，通过化学反应进行捕获 |
| **无法捕获** | **一氧化碳**、甲烷、二氧化碳、氮气 | 分子微小、无极性且沸点极低 |

> **一氧化碳无法被活性炭过滤捕获。无论填充多厚重的木炭层，一氧化碳都会原封不动直接穿透。**

&nbsp;&nbsp;&nbsp;要消除一氧化碳，不能靠捕获，而必须将其**化学转化为其他无害物质（氧化）**。专业避难烟罩（防烟面罩）中含有可将一氧化碳氧化为二氧化碳的催化剂（如霍普卡莱特等），但此类催化剂极易受潮失活且存在保质期，根本无法在户内自制。在灾难状况下，应对一氧化碳的唯一方式并非过滤，而是**立刻彻底离开该空间**。

---
### 4-2. 穿透（破过 / ブレイクスルー）
&nbsp;&nbsp;&nbsp;活性炭所能吸附的气体总量是有限的。一旦吸附表面完全饱和，随后涌入的气体就会原封不动直接穿透，这一临界点被称为**穿透（破过）**。

| 影响因素 | 加速穿透的条件 |
| --- | --- |
| 浓度 | 气体浓度越高，饱和速度越快 |
| 呼吸量 | 呼吸越急促，单位时间内穿透流过的气体量越大 |
| 湿度 | 水蒸气会率先抢占吸附位点 |
| 温度 | 高温环境下已吸附的分子会脱附逸散 |
| 存放状态 | 仅拆封暴露于空气中，就会吸附空气中的物质而消耗寿命 |

&nbsp;&nbsp;&nbsp;最致命的危险在于**根本没有可靠的手段能提前感知穿透的发生**。当你再次闻到气味时，意味着气体早已穿透通过，这并非事前预警，而是事后通告。况且对于一氧化碳这类完全无味的气体，或致死浓度低于嗅觉阈值的物质，连这种事后通告都不复存在。

### 4-3. 火灾烟雾真正致人死亡的方式
&nbsp;&nbsp;&nbsp;火灾中的绝大多数遇难者并非被火烧死，而是因吸入浓烟而亡。然而，浓烟中致人死亡的毒性成分，绝非简易口罩能有哪怕一丝一毫阻挡作用的成分。

| 致死因素 | 对人体的生理作用机制 | 简易口罩的效果 |
| --- | --- | --- |
| 一氧化碳 | 与血红蛋白极强结合，阻断氧气输送 | 完全无效 |
| 氰化氢 | 直接麻痹细胞能量生产（线粒体） | 完全无效 |
| 缺氧 | 燃烧剧烈消耗氧气导致环境浓度骤降 | 完全无效 |
| 高温气体 | 导致呼吸道灼伤与水肿，引发气道阻塞 | 几乎无效 |
| 刺激性气体 | 氯化氢、丙烯醛等剧烈灼伤肿胀气道 | 几乎无效 |
| 积炭颗粒 (煤烟) | 气道刺激与沉着 | 局部有效 |

&nbsp;&nbsp;&nbsp;氰化氢（青酸气体）尤为需要高度警惕。它会在含氮物质燃烧时大量产生，而现代居住空间中充斥着此类材质。聚氨酯发泡保温材料与床垫、尼龙地毯与衣物、羊毛与丝织品均在此列。这与前文《废物处理》中阐明绝不可焚烧发泡塑料的原因完全一致。氰化氢与一氧化碳会协同产生加成毒性，使人以远快于单一气体时的速度丧失意识。

> **在火灾浓烟中致人死亡的绝非积炭颗粒（煤烟）。用布捂住口鼻阻挡肉眼可见的黑烟，只会让人在吸入致死无色无味毒气的同时产生“受到保护”的致命错觉。**

&nbsp;&nbsp;&nbsp;“低姿态弯腰逃生”的避险原则也必须准确理解。灼热的浓烟与煤烟会向上浮升，低姿态在维持视线与避开热气方面确实具备明确优势。然而一氧化碳的密度与空气极为接近，会均匀混合充满整个空间。**即使趴在地上也无法躲避一氧化碳。** 低姿态仅能为你争取极微小的撤离时间，而终点永远应当是“室外”。

---
### 4-4. 判断标准
&nbsp;&nbsp;&nbsp;最后，将截至目前的所有内容归纳总结为一份清晰的决策判断标准。

| 场景/状况 | 正确的决策与行动 |
| --- | --- |
| 火灾浓烟 | 立刻撤离。口罩仅为逃生过程中的微弱辅助，绝不能作为滞留或折返回现场的依据 |
| 密闭空间 | 绝不进入。先强制换气通风，对倒下的人员应在外部使用绳索拉出 |
| 有毒气体泄露 | 顺风/侧风向高处或上风向移动。若处于室内则关紧门窗并密封缝隙 |
| 坍塌粉尘 / 火山灰 | 物理过滤确实有效。密合度与多层布料具备实际防护意义 |
| 霉菌 / 粪便清理 | 开窗通风，先用水打湿表面，随后用布捂住口鼻防止颗粒散播吸入 |
| 传染病飞沫 | 物理过滤有效。密合度与佩戴时长决定防护性能 |

&nbsp;&nbsp;&nbsp;核心原则为：**“若危险源为‘颗粒物’，过滤有效；若为‘气体’或‘缺氧’，过滤完全无效。”** 在火灾浓烟或有毒气体泄露状况下，口罩绝不能成为决策依据；而在火山灰、清理作业或传染病飞沫状况下，佩戴口罩能够提供实质性的防护。

&nbsp;&nbsp;&nbsp;而在任何状况下，始终有两项行动优先于过滤：**“彻底离开该场所”与“强制对流换气”。** 口罩仅能让你稍微少吸入一点受污染的空气；换气能减少受污染空气本身的总量；而撤离则能完全避免吸入。一旦这一优先顺序发生颠倒，简易呼吸防护具就会从防护装备沦为让你在致命毒场中停留更久的催命符。
