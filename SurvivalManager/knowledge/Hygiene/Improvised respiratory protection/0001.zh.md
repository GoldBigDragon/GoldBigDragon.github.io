## 引言
&nbsp;&nbsp;&nbsp;口罩是过滤器，而不是盾牌。过滤器按大小筛选，所以对灰尘、灰烬、飞沫等颗粒有效，但对一氧化碳、氯气这类以分子状态与空气混合的气体无效。在缺氧的空间里，任何过滤装置都无法凭空造出氧气。

&nbsp;&nbsp;&nbsp;本文与其讲简易口罩的做法，不如讲过滤起作用的原理与局限。它解释了为什么0.3μm的颗粒最容易穿过、为什么贴合比滤材等级（KF94、KF80等）更重要、湿毛巾的作用范围，以及活性炭为什么抓不住一氧化碳。

> **原则：**离开与通风先于过滤。

---

## 1. 能挡住的与挡不住的
> **注意：**简易口罩对灰尘、灰烬、烟灰、飞沫等颗粒部分有效，但对一氧化碳、氯气、氨气、硫化氢等气体和蒸气实际上无能为力。在缺氧的空间里，任何口罩都没有用。

---
### 1-1. 危险类型
&nbsp;&nbsp;&nbsp;这三种危险的应对手段完全不同，所以要加以区分。

| 危险类型 | 例子 | 简易口罩 | 所需之物 |
| --- | --- | --- | --- |
| 颗粒 | 泥土灰尘、火山灰、坍塌粉尘、烟灰、霉菌孢子、飞沫、干燥排泄物的粉尘 | 部分有效 | 紧贴佩戴口罩 |
| 气体、蒸气 | 一氧化碳、氯气、氨气、硫化氢、二氧化硫、氰化氢 | 几乎无能为力 | 针对该气体的吸附式、催化式滤毒罐 |
| 缺氧 | 水井、化粪池、地下室、筒仓、储罐、密闭的火灾空间 | 完全无能为力 | 供气装备，或者不要进入 |

- 颗粒与气体以大小区分。泥土灰尘是几μm，烟灰在0.1μm上下，飞沫是几到几十μm，都可能被纤维挡住。气体分子约为0.0003μm，比颗粒小千到万倍，任何纤维结构都无法把它们滤出。气体要靠化学方式捕获或使其反应，而手段因气体而异。
- 所有过滤式呼吸防护具都以周围空气中有足够呼吸的氧气为前提。口罩只能滤掉坏的东西，不能添加好的东西。氧气浓度低于19.5%的空间里，口罩毫无意义，而被保护的错觉会让人走得更深。

---
### 1-2. 感官不会发出警告的气体
| 气体 | 感觉 | 为什么危险 |
| --- | --- | --- |
| 一氧化碳 | 无色、无味、无刺激 | 没有信号。从头痛和嗜睡开始，就这样睡着了 |
| 硫化氢 | 低浓度时有臭鸡蛋味 | 高浓度时嗅觉麻痹，气味消失 |
| 甲烷、氮气 | 无味 | 没有毒性，但排挤氧气导致窒息 |
| 二氧化碳 | 无味 | 沉积在低处，在密闭空间里积聚 |
| 氯气、氨气 | 强烈刺激 | 能凭气味察觉，但那时已经接触了 |

- 硫化氢：如果气味原先有后来消失了，不是变安全了，而可能是浓度升到了致命水平。这是化粪池、下水道、堆肥堆、长期积水处事故的典型经过。
- 一氧化碳：它与血红蛋白的结合力比氧气强200倍以上，阻碍氧气运输，却没有窒息的感觉。反而会犯困，无法自行撤离。这与《害虫与鼠类防除》中蚊香的危险是同一个原理。

---
### 1-3. 密闭空间事故
&nbsp;&nbsp;&nbsp;水井、化粪池、地下储藏室、筒仓、水箱、长期封闭的地下室，空气不流通，氧气被消耗，其他气体积聚。这是因为有机物分解时消耗氧气，放出二氧化碳、硫化氢和甲烷。

&nbsp;&nbsp;&nbsp;事故的形态几乎总是一样。一个人进去倒下，进去救人的人倒下，接着下一个人又进去。倒下的人不显痛苦，悄无声息地失去意识，所以外面的人察觉不到危险。

> **注意：**有人在密闭空间里倒下时冲进去，不是救援，而是增加死者。毛巾或口罩在这种情况下什么用也没有。

- 能做的事：不要进去。在外面用钩子或绳索把人拉出来。先换空气。打开盖子耐心通风，或者从上往下送风，把重的气体顶上去。
- 用放下蜡烛或火柴看火是否熄灭的老办法，只能知道缺氧，检测不出一氧化碳，而有甲烷时还会成为点火源。这不是可靠的判定手段。

## 2. 颗粒过滤的原理
### 2-1. 过滤机制
&nbsp;&nbsp;&nbsp;过滤无法只用筛分来解释。如果只是筛分，挡住0.1μm的颗粒就需要0.1μm的孔，那就无法呼吸了。实际上有五种机制共同起作用。

| 机制 | 作用方式 | 捕获效果最好的大小 |
| --- | --- | --- |
| 筛分 | 比纤维间隙大的颗粒直接被挡住 | 几μm以上 |
| 惯性撞击 | 较重的颗粒跟不上气流，撞到纤维上 | 1μm以上 |
| 拦截 | 顺着气流运动的颗粒擦过纤维而粘住 | 0.5-1μm |
| 扩散 | 较轻的颗粒作布朗运动晃动，碰到纤维 | 0.1μm以下 |
| 静电吸附 | 带电的纤维把颗粒吸过来 | 与大小无关，全部区间 |

&nbsp;&nbsp;&nbsp;惯性撞击和拦截是颗粒越大越有效，扩散是越小越有效。两种趋势相反，所以两者之间会出现两者都较弱的低谷。这个低谷大约在0.3μm，这个尺寸最容易穿过（最易穿透粒径）。

&nbsp;&nbsp;&nbsp;N95等级中的95%，是在最容易穿过的尺寸下测得的最差性能。比这更大或更小的颗粒都能被更好地滤除。所谓小于0.3μm的病毒会穿过的说法并不成立。越小，扩散越强，反而越容易被抓住。

---
### 2-2. 静电与呼吸速度
- 工业生产的口罩，其性能很大一部分来自纤维上带的电荷。给极细纤维制成的无纺布通上电，经过的颗粒就会被吸过来粘住。它在不缩小孔隙的情况下提高过滤性能，所以呼吸阻力保持较低。
- 这种电荷会因水、酒精、洗涤剂、高湿度和长期存放而消失。这就是清洗口罩或用酒精消毒会使性能下降的原因。自制的布口罩原本就没有电荷，只剩纯粹的机械过滤。
- 空气通过得快，小颗粒在纤维附近停留的时间就短，被扩散作用抓住的机会就减少。呼吸越急促，过滤性能越低，所以跑步或搬重物时佩戴的口罩，比静止时挡得更少。

---
### 2-3. 层数
&nbsp;&nbsp;&nbsp;布叠起来会提高过滤性能，但呼吸阻力上升得越来越陡。过了某个点之后，就只剩损失。

| 层数 | 过滤性能 | 呼吸阻力 |
| --- | --- | --- |
| 1层 | 低 | 低 |
| 2层 | 明显上升 | 明显上升 |
| 3-4层 | 略有上升 | 大幅上升 |
| 更多 | 几乎停滞 | 急剧上升 |

- 阻力升高后，空气会流向阻力低的一侧，从口罩边缘的缝隙漏进来。于是出现了布料越好、漏气反而越多的悖论。
- 呼吸困难时，人会摘掉口罩或把口罩拉下来戴。即使戴着，如果呼出的气体又被吸入，二氧化碳就会积聚，引起头痛和头晕。对心肺疾病患者、老年人和幼儿来说，这本身就是危险。
- 层数的标准不是过滤率，而是在那种状态下能否按所需时间持续呼吸。取决于是只用来短暂通过，还是要戴着工作几个小时。

## 3. 材料与贴合
### 3-1. 贴合为什么比布料等级更重要
&nbsp;&nbsp;&nbsp;戴上口罩后，空气会走两条路进入：穿过口罩的路径，以及从脸与口罩之间的缝隙漏入的路径。从缝隙漏入的空气完全没有经过任何过滤。即使布料能滤掉99%的颗粒，如果吸入空气的10%从缝隙进入，整体性能也只停留在90%左右。布料只能滤掉70%，只要没有漏气，就能完整发挥70%。让口罩严丝合缝地贴在脸上，比把布料等级提高一级差别更大。

| 出现缝隙的位置 | 原因 | 改善 |
| --- | --- | --- |
| 鼻子两侧 | 布料无法顺着鼻梁的起伏 | 放入铁丝或薄金属条，按压贴合 |
| 脸颊边缘 | 带子松，布料浮起 | 勒紧带子，把边缘折起来形成平面 |
| 下巴下方 | 说话或活动时张开 | 把尺寸做得能包住下巴 |
| 胡须 | 空气从毛发之间通过 | 根本无法贴合 |

&nbsp;&nbsp;&nbsp;有胡须的地方，任何口罩都贴不紧。检查贴合的方法是：用手掌盖住口罩吸气，布被吸向脸的一侧就是贴合了；如果感觉到哪里有风进来，那个位置就是漏气的地方。

---
### 3-2. 各种材料的大致性能
&nbsp;&nbsp;&nbsp;这是公开研究中报告的布料本身的大致范围。它因测量条件和颗粒大小而差别很大，并不是佩戴时的性能。

| 材料 | 大致过滤范围 | 呼吸阻力 | 评价 |
| --- | --- | --- | --- |
| 医用外科口罩 | 高（约90%左右） | 中等 | 作为基准的比较对象 |
| 吸尘器集尘袋 | 高（约85-95%） | 非常高 | 过滤好，但难以呼吸，且有玻璃纤维风险 |
| 抹布、厚棉毛巾 | 中上（约70-85%） | 高 | 仅短时间内实用 |
| 混纺棉衬衫 | 中等（约70%） | 中等 | 性能与呼吸之间的平衡相对较好 |
| 枕套、亚麻 | 中等（约55-60%） | 低 | 适合长时间使用 |
| 棉T恤 | 中等（约50-70%） | 低 | 叠着用最稳妥 |
| 丝绸、围巾 | 低（约50%左右） | 低 | 只能挡住大的灰尘 |
| 咖啡滤纸 | 中等 | 非常高 | 阻力大，空气从侧面漏出，实际效果低 |
| 无纺布（口罩用） | 高 | 低 | 只有电荷还在时才有这种性能 |

- 过滤得越好的材料越难呼吸，越容易呼吸的材料过滤得越少。这种此消彼长的关系是关键。
- 吸尘器集尘袋的过滤性能接近外科口罩，但呼吸阻力太大，空气从边缘漏出，无法长时间佩戴。有些产品含有玻璃纤维，本身就成了吸入的危险。
- 研究者推荐棉T恤和枕套，不是因为过滤效果最好，而是因为这种组合可以反复使用。

---
### 3-3. 湿布的作用范围
&nbsp;&nbsp;&nbsp;在火灾或有毒气体的情况下，建议把毛巾打湿捂住口鼻，这种建议有部分依据。

| 作用 | 原理 | 局限 |
| --- | --- | --- |
| 捕集颗粒 | 水填满纤维间的空隙，通道变窄，颗粒粘在湿纤维上不再被扬起 | 呼吸阻力大幅上升，而且很快变干 |
| 吸收水溶性气体 | 氨、氯、氯化氢、二氧化硫易溶于水，一部分被布上的水抓住 | 布里的水量极少，很快饱和 |
| 阻隔热气 | 把热空气稍微冷却，延缓气道烧伤 | 无法阻挡热源本身 |

> **注意：**湿布对一氧化碳和氰化氢没有效果。即使是对水溶性气体，效果也只有几十秒到几分钟，也就是只够争取离开那个地方的时间。相信湿毛巾而决定留下来，会导致事故。

- 正确用途：在穿过烟雾走出去的过程中使用。不要为了在烟雾里做什么事而使用。
- 用来打湿的水：用被污染的水打湿的布贴在脸上，会让病原体直接进入呼吸道。清理霉菌或排泄物时打湿布要用干净的水，任何情况下都不能用尿液或积水。

## 4. 气体与烟雾、判断标准
### 4-1. 活性炭能抓住的与抓不住的
&nbsp;&nbsp;&nbsp;活性炭不是过滤，而是抓取。把炭在高温下处理，内部形成无数细小的孔，表面积变得极大，经过的气体分子会粘在这个表面上。分子越大、越重、沸点越高，越容易停留；小的、轻的、沸点低的分子即使粘上也很快脱落。

| 类别 | 气体 | 原因 |
| --- | --- | --- |
| 抓得好 | 有机溶剂蒸气、苯、甲苯、恶臭物质、部分杀虫剂蒸气 | 分子大，沸点高 |
| 需要特殊处理 | 氨、氯、二氧化硫、氰化氢 | 要添加化学药剂，通过化学反应捕获 |
| 抓不住 | 一氧化碳、甲烷、二氧化碳、氮气 | 分子小，无极性，沸点非常低 |

> **注意：**一氧化碳无法被活性炭滤除。无论把炭填得多厚，它都会原样穿过。

&nbsp;&nbsp;&nbsp;一氧化碳不是要抓住，而是要转化成别的物质。专业装备的防烟面罩里装有把一氧化碳氧化成二氧化碳的催化剂，但这种催化剂怕潮湿，有使用寿命，而且在家里做不出来。灾难情况下对一氧化碳的应对只有一个：离开那个空间。

---
### 4-2. 穿透
&nbsp;&nbsp;&nbsp;活性炭能抓住的气体量不是无限的。表面被占满之后，之后进来的气体就原样通过，这个时间点就是穿透。

| 因素 | 使穿透提前的条件 |
| --- | --- |
| 浓度 | 气体浓度越高，越快饱和 |
| 呼吸量 | 呼吸越急促，单位时间通过量越大 |
| 湿度 | 水蒸气先占据吸附位点 |
| 温度 | 温度高时，吸附上的分子会脱落 |
| 保存 | 仅仅拆开包装放着，也会吸附空气中的物质而被消耗 |

&nbsp;&nbsp;&nbsp;最危险的是没有合适的办法察觉穿透。如果又开始闻到气味，气体已经在通过了，那不是警告，而是事后通知。对于一氧化碳这类无味气体，或有害浓度低于能闻到气味的浓度的物质，连这种信号都没有。

---
### 4-3. 火灾烟雾杀人的方式
&nbsp;&nbsp;&nbsp;火灾死亡者中相当一部分不是被烧死，而是因吸入烟雾死亡。烟雾中真正致人死亡的成分，口罩几乎挡不住。

| 死亡因素 | 作用 | 简易口罩的效果 |
| --- | --- | --- |
| 一氧化碳 | 与血红蛋白结合，阻断氧气运输 | 无 |
| 氰化氢 | 使细胞的能量生产本身陷于瘫痪 | 无 |
| 缺氧 | 火消耗氧气，浓度下降 | 无 |
| 高温气体 | 造成气道烧伤和水肿，气道被堵 | 几乎没有 |
| 刺激性气体 | 氯化氢、丙烯醛等使气道肿胀 | 几乎没有 |
| 烟灰颗粒 | 刺激气道并沉积 | 部分有效 |

- 氰化氢在含氮物质燃烧时产生。现代住宅里到处是聚氨酯发泡保温材料和床垫、尼龙地毯和衣物、羊毛和丝绸等。这与《污物处置》中说发泡塑料不能烧的原因相同。氰化氢和一氧化碳共同作用，比单独存在时让人丧失意识快得多。
- 用布挡住肉眼可见的黑烟，只会让人一边吸入真正致命的无色气体，一边误以为受到了保护。
- 低姿：热烟和烟灰会上浮，所以低处对视线和热量有利。但是一氧化碳密度与空气相近，在整个空间中均匀混合，趴下也躲不开一氧化碳。低姿只能多争取一点离开的时间，目的地始终是室外。

---
### 4-4. 判断标准
| 情况 | 正确的判断 |
| --- | --- |
| 火灾烟雾 | 立即离开。口罩只是离开途中的辅助，不能成为返回的依据 |
| 密闭空间 | 不要进入。先通风，把倒下的人从外面拉出来 |
| 有毒气体泄漏 | 背对风向，向高处、上风方向移动。在室内就关上窗户，堵住缝隙 |
| 坍塌粉尘、火山灰 | 过滤确实有帮助。贴合与多层布有意义 |
| 清理霉菌、排泄物 | 打开门通风，先用水把表面润湿，再用布遮住，防止颗粒扩散到空气中 |
| 传染病飞沫 | 过滤有帮助。贴合与佩戴时间决定性能 |

&nbsp;&nbsp;&nbsp;如果危险是颗粒，过滤有帮助；如果是气体或缺氧，则没有帮助。在火灾烟雾和有毒气体泄漏中，口罩不能成为判断的依据。在火山灰、清理和传染病飞沫中，口罩能提供一定程度的保护。

&nbsp;&nbsp;&nbsp;无论哪种情况，都有两件事优先于过滤：离开现场和更换空气。口罩让人少吸一点污染的空气，通风减少污染空气本身，而离开则是干脆不吸。如果顺序颠倒，简易呼吸防护具就会成为在危险地方停留更久的理由。
