## 4. 気体と煙、武器判断基準
&nbsp;&nbsp;&nbsp;ここまでは粒子に関する内容でした。本章では、ろ過が理論的に機能しなくなる領域、すなわち「気体」を扱います。納得災害において最も多くの人を死に至らしめる呼吸障害である「火災の煙」が、なぜマスクで解決できる問題ではないのかを整理します。

---
### 4-1. 活性炭が捕獲できるものと捕獲できないもの
&nbsp;&nbsp;&nbsp;活性炭は物理的にろ過するのではなく**吸着・捕獲します。** 木炭を高温処理して内部に無数の微細孔を形成させることで表面積が極限まで拡大し、通過する気体分子がこの表面に付着・保持されます。

&nbsp;&nbsp;&nbsp;しかし、すべての気体が同様に吸着されるわけではありません。**分子が大きく、重く、沸点が高い物質ほど**表面に留まりやすく、小さく、軽く、沸点が低い分子は吸着してもすぐに脱離して抜け出します。

| 区分 | 対象気体 | 理由・メカニズム |
| --- | --- | --- |
| 良好に捕獲 | 有機溶剤蒸気、ベンゼン、トルエン、悪臭物質、一部の農薬蒸気 | 分子が大きく沸点が高いため |
| 特殊処理が必要 | アンモニア、塩素、二酸化硫黄、シアン化水素 | 化学薬剤を添着させ、化学反応によって捕獲するため |
| **捕獲不可能** | **一酸化炭素**、メタン、二酸化炭素、窒素 | 分子が小さく無極性であり、沸点が極めて低いため |

> **一酸化炭素は活性炭で捕獲・ろ過することはできません。木炭層をどれほど厚く充填しても、一酸化炭素はそのまま透過します。**

&nbsp;&nbsp;&nbsp;一酸化炭素を処理するには、捕獲するのではなく**別の無害な物質へ化学変換（酸化）**しなければなりません。専門的な避難用フード（防煙フード）には一酸化炭素を二酸化炭素へ酸化させる触媒（ホプカライト等）が内蔵されていますが、この触媒は湿気に弱く有効期限が存在し、自作することは不可能です。災害下における一酸化炭素への唯一の対処法は、ろ過ではなく**「その空間から即座に退避すること」**のみです。

---
### 4-2. 破過（ブレイクスルー）
&nbsp;&nbsp;&nbsp;活性炭が吸着可能な気体の容量には限界が存在します。吸着面が飽和状態に達すると、それ以降流入した気体はそのまま透過し、この時点を**破過（ブレイクスルー）**と呼びます。

| 変動要因 | 破過を加速させる条件 |
| --- | --- |
| 濃度 | 気体濃度が高いほど急速に飽和へ至ります |
| 呼吸量 | 息が上がるほど単位時間あたりの流出入量が増大します |
| 湿度 | 水蒸気が吸着サイトを先行して占有します |
| 温度 | 高温環境下では吸着していた分子が脱離します |
| 保管状態 | 開封放置するだけで空気中の物質を吸着・消費します |

&nbsp;&nbsp;&nbsp;最も危険な点は、**破過の発生を事前に感知する確実な手段が存在しないこと**です。再び臭気を感じ始めた時点で、すでに気体は透過しており、それは事前警告ではなく事後通告に過ぎません。さらに一酸化炭素のように無臭の気体や、致死濃度が嗅覚閾値より低い物質においては、この事後通告すら存在しません。

---
### 4-3. 火災の煙が実際に人を死に至らしめるメカニズム
&nbsp;&nbsp;&nbsp;火災における犠牲者の大半は、焼死ではなく煙の吸入によって死亡します。しかし、その煙の中で人を死に至らしめる有害成分は、簡易マスクで少しでも防ぐことができるような成分ではありません。

| 致死要因 | 人体への作用メカニズム | 簡易マスクの効果 |
| --- | --- | --- |
| 一酸化炭素 | ヘモグロビンと強力に結合し、酸素運搬を阻害 | 一切なし |
| シアン化水素 | 細胞のエネルギー代謝（ミトコンドリア）自体を麻痺 | 一切なし |
| 酸素欠乏 | 燃焼により酸素が消費され、環境濃度が低下 | 一切なし |
| 高温ガス | 気道に熱傷と浮腫を引き起こし、気道を閉塞 | ほぼなし |
| 刺激性ガス | 塩化水素、アクロレイン等が気道粘膜を激しく生傷 | ほぼなし |
| スス（煤粒子） | 気道刺激および沈着 | 部分的に有効 |

&nbsp;&nbsp;&nbsp;シアン化水素（青酸ガス）は特に知っておくべき危険物質です。窒素を含む物質が燃焼する際に発生しますが、現代の住宅空間には該当素材が溢れています。ポリウレタンフォーム断熱材やマットレス、ナイロン製カーペットや衣類、羊毛や絹製品がこれに該当します。前述の「廃棄物処理」で泡プラスチックを焼却してはならない理由と同義です。シアン化水素と一酸化炭素は複合的に作用し、単一物質の場合よりも格段に早い時間で意識障害を引き起こします。

> **火災の煙において人を殺すのは黒煙（スス）ではありません。視覚的な黒煙を布で遮る行為は、死を招く無色無臭の有毒ガスを吸入しながら「保護されている」と錯覚させる極めて危険な行為です。**

&nbsp;&nbsp;&nbsp;「低い姿勢で移動する」という避難原則も正確に理解する必要があります。熱い煙やススは上方に浮上するため、低い姿勢は視界確保と熱気回避において明確に有利です。しかし一酸化炭素は空気とほぼ同等の密度を有するため、空間全体に均一に拡散・混合します。**伏せた状態になっても一酸化炭素を回避することはできません。** 低い姿勢は退避時間をわずかに稼ぐための手段に過ぎず、目指すべき目的地は常に「屋外」です。

---
### 4-4. 判断基準
&nbsp;&nbsp;&nbsp;最後に、これまで解説した全内容を単一の判断フローとしてまとめます。

| 状況・環境 | 正しい判断・行動 |
| --- | --- |
| 火災の煙 | 即座に現場から離脱・退避します。マスクは退避中の補助に過ぎず、現場に留まったり再進入する根拠とはなりません |
| 密閉空間 | 絶対に入らない。まず強制換気を行い、倒れた者は外部からロープ等で引き出します |
| 有毒ガス漏洩 | 風上に向かい、高所・風上側へ移動します。屋内であれば窓を閉め隙間を目張りします |
| 倒壊粉塵・火山灰 | 物理ろ過が実際に有効です。密着と複数層の布が意味を持ちます |
| カビ・糞尿清掃 | 窓を開けて換気し、表面を事前に水で濡らした後、布で口元を覆い粒子の飛散・吸入を防ぎます |
| 感染症飛沫 | 物理ろ過が有効です。密着度と着用時間が保護性能を左右します |

&nbsp;&nbsp;&nbsp;**「危険が『粒子』であればろ過は有効であり、『気体』または『酸素欠乏』であればろ過は無効である」** というのが根本原則です。火災の煙や有毒ガス漏洩下では、マスクを判断の根拠にしてはならず、火山灰、清掃作業、感染症飛沫下でのマスク着用は一定の保護効果を提供します。

&nbsp;&nbsp;&nbsp;그리고いかなる状況においても、ろ過に優先する2つの基本行動が存在します。**「その場から離脱すること」**と**「空気を入れ替えること（換気）」**です。マスクは汚染空気の吸入量をわずかに減らす装置であり、換気は汚染空気そのものを減らす作業であり、離脱は吸入自体を完全に回避する行動です。この優先順位が逆転した瞬間、簡易呼吸保護具は保護具ではなく、致死的な場所に長く留まらせる原因へと変貌します。
