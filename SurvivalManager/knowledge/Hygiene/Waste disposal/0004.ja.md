## 3. 安定化と残りの経路
&nbsp;&nbsp;&nbsp;閉じ込めた大便を無害にする作業と、トイレでは防げない残りの経路(手、ハエ、月経、ごみ)を扱います。

---
### 3-1. 堆肥化
&nbsp;&nbsp;&nbsp;堆肥化トイレは、大便を炭素源と混ぜて、好気性微生物に分解させる方式です。微生物の代謝熱で山の内部の温度が上がり、その熱が病原体を殺します。殺菌の主体は微生物ではなく温度です。

| 病原体 | 死滅条件(おおよそ) |
| --- | --- |
| 大腸菌・サルモネラなどの細菌 | 55℃で数時間 |
| 腸管ウイルス | 55-60℃で数時間 |
| 原虫のシスト | 55℃で数時間 |
| 回虫卵 | 55℃で約1時間、60℃以上で数分、45℃以下では数か月生存 |

- 回虫卵が事実上の基準です。回虫卵が死んでいれば残りはほとんど死んでおり、生きていれば堆肥化は失敗です。
- WHOの勧告: 熱による堆肥化は、50℃以上を最低1週間維持します。この条件を満たせなかった山は、堆肥ではなく依然として大便です。
- 温度が上がるには、山が自ら断熱できる大きさ(最低1m³程度)で、水分が50-60%で、炭素と窒素の比がおおよそ25-30対1で、酸素が供給されるよう切り返す必要があります。冬、小さな容器、水分過多、炭素源の不足のうち、どれか1つに当てはまるだけでも温度が上がりません。
- 温度を確保できないなら、時間を使います。密閉して長く置くことです。常温20-35℃で1年以上貯蔵すると、ウイルスと原虫は大部分が死滅しますが、回虫卵は残ることがあります。低温貯蔵で処理した大便は、そのまま食べる野菜ではなく、果樹、飼料作物、薪用の木のように、接触が少ない所に使います。

---
### 3-2. 手洗い
&nbsp;&nbsp;&nbsp;手から病原体を取り除く力は3つあります。摩擦で皮膚からはがし、界面活性で油膜についたものを引き離し、流水で、はがしたものを手の外へ流し出します。1つでも欠けると、効果が大きく減ります。

&nbsp;&nbsp;&nbsp;最もよく欠けるのは流水です。たらいに水をためて手を浸してこすると、摩擦と界面活性は働きますが、はがれた病原体がその水に浮かび、手を出すときに再びつきます。複数の人が同じたらいを使うと、たらい自体が感染源になります。

> **注意:** 手洗いで、水の量より重要なのは、水が一方向に流れ出ていくかどうかです。たまり水に手を浸すのは手洗いではなく、病原体を分け合う行為です。

&nbsp;&nbsp;&nbsp;最小限の水でこの原理を実現した構造が、ティッピータップ(tippy tap)です。水を入れた容器をひもで吊るし、足で踏むと傾いて、細い水の筋が出るようにつくります。

- 流れる水なので、再汚染がありません。
- 手で蛇口に触れる必要がないため、接触汚染がありません。
- 水の筋が細く、1回洗うのに100ml前後で足ります(たらいは500ml以上)。

&nbsp;&nbsp;&nbsp;石鹸がないときの代用品は、摩擦材です。石鹸の界面活性の機能を完全に代替することはできませんが、粗い粒子で摩擦を大きくし、流水で洗い流せば、かなりの部分を補えます。

| 代用品 | 原理 | 効果と注意点 |
| --- | --- | --- |
| 木灰 | アルカリ性で、細かい粒子の摩擦が大きい。水と出会うと弱い灰汁になり、一部の界面活性も現れる | 石鹸に最も近い代用品。細かい灰を使い、完全にすすぐ |
| 細かい砂 | 摩擦だけを提供 | 手を傷めない程度に細かいものを使う |
| 土 | 摩擦と粒子の吸着 | 大便に汚染されている可能性のある地表の土は避け、表層より下の土を使う |
| 灰汁 | 強い界面活性 | 洗濯・食器用。手には濃度を大きく下げて使う |
| サポニンを含む植物(サイカチの実、ソープワートなど) | 天然の界面活性剤 | 手に入れば有用だが、地域によっては入手が難しい |

&nbsp;&nbsp;&nbsp;洗う時点は、病原体が手に上がった直後と、口に入る直前が、最も効率的です。

- 上がった直後: 用便後、子どもの世話の後、患者に接触した後
- 入る直前: 調理前、食事前、傷の手当ての前

### 3-3. ハエの遮断
&nbsp;&nbsp;&nbsp;ハエ対策は、成虫を殺すことではなく、繁殖の連鎖を断つことです。イエバエの卵は、条件がよければ1日以内に孵化し、ウジは1週間前後で成虫になります。むき出しの大便や生ごみの山1つが、数日で数百匹をつくります。

&nbsp;&nbsp;&nbsp;遮断する点は3か所です。大便をすぐ覆って産卵を防ぎ、トイレの穴にふたをして出入りを防ぎ、残飯を毎日埋めるか燃やします。ふた1つのほうが殺虫剤より効果があります。成虫を追い払うことは、この3つをすべて行った後の補助手段です。

---
### 3-4. 月経の衛生
&nbsp;&nbsp;&nbsp;月経は災害でも止まりませんが、対応する物資は最初に途切れます。放置すると感染と活動の制限につながり、トイレを使うこと自体を避けるようになって、前の障壁も一緒に崩れます。

- 再利用する布で重要なのは、完全に乾かすことです。濡れたまま畳んでおくと、細菌とカビが増えて感染の危険になります。
- 洗濯の順序: 先に冷水ですすいで、血液のタンパク質を取り除きます(先にお湯を使うと、タンパク質が凝固して繊維に固着します)。石鹸または薄い灰汁で洗濯します。直射日光で完全に乾かします。日光は乾燥と紫外線殺菌を同時に行うので、日陰干しより優れています。
- 吸収材として使える自然材料は、煮て乾かした綿織物、きれいな乾いたコケ、柔らかい乾いた草です。すべて刺激と汚染の可能性があるので、直接触れる面には、できるだけ煮た綿織物を使います。
- 使用した物は、大便と同じ等級として扱い、埋めるか燃やします。

### 3-5. 一般廃棄物
&nbsp;&nbsp;&nbsp;ごみはし尿より急ぎませんが、放置するとハエとネズミの繁殖地になり、前の障壁を無力化します。処理の方法は焼却と埋設で、何を燃やせるかが肝心です。

&nbsp;&nbsp;&nbsp;家庭用のたき火の燃焼温度はおおむね600-800℃で、酸素の供給も不均一です。これは不完全燃焼を意味し、ある物質は、元よりはるかに危険な物質に変わります。

| 区分 | 品目 | 理由 |
| --- | --- | --- |
| 燃やしてよいもの | 紙、乾いた木、乾いた草、天然繊維(綿・麻) | 炭素・水素・酸素が中心なので、燃焼生成物が比較的単純 |
| 燃やしてはいけないもの | PVC(電線の被覆、ビニール床材、一部の配管・包装材) | 塩素を含むため、低温の不完全燃焼でダイオキシン・フランが生成される。ごく微量でも毒性が大きく、体内に蓄積 |
| 燃やしてはいけないもの | 発泡プラスチック(ポリウレタンのスポンジ、マットレス、断熱材) | 窒素を含むため、燃焼時にシアン化水素が発生。火災による死亡の主な原因物質 |
| 燃やしてはいけないもの | 発泡スチロール、タイヤ、塗装した木材、防腐処理した木材 | 芳香族化合物、重金属、ヒ素・クロム化合物が煙と灰として放出される |
| 燃やしてはいけないもの | 電池、蛍光灯、ペンキ缶、密閉容器、スプレー缶 | 重金属の放出または爆発の危険 |

- 区別が難しいときの基準: もともと自然にあったものは燃やせ、人が合成したものは、おおむね燃やしてはいけません。
- 燃やせないものは埋めます。埋設の位置は、し尿の穴と同じ基準です(水源から30m以上、地下水面の上、水源より地形的に低い側)。
- 電池やペンキのように重金属を含むものは、別に集めて表示します。土壌で分解されないので、状況が回復した後、その場所に何が埋まっているのか誰も知らない状態が最も悪いです。
- 生ごみは、燃やすより埋めます。水分が多くて燃えにくく、煙だけが出ますが、埋めれば土壌微生物が分解します。30cm以上覆うと、ハエの産卵とネズミの接近を同時に防げます。
