## 2. 発生源の除去と忌避
&nbsp;&nbsp;&nbsp;発生源の除去は、昆虫の生活環のうち、最も脆弱で動けない段階(卵・幼虫)を狙います。成虫は飛び回って散らばりますが、卵と幼虫は一か所に集まっていて、逃げられません。同じ労力で、はるかに多くの個体を除去できます。

---
### 2-1. たまり水の1週間ルール
&nbsp;&nbsp;&nbsp;蚊は水の中で生まれます。卵から成虫まで、夏の25-30℃でおおむね7-10日かかり、水温が低ければ2週間以上かかることもあります。

> **たまり水を週に一度、空にするか、ひっくり返せば、その水から成虫になって飛び立つ蚊はいません。**

&nbsp;&nbsp;&nbsp;蚊の幼虫は水中でしか生きられないので、水をあければ、幼虫とさなぎはすぐに干からびて死にます。殺虫剤も、油も、特別な処理も要りません。水がたまる場所を、もれなく見つければよいのです。ヤブカの仲間はペットボトルのキャップにたまった水でも繁殖するので、人が水たまりだと認識しない場所が問題です。

| よく見落とされる産卵場所 | なぜ見落とされるか |
| --- | --- |
| 植木鉢の受け皿、空の植木鉢 | 水がたまっているのが見えない |
| 捨てられたタイヤ | 内側に水が残り、冬も凍らない |
| 詰まった雨どい・排水溝 | 視界から外れている |
| 防水シート・ビニールのしわ | 少量だが、水が補充され続ける |
| ふたのない水がめ・バケツ | 飲料用なので、空にしようと思わない |
| 廃棄された容器、缶、瓶 | がれきの中に埋もれて見えない |
| 木の穴、竹の切り株 | 自然物なので、発生源と考えない |
| 浄化槽・下水の滞留 | 近づくのが難しい |

&nbsp;&nbsp;&nbsp;空にできない水には、ほかの方法を使います。

- 貯水槽・雨水タンクのように、保管しなければならない水: ふたをして、産卵そのものを防ぎます。
- ふたをできない広い水面: 植物油や廃油を、ごく薄く浮かべます。幼虫とさなぎが水面に呼吸管を出せずに窒息します。この水は飲料水に使えず、周囲の土壌と水系を汚染するので、捨てられた水たまりにだけ限定的に使います。
- 魚を入れられる水槽: メダカ、ドジョウのような小型の淡水魚が幼虫を食べ尽くします。最もきれいな解決法です。

### 2-2. 煙は殺虫剤ではない
&nbsp;&nbsp;&nbsp;蚊遣り火は実際に蚊を減らしますが、原理を正確に知っておく必要があります。煙が蚊を追い払う理由は3つあります。

1. 煙の粒子が蚊の化学感覚器をふさぎ、人が吐き出す二酸化炭素と体臭の臭いの道筋を乱します。臭いの道筋が途切れると、蚊は目標を見つけられません。
2. 植物によっては、煙に混ざった揮発性化合物そのものが忌避作用をします。ヨモギのシネオールとツジョン、コノテガシワ・ビャクシンのテルペン類、松葉のピネンが該当します。
3. 煙の上昇気流のために、飛ぶ力の弱い蚊は近づきにくくなります。

&nbsp;&nbsp;&nbsp;3つとも、殺す作用ではありません。煙が晴れれば蚊は戻ってきて、風が少し吹くだけで煙が片側に寄り、反対側は無防備になります。蚊遣り火は、蚊帳や発生源の除去の代わりにはならず、屋外活動中の補助手段です。

| 材料 | 主な成分 | 特徴 |
| --- | --- | --- |
| ヨモギ(乾燥させたもの) | シネオール、ツジョン、カンファー | 最も広く使われ、香りが強く、長く燃える |
| コノテガシワ・ヒノキ・ビャクシンの葉 | テルペン類 | 香りが強く、煙が濃い |
| 松葉・松ぼっくり | ピネン | 手に入りやすいが、松ヤニのため炎が残りやすい |
| 柑橘類の皮(乾燥させたもの) | リモネン | 少量でも香りが強い |
| 緑の草・生木 | 水分 | 成分より煙の量で作用 |

- コツ: 炎を出さず、長くいぶらせます。よく乾いた材料の上に、乾きの浅い材料や生草をかぶせると、不完全燃焼が続いて、煙が多く出て長持ちします。土を軽くかぶせて酸素の供給を減らすのも、同じ原理です。
- 煙をたくさん出すということは、不完全燃焼を起こすということで、不完全燃焼は一酸化炭素を作ります。一酸化炭素は色も臭いもなく、ヘモグロビンに酸素より200倍以上強く結合して、酸素の運搬を妨げます。頭痛と眠気から始まって意識を失い、眠気のためにそのまま眠って死亡する事故が繰り返されています。

> **注意:** 密閉されたテントや部屋の中で蚊遣り火をたくと、蚊よりもはるかに確実に人が死にます。燻煙は必ず屋外か完全に開けた空間で行い、屋内では換気なしにはどんな形の火も置きません。

### 2-3. ジョチュウギクと植物性の忌避剤
&nbsp;&nbsp;&nbsp;天然素材の中で、実際に殺す力のある植物は、ジョチュウギク(除虫菊、*Chrysanthemum cinerariifolium*)だけです。花に含まれるピレトリンは、現代の殺虫剤の大きな柱であるピレスロイド系の原型です。

- 作用: 昆虫の神経細胞の電位依存性ナトリウムチャネルに結合して、チャネルが閉じられないようにします。神経が止まらずに信号を繰り返し送り、昆虫はただちに運動の制御を失って落ちます。
- 哺乳類への毒性が低い理由: ナトリウムチャネルが構造的に敏感でなく、肝臓と血液のエステル分解酵素がピレトリンを速やかに分解します。

| 項目 | 内容 |
| --- | --- |
| 有効な部位 | 花、特に子房の部分に成分が集中 |
| 収穫の時期 | 花が十分に咲いて、中央の筒状花が3、4列開いたときに含有量が最も高い |
| 乾燥 | 必ず日陰で乾かす。ピレトリンは光で分解されるので、日光乾燥は成分を破壊する |
| 保管 | 密閉して暗い場所に置く。時間がたつと効力が落ちる |
| 使用 | 細かく砕いて粉としてまく、燃やして煙を出す、水・油・アルコールに浸して使う |
| 残留 | 光で速やかに分解されて、ほとんど残らない |

- 光で分解される性質は、長所であり短所でもあります。環境に残らず、食品の周辺でも比較的安全ですが、持続効果がほとんどなく、毎回新しく使わなければなりません。
- ピレトリンは、魚類とネコに対する毒性が強いです。水槽の近くやネコがいる空間では注意します。

| そのほかの植物 | 成分と作用 | 実際の有用性 |
| --- | --- | --- |
| ニーム(neem) | アザジラクチン。摂食阻害と成長攪乱 | すぐには殺さず、個体群を徐々に減らす |
| シナモン | シンナムアルデヒド。忌避と幼虫の殺虫 | 幼虫への殺虫効果が報告されている |
| クローブ | オイゲノール。忌避 | 香りが強く、短時間の忌避に有用 |
| シトロネラ・レモングラス | シトロネラール、ゲラニオール | 忌避効果は明らかだが、持続時間は短い |
| ユーカリ | シネオール | 忌避に使われ、原液は皮膚への刺激がある |

> **注意:** タバコの葉の浸出液は勧めません。ニコチンは強力な殺虫成分ですが、人にも強い神経毒です。皮膚からよく吸収されるため、浸出液を素手で扱うだけで、吐き気、めまい、心拍の異常が現れることがあります(タバコの収穫労働者の緑タバコ病)。解毒剤もなく、濃度を推し量る方法もない災害時には、得るものよりも失うもののほうがはるかに大きいです。
