## 2. 清除孳生源与驱避
&nbsp;&nbsp;&nbsp;清除孳生源，针对的是昆虫生活史中最脆弱、不能移动的阶段（卵和幼虫）。成虫会飞着四散，但卵和幼虫聚在一处，逃不掉。同样的努力可以清除多得多的个体。

---
### 2-1. 积水一周规则
&nbsp;&nbsp;&nbsp;蚊子在水里出生。从卵到成虫，夏季25-30℃时大致需要7-10天，水温低时也可能需要两周以上。

> **积水每周倒空或翻过来一次，那里的水中就没有蚊子能长成成虫飞起来。**

&nbsp;&nbsp;&nbsp;蚊子幼虫只能生活在水里，所以把水倒掉，幼虫和蛹会立即干死。不需要杀虫剂，不需要油，也不需要特殊处理。只要把积水的地方一处不漏地找出来。伊蚊类连瓶盖里积的水也能孳生，所以问题出在人们不认为是水洼的地方。

| 常被遗漏的产卵地 | 为什么被遗漏 |
| --- | --- |
| 花盆托盘、空花盆 | 没注意到积了水 |
| 废弃轮胎 | 里面残留着水，冬天也不结冰 |
| 堵塞的雨水口、排水槽 | 不在视线之内 |
| 防水布、塑料布的褶皱 | 量少，但水不断得到补充 |
| 没有盖子的水桶、水盆 | 是饮用水，没人想到要倒空 |
| 废弃的容器、罐头盒、瓶子 | 埋在残骸里看不见 |
| 树洞、竹子的残桩 | 是天然物，不被当作孳生源 |
| 化粪池、下水道的积水 | 难以接近 |

&nbsp;&nbsp;&nbsp;对于无法倒空的水，用其他方法。

- 像蓄水池、雨水桶这样必须保存的水：盖上盖子，从根本上防止产卵。
- 无法加盖的大面积水面：在水面上浮一层极薄的植物油或废油。幼虫和蛹在水面无法伸出呼吸管，会窒息。这样的水不能作饮用水，还会污染周围的土壤和水系，所以只限用于废弃的水洼。
- 能放鱼的水箱：青鳉、泥鳅这类小型淡水鱼会把幼虫吃光。这是最干净的办法。

---
### 2-2. 烟不是杀虫剂
&nbsp;&nbsp;&nbsp;蚊烟火确实能减少蚊子，但必须准确了解原理。烟驱赶蚊子的原因有三个。

1. 烟颗粒遮住蚊子的化学感受器，扰乱人呼出的二氧化碳和体味所形成的气味轨迹。气味轨迹中断后，蚊子就找不到目标。
2. 视植物而定，混在烟里的挥发性化合物本身就起驱避作用。艾草的桉叶素和侧柏酮、侧柏和圆柏的萜烯类、松针的蒎烯属于此类。
3. 烟的上升气流使飞行能力弱的蚊子难以靠近。

&nbsp;&nbsp;&nbsp;三者都不是杀死的作用。烟一散，蚊子就回来了，稍有一点风，烟就偏向一侧，另一侧就毫无防备。蚊烟火不能代替蚊帐或清除孳生源，只是户外活动时的辅助手段。

| 材料 | 主要成分 | 特点 |
| --- | --- | --- |
| 艾草（晒干的） | 桉叶素、侧柏酮、樟脑 | 使用最广泛，香味浓，燃烧持久 |
| 侧柏、扁柏、圆柏叶 | 萜烯类 | 香味浓，烟浓 |
| 松针、松果 | 蒎烯 | 容易弄到，但因松脂而容易留下明火 |
| 柑橘皮（晒干的） | 柠檬烯 | 少量香味也浓 |
| 绿草、生木 | 水分 | 靠烟的量而不是成分起作用 |

- 窍门：不要冒明火，让它长时间熏着。在干透的材料上盖上不太干的材料或青草，不完全燃烧会持续，烟多而且持久。薄薄盖一层土以减少氧气供应，也是同样的原理。
- 烟多意味着引起不完全燃烧，而不完全燃烧会产生一氧化碳。一氧化碳无色无味，与血红蛋白的结合力比氧强200倍以上，阻碍氧的运输。它从头痛和困倦开始，进而失去意识，因困倦而就这样睡着死亡的事故一再发生。

> **注意：** 在封闭的帐篷或房间里点蚊烟火，杀死人比杀死蚊子可靠得多。熏烟必须在室外或完全敞开的空间进行，室内不通风的话，不要放任何形式的火。

### 2-3. 除虫菊与植物驱避剂
&nbsp;&nbsp;&nbsp;天然材料中，真正具有杀灭力的植物只有除虫菊（*Chrysanthemum cinerariifolium*）。花里所含的除虫菊酯，是现代杀虫剂的一大支柱——拟除虫菊酯类的原型。

- 作用：与昆虫神经细胞的电压门控钠通道结合，使通道无法关闭。神经不停地反复发出信号，昆虫立即失去运动控制而掉落。
- 对哺乳动物毒性低的原因：钠通道在结构上较不敏感，肝脏和血液中的酯分解酶会迅速分解除虫菊酯。

| 项目 | 内容 |
| --- | --- |
| 有效部位 | 花，成分尤其集中在子房部分 |
| 采收时期 | 花充分开放、中央的筒状花开了三四圈时含量最高 |
| 干燥 | 一定要在阴凉处晾干。除虫菊酯遇光分解，所以晒干会破坏成分 |
| 保存 | 密封后放在黑暗处。时间久了药效会下降 |
| 使用 | 磨成细粉撒布，或者烧着产烟，或者用水、油、酒精浸泡使用 |
| 残留 | 遇光迅速分解，几乎没有残留 |

- 遇光分解的性质既是优点也是缺点。它不残留在环境中，在食品周围也相对安全，但几乎没有持续效果，必须每次重新使用。
- 除虫菊酯对鱼类和猫的毒性很强。在鱼缸附近或有猫的空间要注意。

| 其他植物 | 成分与作用 | 实际用处 |
| --- | --- | --- |
| 印楝（neem） | 印楝素。抑制取食和扰乱生长 | 不会立即杀死，而是慢慢减少种群 |
| 肉桂 | 肉桂醛。驱避和杀幼虫 | 有杀幼虫效果的报道 |
| 丁香 | 丁香酚。驱避 | 香味浓，对短时间驱避有用 |
| 香茅、柠檬草 | 香茅醛、香叶醇 | 驱避效果明确但持续时间短 |
| 桉树 | 桉叶素 | 用于驱避，原液对皮肤有刺激 |

> **注意：** 不推荐烟草叶浸出液。尼古丁是强力的杀虫成分，但对人也是很强的神经毒素。它容易经皮肤吸收，光是徒手处理浸出液就可能出现恶心、头晕、心律异常（烟草采收工人的绿烟草病）。在没有解毒剂、也无法估计浓度的灾难情况下，得不偿失。
