## 2. 발생원 제거와 기피
&nbsp;&nbsp;&nbsp;발생원 제거는 곤충 생활사에서 가장 취약하고 움직이지 못하는 단계(알·유충)를 노립니다. 성충은 날아다니며 흩어지지만 알과 유충은 한자리에 모여 있고 도망가지 못합니다. 같은 노력으로 훨씬 많은 개체를 제거할 수 있습니다.

---
### 2-1. 고인 물 1주일 규칙
&nbsp;&nbsp;&nbsp;모기는 물에서 태어납니다. 알에서 성충까지 여름철 25-30℃에서 대체로 7-10일이 걸리고, 수온이 낮으면 2주 이상 걸리기도 합니다.

> **고인 물을 일주일에 한 번 비우거나 뒤집으면 그 물에서 성충이 되어 날아오르는 모기는 없습니다.**

&nbsp;&nbsp;&nbsp;모기 유충은 물속에서만 살 수 있어 물을 쏟으면 유충과 번데기가 즉시 말라 죽습니다. 살충제도 기름도 특별한 처리도 필요 없습니다. 물이 고인 곳을 빠짐없이 찾아내면 됩니다. 숲모기 종류는 병뚜껑에 고인 물에서도 번식하므로 사람이 물웅덩이라고 인식하지 않는 곳이 문제입니다.

| 흔히 놓치는 산란지 | 왜 놓치는가 |
| --- | --- |
| 화분 받침, 빈 화분 | 물이 고인 것을 보지 못함 |
| 버려진 타이어 | 안쪽에 물이 남고 겨울에도 얼지 않음 |
| 막힌 빗물받이·홈통 | 시야에서 벗어남 |
| 방수포·비닐의 주름 | 소량이지만 계속 물이 보충됨 |
| 뚜껑 없는 물통·양동이 | 식수용이라 비울 생각을 하지 않음 |
| 폐기된 용기, 캔, 병 | 잔해 속에 묻혀 보이지 않음 |
| 나무 구멍, 대나무 그루터기 | 자연물이라 발생원으로 여기지 않음 |
| 정화조·하수구 고임 | 접근이 어려움 |

&nbsp;&nbsp;&nbsp;비울 수 없는 물은 다른 방법을 씁니다.

- 저수조·빗물통처럼 보관해야 하는 물: 뚜껑을 덮어 산란 자체를 막습니다.
- 뚜껑을 덮을 수 없는 넓은 수면: 식물성 기름이나 폐유를 아주 얇게 띄웁니다. 유충과 번데기가 수면에서 호흡관을 내밀 수 없어 질식합니다. 이 물은 식수로 쓸 수 없고 주변 토양과 수계를 오염시키므로 버려진 웅덩이에만 제한적으로 씁니다.
- 물고기를 넣을 수 있는 수조: 송사리, 미꾸라지 같은 소형 담수어가 유충을 먹어 치웁니다. 가장 깨끗한 해법입니다.

---
### 2-2. 연기는 살충이 아니다
&nbsp;&nbsp;&nbsp;모깃불은 실제로 모기를 줄이지만 원리를 정확히 알아야 합니다. 연기가 모기를 쫓는 이유는 세 가집니다.

1. 연기 입자가 모기의 화학 감각기를 가려, 사람이 내뿜는 이산화탄소와 체취의 냄새길을 흐트러뜨립니다. 냄새길이 끊기면 모기는 목표를 찾지 못합니다.
2. 식물에 따라 연기에 섞인 휘발성 화합물 자체가 기피 작용을 합니다. 쑥의 시네올과 투욘, 측백·향나무의 테르펜류, 솔잎의 피넨이 해당합니다.
3. 연기의 상승 기류 때문에 비행이 약한 모기가 접근하기 어렵습니다.

&nbsp;&nbsp;&nbsp;세 가지 모두 죽이는 작용이 아닙니다. 연기가 걷히면 모기는 돌아오고, 바람이 조금만 불어도 연기가 한쪽으로 쏠려 반대편은 무방비가 됩니다. 모깃불은 모기장이나 발생원 제거를 대신하지 못하고 야외 활동 중의 보조 수단입니다.

| 재료 | 주요 성분 | 특징 |
| --- | --- | --- |
| 쑥(말린 것) | 시네올, 투욘, 캄퍼 | 가장 널리 쓰이며 향이 강하고 오래 탐 |
| 측백·편백·향나무 잎 | 테르펜류 | 향이 강하고 연기가 진함 |
| 솔잎·솔방울 | 피넨 | 구하기 쉽지만 송진 때문에 불꽃이 잘 남 |
| 감귤 껍질(말린 것) | 리모넨 | 소량으로도 향이 강함 |
| 녹색 풀·생나무 | 수분 | 성분보다 연기의 양으로 작용 |

- 요령: 불꽃을 내지 않고 오래 그을리게 합니다. 잘 마른 재료 위에 덜 마른 재료나 생풀을 덮으면 불완전 연소가 이어져 연기가 많이 나고 오래갑니다. 흙을 살짝 덮어 산소 공급을 줄이는 것도 같은 원리입니다.
- 연기를 많이 낸다는 것은 불완전 연소를 일으킨다는 뜻이고, 불완전 연소는 일산화탄소를 만듭니다. 일산화탄소는 색도 냄새도 없고 헤모글로빈에 산소보다 200배 이상 강하게 결합해 산소 운반을 막습니다. 두통과 졸음으로 시작해 의식을 잃으며, 졸음 때문에 그대로 잠들어 사망하는 사고가 반복됩니다.

> **주의:** 밀폐된 텐트나 방 안에서 모깃불을 피우면 모기보다 훨씬 확실하게 사람이 죽습니다. 훈연은 반드시 옥외나 완전히 열린 공간에서 하고, 실내에서는 환기 없이 어떤 형태의 불도 두지 않습니다.

---
### 2-3. 제충국과 식물성 기피제
&nbsp;&nbsp;&nbsp;자연 재료 중 실제로 죽이는 힘을 가진 식물은 제충국(除蟲菊, *Chrysanthemum cinerariifolium*)뿐입니다. 꽃에 든 피레트린은 현대 살충제의 큰 축인 피레스로이드 계열의 원형입니다.

- 작용: 곤충 신경세포의 전압 의존성 나트륨 통로에 결합해 통로가 닫히지 못하게 합니다. 신경이 멈추지 않고 신호를 반복해서 보내 곤충은 즉시 운동 조절을 잃고 떨어집니다.
- 포유류 독성이 낮은 이유: 나트륨 통로가 구조적으로 덜 민감하고, 간과 혈액의 에스터 분해 효소가 피레트린을 빠르게 분해합니다.

| 항목 | 내용 |
| --- | --- |
| 유효 부위 | 꽃, 특히 씨방 부분에 성분이 집중 |
| 수확 시기 | 꽃이 충분히 피어 중앙의 통상화가 서너 줄 열렸을 때 함량이 가장 높음 |
| 건조 | 반드시 그늘에서 말림. 피레트린은 빛에 분해되므로 햇볕 건조는 성분을 파괴 |
| 보관 | 밀폐해 어두운 곳에 둠. 시간이 지나면 효력이 떨어짐 |
| 사용 | 곱게 빻아 가루로 뿌리거나, 태워서 연기를 내거나, 물·기름·알코올에 우려 사용 |
| 잔류 | 빛에 빠르게 분해되어 잔류가 거의 없음 |

- 빛에 분해되는 성질은 장점이자 단점입니다. 환경에 남지 않고 식품 주변에서도 비교적 안전하지만, 지속 효과가 거의 없어 매번 새로 써야 합니다.
- 피레트린은 어류와 고양이에게 독성이 강합니다. 수조 근처나 고양이가 있는 공간에서는 주의합니다.

| 그 밖의 식물 | 성분과 작용 | 실제 유용성 |
| --- | --- | --- |
| 님(neem) | 아자디라크틴. 섭식 저해와 성장 교란 | 즉시 죽이지는 않고 개체군을 서서히 줄임 |
| 계피 | 신남알데하이드. 기피와 유충 살충 | 유충 살충 효과가 보고되어 있음 |
| 정향 | 유제놀. 기피 | 향이 강해 단시간 기피에 유용 |
| 시트로넬라·레몬그라스 | 시트로넬랄, 제라니올 | 기피 효과는 분명하나 지속 시간이 짧음 |
| 유칼립투스 | 시네올 | 기피에 쓰이며 원액은 피부 자극이 있음 |

> **주의:** 담뱃잎 침출액은 권하지 않습니다. 니코틴은 강력한 살충 성분이지만 사람에게도 강한 신경독입니다. 피부로 잘 흡수되어 침출액을 맨손으로 다루는 것만으로 구역질, 어지럼, 심박 이상이 나타날 수 있습니다(담뱃잎 수확 노동자의 녹색담배병). 해독제도 없고 농도를 가늠할 방법도 없는 재난 상황에서는 얻는 것보다 잃는 것이 훨씬 큽니다.
