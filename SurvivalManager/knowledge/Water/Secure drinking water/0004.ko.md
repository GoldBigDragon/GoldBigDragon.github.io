## 3. 식수 보관
---
### 3-1. 저장 용기 선택
&nbsp;&nbsp;&nbsp;식수 저장 용기는 튼튼하고 깨지지 않으며, 식품 보관에 적합한 재질이어야 합니다. 특히 휘발유, 살충제, 세제, 윤활유 등 독성 물질을 담았던 용기는 아무리 깨끗하게 세척하더라도 식수 보관 용도로 사용해서는 안 됩니다.  

| 용기 | 내용 |
| --- | --- |
| 상업용 생수병 | 개봉하지 않은 상업용 생수가 가장 안전하고 신뢰할 수 있는 비상 수원입니다. 단, 얇은 PET 병은 장기간 사용 시 변형되거나 균열이 발생할 수 있으며, 반복 재사용에는 적합하지 않습니다. |
| 식품 등급 용기 | 식품 등급 용기는 식수 장기 보관에 적합합니다. |
| HDPE 용기 | HDPE 용기는 내구성과 내화학성이 뛰어나 식수 보관에 널리 사용됩니다. 단, 식품용으로 인증된 제품인지 반드시 확인해야 합니다. |
| 파란색 물탱크 | 식수 저장용으로 제작된 파란색 물탱크는 장기 보관에 적합하며, 대용량 비축에 유리합니다. |
| 유리병 | 화학물질 용출 우려가 없고 세척이 용이하여 장기 보관에 적합합니다. 단, 충격에 약하고 물이 얼면 파손될 수 있습니다. |
| 스테인리스 텀블러 | 내구성이 뛰어나고 빛을 완벽히 차단하여 녹조 발생을 억제합니다. 단, 염소계 표백제(락스)를 섞어 소독한 물을 장기간 보관하면 부식될 수 있습니다. |
| 음료수 병 | 식품용으로 사용 가능하지만, 당분이나 향료 등의 잔류물이 남아 있으면 세균이 번식할 수 있으므로 사용 전 충분히 세척하고 건조해야 합니다. |
| 도자기 | 온도를 서늘하게 유지하는 데 유리하지만, 완전한 밀폐가 어렵고, 무거워서 이동이 불편합니다. |
| 우유팩·우유통 | 우유 단백질과 지방이 내부에 남기 쉬워 완전한 세척이 어렵고, 세균 증식 위험이 있으므로 장기 저장에는 권장되지 않습니다. |
| 식품용 지퍼백 | 단기 보관이나 냉동 보관에는 적합하지만, 쉽게 찢어질 수 있어 주력 저장 용기로는 부적합합니다. |
| 접이식 물통 | 보관 공간을 적게 차지하지만, 재질이 얇아 파손되기 쉽고 내부 세척과 건조가 어렵습니다. |
| 김치통·플라스틱 밀폐용기 | 식품용 제품은 안전하고 밀폐력이 우수하지만, 음식 냄새가 배어 물맛에 영향을 줄 수 있습니다. |
| 식품용 대용량 드럼통 | 식용유, 시럽 등을 담았던 식품용 용기는 재사용이 가능합니다. 단, 냄새와 잔류물을 완전히 제거해야 합니다. |
| 공업용 대용량 드럼통 | 세제, 윤활유, 부동액, 화학약품 등을 담았던 용기는 세척 후에도 독성 물질이 잔류할 수 있으므로 절대 식수 저장 용도로 사용해서는 안 됩니다. |

---
### 3-2. 저장 용기 세척
&nbsp;&nbsp;&nbsp;저장 용기에 식수를 담기 전에 반드시 세척 및 소독 과정을 거쳐야 미생물 성장을 방지할 수 있습니다. 장기 보관을 고려한다면 표백제(차아염소산나트륨 5-9%)를 물 1L당 2방울 첨가하여 보관합니다.  

| 단계 | 내용 |
| --- | --- |
| 1. 세척 | 용기를 비누와 물로 깨끗이 씻고 완전히 헹굽니다. |
| 2. 소독액 제조 | 물 1L당 향료, 세정제, 색상 보호제 등의 첨가물이 없는 표백제(차아염소산나트륨 5%) 약 5mL를 섞어 약 250ppm 수준의 소독액을 만듭니다. |
| 3. 소독 | 소독액을 용기에 붓고 뚜껑을 닫아 용기 내부 전체 표면에 닿도록 흔듭니다. |
| 4. 대기 및 배출 | 최소 30초 동안 기다린 후 소독액을 버립니다. |
| 5. 건조 및 보관 | 용기를 자연 건조 또는 소독액을 버린 뒤 깨끗한 물로 헹군 후, 식수를 채우고 밀봉합니다. |

### 3-3. 저장 환경 관리
&nbsp;&nbsp;&nbsp;저장된 물은 시간이 지나면서 주변 환경의 영향을 받을 수 있으므로, 수질 유지를 위해 적절한 보관 환경과 정기적인 관리가 필요합니다.  

| 항목 | 내용 |
| --- | --- |
| 온도 | 높은 온도는 플라스틱 노화와 미생물 증식 가능성을 높이기 때문에, 10-21°C 사이의 서늘하고 온도 변화가 크지 않은 장소에 보관합니다. |
| 빛 | 플라스틱을 열화 시키고, 용기 내부에 조류(Algae) 성장을 촉진 시키는 직사광선이 닿지 않도록 어두운 곳에 보관해야합니다. |
| 위치 | 식품용 HDPE 용기는 콘크리트 바닥과 직접 접촉해도 큰 문제는 없지만, 습기와 오염 방지를 위해 선반, 팔레트 등 바닥에 닿지 않도록 보관하는 것이 좋습니다. |
| 화학 물질 | 가솔린, 살충제, 페인트, 세제, 비료 등 휘발성 화학 물질 근처에 보관하면 화학 증기가 플라스틱을 투과하여 물을 오염시킬 수 있으므로, 반드시 격리보관해야합니다. |
| 점검 | 용기에 저장 날짜를 표시하여 6-12개월마다 용기를 점검하고, 냄새가 나거나 변색된 식수는 교체하는 것이 좋습니다. 교체한 물은 청소용수나 농업용수 등으로 활용할 수 있습니다. |
| 2차 오염 방지 | 손이나 오염된 컵을 용기 내부에 넣지 않습니다. 수도꼭지가 부착된 저장 용기를 사용하거나, 물을 덜어낼 전용 국자를 준비하여 오염 위험을 줄일 수 있습니다. |
| 정화 수단 준비 | 저장된 물이 항상 안전하다고 가정해서는 안 됩니다. 비상 상황에 대비하여 끓이기 도구, 정수 필터, 정수제 등 서로 다른 방식의 정화 수단을 최소 두 가지 이상 준비하는 것이 좋습니다. |
| 산소 재공급 | 장기 저장된 물은 용존산소가 부족해 맛이 밋밋하게 느껴질 수 있습니다. 마시기 전에 깨끗한 두 용기 사이를 오가며 물을 몇 번 따르면 산소가 공급되어 물맛이 개선될 수 있습니다. |
