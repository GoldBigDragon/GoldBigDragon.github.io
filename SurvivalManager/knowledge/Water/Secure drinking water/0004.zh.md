## 3. 饮用水贮藏
---
### 3-1. 储水容器选择
&nbsp;&nbsp;&nbsp;饮用水贮藏容器必须质地坚固、不易破裂，且材质须符合食品接触标准。特别是曾盛装过汽油、杀虫剂、洗涤剂、润滑油等毒性物质的容器，无论清洗得多么干净，都绝不可用于饮用水的贮藏。  

| 容器 | 内容 |
| --- | --- |
| 商业瓶装水瓶 | 未开封的商业瓶装水是最安全、最值得信赖的应急水源。但由于薄款 PET 塑料瓶在长期存放时可能会发生变形或产生裂纹，因此不适合反复再使用。 |
| 食品级容器 | 食品级容器是饮用水长期贮藏的理想选择。 |
| HDPE 容器 | HDPE（高密度聚乙烯）容器由于具有极佳的耐用性 and 耐化学性，被广泛用于饮用水贮藏。但使用前必须确认其是否通过食品级认证。 |
| 蓝色储水箱 | 专门针对饮用水贮藏制造的蓝色水箱适合长期保存，有利于大容量非电力备。 |
| 玻璃瓶 | 不存在释放化学物质的隐患，且易于清洗，适合长期保存。但缺点是不抗冲击，且水结冰时可能会导致其破裂。 |
| 不锈钢保温杯 | 耐用性极佳，且能完美阻隔光线，可有效抑制藻类（绿藻）滋生。但若在其中长期存放混有氯系 bleach（消毒液）的水，可能会引发腐蚀。 |
| 饮料瓶 | 虽然属于食品接触材质，但若内部残留糖分或香料等，极易导致细菌滋生，因此使用前必须进行充分的清洗 context 和干燥。 |
| 陶瓷器具 | 有利于将水温保持在微凉状态，但缺点是难以实现绝对密封，且器身沉重、搬运不便。 |
| 牛奶盒、牛奶桶 | 牛奶蛋白 inside 和脂肪极易残留于内部，导致彻底清洗极其困难，存在细菌滋生风险，故不推荐用于长期贮藏。 |
| 食品级自封袋 | 虽然适合短期保存或冷冻保存，但由于容易破裂，不宜作为主力的储水容器。 |
| 折叠水袋 | 虽然占用空间少，但材质较薄易破损，且内部的清洗 and 干燥较为困难。 |
| 泡菜桶、塑料保鲜盒 | 属于食品级产品，安全性高且密封性能优异，但可能会有残留的食物味道影响到水质口感。 |
| 食品级大容量桶 | 曾盛装过食油、糖浆等食品的工业级/大容量容器可以洗净后再使用。但前提是必须完全清除异味和残留物。 |
| 工业用大容量桶 | 曾盛装过洗涤剂、润滑油、防冻液、化学药剂等的容器，即使经过清洗，毒性物质仍可能发生残留，因此绝对禁止用于饮用水的贮藏。 |

---
### 3-2. 储水容器清洗
&nbsp;&nbsp;&nbsp;在向储水容器中灌入饮用水之前，必须先经过洗涤 and 消毒程序，以防范微生物滋生。若考虑长期贮藏，可按每 1L 水加 2 滴的比例添加漂白剂（次氯酸钠 5-9%）后密封保存。  

| 步骤 | 内容 |
| --- | --- |
| 1. 洗涤 | 利用肥皂和水将容器彻底清洗干净，并用清水完全冲洗净。 |
| 2. 配制消毒液 | 按每 1L 水混入约 5mL 纯净漂白剂（次氯酸钠 5%，不含香料、洗涤剂、护色剂等添加剂）的比例，配制出浓度约为 250ppm 的消毒液。 |
| 3. 消毒 | 将配制好的消毒液倒入容器中，盖紧盖子并用力摇晃，确保消毒液完全接触到容器内部的整个表面。 |
| 4. 等待与摒弃 | 至少静置等待 30 秒，随后将消毒液倒掉。 |
| 5. 干燥与贮藏 | 将容器置于空气中自然晾干，或者倒掉消毒液后用干净的水冲洗净，随后灌满饮用水并进行紧密密封。 |

---
### 3-3. 贮藏环境管理
&nbsp;&nbsp;&nbsp;贮藏的水随着时间的推移可能会受到周边环境的影响，因此为了维持水质，必须保持适宜的贮藏环境并进行定期管理。  

| 项目 | 内容 |
| --- | --- |
| 温度 | 高温会加速塑料老化并增加微生物滋生的可能性，因此应将其存放在 10-21°C 之间、温度没有剧烈变化的阴凉处。 |
| 光线 | 为了防范塑料老化退化、以及防止容器内部产生藻类（Algae）滋生，必须将其存放在阳光无法直射的黑暗处。 |
| 位置 | 虽然食品级 HDPE 容器直接接触混凝土水泥地面没有太大问题，但为了防潮 and 预防二次污染，最好利用层架、托盘等将其垫高，避免直接接触地面。 |
| 化学物质 | 若将其存放在汽油、杀虫剂、油漆、洗涤剂、肥料等挥发性化学物质附近，化学蒸汽可能会透过塑料污染水质，因此必须进行严格的隔离贮藏。 |
| 检查 | 最好在容器上标明开始贮藏的日期，每隔 6-12 个月定期检查一次容器，一旦发现水产生异味或发生变色，应立即进行更换。换下来的水可以转作清扫用水或农业灌溉用水。 |
| 防范二次污染 | 严禁将手或不干净的杯子直接伸入储水容器内部。通过使用附带水龙头的储水容器，或者准备一把专用的长柄水瓢来舀水，可以有效降低污染风险。 |
| 准备多样化精制手段 | 切勿盲目假设贮藏的水永远绝对安全。为了应对紧急情况，最好同时准备至少两种以上不同方式的净水手段，如煮沸工具、净水过滤器、净水药剂等。 |
| 重新充氧 | 长期贮藏的水由于内部缺乏溶解氧，饮用时口感可能会显得平淡乏味。在饮用前，可以在两个干净的容器之间来回交替倒水数次，从而将空气中的氧气重新带入水中，以此改善水质口感。 |
