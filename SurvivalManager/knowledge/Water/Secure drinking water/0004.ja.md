## 3. 飲料水の保管
---
### 3-1. 貯蔵容器の選択
&nbsp;&nbsp;&nbsp;飲料水の貯蔵容器は頑丈で破損しにくく、食品保管に適した材質でなければなりません。特にガソリン、殺虫剤、洗剤、潤滑油などの毒性物質を入れていた容器は、いかにきれいに洗浄したとしても、飲料水保管の用途に使用してはなりません。  

| 容器 | 内容 |
| --- | --- |
| 市販のペットボトル | 開封していない市販のペットボトル水が、最も安全で信頼できる非常用水源です。ただし、薄いPETボトルは長期間使用すると変形したり亀裂が発生したりすることがあり、繰り返しの再利用には適していません。 |
| 食品グレードの容器 | 食品グレードの容器は、飲料水の長期保管に適しています。 |
| HDPE容器 | HDPE容器は耐久性と耐化学性に優れ、飲料水の保管に広く使用されています。ただし、食品用として認証された製品であるか必ず確認しなければなりません。 |
| 青色の給수탱크（給水タンク） | 飲料水貯蔵用に製造された青色の給水タンクは長期保管に適しており、大容量の備蓄に有利です。 |
| ガラス瓶 | 化学物質の溶出の懸念がなく、洗浄が容易なため長期保管に適しています。ただし、衝撃に弱く、水が凍結すると破損する恐れがあります。 |
| ステンレスボトル | 耐久性に優れ、光を完全に遮断して緑藻の発生を抑制します。ただし、塩素系漂白剤を混ぜて消毒した水を長期間保管すると、腐食する原因になります。 |
| 飲料の空き瓶 | 食品用として使用可能ですが、糖分や香料などの残留物が内部に残っていると細菌が繁殖する可能性があるため、使用前に十分に洗浄し、乾燥させなければなりません。 |
| 陶磁器 | 温度を涼しく維持するのに有利ですが、完全な密閉が困難であり、重量が重いため移動が不便です。 |
| 牛乳パック・牛乳容器 | 牛乳のタンパク質や脂肪が内部に残りやすく完全な洗浄が困難であり、細菌繁殖のリスクがあるため、長期貯蔵には推奨されません。 |
| 食品用のジッパーバッグ | 短期保管や冷凍保管には適していますが、破れやすいため主力の貯蔵容器としては不向きです。 |
| 折りたたみ式水タンク | 保管スペースをとらないですが、材質が薄いため破損しやすく、内部の洗浄や乾燥が困難です。 |
| キムチ容器・プラスチック密閉容器 | 食品用の製品は安全で密閉性に優れていますが、食品の臭いが移り、水の味に影響を与えることがあります。 |
| 食品用の大容量ドラム缶 | 食用油、シロップなどを入れていた食品用の容器は再利用が可能です。ただし、臭気や残留物を完全に除去しなければなりません。 |
| 工業用の大容量ドラム缶 | 洗剤、潤滑油、不凍液、化学薬品などを入れていた容器は、洗浄後であっても毒性物質が残留する可能性があるため、絶対に飲料水の貯蔵用途に使用してはなりません。 |

---
### 3-2. 貯蔵容器の洗浄
&nbsp;&nbsp;&nbsp;貯蔵容器に飲料水を満たす前に、必ず洗浄および消毒の工程を経なければ微生物の繁殖を防止できません。長期保管を考慮するならば、漂白剤（次亜塩素酸ナトリウム5〜9%）を水1Lあたり2滴添加して保管します。  

| 段階 | 内容 |
| --- | --- |
| 1. 洗浄 | 容器を石鹸と水できれいに洗い、完全にすすぎます。 |
| 2. 消毒液の製造 | 水1Lあたり、香料、洗浄剤、着色保護剤などの添加物のない漂白剤（次亜塩素酸ナトリウム5%）約5mLを混ぜ合わせ、約250ppm水準の消毒液を作ります。 |
| 3. 消毒 | 消毒液を容器に注ぎ、蓋を閉めて容器内部の表面全体に行き渡るように振ります。 |
| 4. 待ち時間および排出 | 最低でも30秒間待った後、消毒液を廃棄します。 |
| 5. 乾燥および保管 | 容器を自然乾燥させるか、または消毒液を廃棄した後に清潔な水ですすいだ後、飲料水を充填して密閉します。 |

---
### 3-3. 貯蔵環境の管理
&nbsp;&nbsp;&nbsp;貯蔵された水は、時間の経過とともに周囲の環境の影響を受ける可能性があるため、水質維持のために適切な保管環境と周期的な管理が必要です。  

| 項目 | 内容 |
| --- | --- |
| 温度 | 高温はプラスチックの劣化や微生物の繁殖の可能性を高めるため、10〜21°Cの間の涼しく温度変化が大きくない場所に保管します。 |
| 光 | プラスチックを劣化させ、容器内部に藻類（Algae）の繁殖を促進させる直射日光が当たらないよう、暗い場所に保管しなければなりません。 |
| 位置 | 食品用のHDPE容器はコンク리트（コンクリート）の床に直接接触しても大きな問題はないですが、湿気や汚染の防止のため、棚やパレットなど床に触れないように保管することが望ましいです。 |
| 化学物質 | ガソリン、殺虫剤、塗料、洗剤、肥料などの揮発性化学物質の近くに保管すると、化学蒸気がプラスチックを透過して水を汚染させる可能性があるため、必ず隔離して保管しなければなりません。 |
| 点検 | 容器に貯蔵した日付を表示し、6〜12ヶ月ごとに容器を点検し、臭気がしたり変色したりした飲料水は交換することが望ましいです。交換した水は清掃用水や農業用水などとして活用できます。 |
| 二次汚染の防止 | 手や汚染されたコップを容器の内部に入れてはなりません。蛇口が取り付けられた貯蔵容器を使用するか、または水を汲み出す専用のひしゃくを準備することで、汚染のリスクを低減できます。 |
| 浄水手段の準備 | 貯蔵された水が常に安全であると仮定してはなりません。非常事態に備えて、煮沸用の道具、浄水フィルター、浄化剤など、異なる方式の浄水手段を最低でも2種類以上準備することが望ましいです。 |
| 酸素の再供給 | 長期貯蔵された水は溶存酸素が不足し、味が淡白（物足りなく）に感じられることがあります。飲む前に、清潔な二つの容器の間を行き来させるように水を数回注ぐと、酸素が供給されて水の味が改善されることがあります。 |
