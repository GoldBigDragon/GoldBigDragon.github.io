## 1. 水の確保
&nbsp;&nbsp;&nbsp;水道水の供給が中断されたり汚染が発生したりした際は、市販のペットボトル水（未開封）、浄水器のタンク、冷凍庫の氷、缶詰のスープなど、安全が保障された水源を優先的に利用することが望ましいです。

---
### 1-1. 代替水源
&nbsp;&nbsp;&nbsp;安全が保障された水源を確保できない場合、最後の手段として下記の項目から水を確保することができます。下記の項目は、非常時に水を確保できる水源に過ぎず、飲用可能かどうかは分かりません。適切な浄水または消毒の工程を経たとしても、化学的汚染物質は除去されない場合があり、安全性を保障できないため、可能な場合は洗浄・清掃などの衛生目的としてのみ使用しなければなりません。  

&nbsp;&nbsp;&nbsp;浮遊物質、異臭、暗い色のある水は避けなければなりません。燃料、農薬、毒性化学物質、または放射性物質で汚染された水は、煮沸、濾過、消毒などの方法でも安全にすることはできないため、確保してはなりません。戦争地域では、爆発、施設の破壊、下水の流出などによって水源が化学的・生物学的に汚染される可能性があるため、水源の選択には格別の注意が必要です。  

| 水源 | 備考 |
| --- | --- |
| 雨水 | 雨水受けのタンクに集めて確保します。屋根や樋（とい）を通じて確保する場合、鳥の排泄物、ほこり、金属成分などが混入する恐れがあります。 |
| 川、湖 | 流速が速い地点を優先して確保します。ただし、上流の汚染状況を確認できない場合は安全性を保障できません。 |
| 浴槽 | 災害発生直後に水道水で満たしておいた場合は比較的汚染の可能性が低いですが、長期間放置された水は細菌繁殖のリスクがあります。 |
| 霧（露） | 日が昇る前に、布やタオルなど吸水性の良い織物を利用して、ほこりや汚染物質のない植物、金属板、ビニール、テント、プラスチックシートなど清潔な表面の露を集めます。農耕地、道路脇、産業施設の周辺は避けなければなりません。 |
| 温水器のタンク | 電源および温水供給源をまず遮断した後、沈殿物は廃棄し、比較的透明な水だけを使用します。ただし、暖房水と連結されたシステムであるかどうかを確認できない場合は確保を推奨しません。 |
| 配管の残留水 | 家の中で最も低い場所にある蛇口を開けて残留水を確保します。配管の汚染状況の確認が不可能な場合は、確保しません。 |
| ペットの給水器 | ペットの唾液が混ざり、細菌汚染の可能性が高いです。 |
| 加湿器のタンク | 細菌およびカビが繁殖する可能性が高いです。 |
| プール | 塩素や化学薬品による汚染のリスクが高いため、洗浄、清掃などの衛生目的としてのみ確保します。 |
| ウォーターベッド | 殺藻剤や防腐剤が含まれている可能性が高いです。 |
| 除湿機の凝縮水 | 金属成分、カビ、細菌などによる汚染の可能性があります。 |
| 花瓶の水 | 栄養剤・細菌汚染の可能性が高いです。 |
| 水槽の水 | 硝酸塩・排泄物が含まれている可能性が高いです。 |
| 植木鉢の受け皿の水 | 肥料・細菌汚染の可能性が高いです。 |
| 便器のタンク | 用便を足す便器ではなく、便器の後方にある水タンクの水だけを使用しなければなりません。化学洗浄剤がない場合にのみ確保可能ですが、細菌、沈殿物、および金属成分による汚染의（汚染の）可能性があります。 |
| ボイラーの暖房水 | 不凍液、防錆剤、腐食抑制剤などが含まれる可能性があるため確保しません。 |
| ラジエーターの水 | 不凍液、防錆剤、腐食抑制剤などが含まれる可能性があるため確保しません。 |

### 1-2. 水分の捕集
&nbsp;&nbsp;&nbsp;周辺に代替水源が不足している場合、自然な蒸発・凝結現象や植物の蒸散作用を利用して、少量の水を確保することができます。ただし、下記の方法は一般的に大量の水を確保することが難しく、確保した水は一般的に原水より清潔ですが、設置環境や汚染の有無によって安全性を保障できないため、可能な限り浄水・消毒の工程を経て使用しなければなりません。  

&nbsp;&nbsp;&nbsp;水分捕集の方法だけで成人1人が1日に必要な水分を確保することは困難であるため、水分捕集は主な水源確保の手法ではなく補助的な手段として活用しなければならず、可能な場合は複数を同時に設置して確保量を増やさなければなりません。  

![image](./media/Water_Harvesting.png)  

| 方法 | 内容 |
| --- | --- |
| 蒸散バッグ | 毒性がなく、葉が多い健康な枝に透明なビニール袋を被せて密閉します。日光による植物の蒸散作用によりビニール内部に水滴が結露し、気象条件や植物の状態によって異なりますが、1日に約50mLの水を確保できます。 |
| 植物バッグ | 毒性のない草、葉など比較的安全な植物材料を透明なビニール袋に入れて密閉し、日光に露出させます。植物表面の汚染物質が凝縮水に混入する可能性があるため注意が必要であり、1日に約50mLの水を確保できます。 |
| 太陽熱蒸留 | ビニールと水を溜める容器を利用し、土壌や植物の水分を蒸発・凝縮させて水を確保する方法です。窪みの表面積が大きいほど集水面積が広くなり、内部に水分を含有した物質が多いほど蒸発量が多くなります。良好な環境条件下で1日に約250mLの水を確保できますが、土壌の水分含有量が低かったり気温が低かったりする場合は、確保量がこれより少なくなることがあります。ビニールの密閉処理が不十分だと効率が低下し、同じ位置で繰り返し使用すると土壌内の水分が減少して生産量が徐々に減少することがあります。 |
