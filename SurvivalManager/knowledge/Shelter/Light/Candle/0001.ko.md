# 양초
---
## 1. 원리
&nbsp;&nbsp;&nbsp;양초가 불을 밝히는 원리는 물리적인 현상에 기반합니다. 심지는 수많은 미세한 섬유질로 이루어져 있으며, 불이 붙으면 심지 주변의 연료가 액화되어 모세관 현상에 의해 심지의 미세한 틈을 따라 위로 빨려 올라갑니다.  

&nbsp;&nbsp;&nbsp;심지 끝에 도달한 액체 연료는 불꽃의 열에 의해 기체 상태로 변합니다. 이 기화된 연료가 공기 중의 산소와 결합하여 연소(불꽃)를 일으키며 빛과 열을 방출합니다.  

&nbsp;&nbsp;&nbsp;불꽃의 열은 계속해서 아래쪽의 고체 왁스나 액체 기름을 녹여 모세관 현상을 통해 심지로 끌어올리는 순환 구조를 만듭니다.

---
## 2. 재료
&nbsp;&nbsp;&nbsp;양초를 제작할 때 사용되는 재료는 연료, 심지, 용기로 나뉩니다. 초기 양초 제작 시에는 동물성 지방(소 지방, 돼지 지방, 밀랍)을 연료로 사용했으며, 현대에는 파라핀, 밀랍, 그리고 콩기름에서 추출한 소이 왁스 등 다양한 재료가 사용되고 있습니다.

&nbsp;&nbsp;&nbsp;면사, 종이, 천, 심지어 감귤류의 섬유질을 심지로 사용할 수 있습니다. 다만 인쇄된 종이(예: 신문지)의 경우 그을음이 많으며 연소 중 불티 발생 위험이 있으므로 주의해야 합니다.

&nbsp;&nbsp;&nbsp;양초 용기는 기름이나 왁스가 새어 나가지 않는 유리, 캔, 세라믹을 사용할 수 있으며, 플라스틱, 나무 등은 열에 취약하므로 사용하지 않는 것이 좋습니다.

---
## 3. 주의사항
&nbsp;&nbsp;&nbsp;양초를 제작하고 운용할 때는 화재 및 건강상의 위험을 최소화하기 위해 안전 수칙을 반드시 준수해야 합니다.

&nbsp;&nbsp;&nbsp;양초 사용 전, 주변에 불이 붙을 만한 가연성 물질을 제거하고, 자리를 비울 때는 양초를 끄고 나갑니다.  

&nbsp;&nbsp;&nbsp;양초 바닥은 뜨거워질 수 있으므로, 나무나 열에 민감한 표면에 직접 두지 말고, 슬레이트나 내열 받침대를 사용해야 합니다.  

&nbsp;&nbsp;&nbsp;직접 만든 비상용 양초는 그을음 및 미립자를 발생시키거나 환기 부족 위험이 있으므로, 실내 사용 시 반드시 주기적인 환기가 필요합니다.

&nbsp;&nbsp;&nbsp;양초를 태우기 전, 심지를 항상 0.6cm 길이로 다듬어야 합니다. 심지가 너무 길면 불꽃이 너무 높고 흔들리며, 그을음과 버섯 모양 의 탄소 축적이 발생하여 과열을 유발할 수 있습니다.  

&nbsp;&nbsp;&nbsp;기름을 이용한 비상용 양초의 경우, 안전을 위해 연속 연소 4시간을 초과하지 않도록 주의합니다.

## 4. 제작
### 4-1. 참치캔 양초
| 순서 | 방법 |
| :---: | :--- |
| 1 | 식용유에 절인 참치캔과 면 끈을 준비합니다. |
| 2 | 면 끈을 참치캔 높이보다 약간 길게 자릅니다. |
| 3 | 캔 뚜껑 중앙에 작은 구멍을 뚫고, 면 끈 심지를 구멍에 넣어 기름에 충분히 적십니다. |
| 4 | 심지 끝부분에 불을 붙여 연소시킵니다. |

### 4-2. 오렌지 껍질 양초
| 순서 | 방법 |
| :---: | :--- |
| 1 | 오렌지나 자몽을 반으로 자른 후, 과육을 조심스럽게 분리하여 중심부의 흰 심지를 손상시키지 않고 껍질 바닥에 남겨둡니다. |
| 2 | 심지 끝부분만 공기에 노출될 정도로 껍질 용기에 식용유를 채웁니다. |
| 2 | 심지 상단에 식용유를 살짝 발라 점화가 잘 되도록 합니다. |
| 3 | 심지 끝부분에 불을 붙여 연소시킵니다. |

### 4-3. 버터 양초
| 순서 | 방법 |
| :---: | :--- |
| 1 | 버터 블록에서 적당한 크기를 잘라냅니다. |
| 2 | 얇은 드라이버나 송곳으로 중앙에 깊게 구멍을 뚫습니다. |
| 3 | 심지를 구멍에 끼우고, 심지 상단에 버터를 살짝 발라 점화가 잘 되도록 합니다. |
| 4 | 심지 끝부분에 불을 붙여 연소시킵니다. |

### 4-4. 왁스 양초
| 순서 | 방법 |
| :---: | :--- |
| 1 | 성형 틀의 부피에 맞게 왁스를 계량합니다. |
| 2 | 왁스를 70-80°C까지 중탕하되, 온도가 90°C를 넘지 않도록 주의합니다. |
| 3 | 왁스가 70°C에 도달하면 불에서 내립니다. |
| 4 | 향료가 있을 경우, 부피(ml)가 아닌 무게(g) 기준으로 왁스 중량 대비 6%의 향료를 계량하여 혼합합니다. |
| 5 | 향료를 첨가한 후 2분 동안 부드럽게 저어 향료가 왁스에 물리적으로 분산/용해되도록 합니다. |
| 6 | 왁스가 약간 불투명해지는 약 55-60°C 또는 왁스 제조사가 권장하는 적정 주입 온도까지 식을 때까지 기다립니다. |
| 7 | 왁스를 성형 틀 중앙에 천천히, 꾸준히 부어 표면 수축을 방지합니다. |
| 8 | 왁스가 굳는 동안 심지를 중앙에 고정하고, 온도 변화가 없는 공간에서 최소 24시간 냉각시킵니다. |
| 9 | 초기 경화 과정이 끝난 양초는 품질 향상을 위해 3-14일 동안 숙성시킵니다. |

## 5. 원료 추출 방법
&nbsp;&nbsp;&nbsp;비상 상황에서 상업용 왁스를 구할 수 없을 때, 주변에서 얻을 수 있는 천연 재료를 정제하여 양초 연료로 활용할 수 있습니다.

### 5-1. 동물성 왁스 추출
| 순서 | 방법 |
| :---: | :--- |
| 1 | 소(탈로우)나 돼지(라드)의 지방 조직을 깨끗이 씻어 불순물을 제거합니다. |
| 2 | 지방을 최대한 잘게 썰어 열이 닿는 면적을 넓힙니다. |
| 3 | 냄비에 아주 적은 양의 물과 지방을 넣고 약한 불로 중탕합니다. |
| 4 | 지방이 녹아 액체가 되면 고운 천이나 망으로 찌꺼기를 걸러냅니다. |
| 5 | 걸러낸 액체를 식히면 고체 형태의 천연 동물성 왁스가 됩니다. |

### 5-2. 벌집 밀랍 추출
| 순서 | 방법 |
| :---: | :--- |
| 1 | 꿀을 채취하고 남은 벌집(밀랍)을 물에 넣고 85°C 이하로 가열합니다. |
| 2 | 밀랍이 완전히 녹으면 뜨거운 상태에서 천으로 불순물을 여과합니다. |
| 3 | 여과된 용액을 그대로 식히면 밀랍이 물보다 가벼워 상단에 층을 이루며 굳습니다. |
| 4 | 굳은 밀랍 판을 떼어내어 하단의 불순물을 긁어내고 다시 한번 정제하여 사용합니다. |
