# 蜡烛
---
## 1. 原原理
&nbsp;&nbsp;&nbsp;蜡烛发光的原理基于物理现象。烛芯由无数微小的纤维组成，点燃后，烛芯周围的燃料发生液化，通过毛细现象沿着烛芯的微小缝隙向上吸取。  

&nbsp;&nbsp;&nbsp;到达烛芯末端的液体燃料受火焰热量影响转化为气态。这种气化燃料与空气中的氧气结合引发燃烧（火焰），并释放出光 and 热。  

&nbsp;&nbsp;&nbsp;火焰的热量持续熔化下方固态的蜡或液态的油，通过毛细现象将其引向烛芯，从而形成循环结构。

---
## 2. 材料
&nbsp;&nbsp;&nbsp;制造蜡烛时使用的材料分为燃料、烛芯 and 容器。在早期制造蜡烛时，人们使用动物脂肪（牛脂、猪脂、蜂蜡）作为燃料；而在现代，则使用石蜡、蜂蜡以及从豆油中提取的大豆蜡等多种材料。

&nbsp;&nbsp;&nbsp;棉线、纸、布、甚至柑橘类的纤维都可以用作烛芯。但如果是带有印刷的纸（如报纸），由于其烟尘较多且在燃烧过程中存在引发火星的危险，因此须格外注意。

&nbsp;&nbsp;&nbsp;蜡烛容器可以使用不易漏油或漏蜡的玻璃、铁罐、陶瓷；而塑料、木材等由于不耐热，最好不要使用。

---
## 3. 注意事项
&nbsp;&nbsp;&nbsp;在制造 and 动用蜡烛时，必须严格遵守安全守则，以最大程度减少火灾及健康风险。

&nbsp;&nbsp;&nbsp;使用蜡烛前，须清除周围可燃的易燃物质；离开时，必须将蜡烛熄灭后再行外出。  

&nbsp;&nbsp;&nbsp;由于蜡烛底部可能会变得炽热，切勿将其直接放置在木材或对热敏感的表面上，必须使用石板或耐热垫。  

&nbsp;&nbsp;&nbsp;自制的应急蜡烛可能会产生烟尘及微粒，或者存在通风不足的危险，因此在室内使用时必须定期进行通风。

&nbsp;&nbsp;&nbsp;点燃蜡烛前，必须始终将烛芯修剪至 0.6cm 的长度。如果烛芯过长，火焰会过高且发生摇晃，并且会产生烟尘 and 蘑菇状的碳积聚，从而可能引发过热。  

&nbsp;&nbsp;&nbsp;如果是利用油脂制作的应急蜡烛，为安全起见，注意连续燃烧时间不要超过 4 小时。

## 4. 制造
### 4-1. 金枪鱼罐头蜡烛
| 步骤 | 方法 |
| :---: | :--- |
| 1 | 准备好浸油的金枪鱼罐头 and 棉绳。 |
| 2 | 将棉绳裁剪得比金枪鱼罐头的高度略长一些。 |
| 3 | 在罐头盖中央钻一个小孔，将棉绳烛芯插入孔中，使其充分浸润油脂。 |
| 4 | 点燃烛芯末端使其燃烧。 |

### 4-2. 橙皮蜡烛
| 步骤 | 方法 |
| :---: | :--- |
| 1 | 将橙子或葡萄柚切成两半，随后小心地剥离果肉，在不破坏中心部位白色髓心的前提下，将其保留在果皮底部。 |
| 2 | 向果皮容器中注入食油，注入量以烛芯顶端刚好暴露在空气中为准。 |
| 3 | 在烛芯上端稍微涂抹少许食油，以便于点燃。 |
| 4 | 点燃烛芯末端使其燃烧。 |

### 4-3. 黄油蜡烛
| 步骤 | 方法 |
| :---: | :--- |
| 1 | 从黄油块上切下合适的大小。 |
| 2 | 用细螺丝刀或锥子在正中央深深地钻一个孔。 |
| 3 | 将烛芯插入孔中，并在烛芯上端稍微涂抹少许黄油，以便于点燃。 |
| 4 | 点燃烛芯末端使其燃烧。 |

### 4-4. 蜡烛
| 步骤 | 方法 |
| :---: | :--- |
| 1 | 根据模具的体积称量好蜡。 |
| 2 | 将蜡隔水加热至 70-80°C，注意温度不要超过 90°C。 |
| 3 | 当蜡的温度达到 70°C 时，将其从火上移开。 |
| 4 | 如果有香精，以重量（g）而非体积（ml）为准，称量相当于蜡重量 6% 的香精并进行混合。 |
| 5 | 添加香精后，轻轻搅拌 2 分钟，使香精在蜡中实现物理分散/溶解。 |
| 6 | 等待蜡冷却至开始变得微不透明的约 55-60°C，或者冷却至蜡制造商推荐的适宜浇注温度。 |
| 7 | 将蜡缓缓地、稳定地注入模具中央，以防止表面发生收缩。 |
| 8 | 在蜡固化期间，将烛芯固定在中央，并在温度没有剧烈变化的空气空间中冷凉至少 24 小时。 |
| 9 | 结束初期固化过程的蜡烛，为了提升品质，须使其熟化 3-14 天。 |

## 5. 原料提取方法
&nbsp;&nbsp;&nbsp;在无法获取商业蜡的紧急情况下，可以通过精炼从周边获取的天然材料来将其转化为蜡烛燃料。

### 5-1. 动物蜡提取
| 步骤 | 方法 |
| :---: | :--- |
| 1 | 将牛（牛脂）或猪（猪脂）的脂肪组织清洗干净，去除杂质。 |
| 2 | 尽可能将脂肪切得细碎，以增大受热面积。 |
| 3 | 在锅中加入极少量的水 and 脂肪，用微火隔水熬煮。 |
| 4 | 待脂肪熔化呈现液体状态后，用细布或网筛滤去残渣。 |
| 5 | 将过滤后的液体冷却，即成为固体形态的天然动物蜡。 |

### 5-2. 蜂巢蜂蜡提取
| 步骤 | 方法 |
| :---: | :--- |
| 1 | 将采蜜后剩下的蜂巢（蜂蜡）放入水中加热。 |
| 2 | 待蜂蜡完全熔化后，在受热状态下用布过滤杂质。 |
| 3 | 将过滤后的溶液直接冷却，由于蜂蜡比水轻，会在上层形成薄板状并固化。 |
| 4 | 剥离固化的蜂蜡板，刮去底部的杂质，再次进行精炼后即可使用。 |
