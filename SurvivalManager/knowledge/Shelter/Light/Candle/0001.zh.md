# 蜡烛
---
## 1. 原理
&nbsp;&nbsp;&nbsp;蜡烛依靠毛细现象和燃烧的循环来持续发光。

1. 点燃后，烛芯周围的燃料液化，通过毛细现象沿烛芯的细微缝隙上升。
2. 到达烛芯顶端的液态燃料在火焰热量的作用下汽化。
3. 汽化的燃料与空气中的氧气结合燃烧，产生光和热。
4. 火焰的热量不断熔化下方的固态蜡或液态油，并将其输送到烛芯。

---
## 2. 材料
- 燃料：早期使用动物脂肪（牛脂、猪油、蜂蜡）。现代则使用石蜡、蜂蜡、从大豆油中提取的大豆蜡等。
- 烛芯：可以使用棉线、纸、布和柑橘类的纤维。印刷过的纸（如报纸）烟灰多，燃烧时还有迸出火星的危险。
- 容器：不漏油、不漏蜡的玻璃、罐头盒或陶瓷。塑料和木头不耐热，不要使用。

---
## 3. 注意事项
- 使用前清除周围的可燃物，离开时先熄灭蜡烛再走。
- 蜡烛底部会发烫，不要直接放在木头或怕热的表面上，应使用石板或耐热底座。
- 自制的应急蜡烛会产生烟灰和微粒，并有通风不足的风险，在室内使用时要定期通风。
- 点燃前把烛芯修剪到0.6厘米。烛芯过长会使火焰变高、摇晃，烟灰和蘑菇状的积碳还可能导致过热。
- 使用油的应急蜡烛，连续燃烧不要超过4小时。

## 4. 制作
### 4-1. 金枪鱼罐头蜡烛
1. 准备一罐食用油浸的金枪鱼罐头和一根棉线。
2. 把棉线剪得比罐头高度略长。
3. 在罐盖中央钻一个小孔，穿入棉线作烛芯，并让它在油中充分浸透。
4. 点燃烛芯顶端。

### 4-2. 橙皮蜡烛
1. 把橙子或葡萄柚切成两半，小心取出果肉。中心的白色芯不要损坏，留在果皮底部。
2. 往果皮容器里倒入食用油，让只有芯的顶端露在空气中。
3. 在芯的上端稍微抹一点食用油，便于点火。
4. 点燃芯的顶端。

### 4-3. 黄油蜡烛
1. 从黄油块上切下大小合适的一块。
2. 用细螺丝刀或锥子在中央钻一个深孔。
3. 把烛芯插入孔中，在芯的上端稍微抹一点黄油，便于点火。
4. 点燃烛芯顶端。

### 4-4. 蜡制蜡烛
1. 按模具的容积称量蜡。
2. 把蜡隔水加热到70-80℃，但不要超过90℃。
3. 蜡达到70℃后离火。
4. 如果使用香料，不按体积（ml）而按重量（g）计量，取蜡重的6%混入。
5. 加入香料后轻轻搅拌2分钟，使其在蜡中分散并溶解。
6. 让蜡冷却到略显不透明的约55-60℃，或蜡厂家推荐的浇注温度。
7. 把蜡缓慢、平稳地倒入模具中央，防止表面收缩。
8. 蜡凝固期间把烛芯固定在中央，放在温度没有变化的地方至少冷却24小时。
9. 初步固化完成的蜡烛为提高品质，需熟化3-14天。

## 5. 原料提取
&nbsp;&nbsp;&nbsp;买不到商品蜡时，可以把身边的天然材料精制后用作蜡烛燃料。

### 5-1. 动物蜡
1. 把牛（牛脂）或猪（猪油）的脂肪组织洗净，去除杂质。
2. 把脂肪尽量切碎，增大受热面积。
3. 在锅中放入极少量的水和脂肪，用小火隔水加热。
4. 脂肪融化成液体后，用细布或滤网滤去残渣。
5. 滤出的液体冷却后就成了固态动物蜡。

### 5-2. 蜂巢蜂蜡
1. 把取蜜后剩下的蜂巢（蜂蜡）放入水中，加热到85℃以下。
2. 蜂蜡完全融化后，趁热用布滤去杂质。
3. 滤出的液体直接冷却，蜂蜡比水轻，会在上层形成一层并凝固。
4. 取下凝固的蜂蜡板，刮掉下面的杂质，再精制一次后使用。
