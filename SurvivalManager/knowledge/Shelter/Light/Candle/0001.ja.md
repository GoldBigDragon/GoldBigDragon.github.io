# ろうそく
---
## 1. 原理
&nbsp;&nbsp;&nbsp;ろうそくは、毛細管現象と燃焼の循環によって火を灯します。

1. 火が付くと、芯の周りの燃料が液化し、毛細管現象によって芯の細かな隙間を伝って上がります。
2. 芯の先端に達した液体燃料が、炎の熱で気化します。
3. 気化した燃料が空気中の酸素と結び付いて燃焼し、光と熱を出します。
4. 炎の熱が下の固体のロウや液体の油を溶かし続け、芯へと引き上げます。

---
## 2. 材料
- 燃料: 初期には動物性の脂(牛脂、豚脂、蜜ろう)を使っていました。現代ではパラフィン、蜜ろう、大豆油から抽出したソイワックスなどを使います。
- 芯: 木綿糸、紙、布、柑橘類の繊維を使えます。印刷された紙(新聞紙など)は煤が多く、燃焼中に火の粉が飛ぶ危険があります。
- 容器: 油やロウが漏れないガラス、缶、セラミック。プラスチックと木は熱に弱いため使いません。

---
## 3. 注意事項
- 使用前に周囲の可燃物を片付け、席を外すときはろうそくを消してから出ます。
- ろうそくの底は熱くなるため、木や熱に弱い面に直接置かず、スレートや耐熱性の台を使います。
- 自作の非常用ろうそくは煤や微粒子が出て換気不足になる恐れがあるため、室内では定期的に換気します。
- 燃やす前に芯を0.6cmに整えます。芯が長いと炎が高く揺れやすくなり、煤やキノコ状の炭素の付着によって過熱することがあります。
- 油を使う非常用ろうそくは、連続燃焼を4時間以内にします。

---
## 4. 作り方
### 4-1. ツナ缶ろうそく
1. 食用油漬けのツナ缶と木綿の紐を用意します。
2. 木綿の紐を缶の高さより少し長めに切ります。
3. 缶のふたの中央に小さな穴を開け、木綿の紐の芯を入れて油に十分に浸します。
4. 芯の先に火を付けます。

### 4-2. オレンジの皮のろうそく
1. オレンジやグレープフルーツを半分に切り、果肉を丁寧に取り出します。中心部の白い芯は傷つけず、皮の底に残します。
2. 芯の先だけが空気に触れるように、皮の容器に食用油を満たします。
3. 芯の上部に食用油を少し塗り、火が付きやすくします。
4. 芯の先に火を付けます。

### 4-3. バターろうそく
1. バターの塊から適当な大きさを切り取ります。
2. 細いドライバーかきりで中央に深く穴を開けます。
3. 芯を穴に差し込み、芯の上部にバターを少し塗って火が付きやすくします。
4. 芯の先に火を付けます。

### 4-4. ロウのろうそく
1. 型の容量に合わせてロウを計量します。
2. ロウを70-80℃まで湯せんで溶かしますが、90℃を超えないようにします。
3. ロウが70℃に達したら火から下ろします。
4. 香料を使う場合は、容量(ml)ではなく重さ(g)を基準に、ロウの重量の6%を計量して混ぜます。
5. 香料を入れたら、2分間静かにかき混ぜ、ロウに分散・溶解させます。
6. ロウが少し不透明になる約55-60℃、またはロウのメーカーが推奨する注入温度まで冷まします。
7. ロウを型の中央にゆっくり一定の速さで注ぎ、表面の収縮を防ぎます。
8. ロウが固まる間は芯を中央に固定し、温度変化のない場所で最低24時間冷まします。
9. 初期硬化を終えたろうそくは、品質を高めるために3-14日間熟成させます。

---
## 5. 原料の抽出
&nbsp;&nbsp;&nbsp;市販のロウが手に入らないときは、身近な天然素材を精製してろうそくの燃料にします。

### 5-1. 動物性ロウ
1. 牛(タロー)や豚(ラード)の脂肪組織をきれいに洗い、不純物を取り除きます。
2. 脂肪をできるだけ細かく刻み、熱が当たる面積を広げます。
3. 鍋にごく少量の水と脂肪を入れ、弱火で湯せんします。
4. 脂肪が溶けて液体になったら、目の細かい布や網で残りかすをこします。
5. こした液体を冷ますと、固体の動物性ロウになります。

### 5-2. 蜂の巣の蜜ろう
1. 蜂蜜を採った後に残った巣(蜜ろう)を水に入れ、85℃以下で加熱します。
2. 蜜ろうが完全に溶けたら、熱いうちに布で不純物をこします。
3. こした液をそのまま冷ますと、蜜ろうは水より軽いため上部に層をなして固まります。
4. 固まった蜜ろうの板を取り外し、下面の不純物を削り取って、もう一度精製してから使います。
