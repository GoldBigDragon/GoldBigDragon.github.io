# ろうそく
---
## 1. 原理
&nbsp;&nbsp;&nbsp;蝋燭が灯りを Tomす（ともす）原理は物理的な現象に基づいています。芯は数多くの微細な繊維質から構成されており、火がつくと芯の周囲の燃料が液化し、毛細管現象によって芯の微細な隙間に沿って上方へと吸い上げられます。  

&nbsp;&nbsp;&nbsp;芯の先端に到達した液体燃料は、炎の熱によって気체（気体）状態へと変化します。この気化した燃料が空気中の酸素と結合して燃焼（炎）を起こし、光と熱を放出します。  

&nbsp;&nbsp;&nbsp;炎の熱は継続して下方の固体ワックスや液体油を融解させ、毛細管現象を通じて芯へと引き上げる循環構造を作り出します。

---
## 2. 材料
&nbsp;&nbsp;&nbsp;蝋燭を製造する際に使用される材料は、燃料、芯、容器に分類されます。初期の蝋燭製造時は動物性脂肪（牛脂、豚脂、蜜蝋）を燃料として使用しており、現代にはパラフィン、蜜蝋、そして大豆油から抽出したソイワックスなど、多様な材料が使用されています。

&nbsp;&nbsp;&nbsp;綿糸、紙、布、さらには柑橘類の繊維質を芯として使用することができます。ただし、印刷された紙（例：新聞紙）の場合は煤（すす）が多く、燃焼中に火の粉が発生する危険性があるため注意が必要です。

&nbsp;&nbsp;&nbsp;蝋燭の容器は、油やワックスが漏れ出さないガラス、缶、セラミックを使用することができ、プラスチックや木などは熱に弱いため使用しないことが望ましいです。

---
## 3. 注意事項
&nbsp;&nbsp;&nbsp;蝋燭を製造・運用する際は、火災および健康上のリスクを最小限に抑えるため、安全規則を必ず遵守しなければなりません。

&nbsp;&nbsp;&nbsp;蝋燭の使用前は、周囲に引火する恐れのある可燃性物質を除去し、その場を離れる際は蝋燭の火を消してから退出します。  

&nbsp;&nbsp;&nbsp;蝋燭の底部は高温になることがあるため、木材や熱に弱い表面に直接置かず、スレートや耐熱敷物を使用しなければなりません。  

&nbsp;&nbsp;&nbsp;自家製の非常用蝋燭は、煤や微粒子を発生させたり、換気不足のリスクを伴ったりするため、室内で使用する際は必ず周期的な換気が必要です。

&nbsp;&nbsp;&nbsp;蝋燭を灯す前は、芯を常に0.6cmの長さに整えなければなりません。芯が長すぎると炎が高くなりすぎて揺らぎ、煤やキノコ状の炭소（炭素）蓄積が発生して過熱を引き起こす原因となります。  

&nbsp;&nbsp;&nbsp;油を利用した非常用蝋燭の場合、安全のために連続燃焼が4時間を超えないよう注意します。

## 4. 製造
### 4-1. ツナ缶キャンドル
| 順序 | 方法 |
| :---: | :--- |
| 1 | 植物油に漬けられたツナ缶と綿紐を準備します。 |
| 2 | 綿紐をツナ缶の高さよりもわずかに長めに切り落とします。 |
| 3 | 缶の蓋の中央に小さな穴を開け、綿紐の芯を穴に通して油に十分に浸します。 |
| 4 | 芯の先端に点火して燃焼させます。 |

### 4-2. オレンジピールキャンドル
| 順序 | 方法 |
| :---: | :--- |
| 1 | オレンジやグレープフルーツを半分に切った後、果肉を丁寧に分離し、中心部の白い芯を損傷させずに皮の底部に残します。 |
| 2 | 芯の先端だけが空気に露出する程度の深さまで、皮の容器に植物油を満たします。 |
| 3 | 芯の上部に植物油を軽く塗布し、点火がスムーズに行われるようにします。 |
| 4 | 芯의 先端に点火して燃焼させます。 |

### 4-3. バターキャンドル
| 順序 | 方法 |
| :---: | :--- |
| 1 | バターのブロックから適当な大きさを切り出します。 |
| 2 | 細いドライバーや千枚通しで中央に深く穴を開けます。 |
| 3 | 芯を穴に挿입（挿入）し、芯の上部にバターを軽く塗布して点火がスムーズに行われるようにします。 |
| 4 | 芯의 先端に点火して燃焼させます。 |

### 4-4. ワックスキャンドル
| 順序 | 方法 |
| :---: | :--- |
| 1 | 成形型の体積に合わせてワックスを計量します。 |
| 2 | ワックスを70〜80°Cまで湯煎（ゆせん）しますが、温度が90°Cを超えないよう注意します。 |
| 3 | ワックスが70°Cに到達したら火から下ろします。 |
| 4 | 香料がある場合、体積（ml）ではなく重量（g）を基準とし、ワックス重量に対して6%の香料を計量して混合します。 |
| 5 | 香料を添加した後、2分間穏やかに撹拌し、香料がワックスに物理的に分散・溶解するようにします。 |
| 6 | ワックスがわずかに不透明になり始める約55〜60°C、またはワックス製造元が推奨する適正注入（注入）温度まで冷却されるのを待ちます。 |
| 7 | ワックスを成形型の中央にゆっくりと、一定のペースで注ぎ入れ、表面の収縮を防止します。 |
| 8 | ワックスが凝固する間、芯を中央に固定し、温度変化のない空間で最低24時間冷却させます。 |
| 9 | 初期の硬化工程が終わった蝋燭は、品質向上のために3〜14日間熟成させます。 |

## 5. 原료（原料）抽出方法
&nbsp;&nbsp;&nbsp;非常事態において商業用のワックスを入手できない場合、周囲から得られる天然の材料を精製して蝋燭の燃料として活用することができます。

### 5-1. 動物性ワックスの抽出
| 順序 | 方法 |
| :---: | :--- |
| 1 | 牛（タロー）や豚（ラード）の脂肪組織をきれいに洗浄し、不순（不純）物を確認して除去します。 |
| 2 | 脂肪をできるだけ細かく刻み、熱が伝わる面積を広げます。 |
| 3 | 鍋に極めて少量の水と脂肪を入れ、弱火で湯煎します。 |
| 4 | 脂肪が融解して液体になったら、目の細かい布や網で残渣を濾し取ります。 |
| 5 | 濾し取った液体を冷却すると、固体形状の天然動物性ワックスになります。 |

### 5-2. 蜜蝋（みつろう）の抽出
| 順序 | 方法 |
| :---: | :--- |
| 1 | 蜂蜜を採取した後に残った巣（蜜蝋の原料）を水に入れて加熱します。 |
| 2 | 蜜蝋が完全に融解したら、熱い状態のまま布で不純物を濾過します。 |
| 3 | 濾過された溶液をそのまま冷却すると、蜜蝋は水よりも軽いため上層に層を形成して凝固します。 |
| 4 | 凝固した蜜蝋の板を取り出して下部の不純物を削り落とし、もう一度精製して使用します。 |
