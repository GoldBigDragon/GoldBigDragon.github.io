## Introduction
&nbsp;&nbsp;&nbsp;This is a crash guide written so that a person who knows nothing about electricity can install and use a 24V solar system on their own in a disaster. Theory is kept to a minimum, and only the common knowledge needed for installation is included. Later content assumes the earlier content, so if you are a beginner, read from Chapter 1 in order and carry out the work one step at a time.

> **Caution:** This guide is basic knowledge for emergencies. Whenever circumstances allow, be sure to get help from an experienced person.
