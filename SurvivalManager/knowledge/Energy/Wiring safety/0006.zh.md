## 5. 触电、火灾与灾难情况下的危险
### 5-1. 电流与人体电阻
&nbsp;&nbsp;&nbsp;伤害身体的是通过身体的电流大小、流过的时间和经过的路径。电压只是产生该电流的条件之一，即使电压相同，人体电阻不同，流过的电流也会大不相同。

| 身体状态 | 大致人体电阻 |
|:---|---:|
| 干燥的手，手到手 | 10,000-100,000Ω |
| 出汗的手 | 1,000-5,000Ω |
| 湿手 | 500-1,500Ω |
| 浸在水中 | 200-500Ω |
| 皮肤破损的伤口 | 几百Ω |

&nbsp;&nbsp;&nbsp;人体电阻的大部分由皮肤角质层承担。干燥时它是出色的绝缘体，被水浸湿就成为导电通道，汗水中的盐分还增加了电解质。接触同样的220V，手干燥时可能流过20mA出头，手湿时可能超过200mA。水和汗水使危险增大，不是因为电压升高，而是因为人体电阻降到了几十分之一。

---
### 5-2. 不同电流大小的影响
&nbsp;&nbsp;&nbsp;这是工频交流从手流向脚时的大致影响。因个体差异和接触时间而异。

| 电流 | 对身体的影响 |
|---:|:---|
| 0.5-1mA | 勉强能感觉到 |
| 1-5mA | 刺痛，可能因受惊而失去平衡 |
| 5-10mA | 疼痛，肌肉收缩 |
| 10-20mA | 无法自行松手（摆脱不能） |
| 20-50mA | 呼吸肌僵硬，无法呼吸 |
| 50mA以上 | 心室颤动的危险增加 |
| 几A以上 | 心脏骤停和深度烧伤 |

- 摆脱不能（10-20mA）是最值得注意的范围。使手指弯曲的肌肉比使手指伸直的肌肉强，所以电流一流过，手就会自己握紧，把电线抓得更牢。接触时间变长，皮肤被烧伤使电阻进一步下降，电流变得更大。这就是触电时，时间比电流大小更具决定性的原因。
- 从手到手，或从手到对侧脚流过的电流，会穿过心脏。这就是为什么建议在处理电时养成一只手插在口袋里或放在背后的习惯。

---
### 5-3. 交流与直流的危险
- 交流：每秒改变方向100多次，反复刺激肌肉和神经。摆脱不能在低得多的电流下就会发生，而且撞上心跳周期中对刺激最脆弱的那一小段的概率也高。引起心室颤动的最小电流，直流是交流的好几倍。
- 直流：这并不意味着安全。在接触的瞬间和离开的瞬间会带来强烈的冲击，而且电弧不会熄灭，在烧伤和火灾方面更危险。大型电池组即使电压低，短路时流过的电流也极大，能把金属工具瞬间熔化。这就是在电池周围作业时要摘掉戒指、手表、项链的原因。

---
### 5-4. 发现触电者时
> **注意：** 在对触电者伸手之前，先切断电源。正在接触的人本身就是通着电的导体，一抓住他，施救的人也进入同一个电路。

- 没有办法切断电源时，用干木棍、干绳子、折厚的干布这类不导电的东西把人推开。湿的东西和金属会原样传导电流。
- 断落的高压线落在地上时，靠近本身就很危险。电流在地下扩散，在地面上产生电位差，所以如果两脚分开，仅凭两脚之间的电压差就会触电。原则是不要靠近。必须移动时，两脚并拢，小步挪动。

---
### 5-5. 电气火灾
| 原因 | 怎样起火 |
|:---|:---|
| 过载 | 电线超过允许电流持续发热，外皮老化而起火 |
| 短路 | 两个导体直接接触，瞬间流过大电流，迸出火花 |
| 接触不良电弧 | 松动的接头处反复出现微小火花，局部达到几千度 |
| 漏电起痕 | 落有灰尘和潮气的绝缘物表面流过微小电流，碳化路径不断增长 |

- 漏电起痕最难察觉。它在没有大到使断路器反应的电流的情况下，历时几个月进展，黑色的碳化线不断变宽，在某一刻导致短路。典型的发生地点是插座后面、积了灰尘的插线板内部、长期插着的插头的两片之间。定期拔下来擦去灰尘、查看有没有烧焦痕迹，是唯一的预防办法。
- 电源还通着时不要用水。水柱成为导体，电流会回到灭火的人身上。先切断，切断之后才可以用水。大容量电池即使拉下断路器，仍然蕴含能量，所以依然危险。

---
### 5-6. 灾难情况特有的危险
| 危险 | 为什么产生 |
|:---|:---|
| 临时布线 | 铺在地上被踩、被压、被淋湿，外皮损伤不断累积 |
| 章鱼式连接 | 负载集中在一条电路上，超过电线的允许电流 |
| 卷着使用的电线盘 | 热量散不出去，即使在额定值以下也过热 |
| 被水淹过的配电盘 | 水干了以后，触点上残留的腐蚀和异物会引发漏电起痕 |
| 湿地面 | 人体电阻骤降，形成接地路径 |
| 发电机反送电 | 使抢修人员和邻居触电 |

> **注意：** 不要把发电机反过来插到室内插座上向建筑物送电。发电机的电沿着家里的布线流入电线杆上的变压器，变压器会反向工作而升压到几千伏，使以为已断电而作业的抢修人员和邻居触电。

- 正确的做法是把设备直接连接发电机，或者通过把建筑物布线与电网物理隔离的切换开关。这种开关必须是发电机和外部电网无法同时接通的结构。
- 内燃机发电机会排出一氧化碳。它无色无味，人不知不觉就会倒下。在窗边、半开的车库、地下空间、帐篷附近运转，等同于在室内运转。

### 5-7. 测量
| 确认项目 | 测量方法 | 注意事项 |
|:---|:---|:---|
| 有无电压 | 用电压测量档测两端 | 手指不要碰到表笔的金属部分 |
| 极性 | 用直流电压档测 | 符号为负，则极性相反 |
| 通断 | 用电阻或通断档测 | 必须在切断电源的状态下 |
| 电流 | 断开电路，串联接入测量 | 在电压档状态下并到电路上，测量仪会烧坏 |

- 不要相信“电已经切断”这个事实，要用测量来确认。
- 测量仪也会坏。要经过三个步骤：在有电的电路上确认测量仪正常，测量目标电路，再在有电的电路上确认测量仪仍然正常。跳过的话，坏掉的测量仪一直指着0V，就会误判为安全。
- 档位放错的情况也很常见。用交流档测直流电路，会得到接近0的值，很容易误以为没有电。测量前，要确认自己要测的东西与测量仪现在的测量状态一致。
