## 5. 感電、火災、災害時の危険
### 5-1. 電流と人体の抵抗
&nbsp;&nbsp;&nbsp;体を傷つけるのは、体を通過した電流の大きさ、流れた時間、通った経路です。電圧はその電流を作る条件の1つにすぎず、同じ電圧でも、人体の抵抗が変われば、流れる電流が大きく変わります。

| 体の状態 | おおよその人体の抵抗 |
|:---|---:|
| 乾いた手、手から手 | 10,000-100,000Ω |
| 汗をかいた手 | 1,000-5,000Ω |
| 濡れた手 | 500-1,500Ω |
| 水に浸かった状態 | 200-500Ω |
| 皮膚がはがれた傷 | 数百Ω |

&nbsp;&nbsp;&nbsp;人体の抵抗の大部分は、皮膚の角質層が担っています。乾いた状態ではすぐれた絶縁体ですが、水に濡れると電気が通る通路になり、汗の塩分は電解質まで加えます。同じ220Vに触れても、手が乾いていれば20mA余り、濡れていれば200mAを超えて流れることがあります。水と汗が危険を大きくする理由は、電圧が上がるからではなく、体の抵抗が数十分の一に下がるからです。

---
### 5-2. 電流の大きさ別の影響
&nbsp;&nbsp;&nbsp;商用周波数の交流が手から足へ流れたときの、おおよその影響です。個人差と接触時間によって変わります。

| 電流 | 体に現れる影響 |
|---:|:---|
| 0.5-1mA | かろうじて感じられる程度 |
| 1-5mA | ちくっとして、驚いてバランスを失うことがある |
| 5-10mA | 痛み、筋肉の収縮 |
| 10-20mA | 自分で手を離せない離脱不能 |
| 20-50mA | 呼吸筋が硬直して息ができない |
| 50mA以上 | 心室細動の危険が増加 |
| 数A以上 | 心停止と深いやけど |

- 離脱不能(10-20mA)が、最も注目すべき区間です。指を閉じる筋肉が開く筋肉より強いため、電流が流れると手がひとりでに握り込まれて、電線をさらに強くつかみます。接触時間が長くなり、皮膚が焼けて抵抗がさらに下がり、電流がさらに大きくなります。感電では、電流の大きさより時間のほうが決定的な理由です。
- 手から手、または手から反対側の足へ流れる電流は、心臓を横切ります。電気を扱うときに、片手をポケットに入れたり背中に回したりする習慣が勧められる理由です。

---
### 5-3. 交流と直流の危険
- 交流: 1秒に100回以上向きを変え、筋肉と神経を繰り返し刺激します。離脱不能がはるかに低い電流で起こり、心拍の周期のうち刺激に最も弱い短い区間にぶつかる確率も高いです。心室細動を起こす最小の電流は、直流では交流の数倍です。
- 直流: 安全という意味ではありません。触れた瞬間と離れた瞬間に強い衝撃を与え、アークが消えないので、やけど・火災の面ではより危険です。大きなバッテリーバンクは、電圧が低くても、短絡時に流れる電流が膨大で、金属の工具を一瞬で溶かします。バッテリーの周辺で作業するときに、指輪・腕時計・ネックレスを外す理由です。

---
### 5-4. 感電した人を見つけたとき
> **注意:** 感電した人に手を触れる前に、まず電源を切ります。接触中の人は、それ自体が電気の流れる導体であり、つかんだ瞬間に、救助しようとした人も同じ回路に入ります。

- 電源を切る方法がなければ、乾いた木の棒、乾いたロープ、厚く折った乾いた布のように、電気が通らない物で押しのけます。濡れた物や金属は、電流をそのまま伝えます。
- 切れた高圧線が地面に触れているときは、近づくこと自体が危険です。電流が地中に広がって地表に電位差が生じるので、両足が離れていれば、足の間の電圧差だけで感電します。原則は近づかないことです。やむを得ず移動する場合は、両足をそろえたまま小刻みに動きます。

### 5-5. 電気火災
| 原因 | どのように火がつくか |
|:---|:---|
| 過負荷 | 電線が許容電流を超えて発熱し続け、被覆が劣化して発火 |
| 短絡 | 2つの導体が直接触れて瞬間的に大きな電流が流れ、火花が飛ぶ |
| 接触不良のアーク | 緩んだ接続部で微細な火花が繰り返され、局所的に数千度に達する |
| トラッキング | ほこりと湿気が付いた絶縁物の表面に微細な電流が流れ、炭化した経路が伸びていく |

- トラッキングが最も気づきにくいものです。ブレーカーが反応するほど大きな電流が流れないまま数か月にわたって進行し、炭化した黒い筋が広がって、ある瞬間に短絡につながります。コンセントの裏側、ほこりがたまったテーブルタップの内部、長く差しっぱなしにしたプラグの2枚の刃の間が、典型的な発生箇所です。定期的に抜いてほこりを拭き、焦げた跡がないか見ることが、唯一の予防です。
- 電源が生きていれば、水を使いません。水流が導体になって、火を消す人に電流が戻ってきます。遮断が先で、遮断した後は水を使ってもかまいません。大容量のバッテリーは、ブレーカーを落としてもエネルギーを抱えているので、依然として危険です。

### 5-6. 災害時特有の危険
| 危険 | なぜ生じるか |
|:---|:---|
| 仮設配線 | 床に敷かれて踏まれ、押され、濡れて、被覆の損傷が蓄積する |
| タコ足配線 | 1つの回路に負荷が集中して、電線の許容電流を超える |
| 巻いたまま使うリール | 熱が逃げられず、定格以下でも過熱する |
| 浸水した配電盤 | 水が乾いた後も、接点に残った腐食と異物がトラッキングを招く |
| 濡れた床 | 人体の抵抗が急減し、接地の経路ができる |
| 発電機の逆送電 | 復旧作業者と近隣住民を感電させる |

> **注意:** 発電機を家の中のコンセントに逆に差して、建物に電気を入れてはいけません。発電機の電気が家の配線を伝って電柱の変圧器に流れ込むと、変圧器が逆に作動して数千Vに昇圧され、電気が切れたと信じて作業していた復旧作業者や近隣住民を感電させます。

- 正しい方法は、機器を発電機に直接つなぐか、建物の配線を系統から物理的に切り離す切替スイッチを経由することです。このスイッチは、発電機と外部の系統が同時につながることのない構造でなければなりません。
- 内燃機関の発電機は一酸化炭素を出します。色も臭いもなく、気づかないまま倒れます。窓の近く、半分開いたガレージ、地下空間、テントの近くで回すのは、屋内で回すのと同じです。

### 5-7. 測定
| 確認項目 | 測定方法 | 注意すべき点 |
|:---|:---|:---|
| 電圧の有無 | 電圧測定モードで両端を測る | 指がテストリードの金属部に触れないようにする |
| 極性 | 直流電圧モードで測る | 符号がマイナスなら極性が逆 |
| 導通 | 抵抗または導通モードで測る | 必ず電源を切った状態でのみ |
| 電流 | 回路を切って直列に入れて測る | 電圧モードのまま回路に当てると、測定器が焼ける |

- 電源を切ったという事実を信じず、測定で確認します。
- 測定器も故障することがあります。生きている回路で測定器が正常か確認し、対象の回路を測定し、再び生きている回路で測定器がまだ正常か確認する、3段階を経ます。省くと、故障した測定器が0Vを指し続けている状況で、安全だと誤判断します。
- モードを間違えて置く場合もよくあります。直流回路を交流モードで測ると0に近い値が出て、電気がないと勘違いしやすくなります。測定の前に、何を測ろうとしているかと、測定器が今何を測る状態になっているかが一致しているかを確認します。
