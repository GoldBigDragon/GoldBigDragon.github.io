## 1. 发电规划：所需电力与方式选择
### 1-1. 区分需要用电的用途
&nbsp;&nbsp;&nbsp;用电会更方便的事，和不用电就做不到的事，是不同的。把有限的发电能力用在前者，就没有余力应付后者了。

| 用途 | 不用电的做法 | 判断 |
|:---|:---|:---|
| 照明 | 油灯、蜡烛、白天干活 | LED耗电极小，是用电更有利的例外 |
| 烹饪 | 火、木炭、火箭炉 | 用电来做是极大的浪费 |
| 取暖 | 柴火、温突（韩式地暖）、加强保温 | 电取暖是最差的选择 |
| 烧水 | 火 | 火有压倒性的优势 |
| 抽水 | 吊桶、手动水泵、提水水车 | 不用电也能做到 |
| 冷藏 | 地下储藏、蒸发冷却、腌制和熏制 | 用电更有利，但耗电大 |
| 通信 | 无 | 只能用电 |
| 接收和记录信息 | 无 | 只能用电 |
| 医疗设备 | 无 | 只能用电 |
| 给手电筒、对讲机充电 | 无 | 只能用电 |

&nbsp;&nbsp;&nbsp;表中最下面四行就是发电的全部理由，而且耗电都很小。

---
### 1-2. 计算耗电量
&nbsp;&nbsp;&nbsp;先写下所需电量并算出总和，再选择与总和相配的设备。先定设备再迁就着用的计划，几乎都会失败。

| 设备 | 耗电功率 | 每日使用 | 每日电量 |
|:---|---:|---:|---:|
| LED灯泡1个 | 3-7W | 4小时 | 12-28Wh |
| 收音机 | 1-5W | 4小时 | 4-20Wh |
| 手机充电 | 5-15W | 2小时 | 10-30Wh |
| 对讲机充电 | 5-10W | 2小时 | 10-20Wh |
| 笔记本电脑 | 30-65W | 3小时 | 90-195Wh |
| 小风扇 | 20-40W | 6小时 | 120-240Wh |
| 小冰箱 | 压缩机60-100W | 间歇运行 | 300-800Wh |
| 电热水壶 | 1,500-2,000W | 10分钟 | 250-330Wh |
| 电暖炉 | 1,000-2,000W | 1小时 | 1,000-2,000Wh |

&nbsp;&nbsp;&nbsp;照明、收音机和通信设备一整天用电量的总和在100Wh上下。电热水壶只开10分钟，就比这用得多。一个产热设备比其他所有负载的总和还大，所以列不列入清单，所需设备的规模就不同。

> **注意：** 用电来产热，发电规模要扩大十倍。热用火来产生，电只用于只有电才能做的事。

---
### 1-3. 计入损耗
&nbsp;&nbsp;&nbsp;在计算出的耗电量上加上传输过程的损耗，才是所需的发电量。

| 环节 | 大致效率 |
|:---|---:|
| 布线与接头 | 95-98% |
| 充电控制器 | 90-97% |
| 电池充放电 | 80-85% |
| 逆变器转换 | 85-90% |

- 同时经过电池和逆变器，总效率在70%上下。要每天用200Wh，就必须发280-300Wh。
- 再加上阴天、枯水期以及因故障、检修而停机的天数，留出余量。
- 不经过逆变器，两个损耗环节就消失了。电池、LED、收音机、充电器都以直流工作，所以直接使用直流。
- 逆变器光是开着，就会消耗待机功率。

---
### 1-4. 选择发电方式的标准
| 方式 | 持续性 | 制作难度 | 燃料 | 主要危险 |
|:---|:---|:---|:---|:---|
| 水力 | 非常高 | 中等 | 不需要 | 溺水、洪水 |
| 太阳能 | 仅白天 | 低 | 不需要 | 低 |
| 风力 | 不稳定 | 高 | 不需要 | 转子损坏、强风 |
| 蒸汽 | 高 | 非常高 | 柴火 | 锅炉爆炸 |
| 木煤气 | 高 | 高 | 柴火 | 一氧化碳、火灾 |
| 人力 | 仅在需要时 | 低 | 食物 | 低 |

&nbsp;&nbsp;&nbsp;选择标准不是最大功率，而是每天实际得到的电量。太阳能的额定功率看起来很大，但每天只发电3-5小时，而水力在相同额定功率下可以运转24小时。100W的水力设备，每天发的电量与400W的太阳能设备相近。
