## 1. 在发电前必须提出的问题
### 1-1. 这项工作能否在不用电的情况下完成
&nbsp;&nbsp;&nbsp;这是在启动发电前必须通过的审问。用电会很方便的工作，与不用电就完全无法完成的工作，属于完全不同的范畴；将有限的发电能力消耗于前者，就会失去应对后者的余力。

| 用途 | 无需电力的替代方法 | 判定 |
|:---|:---|:---|
| 照明 | 油灯、蜡烛、利用白昼工作 | LED功耗极低，例外地以用电更为有利 |
| 烹饪 | 明火、木炭、火箭炉 | 用电烹饪是巨大的浪费 |
| 暖房 | 柴火、火炕、加强保温绝热 | 电暖房是最糟糕的选择 |
| 烧水 | 明火 | 明火具备压倒性优势 |
| 抽水 | 水桶、手动泵、水车 | 完全可以无电完成 |
| 冷藏 | 地下贮藏、蒸发冷却、盐渍与腌熏 | 用电虽有利但功耗极大 |
| 通信 | 无 | 仅限用电 |
| 信息接收与记录 | 无 | 仅限用电 |
| 医疗设备 | 无 | 仅限用电 |
| 手电筒与对讲机充电 | 无 | 仅限用电 |

&nbsp;&nbsp;&nbsp;表格底部的最后四行，就是制造电力的全部理由。而这四项用途的功耗都极其微小。

---
### 1-2. 优先计算功率消耗
&nbsp;&nbsp;&nbsp;先确定发电设备、再按设备去凑用电量的计划几乎注定失败。必须遵循先列出所需电量并计算总和、再根据总和选择契合设备的顺序。

| 用电设备 | 消耗功率 | 每日使用时间 | 每日用电量 |
|:---|---:|---:|---:|
| LED灯泡 1个 | 3-7W | 4小时 | 12-28Wh |
| 收音机 | 1-5W | 4小时 | 4-20Wh |
| 手机充电 | 5-15W | 2小时 | 10-30Wh |
| 对讲机充电 | 5-10W | 2小时 | 10-20Wh |
| 笔记本电脑 | 30-65W | 3小时 | 90-195Wh |
| 小型风扇 | 20-40W | 6小时 | 120-240Wh |
| 小型冰箱 | 压缩机 60-100W | 间歇运转 | 300-800Wh |
| 电热水壶 | 1,500-2,000W | 10分钟 | 250-330Wh |
| 电暖气 | 1,000-2,000W | 1小时 | 1,000-2,000Wh |

&nbsp;&nbsp;&nbsp;从本表中应当解读的并非具体的单个数字，而是整体结构。将照明、收音机与通信设备使用一整天所需的电量加在一起也不过100Wh左右，而将电热水壶仅开启10分钟所消耗的电量就超越了这一总和。发热设备所占的比重超越了其他所有负载的总和，将这单单一种发热设备纳入或剔除出清单，会将所需发电设备的规模彻底推向完全不同的维度。

> **一旦试图用电来产生热量，发电计划就会瞬间变成十倍规模的难题。热量应当由明火产生，而电力则应留给只有电力才能完成的事。**

---
### 1-3. 加上损耗才能得出实际需求量
&nbsp;&nbsp;&nbsp;计算出的消耗量并不能直接等同于所需的发电量。因为发电机发出的电力在到达用电设备之前，需要经历多个环节并逐级衰减。

| 环节 | 大致效率 |
|:---|---:|
| 配线与连接接头 | 95-98% |
| 充电控制器 | 90-97% |
| 蓄电池充放电 | 80-85% |
| 逆变器转换 | 85-90% |

&nbsp;&nbsp;&nbsp;经历经由蓄电池贮存并由逆变器逆变为交流电的全部路径后，综合效率会降至70%左右。因此，若计划每日消耗200Wh，则每日必须发电280-300Wh才能使计算平衡。在此基础上，还必须为阴天、枯水期以及因故障和维护导致发电中断的日子留出裕量（缓冲）。

&nbsp;&nbsp;&nbsp;最简便的节约方式就是不经过逆变器。蓄电池、LED、收音机与充电器均运行于直流电，消除“将直流逆变为交流、再在设备内部变压回直流”的路径，就能将两级损耗整段消除。仅开启逆变器本身所消耗的待机功耗同样不可忽视。

### 1-4. 选择发电方式的标准
| 方式 | 连续性 | 制造难易度 | 燃料 | 主要危险 |
|:---|:---|:---|:---|:---|
| 水力 | 极高 | 中等 | 无需 | 溺水、洪水 |
| 太阳能 | 仅限白昼 | 低 | 无需 | 低 |
| 风力 | 不稳定 | 高 | 无需 | 旋转体破损、强风 |
| 蒸汽 | 高 | 极高 | 柴火 | 锅炉爆炸 |
| 木材气 | 高 | 高 | 柴火 | 一氧化碳、火灾 |
| 人力 | 仅在需要时 | 低 | 食物 | 低 |

&nbsp;&nbsp;&nbsp;挑选时的标准并非最大峰值功率，而是每日实际获取的总电量。太阳能发电即便标称额定功率看起来很大，每日实际有效发电时间也仅有3-5小时；而水力发电即便额定功率相同，也能24小时不间断运转。一套100W的小型水力发电设备，其每日产生的总电量与一套400W的太阳能发电设备大致相当。
