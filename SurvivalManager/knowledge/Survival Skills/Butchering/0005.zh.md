## 4. 物尽其用的分割
&nbsp;&nbsp;&nbsp;平时的精肉加工以瘦肉为中心，把其余部分称为副产物，但在灾害状况下，这种区分并不成立。瘦肉所含的热量不到整只动物的一半，而人体最容易缺乏的营养素——脂肪与维生素，大多存在于瘦肉以外的部位。需要判断的不是该丢弃哪个部位，而是该按什么顺序使用它们。

---
### 4-1. 脂肪的价值与兔饥饿症
&nbsp;&nbsp;&nbsp;脂肪每1g约含9kcal，密度是蛋白质与碳水化合物（每克4kcal）的两倍以上。搬运同样重量时，脂肪提供的热量占绝对优势；而且脂肪几乎不含水分，细菌难以滋生，因此保存性也最好。所以在饥饿的状况下，脂肪的价值高于瘦肉。

| 脂肪的位置 | 性质 | 主要用途 |
| --- | --- | --- |
| 肾脏周围脂肪 | 熔点高、质地坚硬，饱和脂肪比例高 | 提炼后凝固保存时间最长 |
| 背部与皮下脂肪 | 厚且量多 | 提炼成油脂，或作为包裹瘦肉的保护层 |
| 腹腔网膜 | 薄薄的网状膜 | 用来包裹瘦肉烘烤，或延缓干燥过程中的失水 |
| 肌间脂肪 | 分散在肌纤维之间 | 烹调时融化产生风味，很难单独回收 |
| 骨髓 | 脂肪含量非常高 | 敲开骨头直接食用，或熬煮后撇取油脂 |
| 脑与眼周组织 | 富含脂质与磷脂 | 除食用外，也是鞣制皮革的原料 |

&nbsp;&nbsp;&nbsp;提炼脂肪的原理很简单。用小火慢慢加热，脂肪细胞的细胞膜会破裂，油脂流出，结缔组织则收缩成渣滓留下来。必须加热到剩余水分完全蒸发为止，若残留水分，保存过程中该处就会滋生霉菌与细菌。火力太大会使油脂烧焦、引发氧化酸败，所以原则是用低温长时间加热。

&nbsp;&nbsp;&nbsp;脂肪不足时出现的问题就是兔饥饿症。名字虽然来自兔子，但泛指长期只吃几乎不含体脂肪的野生小型动物瘦肉所引发的一系列代谢异常。原因在于肝脏和肾脏的处理能力。要把蛋白质当作能量使用，就必须从氨基酸上剥离氮，被剥离的氮经氨转化为尿素后随尿液排出。尿素循环的处理速度存在上限，大约是每1kg体重每天2g左右，以成人计算，每天上限约为200~300g。超过这个限度，血液中的氨和氨基酸就会堆积，为了排出尿素还需大量用水，脱水也会随之而来。

| 病程 | 症状 |
| :---: | --- |
| 3-4天 | 严重疲劳感、恶心、无论怎么吃都无法缓解的饥饿感 |
| 7-10天 | 开始腹泻，并伴随脱水 |
| 2-3周 | 衰竭急剧发展，可能导致死亡 |

&nbsp;&nbsp;&nbsp;安全范围是让蛋白质占总摄入热量的比例保持在35%以下，最好在25%以下。有记录的案例显示，这一比例超过45%时就会出现症状。实用做法是每天摄入热量的30-50%应来自脂肪；如果只有瘦肉可吃，就不应该靠多吃来补足热量，而应同时搭配根茎类和坚果等富含脂肪或碳水化合物的食物一起食用。

> **如果只有瘦肉而没有脂肪，多吃并不是答案。在获得脂肪或碳水化合物之前，反而应该减少吃肉，这样才安全。**

### 4-2. 内脏的营养与维生素A过量中毒
&nbsp;&nbsp;&nbsp;内脏集中蕴含着野外可获取的营养素中瘦肉无法提供的部分。尤其是肝脏，是维生素A、铁、维生素B12、叶酸与铜的储藏库。只吃谷物和肉的话，几周内就会缺乏的营养素，大多都在这里。

| 部位 | 主要营养 | 处理要点 |
| --- | --- | --- |
| 肝脏 | 维生素A、铁、维生素B12、叶酸、铜 | 取出时不弄破胆囊，若有白斑或结节则整块丢弃 |
| 心脏 | 组成接近肌肉，含铁与辅酶Q10 | 去除瓣膜与凝血后，可当作普通肌肉使用 |
| 肾脏 | 铁与B族维生素 | 尿味较重，需对半切开、浸水后再烹调 |
| 肺与脾 | 蛋白质与铁 | 组织疏松、容易变质，应最先食用 |
| 脑 | 脂质与磷脂 | 有食用价值，但在存在朊病毒病风险的物种中应避免食用 |
| 骨髓 | 脂肪与热量 | 敲开骨头即可获得，是密度最高的热量来源 |

&nbsp;&nbsp;&nbsp;肝脏还存在方向相反的风险。维生素A属于脂溶性，不易被人体排出，会在肝脏中蓄积。然而部分动物的肝脏所含维生素A，其含量已超出人体所能承受的水平。多份记录显示，在北极活动的探险队员食用北极熊、海豹或雪橇犬的肝脏后，出现剧烈头痛、呕吐、嗜睡，数日后皮肤剥落等症状。北极熊肝脏只需食用500g就会达到急性中毒剂量。

&nbsp;&nbsp;&nbsp;之所以会出现这种蓄积，是因为这些动物处于食物链上层，维生素A会逐级浓缩。相反，鹿、兔、牛、猪（野猪除外）等草食或杂食动物的肝脏，只要食用常识范围内的分量就是安全的。规则很简单：肉食性大型哺乳动物与海洋哺乳动物的肝脏不吃；其余动物的肝脏每天也不超过100g左右，且不要每天都吃。

### 4-3. 骨、血、肠与皮
&nbsp;&nbsp;&nbsp;骨头本身不能吃，但含有骨髓、明胶与矿物质。把骨头切开久煮，关节与软骨中的胶原蛋白会溶解成明胶，使汤汁产生黏稠感，这种汤是与坚韧部位、根茎类一起炖煮的最佳基底。事先把骨头敲碎，可以增大表面积、加快析出速度，还能连骨髓一起回收。

&nbsp;&nbsp;&nbsp;血富含蛋白质与铁，但也是最容易变质的部位。接血后要立即搅拌以防止凝固，或者反过来让其凝固后再烹调；如果不搅拌而放置，就会分离成血块和清液，变得难以处理。加盐可以延缓凝固。不过血是细菌最容易滋生的介质，因此必须彻底加热。

&nbsp;&nbsp;&nbsp;肠子先把内容物挤压干净，再翻过来刮掉内侧黏膜，经过多次冲洗后，就只剩下薄而坚韧的膜。这层膜可以用作香肠和血肠（sundae）的肠衣，晒干后还能当作弓弦和缝合线使用。反刍动物的胃壁格外厚实，可以作为单独的食材。

| 副产物 | 作为工具的价值 |
| --- | --- |
| 筋腱 | 晒干后敲打会裂成纤维，沾湿后又会重新黏合，是最坚韧的天然绳索 |
| 骨 | 锥子、针、鱼钩、箭头、刮削器 |
| 角与蹄 | 煮软后可塑形，冷却后变硬。久煮则化为胶 |
| 皮 | 生皮晒干后会变得像石头一样坚硬，可做绳索和容器；鞣制后则可制成衣物 |
| 膀胱与胃 | 晒干后可制成盛水或盛油的袋子 |

&nbsp;&nbsp;&nbsp;皮如果在剥下后不立即处理，几个小时内就会开始腐败。详细原理将在生存技能中的皮革鞣制文档中说明。

### 4-4. 处理残骸并转入保存
&nbsp;&nbsp;&nbsp;无法使用的残骸放在哪里，既是卫生问题，也是安全问题。把内脏内容物和骨头碎块丢在作业场附近，三天之内苍蝇的蛆虫就会在那里安家，闻到气味的捕食者甚至会一路找到人的住处。熊和野猪在数公里之外就能察觉到腐败的气味。

| 处理方法 | 原理 | 局限 |
| --- | --- | --- |
| 深埋 | 泥土能阻止气味扩散 | 需挖到60cm以上，太浅会被扒开 |
| 焚烧 | 分解有机物，消除气味 | 耗费大量燃料，烟雾会暴露位置 |
| 远离水源 | 防止饮用水源受污染 | 须与取水点保持至少50m以上距离 |
| 移离住处 | 使捕食者远离人 | 应顺风向搬移 |

&nbsp;&nbsp;&nbsp;分割一旦完成，与时间的赛跑就开始了。一个人一天能吃下的肉量有限，而一头中型动物一次就能带来数天以上的分量。所以分割的最后一步永远是保存，而保存的计划必须在开始分割之前就已经制定好。

&nbsp;&nbsp;&nbsp;各种保存方法最终都归结为同一个原理：夺走细菌能利用的水分，或者制造出细菌无法忍受的环境。干燥通过蒸发水分降低水分活度，腌制利用渗透压从细菌中夺走水分，熏制则用烟中的酚类和醛类给表面杀菌，同时帮助干燥。用脂肪封存的方法，是把融化的脂肪浇在肉上使其凝固，从物理上阻断氧气与细菌的接触。各方法的具体条件与组合方式，将在食品保存文档中继续说明。
