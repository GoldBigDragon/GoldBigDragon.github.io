## 4. 副产品的利用与保存
&nbsp;&nbsp;&nbsp;灾难情况下，瘦肉与副产品的区分是不成立的。瘦肉不到一只动物所产热量的一半，最紧缺的脂肪和维生素大多不在瘦肉里。要判断的不是丢弃哪些部位，而是以什么顺序使用。

---
### 4-1. 脂肪与兔饥饿
&nbsp;&nbsp;&nbsp;脂肪每克约9kcal，密度比蛋白质和碳水化合物的4kcal高出一倍以上。几乎不含水，细菌难以生长，所以保存性也最好。在饥饿的情况下，脂肪比瘦肉更有价值。

| 脂肪的位置 | 性质 | 主要用途 |
| --- | --- | --- |
| 肾周脂肪 | 熔点高，坚硬，饱和脂肪比例高 | 熬炼后凝固，保存得最久 |
| 背部和皮下脂肪 | 厚，量大 | 熬油，包裹瘦肉的保护层 |
| 腹腔的网膜 | 薄薄的网状膜 | 包裹瘦肉烤，或减缓风干时的干瘪 |
| 肌间脂肪 | 分散在肌纤维之间 | 烹调时融化，产生风味，难以另外回收 |
| 骨髓 | 脂肪含量很高 | 敲开骨头直接吃，或煮后撇去浮油 |
| 脑和眼周 | 富含脂质和磷脂 | 除食用外，是皮革鞣制的材料 |

- 熬炼脂肪：用小火慢慢加热，脂肪细胞的膜破裂，油流出来，结缔组织缩小，成为残渣留下。加热到剩余水分蒸发为止。水分残留的话，保存期间会长霉长菌。火大了油会烧焦并开始酸败，所以要在低温下长时间加热。

&nbsp;&nbsp;&nbsp;脂肪不足时出现的问题是兔饥饿。指的是只持续吃几乎没有体脂肪的野生小型动物的瘦肉时产生的代谢异常。原因是肝脏和肾脏的处理容量。要把蛋白质用作能量，就得从氨基酸上取下氮，氮经过氨变成尿素，随尿排出。尿素循环的处理速度每公斤体重每天2g多一点，以成年人计，每天200-300g是极限。超过这个限度，血中的氨和氨基酸会积累，为了排出尿素还要大量用水，也会出现脱水。

| 经过 | 症状 |
| :---: | --- |
| 3-4天 | 严重疲劳感，恶心，怎么吃也填不满的饥饿 |
| 7-10天 | 开始腹泻，并叠加脱水 |
| 2-3周 | 衰弱急剧发展，可能导致死亡 |

- 安全范围：在总摄入热量中，蛋白质比例控制在35%以下，尽量在25%以下。记录的案例中，超过45%时出现了症状。
- 每天摄入热量的30-50%从脂肪获得。只有瘦肉时，不要为了凑够热量而多吃，而要同时吃根茎、坚果等提供脂肪或碳水化合物的东西。

> **注意：** 只有瘦肉、没有脂肪时，多吃不是答案。在得到脂肪或碳水化合物之前，反而减少吃肉更安全。

---
### 4-2. 内脏的营养与维生素A过量
&nbsp;&nbsp;&nbsp;内脏集中含有瘦肉无法提供的营养素。肝脏是维生素A、铁、维生素B12、叶酸、铜的储藏库。只吃谷物和肉的话，几周内就会出现缺乏的营养素，大部分都在这里。

| 部位 | 主要营养 | 处理要点 |
| --- | --- | --- |
| 肝 | 维生素A、铁、维生素B12、叶酸、铜 | 不要弄破胆囊，把它取下来。有白点或结节的话，全部丢弃 |
| 心脏 | 成分接近肌肉，含铁和辅酶Q10 | 去掉瓣膜和凝血块后，像普通肌肉一样使用 |
| 肾 | 铁和B族维生素 | 尿味重，所以对半剖开后泡在水里，再烹调 |
| 肺和脾 | 蛋白质和铁 | 组织疏松，容易变质，所以最先吃掉 |
| 脑 | 脂质和磷脂 | 有食用价值，但有朊病毒病风险的物种要避开 |
| 骨髓 | 脂肪和热量 | 敲开骨头就能直接得到的密度最高的热量来源 |

&nbsp;&nbsp;&nbsp;肝脏有相反方向的风险。维生素A是脂溶性的，不易排出，会蓄积在肝脏里，一些动物的肝脏含有的维生素A，达到人无法承受的水平。有多起记录显示，北极探险队吃了北极熊、海豹、雪橇犬的肝脏，出现严重头痛、呕吐、嗜睡，几天后皮肤脱落。北极熊的肝脏只吃500g就达到急性中毒量。越是食物链上层的动物，维生素A在每个环节被浓缩得越多。

> **注意：** 不要吃大型食肉哺乳动物和海洋哺乳动物的肝脏。鹿、兔、牛、猪（野猪除外）这类食草、杂食动物的肝脏，在常理的量内是安全的。其他的肝脏，每天也不要超过100g左右，且不要每天吃。

---
### 4-3. 骨、血、肠、皮
- 骨：本身不能吃，但含有骨髓、明胶和矿物质。切开久煮，关节和软骨的胶原蛋白会融化成明胶，使汤带上黏性，是与坚韧部位和根茎一起煮的好底汤。事先敲碎会增加表面积，萃取更快，骨髓也一并回收。
- 血：富含蛋白质和铁，但最容易变质。接到后立即搅拌以防凝固，或者反过来让它凝固后再烹调。不搅拌的话会分成血块和清液，难以处理。加盐会延缓凝固。因为它是细菌最容易生长的介质，所以一定要完全加热。
- 肠：把内容物捋出后翻过来，刮掉内侧黏膜，多次冲洗，就只剩下薄而坚韧的膜。这层膜成为香肠和血肠的肠衣，晒干后也可用作弓弦和缝合线。反刍动物的胃特别厚，可以作为另外的食材。

| 副产品 | 作为工具的价值 |
| --- | --- |
| 筋 | 晒干后敲打会分成纤维，浸湿后又会黏合，成为最强的天然绳 |
| 骨 | 锥子、针、鱼钩、箭头、刮刀 |
| 角和蹄 | 煮后变软可塑形，冷却后变硬。久煮成为胶 |
| 皮 | 生皮干了会硬如石头，成为绳和容器，鞣制后成为衣服 |
| 膀胱和胃 | 晒干后成为盛水和油的袋子 |

&nbsp;&nbsp;&nbsp;皮剥下后若不立即处理，几个小时内就开始腐败。原理在“皮革鞣制”文档中讲述。

---
### 4-4. 残余物处理与保存
&nbsp;&nbsp;&nbsp;不能用的残余物放在哪里，既是卫生问题，也是安全问题。内脏内容物和碎骨丢在作业场附近，三天内就会生蛆，闻到气味的捕食者会一直找到人的住处。熊和野猪在几公里外就能察觉腐败气味。

| 处理方法 | 原理 | 局限 |
| --- | --- | --- |
| 深埋 | 土壤阻止气味扩散 | 必须挖60cm以上，浅了会被刨开 |
| 焚烧 | 分解有机物并消除气味 | 耗费大量燃料，烟会暴露位置 |
| 远离水源 | 防止饮用水源污染 | 必须与水源地至少相距50m以上 |
| 从住处移开 | 使捕食者远离人 | 移到下风一侧 |

&nbsp;&nbsp;&nbsp;分解结束后，与时间的战斗就开始了。一个人一天能吃的肉是有限的，一只中型动物的量超过好几天的份。分解的最后阶段始终是保存，保存计划要在开始分解之前制定好。

&nbsp;&nbsp;&nbsp;各种保存方法都归结为同一个原理：夺走细菌能用的水，或者制造细菌无法忍受的环境。

- 干燥：蒸发水分，降低水分活度。
- 盐腌：靠渗透压夺走细菌体内的水。
- 熏制：用烟中的酚类和醛类给表面杀菌，并帮助干燥。
- 油脂封存：把融化的脂肪浇在肉上凝固，从物理上阻断氧气和细菌的接近。

&nbsp;&nbsp;&nbsp;各方法的具体条件与组合，在“食品保藏”文档中继续讲述。
