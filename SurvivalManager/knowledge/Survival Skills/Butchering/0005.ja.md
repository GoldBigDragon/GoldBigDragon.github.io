## 4. 副産物の活用と保存
&nbsp;&nbsp;&nbsp;災害時には、赤身と副産物の区別は成り立ちません。赤身は1頭から出る熱量の半分に満たず、最も不足する脂肪とビタミンは、大部分が赤身ではない所にあります。判断するのは、どの部位を捨てるかではなく、どの順序で使うかです。

---
### 4-1. 脂肪とウサギ飢餓
&nbsp;&nbsp;&nbsp;脂肪は1gあたり約9kcalで、タンパク質と炭水化物の4kcalより2倍以上密度が高くなります。水をほとんど含まず、細菌が育ちにくいため、保存性も最もよいです。飢えた状況では、脂肪は赤身より価値が大きくなります。

| 脂肪の位置 | 性質 | 主な用途 |
| --- | --- | --- |
| 腎臓の周りの脂肪 | 融点が高く硬い、飽和脂肪の割合が高い | 精製して固めると最も長く保管できる |
| 背と皮下の脂肪 | 厚く量が多い | 精製油、赤身を包む保護層 |
| 腹腔の網膜 | 薄い網目状の膜 | 赤身を包んで焼く、乾燥中の乾き過ぎを遅らせる |
| 筋肉の間の脂肪 | 筋線維の間に分散 | 調理中に溶けて風味をつくり、別に回収しにくい |
| 骨髄 | 脂肪含有量がきわめて高い | 骨を割ってすぐ食べる、または煮て油をすくう |
| 脳と目の周り | 脂質とリン脂質が豊富 | 食用のほか、皮の鞣しの材料 |

- 脂肪の精製: 弱火でゆっくり加熱すると、脂肪細胞の膜が破れて油が流れ出し、結合組織は縮んでかすとして残ります。残った水分が蒸発するまで加熱します。水分が残ると、保管中にカビや細菌が育ちます。火が強いと油が焦げて酸化が始まるため、低い温度で長く加熱します。

&nbsp;&nbsp;&nbsp;脂肪が不足したときに現れる問題が、ウサギ飢餓です。体脂肪がほとんどない野生の小型動物の赤身だけを食べ続けたときに生じる代謝異常を指します。原因は、肝臓と腎臓の処理容量です。タンパク質をエネルギーとして使うには、アミノ酸から窒素を切り離さなければならず、窒素はアンモニアを経て尿素に変わり、尿として出ていきます。尿素回路の処理速度は、体重1kgあたり1日2g余り、成人で1日200-300gが限界です。これを超えると、血中のアンモニアとアミノ酸がたまり、尿素を出すために水を大量に使って、脱水も起こります。

| 経過 | 症状 |
| :---: | --- |
| 3-4日 | ひどい疲労感、吐き気、いくら食べても満たされない空腹 |
| 7-10日 | 下痢が始まり、脱水が重なる |
| 2-3週間 | 衰弱が急速に進み、死に至ることがある |

- 安全な範囲: 総摂取熱量のうち、タンパク質の割合を35%未満、できれば25%未満にします。記録された事例では、45%を超えたときに症状が現れました。
- 1日の摂取熱量の30-50%を脂肪から得ます。赤身しかないときは、熱量を満たすためにさらに食べず、根やナッツのように、脂肪や炭水化物をくれるものを一緒に食べます。

> **注意:** 赤身しかなく脂肪がないときは、さらに食べることは解決になりません。脂肪や炭水化物が手に入るまでは、むしろ肉を減らすほうが安全です。

### 4-2. 内臓の栄養とビタミンAの過剰
&nbsp;&nbsp;&nbsp;内臓には、赤身が与えてくれない栄養素が集中して含まれています。肝臓は、ビタミンA、鉄、ビタミンB12、葉酸、銅の貯蔵庫です。穀物と肉だけを食べると数週間で欠乏が起こる栄養素の大部分が、ここにあります。

| 部位 | 主な栄養 | 取り扱いの要点 |
| --- | --- | --- |
| 肝臓 | ビタミンA、鉄、ビタミンB12、葉酸、銅 | 胆嚢を破らずに取り外す。白い点や結節があれば、すべて捨てる |
| 心臓 | 筋肉に近い組成、鉄とコエンザイムQ10 | 弁と固まった血を取り除けば、普通の筋肉のように使う |
| 腎臓 | 鉄とビタミンB群 | 尿のにおいが強いので、半分に割って水に浸してから調理 |
| 肺と脾臓 | タンパク質と鉄 | 組織が粗くて早く傷むので、最初に消費 |
| 脳 | 脂質とリン脂質 | 食用の価値はあるが、プリオン病の危険がある種では避ける |
| 骨髄 | 脂肪と熱量 | 骨を割ってすぐ得られる、最も密度の高い熱量源 |

&nbsp;&nbsp;&nbsp;肝臓には、逆方向の危険があります。ビタミンAは脂溶性なので簡単には排出されず、肝臓に蓄積しますが、一部の動物の肝臓には、人が耐えられない水準のビタミンAが含まれています。北極探検隊が、ホッキョクグマ、アザラシ、そり犬の肝臓を食べて、ひどい頭痛、嘔吐、眠気、数日後に皮膚がはがれる症状に見舞われた記録がいくつもあります。ホッキョクグマの肝臓は、500g食べるだけで急性中毒量に達します。食物連鎖の上位の動物ほど、ビタミンAが段階ごとに濃縮されます。

> **注意:** 肉食性の大型哺乳類と海洋哺乳類の肝臓は食べません。シカ、ウサギ、牛、豚(イノシシを除く)のような草食・雑食動物の肝臓は、常識的な量であれば安全です。それ以外の肝臓も、1日100g余りを超えず、毎日は食べません。

### 4-3. 骨、血、腸、皮
- 骨: それ自体は食べられませんが、骨髄、ゼラチン、ミネラルを含んでいます。切って長く煮ると、関節と軟骨のコラーゲンがゼラチンに溶けて出汁にとろみがつき、硬い部位や根と一緒に煮る、よいベースになります。あらかじめ砕いておくと表面積が増えて抽出が速く、骨髄も一緒に回収できます。
- 血: タンパク質と鉄が豊富ですが、最も早く傷みます。受けたらすぐにかき混ぜて凝固を防ぐか、逆に固めてから調理します。かき混ぜないと、塊と澄んだ液に分かれて扱いにくくなります。塩を入れると凝固が遅くなります。細菌が最も育ちやすい媒質なので、必ず完全に加熱します。
- 腸: 内容物をしごき出した後、裏返して内側の粘膜をこそげ取り、何度かすすぐと、薄くて強靭な膜だけが残ります。この膜がソーセージやスンデ(血の腸詰め)のケーシングになり、乾かすと弓の弦や縫合糸にも使います。反芻動物の胃は特に厚く、別の食材になります。

| 副産物 | 道具としての価値 |
| --- | --- |
| 腱 | 乾かして叩くと繊維にほぐれ、濡らすと再びくっついて、最も強い天然のひもになる |
| 骨 | 錐、針、釣り針、矢じり、掻き器 |
| 角とひづめ | 煮ると柔らかくなって成形でき、冷めると硬くなる。長く煮ると膠(にかわ)になる |
| 皮 | 生皮は乾くと石のように硬くなってひもや容器になり、鞣すと衣服になる |
| 膀胱と胃 | 乾かすと水や油を入れる袋になる |

&nbsp;&nbsp;&nbsp;皮は、剥いだ直後に処理しないと、数時間以内に腐敗が始まります。原理は「皮革の鞣し」の文書で扱います。

### 4-4. 残骸の処理と保存
&nbsp;&nbsp;&nbsp;使えない残骸をどこに置くかは、衛生の問題であり、安全の問題でもあります。内臓の内容物や骨のかけらを作業場の近くに捨てると、3日以内にウジが住みつき、においを嗅ぎつけた捕食者が人の住まいまでやって来ます。クマとイノシシは、数km離れていても腐敗臭を感知します。

| 処理方法 | 原理 | 限界 |
| --- | --- | --- |
| 深く埋める | 土がにおいの拡散を防ぐ | 60cm以上掘る必要があり、浅いと掘り返される |
| 燃やす | 有機物を分解し、においをなくす | 燃料が多く要り、煙が位置を知らせてしまう |
| 水から離す | 飲用水源の汚染を防ぐ | 水源地から最低50m以上離す必要がある |
| 住まいから移す | 捕食者を人から遠ざける | 風が吹いていく側へ移す |

&nbsp;&nbsp;&nbsp;解体が終わると、時間との戦いが始まります。人が1日に食べられる肉は限られており、中型の動物1頭は数日分以上の量です。解体の最後の段階は常に保存であり、保存の計画は解体を始める前に立てておきます。

&nbsp;&nbsp;&nbsp;保存の方法はすべて、細菌が使える水を奪うか、細菌が耐えられない環境をつくるという、1つの原理に収束します。

- 乾燥: 水を蒸発させて水分活性を下げます。
- 塩漬け: 浸透圧で細菌から水を奪います。
- 燻製: 煙のフェノールとアルデヒドで表面を殺菌し、乾燥を助けます。
- 脂肪封じ: 溶かした脂肪を肉の上に注いで固め、酸素と細菌の接近を物理的に遮断します。

&nbsp;&nbsp;&nbsp;各方法の具体的な条件と組み合わせは、「食品保存」の文書に続きます。
