## 4. 無駄のない解体
&nbsp;&nbsp;&nbsp;平時の精肉は赤身肉を中心に置き、それ以外を副産物と呼びますが、災害の状況ではこの区分は成り立ちません。赤身肉は一頭から得られる熱量の半分に満たず、人がまず不足しがちな栄養素である脂肪とビタミンは、そのほとんどが赤身肉以外の場所にあります。どの部位を捨てるかではなく、どの順序で使うかが判断の対象です。

---
### 4-1. 脂肪の価値とウサギ飢餓
&nbsp;&nbsp;&nbsp;脂肪は1gあたり約9kcalで、タンパク質と炭水化物の4kcalより密度が二倍以上高くなっています。同じ重さを運ぶ場合、脂肪が与える熱量は圧倒的で、水分をほとんど含まないため細菌が育ちにくく、保存性も最も優れています。そのため、飢えた状況では脂肪は赤身肉よりも価値が大きくなります。

| 脂肪の部位 | 性質 | 主な用途 |
| --- | --- | --- |
| 腎臓まわりの脂肪 | 融点が高く硬い、飽和脂肪の割合が高い | 精製して固めると最も長く保存できます |
| 背と皮下の脂肪 | 厚く量が多い | 精製した油、赤身肉を包む保護層 |
| 腹腔の網膜（あみあぶら） | 薄い網状の膜 | 赤身肉を包んで焼いたり、乾燥中の乾きを遅らせたりします |
| 筋肉間脂肪 | 筋繊維の間に分散 | 調理中に溶けて風味を生み出しますが、別に回収するのは困難です |
| 骨髄 | 脂肪含有量が非常に高い | 骨を割ってそのまま食べるか、煮て油を取ります |
| 脳と目のまわり | 脂質とリン脂質が豊富 | 食用のほか、なめし（皮革処理）の材料にもなります |

&nbsp;&nbsp;&nbsp;脂肪を精製する原理は単純です。弱火でゆっくり加熱すると脂肪細胞の膜が破れて油が流れ出し、結合組織は縮んでかすとして残ります。残った水分が蒸発しきるまで加熱する必要があり、水分が残っていると保管中にその部分でカビや細菌が繁殖します。火が強いと油が焦げて酸化が始まるため、低い温度で長く置くのが原則です。

&nbsp;&nbsp;&nbsp;脂肪が不足したときに現れる問題がウサギ飢餓です。名前はウサギに由来しますが、体脂肪がほとんどない野生の小型動物の赤身肉ばかりを食べ続けたときに生じる代謝異常全般を指します。原因は肝臓と腎臓の処理能力にあります。タンパク質をエネルギーとして使うには、アミノ酸から窒素を切り離す必要があり、切り離された窒素はアンモニアを経て尿素に変わり、尿として排出されます。尿素回路の処理速度には上限があり、体重1kgあたり1日2gあまり、成人であれば1日200~300g程度が限界です。これを超えると血中のアンモニアとアミノ酸が蓄積し、尿素を排出するために大量の水を使わなければならず、脱水も同時に起こります。

| 経過 | 症状 |
| :---: | --- |
| 3-4日 | 強い倦怠感、吐き気、いくら食べても満たされない空腹感 |
| 7-10日 | 下痢が始まり、脱水が重なります |
| 2-3週間 | 衰弱が急速に進み、死に至ることもあります |

&nbsp;&nbsp;&nbsp;安全な範囲は、総摂取熱量に占めるタンパク質の割合を35%未満、できれば25%未満に抑えることです。記録された事例では、この割合が45%を超えたときに症状が現れました。実用的には、1日の摂取熱量の30-50%を脂肪から得る必要があり、赤身肉しかない状況では、熱量を満たすためにさらに多く食べるのではなく、根菜や木の実のように脂肪や炭水化物を主に与えるものを一緒に食べなければなりません。

> **赤身肉しかなく脂肪がない場合、もっと食べることは解決策ではありません。脂肪や炭水化物が手に入るまでは、むしろ肉を減らすほうが安全です。**

### 4-2. 内臓の栄養とビタミンA過剰症
&nbsp;&nbsp;&nbsp;内臓には、野生で得られる栄養素のうち赤身肉では補えないものが集中的に詰まっています。特に肝臓はビタミンA、鉄、ビタミンB12、葉酸、銅の貯蔵庫です。穀物と肉だけを食べていると数週間のうちに欠乏する栄養素の大半が、ここに含まれています。

| 部位 | 主な栄養 | 取り扱いの要点 |
| --- | --- | --- |
| 肝臓 | ビタミンA、鉄、ビタミンB12、葉酸、銅 | 胆嚢を破らずに取り外し、白い斑点や結節があれば全部廃棄します |
| 心臓 | 筋肉に近い組成、鉄とコエンザイムQ10 | 弁と固まった血を取り除けば、普通の筋肉と同じように使えます |
| 腎臓 | 鉄とビタミンB群 | 尿の臭いが強いため、半分に割って水に浸してから調理します |
| 肺と脾臓 | タンパク質と鉄 | 組織が粗く傷みやすいため、最初に消費します |
| 脳 | 脂質とリン脂質 | 食用としての価値はありますが、プリオン病の危険がある種では避けます |
| 骨髄 | 脂肪と熱量 | 骨を割ればすぐ得られる、最も密度の高い熱量源です |

&nbsp;&nbsp;&nbsp;肝臓には正反対の方向の危険もあります。ビタミンAは脂溶性であるため体から排出されにくく、肝臓に蓄積します。ところが一部の動物の肝臓は、人間が処理しきれない水準のビタミンAを含んでいます。北極で活動した探検隊が、ホッキョクグマやアザラシ、そり犬の肝臓を食べて激しい頭痛と嘔吐、眠気、数日後には皮膚が剥がれる症状を経験した記録が複数残っています。ホッキョクグマの肝臓はわずか500gを食べただけでも急性中毒量に達します。

&nbsp;&nbsp;&nbsp;このような蓄積が起こるのは、これらの動物が食物連鎖の上位に位置し、ビタミンAが段階を追うごとに濃縮されるためです。反対に、シカ、ウサギ、牛、豚（イノシシを除く）のように草食性または雑食性の動物の肝臓は、常識的な量を食べる限り安全です。ルールは単純です。肉食性の大型哺乳類と海洋哺乳類の肝臓は食べず、それ以外の肝臓も1日に100gあまりを超えないようにし、毎日は食べないことです。

### 4-3. 骨と血、腸、そして皮
&nbsp;&nbsp;&nbsp;骨はそれ自体を食べることはできませんが、骨髄とゼラチン、ミネラルを含んでいます。骨を切って長く煮込むと、関節と軟骨のコラーゲンがゼラチンとなって溶け出し、スープに粘性が生まれます。このスープは、硬い部位や根菜を一緒に煮込むための最良の土台になります。骨をあらかじめ砕いておくと表面積が増えて抽出が速くなり、骨髄まで一緒に回収できます。

&nbsp;&nbsp;&nbsp;血はタンパク質と鉄が豊富ですが、最も早く傷む部位でもあります。受け取ったらすぐにかき混ぜて凝固を防ぐか、逆に固めてから調理する必要があり、かき混ぜずに放置すると塊と透明な液体に分かれて扱いにくくなります。塩を加えると凝固が遅くなります。ただし血は細菌が最もよく育つ培地であるため、必ず完全に加熱しなければなりません。

&nbsp;&nbsp;&nbsp;腸は内容物をしごき出した後、裏返して内側の粘膜をこそげ取り、何度もすすぐと薄くて丈夫な膜だけが残ります。この膜がソーセージやスンデ（韓国式腸詰め）のケーシングになり、乾燥させれば弓の弦や縫合糸としても使えます。胃は反芻動物で特に厚く、別の食材になります。

| 副産物 | 道具としての価値 |
| --- | --- |
| 腱 | 乾かして叩くと繊維状にほぐれ、濡らすと再び結着して最も強い天然の紐になります |
| 骨 | 錐、針、釣り針、鏃、スクレイパー |
| 角と蹄 | 煮ると軟らかくなって成形でき、冷めると硬くなります。長く煮ると膠になります |
| 皮 | 生皮は乾くと石のように硬くなり、紐や容器になり、なめすと衣服になります |
| 膀胱と胃 | 乾かすと水や油を入れる袋になります |

&nbsp;&nbsp;&nbsp;皮は剥いだ直後に処理しないと、数時間以内に腐敗が始まります。詳しい原理は、生存技術のなめし（皮革処理）の文書で扱います。

### 4-4. 残骸の処理と保存への移行
&nbsp;&nbsp;&nbsp;使えない残骸をどこに置くかは、衛生の問題であると同時に安全の問題でもあります。内臓の内容物や骨片を作業場の近くに捨てると、三日以内にハエのウジが住み着き、臭いを嗅ぎつけた捕食者が人の住みかまで訪ねてきます。クマやイノシシは数キロメートル先からでも腐敗臭を感知します。

| 処理方法 | 原理 | 限界 |
| --- | --- | --- |
| 深く埋める | 土が臭いの拡散を防ぎます | 60cm以上掘る必要があり、浅いと掘り返されます |
| 焼却する | 有機物を分解し、臭いをなくします | 燃料を多く使い、煙で位置が露見します |
| 水場から離す | 飲用水源の汚染を防ぐ | 上水源から最低50m以上離す必要があります |
| 住みかから移す | 捕食者を人から遠ざけます | 風が吹いていく方向へ移動させます |

&nbsp;&nbsp;&nbsp;解体が終わると、時間との戦いが始まります。人が一日に食べられる肉の量には限りがあり、中型動物一頭は一度に数日分以上の量をもたらします。そのため解体の最後の段階は常に保存であり、保存の計画は解体を始める前に立てておかなければなりません。

&nbsp;&nbsp;&nbsp;保存方法はすべて一つの原理に収束します。細菌が使える水を奪うか、細菌が耐えられない環境をつくるかです。乾燥は水分を蒸発させて水分活性を下げ、塩漬けは浸透圧によって細菌から水分を奪い、燻煙は煙に含まれるフェノールとアルデヒドで表面を殺菌すると同時に乾燥を助けます。脂肪で封じる方法は、溶かした脂肪を肉の上に注いで固め、酸素と細菌の接触を物理的に遮断します。各方法の具体的な条件と組み合わせは、食品保存の文書で続けて扱います。
