## 4. 狩猎工具与野生动物传来的疾病
&nbsp;&nbsp;&nbsp;在没有通道的开阔地、鸟类聚集的水边、没有陷阱材料的环境这类仅靠陷阱无法应对的情况下，需要投掷和射击的工具。狩猎工具说到底，都是人的肌肉产生的能量如何储存、又如何集中到多小的面积上的问题。

---
### 4-1. 从能量传递看狩猎工具
&nbsp;&nbsp;&nbsp;人的手臂又短又慢。徒手投掷的石头的速度由手臂的长度和旋转速度决定，不会超过这个上限。所有投射武器，都是为了突破这个限制，要么加长杠杆，要么预先储存能量再一次性释放。

| 工具 | 增加能量的方法 | 特点 |
| --- | --- | --- |
| 投掷棒 | 转动惯量和宽的打击面积 | 最容易制作，对地栖鸟类和小动物有效 |
| 投石索（sling） | 按绳子长度增大回转半径 | 威力大，但练熟要很长时间 |
| 投矛 | 以整条手臂作杠杆 | 射程短，易回收 |
| 投矛器（阿特拉特尔） | 人为延长手臂长度 | 同样的力下大幅提高矛的速度 |
| 弓 | 把拉弦期间的力储存在弓臂中 | 一次性释放储存的能量 |

- 投矛器：增加手臂的有效长度。钩住矛尾端的短杆从手腕处延伸出去，放矛瞬间的切线速度与回转半径成正比增大。臂长70cm的人使用50cm的投矛器，有效半径变为1.7倍，同样角速度下速度也是1.7倍。动能与速度的平方成正比，所以能量约为3倍。
- 弓：拉弦期间所做的功储存为弓臂的弹性能量，松手的瞬间转移到箭上。储存的功接近拉力与拉距相乘的面积。同样张力下，拉距长的弓更强，同样拉距下，张力大的弓更强。弓短的话，拉同样的距离弓臂也会弯得过度而折断，所以拉距不能增加。这就是弓要做得大的原因。

| 要素 | 原理 | 失败的原因 |
| --- | --- | --- |
| 弓臂材料 | 必须同时耐压缩和拉伸 | 干木头在拉伸一侧开裂 |
| 弓臂厚度 | 越往两端越薄 | 厚度均匀的话只有中间弯曲而折断 |
| 拉距 | 越长储存的能量越多 | 超过弓长的一半就危险 |
| 弓弦 | 不得伸长 | 会伸长的绳子会吸收能量 |
| 箭杆的直线性 | 弯曲的话方向会偏 | 用热把弯曲的树枝烤直后使用 |
| 箭的重量 | 越重穿透力越大，越轻速度越快 | 太轻会折断弓 |
| 箭羽 | 通过旋转和阻力稳定姿态 | 没有箭羽，箭会横着飞出去 |

- 弓的材料选用白蜡树、桑树、栎树、竹子这类弹性大、纹理直的木材。
- 使木头的外层成为弓背。外侧纤维耐拉伸，内侧耐压缩。方向弄反的话，弓几乎一定会折断。
- 弓是灾难情况下最难做的工具之一。晾干和修整弓臂要花好几周，还得备齐弓弦、箭、箭羽，要命中则需要长期练习。不是当下正在挨饿的人最先要动手的对象。用陷阱建立起基本供给、有了余力之后，再作为长期投资开始。

### 4-2. 从野生动物传给人的疾病
&nbsp;&nbsp;&nbsp;处理野生动物时，有一种比枪伤或咬伤常见得多、也更隐蔽的危险，就是人畜共患传染病。感染途径直接决定烹调和处理方式。

| 疾病 | 主要媒介 | 感染途径 | 对处理的限制 |
| --- | --- | --- | --- |
| 狂犬病 | 貉、獾、蝙蝠、犬科动物 | 咬伤，经伤口的唾液 | 行为异常的动物，不抓也不碰 |
| 兔热病（土拉菌病） | 兔类、啮齿类、蜱虫 | 皮肤伤口、吸入、未煮熟的肉 | 不徒手剥皮，并彻底煮熟 |
| 布鲁氏菌病 | 野猪、鹿类 | 接触血液和体液，生食 | 分解时避免体液溅入眼睛和口中 |
| 钩端螺旋体病 | 鼠等啮齿类、被污染的水 | 经伤口和黏膜接触尿液 | 有伤口就不要下水 |
| 弓形虫病 | 猫科动物、肉类 | 未煮熟的肉中的包囊 | 充分加热即可杀死 |
| 汉坦病毒 | 黑线姬鼠等啮齿类 | 吸入干燥的排泄物 | 不要干扫洞穴和巢窝 |
| 旋毛虫病 | 野猪、熊 | 肌肉中带有幼虫的肉 | 必须煮熟到中心 |
| 禽流感 | 野生鸟类 | 接触粪便、体液 | 不碰死亡的鸟类 |

&nbsp;&nbsp;&nbsp;反复出现的规则有三条。

1. 体液和血液经皮肤伤口和黏膜进入。手上有伤口就不要分解动物，或者用什么东西盖住。
2. 大部分病原体经充分加热即可杀死。野生肉毫无例外地要完全煮熟了吃。只烹熟表面，对肌肉中的幼虫没有效果。
3. 有吸入干燥排泄物的途径。动物的洞穴或巢窝处，不要干扫或掸拍，要洒水压住灰尘后再清理。

- 行为与平时不同的动物不捕。本是夜行性却在白天走动、看到人也不逃跑、摇摇晃晃或流口水的动物，容易捕，也就很可能病了。
- 被陷阱捕到的个体中，格外瘦、掉毛，或肝脏和脾脏上有白点，或腹腔里有脓和恶臭的，全部丢弃。吃了得到的热量，远不及可能失去的。

> **注意：** 野生肉毫无例外地要煮熟到中心再吃。行为异常或脏器看起来有异常的个体，即使饿也要丢弃。

### 4-3. 法律与伦理
&nbsp;&nbsp;&nbsp;本文内容平时不能原样实施（参见引言中的法律注意事项）。大韩民国的狩猎许可分为使用枪支的第一类和使用其他工具的第二类，必须经过考试、培训和体检。套索、陷阱、坑阱不分对象物种，甚至会捕到濒危物种，所以原则上禁止。

&nbsp;&nbsp;&nbsp;即使在生存状况下，仍然保留三条原则。

- 只捕需要的量。
- 捕到的不浪费。
- 离开时把陷阱全部收走。

&nbsp;&nbsp;&nbsp;把一个地区的动物全部捕光，在那个地区就很难过下一个季节，灾难持续得越久，这种损失越会回到人自己身上。如何把捕到的动物毫无剩余地用掉，在屠宰文档中继续讲述。
