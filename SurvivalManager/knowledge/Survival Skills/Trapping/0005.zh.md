## 4. 狩猎工具与来自野生动物的疾病
&nbsp;&nbsp;&nbsp;有些情况单靠陷阱应付不了。在没有兽道的开阔地、鸟类聚集的水边、缺乏制作陷阱材料的环境中，就需要投掷或发射类的工具。所有狩猎工具，归根结底都是同一个问题：如何储存人体肌肉产生的能量，再把它集中到多小的面积上释放。

---
### 4-1. 从能量传递看狩猎工具
&nbsp;&nbsp;&nbsp;人的手臂又短又慢。徒手投掷石块的速度由手臂长度和旋转速度决定，超过这个限度就上不去了。所有投射武器为了突破这个极限，都会采用两种方法之一：把杠杆加长，或者预先储存能量、再一次性释放。

| 工具 | 增大能量的方法 | 特点 |
| --- | --- | --- |
| 投掷棒 | 转动惯量与较大的打击面 | 最容易制作，对地栖鸟类和小型动物有效 |
| 投石器（弹弓/甩石器） | 靠绳长增加旋转半径 | 威力大，但需要很长时间才能熟练 |
| 投矛 | 把整条手臂当作杠杆使用 | 射程短，但容易回收 |
| 投矛器（阿特拉特尔） | 人为延长手臂的长度 | 用同样的力气大幅提高矛的速度 |
| 弓 | 把拉弦过程中的力储存在弓身里 | 一次性释放储存的能量 |
| 陷阱 | 不使用人的力气 | 不能与上述工具相提并论 |

&nbsp;&nbsp;&nbsp;投矛器提升威力的原理，是延长手臂的有效长度。挂住矛尾的短棍从手腕处伸出去后，投出瞬间的切线速度就会随旋转半径成比例增大。一个手臂长70cm的人，如果使用长50cm的投矛器，有效半径就变为1.7倍；角速度相同的话，矛的速度也会相应提高。动能与速度的平方成正比，因此能量会变为约3倍。

&nbsp;&nbsp;&nbsp;弓则是另一种原理。拉弦过程中人所做的功，会以弹性能的形式储存在弓身里，松手的瞬间这份能量转移到箭上。储存的功的大小，接近于力与距离的乘积，也就是拉力乘以拉距所构成的面积。因此，张力相同时，拉距越长的弓储存的能量越多；拉距相同时，张力越大的弓越强劲。这就是弓要做得大的原因。弓身短的话，拉开同样的距离会让弓身弯曲过度而折断，因此无法增加拉距。

| 要素 | 原理 | 失败的原因 |
| --- | --- | --- |
| 弓身材料 | 必须同时耐压缩和耐拉伸 | 干木头会从受拉一侧裂开 |
| 弓身厚度 | 越靠两端越薄 | 厚度均匀的话只有中段会弯折 |
| 拉距 | 越长储存的能量越多 | 超过弓长的一半就很危险 |
| 弓弦 | 不能拉伸变长 | 会伸长的绳会把能量吸收掉 |
| 箭杆的直度 | 弯曲会导致方向偏移 | 弯曲的树枝要用热处理拉直后使用 |
| 箭的重量 | 越重穿透力越强，越轻速度越快 | 太轻会把弓震坏 |
| 箭羽 | 靠旋转和阻力稳定姿态 | 没有箭羽，箭会横着飞 |

&nbsp;&nbsp;&nbsp;弓的材料要用白蜡树、桑树、栎树、竹子这类弹性大、纹理直的木材。最好的做法是让木材外侧的一层成为弓背。木材外侧的纤维耐拉伸，内侧耐压缩，这样正好把树木生长时形成的结构，对应到弓身受力的分布上。如果把方向弄反，弓几乎必定会断裂。

&nbsp;&nbsp;&nbsp;然而，弓是灾难状况下最难制作的工具之一。晾干并打磨弓身需要好几周，还得配齐弓弦、箭和箭羽，要射中目标更需要长期练习。这不是正在挨饿的人一开始就该碰的东西。现实的顺序是：先用陷阱建立基本的食物供给，等有余力了，再把弓当作长期投资来着手制作。

### 4-2. 从野生动物传给人的疾病
&nbsp;&nbsp;&nbsp;处理野生动物时，有一种比枪伤或咬伤远为常见、也远为无声的危险，那就是人畜共患病。这些疾病之所以重要，不只是因为危险，更因为它们的传播途径直接决定了烹饪和处理的方式。

| 疾病 | 主要携带者 | 传播途径 | 对处理方式的限制 |
| --- | --- | --- | --- |
| 狂犬病 | 貉、狗獾、蝙蝠、犬科动物 | 咬伤，唾液经伤口进入 | 行为异常的动物既不能捕捉也不能触碰 |
| 兔热病 | 兔类、啮齿类、蜱虫 | 皮肤伤口、吸入、未熟肉 | 不徒手剥皮，并要彻底煮熟 |
| 布鲁氏菌病 | 野猪、鹿类 | 接触血液和体液、生食 | 分割时避免体液溅入眼睛和口中 |
| 钩端螺旋体病 | 老鼠等啮齿类、受污染的水 | 尿液经伤口或黏膜接触 | 有伤口时不要下水 |
| 弓形虫病 | 猫科动物、肉类 | 未熟肉中的包囊 | 充分加热可将其杀灭 |
| 汉坦病毒 | 黑线姬鼠等啮齿类 | 吸入干燥的排泄物 | 不要在干燥状态下清扫洞穴和巢穴 |
| 旋毛虫病 | 野猪、熊 | 肌肉中带幼虫的肉 | 必须彻底加热至中心部位 |
| 禽流感 | 野生鸟类 | 接触粪便、体液 | 不要触碰死去的鸟 |

&nbsp;&nbsp;&nbsp;这份清单中反复出现的规律有三条。第一，体液和血液经由皮肤伤口和黏膜进入体内，因此手上有伤口时不应进行分割处理，或必须用东西包扎好。第二，大多数病原体经充分加热即可被杀灭，因此野味无一例外都必须彻底煮熟才能吃，只把表面烤熟的做法对肌肉内的幼虫毫无效果。第三，存在吸入干燥排泄物这一传播途径，因此动物的洞穴或巢穴不能在干燥状态下使用或拍打清扫，必须先洒水使其湿润后再清理。

&nbsp;&nbsp;&nbsp;行为异于寻常的动物不要捕捉。明明是夜行性动物却在白天出没、见人也不逃跑、走路摇晃或流口水的动物，越容易捕捉，патients患病的可能性就越高。即使是落入陷阱的个体，凡是身体异常消瘦、掉毛，或肝脏和脾脏上有白斑，或腹腔中有脓液和恶臭的，都必须全部丢弃。吃下这样一个个体所获得的热量，远远比不上可能因此失去的东西。

&nbsp;&nbsp;&nbsp;这些规则可以归纳成一句话：野味无一例外要彻底加热到中心部位再吃，行为异常或脏器有异样的个体，哪怕再饿也要丢弃。

### 4-3. 法律与伦理
&nbsp;&nbsp;&nbsp;本文档整理的内容，并不是平时可以照做的知识。在韩国，只有依据《野生生物保护及管理法》取得狩猎许可证、并在指定猎场获得狩猎批准的人，才能在规定的时期猎取规定的物种。狩猎许可证分为使用枪支的第1种和使用其他工具的第2种，都必须经过考试、培训和体检。尤其是设置套索、陷阱和陷坑，不分对象物种、连濒危物种也会被捕获，因此原则上禁止，无证狩猎将被处以2年以下有期徒刑或2,000万韩元以下罚款。其他国家大多也有类似规定。本文档是以公共体系无法运作的生存状况为前提整理的知识，在平时必须先确认读者所在国的狩猎法和野生生物保护法，并只能在其规定范围内行事。

&nbsp;&nbsp;&nbsp;即便身处生存状况，也有不变的原则：只捕获需要的量，捕到的绝不浪费，离开时收走所有陷阱。如果把一个地区的动物捕捞殆尽，这个地区就很难撑过下一个季节；灾难持续得越久，这种损失最终就越会转嫁到人类自己身上。如何把捕获的动物物尽其用，将在屠宰与分割文档中继续讨论。
