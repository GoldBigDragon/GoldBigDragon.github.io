## 4. 狩猟道具と野生動物から来る病気
&nbsp;&nbsp;&nbsp;通り道のない開けた場所、鳥が集まる水辺、罠の材料がない環境のように、罠だけでは対応できない状況では、投げたり射たりする道具が必要です。狩猟道具はすべて、人の筋肉がつくったエネルギーをどう蓄え、どれだけ小さな面積に集中させるかという問題です。

---
### 4-1. エネルギー伝達で見る狩猟道具
&nbsp;&nbsp;&nbsp;人の腕は短くて遅いものです。素手で投げる石の速度は、腕の長さと回転速度で決まり、それ以上は上がりません。すべての投射武器は、この限界を超えるために、てこを長くするか、エネルギーをあらかじめ蓄えておいて一度に放ちます。

| 道具 | エネルギーを大きくする方法 | 特徴 |
| --- | --- | --- |
| 投げ棒 | 回転慣性と広い打撃面積 | 最も作りやすく、地上性の鳥類や小型動物に有効 |
| 投石器(スリング) | ひもの長さの分、回転半径を延ばす | 威力は大きいが、習熟に非常に長くかかる |
| 投げ槍 | 腕全体をてことして使う | 射程が短く、回収が易しい |
| 投槍器(アトラトル) | 腕の長さを人工的に延長 | 同じ力で槍の速度を大きく上げる |
| 弓 | 弦を引く間の力を弓の腕に蓄える | 蓄えたエネルギーを一度に放つ |

- 投槍器: 腕の有効な長さを延ばします。槍の後端を引っかけた短い棒が手首から伸びると、槍を放す瞬間の接線速度が回転半径に比例して大きくなります。腕の長さ70cmの人が長さ50cmの投槍器を使うと、有効半径が1.7倍になり、同じ角速度なら速度も1.7倍です。運動エネルギーは速度の2乗に比例するので、エネルギーは約3倍になります。
- 弓: 弦を引く間にした仕事が弓の腕の弾性エネルギーとして蓄えられ、放す瞬間に矢へ移っていきます。蓄えられる仕事は、引く力と引く長さを掛けた面積に近くなります。同じ張力なら引く長さが長い弓が、同じ引く長さなら張力が大きい弓が、より強力です。弓が短いと、同じ距離を引いても弓の腕が曲がりすぎて折れるので、引く長さを延ばせません。弓を大きくつくる理由です。

| 要素 | 原理 | 失敗の原因 |
| --- | --- | --- |
| 弓の腕の材料 | 圧縮と引っ張りの両方に耐える必要がある | 乾いた木は引っ張り側で裂ける |
| 弓の腕の厚さ | 両端に行くほど薄く | 厚さが均一だと真ん中だけが曲がって折れる |
| 引く長さ | 長いほど蓄えるエネルギーが増える | 弓の長さの半分を超えると危険 |
| 弦 | 伸びてはならない | 伸びるひもはエネルギーを吸収する |
| 矢柄の直進性 | 曲がると方向がそれる | 曲がった枝を熱でまっすぐにして使う |
| 矢の重さ | 重いほど貫通力、軽いほど速度 | 軽すぎると弓を折ってしまう |
| 矢羽根 | 回転と抗力で姿勢を安定させる | 羽根がないと矢が横になって飛ぶ |

- 弓の材料には、トネリコ、クワ、カシ、竹のように、弾性が大きく木目がまっすぐなものを使います。
- 木の外側の層が弓の背になるようにします。外側の繊維は引っ張りに強く、内側は圧縮に強いのです。向きを逆にすると、弓はほぼ必ず折れます。
- 弓は、災害時に最もつくりにくい道具の1つです。弓の腕を乾かして整えるのに数週間かかり、弦・矢・矢羽根までそろえる必要があり、命中させるには長い練習が必要です。今まさに飢えている人が最初に手を出す対象ではありません。罠で基本の供給をつくり、余裕ができたら、長期の投資として始めます。

### 4-2. 野生動物から人にうつる病気
&nbsp;&nbsp;&nbsp;野生動物を扱うときには、銃創やかみ傷よりはるかに多く静かな危険である、人獣共通感染症があります。感染経路が、調理と取り扱いの方法を直接決めます。

| 病気 | 主な媒介 | 感染経路 | 取り扱いへの制約 |
| --- | --- | --- | --- |
| 狂犬病 | タヌキ、アナグマ、コウモリ、イヌ科の動物 | かみ傷、傷口からの唾液 | 行動のおかしい動物は、捕まえも触れもしない |
| 野兎病 | ウサギ類、げっ歯類、マダニ | 皮膚の傷、吸入、加熱不足の肉 | 素手で皮を剥がさず、完全に加熱する |
| ブルセラ症 | イノシシ、シカ類 | 血液や体液との接触、生食 | 解体時に目や口に体液が飛ばないようにする |
| レプトスピラ症 | ネズミなどのげっ歯類、汚染された水 | 傷や粘膜からの尿との接触 | 傷があるときは水に入らない |
| トキソプラズマ症 | ネコ科の動物、肉 | 加熱不足の肉のシスト | 十分な加熱で死滅 |
| ハンタウイルス | アカネズミなどのげっ歯類 | 乾いた排泄物の吸入 | 巣穴や巣を乾いたまま掃かない |
| 旋毛虫症 | イノシシ、クマ | 筋肉中に幼虫のいる肉 | 中心部まで完全に加熱する必要がある |
| 鳥インフルエンザ | 野生の鳥類 | 糞便、体液との接触 | 死んだ鳥類には触れない |

&nbsp;&nbsp;&nbsp;繰り返される規則は3つあります。

1. 体液と血液は、皮膚の傷と粘膜から入ってきます。手に傷があれば解体しないか、何かで覆います。
2. 大部分の病原体は、十分な加熱で死滅します。野生の肉は、例外なく完全に加熱して食べます。表面だけ焼く調理は、筋肉中の幼虫には効果がありません。
3. 乾いた排泄物を吸い込む経路があります。動物の巣穴や巣の跡は、乾いたまま掃いたり払ったりせず、水をまいて沈めてから片づけます。

- 普段と違う行動をする動物は捕らえません。夜行性なのに昼間に歩き回る、人を見ても逃げない、ふらついたりよだれを垂らしたりしている動物は、捕まえやすい分、病気である可能性が高いものです。
- 罠にかかった個体のうち、特にやせて毛が抜けていたり、肝臓と脾臓に白い点があったり、腹腔に膿と悪臭があったりするものは、すべて捨てます。食べて得られる熱量よりも、失うもののほうがはるかに大きいのです。

> **注意:** 野生の肉は、例外なく中心部まで完全に加熱して食べます。行動がおかしかったり、臓器に異常が見られたりする個体は、空腹でも捨てます。

### 4-3. 法と倫理
&nbsp;&nbsp;&nbsp;この文書の内容は、平常時にはそのまま実行できません(はじめにの法的な注意を参照)。大韓民国の狩猟免許は、銃器を使う第1種と、それ以外の道具を使う第2種に分かれ、試験、講習、身体検査を経なければなりません。くくり罠・罠・落とし穴は、対象となる種を選ばず、絶滅危惧種までかかってしまうため、原則として禁止されています。

&nbsp;&nbsp;&nbsp;生存状況でも残る原則は3つあります。

- 必要な分だけ獲ります。
- 獲ったものは捨てません。
- 去るときは罠をすべて回収します。

&nbsp;&nbsp;&nbsp;ある地域の動物をすべて獲り尽くすと、その地域で次の季節を越すのが難しくなり、災害が長引くほど、この損失は人自身に返ってきます。獲った動物を余すところなく使う方法は、屠畜の文書に続きます。
