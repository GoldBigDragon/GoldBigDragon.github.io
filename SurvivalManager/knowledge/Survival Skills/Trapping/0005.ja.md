## 4. 狩猟道具と野生動物から来る病気
&nbsp;&nbsp;&nbsp;罠だけでは対応できない状況もあります。通り道のない開けた場所、鳥が集まる水辺、罠を作る材料がない環境では、投げたり撃ったりする道具が必要です。狩猟道具はすべて、人の筋肉が生み出したエネルギーをどう蓄え、どれだけ小さな面積に集中させるかという問題に還元されます。

---
### 4-1. エネルギー伝達から見た狩猟道具
&nbsp;&nbsp;&nbsp;人の腕は短くて遅いものです。素手で投げる石の速度は腕の長さと回転速度で決まり、それ以上には上がりません。あらゆる投射武器は、この限界を超えるために二つの方法のどちらかを使います。てこを長くするか、エネルギーをあらかじめ蓄えておいて一度に放出するかです。

| 道具 | エネルギーを大きくする方法 | 特徴 |
| --- | --- | --- |
| 投げ棒 | 回転慣性と広い打撃面積 | もっとも作りやすく、地上性の鳥や小型動物に有効です |
| 投石器（スリング） | 紐の長さの分だけ回転半径を伸ばす | 威力は大きいが習熟に非常に時間がかかります |
| 投げ槍 | 腕全体をてことして使う | 射程は短いが回収は容易です |
| 投槍器（アトラトル） | 腕の長さを人為的に延長する | 同じ力で槍の速度を大きく上げます |
| 弓 | 弦を引く間の力を弓の本体に蓄える | 蓄えたエネルギーを一度に放出します |
| 罠 | 人の力を使わない | 上記の道具とは比較の対象になりません |

&nbsp;&nbsp;&nbsp;投槍器が威力を高める原理は、腕の有効な長さを伸ばすことです。槍の後端を引っかけた短い棒が手首から延びていると、槍を放す瞬間の接線速度は回転半径に比例して大きくなります。腕の長さが70cmの人が長さ50cmの投槍器を使うと有効半径は1.7倍になり、同じ角速度であれば槍の速度もその分だけ上がります。運動エネルギーは速度の二乗に比例するため、エネルギーは約3倍になります。

&nbsp;&nbsp;&nbsp;弓は別の原理です。弦を引く間に人がした仕事が弓の本体に弾性エネルギーとして蓄えられ、放す瞬間にそのエネルギーが矢に移ります。蓄えられる仕事の大きさは力と距離の積、つまり引く力と引き幅を掛けた面積に近いものです。そのため、同じ張力なら引き幅が長い弓のほうがより多くのエネルギーを蓄え、同じ引き幅なら張力が大きい弓のほうが強くなります。弓を大きく作る理由はここにあります。弓が短いと、同じ距離を引いても弓の本体が過度にしなって折れてしまうため、引き幅を伸ばせません。

| 要素 | 原理 | 失敗の原因 |
| --- | --- | --- |
| 弓の材料 | 圧縮と引張の両方に耐えなければならない | 乾いた木は引張側から裂けます |
| 弓の厚み | 両端に向かうほど薄く | 厚みが均一だと中央だけがしなって折れます |
| 引き幅 | 長いほど蓄積エネルギーが増加 | 弓の長さの半分を超えると危険です |
| 弦 | 伸びてはいけない | 伸びる紐はエネルギーを吸収してしまいます |
| 矢柄の直進性 | 曲がっていると方向がずれる | 曲がった枝は熱で伸ばして使います |
| 矢の重さ | 重いほど貫通力、軽いほど速度 | 軽すぎると弓を壊します |
| 矢羽根 | 回転と抗力で姿勢を安定させる | 矢羽根がないと矢が横向きに寝て飛びます |

&nbsp;&nbsp;&nbsp;弓の材料には、トネリコ、クワ、ナラ類、竹のように弾性が大きく木目がまっすぐなものを使います。もっとも良い形は、木の外側の層が弓の外側（背）になるようにすることです。木の外側の繊維は引張に強く、内側は圧縮に強いため、木が育つときの構造をそのまま弓の力の分布に合わせることになります。この向きを逆にすると、弓はほぼ確実に折れます。

&nbsp;&nbsp;&nbsp;しかし弓は、災害状況でもっとも作りにくい道具の一つです。弓の本体を乾燥させて仕上げるのに何週間もかかり、弦と矢と矢羽根まで揃えなければならず、命中させるには長い練習が必要です。今まさに飢えている人が最初に手を出す対象ではありません。罠で基本の供給を確保したあと、余裕ができたときに長期投資として始めるという順序が現実的です。

### 4-2. 野生動物から人へとうつる病気
&nbsp;&nbsp;&nbsp;野生動物を扱う作業には、銃創や咬傷よりもはるかにありふれていて静かな危険があります。人獣共通感染症です。これらの病気が重要なのは、単に危険だからではなく、感染経路が調理と取り扱いの方法を直接決めるからです。

| 病気 | 主な媒介 | 感染経路 | 取り扱い上の制約 |
| --- | --- | --- | --- |
| 狂犬病 | タヌキ、アナグマ、コウモリ、イヌ科動物 | 咬傷、傷口を通じた唾液 | 行動がおかしい動物は捕まえも触りもしません |
| 野兎病 | ウサギ類、齧歯類、ダニ | 皮膚の傷、吸入、加熱不十分な肉 | 素手で皮をはがず、完全に加熱します |
| ブルセラ症 | イノシシ、シカ類 | 血液と体液への接触、生食 | 解体時に目や口へ体液が飛ばないようにします |
| レプトスピラ症 | ネズミなどの齧歯類、汚染された水 | 傷口や粘膜を通じた尿への接触 | 傷があるときは水に入りません |
| トキソプラズマ症 | ネコ科動物、食肉 | 加熱不十分な肉の中の嚢子 | 十分な加熱で死滅させます |
| ハンタウイルス | セスジネズミなどの齧歯類 | 乾燥した排泄物の吸入 | 巣穴や巣を乾いたまま掃きません |
| 旋毛虫症 | イノシシ、クマ | 筋肉内に幼虫がいる肉 | 中心部まで完全に加熱しなければなりません |
| 鳥インフルエンザ | 野生の鳥 | 糞便、体液への接触 | 死んでいる鳥には触れません |

&nbsp;&nbsp;&nbsp;この一覧に繰り返し現れる規則は三つです。第一に、体液と血液は皮膚の傷や粘膜から入り込むため、手に傷があるときは解体をしないか、何かで覆わなければなりません。第二に、ほとんどの病原体は十分な加熱で死滅するため、野生の肉は例外なく完全に加熱して食べる必要があり、表面だけを炙る調理は筋肉内の幼虫にはまったく効果がありません。第三に、乾いた排泄物を吸い込むという経路があるため、動物の巣穴や巣の跡を乾いたまま使ったり払い落としたりしてはならず、水をまいて湿らせてから片付けなければなりません。

&nbsp;&nbsp;&nbsp;いつもと違う行動をする動物は捕まえません。夜行性なのに昼間歩き回っている、人を見ても逃げない、よろめいたりよだれを垂らしたりしている動物は、捕まえやすい分だけ病気にかかっている可能性が高いのです。罠にかかった個体の中でも、体が異様に痩せて毛が抜けていたり、肝臓や脾臓に白い斑点があったり、腹腔に膿と悪臭があったりする個体は、すべて処分しなければなりません。こうした個体を一つ食べて得られる熱量よりも、失うもののほうがはるかに大きいのです。

&nbsp;&nbsp;&nbsp;これらの規則は一つの文にまとめられます。野生の肉は例外なく中心部まで完全に加熱して食べ、行動がおかしいか臓器に異常が見える個体は、腹が減っていても処分するということです。

### 4-3. 法と倫理
&nbsp;&nbsp;&nbsp;この文書にまとめた内容は、平時にそのまま実行できる知識ではありません。韓国では、「野生生物の保護及び管理に関する法律」に従って狩猟免許を取得し、指定された猟場で狩猟承認を受けた人だけが、定められた時期に定められた種を捕獲できます。狩猟免許は、銃器を使う第1種とそれ以外の道具を使う第2種に分かれ、試験と講習、身体検査を経なければなりません。特にくくり罠や箱罠、落とし穴の設置は対象種を問わず絶滅危惧種までかかってしまうため原則として禁止されており、無免許での狩猟は2年以下の懲役または2,000万ウォン以下の罰金に処せられます。他の国にも大半は同じ趣旨の規制があります。この文書は公的な仕組みが機能しない生存状況を前提とした知識の整理であり、平時には必ず読者ご自身の国の狩猟法と野生生物保護法を確認し、その範囲内でのみ行わなければなりません。

&nbsp;&nbsp;&nbsp;生存状況でも変わらず残る原則があります。必要な分だけ捕らえ、捕らえたものは無駄にせず、立ち去るときは罠をすべて回収することです。ある地域の動物を根こそぎ捕らえてしまうと、その地域は次の季節を越えにくくなり、災害が長引くほどこの損失は人間自身に返ってきます。捕らえた動物をどう余さず使うかは、屠畜と解体の文書で続けて扱います。
