## 3. 罠が失敗する理由と運用、そして安全
&nbsp;&nbsp;&nbsp;初めて罠を仕掛ける人の罠は、そのほとんどが空です。構造が間違っているのではなく、動物がその場所を避けるか、そもそもその場所に来ないからです。失敗の原因はいくつかに整理でき、そのほとんどは知ってしまえば避けられます。

---
### 3-1. 失敗の原因
| 原因 | どう働くか | 対応 |
| --- | --- | --- |
| 人の匂い | 哺乳類は人の匂いを捕食者の合図として学習します | 手に土や灰をこすりつけ、設置時間を短くします |
| 金属の匂いと光 | 鉄の酸化臭と反射光は自然界にない合図です | 針金を火であぶるか泥を塗っておきます |
| 新しい木の匂い | 切ったばかりの生木の樹液の匂いは非常に強いです | 乾いた木を使うか、切り口を土で覆います |
| 通り道から外れた設置 | よく見える場所は動物が通らない場所です | 痕跡がはっきりした隘路にだけ仕掛けます |
| 引き金の感度不良 | 固すぎると作動せず、敏感すぎると風で崩れます | 指で軽く押したときに外れる程度に合わせます |
| 荒らされた周囲 | 草が折れ土が掘り返された場所は動物が警戒します | 踏んだ跡を落ち葉で覆い、折れた草を起こしておきます |
| 輪がへたる | 括り罠が寝てしまうと動物はそのまま踏んで通り過ぎます | 細い枝や草の茎で輪を立てておきます |
| 落下物不足 | 負傷させるだけで取り逃がします | 体重の5倍以上に増やします |

&nbsp;&nbsp;&nbsp;人の匂いはもっとも頻繁に名指しされますが、実際には二番目の要因です。一番目は常に位置です。匂いが残っていても動物が必ず通らなければならない隘路であれば数日のうちに捕れますが、位置が間違っていれば匂いが完全に消えても永遠に空のままです。匂いを消すことに時間を使う前に痕跡を読むことに時間を使うほうが、回収量をはるかに大きく変えます。

&nbsp;&nbsp;&nbsp;引き金の感度は数値化しにくい部分です。圧殺式の罠の引き金は、指で餌の棒を横に軽く押したときに崩れながら、風や小さな振動には持ちこたえる程度が基準です。接点を深く掘ると構造は安定しますが動物が触れても外れず、浅く仕上げると敏感になりますが自然に崩れてしまいます。この均衡点は材料と重さによって異なるため、実際に何度も組んで手で試してみるしかありません。

---
### 3-2. 設置密度と回収の周期
&nbsp;&nbsp;&nbsp;罠は見回りの経路上に配置します。ばらばらに置くと確認にかかる熱量が回収量を上回ってしまうため、一つの輪状の経路を決め、その経路に沿って配置するのが原則です。経路の長さは一日に一往復できる距離を超えてはいけません。

| 項目 | 基準 | 理由 |
| --- | --- | --- |
| 罠の数 | 最低10個、できれば20個以上 | 回収確率は数に応じて速く上がります |
| 罠の間隔 | 通り道の隘路ごと、おおむね20-50m | 密集しすぎると一頭が複数の罠を壊してしまいます |
| 見回りの経路 | 一日で往復できる輪 | 確認のコストが回収量を上回ってはいけません |
| 確認の周期 | 最低一日一回、朝 | 夜にかかった個体をもっとも早く回収できます |
| 移動の判断 | 三日以上痕跡もなければ移す | 痕跡のない場所はいつまで置いても空のままです |

&nbsp;&nbsp;&nbsp;一日に一回以上確認しなければならない理由は効率のためではありません。第一は倫理です。括り罠や不完全な圧殺式の罠にかかった動物は即死しないことがあり、その動物は人が来るまで苦しみの中にいます。罠を仕掛ける行為は、その苦しみを最小限にする責任も同時に負うことです。第二は腐敗です。夏場に一晩中死んでいた動物は、朝にはすでに内臓から腐敗が始まっており、真昼まで放置すると食べられなくなります。第三は横取りです。かかった動物は他の捕食者にとってももっとも手軽な獲物であるため、半日遅れただけでも何も残りません。

---
### 3-3. 安全
&nbsp;&nbsp;&nbsp;罠は人と動物を区別しません。体重の5倍を超える石が崩れ落ちる圧殺式の罠、首を締め上げる大型の括り罠、尖った杭が立った落とし穴は、どれも人に対してもそのまま作動します。特に飢えて疲労した状態では、自分が設置した罠の位置さえ正確に思い出せなくなるため、設置位置は必ず記録するか、目立つ目印を残しておかなければなりません。

| 危険 | 内容 |
| --- | --- |
| 自分の罠にかかる | 大型の罠は人に骨折や裂傷を負わせます |
| 他人がかかる | 一緒にいる人や子どもが通りかかることがあります |
| 位置を忘れる | 記憶だけに頼ると数日で忘れます |
| 回収せずに立ち去る | 人がいなくなった後も罠は動物を殺し続けます |
| 負傷した動物に近づく | 追い詰められた動物は普段よりはるかに攻撃的です |
| 感染 | 咬み傷や引っかき傷は災害状況では治療が困難です |

&nbsp;&nbsp;&nbsp;目印は、動物を警戒させずに人の目には留まるものでなければなりません。通り道から少し離れた木に石を積んでおいたり、木の枝を特定の方向に折っておいたりする方法で十分です。紙に描いた略図を併せて残しておけば、他の人でも回収できます。

&nbsp;&nbsp;&nbsp;その場を離れるときは、必ずすべての罠を解体しなければなりません。回収しなかった罠は、誰も食べない動物を殺し続ける装置であり、のちにそこを通る人にとっても危険です。括り罠は輪をほどき、圧殺式の罠は落下物を下ろし、落とし穴は埋め戻すか、少なくとも蓋を取り払って目に見えるようにしなければなりません。

&nbsp;&nbsp;&nbsp;負傷した動物に近づくことは、罠の運用でもっとも危険な瞬間です。逃げられない動物は必ず抵抗し、キバノロやイノシシはもちろん、タヌキやアナグマも人に深刻な傷を負わせることがあります。小さな動物でも咬まれれば狂犬病の危険があります。近づく前にまず長い棒で反応を確かめ、生きていれば距離を保ったまま長い道具で即座に処置しなければなりません。素手で捕まえようとすることは、どんな場合にも行いません。特に頭を上げられずうずくまって反応が鈍い動物、昼間歩き回る夜行性動物、人を見ても逃げない動物は、病気にかかっている可能性が高いため、捕まえずに離れなければなりません。
