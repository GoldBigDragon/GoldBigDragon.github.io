## 3. 罠が失敗する理由、運用、安全
&nbsp;&nbsp;&nbsp;最初に仕掛けた罠は、ほぼすべて空です。構造が間違っているからではなく、動物がその場所を避けるか、そもそも来ないからです。失敗の原因はいくつかにまとめられ、大部分は知っていれば避けられます。

---
### 3-1. 失敗の原因
| 原因 | どう作用するか | 対応 |
| --- | --- | --- |
| 人のにおい | 哺乳類は人のにおいを捕食者の信号として学習する | 手を土と灰でこすり、設置時間を短くする |
| 金属のにおいと光 | 鉄の酸化したにおいと反射光は、自然にない信号 | 針金を火であぶるか、泥を塗る |
| 新しい木のにおい | 切りたての生木の樹液のにおいは非常に強い | 乾いた木を使うか、切り口を土で隠す |
| 通り道を外れた設置 | よく目立つ場所は、動物が通らない場所 | 痕跡のはっきりした隘路にだけ設置する |
| 引き金の感度不良 | きつすぎると作動せず、敏感すぎると風で崩れる | 指で軽く押すとほどける程度に調整する |
| 乱された周囲 | 草が折れ、土が掘り返された場所は、動物が警戒する | 踏んだ場所を落ち葉で覆い、折れた草を起こす |
| 輪が沈む | くくり罠が寝ていると、動物はそのまま踏んで通る | 細い枝や草の茎で輪を立てておく |
| 落下物不足 | 傷を負わせるだけで逃す | 体重の5倍以上に増やす |

- 人のにおいは最もよく原因に挙げられますが、実際には2番目の要因です。1番目は、常に位置です。においが残っていても、動物が必ず通る隘路なら数日以内に獲れ、位置が誤っていれば、においが完全になくなっても永遠に空のままです。においを消すのに使う時間より、痕跡を読むのに使う時間のほうが、回収量をはるかに大きく変えます。
- 引き金の感度は、定量化が難しいものです。圧殺罠の引き金は、指で餌の棒を横に軽く押したときに崩れ、風や小さな振動には耐える程度が基準です。接点を深く彫ると構造は安定しますが、動物が触れてもほどけず、浅く整えると敏感ですが、ひとりでに崩れます。均衡点は材料と重さによって異なるので、何度も立てて、手で試します。

---
### 3-2. 設置密度と回収周期
&nbsp;&nbsp;&nbsp;罠は巡回経路の上に配置します。散らして置くと、確認に使う熱量が回収量を超えるので、1つの環状の経路を決め、その経路に沿って配置します。経路の長さは、1日に1回往復できる距離を超えません。

| 項目 | 基準 | 理由 |
| --- | --- | --- |
| 罠の数 | 最低10個、できれば20個以上 | 回収の確率が数に応じて速く上がる |
| 罠の間隔 | 通り道の隘路ごとに、おおむね20-50m | 密すぎると1匹が複数の罠を壊す |
| 巡回経路 | 1日で往復できる環 | 確認の費用が回収量を超えてはならない |
| 確認の周期 | 最低1日1回、朝 | 夜にかかった個体を最も早く回収 |
| 移動の判断 | 3日以上、痕跡もなければ移す | 痕跡のない場所は、置き続けても空のまま |

&nbsp;&nbsp;&nbsp;1日1回以上確認する理由は、効率だけではありません。

- 倫理: くくり罠や不完全な圧殺罠にかかった動物は、即死しないことがあり、人が来るまで苦痛の中にいます。罠を仕掛ける人は、その苦痛を最小限にする責任を負います。
- 腐敗: 夏に一晩中死んでいた動物は、朝には内臓から腐敗が始まっており、昼まで置くと食べられなくなります。
- 盗難: かかった動物は、ほかの捕食者にとっても最も手軽な餌なので、半日遅れただけでも残るものがありません。

---
### 3-3. 安全
&nbsp;&nbsp;&nbsp;罠は人と動物を区別できません。体重の5倍を超える石が崩れる圧殺罠、首を絞める大型のくくり罠、尖った杭の立つ穴は、すべて人にもそのまま作動します。飢えて疲れていると、自分が仕掛けた罠の位置さえ正確に覚えていられないので、設置位置を必ず記録するか、目立つ目印で残します。

| 危険 | 内容 |
| --- | --- |
| 自分の罠にかかる | 大型の罠は、人に骨折と裂傷を負わせる |
| 他人がかかる | 一緒にいる人や子どもが通りかかるかもしれない |
| 位置を忘れる | 記憶だけに頼ると、数日で忘れる |
| 回収せずに去る | 人がいなくなった後も、罠は動物を殺し続ける |
| けがをした動物への接近 | 追い詰められた動物は、普段よりはるかに攻撃的 |
| 感染 | かまれたり引っかかれたりした傷は、災害時には治療が難しい |

- 目印は、動物が警戒せず、人の目には目立つものでなければなりません。通り道から少し離れた木に石を積んだり、枝を特定の方向に折っておいたりすれば十分です。紙に描いた略図を一緒に置けば、ほかの人も回収できます。
- その場所を去るときは、すべての罠を解体します。回収されていない罠は、誰も食べない動物を殺し続け、後から通る人にとっても危険です。くくり罠は輪をほどき、圧殺罠は落下物を下ろし、落とし穴は埋めるか、少なくともふたを取り除いて目に見えるようにします。

> **注意:** けがをした動物に近づくことが、罠の運用で最も危険な瞬間です。逃げられない動物は必ず抵抗し、キバノロやイノシシはもちろん、タヌキやアナグマも深刻な傷を負わせられます。小さな動物でも、かまれると狂犬病の危険があります。近づく前に長い棒で反応を確かめ、生きていれば距離を置いたまま、長い道具でただちに処理します。手でつかもうとはしません。

&nbsp;&nbsp;&nbsp;頭を上げられずにうずくまり、反応が鈍い動物、昼間に歩き回る夜行性の動物、人を見ても逃げない動物は、病気にかかっている可能性が高いものです。捕らえず、退きます。
