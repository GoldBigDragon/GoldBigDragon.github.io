## 1. 罠が狩猟より優先される理由と痕跡の読み方
&nbsp;&nbsp;&nbsp;罠を仕掛ける作業の半分は作る技術であり、残りの半分はどこに仕掛けるかを決める判断力です。よくできた罠でも場所を間違えれば永遠に空のままであり、粗雑な罠でも動物が必ず通る場所にあれば捕れます。そのため、痕跡を読む知識は罠作りの技術よりも先に来るものです。

---
### 1-1. 熱量収支から見た罠と狩猟
&nbsp;&nbsp;&nbsp;狩猟と罠の違いを数字で比較すると、なぜ罠が優先されるのかがはっきりします。以下の数値は状況によって大きく変わりますが、桁の違いを示すには十分です。

| 項目 | 追跡狩猟 | 罠10個の運用 |
| --- | --- | --- |
| 一日の消費熱量 | 2,000~3,000kcal | 300~600kcal（設置と見回り） |
| 初期投入 | 道具作りと習熟 | 罠作り半日から一日 |
| 作動時間 | 人が起きて活動している間だけ | 一日24時間 |
| 負傷リスク | 高い | 低い |
| 失敗時の損失 | 消費した熱量の全額 | 時間だけの損失、罠は残る |
| 回収の安定性 | 非常に不安定 | 多く仕掛けるほど安定 |

&nbsp;&nbsp;&nbsp;罠の本当の価値は、独立した試行を繰り返すことにあります。罠一つの一日の成功率が5%だとすると、十個仕掛けたときに一日で最低一匹を得る確率は、1から0.95の10乗を引いた値、つまり約40%です。二十個なら約64%、三十個なら約79%になります。罠の質を上げるよりも数を増やすほうが回収確率を速く上げるということであり、これが罠を運用する人々が少数の精巧な罠よりも多数の単純な罠を好む理由です。

> **罠は性能ではなく数で成功率を作ります。一つを完璧に作る時間があれば、粗雑なものを五つ仕掛けるほうが常に優れています。**

---
### 1-2. 通り道を見つけ出す原理
&nbsp;&nbsp;&nbsp;野生動物はでたらめに歩き回るわけではありません。動物も人と同じようにエネルギーを節約しようとするため、一度通った経路を繰り返し使います。繰り返し通ると植生が押しつぶされて道ができ、その道がまた次の通行を誘います。こうして形成された通り道を見つけることが、罠設置の出発点です。

&nbsp;&nbsp;&nbsp;動物の一日の移動は、たいてい寝床、水場、餌場という三地点を結ぶ三角形の上で行われます。そのため通り道もこの三地点の間に集中し、特に水辺へ下りる道は複数の個体・複数の種が共有するため、もっとも痕跡がはっきりしています。

| 痕跡 | 読み取れる情報 |
| --- | --- |
| 足跡 | 種、大きさ、進行方向、頭数。泥や砂、雪の上でもっともよく残ります |
| 糞 | 種と餌の種類。湿っていれば最近、乾いてひび割れていれば古いものです |
| 採食の跡 | かじられた樹皮、掘り返された土、食いちぎられた草の高さで種の大きさを見積もります |
| 踏み倒された草と通り道 | 繰り返し通行した証拠であり、幅が狭くはっきりしているほど利用頻度が高いです |
| 毛と擦れた跡 | 通り道が狭まる地点の枝や金網に毛が残ります |
| 寝床 | 草が押しつぶされてくぼんだ場所。近くに必ず進入路と脱出路があります |
| 爪跡、角の跡 | 木の幹に残る印で、大型個体の存在を知らせます |

&nbsp;&nbsp;&nbsp;罠を仕掛ける場所は、通り道の中でも隘路になっている地点です。隘路とは、動物が選べる経路が一つに絞られる場所を指します。倒木の下をくぐらなければならない場所、岩の間の隙間、柵や茂みが途切れる地点、川を渡る浅瀬、二つの通り道が合流する地点がこれに当たります。隘路では動物が通る位置の不確実性が小さくなるため、同じ罠でも通り道の真ん中に置くより成功率が何倍も高くなります。

&nbsp;&nbsp;&nbsp;隘路が自然にない場合は作ることができます。通り道の両脇に木の枝を斜めに挿して柵を立てると、動物はわざわざ乗り越えず、開いた隙間から通ろうとします。このとき柵は動物が越えられないほど高い必要はなく、越えるより回り道するほうが楽だと感じる程度で十分です。この原理を誘導柵といい、少数の罠で広い通り道をカバーできるようにしてくれます。

### 1-3. 獲物の大きさと罠の対応
&nbsp;&nbsp;&nbsp;罠は狙う動物の大きさに合っていなければなりません。小さすぎる罠は動物を傷つけるだけで取り逃がし、大きすぎる罠は小さな動物が引き金に触れられず作動しません。

| 目標 | おおよその体重 | 適した罠 | 注意点 |
| --- | :---: | --- | --- |
| ノネズミ、モグラ | 0.03~0.2kg | 小型圧殺式の罠、瓶落とし | 回収量は少ないが成功率がもっとも高いです |
| シマリス、キタリス | 0.2~0.4kg | 木の幹に立てた括り罠のはしご | 木に登る習性を利用します |
| ウサギ類 | 1~2.5kg | 首用括り罠、自動括り罠、中型圧殺式の罠 | 通り道がはっきりしており、もっとも扱いやすい目標です |
| キジ、カモなど鳥類 | 0.8~1.5kg | 鳥網、餌の落とし罠、足用括り罠 | 飛び立つ方向を塞ぐ必要があります |
| タヌキ、アナグマ | 5~10kg | 大型括り罠、箱罠 | 力が強く結着部が先に壊れます |
| キバノロ | 15~25kg | 大型の首用括り罠 | 人も怪我をしかねない大きさです |
| イノシシ | 50~150kg | 落とし穴、大型括り罠 | 近づくこと自体が非常に危険です |

&nbsp;&nbsp;&nbsp;災害状況で現実的な目標は小型動物です。ウサギ一匹は約1,000kcal、リス一匹は200kcal余りですが、これらは個体数が多く、通り道がはっきりしていて、罠を壊しません。大型動物一匹が与える熱量が大きいからといって大型の罠だけに資源を投入すると、成功するまでの期間を持ちこたえられないことが多いのです。小型の罠を数多く仕掛けて毎日の供給を作り、大型の罠は余裕があるときに追加するという順序が安全です。

&nbsp;&nbsp;&nbsp;ただし、小型動物だけを食べることには限界があります。ウサギやリスのような野生の小型動物は体脂肪が非常に少なく、これだけを食べ続けるとタンパク質過剰による不調が生じます。この問題は屠畜と解体の文書で詳しく扱います。
