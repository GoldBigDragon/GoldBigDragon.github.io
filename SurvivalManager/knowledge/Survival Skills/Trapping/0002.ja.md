## 1. 罠と狩猟の比較、痕跡を読む
&nbsp;&nbsp;&nbsp;罠を仕掛けることの半分はつくる技術で、残りの半分はどこに仕掛けるかを決める判断です。よくできた罠も、間違った場所に置けば永遠に空のままで、粗末な罠も、動物が必ず通る場所にあれば獲れます。痕跡を読む知識が、罠をつくる技術より先です。

---
### 1-1. 熱量収支で見る罠と狩猟
&nbsp;&nbsp;&nbsp;下の値は状況によって大きく異なりますが、桁の違いを示すには十分です。

| 項目 | 追跡する狩猟 | 罠10個の運用 |
| --- | --- | --- |
| 1日の消費熱量 | 2,000-3,000kcal | 300-600kcal(設置と見回り) |
| 初期の投入 | 道具の製作と熟練 | 罠の製作に半日から1日 |
| 作動時間 | 人が起きて活動している間だけ | 1日24時間 |
| けがの危険 | 高い | 低い |
| 失敗したときの損失 | 消耗した熱量の全額 | 時間だけの損失、罠は残る |
| 回収の安定性 | 非常に不安定 | 多く仕掛けるほど安定 |

&nbsp;&nbsp;&nbsp;罠の本当の価値は、独立した試行の繰り返しにあります。罠1つの1日の成功率が5%のとき、1日に最低1匹を得る確率は、罠10個で約40%、20個で約64%、30個で約79%です(1 - 0.95のn乗)。罠の品質を高めるより、数を増やすほうが、回収の確率をより速く高めます。罠は性能ではなく数で、成功率をつくります。1つを完璧につくる時間があれば、粗末なものを5つ仕掛けるほうがよいです。

---
### 1-2. 通り道を見つける原理
&nbsp;&nbsp;&nbsp;野生動物もエネルギーを節約しようとするので、一度通った経路を繰り返し使います。繰り返しの通行で植生が踏まれて道ができ、その道が次の通行を誘います。この通り道を見つけることが、罠の設置の出発点です。

&nbsp;&nbsp;&nbsp;動物の1日の移動は、たいてい寝床、水、餌場を結ぶ三角形の上で行われます。通り道もこの3つの地点の間に集中し、特に水辺へ下りる道は、複数の個体と複数の種が共有していて、痕跡が最もはっきりしています。

| 痕跡 | 読み取れる情報 |
| --- | --- |
| 足跡 | 種、大きさ、進行方向、頭数。泥・砂・雪の上で最もよく残る |
| 糞 | 種と餌の種類。湿っていれば最近、乾いてひび割れていれば古い |
| 食べ跡 | かじられた樹皮、掘り返された土、ちぎられた草の高さで種の大きさを推し量る |
| 踏まれた草と通り道 | 繰り返し通った証拠。幅が狭くはっきりしているほど、利用頻度が高い |
| 毛とこすった跡 | 通り道が狭くなる地点の木の枝や有刺鉄線に毛が残る |
| 寝床 | 草が押されてくぼんだ場所。近くに必ず進入路と逃げ道がある |
| 爪跡、角の跡 | 木の幹に残る印で、大型の個体の存在を知らせる |

- 罠を仕掛ける場所は、通り道の中でも隘路(ボトルネック)です。隘路は、動物が選べる経路が1つに絞られる所です。倒木の下を通らなければならない場所、岩の間の隙間、柵や茂みが途切れた地点、小川を渡る浅瀬、2つの通り道が合流する地点が該当します。隘路では、動物が通る位置の不確実性が小さくなり、通り道の真ん中に置くより、成功率が数倍高くなります。
- 隘路がなければつくります。通り道の両脇に枝を斜めに挿して柵を立てると、動物は越えるより回り込むほうが楽だと感じ、開いた隙間を通ります(誘導柵)。柵は、動物が越えられないほど高い必要はありません。少数の罠で、広い通り道をまかなえるようにしてくれます。

---
### 1-3. 動物の大きさ別の罠
&nbsp;&nbsp;&nbsp;罠は、目標とする動物の大きさに合っていなければなりません。小さすぎる罠は動物にけがをさせるだけで逃し、大きすぎる罠は、小さな動物が引き金に触れられず作動しません。

| 目標 | おおよその体重 | 適した罠 | 注意点 |
| --- | :---: | --- | --- |
| ノネズミ、モグラ | 0.03-0.2kg | 小型の圧殺罠、瓶の落とし穴 | 回収量は少ないが、成功率が最も高い |
| シマリス、リス | 0.2-0.4kg | 木の幹に立てたくくり罠のはしご | 木に登る習性を利用 |
| ウサギ類 | 1-2.5kg | 首のくくり罠、跳ね上げ式のくくり罠、中型の圧殺罠 | 通り道がはっきりしていて、最も扱いやすい目標 |
| キジ、カモなどの鳥類 | 0.8-1.5kg | 鳥網、餌の罠、足のくくり罠 | 飛び立つ方向をふさぐ必要がある |
| タヌキ、アナグマ | 5-10kg | 大型のくくり罠、箱罠 | 力が強く、結束部が先に壊れる |
| キバノロ | 15-25kg | 大型の首のくくり罠 | 人もけがをしうる大きさ |
| イノシシ | 50-150kg | 落とし穴、大型のくくり罠 | 近づくこと自体が非常に危険 |

- 災害時の現実的な目標は小さな動物です。ウサギ1羽は約1,000kcal、シマリス1匹は200kcal余りですが、個体数が多く、通り道がはっきりしていて、罠を壊しません。
- 大型の動物が与える熱量が大きいからと、大きな罠にだけ資源を投入すると、成功するまでの期間をもちこたえられない場合が多くあります。小さな罠を多く仕掛けて毎日の供給をつくり、大きな罠は余裕があるときに追加します。
- 小さな動物だけを食べると、体脂肪の不足でタンパク質過剰の異常が生じます。屠畜の文書のウサギ飢餓の項目を参照します。
