## 1. 陷阱优先于狩猎的原因与如何读懂痕迹
&nbsp;&nbsp;&nbsp;布设陷阱的工作，一半是制作技术，另一半是判断该放在哪里。做得再好的陷阱放错位置也会永远空着，再粗糙的陷阱只要放在动物必经之路上就能捕到猎物。因此，读懂痕迹的知识要先于制作陷阱的技术。

---
### 1-1. 从热量收支看陷阱与狩猎
&nbsp;&nbsp;&nbsp;用数字比较狩猎与陷阱的差异，就能清楚看出陷阱为何应优先采用。下列数值会因情况而有很大差异，但足以显示数量级上的区别。

| 项目 | 追猎 | 运用十个陷阱 |
| --- | --- | --- |
| 每日消耗热量 | 2,000~3,000kcal | 300~600kcal（布设与巡查） |
| 初期投入 | 制作工具并熟练掌握 | 制作陷阱需半天到一天 |
| 作用时间 | 仅限人醒着活动的时段 | 每天24小时 |
| 受伤风险 | 高 | 低 |
| 失败时的损失 | 全部消耗的热量 | 只损失时间，陷阱仍在 |
| 收获的稳定性 | 非常不稳定 | 布设越多越稳定 |

&nbsp;&nbsp;&nbsp;陷阱真正的价值在于独立试验的重复。如果一个陷阱一天的成功率是5%，布设十个后一天内至少收获一只的概率，就是1减去0.95的10次方，约为40%。二十个约为64%，三十个约为79%。这意味着比起提升陷阱的质量，增加数量能更快提高收获概率，这也是运用陷阱的人更偏好大量简单陷阱、而非少量精巧陷阱的原因。

> **陷阱靠的不是性能，而是数量来创造成功率。与其花时间做一个完美的陷阱，不如布设五个粗糙的，后者永远更好。**

---
### 1-2. 找出兽道的原理
&nbsp;&nbsp;&nbsp;野生动物不会随机游荡。动物和人一样想节省能量，因此会反复使用走过一次的路线。反复经过会压倒植被形成道路，而这条路又会引导下一次通行。找到这样形成的通道，正是布设陷阱的起点。

&nbsp;&nbsp;&nbsp;动物一天的活动大多发生在连接巢穴、水源、觅食地这三点的三角形范围内。因此兽道也集中在这三点之间，尤其通往水边的路会被多个个体、多个物种共用，痕迹最为明显。

| 痕迹 | 能读出的信息 |
| --- | --- |
| 足迹 | 物种、大小、前进方向、数量。在泥地、沙地、雪地上留存得最清楚 |
| 粪便 | 物种和食物种类。潮湿说明是最近留下的，干裂则说明已经很久了 |
| 觅食痕迹 | 通过啃过的树皮、翻动的泥土、被啃食的草的高度来估计物种的大小 |
| 被压倒的草与通道 | 是反复通行的证据，路径越窄越清晰，使用频率就越高 |
| 毛发与蹭蹭痕迹 | 通道变窄处的树枝或铁丝网上会留下毛发 |
| 卧息地 | 草被压平凹陷之处，附近必定有进入路线和逃离路线 |
| 爪痕、角痕 | 留在树干上的痕迹，表明有大型个体存在 |

&nbsp;&nbsp;&nbsp;应该布设陷阱的位置，是兽道中形成瓶颈的地点。所谓瓶颈，指的是动物可选路线收窄为一条的地方。必须从倒木下方穿过的地方、岩石之间的缝隙、栅栏或灌木丛中断的地点、可涉水而过的浅滩、两条通道汇合之处，都属于此类。在瓶颈处，动物经过位置的不确定性变小，因此同样的陷阱放在这里，比放在通道正中央成功率要高出好几倍。

&nbsp;&nbsp;&nbsp;如果天然没有瓶颈，也可以人工制造。在通道两侧斜插树枝搭起围栏，动物就不会特意翻越，而会试图从留出的空隙通过。这时围栏不需要高到动物无法跨越，只要让动物觉得绕行比翻越更省事就足够了。这个原理称为陷阱导栏，能让少量陷阱应付宽阔的通道。

### 1-3. 猎物大小与陷阱的对应
&nbsp;&nbsp;&nbsp;陷阱必须与目标动物的大小相匹配。太小的陷阱只会伤到动物却抓不住，太大的陷阱小动物又碰不到扳机而无法触发。

| 目标 | 大致体重 | 合适的陷阱 | 注意事项 |
| --- | :---: | --- | --- |
| 田鼠、鼹鼠 | 0.03~0.2kg | 小型压杀式陷阱、瓶式陷阱 | 收获量小，但成功率最高 |
| 花鼠、松鼠 | 0.2~0.4kg | 立在树干上的套索梯 | 利用其攀树的习性 |
| 兔类 | 1~2.5kg | 颈部套索、自动套索、中型压杀式陷阱 | 兽道清晰，是最容易应付的目标 |
| 雉鸡、鸭等鸟类 | 0.8~1.5kg | 鸟网、诱饵陷阱、脚部套索 | 必须挡住鸟起飞的方向 |
| 貉、狗獾 | 5~10kg | 大型套索、箱式陷阱 | 力气大，绑扎处会先损坏 |
| 獐 | 15~25kg | 大型颈部套索 | 这个体型连人都可能受伤 |
| 野猪 | 50~150kg | 陷坑、大型套索 | 光是靠近就非常危险 |

&nbsp;&nbsp;&nbsp;在灾难状况下，现实的目标是小型动物。一只兔子约1,000kcal，一只松鼠约200kcal出头，但这类动物数量多、兽道清晰，也不会破坏陷阱。如果因为一只大型动物给出的热量更多，就把资源全投入大型陷阱，往往撑不到成功的那一刻。更安全的顺序是：多布设小型陷阱，形成每日的稳定供给，大型陷阱等有余力时再补充。

&nbsp;&nbsp;&nbsp;不过，只吃小型动物也有局限。兔子和松鼠这类野生小型动物体脂极少，如果只靠它们维持饮食，会因蛋白质过剩而出现问题。这个问题将在屠宰与分割文档中详细讨论。
