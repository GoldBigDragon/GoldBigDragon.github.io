## 1. 陷阱与狩猎的比较，解读痕迹
&nbsp;&nbsp;&nbsp;设陷阱，一半是制作的技术，另一半是决定设在哪里的判断。做得再好的陷阱放错地方也永远是空的，做得粗糙的陷阱只要在动物必经之处也能捕到。读懂痕迹的知识先于制作陷阱的技术。

---
### 1-1. 从热量收支看陷阱与狩猎
&nbsp;&nbsp;&nbsp;下面的数值因情况而差别很大，但足以显示数量级的差异。

| 项目 | 追击狩猎 | 运作十个陷阱 |
| --- | --- | --- |
| 每日消耗热量 | 2,000-3,000kcal | 300-600kcal（设置和巡查） |
| 初期投入 | 制作工具和熟练度 | 制作陷阱需半天到一天 |
| 运作时间 | 仅限人清醒活动期间 | 一天24小时 |
| 受伤风险 | 高 | 低 |
| 失败时的损失 | 消耗的热量全部损失 | 只损失时间，陷阱还在 |
| 回收的稳定性 | 非常不稳定 | 放得越多越稳定 |

&nbsp;&nbsp;&nbsp;陷阱的真正价值在于独立试验的重复。一个陷阱每天成功率为5%时，一天至少得到一只的概率，10个陷阱约为40%，20个约为64%，30个约为79%（1 - 0.95的n次方）。增加数量比提高陷阱质量更快地提高回收概率。陷阱靠的不是性能，而是数量来产生成功率。与其花时间把一个做到完美，不如放五个粗糙的。

---
### 1-2. 寻找通道的原理
&nbsp;&nbsp;&nbsp;野生动物也想节省能量，所以走过一次的路径会反复使用。反复通行会踩倒植被形成小路，这条路又会引导下一次通行。找到这些通道，是设置陷阱的出发点。

&nbsp;&nbsp;&nbsp;动物一天的移动大多发生在连接睡处、水、觅食地的三角形上。通道也集中在这三个点之间，尤其是下到水边的路，被多个个体和多个物种共用，痕迹最为清晰。

| 痕迹 | 解读出的信息 |
| --- | --- |
| 足迹 | 种类、大小、行进方向、数量。在泥、沙、雪上留得最好 |
| 粪便 | 种类和食物类型。湿润说明是最近的，干燥开裂则是很久以前的 |
| 觅食痕迹 | 啃过的树皮、刨开的泥土、被扯断的草的高度，可以估计物种的大小 |
| 被压倒的草与通道 | 反复通行的证据。越窄越清晰，使用频率越高 |
| 毛发与蹭痕 | 通道变窄之处的树枝或铁丝网上会留下毛 |
| 睡处 | 草被压成凹陷的地方。附近一定有进入的路和逃脱的路 |
| 爪痕、角痕 | 留在树干上的标记，显示有大型个体存在 |

- 设陷阱的位置，是通道中的瓶颈。瓶颈是动物可选择的路径缩减为一条的地方。必须从倒下的树下面通过的地方、岩石之间的缝隙、栅栏或灌木丛断开的位置、过溪的浅滩、两条通道汇合的点都属于此类。在瓶颈处，动物经过的位置的不确定性变小，成功率比放在通道正中央高出好几倍。
- 没有瓶颈就造一个。在通道两侧斜插树枝立起栅栏，动物会觉得绕过去比跨过去更省事，从留出的缺口通过（引导栅栏）。栅栏不必高到动物跳不过去。它能让少量陷阱负责宽阔的通道。

---
### 1-3. 按动物大小选陷阱
&nbsp;&nbsp;&nbsp;陷阱必须与目标动物的大小相配。太小的陷阱只会伤到动物然后让它跑掉，太大的陷阱小动物碰不到触发机关而不起作用。

| 目标 | 大致体重 | 适合的陷阱 | 注意事项 |
| --- | :---: | --- | --- |
| 田鼠、鼹鼠 | 0.03-0.2kg | 小型压砸陷阱、瓶坑陷阱 | 回收量少，但成功率最高 |
| 花鼠、松鼠 | 0.2-0.4kg | 立在树干上的套索梯 | 利用其爬树的习性 |
| 兔类 | 1-2.5kg | 颈部套索、自动套索、中型压砸陷阱 | 通道清晰，是最容易处理的目标 |
| 雉、鸭等鸟类 | 0.8-1.5kg | 捕鸟网、诱饵陷阱、脚套索 | 必须堵住它们飞起的方向 |
| 貉、獾 | 5-10kg | 大型套索、箱式陷阱 | 力气大，绑扎处先被弄坏 |
| 獐 | 15-25kg | 大型颈部套索 | 人也可能受伤的大小 |
| 野猪 | 50-150kg | 坑阱、大型套索 | 光是接近就极其危险 |

- 灾难情况下现实的目标是小动物。一只兔子约1,000kcal，一只花鼠200kcal多一点，但数量多，通道清晰，且不会弄坏陷阱。
- 因为大型动物提供的热量大，就只把资源投入大陷阱，往往撑不到成功的那一天。多放小陷阱，创造每天的供给，有余力时再增加大陷阱。
- 只吃小动物，会因体脂肪不足出现蛋白质过剩的异常。参考屠宰文档中的兔饥饿一节。
