## 3. 陷阱失败的原因、运用与安全
&nbsp;&nbsp;&nbsp;最初放的陷阱几乎全都是空的。不是因为结构错了，而是因为动物避开那个位置，或者压根不来。失败的原因可以归纳为几种，大多数只要知道就能避免。

---
### 3-1. 失败的原因
| 原因 | 如何起作用 | 应对 |
| --- | --- | --- |
| 人的气味 | 哺乳动物把人的气味学成捕食者的信号 | 用泥土和草木灰搓手，并缩短设置时间 |
| 金属的气味和光 | 铁的氧化气味和反射光是自然界中没有的信号 | 把铁丝在火上熏黑，或涂上泥 |
| 新木头的气味 | 刚砍的生木头的汁液气味非常强 | 用干木头，或用土盖住砍断的面 |
| 偏离通道的设置 | 容易看到的位置，是动物不经过的位置 | 只设在痕迹清晰的瓶颈处 |
| 触发机关灵敏度不良 | 太紧就不起作用，太敏感风一吹就塌 | 调整到用手指轻轻一推就松开的程度 |
| 被弄乱的周围 | 草被折断、泥土被刨开的地方，动物会警惕 | 用落叶盖住踩过的地方，把折断的草扶起来 |
| 环塌下去 | 套索被放倒的话，动物直接踩过去 | 用细树枝或草茎把环撑起来 |
| 落下物不足 | 只造成受伤而让动物逃脱 | 增加到体重的5倍以上 |

- 人的气味最常被指为原因，但实际上是第二位的因素。第一位始终是位置。即使气味还留着，只要是动物必经的瓶颈，几天内就能捕到；位置不对的话，即使气味完全消失，也永远是空的。花在解读痕迹上的时间，比花在消除气味上的时间，更能大幅改变回收量。
- 触发机关的灵敏度很难量化。压砸陷阱的触发机关，标准是用手指把饵杆往旁边轻轻一推就塌下，但能承受风或小的震动。接触点挖深了，结构稳定，但动物碰了也不松开；修浅了，灵敏，但会自己塌下。平衡点随材料和重量而不同，所以要多次架设，用手试验。

---
### 3-2. 设置密度与回收周期
&nbsp;&nbsp;&nbsp;陷阱布置在巡查路线上。分散放置的话，查看所耗的热量会超过回收量，所以确定一条环形路线，沿着这条路线布置。路线长度不超过一天可以往返一次的距离。

| 项目 | 标准 | 理由 |
| --- | --- | --- |
| 陷阱数量 | 至少10个，可能的话20个以上 | 回收概率随数量迅速上升 |
| 陷阱间隔 | 通道的每个瓶颈处，一般为20-50m | 太密的话，一个个体会弄坏好几个陷阱 |
| 巡查路线 | 一天可往返的环线 | 查看成本不得超过回收量 |
| 检查周期 | 至少一天一次，在早晨 | 最快回收夜里被捕的个体 |
| 转移判断 | 三天以上连痕迹都没有就挪位置 | 没有痕迹的位置，继续放也是空的 |

&nbsp;&nbsp;&nbsp;一天至少检查一次，理由不只是效率。

- 伦理：被套索或不牢靠的压砸陷阱困住的动物可能不会当场死亡，在人来之前一直处于痛苦中。设陷阱的人有责任把这种痛苦降到最低。
- 腐败：夏天夜里死了一整夜的动物，到早晨内脏已经开始腐败，放到中午就不能吃了。
- 被盗：被捕的动物对其他捕食者来说也是最容易到手的食物，哪怕只晚了半天，也什么都不剩。

---
### 3-3. 安全
&nbsp;&nbsp;&nbsp;陷阱分不清人和动物。体重5倍以上的石头塌下的压砸陷阱、勒住脖子的大型套索、立着尖桩的坑，对人也都同样起作用。饥饿疲劳时，连自己设置的陷阱的位置都记不准确，所以务必记录设置位置，或用醒目的标记留下来。

| 风险 | 内容 |
| --- | --- |
| 自己被自己的陷阱困住 | 大型陷阱会造成人骨折和撕裂伤 |
| 别人被困住 | 一起的人和孩子可能经过 |
| 忘记位置 | 只靠记忆的话，几天就忘了 |
| 不回收就离开 | 人消失之后，陷阱仍继续杀死动物 |
| 接近受伤的动物 | 被逼到绝境的动物比平时攻击性强得多 |
| 感染 | 被咬或被抓的伤口在灾难情况下很难治疗 |

- 标记必须是动物不会警惕、但人眼能看到的东西。在离通道稍远的树上堆些石头，或把树枝朝特定方向折弯，就足够了。一并留下画在纸上的草图，别人也能回收。
- 离开那个地方时，把所有陷阱拆除。没有回收的陷阱会继续杀死没人吃的动物，对以后经过的人也危险。套索要解开环，压砸陷阱要把落下物放下，坑要填上，至少要把盖子拿掉，让它看得见。

> **注意：** 接近受伤的动物，是运用陷阱时最危险的时刻。无法逃脱的动物一定会反抗，不仅是獐和野猪，貉和獾也可能造成严重的伤。即使是小动物，被咬也有狂犬病风险。接近之前，用长棍确认反应，如果还活着，保持距离，用长工具立即处理。不要想用手抓。

&nbsp;&nbsp;&nbsp;抬不起头、蜷缩着、反应迟缓的动物，白天出来走动的夜行性动物，看到人也不逃跑的动物，很可能得了病。不要捕，退开。
