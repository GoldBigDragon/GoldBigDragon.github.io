## 3. 陷阱失败的原因、运用与安全
&nbsp;&nbsp;&nbsp;初次布设陷阱的人，做出来的陷阱几乎全是空的。这不是结构出了问题，而是动物躲开了那个地方，或者根本不会经过那里。失败的原因可以归纳为几类，大多数只要了解就能避免。

---
### 3-1. 失败的原因
| 原因 | 如何起作用 | 对策 |
| --- | --- | --- |
| 人的气味 | 哺乳动物会把人的气味当作捕食者信号来记住 | 用泥土和草木灰搓手，并缩短布设时间 |
| 金属的气味与反光 | 铁的氧化气味和反光是自然界中不存在的信号 | 把铁丝在火上熏黑，或涂上泥浆 |
| 新伐木材的气味 | 刚砍下的生木树液气味非常浓烈 | 使用干木材，或用泥土遮住切口 |
| 偏离兽道布设 | 显眼的地方正是动物不会经过的地方 | 只布设在痕迹清晰的瓶颈处 |
| 扳机灵敏度不当 | 太紧不会触发，太灵敏又会被风吹垮 | 调到手指轻推一下就能松脱的程度 |
| 周围环境凌乱 | 草被压折、泥土被翻动的地方会让动物警觉 | 用落叶盖住踩过的痕迹，把压弯的草重新扶起 |
| 套索圈塌陷 | 圈一旦倒伏，动物就会直接踩过去 | 用细枝或草茎把圈撑起 |
| 落下物不够重 | 只会伤到动物却让它跑掉 | 增加到体重的5倍以上 |

&nbsp;&nbsp;&nbsp;人的气味最常被归咎，但实际上只是第二位的因素。第一位永远是位置。即使留有气味，只要是动物必经的瓶颈，几天内也能捕到；而位置选错了，就算气味完全消失，陷阱也会永远空着。与其花时间去除气味，不如花时间读懂痕迹，这样对收获量的改变要大得多。

&nbsp;&nbsp;&nbsp;扳机的灵敏度是难以量化的部分。压杀式陷阱的扳机，标准是用手指轻推饵杆一下就会塌落，但要能扛住风吹或轻微震动。接点挖得深，结构就稳定，可动物碰了也不会松脱；削得浅，就灵敏，但会自己塌掉。这个平衡点因材料和重量而异，只能实际动手搭建多次、用手试验才能找到。

---
### 3-2. 布设密度与回收周期
&nbsp;&nbsp;&nbsp;陷阱应布设在巡查路线上。分散布设会导致确认所耗的热量超过收获量，因此原则是确定一条环形路线，沿着这条路线布设。路线的长度不应超过一天内能往返一次的距离。

| 项目 | 标准 | 原因 |
| --- | --- | --- |
| 陷阱数量 | 至少10个，最好20个以上 | 收获概率会随数量快速上升 |
| 陷阱间距 | 每个兽道瓶颈处一个，大致20-50m | 太密集会导致一个个体破坏多个陷阱 |
| 巡查路线 | 一天内可往返的环形路线 | 确认成本不能超过收获量 |
| 检查周期 | 至少每天一次，早上 | 能最快收回夜里捕到的猎物 |
| 是否搬迁 | 三天以上没有痕迹就搬走 | 没有痕迹的地方放再久也是空的 |

&nbsp;&nbsp;&nbsp;必须每天至少检查一次，原因不在效率。第一是伦理。困在套索或不牢靠的压杀式陷阱里的动物，有时不会立即死亡，它会一直痛苦，直到人来为止。布设陷阱这件事，也同时意味着承担起把这种痛苦降到最低的责任。第二是腐败。夏季一整夜死去的动物，到早上内脏就已经开始腐败，放到正午就没法吃了。第三是被偷走。落网的动物对其他捕食者来说也是最容易到手的猎物，哪怕只晚半天，也可能什么都剩不下。

---
### 3-3. 安全
&nbsp;&nbsp;&nbsp;陷阱分不清人和动物。能压垮超过体重5倍重石的压杀式陷阱、能勒紧脖子的大型套索、立着尖木桩的陷坑，对人同样会原样起作用。尤其在饥饿疲惫的状态下，人甚至会记不清自己设置的陷阱到底在哪里，因此布设位置必须做记录，或者留下醒目的标记。

| 危险 | 内容 |
| --- | --- |
| 被自己的陷阱夹住 | 大型陷阱会造成骨折和撕裂伤 |
| 他人中招 | 同行的人或孩子可能会经过那里 |
| 忘记位置 | 只靠记忆，几天内就会忘记 |
| 未回收就离开 | 人离开之后，陷阱仍会继续杀死动物 |
| 靠近受伤的动物 | 被逼入绝境的动物会比平时凶猛得多 |
| 感染 | 咬伤或抓伤在灾难状况下很难得到治疗 |

&nbsp;&nbsp;&nbsp;标记应该做到既不惊动动物，又能让人一眼看见。在离兽道稍远的树上堆几块石头，或把树枝折向特定方向，这样就足够了。再配上一张画在纸上的简图，其他人也能找到并回收。

&nbsp;&nbsp;&nbsp;离开那个地方时，必须拆除所有陷阱。没有回收的陷阱，会变成不断杀死无人食用的动物的装置，也会对日后经过那里的人构成危险。套索要解开圈套，压杀式陷阱要卸下落下物，陷坑要填平，或者至少把盖子移开、让它能被看见。

&nbsp;&nbsp;&nbsp;靠近受伤的动物，是陷阱运用中最危险的时刻。无法逃脱的动物一定会反抗，獐和野猪自不必说，就连貉和狗獾也可能对人造成严重伤害。即使是小动物，被咬到也有感染狂犬病的风险。靠近之前应先用长棍确认其反应，如果还活着，就要保持距离、用长柄工具立即处理。任何情况下都不要试图徒手抓捕。尤其是抬不起头、蜷缩着反应迟钝的动物，白天出没的夜行性动物，以及见人也不逃跑的动物，很可能已经患病，应该放弃捕捉、后退离开。
