## 3. 筌、網、簗、延縄
&nbsp;&nbsp;&nbsp;これらの漁具は、人がその場を離れている間も作動します。共通の原理は、魚が自分から入ってくるようにし、入った後は出る経路を見つけられないようにすることです。閉じ込める力ではなく、魚の行動の習性を利用します。

---
### 3-1. 筌
- 構造: 入口は外から内へ向かって狭くなる漏斗の形で、漏斗の先は筌の内部の真ん中に吊られています。魚は餌のにおいをたどって広い入口から入り、壁が自然に内側へ案内します。
- 脱出を防ぐ原理: 行き止まりに閉じ込められた魚は、壁面に沿って周囲を回る習性があります。漏斗の出口は壁ではなく空間の真ん中にあり、内側へ尖って向いているため、壁に沿って回る経路と出会いません。漏斗の先が壁に近かったり、漏斗が短くて壁面からまっすぐ続いたりすると、脱出率が大きく上がります。

| 設計要素 | 基準 | 理由 |
| --- | --- | --- |
| 漏斗の入口の直径 | 狙う魚が通れる程度 | 大きすぎると大きな魚が入って漁具を壊して出ていく |
| 漏斗の先の直径 | 目標魚種の胴の太さよりやや大きい | 狭いほど脱出率が下がるが、進入率も下がる |
| 漏斗の長さ | 筌の深さの3分の1前後 | 先が空間の中央に来るようにして、壁面の経路から切り離す |
| ひごの間隔 | 目標魚種より狭く | 小さな個体は抜けさせて資源の損失を減らす |
| 筌の向き | 入口を水の流れの下流側へ | 魚はたいてい上流を向いており、においを嗅いで逆らって入ってくる |

- 材料: 竹とヤナギの枝は、水に長く浸けても腐りにくく、割ると一定の太さのひごが取れ、濡れると柔軟になります。乾いた状態で曲げると折れるので、編む前に水に浸けます。
- 編み方: 縦ひごを縦に立て、細い枝を横に巻いていきます。巻く方向を1本ずつずらすと、縦ひごが固定されて構造が自ら保たれます。
- 設置場所: 魚が行き来する通り道。筌は魚を呼ぶ力が弱く、すでに魚が通う所に置かないと、餌を入れても空のままです。水草帯の縁、岩の隙間の横、水が狭まる首、水深が変わる段差を優先します。

---
### 3-2. 網
&nbsp;&nbsp;&nbsp;網が獲る方式は2つあります。網目に体がはまって抜けられなくする刺し網と、魚を囲んで逃げ場をなくす投網・地引き網です。

&nbsp;&nbsp;&nbsp;刺し網の選択性は、魚の胴回りで決まります。頭は通ったのに最も太い胴回りが網目の周囲より大きいと、前にも後ろにも行けず、えらぶたが網糸に引っかかって固定されます。小さすぎる魚はそのまま抜け、大きすぎる魚は頭から入れずに引き返すので、獲れる大きさに上限と下限の両方が生じます。網目の大きさを変えるだけで、獲る大きさを決められます。

| 網目の一辺 | 主にかかる魚体長(おおよそ) | 備考 |
| :---: | :---: | --- |
| 20mm | 10cm前後 | オイカワ、ワカサギなどの小型種 |
| 35mm | 15-20cm | フナ、ニゴイ類の幼魚 |
| 50mm | 25-30cm | 中型のフナ、コイの幼魚 |
| 75mm | 35-45cm | 中大型の個体 |
| 100mm以上 | 50cm以上 | 大型種に限る |

&nbsp;&nbsp;&nbsp;網が水中で壁のように立つには、上側に浮き、下側に沈子をつけます。浮きは、木片、乾燥したヒョウタン、中空のアシの束のように水より密度の小さいもの、沈子は、穴をあけた石や小石を糸に通したものです。浮力と沈む力が釣り合ってはじめて網がぴんと張り、一方が足りないと、網が斜めに寝たり底に敷かれたりして、獲れません。

| 種類 | 原理 | 必要な条件 |
| --- | --- | --- |
| 刺し網 | 水の流れを横切って立てておき、魚が自分でかかるようにする | 材料が少なく済み、人がいなくてもよい |
| 三枚網 | 目の粗い外網2枚の間に細かい内網を入れて袋をつくる | 大きさの選択性が低く、小さな個体まで獲れる |
| 投網 | 円盤形の網を投げて覆い、縁の錘がすぼまって閉じ込める | 熟練が必要で、底に引っかかるものがないこと |
| 地引き網 | 水辺で網により広い面積を囲んで引き寄せる | 複数の人が必要で、底が平らなこと |
| すくい網 | 小さな網を当てて魚を追い込む | 浅い小川で最も手軽な方法 |

### 3-3. 簗と石干見
&nbsp;&nbsp;&nbsp;水の動きそのものを漁具に変えた構造物です。潮の干満の差が大きい干潟では、満ち潮に乗って魚が浅い所まで入り、引き潮で出ていきます。出ていく水路に低い石垣を築いておくと、水は石の隙間から抜け、魚は残ります。

- 馬蹄形: 出ていく水を受け止めるための形です。開いた側を海の方向に向け、内側へくぼませて曲げておくと、引き潮に押されて出ていく魚が石垣に沿って移動し、曲率が集まる1点に集中します。その地点に、他の場所より厚く高く築いた池を、イムトン(留め池)と呼びます。水がすべて引いても、イムトンには水が残り、魚が生きたまま集まります。
- 石垣の高さ: 潮間帯の内側で30cm未満から始め、海側に行くほど高くなります。水が深く満ちる側ほど、魚が越えられないよう、石垣を高くしなければなりません。
- 河川: 瀬の下流側にV字に石を積み、頂点を下流に向けます。下流へ下ってくる魚が頂点の狭い隙間に集まるので、その場所に筌や簀を置きます。
- 利点: 餌が要らず、一度築けば数十年作動し、潮汐という無限のエネルギー源が人の代わりに魚を追い込んでくれます。
- 欠点: 初期の労働量が非常に大きく、場所を誤ると労働がすべて無駄になります。潮の流れと地形を何度かの潮時にわたって観察してから築きます。

### 3-4. 延縄と夜間の設置
&nbsp;&nbsp;&nbsp;延縄は、長い幹縄に一定の間隔で短い枝縄をつけ、各枝縄の先に針やゴージフックを吊るした漁具です。同じ時間に数十本の針を水中に入れておくので、時間あたりの回収の期待値がはるかに大きくなります。

| 要素 | 考慮事項 |
| --- | --- |
| 枝縄の間隔 | 互いに絡まないよう、枝縄の長さの2倍以上 |
| 枝縄の長さ | 短いと絡みが少なく、長いと餌が自然に動く |
| 幹縄の固定 | 両端を杭や重い石に結び、流されないようにする |
| 設置の深さ | 底につければナマズ類とウナギ類、中層に浮かせれば遊泳性の魚種 |
| 回収の時刻 | 日の出直前が最も回収量が大きい |

- 夜に沈めておく理由の1つ目: ナマズ、ウナギ、ギギ類のように、嗅覚で餌を探す夜行性の魚種が夜に活動し、これらは視覚に頼らないため、糸が見えるかどうかは問題になりません。
- 2つ目: 人が眠る時間を漁具が働く時間に変えるので、熱量収支の上で最も有利です。
- 一晩中かかっていた魚はすでに死んでいる場合が多く、水温が高いと、朝に回収したときには腐敗が始まっていることがあります。夏は回収の周期を短くするか、生きたまま閉じ込める筌を増やします。
- 設置した漁具の位置を覚えておらず回収できないと、その漁具は、誰も食べない魚を殺し続ける装置になります。
