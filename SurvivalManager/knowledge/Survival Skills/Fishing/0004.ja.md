## 3. 筌と網、魞、延縄
&nbsp;&nbsp;&nbsp;ここで扱う漁具は、いずれも人がその場を離れている間に働きます。共通する原理は、魚を自分から入ってくるように仕向け、入った後は出る経路を見つけられないようにすることです。閉じ込める力ではなく、魚の行動習性を利用する点が核心です。

---
### 3-1. 筌が魚を閉じ込める原理
&nbsp;&nbsp;&nbsp;筌の入り口は、外側から内側に向かうほど狭くなる漏斗の形をしており、漏斗の先端は筌の内部の真ん中に吊るされています。魚は餌の匂いをたどって漏斗の広い入り口から入ってきます。ここまでは壁が自然に内側へと導くため、難しくありません。

&nbsp;&nbsp;&nbsp;出られない理由は、魚が行き止まりに閉じ込められたとき、壁面に沿って周囲を回る習性があるためです。魚は空間の中央に浮かぶ小さな穴を探して出ていくのではなく、外側の壁に沿って回りながら出口を探そうとします。ところが漏斗の出口は壁ではなく空間の真ん中にあり、しかも先端が内側を向いているため、壁に沿って回る魚の経路とは交わりません。これが筌のすべてです。漏斗の先端を壁に近づけたり、漏斗を短くして壁面から直接つながるようにしたりすると、脱出率が大きく上がってしまいます。

| 設計要素 | 基準 | そうする理由 |
| --- | --- | --- |
| 漏斗入り口の直径 | 狙う魚が通れる程度 | 大きすぎると大きな魚が入り込み、漁具を壊して出て行きます |
| 漏斗先端の直径 | 目標魚種の胴回りより少し大きい | 狭いほど脱出率は下がるが、進入率も下がる |
| 漏斗の長さ | 筌の深さの3分の1前後 | 先端が空間の中央に来るようにして壁面経路と切り離します |
| 骨組みの間隔 | 目標魚種より狭く | 小さな個体は逃げられるようにして資源の損失を減らします |
| 筌の向き | 入り口を水の流れの下流側へ | 魚はおおむね上流を向いているため、匂いを嗅いで流れに逆らって入ってきます |

&nbsp;&nbsp;&nbsp;竹と柳の枝が良い材料である理由は、水に長く浸けても傷みにくい一方、割ると一定の太さの骨材が取れ、濡れると柔軟になって曲げられるからです。乾いた状態で曲げると折れるため、編む前に水に浸けておきます。編み方は、縦骨を縦に立て、細い枝を横に巻きつけていくもので、巻く方向を一段ごとにずらすと縦骨が固定され、構造がひとりでに保たれます。

&nbsp;&nbsp;&nbsp;設置場所は、魚が行き来する通り道でなければなりません。筌は魚を呼び寄せる力が弱いため、すでに魚が通っている場所に置かないと、餌をどれだけ入れても空のままです。水草帯の縁、岩の隙間のそば、水が狭まる場所、水深が変わる段差を優先します。

### 3-2. 網目と網の種類
&nbsp;&nbsp;&nbsp;網が魚を捕らえる方式は二つあります。一つは網目に体が挟まって抜けられなくすることで、もう一つは魚を囲い込んで逃げ場をなくすことです。前者が刺し網であり、後者が投網と地引き網です。

&nbsp;&nbsp;&nbsp;刺し網の選択性は、魚の胴回りによって決まります。頭は通ったのに、最も太い胴回りが網目の周囲より大きいと、魚は前にも後ろにも進めなくなり、鰓蓋が網糸に引っかかって固定されます。そのため刺し網には、捕れるサイズの上限と下限が同時に生じます。小さすぎる魚はそのまま抜けていき、大きすぎる魚は頭から入れずに引き返します。この性質のおかげで、網目の大きさを変えるだけで、どのサイズの魚を捕るかを決めることができます。

| 網目の一辺 | 主に掛かる魚体長（おおよそ） | 備考 |
| :---: | :---: | --- |
| 20mm | 10cm前後 | オイカワ、ワカサギなどの小型種 |
| 35mm | 15-20cm | フナ、ヌチ（コイ科）の若い個体 |
| 50mm | 25-30cm | 中型のフナ、コイの若い個体 |
| 75mm | 35-45cm | 中大型の個体 |
| 100mm以上 | 50cm以上 | 大型種に限られます |

&nbsp;&nbsp;&nbsp;網が水中で壁のように立つためには、上側に浮きを、下側に沈子を付けなければなりません。浮きは木片や乾いた瓢箪、中が空洞の葦の束のように、密度が水より小さいものであればよく、沈子は穴を開けた石や小石を糸に通したものであればよいです。浮力と沈降力の大きさが釣り合って初めて網がぴんと張り、どちらかが不足すると網が斜めに傾いたり、底に張り付いたりして魚が掛かりません。

| 種類 | 原理 | 必要な条件 |
| --- | --- | --- |
| 刺し網 | 水路を横切るように立てておき、魚が自分から掛かるようにする | 材料が少なくて済み、人がいなくてもよい |
| 三枚網 | 粗い外網二枚の間に目の細かい内網を入れ、袋を作る | サイズの選択性が低く、小さな個体まで捕れます |
| 投網 | 円盤形の網を投げてかぶせ、縁の錘がすぼまって閉じ込める | 熟練が必要で、底に引っかかるものがあってはいけません |
| 地引き網 | 水辺から網で広い面積を囲み、引き寄せる | 複数の人手が必要で、底が平らでなければなりません |
| タモ網、二人網 | 小さな網を構え、魚を追い込む | 浅い小川で最も手軽な方法です |

### 3-3. 魞と石干見
&nbsp;&nbsp;&nbsp;魞と石干見は、水の動きそのものを漁具に変える構造物です。干満差の大きい干潟では、満ち潮で魚が浅い場所まで入り込み、引き潮で出て行きます。このとき出て行く水路に低い石垣を積んでおくと、水は石の隙間から抜けますが、魚は残ります。

&nbsp;&nbsp;&nbsp;石干見の典型的な形が馬蹄形である理由は、出て行く水を受け止めるためです。開いた側を海の方向に向け、内側に凹むように曲げておくと、引き潮に押し流される魚は石垣沿いに移動し、曲率が集まる一点に集中します。その地点には他の場所より厚く高く積んだ溜まりを設けますが、これを「イムトン」（魚だまり）と呼びます。水がすっかり引いても、イムトンには水が残り、魚が生きたまま集まります。

&nbsp;&nbsp;&nbsp;石垣の高さは一定ではなく、潮間帯の内側では30cm未満から始まり、海側に向かうほど高くなります。これは水が深くたまる側ほど石垣を高くしないと、魚が石垣を越えてしまうためです。河川でも同じ原理が使われます。瀬の下手にV字形に石を積み、頂点を下流に向けておくと、下流へ降りてくる魚が頂点の狭い隙間に集まるので、その場所に筌や簀を置けばよいのです。

&nbsp;&nbsp;&nbsp;魞と石干見の決定的な利点は、餌が要らないこと、一度築けば数十年にわたって働き続けること、そして潮汐という無尽蔵のエネルギー源が人に代わって魚を追い込んでくれることです。欠点は、初期の労働量が非常に大きいことと、位置を誤るとその労働がすべて無駄になることです。潮の流れと地形を、何度もの潮時にわたって観察してから築かなければなりません。

### 3-4. 延縄と夜間の設置
&nbsp;&nbsp;&nbsp;延縄は、一本の長い道糸に一定間隔で短い枝糸を付け、各枝糸の先に針やゴージを結んだ漁具です。一人が釣り竿一本で針一本を管理する代わりに、同じ時間に数十本の針を水中に入れておく方式であるため、一時間あたりの回収期待値がはるかに大きくなります。

| 要素 | 考慮事項 |
| --- | --- |
| 枝糸の間隔 | 互いに絡まないよう、枝糸の長さの二倍以上 |
| 枝糸の長さ | 短ければ絡まりが少なく、長ければ餌が自然に動きます |
| 道糸の固定 | 両端を杭や重い石に結び、流されないようにします |
| 設置深度 | 底に沈めればナマズ類とウナギ類、中層に浮かせれば遊泳性魚種 |
| 回収時刻 | 日の出直前が最も回収量が大きくなります |

&nbsp;&nbsp;&nbsp;延縄を夜に仕掛けておく理由は二つあります。第一に、ナマズ、ウナギ、ギギのように嗅覚で餌を探す夜行性魚種が夜に活動し、これらは視覚に頼らないため、糸が見えるかどうかは問題になりません。第二に、人が眠っている時間を漁具が働く時間に変えるため、熱量収支の面で最も有利です。

&nbsp;&nbsp;&nbsp;ただし、一晩中掛かったままだった魚はすでに死んでいることが多く、水温が高いと朝回収したときにはすでに腐敗が始まっている状態のこともあります。夏場は回収周期を短くするか、生きたまま閉じ込めておける筌のほうを増やすほうが安全です。また、設置した漁具の位置を覚えておらず回収できなくなると、その漁具は誰にも食べられない魚を殺し続ける装置になってしまいます。
