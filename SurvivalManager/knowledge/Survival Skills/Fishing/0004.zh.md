## 3. 鱼笼、渔网、鱼梁与延绳钓
&nbsp;&nbsp;&nbsp;这里介绍的渔具，全部都是在人离开现场时发挥作用的。它们共通的原理是：让鱼自己游进来，进来之后又找不到出去的路径。关键不在于用力量困住鱼，而在于利用鱼的行为习性。

---
### 3-1. 鱼笼困住鱼的原理
&nbsp;&nbsp;&nbsp;鱼笼的入口呈漏斗状，从外侧到内侧逐渐变窄，漏斗的尖端悬在鱼笼内部的正中央。鱼会循着饵料的气味从漏斗宽大的入口游进去。到这一步为止，笼壁会自然地把鱼引向内侧，并不困难。

&nbsp;&nbsp;&nbsp;鱼出不去的原因，在于鱼被困在死角时，有沿着壁面绕圈的习性。鱼不会去寻找悬浮在空间中央的小孔出口，而是沿着外侧笼壁绕圈寻找出口。然而漏斗的出口并不在壁上，而是在空间正中央，而且尖端朝内，因此不会与沿壁绕圈的鱼的路径相交。这就是鱼笼的全部原理。如果把漏斗尖端做得太靠近笼壁，或者漏斗太短、直接与笼壁相连，逃脱率就会大幅上升。

| 设计要素 | 标准 | 这样做的原因 |
| --- | --- | --- |
| 漏斗入口直径 | 以目标鱼种能通过为准 | 过大会让大鱼进入并撞破渔具逃走 |
| 漏斗尖端直径 | 比目标鱼种的身体略粗 | 越窄逃脱率越低，但进入率也会降低 |
| 漏斗长度 | 鱼笼深度的3分之1左右 | 使尖端落在空间中央，与沿壁路径分开 |
| 笼条间距 | 比目标鱼种更窄 | 让小个体能够逃出，以减少资源损失 |
| 鱼笼朝向 | 入口朝向水流下游 | 鱼大多面朝上游，会循着气味逆流游入 |

&nbsp;&nbsp;&nbsp;竹子和柳条之所以是好材料，是因为它们即使长期泡水也不易腐烂，剖开后能得到粗细均匀的篾条，沾湿后又会变得柔韧、便于弯折。干燥状态下弯折会折断，所以编织前要先泡水。编织方式是把纵向的骨架条竖直立起，再用细枝条横向缠绕，每绕一圈就把缠绕方向错开一格，骨架条就会被固定住，结构便能自行保持稳定。

&nbsp;&nbsp;&nbsp;设置位置必须是鱼群往来的必经之路。鱼笼吸引鱼的能力较弱，如果不放在鱼群已经出没的地方，无论放多少饵料都只会是空的。应优先选择水草区边缘、石缝旁、水流变窄处，以及水深发生落差的地方。

### 3-2. 网眼与渔网的种类
&nbsp;&nbsp;&nbsp;渔网捕鱼的方式有两种。一种是让鱼身卡在网眼中无法脱出，另一种是把鱼围住、使其无处可逃。前者是刺网，后者是抛网与地拉网。

&nbsp;&nbsp;&nbsp;刺网的选择性取决于鱼的体围。如果头部已经穿过，但最粗的体围比网眼周长更大，鱼就会前进不得、后退也不得，鳃盖会被网线卡住固定。因此刺网对捕获尺寸会同时产生上限和下限。太小的鱼会直接穿网而出，太大的鱼则连头都穿不进去，只能折返。正是靠这个特性，只需改变网眼大小，就能决定要捕获哪种尺寸的鱼。

| 网眼边长 | 主要挂住的鱼体长（大致） | 备注 |
| :---: | :---: | --- |
| 20mm | 10cm左右 | 马口鱼、池沼公鱼等小型鱼种 |
| 35mm | 15-20cm | 鲫鱼、重唇鱼的幼鱼 |
| 50mm | 25-30cm | 中型鲫鱼、鲤鱼的幼鱼 |
| 75mm | 35-45cm | 中大型个体 |
| 100mm以上 | 50cm以上 | 仅限大型鱼种 |

&nbsp;&nbsp;&nbsp;渔网要在水中像墙一样立起，就必须在上方装浮子、下方装沉子。浮子只要是木块、干葫芦、中空芦苇束等密度小于水的东西即可；沉子只要是打了孔的石头或穿在绳上的碎石即可。浮力与下沉力的大小相配，渔网才能绷紧展开；只要有一方不足，渔网就会歪斜或贴在水底，捕不到鱼。

| 种类 | 原理 | 所需条件 |
| --- | --- | --- |
| 刺网 | 横跨水道竖起，让鱼自己撞挂上去 | 用料少，无需人在场 |
| 三重刺网 | 在两层稀疏外网之间夹入一层细密内网，形成口袋 | 尺寸选择性低，连小个体都会被捕获 |
| 抛网 | 抛出圆盘状渔网罩下，边缘坠子收拢将鱼困住 | 需要熟练技巧，且水底不能有挂网物 |
| 地拉网 | 在岸边用渔网围住大片水域后拉拢收网 | 需要多人协作，且水底须平坦 |
| 抄网、拦河小网 | 支起小网，把鱼驱赶进去 | 在浅溪中是最简便的方法 |

### 3-3. 鱼梁与石沪
&nbsp;&nbsp;&nbsp;鱼梁与石沪，是把水流本身变成渔具的构造物。在潮差很大的滩涂上，涨潮时鱼会跟随潮水进入浅处，退潮时又随之退出。这时若在退水的水道上砌一道低矮的石墙，水会从石缝中漏走，鱼却会留下来。

&nbsp;&nbsp;&nbsp;石沪的典型形状之所以是马蹄形，是为了迎面拦截退去的水流。把开口一侧朝向大海，整体向内弯曲成凹形，退潮时被冲出的鱼就会沿着石墙移动，最终集中到曲率汇聚的那一点。在该处会砌筑一个比其他地方更厚更高的水塘，这被称为"imtong"（鱼窝）。即使潮水完全退去，imtong里仍会留有积水，鱼便会活着聚集在那里。

&nbsp;&nbsp;&nbsp;石墙的高度并不统一，从潮间带内侧不足30cm开始，越靠近海一侧就越高。这是因为水位越深的一侧，墙就必须越高，否则鱼会越墙而出。河流中也采用同样的原理。在浅滩下方用石头堆成V字形，让顶点朝向下游，顺流而下的鱼就会聚集到顶点的狭窄缝隙处，此时只需在那个位置放上鱼笼或竹帘即可。

&nbsp;&nbsp;&nbsp;鱼梁与石沪的决定性优点在于不需要饵料，一旦筑成便能运作数十年，而且潮汐这种无穷的能量来源会代替人来驱赶鱼群。缺点是前期劳动量非常大，而且一旦选址失误，这些劳动就会全部白费。必须在多个潮汐周期中反复观察水流与地形之后，才能动工修筑。

### 3-4. 延绳钓与夜间布放
&nbsp;&nbsp;&nbsp;延绳钓是在一根长长的主线上按一定间隔系上短小的支线，每条支线末端再挂上鱼钩或卡钩的渔具。它不是一个人用一根鱼竿看管一枚鱼钩，而是在同一时间把数十枚鱼钩同时放入水中，因此每小时的预期渔获量要大得多。

| 要素 | 需考虑的事项 |
| --- | --- |
| 支线间距 | 为避免互相缠绕，须为支线长度的两倍以上 |
| 支线长度 | 短则不易缠绕，长则饵料动作更自然 |
| 主线固定 | 两端系在木桩或重石上，防止被冲走 |
| 布放深度 | 贴底放置可钓鲇鱼类和鳗鱼类，悬浮中层可钓游泳性鱼种 |
| 起钓时间 | 日出前渔获量最大 |

&nbsp;&nbsp;&nbsp;延绳钓在夜间下放的理由有两个。第一，鲇鱼、鳗鱼、黄颡鱼这类靠嗅觉觅食的夜行性鱼种会在夜间活动，它们不依赖视觉，因此钓线是否显眼并不成问题。第二，这种方式把人睡觉的时间转变为渔具工作的时间，在热量收支上最为有利。

&nbsp;&nbsp;&nbsp;不过，整夜挂在线上的鱼大多已经死亡，水温高时，早上收线时鱼可能已经开始腐败。夏季最好缩短回收周期，或者增加能让鱼活着被困住的鱼笼比例，这样更安全。另外，如果记不住渔具设置的位置而无法回收，那件渔具就会变成一台不断杀死无人食用的鱼的装置。
