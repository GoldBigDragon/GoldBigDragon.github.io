## 3. 鱼笼、渔网、鱼梁、延绳钓
&nbsp;&nbsp;&nbsp;这些渔具在人离开的时候也在运作。共同的原理是让鱼自己进来，进来之后又找不到出去的路。利用的是鱼的行为习性，而不是关住它们的力量。

---
### 3-1. 鱼笼
- 结构：入口是从外向内逐渐变窄的漏斗形，漏斗的末端悬在鱼笼内部的正中央。鱼循着饵的气味从宽大的入口进入，笼壁自然地把它们引向里面。
- 防止逃脱的原理：被困在死角的鱼有沿着壁面绕圈的习性。漏斗的出口不在壁上，而在空间正中央，并尖锐地朝向内侧，所以与沿壁绕行的路线不相交。漏斗末端靠近笼壁，或者漏斗太短、从壁面直接连出去的话，逃脱率会大幅上升。

| 设计要素 | 标准 | 理由 |
| --- | --- | --- |
| 漏斗入口直径 | 目标鱼能通过的程度 | 过大的话，大鱼进来后会撞坏渔具逃走 |
| 漏斗末端直径 | 比目标鱼种的身体粗细略大 | 越窄逃脱率越低，但进入率也降低 |
| 漏斗长度 | 约为鱼笼深度的三分之一 | 使末端位于空间中央，与壁面路线分开 |
| 篾条间距 | 比目标鱼种窄 | 让小个体漏出去，减少资源损失 |
| 鱼笼朝向 | 入口朝向水流的下游一侧 | 鱼大多朝着上游，闻到气味后逆流进入 |

- 材料：竹子和柳条在水里泡很久也不容易变软，劈开后可以得到粗细一致的篾条，湿了会变柔韧。干着弯曲会折断，所以编之前先泡水。
- 编法：把经篾竖起来，用细枝横向缠绕。每一根缠绕的方向错开一格，经篾就被固定，结构能自行保持。
- 设置位置：鱼经过的要道。鱼笼招鱼的力量弱，不放在鱼本来就经过的地方的话，放了饵也是空的。优先选水草带边缘、石缝旁边、水变窄的咽喉处、水深变化的落差。

---
### 3-2. 渔网
&nbsp;&nbsp;&nbsp;渔网捕鱼的方式有两种。让身体卡在网目里无法脱出的刺网，以及把鱼围住、使其无处可逃的撒网和拉网。

&nbsp;&nbsp;&nbsp;刺网的选择性由鱼的身体周长决定。头穿过去了，但最粗的身体周长大于网目周长，鱼就前进后退都不行，鳃盖被网线挂住固定。太小的鱼直接漏出去，太大的鱼头进不去而退回，所以捕到的大小上下限都有。仅靠改变网目大小就能决定捕多大的鱼。

| 网目边长 | 主要挂住的体长（大致） | 备注 |
| :---: | :---: | --- |
| 20mm | 10cm左右 | 宽鳍鱲、池沼公鱼等小型种 |
| 35mm | 15-20cm | 鲫鱼、唇䱻的幼鱼 |
| 50mm | 25-30cm | 中型鲫鱼、鲤鱼的幼鱼 |
| 75mm | 35-45cm | 中大型个体 |
| 100mm以上 | 50cm以上 | 仅限大型种 |

&nbsp;&nbsp;&nbsp;网要像墙一样立在水里，上面挂浮子，下面挂沉子。浮子是木块、干葫芦、空心芦苇束这类密度比水小的东西，沉子是穿孔的石头或穿在绳上的卵石。浮力和下沉力要匹配，网才能绷直展开，一边不足的话，网会斜躺或铺在水底，什么也捕不到。

| 种类 | 原理 | 所需条件 |
| --- | --- | --- |
| 刺网 | 横截水路立着放，让鱼自己挂住 | 材料用得少，无须有人在场 |
| 三层刺网 | 在两层稀疏的外网之间放细密的内网，形成口袋 | 大小选择性低，连小个体也会被捕到 |
| 撒网 | 抛出圆盘形网罩住，边缘的坠子收拢把鱼围住 | 需要熟练，且水底不能有挂碍物 |
| 拉网 | 在水边用网围住大片面积后拉拽 | 需要多人，水底要平坦 |
| 抄网 | 架一张小网，把鱼赶进去 | 浅溪中最简便的方法 |

### 3-3. 鱼梁与石梁
&nbsp;&nbsp;&nbsp;这是把水的运动本身变成渔具的构筑物。在潮差大的滩涂，鱼随涨潮进入浅处，又随退潮离开。在退水的水道上砌一道低矮的石墙，水从石缝间流走，鱼就被留下。

- 马蹄形：用来拦截退水的形状。开口一侧朝向大海，向内凹弯，被退潮推出去的鱼沿着墙移动，会集中到曲率汇聚的一点。在那一点砌得比别处更厚更高的水池，称为Imtong（留鱼池）。水全部退完后，留鱼池里还留着水，鱼活着聚集在里面。
- 墙的高度：在潮间带内侧从30cm以下开始，越往海一侧越高。水涨得越深的一侧，墙必须越高，鱼才跳不过去。
- 河流：在浅滩下游用石头砌成V字形，顶点朝向下游。顺流而下的鱼会聚集到顶点的狭窄缝隙里，所以在那里放鱼笼或鱼箔。
- 优点：不需要饵，一旦砌成能运作几十年，潮汐这一无穷的能量来源代替人把鱼赶过来。
- 缺点：初期劳动量非常大，位置选错的话，劳动全部白费。要在多个潮期观察潮水流向和地形之后再砌。

### 3-4. 延绳钓与夜间设置
&nbsp;&nbsp;&nbsp;延绳钓是在长长的干线上每隔一定间距挂短支线，每根支线末端系钩或咽钩的渔具。同一时间有几十个钩放在水里，所以每小时的预期回收量大得多。

| 要素 | 考虑事项 |
| --- | --- |
| 支线间距 | 至少为支线长度的两倍，避免互相缠绕 |
| 支线长度 | 短的话缠绕少，长的话饵能自然活动 |
| 干线的固定 | 两端系在木桩或重石上，防止漂走 |
| 设置深度 | 贴着水底是鲶鱼类和鳗鲡类，浮在中层是游泳性鱼种 |
| 回收时刻 | 日出前一刻回收量最大 |

- 夜里泡着的原因一：鲶鱼、鳗鲡、黄颡鱼这类靠嗅觉找食的夜行性鱼种在夜里活动，它们不依赖视觉，所以绳子看不看得见不成问题。
- 原因二：把人睡觉的时间变成渔具工作的时间，在热量收支上最有利。
- 挂了一整夜的鱼往往已经死了，水温高的话，早上回收时可能已经开始腐败。夏天要缩短回收周期，或增加能让鱼活着关住的鱼笼。
- 设置的渔具因为不记得位置而无法回收的话，那个渔具就变成不断杀死没人吃的鱼的装置。
