## 4. 餌と獲った後の処理、食用の安全
&nbsp;&nbsp;&nbsp;獲るところまでが釣りの半分で、残りの半分は、獲ったものを安全に食べられる状態に保つ仕事です。魚は陸上の動物よりはるかに早く傷みます。

---
### 4-1. 餌
&nbsp;&nbsp;&nbsp;餌は魚に、においと動きの2つの信号を与えます。においは水に溶けて拡散して広い範囲に届きますが、方向の情報が弱く、動きは狭い範囲でしか見えませんが、即座の攻撃を誘います。どちらの信号が効くかは、魚種と状況によって異なります。

| 餌 | 作動する信号 | 適した状況 |
| --- | --- | --- |
| ミミズ | においと動きの両方 | ほとんどすべての淡水魚に効く基本の餌 |
| サナギ、昆虫の幼虫 | 強いにおい | 濁った水、夜間、筌用 |
| バッタ、コオロギ | 水面での動き | 夏に表層を狙う魚種 |
| 魚の内臓、えら | 非常に強いにおい | 筌と延縄に適する。カニやエビも集まる |
| 細かく切った魚の身 | においと視覚 | 肉食性の魚種全般 |
| 貝、カワニナの身 | におい | 水が澄んでいるとき有効 |
| 穀物の練り餌、煮た穀物 | におい | コイやフナなどの雑食性の魚種 |
| きらきらした破片、羽 | 視覚と動き | 水が澄んでいて光があり、魚が活発なときだけ |

- 人工の餌は、3つの条件がすべて必要です。魚が餌を探して活動中で、水が澄んで視覚が働き、人が餌に動きを与えられることです。1つでも欠けると、ほとんど作動しません。
- 受け身の漁具では、人が動きを与えられないので、においの強い餌が有利です。
- 獲った魚の内臓は捨てずに、次の筌の餌として循環させます。

---
### 4-2. 魚が早く傷む理由
&nbsp;&nbsp;&nbsp;獲れたての魚の筋肉は、原則として無菌の状態です。細菌は表皮、えら、消化管にあり、身の中にはありません。

| 部位 | 細菌の密度(おおよそ) | 処理での意味 |
| --- | :---: | --- |
| 身(筋肉) | 無菌に近い | 汚染は外から入ってくる |
| 表皮の粘液 | 10²-10⁷ cfu/cm² | 粘液を洗い流すと密度が大きく下がる |
| えら | 10³-10⁹ cfu/g | 血液が集まっているので、細菌の増殖が最も速い |
| 消化管 | 10³-10⁹ cfu/g | 消化酵素も一緒にあり、組織を崩す |

- 内臓を早く取り出さなければならない理由: 魚が死ぬと、消化酵素が餌の代わりに自分自身、つまり腹腔の壁を消化し始めます。消化管に穴があくと、その中の細菌が無菌だった身に直接入り込み、腐敗が内側から同時に進みます。餌をたくさん食べたまま獲れた魚が特に早く柔らかくなるのも、消化酵素が多いためです。
- 血を抜くと保存性が上がる理由: 血液は細菌にとって栄養豊富な培地であり、ヘモグロビンの鉄は脂肪の酸化を促進する触媒です。死ぬときに暴れた魚は、筋肉に乳酸がたまってpHがさらに下がり、組織が柔らかくなります。獲ってすぐにえらの後ろを切り、心臓が動いている間に血を抜くと、身に残る血液が減り、酸化も細菌の増殖も遅くなります。心臓が止まると血がうまく抜けないので、時間との勝負です。
- 獲った直後に血を抜き、えらと内臓を取り除くことが、冷蔵なしで魚を守れる最大の措置です。行わなければ、他のどんな保存処理も、すでに始まった内部の腐敗を元に戻せません。
- 死後硬直(FAO資料): 0℃でストレスを受けたタラは、2-8時間で硬直が始まり、20-65時間で解けます。ストレスを受けていない個体は、14-15時間後に始まり、72-96時間で解けます。硬直が遅く始まり長く続くほど、身が長く固く、細菌が侵入しにくくなります。魚を長く苦しめず、素早く死なせることが、保存に有利な理由です。

### 4-3. 淡水魚の寄生虫
&nbsp;&nbsp;&nbsp;淡水魚を生で食べることは、災害時でも避けるべき、数少ない絶対的な禁忌です。肝吸虫は、淡水の貝類を第一中間宿主、コイ科の淡水魚を第二中間宿主とし、人が加熱不足の淡水魚を食べたときに感染します。韓国疾病管理庁の資料によると、感染後約3-4週間の潜伏期間を経て、大部分は無症状ですが、長期の感染は胆管がんの危険因子です。2012年の調査で、韓国国内の感染率は全人口の1.9%でした。

| 寄生虫 | 感染経路 | 特徴 |
| --- | --- | --- |
| 肝吸虫 | コイ科の淡水魚の生食 | 無症状で数年続き、胆管がんの危険を高める |
| 有棘顎口虫 | 淡水魚、両生類、爬虫類の生食 | 幼虫が皮膚の下や臓器を移動し、目や中枢神経を侵すことがある |
| 横川吸虫 | アユ、ウグイの生食 | 下痢と腹痛 |
| 広節裂頭条虫 | サケ科の魚類の生食 | ビタミンB12欠乏性貧血 |
| アニサキス | 海産魚の生食 | 胃壁に食い込み、急性の腹痛 |

- すべて、十分な加熱で死滅します。身の中心部が63℃以上なら安全で、実質的には、身が白く不透明になり、骨から簡単にはがれる状態が基準です。
- 塩漬けにしたり、酢や酒に浸したりする方法は、信頼できません。冷凍は有効ですが、災害時には確保が難しいものです。
- 調理器具を介した間接感染も成り立ちます。生魚を扱った包丁とまな板には、熱湯をかけて処理します。

### 4-4. 毒を持つ魚
&nbsp;&nbsp;&nbsp;毒を持つ魚は、食べると危険なものと、触ると危険なものに分かれ、対応がまったく異なります。

| 対象 | 毒の性質 | 知っておくべき点 |
| --- | --- | --- |
| フグ類 | テトロドトキシン。卵巣、肝臓、内臓、皮に集中 | 120℃で1時間加熱しても壊れず、産卵期の春と夏に毒が最も多い |
| オニオコゼ、ハチ、ゴンズイ | 背びれと胸びれのとげのタンパク質毒 | 刺されると極度の痛み。死んだ個体のとげも危険 |
| ウツボ類の一部、大型の熱帯魚 | シガテラ毒 | 熱帯のサンゴ礁の食物連鎖を通じて蓄積し、加熱で壊れない |
| 淡水のエイ | 尾のとげの毒 | 物理的な傷が大きく、感染の危険が高い |
| アナゴ、ウツボの血液 | イクチオトキシン | 加熱すると壊れるので、生食だけ避ければよい |

> **注意:** テトロドトキシンは、加熱では除けず、解毒剤がなく、筋肉を麻痺させて呼吸筋を止めます。食品安全ナラの資料によると、毒性は青酸カリの約10倍以上で、嘔吐と頭痛から始まり、言語障害と筋肉麻痺へ進み、重ければ数時間以内に死亡します。フグを安全に食べるには、種を正確に識別し、毒のある部位をすべて取り除かなければならず、平常時でも資格のある人だけが行います。災害時にフグを食べようとすることは、空腹より大きな危険を冒す選択です。

&nbsp;&nbsp;&nbsp;とげによる毒は大部分がタンパク質なので、熱に弱いものです。刺されたとき、耐えられる程度の熱いお湯に傷口を浸すと、痛みが和らぎます。痛みの緩和にとどまり、感染の危険をなくしてはくれません。

### 4-5. 知らない魚に対する原則
&nbsp;&nbsp;&nbsp;識別に自信がないとき、参考にできる形態的な傾向があります。規則ではなく傾向であり、例外が多くあります。

| 観察対象 | 注意を要する特徴 |
| --- | --- |
| 体型 | 体が球のように膨らむ、またはお腹が特に膨らんだ形 |
| 皮膚 | うろこがなく、厚い革のような皮膚 |
| ひれ | 鋭く硬いとげが目立つひれ |
| 歯 | オウムのくちばしのように融合した歯 |
| えらの穴 | とても小さな穴に縮小した形 |
| 状態 | 死んで浮いていた個体、においのする個体 |

- 形で毒の有無が判定できるという考え自体が危険です。ありふれた姿の種にも毒があり、恐ろしげな姿の種が安全なこともあります。
- 原則: 名前を知っていて安全だと確信できる種だけを食べ、確信がなければ食べません。飢えは数日は耐えられますが、神経毒は数時間で命を奪います。確信のない個体は、食べる代わりに次の筌の餌として使います。
- 内臓は特に注意します。魚の毒素の大部分は、肝臓、卵巣、消化管に蓄積し、筋肉にははるかに少なくなります。種に確信が持てない魚は、内臓をすべて捨てて身だけを十分に加熱し、内臓に触れた手と包丁も洗います。
