## 4. 餌と獲った後の処理、そして食用としての安全性
&nbsp;&nbsp;&nbsp;捕るところまでが釣りの半分であり、残りの半分は、捕ったものを安全に食べられる状態に保つ作業です。魚は陸上動物よりもはるかに早く傷み、その理由を知れば、なぜ特定の処理を急がなければならないのかが明確になります。

---
### 4-1. 餌が効く条件
&nbsp;&nbsp;&nbsp;餌は魚に二種類の合図を送ります。匂いと動きです。匂いは水に溶けて拡散するため広い範囲に届きますが方向の情報が弱く、動きは狭い範囲でしか見えませんが即座の攻撃を誘います。どちらの合図が効くかは、魚種と状況によって異なります。

| 餌 | 作用する合図 | 適した状況 |
| --- | --- | --- |
| ミミズ | 匂いと動きの両方 | ほとんどすべての淡水魚に効く基本の餌です |
| 蛹、昆虫の幼虫 | 強い匂い | 濁った水、夜間、筌用に適しています |
| バッタ、コオロギ | 水面での動き | 夏場、表層を狙う魚種に有効です |
| 魚の内臓、エラ | 非常に強い匂い | 筌と延縄に適しており、カニやエビも集めます |
| 細かく切った魚の身 | 匂いと視覚 | 肉食性の魚種全般に効きます |
| 貝、カワニナの身 | 匂い | 水が澄んでいるときに有効です |
| 穀物の練り餌、茹でた穀物 | 匂い | コイやフナなど雑食性の魚種に効きます |
| 光る破片、羽根 | 視覚と動き | 水が澄み、光があり、魚が活発なときにだけ効きます |

&nbsp;&nbsp;&nbsp;人工餌が効く条件は狭いものです。魚が餌を探して活動中であること、水が澄んでいて視覚が働くこと、人が餌に動きを与えられることが必要です。三つの条件のうちどれか一つでも欠けると、人工餌はほとんど働きません。受動漁具では人が動きを与えられないため、匂いの強い餌が原則として有利です。捕った魚の内臓は捨てるのではなく、次の筌の餌として循環させるのが最も効率的です。

---
### 4-2. 魚が早く傷む理由
&nbsp;&nbsp;&nbsp;獲れたばかりの魚の筋肉は、原則として無菌の状態です。細菌は表皮、エラ、消化管に生息しており、身の中には入り込んでいません。FAOの資料によると、表皮の細菌数は1㎠あたり10の2乗から10の7乗の水準であり、エラと腸の中では1gあたり10の3乗から10の9乗の水準に達します。つまり細菌は三つの場所に集中しているのです。

| 部位 | 細菌密度（おおよそ） | 処理における意味 |
| --- | :---: | --- |
| 身（筋肉） | 無菌に近い | 汚染は外部から入り込みます |
| 表皮の粘液 | 10の2-7乗 cfu/㎠ | 粘液を洗い流すと密度が大きく下がります |
| エラ | 10の3-9乗 cfu/g | 血液が集中しており、細菌の増殖が最も速い |
| 消化管 | 10の3-9乗 cfu/g | 消化酵素まで存在し、組織を崩壊させます |

&nbsp;&nbsp;&nbsp;内臓を早く取り出さなければならない理由はここにあります。魚が死ぬと、消化酵素はもはや餌を消化するのではなく、自分自身、つまり腹腔の壁を消化し始めます。消化管に穴が開くと、その中の細菌がただちに無菌だった身の中へ入り込み、この時点から腐敗は表面だけでなく内側からも同時に進みます。餌をたくさん食べた状態で捕らえられた魚が特に早く軟らかく崩れるのも、消化酵素の量が多いためです。

&nbsp;&nbsp;&nbsp;血を抜くことが保存性を高める理由は、これとは少し異なります。血液は細菌にとって栄養豊富な培地であり、ヘモグロビンの鉄は脂肪の酸化を促進する触媒として働きます。また、死ぬ間際にもがいた魚は筋肉に乳酸がたまってpHがさらに下がり、組織が軟らかくなります。捕らえたらすぐにエラの後ろを切り、心臓がまだ動いている間に血を抜けば、身に残る血液量が減り、酸化も細菌の増殖も遅くなります。心臓が止まった後は血が抜けにくくなるため、この処理は時間との勝負です。

&nbsp;&nbsp;&nbsp;まとめると、捕ったらすぐに血を抜き、エラと内臓を取り除くことが、冷蔵なしで魚を守るための最大の措置です。この二つを行わなければ、他のどんな保存処理も、すでに始まった内部の腐敗を元に戻すことはできません。

&nbsp;&nbsp;&nbsp;死後硬直についても知っておく必要があります。FAOの資料によれば、0°Cでストレスを受けたタラは2-8時間で硬直が始まり20-65時間でほぐれますが、ストレスを受けなかった個体は14-15時間後に始まり72-96時間でほぐれます。硬直の開始が遅く、持続時間が長いほど、身は長く硬い状態を保ち、細菌が侵入しにくくなります。魚を長く苦しめず、速やかに絶命させることが保存に有利である理由はここにあります。

### 4-3. 淡水魚の寄生虫
&nbsp;&nbsp;&nbsp;淡水魚を生で食べることは、災害状況であっても避けるべき数少ない絶対的な禁忌の一つです。肝吸虫は淡水産の貝類を第1中間宿主、コイ科の淡水魚を第2中間宿主とし、人が十分に火を通していない淡水魚を食べたときに感染します。韓国疾病管理庁の資料によれば、感染後約3-4週間の潜伏期を経て、多くは無症状ですが、長期感染は胆管がんの危険因子となります。2012年の調査では、韓国国内の感染率は全人口の1.9%でした。

| 寄生虫 | 感染経路 | 特徴 |
| --- | --- | --- |
| 肝吸虫 | コイ科淡水魚の生食 | 無症状のまま数年続き、胆管がんのリスクを高めます |
| 顎口虫 | 淡水魚、両生類、爬虫類の生食 | 幼虫が皮下や臓器を移動し、目や中枢神経を侵すことがあります |
| 横川吸虫 | アユ、ウグイの生食 | 下痢と腹痛を引き起こします |
| 広節裂頭条虫 | サケ科魚類の生食 | ビタミンB12欠乏性貧血を引き起こします |
| アニサキス | 海産魚の生食 | 胃壁に食い込み、急性の腹痛を引き起こします |

&nbsp;&nbsp;&nbsp;これらの寄生虫に共通するのは、十分な加熱によってすべて死滅するという点です。身の中心部が63°C以上に達すれば安全であり、実際には身が白く不透明になり、骨から簡単に外れる状態が目安になります。塩に漬けたり、酢に浸けたり、酒に浸けたりする方法は信頼できません。冷凍は有効ですが、災害状況では確保しにくい条件です。調理器具やまな板を介した間接感染も成立するため、生魚を扱った包丁とまな板には沸騰した湯をかけて処理しなければなりません。

### 4-4. 毒を持つ魚
&nbsp;&nbsp;&nbsp;毒を持つ魚は二つの部類に分かれます。食べると危険なものと、触れると危険なものです。この二つの危険は、対処法がまったく異なります。

| 対象 | 毒の性質 | 知っておくべき点 |
| --- | --- | --- |
| フグ類 | テトロドトキシン、卵巣と肝臓、内臓、皮に集中 | 120°Cで1時間加熱しても分解されず、産卵期である春と夏に毒が最も多くなります |
| オニオコゼ、ハオコゼ、ゴンズイ | 背びれと胸びれの棘にあるタンパク質毒 | 刺されると激しい痛みが起こり、死んだ個体の棘も危険です |
| ウツボ類の一部、大型の熱帯魚 | シガテラ毒 | 熱帯サンゴ礁の食物連鎖を通じて蓄積し、加熱では分解されません |
| マムシに噛まれたような淡水エイ | 尾の棘の毒 | 物理的な傷が大きく、感染のリスクが高い |
| アナゴ、ウツボの血液 | イクチオトキシン | 加熱すれば分解されるため、生食さえ避ければよい |

&nbsp;&nbsp;&nbsp;テトロドトキシンが特に危険な理由は、加熱しても消えず、解毒剤がなく、筋肉を麻痺させて呼吸筋を止めてしまう点にあります。韓国「食品安全ナラ」の資料によれば、その毒性は青酸カリの約10倍以上であり、症状は嘔吐と頭痛から始まり、言語障害と筋肉麻痺へと進行し、重い場合は数時間以内に死に至ります。フグを安全に食べるには種を正確に識別し、毒のある部位をすべて取り除かなければなりませんが、これは平常時でも資格を持つ人だけが行うことです。災害状況でフグを食べようとすることは、空腹より大きな危険を冒す選択です。

&nbsp;&nbsp;&nbsp;棘による毒は、そのほとんどがタンパク質であり、熱に弱いという性質があります。そのため、刺されたときに我慢できる程度の熱いお湯に傷口を浸すと、痛みが和らぎます。ただし、これはあくまで痛みの緩和であって、傷の感染リスクをなくしてくれるわけではありません。

### 4-5. 見知らぬ魚への対処原則
&nbsp;&nbsp;&nbsp;識別に確信が持てないとき、参考にできる形態的傾向があります。ただしこれは規則ではなく傾向にすぎず、例外が多くあります。

| 観察対象 | 注意を要する特徴 |
| --- | --- |
| 体形 | 体がボールのように膨らんだり、腹が異様に膨らんだ形 |
| 皮膚 | うろこがなく、分厚い皮のような肌 |
| ひれ | 鋭く硬い棘が目立つひれ |
| 歯 | オウムのくちばしのように癒合した歯 |
| えら穴 | えら穴がごく小さな穴に縮小した形 |
| 状態 | 死んで浮いていた個体、臭いのする個体 |

&nbsp;&nbsp;&nbsp;しかし、形態だけで毒の有無を判定できるという考え方そのものが危険です。実際には、ごく普通に見える種に毒があり、恐ろしげに見える種が安全なこともあります。災害状況で守るべき原則は単純です。名前を知っていて安全だと確信できる種だけを食べ、確信が持てなければ食べないことです。飢えは数日なら耐えられますが、神経毒は数時間で命を奪います。確信の持てない個体は、食べるのではなく次の筌の餌として使うほうが合理的です。

&nbsp;&nbsp;&nbsp;内臓には特に注意が必要です。ほとんどの魚類の毒素は肝臓、卵巣、消化管に蓄積し、筋肉にはずっと少ししか含まれません。種を確信できない魚は、内臓を必ず全量廃棄し、身だけを十分に加熱しなければならず、その内臓に触れた手とナイフも洗わなければなりません。
