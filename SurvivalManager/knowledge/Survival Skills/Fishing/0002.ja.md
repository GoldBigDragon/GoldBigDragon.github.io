## 1. 釣りと狩猟の熱量収支、魚がいる場所
&nbsp;&nbsp;&nbsp;釣りと狩猟は、同じ目的を持つ別の道具ではなく、熱量収支の構造が根本的に異なる活動です。どの方法を先に試すかを決める基準から整理します。

---
### 1-1. 投入した熱量に対する回収
&nbsp;&nbsp;&nbsp;成人男性の基礎代謝量は1日1,500-1,700kcalで、1日中険しい地形を歩くと2,000kcal以上が加わります。飢えると体が活動量を自ら減らすので、熱量を多く使う活動は、失敗したときの損失が大きくなります。狩猟は成功率が低く、失敗しても消耗した熱量は戻ってきません。受け身の漁具は、作るときに一度だけ熱量を使えば、その後は確認しに行く費用だけがかかります。

| 方式 | 投入の性格 | 人がいる必要があるか | 失敗したときの損失 |
| --- | --- | :---: | --- |
| 追跡する狩猟 | 高熱量、長時間 | 必要 | 消耗した熱量の全損 |
| 竿での釣り | 中程度、待ち時間が長い | 必要 | 時間の損失、熱量の損失は少ない |
| 筌、刺し網、延縄 | 製作に集中して投入、その後は低い | いなくてもよい | 漁具そのものは残る |
| 簗、石干見 | 初期の投入が非常に大きい | いなくてもよい | 構造物がずっと残り、回収を続けられる |
| 手探りで捕まえる | 低い | 必要 | 体温を失う危険 |

- 受け身の漁具の価値は、回収量ではなく回収の安定性です。筌を10個仕掛ければ、すべて空の日はまれで、どれか1つからは何かが出ます。1日の熱量を満たせなくても、タンパク質の供給がゼロの日をなくしてくれることが、飢えの中でははるかに重要です。
- 漁具は人が眠っている間も働き、狩猟は起きている間だけ働きます。飢えるほど起きている時間が減るので、漁具の側が有利になります。
- 見返り: 漁具に使う糸と材料を集めて撚るのに数日かかるので、状況が悪化する前に先に手を付けなければなりません。すでに衰弱した後には、漁具を作る体力がありません。

---
### 1-2. 魚がいる場所を読む原理
&nbsp;&nbsp;&nbsp;魚は水中に均一に散らばっているわけではありません。餌が集まる場所、身を隠せる場所、泳ぐのに必要なエネルギーが少ない場所、この3つの条件が重なる狭い区域に集まり、そのような区域は、地形から目で読み取れます。

| 地形の要素 | 魚が集まる理由 |
| --- | --- |
| 水深が急に変わる段差 | 深い側は隠れ家、浅い側は餌場で、2か所を行き来する通り道になる |
| 倒木、岩の積み重なり、水草の縁 | 身を隠せる構造物があり、小さな生き物が付いて暮らすので餌が豊富 |
| 流れが折れ曲がって逆に回る場所 | 流速が弱まって泳ぐ力が少なくて済み、上流から流されてきた餌が集まる |
| 2つの流れが合流する地点 | 餌と酸素が同時に供給され、流速の境界ができる |
| 橋脚、堰、水門の下 | 人工の構造物が流速の境界と日陰を同時につくる |
| 日陰になる水際 | 表面の温度が低く、上から見下ろす捕食者から隠れられる |
| 潮間帯の潮だまり | 引き潮で魚が閉じ込められて残る |

&nbsp;&nbsp;&nbsp;流れが折れる場所は特に重要です。流れる水の中で位置を保つには熱量を使い続けなければならないので、魚は速い流れのすぐ隣の遅い場所にとどまり、流れが運んでくる餌だけを選んで食べます。岩の裏、湾曲の内側、瀬が終わって深くなる首の部分が該当します。水面の模様が急に滑らかになったり、逆向きに回ったりしている所が、その場所です。

---
### 1-3. 水温と溶存酸素
&nbsp;&nbsp;&nbsp;魚は変温動物なので、水温が上がると代謝率が上がって餌をよく食べます。ところが、水に溶ける酸素の量は、水温が上がるほど減ります。夏の暑い水では酸素の要求が大きくなり、供給が小さくなって、魚は酸素が確保される場所に集まります。

| 水温 | 淡水の飽和溶存酸素(おおよそ) | 魚の状態 |
| :---: | :---: | --- |
| 0℃ | 約14.6mg/L | 代謝が最低、ほとんど食べない |
| 10℃ | 約11.3mg/L | 活動を始め、深い所にとどまる |
| 20℃ | 約9.1mg/L | 最も活発に食べる区間 |
| 25℃ | 約8.3mg/L | 活発だが、酸素の余裕が減る |
| 30℃ | 約7.6mg/L | 表層を避け、冷たい水、瀬、湧き水へ移動 |

- 溶存酸素が5mg/Lを下回ると魚はストレスを受け、2mg/Lを下回ると大部分の種が死にます。
- 真夏のよどんだ水で、魚が水面に口を出してぱくぱくしていたら、酸素不足の合図です。このような場所では、漁具を仕掛けても、かかった魚がまもなく死んで腐ります。
- 冬は氷の下の深い所の水温が最も安定しているので、魚がそこに集まります。

---
### 1-4. 時間帯と季節
&nbsp;&nbsp;&nbsp;大部分の魚は、夜明けと日暮れに最も活発です。暗くなり始めると、小魚はまだ見えるが上から見下ろす鳥にはよく見えない時間帯が生じ、小魚が浅い所に出てきて、それを狙う大きな魚もついて出てきます。真昼は、深くて日陰になった所へ退きます。

| 時期 | 魚の行動 | 釣りでの意味 |
| --- | --- | --- |
| 夜明け、黄昏 | 浅い所に出て活発に食べる | 釣りと投網の適期 |
| 真昼 | 深い所、構造物の下へ移動 | 筌を深い所に置く |
| 夜間 | 種によって活発。ナマズ類とウナギ類は夜行性 | 延縄と筌を夜に沈めておく理由 |
| 春の産卵期 | 浅い瀬と水草帯に集まる | 最も獲りやすい時期だが、資源枯渇の危険が大きい |
| 夏 | 水温が上がり、酸素不足の区間を避ける | 冷たい水が出る場所に集中 |
| 秋 | 冬に備えて活発に食べる | 回収量が最も安定する時期 |
| 冬 | 代謝が下がり、深い所に停滞 | 漁具の回収周期を延ばしても差し支えない |

&nbsp;&nbsp;&nbsp;産卵期に集まった魚は最も獲りやすいですが、そのとき獲る1匹は、次の世代の数百匹をなくすことになります。災害が数か月で終わらない可能性を考えれば、産卵場をまるごとさらう方式は、その場所の収穫を、翌年の飢えと引き換えにする選択です。
