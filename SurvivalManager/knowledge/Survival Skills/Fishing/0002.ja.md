## 1. 釣りが狩猟に優先する理由と魚の読み方
&nbsp;&nbsp;&nbsp;釣りと狩猟は、同じ目的を持つ別々の道具なのではなく、熱量収支の構造そのものが根本的に異なる二つの活動です。この違いを理解しないまま狩猟に時間を使って飢える例が多いため、どちらの方法を先に試すかを決める基準からまず整理します。

---
### 1-1. 投入熱量に対する回収
&nbsp;&nbsp;&nbsp;成人男性が一日に消費する基礎代謝量はおよそ1,500~1,700kcalで、一日中険しい地形を歩くとこれに2,000kcal以上が加わります。飢えた状態では、体がこの予算を減らそうとして活動量そのものを自ら落とすため、熱量を多く使う活動は失敗したときの損失が非常に大きくなります。狩猟は成功率が低く、失敗しても消費した熱量は戻ってきませんが、釣りの中でも受動的な漁具を使う方式は、製作に一度熱量を使ってしまえば、その後は見に行く分の費用しかかかりません。

| 方式 | 投入の性格 | 人がその場にいる必要があるか | 失敗したときの損失 |
| --- | --- | :---: | --- |
| 追跡狩猟 | 高い熱量、長時間 | 必要 | 消費した熱量が全量損失 |
| 竿釣り | 中程度、待機時間が長い | 必要 | 時間の損失、熱量の損失は少ない |
| 筌、刺し網、延縄 | 製作に集中投入、その後は低い | 不要 | 漁具そのものは残る |
| 魞、石干見 | 初期投入が非常に大きい | 不要 | 構造物が残り続け、回収され続けます |
| 手探りで捕まえる | 低い | 必要 | 体温を失う危険 |

&nbsp;&nbsp;&nbsp;受動漁具の価値は、回収量ではなく回収の安定性にあります。筌を十個仕掛ければ、一日ですべてが空である日はまれで、どれか一つからは何かが出てきます。一日の熱量をすべて満たせなくても、タンパク質の供給が0になる日をなくすことのほうが、飢餓状態ではずっと重要です。

> **漁具は人が眠っている間も働き、狩猟は人が起きているときにしか働きません。飢えるほど起きていられる時間は短くなるため、飢えるほど漁具のほうが有利になります。**

&nbsp;&nbsp;&nbsp;ただし、受動漁具には代償もあります。漁具を作るのに必要な糸や編む材料を集めて撚るのには数日かかるため、状況が悪化する前にあらかじめ着手しておかなければなりません。すでに衰弱してしまった後では、漁具を作る体力さえ残っていません。

---
### 1-2. 魚のいる場所を読む原理
&nbsp;&nbsp;&nbsp;魚は水中に均等に散らばっているわけではありません。魚の分布は、三つの要求が重なる地点で決まります。第一は餌が集まる場所、第二は体を隠せる場所、第三は泳ぐのに使うエネルギーが少なくて済む場所です。この三つの条件が同時に満たされる狭い区域に個体が集中し、そうした区域は地形から目で読み取ることができます。

| 地形要素 | 魚が集まる理由 |
| --- | --- |
| 水深が急に変わる段差 | 深い側は隠れ場、浅い側は餌場となり、両者を行き来する通り道になります |
| 倒木、岩の集まり、水草の縁 | 身を隠せる構造物があり、小さな生物が付着して暮らすため餌が豊富です |
| 水流が折れ返って渦を巻く場所 | 流速が落ちて泳ぐ力が少なくて済み、上流から流れてきた餌が集まります |
| 二つの水流が合流する地点 | 餌と酸素が同時に供給され、流速の境界が生まれます |
| 橋脚、堰、水門の下 | 人工構造物が流速の境界と日陰を同時に作ります |
| 日陰になる水辺 | 表面温度が低く、上から見下ろす捕食者から隠れられます |
| 潮間帯の水たまり | 引き潮で魚が閉じ込められて残ります |

&nbsp;&nbsp;&nbsp;流速が折れる場所が特に重要です。流れる水の中で、魚は同じ場所にとどまるために泳ぎ続け、絶えず熱量を消費しています。そのため魚は、速い流れのすぐ脇にある遅い場所にとどまりながら、速い流れが運んでくる餌だけを選んで食べます。岩の陰、湾曲部の内側、瀬が終わって深くなる場所がこれに当たります。水面の模様が急に滑らかになったり、逆巻いたりしている場所こそが、まさにその位置です。

---
### 1-3. 水温と溶存酸素
&nbsp;&nbsp;&nbsp;魚は変温動物であるため、水温が上がると代謝率が上がり、餌をより多く食べるようになります。しかし水に溶けることのできる酸素の量は、水温が上がるほど減っていきます。この二つの曲線が逆方向に動くため、夏場の暖かい水では魚の酸素要求は大きくなる一方で供給は小さくなるという状況が生まれ、魚は酸素が確保できる場所に集まります。

| 水温 | 淡水の飽和溶存酸素（おおよそ） | 魚の状態 |
| :---: | :---: | --- |
| 0°C | 約14.6mg/L | 代謝最低、ほとんど食べない |
| 10°C | 約11.3mg/L | 活動開始、深い場所にとどまる |
| 20°C | 約9.1mg/L | 最も活発に食べる区間 |
| 25°C | 約8.3mg/L | 活発だが酸素の余裕は減少 |
| 30°C | 約7.6mg/L | 表層を避け、冷たい水、瀬、湧水へ移動 |

&nbsp;&nbsp;&nbsp;一般に溶存酸素が5mg/Lを下回ると魚はストレスを受け、2mg/Lを下回るとほとんどの種が死にます。真夏の淀んだ水で魚が水面に口を出してパクパクさせている様子は酸素不足の合図であり、こうした場所では漁具を仕掛けてもほどなく捕らえた魚が死んで腐ってしまいます。反対に冬は、氷の下の深い場所の水温が最も安定しているため、魚はそこに集まります。

---
### 1-4. 時間帯と季節
&nbsp;&nbsp;&nbsp;ほとんどの魚が夜明けと日暮れに最も活発になる理由は、光の量が捕食者と被食者に異なる形で作用するからです。暗くなり始めると、小さな魚はまだ見えるのに、上から見下ろす鳥はよく見えなくなる時間帯が生まれ、この時間に小さな魚が浅い場所に出てきて、それを狙う大きな魚もついて出てきます。真昼には反対に、深く日陰になった場所へと引っ込みます。

| 時期 | 魚の行動 | 釣りにおける意味 |
| --- | --- | --- |
| 夜明け、黄昏 | 浅い場所に出て活発に食べる | 釣りと投網の好機 |
| 真昼 | 深い場所、構造物の下へ移動 | 筌は深い場所に置く必要がある |
| 夜間 | 種によって活発、ナマズ類とウナギ類は夜行性 | 延縄と筌を夜に仕掛けておく理由 |
| 春の産卵期 | 浅い瀬と水草帯に群がる | 最も釣りやすい時期だが資源枯渇の危険が大きい |
| 夏 | 水温上昇、酸素不足区間を回避 | 冷たい水が出る場所に集中する |
| 秋 | 冬に備えて活発に食べる | 回収量が最も安定する時期 |
| 冬 | 代謝低下、深い場所に停滞 | 漁具の回収周期を延ばしてもよい |

&nbsp;&nbsp;&nbsp;産卵期に集まった魚は最も捕まえやすいのですが、そのとき捕る一匹は、次世代の数百匹を失わせることに等しくなります。災害が数か月で終わらない可能性を考えるなら、産卵期の産卵場を根こそぎさらう方式は、その場での収穫を翌年の飢えと引き換えにする選択です。
