## 1. 钓鱼优先于狩猎的原因与识鱼之法
&nbsp;&nbsp;&nbsp;钓鱼和狩猎并不是目的相同、只是工具不同的两件事，而是热量收支结构从根本上就不一样的两种活动。不理解这一差异、把时间投入狩猎却因此挨饿的例子并不少见，所以本节先整理该优先尝试哪种方法的判断标准。

---
### 1-1. 投入热量与回收的比较
&nbsp;&nbsp;&nbsp;成年男性一天消耗的基础代谢量大约是1,500~1,700kcal，若整天在险峻地形中行走，还要再加上2,000kcal以上。处于饥饿状态时，身体会为了压缩这份预算而自行降低活动量，因此消耗大量热量的活动一旦失败，损失就会非常大。狩猎成功率低，即使失败，消耗掉的热量也不会回来；而钓鱼当中使用被动式渔具的方式，只要在制作阶段投入一次热量，之后就只需要花费前去查看的成本。

| 方式 | 投入特性 | 是否需要人在场 | 失败时的损失 |
| --- | --- | :---: | --- |
| 追猎 | 高热量、耗时长 | 需要 | 消耗的热量全部损失 |
| 竿钓 | 中等，等待时间长 | 需要 | 损失时间，热量损失较少 |
| 鱼笼、刺网、延绳钓 | 集中投入于制作，之后很低 | 不需要 | 渔具本身会保留下来 |
| 鱼梁、石沪 | 初期投入非常大 | 不需要 | 构造物持续留存并不断回收渔获 |
| 徒手摸鱼 | 低 | 需要 | 有体温流失的风险 |

&nbsp;&nbsp;&nbsp;被动渔具的价值不在于回收量，而在于回收的稳定性。放十个鱼笼，一天之内全部落空的日子很少见，总会有一个笼子里出点什么。即使无法填满一天所需的全部热量，让蛋白质供给变为0的日子不再出现，在饥饿状态下要重要得多。

> **渔具在人睡着时也会工作，而狩猎只有在人清醒时才起作用。越是饥饿，清醒的时间就越短，因此越是饥饿，渔具就越占优势。**

&nbsp;&nbsp;&nbsp;不过，被动渔具也有相应的代价。准备制作渔具所需的绳线与编织材料并将其捻好，需要花上好几天，因此必须在状况恶化之前就提前动手。一旦已经陷入衰弱，就连制作渔具的体力都不会再剩下。

---
### 1-2. 判断鱼群所在位置的原理
&nbsp;&nbsp;&nbsp;鱼在水中并不是均匀分布的。鱼的分布取决于三种需求重叠的地点。第一是食物聚集的地方，第二是能够藏身的地方，第三是游动所耗能量较少的地方。个体会集中在同时满足这三个条件的狭窄区域，而这样的区域可以从地形上用肉眼判断出来。

| 地形要素 | 鱼群聚集的原因 |
| --- | --- |
| 水深骤变的落差处 | 深处作为藏身处，浅处作为觅食场，成为往返两处的通道 |
| 倒木、乱石堆、水草边缘 | 有可供藏身的结构物，小型生物附着其上生活，食物丰富 |
| 水流折返回旋处 | 流速变缓，游动所需力气较小，上游漂来的食物也会在此聚集 |
| 两股水流交汇处 | 食物与氧气同时得到补给，并形成流速分界 |
| 桥墩、堰坝、水闸下方 | 人工构造物同时制造出流速分界与阴影 |
| 有阴影的水边 | 表层水温较低，也能躲避从上方俯视的捕食者 |
| 潮间带的水洼 | 退潮时鱼会被困在其中 |

&nbsp;&nbsp;&nbsp;水流转折的地方尤其重要。在流动的水中，鱼要靠不断游动才能停留在原地，因此会持续消耗热量。所以鱼会停留在急流旁边流速较缓的位置，只挑选急流带来的食物进食。岩石后方、河湾内侧、浅滩尽头转深的水口，都属于这类位置。水面纹路突然变得平滑，或出现回旋的地方，正是这样的位置。

---
### 1-3. 水温与溶氧量
&nbsp;&nbsp;&nbsp;鱼是变温动物，水温升高会使代谢率上升，进食量也随之增加。然而水中能够溶解的氧气量，却会随水温升高而减少。由于这两条曲线的变化方向相反，夏季的暖水中就会出现鱼类对氧气的需求增大、而供给却在减少的局面，鱼因此会聚集到氧气有保障的地方。

| 水温 | 淡水的饱和溶氧量（大致） | 鱼的状态 |
| :---: | :---: | --- |
| 0°C | 约14.6mg/L | 代谢最低，几乎不进食 |
| 10°C | 约11.3mg/L | 开始活动，停留在深处 |
| 20°C | 约9.1mg/L | 摄食最活跃的区间 |
| 25°C | 约8.3mg/L | 依然活跃，但氧气余量减少 |
| 30°C | 约7.6mg/L | 避开表层，向冷水、浅滩、涌泉处移动 |

&nbsp;&nbsp;&nbsp;一般来说，溶氧量降到5mg/L以下时鱼会承受压力，降到2mg/L以下时大多数鱼种就会死亡。盛夏死水中鱼把嘴伸出水面一张一合，正是缺氧的信号；在这种地方即便设下渔具，捕到的鱼也会很快死亡腐坏。相反，冬季冰层下方深处的水温最为稳定，鱼因此会聚集在那里。

---
### 1-4. 时段与季节
&nbsp;&nbsp;&nbsp;大多数鱼在黎明和黄昏时最为活跃，原因在于光照量对捕食者与被捕食者的作用并不相同。天色开始变暗时，会出现小鱼还能看见、而从上方俯视的鸟类却看不清楚的时段，此时小鱼会游到浅处，而盯上它们的大鱼也会随之出现。正午则相反，鱼会退到又深又有阴影的地方。

| 时段 | 鱼的行为 | 对钓鱼的意义 |
| --- | --- | --- |
| 黎明、黄昏 | 游到浅处积极觅食 | 垂钓与撒网的最佳时机 |
| 正午 | 移向深处或构造物下方 | 鱼笼应放置在深处 |
| 夜间 | 依鱼种而活跃，鲇鱼类与鳗鱼类为夜行性 | 延绳钓与鱼笼在夜间下钩布放的原因 |
| 春季产卵期 | 集中于浅滩与水草区 | 最容易捕获的时期，但资源枯竭的风险很大 |
| 夏季 | 水温上升，回避缺氧区段 | 集中于有冷水涌出的地方 |
| 秋季 | 为过冬积极进食 | 渔获最稳定的时期 |
| 冬季 | 代谢下降，滞留深处 | 可以延长渔具的回收周期 |

&nbsp;&nbsp;&nbsp;聚集在产卵期的鱼最容易捕获，但那时捕到的一条鱼，相当于消灭了下一代数百条鱼。如果考虑到灾害可能不会在几个月内结束，把产卵期的产卵场一网打尽的做法，就是拿当下的收获去换取来年的饥荒。
