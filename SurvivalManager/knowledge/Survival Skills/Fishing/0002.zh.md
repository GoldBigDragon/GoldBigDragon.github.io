## 1. 钓鱼与狩猎的热量收支，鱼所在的地方
&nbsp;&nbsp;&nbsp;钓鱼和狩猎不是目的相同而工具不同，而是热量收支的结构从根本上就不同的活动。先梳理决定先尝试哪种方法的标准。

---
### 1-1. 相对于投入热量的回收
&nbsp;&nbsp;&nbsp;成年男性的基础代谢量每天为1,500-1,700kcal，在险峻的地形上走一整天还要再增加2,000kcal以上。饥饿时身体会自行减少活动量，所以消耗大量热量的活动，失败时的损失很大。狩猎成功率低，失败了消耗的热量也回不来。被动渔具只在制作时花一次热量，此后只需要花去查看的成本。

| 方式 | 投入性质 | 是否需要人在场 | 失败时的损失 |
| --- | --- | :---: | --- |
| 追逐狩猎 | 高热量，长时间 | 需要在场 | 消耗的热量全部损失 |
| 鱼竿钓鱼 | 中等，等待时间长 | 需要在场 | 损失时间，热量损失少 |
| 鱼笼、刺网、延绳钓 | 制作时集中投入，之后低 | 不在场也可以 | 渔具本身还在 |
| 鱼梁、石梁 | 初期投入非常大 | 不在场也可以 | 构筑物一直留着，持续回收 |
| 用手摸鱼 | 低 | 需要在场 | 有损失体温的风险 |

- 被动渔具的价值不在于回收量，而在于回收的稳定性。放十个鱼笼，全部空着的日子很少见，总会有一个捕到点什么。即使填不满一天的热量，消除蛋白质供应为零的日子，在饥饿状态下重要得多。
- 渔具在人睡着时也在工作，狩猎只在清醒时工作。越饥饿，清醒的时间越少，渔具这边就越有利。
- 代价：为渔具寻找和搓捻绳子与材料要花几天，所以必须在情况恶化之前预先动手。已经衰弱之后，就没有制作渔具的体力了。

---
### 1-2. 判断鱼所在位置的原理
&nbsp;&nbsp;&nbsp;鱼并不是均匀散布在水里。它们聚集在饵料聚集的地方、能藏身的地方、游动耗能少的地方这三个条件重叠的狭窄区域，而这样的区域从地形上用眼睛就能判断。

| 地形要素 | 鱼聚集的原因 |
| --- | --- |
| 水深急剧变化的落差 | 深的一侧是藏身处，浅的一侧是觅食处，成为往返两处的要道 |
| 倒下的树、岩石堆、水草边缘 | 有可藏身的结构物，小生物附着生活，饵料丰富 |
| 水流折返回旋的地方 | 流速减弱，游动耗力少，上游冲下来的饵料会聚集 |
| 两股水流汇合的点 | 同时供应饵料和氧气，形成流速分界 |
| 桥墩、堰、水闸下面 | 人工构筑物同时造出流速分界和阴影 |
| 有阴影的水边 | 表面温度低，并能躲开从上方俯视的捕食者 |
| 潮间带的水洼 | 退潮时鱼被困留下 |

&nbsp;&nbsp;&nbsp;水流折转的位置特别重要。要在流水中保持原位，就得不断消耗热量，所以鱼待在紧挨着急流的缓流处，只挑水流送来的饵料吃。岩石后面、河湾内侧、浅滩结束变深的咽喉处都属于此类。水面纹路突然变得平滑或倒转回旋的地方，就是这样的位置。

---
### 1-3. 水温与溶解氧
&nbsp;&nbsp;&nbsp;鱼是变温动物，水温升高，代谢率升高，吃得更多。但溶解在水中的氧气量随水温升高而减少。夏天的热水里，氧气需求变大而供给变小，鱼就会聚集到有氧气的地方。

| 水温 | 淡水的饱和溶解氧（大致） | 鱼的状态 |
| :---: | :---: | --- |
| 0℃ | 约14.6mg/L | 代谢最低，几乎不吃 |
| 10℃ | 约11.3mg/L | 开始活动，待在深处 |
| 20℃ | 约9.1mg/L | 觅食最活跃的区间 |
| 25℃ | 约8.3mg/L | 活跃，但氧气余量减少 |
| 30℃ | 约7.6mg/L | 避开表层，向冷水、浅滩、涌泉移动 |

- 溶解氧降到5mg/L以下，鱼会受到应激，降到2mg/L以下，大部分种类会死亡。
- 盛夏的死水里，鱼把嘴伸出水面一张一合，就是缺氧的信号。在这样的地方，即使放下渔具，捕到的鱼也很快就死掉腐烂。
- 冬天，冰下深处的水温最稳定，所以鱼聚集在那里。

---
### 1-4. 时间段与季节
&nbsp;&nbsp;&nbsp;大部分鱼在黎明和黄昏最活跃。天色开始变暗，会出现小鱼还能看见、而从上方俯视的鸟看不清的时间段，小鱼就到浅处来，捕食它们的大鱼也跟着出来。正午则退到深而有阴影的地方。

| 时期 | 鱼的行为 | 对钓鱼的意义 |
| --- | --- | --- |
| 黎明、黄昏 | 来到浅处，活跃觅食 | 钓鱼和撒网的最佳时机 |
| 正午 | 移到深处、构筑物下面 | 把鱼笼放在深处 |
| 夜间 | 因种类而异地活跃。鲶鱼类和鳗鲡类是夜行性 | 延绳钓和鱼笼在夜里泡着的原因 |
| 春季产卵期 | 聚集到浅滩和水草带 | 最容易捕到的时期，但耗竭资源的风险很大 |
| 夏季 | 水温上升，躲开缺氧区间 | 集中在冷水涌出的地方 |
| 秋季 | 为过冬而活跃觅食 | 回收量最稳定的时期 |
| 冬季 | 代谢降低，滞留在深处 | 延长渔具回收周期也无妨 |

&nbsp;&nbsp;&nbsp;产卵期聚集的鱼最容易捕，但那时捕一条，等于灭掉下一代的几百条。考虑到灾难可能不会在几个月内结束，把产卵场整个扫一遍的做法，是用那个地方的收获去换明年的饥饿。
