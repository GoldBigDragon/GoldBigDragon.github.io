## 4. 饵料与捕获后的处理，食用安全
&nbsp;&nbsp;&nbsp;捕到只是钓鱼的一半，另一半是把捕到的东西保持在可以安全食用的状态。鱼比陆生动物变质快得多。

---
### 4-1. 饵料
&nbsp;&nbsp;&nbsp;饵给鱼两种信号：气味和运动。气味溶于水并扩散，能到达很大的范围，但方向信息弱；运动只在很小的范围内能看到，但会引起立即的攻击。哪种信号管用，因鱼种和情况而异。

| 饵 | 起作用的信号 | 适合的情况 |
| --- | --- | --- |
| 蚯蚓 | 气味和运动都有 | 对几乎所有淡水鱼都管用的基本饵 |
| 蛹、昆虫幼虫 | 强烈气味 | 浑水、夜间、鱼笼用 |
| 蝗虫、蟋蟀 | 水面上的运动 | 夏季针对表层的鱼种 |
| 鱼内脏、鱼鳃 | 非常强烈的气味 | 适合鱼笼和延绳钓。也会招来螃蟹和虾 |
| 切碎的鱼肉 | 气味和视觉 | 肉食性鱼种通用 |
| 蛤蜊、田螺肉 | 气味 | 水清时有效 |
| 谷物面团、煮熟的谷物 | 气味 | 鲤鱼和鲫鱼等杂食性鱼种 |
| 闪亮的碎片、羽毛 | 视觉和运动 | 仅限水清、有光线、鱼活跃的时候 |

- 人工饵三个条件缺一不可。鱼正在活动觅食，水清澈到视觉能起作用，人能给饵以运动。缺一个，就几乎不起作用。
- 被动渔具上人无法给饵运动，所以气味强的饵有利。
- 捕到的鱼的内脏不要丢掉，作为下一个鱼笼的饵循环使用。

---
### 4-2. 鱼为什么很快变质
&nbsp;&nbsp;&nbsp;刚捕到的鱼的肌肉原则上是无菌的。细菌在表皮、鳃和消化道里，肉里面没有。

| 部位 | 细菌密度（大致） | 对处理的意义 |
| --- | :---: | --- |
| 肉（肌肉） | 近乎无菌 | 污染是从外面进来的 |
| 表皮黏液 | 10²-10⁷ cfu/cm² | 洗掉黏液，密度会大幅下降 |
| 鳃 | 10³-10⁹ cfu/g | 血液集中，所以细菌繁殖最快 |
| 消化道 | 10³-10⁹ cfu/g | 连消化酶也在一起，会破坏组织 |

- 为什么必须尽快取出内脏：鱼一死，消化酶就不再消化食物，而是开始消化鱼自己，也就是腹腔壁。消化道一穿孔，里面的细菌就直接进入原本无菌的肉里，腐败从内部同时进行。吃饱了被捕到的鱼特别快变软，也是因为消化酶多。
- 为什么放血能提高保存性：血液是营养丰富的细菌培养基，血红蛋白中的铁是促进脂肪氧化的催化剂。死前挣扎过的鱼，肌肉里乳酸积累，pH进一步下降，组织变软。捕到后马上切断鳃后面，趁心脏还在跳动时放血，肉里残留的血就会减少，氧化和细菌繁殖都会变慢。心脏停了血就放不出来，所以是和时间赛跑。
- 捕到后立即放血并去除鳃和内脏，是没有冷藏时保护鱼的最大措施。不做的话，其他任何保存处理都无法逆转已经开始的内部腐败。
- 尸僵（FAO资料）：在0℃下受到应激的鳕鱼，2-8小时开始僵硬，20-65小时解除。没有受到应激的个体14-15小时后开始，72-96小时解除。僵硬开始得越晚、持续得越久，肉保持坚实的时间越长，细菌越难侵入。这就是不长时间折磨鱼、迅速杀死它对保存有利的原因。

### 4-3. 淡水鱼的寄生虫
&nbsp;&nbsp;&nbsp;生吃淡水鱼是即使在灾难情况下也要避免的少数绝对禁忌之一。华支睾吸虫（肝吸虫）以淡水贝类为第一中间宿主，以鲤科淡水鱼为第二中间宿主，人吃了没煮熟的淡水鱼就会感染。据韩国疾病管理厅资料，感染后经过约3-4周的潜伏期，大多无症状，但长期感染是胆管癌的危险因素。2012年调查中，韩国的感染率为全体人口的1.9%。

| 寄生虫 | 感染途径 | 特点 |
| --- | --- | --- |
| 华支睾吸虫 | 生吃鲤科淡水鱼 | 无症状地持续数年，增加胆管癌的风险 |
| 棘颚口线虫 | 生吃淡水鱼、两栖类、爬行类 | 幼虫在皮下和器官中移行，可能侵犯眼睛和中枢神经 |
| 横川后殖吸虫 | 生吃香鱼、雅罗鱼 | 腹泻和腹痛 |
| 阔节裂头绦虫 | 生吃鲑科鱼类 | 维生素B12缺乏性贫血 |
| 异尖线虫（Anisakis） | 生吃海鱼 | 钻入胃壁，引起急性腹痛 |

- 充分加热都能杀死。肉的中心部位在63℃以上就是安全的，实际上以肉变成白色不透明、容易与骨头分离的状态为标准。
- 用盐腌，或浸在醋或酒里的方法不可靠。冷冻有效，但灾难情况下很难做到。
- 通过烹调工具的间接感染也成立。处理过生鱼的刀和砧板，用开水浇过。

### 4-4. 有毒的鱼
&nbsp;&nbsp;&nbsp;有毒的鱼分为吃了有危险的和碰了有危险的，应对方式完全不同。

| 对象 | 毒的性质 | 需要了解的 |
| --- | --- | --- |
| 河豚类 | 河豚毒素。集中在卵巢、肝脏、内脏、皮 | 120℃加热1小时也不会被破坏，产卵期的春季和夏季毒性最强 |
| 鬼鲉、红鳍鲉类、线纹鳗鲇 | 背鳍和胸鳍棘刺的蛋白质毒 | 被刺会极度疼痛。死去个体的棘刺也危险 |
| 部分海鳝类、大型热带鱼 | 西加毒素 | 通过热带珊瑚礁食物链蓄积，加热不会被破坏 |
| 淡水鲼 | 尾刺的毒 | 物理伤口大，感染风险高 |
| 海鳗、海鳝的血液 | 鱼血毒素 | 加热就会被破坏，所以只要避免生吃即可 |

> **注意：** 河豚毒素不能靠加热去除，没有解毒剂，会麻痹肌肉，使呼吸肌停止。据食品安全国资料，毒性约为氰化钾的10倍以上，从呕吐和头痛开始，发展到言语障碍和肌肉麻痹，严重时数小时内死亡。要安全地吃河豚，必须准确识别种类并去除全部有毒部位，平时也只有具备资质的人才做。灾难情况下尝试吃河豚，是甘冒比饥饿更大的风险的选择。

&nbsp;&nbsp;&nbsp;棘刺造成的毒大多是蛋白质，怕热。把伤口浸在能忍受的热水里，疼痛会减轻。这只是缓解疼痛，并不能消除感染风险。

### 4-5. 对待不认识的鱼的原则
&nbsp;&nbsp;&nbsp;对识别没有把握时，有一些可以参考的形态倾向。是倾向而不是规则，例外很多。

| 观察对象 | 需要注意的特征 |
| --- | --- |
| 体形 | 身体像球一样膨胀，或肚子格外鼓胀的形态 |
| 皮肤 | 没有鳞片，皮肤厚得像皮革 |
| 鳍 | 带有突出的锋利坚硬棘刺的鳍 |
| 牙齿 | 像鹦鹉嘴一样愈合的牙齿 |
| 鳃孔 | 缩小成很小的孔 |
| 状态 | 漂浮着的死鱼、有臭味的个体 |

- 认为能从形态判断有没有毒，这个想法本身就很危险。长得普通的种类也可能有毒，长得吓人的种类也可能是安全的。
- 原则：只吃知道名字、确信安全的种类，没有把握就不吃。饥饿能忍几天，神经毒素几个小时就夺走性命。没把握的个体不要吃，用作下一个鱼笼的饵。
- 内脏要特别小心。大部分鱼毒素蓄积在肝脏、卵巢、消化道，肌肉里要少得多。对无法确定种类的鱼，内脏全部丢弃，只把肉充分加热，并清洗接触过内脏的手和刀。
