## 4. 诱饵与捕获后的处理，以及食用安全
&nbsp;&nbsp;&nbsp;捕到鱼只是钓鱼的一半，剩下的一半，是要把捕到的鱼维持在能够安全食用的状态。鱼比陆地动物腐坏得快得多，了解其中的原因，就能明白为什么某些处理必须争分夺秒。

---
### 4-1. 诱饵起作用的条件
&nbsp;&nbsp;&nbsp;诱饵会向鱼发出两种信号：气味和动作。气味溶于水中扩散，能到达较大范围，但方向信息较弱；动作只有在狭窄范围内才能被看见，却能诱发即时的攻击。哪种信号更有效，取决于鱼种与当时的情况。

| 诱饵 | 起作用的信号 | 适合的情况 |
| --- | --- | --- |
| 蚯蚓 | 气味与动作兼具 | 对几乎所有淡水鱼都有效的基本诱饵 |
| 蛹、昆虫幼虫 | 气味强烈 | 适合浑水、夜间与鱼笼诱饵 |
| 蚱蜢、蟋蟀 | 水面上的动作 | 对夏季瞄准表层的鱼种有效 |
| 鱼内脏、鱼鳃 | 气味非常强烈 | 适合鱼笼与延绳钓，也能招来蟹和虾 |
| 切碎的鱼肉 | 气味与视觉 | 对肉食性鱼种普遍有效 |
| 贝类、田螺的肉 | 气味 | 在水质清澈时有效 |
| 谷物面团、煮熟的谷物 | 气味 | 对鲤鱼、鲫鱼等杂食性鱼种有效 |
| 闪亮的碎片、羽毛 | 视觉与动作 | 只在水清、有光线且鱼活跃时才有效 |

&nbsp;&nbsp;&nbsp;人工诱饵起作用的条件比较狭窄。需要鱼正在觅食活动、水质清澈使视觉发挥作用、并且要有人能让诱饵产生动作。三个条件中只要缺一个，人工诱饵基本就不起作用。在被动渔具上，由于没有人能赋予诱饵动作，原则上气味浓烈的诱饵更为有利。捕到的鱼的内脏不应丢弃，而应循环用作下一个鱼笼的诱饵，这样效率最高。

---
### 4-2. 鱼腐坏得快的原因
&nbsp;&nbsp;&nbsp;刚捕获的鱼，其肌肉原则上处于无菌状态。细菌生活在表皮、鱼鳃和消化道中，并未进入鱼肉内部。根据FAO的资料，表皮的细菌数量约为每1㎠有10的2次方到10的7次方，鱼鳃和肠道内则可达到每1g有10的3次方到10的9次方。也就是说，细菌集中在这三个部位。

| 部位 | 细菌密度（大致） | 在处理上的意义 |
| --- | :---: | --- |
| 鱼肉（肌肉） | 接近无菌 | 污染来自外部 |
| 表皮黏液 | 10的2-7次方 cfu/㎠ | 冲洗掉黏液后密度会大幅下降 |
| 鱼鳃 | 10的3-9次方 cfu/g | 血液集中，细菌增殖最快 |
| 消化道 | 10的3-9次方 cfu/g | 还有消化酶存在，会破坏组织结构 |

&nbsp;&nbsp;&nbsp;必须尽快取出内脏的理由就在这里。鱼一旦死亡，消化酶就不再消化食物，而是开始消化鱼自身，也就是腹腔壁。消化道一旦被穿透，其中的细菌便会立刻进入原本无菌的鱼肉，从这一刻起，腐败不只发生在表面，同时也从内部进行。饱食状态下被捕获的鱼之所以特别快变软，也是因为体内消化酶的量更多。

&nbsp;&nbsp;&nbsp;放血能提高保存性的原因略有不同。血液是细菌营养丰富的培养基，血红蛋白中的铁则会作为催化剂促进脂肪氧化。另外，死前挣扎过的鱼，肌肉中会积累乳酸，使pH进一步下降，组织也随之变软。捕获后立即切断鱼鳃后方，在心脏还在跳动时放血，留在鱼肉中的血液量就会减少，氧化和细菌增殖都会随之减缓。心脏一旦停止跳动，血就不容易放出，因此这项处理是一场与时间的较量。

&nbsp;&nbsp;&nbsp;总结来说，捕获后立即放血并去除鱼鳃与内脏，是在没有冷藏条件下保护鱼肉的最重要措施。不做这两件事，无论采取任何其他保存处理，都无法逆转已经开始的内部腐败。

&nbsp;&nbsp;&nbsp;死后僵直也是需要了解的知识。根据FAO的资料，在0°C下受到应激的鳕鱼会在2-8小时内开始僵直、20-65小时后解除，而未受应激的个体则在14-15小时后开始僵直、72-96小时后解除。僵直开始得越晚、持续得越久，鱼肉就能保持坚实的时间越长，细菌也就越难侵入。不长时间折磨鱼、而是尽快将其处死，之所以有利于保存，原因就在于此。

### 4-3. 淡水鱼的寄生虫
&nbsp;&nbsp;&nbsp;生食淡水鱼，是即使在灾害状况下也应避免的少数绝对禁忌之一。肝吸虫以淡水贝类为第1中间宿主，以鲤科淡水鱼为第2中间宿主，人在食用未煮熟的淡水鱼时会被感染。根据韩国疾病管理厅的资料，感染后约经过3-4周的潜伏期，大多数感染者无症状，但长期感染会成为胆管癌的危险因素。2012年的一项调查显示，韩国国内的感染率为总人口的1.9%。

| 寄生虫 | 感染途径 | 特点 |
| --- | --- | --- |
| 肝吸虫 | 生食鲤科淡水鱼 | 无症状持续数年，并会升高胆管癌风险 |
| 颚口虫 | 生食淡水鱼、两栖类、爬行类 | 幼虫在皮下与脏器间移行，可侵犯眼部与中枢神经 |
| 横川吸虫 | 生食香鱼、雅罗鱼 | 引起腹泻与腹痛 |
| 阔节裂头绦虫 | 生食鲑科鱼类 | 引起维生素B12缺乏性贫血 |
| 异尖线虫（安尼萨基斯） | 生食海产鱼 | 钻入胃壁，引发急性腹痛 |

&nbsp;&nbsp;&nbsp;这些寄生虫的共同点是，只要充分加热就都会被杀灭。鱼肉中心部达到63°C以上即为安全，实际操作中可以肉眼判断：鱼肉变白不透明、且容易与骨头分离即达标。用盐腌、用醋泡、用酒泡等方法都不可靠。冷冻有效，但在灾害状况下是难以具备的条件。通过厨具和砧板发生的间接感染同样成立，因此处理过生鱼的刀具和砧板都必须浇淋沸水消毒。

---
### 4-4. 有毒的鱼
&nbsp;&nbsp;&nbsp;有毒的鱼可以分为两类：吃了危险的，以及碰了危险的。这两种危险的应对方法完全不同。

| 对象 | 毒素性质 | 需了解的要点 |
| --- | --- | --- |
| 河鲀类 | 河鲀毒素，集中在卵巢、肝脏、内脏与皮肤 | 即使以120°C加热1小时也不会被破坏，产卵期的春夏两季毒性最强 |
| 日本鬼鲉、小鲉、线纹鳗鲇 | 背鳍与胸鳍棘刺中的蛋白质毒素 | 被刺后会剧痛，死亡个体的棘刺同样危险 |
| 部分海鳝类、大型热带鱼 | 雪卡毒素 | 通过热带珊瑚礁食物链蓄积，加热无法破坏 |
| 蜇伤如同被蝮蛇咬伤的淡水黄貂鱼 | 尾刺的毒素 | 造成的物理创伤大，感染风险高 |
| 海鳗、海鳝的血液 | 鱼毒素（Ichthyotoxin） | 加热即可破坏，只需避免生食 |

&nbsp;&nbsp;&nbsp;河鲀毒素之所以特别危险，是因为它无法通过加热去除、没有解毒剂，并且会使肌肉麻痹、导致呼吸肌停止运作。根据韩国"食品安全国"门户的资料，其毒性约为氰化钾的10倍以上，症状从呕吐和头痛开始，发展为语言障碍和肌肉麻痹，严重时数小时内即可致死。要安全食用河鲀，必须准确辨别鱼种并彻底去除所有有毒部位，而这即使在平时也只有具备资质的人才能操作。在灾害状况下尝试食用河鲀，是在冒一个比饥饿本身更大的风险。

&nbsp;&nbsp;&nbsp;棘刺造成的毒素大多是蛋白质，遇热不稳定。因此被刺伤后，把伤处浸在能够忍受的热水中，可以减轻疼痛。不过这只是缓解疼痛，并不能消除伤口感染的风险。

---
### 4-5. 应对不明鱼类的原则
&nbsp;&nbsp;&nbsp;当无法确信如何识别时，有一些可供参考的形态倾向。不过这只是倾向，而非规则，例外情况很多。

| 观察对象 | 需要留意的特征 |
| --- | --- |
| 体形 | 身体像球一样膨胀，或腹部异常鼓胀的形态 |
| 皮肤 | 没有鱗片、如厚皮革般的皮肤 |
| 鳍 | 尖锐坚硬的棘刺明显突出的鳍 |
| 牙齿 | 像鹦鹉喙一样愈合在一起的牙齿 |
| 鳃孔 | 鳃孔缩小成极小孔洞的形态 |
| 状态 | 死后漂浮的个体、带有异味的个体 |

&nbsp;&nbsp;&nbsp;然而，认为仅凭形态就能判断是否有毒，这种想法本身就很危险。实际上，看起来普通的鱼种也可能有毒，而外形凶猛的鱼种也可能是安全的。灾害状况下应遵循的原则很简单：只吃自己知道名字、并确信安全的鱼种，没有把握就不吃。饥饿可以忍耐数日，神经毒素却能在数小时内夺走性命。对于没有把握的个体，与其食用，不如用作下一个鱼笼的诱饵，这样更为合理。

&nbsp;&nbsp;&nbsp;内脏尤其需要小心。大多数鱼类毒素蓄积在肝脏、卵巢和消化道中，肌肉中含量则少得多。对于无法确定种类的鱼，必须把内脏全部丢弃，只将鱼肉充分加热后食用，接触过内脏的手和刀具也必须清洗干净。
