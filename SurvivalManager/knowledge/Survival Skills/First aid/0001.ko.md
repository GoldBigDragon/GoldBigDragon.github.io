# 응급처치
&nbsp;&nbsp;&nbsp;본 문서는 교육·참고용입니다. 어떤 경우에도 전문 의료진의 진료를 대체할 수 없으며, 응급 상황에서는 가능한 한 빨리 119(또는 현지 구조 체계)에 신고하세요. 일부 처치(바늘 감압술, 약물 투여 등)는 의료 교육을 받은 인원만 시행해야 합니다.

---
## 1. 개요와 기본 원칙
&nbsp;&nbsp;&nbsp;이 지침은 재난·전쟁·극한 환경에서 발생하는 심각한 응급 상황에 대비하여, 전문 의료진의 도움을 받기 전까지 생명을 유지하고 부상의 악화를 막는 응급처치를 제공하는 것을 목표로 합니다.  

&nbsp;&nbsp;&nbsp;응급처치는 치료가 아니라 "살아서 구조될 때까지 버티게 하는 기술"입니다. 상황이 회복되더라도 반드시 의료진의 진료를 받아야 합니다.

---
### 1-1. 처치 전 유의사항
&nbsp;&nbsp;&nbsp;부상자의 의식이 있으면 시행할 처치를 설명하고 동의를 구합니다. 부상자의 의식이 없거나 생명이 위급하면 동의 없이 즉시 처치를 시행합니다.

&nbsp;&nbsp;&nbsp;상황이 위험하거나 판단이 서지 않으면, 무리한 처치보다 자신의 안전 확보와 신속한 신고를 우선합니다.

---
### 1-2. 기본 원칙
| 원칙 | 내용 |
| --- | --- |
| 안전 확보 | 처치자 자신의 안전을 우선해야 합니다. 현장을 조사하여 감전·화재·붕괴·유해가스 등 위험 요소를 먼저 확인한 뒤 환자에게 접근합니다. |
| 신고·협력 | 즉시 신고하고 주변의 도움을 구체적으로 요청해야 합니다. 119(또는 현지 구조 체계) 신고 시 환자 상태·위치·시행한 처치를 명확히 전달해야하며, 주변인을 특정하여 "AED 가져오기", "교대" 등의 임무를 지정합니다. |
| 환자 관리 | 의식·기도·호흡·맥박을 확인한 후 응급 조치를 취합니다. 무의식 환자에게 음료를 섭취시켜서는 안되며, 젖은 옷은 제거하고 담요로 보온해야 합니다. |

---
## 2. 외상 처치 우선순위: M.A.R.C.H. 프로토콜
&nbsp;&nbsp;&nbsp;군사·재난 환경에서 우선순위에 따라 부상을 처치하는 방법입니다.

| 순위 | 단계 | 내용 |
| :---: | --- | --- |
| 1 | M - Massive Bleeding | 대량 출혈 |
| 2 | A - Airway | 기도 확보 |
| 3 | R - Respiration | 호흡·흉부 손상 |
| 4 | C - Circulation | 순환·쇼크 관리 |
| 5 | H - Head injury / Hypothermia | 머리 부상·저체온증 |

---
### 2-1. Massive Bleeding (대량 출혈)
&nbsp;&nbsp;&nbsp;대량 출혈은 생명을 가장 빠르게 위협하므로 지혈대(Tourniquet)와 상처 패킹(Wound Packing)으로 신속히 지혈하는 것이 최우선입니다.

#### 2-1-1. 지혈대
&nbsp;&nbsp;&nbsp;사지(팔·다리)의 심각한 출혈로 직접 압박만으로 지혈이 불가능할 때 사용합니다.

| 순서 | 지혈대 사용 방법 |
| :---: | --- |
| 1 | 근위부(심장 쪽)와 관절을 피해 출혈 부위에서 약 5-7cm 부근에 위치시킵니다. (위급 상황에서는 옷 위로 사지의 가장 높은 곳에 우선 적용 후 나중에 재조정합니다) |
| 2 | 벨크로 띠를 고리에 통과시켜 강하게 잡아당겨 고정합니다. |
| 3 | 조임대를 출혈이 완전히 멈출 때까지 돌립니다. |
| 4 | 조임대를 고정 고리에 끼우고 남은 띠를 정리합니다. |
| 5 | 적용 시간을 반드시 기록합니다. |
| 6 | 출혈이 멈추지 않으면 첫 지혈대 바로 위(근위부)에 두 번째 지혈대를 추가합니다. |
| 7 | 현장에서 임의로 풀지 않습니다. |

#### 2-1-2. 상처 패킹(Wound Packing)
&nbsp;&nbsp;&nbsp;지혈대 적용이 불가능한 부위(사타구니·목·겨드랑이 등)의 관통상 출혈에 사용합니다.

| 순서 | 상처 패킹 처치 내용 |
| :---: | --- |
| 1 | 거즈 끝을 작은 공 모양으로 말아 올립니다. |
| 2 | 출혈이 가장 심한 깊은 부위까지 거즈를 깊숙이 밀어 넣습니다. |
| 3 | 손가락을 교체할 때도 압력이 유지되도록 주의하며 상처 내부를 꽉 채웁니다. |
| 4 | 패킹 완료 후 양손으로 최소 3분간 강하게 압박합니다. |
| 5 | 출혈이 멈춘 것을 확인한 뒤 압박 붕대로 고정합니다. |

---
### 2-2. Airway (기도 확보)
&nbsp;&nbsp;&nbsp;환자가 의식이 있고 말을 할 수 있으면 기도는 열린 것으로 간주합니다. 의식이 없거나 호흡에 문제가 있으면 즉시 기도를 확보합니다.  

&nbsp;&nbsp;&nbsp;경추 손상이 의심될 때는 턱을 들어 올립니다. 구토·기도 폐쇄 위험이 경추 손상 위험보다 크다고 판단되면, 경추 고정보다 기도 확보를 우선합니다.  

&nbsp;&nbsp;&nbsp;의식이 없거나 구강 기도기(OPA) 사용이 어려울 경우, 비인두 기도기(NPA)를 삽입합니다. 만일 NPA가 없거나 두부·안면 골절, 심한 코 출혈 시에는 회복 자세(옆으로 눕힌 자세)로 눕혀 기도를 확보합니다.

---
### 2-3. Respiration (호흡·흉부 손상)
&nbsp;&nbsp;&nbsp;흉부 손상(총상·자상 등)으로 인한 긴장성 기흉(Tension Pneumothorax)은 생명을 위협하므로 즉시 처치합니다.

#### 2-3-1. 개방성 기흉

| 순서 | 개방성 기흉 처치 내용 |
| :---: | --- |
| 1 | 흉부의 구멍을 확인합니다. |
| 2 | 밀폐 드레싱(Chest Seal)으로 공기 유입을 막습니다. |
| | 배출 밸브형(vented) 밀폐 드레싱을 우선 사용합니다. |
| | 배출 밸브형 밀폐 드레싱이 없으면 완전 밀폐 후, 긴장성 기흉 징후가 나타나면 드레싱 한쪽을 잠시 떼어 압력을 빼줍니다. |
| | 둘 다 없을 때의 임시방편으로만 삼면 밀봉(three-sided seal)을 적용합니다. |

#### 2-3-2. 긴장성 기흉 관리
&nbsp;&nbsp;&nbsp;지속되는 호흡 곤란, 흉부 좌우 움직임 불균형, 약해지는 맥박, (저혈량 쇼크가 아닌데도) 목정맥 팽창(JVD) 증상이 발현될 경우, 긴장성 기흉 증상일 가능성이 높습니다.

&nbsp;&nbsp;&nbsp;바늘 감압술(NCD)은 잘못 시술 시 폐·심장·주요 혈관에 치명상을 줄 수 있으므로 의료 교육을 받은 전문 인원만 시행해야 합니다.

&nbsp;&nbsp;&nbsp;교범 기준 바늘 감압술 위치는 빗장중앙선 2번째 늑간, 또는 앞겨드랑이선 5번째 늑간이며, 해당 부위에 바늘을 삽입하여 흉강 내 압력을 해소합니다. 압력이 해소될 경우, 폐 재팽창과 심장으로의 혈액 순환이 회복됩니다.

---
### 2-4 Circulation (순환·쇼크 관리)
&nbsp;&nbsp;&nbsp;모든 지혈 처치가 유효한지 재확인하고, 쇼크 징후를 파악해 순환을 유지합니다.

| 쇼크 징후 | 내용 |
| :---: | --- |
| 색 | 창백하거나 푸른색 |
| 상태 | 차고 축축한 피부 |
| 온도 | 체온 저하 |

| 쇼크 단계 | 내용 |
| :---: | --- |
| 보상성 쇼크 | 심박수를 높여 혈압을 유지하려는 단계 |
| 비보상성 쇼크 | 혈액 손실이 너무 커 더 이상 버티지 못하는 심각한 상태 |

| 순서 | 쇼크 처치 내용 |
| :---: | --- |
| 1 | 환자를 수평으로 눕히고 다리를 지면에서 15-30cm 들어 올립니다. 단, 명백한 골반·복부·흉부·척추 손상이 있으면 다리 거상은 내부 출혈을 악화시킬 수 있으므로 금지합니다. |
| 2 | 젖은 옷은 즉시 제거하고, 담요·옷으로 보온합니다. |
| 3 | 환자가 무의식 상태라면 아무것도 먹이지 말고, 기도가 막히지 않도록 고개를 옆으로 돌립니다. |
| 4 | 맥박·혈압·호흡을 10분 간격으로 확인하되, 대량 출혈 환자는 더 짧은 간격으로 확인합니다. |

---
### 2-5. Head injury / Hypothermia (머리 부상·저체온증)
&nbsp;&nbsp;&nbsp;동공 확장, 너구리 눈, 귀·코에서 맑은 액체(뇌척수액) 누출 시 머리 부상 징후로 봅니다. 머리 부상 징후가 보일 경우, 척추 손상 동반 가능성이 있으므로 머리와 목을 고정한 채 이송해야 합니다.

&nbsp;&nbsp;&nbsp;심각한 외상 환자는 출혈·쇼크로 체온이 급격히 떨어지며, 이는 응고 장애를 유발해 출혈을 악화시킵니다.

| 순서 | 저체온증 처치 내용 |
| :---: | --- |
| 1 | 따뜻한 곳으로 옮기고 젖은 옷을 제거합니다. |
| 2 | 담요·보온포로 몸 전체를 감싸고, 머리에 후드·모자를 씌워 열 손실을 막습니다. |
| 3 | 중증 외상 환자는 수술 대비 및 흡인 위험으로 경구 섭취 절대 금지. 경증 저체온이고 외상이 없을 때만 따뜻한 음료를 소량씩 허용합니다. |

---
## 3. 심폐소생술(CPR)
![image](./media/CPR.png)  

&nbsp;&nbsp;&nbsp;심정지 환자의 생존율은 4분 이내의 정확한 CPR에 달려 있으며, 10분이 넘으면 뇌 손상·사망 가능성이 급격히 높아집니다. 자동심장충격기(AED)를 함께 사용하면 생존율이 두 배 이상 높아집니다.

&nbsp;&nbsp;&nbsp;압박 속도는 분당 100~120회가 적당하며, 압박과 인공호흡의 비율은 30:2가 적당합니다. 가슴압박 중단은 10초 이내로 최소화 해야하며, 압박 이후 가슴이 완전히 이완되도록 합니다.

---
### 3-1. 대상별 절차
| 구분 | 반응 확인 | 손 위치·압박 깊이 | 단독 구조 시 | 인공호흡 |
| --- | --- | --- | --- | --- |
| 성인 | 어깨를 두드리며 "괜찮으세요?" | 두 손 깍지, 가슴 중앙(흉골 아래 1/2). 약 5~6 cm | 즉시 119(또는 현지 구조 체계) 신고 후 CPR | 권장하되, 일반인은 가슴압박만으로도 효과적 |
| 소아(1세~사춘기) | 어깨를 두드림 | 한 손, 가슴 중앙. 가슴 두께의 약 1/3(약 5 cm) | 2분 CPR 먼저 시행 후 119(또는 현지 구조 체계) 신고 | 호흡성 심정지가 많으므로 반드시 30:2 시행 |
| 영아(1세 미만) | 발바닥을 두드림 | 두 손가락, 가슴 중앙. 가슴 두께의 약 1/3(약 4 cm) | 2분 CPR 먼저 시행 후 119(또는 현지 구조 체계) 신고 | 호흡성 심정지가 많으므로 반드시 30:2 시행 |

| 순서 | 심폐소생술 공통 절차 |
| :---: | --- |
| 1 | 위험 요소 확인 후 안전을 확보하고 접근합니다. |
| 2 | 반응을 확인합니다(위 표 기준). |
| 3 | 무반응 시 주변인을 특정하여 도움을 요청합니다. |
| | "거기 검은 옷 입으신 분, 119(또는 현지 구조 체계) 신고해 주세요!" / "흰색 옷 입으신 분, AED 가져와 주세요!" |
| | 혼자라면 휴대폰 스피커 모드로 119(또는 현지 구조 체계)와 통화하며 진행합니다. |
| 4 | 가슴 움직임을 보고 10초 이내로 호흡을 확인합니다. 비정상 호흡(헐떡임 포함)은 호흡 없음으로 간주. |
| 5 | 호흡이 있으면 회복 자세로 전환, 없으면 가슴 압박을 시작합니다. |
| 6 | 구급대 도착 또는 환자 회복 시까지 30:2를 반복합니다. |

---
### 3-2. 인공호흡
| 순서 | 인공호흡 절차 |
| :---: | --- |
| 1 | 머리를 뒤로 젖히고 턱을 들어 기도를 확보합니다. |
| 2 | 코를 막고(영아는 입과 코를 동시에 덮고, 머리는 중립 위치 유지) 1초간 가슴이 부풀 정도로 불어 넣습니다. |
| 3 | 감염 방지를 위해 인공호흡용 마스크·안면 보호대 사용을 권장합니다. |

---
### 3-3. 자동심장충격기(AED) 사용법
![image](./media/AED.png)  

| 순서 | 자동심장충격기(AED) 사용법 |
| --- | --- |
| 1 | 도착 즉시 전원을 켜고 음성 안내를 따릅니다. 이때, CPR을 멈추지 않고 준비 병행해야 합니다. |
| 2 | 오른쪽 쇄골 아래 + 왼쪽 겨드랑이 아래 옆구리에 패드를 부착합니다. 영아는 가슴 중앙(앞)과 등(뒤)에 부착(전후방 부착 방식) 합니다. 가능하면 소아용 패드/에너지 감쇠기를 사용하고, 없으면 성인 패드를 쓰되 패드끼리 닿지 않도록 합니다. |
| 3 | "환자와 접촉 금지" 안내 시 환자에게서 떨어집니다. |
| 4 | 충격 버튼을 누르기 직전 "물러나세요"를 외쳐 모두 떨어지도록 합니다. 충전이 완료되면 충격 버튼을 누릅니다. |
| 5 | 환자로부터 심장 박동 감지 시 회복 자세로 전환합니다. 심장 박동이 감지되지 않는다면 충격 후 즉시 CPR을 재개하고, 음성 지시를 반복합니다. |

---
### 3-4. 유의사항
&nbsp;&nbsp;&nbsp;구조자는 2분마다 교대하여 피로로 인한 압박 깊이 저하를 막아야 합니다.  

&nbsp;&nbsp;&nbsp;환자가 다수일 경우 호흡이 없는 환자를 우선합니다.  

&nbsp;&nbsp;&nbsp;저체온 환경에서는 "차갑지만 죽지 않았다" 원칙 아래 체온 회복 전까지 CPR 지속을 고려합니다.  

&nbsp;&nbsp;&nbsp;좁은 공간·차량에서는 가능한 한 평평한 바닥으로 이동시킵니다.  

&nbsp;&nbsp;&nbsp;대량 출혈·중증 외상 환자는 통제되지 않은 출혈 처치가 CPR보다 우선됩니다.

## 4. 상황별 응급처치
### 4-1. 외상·출혈
| 종류 | 특징 | 처치 |
| :---: | --- | --- |
| 찰과상 | 긁힌 상처. 출혈은 적으나 감염 우려가 있습니다. | 흐르는 물로 씻고 소독 후 드레싱합니다. |
| 절상 | 베인 상처. 깊이에 따라 출혈이 많을 수 있습니다. | 깨끗한 거즈로 5분 이상 직접 압박합니다. |
| 자상 | 찔린 상처. 신경·혈관 손상 위험이 있습니다. | 박힌 물체는 강제로 제거하지 말고 그대로 보호하며 이송합니다. |
| 교상 | 물린 상처. 구강 내 세균 감염 위험이 있습니다. | 상처 상태에 따라 병원 치료를 받습니다. |

| 순서 | 대량 출혈 시  빠른 조치 |
| :---: | --- |
| 1 | 손·천·거즈로 환부를 강하게 직접 압박합니다. |
| 2 | 10분 이상 압박을 유지합니다. |
| 3 | 출혈이 지속되면 팔·다리에 한정해 지혈대를 사용합니다. |
| 4 | 상처보다 심장 쪽(근위부, 약 5-7 cm 위)에 적용하고 시간을 기록합니다. |

&nbsp;&nbsp;&nbsp;일반 지혈 시 출혈 부위를 심장보다 높게 들면 출혈 감소에 도움됩니다. 응고된 피 덩이는 떼어내지 않으며, 지혈제·연고를 뿌리는 행위는 병원 처치에 지장을 주므로 삼갑니다.

---
### 4-2. 화상·열 손상
&nbsp;&nbsp;&nbsp;화상 부위의 물집을 터뜨리거나, 달라붙은 옷·물질을 강제로 떼어서는 안되며, 얼음을 환부에 직접 접촉해서는 안됩니다. 기름·된장·간장·치약·로션·연고 등을 바르는 민간요법은 감염 위험을 높입니다.

&nbsp;&nbsp;&nbsp;쇼크가 의심되면 눕히고 다리를 약간 올립니다. 담요로 보온하고, 의식이 있고 구토가 없을 때만 소량씩 물을 공급합니다.

| 구분 | 특징 | 처치 |
| :---: | --- | --- |
| 1도 | 표피 손상. 붉어지고 통증, 물집이 없습니다. | 흐르는 찬물로 냉각 후 드레싱 하고 보습에 신경씁니다. |
| 2도 | 진피까지 손상. 물집, 심한 통증이 동반됩니다. | 물집을 터뜨리지 않고 냉각 후 보호하며, 통증성 쇼크를 대비합니다. |
| 3도 | 피하조직까지 손상. 통증이 둔하거나 없습니다. (피부 이식 필요) | 환부 냉각은 짧게, 즉시 깨끗한 천으로 덮고 보온하며 병원으로 이송합니다. |

| 순서 | 공통 화상 처치 |
| :---: | --- |
| 1 | 열원에서 멀어지고, 화상 부위의 옷·장신구(반지·시계 등)를 신속히 제거합니다. 피부에 달라붙은 옷은 가위로 잘라내고, 강제로 떼어내지 않습니다. |
| 2 | 흐르는 미지근한 찬물(약 18-20℃) 또는 식염수로 약 15-20분 냉각합니다. 이때 얼음을 직접 접촉해서는 안되며, 광범위·중증 화상은 저체온 위험이 있으므로 과도하게 냉각하지 않습니다. |
| 3 | 화상 전용 드레싱과 깨끗한 거즈로 덮고 압박하지 않습니다. |

---
### 4-3. 근골격계 손상: R.I.C.E.
| 항목 | 행동 |
| :---: | --- |
| Rest(안정) | 다친 부위를 움직이지 않게 편한 자세로 휴식합니다. |
| Ice(냉찜질) | 초기 부종·통증 완화 목적에 한하여 얼음 및 차가운 것으로 약 15분 동안 찜질합니다. (장기간 냉찜질은 회복을 지연시킵니다) |
| Compression(압박) | 부목이나 탄력 붕대로 환부를 고정합니다. 붕대는 심장에서 먼 곳→가까운 쪽 순서로 감습니다. |
| Elevation(거상) | 순환 촉진과 붓기 및 통증 감소를 위해 베개로 심장보다 높게 환부를 올립니다. |

&nbsp;&nbsp;&nbsp;골절 시에는 부러진 뼈를 억지로 맞추거나 밀어 넣으면 안됩니다. 부목 사용 시, 골절 부위 양쪽 관절을 포함하는 길이 이상으로 사용하되, 부목 고정 후에는 30분 간격으로 혈액 순환을 관찰하고, 순환이 원활하지 않으면 느슨하게 조정해야 합니다.

### 4-4. 기도 폐쇄(질식)
![image](./media/Heimlich_Maneuver.png)  

&nbsp;&nbsp;&nbsp;"목에 뭐가 걸렸나요?"라고 묻습니다. 말을 못 하고 목을 움켜잡으면 완전 폐쇄. 스스로 기침을 하면 기도가 완전히 막힌 것이 아니므로 기침을 유도합니다. 영아는 복강 내 장기 손상 위험이 있으므로 복부 밀어내기(하임리히법)를 시행하지 않습니다.

| 순서 | 영아(1세 미만) |
| :---: | --- |
| 1 | 한 손으로 영아의 턱·광대뼈를 감싸 잡고, 머리가 몸보다 낮게 향하도록 허벅지 위에 엎어 놓습니다. |
| 2 | 손바닥 끝으로 양쪽 날개뼈 가운데를 세게 5회 두드립니다. |
| 3 | 턱과 뒤통수를 감싸 반대로 돌립니다. |
| 4 | 양쪽 젖꼭지 중앙 바로 아래 흉골에 두 손가락을 놓고 빠르고 강하게 5회 압박합니다. |
| 5 | 이물질이 제거될 때까지 등 두드리기와 가슴 압박을 반복합니다. |

| 순서 | 성인 및 소아 |
| :---: | --- |
| 1 | 환자 뒤에 서서 한쪽 다리를 환자 다리 사이에 넣어 지지합니다. |
| 2 | 한쪽 주먹의 엄지 쪽을 배꼽과 명치 사이에 댑니다. |
| 3 | 다른 손으로 주먹을 감싸 후상방(대각선 위)으로 강하게 밀쳐 올립니다. |
| 4 | 이물질이 배출되거나 환자가 의식을 잃을 때까지 반복합니다. (의식 소실 시 CPR로 전환) |

| 순서 | 혼자 있을 때 |
| :---: | --- |
| 1 | 기침으로 배출을 시도합니다. |
| 2 | 안 되면 주먹을 배꼽 위·갈비뼈 아래에 놓고 다른 손으로 감싸 위로 강하게 밀어 올립니다. |
| 3 | 여전히 안 되면 의자·탁자 등 고정된 물체의 모서리에 상복부를 대고 체중을 실어 압박합니다. |

### 4-5. 절단
&nbsp;&nbsp;&nbsp;절단 부위를 깨끗한 거즈·천으로 강하게 직접 압박하고 심장보다 높게 올립니다.

| 순서 | 절단물 관리·이송 절차 |
| :---: | --- |
| 1 | 생리식염수나 깨끗한 물로 가볍게 씻어 이물질을 제거합니다. |
| 2 | 식염수에 적신 깨끗한 천으로 절단물을 감쌉니다. |
| 3 | 비닐 주머니나 밀폐 용기에 넣어 밀봉합니다. |
| 4 | 얼음과 물이 담긴 용기에 밀봉된 주머니를 넣습니다. 이때, 절단물이 얼음에 직접 닿지 않아야 합니다. |
| 5 | 4-6시간 이내 접합 수술이 가능한 병원으로 이송합니다. |

---
### 4-6. 감전
| 순서 | 감전 처치 |
| :---: | --- |
| 1 | 전원을 차단합니다. 전원 차단 전에는 절대 환자와 접촉해서는 안됩니다. |
| 2 | 전원을 끌 수 없으면 마른 나무 막대기나 고무장갑 등 절연체로 환자를 전기에서 분리합니다. |
| 3 | 호흡이나 맥박이 없으면 즉시 CPR을 수행하고, AED 도착 시 사용합니다. |

---
### 4-7. 질식 사고(산소 결핍·유해 가스)
| 순서 | 질식 처치 |
| :---: | --- |
| 1 | 구조자는 공기 호흡기나 송기 마스크 등의 보호구를 착용합니다. |
| 2 | 질식 사고가 발생한 구역으로 진입하여 즉시 환기합니다. |
| 3 | 환자를 안전한 공기가 있는 곳으로 이동시킵니다. |
| 4 | 무의식 환자는 기도를 확보하고, 호흡이 약하거나 맥박이 없으면 CPR과 함께 고농도 산소를 공급합니다. |

## 5. 환경·교상 손상
### 5-1. 열 관련 질환
| 구분 | 의식 | 땀 | 체온 | 위험도 |
| --- | --- | --- | --- | --- |
| 열 경련 | 정상 | 많음 | 정상~약간 높음 | 낮음 |
| 일사병 | 약간 저하 가능 | 많음 | 37℃ 이상 | 중간 |
| 열사병 | 혼미~없음 | 없거나 있음 | 40℃ 이상 | 매우 위험 |

| 순서 | 열 질환 공통 처치 |
| :---: | --- |
| 1 | 즉시 그늘·실내·지하 등 시원한 곳으로 이동합니다. |
| 2 | 몸에 물을 뿌리고 부채질하여 증발 냉각합니다. |
| 3 | 의식이 있을 때만 물에 소금·설탕을 섞어 수분·전해질을 보충합니다. |

&nbsp;&nbsp;&nbsp;열 경련 환자는 활동을 중단 시키고 충분한 휴식을 취하도록 합니다. 수분·전해질 보충, 경련 부위 스트레칭을 병행합니다. 경련+어지러움+구토 동반 시 일사병으로 진행될 가능성이 있습니다.  

&nbsp;&nbsp;&nbsp;일사병 환자는 그늘 아래 눕히고 다리를 약간 올립니다. 구토 시 옆으로 돌려 기도를 확보하고, 젖은 수건으로 목·겨드랑이·사타구니 등의 대혈관 부위를 닦아 증발 냉각합니다. 의식이 있을 때만 물을 소량씩 반복 섭취합니다.  

&nbsp;&nbsp;&nbsp;열사병 환자는 냉각이 최우선이며, 119(또는 현지 구조 체계) 신고와 동시에 즉시 찬물에 담그거나 젖은 천을 덮고 부채질 합니다. 목·겨드랑이·사타구니를 집중 냉각하고, 호흡·맥박을 지속 관찰하여 멈추면 CPR을 시작합니다. 물을 억지로 먹이거나 해열제를 사용해서는 안됩니다.

---
### 5-2. 뱀에게 물렸을 때
&nbsp;&nbsp;&nbsp;독사(주로 살무사류)의 독은 대부분 혈액·림프계를 통해 퍼지므로, 대응 목표는 독의 "제거"가 아니라 "확산을 늦추는 것"입니다. 움직일수록 독이 빨리 퍼지므로 움직임을 최소화하고 환부를 고정해야합니다.

&nbsp;&nbsp;&nbsp;입으로 독 빨기, 칼로 절개, 지혈대로 세게 묶기, 전기 충격, 얼음 직접 대기, 음주, 뛰거나 움직이기, 된장·담뱃재 바르기 등의 행동을 해서는 안됩니다.

&nbsp;&nbsp;&nbsp;심한 통증, 급격한 부종, 물집, 괴사, 어지러움, 구토, 시야 흐림, 호흡 곤란 중 하나라도 해당하면 독사 물림으로 간주합니다.

| 순서 | 처치 |
| :---: | --- |
| 1 | 뱀에게서 즉시 떨어져 거리를 확보하고 119(또는 현지 구조 체계)에 신고합니다. |
| 2 | 환자를 눕히고 안심시켜 심박수를 낮춥니다. |
| 3 | 부종을 대비하여 반지·시계·꽉 끼는 옷 등을 미리 제거합니다. |
| 4 | 물린 부위를 흐르는 물로 가볍게 씻고 문지르지 않습니다. |
| 5 | 물린 부위에서 심장 쪽으로 약 5-10cm 떨어진 곳에 도톰하게 접은 거즈를 덧대고, 손가락 하나가 들어갈 정도로 붕대를 감아 림프·정맥 흐름만 늦춥니다(동맥까지 조이지 않도록 절대 세게 묶지 않음). 부목으로 고정합니다. |
| 6 | 물린 부위를 심장보다 약간 낮거나 같은 높이에 둡니다. |
| 7 | 의식이 있고 구토가 없으면 물을 소량씩 섭취시키고, 체온을 유지해 쇼크를 예방합니다. |
| 8 | 가능하면 들것으로 이동하되, 장거리 고립 시에는 무리한 이동보다 구조 대기가 안전할 수 있습니다. |

---
### 5-3. 벌에 쏘였을 때
&nbsp;&nbsp;&nbsp;대부분 국소 통증으로 끝나지만, 일부는 중증 전신 알레르기 쇼크(아나필락시스)로 이어질 수 있습니다. 벌침 제거 못지않게 전신 반응 감시가 중요합니다.

&nbsp;&nbsp;&nbsp;벌떼의 공격을 최소화 하려면 향수나 밝은색(화려한) 옷을 자제해야 하며, 벌이 공격하면 멀리 빠르게 도망가는 것이 가장 효과적입니다. 특히 벌을 쫓으려 공격하거나 물 속에 들어가서 숨을 참고 있어서는 안됩니다.

| 순서 | 처치 |
| :---: | --- |
| 1 | 벌은 페로몬으로 추가 공격을 유도하므로 벌이 많은 곳을 빠르게 이탈합니다. |
| 2 | 벌침의 독낭이 계속 독을 주입하므로, 가능한 빨리 카드·손톱 등 단단하고 평평한 물건으로 피부를 긁어내듯 밀어서 벌침을 제거합니다. |
| | 핀셋으로 침을 집으면 독낭을 꽉 짜버리는 결과가 되어, 남아있던 독액이 한꺼번에 부상자의 몸속으로 주입될 수 있습니다. |
| 3 | 비누와 깨끗한 물로 환부를 세척하고, 얼음을 천에 싸서 냉찜질합니다. |
| 4 | 가려워도 감염 예방을 위해 긁지 않습니다. |
| 5 | 전신 증상(어지러움·실신감 등)이 의심되면 환자를 눕히고 다리를 들어 올려 쇼크에 대비합니다. (호흡 곤란 시 상체를 약간 세워줍니다) |

&nbsp;&nbsp;&nbsp;아나필락시스 증상으로는 입술·혀·목 부종, 전신 두드러기, 호흡 곤란, 쉰 목소리, 의식 저하, 혈압 저하, 입술·혀·손끝의 청색증이 발현됩니다.

| 순서 | 아나필락시스 행동 요령 |
| :---: | --- |
| 1 | 즉시 환자를 눕히고 다리를 들어 올려 저혈압 쇼크를 예방합니다. (호흡 곤란 시 상체를 세워줍니다) |
| 2 | 에피네프린 자동주사기(EpiPen 등)를 허벅지에 즉시 주사합니다. |
| 3 | 의식이 없으면 옆으로 눕혀 기도를 확보합니다. |
| 4 | 호흡·맥박을 지속 확인하고 필요 시 CPR을 시행합니다. |

## 6. 환자 분류(Triage)
&nbsp;&nbsp;&nbsp;재난 상황에서 환자 분류는 한정된 의료 자원을 가장 효율적으로 배분하여 최대한 많은 생명을 구하는 것이 목적입니다.

### 6-1. START 분류 체계
&nbsp;&nbsp;&nbsp;START(Simple Triage and Rapid Treatment)는 현장에서 60초 이내에 환자를 평가하여 4가지 색상으로 분류합니다.

#### 6-1-1. 1차 분류: 보행 가능 여부
> "걸을 수 있는 사람은 이쪽으로 오세요"
- 보행 가능 → 초록(비응급), 안전한 장소로 이동
- 보행 불가 → 현장에서 호흡·순환·의식(RPM) 순으로 평가

#### 6-1-2. 2차 분류: RPM 평가
| 항목 | 기준 | 결과 |
| --- | --- | --- |
| Respiration | 기도 확보 후에도 호흡 없음 | 검정(사망) |
| | 분당 30회 초과 호흡 | 빨강(긴급) |
| | 분당 30회 이하 호흡 | 다음 단계(P) |
| Perfusion | 요골 맥박 없음 또는 CRT(모세혈관 재충혈) 2초 초과 | 빨강(긴급) |
| | 요골 맥박 있고 CRT 2초 이하 | 다음 단계(M) |
| Mental | 단순 명령 이행 불가 | 빨강(긴급) |
| | 단순 명령 이행 가능 | 노랑(응급) |

### 6-2. 분류표(Triage Tag) 색상
| 색상 | 분류 | 의미·우선순위 |
| :---: | :---: | --- |
| 빨강 | 긴급 | 생명을 위협받고 있어, 즉각 처치·이송이 필요합니다. (기도 폐쇄, 쇼크, 심각한 출혈) |
| 노랑 | 응급 | 심각하나 1-2시간 내 처치 시 생명에 지장이 없습니다. (개방성 골절, 경증 화상) |
| 초록 | 비응급 | 경미하거나, 스스로 보행이 가능하여 수 시간 후 처치해도 무방합니다. (찰과상, 경미한 염좌) |
| 검정 | 사망/생존 가망 없음 | 이미 사망했거나 대규모 재난 혹은 자원 극부족 상황 원칙으로 인해 제한된 자원으로 소생 불가합니다. (심정지, 치명적 머리 부상) |
