## 7. 水分管理

### 7-1. 各生育阶段的标准

| 时期 | 水分管理 | 理由 |
|---|---|---|
| 播种-发芽 | 保持不干 | 复合种子要吸足水分，外壳才能松开 |
| 生长初期 | 听凭自然降水，干旱时补水 | 引导根向深处扎 |
| 根膨大期 | 充分供水，不让土壤干 | 这一时期干旱会同时降低产量和糖度 |
| 收获前2-3周 | 停止灌溉 | 糖度升高，耐储性变好 |
| 越冬期 | 不灌溉 | 冻了又化，根会受伤 |

&nbsp;&nbsp;&nbsp;收获前停止灌溉，会直接影响糖度。不停地浇水，根会吸足水分，重量增加，但糖的浓度会被稀释。反过来，断水2-3周，水分减少，糖的浓度就会升高。如果是按重量出售的作物，这是亏本的；但如果目的是得到食糖，则是划算的。在灾害情境下属于后者。

### 7-2. 缺水与水分过多的症状

| 类别 | 症状 | 进展 | 措施 |
|---|---|---|---|
| 缺水 | 中午叶片下垂，傍晚恢复 | 初期 | 加强覆盖 |
| 缺水 | 下部叶片发黄干枯，生长停止 | 中期 | 向畦间灌水 |
| 缺水 | 根变细变硬 | 严重 | 产量和糖度一起下降 |
| 缺水后灌水 | 根纵向开裂 | 问题 | 必须均匀地供水 |
| 过多 | 下部叶片变黄，根的上部变软 | 危险 | 立即疏通排水沟 |
| 过多 | 根部有恶臭，内部发褐 | 根腐 | 把该植株拔掉丢弃 |

&nbsp;&nbsp;&nbsp;根开裂的现象，多半不是缺水本身造成的，而是水分急剧变化所致。久旱之后突然下大雨，内部组织迅速膨胀，外皮跟不上而胀裂。开裂的根，病菌会从裂缝侵入，无法贮藏。用覆盖来缩小土壤水分的波动幅度，是最有效的预防办法。

## 8. 栽培管理

### 8-1. 间苗 - 不能省略的作业

| 次序 | 时期 | 作业 |
|---|---|---|
| 第1次 | 2-3片真叶 | 间到株距3-5cm |
| 第2次 | 5-6片真叶 | 最终间到株距10-15cm |

&nbsp;&nbsp;&nbsp;甜菜的种子是几粒聚在一起的团块，所以同一处会同时冒出两三株芽。如果放任不管，它们会互相挤压着生长，结果全都又细又畸形。间苗是种植甜菜时最重要的管理作业，拖得越晚，连要保留的植株的根也会受伤。间下来的幼苗不要扔掉，可以做成凉拌野菜（namul）吃。味道和莙荙菜一样。

&nbsp;&nbsp;&nbsp;间苗时，与其拔，不如用剪刀在贴近地面处剪断。因为一拔，连旁边植株的根也会被晃动。最终间距10-15cm看上去很窄，但比这更宽的话，根会长得过大，糖的浓度反而有下降的倾向。

### 8-2. 培土

| 时期 | 作业 | 效果 |
|---|---|---|
| 生长期间1-2次 | 往根的上部培土 | 防止根暴露在阳光下 |
| 雨后 | 盖住露出的根肩 | 如果土被冲走，就再盖一次 |

&nbsp;&nbsp;&nbsp;甜菜的根在生长过程中，肩部会被顶出地面。这一部分一见阳光就会变成绿色，绿色部分糖度低、带苦味，提取食糖时会使糖浆变浑浊。培土是防止这种情况的唯一办法，既完全不花钱，又直接影响糖的得率。

### 8-3. 其他管理

| 作业 | 时期 | 内容 |
|---|---|---|
| 除草 | 生长初期 | 初期生长慢，会被杂草压住 |
| 覆盖 | 播种后，幼苗成活之后 | 用稻草或落叶。减小水分波动，防止开裂 |
| 采叶 | 从生长中期开始 | 一点一点摘下部叶片。摘得太多，糖度会下降 |
| 越冬保温 | 11-12月 | 用稻草或落叶盖住根肩 |
| 清除抽薹株 | 春季 | 抽出花茎的植株根不能用，所以先挖出来 |

## 9. 病虫害

### 9-1. 主要病害

| 病名 | 症状 | 条件 | 不用药的应对办法 |
|---|---|---|---|
| 烂根病 | 根变软腐烂，有臭味 | 过湿、排水不良 | 改善排水是唯一的对策 |
| 褐斑病 | 叶片上出现褐色斑点并扩散 | 高温高湿 | 保证通风、摘除病叶、3年以上轮作 |
| 白粉病 | 叶面覆盖一层白粉 | 干燥且昼夜温差大时 | 牛奶10倍稀释液、小苏打稀释液 |
| 根腐病 | 根内部发黑腐烂 | 苋科连作地 | 休作3年。也不要与莙荙菜、红菜头连续种植 |
| 心腐病 | 根内部发黑，新叶畸形 | 缺硼 | 不是病。用海藻和多样化的堆肥补硼 |

&nbsp;&nbsp;&nbsp;最后一行很重要。心腐病的名字里带着“病”字，但并没有病原菌。它是因为缺硼、组织无法正常形成而产生的纯粹缺素症状。喷药毫无用处，只有补充硼才是对策。人们常把它误当成病害，因而换地块或换种子。

### 9-2. 主要害虫

| 害虫 | 危害 | 不用药的应对办法 |
|---|---|---|
| 蚜虫类 | 吸食汁液并传播病毒 | 喷肥皂水，保护瓢虫和寄生蜂，避免氮过量 |
| 孢囊线虫 | 寄生在根上，使生长停止 | 无法治疗。用非寄主作物轮作多年 |
| 根菜类害虫 | 在根上蛀孔 | 抗性品系和提早播种。10月之前收获，危害约在1%的水平 |
| 地老虎 | 咬断幼苗的茎基部 | 夜里捕捉。在茎基部围一圈草木灰 |
| 叶甲 | 啃食叶片 | 水冲洗、人工捕捉 |

&nbsp;&nbsp;&nbsp;防治自立度A这一等级的依据，就在这张表的第三行。有实证表明，使用抗性品系并提早播种，可将主要害虫的发生量降低90%以上；10月之前收获完毕，危害只停留在1%左右。这意味着，在没有药剂的情况下，仅靠调节种植时间和收挖时间就能解决大部分问题，这与马铃薯疫病那种除了预防别无他法的病害有根本区别。

&nbsp;&nbsp;&nbsp;不过，孢囊线虫是例外。一旦侵入，会在土壤中留存多年，即使用药剂也难以防治。唯一的对策是在那块地里多年不种苋科作物。这就是种植甜菜之前必须查明那块地的历史的原因。

### 9-3. 不用药的防治原则

| 原则 | 内容 |
|---|---|
| 轮作 | 苋科作物要间隔3年以上。莙荙菜和红菜头也属于同一科 |
| 排水 | 这是预防烂根的唯一办法。要把垄和排水沟做好 |
| 调整时期 | 通过提早播种和提早收获避开害虫发生期 |
| 健康种子 | 经过温水处理和筛选 |
| 通风 | 通过间苗让植株之间空气流通 |
| 残茬处理 | 有病的叶和根不要留在田里，烧掉或深埋 |

## 10. 营养缺乏与过量

| 症状 | 原因 | 判断方法 | 天然材料应对 |
|---|---|---|---|
| 整张叶片发黄，植株矮小 | 缺氮 | 从下部叶片开始 | 腐熟堆肥、稀释10倍的尿液。仅限生长初期 |
| 叶缘变褐焦枯 | 缺钾 | 在根膨大期常见 | 草木灰 |
| 生长不良，叶片呈深紫色 | 缺磷 | 在低温期和酸性土壤中常见 | 骨粉、草木灰 |
| 新叶畸形，根内部发黑腐烂 | 缺硼 | 被称为心腐病 | 干海藻、堆肥多样化 |
| 叶脉间发黄 | 缺镁 | 从下部叶片开始 | 白云石、堆肥 |
| 幼叶发黄而只有叶脉保持绿色 | 缺铁 | 土壤pH过高时 | 减少用灰，增加有机质 |
| 只有叶片茂盛，根小，糖度低 | 氮过量 | 叶色过浓 | 停止供氮，用草木灰补钾 |
| 根开裂 | 水分骤变、未腐熟堆肥、石块 | 裂面光滑 | 用覆盖使水分均匀 |

&nbsp;&nbsp;&nbsp;种植甜菜最需要小心的是氮过量。在别的作物上，叶子繁茂并不是毛病，但在甜菜上，却直接意味着食糖的损失。因为只要植株判断自己还需要继续生长，糖就不会向下输送到根里。尤其是像稀释尿液这样见效快的氮源，如果在后期使用，就会只让叶子长得浓绿茂盛，到秋天挖出来一看，糖度已降到了一半。

> **甜菜的氮肥施用在5-6片真叶时就结束。此后的氮不是肥料，而是损失。**

## 11. 间作与轮作

### 11-1. 搭配宜忌

| 宜忌 | 对象 | 理由 |
|:---:|---|---|
| 适宜 | 豆科作物 | 固氮后，把氮留给下一茬的甜菜 |
| 适宜 | 洋葱、大蒜 | 能驱避害虫，且根的深度不同，竞争少 |
| 适宜 | 生菜、菠菜 | 前期覆盖垄间，抑制杂草 |
| 一般 | 大白菜、萝卜 | 存在养分竞争 |
| 避免 | 莙荙菜、红菜头、饲料用萝卜 | 同科又同种。会共有病害并杂交 |
| 避免 | 同一地块连作 | 根腐病和线虫会不断积累 |

### 11-2. 轮作顺序

| 顺序 | 作物 | 作用 |
|---|---|---|
| 第1年 | 甜菜 | 大量带走氮和钾 |
| 第2年 | 豆科（大豆、红小豆、豌豆） | 恢复氮素 |
| 第3年 | 叶菜类或洋葱类 | 利用剩余的氮。不属于苋科 |
| 第4年 | 再种甜菜 | 遵守3年以上的间隔 |

&nbsp;&nbsp;&nbsp;连作适应性B意味着要休作3年。不遵守这个间隔，根腐病和孢囊线虫就会不断积累，几年后整块地会突然崩溃。而且在计算这个间隔时，必须把莙荙菜和红菜头当作同一种作物。三者学名相同，是同一个种，对病原菌来说没有区别。在菜园里，把种过莙荙菜的地方，第二年种上甜菜，这很常见，但这与在同一处连续种甜菜没有两样。

## 12. 收获

### 12-1. 判断时期

| 用途 | 时期 | 判断标准 |
|---|---|---|
| 嫩叶菜 | 播种后30-40天 | 叶长15-20cm |
| 间下的幼苗 | 2-6片真叶 | 做凉拌野菜 |
| 根（春播） | 播种后90-150天 | 根直径5-10cm |
| 根（越冬栽培） | 次年4-5月 | 糖度和产量最高 |
| 出现抽薹迹象时 | 立即 | 花茎一抽出，糖就流失 |

&nbsp;&nbsp;&nbsp;越冬栽培确定收获时点的标准是花茎。春天气温升高后，甜菜进入第二年，开始抽出花茎，从那一刻起，贮藏在根中的糖被用来形成花茎和种子，迅速减少。当植株中心的叶子向上蹿起、茎变粗的迹象出现时，就是最后的时点。济州岛试验中4月收获被证明最优，也是因为它正好处在这一界限之前。

### 12-2. 收获要点

| 步骤 | 内容 |
|---|---|
| 1 | 选晴朗干燥的日子。湿着贮藏会腐烂 |
| 2 | 用小锄（homi）在植株旁边挖松土壤 |
| 3 | 把叶子拢在一起握住，笔直向上拔出。不要扭动 |
| 4 | 切去叶子。在根的上部留下1-2cm |
| 5 | 须根和根尾保持原样。切断的话，病菌会从那里侵入 |
| 6 | 轻轻抖掉泥土。不要用水洗 |
| 7 | 叶子当蔬菜吃，或还回田里 |

&nbsp;&nbsp;&nbsp;切叶子时，如果切得太贴近，根的头部就会露出来，腐烂就从那里开始。反过来，留得太长，叶子会继续生长，消耗根里的糖。留下1cm到2cm，就是这两种风险之间的合适位置。

### 12-3. 收获后的分类

| 类别 | 处理 |
|---|---|
| 大而无伤的 | 转入窖藏 |
| 开裂或有伤的 | 最先用来提取食糖。不贮藏 |
| 变绿的肩部 | 切掉。会使糖浆浑浊并带苦味 |
| 细小或畸形的 | 用作食物或家畜饲料 |
| 最端正、最大的 | 单独收集作种根 |
| 叶 | 做凉拌野菜、汤、腌菜。有剩余就还回田里 |
