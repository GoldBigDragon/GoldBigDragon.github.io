## はじめに
&nbsp;&nbsp;&nbsp;テンサイ(Beta vulgaris)はヒユ科の二年草で、フダンソウ、ビーツと同じ種であり、根に糖をためるように改良された系統です。18世紀末のヨーロッパで、サトウキビに代わる甘味料の原料として生まれ、ナポレオン戦争で砂糖の輸入が止まったフランスで広がりました。災害への備えの評価は総合S(52.4点、有効183種中9位)、短期S(53.7)、長期S(51.2)、副食B(47.4点)で、面積当たりの熱量がS(1㎡当たり3,850kcal)であり、乾燥した種子は常温密閉で5年もちます。しかし、この作物を扱う本当の理由は甘みです。糖はもっとも早く吸収される熱量であり、濃度が60%を超えると細菌やカビが育たない防腐剤であり、酒と酢の原料でもあります。代償は燃料です。根の糖は15%前後なので、砂糖1kgに薪が5-15kg必要になり、災害時の答えはシロップで止めることが多くなります(第10節)。

## 1. 災害への備えの評価
| 区分 | 等級 | スコア |
|:---|:---:|:---:|
| 総合 | S | 52.4 |
| 短期 | S | 53.7 |
| 長期 | S | 51.2 |
| 副食 | B | 47.4 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: 施設の負担、温度幅。S: 面積当たりの熱量、味、種子の寿命。A: 耐寒性、防除の自立度、国内での栽培の普及度。B: 水の消費量、日射、連作への適応性、合成資材を投入しない場合の収量維持率、整地・掘削エネルギー、収量の安定性 |
| 弱み | E: 非食用の価値。D: 微量栄養素、収穫速度、永続性、自家採種。C: タンパク質密度、施肥、調理・加工の要求度、病害虫圧、貯蔵性 |

> **テンサイは熱量の作物であり甘味料の作物でもあり、甘味料は災害時に貯蔵技術の幅そのものを広げます。**

&nbsp;&nbsp;&nbsp;種子の寿命Sは、種芋、塊茎、挿し穂を生きたまま毎冬守らなければならない他のイモ・根菜類と違い、乾燥した種子を瓶に入れて5年置けるという意味です。温度幅SSと耐寒性Aは、5-28℃で育ち氷点下5℃に耐えるという意味で、防除の自立度Aは、抵抗性の系統と早まきで主な害虫の発生が90%以上減り、10月前に収穫すれば被害が1%程度だという実証によるものです。自家採種Dは、二年草のため根を越冬させて翌年植え直さないと種が採れないという意味(第8節)で、微量栄養素Dは、熱量を満たすだけ食べても推奨量の10%を超える栄養素が7種しかなく、主食にはなれないという意味です。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | ヒユ科テンサイ属(Beta)の二年草。フダンソウ、ビーツ(赤いテンサイ)、飼料用ビートと同じ種。涼しい気候を好み、25℃を超えると生育が鈍る |
| 葉・茎 | フダンソウと同じ葉で、根を育てる間に下のほうの葉を摘んで野菜として食べられる |
| 根 | 白色の紡錘形で、直径10-15cm、長さ30cm以上。赤い色素はシロップを赤黒く染めるので、砂糖用は白い根の系統でなければならない |
| 花・種子 | 2年目に花茎が1m以上立ち、小さな緑色の花が風で受粉する。種子は複数の種が固まった複合種子で、ひと粒から2-3本の芽が出る |

&nbsp;&nbsp;&nbsp;播種後4週間までは発芽・幼苗期、4-10週は栄養成長期(窒素)、10-16週は根の肥大期(カリウム、ホウ素)、16-22週は糖の蓄積期(カリウム)で、2年目の春に抽苔すると根の糖が消耗されます。窒素が残っていると植物は葉をつくり続けて糖を根に送らないため、糖の蓄積期の窒素の残りがもっともよくある失敗です。100g当たり熱量43-77kcal、ショ糖14-20g(越冬栽培では20Brix以上)、タンパク質0.8-1.8gで、デンプンではなくショ糖のまま蓄えるため、汁を搾って水を飛ばすだけで甘味料になります。葉にはビタミンAとK、鉄、マグネシウムが多く、根の弱点を補います。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 生育5-28℃(適温15-20℃)、25℃以上では糖がたまらない、発芽は5℃以上。氷点下5℃を下回ると根が凍って軟らかくなる |
| 水・光 | 総蒸発散量は約550mm。1日6時間以上(適正は8時間以上)の日照が必要で、日陰では糖度が下がる |
| 土壌 | 深くて石のない砂壌土-壌土、pH 6.0-7.5(適正6.5-7.0)。他のイモ・根菜類と違って酸性に弱いため、石灰や木灰で矯正する(木灰はカリウムの供給とpHの矯正を兼ねる) |
| 作型 | 秋まき・越冬は9月中旬-10月上旬に播種し、翌年の4-5月に収穫(南部、済州)。春まきは3月中旬-4月初めに播種し、7-8月に収穫(中部、北部)で、暑くなる前に掘る。夏の高温期は避ける |

&nbsp;&nbsp;&nbsp;越冬栽培が有利です。同じ畑で12月に掘ったときは1,000㎡当たり5.8tだった収量が、そのまま置いて翌年4月に掘ると7.8tと34%増え、糖度は20.8Brixまで上がりました。低温そのものが糖をためる合図になるからです。秋まきは時期の幅が狭く、早すぎると冬の前に低温を感知して翌春に抽苔し、遅すぎると冬を越せるほど育たず凍って枯れます。

&nbsp;&nbsp;&nbsp;品種には、テナー(Tener、済州の越冬栽培で20.8Brix)、スエズ(Suez)、タングムテンサイ(忠州固有)があります。砂糖が目的なら糖度の高い白い根の系統を、熱量が目的なら根の大きい系統を選びます。市販の種子の多くは交配種で、採った種子では性質がばらつくため、最初から固定種を確保します。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 土地づくり | 20-30cm以上の深さに耕し、石を必ず取り除く(石や硬い層にあたると根が割れたり曲がったりする)。畝の高さ15-20cmと排水溝をつくる(根腐れのただ一つの予防策) |
| 施肥(1,000㎡) | 窒素10-15kg(元肥50%、追肥50%)、リン酸8-10kg(全量元肥)、カリウム10-15kg(元肥と追肥)、完熟堆肥1,000-1,500kg(未熟だと根が割れる)。元肥は播種の2週間前、追肥は本葉5-6枚で窒素中心に与えて終える。それ以降の窒素は収量ではなく糖を失わせる |
| 災害時の代替肥料 | 木灰(1㎡当たりひとつかみふたつかみ)、完熟堆肥、尿の10倍希釈液(本葉6枚以降は禁止)、骨粉、畑に戻した葉と加工の搾りかす(カリウムの循環) |
| ホウ素 | 不足すると根の中が黒く腐り、多すぎると毒性が出るため幅が狭い。現実的な入手経路は海藻(ワカメ、昆布、アオサを乾かして元肥に混ぜるか、水に浸した液を与える)で、内陸では堆肥の材料を多様にする |
| 播種 | 深さ1.5-2.5cm、条間30-40cm、最終の株間10-15cm、1,000㎡当たり1-1.5kg(間引きを見込む)。土を薄くかぶせて押さえて密着させ、発芽まで乾かさない |
| 種子の処理 | 殻が硬くて発芽がそろわないので、1日水に浸してすぐ播く(再び乾かすと発芽力が落ちる)。木灰をまぶすか、50-55℃の湯に10-15分浸して表面の病原菌を減らす |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から発芽まで | 乾かさないように保つ(複合種子は水を十分に吸わないと殻がゆるまない)。生育初期は自然の雨にまかせ、乾燥したときだけ補う |
| 根の肥大期 | 乾かさないよう十分に(乾燥は収量と糖度をともに下げる) |
| 収穫の2-3週間前 | 灌水を止める(水分が減って糖濃度が上がり、貯蔵性がよくなる)。越冬期にも灌水しない |

| 管理 | 方法 |
|:---|:---|
| 間引き | 複合種子から2-3本の芽がいっしょに出るので省けない。本葉2-3枚で3-5cm、5-6枚で最終の10-15cm間隔に残す。遅れるほど残す株の根まで傷むので、引き抜かずにはさみで地際に近いところから切る。間引いた若い株はナムルとして食べる |
| 土寄せ | 生育中に1-2回、雨のあとは露出した肩を覆う。日光にあたって緑色になった肩は糖度が低く苦みがあり、シロップを濁らせる |
| そのほかの管理 | 初期の生育が遅いため草取りが必須で、わらや落ち葉のマルチは水分の振れ幅を小さくして割れを防ぐ。下のほうの葉は少しずつだけ摘んで食べる。越冬時はわらや落ち葉で肩を覆い、春に花茎が立った株は根が使えないので先に掘る |
| 水不足、過多 | 昼に葉がしおれて夕方に回復するならマルチを補強し、下の葉が枯れたら畝の間に水を入れる。不足のあとに急に水をやると根が縦に割れて貯蔵できなくなる。過多だと上部が軟らかくなり悪臭のする根腐れになるので、その株は廃棄して排水溝を掘る |

## 6. 病害虫と養分の問題
&nbsp;&nbsp;&nbsp;病害虫圧はC(無防除の推定減収率50.6%)ですが、防除の自立度はAで、薬なしでまく時期と掘る時期を調整するだけでほとんどの問題が解決します。例外はテンサイシストセンチュウと根腐病で、土の中に何年も残るので、植える前に畑の履歴を確認しなければなりません。

| 病害虫 | 症状と条件 | 予防と対処 |
|:---|:---|:---|
| 根腐病、シストセンチュウ | 根の中が黒く腐る(ヒユ科の連作地) / 根に寄生して生育が止まる | 3年以上休ませ、フダンソウやビーツとも続けて植えない / 治療法がないので、非寄主作物と何年も輪作する |
| 褐斑病、うどんこ病 | 葉に茶色の斑点が広がる(高温多湿) / 葉の表面に白い粉(乾燥して昼夜の差が大きいとき) | 風通しを確保し、病葉を取り除き、3年以上輪作する / 牛乳の10倍希釈液、重曹の希釈液 |
| 害虫 | アブラムシ(ウイルスを媒介)、根菜の害虫(根に穴)、ネキリムシ(若い株の根元)、ハムシ(葉を食べる) | せっけん水の散布、テントウムシと寄生バチの保護 / 抵抗性の系統と早まき、10月前の収穫 / 夜に捕る、根元に灰を巻く / 手で捕る |

| 症状 | 原因と対処 |
|:---|:---|
| 新葉が奇形で根の中が黒く腐る | ホウ素欠乏(心腐れ病と呼ばれるが病原菌のない純粋な欠乏症なので、薬は役に立たない)。乾燥海藻、堆肥の多様化 |
| 葉だけが茂って根が小さく糖度が低い | 窒素過多(もっとも警戒すべきもので、後半の尿の希釈液は糖度を半分に下げる)。窒素を止めて木灰でカリウムを補う |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | マメ科(窒素を固定して次の作期に残す)、タマネギ、ニンニク(害虫を寄せつけない)、サンチュ、ホウレンソウ(初期に畝の間を覆って雑草を抑える) |
| 普通 | ハクサイ、ダイコン(養分の競合) |
| 悪い | フダンソウ、ビーツ、飼料用ビート(同じ種なので病気を共有し、交雑する)、同じ場所での連作(根腐病とセンチュウが蓄積する) |

&nbsp;&nbsp;&nbsp;輪作は、1年目テンサイ(窒素とカリウムを大量に持ち出す)、2年目マメ科(窒素の回復)、3年目葉菜類またはネギ類(ヒユ科ではない)、4年目に再びテンサイの順で、3年以上の間隔を守ります。間隔を守らないと根腐病とセンチュウが蓄積し、数年後に畑全体が崩れます。フダンソウとビーツはテンサイと同じ1つの種で病原菌には区別がつかないため、家庭菜園でフダンソウを植えた場所に翌年テンサイを植えるのも連作です。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 根は春まきの播種後90-150日(直径5-10cm)に掘り、越冬栽培では翌年4-5月に掘る。春に株の中心から葉が上に伸びて茎が太くなる抽苔の兆しが見えたらそれが最後の時点で、その後は根の糖が花茎に抜けていく |
| 要領 | 晴れて乾いた日に株の横の土をゆるめてから、葉をまとめて持ちまっすぐ抜く。葉は根の上部から1-2cm残して切る(短く切りすぎると頭から腐りが入り、長いと葉が糖を消耗する)。細根と尾は切らず(菌が入る)、土だけ払って水では洗わない。割れたり傷ついたりした根は貯蔵せず、先に砂糖の抽出に使う |

| 採種 | 基準 |
|:---|:---|
| 構造 | 種を採るには、1年目の根を食べずに冬を越して春に植え直す種根の維持が必要で、これがテンサイの自立の唯一のボトルネック |
| 種根の選抜と貯蔵 | まっすぐで割れておらず傷のない中くらい以上の大きさの根のうち、切って味見して甘いものを選び、葉は頭から3-5cm残して切り(生長点の保護)、細根は切らない。冬の間に一部は傷むので、必要な量の2-3倍を残す。湿った砂や土に頭を上にして立てて穴に埋め(0-4℃)、2週間ごとに点検する。南部では掘らずにわらを20-30cmかぶせてその場で越冬させるのがもっとも確実(中部以北は危険) |
| 再植え付け、開花 | 3月中旬-4月初めに頭が地面に少し出るように50-60cm間隔で植え、1mを超えて伸びて倒れる花茎に支柱を立てる。5-6月に開花し、穂が茶色く乾いたらしごき取って日陰で完全に乾かす |
| 隔離、株数 | 風で受粉するため、フダンソウ、ビーツ、ほかのテンサイ品種と交雑する。隔離が難しいので、同じ年には1品種だけ花を咲かせ、フダンソウとビーツはその年に採種しない。近親交配に弱いので、10株以上、できれば20株以上から採って混ぜる |
| 保管 | 完全に乾かして密閉容器に入れ、木灰か炭を布に包んでいっしょに入れて涼しく暗い所に置く。常温密閉で約5年もち、毎年数粒で発芽率を確認し、5年目が来る前に一度は採種する |

## 9. 貯蔵
&nbsp;&nbsp;&nbsp;貯蔵性Cは、貯蔵期間Bに貯蔵の損失率5.09%が反映された等級です。根は貯蔵中も呼吸して自分の体の糖を燃料に使うため、長く置くほど、温度が高いほど糖が減ります。キュアリング(10-15℃、湿度85-95%、暗くて弱い通風、1-2週間)のあとに本貯蔵(0-4℃、湿度85-95%、完全な暗黒)に入り、氷点下では凍って軟らかくなり、8℃以上では芽が出ます。

| 方式 | 方法 | 期間 |
|:---|:---|:---|
| 土室貯蔵 | 水はけのよい土地を1.5m掘って屋根と通気口をつくる(0-4℃)。もっとも安定しているが、掘る労働が大きい | 3-4か月 |
| 穴・クランプ貯蔵 | 直径1.5m、深さ20-30cmに浅く掘り、乾いたわらを10cm敷いたあと、キュアリングを終えた根を高さ60cm以内の盛り土の形に積む。わら20-30cmと土15-20cmをかぶせ、頂上にわら束で通気口をつくり(ふさぐと熱と湿気がこもって腐る)、周りに排水溝を掘る(0-5℃) | 2-3か月 |
| 加工貯蔵 | シロップ(密閉すれば1年以上)、結晶砂糖(数年)、乾燥片(6か月-1年)、2-3%の塩水での乳酸発酵(室温で1-2週間)、酒と酢 | 数か月-数年 |

> **テンサイを長く保管するいちばん確実な方法は、根を守ることではなくシロップに変えることです。根は4か月ですが、シロップは年を越えます。**

## 10. 砂糖の抽出、調理と注意事項
| 注意 | 内容 |
|:---|:---|
| 根 | キャッサバのシアン配糖体やジャガイモのソラニンのような毒性がなく、通常の量では安全。生でも食べられるが、硬くて土のにおいがするので加熱したほうがよく(丸ごと茹でるなら30-40分、蒸すなら35-45分で、糖が水に抜けない蒸すほうがよい)、食べすぎると糖分で腹をこわすことがある。変色したりにおいがおかしかったりしたら捨て、中が黒い部分(ホウ素欠乏)はえぐり取れば残りは食べられる |
| 葉 | フダンソウと同じくシュウ酸があり、窒素を多く与えた畑の葉には硝酸塩がたまるので(幼児に注意)、沸騰した湯で1-2分茹でて湯を捨てる。腎臓結石の既往がある人は多く食べない |
| 砂糖の加工 | 煮えた糖液は水より熱く粘りが強いので火傷が深く、突然吹きこぼれるので、鍋の3分の2以下しか入れず、底が焦げないように混ぜ続ける。石灰は目や皮膚につけない。薄い糖液は数日で発酵し、発酵中の液を密閉すると容器が破裂する |

| 砂糖の抽出 | 方法 |
|:---|:---|
| 切断、抽出 | 土を洗い、緑色の肩と細根を切り落としてから、厚さ2-3mmの細切りにし、浸る程度の水で70-75℃で40分-1時間煮出す。沸騰させてはいけない。80℃を超えるとペクチンが溶けて汁が粘り、濾せなくなり、60℃より低いと糖が出にくく雑菌が繁殖する。温度計がなければ、湯気が立つが沸騰していない程度が目安 |
| 向流抽出 | 前の回で出た汁を次の回の新しい細切りにかけて温め直すことを3-4回繰り返すと汁が濃くなり、最後の細切りは新しい水ですすいで、その水を次のバッチの最初の回に使う。蒸発させる水が半分以下になり、薪が少なくてすむ |
| 圧搾、清澄 | 細切りを布に包んで力いっぱい搾って残りの汁を回収し、搾りかすは飼料か堆肥に使う。煮詰める間ずっと茶色い泡をすくい取る(必須)。もっとも効果が大きいのは石灰処理である。貝殻やカキ殻を薪の火で真っ赤に焼いて生石灰をつくり、水を加えて消石灰にしてから、澄んだ上澄みを汁に少しずつ入れて沈殿させ、濾す(多いと苦みと石けんの味が残る) |
| 煮詰め、燃料 | 浅くて広い鍋の蓋を開けて煮詰め、スプーンから糸のように垂れて落ち、糖度が約70%になればシロップの完成。砂糖1kgを得るには水4.5-5Lを蒸発させる必要があり、開放の火(熱効率5-15%)では薪が5-15kg必要。節約法は、向流抽出(最大)、ほかの調理の余熱、浅い黒い器に汁を入れて布をかけ日なたに置く予備濃縮 |
| 凍結濃縮 | 氷点下の夜に、汁を浅くて広い器に入れて外に出し、朝にできた氷(ほぼ純粋な水)を取り除くことを何晩も繰り返す。燃料がまったく要らないが、濃度が上がると凝固点が下がり、おおよそ半分までしかできない。冬のある地域では、秋に汁を搾り、冬の夜に凍結濃縮して、春に煮詰める順序がいちばん燃料が少ない |
| シロップ、結晶 | 災害時の答えはたいていシロップ。追加の燃料も道具も要らず、損失がなく、甘味づけ、漬け込み、保存、発酵のすべてに使える。糖度60-65%を下回ると発酵したりカビが生えたりするので、70%付近まで煮詰める。結晶砂糖は、水に落とすと軟らかい塊にまとまるまでさらに煮詰め、冷ましながらゆっくり混ぜ、できた結晶を布袋に吊るして数日かけて糖蜜を抜き、乾かして得る。長く運ぶときやきわめて長く備蓄するときに向く。根100kgからシロップが約18-21kgできる |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵した根と種根の点検(2週間に一度、腐ったものを選り出す)、冬の凍結濃縮。2月に堆肥の切り返し、石灰や木灰での酸度矯正 |
| 3-4月 | 3月に耕起と石拾い、春まき(中旬以降)、種根の植え直し。4月に越冬栽培の収穫(花茎が立つ前、糖度が最高)、発芽の確認、1回目の間引き |
| 5-6月 | 5月に2回目の間引き、追肥(窒素はこれが最後)、草取り。6月に土寄せ、葉の収穫開始、採種株の支柱立て |
| 7-8月 | 7月に春まきの収穫(暑さの前)、種子の成熟の観察。8月に穂が茶色く乾いたら採種と種子の乾燥、砂糖の加工 |
| 9-10月 | 9月中旬から秋まきと元肥(時期を逃すと冬を越せない)。10月上旬までに播種を終えて間引き |
| 11-12月 | 11月に越冬の準備(わらマルチ)、収穫分のキュアリングと土室での貯蔵、種根は別に保管。12月に砂糖の加工に集中(ほかの調理の余熱もいっしょに使う)、貯蔵の点検 |

> **テンサイは、窒素を本葉5-6枚で止め、間引きを先送りにせず、南部では秋にまいて越冬させ、種根を必要量の2倍残し、煮詰める前に濃縮して薪を減らす作物です。**
