## 13. 種根の維持と採種

### 13-1. 2年がかりの仕事

&nbsp;&nbsp;&nbsp;テンサイの自家採種の等級はDです。二年生植物で、1年目に根をつくり、2年目に花を咲かせて種子を結ぶからです。種子を採るには、食べられる根を食べずに冬の間生かしておき、翌年の春にもう一度植えなければなりません。この過程を種根の維持と呼びます。ジャガイモの種いもの保管や、キャッサバの挿し穂の越冬と同じ性格の作業であり、テンサイが自立するうえでの唯一のボトルネックです。

| 段階 | 時期 | 内容 |
|---|---|---|
| 1. 種根の選抜 | 収穫期 | 最もまっすぐで健康な根を選びます |
| 2. 種根の貯蔵 | 冬 | 室（むろ）や砂に埋めて、凍らないように越冬させます |
| 3. 再定植 | 翌年の春 | 頭が地面に少し出るように植え直します |
| 4. 抽だい・開花 | 春-初夏 | 花茎が1m以上伸びます |
| 5. 種子の成熟 | 夏 | 穂が茶色く乾くまで置きます |
| 6. 採種と乾燥 | 夏 | 振るい落として採り、日陰で完全に乾かします |
| 7. 保管 | 以後5年 | 密閉、冷涼、暗所 |

### 13-2. 種根の選抜

| 項目 | 基準 | 理由 |
|---|---|---|
| 形 | まっすぐで裂けていないもの | 形質が子孫に伝わります |
| 大きさ | 中程度以上で、大きすぎないもの | 大きすぎるものは貯蔵中に腐りやすいです |
| 糖度 | 切って味見して甘いもの | 1株を切って確認し、残りはその株の周辺から選びます |
| 傷 | ないもの | 傷があると貯蔵中に腐ります |
| 葉の切り方 | 頭から3-5cm長く残します | 食用より長く残して生長点を守ります |
| 細根 | 切りません | 切り口から菌が入ります |
| 数量 | 必要量の2、3倍 | 冬の間に一部は必ず傷みます |

&nbsp;&nbsp;&nbsp;種根として残す根は、葉を長く残して切ります。食用にするものは1-2cmを残しますが、種根は3-5cmを残します。頭の部分にある生長点が傷むと、翌年の春に芽が出なくなるからです。

### 13-3. 種根の貯蔵

| 方式 | 条件 | 方法 |
|---|---|---|
| 室貯蔵 | 0-4℃、湿度90-95% | しっとりした砂や土に立てて埋めます。頭が上になるようにします |
| 穴貯蔵 | 0-5℃ | わら、根、わら、土の順に、塚のように積み、通気口をつくります |
| その場での越冬 | 韓国南部、済州島 | 畑にそのまま置き、わらを厚くかぶせます。最も手間がかかりません |
| 室内の砂箱 | 0-5℃ | 少量に向いています |

&nbsp;&nbsp;&nbsp;韓国南部では、種根を掘り上げず、畑にそのまま置いておく方法が最も確実です。テンサイは氷点下5℃まで耐えるので、わらを20-30cmかぶせておけば、韓国南部の冬はたいてい越せます。掘り上げて貯蔵する過程で生じる傷や損失がまったくないことが、大きな長所です。韓国中部以北では、この方法は危険なので、掘り上げて室に入れなければなりません。

| 貯蔵中の点検 | 内容 |
|---|---|
| 周期 | 2週間に1回 |
| 確認事項 | 軟らかくなったもの、カビ、異臭 |
| 対処 | 傷んだものはすぐに取り出します。一つが隣のものに感染させます |
| 乾燥 | 砂が乾きすぎていたら、水を軽く振りかけます |
| 温度 | 0℃を下回らないようにします |

### 13-4. 再定植と採種

| 項目 | 基準 |
|---|---|
| 時期 | 韓国では3月中旬-4月上旬、地面が解けた後 |
| 植える深さ | 頭が地面に少し出る程度に |
| 間隔 | 50-60cm。花茎が大きく育つので、広めに |
| 支え | 花茎が1m以上に伸びて倒れるので、支柱を立てます |
| 開花 | 5-6月。風で受粉します |
| 隔離 | フダンソウ、ビーツ、ほかのテンサイ品種から遠く離します |
| 成熟 | 穂が茶色く乾くまで置きます |
| 採種 | 穂をしごいて採り、日陰で完全に乾かします |
| 個体数 | 最低10株以上から一緒に採ります |

&nbsp;&nbsp;&nbsp;隔離と個体数の二つが特に重要です。テンサイは風で受粉する他家受粉植物なので、近くでフダンソウやビーツが花を咲かせると交雑して、子孫に思いがけないものが出てきます。商業的には数kmの隔離距離を置きますが、災害時にそこまで離すのは困難です。現実的な代替策は、時期をずらすこと、つまり同じ年には一つの品種だけに花を咲かせ、フダンソウとビーツはその年に採種しない方法です。

&nbsp;&nbsp;&nbsp;個体数が少ないと、数世代で生育が目に見えて悪くなります。他家受粉植物は近親交配に弱いからです。10株以上、できれば20株以上から一緒に種子を採って混ぜておくのが原則です。この一点を守らないと、5年後に播く種子はあっても、まともに育たないという状況になります。

### 13-5. 種子の保管

| 項目 | 基準 |
|---|---|
| 乾燥 | 日陰で完全に乾かします。手で折れるほど |
| 容器 | 密閉容器やガラス瓶 |
| 乾燥剤 | 草木灰、炭、生石灰を布に包んで一緒に入れます |
| 温度 | 涼しく変動の少ない場所 |
| 光 | 完全な暗所 |
| 寿命 | 常温密閉で約5年 |
| 発芽の確認 | 毎年数粒を濡らした布に包んでおき、発芽率を確認します |

> **種子寿命5年は、テンサイの最大の資産です。毎年採種する必要がないという意味であり、これは二年生植物という弱点をほぼ相殺します。ただし、5年目が来る前に、一度は2年がかりの採種をしておかなければなりません。**

## 14. 毒性と注意事項

### 14-1. 根は安全です

&nbsp;&nbsp;&nbsp;テンサイは、一般的な摂取量では安全な食品です。キャッサバのシアン配糖体やジャガイモのソラニンのような毒性物質がありません。生で食べても中毒にならず、子どもに与えても構いません。

| 項目 | 内容 |
|---|---|
| 生食 | 可能です。硬くて土のにおいがするので、加熱したほうがよいです |
| 過剰摂取 | 糖分が多く、おなかをこわすことがあります。毒性ではありません |
| 傷んだ根 | 変色したり異臭がしたりしたら捨てます |
| 緑色に変わった肩 | 苦みがあり、糖度が低いです。切り落とします |
| 芯が黒いもの | ホウ素欠乏です。その部分をくり抜けば、残りは食べられます |

### 14-2. 葉にはやや注意が必要です

| 項目 | 内容 |
|---|---|
| シュウ酸 | フダンソウと同様にシュウ酸が含まれます。ゆでて、そのゆで汁を捨てれば減ります |
| 結石 | 腎臓結石の既往のある人は、たくさん食べません |
| 硝酸塩 | 窒素を多く与えた畑の葉には、硝酸塩がたまります。特に幼児に注意します |
| 処理 | 沸騰した湯で1-2分ゆでて、そのゆで汁を捨てれば、シュウ酸と硝酸塩がともに減ります |
| 家畜への給与 | 葉を急に大量に与えると、牛や羊に問題が生じます。少しずつ増やします |

&nbsp;&nbsp;&nbsp;硝酸塩の問題は、災害時に特に覚えておく価値があります。化学肥料がない代わりに、薄めた尿を頻繁に使うことになりますが、窒素が過剰に入ると、葉に硝酸塩が蓄積します。硝酸塩そのものは大きな問題ではありませんが、体内で亜硝酸塩に変わると、酸素を運ぶ能力を低下させます。幼児にはより危険です。ゆでてそのゆで汁を捨てるだけでかなりの部分が除去されるため、葉は生で食べるより、ゆでて食べるほうが安全です。

### 14-3. 砂糖加工の過程での注意

| 項目 | 内容 |
|---|---|
| 煮立った糖液 | 水より沸点が高く、粘性が大きいため、やけどが深くなります。特に気をつけます |
| 吹きこぼれ | 煮詰める途中で突然沸き上がって吹きこぼれます。鍋の3分の2を超えて満たさないようにします |
| 焦げつき | 濃度が上がると底が焦げ始めます。かき混ぜ続ける必要があります |
| 石灰の使用 | 精製に石灰を使う場合は、目や皮膚に触れないようにします |
| 発酵 | 濃度の低い糖液は数日で発酵します。望まなければ、早く煮詰めます |
| 密閉 | 発酵中の液を密閉すると、容器が破裂します |

## 15. 冷蔵庫なしの貯蔵

### 15-1. 貯蔵の三段階

| 段階 | 条件 | 期間 | 目的 |
|---|---|---|---|
| 1. キュアリング | 10-15℃、湿度85-95%、暗くて弱い通風 | 1-2週間 | 傷口をふさぎ、水分の損失を減らします |
| 2. 本貯蔵 | 0-4℃、湿度85-95%、完全な暗黒 | 3-4か月 | 呼吸を減らし、糖の消耗を遅らせます |
| 3. 点検 | 2週間に1回 | 貯蔵期間中ずっと | 腐った一つが全体をだめにするのを防ぎます |

&nbsp;&nbsp;&nbsp;テンサイの貯蔵で特に覚えておくべきことは、貯蔵中に糖が減るという事実です。根は生きた組織なので、貯蔵中も呼吸しており、その燃料として自分の体に蓄えた糖を使います。温度が高いほど呼吸が速まり、糖が早くなくなります。0-4℃という条件は、凍らせずに呼吸を最大限遅らせられるポイントです。砂糖を目的とするなら、貯蔵期間を短くし、収穫後できるだけ早く加工するほうが有利です。

### 15-2. 無電力貯蔵方式の比較

| 方式 | つくり方 | 温度 | 期間 | 長所 | 短所 |
|---|---|---|---|---|---|
| その場での越冬 | 畑にそのまま置き、わらを20-30cmかぶせます | 地中温度 | 冬の間じゅう | 労働がほとんどなく、糖度が上がります | 韓国中部以北では凍る危険があります |
| 室貯蔵 | 水はけのよい土地を1.5m掘り、屋根と通気口をつくります | 0-4℃ | 3-4か月 | 最も安定しています | 掘る労働が大きいです |
| 穴・クランプ | 30cm掘り、わら、根、わら、土の順に積みます | 0-5℃ | 2-3か月 | 1日でつくれます | 一度開けると、また覆うのが難しいです |
| 砂層貯蔵 | 箱に乾いた砂と根を交互に入れます | 周囲温度 | 1-2か月 | 腐敗の伝染を防ぎます | 涼しい場所が別に必要です |
| わら・もみ殻断熱 | 涼しい室内に、わらで包んで積みます | 5-10℃ | 1か月 | 施設が要りません | 温度が高いと芽が出ます |

### 15-3. 穴貯蔵のつくり方

| 順序 | 内容 |
|---|---|
| 1 | 水がたまらない高い場所を選びます。北向きの斜面がよいです |
| 2 | 直径1.5m、深さ20-30cmで浅く掘ります |
| 3 | 底に乾いたわらを10cm敷きます |
| 4 | キュアリングを終えた根を、塚の形に積みます。高さ60cm以内 |
| 5 | 乾いたわらで全体を20-30cm覆います |
| 6 | その上に土を15-20cmかぶせ、表面を叩いて雨水が流れるようにします |
| 7 | 頂上にわらを一束立てて通気口をつくります。ふさぐと中で腐ります |
| 8 | 周囲に排水溝を掘ります |

&nbsp;&nbsp;&nbsp;通気口が要です。根は貯蔵中も呼吸しており、熱と水蒸気と二酸化炭素を出します。完全に密閉すると、中で温度が上がり、湿気がこもって、数日で全体が軟化します。頂上のわら束は、空気を通しながら雨水は防ぐ構造です。

### 15-4. 貯蔵条件の詳細

| 条件 | 目標 | 外れたとき |
|---|---|---|
| 温度 | 0-4℃ | 氷点下では凍って軟化します。8℃以上では芽が出て、糖が急速に減ります |
| 湿度 | 85-95% | 低いとしなび、高いとカビが生えます |
| 光 | 完全な暗黒 | 光を受けると頭が緑色に変わります |
| 通風 | 弱く持続的に | ふさぐと熱と湿気がこもり、強すぎると乾きます |
| 葉 | 1-2cm残して切ります | 長いと伸びて糖を消費し、短いと頭から腐敗が入ります |
| 点検 | 2週間に1回 | 腐った一つが周りを急速に感染させます |

### 15-5. 加工による超長期貯蔵

| 方法 | 手順 | 期間 | 備考 |
|---|---|---|---|
| シロップ | 汁を搾って煮詰めます | 1年以上 | 最も実用的です。第16節で詳しく扱います |
| 結晶砂糖 | シロップをさらに煮詰めて結晶をつくります | 数年 | 燃料が多くかかりますが、保管が最も簡単です |
| 乾燥片 | 薄く切って完全に乾かします | 6か月-1年 | 水で戻して使うか、そのままかんで食べます |
| 乳酸発酵 | 2-3%の塩水に漬け、室温で1-2週間 | 数か月 | おかずになります |
| 酢 | 汁を発酵させて酒をつくり、さらに酢酸発酵させます | 数年 | ほかの食品の保存手段になります |
| 酒 | 汁をそのまま発酵させます | 数か月 | 熱量の保存と消毒用を兼ねます |

> **テンサイを長く保管する最も確実な方法は、根を守ることではなく、シロップに変えることです。根は4か月ですが、シロップは年を越します。**
