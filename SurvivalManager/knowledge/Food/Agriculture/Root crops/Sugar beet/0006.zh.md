## 16. 糖的提取与烹饪

### 16-1. 作为食物食用时

| 方法 | 燃料消耗 | 步骤 | 备注 |
|---|:---:|---|---|
| 煮 | 中等 | 带皮放入水中煮30-40分钟 | 煮熟后，皮可以用手剥掉 |
| 蒸 | 少 | 放入少量水，蒸35-45分钟 | 糖不会流失到水里 |
| 切碎煮 | 少 | 切成1-2cm，煮15-20分钟 | 放入汤或粥中 |
| 余热烹饪 | 很少 | 煮沸15分钟后熄火，用布包好放置1小时 | 把燃料消耗降到一半以下 |
| 埋灰烤 | 很少 | 埋进热灰中40-50分钟 | 甜味更浓 |
| 干片 | 少 | 用水泡发后直接使用 | 事先晒干备好，每顿饭都能省燃料 |
| 叶 | 很少 | 在沸水中焯1-2分钟 | 焯过的水要倒掉 |

&nbsp;&nbsp;&nbsp;蒸比煮更好的原因，在甜菜上尤其明显。根中的糖很容易溶于水，煮的时候，其中相当一部分糖会流失到水里。如果把煮过的水当作汤汁一起食用就无妨，但要是倒掉，就等于把甜味和热量一起扔掉了。蒸则没有这种损失。

### 16-2. 糖是如何得到的

&nbsp;&nbsp;&nbsp;甜菜的根重量的14-20%是蔗糖，也就是糖本身。其余大部分是水，一部分是纤维。因此，提取糖并不是化学转化，而是物理分离。从细胞中取出糖，蒸发掉其中的水，再让剩下的部分凝固，这三步就是全部。这是它与必须把淀粉转化为糖的谷物和马铃薯的根本区别。

| 步骤 | 工作内容 | 难点 |
|---|---|---|
| 1. 切丝 | 打开细胞，为糖的流出开辟通道 | 容易 |
| 2. 提取 | 用水把糖引出来 | 需要控制温度 |
| 3. 压榨 | 榨出剩余的汁液 | 费力 |
| 4. 澄清 | 除去杂质 | 需要材料 |
| 5. 熬煮 | 蒸发水分 | 最耗燃料 |
| 6. 结晶 | 让糖凝固 | 需要技术和时间 |
| 7. 分离糖蜜 | 把结晶与剩下的液体分开 | 需要工具 |

### 16-3. 切丝与提取

| 项目 | 标准 | 理由 |
|---|---|---|
| 处理 | 洗净泥土，切去绿色的肩部和须根 | 它们是苦味和土腥味的来源 |
| 皮 | 薄薄削去一层，或者直接带皮使用 | 削皮后汁液更清，不削皮则得率更高 |
| 切丝粗细 | 厚2-3mm的细丝 | 越细，糖出得越快 |
| 提取用水温度 | 70-75度 | 最重要的数字 |
| 提取时间 | 40分钟-1小时 | 直到丝变软、水变甜为止 |
| 水量 | 刚好没过丝即可 | 水多了，之后要蒸发的水就增多 |
| 搅拌 | 偶尔搅拌 | 浸出均匀 |

&nbsp;&nbsp;&nbsp;70-75℃这个温度并不是随意定下的。在这个温度下，细胞膜发生变性，糖可以自由渗出，而组织本身还不会崩解。超过80℃，果胶会溶出，使汁液变得黏稠而无法过滤。低于60℃，细胞膜原样保留，糖不容易出来，而且杂菌还会繁殖。如果没有温度计，水面冒出热气但尚未沸腾、手指伸进去觉得烫、很快就要抽出来的程度，就在这个温度附近。绝对不能煮沸。

> **用来提取糖的水不能煮沸。煮沸后汁液会变得黏稠而无法过滤，颜色和气味也会变差。**

### 16-4. 节水的逆流提取

&nbsp;&nbsp;&nbsp;这里就出现了能够大幅节省燃料的诀窍。往刚切好的丝上浇清水，会得到稀薄的汁液，而这些稀汁里的水之后必须全部蒸发掉。如果改用上一批得到的汁液作为下一批的提取液，浓度就会不断升高。

| 顺序 | 内容 |
|---|---|
| 1 | 第一批用清水提取，得到稀薄的汁液 |
| 2 | 不要倒掉这些汁液，而是浇到下一批新切的丝上，再次加热到70-75℃ |
| 3 | 同一份汁液重复使用三到四次 |
| 4 | 批次越多，汁液越浓 |
| 5 | 浓度足够时，只熬煮这份汁液 |
| 6 | 最后剩下的丝，再用新水冲洗一次，这些水用于下一轮的第一批 |

&nbsp;&nbsp;&nbsp;这种方式与工业流程的原理相同。在得到同样数量的糖的同时，需要蒸发的水量可以减少到一半以下，柴火也相应地少用。既不需要增加工具，只是改变一下顺序，所以是灾害情境下必须采用的诀窍。

### 16-5. 压榨与残渣处理

| 项目 | 内容 |
|---|---|
| 压榨 | 把提取完的丝用布包好，用力挤压。用杠杆或石头压也可以 |
| 回收 | 能挤出相当多的残余汁液。省略的话损失很大 |
| 残渣 | 残留纤维和残糖 |
| 家畜饲料 | 牛、猪、鸡都爱吃。是很好的饲料 |
| 堆肥 | 如果不用作饲料，就还田 |
| 发酵 | 经乳酸发酵后，可以作为冬季饲料保存 |

### 16-6. 澄清——除去杂质

&nbsp;&nbsp;&nbsp;榨出的汁液中，除了糖，还混有蛋白质、果胶、有机酸、泥土和色素。如果不除去这些东西，糖浆就会又黑又苦，也不容易结晶。家庭中可以使用的方法有三种。

| 方法 | 步骤 | 效果 | 材料来源 |
|---|---|---|---|
| 撇去泡沫 | 熬煮全程，用勺子撇去浮在表面的褐色泡沫 | 是基本且必需的做法 | 不需要 |
| 石灰处理 | 溶入少量熟石灰以提高pH值，加热后让其沉淀再滤除 | 效果最大 | 把贝壳或牡蛎壳用大火烧成生石灰，加水浸泡就成了熟石灰 |
| 蛋清 | 把蛋清搅入冷汁液，慢慢加热，蛋清凝固时会裹住杂质浮上来。把它撇去 | 中等 | 需要有鸡蛋 |
| 布过滤 | 用细布多次过滤 | 去除泥土和残渣 | 不需要 |
| 草木灰水 | 使用少量草木灰浸水后得到的澄清上层液 | 起辅助作用 | 容易获得 |

&nbsp;&nbsp;&nbsp;石灰处理是工业流程的核心，在家庭中也可以进行。把贝壳或牡蛎壳放进柴火中烧得通红，就成了生石灰，往上面浇水，它会放出热量并变成熟石灰。把它溶于水，只取澄清的上层液，一点一点加入汁液中，蛋白质和果胶就会絮凝并沉淀。不过加入的量过多，会残留苦味和肥皂味，所以要一点一点地加，边加边观察状态。加入石灰后，用管子把炭火的烟引入液体中通过，就会生成碳酸钙，裹住杂质一起沉淀，这就是工业流程中的碳酸化阶段。

| 注意 | 内容 |
|---|---|
| 草木灰水过量 | 钾盐残留，妨碍结晶。只用少量 |
| 石灰过量 | 残留苦味和异味 |
| 处理生石灰 | 遇水会发热。不要让它接触眼睛和皮肤 |
| 局限 | 在家庭条件下很难做出完全洁白的白糖。土腥味和颜色会多少残留一些 |

### 16-7. 熬煮——最耗燃料的阶段

| 项目 | 内容 |
|---|---|
| 工具 | 浅而宽的锅或釜。表面积越大，蒸发越快 |
| 锅盖 | 敞开着。目的就是蒸发 |
| 火力 | 开始时用大火，变稠后用小火 |
| 搅拌 | 浓度升高后要不停搅拌。否则锅底会糊 |
| 装入量 | 不超过锅的2/3。否则会突然沸腾溢出 |
| 泡沫 | 持续撇去 |
| 糖浆完成 | 从勺子上呈丝状拉长滴落。糖度约70% |
| 防烫伤 | 沸腾的糖液比水更烫且黏性大，烫伤很深 |

#### 燃料计算

| 项目 | 数值 |
|---|:---|
| 把1L水烧开并蒸发掉所需的热量 | 约620kcal（加热80 + 蒸发540） |
| 干柴的热值 | 每1kg约3,500-4,000kcal |
| 敞口灶的热效率 | 5-15% |
| 1kg柴火实际可用的热量 | 约175-600kcal |
| 蒸发1L水所需的柴火 | 约1-3.5kg |
| 得到1kg糖需要蒸发的水 | 约4.5-5L |
| 每1kg糖所需的柴火 | 约5-15kg |

&nbsp;&nbsp;&nbsp;这张表就是甜菜加工的现实。1kg糖要用5-15kg柴火。想一想整个冬季取暖和做饭所用的柴火，这绝不是一个小数目。所以节省燃料的方法与加工步骤同样重要。

| 节约方法 | 内容 |
|---|---|
| 逆流提取 | 把需要蒸发的水量本身减少一半。效果最大 |
| 浅而宽的容器 | 蒸发面积越大，同样的热量能蒸发得越多 |
| 挡风 | 用石头或泥土围住灶的四周，减少热量散失 |
| 多个锅 | 并排放在同一堆火上，同时熬煮 |
| 利用其他烹饪的余热 | 做完饭后，继续把锅放在剩下的火上 |
| 阳光预浓缩 | 把汁液倒入浅而黑的容器，盖上布，放在阳光下。几天内会自然变浓 |
| 冷冻浓缩 | 参见下一节 |

### 16-8. 不用燃料的浓缩方法——冷冻浓缩

&nbsp;&nbsp;&nbsp;这是冬季可以使用的方法，完全不用柴火。原理很简单。糖水结冰时，先结冰的是纯水，糖留在没有结冰的液体里。因此把冰捞出来，剩下液体的糖浓度就升高了。

| 顺序 | 内容 |
|---|---|
| 1 | 把汁液倒入浅而宽的容器 |
| 2 | 在零下的夜晚放到室外 |
| 3 | 表面和边缘会结冰。这几乎是纯水 |
| 4 | 早晨把冰捞出丢掉 |
| 5 | 剩下的液体已经变得更浓 |
| 6 | 连续重复好几个夜晚 |

| 项目 | 内容 |
|---|---|
| 优点 | 完全不需要燃料 |
| 局限 | 浓度越高，冰点越低，最后不再结冰。大约只能浓缩到一半左右 |
| 之后 | 之后改用火熬煮。需要蒸发的水已大大减少 |
| 条件 | 只有在连续多日夜晚温度在零下的地区才能采用 |
| 注意 | 捞出的冰中也残留少量糖。融化后用作下一批的提取用水 |

> **如果在有冬季的地区加工甜菜，那么秋季收获、榨汁，在冬夜冷冻浓缩，再到春天熬煮，这种方式用的燃料最少。**

### 16-9. 结晶与糖蜜分离

| 顺序 | 内容 |
|---|---|
| 1 | 把糖浆继续熬浓。用勺子舀起滴入冷水，凝成柔软团块的程度 |
| 2 | 离火，连容器一起放在阴凉处 |
| 3 | 如果已有做好的糖，撒几粒进去。它们会成为结晶的晶种 |
| 4 | 冷却期间缓慢搅拌。结晶会均匀长大 |
| 5 | 数小时到数日内会形成结晶 |
| 6 | 把结晶和液体装入布袋吊起来。几天内糖蜜会渗出 |
| 7 | 压榨的话渗出更快，但结晶也会一起被压碎 |
| 8 | 把剩下的结晶摊开，完全晾干 |

| 产物 | 性质与用途 |
|---|---|
| 结晶糖 | 带褐色。最容易保存，体积小 |
| 糖蜜 | 黑而浓稠的糖浆。还残留20-30%的糖 |
| 糖蜜的用途 | 调味、家畜饲料、酿酒和制醋的原料、酵母培养 |

### 16-10. 做到结晶，还是停在糖浆

| 比较 | 糖浆 | 结晶糖 |
|---|---|---|
| 额外燃料 | 不需要 | 需要继续熬煮 |
| 技术 | 容易 | 需要控制温度和冷却 |
| 工具 | 有口锅就行 | 需要袋子、过滤架和时间 |
| 损失 | 没有 | 有20-30%的糖随糖蜜流失 |
| 保存 | 密封后1年以上 | 数年 |
| 体积与重量 | 大 | 小 |
| 用途 | 调味增甜、腌渍、保存、发酵都可以 | 相同 |

&nbsp;&nbsp;&nbsp;灾害情境下的答案，大体上是糖浆。糖浆同样可以用来增甜、腌渍水果、保存和发酵，没有损失，对技术和工具的要求也更低。结晶糖有利的情况，是需要长途搬运，或者需要储备很长时间的时候。不过糖浆的糖度一旦降到60-65%以下，就会发酵或长霉，所以必须充分熬煮，把糖度提高到70%左右。

### 16-11. 得率与甜味料的用途

| 原料 | 产物 |
|---|---|
| 甜菜100kg | 汁液70-80L，糖12-15kg |
| 这些汁液 | 约18-21kg糖浆（糖度70%） |
| 这些糖浆 | 8-12kg结晶糖和5-8kg糖蜜 |
| 残渣 | 家畜饲料或堆肥 |

| 用途 | 内容 |
|---|---|
| 热量 | 是吸收最快的热量来源 |
| 保存 | 糖度60%以上时，细菌和霉菌无法生长。可用于腌渍水果和做果酱 |
| 发酵 | 可作为酿酒和制醋的原料。醋又是保存其他食品的手段 |
| 士气 | 在饥饿的处境中，甜味是任何其他东西都无法替代的慰藉 |
| 交换 | 在物流中断的情况下，甜味料的交换价值很高 |

## 17. 全年作业日程

| 月份（韩国） | 作业 | 要点 |
|---|---|---|
| 1月 | 检查贮藏的根，检查种根，冬季冷冻浓缩 | 每2周一次，挑出腐烂的 |
| 2月 | 制订田间计划，翻堆堆肥，用石灰或草木灰调节酸度 | 甜菜喜欢中性土壤 |

| 5月 | 第2次间苗，追肥（氮肥以这次为最后一次），除草 | 真叶5-6片之后停施氮肥 |
| 6月 | 培土，开始收叶，留种株的开花管理 | 给留种株立支柱 |
| 7月 | 收获春播的甜菜，观察种子成熟 | 在暑热到来之前挖收 |
| 8月 | 留种与种子晾干，制糖加工 | 穗变成褐色干枯后，把种子撸下来 |
| 9月 | 秋播（从中旬起），基肥 | 错过时机就无法越冬 |
| 10月 | 秋播收尾，间苗 | 最晚到上旬 |
| 11月 | 越冬准备，稻草覆盖，收获部分的愈伤处理与窖藏 | 种根要单独做标记保存 |
| 12月 | 集中制糖加工，检查贮藏 | 同时利用其他烹饪的余热 |

### 17-1. 不可忘记的五件事

| 项目 | 内容 |
|---|---|
| 氮肥只施到真叶6片 | 此后施的氮肥只会让叶片生长，糖分却会减少 |
| 间苗不要拖延 | 因为是多胚种子，会同时长出多个芽。不间苗的话，全都会长得很小 |
| 越冬栽培更有利 | 在韩国南部，秋季播种、翌年春季挖收，糖度和产量都能达到最高 |
| 种根留双倍 | 冬季里一部分一定会烂掉。留种需要10株以上 |
| 熬煮前先浓缩 | 用逆流提取和冷冻浓缩减少需要蒸发的水，柴火用量就能减半 |
