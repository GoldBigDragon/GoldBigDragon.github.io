## 16. 설탕 추출과 조리

### 16-1. 식용으로 먹을 때

| 방법 | 연료 소모 | 절차 | 비고 |
|---|:---:|---|---|
| 삶기 | 중간 | 껍질째 물에 넣고 30-40분 | 껍질은 익힌 뒤 손으로 벗겨집니다 |
| 찌기 | 적음 | 물을 조금 넣고 35-45분 | 당이 물에 빠져나가지 않습니다 |
| 잘게 썰어 삶기 | 적음 | 1-2cm로 썰면 15-20분 | 국이나 죽에 넣습니다 |
| 잔열 조리 | 매우 적음 | 15분 끓인 뒤 불을 끄고 천으로 감싸 1시간 | 연료를 절반 이하로 줄입니다 |
| 재 속 굽기 | 매우 적음 | 뜨거운 재에 묻어 40-50분 | 단맛이 진해집니다 |
| 말린 조각 | 적음 | 물에 불려 바로 씁니다 | 미리 말려 두면 끼니마다 연료를 아낍니다 |
| 잎 | 매우 적음 | 끓는 물에 1-2분 데칩니다 | 데친 물은 버립니다 |

&nbsp;&nbsp;&nbsp;삶는 것보다 찌는 편이 나은 이유가 사탕무에서는 특히 분명합니다. 뿌리의 당이 물에 잘 녹기 때문에 삶으면 그 당의 상당 부분이 물로 빠져나갑니다. 삶은 물을 국물로 함께 쓴다면 상관없지만 버린다면 단맛과 열량을 함께 버리는 셈입니다. 찌면 그 손실이 없습니다.

### 16-2. 설탕은 어떻게 나오는가

&nbsp;&nbsp;&nbsp;사탕무의 뿌리는 무게의 14-20%가 자당, 즉 설탕 그 자체입니다. 나머지의 대부분은 물이고 일부가 섬유질입니다. 그러므로 설탕을 얻는 일은 화학적 변환이 아니라 물리적 분리입니다. 세포에서 당을 꺼내고, 그 물을 날리고, 남은 것을 굳히는 세 가지가 전부입니다. 전분을 당으로 바꿔야 하는 곡물이나 감자와 결정적으로 다른 점입니다.

| 단계 | 하는 일 | 어려움 |
|---|---|---|
| 1. 썰기 | 세포를 열어 당이 나올 통로를 만듭니다 | 쉽습니다 |
| 2. 추출 | 물로 당을 끌어냅니다 | 온도 관리가 필요합니다 |
| 3. 압착 | 남은 즙을 짜냅니다 | 힘이 듭니다 |
| 4. 청징 | 불순물을 걷어 냅니다 | 재료가 필요합니다 |
| 5. 졸이기 | 물을 날립니다 | 연료를 가장 많이 먹습니다 |
| 6. 결정화 | 설탕을 굳힙니다 | 기술과 시간이 필요합니다 |
| 7. 당밀 분리 | 결정과 남은 액을 나눕니다 | 도구가 필요합니다 |

### 16-3. 썰기와 추출

| 항목 | 기준 | 이유 |
|---|---|---|
| 손질 | 흙을 씻고 녹색 어깨와 잔뿌리를 잘라 냅니다 | 쓴맛과 흙내의 원인입니다 |
| 껍질 | 얇게 벗기거나 그대로 씁니다 | 벗기면 맑아지고 안 벗기면 수율이 올라갑니다 |
| 써는 굵기 | 2-3mm 두께의 얇은 채 | 얇을수록 당이 빨리 나옵니다 |
| 추출 물 온도 | 70-75도 | 가장 중요한 숫자입니다 |
| 추출 시간 | 40분-1시간 | 채가 물러지고 물이 달아질 때까지 |
| 물의 양 | 채가 잠길 정도로만 | 물이 많으면 나중에 날릴 물이 늘어납니다 |
| 젓기 | 가끔 저어 줍니다 | 고르게 우러납니다 |

&nbsp;&nbsp;&nbsp;70-75℃라는 온도는 우연히 정해진 것이 아닙니다. 이 온도에서 세포막이 변성되어 당이 자유롭게 빠져나오지만, 조직 자체는 아직 무너지지 않습니다. 80℃를 넘으면 펙틴이 녹아 나와 즙이 끈적해지고 걸러지지 않습니다. 60℃ 아래에서는 세포막이 그대로 남아 당이 잘 나오지 않고 게다가 잡균이 번식합니다. 온도계가 없다면 물에서 김이 오르되 아직 끓지 않는 상태, 손가락을 담그면 뜨거워서 곧 빼게 되는 정도가 그 근처입니다. 끓이면 안 됩니다.

> **당을 끌어내는 물은 끓이지 않습니다. 끓이면 즙이 끈적해져 걸러지지 않고, 색과 냄새도 나빠집니다.**

### 16-4. 물을 아끼는 향류 추출

&nbsp;&nbsp;&nbsp;여기서 연료를 결정적으로 아낄 수 있는 요령이 나옵니다. 갓 썬 채에 맹물을 부으면 묽은 즙이 나오고, 그 묽은 즙의 물을 나중에 전부 날려야 합니다. 대신 앞 회차에서 나온 즙을 다음 회차의 추출액으로 쓰면 농도가 계속 올라갑니다.

| 순서 | 내용 |
|---|---|
| 1 | 첫 회차는 맹물로 추출합니다. 묽은 즙이 나옵니다 |
| 2 | 그 즙을 버리지 않고 다음 회차의 새 채에 부어 다시 70-75℃로 데웁니다 |
| 3 | 같은 즙으로 세 번에서 네 번까지 반복합니다 |
| 4 | 회차가 거듭될수록 즙이 진해집니다 |
| 5 | 충분히 진해지면 그것만 졸입니다 |
| 6 | 마지막에 남은 채는 새 물로 한 번 더 헹궈 그 물을 다음 첫 회차에 씁니다 |

&nbsp;&nbsp;&nbsp;이 방식이 산업 공정의 원리와 같습니다. 같은 양의 설탕을 얻으면서 날려야 할 물의 양을 절반 이하로 줄일 수 있고, 그만큼 장작이 덜 듭니다. 도구가 늘어나는 것도 아니고 그저 순서를 바꾸는 것뿐이므로, 재난 상황에서 반드시 적용해야 할 요령입니다.

### 16-5. 압착과 찌꺼기 처리

| 항목 | 내용 |
|---|---|
| 압착 | 추출을 마친 채를 천에 싸서 힘껏 짭니다. 지렛대나 돌로 눌러도 됩니다 |
| 회수 | 남은 즙의 상당량이 나옵니다. 생략하면 손실이 큽니다 |
| 찌꺼기 | 섬유질과 잔당이 남아 있습니다 |
| 가축 사료 | 소, 돼지, 닭 모두 잘 먹습니다. 훌륭한 사료가 됩니다 |
| 퇴비 | 사료로 쓰지 않는다면 밭에 되돌립니다 |
| 발효 | 젖산발효시키면 겨울 사료로 보관할 수 있습니다 |

### 16-6. 청징 - 불순물 걷어 내기

&nbsp;&nbsp;&nbsp;짜낸 즙에는 당 외에 단백질, 펙틴, 유기산, 흙, 색소가 섞여 있습니다. 이것들을 걷어 내지 않으면 시럽이 검고 쓰며, 결정이 잘 생기지 않습니다. 가정에서 쓸 수 있는 방법은 셋입니다.

| 방법 | 절차 | 효과 | 재료 확보 |
|---|---|---|---|
| 거품 걷어 내기 | 졸이는 내내 표면에 뜨는 갈색 거품을 국자로 걷어 냅니다 | 기본이자 필수입니다 | 필요 없음 |
| 석회 처리 | 소석회를 소량 풀어 pH를 올리고 데운 뒤 가라앉혀 걸러 냅니다 | 가장 효과가 큽니다 | 조개껍데기나 굴껍데기를 세게 구워 생석회를 만들고 물에 재우면 소석회가 됩니다 |
| 달걀 흰자 | 찬 즙에 흰자를 풀어 넣고 서서히 데우면 흰자가 굳으면서 불순물을 껴안고 떠오릅니다. 걷어 냅니다 | 중간 | 달걀이 있어야 합니다 |
| 천 여과 | 고운 천에 여러 번 거릅니다 | 흙과 찌꺼기 제거 | 필요 없음 |
| 재 잿물 | 나무재를 물에 우린 맑은 윗물을 소량 씁니다 | 보조적입니다 | 손쉽습니다 |

&nbsp;&nbsp;&nbsp;석회 처리는 산업 공정의 핵심이며 가정에서도 가능합니다. 조개껍데기나 굴껍데기를 장작불 속에서 벌겋게 달구면 생석회가 되고, 여기에 물을 부으면 열을 내며 소석회로 변합니다. 이것을 물에 풀어 맑은 윗물만 받아 즙에 조금씩 넣으면 단백질과 펙틴이 엉겨 붙어 가라앉습니다. 다만 넣는 양이 지나치면 쓴맛과 비누 맛이 남으므로 소량씩 넣으며 상태를 봅니다. 석회를 넣은 뒤 숯불의 연기를 관으로 끌어 액 속에 통과시키면 탄산칼슘이 생겨 불순물을 껴안고 가라앉는데, 이것이 산업 공정의 탄산화 단계입니다.

| 주의 | 내용 |
|---|---|
| 재 잿물 과다 | 칼륨염이 남아 결정화를 방해합니다. 소량만 씁니다 |
| 석회 과다 | 쓴맛과 이취가 남습니다 |
| 생석회 취급 | 물과 만나면 뜨거워집니다. 눈과 피부에 닿지 않게 합니다 |
| 한계 | 가정에서 완전한 백설탕은 만들기 어렵습니다. 흙내와 색이 어느 정도 남습니다 |

### 16-7. 졸이기 - 연료를 가장 많이 먹는 단계

| 항목 | 내용 |
|---|---|
| 도구 | 얕고 넓은 냄비나 솥. 표면적이 넓을수록 빨리 증발합니다 |
| 뚜껑 | 열어 둡니다. 증발이 목적입니다 |
| 불 | 처음에는 세게, 걸쭉해지면 약하게 |
| 젓기 | 농도가 오르면 계속 저어야 합니다. 바닥이 탑니다 |
| 채우는 양 | 냄비의 3분의 2를 넘기지 않습니다. 갑자기 끓어 넘칩니다 |
| 거품 | 계속 걷어 냅니다 |
| 시럽 완성 | 숟가락에서 실처럼 늘어지며 떨어집니다. 당도 약 70% |
| 화상 주의 | 끓는 당액은 물보다 뜨겁고 점성이 커서 화상이 깊습니다 |

#### 연료 계산

| 항목 | 수치 |
|---|:---|
| 물 1L를 끓여 날리는 데 필요한 열 | 약 620kcal(가열 80 + 증발 540) |
| 마른 장작의 열량 | 1kg당 약 3,500-4,000kcal |
| 개방 화덕의 열효율 | 5-15% |
| 장작 1kg으로 실제 쓸 수 있는 열 | 약 175-600kcal |
| 물 1L를 날리는 데 드는 장작 | 약 1-3.5kg |
| 설탕 1kg을 얻는 데 날려야 할 물 | 약 4.5-5L |
| 설탕 1kg당 장작 | 약 5-15kg |

&nbsp;&nbsp;&nbsp;이 표가 사탕무 가공의 현실입니다. 설탕 1kg에 장작 5-15kg. 겨울 한 철 난방과 취사에 쓸 장작을 생각하면 결코 가볍지 않은 양입니다. 그래서 연료를 아끼는 방법이 절차만큼 중요합니다.

| 절약 방법 | 내용 |
|---|---|
| 향류 추출 | 날릴 물의 양 자체를 절반으로 줄입니다. 가장 효과가 큽니다 |
| 얕고 넓은 그릇 | 증발 면적이 넓으면 같은 열로 더 많이 날립니다 |
| 바람 막기 | 화덕 둘레를 돌이나 흙으로 막아 열이 새는 것을 줄입니다 |
| 냄비 여러 개 | 한 불 위에 나란히 올려 동시에 졸입니다 |
| 다른 조리의 잔열 | 밥을 짓고 남은 불에 계속 올려 둡니다 |
| 햇볕 예비 농축 | 얕은 검은 그릇에 즙을 붓고 천을 덮어 볕에 둡니다. 며칠에 걸쳐 저절로 진해집니다 |
| 동결 농축 | 아래 항목을 참고합니다 |

### 16-8. 연료 없이 농축하는 법 - 동결 농축

&nbsp;&nbsp;&nbsp;겨울에 쓸 수 있는 방법이며 장작을 전혀 쓰지 않습니다. 원리는 단순합니다. 설탕물이 얼 때 먼저 어는 것은 순수한 물이고, 당은 얼지 않은 액체 쪽에 남습니다. 그러므로 얼음을 걷어 내면 남은 액의 당 농도가 올라갑니다.

| 순서 | 내용 |
|---|---|
| 1 | 즙을 얕고 넓은 그릇에 붓습니다 |
| 2 | 영하의 밤 동안 밖에 내놓습니다 |
| 3 | 표면과 가장자리에 얼음이 생깁니다. 이것은 거의 순수한 물입니다 |
| 4 | 아침에 얼음을 걷어 버립니다 |
| 5 | 남은 액은 더 진해져 있습니다 |
| 6 | 여러 밤 반복합니다 |

| 항목 | 내용 |
|---|---|
| 장점 | 연료가 전혀 들지 않습니다 |
| 한계 | 농도가 올라갈수록 어는점이 내려가 더 이상 얼지 않습니다. 대략 절반 정도까지 |
| 이후 | 그 뒤부터는 불로 졸입니다. 날릴 물이 크게 줄어 있습니다 |
| 조건 | 영하의 밤이 여러 날 이어지는 지역에서만 가능합니다 |
| 주의 | 걷어 낸 얼음에도 약간의 당이 남아 있습니다. 녹여서 다음 회차 추출수로 씁니다 |

> **겨울이 있는 지역에서 사탕무를 가공한다면, 수확은 가을에 하고 즙을 내어 겨울밤에 얼려 농축한 다음 봄에 졸이는 방식이 연료를 가장 적게 씁니다.**

### 16-9. 결정화와 당밀 분리

| 순서 | 내용 |
|---|---|
| 1 | 시럽을 더 졸입니다. 숟가락으로 떠 찬물에 떨어뜨렸을 때 말랑한 덩어리로 뭉치는 정도 |
| 2 | 불에서 내려 그릇째 서늘한 곳에 둡니다 |
| 3 | 이미 만든 설탕이 있다면 몇 알을 뿌립니다. 결정의 씨가 됩니다 |
| 4 | 식는 동안 천천히 저어 줍니다. 결정이 고르게 자랍니다 |
| 5 | 몇 시간에서 며칠에 걸쳐 결정이 생깁니다 |
| 6 | 결정과 액을 천 자루에 담아 매답니다. 며칠에 걸쳐 당밀이 빠져나옵니다 |
| 7 | 눌러 짜면 더 빨리 빠지지만 결정도 함께 부서집니다 |
| 8 | 남은 결정을 넓게 펴 완전히 말립니다 |

| 산물 | 성질과 쓰임 |
|---|---|
| 결정 설탕 | 갈색빛이 돕니다. 보관이 가장 쉽고 부피가 작습니다 |
| 당밀 | 검고 진한 시럽입니다. 당이 20-30% 남아 있습니다 |
| 당밀의 쓰임 | 조미, 가축 사료, 술과 식초의 원료, 효모 배양 |

### 16-10. 결정까지 갈 것인가, 시럽에서 멈출 것인가

| 비교 | 시럽 | 결정 설탕 |
|---|---|---|
| 추가 연료 | 없음 | 더 졸여야 합니다 |
| 기술 | 쉽습니다 | 온도와 냉각 관리가 필요합니다 |
| 도구 | 냄비면 됩니다 | 자루, 거름틀, 시간이 필요합니다 |
| 손실 | 없습니다 | 당의 20-30%가 당밀로 빠집니다 |
| 보관 | 밀폐하면 1년 이상 | 몇 해 |
| 부피와 무게 | 큽니다 | 작습니다 |
| 용도 | 감미, 절임, 보존, 발효 모두 가능 | 같습니다 |

&nbsp;&nbsp;&nbsp;재난 상황에서의 답은 대체로 시럽입니다. 시럽으로도 감미, 과일 절임, 보존, 발효가 전부 가능하고 손실이 없으며 기술도 도구도 덜 듭니다. 결정 설탕이 유리한 경우는 오래 옮겨야 하거나 아주 오래 비축해야 할 때입니다. 다만 시럽은 당도가 60-65% 아래로 내려가면 발효하거나 곰팡이가 피므로, 충분히 졸여 70% 근처까지 올려 두어야 합니다.

### 16-11. 수율과 감미료의 쓰임

| 원료 | 산물 |
|---|---|
| 사탕무 100kg | 즙 70-80L, 당 12-15kg |
| 그 즙 | 시럽 약 18-21kg(당도 70%) |
| 그 시럽 | 결정 설탕 8-12kg과 당밀 5-8kg |
| 찌꺼기 | 가축 사료 또는 퇴비 |

| 쓰임 | 내용 |
|---|---|
| 열량 | 가장 빠르게 흡수되는 열량원입니다 |
| 보존 | 당도 60% 이상에서 세균과 곰팡이가 자라지 못합니다. 과일 절임과 잼 |
| 발효 | 술과 식초의 원료가 됩니다. 식초는 다시 다른 식품의 보존 수단입니다 |
| 사기 | 굶주린 상황에서 단맛은 다른 무엇으로도 대체되지 않는 위안입니다 |
| 교환 | 물류가 끊긴 상황에서 감미료는 교환 가치가 높습니다 |

## 17. 연간 작업 일정

| 월 | 작업 | 요점 |
|---|---|---|
| 1월 | 저장 뿌리 점검, 종근 점검, 겨울 동결 농축 | 2주에 한 번 썩은 것을 골라냅니다 |
| 2월 | 밭 계획, 퇴비 뒤집기, 석회나 나무재로 산도 교정 | 사탕무는 중성을 좋아합니다 |
| 3월 | 밭 갈이와 돌 골라내기, 봄 파종(중순 이후), 종근 재정식 | 깊이 갈수록 뿌리가 곧습니다 |
| 4월 | 월동 재배 수확(당도 최고), 발아 확인, 1차 솎음 | 꽃대가 오르기 전에 캡니다 |
| 5월 | 2차 솎음, 웃거름(질소는 이때가 마지막), 김매기 | 본잎 5-6매 이후 질소를 끊습니다 |
| 6월 | 북주기, 잎 수확 시작, 채종 포기 개화 관리 | 채종 포기는 지주를 세웁니다 |
| 7월 | 봄 파종 수확, 종자 성숙 관찰 | 더위가 오기 전에 캡니다 |
| 8월 | 채종과 종자 건조, 설탕 가공 | 이삭이 갈색으로 마르면 훑습니다 |
| 9월 | 가을 파종(중순부터), 밑거름 | 시기를 놓치면 겨울을 나지 못합니다 |
| 10월 | 가을 파종 마무리, 솎음 | 상순까지가 한계입니다 |
| 11월 | 월동 준비, 짚 멀칭, 수확분 아물이와 움 저장 | 종근은 따로 표시해 보관합니다 |
| 12월 | 설탕 가공 집중, 저장 점검 | 다른 조리의 잔열을 함께 씁니다 |

### 17-1. 잊지 말아야 할 다섯 가지

| 항목 | 내용 |
|---|---|
| 질소는 본잎 6매까지 | 그 뒤의 질소는 잎만 키우고 설탕을 없앱니다 |
| 솎음을 미루지 않습니다 | 복합종자라 여러 싹이 함께 납니다. 솎지 않으면 전부 잘아집니다 |
| 월동 재배가 유리합니다 | 남부에서는 가을에 심어 이듬해 봄에 캐면 당도와 수량이 모두 최대가 됩니다 |
| 종근을 두 배로 남깁니다 | 겨울 동안 일부는 반드시 상합니다. 채종에는 열 포기 이상이 필요합니다 |
| 졸이기 전에 농축합니다 | 향류 추출과 동결 농축으로 날릴 물을 줄이면 장작이 절반으로 줍니다 |
