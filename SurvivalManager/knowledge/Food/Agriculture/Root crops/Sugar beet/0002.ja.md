### 1-3. 強みをどう読むか

&nbsp;&nbsp;&nbsp;テンサイの最大の強みは、種子寿命Sです。この表に載っているいも類（塊茎・塊根）の大半は、種子寿命がEです。ジャガイモは種いもを、アピオスとキクイモは塊茎を、キャッサバは挿し穂を、生きた状態のまま毎冬守らなければならず、そのうち1つでも枯れてしまえば翌年の栽培はできません。テンサイは乾いた種子を壺に入れて、常温で5年置けます。災害がいつ来るか分からない状況で、あらかじめ確保しておき、必要なときに取り出して播ける数少ない作物です。

&nbsp;&nbsp;&nbsp;温度適応幅SSと耐寒性Aも価値の大きい点です。5-28℃で生育し、氷点下5℃に耐えます。これは、韓国南部では秋に播いて冬を越させ、翌春に掘り上げる作型が可能であることを意味します。実際に済州島でこの方法で栽培したところ、糖度が20.8Brixまで上がり、収量も12月収穫に比べて34%増えたという記録があります。冬の間、畑が空いている期間を食料生産に使えることは、面積が足りない状況では特に大きな意味を持ちます。

&nbsp;&nbsp;&nbsp;防除自立度Aにも注目すべきです。この表で、いも類にAが付くことはまれです。根拠は、抵抗性系統と早期播種を組み合わせると主要な害虫の発生を90%以上減らせること、10月より前に収穫すれば被害が1%程度にとどまることの実証です。つまり、農薬がなくても、植える時期を調整するだけでかなりの部分に対応できます。ジャガイモが疫病の前でなすすべがないのとは対照的です。

### 1-4. 弱みをどう読むか

&nbsp;&nbsp;&nbsp;自家採種Dが、もっとも実質的な弱みです。テンサイは二年草で、1年目に根をつくり、2年目に花茎を伸ばして種子を結びます。種子を採るには、根を食べずに冬の間生かしておき、翌春に植え直さなければなりません。種子寿命が5年であることがこの弱みをかなり和らげてはくれますが、5年が過ぎればいずれ採種をしなければならず、そのときは2年にわたる作業が必要です。13節でこの問題を詳しく扱います。

&nbsp;&nbsp;&nbsp;微量栄養素Dは、テンサイを主食にできない理由です。熱量を満たすだけ食べても、推奨量の10%を超える栄養素は7種類しかありません。タンパク質密度もCで、要求ラインにわずかに届きません。テンサイは熱量と甘味を供給する作物であって、栄養を供給する作物ではありません。ただし、葉を一緒に食べると事情が変わります。テンサイの葉はフダンソウと同じものですから、ビタミンとミネラルが豊富な葉物野菜になります。

&nbsp;&nbsp;&nbsp;施肥Cは、ほかのいも類に比べて肥料を要求するという意味です。しかもホウ素を別に必要とします。ホウ素が不足すると根の内部が黒く腐る心腐れ病が出ますが、これは病原菌によるものではなく、純粋な欠乏症状です。化学肥料がない状況でホウ素を補う手段が限られていることが、テンサイ栽培の隠れた難題です。

&nbsp;&nbsp;&nbsp;貯蔵性Cも併せて見る必要があります。室（むろ）に入れれば3か月から4か月は可能ですが、ジャガイモより短く、貯蔵中に糖がゆっくり消耗します。つまり、長く置けば置くほど砂糖が減ります。砂糖が目的なら、収穫後できるだけ早く加工するほうが有利です。

> **テンサイは熱量作物であり、甘味料作物です。そして甘味料は、災害時に貯蔵技術の幅そのものを広げます。**

## 2. どんな植物か

### 2-1. 分類と原産地

&nbsp;&nbsp;&nbsp;テンサイはヒユ科（Amaranthaceae）フダンソウ属（Beta）の二年草です。フダンソウ、ビート（赤いテンサイ）、飼料用ダイコンと、すべて同じ種であり、人がどの部位を育てるよう選抜したかによって分かれた系統です。フダンソウは葉を、ビートは色と味を、テンサイは根の糖を育てた結果です。ホウレンソウとは同じ科ですが、属が違います。

&nbsp;&nbsp;&nbsp;この事実が実務で持つ意味は2つあります。第一に、テンサイの葉はフダンソウの葉と同じですから、そのまま食べられます。根を育てている間も下の葉を摘んで野菜として使え、収穫までの長い空白を埋めてくれます。第二に、フダンソウやビートとは交雑し、同じ病害を共有します。採種するときは互いに離して植えなければならず、輪作でもこれらを同じ場所に続けて植えてはいけません。

&nbsp;&nbsp;&nbsp;野生の祖先は、地中海と大西洋沿岸の海辺の植物です。塩分と風に耐え、涼しい気候でよく育ち、夏の高温には弱い性質があります。テンサイが25℃を超えると生長が鈍り、涼しい秋に糖を集中して蓄えるのは、このためです。

### 2-2. 外見の特徴

| 器官 | 特徴 |
|---|---|
| 葉 | 幅広い卵形で光沢があり、葉脈が太くはっきりしています。フダンソウと同じ形です |
| 葉柄 | 厚くて汁気が多いです。フダンソウのように食べられます |
| 根（食用部） | 白色の主根で紡錘形です。直径10-15cm、長さ30cm以上 |
| 根の先端 | 細く続き、1m以上の深さまで入ります |
| 花茎 | 2年目に1m以上伸びます |
| 花 | 緑色の小さく目立たない花が穂状につきます。風によって受粉します |
| 果実 | 複数の種子が固まってできた多胚種子です |

&nbsp;&nbsp;&nbsp;多胚種子であることは、播種で重要な点です。1粒の種子のように見えるものが実際には2、3個の種子が固まった塊であり、1か所に播くと複数の芽が一度に出てきます。そのためテンサイは必ず間引かなければならず、間引かないと根が互いに押しのけ合って、すべて小粒になります。市販の種子には、この塊を砕いて1粒ずつにしたものもありますが、自家採種した種子はそのまま多胚種子です。

&nbsp;&nbsp;&nbsp;根が白色であることも覚えておく価値があります。赤いビートと取り違えやすいのですが、赤い色素は糖の抽出過程でシロップを黒ずんだ赤に染め、土臭さを残します。砂糖が目的なら、必ず白いテンサイの系統でなければなりません。

### 2-3. 生育段階

| 段階 | 時期 | 主な生理 | 重要な養分 |
|---|---|---|---|
| 発芽・幼苗期 | 播種後4週まで | 多胚種子から複数の芽が一緒に出ます | リン酸、窒素 |
| 栄養生長期 | 4-10週 | 葉を広げ、根が太り始めます | 窒素 |
| 根の肥大期 | 10-16週 | 根が本格的に太ります | カリウム、ホウ素 |
| 糖蓄積期 | 16-22週 | 葉でつくられた糖がショ糖として根に蓄えられます | カリウム、窒素は抑制 |
| 成熟・収穫期 | 収穫直前 | 糖度が最高に達します | 灌水の中止 |
| 越冬（越冬作型） | 冬 | 低温にあうことで糖度がさらに上がります | - |
| 抽だい・開花（2年目） | 翌春 | 花茎が伸び、根の糖が消耗します | - |

> **窒素は前半に、カリウムは後半に施します。糖蓄積期に窒素が残っていると、植物は葉をつくり続けて、糖を根に送りません。テンサイ栽培でもっともよくある失敗がこれです。**

&nbsp;&nbsp;&nbsp;糖がいつ蓄えられるのかを理解すると、栽培のコツが見えてきます。葉は光合成で糖をつくり、その糖は葉自身の生長に使われるか、根に下りて貯蔵されます。植物がまだ育つ必要があると判断すれば糖は葉へ、これ以上育つ必要がないと判断すれば根へ向かいます。窒素が十分にあれば植物は育ち続けようとし、涼しくなって窒素が減ると貯蔵に切り替わります。秋作や越冬栽培で糖度が高く出るのは、このためです。

### 2-4. 100g当たりの栄養

| 栄養素 | 含量 | 備考 |
|---|:---:|---|
| 熱量 | 43-77kcal | 品種や栽培条件によって大きく異なります |
| 水分 | 約78g | 残りの大部分は糖です |
| 炭水化物 | 10-20g | ほぼすべてがショ糖です |
| ショ糖（砂糖） | 14-20g | これが抽出の対象です。越冬栽培では20ブリックス以上 |
| タンパク質 | 0.8-1.8g | 少ないです |
| 脂質 | 0.08-0.2g | ほとんどありません |
| カリウム | 含有 | 根にも葉にも多く含まれます |
| ビタミンC | 含有 | 加熱すると減ります |

&nbsp;&nbsp;&nbsp;テンサイで特別なのは、蓄えられた糖の形です。ジャガイモやキャッサバがデンプンとして蓄えるのに対し、テンサイはショ糖、つまり私たちが砂糖と呼ぶその物質のまま蓄えます。デンプンを糖に変えるには酵素や酸が必要ですが、テンサイでは汁を搾って水を飛ばすだけで済みます。災害時に甘味料を自給できるほぼ唯一の道筋が、ここに開けます。

&nbsp;&nbsp;&nbsp;葉も併せて見るべきです。テンサイの葉はフダンソウと同じですから、100g当たりビタミンAとK、鉄、マグネシウムがかなり含まれています。根が微量栄養素Dという弱みを抱えているのを、葉が大きく補ってくれます。根を育てている間に下の葉を少しずつ摘んで食べれば、播種から収穫までの5か月間、野菜を得られます。ただし、葉を摘みすぎると光合成面積が減って糖度が下がります。
