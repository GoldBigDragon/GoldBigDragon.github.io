## 3. 栽培环境

### 3-1. 临界值与最适值

| 项目 | 临界值 | 最适值 | 超出范围时 |
|---|---|---|---|
| 生长温度 | 5-28℃ | 15-20℃ | 幅度达23℃，范围很宽。喜欢凉爽的气候 |
| 高温临界 | 25℃以上 | - | 生长迟缓，糖分无法积累 |
| 低温临界 | 零下5℃ | - | 低于此温度，根会冻伤变软 |
| 发芽温度 | 5℃以上 | 15-20℃ | 温度低则发芽迟缓且不整齐 |
| 光照 | 每天6小时以上 | 每天8小时以上 | 荫蔽时糖度会明显下降 |
| 土壤pH | 6.0-7.5 | 6.5-7.0 | 不耐酸性土壤。与其他薯类（块茎/块根）相反 |
| 土壤 | 砂壤土-壤土 | 深厚松软的壤土 | 石块和黏土多，则根会开裂 |
| 水分 | 总ET约550mm | 膨大期要充足 | 过湿则根会腐烂 |
| 硼 | 另有需求 | - | 缺硼则根内部发黑腐烂 |

&nbsp;&nbsp;&nbsp;甜菜与其他薯类（块茎/块根）有一个决定性的不同，就是土壤酸度。马铃薯能耐受pH 5.0-6.0，美洲土圞儿5.0-6.0，木薯可耐受4.5-7.5，而甜菜要求接近中性。在酸性土壤中，生长会明显变差，也更容易得病。韩国的旱地大多偏酸，因此需要用石灰或草木灰来调节。灾害情境下如果弄不到石灰，草木灰可以代替；这样一来，补钾和调节pH可以一次解决，反而更高效。

### 3-2. 栽培类型 - 这种作物的关键

| 栽培类型 | 播种 | 收获 | 适宜地区 | 特点 |
|---|---|---|---|---|
| 秋播·越冬栽培 | 9月中旬-10月上旬 | 次年4-5月 | 韩国南部、济州岛 | 糖度和产量都达到最高 |
| 春播 | 3月中旬-4月上旬 | 7-8月 | 韩国中部、韩国北部 | 必须在暑热到来之前收挖 |
| 避开夏季 | - | - | 韩国全境 | 一定要避开高温期 |

&nbsp;&nbsp;&nbsp;越冬栽培要有利得多，这一点有实际试验结果支持。同一块地，12月收挖时每1,000㎡产量为5.8吨，而留在地里到次年4月再挖，则为7.8t，增加了34%。糖度升到了20.8Brix。原因有两个。冬季虽然生长几乎停止，但晴天光合作用仍在继续，糖得以积累；而低温本身就是促使植物积累糖的信号。为了避免冻结而提高细胞内的糖浓度，就是植物越冬的策略。

| 条件 | 判断 |
|---|---|
| 深厚、无石块的田地 | 最好。主根可以笔直生长 |
| 凉爽、日照充足的地方 | 好。糖度会提高 |
| 接近中性的土壤 | 好。若偏酸，要事先调节 |
| 容易积水的低洼地 | 避免。会发生根腐 |
| 石块多的地 | 避免。根会开裂并畸形 |
| 种过莙荙菜、红菜头的地方 | 避免。要间隔3年 |
| 夏季高温严重的地方 | 调整播种时间 |

## 4. 品种

### 4-1. 主要品种

| 品种 | 特点 | 灾害适合度 |
|---|---|:---:|
| Tener | 韩国育成的品种。在济州岛越冬栽培中，糖度达到了20.8Brix | 高 |
| Suez | 韩国育成的品种，对忠州地区适应性好 | 高 |
| Tangeum甜菜 | 忠州地区特有的品种 | 高 |
| 饲料用品系 | 糖度较低，但根大、产量高 | 中等。对保障热量有利 |

### 4-2. 按情况选择的标准

| 情况 | 选择 | 理由 |
|---|---|---|
| 以制糖为目的时 | 糖度高的白根品系 | 没有红色素，糖浆才清澈 |
| 以保障热量为目的时 | 根大的品系 | 糖度低，总量也多 |
| 韩国南部·济州岛 | Tener等适应越冬的品系 | 经过越冬，糖度才能达到最高 |
| 韩国中部·韩国北部 | 早熟品系 | 要在暑热到来之前收挖 |
| 同时养家畜时 | 饲料用品系 | 根和叶都可作饲料 |
| 长期使用种子时 | 固定品种 | 杂交种自家留种后性状会分离 |

&nbsp;&nbsp;&nbsp;最后一行很重要。商业流通的甜菜种子中有相当一部分是杂交种，从杂交种上收下的种子，下一代性状会分离，糖度和产量会大幅下降。要发挥种子寿命长达5年的优势，从一开始就最好备下固定品种。如果难以区分，就只有实际留几株的种，种下去看后代是否整齐一致。

## 5. 整地与施肥

### 5-1. 土地准备

| 项目 | 标准 | 理由 |
|---|---|---|
| 翻耕 | 深20-30cm，尽量更深 | 为主根笔直生长开辟通道 |
| 拣石 | 必须做 | 根碰到石头会开裂 |
| 垄高 | 15-20cm | 防止过湿 |
| 排水沟 | 保证畅通 | 这是预防根腐的唯一办法 |
| 土壤酸度 | 调节至pH 6.0-7.0 | 偏酸就施石灰或草木灰 |
| 有机质 | 腐熟堆肥1,000-1,500kg/1,000㎡ | 未腐熟的堆肥会使根开裂 |

&nbsp;&nbsp;&nbsp;深耕对甜菜尤其重要。主根要笔直向下生长，才能长成纺锤形的大根，如果30cm以下有坚硬的土层，根就会在那里开裂或向侧面弯曲。开裂的根产量下降，泥土夹在其中，也很难洗净。在没有机械的情况下，用铁锹翻到两锹深的双层挖掘很有效，而这项劳动也正是甜菜的整地·挖掘能耗等级停留在B的原因。

### 5-2. 标准施肥量（以1,000㎡计）

| 肥料 | 施肥量 | 时期 |
|---|:---:|---|
| 氮（N） | 10-15kg | 基肥50%，追肥50% |
| 磷（P） | 8-10kg | 全部作基肥 |
| 钾（K） | 10-15kg | 分基肥和追肥施用 |
| 堆肥 | 1,000-1,500kg | 腐熟堆肥，全部作基肥 |
| 硼 | 少量 | 仅在缺硼地区施用。过量反而有害 |

### 5-3. 基肥与追肥

| 类别 | 时期 | 内容 |
|---|---|---|
| 基肥 | 播种前2周 | 堆肥和磷、钾的全部，氮的一半 |
| 追肥 | 5-6片真叶时 | 以氮为主，施剩下的一半 |
| 禁止 | 糖分积累期之后 | 此时施氮，糖度会急剧下降 |

> **氮肥追肥只能施到5-6片真叶为止。此后施的氮不会增加产量，只会把糖消耗掉。**

### 5-4. 没有化肥时 - 灾害情境下的替代肥料

| 替代资源 | 提供的养分 | 制作与使用方法 | 注意 |
|---|---|---|---|
| 草木灰 | 钾、磷、钙 | 最适合甜菜。兼具补钾和调节pH的作用 | 每㎡一两把。过量会使pH升得过高 |
| 腐熟堆肥 | 多种养分 | 作基肥大量施入 | 必须是完全腐熟的。未腐熟的会使根开裂 |
| 稀释尿液 | 氮、钾 | 用水稀释10倍，仅在生长初期施用 | 6片真叶之后不再施用 |
| 骨粉 | 磷、钙 | 烧后捣碎，混入堆肥 | 见效慢 |
| 贝壳·蛋壳 | 钙 | 烧后磨成细粉 | 用于调节酸性 |
| 海藻 | 钾、微量元素、硼 | 晒干捣碎，或用水浸泡后施用 | 是少数能获得硼的途径之一 |
| 甜菜叶与加工残渣 | 钾、有机质 | 收获后还回田里 | 这是钾素循环的关键 |

&nbsp;&nbsp;&nbsp;硼是灾害情境下最棘手的问题。硼是微量元素，只需要极少量，但缺了的话根内部会发黑腐烂，反过来多了又会出现毒性，是一种适宜范围很窄的元素。在没有化肥的情况下，获得硼的现实途径是海藻。把裙带菜、海带、石莼之类晒干捣碎，混入基肥，或者用水浸泡后灌根，就会连同硼一起带入钾和其他微量元素。在靠近海边的地区，这种方法尤其有效。在内陆的话，让堆肥的材料多样化是次优的办法。

## 6. 播种

### 6-1. 时期

| 栽培类型 | 播种时期（韩国） | 收获时期（韩国） |
|---|---|---|
| 秋播·越冬 | 9月中旬-10月上旬 | 次年4-5月 |
| 春播 | 3月中旬-4月上旬 | 7-8月 |

&nbsp;&nbsp;&nbsp;秋季播种的时机不能错过。播得太早，入冬前长得过大，感受到低温，次年春天就会抽出花茎。这叫抽薹，抽薹的甜菜，根中的糖会流失到花茎里，变得不能用。播得太晚，长得不足以越冬，就会冻死。9月中旬到10月上旬这个狭窄的窗口期，就是在这两种风险之间确定下来的。

### 6-2. 播种方法

| 项目 | 标准 | 理由 |
|---|---|---|
| 播种深度 | 1.5-2.5cm | 太深则发芽不良 |
| 行距 | 30-40cm | 保证通风和光合作用 |
| 株距（最终） | 10-15cm | 为根的增粗留出空间 |
| 播种量 | 每1,000㎡用1-1.5kg | 考虑到要间苗，多播一些 |
| 播种后 | 薄薄盖一层土，轻轻压实使其贴紧 | 种子悬空会干 |
| 灌溉 | 到发芽为止不让土壤干 | 忌过湿 |

### 6-3. 种子处理

| 方法 | 步骤 | 效果 |
|---|---|---|
| 水泡 | 在水里泡一天后再播 | 复合种子的外壳变软，发芽加快 |
| 温水处理 | 在50-55℃的水中浸泡10-15分钟 | 减少表面病原菌 |
| 草木灰处理 | 给种子裹上草木灰 | 兼有消毒和干燥的作用 |
| 筛选 | 捞掉浮起来的种子 | 去除内部空瘪的种子 |

&nbsp;&nbsp;&nbsp;复合种子外壳厚而硬，导致发芽不整齐，是甜菜的常见问题。泡水一天，发芽可以提早几天，也更整齐。不过，泡过水的种子要立即播种，如果再晒干存放，发芽力反而会下降。进行温水处理时，要注意不要超过60℃。
