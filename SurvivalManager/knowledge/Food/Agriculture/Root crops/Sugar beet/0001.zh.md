## 引言
&nbsp;&nbsp;&nbsp;甜菜（Beta vulgaris）是苋科二年生草本，与莙荙菜、红菜头同属一个种，是为了把糖集中到根里而改良出来的品系。18世纪末在欧洲作为代替甘蔗的甜味原料培育出来，在拿破仑战争使砂糖进口中断的法国发展起来。灾害应对评估的综合等级为S（52.4分，有效183种中第9位），短期S（53.7）、长期S（51.2）、副食B（47.4分），单位面积热量为S（每㎡3,850kcal），干种子常温密封能保存5年。但种这种作物的真正理由是甜味。糖是吸收最快的热量，也是浓度超过60%时细菌和霉菌无法生长的防腐剂，还是酒和醋的原料。代价是燃料。根里的糖只有15%左右，1kg砂糖要用5-15kg柴火，所以灾害状况下的答案往往是只做到糖浆为止（第10节）。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | S | 52.4 |
| 短期 | S | 53.7 |
| 长期 | S | 51.2 |
| 副食 | B | 47.4 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：设施负担、温度幅度。S：单位面积热量、口味、种子寿命。A：耐寒性、防治自立度、国内种植普及度。B：水消耗量、光照、连作适应性、无合成投入产量保持率、整地·挖掘能量、产量稳定性 |
| 劣势 | E：非食用价值。D：微量营养素、收获速度、持续性、自留种。C：蛋白质密度、施肥、烹调·加工要求度、病虫害压力、耐储性 |

> **甜菜既是热量作物，也是甜味剂作物，而甜味剂本身就会拓宽灾害状况下的储存技术范围。**

&nbsp;&nbsp;&nbsp;种子寿命S是指，不像其他薯类需要每年冬天把种薯、块茎、插条保持存活，干燥的种子可以装在罐里放5年。温度幅度SS和耐寒性A是指它在5-28℃生长，能耐受-5℃；防治自立度A则来自这样的实证：抗病品系加早播能使主要害虫发生减少90%以上，在10月前收获，损失只有1%左右。自留种D是指它是二年生，要把根越冬后第二年重新栽种才能收到种子（第8节）；微量营养素D是指即使吃到满足热量，超过推荐量10%的营养素也只有7种，所以不能当主食。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 苋科甜菜属（Beta）二年生草本。与莙荙菜、红菜头（红色甜菜）、饲用甜菜是同一个种。喜凉爽气候，超过25℃生长就会变慢 |
| 叶、茎 | 叶与莙荙菜相同；在培育根的期间，可以摘下部的叶子当蔬菜吃 |
| 根 | 白色纺锤形，直径10-15cm，长30cm以上。红色素会把糖浆染成暗红，所以制糖必须用白根品系 |
| 花、种子 | 第2年花茎长到1m以上，绿色小花靠风授粉。种子是多粒种子粘在一起的复合种子（种球），所以一个种球会长出两三个芽 |

&nbsp;&nbsp;&nbsp;播种后4周内为发芽·幼苗期，4-10周为营养生长期（氮），10-16周为根膨大期（钾、硼），16-22周为糖积累期（钾）；第2年春天抽薹，根里的糖就会被消耗。氮还有剩余时，植株会不停地长叶子，不把糖送到根里，所以糖积累期氮残留是最常见的失败。每100g含热量43-77kcal、蔗糖14-20g（越冬栽培时在20Brix以上）、蛋白质0.8-1.8g；它以蔗糖的形式而不是淀粉储存，所以榨汁后把水蒸发掉就是甜味剂。叶子含有丰富的维生素A和K、铁、镁，可以弥补根的不足。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 生长5-28℃（适温15-20℃），25℃以上糖不积累，发芽要5℃以上。-5℃以下根会冻结变软 |
| 水分、光照 | 总蒸散量约550mm。每天需要6小时以上（适宜8小时以上）日照，阴处糖度会下降 |
| 土壤 | 深厚无石的砂壤土-壤土，pH6.0-7.5（适宜6.5-7.0）。与其他薯类不同，怕酸性，所以用石灰或木灰调节（木灰兼有补钾和调节pH的作用） |
| 栽培类型 | 秋播越冬：9月中旬-10月上旬播种，翌年4-5月收获（南部、济州岛）。春播：3月中旬-4月初播种，7-8月收获（中部、北部），要在变热前挖出。避开夏季高温期 |

&nbsp;&nbsp;&nbsp;越冬栽培有利。同一块田里，12月挖时每1,000㎡产5.8t，原地不动到翌年4月再挖，增至7.8t，增加了34%，糖度升到20.8Brix。因为低温本身就是让植株积累糖的信号。秋播的时间窗口很窄：种得太早，冬前就感受到低温，翌年春天抽薹；种得太晚，长得不够过冬，就会冻死。

&nbsp;&nbsp;&nbsp;品种有Tener（济州岛越冬栽培中为20.8Brix）、Suez和忠州特有的Tangeum甜菜。制糖时选糖度高的白根品系，要热量时选根大的品系。市售种子很多是杂交种，留的种子性状会分离，所以一开始就要备好固定品种。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 翻耕20-30cm以上深，一定要清除石头（根碰到石头或硬土层就会裂开或弯曲）。起15-20cm的高垄并开排水沟（防止根腐的唯一办法） |
| 施肥（1,000㎡） | 氮10-15kg（基肥50%、追肥50%）、磷8-10kg（全部作基肥）、钾10-15kg（基肥和追肥）、腐熟堆肥1,000-1,500kg（未腐熟会使根裂开）。基肥在播种前2周施入，追肥在真叶5-6片时以氮为主施入后就结束。此后的氮不会提高产量，只会使糖消失 |
| 灾害替代肥料 | 木灰（每㎡一两把）、腐熟堆肥、稀释10倍的尿液（真叶6片以后禁用）、骨粉、还田的叶子和加工残渣（钾循环） |
| 硼 | 缺少时根里发黑腐烂，过量则有毒，所以安全范围很窄。现实的来源是海藻（把干裙带菜、海带、石莼混进基肥，或浸水后灌施），内陆则让堆肥原料多样化 |
| 播种 | 深1.5-2.5cm，行距30-40cm，最终株距10-15cm，每1,000㎡ 1-1.5kg（预留间苗量）。薄薄盖一层土并压实使之贴紧，发芽前不要让土变干 |
| 种子处理 | 种皮坚硬、发芽不整齐，所以用水浸泡一天后立即播种（再晒干会降低发芽力）。裹木灰，或放入50-55℃的水中浸10-15分钟，以减少表面病原菌 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种到发芽 | 保持不干（种球要充分吸水，种皮才会软化）。生长初期靠自然降水，干旱时才补水 |
| 根膨大期 | 充足而不干（干旱会同时降低产量和糖度） |
| 收获前2-3周 | 停止灌水（水分减少，糖浓度上升，耐储性变好）。越冬期也不灌水 |

| 管理 | 方法 |
|:---|:---|
| 间苗 | 种球会同时长出两三个芽，所以不能省。真叶2-3片时留3-5cm，5-6片时定苗到10-15cm。越晚间苗，要保留植株的根越受损，所以不要拔，用剪刀在贴近地面处剪断。间下来的嫩苗当凉拌菜吃 |
| 培土 | 生长期间1-2次，雨后盖住露出的根肩。晒了太阳变绿的根肩糖度低、有苦味，还会使糖浆浑浊 |
| 其他管理 | 初期生长慢，所以除草是必须的，稻草或落叶覆盖能缩小水分波动幅度并防止裂根。下部的叶子只能一点一点摘来吃。越冬时用稻草或落叶盖住根肩，春天抽了花茎的植株根已无法使用，要先挖掉 |
| 缺水、过湿 | 中午叶子下垂、傍晚恢复的话，就加强覆盖；下部叶子干枯的话，往垄间引水。缺水后突然浇水会使根纵向裂开而无法储存。过湿则上部变软并发出恶臭，成为根腐，所以该株要丢弃并开排水沟 |

## 6. 病虫害与养分问题
&nbsp;&nbsp;&nbsp;病虫害压力为C（无防治估计减产率50.6%），但防治自立度为A，所以不用药，只靠调节播种和挖收的时间就能解决大部分问题。例外是甜菜孢囊线虫和根腐病，它们会在土壤中留存数年，所以种植前要确认田块的历史。

| 病虫害 | 症状与条件 | 预防与应对 |
|:---|:---|:---|
| 根腐病、孢囊线虫 | 根里发黑腐烂（苋科连作地） / 寄生在根上，生长停止 | 休耕3年以上，也不与莙荙菜、红菜头连作 / 无法治疗，所以与非寄主作物轮作数年 |
| 褐斑病、白粉病 | 叶片上褐色斑点蔓延（高温高湿） / 叶面出现白粉（干燥且昼夜温差大时） | 保证通风，摘除病叶，轮作3年以上 / 稀释10倍的牛奶、小苏打溶液 |
| 害虫 | 蚜虫（传播病毒）、根菜类害虫（在根上蛀孔）、地老虎（咬断幼株基部）、叶甲（啃叶） | 喷肥皂水，保护瓢虫和寄生蜂 / 抗病品系和早播，10月前收获 / 夜里捕捉，在基部围一圈草木灰 / 人工捕捉 |

| 症状 | 原因与措施 |
|:---|:---|
| 新叶畸形、根里发黑腐烂 | 缺硼（虽叫心腐病，但没有病原菌，是单纯的缺素，所以用药无效）。干海藻、堆肥原料多样化 |
| 只有叶子茂盛、根小、糖度低 | 氮过多（最需要警惕的问题，后期用稀释尿液会使糖度减半）。停止施氮，用木灰补钾 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 豆科（固氮并留给下一茬）、洋葱、大蒜（驱避害虫）、生菜、菠菜（早期覆盖垄间抑制杂草） |
| 一般 | 白菜、萝卜（争夺养分） |
| 差 | 莙荙菜、红菜头、饲用甜菜（同一个种，共有病害并杂交）、同一地块连作（根腐病和线虫积累） |

&nbsp;&nbsp;&nbsp;轮作的顺序是：第一年甜菜（大量带走氮和钾），第二年豆科（恢复氮），第三年叶菜类或葱类（不是苋科），第四年再种甜菜，间隔要保持3年以上。不遵守间隔，根腐病和线虫就会积累，几年后整块田突然垮掉。莙荙菜和红菜头与甜菜是同一个种，对病原菌来说无法区分，所以在菜园里种过莙荙菜的地方，第二年种甜菜也算连作。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时机 | 春播的根在播种后90-150天（直径5-10cm）挖出，越冬栽培在翌年4-5月挖出。春天看到抽薹征兆（植株中心的叶子向上伸长、茎变粗）就是最后时机，此后根里的糖会流向花茎 |
| 要领 | 在晴朗干燥的日子，先松动植株旁边的土，再把叶子拢在一起笔直向上拔出。叶子在根的上部留1-2cm切下（切得太贴近，腐烂会从头部进入，留得太长，叶子会消耗糖）。不要切须根和尾根（病菌会进入），只抖掉泥土，不用水洗。裂开或有伤的根不储存，先用来提取糖 |

| 留种 | 标准 |
|:---|:---|
| 结构 | 要收种子，就得把第一年的根留着不吃，越冬后在春天重新栽种（留种根），这是甜菜自给自足的唯一瓶颈 |
| 种根选留与储存 | 选笔直、没裂开、无伤、中等以上大小的根，切开尝一尝，挑甜的；叶子在头部留3-5cm切下（保护生长点），不要切须根。冬天会有一部分变坏，所以要留下所需量的两三倍。把根头朝上竖着埋进湿润的沙子或土里的窖中（0-4℃），每2周检查一次。南部不挖出，盖上20-30cm稻草原地越冬最为可靠（中部以北有风险） |
| 重新栽种、开花 | 3月中旬-4月初，让根头略微露出地面，按50-60cm间距栽种，并给长到1m以上而倒伏的花茎立支架。5-6月开花，穗子干成褐色后捋下，在阴凉处彻底晾干 |
| 隔离、株数 | 靠风授粉，会与莙荙菜、红菜头和其他甜菜品种杂交。隔离有困难，所以同一年只让一个品种开花，当年不对莙荙菜和红菜头留种。怕近交，所以要从十株以上、最好20株以上的植株上取种并混合 |
| 保管 | 彻底晾干后装进密封容器，把木灰或木炭用布包好一起放入，置于阴凉黑暗处。常温密封能保存约5年，每年用几粒种子确认发芽率，并在第5年到来之前留一次种 |

## 9. 储存
&nbsp;&nbsp;&nbsp;耐储性C是把储存期限B和储存损失率5.09%合起来的等级。根在储存期间也在呼吸，并把自身的糖当燃料，所以放得越久、温度越高，糖就越少。经过愈合处理（10-15℃，湿度85-95%，黑暗，微通风，1-2周）后进入正式储存（0-4℃，湿度85-95%，完全黑暗），零下会冻软，8℃以上会发芽。

| 方式 | 方法 | 期限 |
|:---|:---|:---|
| 窖储存 | 在排水良好的地方向下挖1.5m，做屋顶和通气口（0-4℃）。最稳定，但挖掘的劳动量大 | 3-4个月 |
| 坑·土堆储存 | 挖直径1.5m、深20-30cm的浅坑，铺10cm干稻草，把愈合处理完的根堆成高度不超过60cm的坟包状。盖上20-30cm稻草和15-20cm土，在顶部用草束做通气口（堵住的话热量和湿气积聚而腐烂），并在四周挖排水沟（0-5℃） | 2-3个月 |
| 加工储存 | 糖浆（密封可存1年以上）、结晶砂糖（数年）、干片（6个月-1年）、2-3%盐水中的乳酸发酵（常温1-2周）、酒和醋 | 数月-数年 |

> **长期保存甜菜最可靠的办法，不是守住根，而是把它变成糖浆。根只能存四个月，糖浆却能过年。**

## 10. 糖的提取、烹调与注意事项
| 注意 | 内容 |
|:---|:---|
| 根 | 没有木薯的氰苷或马铃薯的龙葵素那样的毒素，一般食用量下是安全的。生吃也可以，但又硬又有土味，加热更好（整个煮30-40分钟，蒸35-45分钟，蒸的话糖不会溶进水里，更好），吃多了会因糖分而肚子不舒服。变色或有异味的要扔掉，里面发黑的部分（缺硼）挖掉后，其余的可以吃 |
| 叶 | 与莙荙菜一样含草酸，氮施得多的田里的叶子会积累硝酸盐（注意幼儿），所以在沸水中焯1-2分钟并倒掉水。有肾结石病史的人不要多吃 |
| 制糖 | 沸腾的糖液比水更烫、更黏，烫伤很深，还会突然溢出，所以锅里最多装三分之二，并不停搅拌以免锅底烧焦。石灰不要沾到眼睛和皮肤。稀的糖液几天就会发酵，把发酵中的液体密封会使容器爆裂 |

| 糖的提取 | 方法 |
|:---|:---|
| 切片、提取 | 洗掉泥土，切掉绿色根肩和须根，切成2-3mm厚的细丝，用刚好没过的水在70-75℃下浸提40分钟-1小时。不能煮沸：超过80℃果胶会溶出，汁液变黏而无法过滤，低于60℃糖出不来，杂菌还会繁殖。没有温度计时，以水冒热气但没沸腾为准 |
| 逆流提取 | 把前一轮出来的汁倒在下一轮的新丝上重新加热，重复3-4次，汁就会变浓；最后的丝用新水冲洗，这水用于下一批的第一轮。要蒸发的水减少到一半以下，所以柴火更省 |
| 压榨、澄清 | 把丝用布包起来用力压榨，回收剩下的汁，渣滓用作饲料或堆肥。熬煮全程都要撇去褐色泡沫（必须），效果最大的是石灰处理。把蛤蜊壳或牡蛎壳放在柴火里烧红做成生石灰，加水变成熟石灰后，把清澈的上层液一点一点加进汁里，沉淀后过滤（加多了会留下苦味和肥皂味） |
| 熬煮、燃料 | 用浅而宽的锅敞盖熬煮，勺子舀起能拉成丝状滴落、糖度约70%时糖浆就做好了。要得到1kg砂糖，必须蒸发4.5-5L水，在敞开的明火（热效率5-15%）上需要5-15kg柴火。节省的办法有逆流提取（最大）、利用其他烹调的余热，以及把汁盛在浅的黑色容器里盖上布放在太阳下预浓缩 |
| 冷冻浓缩 | 在零下的夜晚，把汁放在浅而宽的容器里拿到室外，早上把结出的冰（几乎是纯水）取走，连续重复许多晚。完全不用燃料，但浓度上升后冰点下降，大约只能做到一半。在有冬季的地区，秋天榨汁、冬夜冷冻浓缩、春天熬煮的顺序最省燃料 |
| 糖浆、结晶 | 灾害状况下的答案通常是糖浆。不需要额外的燃料和工具，没有损失，甜味调味、腌渍、保存、发酵都能用。糖度低于60-65%时会发酵或长霉，所以要熬到70%左右。结晶砂糖则是继续熬到滴进冷水能聚成软团，边冷却边慢慢搅拌，把生成的结晶装进布袋吊起，几天里沥出糖蜜，再晾干而得，适合长途搬运或长期储备。100kg根能出约18-21kg糖浆 |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存的根和种根（每2周挑出腐烂的），冬季冷冻浓缩。2月翻堆堆肥，用石灰或木灰调节酸度 |
| 3-4月 | 3月翻耕并清石，春播（中旬以后），重新栽种种根。4月收获越冬栽培的甜菜（花茎抽出之前，糖度最高），确认发芽，第一次间苗 |
| 5-6月 | 5月第二次间苗、追肥（氮到此为止）、除草。6月培土，开始摘叶，给留种株立支架 |
| 7-8月 | 7月收获春播的（变热之前），观察种子成熟。8月穗子干成褐色后采种并晾干种子，加工糖 |
| 9-10月 | 9月中旬起秋播并施基肥（错过时机就无法过冬）。10月上旬前播完并间苗 |
| 11-12月 | 11月做越冬准备（稻草覆盖），收获物愈合处理后入窖储存，种根另外保管。12月集中加工糖（同时利用其他烹调的余热），检查储存物 |

> **甜菜是这样一种作物：氮在真叶5-6片时就停，间苗不拖延，南部秋播越冬，种根留所需量的两倍，熬煮前先浓缩以减少柴火。**
