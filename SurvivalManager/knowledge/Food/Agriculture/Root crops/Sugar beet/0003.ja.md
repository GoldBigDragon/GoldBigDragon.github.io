## 3. 栽培環境

### 3-1. 限界値と最適値

| 項目 | 限界値 | 最適値 | 外れたとき |
|---|---|---|---|
| 生育温度 | 5-28℃ | 15-20℃ | 幅が23℃と広いです。冷涼な気候を好みます |
| 高温限界 | 25℃以上 | - | 生長が鈍り、糖が蓄積しません |
| 低温限界 | 氷点下5℃ | - | それより下では根が凍って軟化します |
| 発芽温度 | 5℃以上 | 15-20℃ | 低いと発芽が遅れ、そろいません |
| 光量 | 1日6時間以上 | 1日8時間以上 | 日陰になると糖度が目立って落ちます |
| 土壌pH | 6.0-7.5 | 6.5-7.0 | 酸性土壌に弱いです。他のいも類（塊茎・塊根）とは逆です |
| 土壌 | 砂壌土-壌土 | 深くて軟らかい壌土 | 石と粘土が多いと根が裂けます |
| 水分 | 総ET約550mm | 肥大期に十分に | 過湿だと根が腐ります |
| ホウ素 | 別途要求 | - | 不足すると根の内部が黒く腐ります |

&nbsp;&nbsp;&nbsp;テンサイが他のいも類（塊茎・塊根）と決定的に異なる点が、土壌の酸度です。ジャガイモはpH 5.0-6.0、アピオスは5.0-6.0、キャッサバは4.5-7.5まで耐えますが、テンサイは中性付近を要求します。酸性土壌では生育が目に見えて悪くなり、病気にも弱くなります。韓国の畑はおおむね酸性に傾いているため、石灰や草木灰による矯正が必要です。災害時に石灰が手に入らなければ草木灰が代替になりますが、この場合、カリウムの供給とpHの矯正を一度に解決できるため、かえって効率的です。

### 3-2. 作型 - この作物のカギ

| 作型 | 播種 | 収穫 | 適する地域 | 特徴 |
|---|---|---|---|---|
| 秋まき・越冬栽培 | 9月中旬-10月上旬 | 翌年4-5月 | 韓国南部、済州島 | 糖度も収量も最大になります |
| 春まき | 3月中旬-4月上旬 | 7-8月 | 韓国中部、韓国北部 | 暑さが来る前に掘り取る必要があります |
| 夏の回避 | - | - | 韓国全域 | 高温期を必ず避けます |

&nbsp;&nbsp;&nbsp;越冬栽培のほうがはるかに有利であるという事実は、実際の試験結果に裏づけられています。同じ畑で12月に掘り取った場合は1,000㎡あたり5.8トンだった収量が、そのまま置いて翌年4月に掘り取ると7.8tになり、34%増えました。糖度は20.8Brixまで上がりました。理由は二つあります。冬の間、生長はほとんど止まりますが、晴れた日には光合成が続いて糖がたまること、そして低温そのものが、植物に糖を蓄積させる合図になることです。凍結を避けるために細胞内の糖濃度を高めるのが、植物の冬越しの戦略です。

| 条件 | 判断 |
|---|---|
| 深くて石のない畑 | 最も適しています。主根がまっすぐ伸びます |
| 冷涼で日当たりのよい場所 | よいです。糖度が上がります |
| 中性に近い土壌 | よいです。酸性なら事前に矯正します |
| 水がたまる低地 | 避けます。根腐れが起こります |
| 石の多い土地 | 避けます。根が裂けて奇形になります |
| フダンソウ・ビーツを植えていた場所 | 避けます。3年の間隔をあけます |
| 夏の高温がひどい場所 | 播種時期を調整します |

## 4. 品種

### 4-1. 主な品種

| 品種 | 特徴 | 災害時の適合度 |
|---|---|:---:|
| テナー（Tener） | 韓国で育成された品種です。済州島の越冬栽培で、糖度20.8Brixを記録しました | 高い |
| スエズ（Suez） | 韓国で育成された品種で、忠州地域への適応性がよいです | 高い |
| タングム・テンサイ | 忠州地域固有の品種です | 高い |
| 飼料用系統 | 糖度は低いものの、根が大きく収量が多いです | 普通。熱量の確保には有利です |

### 4-2. 状況別の選択基準

| 状況 | 選択 | 理由 |
|---|---|---|
| 砂糖の生産が目的のとき | 糖度が高い白い根の系統 | 赤い色素がないほうが、シロップが澄みます |
| 熱量の確保が目的のとき | 根が大きい系統 | 糖度が低くても総量が多くなります |
| 韓国南部・済州島 | テナーなど越冬に適応した系統 | 冬を越してこそ糖度が最大になります |
| 韓国中部・韓国北部 | 早生系統 | 暑さが来る前に掘り取る必要があります |
| 家畜を一緒に飼うとき | 飼料用系統 | 根も葉も飼料に使います |
| 種子を長く使うとき | 固定種 | 交配種は自家採種しても形質が分離します |

&nbsp;&nbsp;&nbsp;最後の行が重要です。商業的に流通しているテンサイの種子の相当数は交配種であり、交配種から採った種子は、次の世代で形質が分離して、糖度と収量が大きく落ちます。種子寿命が5年という利点を生かすには、最初から固定種を確保するほうがよいでしょう。見分けが難しい場合は、数株を実際に採種して播いてみて、子孫がそろっているかどうかを確認するしかありません。

## 5. 畑の準備と肥料

### 5-1. 土づくり

| 項目 | 基準 | 理由 |
|---|---|---|
| 耕起 | 20-30cmの深さ、できるだけ深く | 主根がまっすぐ伸びる道をつくります |
| 石の除去 | 必ず行います | 石に当たると根が裂けます |
| 畝の高さ | 15-20cm | 過湿を防ぎます |
| 排水溝 | 確保 | 根腐れの唯一の予防策です |
| 土壌酸度 | pH 6.0-7.0に矯正 | 酸性なら石灰か草木灰を入れます |
| 有機物 | 完熟堆肥1,000-1,500kg/1,000㎡ | 未熟な堆肥は根を裂けさせます |

&nbsp;&nbsp;&nbsp;深く耕すことは、テンサイでは特に重要です。主根がまっすぐ下へ伸びてこそ紡錘形の大きな根になりますが、30cmより下に硬い層があると、そこで根が裂けたり横に曲がったりします。裂けた根は収量が減り、土が挟まって洗うのも困難です。機械がない状況では、スコップで2スコップの深さまで掘り返す二重掘りが効果的であり、この労働は、テンサイの整地・掘削エネルギーの等級がBにとどまる理由でもあります。

### 5-2. 標準施肥量（1,000㎡あたり）

| 肥料 | 施肥量 | 時期 |
|---|:---:|---|
| 窒素（N） | 10-15kg | 元肥50%、追肥50% |
| リン酸（P） | 8-10kg | 全量を元肥 |
| カリウム（K） | 10-15kg | 元肥と追肥に分けます |
| 堆肥 | 1,000-1,500kg | 完熟堆肥、全量を元肥 |
| ホウ素 | 少量 | 欠乏地域でのみ。過剰だとかえって有害です |

### 5-3. 元肥と追肥

| 区分 | 時期 | 内容 |
|---|---|---|
| 元肥 | 播種2週間前 | 堆肥とリン酸・カリウムの全量、窒素は半分 |
| 追肥 | 本葉5-6枚 | 窒素を中心に残りの半分 |
| 禁止 | 糖蓄積期以降 | このときに窒素を与えると、糖度が急激に落ちます |

> **窒素の追肥は本葉5-6枚までです。それ以降に与えた窒素は、収量を増やすのではなく、砂糖を消してしまいます。**

### 5-4. 化学肥料がないとき - 災害時の代替肥料

| 代替資源 | 供給する養分 | 作り方と使い方 | 注意 |
|---|---|---|---|
| 草木灰 | カリウム、リン酸、カルシウム | テンサイに最も合います。カリウムの供給とpHの矯正を兼ねます | 1㎡あたり1、2握り。過剰だとpHが上がりすぎます |
| 完熟堆肥 | 各種の養分 | 元肥として十分に入れます | 必ず完熟したもの。未熟だと根が裂けます |
| 薄めた尿 | 窒素、カリウム | 水で10倍に薄め、生育初期にだけ与えます | 本葉6枚以降は与えません |
| 骨粉 | リン酸、カルシウム | 焼いて砕き、堆肥に混ぜます | 効果が遅いです |
| 貝殻・卵の殻 | カルシウム | 焼いて細かく砕きます | 酸性の矯正に使います |
| 海藻 | カリウム、微量元素、ホウ素 | 乾かして砕くか、水に浸した液を与えます | ホウ素を入手できる数少ない経路です |
| テンサイの葉と加工かす | カリウム、有機物 | 収穫後に畑へ戻します | カリウム循環の要です |

&nbsp;&nbsp;&nbsp;ホウ素が、災害時に最も厄介な問題です。ホウ素は微量元素なのでごく少量しか必要としませんが、なければ根の内部が黒く腐り、逆に多すぎると毒性が現れるという、適正な幅の狭い元素です。化学肥料がない状況でホウ素を得る現実的な経路は、海藻です。ワカメ、昆布、アオサのようなものを乾かして砕き、元肥に混ぜるか、水に浸した液を灌注すると、ホウ素とともにカリウムやほかの微量元素も一緒に入ります。海に近い地域では、この方法が特に有効です。内陸であれば、堆肥の材料を多様にすることが次善策です。

## 6. 播種

### 6-1. 時期

| 作型 | 播種時期（韓国） | 収穫時期（韓国） |
|---|---|---|
| 秋まき・越冬 | 9月中旬-10月上旬 | 翌年4-5月 |
| 春まき | 3月中旬-4月上旬 | 7-8月 |

&nbsp;&nbsp;&nbsp;秋まきの時期を逃してはいけません。早く播きすぎると、冬が来る前に育ちすぎて低温を感知し、翌年の春に花茎を立ててしまいます。これを抽だいといい、抽だいしたテンサイは、根の糖が花茎へ抜けてしまい、使えなくなります。遅く播きすぎると、冬を越せるだけの大きさに育たず、凍って枯死します。9月中旬から10月上旬という狭い窓は、この二つの危険の間で決まったものです。

### 6-2. 播種方法

| 項目 | 基準 | 理由 |
|---|---|---|
| 播種の深さ | 1.5-2.5cm | 深いと発芽が不良になります |
| 条間 | 30-40cm | 風通しと光合成を確保します |
| 株間（最終） | 10-15cm | 根が太くなる空間です |
| 播種量 | 1,000㎡あたり1-1.5kg | 間引くことを見込んで多めにまきます |
| 播種後 | 土を薄くかぶせ、軽く押さえて密着させます | 種子が浮いていると乾きます |
| かん水 | 発芽まで乾かさないようにします | 過湿は禁物です |

### 6-3. 種子の処理

| 方法 | 手順 | 効果 |
|---|---|---|
| 水に浸す | 1日水に浸してから播きます | 複合種子の殻が柔らかくなり、発芽が速まります |
| 温湯処理 | 50-55℃の湯に10-15分浸します | 表面の病原菌を減らします |
| 灰処理 | 種子に草木灰をまぶします | 消毒と乾燥を兼ねます |
| 選別 | 浮く種子を取り除きます | 中が空の種子を除きます |

&nbsp;&nbsp;&nbsp;複合種子は殻が厚くて硬く、発芽がそろわないことが、テンサイによくある問題です。1日水に浸けておくと、発芽が数日早まり、そろって出ます。ただし、水に浸した種子はすぐに播かなければならず、もう一度乾かして置くと、かえって発芽力が落ちます。温湯処理をする場合は、60℃を超えないように注意します。
