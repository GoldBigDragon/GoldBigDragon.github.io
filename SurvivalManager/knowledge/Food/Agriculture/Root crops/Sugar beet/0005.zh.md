## 13. 种根的维持与留种

### 13-1. 要花两年的工作

&nbsp;&nbsp;&nbsp;甜菜的自家留种等级为D。因为它是二年生作物，第一年形成根，第二年才开花结籽。要留种，就得把本来可以吃的根留着不吃，让它在冬天保持存活，次年春天再重新栽种。这一过程称为种根维持。它与马铃薯种薯的保管、木薯插穗的越冬性质相同，是甜菜实现自立的唯一瓶颈。

| 阶段 | 时期 | 内容 |
|---|---|---|
| 1. 选择种根 | 收获期 | 挑选最端正、最健康的根 |
| 2. 种根贮藏 | 冬季 | 埋在地窖或沙里，防止冻坏 |
| 3. 重新定植 | 次年春季 | 重新栽下，让根头微微露出地面 |
| 4. 抽薹·开花 | 春季-初夏 | 花茎抽高到1m以上 |
| 5. 种子成熟 | 夏季 | 放到穗子变褐变干为止 |
| 6. 采种与干燥 | 夏季 | 把种子抖落收集，在阴凉处彻底晾干 |
| 7. 保管 | 此后5年 | 密闭、凉爽、暗处 |

### 13-2. 种根的选择

| 项目 | 标准 | 理由 |
|---|---|---|
| 形状 | 笔直、不开裂的 | 性状会遗传给后代 |
| 大小 | 中等以上，但不要过大 | 过大的在贮藏中容易腐烂 |
| 糖度 | 切开尝过觉得甜的 | 先切开一株确认，其余的从该株周围挑选 |
| 伤 | 没有伤的 | 有伤的在贮藏中会腐烂 |
| 切叶 | 从根头处留3-5cm长 | 比食用的留得长，以保护生长点 |
| 须根 | 不要切断 | 切口会让病菌侵入 |
| 数量 | 所需量的2、3倍 | 冬季里总有一部分会坏掉 |

&nbsp;&nbsp;&nbsp;留作种根的根，切叶时要留得长一些。食用的留1-2cm，而种根要留3-5cm。因为根头部位的生长点一旦受损，次年春天就不会发芽。

### 13-3. 种根的贮藏

| 方式 | 条件 | 方法 |
|---|---|---|
| 窖藏 | 0-4℃，湿度90-95% | 竖着埋在湿润的沙或土里。让根头朝上 |
| 坑藏 | 0-5℃ | 按稻草、根、稻草、土的顺序堆成坟丘状，并留出通气口 |
| 原地越冬 | 韩国南部、济州岛 | 就留在田里，盖上厚厚的稻草。最省事 |
| 室内沙箱 | 0-5℃ | 适合少量 |

&nbsp;&nbsp;&nbsp;在韩国南部，不挖种根、直接留在田里的方法最可靠。甜菜能耐零下5℃，盖上20-30cm的稻草，通常就能度过韩国南部的冬天。完全没有挖出来贮藏过程中产生的伤口和损耗，是它的一大优点。韩国中部以北，这种方法有风险，必须挖出来放进地窖。

| 贮藏期间检查 | 内容 |
|---|---|
| 周期 | 每2周一次 |
| 检查事项 | 发软的、霉变、异味 |
| 措施 | 坏掉的立即取出。一个坏了会传染旁边的 |
| 干燥 | 沙子太干，就稍微洒点水 |
| 温度 | 不要降到0℃以下 |

### 13-4. 重新定植与留种

| 项目 | 标准 |
|---|---|
| 时期 | 在韩国为3月中旬-4月上旬，土地解冻之后 |
| 栽植深度 | 让根头微微露出地面 |
| 间距 | 50-60cm。花茎会长得很大，所以要宽 |
| 支撑 | 花茎长到1m以上会倒伏，所以要立支柱 |
| 开花 | 5-6月。靠风传粉 |
| 隔离 | 与莙荙菜、红菜头和其他甜菜品种保持远距离 |
| 成熟 | 放到穗子变褐变干为止 |
| 采种 | 把穗子捋下收集，在阴凉处彻底晾干 |
| 株数 | 至少要从10株以上一起收种 |

&nbsp;&nbsp;&nbsp;隔离和株数这两点尤其重要。甜菜是靠风传粉的异花授粉植物，附近的莙荙菜或红菜头开花时就会杂交，后代会出现意想不到的东西。商业上要设置数km的隔离距离，但在灾害情境下很难隔开那么远。现实的替代办法是错开时间，也就是同一年只让一个品种开花，莙荙菜和红菜头那一年不留种。

&nbsp;&nbsp;&nbsp;株数少的话，几代之内长势就会明显变差，因为异花授粉植物不耐近亲繁殖。原则是从10株以上、最好20株以上一起收种，并混在一起。不遵守这一点，5年之后就会遇到有种子可种、却长不好的局面。

### 13-5. 种子保管

| 项目 | 标准 |
|---|---|
| 干燥 | 在阴凉处彻底晾干。干到用手能掰断的程度 |
| 容器 | 密闭容器或玻璃瓶 |
| 干燥剂 | 把草木灰、木炭、生石灰用布包好一起放入 |
| 温度 | 凉爽、变化小的地方 |
| 光 | 完全暗处 |
| 寿命 | 常温密闭约5年 |
| 发芽确认 | 每年取几粒用湿布包起来，检查发芽率 |

> **种子寿命5年是甜菜最大的资产。这意味着不必每年留种，几乎抵消了二年生这一弱点。不过，在第5年到来之前，必须进行一次历时两年的留种。**

## 14. 毒性与注意事项

### 14-1. 根是安全的

&nbsp;&nbsp;&nbsp;甜菜在一般食用量下是安全的食物。它没有木薯的氰苷或马铃薯的龙葵素那样的毒性物质。生吃也不会中毒，也可以给孩子吃。

| 项目 | 内容 |
|---|---|
| 生食 | 可以。但质地坚硬且有土腥味，煮熟后吃更好 |
| 过量食用 | 糖分多，可能引起肚子不适。不是毒性 |
| 变质的根 | 变色或有异味就丢掉 |
| 变绿的肩部 | 带苦味，糖度低。切掉 |
| 心部发黑的 | 是缺硼。把那一部分挖掉，其余的可以吃 |

### 14-2. 对叶子要稍加注意

| 项目 | 内容 |
|---|---|
| 草酸 | 与莙荙菜一样含有草酸。焯水后倒掉焯水的水，就能减少 |
| 结石 | 有肾结石病史的人不要多吃 |
| 硝酸盐 | 施氮多的田里的叶子会积累硝酸盐。对幼儿尤其要注意 |
| 处理 | 在沸水中焯1-2分钟，倒掉焯水的水，草酸和硝酸盐都会减少 |
| 喂养家畜 | 突然大量喂叶子，牛羊会出问题。要逐渐增加 |

&nbsp;&nbsp;&nbsp;硝酸盐问题在灾害情境下尤其值得记住。没有化肥，往往就会频繁使用稀释尿液，而氮施得过多，叶子里就会积累硝酸盐。硝酸盐本身问题不大，但在体内转变成亚硝酸盐后，会降低血液运输氧气的能力。对幼儿更危险。只需焯水并倒掉焯水的水，就能去除相当一部分，所以叶子与其生吃，不如焯过再吃更安全。

### 14-3. 制糖加工过程中的注意事项

| 项目 | 内容 |
|---|---|
| 沸腾的糖液 | 沸点比水高、黏度大，烫伤会很深。要格外小心 |
| 溢出 | 熬煮途中会突然沸腾溢出。不要装得超过锅的2/3 |
| 糊底 | 浓度升高后锅底开始焦糊。必须不停搅拌 |
| 使用石灰 | 如果精制时用石灰，要避免接触眼睛和皮肤 |
| 发酵 | 浓度低的糖液几天就会发酵。如果不想发酵，就尽快熬浓 |
| 密封 | 把正在发酵的液体密封，容器会胀裂 |

## 15. 无冰箱贮藏

### 15-1. 贮藏的三个阶段

| 阶段 | 条件 | 期间 | 目的 |
|---|---|---|---|
| 1. 愈伤处理 | 10-15℃，湿度85-95%，黑暗、微弱通风 | 1-2周 | 封住伤口，减少水分损失 |
| 2. 正式贮藏 | 0-4℃，湿度85-95%，完全黑暗 | 3-4个月 | 降低呼吸，延缓糖的消耗 |
| 3. 检查 | 每2周1次 | 整个贮藏期间 | 防止一个烂的毁掉全部 |

&nbsp;&nbsp;&nbsp;甜菜贮藏中需要特别记住的是，贮藏期间糖会减少。根是活的组织，贮藏期间也在呼吸，并用自己体内贮存的糖作燃料。温度越高，呼吸越快，糖消失得也越快。0-4℃这个条件，是既不冻坏又能最大限度减缓呼吸的点。如果目的是制糖，就应缩短贮藏时间，收获后尽快加工更有利。

### 15-2. 无电力贮藏方式比较

| 方式 | 做法 | 温度 | 期间 | 优点 | 缺点 |
|---|---|---|---|---|---|
| 原地越冬 | 就留在田里，盖20-30cm稻草 | 地温 | 整个冬天 | 几乎不用劳动，糖度还会升高 | 韩国中部以北有冻坏的风险 |
| 窖藏 | 在排水良好的地面挖1.5m深，做出顶棚和通气口 | 0-4℃ | 3-4个月 | 最稳定 | 挖掘的劳动量大 |
| 坑·堆垛（clamp） | 挖30cm深，按稻草、根、稻草、土的顺序堆放 | 0-5℃ | 2-3个月 | 一天就能做好 | 一旦打开，很难再盖好 |
| 沙层贮藏 | 在箱子里一层干沙一层根地放 | 环境温度 | 1-2个月 | 防止腐烂传染 | 另外需要一个凉爽的位置 |
| 稻草·稻壳保温 | 在凉爽的室内用稻草包裹堆放 | 5-10℃ | 1个月 | 不需要设施 | 温度高会发芽 |

### 15-3. 坑藏的做法

| 步骤 | 内容 |
|---|---|
| 1 | 选一个不积水的高处。朝北的坡面为佳 |
| 2 | 挖一个直径1.5m、深20-30cm的浅坑 |
| 3 | 在底部铺10cm干稻草 |
| 4 | 把完成愈伤处理的根堆成坟丘状。高度不超过60cm |
| 5 | 用干稻草把整体盖20-30cm |
| 6 | 再在上面盖15-20cm土，拍实表面，让雨水流走 |
| 7 | 在顶上竖一束稻草做通气口。堵住的话，里面会腐烂 |
| 8 | 在四周挖排水沟 |

&nbsp;&nbsp;&nbsp;通气口是关键。根在贮藏期间也在呼吸，会释放热量、水蒸气和二氧化碳。完全密闭的话，里面温度升高、湿气积聚，几天之内整堆就会变软腐烂。顶上的稻草束既能让空气流通，又能挡住雨水。

### 15-4. 贮藏条件详解

| 条件 | 目标 | 超出范围时 |
|---|---|---|
| 温度 | 0-4℃ | 零下会冻坏变软。8℃以上会发芽，糖迅速减少 |
| 湿度 | 85-95% | 低则皱缩，高则长霉 |
| 光 | 完全黑暗 | 见光根头会变绿 |
| 通风 | 微弱而持续 | 堵住则积热积湿，风太强则失水变干 |
| 叶 | 切后留1-2cm | 留长了会继续生长消耗糖，留短了腐烂会从根头侵入 |
| 检查 | 每2周1次 | 一个烂了会迅速传染周围的 |

### 15-5. 通过加工实现超长期贮藏

| 方法 | 步骤 | 期间 | 备注 |
|---|---|---|---|
| 糖浆 | 榨汁后熬煮浓缩 | 1年以上 | 最实用。第16节会详细讨论 |
| 结晶食糖 | 把糖浆继续熬浓，使其结晶 | 数年 | 耗燃料多，但保管最容易 |
| 干片 | 切成薄片，彻底晒干 | 6个月-1年 | 用水泡发后使用，或直接嚼着吃 |
| 乳酸发酵 | 泡在2-3%的盐水里，室温放1-2周 | 数月 | 可以当小菜 |
| 醋 | 把汁发酵成酒，再进行醋酸发酵 | 数年 | 成为其他食物的保存手段 |
| 酒 | 直接把汁发酵 | 数月 | 兼作热量储存和消毒用 |

> **长期保存甜菜最可靠的办法，不是保住根，而是把它变成糖浆。根只能存4个月，糖浆则可以跨年。**
