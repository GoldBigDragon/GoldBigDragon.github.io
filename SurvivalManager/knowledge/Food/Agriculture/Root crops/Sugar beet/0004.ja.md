## 7. 水管理

### 7-1. 生育段階別の基準

| 時期 | 水管理 | 理由 |
|---|---|---|
| 播種-発芽 | 乾かないように保つ | 複合種子は水を十分に吸ってこそ、殻がほぐれます |
| 生育初期 | 自然の降水に任せ、乾燥時は補う | 根を深く伸ばすよう促します |
| 根の肥大期 | 乾かないよう十分に | この時期の乾燥は、収量と糖度をともに下げます |
| 収穫直前の2-3週間 | かん水を中止 | 糖度が上がり、貯蔵性がよくなります |
| 越冬期 | かん水しません | 凍結と融解を繰り返すと根が傷みます |

&nbsp;&nbsp;&nbsp;収穫直前のかん水中止は、糖度に直接影響します。水をやり続けると、根が水を含んで重さは増えますが、糖の濃度は薄まります。逆に2-3週間水を断つと、水分が減って糖の濃度が上がります。重さで売る作物なら損ですが、砂糖を得ることが目的なら得になります。災害時には後者です。

### 7-2. 水不足と水過多の症状

| 区分 | 症状 | 進行 | 対処 |
|---|---|---|---|
| 不足 | 日中に葉が垂れ、夕方に回復する | 初期 | マルチングを補強します |
| 不足 | 下の葉が黄色く枯れ、生育が止まる | 中期 | 畝の間に水を引きます |
| 不足 | 根が細く硬くなる | 深刻 | 収量と糖度がともに下がります |
| 不足後の給水 | 根が縦に裂ける | 問題 | 水分の供給を均一にしなければなりません |
| 過剰 | 下の葉が黄色くなり、根の上部が軟化する | 危険 | すぐに排水溝を掘ります |
| 過剰 | 根から悪臭、内部が茶色 | 根腐れ | その株を抜いて廃棄します |

&nbsp;&nbsp;&nbsp;根が裂ける現象は、たいてい水不足そのものではなく、水分の急激な変化によって生じます。日照りが続いたあとに突然大雨が降ると、内側の組織が急速にふくらみ、外側の皮がそれについていけずに裂けます。裂けた根は、その隙間から菌が入るため、貯蔵できません。マルチングで土壌水分の変動幅を小さくすることが、最も効果的な予防策です。

## 8. 栽培管理

### 8-1. 間引き - 省略できない作業

| 回 | 時期 | 作業 |
|---|---|---|
| 1回目 | 本葉2-3枚 | 株間3-5cmに間引きます |
| 2回目 | 本葉5-6枚 | 株間10-15cmに最終の間引きをします |

&nbsp;&nbsp;&nbsp;テンサイの種子は複数が固まった塊なので、1か所から2、3本の芽が一緒に出てきます。これをそのままにしておくと、互いに押し合いながら育って、すべて細く奇形になります。間引きはテンサイ栽培で最も重要な管理作業で、遅れれば遅れるほど、残す株の根まで傷みます。間引いた若い株は捨てずに、ナムル（和え物）にして食べます。フダンソウと同じ味です。

&nbsp;&nbsp;&nbsp;間引くときは、引き抜くよりも、はさみで地面の近くを切るほうがよいです。引き抜くと、隣の株の根まで揺らしてしまうからです。最終間隔の10-15cmは狭く見えますが、これより広げると、根が大きくなりすぎて、糖の濃度はかえって下がる傾向があります。

### 8-2. 土寄せ

| 時期 | 作業 | 効果 |
|---|---|---|
| 生育中に1-2回 | 根の上部に土を寄せます | 根が日光にさらされるのを防ぎます |
| 雨の後 | 現れた肩を覆います | 土が流れ去ったら、もう一度覆います |

&nbsp;&nbsp;&nbsp;テンサイの根は、育つにつれて肩の部分が地表面の上へ押し上げられてきます。その部分が日光を受けると緑色に変わりますが、緑色の部分は糖度が低く、苦みがあり、砂糖を抽出するときにシロップを濁らせます。土寄せはこれを防ぐ唯一の方法で、費用がまったくかからないうえに、糖の収率に直接影響する作業です。

### 8-3. その他の管理

| 作業 | 時期 | 内容 |
|---|---|---|
| 草取り | 生育初期 | 初期の生長が遅く、雑草に負けます |
| マルチング | 播種後、根づいてから | わらや落ち葉。水分の変動を減らして裂けを防ぎます |
| 葉の収穫 | 生育中期から | 下の葉を少しずつ摘みます。やりすぎると糖度が落ちます |
| 越冬時の保温 | 11-12月 | わらや落ち葉で肩を覆います |
| 抽だい株の除去 | 春 | 花茎が立った株は根が使えないので、先に掘り取ります |

## 9. 病害虫

### 9-1. 主な病害

| 病名 | 症状 | 条件 | 薬を使わない対応 |
|---|---|---|---|
| 根腐れ病 | 根が軟らかく腐り、悪臭がします | 過湿、排水不良 | 排水の改善が唯一の対策です |
| 褐斑病 | 葉に褐色の斑点ができて広がります | 高温多湿 | 風通しの確保、病葉の除去、3年以上の輪作 |
| うどんこ病 | 葉の表面が白い粉で覆われます | 乾燥して日較差が大きいとき | 牛乳の10倍希釈液、重曹の希釈液 |
| 根腐病 | 根の内部が黒く腐ります | ヒユ科の連作地 | 3年休作。フダンソウ、ビーツとも続けて植えません |
| 心腐れ病 | 根の内部が黒く、新しい葉が奇形になります | ホウ素欠乏 | 病気ではありません。海藻と堆肥の多様化でホウ素を補います |

&nbsp;&nbsp;&nbsp;最後の行が重要です。心腐れ病は名前に「病」とついていますが、病原菌はありません。ホウ素が足りず、組織が正常につくられないために生じる、純粋な欠乏症状です。薬を散布しても何の役にも立たず、ホウ素を供給することだけが対策です。これを病気と誤認して、畑を移したり種子を替えたりすることがよくあります。

### 9-2. 主な害虫

| 害虫 | 被害 | 薬を使わない対応 |
|---|---|---|
| アブラムシ類 | 汁を吸い、ウイルスを媒介します | 石けん水の噴霧、テントウムシと寄生バチの保護、窒素過多の回避 |
| シストセンチュウ | 根に寄生して生育が止まります | 治療法はありません。非宿主作物で何年も輪作 |
| 根菜類の害虫 | 根に穴をあけます | 抵抗性系統と早まき。10月以前に収穫すれば、被害は1%程度 |
| ネキリムシ | 若い株の根元を切ります | 夜に捕まえます。根元に灰を巻きます |
| ハムシ | 葉をかじります | 水洗い、手で捕まえる |

&nbsp;&nbsp;&nbsp;防除自立度Aという等級の根拠が、この表の3行目にあります。抵抗性系統を使って播種を前倒しすれば、主要な害虫の発生を90%以上減らせ、10月以前に収穫を終えれば、被害は1%程度にとどまるという実証があります。薬がない状況で、播く時期と掘る時期を調整するだけで大部分を解決できるという意味であり、これはジャガイモの疫病のように、予防しか手立てのない病気とは根本的に異なります。

&nbsp;&nbsp;&nbsp;ただし、シストセンチュウは例外です。一度入り込むと土壌に何年も残り、薬剤でも防除が困難です。唯一の対策は、その畑にヒユ科の作物を何年も植えないことです。テンサイを植える前に、その畑の履歴を確認しなければならない理由です。

### 9-3. 薬を使わない防除の原則

| 原則 | 内容 |
|---|---|
| 輪作 | ヒユ科の作物は3年以上の間隔をあけます。フダンソウとビーツも同じ科です |
| 排水 | 根腐れの唯一の予防策です。畝と排水溝をきちんとつくります |
| 時期の調整 | 早まきと早採りで害虫の発生期を避けます |
| 健全な種子 | 温湯処理と選別を行います |
| 風通し | 間引きで株の間に空気を通します |
| 残さの処理 | 病気の葉と根は畑に置かず、焼くか深く埋めます |

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 確認方法 | 天然材料での対処 |
|---|---|---|---|
| 葉全体が黄色く、株が小さい | 窒素欠乏 | 下の葉から始まります | 完熟堆肥、尿の10倍希釈液。生育初期のみ |
| 葉の縁が茶色く焼ける | カリウム欠乏 | 根の肥大期に多く見られます | 草木灰 |
| 生育不振、葉が濃い紫色 | リン酸欠乏 | 低温期と酸性土壌でよく見られます | 骨粉、草木灰 |
| 新しい葉が奇形で、根の内部が黒く腐る | ホウ素欠乏 | 心腐れ病と呼ばれます | 乾燥海藻、堆肥の多様化 |
| 葉脈の間が黄色くなる | マグネシウム欠乏 | 下の葉から始まります | ドロマイト（白雲石）、堆肥 |
| 若い葉が黄色く、葉脈だけが緑 | 鉄欠乏 | 土壌pHが高すぎるとき | 灰の使用を減らし、有機物を増やします |
| 葉だけが茂り、根が小さく、糖度が低い | 窒素過剰 | 葉の色が濃すぎます | 窒素を断ち、草木灰でカリウムを補います |
| 根が裂ける | 水分の急変、未熟な堆肥、石 | 裂け目が滑らかです | マルチングで水分を均一にします |

&nbsp;&nbsp;&nbsp;テンサイで最も注意すべきなのは、窒素過剰です。ほかの作物では葉が茂ることは欠点ではありませんが、テンサイではそのまま砂糖の損失になります。植物が成長を続けなければならないと判断する限り、糖は根に下りていかないからです。特に、薄めた尿のように窒素が速く効く資源を後半に使うと、葉だけが濃い緑色に茂り、秋に掘ってみると糖度が半分に落ちています。

> **テンサイの窒素施肥は、本葉5-6枚で終わります。それ以降の窒素は、肥料ではなく損失です。**

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 対象 | 理由 |
|:---:|---|---|
| 良い | マメ科の作物 | 窒素を固定して、次の作期のテンサイに残します |
| 良い | タマネギ、ニンニク | 害虫を忌避させ、根の深さが違うので競合が少なくなります |
| 良い | サンチュ（リーフレタス）、ホウレンソウ | 初期に畝の間を覆って雑草を抑えます |
| 普通 | ハクサイ、ダイコン | 養分の競合があります |
| 避ける | フダンソウ、ビーツ、飼料用ダイコン | 同じ科で同じ種です。病気を共有し、交雑します |
| 避ける | 同じ場所での連作 | 根腐病とセンチュウが蓄積します |

### 11-2. 輪作の順序

| 順序 | 作物 | 役割 |
|---|---|---|
| 1年目 | テンサイ | 窒素とカリウムを大量に持ち出します |
| 2年目 | マメ科（ダイズ、アズキ、エンドウ） | 窒素を回復させます |
| 3年目 | 葉菜類またはタマネギ類 | 残った窒素を使います。ヒユ科ではありません |
| 4年目 | 再びテンサイ | 3年以上の間隔を守ります |

&nbsp;&nbsp;&nbsp;連作適応性Bは、3年の休作を意味します。この間隔を守らないと、根腐病とシストセンチュウが蓄積し、数年後に突然、畑全体が崩壊します。また、この間隔を数えるときには、フダンソウとビーツを同じ作物として扱わなければなりません。3つは学名が同じ一つの種なので、病原菌にとっては区別がつきません。家庭菜園でフダンソウを植えていた場所に翌年テンサイを植えることがよくありますが、これは同じ場所にテンサイを続けて植えたのと変わりません。

## 12. 収穫

### 12-1. 時期の判断

| 用途 | 時期 | 判定基準 |
|---|---|---|
| 若い葉菜 | 播種後30-40日 | 葉の長さ15-20cm |
| 間引き株 | 本葉2-6枚 | ナムルに使います |
| 根（春まき） | 播種後90-150日 | 根の直径5-10cm |
| 根（越冬栽培） | 翌年4-5月 | 糖度と収量が最大です |
| 抽だいの兆しが見えたとき | 直ちに | 花茎が立つと糖が抜けます |

&nbsp;&nbsp;&nbsp;越冬栽培で収穫時期を判断する基準は、花茎です。春になって気温が上がると、テンサイは2年目に入って花茎を立て始めますが、その瞬間から、根に貯蔵された糖が花茎と種子をつくるのに使われ、急速に減っていきます。株の中心から葉が上へ伸び上がり、茎が太くなる兆しが見えたら、それが最後のタイミングです。済州島の試験で4月の収穫が最適という結果が出たのも、この限界の直前だからです。

### 12-2. 収穫のコツ

| 順序 | 内容 |
|---|---|
| 1 | 晴れて乾燥した日を選びます。濡れたまま貯蔵すると腐ります |
| 2 | 株の脇をホミ（手鍬）で掘り、土を緩めます |
| 3 | 葉をまとめて握り、まっすぐ上へ引き抜きます。ひねりません |
| 4 | 葉を切ります。根の上部から1-2cmを残します |
| 5 | 細根と尾はそのままにします。切るとそこから菌が入ります |
| 6 | 土を軽く払い落とします。水で洗いません |
| 7 | 葉は野菜として使うか、畑に戻します |

&nbsp;&nbsp;&nbsp;葉を切るときに、あまり根元ぎりぎりで切ると、根の頭の部分が露出して、そこから腐敗が始まります。逆に、長く残しすぎると、葉が伸び続けて根の糖を消耗します。1cmから2cmを残すのが、この二つの危険の間の適切な点です。

### 12-3. 収穫後の分類

| 区分 | 処理 |
|---|---|
| 大きくて傷のないもの | 室（むろ）貯蔵に回します |
| 裂けたり傷があるもの | 真っ先に砂糖の抽出に使います。貯蔵しません |
| 緑色に変わった肩 | 切り落とします。シロップを濁らせ、苦みを出します |
| 小さいものや奇形のもの | 食用や家畜の飼料に使います |
| 最もまっすぐで大きいもの | 種根として別に集めます |
| 葉 | ナムル、汁物、漬物。余れば畑に戻します |
