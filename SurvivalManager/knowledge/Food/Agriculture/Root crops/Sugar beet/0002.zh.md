### 1-3. 如何解读优势

&nbsp;&nbsp;&nbsp;甜菜最大的优势是种子寿命为S。这张表中收录的薯类（块茎/块根）大多数种子寿命为E。马铃薯要保护种薯，美洲土圞儿和菊芋要保护块茎，木薯要保护插穗，它们每个冬天都得保持存活状态，其中只要有一样死了，次年就没有收成。而甜菜可以把干燥的种子装进陶罐，在常温下放置5年。在不知道灾害何时降临的情况下，它是为数不多可以提前备好、需要时取出来播种的作物之一。

&nbsp;&nbsp;&nbsp;温度适应幅度SS和耐寒性A同样很有价值。它在5-28℃的范围内都能生长，能耐零下5℃的低温。这意味着，在韩国南部秋季播种、越冬后于次年春季收挖的栽培方式是可行的；实际上，在济州岛用这种方式栽培，有糖度升到20.8Brix、产量也比12月收获增加34%的记录。能把冬季田地闲置的时间用于粮食生产，在土地面积不足的情况下尤其有意义。

&nbsp;&nbsp;&nbsp;防治自立度A也是值得关注的项目。在这张表里，薯类中拿到A的情况很少见。依据是实证研究表明：把抗性品系与提早播种结合起来，可将主要害虫的发生量降低90%以上，10月之前收获，危害只停留在1%左右。也就是说，即使没有药剂，仅靠调整种植时间，就能应对相当一部分问题。这与马铃薯面对疫病时束手无策形成对照。

### 1-4. 如何解读弱点

&nbsp;&nbsp;&nbsp;自家留种D是最实际的弱点。甜菜是二年生作物，第一年形成根，第二年抽出花茎并结籽。要留种，就不能把根吃掉，而要让它在冬天保持存活，次年春天重新栽下去。种子寿命达5年这一事实在相当程度上缓解了这个弱点，但5年之后终究还是要留种，而那时需要进行跨越两年的作业。第13节会详细讨论这个问题。

&nbsp;&nbsp;&nbsp;微量营养素D是甜菜不能当作主食的原因。即使吃到能满足热量需求的量，超过推荐量10%的营养素也只有7种。蛋白质密度同样是C，略低于需求线。甜菜是提供热量和甜味的作物，而不是提供营养的作物。不过，如果把叶子也一起吃，情况就不同了。甜菜的叶子与莙荙菜是同一种东西，是富含维生素和矿物质的蔬菜。

&nbsp;&nbsp;&nbsp;施肥需求C意味着，与其他薯类相比，它对肥料的需求更高。此外，它还单独需要硼。缺硼时，根内部会发黑腐烂，形成心腐病；这并非病原菌所致，而是纯粹的缺素症状。在没有化肥的情况下，补充硼的办法有限，这是种植甜菜隐藏的难题。

&nbsp;&nbsp;&nbsp;耐储性C也需要一并考虑。放进地窖可以贮存3到4个月，但比马铃薯短，而且贮藏期间糖会慢慢消耗。也就是说，放得越久，糖就越少。如果目的是制糖，收获后尽快加工更有利。

> **甜菜既是热量作物，也是甜味剂作物。而在灾害情境下，甜味剂本身就能拓宽贮藏技术的范围。**

## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

&nbsp;&nbsp;&nbsp;甜菜是苋科（Amaranthaceae）甜菜属（Beta）的二年生草本。它与莙荙菜、红菜头（红甜菜）、饲料用萝卜全都是同一个种，是人类根据想要培育哪个部位而挑选分化出来的品系。莙荙菜是培育叶子的结果，红菜头是培育颜色和味道的结果，甜菜则是培育根中糖分的结果。它与菠菜同科，但不同属。

&nbsp;&nbsp;&nbsp;这一事实在实际操作中有两层含义。第一，甜菜的叶子与莙荙菜的叶子相同，可以直接食用。即使在培育根的期间，也可以摘下下部的叶子当蔬菜，填补到收获为止的漫长空档。第二，它与莙荙菜和红菜头可以杂交，并共有相同的病害。留种时必须让它们彼此远远隔开种植，轮作时也不能把它们连续种在同一块地里。

&nbsp;&nbsp;&nbsp;它的野生祖先是地中海和大西洋沿岸的海滨植物。耐盐碱和海风，在凉爽的气候下生长良好，怕夏季高温。甜菜超过25℃就生长迟缓，并在凉爽的秋季集中积累糖分，原因就在这里。

### 2-2. 外形

| 器官 | 特征 |
|---|---|
| 叶 | 宽卵形，有光泽，叶脉粗而明显。形状与莙荙菜相同 |
| 叶柄 | 肥厚多汁。可以像莙荙菜一样食用 |
| 根（食用部分） | 白色的主根，呈纺锤形。直径10-15cm，长30cm以上 |
| 根尖 | 细细地延伸下去，深入1m以上 |
| 花茎 | 第2年抽出，高1m以上 |
| 花 | 绿色，细小不显眼，呈穗状着生。靠风传粉 |
| 果实 | 多粒种子聚结硬化而成的复合种子（种球） |

&nbsp;&nbsp;&nbsp;复合种子这一点对播种很重要。看上去像一粒种子的东西，实际上是两三粒种子聚结成的团块，种在一处就会同时冒出好几株芽。所以甜菜必须间苗，不间苗的话，根会互相挤压，最后全都长得细小。商品种子中也有把这种团块磨开、制成单粒的，但自家留种的种子仍然是复合种子。

&nbsp;&nbsp;&nbsp;根是白色这一点也值得记住。它容易与红菜头混淆，而红色素在提取糖的过程中会把糖浆染成暗红色，并留下土腥味。如果目的是制糖，就必须使用白甜菜品系。

### 2-3. 生育阶段

| 阶段 | 时期 | 关键生理 | 重要营养 |
|---|---|---|---|
| 发芽·幼苗期 | 播种后4周以内 | 复合种子会同时长出多株芽 | 磷、氮 |
| 营养生长期 | 4-10周 | 叶片展宽，根开始变粗 | 氮 |
| 根膨大期 | 10-16周 | 根开始快速膨大 | 钾、硼 |
| 糖分积累期 | 16-22周 | 叶片制造的糖以蔗糖形式积累在根中 | 钾，抑制氮 |
| 成熟·收获期 | 收获之前 | 糖度达到最高 | 停止灌溉 |
| 越冬（越冬栽培） | 冬季 | 经历低温，糖度进一步上升 | - |
| 抽薹·开花（第2年） | 次年春季 | 花茎抽出，根中的糖被消耗 | - |

> **氮肥用在前期，钾肥用在后期。糖分积累期如果氮还有剩余，植株就会不断长叶子，而不把糖输送到根里。这是种植甜菜时最常见的失败。**

&nbsp;&nbsp;&nbsp;弄清糖是什么时候积累的，就能看出栽培的要领。叶片通过光合作用制造糖，这些糖要么用于叶片自身的生长，要么向下运到根里贮存。植株如果判断自己还需要生长，糖就流向叶片；如果判断没有必要再长，糖就流向根。氮充足时，植株会一直想长；天气转凉、氮减少后，就转向贮存。秋季栽培和越冬栽培的糖度偏高，原因就在这里。

### 2-4. 每100g营养

| 营养素 | 含量 | 备注 |
|---|:---:|---|
| 热量 | 43-77kcal | 因品种和栽培条件差异很大 |
| 水分 | 约78g | 其余大部分是糖 |
| 碳水化合物 | 10-20g | 几乎全部是蔗糖 |
| 蔗糖（食糖） | 14-20g | 这是被提取的对象。越冬栽培时在20Brix以上 |
| 蛋白质 | 0.8-1.8g | 含量少 |
| 脂肪 | 0.08-0.2g | 几乎没有 |
| 钾 | 含有 | 根和叶中都很多 |
| 维生素C | 含有 | 加热会减少 |

&nbsp;&nbsp;&nbsp;甜菜的特别之处在于所贮存糖的形态。马铃薯和木薯以淀粉形式贮存，而甜菜贮存的是蔗糖，也就是我们所说的食糖这种物质本身。要把淀粉变成糖，需要酶或酸，而甜菜只要榨出汁、把水分蒸发掉就行。在灾害情境下能够自给甜味剂的几乎唯一的途径，就从这里打开。

&nbsp;&nbsp;&nbsp;叶子也需要一并考虑。甜菜叶与莙荙菜相同，每100g含有相当多的维生素A和K、铁、镁。根在微量营养素上只有D的弱点，叶子在很大程度上弥补了这一点。在培育根的期间，一点一点摘下部叶片来吃，从播种到收获的五个月里都能有蔬菜可吃。不过，叶子摘得太多，光合作用面积会减少，糖度就会下降。
