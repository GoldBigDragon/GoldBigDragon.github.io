## 16. 砂糖の抽出と調理

### 16-1. 食用として食べるとき

| 方法 | 燃料消費 | 手順 | 備考 |
|---|:---:|---|---|
| 茹でる | 中程度 | 皮つきのまま水に入れて30-40分 | 皮は火が通ったあと、手でむけます |
| 蒸す | 少ない | 水を少し入れて35-45分 | 糖が水に流れ出しません |
| 細かく切って茹でる | 少ない | 1-2cmに切れば15-20分 | スープやおかゆに入れます |
| 余熱調理 | 非常に少ない | 15分煮立てたあと火を止め、布で包んで1時間 | 燃料を半分以下に減らせます |
| 灰焼き | 非常に少ない | 熱い灰に埋めて40-50分 | 甘みが濃くなります |
| 乾燥片 | 少ない | 水で戻してすぐ使います | あらかじめ乾燥させておけば、食事のたびに燃料を節約できます |
| 葉 | 非常に少ない | 沸騰した湯で1-2分湯通しします | 湯通しした湯は捨てます |

&nbsp;&nbsp;&nbsp;茹でるより蒸すほうがよい理由は、テンサイでとりわけはっきりしています。根の糖は水によく溶けるため、茹でるとその糖のかなりの部分が湯に流れ出てしまいます。ゆで汁をスープとして一緒に使うなら問題ありませんが、捨てるなら甘みと熱量を一緒に捨てることになります。蒸せば、その損失はありません。

### 16-2. 砂糖はどのようにして得られるのか

&nbsp;&nbsp;&nbsp;テンサイの根は、重さの14-20%がショ糖、つまり砂糖そのものです。残りの大部分は水で、一部が繊維質です。したがって、砂糖を得る作業は化学的な変換ではなく、物理的な分離です。細胞から糖を取り出し、その水分を飛ばし、残ったものを固める、この三つがすべてです。デンプンを糖に変えなければならない穀物やジャガイモとは決定的に異なる点です。

| 段階 | 作業内容 | 難しさ |
|---|---|---|
| 1. 細切り | 細胞を開いて、糖が出てくる通り道をつくります | 簡単です |
| 2. 抽出 | 水で糖を引き出します | 温度管理が必要です |
| 3. 圧搾 | 残った汁を搾ります | 力が要ります |
| 4. 清澄 | 不純物を取り除きます | 材料が必要です |
| 5. 煮詰め | 水分を飛ばします | 燃料を最も多く消費します |
| 6. 結晶化 | 砂糖を固めます | 技術と時間が必要です |
| 7. 糖蜜の分離 | 結晶と残りの液を分けます | 道具が必要です |

### 16-3. 細切りと抽出

| 項目 | 基準 | 理由 |
|---|---|---|
| 下処理 | 土を洗い落とし、緑色の肩の部分とひげ根を切り落とします | 苦みと土臭さの原因になります |
| 皮 | 薄くむくか、そのまま使います | むくと液が澄み、むかないと収率が上がります |
| 切る太さ | 厚さ2-3mmの細切り | 薄いほど糖が早く出ます |
| 抽出に使う水の温度 | 70-75度 | 最も重要な数字です |
| 抽出時間 | 40分-1時間 | 細切りが柔らかくなり、水が甘くなるまで |
| 水の量 | 細切りがかぶる程度だけ | 水が多いと、あとで飛ばす水が増えます |
| かき混ぜ | ときどきかき混ぜます | 均一に出ます |

&nbsp;&nbsp;&nbsp;70-75℃という温度は、偶然決まったものではありません。この温度で細胞膜が変性して糖が自由に出てきますが、組織そのものはまだ崩れません。80℃を超えるとペクチンが溶け出して汁が粘り、濾せなくなります。60℃を下回ると細胞膜がそのまま残って糖がなかなか出ず、おまけに雑菌が繁殖します。温度計がなければ、水から湯気が立っているもののまだ沸騰していない状態、指を入れると熱くてすぐ引っ込めてしまう程度が、その近辺です。煮立たせてはいけません。

> **糖を引き出す水は煮立てません。煮立てると汁が粘って濾せなくなり、色や臭いも悪くなります。**

### 16-4. 水を節約する向流抽出

&nbsp;&nbsp;&nbsp;ここで、燃料を決定的に節約できるコツが出てきます。切りたての細切りに真水を注ぐと薄い汁が出ますが、その薄い汁の水分をあとですべて飛ばさなければなりません。そこで、前の回に出た汁を次の回の抽出液として使えば、濃度がどんどん上がっていきます。

| 手順 | 内容 |
|---|---|
| 1 | 最初の回は真水で抽出します。薄い汁が出ます |
| 2 | その汁を捨てずに、次の回の新しい細切りに注ぎ、再び70-75℃に温めます |
| 3 | 同じ汁で三回から四回まで繰り返します |
| 4 | 回を重ねるほど汁が濃くなります |
| 5 | 十分に濃くなったら、それだけを煮詰めます |
| 6 | 最後に残った細切りは新しい水でもう一度すすぎ、その水を次の最初の回に使います |

&nbsp;&nbsp;&nbsp;この方式は、工業プロセスの原理と同じです。同じ量の砂糖を得ながら、飛ばすべき水の量を半分以下に減らすことができ、その分だけ薪が少なくて済みます。道具が増えるわけでもなく、ただ順序を変えるだけなので、災害時には必ず取り入れるべきコツです。

### 16-5. 圧搾と搾りかすの処理

| 項目 | 内容 |
|---|---|
| 圧搾 | 抽出を終えた細切りを布で包み、力いっぱい搾ります。てこや石で押さえてもかまいません |
| 回収 | 残っていた汁がかなりの量出ます。省くと損失が大きくなります |
| 搾りかす | 繊維質と残糖が残っています |
| 家畜の飼料 | 牛、豚、鶏とも、よく食べます。立派な飼料になります |
| 堆肥 | 飼料に使わないなら、畑に戻します |
| 発酵 | 乳酸発酵させれば、冬の飼料として保存できます |

### 16-6. 清澄――不純物を取り除く

&nbsp;&nbsp;&nbsp;搾った汁には、糖のほかに、タンパク質、ペクチン、有機酸、土、色素が混ざっています。これらを取り除かないと、シロップは黒く苦くなり、結晶もできにくくなります。家庭で使える方法は三つです。

| 方法 | 手順 | 効果 | 材料の確保 |
|---|---|---|---|
| 泡の除去 | 煮詰めている間ずっと、表面に浮く茶色い泡をお玉ですくい取ります | 基本であり、必須です | 不要 |
| 石灰処理 | 消石灰を少量溶いてpHを上げ、温めたあと沈殿させて濾し取ります | 最も効果が大きいです | 貝殻やカキ殻を強火で焼いて生石灰をつくり、水に浸すと消石灰になります |
| 卵白 | 冷たい汁に卵白を溶き入れ、ゆっくり温めると、卵白が固まりながら不純物を抱き込んで浮いてきます。それをすくい取ります | 中程度 | 卵が必要です |
| 布濾し | 目の細かい布で何度も濾します | 土やかすの除去 | 不要 |
| 草木灰の灰汁 | 草木灰を水に浸した澄んだ上澄みを少量使います | 補助的です | 手軽です |

&nbsp;&nbsp;&nbsp;石灰処理は工業プロセスの核心ですが、家庭でも可能です。貝殻やカキ殻を薪の火の中で真っ赤になるまで熱すると生石灰になり、そこに水を注ぐと熱を出しながら消石灰に変わります。これを水に溶いて澄んだ上澄みだけを取り、汁に少しずつ加えると、タンパク質とペクチンが凝集して沈みます。ただし、加える量が多すぎると苦みと石けんのような味が残るため、少量ずつ加えながら状態を見ます。石灰を加えたあと、炭火の煙を管で導いて液の中に通すと、炭酸カルシウムができ、不純物を抱き込んで沈みます。これが工業プロセスにおける炭酸化の段階です。

| 注意 | 内容 |
|---|---|
| 草木灰の灰汁の入れすぎ | カリウム塩が残って結晶化を妨げます。少量だけ使います |
| 石灰の入れすぎ | 苦みと異臭が残ります |
| 生石灰の取り扱い | 水に触れると熱くなります。目や皮膚につかないようにします |
| 限界 | 家庭で完全な白砂糖をつくるのは困難です。土臭さと色がある程度残ります |

### 16-7. 煮詰め――燃料を最も多く消費する段階

| 項目 | 内容 |
|---|---|
| 道具 | 浅くて広い鍋や釜。表面積が広いほど早く蒸発します |
| ふた | 開けておきます。蒸発が目的だからです |
| 火 | 最初は強く、とろみが出たら弱く |
| かき混ぜ | 濃度が上がったら、絶えずかき混ぜなければなりません。底が焦げます |
| 入れる量 | 鍋の3分の2を超えないようにします。急に吹きこぼれます |
| 泡 | すくい取り続けます |
| シロップの完成 | スプーンから糸を引くように垂れ落ちます。糖度は約70% |
| やけど注意 | 煮立った糖液は水より高温で粘り気が強く、やけどが深くなります |

#### 燃料の計算

| 項目 | 数値 |
|---|:---|
| 水1Lを沸かして飛ばすのに必要な熱 | 約620kcal（加熱80 + 蒸発540） |
| 乾いた薪の熱量 | 1kgあたり約3,500-4,000kcal |
| 開放型かまどの熱効率 | 5-15% |
| 薪1kgで実際に使える熱 | 約175-600kcal |
| 水1Lを飛ばすのに要する薪 | 約1-3.5kg |
| 砂糖1kgを得るために飛ばすべき水 | 約4.5-5L |
| 砂糖1kgあたりの薪 | 約5-15kg |

&nbsp;&nbsp;&nbsp;この表がテンサイ加工の現実です。砂糖1kgに薪5-15kg。冬の一シーズンの暖房と煮炊きに使う薪を考えると、決して軽くない量です。だから、燃料を節約する方法が、手順と同じくらい重要です。

| 節約方法 | 内容 |
|---|---|
| 向流抽出 | 飛ばす水の量そのものを半分に減らします。最も効果が大きいです |
| 浅くて広い容器 | 蒸発面積が広ければ、同じ熱でより多く飛ばせます |
| 風よけ | かまどの周りを石や土でふさいで、熱が逃げるのを減らします |
| 鍋を複数使う | 一つの火の上に並べて、同時に煮詰めます |
| ほかの調理の余熱 | ご飯を炊いたあとの残り火に、そのまま載せておきます |
| 日光による予備濃縮 | 浅い黒い容器に汁を入れ、布をかぶせて日なたに置きます。数日かけて自然に濃くなります |
| 凍結濃縮 | 次の項目を参照します |

### 16-8. 燃料を使わず濃縮する方法――凍結濃縮

&nbsp;&nbsp;&nbsp;冬に使える方法で、薪をまったく使いません。原理は単純です。砂糖水が凍るとき、先に凍るのは純粋な水で、糖は凍っていない液体のほうに残ります。したがって、氷を取り除けば、残った液の糖濃度が上がります。

| 手順 | 内容 |
|---|---|
| 1 | 汁を浅くて広い容器に注ぎます |
| 2 | 氷点下の夜の間、外に出しておきます |
| 3 | 表面と縁に氷ができます。これはほぼ純粋な水です |
| 4 | 朝、氷を取り除いて捨てます |
| 5 | 残った液は、より濃くなっています |
| 6 | 何晩か繰り返します |

| 項目 | 内容 |
|---|---|
| 長所 | 燃料がまったくかかりません |
| 限界 | 濃度が上がるほど凝固点が下がり、それ以上は凍らなくなります。おおよそ半分程度まで |
| その後 | それ以降は火で煮詰めます。飛ばす水が大きく減っています |
| 条件 | 氷点下の夜が何日も続く地域でのみ可能です |
| 注意 | 取り除いた氷にも、わずかな糖が残っています。溶かして、次の回の抽出水に使います |

> **冬のある地域でテンサイを加工するなら、秋に収穫し、汁を搾って冬の夜に凍らせて濃縮したうえで、春に煮詰める方式が、燃料の使用量を最も少なくできます。**

### 16-9. 結晶化と糖蜜の分離

| 手順 | 内容 |
|---|---|
| 1 | シロップをさらに煮詰めます。スプーンですくって冷水に落としたとき、柔らかい塊にまとまる程度 |
| 2 | 火から下ろし、容器ごと涼しい場所に置きます |
| 3 | すでにつくった砂糖があれば、数粒まきます。結晶の種になります |
| 4 | 冷める間、ゆっくりかき混ぜます。結晶が均一に育ちます |
| 5 | 数時間から数日かけて結晶ができます |
| 6 | 結晶と液を布袋に入れて吊るします。数日かけて糖蜜が抜け出ます |
| 7 | 押して搾ればもっと早く抜けますが、結晶も一緒に砕けます |
| 8 | 残った結晶を広げて完全に乾かします |

| 産物 | 性質と用途 |
|---|---|
| 結晶砂糖 | 茶色みを帯びています。保存が最も簡単で、かさが小さいです |
| 糖蜜 | 黒くて濃いシロップです。糖が20-30%残っています |
| 糖蜜の用途 | 調味、家畜の飼料、酒や酢の原料、酵母の培養 |

### 16-10. 結晶まで進めるか、シロップで止めるか

| 比較 | シロップ | 結晶砂糖 |
|---|---|---|
| 追加の燃料 | なし | さらに煮詰める必要があります |
| 技術 | 簡単です | 温度と冷却の管理が必要です |
| 道具 | 鍋があれば足ります | 袋、濾し枠、時間が必要です |
| 損失 | ありません | 糖の20-30%が糖蜜として抜けます |
| 保存 | 密閉すれば1年以上 | 数年 |
| かさと重さ | 大きいです | 小さいです |
| 用途 | 甘味づけ、漬け込み、保存、発酵のすべてが可能 | 同じです |

&nbsp;&nbsp;&nbsp;災害時の答えは、おおむねシロップです。シロップでも、甘味づけ、果物の漬け込み、保存、発酵がすべて可能で、損失がなく、技術も道具も少なくて済みます。結晶砂糖が有利なのは、長く運ばなければならないときや、非常に長く備蓄しなければならないときです。ただし、シロップは糖度が60-65%を下回ると発酵したりカビが生えたりするため、十分に煮詰めて70%近くまで上げておく必要があります。

### 16-11. 収量と甘味料の使い道

| 原料 | 産物 |
|---|---|
| テンサイ100kg | 汁70-80L、糖12-15kg |
| その汁 | シロップ約18-21kg（糖度70%） |
| そのシロップ | 結晶砂糖8-12kgと糖蜜5-8kg |
| 搾りかす | 家畜の飼料または堆肥 |

| 用途 | 内容 |
|---|---|
| 熱量 | 最も速く吸収される熱量源です |
| 保存 | 糖度60%以上では、細菌やカビが育ちません。果物の漬け込みやジャム |
| 発酵 | 酒や酢の原料になります。酢はさらに、ほかの食品の保存手段になります |
| 士気 | 飢えた状況では、甘みは、ほかの何ものにも代えがたい慰めです |
| 交換 | 物流が途絶えた状況では、甘味料は交換価値が高くなります |

### 17-1. 忘れてはならない五つのこと

| 項目 | 内容 |
|---|---|
| 窒素は本葉6枚まで | それ以降の窒素は葉だけを育て、砂糖を減らします |
| 間引きを先延ばしにしません | 多胚種子なので、複数の芽が一緒に出ます。間引かないと、すべて小ぶりになります |
| 越冬栽培が有利です | 韓国南部では、秋に植えて翌春に掘ると、糖度も収量も最大になります |
| 種根は倍の数を残します | 冬の間に一部は必ず傷みます。採種には10株以上が必要です |
| 煮詰める前に濃縮します | 向流抽出と凍結濃縮で飛ばす水を減らせば、薪が半分になります |
