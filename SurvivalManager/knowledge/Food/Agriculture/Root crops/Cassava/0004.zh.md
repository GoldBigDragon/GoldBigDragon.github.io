## 7. 水分管理

### 7-1. 各生长阶段标准

| 时期 | 水分管理 | 理由 |
|---|---|---|
| 扦插后即刻 | 充分浇透 | 成活前仅靠贮存养分支撑，干燥就会枯死 |
| 成活-营养生长期 | 交给自然降水 | 耐旱性强，一般干旱都能承受 |
| 块根膨大期 | 仅在严重干旱时补水 | 这一时期的干旱会直接影响产量 |
| 收获前2-3周 | 停止灌溉 | 表皮变硬，淀粉更充实 |

&nbsp;&nbsp;&nbsp;木薯的耐旱性来自多种机制的叠加。它通过落叶减少蒸腾、迅速关闭气孔、把根扎到2m以上的深度。数月不下雨时，它会把叶子全部落光，像干枯的木棍一样立着，等到下雨才重新长叶。这段时间根中的淀粉会被消耗，因此产量下降，但不会枯死。这与谷物一次干旱就全军覆没有着决定性的不同。

### 7-2. 缺水与积水的症状

| 类别 | 症状 | 进展 | 处理 |
|---|---|---|---|
| 缺水 | 下部叶片先发黄脱落 | 正常反应 | 无需处理，是生存策略 |
| 缺水 | 叶片几乎落尽，只剩茎干 | 严重 | 根部淀粉被消耗，降雨后可恢复 |
| 缺水 | 成活前插条枯萎 | 致命 | 无法恢复，须重新扦插 |
| 积水 | 下部叶片发黄、基部发黑 | 危险 | 立即开挖排水沟 |
| 积水 | 挖开一看根部发软发臭 | 致命 | 无法挽回，须放弃该区域 |

> **木薯不会旱死，却会涝死。绝不种在积水的地方。**

## 8. 栽培管理

### 8-1. 杂草管理——前4个月是关键

| 时期 | 作业 | 理由 |
|---|---|---|
| 扦插-3个月 | 定期除草，2-3次 | 前期生长缓慢，会被杂草压制 |
| 3-4个月 | 视情况除草，加强覆盖 | 地面尚未被叶片覆盖 |
| 4个月以后 | 基本无需除草 | 叶片覆盖地面，抑制杂草 |

&nbsp;&nbsp;&nbsp;木薯种植中决定产量的最大变量，既不是施肥也不是浇水，而是前期的杂草管理。扦插后3个月内若被杂草压制，田地就再也无法恢复。反之，只要挺过这段时期，之后几乎不用再费心。这意味着劳动力要集中投入到前期，在灾害情况下安排人手时是重要信息。

### 8-2. 培土

| 时期 | 作业 | 效果 |
|---|---|---|
| 生长期1-2次 | 在茎基部培土 | 防止倒伏，促进根系发育 |
| 多雨时期 | 重新加高畦面 | 防止积水 |
| 根部露出时 | 覆土 | 露出的根会变绿变硬 |

### 8-3. 其他管理

| 作业 | 时期 | 内容 |
|---|---|---|
| 间苗 | 苗高15-20cm | 每穴只留健壮的1-2株 |
| 采叶 | 生长中期以后 | 摘取上部嫩叶作蔬菜食用，摘取过多会使块根变小 |
| 保证地温 | 前期 | 在韩国用覆盖物或草木灰提高地温 |
| 防风 | 台风季 | 株高2-4m，容易被风吹倒，须在基部培土 |

&nbsp;&nbsp;&nbsp;采叶在木薯种植中具有特殊意义。在等待块根成熟的8个月里，叶片会持续生长，其间可以摘叶作蔬菜食用。叶片的蛋白质远多于块根，能弥补木薯饮食中最大的弱点。不过摘叶过多会减少光合作用面积，使块根产量下降。一株保留下部叶片，只摘上部几片嫩叶为宜，叶片的处理务必遵照第14节的方法。

## 9. 病虫害

### 9-1. 主要病害

| 病害 | 症状 | 危害 | 无农药应对 |
|---|---|---|---|
| 木薯花叶病（CMD） | 叶片出现花叶状斑纹并卷缩 | 减产30-70% | 抗病品种、挑选健壮插条，无法治疗 |
| 木薯褐条病（CBSD） | 茎上出现褐色条纹，块根内部变褐腐烂 | 可能导致全田绝收 | 抗病品种，拔除并烧毁病株 |
| 细菌性枯萎病 | 叶片出现水渍状斑点，茎萎蔫 | 中等 | 健壮插条、轮作、烧毁病残体 |
| 根腐病 | 块根变软发臭 | 致命 | 改善排水是唯一对策 |
| 炭疽病 | 茎叶出现凹陷斑点 | 中等 | 保证通风、清除病部 |

&nbsp;&nbsp;&nbsp;木薯的病害几乎全部通过插条传入。从感染病毒的植株上剪下的茎，会原封不动地携带病毒，第二年就会传遍整片田地。因此木薯防治的核心不是农药，而是插条挑选。评价表中防治自立度写着"仅靠挑选健壮插条基本即可应对"，原因就在这里。即使没有农药，靠肉眼挑选这件事仍然能做到。

### 9-2. 主要害虫

| 害虫 | 危害 | 无农药应对 |
|---|---|---|
| 粉虱 | 吸食汁液并传播花叶病病毒 | 抗病品种、黄色粘虫板、清除周边杂草 |
| 蚜虫 | 吸食汁液并传播病毒 | 水冲洗、肥皂水、保护瓢虫和寄生蜂 |
| 红蜘蛛 | 叶片出现黄斑并脱落 | 向叶背喷水，干旱期发生严重 |
| 介壳虫 | 附着在茎上抑制生长 | 在插条阶段挑除，保护寄生蜂 |
| 白蚁 | 啃食插条和块根 | 种植时混入草木灰 |
| 野猪·啮齿类 | 挖食块根 | 设置围栏。高苦味种受害相对较少 |

### 9-3. 无农药防治五原则

| 原则 | 内容 |
|---|---|
| 挑选插条 | 绝不从有病征的植株上采取插条，这占防治工作的八成 |
| 抗病系统 | 若能获得，就使用抗病系统 |
| 立即清除病株 | 一旦发现花叶症状，当场拔除并烧毁 |
| 轮作 | 不在同一块地连续种植，间隔2年以上 |
| 保护天敌 | 保护粉虱和蚜虫的天敌——寄生蜂和瓢虫 |

## 10. 营养缺乏与过量

| 症状 | 原因 | 确认方法 | 天然材料应对 |
|---|---|---|---|
| 整株叶片发黄，植株矮小 | 缺氮 | 从下部叶片开始 | 腐熟堆肥、10倍稀释尿液 |
| 叶缘焦褐 | 缺钾 | 块根膨大期常见 | 草木灰，对木薯最为重要 |
| 整体生长不良，叶片呈深紫色 | 缺磷 | 酸性土壤中常见 | 骨粉、草木灰 |
| 新叶细小畸形、叶尖枯死 | 缺硼 | 从嫩叶开始出现 | 堆肥多样化，少量撒施草木灰 |
| 叶脉间发黄 | 缺镁 | 从下部叶片开始 | 白云石粉、堆肥 |
| 茎叶徒长而块根细弱 | 氮过量 | 叶色过深 | 停止供氮，用草木灰补钾 |

&nbsp;&nbsp;&nbsp;木薯最常见、损失也最大的是缺钾。由于钾直接参与淀粉向块根的运输，一旦缺钾，即使叶片看起来正常，块根也会长得细瘦。而且木薯每次收获都会带走大量的钾，若不施肥连作，钾会最先耗尽。这就是草木灰在木薯种植中比其他任何作物都更珍贵的原因。

## 11. 间作与轮作

### 11-1. 搭配

| 搭配 | 对象 | 理由 |
|:---:|---|---|
| 好 | 豆科作物（豇豆、花生、大豆） | 固氮供给木薯，利用前期4个月的空闲空间 |
| 好 | 玉米 | 在木薯前期生长缓慢期间提前收获 |
| 好 | 南瓜、甘薯 | 覆盖地面，减少杂草和水土流失 |
| 一般 | 叶菜类 | 种在畦间，早期收获 |
| 避免 | 同地连作 | 病原菌累积，钾逐渐枯竭 |
| 避免 | 大戟科作物 | 会共患同类病害 |

&nbsp;&nbsp;&nbsp;木薯与豆科作物间作，是非洲广泛采用的方式。木薯种下后有4个月几乎无法覆盖地面，这段时间的空间被浪费掉，若在此处种上豇豆或花生，4个月就能收获。而且豆科固定的部分氮留在土壤中，供木薯后期生长使用。在灾害情况下，能在同一块田里同时获得蛋白质来源和热量来源，这一点意义重大。

### 11-2. 轮作顺序

| 顺序 | 作物 | 作用 |
|---|---|---|
| 第1年 | 木薯 | 大量消耗钾和磷 |
| 第2年 | 豆科（大豆、豇豆、红小豆） | 恢复氮素 |
| 第3年 | 叶菜类或谷物 | 利用剩余的氮 |
| 第4年 | 再次种木薯 | 保持3-4年的间隔 |

&nbsp;&nbsp;&nbsp;连作适应性A这一等级，附有"即使在贫瘠土地上，地力消耗也很大"的说明。木薯能在贫瘠土地上生长，并不意味着它不会消耗那片土地。恰恰相反，它能在寸草不生的土地上把根填满淀粉，这种能力也意味着它把土壤中残余的养分彻底榨取殆尽。若把木薯连续多年种在同一块地，那片土地终将连木薯也种不活。把茎、叶、表皮务必归还田地，并休作2年以上或间种豆科作物，是应对这一问题的唯一办法。

## 12. 收获

### 12-1. 判断时机

| 用途 | 收获时期（扦插后） | 判断标准 |
|---|:---:|---|
| 即食 | 6-8个月 | 淀粉较少，质地不那么硬实 |
| 淀粉·粉类加工 | 8-12个月 | 淀粉含量与产量均达到最大 |
| 延迟收获 | 12-24个月 | 纤维增多变硬，但仍可食用 |
| 韩国露地 | 5月初扦插，10月底收获 | 必须在霜冻前结束 |
| 外观信号 | 下部叶片发黄脱落，茎的基部木质化 | 可试挖一株检查粗细 |

&nbsp;&nbsp;&nbsp;在韩国没有选择的余地。霜一降，地上部分就会枯死，地上部分一死，根很快也开始腐坏。必须在10月底前全部挖完，这意味着要把热带地区8到12个月的作期压缩到6个月，产量也会相应减少。一旦发布初霜预报，即使块根还没长成熟，也最好尽早挖出。

### 12-2. 收获要领

| 顺序 | 内容 |
|---|---|
| 1 | 选择晴朗干燥的日子，潮湿的根会立刻腐烂 |
| 2 | 保留地上部分茎30-50cm后剪断，这段茎作为把手 |
| 3 | 以留下的茎为杠杆，从块根的反方向撬起 |
| 4 | 土壤板结时，先挖松植株周围的土 |
| 5 | 注意不要弄断块根，断面会成为腐烂的起点 |
| 6 | 轻轻拍掉泥土，不要用水冲洗 |
| 7 | 剩余的茎另行收集，留作插条 |

### 12-3. 收获后处理——没有时间

| 经过时间 | 状态 |
|---|---|
| 收获后即刻 | 肉质洁白，正常 |
| 24-48小时 | 肉质开始出现发青的条纹 |
| 48-72小时 | 变为褐色，产生苦味和异味 |
| 3-5天 | 开始腐烂 |

&nbsp;&nbsp;&nbsp;这种变化称为生理性变质。它不是霉菌或细菌所致，而是块根自身的创伤反应，从挖出的那一刻起就不可逆转地进行下去，比其他任何薯类（块茎/块根）都快。因此，木薯的原则不是"收获后几天内加工"，而是"当天挖当天加工"。从挖出、搬运、去皮，到切片晾晒，都必须在一天之内完成。正因为这种劳动负担，分批少量挖、少量处理才是切合实际的做法。

> **田地就是仓库。只挖本周要吃、要加工的量。一次性挖太多，三天内就会有一半报废。**

## 13. 插条保存与留种

### 13-1. 插条即种子

&nbsp;&nbsp;&nbsp;木薯的自家留种等级为SS。把一株上长出的2-4m茎秆每15cm剪一段，能得到10段以上的插条，每一段都能长成来年的一株。增殖率非常高，即使从很少的种苗开始，两三年后也能种满相当大的面积。

| 项目 | 标准 |
|---|---|
| 采集部位 | 茎的中段，直径2-3cm |
| 采集时期 | 与收获同时，10月底 |
| 保存单位 | 不切断，保留1m左右的长段 |
| 保存温度 | 10度以上，不结冰之处 |
| 保存湿度 | 保持不干燥的程度，切忌完全干燥 |
| 保存期限 | 最长2-3个月，时间越长成活率越低 |

### 13-2. 韩国最棘手的问题——插条越冬

&nbsp;&nbsp;&nbsp;种子寿命评为E，实质就在于此。木薯的茎是活组织，一旦结冰就会死亡，干燥也会死亡，潮湿则会腐烂。在热带地区没有这个问题，因为可以直接从留在地里的木薯上按需剪茎使用。在韩国，从11月到次年4月长达5个多月的时间里，必须由人来守护存活的茎。在断暖的情况下，这是木薯种植中最大的瓶颈。

| 方法 | 条件 | 成功率 | 备注 |
|---|---|:---:|---|
| 立放于室内阴凉处 | 10-15℃，湿度中等 | 中等 | 最简单的方法，扎成捆立放以防干燥 |
| 将基部埋入湿沙中 | 10℃以上 | 高 | 偶尔浇水以防沙子变干 |
| 埋入土窑或地窖 | 能保持10℃以上之处 | 中等 | 温度低于5℃就会失败 |
| 假植于温室或塑料大棚内 | 10℃以上 | 高 | 若条件允许，是最可靠的方法 |
| 盆栽后在室内越冬 | 15℃以上，光照充足处 | 高 | 适合少量种苗，以活体植株方式过冬 |
| 露地放任不管 | - | 0 | 必定冻死 |

&nbsp;&nbsp;&nbsp;最可靠的方法不是保存插条，而是让活体植株在室内过冬。用小花盆种一两株，放在明亮温暖的室内，冬天虽会掉一些叶子但能存活，春天一到就能从这株上剪茎作插条使用。哪怕只养活一株，第二年也能变成十株。原则是同时采用多种方法以分散风险。

> **在韩国，木薯种植的成败不是取决于田地，而是取决于冬季室内。一旦失去插条，第二年就没有木薯可种。**

### 13-3. 种子繁殖

| 项目 | 内容 |
|---|---|
| 结实 | 结出蒴果并产生种子 |
| 发芽 | 发芽率低且不规律 |
| 特性 | 会出现与母株不同的性状 |
| 生长 | 实生苗块根成熟所需时间更长 |
| 实用性 | 不用于繁殖，仅用于育种目的 |
