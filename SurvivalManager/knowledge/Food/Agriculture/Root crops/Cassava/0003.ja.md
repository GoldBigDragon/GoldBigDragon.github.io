## 3. 栽培環境

### 3-1. 限界値と最適値

| 項目 | 限界値 | 最適値 | 外れた場合 |
|---|---|---|---|
| 生育温度 | 15-38℃ | 25-35℃ | 幅が10℃と狭いです。15℃を下回ると生育が事実上止まります |
| 低温限界 | 10℃ | - | 10℃以下で生育停止。0℃で地上部が枯死します |
| 霜 | 耐えられません | - | 一度の霜でその年の作期が終わります |
| 年間降水量 | 500-1,500mm | 1,000-1,500mm | 500mm未満でも生き残ります。収量が減るだけです |
| 総蒸発散量 | - | 約400mm | ジャガイモの500-700mmより少ないです |
| 土壌pH | 4.0-8.0 | 5.5-6.5 | 酸性への適応力が非常に高いです |
| 土壌 | 砂質土~壌土 | 排水の良い砂壌土 | 冠水や排水不良地では根がすぐに腐ります |
| 標高 | 0-1,500m | 低地 | 標高が高いと気温が低くなり生育が遅れます |
| 日照 | 1日6-8時間 | 1日8時間以上 | 40%遮光で相対収量約80% |

&nbsp;&nbsp;&nbsp;温度適応幅10℃と耐寒性Eは、韓国でキャッサバを扱うあらゆる計画の出発点です。韓国中部では、日平均気温が20℃を超える期間はおおむね6月から9月までの4か月です。5月初めに植えて10月末に掘り出せば6か月の作期になりますが、そのうちキャッサバがまともに育つ期間は4か月ほどです。熱帯で10か月かけて得る収量の半分が出れば上出来です。

### 3-2. 災害時における立地選び

| 条件 | 判断 |
|---|---|
| 南向きの斜面で風が遮られる場所 | 最も良いです。地温が早く上がり作期が長くなります |
| 砂が混じった排水の良い土地 | 良いです。根が深く入り、掘り出しやすいです |
| 痩せた酸性の赤土 | 良いです。他の作物が使えない土地を活用できます |
| 傾斜地 | 可能ですが15℃以上では等高線状の階段を作ります |
| 低地、水がたまる場所 | 絶対に避けます。数日で根が腐ります |
| 霜だまりや冷気がたまる盆地 | 避けます。初霜が早く来て作期が短くなります |
| 粘土質の重い土壌 | 避けます。根が太くならず、掘り出すのも難しいです |

&nbsp;&nbsp;&nbsp;韓国でキャッサバを植えるなら、温室やビニールトンネルを使わない限り南部地域が有利ですが、それでも作期は短くなります。施設負担SSという等級は熱帯基準であり、韓国では地温を上げるためのマルチングが事実上必要です。ビニールがなければ、黒い腐葉土や灰を表面に薄くまいて地温を高める方法を使います。

## 4. 品種

### 4-1. 高苦味種と低苦味種 - 最も重要な区分

&nbsp;&nbsp;&nbsp;キャッサバの品種を分ける基準は、収量でも生育日数でもなく、シアン配糖体の含有量です。慣習的に甘味品種（低苦味種）と苦味品種（高苦味種）と呼びますが、正確には、シアン含有量が低い系統と高い系統という意味です。

| 区分 | 低苦味種（甘味品種） | 高苦味種（苦味品種） |
|---|---|---|
| シアン含有量 | 生重量1kgあたり約50mg以下 | 100mgから1,000mg以上まで |
| 分布 | 果肉の濃度は低く、皮に集中しています | 果肉にもかなりの量が含まれています |
| 処理 | 厚く皮をむいて十分に煮ればよいです | すりつぶして発酵、乾燥、浸水などの多段階処理が必須です |
| 収量 | 相対的に低いです | 高いです。でんぷん含有量も高いです |
| 病害虫 | 動物や虫の被害をより多く受けます | シアン濃度が防御の役割を果たします |
| 盗難 | 畑から抜き取られやすいです | 処理法を知らなければ食べられないため盗難が少ないです |
| 用途 | 即席の食用、ゆでて食べる | でんぷん、粉、発酵加工品 |

&nbsp;&nbsp;&nbsp;アフリカの農家があえて高苦味種を植える理由は、上の表の下三行にあります。収量が高く、動物にあまり食べられず、人に盗まれません。飢饉が深刻になるほど高苦味種の比重が増える傾向があり、その結果、飢饉の時期にコンゾの発生が増えます。災害時にどの品種を選ぶかは、収量と安全性の間のトレードオフです。

> **苦味で品種を判定することはできますが、苦味の強さとシアン含有量は正確には比例しません。品種が分からないキャッサバは、すべて高苦味種として扱い処理するのが原則です。**

### 4-2. 主な品種

| 品種 | 特徴 | 災害適合度 |
|---|---|:---:|
| Kasetsart 50 | タイで最も広く栽培されている品種です。でんぷん含有量が高く多収です | 高い |
| Rayong 9 | タイの主要品種です。多収で乾物率が高いです | 高い |
| KM505, KM140 | 病害虫抵抗性に優れています。ウイルス病発生地域に適します | 高い |
| 在来低苦味種 | 収量は低いですが処理が簡単です | 初心者向け |

### 4-3. 状況別の選択基準

| 状況 | 選択 | 理由 |
|---|---|---|
| 処理の知識や道具が整っていないとき | 低苦味種 | 皮むきと煮ることだけで安全な水準に達します |
| 子どもや高齢者が一緒に食べるとき | 低苦味種 | 体重当たりの摂取量が多く危険性が高いです |
| でんぷんや粉として備蓄するとき | 高苦味種 | でんぷん含有量が高く、どのみち多段階の加工を経ます |
| 動物被害や盗難が深刻なとき | 高苦味種 | それ自体が防御手段になります |
| ウイルス病発生地域 | KM505, KM140 | 抵抗性の系統です |
| 短い作期（韓国の露地） | 早生系統 | 6か月以内に根が付かなければなりません |

## 5. 畑の準備と肥料

### 5-1. 土作り

| 項目 | 基準 | 理由 |
|---|---|---|
| 耕起 | 深さ20-30cm | 塊根が伸びる空間を作ります |
| 畝 | 高畝、高さ30cm以上 | 冠水を防ぎます。キャッサバの唯一の致命的弱点です |
| 排水路 | 畝ごとに確保します | 水がたまると数日で根が腐ります |
| 土壌酸度 | pH4.5-7.5に適応 | 別途矯正の必要はありません |
| 傾斜地 | 15度以上は等高線状の階段にします | 根を掘り出すと土がむき出しになり浸食が激しくなります |
| 地温確保 | 黒いマルチや灰 | 韓国では初期の地温が鍵になります |

### 5-2. 標準施肥量（1,000㎡、300坪基準）

| 肥料 | 施肥量 | 備考 |
|---|:---:|---|
| 窒素（N） | 8-12kg | 元肥と追肥に分けます |
| リン酸（P） | 6-10kg | 全量元肥 |
| カリウム（K） | 8-12kg | 全量元肥。でんぷん蓄積に最も重要です |
| 堆肥 | 1,000-1,500kg | 完熟堆肥、全量元肥 |

&nbsp;&nbsp;&nbsp;施肥等級がSSであるということは、この表のとおりに与えなくても収穫が得られるという意味です。実際、アフリカの小農のキャッサバ畑は大半が無施肥です。ただし無施肥のまま栽培を続けると、土壌のカリウムが急速に枯渇します。キャッサバは根にでんぷんを蓄える過程でカリウムを大量に取り込みますが、その根を丸ごと掘り出して畑の外に持ち出すためです。連作適応性がA（2年休作）にとどまり、「痩せた土地でも地力の消耗が大きい」という注記が付いている理由がここにあります。

### 5-3. 化学肥料がないとき - 災害時の代替肥料

| 代替資源 | 供給される養分 | 作り方と使い方 | 注意 |
|---|---|---|---|
| 草木灰 | カリウム、リン酸、カルシウム | キャッサバにとって最も重要な代替材です。㎡あたり一、二握り | アルカリ性のため、多すぎるとpHが上がります |
| キャッサバの茎と葉 | カリウム、窒素、有機物 | 収穫後に残った茎と葉をその場に戻します | 最も確実なカリウム循環方法です |
| 皮と加工残渣 | カリウム、有機物 | 堆肥に回します | シアンが残っているため家畜にそのまま与えません |
| 完熟堆肥 | 総合的な養分 | 落ち葉と草と糞尿を6か月以上かけて発酵させます | 未熟なまま使うと根を傷めます |
| 尿の希釈液 | 窒素、カリウム | 水で10倍に薄めて畝の間に与えます | 葉に直接かからないようにします |
| 骨粉 | リン酸、カルシウム | 焼いて砕き堆肥に混ぜます | 効果が遅いです |

&nbsp;&nbsp;&nbsp;キャッサバ栽培における資源循環の要は、茎と葉と皮を畑の外に出さないことです。収穫した根だけを持ち出し、残りをすべて畑に戻せば、カリウムの損失をかなり減らせます。特に皮は重量で根全体の10-20%を占めており、これを堆肥に回せば少なくない養分になります。ただし皮はシアン濃度が最も高いため、家畜にそのまま与えず、十分に腐らせてから使います。

## 6. 挿し木

### 6-1. 時期

| 地域 | 挿し木時期 | 収穫時期 | 備考 |
|---|---|---|---|
| 韓国（中部・南部） | 5月初め | 10月末 | 霜と霜の間の6か月がすべてです |
| 熱帯 | 気温20℃以上ならいつでも | 8-18か月後 | 雨季の始まりに合わせます |

&nbsp;&nbsp;&nbsp;韓国における5月初めという時期は、遅霜が終わった直後を意味します。キャッサバは霜に一度も耐えられないため、一日でも早いと全滅します。逆に遅く植えると作期が短くなり、根が育ちません。この狭い時期を逃さないことが、韓国でキャッサバを育てる第一の条件です。

### 6-2. 挿し穂の準備

| 項目 | 基準 | 理由 |
|---|---|---|
| 採取部位 | 茎の中間部分 | 先端は柔らかく、根元は木質化が進みすぎています |
| 茎の太さ | 直径2-3cm | 貯蔵養分が十分でないと活着が良くありません |
| 挿し穂の長さ | 15-20cm | 短いと養分が足りず、長いと無駄になります |
| 節の数 | 3-5個 | 節ごとに芽が出ることがあります |
| 茎の状態 | 硬くて健全なもの | ウイルスに感染した挿し穂は収量を30-40%落とします |
| 切り口 | 斜めに切ります | 根が出る面積が広くなります |
| 上下 | 必ず区別します | 逆さに挿すと芽が出ません |

&nbsp;&nbsp;&nbsp;挿し穂の上下は、節に残る葉痕の向きで見分けます。葉痕は上を向いた半月形で、その上側に芽があります。判断が難しい場合は、斜めに寝かせて挿します。寝かせて挿せば、どちら向きでも節から芽と根が出ます。

### 6-3. 挿し穂の消毒

| 方法 | 手順 | 効果 |
|---|---|---|
| 温湯処理 | 50-55℃の湯に10-15分浸けます | 表面の病原菌が死にます |
| 灰処理 | 切り口に草木灰をまぶします | 消毒と乾燥を兼ねます |
| 乾燥 | 日陰で1日ほど切り口を乾かします | 腐敗を防ぎます |
| 選別 | 病徴のある茎は使いません | 最も効果的な防除です |

&nbsp;&nbsp;&nbsp;温湯処理を行う際は温度が重要です。60℃を超えると挿し穂自体が死に、45℃を下回ると病原菌が生き残ります。温度計がない場合、手を入れて数秒は耐えられるが長くは浸けていられない程度がおおむね50℃前後です。ただしこの方法は感覚を誤ると種苗をまるごと失うため、確信が持てないなら健全な挿し穂を目で選び出す方が安全です。

### 6-4. 植え付け

| 項目 | 基準 | 理由 |
|---|---|---|
| 植え付ける深さ | 5-10cm | 挿し穂の3分の1から半分が埋まるようにします |
| 植え付ける角度 | 15-45度の傾斜または垂直 | 斜めに挿すと根が片側に集まり掘り出しやすくなります |
| 株間 | 80-100cm | 広く見えますが、低木状に育つため必要です |
| 条間 | 80-100cm | 通風と光合成を確保します |
| 植え付け後 | 土を密着させ十分に灌水します | 活着するまで乾かさないようにします |
| 間引き | 草丈15-20cmのとき | 1つの穴に最も丈夫な1-2本だけ残します |

&nbsp;&nbsp;&nbsp;植え付ける角度を斜めにするのには理由があります。垂直に挿すと根が四方に深く広がり、掘り出す際に鍬入れが増え、根が切れてしまいます。45°前後に寝かせて挿すと根が片側に集まって出るため、収穫時に反対側からてこの原理で持ち上げれば一度に引き抜けます。手で掘り出さなければならない状況では、この差はかなり大きなものです。
