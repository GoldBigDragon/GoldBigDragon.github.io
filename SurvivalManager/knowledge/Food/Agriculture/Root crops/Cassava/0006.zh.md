## 15. 无冰箱贮藏

### 15-1. 木薯没有活体贮藏方式

&nbsp;&nbsp;&nbsp;耐储性评级E在这张表中属于最低之列。马铃薯在地窖里能存4个月，菊芋在地下能撑过整个冬天，但木薯块根挖出后2到3天内部就会发青，3、4天就开始腐坏，比其他任何薯类（块茎/块根）都快。原因在于解剖结构：木薯是根，根一旦离开母株就会产生创伤反应，这与马铃薯和菊芋作为茎能够自行生成木栓层封闭伤口有着根本的不同。

&nbsp;&nbsp;&nbsp;因此，木薯的贮藏策略只有两条路：不挖，留在地里；或者挖出后立刻加工。挖出的生块根几乎没有可以贮藏的方法，应视作事实上不存在。

| 贮藏对象 | 马铃薯 | 木薯 |
|---|---|---|
| 食用部位 | 茎（块茎） | 根（块根） |
| 伤口愈合 | 能自行形成木栓层 | 无法形成 |
| 挖出后的极限 | 1-2个月 | 2-3天 |
| 主要贮藏法 | 地窖贮藏 | 不挖，留在地里 |
| 长期贮藏法 | 淀粉与干燥 | 干燥与淀粉，实际上是唯一的方法 |

### 15-2. 地下贮藏——热带的标准做法

| 项目 | 内容 |
|---|---|
| 原理 | 不收获，留在地下。只要块根仍连着母株就不会腐坏 |
| 期限 | 从第8个月到第24个月 |
| 方法 | 保留地上部分存活，只挖需要的株数 |
| 优点 | 不需要电力、设施或劳力，新鲜度最高 |
| 缺点 | 时间越久纤维越多、质地越硬，淀粉比例下降 |
| 风险 | 野猪和啮齿类，高苦味种受害相对较少 |
| 在韩国 | 不成立。霜一来地上部分就枯死，根很快也会腐坏 |

> **在韩国种植木薯，无法采用留在田里的贮藏方式。必须在10月底全部挖出并立即加工。热带地区行得通的贮藏策略在韩国行不通，这是在韩国种植木薯时最大的负担。**

### 15-3. 挖出后的短期保存

| 方式 | 方法 | 期限 | 备注 |
|---|---|---|---|
| 埋入湿沙或湿土 | 把整根重新埋入土中 | 1-2周 | 模拟留在田里的状态 |
| 埋入湿锯末·稻壳中 | 在箱中一层层码放 | 1-2周 | 注意防止干燥 |
| 蜡·泥浆包裹 | 用泥浆封住切口和表面 | 2-4周 | 封住伤口，延缓变质 |
| 阴凉室内 | 摊放在通风良好的阴凉处 | 2-5天 | 实际上只是临时存放 |
| 浸泡在水中 | 完全浸没 | 3-7天 | 须换水，可与解毒浸泡兼用 |

&nbsp;&nbsp;&nbsp;泥浆包裹是没有工具时可用的方法。把挖出块根的切口和伤口处涂上细腻的泥浆封住，能减少与空气的接触，延缓变质。不过这种方法也撑不过几周，并非根本的解决办法。

### 15-4. 通过加工实现长期贮藏——实际上唯一的途径

| 方法 | 步骤 | 期限 | 备注 |
|---|---|---|---|
| 干片 | 去皮后切成5mm以下晒干4-7天至彻底干燥 | 1-2年 | 同时解决脱毒和贮藏问题 |
| 粉 | 把彻底晒干的干片用臼或石磨磨碎 | 1-2年 | 密封保存，放入草木灰或炭作干燥剂 |
| 淀粉（木薯淀粉） | 磨碎后加水搅散，沉淀物反复漂洗后晒干 | 数年 | 脱毒效果最好，几乎不生虫 |
| 发酵加工品 | 磨碎后发酵3-5天、压榨、炒制 | 6个月-1年 | 西非的加里做法 |
| 颗粒干制品 | 将发酵压榨后的团块搓成颗粒蒸干 | 1年以上 | 用水泡开即可直接食用 |

&nbsp;&nbsp;&nbsp;提取淀粉在灾害情况下特别有用，因为贮藏期最长、体积和重量大幅减少、几乎不生虫，最重要的是脱毒效果最为可靠。步骤如下：把厚厚去皮的块根用擦板或石臼彻底捣碎，用布包好在水中揉搓，会流出白色的浆水。静置30分钟到1小时让沉淀物沉降，倒掉上层清水后再加入新水，重复沉降3、4次。在这个过程中，溶于水的氰化物会随上层清水不断流失。最后把剩下的白色沉淀摊开彻底晒干，就是木薯淀粉（tapioca）。100kg块根大约能得到20kg到25kg淀粉。

| 注意 | 内容 |
|---|---|
| 倒掉的上层清水 | 毒素溶于其中，不可饮用，也不可喂给家畜 |
| 挤压后的残渣 | 含有纤维和残余淀粉，须充分发酵后作家畜饲料 |
| 干燥 | 须彻底晒干，残留水分会发霉 |
| 保存 | 密封容器中放入草木灰或炭 |

## 16. 烹饪与加工

### 16-1. 省燃料的烹饪方法

| 方法 | 燃料消耗 | 步骤 | 备注 |
|---|:---:|---|---|
| 淀粉·粉类烹调 | 非常少 | 倒入沸水中搅散即刻熟 | 燃料效率最高 |
| 切碎煮制 | 少 | 切成2cm以下需15-20分钟 | 表面积大，脱毒也随之加快 |
| 蒸制 | 少 | 加少量水蒸25-30分钟 | 但须留出气体逸出的通道 |
| 整根煮 | 中等 | 20-30分钟 | 不适用于高苦味种 |
| 余热焖煮 | 非常少 | 煮15分钟后关火包裹焖1小时 | 仅用于已完成前期脱毒的原料 |
| 埋灰烤制 | 非常少 | 埋入热灰中30-40分钟 | 仅用于低苦味种 |

> **为省燃料而缩短加热时间，在其他作物上是节约，在木薯上却是危险。节约要在前面的步骤中完成。只要提前磨碎、浸泡、晒干，最后加热的时间就可以缩短。**

&nbsp;&nbsp;&nbsp;这一点是木薯烹饪的核心原理。低苦味种若直接煮食需要20到30分钟的燃料，但若提前晒干磨成粉，只需倒入沸水搅散即可。也就是说，在收获季集中投入燃料和时间进行加工，之后数月里每顿饭都能大大节省燃料。考虑到冬季柴火变得珍贵的情况，这种提前投入格外划算。

### 16-2. 烹调注意事项

| 项目 | 内容 |
|---|---|
| 表皮 | 绝对不可食用，氰化物浓度最高 |
| 中心芯 | 质地坚韧，氰化物含量也相对较高，须去除 |
| 煮的水 | 必须倒掉，不可用作汤汁 |
| 锅盖 | 保持打开，必须让气体逸出 |
| 室内大量烹调 | 须通风 |
| 口味判断 | 若仍有苦味或涩味则不可食用 |
| 变色的块根 | 若内部有青色条纹或褐色，须挖去该部分；严重时应全部废弃 |
| 儿童 | 即使同样的量也危险得多，只能给予处理确实到位的部分 |

### 16-3. 兼顾贮藏的加工

| 加工 | 步骤 | 结果 |
|---|---|---|
| 木薯粉 | 去皮后切薄片彻底晒干再磨碎 | 用于煮粥、和面、做年糕。不含麸质，与谷物粉混合使用效果更好 |
| 木薯淀粉 | 磨碎后加水搅散，沉淀物反复漂洗后晒干 | 保存最久、最安全 |
| 发酵颗粒 | 磨碎后发酵、压榨、炒制 | 用水泡开即可直接食用，即西非的加里 |
| 蒸糕 | 把煮熟的块根用臼捣成团 | 即西非的福福 |
| 薯片 | 切薄片晒干后用油煎或埋灰烤 | 既是零食也是应急食品 |
| 炖叶 | 将捣碎久煮的叶片用油和盐炖煮 | 可作为蛋白质来源 |

### 16-4. 木薯饮食的原则

| 原则 | 理由 |
|---|---|
| 不单吃木薯 | 蛋白质不足会降低氰化物解毒能力 |
| 与豆类一起种植、一起食用 | 在同一块田里同时获得热量和蛋白质 |
| 不丢弃叶片 | 是弥补块根蛋白质不足最简便的手段 |
| 保证食盐和海藻的供应 | 若再叠加碘缺乏，甲状腺问题会加重 |
| 不依赖单一加工品 | 避免一次加工失败毁掉全部粮食 |

## 17. 全年作业日程

| 月份 | 作业 | 要点 |
|---|---|---|
| 1月 | 插条越冬管理，检查加工品 | 保持不低于10℃，是最危险的时期 |
| 2月 | 检查插条状态，规划田地 | 挑出干枯或发软的茎 |
| 3月 | 整地、起畦、施入堆肥 | 高畦和排水沟是关键 |
| 4月 | 剪取插条并消毒，保证地温 | 关注晚霜情况并等待时机 |
| 5月初 | 扦插定植 | 晚霜刚结束之后，错过这个时期作期就会不够 |
| 5-6月 | 浇水促成活、间苗、第1次除草 | 前4个月的杂草管理决定产量 |
| 7月 | 第2次除草、培土、开始采叶 | 只少量采摘上部嫩叶 |
| 8月 | 防台风，采叶 | 在茎基部培土 |
| 9月 | 块根膨大期，干旱时浇水 | 此时块根开始变粗 |
| 10月 | 停止灌溉，准备收获，检查加工工具 | 每天关注霜冻预报 |
| 10月底 | 全部收获，采集插条，立即加工 | 挖出当天就去皮、切片、晒干 |
| 11月 | 完成晒干与淀粉加工，准备插条越冬 | 把田里剩余的茎叶和表皮归还田地 |
| 12月 | 插条越冬管理，检查粉类保存情况 | 保持不结冰、不干燥 |

### 17-1. 不可忘记的五件事

| 项目 | 内容 |
|---|---|
| 不省略处理步骤 | 越饥饿越要遵守程序，孔佐病总是伴随饥荒而来 |
| 仅靠煮是不够的 | 先破坏细胞、浸泡、晒干，最后才加热，顺序就是生命 |
| 不单吃木薯 | 没有蛋白质，身体就无法解毒氰化物 |
| 当天挖当天加工 | 两天就会开始腐坏，须分批少量挖、少量处理 |
| 一旦失去插条就前功尽废 | 在韩国，木薯种植的成败取决于冬季室内 |
