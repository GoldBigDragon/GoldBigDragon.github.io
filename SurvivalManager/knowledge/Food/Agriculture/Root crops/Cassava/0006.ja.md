## 15. 冷蔵庫なしの貯蔵

### 15-1. キャッサバには生体貯蔵がありません

&nbsp;&nbsp;&nbsp;貯蔵性等級Eは、この表の中で最も低い部類です。ジャガイモは室（むろ）で4か月、キクイモは地中で冬の間ずっと持ちこたえますが、キャッサバの根は掘り出してから2日から3日で中が青くなり、3、4日で傷み始めます。他のどのいも類（塊茎・塊根）よりも速いです。理由は解剖学的なところにあります。キャッサバは根であり、根は母体から切り離されると傷害反応を起こします。ジャガイモとキクイモが茎であるために自らコルク層を作って傷口を塞ぐのとは、根本的に異なります。

&nbsp;&nbsp;&nbsp;したがって、キャッサバの貯蔵戦略は二つの道しかありません。掘り出さずに土の中に置いておくか、掘り出してすぐに加工するかです。掘り出した生の根を貯蔵する方法は、事実上存在しないと考えるべきです。

| 貯蔵の観点 | ジャガイモ | キャッサバ |
|---|---|---|
| 食べる部位 | 茎（塊茎） | 根（塊根） |
| 傷口の封止 | コルク層を自ら作ります | 作れません |
| 掘り出し後の限界 | 1-2か月 | 2-3日 |
| 主な貯蔵法 | 室（むろ）貯蔵 | 掘り出さず土に置く |
| 長期貯蔵法 | でんぷんと乾燥 | 乾燥とでんぷん。事実上唯一の方法です |

### 15-2. 地中貯蔵 - 熱帯での標準

| 項目 | 内容 |
|---|---|
| 原理 | 収穫せず地中にそのまま置きます。根が母体につながっている限り傷みません |
| 期間 | 8か月目から24か月まで |
| 方法 | 地上部を生かしたまま、必要な株だけを掘り出します |
| 長所 | 電力も施設も労力も要りません。鮮度が最も高いです |
| 短所 | 時間が経つほど繊維質が増えて硬くなり、でんぷんの比率が下がります |
| 危険 | イノシシとげっ歯類。高苦味種は相対的に被害が少ないです |
| 韓国では | 成り立ちません。霜が来ると地上部が枯れ、根もすぐに傷みます |

> **韓国でキャッサバを育てるなら、畑に置いたままの貯蔵は不可能です。10月末に全量を掘り出し、すぐに加工しなければなりません。熱帯で通用する貯蔵戦略が通用しないという点が、韓国でキャッサバを扱ううえで最大の負担です。**

### 15-3. 掘り出した後の短期保管

| 方式 | 方法 | 期間 | 備考 |
|---|---|---|---|
| 湿った砂や土に埋める | 丸ごとの根を土に埋め戻します | 1-2週間 | 畑に置いた状態をまねる方式です |
| 湿ったおがくず・もみ殻に埋める | 箱に層状に入れます | 1-2週間 | 乾かないよう管理します |
| ワックス・泥コーティング | 切り口と表面を泥で塗り封じます | 2-4週間 | 傷口をふさいで変質を遅らせます |
| 涼しい室内 | 風通しの良い日陰に広げておきます | 2-5日 | 事実上の一時保管です |
| 水に浸けておく | 完全に浸します | 3-7日 | 水を替えます。解毒の浸水と兼ねられます |

&nbsp;&nbsp;&nbsp;泥コーティングは、道具がないときに使える方法です。掘り出した根の切り口や傷んだ部分に細かい泥のペーストを塗って封じると、空気との接触が減り変質が遅くなります。ただしこれも数週間しかもたず、根本的な解決にはなりません。

### 15-4. 加工による長期貯蔵 - 事実上唯一の道

| 方法 | 手順 | 期間 | 備考 |
|---|---|---|---|
| 乾燥チップ | 皮をむき5mm以下に切って4-7日完全乾燥 | 1-2年 | 解毒と貯蔵を同時に解決します |
| 粉 | 完全に乾いたチップを臼や石臼で挽きます | 1-2年 | 密閉し、灰や炭を乾燥剤として入れます |
| でんぷん（タピオカ） | すりつぶして水に溶かし、沈殿物を何度もすすいで乾かします | 数年 | 解毒効果が最も大きいです。虫もほとんど付きません |
| 発酵加工品 | すりつぶして3-5日発酵、圧搾、炒める | 6か月-1年 | 西アフリカのガリ方式です |
| 粒状乾燥 | 発酵後に圧搾した塊を粒状にして蒸し乾かします | 1年以上 | 水で戻してそのまま食べます |

&nbsp;&nbsp;&nbsp;でんぷん抽出は災害時に特に有用です。貯蔵期間が最も長く、体積と重量が大きく減り、虫もほとんど付かず、何より解毒効果が最も確実だからです。手順はこうです。皮を厚くむいた根をおろし金や石臼で完全にすりつぶします。布に包んで水の中でもむと白い水が出ます。そのまま30分から1時間置いて沈殿物を沈め、上澄みを捨てたあと新しい水を注いでまた沈めることを3、4回繰り返します。この過程で、水に溶けるシアン化合物が上澄みとともに抜け続けます。最後に残った白い沈殿物を広げて完全に乾かせばタピオカでんぷんです。100kgの根からおよそ20kgから25kgが得られます。

| 注意 | 内容 |
|---|---|
| 捨てた上澄み | 毒が溶けています。飲まず、家畜にも与えません |
| 搾りかす | 繊維質と残ったでんぷんがあります。十分に発酵させたあと家畜の飼料にします |
| 乾燥 | 完全に乾かします。湿気が残るとカビが生えます |
| 保管 | 密閉容器に灰や炭を一緒に入れます |

## 16. 調理と加工

### 16-1. 燃料を節約する調理法

| 方法 | 燃料消費 | 手順 | 備考 |
|---|:---:|---|---|
| でんぷん・粉の調理 | 非常に少ない | 沸騰した湯に溶かせばすぐに火が通ります | 燃料効率が最も良いです |
| 細かく切って煮る | 少ない | 2cm以下に切れば15-20分 | 表面積が広く解毒も同時に速まります |
| 蒸す | 少ない | 水を少し入れて25-30分 | ただしガスが抜ける通路を開けておきます |
| 丸ごと煮る | 中程度 | 20-30分 | 高苦味種には使いません |
| 余熱調理 | 非常に少ない | 15分煮たあと火を止めて包み1時間 | 前段階の解毒を終えたものにのみ使います |
| 灰の中で焼く | 非常に少ない | 熱い灰に埋めて30-40分 | 低苦味種にのみ使います |

> **燃料を節約しようと加熱時間を短くすることは、他の作物では節約ですが、キャッサバでは危険です。節約は前段階で行います。あらかじめすりつぶし、浸し、乾かしておけば、最後の加熱は短くても構いません。**

&nbsp;&nbsp;&nbsp;この点が、キャッサバ調理の核心原理です。低苦味種をそのまま煮て食べるには20分から30分の燃料が必要ですが、あらかじめ乾かして粉にしておけば、沸騰した湯に溶かすだけで済みます。つまり収穫期に燃料と時間を集中して加工しておけば、その後何か月もの間、食事のたびに燃料を大きく節約できます。冬の間に薪が貴重になる状況を考えれば、この先行投資は特に価値が大きいです。

### 16-2. 調理上の注意

| 項目 | 内容 |
|---|---|
| 皮 | 絶対に食べません。シアン濃度が最も高いです |
| 中心の芯 | 硬く、シアンも相対的に多いです。取り除きます |
| 煮汁 | 必ず捨てます。汁物には使いません |
| 蓋 | 開けておきます。ガスが抜けなければなりません |
| 室内での大量調理 | 換気します |
| 味の判定 | 苦味や渋味が残っていれば食べません |
| 変色した根 | 中に青い筋や褐色があればその部分をえぐり取ります。ひどければ全量廃棄します |
| 子ども | 同じ量でもはるかに危険です。処理が確実なものだけを与えます |

### 16-3. 貯蔵を兼ねた加工

| 加工 | 手順 | 結果 |
|---|---|---|
| キャッサバ粉 | 皮をむき薄く切って完全乾燥後に挽きます | 粥、生地、餅として使います。グルテンがないため穀物粉と混ぜて使うとよいです |
| タピオカでんぷん | すりつぶして水に溶かし、沈殿物を何度もすすいで乾かします | 最も長持ちし、最も安全です |
| 発酵粒 | すりつぶして発酵、圧搾、炒める | 水で戻してそのまま食べます。西アフリカのガリ |
| 蒸し餅 | 煮た根を臼でついて生地にします | 西アフリカのフフ |
| チップ | 薄く切って乾かしたあと油や灰で焼きます | おやつであり非常食です |
| 葉の煮つけ | つき砕いて長く煮た葉を油と塩で煮つけます | タンパク質源になります |

### 16-4. キャッサバ食の原則

| 原則 | 理由 |
|---|---|
| キャッサバだけを食べません | タンパク質が不足すると、シアンの解毒能力が落ちます |
| 豆類を一緒に植えて一緒に食べます | 熱量とタンパク質を一つの畑で確保します |
| 葉を捨てません | 根のタンパク質不足を補う最も手軽な手段です |
| 塩と海藻を確保します | ヨウ素不足が重なると甲状腺の問題が大きくなります |
| 一種類の加工品に頼りません | 一つの加工の失敗が食料全体を台無しにしないようにします |

## 17. 年間作業スケジュール

| 月 | 作業 | 要点 |
|---|---|---|
| 1月 | 挿し穂の越冬管理、加工品の点検 | 10℃を下回らないように守ります。最も危険な時期です |
| 2月 | 挿し穂の状態確認、畑の計画 | 乾いたり軟らかくなったりした茎を取り除きます |
| 3月 | 畑の準備、畝立て、堆肥入れ | 高畝と排水路が要点です |
| 4月 | 挿し穂切りと消毒、地温確保 | 遅霜を確認しながら待ちます |
| 5月初め | 挿し木定植 | 遅霜が終わった直後。この時期を逃すと作期が足りなくなります |
| 5-6月 | 活着のための灌水、間引き、1回目の除草 | 初期4か月の雑草管理が収量を決めます |
| 7月 | 2回目の除草、土寄せ、葉の収穫開始 | 上部の若葉だけを少しずつ摘みます |
| 8月 | 台風対策、葉の収穫 | 株元に土を寄せます |
| 9月 | 塊根肥大期、干ばつ時の灌水 | このとき根が太くなります |
| 10月 | 灌水中止、収穫準備、加工道具の点検 | 霜の予報を毎日確認します |
| 10月末 | 全量収穫、挿し穂採取、即時加工 | 掘った当日に皮をむき、切って乾かします |
| 11月 | 乾燥とでんぷん加工の仕上げ、挿し穂の越冬準備 | 畑に残った茎と葉と皮を戻します |
| 12月 | 挿し穂の越冬管理、粉の保管点検 | 凍らせず乾かさないように守ります |

### 17-1. 忘れてはならない五つのこと

| 項目 | 内容 |
|---|---|
| 処理を省きません | 空腹であるほど手順を守ります。コンゾはいつも飢饉とともにやって来ます |
| 煮るだけでは不十分です | まず砕き、浸し、乾かしたあとに加熱します。順序が命です |
| キャッサバだけを食べません | タンパク質がなければ、体がシアンを解毒できません |
| 掘った当日に加工します | 2日で傷み始めます。少しずつ掘り出して少しずつ処理します |
| 挿し穂を失えば終わりです | 韓国でのキャッサバ農業の成否は、冬の室内で決まります |
