## はじめに
&nbsp;&nbsp;&nbsp;キャッサバ(Manihot esculenta)は、ブラジル中西部原産のトウダイグサ科の低木で、地中の太い塊根にでんぷんをためます。干ばつで穀物が全滅した年にも持ちこたえ、肥料のない痩せた赤土でも育ち、収穫期を過ぎても1、2年は地中に置いておけるため、飢饉の最後のとりでと呼ばれます。災害に備える評価では総合S(53.8点、有効183種中7位)で、面積当たりの熱量SS(㎡当たり4,000kcal、自給ラインの1.53倍)は根菜・イモ類で最も高い値です。ところが、全部位に青酸配糖体が含まれているため、処理していない苦味種は一食で人を死なせることがあり、処理が不十分なキャッサバを数週間から数か月食べ続けると、両足がこわばって歩けなくなるコンゾにかかります。コンゾはいつも飢饉とともに現れます。空腹になると、3日浸すべきものを1日しか浸さなくなるからです。だから、栽培法よりも先に、第10節の解毒の手順を身につけなければなりません。

|:---|:---:|:---:|
| 総合 | S | 53.8 |
| 短期 | S | 51.9 |
| 長期 | S | 55.8 |
| 副食 | B | 48.1 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: 面積当たりの熱量、施肥、施設の負担、自家採種。S: 水の消費量。A: 微量栄養素、永続性、連作への適応性。B: 日射、合成資材を投入しない場合の収量維持率、整地・掘削エネルギー、収量の安定性 |
| 弱み | E: タンパク質密度、調理・加工の要求度、耐寒性、貯蔵性、非食用の価値、種子の寿命。D: 収穫速度、国内での栽培の普及度。C: 温度幅、病害虫圧、防除の自立度、味 |

> **キャッサバは、最も少ない投入で最も多くの熱量を出す作物であると同時に、最も多くの処理の労力と最も大きな危険を求める作物です。**

&nbsp;&nbsp;&nbsp;面積当たりの熱量SSは、65㎡ほどで1人の1年分の熱量をまかなえるという意味で、ジャガイモ(130㎡)の半分であり、肥料なしでも収穫できます。自家採種SSは、茎を挿して増やすため、種子の供給が途絶えても面積を広げられるという意味で、永続性Aは、植えて8か月で食べられ、その後1、2年は地中に置けるという意味です。タンパク質密度Eは、熱量に対するタンパク質が3.4%で、必要ラインの10%の3分の1しかないという意味で、調理・加工Eはシアンを除く手順のためであり、この項目がEなのはキャッサバだけです。耐寒性Eは霜が1回降りただけで枯れるという意味で、韓国の露地では5月に挿し木して10月末に掘る1年の作期しか成り立たず、貯蔵性Eは掘ってから2、3日で傷むという意味です。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | トウダイグサ科キャッサバ属の多年生低木 |
| 葉、茎 | 5-7裂に分かれた掌状複葉。茎はまっすぐに立ち、2-4mまで伸びる |
| 塊根 | 長さ20-50cm、重さ1-5kgのものが1株に5-10個。芽がなく、植えても芽が出ないので、増やすのは茎で行う |

&nbsp;&nbsp;&nbsp;挿し木の1-2か月後に節から根と芽が出て、2-6か月に茎と葉を広げ(初期の生長は遅い)、6-10か月に塊根が太り(カリウムの要求が最大)、10-12か月に皮が固まります。100g当たり熱量160kcal(ゆでると112kcal)で根菜・イモ類で最も高く、炭水化物38gはほぼすべてでんぷんで、タンパク質1.4g、脂質0.3g、食物繊維1.8g、ビタミンC20.6mgです。葉は生重量100g当たりタンパク質が5-10gで、リシンが豊富なため、根のタンパク質不足をかなり補います。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 生育15-38℃(適温25-35℃)で、幅は10℃にすぎない。10℃以下で生長が止まり、0℃で地上部が枯れ、霜が1回降りただけで作期が終わる |
| 水、日照 | 年間降水量500-1,500mm(500mmを下回っても収量が減るだけ)。1日6-8時間以上の日照(40%の遮光で相対収量は約80%) |
| 土壌 | pH4.0-8.0(適正5.5-6.5)。水はけのよい砂壌土-壌土が適正で、冠水や粘土質では根が腐る |

&nbsp;&nbsp;&nbsp;韓国中部で日平均気温が20℃を超える期間は4か月ほどなので、5月上旬に植えて10月末に掘る作期で、熱帯の収量の半分が出ればうまくいったといえます。南向きで風が遮られた水はけのよい砂質の土地が適しており、水がたまる低地と冷気がたまる盆地は避けます。

| 区分 | 甘味種 | 苦味種 |
|:---|:---|:---|
| シアン含量(生重量1kg) | 約50mg以下 | 100mgから1,000mg以上 |
| 処理 | 厚くむいて十分にゆでる | すりおろして発酵、乾燥、浸漬などの多段階の処理が必須 |
| 収量、防御 | 収量が低く、獣や盗難の被害が大きい | 収量とでんぷん含量が高く、苦味が防御手段になる |

> **苦味とシアン含量は正確には比例しないので、品種のわからないキャッサバはすべて苦味種として扱って処理します。**

&nbsp;&nbsp;&nbsp;処理の知識と道具がない場合や子どもと高齢者がいっしょに食べる場合は甘味種を、でんぷんや粉にして備蓄する場合や獣の被害が大きい場合は苦味種を選びます。韓国の露地には早生の系統が向きます。

## 4. 畑の準備と挿し木
| 項目 | 基準 |
|:---|:---|
| 整地 | 深さ20-30cmに耕し、高さ30cm以上の高い畝ごとに排水溝をつくる(水がたまると数日で根が腐る)。韓国では黒いマルチや灰で初期の地温を確保 |
| 施肥(1,000㎡) | 窒素8-12kg、リン酸6-10kg、カリウム8-12kg(でんぷんの蓄積にもっとも重要)、完熟堆肥1,000-1,500kg。窒素は元肥と追肥に分け、残りは全量を元肥にする。無肥料でも収穫できるがカリウムが枯渇する |
| 災害時の代替肥料 | 木灰(㎡当たりひとつかみかふたつかみ、カリウムの供給にもっとも重要で、多いとpHが上がる)、収穫後の茎・葉・皮を畑に戻す(皮はシアンがあるので腐らせてから使う)、6か月以上寝かせた堆肥、尿の10倍希釈液 |
| 挿し穂 | 茎の中ほどの硬くて健全な直径2-3cmのものを、節3-5個、15-20cmに斜めに切り、切り口に木灰をつけて日陰で1日乾かす。上下は葉痕で見分け(葉痕が上向きの半月形で、その上側に芽)、迷ったら寝かせて挿す。ウイルスに感染した挿し穂は収量を30-40%下げる |
| 植え付け | 5月上旬の遅霜が終わった直後(1日でも早いと全滅し、遅いと作期が足りない)。深さ5-10cm、15-45度に斜めに挿すと根が片側に集まって掘りやすい。株間・列間は80-100cm。草丈15-20cmのとき1つの穴に丈夫な1-2本だけを残す |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 挿し木の直後 | たっぷり湿らせる(根づくまでは蓄えた養分だけで耐えるので、乾くと枯れる) |
| 活着から栄養生長期 | 自然の降雨に任せる |
| 塊根の肥大期 | ひどい干ばつのときだけ補う(この時期の乾燥は収量に直接影響する)。収穫の2-3週間前は灌水を止める(皮が固まってでんぷんが充実する) |

| 管理 | 方法 |
|:---|:---|
| 雑草 | 収量を分けるいちばん大きな変数は初期の雑草管理。植え付け後3か月は2-3回草取りし、4か月以降は葉が地面を覆ってほとんど不要 |
| 土寄せ | 生育中に1-2回、株元に土を寄せて倒伏を防ぎ、雨が多い時期は畝を再び高くし、露出した根は土で覆う |
| 葉の収穫 | 生育中期以降に、上のほうの若い葉を数枚ずつだけ摘んで野菜として使う(摘みすぎると根が小さくなる)。必ず第10節の葉の処理の手順に従う |
| 過湿 | 下葉が黄色くなって株元が黒ずんだらただちに排水溝を掘り、根が柔らかくなって悪臭がしたらその区画をあきらめる |

> **キャッサバは干ばつでは枯れず、水で枯れます。水がたまる場所には植えません。**

## 6. 病害虫と養分の問題
&nbsp;&nbsp;&nbsp;キャッサバの病気は、ほぼすべて挿し穂に乗って入ってくるため、防除の核心は薬ではなく挿し穂の選別(病徴のある株からは挿し穂をとらない、防除の8割)です。病株は症状が見えたらその場で抜いて焼き、同じ畑で連作せず、寄生バチやテントウムシなどの天敵を守ります。

| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| キャッサバモザイク病、キャッサバ褐色条斑病 | 葉にモザイク模様が出て縮れ、収量が30-70%減る / 茎に褐色の筋が出て、根の中が褐色に腐り、作物全体が失敗することがある | 治療法がないので、抵抗性品種と健全な挿し穂を使い、感染株を抜いて焼く |
| コナジラミ、アブラムシ、ハダニ | コナジラミとアブラムシは汁を吸ってウイルスを運ぶ / ハダニは乾燥期に葉が黄色くまだらになって落ちる | 黄色い粘着トラップ、周囲の雑草の除去、水洗い、石けん水 / 葉裏に水をかける |

| 症状 | 原因と対処 |
|:---|:---|
| 葉全体が黄色くなって株が小さい / 茎と葉ばかり茂って根が細い | 窒素欠乏。完熟堆肥と尿の10倍希釈液 / 窒素過剰。窒素を止めて木灰でカリウムを補う |
| 葉の縁が褐色に枯れる(塊根の肥大期) | カリウム欠乏で、もっともよく見られ、被害も大きい(葉は健全に見えても根が細いまま)。木灰 |
| 葉が濃い紫色になる | リン欠乏(酸性土壌でよく見られる)。骨粉と木灰 |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | マメ科作物(窒素を固定し、キャッサバが地面をまだ覆えない最初の4か月の空き地で収穫できる)、トウモロコシ(初期生育が遅い間に先に収穫できる)、カボチャ・サツマイモ(地面を覆い、雑草と侵食を減らす) |
| 普通 | 葉菜類(畝の間に植えて早めに収穫) |
| 悪い | 同じ畑での連作(病原菌がたまり、カリウムが枯渇する)、トウダイグサ科の作物(同じ病気を共有する) |

&nbsp;&nbsp;&nbsp;キャッサバは痩せた土地でも育ちますが、残っている養分を最後まで吸い尽くすため、同じ畑に何年も続けて植えるとキャッサバさえ育たなくなります。順序は、1年目キャッサバ、2年目マメ科(窒素の回復)、3年目葉菜類か穀物、4年目に再びキャッサバで、3-4年の間隔を守ります。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | すぐ食べる用は挿し木から6-8か月、でんぷん・粉に加工する用は8-12か月、12-24か月では硬くなるが食べられる。韓国の露地は10月末に収穫し、初霜の予報が出たら未熟でも掘る |
| 要領 | 晴れて乾いた日に、地上部を30-50cm残して切り、持ち手にして、株の周りを掘ってゆるめたあと、反対側からてこのように持ち上げる。根を折らないよう注意する(折れた面から腐敗が始まる)。土を払うだけで洗わず、残った茎は挿し穂用に集める |
| 収穫後 | 白い果肉は24-48時間で青みがかった筋が出て、48-72時間で褐色になって苦味が出て、3-5日で腐る。掘った当日に皮をむいて切って乾かさなければならないので、今週食べて加工できる分だけを掘る |

| 採種 | 基準 |
|:---|:---|
| 挿し穂 | 茎がそのまま種子。10月末の収穫と同時に、中ほどの直径2-3cmの茎を切らず、1m前後の長い節のまま、10℃以上で凍らず乾かない場所に、最長2-3か月保管(長いほど活着率が下がる) |
| 越冬 | 種子の寿命Eの実体。露地に放置すれば必ず枯れる。濡れた砂に株元を埋めるか、温室・ビニールトンネルに仮植えすれば成功率が高く、室内の涼しい場所(10-15℃)に束にして立てるか、土室・穴蔵(5℃を下回ると失敗)に置けば中程度で、鉢に植えて15℃以上の明るい室内で生きた株のまま越すのがもっとも確実。複数の方法を同時に使う |

> **韓国でキャッサバ栽培の成否を決めるのは、畑ではなく冬の室内です。挿し穂を失えば、翌年のキャッサバはありません。**

## 9. 貯蔵
&nbsp;&nbsp;&nbsp;キャッサバは根なので、傷をコルク層でふさげず、掘ってから2、3日で変質するため、貯蔵の戦略は、掘らずに地中に置くか、掘ってすぐ加工するかの2つしかありません。

| 方式 | 方法 | 期間 |
|:---|:---|:---|
| 地中での貯蔵 | 収穫せず、地上部を生かしたまま必要な株だけを掘る。電力・設備・労力が要らず鮮度がもっとも高いが、時間がたつほど硬くなり、イノシシや齧歯類に狙われる。韓国では霜で地上部が枯れ、根もすぐ傷むので成り立たない | 8か月目から24か月まで |
| 掘ったあとの短期保管 | 丸ごとの根を濡れた砂や土に埋める(1-2週間)。切り口と傷を粘土の泥でふさぐと2-4週間。水に浸かるように入れて水を替えれば3-7日 | 2日から4週間 |
| 乾燥チップ、粉 | 皮をむいて5mm以下に切り、4-7日完全に乾燥(解毒と貯蔵を同時に解決)。チップを挽いた粉は、灰や炭を乾燥剤として入れて密閉 | 1-2年 |
| でんぷん(タピオカ) | 皮を厚くむいた根を完全にすりつぶして布に包み、水の中でもみ、30分-1時間沈めたあと上水を捨てて新しい水を注ぐことを3-4回くり返し、沈殿を乾かす。根100kgから20-25kgとれ、虫がほとんどつかず、解毒効果がもっとも高い。上水は毒が溶けているので捨てる | 数年 |

> **韓国では地中での貯蔵ができないので、10月末にすべて掘ってすぐ加工しなければなりません。**

## 10. 調理と注意事項
&nbsp;&nbsp;&nbsp;青酸配糖体(大部分はリナマリン)は全部位にあり、皮は果肉の数倍から数十倍、葉はしばしば根より多く含みます。生の根のシアン換算量は1kg当たり、甘味種が約50mg以下、苦味種が100-1,000mg以上ですが、成人の急性致死量は約30-200mgなので、1,000mg級の苦味種の根200g(一食分)で致死量の範囲の上限に達します。どの品種でも生で食べてはいけません。この物質自体は毒ではなく、組織が壊れると(皮をむく、切る、かむとき)酵素リナマラーゼが分解してシアン化水素(沸点26℃)をつくります。したがって、まず細胞を壊して酵素を働かせ、時間をかけてシアン化水素まで進め、それを空気中に飛ばすか水で洗い流してから、最後に加熱します。

> **ゆでることはシアン化水素を飛ばしますが、まだシアン化水素になっていないリナマリンはそのまま残します。そしてそのリナマリンは、人の腸の中で毒に変わります。**

&nbsp;&nbsp;&nbsp;大きな塊をそのままゆでると、熱が内部に届く前に酵素が先に死に(約72℃)、熱に安定なリナマリンが残って、食べたあとに腸内細菌が分解し、体内でシアンが出ます。苦味種は、下の手順を飛ばすと、どれだけ長く煮ても危険が残ります。

| 段階 | 方法 |
|:---|:---|
| 皮むき | シアンは皮(2-3mm)に集中しているので、外側の褐色の層と内側の白い層をいっしょに厚くむき、中心の硬い芯も除く。むいた面がなめらかな白でなければならず、ピンクや淡い層が残っていればむき足りない。皮は食べず、腐らせて堆肥にする |
| 水に浸す | 甘味種の切り身は6-12時間、苦味種の切り身は24-72時間、苦味種の丸ごとの根は3-6日(完全に浸かるように)。1日1回以上水を替え(替えなければそれ以上抜けない)、暖かいほど速い。密閉容器はガスがたまるので使わず、浸した水は飲んだり、家畜に与えたり、畑に捨てたりしない |
| すりおろして発酵 | もっとも効果が大きい(95%以上除去)。皮をむいた根を完全につぶし、日陰で3-5日発酵させ、石で押して汁をしぼって捨てたあと、残りを炒めるか蒸して食べる。苦味種を大量に処理するのにもっとも確実(西アフリカのガリの方式) |
| 完全乾燥 | 5mm以下に薄く切り、日なたで4-7日、パキッと音をたてて折れるまで乾かす(除去率60-90%)。乾ききっていないものを袋に入れるとカビが生え、毒も残る |
| 十分な加熱 | 前の段階を経たあと、2-3cmの切り身を沸騰した湯で20-30分、ふたを開けてガスを逃がし、ゆで汁は必ず捨てる。苦味と渋みが残ってはならず、室内で大量にゆでるときは換気する |

&nbsp;&nbsp;&nbsp;甘味種は、皮むき、6-12時間の浸漬、20-30分のゆで時間で1日、苦味種は家庭で食べる場合が1-2週間、大量加工が1週間(すりおろし、発酵、圧搾、炒め)かかり、品種がわからなければ苦味種の手順に従います。乾燥させて挽いた粉にもリナマリンが残っていることが多いので、同じ体積の水を混ぜて1cm以下に薄く広げ、日陰で5時間以上置いてから調理します。葉は、太い葉柄を取ってすり鉢で完全につぶし、水を替えながら30分以上ゆでてゆで汁を捨て、さっと湯通しする青菜のような方式は危険です。

| 危険 | 内容 |
|:---|:---|
| 急性中毒 | 摂取後、数十分から6時間でめまい、頭痛、吐き気、嘔吐、腹痛、下痢で始まり、呼吸が速く浅くなって意識がもうろうとし、重症では痙攣、チアノーゼ、意識消失、呼吸麻痺、死亡に至る。子どもは体重当たりの摂取量が大きく、同じ量でもはるかに危険。疑われたら、それ以上食べさせず、残った食べ物を片づけ、新鮮な空気が通る場所に寝かせて安静にし、意識があれば水を少しずつ与えるが無理に吐かせず、意識が落ちたら横向きに寝かせて気道を確保する。医療が届かなければ、予防が唯一の対策 |
| 慢性中毒 | コンゾは、処理が不十分な苦味種を数週間以上食べ続けたとき、数時間から数日で両足がこわばって歩けなくなる病気(子どもと妊娠可能な年齢の女性に多い)で、熱帯性運動失調性神経障害は、数年かけて歩行がふらつき、視力と聴力が落ちる病気(40歳以上)。どちらも回復せず、治療法がなく、タンパク質欠乏が重なると急激に増える |
| タンパク質、ヨウ素 | シアンは肝臓でタンパク質の硫黄を使ってチオシアン酸塩になり、尿に出るので、タンパク質が熱量のわずか3.4%のキャッサバだけを食べると解毒能力が落ちる。豆、魚、卵、キャッサバの葉のどれかをいっしょに食べる必要があり、チオシアン酸塩が甲状腺のヨウ素の取り込みを妨げるので、塩と海藻も確保する |

| 調理 | 方法 |
|:---|:---|
| 燃料の節約 | 加熱時間を縮めることはキャッサバでは危険なので、節約は前の段階で行う。あらかじめすりおろし、浸し、乾かして粉にしておけば、沸騰した湯に溶くだけで火が通る。解毒を終えたものは、15分煮立てたあと火を止めて包み、1時間置く方法も使える |
| 食べ方 | 粉は穀物の粉と混ぜて、粥、生地、餅にする。中に青い筋や褐色の部分がある根は、その部分をくり抜き、ひどければ全量廃棄する |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 挿し穂の越冬管理(10℃を下回らないよう守る、もっとも危険な時期)、加工品の点検。2月に乾いたり柔らかくなった茎を取り除き、畑の計画 |
| 3-4月 | 3月に畑の準備、高い畝と排水溝、堆肥の施用。4月に挿し穂を切り、地温を確保 |
| 5-6月 | 5月上旬の遅霜の直後に挿し木を植え付け。活着のための灌水、間引き、1回目の草取り |
| 7-8月 | 7月に2回目の草取り、土寄せ、上のほうの若い葉の収穫開始。8月に台風対策(株元に土を寄せる) |
| 9-10月 | 9月、塊根の肥大期に干ばつ時の灌水。10月に灌水を止め、霜の予報を確認。10月末に全量収穫、挿し穂の採取、掘った当日に皮をむいて切って乾かす |
| 11-12月 | 11月に乾燥とでんぷん加工の仕上げ、茎・葉・皮を畑に戻し、挿し穂の越冬準備。12月に挿し穂の越冬管理と粉の保管点検 |

> **キャッサバは、空腹なほど手順を省かず、ゆでるだけで終わらせず、キャッサバだけを食べず、掘った当日に加工し、挿し穂を冬の室内で守らなければならない作物です。**
