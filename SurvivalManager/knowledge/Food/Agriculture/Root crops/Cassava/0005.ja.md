## 14. シアン配糖体と毒性除去

&nbsp;&nbsp;&nbsp;この節は料理法ではありません。この節の内容を知らずにキャッサバを食べると、人が死ぬか、一生歩けなくなります。キャッサバを食料として扱おうとする人は、栽培法よりも先にこの節を身につけなければなりません。

### 14-1. 何が含まれているか

&nbsp;&nbsp;&nbsp;キャッサバのすべての部位にはシアン配糖体が含まれています。大部分はリナマリンで、約5%がロタウストラリンです。この物質自体は毒ではありません。毒はそれが分解されるときに生じます。

| 順序 | 何が起こるか |
|---|---|
| 1 | リナマリンは細胞内の液胞に入っています |
| 2 | リナマレースという酵素は、細胞壁側に別に存在します |
| 3 | 組織が壊れると両者が出会います。皮をむいたり、切ったり、噛んだりするときです |
| 4 | 酵素がリナマリンを切断し、ブドウ糖とアセトンシアノヒドリンを作ります |
| 5 | アセトンシアノヒドリンは、pH5以上または35℃以上であれば自然に分解します |
| 6 | その結果、アセトンとシアン化水素（HCN）、すなわち青酸ガスが生じます |
| 7 | シアン化水素は沸点が26℃で、揮発性が高いです |

&nbsp;&nbsp;&nbsp;この七つの段階に、キャッサバ処理のすべての原理が含まれています。毒性除去とは、結局のところリナマリンをシアン化水素に変えたうえで、それを空気中に飛ばすか水で洗い流すことです。そのためには、まず細胞を壊して酵素と基質を出会わせなければならず、次に時間と温度と空気を与えてガスを抜けさせなければなりません。

### 14-2. どれほど危険か

| 項目 | 数値 |
|---|---|
| 低苦味種の生の根 | 生重量1kgあたりシアン相当量約50mg以下 |
| 高苦味種の生の根 | 100mgから1,000mg以上まで |
| 皮（内側の白い層を含む） | 果肉より数倍から数十倍高いです |
| 葉 | しばしば根より高いです |
| 国際基準（キャッサバ粉） | 乾燥重量1kgあたりシアン相当量10mg以下 |
| 成人の急性致死量 | 体重1kgあたりシアン化水素約0.5-3.5mg |
| 60kg成人換算 | およそ30-200mg |

&nbsp;&nbsp;&nbsp;この表を掛け合わせてみると、事態がはっきりします。シアン相当量1,000mgの高苦味種の根200g、つまり一食分には、シアン相当量（200mg）が含まれていることになります。これは成人致死量範囲の上限に相当します。未処理の高苦味種キャッサバの一食分が人を死なせ得るという話は誇張ではありません。子どもならはるかに少ない量でも危険です。

### 14-3. なぜ煮るだけでは不十分なのか

&nbsp;&nbsp;&nbsp;最も重要で、最も誤解されやすい部分です。常識的に考えれば長く煮れば毒が飛んでいきそうですが、丸ごと、あるいは大きな塊のまま煮ると、かえって毒が残ります。理由は酵素にあります。

| 状況 | 起こること |
|---|---|
| 大きな塊のまま煮ます | 熱が内部まで届く間に酵素が先に破壊されます |
| 酵素が死にます | リナマレースは約72℃で活性を失います |
| リナマリンはそのまま残ります | リナマリン自体は熱に安定しており、煮ても、ほとんど分解されません |
| 人が食べます | 腸内の細菌がリナマリンを分解します |
| 体内でシアンが生じます | 数時間後に中毒症状が現れます |

> **煮ることはシアン化水素を飛ばしますが、まだシアン化水素になっていないリナマリンはそのまま残します。そして、そのリナマリンは人の腸の中で毒に変わります。**

&nbsp;&nbsp;&nbsp;したがって、処理の順序が決定的です。まず細胞を壊して酵素を働かせ、十分な時間を与えてリナマリンがアセトンシアノヒドリンを経てシアン化水素になるまで進ませ、最後に加熱します。すりつぶし、水に浸し、発酵させ、乾燥させるすべての手順は、この順序を作るためのものです。低苦味種はもともと含有量が低いため皮むきと煮ることだけで安全線を下回りますが、高苦味種でこの順序を飛ばすと、どれだけ長く煮ても危険は残ります。

### 14-4. 高苦味種と低苦味種の見分け方

| 方法 | 信頼度 | 説明 |
|---|:---:|---|
| 品種情報 | 最も高い | 系統が分かって植えたなら、それに従います |
| 味 | 普通 | 生のものをごく少量舌に当てると、高苦味種は強く苦いです。飲み込みません |
| 皮の色と厚さ | 低い | 参考程度にとどめます |
| 栽培条件 | 参考 | 干ばつや痩せた土壌では、同じ品種でもシアン含有量が上がります |

> **苦味とシアン含有量はおおむね比例しますが、正確には比例しません。品種が分からないキャッサバは、すべて高苦味種として扱い処理します。この原則一つが、事故の大部分を防ぎます。**

### 14-5. 除去手順 - 段階別

#### 14-5-1. 皮むき

| 項目 | 内容 |
|---|---|
| 原理 | シアン配糖体が皮に集中しています |
| 方法 | 縦に切れ目を入れたあと、外側の褐色層と内側の白い層を一緒にむきます |
| 厚さ | 皮全体の厚さは2-3mmです。薄くこそげ取るだけでは意味がありません |
| 判断 | むいた面がなめらかな白色になっていなければなりません。ピンク色や薄い層が残っていれば、むき足りません |
| 除去率 | 総量のかなりの部分がこの段階でなくなります |
| 皮の処理 | 人も家畜も食べません。十分に腐らせて堆肥として使います |
| 中心の芯 | 中央の硬い繊維質の芯も一緒に取り除きます |

#### 14-5-2. 水に浸す

| 項目 | 内容 |
|---|---|
| 原理 | シアン配糖体とその分解産物が水に溶けて抜け出します |
| 低苦味種 | 切り分けて6-12時間で十分です |
| 高苦味種（丸ごと） | 3-6日。皮をむいて水に完全に浸します |
| 高苦味種（切り分け） | 24-72時間。切り分けが小さいほど速くなります |
| 水替え | 1日1回以上取り替えます。替えないと濃度が平衡に達し、それ以上抜けなくなります |
| 温度 | 暖かいほど速くなります。30度前後が効率的です |
| 浸した水 | 毒が溶けています。人も家畜も飲まず、畑にも捨てません |
| 注意 | 密閉容器に浸しません。ガスがたまります |

#### 14-5-3. すりつぶして発酵させる

| 項目 | 内容 |
|---|---|
| 原理 | 細胞を最大限に壊し、酵素が全面的に働くようにします。最も効果が大きいです |
| 方法 | 皮をむいた根をおろし金や石臼で完全にすりつぶします |
| 発酵 | すりつぶしたものを袋や容器に入れ、日陰で3-5日置きます |
| 圧搾 | 袋に入れて石で押さえ、汁を搾り出します。汁に毒が溶けています |
| 匂い | 酸っぱい発酵臭がします。これは正常です |
| 除去率 | きちんと行えば95%以上除去されます |
| その後 | 搾った後の塊を炒めるか蒸して食べます |
| 注意 | 搾った汁は捨てます。でんぷんを回収したい場合は、汁を沈殿させて沈殿物だけを何度もすすいで使います |

&nbsp;&nbsp;&nbsp;西アフリカのガリ（発酵させたキャッサバ加工品）やフフ（キャッサバの主食料理）がこの方式です。すりつぶし、袋に入れて数日発酵させ、押して搾り、再び炒めるか蒸すという四段階が、何世代にもわたって磨き上げられた解毒工程です。災害時に高苦味種を大量に処理しなければならないなら、この方式が最も確実です。

#### 14-5-4. 完全乾燥

| 項目 | 内容 |
|---|---|
| 原理 | 薄く切ると酵素が働き、乾く間にシアン化水素が空気中に飛んでいきます |
| 厚さ | 5mm以下の薄さに切ります。厚いと内部に残ります |
| 方式 | 天日に干します。4-7日 |
| 陰干し | 天日より遅いですが、酵素がより長く働くため除去率がかえって高いという報告があります |
| 判定 | パキッと音を立てて折れ、手で砕けるようになるまで乾かします |
| 除去率 | 条件により60-90% |
| 注意 | 乾き切っていないものを袋に入れるとカビが生え、毒も残ります |

#### 14-5-5. 十分な加熱

| 項目 | 内容 |
|---|---|
| 原理 | 残ったシアン化水素を飛ばし、でんぷんを加熱します |
| 低苦味種 | 2-3cmの切り分けにして沸騰した湯で20-30分。蓋をしません |
| 高苦味種 | 前段階を経たあとに加熱します。加熱だけでは不十分です |
| 煮汁 | 必ず捨てます。シアンが溶けています |
| 蓋 | 開けておきます。ガスが抜けなければなりません |
| 換気 | 室内で大量に煮るときは窓を開けます |
| 判定 | 苦味と渋味が完全になくならなければなりません |

### 14-6. 品種別の最小手順

| 区分 | 手順 | 所要時間 |
|---|---|---|
| 低苦味種 | 皮を厚くむく、切り分ける、水に6-12時間浸す、水を捨てて20-30分煮る、煮汁を捨てる | 1日 |
| 高苦味種（家庭食用） | 皮をむく、切り分ける、水に3-5日浸し毎日水を替える、5mmに切って4-7日完全乾燥、粉に挽く、調理時に十分加熱 | 1-2週間 |
| 高苦味種（大量加工） | 皮をむく、完全にすりつぶす、袋に入れて3-5日発酵、押して搾る、炒めるか蒸す | 1週間 |
| 品種不明 | 高苦味種の手順に従います | - |

### 14-7. 粉を再び湿らせる方法

&nbsp;&nbsp;&nbsp;乾かして挽いたキャッサバ粉にも、リナマリンが残っている場合が多くあります。乾燥が不十分だったり、急いで乾かしたりした粉は特にそうです。この残留分をさらに減らす簡単な方法があります。

| 順序 | 内容 |
|---|---|
| 1 | 粉に同じ体積の水を混ぜ、湿った生地状にします |
| 2 | 広い器や板に厚さ1cm以下に薄く広げます |
| 3 | 日陰で5時間以上そのまま置きます |
| 4 | この間に、粉に残っていた酵素がリナマリンを分解し、シアン化水素が飛んでいきます |
| 5 | その後、普段どおり煮るか蒸して食べます |

&nbsp;&nbsp;&nbsp;原理は単純です。リナマレースは乾燥状態では働けませんが、死にもしません。水に触れると再び活性を取り戻します。薄く広げる理由は、生じたガスが早く抜けるようにするためであり、日陰に置く理由は直射日光が酵素を破壊するからです。この一段階を加えるだけで、残留シアンが数分の一に減ります。道具も燃料も要らないため、災害時に特に価値が大きいです。

### 14-8. 葉の処理

| 項目 | 内容 |
|---|---|
| 栄養 | 生重量100gあたりタンパク質5-10g。リジンが豊富です |
| 危険性 | シアン含有量がしばしば根より高いです |
| 第1段階 | 若葉を摘み、太い葉柄を取り除きます |
| 第2段階 | 臼に入れて完全につき砕きます。細胞を壊すことが要点です |
| 第3段階 | 30分以上、水を替えながら煮ます |
| 第4段階 | 煮汁は捨てます |
| 判定 | 苦味が残っていれば再び煮ます |
| 注意 | さっと湯通しして食べる方法は危険です。ナムルのように扱ってはいけません |

&nbsp;&nbsp;&nbsp;キャッサバの葉は、キャッサバ食の最大の弱点であるタンパク質不足を補うほぼ唯一の手段です。根だけを食べると熱量は満たされても体はやせ細っていきますが、葉を一緒に食べればその問題は大きく減ります。さらに葉は、根が熟す前の生育中期から摘めるため、収穫までの長い空白を埋めてくれます。ただし、シアン含有量が根より高いという点を忘れてはいけません。つき砕くことと長く煮ることの二段階は省略できません。

### 14-9. 急性中毒

| 項目 | 内容 |
|---|---|
| 発現時刻 | 摂取後数十分から6時間。腸内細菌による分解を経ると、より遅く現れます |
| 初期症状 | めまい、頭痛、吐き気、嘔吐、腹痛、下痢 |
| 進行症状 | 速く浅い呼吸、動悸、不安、朦朧状態 |
| 重症 | 痙攣、チアノーゼ、意識消失、呼吸麻痺、死亡 |
| 匂い | 苦いアーモンドの匂いがすることがありますが、この匂いを感じ取れない人がかなりいます |
| 弱者 | 子ども。体重当たりの摂取量が多く、同じ量でもはるかに危険です |

| 状況 | 対応 |
|---|---|
| 摂取直後に疑われるとき | それ以上食べさせず、残った食べ物を片付けます |
| 症状が出たとき | 新鮮な空気が通る場所に寝かせ、安静にさせます |
| 意識があるとき | 水を少しずつ与えます。無理に吐かせません |
| 意識低下、痙攣時 | 横向きに寝かせ気道を確保します |
| 回復後 | 原因となったキャッサバは全量廃棄し、処理手順を再点検します |
| 前提 | 医療の届かない状況でできることは限られています。予防が唯一の対策です |

### 14-10. 慢性中毒 - コンゾと神経障害

&nbsp;&nbsp;&nbsp;キャッサバで実際により多くの人を傷つけているのは、急性中毒ではなく慢性中毒です。急性中毒は目につきますが、慢性中毒は徐々に訪れます。

| 区分 | コンゾ | 熱帯性運動失調性神経障害 |
|---|---|---|
| 発現 | 突発的です。数時間から数日の間に現れます | 徐々に進行します。数年かかります |
| 主な症状 | 両足が硬直し、歩けなくなります | 歩行がふらつき、視力が落ち、耳が遠くなります |
| 対象 | 子どもと妊娠可能な年齢の女性に多いです | 40歳以上に多いです |
| 経過 | 回復しません。悪化が止まるだけです | 進行性です |
| 条件 | 処理が不十分な高苦味種を数週間以上食べ続けたとき | 処理不足の状態への長期曝露 |
| 悪化要因 | タンパク質欠乏が重なると急激に増えます | 同じです |
| 治療 | ありません | ありません |

&nbsp;&nbsp;&nbsp;コンゾがいつ発生するかを知ることが重要です。この病気はいつも飢饉とともにやって来ます。普段は三日浸すものを、空腹のあまり一日だけ浸し、七日乾かすものを二日で取り込んで食べてしまうからです。災害状況とは、まさにこうした近道を選びやすい状況であり、それゆえにこの節の手順が最も守られにくい状況でもあります。

### 14-11. タンパク質と解毒の関係

&nbsp;&nbsp;&nbsp;体内に入ったシアンは、肝臓でチオシアン酸塩に変えられ、尿として排出されます。この反応には硫黄が必要で、その硫黄はメチオニンやシステインのような含硫アミノ酸から供給されます。つまり、タンパク質を十分に食べる人はシアンを解毒できますが、タンパク質が不足している人は、同じ量のシアンでもはるかに大きな害を受けます。

| 状況 | 結果 |
|---|---|
| キャッサバだけを食べる | タンパク質が熱量比でわずか3.4%。解毒能力が落ちます |
| 解毒能力が落ちる | 同じシアンでもより大きく損傷します |
| 損傷が蓄積する | コンゾと神経障害の危険が高まります |
| 結果 | キャッサバだけを食べることが、毒をより毒性の強いものにします |

> **キャッサバを安全に食べるための最も重要な条件の一つは、キャッサバだけを食べないことです。豆、魚、卵、キャッサバの葉のいずれかを一緒に食べてこそ、体がシアンを処理できます。**

&nbsp;&nbsp;&nbsp;チオシアン酸塩はもう一つの問題も引き起こします。甲状腺がヨウ素を取り込むのを妨げ、ヨウ素が不足している地域では甲状腺腫やそれによる発育障害を増やします。海から遠く、塩や海藻を入手しにくい内陸地域でキャッサバに依存する際に、特に注意すべき点です。

### 14-12. 絶対にしてはいけないこと

| 禁止事項 | 理由 |
|---|---|
| 生で食べる | どの品種であっても禁止です |
| 皮を薄くしかむかない | シアンが最も多い部位がそのまま残ります |
| 大きな塊を丸ごと長く煮る | 酵素が先に死んでリナマリンがそのまま残ります |
| 蓋をして煮る | ガスが抜け出せません |
| 煮汁や浸した水を使う | 毒が溶けています。汁物には使いません |
| 浸した水を家畜に与える | 家畜も中毒します |
| 密閉容器で発酵させる | ガスがたまり危険です |
| 乾き切っていない粉を使う | シアンが残りカビが生えます |
| 苦味が残っているのに食べる | 処理が終わっていないという信号です |
| 手順を省く | 空腹であるほど手順を守らなければなりません |
