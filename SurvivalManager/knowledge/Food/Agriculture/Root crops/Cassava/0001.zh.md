---
## 引言
&nbsp;&nbsp;&nbsp;木薯（Manihot esculenta）是原产于巴西中西部的大戟科灌木，在地下粗大的块根里储满淀粉。干旱使谷物绝收的年份它也能撑住，在没有肥料的贫瘠红土上也能生长，过了收获期还能在地里再放一两年，因此被称为饥荒的最后一道屏障。在灾害应对评估中，它的综合等级为S（53.8分，有效183种中第7位），单位面积热量SS（每㎡4,000kcal，是自给线的1.53倍）在根茎·块茎类中最高。然而它的所有部位都含有含氰糖苷，未经处理的苦味品种一顿饭就能致人死亡，把处理不彻底的木薯连续吃几周到几个月，会得上双腿僵硬、无法行走的konzo（木薯中毒性痉挛性瘫痪）。konzo总是和饥荒一起到来，因为饿了的人会把本该泡三天的东西只泡一天。所以比起种植方法，更要先学会第10节的解毒步骤。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | S | 53.8 |
| 短期 | S | 51.9 |
| 长期 | S | 55.8 |
| 副食 | B | 48.1 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：单位面积热量、施肥、设施负担、自留种。S：水消耗量。A：微量营养素、持续性、连作适应性。B：光照、无合成投入产量保持率、整地·挖掘能量、产量稳定性 |
| 劣势 | E：蛋白质密度、烹调·加工要求度、耐寒性、耐储性、非食用价值、种子寿命。D：收获速度、国内种植普及度。C：温度幅度、病虫害压力、防治自立度、口味 |

> **木薯是以最少的投入产出最多热量的作物，同时也是要求最多处理劳动、承担最大风险的作物。**

&nbsp;&nbsp;&nbsp;单位面积热量SS，意思是65㎡出头就能供一个人一年的热量，是土豆（130㎡）的一半，而且不施肥也能收获。自留种SS是指它靠插茎繁殖，即使种子供应中断也能扩大面积；持续性A是指种下八个月就能吃，之后还可以在地里再放一两年。蛋白质密度E是指蛋白质只占热量的3.4%，仅为要求线10%的三分之一；烹调·加工E是因为要去除氰化物，这个项目为E的作物只有木薯。耐寒性E是指一次霜冻就会死，所以在韩国露地只能做5月扦插、10月底挖掘的一年一季；耐储性E是指挖出后2-3天就会变质。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 大戟科木薯属多年生灌木 |
| 叶、茎 | 裂成5-7片的掌状复叶。茎笔直站立，可长到2-4m |
| 块根 | 长20-50cm、重1-5kg，每株5-10个。没有芽眼，种下去也不发芽，所以繁殖要用茎 |

&nbsp;&nbsp;&nbsp;扦插后1-2个月，节上长出根和芽；2-6个月茎和叶扩展（初期生长慢）；6-10个月块根增粗（钾的需求最大）；10-12个月外皮变硬。每100g含热量160kcal（煮后112kcal），在根茎·块茎类中最高，碳水化合物38g几乎全是淀粉，蛋白质1.4g、脂肪0.3g、膳食纤维1.8g、维生素C 20.6mg。叶子每100g鲜重含蛋白质5-10g且赖氨酸丰富，能在很大程度上弥补根部蛋白质的不足。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 生长15-38℃（适宜25-35℃），幅度只有10℃。10℃以下生长停止，0℃地上部死亡，一次霜冻就结束一季 |
| 水分、光照 | 年降水量500-1,500mm（低于500mm只是产量下降）。每天6-8小时以上日照（遮光40%时相对产量约80%） |
| 土壤 | pH4.0-8.0（适宜5.5-6.5）。排水良好的砂壤土-壤土最适宜，淹水和黏土质土壤中根会腐烂 |

&nbsp;&nbsp;&nbsp;在韩国中部，日平均气温超过20℃的时期只有四个多月，所以5月初种下、10月底挖掘的一季里，能收到热带产量的一半就算很好。朝南、避风、排水良好的砂质地块较好，要避开积水的低洼地和冷空气聚集的盆地。

| 类别 | 甜味品种 | 苦味品种 |
|:---|:---|:---|
| 氰化物含量（每1kg鲜重） | 约50mg以下 | 100mg至1,000mg以上 |
| 处理 | 削厚皮并充分煮熟 | 必须经过磨碎发酵、干燥、浸泡等多步处理 |
| 产量、防御 | 产量低，兽害和被偷的损失大 | 产量和淀粉含量高，苦味成为防御手段 |

> **苦味与氰化物含量并不严格成正比，所以不知道品种的木薯一律按苦味品种来处理。**

&nbsp;&nbsp;&nbsp;缺少处理知识和工具、或者有儿童和老人一起吃时，选甜味品种；要储备淀粉和粉、或者兽害严重时，选苦味品种。韩国露地适合早熟品系。

## 4. 整地与扦插
| 项目 | 标准 |
|:---|:---|
| 整地 | 翻耕20-30cm深，起30cm以上的高垄，每条垄都留排水沟（积水几天就会烂根）。在韩国用黑色覆盖物或草木灰保证初期地温 |
| 施肥（1,000㎡） | 氮8-12kg、磷6-10kg、钾8-12kg（对淀粉积累最重要）、腐熟堆肥1,000-1,500kg。氮分基肥和追肥，其余全部作基肥。不施肥也能收获，但钾会耗尽 |
| 灾害替代肥料 | 木灰（每㎡一两小撮，是供钾最重要的来源，过多会抬高pH）、收获后把茎、叶、皮还回田里（皮含氰化物，要先沤烂再用）、沤制6个月以上的堆肥、稀释10倍的尿液 |
| 插穗 | 取茎中段结实健康、直径2-3cm的部分，斜切成15-20cm、带3-5个节的段，切口蘸木灰，在阴凉处晾一天。上下用叶痕分辨（叶痕为朝上的半月形，芽在其上方），拿不准就平放着插。感染病毒的插穗会使产量下降30-40% |
| 种植 | 5月初晚霜刚过之后（早一天就会全部冻死，晚了则生长季不够）。深5-10cm，以15-45度斜插，根会集中到一侧，便于挖掘。株距、行距80-100cm。苗高15-20cm时，每穴只留最壮的1-2根 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 扦插后立即 | 浇透（生根前只靠储存养分维持，干了就会死） |
| 生根到营养生长期 | 交给自然降水 |
| 块根膨大期 | 只在严重干旱时补水（这一时期的干旱直接影响产量）。收获前2-3周停止灌水（外皮变硬，淀粉充实） |

| 管理 | 方法 |
|:---|:---|
| 杂草 | 决定产量的最大变量是前期杂草管理。种后3个月除草2-3次，4个月后叶子盖住地面，几乎不用再除 |
| 培土 | 生长期间1-2次在基部培土防倒伏，雨多时重新把垄堆高，露出的根要用土盖上 |
| 采叶 | 生长中期以后每次只摘几片上部嫩叶当蔬菜吃（摘多了根会变小）。务必遵循第10节的叶片处理步骤 |
| 积水 | 下部叶片发黄、基部发黑时立即疏通排水沟，根变软发臭就放弃这块地 |

> **木薯不是死于干旱，而是死于水。积水的地方不要种。**

## 6. 病虫害与养分问题
&nbsp;&nbsp;&nbsp;木薯的病害几乎都随插穗传入，所以防治的关键不是药，而是挑选插穗（不从有病症的植株上取插穗，这占防治的八成）。病株一出现症状就当场拔掉烧毁，不在同一块田里连作，并保护寄生蜂和瓢虫等天敌。

| 病虫害 | 症状与条件 | 不用药的防治 |
|:---|:---|:---|
| 木薯花叶病、木薯褐条病 | 叶片出现花叶斑纹并卷曲，产量下降30-70% / 茎上出现褐色条纹，根内部褐变腐烂，可能整茬作物失败 | 无法治愈，所以使用抗病品种和健康插穗，拔掉病株烧毁 |
| 粉虱、蚜虫、红蜘蛛 | 粉虱和蚜虫吸汁并传播病毒 / 红蜘蛛在干燥期使叶片发黄斑驳并脱落 | 黄色粘虫板、清除周边杂草、水洗、肥皂水 / 向叶背喷水 |

| 症状 | 原因与措施 |
|:---|:---|
| 整片叶子发黄、植株矮小 / 只有茎叶茂盛、根很细 | 缺氮。腐熟堆肥和稀释10倍的尿液 / 氮过剩。停止施氮，用木灰补钾 |
| 叶缘焦褐（块根膨大期） | 缺钾，最常见且损失最大（叶子看起来正常但根仍很细）。木灰 |
| 叶片变成深紫色 | 缺磷（酸性土壤中常见）。骨粉和木灰 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 豆科作物（固氮，并在木薯还没盖住地面的头四个月空地上收获）、玉米（趁木薯初期生长慢时先收）、南瓜·甘薯（盖住地面，减少杂草和侵蚀） |
| 一般 | 叶菜类（种在垄间，早点收获） |
| 差 | 同一块田连作（病原菌积累、钾耗尽）、大戟科作物（共有相同病害） |

&nbsp;&nbsp;&nbsp;木薯能在贫瘠的土地上生长，但会把剩下的养分吸到底，所以在同一块田里连续种几年，连木薯都长不出来。顺序是第一年木薯、第二年豆科（恢复氮）、第三年叶菜或谷物、第四年再种木薯，间隔保持3-4年。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 即食的在扦插后6-8个月，加工淀粉和粉的在8-12个月，12-24个月会变老，但仍可食用。韩国露地在10月底收获，一旦发布初霜预报，即使没完全成熟也要挖 |
| 要领 | 选晴朗干燥的日子，留30-50cm把地上部砍断当把手，把植株周围挖松，再从另一侧像撬杠一样提起。小心不要弄断根（断面会开始腐烂）。只抖掉泥土，不要水洗，剩下的茎收集起来作插穗 |
| 收获后 | 白色果肉24-48小时出现青色条纹，48-72小时变褐并带苦味，3-5天开始腐烂。因为必须在挖出当天削皮、切片、晒干，所以只挖这周能吃完、加工完的量 |

| 留种 | 标准 |
|:---|:---|
| 插穗 | 茎就是种子。10月底收获时，把中段直径2-3cm的茎不切断，留成1m左右的长段，放在10℃以上、不结冰也不干燥的地方，最多保存2-3个月（越久生根率越低） |
| 越冬 | 这就是种子寿命E的实质。放在露地一定会死。把基部埋进湿沙，或移栽到温室、塑料棚里，成功率高；在室内凉爽处（10-15℃）成捆立放，或放进土窖、地窖（低于5℃就失败），成功率中等；种在花盆里，在15℃以上的明亮室内以活株形式过冬最为可靠。要同时使用多种方法 |

> **在韩国，木薯种植的成败不是在田里，而是在冬天的室内决定的。丢了插穗，来年就没有木薯。**

## 9. 储存
&nbsp;&nbsp;&nbsp;木薯是根，无法用木栓层封住伤口，挖出后2-3天就会变质，所以储存策略只有两条：不挖出来留在地里，或者挖出后马上加工。

| 方式 | 方法 | 期限 |
|:---|:---|:---|
| 地里储存 | 不收获，保留地上部存活，只挖需要的植株。不需要电力、设施和劳动，新鲜度最高，但随时间变老，还会被野猪和啮齿动物盯上。在韩国行不通，因为霜冻使地上部死亡，根也很快变坏 | 从第8个月到第24个月 |
| 挖出后短期保存 | 把整根埋进湿沙或土里（1-2周）。用黏土泥浆封住切口和伤口可保存2-4周。泡在水里并换水可保存3-7天 | 2天到4周 |
| 干燥片、粉 | 削皮后切成5mm以下，彻底晒干4-7天（同时解决解毒和储存）。把干片磨成的粉装进密封容器，放灰或木炭作干燥剂 | 1-2年 |
| 淀粉（木薯淀粉） | 把削厚皮的根彻底磨碎，用布包着在水中揉洗，静置30分钟到1小时后倒掉上层水、加新水，重复3-4次，再晒干沉淀物。100kg的根能得20-25kg，几乎不生虫，解毒效果最好。倒出的上层水含毒，要丢弃 | 数年 |

> **在韩国无法在地里储存，所以必须在10月底全部挖出并立即加工。**

## 10. 烹调与注意事项
&nbsp;&nbsp;&nbsp;含氰糖苷（主要是亚麻苦苷）存在于所有部位，皮中含量是果肉的几倍到几十倍，叶子往往比根还高。鲜根的氰化物当量每1kg甜味品种约50mg以下，苦味品种100-1,000mg以上，而成人急性致死量约30-200mg，所以1,000mg级苦味品种的根200g（一顿饭）就达到致死范围的上限。不管什么品种都不要生吃。这种物质本身不是毒，组织一旦破碎（削皮、切、咀嚼时），亚麻苦苷酶就会将其分解，生成氰化氢（沸点26℃）。所以要先破碎细胞让酶发挥作用，留出时间使其进行到氰化氢，再让它散入空气或用水冲走，最后才加热。

> **煮可以把氰化氢驱走，但还没变成氰化氢的亚麻苦苷会原样留下。而这些亚麻苦苷在人的肠道里会变成毒。**

&nbsp;&nbsp;&nbsp;把大块整个煮的话，热量还没传到内部，酶就先死了（约72℃），耐热的亚麻苦苷留了下来，吃下去后肠道细菌将其分解，在体内放出氰化物。如果跳过下面的步骤，苦味品种无论煮多久都仍有危险。

| 步骤 | 方法 |
|:---|:---|
| 削皮 | 氰化物集中在皮（2-3mm）里，所以要把外层褐色和内层白色一起削厚，并去掉中间发硬的芯。削后的表面必须是光滑的白色，若还留有粉色或浅色层就是没削够。皮不能吃，要沤烂做堆肥 |
| 浸泡 | 甜味品种的块6-12小时，苦味品种的块24-72小时，苦味品种的整根3-6天（完全浸没）。每天至少换一次水（不换就不再析出），越暖越快。不要用密封容器，因为会积聚气体，泡过的水不能喝、不能喂牲畜、也不能倒在田里 |
| 磨碎发酵 | 效果最大（去除95%以上）。把削皮后的根彻底捣碎，在阴凉处发酵3-5天，用石头压出汁液丢弃，再把剩下的炒或蒸着吃。是大量处理苦味品种最可靠的办法（西非加里的做法） |
| 彻底干燥 | 切成5mm以下的薄片，在阳光下晒4-7天，直到一折就啪地断开（去除率60-90%）。没干透就装袋会长霉，毒也会残留 |
| 充分加热 | 经过前面的步骤后，把2-3cm的块放进沸水煮20-30分钟，开盖让气体散出，煮过的水一定要倒掉。苦味和涩味必须完全消失，在室内大量煮时要通风 |

&nbsp;&nbsp;&nbsp;甜味品种削皮、浸泡6-12小时、煮20-30分钟，一天就够；苦味品种家庭食用需要1-2周，大量加工需要1周（磨碎、发酵、压榨、炒），不知道品种时就按苦味品种的步骤来。干燥后磨成的粉里也常残留亚麻苦苷，所以要加等体积的水拌匀，摊成1cm以下的薄层，在阴凉处放5小时以上再烹调。叶子要去掉粗叶柄，在臼中彻底捣烂，换水煮30分钟以上，再倒掉煮过的水；像青菜那样快速焯一下是危险的。

| 危险 | 内容 |
|:---|:---|
| 急性中毒 | 吃后几十分钟到6小时开始头晕、头痛、恶心、呕吐、腹痛、腹泻，接着呼吸变快变浅、神志恍惚，重症则出现抽搐、发绀、意识丧失、呼吸麻痹乃至死亡。儿童按体重计的摄入量更大，同样的量危险得多。怀疑中毒时，不要让其再吃，收走剩下的食物，让人躺在空气新鲜的地方保持安静；有意识时少量多次给水，但不要强行催吐；意识下降时让其侧卧以保持气道通畅。医疗够不到时，预防是唯一的对策 |
| 慢性中毒 | konzo是连续几周以上吃处理不充分的苦味品种后，在几小时到几天内双腿僵硬、无法行走的疾病（多见于儿童和育龄女性）；热带共济失调性神经病是数年间步态不稳、视力和听力下降的疾病（40岁以上）。两者都无法恢复，也没有治疗方法，叠加蛋白质缺乏时会急剧增多 |
| 蛋白质、碘 | 氰化物在肝脏里借蛋白质中的硫变成硫氰酸盐，随尿排出，所以蛋白质只占热量3.4%的木薯，单吃会削弱解毒能力。要与豆、鱼、蛋、木薯叶中的任何一种一起吃；硫氰酸盐会妨碍甲状腺摄取碘，所以也要备好盐和海藻 |

| 烹调 | 方法 |
|:---|:---|
| 节省燃料 | 缩短加热时间对木薯很危险，所以要在前面的步骤里节省。预先磨碎、浸泡、晒干做成粉，只要倒进沸水里搅开就熟。对已完成解毒的，也可以煮沸15分钟后关火包好闷1小时 |
| 吃法 | 把粉与谷物粉混合做粥、面团和糕。里面有青色条纹或褐色的根，要挖掉那一部分，严重的整根丢弃 |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 插穗越冬管理（不让温度降到10℃以下，是最危险的时期），检查加工品。2月挑出干枯或变软的茎，规划田地 |
| 3-4月 | 3月整地、起高垄和排水沟、施堆肥。4月切插穗，保证地温 |
| 5-6月 | 5月初晚霜刚过就扦插定植。浇水促生根、间苗、第一次除草 |
| 7-8月 | 7月第二次除草、培土、开始采上部嫩叶。8月防台风（给基部培土） |
| 9-10月 | 9月块根膨大期干旱时灌水。10月停止灌水，确认霜冻预报。10月底全部收获，采集插穗，挖出当天削皮、切片、晒干 |
| 11-12月 | 11月完成干燥和淀粉加工，把茎、叶、皮还回田里，准备插穗越冬。12月管理插穗越冬，检查储存的粉 |

> **木薯是这样一种作物：越饿越不能省略步骤，不能只靠煮，不能只吃木薯，要在挖出当天加工，并在冬天的室内保住插穗。**
