## 3. 栽培环境

### 3-1. 临界值与最适值

| 项目 | 临界值 | 最适值 | 超出范围时 |
|---|---|---|---|
| 生长温度 | 15-38℃ | 25-35℃ | 幅度仅10℃，较窄。低于15℃生长基本停止 |
| 低温极限 | 10℃ | - | 10℃以下生长停止，0℃时地上部分枯死 |
| 霜冻 | 无法耐受 | - | 一次霜冻就会结束当年的作期 |
| 年降水量 | 500-1,500mm | 1,000-1,500mm | 低于500mm也能存活，只是产量会下降 |
| 总蒸散量 | - | 约400mm | 少于马铃薯的500-700mm |
| 土壤pH | 4.0-8.0 | 5.5-6.5 | 对酸性土壤的适应能力非常强 |
| 土壤 | 沙质土至壤土 | 排水良好的沙壤土 | 积水或排水不良地块中根会很快腐烂 |
| 海拔 | 0-1,500m | 低地 | 海拔越高气温越低，生长会延迟 |
| 光照 | 每天6-8小时 | 每天8小时以上 | 40%遮光时相对产量约80% |

&nbsp;&nbsp;&nbsp;温度适应幅度10℃和耐寒性E，是在韩国种植木薯一切计划的出发点。在韩国中部，日平均气温超过20℃的时期大约是6月到9月这4个月。5月初种下、10月底挖出的话作期为6个月，但其中木薯能真正正常生长的时期只有4个月左右。若能收获热带地区种10个月所得产量的一半，就算是不错的结果了。

### 3-2. 灾害情况下的选址

| 条件 | 判断 |
|---|---|
| 朝南坡地、挡风处 | 最理想。地温回升快，作期更长 |
| 含沙、排水良好的土地 | 好。根扎得深，也容易挖 |
| 贫瘠的酸性红土 | 好，可利用其他作物无法使用的土地 |
| 坡地 | 可以种植，但达到15℃以上时需修筑等高线梯田 |
| 低洼积水处 | 绝对避免。几天内根就会腐烂 |
| 易积霜的低洼地、冷气汇聚的盆地 | 避免。初霜来得早，作期会缩短 |
| 黏土较多的黏重土壤 | 避免。根难以长粗，挖掘也困难 |

&nbsp;&nbsp;&nbsp;若要在韩国种植木薯，除非使用温室或塑料大棚，否则南部地区更有利，即便如此作期也会较短。设施负担SS这一等级是按热带标准评定的，在韩国实际上需要通过覆盖来提高地温。如果没有薄膜，可以在地表薄薄撒一层黑色腐叶土或草木灰来提高地温。

## 4. 品种

### 4-1. 高苦味种与低苦味种——最重要的区分

&nbsp;&nbsp;&nbsp;区分木薯品种的标准，既不是产量也不是生育期，而是氰苷含量。习惯上称为甜味品种（低苦味种）和苦味品种（高苦味种），但准确地说，指的是氰化物含量低的品系和含量高的品系。

| 区分 | 低苦味种（甜味品种） | 高苦味种（苦味品种） |
|---|---|---|
| 氰化物含量 | 每1kg鲜重约50mg以下 | 100mg到1,000mg以上不等 |
| 分布 | 肉质部分浓度低，集中在皮部 | 肉质部分也含有相当数量 |
| 处理 | 厚厚去皮后充分煮熟即可 | 必须经过磨碎发酵、干燥、浸泡等多道工序 |
| 产量 | 相对较低 | 较高，淀粉含量也高 |
| 病虫害 | 更容易受到兽害和虫害 | 氰化物浓度起到防御作用 |
| 盗窃 | 容易被人从地里拔走 | 不懂处理方法就无法食用，因此较少被盗 |
| 用途 | 即食、煮食 | 淀粉、粉类、发酵加工品 |

&nbsp;&nbsp;&nbsp;非洲农户之所以特意种植高苦味种，原因就在上表的下面三行：产量高、动物不太啃食、人也偷不走。饥荒越严重，高苦味种所占比重往往越大，结果饥荒时期孔佐病的发生也随之增加。在灾害情况下选择哪种品种，是产量与安全之间的权衡取舍。

> **虽然可以凭苦味判断品种，但苦味程度与氰化物含量并不完全成正比。对品种不明的木薯，原则上一律按高苦味种处理。**

### 4-2. 主要品种

| 品种 | 特征 | 灾害适用度 |
|---|---|:---:|
| Kasetsart 50 | 泰国种植面积最大的品种，淀粉含量高、产量大 | 高 |
| Rayong 9 | 泰国的主要品种，高产且干物率高 | 高 |
| KM505, KM140 | 抗病虫害能力强，适合病毒病发生地区 | 高 |
| 本地低苦味种 | 产量较低，但处理简单 | 适合初学者 |

### 4-3. 分情况的选择标准

| 情况 | 选择 | 理由 |
|---|---|---|
| 缺乏处理知识和工具时 | 低苦味种 | 仅靠去皮和煮熟就能达到安全水平 |
| 儿童和老人一起食用时 | 低苦味种 | 按体重计算摄入量更大，风险更高 |
| 要储备淀粉或粉类时 | 高苦味种 | 淀粉含量高，反正都要经过多道加工 |
| 兽害和盗窃严重时 | 高苦味种 | 本身就是一种防御手段 |
| 病毒病发生地区 | KM505, KM140 | 抗病系统 |
| 作期短（韩国露地） | 早熟系统 | 必须在6个月内长成块根 |

## 5. 整地与施肥

### 5-1. 整地

| 项目 | 标准 | 理由 |
|---|---|---|
| 耕地 | 深20-30cm | 为块根伸展留出空间 |
| 畦 | 高畦，高度30cm以上 | 防止积水，这是木薯唯一的致命弱点 |
| 排水沟 | 每条畦都要挖 | 一旦积水，几天内根就会腐烂 |
| 土壤酸度 | 可适应pH 4.5-7.5 | 无需另行调节 |
| 坡地 | 15度以上修筑等高线梯田 | 挖根后土壤裸露，侵蚀严重 |
| 保证地温 | 黑色覆盖物或草木灰 | 在韩国，初期地温是关键 |

### 5-2. 标准施肥量（1,000㎡，300坪，约990㎡）

| 肥料 | 施肥量 | 备注 |
|---|:---:|---|
| 氮（N） | 8-12kg | 分为基肥和追肥 |
| 磷（P） | 6-10kg | 全部作基肥 |
| 钾（K） | 8-12kg | 全部作基肥，对淀粉积累最为重要 |
| 堆肥 | 1,000-1,500kg | 腐熟堆肥，全部作基肥 |

&nbsp;&nbsp;&nbsp;施肥需求等级为SS，意味着即使不按这张表施肥也能有收成。实际上，非洲小农的木薯田大多不施肥。但若持续不施肥种植，土壤中的钾会迅速枯竭。因为木薯在根部积累淀粉的过程中会大量吸收钾，而这些根又被整个挖出、带离田地。这正是连作适应性只评为A（休作2年），并附有"即使在贫瘠土地上，地力消耗也很大"这一说明的原因。

### 5-3. 没有化肥时——灾害替代肥料

| 替代资源 | 供给养分 | 制作方法与使用方法 | 注意 |
|---|---|---|---|
| 草木灰 | 钾、磷、钙 | 对木薯而言最重要的替代肥料，每㎡一两把 | 呈碱性，用量过多会使pH升高 |
| 木薯茎叶 | 钾、氮、有机质 | 把收获后剩下的茎叶归还到原地 | 最可靠的钾循环方式 |
| 表皮与加工残渣 | 钾、有机质 | 用作堆肥 | 仍残留氰化物，不可直接喂给家畜 |
| 腐熟堆肥 | 综合养分 | 将落叶、杂草与粪便堆沤发酵6个月以上 | 未腐熟就使用会伤根 |
| 稀释尿液 | 氮、钾 | 用水稀释10倍后浇在畦间 | 避免直接接触叶片 |
| 骨粉 | 磷、钙 | 烧过磨碎后拌入堆肥 | 见效较慢 |

&nbsp;&nbsp;&nbsp;木薯种植中资源循环的关键，是不把茎、叶和表皮带出田地。只带走收获的块根，其余全部归还田地，就能大幅减少钾的流失。特别是表皮按重量计约占整个根部的10-20%，把它用作堆肥能提供不少养分。不过表皮的氰化物浓度最高，不能直接喂给家畜，须充分腐熟后再使用。

## 6. 扦插

### 6-1. 时期

| 地区 | 扦插时期 | 收获时期 | 备注 |
|---|---|---|---|
| 韩国（中部·南部） | 5月初 | 10月底 | 仅有霜期之间的6个月 |
| 热带 | 气温20℃以上时随时可以 | 8-18个月后 | 配合雨季开始 |

&nbsp;&nbsp;&nbsp;在韩国，5月初这个时期指的是晚霜刚结束之后。木薯一次霜冻也扛不住，哪怕早种一天也会全军覆没。反之，种得太晚则作期缩短，根长不成。不错过这个狭窄的时间窗口，是在韩国种植木薯的第一个条件。

### 6-2. 插条准备

| 项目 | 标准 | 理由 |
|---|---|---|
| 采集部位 | 茎的中段 | 顶端太嫩，基部木质化过重 |
| 茎粗 | 直径2-3cm | 贮存养分充足才能保证成活率 |
| 插条长度 | 15-20cm | 太短养分不足，太长则浪费 |
| 节数 | 3-5个 | 每个节都可能发芽 |
| 茎的状态 | 坚实健壮 | 感染病毒的插条会使产量下降30-40% |
| 切口 | 斜切 | 增大生根面积 |
| 上下方向 | 必须区分清楚 | 插反了不会发芽 |

&nbsp;&nbsp;&nbsp;插条的上下方向，可通过节上叶痕的朝向来分辨。叶痕呈朝上的半月形，其上方就是芽。难以判断时，可斜卧着插入。斜卧插入的话，无论哪个方向，节上都能长出芽和根。

### 6-3. 插条消毒

| 方法 | 步骤 | 效果 |
|---|---|---|
| 热处理 | 浸入50-55℃热水中10-15分钟 | 杀死表面病原菌 |
| 草木灰处理 | 在切口涂抹草木灰 | 兼具消毒与干燥效果 |
| 晾干 | 在阴凉处晾干切口约1天 | 防止腐烂 |
| 挑选 | 不使用有病征的茎 | 最有效的防治手段 |

&nbsp;&nbsp;&nbsp;进行热水处理时，温度很关键。超过60℃插条本身会死亡，低于45℃则病原菌能够存活。若没有温度计，大致可以手伸入水中，能忍受几秒但难以长时间浸泡的程度，大约就是50℃左右。不过这种方法一旦手感判断有误，就会把种苗整批损失，若没有把握，靠肉眼挑选健壮插条会更保险。

### 6-4. 种植

| 项目 | 标准 | 理由 |
|---|---|---|
| 种植深度 | 5-10cm | 使插条的三分之一到一半埋入土中 |
| 种植角度 | 倾斜15-45度或垂直 | 斜插可使根集中在一侧，便于采挖 |
| 株距 | 80-100cm | 看似偏宽，但因长成灌木状而有必要 |
| 行距 | 80-100cm | 保证通风与光合作用 |
| 种植后 | 压实土壤并充分浇水 | 保持湿润直至成活 |
| 间苗 | 苗高15-20cm时 | 每穴只留最健壮的1-2株 |

&nbsp;&nbsp;&nbsp;种植角度采用斜插是有原因的。垂直插入的话，根会向四面深深扩展，挖掘时下锹次数增多，还容易把根挖断。若以45°左右斜卧插入，根就会集中长向一侧，收获时从对侧用杠杆一撬，就能一次性带出。在需要徒手挖掘的情况下，这个差异相当大。
