## 14. 시안배당체와 독성 제거

&nbsp;&nbsp;&nbsp;이 절은 조리법이 아닙니다. 이 절의 내용을 모르고 카사바를 먹으면 사람이 죽거나 평생 걷지 못하게 됩니다. 카사바를 식량으로 다루려는 사람은 재배법보다 이 절을 먼저 익혀야 합니다.

### 14-1. 무엇이 들어 있는가

&nbsp;&nbsp;&nbsp;카사바의 모든 부위에는 시안배당체가 들어 있습니다. 대부분은 리나마린이고, 약 5%가 로타우스트랄린입니다. 이 물질 자체는 독이 아닙니다. 독은 그것이 분해될 때 나옵니다.

| 순서 | 무슨 일이 일어나는가 |
|---|---|
| 1 | 리나마린은 세포 안쪽 액포에 들어 있습니다 |
| 2 | 리나마레이스라는 효소는 세포벽 쪽에 따로 들어 있습니다 |
| 3 | 조직이 부서지면 둘이 만납니다. 껍질을 벗기거나 썰거나 씹을 때입니다 |
| 4 | 효소가 리나마린을 잘라 포도당과 아세톤시아노히드린을 만듭니다 |
| 5 | 아세톤시아노히드린은 pH 5 이상이거나 35℃ 이상이면 저절로 분해됩니다 |
| 6 | 그 결과 아세톤과 시안화수소(HCN), 즉 청산가스가 나옵니다 |
| 7 | 시안화수소는 끓는점이 26℃로 휘발성이 높습니다 |

&nbsp;&nbsp;&nbsp;이 일곱 단계가 카사바 처리의 모든 원리를 담고 있습니다. 독성 제거란 결국 리나마린을 시안화수소로 바꾼 다음 그것을 공기 중으로 날려 보내거나 물에 씻어 내는 일입니다. 그러려면 먼저 세포를 부수어 효소와 기질을 만나게 해야 하고, 그다음 시간과 온도와 공기를 주어 가스가 빠져나가게 해야 합니다.

### 14-2. 얼마나 위험한가

| 항목 | 수치 |
|---|---|
| 저미종 신선 뿌리 | 신선 중량 1kg당 시안 상당량 약 50mg 이하 |
| 고미종 신선 뿌리 | 100mg에서 1,000mg 이상까지 |
| 껍질(안쪽 흰 층 포함) | 속살보다 몇 배에서 수십 배 높습니다 |
| 잎 | 흔히 뿌리보다 높습니다 |
| 국제 기준(카사바 가루) | 건조 중량 1kg당 시안 상당량 10mg 이하 |
| 성인 급성 치사량 | 체중 1kg당 시안화수소 약 0.5-3.5mg |
| 60kg 성인 환산 | 대략 30-200mg |

&nbsp;&nbsp;&nbsp;이 표를 곱해 보면 사태가 분명해집니다. 시안 상당량 1,000mg의 고미종 뿌리 200g, 즉 한 끼 분량에는 시안 상당량(200mg)이 들어 있습니다. 성인 치사량 범위의 상한에 해당합니다. 처리하지 않은 고미종 카사바 한 끼가 사람을 죽일 수 있다는 말은 과장이 아닙니다. 아이라면 훨씬 적은 양으로도 위험합니다.

### 14-3. 왜 삶는 것만으로는 부족한가

&nbsp;&nbsp;&nbsp;가장 중요하고 가장 많이 오해되는 부분입니다. 상식적으로 생각하면 오래 끓이면 독이 날아갈 것 같지만, 통째로 또는 큰 덩어리로 삶으면 오히려 독이 남습니다. 이유는 효소에 있습니다.

| 상황 | 일어나는 일 |
|---|---|
| 큰 덩어리를 그대로 끓입니다 | 열이 안쪽까지 도달하는 동안 효소가 먼저 파괴됩니다 |
| 효소가 죽습니다 | 리나마레이스는 약 72℃에서 활성을 잃습니다 |
| 리나마린은 그대로 남습니다 | 리나마린 자체는 열에 안정해서 끓여도 거의 분해되지 않습니다 |
| 사람이 먹습니다 | 장 속의 세균이 리나마린을 분해합니다 |
| 몸 안에서 시안이 나옵니다 | 몇 시간 뒤 중독 증상이 나타납니다 |

> **삶기는 시안화수소를 날려 보내지만, 아직 시안화수소가 되지 않은 리나마린은 그대로 남깁니다. 그리고 그 리나마린은 사람의 장 속에서 독으로 바뀝니다.**

&nbsp;&nbsp;&nbsp;그러므로 처리의 순서가 결정적입니다. 먼저 세포를 부수어 효소를 일하게 하고, 충분한 시간을 주어 리나마린이 아세톤시아노히드린을 거쳐 시안화수소까지 가도록 한 다음, 마지막에 가열합니다. 갈고, 담그고, 발효시키고, 말리는 모든 절차가 이 순서를 만들기 위한 것입니다. 저미종은 원래 함량이 낮아 박피와 삶기만으로 안전선 아래로 내려가지만, 고미종에서 이 순서를 건너뛰면 아무리 오래 끓여도 위험은 남습니다.

### 14-4. 고미종과 저미종의 판별

| 방법 | 신뢰도 | 설명 |
|---|:---:|---|
| 품종 정보 | 가장 높음 | 계통을 알고 심었다면 그에 따릅니다 |
| 맛 | 보통 | 생것을 아주 조금 혀에 대면 고미종은 강하게 씁니다. 삼키지 않습니다 |
| 껍질 색과 두께 | 낮음 | 참고만 합니다 |
| 재배 조건 | 참고 | 가뭄과 척박한 토양에서는 같은 품종도 시안 함량이 올라갑니다 |

> **쓴맛과 시안 함량은 대체로 비례하지만 정확히 비례하지는 않습니다. 품종을 모르는 카사바는 전부 고미종으로 취급해 처리합니다. 이 원칙 하나가 사고의 대부분을 막습니다.**

### 14-5. 제거 절차 - 단계별

#### 14-5-1. 껍질 벗기기

| 항목 | 내용 |
|---|---|
| 원리 | 시안배당체가 껍질에 집중되어 있습니다 |
| 방법 | 세로로 칼집을 낸 뒤 바깥 갈색 층과 안쪽 흰 층을 함께 벗깁니다 |
| 두께 | 껍질 전체 두께는 2-3mm입니다. 얇게 긁어내면 소용없습니다 |
| 판단 | 벗긴 면이 매끈한 흰색이 되어야 합니다. 분홍이나 연한 층이 남으면 덜 벗긴 것입니다 |
| 제거율 | 총량의 상당 부분이 이 단계에서 사라집니다 |
| 껍질 처리 | 사람도 가축도 먹지 않습니다. 충분히 썩혀 퇴비로 씁니다 |
| 중심 심 | 가운데 질긴 섬유질 심도 함께 제거합니다 |

#### 14-5-2. 물에 담그기

| 항목 | 내용 |
|---|---|
| 원리 | 시안배당체와 그 분해산물이 물에 녹아 빠져나갑니다 |
| 저미종 | 토막 내어 6-12시간이면 충분합니다 |
| 고미종(통뿌리) | 3-6일. 껍질을 벗기고 물에 완전히 잠기게 합니다 |
| 고미종(토막) | 24-72시간. 토막이 작을수록 빨라집니다 |
| 물 갈기 | 하루 한 번 이상 갈아 줍니다. 갈지 않으면 농도가 평형에 도달해 더 빠지지 않습니다 |
| 온도 | 따뜻할수록 빠릅니다. 30도 안팎이 효율적입니다 |
| 담근 물 | 독이 녹아 있습니다. 사람도 가축도 마시지 않고 밭에 버리지 않습니다 |
| 주의 | 밀폐 용기에 담그지 않습니다. 가스가 고입니다 |

#### 14-5-3. 갈아서 발효시키기

| 항목 | 내용 |
|---|---|
| 원리 | 세포를 최대한 부수어 효소가 전면적으로 작용하게 합니다. 가장 효과가 큽니다 |
| 방법 | 껍질을 벗긴 뿌리를 강판이나 돌절구로 완전히 으깹니다 |
| 발효 | 으깬 것을 자루나 용기에 담아 그늘에서 3-5일 둡니다 |
| 압착 | 자루에 담아 돌로 눌러 즙을 짜냅니다. 즙에 독이 녹아 있습니다 |
| 냄새 | 시큼한 발효 냄새가 납니다. 이는 정상입니다 |
| 제거율 | 제대로 하면 95% 이상 제거됩니다 |
| 이후 | 짜낸 덩어리를 볶거나 쪄서 먹습니다 |
| 주의 | 짜낸 즙은 버립니다. 전분을 회수하려면 즙을 가라앉혀 앙금만 여러 번 헹궈 씁니다 |

&nbsp;&nbsp;&nbsp;서아프리카의 가리와 푸푸가 이 방식입니다. 갈고, 자루에 담아 며칠 발효시키고, 눌러 짜고, 다시 볶거나 찌는 네 단계가 몇 세대에 걸쳐 다듬어진 해독 공정입니다. 재난 상황에서 고미종을 대량으로 처리해야 한다면 이 방식이 가장 확실합니다.

#### 14-5-4. 완전 건조

| 항목 | 내용 |
|---|---|
| 원리 | 얇게 썰면 효소가 작용하고, 마르는 동안 시안화수소가 공기 중으로 날아갑니다 |
| 두께 | 5mm 이하로 얇게 썹니다. 두꺼우면 속에 남습니다 |
| 방식 | 햇볕에 널어 말립니다. 4-7일 |
| 그늘 건조 | 햇볕보다 느리지만 효소가 더 오래 일해 제거율이 오히려 높다는 보고가 있습니다 |
| 판정 | 딱 소리가 나며 부러지고 손으로 부서질 때까지 말립니다 |
| 제거율 | 조건에 따라 60-90% |
| 주의 | 덜 마른 것을 자루에 담으면 곰팡이가 생기고 독도 남습니다 |

#### 14-5-5. 충분한 가열

| 항목 | 내용 |
|---|---|
| 원리 | 남은 시안화수소를 날려 보내고 전분을 익힙니다 |
| 저미종 | 2-3cm 토막으로 끓는 물에 20-30분. 뚜껑을 덮지 않습니다 |
| 고미종 | 앞 단계를 거친 뒤 가열합니다. 가열만으로는 부족합니다 |
| 삶은 물 | 반드시 버립니다. 시안이 녹아 있습니다 |
| 뚜껑 | 열어 둡니다. 가스가 빠져나가야 합니다 |
| 환기 | 실내에서 대량으로 삶을 때는 창을 엽니다 |
| 판정 | 쓴맛과 떫은맛이 완전히 사라져야 합니다 |

### 14-6. 품종별 최소 절차

| 구분 | 절차 | 소요 |
|---|---|---|
| 저미종 | 껍질 두껍게 벗기기, 토막 내기, 물에 6-12시간 담그기, 물 버리고 20-30분 삶기, 삶은 물 버리기 | 하루 |
| 고미종(가정 식용) | 껍질 벗기기, 토막 내기, 물에 3-5일 담그며 매일 물 갈기, 5mm로 썰어 4-7일 완전 건조, 가루로 빻기, 조리 시 충분히 가열 | 1-2주 |
| 고미종(대량 가공) | 껍질 벗기기, 완전히 갈기, 자루에 담아 3-5일 발효, 눌러 짜기, 볶거나 찌기 | 1주 |
| 품종 불명 | 고미종 절차를 따릅니다 | - |

### 14-7. 가루를 다시 습윤시키는 방법

&nbsp;&nbsp;&nbsp;말려 빻은 카사바 가루에도 리나마린이 남아 있는 경우가 많습니다. 건조가 불충분했거나 서둘러 말린 가루가 특히 그렇습니다. 이 잔류분을 추가로 줄이는 간단한 방법이 있습니다.

| 순서 | 내용 |
|---|---|
| 1 | 가루에 같은 부피의 물을 섞어 축축한 반죽 상태로 만듭니다 |
| 2 | 넓은 그릇이나 판에 1cm 이하 두께로 얇게 폅니다 |
| 3 | 그늘에서 5시간 이상 그대로 둡니다 |
| 4 | 이 동안 가루에 남아 있던 효소가 리나마린을 분해하고 시안화수소가 날아갑니다 |
| 5 | 그 뒤 평소대로 끓이거나 쪄서 먹습니다 |

&nbsp;&nbsp;&nbsp;원리는 단순합니다. 리나마레이스는 건조 상태에서는 일하지 못하지만 죽지도 않습니다. 물을 만나면 다시 활성을 되찾습니다. 얇게 펴는 이유는 생성된 가스가 빨리 빠져나가게 하기 위함이고, 그늘에 두는 이유는 직사광선이 효소를 파괴하기 때문입니다. 이 한 단계만 추가해도 잔류 시안이 몇 분의 일로 줄어듭니다. 도구도 연료도 들지 않으므로 재난 상황에서 특히 값어치가 큽니다.

### 14-8. 잎의 처리

| 항목 | 내용 |
|---|---|
| 영양 | 신선 중량 100g당 단백질 5-10g. 라이신이 풍부합니다 |
| 위험 | 시안 함량이 흔히 뿌리보다 높습니다 |
| 1단계 | 어린잎을 따서 굵은 잎자루를 제거합니다 |
| 2단계 | 절구에 넣고 완전히 찧습니다. 세포를 부수는 것이 핵심입니다 |
| 3단계 | 30분 이상 물을 갈아 가며 삶습니다 |
| 4단계 | 삶은 물은 버립니다 |
| 판정 | 쓴맛이 남아 있으면 다시 삶습니다 |
| 주의 | 살짝 데쳐 먹는 방식은 위험합니다. 나물처럼 다루면 안 됩니다 |

&nbsp;&nbsp;&nbsp;카사바 잎은 카사바 식단의 최대 약점인 단백질 부족을 메워 주는 거의 유일한 수단입니다. 뿌리만 먹으면 열량은 채워도 몸이 말라 가는데, 잎을 함께 먹으면 그 문제가 크게 줄어듭니다. 게다가 잎은 뿌리가 여물기 전인 생육 중기부터 딸 수 있어 수확까지의 긴 공백을 메웁니다. 다만 시안 함량이 뿌리보다 높다는 점을 잊으면 안 됩니다. 찧고 오래 삶는 두 단계는 생략할 수 없습니다.

### 14-9. 급성 중독

| 항목 | 내용 |
|---|---|
| 발현 시각 | 섭취 후 수십 분에서 6시간. 장내 세균 분해를 거치면 더 늦게 나타납니다 |
| 초기 증상 | 어지러움, 두통, 메스꺼움, 구토, 복통, 설사 |
| 진행 증상 | 빠르고 얕은 호흡, 심계항진, 불안, 혼미 |
| 중증 | 경련, 청색증, 의식 소실, 호흡 마비, 사망 |
| 냄새 | 쓴 아몬드 냄새가 날 수 있으나 이 냄새를 못 맡는 사람이 상당수입니다 |
| 취약 대상 | 어린이. 체중당 섭취량이 커서 같은 양이 훨씬 위험합니다 |

| 상황 | 대응 |
|---|---|
| 섭취 직후 의심 | 더 먹지 않게 하고 남은 음식을 치웁니다 |
| 증상 발생 | 신선한 공기가 통하는 곳에 눕히고 안정시킵니다 |
| 의식 있음 | 물을 조금씩 줍니다. 억지로 토하게 하지 않습니다 |
| 의식 저하, 경련 | 옆으로 눕혀 기도를 확보합니다 |
| 회복 후 | 원인이 된 카사바는 전량 폐기하고 처리 절차를 다시 점검합니다 |
| 전제 | 의료가 닿지 않는 상황에서 할 수 있는 일은 제한적입니다. 예방이 유일한 대책입니다 |

### 14-10. 만성 중독 - 콘조와 신경병증

&nbsp;&nbsp;&nbsp;카사바에서 실제로 더 많은 사람을 상하게 하는 것은 급성 중독이 아니라 만성 중독입니다. 급성 중독은 눈에 띄지만 만성 중독은 서서히 옵니다.

| 구분 | 콘조 | 열대실조성신경병증 |
|---|---|---|
| 발현 | 갑작스럽습니다. 몇 시간에서 며칠 사이에 나타납니다 | 서서히 진행합니다. 수년에 걸칩니다 |
| 주 증상 | 두 다리가 뻣뻣해지며 걷지 못하게 됩니다 | 걸음이 흔들리고 시력이 떨어지며 귀가 어두워집니다 |
| 대상 | 어린이와 가임기 여성에게 많습니다 | 40세 이상에게 많습니다 |
| 경과 | 회복되지 않습니다. 악화가 멈출 뿐입니다 | 진행성입니다 |
| 조건 | 처리가 불충분한 고미종을 몇 주 이상 계속 먹을 때 | 처리 부족 상태의 장기 노출 |
| 악화 요인 | 단백질 결핍이 겹칠 때 급격히 늘어납니다 | 같습니다 |
| 치료 | 없습니다 | 없습니다 |

&nbsp;&nbsp;&nbsp;콘조가 언제 발생하는지를 아는 것이 중요합니다. 이 병은 언제나 기근과 함께 옵니다. 평소에는 사흘 담그던 것을 배가 고파 하루만 담그고, 이레 말리던 것을 이틀 만에 걷어 먹기 때문입니다. 재난 상황이란 정확히 이런 지름길을 택하기 쉬운 상황이며, 그래서 이 절의 절차가 지켜지기 가장 어려운 상황이기도 합니다.

### 14-11. 단백질과 해독의 관계

&nbsp;&nbsp;&nbsp;몸에 들어온 시안은 간에서 티오시안산염으로 바뀌어 소변으로 배출됩니다. 이 반응에는 황이 필요하고, 그 황은 메티오닌과 시스테인 같은 함황 아미노산에서 나옵니다. 즉 단백질을 충분히 먹는 사람은 시안을 해독하지만, 단백질이 모자란 사람은 같은 양의 시안에도 훨씬 크게 다칩니다.

| 상황 | 결과 |
|---|---|
| 카사바만 먹음 | 단백질이 열량 대비 3.4%뿐. 해독 능력이 떨어집니다 |
| 해독 능력이 떨어짐 | 같은 시안에 더 크게 손상됩니다 |
| 손상이 누적됨 | 콘조와 신경병증의 위험이 올라갑니다 |
| 결과 | 카사바만 먹는 것이 독을 더 독하게 만듭니다 |

> **카사바를 안전하게 먹는 가장 중요한 조건 가운데 하나는 카사바만 먹지 않는 것입니다. 콩, 생선, 달걀, 카사바 잎 가운데 무엇이든 함께 먹어야 몸이 시안을 처리할 수 있습니다.**

&nbsp;&nbsp;&nbsp;티오시안산염은 또 다른 문제도 일으킵니다. 갑상샘이 요오드를 받아들이는 것을 방해해, 요오드가 부족한 지역에서는 갑상샘종과 그로 인한 발육 장애를 늘립니다. 바다에서 멀고 소금과 해조류를 구하기 어려운 내륙 지역에서 카사바에 의존할 때 특히 주의해야 하는 부분입니다.

### 14-12. 절대 하지 말아야 할 것

| 금지 | 이유 |
|---|---|
| 생으로 먹기 | 어떤 품종이든 금지입니다 |
| 껍질을 얇게만 벗기기 | 시안이 가장 많은 부위가 그대로 남습니다 |
| 큰 덩어리를 통째로 오래 삶기 | 효소가 먼저 죽어 리나마린이 그대로 남습니다 |
| 뚜껑을 덮고 삶기 | 가스가 빠져나가지 못합니다 |
| 삶은 물이나 담근 물 쓰기 | 독이 녹아 있습니다. 국물로 쓰지 않습니다 |
| 담근 물을 가축에게 주기 | 가축도 중독됩니다 |
| 밀폐 용기에서 발효시키기 | 가스가 고여 위험합니다 |
| 덜 마른 가루 쓰기 | 시안이 남고 곰팡이가 핍니다 |
| 쓴맛이 남았는데 먹기 | 처리가 끝나지 않았다는 신호입니다 |
| 절차를 줄이기 | 배가 고플수록 절차를 지켜야 합니다 |
