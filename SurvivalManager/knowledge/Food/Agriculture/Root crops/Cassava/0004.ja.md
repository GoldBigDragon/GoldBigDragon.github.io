## 7. 水管理

### 7-1. 生育段階別の基準

| 時期 | 水管理 | 理由 |
|---|---|---|
| 挿し木直後 | 十分に湿らせます | 活着前は貯蔵養分だけで持ちこたえます。乾くと枯れます |
| 活着-栄養生長期 | 自然降雨に任せます | 耐乾性が強く、多少の干ばつには耐えます |
| 塊根肥大期 | 深刻な干ばつのときだけ補水 | この時期の乾燥は収量に直接影響します |
| 収穫前2-3週間 | 灌水を中止します | 皮が硬くなりでんぷんが充実します |

&nbsp;&nbsp;&nbsp;キャッサバの耐乾性は、いくつもの仕組みが重なって生まれます。葉を落として蒸散を減らし、気孔を素早く閉じ、根を2m以上の深さまで下ろします。何か月も雨が降らないと葉をすべて落として枯れ枝のように立ち尽くしますが、雨が降るとまた葉を出します。この期間、根のでんぷんが消耗されるため収量は減りますが、枯れはしません。穀物が一度の干ばつで全滅するのとは決定的に異なる点です。

### 7-2. 水分不足と過多の症状

| 区分 | 症状 | 進行 | 対処 |
|---|---|---|---|
| 不足 | 下の葉から黄変して落ちる | 正常な反応 | 対処しません。生存戦略です |
| 不足 | 葉がほとんど落ちて茎だけ残る | 深刻 | 根のでんぷんが消耗します。雨が降れば回復します |
| 不足 | 活着前に挿し穂が枯れる | 致命的 | 回復しません。挿し直す必要があります |
| 過多 | 下の葉が黄色くなり根元が黒ずむ | 危険 | 直ちに排水路を作ります |
| 過多 | 根を掘ってみると軟化し悪臭がする | 致命的 | 回復不可能。該当区域を放棄します |

> **キャッサバは干ばつでは枯れず、水で枯れます。水がたまる場所には植えません。**

## 8. 栽培管理

### 8-1. 雑草管理 - 最初の4か月がすべてです

| 時期 | 作業 | 理由 |
|---|---|---|
| 挿し木-3か月 | 定期的に除草します。2-3回 | 初期生育が遅く雑草に負けます |
| 3-4か月 | 必要に応じて除草、マルチの補強 | まだ地面が覆われていません |
| 4か月以降 | ほとんど必要ありません | 葉が地面を覆い雑草が抑えられます |

&nbsp;&nbsp;&nbsp;キャッサバ栽培で収量を左右する最大の変数は、肥料でも水でもなく初期の雑草管理です。挿し木後3か月間、雑草に負けた畑は最後まで回復しません。逆にこの時期さえ乗り切れば、その後はほとんど手がかかりません。労働を前半に集中させるべきだという意味であり、災害時に人手を配分するうえで重要な情報です。

### 8-2. 土寄せ

| 時期 | 作業 | 効果 |
|---|---|---|
| 生育中に1-2回 | 株元に土を寄せます | 倒伏を防ぎ、根の発達を助けます |
| 雨の多い時期 | 畝を再び高くします | 冠水を防ぎます |
| 根が露出したとき | 土をかぶせます | 露出した根は緑色に変わり硬くなります |

### 8-3. その他の管理

| 作業 | 時期 | 内容 |
|---|---|---|
| 間引き | 草丈15-20cm | 1つの穴に丈夫な1-2本だけ残します |
| 葉の収穫 | 生育中期以降 | 上部の若葉を摘んで野菜として使います。摘みすぎると根が小さくなります |
| 地温確保 | 初期 | 韓国ではマルチや灰で地温を上げます |
| 防風 | 台風期 | 草丈が2-4mあり風で倒れます。株元に土を寄せます |

&nbsp;&nbsp;&nbsp;葉の収穫は、キャッサバ栽培において特別な意味を持ちます。根が熟すまでの8か月を待つ間も葉は成長し続けるため、その間に葉を摘んで野菜として使うことができます。タンパク質が根よりはるかに多く、キャッサバの食事の最大の弱点を補ってくれます。ただし葉を摘みすぎると光合成面積が減り、根の収量が落ちます。一株につき下の葉を残し、上部の若葉を数枚ずつ摘む程度が適量であり、葉の処理は必ず14節に従ってください。

## 9. 病害虫

### 9-1. 主な病害

| 病気 | 症状 | 被害 | 無農薬での対応 |
|---|---|---|---|
| キャッサバモザイク病（CMD） | 葉にモザイク状の模様ができて縮れます | 収穫量30-70%減少 | 抵抗性品種、健全な挿し穂の選別。治療法なし |
| キャッサバ褐色条斑病（CBSD） | 茎に褐色の縞模様が現れ、根の内部が褐色に腐ります | 作物全体が失敗する可能性 | 抵抗性品種。感染株は抜いて焼却します |
| 細菌性萎凋病 | 葉に水浸状の斑点、茎の萎凋 | 中程度 | 健全な挿し穂、輪作、病残渣の焼却 |
| 根腐病 | 根が軟化し悪臭がします | 致命的 | 排水改善が唯一の対策です |
| 炭疽病 | 茎と葉にくぼんだ斑点 | 中程度 | 通風確保、病斑部の除去 |

&nbsp;&nbsp;&nbsp;キャッサバの病害はほとんどすべて挿し穂を通じて入り込みます。ウイルス病にかかった株から切り取った茎は、そのウイルスをそのまま抱えており、翌年畑全体に広げてしまいます。そのため、キャッサバの防除の要は薬ではなく挿し穂の選別です。評価表で防除自立度に「健全な挿し穂の選別だけでほぼ対応可能」と書かれている理由がこれです。薬がない状況でも、目で選び出す作業はできます。

### 9-2. 主な害虫

| 害虫 | 被害 | 無農薬での対応 |
|---|---|---|
| コナジラミ | 汁を吸いモザイク病ウイルスを媒介します | 抵抗性品種、黄色粘着トラップ、周辺の雑草除去 |
| アブラムシ | 汁を吸いウイルスを媒介します | 水洗い、石けん水、テントウムシと寄生バチの保護 |
| ハダニ | 葉が黄色くまだらになって落ちます | 葉の裏に水をかけます。乾燥期に多発します |
| カイガラムシ | 茎に付着して生育を止めます | 挿し穂の段階で取り除きます。寄生バチの保護 |
| シロアリ | 挿し穂や根をかじります | 植え付け時に草木灰を混ぜます |
| イノシシ・げっ歯類 | 根を掘って食べます | 柵を設けます。高苦味種は相対的に被害が少ないです |

### 9-3. 無農薬防除の五原則

| 原則 | 内容 |
|---|---|
| 挿し穂の選別 | 病徴のある株からは絶対に挿し穂を取りません。防除の8割を占めます |
| 抵抗性系統 | 入手できるなら抵抗性系統を使います |
| 罹病株の即時除去 | モザイク症状が見えたら、その場で抜いて焼きます |
| 輪作 | 同じ畑で連続栽培しません。2年以上の間隔を空けます |
| 天敵の保護 | コナジラミとアブラムシの天敵である寄生バチとテントウムシを生かします |

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 確認方法 | 自然素材による対処 |
|---|---|---|---|
| 葉全体が黄色くなり株が小さい | 窒素欠乏 | 下の葉から始まります | 完熟堆肥、尿の10倍希釈液 |
| 葉の縁が褐色に焦げたようになる | カリウム欠乏 | 塊根肥大期によく見られます | 草木灰。キャッサバにとって最も重要です |
| 生育全体が不振で葉が濃い紫色 | リン酸欠乏 | 酸性土壌でよく見られます | 骨粉、草木灰 |
| 新葉が小さく奇形で先端が枯れる | ホウ素欠乏 | 若い葉から現れます | 堆肥の多様化、灰の少量散布 |
| 葉脈の間が黄色くなる | マグネシウム欠乏 | 下の葉からです | ドロマイト、堆肥 |
| 茎と葉ばかり茂り根が細い | 窒素過剰 | 葉の色が濃すぎます | 窒素供給を止め、草木灰でカリウムを補います |

&nbsp;&nbsp;&nbsp;キャッサバで最もよく見られ、最も損失が大きいのはカリウム欠乏です。でんぷんを根に運ぶ働きにカリウムが直接関わっているため、カリウムが不足すると葉は健全に見えても根は細いままになります。さらにキャッサバは収穫のたびにかなりの量のカリウムを畑の外に持ち出すため、無施肥で連作するとカリウムが真っ先に底をつきます。草木灰がキャッサバ栽培において他のどの作物よりも貴重な資源である理由です。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 対象 | 理由 |
|:---:|---|---|
| 良い | マメ科作物（ササゲ、ラッカセイ、ダイズ） | 窒素を固定してキャッサバに供給します。初期4か月の空きスペースを使います |
| 良い | トウモロコシ | キャッサバの初期生育が遅い間に先に収穫します |
| 良い | カボチャ、サツマイモ | 地面を覆い雑草と浸食を減らします |
| 普通 | 葉物野菜 | 畝の間に植えて早期に収穫します |
| 避ける | 同じ畑での連作 | 病原菌が蓄積しカリウムが枯渇します |
| 避ける | トウダイグサ科の作物 | 同じ病害を共有します |

&nbsp;&nbsp;&nbsp;キャッサバとマメ科作物の間作は、アフリカで広く使われている方式です。キャッサバは植えてから4か月間ほとんど地面を覆わないため、その間のスペースが無駄になりますが、そこにササゲやラッカセイを植えれば4か月で収穫が得られます。さらに、マメ科が固定した窒素の一部が土壌に残り、キャッサバの後半の生育に使われます。災害時にタンパク質供給源と熱量供給源を同じ畑で同時に確保できるという点でも意義が大きいです。

### 11-2. 輪作の順序

| 順序 | 作物 | 役割 |
|---|---|---|
| 1年目 | キャッサバ | カリウムとリン酸を大きく持ち出します |
| 2年目 | マメ科（ダイズ、ササゲ、アズキ） | 窒素を回復させます |
| 3年目 | 葉物野菜または穀物 | 残った窒素を使います |
| 4年目 | 再びキャッサバ | 3-4年の間隔を守ります |

&nbsp;&nbsp;&nbsp;連作適応性Aという等級には、「痩せた土地でも地力の消耗が大きい」という注記が付いています。キャッサバが痩せた土地で育つという事実は、その土地を消耗させないという意味ではありません。むしろ、何も育たない土地でも根いっぱいにでんぷんを満たす能力は、それだけ土壌に残った養分を最後までかき集めるという意味でもあります。キャッサバを同じ畑に何年も連続して植えると、その土地はキャッサバさえ育たない状態になります。茎と葉と皮を必ず畑に戻し、2年以上休作するかマメ科を組み込むことが、この問題への唯一の対応です。

## 12. 収穫

### 12-1. 時期の判断

| 用途 | 収穫時期（挿し木後） | 判断基準 |
|---|:---:|---|
| 即席の食用 | 6-8か月 | でんぷんが少なく、あまり硬くありません |
| でんぷん・粉加工 | 8-12か月 | でんぷん含有量と収量が最大です |
| 遅延収穫 | 12-24か月 | 繊維質が増えて硬くなりますが食べられます |
| 韓国の露地 | 5月初め挿し木、10月末収穫 | 霜が来る前に必ず終えます |
| 外見上の兆候 | 下の葉が黄色くなって落ち、茎の下部が木質化します | 試しに1株掘り出し太さを確認します |

&nbsp;&nbsp;&nbsp;韓国では選択の余地がありません。霜が来ると地上部が枯れ、地上部が枯れると根もすぐに傷み始めます。10月末までに全量を掘り出さなければならず、これは熱帯での8か月から12か月の作期を6か月に縮めるという意味です。収量はそれだけ減ります。初霜の予報が出たら、まだ十分に熟していなくても掘り出したほうがよいです。

### 12-2. 収穫のコツ

| 順序 | 内容 |
|---|---|
| 1 | 晴れて乾燥した日を選びます。濡れた根はすぐに腐敗します |
| 2 | 地上部の茎を30-50cm残して切ります。この茎が持ち手になります |
| 3 | 残した茎をてこにして、根の反対側から持ち上げます |
| 4 | 土が固ければ、まず株の周りを掘って緩めます |
| 5 | 根を切らないよう注意します。切れた面から腐敗が始まります |
| 6 | 土を軽く払い落とします。水では洗いません |
| 7 | 残った茎は挿し穂用に別途集めます |

### 12-3. 収穫後の処理 - 時間がありません

| 経過時間 | 状態 |
|---|---|
| 収穫直後 | 白い果肉、正常 |
| 24-48時間 | 果肉に青みがかった筋が現れ始めます |
| 48-72時間 | 褐色に変わり、苦味と異臭が生じます |
| 3-5日 | 腐敗が始まります |

&nbsp;&nbsp;&nbsp;この変化を生理的変質と呼びます。カビや細菌によるものではなく根自体の傷害反応であり、掘り出した瞬間から不可逆的に進行します。他のどのいも類（塊茎・塊根）よりも速いです。そのためキャッサバでは、「収穫後数日以内に加工する」ではなく「掘った当日に加工する」が原則です。掘り出して運び、皮をむき、切って乾かすところまでを1日以内に終えなければなりません。この労働負担のため、キャッサバは少しずつ掘り出して少しずつ処理する方式で扱うのが現実的です。

> **畑が貯蔵庫です。今週食べて加工する分だけ掘り出します。一度に掘り出すと、3日で半分が使えなくなります。**

## 13. 挿し穂の保存と採種

### 13-1. 挿し穂がそのまま種子です

&nbsp;&nbsp;&nbsp;キャッサバの自家採種等級はSSです。一株から出た2-4mの茎を15cmずつに切ると10本以上の挿し穂が取れ、その一本一本が翌年の一株になります。増殖率が非常に高いため、わずかな種苗から始めても2、3年で相当な面積を埋められます。

| 項目 | 基準 |
|---|---|
| 採取部位 | 茎の中間、直径2-3cm |
| 採取時期 | 収穫と同時、10月末 |
| 保存単位 | 切らずに1m前後の長い節のまま保存します |
| 保存温度 | 10度以上、凍らない場所 |
| 保存湿度 | 乾かない程度。完全乾燥は厳禁です |
| 保存期間 | 最長2-3か月。長いほど活着率が落ちます |

### 13-2. 韓国で最も難しい問題 - 挿し穂の越冬

&nbsp;&nbsp;&nbsp;種子寿命Eという等級の実体がこれです。キャッサバの茎は生きた組織であるため、凍れば死に、乾けば死に、湿れば腐ります。熱帯ではこの問題がありません。畑に立ったままのキャッサバから、必要なときに茎を切って使えばよいからです。韓国では11月から4月まで5か月以上、生きた茎を人が守り続けなければなりません。暖房が絶たれた状況では、これがキャッサバ栽培最大の隘路です。

| 方法 | 条件 | 成功率 | 備考 |
|---|---|:---:|---|
| 室内の涼しい場所に立てておく | 10-15℃、湿度は普通 | 中程度 | 最も簡単です。乾かないよう束にして立てます |
| 湿った砂に根元を埋める | 10℃以上 | 高い | 砂が乾かないよう時々水をやります |
| 土室・室（むろ）に埋める | 10℃以上を保てる場所 | 中程度 | 気温が5℃を下回ると失敗します |
| 温室・ビニールトンネル内に仮植え | 10℃以上 | 高い | 可能であれば最も確実です |
| 鉢に植えて室内で越冬 | 15℃以上、明るい場所 | 高い | 少量向きです。生きた株のまま越します |
| 露地放置 | - | 0 | 必ず枯れます |

&nbsp;&nbsp;&nbsp;最も確実な方法は、挿し穂を保存することではなく、生きた株を室内で越させることです。小さな鉢に一、二株を植えて明るく暖かい室内に置けば、冬の間に多少葉を落としながらも生き残り、春が来ればその株から茎を切って挿し穂として使えます。一株だけ生かせても、翌年には十株になります。複数の方法を同時に使ってリスクを分散させるのが原則です。

> **韓国でのキャッサバ栽培の成否は、畑ではなく冬の室内で決まります。挿し穂を失えば、翌年のキャッサバはありません。**

### 13-3. 種子繁殖

| 項目 | 内容 |
|---|---|
| 結実 | 蒴果ができ種子が生じます |
| 発芽 | 発芽率が低く不規則です |
| 特性 | 母株と異なる特性が現れます |
| 生育 | 実生は根が熟すまでより長くかかります |
| 実用性 | 繁殖には使いません。育種目的にのみ使います |
