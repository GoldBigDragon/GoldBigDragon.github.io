## 14. 氰苷与脱毒处理

&nbsp;&nbsp;&nbsp;本节不是烹饪方法。不了解本节内容就食用木薯，会导致死亡或终身无法行走。想把木薯当作粮食的人，必须先掌握本节内容，而不是先学栽培方法。

### 14-1. 含有什么物质

&nbsp;&nbsp;&nbsp;木薯的所有部位都含有氰苷。大部分是亚麻苦苷，约5%是百脉根苷。这种物质本身并不是毒素，毒素产生于它分解之时。

| 顺序 | 发生了什么 |
|---|---|
| 1 | 亚麻苦苷存在于细胞内的液泡中 |
| 2 | 一种叫亚麻苦苷酶的酶，则单独存在于细胞壁一侧 |
| 3 | 组织被破坏时两者相遇，也就是去皮、切割或咀嚼的时候 |
| 4 | 酶分解亚麻苦苷，生成葡萄糖和丙酮氰醇 |
| 5 | 丙酮氰醇在pH 5以上或35℃以上时会自行分解 |
| 6 | 结果生成丙酮和氰化氢（HCN），也就是氢氰酸气体 |
| 7 | 氰化氢沸点为26℃，挥发性很强 |

&nbsp;&nbsp;&nbsp;这七个步骤，涵盖了木薯处理的全部原理。归根结底，脱毒就是把亚麻苦苷转化为氰化氢，再将其挥发到空气中或用水冲洗掉。要做到这一点，首先必须破坏细胞，让酶与底物相遇；随后要给予足够的时间、温度与空气，让气体逸出。

### 14-2. 危险程度有多大

| 项目 | 数值 |
|---|---|
| 低苦味种鲜根 | 每1kg鲜重氰化物当量约50mg以下 |
| 高苦味种鲜根 | 100mg到1,000mg以上不等 |
| 表皮（含内侧白层） | 比肉质部分高出数倍至数十倍 |
| 叶片 | 常高于块根 |
| 国际标准（木薯粉） | 每1kg干重氰化物当量10mg以下 |
| 成人急性致死量 | 每1kg体重氰化氢约0.5-3.5mg |
| 折合60kg成人 | 约30-200mg |

&nbsp;&nbsp;&nbsp;把这张表的数字相乘，情况就一目了然了。氰化物当量为1,000mg的高苦味种块根200g，也就是一顿饭的量，就含有氰化物当量（200mg）。这已达到成人致死量范围的上限。未经处理的高苦味种木薯一顿饭就能致人死亡，这并非夸张之词。若是儿童，危险剂量还要低得多。

### 14-3. 为什么仅靠煮不够

&nbsp;&nbsp;&nbsp;这是最重要、也最常被误解的部分。按常理，煮得越久毒素应该挥发得越多，但如果整个或大块地煮，毒素反而会残留下来。原因就在于酶。

| 情况 | 发生的事 |
|---|---|
| 整块直接煮 | 在热量传到内部之前，酶就先被破坏了 |
| 酶失活 | 亚麻苦苷酶在约72℃时失去活性 |
| 亚麻苦苷原样残留 | 亚麻苦苷本身耐热，煮沸也几乎不分解 |
| 人食用后 | 肠道细菌会分解亚麻苦苷 |
| 体内产生氰化物 | 数小时后出现中毒症状 |

> **煮沸能让氰化氢挥发，却会把尚未变成氰化氢的亚麻苦苷原样留下。而这些亚麻苦苷会在人的肠道内转变为毒素。**

&nbsp;&nbsp;&nbsp;因此，处理的顺序至关重要。要先破坏细胞、让酶发挥作用，再给予充分的时间，让亚麻苦苷经丙酮氰醇转化为氰化氢，最后才加热。磨碎、浸泡、发酵、晾干等所有工序，都是为了造就这个顺序。低苦味种由于本身含量低，仅靠去皮和煮熟就能降到安全线以下；但高苦味种若跳过这个顺序，无论煮多久，危险都不会消失。

### 14-4. 高苦味种与低苦味种的辨别

| 方法 | 可信度 | 说明 |
|---|:---:|---|
| 品种信息 | 最高 | 若知道所种品系，以此为准 |
| 口味 | 一般 | 取极少量生品触舌试味，高苦味种会有强烈苦味，切勿吞咽 |
| 表皮颜色与厚度 | 低 | 仅供参考 |
| 种植条件 | 参考 | 在干旱和贫瘠土壤中，即使同一品种氰化物含量也会升高 |

> **苦味与氰化物含量大体成正比，但并不精确对应。品种不明的木薯一律按高苦味种处理。仅这一条原则，就能防止大多数事故。**

### 14-5. 去除程序——分步骤

#### 14-5-1. 去皮

| 项目 | 内容 |
|---|---|
| 原理 | 氰苷集中在表皮 |
| 方法 | 先竖着划一道口子，再把外侧棕色层和内侧白色层一起削掉 |
| 厚度 | 表皮总厚度为2-3mm，只是薄薄刮一层没有用 |
| 判断 | 削好的表面应呈光滑的白色，若残留粉色或浅色薄层，说明去皮不彻底 |
| 去除率 | 这一步能去除相当大一部分总量 |
| 表皮处理 | 人和家畜都不可食用，须充分腐熟后用作堆肥 |
| 中心芯 | 中间坚韧的纤维芯也要一并去除 |

#### 14-5-2. 浸水

| 项目 | 内容 |
|---|---|
| 原理 | 氰苷及其分解产物溶于水中流失 |
| 低苦味种 | 切块后浸泡6-12小时即可 |
| 高苦味种（整根） | 3-6天。去皮后完全浸没在水中 |
| 高苦味种（切块） | 24-72小时，切块越小越快 |
| 换水 | 每天至少换水1次，不换水浓度会达到平衡，不再继续析出 |
| 温度 | 越温暖越快，30度左右效率最高 |
| 浸泡水 | 毒素溶于其中，人畜均不可饮用，也不可倒入田地 |
| 注意 | 不可用密闭容器浸泡，气体会积聚 |

#### 14-5-3. 磨碎发酵

| 项目 | 内容 |
|---|---|
| 原理 | 最大限度破坏细胞，让酶全面发挥作用，效果最显著 |
| 方法 | 把去皮后的块根用擦板或石臼彻底捣碎 |
| 发酵 | 将捣碎物装入袋子或容器，在阴凉处放置3-5天 |
| 压榨 | 装入袋中用石头压榨出汁，毒素溶于汁液中 |
| 气味 | 会有酸味发酵气味，这是正常现象 |
| 去除率 | 操作得当可去除95%以上 |
| 之后 | 将榨过的团块炒熟或蒸熟食用 |
| 注意 | 榨出的汁液要倒掉。若想回收淀粉，可让汁液沉淀，只取沉淀物反复漂洗后使用 |

&nbsp;&nbsp;&nbsp;西非的加里（garri，发酵木薯食品）和福福（fufu，木薯制成的主食）就是这种方式。磨碎、装袋发酵数日、压榨、再炒熟或蒸熟，这四个步骤是经过好几代人打磨出来的解毒工艺。若在灾害情况下需要大批量处理高苦味种，这种方式最为可靠。

#### 14-5-4. 彻底晒干

| 项目 | 内容 |
|---|---|
| 原理 | 切薄片后酶开始作用，在晾干过程中氰化氢挥发到空气中 |
| 厚度 | 切成5mm以下的薄片，太厚会残留在内部 |
| 方式 | 摊开晒太阳，4-7天 |
| 阴干 | 虽然比晒太阳慢，但据报告酶作用时间更长，去除率反而更高 |
| 判断标准 | 晒至折断时发出脆响、能用手掰碎为止 |
| 去除率 | 视条件而定，60-90% |
| 注意 | 未晒透就装袋会发霉，毒素也会残留 |

#### 14-5-5. 充分加热

| 项目 | 内容 |
|---|---|
| 原理 | 让残留的氰化氢挥发，同时使淀粉熟化 |
| 低苦味种 | 切成2-3cm的块，在沸水中煮20-30分钟，不加盖 |
| 高苦味种 | 须先经过前面的步骤再加热，仅靠加热是不够的 |
| 煮的水 | 必须倒掉，其中溶有氰化物 |
| 锅盖 | 保持打开，必须让气体逸出 |
| 通风 | 在室内大量煮制时要开窗 |
| 判断标准 | 苦味和涩味必须完全消失 |

### 14-6. 各品种最低限程序

| 区分 | 步骤 | 耗时 |
|---|---|---|
| 低苦味种 | 厚厚去皮、切块、浸水6-12小时、倒掉浸泡水后煮20-30分钟、倒掉煮汁 | 1天 |
| 高苦味种（家庭食用） | 去皮、切块、浸水3-5天并每日换水、切成5mm晒干4-7天至彻底干燥、磨成粉、烹调时充分加热 | 1-2周 |
| 高苦味种（大批量加工） | 去皮、彻底磨碎、装袋发酵3-5天、压榨、炒熟或蒸熟 | 1周 |
| 品种不明 | 按高苦味种的程序处理 | - |

### 14-7. 让木薯粉重新湿润的方法

&nbsp;&nbsp;&nbsp;晒干磨成的木薯粉中，往往仍残留亚麻苦苷，干燥不充分或匆忙晒干的粉尤其如此。有一个简单的方法可以进一步减少这部分残留。

| 顺序 | 内容 |
|---|---|
| 1 | 将粉与等体积的水混合，调成湿润的糊状 |
| 2 | 摊在宽口容器或板子上，厚度不超过1cm |
| 3 | 在阴凉处静置5小时以上 |
| 4 | 这段时间里，粉中残留的酶会分解亚麻苦苷，氰化氢随之挥发 |
| 5 | 之后照常煮或蒸熟食用 |

&nbsp;&nbsp;&nbsp;原理很简单。亚麻苦苷酶在干燥状态下无法工作，但也不会死亡，一旦遇水就会重新恢复活性。摊薄的原因是让产生的气体尽快逸出，放在阴凉处的原因是直射阳光会破坏酶。只需多加这一步，残留的氰化物就能减少到几分之一。由于不需要工具也不需要燃料，在灾害情况下格外有价值。

### 14-8. 叶片的处理

| 项目 | 内容 |
|---|---|
| 营养 | 每100g鲜重含蛋白质5-10g，富含赖氨酸 |
| 风险 | 氰化物含量常高于块根 |
| 第1步 | 采摘嫩叶，去掉粗叶柄 |
| 第2步 | 放入臼中彻底捣碎，破坏细胞是关键 |
| 第3步 | 换水煮制30分钟以上 |
| 第4步 | 倒掉煮的水 |
| 判断标准 | 若仍有苦味须再次煮制 |
| 注意 | 略微焯烫后食用的方式很危险，不能像凉拌野菜那样处理 |

&nbsp;&nbsp;&nbsp;木薯叶几乎是弥补木薯饮食最大弱点——蛋白质不足——的唯一手段。只吃块根虽能填饱肚子却会让身体日渐消瘦，若同时吃叶子，这个问题就能大大缓解。而且叶片在块根成熟之前、生长中期就能采摘，填补了直到收获前的漫长空档。不过必须记住，叶片的氰化物含量比块根更高，捣碎和久煮这两个步骤不可省略。

### 14-9. 急性中毒

| 项目 | 内容 |
|---|---|
| 发作时间 | 摄入后数十分钟到6小时，经肠道细菌分解后出现得更晚 |
| 早期症状 | 头晕、头痛、恶心、呕吐、腹痛、腹泻 |
| 进展期症状 | 呼吸急促而浅、心悸、焦躁不安、意识模糊 |
| 重症 | 抽搐、发绀、意识丧失、呼吸麻痹、死亡 |
| 气味 | 可能有苦杏仁味，但相当多人闻不出这种气味 |
| 高危人群 | 儿童。按体重计算摄入量更大，同样的量危险得多 |

| 情况 | 应对 |
|---|---|
| 刚摄入即怀疑中毒时 | 不再让其进食，收走剩余食物 |
| 出现症状时 | 让患者躺在通风处，保持安静 |
| 意识清醒时 | 少量多次喂水，不要强行催吐 |
| 意识下降或抽搐时 | 使其侧卧，确保呼吸道通畅 |
| 恢复后 | 将致病的木薯全部废弃，重新检查处理程序 |
| 前提 | 在得不到医疗救助的情况下能做的有限，预防是唯一的对策 |

### 14-10. 慢性中毒——孔佐病与神经病变

&nbsp;&nbsp;&nbsp;木薯真正伤害更多人的，不是急性中毒，而是慢性中毒。急性中毒显而易见，慢性中毒却是悄然而至。

| 区分 | 孔佐病 | 热带共济失调性神经病变 |
|---|---|---|
| 发病 | 突然发作，数小时至数天内出现 | 渐进发展，历时数年 |
| 主要症状 | 双腿僵硬，无法行走 | 步态不稳、视力下降、听力减退 |
| 高发人群 | 多见于儿童和育龄妇女 | 多见于40岁以上人群 |
| 病程 | 无法恢复，只能阻止恶化 | 进行性发展 |
| 诱因 | 持续数周以上食用处理不充分的高苦味种 | 长期暴露于处理不足的状态 |
| 加重因素 | 合并蛋白质缺乏时会急剧增加 | 相同 |
| 治疗 | 无 | 无 |

&nbsp;&nbsp;&nbsp;了解孔佐病何时发生非常重要。这种病总是伴随饥荒而来。因为饥饿难耐，人们会把平时要泡三天的东西只泡一天，把要晒七天的东西两天就收起来吃掉。灾害情况正是最容易走这种捷径的状况，因此也是本节的程序最难被遵守的状况。

### 14-11. 蛋白质与解毒的关系

&nbsp;&nbsp;&nbsp;进入体内的氰化物会在肝脏中转化为硫氰酸盐，随尿液排出。这一反应需要硫，而硫来自蛋氨酸和半胱氨酸等含硫氨基酸。也就是说，蛋白质摄入充足的人能够解毒氰化物，而蛋白质不足的人，即使摄入相同量的氰化物，受到的伤害也会大得多。

| 情况 | 结果 |
|---|---|
| 只吃木薯 | 蛋白质仅占热量的3.4%，解毒能力下降 |
| 解毒能力下降 | 同样的氰化物造成更大损伤 |
| 损伤累积 | 孔佐病和神经病变的风险上升 |
| 结果 | 只吃木薯会让毒性变得更强 |

> **安全食用木薯最重要的条件之一，就是不要只吃木薯。必须搭配豆类、鱼、蛋、木薯叶中的任意一种一起吃，身体才能处理氰化物。**

&nbsp;&nbsp;&nbsp;硫氰酸盐还会引发另一个问题。它会妨碍甲状腺摄取碘，在缺碘地区会增加甲状腺肿及由此导致的发育障碍。远离海洋、难以获得食盐和海藻的内陆地区若依赖木薯为生，尤其需要注意这一点。

### 14-12. 绝对不可做的事

| 禁止事项 | 理由 |
|---|---|
| 生食 | 无论何种品种都禁止 |
| 只薄薄去皮 | 氰化物最多的部位原样残留 |
| 整块长时间煮 | 酶先失活，亚麻苦苷原样残留 |
| 加盖煮 | 气体无法逸出 |
| 使用煮过或浸泡过的水 | 毒素溶于其中，不可用作汤汁 |
| 把浸泡水喂给家畜 | 家畜也会中毒 |
| 在密闭容器中发酵 | 气体积聚，十分危险 |
| 使用未晒透的粉 | 氰化物残留且会发霉 |
| 仍有苦味却食用 | 这是处理尚未完成的信号 |
| 省略步骤 | 越饥饿越要严格遵守程序 |
