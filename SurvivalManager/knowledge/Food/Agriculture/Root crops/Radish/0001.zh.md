## 引言
&nbsp;&nbsp;&nbsp;萝卜（Raphanus sativus）是原产于地中海沿岸到中亚一带的十字花科二年生根菜，我们吃的白色部分是为了第二年开花，由根和茎的下部膨大而成的养分仓库。所以耐储藏，而一旦抽薹就不能吃了。灾害应对评估的综合等级为S（51.8分，有效183种中第11位），短期S（52.6）、长期S（51.0）、副食SS（62.2分），三项都很高。从播种到收获55-70天（评估标准），埋进窖里能存3-4个月，切开晒干能存一年以上，叶子（萝卜缨）另外又是一种食物，在同一块地里连作也没有大问题。另一方面，0℃时根会冻坏，对湿害极为敏感，错过播种和收获的时机，收获物本身就没有了。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | S | 51.8 |
| 短期 | S | 52.6 |
| 长期 | S | 51.0 |
| 副食 | SS | 62.2 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：设施负担、烹调·加工要求度、连作适应性、国内种植普及度。S：收获速度、口味、种子寿命。A：蛋白质密度、微量营养素、自留种。B：单位面积热量、施肥、水消耗量、光照、温度幅度、产量稳定性 |
| 劣势 | D：持续性、非食用价值。C：耐寒性、病虫害压力、防治自立度、耐储性、无合成投入产量保持率、整地·挖掘能量 |

> **萝卜不是某一项特别出色的作物，而是因为决定性的差项很少，所以得分很高的作物。**

&nbsp;&nbsp;&nbsp;单位面积热量B是指每100g热量只有21kcal，热量密度虽低，但每1,000㎡能收7,000kg，折合每㎡1,470kcal（自给线的0.56倍）；一棵就有1.3-1.6kg，所以进到厨房的重量是叶菜的两倍以上。叶子占根重的30-50%，是另一种食物。连作适应性SS是指农村振兴厅把萝卜归入连作无害组，并不是说它不会感染根肿病。耐寒性C是指0℃时根会冻坏，冬天不能留在田里，耐储性C是指储存期限为B，但因损失率8.94%而降了一级。整地·挖掘能量C是指深耕22cm，每㎡要消耗239kcal，是叶菜的两倍以上。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 十字花科萝卜属二年生草本。因为是萝卜属而不是芸薹属，与白菜、甘蓝、芥菜、羽衣甘蓝在自然状态下不会杂交 |
| 花、果实 | 白色或淡紫色的花。角果饱满，不易裂开，内有4-10粒种子，嫩角果可以吃 |
| 食用部位 | 上面约三分之一是茎的下部（下胚轴）膨大而成，下面才是真正的根。上部更甜更硬，用于生拌凉菜，下部用于做汤和炖菜。叶子（萝卜缨）也是食物 |

&nbsp;&nbsp;&nbsp;播种后2周内为发芽·幼苗期，2-6周为叶片增多的营养生长期，6-10周为根膨大期，10-13周为成熟期，之后经历低温就会抽薹。以第6周前后为界，根由长度生长转为粗度生长。笔直的根在最初几天遇到什么样的土决定形状，碰到石头、硬土或未腐熟的堆肥就会裂开，之后再怎么管理也无法恢复。每100g含热量21kcal、蛋白质0.77g（占热量14.7%）、糖类2.96g、维生素C 20-25mg、钙23mg；萝卜缨含有根里几乎没有的β-胡萝卜素，钙和铁也比根多得多。帮助消化的淀粉酶类酶怕热。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 生长适温17-23℃，根膨大适温21-23℃（低了变慢，高了只长叶子并出现糠心），发芽15-30℃。0℃时根组织冻结而被破坏 |
| 水分、光照 | 总蒸散量约500mm。喜强光，遮光40%时相对产量约80%，在阴处只长叶子而徒长 |
| 土壤 | 排水良好的砂壤土-壤土，耕层20-30cm，垄高15-20cm，pH6.5-7.5（抑制根肿病）。没有石灰时，播种前2周每㎡施稍多于一把的木灰，但要与堆肥间隔几天（同时施入，堆肥中的氮会变成氨挥发掉） |

&nbsp;&nbsp;&nbsp;湿害是最大的风险。积水后根无法呼吸，软腐病细菌扩散，几天内整根烂成一滩并发出恶臭。干旱之后突然浇大量的水，表皮会纵向裂开（裂根），无法储存，所以浇水要均匀而不是浇得多，排水要排在其他所有管理之前。

&nbsp;&nbsp;&nbsp;-1℃左右的轻霜会把淀粉变成糖，提高甜味，但-3至-4℃以下的寒潮会使细胞冻裂，解冻后变软腐烂。秋萝卜要在11月中旬第一次强寒潮之前拔收。萝卜在种子或很小的幼苗时就能感受低温（0-13℃），所以春天播得太早会抽薹。

&nbsp;&nbsp;&nbsp;秋萝卜（70-90天）是灾害应对的核心。它在凉爽条件下缓慢膨大，组织紧实，含糖多，在窖里能存3-4个月。春萝卜（50-60天）组织松软、水分多，耐储性差；叶用小萝卜（yeolmu，20-40天）和总角萝卜（chonggak，40-60天）是吃叶子的品系，在灾害初期最先产出可吃的东西。市售种子很多是一代杂种，留下的种子性状会分离，所以灾害可能持续时，要事先备好固定品种或地方品种。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 翻耕20-30cm深，清除石头、木片和硬土块。在播种前2周以上施入腐熟堆肥并深翻拌匀（未腐熟的堆肥是根裂开最常见的原因） |
| 施肥（1,000㎡） | 氮10-12kg、钾8-10kg、堆肥1,000-1,500kg。基肥在播种前1-2周施入，追肥是真叶3-4片时施氮、6-7片时施钾。膨大期的氮只会让叶子生长并使组织变松软，所以收获前一个月就停止 |
| 灾害替代肥料 | 腐熟堆肥（每㎡1-1.5kg）、木灰（补钾并调节酸度，每年少量）、稀释10-15倍的尿液（仅第一次追肥用）、木灰浸一天后滤出的浸出液（膨大期补钾） |
| 栽培类型 | 秋萝卜7月中旬-9月上旬播种、10月中旬-11月下旬收获，初霜前70-90天为适期（中部8月中下旬，南部9月初）。播晚了，还没膨大就到了寒冷季节。春萝卜3月中旬-4月下旬播种、5月中旬-7月上旬收获，要在气温超过20℃之前结束。越冬萝卜9月下旬-10月播种，翌年早春收获（南部、沿海） |
| 播种 | 必须直播（移栽会折断主根而使根裂开）。深1-2cm，穴播每穴1-2粒，行距60-70cm，最终株距25-30cm（每1,000㎡ 8,000-9,000株） |
| 种子处理 | 挑选饱满的大粒种子，裹上木灰消毒并晾干。温汤浸种（50-55℃ 10-15分钟，超过60℃种子会死，低于45℃病原菌会存活）是不用药剂就能切断种传病害的最可靠的方法 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 发芽到幼苗期 | 少量多次浇水，别让表土干（根还浅） |
| 根膨大期 | 均匀而充足（水分波动会造成裂根）。收获前2周起逐渐减少，使组织紧实 |
| 雨季 | 保证排水沟畅通（湿害的风险大于干旱） |

| 管理 | 方法 |
|:---|:---|
| 覆盖 | 在株间铺稻草或干草，水分的波动幅度会变小，是防止裂根最便宜的办法 |
| 间苗 | 真叶3-4片时每穴留一株，6-7片时间到株距25-30cm。拔会摇动要保留植株的根而导致裂根，所以用剪刀或指甲在贴近地面处剪断。间苗晚了会剩下许多细萝卜，间下来的嫩萝卜当作叶用小萝卜吃 |
| 除草、根肩 | 最初3-4周是与杂草的较量，叶子盖住地面后几乎不需要。别把锄头深插，以免切断须根。根的上部露出地面是正常的，露得多了就轻轻盖些土 |
| 摘叶 | 膨大开始之前只摘下部的老叶2-3片，始终留下8片以上。膨大期之后不摘 |
| 缺水 | 中午叶子萎蔫、傍晚恢复就是暂时的。持续缺水则根变细、辣味变强 |

## 6. 病虫害与养分问题
&nbsp;&nbsp;&nbsp;病虫害压力和防治自立度都是C（无防治估计减产率51.7%）。主要问题发生在地下，看不见，等看见时那一株已经没了。防治不是事后处理，而是排水、酸度、轮作、健康种子这些事先条件，这四项不齐备，之后能做的事几乎没有。

| 病虫害 | 症状与条件 | 预防与应对 |
|:---|:---|:---|
| 软腐病 | 根烂成糊状并发出恶臭，汁液蔓延到邻近植株（湿害、伤口、氮过多）。储藏中也会继续发展 | 高垄和排水沟，不弄伤。病株立即拔出，丢到远处或埋掉，不放进堆肥 |
| 根肿病、线虫 | 根上长瘤，植株萎蔫（酸性土壤、十字花科连作） / 成排长出串珠状小瘤 | 用木灰把pH保持在6.5-7.0，与非十字花科作物轮作，间作万寿菊。即使连作适应性是SS，病原菌也会积累 |
| 霜霉病、白粉病 | 叶片变黄，叶背长霉（潮湿） / 叶面出现白粉（干湿交替） | 间苗以通风，摘除病叶 / 把牛奶稀释10倍在晴天早晨喷洒（阴天牛奶会变质），小苏打每1L水1g多一点（浓了会伤叶） |
| 病毒病、黑腐病 | 花叶、卷曲（蚜虫传播） / 叶缘呈V字形枯焦（高温高湿、伤口） | 防治蚜虫，病株拔出烧掉 / 种子温汤浸种，清除病株 |
| 害虫 | 跳甲（出苗后到真叶3-4片时最致命）、蚜虫、小菜蛾和菜粉蝶幼虫（啃叶）、蛴螬和地老虎（啃根） | 出苗后立即盖防虫网，撒木灰 / 每1L水加20g肥皂的肥皂水喷到叶背，隔几天一次，保护瓢虫 / 人工捕捉 |

| 症状 | 原因与措施 |
|:---|:---|
| 叶缘变褐枯焦 | 缺钾。施木灰或木灰浸出液 |
| 根里发黑或发褐（黑心） | 缺硼（有机质少的沙地、酸度高的田、干旱年份）。多施堆肥，木灰别施过量（硼会被土壤固定） |
| 只有叶子茂盛、根很细 | 氮过多（最常见的失败原因，组织松软，储藏中会烂）。停止施氮并补钾 |
| 根裂开或分叉 | 由未腐熟堆肥、石头、硬土造成，下一茬改进整地。里面空了就是糠心（第8节） |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 生菜、菠菜（根深不同，竞争小，还能覆盖地面。生菜40-50天、萝卜70-90天，同一块地可收两种）、大葱、韭菜（气味扰乱害虫）、万寿菊（抑制线虫） |
| 差 | 白菜、芥菜、甘蓝等十字花科（共有病虫害）、胡萝卜、牛蒡等其他根菜（争夺同一深度） |

&nbsp;&nbsp;&nbsp;轮作以4年为一个周期：第一年萝卜或白菜等十字花科，第二年豆科（固氮），第三年叶菜类或葱类，第四年玉米或高粱等禾本科（深根把下层养分带上来）。豆后马上种萝卜，氮多可能只长叶子，所以中间再种一茬别的作物，或者等豆秸充分腐熟后再种。萝卜的粗根扎得深，拔出后会留下可通水通气的洞，所以有时把它放在轮作中间，用来不靠机械松动硬地。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时机 | 春萝卜在气温超过20℃之前，秋萝卜在11月中旬降到-3℃以下之前拔收。再多放几天也不会变粗，只会糠心，所以根肩直径达到品种标准或外叶开始下垂时就拔 |
| 要领 | 在晴朗干燥的日子，把叶子拢在一起笔直向上拔（拔不动就用锄头在旁边挖开）。不要扔或摔（伤口是软腐病的入口）。只抖掉泥土，不用水洗。萝卜缨在叶子连接处干净地切下，另外处理，并在阴凉处晾半天，让表面水分散去 |
| 糠心 | 根内部像海绵一样空掉，失去口味和耐储性。收获过晚、抽薹、高温干燥、急速膨大（氮过多、突然降雨）、冻后解冻、叶片受损都会造成，无法逆转，所以掌握时机就是预防。糠心的萝卜用来熬汤或做萝卜干，不放进窖里 |

| 留种 | 标准 |
|:---|:---|
| 特性 | 二年生且自交不亲和，只留一株的话，花虽然开，却几乎结不了种子。蜜蜂和风传粉（异花授粉），种子常温密封能保存5年。在路边和田埂上自生的野萝卜，种子也能正常发芽，在种子供应中断时是一种保险，但根又细又韧 |
| 方法 | 直播留种是春天播种、当年就收到种子，又快又容易，但看不到根、无法挑选，几年后根会变细变韧。采根留种是秋天挑选粗、直、没有糠心的根，越冬后在春天重新栽种，可以保持品质。灾害第一年用直播留种确保种子，有余力后用采根留种守住品质 |
| 杂交 | 所有萝卜品种（秋萝卜、春萝卜、叶用小萝卜、总角萝卜、樱桃萝卜）与野萝卜都会完全杂交，与白菜、甘蓝、芥菜不杂交 |
| 隔离、株数 | 与其他开花的萝卜相距500m以上（严格说1km），或每年只让一个品种开花，田边的野萝卜在开花前割掉。留种株至少10株，最好20株以上（太少会降低结实率并造成近交衰退）。套网时把几株放在一起，用毛笔移粉 |
| 程序 | 把选出的根埋进窖里，或留少许叶子重新栽回田里盖上稻草越冬（11-2月），2-3月重新栽种，让根肩略微露出。3-4月抽薹（立支架），4-5月开花，6-7月角果干成褐色、摇动有响声时连茎割下，在阴凉处晾1-2周后装袋敲打或踩踏（角果不易裂开，脱粒很费力） |

## 9. 储存
&nbsp;&nbsp;&nbsp;耐储性C是把储存期限B和损失率8.94%合起来的等级，所以萝卜虽然耐放，储存中损失的量也不少。只储存没洗过的完好萝卜，只要有一个受伤、糠心或有软腐迹象的，整个冬天都会让旁边的萝卜变坏。冬季饮食分两路安排：维生素C来自窖里的生萝卜和发酵食品，热量和体积来自干制品。

| 方式 | 方法 | 期限 |
|:---|:---|:---|
| 窖储存 | 在不积水的地方挖宽60cm、深75cm的坑，铺干稻草或沙子，把萝卜按长叶的一端朝下竖着放入。盖上厚稻草，再分2-3次覆土40-60cm，四周挖排水沟。0-4℃，湿度85-95%。分成几个窖，打开时只取需要的量并重新盖好 | 3-4个月 |
| 埋藏、室内 | 平放在田里并盖上稻草和土 / 埋在略潮的沙里，萝卜互不接触 / 用纸逐个包好放在阴凉处 | 2-3个月 / 1-2个月 / 1-2个月 |
| 萝卜干 | 切成0.5-1cm，摊在向阳通风处，不要重叠，每天翻一两次（晴天3-5天，弯曲时不断而是弯下的程度）。10kg缩成1kg，但维生素C大部分会损失 | 6个月-1年以上 |
| 干萝卜缨 | 抖掉萝卜缨枯萎的叶子和泥土，不洗，捆好倒挂在通风的阴凉处，晾一两个月。使用时泡一夜再煮，倒掉煮水并漂洗，之后做凉拌菜或汤 | 数月 |
| 萝卜水泡菜、腌渍 | 萝卜水泡菜是把整个萝卜泡在2-3%的盐水里发酵（连汤一起吃，保留相当多的维生素C），咸菜式是10-15%盐渍（吃前用水泡去盐），酱渍是用酱油或大酱腌制。材料完全浸没在盐水下、盐浓度不低于2%时，长的是乳酸菌而不是杂菌 | 数月-1年以上 |

## 10. 烹调与注意事项
| 注意 | 内容 |
|:---|:---|
| 变质的萝卜 | 得了软腐病的萝卜外表看起来完好，里面却已烂成糊状，切开有恶臭，所以不要吃，扔掉。储存期间每次检查一两个并挑出 |
| 致甲状腺肿物质 | 芥子油苷的部分分解产物会妨碍甲状腺利用碘。一般用量没有问题，但在缺碘的饮食中长期大量吃生萝卜就有危险，所以在海藻没有了的灾害状况下要掺入熟的（加热可减少） |
| 其他 | 一次吃很多生萝卜可能刺激胃，氮施得多的萝卜会积累硝酸盐。没有急性毒性，也不需要解毒程序 |

| 烹调 | 方法 |
|:---|:---|
| 生吃 | 洗净切开就行，不用燃料，水分多，也能解渴。维生素C和膳食纤维集中在皮下，所以带皮用。萝卜泥保留着消化酶，与米饭、年糕、土豆一起吃有助于淀粉消化 |
| 熟制、加工 | 久煮辣味散去、甜味出来，所以只用萝卜、盐和水也能成为一道完整的汤。晒干泡发或发酵后食用，已抽薹的萝卜的嫩角果可以做凉拌菜或酱渍菜 |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查窖里的萝卜并挑出坏的，检查萝卜干和干萝卜缨。2月翻堆堆肥，准备春萝卜地，确认留种株越冬 |
| 3-4月 | 3月中旬起播春萝卜，重新栽种越冬的留种株。4月春萝卜间苗和追肥，给留种株立支架 |
| 5-6月 | 5月开始收春萝卜，留种株开花（隔离管理）。6月春萝卜收完，为夏天清理田地 |
| 7-8月 | 7月上旬采种，中旬起准备秋萝卜地并播种。8月继续播种，防备出苗期的跳甲，第一次间苗 |
| 9-10月 | 9月第二次间苗和追肥，管好秋季连阴雨时的排水，上旬前播完。10月管理根膨大期，中旬起开始早收 |
| 11-12月 | 11月中旬主收获，整理萝卜缨，挖窖储存，晾晒萝卜干和干萝卜缨，腌制越冬泡菜（作业集中，所以把播种每隔十天分开，分散收获期）。12月管理储存物，检查萝卜水泡菜和泡菜的熟成，清理田地 |

> **萝卜是这样一种作物：守住播种窗口（7月中旬-9月上旬）和收获窗口（11月中旬、-3℃之前），把排水放在最前面，只储存完好的萝卜。**
