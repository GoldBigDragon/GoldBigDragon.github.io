## 13. 採種 - 二年生と自家不和合性

### 13-1. 二つの障壁

&nbsp;&nbsp;&nbsp;ダイコンの採種には二つの壁があります。一つは二年生という生活型、もう一つは自家不和合性という受粉様式です。評価表の自家採種の等級がAにとどまる理由は、ここにあります。

| 障壁 | 内容 | 結果 |
|:---|:---|:---|
| 二年生 | 低温を経験しないと花茎が立ちません | 種を採るには、根を越冬させなければなりません |
| 自家不和合性 | 自分の花粉ではうまく受精しません | 複数の株を一緒に開花させる必要があります |
| 他家受粉 | ハチや風が花粉を運びます | ほかの品種と混ざります |

&nbsp;&nbsp;&nbsp;ただし、ダイコンの二年生という性質は、ハクサイやキャベツほど厳密ではありません。ダイコンは種子の状態やごく幼い苗の状態でも低温を感知する種子春化型に近いため、春に早く播いたダイコンがその年の夏に開花することがよくあります。そのため、ダイコンの種を得る道は二つあります。

| 方法 | 手順 | 長所と限界 |
|:---|:---|:---|
| 直播き採種 | 春に播いてそのままにしておくと、その年に花が咲いて種ができます | 早くて簡単ですが、根を見て選ぶことができません |
| 根選抜採種 | 秋に育て、根を見て良いものを選んで越冬させ、春に植え直します | 品質を選抜できますが、手間がかかります |

&nbsp;&nbsp;&nbsp;この二つの違いは決定的です。直播き採種は、根がどのような形をしているか分からないまま種を採ることです。葉だけを見て選ぶことになるため、数年たつと根が細くて硬くなる方向へ傾いていきます。野生に戻る方向です。根選抜採種は、根を掘り上げて太くてまっすぐで形のよいものを選び、植え直す方式なので、品種の性質が維持されます。

> **災害発生の初年は直播き採種で種子を確保し、余裕ができたら根選抜採種で品質を守ります。根選抜採種を数年飛ばすと、ダイコンは急速に野生の側へ戻ってしまいます。**

### 13-2. 何と交雑するか

| 作物 | 学名 | ダイコンとの交雑 |
|:---|:---|:---|
| すべてのダイコン品種（秋ダイコン、春ダイコン、ヨルム（若どりの小ダイコン）、チョンガクム（葉付きの小型ダイコン）、ハツカダイコン） | Raphanus sativus | 完全に交雑します |
| 野生ダイコン・ハマダイコン | Raphanus raphanistrum など | 交雑します |
| ハクサイ、カブ、チンゲンサイ | Brassica rapa | 自然状態では交雑しません |
| キャベツ、ケール、ブロッコリー | Brassica oleracea | 交雑しません |
| カラシナ、マスタード | Brassica juncea | 交雑しません |

&nbsp;&nbsp;&nbsp;ダイコンがアブラナ属ではなくダイコン属に属するという事実が重要です。ダイコンの種を採る年に、ハクサイやカラシナやケールが開花しても問題ありません。属が違うので、花粉が付いても受精しません。アブラナ科の作物を複数、同じ畑で育てる状況では、これは大きな利点です。

&nbsp;&nbsp;&nbsp;問題になるのは、ダイコン同士だけです。秋ダイコン、ヨルム、チョンガクム、ハツカダイコンは、見た目がまったく違って見えても、すべて同じ種なので完全に混ざります。ヨルムのそばで秋ダイコンが開花すると、翌年には根が細く葉ばかり茂る雑種ができます。さらに、道端や土手に自生する野生ダイコンも交雑の相手です。都市の郊外や川辺によく生え、春に白や薄紫の花を咲かせるあの草がダイコンの野生型で、これと混ざった種からは、根が細くて硬いダイコンができます。

### 13-3. 隔離と受粉

| 方法 | 内容 | 現実性 |
|:---|:---|:---|
| 隔離距離 | ほかのダイコンの開花株から500m以上、厳密には1km離します | 野生ダイコンまで管理するのは難しいです |
| 年ずらし栽培 | 1年に1品種だけを開花させます | 最も現実的です |
| 網掛け | 開花前に網をかぶせてハチの出入りを防ぎます | 自家不和合性のため、中で手作業により花粉を移す必要があります |
| 周辺の整理 | 畑の周りの野生ダイコンを、花が咲く前に刈り取ります | 周囲と一緒に行わないと効果が出ません |

&nbsp;&nbsp;&nbsp;ダイコンは自家不和合性が強い作物です。自分の花粉が自分の雌しべに付いても、花粉管が伸びないようにする遺伝的な仕組みがあります。近親交配を避けようとする植物側の戦略ですが、人間の立場からは、採種を難しくする性質です。1株だけを隔離しておくと、花はたくさん咲いても、種はほとんどできません。

> **採種用の株は最低10株、できれば20株以上を一緒に開花させます。自家不和合性の作物では、株数が少ないと結実率が下がり、数世代たつと近交弱勢で勢いが衰えます。**

&nbsp;&nbsp;&nbsp;網をかぶせる場合も、複数の株を一つの網の中に一緒に入れる必要があります。その中にはハチがいないので、人が筆やブラシで花から花へと行き来しながら花粉を移してやります。午前中の、花が十分に開いたときがよいです。手間はかかりますが、純度は確実に守られます。

### 13-4. 採種の手順

| 段階 | 時期（韓国の気候基準） | 内容 |
|:---|:---|:---|
| 採種株の選抜 | 秋の収穫期 | 根が太くてまっすぐで、す入りがなく、品種の特性がはっきりしているものを選びます |
| 越冬 | 11月-2月 | 根を室（むろ）に埋めるか、葉を少し残して畑に植え直し、わらで覆います |
| 再定植 | 2-3月 | 越冬した根を、肩が少し出るように植え直します |
| 抽だい | 3-4月 | 花茎が立ちます。倒れないように支柱を立てます |
| 開花 | 4-5月 | 白や薄紫の花が咲きます。この時期に隔離を守ります |
| 着莢 | 5-6月 | ふっくらとしたさやがつきます |
| 収穫 | 6-7月 | さやが茶色く枯れ、振ると音がするようになったら、茎ごと刈ります |
| 後熟・脱粒 | 収穫直後 | 日陰で1-2週間乾かしたあと、袋に入れてたたいたり踏んだりします |
| 選別・保管 | 完全乾燥後 | 箕であおって殻を飛ばし、密閉して涼しい場所に置きます |

&nbsp;&nbsp;&nbsp;ダイコンのさやは、ほかのアブラナ科と違って、あまりはじけません。スポンジのような組織が種を包んでいるため、乾いたあとも自然には割れません。この性質のおかげで、畑で種を失う危険は低いのですが、その代わり脱穀が大変です。袋に入れてたたいたり足で踏んだりして砕き、それでも出てこなければ、臼に入れて軽くつきます。強くつくと種が傷むので、力加減が必要です。

| 項目 | 基準 |
|:---|:---|
| 種子寿命 | 常温・密閉で5年 |
| 最適な保管 | 涼しく暗く乾燥した場所、密閉容器 |
| 乾燥剤 | 炒って冷ました米、炭、乾いた草木灰 |
| 発芽確認 | 毎年20粒を湿らせた布の上に置き、数日後に発芽率を数えます |
| 1株当たりの収量 | 種子数千粒 |

## 14. 毒性と注意すべき成分

&nbsp;&nbsp;&nbsp;ダイコンは、一般的な摂取量であれば安全な食品です。洗ってそのまま食べられ、評価表の調理・加工の等級SSがその事実を反映しています。急性毒性はなく、特別な解毒の手順も必要ありません。

| 項目 | 内容 | 対応 |
|:---|:---|:---|
| カラシ油配糖体（辛味） | アブラナ科に共通する成分。少量では問題ありません | 生のダイコンを一度にたくさん食べると、胃が刺激されることがあります |
| ゴイトロゲン | カラシ油配糖体の分解物の一部がヨウ素の吸収を妨げます | 加熱調理した形を取り混ぜ、海藻類を添えます |
| 硝酸塩 | 窒素を多く施したダイコンに蓄積します | 窒素を与えすぎません |
| 傷んだダイコン | 軟腐病にかかったダイコンから出る悪臭と軟化 | 食べずに捨てます |

&nbsp;&nbsp;&nbsp;ゴイトロゲンについて、もう少し書いておきます。アブラナ科の植物の辛味成分が分解されるときにできる物質のうち一部は、甲状腺でヨウ素が使われる過程を妨げます。ヨウ素を十分に摂っている人が普通の量のダイコンを食べることは、問題になりません。危険になる条件は、ヨウ素が不足した食事で、アブラナ科の野菜を生のまま大量に、長期間食べ続けるときです。

&nbsp;&nbsp;&nbsp;災害時には、この条件が実際に生じる可能性があります。物流が途絶えて海から遠ざかると、ワカメやコンブやノリが手に入らなくなります。対応は、加熱調理した形を取り混ぜることです。加熱すると分解酵素が壊れて、ゴイトロゲンの生成が減ります。ダイコンは、汁物や煮物のように火を通して食べる調理法が多いので、この問題が深刻になる可能性は低いほうです。

&nbsp;&nbsp;&nbsp;最も実質的な注意事項は、傷んだダイコンを見分けることです。軟腐病にかかったダイコンは、外側は無事に見えても中が粥のようにどろどろになっていて、切ると悪臭がします。貯蔵中に1、2本ずつ確認して、傷んだものを取り除く作業が、冬の間ずっと必要です。
