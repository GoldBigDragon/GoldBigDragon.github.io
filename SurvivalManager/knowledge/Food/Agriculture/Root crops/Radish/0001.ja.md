## はじめに
&nbsp;&nbsp;&nbsp;ダイコン(Raphanus sativus)は、地中海沿岸から中央アジアにかけてが原産のアブラナ科の二年草の根菜で、食べる白い部分は、翌年に花を咲かせるために根と茎の下部がふくらんだ養分の貯蔵庫です。そのため貯蔵性がよく、花茎が立つと食べられなくなります。災害への備えの評価は総合S(51.8点、有効183種中11位)、短期S(52.6)、長期S(51.0)、副食SS(62.2点)で、3つの値がすべて高くなっています。播種から収穫まで55-70日(評価の基準)で、穴に埋めれば3-4か月、切って干せば1年以上貯蔵でき、葉(ダイコンの葉)が別の食料になり、同じ場所に続けて植えても大きな問題がありません。一方、0℃で根が凍り、湿害にきわめて弱く、播種と収穫の時期を逃すと収穫物そのものがなくなります。

## 1. 災害への備えの評価
| 区分 | 等級 | スコア |
|:---|:---:|:---:|
| 総合 | S | 51.8 |
| 短期 | S | 52.6 |
| 長期 | S | 51.0 |
| 副食 | SS | 62.2 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: 施設の負担、調理・加工の要求度、連作への適応性、国内での栽培の普及度。S: 収穫速度、味、種子の寿命。A: タンパク質密度、微量栄養素、自家採種。B: 面積当たりの熱量、施肥、水の消費量、日射、温度幅、収量の安定性 |
| 弱み | D: 永続性、非食用の価値。C: 耐寒性、病害虫圧、防除の自立度、貯蔵性、合成資材を投入しない場合の収量維持率、整地・掘削エネルギー |

> **ダイコンは、どれか1項目が突出して優れた作物ではなく、決定的に悪い項目が少ないために点数が高い作物です。**

&nbsp;&nbsp;&nbsp;面積当たりの熱量Bは、100gで21kcalと熱量密度は低くても1,000㎡当たり7,000kgがとれて1㎡当たり1,470kcal(自給ラインの0.56倍)になるという意味で、1株が1.3-1.6kgあるため、葉物より台所に入る重さが2倍以上になります。葉は根の重さの30-50%あり、別の食料です。連作への適応性SSは、農村振興庁が連作の害が出ない群に分類しているという意味であり、根こぶ病にかからないという意味ではありません。耐寒性Cは0℃で根が凍り、冬の畑に置いておけないという意味で、貯蔵性Cは貯蔵期間はBですが損失率8.94%のため1段階下がったという意味です。整地・掘削エネルギーCは、深さ22cmの深耕で1㎡当たり239kcalかかり、葉物の2倍以上になるという意味です。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | アブラナ科ダイコン属(Raphanus)の二年草。アブラナ属(Brassica)ではないため、ハクサイ、キャベツ、カラシナ、ケールとは自然状態で交雑しない |
| 花・実 | 白色または薄紫色の花。莢は太くてふくらんでおり、はじけにくく、種子が4-10個入っていて、若い莢は食べられる |
| 食用部位 | 上の3分の1ほどは茎の下部(胚軸)が太ったもので、下側が本当の根。上側のほうが甘くて硬く生のサラダに、下側は汁物や煮物に使う。葉も食料 |

&nbsp;&nbsp;&nbsp;播種後2週間までは発芽・幼苗期、2-6週は葉が増える栄養成長期、6-10週は根の肥大期、10-13週は成熟期で、その後に低温にあうと抽苔します。6週ごろを境に、根は長さの成長から太さの成長に移ります。まっすぐな根は最初の数日間に出会った土で形が決まるため、石や固い土や未熟な堆肥にあたると割れ、あとから管理しても元に戻せません。100g当たり熱量21kcal、タンパク質0.77g(熱量比14.7%)、糖類2.96g、ビタミンC 20-25mg、カルシウム23mgで、葉には根にほとんどないβ-カロテンがあり、カルシウムと鉄も根よりはるかに多く含まれます。消化を助けるアミラーゼ系の酵素は熱に弱いです。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 生育適温17-23℃、根の肥大適温21-23℃(低いと遅く、高いと葉だけが育ってス入りする)、発芽15-30℃。0℃で根の組織が凍って破壊される |
| 水・光 | 総蒸発散量は約500mm。強い光を好み、40%遮光で相対収量は約80%、日陰では葉だけが徒長する |
| 土壌 | 水はけのよい砂壌土-壌土、耕起の深さ20-30cm、畝の高さ15-20cm、pH 6.5-7.5(根こぶ病の抑制)。石灰がなければ、木灰を1㎡当たりひとつかみ強、播種の2週間前に入れるが、堆肥とは数日あける(同時に入れると堆肥の窒素がアンモニアとして逃げる) |

&nbsp;&nbsp;&nbsp;過湿が最大の危険です。水がたまると根が呼吸できず、軟腐病の細菌が広がって、数日で根がまるごと溶けて悪臭を放ちます。乾いたあとに急に多くの水を受けると皮が縦に割れて(裂根)貯蔵できなくなるため、水は量より均一に与え、排水をほかのあらゆる管理より先に整えます。

&nbsp;&nbsp;&nbsp;氷点下1℃前後の軽い霜はデンプンを糖に変えて甘みを上げますが、氷点下3-4℃以下の寒波は凍って細胞が破裂し、解けると軟らかくなって腐ります。秋ダイコンは11月中旬の最初の強い寒波の前に抜きます。ダイコンは種子や幼い苗のときにも低温(0-13℃)を感知するため、春に早くまきすぎると花茎が立ちます。

&nbsp;&nbsp;&nbsp;秋ダイコン(70-90日)が災害への備えの中心です。涼しい条件でゆっくり太るため組織が締まって糖が多く、穴の中で3-4か月もちます。春ダイコン(50-60日)は組織が軟らかく水分が多いため貯蔵に向かず、ヨルム(20-40日)とチョンガク大根(40-60日)は葉を食べる系統で、災害の初期にいちばん早く食べ物を出します。市販の種子の多くは一代雑種のため、採った種子では性質がばらつくので、災害が長引きそうな場合は固定種や在来種を確保します。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 整地 | 20-30cmの深さに耕し、石、木片、固い土の塊を取り除く。完熟堆肥を播種の2週間以上前に入れて深く混ぜる(未熟な堆肥が割れのもっとも多い原因) |
| 施肥(1,000㎡) | 窒素10-12kg、カリウム8-10kg、堆肥1,000-1,500kg。元肥は播種の1-2週間前、追肥は本葉3-4枚で窒素、6-7枚でカリウム。肥大期の窒素は葉だけを育てて組織を軟らかくするので、収穫の1か月前から止める |
| 災害時の代替肥料 | 完熟堆肥(1㎡当たり1-1.5kg)、木灰(カリウムの供給と酸度の矯正、毎年少しずつ)、尿の10-15倍希釈液(1回目の追肥のみ)、灰を1日浸してこした浸出液(肥大期のカリウム) |
| 作型 | 秋ダイコンは7月中旬-9月上旬に播種し、10月中旬-11月下旬に収穫し、初霜の70-90日前が適期(中部は8月中下旬、南部は9月初め)。遅れると太る前に寒さが来る。春ダイコンは3月中旬-4月下旬に播種し、5月中旬-7月上旬に収穫し、気温が20℃を超える前に終える。越冬ダイコンは9月下旬-10月に播種し、翌年の早春に収穫(南部、海岸) |
| 播種 | 必ず直まき(移植すると主根が折れて割れる)。深さ1-2cm、点まきで1穴1-2粒、条間60-70cm、最終の株間25-30cm(1,000㎡当たり8,000-9,000株) |
| 種子の処理 | 大きくふっくらした種子を選び、木灰をまぶして消毒・乾燥する。温湯浸漬(50-55℃で10-15分、60℃を超えると種子が死に、45℃未満では病原菌が生き残る)は、薬剤なしで種子伝染を断つもっとも確実な方法 |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 発芽-幼苗期 | 表土が乾かないように軽くこまめに(根が浅い) |
| 根の肥大期 | 均一に十分に(水分の変動が割れを生む)。収穫の2週間前から徐々に減らして組織を締める |
| 梅雨期 | 排水溝を確保する(過湿は干ばつより大きな危険) |

| 管理 | 方法 |
|:---|:---|
| マルチング | わらや枯れ草を株間に敷くと水分の振れ幅が小さくなり、割れを防ぐいちばん安上がりな手段 |
| 間引き | 本葉3-4枚で1穴1株にし、6-7枚で株間25-30cmに仕上げる。引き抜くと残す株の根が揺れて割れるので、はさみや爪で地際に近いところから切る。遅れると細いダイコンばかり何本も残り、間引いた若いダイコンはヨルムとして食べる |
| 除草、肩 | 最初の3-4週間が雑草との勝負で、葉が地面を覆えばほとんど不要。細根を切らないようにくわを深く入れない。根の上部が地上に出るのは正常で、多く露出したら軽く土をかぶせる |
| 葉の収穫 | 肥大が始まるまでは下のほうの古い葉を2-3枚だけ摘み、8枚以上は必ず残す。肥大期以降は摘まない |
| 水不足 | 昼に葉がしおれて夕方に回復するなら一時的。続くと根が細くなり辛みが強くなる |

## 6. 病害虫と養分の問題
&nbsp;&nbsp;&nbsp;病害虫圧と防除の自立度はどちらもC(無防除の推定減収率51.7%)です。主な問題が地中で起こって見えず、見えたときにはすでにその株を失っています。防除は事後の処理ではなく、排水、酸度、輪作、健全な種子という事前の条件であり、この4つが整っていなければ、そのあとにできることはほとんどありません。

| 病害虫 | 症状と条件 | 予防と対処 |
|:---|:---|:---|
| 軟腐病 | 根がどろどろに軟らかくなって悪臭がし、汁が隣の株に広がる(過湿、傷、窒素過多)。貯蔵中も進行する | 高い畝と排水溝、傷をつけない。病んだ株はすぐ抜いて遠くに捨てるか埋め、堆肥に入れない |
| 根こぶ病、センチュウ | 根にこぶができてしおれる(酸性土壌、アブラナ科の連作) / ビーズのような小さなこぶが並んでできる | 木灰でpH 6.5-7.0を保つ、アブラナ科以外の作物と輪作、マリーゴールドを混植する。連作への適応性がSSでも病原菌は蓄積する |
| べと病、うどんこ病 | 葉が黄色くなって裏にカビが生える(多湿) / 葉に白い粉がつく(乾燥と湿度の交互) | 間引きで風通しを確保し、病んだ葉を取り除く / 牛乳の10倍希釈液を晴れた日の朝に散布(曇りの日は牛乳が傷む)、重曹は水1Lに1g強(濃いと葉が傷む) |
| ウイルス病、黒腐病 | モザイク、縮れ(アブラムシが媒介) / 葉の縁がV字に枯れる(高温多湿、傷) | アブラムシを防ぎ、病んだ株は抜いて燃やす / 種子の温湯浸漬、病株の除去 |
| 害虫 | ノミハムシ(発芽直後-本葉3-4枚のときに致命的)、アブラムシ、コナガ・モンシロチョウの幼虫(葉を食べる)、コガネムシの幼虫・ネキリムシ(根を食べる) | 発芽直後に防虫ネット、木灰の散布 / 石けん水1Lに20gを葉の裏まで数日おきに、テントウムシを保護 / 手で捕る |

| 症状 | 原因と対処 |
|:---|:---|
| 葉の縁が茶色く枯れる | カリウム欠乏。木灰や灰の浸出液を与える |
| 根の中が黒または茶色(黒心) | ホウ素欠乏(有機物が少ない砂地、酸度が高い畑、干ばつの年)。堆肥を十分に入れ、木灰は入れすぎない(ホウ素が土に固定される) |
| 葉だけが茂って根が細い | 窒素過多(もっとも多い失敗の原因で、組織が軟らかく貯蔵中に腐る)。窒素を止めてカリウムを補う |
| 根が割れる、二股になる | 未熟な堆肥、石、固い土が原因なので、次の作期に畑の準備を改善する。中が空洞ならス入り(第8節) |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | サンチュ、ホウレンソウ(根の深さが違って競合が少なく、地面を覆う。サンチュは40-50日、ダイコンは70-90日なので同じ面積で2つの作物が得られる)、長ネギ、ニラ(においが害虫を惑わす)、マリーゴールド(センチュウを抑える) |
| 悪い | ハクサイ、カラシナ、キャベツなどのアブラナ科(病害虫を共有)、ニンジン、ゴボウなどほかの根菜(同じ深さを奪い合う) |

&nbsp;&nbsp;&nbsp;輪作は4年周期で、1年目はダイコンやハクサイなどのアブラナ科、2年目はマメ科(窒素固定)、3年目は葉菜類またはネギ類、4年目はトウモロコシやソルガムなどのイネ科(深い根で下層の養分を引き上げる)の順です。豆の直後にすぐダイコンを植えると窒素が多くて葉だけが茂ることがあるため、間にほかの作物を1回入れるか、豆の残渣を十分に腐熟させてから植えます。ダイコンは太い根が深く入り、抜いた跡に水と空気が通る穴を残すため、固い土を機械なしでほぐす目的で輪作の途中に入れることもあります。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 春ダイコンは気温が20℃を超える前に、秋ダイコンは11月中旬に氷点下3℃を下回る前に抜く。数日置いても太らずス入りするだけなので、肩の直径が品種の基準に達するか、外葉が垂れ始めたら抜く |
| 要領 | 晴れて乾いた日に葉をまとめて持ち、まっすぐ上に抜く(抜けなければくわで横を掘る)。投げたり落としたりしない(傷が軟腐病の入り口)。土だけを払い、水で洗わない。葉は付け根できれいに切って別に扱い、日陰で半日、表面の水気を飛ばす |
| ス入り | 根の中がスポンジのように空洞になり、味と貯蔵性が失われる現象。収穫適期の超過、抽苔、高温・乾燥、急な肥大(窒素過多、突然の降雨)、凍結後の解凍、葉の傷みで起こり、元には戻せないので、時期の管理がそのまま予防になる。ス入りしたダイコンは汁物や切り干しに使い、穴には入れない |

| 採種 | 基準 |
|:---|:---|
| 特性 | 二年草で自家不和合性のため、1株だけでは花が咲いても種がほとんどつかない。ハチと風が花粉を運ぶ他家受粉で、種子は常温密閉で5年もつ。道端や土手に自生する野生のダイコンの種も正常に発芽し、種子の供給が途絶えたときの保険になるが、根は細くて硬い |
| 方法 | 直まき採種は春にまいてその年に種を得るので速くて簡単だが、根を見て選べず、数年後には根が細くて硬くなる。根を選ぶ採種は秋に太くてまっすぐでス入りしていない根を選んで越冬させ、春に植え直す方法で、品質が保たれる。災害の初年は直まき採種で種子を確保し、余裕ができたら根を選ぶ採種で品質を守る |
| 交雑 | すべてのダイコン品種(秋ダイコン、春ダイコン、ヨルム、チョンガク大根、ハツカダイコン)と野生のダイコンは完全に交雑し、ハクサイ、キャベツ、カラシナとは交雑しない |
| 隔離、株数 | ほかのダイコンの開花株から500m以上(厳密には1km)離すか、1年に1品種だけ花を咲かせ、畑の周りの野生のダイコンは花が咲く前に刈り取る。採種株は最低10株、できれば20株以上(少ないと結実率が下がり、近交弱勢が出る)。網をかけるときは複数の株をいっしょに入れ、筆で花粉を移す |
| 手順 | 選んだ根を穴に埋めるか、葉を少し残して畑に植え直してわらをかぶせて越冬させ(11-2月)、2-3月に肩が少し出るように植え直す。3-4月に抽苔(支柱)、4-5月に開花、6-7月に莢が茶色く乾いて振ると音がしたら茎ごと刈り、日陰で1-2週間干して袋に入れ、たたくか踏む(莢がはじけにくく脱穀が大変) |

## 9. 貯蔵
&nbsp;&nbsp;&nbsp;貯蔵性Cは、貯蔵期間Bに損失率8.94%が反映された等級で、ダイコンは長くもちますが、貯蔵中に失う量も少なくありません。洗っていない健全なものだけを貯蔵し、傷があるもの、ス入りしたもの、軟腐病の兆しがあるものが1本あると、冬のあいだずっと隣のダイコンを傷めます。冬の食事は、ビタミンCを穴の中の生のダイコンと発酵食品から、熱量と量を乾燥品から得る2本立てで組みます。

| 方式 | 方法 | 期間 |
|:---|:---|:---|
| 穴貯蔵 | 水がたまらない場所に幅60cm、深さ75cmに掘り、乾いたわらか砂を敷いて、ダイコンを葉があったほうを下にして立てて入れる。わらを厚くかぶせ、土を2-3回に分けて40-60cmかぶせたあと、周りに溝を掘る。0-4℃、湿度85-95%。穴をいくつかに分け、開けたら必要な分だけ取り出して再び覆う | 3-4か月 |
| 埋設、室内 | 畑に寝かせて埋め、わらと土をかぶせる / 少し湿らせた砂に、ダイコン同士が触れないように埋める / 紙に1本ずつ包んで涼しい所に置く | 2-3か月 / 1-2か月 / 1-2か月 |
| 切り干し | 0.5-1cmに切り、日当たりと風通しのよい場所に重ならないように広げ、1日に1-2回裏返す(晴天で3-5日、曲げても折れずにしなる程度)。10kgが1kgに減るが、ビタミンCは大半が失われる | 6か月-1年以上 |
| 干し葉(シレギ) | 葉のしおれた部分と土を払い、洗わずに束ねて風通しのよい日陰に逆さにつるし、1-2か月干す。使うときは一晩戻して茹で、茹で汁を捨ててすすいだあと、ナムルや汁物に使う | 数か月 |
| トンチミ、漬物 | トンチミは丸ごとのダイコンを2-3%の塩水に漬けて発酵させる(汁ごと食べるのでビタミンCがかなり残る)、チャンジ式は10-15%の塩漬け(食べる前に水で塩抜き)、チャンアチは醤油やテンジャンに漬けたもの。材料が漬け汁の下に完全に沈み、塩分濃度が2%を下回らなければ、雑菌ではなく乳酸菌が育つ | 数か月-1年以上 |

## 10. 調理と注意事項
| 注意 | 内容 |
|:---|:---|
| 傷んだダイコン | 軟腐病にかかったダイコンは外見が無事でも中がどろどろに軟らかく、切ると悪臭がするので、食べずに捨てる。貯蔵中に1-2本ずつ確認して取り除く |
| ゴイトロゲン | グルコシノレートの分解物の一部が、甲状腺でのヨウ素の利用を妨げる。通常の量なら問題ないが、ヨウ素が不足した食事で生のものを大量に長く食べると危険なので、海藻がなくなった災害状況では加熱したものを混ぜる(加熱で減る) |
| そのほか | 生のダイコンを一度に大量に食べると胃が刺激されることがあり、窒素を多く与えたダイコンには硝酸塩がたまる。急性の毒性はなく、解毒の手順も不要 |

| 調理 | 方法 |
|:---|:---|
| 生 | 洗って切るだけでよく燃料がいらず、水分が多いので渇きにも役立つ。ビタミンCと食物繊維が皮のすぐ下に集中しているので、皮つきで使う。おろしたダイコンは消化酵素が生きており、ご飯、餅、イモといっしょに食べるとデンプンの消化を助ける |
| 加熱、加工 | 長く煮ると辛みが飛んで甘みが出るので、ダイコンと塩と水だけでも完結した汁物になる。干して戻して使うか発酵させて使い、花茎が立ったダイコンの若い莢はナムルやチャンアチにする |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 穴の中のダイコンを確認して傷んだものを選び出す、切り干しと干し葉の点検。2月に堆肥の切り返し、春ダイコンの畑の準備、採種株の越冬確認 |
| 3-4月 | 3月中旬から春ダイコンを播種し、越冬した採種株を植え直す。4月に春ダイコンの間引きと追肥、採種株の支柱立て |
| 5-6月 | 5月に春ダイコンの収穫開始、採種株の開花(隔離の管理)。6月に春ダイコンの収穫終了、夏に備えて畑を片づける |
| 7-8月 | 7月上旬に採種、中旬から秋ダイコンの畑の準備と播種。8月に播種を続け、発芽期のノミハムシに備え、1回目の間引き |
| 9-10月 | 9月に2回目の間引きと追肥、秋の長雨の排水管理、上旬までに播種を終える。10月に根の肥大期の管理、中旬から早どり開始 |
| 11-12月 | 11月中旬に本収穫、葉の整理、穴づくりと貯蔵、切り干しと干し葉の乾燥、キムジャン(作業が集中するので、播種を10日間隔で分けて収穫期を分散)。12月に貯蔵品の管理、トンチミとキムチの熟成確認、畑の片づけ |

> **ダイコンは、播種の時期(7月中旬-9月上旬)と収穫の時期(11月中旬、氷点下3℃の前)を守り、排水を最優先で整え、健全なものだけを貯蔵する作物です。**
