## 2. どんな植物か

### 2-1. 分類と原産地

| 項目 | 内容 |
|:---|:---|
| 学名 | Raphanus sativus |
| 分類 | Magnoliophyta Magnoliopsida / Brassicales / Brassicaceae / Raphanus |
| 生活型 | 二年生。条件によっては一年生のように、その年のうちに花が咲くこともあります |
| 原産地 | 地中海沿岸から中央アジアにかけての地域 |
| 食用部位 | 肥大した根と茎の下部、そして葉 |
| 属 | Raphanus。アブラナ属（Brassica）とは別の属です |

&nbsp;&nbsp;&nbsp;ダイコンがアブラナ属ではなくダイコン属（Raphanus）であるという事実は、実務上重要です。ハクサイ、キャベツ、カラシナ、ケールはいずれもアブラナ属なので、互いの交雑の可能性を考慮する必要がありますが、ダイコンは属が異なるため、これらと自然状態では交雑しません。ダイコンのそばでハクサイが花を咲かせても、ダイコンの種子は純粋なまま保たれます。その代わり、ダイコンは同じ属のほかのダイコン品種や、野生化したダイコンと自由に交雑します。この区別が、第13節の採種の核心です。

&nbsp;&nbsp;&nbsp;私たちが食べる白い部分は、純粋な根ではありません。上側の3分の1ほどは、胚軸と呼ばれる茎の下部が太くなったもので、下側が本当の根です。ダイコンを引き抜いてみると、上側には細根がなく、下側にだけ細根が列をなしてついていますが、その境目が茎と根の境目です。上側は地上に出て日光を受け、緑色を帯びることもあり、この部分は下側より甘くて固いのです。ダイコンを調理するとき、上側はセンチェ（生の和え物）やサラダに、下側は汁物や煮物に使う習慣には、このような組織の違いが背景にあります。

### 2-2. 形態

| 器官 | 特徴 |
|:---|:---|
| 葉 | 羽状に裂け、粗い鋸歯があります。根の上部から束になって出ます |
| 茎 | 普段はほとんどなく、花茎が立つと60-100cmまで伸びます |
| 根（食用部） | 円筒形から球形まで、品種によってさまざまです。白、赤、黒、緑 |
| 花 | 白または淡紫色。4枚の花弁をもつアブラナ科の典型です |
| 果実 | 角果（さや）。中に4-10個の種子が入っています |
| 種子 | アブラナ科にしては大きめで、種皮が固いです |

&nbsp;&nbsp;&nbsp;ダイコンのさやは、ほかのアブラナ科作物とは形が異なります。カラシナやハクサイのさやは細長く、熟すと縦にぱっくりと裂けて種子をこぼしますが、ダイコンのさやはふっくらとしてスポンジのような組織で満たされており、あまり裂けません。種子を取り出すには、砕くか叩く必要があります。この性質は、採種においては諸刃の剣です。畑で勝手にはじけて種子を失う危険が低い代わりに、脱穀に手間がかかります。

&nbsp;&nbsp;&nbsp;若いさやは食べられます。まだ青くて柔らかいうちに摘むと、シャキシャキして辛みのある味がし、ナムル（野菜の和え物）やチャンアチ（醤油漬け）にして使います。花茎が立って根が食べられなくなったダイコンを、完全には捨てなくてよい理由がここにあります。春先、貯蔵食品が底をつく時期に得られる資源です。

### 2-3. 生育段階

| 段階 | 時期（播種を起点） | 主な生理 | 多く使う養分 |
|:---|:---|:---|:---|
| 発芽・幼苗期 | 播種-2週 | 子葉が開き、直根が下に伸びます | リン、窒素 |
| 栄養生長期 | 2-6週 | 葉が増え、根が長さ方向に伸びます | 窒素 |
| 根の肥大期 | 6-10週 | 根が太くなり、糖分がたまります | カリウム |
| 成熟・収穫期 | 10-13週 | 根が充実し、貯蔵性が備わります | 灌水を減らします |
| 抽だい・開花期 | 低温感応後 | 花茎が立ち、根の養分が花茎へ流出します | リン、カリウム |

&nbsp;&nbsp;&nbsp;この表で決定的な転換点は、6週目ごろです。それまでダイコンは長さ方向に伸び、その後は太さ方向に育ちます。初期に葉を十分につくっておかないと、根を太らせる光合成能力が足りなくなり、逆に初期に窒素が多すぎると、葉ばかりが茂って根に養分が行きません。施肥を元肥と追肥に分け、追肥の性格を窒素からカリウムに切り替える理由は、この転換点にあります。

&nbsp;&nbsp;&nbsp;最も重要なのは、直根が初期に下へ伸びていくときの様子です。ダイコンの主根は種子から出たあと、まっすぐ垂直に下がっていきますが、この根の先端が石や固い土、未熟な堆肥の塊にぶつかると、その場で向きを変えたり裂けたりします。そして、その痕跡がそのまま収穫物の形になります。ダイコンが裂ける、曲がる、二股に分かれるといった奇形は、ほぼすべてこの時期に決まります。

> **ダイコンの形は、根が最初の数日間に出会った土の状態で決まります。あとからどれだけうまく管理しても、すでに裂けた根をまっすぐにすることはできません。畑を深く耕し、石を取り除く準備作業が、ダイコンでとりわけ重要な理由です。**

### 2-4. 100gあたりの栄養

| 成分 | 含有量（根、生） | 備考 |
|:---|:---:|:---|
| 熱量 | 21kcal | 品種と部位によって13-21kcal |
| 炭水化物 | 2.8-3.4g | |
| タンパク質 | 0.77g | 熱量に占める割合14.7% |
| 脂質 | 0.1-0.2g | |
| 糖類 | 2.96g | 葉菜類よりも明らかに高い |
| ビタミンC | 20-25mg | 冬場の主要な供給源 |
| カルシウム | 23mg | |
| リン | 34mg | |
| カリウム | 豊富 | |

&nbsp;&nbsp;&nbsp;ダイコンの根の栄養で最も価値があるのは、ビタミンCです。100gあたり20-25mgというのは葉菜類ほど高くはありませんが、ダイコンの強みは含有量ではなく貯蔵性です。室（むろ。土中に掘った貯蔵穴）に埋めたダイコンは、3、4か月が過ぎてもビタミンCをかなりの部分保ちます。ほかの野菜はその期間を持ちこたえられず、持ちこたえたとしても、干したりゆでたりする過程でビタミンCを失います。真冬にビタミンCを供給する経路が、ダイコンと発酵食品と、畑に生き残った葉菜類のいくつかだけであることを考えると、この項目の重みが変わってきます。

&nbsp;&nbsp;&nbsp;ダイコンの葉は、根とは異なる栄養構成をもっています。β-カロテンは根にはほとんどありませんが葉には多く、カルシウムと鉄も葉のほうがはるかに高い値です。食物繊維も葉に多く含まれます。根と葉をあわせて食べれば、栄養構成が一方に偏りません。ダイコンの葉を捨てることは、この作物が与えてくれるものの半分を捨てることです。

&nbsp;&nbsp;&nbsp;ダイコンの辛みと消化促進作用は、互いに異なる二つの成分によるものです。辛みはアブラナ科に共通するカラシ油配糖体が分解されて生じる物質で、消化を助けるのはアミラーゼ系の酵素です。この酵素はデンプンを分解するため、ご飯やトック（餅）と一緒に食べると消化が楽になります。ただし熱に弱く、加熱すると失われます。生のダイコンをおろして添える調理法は、この酵素を生かす方法です。

## 3. 栽培環境

### 3-1. 温度

| 区分 | 温度 | 説明 |
|:---|:---:|:---|
| 生育適温 | 17-23℃ | 葉と根がともによく育ちます |
| 根の肥大適温 | 21-23℃ | この範囲で太るスピードが最も速くなります |
| 生育可能範囲 | 15-27℃ | 幅12℃ |
| 発芽温度 | 15-30℃ | 40℃以上では発芽しません |
| 凍害限界 | 0℃ | 根の組織が凍って破壊されます |
| 抽だい誘導低温 | 0-13℃を一定期間 | その後、日が長くなると花茎が立ちます |

&nbsp;&nbsp;&nbsp;ダイコンの温度条件で最も幅が狭く厳しいのは、根の肥大適温です。21-23℃という狭い範囲です。これより低いと太るスピードが遅くなり、高いと葉ばかりが茂って根にスが入ります。秋ダイコンが災害時の基本作型である理由がここにあります。韓国では、8月末から9月初めに播種すると、初期の生育は暖かい条件で速く進み、根が太る頃には気温が20℃前後まで下がって、肥大適温にぴたりと当てはまります。自然の気温の曲線と作物の生理がかみ合う区間であり、これを人為的に作り出すことはできません。

&nbsp;&nbsp;&nbsp;抽だいの問題は、ダイコンでとりわけ厄介です。ダイコンは種子の状態や、ごく幼い幼苗の状態でも低温を感知します。春に早くまいたダイコンが、育つ途中で花茎を上げてしまうことがよくありますが、種子が土の中で低温にあったことが原因です。ケールやキャベツのように、ある程度育ってから初めて低温に反応する作物とは異なります。春の播種を早くしすぎてはいけない理由です。

| 状態 | ダイコンに起こること |
|:---|:---|
| 氷点下1℃前後の弱い霜 | 細胞が凍らないようにデンプンを糖に変えるため、甘みが増します |
| 氷点下3-4℃以下の寒波 | 細胞内の水が凍って体積が増え、組織が破裂します |
| 凍って解けたあと | 破裂した細胞から汁が漏れ出て、軟化して腐ります |

> **弱い霜は薬になり、強い寒波は毒になります。この境目がおよそ氷点下3℃であり、ダイコンの収穫時期の判断とは、結局のところこの線を越える前に引き抜くことです。**

### 3-2. 光

| 項目 | 基準 | 備考 |
|:---|:---|:---|
| 日照要求 | 強い光を好みます | 光飽和点が高い作物です |
| 半日陰への適応 | 限定的 | 40%遮光時のいも類（塊茎・塊根）・根菜の相対収量は約80% |
| 不足時の症状 | 葉だけが長く徒長し、根が太りません | |

&nbsp;&nbsp;&nbsp;ダイコンが葉菜類よりも多くの光を必要とするのは、貯蔵器官をつくらなければならないからです。葉菜類は光合成産物をそのまま葉にためておけばよいのですが、ダイコンは葉でつくったものを根に移して貯蔵しなければなりません。この過程には余分なエネルギーが必要です。光が足りないと、植物はまず葉を維持し、その次に余った分を根に送るため、日陰で育ったダイコンは葉ばかりが茂り、根は細くなります。

&nbsp;&nbsp;&nbsp;評価表の遮光時の相対収量80%は、葉菜類の86%より低い値です。実際の畑で場所を割り振るとき、この差を活用できます。日当たりのいちばん良い場所にはダイコンやジャガイモのような貯蔵器官をもつ作物をあて、建物や木の陰になる場所にはサンチュ（リーフレタス）やフダンソウのような葉菜類を置きます。同じ畑でも総収穫量が変わってきます。

### 3-3. 水と土壌

| 項目 | 基準 | 備考 |
|:---|:---|:---|
| 総蒸発散量 | 約500mm | 葉菜類より多い |
| 土壌水分 | 均一に保つ | 乾湿を繰り返すと裂けます |
| 過湿 | 最大の危険 | 軟腐病と根の奇形の直接の原因 |
| 土壌 | 排水のよい砂壌土から壌土 | 土層が深く水はけのよい土地 |
| 土壌酸度 | pH 6.5-7.5 | pH 6.5-6.8に矯正するのが無難です |
| 畝の高さ | 15-20cm | 湿害防止の要 |
| 深耕 | 20-30cm | 根がまっすぐ伸びる空間 |

&nbsp;&nbsp;&nbsp;ダイコンは、湿害に最も弱い作物のひとつです。理由は構造にあります。太い根は表面積に比べて体積が大きく、その中に水と糖がぎっしり詰まっています。土壌に水がたまって酸素がなくなると根は呼吸できなくなり、その状態で軟腐病の細菌が傷や皮を通って入り込むと、内側の糖を食べながら急速に広がります。数日で根が丸ごと溶けて水のようになり、悪臭を放ちます。

> **ダイコン栽培では、排水がほかのどの管理よりも先です。畝を高く立てて排水溝を保つこと、とりわけ韓国の9月の秋雨（秋のチャンマ）に備えることが、一年の農作業の成否を分けます。**

&nbsp;&nbsp;&nbsp;逆に、水が不足しても問題が起こります。ダイコンは水分が不足した期間を経たあとで急に多くの水を受けると、皮がその速さに追いつけず、縦に裂けます。裂根と呼ばれる現象です。裂けたダイコンは貯蔵できず、その裂け目から病気が入り込みます。したがってダイコンの水管理は、多く与えるか少なく与えるかではなく、均一に与えられるかどうかの問題です。わらや枯れ草によるマルチングが、この均一さをつくる最も安上がりな手段です。

&nbsp;&nbsp;&nbsp;土壌酸度はpH 6.5-7.5と、ほかのアブラナ科作物よりやや高めを目安にします。根こぶ病を抑えるためです。石灰がない状況では草木灰で代用しますが、草木灰はアルカリ性が強く効果も速いため、一度に多く入れません。㎡あたりひとつかみ強を播種の2週間前に入れ、土とよく混ぜます。ただし、草木灰と堆肥を同時に入れると、アルカリ性のために堆肥の窒素がアンモニアとなって逃げてしまうので、数日ずらして施すのがよいでしょう。

## 4. 品種

### 4-1. 系統別の特徴

| 系統 | 生育期間 | サイズ | 特徴 |
|:---|:---:|:---:|:---|
| 春ダイコン | 50-60日 | 1,200-1,600g | 抽だいに強くなるよう育成されています。貯蔵性は低いです |
| 夏ダイコン | 短い | 1,000-1,100g | 高温に耐えるようにつくられましたが、品質は劣ります |
| 秋ダイコン | 70-90日 | 1,300-1,400g | 貯蔵性が最も良く、糖度が高いです |
| 冬ダイコン・越冬ダイコン | 長い | さまざま | 耐寒性に優れ、韓国南部で越冬栽培ができます |
| 四季ダイコン | 中程度 | 中程度 | 周年栽培が可能ですが、どの季節でも最高にはなりません |
| ヨルム（若採りダイコン） | 20-40日 | 小さい | 葉を食べるための系統。根は細いです |
| チョンガクム（アルタリ。小型のダイコン） | 40-60日 | 小さい | 根と葉をともに食べます。キムチ用 |

&nbsp;&nbsp;&nbsp;この表で災害への備えの中心となるのは、秋ダイコン系統です。貯蔵性が決定的だからです。春ダイコンは早く育ちますが、組織が軟らかく水分が多いため、室に入れても長くは持ちません。秋ダイコンは涼しい条件でゆっくり太り、細胞壁が固くなり、糖がたまります。この違いが、貯蔵期間の数か月の差を生みます。

&nbsp;&nbsp;&nbsp;ヨルムとチョンガクムは、性格の異なる資源です。根ではなく葉を目的とする系統で、播種から収穫まで20-40日と極めて短くなっています。災害の初期、畑に何もないときに、いちばん早く食べものを出してくれる選択肢です。根菜としてのダイコンが70-90日待たなければならないのとは対照的です。畑の一角にヨルムをまいておき、主作物のダイコンが育つあいだに葉を食べるという配置が可能です。

### 4-2. 状況別の選択基準

| 状況 | 選択 | 理由 |
|:---|:---|:---|
| 災害初期、最短期の食料 | ヨルム、チョンガクム | 20-40日で葉と小さな根を収穫できます |
| 冬の備蓄の中心 | 秋ダイコン系統 | 室貯蔵で3-4か月。糖度が高いです |
| 春先の空白期を埋める | 春ダイコン系統 | 50-60日。ただし夏の前に必ず収穫します |
| 韓国南部での越冬 | 冬ダイコン・越冬ダイコン系統 | 耐寒性が相対的に強いです |
| ダイコンの葉とシレギ（干した大根葉）の確保 | 葉がよく茂る系統 | 葉の量が根と同じくらい重要です |
| 種子の確保を優先 | 在来種、固定種 | 種子を採っても性質が保たれます |

&nbsp;&nbsp;&nbsp;最後の行は、災害が長引くときに決定的に重要になります。市場に流通しているダイコンの種子の相当数は、一代雑種です。収量と均一性に優れますが、その種子を採ってもう一度植えると、性質がばらばらに分離してしまいます。災害が数年続く状況であれば、最初から固定種や在来種を確保しておくほうがよいでしょう。初年度の収量は少し落ちても、翌年から種子が自給できます。

&nbsp;&nbsp;&nbsp;複数の系統を混ぜて植えるのも、リスクを分散する方法です。秋ダイコンを中心に置きつつヨルムを少し添えると、収穫時期が分散し、どちらか一方が病気や気象の被害にあっても、すべてを失うことはありません。
