## 5. 畑の準備と肥料

### 5-1. 畑づくり

| 項目 | 方法 |
|:---|:---|
| 耕起 | 20-30cmの深さに耕し、土塊を砕いて均一に整地します |
| 石拾い | 根が届く深さの石や木片を取り除きます |
| 畝 | 高さ15-20cm。排水溝も一緒につくります |
| 土壌酸度 | pH 6.5-6.8に合わせます。酸性なら草木灰を使います |
| 有機物 | 完熟堆肥を播種の2週間以上前に入れ、深く混ぜ込みます |

&nbsp;&nbsp;&nbsp;ダイコンの畑の準備は、ほかの野菜よりも深く、念入りに行う必要があります。収穫物の形がここで決まるからです。根はまっすぐ30cm近く下りていかなければなりませんが、その道筋に石や固い土塊、未熟な堆肥の破片があると、根の先端が向きを変えたり二股に裂けたりします。裂けたダイコンは食べることはできても貯蔵が難しく、皮をむいて整えるのに手間がかかります。

> **未熟な堆肥は、ダイコンの根を裂けさせる最もありふれた原因です。分解が終わっていない有機物の塊が根の先端に触れると、その場で根が分かれます。堆肥は必ず完全に腐熟させ、播種の2週間以上前に入れます。**

&nbsp;&nbsp;&nbsp;深く耕す作業は力がいり、評価表の整地・掘削エネルギーCがその負担を反映しています。㎡あたり239kcalで、葉菜類の2倍を超えます。ただし、この労働はダイコンのためだけに使われて終わるわけではありません。一度深く耕した畑は次の作物にも有益で、とりわけダイコンが通ったあとは、太い根が抜けた穴のおかげで水と空気がよく通ります。ダイコンを輪作の途中に入れると、畑の物理性が改善される効果があります。

### 5-2. 施肥量

| 肥料 | 1,000㎡あたり | ㎡換算 | 施し方 |
|:---|:---:|:---:|:---|
| 窒素（N） | 10-12kg | 10-12g | 元肥に半量、追肥に半量 |
| リン酸（P） | 6-8kg | 6-8g | 全量を元肥 |
| カリウム（K） | 8-10kg | 8-10g | 元肥と追肥に分けて施用 |
| 堆肥 | 1,000-1,500kg | 1-1.5kg | 播種の2週間以上前 |
| 石灰 | 100-150kg | 100-150g | 酸性土壌の矯正用 |

| 区分 | 時期 | 性格 |
|:---|:---|:---|
| 元肥 | 播種の1-2週間前 | 堆肥、リン酸全量、カリウムの一部、窒素の半量 |
| 追肥1回目 | 本葉3-4枚 | 窒素中心。葉を増やして光合成能力を高めます |
| 追肥2回目 | 本葉6-7枚 | カリウム中心。根の肥大を助けます |

&nbsp;&nbsp;&nbsp;ダイコンの施肥で核心となるのは、追肥の性格が途中で切り替わる点です。1回目は窒素、2回目はカリウムです。この順序には生理的な理由があります。初期には葉を十分につくって光合成の工場を整える必要があり、その工場が稼働し始めたら、つくられた糖を根に運ばなければなりませんが、その移動にカリウムが関わります。カリウムは植物体内で糖の輸送を助ける元素であり、根菜やいも類（塊茎・塊根）で特に重視されるのはこのためです。

&nbsp;&nbsp;&nbsp;逆に、根の肥大期に窒素を多く与えると問題が起こります。植物は窒素が十分にあると葉をつくり続けようとし、根に送るべき糖を葉づくりに使ってしまいます。その結果は、葉ばかりが茂って根の細いダイコンです。しかも、窒素過剰で育ったダイコンは組織が軟らかく、貯蔵中に腐りやすくなります。収穫の1か月前からは窒素を与えないのが原則です。

### 5-3. 災害時の代替肥料

| 代替資源 | 供給する栄養素 | 使い方 | 注意 |
|:---|:---|:---|:---|
| 完熟堆肥 | 窒素・リン酸・カリウムと微量要素全般 | ㎡あたり1-1.5kgを元肥として深く混ぜ込みます | 未熟なものは根を裂けさせます |
| 草木灰 | カリウム、リン酸、カルシウム | ㎡あたりひとつかみ。酸度矯正とカリウム供給を兼ねます | 一度に多く入れるとアルカリ性に傾きます |
| 薄めた尿 | 窒素 | 水で10倍から15倍に薄め、株の間に注ぎます | 追肥1回目にのみ使います。肥大期には使いません |
| 骨粉 | リン酸、カルシウム | 堆肥に混ぜて元肥として入れます | 分解が遅いため、あらかじめ入れておく必要があります |
| 草木灰の浸出液 | カリウム | 灰を水に浸してこし、肥大期に与えます | 根の肥大期のカリウム供給に役立ちます |
| 落ち葉・草の腐葉土 | 有機物 | 畑に入れて物理性を改善します | 完全に腐熟したものだけを使います |

&nbsp;&nbsp;&nbsp;ダイコンで特に価値のある代替資源は、草木灰です。カリウムを供給すると同時にpHを引き上げて、根こぶ病を抑えるからです。ダイコンが求めるpH 6.5-7.5はアブラナ科作物の中でも高めで、石灰なしでこの酸度を維持するには、草木灰がほぼ唯一の手段です。ただし、草木灰は窒素をまったく供給しないので、堆肥や薄めた尿と役割を分担する必要があります。

&nbsp;&nbsp;&nbsp;カリウムを根の肥大期に供給する実用的な方法は、草木灰の浸出液です。草木灰を水に浸して1日ほど置き、上澄みをすくって株の間に注ぐと、カリウムがすぐに吸収されます。固形のまま散布するより効果が速く、アルカリ性が土全体を変えてしまう負担も少なくて済みます。

## 6. 播種と間引き

### 6-1. 作型

| 作型 | 播種時期（韓国） | 収穫時期（韓国） | 備考 |
|:---|:---|:---|:---|
| 春ダイコン | 3月中旬-4月下旬 | 5月中旬-7月上旬 | 高温になる前に必ず収穫します |
| 夏ダイコン | 5-6月 | 7-8月 | 標高の高い地域でのみ成り立ちます |
| 秋ダイコン | 7月中旬-9月上旬 | 10月中旬-11月下旬 | 災害への備えの中心となる作型 |
| 越冬ダイコン | 9月下旬-10月 | 翌年の早春 | 韓国南部と沿岸地域 |

&nbsp;&nbsp;&nbsp;四つの作型のうち、秋ダイコンが圧倒的に重要です。理由はいくつかあります。第一に、根が太る時期に気温が肥大適温の21-23℃まで下がってきます。第二に、育つあいだずっと気温が下がる方向なので、抽だいの圧力がありません。第三に、収穫物がそのまま貯蔵につながります。第四に、涼しい条件でゆっくり育ったダイコンは組織が固く糖が多いため、貯蔵性がよいのです。

&nbsp;&nbsp;&nbsp;春ダイコンは反対の条件で育ちます。気温が上がる方向なので、根が太る頃にはすでに適温を超えており、抽だいの圧力も高まり続けます。そのため、春ダイコンは小さくて軟らかく、スが入りやすいのです。春に播種する場合でも、目的は貯蔵ではなく、その時期に食べるものを得ることにあります。

> **播種の時期を逃すと、収穫そのものが失敗します。韓国では、秋ダイコンは7月中旬から9月上旬のあいだにまかなければならず、これより遅いと根が太る前に寒さが来ます。災害時において、時期は交渉の対象ではありません。**

&nbsp;&nbsp;&nbsp;韓国中部と韓国南部の時期の差は、おおよそ10日から15日です。韓国中部は8月中旬から下旬、韓国南部は9月初めが中心になります。判断の基準は、初霜の予想日から逆算して数えることです。初霜の70-90日前が播種の適期です。

### 6-2. 播種方法

| 項目 | 基準 | 備考 |
|:---|:---|:---|
| 播種深度 | 1-2cm | 深すぎると発芽が悪くなります |
| 播種方法 | 点まき。1穴あたり1-2粒 | 移植はしません |
| 条間 | 1条植え60-70cm、2条植え60cm | |
| 株間 | 25-30cm（最終） | 間引きで調整します |
| 目標株数 | 1,000㎡あたり8,000-9,000株 | |
| 覆土と鎮圧 | 細かい土をかぶせ、軽く押さえます | 種子と土が密着する必要があります |

&nbsp;&nbsp;&nbsp;ダイコンは必ず畑に直接まきます。苗を育てて移植してはいけません。理由は直根にあります。移植の過程で主根の先端が切れたり曲がったりすると、その部分から根が裂け、その痕跡がそのまま収穫物の形になります。ハクサイとキャベツは育苗して定植するのが常識ですが、ダイコンはその正反対です。

&nbsp;&nbsp;&nbsp;1穴に1、2粒だけ入れる点まきを勧めるのも、同じ理由からです。何粒も入れてあとで間引くと、残した株の根が間引きの過程で揺さぶられます。種子に余裕があるなら、3、4粒入れて発芽の失敗に備えてもかまいませんが、間引くときは引き抜かず、地際で切らなければなりません。

### 6-3. 種子処理

| 処理 | 手順 | 効果 |
|:---|:---|:---|
| 選別 | 大きくてふっくらし、色のそろった種子を選びます | 初期の勢いが良くなります |
| 温湯浸漬 | 50-55℃の湯に10-15分浸してから、冷水で冷まします | 種子の表面と内部の病原菌を殺します |
| 灰処理 | 種子に細かい草木灰をまぶします | 消毒と乾燥を兼ねます |

&nbsp;&nbsp;&nbsp;温湯浸漬は、薬剤がない状況で使える最も確実な種子消毒法です。種子自体は50-55℃に10-15分耐えますが、表面と内部の病原菌はその条件で死にます。60℃を超えると種子も死に、45℃を下回ると病原菌が生き残るため、温度が重要です。温度計がなければ、沸騰した湯と冷水をおおよそ1対1で混ぜ、手を入れたときに熱いけれど数秒は耐えられる程度を目安にします。処理後は冷水で冷まし、日陰で乾かします。

## 7. 水管理

### 7-1. 生育段階別の水

| 時期 | 管理 | 備考 |
|:---|:---|:---|
| 播種-発芽 | 表土が乾かないように保ちます | 発芽がそろわないと、株ごとに大きさが変わります |
| 幼苗期 | 軽く、こまめに | 根がまだ浅いためです |
| 根の肥大期 | 均一に、十分に | この時期の水分変動が裂根を招きます |
| 収穫2週間前 | 徐々に減らします | 組織が固くなり、貯蔵性が高まります |
| 韓国の梅雨（チャンマ、6月下旬～7月） | 排水溝を確保します | 過湿は干ばつより大きな危険です |

&nbsp;&nbsp;&nbsp;ダイコンの水管理で覚えておくべき原則はひとつです。絶対量よりも均一さです。乾いた期間が続いたあとで急に雨が降ると、根の内側が急速にふくらみますが、皮はその速さについていけず、縦に裂けます。これが裂根であり、裂けたダイコンは貯蔵できません。逆に、水がたまったままだと、酸素不足で根が腐ります。

&nbsp;&nbsp;&nbsp;均一さをつくる最も安上がりな手段は、マルチングです。わらや枯れ草を株の間に敷くと、雨が降るときには雨水がゆっくりしみ込み、乾くときには蒸発が抑えられて、土壌水分の振れ幅が小さくなります。ビニールがない状況では、この効果はとりわけ大きくなります。

### 7-2. 水が足りないとき、多すぎるとき

| 状態 | 症状 | 結果 |
|:---|:---|:---|
| 不足 | 葉が昼にしおれ、夕方に回復します | 一時的。まだ回復可能です |
| 不足 | 根が細くなり、辛みが強くなります | カラシ油配糖体が増えます |
| 不足後の灌水 | 根が縦に裂けます | 貯蔵ができなくなります |
| 過多 | 下の葉が黄色く変わります | 根の酸素不足 |
| 過多 | 根が軟化して悪臭がします | 軟腐病。その株は処分しなければなりません |
| 過多 | 根の表面に細根が増えます | 酸素を求めて伸びたものです |

&nbsp;&nbsp;&nbsp;軟腐病にかかったダイコンを見つけたら、すぐに畑から抜き取って、遠くに捨てるか埋めます。堆肥の山に入れてはいけません。この病気の細菌は土壌中で長く生き残り、次の作物にも引き継がれます。感染したダイコンから流れ出た汁が隣の株に触れると、そのままうつります。

## 8. 栽培管理

### 8-1. 間引き

| 回 | 時期 | 残す間隔 |
|:---|:---|:---|
| 1回目 | 本葉3-4枚 | 1穴あたり1株だけ残します |
| 2回目 | 本葉6-7枚 | 最終的に25-30cm間隔 |

&nbsp;&nbsp;&nbsp;間引きを適期に行わないと、ダイコンは太りません。隣の株と根がぶつかると育つ空間がなくなり、互いに押しのけ合って、結果として細いダイコンがたくさん残ります。同じ畑で株数は多くても、総重量はかえって減ります。

&nbsp;&nbsp;&nbsp;間引くときは引き抜かず、ハサミや爪で地際近くを切ります。引き抜くと、残そうとする株の根も一緒に揺さぶられて、その部分から根が裂けます。切り取れば、地中に残った根は腐って有機物になり、隣の株には影響がありません。

> **間引いた若いダイコンはヨルム（若採りダイコン）です。葉と小さな根をそのまま和え物やキムチに使います。ダイコン栽培での最初の収穫は、根を引き抜く日ではなく、間引く日です。**

### 8-2. 土寄せと肩の管理

&nbsp;&nbsp;&nbsp;ダイコンは育つにつれて、根の上部が地面の上に押し上げられてきます。これは正常な現象で、品種によって程度が異なります。露出した部分は日光を受けて緑色を帯びますが、味には問題がなく、むしろ甘みが強くなります。ただし、露出が多すぎると霜に直接当たって凍り、風に揺さぶられて細根が切れ、表面がざらざらになります。

| 状況 | 対処 |
|:---|:---|
| 肩が少し露出している | そのままにします。正常です |
| 肩が大きく露出している | 土を軽くかぶせます |
| 株が傾いている | 株元に土を寄せて立てます |
| 霜が頻繁に降りるようになった | わらや枯れ草で肩を覆います |

### 8-3. 雑草管理

| 時期 | 方法 | 備考 |
|:---|:---|:---|
| 生育初期 | 小さいうちに手で抜くか、浅く削ります | この時期が最も重要です |
| 間引きと同時 | 間引きながら周囲の草を取り除きます | 作業を兼ねられます |
| 葉が地面を覆ったあと | ほとんど必要ありません | 日陰が雑草を抑えます |

&nbsp;&nbsp;&nbsp;ダイコンは葉が大きく広がるため、いったん定着すれば、雑草を自力で抑え込みます。勝負は最初の3週から4週で決まります。この期間に雑草が先に場所を占めてしまうと、ダイコンは光と養分の競争に負けて、根が太りません。

&nbsp;&nbsp;&nbsp;除草のときは、手鍬を深く入れないように注意します。ダイコンの細根は地表近くに広く張っており、この細根が切れると、根の表面がざらざらになったり裂けたりします。草は株から遠いほうから浅く削り取り、株のすぐ隣の草は手で抜きます。

### 8-4. ダイコンの葉の摘み取り

&nbsp;&nbsp;&nbsp;根を引き抜く前に、下のほうの古い葉を数枚摘んで食べることができます。光合成能力が落ちた葉なので、根の肥大に大きな影響を与えません。ただし、一度に多く摘んではいけません。葉こそが工場であり、その工場がつくったものが根にたまるからです。

| 項目 | 基準 |
|:---|:---|
| 摘める葉 | 下から数えて、十分に育った葉2-3枚 |
| 残すべき葉 | 常に8枚以上 |
| 時期 | 根の肥大が始まる前までが安全です |
| 肥大期以降 | 摘みません。根の太さに直接影響します |
