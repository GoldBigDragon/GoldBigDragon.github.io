## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

| 项目 | 内容 |
|:---|:---|
| 学名 | Raphanus sativus |
| 分类 | Magnoliophyta Magnoliopsida / Brassicales / Brassicaceae / Raphanus |
| 生活型 | 二年生。视条件不同，也可能像一年生植物那样当年开花 |
| 原产地 | 从地中海沿岸到中亚的地区 |
| 可食部位 | 膨大的根和茎的下部，以及叶（萝卜缨） |
| 属 | Raphanus。与芸薹属（Brassica）不同属 |

&nbsp;&nbsp;&nbsp;萝卜不属于芸薹属，而属于萝卜属（Raphanus），这一点在实际操作中很重要。大白菜、结球甘蓝、芥菜、羽衣甘蓝都属于芸薹属，彼此之间需要考虑杂交的可能性，而萝卜属不同，在自然状态下不会与它们杂交。即使萝卜旁边的大白菜开花，萝卜的种子也能保持纯正。相反，萝卜会与同属的其他萝卜品种以及野生化的萝卜自由杂交。这一区分是第13节留种的关键。

&nbsp;&nbsp;&nbsp;我们食用的白色部分并不是单纯的根。上部约3分之1是被称为下胚轴的茎的下部膨大而成，下部才是真正的根。把萝卜拔出来看，上部没有须根，只有下部成排长着须根，这个分界线就是茎与根的分界线。上部露出地面，受阳光照射，有时会带绿色，这一部分比下部更甜、更硬实。烹调萝卜时，上部用来做生拌小菜（saengchae）或沙拉，下部用来煮汤或炖菜，这一习惯背后就有这种组织差异。

### 2-2. 形态

| 器官 | 特征 |
|:---|:---|
| 叶 | 呈羽状分裂，有粗锯齿。在根的上部簇生 |
| 茎 | 平时几乎不可见，抽薹后可长到60-100cm |
| 根（食用部分） | 从圆筒形到圆球形，因品种而异。有白色、红色、黑色、绿色 |
| 花 | 白色或淡紫色。具有十字花科典型的四片花瓣 |
| 果实 | 角果（荚果）。内含4-10粒种子 |
| 种子 | 在十字花科中算大的，种皮坚硬 |

&nbsp;&nbsp;&nbsp;萝卜的角果与其他十字花科作物的外形不同。芥菜或大白菜的角果细长，成熟后会沿纵向裂开，将种子散落出来；而萝卜的角果饱满，里面充满海绵状组织，不易开裂。要取出种子，需要捣碎或敲打。这一特性在留种时是一把双刃剑：在田里自行爆裂而损失种子的风险较低，但脱粒很费力。

&nbsp;&nbsp;&nbsp;嫩角果可以食用。趁尚青嫩时摘下，口感脆爽，带点辛辣味，可以做成凉拌野菜（namul）或酱菜。抽薹后根部不能吃的萝卜，也不必完全丢弃，原因就在这里。这是春季储备食品耗尽时期可以获得的资源。

### 2-3. 生长阶段

| 阶段 | 时期（以播种为起点） | 关键生理 | 需求较多的养分 |
|:---|:---|:---|:---|
| 发芽·幼苗期 | 播种-2周 | 子叶展开，直根向下扎入土中 | 磷、氮 |
| 营养生长期 | 2-6周 | 叶片增多，根在长度上生长 | 氮 |
| 根膨大期 | 6-10周 | 根变粗，糖分积累 | 钾 |
| 成熟·收获期 | 10-13周 | 根部充实，具备耐储性 | 减少灌水 |
| 抽薹·开花期 | 感受低温后 | 花茎抽出，根中的养分流向花茎 | 磷、钾 |

&nbsp;&nbsp;&nbsp;这张表中决定性的转折点在第6周前后。此前萝卜是在长度上生长，此后则在粗度上生长。如果早期没有长出足够的叶片，就缺乏使根变粗的光合作用能力；反过来，如果早期氮过多，就会只长叶子，养分到不了根部。把施肥分为基肥和追肥，并将追肥的性质由氮转为钾，原因就在于这个转折点。

&nbsp;&nbsp;&nbsp;最重要的是直根在早期向下扎入土中的方式。萝卜的主根自种子萌发后径直垂直向下生长，如果根尖碰到石块、板结的土壤或未腐熟的堆肥块，就会在那里改变方向或开裂。这种痕迹会原样变成收获物的形状。萝卜出现开裂、弯曲、分叉等畸形，几乎全都是在这一时期决定的。

> **萝卜的形状取决于根在最初几天里遇到的土壤状况。以后无论管理得多好，也无法让已经开裂的根变直。深耕田地、拣出石块的准备工作对萝卜格外重要，原因就在于此。**

### 2-4. 每100g的营养成分

| 成分 | 含量（根，生） | 备注 |
|:---|:---:|:---|
| 热量 | 21kcal | 因品种和部位不同为13-21kcal |
| 碳水化合物 | 2.8-3.4g | |
| 蛋白质 | 0.77g | 占热量的比例为14.7% |
| 脂肪 | 0.1-0.2g | |
| 糖类 | 2.96g | 明显高于叶菜类 |
| 维生素C | 20-25mg | 冬季的主要来源 |
| 钙 | 23mg | |
| 磷 | 34mg | |
| 钾 | 丰富 | |

&nbsp;&nbsp;&nbsp;萝卜根的营养中最有价值的是维生素C。每100g含20-25mg，虽然不及叶菜那么高，但萝卜的优势不在含量，而在耐储存。埋入地窖的萝卜，经过三四个月仍能保留相当一部分维生素C。其他蔬菜撑不过这么长的时间，即使撑过去了，在晒干或煮制的过程中也会损失维生素C。想到隆冬时节能提供维生素C的途径只有萝卜、发酵食品和田里存活下来的几种叶菜，就会明白这一项的分量有多重。

&nbsp;&nbsp;&nbsp;萝卜缨的营养构成与根不同。β-胡萝卜素在根中几乎没有，在叶中却很多，钙和铁也是叶中高得多。膳食纤维同样是叶中更多。根和叶一起吃，营养构成就不会偏向一边。丢掉萝卜缨，就等于丢掉了这种作物所给予的一半。

&nbsp;&nbsp;&nbsp;萝卜的辛辣味和助消化作用来自两种不同的成分。辛辣味是十字花科共有的芥子油苷分解后产生的物质，而帮助消化的是淀粉酶类的酶。这种酶能分解淀粉，所以与米饭或年糕一起吃，消化会更轻松。不过它怕热，煮熟后就会消失。把生萝卜擦成泥作为配菜的做法，正是保住这种酶的方式。

## 3. 栽培环境

### 3-1. 温度

| 类别 | 温度 | 说明 |
|:---|:---:|:---|
| 生长适温 | 17-23℃ | 叶和根都生长良好 |
| 根膨大适温 | 21-23℃ | 在这一范围内，变粗的速度最快 |
| 可生长范围 | 15-27℃ | 幅度12℃ |
| 发芽温度 | 15-30℃ | 40℃以上不发芽 |
| 冻害极限 | 0℃ | 根部组织冻结而遭到破坏 |
| 诱导抽薹的低温 | 0-13℃持续一定时间 | 此后随着日照时间变长就会抽薹 |

&nbsp;&nbsp;&nbsp;萝卜的温度条件中，最窄、最严格的是根膨大适温，只有21-23℃这一狭窄的区间。低于这个温度，变粗的速度就会变慢；高于这个温度，则只长叶子，根会糠心。这就是秋萝卜成为灾害情境下基本栽培类型的原因。在韩国，8月底到9月初播种，初期生长在温暖条件下很快，等到根开始变粗时，气温已降到20℃左右，正好落在膨大适温内。这是自然的气温曲线与作物生理相互吻合的区间，无法人为制造出来。

&nbsp;&nbsp;&nbsp;抽薹问题在萝卜上尤其棘手。萝卜在种子状态或非常幼小的幼苗状态下就能感受低温。春天播种过早的萝卜常常长到一半就抽薹，原因是种子在土壤中经历了低温。这与羽衣甘蓝、结球甘蓝等长到一定大小之后才对低温产生反应的作物不同。这就是春播不能过早的原因。

| 状态 | 萝卜发生的变化 |
|:---|:---|
| 零下1℃左右的轻霜 | 细胞为避免结冰，将淀粉转化为糖，甜味增加 |
| 零下3-4℃以下的寒潮 | 细胞内的水结冰，体积增大，组织胀破 |
| 冻结后解冻 | 破裂的细胞渗出汁液，变软并腐烂 |

> **轻霜是补药，严寒是毒药。这条界线大约在零下3℃，判断萝卜收获时机，归根结底就是要在越过这条线之前把萝卜拔出来。**

### 3-2. 光照

| 项目 | 标准 | 备注 |
|:---|:---|:---|
| 光照需求 | 喜强光 | 光饱和点高的作物 |
| 耐半阴程度 | 有限 | 40%遮光时薯类（块茎/块根）·根菜相对产量约80% |
| 不足时的症状 | 只有叶子徒长，根不膨大 | |

&nbsp;&nbsp;&nbsp;萝卜比叶菜需要更多光照，是因为它必须形成贮藏器官。叶菜可以把光合产物直接积存在叶子里，而萝卜则必须把叶子制造的物质转运到根中贮存。这个过程需要额外的能量。光照不足时，植物会先维持叶片，然后才把剩余的部分送往根部，所以在阴处生长的萝卜叶子茂盛而根很细。

&nbsp;&nbsp;&nbsp;评价表中遮光时的相对产量80%，低于叶菜的86%。在实际田地里安排位置时，可以利用这一差别。日照最好的位置留给萝卜、马铃薯这类贮藏器官作物，建筑物或树木投下阴影的位置则种生菜、莙荙菜这类叶菜。同样一块地，总收获量会因此不同。

### 3-3. 水分与土壤

| 项目 | 标准 | 备注 |
|:---|:---|:---|
| 总蒸散量 | 约500mm | 比叶菜多 |
| 土壤水分 | 保持均匀 | 反复干湿交替会开裂 |
| 过湿 | 最大的风险 | 软腐病和根畸形的直接原因 |
| 土壤 | 排水良好的砂壤土至壤土 | 土层深厚、排水通畅的土地 |
| 土壤酸碱度 | pH 6.5-7.5 | 调整到pH 6.5-6.8较为稳妥 |
| 垄高 | 15-20cm | 防止湿害的关键 |
| 深耕 | 20-30cm | 供根笔直向下生长的空间 |

&nbsp;&nbsp;&nbsp;萝卜是最容易受湿害影响的作物之一。原因在于其结构。粗大的根相对于表面积体积很大，里面充满了水和糖。土壤积水、缺氧后，根无法呼吸，此时软腐病细菌若经伤口或表皮侵入，就会以内部的糖为食迅速繁殖。几天之内，一根萝卜就会整个化成水，并散发恶臭。

> **种植萝卜时，排水比其他一切管理都更优先。把垄筑高、保持排水沟通畅，尤其是要防备韩国9月的秋季梅雨季，这决定了一年农事的成败。**

&nbsp;&nbsp;&nbsp;反过来，水分不足也会出问题。萝卜经历一段缺水期后，如果突然得到大量水分，表皮跟不上膨胀的速度，就会纵向开裂。这种现象称为裂根。开裂的萝卜无法贮藏，病菌会从裂缝侵入。因此萝卜的水分管理，问题不在于浇得多还是少，而在于浇得是否均匀。用稻草或干草覆盖，是实现这种均匀的最廉价手段。

&nbsp;&nbsp;&nbsp;土壤酸碱度以pH 6.5-7.5为宜，比其他十字花科作物略高一些。这是为了抑制根肿病。没有石灰时可用草木灰代替，但草木灰碱性强、见效快，不要一次施入过多。每㎡施一把多一点，在播种前2周施入并与土壤充分混匀。不过，草木灰和堆肥同时施入时，碱性会使堆肥中的氮以氨的形式挥发，所以最好错开几天。

## 4. 品种

### 4-1. 各类型的特点

| 类型 | 生长期 | 大小 | 特点 |
|:---|:---:|:---:|:---|
| 春萝卜 | 50-60天 | 1,200-1,600g | 经育种增强了抗抽薹能力。耐储性低 |
| 夏萝卜 | 短 | 1,000-1,100g | 培育成耐高温，但品质较差 |
| 秋萝卜 | 70-90天 | 1,300-1,400g | 耐储性最好，糖度高 |
| 冬萝卜·越冬萝卜 | 长 | 多样 | 耐寒性优良，可在韩国南部越冬栽培 |
| 四季萝卜 | 中等 | 中等 | 可全年栽培，但在哪个季节都不是最佳 |
| yeolmu（嫩叶小萝卜） | 20-40天 | 小 | 以吃叶为目的的类型，根细 |
| chonggakmu（altari，小型带缨萝卜） | 40-60天 | 小 | 根和叶一起吃。用于做韩式泡菜 |

&nbsp;&nbsp;&nbsp;在这张表中，灾害应对的核心是秋萝卜类型，因为耐储性具有决定性意义。春萝卜生长快，但组织松软、水分多，放进地窖也存放不久。秋萝卜在凉爽条件下慢慢变粗，细胞壁变得坚实，糖分不断积累。这一差别造成了贮藏期相差几个月。

&nbsp;&nbsp;&nbsp;yeolmu和chonggakmu是性质不同的资源。它们是以叶而不是根为目的的类型，从播种到收获只需20-40天，极为短暂。这是灾害初期田里一无所有时，能最早拿出食物的选项。这与作为根菜的萝卜需要等待70-90天形成对照。可以在田地一角撒播yeolmu，在主栽萝卜生长期间食用其叶子。

### 4-2. 不同情境下的选择标准

| 情境 | 选择 | 原因 |
|:---|:---|:---|
| 灾害初期，最短期食物 | yeolmu、chonggakmu | 20-40天就能收获叶和小根 |
| 冬季储备的核心 | 秋萝卜类型 | 窖藏3-4个月。糖度高 |
| 填补春季空档 | 春萝卜类型 | 50-60天。但必须在夏季之前收获 |
| 韩国南部越冬 | 冬萝卜·越冬萝卜类型 | 耐寒性相对较强 |
| 确保萝卜缨和干萝卜缨 | 叶片茂盛的类型 | 叶的产量与根同样重要 |
| 优先确保种子 | 地方品种、固定品种 | 留种后性状仍能保持 |

&nbsp;&nbsp;&nbsp;最后一行在灾害持续时间较长时会变得至关重要。市面上流通的萝卜种子，相当多数是一代杂种。产量和整齐度都很出色，但如果留下它的种子再种，性状会各不相同、发生分离。如果灾害要持续好几年，一开始就确保固定品种或地方品种更好。第一年的产量即使略低，从第二年起种子就能自给。

&nbsp;&nbsp;&nbsp;混种多个类型也是分散风险的办法。以秋萝卜为主，再搭配少量yeolmu，收获时间就会错开，即使其中一方遭遇病害或天气灾害，也不至于全部损失。
