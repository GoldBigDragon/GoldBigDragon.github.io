## 9. 病虫害 - 不用药的防治方法

&nbsp;&nbsp;&nbsp;萝卜的病虫害压力等级为C，无防治减产率估计为51.7%。防治自立度也是C，低于芥菜和羽衣甘蓝的B。原因是萝卜的主要病害大多发生在地下。叶子上的虫子看得见、抓得到，但使根变软的细菌、形成肿瘤的病原菌以及线虫是看不见的。等看见时，这一株已经没了。

> **萝卜的防治不是事后处理，而是事前条件。排水、酸碱度、轮作、健康种子，这四项如果不具备，之后几乎无事可做。**

### 9-1. 主要病害

| 病害 | 症状 | 发生条件 | 不用药的应对办法 |
|:---|:---|:---|:---|
| 软腐病 | 根变软腐烂，发出恶臭 | 过湿、排水不良、伤口 | 把垄筑高，确保排水沟畅通。病株立即扔到远处 |
| 霜霉病 | 叶片变黄，叶背长出霉层 | 湿度大、通风不良 | 通过间苗拉开间距，摘除病叶 |
| 根肿病（疣病） | 根上长出肿瘤，植株萎蔫 | 酸性土壤、十字花科连作 | 用草木灰把pH提高到接近7.0，并实行轮作 |
| 病毒病 | 叶片出现花叶斑纹并皱缩 | 由蚜虫传播 | 防治蚜虫，病株拔除后烧掉 |
| 白粉病 | 叶面覆盖白色粉末 | 干燥与潮湿交替出现时 | 保证通风和光照。喷洒稀释牛奶或小苏打溶液 |
| 黑腐病 | 叶缘呈V字形干枯 | 高温高湿、伤口 | 种子温汤浸种、清除病株 |

&nbsp;&nbsp;&nbsp;软腐病是萝卜最可怕的病害。致病细菌从伤口或自然裂隙侵入，分泌能溶解根组织细胞壁的酶。细胞壁一旦溶解，组织就整个烂成糊状，汁液流出，蔓延到旁边的植株。贮藏期间病害也会继续发展，所以只要往地窖里混进一个病萝卜，整个冬天都会持续受损。

&nbsp;&nbsp;&nbsp;预防方法有三条。第一，不让水积存。垄高15-20cm并保持排水沟畅通，这就是全部。第二，不要造成伤口。除草时用小锄刮伤根部，或收获时扔萝卜，这些伤口就成了入口。第三，不要过量施氮。氮过量长出来的萝卜组织松软、细胞壁薄，细菌容易穿透。

&nbsp;&nbsp;&nbsp;稀释牛奶对白粉病有效，是因为牛奶中的蛋白质和脂肪在叶面干燥后形成一层薄膜，在此过程中从物理上压制了霉菌的菌丝。把牛奶用水稀释约10倍，在晴天的早晨喷洒，让它在阳光下晾干。阴天喷洒的话，牛奶会变质，反而滋生杂菌。如果用小苏打，按每1L水加1g多一点的浓度调得淡一些，浓了会伤叶子。

### 9-2. 主要害虫

| 害虫 | 危害 | 不用药的防治 |
|:---|:---|:---|
| 蚜虫 | 在叶背吸取汁液并传播病毒 | 喷肥皂水、撒草木灰、保护瓢虫 |
| 跳甲 | 在幼叶上咬出像针刺一样的小孔 | 发芽后立即覆盖防虫网、草木灰、调整播种时间 |
| 小菜蛾 | 啃食叶片 | 防虫网、人工捕捉 |
| 菜粉蝶幼虫 | 在叶片上咬出大洞 | 搓掉叶背的黄色虫卵 |
| 根结线虫 | 根上成串长出小瘤，生长停止 | 轮作、用草木灰调节pH、与万寿菊间作 |
| 蛴螬·地老虎 | 啃食根和基部 | 翻地时捡出，夜间人工捕捉 |

&nbsp;&nbsp;&nbsp;跳甲是萝卜上最常见的早期害虫。它是循着十字花科植物的气味而来的黑色小昆虫，一碰就像跳蚤一样弹跳逃走。长成的植株即使叶子上有些孔洞也能撑住，但在子叶和第一片真叶阶段受害的话，就会直接死亡。在发芽后到长出三四片真叶期间覆盖防虫网最为有效，只要度过这个时期，受害就会大大减轻。

&nbsp;&nbsp;&nbsp;线虫是肉眼看不见的丝状小生物，侵入根部形成瘤，并在瘤里生活。如果说根肿病的瘤是又大又凹凸不平的肿块，线虫的瘤则是小小的、像珠子一样成串长出。在没有药剂的情况下，唯一的应对办法是轮作，也就是连续几年种植线虫不能取食的作物，把它们饿死。万寿菊这类植物据说会从根部分泌抑制线虫的物质，种在田边或株间会有帮助。

### 9-3. 天然防治剂

| 防治剂 | 配制方法 | 对象 |
|:---|:---|:---|
| 肥皂水 | 把20g无香味的肥皂溶于1L水 | 蚜虫、叶螨 |
| 草木灰液 | 把草木灰泡在水里放置24小时，过滤后使用 | 蚜虫、蝽象 |
| 撒草木灰 | 趁早晨有露水时，把过筛的细灰撒在叶上 | 驱避跳甲、补充钾 |
| 木醋液 | 稀释300-500倍后喷雾 | 驱避作用、抑制病害 |
| 稀释牛奶 | 把牛奶用水稀释10倍，在晴天早晨喷洒 | 白粉病 |
| 小苏打溶液 | 每1L水加1g多一点 | 白粉病 |

&nbsp;&nbsp;&nbsp;肥皂水对蚜虫起作用的原理不是毒性，而是物理作用。表面活性成分会溶解蚜虫体表的蜡质层，并堵住呼吸孔。只有直接接触到的个体会死亡，没有残效，所以要连叶背都仔细喷湿，并每隔几天重复一次。浓度提高的话，萝卜的叶子也会受伤，所以要守住每1L用20g这条线。

### 9-4. 农业防治原则

| 原则 | 内容 |
|:---|:---|
| 排水 | 把垄筑高，保持排水沟畅通。这在萝卜上最为重要 |
| 酸碱度 | 用草木灰把pH维持在6.5-7.0，抑制根肿病 |
| 轮作 | 在中间安排非十字花科的作物，尤其是豆科 |
| 健康种子 | 通过温汤浸种切断种子传病 |
| 通风 | 通过间苗保证株间距离 |
| 残体处理 | 病根和病叶不要放进堆肥，而要烧掉或埋到远处 |
| 时间调整 | 避开害虫发生高峰期播种 |

&nbsp;&nbsp;&nbsp;评价表中的连作适应性为SS，因此很容易理解成萝卜可以连续种植。然而这个等级指的是萝卜自身相对的抗性，并不意味着病原菌不会积累。如果田里已经有了根肿病和线虫，萝卜最终也会遭殃。田地有余裕的话，在中间安排豆科的轮作仍然是最佳选择。

## 10. 营养缺乏与过量

| 症状 | 原因 | 用天然材料采取的措施 |
|:---|:---|:---|
| 整个叶片变黄，植株矮小 | 缺氮 | 把腐熟堆肥施在植株之间，或把尿液稀释10-15倍后浇施 |
| 叶缘变褐干枯 | 缺钾 | 撒草木灰或浇草木灰浸出液 |
| 生长不良，叶片带紫色 | 缺磷 | 施入骨粉或草木灰。地温低时也会出现同样症状 |
| 叶脉之间变黄 | 缺镁 | 增加堆肥 |
| 根内部变黑 | 缺硼 | 充分施入有机物，并避免pH过高 |
| 根不粗，只长叶子 | 氮过量 | 停止供氮，补充钾 |
| 根开裂或分叉 | 未腐熟的堆肥、石块、板结的土 | 不是营养问题。下一茬改善整地 |
| 根内部出现空洞 | 糠心 | 在第12节中说明 |

&nbsp;&nbsp;&nbsp;缺硼是萝卜上特征性的问题。表面看起来完好的萝卜切开后，内部发黑或变成褐色，这种症状称为黑心病。硼是植物只需要极少量的微量元素，但它参与细胞壁的形成，缺乏时组织就会崩坏。在有机物不足的沙地、pH过高的田块以及干旱严重的年份，这种症状容易出现。应对办法是充分施入堆肥。充分腐熟的堆肥中含有各种微量元素。

&nbsp;&nbsp;&nbsp;草木灰施得过多，pH升得过高，反而会使硼等微量元素被土壤固定，根无法吸收。也就是说，提高pH与供给微量元素可能相互冲突，所以草木灰的原则是不要一次施很多，而要每年少量施入。

&nbsp;&nbsp;&nbsp;氮过量是萝卜最常见的失败原因。往田里施的肥越多似乎越好，但萝卜恰恰相反。氮充足时，植物会不断长叶，不把糖输往根部。叶子繁茂、颜色浓绿，拔出来一看，根却只有手指那么粗。而且，在氮多的条件下长大的萝卜组织松软，贮藏中容易腐烂。

## 11. 间作与轮作

| 搭配 | 对象 | 效果 |
|:---:|:---|:---|
| 好 | 豆科作物（豌豆、菜豆、豇豆） | 固氮并留在土中 |
| 好 | 生菜、菠菜 | 根的深度不同，竞争少，并能覆盖地面 |
| 好 | 大葱、韭菜 | 气味会扰乱害虫 |
| 好 | 万寿菊 | 抑制根结线虫 |
| 差 | 大白菜、芥菜、结球甘蓝等十字花科 | 共有相同的病虫害 |
| 差 | 胡萝卜、牛蒡等其他根菜 | 争夺同一深度 |

&nbsp;&nbsp;&nbsp;把生菜和萝卜混种，在空间利用上尤其高效。生菜根浅，在近地表处铺展，40-50天就收完；萝卜根往深处扎，要70-90天。萝卜的叶子还小的时候，生菜在其间生长，覆盖地面，抑制杂草；等到收生菜的时候，萝卜已经长大占据了位置。同样的面积能收获两种作物。

| 轮作顺序示例 | 年次 | 作物 | 田里发生的变化 |
|:---|:---:|:---|:---|
| 4年周期 | 第1年 | 萝卜、大白菜等十字花科 | 消耗大量氮，并翻动深层土壤 |
| | 第2年 | 豆科（大豆、豌豆、豇豆） | 氮被固定并积累 |
| | 第3年 | 生菜、莙荙菜等叶菜类，或洋葱类 | 利用浅层养分 |
| | 第4年 | 玉米、高粱等禾本科 | 用深根把下层养分提上来 |
| | 再回到第1年 | 萝卜 | 在病原菌密度降低的状态下重新开始 |

&nbsp;&nbsp;&nbsp;萝卜在轮作中起着特殊的作用，因为它粗大的根深深扎下，会从物理上翻动土壤。把萝卜拔出后，原处会留下一个纵向的长孔，水和空气会通过这个孔进入下层。种萝卜或芜菁来在没有机械的情况下疏松板结的土地，这种技术自古就在使用。如果不收获，让它直接在土里腐烂，那个位置就会成为富含有机物的通道。

&nbsp;&nbsp;&nbsp;把豆科安排在萝卜之前尤其有利。萝卜是用氮不少的作物，而豆科会固定空气中的氮并留在土壤中。不过，收完豆子后马上种萝卜的话，氮可能过多，导致只长叶子，所以最好在中间插入一茬别的作物，或者等豆子的残体充分腐熟之后再种。

## 12. 收获 - 糠心与时机问题

### 12-1. 收获时间

| 栽培类型 | 判断标准 | 备注 |
|:---|:---|:---|
| 春萝卜 | 气温超过20℃之前 | 遇到高温就会抽薹并糠心 |
| 秋萝卜 | 在韩国为11月中旬，第一次强寒潮之前 | 在降到零下3度以下之前拔出 |
| 大小标准 | 根肩直径达到品种标准时 | 再留着也不会变粗，只会糠心 |
| 叶片状态 | 外叶开始下垂时 | 是成熟的信号 |

&nbsp;&nbsp;&nbsp;萝卜收获时，判断上的分歧点在于是再留几天让它长粗，还是现在就拔。答案通常是现在就拔。萝卜过了某个时点就不会再变粗，反而开始在内部糠心。在萝卜上，因为几天的贪心而毁掉一年储备粮的事情很常见。

### 12-2. 糠心为什么会发生

&nbsp;&nbsp;&nbsp;糠心是萝卜内部像海绵一样出现空洞的现象，也称为空洞现象。表面看起来完好的萝卜切开后，内部干松发糠，有白色孔洞，就是糠心了。这样的萝卜不好吃，也无法贮藏。

&nbsp;&nbsp;&nbsp;原因不止一个，但有共同的机制：细胞膨大变大的速度，超过了填充细胞内部的内容物的供应速度。只是外壳变大而里面空了，细胞壁就承受不住而破裂，成为空洞。

| 原因 | 发生机制 |
|:---|:---|
| 超过适宜收获期 | 膨大结束后，根仍不断吸水，细胞被拉长 |
| 抽薹 | 花茎抽出后，根中储存的糖和养分转移到花茎，内部变空 |
| 高温与干燥 | 呼吸消耗的量超过光合作用补充的量 |
| 急剧膨大 | 氮过多或突然降雨，导致长得过快 |
| 低温冻害后解冻 | 结冰的细胞在解冻时破裂，留下空洞 |
| 叶片受损 | 叶片因病虫受害，糖的供应就会中断 |

> **糠心的本质，是根不再充当贮藏库的信号。萝卜正在为次年开花而积攒养分，一旦判断这个计划结束，就会停止贮藏，把内容物转移到别处。人可以吃的东西，只存在于这段时间之内。**

&nbsp;&nbsp;&nbsp;因此，防止糠心的办法实际上就是把握时机：及时拔出，选择不会引发抽薹的栽培类型，不过量施氮，保持水分均匀，保护好叶片的健康。已经糠心的萝卜无法恢复原状。

&nbsp;&nbsp;&nbsp;糠心的萝卜也不必全部丢弃。生吃虽然发柴，但用来熬汤或晒干还是可以用的。切成萝卜干晒制，反而因为水分少而干得更快。不过不能放进地窖贮藏。空洞里腐败进展很快，还会连累旁边完好的萝卜一起变坏。

### 12-3. 收获要领

| 项目 | 要领 |
|:---|:---|
| 天气 | 晴朗干燥的日子。避开刚下过雨的时候 |
| 拔法 | 把叶子拢在一起握住，笔直向上拔。拔不动时用小锄把旁边的土刨开 |
| 伤口 | 不要扔或摔落。伤口会成为软腐病的入口 |
| 泥土 | 抖掉，但不用水洗 |
| 萝卜缨处理 | 在根与叶交接的部位切下，另行处理 |
| 预晾 | 在阴凉处放半天左右，让表面水分散去 |

&nbsp;&nbsp;&nbsp;不洗是贮藏的基本要求。带着泥土的状态反而能保住表面的水分，并盖住伤口。用水一洗，表面的薄薄一层保护层就被洗掉，潮湿的地方会滋生霉菌和细菌。原则是在吃之前才洗。

&nbsp;&nbsp;&nbsp;切萝卜缨时，不要在根的一侧留下一点肉，而应在叶子着生的部位干净利落地切下。如果留有叶柄，这部分会先腐烂并蔓延到根上。反过来，如果切得太深，露出根的内部果肉，那个切面会在干燥时开裂，或者病菌从那里侵入。
