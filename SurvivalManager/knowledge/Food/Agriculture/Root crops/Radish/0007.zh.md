## 15. 无冰箱贮藏 - 地窖与干燥

&nbsp;&nbsp;&nbsp;萝卜的耐储性等级为C，贮藏期本身被评为B。窖藏可存放3-4个月，切成薄片晒干则可以存放一年以上。在没有电力和冷藏的条件下，能放这么久的蔬菜并不多。把萝卜列为灾害应对作物的理由，有一半就在这一项上。

### 15-1. 窖藏

| 项目 | 标准 |
|:---|:---|
| 温度 | 0-4℃ |
| 湿度 | 85-95% |
| 坑 | 宽60cm，深75cm左右 |
| 放入方法 | 把萝卜竖着放，让原来长叶子的一端朝下 |
| 覆盖顺序 | 先盖稻草，再在上面分2-3次盖40-60cm的土 |
| 期限 | 3-4个月 |

&nbsp;&nbsp;&nbsp;窖藏的原理是借助土地缓冲温度的能力。地表的温度随昼夜和季节大幅升降，越往深处波动越小，1m以下全年几乎恒定。把坑挖75cm深，再在上面盖40-60cm的土，萝卜所处的位置整个冬天都保持在0℃到4℃之间。这是既不冻结、又不发芽的条件。

&nbsp;&nbsp;&nbsp;湿度85-95%这个条件也很重要。萝卜是含水量94%的蔬菜，放在干燥的地方，水分会很快散失，变得皱缩、发糠。土里湿度保持得高，所以这个问题自然就解决了。反过来，积水会导致腐烂，所以坑一定要挖在排水良好的位置。坡地上部或排水好的沙地比较好，应避开稻田底部或积水的低洼地。

| 步骤 | 方法 |
|:---|:---|
| 选位置 | 不积水、排水良好的地方 |
| 挖坑 | 宽60cm，深75cm |
| 底部 | 铺干稻草或干沙 |
| 放入 | 把萝卜竖着整齐码放。有伤或糠心的不放入 |
| 覆盖 | 厚厚地盖一层稻草，土分2-3次盖上 |
| 标记 | 标出位置，并在周围挖排水沟，避免水流进来 |
| 取出 | 每次只取需要的量，再盖好 |

> **放进窖里的萝卜，一定要只挑完好的。有伤、糠心或有软腐病迹象的一个萝卜，就会在整个冬天里把旁边的萝卜都弄坏。挑选的工作比埋藏更重要。**

&nbsp;&nbsp;&nbsp;把窖分成几个，比只做一个大的更安全。因为每次打开，温度和湿度都会被扰乱。按每个月的量分开埋藏，用完一个窖之后再开下一个。

### 15-2. 土中埋藏与室内保管

| 方法 | 条件 | 期限 |
|:---|:---|:---|
| 就地埋在田里 | 把挖出的萝卜在田边平放埋好，盖上稻草和土 | 2-3个月 |
| 沙埋 | 在箱子或坛子里，一层干沙一层萝卜地码放 | 1-2个月 |
| 用报纸·纸包裹 | 逐个包好，放在阴凉黑暗的地方 | 1-2个月 |
| 带泥放进仓房 | 不洗，竖放在阴凉的仓房里 | 3-4周 |

&nbsp;&nbsp;&nbsp;沙埋是在无法挖窖的情况下使用的方法。沙子填满萝卜之间的空隙，减少与空气的接触，并保持湿度。太干的沙子会抢走萝卜的水分，所以稍微有点潮湿最好；只要让萝卜之间互不接触，即使有一个坏了，也不会蔓延到旁边。

### 15-3. 萝卜干

| 步骤 | 方法 |
|:---|:---|
| 切 | 切成粗0.5-1cm的条状或薄片 |
| 晾晒 | 在阳光充足、通风的地方摊开，不要重叠 |
| 翻面 | 每天翻一两次，使其干得均匀 |
| 时间 | 以晴天计，3-5天 |
| 成品 | 用手弯折时不断、能弯曲的程度 |
| 保管 | 放入密封容器，同时放入木炭或炒过的米 |
| 保存期限 | 6个月到1年以上 |

&nbsp;&nbsp;&nbsp;萝卜干是萝卜各种贮藏方法中最可靠、体积最小的一种。含水量94%的萝卜晒干后，重量会降到10%以下。10kg的萝卜变成1kg，一个坛子就装得下。窖藏只有3-4个月，而晒干的可以存放一年以上，所以能从冬天一直吃到春夏的粮食，归根结底还是晒干的那一种。

&nbsp;&nbsp;&nbsp;不过，晒干的过程中，维生素C大部分会消失。留下的是膳食纤维、矿物质和糖。因此冬季的饮食要分成两路安排。维生素C从窖藏的生萝卜和发酵食品中获得，热量和体积则从晒干的萝卜中获得。只靠其中任何一方，都很难过冬。

&nbsp;&nbsp;&nbsp;晾晒时的关键是摊开，不要重叠。重叠的部分晒不干，会在那个位置长霉。夜里要收回来或盖上，避免沾上露水。

### 15-4. 萝卜缨与干萝卜缨

| 步骤 | 方法 |
|:---|:---|
| 处理 | 抖掉枯叶和泥土。不洗 |
| 焯水（可选） | 在沸水里稍微焯一下，再用冷水冲洗，颜色好看，也更柔软 |
| 晾晒 | 把几根扎成一束，倒挂在屋檐下或阴凉处 |
| 条件 | 通风且直射阳光不强的地方 |
| 时间 | 一个月到两个月 |
| 保管 | 完全干透后，装进袋子或箱子，放在阴凉处 |
| 食用 | 煮后用水浸泡，剥去外皮，做成凉拌野菜（namul）或汤 |

&nbsp;&nbsp;&nbsp;干萝卜缨是晒干的萝卜缨。这是把拔萝卜时一起带出来的叶子不扔掉、变成冬季粮食的办法，能使一棵萝卜所提供的东西翻一倍。萝卜缨的营养构成与根不同。它含有根里几乎没有的β-胡萝卜素，以及比根多得多的钙、铁和膳食纤维。

&nbsp;&nbsp;&nbsp;晒干的干萝卜缨直接吃太韧，不能吃。要先用水泡一夜再煮，煮过的水倒掉，再冲洗一遍。这样韧的纤维会变软，涩味也会去掉。外皮厚的茎，用手剥掉后会柔软得多。由于有用到燃料的工序，所以放在煮其他东西的火上一起煮，效率更高。

### 15-5. 韩式泡菜与腌菜

| 方式 | 盐浓度 | 时间 | 特点 |
|:---|:---:|:---|:---|
| 萝卜水泡菜（dongchimi） | 2-3%盐水 | 几个月 | 连汤汁一起吃。保留相当多的维生素C |
| 萝卜块泡菜（kkakdugi）·带缨小萝卜泡菜（chonggak-gimchi） | 腌后加调料 | 几个月 | 发酵使耐储性和消化性变好 |
| 咸萝卜腌菜（jjanji）式盐渍 | 10-15% | 1年以上 | 吃之前必须用水泡去咸味 |
| 酱菜 | 泡进酱油或大酱里 | 几个月 | 咸味小菜。兼具补充盐分的作用 |

&nbsp;&nbsp;&nbsp;dongchimi是在灾害情境下特别有价值的贮藏方法。把整个萝卜泡在盐水里，在低温下缓慢发酵，几乎不需要调料，只要有盐和水就能腌。乳酸菌生长时产生的酸可以抑制杂菌，这个过程中维生素C得以大量保存。连汤汁一起吃，所以损失少。冬天没有新鲜蔬菜时，这类发酵食品在历史上之所以能预防坏血病，原因就在于此。

> **乳酸发酵的条件有两个。材料要完全浸没在汤汁之下，并且盐浓度不能降到2%以下。只要这两个条件得到遵守，生长的就是乳酸菌而不是杂菌。**

## 16. 烹饪与加工

| 方法 | 燃料 | 维生素C保存 | 备注 |
|:---|:---:|:---:|:---|
| 凉拌生萝卜、萝卜丝 | 无 | 最大 | 消化酶也保持活性 |
| 用擦板擦成泥 | 无 | 最大 | 帮助淀粉消化 |
| 汤 | 与其他烹饪合并 | 连汤一起吃则保留 | 萝卜最常见的用法 |
| 炖煮 | 中等 | 低 | 久煮会出甜味 |
| 发酵（dongchimi、韩式泡菜） | 无 | 保留相当多 | 兼具贮藏与烹饪 |
| 晒干备用，泡发后使用 | 晒干时靠阳光和风 | 几乎没有 | 矿物质和膳食纤维保留 |

&nbsp;&nbsp;&nbsp;在燃料珍贵的情况下，萝卜的一大优点是不用煮熟也能吃。洗净切开就行，水分多，还可以代替水。口渴而饮用水不足的时候，一片生萝卜确实有帮助。

&nbsp;&nbsp;&nbsp;擦成泥吃萝卜的做法有生理学依据。萝卜中所含的淀粉酶类酶会分解淀粉，所以和米饭、年糕或马铃薯一起吃，消化会轻松。这种酶怕热，煮熟就消失了，要擦成泥、破坏细胞才会释放出来。在以谷物为主的饮食里，胃胀时配上生萝卜的习惯，就是由此而来。

&nbsp;&nbsp;&nbsp;萝卜久煮后，辛辣味消失，出现甜味。这是因为辛辣成分芥子油苷的分解产物挥发后，剩下的糖显现出来。所以萝卜适合用来做汤底。即使汤里没有其他材料，只放萝卜，汤里也会有甜味和鲜味。只用盐、水和萝卜煮的汤，在灾害情境下也能成为一道完整的食物，原因就在于此。

&nbsp;&nbsp;&nbsp;不需要去皮这一点也值得记住。萝卜皮下面紧挨着的部分集中了维生素C和膳食纤维，洗净后连皮一起用，营养上更有利，处理时间也能缩短。

## 17. 全年作业日程

| 月份（以韩国气候为准） | 作业 |
|:---|:---|
| 1月 | 检查窖里萝卜的状态。挑出腐烂的。检查萝卜干和干萝卜缨 |
| 2月 | 翻堆堆肥。准备春萝卜的田地。确认留种株越冬情况 |
| 3月 | 从中旬开始播春萝卜。把越冬的留种株重新种下 |
| 4月 | 春萝卜间苗和追肥。留种株抽薹，立支柱 |
| 5月 | 春萝卜开始收获。留种株开花，做好隔离管理 |
| 6月 | 春萝卜收获完毕。留种株结角。为应对夏季整理田地 |
| 7月 | 上旬留种。中旬开始整备秋萝卜田地并播种 |
| 8月 | 继续播种秋萝卜。发芽期防备跳甲。第一次间苗 |
| 9月 | 第二次间苗和追肥。做好秋季连阴雨的排水管理。上旬前完成播种 |
| 10月 | 管理根部膨大期。中旬开始早收 |
| 11月 | 中旬主收获。越冬泡菜腌制（kimjang）。建窖与贮藏。晾晒萝卜干和干萝卜缨 |
| 12月 | 管理贮藏品。检查dongchimi和韩式泡菜的熟成。整理田地 |

&nbsp;&nbsp;&nbsp;这张表中最紧张的时段，是7月中旬到9月上旬的播种适期，以及11月中旬的收获适期。这两个适期都很窄，错过就无法挽回。播种晚了，根还没长粗，寒冷就来了；收获晚了，萝卜冻坏就不能吃了。萝卜是对时间要求严格的作物，这种严格是这种作物唯一的大缺点。

&nbsp;&nbsp;&nbsp;也要提前知道，11月的工作量是一年中最大的。收获、整理萝卜缨、挖窖和埋藏、晾晒，以及kimjang，都集中在很短的时间里。如果劳动力不足，把播种每隔十天分一批，使收获期错开，是比较现实的做法。
