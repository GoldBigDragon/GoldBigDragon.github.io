## 9. 病害虫 - 薬に頼らない防ぎ方

&nbsp;&nbsp;&nbsp;ダイコンの病害虫圧の等級はC、無防除時の減収率は推定51.7%です。防除自立度もCで、カラシナやケールのBより低くなっています。理由は、ダイコンの主な病害がほとんど地中で起こるからです。葉についた虫は見て捕まえることができますが、根を軟化させる細菌、こぶをつくる病原菌、センチュウは目に見えません。見えたときには、すでにその株を失ったあとです。

> **ダイコンの防除は事後の対処ではなく、事前の条件です。排水、酸度、輪作、健全な種子、この四つが整っていなければ、その後にできることはほとんどありません。**

### 9-1. 主な病害

| 病害 | 症状 | 発生条件 | 薬を使わない対応 |
|:---|:---|:---|:---|
| 軟腐病 | 根が軟化して腐り、悪臭がします | 過湿、排水不良、傷 | 畝を高くして排水溝を確保します。病気の株はすぐに遠くへ捨てます |
| べと病 | 葉が黄色く変わり、裏面にカビが生えます | 多湿、風通しの悪さ | 間引きで間隔を空け、病気の葉を取り除きます |
| 根こぶ病（いぼ病） | 根にこぶができ、株がしおれます | 酸性土壌、アブラナ科の連作 | 草木灰でpHを7.0近くまで上げ、輪作します |
| ウイルス病 | 葉にモザイク模様ができ、縮れます | アブラムシが媒介します | アブラムシを防ぎ、病気の株は抜いて焼却します |
| うどんこ病 | 葉の表面に白い粉が覆います | 乾燥と湿潤が交互に来るとき | 風通しと日照を確保します。薄めた牛乳や重曹水を散布します |
| 黒腐病 | 葉の縁がV字形に枯れます | 高温多湿、傷 | 種子の温湯浸漬、罹病株の除去 |

&nbsp;&nbsp;&nbsp;軟腐病はダイコンで最も恐ろしい病気です。原因となる細菌は、傷や自然の隙間から入り込み、根の組織の細胞壁を溶かす酵素を放出します。細胞壁が溶けると組織が丸ごとどろどろの粥状になり、その汁が流れて隣の株に広がります。貯蔵中にも進行するため、室（むろ。土中に掘った貯蔵穴）に病気のダイコンを1本混ぜ入れると、冬のあいだずっと損害が続きます。

&nbsp;&nbsp;&nbsp;防ぐ方法は三つあります。第一に、水をためないことです。畝の高さ15-20cmと排水溝の維持がすべてです。第二に、傷をつけないことです。除草のときに手鍬で根を引っかいたり、収穫のときにダイコンを投げたりすると、その傷が入り口になります。第三に、窒素を与えすぎないことです。窒素過剰で育ったダイコンは組織が軟らかく、細胞壁が薄いため、細菌が突き破りやすくなります。

&nbsp;&nbsp;&nbsp;うどんこ病に薄めた牛乳が効くのは、牛乳中のタンパク質と脂肪が葉の表面で乾いて膜をつくり、その過程でカビの菌糸を物理的に押さえ込んでしまうからです。牛乳を水で10倍ほどに薄め、晴れた日の朝に散布して、日光で乾かします。曇りの日に散布すると牛乳が傷み、かえって雑菌が繁殖します。重曹を使う場合は、水1Lに1g強の薄い濃度で溶かします。濃いと葉が傷みます。

### 9-2. 主な害虫

| 害虫 | 被害 | 薬を使わない防除 |
|:---|:---|:---|
| アブラムシ | 葉の裏から汁を吸い、ウイルスを媒介します | 石けん水の散布、草木灰の散布、テントウムシの保護 |
| ノミハムシ | 若い葉に針で刺したような穴をあけます | 発芽直後の防虫ネット、草木灰、播種時期の調整 |
| コナガ | 葉を食害します | 防虫ネット、手で捕殺 |
| モンシロチョウの幼虫 | 葉に大きな穴をあけます | 葉裏の黄色い卵をこすり落とします |
| ネコブセンチュウ | 根に小さなこぶが連なってでき、生育が止まります | 輪作、草木灰によるpH調整、マリーゴールドの間作 |
| コガネムシの幼虫・ネキリムシ | 根と株元をかじります | 耕起時に見つけて取り除く、夜に手で捕殺 |

&nbsp;&nbsp;&nbsp;ノミハムシは、ダイコンで最も多い初期害虫です。アブラナ科植物のにおいをたどってやってくる小さな黒い昆虫で、触れるとノミのように跳ねて逃げます。生長した株は葉に多少穴があいても持ちこたえますが、子葉と最初の本葉の段階でやられるとそのまま枯れてしまいます。発芽直後から本葉3、4枚までの期間にネットをかぶせるのが最も効果的で、この時期さえ乗り越えれば被害は大きく減ります。

&nbsp;&nbsp;&nbsp;センチュウは、目に見えない糸状の小さな生き物で、根に侵入してこぶをつくり、その中で生活します。根こぶ病のこぶが大きくてでこぼこした塊だとすれば、センチュウのこぶは小さく、数珠のように連なってつきます。農薬がない状況での対応は輪作しかありません。センチュウが食べられない作物を数年植えて、飢えさせる方法です。マリーゴールドのような植物は、根からセンチュウを抑える物質を出すことが知られており、畑の縁や株の間に植えると役に立ちます。

### 9-3. 自然由来の防除資材

| 防除資材 | 調製法 | 対象 |
|:---|:---|:---|
| 石けん水 | 無香料の石けん20gを水1Lに溶かします | アブラムシ、ハダニ |
| 草木灰液 | 草木灰を水に浸して24時間置き、こして使います | アブラムシ、カメムシ |
| 草木灰の散布 | ふるいにかけた細かい灰を、朝露のあるうちに葉にまきます | ノミハムシの忌避、カリウム供給 |
| 木酢液 | 300-500倍に薄めて散布します | 忌避効果、病気の抑制 |
| 薄めた牛乳 | 牛乳を水で10倍に薄め、晴れた日の朝に散布します | うどんこ病 |
| 重曹水 | 水1Lに1g強 | うどんこ病 |

&nbsp;&nbsp;&nbsp;石けん水がアブラムシに効く原理は、毒性ではなく物理作用です。界面活性成分がアブラムシの体表のロウ層を溶かし、気門をふさぎます。直接かかった個体しか死なず、残効性がないため、葉の裏までていねいに濡らし、数日おきに繰り返す必要があります。濃度を高くするとダイコンの葉も傷むので、1Lあたり20gの線を守ります。

### 9-4. 耕種的防除の原則

| 原則 | 内容 |
|:---|:---|
| 排水 | 畝を高く立て、排水溝を維持します。ダイコンで最も重要です |
| 酸度 | 草木灰でpH 6.5-7.0を保ち、根こぶ病を抑えます |
| 輪作 | アブラナ科以外の作物、特にマメ科を間に入れます |
| 健全な種子 | 温湯浸漬で種子伝染を断ちます |
| 風通し | 間引きで間隔を確保します |
| 残渣処理 | 病気の根と葉は堆肥に入れず、焼却するか遠くに埋めます |
| 時期の調整 | 害虫の発生最盛期を避けて播種します |

&nbsp;&nbsp;&nbsp;評価表の連作適応性がSSなので、ダイコンは続けて植えてもよいと読み取りがちです。しかし、この等級はダイコン自体の相対的な抵抗性を指すものであって、病原菌が蓄積しないという意味ではありません。根こぶ病やセンチュウがすでに入り込んだ畑であれば、ダイコンも結局はやられます。畑に余裕があるなら、マメ科を間に入れる輪作が依然として最善です。

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然素材による対処 |
|:---|:---|:---|
| 葉全体が黄色くなり、株が小さい | 窒素欠乏 | 完熟堆肥を株の間に入れるか、尿を10-15倍に薄めて与えます |
| 葉の縁が褐色に枯れます | カリウム欠乏 | 草木灰をまくか、草木灰の浸出液を与えます |
| 生育が悪く、葉が紫色を帯びます | リン酸欠乏 | 骨粉か草木灰を入れます。地温が低いときも同じ症状が出ます |
| 葉脈の間が黄色くなります | マグネシウム欠乏 | 堆肥を増やします |
| 根の内部が黒く変色します | ホウ素欠乏 | 有機物を十分に入れ、pHが高くなりすぎないようにします |
| 根が太らず、葉ばかり茂ります | 窒素過剰 | 窒素の供給を止め、カリウムを補います |
| 根が裂けたり二股に分かれたりします | 未熟な堆肥、石、固い土 | 栄養の問題ではありません。次の作付けで畑の準備を改善します |
| 根の内部に空洞ができます | ス入り | 第12節で扱います |

&nbsp;&nbsp;&nbsp;ホウ素欠乏は、ダイコンで特徴的に現れる問題です。外見は問題なさそうなダイコンを切ったとき、中が黒または褐色に変色している症状で、黒心症と呼ばれます。ホウ素は植物がごく少量しか必要としない微量要素ですが、細胞壁をつくるのに関わっているため、不足すると組織が崩れます。有機物が不足した砂地、pHが高すぎる畑、干ばつがひどかった年に出やすくなります。対応は、堆肥を十分に入れることです。よく熟した堆肥には、微量要素がまんべんなく含まれています。

&nbsp;&nbsp;&nbsp;草木灰を入れすぎてpHが上がりすぎると、かえってホウ素をはじめとする微量要素が土に固定されて、根が吸収できなくなります。pHを上げることと微量要素を供給することが食い違う場合があるという意味で、そのため草木灰は、一度に多くではなく、毎年少しずつ入れるのが原則です。

&nbsp;&nbsp;&nbsp;窒素過剰は、ダイコンで最もよくある失敗の原因です。畑に肥料を多く入れるほど良さそうに思えますが、ダイコンはその逆です。窒素が十分にあると、植物は葉をつくり続けようとして、根に糖を送りません。葉が茂って濃い緑色をしているのに、引き抜いてみると根が指ほどの太さしかないダイコンが出てきます。しかも、窒素が多い条件で育ったダイコンは組織が軟らかく、貯蔵中に腐りやすくなります。

## 11. 間作と輪作

| 相性 | 対象 | 効果 |
|:---:|:---|:---|
| 良い | マメ科作物（エンドウ、インゲンマメ、ササゲ） | 窒素を固定して残してくれます |
| 良い | サンチュ（リーフレタス）、ホウレンソウ | 根の深さが異なるため競合が少なく、地面を覆います |
| 良い | 長ネギ、ニラ | においが害虫を惑わせます |
| 良い | マリーゴールド | ネコブセンチュウを抑えます |
| 悪い | ハクサイ、カラシナ、キャベツなどのアブラナ科 | 同じ病害虫を共有します |
| 悪い | ニンジン、ゴボウなどほかの根菜 | 同じ深さをめぐって競合します |

&nbsp;&nbsp;&nbsp;サンチュとダイコンを混ぜて植える配置は、空間の活用という点で特に効率的です。サンチュは根が浅く地表近くに広がり、40-50日で終わりますが、ダイコンは根が深く下りて70-90日かかります。ダイコンの葉がまだ小さいうちに、その間でサンチュが育って地面を覆い、雑草を防ぎ、サンチュを収穫する頃にはダイコンが大きくなって場所を占めます。同じ面積から二つの作物が得られます。

| 輪作順序の例 | 年次 | 作物 | 畑で起こること |
|:---|:---:|:---|:---|
| 4年周期 | 1年目 | ダイコン、ハクサイなどのアブラナ科 | 窒素を多く消費し、深い層を掘り起こします |
| | 2年目 | マメ科（ダイズ、エンドウ、ササゲ） | 窒素が固定されて蓄積します |
| | 3年目 | サンチュ、フダンソウなどの葉菜類、またはタマネギ類 | 浅い層の養分を使います |
| | 4年目 | トウモロコシ、モロコシ（タカキビ）などのイネ科 | 深い根で下層の養分を引き上げます |
| | 再び1年目 | ダイコン | 病原菌の密度が下がった状態から始まります |

&nbsp;&nbsp;&nbsp;ダイコンは輪作の中で特別な役割を果たします。太い根が深く下りて土を物理的に掘り起こすからです。ダイコンを引き抜いたあとには縦に長い穴が残り、その穴を通って水と空気が下の層まで入ります。固くなった土を機械なしでほぐす方法として、ダイコンやカブを植える技術は昔から使われてきました。収穫せずにそのまま地中で腐らせておけば、その場所は有機物の豊富な通り道になります。

&nbsp;&nbsp;&nbsp;マメ科をダイコンの前に置く配置が特に有利です。ダイコンは窒素をかなり使う作物で、マメ科は空気中の窒素を固定して土壌に残します。ただし、豆を収穫した直後にすぐダイコンを植えると、窒素が多すぎて葉ばかり茂ることがあるため、間に別の作物を一度入れるか、豆の残渣を十分に腐熟させてから植えるのがよいでしょう。

## 12. 収穫 - ス入りと時期の問題

### 12-1. 収穫時期

| 作型 | 判断基準 | 備考 |
|:---|:---|:---|
| 春ダイコン | 気温が20℃を超える前 | 高温になると抽だいし、スが入ります |
| 秋ダイコン | 韓国では11月中旬、最初の強い寒波の前 | 氷点下3度を下回る前に引き抜きます |
| サイズの基準 | 肩の直径が品種の基準に達したとき | それ以上置いても太らず、スが入るだけです |
| 葉の状態 | 外葉が下に垂れ始めたとき | 成熟のサインです |

&nbsp;&nbsp;&nbsp;ダイコンの収穫で判断が分かれるのは、あと数日置いて太らせるか、今抜くかという点です。答えはたいてい、今抜くほうです。ダイコンはある時点を過ぎると、それ以上は太らなくなり、代わりに中にスが入り始めます。数日の欲が一年分の貯蔵食料を台なしにすることが、ダイコンではよくあります。

### 12-2. ス入りはなぜ起こるのか

&nbsp;&nbsp;&nbsp;ス入りは、ダイコンの内部にスポンジのような空洞ができる現象です。空洞症とも呼ばれます。外見は問題なさそうなダイコンを切ったとき、中がぱさぱさして白い穴があいていれば、スが入っています。このようなダイコンは味が悪く、貯蔵もできません。

&nbsp;&nbsp;&nbsp;原因はひとつではなく複数ありますが、共通する仕組みがあります。細胞がふくらんで大きくなる速さに、細胞内を満たす内容物の供給が追いつかないのです。殻だけが大きくなって中が空になると、細胞壁が耐えきれずに破れて空洞になります。

| 原因 | どのように起こるか |
|:---|:---|
| 収穫適期の超過 | 肥大が終わったあとも根が水を吸い続け、細胞が引き伸ばされます |
| 抽だい | 花茎が立つと、根に貯蔵された糖と養分が花茎へ移って中が空になります |
| 高温と乾燥 | 呼吸で消耗する量が、光合成で補う量を上回ります |
| 急激な肥大 | 窒素過多や突然の降雨で、あまりにも速く太ります |
| 低温による凍害後の解凍 | 凍っていた細胞が解けるときに破れ、空洞が残ります |
| 葉の損傷 | 葉が病気や虫で傷むと、糖の供給が途絶えます |

> **ス入りの本質は、根が貯蔵庫の役目をやめたというサインです。ダイコンは翌年に花を咲かせるために養分をためている最中ですが、その計画が終わったと判断すると、貯蔵をやめて内容物をほかの場所へ移します。人間が食べられるものは、その間にだけ存在します。**

&nbsp;&nbsp;&nbsp;したがって、ス入りを防ぐ方法は、事実上、時期の管理です。適期に抜き、抽だいを招かない作型を選び、窒素を与えすぎず、水分を均一に保ち、葉を健康に守ることです。すでにスが入ったダイコンを元に戻す方法はありません。

&nbsp;&nbsp;&nbsp;スが入ったダイコンでも、すべて捨てる必要はありません。生で食べるとぱさぱさしていますが、だしを取ったり干したりすれば使えます。切り干し大根にすれば、むしろ水分が少ないので早く乾きます。ただし、室に入れて貯蔵してはいけません。空洞の中で腐敗が速く進み、隣の健全なダイコンまで傷めてしまいます。

### 12-3. 収穫のコツ

| 項目 | コツ |
|:---|:---|
| 天候 | 晴れて乾いた日。雨の直後は避けます |
| 抜き方 | 葉をまとめて持ち、まっすぐ上に引き抜きます。抜けにくければ手鍬で脇を掘ります |
| 傷 | 投げたり落としたりしません。傷が軟腐病の入り口になります |
| 土 | 払い落としますが、水では洗いません |
| 葉の処理 | 根と葉が接する部分で切り、別に扱います |
| 予乾 | 日陰で半日ほど置き、表面の水分を飛ばします |

&nbsp;&nbsp;&nbsp;洗わないことが貯蔵の基本です。土がついたままのほうが、かえって表面の水分を守り、傷を覆ってくれます。水で洗うと表面の薄い保護層がはがれ、濡れた場所でカビや細菌が繁殖します。食べる直前に洗うのが原則です。

&nbsp;&nbsp;&nbsp;ダイコンの葉を切るときは、根側の肉を少しも残さず、葉がついている部分できれいに切ります。葉柄が残っていると、その部分が先に腐り、根に広がります。逆に、深く切りすぎて根の中身が露出すると、その断面が乾いて裂けたり、そこから病気が入り込んだりします。
