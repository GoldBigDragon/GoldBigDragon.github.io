## 15. 冷蔵庫なしの貯蔵 - 室（むろ）と乾燥

&nbsp;&nbsp;&nbsp;ダイコンの貯蔵性の等級はCで、貯蔵期間そのものはBと評価されました。室貯蔵で3-4か月、薄く切って干せば1年を超えてもちます。電気も冷蔵もない条件で、これほど長くもつ野菜は多くありません。ダイコンを災害に備える作物に挙げる理由の半分が、この項目にあります。

### 15-1. 室貯蔵

| 項目 | 基準 |
|:---|:---|
| 温度 | 0-4℃ |
| 湿度 | 85-95% |
| 穴 | 幅60cm、深さ75cm前後 |
| 入れ方 | ダイコンを立てて入れ、葉が付いていた側を下に向けます |
| 覆う順序 | まずわらをかぶせ、その上に土を2-3回に分けて40-60cm覆います |
| 期間 | 3-4か月 |

&nbsp;&nbsp;&nbsp;室貯蔵の原理は、地面の温度を緩衝する力を借りることです。地表は昼夜や季節によって温度が大きく上下しますが、深く下がるほど変動が小さくなり、1m下では年間を通してほぼ一定です。穴を75cm掘り、その上に土を40-60cm覆うと、ダイコンが置かれた場所は、冬の間ずっと0℃から4℃の間にとどまります。凍らず、しかも芽が出ない条件です。

&nbsp;&nbsp;&nbsp;湿度85-95%という条件も重要です。ダイコンは水分が94%の野菜なので、乾燥した場所に置くとたちまち水分が抜けて、しわしわになり、スカスカになります。土の中は湿度が高く保たれるので、この問題はひとりでに解決します。逆に、水がたまると腐るので、穴は必ず水はけのよい場所に掘る必要があります。斜面の上のほうや排水のよい砂地がよく、田んぼの跡や水が集まる低地は避けます。

| 段階 | 方法 |
|:---|:---|
| 場所選び | 水がたまらず、排水のよい場所 |
| 掘る | 幅60cm、深さ75cm |
| 底 | 乾いたわらや乾いた砂を敷きます |
| 入れる | ダイコンを立てて、きちんと並べて入れます。傷があるものやす入りのものは入れません |
| 覆う | わらを厚くかぶせ、土を2-3回に分けて覆います |
| 目印 | 場所に目印をつけ、水が流れ込まないよう周囲に溝を掘ります |
| 取り出し | 一度に必要な分だけ取り出し、再び覆います |

> **室に入れるダイコンは、必ず傷みのないものだけを選びます。傷があったり、す入りだったり、軟腐病の兆候があったりするダイコンが1本あるだけで、冬の間ずっと隣のダイコンを傷めます。選ぶ作業は、埋める作業より重要です。**

&nbsp;&nbsp;&nbsp;室は、一つを大きく作るより、いくつかに分けるほうが安全です。開けるたびに温度と湿度が乱れるからです。1か月分ずつ分けて埋め、一つの室を使い切ってから次の室を開けます。

### 15-2. 土中への埋設と屋内保管

| 方法 | 条件 | 期間 |
|:---|:---|:---|
| 畑にそのまま埋める | 掘り上げたダイコンを畑の一角に寝かせて埋め、わらと土をかぶせます | 2-3か月 |
| 砂に埋める | 箱や甕に、乾いた砂とダイコンを交互に層にして詰めます | 1-2か月 |
| 新聞紙・紙に包む | 1本ずつ包んで、涼しく暗い場所に置きます | 1-2か月 |
| 土付きのまま蔵に置く | 洗わずに、涼しい蔵に立てて置きます | 3-4週間 |

&nbsp;&nbsp;&nbsp;砂に埋める方法は、室を掘れない状況で使う方法です。砂がダイコンの間を埋めて空気との接触を減らし、湿度を保ちます。からからに乾いた砂はダイコンの水分を奪うので、少ししっとりしている程度がよく、ダイコン同士が触れ合わないようにすれば、一つが傷んでも隣へ広がりません。

### 15-3. 切り干し大根

| 段階 | 方法 |
|:---|:---|
| 切る | 太さ0.5-1cmの棒状か、薄い切り片に切ります |
| 干す | 日当たりがよく風通しのよい場所に、重ならないよう広げて干します |
| 裏返す | 1日に1、2回裏返して、均等に乾かします |
| 期間 | 晴れた日を基準に3-5日 |
| 仕上がり | 手で曲げたときに折れず、しなる程度 |
| 保管 | 密閉容器に入れ、炭や炒った米を一緒に入れます |
| 保存期間 | 6か月から1年以上 |

&nbsp;&nbsp;&nbsp;切り干し大根は、ダイコンの貯蔵法の中で最も確実で、最もかさが小さくなる方法です。水分94%のダイコンが乾くと、重さは10%未満に減ります。10kgのダイコンが1kgになり、甕一つに収まります。室貯蔵が3-4か月であるのに対して、干したものは1年を超えてもつので、冬を越えて春や夏まで続く食料は、結局のところ干したほうです。

&nbsp;&nbsp;&nbsp;ただし、干す過程でビタミンCはほとんど失われます。残るのは食物繊維とミネラルと糖です。そのため、冬の献立は二本立てで組む必要があります。ビタミンCは室に置いた生のダイコンと発酵食品から得て、熱量とかさは干したものから得ます。どちらか一方だけでは、冬を越すのは難しいです。

&nbsp;&nbsp;&nbsp;干すときは、重ならないように広げて干すことが肝心です。重なった部分は乾かず、その場でカビが生えます。夜は露に当たらないよう、取り込むか覆いをかけます。

### 15-4. ダイコンの葉とシレギ（干した大根葉）

| 段階 | 方法 |
|:---|:---|
| 下処理 | しおれた葉と土を払い落とします。洗いません |
| 下ゆで（任意） | 沸騰した湯にさっとくぐらせて冷水ですすぐと、色がよく、やわらかくなります |
| 干す | 何本かを束ねて、軒下や日陰に逆さにつるします |
| 条件 | 風通しがよく、直射日光が強くない場所 |
| 期間 | 1か月から2か月 |
| 保管 | 完全に乾いたら、袋や箱に入れて涼しい場所に置きます |
| 使い方 | ゆでて水にさらし、皮をむいて、ナムル（野菜の和え物）や汁物に使います |

&nbsp;&nbsp;&nbsp;シレギは、ダイコンの葉を干したものです。ダイコンを抜くときに一緒に出てくる葉を捨てず、冬の食料に変える方法で、ダイコン1株が与えてくれるものを2倍に増やします。葉の栄養構成は根とは違います。根にはほとんどないβ-カロテンと、根よりはるかに多いカルシウムと鉄と食物繊維が含まれています。

&nbsp;&nbsp;&nbsp;干したシレギは、そのままでは硬くて食べられません。水に一晩浸してからゆで、ゆで汁は捨てて、もう一度すすぎます。この過程で、硬い繊維がやわらかくなり、えぐみが抜けます。外皮が厚い茎は、手でむき取ると、ぐっとやわらかくなります。燃料を使う工程があるので、ほかのものを煮炊きする火に一緒にかける方法が効率的です。

### 15-5. キムチと漬物

| 方式 | 塩分濃度 | 期間 | 特徴 |
|:---|:---:|:---|:---|
| トンチミ（大根の水キムチ） | 2-3%の塩水 | 数か月 | 漬け汁ごと食べます。ビタミンCがかなりの量残ります |
| カクテキ（角切り大根のキムチ）・チョンガクキムチ（葉付き小ダイコンのキムチ） | 塩漬けのあと薬味で和える | 数か月 | 発酵により、貯蔵性と消化がよくなります |
| チャンジ型の塩漬け（塩漬け大根の漬物） | 10-15% | 1年以上 | 食べる前に水にさらして塩抜きする必要があります |
| チャンアチ（醤油漬け） | 醤油やテンジャン（韓国味噌）に漬け込む | 数か月 | 塩辛いおかず。塩分の補給も兼ねます |

&nbsp;&nbsp;&nbsp;トンチミは、災害時に特に価値の高い貯蔵法です。塩水にダイコンを丸ごと漬けて低温でゆっくり発酵させる方式で、薬味がほとんど入らないため、塩と水さえあれば漬けられます。乳酸菌が増えながら作る酸が雑菌を抑え、その過程でビタミンCがかなりの量保たれます。漬け汁まで飲み食いするので、損失が少なくてすみます。冬に新鮮なものがないとき、こうした発酵食品が壊血病を防いできた歴史的な理由が、これです。

> **乳酸発酵の条件は二つです。材料が漬け汁の下に完全に沈んでいること、そして塩分濃度が2%を下回らないこと。この二つの条件が守られれば、雑菌ではなく乳酸菌が育ちます。**

## 16. 調理と加工

| 方法 | 燃料 | ビタミンC保存 | 備考 |
|:---|:---:|:---:|:---|
| 生なます、千切り | なし | 最大 | 消化酵素も生きています |
| おろし金ですりおろす | なし | 最大 | デンプンの消化を助けます |
| 汁物やスープ | ほかの調理と兼ねる | 汁ごと食べれば保たれる | ダイコンの最も一般的な使い方 |
| 煮物 | 中程度 | 低い | 長く煮ると甘みが出ます |
| 発酵（トンチミ、キムチ） | なし | かなりの量が保たれる | 貯蔵と調理を兼ねます |
| 干しておいて戻して使う | 乾燥時は日光と風 | ほとんどなし | ミネラルと食物繊維は残ります |

&nbsp;&nbsp;&nbsp;燃料が貴重な状況で、ダイコンの大きな長所は、加熱しなくても食べられることです。洗って切るだけでよく、水分が多いので水の代わりにもなります。のどが渇いているのに飲み水が足りない状況で、生のダイコン一切れが実際に助けになります。

&nbsp;&nbsp;&nbsp;ダイコンをすりおろして食べる調理法には、生理学的な根拠があります。ダイコンに含まれるアミラーゼ系の酵素がデンプンを分解するので、ご飯やトック（餅）やジャガイモと一緒に食べると、消化が楽になります。この酵素は熱に弱く、加熱すると失われ、すりおろして細胞を壊してはじめて外に出てきます。穀物中心の食事で胃がもたれるときに生のダイコンを添える習慣は、ここから生まれました。

&nbsp;&nbsp;&nbsp;ダイコンを長く煮ると、辛味が消えて甘みが出ます。辛味成分であるカラシ油配糖体の分解物が揮発して、残った糖が現れるからです。そのため、ダイコンは汁の具材によく向いています。ほかに具材のない汁にダイコンだけを入れても、汁に甘みとうま味が生まれます。塩と水とダイコンだけで煮た汁が、災害時にひとつの完結した食事になりうる理由です。

&nbsp;&nbsp;&nbsp;皮をむく必要がないという点も、覚えておく価値があります。ダイコンの皮のすぐ下にビタミンCと食物繊維が集まっているため、洗って皮ごと使うほうが栄養面で有利で、下ごしらえの時間も短くなります。

## 17. 年間作業スケジュール

| 月（韓国の気候基準） | 作業 |
|:---|:---|
| 1月 | 室の中のダイコンの状態確認。傷んだものを取り除く。切り干し大根とシレギの点検 |
| 2月 | 堆肥の切り返し。春ダイコンの畑の準備。採種株の越冬確認 |
| 3月 | 中旬から春ダイコンの播種。越冬した採種株の植え直し |
| 4月 | 春ダイコンの間引きと追肥。採種株の抽だい、支柱立て |
| 5月 | 春ダイコンの収穫開始。採種株の開花、隔離の管理 |
| 6月 | 春ダイコンの収穫完了。採種株の着莢。夏に備えた畑の整理 |
| 7月 | 上旬に採種。中旬から秋ダイコンの畑の準備と播種開始 |
| 8月 | 秋ダイコンの播種を継続。発芽期のノミハムシ対策。1回目の間引き |
| 9月 | 2回目の間引きと追肥。秋の長雨に備えた排水管理。上旬までに播種を締め切る |
| 10月 | 根の肥大期の管理。中旬から早どりの開始 |
| 11月 | 中旬に本収穫。キムジャン（越冬用キムチ漬け）。室づくりと貯蔵。切り干し大根とシレギを干す |
| 12月 | 貯蔵品の管理。トンチミとキムチの熟成確認。畑の整理 |

&nbsp;&nbsp;&nbsp;この表で最も切迫した時期は、7月中旬から9月上旬までの播種適期と、11月中旬の収穫適期です。どちらも適期の幅が狭く、逃すと取り返しがつきません。播種が遅れると、根が太くなる前に寒さが来て、収穫が遅れると、凍って食べられなくなります。ダイコンは時期に厳しい作物で、その厳しさが、この作物の唯一の大きな欠点です。

&nbsp;&nbsp;&nbsp;11月の作業量が1年で最も多いという点も、あらかじめ知っておく必要があります。収穫、葉の整理、室の掘削と埋設、干す作業、キムジャンが、短い期間に重なります。労働力が足りない場合は、播種を10日間隔に分けて、収穫期を分散させるのが現実的です。
