- 来源: 韩国农村振兴厅 农事路（Nongsaro）、韩国国家标准食品成分表、FAO ECOCROP、Wiki、Gemini、Claude、Chat-GPT

---
## 引言
&nbsp;&nbsp;&nbsp;马铃薯（Solanum tuberosum）是来自南美洲安第斯高原的茄科作物，擅长在凉爽气候下短时间内把淀粉填进地下，但在盛夏高温和积水的土地上却毫无办法。在灾害应对评估中，它的综合等级为B（48.1分，有效183种中第35位），短期S（50.6）、长期B（45.6）、副食S（52.5分），是能很快拿出食物但撑不了太久的作物。种下后80-90天就能收获，蛋白质占热量的12%，在灾害第一年很可靠；但化肥和农药一旦消失，产量会崩溃到常规的18%，晚疫病无药可治，而且要靠活的块茎而不是种子来传代，病毒会不断积累。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | B | 48.1 |
| 短期 | S | 50.6 |
| 长期 | B | 45.6 |
| 副食 | S | 52.5 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：设施负担。S：口味、国内种植普及度、自留种。A：单位面积热量、蛋白质密度、微量营养素、收获速度、连作适应性。B：水消耗量、光照、烹调·加工要求度、病虫害压力、耐储性、整地·挖掘能量、产量稳定性 |
| 劣势 | E：无合成投入产量保持率、非食用价值、种子寿命。D：持续性、防治自立度。C：施肥、温度幅度、耐寒性 |

> **把马铃薯当主食，最大的优点不是热量，而是随热量而来的蛋白质。**

&nbsp;&nbsp;&nbsp;单位面积热量A，是每㎡2,010kcal、自给线的0.77倍，也就是130㎡出头就能供一个人一年的大部分热量。蛋白质密度A是指蛋白质占热量的12%、氨基酸评分在90以上，甘薯和木薯都是E。无合成投入产量保持率E（17.6%）是瑞士40年试验的实测值，不施肥的小区产量只有常规的六分之一左右，所以要做好心理准备：平时出300kg的田，只能出50kg出头。种子寿命E是指不能用干种子而要用活的块茎传到春天，自留种重复几次，3-4年产量就会下降；防治自立度D是指晚疫病的防治全靠预防。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 茄科茄属多年生草本。原产秘鲁和玻利维亚的安第斯高原 |
| 叶、茎 | 小叶5-7枚的奇数羽状复叶。茎高30-100cm，根系浅而散 |
| 花、果 | 5-6月开白色、淡粉色、紫色的花。果实是像圣女果的绿色浆果，剧毒，不能吃 |
| 块茎 | 地下茎末端膨大而成的储藏器官，是茎而不是根。所以有芽眼，见光会变绿，有毒的生物碱也会增加 |

&nbsp;&nbsp;&nbsp;出苗后约30天扩展叶、茎和根，开花前后地下茎末端开始膨大，之后块茎变大（钾的需求最大），茎枯黄后外皮变硬。氮要在前期施，钾要在后期施，后期氮过剩只会让叶子茂盛，破坏块茎的形成和耐储性。块茎的形成由日长和夜温决定，夜温持续在20℃以上就不会开始。每100g含热量66-85kcal、碳水化合物14.8-19.6g（大部分是淀粉）、蛋白质1.5-2.0g、膳食纤维2.3g、钾420mg、维生素C 9.7mg。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 生长14-23℃（5℃以下和30℃以上为极限），块茎膨大14-18℃（27-30℃以上时膨大停止、只长叶），夜温12-18℃，发芽15-20℃ |
| 水分、光照 | 全生育期400-800mm，淹水24小时根和块茎就会腐烂。每天6小时以上日照，遮光40%时相对产量约80% |
| 土壤 | 排水良好的砂壤土-壤土，耕层25cm以上，pH5.0-6.0。pH6.5以上疮痂病（块茎表面的木栓质硬痂）会激增，所以不施石灰，木灰每10㎡也不超过约1.8L |

&nbsp;&nbsp;&nbsp;选址依次是：排水良好的坡地或高地（一次淹水就会损失整块田，而且排水事后无法补救）、露水干得早的朝东或东南向并通风的地方（会破坏晚疫病孢子的萌发条件）、最近3-4年没种过茄科的地、以及能把水运到的距离。

&nbsp;&nbsp;&nbsp;粉质品种（Namjak、Dubaek、Haryeong、Russet）淀粉多、口感粉面，适合煮和提取淀粉；黏质品种（Daeseo、Daeji）久煮不烂，适合炖煮和做汤。Sumi（早熟90-100天）是韩国主力品种，有利于在灾害初期保障粮食；Chubaek（极早熟80-90天）最快有得吃，但要放弃储存；Jopung（极早熟）对晚疫病相对较强。要过冬就用耐储的Daeji（中晚熟110-120天）和Russet，多雨凉爽的地方适合抗晚疫病的Kennebec，Dubaek需要多施20%以上的肥料，肥料不足时要避开。每年天气不同、各品种结果也不同，所以早熟和中晚熟品种混种，夏天超过30℃的平原地区则用甘薯代替马铃薯。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 翻耕20-30cm深，把土块打碎到拳头大小以下，起20-30cm高的垄并开20cm以上深的排水沟。保持pH5.0-5.5，不施石灰 |
| 施肥（1,000㎡） | 氮10-13.7kg（基肥50%、追肥50%），磷8.8kg，钾13kg（磷和钾全部作基肥），腐熟堆肥1,500-2,000kg。基肥在播种前1-2周施入，不要直接接触种薯；追肥在株高20cm左右、第一次培土时施，开花后不再施。未腐熟的堆肥会使种薯腐烂 |
| 灾害替代肥料 | 木灰（筛过的白灰每10㎡ 1-2L，过多会抬高pH，疮痂病激增）、翻堆6个月以上制成的腐熟堆肥、稀释10倍以上的尿液（腐熟2周以上，收获前3周停用，不要沾到叶子）、骨粉、前一年翻压的毛叶苕子或紫云英 |
| 种薯 | 播种前20-35天准备。剔除有病斑、伤口、发软的，顺着芽眼纵切成2-4块、每块30-50g并带1-2个芽眼（横切会出现没有芽眼的块而腐烂）。切口蘸木灰，在阴凉处放2-3天愈合，再在15-20℃、湿度80-90%的散射光下催芽25-35天，培育粗短的绿色芽（在黑暗中会长出白色细弱的芽）。温水处理（50-55℃ 10-15分钟）超过60℃芽就会死 |
| 种植 | 春播在2月上旬-3月下旬种，5月下旬-6月下旬收获，解冻后尽量早种、在雨季前收完，是最有力的晚疫病防治。高冷地在4月中旬-5月中旬种，南部沿海的秋播在8月中旬-下旬种。深5-10cm，单行垄距70-80cm、株距20-25cm，芽朝上、切面朝下。每1,000㎡用150-200kg |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种到出苗 | 只浇到土壤不干的程度（种薯靠储存养分维持，水多会烂） |
| 出苗到开花前 | 保持适度水分，避免过湿（稍微缺一点水能让根扎得深） |
| 块茎膨大期 | 最重要，要浇足（这一时期一个月干旱会使产量减半）。要分次浇，以免出现裂口和二次生长 |
| 收获前10天-2周 | 停止灌水（外皮变硬，耐储性提高） |

| 管理 | 方法 |
|:---|:---|
| 覆盖 | 5cm以上厚的稻草是塑料膜的首选替代品，能使蒸发减少一半以上并防止泥水溅起，实际上起到灌水的作用。它不能提高地温，所以出苗后再盖 |
| 培土 | 第一次在茎长到10-20cm时，把垄间的土培到基部5-10cm；第二次在2-3周后再培5-10cm。可防止块茎变绿和龙葵素生成，增加块茎数量，防止倒伏，还能挡住晚疫病孢子随雨水下渗的途径，所以无论什么情况都不能省略 |
| 其他管理 | 除草是必须的，出苗后一个月最怕杂草竞争。一个种薯长出5根以上茎时，只留3-4根，其余拔掉 |
| 缺水、过湿 | 中午叶片下垂、傍晚恢复是警戒信号，要往垄间引水；傍晚也不恢复就立即灌水，但不要一次浇很多。下部叶片发黄、根发黑就挖排水沟；茎基变软发臭则无法挽救，要把该株拿出田外 |

## 6. 病虫害与养分问题
&nbsp;&nbsp;&nbsp;晚疫病在凉爽多雨的天气里，从出现第一个病斑起一周就能让整块田变黑枯死，而且无药可治，所以防治全靠预防。要用抗病品种、宽株距、高垄、早播，使雨季与生长后期错开，一发现第一个病斑，就立即用镰刀把整个地上部割下来在田外烧掉，2周后只收块茎。产量虽然会减少，却能防止病菌毁掉全部块茎和储存的薯。

| 病虫害 | 症状与条件 | 预防与应对 |
|:---|:---|:---|
| 晚疫病 | 叶片出现水渍状黑褐色斑点，叶背有白霉，块茎褐色腐烂（气温15-20℃、湿度90%以上持续两天以上） | 抗病品种、宽株距、高垄、早播，发病时清除地上部。病残体不留在田里，烧掉或深埋 |
| 软腐病、黑胫病 | 块茎变软发臭 / 茎基发黑腐烂、植株萎蔫（过湿、带病种薯） | 改善排水，收获时不伤块茎，用健康种薯。感染的立即隔离丢弃 |
| 病毒病 | 花叶、卷叶、植株矮小（蚜虫传播） | 无法治疗。用无病种薯、防治蚜虫、清除病株。是自留种退化的主因 |
| 害虫 | 蚜虫（吸汁并传播病毒）、马铃薯块茎蛾、线虫、田鼠 | 肥皂水和保护瓢虫 / 培土，收获后不在田里留薯 / 抗病品种和3年以上轮作 / 清除田边杂草，储藏处地面铺铁丝网 |

&nbsp;&nbsp;&nbsp;没有药物时唯一能自制的晚疫病对策是波尔多液：把1kg硫酸铜溶于80L水，把1kg生石灰溶于20L水，再把铜液倒入石灰液里混匀（这是预防剂，发病后无效，也不要用金属容器）。防治蚜虫用把20g无香皂溶于1L水的肥皂水。

| 症状 | 原因与措施 |
|:---|:---|
| 下部叶片发黄、植株矮小 / 叶缘焦褐 / 叶片由深绿变紫（低温期） | 缺氮 / 缺钾 / 缺磷。腐熟堆肥和稀释10倍的尿液 / 在垄沟里少量撒木灰 / 骨粉和木灰 |
| 只有叶子茂盛、块茎小 | 氮过剩。停止施氮，用木灰补钾 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 菜豆和豌豆等豆科（固氮）、万寿菊（抑制线虫）、旱金莲（引走蚜虫） |
| 一般 | 十字花科、菠菜、莴苣（覆盖地面减少杂草，竞争不大） |
| 差 | 番茄、茄子、辣椒（同属茄科，共有晚疫病和害虫）、南瓜·黄瓜·向日葵（争夺空间和养分） |

&nbsp;&nbsp;&nbsp;马铃薯属于两年休耕类，但晚疫病和疮痂病会留在土里，所以隔3-4年更安全。顺序是第一年马铃薯，第二年豆科（恢复氮），第三年叶菜类或葱·洋葱类，第四年谷物或根菜类。同一块田连续种马铃薯，第一年看不出来，到第三年土传病害超过临界密度就会突然崩溃。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 茎完全枯死后1-2周，用拇指搓揉外皮不会脱落时（皮层固化），在连续2-3天晴朗干燥的天气后挖。若晚疫病已蔓延或预报有雨季，就割掉地上部，2周后再挖 |
| 要领 | 用镰刀割掉地上部茎，从离植株30cm处用锄头或铁锹把土像托起一样挖开，用手取出。把挖过的地方再翻一遍找剩下的。只轻轻抖掉泥土，不要水洗，在阴凉处摊开2-3小时晾干表面（即使两小时的直射阳光也会开始变绿） |
| 分拣 | 当场分成四类。伤薯立即食用或干燥、加工淀粉，病薯拿出田外丢弃，储藏用的愈合处理后正式储存，种薯候补（30-50g的健康块茎）单独保管 |

| 留种 | 标准 |
|:---|:---|
| 挑选 | 30-50g（鸡蛋大小）、没有病斑、伤口和软烂的。生长期间给花叶或卷叶的植株、特别矮小的植株插上木棍做标记，它们的薯用于食用而不留作种薯（淘汰病株，病毒会随块茎原样传到下一代，是不用药减缓退化最有效的手段） |
| 保管 | 2-4℃、湿度85-90%，埋在湿润的沙子或锯末里，微通风，每2周检查一次、挑出烂的。种薯允许有弱光（变绿后老鼠和害虫较少啃食）。绝不与食用的马铃薯放在同一格，并做醒目标记 |
| 应对退化 | 种薯田只设在凉爽的高地，比一般收获早2-3周挖，用浅色覆盖物和旱金莲减少蚜虫，并与其他地区的种植者交换种薯 |
| 真实种子 | 绿色果实里的种子大多不遗传病毒，是切断退化的最后手段。实生苗与亲本完全不同，第一年的薯又小又不整齐，要从中挑好的用块茎延续，需要再多花2年。果实剧毒，除了取种以外绝不能吃 |

## 9. 储存
&nbsp;&nbsp;&nbsp;储存分三个阶段。愈合处理（10-15℃，湿度85-95%，黑暗、微通风，1-2周）让伤口形成木栓层，防止腐烂和水分流失；正式储存（3-5℃，湿度85-95%，完全黑暗，微通风，4-6个月）抑制呼吸和发芽；每周检查一次，挑出烂的。跳过愈合处理，储存期会缩短一半以上。0℃以下会冻伤变软，10℃以上会发芽。不要与洋葱放在同一格，也不要用家用冰箱。

| 方式 | 方法 | 期限 |
|:---|:---|:---|
| 窖储存 | 在排水好的地方向下挖1.5-2m，盖上屋顶并做通气口（0-4℃）。最稳定，但劳动量大，地下水位高就不行 | 4-6个月 |
| 坑·土堆储存 | 一把铁锹一天就能做成。挖直径1.5m、深20-30cm的浅坑，铺10cm干稻草，把愈合处理完的马铃薯堆成高度不超过60cm的坟包状，盖上20-30cm干稻草和15-20cm土并拍实，在顶部用草束做通气口（堵住的话热量和湿气积聚，几天就会烂软）。一打开就很难再盖，所以要一次全部取出（0-5℃） | 3-5个月 |
| 加工储存 | 切成5mm以下，在沸水中焯1-2分钟后彻底晒干（不焯会褐变），或磨成粉。磨碎后加水搅开、只取沉淀的淀粉浆，多次冲洗后晒干做成淀粉，连边角料和小薯都能用上，体积变小、不生虫（100kg出12-18kg） | 干片数月-1年，粉1-2年，淀粉数年 |

> **灾害储存的标准策略是并用。好的放进窖里当冬季粮食，边角料和小的做成淀粉和粉，作为数年的储备。**

## 10. 烹调与注意事项
| 注意 | 内容 |
|:---|:---|
| 龙葵素、卡茄碱 | 表皮变绿的、发芽的、带苦味或涩辣味的含量非常高，伤口、病变部位以及小而未成熟的也高。果实、叶、茎不能吃。绿色部分以及芽和芽眼周围要深深挖掉，范围大就整个丢弃，有苦味就不吃。只削皮是不够的 |
| 症状 | 吃后几小时开始呕吐、腹痛、腹泻，严重时出现头痛、头晕、神经症状。对成人致命的情况罕见，但对儿童和体弱者危险 |
| 通风 | 密闭的储藏处或地下窖里大量马铃薯腐烂时会产生有害气体并消耗氧气，进入前要先开门充分通风，先放进一支蜡烛，熄灭了就不要进去 |

> **加热不能破坏龙葵素。煮、烤、炸，毒性都原样留下。唯一的办法是挖掉或丢弃。**

| 烹调 | 方法 |
|:---|:---|
| 节省燃料 | 整个煮是带皮浸没在水中20-30分钟（营养损失少），蒸是放少量水25-30分钟，切成2cm以下则10-15分钟。保温烹调是煮沸10分钟后离火，用稻草、毯子或稻壳厚厚裹住闷40分钟，燃料可省一半以上；埋进热灰中烤30-40分钟，或把淀粉倒入沸水中搅开，也能立即做熟 |
| 吃法 | 带皮吃在维生素C和膳食纤维方面更好。煮的水里溶有钾和维生素，可以当汤用。生马铃薯的淀粉不能消化，会引起腹痛，所以一定要煮熟 |
| 加工 | 把磨碎的马铃薯挤去水分，用剩下的渣和沉淀的淀粉合在一起和面，做马铃薯饼或面疙瘩，边角料一点不剩。泡在水里发酵好几周后只滤出淀粉的“烂薯”，气味很重但淀粉回收率高。焯过晒干的片泡发后放进汤和粥里 |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存的马铃薯和种薯（每周剔除烂的，储藏处不要降到0℃以下）。2月挑选种薯，规划田地，翻堆堆肥 |
| 3-4月 | 3月切种薯并愈合处理，开始催芽（播种前20-35天），施基肥、起垄。4月播春马铃薯（中部上旬-中旬），预报晚霜时用土或稻草盖住 |
| 5-6月 | 5月出苗、第一次培土、追肥、除草。6月块茎膨大期集中灌水、第二次培土、监视晚疫病 |
| 7-8月 | 7月收获春播的（目标是雨季前收完）、愈合处理、整理储藏处。8月在南部播秋马铃薯（不切块、整个种），收获高冷地夏播的 |
| 9-10月 | 9月管理秋马铃薯并培土，单独管理种薯田。10月停止灌水，准备储存，霜前收完 |
| 11-12月 | 11月收获秋马铃薯，愈合处理，窖·坑储存（种薯另放）。12月检查储存，加工淀粉和干片（先处理难储存的），做明年的计划 |

> **马铃薯是这样一种作物：绿色、芽和苦味要挖掉或丢弃，茄科作物隔3-4年轮作，培土一次不漏，收获后做愈合处理，并把种薯与食用马铃薯分开保管。**
