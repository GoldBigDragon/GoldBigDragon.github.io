## はじめに
&nbsp;&nbsp;&nbsp;ジャガイモ(Solanum tuberosum)は、南アメリカのアンデス高原から来たナス科の作物で、涼しい気候で短い期間に地中へでんぷんを詰め込むのは得意ですが、真夏の高温と水がたまった土地では無力です。災害に備える評価では総合B(48.1点、有効183種中35位)、短期S(50.6)、長期B(45.6)、副食S(52.5点)で、すぐ食べ物を出してくれますが、長く持ちこたえさせてはくれない作物です。植えて80-90日で収穫でき、熱量に対するタンパク質が12%に達するため災害の初年は頼りになりますが、化学肥料と農薬がなくなると収量は慣行の18%に崩れ、疫病には治療薬がなく、種子ではなく生きた塊茎で世代をつながなければならないためウイルスがたまります。

## 1. 災害への備えの評価
| 区分 | 等級 | スコア |
|:---|:---:|:---:|
| 総合 | B | 48.1 |
| 短期 | S | 50.6 |
| 長期 | B | 45.6 |
| 副食 | S | 52.5 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: 施設の負担。S: 味、国内での栽培の普及度、自家採種。A: 面積当たりの熱量、タンパク質密度、微量栄養素、収穫速度、連作への適応性。B: 水の消費量、日射、調理・加工の要求度、病害虫圧、貯蔵性、整地・掘削エネルギー、収量の安定性 |
| 弱み | E: 合成資材を投入しない場合の収量維持率、非食用の価値、種子の寿命。D: 永続性、防除の自立度。C: 施肥、温度幅、耐寒性 |

> **ジャガイモを主食にするときのいちばん大きな長所は、熱量ではなく、熱量とともに付いてくるタンパク質です。**

&nbsp;&nbsp;&nbsp;面積当たりの熱量Aは、㎡当たり2,010kcalで自給ラインの0.77倍、つまり130㎡ほどで1人の1年分の熱量の大部分をまかなえるという意味です。タンパク質密度Aは、熱量に対して12%でアミノ酸スコアが90以上という意味で、サツマイモとキャッサバはEです。合成資材を投入しない場合の収量維持率E(17.6%)は、スイスの40年間の試験で肥料なしの区画が慣行の6分の1ほどだったという実測値で、平時に300kgとれていた畑で50kgほどしかとれないことを覚悟しなければなりません。種子の寿命Eは、乾いた種子ではなく生きた塊茎で春まで越さなければならず、自家採種を重ねると3-4年で収量が落ちるという意味で、防除の自立度Dは、疫病の防除がすべて予防だという意味です。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | ナス科ナス属の多年草。ペルーとボリビアのアンデス高原原産 |
| 葉、茎 | 小葉5-7枚の奇数羽状複葉。茎は高さ30-100cmで、根は浅く広がる浅根性 |
| 花、実 | 5-6月に白、薄いピンク、紫の花が咲く。実はミニトマトに似た緑色の液果で、猛毒のため食べられない |
| 塊茎 | 地下茎の先が膨らんだ貯蔵器官で、根ではなく茎。そのため芽があり、光を受けると緑色に変わって有毒なアルカロイドが増える |

&nbsp;&nbsp;&nbsp;出芽後約30日は葉と茎と根を広げ、開花の前後に地下茎の先が膨らみはじめ、その後塊茎が大きくなり(カリウムの要求が最大)、茎が黄色く枯れると皮が固まります。窒素は初期に、カリウムは後期に与え、後期の窒素過剰は葉だけを茂らせて塊茎の形成と貯蔵性を損ないます。塊茎の形成は日長と夜の気温で決まり、夜の気温が20℃以上で続くと始まりません。100g当たり熱量66-85kcal、炭水化物14.8-19.6g(大部分がでんぷん)、タンパク質1.5-2.0g、食物繊維2.3g、カリウム420mg、ビタミンC9.7mgです。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 生育14-23℃(5℃以下と30℃以上は限界)、塊茎の肥大14-18℃(27-30℃以上で肥大が止まり葉だけが伸びる)、夜の気温12-18℃、発芽15-20℃ |
| 水、日照 | 全生育期で400-800mmで、24時間の冠水で根と塊茎が腐る。1日6時間以上の日照で、40%の遮光で相対収量は約80% |
| 土壌 | 水はけのよい砂壌土-壌土、作土25cm以上、pH5.0-6.0。pH6.5以上でそうか病(塊茎の表面のコルク質のかさぶた)が急増するので、石灰は入れず、木灰も10㎡当たり1.8Lほどを超えない |

&nbsp;&nbsp;&nbsp;立地は、水が抜ける傾斜地や高い土地(冠水が1回あれば畑全体を失い、排水はあとから直せない)、露が早く乾く東向きや南東向きと風通しのよい場所(疫病の胞子が発芽する条件が崩れる)、最近3-4年間ナス科を植えていない土地、水を運んでこられる距離の順に選びます。

&nbsp;&nbsp;&nbsp;粉質の品種(ナムジャク、トゥベク、ハリョン、ラセット)はでんぷんが多くほくほくして、ゆでる・でんぷんの抽出に向き、粘質の品種(デソ、テジ)は長く煮ても崩れず、煮物と汁物に向きます。スミ(早生90-100日)は韓国の主力品種で災害初期の食料確保に有利、チュベク(極早生80-90日)はもっとも早く食べ物が出ますが貯蔵はあきらめなければならず、チョプン(極早生)は疫病に比較的強い品種です。冬を越すには貯蔵性のよいテジ(中晩生110-120日)とラセット、雨が多く涼しい場所には疫病抵抗性のあるケネベックが合い、トゥベクは肥料を20%以上多く求めるので、肥料が足りないときは避けます。年ごとに天候が違い品種ごとに結果も違うので、早生と中晩生を混ぜて植え、夏が30℃を超える平地ではジャガイモの代わりにサツマイモを植えます。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 整地 | 20-30cmの深さに耕して土の塊はこぶし大以下に砕き、高さ20-30cmの畝と深さ20cm以上の排水溝をつくる。pH5.0-5.5を保ち、石灰は入れない |
| 施肥(1,000㎡) | 窒素10-13.7kg(元肥50%、追肥50%)、リン酸8.8kg、カリウム13kg(リン酸とカリウムは全量を元肥)、完熟堆肥1,500-2,000kg。元肥は播種の1-2週間前に種芋に直接触れないように与え、追肥は草丈20cmのころ1回目の土寄せとともに与え、開花以降は与えない。未熟な堆肥は種芋を腐らせる |
| 災害時の代替肥料 | 木灰(ふるいにかけた白い灰を10㎡当たり1-2L、多いとpHが上がってそうか病が急増)、6か月以上切り返してつくった完熟堆肥、尿の10倍以上の希釈液(2週間以上熟成、収穫の3週間前に中止、葉に触れないように)、骨粉、前年にすき込んだヘアリーベッチやレンゲ |
| 種芋 | 播種の20-35日前に準備する。病斑、傷、柔らかいものは除き、芽が1-2個入るように縦に2-4等分して30-50gに切る(横に切ると芽のない切片が腐る)。切り口に木灰をつけて日陰で2-3日置いて癒やし、15-20℃、湿度80-90%の散光で25-35日芽出しして、太くて短い緑色の芽を出させる(暗いと白くて弱い芽が出る)。温湯処理(50-55℃で10-15分)は、60℃を超えると芽が死ぬ |
| 植え付け | 春作は2月上旬-3月下旬に植えて5月下旬-6月下旬に収穫し、雪解け直後にできるだけ早く植えて梅雨前に収穫を終えることが、もっとも強力な疫病の防除。高冷地は4月中旬-5月中旬、南部沿岸の秋作は8月中旬-下旬に植える。深さ5-10cm、1列は畝の間隔70-80cmで株間20-25cm、芽を上に切り口を下に。1,000㎡当たり150-200kg |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から出芽 | 乾かない程度だけ(種芋は蓄えた養分で耐える時期なので、水が多いと腐る) |
| 出芽から開花前 | 適度な水分を保ち過湿は避ける(少し足りないくらいにすると根が深く伸びる) |
| 塊茎の肥大期 | もっとも重要で、たっぷり与える(この時期の1か月の干ばつが収量を半分に減らす)。分けて与えないと亀裂や二次生長が出る |
| 収穫の10日-2週間前 | 灌水を止める(皮が固まって貯蔵性が上がる) |

| 管理 | 方法 |
|:---|:---|
| マルチ | 厚さ5cm以上のわらがビニールの代わりの第一候補で、蒸発を半分以下に減らし、泥はねを防ぎ、事実上の灌水の役目を果たす。地温は上げられないので出芽後にかける |
| 土寄せ | 1回目は茎が10-20cmのとき、畝の間の土を株元に5-10cm寄せ、2回目は2-3週間後にさらに5-10cm寄せる。塊茎の緑化とソラニンの生成を防ぎ、塊茎の数を増やし、倒れるのを防ぎ、疫病の胞子が雨水に乗って下りてくる経路を断つので、どんな状況でも省かない |
| そのほかの管理 | 草取りは必須で、出芽後の1か月が雑草との競合にもっとも弱い。1つの種芋から茎が5本を超えて出たら、3-4本だけ残して抜く |
| 水不足、過多 | 昼に葉がしおれて夕方に回復するなら警戒信号なので畝の間に水を流し込み、夕方も回復しなければただちに灌水するが一度にたくさんは与えない。下葉が黄色くなって根が黒ずんだら排水溝を掘り、茎の根元が柔らかくなって悪臭がしたら回復できないのでその株を畑の外へ出す |

## 6. 病害虫と養分の問題
&nbsp;&nbsp;&nbsp;疫病は、涼しくて雨の多い天気では最初の斑点が見えてから1週間で畑全体が黒く枯れ、治療薬がないので防除はすべて予防です。抵抗性品種、広い株間、高い畝、早い播種で梅雨と生育後期がずれるように配置し、最初の病斑を見つけたらただちに地上部全体を鎌で刈り取って畑の外で焼き、2週間後に塊茎だけを収穫します。収量は減っても、菌が塊茎と貯蔵分の全体をだめにする事態を防げます。

| 病害虫 | 症状と条件 | 予防と対処 |
|:---|:---|:---|
| 疫病 | 葉に水に濡れたような黒褐色の斑点、裏に白いカビ、塊茎の褐色の腐れ(気温15-20℃で湿度90%以上が2日以上) | 抵抗性品種、広い株間、高い畝、早い播種、発病時の地上部の除去。病んだ残渣は畑に残さず、焼くか深く埋める |
| 軟腐病、黒あし病 | 塊茎が柔らかくなって悪臭 / 茎の根元が黒く腐って株がしおれる(過湿、感染した種芋) | 排水の改善、傷をつけずに収穫、健全な種芋。感染したものはただちに隔離して廃棄 |
| ウイルス病 | モザイク模様、葉の巻き、株の矮小(アブラムシが媒介) | 治療不可。無病の種芋、アブラムシの防除、病株の除去。自家採種の劣化の主因 |
| 害虫 | アブラムシ(汁を吸いウイルスを運ぶ)、ジャガイモガ、センチュウ、ノネズミ | 石けん水とテントウムシの保護 / 土寄せと収穫後に畑にイモを残さない / 抵抗性品種と3年以上の輪作 / 畑の周りの雑草の除去と貯蔵庫の床の金網 |

&nbsp;&nbsp;&nbsp;薬がないときにつくれる疫病への唯一の対応手段はボルドー液で、硫酸銅1kgを水80Lに溶かし、生石灰1kgを水20Lに溶いた石灰液に銅液を注いで混ぜます(予防剤で、発病後は効果がなく、金属製の容器は使いません)。アブラムシには、無香料の石けん20gを水1Lに溶かした石けん水を使います。

| 症状 | 原因と対処 |
|:---|:---|
| 下葉から黄色くなって株が小さい / 葉の縁が褐色に枯れる / 葉が濃い緑色から紫がかる(低温期) | 窒素欠乏 / カリウム欠乏 / リン欠乏。完熟堆肥と尿の10倍希釈液 / 木灰を溝に少量 / 骨粉と木灰 |
| 葉ばかり茂って塊茎が小さい | 窒素過剰。窒素を止めて木灰でカリウムを補う |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | インゲンやエンドウなどのマメ科(窒素固定)、マリーゴールド(センチュウを抑える)、ナスタチウム(アブラムシを誘って分散させる) |
| 普通 | アブラナ科、ホウレンソウ、レタス(地面を覆って雑草を減らし、競合は大きくない) |
| 悪い | トマト、ナス、トウガラシ(同じナス科で疫病と害虫を共有する)、カボチャ・キュウリ・ヒマワリ(空間と養分を競う) |

&nbsp;&nbsp;&nbsp;ジャガイモは2年休作群ですが、疫病とそうか病が土に残るので、3-4年あけるほうが安全です。順序は、1年目ジャガイモ、2年目マメ科(窒素の回復)、3年目葉菜類かネギ・タマネギ類、4年目穀物か根菜類です。同じ畑にジャガイモを続けて植えると、1年目は目立たず、3年目に土壌伝染病が限界密度を超えて突然崩れます。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 茎が完全に枯れて1-2週間たち、親指でこすっても皮がむけなくなったら(スキンセット)、晴れて乾いた日が2-3日続いたあとに掘る。疫病が広がったり梅雨が予報されたりしたら、地上部を切って2週間後に掘る |
| 要領 | 地上部の茎を鎌で刈り、株から30cm離れたところから鍬やスコップを入れて土を持ち上げるように掘り、手で取り出す。掘った跡をもう一度かき回して残りを探す。土を軽く払うだけで洗わず、日陰に広げて2-3時間表面を乾かす(2時間の直射日光でも緑化が始まる) |
| 仕分け | その場で4つに分ける。傷物はすぐ消費するか乾燥・でんぷん加工、病害物は畑の外へ出して廃棄、貯蔵品はキュアリングのあと本貯蔵、種芋候補(30-50gの健全なもの)は別に保管 |

| 採種 | 基準 |
|:---|:---|
| 選別 | 30-50g(卵ほど)で病斑・傷・柔らかさのないもの。生育中にモザイク模様や縮れた株、とくに小さい株に棒を立てて目印にし、その株のイモは食べるほうに回して種芋として残さない(病株の淘汰。ウイルスは塊茎でそのまま次の世代に移るので、薬なしで劣化を遅らせるもっとも効果的な手段) |
| 保管 | 2-4℃、湿度85-90%、湿った砂やおがくずに埋めて弱い通風、2週間に1回点検して腐ったものを取り除く。種芋は弱い光を許す(緑化するとネズミや虫が食べにくくなる)。食用のイモと絶対に同じ仕切りに置かず、目立つように印をつける |
| 劣化への対処 | 種芋用の畑だけを涼しい高地に置き、通常の収穫より2-3週間早く掘り、明るい色のマルチとナスタチウムでアブラムシを減らし、ほかの地域の栽培者と種芋を交換する |
| 真正種子 | 緑色の実の中の種子は、大部分のウイルスを受け継がないので、劣化を断つ最後の手段。実生は親とまったく違い、最初の年は小さくそろわないので、その中の良いものを選んで塊茎でつないでいくため、さらに2年かかる。実は猛毒なので、種子をとる目的以外では絶対に食べない |

## 9. 貯蔵
&nbsp;&nbsp;&nbsp;貯蔵は3段階です。キュアリング(10-15℃、湿度85-95%、暗く弱い通風、1-2週間)で傷にコルク層をつくり腐敗と水分の損失を防ぎ、本貯蔵(3-5℃、湿度85-95%、完全な暗闇、弱い通風、4-6か月)で呼吸と発芽を抑え、週1回点検して腐ったものを取り除きます。キュアリングを省くと貯蔵期間が半分以下に縮まります。0℃以下では凍害で柔らかくなり、10℃以上では芽が出ます。タマネギと同じ仕切りに置かず、家庭用の冷蔵庫は使いません。

| 方式 | 方法 | 期間 |
|:---|:---|:---|
| 土室貯蔵 | 水はけのよい土地を1.5-2m掘って屋根をかけ、通気口をつくる(0-4℃)。もっとも安定しているが労力が大きく、地下水位が高いと不可 | 4-6か月 |
| 穴・クランプ貯蔵 | スコップ1本で1日でつくれる。直径1.5m、深さ20-30cmに浅く掘り、乾いたわらを10cm敷いたあと、キュアリングを終えたイモを高さ60cm以内の盛り土の形に積み、乾いたわら20-30cmと土15-20cmをかぶせてたたき、頂上にわら束で通気口をつくる(ふさぐと熱と湿気がこもって数日で柔らかくなる)。開けると再びかぶせにくいので、一度に全部を取り出す(0-5℃) | 3-5か月 |
| 加工貯蔵 | 5mm以下に切って熱湯で1-2分ゆで完全に乾燥(ゆでないと褐変)するか、挽いて粉にする。すりおろして水に溶き、沈んだ沈殿だけを取って何度もすすいで乾かしたでんぷんは、切れ端と小さいイモをすべて回せ、かさが減り虫がつかない(100kgから12-18kg) | 乾燥片数か月-1年、粉1-2年、でんぷん数年 |

> **災害時の貯蔵戦略の標準は併用です。商品になるものは土室に入れて冬の食料にし、切れ端と小さいものはでんぷんと粉に回して数年分の備蓄にします。**

## 10. 調理と注意事項
| 注意 | 内容 |
|:---|:---|
| ソラニン、チャコニン | 皮が緑色に変わったもの、芽が出たもの、苦味やえぐみがあるものは含有量が非常に高く、傷・病んだ部分や小さくて未熟なものも高い。実と葉と茎は食べない。緑色の部分と芽やくぼみの周りは深くえぐり取り、広ければ丸ごと捨て、苦味があれば食べない。皮をむくだけでは足りない |
| 症状 | 摂取の数時間後に嘔吐、腹痛、下痢で始まり、重症では頭痛、めまい、神経症状。成人で致命的になることはまれだが、子どもと弱った人には危険 |
| 換気 | 密閉した貯蔵庫や地下の土室でイモが大量に腐ると有害なガスが出て酸素が減るので、入る前に戸を開けて十分に換気し、先にろうそくを入れて消えたら入らない |

> **加熱はソラニンを壊しません。ゆでても、焼いても、揚げても毒性はそのまま残ります。唯一の方法は、えぐり取るか捨てることです。**

| 調理 | 方法 |
|:---|:---|
| 燃料の節約 | 丸ごとゆでるなら皮つきで水に浸かるように入れて20-30分(栄養の損失が少ない)、蒸すなら水を少し入れて25-30分、2cm以下に切れば10-15分。保温調理は10分煮立てたあと火から下ろし、わらや毛布やもみ殻で厚く包んで40分置くと燃料が半分以下で済み、熱い灰に埋めて30-40分焼いたり、でんぷんを沸騰した湯に溶いたりしてもすぐ火が通る |
| 食べ方 | 皮ごと食べるほうがビタミンCと食物繊維の面で優れる。ゆで汁にはカリウムとビタミンが溶けているので汁として使う。生のジャガイモはでんぷんが消化されず腹痛を起こすので、必ず加熱する |
| 加工 | すりおろしたイモの水気を絞り、残ったかすと沈んだでんぷんを合わせた生地で、イモ餅やオンシミをつくって切れ端を余さず使う。水に浸して何週間も発酵させたあとでんぷんだけを漉し取る腐らせたイモは、においが強いがでんぷんの回収率が高い。ゆでて乾かした切片は水で戻して汁や粥に入れる |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵したイモと種芋の点検(週1回腐ったものを取り除き、貯蔵庫が0℃を下回らないように)。2月に種芋の選別、畑の計画、堆肥の切り返し |
| 3-4月 | 3月に種芋の切断とキュアリング、芽出しの開始(播種の20-35日前)、元肥と畝づくり。4月に春ジャガイモの播種(中部は上旬-中旬)、遅霜の予報が出たら土やわらで覆う |
| 5-6月 | 5月に出芽、1回目の土寄せ、追肥、草取り。6月に塊茎の肥大期の集中的な灌水、2回目の土寄せ、疫病の監視 |
| 7-8月 | 7月に春作の収穫(梅雨前に終えるのが目標)、キュアリング、貯蔵庫の整備。8月に南部で秋ジャガイモの播種(切らずに丸ごと)、高冷地の夏作の収穫 |
| 9-10月 | 9月に秋ジャガイモの生育管理と土寄せ、種芋用の畑を別に管理。10月に灌水を止め、貯蔵の準備、霜の前に収穫を終える |
| 11-12月 | 11月に秋ジャガイモの収穫、キュアリング、土室・穴での貯蔵(種芋は別)。12月に貯蔵の点検、でんぷん・乾燥の加工(貯蔵しにくいものから)、翌年の計画 |

> **ジャガイモは、緑色と芽と苦味をえぐり取るか捨て、ナス科を3-4年あけて回し、土寄せを欠かさず、収穫後にキュアリングをし、種芋を食用のイモと分けて保管する作物です。**
