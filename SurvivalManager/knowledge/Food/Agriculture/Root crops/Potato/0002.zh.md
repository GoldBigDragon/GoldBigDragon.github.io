&nbsp;&nbsp;&nbsp;马铃薯的综合等级为B，得分48.1分。按同一量表分情景看，挺过灾害初期的短期能力为S（50.6），跨越多年的长期自立能力为B（45.6），作为主食之外副食资源的副食价值为S（52.5）。短期比长期高5分，这一事实概括了马铃薯的性格：能快速提供食物，却不能让人长久撑下去。

### 1-3. 如何解读优势

&nbsp;&nbsp;&nbsp;获得A级以上的项目是生产力的三个项目，以及收获速度、设施负担、连作适应性、口味、韩国国内普及度和自家留种。这一组合的含义很明确：马铃薯只需在什么都没整理过的裸地上插上种薯，三个月内就能同时提供足以让人维持生存的热量和蛋白质。每㎡2,010kcal，是成年人一天所需热量自给基准线的0.77倍。换句话说，用130㎡出头、不到40坪（约132㎡）的地，几乎可以仅靠马铃薯供应一个人一年的大部分热量。

&nbsp;&nbsp;&nbsp;蛋白质密度达到A级，在薯类（块茎/块根）中十分罕见。同一张表中，甘薯和木薯这一项都是E级。马铃薯热量对蛋白质的比例为12%，超过了人体所需最低限10%。而且氨基酸评分超过90，没有谷物常见的赖氨酸不足问题。在灾害情形下肉类和豆类变得稀缺时，这种差异会在数月后体现在身体状态上。只吃甘薯的话，肚子饱了但肌肉会流失，马铃薯则不会如此。

> **把马铃薯当作主食时，最大的优势不是热量本身，而是随热量一同获得的蛋白质。**

### 1-4. 如何解读劣势

&nbsp;&nbsp;&nbsp;被评为E级的项目有三个：无合成投入产量保持率、非食用价值、种子寿命。其中对灾害应对而言最致命的是第一项和第三项。

&nbsp;&nbsp;&nbsp;无合成投入产量保持率17.6%，是瑞士一项长达40年的长期对比试验得出的实测数据。完全不施肥地块的马铃薯产量，只有常规地块的1/6左右。这个数字不仅包含缺肥造成的损失，也包含疫病无防治造成的损失。也就是说，在物流中断的情况下种植马铃薯，要做好平时能产300kg的地只产出50kg左右的心理准备。本文第5节和第9节篇幅特别长，原因就在这里：用草木灰和腐熟堆肥能把钾和磷补到什么程度，用波尔多液和农业防治能把疫病的发展拖延多久，决定着马铃薯种植的成败。

&nbsp;&nbsp;&nbsp;种子寿命为E级是性质不同的问题。马铃薯无法以干燥种子的形式保存，必须以活体块茎的状态延续到来年春天，期间一旦受冻、腐烂或发芽殆尽，来年就无法耕种。而且反复自家留种，蚜虫传播的病毒会不断积累，3-4年后产量就会明显下降。在平时，国家会供应无病种薯来掩盖这个问题，但一旦供应中断，就必须正面应对。第13节中介绍的顶芽选种和高冷地留种，正是应对之策。

&nbsp;&nbsp;&nbsp;防治自立度D级也需要一并考量。疫病没有治疗药物，在已经蔓延的地块里能做的，只是割除地上部分、阻止病菌下移到块茎这种程度。因此马铃薯种植的防治全部是预防性的：抗病品种、宽株距、高垄、早播、烧毁病残体。除这五项之外，事实上没有别的无药可用手段。

## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

&nbsp;&nbsp;&nbsp;马铃薯是茄科（Solanaceae）茄属（Solanum）的多年生草本植物，但栽培时按一年生处理。它与番茄、茄子、辣椒、烟草同属一家。这一事实不是浪漫，而是警示：它们共同携带疫病、青枯病、烟草花叶病毒、二十八星瓢虫。若在同一块地里并排种植或连作，就会相互助长彼此的病害。

&nbsp;&nbsp;&nbsp;马铃薯原产于横跨秘鲁和玻利维亚、的的喀喀湖周边的安第斯高原。这里的条件是：年平均气温低，昼夜温差大，土壤呈酸性，降雨集中在特定季节。马铃薯偏好pH 5.0-6.0的酸性土壤、在凉爽的夜间气温下容易形成块茎、对积水极度敏感的原因，全部都源于此。

### 2-2. 外形特征

| 器官 | 特征 |
|---|---|
| 叶 | 奇数羽状复叶，由5-7片小叶组成，表面有细毛 |
| 茎 | 直立或略呈蔓性，株高30-100cm，会分枝 |
| 根 | 须根系，属浅根性、分布浅。因此对干旱反应很快 |
| 花 | 白色、淡粉色、紫色等，5-6月开放，自花授粉和异花授粉均可发生 |
| 果实 | 形似未熟的小番茄的浆果，成熟后仍保持绿色，剧毒不可食用 |
| 块茎 | 地下茎（匍匐茎）顶端膨大形成的贮藏器官，是茎而非根 |

&nbsp;&nbsp;&nbsp;食用部分是茎而非根，这一点在实际操作中很重要。正因为是茎，所以有芽眼；也正因为是茎，见光后会产生叶绿素而变绿，并随之增加毒性生物碱。这正是必须进行培土、也必须让贮藏室保持完全黑暗的原因。

### 2-3. 生长阶段

| 阶段 | 时期 | 主要生理 | 重要养分 |
|---|---|---|---|
| 萌芽期 | 从播种到出苗 | 仅依靠种薯自身贮藏的养分发芽 | 依赖自身养分 |
| 茎叶生长期 | 出苗后约30天内 | 叶、茎、根不断扩展 | 氮、磷 |
| 块茎形成期 | 开花前后 | 地下茎顶端开始膨大 | 磷、钾 |
| 块茎膨大期 | 形成后至成熟前 | 块茎增大，淀粉不断积累 | 钾需求量最大 |
| 成熟期 | 茎秆变黄枯萎时 | 表皮硬化（skin set） | 忌氮肥过量 |

> **氮肥用在前期，钾肥用在后期。后期氮肥过量只会让叶片徒长，同时毁掉块茎形成和耐储性。**

&nbsp;&nbsp;&nbsp;块茎形成期由日照长度和夜间气温决定。夜间气温高时，植株不会形成块茎，只会持续生长叶片和茎。这正是盛夏平地马铃薯栽培失败的根本原因。高冷地之所以存在夏季栽培，也是因为夜间凉爽。

### 2-4. 每100克的营养成分

| 营养素 | 含量 | 备注 |
|---|:---:|---|
| 热量 | 66-85kcal | 因品种和烹饪方法而异 |
| 碳水化合物 | 14.8-19.6g | 大部分为淀粉 |
| 蛋白质 | 1.5-2.0g | 是必需氨基酸齐全的优质蛋白质 |
| 脂肪 | 0.1g | 几乎不含 |
| 膳食纤维 | 2.3g | 有助于维持饱腹感 |
| 钾 | 420mg | 参与电解质平衡与血压调节 |
| 维生素C | 9.7mg | 靠近薯皮的部分含量较多 |
| B族维生素 | 硫胺素、核黄素、烟酸、B6 | 是能量代谢所需 |

&nbsp;&nbsp;&nbsp;马铃薯的维生素C含量本身不及柑橘类，但因为被淀粉包裹，加热过程中损失相对较少。每天吃500g马铃薯，可满足维生素C推荐摄入量的近一半。在新鲜蔬菜断绝的冬季，正是这部分维生素C能预防坏血病。带皮煮可减少损失。
