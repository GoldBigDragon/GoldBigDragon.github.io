## 12. 收获

### 12-1. 判断时机

| 标准 | 内容 | 判定 |
|---|---|---|
| 叶与茎 | 从下部叶片开始变黄，全株开始枯萎 | 黄叶期，收获期将近 |
| 茎秆枯死 | 茎秆完全干枯死亡 | 枯死后1-2周再收获 |
| 表皮测试 | 用拇指摩擦块茎表皮不会脱落 | skin set已完成，可以贮藏 |
| 天气 | 晴朗干燥的天气持续2-3天后 | 土壤变干，伤口和沾土都较少 |

&nbsp;&nbsp;&nbsp;茎秆枯死后还要再等1-2周，是为了让薯皮变硬。薯皮尚未充分变硬的马铃薯，在收获和搬运过程中表皮会脱落，每一处伤口都会成为贮藏期间腐烂的起点。挖得稍早的马铃薯，味道或许不错，却无法用于贮藏。

&nbsp;&nbsp;&nbsp;不过也有例外。如果疫病已经蔓延，或预报即将进入韩国的梅雨季（6月下旬至7月），就不必再等，应立即割除地上部分，2周后再挖出。若继续留在地里，随雨水渗下的病菌会感染块茎。

### 12-2. 收获要领

| 顺序 | 内容 | 理由 |
|---|---|---|
| 1 | 先用镰刀割除地上部分的茎 | 若抓住茎往外拔，块茎会脱落留在土里 |
| 2 | 从距植株30cm处开始下锄或下铲 | 离得太近会挖伤块茎 |
| 3 | 像把土掀起来一样挖，用手取出薯块 | 硬拉会使薯皮脱落 |
| 4 | 再翻一遍挖过的地方，找出遗漏的薯块 | 遗留的薯块来年会自生并传播病害 |
| 5 | 轻轻拍掉泥土，不要用水冲洗 | 水分是贮藏期间腐烂的直接原因 |
| 6 | 摊在阴凉处晾2-3小时使表面变干 | 放在直射阳光下会开始变绿 |

> **不要把马铃薯摊在阳光下晾晒。哪怕只晒两个小时的直射阳光，表面也会开始变绿。**

### 12-3. 收获后的分类

&nbsp;&nbsp;&nbsp;挖出的马铃薯要当场分成四类。如果混放在一起，一个坏薯就会拖累其余所有薯块。

| 分类 | 标准 | 用途 |
|---|---|---|
| 破损品 | 被农具挖伤或表皮大面积脱落的薯块 | 立即食用，或在数日内加工成干制品或淀粉 |
| 病害品 | 有斑点、发软、异味的薯块 | 移出田外废弃，不可放在贮藏室附近 |
| 贮藏品 | 无伤口、个头中等以上的健康薯块 | 愈伤处理后进入正式贮藏 |
| 种薯候选 | 30-50g、健康且形状端正的薯块 | 单独装入容器分开保存 |

## 13. 种薯保存与留种

&nbsp;&nbsp;&nbsp;本节是马铃薯灾害应对中最薄弱的一环，也是最需要下功夫的部分。马铃薯无法以干燥种子的形式保存。如果不能把来年春天要种的种薯以活体状态延续下去，来年就没有收成。

### 13-1. 种薯挑选

| 标准 | 内容 | 理由 |
|---|---|---|
| 大小 | 30-50g，约鸡蛋大小 | 太小则前期长势弱，太大则消耗种薯量大 |
| 形状 | 呈现该品种固有形态的薯块 | 畸形可能是病毒或生理障碍的信号 |
| 状态 | 无病斑、无伤口、不发软的薯块 | 否则会成为贮藏期间的传染源 |
| 选株 | 在生长期给长势最健康的植株做标记，只从这些植株留种 | 这是在田间筛除带毒植株的唯一方法 |

&nbsp;&nbsp;&nbsp;在生长期巡视田地时，请在叶片呈花叶状或卷缩、以及特别矮小的植株旁插上标记棍。这些植株结出的马铃薯用作食用，不留作种薯，因为病毒会通过块茎原样传给下一代。这项操作称为病株淘汰，是在没有药剂的条件下延缓种薯退化的最有效手段。

### 13-2. 种薯保存

| 条件 | 目标 | 做法 |
|---|---|---|
| 温度 | 2-4℃ | 地窖或地下室中最凉爽的位置 |
| 湿度 | 85-90% | 埋入湿润的沙子或木屑中 |
| 光照 | 允许散射光 | 与食用薯不同，稍微见光反而更好 |
| 通风 | 保持微弱持续通风 | 排出乙烯和湿气 |
| 检查 | 每2周一次 | 立即挑出腐烂的薯块 |

&nbsp;&nbsp;&nbsp;之所以唯独对种薯允许见光，是为了反过来利用变绿这一特性。变绿的马铃薯茄碱增多，人不能食用，但同样程度上老鼠和虫子也不太爱啃食，还更耐腐烂。春天种植时是整块带皮种下的，所以不会有问题。不过必须把种薯放在与食用薯不同的位置，并做上醒目的标记。

> **种薯绝不能和食用薯放在同一处。在饥饿的情况下，误食变绿种薯的事故确实会发生。**

### 13-3. 退化及其应对

&nbsp;&nbsp;&nbsp;若持续自家留种，蚜虫传播的病毒会代代累积。3-4年后产量就会明显下降，此后会急剧崩溃。在平时，只要重新购买无病种薯即可解决，但在供应中断的情况下，必须用以下方法来延缓退化。

| 方法 | 内容 | 效果 |
|---|---|---|
| 病株淘汰 | 生长期标记有症状的植株，将其排除在种薯之外 | 最基础也最有效 |
| 高冷地留种 | 只把种薯专用地设在凉爽的高地 | 蚜虫密度低，感染速度较慢 |
| 提前收获 | 种薯用地比一般收获提前2-3周挖收 | 避开蚜虫增多的后期感染 |
| 蚜虫抑制 | 使用亮色覆盖物、旱金莲诱集、保护瓢虫 | 减少传毒媒介即可减少感染 |
| 种薯交换 | 与其他地区的种植者互换种薯 | 更换品系以稀释累积的病毒 |
| 使用实生种子 | 播种马铃薯果实中的真种子，以实生苗培育 | 病毒几乎不会随之传递 |

&nbsp;&nbsp;&nbsp;最后这种实生种子方式需要补充说明。马铃薯花谢后结出的绿色果实中，含有真正的种子。这些种子大多不会继承病毒，因此可以作为切断退化的手段。不过马铃薯遗传上高度杂合，实生苗长出的个体性状与母株完全不同。第一年会长出个头小且大小不一的马铃薯，须从中挑选优良个体，从第二年起改用块茎方式延续下去。虽然要多花2年时间，但这是种薯品系彻底崩溃时的最后手段。

> **马铃薯的果实本身剧毒，除留种用途外绝对不可食用。**

## 14. 毒性与注意事项

### 14-1. 茄碱与卡茄碱

&nbsp;&nbsp;&nbsp;马铃薯中天然含有茄碱和卡茄碱这类糖苷生物碱。它们本是马铃薯用来抵御虫害和霉菌的物质。正常的马铃薯中也存在微量，但不足以构成问题，而在以下条件下会急剧增加。

| 条件 | 危险度 | 理由 | 处理 |
|---|:---:|---|---|
| 表皮变绿的薯块 | 极高 | 见光后叶绿素与生物碱一同增加 | 将变绿部分深挖去除，范围大则整个丢弃 |
| 已发芽的薯块 | 极高 | 生物碱集中在芽及其周围 | 将芽及芽眼周围挖除 |
| 有苦味或麻涩味的薯块 | 极高 | 苦味本身就是生物碱的信号 | 请勿食用 |
| 伤口部位、病变部位 | 高 | 作为防御反应，生物碱会增加 | 予以挖除 |
| 个头小、未成熟的薯块 | 中等 | 未成熟块茎含量较高 | 应食用充分成熟的薯块 |
| 果实、叶、茎 | 极高 | 并非食用部位 | 请勿食用 |
| 正常的马铃薯 | 安全 | 含量不构成问题 | 可以带皮烹饪 |

&nbsp;&nbsp;&nbsp;中毒症状在食用后数小时内表现为呕吐、腹痛、腹泻，严重时会发展为头痛、眩晕和神经系统症状。对成年人而言致命的情况较少见，但对儿童和体弱的老人则很危险。

> **加热无法破坏茄碱。无论煮、烤还是炸，毒性都会原样保留。唯一的办法是挖除或丢弃。**

### 14-2. 贮藏室通风

&nbsp;&nbsp;&nbsp;在密闭的贮藏室里，如果马铃薯大量腐烂，腐败过程会产生有害气体并消耗氧气。进入密闭贮藏室或地下窖穴前，必须先打开门充分通风后再进入。先放入一支蜡烛、若火焰熄灭就不进入的老办法，至今依然有效。

## 15. 无冰箱贮藏

### 15-1. 贮藏的三个阶段

| 阶段 | 条件 | 期限 | 目的 |
|---|---|---|---|
| 1. 愈伤处理（curing） | 10-15℃，湿度85-95%，黑暗且微弱通风 | 1-2周 | 在伤口处形成木栓层，阻断腐烂和水分流失 |
| 2. 正式贮藏 | 3-5℃，湿度85-95%，完全黑暗，微弱通风 | 4-6个月 | 使呼吸作用降到最低并抑制发芽 |
| 3. 检查 | 每周1次 | 贯穿整个贮藏期 | 防止一个烂薯拖累全部 |

&nbsp;&nbsp;&nbsp;若省去愈伤处理，贮藏期限会缩短到一半以下。挖掘时形成的细微伤口若一直敞开，病菌就会从那里侵入，水分也会随之流失。在10-15℃的温暖环境中放置1-2周，伤口上方会长出木栓组织将其封合。完成这一过程后，才能移到阴凉处存放。

### 15-2. 无电力贮藏方式比较

| 方式 | 制作方法 | 温度 | 期限 | 优点 | 缺点 |
|---|---|---|---|---|---|
| 窖藏 | 在排水良好的地方挖1.5-2m深，盖顶并留通气口 | 0-4℃ | 4-6个月 | 最为稳定，整个冬天都能维持 | 挖掘劳动量大，地下水位高时无法采用 |
| 坑藏·堆藏 | 挖30cm深的坑，按稻草、马铃薯、稻草、土的顺序覆盖，堆成坟丘状 | 0-5℃ | 3-5个月 | 无需工具，一天就能建成 | 打开后难以重新封好，须一次性取完 |
| 沙层贮藏 | 在箱中把干沙和马铃薯层层铺放 | 环境温度 | 2-4个月 | 可阻断腐烂传染，适合少量存放 | 需要另外准备阴凉场所 |
| 稻草·稻壳保温 | 在凉爽的室内角落用稻草包裹堆放，完全遮光 | 5-10℃ | 1-2个月 | 无需额外设施 | 室温偏高时会发芽 |
| 朝北土窑·洞穴 | 利用现有地形 | 4-10℃ | 2-4个月 | 几乎不费劳力 | 湿度和鼠患较难控制 |

### 15-3. 坑藏的做法

&nbsp;&nbsp;&nbsp;当手头只有一把铁锹时，这是最现实可行的方法。

| 顺序 | 内容 |
|---|---|
| 1 | 选择不积水的高处，朝北的坡地较好 |
| 2 | 挖直径1.5m、深20-30cm的浅坑 |
| 3 | 坑底铺10cm厚的干稻草，隔绝地面湿气 |
| 4 | 将完成愈伤处理的马铃薯堆成坟丘状，高度不超过60cm |
| 5 | 用干稻草把整堆覆盖至20-30cm厚 |
| 6 | 再盖15-20cm厚的土，拍实表面使雨水能顺势流走 |
| 7 | 在顶部竖一束稻草作通气口，一旦堵塞内部就会腐烂 |
| 8 | 在四周挖排水沟 |

&nbsp;&nbsp;&nbsp;通气口是关键。马铃薯在贮藏期间也在呼吸，会散发热量、水蒸气和二氧化碳。若完全密闭，内部温度升高、湿气积聚，几天之内就会整堆变软腐烂。顶部的稻草束正是一种既能透气又能挡雨的结构。

### 15-4. 贮藏条件详解

| 条件 | 目标 | 偏离时 |
|---|---|---|
| 温度 | 3-5℃ | 0℃以下会因冻害而变软；10℃以上会发芽 |
| 温度下限须知 | 长期存放于4℃以下 | 淀粉会转化为糖分而变甜，油炸时会发黑焦糊 |
| 湿度 | 85-95% | 偏低会皱缩，偏高会长霉 |
| 光照 | 完全黑暗 | 即使微弱光线也会导致变绿 |
| 通风 | 微弱且持续 | 堵塞会积热积湿，过强则会干缩 |

| 注意事项 | 理由 |
|---|---|
| 不与洋葱放在同一处 | 洋葱释放的气体会加速马铃薯腐烂 |
| 与苹果同放可抑制发芽 | 苹果释放的乙烯能抑制发芽，但也会同时加速老化 |
| 禁用家用冰箱 | 温度过低且过于干燥，不适合马铃薯 |
| 每周检查1次 | 一个烂薯会迅速感染周围薯块 |

### 15-5. 通过加工实现超长期贮藏

| 方法 | 步骤 | 期限 | 备注 |
|---|---|---|---|
| 冻干（chuño） | 夜间冷冻、白天踩踏挤出水分，重复此过程1周以上后彻底晒干 | 可存数年 | 安第斯高原的传统方法，只适用于夜间气温降到零度以下的地区 |
| 切薄片晒干 | 切成5mm以下薄片，在沸水中焯1-2分钟后彻底晒干 | 数月至1年 | 不焯水会褐变，贮藏中会变质 |
| 提取淀粉 | 磨碎后加水搅散，只取沉淀的淀粉反复漂洗后晒干 | 可存数年 | 体积和重量都会减小，也几乎不生虫 |
| 磨粉 | 将完全晒干的薯片用石臼或石磨磨碎 | 1-2年 | 需要密封保存并配合干燥剂 |

&nbsp;&nbsp;&nbsp;提取淀粉在灾害情况下尤其有用，因为可以把削去伤口或病斑后剩下的碎块、以及不易贮藏的小马铃薯，全部转化为淀粉。方法如下：把带皮磨碎或擦碎的马铃薯用布包住，放入水中揉搓。出现白色浆水后静置30分钟到1小时使其沉淀。倒掉上层清水，加入清水再次沉淀，如此反复三四次。最后把剩下的白色沉淀摊开彻底晒干，就是马铃薯淀粉。100kg马铃薯大约能提取出12-18kg淀粉。

> **灾害贮藏的标准策略是双管齐下：良品入窖作为过冬口粮，碎块和小薯则加工成淀粉和粉，制成可存数年的储备。**

## 16. 烹饪与加工

### 16-1. 省燃料的烹饪方法

| 方法 | 燃料消耗 | 步骤 | 备注 |
|---|:---:|---|---|
| 整个煮 | 中等 | 带皮没入水中煮20-30分钟 | 带皮煮可减少营养流失 |
| 蒸 | 少 | 只加少量水，用蒸汽蒸熟，25-30分钟 | 比煮更省水省燃料 |
| 切小块煮 | 少 | 切成2cm以下只需10-15分钟 | 表面积增大，更快熟透 |
| 余热焖煮 | 极少 | 煮10分钟后熄火，用厚布包裹焖40分钟 | 属于保温烹饪，可将燃料消耗降到一半以下 |
| 埋灰烤 | 极少 | 埋入生火后余下的热灰中30-40分钟 | 利用做完其他饭菜后灶膛的余热 |
| 淀粉烹调 | 少 | 淀粉倒入沸水中即刻熟化 | 燃料效率最高 |

&nbsp;&nbsp;&nbsp;余热焖煮是在燃料稀缺情况下最有价值的技巧。只需把锅烧开10分钟后离火，用稻草、毯子、稻壳等厚厚包裹起来，内部温度就能在一小时以上保持在80度以上，继续把食物焖熟。这种方法尤其适合像马铃薯这样富含淀粉的作物。只要一个塞满稻草的木箱，就是足够用的工具。

### 16-2. 烹饪注意事项

| 项目 | 内容 |
|---|---|
| 薯皮 | 若是正常的马铃薯，带皮食用在维生素C和膳食纤维方面更有优势 |
| 变绿部位 | 必须深挖去除，仅削皮是不够的 |
| 煮薯水 | 钾和维生素已溶入水中，宜作为汤汁一并利用 |
| 生马铃薯 | 淀粉无法消化，会引起腹痛，须务必煮熟 |
| 放凉的马铃薯 | 抗性淀粉增多，血糖上升会更平缓 |

### 16-3. 兼作贮藏的加工

| 加工 | 步骤 | 结果 |
|---|---|---|
| gamja-tteok（土豆年糕）·gamja-ongsimi（土豆疙瘩汤） | 挤出磨碎马铃薯的水分，将剩余薯渣与沉淀的淀粉混合揉成面团 | 可将碎马铃薯物尽其用 |
| 马铃薯发酵（沤制马铃薯） | 浸水发酵数周后，只滤取淀粉 | 江原道的传统方法，气味浓烈但淀粉回收率高 |
| 马铃薯干片 | 焯水后切薄片晒干 | 用水泡发后加入汤或粥中 |
| 马铃薯粉 | 将晒干的薯片磨碎 | 与谷物粉混合用于制作面团 |

| 1月 | 检查贮藏的马铃薯，确认种薯状态 | 每周1次清除烂薯，贮藏室温度不低于0度 |
| 2月 | 挑选种薯，规划田块，翻堆堆肥 | 韩国南部从下旬开始播种 |
| 3月 | 种薯切块与愈伤，开始催芽，施基肥并起垄 | 催芽须在播种前20-35天开始 |
| 4月 | 春马铃薯播种（韩国中部上旬至中旬），防范霜冻 | 预报晚霜时用土或稻草覆盖 |
| 5月 | 出苗，第1次培土，追肥，除草 | 是与杂草竞争最脆弱的时期 |
| 6月 | 块茎膨大期集中灌溉，第2次培土，监测疫病 | 多雨时须每天查看叶片 |
| 7月 | 春季栽培收获，愈伤处理，整理贮藏室 | 目标是在梅雨季前完成收获 |
| 8月 | 秋马铃薯播种（韩国南部），夏季栽培收获（高冷地） | 秋马铃薯整薯种植，不切块 |
| 9月 | 秋马铃薯生长管理，培土 | 种薯专用地须单独管理 |
| 10月 | 秋马铃薯停止灌溉，准备贮藏 | 须在降霜前完成收获 |
| 11月 | 秋马铃薯收获，愈伤处理，窖藏·坑藏 | 种薯须单独保存 |
| 12月 | 检查贮藏情况，加工淀粉·干制品，规划来年 | 优先把不易贮藏的薯块转为加工 |

### 17-1. 不可忘记的五件事

| 项目 | 内容 |
|---|---|
| 变绿与发芽 | 变绿、发芽、苦味都是茄碱的信号，加热无法消除，须挖除或丢弃 |
| 禁止连作 | 茄科作物须间隔3-4年，第三年会突然崩溃 |
| 培土 | 不花成本就能同时提高产量、安全性和抗病性 |
| 愈伤处理 | 收获后进行1-2周的愈伤处理可使贮藏期延长一倍 |
| 种薯 | 须与食用薯分开保存，只从健康植株留种 |
