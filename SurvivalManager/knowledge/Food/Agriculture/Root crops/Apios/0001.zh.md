## 引言
&nbsp;&nbsp;&nbsp;美洲土圞儿（Apios americana）是原本在北美洲东部河边和潮湿森林边缘自行生长的豆科藤本植物。北美原住民长期挖来食用，但收获麻烦，第一次收获要等很久，始终没有成为大规模种植的作物，在韩国也没有进入国家统计。然而在以电力、物流和化学投入品全部中断为前提的评估中，它的综合等级为SS（67.7分，有效183种中第1位），排在谷物和土豆之上。平时的农业以肥料、农药和机械可以随意使用为前提，比拼单位面积产量，但一旦问到没人施肥、没人打药、没人翻地时这种植物能否持续产出食物，排名就颠倒了。它是豆科，靠根瘤菌自己制造氮；是多年生，种一次每年都会重新长出；地下块茎在零下20℃以下也能越冬；不需要防治；热量中蛋白质的比例为13.9%，是根茎·块茎类中最高的。不过，没有国家层面的产量统计，评估表的许多项目不是实测，而是用推测值和替代值填充的，所以不能把优势的大小照数字原样相信。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | SS | 67.7 |
| 短期 | SS | 67.0 |
| 长期 | SS | 68.5 |
| 副食 | SS | 65.7 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：持续性、施肥、设施负担、温度幅度、耐寒性、防治自立度、连作适应性、整地·挖掘能量。S：单位面积热量、口味、自留种。A：蛋白质密度、水消耗量、产量稳定性。B：烹调·加工要求度、无合成投入产量保持率 |
| 劣势 | E：种子寿命。D：微量营养素、收获速度、光照。C：病虫害压力、耐储性、非食用价值、国内种植普及度 |

> **灾害应对评估衡量的不是精心照料时能收多少，而是没人照料时还剩多少。美洲土圞儿胜过谷物的原因，全在这句话里。**

&nbsp;&nbsp;&nbsp;带SS的八个项目，问的都是人必须投入什么，而美洲土圞儿对所有这些的回答都是什么都不用投入。尤其是氮，它是灾害中最先断供的养分，也是谷物在无投入条件下崩溃的首要原因，而美洲土圞儿根本不经过这个瓶颈。挖掘能量分摊到10年，投入的挖掘能量所换回的热量是161倍（土豆10.6倍），无合成投入产量保持率为B（45.1%），远高于土豆的E（17.6%）。另一方面，也要一并看到：收获速度D，意思是种下后要等两三年才能正经收获；微量营养素D；国内种植普及度C（只有一两个道能找到种块茎）；以及遮光40%产量就减半的光照D。各项目的等级见“灾害应对作物评价结果”文档。

| 项目 | 显示值 | 实际依据 |
|:---|:---|:---|
| 单位面积热量 | 2,000kg/1,000㎡ | 国内试验栽培的报告值为500-800kg。接近良好条件下的上限假设 |
| 病虫害压力 | 减产率48.9% | 借用整个豆科的值得出的推测值 |
| 无合成投入产量保持率 | 45.1% | 把土豆的有机栽培产量比套用到整个根茎·块茎类的替代值 |

&nbsp;&nbsp;&nbsp;固氮、地下越冬和持续性是由植物本性得出的事实，不会动摇，但单位面积产量、产量稳定性以及病害流行时的损失，没人认真统计过。所以不能把全部粮食押在美洲土圞儿一种作物上，而且灾害发生当年的秋天它不会提供食物，所以要在平时提前种上。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 豆科土圞儿属多年生藤本植物 |
| 叶、藤 | 小叶5-7枚的羽状复叶。藤蔓长到3-5m，没有可缠绕的对象就在地面爬行缠成一团 |
| 块茎、根瘤 | 沿着地下茎，从鹌鹑蛋到鸡蛋大小的块茎像念珠一样串生20-50个。须根上有小米粒大小的根瘤 |
| 花、荚 | 6-8月开香味浓的红紫色到粉褐色花。5-10cm的荚有的年份不结 |

&nbsp;&nbsp;&nbsp;种下后约15天，块茎的芽眼里长出新芽，藤蔓伸展，8-9月块茎膨大（钾的需求最大）。第一年把力气用在扎根和伸展地下茎上，长不到可收获的大小；从第二年秋天起可以食用，第三年产量稳定。每100g含热量175kcal（土豆的2.5倍）、碳水化合物约38g、蛋白质6.10g（土豆的3倍，必需氨基酸齐全）、脂肪约1g，膳食纤维约为土豆的5倍，钙约30倍，铁约4倍，维生素C约5倍。因为微量营养素为D，要搭配叶菜或南瓜这类胡萝卜素多的作物。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 生长5-30℃（适宜25-30℃）。低于5℃生长停止但不会死，超过30℃只长藤蔓，块茎膨大变慢。出苗需平均气温15℃以上。零下20℃以下仍能在地下存活，在韩国全境不用任何措施即可越冬 |
| 光照、土壤 | 每天4-6小时以上（适宜8小时以上）。pH4.5-7.0（适宜5.0-6.0，碱性土壤中铁、锰的吸收受阻，叶片发黄）。砂壤土-壤土（黏土过重块茎会畸形） |
| 水 | 适宜经常保持湿润，能耐相当长时间的淹水（在薯类中非常耐过湿）。干燥会使块茎变小。总蒸散量约400mm（土豆500-700mm） |

&nbsp;&nbsp;&nbsp;25℃的温度幅度，是冷年和热年都不会彻底绝收的保险。美洲土圞儿的价值不在于好田，而在于把其他作物用不了的边角地变成粮食产地，所以水边、沟边、田埂、山坡下潮湿的坡脚（有机物堆积，不需要肥料）、田边和围栏（用作支架）都适合。要避开完全背阴处或林中、石灰质碱性土壤（pH7以上），以及需要经常翻耕的田地中央。

| 品系 | 特点 | 产量（kg/1,000㎡） |
|:---|:---|:---|
| 红色品系（Red-vine） | 早熟，块茎数量多。适合霜期早的地方 | 500-800 |
| 绿色品系（Green-vine） | 晚熟，块茎数量少但个头大，适合作种块茎 | 500-700 |

&nbsp;&nbsp;&nbsp;国内普及度为C，灾害中几乎没有挑选品系的余地。平时提前占一块地种上，每年会自己繁殖，现在的十个块茎几年后就能变成几百个种块茎，这是最便宜的准备。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 3月翻耕20-30cm深（越深块茎越大），垄高30cm以上，排水沟深30cm以上。用木板或沟渠分区，防止地下茎越到邻田，并覆盖稻草或落叶 |
| 施肥（1,000㎡） | 不施石灰（镁石灰120kg仅用于纠正强酸性）。氮8kg、磷12kg、钾12kg、腐熟堆肥1,000kg（全部作基肥）。氮给多了，根瘤菌会变懒、只长藤蔓、块茎变小，所以不是帮助而是妨碍 |
| 灾害替代肥料 | 木灰（每㎡一小撮薄撒，过多会抬高pH而有害）、沤制6个月以上的堆肥、骨粉（只作基肥）、尿液稀释10倍、落叶和草覆盖5-10cm。首次种植的地块，把种过美洲土圞儿或豆类的田里的土取一小撮拌进种植穴，接种根瘤菌 |
| 种块茎 | 3月刚挖出的（比秋天挖出后保存的好）、5g左右、结实无皱、芽眼突起明显的块茎。剔除有黑斑或变软的。先催芽再种，出苗整齐 |
| 种植 | 4月上旬-中旬晚霜过后、平均气温15℃左右时种植。深度5-7.5cm，种块茎间距30cm，垄距60-75cm（每1,000㎡约3,300个）。轻轻压实后浇水。出苗约需15天（晚的要一个月），不要急着挖开看 |

> **种植方向是最容易失败的地方。长出茎的上端钝圆、突起聚集，长出根的下端光滑而尖，尖的一头朝下。拿不准就横着放倒种。放倒种它会自己找方向，倒着种则会死掉。**

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 种植到营养生长期（5-7月） | 浇到土壤不干的程度，自然降水足够，干旱时补充（此时的干燥可以恢复） |
| 块茎膨大期（8-9月） | 充分灌水（唯一决定产量的关键时期，遇空梅年块茎长不粗） |
| 成熟·收获期（10月以后） | 停止灌水（外皮变硬，耐储性提高） |

| 管理 | 方法 |
|:---|:---|
| 支架 | 沿垄每隔2m立一根支柱，在1.8-2m高度用黄瓜网或绳子拉成格子。藤蔓长到30cm左右时挂一次，支柱底部打入土中30cm以上。没有黄瓜网的话，隔一行种玉米或向日葵当支架，或者种在围栏旁 |
| 防台风 | 预报发布前给支柱底部培土，并从一列两端的木桩拉斜拉绳。8月的台风主要是雨害，先疏通排水沟；9月的台风雨和强风一起来，优先固定支柱 |
| 其他管理 | 除草只在5-6月初期做（藤蔓覆盖地面后杂草减少）。7-8月摘花能让更多养分流向块茎，摘下的花晾干后泡茶。每年一次剪掉伸出分区之外的地下茎 |

## 6. 病虫害与养分问题
&nbsp;&nbsp;&nbsp;病虫害压力为C，但防治自立度为SS。这意味着没有已知的那种像土豆晚疫病或木薯花叶病那样一旦传入就全军覆没的病害，而且如果大规模种植，可能会出现美洲土圞儿特有的病虫害。

| 病虫害 | 症状与条件 | 不用药的防治 |
|:---|:---|:---|
| 蚜虫、红蜘蛛 | 夏季高温期在新芽和叶背吸汁 / 高温干燥期叶片变粗糙并出现银白色斑点 | 用水冲洗，喷稀释的肥皂水（草木灰水或天然皂用水稀释500倍），木醋液200-500倍，保护瓢虫 / 向叶背喷水提高湿度 |
| 细菌性斑点病、白粉病 | 梅雨季叶片出现黑斑 / 夏末叶面出现白粉 | 保证通风，摘除病叶烧掉，用支架把藤蔓架高 / 牛奶用水稀释10倍后喷洒 |
| 田鼠、鼹鼠、野猪 | 冬春啃食地下块茎 / 秋冬刨地取食 | 清除田边杂草，在分区周围埋木板 / 围栏，阻断气味 |

&nbsp;&nbsp;&nbsp;灾害中最具威胁的不是霉菌或细菌，而是野兽。留在土里的块茎对野猪和田鼠来说也是整个冬天敞开的粮仓，而且人挨饿的年头野兽也挨饿，所以要在储存区周围围上围栏，并把一部分收获量另外挖出来搬进室内，分散风险。

| 症状 | 原因与措施 |
|:---|:---|
| 藤蔓旺长但块茎小 | 氮过剩，是美洲土圞儿上最常见的问题。7月前后稍微刨开须根，若有小米粒大小的粉红色根瘤、切开后里面发红，说明固氮活跃，应停止施氮，并用木灰补充钾 |
| 下部叶片褪成浅绿色，没有根瘤 | 缺氮（共生失败）。少量浇施稀尿液，并拌入种过美洲土圞儿或豆科的田里的土重新接种 |
| 叶片发紫 / 边缘变褐焦枯 / 只有叶脉是绿的 | 缺磷 / 缺钾 / 缺铁或缺镁（pH7以上）。骨粉和木灰 / 木灰 / 用腐叶土和堆肥降低pH |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 玉米·向日葵（成为活支架，美洲土圞儿留下氮）、叶菜类（第二年直接用上留下的氮）、果园下（藤蔓抑制杂草并提供氮） |
| 一般 | 根菜类（与地下茎混在一起，收获麻烦） |
| 差 | 经常翻耕的田、南瓜·黄瓜等其他藤本作物（缠在一起，双方都难以收获） |

&nbsp;&nbsp;&nbsp;美洲土圞儿给邻近作物的最大礼物是氮。它是多年生，这种积累逐年叠加，种过几年的地块交给其他作物，从第一年起就长得好。轮作几乎不适用（连作适应性SS），同一块地长期种下去是基本做法；换区时的顺序是美洲土圞儿（5-10年）→ 叶菜或谷物 → 根菜类 → 再回到美洲土圞儿，清除后的地块适合种白菜、菠菜这类用氮多的作物。哪怕只留下指甲盖大的一小块块茎，第二年也会发芽，所以要种在田边、围栏旁、沟边这类能长期让出来的地方。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 种后2-3年起（第一年不挖）。从藤蔓变黄枯死的11月中旬到次年3月随时可挖，在土里不会变坏，反而部分淀粉转化为糖，味道更好。种块茎在次年3月挖，花在8月上旬-中旬（盛开前）采 |
| 要领 | 从距植株30cm以上的外侧往里挖，用手顺着地下茎，把像念珠一样串连的块茎提起来。不要用铁锹猛劈（受伤的块茎不能储存）。只轻轻抖掉泥土、不要水洗（沾水几天就会变软，所以吃前再洗），只挖需要的量，其余用土盖好留着 |
| 处理 | 大的当场吃或短期储存，中等的晒干·磨粉加工，5g左右的单独收集作种块茎，受伤的最先吃 |

| 留种 | 标准 |
|:---|:---|
| 种块茎 | 种子寿命为E，但土里的块茎本身就是活的种子库，每年自己增殖。把5g左右的小块茎在次年3月刚从土里挖出后2周内种下。虽然是无性繁殖，但没有大病，所以世代退化几乎没有（和土豆不同） |
| 需要保存时 | 埋进盛土的花盆5-10cm深，放在不结冰的地方可到春天；用湿报纸包好放在凉爽处可保存2-4周 |
| 种子繁殖 | 后代性状与母本不同，不实用；但只靠无性繁殖延续，整块田会变成同一个个体，致命的病害流行时会一下子垮掉。灾害持续多年时，把变褐干枯的荚里的种子浸泡一天或划伤种皮后种下，另外培育几株实生苗 |

## 9. 储存
&nbsp;&nbsp;&nbsp;美洲土圞儿储存最大的敌人是干燥。木栓层很薄，块茎干了就会死，所以必须保持湿度90%以上，常温保存实际上最多2-3周。

| 方式 | 方法 | 期限 |
|:---|:---|:---|
| 原地储存 | 不挖出来，留在土里，初霜后清除藤蔓，盖上20-30cm的稻草或落叶（为防止土地冻得像石头一样挖不动）。不需要电力、设施和劳动，新鲜度最高，但会成为田鼠和野猪的目标 | 整个冬天，最长数年 |
| 沙层储存 | 在箱子里把湿沙和块茎一层层交替放入，放在0-4℃，沙干了就洒点水 | 2-3个月 |
| 地窖、坑储存 | 地窖在排水好的地方向下挖1.5m以上，做屋顶和通气口，保持湿度85-95%（3-4个月）。坑挖成直径1-1.5m、深30cm，铺干稻草，把块茎堆成坟包状，中间填入湿沙或腐叶土防止干燥，盖上20-30cm稻草和15cm土后，在顶部用草束做通气口，周围挖排水沟 | 2-4个月 |
| 干燥片、粉、淀粉 | 切成3-5mm，用开水焯2-3分钟后彻底晒干（不焯会褐变，抑制成分残留）。磨好的粉放进加了灰或木炭的密封容器，淀粉是磨碎后加水搅开、沉淀，沉淀物多次冲洗后晒干，连边角料和受伤的块茎都能用完 | 片6个月-1年，粉1-2年，淀粉数年 |

> **储存策略的基本是分散。大部分留在地里当冬季粮食，一部分挖出来做成干片和粉，用来防备野兽和严寒。**

## 10. 烹调与注意事项
| 注意 | 内容 |
|:---|:---|
| 必须煮熟 | 这不是龙葵碱（茄科成分）的问题，而是豆科共有的胰蛋白酶抑制剂和凝集素，生吃会消化不良，引起腹痛、恶心、腹泻。无法凭肉眼判断是否煮透，所以要在开水或蒸锅中充分煮30分钟以上 |
| 皂苷 | 是苦味和泡沫的来源，倒掉煮的第一锅水就会减少。少量无害 |
| 过敏 | 因为是豆科，对花生或大豆过敏的人，先少量试吃 |

| 烹调 | 方法 |
|:---|:---|
| 蒸、煮 | 蒸时只放少量水，用蒸汽蒸30分钟（味道浓，营养损失少）。煮时让水没过块茎煮30分钟，倒掉第一锅水能减轻苦味，也最可靠地去除抑制成分 |
| 节省燃料 | 只煮10分钟的话里面会残留抑制成分，所以不缩短时间，而是把热量闷住。煮沸15分钟后，连锅用稻草或厚布裹住放1小时以上，燃料可减半以上。埋进热灰中烤30-40分钟，或者把粉倒入开水中搅开，立即煮熟 |
| 口味、吃法 | 像栗子和土豆混合的香味。煮熟后皮能用手剥掉，带皮吃也无妨。煮着吃粉糯，烤着吃有嚼劲 |
| 加工 | 把煮后晒干的片磨成粉，与谷物粉混合做面团和粥；把煮熟的块茎在2-3%盐水中乳酸发酵1-2周做成的酱菜，能减轻消化负担（不要生着发酵）。花晾干后泡茶 |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 只挖需要吃的量（地冻时先拨开稻草再挖），检查储存的块茎。2月翻堆堆肥，备好支架材料，选定新分区的位置 |
| 3-4月 | 3月采集并挑选种块茎，翻耕，施基肥并起垄。4月上旬-中旬种植种块茎（尖的一头朝下），覆盖 |
| 5-6月 | 5月确认出苗，设置支架和网，除草（藤蔓长到30cm左右时挂到网上）。6月引蔓，开始开花 |
| 7-8月 | 7月除草收尾，检查根瘤，干旱时灌水，开始摘花。8月采花，块茎膨大期集中灌水，防台风（对产量最重要的月份） |
| 9-10月 | 9月继续灌水，防台风（固定支柱），清理边界外的地下茎。10月停止灌水，观察藤蔓变黄（不要着急） |
| 11-12月 | 11月清除藤蔓，第一次收获，盖20-30cm稻草。12月收获所需的量，晒干和磨粉加工（为防兽害，把一部分转移到室内） |

> **美洲土圞儿是这样一种作物：平时提前种上（第一次收获在两三年后），尖的一头朝下种，必须煮30分钟以上再吃，不洗、留在土里或湿沙中保存，由于难以清除，要划定边界，种在可以长期让出的地方。**
