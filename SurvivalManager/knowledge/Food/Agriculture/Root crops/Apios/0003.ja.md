## 3. 栽培環境

### 3-1. 限界値と最適値

| 項目 | 限界値 | 最適値 | 外れた場合 |
|---|---|---|---|
| 生育温度 | 5-30℃ | 25-30℃ | 5℃を下回ると生育は止まりますが枯れはしません。30℃を超えるとつるばかり伸びて塊茎の肥大が鈍ります |
| 越冬温度 | 氷点下20℃以下まで地中で生存 | - | 韓国全土で何の対策もせずに越冬します。USDA 4-9地帯 |
| 出芽条件 | 平均気温15℃以上 | - | それを下回ると芽は出ず、地中で待機します |
| 光量 | 1日4-6時間 | 1日8時間以上 | 40%遮光で収量が半分に落ちます。耐えはしますがよく育つわけではありません |
| 土壌pH | 4.5-7.0 | 5.0-6.0 | アルカリ性では鉄とマンガンの吸収が妨げられ、葉が黄色くなります |
| 土壌 | 砂壌土-壌土 | 有機物の多い砂質壌土 | 粘土質が強いと塊茎が変形し、掘り取りにくくなります |
| 水分 | 冠水にかなりの期間耐える | 常に湿った状態 | 乾燥すると塊茎が小さくなります。いも類（塊茎・塊根）の中でも過湿に非常に強い部類です |
| 総蒸発散量 | - | 作期全体で約400mm | ジャガイモの500-700mmより少ないです |

&nbsp;&nbsp;&nbsp;温度適応幅25℃は、この表の中で最も注目すべき数字です。ジャガイモの幅は10℃、キャッサバも10℃であるのに対し、アピオスは5℃から30℃まで耐えます。これは、涼しい年でも暑い年でも完全にだめになることはないという意味です。災害時に天気予報がなく、異常気象が頻発する状況では、幅が広いということ自体が一種の保険になります。ある年の気候が異常だからといって、畑全体が収穫ゼロになる事態は起こりにくくなります。

### 3-2. 災害時の立地選び

| 条件 | 判断 |
|---|---|
| 水辺・溝端・田んぼの畔 | 最も適しています。他の作物が過湿で使えない土地をアピオスなら使えます |
| 山の斜面下の湿った裾野 | 適しています。有機物が流れ込んで堆積した場所なので、肥料が要りません |
| 畑の縁・垣根 | 適しています。垣根を支柱として使え、他の作物との境界も分けられます |
| 完全な日陰・森の中 | 避けます。耐えはしますが、収量が半分以下に落ちます |
| 石灰質アルカリ土壌 | 避けます。pH7以上で生育が目に見えて悪くなります |
| 頻繁に耕す必要がある畑の真ん中 | 避けます。多年生のため、同じ場所を長く空けておく必要があります |

&nbsp;&nbsp;&nbsp;災害時には畑はいつも不足します。ですからアピオスの本当の価値は、良い畑でたくさん収穫できることにあるのではなく、他の作物が使えない余り地を食料生産地に変えることにあります。水はけが悪くジャガイモやサツマイモが腐ってしまう場所、山裾の半日陰、溝端の細長い帯状地。こうした場所にアピオスを植えれば、普段は何も生み出さなかった面積から熱量が生まれます。

> **アピオスは良い畑を占有するための作物ではなく、悪い土地を食べられる土地に変える作物です。**

## 4. 品種

### 4-1. 二つの系統

&nbsp;&nbsp;&nbsp;韓国国内に導入され試験栽培されているアピオスは、大きく赤色系統と緑色系統に分かれます。つるの色で区別され、品種というよりも系統と呼ぶ方が正確です。正式に登録された品種体系が確立されていないためです。

| 系統 | 特徴 | 収穫量(kg/1,000㎡) | 災害適合度 |
|---|---|:---:|:---:|
| 赤色系統(Red-vine) | 早生で成熟が早いです。一株に付く塊茎の数が多いです | 500-800 | 高い |
| 緑色系統(Green-vine) | 晩生で塊茎の数は少ない代わりに、粒が大きくなる傾向があります | 500-700 | 普通 |

&nbsp;&nbsp;&nbsp;ここに記した収穫量500-800kgは、韓国国内の試験栽培で得られた値です。1節の評価で使われた2,000kgとは大きな差があります。この差をどう理解すべきかというと、アピオスの収量は植えてから何年経ったか、どれだけ密に植えたか、地下茎をどれだけ余さず掘り出したかによって、何倍にも変わるからです。2年目の最初の収穫は少なく、5年目の畑では地中が塊茎でいっぱいになります。栽培者は低い方の数字を基準に計画を立て、高い方が出ればその分を余裕として考える方が安全です。

### 4-2. 状況別の選択基準

| 状況 | 選択 | 理由 |
|---|---|---|
| 霜が早い地域、短い夏 | 赤色系統 | 早生なので霜が降りる前に塊茎が充実します |
| できるだけ早く食べたいとき | 赤色系統 | 成熟が早く塊茎の数が多いため、2年目の収穫がより良くなります |
| 種イモを大きく育てて増やしたいとき | 緑色系統 | 粒が大きく、種イモとして÷良いです |
| 系統を見分けられないとき | 入手できるもの | 両系統の栽培法と収量の差は大きくありません |

&nbsp;&nbsp;&nbsp;現実には、災害時に系統を選ぶ余地はほとんどありません。韓国国内での普及度がC、つまり一つか二つの道でしか入手できない作物だからです。したがって、品種選びよりも重要なのは、平時のうちにあらかじめ一区画を確保して植えておくことです。アピオスは一度植えておけば毎年自然に増えていくため、今10粒を植えておけば、数年後には数百粒の種イモを持つことになります。これがアピオスについてできる最も安上がりな備えです。

## 5. 畑の準備と肥料

### 5-1. 土づくり

| 項目 | 基準 | 理由 |
|---|---|---|
| 耕起 | 3月、深さ20-30cm | 塊茎が伸びる空間を作ります。深く耕すほど粒が大きくなります |
| 畝の高さ | 30cm以上 | 過湿に強い作物ですが、水が溜まると塊茎が傷みます |
| 排水路の深さ | 30cm以上 | 韓国の梅雨（チャンマ、6月下旬~7月）の冠水を排出します |
| 土壌酸度 | pH5-6を維持 | 無理に石灰で上げる必要はありません |
| 境界の処理 | 板や溝で区画します | 地下茎が隣の畑に広がるのを防ぎます |
| 被覆 | 稲わらまたは落ち葉でマルチング | 除草と保湿を兼ねます |

&nbsp;&nbsp;&nbsp;他のいも類（塊茎・塊根）作物と異なり、アピオスの畑を準備する際には石灰を入れません。ほとんどの作物はpH6.5前後を好むため酸性土壌に石灰をまきますが、アピオスはpH5-6が最適です。石灰が貴重な状況では、これは小さくない利点です。下の施肥表にある苦土石灰120kgは、強酸性に偏った畑を矯正する際の値であり、pH5以上であれば入れなくても構いません。

### 5-2. 標準施肥量 (1,000㎡、300坪基準)

| 肥料 | 施肥量 | 時期 |
|---|:---:|---|
| 窒素(N) | 8kg | 元肥。マメ科のため少なめに施します |
| リン酸(P) | 12kg | 全量元肥 |
| カリウム(K) | 12kg | 全量元肥 |
| 堆肥 | 1,000kg | 完熟堆肥、全量元肥 |
| 苦土石灰 | 120kg | 強酸性土壌を矯正する場合のみ |

&nbsp;&nbsp;&nbsp;窒素が8kgとリン酸・カリウムより少ないことが重要です。マメ科作物に窒素を多く与えると根粒菌が怠けるようになります。窒素が豊富にあると、植物はあえて共生関係を維持する理由がなくなるため根粒が減り、結果として自立する力が落ちます。しかも窒素が過剰だとつるばかり茂って塊茎が小さくなります。アピオスに窒素をたっぷり与えることは、助けにはならずむしろ妨げになります。

### 5-3. 化学肥料がないとき - 災害時の代替肥料

| 代替資源 | 供給される養分 | 作り方と使い方 | 注意 |
|---|---|---|---|
| 草木灰 | カリウム、リン酸、カルシウム | 広葉樹の灰の方がカリウムが多いです。㎡当たりひとつかみずつ浅くすき込みます | アルカリ性のため多く入れるとpHが上がり、かえって害になります |
| 完熟堆肥 | 総合養分、有機物 | 落ち葉、草、糞尿を積んで6か月以上発酵させます | 未熟な堆肥は根を傷めます |
| 骨粉 | リン酸、カルシウム | 骨を焼いて砕いた後、堆肥に混ぜて1か月以上置きます | 効き目が遅いため元肥としてのみ使います |
| 薄めた尿 | 窒素、カリウム | 水で10倍に薄めて畝の間に施します | アピオスには最小限にとどめます。葉に直接かからないようにします |
| 落ち葉・草マルチング | 有機物、保湿 | 畝の上に5-10cm覆います | 腐りながら徐々に養分になります |
| 根粒 | 窒素 | 別の資源ではなく、植物自体が持つ能力です | 初めて植える土地には、アピオスを掘り取った跡の土をひとつかみ混ぜます |

&nbsp;&nbsp;&nbsp;最後の行がアピオスならではのコツです。根粒菌は、あらかじめ土の中にいなければ感染が起こりません。アピオスや他のマメ科作物を一度も植えたことのない土地では根粒ができにくく、初年度の生育が振るわないことがあります。すでにアピオスがよく育っている場所の土をひとつかみ持ってきて、植え付ける穴に混ぜ込めば接種効果が得られます。市販の接種剤がない状況で使える方法であり、ダイズやアズキを植えていた畑の土もある程度役立ちます。

> **マメ科作物にとって最も安上がりな投資は肥料ではなく、根粒菌が生きている土ひとつかみです。**

## 6. 種イモの準備と植え付け

### 6-1. 時期

| 区分 | 時期 | 備考 |
|---|---|---|
| 種イモの準備 | 3月 | 前年の秋に掘り上げておいたものより、3月に掘り出したものの方が良いです |
| 植え付け | 4月上旬-中旬 | 遅霜が終わった後、平均気温15度前後 |
| 出芽 | 植え付け後約15日 | 遅い場合は1か月かかることもあります。急いで掘り返さないようにします |

&nbsp;&nbsp;&nbsp;種用の塊茎は、秋に掘り上げて保管するよりも、翌年3月に土から掘りたてを使う方が良いです。アピオスの塊茎はコルク層が薄いため、常温に置くと水分が急速に失われますが、土の中にそのまま置いておけばそうした損失がありません。土そのものが貯蔵庫になるわけです。この原則は、貯蔵を扱う15節の要点と同じです。

### 6-2. 種イモの選別

| 項目 | 基準 | 理由 |
|---|---|---|
| 大きさ | 5g前後 | 小さすぎると初期生育が振るわず、大きすぎると種イモが無駄になります |
| 状態 | 硬くしわのないもの | 柔らかかったりしなびたりしたものは水分を失っており、発芽率が落ちます |
| 芽 | 突起がはっきりしているもの | 芽が死んでいる塊茎からは芽が出ません |
| 病徴 | 黒い斑点や軟化した部分がないもの | 植え付けた後、土の中で腐ります |
| 催芽 | あらかじめ芽出ししてから植えると有利です | 出芽が揃い、初期生育が早まります |

### 6-3. 植え付けの向き

&nbsp;&nbsp;&nbsp;アピオス栽培で最も失敗が多いのがこの点です。ジャガイモと違い、アピオスの塊茎は上下がはっきりしており、逆さまに植えると芽が土の中で方向を見失い、そのまま枯れてしまいます。

| 区分 | 見分け方 |
|---|---|
| 上側(茎が出る方向) | 尖っておらず丸みを帯びていて、でこぼこした突起がいくつも集まっています |
| 下側(根が出る方向) | 滑らかで尖っています。こちらを地面に向けます |

> **尖っている方が下です。判断がつかない場合は横に寝かせて植えます。寝かせれば自分で向きを定めますが、逆さまに植えると枯れます。**

### 6-4. 植え付け

| 項目 | 基準 | 理由 |
|---|---|---|
| 植え付ける深さ | 5-7.5cm | 浅いと乾燥に弱く、深いと出芽が遅れます |
| 種イモの間隔 | 30cm | 地下茎が伸びる余裕を与えます |
| 畝の間隔 | 60-75cm | つるを這わせる支柱を立てる空間です |
| 坪当たりの種イモ数 | 約11個 | 1,000㎡当たり約3,300個 |
| 植え付け後 | 軽く押さえて土を密着させ、水をやります | 塊茎と土の間に隙間があると発根が遅れます |

&nbsp;&nbsp;&nbsp;アピオスは種子消毒が事実上不要な作物です。種子ではなく塊茎で繁殖し、大きな病害もないためです。消毒薬があったとしても使う理由はほとんどありません。ただし切り口ができた場合は、日陰で1日乾かしてキュアリングしてから植え、草木灰をまぶしておくと腐敗を減らせます。種子で繁殖させる場合に限り、1日水に浸すか種皮に傷をつけて発芽を助けます。
