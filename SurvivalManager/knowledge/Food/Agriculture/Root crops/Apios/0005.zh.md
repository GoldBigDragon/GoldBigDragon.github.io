## 12. 收获

### 12-1. 时期判断

| 类别 | 时期 | 判断标准 |
|---|---|---|
| 首次收获 | 种植后2-3年 | 第一年不挖，这是培育根系的一年 |
| 正式收获 | 11月中旬至次年3月 | 藤蔓枯黄死去之后 |
| 种薯用收获 | 次年3月 | 3月现挖的比秋天挖的种薯状态更好 |
| 花朵采收 | 8月上旬至中旬 | 完全绽放前香气最浓 |

&nbsp;&nbsp;&nbsp;收获期的跨度非常宽，是美洲土圞儿的一大优点。从11月到次年3月，四个多月里随时都可以挖。留在地下不但不会变差，反而会随着越冬部分淀粉转化为糖分，滋味变得更好。不像马铃薯那样必须在固定期限内赶紧挖出、赶紧贮藏。只挖出所需的量，其余留在原地即可。

### 12-2. 收获要领

| 顺序 | 内容 |
|---|---|
| 1 | 从支架上取下枯死的藤蔓，剪断基部 |
| 2 | 从距植株30cm以上的外侧开始向内挖 |
| 3 | 找到地下茎，用手顺着摸索并向上提起，串珠状连接的块茎会一并带出 |
| 4 | 不要用铁锹直接铲下去，受伤的块茎无法贮藏 |
| 5 | 轻轻拍掉泥土，不要用水冲洗 |
| 6 | 只挖出所需的量，其余区域覆土后保持原样 |

&nbsp;&nbsp;&nbsp;美洲土圞儿收获麻烦这一说法确有其事。块茎沿地下茎散布，不像马铃薯那样掀开一株根部就能收完。必须顺着一条茎去挖，而且薯粒大小不一，小的很难与泥土区分开来。这道工序也是美洲土圞儿未能成为商业作物的原因之一。但如果在灾害状况下劳动力就是唯一的资源，这笔账就不一样了：不需要耕地，不需要买种，不需要施肥，代价只是挖取要花更多时间，这是一笔可以接受的交换。

### 12-3. 收获后处理

| 类别 | 处理方式 |
|---|---|
| 大个（鸡蛋大小以上） | 立即食用或转入短期贮藏 |
| 中等大小 | 加工成干品或磨粉 |
| 小个（5g左右） | 另外收集作种薯 |
| 有损伤的 | 优先食用，不作贮藏 |
| 泥土 | 只拍掉即可，若水洗会大幅缩短贮藏期 |

> **不要清洗。美洲土圞儿木栓层较薄，若保持湿润状态，几天内就会变软。请在食用前再清洗。**

## 13. 种薯保存与留种

### 13-1. 种薯即种子

&nbsp;&nbsp;&nbsp;美洲土圞儿的种子寿命等级为E，意味着把干种子装进罐子保存数年这种方式行不通。但这一弱点对美洲土圞儿来说并不构成实质问题，因为种在地里的块茎本身就是一座活的种子仓库，而且这座仓库每年都会自行增多。马铃薯同样是种子寿命E，但一旦种薯死掉，第二年就没有作物可种，风险很大；美洲土圞儿则不同，除非把整块地都挖空，否则种薯不会消失。

| 项目 | 标准 |
|---|---|
| 种薯大小 | 5g左右，太大的食用，用小的作种薯 |
| 采集时期 | 次年3月，从地里现挖的最好 |
| 挑选 | 坚实、无皱缩、芽眼凸起明显 |
| 保存期限 | 挖出后应尽量在2周内种下 |
| 退化 | 虽是无性繁殖，但因没有严重病害，几乎观察不到世代退化 |

&nbsp;&nbsp;&nbsp;马铃薯若连续自留种3、4年，蚜虫传播的病毒会不断累积，产量会明显下降。美洲土圞儿几乎没有这类报告，这正是自家留种等级为S的原因，而且灾害持续得越久，这一价值就越大。即便国家不提供无病种子，也能靠自身延续世代的作物并不多。

### 13-2. 需要保存种薯时

&nbsp;&nbsp;&nbsp;原则上应留在地里，种植前再挖，但也有需要保存的情况，比如迁移地块，或分给他人时。

| 方法 | 条件 | 期限 |
|---|---|---|
| 花盆埋藏 | 埋入装有泥土的花盆中，深5-10cm，放在不结冰处，偶尔浇水防止土壤干燥 | 至春季 |
| 沙藏 | 在箱中将湿润的沙子与块茎层层叠放，0-4度 | 2-3个月 |
| 湿报纸包裹 | 用报纸包好，稍微喷水后放在阴凉处 | 2-4周 |
| 直接常温放置 | 不建议 | 1-2周后开始干瘪 |

&nbsp;&nbsp;&nbsp;共同的原理只有一个：美洲土圞儿的块茎一旦变干就会死。这与马铃薯喜欢干燥场所正好相反。因为木栓层薄，水分会不断流失，所以保存的目标不是防腐，而是防干。必须维持90%以上的湿度，因此潮湿的沙子和泥土是最好的保存材料。

### 13-3. 用种子繁殖时

| 项目 | 方法 |
|---|---|
| 留种个体 | 最健壮、结薯最粗大的植株 |
| 成熟判断 | 待豆荚变为褐色并干燥 |
| 分离 | 抖动豆荚取出种子 |
| 干燥 | 在阴凉处彻底晾干 |
| 播种前处理 | 用水浸泡1天，或在种皮上划伤 |
| 特性 | 后代不会表现出与母株相同的特性 |

&nbsp;&nbsp;&nbsp;用种子繁殖并不是一种实用的方法。有的年份结荚，有的年份不结荚，发芽率也不高，而且用种子种下后要更久才能长出块茎。尽管如此，仍值得一试。如果一直只靠无性繁殖，整块地在遗传上就会变成同一个个体，一旦这个个体出现致命病害，就会一次性全军覆没。种子繁殖能降低这一风险，同时也创造出更适应当地环境的个体出现的机会。如果灾害持续多年，在地里的一角另外培育几株实生苗，就相当于买了一份保险。

## 14. 毒性与注意事项

### 14-1. 必须煮熟后食用

&nbsp;&nbsp;&nbsp;美洲土圞儿不能生吃，这一点是确定的。不过关于其原因，坊间常常流传着错误的说法，有必要在此加以澄清。

| 类别 | 内容 |
|---|---|
| 流传较广的说法 | 像马铃薯一样含有龙葵素，生吃会有危险 |
| 实际情况 | 龙葵素是茄科植物的生物碱，属于豆科的美洲土圞儿并不含有 |
| 真正原因 | 是豆科植物普遍含有的蛋白酶抑制剂（胰蛋白酶抑制剂）和凝集素类成分 |
| 症状 | 生吃会导致消化不良，出现腹痛、恶心、腹泻 |
| 去除方法 | 加热可破坏大部分。应充分加热30分钟以上 |
| 结论 | 无论原因为何，结论都一样：不生吃 |

&nbsp;&nbsp;&nbsp;胰蛋白酶抑制剂顾名思义，是一种会妨碍人体消化酶的蛋白质，原理与生吃大豆会闹肚子相同。它不耐热，充分煮或蒸后就会失去活性。由于无法用肉眼判断这种成分残留的程度，以时间为标准更为安全：沸水中煮30分钟，或蒸锅中蒸30分钟以上。没煮熟的美洲土圞儿会残留刺激和涩的味道，因此从口感上也能在一定程度上加以分辨。

### 14-2. 其他注意事项

| 项目 | 内容 |
|---|---|
| 皂苷 | 是苦味与起泡的原因，倒掉第一遍煮的水可以减少。少量无害 |
| 豆类过敏 | 因属豆科植物，对花生或大豆过敏者首次食用应先以少量测试 |
| 过量食用 | 膳食纤维为马铃薯的5倍，突然大量食用会导致腹胀 |
| 繁殖力 | 虽非毒性问题，但不加管理就会蔓延，需要划定边界 |
| 花与种子 | 花可晒干泡茶，种子不作食用 |

## 15. 无冰箱贮藏

### 15-1. 贮藏原则不同

&nbsp;&nbsp;&nbsp;美洲土圞儿的贮藏原理与马铃薯、甘薯正好相反。马铃薯贮藏的目标是适度降低湿度以防止腐烂，而美洲土圞儿贮藏的目标则是保住水分。由于木栓层薄，表面的水分会不断蒸发，若直接放在常温下，大约两周后就会变得干瘪。这正是耐储性等级为C的原因，而能彻底化解这一弱点的方法就是地下贮藏。

| 贮藏目标 | 马铃薯 | 美洲土圞儿 |
|---|---|---|
| 最大的敌人 | 腐烂与发芽 | 干燥 |
| 目标湿度 | 85-95% | 90%以上 |
| 常温保存上限 | 1-2个月 | 1个月以内，实际2-3周 |
| 最佳方法 | 地窖贮藏 | 不挖，留在地下 |

### 15-2. 原位贮藏——最好的方法

| 项目 | 内容 |
|---|---|
| 原理 | 不收获，直接留在地下，泥土能同时维持温度和湿度 |
| 方法 | 初霜后清除藤蔓，覆盖20-30cm厚的稻草或落叶 |
| 期限 | 整个冬季，实际上可长达数年 |
| 温度 | 地温不易降到零下。即使外部气温低至零下20℃，块茎依然能存活 |
| 优点 | 不需要电力、设施和劳力，新鲜度也最高 |
| 缺点 | 地面深度结冰后难以挖取，容易成为田鼠和野猪的目标 |

&nbsp;&nbsp;&nbsp;原位贮藏中稻草覆盖的作用不是保温，而是防止地表冻结。块茎本身即使结冰也能存活，但如果地面冻得像石头一样硬，铁锹就插不进去，也就无法挖取。铺上20到30cm厚的稻草或落叶，即使在隆冬也能让下面的泥土保持松软。覆盖材料可以直接使用秋天清理下来的美洲土圞儿藤蔓。

### 15-3. 挖出后的无电力贮藏

| 方式 | 方法 | 温度 | 期限 | 注意事项 |
|---|---|---|---|---|
| 沙层贮藏 | 在箱中将湿润的沙子与块茎层层叠放 | 0-4℃ | 2-3个月 | 沙子变干时稍微喷水 |
| 地窖贮藏 | 在排水良好的地方挖1.5m以上深，设顶棚与通气口 | 0-4℃ | 3-4个月 | 保持湿度85-95% |
| 土坑贮藏 | 挖30cm深，按稻草、块茎、稻草、泥土的顺序堆成坟丘状 | 0-5℃ | 2-3个月 | 在顶部用稻草束留出通气口 |
| 湿报纸包裹 | 用报纸包好，稍微喷水后放在阴凉处 | 阴凉室内 | 2-4周 | 只适用于少量 |
| 低温贮藏窖 | 7-15℃，埋入沙中 | 7-15度 | 1-2个月 | 因温度较高，期限较短 |

### 15-4. 土坑贮藏的做法

| 顺序 | 内容 |
|---|---|
| 1 | 选择不积水的地方，北向坡地较好 |
| 2 | 挖成直径1-1.5m、深30cm的浅坑 |
| 3 | 坑底铺10cm厚的干稻草 |
| 4 | 将拍掉泥土的块茎堆成坟丘状，高度控制在50cm以内 |
| 5 | 在缝隙间填入湿润的沙子或腐叶土以防干燥 |
| 6 | 铺20-30cm稻草，再在上面覆盖15cm泥土 |
| 7 | 在顶部竖起稻草束作为通气口 |
| 8 | 在四周挖排水沟 |

&nbsp;&nbsp;&nbsp;与马铃薯的土坑贮藏不同的地方在于第5步，也就是要在缝隙间填入含水的材料。马铃薯只用干稻草就够了，但美洲土圞儿如果也这样处理，内部水分会流失而干瘪。湿润的沙子、湿锯末、腐叶土，用哪种都可以。不过湿到能滴水的程度会长霉，标准是用手握紧能成团但不渗水。

### 15-5. 通过加工实现超长期贮藏

| 方法 | 步骤 | 期限 | 备注 |
|---|---|---|---|
| 干燥薄片 | 切成3-5mm厚，沸水中焯2-3分钟后完全晒干 | 6个月至1年 | 不焯水会变色，且抑制成分会残留 |
| 粉末 | 将完全干燥的薄片用石臼或石磨磨碎 | 1-2年 | 密封容器中放入草木灰或炭一起保存 |
| 淀粉 | 磨碎后溶于水中，将沉淀多次漂洗后晒干 | 数年 | 边角料和受损的块茎也可物尽其用 |
| 乳酸发酵 | 浸入2-3%的盐水中，室温放置1-2周 | 数月 | 煮熟后再发酵，不用生的发酵 |

> **贮藏策略的基本原则是分散。大部分留在地下作为过冬口粮，一部分挖出制成干品或磨粉，以应对野兽和严寒。**

## 16. 烹饪与加工

### 16-1. 节省燃料的烹饪方法

| 方法 | 燃料消耗 | 步骤 | 备注 |
|---|:---:|---|---|
| 蒸 | 少 | 只加少量水，蒸汽蒸30分钟 | 皂苷不易流失，味道浓郁，营养损失少 |
| 煮 | 中等 | 没水煮30分钟，倒掉第一遍水可减少苦味 | 能最彻底地去除抑制成分 |
| 余热焖煮 | 极少 | 煮15分钟后关火，用厚布包裹静置1小时以上 | 可将燃料消耗降至一半以下 |
| 灰烬煨烤 | 极少 | 埋入灶中余下的热灰中30-40分钟 | 利用其他烹饪结束后的余热 |
| 粉末烹调 | 少 | 粉末溶入沸水中即刻熟透 | 燃料效率最高 |

&nbsp;&nbsp;&nbsp;与马铃薯不同，美洲土圞儿在缩短烹饪时间上存在限制，因为要确实清除蛋白酶抑制剂，就必须让中心部分也充分熟透。只煮10分钟就取出的话，表面虽然熟了，内部仍会残留抑制成分。因此节省燃料的方法不是缩短时间，而是把热量留住。只煮15分钟后，连锅一起用稻草或毯子厚厚包裹，静置1小时以上，内部温度会保持在80度以上并持续加热。一个塞满稻草的木箱，就是这项技巧的全部。

### 16-2. 味道与食用方法

| 项目 | 内容 |
|---|---|
| 味道 | 味道像栗子和马铃薯混合，甜味不如香浓的口感突出 |
| 苦味 | 由皂苷引起，倒掉第一遍煮的水可以减少 |
| 表皮 | 煮熟后可用手剥掉，也可以连皮一起吃 |
| 口感 | 煮后粉糯，烤后则变得软糯有嚼劲 |
| 搭配 | 只需盐调味即可，与大酱也很搭 |
| 花 | 晒干后可泡茶，香气浓郁 |

### 16-3. 兼顾贮藏的加工

| 加工 | 步骤 | 结果 |
|---|---|---|
| 美洲土圞儿粉 | 将煮熟晒干的薄片磨碎 | 可与谷物粉混合用于和面或煮粥 |
| 淀粉 | 磨碎溶于水中，取沉淀晒干 | 体积减小，不易生虫 |
| 酱煮 | 整颗用酱油或盐水煮至收汁 | 可在常温下保存数日 |
| 发酵酱菜 | 将煮熟的块茎浸入盐水中进行乳酸发酵 | 减轻消化负担，可作配菜 |
| 美洲土圞儿茶 | 切薄片晒干后炒制 | 可与花一同冲泡 |

## 17. 全年作业日程

| 月份 | 作业 | 要点 |
|---|---|---|
| 1月 | 按需从地里挖取食用，检查贮藏情况 | 地面结冰时先撤去稻草再挖 |
| 2月 | 规划田地、翻堆肥、准备支架材料 | 确定新辟地块的位置 |
| 3月 | 采集和挑选种薯、耕地、施基肥并起垄 | 种薯以3月现挖的优于秋天挖的 |
| 4月 | 种植种薯（上旬至中旬）、覆盖 | 尖的一端朝下 |
| 5月 | 检查出苗、搭建支架与网、除草 | 藤蔓长到30cm左右时搭上网 |
| 6月 | 引导藤蔓、检查根瘤、开始开花 | 轻挖须根检查根瘤 |
| 7月 | 完成除草，干旱时灌溉 | 从此时起藤蔓会自行压制杂草 |
| 8月 | 采花、块茎膨大期集中灌溉、防备台风 | 是左右产量最重要的月份 |
| 9月 | 持续灌溉、防备台风、清理越界的地下茎 | 9月台风会吹倒支架 |
| 10月 | 停止灌溉，观察藤蔓变黄情况 | 不必着急 |
| 11月 | 清理藤蔓、首次收获、稻草覆盖20-30cm | 只挖所需的量 |
| 12月 | 收获所需部分，加工成干品或磨粉 | 为防兽害，部分转移至室内保存 |

### 17-1. 不可忘记的五件事

| 项目 | 内容 |
|---|---|
| 首次收获在两三年后 | 灾害发生的当年不会提供任何东西，这是需要在平时提前种下的作物 |
| 种植方向 | 尖的一端朝下，倒着种会在地下死亡 |
| 必须煮熟 | 生吃会消化不良、闹肚子，须加热30分钟以上 |
| 干了就会死 | 不清洗、不晾干，放在地下或湿沙中保存 |
| 划定边界 | 一旦种下就很难清除，只应种在可以长期占用的地方 |
