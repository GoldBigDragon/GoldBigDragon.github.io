## 12. 収穫

### 12-1. 時期の判断

| 区分 | 時期 | 判断基準 |
|---|---|---|
| 初収穫 | 植えてから2-3年 | 初年度は掘りません。根を育てる年です |
| 本格収穫 | 11月中旬-翌年3月 | つるが黄色く枯れた後 |
| 種イモ用収穫 | 翌年3月 | 秋よりも3月に掘ったものの方が種イモとして状態が良いです |
| 花の収穫 | 8月上旬-中旬 | 完全に開く直前が最も香りが強いです |

&nbsp;&nbsp;&nbsp;収穫時期の幅が非常に広いことが、アピオスの大きな利点です。11月から翌年3月まで、4か月以上の間いつでも掘ることができます。地中にあっても状態が悪くなるどころか、冬を越すうちにでんぷんの一部が糖に変わり、むしろ味が良くなります。ジャガイモのように決まった期間に急いで掘り、急いで貯蔵しなければならないという圧力がありません。必要な分だけ掘り、残りはそのままにしておきます。

### 12-2. 収穫のコツ

| 順序 | 内容 |
|---|---|
| 1 | 枯れたつるを支柱から取り除き、根元を切ります |
| 2 | 株から30cm以上離れた外側から掘り進めます |
| 3 | 地下茎を見つけ、手でたどりながら持ち上げます。数珠つなぎになった塊茎が一緒に付いてきます |
| 4 | シャベルで突き刺さないようにします。傷ついた塊茎は貯蔵できません |
| 5 | 土を軽く払い落とします。水では洗いません |
| 6 | 必要な分だけ掘り、残りの区画は土をかぶせてそのままにします |

&nbsp;&nbsp;&nbsp;アピオスの収穫が手間だという評判は事実です。塊茎が地下茎に沿って散らばっているため、ジャガイモのように一株の下を掘り返せば終わるわけではありません。一本の茎をたどりながら掘らなければならず、粒の大きさもまちまちなので、小さいものは土と見分けがつきにくいです。この作業がアピオスが商業作物になれなかった理由の一つでもあります。しかし、災害時に労働力こそが唯一の資源であるなら、計算は変わってきます。畑を耕す必要も、種を買う必要も、肥料を施す必要もない代わりに、掘るのに時間がかかるという取引です。

### 12-3. 収穫後の処理

| 区分 | 処理 |
|---|---|
| 大きいもの(卵大以上) | すぐに食べるか、短期貯蔵に回します |
| 中くらいのもの | 乾燥や粉に加工します |
| 小さいもの(5g前後) | 種イモとして別に集めます |
| 傷のあるもの | 真っ先に食べます。貯蔵しません |
| 土 | 払い落とすだけにします。洗うと貯蔵期間が大きく縮まります |

> **洗いません。アピオスはコルク層が薄いため、濡れた状態のままにしておくと数日で軟らかくなってしまいます。食べる直前に洗います。**

## 13. 種イモの保存と採種

### 13-1. 種イモがそのまま種子です

&nbsp;&nbsp;&nbsp;アピオスの種子寿命の等級はEです。乾燥させた種を甕に入れて何年も保管するというやり方が通用しないという意味です。しかしこの弱点は、アピオスに限っては実質的な問題になりません。土の中に植わっている塊茎そのものが生きた種子庫であり、その庫は毎年自然に増えていくからです。ジャガイモが種子寿命Eでありながら、種イモを失えば翌年の作付けがなくなるというリスクを抱えているのとは異なり、アピオスは畑全体を掘り返さない限り種イモが消えることはありません。

| 項目 | 基準 |
|---|---|
| 種イモの大きさ | 5g前後。大きすぎるものは食べ、小さいものを種イモに使います |
| 採取時期 | 翌年3月。土から掘りたてのものが最も良いです |
| 選別 | 硬くしわがなく、芽の突起がはっきりしているもの |
| 保管期間 | 掘り出した後、できるだけ2週間以内に植えます |
| 退化 | 栄養繁殖ですが大きな病気がないため、世代を重ねての退化はほとんど見られません |

&nbsp;&nbsp;&nbsp;ジャガイモは自家採種を3、4年繰り返すと、アブラムシが媒介するウイルスが蓄積し、収量が目に見えて落ちます。アピオスにはそうした報告がほとんどありません。これが自家採種の等級がSである理由であり、災害が長引くほどその値打ちが増していく性質です。国が無病種子を供給してくれなくても自力で世代をつないでいける作物は、そう多くありません。

### 13-2. 種イモを保管しなければならないとき

&nbsp;&nbsp;&nbsp;原則は土にそのまま置いておき、植え付け直前に掘ることですが、畑を移す場合や他人に分け与える場合のように、保管が必要になることもあります。

| 方法 | 条件 | 期間 |
|---|---|---|
| 鉢植え埋設 | 土の入った鉢に5-10cmの深さで埋め、凍らない場所に置きます。土が乾かないよう時々水をやります | 春まで |
| 砂埋設 | 箱に湿った砂と塊茎を層状に入れます。0-4度 | 2-3か月 |
| 濡れた新聞紙 | 新聞紙で包み、軽く水を振りかけて涼しい場所に置きます | 2-4週間 |
| そのまま常温 | 勧められません | 1-2週間後からしなびてきます |

&nbsp;&nbsp;&nbsp;共通する原理は一つです。アピオスの塊茎は乾くと死にます。ジャガイモが乾燥した場所を好むのとはまったく正反対です。コルク層が薄く水分がそのまま抜けていくため、保管の目標は腐敗を防ぐことではなく乾燥を防ぐことです。湿度90%以上を保つ必要があり、そのため湿った砂や土が最良の保管材料になります。

### 13-3. 種子で繁殖させるとき

| 項目 | 方法 |
|---|---|
| 採種する個体 | 最も健康で粒が太く付いた株 |
| 成熟の判断 | 莢が茶色に変わり乾くまで置きます |
| 分離 | 莢を振るって種子を取ります |
| 乾燥 | 日陰で完全に乾かします |
| 播種前の処理 | 1日水に浸すか、種皮に傷をつけます |
| 特性 | 母株と同じ特性は出ません |

&nbsp;&nbsp;&nbsp;種子による繁殖は実用的な方法ではありません。莢が付く年と付かない年があり、発芽率も高くなく、種子から植えると塊茎が出るまでにさらに時間がかかります。それでもやってみる価値はあります。栄養繁殖だけを続けると、畑全体が遺伝的に一つの個体になってしまい、いつかその個体に致命的な病気が現れれば一度に崩壊します。種子繁殖はそのリスクを減らし、同時にその地域の環境により適した個体が生まれる機会を作ります。災害が何年も続くなら、畑の片隅に実生の株を数株別に育てておくことが保険になります。

## 14. 毒性と注意事項

### 14-1. 必ず加熱して食べます

&nbsp;&nbsp;&nbsp;アピオスは生で食べてはいけません。この結論は確かです。ただし、その理由についてはよく誤った説明が出回っているため、整理しておく必要があります。

| 区分 | 内容 |
|---|---|
| 広く知られた説明 | ジャガイモのようにソラニンが含まれていて生食すると危険だ |
| 実際 | ソラニンはナス科植物のアルカロイドです。マメ科であるアピオスには含まれていません |
| 実際の原因 | マメ科に共通するタンパク質分解酵素阻害剤(トリプシンインヒビター)とレクチン系の成分です |
| 症状 | 生食すると消化されず、腹痛、吐き気、下痢が起こります |
| 除去方法 | 加熱すればほとんどが破壊されます。30分以上十分に加熱します |
| 結論 | 原因が何であれ結論は同じです。生では食べません |

&nbsp;&nbsp;&nbsp;トリプシンインヒビターは、その名の通り人の消化酵素の働きを妨げるタンパク質です。生の大豆を食べるとお腹を壊すのと同じ原理です。熱に弱く、十分に茹でたり蒸したりすると活性を失います。この成分がどれだけ残っているかは目で確認できないため、時間を基準にするのが安全です。沸騰した湯で30分、蒸し器で30分以上です。火の通りが足りないアピオスはえぐみと渋みが残るため、味である程度見分けることもできます。

### 14-2. そのほかの注意

| 項目 | 内容 |
|---|---|
| サポニン | 苦味と泡立ちの原因です。最初に茹でた湯を捨てると減ります。少量は無害です |
| 豆アレルギー | マメ科植物のため、ラッカセイやダイズにアレルギーがある人は、最初は少量で確認します |
| 食べ過ぎ | 食物繊維がジャガイモの5倍あるため、急に多く食べるとお腹にガスがたまります |
| 繁殖力 | 毒性ではありませんが、管理しないと広がります。境界の区画が必要です |
| 花と種子 | 花は乾燥させてお茶に使います。種子は食用にしません |

## 15. 冷蔵庫なしの貯蔵

### 15-1. 貯蔵の原則が違います

&nbsp;&nbsp;&nbsp;アピオスの貯蔵は、ジャガイモやサツマイモとは正反対の原理で動きます。ジャガイモ貯蔵の目標は湿気を適度に下げて腐敗を防ぐことですが、アピオス貯蔵の目標は水分を守ることです。コルク層が薄く表面から水分が絶えず蒸発するため、常温にそのまま置くと2週間ほどでしなびてしまいます。貯蔵性の等級がCである理由がこれであり、その弱点を完全に無力化する方法が地中貯蔵です。

| 貯蔵の目標 | ジャガイモ | アピオス |
|---|---|---|
| 最大の敵 | 腐敗と発芽 | 乾燥 |
| 目標湿度 | 85-95% | 90%以上 |
| 常温保管の限界 | 1-2か月 | 1か月以内、実質2-3週間 |
| 最善の方法 | 室（むろ）貯蔵 | 掘らずに土に置いておく |

### 15-2. その場貯蔵 - 最も良い方法

| 項目 | 内容 |
|---|---|
| 原理 | 収穫せずに土の中にそのまま置きます。土が温度と湿度の両方を保ってくれます |
| 方法 | 初霜の後につるを取り除き、わらや落ち葉を20-30cm覆います |
| 期間 | 冬の間ずっと。実質的には数年まで可能です |
| 温度 | 地中温度は氷点下まで下がりにくいです。外気が氷点下20℃でも塊茎は生き延びます |
| 長所 | 電力、施設、労働のいずれも要りません。鮮度が最も高いです |
| 短所 | 地面が深く凍ると掘りにくくなります。野ネズミやイノシシの標的になります |

&nbsp;&nbsp;&nbsp;その場貯蔵における藁マルチングの役割は、保温ではなく地面の凍結防止です。塊茎自体は凍っても生き延びますが、地面が石のように凍ってしまうとシャベルが入らず掘り出せません。20cmから30cmの藁や落ち葉は、真冬でもその下の土を軟らかい状態に保ってくれます。マルチング材料は、秋に取り除いたアピオスのつるをそのまま使っても構いません。

### 15-3. 掘り出した後の無電力貯蔵

| 方式 | 方法 | 温度 | 期間 | 注意 |
|---|---|---|---|---|
| 砂層貯蔵 | 箱に湿った砂と塊茎を層状に入れます | 0-4℃ | 2-3か月 | 砂が乾いたら軽く水を振りかけます |
| 室（むろ）貯蔵 | 水はけの良い土地を1.5m以上掘り、屋根と通気口を設けます | 0-4℃ | 3-4か月 | 湿度85-95%を保ちます |
| 穴貯蔵 | 30cm掘り、わら、塊茎、わら、土の順に塚のように積み上げます | 0-5℃ | 2-3か月 | 頂上にわら束で通気口を作ります |
| 濡れた新聞紙で包む | 新聞紙に包み、軽く水を振りかけて涼しい場所に置きます | 涼しい室内 | 2-4週間 | 少量にのみ使います |
| 低温貯蔵庫 | 7-15℃、砂に埋めます | 7-15度 | 1-2か月 | 温度が高いため期間は短いです |

### 15-4. 穴貯蔵の作り方

| 順序 | 内容 |
|---|---|
| 1 | 水が溜まらない場所を選びます。北向きの斜面が良いです |
| 2 | 直径1-1.5m、深さ30cmに浅く掘ります |
| 3 | 底に乾いたわらを10cm敷きます |
| 4 | 土を払い落とした塊茎を塚のような形に積み上げます。高さ50cm以内 |
| 5 | 湿った砂や腐葉土を隙間に詰めて乾燥を防ぎます |
| 6 | わらで20-30cm覆い、その上に土を15cm覆います |
| 7 | 頂上にわら束を立てて通気口を作ります |
| 8 | 周囲に排水溝を掘ります |

&nbsp;&nbsp;&nbsp;ジャガイモの穴貯蔵と異なる点は5番、つまり隙間に湿気を含んだ材料を詰めるという点です。ジャガイモは乾いたわらだけで十分ですが、アピオスにそれをすると中の水分が抜けてしなびてしまいます。湿った砂、濡れたおがくず、腐葉土のいずれを使っても構いません。ただし水が滴るほど濡れているとカビが生えるため、手で握ったときにまとまるものの水がにじみ出ない程度を基準にします。

### 15-5. 加工による超長期貯蔵

| 方法 | 手順 | 期間 | 備考 |
|---|---|---|---|
| 乾燥チップ | 3-5mmに切り、熱湯で2-3分湯通ししてから完全に乾燥させます | 6か月-1年 | 湯通ししないと褐変し、阻害成分が残ります |
| 粉 | 完全に乾いたチップを臼や石臼で挽きます | 1-2年 | 密閉容器に灰や炭を一緒に入れます |
| でんぷん | すりおろして水に溶かし、沈んだ澱を何度もすすいで乾かします | 数年 | 端切れや傷ついた塊茎も余さず使います |
| 乳酸発酵 | 2-3%の塩水に漬けて室温で1-2週間 | 数か月 | 茹でてから発酵させます。生のままでは発酵させません |

> **貯蔵戦略の基本は分散です。大部分は土にそのまま置いて冬の食料とし、一部は掘り出して乾燥や粉に加工し、獣害や厳寒に備えます。**

## 16. 調理と加工

### 16-1. 燃料を節約する調理法

| 方法 | 燃料消費 | 手順 | 備考 |
|---|:---:|---|---|
| 蒸す | 少ない | 水を少しだけ入れて蒸気で30分 | サポニンが抜けにくく味は濃く、栄養損失が少ないです |
| 茹でる | 中程度 | 水に浸かるように入れて30分。最初の湯を捨てると苦味が減ります | 阻害成分を最も確実になくします |
| 余熱調理 | 非常に少ない | 15分煮た後、火を止めて厚手の布で包み1時間以上置きます | 燃料を半分以下に減らします |
| 灰の中で焼く | 非常に少ない | かまどに残った熱い灰に埋めて30-40分 | 他の調理を終えた余熱を使います |
| 粉での調理 | 少ない | 粉は熱湯に溶かせばすぐに火が通ります | 燃料効率が最も良いです |

&nbsp;&nbsp;&nbsp;ジャガイモと異なり、アピオスは調理時間を短縮するのに限界があります。タンパク質分解酵素阻害剤を確実になくすには、中心部まで十分に火を通す必要があるからです。10分茹でて取り出すと、表面は火が通っていても中には阻害成分が残ります。そのため燃料を節約する方法は、時間を減らす方向ではなく熱を閉じ込める方向になります。15分だけ煮た後、鍋ごとわらや毛布で厚く包んで1時間以上置くと、内部温度が80度以上を保ったまま調理が続きます。わらを詰めた木箱一つが、この技術のすべてです。

### 16-2. 味と食べ方

| 項目 | 内容 |
|---|---|
| 味 | 栗とジャガイモを混ぜたような味で、甘みよりも香ばしさが強いです |
| 苦味 | サポニンによるものです。最初に茹でた湯を捨てると減ります |
| 皮 | 加熱すると手でむけます。皮ごと食べても構いません |
| 食感 | 茹でるとほくほくし、焼くともちもちします |
| 相性 | 塩だけで十分です。テンジャン（韓国味噌）ともよく合います |
| 花 | 乾燥させてお茶に使います。香りが濃いです |

### 16-3. 貯蔵を兼ねた加工

| 加工 | 手順 | 結果 |
|---|---|---|
| アピオス粉 | 茹でて乾かしたチップを挽きます | 穀物粉と混ぜて生地や粥に使います |
| でんぷん | すりおろして水に溶かし、澱を取って乾かします | 体積が減り、虫が入りません |
| 煮付け | 丸ごと醤油や塩水で煮詰めます | 数日間常温保管が可能になります |
| 発酵漬け | 茹でた塊茎を塩水に漬けて乳酸発酵させます | 消化の負担が減り、おかずになります |
| アピオス茶 | 薄く切って乾かした後、炒ります | 花と一緒に煮出します |

## 17. 年間作業スケジュール

| 月 | 作業 | 要点 |
|---|---|---|
| 1月 | 必要な分だけ土から掘って食べる、貯蔵分の点検 | 地面が凍ったらわらをどけて掘ります |
| 2月 | 畑の計画、堆肥の切り返し、支柱材料の準備 | 新しい区画を作る場所を決めます |
| 3月 | 種イモの採取と選別、耕起、元肥と畝作り | 種イモは秋のものより3月に掘りたてのものが良いです |
| 4月 | 種イモの植え付け(上旬-中旬)、マルチング | 尖っている方が下です |
| 5月 | 出芽の確認、支柱とネットの設置、除草 | つるが30cmほど伸びたらネットに掛けます |
| 6月 | つるの誘引、根粒の確認、開花開始 | 細根を軽く掘って根粒を確認します |
| 7月 | 除草の仕上げ、日照り時の灌水 | この時期からは雑草をつるが自然に抑えてくれます |
| 8月 | 花の収穫、塊茎肥大期の集中灌水、台風対策 | 収量を左右する最も重要な月です |
| 9月 | 灌水継続、台風対策、境界外の地下茎の整理 | 9月の台風は支柱を倒します |
| 10月 | 灌水中止、つるの黄変観察 | 急ぎません |
| 11月 | つるの片付け、初収穫、わらマルチング20-30cm | 必要な分だけ掘ります |
| 12月 | 必要分の収穫、乾燥と粉への加工 | 獣害に備えて一部は屋内に移します |

### 17-1. 忘れてはならない五つのこと

| 項目 | 内容 |
|---|---|
| 初収穫は2、3年後 | 災害が起きたその年には何も与えてくれません。平時にあらかじめ植えておく作物です |
| 植え付けの向き | 尖っている方が下です。逆さまに植えると土の中で枯れます |
