## はじめに
&nbsp;&nbsp;&nbsp;アピオス(Apios americana)は、北アメリカ東部の川辺や湿った森の縁でひとりでに育っていたマメ科のつる植物です。北米の先住民が長く掘って食べてきましたが、収穫に手間がかかり、最初の収穫まで時間がかかるため、大規模に栽培される作物にはならず、韓国でも国の統計に載っていません。ところが、電気・物流・化学資材がすべて途絶えた状況を前提にした評価では、総合SS(67.7点、有効183種中1位)で、穀物やジャガイモより上にあります。平時の農業は、肥料・農薬・機械を思う存分使えるという前提で面積当たりの収量を競いますが、だれも肥料を与えず、薬をまかず、畑を耕さないときに食べ物を出し続けるかを問うと、順位が逆転します。マメ科なので根粒菌で窒素を自分でつくり、多年草なので一度植えれば毎年また生え、地下の塊茎はマイナス20℃を下回っても冬を越し、防除が要らず、熱量に対するタンパク質の比率は根菜・イモ類で最も高い13.9%です。ただし、国単位の収量統計がなく、評価表の多くの欄が実測ではなく推定と代入値で埋められているため、強みの大きさを数字どおりに信じてはいけません。

## 1. 災害への備えの評価
| 区分 | 等級 | スコア |
|:---|:---:|:---:|
| 総合 | SS | 67.7 |
| 短期 | SS | 67.0 |
| 長期 | SS | 68.5 |
| 副食 | SS | 65.7 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: 永続性、施肥、施設の負担、温度幅、耐寒性、防除の自立度、連作への適応性、整地・掘削エネルギー。S: 面積当たりの熱量、味、自家採種。A: タンパク質密度、水の消費量、収量の安定性。B: 調理・加工の要求度、合成資材を投入しない場合の収量維持率 |
| 弱み | E: 種子の寿命。D: 微量栄養素、収穫速度、日射。C: 病害虫圧、貯蔵性、非食用の価値、国内での栽培の普及度 |

> **災害に備える評価が測るのは、手をかけたときにどれだけとれるかではなく、だれも世話をしないときにどれだけ残るかです。アピオスが穀物を上回った理由は、すべてこの一文の中にあります。**

&nbsp;&nbsp;&nbsp;SSがついた8項目は、いずれも人が何を投入しなければならないかを問う項目であり、アピオスはそのすべてに何も投入しなくてよいと答えます。とくに窒素は、災害時に真っ先に途絶える養分で、穀物が無投入の条件で崩れる第一の理由ですが、アピオスはこの関門を通りません。掘削エネルギーは10年に分けて償却され、投入に対して回収できる熱量は161倍(ジャガイモは10.6倍)、合成資材を投入しない場合の収量維持率はB(45.1%)で、ジャガイモのE(17.6%)よりはるかに高くなっています。一方で、植えてから2、3年待たないと本格的な収穫にならないという収穫速度D、微量栄養素D、国内での栽培の普及度C(種芋を入手できる場所が1、2の道に限られる)、40%の遮光で収量が半分になる日射Dもあわせて読む必要があります。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

| 項目 | 表示された値 | 実際の根拠 |
|:---|:---|:---|
| 面積当たりの熱量 | 2,000kg/1,000㎡ | 韓国の試験栽培の報告値は500-800kg。良好な条件の上限を仮定した値に近い |
| 病害虫圧 | 減収率48.9% | マメ科全体の値を借りた推定値 |
| 合成資材を投入しない場合の収量維持率 | 45.1% | ジャガイモの有機栽培の収量比を根菜・イモ類全般に当てはめた代入値 |

&nbsp;&nbsp;&nbsp;窒素固定と地下での越冬と永続性は、植物の性質から導かれる事実なので揺るぎませんが、面積当たりの収量と収量の安定性、病気が広がったときの損失は、だれもきちんと数えていません。したがって、アピオス1つに食料のすべてを賭けてはならず、災害が起きたその年の秋には食べ物を与えてくれないので、平時にあらかじめ植えておきます。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | マメ科アピオス属の多年生つる植物 |
| 葉、つる | 小葉5-7枚の羽状複葉。つるは3-5mまで伸び、からみつく先がなければ地面をはって絡まる |
| 塊茎、根粒 | 地下茎に沿って、ウズラの卵からニワトリの卵ほどの塊茎が数珠のように20-50個つく。細根にアワ粒ほどの根粒 |
| 花、莢 | 6-8月に香りの強い赤紫色から桃褐色の花が咲く。5-10cmの莢はつかない年もある |

&nbsp;&nbsp;&nbsp;植えてから約15日で塊茎の芽から新芽が出てつるが伸び、8-9月に塊茎が肥大します(カリウムの要求が最大)。1年目は根を張って地下茎を伸ばすのに力を使い、収穫できる大きさにはならず、2年目の秋から食べられる大きさになり、3年目に収量が安定します。100g当たり、熱量175kcal(ジャガイモの2.5倍)、炭水化物約38g、タンパク質6.10g(ジャガイモの3倍、必須アミノ酸をすべて備える)、脂質約1gで、食物繊維はジャガイモの約5倍、カルシウムは約30倍、鉄は約4倍、ビタミンCは約5倍です。微量栄養素がDなので、葉菜類やカボチャのようにカロテンの多い作物を組み合わせます。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 生育5-30℃(適温25-30℃)。5℃を下回ると生長は止まるが枯れず、30℃を超えるとつるだけが伸びて塊茎の肥大が鈍る。出芽は平均気温15℃以上。マイナス20℃以下まで地下で生き、韓国全域で何の対策もなしに越冬する |
| 日照、土壌 | 1日4-6時間以上(適正は8時間以上)。pH4.5-7.0(適正5.0-6.0、アルカリ性では鉄・マンガンの吸収が妨げられて葉が黄変)。砂壌土-壌土(粘土質が強いと塊茎が変形) |
| 水 | つねに湿った状態が適正で、かなり長く冠水に耐える(イモ類のなかで過湿に非常に強い)。乾燥すると塊茎が小さくなる。総蒸発散量は約400mm(ジャガイモは500-700mm) |

&nbsp;&nbsp;&nbsp;温度幅25℃は、冷涼な年にも暑い年にも完全には全滅しない保険です。アピオスの値打ちは、良い畑ではなく、ほかの作物が使えない余り地を食料の生産地に変えるところにあるので、水辺・溝沿い・田のあぜ、山の斜面の下の湿った裾(有機物がたまって肥料が要らない)、畑の縁とフェンス(支柱として使う)が適しています。完全な日陰や森の中、石灰質のアルカリ性土壌(pH7以上)、頻繁に耕す畑の真ん中は避けます。

| 系統 | 特徴 | 収量(kg/1,000㎡) |
|:---|:---|:---|
| 赤色系統(Red-vine) | 早生で塊茎の数が多い。霜が早い土地に向く | 500-800 |
| 緑色系統(Green-vine) | 晩生で塊茎の数が少ない代わりに粒が大きく、種芋に向く | 500-700 |

&nbsp;&nbsp;&nbsp;国内での普及度がCなので、災害時に系統を選べる余地はほとんどありません。平時にあらかじめ一か所を確保して植えておけば、毎年ひとりでに増え、今10個の塊茎が数年後には数百個の種芋になります。これがもっとも安上がりな備えです。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 整地 | 3月に深さ20-30cmに耕し(深いほど塊茎が大きい)、畝の高さは30cm以上、排水溝の深さは30cm以上。板や溝で区画して地下茎が隣の畑に越えないようにし、稲わらや落ち葉をかぶせる |
| 施肥(1,000㎡) | 石灰は入れない(苦土石灰120kgは強酸性を矯正するときだけ)。窒素8kg、リン酸12kg、カリウム12kg、完熟堆肥1,000kg(全量を元肥)。窒素を多く与えると根粒菌が怠けてつるだけが茂り、塊茎が小さくなるので、助けではなく妨げになる |
| 災害時の代替肥料 | 木灰(㎡当たりひとつかみを薄く、多いとpHが上がって有害)、6か月以上寝かせた堆肥、骨粉(元肥のみ)、尿の10倍希釈液、落ち葉・草のマルチ5-10cm。初めて植える土地では、アピオスやマメを育てた畑の土をひとつかみ植え穴に混ぜて根粒菌を接種する |
| 種芋 | 3月に掘りたて(秋に掘って保管したものより良い)の5g前後で、硬くてしわがなく、芽の突起がはっきりした塊茎。黒い斑点や柔らかくなったものは除く。芽出しをしてから植えると出芽がそろう |
| 植え付け | 4月上旬-中旬、遅霜が終わったあと、平均気温15℃前後で植える。深さ5-7.5cm、種芋の間隔30cm、畝の間隔60-75cm(1,000㎡に約3,300個)。軽く押さえたあと水をやる。出芽に約15日(遅れると1か月)かかるので、あせって掘って確かめない |

> **植える向きが最も失敗しやすいところです。茎が出る上側は丸みがあって突起が集まっており、根が出る下側はなめらかでとがっていて、とがったほうが下です。判断がつかなければ横に寝かせて植えます。寝かせれば自分で向きを決めますが、逆さに植えると枯れます。**

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 植え付けから栄養生長期(5-7月) | 土が乾かない程度に与え、自然の降雨で足り、乾いたら補う(この時期の乾燥は回復できる) |
| 塊茎の肥大期(8-9月) | たっぷり灌水(収量を左右する唯一の決定的な時期で、空梅雨の年は塊茎が太れない) |
| 成熟・収穫期(10月以降) | 灌水を止める(皮が固まって貯蔵性が上がる) |

| 管理 | 方法 |
|:---|:---|
| 支柱 | 畝に沿って2m間隔で支柱を立て、キュウリネットやひもを高さ1.8-2mに格子状に張る。つるが30cmほど伸びたら一度掛けてやり、支柱の根元は土に30cm以上打ち込む。キュウリネットがなければ、トウモロコシやヒマワリを1列おきに植えて支柱にするか、フェンスのそばに植える |
| 台風対策 | 予報が出る前に支柱の根元に土を寄せ、列の両端の杭から斜めにひもを引く。8月の台風は主に雨の被害なので排水溝を先に整え、9月の台風は雨と強風が同時に来るので支柱の固定が優先 |
| そのほかの管理 | 草取りは5-6月の初期だけ(つるが地面を覆うと雑草が減る)。7-8月に花を摘むと塊茎に回る養分が増え、摘んだ花は乾燥させて茶にする。年に1回、区画の外に伸びた地下茎を切る |

## 6. 病害虫と養分の問題
&nbsp;&nbsp;&nbsp;病害虫圧はCですが、防除の自立度はSSです。ジャガイモの疫病やキャッサバのモザイク病のように、一度入ると全滅する病気が知られていないという意味であり、大規模に栽培されるようになれば、アピオス固有の病害虫が現れる可能性があります。

| 病害虫 | 症状と条件 | 薬を使わない防除 |
|:---|:---|:---|
| アブラムシ、ハダニ | 夏の高温期に新芽と葉裏から汁を吸う / 高温乾燥期に葉がざらつき銀白色の斑点 | 水で洗い流し、石けん水を薄めて散布(灰汁や天然石けんを水で500倍)、木酢液200-500倍、テントウムシを守る / 葉裏に水をかけて湿度を上げる |
| 細菌性斑点病、うどんこ病 | 梅雨どきの葉の黒い斑点 / 晩夏の葉の表面の白い粉 | 風通しの確保、病葉を摘んで焼く、支柱でつるを持ち上げる / 牛乳を水で10倍に薄めて散布 |
| ノネズミ、モグラ、イノシシ | 冬-春に地中の塊茎をかじる / 秋-冬に地面を掘り返して食べる | 畑の周りの雑草を除く、区画の周りに板を埋める / フェンス、においの遮断 |

&nbsp;&nbsp;&nbsp;災害時にもっとも脅威になるのは、カビや細菌ではなく獣です。地中に置いた塊茎は、イノシシやノネズミにとっても冬じゅう開いた食料庫であり、人が飢える年には獣も飢えるので、貯蔵区域の周りにフェンスを張り、収穫量の一部を別に掘って屋内に移し、危険を分散します。

| 症状 | 原因と対処 |
|:---|:---|
| つるばかり茂って塊茎が小さい | 窒素過剰で、アピオスでもっともよく見る問題。7月ごろ細根を少し掘って、アワ粒ほどの桃色のこぶがあり、割ったときに中が赤ければ窒素固定が活発なので、窒素を止めて木灰でカリウムを補う |
| 下葉から薄い緑色に退色、根粒がない | 窒素欠乏(共生の失敗)。薄めた尿を少量与え、アピオスやマメ科を育てた畑の土を混ぜて再接種する |
| 葉が紫色を帯びる / 縁が褐色に枯れる / 葉脈だけが緑 | リン欠乏 / カリウム欠乏 / 鉄・マグネシウム欠乏(pH7以上)。骨粉と木灰 / 木灰 / 腐葉土と堆肥でpHを下げる |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | トウモロコシ・ヒマワリ(生きた支柱になり、アピオスは窒素を残す)、葉菜類(残った窒素を翌年すぐ使う)、果樹園の下(つるが雑草を抑え、窒素を供給する) |
| 普通 | 根菜類(地下茎と入り混じって収穫の手間が増える) |
| 悪い | 頻繁に耕す畑、カボチャやキュウリなどほかのつる作物(絡み合って双方とも収穫が難しい) |

&nbsp;&nbsp;&nbsp;アピオスが隣の作物に贈るいちばんの贈り物は窒素です。多年草なのでこの蓄積が毎年積み重なり、数年育てた場所はほかの作物に渡すと1年目からよく育ちます。輪作はほとんど当てはまらず(連作への適応性SS)、同じ場所に長く置くのが基本で、区画を移すときはアピオス(5-10年)→葉菜類や穀物→根菜類→再びアピオスの順にまわし、取り除いた跡にはハクサイやホウレンソウのように窒素を多く使う作物が向きます。爪ほどの塊茎のかけらが1つ残っても翌年に芽が出るので、畑の縁、フェンスのそば、溝沿いなど、長く明け渡せる場所に植えます。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 植えて2、3年後から(1年目は掘らない)。つるが黄色く枯れた11月中旬から翌年3月までいつでも掘れ、地中で傷まず、むしろでんぷんの一部が糖に変わって味がよくなる。種芋用は翌年3月、花は8月上旬-中旬(満開の直前) |
| 要領 | 株から30cm以上離れた外側から掘り進め、地下茎を手でたどりながら数珠のようにつながった塊茎を持ち上げる。スコップで突き刺さない(傷ついた塊茎は貯蔵できない)。土を軽く払うだけで洗わず(濡れると数日で柔らかくなるので食べる直前に洗う)、必要な分だけ掘って、残りは土をかぶせておく |
| 処理 | 大きいものはすぐ食べるか短期間貯蔵し、中くらいのものは乾燥・粉に加工し、5g前後のものは種芋として別に集め、傷ついたものを最初に食べる |

| 採種 | 基準 |
|:---|:---|
| 種芋 | 種子の寿命はEですが、地中の塊茎がそのまま生きた種の貯蔵庫となって毎年ひとりでに増える。5g前後の小さな塊茎を翌年3月に掘りたてで2週間以内に植える。栄養繁殖ですが大きな病気がなく、世代の劣化はほとんどない(ジャガイモと違って) |
| 保管が必要なとき | 土を入れた鉢に5-10cmの深さで埋めて凍らない場所に置けば春まで、濡らした新聞紙で包んで涼しい場所に置けば2-4週間 |
| 種子による繁殖 | 親と同じ特性が出ないため実用的ではないが、栄養繁殖だけを続けると畑全体が1つの個体になり、致命的な病気が広がったときに一度に崩れる。災害が何年も続くなら、褐色に乾いた莢の種を1日浸すか種皮に傷をつけて植えた実生を数株、別に育てておく |

## 9. 貯蔵
&nbsp;&nbsp;&nbsp;アピオスの貯蔵でもっとも大きな敵は乾燥です。コルク層が薄いため塊茎は乾くと死ぬので、湿度90%以上を保つ必要があり、常温保管は実質2-3週間が限界です。

| 方式 | 方法 | 期間 |
|:---|:---|:---|
| その場での貯蔵 | 掘らずに地中に置き、初霜のあとにつるを片づけて、わらや落ち葉を20-30cmかぶせる(地面が石のように凍って掘れなくなるのを防ぐため)。電力・設備・労力が要らず、鮮度がもっとも高いが、ノネズミやイノシシの標的になる | 冬じゅう、数年まで |
| 砂層貯蔵 | 箱に湿った砂と塊茎を交互に重ねて0-4℃に置き、砂が乾いたら水を少し振りかける | 2-3か月 |
| 土室・穴での貯蔵 | 土室は水はけのよい土地を1.5m以上掘り、屋根と通気口をつくって湿度85-95%を保つ(3-4か月)。穴は直径1-1.5m、深さ30cmに掘って乾いたわらを敷き、塊茎を盛り土の形に積み、湿った砂や腐葉土を間に詰めて乾燥を防ぎ、わら20-30cmと土15cmをかぶせたあと、頂上にわら束で通気口をつくり、周りに排水溝を掘る | 2-4か月 |
| 乾燥チップ、粉、でんぷん | 3-5mmに切って熱湯で2-3分ゆでたあと完全に乾燥(ゆでないと褐変し、阻害成分が残る)。挽いた粉は灰や炭を入れた密閉容器に、すりおろして水に溶かし沈めた沈殿を何度もすすいで乾かしたでんぷんは、切れ端や傷ついた塊茎まで余さず使う | チップ6か月-1年、粉1-2年、でんぷん数年 |

> **貯蔵戦略の基本は分散です。大部分は地中にそのまま置いて冬の食料にし、一部は掘って乾燥・粉に回し、獣と厳寒に備えます。**

## 10. 調理と注意事項
| 注意 | 内容 |
|:---|:---|
| 必ず加熱 | ソラニン(ナス科の成分)ではなく、マメ科に共通するトリプシンインヒビターとレクチンのせいで、生で食べると消化できず、腹痛・吐き気・下痢が起こる。加熱不足かどうか目では分からないので、熱湯か蒸し器で30分以上十分に加熱 |
| サポニン | 苦味と泡の原因で、ゆでた最初の湯を捨てると減る。少量は無害 |
| アレルギー | マメ科なので、ラッカセイやダイズのアレルギーがあれば、最初は少量で確認 |

| 調理 | 方法 |
|:---|:---|
| 蒸す、ゆでる | 蒸す場合は水を少しだけ入れて蒸気で30分(味が濃く、栄養の損失が少ない)。ゆでる場合は水に浸かるように入れて30分で、最初の湯を捨てると苦味が減り、阻害成分をもっとも確実に除ける |
| 燃料の節約 | 10分だけゆでると中に阻害成分が残るので、時間を縮めず、熱を閉じ込める。15分煮立てたあと、鍋ごとわらや厚い布でくるんで1時間以上置くと、燃料が半分以下。熱い灰に埋めて30-40分焼くか、粉は熱湯に溶いてすぐ火を通す |
| 味、食べ方 | クリとジャガイモを混ぜたような香ばしい味。加熱すれば皮が手でむけ、皮ごと食べてもよい。ゆでるとほくほくし、焼くともちもちする |
| 加工 | ゆでて乾燥させたチップを挽いた粉は、穀物の粉と混ぜて生地や粥に使い、ゆでた塊茎を2-3%の塩水で1-2週間乳酸発酵させた漬物は消化の負担が減る(生のまま発酵させない)。花は乾燥させて茶にする |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 必要な分だけ掘って食べる(地面が凍ったらわらをのけて掘る)、貯蔵分の点検。2月に堆肥の切り返し、支柱の材料の準備、新しい区画の場所決め |
| 3-4月 | 3月に種芋の採取と選別、耕うん、元肥と畝づくり。4月上旬-中旬に種芋の植え付け(とがったほうが下)、マルチ |
| 5-6月 | 5月に出芽の確認、支柱とネットの設置、草取り(つるが30cmほど伸びたらネットに掛ける)。6月につるの誘引、開花開始 |
| 7-8月 | 7月に草取りの仕上げ、根粒の確認、干ばつ時の灌水、花摘みの開始。8月に花の収穫、塊茎の肥大期の集中的な灌水、台風対策(収量を左右するもっとも重要な月) |
| 9-10月 | 9月に灌水の継続、台風対策(支柱の固定)、境界の外の地下茎の整理。10月に灌水を止め、つるの黄変を観察(あせらない) |
| 11-12月 | 11月につるの片づけ、最初の収穫、わら20-30cmをかぶせる。12月に必要分の収穫、乾燥と粉への加工(獣害に備えて一部は屋内に移す) |

> **アピオスは、平時にあらかじめ植え(最初の収穫は2、3年後)、とがったほうを下にして植え、必ず30分以上加熱して食べ、洗わずに地中や湿った砂に置き、取り除くのが難しいので、境界を決めて長く明け渡せる場所に植える作物です。**
