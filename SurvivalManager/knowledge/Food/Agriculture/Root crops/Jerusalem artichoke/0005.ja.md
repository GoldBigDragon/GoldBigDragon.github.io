## 12. 収穫

### 12-1. 時期の判断

| 区分 | 時期 | 判断基準 |
|---|---|---|
| 最適期 | 初霜が降りた後 | 地上部が枯れ、イヌリンと糖度が最高に達します |
| 収穫期間 | 11月中旬-翌年3月 | 四か月余りいつでも掘れます |
| 種芋用 | 翌年3月 | 土から掘り出したばかりのものが最も状態が良いです |
| 早すぎる収穫 | 9月以前 | 塊茎がまだできていません。収量の大半を失います |

&nbsp;&nbsp;&nbsp;初霜を待つ理由は二つあります。一つは霜が降りる直前まで葉が糖を作り続け地中に送り込むためで、もう一つは低温にさらされるとイヌリンの一部がより短い鎖に分解されて甘味が増すためです。霜の前に掘ったキクイモは味が薄く、霜の後に掘ったものは甘いです。冬を過ごすうちにこの変化はさらに進みます。

### 12-2. 収穫のコツ

| 順序 | 内容 |
|---|---|
| 1 | 地上部の茎を根元から切り落とします。刈った茎はその場に覆います |
| 2 | 株から30cm以上離れた外側から掘り進めます |
| 3 | 鍬や三本鍬で土を持ち上げ、塊茎を露出させます |
| 4 | シャベルで打ち下ろしません。傷ついた塊茎はすぐに軟化します |
| 5 | 土を軽く払い落とします。水で洗いません |
| 6 | 必要な分だけ掘り、残りは土をかぶせてそのままにします |

&nbsp;&nbsp;&nbsp;収穫で最も重要な原則は、一度に全部掘らないことです。キクイモは掘った瞬間から水分を失い始め、常温で2-4週間もすればしなびます。一方、地中にある間は数か月経っても掘ったばかりのものと変わりません。そのため、今週食べる分だけ掘り、来週また掘るという方法は、キクイモにおいては怠惰ではなく最善の貯蔵戦略です。

### 12-3. 収穫後の分類

| 区分 | 処理 |
|---|---|
| 大きくて傷のないもの | すぐに食べるか室(むろ)に入れます |
| 中くらいの大きさ | 切って乾燥させ、チップと粉にします |
| 小さいもの(30-50g) | 種芋として別に集めます |
| 傷ついたもの | 最初に食べます。貯蔵しません |
| 土 | 払い落とすだけにします。洗うと貯蔵期間が半分に減ります |

## 13. 種芋の保存と採種

### 13-1. 土地こそが種子倉庫です

&nbsp;&nbsp;&nbsp;キクイモの種子寿命の等級はEです。乾燥した種子で何年も保管する方式が不可能という意味ですが、この作物に限っては実質的な弱点にはなりません。畑そのものが種子倉庫であり、その倉庫は毎年自然に増えていくからです。ジャガイモは種いもを冬に死なせるとその年の作付けができなくなりますが、キクイモは畑を丸ごと掘り返さない限り種芋がなくなることはありません。

| 項目 | 基準 |
|---|---|
| 種芋の大きさ | 30-50g、卵サイズ |
| 採取時期 | 3月、植え付け直前に掘り出します |
| 選別 | 固くて芽が生きており、病気の症状がないもの |
| 保管 | 掘ったらすぐに植えるのが最も良いです |
| 増殖率 | 一つから数十個。一年で数十倍になります |
| 退化 | 無性繁殖ですが、ウイルス退化の報告はほとんどありません |

&nbsp;&nbsp;&nbsp;増殖率が非常に高いという点は、実務上大きな意味を持ちます。十個植えれば、その年の秋には数百個になります。翌年には数千個になります。災害の初期に種芋を手に入れにくくても、数個だけ確保できれば二年でかなりの面積を満たせます。これは種を毎年買わなければならない作物とは根本的に異なる性質です。

### 13-2. 種子で繁殖させる場合

| 項目 | 内容 |
|---|---|
| 種子の結実 | 韓国国内の気候では種子がうまく熟しません |
| 発芽 | 発芽率が低く不規則です |
| 特性 | 母株と同じ特性が出ません |
| 実用性 | 繁殖には使いません |

&nbsp;&nbsp;&nbsp;キクイモは種子による繁殖が事実上意味を持たない作物です。韓国の秋は種子が完全に熟す前に霜が降りることが多く、熟したとしても発芽率が低いです。繁殖はもっぱら塊茎によって行われます。ただこのため、一地域のキクイモが遺伝的にほぼ単一になるという現象が生じ、これはいつか特定の病気が現れたときに弱点になり得ます。複数の場所から種芋を持ってきて混ぜて植えれば、その危険をある程度減らせます。

## 14. イヌリンと注意事項

### 14-1. 毒性はありません。しかし初めて食べると具合が悪くなります

&nbsp;&nbsp;&nbsp;キクイモには毒性物質がありません。キャッサバのシアン配糖体やジャガイモのソラニンのような危険は存在せず、生で食べても中毒しません。それでもこの節を別に設けている理由は、初めて食べる人が満腹になるまで食べると、ほぼ必ず激しい腹部膨満と腹痛を経験するためです。災害時に飢えた人がキクイモを一杯食べきって一晩中苦しむことは実際に起こります。これは毒ではなく消化生理の問題ですが、本人には区別がつきません。

| 段階 | 体内で起こること |
|---|---|
| 1 | イヌリンは果糖が鎖のようにつながった多糖類です |
| 2 | 人の消化酵素はこの結合を切ることができません |
| 3 | 胃と小腸をそのまま通過して大腸に到達します |
| 4 | 大腸の細菌がイヌリンを発酵させます |
| 5 | この過程で水素、二酸化炭素、メタンが大量に発生します |
| 6 | お腹が膨れてガスが溜まり、けいれん性の痛みと下痢が起こります |

### 14-2. 症状と適応

| 摂取量 | 慣れていない人 | 慣れた人 |
|---|---|---|
| 50g以下 | 大抵症状なし | 症状なし |
| 100-150g | 軽い膨満感 | 症状なし |
| 200-300g | 明確な膨満、頻繁なおなら、腹部の不快感 | 軽い膨満 |
| 500g以上 | 激しい腹痛、下痢、数時間続く | 膨満とおなら |

&nbsp;&nbsp;&nbsp;重要なのは、この反応が適応するという事実です。イヌリンを継続的に食べると大腸の細菌の構成が変わり発酵が穏やかになり、数週間のうちに同じ量を食べても症状が大きく減ります。したがってキクイモを食料として使うには、災害が起きた後ではなくその前から、あるいは災害の初期から少量ずつ始めて体を慣らしておく必要があります。1日50gから始めて2週間かけて増やしていく方法が無難です。

| 対象 | 注意 |
|---|---|
| 子ども | 体重当たりの摂取量が大きくなるため、より少ない量から始めます |
| 高齢者 | 腸の機能が弱い場合、症状が長引きます |
| 過敏性腸症候群がある人 | 症状が特に強く出ます。少量に制限します |
| すでに下痢をしている人 | 食べさせません。脱水を悪化させます |
| 糖尿病がある人 | 血糖を急激に上げないため、むしろ有利です |

### 14-3. ガスを減らす方法

| 方法 | 原理 | 効果 |
|---|---|---|
| 長く煮る | 加熱と酸でイヌリンの鎖が一部切れます | 中程度 |
| 酢を入れて煮る | 酸が加水分解を促進します | 中程度 |
| 乳酸発酵 | 細菌が事前にイヌリンを分解します | 大きい |
| 低温貯蔵後に調理 | 貯蔵中に自然分解が進みます | 中程度 |
| 長期乾燥 | 乾燥と再水和の過程で一部分解されます | 小さい |
| 少量を頻繁に | 大腸の細菌が適応します | 最も大きい |

> **最も確実な方法は発酵です。塩水に浸けて1-2週間乳酸発酵させると、細菌がイヌリンを事前に分解し、人の大腸に到達する量が大きく減ります。おかずになりながら消化の負担も同時に解決されるわけです。**

### 14-4. その他の注意

| 項目 | 内容 |
|---|---|
| 生食 | 可能ですが膨満がより強く出ます。加熱して食べる方がよいです |
| 葉と茎 | 人は食べません。家畜の飼料には使えます |
| 傷んだ塊茎 | 軟化して悪臭がする場合は捨てます |
| 繁殖力 | 毒性ではありませんが、管理しないと畑の配置が崩れます |
| アレロパシー | 隣接する作物の生育を抑制します |

## 15. 冷蔵庫なしの貯蔵

### 15-1. 地中こそが貯蔵庫です

&nbsp;&nbsp;&nbsp;キクイモはジャガイモと違って厚いコルク層がありません。掘り出して常温に置くと表面から水分が急速に抜け、数日から2週間でしなびてしまいます。貯蔵性の等級がCである理由がこれです。ところが同じ塊茎が地中にある間は、数か月経っても無事です。土が温度と湿度を同時に保ってくれるためです。そのためキクイモ貯蔵の第一原則は、貯蔵庫を作ることではなく掘らないことです。

| 貯蔵の目標 | ジャガイモ | キクイモ |
|---|---|---|
| 最大の敵 | 腐敗、発芽、緑化 | 乾燥 |
| 常温保管の限界 | 1-2ヶ月 | 2-4週間 |
| 最善の方法 | 室(むろ)貯蔵 | 掘らずに地中に置く |
| 目標湿度 | 85-95% | 90%以上 |

### 15-2. その場での越冬貯蔵

| 項目 | 内容 |
|---|---|
| 原理 | 収穫せずに地中にそのまま置きます。生きた貯蔵庫です |
| 方法 | 初霜の後に地上部を刈り、藁や落ち葉を20-30cm覆います |
| 期間 | 冬の間中、実質的に翌年の春まで |
| 温度 | 地中温度で維持されます。外気がマイナス20度でも塊茎は生きています |
| 長所 | 電力、施設、労働がすべて不要です。鮮度が最も高いです |
| 短所 | 地面が深く凍ると掘りにくくなります。ネズミ類やイノシシの標的になります |

&nbsp;&nbsp;&nbsp;マルチングの目的は塊茎を凍らせないことではありません。キクイモの塊茎は凍っても死にません。目的はその上の土が石のように凍ってシャベルが入らなくなる状況を防ぐことです。20cmから30cmの藁や落ち葉があれば、真冬でもその下の土は柔らかいまま保たれます。秋に刈った茎をそのまま覆っても構いません。

### 15-3. 掘り出した後の無電力貯蔵

| 方式 | 方法 | 温度 | 期間 | 注意 |
|---|---|---|---|---|
| 室・土窟貯蔵 | 湿った砂、土、おがくずに層状に埋めます | 0-4℃ | 2-3ヶ月 | 湿度85-95%を守ります |
| 穴貯蔵 | 30cm掘り、藁、塊茎、藁、土の順に土饅頭のように積みます | 0-5℃ | 1-2ヶ月 | てっぺんに藁束で通気口を作ります |
| 砂箱 | 箱に乾いた砂と塊茎を層状に入れます | 涼しい室内 | 1-2ヶ月 | 砂が乾きすぎたら水を軽くふりかけます |
| 湿った布で包む | 布や新聞紙に包んで涼しい場所に置きます | 涼しい室内 | 2-3週間 | 少量にのみ使います |
| そのまま常温 | 勧めません | - | 1-2週間 | すぐにしなびます |

### 15-4. 穴貯蔵の作り方

| 順序 | 内容 |
|---|---|
| 1 | 水が溜まらない高い場所を選びます。北向きの斜面が良いです |
| 2 | 直径1-1.5m、深さ30cmで浅く掘ります |
| 3 | 底に乾いた藁を10cm敷きます |
| 4 | 土を払った塊茎を土饅頭状に積みます。高さ50cm以内 |
| 5 | 隙間に湿った砂や腐葉土を詰めて乾燥を防ぎます |
| 6 | 藁で20-30cm覆い、その上に土を15cm被せて叩きます |
| 7 | てっぺんに藁の束を一つ立てて通気口を作ります |
| 8 | 周囲に排水溝を掘ります |

&nbsp;&nbsp;&nbsp;ジャガイモの穴貯蔵と違う点は5番です。ジャガイモは乾いた藁だけで十分ですが、キクイモはそうすると中で乾いてしまいます。手で握ると固まるが水がにじみ出ない程度に湿らせた砂や腐葉土を間に詰める必要があります。ただこのため腐敗の危険も一緒に高まるので、通気口を必ず作り、2週間に一度は開けて確認します。

### 15-5. 加工による超長期貯蔵

| 方法 | 手順 | 期間 | 備考 |
|---|---|---|---|
| 乾燥チップ | 2-3mmに薄く切り、日光や竈の残熱で完全に乾燥させます | 数ヶ月-数年 | 体積と重量が大きく減ります |
| 粉 | 完全に乾いたチップを臼や石臼で挽きます | 1-2年 | 密閉し、灰や炭を乾燥剤として一緒に入れます |
| 乳酸発酵 | 2-3%の塩水に浸け、室温で1-2週間 | 数ヶ月 | 消化の負担が大きく減ります |
| チャンアチ(醤油漬け) | 醤油やテンジャンに漬け込みます | 数ヶ月-1年 | おかずになりながら保存されます |
| 酢漬け | 煮た酢水に浸けます | 数ヶ月 | 酸味がイヌリンの分解を助けます |

> **貯蔵戦略の標準は並行です。大部分は地中にそのまま置き、一部は乾燥と粉に加工して獣と厳寒に備え、一部は発酵させて消化の負担を減らしたおかずにします。**

## 16. 調理と加工

### 16-1. 燃料を節約する調理

| 方法 | 燃料消費 | 手順 | 備考 |
|---|:---:|---|---|
| 生食 | なし | 洗って切って食べます | シャキシャキして甘いですが、膨満が強く出ます |
| 茹でる | 少ない | 水に入れて10-15分 | デンプンが少なく、ジャガイモより早く煮えます |
| 蒸す | 少ない | 水を少し入れて15分 | 味が濃く、栄養の損失が少ないです |
| 残熱調理 | 非常に少ない | 5分沸かした後、火を止めて布で包み30分 | 燃料を大きく節約します |
| 灰の中で焼く | 非常に少ない | 竈に残った灰に埋めて20-30分 | 皮付きのまま焼きます |
| 粉調理 | 少ない | 沸騰した湯に溶かせばすぐに煮えます | 燃料効率が最も良いです |

&nbsp;&nbsp;&nbsp;調理・加工の等級がAである理由は、加熱時間が10分で十分で、生食まで可能だからです。燃料が極端に貴重な状況では、これは大きな利点です。ただ、前述の理由により生食は膨満が最も強く出て、長く煮るほどイヌリンが少しずつ分解されて負担が減ります。燃料とお腹の間の取引というわけです。慣れる前は長く煮て、慣れた後は短く火を通せばよいです。

### 16-2. 味と食べ方

| 項目 | 内容 |
|---|---|
| 味 | 生のものは梨とレンコンを混ぜたようにシャキシャキして甘いです |
| 加熱した味 | 柔らかくなり甘味が強くなります。デンプン感がなくジャガイモとは異なります |
| 皮 | むかなくても構いません。ブラシでこすって土だけ落とします |
| 変色 | 切るとすぐに褐変します。酢水に浸けておくと軽減されます |
| 相性 | 味噌汁、煮物、天ぷら、漬物すべてに合います |
| 汁 | 茹で汁には糖とカリウムが溶け出しているので、一緒に使います |

### 16-3. 貯蔵を兼ねた加工

| 加工 | 手順 | 結果 |
|---|---|---|
| キクイモチップ | 薄く切って完全に乾燥 | そのまま食べるか、水で戻して汁物に入れます |
| イヌリン粉 | 乾いたチップを挽きます | 穀物の粉に混ぜて使うか、粥を作ります |
| 茶 | 切って乾燥させた後、炒って煮出します | 香ばしいです。冬の飲み物になります |
| 乳酸発酵ピクルス | 塩水に浸けて1-2週間 | おかずになり、消化の負担が減ります |
| チャンアチ(醤油漬け) | テンジャンや醤油に漬け込みます | 数ヶ月保存でき、塩気で塩分も一緒に取れます |
| シロップ | 長く煮詰めてイヌリンを分解させます | 果糖シロップになります。甘味を出す時に使います |

## 17. 年間作業スケジュール

| 月 | 作業 | 要点 |
|---|---|---|
| 1月 | 必要な分だけ地中から掘る、貯蔵分の点検 | 藁をよけて掘った後、また覆います |
| 2月 | 畑の計画、堆肥の切り返し | 新しい区域を作る場所と遮断壁を決めます |
| 3月 | 種芋の採取と選別、植え付け開始 | 土が緩んだらすぐ植えます |
| 4月 | 植え付け完了、マルチング | 灌水は不要です |
| 5月 | 出芽確認、1回目の摘心、除草 | 高さが1mほどになったら頂芽を切ります |
| 6月 | 除草の仕上げ | これ以降は雑草が自然に消えます |
| 7月 | 2回目の摘心、倒伏対策 | 高さを1.5m前後に抑えます |
| 8月 | つぼみ摘み、台風対策 | まだ塊茎はできていません |
| 9月 | 塊茎肥大の開始、深刻な干ばつの時のみ灌水 | この頃から塊茎が太り始めます |
| 10月 | 開花の観察、収穫準備 | 焦りません |
| 11月 | 初霜後に地上部を刈る、初回収穫、藁マルチング20-30cm | 必要な分だけ掘ります |
| 12月 | 必要分の収穫、乾燥と発酵加工 | 獣害に備えて一部は室内に移します |

### 17-1. 忘れてはならない五つのこと

| 項目 | 内容 |
|---|---|
| 初めて食べる時は少量に | イヌリンのせいで激しいガスと腹痛が起こります。50gから2週間かけて増やします |
| 植える場所は元に戻せません | 一度植えると根絶はほぼ不可能です。境界や余った土地に遮断壁と共に植えます |
| 初霜を待ちます | 霜の前は塊茎が小さく味もよくありません。9月以前の収穫は損です |
| 掘らないことが貯蔵です | 地中に置けば数ヶ月経っても無事で、掘れば2週間でしなびます |
| 肥料を与えません | 窒素を与えると丈だけが伸び、塊茎が小さくなります。堆肥は他の作物に回します |
