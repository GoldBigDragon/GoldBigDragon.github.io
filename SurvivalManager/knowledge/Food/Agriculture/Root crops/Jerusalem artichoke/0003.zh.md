## 3. 栽培环境

### 3-1. 极限值与最适值

| 项目 | 极限值 | 最适值 | 超出范围时 |
|---|---|---|---|
| 生长温度 | 5-30℃ | 18-25℃ | 幅度达25℃，非常宽，在大多数气候下都不会枯死 |
| 越冬温度 | 零下20-30℃仍可在地下存活 | - | 在韩国全境无需任何防护即可越冬 |
| 发芽温度 | 5-10℃以上 | - | 土壤解冻后即可种植 |
| 光照量 | 每天6小时以上 | 每天8小时以上 | 40%遮光下产量仍能保持约80%，对阴凉较为耐受 |
| 土壤pH | 5.0-8.0 | 5.8-7.0 | 从酸性到弱碱性都能适应 |
| 土壤 | 几乎不挑 | 排水良好的砂壤土至壤土 | 在黏土中块茎会长得畸形，也难以挖掘 |
| 水分 | 无需灌溉即可栽培 | 只需在块茎膨大期保持湿润 | 反而不耐涝，积水会导致根部腐烂 |
| 总蒸散量 | - | 每㎡约100L | 相当于马铃薯的20%的水平 |

&nbsp;&nbsp;&nbsp;这张表中最令人惊讶的一栏是耗水量。马铃薯整个生长期要用掉500-700mm的水，而菊芋只需要100mm左右。韩国年降水量在1,200mm左右，这意味着即便是再干旱的年份，仅靠自然降水也足够了。在没有电抽水、也没有人能挑水的情况下，不需要灌溉这一条件是决定性的。事实上，河滩上的野生菊芋即便没有人浇水，每年也能长得比人高。

&nbsp;&nbsp;&nbsp;不过它出乎意料地不耐涝。耐旱和耐涝是两件不同的事。根部若浸水数日，氧气被切断，块茎就会软化并招致软腐病。这也是选择栽培环境时唯一需要留意的条件。

### 3-2. 灾害情况下的选址

| 条件 | 判断 |
|---|---|
| 河滩、堤坝、水渠边的高地 | 最好。靠近水源但不积水 |
| 废弃田地、混有砾石的贫瘠地 | 好。能把别的作物放弃的土地变成产粮之地 |
| 屋后、篱笆外、山脚 | 好。可以利用非田地的空间 |
| 兼作防风带的田边 | 好。株型高，能起防风作用 |
| 菜园正中间 | 避免。会蔓延挤占其他作物 |
| 积水的低洼地 | 避免。这是唯一的弱点 |
| 需要经常翻耕的主要田地 | 避免。种下后无法恢复原状 |

> **菊芋不是种在好田里的作物，而是把非田地变成田地的作物。而且一旦种下，就很难恢复原状。**

## 4. 品种

### 4-1. 品系比较

&nbsp;&nbsp;&nbsp;菊芋是一种正式品种体系比较松散的作物。在韩国国内流通的大多是从野外采集或早已扩散开来的本地品系，而带名字的品种大多是从海外引进的。

| 品系 | 产量与繁殖力 | 栽培难易度 | 适宜环境 | 口感 | 灾害适用度 |
|---|:---:|:---:|---|---|:---:|
| 野生·本地品系 | 繁殖力极强，放任也能再生 | 可放任不管 | 从冷温带到温带都适应 | 带土腥味，口感粗糙 | 最优先 |
| 富索(Fuseau) | 稳定 | 容易 | 温带，凉爽的夏季 | 光滑爽脆 | 高。处理简便，很实用 |
| 斯坦皮德(Stampede) | 早熟且块茎粗大 | 非常容易 | 寒冷地区，夏季短 | 味道温和，爽脆 | 高。生长期短的地区首选 |
| 矮生阳光(Dwarf Sunray) | 中等 | 容易 | 温带，多风地区 | 软嫩顺滑 | 一般。株型矮小不易倒伏 |
| 红富索(Red Fuseau) | 稳定 | 容易 | 温带 | 香醇可口 | 一般。红色色素是抗氧化成分 |
| 斯科罗斯佩尔卡(Skorospelka) | 早熟 | 耐寒性极强 | 极寒冷地区，夏季极短 | 味道温和 | 高。专门适应严寒地区 |

### 4-2. 按情况选择的标准

| 情况 | 选择 | 理由 |
|---|---|---|
| 无法获得种薯时 | 野生品系 | 秋天在河滩或路边挖取即可 |
| 想尽快扩繁时 | 野生品系 | 繁殖力最强 |
| 需要经常处理和烹饪时 | 富索 | 表皮光滑，清洗削皮都容易 |
| 早霜的高海拔地区 | 斯坦皮德、斯科罗斯佩尔卡 | 早熟，即使夏季短也能结实 |
| 风大的地方 | 矮生阳光 | 株型矮小，倒伏较少 |

&nbsp;&nbsp;&nbsp;在灾害情况下，菊芋的优势不在于品种，而在于韩国国内栽培普及度SS这一项。由于它已在韩国8个道全境自生并归化，即使在种子流通完全中断的情况下，只要记住秋天开黄花的地方，霜后去挖，就能直接当作种薯使用。这与必须购买种子、必须购买苗的作物，起点完全不同。

## 5. 整地与施肥

### 5-1. 整地

| 项目 | 标准 | 理由 |
|---|---|---|
| 耕地 | 深度20-30cm | 耕得越深，块茎越大，也越容易挖 |
| 垄高 | 30cm以上 | 防止唯一的弱点——积水过湿 |
| 排水沟 | 30cm以上 | 积水会使块茎变软腐烂 |
| 土壤酸度 | pH5.8-7.0 | 不特意调整也能生长 |
| 位置 | 单独划出一块区域 | 因为存在化感作用和过度繁殖的问题 |
| 边界阻隔 | 深40-60cm的挡板或沟渠 | 阻止地下茎向两侧扩展 |

&nbsp;&nbsp;&nbsp;设置边界阻隔不是可选项，而是必须做的工作。菊芋的地下茎一年能伸展将近1m，每个末端都会长出新的块茎。若不采取任何措施，两三年内就会侵占到邻近的地里。木板、石板、铁皮，无论哪种材料，只要埋入地下40cm以上立起来，大多都能挡住。也可以挖沟来设边界，但这种方法每年都要沿沟用铁铲把越过来的根切断。

### 5-2. 标准施肥量(以1,000㎡为准)

| 肥料 | 施肥量 | 备注 |
|---|:---:|---|
| 氮(N) | 尽量减少 | 过量会导致只长叶子，块茎减少 |
| 磷酸(P) | 3-4kg | 有助于根系发育 |
| 钾(K) | 3-5kg | 对块茎膨大最为重要 |
| 堆肥 | 1,000-1,500kg | 腐熟堆肥，全部作基肥 |

&nbsp;&nbsp;&nbsp;马铃薯的标准施肥量按氮磷钾合计约为32g ㎡，相比之下菊芋只需25%以下，而且即便不给这些也能生长。施肥需求SS这个等级的意思不是"可以少施"，而是"完全不施也可以"。事实上，野生种群不施任何肥料，每年也能长得比人高。因此在灾害情况下，有限的堆肥不应用在菊芋上，而应留给像马铃薯、大白菜这类需要施肥的作物，这样才能提高整体收成。

### 5-3. 基肥与追肥

| 类别 | 时期 | 内容 |
|---|---|---|
| 基肥 | 种植前 | 堆肥、磷酸和钾，氮尽量减少 |
| 追肥 | 7月中旬(可选) | 只有以高产为目标时才需要，不做也无妨 |
| 覆盖 | 种植后 | 铺5-10cm的落叶或稻草，只需压住初期杂草即可 |

### 5-4. 没有化肥时——灾害应对代用肥料

| 替代资源 | 提供的养分 | 制法与用法 | 注意事项 |
|---|---|---|---|
| 草木灰 | 钾、磷酸、钙 | 阔叶树灰含钾较多，每㎡施一把 |
| 腐熟堆肥 | 综合养分 | 将落叶、杂草与粪肥堆放腐熟6个月以上 | 未腐熟会伤根 |
| 落叶覆盖 | 有机质、保湿 | 厚厚地铺在垄面上 | 放着不管，第二年就会化作土壤 |
| 骨粉 | 磷酸、钙 | 烧后捣碎，混入堆肥 | 见效较慢 |
| 稀释尿液 | 氮 | 最好不要使用 | 氮对菊芋有害 |
| 地上部残体 | 有机质、钾 | 把秋天割下的茎秆直接覆盖在原地 | 是最简便的自给肥料 |

&nbsp;&nbsp;&nbsp;最后一行正是种植菊芋的要领。一年内长到3m高的茎叶是相当可观的有机质，其中含有从地里吸收上来的钾。如果不烧掉、不清走，而是就地割倒覆盖，养分就会在田里循环。冬天它能起到覆盖保温的作用，防止地面深度冻结，到了春天又会腐烂变成有机质。这样一来，不从外部引入任何东西，田地也能维持下去。

## 6. 种薯准备与栽种

### 6-1. 种植时期

| 栽培方式 | 时期 | 备注 |
|---|---|---|
| 春种 | 3-5月，土壤解冻后即可 | 最常见 |
| 秋种 | 10-11月 | 让其直接越冬，第二年春天发芽 |

&nbsp;&nbsp;&nbsp;能够秋种这一点，在灾害情况下意义重大。秋天挖出的块茎在常温下2-4周就会开始干缩，如果没有合适的地方存放，直接种下去才是最可靠的保存方法。它会在地下过冬，春天自己发芽，这种方法把搭建贮藏设施的劳动和风险彻底省掉了。

### 6-2. 种薯准备

| 项目 | 标准 | 理由 |
|---|---|---|
| 大小 | 鸡蛋大小，30-50g | 太小会导致早期生长迟缓 |
| 切块 | 较大的种薯切块时保留2-3个芽眼 | 以节省种薯 |
| 切面 | 在阴凉处晾1天使切口愈合 | 防止在地下腐烂 |
| 草木灰处理 | 在切面上蘸草木灰 | 兼具消毒与干燥的作用 |
| 挑选 | 剔除有病和发软的种薯 | 病害大多是随种薯带入的 |
| 保存 | 挖出后立即种下最好 | 干燥后会导致发芽延迟 |

### 6-3. 栽种

| 项目 | 标准 | 理由 |
|---|---|---|
| 种植深度 | 5-10cm | 太浅不耐旱，太深则出苗延迟 |
| 株距 | 30-45cm | 窄一些也能生长，但块茎会变小 |
| 行距 | 60-70cm | 保证通风和光合作用 |
| 种植方向 | 芽眼朝上 | 与美洲土圞儿不同，对方向不太敏感 |
| 种植后 | 覆土并轻轻压实 | 无需灌溉 |

&nbsp;&nbsp;&nbsp;菊芋基本上不存在种子消毒这个概念，因为它不是靠种子繁殖，而是靠块茎繁殖，随种薯带入的病害也不多。只需将切面晾1天使其愈合，再蘸上草木灰就足够了。在没有药剂的情况下，这不是一个小优点。
