## 引言
&nbsp;&nbsp;&nbsp;菊芋（Helianthus tuberosus）在韩国也叫“ttungttanji”，是菊科向日葵属的多年生草本，与土豆没有关系。它来自北美洲中部，朝鲜后期作为饲料传入后从田里逃了出去，如今在全国的路边、河滩和废弃的田里长得比人还高。在灾害应对评估中，它的综合等级为SS（58.8分，有效183种中第3位），短期、长期、副食也都是SS。带SS的九个项目大多是在问人必须投入什么。如果说平时的评估是比拼好条件下能收多少，那么灾害应对评估就是在问毫无条件时还剩下什么，项目一换，冠军也就换了。不过这个分数的依据很浅，初次吃的人会因菊粉而出现严重的胀气和腹痛，而且一旦种下就无法清除。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | SS | 58.8 |
| 短期 | SS | 57.7 |
| 长期 | SS | 60.0 |
| 副食 | SS | 71.7 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：持续性、施肥、水消耗量、设施负担、温度幅度、耐寒性、连作适应性、整地·挖掘能量、国内种植普及度。S：蛋白质密度、口味、自留种。A：微量营养素、烹调·加工要求度。B：单位面积热量、光照、无合成投入产量保持率、产量稳定性 |
| 劣势 | E：种子寿命。D：收获速度、非食用价值。C：病虫害压力、防治自立度、耐储性 |

> **菊芋排名靠前，不是因为产量多，而是因为任何年份都不会绝收。**

&nbsp;&nbsp;&nbsp;单位面积热量B，是每㎡1,400kcal、自给线的0.54倍，也就是一个人要靠它生活需要近200㎡的田，比土豆低。尽管如此仍是SS，是因为它不需要肥料、灌溉和设施，能从残留的块茎自己再长出来，挖掘能量分摊到10年（每年22kcal，换回的热量是134倍，土豆10.6倍），再加上25℃的温度幅度和零下20℃以下的耐寒性，坏年景只是变小而不会消失。灾害中需要的不是好年景的最大产量，而是坏年景的最低保障。各项目的等级见“灾害应对作物评价结果”文档。

| 项目 | 显示值 | 实际依据 |
|:---|:---|:---|
| 单位面积热量 | 4,000kg/1,000㎡ | 没有官方单产统计，是按良好条件假设的值 |
| 每100g热量 | 35kcal | 其他资料为68-76kcal，相差一倍。菊粉不被消化，身体实际利用的热量更接近较低的数值 |
| 病虫害压力、无合成投入产量保持率 | 减产率50.6%、45.1% | 借用整个双子叶植物纲的推测值，以及把土豆的有机栽培产量比套用到整个薯类的替代值。防治自立度C是因这些依据薄弱而调低的值，实际上几乎不需要防治 |

&nbsp;&nbsp;&nbsp;副食SS（71.7）来自蛋白质2.18g除以热量35kcal得出的24.9%，是分母小才显得高。要凑够每天2,100kcal得吃6kg，所以菊芋不是主食，而是辅助主食、在没有主食的年头让人不致饿死的作物。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 菊科向日葵属多年生草本。原产北美洲中部和东部 |
| 叶、茎 | 宽卵形，先端尖，边缘有锯齿。茎笔直站立，可长到1.5-3m，带粗糙的刚毛 |
| 花 | 8-10月开直径5-8cm的黄色头状花序（像小向日葵） |
| 块茎 | 形状像凹凸不平的生姜，有红色、白色和带紫色的。长在根端和地下茎端 |

&nbsp;&nbsp;&nbsp;4月地面解冻后，块茎的芽眼里长出新芽，5-7月茎每天长几厘米，8-10月开花。块茎膨大得晚，整个夏天只长茎叶，到日照变短的9月底才开始结块茎，霜降之后最大最甜。每100g含热量35kcal（韩国国家标准食品成分表）、碳水化合物约17g（大部分是菊粉，几乎没有淀粉）、蛋白质2.18g、脂肪0.01g、糖类6.37g（储存和加热中菊粉分解而增多）、钾约630mg，比土豆和甘薯都多。菊粉是果糖连成长链的多糖，人的消化酶切不断它。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 生长5-30℃（适宜18-25℃），幅度达25℃。零下20-30℃也能在地下存活，在韩国全境不用任何措施即可越冬。发芽需5-10℃以上，所以地一解冻就能种 |
| 水分、光照 | 可不灌溉栽培，只在块茎膨大期保持湿润即可。每天6小时以上（适宜8小时以上）日照，遮光40%时产量约80% |
| 土壤 | pH5.0-8.0（适宜5.8-7.0），几乎不挑。排水良好的砂壤土-壤土最适宜，黏土中块茎会畸形且难挖 |

&nbsp;&nbsp;&nbsp;它反而怕过湿，水积几天块茎就会变软并染上软腐病，所以栽培环境里要留意的条件只有这一个。河滩和堤坝、沟边的土坡（离水近但不积水）、废弃的田和夹着砾石的贫瘠地、房后、围栏外和山脚、兼作防风的田边都适合；要避开菜园中央、积水的低洼地和需要经常翻耕的主力田。

> **菊芋不是种在好田里的作物，而是把不是田的土地变成田的作物。而且一旦种下就很难回头。**

&nbsp;&nbsp;&nbsp;品种体系比较松散，野生·土生品系繁殖力最强、灾害适应度最高，秋天在河滩或路边挖来就是种块茎。还有易于处理的Fuseau、适合寒冷地区的早熟品种Stampede和Skorospelka，以及植株矮小、抗风的Dwarf Sunray。

## 4. 整地与种植
| 项目 | 标准 |
|:---|:---|
| 整地 | 翻耕20-30cm深（越深块茎越大、越好挖），起30cm以上的垄和30cm以上的排水沟。单独划分地块，并埋入40-60cm深的木板或挖沟作隔离带，这是必须的（地下茎一年伸出近1m，两三年就会占领邻田） |
| 施肥（1,000㎡） | 氮尽量少（过多只长叶、块茎减少），磷3-4kg，钾3-5kg（对块茎膨大最重要）。不到土豆用量的25%，不施也能长，所以有限的堆肥留给土豆或白菜。用落叶或稻草覆盖5-10cm |
| 灾害替代肥料 | 木灰（每㎡一小撮）、落叶覆盖、把秋天割下的茎就地盖回（最简便的自给肥料，钾得以循环，冬天还能当覆盖物）。氮对它有害，所以不用稀释尿液 |
| 种块茎 | 鸡蛋大小的30-50g（小了初期生长晚）。大的切成每块带2-3个芽眼，切口蘸木灰，在阴凉处晾一天愈合。剔除有病的和变软的，挖出后立即种最好 |
| 种植 | 春季地一解冻就在3-5月种，秋季在10-11月种（原样越冬，来春发芽，所以以种代储最可靠）。深5-10cm，株距30-45cm，行距60-70cm，芽朝上。盖土轻压，不必灌水 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 种后立即 | 浇一次透水 |
| 营养生长期（5-7月） | 交给自然降水（过湿反而有害） |
| 块茎膨大期（9-10月） | 只在严重干旱时补水（只有这一时期的干旱会影响产量） |
| 成熟期（11月以后） | 停止灌水 |

| 管理 | 方法 |
|:---|:---|
| 打顶 | 5月株高约1m时和7月各掐一次顶芽，8-9月摘除花蕾，把株高控制在1.5m左右（既避免养分损失和秋台风倒伏，又让养分流向块茎）。掐下的顶芽用作覆盖物 |
| 防倒伏 | 基部培土、把几株捆在一起的围绳、密植、迎风一侧设围栏或种其他作物 |
| 其他管理 | 除草在5-6月做一两次即可（植株长高后杂草会自行消失）。秋天割地上部时，沿地块边界把铁锹深深插入，切断越界的地下茎，这项边界检查是每年都不能漏掉的唯一一项作业 |
| 积水症状 | 下部叶片发黄、基部发黑就立即疏通排水沟；基部变软并出现白色菌丝（白绢病）就把该株拔掉烧毁 |

## 6. 病虫害与养分问题
&nbsp;&nbsp;&nbsp;下列病害很少使整块田绝收。野生种群没有任何防治也维持了几十年，所以保证排水、通风，发现病株就当场拔掉烧毁，这样就够了。在灾害中威胁菊芋的不是病菌，而是野兽。

| 病虫害 | 症状与条件 | 不用药的防治 |
|:---|:---|:---|
| 白绢病、菌核病 | 根颈部扩散白色菌丝，植株突然萎蔫死亡（高温高湿） / 茎变软，长出白色绵状菌丝和黑色菌核（凉爽潮湿时） | 改善排水，清除并烧毁病株，在该处撒木灰 / 保证通风，3-4年轮作 |
| 锈病、白粉病、细菌性软腐病 | 叶背出现橙褐色粉末（梅雨季） / 叶面出现白粉 / 块茎变软发臭（收获时的伤口、过湿） | 保证通风并清除病叶 / 牛奶稀释10倍或小苏打稀释液（每1L水5g） / 挖掘时不伤块茎并晾干，病块茎立即丢弃 |
| 蚜虫 | 吸食新芽汁液 | 避免氮过量，保护瓢虫，水洗、肥皂水、木灰 |
| 田鼠、野猪 | 大量啃食地下块茎 | 清除田边杂草，在分区周围埋铁丝网或木板，设围栏。这是原地储存的最大风险，所以不要把全部放在一处，而是分成几块 |

| 症状 | 原因与措施 |
|:---|:---|
| 只有叶茎茂盛、块茎小（株高超过3m） | 氮过剩，是最常见的问题。停止施氮，用打顶来平衡 |
| 叶缘焦褐（块茎膨大期） / 叶片发紫（低温期） | 缺钾 / 缺磷。木灰 / 骨粉和木灰 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 防风隔离作物（植株高，能挡风）、蜜源植物（秋天开的花招引蜜蜂）、饲料地块（茎叶作牲畜饲料） |
| 一般 | 无。因化感作用本身就不适合间作，单独分区种植是原则 |
| 差 | 豆类、番茄和大部分蔬菜（化感物质抑制1m以内邻近作物的生长）、田中央的任何作物（地下茎侵入并将其挤走） |

&nbsp;&nbsp;&nbsp;连作适应性SS是指可以永久留在同一个位置，这就是基本种法，白绢病严重了再挪。要换区的话，必须在旧地上连续3-5年清除不断冒出的芽。持续性SS的另一面是一旦种下就无法清除：一株一年产生几十个块茎，向四周散布1m以上，哪怕只剩下指甲盖大的一小块，第二年也会发芽。一次深挖效果很低，最有效的办法是饿死它。趁芽还没展叶就不断割掉，让块茎无法补充储备，2-3年密度就会大幅下降；用厚布或木板完全盖住1-2年，或者放猪去拱食，效果也很高。即便如此，彻底根除在现实中仍然很难。

> **种菊芋是无法反悔的决定。不要种在田中央，而要种在边界或边角地，从一开始就埋下隔离墙，是唯一简便的对策。**

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 初霜之后是最佳时期（地上部枯死，菊粉和甜度达到最高，低温使一部分菊粉分解成较短的链而更甜）。从11月中旬到次年3月四个多月随时可挖，种块茎在3月挖。9月以前块茎还没长成，会损失大部分产量 |
| 要领 | 把地上部茎在基部割断，就地盖上，用锄头或三齿叉把土翻起，露出块茎。不要用铁锹猛劈（受伤的块茎很快变软）。只抖掉泥土，不要水洗（水洗会使储存期缩短一半） |
| 分拣 | 大而无瑕的当场吃或放进窖里，中等的切片晒干做成干片和粉，30-50g的小块茎单独收集作种块茎。挖出后水分立刻开始流失，所以只挖这周要吃的量就是最好的储存策略 |

| 留种 | 标准 |
|:---|:---|
| 种块茎 | 种子寿命为E，但地里的块茎本身就是种子库。把30-50g、结实、芽眼活着且无病症的块茎在3月种植前挖出，立即种下 |
| 增殖 | 种下十个，当年秋天就有几百个，第二年有几千个，两年就能铺满相当大的面积。几乎没有病毒退化的报告 |
| 种子繁殖 | 在韩国气候下种子不易成熟，发芽率低，所以不用。繁殖只靠块茎，容易在遗传上趋于单一，所以要从多处取种块茎混合种植 |

## 9. 储存
&nbsp;&nbsp;&nbsp;菊芋不像土豆那样有厚的木栓层，挖出后放在常温下2-4周（快的几天）就会皱缩，所以最大的敌人不是腐烂，而是干燥。因此储存的第一原则不是建储藏库，而是不挖。

| 方式 | 方法 | 期限 |
|:---|:---|:---|
| 原地越冬储存 | 不收获，留在地里。初霜后割掉地上部，盖上20-30cm的稻草或落叶（块茎冻了也不会死，盖草是为了防止土地冻得像石头一样、铁锹插不进去）。缺点是会成为田鼠和野猪的目标 | 整个冬天，到来年春天 |
| 窖、地窖储存 | 与湿沙、土或锯末层层埋入，保持0-4℃、湿度85-95% | 2-3个月 |
| 坑储存 | 挖30cm，按稻草、块茎、稻草、土的顺序堆成坟包状。与土豆不同，要在中间填入湿沙或腐叶土以免变干，盖上20-30cm稻草和15cm土后，在顶部用草束做通气口，每2周打开检查一次 | 1-2个月 |
| 干燥片、粉 | 切成2-3mm薄片，在阳光下或用灶台余热彻底晒干。体积和重量大幅减小。粉要密封，并放灰或木炭作干燥剂 | 干片数月到数年，粉1-2年 |
| 乳酸发酵、酱菜、醋渍 | 在2-3%盐水中常温1-2周 / 埋进酱油或大酱 / 浸入煮开的醋水（酸味有助于分解菊粉）。成为小菜，同时减轻消化负担 | 数月到1年 |

> **储存策略的标准是并用。大部分原样留在地里，一部分做成干片和粉以防备野兽和严寒，一部分发酵成减轻消化负担的小菜。**

## 10. 烹调与注意事项
&nbsp;&nbsp;&nbsp;菊芋不含有毒物质，生吃也不会中毒，但初次吃的人吃饱的话，几乎必定出现严重的腹胀和腹痛。因为人的消化酶切不断菊粉的键，菊粉直接通过胃和小肠到达大肠，大肠细菌发酵它，产生大量的氢气、二氧化碳和甲烷。不过，持续吃菊粉会改变大肠细菌的组成，几周内症状就会明显减轻，所以从每天50g开始、用两周逐步增加的方式比较稳妥，并且要在灾害发生之前或初期就开始少量多次地让身体适应。

| 摄入量 | 不习惯的人 | 已适应的人 |
|:---|:---|:---|
| 100-150g | 轻微腹胀 | 无症状 |
| 200-300g | 明显腹胀、频繁放屁、腹部不适 | 轻微腹胀 |
| 500g以上 | 严重腹痛、腹泻，持续数小时 | 腹胀和放屁 |

| 注意 | 内容 |
|:---|:---|
| 对象 | 儿童按体重计的摄入量更大，要从更少的量开始；患肠易激综合征的人限制为少量；已在腹泻的人不要让其吃。糖尿病患者因其不会使血糖快速升高，反而有利 |
| 减少胀气 | 少量多次吃效果最大，在盐水中乳酸发酵1-2周最可靠，因为细菌提前分解了菊粉。久煮、加醋煮、低温储存后再烹调、长期干燥也有一定帮助 |
| 其他注意 | 可以生吃，但腹胀更重，所以煮熟吃更好；茎叶人不吃，可作牲畜饲料。变软发臭的块茎要丢弃 |

| 烹调 | 方法 |
|:---|:---|
| 节省燃料 | 加热10分钟就够。煮是入水10-15分钟，蒸是放少量水15分钟，余热烹调是煮5分钟后关火用布裹住闷30分钟，灰烤是埋进热灰带皮烤20-30分钟，粉倒入沸水中搅开即熟。煮得越久菊粉分解得越多、负担越轻，所以没适应之前多煮一会儿，适应之后少煮 |
| 口味、吃法 | 生吃像梨和莲藕混合一样脆甜，煮熟后变软、甜味增强，没有淀粉感。不用削皮，用刷子刷掉泥土即可，切开后容易变褐，所以泡在醋水里。大酱汤、炖菜、油炸、腌制都可以，煮的水里溶有糖和钾，可以当汤用 |
| 加工 | 干片可直接吃，或泡发后放进汤里；把干片磨成的粉掺进谷物粉或煮粥；炒过的用来泡茶。长时间熬煮会使菊粉分解而成为果糖浆 |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 只挖要吃的量（拨开稻草挖后再盖上），检查储存的块茎。2月翻堆堆肥，选定新分区的位置和隔离墙 |
| 3-4月 | 3月采集并挑选种块茎，地一解冻就开始种。4月种完，覆盖（不必灌水） |
| 5-6月 | 5月确认出苗，第一次打顶（株高约1m），除草。6月除草收尾（之后杂草自行消失） |
| 7-8月 | 7月第二次打顶，防倒伏（株高1.5m左右）。8月摘花蕾，防台风 |
| 9-10月 | 9月块茎开始变粗，仅在严重干旱时灌水。10月观察开花，准备收获（不要着急） |
| 11-12月 | 11月初霜后割掉地上部，第一次收获，盖20-30cm稻草（只挖需要的量）。12月收获所需的量，晒干和发酵加工（为防兽害，把一部分转移到室内） |

> **菊芋是这样一种作物：一开始从50g起少量吃，因为无法反悔而连同隔离墙一起种在边界或边角地，等初霜后只挖需要的量，把不挖、留在地里当作储存，并且不施肥。**
