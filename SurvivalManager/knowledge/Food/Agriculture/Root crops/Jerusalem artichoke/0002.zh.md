### 1-3. 近乎野生的作物为何超越了谷物

&nbsp;&nbsp;&nbsp;菊芋的单位面积热量仅为B。每㎡1,400kcal，为自给线的0.54倍，也就是说，一个人若只靠它生活，需要将近200㎡的地。低于马铃薯，是木薯的三分之一。收获速度也是D。尽管如此，综合等级却是SS，原因是这项评价衡量的不是产量，而是别的东西。

&nbsp;&nbsp;&nbsp;第一是投入。施肥需求SS意味着完全不施肥也可以。耗水量SS意味着不灌溉、仅靠自然降水就能种植成立。总蒸散量约为每㎡100L左右，相当于马铃薯的20%的水平。设施负担SS意味着不需要地膜、大棚或支架。在灾害情况下，这三点不只是节省成本，而是能种与不能种的分界线。当买不到氮肥、没有电抽水、也买不到地膜时，需肥量大的谷物根本无法种下去。菊芋是在这种条件下仍能种植的少数作物之一。

&nbsp;&nbsp;&nbsp;第二是持续性。一年生谷物年年都要翻地、播种、还要护种。这三项工作只要有一项失败，当年的收成就会全部落空。菊芋则靠残留的块茎自行再生。挖掘能耗按10年分摊，年均只有22kcal，投入的挖掘能耗与回收热量之比达到134倍，而马铃薯只有10.6倍。在人力是唯一动力的情况下，这十二倍的差距，直接就是能耕种面积的差距。

&nbsp;&nbsp;&nbsp;第三是环境适应。温度适应幅度25℃，耐寒性零下20℃以下，能适应贫瘠土壤，并在韩国全境野生自生。这四点叠加，得出的结果就是"无论那一年是什么样的年份，菊芋都活下来了"。谷物只要遇上一次冷害或一次干旱，整片地就会绝收。菊芋在坏年份只是长得小一些，并不会消失。灾害情况下需要的不是好年份的最大产量，而是坏年份的最低保障。

> **菊芋能名列前茅，不是因为产量高，而是因为无论哪一年都不会绝收。**

### 1-4. 但这个分数的依据并不牢固

&nbsp;&nbsp;&nbsp;菊芋是官方统计之外的作物。它不是韩国作况调查的品目，也没有长期试验数据。评价表中的许多栏目，填的不是实测值，而是估计值和插补值。

| 项目 | 表中数值 | 实际依据的性质 |
|:---|:---|:---|
| 单位面积热量 | 4,000kg/1,000㎡ | 没有官方单产统计，是按良好条件假设的数值 |
| 每100g热量 | 35kcal | 其他资料记为68-76kcal，相差两倍 |
| 病虫害压力 | 估计减产率50.6% | 并非菊芋的实测值，而是从双子叶植物纲整体借用的可信度L6估计值 |
| 防治自立度 | C | 因减产率的依据较弱而一并调低的数值，实际上几乎不需要防治 |
| 无合成投入产量保持率 | 45.1% | 是把马铃薯的有机/常规产量比套用到薯类整体得出的插补值 |
| 确证系数 | 0.986 | 意味着25个单元格中有1个是用下层插补填上的 |

&nbsp;&nbsp;&nbsp;热量数值的差异尤为重要。菊芋的碳水化合物大部分是菊糖，菊糖无法被人体的消化酶分解。它不在小肠被吸收，而是直接进入大肠由细菌发酵，在这个过程中人体实际获得的热量远低于同等重量的淀粉。韩国国家标准食品成分表中的35kcal正是反映了这一点，而68-76kcal这个数值则是把碳水化合物按淀粉来计算得出的。实际上人体能利用的热量更接近较低的那个数字。

&nbsp;&nbsp;&nbsp;而这一事实也让人重新审视副食等级SS（71.7）。蛋白质密度评为S级，是把蛋白质2.18g除以热量35kcal得出的24.9%算出来的。这个比例高，不是因为分子大，而是因为分母小。吃100g菊芋获得的蛋白质绝对量是2.18g，只比马铃薯略多一点。虽然按热量折算表现不错，但也必须同时看到热量本身偏低这一事实。若靠菊芋满足每日2,100kcal，需要吃6kg，这不是人实际能吃下的量。评价表微量营养素一项中"实际需要6.0kg"写的正是这个意思。

> **菊芋不是主食，它是用来补充主食、并在没有主食的年份里让人不至于饿死的作物。**

## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

&nbsp;&nbsp;&nbsp;菊芋是菊科（Asteraceae）向日葵属（Helianthus）的多年生草本植物。它与向日葵同属，花看起来就像一朵小向日葵。它与马铃薯连科、目都不同。名字里带"芋"，只是因为它地下会长出块茎。英语圈称它为"耶路撒冷朝鲜蓟"，这个名字同样没有根据，它和耶路撒冷毫无关系，也不是朝鲜蓟。

&nbsp;&nbsp;&nbsp;它原产于北美中部到东部，生长在草原、河边和林缘那些荒废的土地上。这里说的荒废土地，是指洪水冲刷过的地方、山火烧过的地方，以及野兽翻掘过的地方。能在这种地方存活下来的植物，策略是固定的：迅速长高以独占阳光，在地下形成贮藏器官为来年做准备，哪怕只剩一小块碎片也能再生。菊芋的一切特性——能长到3m高的株型、地下的块茎，以及惊人的繁殖力——都源自这一策略。而这一策略在灾害情况下对人极为有利，因为荒废的土地正是灾后最常见的土地。

### 2-2. 形态特征

| 器官 | 特征 |
|---|---|
| 叶 | 呈宽卵形，叶尖尖，边缘有锯齿。下部叶对生，上部叶互生 |
| 茎 | 直立生长，可达1.5-3m，全株覆有粗糙的硬毛 |
| 根 | 向地下深处伸展，根尖和地下茎顶端会结出块茎 |
| 花 | 花期为8-10月，黄色头状花，直径5-8cm，形似小向日葵 |
| 块茎 | 形状凹凸不平，像生姜。有红色、白色和带紫色的品种 |
| 种子 | 会结出瘦果，但不用于繁殖 |

&nbsp;&nbsp;&nbsp;块茎表面凹凸不平、须根多，这一点在实际操作中很重要。它不像马铃薯那样光滑，削皮麻烦，缝隙里还容易卡土，清洗也费事。因此在商业上被视为一种费工的作物。但它不削皮也能吃，反而皮里营养更多，所以在灾害情况下这不算问题，只要用刷子刷掉泥土就够了。

### 2-3. 生长阶段

| 阶段 | 时期 | 关键生理活动 | 重要养分 |
|---|---|---|---|
| 发芽·早期定植 | 4月 | 土壤解冻后，块茎的芽眼开始发芽 | 磷酸、少量氮 |
| 营养生长期 | 5-7月 | 茎每天生长数厘米 | 氮、钾 |
| 开花期 | 8-10月 | 开出黄色的花，从这时起块茎开始膨大 | 钾 |
| 块茎膨大期 | 9-11月 | 叶片制造的糖转化为菊糖，储存在地下 | 钾、磷酸 |
| 成熟·贮藏 | 初霜前后 | 地上部分枯死，只剩下块茎，此时菊糖含量最高 | 停止灌溉 |

&nbsp;&nbsp;&nbsp;块茎膨大开始得晚，这一点很重要。整个夏天只长茎叶，要等到日照变短才真正开始往地下储存养分。所以8月挖开来看什么都没有，要到9月底才开始结出块茎，霜降之后才长得最粗最甜。心急提早挖，会损失大部分产量。等到初霜之后才收获，是菊芋收获的原则。

### 2-4. 每100g的营养成分

| 营养素 | 含量 | 备注 |
|---|:---:|---|
| 热量 | 35kcal（韩国国家标准食品成分表） | 其他资料为68-76kcal，是菊糖热量换算方式不同所致 |
| 碳水化合物 | 约17g | 大部分是菊糖，几乎不含淀粉 |
| 蛋白质 | 2.18g | 作为薯类而言，含量不算少 |
| 脂肪 | 0.01g | 基本可以忽略 |
| 糖类 | 6.37g | 在贮藏和加热过程中，菊糖分解会使其含量增加 |
| 钾 | 约630mg | 高于马铃薯和甘薯 |
| 铁 | 含有 | 在薯类中含量偏高 |
| 维生素C | 含有 | 加热后会损失相当一部分 |
| 菊糖 | 丰富 | 是人体无法消化的多糖 |

&nbsp;&nbsp;&nbsp;理解菊芋的关键在于菊糖。菊糖是果糖长链连接而成的多糖，在化学结构上与马铃薯的淀粉不同。人的消化酶能分解淀粉，却分解不了菊糖。因此菊糖会原样穿过胃和小肠，进入大肠，成为那里细菌的食物。这一特性若发挥好的一面，会使肠道内益生菌增加、血糖上升变得缓慢；若发挥坏的一面，就会产生大量气体和腹痛。第14节会详细说明，但想把菊芋用作灾难食物的人，最先该了解的不是栽培方法，而是这一特性。
