### 1-3. ほぼ野生の作物が穀物を上回った理由

&nbsp;&nbsp;&nbsp;キクイモの面積当たり熱量はBに過ぎません。㎡当たり1,400kcalで自給ラインの0.54倍、つまり一人がこれだけで生きるには200㎡近い畑が必要です。ジャガイモより低く、キャッサバの3分の1です。収穫速度もDです。それでも総合がSSである理由は、この評価が収量ではなく別のものを測っているからです。

&nbsp;&nbsp;&nbsp;第一は投入です。施肥SSは肥料を全く与えなくてもよいという意味です。水消費量SSは灌水なしで自然降水だけで栽培が成り立つという意味です。総蒸発散量は㎡当たり100L前後で、ジャガイモの20%の水準です。施設負担SSはビニールもハウスも支柱も必要ないという意味です。災害時にはこの三つは単純なコスト削減ではなく、可能と不可能の境界です。窒素肥料が手に入らず、ポンプを回す電気がなく、ビニールも買えないとき、多肥性の穀物はそもそも植えることができません。キクイモはその条件下でも植えられる数少ない作物です。

&nbsp;&nbsp;&nbsp;第二は永続性です。一年生の穀物は毎年畑を耕し、種をまき、その種を守らなければなりません。この三つの作業のうち一つでも失敗すれば、その年の収穫はまるごと失われます。キクイモは残った塊茎から自然に再生します。掘削エネルギーは10年に分けて償却されるため年間22kcalに過ぎず、投入した掘削エネルギーに対する回収熱量は134倍です。ジャガイモは10.6倍です。人の体が唯一の動力である状況では、この十二倍の差はそのまま耕作できる面積の差になります。

&nbsp;&nbsp;&nbsp;第三は環境適応です。温度適応幅25℃、耐寒性はマイナス20℃以下、貧しい土壌への適応、韓国全土での自生。この四つが重なると、「その年がどんな年であってもキクイモは生き残った」という結果になります。穀物は冷害一度、干ばつ一度で畑全体が失われます。キクイモは悪い年には小さくなるだけで、消えることはありません。災害時に必要なのは良い年の最大収量ではなく、悪い年の最低保証です。

> **キクイモが上位に来た理由は、たくさん収穫できるからではなく、どんな年にも全滅しないからです。**

### 1-4. しかし、この点数の根拠は薄い

&nbsp;&nbsp;&nbsp;キクイモは公式統計の外にある作物です。韓国の作況調査の対象品目ではなく、長期試験データもありません。評価表の多くの欄は観測ではなく推定と代入で埋められています。

| 項目 | 表示された値 | 実際の根拠の性質 |
|:---|:---|:---|
| 面積当たり熱量 | 4,000kg/1,000㎡ | 公式の単収統計がありません。良好な条件を仮定した値です |
| 100gあたりの熱量 | 35kcal | 他の資料では68-76kcalとされています。二倍の差です |
| 病害虫圧 | 推定減収率50.6% | キクイモの実測値ではなく、双子葉植物綱全体から借用した信頼度L6の推定値です |
| 防除自立度 | C | 減収率の根拠が弱いため、合わせて下げた値です。実際には防除がほとんど不要です |
| 無合成投入での収量維持率 | 45.1% | ジャガイモの有機/慣行の収量比をいも類全般に適用した代入値です |
| 確証係数 | 0.986 | 25個のセルのうち1個が下位階層の代入で埋められたことを意味します |

&nbsp;&nbsp;&nbsp;熱量の値の違いは特に重要です。キクイモの炭水化物はほとんどがイヌリンで、イヌリンは人の消化酵素では分解されません。小腸で吸収されずに大腸まで下って細菌が発酵させるため、この過程で人が得る熱量は同じ重さのデンプンよりずっと少なくなります。韓国国家標準食品成分表の35kcalはこの点を反映した値で、68-76kcalという値は炭水化物をデンプンと同じように計算した値です。実際に体が使える熱量は低い方に近いといえます。

&nbsp;&nbsp;&nbsp;そしてこの事実は、副食等級SS(71.7)を見直させます。タンパク質密度Sという等級は、タンパク質2.18gを熱量35kcalで割った24.9%から出たものです。分子が大きいからではなく、分母が小さいから出た比率です。キクイモを100g食べたときに得られるタンパク質の絶対量は2.18gで、ジャガイモよりわずかに多い程度です。熱量比では優れていますが、熱量自体が少ないという事実も併せて見る必要があります。キクイモで1日2,100kcalを満たすには6kg食べなければならず、これは人が実際に食べられる量ではありません。評価表の微量栄養素の項目に「実際の必要量6.0kg」と書かれているのはこの意味です。

> **キクイモは主食ではありません。主食を補い、主食がない年に飢え死にしないようにしてくれる作物です。**

## 2. どんな植物か

### 2-1. 分類と原産地

&nbsp;&nbsp;&nbsp;キクイモはキク科(Asteraceae)ヒマワリ属(Helianthus)の多年草です。ヒマワリと同じ属で、花を見ると小さなヒマワリのような形をしています。ジャガイモとは科も目も異なります。名前に「イモ」がつくのは、地中に塊茎ができるためにすぎません。英語圏で「エルサレムアーティチョーク」と呼ぶのも同様に根拠のない名前です。エルサレムとは何の関係もなく、アーティチョークとも違う植物です。

&nbsp;&nbsp;&nbsp;原産地は北米中部から東部です。草原や川辺、森の縁の荒れた土地で育ちました。荒れた土地とは、洪水が押し流した跡地、山火事が通り過ぎた跡地、獣が掘り返した跡地を指します。こうした場所で生き残る植物の戦略は決まっています。早く大きく育って光を独占し、地中に貯蔵器官を作って翌年に備え、切れ端だけ残っても再生することです。キクイモのあらゆる性質、つまり3mまで伸びる高さと地中の塊茎、そして恐ろしい繁殖力はすべてこの戦略から来ています。そしてこの戦略は、災害時には人にとって非常に有利に働きます。荒れた土地こそが、災害後に最もありふれた土地だからです。

### 2-2. 形態

| 器官 | 特徴 |
|---|---|
| 葉 | 広い卵形で先端が尖り、縁には鋸歯があります。下部は対生し、上部は互生します |
| 茎 | 直立し、1.5-3mまで伸びます。全体にざらついた剛毛があります |
| 根 | 地中深くまで伸びます。根の先端と地下茎の先端に塊茎がつきます |
| 花 | 8-10月に咲きます。黄色の頭状花で、直径5-8cmの小さなヒマワリのような形です |
| 塊茎 | ゴツゴツしたショウガのような形をしています。赤いもの、白いもの、紫がかったものがあります |
| 種子 | 痩果ができますが、繁殖には使いません |

&nbsp;&nbsp;&nbsp;塊茎の形がゴツゴツしていて細根が多い点は、実際の作業では重要です。ジャガイモのように滑らかではないため皮をむくのが面倒で、隙間に土が入り込み洗うのも厄介です。このため商業的には手間のかかる作物として扱われます。しかし皮をむかなくても食べられ、むしろ皮の側に栄養が多いため、災害時には問題になりません。ブラシでこすって土だけ落とせば十分です。

### 2-3. 生育段階

| 段階 | 時期 | 主な生理 | 重要な養分 |
|---|---|---|---|
| 発芽・初期定着 | 4月 | 土が緩むと塊茎の芽から芽が出てきます | リン酸、少量の窒素 |
| 栄養生長期 | 5-7月 | 茎が一日に数cmずつ伸びます | 窒素、カリウム |
| 開花期 | 8-10月 | 黄色い花が咲きます。この頃から塊茎が太り始めます | カリウム |
| 塊茎肥大期 | 9-11月 | 葉で作られた糖がイヌリンに変わり、地中に蓄積されます | カリウム、リン酸 |
| 成熟・貯蔵 | 初霜の前後 | 地上部が枯れ、塊茎だけが残ります。この時イヌリン含量が最高になります | 灌水を停止 |

&nbsp;&nbsp;&nbsp;塊茎の肥大が遅く始まる点が重要です。夏の間はずっと茎と葉だけを育て、日が短くなり始めてようやく地中への貯蔵を始めます。そのため8月に掘ってみても何もなく、9月末になってやっと粒が付き始め、霜が降りた後に最も太く甘くなります。焦って早く掘ると、収量の大部分を失います。初霜を待つことがキクイモ収穫の原則です。

### 2-4. 100gあたりの栄養

| 栄養素 | 含量 | 備考 |
|---|:---:|---|
| 熱量 | 35kcal(韓国国家標準食品成分表) | 他の資料は68-76kcal。イヌリンの熱量換算の違いです |
| 炭水化物 | 約17g | 大部分がイヌリンです。デンプンはほとんどありません |
| タンパク質 | 2.18g | いも類としては少なくない量です |
| 脂質 | 0.01g | 実質的にありません |
| 糖類 | 6.37g | 貯蔵中や加熱中にイヌリンが分解されて増加します |
| カリウム | 約630mg | ジャガイモやサツマイモより多いです |
| 鉄 | 含有 | いも類の中では多い方です |
| ビタミンC | 含有 | 加熱するとかなりの量が失われます |
| イヌリン | 豊富 | 人が消化できない多糖類です |

&nbsp;&nbsp;&nbsp;キクイモを理解する鍵はイヌリンです。イヌリンは果糖が長くつながった多糖類で、ジャガイモのデンプンとは化学的に異なります。人の消化酵素はデンプンを切ることはできても、イヌリンは切ることができません。そのためイヌリンは胃と小腸をそのまま通過して大腸に到達し、そこに住む細菌の餌になります。この性質が良い方向に働けば、腸内の善玉菌が増え、血糖がゆっくり上がる効果になります。悪い方向に働けば、大量のガスと腹痛になります。第14節で詳しく取り上げますが、キクイモを災害食として使おうとする人が最初に知っておくべきことは、栽培法ではなくこの性質です。
