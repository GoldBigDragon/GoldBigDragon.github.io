## 12. 收获

### 12-1. 时期判断

| 类别 | 时期 | 判断标准 |
|---|---|---|
| 最佳时期 | 初霜降下之后 | 地上部分枯死，菊糖与糖度都达到最高 |
| 收获期 | 11月中旬至次年3月 | 长达四个多月，随时都能挖 |
| 留种用 | 次年3月 | 刚从地里挖出的状态最好 |
| 收获过早 | 9月以前 | 块茎尚未形成，会损失大部分产量 |

&nbsp;&nbsp;&nbsp;等待初霜有两个原因。一是霜降之前叶片会持续制造糖分并输送到地下，二是经历低温后，部分菊糖会分解成更短的链，甜度增加。霜前挖出的菊芋味道平淡，霜后挖出的则香甜。经过一整个冬天，这种变化会更加明显。

### 12-2. 收获要领

| 顺序 | 内容 |
|---|---|
| 1 | 从基部剪断地上部的茎，割下的茎覆盖在原地 |
| 2 | 从距离植株30cm以外的地方开始向内挖 |
| 3 | 用锄头或三齿耙翻起土壤，露出块茎 |
| 4 | 不要用铁铲直接向下砍，受伤的块茎很快就会腐烂变软 |
| 5 | 轻轻拍掉泥土，不要用水冲洗 |
| 6 | 只挖需要的量，其余的重新覆土留在原处 |

&nbsp;&nbsp;&nbsp;收获中最重要的原则是不要一次全部挖完。菊芋从挖出的那一刻起就开始失水，常温下2-4周就会干缩。相反，留在地下的话，过了几个月也和刚挖出来的没什么区别。因此，这周吃多少就挖多少，下周再挖，这种方式对菊芋来说不是偷懒，而是最好的贮藏策略。

### 12-3. 收获后的分类

| 类别 | 处理 |
|---|---|
| 大而无损伤的 | 直接食用或放入地窖 |
| 中等大小的 | 切片晒干，制成薯片和粉 |
| 小的(30-50g) | 单独收集作为种薯 |
| 有损伤的 | 最先食用，不做贮藏 |
| 泥土 | 只拍掉即可，冲洗会使贮藏期缩短一半 |

## 13. 种薯保存与留种

### 13-1. 土地本身就是种子仓库

&nbsp;&nbsp;&nbsp;菊芋的种子寿命等级为E，意味着无法像干种子那样保存多年，但对这种作物来说，这并不构成实质性的弱点。因为田地本身就是种子仓库，而这个仓库每年都会自行增多。马铃薯如果种薯在冬天死掉，第二年就没法种了，但菊芋只要不把整片地都挖走，种薯就不会消失。

| 项目 | 标准 |
|---|---|
| 种薯大小 | 30-50g，鸡蛋大小 |
| 采收时期 | 3月，在种植前挖出 |
| 挑选 | 结实、芽眼有活力、无病症的种薯 |
| 保存 | 挖出后立即种下最好 |
| 增殖率 | 一个能长出数十个，一年就能增加数十倍 |
| 退化 | 尽管是无性繁殖，但几乎没有病毒退化的报告 |

&nbsp;&nbsp;&nbsp;增殖率极高这一点，在实际操作中意义重大。种下十个，当年秋天就能变成数百个，第二年则能变成数千个。即便在灾害初期难以获得种薯，只要确保有几个，两年内就能种满相当大的面积。这与必须每年购买种子的作物有着根本不同的性质。

### 13-2. 用种子繁殖时

| 项目 | 内容 |
|---|---|
| 种子结实 | 在韩国国内的气候条件下，种子不易成熟 |
| 发芽 | 发芽率低且不稳定 |
| 特性 | 后代性状与母株不同 |
| 实用性 | 不用于繁殖 |

&nbsp;&nbsp;&nbsp;菊芋是一种靠种子繁殖基本没有意义的作物。韩国的秋天常常在种子完全成熟之前就降霜，即便成熟了发芽率也很低。繁殖完全依靠块茎完成。不过这也导致同一地区的菊芋在遗传上几乎变得单一，这在某天特定病害出现时可能成为弱点。从多个地方取来种薯混合种植，可以在一定程度上降低这种风险。

## 14. 菊糖与注意事项

### 14-1. 没有毒性，但初次食用会不适

&nbsp;&nbsp;&nbsp;菊芋不含毒性物质，不存在像木薯的氰苷或马铃薯的茄碱那样的风险，生吃也不会中毒。尽管如此，之所以单独设立这一节，是因为第一次吃的人如果吃到很饱，几乎必定会经历严重的腹胀和腹痛。灾害情况下，饥饿的人吃完一碗菊芋后整夜受苦的情况确实会发生。这不是中毒，而是消化生理上的问题，但对本人来说是无法区分的。

| 阶段 | 体内发生的变化 |
|---|---|
| 1 | 菊糖是果糖像链条一样连接而成的多糖 |
| 2 | 人体的消化酶无法切断这种结合 |
| 3 | 会原样通过胃和小肠，到达大肠 |
| 4 | 大肠里的细菌会发酵菊糖 |
| 5 | 在这个过程中会产生大量氢气、二氧化碳和甲烷 |
| 6 | 腹部膨胀积气，出现痉挛性疼痛和腹泻 |

### 14-2. 症状与适应

| 摄入量 | 不习惯的人 | 已适应的人 |
|---|---|---|
| 50g以下 | 大多无症状 | 无症状 |
| 100-150g | 轻微胀气感 | 无症状 |
| 200-300g | 明显胀气，频繁排气，腹部不适 | 轻微胀气 |
| 500g以上 | 剧烈腹痛、腹泻，持续数小时 | 胀气和排气 |

&nbsp;&nbsp;&nbsp;重要的是，这种反应是可以适应的。持续食用菊糖会改变大肠内细菌的组成，使发酵变得温和，几周之内即便吃同样的量，症状也会大幅减轻。因此，若要把菊芋当作食物来源，应该在灾害发生之前，或者从灾害初期就开始少量食用，让身体逐渐适应。从每天50g开始，用两周时间逐渐增加，是比较稳妥的做法。

| 对象 | 注意事项 |
|---|---|
| 儿童 | 按体重计算的摄入量偏大，应从更少的量开始 |
| 老年人 | 若肠道功能较弱，症状会持续较久 |
| 患有肠易激综合征的人 | 症状会特别严重，应严格限制在少量 |
| 已经腹泻的人 | 不要食用，会加重脱水 |
| 患有糖尿病的人 | 不会使血糖骤升，反而有利 |

### 14-3. 减少胀气的方法

| 方法 | 原理 | 效果 |
|---|---|---|
| 长时间煮 | 加热和酸会使部分菊糖链断裂 | 中等 |
| 加醋煮 | 酸能促进水解 | 中等 |
| 乳酸发酵 | 细菌提前分解菊糖 | 大 |
| 低温贮藏后再烹饪 | 贮藏期间会自然分解 | 中等 |
| 长期晾干 | 在干燥与回水过程中会部分分解 | 小 |
| 少量多次食用 | 让大肠细菌逐渐适应 | 最大 |

> **最可靠的方法是发酵。用盐水浸泡进行1-2周乳酸发酵，细菌会提前分解菊糖，使到达人体大肠的量大幅减少。这样一来，既做成了小菜，也顺带解决了消化负担的问题。**

### 14-4. 其他注意事项

| 项目 | 内容 |
|---|---|
| 生食 | 可以，但胀气会更严重，煮熟食用更好 |
| 叶和茎 | 人不食用，可用作家畜饲料 |
| 变质的块茎 | 若已软化并有异味，应丢弃 |
| 繁殖力 | 并非毒性问题，但不加管理会打乱田地布局 |
| 化感作用 | 会抑制邻近作物的生长 |

## 15. 无冰箱贮藏

### 15-1. 地下就是贮藏库

&nbsp;&nbsp;&nbsp;菊芋不像马铃薯那样有厚厚的木栓层。挖出后放在常温下，表面水分会迅速蒸发，几天到2周内就会变得干瘪。这就是耐储性评级为C的原因。然而同样的块茎留在地下时，过了几个月依然完好，因为土壤能同时保持温度和湿度。所以菊芋贮藏的第一原则不是建造贮藏设施，而是不挖出来。

| 贮藏目标 | 马铃薯 | 菊芋 |
|---|---|---|
| 最大的敌人 | 腐烂、发芽、变绿 | 干燥 |
| 常温保存极限 | 1-2个月 | 2-4周 |
| 最好的方法 | 地窖贮藏 | 不挖，留在地里 |
| 目标湿度 | 85-95% | 90%以上 |

### 15-2. 原地越冬贮藏

| 项目 | 内容 |
|---|---|
| 原理 | 不收获，直接留在地下，是活的贮藏库 |
| 方法 | 初霜后割去地上部分，覆盖20-30cm稻草或落叶 |
| 期限 | 整个冬天，实际上可到第二年春天 |
| 温度 | 保持地温，即便外部气温零下20度，块茎依然存活 |
| 优点 | 不需要电力、设施和劳力，新鲜度也最高 |
| 缺点 | 若地面深度冻结会难以挖掘，也容易成为鼠类和野猪的目标 |

&nbsp;&nbsp;&nbsp;覆盖的目的不是防止块茎冻住——菊芋的块茎即使冻了也不会死。目的是防止上方的土壤冻得像石头一样，铁铲插不进去。铺上20到30cm的稻草或落叶，即使在寒冬正中，下面的土壤也能保持松软。秋天割下的茎秆直接盖上去也可以。

### 15-3. 挖出后的无电力贮藏

| 方式 | 方法 | 温度 | 期限 | 注意事项 |
|---|---|---|---|---|
| 地窖·土窖贮藏 | 用湿润的沙子、泥土、木屑层层掩埋 | 0-4℃ | 2-3个月 | 保持湿度85-95% |
| 坑贮 | 挖30cm深，按稻草、块茎、稻草、土的顺序堆成土丘状 | 0-5℃ | 1-2个月 | 顶部用稻草束留出通气孔 |
| 沙箱贮藏 | 在箱中将干砂与块茎层层放入 | 凉爽的室内 | 1-2个月 | 若沙子太干可稍微喷点水 |
| 湿布包裹 | 用布或报纸包好放在凉爽处 | 凉爽的室内 | 2-3周 | 只适用于少量 |
| 直接常温放置 | 不推荐 | - | 1-2周 | 很快就会干缩 |

### 15-4. 坑贮的做法

| 顺序 | 内容 |
|---|---|
| 1 | 选择不积水的高处，北向坡地较好 |
| 2 | 挖成直径1-1.5m、深30cm的浅坑 |
| 3 | 在坑底铺10cm干稻草 |
| 4 | 把拍去泥土的块茎堆成土丘状，高度控制在50cm以内 |
| 5 | 缝隙间填入湿润的沙子或腐叶土以防干燥 |
| 6 | 用稻草覆盖20-30cm，再盖15cm的土并拍实 |
| 7 | 在顶部立一束稻草作为通气孔 |
| 8 | 在周围挖排水沟 |

&nbsp;&nbsp;&nbsp;与马铃薯坑贮不同的地方在于第5步。马铃薯只用干稻草就够了，但菊芋这样做内部会干掉。需要在缝隙间填入湿度恰到好处的沙子或腐叶土——用手握能成团但不渗水的程度。不过这样一来腐烂的风险也会上升，所以一定要留通气孔，并每两周打开检查一次。

### 15-5. 通过加工实现超长期贮藏

| 方法 | 步骤 | 期限 | 备注 |
|---|---|---|---|
| 干片 | 切成2-3mm薄片，用日晒或炉灶余热完全晒干 | 数月至数年 | 体积和重量大幅减少 |
| 粉 | 将完全干燥的薄片用石臼或磨盘磨碎 | 1-2年 | 密封保存，加入灰或炭作干燥剂 |
| 乳酸发酵 | 浸入2-3%的盐水中，室温放置1-2周 | 数月 | 消化负担大幅减轻 |
| 酱菜 | 腌入酱油或大酱中保存 | 数月至1年 | 做成小菜的同时得以保存 |
| 醋渍 | 浸入煮开的醋水中 | 数月 | 酸味有助于菊糖分解 |

> **贮藏策略的标准做法是多管齐下：大部分留在地里，一部分晒干磨粉以应对野兽和严寒，一部分发酵制成消化负担较轻的小菜。**

## 16. 烹饪与加工

### 16-1. 节省燃料的烹饪方法

| 方法 | 燃料消耗 | 步骤 | 备注 |
|---|:---:|---|---|
| 生食 | 无 | 洗净切好即可食用 | 爽脆香甜，但胀气明显 |
| 煮 | 少 | 放入水中煮10-15分钟 | 淀粉少，比马铃薯更快煮熟 |
| 蒸 | 少 | 加少量水蒸15分钟 | 味道浓郁，营养损失较少 |
| 余热焖煮 | 极少 | 煮5分钟后关火，用布包裹焖30分钟 | 大幅节省燃料 |
| 灰烤 | 极少 | 埋入炉灶余灰中20-30分钟 | 带皮烤制 |
| 粉末烹饪 | 少 | 用开水冲开即可熟 | 燃料效率最高 |

&nbsp;&nbsp;&nbsp;烹饪·加工评级为A，是因为加热10分钟就足够，甚至可以生吃。在燃料极其珍贵的情况下，这是相当大的优势。不过如前所述，生食的胀气最严重，煮得越久，菊糖分解得越多，负担也就越小。这可以说是燃料和肠胃之间的一种权衡。在还不适应之前多煮一会儿，适应之后就可以少煮一些。

### 16-2. 味道与食用方法

| 项目 | 内容 |
|---|---|
| 味道 | 生的口感像梨子混合莲藕，爽脆微甜 |
| 熟食口感 | 变软后甜度增强，没有淀粉的粉质感，与马铃薯不同 |
| 皮 | 不削皮也可以，用刷子刷掉泥土即可 |
| 变色 | 切开后很快会褐变，浸泡在醋水中可以减轻 |
| 搭配 | 大酱汤、炖菜、炸物、腌菜都适合 |
| 汤汁 | 煮过的水中溶有糖分和钾，应一并利用 |

### 16-3. 兼顾贮藏的加工

| 加工 | 步骤 | 结果 |
|---|---|---|
| 菊芋干片 | 切薄片后完全晒干 | 可直接食用，或泡水后放入汤中 |
| 菊糖粉 | 将干片磨碎 | 可掺入谷物粉使用，或煮粥 |
| 茶 | 切片晒干后炒制，再泡水饮用 | 香气浓郁，是冬季饮品 |
| 乳酸发酵泡菜 | 浸入盐水1-2周 | 做成小菜，同时减轻消化负担 |
| 酱菜 | 腌入大酱或酱油中 | 可保存数月，咸味中也摄入了盐分 |
| 糖浆 | 长时间熬煮以分解菊糖 | 变成果糖糖浆，用于增添甜味 |

## 17. 全年作业日程

| 月份 | 作业 | 要点 |
|---|---|---|
| 1月 | 按需从地里挖取，检查贮藏情况 | 掀开稻草挖取后再重新覆盖 |
| 2月 | 规划田地，翻堆肥 | 确定新区域的位置和隔离墙 |
| 3月 | 采收挑选种薯，开始种植 | 土壤解冻后即可种植 |
| 4月 | 完成种植，覆盖 | 无需灌溉 |
| 5月 | 检查出苗，第一次摘心，除草 | 长到1m左右时剪去顶芽 |
| 6月 | 完成除草 | 此后杂草会自然消失 |
| 7月 | 第二次摘心，预防倒伏 | 将株高控制在1.5m左右 |
| 8月 | 摘花蕾，防台风 | 此时块茎尚未形成 |
| 9月 | 块茎开始膨大，严重干旱时才灌溉 | 从此时起块茎开始变粗 |
| 10月 | 观察开花，准备收获 | 不要着急 |
| 11月 | 初霜后割去地上部分，首次收获，铺稻草覆盖20-30cm | 只挖需要的量 |
| 12月 | 收获所需部分，进行晒干与发酵加工 | 为防兽害，部分转移到室内保存 |

### 17-1. 不可忘记的五件事

| 项目 | 内容 |
|---|---|
| 初次食用要少量 | 菊糖会引起严重的胀气和腹痛，从50g开始用2周逐渐增加 |
| 种植地点无法恢复原状 | 一旦种下几乎无法根除，应种在边界或边角地并配合隔离墙 |
| 要等待初霜 | 霜降前块茎小且味道不好，9月以前收获是种损失 |
| 不挖就是贮藏 | 留在地下几个月也完好，挖出后2周就会干缩 |
| 不施肥 | 施氮只会让株高增加而块茎变小，堆肥应留给其他作物 |
