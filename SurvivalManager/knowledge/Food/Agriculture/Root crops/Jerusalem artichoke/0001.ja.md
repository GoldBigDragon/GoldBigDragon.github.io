## はじめに
&nbsp;&nbsp;&nbsp;キクイモ(Helianthus tuberosus)は、韓国ではトゥンタンジとも呼ばれるキク科ヒマワリ属の多年草で、ジャガイモとは関係がありません。北アメリカ中部から来て、朝鮮後期に飼料用として入ったあと畑の外へ逃げ出し、いまでは全国の道端や河川敷、放棄された畑で人の背丈より高く育ちます。災害に備える評価では総合SS(58.8点、有効183種中3位)で、短期、長期、副食もすべてSSです。SSがついた9項目は、そのほとんどが人が何を投入しなければならないかを問う項目です。平時の評価が良い条件でどれだけとれるかを競う試合なら、災害に備える評価は何の条件もないときに何が残るかを問う試合で、種目が変われば優勝者も変わります。ただし、この点数は根拠が浅く、初めて食べる人はイヌリンのために強いガスと腹痛に苦しみ、一度植えると取り除けません。

## 1. 災害への備えの評価
| 区分 | 等級 | スコア |
|:---|:---:|:---:|
| 総合 | SS | 58.8 |
| 短期 | SS | 57.7 |
| 長期 | SS | 60.0 |
| 副食 | SS | 71.7 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: 永続性、施肥、水の消費量、施設の負担、温度幅、耐寒性、連作への適応性、整地・掘削エネルギー、国内での栽培の普及度。S: タンパク質密度、味、自家採種。A: 微量栄養素、調理・加工の要求度。B: 面積当たりの熱量、日射、合成資材を投入しない場合の収量維持率、収量の安定性 |
| 弱み | E: 種子の寿命。D: 収穫速度、非食用の価値。C: 病害虫圧、防除の自立度、貯蔵性 |

> **キクイモが上位に入った理由は、たくさんとれるからではなく、どんな年にも全滅しないからです。**

&nbsp;&nbsp;&nbsp;面積当たりの熱量Bは、㎡当たり1,400kcalで自給ラインの0.54倍、つまり1人がこれで暮らすには200㎡近い畑が必要だという意味で、ジャガイモより低い値です。それでもSSなのは、肥料も灌水も設備も要らず、残った塊茎からひとりでにまた生えて掘削エネルギーが10年に分けて償却され(年22kcal、回収できる熱量は134倍、ジャガイモは10.6倍)、温度幅25℃とマイナス20℃以下の耐寒性が重なって、悪い年には小さくなるだけで消えないからです。災害時に必要なのは、良い年の最大収量ではなく、悪い年の最小保証です。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

| 項目 | 表示された値 | 実際の根拠 |
|:---|:---|:---|
| 面積当たりの熱量 | 4,000kg/1,000㎡ | 公式の単収統計がないため、良好な条件を仮定した値 |
| 100g当たりの熱量 | 35kcal | ほかの資料は68-76kcalで2倍の差。イヌリンが消化されないため、体が使える熱量は低いほうに近い |
| 病害虫圧、合成資材を投入しない場合の収量維持率 | 減収率50.6%、45.1% | 双子葉植物綱全体の値を借りた推定値と、ジャガイモの有機栽培の収量比を根菜・イモ類全般に当てはめた代入値。防除の自立度Cはこの根拠が弱いため下げた値で、実際には防除がほとんど要らない |

&nbsp;&nbsp;&nbsp;副食SS(71.7)は、タンパク質2.18gを熱量35kcalで割った24.9%から出た値で、分母が小さいために高く出たものです。1日2,100kcalを満たすには6kgを食べなければならないので、キクイモは主食ではなく、主食を補い、主食がない年に飢え死にしないようにしてくれる作物です。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | キク科ヒマワリ属の多年草。北アメリカ中部と東部原産 |
| 葉、茎 | 幅の広い卵形で先がとがり、縁にぎざぎざがある。茎はまっすぐに立って1.5-3mまで伸び、ざらざらした剛毛がある |
| 花 | 8-10月に直径5-8cmの黄色い頭状花(小さなヒマワリの形)が咲く |
| 塊茎 | ごつごつしたショウガの形で、赤いもの、白いもの、紫がかったものがある。根の先と地下茎の先につく |

&nbsp;&nbsp;&nbsp;4月に地面が解けると塊茎の芽から新芽が出て、5-7月に茎が1日に数cmずつ伸び、8-10月に花が咲きます。塊茎は遅れて肥大し、夏じゅうは茎と葉だけを育て、日が短くなる9月末から実がつきはじめ、霜が降りたあとにもっとも大きく甘くなります。100g当たり熱量35kcal(韓国国家標準食品成分表)、炭水化物約17g(大部分がイヌリンで、でんぷんはほとんどない)、タンパク質2.18g、脂質0.01g、糖類6.37g(貯蔵中や加熱中にイヌリンが分解されて増える)、カリウム約630mgで、ジャガイモやサツマイモより多く含みます。イヌリンは果糖が長くつながった多糖類で、人の消化酵素では切れません。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 生育5-30℃(適温18-25℃)で、幅は25℃。マイナス20-30℃でも地中で生き、韓国全域で何の対策もなしに越冬する。発芽は5-10℃以上なので、地面が解けしだい植えられる |
| 水、日照 | 灌水なしで栽培でき、塊茎の肥大期にだけ湿っていればよい。1日6時間以上(適正は8時間以上)の日照で、40%の遮光で収量は約80% |
| 土壌 | pH5.0-8.0(適正5.8-7.0)でほとんど選ばない。水はけのよい砂壌土-壌土が適正で、粘土では塊茎が変形して掘りにくい |

&nbsp;&nbsp;&nbsp;過湿にはむしろ弱く、水が数日たまると塊茎が柔らかくなって軟腐病が入るので、栽培環境で気をつける条件はこの1つです。河川敷や堤防、溝沿いの土手(水は近いがたまらない場所)、放棄された畑や砂利まじりの痩せ地、家の裏や垣根の外や山すそ、風よけを兼ねた畑の縁が適しており、菜園の真ん中と水がたまる低地と頻繁に耕す主力の畑は避けます。

> **キクイモは良い畑に植える作物ではなく、畑ではない土地を畑に変える作物です。そして一度植えると元に戻すのは難しくなります。**

&nbsp;&nbsp;&nbsp;正式な品種体系はゆるく、野生・在来の系統は繁殖力がもっとも強く、災害への適合度ももっとも高く、河川敷や道端で秋に掘ればそのまま種芋になります。手入れが楽なフュゾー、寒冷地に向く早生のスタンピードとスコロスペルカ、背が低く風に強いドワーフサンレイもあります。

## 4. 畑の準備と植え付け
| 項目 | 基準 |
|:---|:---|
| 整地 | 深さ20-30cmに耕し(深いほど塊茎が大きく掘りやすい)、高さ30cm以上の畝と30cm以上の排水溝をつくる。専用の区画に分け、板や溝を40-60cmの深さに埋める境界の遮断は必須(地下茎は1年に1m近く伸びて、2、3年で隣の畑を占領する) |
| 施肥(1,000㎡) | 窒素は最小限(多いと葉ばかり茂って塊茎が減る)、リン酸3-4kg、カリウム3-5kg(塊茎の肥大にもっとも重要)。ジャガイモの25%以下で、与えなくても育つので、限られた堆肥はジャガイモやハクサイに回す。マルチは落ち葉かわら5-10cm |
| 災害時の代替肥料 | 木灰(㎡当たりひとつかみ)、落ち葉のマルチ、秋に刈った茎をその場に敷く(もっとも簡単な自給肥料で、カリウムが循環し、冬はマルチになる)。尿の希釈液は窒素が有害なので使わない |
| 種芋 | 卵ほどの大きさの30-50g(小さいと初期の生育が遅い)。大きいものは芽を2-3個含むように切り、切り口に木灰をつけて日陰で1日乾かして癒やす。病気のものや柔らかくなったものは除き、掘ってすぐ植えるのが最善 |
| 植え付け | 春は3-5月に地面が解けしだい、秋は10-11月(そのまま越冬して翌春に芽が出るので、保管の代わりに植えてしまうのがもっとも確実)。深さ5-10cm、株間30-45cm、畝の間隔60-70cm、芽を上に。土をかぶせて軽く押さえ、灌水は不要 |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 植え付けの直後 | 1回たっぷり与える |
| 栄養生長期(5-7月) | 自然の降雨に任せる(過湿のほうがむしろ有害) |
| 塊茎の肥大期(9-10月) | ひどい干ばつのときだけ補う(この時期の乾燥だけが収量に影響する) |
| 成熟期(11月以降) | 灌水を止める |

| 管理 | 方法 |
|:---|:---|
| 摘心 | 5月に草丈が1mほどになったときと7月に頂部の芽を切り、8-9月に花のつぼみを摘んで、草丈を1.5m前後に抑える(養分の損失と秋の台風による倒伏を防ぎ、養分を塊茎に回す)。切った芽はマルチに使う |
| 倒伏防止 | 株元の土寄せ、数株をまとめて縛る周囲のひも、密植、風が来る側の垣根や別の作物 |
| そのほかの管理 | 草取りは5-6月に1-2回で足りる(草丈が高くなれば雑草はひとりでに消える)。秋に地上部を刈るとき、区画の境界に沿ってスコップを深く差し込み、越えた地下茎を断つ境界の点検は、毎年欠かしてはならない唯一の作業 |
| 過湿の症状 | 下葉が黄色くなって株元が黒ずんだらただちに排水溝を掘り、株元が柔らかくなって白い菌糸が見えたら(白絹病)その株を抜いて焼く |

## 6. 病害虫と養分の問題
&nbsp;&nbsp;&nbsp;以下の病気が畑を全滅させることはまれです。野生の群落が何の防除もなく数十年維持されているので、排水の確保、風通し、病んだ株を見つけたらその場で抜いて焼くことで十分です。災害時にキクイモを脅かすのは、病原菌ではなく獣です。

| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| 白絹病、菌核病 | 株元に白い菌糸が広がり、株が急にしおれる(高温多湿) / 茎が柔らかくなり、白い綿のような菌糸と黒い菌核ができる(涼しくて湿っているとき) | 排水の改善、病株の除去と焼却、その場所に木灰 / 風通しの確保、3-4年の輪作 |
| さび病、うどんこ病、細菌性軟腐病 | 葉裏のオレンジがかった褐色の粉(梅雨どき) / 葉の表面の白い粉 / 塊茎が柔らかくなって悪臭(収穫時の傷、過湿) | 風通しの確保と病葉の除去 / 牛乳の10倍希釈液か重曹の希釈液(水1Lに5g) / 傷をつけずに掘って乾燥、病んだ塊茎はただちに廃棄 |
| アブラムシ | 新芽から汁を吸う | 窒素の与えすぎを避けてテントウムシを守る、水洗い、石けん水、木灰 |
| ノネズミ、イノシシ | 地中の塊茎を大量に食べる | 畑の周りの雑草の除去、区画の周りに金網や板を埋める、フェンス。その場での貯蔵の最大の危険なので、全部を1か所に置かず、複数の区画に分ける |

| 症状 | 原因と対処 |
|:---|:---|
| 葉と茎ばかり茂って塊茎が小さい(草丈が3mを超える) | 窒素過剰で、もっともよく見られる問題。窒素を止めて摘心で釣り合いをとる |
| 葉の縁が褐色に枯れる(塊茎の肥大期) / 葉が紫がかる(低温期) | カリウム欠乏 / リン欠乏。木灰 / 骨粉と木灰 |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | 風よけの境界作物(背が高く風を防ぐ)、蜜源植物(秋に咲く花がミツバチを集める)、飼料用の区画(葉と茎を家畜の餌にする) |
| 普通 | なし。アレロパシーのため間作自体が合わず、専用の区画で栽培するのが原則 |
| 悪い | 豆、トマト、大部分の野菜(他感物質で1m以内の隣の作物の生育を抑える)、畑の真ん中のあらゆる作物(地下茎が侵入して押しのける) |

&nbsp;&nbsp;&nbsp;連作への適応性SSは、同じ場所に永久に置いてよいという意味で、それが基本の栽培方法であり、白絹病がひどくなったらそのとき移します。区画を移すには、古い場所で3-5年間出つづける芽を取り除かなければなりません。永続性SSの裏面は、一度植えると取り除けないという点で、1株が1年に数十個の塊茎を四方1m以上にまき散らすため、爪ほどのかけらが1つ残っても翌年に芽が出ます。一度深く掘り出すのは効果が低く、もっとも効果的な方法は飢えさせることです。芽が葉を広げる前に切りつづけて塊茎が貯蔵分を補充できないようにすれば、2-3年で密度が大きく下がり、厚い布や板で1-2年完全に覆うか、ブタを放牧しても効果が高くなります。それでも完全な根絶は現実的には難しいといえます。

> **キクイモを植えるのは、取り返しのつかない決定です。畑の真ん中ではなく境界や余り地に植え、最初から遮断壁を埋めておくのが、唯一の簡単な対策です。**

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 初霜が降りたあとが最適期(地上部が枯れてイヌリンと糖度が最高になり、低温でイヌリンの一部が短い鎖に分解されてさらに甘くなる)。11月中旬から翌年3月まで4か月以上いつでも掘れ、種芋用は3月に掘る。9月以前は実がつかず、収量の大部分を失う |
| 要領 | 地上部の茎を株元で切ってその場に敷き、鍬や三つ又で土を持ち上げて塊茎を出す。スコップで突き刺さない(傷ついた塊茎はすぐ柔らかくなる)。土を払うだけで洗わない(洗うと貯蔵期間が半分になる) |
| 仕分け | 大きくて傷のないものはすぐ食べるか土室に入れ、中くらいのものは切って乾燥させチップと粉にし、30-50gの小さいものは種芋として別に集める。掘った瞬間から水分が抜けるので、今週食べる分だけ掘るのが最善の貯蔵戦略 |

| 採種 | 基準 |
|:---|:---|
| 種芋 | 種子の寿命はEだが、地中の塊茎がそのまま種の貯蔵庫。30-50gの硬くて芽が生きていて病徴のないものを、3月の植え付け直前に掘ってすぐ植える |
| 増殖 | 10個植えるとその秋に数百個、翌年には数千個になり、2年でかなりの面積を埋められる。ウイルスによる劣化の報告はほとんどない |
| 種子による繁殖 | 韓国の気候では種子がよく熟さず発芽率も低いため使わない。繁殖が塊茎だけなので遺伝的に単一になりやすく、複数の場所から種芋を持ち寄って混ぜて植える |

## 9. 貯蔵
&nbsp;&nbsp;&nbsp;キクイモはジャガイモと違って厚いコルク層がなく、掘って常温に置くと2-4週間(早ければ数日)でしわしわになるため、最大の敵は腐敗ではなく乾燥です。だから貯蔵の第一原則は、貯蔵庫をつくることではなく、掘らないことです。

| 方式 | 方法 | 期間 |
|:---|:---|:---|
| その場での越冬貯蔵 | 収穫せず地中に置く。初霜のあとに地上部を刈り、わらや落ち葉を20-30cmかぶせる(塊茎は凍っても死なず、地面が石のように凍ってスコップが入らなくなるのを防ぐため)。欠点は、ノネズミやイノシシの標的になること | 冬じゅう、翌春まで |
| 土室・穴蔵での貯蔵 | 湿った砂、土、おがくずに交互に埋め、0-4℃、湿度85-95%を保つ | 2-3か月 |
| 穴での貯蔵 | 30cm掘り、わら、塊茎、わら、土の順に盛り土のように積む。ジャガイモと違って間に湿った砂や腐葉土を詰めて乾かないようにし、わら20-30cmと土15cmをかぶせたあと、頂上にわら束で通気口をつくり、2週間に1回開けて確認 | 1-2か月 |
| 乾燥チップ、粉 | 2-3mmに薄く切り、日なたやかまどの余熱で完全に乾燥。かさと重さが大きく減る。粉は密閉し、灰や炭を乾燥剤として入れる | チップ数か月-数年、粉1-2年 |
| 乳酸発酵、漬物、酢漬け | 2-3%の塩水に室温で1-2週間 / しょうゆやテンジャンに漬ける / 煮立てた酢水に漬ける(酸味がイヌリンの分解を助ける)。おかずになり、消化の負担も減る | 数か月-1年 |

> **貯蔵戦略の標準は併用です。大部分は地中にそのまま置き、一部は乾燥・粉に回して獣と厳寒に備え、一部は発酵させて消化の負担を減らしたおかずにします。**

## 10. 調理と注意事項
&nbsp;&nbsp;&nbsp;キクイモには毒性物質がなく、生で食べても中毒しませんが、初めて食べる人が満腹になるまで食べると、ほぼ必ず強い腹部膨満と腹痛に見舞われます。人の消化酵素はイヌリンの結合を切れないため、胃と小腸をそのまま通って大腸に着き、大腸の細菌が発酵させて水素、二酸化炭素、メタンが大量に出るからです。ただし、イヌリンを続けて食べると大腸の細菌の構成が変わり、数週間で症状が大きく減るので、1日50gから始めて2週間かけて増やす方法が無難で、災害が起きる前か初期から少量ずつ体を慣らしておきます。

| 摂取量 | 慣れていない人 | 慣れた人 |
|:---|:---|:---|
| 100-150g | 軽い膨満感 | 症状なし |
| 200-300g | はっきりした膨満、頻繁なおなら、腹部の不快感 | 軽い膨満 |
| 500g以上 | 強い腹痛、下痢が数時間続く | 膨満とおなら |

| 注意 | 内容 |
|:---|:---|
| 対象 | 子どもは体重当たりの摂取量が大きいのでより少ない量から始め、過敏性腸症候群のある人は少量に限り、すでに下痢をしている人には食べさせない。糖尿病のある人は血糖を急に上げないのでむしろ有利 |
| ガスを減らす | 少量ずつ頻繁に食べるのがもっとも効果が大きく、塩水で1-2週間乳酸発酵させると細菌があらかじめイヌリンを分解するのでもっとも確実。長くゆでる、酢を入れてゆでる、低温で貯蔵してから調理する、長期の乾燥も多少役立つ |
| そのほかの注意 | 生食は可能だが膨満がひどくなるので加熱して食べるほうがよく、葉と茎は人は食べず家畜の飼料にする。柔らかくなって悪臭がする塊茎は捨てる |

| 調理 | 方法 |
|:---|:---|
| 燃料の節約 | 加熱時間は10分で十分。ゆでるなら水に入れて10-15分、蒸すなら水を少し入れて15分、余熱調理は5分煮立てたあと火を止めて布で包み30分、灰焼きは熱い灰に埋めて皮ごと20-30分で、沸騰した湯に溶いた粉はすぐ火が通る。長くゆでるほどイヌリンが少し分解されて負担が減るので、慣れる前は長くゆで、慣れたあとは短く火を通す |
| 味、食べ方 | 生はナシとレンコンを混ぜたようにシャキシャキして甘く、加熱すると柔らかくなって甘みが強まり、でんぷんの感じがない。皮はむかず、ブラシでこすって土だけ落とし、切ると褐変するので酢水につけておく。テンジャン汁、煮物、揚げ物、漬物がすべて可能で、ゆで汁には糖とカリウムが溶けているので汁として使う |
| 加工 | 乾燥チップはそのまま食べるか水で戻して汁に入れ、チップを挽いた粉は穀物の粉に混ぜるか粥にし、炒ったものは茶にする。長く煮詰めるとイヌリンが分解されて果糖シロップになる |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 必要な分だけ掘って食べる(わらをのけて掘ったあと再びかぶせる)、貯蔵分の点検。2月に堆肥の切り返し、新しい区画の場所と遮断壁を決める |
| 3-4月 | 3月に種芋の採取と選別、地面が解けしだい植え付けを始める。4月に植え付けの仕上げ、マルチ(灌水は不要) |
| 5-6月 | 5月に出芽の確認、1回目の摘心(草丈1mほど)、草取り。6月に草取りの仕上げ(以後は雑草がひとりでに消える) |
| 7-8月 | 7月に2回目の摘心、倒伏への備え(草丈1.5m前後)。8月に花のつぼみ摘み、台風対策 |
| 9-10月 | 9月に塊茎が太りはじめ、ひどい干ばつのときだけ灌水。10月に開花の観察、収穫の準備(あせらない) |
| 11-12月 | 11月に初霜のあと地上部を刈り、最初の収穫、わらのマルチ20-30cm(必要な分だけ掘る)。12月に必要分の収穫、乾燥と発酵の加工(獣害に備えて一部は屋内に移す) |

> **キクイモは、最初は50gから少量ずつ食べ、取り返しがつかないので境界や余り地に遮断壁とともに植え、初霜を待って必要な分だけ掘り、掘らずに地中に置くことを貯蔵とし、肥料を与えない作物です。**
