## 引言
&nbsp;&nbsp;&nbsp;甘薯（Ipomoea batatas）是来自中南美洲热带低地的旋花科藤本植物，我们吃的部分不是茎，而是根膨大形成的块根。灾害应对评估的综合等级为SS（57.6分，有效183种中第4位），短期S（56.7）、长期SS（58.4）、副食S（53.2分），长期高于短期。栽种后要120-150天才能收获，但一旦扎稳根，几乎不需要肥料和农药，每㎡就能产出3,675kcal，富含β-胡萝卜素，耐瘠薄和干旱，还可以连作。致命的缺陷是蛋白质只占热量的3.0%（E），所以必须与豆类一起种。此外它遇霜即死，收获的块根在9℃以下也会受冷害，如果不能让种薯整个冬天都在13℃左右存活，第二年的农事就会中断。胜负不在田里，而在冬天的储藏处。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | SS | 57.6 |
| 短期 | S | 56.7 |
| 长期 | SS | 58.4 |
| 副食 | S | 53.2 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：连作适应性、口味。S：单位面积热量、微量营养素、施肥、国内种植普及度、自留种。A：水消耗量。B：设施负担、光照、烹调·加工要求度、耐储性、无合成投入产量保持率、产量稳定性 |
| 劣势 | E：蛋白质密度、耐寒性、非食用价值、种子寿命。D：持续性。C：收获速度、温度幅度、病虫害压力、防治自立度、整地·挖掘能量 |

> **一垄甘薯既是主食，又是维生素来源，还是菜园，但人不能只靠甘薯活着。与豆类一起种不是选择，而是栽培计划的一部分。**

&nbsp;&nbsp;&nbsp;单位面积热量S与施肥S同时出现是关键。甘薯每㎡用15g养分产出3,675kcal，投入产出比马铃薯（32g，2,010kcal）高出近四倍，无合成投入产量保持率也是45.1%，高于马铃薯的17.6%。连作适应性SS是指农村振兴厅把它归入连作无害组，这在薯类中是例外。微量营养素S的实质是β-胡萝卜素，叶和茎也能做凉拌菜。蛋白质密度E是指如果每天2,100kcal只靠甘薯，蛋白质只有约16g（成年男性需要55g），几个月后就会掉肌肉、伤口不愈合、容易感染，所以要把田地面积的25-33%分给豆科。耐寒性E和种子寿命E是同一个问题：必须让种薯保持温暖地存活（第8节）。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 旋花科番薯属（Ipomoea）藤本植物。与马铃薯是完全不同的谱系，大多数病虫害不共有，所以把两种作物分开种植，就能避免一方全军覆没 |
| 叶、茎 | 茎是贴地爬的藤蔓，长到1-3m，每个节都生根。叶和叶柄可食用 |
| 花、果实 | 是短日照植物，在韩国还没开花就下霜了，所以几乎不开花。不能靠种子延续，必须靠活的根传代 |
| 块根 | 膨大的根。没有芽眼，但任何部位都能长出不定芽 |

&nbsp;&nbsp;&nbsp;栽种后2周内为成活期（水分绝对重要），2-8周为蔓伸长期（氮、钾）；30-50天开始形成块根，50-120天经过块根膨大期（钾需求最大），120天以后进入成熟期（停止灌水）。根起初全是细的纤维根，其中一部分膨大成储藏根；氮和水充足时，植株感觉不到需要储存，只长藤蔓，所以要略带饥饿，它才会把养分积到根里。每100g含热量147kcal、碳水化合物31-35g、糖类9.83g、蛋白质1.09g、维生素C 10-23mg，维生素A（β-胡萝卜素）在橙色越深时越多。甜味是加热和储存期间β-淀粉酶在50-70℃把淀粉变成麦芽糖产生的，所以用文火慢慢加热，就越甜。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 生长25-30℃（15℃以下停止，35℃以上为极限），块根膨大20-30℃（超过30℃只长藤蔓），夜温18℃以上（10℃以下发生冷害），栽插时地温18℃以上（低于15℃不能成活）。霜冻一夜就使地上部死亡 |
| 水分、光照 | 总蒸散量约400mm，淹水24小时根就会腐烂。每天需要6小时以上日照（不足4小时只长藤蔓），遮光40%时相对产量约80% |
| 土壤 | 排水良好的砂壤土或沙地，耕层30cm以上。黏土和地下水位高的地方，块根膨大不起来。在pH4.2-8.3都能生长，几乎不挑酸碱度 |

&nbsp;&nbsp;&nbsp;选址依次是：不积水的地方（排水不良是最常见的失败原因）、向阳的南向坡地、掺沙的轻质土、能挡风的地方。肥沃的土地只长藤蔓，所以肥力低的地反而有利，其他作物种不了的贫瘠干旱之地就是甘薯的地方。

&nbsp;&nbsp;&nbsp;粉质类（板栗薯等）水分少、淀粉多，适合干燥和做粉，储存中腐烂也较少；黏质类（南瓜薯等）水分和糖多，适合烤和煮粥，β-胡萝卜素最丰富。选品种最重要的指标不是产量，也不是口味，而是储存中的腐烂率。在相同条件下储存四个月，Daeyumi和Gogeonmi的腐烂率不到1%，Sincheonmi却达到36.7%，1,000kg里损失360kg。霜来得早的地区，适合100-120天就能收获的板栗薯、Hopungmi和Sodammi。

## 4. 整地与栽插
| 项目 | 标准 |
|:---|:---|
| 整地 | 翻耕25-30cm深，起高25-35cm、宽60-75cm的高垄，并开深20cm以上的沟（排水变好、地温升高、块根长粗的最便宜的投入）。把土打碎到松软 |
| 施肥（1,000㎡） | 氮尽量少（过量是致命的，瘠薄地可以不施），磷10-15kg，钾15-20kg（对块根膨大最重要），腐熟堆肥1,000-1,500kg，在栽插前2周全部作基肥。原则上不追肥（生长中期施氮会使储存停止，植株重新长藤蔓） |
| 灾害替代肥料 | 木灰（每10㎡ 1-2L）、腐熟堆肥、稀释20倍的尿液（仅用于成活期，膨大期禁用）、骨粉、用淡水漂去盐分的海藻、稻草和落叶 |
| 育苗床 | 栽插前50-60天，在向阳处挖深50-60cm、宽1-1.2m的坑，把刚排出的马粪或牛粪与稻草、落叶混合，踩实铺成30-40cm厚并浇水发酵（没有牲畜就用落叶、米糠、尿液），再盖10-15cm掺沙的土。土温稳定在30℃左右时，把种薯按3-5cm间距平放，盖3-4cm土，夜里盖草帘，出芽后降到23-25℃ |
| 薯苗 | 30-40天长到25-30cm；留3-5cm基部剪下，还会再长新芽，所以一个种薯能剪3-4次。选有5-7节、铅笔粗细以上的健壮薯苗，放在阴凉处一天让切口愈合，然后在50-55℃的水中浸10-15分钟，或蘸木灰消毒 |
| 栽插时期 | 地温18℃以上、最低气温稳定在15℃以上时（以温度而非日期为准）。南部4月下旬-5月中旬，中部5月中旬-6月上旬；6月下旬以后生长期不够，只结小薯 |
| 栽插 | 平放，把3-4节埋入3-5cm深，让顶端的2-3片叶露出地面（每个节上都会结薯，直插的话只在一处生根，收成减半）。株距25-30cm、垄距70-90cm，栽后立即每株浇100cc以上的水 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 栽插后立即 | 浇透（无根的茎能活下来的唯一条件）。在阴天栽插，并在几天里用稻草或草遮阴，或把叶子剪掉一半以减少蒸腾 |
| 成活期到块根形成期 | 干了就补水，之后靠自然降水，块根形成期（30-50天）要略微偏干（水充足时只长藤蔓，干旱胁迫会促进储藏根形成） |
| 块根膨大期（50-120天） | 干旱持续2周以上时，每周浇透一次（在缺水60天的试验区，单个薯的平均重量减少了75%）。水有限时集中在7-8月 |
| 收获前3周 | 停止灌水（糖度上升，耐储性变好） |

| 管理 | 方法 |
|:---|:---|
| 提蔓 | 贴地的每个节都会长细根抢夺养分，所以从7月起每隔2-3周，在阴天或傍晚把藤蔓略微提起，弄断节上的根后放回原处。过于茂盛时，剪掉顶端约30cm，当凉拌菜吃 |
| 除草 | 栽后40天内、藤蔓盖住地面之前最重要（不除草会有40-50%的产量差异）。盖住之后藤蔓会抑制杂草 |
| 覆盖 | 厚5cm以上的稻草或干草是代替塑料膜的首选，割下的草要在种子成熟前铺上 |
| 摘叶、茎 | 栽后60天到下霜前，摘藤蔓顶端15cm以内的嫩芽和叶柄，一次不超过全部叶片的三分之一（摘多了块根膨大会推迟）。剥掉外皮，焯水后做凉拌菜或汤 |
| 缺水、过湿 | 缺水时中午叶片卷起、新叶变小（膨大期要立即灌水）；严重时灌水并盖稻草。过湿时只长藤蔓，所以要挖排水沟。淹水使根变黑并发臭的话无法恢复，要立即排水，能挖就挖出来 |

## 6. 病虫害与养分问题
&nbsp;&nbsp;&nbsp;病虫害负担较低。防治自立度C是指几乎不需要防治，需要时用天然材料就足够，也没有像马铃薯晚疫病那样无药可治的病害。预防靠健壮的薯苗和种薯（一半取决于这里）、高垄、彻底的愈合处理，以及收获后清理残体。

| 病虫害 | 症状与条件 | 预防与应对 |
|:---|:---|:---|
| 软腐病 | 块根变软并发出恶臭（伤口、过湿、储存中高温） | 无伤收获，彻底做愈合处理，立即清除感染的薯 |
| 黑斑病 | 块根表面出现黑色斑点并发苦（感染的种薯和薯苗） | 挑选健康种薯，温汤处理。发苦就不要吃（第10节） |
| 蔓割病、炭疽病、白粉病 | 茎基部裂开并萎蔫（土传） / 叶和茎上有褐色病斑（雨季过湿） / 叶面出现白粉（干燥且昼夜温差大时） | 抗病品种、健康薯苗、排水 / 保证通风，摘除病叶 / 牛奶按1比9稀释 |
| 病毒病 | 叶片花叶、畸形、减产（蚜虫、种薯传染） | 只从健康植株上选留种薯 |
| 害虫 | 金针虫（在块根上蛀孔）、甘薯麦蛾（叶和茎）、蚜虫和红蜘蛛、地老虎（在基部咬断幼苗）、线虫（根上长瘤）、田鼠和野猪（挖食块根） | 不用未腐熟堆肥，放马铃薯块诱捕，轮作 / 摘除受害叶，烧掉残体 / 肥皂水（20g无香皂加1L水），保护瓢虫 / 基部撒灰或围纸圈 / 万寿菊 / 围栏、带刺树枝，提前收获 |

| 症状 | 原因与措施 |
|:---|:---|
| 叶缘焦褐卷曲 | 缺钾。在沟里少量撒木灰 |
| 只有藤蔓茂盛、块根长不粗 | 氮过多（压倒性地最常见的问题）。停止施氮，提蔓，掐芽当凉拌菜吃，第二年不在那块地施肥 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 很好 | 豆科（大豆、豇豆、菜豆）：固氮，并把甘薯缺少的蛋白质提供给人 |
| 好 | 玉米、高粱（在高秆作物下，甘薯覆盖地面）、万寿菊（抑制线虫）、紫苏（气味驱避害虫） |
| 一般 | 生菜、菠菜（在藤蔓覆盖前的早期收获并拔掉） |
| 差 | 马铃薯（共有金针虫和线虫，争夺空间）、番茄、辣椒、茄子（线虫危害叠加）、南瓜（争夺空间） |

&nbsp;&nbsp;&nbsp;甘薯属于连作无害组，所以地小时可固定在同一块地，每年少量补充堆肥。有余地时，推荐按甘薯、豆科、叶菜类或谷物三年轮作；几年之后线虫和蔓割病的密度可能升高，所以出现线虫时，种一年万寿菊或苏丹草再翻压入土。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时机 | 栽后120-150天，但标准不是“长足了没有”，而是“冷之前没有”。要在地温降到15℃以下之前、霜降之前结束（遭霜的叶子的冷害会传到根里）；待在10℃以下土里的甘薯，挖出后储存中必定腐烂，所以即使没长粗，也要在霜前挖出。先挖一两株检查大小 |
| 要领 | 收获前5-7天清除藤蔓，让皮变硬，然后在晴朗干燥的上午，在离植株30cm的外侧挖下去，连土一起托起，用手分离（不要拉扯）。只抖掉泥土，不用水洗，在阴凉处晾2-3小时。皮很薄，一道指甲痕就是腐烂的起点，所以把有伤的另外收集，先吃掉 |

| 留种 | 标准 |
|:---|:---|
| 结构 | 温带很少开花，实生苗性状参差不齐，所以繁殖全是无性繁殖。基因型100%保留，但种子不能晒干保存，必须以活的甘薯过冬，种薯一旦冻坏或烂掉，第二年就没有可种的东西 |
| 选种薯 | 在长得最好的植株上选150-250g的纺锤形薯，要完全没有伤口、病斑和黑点（一个就会传给全部）。每1,000㎡种植面积需60-80kg，一个种薯能出20-30株苗 |
| 越冬 | 愈合处理（30-33℃，湿度90-95%，3-4天）后，用4-5天逐渐降到13℃，在12-15℃、湿度85-90%下保管。与马铃薯窖（3-5℃）放在一起的话，只有甘薯全军覆没，所以要分开；住人房间的角落或厨房后面最安全。没有电时要得到30℃，就把箱子放在向阳房间里最暖的地方（炕头），用稻草或毯子裹好，并放一碗水保持湿度 |
| 防止退化 | 反复无性繁殖会积累病毒，5-6年产量会明显下降。每年只从最旺盛的植株上留种薯，剪苗要用离母株最远的末端的苗（病毒浓度低），叶片花斑或卷曲的植株吃掉，每4-5年与其他地区交换种薯 |

## 9. 储存
&nbsp;&nbsp;&nbsp;储存的成败取决于收获后立即进行的3-4天愈合处理（30-33℃，湿度90-95%）。伤口表面形成木栓层，阻挡病原菌，使储存损失减半以下。逐渐降温后进入正式储存（12-15℃，湿度85-90%，黑暗，微通风），能保存5-6个月，每2周检查一次，立即清除变软的。9℃以下里面会变硬并腐烂，18℃以上会发芽。

| 方式 | 方法 | 期限 |
|:---|:---|:---|
| 室内箱储 | 愈合处理后，装进铺了报纸的纸箱，一层层放好，置于住人房间的角落。最可靠 | 4-6个月 |
| 稻壳·沙层、稻草保温 | 在箱里与稻壳或干沙交替装入（防止腐烂传染） / 在室内角落铺厚稻草，堆好后用稻草和草帘盖上 | 3-5个月 / 3-4个月 |
| 炕边 | 烟道旁边的空间。温度合适时最好，太热会发芽 | 5-6个月 |
| 甘薯干片 | 把生薯切成5mm厚，在太阳下晒3-5天彻底干燥（体积缩小到20%，只要防虫就能存过一年）。用水泡发煮粥，或磨成粉做年糕 | 1-2年 |
| 薯条干、淀粉 | 蒸熟去皮，纵向切条晒干 / 磨碎后加水搅开，把沉淀下来的淀粉晒干 | 6个月-1年 / 数年 |

> **灾害状况下的最佳组合是室内箱储加甘薯干片。储存中开始变软的，要在腐烂之前立即切片晒干，转成长期储备。**

## 10. 烹调与注意事项
| 注意 | 内容 |
|:---|:---|
| 黑斑病 | 表皮有凹陷的黑色斑点，切开后里面也是褐色，苦得厉害。此时产生的甘薯黑疗素（ipomeamarone）是加热也不会被破坏的肝肺毒性物质，牲畜吃了会因肺水肿死亡。一发苦就立即吐掉，全部扔掉 |
| 腐烂部分 | 霉菌毒素扩散的范围远大于肉眼可见的变色部分，所以只要有一部分变软，就不要挖掉了事，整个扔掉 |
| 生甘薯 | 没有龙葵素那样的常在毒性，可以带皮吃，发了芽只要去掉那部分。但生淀粉不能消化，会在大肠里发酵，引起胀气和腹痛，所以当主食吃时一定要煮熟 |
| 薯尖 | 叶和茎含草酸，所以要倒掉焯水的水，并剥掉叶柄的外皮。每天大量吃有肾结石风险，所以要与其他凉拌菜轮换着吃 |

| 烹调 | 方法 |
|:---|:---|
| 灰烤 | 几乎不用燃料，需要40-60分钟，甜味最浓。这是因为它在60-75℃停留得久，β-淀粉酶把淀粉变成麦芽糖；用大火急着加热，酶会变性，甜味就淡。把它埋在做完饭的余火里，是燃料效率最好的做法 |
| 蒸、煮、余热 | 蒸25-35分钟，煮20-30分钟（糖会流失到水里），加热30分钟后保温2小时的余热烹调，味道与蒸相同 |
| 加工 | 糖稀和饴糖（在蒸熟的甘薯里倒入麦芽水，在60℃糖化6-8小时后熬浓；没有砂糖时的甜味剂，常温可长期保存）、淀粉、甘薯米酒（蒸熟的甘薯、酒曲和水，在20-25℃发酵5-7天）、焯后晒干的干菜 |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 每2周检查一次储存的甘薯，清除变软的 |
| 3-4月 | 3月挑选种薯，设置育苗床并埋入（栽插前50-60天）。4月培育薯苗，翻耕，施堆肥和木灰，起垄 |
| 5-6月 | 5月确认地温15℃以上后，第一次剪苗并栽插。6月检查成活，补栽缺株，除草，利用第二次剪的苗 |
| 7-8月 | 7月提蔓，开始收甘薯尖。8月管理藤蔓，继续收尖（块根膨大期） |
| 9-10月 | 9月试挖确认大小和霜期。10月清除藤蔓，5-7天后收获，立即做愈合处理 |
| 11-12月 | 11月完成愈合处理，降温，开始正式储存，晒甘薯干片。12月检查储存，坏的立即加工 |

> **甘薯是这样一种作物：绝不让温度降到9℃以下，不省略3-4天的愈合处理，发苦就不吃，让种薯活着过冬，并与豆类一起种。**
