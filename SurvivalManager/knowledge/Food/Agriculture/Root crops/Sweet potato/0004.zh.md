## 7. 水分管理

### 7-1. 按生育阶段的标准

| 时期 | 水分管理 | 原因 |
|---|---|---|
| 扦插后立即 | 浇透。每株100cc以上 | 这是没有根的茎能够存活的唯一条件 |
| 成活期（2周） | 干了就补。选阴天栽插更有利 | 在长出根之前，叶片会不断散失水分 |
| 藤蔓伸长期 | 不灌水。靠自然降水 | 水分充足时只会长藤蔓 |
| 块根形成期（30-50天） | 略微干燥 | 干旱胁迫会促进贮藏根的形成 |
| 块根膨大期（50-120天） | 干旱持续2周以上时，每周充分浇1次 | 这一时期缺水对产量的影响最大 |
| 收获前3周 | 停止灌水 | 糖度升高，耐储性变好 |

&nbsp;&nbsp;&nbsp;扦插后立即浇的水最重要。薯苗是在没有根的状态下栽插的，因此没有办法补充叶片蒸发掉的水分。熬不过这个阶段，就会直接干枯。缺水的情况下，应选在阴天或下雨前栽插，栽插后几天里白天用稻草或草覆盖，为其遮阴，这样很有效。把叶片剪掉一半左右来减少蒸腾，也是一种办法。

&nbsp;&nbsp;&nbsp;膨大期的干旱危害可以用数字来确认。在定植后60天缺水的试验区，每个薯块的平均重量从41.2g减少到10.6g，减少了75%。如果运水的余力有限，就应当把水集中用在这个时期，在韩国大致是7月到8月。

### 7-2. 缺水与水多的症状

| 类别 | 症状 | 对策 |
|---|---|---|
| 缺水 | 叶片在正午卷曲，新叶变小 | 膨大期就立即灌水，其他时期则不必理会 |
| 严重缺水 | 藤蔓末端停止生长，下部叶片变黄脱落 | 灌水并铺稻草覆盖 |
| 水多 | 藤蔓过度茂盛，叶片大而呈深绿色 | 挖排水沟，把藤蔓提起来 |
| 淹水 | 根变黑并发出臭味 | 无法恢复。立即排水，能挖就挖 |

## 8. 栽培管理

### 8-1. 提蔓

&nbsp;&nbsp;&nbsp;甘薯的藤蔓在着地的每个节上都会生根。这些根不膨大，保持细小的状态，吸收养分和水分，抢走本应流向原来位置薯块的养分。结果是整块田里散布着细小的薯，却长不出大薯。

| 作业 | 时期 | 方法 | 效果 |
|---|---|---|---|
| 提蔓 | 在韩国，7月起每隔2-3周 | 轻轻提起藤蔓，切断节上的根，放回原处 | 养分集中到原来的植株上 |
| 翻蔓 | 同一时期 | 把整条藤蔓翻到另一侧 | 效果比提蔓大，但叶片会受损 |
| 摘心 | 藤蔓过度茂盛时 | 剪掉末端30cm左右 | 剪下的茎可以做凉拌野菜食用 |

&nbsp;&nbsp;&nbsp;提蔓最好在阴天或傍晚进行。中午进行的话，叶片会被翻过来被太阳灼伤，并因胁迫使生长停滞几天。

### 8-2. 除草

| 项目 | 内容 |
|---|---|
| 关键时期 | 扦插后40天内，藤蔓覆盖地面之前 |
| 效果 | 除了清除杂草，还能打碎板结的表土，改善通气和水分渗透 |
| 产量差异 | 据报告，除草的田与不除草的田之间有40-50%的产量差异 |
| 之后 | 藤蔓覆盖地面后，杂草会自行受到抑制 |

&nbsp;&nbsp;&nbsp;甘薯前期生长缓慢，容易被杂草压制。但是一旦藤蔓覆盖了地面，它本身就成为强有力的杂草抑制剂。也就是说，只要守住最初的40天，其余时间几乎不用费工。在劳动力不足的灾害情境中，这一特性很重要。可以把力气集中在最初的一个月，之后就能腾出手来做别的事。

### 8-3. 覆盖

| 种类 | 效果 | 灾害情境下 |
|---|---|---|
| 黑色塑料膜 | 提高地温、抑制杂草、保墒 | 效果最大，但没有塑料膜就无法使用 |
| 稻草·干草 | 保墒、抑制杂草、改良土壤 | 替代塑料膜的首选。厚度5cm以上 |
| 落叶 | 保墒、增加有机质 | 压上土，避免被风吹走 |
| 割草覆盖 | 保墒、抑制杂草 | 割下田边的杂草，直接覆盖。要在杂草结籽之前 |

### 8-4. 收获叶和茎

&nbsp;&nbsp;&nbsp;甘薯的叶柄和嫩茎是出色的蔬菜。整个夏天都可以反复采摘，对根的产量影响不大。在灾害情境中，这是重要的额外收获。因为这意味着在等待四个月才能挖根的时间里，这块田里已经有东西可吃了。

| 项目 | 标准 |
|---|---|
| 收获时期 | 扦插后60天起到下霜前 |
| 采摘量 | 一次不超过全部叶片的三分之一 |
| 部位 | 藤蔓末端15cm以内的嫩茎和叶柄 |
| 处理 | 剥去叶柄的外皮就不会老韧 |
| 烹饪 | 焯水后做凉拌野菜，或放入汤中。避免生吃 |
| 注意 | 采摘过于频繁会使根的膨大延迟 |

## 9. 病虫害

&nbsp;&nbsp;&nbsp;甘薯的病虫害负担较低。评价中防治自立度获得了C，但其依据是几乎不需要防治，即使需要，用天然材料也足够。与马铃薯不同，甘薯没有无药可治的致命病害。

### 9-1. 主要病害

| 病名 | 症状 | 有利条件 | 不用药的应对 |
|---|---|---|---|
| 软腐病 | 根变软并发出臭味 | 伤口、过湿、贮藏期间高温 | 无伤口收获、彻底愈伤处理、立即清除感染的薯块 |
| 黑斑病 | 根表面出现黑色斑点，味苦 | 带病的种薯和薯苗 | 挑选健康的种薯，温汤处理 |
| 蔓割病 | 茎基部开裂并枯萎 | 土壤传染 | 抗病品种、健康薯苗、排水 |
| 炭疽病 | 叶和茎上出现褐色病斑 | 韩国的梅雨季（6月下旬至7月）过湿 | 保证通风、清除病叶 |
| 白粉病 | 叶片表面出现白色粉末 | 干燥且昼夜温差大时 | 喷洒牛奶稀释液（1比9） |
| 病毒病 | 叶片花叶、畸形、产量下降 | 蚜虫传播、种薯传染 | 只从健康植株上选留种薯 |

&nbsp;&nbsp;&nbsp;甘薯最需要警惕的病害是黑斑病。感染的甘薯会发苦，并产生对人和家畜有害的物质。贮藏期间会出现黑斑，该部位变硬并发苦。这部分必须剜掉，如果斑点扩散到多处，就必须整个丢弃。给家畜吃会引起肺水肿。

> **甘薯发苦就不要吃。甘薯本来就不是苦的作物，苦味是生病的信号。**

### 9-2. 主要害虫

| 害虫 | 危害 | 不用药的防治 |
|---|---|---|
| 金针虫（叩头虫幼虫） | 在根上咬出孔洞，降低商品性和耐储性 | 禁用未腐熟堆肥、马铃薯块诱捕、轮作、收获后翻耕田地 |
| 危害甘薯的蛾类幼虫 | 啃食叶和茎 | 清除受害叶片，焚烧残株 |
| 蚜虫 | 吸食汁液并传播病毒 | 喷洒肥皂水，保护瓢虫 |
| 叶螨 | 叶背变白 | 用水强力冲洗。干燥时发生 |
| 地老虎 | 把幼嫩的薯苗从基部咬断 | 栽后在基部撒灰，或用纸在周围围一圈 |
| 线虫 | 根上长瘤，表面粗糙 | 种植万寿菊、轮作、抗病品种 |
| 田鼠·野猪 | 刨食根 | 围栏、提前收获 |

&nbsp;&nbsp;&nbsp;在灾害情境中，甘薯实际上最大的有害生物不是昆虫，而是野生动物。野猪和田鼠能准确找到甘薯田。比较现实的对策，是在田边放置带有人气味的东西、围一圈带刺的树枝，或者抓紧收获。

### 9-3. 天然防治剂

| 防治剂 | 配制方法 | 用途 |
|---|---|---|
| 肥皂水 | 20g无香肥皂兑1L水 | 蚜虫、叶螨 |
| 牛奶稀释液 | 牛奶与水按1比9 | 白粉病 |
| 草木灰 | 把过筛的干灰撒在带露水的叶片上 | 驱避害虫，辅助补钾 |
| 木醋液 | 稀释50-100倍 | 驱避害虫，辅助杀菌 |
| 温汤处理 | 50-55℃，10-15分钟 | 种薯和薯苗消毒 |

### 9-4. 预防原则

| 原则 | 内容 |
|---|---|
| 健康种苗 | 只使用由无病种薯培育的薯苗。成败有一半在于此 |
| 排水 | 把垄做高 |
| 愈伤处理 | 收获后必须让伤口愈合，贮藏期间病害才不会蔓延 |
| 残体处理 | 收获后不把藤蔓和剩下的根留在田里 |
| 淘汰病株 | 在生长期间标记出现症状的植株，不作种薯用 |

## 10. 营养缺乏与过量

| 症状 | 原因 | 判断方法 | 用天然材料的处理 |
|---|---|---|---|
| 下部叶片开始变黄，藤蔓变细 | 缺氮 | 从老叶开始发展 | 腐熟堆肥，仅在成活期施用稀释20倍的尿液 |
| 叶缘呈褐色焦枯并卷曲 | 缺钾 | 从叶尖和叶缘开始 | 在沟里少量施草木灰，施草和果皮堆肥 |
| 生长迟缓，叶片由深绿变紫红 | 缺磷 | 低温期常见 | 骨粉、草木灰 |
| 新叶生长点枯萎 | 缺钙 | 从幼叶开始发展 | 把蛋壳烧后捣碎撒施 |
| 只有叶脉之间发黄 | 缺镁 | 从下部叶片开始 | 白云石、丰富堆肥材料的种类 |
| 新叶整体呈浅黄色 | 缺铁 | pH较高时 | 补充有机质，停用草木灰 |
| 只有藤蔓茂盛，根细而不膨大 | 氮过量 | 叶片大而深绿，藤蔓粗壮 | 停止供氮、提蔓、用草木灰补钾 |
| 根又细又长 | 氮过量或过湿 | 须根多 | 改善排水，不浇水 |
| 根开裂畸形 | 土壤板结，水分不均衡 | 有硬土或撞到石头的痕迹 | 深耕并把垄做高 |

&nbsp;&nbsp;&nbsp;甘薯上压倒性最常见的问题，不是缺乏，而是氮过量。典型情况是藤蔓长得有人那么高，挖开一看却没有薯。出现这种症状，当年能做的事不多。勤于提蔓、摘取嫩尖做成凉拌野菜食用，以减少损失，而第二年在这块地里不施肥，就是对策。

## 11. 间作与轮作

### 11-1. 搭配宜忌

| 搭配 | 对象 | 效果 |
|:---:|---|---|
| 非常好 | 豆科（大豆、豇豆、菜豆） | 固氮，并把甘薯所缺的蛋白质提供给人 |
| 好 | 玉米、高粱 | 在高秆作物下，甘薯覆盖地面，空间得到双重利用 |
| 好 | 万寿菊 | 抑制根结线虫 |
| 好 | 紫苏（荏） | 靠气味驱避部分害虫，还能成为油脂来源 |
| 一般 | 生菜、菠菜 | 在甘薯藤蔓覆盖之前的早期收获后撤出 |
| 差 | 马铃薯 | 共有金针虫和线虫，并争夺空间 |
| 差 | 番茄、辣椒、茄子 | 线虫危害叠加 |
| 差 | 南瓜 | 两者都贴地蔓生，空间竞争极其激烈 |

&nbsp;&nbsp;&nbsp;甘薯与豆科的搭配，意义超出了单纯的相合。甘薯唯一的致命缺陷是蛋白质不足，而豆类恰好把它补上。同时，豆科根部的固氮作用，自然地供给甘薯所需的少量氮。无论在田里还是在餐桌上，两者都是一对。

> **甘薯田旁边一定要有豆田。这不是耕作方法，而是营养设计。**

### 11-2. 轮作

&nbsp;&nbsp;&nbsp;甘薯被归为连作无害组。这意味着在同一块地里连续种植也没有大问题，在薯类（块茎/块根）中是非常例外的特性。不过它并非完全无害，过了几年，线虫和蔓割病的密度可能会上升。

| 方式 | 适用情形 | 内容 |
|---|---|---|
| 连作 | 田地狭小、没有余地时 | 把甘薯固定在同一处。每年少量补充堆肥 |
| 两年轮换 | 稍有余地时 | 甘薯与豆科交替种植 |
| 三年轮作 | 推荐 | 甘薯 → 豆科 → 叶菜类或谷物 |
| 发生线虫时 | 必须 | 种一年万寿菊或苏丹草，然后翻耕入土 |

&nbsp;&nbsp;&nbsp;与其冬天把田空着，不如种绿肥。在韩国，甘薯收获后的10月播下黑麦或毛叶苕子，冬季可以防止土壤流失，春天翻耕入土就成为有机质和氮。毛叶苕子是豆科，会固氮，但对甘薯来说氮可能过多，所以调整用量或使用黑麦更安全。
