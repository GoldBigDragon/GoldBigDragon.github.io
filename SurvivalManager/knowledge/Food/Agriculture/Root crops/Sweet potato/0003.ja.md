## 3. 栽培環境

### 3-1. 限界値と最適値

| 条件 | 最適値 | 限界値 | 限界を超えると起きること |
|---|---|---|---|
| 生育気温 | 25-30℃ | 15℃以下、35℃以上 | 15℃を下回ると生育が止まります |
| 塊根肥大の温度 | 20-30℃ | 30℃超 | つるだけが伸びて、根が太りません |
| 最低気温 | 夜間18℃以上 | 10℃以下 | 低温障害で生育が止まります |
| 霜 | 耐えられません | 0℃ | 地上部が一晩で枯れます |
| 地温（挿し付け時） | 18℃以上 | 15℃未満 | 活着せず、つる苗が腐ります |
| 日照 | 1日6時間以上 | 4時間未満 | つるだけが長くなり、塊根ができません |
| 遮光耐性 | 40%遮光で相対収量約80% | | 日陰でもある程度持ちこたえます |
| 総水要求量 | 約400mm | 冠水24時間 | 根が腐ります |
| 土壌 | 水はけのよい砂壌土、砂地 | 粘質土、地下水位の高い土地 | 根が太れず、形がいびつになります |
| 作土の深さ | 30cm以上 | 20cm未満 | 根が横にばかり伸びて小さくなります |
| 土壌酸度 | pH 5.5-6.5 | pH 4.2-8.3でも生育 | 酸度に対する適応幅が非常に広いです |

&nbsp;&nbsp;&nbsp;土壌酸度の適応幅がpH 4.2-8.3というのは、驚くべき数値です。大半の作物がpHの幅で1-1.5程度の範囲でしか順調に育たないのと比べると、サツマイモは事実上、酸度を選びません。土壌診断も石灰散布もできない状況では、この特性は決定的です。土地がどうであれ、とにかく植えれば育ちます。

&nbsp;&nbsp;&nbsp;反対に、決して妥協できない条件は排水と地温です。水がたまる土地では根が腐り、地温が低いと活着そのものが成り立ちません。砂の混じった痩せ地が、むしろサツマイモにとってはよい畑です。開墾地、川沿いの砂地、傾斜した礫地のように、ほかの作物が失敗する場所が、サツマイモには適地になります。

> **ほかの作物を植えられない痩せて乾いた土地が残っているなら、そこがサツマイモの場所です。**

### 3-2. 災害時の立地選び

| 順位 | 条件 | 理由 |
|---|---|---|
| 1 | 水がたまらない場所 | 排水不良はサツマイモ栽培が失敗する最も一般的な原因です |
| 2 | 南向きの日当たりのよい傾斜地 | 地温が早く上がり、日照が長くなります |
| 3 | 砂の混じった軽い土 | 根が太りやすく、掘り取りも楽です |
| 4 | 風を防いでくれる場所 | 台風でつるがひっくり返るのを減らせます |
| 5 | 肥料分の少ない土地 | かえって有利です。肥沃な土地はつるばかりを育てます |

## 4. 品種

### 4-1. 食感による分類

| 区分 | 特徴 | 代表品種 | 適した用途 |
|---|---|---|---|
| 粉質（パムゴグマ、栗いも） | デンプンが多く水分が少なく、ほくほくしています | パムゴグマ、シンチョンミ、ユルミ | 茹でる、蒸す、粉とデンプン |
| 粘質（ホバクゴグマ、かぼちゃいも） | 水分と糖が多く、しっとり柔らかいです | ホバクゴグマ、テユミ | 焼く、煮つけ、粥 |
| 高糖度（クルゴグマ、蜜いも） | 貯蔵すると糖度がさらに上がります | ベニハルカ、ホプンミ | 焼く、生食、おやつ |

&nbsp;&nbsp;&nbsp;災害への備えという観点では、粉質系が有利な面があります。水分が少なく乾燥や粉への加工に向いており、デンプンの歩留まりが高く、貯蔵中の腐敗も少なめです。一方、粘質系は熱量密度は高いものの水分が多く、乾燥に燃料と時間がよけいにかかり、貯蔵中に軟化しやすくなります。

### 4-2. 主要品種の比較

| 品種 | 栽培期間 | 収量 | 貯蔵性 | 栽培の難易度 | 食感 | 特徴 |
|---|:---:|:---:|:---:|:---:|---|---|
| パムゴグマ（系統） | 100-120日 | 中上 | 上 | 易しい | 粉質 | 栽培期間が短く、貯蔵性がよいです |
| ホバクゴグマ | 120-130日 | 上 | 中 | 易しい | 粘質 | β-カロテンが最も豊富です |
| ベニハルカ | 130-150日 | 上 | 中 | 普通 | 粘質 | 貯蔵すると糖度が大きく上がります。温暖地向き |
| ホプンミ | 早期栽培型 | 非常に高い | 上 | 易しい | 粉質 | 早期栽培での増収効果が大きいです |
| ソダムミ | 早期栽培型 | 高い | 上 | 易しい | 粉質 | ホプンミとともに早期栽培に適しています |
| テユミ | 中晩生 | 高い | 最上 | 易しい | 粉質 | 貯蔵中の腐敗率が1%未満です |
| コゴンミ | 中晩生 | 高い | 最上 | 易しい | 粉質 | 貯蔵性が最も優れた系統です |

| 紫サツマイモ | 110-130日 | 中 | 中 | 易しい | 粘質 | アントシアニンが豊富です |
| ヨンファンミ・ユルミ | 中生 | 中 | 中 | 易しい | 粉質 | 葉とつるが柔らかく、ナムル用に向いています |

### 4-3. 状況別の選択基準

| 状況 | 選択 | 理由 |
|---|---|---|
| 冬を越す必要がある | テユミ、コゴンミ | 貯蔵中の腐敗率が1%未満です |
| 霜が早い地域 | パムゴグマ、ホプンミ、ソダムミ | 100-120日で収穫できます |
| ビタミンAの補強 | ホバクゴグマ | β-カロテンの含有量が最も高いです |
| 葉とつるまで食べたい | ヨンファンミ、ユルミ | 葉柄が柔らかく、えぐみが少ないです |
| 粉・デンプンとして備蓄 | パムゴグマ系統、テユミ | 粉質なのでデンプンの歩留まりが高いです |
| 貯蔵施設が不十分 | テユミ、コゴンミ | 温度が変動しても耐えます |
| 避けるべきもの | シンチョンミ | 味はよいが、貯蔵中に3分の1以上が腐ります |

&nbsp;&nbsp;&nbsp;貯蔵性の差は、実際の数値で見ると劇的です。同じ条件で4か月貯蔵したとき、テユミとコゴンミの腐敗率は1%を下回るのに対し、シンチョンミは36.7%にのぼります。1,000kgを貯蔵した場合、10kgを失うか360kgを失うかの違いです。災害時には、品種選びひとつが冬の食料の3分の1を左右します。

> **サツマイモの品種選びで最も重要な指標は、収量でも味でもなく、貯蔵中の腐敗率です。**

## 5. 畑の準備と肥料

### 5-1. 土づくり

| 項目 | 基準 | 理由 |
|---|---|---|
| 耕す深さ | 25-30cm | 根が下へ伸びる空間をつくります |
| 畝の高さ | 25-35cm | 高いほど根が太り、排水がよくなります |
| 畝の幅 | 60-75cm | 1条植えまたは2条植えに合わせます |
| 畝間 | 深さ20cm以上 | 韓国の梅雨（チャンマ、6月下旬～7月）の水の通り道になります |
| 土の状態 | ほろほろになるまで砕く | 硬い土では根が曲がります |
| 土壌酸度 | pH 5.5-6.5を推奨 | あまり気にしなくても構いません |

&nbsp;&nbsp;&nbsp;畝を高くすることが、サツマイモ栽培で最も安上がりで確実な投資です。高い畝は排水をよくし、地温を上げ、根が育つやわらかい土の層を厚くします。試験で畝の高さを20-35cmに上げただけで収量が目に見えて増えた事例が、繰り返し報告されています。

### 5-2. 標準施肥量（1,000㎡当たり）

| 肥料 | 施肥量 | 備考 |
|---|---|---|
| 窒素 | 最小限に | 過剰は致命的です。痩せ地では省いても構いません |
| リン酸 | 10-15kg | 根の発達を助けます。全量を元肥に |
| カリウム | 15-20kg | 塊根の肥大に最も重要です。全量を元肥に |
| 堆肥 | 1,000-1,500kg | 完熟堆肥。過剰は禁物 |

&nbsp;&nbsp;&nbsp;1㎡当たりに換算すると15g前後です。ジャガイモの半分にも届きません。サツマイモの施肥の原則は、一文に要約できます。窒素は最小限に、カリウムはたっぷりと。

### 5-3. 元肥と追肥

| 区分 | 時期 | 内容 | 注意 |
|---|---|---|---|
| 元肥 | 挿し付けの2週間前 | 堆肥、リン酸、カリウムを全量 | 窒素はほとんど入れません |
| 追肥 | 原則として省略 | 効果がはっきりしません | 砂地で流亡がひどいときだけカリウムを少量補給 |

&nbsp;&nbsp;&nbsp;追肥を与えないというのは違和感があるかもしれませんが、サツマイモではこれが定石です。生育の中ごろに窒素を入れると、植物は蓄えるのをやめて、再びつるを伸ばし始めます。すでに太り始めていた根も肥大を止めます。災害時に肥料が足りないことは、サツマイモ栽培に関する限り、むしろ幸いです。

### 5-4. 化学肥料がないとき - 災害時の代替肥料

| 代替資源 | 供給成分 | つくり方と使い方 | 注意 |
|---|---|---|---|
| 草木灰 | カリウム、リン酸、カルシウム | ふるいにかけた白い灰を10㎡当たり1-2L、畝をつくる前にまいて混ぜます | サツマイモは酸度への適応幅が広いので、ジャガイモより負担が少なくて済みます |
| 完熟堆肥 | 総合 | 落ち葉と草を6か月以上積んでつくります。元肥として少量 | 多すぎるとつるばかりが茂ります |
| 薄めた尿 | 窒素、カリウム | 挿し付け直後の活着期にだけ、20倍に薄めて少量 | 肥大期には絶対に与えません |
| 骨粉 | リン酸、カルシウム | 元肥として土に混ぜます | 分解が遅いです |
| 海藻 | カリウム、微量要素 | 真水ですすいで、畝にマルチングします | 塩分を必ず抜きます |
| 稲わら・落ち葉 | 有機物、カリウム | 畝間に敷いておくと徐々に分解されます | 土壌の物理性がよくなります |
| タバコの灰・炭粉 | カリウム、土壌改良 | 少量を畝に混ぜます | 大量に使うとアルカリ化を招きます |

> **サツマイモに肥料を与えるときの最も一般的な失敗は、与えすぎることです。もったいなくて少なめに与えるくらいが、サツマイモにはほぼ正解です。**

## 6. 挿し付けと苗づくり

### 6-1. なぜ種いもをそのまま植えないのか

&nbsp;&nbsp;&nbsp;ジャガイモは種いもを切って畑に直接植えますが、サツマイモはそうしません。サツマイモを丸ごと埋めると、その場所で複数の芽が出はしますが、新しい根がきちんと太らず、もとのいもに付随する形で育つため、収量が大きく落ちます。そこで、まず苗床で種いもに芽を出させてつるを育て、そのつるを切り取って畑に挿します。この切り取ったつるを「つる苗」または単に「苗」と呼びます。

&nbsp;&nbsp;&nbsp;この方式の利点は増殖率です。種いも1個からつる苗が20-30本取れます。つまり、10個の種いもさえ生かしておけば、翌年には200-300本の苗が得られ、畑一区画を埋められます。これが、評価表で自家採種の項目がSを得た根拠です。

### 6-2. 苗床のつくり方 - ビニールも電気もないとき

&nbsp;&nbsp;&nbsp;サツマイモの育苗で要となるのは、韓国の気候では3月末から4月に地温を25-30℃に上げることです。電熱線がなければ発酵熱を使います。昔ながらの温床の方法が、そのまま通用します。

| 手順 | 内容 |
|---|---|
| 1 | 日当たりのよい南向きの場所に、深さ50-60cm、幅1-1.2mの穴を掘ります |
| 2 | 出たばかりの馬ふんや牛ふんをわら、落ち葉と混ぜ、穴に30-40cmの厚さに踏み込みます |
| 3 | 水をまいて湿らせ、数日覆っておくと発酵が始まり、熱が出ます |
| 4 | 発酵熱が上がったら、その上に砂を混ぜた土を10-15cmかぶせます |
| 5 | 土の温度が30度前後で安定したら、種いもを寝かせて並べ、土を3-4cmかぶせます |
| 6 | わらむしろや透明なカバーで夜は覆い、昼は開けます |

&nbsp;&nbsp;&nbsp;馬ふんは発酵熱が最も強く、長く続きます。家畜がいなければ、落ち葉と米ぬか、尿を混ぜて積んでも熱が出ます。発酵熱の温床は、1か月から1か月半のあいだ20-40℃の温度を保ち、これはサツマイモの育苗にちょうど合う期間と温度です。

| 育苗条件 | 基準 |
|---|---|
| 種いもを置く向き | 太いほう（へたの反対側）がやや上を向くように寝かせます |
| 種いもの間隔 | 互いに触れないよう3-5cm |
| 床土の温度 | 初期は30-32℃、芽が出たら25℃ |
| 期間 | 30-40日でつる苗を切り取れます |
| 水 | 乾かない程度だけ。湿りすぎると腐ります |

### 6-3. つる苗の選び方

| 項目 | 基準 | 理由 |
|---|---|---|
| 長さ | 20-30cm | 短すぎると節の数が足りません |
| 節の数 | 5-7個 | 土に埋まる節ごとにいもができます |
| 太さ | 鉛筆の太さ以上 | 細いものは活着が悪いです |
| 部位 | つるの先端側（生長点のある部分） | 最も活力があります |
| 切り方 | 根ごと引き抜かず、地面から2-3cm上で切ります | 残った株元からまた芽が出て、2回目、3回目の採取ができます |
| 切った後 | 日陰で1日置いて切り口を癒合させます | 活着率が上がります |

### 6-4. 植える時期

| 地域 | 時期 | 基準 |
|---|---|---|
| 韓国南部 | 4月下旬-5月中旬 | |
| 韓国中部 | 5月中旬-6月上旬 | |
| 共通の基準 | 地温18℃以上、最低気温15℃以上が安定したとき | 時期よりも温度が基準です |
| 期限 | 6月下旬以降は避けます | 生育期間が足りず、小さないもしかできません |

### 6-5. 植え方 - 寝かせ植え

| 項目 | 基準 | 理由 |
|---|---|---|
| 向き | 寝かせて水平に近く | 立てて植えると一点からしか根が出ません |
| 埋める節の数 | 3-4節 | 節ごとにいもがつきます |
| 深さ | 3-5cm | 深いと地温が低く、活着が遅れます |
| 地上に残す部分 | 先端の葉2-3枚が地上に出るように | 光合成が活着を助けます |
| 株間 | 25-30cm | |
| 畝の間隔 | 70-90cm | |
| 植えた後 | 1株当たり水100cc以上をすぐに灌水 | 活着の成否がここで決まります |

&nbsp;&nbsp;&nbsp;寝かせ植えにはいくつかの変形があります。水平にまっすぐ寝かせる水平植えは、いもの数が多くて大きさが揃う一方、深くつかないので掘りやすいです。鎌の形に曲げて植える改良水平植えは、活着がやや早くなります。斜めに挿す斜め植えは干ばつに強いものの、いもの数が減り、大きさが不揃いになります。水をこまめにやれない状況なら斜め植えが、水が確保できるなら水平植えがよいでしょう。

> **立てて植えたサツマイモ畑と寝かせて植えたサツマイモ畑では、収穫量に2倍もの差が出ます。植える姿勢ひとつが、一年の作柄を分けます。**

### 6-6. つる苗の消毒

| 方法 | 手順 | 効果 |
|---|---|---|
| 温湯処理 | 50-55℃の湯に10-15分浸けます | 表面の病原菌を殺します |
| 草木灰処理 | 切り口に乾いた灰をつけます | 切り口の腐敗を防ぎます |
| 木酢液への浸漬 | 100倍希釈液に10分 | 殺菌を補助します |
| 健全な個体の選別 | 斑点や萎れた苗を除きます | 最も効果が大きい方法です |
