## はじめに
&nbsp;&nbsp;&nbsp;サツマイモ(Ipomoea batatas)は中南米の熱帯低地から来たヒルガオ科のつる植物で、食べる部分は茎ではなく根が太った塊根です。災害への備えの評価は総合SS(57.6点、有効183種中4位)、短期S(56.7)、長期SS(58.4)、副食S(53.2点)で、長期が短期より高くなっています。植えてから120-150日かかりますが、根づけば肥料も薬もほとんど要らずに1㎡当たり3,675kcalを生み、β-カロテンが豊富で、やせ地と干ばつに強く、連作もできます。決定的な欠点は、熱量に対するタンパク質が3.0%(E)しかなく、マメ類といっしょに作らなければならないことです。また霜で即死し、収穫した根も9℃を下回ると冷害を受け、種芋を冬のあいだ13℃前後で生かしておけなければ翌年の農作が途切れます。勝負は畑ではなく冬の貯蔵庫でつきます。

## 1. 災害への備えの評価
| 区分 | 等級 | スコア |
|:---|:---:|:---:|
| 総合 | SS | 57.6 |
| 短期 | S | 56.7 |
| 長期 | SS | 58.4 |
| 副食 | S | 53.2 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: 連作への適応性、味。S: 面積当たりの熱量、微量栄養素、施肥、国内での栽培の普及度、自家採種。A: 水の消費量。B: 施設の負担、日射、調理・加工の要求度、貯蔵性、合成資材を投入しない場合の収量維持率、収量の安定性 |
| 弱み | E: タンパク質密度、耐寒性、非食用の価値、種子の寿命。D: 永続性。C: 収穫速度、温度幅、病害虫圧、防除の自立度、整地・掘削エネルギー |

> **サツマイモの1畝は主食でありビタミン源であり野菜畑でもありますが、サツマイモだけで生きていくことはできません。マメをいっしょに植えるのは選択ではなく栽培計画の一部です。**

&nbsp;&nbsp;&nbsp;面積当たりの熱量Sと施肥Sが並んでいる点が要です。サツマイモは1㎡当たり15gの養分で3,675kcalをつくり、ジャガイモ(32g、2,010kcal)より投入に対する産出が4倍近く大きく、合成資材を投入しない場合の収量維持率も45.1%とジャガイモの17.6%より高くなっています。連作への適応性SSは、農村振興庁が連作の害が出ない群に分類しているという意味で、イモ・根菜類のなかでは例外です。微量栄養素Sの実体はβ-カロテンで、葉と茎もナムルになります。タンパク質密度Eは、1日2,100kcalをサツマイモだけで満たすとタンパク質が約16gしかとれず(成人男性の必要量は55g)、数か月で筋肉が落ち、傷が治らず、感染しやすくなるという意味なので、畑の面積の25-33%をマメ科に割り当てます。耐寒性Eと種子の寿命Eは、種芋を暖かく生かしておかなければならないという一つの問題です(第8節)。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | ヒルガオ科サツマイモ属(Ipomoea)のつる性植物。ジャガイモとはまったく別の系統で病害虫をほとんど共有しないため、2つの作物を分けて植えれば片方の全滅を避けられる |
| 葉・茎 | 茎は地面をはうつるで1-3mまで伸び、節ごとに根を出す。葉と葉柄は食用 |
| 花・実 | 短日植物で、韓国では花が咲く前に霜が降りるため、ほとんど咲かない。種子では続けられず、生きた根で世代をつながなければならない |
| 塊根 | 根が肥大したもの。芽はないが、どの部分からでも不定芽を出せる |

&nbsp;&nbsp;&nbsp;植え付け後2週間までは活着期(水分が絶対的)、2-8週はつる伸長期(窒素、カリウム)で、30-50日に塊根ができ始め、50-120日に肥大期(カリウム要求が最大)を経て、120日以降の成熟期(灌水を止める)に入ります。根は最初はすべて細い繊維根で、一部が太って貯蔵根になりますが、窒素と水が十分にあると植物は貯蔵する必要を感じずにつるだけを育てるため、ほどよく飢えているときに根に養分をためます。100g当たり熱量147kcal、炭水化物31-35g、糖類9.83g、タンパク質1.09g、ビタミンC 10-23mgで、ビタミンA(β-カロテン)はオレンジ色が濃いほど多くなります。甘みは加熱と貯蔵の間にβ-アミラーゼが50-70℃でデンプンを麦芽糖に変えて生じるため、とろ火でゆっくり加熱するほど甘くなります。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 生育25-30℃(15℃以下で止まり、35℃以上が限界)、塊根の肥大20-30℃(30℃を超えるとつるだけが伸びる)、夜18℃以上(10℃以下で低温障害)、植え付け時の地温18℃以上(15℃未満では活着しない)。霜で地上部が一晩で枯れる |
| 水・光 | 総蒸発散量は約400mmで、24時間冠水すると根が腐る。1日6時間以上の日照が必要で(4時間未満ではつるだけが長くなる)、40%遮光で相対収量は約80% |
| 土壌 | 水はけのよい砂壌土や砂地、耕起の深さ30cm以上。粘土質や地下水位の高い土地では根が太れない。pH 4.2-8.3でも育ち、酸度をほとんど問わない |

&nbsp;&nbsp;&nbsp;立地は、水がたまらない場所(排水不良がもっとも多い失敗の原因)、日当たりのよい南向きの傾斜地、砂の混じった軽い土、風を防げる場所の順に選びます。肥えた土地はつるだけを育てるため、地力の低い土地のほうがむしろ有利で、ほかの作物が植えられないやせて乾いた土地がサツマイモの場所です。

&nbsp;&nbsp;&nbsp;粉質系(栗系など)は水分が少なくデンプンが多いので乾燥や粉への加工に向き、貯蔵中の腐敗も少なく、粘質系(カボチャ系など)は水分と糖が多いので焼きものや粥に向き、β-カロテンがもっとも豊富です。品種選びでいちばん大事な指標は、収量でも味でもなく貯蔵中の腐敗率です。同じ条件で4か月貯蔵すると、デユミとコゴンミは腐敗率が1%未満なのに対し、シンチョンミは36.7%に達し、1,000kgのうち360kgを失います。霜が早い地域には、100-120日で収穫できる栗系、ホプンミ、ソダムミが向きます。

## 4. 畑の準備と植え付け
| 項目 | 基準 |
|:---|:---|
| 土地づくり | 25-30cmの深さに耕し、高さ25-35cm、幅60-75cmの高い畝と深さ20cm以上の溝をつくる(排水がよくなり、地温が上がり、根が太る、もっとも安上がりな投資)。土はぽろぽろになるまで砕く |
| 施肥(1,000㎡) | 窒素は最小限(過多は致命的で、やせ地では省く)、リン酸10-15kg、カリウム15-20kg(塊根の肥大にもっとも重要)、完熟堆肥1,000-1,500kgを、植え付けの2週間前に全量元肥として与える。追肥は原則として省く(生育中盤の窒素は貯蔵を止めてつるを再び育てる) |
| 災害時の代替肥料 | 木灰(10㎡当たり1-2L)、腐熟堆肥、尿の20倍希釈液(活着期のみ、肥大期は禁止)、骨粉、真水ですすいで塩気を抜いた海藻、稲わらと落ち葉 |
| 育苗床 | 植え付けの50-60日前に南向きに深さ50-60cm、幅1-1.2mで掘り、出たばかりの馬ふんか牛ふんをわらや落ち葉と混ぜて30-40cmの厚さに踏み込み、水をまいて発酵させ(家畜がいなければ落ち葉、米ぬか、尿)、砂を混ぜた土を10-15cmかぶせる。土の温度が30℃前後で安定したら種芋を3-5cm間隔で寝かせて土を3-4cmかぶせ、夜はむしろをかけ、芽が出たら23-25℃に下げる |
| つる苗 | 30-40日で25-30cmに育ち、株元を3-5cm残して切ると再び芽が出て、1つの種芋から3-4回採れる。節が5-7個で鉛筆の太さ以上の健全な苗を選び、1日日陰に置いて切り口を癒やしたあと、50-55℃の湯に10-15分浸すか木灰をまぶして消毒する |
| 植え付け時期 | 地温18℃以上、最低気温15℃以上が安定したとき(時期より温度が基準)。南部は4月下旬-5月中旬、中部は5月中旬-6月上旬で、6月下旬以降は生育期間が足りず小さなイモしかできない |
| 植え付け | 寝かせて3-4節を3-5cmの深さに埋め、先端の葉2-3枚を地上に出す(節ごとにイモがつき、立てて植えると根が1か所からしか出ず収量が半分になる)。株間25-30cm、畝間70-90cmで植え、すぐに1株当たり100cc以上の水をやる |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 植え付け直後 | たっぷりやる(根のない茎が生き残る唯一の条件)。曇りの日に植え、数日間わらや草で日陰をつくるか、葉を半分ほど切って蒸散を減らす |
| 活着期から塊根形成期 | 乾いたら補い、その後は自然の雨にまかせ、塊根形成期(30-50日)はやや乾かし気味にする(水が十分だとつるだけが育ち、乾燥ストレスが貯蔵根の形成を促す) |
| 塊根の肥大期(50-120日) | 干ばつが2週間以上続けば週1回たっぷりやる(60日間水が不足した試験区で、イモ1個の平均重量が75%減った)。水が限られるなら7-8月に集中する |
| 収穫の3週間前 | 灌水を止める(糖度が上がり、貯蔵性がよくなる) |

| 管理 | 方法 |
|:---|:---|
| つる返し | 地面についた節ごとに細い根が出て養分を奪うので、7月から2-3週間おきに、曇りの日か夕方に、つるを軽く持ち上げて節の根を切り、元の位置に置く。茂りすぎたら先端30cmほどを切ってナムルとして食べる |
| 草取り | 植え付け後40日までの、つるが地面を覆う前が大事(しないと収量に40-50%の差が出る)。覆ったあとはつるが雑草を抑える |
| マルチング | 厚さ5cm以上のわらや干し草がポリフィルムの代わりの第一候補で、刈った草は種が実る前に敷く |
| 葉・茎の収穫 | 植え付け後60日から霜までのあいだ、つるの先端15cm以内の若い芽と葉柄を、一度に全体の葉の3分の1以下で摘む(摘みすぎると肥大が遅れる)。外皮をむいて茹で、ナムルや汁物にして食べる |
| 水不足、過多 | 不足すると昼に葉が丸まり新しい葉が小さくなる(肥大期ならすぐ灌水)。ひどければ灌水してわらをかける。過多だとつるだけが茂るので排水溝を掘る。冠水で根が黒くなり悪臭がするなら回復は不可能なので、すぐ水を抜き、掘れるなら掘る |

## 6. 病害虫と養分の問題
&nbsp;&nbsp;&nbsp;病害虫の負担は低めです。防除の自立度Cは、防除がほとんど要らず、要る場合も自然素材で足りるという意味で、ジャガイモの疫病のような治療薬のない病害はありません。予防は、健全な苗と種芋(半分はここで決まる)、高い畝、徹底したキュアリング、収穫後の残渣の整理で成り立ちます。

| 病害虫 | 症状と条件 | 予防と対処 |
|:---|:---|:---|
| 軟腐病 | 根が軟らかくなって悪臭がする(傷、過湿、貯蔵中の高温) | 傷をつけずに収穫し、キュアリングを徹底し、感染したものはすぐ取り除く |
| 黒斑病 | 根の表面に黒い斑点ができて苦い(感染した種芋と苗) | 健全な種芋を選び、温湯処理をする。苦みがあれば食べない(第10節) |
| つる割病、炭疽病、うどんこ病 | 茎の株元が割れてしおれる(土壌伝染) / 葉と茎に茶色い病斑(梅雨期の過湿) / 葉に白い粉(乾燥して昼夜の差が大きいとき) | 抵抗性品種、健全な苗、排水 / 風通しを確保し、病葉を取り除く / 牛乳の1対9希釈液 |
| ウイルス病 | 葉のモザイク、奇形、収量の低下(アブラムシ、種芋で伝染) | 健康な株からだけ種芋を選ぶ |
| 害虫 | ハリガネムシ(根に穴)、ガの幼虫(葉と茎)、アブラムシ・ハダニ、ヨトウ類(若い苗を株元で切る)、センチュウ(根にこぶ)、野ネズミ・イノシシ(根を掘って食べる) | 未熟な堆肥を使わない、ジャガイモ片のトラップ、輪作 / 被害葉の除去、残渣の焼却 / せっけん水(無香料の石けん20gに水1L)、テントウムシの保護 / 株元に灰か紙の囲み / マリーゴールド / 柵、とげのある枝、収穫を早める |

| 症状 | 原因と対処 |
|:---|:---|
| 葉の縁が茶色く焼けて巻く | カリウム欠乏。木灰を溝に少量 |
| つるだけが茂って根が太らない | 窒素過多(圧倒的によくある問題)。窒素を止め、つるを持ち上げ、芽を摘んでナムルとして食べ、翌年はその場所に肥料を入れない |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| とても良い | マメ科(ダイズ、ササゲ、インゲンマメ): 窒素を固定し、サツマイモにないタンパク質を人に供給する |
| 良い | トウモロコシ、ソルガム(背の高い作物の下でサツマイモが地面を覆う)、マリーゴールド(センチュウを抑える)、エゴマ(においで害虫を寄せつけない) |
| 普通 | レタス、ホウレンソウ(つるが覆う前の初期に収穫して抜く) |
| 悪い | ジャガイモ(ハリガネムシとセンチュウを共有し、場所を奪い合う)、トマト、トウガラシ、ナス(センチュウの被害が重なる)、カボチャ(場所の競合) |

&nbsp;&nbsp;&nbsp;サツマイモは連作の害が出ない群なので、畑が狭ければ同じ場所に固定し、毎年堆肥を少量補います。余裕があればサツマイモ、マメ科、葉菜類か穀類の3年輪作を勧めます。数年たつとセンチュウとつる割病の密度が上がることがあるので、センチュウが出たらマリーゴールドかスーダングラスを1年植えてすき込みます。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 植え付け後120-150日だが、基準は「大きくなったか」ではなく「寒くなる前か」である。地温が15℃を下回る前、霜の前に終え(霜にあたった葉の冷害が根に下りる)、地温が10℃を下回った土の中にあったイモは掘ったあとの貯蔵中に必ず腐るので、太りきっていなくても霜の前に掘る。1-2株を先に掘って太さを確認する |
| 要領 | 5-7日前につるを片づけて皮を固めたうえで、晴れて乾いた日の午前に、株から30cm外側を掘って土ごと持ち上げ、手で外す(引っ張らない)。土だけ払って水では洗わず、日陰で2-3時間乾かす。皮が薄く、爪の傷1つが腐敗の始まりになるので、傷ついたものは別にまとめて先に食べる |

| 採種 | 基準 |
|:---|:---|
| 構造 | 温帯では開花がまれで実生は形質がばらばらなので、繁殖はすべて栄養繁殖である。遺伝子型は100%保たれるが、種子を乾かして保管できないため、生きたイモで冬を越さなければならず、種芋が凍ったり腐ったりすれば翌年植えるものがない |
| 種芋の選び方 | 150-250gの紡錘形で、傷、病斑、黒い点がまったくないもの(1つが全体にうつす)を、いちばんよく育った株から選ぶ。植え付け面積1,000㎡当たり60-80kgで、1つの種芋から苗が20-30本とれる |
| 越冬 | キュアリング(30-33℃、湿度90-95%、3-4日)のあと、4-5日かけて13℃まで徐々に冷まし、12-15℃、湿度85-90%で保管する。ジャガイモ用の土室(3-5℃)にいっしょに置くとサツマイモだけが全滅するので別にし、人が暮らす部屋の隅か台所の裏が最も安全である。電気なしで30℃をつくるには、箱ごと日当たりのよい部屋のいちばん暖かい場所(オンドルの焚き口側)に置き、わらや毛布で包んで水の入った器で湿度を保つ |
| 退化の管理 | 栄養繁殖を繰り返すとウイルスがたまり、5-6年で収量が目に見えて減る。毎年いちばん元気な株からだけ種芋を残し、苗は親株から遠い先端側のものを使い(ウイルス濃度が低い)、葉がまだらになったり縮んだりした株は食べ、4-5年ごとにほかの地域の種芋と交換する |

## 9. 貯蔵
&nbsp;&nbsp;&nbsp;貯蔵の成否は、収穫直後3-4日のキュアリング(30-33℃、湿度90-95%)で決まります。傷の表面にコルク層ができて病原菌を防ぎ、貯蔵の損失が半分以下になります。続いて徐々に冷ましてから本貯蔵(12-15℃、湿度85-90%、暗黒、弱い通風)に入り、5-6か月もちます。2週間に1回点検して軟らかくなったものをすぐ取り除きます。9℃以下では中が硬くなって腐り、18℃以上では芽が出ます。

| 方式 | 方法 | 期間 |
|:---|:---|:---|
| 室内の箱 | キュアリングのあと、段ボール箱に新聞紙を敷いて層にして詰め、人が暮らす部屋の隅に置く。もっとも確実 | 4-6か月 |
| もみがら・砂の層、わら断熱 | 箱にもみがらや乾いた砂と交互に詰める(腐敗の伝染を防ぐ) / 室内の隅にわらを厚く敷いて積み、わらとむしろで覆う | 3-5か月 / 3-4か月 |
| オンドルのそば | 焚き口の脇の空間。温度が合えば最高だが、熱すぎると芽が出る | 5-6か月 |
| 切り干し | 生のものを5mmの厚さに切り、日なたで3-5日完全に乾燥させる(体積が20%に減り、虫さえ防げば年を越す)。水で戻して粥にするか、粉に挽いて餅をつくる | 1-2年 |
| 干しイモ、デンプン | 蒸して皮をむき、細長く切って乾燥 / すりおろして水に溶き、沈んだ沈殿を乾かす | 6か月-1年 / 数年 |

> **災害への備えの最適な組み合わせは、室内の箱での貯蔵と切り干しです。貯蔵中に軟らかくなり始めたものは、腐る前にすぐ切って干し、長期の備蓄に回します。**

## 10. 調理と注意事項
| 注意 | 内容 |
|:---|:---|
| 黒斑病 | 皮にくぼんだ黒い斑点があり、切ると中身まで茶色で、ひどく苦い。このときできるイポメアマロンは加熱しても壊れない肝臓・肺への毒性物質で、家畜が食べると肺水腫で死ぬ。苦みがあればすぐ吐き出して全部捨てる |
| 腐った部分 | カビの毒素は目に見える変色部分よりはるかに広く広がっているので、一部が軟らかくなったらえぐり取らずに丸ごと捨てる |
| 生のサツマイモ | ソラニンのような常時の毒性はなく、皮つきでも食べられ、芽が出たらその部分だけ取る。ただし生のデンプンは消化されず大腸で発酵してガスと腹痛を起こすので、主食として食べるときは必ず加熱する |
| 茎葉 | 葉と茎にシュウ酸があるので、茹で汁は捨て、葉柄の外皮はむく。毎日大量に食べると腎臓結石の危険があるので、ほかのナムルと交互に食べる |

| 調理 | 方法 |
|:---|:---|
| 焼き芋(灰焼き) | 燃料がほとんど要らず40-60分かかり、甘みがもっとも強い。60-75℃に長くとどまってβ-アミラーゼがデンプンを麦芽糖に変えるためで、強火で急いで加熱すると酵素が変性して甘みが弱くなる。炊事が終わったおき火に埋めておくのが燃料効率では最善 |
| 蒸す、茹でる、余熱 | 蒸すのは25-35分、茹でるのは20-30分(水に糖が抜ける)、30分加熱したあと2時間保温する余熱調理は蒸すのと同じ味 |
| 加工 | 水あめ状の甘味料(チョチョン)と飴(ヨッ)(蒸したサツマイモに麦芽水を注ぎ、60℃で6-8時間糖化させて煮詰める。砂糖がないときの甘味料で、常温で長く保管できる)、デンプン、サツマイモのマッコリ(蒸したサツマイモ、麹、水を20-25℃で5-7日)、茹でて干したナムル |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵したサツマイモを2週間おきに点検し、軟らかくなったものを取り除く |
| 3-4月 | 3月に種芋を選び、育苗床を設けて埋める(植え付けの50-60日前)。4月に苗を育て、耕起し、堆肥と木灰を入れ、畝をつくる |
| 5-6月 | 5月に地温15℃以上を確認し、苗の1回目の採取と植え付け。6月に活着の確認、欠株の補植、草取り、2回目の苗の活用 |
| 7-8月 | 7月につる返しをして、サツマイモの茎葉の収穫を始める。8月につるの管理、茎葉の収穫を続ける(根の肥大期) |
| 9-10月 | 9月に試し掘りで太さと霜の時期を確認する。10月につるを片づけ、5-7日後に収穫してすぐキュアリング |
| 11-12月 | 11月にキュアリングを終え、冷まし、本貯蔵を始め、切り干しを乾燥させる。12月に貯蔵の点検、傷んだものはすぐ加工 |

> **サツマイモは、9℃を下回らせず、3-4日のキュアリングを省かず、苦みがあれば食べず、種芋を生かして冬を越し、マメ科といっしょに植える作物です。**
