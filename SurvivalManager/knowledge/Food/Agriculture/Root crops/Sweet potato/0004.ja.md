## 7. 水管理

### 7-1. 生育段階別の基準

| 時期 | 水管理 | 理由 |
|---|---|---|
| 挿し付け直後 | たっぷりと。1株当たり100cc以上 | 根のない茎が生き残る唯一の条件です |
| 活着期（2週間） | 乾いたら補給。曇りの日に植えると有利です | 根が出るまで、葉から水分が出続けるからです |
| つる伸長期 | 灌水しません。自然の降水に任せます | 水が十分にあるとつるばかりが伸びます |
| 塊根形成期（30-50日） | やや乾燥気味に | 乾燥ストレスが貯蔵根の形成を促します |
| 塊根肥大期（50-120日） | 干ばつが2週間以上続いたら週1回たっぷりと | この時期の水不足が収量を最も大きく減らします |
| 収穫の3週間前 | 灌水を停止 | 糖度が上がり、貯蔵性がよくなります |

&nbsp;&nbsp;&nbsp;挿し付け直後の水が最も重要です。つる苗は根のない状態で植えるため、葉から蒸発する水分を補う手段がありません。この時期を乗り越えられなければ、そのまま枯れます。水が足りない状況なら、曇りの日か雨が降る直前に植え、植えたあと数日間は日中にわらや草をかぶせて日陰をつくってやるのが有効です。葉を半分ほど切り取って蒸散を減らす方法もあります。

&nbsp;&nbsp;&nbsp;肥大期の干ばつ被害は、数値で確認されています。定植後60日間水分が不足した試験区では、いも1個の平均重量が41.2gから10.6gへと、75%も減少しました。水を運ぶ余力が限られているなら、この時期、韓国ではおおよそ7月から8月に集中すべきです。

### 7-2. 水不足と過多の症状

| 区分 | 症状 | 対応 |
|---|---|---|
| 不足 | 葉が日中に丸まり、新しい葉が小さくなります | 肥大期ならすぐに灌水、ほかの時期ならそのままにします |
| ひどい不足 | つるの先端の生長が止まり、下の葉が黄色くなって落ちます | 灌水して、わらでマルチングします |
| 過多 | つるが茂りすぎ、葉が大きく濃い緑色になります | 排水溝を掘り、つるを持ち上げます |
| 冠水 | 根が黒く変色し、悪臭がします | 回復は不可能です。すぐに水を抜き、掘れるなら掘り取ります |

## 8. 栽培管理

### 8-1. つるの持ち上げ

&nbsp;&nbsp;&nbsp;サツマイモのつるは、地面に触れた節ごとに根を出します。これらの根は太らず細いまま残り、養分と水を吸い上げて、もとの株のいもに行くはずの養分を奪います。結果として、畑全体に小さないもが散らばり、大きないもはできません。

| 作業 | 時期 | 方法 | 効果 |
|---|---|---|---|
| つるの持ち上げ | 韓国では7月から2-3週間おき | つるを軽く持ち上げて節の根を切り、元の位置に戻します | 養分がもとの株に集中します |
| つる返し | 同じ時期 | つるをまるごと反対側へ返します | 持ち上げより効果が大きいが、葉が傷みます |
| 摘心 | つるが茂りすぎたとき | 先端の30cmほどを切り取ります | 切り取った茎はナムルとして食べます |

&nbsp;&nbsp;&nbsp;つるの持ち上げは、曇りの日か夕方に行うのがよいでしょう。日中に行うと葉が裏返って日に焼け、ストレスで生育が数日間止まります。

### 8-2. 草取り

| 項目 | 内容 |
|---|---|
| 重要な時期 | 挿し付け後40日まで、つるが地面を覆う前 |
| 効果 | 雑草の除去に加え、固まった表土を砕いて通気と水の浸透を改善します |
| 収量の差 | 草取りをした畑としていない畑の間に、40-50%の収量差が報告されています |
| その後 | つるが地面を覆ったあとは、雑草が自然に抑えられます |

&nbsp;&nbsp;&nbsp;サツマイモは初期の生育が遅く、雑草に負けやすい作物です。しかし、いったんつるが地面を覆ってしまえば、それ自体が強力な雑草抑制材になります。つまり、最初の40日だけ守ってやれば、残りの期間はほとんど手がかかりません。労働力が不足する災害時には、この特性が重要です。力を最初の1か月に集中し、その後はほかの仕事に充てられます。

### 8-3. マルチング

| 種類 | 効果 | 災害時には |
|---|---|---|
| 黒ビニール | 地温上昇、雑草抑制、保湿 | 最も効果が大きいが、ビニールがなければ使えません |
| わら・干し草 | 保湿、雑草抑制、土壌改良 | ビニールの代替の第一候補。厚さ5cm以上 |
| 落ち葉 | 保湿、有機物 | 風で飛ばないよう土をのせます |
| 刈り草マルチ | 保湿、雑草抑制 | 畑の周りの雑草を刈って、そのまま覆います。種が実る前に |

### 8-4. 葉とつるの収穫

&nbsp;&nbsp;&nbsp;サツマイモの葉柄と若いつるは、優れた野菜です。夏の間ずっと繰り返し摘み取れ、根の収量に大きな影響を与えません。災害時には、これは重要な副収入です。根を掘り取るまで4か月待つあいだに、この畑からすでに食べるものが得られるということだからです。

| 項目 | 基準 |
|---|---|
| 収穫時期 | 挿し付け後60日から霜が降りる前まで |
| 採取量 | 一度に全体の葉の3分の1を超えないようにします |
| 部位 | つるの先端15cm以内の若いつると葉柄 |
| 下処理 | 葉柄の外皮をむくと筋っぽくなりません |
| 調理 | 茹でてナムルにするか、汁物に入れます。生食は避けます |
| 注意 | 摘みすぎると根の肥大が遅れます |

## 9. 病害虫

&nbsp;&nbsp;&nbsp;サツマイモは病害虫の負担が低いほうです。評価で防除自立度がCを得ましたが、その根拠は、防除がほとんど必要なく、必要な場合でも天然素材で足りるということです。ジャガイモと違って、治療薬のない致命的な病害はありません。

### 9-1. 主な病害

| 病名 | 症状 | 発生しやすい条件 | 薬を使わない対応 |
|---|---|---|---|
| 軟腐病 | 根が軟化して悪臭がします | 傷、過湿、貯蔵中の高温 | 傷つけずに収穫、キュアリングの徹底、感染したものはすぐに除去 |
| 黒斑病 | 根の表面に黒い斑点、苦味 | 感染した種いもとつる苗 | 健全な種いもの選別、温湯処理 |
| つる割病 | 茎の株元が裂けて萎れます | 土壌伝染 | 抵抗性品種、健全なつる苗、排水 |
| 炭疽病 | 葉とつるに褐色の病斑 | 韓国の梅雨（チャンマ、6月下旬～7月）の過湿 | 風通しの確保、病葉の除去 |
| うどんこ病 | 葉の表面に白い粉 | 乾燥して日較差が大きいとき | 牛乳の希釈液（1対9）を散布 |
| ウイルス病 | 葉のモザイク、奇形、収量減少 | アブラムシによる媒介、種いもでの伝染 | 健康な株からのみ種いもを選ぶ |

&nbsp;&nbsp;&nbsp;サツマイモで最も注意すべき病気は黒斑病です。感染したサツマイモは苦味が出て、人や家畜に有害な物質をつくります。貯蔵中に黒い斑点ができ、その部分が硬くなって苦味が出ます。この部分は必ずえぐり取らなければならず、斑点が複数の場所に広がっているなら、丸ごと捨てなければなりません。家畜に与えると肺水腫を起こします。

> **サツマイモから苦味がしたら、食べないでください。サツマイモは本来、苦くない作物であり、苦味は病気のサインです。**

### 9-2. 主な害虫

| 害虫 | 被害 | 薬を使わない防除 |
|---|---|---|
| 地虫（コメツキムシの幼虫） | 根に穴をあけ、商品性と貯蔵性を低下させます | 未熟堆肥の使用禁止、ジャガイモ片のトラップ、輪作、収穫後の畑の耕し返し |
| サツマイモに付く蛾の幼虫 | 葉とつるを食害します | 被害葉の除去、残渣の焼却 |
| アブラムシ | 汁を吸い、ウイルスを媒介します | 石けん水の噴霧、テントウムシの保護 |
| ハダニ | 葉の裏が白く変色します | 水を強く吹きかけます。乾燥したときに発生します |
| ネキリムシ（ヤガ類） | 若いつる苗を株元から切ります | 植えたあと株元に灰をまくか、周りに紙を巻きます |
| センチュウ | 根にこぶができ、表面がざらつきます | マリーゴールドの栽培、輪作、抵抗性品種 |
| ノネズミ・イノシシ | 根を掘って食べます | 柵、収穫時期の前倒し |

&nbsp;&nbsp;&nbsp;災害時に、サツマイモにとって実質的に最大の害虫は、虫ではなく野生動物です。イノシシやノネズミは、サツマイモ畑を正確に見つけ出します。人の匂いのするものを畑の周りに置いたり、とげのある枝を巡らせたり、収穫を急いだりするのが現実的な対応です。

### 9-3. 天然の防除資材

| 防除資材 | 調製法 | 用途 |
|---|---|---|
| 石けん水 | 無香料の石けん20gに水1L | アブラムシ、ハダニ |
| 牛乳の希釈液 | 牛乳と水を1対9 | うどんこ病 |
| 草木灰 | ふるいにかけた乾いた灰を、露のついた葉に | 害虫の忌避、カリウムの補給 |
| 木酢液 | 50-100倍に希釈 | 害虫の忌避、殺菌の補助 |
| 温湯処理 | 50-55℃、10-15分 | 種いもとつる苗の消毒 |

### 9-4. 予防の原則

| 原則 | 内容 |
|---|---|
| 健全な種苗 | 病気のない種いもから育てたつる苗だけを使います。成否の半分はここで決まります |
| 排水 | 畝を高くつくります |
| キュアリング | 収穫後に傷を癒合させないと、貯蔵中に病気が広がります |
| 残渣の処理 | 収穫後のつると残った根を畑に放置しません |
| 罹病株の淘汰 | 生育中に症状のある株に印をつけ、種いもに使いません |

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 確認方法 | 天然素材による対処 |
|---|---|---|---|
| 下の葉から黄色くなり、つるが細くなる | 窒素欠乏 | 古い葉から進行 | 完熟堆肥、活着期に限って尿を20倍に希釈 |
| 葉の縁が褐色に焼けて巻く | カリウム欠乏 | 葉先と縁から | 草木灰を畝間に少量、草と果物の皮の堆肥 |
| 生育が遅く、葉が濃い緑色から紫色を帯びる | リン酸欠乏 | 低温期によく見られます | 骨粉、草木灰 |
| 新しい葉の生長点が枯れる | カルシウム欠乏 | 若い葉から進行 | 卵の殻を焼いて砕き、まきます |
| 葉脈の間だけが黄色くなる | マグネシウム欠乏 | 下の葉から | ドロマイト、堆肥の材料の多様化 |
| 新しい葉全体が淡黄色になる | 鉄欠乏 | pHが高いとき | 有機物の補給、草木灰の使用中止 |
| つるばかりが茂り、根が細くて太らない | 窒素過剰 | 葉が大きく濃い緑色で、つるが太い | 窒素の供給を止める、つるの持ち上げ、草木灰でカリウムを補給 |
| 根が細く長いだけ | 窒素過剰または過湿 | 細根が多いです | 排水の改善、水やりをしない |
| 根が割れて奇形になる | 土壌の硬化、水分の不均衡 | 硬い土や石にぶつかった跡 | 深く耕して畝を高くします |

&nbsp;&nbsp;&nbsp;サツマイモで圧倒的に多い問題は、欠乏ではなく窒素過剰です。つるは人の背丈ほどに茂っているのに、掘ってみるといもがない、という状況が典型的です。この症状が見られたら、その年にできることは多くありません。つるをこまめに持ち上げ、先を摘んでナムルとして食べることで損失を減らし、翌年はその場所に肥料を入れないのが答えです。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 対象 | 効果 |
|:---:|---|---|
| 非常に良い | マメ科（ダイズ、ササゲ、インゲンマメ） | 窒素を固定してくれ、サツマイモに足りないタンパク質を人に供給します |
| 良い | トウモロコシ、モロコシ（タカキビ） | 背の高い作物の下でサツマイモが地面を覆い、空間を二重に使えます |
| 良い | マリーゴールド | ネコブセンチュウを抑えます |
| 良い | エゴマ | 匂いで一部の害虫を遠ざけ、油の資源にもなります |
| 普通 | サンチュ（リーフレタス）、ホウレンソウ | サツマイモのつるが覆う前の初期に収穫して抜けます |
| 悪い | ジャガイモ | 地虫とセンチュウを共有し、場所を奪い合います |
| 悪い | トマト、トウガラシ、ナス | センチュウの被害が重なります |
| 悪い | カボチャ | どちらも地面をはうため、場所の奪い合いが激しくなります |

&nbsp;&nbsp;&nbsp;サツマイモとマメ科の組み合わせは、単なる相性以上の意味があります。サツマイモの唯一の致命的な欠点はタンパク質不足であり、マメがそれをぴったり補います。同時に、マメ科の根による窒素固定が、サツマイモに必要な少量の窒素を自然に供給します。畑でも食卓でも、両者は対になっています。

> **サツマイモ畑の隣には、必ず豆畑がなければなりません。これは農法ではなく、栄養設計です。**

### 11-2. 輪作

&nbsp;&nbsp;&nbsp;サツマイモは連作無害群に分類されます。同じ場所に植え続けても大きな問題がないという意味で、いも類（塊茎・塊根）の中では非常に例外的な性質です。ただし、完全に無害というわけではなく、何年も経つとセンチュウやつる割病の密度が上がることがあります。

| 方式 | 適用する状況 | 内容 |
|---|---|---|
| 連作 | 畑が狭く余裕がないとき | サツマイモを同じ場所に固定します。毎年、堆肥を少量補います |
| 2年交代 | 少し余裕があるとき | サツマイモとマメ科を交互に植えます |
| 3年輪作 | 推奨 | サツマイモ → マメ科 → 葉菜類または穀物 |
| センチュウ発生時 | 必須 | マリーゴールドかスーダングラスを1年植えて、すき込みます |

&nbsp;&nbsp;&nbsp;冬に畑を空けておくより、緑肥を植えるほうがよいでしょう。韓国では、サツマイモの収穫後の10月にライムギやヘアリーベッチをまいておくと、冬の間の土壌流出を防ぎ、春にすき込めば有機物と窒素になります。ヘアリーベッチはマメ科なので窒素を固定しますが、サツマイモには窒素が多すぎることがあるため、量を調節するか、ライムギを使うほうが安全です。
