## 3. 栽培环境

### 3-1. 临界值与最适值

| 条件 | 最适值 | 临界值 | 超出后会发生什么 |
|---|---|---|---|
| 生育温度 | 25-30℃ | 15℃以下、35℃以上 | 15℃以下生长停止 |
| 块根膨大温度 | 20-30℃ | 超过30℃ | 只长藤蔓，根不膨大 |
| 最低气温 | 夜间18℃以上 | 10℃以下 | 因低温伤害而停止生长 |
| 霜 | 无法耐受 | 0℃ | 地上部分一夜之间死亡 |
| 地温（扦插时） | 18℃以上 | 低于15℃ | 无法成活，薯苗腐烂 |
| 光照 | 每天6小时以上 | 不足4小时 | 藤蔓徒长，不结块根 |
| 耐遮光性 | 40%遮光时相对产量约80% | | 在荫蔽处也能在一定程度上坚持 |
| 总需水量 | 约400mm | 淹水24小时 | 根会腐烂 |
| 土壤 | 排水良好的砂壤土、沙地 | 黏质土、地下水位高的土地 | 根无法膨大，形状扭曲 |
| 耕作层深度 | 30cm以上 | 不足20cm | 根只向侧面生长，个头变小 |
| 土壤酸度 | pH 5.5-6.5 | pH 4.2-8.3也能生长 | 对酸度的适应范围非常宽 |

&nbsp;&nbsp;&nbsp;土壤酸度的适应范围为pH 4.2-8.3，这是一个令人惊讶的数值。大多数作物只有在pH幅度约1-1.5的范围内才能正常生长，相比之下，甘薯实际上不挑酸度。在无法进行土壤检测、也无法撒施石灰的情况下，这一特性至关重要。无论土质如何，只要种下就能生长。

&nbsp;&nbsp;&nbsp;相反，绝不能妥协的条件是排水和地温。积水的土地上根会腐烂，地温低则根本无法成活。掺有沙子的贫瘠土地，反倒是甘薯的好田。开垦地、河滩沙地、倾斜的砾石地这类其他作物栽培失败的地方，对甘薯来说却是适宜之地。

> **如果还剩下种不了其他作物的贫瘠干旱土地，那里就是甘薯的位置。**

### 3-2. 灾害情境下的选址

| 顺序 | 条件 | 原因 |
|---|---|---|
| 1 | 不积水的地方 | 排水不良是甘薯栽培失败最常见的原因 |
| 2 | 朝南、阳光充足的坡地 | 地温升得快，日照时间长 |
| 3 | 掺有沙子的轻质土 | 根容易膨大，也容易挖 |
| 4 | 能挡风的地方 | 减少台风把藤蔓掀翻的情况 |
| 5 | 肥力低的土地 | 反而有利。肥沃的土地只会长藤蔓 |

## 4. 品种

### 4-1. 按口感分类

| 类别 | 特点 | 代表品种 | 适合用途 |
|---|---|---|---|
| 粉质（Bamgoguma，栗子甘薯） | 淀粉多、水分少，口感干面松软 | Bamgoguma、Sincheonmi、Yulmi | 煮、蒸、磨粉和提取淀粉 |
| 黏质（Hobakgoguma，南瓜甘薯） | 水分和糖分多，湿润柔软 | Hobakgoguma、Daeyumi | 烤、炖煮、熬粥 |
| 高糖（Kkulgoguma，蜜甘薯） | 贮藏后糖度进一步升高 | Beniharuka、Hopungmi | 烤、生食、零食 |

&nbsp;&nbsp;&nbsp;从灾害应对的角度看，粉质类有一些优势。水分少，适合干燥和加工成粉，淀粉出率高，贮藏期间腐烂也较少。相反，黏质类热量密度虽高，但水分多，干燥需要更多的燃料和时间，贮藏期间也更容易变软。

### 4-2. 主要品种比较

| 品种 | 生长期 | 产量 | 耐储性 | 栽培难度 | 口感 | 特点 |
|---|:---:|:---:|:---:|:---:|---|---|
| Bamgoguma（系统） | 100-120天 | 中上 | 上 | 容易 | 粉质 | 生长期短，耐储性好 |
| Hobakgoguma | 120-130天 | 上 | 中 | 容易 | 黏质 | β-胡萝卜素最丰富 |
| Beniharuka | 130-150天 | 上 | 中 | 一般 | 黏质 | 贮藏后糖度大幅升高。适合温暖地区 |
| Hopungmi | 早期栽培型 | 很高 | 上 | 容易 | 粉质 | 早期栽培的增产效果显著 |
| Sodammi | 早期栽培型 | 高 | 上 | 容易 | 粉质 | 与Hopungmi一样适合早期栽培 |
| Daeyumi | 中晚熟 | 高 | 最上 | 容易 | 粉质 | 贮藏期间腐烂率低于1% |
| Gogeonmi | 中晚熟 | 高 | 最上 | 容易 | 粉质 | 耐储性最出色的系统 |
| Sincheonmi | 中晚熟 | 中 | 很低 | 容易 | 粉质 | 贮藏期间腐烂率高，不适合储备 |

### 4-3. 按情形选择的标准

| 情形 | 选择 | 原因 |
|---|---|---|
| 需要越冬 | Daeyumi、Gogeonmi | 贮藏期间腐烂率低于1% |
| 霜期早的地区 | Bamgoguma、Hopungmi、Sodammi | 100-120天即可收获 |
| 补充维生素A | Hobakgoguma | β-胡萝卜素含量最高 |
| 连叶和茎一起吃 | Yeonhwangmi、Yulmi | 叶柄柔嫩，涩味少 |
| 做粉、淀粉储备 | Bamgoguma系统、Daeyumi | 粉质，淀粉出率高 |
| 贮藏设施简陋 | Daeyumi、Gogeonmi | 温度波动也能耐受 |
| 应当避免的 | Sincheonmi | 口味好，但贮藏期间三分之一以上会腐烂 |

&nbsp;&nbsp;&nbsp;耐储性的差别，用实际数字来看十分惊人。在相同条件下贮藏四个月，Daeyumi和Gogeonmi的腐烂率低于1%，而Sincheonmi高达36.7%。贮藏1,000kg时，就是损失10kg还是损失360kg的差别。在灾害情境下，仅品种选择这一项，就能左右冬季三分之一的粮食。

> **选择甘薯品种时，最重要的指标不是产量，也不是口味，而是贮藏期间的腐烂率。**

## 5. 整地与施肥

### 5-1. 整地

| 项目 | 标准 | 原因 |
|---|---|---|
| 耕翻深度 | 25-30cm | 为根向下生长留出空间 |
| 垄高 | 25-35cm | 越高，根越容易膨大，排水也越好 |
| 垄宽 | 60-75cm | 按单行或双行栽植来定 |
| 沟 | 深20cm以上 | 韩国梅雨季（6月下旬至7月）的排水通道 |
| 土壤状态 | 耙碎成松散状 | 土壤板结时根会弯曲 |
| 土壤酸度 | 建议pH 5.5-6.5 | 不必太在意 |

&nbsp;&nbsp;&nbsp;把垄做高，是甘薯栽培中最便宜也最可靠的投入。高垄能改善排水、提高地温，并增厚供根生长的松软土层。试验中反复报告过这样的案例：仅仅把垄高提高到20-35cm，产量就明显增加。

### 5-2. 标准施肥量（以1,000㎡计）

| 肥料 | 施肥量 | 备注 |
|---|---|---|
| 氮 | 尽量少 | 过量是致命的。贫瘠地可以省略 |
| 磷酸 | 10-15kg | 促进根系发育。全部作基肥 |
| 钾 | 15-20kg | 对块根膨大最为重要。全部作基肥 |
| 堆肥 | 1,000-1,500kg | 腐熟堆肥。禁止过量 |

&nbsp;&nbsp;&nbsp;折算成每㎡约为15g上下，不到马铃薯的一半。甘薯的施肥原则可以用一句话概括：氮要最少，钾要充足。

### 5-3. 基肥与追肥

| 类别 | 时期 | 内容 | 注意 |
|---|---|---|---|
| 基肥 | 扦插前2周 | 堆肥、磷酸、钾全部 | 几乎不施氮 |
| 追肥 | 原则上省略 | 效果不明显 | 只有在沙地流失严重时才少量补钾 |

&nbsp;&nbsp;&nbsp;不追肥可能让人感觉陌生，但对甘薯来说这才是正统做法。生育中期施氮，植株就会停止贮藏，重新长起藤蔓。已经开始膨大的根也会停止膨大。在灾害情境中，肥料不足对甘薯种植来说反倒是幸事。

### 5-4. 没有化肥时 - 灾害替代肥料

| 替代资源 | 提供成分 | 制作与使用方法 | 注意 |
|---|---|---|---|
| 草木灰 | 钾、磷酸、钙 | 把过筛的白灰按每10㎡ 1-2L，在做垄前撒施并混匀 | 甘薯对酸度的适应范围宽，所受影响比马铃薯小 |
| 腐熟堆肥 | 综合 | 把落叶和草堆积6个月以上制成。作基肥少量施用 | 过量会使藤蔓徒长 |
| 稀释尿液 | 氮、钾 | 只在扦插后的成活期稀释20倍，少量施用 | 膨大期绝对不能施用 |
| 骨粉 | 磷酸、钙 | 作基肥混入土中 | 分解缓慢 |
| 海藻 | 钾、微量元素 | 用淡水漂洗后覆盖在垄上 | 必须去除盐分 |
| 稻草·落叶 | 有机质、钾 | 铺在沟里，会慢慢分解 | 改善土壤物理性状 |
| 烟草灰·炭粉 | 钾、改良土壤 | 少量混入垄中 | 大量使用会导致碱化 |

> **给甘薯施肥时最常见的错误是施得太多。因为舍不得而少施一些，对甘薯来说反而更接近正解。**

## 6. 扦插与育苗

### 6-1. 为什么不直接种种薯

&nbsp;&nbsp;&nbsp;马铃薯是把种薯切开直接种进田里，而甘薯不这样做。把甘薯整个埋下去，虽然会在原地长出好几个芽，但新根不能正常膨大，只是依附于原来的薯块生长，产量会大幅下降。所以要先在育苗床上让种薯萌芽、培育出藤蔓，再把藤蔓剪下来扦插到田里。这样剪下来的藤蔓称为薯苗，也称秧苗。

&nbsp;&nbsp;&nbsp;这种方式的好处在于繁殖倍数。一个种薯能长出20-30株薯苗。也就是说，只要保住十个种薯，第二年就能得到200-300株薯苗，种满一块地。这正是评价表中自家留种项目获得S的依据。

### 6-2. 搭建育苗床 - 没有塑料薄膜和电的时候

&nbsp;&nbsp;&nbsp;甘薯育苗的关键，是在韩国的3月底到4月把地温提高到25-30℃。没有电热线的话，就利用发酵热。传统的温床方法至今依然适用。

| 步骤 | 内容 |
|---|---|
| 1 | 在向阳的朝南处挖一个深50-60cm、宽1-1.2m的坑 |
| 2 | 把刚排出的马粪或牛粪与稻草、落叶混合，踩实填入坑中，厚30-40cm |
| 3 | 洒水润湿并盖上放置几天，就会开始发酵并发热 |
| 4 | 发酵热升起后，在上面盖10-15cm掺沙的土 |
| 5 | 土温稳定在30度左右时，把种薯平放，再盖3-4cm的土 |
| 6 | 夜里盖上草帘或透明覆盖物，白天打开 |

&nbsp;&nbsp;&nbsp;马粪的发酵热最强，也最持久。没有牲畜的话，用落叶、米糠和尿液混合堆积，也能发热。发酵热温床能在一个月到一个半月内保持20-40℃的温度，这正是甘薯育苗所需要的时长和温度。

| 育苗条件 | 标准 |
|---|---|
| 种薯摆放方向 | 粗的一头（蒂的对侧）稍微朝上平放 |
| 种薯间距 | 互不接触，3-5cm |
| 苗床土温 | 初期30-32℃，出芽后25℃ |
| 时间 | 30-40天即可剪取薯苗 |
| 水分 | 只保持不干即可。过湿会腐烂 |

### 6-3. 挑选薯苗

| 项目 | 标准 | 原因 |
|---|---|---|
| 长度 | 20-30cm | 太短则节数不足 |
| 节数 | 5-7个 | 每个埋入土中的节上都会结薯 |
| 粗细 | 铅笔粗细以上 | 太细的成活不好 |
| 部位 | 藤蔓末端（有生长点的部分） | 活力最好 |
| 剪取方法 | 不连根拔起，在离地面2-3cm处剪断 | 剩下的基部会再长出新苗，可以进行第2次、第3次采集 |
| 剪后 | 放在阴凉处一天，让切口愈合 | 成活率会提高 |

### 6-4. 扦插时期

| 地区 | 时期 | 标准 |
|---|---|---|
| 韩国南部 | 4月下旬-5月中旬 | |
| 韩国中部 | 5月中旬-6月上旬 | |
| 共同标准 | 地温18℃以上、最低气温稳定在15℃以上时 | 以温度为准，而不是以时间为准 |
| 截止 | 避免6月下旬以后 | 生长期不足，只能长出小薯 |

### 6-5. 扦插方法 - 平放扦插

| 项目 | 标准 | 原因 |
|---|---|---|
| 方向 | 平放，尽量接近水平 | 直立扦插只有一个点生根 |
| 埋入节数 | 3-4节 | 每个节上都会结薯 |
| 深度 | 3-5cm | 太深则地温低，成活延迟 |
| 留出部分 | 让顶端的2-3片叶露出地面 | 通过光合作用帮助成活 |
| 株距 | 25-30cm | |
| 垄距 | 70-90cm | |
| 扦插后 | 每株立即浇水100cc以上 | 成活与否在此一举 |

&nbsp;&nbsp;&nbsp;平放扦插有几种变形。水平笔直平放的水平扦插，结薯个数多、大小均匀的同时，结薯不深，容易挖。弯成镰刀形扦插的改良水平扦插，成活稍快。斜着插的斜插耐旱，但结薯个数减少、大小不均。无法经常浇水时，斜插更好；能保证水源时，水平扦插更好。

> **直立扦插的甘薯田与平放扦插的甘薯田，产量相差可达两倍。仅扦插姿势这一项，就决定一年的收成。**

### 6-6. 薯苗消毒

| 方法 | 步骤 | 效果 |
|---|---|---|
| 温汤处理 | 浸入50-55℃的水中10-15分钟 | 杀死表面病原菌 |
| 草木灰处理 | 在切口上蘸干灰 | 防止切口腐烂 |
| 木醋液浸泡 | 100倍稀释液浸泡10分钟 | 辅助杀菌 |
| 挑选健康个体 | 剔除有斑点或枯萎的苗 | 效果最好的方法 |
