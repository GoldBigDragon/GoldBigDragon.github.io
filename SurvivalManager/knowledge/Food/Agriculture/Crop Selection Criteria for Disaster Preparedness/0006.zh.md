## 8. 自立性·附加价值·适口性
### 8-1. 自家留种 `[E2]`

| 等级 | 标准 |
|:--:|:---|
| SS | 通过无性繁殖使遗传上相同的个体无限增殖 |
| S | 自交·纯系维持型 |
| A | 异交，需注意杂交 |
| B | F1杂种 - 性状分离及产量下降 |
| C | F1杂种 - 急剧畸变及存活率下降 |
| D | 留种难度高（二年生·低温春化·长距离隔离） |
| E | 不能发芽·繁殖（三倍体·无种子·终止子技术） |

&nbsp;&nbsp;&nbsp;**种子留存率校正**：在灾害情况下，“需要从收获量中留出百分之几作为次年播种的种子”才是实际的制约。

| 作物 | 种子:收获比例 | 相对于收获量的种子留存率 |
|:---|:---|---:|
| 籽粒苋 | 1,000~1,500 : 1 | 0.07~0.1% |
| 玉米 | 约500 : 1 | 0.2% |
| 小麦 | 约30 : 1 | 3.3% |
| **马铃薯** | **4.2~8.5 : 1** | **12~24%** |

> **种子需求量占收获量的比例超过10%时，下调1个等级。**  
> 马铃薯需要将收获量的1/8~1/4留作种薯，这相当于谷物的30~100倍。以营养体繁殖的10种作物（马铃薯·大蒜·生姜·甘薯·芋头·山药·菊芋·美洲土圞儿·莲藕·草石蚕）均属于此类。

### 8-5. 口味 `[E3]`
&nbsp;&nbsp;&nbsp;即使热量和营养充足，**难以下咽的食物也无法长期摄取**，进食的满足感与维持生存意志·活力直接相关。

| 气味·香气 | 口感 | 甜味 | 等级 | 定义 |
|:--:|:--:|:--:|:--:|:---|
| ○ | ○ | ○ | **SS** | 没有令人排斥的气味/香气/口感，且带有普遍性的甜味 |
| ○ | ○ | × | **S** | 没有令人排斥的气味/香气/口感的日常食品 |
| ○ | × | ○ | **A** | 没有令人排斥的气味或香气的普遍性甜味 |
| ○ | × | × | **B** | 没有令人排斥的气味或香气的日常食品 |
| × | ○ | ○ | **C** | 没有令人排斥口感的甜味 |
| × | ○ | × | **D** | 没有令人排斥口感的日常食品 |
| × | × | - | **E** | 令人排斥的食品 |

```
甜味加分 = (成分表糖类实测值 ≥ 8.0 g/100g，以食用状态为准)
```

&nbsp;&nbsp;&nbsp;**使用糖类实测值的原因**：Brix是折光率，因此也会把糖以外的物质一并读入。菊芋和雪莲果的Brix偏高是因为菊粉·果聚糖，人无法将其感知为甜味，也不会在小肠中被吸收。成分表中的“糖类”只测定游离糖，因此**更接近舌头实际感受到的甜味。**

| 作物 | 糖类 g/100g | 加分 |
|:---|---:|:--:|
| 大枣（生） | 24.34 | ○ |
| 葡萄（巨峰） | 14.33 | ○ |
| 苹果 | 10.62 | ○ |
| 甘薯 | 9.83 | ○ |
| **香瓜** | **8.82** | ○ |
| **山莓** | **7.80** | **×** |
| **西瓜** | **7.12** | **×** |
| **菊芋** | **6.37** | **×** |
| **草莓** | **6.14** | **×** |
| **玉米（普通型）** | **1.94** | **×** |
| **牛油果** | **0.66** | **×** |
| **雪莲果** | **0.50** | **×** |

&nbsp;&nbsp;&nbsp;不直接给出等级，而是将三项属性保留为数据，原因是**判定依据可以被追溯**。不是简单地记为“艾草 = D”，而是记为“气味有排斥感/口感尚可/糖类2.0g → D”，这样在有异议时可以指出是哪项属性出了问题。

## 9. 综合得分计算
### 9-1. 总公式

```
情景得分 = Σ(等级得分 × 实效权重) ÷ Σ(实效权重)
实效权重 = 设计目标权重 × 依据衰减系数c(E)

综合得分 = √(短期得分 × 长期得分) × K(热量) × 确证系数
 但，触发排除关卡时为0
副食因作用不同，不进行合算，单独解读
```

---

|:---|--:|--:|--:|

### 9-3. 生产力系数K - 以乘法形式引入
&nbsp;&nbsp;&nbsp;在灾害应对中，产量不是可由其他项目替代的加分要素，而是**前提条件**，因此以乘法形式反映。

| 热量等级 | 自给倍数 | K |
|:---:|:---|---:|
| SS | ≥1.50 | **1.00** |
| S | ≥1.00 | **1.00** |
| A | ≥0.70 | 0.93 |
| B | ≥0.50 | 0.87 |
| C | ≥0.30 | 0.79 |
| D | ≥0.15 | 0.70 |
| E | <0.15 | **0（排除）** |

> **去掉K后，热量等级与综合得分的相关性会从+0.662骤降至+0.080。**  
> 若没有这个系数，热量为D的野生野菜会在低投入项目上横扫SS，从而超过谷物。这是因为**25个项目中有9个项目的结构是“需求越少、得分越高”**。

---
### 9-4. 确证系数 - 减少依据空白

```
确证系数 = 1 - 0.35 × (下层插补单元数 ÷ 25)
```

| 插补单元 | 确证系数 | 衰减 |
|---:|---:|---:|
| 0 | 1.000 | 0% |
| 3 | 0.958 | 4.2% |
| 7 | 0.902 | 9.8% |
| 14 | 0.804 | 19.6% |
| 25 | 0.650 | 35% |

&nbsp;&nbsp;&nbsp;**该系数不是扣分项，而是改善数据的激励机制。**补齐依据后就会回到1.00。评价标准的目标不是压低作物的分数，而是促使人们补齐依据。

---
### 9-5. 排除关卡
&nbsp;&nbsp;&nbsp;仅靠加权合计无法体现**“单个项目上的致命缺陷”**。

| 关卡 | 条件 | 豁免 | 依据 |
|:---|:---|:---|:---|
| 热量 | 单位面积热量E（低于自给线15%） | - | 无法成立为粮食作物 |
| 留种 | 自家留种E | - | 无法再生产 |
| 贮藏 | 耐储性E | 持续性A以上 | 无法储备。但可在田间随时采收的多年生作物豁免 |
| 病虫害 | 病虫害压力E（无防治减产率超过80%） | - | 无法栽培 |

> **排除与等级E不同。**  
> 被排除的作物也会同时记录25个项目的评价，以及“若无该关卡本应得多少分”。排除并不意味着得分低，而是意味着某个项目存在致命缺陷，因此**该项目一旦改善，就会立即被纳入有效集合。**

### 9-6. 最终等级换算 - 固定百分位
&nbsp;&nbsp;&nbsp;若固定临界分数，每增加一种作物基准就会波动。**因此不以分数、而以百分位来定义。**

| 等级 | 百分位（排除后的有效样本） | 当前对应分数（183种） |
|:--:|:---|---:|
| SS | 前2% | 57.6↑ |
| S | 前7% | 50.5↑ |
| A | 前18% | 48.2↑ |
| B | 前35% | 44.3↑ |
| C | 前60% | 40.6↑ |
| D | 前85% | 36.0↑ |
| E | 低于此 | - |

**热量下限区间规则**

```
综合SS·S等级只授予单位面积热量达到C级(自给线30%)以上的作物
未达标时降2个等级，并必须同时标注副食等级
```

&nbsp;&nbsp;&nbsp;仅靠百分位，副食专用作物（蒲公英·艾草·苦荬菜等）会跻身综合前列区间。这些作物作为副食可明确评为SS，但并非主食候选。通过这一规则，**作物的角色得以分开标注。**
