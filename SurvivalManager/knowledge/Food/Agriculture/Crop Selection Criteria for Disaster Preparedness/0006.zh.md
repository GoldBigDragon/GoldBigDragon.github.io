## 8. 自立性·附加价值·嗜好性
### 8-1. 自留种 `[E2]`

| 等级 | 标准 |
|:--:|:---|
| SS | 通过无性繁殖可无限增殖遗传上相同的个体 |
| S | 自花授粉、纯系维持型 |
| A | 异花授粉，需注意杂交 |
| B | F1杂种 - 性状分离且产量下降 |
| C | F1杂种 - 急剧畸形且存活率下降 |
| D | 留种难度高（二年生、低温春化、需远距离隔离） |
| E | 无法发芽、繁殖（三倍体、无籽、终结者） |

&nbsp;&nbsp;&nbsp;**种子留存率校正**：在灾害中，真正的约束是必须把收获量的百分之几留作来年播种的种子。

| 作物 | 种子:收获比 | 种子占收获量的留存率 |
|:---|:---|---:|
| 苋 | 1,000-1,500 : 1 | 0.07-0.1% |
| 玉米 | 约500 : 1 | 0.2% |
| 小麦 | 约30 : 1 | 3.3% |
| **马铃薯** | **4.2-8.5 : 1** | **12-24%** |

> **种子需求量超过收获量的10%时，下调1个等级。**
> 马铃薯必须把收获量的1/8-1/4留作种薯，这是谷物的30-100倍。以营养体繁殖的10种作物（马铃薯、大蒜、生姜、甘薯、芋头、山药、菊芋、美洲土圞儿、莲藕、草石蚕）属于此类。

### 8-2. 种子寿命（常温密封保存，发芽率保持50%的期间，以年计） `[E2]`

| SS | S | A | B | C | D | E |
|:--:|:--:|:--:|:--:|:--:|:--:|:--:|
| 5以上 | 3以上 | 2以上 | 1.5以上 | 1以上 | 0.5以上 | 种子无法保存 |

| 标准保存寿命 | 作物 |
|:--:|:---|
| 1年 | 洋葱、韭葱 |
| 2年 | 玉米、辣椒、秋葵、菠菜 |
| 3年 | 菜豆、豌豆、胡萝卜、西兰花、芝麻菜 |
| 4年 | 甜菜、白菜、羽衣甘蓝、球茎甘蓝、番茄、南瓜、芥菜 |
| 5年 | 洋蓟、芹菜、黄瓜、生菜、甜瓜、萝卜、芜菁 |

&nbsp;&nbsp;&nbsp;上表以低于10℃、湿度低于40%为前提。本尺度以无电力常温（15-25℃）为前提，所以按保守方式折算。

```
常温寿命 ≒ 标准保存寿命 × 0.4
```

&nbsp;&nbsp;&nbsp;自留种为SS的无性繁殖作物，这个项目常常是E，因此必须把两个项目互补地来看。

|:--:|:--:|:--:|:--:|:--:|:--:|:--:|

### 8-4. 非食用价值（满足的数量） `[E3]`

- 药材
- 木材/纸浆
- 树液

- 向土壤供给养分
- 防治害虫
- 土壤净化

|:--:|:--:|:--:|:--:|:--:|:--:|:--:|

&nbsp;&nbsp;&nbsp;在灾害中，食物价值优先，所以权重保持较低，非食用作物得到较低的等级是正常的。

> **这个项目最容易受到依据空白的影响。**
> 依据薄弱的作物，平均比依据齐全的作物高13.1分（25个项目中最大）。因为“听说可以当药材”这样的话也会被直接计入。每一项都要求提供1条出处，没有则不计数。

### 8-5. 口味 `[E3]`
&nbsp;&nbsp;&nbsp;即使热量和营养充足，难以下咽的食物也无法长期食用，而用餐的满足感与维持生活意志和活力直接相关。

| 气味·香气 | 口感 | 甜味 | 等级 | 定义 |
|:--:|:--:|:--:|:--:|:---|
| ○ | ○ | ○ | **SS** | 没有令人排斥的气味、香气、口感，且有普遍的甜味 |
| ○ | ○ | × | **S** | 没有令人排斥的气味、香气、口感的日常食品 |
| ○ | × | ○ | **A** | 没有令人排斥的气味或香气，且有普遍的甜味 |
| ○ | × | × | **B** | 没有令人排斥的气味或香气的日常食品 |
| × | ○ | ○ | **C** | 没有令人排斥的口感的甜味食物 |
| × | ○ | × | **D** | 没有令人排斥的口感的日常食品 |
| × | × | - | **E** | 被回避的食物 |

```
甜味加分 = （成分表糖类实测值 ≥ 8.0g/100g，按食用状态计）
```

&nbsp;&nbsp;&nbsp;使用糖类实测值，是因为Brix是折光率，连不是糖的东西也一并读了出来。菊芋和菊薯的Brix高是因为菊粉和果聚糖，人感觉不到它们的甜味，在小肠里也不被吸收。成分表中的“糖类”只测游离糖，所以更接近舌头所感受到的。

| 作物 | 糖类 g/100g | 加分 |
|:---|---:|:--:|
| 红枣（鲜） | 24.34 | ○ |
| 葡萄（巨峰） | 14.33 | ○ |
| 苹果 | 10.62 | ○ |
| 甘薯 | 9.83 | ○ |
| **甜瓜** | **8.82** | ○ |
| **山莓** | **7.80** | **×** |
| **西瓜** | **7.12** | **×** |
| **菊芋** | **6.37** | **×** |
| **草莓** | **6.14** | **×** |
| **玉米（非糯性）** | **1.94** | **×** |
| **牛油果** | **0.66** | **×** |
| **菊薯** | **0.50** | **×** |

&nbsp;&nbsp;&nbsp;不直接给出等级，而是把三个属性作为数据保留，是为了能追溯判定的依据。若记成“艾草 = D”，不如记成“香气令人排斥 / 口感尚可 / 糖类2.0g → D”，这样有异议时就能指出是哪个属性的问题。

## 9. 综合得分的计算
### 9-1. 完整公式

```
情景得分 = Σ（等级分 × 有效权重） ÷ Σ（有效权重）
有效权重 = 设计目标权重 × 依据衰减系数 c(E)

综合得分 = √（短期得分 × 长期得分） × K（热量） × 确证系数
 但若触发排除关卡则为0
副食的作用不同，不合并计算，而是单独阅读
```

---

### 9-3. 生产力系数K - 以乘法方式进入
&nbsp;&nbsp;&nbsp;在灾害应对中，产量不是其他项目可以替代的加分因素，而是**前提条件**，所以用乘法来体现。

| 热量等级 | 自给倍数 | K |
|:---:|:---|---:|
| SS | ≥1.50 | **1.00** |
| S | ≥1.00 | **1.00** |
| A | ≥0.70 | 0.93 |
| B | ≥0.50 | 0.87 |
| C | ≥0.30 | 0.79 |
| D | ≥0.15 | 0.70 |
| E | <0.15 | **0（排除）** |

> **去掉K，热量等级与综合得分的相关性会从+0.662崩塌到+0.080。**
> 25个项目中有9个是“需求越少得分越高”的结构，没有K的话，热量为D的野菜会在低投入项目上拿下大量SS，从而超过谷物。

---
### 9-4. 确证系数 - 减少依据空白

```
确证系数 = 1 - 0.35 × （由下层代入的单元格数 ÷ 25）
```

| 代入单元格 | 确证系数 | 衰减 |
|---:|---:|---:|
| 0 | 1.000 | 0% |
| 3 | 0.958 | 4.2% |
| 7 | 0.902 | 9.8% |
| 14 | 0.804 | 19.6% |
| 25 | 0.650 | 35% |

&nbsp;&nbsp;&nbsp;这个系数不是惩罚，而是改进数据的激励。补充依据后会回到1.00。

---
### 9-5. 排除关卡
&nbsp;&nbsp;&nbsp;仅靠加权和无法表达某一项的致命不合格，所以设置关卡。

| 关卡 | 条件 | 豁免 | 依据 |
|:---|:---|:---|:---|
| 热量 | 单位面积热量为E（低于自给线的15%） | - | 不能成立为粮食作物 |
| 留种 | 自留种为E | - | 无法再生产 |
| 储存 | 耐储性为E | 持续性A以上 | 无法储备。但在田间随时收获的多年生作物豁免 |
| 病虫害 | 病虫害压力为E（无防治减产率超过80%） | - | 无法栽培 |

> **排除与等级E不同。**
> 被排除的作物也要同时记录25个项目的评价，以及没有关卡时的得分。排除不是指得分低，而是某一项的致命不合格，所以只要该项得到改善，就会立即进入有效集合。

---
### 9-6. 换算为最终等级 - 固定为百分位
&nbsp;&nbsp;&nbsp;如果固定阈值分数，每增加一种作物标准就会动摇，所以用百分位而不是分数来定义。

| 等级 | 百分位（剔除排除项的有效样本） | 目前对应的分数（183种） |
|:--:|:---|---:|
| SS | 前2% | 57.6以上 |
| S | 前7% | 50.5以上 |
| A | 前18% | 48.2以上 |
| B | 前35% | 44.3以上 |
| C | 前60% | 40.6以上 |
| D | 前85% | 36.0以上 |
| E | 低于此 | - |

**热量下限带规则**

```
综合SS、S等级只授予单位面积热量为C（自给线的30%）以上的作物。
未达标时降2级，并且必须同时标注副食等级。
```

&nbsp;&nbsp;&nbsp;只用百分位的话，仅作副食的作物（蒲公英、艾草、苦荬菜等）会升到综合的上位带。它们作为副食SS价值明确，但并不是主食候选，所以用这条规则把角色分开标注。
