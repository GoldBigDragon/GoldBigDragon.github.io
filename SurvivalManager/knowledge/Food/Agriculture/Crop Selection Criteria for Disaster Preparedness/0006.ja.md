## 8. 自立性・付加価値・嗜好性
### 8-1. 自家採種 `[E2]`

| 等級 | 基準 |
|:--:|:---|
| SS | 栄養繁殖で遺伝的に同一の個体を無限に増やせる |
| S | 自殖・純系維持型 |
| A | 他殖、交雑への注意が必要 |
| B | F1雑種 - 形質の分離と収量の減少 |
| C | F1雑種 - 急激な奇形と生存率の低下 |
| D | 採種の難度が高い(二年生・低温春化・遠距離の隔離) |
| E | 発芽・生殖が不可能(三倍体・無種子・ターミネーター) |

&nbsp;&nbsp;&nbsp;**種子の留保率による補正**: 災害時には、翌年に植える種子を収量の何%取り分けなければならないかが、実質的な制約です。

| 作物 | 種子:収穫の比 | 収穫に対する種子の留保率 |
|:---|:---|---:|
| アマランサス | 1,000-1,500 : 1 | 0.07-0.1% |
| トウモロコシ | 約500 : 1 | 0.2% |
| コムギ | 約30 : 1 | 3.3% |
| **ジャガイモ** | **4.2-8.5 : 1** | **12-24%** |

> **収量に対する種子の所要が10%を超えたら、1等級下げます。**
> ジャガイモは収量の1/8-1/4を種イモとして残さなければならず、これは穀物の30-100倍です。栄養体で繁殖する作物10種(ジャガイモ・ニンニク・ショウガ・サツマイモ・サトイモ・ナガイモ・キクイモ・アピオス・レンコン・チョロギ)が該当します。

&nbsp;&nbsp;&nbsp;上の表は、10℃未満、湿度40%未満を前提にした値です。この尺度は無電力の常温(15-25℃)を前提にするため、保守的に換算します。

### 8-5. 味 `[E3]`
&nbsp;&nbsp;&nbsp;熱量と栄養が十分でも、食べにくい食品は長期の摂取ができず、食事の満足感は生きる意欲や活力の維持に直結します。

| 匂い・香り | 食感 | 甘味 | 等級 | 定義 |
|:--:|:--:|:--:|:--:|:---|
| ○ | ○ | ○ | **SS** | 抵抗を感じる匂い・香り・食感がなく、一般的な甘味がある |
| ○ | ○ | × | **S** | 抵抗を感じる匂い・香り・食感がない日常の食品 |
| ○ | × | ○ | **A** | 抵抗を感じる匂いや香りがなく、一般的な甘味がある |
| ○ | × | × | **B** | 抵抗を感じる匂いや香りがない日常の食品 |
| × | ○ | ○ | **C** | 抵抗を感じる食感がなく、甘味がある |
| × | ○ | × | **D** | 抵抗を感じる食感がない日常の食品 |
| × | × | - | **E** | 忌避される食品 |

```
甘味の加点 = (成分表の糖類の実測値 ≥ 8.0g/100g、摂取する状態の基準)
```

&nbsp;&nbsp;&nbsp;糖類の実測値を使うのは、Brixが屈折率であり、糖でないものも一緒に読んでしまうからです。キクイモとヤーコンのBrixが高いのはイヌリンやフルクタンのためで、人はこれを甘味として感じず、小腸で吸収もされません。成分表の糖類は遊離糖だけを測るので、舌が感じるものにより近いです。

| 作物 | 糖類 g/100g | 加点 |
|:---|---:|:--:|
| ナツメ(生) | 24.34 | ○ |
| ブドウ(巨峰) | 14.33 | ○ |
| リンゴ | 10.62 | ○ |
| サツマイモ | 9.83 | ○ |
| **マクワウリ** | **8.82** | ○ |
| **クマイチゴ** | **7.80** | **×** |
| **スイカ** | **7.12** | **×** |
| **キクイモ** | **6.37** | **×** |
| **イチゴ** | **6.14** | **×** |
| **トウモロコシ(うるち種)** | **1.94** | **×** |
| **アボカド** | **0.66** | **×** |
| **ヤーコン** | **0.50** | **×** |

&nbsp;&nbsp;&nbsp;等級を直接付けず、三つの属性をデータとして残すのは、判定の根拠をたどれるようにするためです。「ヨモギ = D」ではなく、「香りに抵抗あり / 食感は無難 / 糖類2.0g → D」と残せば、異論があるとき、どの属性が問題なのかを指摘できます。

## 9. 総合スコアの計算
### 9-1. 全体の式

```
シナリオのスコア = Σ(等級のスコア × 実効の重み) ÷ Σ(実効の重み)
実効の重み = 設計目標の重み × 根拠の減衰係数 c(E)

総合スコア = √(短期のスコア × 長期のスコア) × K(熱量) × 確証係数
 ただし、排除ゲートにかかれば0
副食は役割が異なるため、合算せずに別に読む
```

---

### 9-3. 生産性係数K - 掛け算で入ります
&nbsp;&nbsp;&nbsp;災害への備えにおいて、生産量は他の項目で代替できる加算要素ではなく**前提条件**なので、掛け算で反映します。

| 熱量の等級 | 自給倍率 | K |
|:---:|:---|---:|
| SS | ≥1.50 | **1.00** |
| S | ≥1.00 | **1.00** |
| A | ≥0.70 | 0.93 |
| B | ≥0.50 | 0.87 |
| C | ≥0.30 | 0.79 |
| D | ≥0.15 | 0.70 |
| E | <0.15 | **0(排除)** |

> **Kを外すと、熱量の等級と総合スコアの相関が+0.662から+0.080へ崩れます。**
> 25項目のうち9項目が「必要が少ないほど高得点」という構造なので、Kがないと、熱量がDの野生の山菜が低投入の項目でSSを総なめにして、穀物を上回ってしまいます。

### 9-4. 確証係数 - 根拠の空白を減らします

```
確証係数 = 1 - 0.35 × (下位層からの代入セル数 ÷ 25)
```

| 代入セル | 確証係数 | 減衰 |
|---:|---:|---:|
| 0 | 1.000 | 0% |
| 3 | 0.958 | 4.2% |
| 7 | 0.902 | 9.8% |
| 14 | 0.804 | 19.6% |
| 25 | 0.650 | 35% |

&nbsp;&nbsp;&nbsp;この係数は罰則ではなく、データを改善するためのインセンティブです。根拠を補えば1.00に戻ります。

---
### 9-5. 排除ゲート
&nbsp;&nbsp;&nbsp;加重和だけでは、一つの項目での致命的な失格を表現できないので、ゲートを置きます。

| ゲート | 条件 | 免除 | 根拠 |
|:---|:---|:---|:---|
| 熱量 | 面積当たりの熱量がE(自給ラインの15%未満) | - | 食料作物として成り立たない |
| 採種 | 自家採種がE | - | 再生産が不可能 |
| 貯蔵 | 貯蔵性がE | 永続性A以上 | 備蓄が不可能。ただし、畑で随時収穫する多年生は免除 |
| 病害虫 | 病害虫圧がE(無防除の減収率が80%超) | - | 栽培が不可能 |

> **排除と等級Eは異なります。**
> 排除された作物も、25項目の評価と、ゲートがなかった場合のスコアを併せて記録します。排除はスコアが低いという意味ではなく、一つの項目での致命的な失格なので、その項目が改善されれば、直ちに有効な集合に入ります。

---
### 9-6. 最終等級への換算 - パーセンタイルで固定
&nbsp;&nbsp;&nbsp;しきい値のスコアを固定すると、作物が追加されるたびに基準が揺らぐので、スコアではなくパーセンタイルで定義します。

| 等級 | パーセンタイル(排除を除く有効な標本) | 現在の対応スコア(183種) |
|:--:|:---|---:|
| SS | 上位2% | 57.6以上 |
| S | 上位7% | 50.5以上 |
| A | 上位18% | 48.2以上 |
| B | 上位35% | 44.3以上 |
| C | 上位60% | 40.6以上 |
| D | 上位85% | 36.0以上 |
| E | それ未満 | - |

**熱量の下限バンド規則**

```
総合SS・S等級は、面積当たりの熱量がC(自給ラインの30%)以上の作物にのみ付与します。
満たさない場合は2等級降格し、副食の等級を必ず併記します。
```

&nbsp;&nbsp;&nbsp;パーセンタイルだけを使うと、副食専用の作物(タンポポ・ヨモギ・ニガナなど)が総合の上位バンドに上がります。これらは副食SSとして価値は明らかですが、主食の候補ではないので、この規則で役割を分けて表記します。
