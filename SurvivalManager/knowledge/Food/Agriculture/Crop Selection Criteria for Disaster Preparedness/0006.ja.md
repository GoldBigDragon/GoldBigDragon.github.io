## 8. 自立性・付加価値・嗜好性
### 8-1. 自家採種 `[E2]`

| 等級 | 基準 |
|:--:|:---|
| SS | 無性繁殖により遺伝的に同一な個体を無限に増殖できる |
| S | 自家受精・純系維持型 |
| A | 他家受精、交雑に注意が必要 |
| B | F1雑種 - 形質分離および収量減少 |
| C | F1雑種 - 急激な奇形および生存率低下 |
| D | 採種の難易度が高い（二年生・低温春化・長距離隔離） |
| E | 発芽・生殖不可（三倍体・無種子・ターミネーター技術） |

&nbsp;&nbsp;&nbsp;**種子留保率の補正**：災害時には「翌年に播く種子として収穫量の何%を取り分けなければならないか」が実質的な制約になります。

| 作物 | 種子:収穫比率 | 収穫量に対する種子留保率 |
|:---|:---|---:|
| アマランサス | 1,000~1,500 : 1 | 0.07~0.1% |
| トウモロコシ | 約500 : 1 | 0.2% |
| コムギ | 約30 : 1 | 3.3% |
| **ジャガイモ** | **4.2~8.5 : 1** | **12~24%** |

> **収穫量に対する種子必要量が10%を超えると、1等級下げます。**  
> ジャガイモは収穫量の1/8~1/4を種いもとして残す必要があり、これは穀物の30~100倍に当たります。栄養体で繁殖する作物10種（ジャガイモ・ニンニク・ショウガ・サツマイモ・サトイモ・ナガイモ・キクイモ・アピオス・レンコン・チョロギ）がこれに該当します。

&nbsp;&nbsp;&nbsp;災害時には食料としての価値が優先されるため重み付けを低く保っており、**非食用作物が低い等級になるのは正常です。**

### 8-5. 味 `[E3]`
&nbsp;&nbsp;&nbsp;熱量と栄養が十分でも、**食べにくい食品は長期摂取が不可能**であり、食事の満足感は生きる意志・活力の維持に直結します。

| 臭い・香り | 食感 | 甘み | 等級 | 定義 |
|:--:|:--:|:--:|:--:|:---|
| ○ | ○ | ○ | **SS** | 拒否感のある臭い/香り/食感がなく、普遍的な甘みがある |
| ○ | ○ | × | **S** | 拒否感のある臭い/香り/食感がない日常食品 |
| ○ | × | ○ | **A** | 拒否感のある臭いや香りがない普遍的な甘み |
| ○ | × | × | **B** | 拒否感のある臭いや香りがない日常食品 |
| × | ○ | ○ | **C** | 拒否感のある食感がない甘み |
| × | ○ | × | **D** | 拒否感のある食感がない日常食品 |
| × | × | - | **E** | 忌避食品 |

```
甘み加算 = (成分表の糖類実測値 ≥ 8.0 g/100g、摂取状態基準)
```

&nbsp;&nbsp;&nbsp;**糖類実測値を使う理由**：Brixは屈折率であるため、糖以外のものも一緒に読み取ってしまいます。キクイモとヤーコンのBrixが高いのはイヌリン・フルクタンのためであり、人はこれを甘みとして感じず、小腸で吸収されることもありません。成分表の「糖類」は遊離糖のみを測定するため、**舌が感じるものに近いのです。**

| 作物 | 糖類 g/100g | 加算 |
|:---|---:|:--:|
| ナツメ（生） | 24.34 | ○ |
| ブドウ（巨峰） | 14.33 | ○ |
| リンゴ | 10.62 | ○ |
| サツマイモ | 9.83 | ○ |
| **マクワウリ** | **8.82** | ○ |
| **キイチゴ** | **7.80** | **×** |
| **スイカ** | **7.12** | **×** |
| **キクイモ** | **6.37** | **×** |
| **イチゴ** | **6.14** | **×** |
| **トウモロコシ（うるち種）** | **1.94** | **×** |
| **アボカド** | **0.66** | **×** |
| **ヤーコン** | **0.50** | **×** |

&nbsp;&nbsp;&nbsp;等級を直接付与せず三つの属性をデータとして残す理由は、**判定根拠を追跡できるから**です。「ヨモギ = D」ではなく「香りに拒否感 / 食感は問題なし / 糖類2.0g → D」として残すことで、異論がある場合にどの属性が問題かを指摘できます。

## 9. 総合点数の計算
### 9-1. 全体式

```
シナリオ点数 = Σ(等級点数 × 実効重み) ÷ Σ(実効重み)
実効重み = 設計目標重み × 根拠減衰係数c(E)

総合点数 = √(短期点数 × 長期点数) × K(熱量) × 確証係数
 ただし、除外ゲートに該当すると0
副食は役割が異なるため合算せず、別途読み取る
```

---
### 9-2. シナリオ別の重み
&nbsp;&nbsp;&nbsp;シナリオ間の違いは**項目の時間的性格のみ**によって決まります。

| 項目 | 短期（0~1年） | 長期（1年以上） | 副食 |
|:---|--:|--:|--:|
| 面積当たり熱量 | **3.50** | 3.00 | 0.50 |
| 無投入収量維持率 | 1.00 | **3.50** | 1.50 |
| 施肥 | 1.75 | **3.00** | 1.75 |
| 連作適応性 | 1.00 | **3.00** | 1.50 |
| 自家採種 | 1.25 | **3.00** | 2.00 |
| 病害虫圧 | **2.50** | 2.50 | 1.50 |
| タンパク質密度 | 1.50 | 2.00 | 2.00 |
| 貯蔵性 | 1.25 | 2.00 | 0.75 |
| 収量安定性 | **2.00** | 1.75 | 0.75 |
| 微量栄養素 | 1.25 | 1.25 | **3.50** |
| 日照 | 1.25 | 1.75 | 1.00 |
| 水消費量 | 1.50 | 1.50 | 1.25 |
| 収穫速度 | **2.00** | 0.75 | 1.50 |
| 永続性 | 0.75 | 1.50 | 1.50 |

| 非食用価値 | 0.50 | 0.75 | 1.00 |

&nbsp;&nbsp;&nbsp;**重み設計**：作物選定に関する文献では、基準となる重みは例外なく専門家アンケートによって算出されており、実証的な成果データで検証された重みは存在しません。根拠のない重みを取り除くと残る選択肢は等重みですが、**等重みもまた「熱量が種子寿命と同等である」という一つの仮定**です。したがって、時間軸によって順序が明確な項目にのみ倍率を設けます。

---
### 9-3. 生産性係数K - 乗算として組み込む
&nbsp;&nbsp;&nbsp;災害対策において生産量は、他の項目で代替可能な加算要素ではなく**前提条件**であるため、乗算で反映します。

| 熱量等級 | 自給倍率 | K |
|:---:|:---|---:|
| SS | ≥1.50 | **1.00** |
| S | ≥1.00 | **1.00** |
| A | ≥0.70 | 0.93 |
| B | ≥0.50 | 0.87 |
| C | ≥0.30 | 0.79 |
| D | ≥0.15 | 0.70 |
| E | <0.15 | **0（除外）** |

> **Kを取り除くと、熱量等級と総合点数の相関が+0.662から+0.080へと崩壊します。**  
> この係数がなければ、熱量Dの野生の山菜が低投入項目でSSを総なめにし、穀物を上回ってしまいます。**25項目中9項目が「必要性が低いほど高得点」という構造**だからです。

---
### 9-4. 確証係数 - 根拠の空白を減らす

```
確証係数 = 1 - 0.35 × (下位階層の代入セル数 ÷ 25)
```

| 代入セル | 確証係数 | 減衰 |
|---:|---:|---:|
| 0 | 1.000 | 0% |
| 3 | 0.958 | 4.2% |
| 7 | 0.902 | 9.8% |
| 14 | 0.804 | 19.6% |
| 25 | 0.650 | 35% |

&nbsp;&nbsp;&nbsp;**この係数は罰点ではなく、データ改善のインセンティブです。**根拠を埋めれば1.00に戻ります。評価尺度の目標は作物の点数を削ることではなく、根拠を埋めさせることです。

---
### 9-5. 除外ゲート
&nbsp;&nbsp;&nbsp;加重合計だけでは根拠不足を補えず、**「一項目における致命的な欠格」**を表現できません。

| ゲート | 条件 | 免除 | 根拠 |
|:---|:---|:---|:---|
| 熱量 | 面積当たり熱量E（自給ライン15%未満） | - | 食料作物として成立不可 |
| 採種 | 自家採種E | - | 再生産不可 |
| 貯蔵 | 貯蔵性E | 永続性A以上 | 備蓄不可。ただし畑で随時収穫できる多年生作物は免除 |
| 病害虫 | 病害虫圧E（無防除時の減収率80%超） | - | 栽培不可 |

> **除外と等級Eは異なります。**  
> 除外された作物も、25項目評価と「ゲートがなかったら何点だったか」を併記します。除外は点数が低いという意味ではなく一項目の致命的な欠格を意味するため、**その項目が改善されれば直ちに有効集合に入ります。**

---
### 9-6. 最終等級換算 - パーセンタイル固定
&nbsp;&nbsp;&nbsp;閾値となる点数を固定すると、作物が追加されるたびに基準が揺らぎます。**点数ではなくパーセンタイルで定義します。**

| 等級 | パーセンタイル（除外を除いた有効サンプル） | 現在対応する点数（183種） |
|:--:|:---|---:|
| SS | 上位2% | 57.6↑ |
| S | 上位7% | 50.5↑ |
| A | 上位18% | 48.2↑ |
| B | 上位35% | 44.3↑ |
| C | 上位60% | 40.6↑ |
| D | 上位85% | 36.0↑ |
| E | それ未満 | - |

**熱量下限バンド規則**

```
総合SS・S等級は、面積当たり熱量C(自給ライン30%)以上の作物にのみ付与する
未達の場合は2等級降格し、副食等級を必ず併記する
```

&nbsp;&nbsp;&nbsp;パーセンタイルだけでは、副食専用作物（タンポポ・ヨモギ・ニガナ等）が総合上位バンドに入ってしまいます。これらは副食SSとして価値は明確ですが、主食の候補ではありません。この規則により**役割が分けて表記**されます。
