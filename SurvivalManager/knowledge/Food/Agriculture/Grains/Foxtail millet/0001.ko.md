## 들어가며
&nbsp;&nbsp;&nbsp;조(粟, Setaria italica)는 중국 황하 유역이 원산이며, 밀과 쌀이 들어오기 전 동아시아 사람들이 수천 년 동안 주식으로 삼은 곡물입니다. 흉년, 척박한 밭, 가뭄 때마다 심던 구황작물입니다. 요수량은 벼의 8.7%이고 총 증발산량 100-200mm면 결실하며, 거름은 질소·인산·칼륨을 합쳐 ㎡당 12g으로 옥수수의 3분의 1이면 충분하고, 심고 65-80일이면 거둡니다. 약점은 수확량(1,000㎡에서 250kg, ㎡당 932kcal이므로 한 사람의 1년 열량에 약 280㎡ 필요), 습해, 그늘입니다. 조는 넉넉히 먹여 주는 작물이 아니라 다른 곡물이 실패했을 때 빈자리를 메우고 척박한 자투리땅을 곡물로 바꾸는 보험에 가깝습니다. 조는 알이 작아 다루기 까다롭고, 그 까다로움은 대부분 수확 뒤에 나타납니다.

## 2. 식물 개요
&nbsp;&nbsp;&nbsp;벼과 강아지풀속의 한해살이풀로 중국 황하 중류가 원산입니다. 강아지풀과 근연이어서 밭에서 어린 잎이 구별되지 않고 드물게 교잡하기도 합니다. 줄기는 80-160cm로 곧게 서고, 뿌리는 얕고 촘촘하게 퍼져 지력 소모는 적지만 도복에 약합니다. 꽃은 원추화서로 이삭이 처지며 자가수정이 기본입니다. 열매는 영과이고 찰조와 메조로 나뉩니다.

| 단계 | 시기 | 핵심 |
|:---|:---|:---|
| 발아·유묘기 | 파종 후 3-4주 | 생장이 느리고 가장 약한 시기. 잡초에 덮이거나 물에 잠기면 그해 농사가 결정됨 |
| 분얼·영양생장기 | 4-8주 | 곁줄기가 갈라짐. 포기 수가 조금 부족해도 스스로 메움 |
| 출수기 | 8-10주 | 이삭이 잎집 밖으로 나옴 |
| 등숙·성숙기 | 10-16주 | 전분이 차고 이삭이 처짐 |

| 100g당 영양 | 함량 |
|:---|:---|
| 열량 | 366-386kcal (마른 알곡) |
| 단백질 | 11.4-11.5g (P:E 12.3%로 곡물 중 상위) |
| 탄수화물 / 지방 | 71.1g / 3-4g |
| 식이섬유 | 11.4g (백미의 7배) |
| 칼슘 / 철 / 칼륨 | 100mg / 7.2mg / 300-350mg |
| 비타민 B군 | 백미의 3배 수준 |
| 부족한 것 | 라이신 |

## 3. 재배 환경과 품종
| 조건 | 최적 | 한계와 영향 |
|:---|:---|:---|
| 생육 기온 | 25-35℃ | 15-44℃. 15℃ 아래에서 생장이 멈추고 서리에 고사 |
| 발아 | 30-31℃ | 최저 4-6℃. 낮으면 발아가 늦고 종자가 썩음 |
| 등숙기 | 20-32℃ | 지나친 고온에서 씨알이 여물지 않음 |
| 빛 | 종일 직사광 | 6시간 이상. 40% 차광에서 수량 45% |
| 물 | 총 100-200mm | 80-350mm. 곡물 가운데 가장 적음 |
| 토양 | 사질-식양질, 물 빠짐 좋은 흙 | 자갈밭, 화전지까지 가능. 점질토에서 뿌리가 상함. pH 5.5-7.5 |
| 지하수위 | 1m 이하 | 높으면 뿌리가 숨을 쉬지 못함 |

&nbsp;&nbsp;&nbsp;남향 구릉지와 경사지(물이 저절로 빠짐), 자갈 섞인 척박지, 산간 화전지가 좋습니다. 평지 밭은 두둑을 높이 세우고, 논을 전환한 밭, 저지대, 그늘진 자리, 북향은 피합니다.

| 품종 | 숙기 | 특징 |
|:---|:---:|:---|
| 찰조(차조) | - | 찰기가 있어 혼반, 떡, 엿, 술에 씀 |
| 메조 | - | 밥, 죽, 가루에 씀. 가루로 빻기 좋고 저장성이 좋음 |
| 삼다찰 | 중생 | 1,000㎡당 224kg. 단간 다수성으로 황금조 대비 12% 증수 |
| 황금조 | 조생 | 내도복성. 서리가 이른 지역과 6월 말 파종에 적합 |
| 조황메(밀양5호) | 중생 | 황금조 대비 27% 증수. 조도열병 저항성 |

&nbsp;&nbsp;&nbsp;재난이 길어질수록 중요해지는 것은 육성 품종이 아니라 그 지역에서 오래 심겨 온 재래종입니다. 조는 자가수정 작물이라 자가 채종이 쉽습니다.

## 4. 밭 준비와 파종
| 항목 | 기준 |
|:---|:---|
| 땅 만들기 | 20-30cm 갈고, 두둑 높이 20-30cm, 밭 둘레와 고랑마다 배수로. 씨알이 작으므로 흙덩이를 잘게 부수고 파종 후 눌러 줌 |
| 시비 | 1,000㎡당 질소·인산·칼륨 각 5-8kg, 완숙 퇴비 1,000kg(전량 밑거름). 거름을 더 주면 수확이 늘지 않고 쓰러짐 |
| 대체 자원 | 나무재 15-30kg, 부숙 퇴비, 오줌 10배 희석액(소량), 콩과 녹비(갈아엎고 2-3주 뒤 파종), 화전 재 |

&nbsp;&nbsp;&nbsp;무투입 수량 유지율은 45%입니다.

| 작형 | 파종 | 수확 |
|:---|:---|:---|
| 봄조 | 5월 초순-중순 | 9월 상순. 가장 일반적이고 수량이 많음 |
| 그루조 | 6월 중순-하순 | 9월 하순-10월. 보리·밀을 벤 자리 |
| 만파 | 6월 말까지 | 10월 초. 한계선이며 조생종만 가능 |

| 파종 | 기준 |
|:---|:---|
| 종자 선별 | 염수선: 물 1L에 소금 43g(비중 약 1.04)에 종자를 넣고 저어 뜬 것을 걷어 내고 가라앉은 것만 건짐. 맑은 물에 두세 번 헹궈 그늘에서 완전히 말림. 소금이 귀하면 물선 |
| 종자 소독 | 나무재 분의(가장 잘 맞음), 50-55℃ 물에 10분(60℃ 초과 시 배가 죽음), 파종 2-3일 전 볕에 2-3시간 |
| 심기 | 1,000㎡당 1-2kg, 줄 간격 60cm, 점뿌림 5-10cm, 깊이 2-3cm. 복토 후 발이나 널판으로 눌러 줌 |

## 5. 물과 재배 관리, 병해충
| 시기 | 물 관리 |
|:---|:---|
| 파종-발아 | 흙이 마르지 않게 |
| 유묘기 | 물을 주지 않음 |
| 분얼·영양생장기 | 자연 강수에 맡김 |
| 출수·등숙기 | 가물면 보충. 수량이 결정되는 시기 |
| 성숙기 | 완전히 끊음 |
| 장마철 | 물을 빼는 것이 관리의 전부 |

> **조밭에서는 물이 부족해 실패하는 일보다 물이 빠지지 않아 실패하는 일이 훨씬 많습니다. 조는 가뭄에 가장 강하고 과습에 가장 약한 곡물입니다.**

| 관리 | 내용 |
|:---|:---|
| 솎기 | 본잎 2-3매에 1차로 성기게, 4-5매에 2차로 포기당 2본씩 남김. 미루면 가늘어져 쓰러짐 |
| 김매기 | 승부처. 출현 후 2주에 1차(잡초가 손가락 길이일 때), 4주에 2차와 북주기. 강아지풀과 구별이 어려우므로 줄뿌림을 지킴 |
| 북주기 | 2차 김매기와 동시, 출수 직전에 한 번 더. 쓰러지면 서너 포기씩 묶어 세움 |
| 기타 | 분얼은 제거하지 않음. 이삭이 처질 무렵 그물이나 실을 늘어 새(참새 떼)를 막음. 짚 멀칭이 잡초와 증발을 줄임 |

| 병해충 | 약 없이 하는 대응 |
|:---|:---|
| 조도열병(5월 하순-8월 하순, 다습) | 저항성 품종, 질소 과다 억제, 병든 포기 조기 제거 |
| 노균병, 줄무늬잎마름병 | 통풍과 배수, 병든 포기 소각, 매개충과 주변 잡초 관리 |
| 깜부기병(종자 전염) | 염수선, 나무재 분의, 병든 이삭 소각 |
| 조명나방(7-8월), 멸강나방 | 피해 줄기 제거·소각, 손으로 잡기, 심하면 조기 수확 |
| 진딧물, 노린재(등숙기) | 비눗물, 천적 보호, 이른 아침 손으로 잡기, 주변 잡초 정리 |
| 새 | 그물, 실 늘이기, 소리 나는 장치 |

&nbsp;&nbsp;&nbsp;조에서 가장 큰 손실은 병도 벌레도 아니고 잡초와 새입니다. 방제 원칙은 배수, 건전 종자, 적정 시비, 통풍(재식 간격과 솎기), 위생(병든 잔재 치우기)입니다. 나무재, 마늘·고추 우린 물, 우유 5-10배 희석액도 씁니다.

| 증상 | 원인과 조치 |
|:---|:---|
| 전체가 누렇게 뜨고 키가 작음 | 질소 결핍. 부숙 퇴비, 오줌 희석액을 아주 소량 |
| 생육이 더디고 잎이 검푸름 | 인산 결핍. 뼛가루 |
| 잎맥 사이만 노래짐 | 마그네슘 결핍. 백운석 가루 |
| 새 잎이 하얗게 뜸 | 철 결핍(대개 알칼리 과다). 나무재 중단 |
| 키만 크고 짙푸르며 쓰러짐 | 질소 과잉(결핍보다 흔함). 질소를 끊고 북주기 |

## 6. 사이짓기와 윤작
| 궁합 | 작물 |
|:---|:---|
| 매우 좋음 | 콩, 팥, 동부(질소 고정과 아미노산 조성 보완) |
| 좋음 | 땅콩, 보리·밀·감자 뒤의 그루조 |
| 보통 | 수수, 기장(재배법이 비슷하나 병해 공유) |
| 나쁨 | 옥수수(키가 커서 조를 그늘지게 함) |

&nbsp;&nbsp;&nbsp;1년차 조, 2년차 콩과(대두, 팥, 동부)로 질소를 회복시키고, 3년차 뿌리채소 또는 잎채소, 4년차 조로 복귀합니다. 연작 적응성은 SS입니다.

## 7. 수확, 탈곡, 채종
| 단계 | 내용 |
|:---|:---|
| 시기 | 조생종 출수 후 45일, 만생종 55일. 이삭이 황갈색이 되어 고개를 깊이 숙이고 손톱으로 눌러 자국이 남지 않을 때. 이삭을 흔들어 씨알이 조금 떨어지면 적기를 막 지난 것 |
| 베기 | 맑은 날 오전 이슬이 마른 뒤 이삭 아래 20-30cm에서 낫으로 벰. 이삭을 아래로 향하게 잡고 천이나 멍석 위에 놓음. 병든 이삭은 따로 나눔 |
| 건조 | 예비 건조 2-3일(18-20%) → 대여섯 이삭씩 묶어 처마 밑에 거꾸로 걸어 말리기 1-2주(15-16%) → 탈곡 → 마무리 볕 건조 2-3일(13-14%) → 그늘에서 하루 두어 고르게 함 |
| 수분 판정 | 깨물면 톡 갈라지며 가루가 남, 소금 시험, 한 줌 쥐었다 펴면 미끄러지듯 흩어짐, 두 손에 담아 흔들면 모래 소리, 병에 밀봉해 하루 두어 김이 서리지 않음 |
| 탈곡 | 자루 안에서 치기(조에 가장 잘 맞음), 멍석 위 도리깨질, 밟기, 통 안에서 비비기, 홈 판 판에 문지르기, 손으로 훑기(종자용) |
| 쭉정이 | 초속 2-3m의 약한 바람에 흘리기, 키질, 부채질, 고운 체. 알이 가벼워 바람 조절이 까다로움 |

| 채종 | 기준 |
|:---|:---|
| 선발 | 등숙기에 미리 표시. 병이 없고 쓰러지지 않으며 이삭이 크고 고른 포기의 주이삭. 깜부기병이 보였거나 유난히 이르거나 늦은 포기는 제외. 일반 수확보다 조금 더 두어 완전히 익힘 |
| 물량 | 필요량의 두 배(1,000㎡당 1-2kg이라 부담이 적음) |
| 보관 | 겉껍질째, 수분 12-13%, 10℃ 이하, 밀폐 용기, 빛 차단. 상온 밀폐 2-3년 |

&nbsp;&nbsp;&nbsp;4-5년마다 종자를 갱신합니다. 종자는 식용 곡식과 반드시 따로 둡니다.

## 8. 저장
&nbsp;&nbsp;&nbsp;저장성은 SS입니다. 겉껍질째 저장하고 먹을 만큼만 도정합니다. 도정한 조는 저장 수명이 절반 이하로 줄어듭니다.

| 항목 | 기준 |
|:---|:---|
| 조건 | 수분 13-14%, 온도 15℃ 이하(25℃ 초과 시 벌레 세대가 빨리 돎), 주변 습도 65% 이하, 두 달마다 점검(냄새, 온기, 결로) |
| 용기 | 유리병, 금속 통 3년 이상 / 항아리 2-3년 / 두꺼운 비닐 1-2년 / 마대 6개월-1년(알이 작아 틈으로 새어 나감) |
| 벌레 방제 | 완전 밀폐(가득 채움), 나무재 2-5%, 규조토 곡물 1kg에 1-3g, 쑥·창포·회화나무 잎, 볶은 소금, 숯, 고운 모래·황토 |

## 9. 조리와 주의사항
| 도정(껍질 벗기기) | 방법 |
|:---|:---|
| 절구 찧기 | 마른 알곡을 넣고 가볍게 여러 번 찧고 5분마다 꺼내 키질. 세게 찧지 않는 것이 핵심 |
| 물 축여 찧기 | 찧기 전 물을 조금 뿌려 20-30분 둠. 껍질이 잘 벗겨지고 알이 덜 깨짐 |
| 기타 | 맷돌(위짝을 띄워 천천히), 돌확 비비기, 디딜방아(힘이 훨씬 덜 듦) |

&nbsp;&nbsp;&nbsp;겨는 버리지 않고 가축 먹이나 거름으로 씁니다. 제분은 볶은 뒤 빻으면 덜 힘들고 고소하며, 가루는 알곡보다 훨씬 빨리 상하므로 한 달 먹을 만큼만 만듭니다.

| 조리 | 연료와 요령 |
|:---|:---|
| 가루죽 | 가루를 물에 풀어 5-10분. 연료가 가장 적게 듦 |
| 좁쌀죽 | 물을 많이 잡아 20분. 소화가 쉬워 아이와 환자에 적합 |
| 좁쌀밥, 혼반 | 30분 이상 불려 쌀보다 물을 조금 더 잡음. 쌀이나 보리에 20-30%를 섞으면 거부감이 적고 영양이 보완됨 |
| 잔열 조리 | 10분 끓인 뒤 짚이나 담요로 감싸 40-60분. 연료를 절반 이하로 줄임 |

&nbsp;&nbsp;&nbsp;저장을 겸한 가공으로는 볶은 가루(밀폐 6개월), 조청·엿(서늘한 곳 1년), 좁쌀 술, 조떡, 튀밥, 발효 죽이 있습니다.

| 주의 | 내용 |
|:---|:---|
| 독성 | 일반적인 섭취량에서 독성이 없음 |
| 곰팡이가 핀 것 | 곰팡이독소는 가열해도 사라지지 않음. 전량 폐기하고 가축에게도 주지 않음 |
| 식이섬유 | 100g에 11.4g으로 매우 높음. 어린이와 노약자에게는 다른 곡물과 섞어 먹임 |
| 단일 식단 | 라이신이 부족하므로 콩류와 함께 먹음 |
| 갑상샘 | 기장류에 고이트로겐이 미량 있다는 보고가 있어, 요오드 섭취가 극도로 부족한 상태에서 장기간 대량으로 먹는 것은 삼감 |
| 덜 익힌 것 | 전분이 소화되지 않으므로 충분히 불려 익힘 |

## 10. 연간 작업 일정
| 월 | 작업 |
|:---|:---|
| 1-2월 | 저장 곡물 점검, 종자 확인, 퇴비 뒤집기, 발아 시험 |
| 3월 | 나무재 모으기, 배수로 점검 |
| 4월 | 밭갈이, 두둑 만들기, 밑거름, 흙 곱게 고르기 |
| 5월 | 염수선, 나무재 분의, 봄조 파종(초중순). 파종 후 반드시 누름 |
| 6월 | 1차 솎기와 김매기, 그루조 파종(중하순) |
| 7월 | 2차 솎기, 북주기, 배수로 손보기, 출수 |
| 8월 | 등숙, 새 쫓기, 병해 감시. 이삭이 처지면 그물을 침 |
| 9월 | 봄조 수확, 예비 건조, 걸어 말리기. 씨알이 떨어지기 시작하면 사흘 안에 벰 |
| 10월 | 그루조 수확, 탈곡, 마무리 건조, 저장(수분 13-14%) |
| 11-12월 | 종자 선별과 별도 보관, 그루터기 갈아 넣기, 도정과 제분, 저장 점검 |

> **잊지 말아야 할 다섯 가지: 배수, 초기 김매기, 거름 절제, 조금 이르게 수확, 겉껍질째 저장.**
