## 12. 収穫と脱穀

### 12-1. 時期の判断

| 基準 | 内容 | 判定 |
|---|---|---|
| 早生種 | 出穂後45日 | おおよその基準です |
| 晩生種 | 出穂後55日 | 品種の説明を確認します |
| 穂の色 | 穂が黄褐色になり深く垂れます | 成熟が近づいています |
| 種粒の硬さ | 爪で押しても跡が残りません | 完熟です |
| 種粒の断面 | 半分に割ると中が白く硬いです | 登熟完了です |
| 脱粒 | 穂を振ると種粒が少し落ちます | 適期をちょうど過ぎています。急ぐ必要があります |
| 天気 | 晴天が2-3日続いた後 | 水分が低く乾燥しやすいです |

&nbsp;&nbsp;&nbsp;アワの収穫適期は狭いです。早すぎると種粒の水分が多く、乾く過程で縮んで精穀のときに割れます。遅すぎると穂から種粒が自然に落ちて地面に散らばります。種粒が小さいため一度地面に落ちると拾えず、損失がそのまま確定します。畑を毎日見回って穂を手で振ってみて、数粒が落ち始めたらその日から三日以内に刈るのが要領です。

> **穀物は少し早めに刈って室内で乾かすことはできますが、遅れて落ちた粒は取り戻せません。**

### 12-2. 収穫のコツ

| 順序 | 内容 | 理由 |
|---|---|---|
| 1 | 晴れた日の午前、露が乾いた後に始めます | 濡れた穂はカビの出発点です |
| 2 | 穂の下20-30cmのところを鎌で刈ります | 柄があれば束ねて掛けやすいです |
| 3 | 刈るときは穂を下に向けて持ちます | 振れると種粒が落ちます |
| 4 | 刈った穂はその場でむしろや布の上に置きます | 地面に散った種粒を回収できます |
| 5 | 病気の穂と健全な穂を分けます | 混ぜるとカビが伝わります |
| 6 | 5-6本ずつ束ねて軒下に逆さに吊るします | 風通しのよい姿勢が乾燥を左右します |

&nbsp;&nbsp;&nbsp;アワを刈るときは、畑に布を敷いてその上で作業するとよいです。種粒が小さいため鎌を一振りするだけでもかなりの量が落ちますが、布を敷いておけばそれを回収できます。小さな違いに見えますが、収穫量の5%から10%に相当します。古着やビニールの切れ端でも構いません。

### 12-3. 穀物の乾燥 - 水分13-14%まで

&nbsp;&nbsp;&nbsp;穀物貯蔵のすべては水分で決まります。水分が15%を超えるとカビが育ち、13%を下回るとカビも虫もほとんど活動を止めます。刈り取ったばかりのアワの水分は20-25%です。これを13-14%まで下げることが、収穫直後の唯一かつ最も重要な課題です。

| 段階 | 方法 | 期間 | 到達水分 |
|---|---|---|---|
| 1. 予備乾燥 | 刈った穂の束を畑や庭に立てておきます | 2-3日 | 18-20% |
| 2. 吊るし乾燥 | 軒下や納屋に逆さに吊るします | 1-2週 | 15-16% |
| 3. 脱穀 | 十分に乾いた後、脱粒します | 1日 | - |
| 4. 仕上げ乾燥 | むしろや布に広げて日に当てます | 2-3日 | 13-14% |
| 5. 水分均一化 | 陰で一日ほど置いて水分を均一にします | 1日 | 均一化 |

&nbsp;&nbsp;&nbsp;日に当てて乾かすときの原則はどの穀物でも同じです。第一に、地面に直接広げません。土から上がる湿気が下側を再び湿らせます。むしろ、布、板のいずれかを一枚敷きます。第二に、3-5cmを超えて積まず、一日に三、四回ひっくり返します。第三に、日が傾いたら取り込むか覆います。夜露に当たると、日中に抜いた水分が戻ってきます。第四に、急いで乾かしません。表面だけ乾いて内部に水分が閉じ込められると、後でカビが生えます。

&nbsp;&nbsp;&nbsp;アワは粒が小さく、風で飛びやすいです。日に当てて乾かすときに風が強ければ、粗い布で覆うか、風の当たらない場所を選びます。飛んでしまった粒は回収できません。

&nbsp;&nbsp;&nbsp;計量器なしで水分を見積もる方法があります。慣れればかなり正確です。

| 方法 | 手順 | 判定 |
|---|---|---|
| 噛む | 種粒を奥歯で噛みます | パチッと割れて粉が出れば13-14%です。潰れれば、まだ湿っています |
| 塩試験 | 乾いた塩ひとさじと穀物ひとつかみを瓶に入れて振り、15分置きます | 塩が瓶の内側に付けば水分が高いです |
| 手触り | ひとつかみ握って開きます | すべるように散れば乾いたもの、固まれば湿ったものです |
| 音 | 両手に入れて振ります | 砂が流れるような音がすれば乾いたものです |
| 瓶試験 | ガラス瓶に半分ほど入れて密封し、一日置きます | 瓶の内側に水滴が曇れば、もっと乾かす必要があります |

&nbsp;&nbsp;&nbsp;瓶試験は貯蔵に入る前の最終確認として最も信頼できます。密閉した瓶の中で穀物と空気が水分平衡に達しますが、水分が14%を超えると瓶内の湿度が70%を超え、気温が下がる明け方に水滴が曇ります。涼しい夜がある秋であれば、よりはっきり現れます。

&nbsp;&nbsp;&nbsp;雨が続いて日光が使えない年もあります。そのときはかまどや暖炉の上の物置、オンドルのうち火元から遠い暖かい場所に薄く広げておきます。数日かけて乾きますが、温度が50℃を超えないようにする必要があります。それを超えると種として使えなくなり、食味も落ちます。手を当てて温かいと感じる程度が適当で、熱いと感じたらすでに高すぎます。

### 12-4. 脱穀 - 道具を使わない方法

&nbsp;&nbsp;&nbsp;アワは脱穀が比較的簡単な穀物です。十分に乾けば穂から種粒がよく落ちるためです。ただし粒が小さいため四方に飛び散り、糠や屑が多く混ざります。作業空間を囲うことがコツです。

| 方法 | 手順 | 規模 | 備考 |
|---|---|---|---|
| 手でこぐ | 穂の柄を持ち、手袋をした手でこぎ落とします | 少量 | 損失が最も少ないです。種子用に使います |
| 袋の中で打つ | 丈夫な袋に穂を入れ、袋ごと地面に叩きつけます | 中程度 | アワに最も合います。粒が飛び散りません |
| 打つ | むしろの上に穂を広げ、唐竿や棒で打ちます | 多量 | 四方を布で囲って行います |
| 踏む | むしろに広げて足でこするように踏みます | 多量 | 力があまりかかりません |
| 桶の中でこする | 大きな桶に穂を入れ、棒でかき回してこすります | 中程度 | 粒が散らばりません |
| 洗濯板でこぐ | 溝の彫られた板に穂を当ててこすります | 少量 | 木の板に溝を彫って作れます |

&nbsp;&nbsp;&nbsp;アワには袋の中で打つ方法が特に合います。粒が小さく、叩いたときに最も飛び散りやすい穀物ですが、袋がそれをすべて受け止めてくれます。丈夫な麻袋や厚手のビニール袋に乾いた穂を3分の1ほど詰めて口を縛った後、袋ごと持ち上げて丸太や平らな石に叩きつけます。二十回ほど打って開けてみると、大部分が落ちています。

&nbsp;&nbsp;&nbsp;唐竿は自分で作ることができます。長い柄の先に短い棒を、革ひもや丈夫なロープで緩く結び付ければよいです。柄を振ると先の棒が回転しながら穀物を打ちます。腕の力で叩くよりはるかに効率が高く、疲れも少なくなります。

### 12-5. しいな飛ばし - 唐箕と箕

&nbsp;&nbsp;&nbsp;脱穀したアワには穂の屑、葉の切れ端、埃、しいなが混ざっています。これをそのまま貯蔵すると、しいなに付いた水分と虫の卵が貯蔵物全体を台無しにします。風で選り分ける作業が必ず必要です。

| 方法 | 手順 | 条件 |
|---|---|---|
| 風に流す | 風のある日に高い場所からゆっくり流し落とします | 風速2-3m。アワは粒が軽いので、風が強いと穀物まで飛んでいきます |
| 箕でふるう | 箕に入れて前に押し引きしながら空中に浮かせます | 風がなくても構いません |
| うちわであおぐ | 一人がゆっくり流し、もう一人がうちわで風を送ります | 風の強さを調整できるためアワに適しています |
| 篩い分け | 粗い篩で大きなしいなを、細かい篩で埃を分けます | アワは粒が小さいため、篩の目が細かい必要があります |
| 水選別 | 水に入れて浮いたしいなを取り除きます | 必ずすぐにまた乾かす必要があります |

&nbsp;&nbsp;&nbsp;アワは粒が軽く、風の調節が難しいです。モロコシやトウモロコシのように強い風に流すと穀物まで飛んでいきます。そのため自然の風よりうちわのように強さを調節できる方法がよく、箕でふるうのが最も確実です。箕をふるうコツは上下に振ることではなく、前に押して引きながら穀物を一瞬空中に浮かせることです。浮いている間に軽いものが後ろに残って前方に集まり、それを手で払い出します。半日で覚えて一生使える技術です。

## 13. 採種

### 13-1. 採種個体の選抜

| 基準 | 内容 | 理由 |
|---|---|---|
| 選抜時期 | 登熟期に畑を回って前もって印をつけます | 収穫後にはどの株のものか分からなくなります |
| 個体の条件 | 病徴がなく倒れておらず、穂が大きく揃っているもの | 形質が次の世代に引き継がれます |
| 穂の位置 | 株の中で最も太い主穂 | 側穂は熟し方が不揃いです |
| 収穫時期 | 通常の収穫より少し長く置いて完全に熟させます | 未熟な種子は発芽率が落ちます |
| 除外対象 | 黒穂病が見られた株、極端に遅いか早い株 | 種子伝染と形質の乱れを防ぎます |
| 量 | 必要量の2倍 | 1,000㎡当たり1-2kgで済むため負担が少ないです |

&nbsp;&nbsp;&nbsp;アワは自家受粉作物なので採種がとても簡単です。他の品種が近くにあっても混じる確率は低く、採った種子は大抵親と同じ性質を示します。災害対策の観点からこれは大きな利点です。トウモロコシのように一世代で崩れることもなく、ジャガイモのように生きた状態で冬を越す必要もありません。

&nbsp;&nbsp;&nbsp;ただし4-5年ごとに種子を更新するよう勧められているのには理由があります。採種を適当に行うと、畑全体から無作為に採った種子を使うことになり、その中には晩熟だったり病気に弱かったり穂が小さい個体の種子が混ざります。それが年々積み重なると、数年後には品種の性質がぼやけてきます。採種個体を厳しく選んで別に管理すれば、この劣化をかなり遅らせることができます。

&nbsp;&nbsp;&nbsp;エノコログサとの交雑も稀に起こります。畑の端のエノコログサは、必ず穂が出る前に抜いておく必要があります。交雑した個体は種粒が落ちやすい性質を受け継ぎ、収穫での損失が大きくなります。

### 13-2. 種子の保管

| 条件 | 基準 | 理由 |
|---|---|---|
| 水分 | 12-13%。食用より少し乾燥させます | 種子は水分が低いほど寿命が長くなります |
| 温度 | 10℃以下が理想です | 高いと呼吸によって胚が消耗します |
| 容器 | ガラス瓶、金属缶、甕 | 湿気と虫を同時に防ぎます |
| 光 | 完全に遮断します | 熱と光が発芽力を落とします |
| 形態 | 殻付きのまま保管します | 精穀したものは寿命がずっと短いです |
| 寿命 | 常温密閉で2-3年 | 条件が良ければもっと持ちます |

&nbsp;&nbsp;&nbsp;種子は食用の穀物と必ず別に置きます。冬が深まり食べ物が減ると種子に手が伸び、一度手をつけると翌年の農業がなくなります。物理的に別の場所、別の容器に置いて印をつけておくことが、人の自制心を信じるよりも確実です。

### 13-3. 発芽試験

&nbsp;&nbsp;&nbsp;古い種子を播く前には発芽力を確認します。濡らした布に種粒50個を包んで暖かい場所に置き、5日待ちます。アワは粒が小さく20個では誤差が大きいため、50個を使います。50個のうち40個以上発芽すればそのまま使い、30から40個なら播種量を増やし、30個未満なら新しい種子を調達する必要があります。

## 14. 毒性と注意事項

### 14-1. 穀粒の毒性 - なし

&nbsp;&nbsp;&nbsp;アワは通常の摂取量では毒性がありません。モロコシと異なり、葉に問題となるほどのシアン配糖体は含まれておらず、穀粒にも取り除くべき毒性成分はありません。精穀して洗い、ご飯を炊けばそのまま安全です。災害時に調理前の特別な解毒処理が不要という点は実質的な利点です。

### 14-2. 注意が必要な場合

| 項目 | 内容 | 対処 |
|---|---|---|
| カビが生えたもの | カビ毒は加熱しても消えません | 全量廃棄します。家畜にも与えません |
| 食物繊維過多 | 100gに11.4gと非常に高いです | 子どもや高齢者には他の穀物と混ぜて食べさせます |
| 単一食 | リジンが不足します | 豆類と一緒に食べます |
| 甲状腺 | 雑穀類にごく微量のゴイトロゲンがあるという報告があります | 通常の摂取量では問題になりません |
| 加熱不足のもの | でんぷんが消化されません | 十分にふやかしてから加熱します |

> **カビが生えた穀物は、洗っても、煮ても、炒っても安全にはなりません。捨てることが唯一の方法です。**

&nbsp;&nbsp;&nbsp;食物繊維の問題は災害時に実際に重要になります。粟飯は満腹感が大きい一方、それだけ消化されない成分が多く、熱量を切実に必要とする人には不利に働くことがあります。特に幼い子どもは胃が小さく、満腹になった時点で必要な熱量をすべて満たせません。アワを食べさせるときは他の穀物と混ぜ、少しでも油脂を加えるほうがよいです。

&nbsp;&nbsp;&nbsp;ゴイトロゲンは雑穀類全般にごく微量存在することが知られている成分で、ヨウ素摂取が極度に不足した状態で長期間大量に食べると甲状腺機能に影響を与える可能性があるという報告があります。韓国のように海藻や塩からヨウ素を得られる環境では、現実的なリスクではありません。ただし、アワの単作だけに依存する食事が何年も続く状況であれば、ワカメやノリのような海藻を確保しておくことが、複数の理由から望ましいです。
