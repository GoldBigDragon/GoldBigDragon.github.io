## 引言
&nbsp;&nbsp;&nbsp;粟（Setaria italica，即谷子）原产于中国黄河流域，在小麦和稻米传入之前，是东亚人数千年来作为主食的谷物。它是在荒年、贫瘠的田、干旱时节常种的救荒作物。需水量是水稻的8.7%，总蒸散量100-200mm就能结实，肥料氮、磷、钾合计每㎡只需12g，是玉米的三分之一，种下后65-80天即可收获。弱点是产量（每1,000㎡产250kg，每㎡932kcal，一个人一年的热量约需280㎡）、涝害和遮阴。粟不是让人吃饱吃好的作物，更像一份保险：在其他谷物歉收时补上缺口，把贫瘠的边角地变成粮食。粟粒小、难处理，这种难处大多出现在收获之后。

## 2. 植物概述
&nbsp;&nbsp;&nbsp;禾本科狗尾草属的一年生草本，原产于中国黄河中游。它与狗尾草亲缘相近，所以在田里幼苗分辨不开，偶尔也会杂交。茎直立，高80-160cm，根浅而密地展开，对地力消耗少，但易倒伏。花为圆锥花序，穗子下垂，以自花授粉为主。果实是颖果，分为糯粟和粳粟。

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 发芽·幼苗期 | 播种后3-4周 | 生长缓慢，是最脆弱的时期。被杂草盖住或被水淹，当年的收成就定了 |
| 分蘖·营养生长期 | 4-8周 | 侧茎分出。即使株数略少，也会自己补上 |
| 抽穗期 | 8-10周 | 穗子从叶鞘中伸出 |
| 灌浆·成熟期 | 10-16周 | 淀粉充实，穗子下垂 |

| 每100g营养 | 含量 |
|:---|:---|
| 热量 | 366-386kcal（干籽粒） |
| 蛋白质 | 11.4-11.5g（P:E 12.3%，在谷物中居前列） |
| 碳水化合物 / 脂肪 | 71.1g / 3-4g |
| 膳食纤维 | 11.4g（白米的7倍） |
| 钙 / 铁 / 钾 | 100mg / 7.2mg / 300-350mg |
| B族维生素 | 约为白米的3倍 |
| 缺乏的 | 赖氨酸 |

## 3. 栽培环境与品种
| 条件 | 最适 | 极限与影响 |
|:---|:---|:---|
| 生长温度 | 25-35℃ | 15-44℃。低于15℃停止生长，遇霜枯死 |
| 发芽 | 30-31℃ | 最低4-6℃。温度低则发芽迟缓，种子腐烂 |
| 灌浆期 | 20-32℃ | 过热则籽粒不饱满 |
| 光 | 全天直射光 | 6小时以上。遮光40%时产量45% |
| 水 | 合计100-200mm | 80-350mm。谷物中最少 |
| 土壤 | 沙质到壤质、排水良好的土 | 砾石地、火耕地都行。黏土会伤根。pH 5.5-7.5 |
| 地下水位 | 1m以下 | 过高则根无法呼吸 |

&nbsp;&nbsp;&nbsp;朝南的丘陵和坡地（水能自行流走）、夹杂砾石的贫瘠地、山地火耕地都适合。平地要把垄堆高，避开稻田改作的旱地、低洼地、背阴处和朝北的地块。

| 品种 | 熟期 | 特点 |
|:---|:---:|:---|
| 糯粟（chajo） | - | 有黏性，用于杂粮饭、年糕、饴糖、酒 |
| 粳粟（mejo） | - | 用于饭、粥、磨粉。易磨成粉，耐储性好 |
| Samdacham | 中熟 | 每1,000㎡ 224kg。矮秆高产型，比Hwanggeumjo增产12% |
| Hwanggeumjo | 早熟 | 抗倒伏。适合霜期早的地区和6月底播种 |
| Johwangme（密阳5号） | 中熟 | 比Hwanggeumjo增产27%。抗稻瘟病 |

&nbsp;&nbsp;&nbsp;灾害持续越久，越重要的不是培育品种，而是当地长期栽种的地方品种。粟是自花授粉作物，留种很容易。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 耕深20-30cm，垄高20-30cm，田四周和每条沟都挖排水沟。籽粒小，要把土块打碎，播后压实 |
| 施肥 | 每1,000㎡ 氮、磷、钾各5-8kg，腐熟堆肥1,000kg（全部作基肥）。多施肥不会增产，反而倒伏 |
| 替代资源 | 草木灰15-30kg、腐熟堆肥、尿液稀释10倍（少量）、豆科绿肥（翻压2-3周后播种）、火耕灰 |

&nbsp;&nbsp;&nbsp;无投入产量保持率为45%。

| 茬口 | 播种 | 收获 |
|:---|:---|:---|
| 春粟 | 5月上旬-中旬 | 9月上旬。最普遍，产量高 |
| 茬粟 | 6月中旬-下旬 | 9月下旬-10月。大麦、小麦收割后的地 |
| 晚播 | 至6月底 | 10月初。极限，只有早熟品种可以 |

| 播种 | 标准 |
|:---|:---|
| 选种 | 盐水选：每1L水溶盐43g（比重约1.04），放入种子搅拌，捞去浮起的，只取沉底的。用清水冲洗两三遍，在阴凉处完全晾干。盐珍贵时用清水选 |
| 种子消毒 | 拌草木灰（最合适）、50-55℃热水10分钟（超过60℃胚会死）、播种前2-3天在阳光下晒2-3小时 |
| 种植 | 每1,000㎡ 1-2kg，行距60cm，点播间距5-10cm，深2-3cm。覆土后用脚或木板压实 |

## 5. 水与栽培管理、病虫害
| 时期 | 水管理 |
|:---|:---|
| 播种-发芽 | 不让土壤变干 |
| 幼苗期 | 不浇水 |
| 分蘖·营养生长期 | 交给自然降雨 |
| 抽穗·灌浆期 | 干旱时补水。决定产量的时期 |
| 成熟期 | 完全停水 |
| 雨季 | 排水就是管理的全部 |

> **在粟田里，因水排不出去而失败的情况，远比因缺水而失败的多。粟是最耐旱、却最怕过湿的谷物。**

| 管理 | 内容 |
|:---|:---|
| 间苗 | 2-3片真叶时第一次疏苗，4-5片时每穴留2株。拖延会变细而倒伏 |
| 除草 | 决胜环节。出苗后2周第一次（杂草如手指长时），4周第二次并培土。与狗尾草难以分辨，所以坚持条播 |
| 培土 | 与第二次除草同时，抽穗前再一次。倒伏后三四株捆在一起扶起 |
| 其他 | 不去掉分蘖。穗子下垂时挂网或拉线防鸟（麻雀成群）。稻草覆盖可减少杂草和蒸发 |

| 病虫害 | 不用农药的应对 |
|:---|:---|
| 稻瘟病（5月下旬-8月下旬，多湿） | 抗病品种、控制氮肥过量、早期拔除病株 |
| 霜霉病、条纹叶枯病 | 通风与排水、焚烧病株、管理传毒昆虫和周边杂草 |
| 黑粉病（种子传染） | 盐水选、拌草木灰、焚烧病穗 |
| 玉米螟（7-8月）、粘虫 | 拔除受害茎秆并焚烧、手捉、严重时提前收获 |
| 蚜虫、蝽（灌浆期） | 肥皂水、保护天敌、清晨手捉、清理周边杂草 |
| 鸟 | 网、拉线、响声装置 |

&nbsp;&nbsp;&nbsp;粟最大的损失既不是病也不是虫，而是杂草和鸟。防治原则是排水、健康种子、适量施肥、通风（株距与间苗）、卫生（清走病残体）。也可用草木灰、大蒜和辣椒浸出液、稀释5-10倍的牛奶。

| 症状 | 原因与处理 |
|:---|:---|
| 整体发黄、植株矮小 | 缺氮。腐熟堆肥、极少量稀释尿液 |
| 生长缓慢、叶片青黑 | 缺磷。骨粉 |
| 只有叶脉之间发黄 | 缺镁。白云石粉 |
| 新叶发白 | 缺铁（通常是碱过多）。停用草木灰 |
| 只长高、深绿并倒伏 | 氮过量（比缺氮更常见）。停氮并培土 |

## 6. 间作与轮作
| 搭配 | 作物 |
|:---|:---|
| 很好 | 大豆、红小豆、豇豆（固氮并补充氨基酸组成） |
| 好 | 花生，以及大麦、小麦、马铃薯之后的茬粟 |
| 一般 | 高粱、黍（栽培方法相近，但共有病虫害） |
| 差 | 玉米（高大，会给粟遮阴） |

&nbsp;&nbsp;&nbsp;第1年种粟，第2年种豆科（大豆、红小豆、豇豆）恢复氮素，第3年种根菜或叶菜，第4年回到粟。连作适应性为SS。

## 7. 收获、脱粒、留种
| 步骤 | 内容 |
|:---|:---|
| 时机 | 早熟品种抽穗后45天，晚熟品种55天。穗子呈黄褐色、深深低头、指甲按不出印时。摇穗掉下少量籽粒，说明刚过最佳期 |
| 收割 | 晴天上午露水干后，在穗下20-30cm处用镰刀割。穗朝下握住，放在布或草席上。病穗另外分开 |
| 干燥 | 预干燥2-3天（18-20%）→ 五六穗扎一捆，倒挂在屋檐下晾1-2周（15-16%）→ 脱粒 → 最后日晒2-3天（13-14%）→ 在阴凉处放一天使其均匀 |
| 水分判断 | 咬一下啪地裂开留下粉末、盐试验、抓一把松开后像滑落般散开、双手捧着摇晃有沙子流动声、装瓶密封一天不起雾 |
| 脱粒 | 在袋里敲打（最适合粟）、在草席上用连枷打、踩、在桶里搓、在刻有凹槽的板上摩擦、用手捋（留种用） |
| 秕壳 | 在2-3m/s的微风中倒下、扬筛、扇风、细筛。籽粒轻，调节风力较难 |

| 留种 | 标准 |
|:---|:---|
| 选择 | 灌浆期预先标记。选无病、未倒伏、穗大而整齐的植株的主穗。出现过黑粉病的植株、特别早或特别晚的植株要排除。比普通收获多留一阵，让它完全成熟 |
| 数量 | 需要量的两倍（每1,000㎡ 1-2kg，负担小） |
| 保存 | 带壳，水分12-13%，10℃以下，密封容器，避光。常温密封2-3年 |

&nbsp;&nbsp;&nbsp;每4-5年更新一次种子。种子一定要与食用的粮食分开存放。

## 8. 储存
&nbsp;&nbsp;&nbsp;耐储性为SS。带壳储存，吃多少碾多少。碾过的粟，储存寿命缩短一半以上。

| 项目 | 标准 |
|:---|:---|
| 条件 | 水分13-14%，温度15℃以下（超过25℃虫子繁殖代数加快），周围湿度65%以下，每两个月检查一次（气味、温度、凝露） |
| 容器 | 玻璃瓶、金属罐3年以上 / 陶罐2-3年 / 厚塑料袋1-2年 / 麻袋6个月-1年（籽粒小，会从缝隙漏出） |
| 虫害防治 | 完全密封（装满）、草木灰2-5%、硅藻土每1kg谷物1-3g、艾草·菖蒲·槐树叶、炒盐、木炭、细沙或黄土 |

## 9. 烹调与注意事项
| 碾米（去壳） | 方法 |
|:---|:---|
| 臼中舂 | 放入干籽粒，轻轻多舂几次，每5分钟取出扬一次。关键是不要用力舂 |
| 润水后舂 | 舂前洒少许水，放置20-30分钟。外壳易脱，籽粒不易碎 |
| 其他 | 石磨（抬起上扇慢慢转）、石钵里搓、脚踏碓（省力得多） |

&nbsp;&nbsp;&nbsp;糠不要扔掉，用作牲畜饲料或肥料。磨粉时，炒后再舂更省力也更香，而面粉比籽粒坏得快得多，所以只做一个月吃的量。

| 烹调 | 燃料与要领 |
|:---|:---|
| 面糊粥 | 把面粉调入水中煮5-10分钟。最省燃料 |
| 小米粥 | 多放水煮20分钟。容易消化，适合儿童和病人 |
| 小米饭、掺饭 | 泡30分钟以上，比煮米饭多放一点水。掺入稻米或大麦20-30%，排斥感小，且营养互补 |
| 余热烹调 | 煮10分钟后用稻草或毯子裹住闷40-60分钟。把燃料减少一半以上 |

&nbsp;&nbsp;&nbsp;兼顾储存的加工有：炒面（密封6个月）、饴糖和麦芽糖（阴凉处1年）、小米酒、小米年糕、爆小米花、发酵粥。

| 注意 | 内容 |
|:---|:---|
| 毒性 | 一般摄入量下无毒性 |
| 发霉的 | 霉菌毒素加热也不消失。全部丢弃，也不给牲畜 |
| 膳食纤维 | 每100g含11.4g，非常高。给儿童和老人时与其他谷物混合 |
| 单一饮食 | 赖氨酸缺乏，所以与豆类一起吃 |
| 甲状腺 | 有报告称黍类含微量致甲状腺肿物质，碘摄入极度不足时，不要长期大量食用 |
| 没煮熟 | 淀粉无法消化，所以要充分浸泡并煮熟 |

## 10. 全年作业计划
| 月 | 作业 |
|:---|:---|
| 1-2月 | 检查储存的谷物、确认种子、翻堆肥、发芽试验 |
| 3月 | 收集草木灰、检查排水沟 |
| 4月 | 耕地、起垄、施基肥、把土整细 |
| 5月 | 盐水选、拌草木灰、播春粟（上旬-中旬）。播后务必压实 |
| 6月 | 第1次间苗和除草、播茬粟（中旬-下旬） |
| 7月 | 第2次间苗、培土、维护排水沟、抽穗 |
| 8月 | 灌浆、驱鸟、监测病害。穗子下垂时拉网 |
| 9月 | 收获春粟、预干燥、悬挂晾干。籽粒开始掉落后三天内割完 |
| 10月 | 收获茬粟、脱粒、最后干燥、储存（水分13-14%） |
| 11-12月 | 挑选种子并单独保管、翻压茬子、碾米与磨粉、检查储存 |

> **不能忘记的五件事：排水、早期除草、节制施肥、稍早收获、带壳储存。**
