## はじめに
&nbsp;&nbsp;&nbsp;アワ(粟、Setaria italica)は中国の黄河流域が原産で、コムギとコメが入ってくる前に、東アジアの人々が数千年にわたって主食としてきた穀物です。凶作の年、やせた畑、干ばつのたびに植えられてきた救荒作物です。要水量はイネの8.7%で、総蒸発散量100-200mmで結実し、肥料は窒素・リン酸・カリウムを合わせて1㎡当たり12gと、トウモロコシの3分の1ですみ、植えて65-80日で収穫できます。弱みは、収量(1,000㎡で250kg、1㎡当たり932kcalで、1人の1年分の熱量に約280㎡が必要)、湿害、日陰です。アワはたっぷり食べさせてくれる作物ではなく、ほかの穀物が失敗したときに穴を埋め、やせた端の土地を穀物に変える保険に近い作物です。粒が小さく扱いにくく、その扱いにくさの大半は収穫後に現れます。

## 2. 植物の概要
&nbsp;&nbsp;&nbsp;イネ科エノコログサ属の一年草で、中国の黄河中流が原産です。エノコログサと近縁なので、畑では若い葉が見分けられず、まれに交雑もします。茎は80-160cmでまっすぐ立ち、根は浅く密に広がるため、地力の消耗は少ないものの倒伏に弱いです。花は円錐花序で穂が垂れ、自家受粉が基本です。果実は穎果で、モチ性とウルチ性があります。

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 発芽・幼苗期 | 播種後3-4週間 | 生長が遅く、最も弱い時期。雑草に覆われたり水に浸かったりすると、その年の作が決まる |
| 分げつ・栄養成長期 | 4-8週 | 側茎が分かれる。株数が少し足りなくても自分で埋める |
| 出穂期 | 8-10週 | 穂が葉鞘の外へ出る |
| 登熟・成熟期 | 10-16週 | デンプンが詰まり、穂が垂れる |

| 100g当たりの栄養 | 含量 |
|:---|:---|
| 熱量 | 366-386kcal(乾燥した粒) |
| タンパク質 | 11.4-11.5g(P:E 12.3%で穀物の中では上位) |
| 炭水化物 / 脂肪 | 71.1g / 3-4g |
| 食物繊維 | 11.4g(白米の7倍) |
| カルシウム / 鉄 / カリウム | 100mg / 7.2mg / 300-350mg |
| ビタミンB群 | 白米の3倍程度 |
| 不足するもの | リシン |

## 3. 栽培環境と品種
| 条件 | 最適 | 限界と影響 |
|:---|:---|:---|
| 生育温度 | 25-35℃ | 15-44℃。15℃を下回ると生長が止まり、霜で枯れる |
| 発芽 | 30-31℃ | 最低4-6℃。低いと発芽が遅れ、種子が腐る |
| 登熟期 | 20-32℃ | 過度の高温で粒が実らない |
| 光 | 終日の直射日光 | 6時間以上。40%遮光で収量45% |
| 水 | 合計100-200mm | 80-350mm。穀物の中で最も少ない |
| 土壌 | 砂質-埴壌質、水はけのよい土 | 砂利畑、焼畑まで可能。粘土質では根が傷む。pH 5.5-7.5 |
| 地下水位 | 1m以下 | 高いと根が呼吸できない |

&nbsp;&nbsp;&nbsp;南向きの丘陵地や斜面(水が自然に抜ける)、砂利混じりのやせ地、山間の焼畑がよいです。平地の畑は畝を高く立て、水田からの転換畑、低地、日陰になる場所、北向きは避けます。

| 品種 | 熟期 | 特徴 |
|:---|:---:|:---|
| モチアワ(チャジョ) | - | 粘りがあり、混ぜご飯、餅、水あめ、酒に使う |
| ウルチアワ(メジョ) | - | ご飯、粥、粉に使う。粉に挽きやすく、貯蔵性がよい |
| サムダチャム | 中生 | 1,000㎡当たり224kg。短稈の多収型で、ファングムジョ比12%増収 |
| ファングムジョ | 早生 | 耐倒伏性。霜が早い地域と6月末の播種に適する |
| ジョファンメ(ミリャン5号) | 中生 | ファングムジョ比27%増収。いもち病抵抗性 |

&nbsp;&nbsp;&nbsp;災害が長引くほど重要になるのは、育成品種ではなく、その地域で長く植えられてきた在来種です。アワは自家受粉の作物なので、採種が簡単です。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 土づくり | 20-30cm耕し、畝の高さ20-30cm、畑の周囲と畝間ごとに排水路。粒が小さいので土塊を細かく砕き、播種後に押さえる |
| 施肥 | 1,000㎡当たり窒素・リン酸・カリウム各5-8kg、完熟堆肥1,000kg(全量元肥)。肥料を増やしても収穫は増えず、倒れる |
| 代替資源 | 木灰15-30kg、腐熟堆肥、尿の10倍希釈液(少量)、マメ科の緑肥(すき込んで2-3週間後に播種)、焼畑の灰 |

&nbsp;&nbsp;&nbsp;無投入での収量維持率は45%です。

| 作型 | 播種 | 収穫 |
|:---|:---|:---|
| 春アワ | 5月上旬-中旬 | 9月上旬。最も一般的で収量が多い |
| 後作アワ | 6月中旬-下旬 | 9月下旬-10月。オオムギ・コムギを刈った跡 |
| 晩播 | 6月末まで | 10月初め。限界線で、早生種のみ可能 |

| 播種 | 基準 |
|:---|:---|
| 種子の選別 | 塩水選: 水1Lに塩43g(比重約1.04)の液に種子を入れてかき混ぜ、浮いたものをすくい取り、沈んだものだけを拾う。きれいな水で2、3回すすぎ、日陰で完全に乾かす。塩が貴重なら水選 |
| 種子の消毒 | 木灰をまぶす(最も合う)、50-55℃の湯に10分(60℃を超えると胚が死ぬ)、播種の2-3日前に日なたで2-3時間 |
| 植え方 | 1,000㎡当たり1-2kg、条間60cm、点まき5-10cm、深さ2-3cm。覆土後に足や板で押さえる |

## 5. 水と栽培管理、病害虫
| 時期 | 水の管理 |
|:---|:---|
| 播種-発芽 | 土を乾かさない |
| 幼苗期 | 水をやらない |
| 分げつ・栄養成長期 | 自然の降雨に任せる |
| 出穂・登熟期 | 乾燥すれば補う。収量が決まる時期 |
| 成熟期 | 完全に切る |
| 梅雨 | 水を抜くことが管理のすべて |

> **アワ畑では、水が足りなくて失敗することより、水が抜けなくて失敗することのほうがはるかに多いです。アワは干ばつに最も強く、過湿に最も弱い穀物です。**

| 管理 | 内容 |
|:---|:---|
| 間引き | 本葉2-3枚で一度まばらにし、4-5枚で1株当たり2本を残す。遅れると細くなって倒れる |
| 草取り | 勝負どころ。出芽後2週間で1回目(雑草が指の長さのとき)、4週間で2回目と土寄せ。エノコログサとの区別が難しいので、条まきを守る |
| 土寄せ | 2回目の草取りと同時に、出穂直前にもう一度。倒れたら3、4株ずつまとめて縛って立てる |
| その他 | 分げつは除かない。穂が垂れる頃に、ネットや糸を張って鳥(スズメの群れ)を防ぐ。わらのマルチは雑草と蒸発を減らす |

| 病害虫 | 農薬を使わない対応 |
|:---|:---|
| いもち病(5月下旬-8月下旬、多湿) | 抵抗性品種、窒素過多の抑制、病んだ株の早期除去 |
| べと病、縞葉枯病 | 風通しと排水、病んだ株の焼却、媒介虫と周辺の雑草の管理 |
| 黒穂病(種子伝染) | 塩水選、木灰をまぶす、病んだ穂の焼却 |
| アワノメイガ(7-8月)、アワヨトウ | 被害を受けた茎を除去して焼却、手で捕る、ひどければ早期収穫 |
| アブラムシ、カメムシ(登熟期) | 石けん水、天敵の保護、早朝に手で捕る、周辺の雑草の整理 |
| 鳥 | ネット、糸張り、音の出る装置 |

&nbsp;&nbsp;&nbsp;アワで最大の損失は、病気でも虫でもなく、雑草と鳥です。防除の原則は、排水、健全な種子、適正な施肥、風通し(植え付け間隔と間引き)、衛生(病んだ残渣を片付ける)です。木灰、ニンニクやトウガラシの浸出液、牛乳の5-10倍希釈液も使います。

| 症状 | 原因と処置 |
|:---|:---|
| 全体が黄色っぽく背が低い | 窒素欠乏。腐熟堆肥、尿の希釈液をごく少量 |
| 生育が遅く葉が青黒い | リン酸欠乏。骨粉 |
| 葉脈の間だけが黄色い | マグネシウム欠乏。苦灰石の粉 |
| 新葉が白くなる | 鉄欠乏(たいていアルカリ過多)。木灰を中止 |
| 草丈ばかり伸び濃緑で倒れる | 窒素過剰(欠乏より多い)。窒素を止めて土寄せ |

## 6. 混植と輪作
| 相性 | 作物 |
|:---|:---|
| 非常によい | ダイズ、アズキ、ササゲ(窒素を固定し、アミノ酸組成を補う) |
| よい | ラッカセイ、オオムギ・コムギ・ジャガイモの後の後作アワ |
| 普通 | モロコシ、キビ(栽培法が似ているが病害虫を共有) |
| 悪い | トウモロコシ(背が高くアワに日陰を作る) |

&nbsp;&nbsp;&nbsp;1年目にアワ、2年目にマメ科(ダイズ、アズキ、ササゲ)で窒素を回復させ、3年目に根菜または葉菜、4年目にアワへ戻します。連作への適応性はSSです。

## 7. 収穫、脱穀、採種
| 段階 | 内容 |
|:---|:---|
| 時期 | 早生種は出穂後45日、晩生種は55日。穂が黄褐色になって深く垂れ、爪で押して跡が残らないとき。穂を振って粒が少し落ちるなら、適期を過ぎたばかり |
| 刈り取り | 晴れた日の午前、露が乾いた後に、穂の下20-30cmを鎌で刈る。穂を下向きに持ち、布やむしろの上に置く。病んだ穂は別にする |
| 乾燥 | 予備乾燥2-3日(18-20%) → 5、6穂ずつ束ね、軒下に逆さに吊るして1-2週間(15-16%) → 脱穀 → 仕上げの天日乾燥2-3日(13-14%) → 日陰で1日置いてそろえる |
| 水分の判定 | 噛むとパリッと割れて粉が残る、塩試験、一握りを握って開くと滑るように散る、両手に入れて振ると砂の流れる音、瓶に密閉して1日置いても曇らない |
| 脱穀 | 袋の中で打つ(アワに最も合う)、むしろの上で殻竿を打つ、踏む、桶の中でこすり合わせる、溝を彫った板にこすりつける、手でしごく(種子用) |
| 殻 | 秒速2-3mの弱い風に流す、箕であおる、うちわであおぐ、目の細かいふるい。粒が軽く、風の調整が難しい |

| 採種 | 基準 |
|:---|:---|
| 選抜 | 登熟期に前もって印を付ける。病気がなく倒れておらず、穂が大きくそろった株の主穂。黒穂病が出た株や、特に早い・遅い株は除く。通常の収穫より少し置いて完全に熟させる |
| 量 | 必要量の2倍(1,000㎡当たり1-2kgなので負担が小さい) |
| 保管 | 殻のまま、水分12-13%、10℃以下、密閉容器、遮光。常温の密閉で2-3年 |

&nbsp;&nbsp;&nbsp;4-5年ごとに種子を更新します。種子は食用の穀物と必ず別にしておきます。

## 8. 貯蔵
&nbsp;&nbsp;&nbsp;貯蔵性はSSです。殻のまま貯蔵し、食べる分だけ精白します。精白したアワは、貯蔵寿命が半分以下に縮みます。

| 項目 | 基準 |
|:---|:---|
| 条件 | 水分13-14%、温度15℃以下(25℃を超えると虫の世代交代が早まる)、周囲の湿度65%以下、2か月ごとに点検(臭い、温かさ、結露) |
| 容器 | ガラス瓶、金属缶3年以上 / 壺2-3年 / 厚手のビニール1-2年 / 麻袋6か月-1年(粒が小さく隙間から漏れる) |
| 虫の防除 | 完全密閉(いっぱいに満たす)、木灰2-5%、珪藻土は穀物1kgに1-3g、ヨモギ・ショウブ・エンジュの葉、炒り塩、炭、細かい砂や黄土 |

## 9. 調理と注意事項
| 精白(殻むき) | 方法 |
|:---|:---|
| 臼で搗く | 乾燥した粒を入れて軽く何度も搗き、5分ごとに取り出して箕であおる。強く搗かないことが要点 |
| 水を含ませて搗く | 搗く前に水を少しかけて20-30分置く。殻がよくむけ、粒が割れにくい |
| その他 | 石臼(上石を浮かせてゆっくり)、石鉢でこする、踏み臼(力がはるかに少なくてすむ) |

&nbsp;&nbsp;&nbsp;ぬかは捨てずに、家畜の餌や肥料にします。製粉は、炒ってから搗くと楽で香ばしく、粉は粒よりはるかに早く傷むので、1か月に食べる分だけ作ります。

| 調理 | 燃料とコツ |
|:---|:---|
| 粉がゆ | 粉を水に溶いて5-10分。燃料が最も少なくてすむ |
| アワ粥 | 水をたっぷり使って20分。消化しやすく、子どもや病人に向く |
| アワご飯、混ぜご飯 | 30分以上浸し、コメより水を少し多めに。コメやオオムギに20-30%混ぜると抵抗感が少なく、栄養が補われる |
| 余熱調理 | 10分煮てから、わらや毛布でくるんで40-60分。燃料を半分以下に減らす |

&nbsp;&nbsp;&nbsp;貯蔵を兼ねた加工には、炒り粉(密閉で6か月)、水あめ・飴(涼しい所で1年)、アワの酒、アワ餅、ポン菓子、発酵粥があります。

| 注意 | 内容 |
|:---|:---|
| 毒性 | 通常の摂取量では毒性なし |
| カビが生えたもの | カビ毒は加熱しても消えない。全量廃棄し、家畜にも与えない |
| 食物繊維 | 100g当たり11.4gと非常に高い。子どもや高齢者には他の穀物と混ぜて食べさせる |
| 単一の食事 | リシンが不足するので、マメ類と一緒に食べる |
| 甲状腺 | キビ類に微量のゴイトロゲンがあるとの報告があり、ヨウ素の摂取が極端に不足した状態で長期間大量に食べることは控える |
| 加熱不足 | デンプンが消化されないので、十分に浸して加熱する |

## 10. 年間の作業予定
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵した穀物の点検、種子の確認、堆肥の切り返し、発芽試験 |
| 3月 | 木灰を集める、排水路の点検 |
| 4月 | 耕起、畝づくり、元肥、土を細かくならす |
| 5月 | 塩水選、木灰をまぶす、春アワの播種(上旬-中旬)。播種後は必ず押さえる |
| 6月 | 1回目の間引きと草取り、後作アワの播種(中旬-下旬) |
| 7月 | 2回目の間引き、土寄せ、排水路の手入れ、出穂 |
| 8月 | 登熟、鳥追い、病害の監視。穂が垂れたらネットを張る |
| 9月 | 春アワの収穫、予備乾燥、吊るし乾燥。粒が落ち始めたら3日以内に刈る |
| 10月 | 後作アワの収穫、脱穀、仕上げの乾燥、貯蔵(水分13-14%) |
| 11-12月 | 種子の選別と別保管、切り株のすき込み、精白と製粉、貯蔵の点検 |

> **忘れてはならない5つ: 排水、初期の草取り、肥料の節制、少し早めの収穫、殻のままの貯蔵。**
