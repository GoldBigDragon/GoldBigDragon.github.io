## 12. 收获与脱粒

### 12-1. 时机判断

| 标准 | 内容 | 判定 |
|---|---|---|
| 早熟品种 | 抽穗后45天 | 是大致的标准 |
| 晚熟品种 | 抽穗后55天 | 需核对品种说明 |
| 穗色 | 穗变成黄褐色并深深低垂 | 接近成熟 |
| 籽粒硬度 | 用指甲按压不留痕迹 | 已完全成熟 |
| 籽粒断面 | 掰开后内部呈白色且坚实 | 灌浆已完成 |
| 脱粒 | 摇动穗时会掉落少量籽粒 | 刚过最佳时期，需赶紧收获 |
| 天气 | 晴天持续2-3天后 | 水分低，容易晒干 |

&nbsp;&nbsp;&nbsp;粟的收获适期很窄。太早收，籽粒水分多，晒干过程中会皱缩，碾米时容易碎。太晚收，穗上的籽粒会自行脱落散在地上。籽粒小，一旦落地就无法捡回，损失也就此定了。诀窍是每天巡田，用手摇一摇穗，一旦开始有几粒掉落，就要在当天起三天之内收割完。

> **谷物可以稍微早收再在室内晾干，但因收晚而落地的籽粒是找不回来的。**

### 12-2. 收获要领

| 顺序 | 内容 | 原因 |
|---|---|---|
| 1 | 选晴天上午，露水干后才开始 | 潮湿的穗是霉变的起点 |
| 2 | 在穗下20-30cm处用镰刀割断 | 留有秸秆才方便捆扎悬挂 |
| 3 | 割的时候让穗朝下 | 晃动时籽粒会掉落 |
| 4 | 割下的穗当场放在布或草席上 | 能收回散落在地上的籽粒 |
| 5 | 把病穗和健康穗分开 | 混放会导致霉菌传播 |
| 6 | 每五六穗一束，倒挂在屋檐下 | 通风的姿势决定晒干的效果 |

&nbsp;&nbsp;&nbsp;割粟时最好在地上铺一层布再在上面作业。籽粒小，哪怕只挥一次镰刀也会掉落不少，铺上布就能把它们收回来。看似细微的差别，其实相当于5%到10%的收成。用旧衣服或塑料布碎片都可以。

### 12-3. 谷物晒干——降到水分13-14%

&nbsp;&nbsp;&nbsp;谷物贮藏的一切都取决于水分。水分超过15%霉菌就会滋生，降到13%以下霉菌和害虫几乎都会停止活动。刚割下的粟水分为20-25%，把它降到13-14%是收获后唯一也是最重要的课题。

| 阶段 | 方法 | 时长 | 达到的水分 |
|---|---|---|---|
| 1. 预晒 | 把割下的穗束立在田里或院子里 | 2-3天 | 18-20% |
| 2. 悬挂晾晒 | 倒挂在屋檐下或棚屋里 | 1-2周 | 15-16% |
| 3. 脱粒 | 充分晒干后脱粒 | 1天 | - |
| 4. 收尾晒干 | 摊在草席或布上晒太阳 | 2-3天 | 13-14% |
| 5. 静置均质 | 在阴凉处放置一天使水分均匀 | 1天 | 均匀化 |

&nbsp;&nbsp;&nbsp;晒太阳的原则对所有谷物都一样。第一，不要直接摊在地上，土壤返上来的潮气会再次弄湿下层，草席、布或木板，铺一层都行。第二，堆放厚度不超过3-5cm，每天翻动三四次。第三，太阳偏西后要收起来或盖住，夜里沾了露水，白天蒸出去的水分又会回来。第四，不能急着求快，表面干了而内部水分被闷住，日后照样会长霉。

&nbsp;&nbsp;&nbsp;粟籽粒小，容易被风吹散。晒的时候如果风大，就要用稀纹布盖住，或者选挡风的地方。被吹走的籽粒是找不回来的。

&nbsp;&nbsp;&nbsp;不用仪器也有办法估算水分，熟练之后相当准确。

| 方法 | 步骤 | 判定 |
|---|---|---|
| 咬齿测试 | 用臼齿咬一下籽粒 | 若"啪"地裂开并出粉，说明是13-14%；若被压扁，说明还湿 |
| 盐瓶测试 | 把一勺干盐和一把谷物放进瓶中摇晃，静置15分钟 | 若盐粘在瓶壁上，说明水分偏高 |
| 手感测试 | 抓一把再松开 | 顺滑散开的是干的，结成团的是湿的 |
| 声音测试 | 放在双手里摇晃 | 若发出流沙般的声音，说明已经干了 |
| 玻璃瓶测试 | 装半瓶密封放置一天 | 若瓶壁内侧起雾，说明还需要再晒 |

&nbsp;&nbsp;&nbsp;玻璃瓶测试是入库贮藏前最后一道确认，也最为可靠。在密封的瓶中，谷物和空气会达到水分平衡：一旦水分超过14%，瓶内湿度就会超过70%，在气温下降的凌晨瓶壁就会起雾。在有凉夜的秋天，这个现象会更明显。

&nbsp;&nbsp;&nbsp;也有连日下雨、无法晒太阳的年份。这时可以摊在灶台或炉子上方的阁楼里，或暖炕里离炕头较远、温度较缓和的一侧，薄薄铺开。要花上几天才能干，但温度不能超过50℃。超过这个温度，就不能再留作种子，口感也会变差。用手摸感觉温热即可，如果觉得烫，就已经太高了。

### 12-4. 脱粒——不用工具的方法

&nbsp;&nbsp;&nbsp;粟是脱粒相对容易的谷物，只要晒得够干，籽粒就容易从穗上脱落。不过籽粒小，容易四处飞溅，还会混入不少糠皮和碎屑。诀窍是把作业空间围起来。

| 方法 | 步骤 | 规模 | 备注 |
|---|---|---|---|
| 手捋脱粒 | 抓住穗秆，用戴手套的手捋下籽粒 | 少量 | 损耗最少，用于留种 |
| 装袋敲打 | 把穗装进结实的袋子，连袋子一起摔向地面 | 中等 | 最适合粟，籽粒不会飞散 |
| 敲打脱粒 | 把穗摊在草席上，用连枷或木棍敲打 | 大量 | 需用布把四周围起来操作 |
| 踩踏脱粒 | 摊在草席上用脚搓踩 | 大量 | 省力 |
| 桶内搓揉 | 把穗放入大桶，用棍子搅动搓揉 | 中等 | 籽粒不会散落 |
| 搓衣板脱粒 | 把穗按在刻有沟纹的板上摩擦 | 少量 | 可以在木板上刻槽自制 |

&nbsp;&nbsp;&nbsp;装袋敲打这种方法特别适合粟。籽粒小，敲打时最容易四处飞溅，而袋子能把它们全部接住。把晒干的穗装进结实的麻袋或厚塑料袋里，装到约三分之一满，扎紧口后，连袋子一起提起来摔向圆木或平整的石头。摔上二十来次打开一看，大部分籽粒都已经脱落。

&nbsp;&nbsp;&nbsp;连枷可以自己做。在长柄的一端用皮带或结实的粗绳松松地系上一根短棒即可。挥动长柄时，末端的短棒会旋转起来敲打谷物，比单纯用臂力敲打效率高得多，也不容易累。

### 12-5. 扬去秕壳——风车与簸箕

&nbsp;&nbsp;&nbsp;脱粒后的粟里混有穗屑、叶片碎片、灰尘和秕壳。如果就这样贮藏起来，秕壳上附着的水分和虫卵会毁掉整批贮粮。用风扬去杂质是必不可少的一步。

| 方法 | 步骤 | 条件 |
|---|---|---|
| 顺风扬撒 | 在有风的日子从高处缓缓倒下 | 风速2-3米/秒。粟粒轻，风大了连谷粒都会被吹跑 |
| 簸扬 | 装入簸箕，前推后拉使谷物在空中扬起 | 没有风也可以做 |
| 扇风扬谷 | 一人缓缓倾倒，另一人用扇子送风 | 可以调节风力大小，适合粟 |
| 筛选 | 用粗筛筛掉大颗秕壳，用细筛筛掉灰尘 | 粟粒小，筛孔需要细密 |
| 水选 | 倒入水中捞出漂浮的秕壳 | 之后必须立刻重新晒干 |

&nbsp;&nbsp;&nbsp;粟粒轻，风力不好把握。像高粱或玉米那样用大风扬撒，会连谷粒一起吹走。因此比起自然风，像扇风那样能调节强弱的方法更好，而簸扬最为可靠。簸扬的要领不是上下抖动，而是前推后拉，让谷物在空中短暂扬起：在悬空的瞬间，轻的部分会落后聚到前边，再用手把它扫出去。这是半天就能学会、一辈子都用得上的技术。

## 13. 留种

### 13-1. 留种个体的选择

| 标准 | 内容 | 原因 |
|---|---|---|
| 选择时期 | 灌浆期巡田提前做标记 | 收获后就分不清是哪株的了 |
| 个体条件 | 无病症、未倒伏、穗大而整齐 | 性状会遗传给下一代 |
| 穗的位置 | 植株上最粗壮的主穗 | 侧穗成熟不均匀 |
| 收获时间 | 比一般收获稍晚，让其完全成熟 | 未成熟种子发芽率会下降 |
| 排除对象 | 出现黑穗病的株，明显偏晚或偏早的株 | 防止种子传病及性状混乱 |
| 数量 | 需求量的两倍 | 每1,000㎡只需1-2kg，负担不大 |

&nbsp;&nbsp;&nbsp;粟是自花授粉作物，留种非常容易。即便附近有其他品种，混杂的概率也很低，留下的种子大多和母株性状相同。从灾害应对的角度看，这是一大优点：不像玉米那样一代就会性状崩溃，也不像马铃薯那样需要以活体状态越冬。

&nbsp;&nbsp;&nbsp;不过，建议每4-5年更新一次种子是有原因的。如果留种时敷衍了事，用的就是从整块地里随意采下的种子，其中会混入晚熟、抗病性差或穗小个体的种子。这种情况年年累积，几年后品种的性状就会变得模糊。如果严格挑选留种个体并单独管理，就能大大延缓这种退化。

&nbsp;&nbsp;&nbsp;与狗尾草的杂交也偶尔发生。地边的狗尾草必须在抽穗前拔掉。杂交个体会继承容易脱粒的性状，导致收获时损失增大。

### 13-2. 种子保存

| 条件 | 标准 | 原因 |
|---|---|---|
| 水分 | 12-13%，比食用的更干一些 | 种子水分越低，寿命越长 |
| 温度 | 10℃以下最为理想 | 温度高会因呼吸作用消耗胚 |
| 容器 | 玻璃瓶、金属罐、陶罐 | 能同时防潮防虫 |
| 光照 | 完全遮蔽 | 热和光会降低发芽力 |
| 形态 | 带壳保存 | 碾过的种子寿命要短得多 |
| 寿命 | 常温密封2-3年 | 条件好的话能保存更久 |

&nbsp;&nbsp;&nbsp;种子必须和食用谷物分开放置。冬天越深、吃的越少，人就越容易动种子的念头，一旦动了，来年就没有粮种可种了。把它放在物理上不同的地方、不同的容器里并做好标记，比依赖人的自制力更可靠。

### 13-3. 发芽试验

&nbsp;&nbsp;&nbsp;播种陈种之前要先确认发芽力。用湿布包50粒种子放在温暖处，等待5天。粟籽粒小，只用20粒误差太大，所以要用50粒。50粒中若有40粒以上发芽，可直接使用；30到40粒之间，就要增加播种量；低于30粒，就必须另外找新种子。

## 14. 毒性与注意事项

### 14-1. 籽粒的毒性——无

&nbsp;&nbsp;&nbsp;粟在一般食用量下没有毒性。与高粱不同，它的叶片中不含足以构成问题的氰苷，籽粒里也没有需要去除的毒性成分。碾米、淘洗后煮熟即可安全食用。灾害情形下不需要特殊的去毒处理，这是一个实际的优点。

### 14-2. 需要注意的情况

| 项目 | 内容 | 处理方法 |
|---|---|---|
| 已发霉的 | 霉菌毒素即便加热也不会消失 | 全部丢弃，也不能喂给家畜 |
| 膳食纤维过多 | 每100g含11.4g，非常高 | 给儿童和老弱者食用时应与其他谷物混合 |
| 单一饮食 | 赖氨酸不足 | 应搭配豆类一起食用 |
| 甲状腺 | 有报告称杂粮类中含有微量致甲状腺肿物质 | 在正常摄入量下不会构成问题 |
| 未煮熟的 | 淀粉无法被消化 | 应充分泡透后煮熟 |

> **已经发霉的谷物，无论洗、煮还是炒，都不会因此变安全。丢弃是唯一的办法。**

&nbsp;&nbsp;&nbsp;膳食纤维的问题在灾害情形下会真正变得重要。粟米饭饱腹感强，但正因如此其中不易消化的成分也多，对急需热量的人来说可能反而不利。尤其是幼儿胃容量小，肚子饱了的时候还没能摄入足够的热量。给孩子吃粟时，最好和其他谷物混合，并尽量添加一点油脂。

&nbsp;&nbsp;&nbsp;致甲状腺肿物质是已知在各种杂粮中普遍存在的微量成分，有报告指出，在碘摄入极度不足的状态下长期大量食用，可能会影响甲状腺功能。在像韩国这样能从海藻和食盐中获取碘的环境里，这并不是现实的风险。不过，如果饮食长年只依赖粟这一种作物，储备一些裙带菜或海苔之类的海藻，出于多种理由都是可取的做法。
