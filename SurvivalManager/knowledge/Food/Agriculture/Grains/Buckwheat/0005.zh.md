## 12. 收获与脱粒

### 12-1. 时期判断——75%至80%原则

| 标准 | 内容 | 判定 |
|---|---|---|
| 成熟比例 | 籽粒75-80%变黑成熟时 | 收获适期 |
| 天数 | 播种后60-75天 | 因品种和当年气温而异 |
| 种子颜色 | 由绿色经褐色变为黑色 | 从下部开始依次成熟 |
| 种子硬度 | 用指甲按压不凹陷 | 已完全成熟 |
| 含水率 | 16%以下 | 收获标准 |
| 落粒 | 用手一撸黑色种子便容易脱落 | 需抓紧时间 |
| 天气 | 连续晴天之后 | 湿着收割难以晒干 |

&nbsp;&nbsp;&nbsp;荞麦收获的难处来自无限生长习性。同一株上，下部的种子已经变黑即将脱落，上部却仍在开花。既不能等全部成熟，过早收割上部又会全部成为秕粒。所以标准定为比例：75-80%变黑成熟时损失最小。

&nbsp;&nbsp;&nbsp;要做出这一判断，需要走遍田地查看植株。挑选几株数种子，估算黑色与非黑色的比例。熟练后只看田地整体颜色也能判断。荞麦田整体开始泛褐色，就是收获的时候了。

> **荞麦最常见的损失，是等待成熟过程中下部种子全部脱落。75%成熟时就应收割。**

&nbsp;&nbsp;&nbsp;还要留意天气。在下雨或潮湿的日子收获，水分偏高难以晒干，期间还会长霉。若有降雨预报，即使稍早也应收割。反之若预计晴天会持续数日，晚一两天也无妨。

### 12-2. 收获要领

| 顺序 | 内容 | 原因 |
|---|---|---|
| 1 | 在露水未干的清晨收割 | 潮湿时种子不易脱落 |
| 2 | 用镰刀从根部割下 | 茎秆柔软，易于割断 |
| 3 | 收割时不要晃动，轻轻放倒 | 荞麦极易落粒 |
| 4 | 在地上铺布或草席，放在其上 | 便于回收脱落的种子 |
| 5 | 捆成把 | 捆得太大内部不易晒干 |
| 6 | 在田间或场院晾晒3-5天 | 这一过程中上部的未熟粒也会成熟 |
| 7 | 不要淋雨 | 淋湿会引发霉变和穗发芽 |

&nbsp;&nbsp;&nbsp;清晨收割是荞麦特有的要领。荞麦种子极易脱落，沾着露水时不易脱落，太阳升起晒干后，镰刀一碰就哗哗往下掉。这一差异能左右10%以上的收获量。

&nbsp;&nbsp;&nbsp;收割后晾晒3-5天的过程很重要。这段时间里茎秆中残留的养分会转移到未熟种子中，使上部种子也在一定程度上成熟。若刚割下就立即脱粒，尚未成熟的种子会直接变成秕粒。这几天是为了获得后熟效果。

### 12-3. 谷物干燥——降至含水率13-14%

&nbsp;&nbsp;&nbsp;谷物贮藏的一切都取决于水分。含水率超过15%就会长霉，降到13%以下霉菌和虫害几乎都会停止活动。荞麦收获时的含水率在16%上下，虽然起点低于其他谷物，但仍需从这里进一步降到13-14%。

| 阶段 | 方法 | 时长 | 目标含水率 |
|---|---|---|---|
| 1. 晾晒 | 将割下的植株摊开或立放在田间或场院晒干 | 3-5天 | 15-16% |
| 2. 脱粒 | 充分晒干后脱粒 | 1天 | - |
| 3. 后期干燥 | 摊在草席或布上晒干 | 2-3天 | 13-14% |
| 4. 回潮均质 | 在阴凉处放置一天左右使水分均匀 | 1天 | 均匀化 |

&nbsp;&nbsp;&nbsp;晒干的原则对各种谷物都一样。第一，不直接摊在地面上，因为地面的湿气会重新浸湿下层。第二，堆放厚度不超过3-5cm，每天翻动三四次。第三，太阳西斜时收起或加盖，夜间受露水打湿，白天蒸发的水分又会回渗。第四，不能急于求成，若只是表面干燥而内部水分被封住，之后会长霉。

&nbsp;&nbsp;&nbsp;荞麦还有其特有的注意事项。荞麦籽粒呈三角形容易滚动，风一吹就散开，外皮光滑，在斜面上还会滑落。最好在晾晒场地周围围出边沿，或把草席边缘折起。

&nbsp;&nbsp;&nbsp;没有计量仪器时，也有估测水分的方法。

| 方法 | 步骤 | 判定 |
|---|---|---|
| 咬粒 | 剥皮后用臼齿咬 | 啪地裂开并掉粉即为13-14% |
| 听皮声 | 抓一把互相搓揉 | 外皮沙沙作响并碎裂即为已干 |
| 盐瓶试验 | 将一勺干盐和一把谷物放入瓶中摇晃后静置15分钟 | 盐粘在瓶壁上说明水分偏高 |
| 手感 | 抓一把再松开 | 若如流沙般散开即为已干 |
| 瓶内试验 | 玻璃瓶装半瓶密封放置一天 | 瓶内壁起雾说明还需继续干燥 |

&nbsp;&nbsp;&nbsp;使用火力烘干时不要超过50度。超过这个温度就不能再用作种子，而荞麦本身种子寿命就短，对此更为敏感。只烘到用手触摸感觉温热的程度即可。

### 12-4. 脱粒——无需工具的方法

&nbsp;&nbsp;&nbsp;荞麦是脱粒非常容易的作物。种子松松地附着在茎秆上，一旦干燥，轻微震动就会脱落。问题反而在于太容易脱落而造成损失。

| 方法 | 步骤 | 规模 | 备注 |
|---|---|---|---|
| 用手撸 | 抓住茎秆用手撸下 | 少量 | 损失最少，用于种子 |
| 敲打 | 摊在草席上，用棍棒或连枷轻轻敲打 | 大量 | 最常用。无需用力敲打 |
| 装袋摔打 | 装入袋中连袋摔在地上 | 中等 | 种子不会溅出 |
| 踩踏 | 摊在草席上用脚踩 | 大量 | 更省力 |
| 摇晃 | 倒提着捆把在桶中摇晃 | 中等 | 特别适合荞麦 |

&nbsp;&nbsp;&nbsp;荞麦脱粒的要领是不要用力敲打。种子本就极易脱落，轻敲即可，用力敲打会打碎三角形外壳，损伤籽粒并增加秕粒。只需倒提捆把在大桶中摇晃，就能落下相当数量。

&nbsp;&nbsp;&nbsp;脱粒后的茎叶可直接铺在田里或用作堆肥。荞麦茎秆柔软分解快，能把荞麦从土壤中吸取的磷和钾归还给土地。

### 12-5. 扬去秕粒

| 方法 | 步骤 | 条件 |
|---|---|---|
| 顺风扬撒 | 在有风的日子从高处缓缓倒下 | 荞麦种子轻，宜用微风 |
| 簸箕扬 | 装入簸箕前推后拉使其扬起 | 最为可靠 |
| 扇风 | 一人倾倒，另一人扇风 | 可调节风力强弱 |
| 过筛 | 用粗筛分出茎秆碎片，用细筛分出碎屑 | 荞麦籽粒大，过筛容易 |
| 水选 | 倒入水中，捞出漂浮的秕粒 | 之后必须立即重新晒干 |

&nbsp;&nbsp;&nbsp;荞麦种子偏轻，需特别注意风力调节。风太大会把饱满的种子也一起吹走。像扇风这类可调节强弱的方法，或簸箕扬法，更为安全。

### 12-6. 脱壳——剥去三角形外壳

&nbsp;&nbsp;&nbsp;荞麦在脱粒之后还有一道工序，就是脱壳，即剥去三角形的坚硬外壳。这层壳硬得无法食用，不剥去就连磨粉也做不到。

| 方法 | 工具 | 步骤 | 备注 |
|---|---|---|---|
| 石臼舂 | 石臼与杵 | 轻舂后过筛，反复进行 | 用力舂会连籽粒一起打碎 |
| 转动石磨 | 石磨 | 将上扇抬起至籽粒大小的间隙后转动 | 只碎外壳，籽粒完好 |
| 湿润后舂 | 石臼 | 略洒水静置30分钟后再舂 | 外壳容易脱落 |
| 炒后舂 | 锅与石臼 | 用小火炒至外壳酥脆后再舂 | 最适合荞麦 |
| 石臼搓磨 | 凹石与圆石 | 用手搓磨使外壳裂开 | 适合少量处理 |
| 木板间搓磨 | 两块木板 | 夹在中间按压搓磨 | 制作简单 |

&nbsp;&nbsp;&nbsp;荞麦脱壳的要领与其他谷物相反。外壳不是紧贴籽粒，而是松松地套在外面，因此不是靠搓磨剥离，而要靠打碎打开。所以将石磨上扇抬起至籽粒直径大小的间隙再转动，就能只打碎外壳而籽粒完好无损。这是最有效的方法，商用荞麦脱壳机也是基于同样的原理运作。

&nbsp;&nbsp;&nbsp;炒后再舂的方法也很有效。用小火炒几分钟，外壳中的水分蒸发变得酥脆，更容易破碎，同时还能激发荞麦特有的焦香。不过炒过的荞麦不能再用作种子，留种用的部分要另外留出。

&nbsp;&nbsp;&nbsp;剥下的外壳不要丢弃。荞麦壳轻盈、透气性好又不易吸潮，长期以来被用作枕芯。也可用作隔热材料，燃烧后是很好的引火物，灰烬还能作肥料。对谷物本身产量偏低的荞麦而言，副产物的用处相对更大。

## 13. 留种

### 13-1. 自交不亲和带来的限制

&nbsp;&nbsp;&nbsp;荞麦留种比本文其他作物更为棘手，因为它是自交不亲和的异花授粉作物。

| 项目 | 内容 | 含义 |
|---|---|---|
| 受精方式 | 长柱花与短柱花须互相接受对方的花粉 | 单株无法结实 |
| 媒介 | 由蜜蜂等昆虫传粉 | 没有昆虫就不结实 |
| 隔离 | 须与其他品种分开 | 套袋无效 |
| 群体维持 | 须从多个植株均匀采集 | 不能只从一株采集 |

&nbsp;&nbsp;&nbsp;其他作物常用的套袋法对荞麦不起作用。因为套袋后只有同一花型相遇，无法受精。若能挑选长柱花与短柱花人工配对，理论上可行，但并不现实。因此荞麦品种的维持依赖距离隔离和花期隔离。

| 方法 | 内容 | 效果 |
|---|---|---|
| 距离隔离 | 与其他品种至少相距500米 | 考虑蜜蜂飞行距离，留有余量 |
| 花期隔离 | 使开花期错开3周以上 | 夏荞与秋荞自然会错开 |
| 单一品种 | 同一地区只种一个品种 | 最为现实 |
| 利用苦荞 | 可自花授粉 | 无需隔离 |

&nbsp;&nbsp;&nbsp;在狭小地区，最现实的方法是只种一个品种。即使同时种植夏荞和秋荞，开花期也会自然错开而不会混杂。问题在于邻家种植其他品种，这是个人无法控制的。若在灾害情形下村落能就统一品种达成共识，那是最好的解决办法。

### 13-2. 留种植株的选拔与保存

| 标准 | 内容 | 原因 |
|---|---|---|
| 植株选拔 | 选无病征、未倒伏且结实多的植株 | 性状得以延续 |
| 多株采集 | 至少从30株以上均匀采集 | 异花授粉作物需要多样性 |
| 收获时机 | 比一般收获稍晚，使其充分成熟 | 未熟种子发芽率低 |
| 下部种子 | 使用先成熟的下部种子 | 最为饱满 |
| 形态 | 务必带壳保存 | 脱壳后寿命会急剧缩短 |
| 水分 | 12-13% | 种子需更干燥一些 |
| 寿命 | 常温下1-2年 | 短于其他谷物 |
| 数量 | 所需量的两倍以上 | 需考虑发芽率下降 |

> **荞麦种子从大约8个月起发芽率开始下降。不能像其他谷物那样储存好几年份，须每年重新留种。**

&nbsp;&nbsp;&nbsp;种子寿命C是荞麦实质上的弱点。高粱或粟可保存2-3年，条件好时更久，荞麦却只有1-2年。若遇歉收导致某年留种失败，品系可能就此断绝。应对办法有两个：第一，每年必须留种；第二，保存在最阴凉干燥的地方。温度每降低10℃，种子寿命大约延长一倍。

&nbsp;&nbsp;&nbsp;荞麦所需种子量少是一个安慰。点播的话，每1,000㎡只需0.5-2kg即可。多留出所需量的两三倍，负担也不算大。

### 13-3. 发芽试验

&nbsp;&nbsp;&nbsp;荞麦的发芽试验尤为重要，因为种子寿命短，仅过一年发芽率就会大幅变化。用湿布包50粒种子放在温暖处，等待3-4天。荞麦发芽快，判定也比其他谷物更早。50粒中40粒以上发芽即可照常使用，30-40粒则将播种量增加到1.5倍，不足30粒就须获取新种子。

## 14. 毒性与注意事项

### 14-1. 荞麦过敏——最重要的注意事项

&nbsp;&nbsp;&nbsp;荞麦本身没有毒性，但荞麦有一项其他作物没有的风险，就是过敏。

| 项目 | 内容 |
|---|---|
| 原因 | 荞麦蛋白质的一部分是很强的过敏原 |
| 发生率 | 并不常见，但在韩国、日本、中国相对报告较多 |
| 症状 | 荨麻疹、口腔和咽喉发痒、腹痛、呕吐、呼吸困难 |
| 严重时 | 过敏性休克。血压下降、气道阻塞，危及生命 |
| 发作速度 | 食用后数分钟到数十分钟内出现 |
| 加热 | 即使加热，致敏性也几乎不减 |
| 微量 | 极少量也可能引发反应 |
| 接触 | 即便不食用，吸入荞麦粉或使用荞麦壳枕头也可能引发反应 |

> **荞麦过敏可能发展为过敏性休克。在医疗中断的灾害状况下，这是实实在在的生命危险。**

&nbsp;&nbsp;&nbsp;这一问题在灾害状况下的分量与平时不同。平时可在急诊室获得处置，但在医院无法运作的情况下，过敏性休克几乎无计可施。因此需要预防性的应对。

| 情况 | 对策 |
|---|---|
| 初次食用者 | 从极少量开始，观察反应后数日内逐渐增加 |
| 幼儿 | 尤须谨慎，最初从不到一勺开始 |
| 有过敏史者 | 不要食用，改用其他作物替代 |
| 出现反应时 | 立即停止，不再尝试 |
| 烹饪用具 | 若有过敏者，应单独使用器具 |
| 荞麦壳枕头 | 不要放在过敏者附近 |

&nbsp;&nbsp;&nbsp;若以社区为单位分配粮食，最好提前了解谁对荞麦有反应。误食混有荞麦面或荞麦凉粉的食物而引发事故的情况确实存在。含荞麦的食物最好加以标示或单独存放。

### 14-2. 苦荞中的芦丁

| 项目 | 内容 |
|---|---|
| 含量 | 是普通荞麦的70-100倍 |
| 安全性 | 一般食用量下没有问题 |
| 味道 | 芦丁分解后会产生强烈苦味 |
| 注意 | 服用抗凝血药物者，大量摄入需谨慎 |
| 处理 | 充分去壳并多次漂洗可减轻苦味 |

&nbsp;&nbsp;&nbsp;苦荞中的芦丁与其说是毒性成分，不如说是药理作用较强的成分。它有增强毛细血管、降低血管通透性的作用，平时是有益的。不过若正在服用与血液凝固相关的药物，可能存在相互作用，大量摄入以避免为宜。灾害状况下持续服用此类药物的情况应属少见，但仍应留意记录。

### 14-3. 其他注意事项

| 项目 | 内容 | 对策 |
|---|---|---|
| 已发霉的 | 霉菌毒素不会因加热而消失 | 全部丢弃 |
| 荞麦光敏症（fagopyrism） | 荞麦中的荞麦醌（fagopyrin）成分可能引发光敏反应 | 多发生于家畜大量食用荞麦叶后又长时间受日晒 |
| 外壳 | 无法消化，卡在口中 | 必须去壳后食用 |
| 加热不足的 | 淀粉无法消化 | 须充分加热 |
| 一般食用 | 安全 | 只要不过敏就没有问题 |

&nbsp;&nbsp;&nbsp;荞麦光敏症主要出现在家畜身上。荞麦叶茎中所含的荞麦醌这种色素进入体内后，皮肤会对阳光变得敏感，在白毛部位出现炎症和溃疡。给家畜大量喂食荞麦叶后又让其整日晒太阳，就可能发生。给家畜喂荞麦残余物时，只要限制用量并提供阴凉处，就不会有问题。人食用的籽粒中几乎不含这种成分。
