## 7. 水分管理

### 7-1. 各生育阶段的标准

| 时期 | 管理 | 原因 |
|---|---|---|
| 从播种到发芽 | 保持土壤不干燥 | 发芽快，3-4天就会出苗 |
| 生育初期 | 防止过湿是关键 | 这一时期的湿害是最常见的失败原因 |
| 开花期 | 需要充足的水分 | 从发芽到开花须有约70mm的降水 |
| 灌浆期 | 宜少，从盛花到成熟20mm即可 | 过湿会导致穗发芽和品质下降 |
| 成熟期 | 完全停止浇水 | 若淋雨籽粒会脱落并发芽 |

&nbsp;&nbsp;&nbsp;荞麦水分管理的特殊之处，在于需求量按阶段有明显分化。从发芽到开花需要70mm，而盛花后到成熟只需20mm，呈现前多后少的结构。它之所以能靠总共250mm这么少的水完成结实，也是因为后段需求量小。

&nbsp;&nbsp;&nbsp;荞麦最重要的水分管理不是浇水，而是排水。荞麦在播种后不久及生育初期对湿害极为敏感。刚播下的种子一旦被水淹，就会直接腐烂；长出子叶的幼苗哪怕只被水淹三天也会死亡。播种前花半天时间开好排水沟，决定着荞麦种植的成败。

### 7-2. 缺水与积水的症状

| 症状 | 原因 | 判断与处理 |
|---|---|---|
| 叶片萎蔫，茎秆下垂 | 缺水 | 若处于开花期应及时补水 |
| 开花很多但不结籽 | 高温、缺水，或传粉昆虫不足 | 多种原因叠加，后文详述 |
| 籽粒小而干瘪 | 灌浆期干旱 | 无法恢复 |
| 幼苗从基部腐软倒伏 | 湿害 | 立即挖沟排水 |
| 叶片发黄发浮，根系发黑 | 过湿，根系缺氧 | 从根本上改善排水 |
| 成熟籽粒发芽 | 成熟期潮湿 | 尽快收获 |

> **荞麦常常出现开花却不结籽的情况。原因大多是高温、缺水、传粉昆虫不足，以及生态型选择错误这四者之一。**

## 8. 栽培管理

### 8-1. 杂草管理——大多不需要

| 时期 | 方法 | 要点 |
|---|---|---|
| 播种后不久 | 无需特别处理 | 荞麦出苗快 |
| 生育初期 | 只拔除明显的大株杂草 | 荞麦会自行压制杂草 |
| 此后 | 不需要 | 叶片会完全覆盖地面 |

&nbsp;&nbsp;&nbsp;荞麦是几乎不需要除草管理的少见作物。发芽只需3-4天，速度极快，宽大的三角形叶片能迅速覆盖地面，不让杂草见光。而且根系分泌的物质还能抑制杂草种子发芽。种下才2周，田里就会被荞麦叶铺满，其他杂草根本长不起来。

&nbsp;&nbsp;&nbsp;正因为这一特性，荞麦也被用来整理田地。在杂草丛生的撂荒地上种一季荞麦并收获，杂草密度就会明显下降。这正是西方所说的净化作物用法。在无法使用除草剂的条件下，这是夺回被杂草占据的田地为数不多的办法之一，而且在这个过程中还能收获粮食。

### 8-2. 培土与防止倒伏

| 项目 | 时期 | 效果 |
|---|---|---|
| 培土 | 至开花期为止 | 在植株基部培土，防止倒伏 |
| 调节播种量 | 播种时 | 过密会使茎秆变细而倒伏 |
| 控制施肥 | 基肥阶段 | 氮肥过多会导致徒长 |
| 硅质肥 | 基肥 | 使茎秆更坚韧 |

&nbsp;&nbsp;&nbsp;荞麦茎秆中空，容易倒伏，加上无限生长的习性使花和籽粒不断在上部累积，重心随之升高。最有效的对策是在开花期之前给植株基部培土。如果是条播，只需把沟里的土耙上来培在根部即可。

&nbsp;&nbsp;&nbsp;一旦倒伏，几乎没有补救办法。荞麦茎秆柔弱，想把它扶起来反而会折断，扶起后也会再次倒下。触地的籽粒不是腐烂就是发芽。因此倒伏完全是一个预防问题。

### 8-3. 传粉——荞麦特有的管理

&nbsp;&nbsp;&nbsp;荞麦是自交不亲和的异花授粉作物，必须依靠昆虫或风来传粉。这是其他谷物所没有的、荞麦独有的管理项目。

| 方法 | 内容 | 效果 |
|---|---|---|
| 保证密度 | 不稀植 | 需要有互相传粉的对象 |
| 招引蜜蜂 | 荞麦是典型的蜜源植物 | 开花期蜜蜂会自动聚集 |
| 禁用农药 | 开花期不喷洒任何药剂 | 传粉昆虫一死就无法结实 |
| 田边留花 | 在田埂边保留其他花卉 | 有助于维持蜂群 |
| 人工授粉 | 开花期沿行间走动并摇动植株 | 在昆虫少时能起到部分作用 |
| 上午时段 | 荞麦在上午散粉 | 要摇动植株的话上午最合适 |

&nbsp;&nbsp;&nbsp;荞麦是典型的蜜源作物这一点是双向起作用的。荞麦开花时蜜蜂会聚集过来完成授粉，若同时养有蜂箱，还能获得蜂蜜。荞麦蜂蜜颜色深、香气浓，铁含量高。在灾害情况下砂糖断绝时，蜂蜜几乎是唯一的浓缩甜味来源，而荞麦正是能产出这种蜂蜜的作物。这也是评价表中非食用价值被评为C、高于其他谷物的原因之一。

&nbsp;&nbsp;&nbsp;反过来，如果假设昆虫消失，荞麦就很脆弱。大规模农药事故或环境剧变导致蜜蜂减少时，荞麦的结实率就会下降。这种情况下应考虑改种苦荞，因为苦荞可以自花授粉，没有昆虫也能结实。

### 8-4. 其他管理

| 项目 | 内容 |
|---|---|
| 摘心 | 不进行。荞麦保持原样生长更好 |
| 追肥 | 通常不需要，生育期短，追肥没有效果 |
| 驱鸟 | 收获前鸟会啄食籽粒，可悬挂反光物驱赶 |
| 残茬处理 | 割下的茎秆可直接铺在田里，也可作堆肥 |

&nbsp;&nbsp;&nbsp;荞麦茎秆是很好的绿肥。它柔软多汁，分解迅速，能把荞麦从土壤中吸收的磷和钾归还给田地，部分抵消荞麦吸肥能力强给后茬带来的不利影响。可以直接铺在收割后的地里，也可以浅耕翻入土中。

## 9. 病虫害

### 9-1. 主要病虫害

| 病虫害 | 发生条件 | 危害 | 不用药的应对方法 |
|---|---|---|---|
| 茎腐病 | 潮湿 | 茎秆软化并枯死 | 改善排水、轮作 |
| 白粉病 | 通风不良 | 叶片表面覆盖白粉 | 喷施稀释牛奶或小苏打液，改善通风 |
| 灰霉病 | 开花期潮湿 | 花及幼嫩籽粒腐软 | 改善排水与通风，摘除病株部位 |
| 蛾类 | 生育期 | 啃食叶片和茎秆 | 早发现早人工捕杀 |
| 蚜虫 | 生育期 | 吸食汁液并诱发煤烟病 | 喷施肥皂水，保护天敌 |
| 鸟 | 收获前 | 啄食籽粒 | 稻草人、反光片、防鸟网 |

&nbsp;&nbsp;&nbsp;在本书涉及的作物中，荞麦对病虫害的应对最为简单。防治自立度被评为SS，意味着即使没有农药，实际造成问题的病虫害也几乎没有。已知的病虫害种类本身不超过六种，没有致命的种类，而且生育期短，病害也没有太多时间蔓延。

&nbsp;&nbsp;&nbsp;不过，评价表中病虫害压力评为C(估计减产率50.6%)偏高，这一点需要说明。这个数值并非荞麦自身的实测值，而是从双子叶植物纲整体平均值推算而来。由于荞麦相关研究资料较少，借用了上一级分类群的数值，因此评价上偏于保守。在实际栽培中，荞麦所受的病虫害损失并不算大。

&nbsp;&nbsp;&nbsp;最实际的损失既不是病害也不是虫害，而是鸟害。荞麦籽粒大、外壳光滑，很招鸟喜欢啄食。收获前的十天到两周内若防不住鸟，就会损失相当一部分收成。没有防鸟网的话，在田地上方拉几道细线、悬挂反光片，或放置能发声的装置，也都有一定效果。

### 9-2. 天然防治剂

| 材料 | 制作方法 | 防治对象 | 注意 |
|---|---|---|---|
| 稀释牛奶 | 用水稀释5-10倍 | 白粉病 | 在晴天早晨喷施 |
| 小苏打液 | 1L水加5g小苏打及少量肥皂 | 白粉病 | 浓度过高会伤叶 |
| 肥皂水 | 1L水加纯肥皂5-10g | 蚜虫 | 正午喷洒会灼伤叶片 |
| 木醋液 | 稀释500-1,000倍 | 预防真菌病害 | 浓度过高会产生药害 |

> **开花期请不要喷洒任何东西。蜜蜂一旦死亡，当年就颗粒无收。**

&nbsp;&nbsp;&nbsp;这一原则对荞麦尤其重要，因为它是自交不亲和作物，没有昆虫结实根本无从谈起，就连肥皂水也会伤害蜜蜂。即便发现病害，开花期也应忍耐，等花期结束后再处理，或者干脆放任不管更好。反正荞麦本来就是几乎不需要防治的作物。

### 9-3. 不用药的防治原则

| 原则 | 内容 | 在荞麦上的应用 |
|---|---|---|
| 排水 | 不让田间积水 | 荞麦病害大多源于潮湿 |
| 通风 | 不密植 | 减少白粉病和灰霉病 |
| 避让 | 让开花期避开盛夏的高温高湿 | 选对栽培方式本身就是防治 |
| 开花期不施药 | 保护蜜蜂 | 结实与否全靠蜜蜂 |
| 防鸟 | 用物理方式阻挡 | 是最大的实际损失来源 |

## 10. 营养缺乏与过量

| 症状 | 原因 | 天然材料应对方法 |
|---|---|---|
| 全株发黄，植株矮小 | 缺氮 | 腐熟堆肥，少量10倍稀释尿液 |
| 叶缘褐变 | 缺钾 | 只撒极少量草木灰 |
| 生长缓慢 | 缺磷 | 把骨粉拌入堆肥，荞麦利用磷的能力强 |
| 开花却不结籽 | 缺硼 | 叶面喷施硼砂；没有的话让堆肥原料多样化 |
| 叶片变红 | 缺磷或低温 | 若是低温所致会自行恢复 |
| 新叶发白 | 缺铁，碱性过高 | 停止施用草木灰或石灰 |
| 徒长倒伏 | 氮肥过量 | 停止施肥并培土 |

&nbsp;&nbsp;&nbsp;荞麦需要特别留意的是硼。缺硼时花能正常开放，籽粒却不结实。这种症状在荞麦中很常见，而且原因众多，诊断困难：高温、缺水、传粉昆虫不足、生态型选错，以及缺硼，都会造成同样的症状。如果能排除前四种原因，就该怀疑是缺硼。每1,000㎡施2-3kg硼砂，或在开花前进行叶面喷施，结实率会明显提高。

&nbsp;&nbsp;&nbsp;缺铁问题在荞麦身上出现的背景与其他作物相反。荞麦喜酸性土壤，若大量施用草木灰或石灰使土壤偏向碱性，铁就会被固定而无法吸收。新叶发白时，应怀疑是碱性过高，并停止施灰。

## 11. 间作与轮作

### 11-1. 搭配组合

| 搭配度 | 对象 | 效果 |
|:---:|---|---|
| 非常好 | 马铃薯(前茬) | 6月挖收后接着种秋荞麦 |
| 非常好 | 大麦、小麦(前茬) | 填补6月收割后的空当 |
| 非常好 | 芝麻(前茬) | 收获后接种秋荞麦 |
| 好 | 玉米、烟草 | 作为前后茬搭配利用 |
| 好 | 水稻(望天田) | 春季收获夏荞麦后延后插秧 |
| 好 | 秋菜(后茬) | 种在收获夏荞麦后的地里 |
| 差 | 荞麦连作 | 连作本身无害，但会减产 |

&nbsp;&nbsp;&nbsp;荞麦的搭配组合表与其他作物性质不同，重点不是同期混种的间作，而是前后接续的轮作。原因在于荞麦生育期短，60到75天就能结束，正好可以填补其他作物之间的空档期，这是荞麦最合理的用法。

| 种植组合 | 流程 |
|---|---|
| 春马铃薯后接秋荞麦 | 6月收马铃薯，7月播荞麦，10月收荞麦 |
| 夏荞麦后接秋菜 | 4月播荞麦，7月收获，随后种大白菜和萝卜 |
| 麦类后接秋荞麦 | 6月收麦类，7月播荞麦 |
| 芝麻后接秋荞麦 | 芝麻收获后接着种 |
| 夏荞麦后接晚稻 | 在望天田中春季收荞麦后延后插秧 |

&nbsp;&nbsp;&nbsp;这些组合的共同点在于，荞麦不会让田地闲置。6月空出的田、7月空出的田，种秋季作物嫌早，种夏季作物又嫌晚，这两到三个月正好由荞麦填补。这样就形成了同一块地一年两收的格局，荞麦单位面积热量D这个弱点也因此得到部分抵消。

### 11-2. 作为净化作物的荞麦

&nbsp;&nbsp;&nbsp;荞麦有一项其他作物所没有的用途，那就是整理田地。

| 效果 | 原理 | 应用 |
|---|---|---|
| 抑制杂草 | 快速生长覆盖地面并释放化感物质 | 在被杂草占据的田里种一年加以整理 |
| 抑制线虫 | 根系分泌物降低线虫密度 | 种在马铃薯或根菜类作物之前 |
| 活化磷素 | 吸收其他作物无法利用的磷 | 翻压入土后这些磷会重新回归土壤 |
| 改善土壤结构 | 直根使土壤变松软 | 有助于疏松板结的田地 |
| 绿肥 | 柔软的茎秆分解迅速 | 开花时翻压可作优质绿肥 |

&nbsp;&nbsp;&nbsp;在既没有农药、也没有地膜、更没有除草剂的条件下，能让田地恢复生机的手段极其有限。荞麦是这为数不多的手段之一，而且更重要的是，它在整理田地的同时还能产出粮食。如果有一块田因杂草丛生、线虫肆虐而使马铃薯长势不佳，那么在这块田里种一年荞麦，是相当合理的选择。

&nbsp;&nbsp;&nbsp;如果只打算把荞麦当绿肥用，应在籽粒成熟之前、花开正盛时翻压入土。那时茎叶量最多、质地最柔软，分解也最快。若等籽粒成熟后再翻压，次年整块田里就会自己冒出荞麦苗，变成杂草。

### 11-3. 轮作顺序与后茬问题

| 年份 | 作物 | 目的 |
|---|---|---|
| 第1年 | 荞麦 | 整理杂草与线虫 |
| 第2年 | 豆科 | 恢复氮素，补充被荞麦吸走的养分 |
| 第3年 | 马铃薯或根菜类 | 利用整理好的地力 |
| 第4年 | 谷物，或重新种荞麦 | - |

> **荞麦的吸肥能力非常强。收获荞麦后的田地，必须施肥或种植豆科作物才能恢复地力。**

&nbsp;&nbsp;&nbsp;荞麦的吸肥能力是一把双刃剑。它既是荞麦能在贫瘠土地上生长的原因，也是后茬会养分不足的原因。荞麦本身几乎不需要施肥，但之所以建议在种荞麦的田里施肥，是为了后茬着想。如果不给荞麦施肥就放任不管，代价将由下一茬作物承担。

&nbsp;&nbsp;&nbsp;荞麦的连作适应性为SS，很耐连作，但如果在同一块田里连续种植多年，产量还是会逐渐下降，原因不是病害，而是养分枯竭。原则上应至少间隔2年，或在中间轮种一茬豆科作物。
