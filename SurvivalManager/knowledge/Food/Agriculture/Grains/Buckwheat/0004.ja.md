## 7. 水管理

### 7-1. 生育段階ごとの基準

| 時期 | 管理 | 理由 |
|---|---|---|
| 播種から発芽まで | 土が乾かないよう保ちます | 発芽が速く3-4日で出芽します |
| 生育初期 | 過湿を防ぐことがすべてです | この時期の湿害が最も多い失敗原因です |
| 開花期 | 十分な水分が必要です | 発芽から開花まで約70mmの降水が必要です |
| 登熟期 | 少なめに。満開から成熟まで20mmで足ります | 過湿だと穂発芽や品質低下が起こります |
| 成熟期 | 完全に断ちます | 雨に当たると種子が落ちたり発芽したりします |

&nbsp;&nbsp;&nbsp;ソバの水管理で特異な点は、必要量が段階ごとにはっきり分かれていることです。発芽から開花までは70mm必要ですが、満開以降成熟までは20mmで十分です。前半が多く後半が少ない構造です。総250mmという少ない水で結実できるのも、後半の必要量が小さいためです。

&nbsp;&nbsp;&nbsp;ソバで最も重要な水管理は、与えることではなく抜くことです。ソバは播種直後と生育初期の湿害に非常に弱いのです。蒔いたばかりの種が水に浸かるとそのまま腐り、子葉が出た若い個体はたった3日水に浸かっただけでも枯れます。播種前に排水路を作るその半日が、ソバ農作の成否を分けます。

### 7-2. 水分不足と過多の症状

| 症状 | 原因 | 判断と対処 |
|---|---|---|
| 葉がしおれ、茎が垂れます | 水分不足 | 開花期なら補給します |
| 花はたくさん咲くのに種子が着きません | 高温または水分不足、あるいは花粉媒介昆虫の不足 | 複数の原因が重なっています。後で扱います |
| 種子が小さくしなびます | 登熟期の干ばつ | 回復しません |
| 若い個体が根元から軟化して倒れます | 湿害 | ただちに溝を掘って水を抜きます |
| 葉が黄色く浮き、根が黒ずみます | 過湿、根の酸素不足 | 排水を根本的に直します |
| 熟した種子から芽が出ます | 成熟期の多湿 | 収穫を急ぎます |

> **ソバは花が咲いても種子が実らないことがよくあります。原因はたいてい高温、水分不足、媒介昆虫の不足、そして生態型の取り違え、この四つのうちのどれかです。**

## 8. 栽培管理

### 8-1. 雑草管理 - ほとんど不要です

| 時期 | 方法 | 要点 |
|---|---|---|
| 播種直後 | 特に対策なし | ソバが速く出芽します |
| 生育初期 | 目立つ大きな雑草だけ抜きます | ソバが自ら雑草を抑えます |
| それ以降 | 不要です | 葉が地面を完全に覆います |

&nbsp;&nbsp;&nbsp;ソバは雑草管理がほとんど要らない珍しい作物です。発芽が3-4日と非常に速く、三角形の広い葉が速やかに地面を覆って雑草に光を与えません。そのうえ根から出る物質が雑草の種子の発芽を抑えます。植えて2週間もすれば畑はソバの葉に覆われ、ほかの草が育てなくなります。

&nbsp;&nbsp;&nbsp;この性質のため、ソバは畑を整理する用途にも使われます。雑草が生い茂った休耕地にソバを一度植えて収穫すると、雑草の密度が目に見えて減ります。欧米でクリーニングクロップと呼ばれる使い方です。除草剤が使えない条件で、雑草に占領された畑を取り戻す数少ない手段であり、その過程で食料まで得られます。

### 8-2. 土寄せと倒伏防止

| 項目 | 時期 | 効果 |
|---|---|---|
| 土寄せ | 開花期まで | 根元に土を寄せて倒伏を防ぎます |
| 播種量の調節 | 播種時 | 過密だと茎が細くなり倒れます |
| 施肥の抑制 | 元肥の段階 | 窒素が多いと徒長します |
| ケイ酸質 | 元肥 | 茎を丈夫にします |

&nbsp;&nbsp;&nbsp;ソバは茎の中が空洞なので倒れやすいのです。そのうえ無限伸育のため上のほうに花や種子がつき続け、重心が高くなります。開花期まで根元に土を寄せる土寄せが最も効果的な対策です。条播きをしたのなら、畝間の土をかき上げるだけで済みます。

&nbsp;&nbsp;&nbsp;倒れたあとはほとんど手の打ちようがありません。ソバは茎が弱いため、起こそうとすると折れてしまい、立てても再び倒れます。地面に触れた種子は腐るか発芽してしまいます。そのため倒伏は、もっぱら予防の問題です。

### 8-3. 花粉媒介 - ソバに特有の管理

&nbsp;&nbsp;&nbsp;ソバは自家不和合性の他家受粉作物なので、必ず昆虫か風が花粉を運んでくれる必要があります。これは他の穀物にはない、ソバだけの管理項目です。

| 方法 | 内容 | 効果 |
|---|---|---|
| 密度の確保 | 疎らに植えません | 花粉をやり取りする相手が必要です |
| ハチを誘う | ソバは代表的な蜜源です | 開花期にハチが自然と集まります |
| 農薬禁止 | 開花期には何も散布しません | 媒介昆虫が死ぬと結実しません |
| 周辺の花 | 畑の縁に他の花を残しておきます | ハチの個体群が維持されます |
| 人工授粉 | 開花期に畝間を歩きながら株を揺らします | 昆虫が少ないとき部分的に助けになります |
| 朝の時間帯 | ソバは午前中に花粉を出します | 揺らすなら午前が良いです |

&nbsp;&nbsp;&nbsp;ソバが代表的な蜜源作物であるという点は、両方向に作用します。ソバの花が咲けばハチが集まって受粉が行われ、同時に養蜂箱があれば蜂蜜が得られます。ソバ蜂蜜は色が濃く香りが強く、鉄分が豊富です。災害時に砂糖がなくなったとき、蜂蜜はほぼ唯一の濃縮甘味料であり、ソバはその蜂蜜を生み出してくれる作物です。評価表で非食用価値がCと他の穀物より高い理由の一つがこれです。

&nbsp;&nbsp;&nbsp;逆に、昆虫がいなくなった状況を想定すると、ソバは脆弱です。大規模な農薬事故や急激な環境変化でハチが減ると、ソバの結実率が下がります。そのときはダッタンソバを検討すべきです。ダッタンソバは自家受精が可能で、昆虫がいなくても結実します。

### 8-4. そのほかの管理

| 項目 | 内容 |
|---|---|
| 摘心 | 行いません。ソバはそのままにしておくほうがよいのです |
| 追肥 | 通常は不要です。生育期間が短く効果がありません |
| 鳥よけ | 収穫直前に鳥が種子を食べます。光るものを吊るします |
| 残渣処理 | 刈った茎はそのまま畑に敷くか堆肥にします |

&nbsp;&nbsp;&nbsp;ソバの茎は良い緑肥になります。柔らかく水分が多いため速く分解し、ソバが土から吸い上げたリン酸とカリウムを畑に返します。ソバの吸肥力が後作に不利に働く問題を部分的に相殺する方法です。刈り取った場所にそのまま敷いておくか、浅くすき込みます。

## 9. 病害虫

### 9-1. 主な病害虫

| 病害虫 | 発生条件 | 被害 | 薬を使わない対応 |
|---|---|---|---|
| 茎腐病 | 多湿 | 茎が軟化して枯死します | 排水改善、輪作 |
| うどんこ病 | 通風不良 | 葉の表面が白い粉で覆われます | 薄めた牛乳や重曹液の散布、通風の確保 |
| 灰色かび病 | 開花期の多湿 | 花と若い種子が軟化します | 排水と通風、病変部の除去 |
| ガ類 | 生育期 | 葉と茎を食害します | 早期発見と捕殺 |
| アブラムシ | 生育期 | 汁を吸いすす病を招きます | 石けん水の散布、天敵の保護 |
| 鳥 | 収穫直前 | 種子を食べます | かかし、光る破片、網 |

&nbsp;&nbsp;&nbsp;ソバは本書で扱う作物の中で、病害虫への対応が最も単純です。防除自立度がSSと評価されたのは、薬がなくても実質的に問題となる病害虫がほとんどないという意味です。知られている病害虫の種類自体が六種を超えず、致命的なものもなく、生育期間が短いため病気が大きく広がる時間もありません。

&nbsp;&nbsp;&nbsp;ただし、評価表の病害虫圧がC(推定減収率50.6%)とやや高く出ている点には説明が必要です。この数値はソバ自体の実測ではなく、双子葉植物綱全体の平均から類推した値です。ソバは関連研究資料が少ないため上位分類群の値を借りており、そのため実際より保守的に評価されている面があります。実際の栽培では、ソバの病害虫被害はそれほど大きくありません。

&nbsp;&nbsp;&nbsp;最も実質的な損失は、病気でも虫でもなく鳥です。ソバの種子は粒が大きく殻が滑らかで、鳥に食べられやすいのです。収穫直前の10日から2週間、鳥を防げないとかなりの量が失われます。網がなければ、畑の上に糸を何本も張ったり、光る破片を吊るしたり、音の出る仕掛けを置いたりするだけでも効果があります。

### 9-2. 天然防除剤

| 材料 | 作り方 | 対象 | 注意 |
|---|---|---|---|
| 薄めた牛乳 | 水で5-10倍に希釈 | うどんこ病 | 晴れた日の朝に散布します |
| 重曹液 | 水1Lに重曹5gと石けん少量 | うどんこ病 | 濃いと葉が傷みます |
| 石けん水 | 水1Lに純石けん5-10g | アブラムシ | 真昼に撒くと葉が焼けます |
| 木酢液 | 500-1,000倍希釈 | かび病の予防 | 濃いと薬害が出ます |

> **開花期には何も散布してはいけません。ハチが死ねば、その年の収穫はありません。**

&nbsp;&nbsp;&nbsp;この原則はソバにおいて特に重要です。自家不和合性の作物なので、昆虫がいなければ結実そのものが成立しないからです。石けん水でさえハチには有害です。病気が見えても開花期は我慢し、花が終わったあとに処理するか、そのままにしておくほうがよいのです。ソバはどのみち防除がほとんど要らない作物です。

### 9-3. 薬を使わない防除の原則

| 原則 | 内容 | ソバでの適用 |
|---|---|---|
| 排水 | 水がたまらないようにします | ソバの病害の大半は多湿から来ます |
| 通風 | 過密に植えません | うどんこ病と灰色かび病を減らします |
| 回避 | 開花期が真夏の高温多湿と重ならないようにします | 作型の選択がそのまま防除になります |
| 開花期は無処理 | ハチを守ります | 結実そのものがハチにかかっています |
| 鳥の遮断 | 物理的に防ぎます | 最も大きな実質的損失源です |

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然素材での対処 |
|---|---|---|
| 株全体が黄色く色あせ、丈が低いです | 窒素欠乏 | 腐熟堆肥、尿の10倍希釈液を少量 |
| 葉の縁が褐変します | カリウム欠乏 | 草木灰をごく少量だけ撒きます |
| 生育が遅いです | リン酸欠乏 | 骨粉を堆肥に混ぜます。ソバはリン酸利用力が高いです |
| 花は咲くのに種子が着きません | ホウ素欠乏 | ホウ砂の葉面散布。なければ堆肥の材料を多様化します |
| 葉が赤く色づきます | リン酸欠乏または低温 | 低温が原因なら自然に回復します |
| 新しい葉が白っぽく色あせます | 鉄欠乏、アルカリ過多 | 草木灰や石灰の施用をやめます |
| 徒長して倒れます | 窒素過剰 | 施肥を中止し土寄せをします |

&nbsp;&nbsp;&nbsp;ソバで特に知っておくべきはホウ素です。ホウ素が不足すると、花は正常に咲くのに種子が着きません。ソバではこの症状がよく見られ、原因が複数あるため診断が難しいのです。高温、水分不足、媒介昆虫の不足、生態型の取り違え、そしてホウ素欠乏、これらすべてが同じ症状を引き起こします。前の四つを排除できるなら、ホウ素を疑います。ホウ砂2-3kgを1,000㎡に施すか、開花直前に葉面散布すると、結実率が目に見えて上がります。

&nbsp;&nbsp;&nbsp;鉄欠乏は他の作物とは逆の文脈で起こります。ソバは酸性土壌を好むため、草木灰や石灰を多く撒いて土がアルカリに傾くと、鉄が固定されて吸収できなくなります。新しい葉が白っぽくなったら、アルカリ過多を疑い、灰の施用をやめます。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 対象 | 効果 |
|:---:|---|---|
| 非常に良い | ジャガイモ(前作) | 6月に掘り上げた跡地に秋ソバを続けて植えます |
| 非常に良い | オオムギ、コムギ(前作) | 6月に刈った跡地を埋めます |
| 非常に良い | ゴマ(前作) | 収穫後、秋ソバへとつなげます |
| 良い | トウモロコシ、タバコ | 前後作として活用します |
| 良い | イネ(天水田) | 春に夏ソバを収穫してから稲を遅く植えます |
| 良い | 秋野菜(後作) | 夏ソバを収穫した跡地に植えます |
| 悪い | ソバの連作 | 連作自体は無害だが収量が減ります |

&nbsp;&nbsp;&nbsp;ソバの相性表は他の作物と性格が異なります。一緒に植える混作ではなく、前後に続けて植える前後作が中心です。理由はソバの生育期間の短さにあります。60日から75日で終わるため、他の作物の間の空き期間を埋めるのに適しており、それがソバの最も合理的な使い方です。

| 作付け組み合わせ | 流れ |
|---|---|
| 春ジャガイモの後に秋ソバ | 6月にジャガイモ収穫、7月にソバ播種、10月にソバ収穫 |
| 夏ソバの後に秋野菜 | 4月にソバ播種、7月収穫、その跡地にハクサイとダイコン |
| 麦類の後に秋ソバ | 6月に麦類収穫、7月にソバ播種 |
| ゴマの後に秋ソバ | ゴマ収穫後に続けて植えます |
| 夏ソバの後に晩稲 | 天水田で春にソバを収穫し、稲を遅く植えます |

&nbsp;&nbsp;&nbsp;これらの組み合わせに共通するのは、ソバが畑を遊ばせないという点です。6月に空く畑、7月に空く畑は、秋作物を植えるには早く、夏作物を植えるには遅い時期です。その2ヶ月から3ヶ月をソバが埋めます。同じ土地で年に二度収穫する構造が生まれ、ソバの面積当たり熱量Dという弱点が部分的に相殺されます。

### 11-2. 浄化作物としてのソバ

&nbsp;&nbsp;&nbsp;ソバには他の作物にない用途が一つあります。畑を整理する用途です。

| 効果 | 原理 | 活用 |
|---|---|---|
| 雑草抑制 | 速い生長で地面を覆い、他感物質を出します | 雑草に占領された畑に一年植えて整理します |
| センチュウ抑制 | 根から出る物質がセンチュウの密度を下げます | ジャガイモや根菜の前に植えます |
| リン酸の可溶化 | 他の作物が使えないリン酸を吸収します | すき込むとそのリン酸が土に戻ります |
| 土壌構造の改善 | 直根が土を柔らかくします | 固くなった畑をほぐすのに役立ちます |
| 緑肥 | 柔らかい茎が速く分解します | 開花時にすき込むと良い緑肥になります |

&nbsp;&nbsp;&nbsp;農薬も、ビニールも、除草剤もない条件で畑を蘇らせる手段はきわめて限られています。ソバはその数少ない手段の一つであり、何より整理をしながら食料まで得られます。雑草が生い茂り、センチュウがはびこってジャガイモの育ちが悪い畑があるなら、そこに一年ソバを入れるのは十分に合理的な選択です。

&nbsp;&nbsp;&nbsp;ソバを緑肥としてだけ使う計画なら、種が実る前、花が満開のときにすき込みます。その時期が茎と葉の量が最も多く、最も柔らかくて速く分解します。種が実ったあとにすき込むと、翌年畑全体にソバが勝手に生えてきて雑草になります。

### 11-3. 輪作の順序と後作の問題

| 年 | 作物 | 目的 |
|---|---|---|
| 1年目 | ソバ | 雑草とセンチュウを整理します |
| 2年目 | マメ科 | 窒素を回復させ、ソバが吸い尽くした養分を補います |
| 3年目 | ジャガイモまたは根菜 | 整理された土地の利点を活かします |
| 4年目 | 穀物、またはソバに戻る | - |

> **ソバは吸肥力が非常に強いです。ソバを収穫した畑は、必ず肥料を入れるかマメ科を入れて回復させなければなりません。**

&nbsp;&nbsp;&nbsp;ソバの吸肥力は諸刃の剣です。痩せた土地でも育つ理由であると同時に、後作が養分不足に陥る理由でもあります。ソバ自体はほとんど肥料が要りませんが、ソバを植える畑に肥料を入れるよう勧めるのは後作のためです。ソバに施肥をせずにそのまま済ませると、次の作物がその代償を払うことになります。

&nbsp;&nbsp;&nbsp;ソバは連作適応性がSSで連作に強い作物ですが、同じ畑に何年も続けて植えると収量が徐々に減っていきます。病害のためではなく、養分が枯渇するためです。最低でも2年間隔を空けるか、間にマメ科を挟むのが原則です。
