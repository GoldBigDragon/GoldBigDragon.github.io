## はじめに
&nbsp;&nbsp;&nbsp;ソバ(Fagopyrum esculentum)はイネ科ではなくタデ科の双子葉植物で、穀物のように食べるのは穀粒ではなく種子です。1,000㎡で150kg、1㎡当たり561kcalと、自給ラインの0.21倍しか採れず、主食の柱にはなれません。それでも救荒作物に数えられるのは、播種から収穫まで60-75日と最も早いからです。ほかの作物が干ばつ、洪水、遅霜で全滅した場所にまいて、その年のうちに何かを収穫できます。また、やせ地や酸性土壌で育ち、肥料は1㎡当たり12g、水は250mmですみ、防除が要らず、タンパク質の質が穀物を圧倒します。弱みは、霜、自家不和合性、短い種子の寿命、硬い殻、アレルギーです。

## 2. 植物の概要
&nbsp;&nbsp;&nbsp;タデ科ソバ属の一年草で、中国南西部からヒマラヤに至る高山地帯が原産です。栽培種には、普通ソバ(F. esculentum)とダッタンソバ(F. tataricum)があります。葉は三角形の心臓形、茎はまっすぐで中空、まっすぐな根は養分を吸う力が強いです。花は白または淡いピンクの総状花序で、長花柱花と短花柱花が互いの花粉を受けなければならない自家不和合性のため、昆虫(ミツバチ)が花粉を運びます。果実は硬い三角形の痩果です。無限伸育性で、花が咲き続け、種子が下から順に熟すため、すべて熟すのを待つと、先に熟したものが落ちます。

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 発芽・幼苗期 | 播種後2週間 | 三、四日で出てきます |
| 栄養成長期 | 2-5週 | 茎と葉が増えます |
| 開花期 | 5-7週 | 昆虫が受粉します。リン酸、ホウ素が重要 |
| 登熟・成熟期 | 7-10週 | 下から順に熟します |

| 100g当たりの栄養 | 含量 |
|:---|:---|
| 熱量 | 364-374kcal(乾燥した種子) |
| タンパク質 | 12.96-13.2g(熱量比13.9%)。リシン不足がない |
| 炭水化物 / 脂肪 / 食物繊維 | 72.8g / 2.2g / 5.0g(脂肪が低く酸化の危険が少ない) |
| その他 | カルシウム、鉄、ビタミンK、ビタミンB群 |
| ルチン | 毛細血管の壁を丈夫にするフラボノイド。殻に近い部分と芽・葉に多く、ダッタンソバは普通ソバの70-100倍。調理でも大きくは壊れず、長く貯蔵するほど減る |

## 3. 栽培環境と品種
| 条件 | 最適 | 限界と影響 |
|:---|:---|:---|
| 生育温度 | 15-25℃ | 5-30℃。5℃を下回ると生育が止まり、霜で枯れる |
| 開花温度 | 17-19℃ | 30℃を超えると受精せず、花だけが咲く |
| 発芽 | 25-31℃ | 0-4.8℃でも発芽 |
| 光 | 1日6-8時間 | 4時間以上。40%遮光でも収量の88% |
| 水 | 合計250mm | 発芽-開花70mm、満開-成熟20mm。過湿に非常に弱い |
| 土壌 | 排水のよい砂質土-壌土 | 酸性土に強く、石灰質・アルカリ土壌では不調。湿った粘土質は失敗 |

> **ソバに石灰をまいてはいけません。ほかの作物にはよいその処方が、ソバには害になります。**

&nbsp;&nbsp;&nbsp;すでに耕してある空いた畑、ほかの作物が失敗した場所、酸性に傾いた古い畑、砂利混じりのやせ地がよいです。石灰質の多い土地と、湿った低地は避けます。

| 生態型 | 代表品種 | 播種 |
|:---|:---|:---|
| 夏ソバ(春まき型) | ヤンジョル(68日、1,000㎡当たり121kg)、ヤンジョル2号(68日、155kgで収量最大、脱粒が少ない) | 春 |
| 秋ソバ(夏まき型) | テサン(73日、130kg、スプラウト収率970%) | 夏 |

> **秋ソバを春にまくと、花は咲いても種子がほとんどできません。ソバ栽培で最もよくある致命的な失敗なので、種子の出所がわからないときは、まず生態型を確認します。**

&nbsp;&nbsp;&nbsp;ダッタンソバは自家受粉できるため隔離が不要で、ルチンが多く、採種と薬効に有利です。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 土づくり | 20cmと浅く耕せば十分(熱量回収倍率が低く、深耕は損)。播種前に必ず排水路を掘り、土を細かく砕く。石灰は入れない |
| 施肥 | 1,000㎡当たり窒素5.4kg、リン酸3.1kg、カリウム3.9kg、完熟堆肥1,000-1,500kg。ホウ砂2-3kgは結実率を高める。ケイ酸質は倒伏を減らす |
| 代替資源 | 腐熟堆肥を少量、尿の10倍希釈液(生育初期)、骨粉、木灰はアルカリ性なので少量のみ |

&nbsp;&nbsp;&nbsp;ソバは養分を吸う力が非常に強く、収穫後の畑に養分があまり残らないので、肥料やマメ科で回復させなければなりません。無投入での収量維持率は45.1%です。

| 作型 | 地域 | 播種 | 収穫 |
|:---|:---|:---|:---|
| 夏ソバ | 中北部 | 4月下旬-5月上旬 | 7月上旬-中旬 |
| 夏ソバ | 南部 | 4月上旬-中旬 | 6月下旬-7月上旬 |
| 秋ソバ | 中北部 | 7月中旬-下旬 | 10月上旬-中旬 |
| 秋ソバ | 南部 | 8月上旬-中旬 | 10月下旬-11月中旬 |

| 播種方法 | 播種量(1,000㎡) | 備考 |
|:---|:---|:---|
| ばらまき | 8-10kg | 最も早い。急いで植えるとき |
| 条まき | 6-8kg、条間30cm | 草取りが可能 |
| 点まき | 0.5-2kg、条間30cm、株間15cm | 種子が最も少なくてすむ |

&nbsp;&nbsp;&nbsp;深さは2-5cmで、軽く覆って押さえます。自家不和合性なので、疎らに植えすぎません。秋ソバは初霜の10-12週間前に播種します。種子の寿命が短いので発芽試験が必須(1年を過ぎた種子は必ず)で、50-55℃の湯に10-15分浸すか、細かい灰をまぶします。わらのマルチは、水分の保持と雑草の抑制に役立ちます。

## 5. 水と栽培管理、病害虫
| 時期 | 水の管理 |
|:---|:---|
| 発芽 | 乾かさない |
| 生育初期 | 過湿を防ぐことがすべて。播種直後の湿害が最もよくある失敗の原因なので、畝間を掘って水を抜く |
| 開花期 | 十分に必要 |
| 登熟期 | 少なめに |
| 成熟期 | 完全に切る。雨に当たると種子が落ちて芽が出る |

&nbsp;&nbsp;&nbsp;花が咲いても種子ができない原因は、たいてい、高温、水分不足、受粉を媒介する昆虫の不足、生態型の取り違えの四つのいずれかです。

| 管理 | 内容 |
|:---|:---|
| 雑草 | ほとんど不要。目立つ大きな雑草だけを抜けば、ソバが自ら抑える |
| 倒伏 | 茎が中空で倒れやすい。開花期まで土寄せし、過密と窒素過多を避ける |
| 受粉の媒介 | 疎らに植えない、開花期には薬を一切まかない、畑の端の花を残してミツバチを保つ、午前に株を揺すって人工授粉 |
| その他 | 摘心と追肥は不要。収穫直前には、鳥よけに光るものを吊るす |

| 病害虫 | 農薬を使わない対応 |
|:---|:---|
| 茎腐れ病、灰色かび病 | 排水と風通し、病んだ部分の除去 |
| うどんこ病 | 牛乳の5-10倍希釈液または重曹液(水1Lに重曹5gと石けん少量)、風通し |
| ガ類、アブラムシ | 手で捕る、石けん水(水1Lに純石けん5-10g)、天敵の保護 |
| 鳥 | 最大の実質的な損失。かかし、光る切れ端、ネット |

> **開花期には何もまかないでください。ミツバチが死ねば、その年の収穫はありません。**

| 欠乏・過剰 | 症状と処置 |
|:---|:---|
| 窒素欠乏 | 黄色っぽくなり背が低い。腐熟堆肥、尿の希釈液を少量 |
| ホウ素欠乏 | 花は咲くのに種子ができない。ホウ砂の葉面散布 |
| 鉄欠乏 | 新葉が白くなる。アルカリ過多なので、木灰と石灰を中止 |
| 窒素過剰 | 草丈ばかり伸びて倒れる。施肥を中止し、土寄せ |

## 6. 混植と輪作
&nbsp;&nbsp;&nbsp;ソバは畑を遊ばせない作物です。6月に掘ったジャガイモ、6月に刈ったオオムギやコムギ、収穫したゴマの後に秋ソバを続けて植え、4月にまいた夏ソバを7月に収穫した場所にハクサイとダイコンを植えるか、天水田に晩生のイネを植えます。ソバの連作は有害ではありませんが、収量が徐々に減ります。

| 浄化作物としての効果 | 活用 |
|:---|:---|
| 雑草の抑制 | 速い生長とアレロパシーで、雑草に占領された畑を、1年植えて整理 |
| 線虫の抑制 | ジャガイモや根菜の前に植える |
| リン酸の可溶化 | ほかの作物が使えないリン酸を吸収し、すき込むと土に戻る |
| 緑肥 | 種子が熟す前、花が満開のときにすき込む |

| 輪作 | 作物 |
|:---|:---|
| 1年目 | ソバ |
| 2年目 | マメ科(窒素の回復) |
| 3年目 | ジャガイモまたは根菜 |
| 4年目 | 穀物、またはソバに戻る |

## 7. 収穫、脱殻、採種
| 順序 | 内容 |
|:---|:---|
| 時期 | 播種後60-75日。種子の75-80%が黒く熟したときに刈る(水分16%以下)。すべて熟すのを待つと、下の種子を失う |
| 刈り取り | 露が乾く前の早朝に、根元を鎌で刈り、揺らさずに寝かせる |
| 乾燥 | 布やむしろを敷いた上に置き、小さな束にして3-5日天日干し。雨に当てない。その後脱穀し、むしろでさらに2-3日乾かして水分13-14%にする |
| 判定 | 殻をむいた粒を噛むとパリッと割れて粉が出る、殻をもむとカサカサ崩れる、瓶に密閉して1日置いても曇らない |
| 脱穀 | 手でしごく(種子用)、むしろの上で棒で軽くたたく(強く打たない)、袋ごと地面に打ちつける、踏む、逆さにして振る |
| 殻 | 弱い風に流す、箕であおぐ、うちわであおぐ、ふるう、水選(すぐ乾かす) |

&nbsp;&nbsp;&nbsp;脱殻(三角形の殻むき)は、臼で軽く搗いて箕であおることを繰り返す、石臼の上石を粒の大きさだけ浮かせて回す、弱火で炒って殻をカリッとさせた後に搗く方法があり、炒ってから搗くのが最も合っています。殻は枕の詰め物、断熱材、焚きつけに使います。

| 採種 | 基準 |
|:---|:---|
| 制約 | 自家不和合性のため、袋かけが通用しない |
| 隔離 | 他の品種と500m以上、または開花期を3週間以上ずらす。一つの地域に一つの品種だけを植えるのが最も現実的 |
| 選抜 | 病気がなく倒れていない30株以上から、まんべんなく。先に熟した下のほうの種子を使う |
| 保管 | 殻のまま、水分12-13%。常温で1-2年で、8か月から発芽率が落ちるので、毎年新しく採る。必要量の2倍 |

## 8. 貯蔵
&nbsp;&nbsp;&nbsp;貯蔵性はSSです。殻のまま貯蔵し、食べる分だけむきます。脱殻すると種子の寿命が急激に縮み、ルチンが光で分解されます。

| 項目 | 基準 |
|:---|:---|
| 条件 | 水分13-14%(種子12-13%)、温度15℃以下、周囲の湿度65%以下、完全遮光、2か月ごとに点検、種子は春秋に発芽試験 |
| 容器 | 金属缶、ガラス瓶3年以上 / 壺2-3年 / 厚手のビニール1-2年 / 麻袋6か月-1年(三角形の種子がよく転がって漏れる) |

| 虫の防除 | 方法 |
|:---|:---|
| 完全密閉 | 容器をいっぱいに満たして閉じる。最も確実 |
| 木灰 | 細かい灰を穀物の体積の2-5%混ぜる。食べる前に洗い流す |
| 珪藻土 | 穀物1kgに1-3g。乾いた状態でのみ働く |
| 補助 | 乾燥トウガラシ・サンショウ、ヨモギ・ショウブの葉、炒り塩、炭。真冬に数日外へ出す(低温)、60℃の日なたに薄く広げる(種子用は除く) |

## 9. 調理と注意事項
> **ソバアレルギーは、アナフィラキシーにつながることがあります。医療が途絶えた災害時には、これは実際の命の危険です。**

&nbsp;&nbsp;&nbsp;ソバのタンパク質の一部は強いアレルゲンで、加熱しても減らず、ごく少量や、粉の吸入、そば殻の枕でも反応が出ることがあります。症状は、じんましん、口とのどのかゆみ、腹痛、嘔吐、呼吸困難で、重い場合は血圧低下と気道閉塞を起こし、食べて数分から数十分以内に現れます。初めて食べる人は、ごく少量(子どもは一さじ以下)から数日かけて増やし、アレルギーの既往がある人は食べず、反応が出たら直ちに中止して再び試さないようにします。調理器具は別にし、そば殻の枕は近くに置かず、食料を分け合う共同体なら、誰が反応するかを前もって把握しておきます。

| 注意 | 内容 |
|:---|:---|
| ダッタンソバ | ルチンが70-100倍で苦味が強い。通常の摂取量は問題ないが、抗凝固薬を服用中なら大量摂取に注意。殻をよくむき、何度もすすぐと苦味が減る |
| カビが生えたもの | カビ毒は加熱しても消えない。全量廃棄 |
| 殻、加熱不足 | 殻は消化されないのでむいて食べ、デンプンは十分に加熱する |

&nbsp;&nbsp;&nbsp;ソバはグルテンがないので小麦を食べられない人も食べられますが、生地に粘りがなく、麺やパンを作りにくいです。小麦粉やデンプンを混ぜるか、熱湯でこねます。殻をむいた後、石臼や臼で挽き、炒ってから搗くと楽で香りが立ちます。粉は粒よりはるかに早く傷むので、1か月に食べる分だけ挽きます。

| 調理 | 燃料とコツ |
|:---|:---|
| 炒り粉 | 水に溶いてすぐ食べる。調理燃料が要らない |
| 粉がゆ | 粉を水に溶いて5-10分。最も効率がよい |
| メミルムク(そばの寄せ物) | 粉を水に溶いてかき混ぜながら煮て、冷まして固める。数日食べられる |
| 焼き物、麺 | 薄く焼く(厚いと中まで火が通らない)。麺は茹で時間が短い |
| 余熱調理 | 煮た後、火を止めてくるんでおくと、燃料を半分以下に減らせる |

&nbsp;&nbsp;&nbsp;ソバもやしは、殻のまま6-12時間水に浸し、水を切って器や布に広げ、1日に2、3回水をかけます。暗い所では3-4日で黄色い芽が出て、光に当てると2日で緑色になり、5-7日で5-10cmになったら殻を取り除いて食べます。土も畑もなく、冬に5日で新鮮な緑の野菜が得られる方法で、ルチンとビタミンが種子より多く含まれます。貯蔵を兼ねた加工には、炒り粒(密閉で6か月)、炒り粉(3-6か月)、乾燥したムク(1年)、デンプン(数年)があります。開花期には、ミツバチからソバ蜜も得られます。

## 10. 年間の作業予定
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵の点検、種子の発芽試験、畑の計画と堆肥の切り返し |
| 3月 | 耕起、排水路の設置、元肥 |
| 4月 | 夏ソバの播種(南部は上旬-中旬、中北部は下旬)。生態型の確認 |
| 5月 | 土寄せ、開花が始まる。開花期には何もまかない |
| 6-7月 | 夏ソバの収穫と天日干し(75-80%が熟したときに刈る)。7月中旬-下旬に中北部で秋ソバを播種(初霜の10-12週間前) |
| 8-9月 | 南部で秋ソバの播種。開花期の管理とミツバチの保護 |
| 10-11月 | 秋ソバの収穫、天日干し、脱穀、乾燥(水分13-14%)、貯蔵、種子の確保 |
| 12月 | 脱殻と製粉、ソバもやしの栽培、貯蔵の点検 |

> **忘れてはならない5つ: 生態型の確認、排水、開花期に何もまかないこと、75-80%が熟したときの収穫、アレルギーへの注意。**
