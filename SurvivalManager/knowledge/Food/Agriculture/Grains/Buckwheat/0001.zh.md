## 引言
&nbsp;&nbsp;&nbsp;荞麦（Fagopyrum esculentum）不是禾本科，而是蓼科的双子叶植物，像谷物一样食用的是种子而不是颖果。每1,000㎡产150kg，每㎡561kcal，只有自给线的0.21倍，不能成为主食的支柱。它之所以仍被算作救荒作物，是因为从播种到收获只要60-75天，是最快的。在其他作物被干旱、洪水、晚霜毁掉的地方补播，当年内仍能有所收获。它还能在贫瘠地和酸性土壤上生长，肥料每㎡只需12g，水只需250mm，不需要防治，蛋白质的质量远胜谷物。弱点是怕霜、自交不亲和、种子寿命短、外壳坚硬以及过敏。

## 2. 植物概述
&nbsp;&nbsp;&nbsp;蓼科荞麦属的一年生草本，原产于中国西南部至喜马拉雅的高山地带。栽培种有普通荞麦（F. esculentum）和苦荞麦（F. tataricum）两种。叶呈三角形心脏状，茎直立中空，笔直的根吸肥力强。花为白色或淡粉色的总状花序，属于长花柱花与短花柱花必须互相接受花粉的自交不亲和，因此由昆虫（蜜蜂）传粉。果实是坚硬的三角形瘦果。它是无限生长型，花不断开放，种子从下往上依次成熟，所以等全部成熟，先熟的就会掉落。

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 发芽·幼苗期 | 播种后2周 | 三四天就出苗 |
| 营养生长期 | 2-5周 | 茎和叶增长 |
| 开花期 | 5-7周 | 昆虫授粉。磷、硼很重要 |
| 灌浆·成熟期 | 7-10周 | 从下往上依次成熟 |

| 每100g营养 | 含量 |
|:---|:---|
| 热量 | 364-374kcal（干种子） |
| 蛋白质 | 12.96-13.2g（占热量的13.9%）。不缺赖氨酸 |
| 碳水化合物 / 脂肪 / 膳食纤维 | 72.8g / 2.2g / 5.0g（脂肪低，不易酸败） |
| 其他 | 钙、铁、维生素K、B族维生素 |
| 芦丁 | 增强毛细血管壁的黄酮类。在靠近外壳的部分和芽、叶中较多，苦荞麦是普通荞麦的70-100倍。烹调不会大量破坏，储存越久越少 |

## 3. 栽培环境与品种
| 条件 | 最适 | 极限与影响 |
|:---|:---|:---|
| 生长温度 | 15-25℃ | 5-30℃。低于5℃生长停止，遇霜枯死 |
| 开花温度 | 17-19℃ | 超过30℃不能受精，只开花不结籽 |
| 发芽 | 25-31℃ | 0-4.8℃也能发芽 |
| 光 | 每天6-8小时 | 4小时以上。遮光40%仍保持产量的88% |
| 水 | 合计250mm | 发芽到开花70mm，盛花到成熟20mm。极怕过湿 |
| 土壤 | 排水良好的沙质土-壤土 | 耐酸性土，在石灰质、碱性土壤中长势差。湿黏土会失败 |

> **不要给荞麦撒石灰。这个对其他作物有益的做法，对荞麦有害。**

&nbsp;&nbsp;&nbsp;适合已经耕好的空闲地、其他作物失败的地块、偏酸的旧田、夹杂砾石的贫瘠地。要避开石灰质多的地和潮湿的低洼地。

| 生态型 | 代表品种 | 播种 |
|:---|:---|:---|
| 夏荞麦（春播型） | Yangjeol（68天，每1,000㎡ 121kg）、Yangjeol 2号（68天，155kg，产量最高，落粒少） | 春季 |
| 秋荞麦（夏播型） | Daesan（73天，130kg，芽菜出率970%） | 夏季 |

> **秋荞麦在春天播种，会开花但几乎不结籽。这是种荞麦时最常见、最致命的错误，所以种子来源不明时，要先确认生态型。**

&nbsp;&nbsp;&nbsp;苦荞麦可以自花授粉，不需要隔离，芦丁含量高，有利于留种和药用。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 浅耕20cm即可（热量回收倍数低，深耕得不偿失）。播种前务必挖排水沟，并把土打碎。不施石灰 |
| 施肥 | 每1,000㎡ 氮5.4kg、磷3.1kg、钾3.9kg、腐熟堆肥1,000-1,500kg。硼砂2-3kg可提高结实率。硅质肥料可减少倒伏 |
| 替代资源 | 少量腐熟堆肥、尿液稀释10倍（生长初期）、骨粉，草木灰呈碱性，只可少量 |

&nbsp;&nbsp;&nbsp;荞麦吸肥力极强，收获后留在地里的养分很少，所以必须用肥料或豆科来恢复。无投入产量保持率为45.1%。

| 茬口 | 地区 | 播种 | 收获 |
|:---|:---|:---|:---|
| 夏荞麦 | 中北部 | 4月下旬-5月上旬 | 7月上旬-中旬 |
| 夏荞麦 | 南部 | 4月上旬-中旬 | 6月下旬-7月上旬 |
| 秋荞麦 | 中北部 | 7月中旬-下旬 | 10月上旬-中旬 |
| 秋荞麦 | 南部 | 8月上旬-中旬 | 10月下旬-11月中旬 |

| 播种方法 | 播种量（1,000㎡） | 备注 |
|:---|:---|:---|
| 撒播 | 8-10kg | 最快。赶着种的时候 |
| 条播 | 6-8kg，行距30cm | 可以除草 |
| 点播 | 0.5-2kg，行距30cm，株距15cm | 用种最少 |

&nbsp;&nbsp;&nbsp;播种深度2-5cm，轻轻覆土并压实。因自交不亲和，不要种得太稀。秋荞麦在初霜前10-12周播种。种子寿命短，发芽试验必不可少（超过1年的种子必须做），并用50-55℃的热水浸10-15分钟，或拌细灰。稻草覆盖有助于保墒和抑制杂草。

## 5. 水与栽培管理、病虫害
| 时期 | 水管理 |
|:---|:---|
| 发芽 | 不让土壤变干 |
| 生长初期 | 防止过湿是全部。播种后立刻出现的涝害是最常见的失败原因，所以要挖沟排水 |
| 开花期 | 需要充足的水 |
| 灌浆期 | 少量 |
| 成熟期 | 完全停水。淋雨会让种子掉落并发芽 |

&nbsp;&nbsp;&nbsp;花开了却不结籽，原因通常是这四种之一：高温、缺水、缺少传粉昆虫、生态型搞错。

| 管理 | 内容 |
|:---|:---|
| 杂草 | 几乎不需要。只拔掉显眼的大杂草，荞麦自己就能压制 |
| 倒伏 | 茎秆中空，容易倒。开花前培土，避免过密和氮肥过多 |
| 传粉 | 不要种得稀，开花期不喷任何药，保留田边的花以留住蜜蜂，上午摇晃植株人工授粉 |
| 其他 | 不需要摘心和追肥。收获前挂上反光的东西驱鸟 |

| 病虫害 | 不用农药的应对 |
|:---|:---|
| 茎腐病、灰霉病 | 排水与通风，摘除病部 |
| 白粉病 | 牛奶稀释5-10倍或小苏打液（每1L水加小苏打5g和少量肥皂），通风 |
| 蛾类、蚜虫 | 手捉、肥皂水（每1L水加纯肥皂5-10g）、保护天敌 |
| 鸟 | 最大的实际损失。稻草人、反光碎片、网 |

> **开花期不要喷任何东西。蜜蜂死了，当年就没有收成。**

| 缺素·过量 | 症状与处理 |
|:---|:---|
| 缺氮 | 发黄、植株矮小。腐熟堆肥、少量稀释尿液 |
| 缺硼 | 开花但不结籽。叶面喷施硼砂 |
| 缺铁 | 新叶发白。碱过多，停用草木灰和石灰 |
| 氮过量 | 只长个子并倒伏。停止施肥，培土 |

## 6. 间作与轮作
&nbsp;&nbsp;&nbsp;荞麦是不让田地闲置的作物。在6月挖完的马铃薯地、6月割完的大麦小麦地、收完的芝麻地里接着种秋荞麦，在4月播种、7月收获的夏荞麦的地里种白菜和萝卜，或在旱田种晚稻。荞麦连作无害，但产量会逐渐减少。

| 净化作物的效果 | 用途 |
|:---|:---|
| 抑制杂草 | 快速生长和化感物质，种一年即可清理被杂草占领的田地 |
| 抑制线虫 | 种在马铃薯或根菜之前 |
| 活化磷 | 吸收其他作物无法利用的磷，翻压后又回到土里 |
| 绿肥 | 种子成熟前、花开满时翻压 |

| 轮作 | 作物 |
|:---|:---|
| 第1年 | 荞麦 |
| 第2年 | 豆科（恢复氮素） |
| 第3年 | 马铃薯或根菜 |
| 第4年 | 谷物，或回到荞麦 |

## 7. 收获、脱壳、留种
| 步骤 | 内容 |
|:---|:---|
| 时机 | 播种后60-75天。75-80%的种子变黑成熟时收割（水分16%以下）。等全部成熟，就会损失下部的种子 |
| 收割 | 在露水干前的清晨，用镰刀从基部割下，不要摇晃，轻轻放倒 |
| 干燥 | 放在铺了布或草席的地上，扎成小捆晒3-5天。不要淋雨。然后脱粒，再在草席上晒2-3天，使水分降到13-14% |
| 判断 | 咬开去壳的籽粒会啪地裂开并有粉末，搓壳时沙沙碎裂，装瓶密封放一天不起雾 |
| 脱粒 | 用手捋（留种用）、在草席上用棍子轻敲（不要用力）、连袋摔在地上、踩踏、倒提着抖 |
| 秕壳 | 在微风中倒下、扬筛、扇风、过筛、水选（立刻晒干） |

&nbsp;&nbsp;&nbsp;脱壳（去掉三角形外壳）可以用臼轻轻舂后扬筛并反复进行，也可以把石磨上扇抬高到籽粒大小转动，或小火炒到外壳变脆后再舂，其中炒后再舂最合适。外壳可用来做枕芯、隔热材料、引火物。

| 留种 | 标准 |
|:---|:---|
| 限制 | 自交不亲和，套袋不起作用 |
| 隔离 | 与其他品种相隔500m以上，或把花期错开3周以上。一个地区只种一个品种最现实 |
| 选择 | 从30株以上无病、未倒伏的植株上均匀选取。使用先成熟的、下部的种子 |
| 保存 | 带壳，水分12-13%。常温下1-2年，从8个月起发芽率开始下降，所以每年重新留种。备足需要量的两倍 |

## 8. 储存
&nbsp;&nbsp;&nbsp;耐储性为SS。带壳储存，吃多少脱多少。脱壳后种子寿命会急剧缩短，芦丁也会被光分解。

| 项目 | 标准 |
|:---|:---|
| 条件 | 水分13-14%（种子12-13%），温度15℃以下，周围湿度65%以下，完全避光，每两个月检查一次，种子在春秋做发芽试验 |
| 容器 | 金属罐、玻璃瓶3年以上 / 陶罐2-3年 / 厚塑料袋1-2年 / 麻袋6个月-1年（三角形种子容易滚动漏出） |

| 虫害防治 | 方法 |
|:---|:---|
| 完全密封 | 容器装满后封上。最可靠 |
| 草木灰 | 把细灰拌入谷物体积的2-5%。吃之前洗掉 |
| 硅藻土 | 每1kg谷物1-3g。只在干燥时起作用 |
| 辅助 | 干辣椒·花椒、艾草·菖蒲叶、炒盐、木炭。隆冬时拿到外面放几天（低温），在60℃的阳光下薄摊（种子除外） |

## 9. 烹调与注意事项
> **荞麦过敏可能引发过敏性休克。在医疗中断的灾害中，这是真实的生命危险。**

&nbsp;&nbsp;&nbsp;荞麦蛋白的一部分是强致敏原，加热也不会减少，极少量、吸入面粉、荞麦壳枕头都可能引起反应。症状有荨麻疹、口喉发痒、腹痛、呕吐、呼吸困难，严重时血压下降、气道堵塞，在吃后几分钟到几十分钟内出现。第一次吃的人要从极少量（小孩一勺以下）开始，数天内逐渐增加；有过敏史的人不要吃；一旦出现反应，立即停止并不再尝试。要单独使用炊具，不要把荞麦壳枕头放在附近，如果是分享食物的集体，要事先弄清谁会有反应。

| 注意 | 内容 |
|:---|:---|
| 苦荞麦 | 芦丁高70-100倍，苦味强烈。一般摄入量没有问题，但正在服用抗凝药时要小心大量摄入。去壳去干净并多次冲洗，可减轻苦味 |
| 发霉的 | 霉菌毒素加热也不消失。全部丢弃 |
| 外壳、没煮熟 | 外壳无法消化，所以要去壳后再吃，淀粉要充分煮熟 |

&nbsp;&nbsp;&nbsp;荞麦不含面筋，不能吃小麦的人也可以吃，但面团没有黏性，难以做成面条或面包。可以掺入小麦粉或淀粉，或用热水和面。去壳后用石磨或臼磨粉，炒后再舂既省力又香。面粉比籽粒坏得快得多，所以只磨一个月吃的量。

| 烹调 | 燃料与要领 |
|:---|:---|
| 炒面 | 加水调开立即吃。不需要烹调燃料 |
| 面糊粥 | 把面粉调入水中煮5-10分钟。效率最高 |
| 荞麦冻（muk） | 面粉加水边搅边煮，再放凉凝固。可吃数天 |
| 煎饼、面条 | 煎薄（厚了里面不熟）。面条煮的时间短 |
| 余热烹调 | 煮开后关火并包裹保温，可把燃料减少一半以上 |

&nbsp;&nbsp;&nbsp;荞麦芽的做法是：带壳浸水6-12小时，沥水后摊在盆或布上，每天喷水两三次。在暗处3-4天长出黄芽，见光两天变绿，5-7天长到5-10cm时去掉外壳食用。这是不需要土壤和田地、冬天五天就能得到新鲜绿色蔬菜的办法，芦丁和维生素比种子多。兼顾储存的加工有：炒籽粒（密封6个月）、炒面（3-6个月）、干荞麦冻（1年）、淀粉（数年）。开花期还可以从蜜蜂那里得到荞麦蜜。

## 10. 全年作业计划
| 月 | 作业 |
|:---|:---|
| 1-2月 | 检查储存、种子发芽试验、制定田间计划并翻堆肥 |
| 3月 | 耕地、修排水沟、施基肥 |
| 4月 | 播夏荞麦（南部上旬-中旬，中北部下旬）。确认生态型 |
| 5月 | 培土，开始开花。开花期不喷任何东西 |
| 6-7月 | 夏荞麦收获和晾晒（75-80%成熟时割）。7月中旬-下旬在中北部播秋荞麦（初霜前10-12周） |
| 8-9月 | 在南部播秋荞麦。花期管理与保护蜜蜂 |
| 10-11月 | 秋荞麦收获、晾晒、脱粒、干燥（水分13-14%）、储存、备留种子 |
| 12月 | 脱壳与磨粉、种荞麦芽、检查储存 |

> **不能忘记的五件事：确认生态型、排水、开花期不喷药、75-80%成熟时收割、防范过敏。**
