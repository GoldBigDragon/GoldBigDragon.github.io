### 1-3. 如何解读优势

&nbsp;&nbsp;&nbsp;评级达到S以上的项目有7个：蛋白质密度S、收获速度S、施肥需求S、耗水量S、设施负担SS、防治自立度SS、耐储性SS、连作适应性SS。综合评级为C的作物身上出现这么多最高等级，实属罕见。原因只有一项，单位面积热量D这一项就把其他一切都压了下去。

&nbsp;&nbsp;&nbsp;收获速度S是荞麦的身份标志。60-75天比本书涉及的任何作物都快。粟为65-80天，与之接近，但荞麦稍快，而且最重要的是，荞麦可以在计划之外的地块临时播种。在韩国，无论是夏季作物因干旱而全军覆没的7月，还是春季作物因晚霜枯死的5月，抑或是因病害而翻毁的那片田地，播下荞麦都能在当年收获点什么。没有哪种作物比荞麦更配得上救荒作物这个说法。

&nbsp;&nbsp;&nbsp;蛋白质密度S是谷物中很少见的等级。蛋白质占热量的比例为13.9%，是需求线的1.4倍，且必需氨基酸评分超过90，获得加分。这最后一项才是关键。禾本科谷物无一例外都缺赖氨酸，没有豆类就无法凑齐完整的蛋白质组成，而荞麦属于蓼科，不受这一局限，赖氨酸充足。在没有豆类的情况下，荞麦本身就能提供接近完整的蛋白质。

&nbsp;&nbsp;&nbsp;防治自立度SS也很有实际意义。荞麦几乎不需要打药。生育期短，病害没有时间蔓延，已知的病虫害种类本身就少，也没有致命的种类。在农药完全断绝的条件下也无需处理，这一点同时减少了劳动量和风险。

&nbsp;&nbsp;&nbsp;连作适应性SS背后有特殊的原因。荞麦不仅耐连作，仅凭种植本身就能整理田地。根系分泌的物质能降低土壤线虫密度，快速生长又能覆盖地面、压制并抑杀杂草。这正是西方称其为净化作物、用于整理田地的原因。在既无农药也无地膜的条件下，它是为数不多能让田地恢复生机的手段之一。

> **荞麦的价值不在产量，而在时机与蛋白质。它是在其他一切计划都落空之处，两个月内就能拿出收成的作物。**

### 1-4. 如何解读劣势

&nbsp;&nbsp;&nbsp;没有被评为E的项目。最低的是单位面积热量D、持续性D、耐寒性D、整地·挖掘能耗D。

&nbsp;&nbsp;&nbsp;单位面积热量D决定了其余的一切。每㎡561kcal，只有玉米的26%、高粱的43%。仅凭这一数字，荞麦就无法成为主食。无论土地多么广阔，只要能种玉米或高粱，那都更划算。选择荞麦的情形只有两种：种其他作物为时已晚，以及土地贫瘠到其他作物都无法生长。

&nbsp;&nbsp;&nbsp;整地·挖掘能耗D是同一问题的另一种体现。热量回收倍数3.9倍，意味着回收的热量还不到耕地所耗能量的4倍。与玉米的16.8倍相比，相差四倍以上。在必须靠人力耕地的条件下，这个效率相当差。为了种荞麦而新开垦土地大多得不偿失，把它播在已经耕好的闲田里才是合理的用法。

&nbsp;&nbsp;&nbsp;耐寒性D压缩了可栽培的时间窗口。5℃以下生长停止，怕霜。秋荞麦必须在初霜前10到12周播种，晚于此时就会在灌浆期遭遇霜冻。

&nbsp;&nbsp;&nbsp;种子寿命C和自家留种A也应一并考察。荞麦种子在常温下放1到2年，发芽力就会明显下降。据报告，大约从32周，也就是8个月左右开始下降。不能像其他谷物那样存放好几年份，必须每年重新留种。而且荞麦是自交不亲和作物，单株无法结实，必须依靠昆虫或风来传播其他植株的花粉。由于是蜜源作物，蜜蜂通常会主动前来，但如果假设蜜蜂消失，这种依赖就会变成弱点。

&nbsp;&nbsp;&nbsp;最后还有一个评价表上体现不出的弱点，那就是过敏。荞麦因人而异会引发严重的过敏反应，罕见情况下会发展为过敏性休克。在医疗中断的灾害情况下，这是现实存在的风险。第14节将详细说明。

## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

&nbsp;&nbsp;&nbsp;荞麦是蓼科(Polygonaceae)荞麦属(Fagopyrum)的一年生双子叶植物。由于不属于禾本科，严格来说并非谷物，因其种子被当作谷物食用，故称为假谷物。它与皱叶酸模、蓼、酸模、大黄同属一个家族。

&nbsp;&nbsp;&nbsp;荞麦原产于中国西南部至喜马拉雅一带的高山地区，那里夏季短而凉爽，土壤浅薄且偏酸性。荞麦之所以能在60-75天内结实，是因为必须在短暂的夏季内完成整个生活史；它适应酸性贫瘠地，也是这种环境造就的结果。反过来，荞麦从未经历过的条件是闷热和潮湿，因此气温超过30℃就无法受精。

&nbsp;&nbsp;&nbsp;栽培种有甜荞(Fagopyrum esculentum)和苦荞(F. tataricum)两种。苦荞的芦丁含量可达甜荞的70-100倍，但正如其名，苦味也很浓。另一方面，它可以自花授粉，留种因此容易得多，这是它的优势。

### 2-2. 形态

| 器官 | 特征 |
|---|---|
| 叶 | 三角形心形。互生，叶柄长 |
| 茎 | 直立，中空，有时带红色 |
| 根 | 直根。根毛多，吸肥能力强 |
| 花 | 白色或淡粉色总状花序。自交不亲和，靠昆虫传粉 |
| 果实 | 三角形瘦果，包裹在坚硬的黑色或褐色外壳中 |

&nbsp;&nbsp;&nbsp;荞麦的花有一种特殊结构。同一品种中，雌蕊长、雄蕊短的长花柱花，与相反的短花柱花两种混合开放。长花柱花只能被短花柱花的花粉授粉，短花柱花也只能被长花柱花的花粉授粉，这就是所谓的自交不亲和。不仅自身花粉无效，同一形态的花之间也不能相互授粉。因此荞麦必须依靠昆虫，田里也必须有足够多的植株。只种几株的话，花开得再繁盛，也几乎结不出种子。

&nbsp;&nbsp;&nbsp;果实的三角形外壳在实际操作上也很重要。这层壳厚而坚硬，松松地包着籽粒。厚而坚硬意味着有利于贮藏，松松地包裹则意味着相对容易去除。这层壳本身还可用作枕芯和隔热材料，因此不会被丢弃。

### 2-3. 生长阶段

| 阶段 | 时期 | 关键生理 | 重要养分 |
|---|---|---|---|
| 发芽·幼苗期 | 播种后2周 | 发芽非常快，3-4天就会出苗 | 磷、氮 |
| 营养生长期 | 2-5周 | 茎叶迅速增多 | 氮 |
| 开花期 | 5-7周 | 开花，昆虫授粉 | 磷、硼 |
| 灌浆·成熟期 | 7-10周 | 籽粒成熟，从下往上依次成熟 | 钾 |

> **荞麦在同一株上会持续开花，种子也依次成熟。等到全部成熟，先熟的籽粒就会全部脱落。**

&nbsp;&nbsp;&nbsp;荞麦在栽培上最大的特点是无限生长。下部的花开放、籽粒成熟的同时，上部仍不断开出新花。因此到了收获期，同一株上会同时存在已经成熟的籽粒、正在灌浆的籽粒和尚未开败的花。如果等到全部成熟，下部已熟的籽粒就会脱落；如果收割过早，上部又会变成秕粒。所以荞麦的收获标准不是看全部，而是看比例：籽粒成熟75-80%时就是适宜的收获期。

&nbsp;&nbsp;&nbsp;开花期气温至关重要。开花适温为17-19℃，超过30℃就无法受精。开花却不结实的现象正是由此而来。夏荞麦一旦遇上盛夏的酷热就会出现这种情况，因此荞麦要把播种时期安排得让开花期落在初夏或初秋。

### 2-4. 每100克的营养成分

| 营养素 | 含量 | 备注 |
|---|:---:|---|
| 热量 | 364-374kcal | 以干燥种子为基准 |
| 碳水化合物 | 72.8g | 大部分为淀粉 |
| 蛋白质 | 12.96-13.2g | 占热量13.9%，远超一般谷物 |
| 脂肪 | 2.2g | 含量低，酸败风险小 |
| 膳食纤维 | 5.0g | 多集中在近壳部位 |
| 芦丁 | 含有 | 属于类黄酮，也称维生素P |
| 钙 | 丰富 | 作为谷物含量偏高 |
| 铁 | 含有 | 有助于预防贫血 |
| 维生素K | 含有 | 谷物中少见的成分 |
| 维生素B群 | 硫胺素、核黄素、泛酸、叶酸 | 种类齐全 |

&nbsp;&nbsp;&nbsp;荞麦营养的核心在于蛋白质的品质。13g的含量在谷物中已属较高，但真正的价值在于氨基酸组成。禾本科谷物无一例外都缺赖氨酸，所以无论吃多少大米、小麦、玉米、高粱、粟，没有豆类就凑不齐完整的蛋白质组成。荞麦属于蓼科，不受此局限，赖氨酸充足，必需氨基酸评分90以上的评价正是这个意思。

&nbsp;&nbsp;&nbsp;在灾害情况下，这种差异至关重要。豆类歉收的年份，或是弄不到豆子的情况下，只吃谷物虽能填饱肚子，蛋白质缺乏却会悄悄袭来：肌肉流失、伤口不愈、免疫力下降。荞麦本身就能在很大程度上解决这个问题。它给出的热量虽少，但这份不多的热量所附带的蛋白质品质却截然不同。

### 2-5. 芦丁

&nbsp;&nbsp;&nbsp;芦丁是荞麦中不可或缺的成分。它属于类黄酮类物质，也称维生素P，是荞麦区别于其他谷物的显著之处。

| 项目 | 内容 |
|---|---|
| 作用 | 增强毛细血管壁，降低血管通透性 |
| 相关 | 预防高血压和动脉硬化，减轻出血倾向 |
| 分布 | 多存在于种皮和近壳部位，以及嫩芽和嫩叶中 |
| 品种差异 | 苦荞是甜荞的70-100倍 |
| 损失 | 碾磨越精、贮藏越久，含量越少 |
| 加热 | 烹饪不会使其大量破坏 |

&nbsp;&nbsp;&nbsp;芦丁在灾害情况下有两方面的意义。第一，在新鲜蔬菜断绝的状态下有助于维护血管健康。维生素C不足会使毛细血管变弱，导致牙龈出血、容易淤青，芦丁在这方面能起到部分补充作用。第二，可以利用荞麦芽。把种子泡水后放在阴暗处，几天就能发芽，芽中所含的芦丁和维生素远多于种子本身。这是在冬天不需要土、不需要田地，几天内就能获得新鲜绿色蔬菜的办法。第16节将详细说明。

&nbsp;&nbsp;&nbsp;芦丁集中在靠近黑色外壳的部位。比起精磨成白色的荞麦粉，连壳一起磨成的粗粉所含的芦丁要多得多。在灾害情况下也没有余力精细碾磨，因此自然而然地会摄入更多芦丁。
