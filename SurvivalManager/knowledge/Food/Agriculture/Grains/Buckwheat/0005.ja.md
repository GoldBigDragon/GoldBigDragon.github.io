## 12. 収穫と脱穀

### 12-1. 時期の判断 - 75~80%の原則

| 基準 | 内容 | 判定 |
|---|---|---|
| 成熟比率 | 種実の75-80%が黒く熟したとき | 収穫の適期です |
| 日数 | 播種後60-75日 | 品種とその年の気温によって異なります |
| 種の色 | 緑色から茶色を経て黒く変わります | 下から順に熟していきます |
| 種の硬さ | 爪で押してもへこみません | 完熟です |
| 水分含量 | 16%以下 | 収穫の基準です |
| 脱粒 | 手でしごくと黒い種が簡単に落ちます | 急ぐ必要があります |
| 天気 | 晴れた日が続いた後 | 濡れたまま刈ると乾燥が難しくなります |

&nbsp;&nbsp;&nbsp;ソバの収穫の難しさは、無限伸育（無限花序）から来ます。一株の中で下のほうの種はすでに黒く熟して落ちようとしているのに、上のほうではまだ花が咲いています。全部が熟すのを待つことはできず、かといって早く刈れば上のほうがすべて実の入らない粒になってしまいます。だから基準が比率なのです。75-80%が黒く熟したときが、最も損失の少ない時点です。

&nbsp;&nbsp;&nbsp;この判断をするには、畑を回って株を見なければなりません。何株かを選んで種を数え、黒いものとそうでないものの比率を見積もります。慣れれば畑全体の色だけでも分かるようになります。ソバ畑が全体的に茶色を帯び始めたら、その頃です。

> **ソバは熟すのを待つうちに下のほうを全部落としてしまうのが最も多い損失です。75%が熟したら刈ります。**

&nbsp;&nbsp;&nbsp;天気も併せて見る必要があります。雨の日や湿った日に収穫すると水分が多く乾燥に手間取り、その間にカビが生えます。雨の予報があれば、少し早くても刈るほうがよいです。逆に晴れた日が数日続きそうであれば、一日二日待ってもかまいません。

### 12-2. 収穫のこつ

| 順序 | 内容 | 理由 |
|---|---|---|
| 1 | 露が乾く前の早朝に刈ります | 湿っているときは種が落ちにくいです |
| 2 | 根元から鎌で刈ります | 茎が柔らかく簡単に刈れます |
| 3 | 刈るときは揺らさず、そっと倒します | ソバは脱粒が非常に起こりやすいです |
| 4 | 畑に布やむしろを敷き、その上に置きます | 落ちた種を回収します |
| 5 | 束に結びます | 大きすぎると中まで乾きません |
| 6 | 畑や庭先で3-5日陽干しします | この過程で上のほうの未熟粒も実ります |
| 7 | 雨に当てません | 濡れるとカビと穂発芽が起こります |

&nbsp;&nbsp;&nbsp;早朝に刈るというのは、ソバに特有のこつです。ソバの種は非常に落ちやすく、露に濡れているときは落ちにくいのですが、日が昇って乾くと鎌を入れただけでバラバラと落ちてしまいます。この差が収穫量の10%以上を左右します。

&nbsp;&nbsp;&nbsp;刈った後に3-5日陽干しする過程が重要です。この期間に茎に残った養分が未熟な種へ移動し、上のほうの種もある程度実ります。刈ってすぐに脱穀すると、まだ熟していない種がそのまま実の入らない粒になってしまいます。後熟の効果を得るための数日間です。

### 12-3. 穀物の乾燥 - 水分13-14%まで

&nbsp;&nbsp;&nbsp;穀物貯蔵のすべては水分で決まります。水分が15%を超えるとカビが育ち、13%を下回るとカビも虫もほとんど活動を止めます。収穫時点のソバの水分は16%前後です。他の穀物より低めから始まるほうですが、ここから13-14%までさらに下げる必要があります。

| 段階 | 方法 | 期間 | 到達水分 |
|---|---|---|---|
| 1. 陽干し | 刈った株を畑や庭先に広げるか立てて乾かします | 3-5日 | 15-16% |
| 2. 脱穀 | 十分に乾いた後に落とします | 1日 | - |
| 3. 仕上げ乾燥 | むしろや布に広げて日に当てて乾かします | 2-3日 | 13-14% |
| 4. 蒸らし | 日陰で一日ほど置き水分を均一にします | 1日 | 均一化 |

&nbsp;&nbsp;&nbsp;日に当てて乾かすときの原則はどの穀物でも同じです。第一に、地面に直接広げません。土の湿気が下側を再び湿らせます。第二に、3-5cmを超えて積まず、一日に三、四回返します。第三に、日が傾いたら取り込むか覆います。夜露に当たると、昼間に抜けた水分がまた戻ってしまいます。第四に、急いで乾かしません。表面だけ乾いて中に水分が閉じ込められると、後でカビが生えます。

&nbsp;&nbsp;&nbsp;ソバに特有の注意点があります。ソバの種は三角形でよく転がるため風で散らばりやすく、皮が滑らかで傾斜面では滑り落ちます。乾かす場所に縁を巡らせるか、むしろの端を折り上げておくとよいです。

&nbsp;&nbsp;&nbsp;計量器なしで水分を見積もる方法があります。

| 方法 | 手順 | 判定 |
|---|---|---|
| 噛んでみる | 皮をむいた粒を奥歯で噛みます | ポキッと割れて粉が出れば13-14%です |
| 皮の音 | 一握り握ってこすり合わせます | 皮がカサカサと音を立てて砕ければ乾いています |
| 塩試験 | 乾いた塩ひとさじと穀物一握りを瓶に入れて振り、15分置きます | 塩が瓶の壁に付けば水分が高いです |
| 手の感触 | 一握り握って開きます | 滑るように散らばれば乾いています |
| 瓶試験 | ガラス瓶に半分入れて密封し一日置きます | 瓶の内側に湯気が曇ればさらに乾かす必要があります |

&nbsp;&nbsp;&nbsp;火力を使うときは50度を超えないようにします。それ以上だと種子として使えなくなり、ソバは種子の寿命が短い作物なのでより敏感です。手を当てて温かい程度までにとどめます。

### 12-4. 脱穀 - 道具なしで行う方法

&nbsp;&nbsp;&nbsp;ソバは脱穀が非常にやさしい作物です。種が茎にゆるく付いているため、乾けば軽い衝撃でも落ちます。むしろ落ちやすすぎて損失が生じるほうが問題です。

| 方法 | 手順 | 規模 | 備考 |
|---|---|---|---|
| 手でしごく | 茎を持って手でしごき落とします | 少量 | 損失が最も少ないです。種子用に使います |
| 叩く | むしろの上に広げ、棒や殻竿で軽く叩きます | 多い | 最も一般的です。強く打つ必要はありません |
| 袋の中で打つ | 袋に入れて袋ごと地面に打ち付けます | 中程度 | 種が飛び散りません |
| 踏む | むしろに広げて足で踏みます | 多い | 力が少なくて済みます |
| 振る | 束を逆さに持って桶の中で振ります | 中程度 | ソバに特によく合います |

&nbsp;&nbsp;&nbsp;ソバの脱穀では、強く打たないことがこつです。種が非常に落ちやすいので軽く叩くだけで十分であり、強く打つと三角形の皮が割れて粒が傷み、実の入らない粒が多くなります。束を逆さに持って大きな桶の中で振るだけでも、かなりの量が落ちます。

&nbsp;&nbsp;&nbsp;脱穀した後の茎と葉は、そのまま畑に敷くか堆肥に使います。ソバの茎は柔らかく分解が速く、ソバが土から吸い上げたリン酸とカリウムを土に返します。

### 12-5. 実の入らない粒を飛ばす

| 方法 | 手順 | 条件 |
|---|---|---|
| 風に流す | 風のある日に高い所からゆっくり落とします | ソバの種は軽いので弱い風がよいです |
| 箕を使う | 箕に入れて前に押し引きしながら浮かせます | 最も確実です |
| あおぐ | 一人が注ぎ、もう一人が風を送ります | 強さを調節できます |
| ふるいがけ | 粗いふるいで茎の切れ端を、細かいふるいでくずを分けます | ソバは粒が大きいのでふるいがけが簡単です |
| 水選別 | 水に入れて浮く実の入らない粒を取り除きます | 必ずすぐにまた乾かす必要があります |

&nbsp;&nbsp;&nbsp;ソバは種が軽めなので風の調節に注意が必要です。強い風に流すと充実した種まで飛んでいきます。あおぐような強さを調節できる方法や箕を使う方法が安全です。

### 12-6. 脱皮 - 三角形の殻をむく

&nbsp;&nbsp;&nbsp;ソバは脱穀の次にもう一段階あります。三角形の硬い殻をむく脱皮です。この殻は食べられないほど硬く、むかなければ粉にすることもできません。

| 方法 | 道具 | 手順 | 備考 |
|---|---|---|---|
| 臼つき | 臼と杵 | 軽くついてはふるいがけを繰り返します | 強くつくと粒まで砕けます |
| 石臼を開けて回す | 石臼 | 上の石を粒の大きさ分浮かせて回します | 殻だけ割れて粒は残ります |
| 水を含ませてつく | 臼 | 水を軽くふりかけ30分置いてからつきます | 殻がよくむけます |
| 炒ってからつく | 釜と臼 | 弱火で炒って殻をパリッとさせてからつきます | ソバに最もよく合います |
| 石でこする | 凹んだ石と丸い石 | 手でこすって殻を割ります | 少量に向いています |
| 板の間でこする | 板二枚 | 間に入れて押しつけてこすります | 簡単に作れます |

&nbsp;&nbsp;&nbsp;ソバの脱皮のこつは他の穀物と反対です。殻が粒にぴったり付いているのではなく、ゆるくかぶさっているだけなので、こすってむくのではなく割って開ける必要があります。そのため石臼の上の石を粒の直径分浮かせて回すと、殻だけ割れて中の粒はそのまま残ります。これが最も効率的な方法で、商業用のソバ脱皮機も同じ原理で動いています。

&nbsp;&nbsp;&nbsp;炒ってからつく方法も効果的です。弱火で数分炒ると殻の水分が飛んでパリッとなり、はるかに割れやすくなると同時に、ソバ特有の香ばしい香りが立ちます。ただし炒ったものは種子として使えないので、種子用は別に取っておく必要があります。

&nbsp;&nbsp;&nbsp;むき取った殻は捨てません。ソバの殻は軽く通気性がよく、湿気を含まないため枕の中身として長く使われてきました。断熱材としても使われ、燃やせばよい焚き付けになり、灰は肥料になります。穀物自体の収穫量が少ないソバでは、副産物の使い道が相対的に大きいのです。

## 13. 採種

### 13-1. 自家不和合性がもたらす制約

&nbsp;&nbsp;&nbsp;ソバの採種は、この文書の他の作物より手間がかかります。自家不和合性の他家受精作物だからです。

| 項目 | 内容 | 含意 |
|---|---|---|
| 受精様式 | 長柱花と短柱花が互いの花粉を受け取る必要があります | 一株だけでは実を結びません |
| 媒介 | ハチなどの昆虫が運びます | 昆虫がいなければ結実しません |
| 隔離 | 他の品種と離す必要があります | 袋かけが通用しません |
| 集団維持 | 複数の個体からまんべんなく受け取る必要があります | 一株だけから受け取ってはいけません |

&nbsp;&nbsp;&nbsp;他の作物で使われる袋かけが、ソバには通用しません。袋の中に閉じ込めると同じ花形同士でしか出会えず受精しないからです。長柱花と短柱花を選んで組み合わせてやれば可能ですが、現実的ではありません。そのためソバの品種維持は距離隔離と時期隔離に頼ります。

| 方法 | 内容 | 効果 |
|---|---|---|
| 距離隔離 | 他の品種と最低500m離します | ハチが飛び回る距離なので余裕を持って取ります |
| 時期隔離 | 開花期を3週間以上ずらします | 夏型と秋型は自然にずれます |
| 単一品種 | 一地域で一品種だけ植えます | 最も現実的です |
| 苦ソバの利用 | 自家受精が可能です | 隔離が不要です |

&nbsp;&nbsp;&nbsp;狭い地域で最も現実的な方法は、一品種だけを植えることです。夏ソバと秋ソバを両方植えても開花期が自然にずれるため混じりません。問題は隣家が別の品種を植える場合で、これは個人では制御できません。災害状況で集落単位で品種をそろえる合意があれば、それが最良の解決策です。

### 13-2. 採種個体の選抜と保管

| 基準 | 内容 | 理由 |
|---|---|---|
| 個体選抜 | 病徴がなく倒れておらず結実の多い株 | 形質が受け継がれます |
| 複数株から | 最低30株以上からまんべんなく受け取ります | 他家受精作物なので多様性が必要です |
| 収穫時期 | 通常より少し遅めにして十分に熟させます | 未熟な種子は発芽率が下がります |
| 下のほうの種 | 先に熟した下のほうの種を使います | 最も充実しています |
| 形態 | 必ず殻付きのまま保管します | 脱皮すると寿命が急激に縮みます |
| 水分 | 12-13% | 種子はもう少し乾燥させます |
| 寿命 | 常温1-2年 | 他の穀物より短いです |
| 数量 | 必要量の2倍以上 | 発芽率の低下を見込みます |

> **ソバの種子は8か月ほどから発芽率が下がり始めます。他の穀物のように数年分を蓄えておくことはできず、毎年新しく採る必要があります。**

&nbsp;&nbsp;&nbsp;種子寿命Cはソバの実質的な弱点です。モロコシやアワは2-3年、条件が良ければさらに長く持ちますが、ソバは1-2年です。不作で一年採種に失敗すると、そのまま系統が途絶えかねません。対応は二つです。第一に、毎年必ず採種します。第二に、最も涼しく乾燥した場所に保管します。温度を10℃下げると種子寿命はおよそ2倍に延びます。

&nbsp;&nbsp;&nbsp;ソバは種子の所要量が少ないことが救いです。点まきなら1,000㎡に0.5-2kgで足ります。必要量の2、3倍を取り分けておいても負担は大きくありません。

### 13-3. 発芽試験

&nbsp;&nbsp;&nbsp;ソバは発芽試験が特に重要です。種子の寿命が短く、一年経つだけでも発芽率が大きく変わるためです。濡れた布に種を50粒包んで暖かい場所に置き、3-4日待ちます。ソバは発芽が早く他の穀物より判定が早いです。50粒中40粒以上ならそのまま使い、30-40粒なら播種量を1.5倍に増やし、30粒未満なら新しい種子を入手する必要があります。

## 14. 毒性と注意事項

### 14-1. ソバアレルギー - 最も重要な注意点

&nbsp;&nbsp;&nbsp;ソバ自体には毒性はありません。しかしソバには他の作物にはない危険が一つあります。アレルギーです。

| 項目 | 内容 |
|---|---|
| 原因 | ソバのタンパク質の一部が強いアレルギー抗原として作用します |
| 頻度 | 多くはありませんが、韓国、日本、中国で相対的に多く報告されています |
| 症状 | じんましん、口や喉のかゆみ、腹痛、嘔吐、呼吸困難 |
| 重い場合 | アナフィラキシー。血圧が下がり気道がふさがれ命に関わります |
| 発現速度 | 食べた後、数分から数十分以内に現れます |
| 熱 | 加熱しても抗原性はほとんど減りません |
| 微量 | ごく少量でも反応が現れることがあります |
| 接触 | 食べなくてもソバ粉を吸い込んだり、ソバ殻枕で反応が出たりすることがあります |

> **ソバアレルギーはアナフィラキシーにつながることがあります。医療が途絶えた災害状況では、これは実質的な生命の危険です。**

&nbsp;&nbsp;&nbsp;災害状況でこの問題が持つ重さは平時とは異なります。平時であれば救急室で処置を受けられますが、病院が機能していない状況ではアナフィラキシーに対してほとんど手の打ちようがありません。したがって予防的な対応が必要です。

| 状況 | 対応 |
|---|---|
| 初めて食べる人 | ごく少量から始め、反応を見ながら数日かけて増やします |
| 小さな子ども | 特に注意します。最初はひとさじ以下から始めます |
| アレルギーの既往がある人 | 食べません。他の作物で代用します |
| 反応が出たとき | 直ちに中止し、再び試しません |
| 調理道具 | アレルギーのある人がいれば道具を別にします |
| ソバ殻枕 | アレルギーのある人の近くに置きません |

&nbsp;&nbsp;&nbsp;共同体単位で食料を分ける状況であれば、誰がソバに反応するかをあらかじめ把握しておくとよいです。ソバ麺やソバ寒天が混ざった料理を知らずに食べてしまう事故が実際に起こります。ソバが入った料理は表示するか別にしておくのが安全です。

### 14-2. 苦ソバのルチン

| 項目 | 内容 |
|---|---|
| 含有量 | 普通ソバの70-100倍です |
| 安全性 | 一般的な摂取量では問題ありません |
| 味 | ルチンが分解されると強い苦味が出ます |
| 注意 | 抗凝固薬を服用中の場合、大量摂取に注意します |
| 処理 | 殻をよくむいて何度もすすぐと苦味が減ります |

&nbsp;&nbsp;&nbsp;苦ソバのルチンは、毒性というより薬理作用の強い成分です。毛細血管を丈夫にし血管透過性を下げる作用があり、普段はよい方向に働きます。ただし血液凝固に関わる薬を飲んでいる場合は相互作用の可能性があるため、大量摂取は避けるほうがよいです。災害状況でそうした薬を飲み続けているケースはまれでしょうが、記録しておきます。

### 14-3. その他の注意点

| 項目 | 内容 | 対応 |
|---|---|---|
| カビが生えたもの | カビ毒は加熱しても消えません | 全量廃棄します |
| ファゴピリズム | ソバのファゴピリンという成分が光過敏症を引き起こすことがあります | 家畜がソバの葉を大量に食べて日光に長時間当たったときに現れます |
| 殻 | 消化されず口に残ります | 必ずむいてから食べます |
| 加熱不足のもの | でんぷんが消化されません | 十分に加熱します |
| 一般的な摂取 | 安全です | アレルギーがなければ問題ありません |

&nbsp;&nbsp;&nbsp;ファゴピリズムは主に家畜に現れる現象です。ソバの葉と茎に含まれるファゴピリンという色素が体内に入ると、皮膚が日光に敏感になり、白い毛の部位に炎症と潰瘍が生じます。ソバの葉を大量に与えた家畜を一日中日なたに置くと発生することがあります。ソバの残さを家畜に与えるときは量を制限し日陰を確保すれば問題ありません。人が食べる種子にはこの成分はほとんど含まれていません。
