## 들어가며
&nbsp;&nbsp;&nbsp;메밀(Fagopyrum esculentum)은 벼과가 아니라 마디풀과의 쌍떡잎식물이며, 곡물처럼 먹는 것은 낟알이 아니라 씨앗입니다. 1,000㎡에서 150kg, ㎡당 561kcal로 자급선의 0.21배밖에 나오지 않아 주식의 축이 될 수 없습니다. 그래도 구황작물로 꼽히는 까닭은 파종에서 수확까지 60-75일로 가장 빠르다는 점입니다. 다른 작물이 가뭄, 홍수, 늦서리로 무너진 자리에 뿌려 그해 안에 무언가를 거둘 수 있습니다. 또한 척박한 땅과 산성 토양에서 자라고, 거름은 ㎡당 12g, 물은 250mm면 되며, 방제가 필요 없고, 단백질의 질이 곡물을 압도합니다. 약점은 서리, 자가불화합성, 짧은 종자 수명, 단단한 껍질, 알레르기입니다.

## 2. 식물 개요
&nbsp;&nbsp;&nbsp;마디풀과 메밀속의 한해살이로 중국 남서부에서 히말라야에 이르는 고산지대가 원산입니다. 재배종은 일반메밀(F. esculentum)과 쓴메밀(F. tataricum)이 있습니다. 잎은 삼각형 심장 모양, 줄기는 곧고 속이 비어 있으며, 곧은 뿌리는 흡비력이 강합니다. 꽃은 흰색 또는 연분홍색 총상꽃차례이고, 장주화와 단주화가 서로의 꽃가루를 받아야 하는 자가불화합성이라 곤충(벌)이 꽃가루를 옮깁니다. 열매는 단단한 삼각형 수과입니다. 무한생육이어서 꽃이 계속 피고 씨가 아래부터 차례로 익으므로, 전부 익기를 기다리면 먼저 익은 것이 떨어집니다.

| 단계 | 시기 | 핵심 |
|:---|:---|:---|
| 발아·유묘기 | 파종 후 2주 | 사나흘이면 올라옵니다 |
| 영양생장기 | 2-5주 | 줄기와 잎이 늘어납니다 |
| 개화기 | 5-7주 | 곤충이 수분합니다. 인산, 붕소가 중요 |
| 등숙·성숙기 | 7-10주 | 아래부터 차례로 익습니다 |

| 100g당 영양 | 함량 |
|:---|:---|
| 열량 | 364-374kcal (마른 씨앗) |
| 단백질 | 12.96-13.2g (열량 대비 13.9%). 라이신 부족이 없음 |
| 탄수화물 / 지방 / 식이섬유 | 72.8g / 2.2g / 5.0g (지방이 낮아 산패 위험이 적음) |
| 그 밖 | 칼슘, 철, 비타민 K, 비타민 B군 |
| 루틴 | 모세혈관 벽을 튼튼하게 하는 플라보노이드. 껍질 가까운 부분과 싹·잎에 많고, 쓴메밀은 일반메밀의 70-100배. 조리해도 크게 파괴되지 않으며 오래 저장할수록 줄어듦 |

## 3. 재배 환경과 품종
| 조건 | 최적 | 한계와 영향 |
|:---|:---|:---|
| 생육 기온 | 15-25℃ | 5-30℃. 5℃ 아래에서 생육이 멈추고 서리에 고사 |
| 개화 온도 | 17-19℃ | 30℃가 넘으면 수정이 되지 않아 꽃만 핌 |
| 발아 | 25-31℃ | 0-4.8℃에서도 발아 |
| 빛 | 하루 6-8시간 | 4시간 이상. 40% 차광에도 수량의 88% |
| 물 | 총 250mm | 발아-개화 70mm, 만개-성숙 20mm. 과습에 매우 약함 |
| 토양 | 배수 양호한 사질토-양토 | 산성토에 강하고 석회질·알칼리 토양에서 부진. 다습한 점질토는 실패 |

> **메밀에 석회를 뿌리지 마십시오. 다른 작물에 좋은 그 처방이 메밀에는 해가 됩니다.**

&nbsp;&nbsp;&nbsp;이미 갈려 있는 빈 밭, 다른 작물이 실패한 자리, 산성으로 기운 묵은 밭, 자갈 섞인 척박지가 좋습니다. 석회질이 많은 땅과 다습한 저지대는 피합니다.

| 생태형 | 대표 품종 | 파종 |
|:---|:---|:---|
| 여름메밀(춘파형) | 양절메밀(68일, 1,000㎡당 121kg), 양절메밀2호(68일, 155kg으로 수량 최대, 탈립이 적음) | 봄 |
| 가을메밀(하파형) | 대산메밀(73일, 130kg, 싹 수율 970%) | 여름 |

> **가을메밀을 봄에 심으면 꽃은 피지만 씨가 거의 맺히지 않습니다. 메밀 농사에서 가장 흔하고 치명적인 실수이므로, 종자의 출처를 알 수 없다면 생태형부터 확인합니다.**

&nbsp;&nbsp;&nbsp;쓴메밀은 자가수정이 가능해 격리가 필요 없고 루틴이 많아 채종과 약효에 유리합니다.

## 4. 밭 준비와 파종
| 항목 | 기준 |
|:---|:---|
| 땅 만들기 | 20cm만 얕게 갈아도 충분(열량 회수 배수가 낮아 깊이갈이는 손해). 파종 전에 배수로를 반드시 내고 흙을 곱게 부숨. 석회는 넣지 않음 |
| 시비 | 1,000㎡당 질소 5.4kg, 인산 3.1kg, 칼륨 3.9kg, 완숙 퇴비 1,000-1,500kg. 붕사 2-3kg은 결실률을 높임. 규산질은 도복을 줄임 |
| 대체 자원 | 부숙 퇴비 소량, 오줌 10배 희석(생육 초기), 뼛가루, 나무재는 알칼리성이라 소량만 |

&nbsp;&nbsp;&nbsp;메밀은 흡비력이 매우 강해 수확한 뒤의 밭에 양분이 적게 남으므로, 거름이나 콩과로 회복시켜야 합니다. 무투입 수량 유지율은 45.1%입니다.

| 작형 | 지역 | 파종 | 수확 |
|:---|:---|:---|:---|
| 여름메밀 | 중북부 | 4월 하순-5월 상순 | 7월 상순-중순 |
| 여름메밀 | 남부 | 4월 상순-중순 | 6월 하순-7월 상순 |
| 가을메밀 | 중북부 | 7월 중순-하순 | 10월 상순-중순 |
| 가을메밀 | 남부 | 8월 상순-중순 | 10월 하순-11월 중순 |

| 파종 방법 | 파종량(1,000㎡) | 비고 |
|:---|:---|:---|
| 산파 | 8-10kg | 가장 빠름. 급히 심을 때 |
| 줄뿌림 | 6-8kg, 열간 30cm | 김매기 가능 |
| 점뿌림 | 0.5-2kg, 열간 30cm, 주간 15cm | 종자가 가장 적게 듦 |

&nbsp;&nbsp;&nbsp;깊이는 2-5cm이며 가볍게 덮고 눌러 줍니다. 자가불화합성이라 너무 성기게 심지 않습니다. 가을메밀은 첫서리 10-12주 전에 파종합니다. 종자는 수명이 짧아 발아 시험이 필수이고(1년이 지난 종자는 반드시), 50-55℃ 물에 10-15분 담그거나 고운 재를 묻힙니다. 짚 멀칭은 수분 유지와 잡초 억제에 쓸모 있습니다.

## 5. 물과 재배 관리, 병해충
| 시기 | 물 관리 |
|:---|:---|
| 발아 | 마르지 않게 |
| 생육 초기 | 과습을 막는 것이 전부. 파종 직후 습해가 가장 흔한 실패 원인이므로 고랑을 파 물을 뺌 |
| 개화기 | 충분히 필요 |
| 등숙기 | 적게 |
| 성숙기 | 완전히 끊음. 비를 맞으면 씨가 떨어지고 싹이 남 |

&nbsp;&nbsp;&nbsp;꽃이 피어도 씨가 맺히지 않는 원인은 대개 고온, 수분 부족, 매개 곤충 부족, 생태형 착오 넷 중 하나입니다.

| 관리 | 내용 |
|:---|:---|
| 잡초 | 거의 필요 없음. 눈에 띄는 큰 잡초만 뽑으면 메밀이 스스로 억제 |
| 도복 | 줄기 속이 비어 쓰러지기 쉬움. 개화기까지 배토, 과밀과 질소 과다를 피함 |
| 수분 매개 | 성기게 심지 않음, 개화기에는 어떤 약도 뿌리지 않음, 밭 가장자리의 꽃을 남겨 벌 유지, 오전에 포기를 흔들어 인공 수분 |
| 기타 | 순지르기와 웃거름은 필요 없음. 수확 직전에는 새를 막기 위해 반짝이는 것을 매달음 |

| 병해충 | 약 없이 하는 대응 |
|:---|:---|
| 줄기썩음병, 잿빛곰팡이병 | 배수와 통풍, 병든 부분 제거 |
| 흰가루병 | 우유 5-10배 희석액 또는 중조액(물 1L에 중조 5g과 비누 소량), 통풍 |
| 나방류, 진딧물 | 손으로 잡기, 비눗물(물 1L에 순비누 5-10g), 천적 보호 |
| 새 | 가장 큰 실질 손실. 허수아비, 반짝이는 조각, 그물 |

> **개화기에는 어떤 것도 뿌리지 마십시오. 벌이 죽으면 그해 수확이 없습니다.**

| 결핍·과잉 | 증상과 조치 |
|:---|:---|
| 질소 결핍 | 누렇게 뜨고 키가 작음. 부숙 퇴비, 오줌 희석액 소량 |
| 붕소 결핍 | 꽃은 피는데 씨가 앉지 않음. 붕사 엽면시용 |
| 철 결핍 | 새 잎이 하얗게 뜸. 알칼리 과다이므로 나무재와 석회를 중단 |
| 질소 과잉 | 웃자라고 쓰러짐. 시비 중단, 배토 |

## 6. 사이짓기와 윤작
&nbsp;&nbsp;&nbsp;메밀은 밭을 놀리지 않게 하는 작물입니다. 6월에 캔 감자, 6월에 벤 보리와 밀, 수확한 참깨 뒤에 가을메밀을 이어 심고, 4월에 심은 여름메밀을 7월에 거둔 자리에 배추와 무를 심거나 천수답에서 늦벼를 심습니다. 메밀 연작은 해롭지 않지만 수량이 서서히 줄어듭니다.

| 정화작물 효과 | 활용 |
|:---|:---|
| 잡초 억제 | 빠른 생장과 타감물질로 잡초에 점령된 밭을 한 해 심어 정리 |
| 선충 억제 | 감자나 뿌리채소 앞에 심음 |
| 인산 가용화 | 다른 작물이 못 쓰는 인산을 흡수했다가 갈아엎으면 흙으로 돌아옴 |
| 녹비 | 씨가 여물기 전, 꽃이 만발했을 때 갈아엎음 |

| 윤작 | 작물 |
|:---|:---|
| 1년차 | 메밀 |
| 2년차 | 콩과 (질소 회복) |
| 3년차 | 감자 또는 뿌리채소 |
| 4년차 | 곡물 또는 메밀 복귀 |

## 7. 수확, 탈각, 채종
| 순서 | 내용 |
|:---|:---|
| 시기 | 파종 후 60-75일. 종실의 75-80%가 검게 익었을 때 벰(수분 16% 이하). 다 익기를 기다리면 아래쪽을 잃음 |
| 베기 | 이슬이 마르기 전 이른 아침에 밑동을 낫으로 베어 흔들지 않고 눕힘 |
| 말리기 | 천이나 멍석을 깐 위에 놓고 작은 다발로 묶어 3-5일 양건. 비를 맞히지 않음. 이후 탈곡하고 멍석에서 2-3일 더 말려 수분 13-14%로 맞춤 |
| 판정 | 껍질을 벗긴 알을 깨물면 톡 갈라지며 가루가 남, 껍질을 비비면 바스락 부서짐, 병에 밀봉해 하루 두어 김이 서리지 않음 |
| 탈곡 | 손으로 훑기(종자용), 멍석 위에서 막대로 가볍게 두드리기(세게 치지 않음), 자루째 내리치기, 밟기, 거꾸로 들고 흔들기 |
| 쭉정이 | 약한 바람에 흘리기, 키질, 부채질, 체 치기, 물 선별(곧바로 말림) |

&nbsp;&nbsp;&nbsp;탈각(삼각형 껍질 벗기기)은 절구로 가볍게 찧고 키질하기를 반복하거나, 맷돌 위짝을 알 크기만큼 띄우고 돌리거나, 약한 불에 볶아 껍질을 바삭하게 한 뒤 찧는 방법이 있고 볶은 뒤 찧기가 가장 잘 맞습니다. 껍질은 베갯속, 단열재, 불쏘시개로 씁니다.

| 채종 | 기준 |
|:---|:---|
| 제약 | 자가불화합성이라 봉지 씌우기가 통하지 않음 |
| 격리 | 다른 품종과 500m 이상 또는 개화기를 3주 이상 어긋나게 함. 한 지역에 한 품종만 심는 것이 가장 현실적 |
| 선발 | 병이 없고 쓰러지지 않은 30포기 이상에서 고루. 먼저 익은 아래쪽 씨를 사용 |
| 보관 | 껍질째, 수분 12-13%. 상온 1-2년이며 8개월부터 발아율이 떨어지므로 해마다 새로 받음. 필요량의 두 배 |

## 8. 저장
&nbsp;&nbsp;&nbsp;저장성은 SS입니다. 껍질째 저장하고 먹을 만큼만 벗깁니다. 탈각하면 종자 수명이 급격히 줄고 루틴이 빛에 분해됩니다.

| 항목 | 기준 |
|:---|:---|
| 조건 | 수분 13-14%(종자 12-13%), 온도 15℃ 이하, 주변 습도 65% 이하, 빛 완전 차단, 두 달마다 점검, 종자는 봄가을 발아 시험 |
| 용기 | 금속 통, 유리병 3년 이상 / 항아리 2-3년 / 두꺼운 비닐 1-2년 / 마대 6개월-1년(삼각형 씨가 잘 굴러 새어 나감) |

| 벌레 방제 | 방법 |
|:---|:---|
| 완전 밀폐 | 용기를 가득 채워 봉합니다. 가장 확실 |
| 나무재 | 고운 재를 곡물 부피의 2-5% 섞음. 먹기 전 씻어 냄 |
| 규조토 | 곡물 1kg에 1-3g. 마른 상태에서만 작동 |
| 보조 | 말린 고추·산초, 쑥·창포 잎, 볶은 소금, 숯. 한겨울에 며칠 바깥에 내놓기(저온), 볕에 얇게 펴 60℃(종자용 제외) |

## 9. 조리와 주의사항
> **메밀 알레르기는 아나필락시스로 이어질 수 있습니다. 의료가 끊긴 재난 상황에서 이것은 실질적인 생명 위험입니다.**

&nbsp;&nbsp;&nbsp;메밀 단백질의 일부가 강한 알레르기 항원이며, 가열해도 줄지 않고 아주 적은 양이나 가루 흡입, 메밀 껍질 베개로도 반응할 수 있습니다. 증상은 두드러기, 입과 목의 가려움, 복통, 구토, 호흡 곤란, 심하면 혈압 저하와 기도 폐쇄로 먹은 뒤 수분에서 수십 분 안에 나타납니다. 처음 먹는 사람은 아주 적은 양(어린아이는 한 숟갈 이하)부터 며칠에 걸쳐 늘리고, 알레르기 이력이 있는 사람은 먹지 않으며, 반응이 나타나면 즉시 중단하고 다시 시도하지 않습니다. 조리 도구를 따로 쓰고 껍질 베개를 가까이 두지 않으며, 식량을 나누는 공동체라면 누가 반응하는지 미리 파악해 둡니다.

| 주의 | 내용 |
|:---|:---|
| 쓴메밀 | 루틴이 70-100배라 쓴맛이 강함. 일반 섭취량은 문제 없으나 항응고제를 복용 중이면 다량 섭취에 주의. 껍질을 잘 벗기고 여러 번 헹구면 쓴맛이 줄어듦 |
| 곰팡이가 핀 것 | 곰팡이독소는 가열해도 사라지지 않음. 전량 폐기 |
| 껍질, 덜 익힌 것 | 껍질은 소화되지 않으므로 벗겨 먹고, 전분은 충분히 익힘 |

&nbsp;&nbsp;&nbsp;메밀은 글루텐이 없어 밀을 못 먹는 사람도 먹을 수 있지만, 반죽에 점성이 없어 국수나 빵을 만들기 어렵습니다. 밀가루나 전분을 섞거나 뜨거운 물로 익반죽합니다. 껍질을 벗긴 뒤 맷돌이나 절구로 빻고, 볶은 뒤 빻으면 덜 힘들고 향이 살아납니다. 가루는 알보다 훨씬 빨리 상하므로 한 달 먹을 만큼만 빻습니다.

| 조리 | 연료와 요령 |
|:---|:---|
| 볶은 가루 | 물에 타서 바로 먹음. 조리 연료가 필요 없음 |
| 가루죽 | 가루를 물에 풀어 5-10분. 가장 효율이 좋음 |
| 메밀묵 | 가루를 물에 풀어 저으며 끓인 뒤 식혀 굳힘. 며칠 먹음 |
| 부침, 국수 | 얇게 지짐(두꺼우면 속이 안 익음). 국수는 삶는 시간이 짧음 |
| 잔열 조리 | 끓인 뒤 불을 끄고 감싸 두면 연료를 절반 이하로 줄임 |

&nbsp;&nbsp;&nbsp;메밀싹은 껍질째 6-12시간 물에 담갔다가 물을 빼고 그릇이나 천에 펴 하루 두세 번 물을 뿌립니다. 어두운 곳에서 3-4일이면 노란 싹이 나고, 빛을 쬐면 이틀 만에 녹색이 되며, 5-7일에 5-10cm가 되면 껍질을 골라 내고 먹습니다. 흙도 밭도 없이 겨울에 닷새 만에 신선한 푸른 것을 얻는 방법이며 루틴과 비타민이 씨앗보다 많습니다. 저장을 겸한 가공으로는 볶은 알(밀폐 6개월), 볶은 가루(3-6개월), 말린 묵(1년), 전분(수년)이 있습니다. 개화기에는 벌에게서 메밀꿀도 얻을 수 있습니다.

## 10. 연간 작업 일정
| 월 | 작업 |
|:---|:---|
| 1-2월 | 저장 점검, 종자 발아 시험, 밭 계획과 퇴비 뒤집기 |
| 3월 | 경운, 배수로 설치, 밑거름 |
| 4월 | 여름메밀 파종(남부 상중순, 중북부 하순). 생태형 확인 |
| 5월 | 배토, 개화 시작. 개화기에는 아무것도 뿌리지 않음 |
| 6-7월 | 여름메밀 수확과 양건(75-80% 익었을 때). 7월 중하순에 중북부 가을메밀 파종(첫서리 10-12주 전) |
| 8-9월 | 남부 가을메밀 파종. 개화기 관리와 벌 보호 |
| 10-11월 | 가을메밀 수확, 양건, 탈곡, 건조(수분 13-14%), 저장, 종자 확보 |
| 12월 | 탈각과 제분, 메밀싹 기르기, 저장 점검 |

> **잊지 말아야 할 다섯 가지: 생태형 확인, 배수, 개화기 무처리, 75-80% 익었을 때 수확, 알레르기 주의.**
