## 7. 水分管理

### 7-1. 各生育阶段的标准

| 时期 | 管理 | 理由 |
|---|---|---|
| 播种至发芽 | 保持土壤不干 | 籽粒大，吸水量多 |
| 幼苗期 | 适度。避免过湿 | 引导根系向深处伸展 |
| 营养生长期 | 充足 | 茎和叶急剧增长 |
| 吐丝·开花期 | 务必充足 | 这2周决定全部产量 |
| 灌浆成熟期 | 充足 | 籽粒充实淀粉的时期 |
| 成熟期 | 停水 | 便于收获后干燥 |
| 韩国的梅雨季（6月下旬至7月） | 排水就是管理 | 淹水4天产量就会崩溃 |

&nbsp;&nbsp;&nbsp;玉米的需水量比其他谷物大。总蒸散量550mm，是高粱的两倍多。以韩国夏季的降水量来看，大体上靠自然降水就能满足，但在梅雨季结束得早、酷暑持续的年份，就会不足。

&nbsp;&nbsp;&nbsp;水分受限的情况下，要把水集中用在吐丝期。玉米在花丝抽出、接受花粉的那2周里如果断水，花丝就会晚抽，与花粉期错开。花粉几天就散尽了，所以花丝一晚，果穗就空了。这种损失，事后无论怎么浇水都无法挽回。营养生长期的干旱只是让植株变矮，而吐丝期的干旱会让收成化为乌有。

### 7-2. 缺水与水分过多的症状

| 症状 | 原因 | 判断与措施 |
|---|---|---|
| 正午叶片向内卷曲 | 暂时缺水 | 傍晚能展开就属正常范围 |
| 早晨叶片仍卷曲 | 实质性干旱 | 若在吐丝期，立即灌溉 |
| 花丝不抽出或抽出很晚 | 吐丝期干旱或高温 | 无法恢复 |
| 果穗顶端籽粒空缺 | 缺水或花粉不足 | 修正来年的布局和灌溉计划 |
| 叶片发黄，从下部叶片开始干枯 | 淹水或缺氮 | 挖开茎基部，看根的颜色来区分 |
| 叶片带紫色 | 低温期磷吸收障碍 | 气温回升后会恢复 |
| 茎基部变软并倒伏 | 淹水引起的根腐烂 | 立即排水并培土 |

> **玉米是既耗水量大、又一遇水淹就立刻垮掉的作物。灌水与排水，两者都不可缺少。**

## 8. 栽培管理

### 8-1. 除草 - 玉米损失的最大因素

| 时期 | 作业 | 要点 |
|---|---|---|
| 出苗后2周 | 第1次除草 | 趁杂草幼小时拔除 |
| 5-7叶期 | 第2次除草、培土、追肥 | 三项作业一次完成 |
| 株高过膝以后 | 必要时 | 玉米形成荫蔽，压制杂草 |

&nbsp;&nbsp;&nbsp;玉米无防治潜在损失68.5%中，有40.3个百分点来自杂草。杂草是比病虫害大得多的损失来源。这在没有农药的条件下是好消息，因为杂草靠的不是药，而是人的双手就能解决的问题。只要勤于除草，就能避免玉米的大部分损失。

&nbsp;&nbsp;&nbsp;不过，时机很重要。玉米长到齐膝高之前，也就是播种后30-45天之间，是与杂草竞争最激烈的阶段。此后，玉米宽大的叶片覆盖地面，杂草长不起来。把人力集中在这一个月，效率最高。

### 8-2. 培土

| 时期 | 作业 | 效果 |
|---|---|---|
| 5-7叶期 | 在茎基部培土，堆到20cm高 | 支持根扎入土中，倒伏大大减少 |
| 株高齐膝 | 必要时再培一次 | 促进根系发育，改善排水 |

&nbsp;&nbsp;&nbsp;培土是对玉米价值特别大的作业。株高达到2-3m的作物要抵御台风，根必须扎得牢，而玉米靠的是从茎基部长出的支持根。培土让这些支持根扎入土中，倒伏就会明显减少。同时，田沟加深，排水也变好。这是一项不花任何成本、却能同时提高产量和稳定性的作业。

### 8-3. 其他管理

| 项目 | 内容 |
|---|---|
| 分蘖 | 即使摘除也不增产，所以保留 |
| 分蘖的发生 | 株数少或肥多时会长出 |
| 人工授粉 | 结实不良时，摇动雄穗使花粉落下 |
| 鸟害 | 啄开果穗苞叶取食。临近成熟时套上网或纸袋 |
| 倒伏后 | 扶起，用土压住茎基部。果穗触地会腐烂 |
| 摘除下部叶片 | 不做。光合面积会减少 |

&nbsp;&nbsp;&nbsp;人工授粉是狭小田块里很有用的技术。如果玉米种的行数少，或连续多日无风，花粉就无法顺利落到花丝上。等早晨露水干后，用手摇动雄穗，或者剪下雄穗到下面植株的花丝上抖落，结实会明显改善。最好在几天里多做几次，因为花丝不是同时抽出的。

## 9. 病虫害

### 9-1. 主要病害

| 病害 | 发生条件 | 症状 | 不用药的应对 |
|---|---|---|---|
| 黑粉病 | 高温高湿，伤口部位 | 果穗或茎上长出白色瘤，破裂后散出黑粉 | 一发现就在破裂前剪下焚烧、改善排水、轮作 |
| 小斑病 | 高温高湿 | 叶片上出现芝麻粒般的斑点 | 保证通风、摘除并焚烧病叶、轮作 |
| 茎腐病 | 受霉菌、细菌污染的水 | 茎内变软并倒伏 | 改为沟灌，减少水花飞溅 |
| 根腐病 | 过湿、长期淹水 | 根变黑腐烂 | 除改善排水外别无办法 |
| 黑条矮缩病 | 灰飞虱传播的病毒 | 叶片变硬，植株矮小 | 管理传毒昆虫、清除周边杂草 |
| 纹枯病 | 过密、潮湿 | 叶鞘变软并干枯 | 保证株行距、排水 |
| 穗腐病 | 灌浆成熟期的雨 | 果穗上长霉 | 提早收获、剥去苞叶晾干、废弃病穗 |

&nbsp;&nbsp;&nbsp;灾难情况下最危险的是穗腐病。问题不在于产量损失，而在于毒性。果穗上长出的霉菌，有一部分会产生黄曲霉毒素、伏马毒素这类毒素，这些毒素加热也不会消失。黄曲霉毒素尤其是强力的肝毒性物质，并且具有致癌性。越是挨饿的时候，越会因为舍不得而吃下去，所以这个判断必须事先定好。

> **长了霉的玉米，洗了、煮了、炒了都不会变得安全。丢弃是唯一的办法，也不能喂给牲畜。**

&nbsp;&nbsp;&nbsp;预防的关键在于干燥。灌浆后期如果连续下雨，果穗上就已经开始长霉了。玉米被苞叶包着，里面一旦湿了就不容易干，因此更危险。遇到这种情况，最好不要等完全成熟，而是提前摘下，剥去苞叶晾干。

&nbsp;&nbsp;&nbsp;黑粉病的性质不同。白色的瘤在破裂成黑粉之前剪掉，就此了结。破裂之后，孢子散布到整块田里，能留存好几年。在田里巡查，找到瘤并在破裂前清除，是对付这种病唯一实际的办法。顺带一提，这种瘤在墨西哥被称为huitlacoche，也被当作食材，但如果不能确切辨别，还是不吃为妙。

### 9-2. 主要害虫

| 害虫 | 时期 | 危害 | 不用药的应对 |
|---|---|---|---|
| 亚洲玉米螟 | 5月底-10月初，一年发生3次 | 幼虫蛀食叶片、茎内和果穗 | 清除并焚烧被害茎、收获后处理残茬、清除卵块 |
| 粘虫 | 突发 | 瞬间啃光叶片 | 人工捕捉，严重时提早收获 |
| 灰飞虱 | 生育期 | 传播病毒 | 清除周边杂草 |
| 蚜虫 | 生育期 | 吸汁并引发煤污病 | 喷洒肥皂水、保护天敌 |
| 鸟类 | 灌浆成熟期 | 剥开苞叶啄食籽粒 | 套纸袋或旧布、拉网 |
| 老鼠 | 灌浆成熟期·贮藏期 | 啃食果穗，咬穿仓库 | 清理田地、使用金属容器 |

&nbsp;&nbsp;&nbsp;亚洲玉米螟是玉米的代表性害虫。在韩国一年发生3次，第1代在5月底到6月初，第2代在7月初到8月中旬，第3代在8月中旬到10月初。幼虫一旦钻进茎里，喷药也够不着，所以即使在平时，也要配合卵孵化的时间来防治。没有农药的条件下可用的手段，只有物理方法。

| 方法 | 内容 | 效果 |
|---|---|---|
| 处理残茬 | 收获后把茎秆收集起来烧掉，或切碎后埋掉 | 消灭在茎内越冬的幼虫 |
| 清除卵块 | 找到叶背鱼鳞状的卵块并擦掉 | 孵化前处理，最为有效 |
| 清除被害茎 | 剪下排出锯末状虫粪的茎并烧掉 | 消灭其中的幼虫 |
| 调整播种期 | 避开第1代发生期播种，或提早播种以躲开 | 使虫的世代与作物生育期错开 |
| 保护天敌 | 不要杀死寄生蜂和蜘蛛 | 虫口密度逐渐下降 |

&nbsp;&nbsp;&nbsp;其中效果最大的是收获后处理残茬。亚洲玉米螟的幼虫在玉米茎里越冬，来年春天出来。割下的茎秆如果原样留在田里，幼虫就会完好无损地在里面存活下来，成为来年虫口的起点。切碎烧掉，烧不了的话，粉碎后深埋进堆肥堆，大部分就会死亡。这是一项不用一滴药，就能把来年的危害降到一半以下的作业。

### 9-3. 天然防治剂

| 材料 | 制作方法 | 对象 | 注意事项 |
|---|---|---|---|
| 肥皂水 | 1L水加纯肥皂5-10g | 蚜虫、螨 | 正午喷洒会灼伤叶片 |
| 草木灰 | 在挂露水的早晨，撒在叶片和叶腋上 | 低龄幼虫 | 在亚洲玉米螟孵化期有效 |
| 木醋液 | 稀释500-1,000倍 | 预防霉菌病害、驱避 | 浓度高会产生药害 |
| 大蒜·辣椒浸出液 | 切碎后浸泡一天，过滤 | 蛾类幼虫、蚜虫 | 对人的眼睛也有刺激 |
| 波尔多液 | 将硫酸铜和生石灰溶于水中 | 预防霉菌病害 | 只有在有材料时才能配制 |

### 9-4. 不用药的防治五原则

| 原则 | 内容 | 在玉米上的应用 |
|---|---|---|
| 除草 | 及早清除杂草 | 40个百分点的损失来自杂草 |
| 处理残茬 | 收获后清理茎秆 | 消除亚洲玉米螟的越冬场所 |
| 排水 | 不让水积存 | 消除根腐病和茎腐病的发生条件 |
| 轮作 | 与豆科作物交替种植 | 既恢复地力，又降低病害密度 |
| 混作 | 混种其他作物 | 与甜椒混作时，病毒病减少了72% |

## 10. 营养缺乏与过量

| 症状 | 原因 | 用天然材料采取的措施 |
|---|---|---|
| 下部叶片沿中脉呈V形变黄 | 缺氮。玉米的典型症状 | 尿液10倍稀释液、腐熟堆肥 |
| 叶片呈深紫色 | 缺磷或低温 | 骨粉、草木灰。若因低温，气温回升后会恢复 |
| 叶缘焦枯 | 缺钾 | 把草木灰撒在株间 |
| 新叶出现白色条纹 | 缺锌。磷过多时常见 | 使堆肥原料多样化 |
| 仅叶脉之间发黄 | 缺镁 | 白云石粉、使堆肥多样化 |
| 果穗顶端没有籽粒 | 吐丝期养分、水分不足 | 提前追肥时间并增加灌溉 |
| 只长个子，叶片黑绿，果穗小 | 氮过量 | 玉米上少见，但极端情况下会出现 |

&nbsp;&nbsp;&nbsp;玉米缺氮的症状很有特点，容易辨认。从下部叶片的叶尖开始，沿中脉向内呈V形变黄扩散。这是因为玉米把不足的氮从下部叶片抽走，输送给上部新叶。看到这种症状，要立刻用稀释尿液或腐熟堆肥追肥，如果还在吐丝期之前，仍可恢复。

## 11. 间作与轮作

### 11-1. 三姐妹种植法 - 玉米灾难栽培的核心

&nbsp;&nbsp;&nbsp;针对玉米消耗地力的问题，有一个传统的解答。这是北美原住民使用了数百年的方式：把玉米、豆和南瓜种在同一个位置。

| 作物 | 作用 | 具体功能 |
|---|---|---|
| 玉米 | 支架 | 植株高大，成为蔓生豆攀爬的柱子 |
| 豆 | 提供氮 | 根瘤菌固定空气中的氮并送入土壤 |
| 南瓜 | 地面覆盖 | 宽大的叶片覆盖地面，压制杂草，减少水分蒸发 |

&nbsp;&nbsp;&nbsp;这种组合在灾难情况下有三重价值。第一，在同一块地里同时获得碳水化合物（玉米）、蛋白质（豆）和维生素（南瓜）。第二，玉米夺走的氮由豆补还回来，缓解地力消耗。第三，南瓜覆盖地面，除草的劳动大幅减少。考虑到玉米损失的最大因素是杂草，仅凭这一效果就有价值。

&nbsp;&nbsp;&nbsp;更重要的是营养的互补性。玉米缺乏赖氨酸和色氨酸，而豆类这两种都很丰富。只吃玉米会得糙皮病，与豆一起吃就不会。中南美洲人把玉米和豆一起吃，并非偶然，而是几千年经验造就的智慧。

| 种植方法 | 内容 |
|---|---|
| 顺序 | 先种玉米，长到齐膝高时种豆，然后种南瓜 |
| 间距 | 玉米株间种一两粒豆，畦边零星种几株南瓜 |
| 豆的品种 | 适合蔓生豆。会顺着玉米往上爬 |
| 注意 | 豆种得太早，会缠住玉米把它拉倒 |

### 11-2. 搭配

| 搭配 | 对象 | 效果 |
|:---:|---|---|
| 非常适宜 | 豆、红小豆、豇豆 | 固氮并分给玉米，补充营养 |
| 非常适宜 | 南瓜 | 覆盖地面，减少杂草和蒸发 |
| 适宜 | 辣椒、甜椒 | 玉米的荫蔽使病毒病减少了72% |
| 适宜 | 马铃薯（前茬） | 生育时期错开 |
| 不宜 | 高粱、粟 | 同属禾本科，共有病虫害，养分竞争大 |
| 不宜 | 玉米连作 | 地力枯竭，亚洲玉米螟累积 |

### 11-3. 轮作顺序

| 年 | 作物 | 目的 |
|---|---|---|
| 第1年 | 玉米（与豆混作） | 确保最大热量 |
| 第2年 | 豆科单作（大豆、红小豆、豇豆） | 恢复地力 |
| 第3年 | 叶菜或根菜 | 利用剩余的养分 |
| 第4年 | 谷物（高粱、粟、燕麦） | 回到玉米之前的缓冲 |
| 第5年 | 回到玉米 | 地力和病害密度已恢复 |

> **玉米连作，头两年看不出来，到第三年就垮了。与豆科轮作不是选项，而是前提。**

&nbsp;&nbsp;&nbsp;评价表中连作适应性A，指的是病虫害方面的值。从地力方面看，玉米是最不适合连作的作物之一。像美国中西部的黑土那样原本有机质就很厚的土地，可以连作，但韩国的旱田土壤没有这样的余地。在没有化肥的条件下，更是如此。

&nbsp;&nbsp;&nbsp;如果地少，难以实行4年轮作，至少也要坚持玉米与豆每年交替种植的2年轮作。再加上三姐妹种植法，把豆一起种下，在种玉米的那一年，氮也能得到一定补充。把这两种方法结合起来，是在肥料不足的条件下延续玉米种植的现实办法。
