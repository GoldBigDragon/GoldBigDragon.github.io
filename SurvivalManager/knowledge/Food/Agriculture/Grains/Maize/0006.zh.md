## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;玉米的耐储性为SS。在FAO食物损失指数的储藏阶段1,577条观测中，损失率中位数为3.00%，晒干的籽粒在常温下可存放3年以上。不过，这一等级只适用于完全干燥的籽粒。嫩玉米在常温下只能放3天，即使有冷藏也最多1-2周。同一种作物的储存期相差上千倍，造成这一差距的就是干燥。

### 15-1. 储存的三大敌人

| 敌人 | 条件 | 后果 | 对策要点 |
|---|---|---|---|
| 霉菌 | 水分15%以上 | 产生黄曲霉毒素，整批废弃 | 干燥 |
| 害虫 | 温度20℃以上，水分12%以上 | 蛀食籽粒，只剩下粉末 | 密封、低温、防治 |
| 老鼠 | 可以接近的容器 | 籽粒大，老鼠尤其爱吃 | 物理隔绝 |

&nbsp;&nbsp;&nbsp;玉米籽粒大，老鼠特别喜欢。布袋和塑料袋很容易被咬穿，一旦咬穿，湿气和害虫会从洞口一起进来。这就是在玉米储存中，金属桶和陶罐的价值比其他谷物更大的原因。

### 15-2. 储存条件

| 条件 | 目标 | 偏离时的后果 |
|---|---|---|
| 水分 | 13-14%，种子为12-13% | 超过15%，黄曲霉毒素的风险急剧上升 |
| 温度 | 15℃以下为宜，越低越好 | 超过25℃，害虫繁殖加快 |
| 湿度 | 周围空气65%以下 | 干燥的籽粒会重新吸收水分 |
| 光线 | 完全遮光 | 温度升高，品质下降 |
| 形态 | 整穗或籽粒 | 整穗通风好，籽粒更节省空间 |
| 检查 | 每两个月一次 | 及早发现就能避免损失 |

### 15-3. 整穗储存与籽粒储存

| 方式 | 优点 | 缺点 | 适用情形 |
|---|---|---|---|
| 整穗储存 | 通风好，霉菌较少滋生。籽粒不易受损 | 体积达三倍以上。老鼠容易接近 | 空间充裕且干燥不完全时 |
| 籽粒储存 | 体积小，容易密封 | 如果没有完全干燥，霉菌会迅速蔓延 | 确认完全干燥时 |

&nbsp;&nbsp;&nbsp;传统的做法是把玉米整穗吊挂起来。编成串挂在屋檐下或棚屋里，整个冬天都会持续晾干，需要时取下几穗，把籽粒搓下来使用。即使干燥不完全也很安全，这是它最大的优点。缺点是体积大，而且容易招老鼠。

&nbsp;&nbsp;&nbsp;最稳妥的折中办法是把两种方式分开。春季之前要吃的部分整穗吊挂，要放过夏天、留到第二年的部分则充分晒干，搓成籽粒后装入密封容器。这样，马上要用的玉米在持续干燥的同时被消耗，长期储备的部分则靠完全密封得到保护。

### 15-4. 储存容器

| 容器 | 密封 | 防鼠 | 期限 | 备注 |
|---|:---:|:---:|---|---|
| 金属桶 | 极好 | 完全 | 3年以上 | 最适合玉米 |
| 陶罐（onggi，韩国传统陶器） | 好 | 完全 | 2-3年 | 温度稳定，老鼠咬不穿 |
| 玻璃瓶 | 极好 | 完全 | 3年以上 | 须放在阴暗处 |
| 厚塑料袋 | 一般 | 差 | 1年 | 老鼠很容易咬穿 |
| 草袋·麻袋 | 差 | 差 | 6个月 | 对老鼠和害虫毫无防备 |
| 吊挂 | 无 | 一般 | 6个月-1年 | 通风好，霉菌较少 |
| 地下储藏窖 | 好 | 好 | 2-3年 | 温度稳定。一旦渗水就会全部损失 |
| 玉米仓 | 无 | 一般 | 1年 | 用稀疏的板条搭成、利于通风的传统构筑物 |

&nbsp;&nbsp;&nbsp;玉米仓是在美国和中南美洲长期使用的构筑物。用稀疏的木条搭成墙壁以利通风，让地板离开地面，并在立柱上安装托盘状的防鼠板，使老鼠爬不上去。整穗堆放进去后，整个冬天一边保存一边持续干燥。如果在灾难中要处理大量玉米，这是值得搭建的设施，只要有木板和立柱，一两天就能建好。

### 15-5. 储存期间的害虫防治 - 不用农药

&nbsp;&nbsp;&nbsp;谷物储存中真正的头号敌人是害虫。玉米象、印度谷螟、拟谷盗之类的害虫，在刚收获的籽粒中就已经以卵的形态混入，到了储藏库里才孵化。玉米象把卵产在籽粒内部，因此外表看似完好的籽粒，某天会被蛀出洞来，虫子从里面爬出。1只在2个月内就能繁殖到数十只，半年后一个桶里就会装满粉末和碎壳。

| 方法 | 原理 | 做法 | 效果 |
|---|---|---|---|
| 完全密封 | 隔绝氧气，使害虫窒息 | 把容器装满后封口 | 最可靠。空隙越小越好 |
| 拌草木灰 | 灰的微细颗粒刮伤害虫的外骨骼，使其脱水 | 按谷物体积的2-5%均匀拌入 | 久经验证的方法。食用前洗掉 |
| 硅藻土 | 微细的硅质外壳损伤外骨骼 | 每1kg谷物拌入1-3g | 效果比草木灰好。只有在干燥状态下才起作用 |
| 细沙·黄土 | 颗粒填满缝隙，阻止害虫移动 | 一层一层铺着放入 | 玉米籽粒大、缝隙多，所以效果显著 |
| 干辣椒 | 辣椒素起驱避作用 | 在容器里放入几个 | 传统上用于玉米储存 |
| 艾蒿·菖蒲·槐树叶 | 精油成分抑制产卵 | 晒干后一层一层放入 | 辅助手段 |
| 炒盐 | 吸附湿气，使害虫失去生存条件 | 用布包好放入 | 兼作干燥剂 |
| 木炭 | 吸收湿气和异味 | 把烧制后晒干的木炭用布包好放入 | 也有助于预防霉菌 |
| 低温处理 | 零下温度会冻死虫卵和幼虫 | 隆冬时放到室外几天后再收回 | 收回时要注意结露 |
| 高温处理 | 60度时虫卵和幼虫死亡 | 在阳光下薄薄摊开，放几个小时 | 不用于种子 |

&nbsp;&nbsp;&nbsp;其中最重要的是第一种。完全密封是不用药也能使用的最强手段。害虫也要呼吸，在密封的容器中，谷物和害虫消耗氧气，二氧化碳不断积累，氧气下降，害虫就会死亡。把容器装得越满、空隙越小，见效越快。玉米籽粒大，籽粒之间留有大量空气，所以要比其他谷物压得更实。装满后摇动使其沉降，再补满，如此重复两三次。

&nbsp;&nbsp;&nbsp;草木灰和硅藻土的原理相同。两者都不是靠化学作用，而是靠物理作用杀虫。微细而锋利的颗粒刮掉覆盖在虫体上的蜡质层后，害虫就会失水干死。这种方式有两个优点：害虫不会产生抗药性，对人体也无害。食用前用水洗净即可。缺点是有湿气就不起作用。谷物一受潮，草木灰和硅藻土都会失效，所以归根结底还是要先干燥。

&nbsp;&nbsp;&nbsp;使用草木灰时，要先过筛，只挑出像面粉一样细的部分。按谷物体积的2到5%，也就是每1斗（约18升）玉米拌入1升（约1.8升）左右的灰，用手翻拌，使每粒籽粒的表面都薄薄裹上一层。玉米籽粒大，相对表面积小，所以用灰量少，之后也容易洗掉。况且就玉米而言，这种灰还有别的用途：烹饪时碱处理所用的灰，正是同一种灰。

&nbsp;&nbsp;&nbsp;干辣椒在传统上也被广泛用于玉米储存。在籽粒之间插入几个辣椒，害虫就不愿靠近。单独使用时效果有限，但与密封或草木灰配合使用，可以作为辅助手段。

### 15-6. 定期检查

| 时间 | 检查事项 | 异常时的处理 |
|---|---|---|
| 每两个月 | 容器外壁的结露、霉味 | 立即打开摊开晒干 |
| 每两个月 | 籽粒上的小孔、底部的粉末 | 这是象甲。全部拿到阳光下晒，再筛出 |
| 每两个月 | 表面像蛛丝一样的丝 | 这是印度谷螟 |
| 每两个月 | 用手抓握时的温热感 | 发热是水分过多的信号 |
| 每两个月 | 容器周围的鼠迹 | 检查是否有粪便或啃咬痕迹 |
| 春秋两季 | 整桶打开，检查气味和颜色 | 如有异味，分成小份逐一检查 |

## 16. 烹饪与加工

### 16-1. 碱处理（尼克斯塔马化） - 玉米烹饪的关键

&nbsp;&nbsp;&nbsp;如果以玉米为主食，这一节是整篇文档中最重要的。这是把干玉米放进溶有草木灰或石灰的水里煮的处理方法，能同时解决三个问题。

| 效果 | 内容 |
|---|---|
| 释放烟酸 | 结合型烟酸转变为可吸收的形态，预防糙皮病 |
| 去皮 | 籽粒外皮变软，搓揉即可脱落 |
| 易于磨粉 | 籽粒变软，用石磨或石臼研磨容易得多 |

| 步骤 | 内容 | 备注 |
|---|---|---|
| 1 | 每1升（约1.8升）干玉米籽粒配3升（约5.4升）水 | 让水充分没过 |
| 2 | 加入玉米体积5%左右的草木灰 | 如果有石灰（生石灰），1%就够了 |
| 3 | 煮沸后转小火，充分煮30-50分钟 | 籽粒膨胀，外皮浮起 |
| 4 | 关火，原样放置一夜 | 这段时间是碱作用的关键 |
| 5 | 倒掉水，用手搓揉去皮 | 黄色的外皮会脱落 |
| 6 | 冲洗三四遍，直到流出清水 | 把灰和碱彻底洗净 |
| 7 | 以此状态烹饪，或捣成粉使用 | 晒干后可长期保存 |

> **加灰煮制这一道工序，就能把玉米变成安全的主食。这也是中南美洲的人们数千年来只吃玉米也能保持健康的原因。**

&nbsp;&nbsp;&nbsp;可用的碱性材料有好几种。烧阔叶树得到的草木灰最容易获得，烧贝壳或骨头制成的石灰也可以使用。如果有熟石灰或生石灰，用量最少就能见效，但用量不当会产生苦味，必须小心。使用草木灰时，要加到肉眼能看到灰的程度，煮出来的水摸起来滑腻，就说明碱已经足够了。

&nbsp;&nbsp;&nbsp;处理过的玉米可以直接煮粥或做饭吃，捣碎和面后，就成了传统玉米煎饼的面团。晒干后可长期保存，需要时用水泡发再捣碎即可。唯一的负担是需要燃料，但一次性大量处理并晒干，就能节省燃料。

### 16-2. 磨粉 - 制作玉米粉

| 方法 | 工具 | 特点 |
|---|---|---|
| 石磨 | 上下两扇石盘 | 磨出的粉最细 |
| 石臼 | 石臼和杵 | 玉米籽粒坚硬，非常费力 |
| 石板研磨 | 扁平的石板和碾石 | 与中南美洲的石磨盘（metate）原理相同 |
| 碱处理后捣碎 | 任何工具均可 | 籽粒变软，容易得多 |
| 炒后捣碎 | 任何工具均可 | 组织酥脆，更省力，也更香 |
| 泡水后研磨 | 石磨 | 加水一起磨，直接得到面团 |

&nbsp;&nbsp;&nbsp;干玉米是谷物中最坚硬的一类，直接捣碎非常费力。用石臼捣时，籽粒会蹦出去，胳膊先累了。所以玉米磨粉必须先做预处理。经过碱处理，籽粒变软，所需的力气可减少一半以上；炒过之后，组织酥碎，磨起来容易得多。用水泡一夜，再放进石磨里加水一起磨，也是个好办法。出来的不是干粉，而是直接得到面团，但如果是当场就吃，就没有问题。

&nbsp;&nbsp;&nbsp;没有石磨的话，也可以自己做。挑两块坚硬的石头，把相对的两面凿粗糙，在上扇中间凿一个孔让谷物落下，再装上把手即可。做得不精细也能用。如果预计灾难会持续很久，这是很值得提前做好的工具。

&nbsp;&nbsp;&nbsp;粉比籽粒变质快得多。玉米粉尤其如此，因为胚芽中的脂肪会混入粉中。一次只磨够吃一个月的量，其余的仍以籽粒形式保存。

### 16-3. 节省燃料的烹饪

| 方法 | 燃料 | 步骤 | 备注 |
|---|:---:|---|---|
| 煮嫩玉米 | 少 | 只加少量水，蒸20分钟 | 蒸比煮更省燃料 |
| 煮干籽粒 | 多 | 泡一夜后煮1小时以上 | 最费燃料 |
| 碱处理后烹饪 | 中等 | 处理过程中已经煮熟 | 一次性集中处理，效率更高 |
| 玉米粉粥 | 极少 | 把粉调入水中煮10分钟 | 效率最高 |
| 煎饼 | 少 | 把面团摊成薄饼煎 | 太厚则里面不熟 |
| 余热烹饪 | 极少 | 煮10分钟后关火，用稻草或毯子包裹放置1小时 | 燃料可减少一半以上 |
| 爆谷（twibap）·爆米花 | 极少 | 放入烧热的锅里，盖上盖子摇动 | 几分钟就好 |
| 灰中烘烤 | 极少 | 把面团埋进热灰里 | 利用其他烹饪的余热 |

&nbsp;&nbsp;&nbsp;直接煮干玉米籽粒，是燃料方面最糟糕的选择。需要煮1小时以上，煮完还不能完全煮烂。进行碱处理，或者捣成粉使用，要省燃料得多。尤其是玉米粉粥，10分钟就能做好，是燃料极度短缺时吃玉米的最佳形式。

&nbsp;&nbsp;&nbsp;爆米花是出人意料的合理烹饪方式。如果种了爆裂型玉米（用来做爆米花的玉米品种），只要放进烧热的锅里，盖上盖子摇动，几分钟就能变成体积膨胀数十倍的食物。几乎不耗燃料，也不需要去皮碾白或磨粉，立刻就能吃。在各种玉米吃法中，它的烹饪效率最高。不过，爆裂型玉米要另外种植。

&nbsp;&nbsp;&nbsp;保温烹饪对干玉米尤其有价值。把泡好的籽粒只煮10分钟，端离火源，连锅一起用装满稻草或稻壳的箱子，或厚被子包起来，内部温度能在1小时以上的时间里保持在80℃以上，烹饪就会继续进行。原本要煮1小时的东西，缩短为10分钟。

### 16-4. 兼顾储存的加工

| 加工 | 步骤 | 保存 | 备注 |
|---|---|---|---|
| 碱处理后干燥 | 把处理过的玉米晒干 | 密封1年 | 用水泡发后即可使用 |
| 炒粉 | 炒后捣碎 | 密封3-6个月 | 用水冲调即可食用 |
| 玉米淀粉 | 泡水磨碎，把沉淀物晒干 | 数年 | 体积缩小，不生虫 |
| 干嫩玉米 | 焯水后剥下籽粒晒干 | 1年 | 用水泡发后放入汤或粥中 |
| 玉米酒 | 在碱处理过的玉米中拌入酒曲发酵 | 密封保存 | 兼具保存热量与消毒饮水的作用 |
| 玉米糖稀（jocheong，谷物熬制的糖浆） | 用麦芽糖化后熬浓 | 阴凉处1年 | 获得甜味和浓缩的热量 |
| 玉米须茶 | 把玉米须晒干备用 | 密封1年 | 利用通常被丢弃的部位 |

&nbsp;&nbsp;&nbsp;提取玉米淀粉在灾难状况下尤其有用。因为被虫蛀过一点的籽粒、破碎的籽粒以及难以储存的零碎，全都可以用来制作淀粉。把泡了一夜的玉米磨碎，用布包起来在水中揉搓，就会流出白色的水。静置沉淀，倒掉上层清水，再倒入新水，重复三四遍，最后把剩下的沉淀物晒干，就是玉米淀粉。体积和重量大幅减少，几乎不生虫，可以保存数年。放入沸水中搅开，立刻就熟，烹饪燃料也几乎不用。

### 16-5. 副产物的利用

| 副产物 | 用途 |
|---|---|
| 穗轴 | 火力旺的柴火。烧成的灰是钾肥。粉碎后可作堆肥 |
| 玉米皮 | 代替绳子，用作草鞋或草席的材料，代替饺子皮或用来包年糕 |
| 茎和叶 | 家畜粗饲料、堆肥原料。不过由于有玉米螟，烧掉更好 |
| 玉米须 | 晒干后泡茶 |

&nbsp;&nbsp;&nbsp;玉米的非食用价值被评为E，但在实际的灾难状况下，副产物的用处并不小。尤其是穗轴火力旺，作为炊事柴火很管用，烧成的灰可以直接用于碱处理和储存防虫。可以说，一种玉米作物就能提供谷物、燃料、碱和防虫剂。

## 17. 全年作业日程

| 月份（以韩国气候为准） | 作业 | 要点 |
|---|---|---|
| 1月 | 检查储存，确认种子，保养工具 | 检查有无霉味和象甲蛀孔 |
| 2月 | 规划田块，翻堆堆肥，发芽试验 | 计算玉米田要施多少堆肥 |
| 3月 | 深耕（18cm以上），挖排水沟，施基肥，撒草木灰 | 运肥是最大的工作量 |
| 4月 | 播种（韩国南部上旬，韩国中部中旬），间隔1-2周分批播种 | 确认土壤温度在12℃以上 |
| 5月 | 间苗（株高15cm），第1次除草，监视玉米螟第1代发生期 | 杂草是造成损失的最大因素 |
| 6月 | 5-7叶期追肥，第2次除草，培土，播种豆类 | 三项作业一次完成 |
| 7月 | 吐丝·开花期集中灌水，人工授粉，玉米螟第2代发生期 | 这2周决定全部产量 |
| 8月 | 收获嫩玉米，灌浆期管理，驱赶鸟类 | 嫩玉米在吐丝后22-25天采收 |
| 9月 | 开始收获籽粒，剥去苞叶挂起晾干 | 确认黑层出现后再掰取 |
| 10月 | 收获收尾，干燥，处理茎秆残茬 | 烧掉茎秆，阻止玉米螟越冬 |
| 11月 | 脱粒，最后干燥，储存，种子单独保管 | 确认水分13-14%后密封 |
| 12月 | 碱处理与磨粉，检查储存，规划下一年 | 一次只加工够吃一个月的量 |

### 17-1. 必须牢记的五件事

| 项目 | 内容 |
|---|---|
| 肥料 | 玉米是需肥量大的作物。没有堆肥计划就去种，就不会有收成 |
| 禁止连作 | 以与豆类轮作或“三姐妹”种植法为前提。第三年就会崩溃 |
| 布局 | 不要种成一长行，而要多行聚在一起种。这是因为靠风传粉 |
| 种子 | F1代到第二年就不能用了。务必获取固定品种或地方品种 |
| 碱处理 | 光吃玉米会得糙皮病。要加灰煮制，或与豆类一起吃 |
