## 3. 栽培环境

### 3-1. 极限值与最适值

| 条件 | 最适值 | 耐受范围 | 超出范围时 |
|---|---|---|---|
| 生育温度 | 20-30℃ | 12-40℃ | 12℃以下生长停止，遇霜冻枯死 |
| 发芽温度 | 32-34℃ | 最低8-11℃ | 土温13℃时出苗需18-20天，15-18℃时需8-10天 |
| 吐丝期温度 | 25-28℃ | 35℃以下 | 超过35℃花粉死亡，果穗空粒 |
| 灌浆成熟期温度 | 20-25℃ | 18-30℃，幅度12℃ | 过热则籽粒灌浆不实 |
| 光照量 | 每天8-10小时直射光 | 6小时以上 | 遮光40%时，产量降至45% |
| 总需水量 | 550mm左右 | 400-700mm | 吐丝期干旱最为致命 |
| 土壤 | 排水良好的砂壤土-壤土 | 大多数土壤 | 透气性尤为重要 |
| 土壤酸碱度 | pH 6.0-6.8 | pH 5.5-7.5 | 强酸性条件下磷被固定 |
| 淹水 | 不应出现 | 最多3天 | 淹水4天以上，株高矮12%，吐丝推迟5天 |
| 霜冻 | 不应出现 | 无 | 一次霜冻就会死亡 |

&nbsp;&nbsp;&nbsp;这张表中最引人注目的是发芽温度的幅度。最适温度为32-34℃，而最低温度为8-11℃。低温下也能发芽，但非常缓慢。土温13℃时，出苗需要20天，在这20天里，种子面临在土中腐烂或被虫吃掉的风险。这意味着，急着播种不一定有利。

&nbsp;&nbsp;&nbsp;淹水这一项也值得具体记录下来。玉米被水淹4天以上，株高和茎粗都会减小，叶片也会早衰。在透气性差的土壤中，株高会矮12%，吐丝推迟5天，而吐丝一推迟，就与花粉散发的时期错开，果穗便会空粒。这就是韩国的梅雨季（6月下旬至7月）排水决定玉米种植成败的原因。

### 3-2. 灾难情况下的选址

| 位置 | 适宜度 | 理由 |
|---|:---:|---|
| 朝南缓坡、全天有日照的田 | 最佳 | 玉米是C4作物，日照直接决定产量 |
| 土层深厚肥沃的平地田 | 最佳 | 需肥量大，本来养分多的土地更有利 |
| 便于集中施用堆肥的近处田块 | 良好 | 减少运肥的劳动 |
| 畜舍或厕所附近 | 良好 | 便于取用粪尿资源 |
| 由水田改造的旱地 | 需注意 | 必须深耕18cm以上并开排水沟 |
| 贫瘠的砾石地 | 不适宜 | 最好留给高粱或粟 |
| 有遮荫的地方 | 不适宜 | 遮光造成的损害比其他作物大得多 |
| 低洼积水处 | 不适宜 | 淹水4天产量就会崩溃 |

&nbsp;&nbsp;&nbsp;灾难情况下分配田地的原则很明确：把最肥沃、日照最好的土地给玉米，把贫瘠的零碎地让给高粱或粟。玉米在好地上能产出压倒性的热量，在差地上则表现平平；相反，高粱和粟在差地上也能发挥应有的作用。利用这种不对称，就是使总收成最大化的布局。

&nbsp;&nbsp;&nbsp;运肥距离也是实际需要考虑的因素。玉米需要大量堆肥，而堆肥很重。如果没有手推车，给1,000㎡运1吨堆肥是要干好几天的活。仅仅是把靠近堆肥堆或畜舍的田块分给玉米，就能节省相当多的劳动。

## 4. 品种

### 4-1. 按用途分类

| 类别 | 特点 | 用途 | 灾难应对角度 |
|---|---|---|---|
| 糯玉米 | 口感黏糯，适合煮着吃 | 作嫩玉米食用 | 韩国国内的代表品种。容易被接受 |
| 甜玉米·超甜玉米 | 糖度高，可以生吃 | 现采现吃 | 难以贮藏，籽粒会皱缩 |
| 籽粒用·饲料用 | 籽粒坚硬，淀粉多 | 晒干贮藏、磨粉 | 是长期储备和作为主食的必需品种 |
| 爆裂型（爆米花用） | 籽粒小而坚硬 | 爆开食用 | 几乎不耗燃料就能烹制 |

> **灾难应对中的分水岭就在这里。嫩玉米用品种只是夏季一季的粮食，只有籽粒用品种才能成为过冬的储备。**

&nbsp;&nbsp;&nbsp;如果忽略这一区别，就会陷入麻烦。糯玉米和甜玉米是作为嫩玉米食用的品种，完全成熟后籽粒会皱缩，淀粉含量低，作为贮藏谷物的价值下降。相反，籽粒用品种当嫩玉米吃不好吃，但完熟后晒干，就成了能存放3年的谷物。玉米的单位面积热量A，是以籽粒用品种为前提的数值。

&nbsp;&nbsp;&nbsp;现实的布局是两种都种。种一部分夏天马上就吃的糯玉米，其余用籽粒用品种补足，作为冬季储备。不过，两种如果种得太近，花粉会相混，使糯玉米失去黏糯性，所以要相隔200m以上，或者把播种期错开3周以上。

### 4-2. 主要品种比较

| 品种 | 成熟期 | 产量 | 特点 |
|---|:---:|:---:|---|
| 糯玉米 | 80-90天 | 中 | 韩国国内的代表品种。口感黏糯 |
| 超甜玉米 | 70-80天 | 中 | 糖度高，生长快 |
| Godangok | 约80天 | 高 | 比糯玉米短10天，可一年种两茬 |
| 籽粒·饲料用 | 90-100天 | 高 | 籽粒坚硬，最适合干燥贮藏 |

### 4-3. 按情况选择的标准

| 情况 | 推荐 | 理由 |
|---|---|---|
| 以长期储备为目的 | 籽粒·饲料用 | 晒干后可保存3年以上 |
| 确保夏季粮食 | 糯玉米 | 煮熟即可直接吃 |
| 需要尽快收获 | 超甜玉米、Godangok | 70-80天即可收获 |
| 面积有限时 | Godangok | 可一年种两茬 |
| 燃料极度匮乏时 | 爆裂型 | 爆开几乎不耗燃料 |
| 需要自家留种时 | 地方品种·固定品种 | F1第二年就会退化 |

&nbsp;&nbsp;&nbsp;最后一项最重要。市面上出售的玉米种子，相当一部分是F1杂交种。F1第一年产量出色，但把从中收的种子再种下去，就会出现自交衰退，株高和果穗参差不齐，收成降到一半以下。如果以物流中断、买不到种子为前提，那么哪怕产量稍低，提前备好地方品种或固定品种也要安全得多。地方品种可以年年留种、持续种植。

## 5. 整地与施肥

### 5-1. 整地

| 项目 | 内容 | 理由 |
|---|---|---|
| 耕深 | 18cm以上，可能的话25-30cm | 根系深而广地伸展，才能满足大量需肥的要求 |
| 排水沟 | 田四周和沟里务必开 | 淹水4天就会使产量崩溃 |
| 垄 | 高15-20cm | 防止梅雨季淹水 |
| 土壤酸碱度 | pH 6.0-6.8 | 酸性过强则磷被固定 |
| 有机物 | 堆肥1,000-1,500kg/1,000㎡ | 需肥量大，必须多施 |
| 石灰 | 用于调节酸性 | 可用草木灰代替 |

&nbsp;&nbsp;&nbsp;玉米整地与其他作物最大的不同在于有机物的用量。它是需肥量大的作物，必须充足施入堆肥，而且这些堆肥要缓慢分解，把养分一直供给到生育后期。有化肥的时候，堆肥只是辅助，没有化肥的条件下，堆肥就是全部。所以玉米种植的准备工作不是从春天，而是从前一年的秋天开始。堆肥堆是什么时候沤起来的，决定了第二年玉米的收成。

### 5-2. 标准施肥量（以1,000㎡计）

| 肥料 | 施肥量 | 时期 |
|---|:---:|---|
| 氮（N） | 10-15kg | 基肥50%，追肥50% |
| 磷（P） | 8-10kg | 全部作基肥 |
| 钾（K） | 8-10kg | 基肥与追肥分施 |
| 堆肥 | 1,000-1,500kg | 用腐熟堆肥，全部作基肥 |

| 类别 | 时期 | 内容 |
|---|---|---|
| 基肥 | 播种前1-2周 | 堆肥全部、磷全部、钾一半、氮一半 |
| 追肥 | 5-7叶期 | 剩余的氮和钾。同时进行培土 |

&nbsp;&nbsp;&nbsp;与其他谷物相反，玉米省肥反而吃亏。高粱和粟多施氮就会倒伏，而玉米茎秆粗壮坚实，能承受相当多的氮，并相应地回报到果穗上。如果肥料有富余，集中给玉米，能增加总收成。

### 5-3. 没有化肥时 - 灾难时的替代肥料

| 替代资源 | 提供的成分 | 制作与使用方法 | 注意事项 |
|---|---|---|---|
| 腐熟堆肥 | 综合养分，尤其是氮 | 把落叶、杂草、粪尿一层层堆起来，沤制3-6个月 | 对玉米来说，用量是关键。提前多堆一些 |
| 稀释尿液 | 氮、钾 | 加水稀释10倍，在5-7叶期顺着沟浇入 | 是追肥的主力 |
| 草木灰 | 钾、磷、钙 | 每1,000㎡撒施40-60kg | 兼有调节酸度的作用 |
| 骨粉 | 磷、钙 | 烧过粉碎后掺入堆肥，放置两个月 | 分解慢，要提前准备 |
| 豆科绿肥 | 氮 | 前茬种大豆、紫云英、毛叶苕子，然后翻压入土 | 对玉米效果最大的办法 |
| 与大豆混作 | 氮 | 在玉米之间一起种大豆 | 是“三姐妹”种植法的核心 |
| 牲畜垫草 | 综合养分 | 将掺有稻草和粪尿的垫草沤熟后使用 | 避免用盐分高的 |
| 人粪堆肥 | 氮、磷 | 与锯末或稻壳混合，完全沤熟6个月以上 | 沤得不透，寄生虫和病原菌会残留 |

&nbsp;&nbsp;&nbsp;玉米的肥料问题比其他任何作物都沉重。把氮10-15kg折算成堆肥，相当于2吨到3吨腐熟堆肥，而且要全部施在1,000㎡的地块里。现实中，每年都备足这个量是很困难的。因此，玉米的施肥策略分成三条路线。

&nbsp;&nbsp;&nbsp;第一，与大豆一起种。大豆根瘤菌固定的氮，有一部分通过土壤流向玉米。虽然不能完全满足，但能弥补相当一部分缺口。第二，在前茬种豆科绿肥，开花时翻压入土。翻压毛叶苕子或紫云英，每1,000㎡可提供8-12kg氮。这几乎满足玉米的标准需氮量。第三，把尿液当追肥使用。成年人一天排出的尿液中含氮6-10g，因此把四口之家一个月的量收集起来，就相当于1,000㎡追肥所需的氮。

> **玉米种植的一半不是在田里，而是在堆肥堆和绿肥田里完成的。没有施肥计划就种玉米，不过是做做样子。**

## 6. 播种

### 6-1. 时期

| 地区 | 适宜播种期 | 备注 |
|---|---|---|
| 韩国南部 | 4月上旬 | 在霜冻风险过后 |
| 韩国中部 | 4月中旬 | 以土温12℃以上为标准 |
| 两茬种植的后茬 | 7月上旬 | 用早熟品种，在霜前收获 |
| 播种极限 | 6月下旬 | 再晚的话，灌浆成熟期会赶上霜冻 |

&nbsp;&nbsp;&nbsp;播种时期的标准是土壤温度。必须超过12℃，超过15℃则好得多。13℃时出苗需要20天，而15-18℃时8-10天就能出苗。与其急着播种、让种子在土里熬20天，不如等一周再播，10天就能出苗，结果更好。

&nbsp;&nbsp;&nbsp;灾难情况下，最好不要一次全部种完，而是每隔1-2周分批播种。这样收获期就被分散开，避免了一次处理不完的问题，也能防止某一时期的台风或病害把全部作物一扫而光。尤其是准备当嫩玉米吃的那一部分，一定要分批播种。一起成熟的话，几天内要么全部吃掉，要么就只能扔掉。

### 6-2. 种子准备

| 项目 | 内容 | 备注 |
|---|---|---|
| 选种 | 用果穗中段饱满整齐的籽粒 | 穗尖和穗基部的籽粒发芽不整齐 |
| 水选 | 放入水中，捞出浮起的种子 | 玉米籽粒大，用眼睛也能挑选 |
| 拌灰 | 裹上草木灰 | 兼有消毒和干燥作用，鸟和蚂蚁也较少来侵扰 |
| 催芽 | 用湿布包好放一天，让种子萌芽 | 发芽更快。注意不要伤到根 |
| 播种粒数 | 每穴2粒 | 为发芽率上一道保险 |

### 6-3. 种子消毒 - 没有农药时

| 方法 | 步骤 | 效果 | 注意事项 |
|---|---|---|---|
| 草木灰拌种 | 给种子稍喷点水，再裹上细灰 | 既能消毒种子表面，又能驱避鸟和蚂蚁 | 最为实用 |
| 温汤浸种法 | 在50-55℃的水中浸泡10分钟，再用冷水冷却 | 杀死表面的病原菌 | 超过60℃种子会死亡 |
| 木醋液浸种 | 在稀释500倍的溶液中浸泡6-12小时 | 表面杀菌并促进发芽 | 原液会使种子死亡 |
| 健康种子选留 | 只从没有黑粉病的植株上留种 | 最为根本 | 必须在生育期做好标记 |

&nbsp;&nbsp;&nbsp;对玉米种子来说，草木灰拌种特别有用。玉米籽粒大，播种后鸟、鼠、蚂蚁经常刨出来吃，裹上灰就不那么显眼，味道也不好，损失会减少。同时还能获得消毒效果。

### 6-4. 种植方法

| 项目 | 标准 | 理由 |
|---|---|---|
| 播种深度 | 3-5cm | 籽粒大，比其他谷物播得深 |
| 行距 | 70cm | 是能走进行间除草和培土的宽度 |
| 株距 | 25cm | 太密则果穗变小 |
| 每穴 | 2粒 | 之后间苗为1株 |
| 布局 | 不种单行，而是多行集中成片 | 风媒授粉效果好 |
| 覆土后 | 轻轻压实 | 使种子与土壤紧贴 |

&nbsp;&nbsp;&nbsp;布局尤其重要。玉米靠风传播花粉，如果种成一长行，花粉就会飘到田外，果穗上的籽粒便稀稀拉拉。至少并排种四行以上，排成方块，就能互相接受对方的花粉，结实均匀。在狭小的菜园里种玉米，常犯的错误是沿着围墙种一行，结果就是籽粒稀疏的果穗。

### 6-5. 间苗

| 时期 | 作业 | 备注 |
|---|---|---|
| 株高15cm | 只留1株，其余间掉 | 不要拔，从基部剪断 |

&nbsp;&nbsp;&nbsp;间苗时最好不要拔，而是剪断。玉米的根相互缠绕，一拔就会连要留下的那株的根也被牵动。用指甲或小刀贴近地面割断，留下的植株就不会受伤。间下来的玉米幼苗可以当作牲畜饲料或堆肥原料。
