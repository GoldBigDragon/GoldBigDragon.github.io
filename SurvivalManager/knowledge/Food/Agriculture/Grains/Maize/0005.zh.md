## 12. 收获与脱粒

### 12-1. 两种收获 - 嫩玉米与谷粒

&nbsp;&nbsp;&nbsp;玉米的收获因目的不同而完全不同。准备煮着吃的嫩玉米，要趁籽粒还嫩时摘下；准备贮藏的谷粒，则要等到完全干透为止。两者的时间相差一个多月。

| 目的 | 时期 | 判断标准 |
|---|---|---|
| 嫩玉米 | 吐丝后22-25天 | 按压籽粒会流出白色浆液，呈奶酪状 |
| 籽粒用谷粒 | 吐丝后50-60天 | 籽粒变硬，基部出现黑层 |

| 类别 | 状态 | 判定 |
|---|---|---|
| 过早状态 | 籽粒内容物像水一样稀 | 还太早 |
| 嫩玉米适期 | 内容物像浆糊或奶酪，呈品种固有的颜色 | 现在就该摘 |
| 过熟 | 内容物变硬，皮变韧 | 作嫩玉米已经晚了。转作谷粒 |
| 谷粒适期 | 指甲掐不进去，苞叶干透 | 收获 |

&nbsp;&nbsp;&nbsp;嫩玉米的适期不过几天。只要晚一两天，甜味就会下降，皮会变韧。所以嫩玉米用的必须每隔1-2周分批播种，并且最好在清晨采摘。因为这时一夜间积累的糖还没有转化为淀粉。

&nbsp;&nbsp;&nbsp;谷粒用的判断标准是黑层。摘下一粒，看基部，在原先连着穗轴的位置会出现黑点。一旦看到这个，之后即使留在田里，籽粒也不会再长大。剩下的只是变干，而这个干燥过程，在屋檐下比在田里更安全。

> **灌浆成熟期如果连续下雨，在黑层出现后要立刻摘下，剥去苞叶晾干。玉米被苞叶包着，一旦淋湿就不容易干。**

### 12-2. 收获要领

| 顺序 | 内容 | 理由 |
|---|---|---|
| 1 | 在晴天上午开始 | 湿的果穗是霉菌的起点 |
| 2 | 把果穗向下掰折，扭动摘下 | 硬拽会伤到茎秆 |
| 3 | 剥去苞叶，但保留两三片 | 可以用保留的苞叶互相捆扎编连 |
| 4 | 看到有霉的果穗要另外挑出废弃 | 混在一起会污染整个仓库 |
| 5 | 用保留的苞叶把两三个果穗捆在一起 | 为悬挂晾干做准备 |
| 6 | 挂在屋檐下或棚屋里 | 通风的悬挂方式决定干燥的效果 |
| 7 | 收获结束的田里，茎秆收集起来烧掉或切碎埋掉 | 消除亚洲玉米螟的越冬场所 |

&nbsp;&nbsp;&nbsp;保留两三片苞叶的做法是传统方式。把保留的苞叶互相编辫或打结，多个果穗就连成一串，便于悬挂。玉米串一串串挂满屋檐下的景象就是这样，而这种悬挂方式是同时满足通风和排水的最佳干燥形式。在绳子紧缺的情况下，用玉米自己的苞叶当绳子，这也是一个优点。

### 12-3. 晾晒

&nbsp;&nbsp;&nbsp;谷物贮藏的一切都取决于水分。水分超过15%，霉菌就会生长；降到13%以下，霉菌和害虫的活动几乎都会停止。刚摘下的玉米水分为25-35%。把它降到13-14%，是收获后唯一也是最重要的任务。玉米籽粒大，比其他谷物干得慢。

| 步骤 | 方法 | 时间 | 达到的水分 |
|---|---|---|---|
| 1. 剥苞叶 | 只留两三片苞叶，其余剥去 | - | 干燥速度大不相同 |
| 2. 悬挂晾干 | 连果穗挂在屋檐下或棚屋里 | 3-6周 | 16-18% |
| 3. 日晒 | 连果穗摊在草席上晒太阳 | 3-5天 | 15% |
| 4. 脱粒 | 籽粒容易脱落时脱下 | 1天 | - |
| 5. 收尾晾晒 | 把谷粒摊开晒干 | 2-4天 | 13-14% |
| 6. 回潮均匀 | 放在阴凉处一天，使水分均匀 | 1天 | 均一化 |

&nbsp;&nbsp;&nbsp;玉米干燥的关键是苞叶。留着苞叶，里面不会干，湿气被困住就会长霉。贮藏中一半以上的霉变，源于苞叶没有剥好。即使为了捆扎而保留两三片，其余的也必须剥掉，尤其是覆盖果穗顶端的部分，必须完全打开。

&nbsp;&nbsp;&nbsp;悬挂晾干要3-6周。比其他谷物长得多。因为籽粒大，连在穗轴上，接触空气的面积小。不要着急，要给足够的时间，期间只要保证不淋雨就行。屋檐下、棚屋、wondumak（田间的高脚凉棚）等等，只要有屋顶、四面通风的地方都可以。

&nbsp;&nbsp;&nbsp;没有水分仪，也有估测水分的办法。

| 方法 | 步骤 | 判定 |
|---|---|---|
| 指甲试验 | 用指甲掐籽粒 | 掐不出痕迹就是干了 |
| 扭转试验 | 双手扭转果穗 | 籽粒哗哗掉落，说明已干到可以脱粒 |
| 咬粒试验 | 用臼齿咬籽粒 | 啪地裂开并有粉末出来，则为13-14% |
| 盐试验 | 把干盐和谷粒装进瓶里摇匀，放15分钟 | 盐粘在瓶壁上，说明水分高 |
| 瓶试验 | 装半瓶放入玻璃瓶中密封，放一天 | 瓶内侧起雾，就要继续晒 |
| 称重试验 | 选定一个果穗，每天称重 | 重量不再减少，就是干透了 |

&nbsp;&nbsp;&nbsp;扭转试验是只能用在玉米上的便利方法。充分干燥的果穗，只要双手一扭，籽粒就哗哗地掉下来。如果用力后籽粒仍然连在穗轴上，说明还是湿的，这样贮藏必定会变质。

&nbsp;&nbsp;&nbsp;使用火力时，温度不要超过50度。超过的话，种子就不能用了，淀粉也会变性，味道变差。可以放在灶台上方的阁楼里，或暖炕的炕梢，但只升到用手触摸感觉温热的程度。

### 12-4. 脱粒

&nbsp;&nbsp;&nbsp;玉米脱粒与其他谷物不同。籽粒密密地嵌在穗轴上，敲打或踩踏的方式不管用。不过每粒籽粒都很大，用手也能剥下来。要领是先空出第一行，腾出空间。

| 方法 | 步骤 | 规模 | 备注 |
|---|---|---|---|
| 拇指推 | 用拇指推下一行，空出一条沟后，把其余的向侧面推下 | 少量 | 只要剥下第一行，其余的就很容易推下 |
| 两穗对搓 | 把两个干果穗对在一起互相搓 | 中等 | 无需工具，最快 |
| 在袋内搓 | 把果穗装进麻袋，用脚踩着滚动 | 大量 | 籽粒不会散落 |
| 瓶盖板 | 在木板上钉上瓶盖或钉子做成板，把果穗在上面摩擦 | 中等 | 是可以简单制作的脱粒器 |
| 放进木臼里舂 | 连果穗放入，轻轻舂 | 中等 | 缺点是穗轴会碎并混入 |
| 铁棒捅 | 把铁棒插进果穗中心转动 | 中等 | 在穗轴上扎孔的同时把籽粒推出 |

&nbsp;&nbsp;&nbsp;最实用的方法，是用拇指空出第一行，再推下其余的。玉米籽粒成行排列，旁边有了空位，就会被推着掉落。只要用拇指指甲一粒一粒地剥下第一行，之后用手掌推，就快得多。手疼的话，可以戴上厚手套，或改用两个果穗对在一起互相搓的方法。

&nbsp;&nbsp;&nbsp;瓶盖板是值得事先做好的简易工具。在木板上把皇冠型瓶盖锯齿朝上钉上许多个，或密密地钉上粗钉子制成。把干果穗压在上面转动，籽粒就会被刮下来。一个人一天能处理的量，是用手剥的三四倍。

&nbsp;&nbsp;&nbsp;穗轴（玉米芯）不要扔掉。晒干的穗轴是火力很好的柴火，烧成的灰是富含钾的肥料。粉碎后可作堆肥的碳源，从前还曾当作瓶塞或刷子使用。灾难情况下，玉米芯是不亚于谷物的资源。

### 12-5. 扬去秕杂

| 方法 | 步骤 | 条件 |
|---|---|---|
| 顺风倾倒 | 有风的日子，从高处慢慢倒下 | 玉米籽粒重，一般的风吹不走 |
| 簸扬 | 装入簸箕，向前推再往回拉，使其扬起 | 簸掉苞叶碎片和碎裂的穗轴 |
| 过筛 | 用粗筛筛出穗轴碎片，用细筛筛出碎屑 | 玉米籽粒大，过筛尤其容易 |
| 手拣 | 拣出长霉的籽粒、被虫蛀的籽粒 | 是贮藏前的最后一道关 |

&nbsp;&nbsp;&nbsp;玉米籽粒大而重，筛选比其他谷物容易。但相应地，用手挑拣这道工序尤为重要。因为几粒长霉的籽粒就可能污染整个仓库。变色的籽粒、尖端发黑的籽粒、有虫孔的籽粒，不要舍不得，都要拣出来。

## 13. 留种

### 13-1. F1与固定品种 - 首先要确认的事

&nbsp;&nbsp;&nbsp;玉米留种时，比其他一切都更要先确认的，是所种品种是F1杂交种还是固定品种。

| 类别 | 自家留种 | 次年结果 |
|---|---|---|
| F1杂交种 | 不可能 | 因自交衰退，株高和果穗参差不齐，收成降到一半以下 |
| 固定品种·地方品种 | 可以 | 只要做好隔离，性状就能保持 |

&nbsp;&nbsp;&nbsp;自交衰退是玉米上表现最严重的现象。F1种子是把性状不同的两个品系杂交而成的，只有在第一代才表现出杂种优势。把从中收的种子再种下去，基因就会分离，大的小的、早熟的晚熟的混杂在一起，整体收成崩溃。

> **如果预计灾难会持续很久，那么即使产量稍低，也必须备好固定品种或地方品种。靠F1是没有第二年的。**

### 13-2. 隔离

| 方法 | 内容 | 效果 |
|---|---|---|
| 距离隔离 | 与其他品种相隔200m以上 | 最可靠，但在狭小的土地上难以做到 |
| 时间隔离 | 把播种期错开3周以上 | 花期不重叠就不会混杂 |
| 套袋 | 花丝抽出之前给果穗套上纸袋 | 适合小规模 |
| 人工授粉 | 把同品种雄穗的花粉抖入袋内 | 与套袋配合使用 |
| 设置屏障 | 在中间种高大的其他作物 | 只有部分效果 |

&nbsp;&nbsp;&nbsp;玉米是靠风传播花粉的异花授粉作物。邻田有其他品种的话，其花粉会飘来混杂，结果当年的果穗上就会立刻表现出来。糯玉米田旁边如果有甜玉米，糯玉米的果穗上就会混杂着没有黏糯性的籽粒。

&nbsp;&nbsp;&nbsp;狭小土地上最实用的方法是套袋。给即将抽出花丝的果穗套上纸袋，把从同品种雄穗上收集的花粉抖入袋内，再扎好。只要这样管理三四个果穗，就足够作为次年的种子。因为一个玉米果穗上嵌着数百粒籽粒。

### 13-3. 留种个体的选择与保存

| 标准 | 内容 | 理由 |
|---|---|---|
| 个体选择 | 无病症、未倒伏、果穗大的植株 | 性状得以延续 |
| 来自多株 | 至少从20-30株中均匀留种 | 异花授粉作物需要遗传多样性 |
| 籽粒位置 | 只用果穗中段的籽粒 | 穗尖和基部的籽粒发芽不整齐 |
| 收获时机 | 完全成熟、出现黑层之后 | 未成熟种子发芽力低 |
| 干燥 | 连果穗充分晒干后用手剥粒 | 避免机械损伤 |
| 水分 | 12-13% | 比食用的再干一些 |
| 保存 | 放在密封容器中，置于凉爽阴暗处 | 同时放入草木灰或干辣椒 |
| 寿命 | 常温密封2-3年 | 凉爽时保存更久 |

&nbsp;&nbsp;&nbsp;玉米留种与粟、高粱这类自花授粉作物不同之处在于，必须从多株上留种。玉米是异花授粉作物，必须维持遗传上多样的群体才健康。如果一直只从最好的一个果穗上留种，几代之后就会出现近交衰退。原则是把至少20-30株的果穗均匀混合，作为次年的种子。

### 13-4. 发芽试验

&nbsp;&nbsp;&nbsp;种植陈种子之前，要确认发芽力。用湿布包20粒种子，放在温暖处，等5-7天。20粒中有18粒以上就照常使用，14-17粒就把每穴改为3粒，12粒以下就必须另找新种子。玉米的标准是每穴播2粒，所以发芽率会直接反映到株数上。

## 14. 毒性与注意事项

### 14-1. 糙皮病 - 玉米作为主食的最大风险

&nbsp;&nbsp;&nbsp;玉米本身没有毒性。但以玉米为主食时会产生一个问题，这个问题在历史上曾夺去数十万人的生命。那就是烟酸缺乏症——糙皮病。

| 项目 | 内容 |
|---|---|
| 原因 | 玉米中的烟酸以无法吸收的结合形态存在 |
| 加重因素 | 玉米也缺乏色氨酸。色氨酸是体内转化为烟酸的原料 |
| 症状 | 日晒部位的皮肤发炎、腹泻、精神异常，以及死亡 |
| 发病条件 | 除玉米外几乎没有其他蛋白质来源的饮食持续数月时 |
| 历史 | 19世纪在南欧和美国南部大规模爆发 |

&nbsp;&nbsp;&nbsp;这种病之所以可怕，是因为玉米是出色的食物。吃得饱，热量也充足，几个月后却发病。不知道原因的话，想不到是玉米造成的。事实上，在19世纪的欧洲，它长期被认为是传染病。

> **以玉米为主食，却没有豆类，也不做碱处理，这样的饮食几个月后就会让人生病。**

&nbsp;&nbsp;&nbsp;应对办法有两种，都不难。第一，与豆一起吃。豆中富含色氨酸和赖氨酸，恰好弥补不足。玉米与豆一起吃，就不会得糙皮病（Pellagra）。第二，碱处理。把玉米放在溶有草木灰或石灰的水中煮，结合就会被打断，烟酸变成可吸收的形态。这称为尼克斯塔马化（nixtamalization），是中南美洲原住民使用了数千年的方法。具体步骤见第16节。

&nbsp;&nbsp;&nbsp;把玉米带到欧洲的人只带走了作物，没有带走这种烹饪方法，这正是糙皮病大流行的原因。在灾难情况下，有没有这方面的知识，可能造成同样的结果。

### 14-2. 霉菌毒素

| 风险因素 | 危险程度 | 措施 |
|---|:---:|---|
| 正常的干谷粒 | 无 | 安全 |
| 果穗上长霉的 | 极高 | 全部废弃。也不要喂牲畜 |
| 贮藏中返潮发出气味的 | 极高 | 废弃。洗过或炒过毒素仍然残留 |
| 变色并结块的 | 高 | 连同该部分一起大范围清除 |
| 仅尖端发黑的籽粒 | 高 | 拣出 |

&nbsp;&nbsp;&nbsp;在谷物中，玉米是最容易受到黄曲霉毒素污染的一类。因为籽粒大，干得慢，又被苞叶包着，里面一旦湿了就不容易干。黄曲霉毒素是强力的肝毒性物质，具有致癌性，加热也不会消失。对儿童尤其危险。

&nbsp;&nbsp;&nbsp;应对完全靠预防。要把苞叶充分剥开晾干，确认水分在13%到14%之后再贮藏，贮藏期间每两个月闻一次气味。已经长霉的，无论多可惜，都不能入口。放入堆肥堆会分解，成为来年的肥料。

### 14-3. 其他注意事项

| 项目 | 内容 |
|---|---|
| 生玉米 | 甜玉米和超甜玉米可以生吃 |
| 干谷粒 | 必须泡发后煮熟。直接吃不会被消化 |
| 玉米须 | 可以泡茶喝。有利尿作用 |
| 黑粉病瘤 | 在墨西哥被食用，但不能确切辨别时不要吃 |
| 单一饮食 | 缺乏赖氨酸和色氨酸。必须与豆一起吃 |
