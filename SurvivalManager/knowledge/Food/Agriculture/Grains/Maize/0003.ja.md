## 3. 栽培環境

### 3-1. 限界値と最適値

| 条件 | 最適値 | 耐えられる範囲 | 外れたとき |
|---|---|---|---|
| 生育気温 | 20-30℃ | 12-40℃ | 12℃を下回ると生長が止まり、霜で枯死します |
| 発芽温度 | 32-34℃ | 最低8-11℃ | 土壌13℃で出芽まで18-20日、15-18℃で8-10日 |
| 絹糸抽出期の気温 | 25-28℃ | 35℃以下 | 35℃を超えると花粉が死んで穂が空になります |
| 登熟期の気温 | 20-25℃ | 18-30℃、幅12℃ | 暑すぎると粒が充実しません |
| 光量 | 1日8-10時間の直射日光 | 6時間以上 | 40%遮光で収量が45%に落ちます |
| 総水要求量 | 550mm前後 | 400-700mm | 絹糸抽出期の干ばつが最も致命的です |
| 土壌 | 排水良好な砂壌土-壌土 | ほとんどの土壌 | 通気性が特に重要です |
| 土壌酸度 | pH 6.0-6.8 | pH 5.5-7.5 | 強酸性ではリン酸が固定されます |
| 冠水 | あってはならない | 3日まで | 4日以上冠水すると草丈が12%低くなり、絹糸抽出が5日遅れます |
| 霜 | あってはならない | なし | 一度の霜で枯れます |

&nbsp;&nbsp;&nbsp;この表で目を引くのは、発芽温度の幅です。最適は32-34℃なのに、最低は8-11℃です。低い温度でも発芽はしますが、非常に遅くなります。土壌温度13℃では芽が出るまでに20日かかり、その20日の間、種子は土の中で腐ったり虫に食べられたりする危険にさらされます。急いで植えることが必ずしも有利ではないという意味です。

&nbsp;&nbsp;&nbsp;冠水の項目も、具体的に記録しておく価値があります。トウモロコシは4日以上水に浸かると、草丈と茎の太さが減り、葉の老化が早まります。通気性の低い土壌では草丈が12%低くなって絹糸抽出が5日遅れ、絹糸抽出が遅れると花粉の時期とずれて穂が空になります。韓国の梅雨（チャンマ、6月下旬～7月）の排水が、トウモロコシ栽培の成否を分ける理由です。

### 3-2. 災害時の立地選び

| 場所 | 適合度 | 理由 |
|---|:---:|---|
| 南向きの緩傾斜で、日が一日中当たる畑 | 最適 | C4作物なので日照が収量を直接決めます |
| 土層が厚く肥沃な平地の畑 | 最適 | 多肥性なので、もともと養分の多い土地が有利です |
| 堆肥を集中して入れられる近場の畑 | 良 | 肥料の運搬労働が減ります |
| 畜舎やトイレの近く | 良 | し尿資源に近づきやすいです |
| 水田から転換した畑 | 注意 | 18cm以上の深耕と排水溝が必須です |
| 痩せた砂利畑 | 不適 | モロコシやアワに回すほうがよいです |
| 日陰になる場所 | 不適 | 遮光の被害が他の作物よりはるかに大きくなります |
| 低地、水がたまる場所 | 不適 | 4日の冠水で収量が崩れます |

&nbsp;&nbsp;&nbsp;災害時に畑を割り振るときの原則は明確です。最も肥沃で日当たりのよい土地をトウモロコシに与え、痩せた端の土地はモロコシやアワに回します。トウモロコシは良い土地で圧倒的な熱量を生みますが、悪い土地では平凡になります。一方、モロコシとアワは悪い土地でも自分の役割を果たします。この非対称性を利用するのが、全体の収穫を最大にする配置です。

&nbsp;&nbsp;&nbsp;肥料の運搬距離も、実質的な考慮事項です。トウモロコシは堆肥を多く要求しますが、堆肥は重いものです。荷車がなければ、1,000㎡に堆肥1トンを運ぶ作業は何日もかかる労働になります。堆肥の山や畜舎に近い畑をトウモロコシに割り当てるだけで、かなりの労働が節約できます。

## 4. 品種

### 4-1. 用途による分類

| 区分 | 特徴 | 用途 | 災害時の観点 |
|---|---|---|---|
| もち種トウモロコシ（チャルオクスス） | もちもちしていて、ゆでて食べるのに向いています | 若採りトウモロコシとして食用 | 韓国国内の代表的な品種。抵抗感が少ないです |
| スイートコーン・スーパースイートコーン | 糖度が高く、生食が可能です | その場で食用 | 貯蔵が難しく、粒がしぼみます |
| 子実用・飼料用 | 粒が硬く、デンプンが多いです | 乾燥貯蔵、製粉 | 長期備蓄と主食化に必須です |
| 爆裂種（ポップコーン用） | 粒が小さく硬いです | ポップコーンにする | 燃料がほとんど要らない調理ができます |

> **災害対策での分かれ道はここです。若採り用の品種は夏の一時期の食料であり、子実用の品種だけが冬を越す備蓄になります。**

&nbsp;&nbsp;&nbsp;この区別を見落とすと困ったことになります。もち種やスイートコーンは若採りで食べる品種なので、完熟させると粒がしぼみ、デンプン含量が低くて、貯蔵穀物としての価値が下がります。一方、子実用の品種は若採りで食べても味がよくありませんが、完熟させて乾燥させれば、3年もつ穀物になります。トウモロコシの面積当たり熱量Aは、子実用を前提とした数値です。

&nbsp;&nbsp;&nbsp;現実的な配置は、両方を植えることです。夏にすぐ食べるもち種トウモロコシをいくらか植え、残りを子実用で埋めて冬の備蓄に回します。ただし、二つの種類を近くに植えると花粉が混ざってもち種のもちもち感がなくなるため、200m以上離すか、播種時期を3週間以上ずらす必要があります。

### 4-2. 主な品種の比較

| 品種 | 熟期 | 収量 | 特徴 |
|---|:---:|:---:|---|
| もち種トウモロコシ | 80-90日 | 中 | 韓国国内の代表。もちもちした食感です |
| スーパースイートコーン | 70-80日 | 中 | 糖度が高く、生育が早いです |
| ゴダンオク | 約80日 | 上 | もち種トウモロコシより10日短く、二期作が可能です |
| 子実・飼料用 | 90-100日 | 上 | 粒が硬く、乾燥貯蔵に最適です |

### 4-3. 状況別の選択基準

| 状況 | おすすめ | 理由 |
|---|---|---|
| 長期備蓄が目的 | 子実・飼料用 | 乾燥させて3年以上保管できます |
| 夏の食料を確保したい | もち種トウモロコシ | ゆでてすぐ食べられます |
| 早い収穫が必要 | スーパースイートコーン、ゴダンオク | 70-80日で収穫できます |
| 面積が限られるとき | ゴダンオク | 二期作が可能です |
| 燃料が極端に不足しているとき | 爆裂種 | ポップコーンにすれば燃料がほとんど要りません |
| 自家採種が必要なとき | 在来種・固定種 | F1は翌年に崩れます |

&nbsp;&nbsp;&nbsp;最後の項目が最も重要です。市販されているトウモロコシ種子の多くはF1交配種です。F1は初年度の収量が優れていますが、そこから採った種をまくと自殖弱勢が現れ、草丈も穂もばらばらになり、収穫が半分以下に落ちます。物流が途絶えて種子を買えない状況を前提とするなら、収量が少し低くても、在来種や固定種を確保しておくほうがはるかに安全です。在来種は毎年種を採って植え続けることができます。

## 5. 畑の準備と肥料

### 5-1. 土づくり

| 項目 | 内容 | 理由 |
|---|---|---|
| 耕す深さ | 18cm以上、できれば25-30cm | 根が深く広く伸びてはじめて、多肥の要求に応えられます |
| 排水溝 | 畑の周囲と畝間に必ず | 4日の冠水が収量を崩します |
| 畝 | 高さ15-20cm | 梅雨期の冠水を防ぎます |
| 土壌酸度 | pH 6.0-6.8 | 酸性が強いとリン酸が固定されます |
| 有機物 | 堆肥1,000-1,500kg/1,000㎡ | 多肥性なので多く入れる必要があります |
| 石灰 | 酸性矯正用 | 草木灰で代用できます |

&nbsp;&nbsp;&nbsp;トウモロコシ畑の準備で他の作物と最も異なる点は、有機物の量です。多肥性の作物なので堆肥をたっぷり入れる必要があり、その堆肥がゆっくり分解しながら生育後半まで養分を供給し続けなければなりません。化学肥料があるときは堆肥は補助でしたが、ない条件では堆肥がすべてになります。そのためトウモロコシ栽培の準備は、春ではなく前年の秋に始まります。堆肥の山をいつ積んだかが、翌年のトウモロコシの収穫を決めます。

### 5-2. 標準施肥量（1,000㎡当たり）

| 肥料 | 施肥量 | 時期 |
|---|:---:|---|
| 窒素（N） | 10-15kg | 元肥50%、追肥50% |
| リン酸（P） | 8-10kg | 全量元肥 |
| カリウム（K） | 8-10kg | 元肥と追肥に分施 |
| 堆肥 | 1,000-1,500kg | 完熟堆肥で全量元肥 |

| 区分 | 時期 | 内容 |
|---|---|---|
| 元肥 | 播種の1-2週間前 | 堆肥全量、リン酸全量、カリウム半量、窒素半量 |
| 追肥 | 5-7葉期 | 残りの窒素とカリウム。土寄せを併せて行います |

&nbsp;&nbsp;&nbsp;トウモロコシは、他の穀物とは反対に、肥料を惜しむと損をします。モロコシやアワは窒素を多く与えると倒れてしまいますが、トウモロコシは茎が太く丈夫で、ある程度の窒素には耐えられ、その分を穂として返してくれます。肥料に余裕がある状況なら、トウモロコシに集中して与えるほうが、全体の収穫を増やせます。

### 5-3. 化学肥料がないとき - 災害時の代替肥料

| 代替資源 | 供給成分 | 作り方と使い方 | 注意 |
|---|---|---|---|
| 完熟堆肥 | 総合、特に窒素 | 落ち葉・草・ふん尿を層状に積み、3-6か月腐熟させます | トウモロコシでは量が鍵です。あらかじめ多めに積んでおきます |
| 薄めた尿 | 窒素、カリウム | 水で10倍に薄め、5-7葉期に畝間に流します | 追肥の主力になります |
| 草木灰 | カリウム、リン酸、カルシウム | 1,000㎡に40-60kgを散布します | 酸度矯正を兼ねます |
| 骨粉 | リン酸、カルシウム | 焼いて砕いた後、堆肥に混ぜて2か月寝かせます | 分解が遅いため、あらかじめ準備します |
| マメ科緑肥 | 窒素 | 前作として豆・レンゲ・ヘアリーベッチをすき込みます | トウモロコシに最も効果が大きい方法です |
| 豆との混植 | 窒素 | トウモロコシの間に豆を一緒に植えます | 三姉妹農法の核心です |
| 家畜の敷きわら | 総合 | 稲わらとふん尿が混ざったものを腐熟させて使います | 塩分が多いものは避けます |
| 人糞堆肥 | 窒素、リン酸 | おがくずやもみ殻と混ぜ、6か月以上完全に腐熟させます | 腐熟が不十分だと寄生虫と病原菌が残ります |

&nbsp;&nbsp;&nbsp;トウモロコシの肥料の問題は、他のどの作物よりも重いものです。窒素10-15kgを堆肥に換算すると完熟堆肥2トンから3トンにあたり、それを1,000㎡の畑に入れなければなりません。現実的に、この量を毎年確保するのは困難です。そのため、トウモロコシの施肥戦略は三つに分かれます。

&nbsp;&nbsp;&nbsp;第一に、豆と一緒に植えます。豆の根粒菌が固定した窒素の一部が、土を通ってトウモロコシに流れていきます。完全に満たすことはできなくても、不足分のかなりの部分を補います。第二に、前作にマメ科緑肥を植え、花が咲く時期にすき込みます。ヘアリーベッチやレンゲをすき込むと、1,000㎡当たり窒素8-12kgが供給されます。これはトウモロコシの標準的な窒素要求をほぼ満たす量です。第三に、尿を追肥として使います。成人一人が一日に出す尿には窒素が6-10g含まれているので、四人家族の一か月分を集めれば、1,000㎡の追肥に相当する窒素が得られます。

> **トウモロコシ栽培の半分は、畑ではなく堆肥の山と緑肥畑で行われます。肥料の計画なしにトウモロコシを植えるのは、植えるまねごとにすぎません。**

## 6. 播種

### 6-1. 時期

| 地域 | 播種適期 | 備考 |
|---|---|---|
| 韓国南部 | 4月上旬 | 霜の危険が過ぎた後です |
| 韓国中部 | 4月中旬 | 土壌温度12℃以上が目安です |
| 二期作の後作 | 7月上旬 | 早生種で霜が降りる前に収穫します |
| 播種の限界 | 6月下旬 | これより遅いと登熟期が霜にかかります |

&nbsp;&nbsp;&nbsp;播種時期の基準は土壌温度です。12℃を超える必要があり、15℃を超えればずっとよくなります。13℃では芽が出るまでに20日かかりますが、15-18℃では8-10日で出ます。急いで植えて土の中で20日を過ごすよりも、1週間待ってから植えて10日で出てこさせるほうが、結果がよくなります。

&nbsp;&nbsp;&nbsp;災害時には、一度にすべて植えず、1-2週間間隔で分けて植えるほうがよいです。収穫期が分散するので、一度に処理しきれない問題を避けられ、ある時期の台風や病害がすべてを持っていってしまうことも防げます。特に、若採りトウモロコシとして食べる分は、必ず分けて植える必要があります。一度に熟すと、数日のうちに全部食べるか、捨てなければなりません。

### 6-2. 種子の準備

| 項目 | 内容 | 備考 |
|---|---|---|
| 選別 | 穂の中ほどの、太くてそろった粒を使います | 先端側と基部の粒は発芽がそろいません |
| 水選 | 水に入れて浮くものを取り除きます | トウモロコシは粒が大きいので目でも選別できます |
| 灰まぶし | 草木灰をまぶします | 消毒と乾燥を兼ね、鳥やアリに狙われにくくなります |
| 催芽 | 湿らせた布に包んで1日置き、芽出しさせます | 発芽が早まります。根を傷めないよう注意します |
| 播種粒数 | 穴当たり2粒 | 発芽率の保険です |

### 6-3. 種子消毒 - 薬がないとき

| 方法 | 手順 | 効果 | 注意 |
|---|---|---|---|
| 草木灰まぶし | 種子に水を軽くかけてから、細かい灰をまぶします | 表面消毒に加え、鳥・アリを遠ざける効果があります | 最も実用的です |
| 温湯浸漬 | 50-55℃の湯に10分浸けてから、冷水で冷まします | 表面の病原菌を殺します | 60℃を超えると種子が死にます |
| 木酢液浸漬 | 500倍の希釈液に6-12時間浸けます | 表面殺菌と発芽促進 | 原液は種子を殺してしまいます |
| 健全種子の選抜 | 黒穂病がなかった株からのみ採ります | 最も根本的です | 生育期に印を付けておく必要があります |

&nbsp;&nbsp;&nbsp;トウモロコシの種子には、草木灰まぶしが特に有用です。粒が大きいため、植えた後に鳥やネズミ、アリに掘り出されて食べられることが多いのですが、灰をまぶすと目立たなくなり、味も落ちるので被害が減ります。消毒効果も同時に得られます。

### 6-4. 植え付け

| 項目 | 基準 | 理由 |
|---|---|---|
| 播種の深さ | 3-5cm | 粒が大きいので、他の穀物より深く植えます |
| 条間 | 70cm | 間に入って草取りと土寄せをするための幅です |
| 株間 | 25cm | 密植しすぎると穂が小さくなります |
| 穴当たり | 2粒 | 後で1株に間引きます |
| 配置 | 一列より何列かまとめて | 風による受粉がよくなります |
| 覆土後 | 軽く押さえます | 土と密着させます |

&nbsp;&nbsp;&nbsp;配置が特に重要です。トウモロコシは風で花粉を運ぶので、一列に長く植えると花粉が畑の外へ飛んでいってしまい、穂の粒がまばらになります。最低でも四列以上を並べて四角形をつくれば、お互いの花粉を受けて、実入りがそろいます。狭い家庭菜園でトウモロコシを植えるときによくある失敗が、塀に沿って一列に植えることで、その結果が粒のまばらな穂です。

### 6-5. 間引き

| 時期 | 作業 | 備考 |
|---|---|---|
| 草丈15cm | 1株だけ残して間引きます | 抜かずに、株元を切り取ります |

&nbsp;&nbsp;&nbsp;間引くときは、抜かずに切り取るのがよいです。トウモロコシの根は互いに絡み合っているので、抜くと残す株の根まで揺さぶられます。爪や小さなナイフで地面近くから切り取れば、残した株が傷みません。間引いた若いトウモロコシは、家畜の飼料や堆肥の材料として使います。
