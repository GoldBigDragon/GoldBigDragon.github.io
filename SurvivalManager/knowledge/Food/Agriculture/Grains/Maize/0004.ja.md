## 7. 水管理

### 7-1. 生育段階別の基準

| 時期 | 管理 | 理由 |
|---|---|---|
| 播種から発芽まで | 土が乾かないように保ちます | 粒が大きく、吸水量が多いためです |
| 幼苗期 | 適度に。過湿を避けます | 根を深く伸ばすように促します |
| 栄養生長期 | 十分に | 茎と葉が急激に増えます |
| 絹糸抽出・開花期 | 必ず十分に | この2週間が収量全体を決めます |
| 登熟期 | 十分に | 粒にデンプンが詰まる時期です |
| 成熟期 | 給水を止めます | 収穫後の乾燥が楽になります |
| 韓国の梅雨（チャンマ、6月下旬～7月）の時期 | 水を抜くことが管理です | 4日間の冠水で収量が崩れます |

&nbsp;&nbsp;&nbsp;トウモロコシの水要求量は、ほかの穀物より大きいです。総蒸発散量は550mmで、モロコシの二倍を超えます。韓国の夏の降水量であれば、たいていは自然の降水でまかなえますが、梅雨が早く明けて猛暑が続く年には不足します。

&nbsp;&nbsp;&nbsp;水が限られている状況なら、絹糸抽出期に集中して与えなければなりません。トウモロコシは、絹糸が出て花粉を受ける2週間のあいだに水が切れると、絹糸が遅れて出て、花粉の時期とずれます。花粉は数日で落ちきってしまうため、絹糸が遅れればそのまま実のない穂になります。この損失は、あとからどれだけ水をやっても回復しません。栄養生長期の干ばつは草丈が低くなる程度で済みますが、絹糸抽出期の干ばつは収穫そのものをなくします。

### 7-2. 水不足と水過多の症状

| 症状 | 原因 | 判断と対処 |
|---|---|---|
| 日中に葉が内側に巻きます | 一時的な水分不足 | 夕方に開けば正常の範囲です |
| 朝になっても葉が巻いたままです | 実質的な干ばつ | 絹糸抽出期なら直ちに灌水します |
| 絹糸が出ない、または非常に遅れます | 絹糸抽出期の干ばつまたは高温 | 回復不能です |
| 穂の先に粒が入っていません | 水分不足または花粉不足 | 翌年の配置と灌水計画を見直します |
| 葉が黄色くなり、下の葉から枯れます | 冠水または窒素不足 | 株元を掘って根の色で見分けます |
| 葉が紫色を帯びます | 低温期のリン酸吸収障害 | 気温が上がれば回復します |
| 株元が軟らかくなって倒れます | 冠水による根の腐敗 | 直ちに排水し、土寄せをします |

> **トウモロコシは水をたくさん使う作物であると同時に、水に浸かるとたちまち崩れる作物でもあります。水を入れることと、水を抜くことの両方が必要です。**

## 8. 栽培管理

### 8-1. 草取り - トウモロコシの損失の最大要因

| 時期 | 作業 | 要点 |
|---|---|---|
| 出芽後2週間 | 1回目の草取り | 雑草が小さいうちに抜きます |
| 5-7葉期 | 2回目の草取りと土寄せ、追肥 | 三つの作業を一度に行います |
| 膝の高さ以降 | 必要に応じて | トウモロコシが日陰をつくって雑草を抑えます |

&nbsp;&nbsp;&nbsp;トウモロコシの無防除の潜在損失68.5%のうち、40.3ポイントが雑草によるものです。病害虫よりも雑草のほうがはるかに大きな損失源です。これは、薬がない条件では朗報です。雑草は薬ではなく人の手で解決できる問題だからです。草取りをまめに行うだけで、トウモロコシの損失の大部分を防ぐことができます。

&nbsp;&nbsp;&nbsp;ただし、時期が重要です。トウモロコシが膝の高さを超える前、つまり播種後30-45日の間が、雑草との競合が最も激しい区間です。それ以降は、トウモロコシの広い葉が地面を覆い、雑草が育たなくなります。労力をこの一か月に集中させるのが効率的です。

### 8-2. 土寄せ

| 時期 | 作業 | 効果 |
|---|---|---|
| 5-7葉期 | 株元に土を20cmの高さまで寄せます | 支持根が土に入り込み、倒伏が大きく減ります |
| 膝の高さ | 必要に応じてもう一度 | 根の発達を助け、水はけをよくします |

&nbsp;&nbsp;&nbsp;土寄せは、トウモロコシでは特に価値の大きい作業です。草丈が2-3mに達する作物が台風に耐えるには、根がしっかり張っていなければなりませんが、トウモロコシでは茎の株元から出る支持根がその役割を果たします。土寄せをして、この支持根が土にしっかり入り込むようにしてやると、倒伏が目に見えて減ります。同時に畝間が深くなり、排水もよくなります。費用がまったくかからず、収量と安定性をともに高める作業です。

### 8-3. その他の管理

| 項目 | 内容 |
|---|---|
| 分げつ | 取り除いても収量が増えないので、そのままにします |
| 分げつの発生 | 株数が少ないときや肥料が多いときに出ます |
| 人工授粉 | 着粒が悪いときは、雄穂を揺すって花粉を落とします |
| 鳥の被害 | 穂の皮をむいて食べます。熟す頃に網や紙袋をかぶせます |
| 倒伏後 | 起こして、土で株元を押さえてやります。穂が地面に触れると腐ります |
| 下葉の除去 | 行いません。光合成面積が減ります |

&nbsp;&nbsp;&nbsp;人工授粉は、狭い畑で役に立つ技術です。トウモロコシを植えた列数が少なかったり、風のない日が続いたりすると、花粉がうまく落ちて付きません。朝露が乾いてから雄穂を手で揺すってやるか、雄穂を切り取って下の株の絹糸の上で振ってやると、着粒がはっきりとよくなります。数日にわたって何度か行うのがよいでしょう。絹糸は一度に出てくるわけではないからです。

## 9. 病害虫

### 9-1. 主な病害

| 病害 | 発生条件 | 症状 | 薬を使わない対応 |
|---|---|---|---|
| 黒穂病 | 高温多湿、傷のある部位 | 穂や茎に白いこぶができ、黒い粉になって破れます | 見つけ次第、破れる前に切り取って焼却、排水改善、輪作 |
| ごま葉枯病 | 高温多湿 | 葉にゴマ粒のような斑点ができます | 風通しの確保、病葉の除去・焼却、輪作 |
| 茎腐病 | カビや細菌に汚染された水 | 茎の中が軟らかくなって倒れます | 畝間灌水に切り替え、水の跳ね返りを減らします |
| 根腐病 | 過湿、長期の冠水 | 根が黒く腐ります | 排水改善のほかに方法がありません |
| 黒条萎縮病 | ヒメトビウンカが媒介するウイルス | 葉が硬くなり、草丈が低くなります | 媒介虫の管理、周辺の雑草の除去 |
| 紋枯病 | 密植、多湿 | 葉鞘が軟らかくなって枯れます | 栽植間隔の確保、排水 |
| 穂腐病 | 登熟期の雨 | 穂にカビが生えます | 早期収穫、皮をむいて乾燥、病気の穂の廃棄 |

&nbsp;&nbsp;&nbsp;災害時に最も危険なのは穂腐病です。収量の損失よりも毒性が問題です。穂に生えるカビの一部はアフラトキシンやフモニシンのような毒素をつくり、この毒素は加熱しても消えません。アフラトキシンは特に強力な肝毒性物質で、発がん性があります。飢えた状況ほどもったいなくて食べてしまいがちですが、この判断はあらかじめ決めておく必要があります。

> **カビが生えたトウモロコシは、洗っても、ゆでても、炒っても安全になりません。捨てることが唯一の方法であり、家畜にも与えません。**

&nbsp;&nbsp;&nbsp;予防は乾燥にかかっています。登熟後半に雨が続くと、穂ではすでにカビが生え始めます。トウモロコシは皮に包まれていて、中が濡れると乾きにくいため、さらに危険です。そのような場合は、完全に熟すのを待たずに収穫し、皮をむいて乾燥させるほうがよいでしょう。

&nbsp;&nbsp;&nbsp;黒穂病は性質が異なります。白いこぶが黒い粉になって破れる前に切り取れば、そこで終わりです。破れたあとは胞子が畑全体に広がり、何年も残ります。畑を回ってこぶを探し、破れる前に取り除くことが、この病気に対する唯一の実質的な対応です。ちなみに、このこぶはメキシコではウイトラコチェと呼ばれ、食用にされることもありますが、確実に見分けられないのであれば、食べないほうが安全です。

### 9-2. 主な害虫

| 害虫 | 時期 | 被害 | 薬を使わない対応 |
|---|---|---|---|
| アワノメイガ | 5月末-10月初め、年3回 | 幼虫が葉、茎の中、穂を食い荒らします | 被害茎の除去・焼却、収穫後の残渣処理、卵塊の除去 |
| アワヨトウ | 突発的に発生 | 葉をあっという間に食い尽くします | 手で捕まえ、ひどければ早期収穫 |
| ヒメトビウンカ | 生育期 | ウイルスを媒介します | 周辺の雑草の除去 |
| アブラムシ | 生育期 | 汁を吸い、すす病を招きます | 石けん水の散布、天敵の保護 |
| 鳥類 | 登熟期 | 皮をむいて粒を食べます | 紙袋や古い布をかぶせる、網 |
| ネズミ | 登熟期・貯蔵期 | 穂を食べ、貯蔵庫に穴をあけます | 畑の整理、金属容器の使用 |

&nbsp;&nbsp;&nbsp;アワノメイガは、トウモロコシの代表的な害虫です。韓国では年3回発生し、第1世代は5月末から6月初め、第2世代は7月初めから8月中旬、第3世代は8月中旬から10月初めです。幼虫が茎の中に潜り込むと、薬を散布しても届かないので、平時でも卵からふ化する時期に合わせて防除します。薬がない条件で使える手段は、物理的なものだけです。

| 方法 | 内容 | 効果 |
|---|---|---|
| 残渣処理 | 収穫後に茎を集めて焼くか、細かく切って埋めます | 茎の中で越冬する幼虫を駆除します |
| 卵塊の除去 | 葉の裏にある鱗のような卵塊を見つけてこすり落とします | ふ化前なので最も効果的です |
| 被害茎の除去 | おがくずのような糞が出ている茎を切って焼きます | その中の幼虫を駆除します |
| 播種時期の調整 | 第1世代の発生を避けて植えるか、早く植えて避けます | 発生世代と生育期をずらします |
| 天敵の保護 | 寄生バチやクモを殺さないようにします | 密度が徐々に下がります |

&nbsp;&nbsp;&nbsp;このうち最も効果が大きいのは、収穫後の残渣処理です。アワノメイガの幼虫はトウモロコシの茎の中で冬を越し、翌年の春に出てきます。刈り取った茎をそのまま畑に置いておくと、その中で幼虫がそっくり生き残り、翌年の個体数の出発点になります。切って焼くか、焼けない場合は細かく砕いて堆肥の山の深くに埋めれば、大部分が死にます。薬を一滴も使わずに、翌年の被害を半分以下に減らせる作業です。

### 9-3. 自然素材の防除剤

| 材料 | 作り方 | 対象 | 注意 |
|---|---|---|---|
| 石けん水 | 水1Lに純石けん5-10g | アブラムシ、ハダニ | 真昼にまくと葉が焼けます |
| 草木灰 | 露の降りた朝に、葉と葉腋にまきます | 若齢幼虫 | アワノメイガのふ化期に効果があります |
| 木酢液 | 500-1,000倍に希釈 | カビによる病気の予防、忌避 | 濃いと薬害が出ます |
| ニンニク・トウガラシの抽出液 | 細かく刻んで一日浸し、濾します | ガの幼虫、アブラムシ | 人の目にも刺激があります |
| ボルドー液 | 硫酸銅と生石灰を水に溶きます | カビによる病気の予防 | 材料がある場合のみ可能です |

### 9-4. 薬を使わない防除の五原則

| 原則 | 内容 | トウモロコシでの適用 |
|---|---|---|
| 草取り | 雑草を初期に取り除きます | 損失の40ポイントが雑草によるものです |
| 残渣処理 | 収穫後に茎を片付けます | アワノメイガの越冬場所をなくします |
| 排水 | 水がたまらないようにします | 根腐病と茎腐病の発生条件をなくします |
| 輪作 | マメ科と交互に植えます | 地力の回復と病害の密度低下を同時に得られます |
| 混作 | 別の作物を混ぜて植えます | パプリカとの混作でウイルス病が72%減りました |

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然素材での対処 |
|---|---|---|
| 下葉の中央の葉脈に沿ってV字形に黄色くなります | 窒素欠乏。トウモロコシの典型的な症状です | 尿の10倍希釈液、完熟堆肥 |
| 葉が濃い紫色を帯びます | リン酸欠乏または低温 | 骨粉、草木灰。低温が原因なら、気温が上がれば回復します |
| 葉の縁が焼けたように枯れます | カリウム欠乏 | 草木灰を株間にまきます |
| 新しい葉に白い縞模様が出ます | 亜鉛欠乏。リン酸過多でよく見られます | 堆肥の材料を多様にします |
| 葉脈の間だけが黄色くなります | マグネシウム欠乏 | ドロマイト粉末、堆肥の多様化 |
| 穂の先に粒がありません | 絹糸抽出期の養分・水分不足 | 追肥の時期を早め、灌水を増やします |
| 草丈ばかり高く、葉が黒みがかった緑色で、穂が小さくなります | 窒素過剰 | トウモロコシでは珍しいものの、極端な場合には現れます |

&nbsp;&nbsp;&nbsp;トウモロコシの窒素欠乏症状は特徴的で、見分けやすいものです。下のほうの葉の先端から始まり、葉脈に沿って内側へV字形に黄色く広がります。トウモロコシが不足した窒素を下葉から引き出して、上の新しい葉へ送るためです。この症状が見えたら直ちに薄めた尿や完熟堆肥を追肥として入れる必要があり、絹糸抽出期の前であればまだ回復が可能です。

## 11. 間作と輪作

### 11-1. 三姉妹農法 - トウモロコシの災害時栽培の要

&nbsp;&nbsp;&nbsp;トウモロコシの地力消耗の問題を解く、伝統的な答えがあります。北米の先住民が数百年にわたって用いてきた方式で、トウモロコシとマメとカボチャを同じ場所に一緒に植えます。

| 作物 | 役割 | 具体的な作用 |
|---|---|---|
| トウモロコシ | 支柱 | 背が高く、つる性のマメが登っていく柱になります |
| マメ | 窒素供給 | 根粒菌が空気中の窒素を固定して土に入れます |
| カボチャ | 地面の被覆 | 広い葉が地面を覆って雑草を抑え、水分の蒸発を防ぎます |

&nbsp;&nbsp;&nbsp;この組み合わせが災害時に持つ価値は三つあります。第一に、一つの土地で炭水化物（トウモロコシ）とタンパク質（マメ）とビタミン（カボチャ）を同時に得られます。第二に、トウモロコシが奪った窒素をマメが戻してくれるので、地力の消耗が和らぎます。第三に、カボチャが地面を覆うため、草取りの労力が大きく減ります。トウモロコシの損失の最大要因が雑草であることを考えれば、この効果だけでも価値があります。

&nbsp;&nbsp;&nbsp;さらに重要なのは、栄養の相互補完性です。トウモロコシはリジンとトリプトファンが不足しており、マメはその二つが豊富です。トウモロコシだけを食べているとペラグラになりますが、マメと一緒に食べればなりません。中南米の人々がトウモロコシとマメを一緒に食べてきたのは偶然ではなく、数千年の経験が生んだ知恵です。

| 植え方 | 内容 |
|---|---|
| 順序 | トウモロコシを先に植え、膝の高さになったらマメを、その次にカボチャを植えます |
| 間隔 | トウモロコシの株間にマメを一、二粒、畝の縁にカボチャをまばらに |
| マメの品種 | つる性のマメが適しています。トウモロコシを伝って登っていきます |
| 注意 | マメを早く植えすぎると、トウモロコシに巻き付いて倒してしまいます |

### 11-2. 相性

| 相性 | 対象 | 効果 |
|:---:|---|---|
| 非常に良い | マメ、アズキ、ササゲ | 窒素を固定して分けてくれ、栄養を補ってくれます |
| 非常に良い | カボチャ | 地面を覆って雑草と蒸発を減らします |
| 良い | トウガラシ、パプリカ | トウモロコシの日陰がウイルス病を72%減らしました |
| 良い | ジャガイモ（前作） | 生育時期がずれます |
| 悪い | モロコシ、アワ | 同じイネ科なので病害虫を共有し、養分の競合が大きいです |
| 悪い | トウモロコシの連作 | 地力が枯渇し、アワノメイガが蓄積します |

### 11-3. 輪作の順序

| 年 | 作物 | 目的 |
|---|---|---|
| 1年目 | トウモロコシ（マメとの混作） | 最大の熱量を確保します |
| 2年目 | マメ科の単作（ダイズ、アズキ、ササゲ） | 地力を回復させます |
| 3年目 | 葉菜類または根菜類 | 残った養分を使います |
| 4年目 | 穀物（モロコシ、アワ、エンバク） | トウモロコシに戻る前の緩衝です |
| 5年目 | トウモロコシに復帰 | 地力と病害の密度が回復しています |

> **トウモロコシの連作は、2年目までは目立たず、3年目に崩れます。マメ科との輪作は選択ではなく前提です。**

&nbsp;&nbsp;&nbsp;評価表の連作適応性Aは、病害虫の面での値です。地力の面では、トウモロコシは連作に最も向かない作物の一つです。アメリカ中西部の黒土のように、もともと有機物が厚く蓄積した土地では連作が可能ですが、韓国の畑の土にはそのような余裕がありません。化学肥料がない条件であれば、なおさらです。

&nbsp;&nbsp;&nbsp;土地が狭くて4年輪作が難しい場合でも、せめてトウモロコシとマメを毎年交互に植える2年輪作は守らなければなりません。これに三姉妹農法でマメを一緒に植えることを加えれば、トウモロコシを植える年にも、窒素がある程度補われます。この二つを組み合わせることが、肥料の乏しい条件でトウモロコシを作り続ける現実的な方法です。
