## 引言
&nbsp;&nbsp;&nbsp;玉米（Zea mays）是人类用数千年时间把墨西哥的野生草类大刍草改良而成的作物。种子被苞叶包裹，无法自行散落，所以必须由人来种植才能存在。在灾害条件下，它最大的优势是单位面积热量。每1,000㎡可收获600kg（每㎡2,148kcal），是自给线的0.82倍，在谷物中最高。代价是需肥量大、消耗地力、F1种子问题以及糙皮病风险。本文档的重点是如何满足这些条件。

| 优势（A） | 单位面积热量（热量回收倍数16.8）、病虫害压力（无防治减产率28.2%）、连作适应性、自留种 |

&nbsp;&nbsp;&nbsp;只要满足条件，它在任何阶段都能发挥作用，但这些条件比其他谷物苛刻得多。连作适应性的A只是病虫害方面的数值，就地力而言，玉米是最不适合连作的作物之一。各项目的完整等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
&nbsp;&nbsp;&nbsp;玉米是禾本科玉蜀黍属的一年生草本，原产于中南美洲的热带高原。它进行C4光合作用，所以光照直接决定产量，并且怕霜、怕淹、怕阴。茎高1.5-3m，由基部的支持根撑住株身。雄花长在茎顶，雌花长在叶腋，雌花的花丝每一根连着一粒籽粒。花丝没有接到花粉的位置会成为空粒。

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 发芽·幼苗期 | 播种后3周 | 磷、氮很重要 |
| 营养生长期 | 3-6周 | 茎和叶急剧增长 |
| 吐丝·开花期 | 6-8周 | 授粉时期。干旱、35℃以上高温、养分不足都会导致秃顶空穗 |
| 灌浆期 | 8-12周 | 籽粒里灌满淀粉 |
| 成熟期 | 12周以后 | 籽粒变硬，基部形成黑层 |

> **吐丝期前后的2周决定全部收成。如果只有一次浇水的机会，就要用在这时。**

| 每100g营养 | 含量 |
|:---|:---|
| 热量 | 358kcal（干籽粒）。蒸熟的鲜嫩玉米为132kcal |
| 碳水化合物 / 脂肪 | 约70g / 约4g（脂肪集中在胚芽） |
| 蛋白质 | 9.94g（P:E 11.1%） |
| 丰富的 | 膳食纤维、钾、磷 |
| 缺乏的 | 赖氨酸、色氨酸、可吸收的烟酸 |

## 3. 栽培环境与品种
| 条件 | 最适 | 极限与影响 |
|:---|:---|:---|
| 生长温度 | 20-30℃ | 12℃以下停止生长，遇霜枯死 |
| 发芽 | 32-34℃ | 地温13℃时出苗需18-20天，15-18℃时8-10天 |
| 吐丝期 | 25-28℃ | 超过35℃花粉死亡，穗子空瘪 |
| 光量 | 每天8-10小时直射光 | 至少需6小时。遮光40%时产量为45% |
| 水 | 合计550mm | 400-700mm。吐丝期干旱最致命 |
| 土壤 | 排水良好的沙壤土-壤土，pH 6.0-6.8 | pH低于5.5时磷被固定 |
| 淹水 | 不能有 | 最多3天。4天以上产量崩溃 |

&nbsp;&nbsp;&nbsp;把最肥沃、日照最好的平地，以及靠近堆肥堆或牲畜棚的地块分给玉米，把贫瘠的边角地让给高粱或谷子。避开有阴影的位置和积水的低洼地。

| 品种 | 熟期 | 用途与灾害视角 |
|:---|:---:|:---|
| 糯玉米 | 80-90天 | 鲜食用。夏季一季的食物 |
| 超甜玉米 | 70-80天 | 可生食，难储存 |
| 高糖玉（Godangok） | 约80天 | 可一年两熟 |
| 籽粒用·饲料用 | 90-100天 | 晒干储存、磨粉。只有这类品种能用于长期储备 |
| 爆裂玉米 | - | 爆开吃，几乎不耗燃料 |

&nbsp;&nbsp;&nbsp;市售种子大部分是F1杂交种，用收下来的种子再种，会因杂种后代衰退使收成降到一半以下。如果预计灾害会持续很久，就要储备地方品种或常规固定品种。糯玉米要与其他品种相隔200m以上，或把播种期错开3周以上。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 深耕18cm以上（可能的话25-30cm），在地块四周和沟里挖排水沟，垄高15-20cm |
| 酸度 | pH 6.0-6.8。酸性土用草木灰调节 |
| 氮 N | 每1,000㎡ 10-15kg。基肥50%，5-7叶期追肥50% |
| 磷 P / 钾 K | 各8-10kg。磷全部作基肥，钾分次施用 |
| 堆肥 | 1,000-1,500kg。腐熟堆肥全部作基肥 |

| 替代肥料 | 方法 |
|:---|:---|
| 豆科绿肥 | 前茬翻压毛叶苕子、紫云英，可提供氮8-12kg。效果最大 |
| 混种豆类 | 在玉米之间一起种豆 |
| 尿液 | 兑水稀释10倍，在5-7叶期顺沟浇灌。追肥的主力 |
| 草木灰 | 撒施40-60kg。提供钾和磷，并调节酸度 |
| 腐熟堆肥 | 把落叶、草、粪便沤3-6个月。头年秋天就开始堆 |
| 人粪堆肥 | 与锯末、稻壳混合，沤6个月以上至完全腐熟。腐熟不透会留下病原菌 |

&nbsp;&nbsp;&nbsp;氮10-15kg相当于腐熟堆肥2-3吨，所以没有施肥计划就种玉米，只是装模作样地种。

| 播种 | 标准 |
|:---|:---|
| 时期 | 南部4月上旬，中部4月中旬。以地温12℃以上为准。后茬在7月上旬，极限是6月下旬。分批，每隔1-2周种一批 |
| 种子挑选 | 穗中部粗大整齐的籽粒。剔除水里浮起来的 |
| 种子消毒 | 拌草木灰（兼防鸟和蚂蚁）、50-55℃热水10分钟、木醋液稀释500倍浸6-12小时 |
| 种植 | 深3-5cm，行距70cm，株距25cm，每穴2粒 |
| 排布 | 至少四行以上合成方块。单行种植的话花粉会飞出地外 |
| 间苗 | 苗高15cm时只留1株。不要拔，从基部剪断 |

## 5. 水与栽培管理、病虫害
| 管理 | 内容 |
|:---|:---|
| 水 | 发芽期不要让土壤变干，营养生长期和灌浆期充分供水，**吐丝·开花期务必充足**，成熟期停水，雨季以排水为管理 |
| 第1次除草 | 出苗后2周 |
| 第2次除草 | 5-7叶期。同时培土（基部培土20cm）和追肥 |
| 人工授粉 | 结实不好时，等露水干后摇晃雄花，让花粉落下。连续几天多做几次 |
| 其他 | 不去除分蘖和下部叶片。倒伏的扶起并培土。成熟时给穗子套纸袋防鸟 |

&nbsp;&nbsp;&nbsp;玉米无防治潜在损失68.5%中，有40.3个百分点来自杂草。杂草靠手而不是农药解决，把除草集中在播种后30-45天。

| 病虫害 | 症状与时期 | 不用药的应对 |
|:---|:---|:---|
| 穗腐病 | 灌浆期遇雨。有霉菌毒素风险 | 提前收获，剥开苞叶晾干，病穗丢弃 |
| 黑粉病 | 穗和茎上长白色瘤，破裂成黑粉 | 在破裂前剪下焚烧，轮作 |
| 茎腐病·根腐病 | 污染水、过湿 | 改善排水，沟灌 |
| 叶斑病·纹枯病 | 高温高湿、密植 | 保证通风，病叶焚烧 |
| 亚洲玉米螟 | 一年3代（5月底-10月初）。幼虫钻入茎内 | 收获后焚烧茎秆，或切碎埋入土中最有效。清除卵块，保护寄生蜂 |
| 蚜虫 | 吸食汁液并引发煤污病 | 喷肥皂水（每1L水加纯肥皂5-10g） |
| 鸟、鼠 | 灌浆期、储存期 | 纸袋、网、金属容器 |

| 缺素症状 | 原因与处理 |
|:---|:---|
| 下部叶片中部沿叶脉呈V字形变黄 | 缺氮。稀释尿液、腐熟堆肥 |
| 叶片深紫色 | 缺磷或低温。骨粉、草木灰 |
| 叶缘焦枯 | 缺钾。在株间撒草木灰 |
| 穗尖没有籽粒 | 吐丝期养分、水分不足。提前追肥并灌水 |

## 6. 间作与轮作
| 作物 | 作用 |
|:---|:---|
| 玉米 | 支架。藤蔓豆攀着它向上爬 |
| 豆类 | 根瘤菌固定空气中的氮 |
| 南瓜 | 宽大的叶片覆盖地面，抑制杂草和蒸发 |

&nbsp;&nbsp;&nbsp;这是北美原住民的“三姐妹”种植法。先种玉米，长到齐膝高时种豆，然后种南瓜。豆子种得太早，会缠着玉米把它拉倒。豆类补足玉米缺少的赖氨酸和色氨酸，所以营养也互相补充。与辣椒、甜椒一起种，病毒病减少了72%。高粱和谷子同属禾本科，共有病虫害，要避免。

| 轮作 | 作物 |
|:---|:---|
| 第1年 | 玉米（混种豆类） |
| 第2年 | 单种豆科（大豆、红小豆、豇豆） |
| 第3年 | 叶菜或根菜 |
| 第4年 | 谷类（高粱、谷子、燕麦） |
| 第5年 | 回到玉米 |

> **玉米连作到第三年会崩溃。即使土地狭小，也至少要每年让玉米与豆类轮流种植。**

## 7. 收获、干燥、留种
| 类型 | 时期与判断 |
|:---|:---|
| 鲜食玉米 | 吐丝后22-25天。按压籽粒会出白浆，呈奶酪状。清晨采收。适期只有几天，所以要分批播种 |
| 干籽粒 | 吐丝后50-60天。基部形成黑层，指甲掐不进去 |

&nbsp;&nbsp;&nbsp;把穗子向下折弯扭下来，苞叶只留两三片，相互编在一起挂在屋檐下。看到发霉的穗子单独挑出来丢弃，收获后田里的茎秆要烧掉，或切碎后埋掉。

| 干燥 | 方法 |
|:---|:---|
| 目标 | 水分从25-35%降到13-14%。超过15%霉菌会生长 |
| 顺序 | 悬挂晾干3-6周 → 带穗日晒3-5天 → 脱粒 → 籽粒日晒2-4天 → 阴凉处放一天使其均匀 |
| 判断 | 一拧籽粒就哗哗掉下，指甲掐不出印，咬一下干脆裂开 |
| 加热干燥 | 50℃以下。超过的话种子会死亡，味道也变差 |

&nbsp;&nbsp;&nbsp;脱粒最实用的办法是用拇指抠下第一行，腾出空槽，再把其余的往旁边推。也可以把两个干穗对着搓，装进麻袋里踩，或在钉了瓶盖、钉子的板上磨擦。穗轴是火力很强的柴火，灰是钾肥。碎屑用簸箕扬或用筛子分开，发霉的和被虫蛀的籽粒用手拣掉。

| 留种 | 标准 |
|:---|:---|
| F1 | 无法自留种。只有常规固定品种、地方品种可以 |
| 隔离 | 与其他品种相隔200m以上，或把播种期错开3周以上，或在花丝抽出前给穗子套纸袋，再撒入同品种的花粉 |
| 选择 | 从20-30株无病、未倒伏的植株上均匀选取。只用穗中部的籽粒 |
| 保存 | 水分12-13%，密封后放在阴凉黑暗处。常温下2-3年 |
| 发芽试验 | 用湿布包20粒，放5-7天。18粒以上正常，14-17粒则每穴3粒，12粒以下则更换 |

## 8. 储存
&nbsp;&nbsp;&nbsp;耐储性为SS，但仅限完全干燥的籽粒。鲜食玉米在常温下最多放三天。储存的敌人是霉菌（水分15%以上，黄曲霉毒素）、虫（20℃以上，水分12%以上）和老鼠。

| 项目 | 标准 |
|:---|:---|
| 条件 | 水分13-14%（种子12-13%），温度15℃以下，周围湿度65%以下，避光，每两个月检查一次 |
| 带穗储存 | 通风好，霉菌较少，但体积是三倍以上，老鼠容易接近。用于开春前吃的部分 |
| 籽粒储存 | 体积小，容易密封。确认完全干燥时。用于撑到来年的部分 |
| 容器 | 金属罐、玻璃瓶3年以上 / 陶罐2-3年 / 厚塑料袋1年 / 麻袋6个月 |

| 虫害防治 | 方法 |
|:---|:---|
| 完全密封 | 容器装满，摇晃使其沉实后再装满。氧气耗尽，虫子死亡 |
| 草木灰 | 把细灰拌入谷物体积的2-5%。吃之前洗掉 |
| 硅藻土 | 每1kg谷物1-3g。只在干燥时起作用 |
| 辅助 | 干辣椒、木炭、炒盐、艾草叶 |
| 高温、低温 | 在60℃的阳光下薄摊几小时（种子除外），隆冬时拿到外面放几天 |

&nbsp;&nbsp;&nbsp;每两个月检查容器表面的凝露和霉味、籽粒上的小孔和底部的粉末（象甲）、表面蛛网状的丝（印度谷螟）、握在手里的温热感（水分过多）以及老鼠的痕迹。

## 9. 烹调与注意事项
> **以玉米为主食，却没有豆类，也不做碱处理，几个月后就会患糙皮病（烟酸缺乏症）。**

&nbsp;&nbsp;&nbsp;玉米中的烟酸是无法吸收的结合形态，色氨酸也不足。症状是暴露于阳光的皮肤发炎、腹泻、精神异常，甚至会致死。与豆类一起吃，或做碱处理，就能预防。

| 顺序 | 碱处理（尼克斯塔玛化） |
|:---:|:---|
| 1 | 干籽粒1份配水3份，加入籽粒体积5%的草木灰（生石灰为1%） |
| 2 | 煮开后转小火煮30-50分钟 |
| 3 | 关火，放置一夜 |
| 4 | 倒掉水，用手搓去外皮 |
| 5 | 冲洗三四遍，直到水变清 |
| 6 | 直接烹调、磨粉或晒干 |

&nbsp;&nbsp;&nbsp;这种处理使烟酸变得可吸收，去掉外皮，并使籽粒变软，磨粉更容易。干玉米非常坚硬，直接磨很费力，所以先做碱处理或炒制，面粉每次只磨一个月吃的量。干籽粒一定要泡发后煮熟。

> **发霉的玉米，洗了、煮了、炒了也不会变安全。不要给人，也不要给牲畜吃，必须丢弃。**

| 烹调 | 燃料与要领 |
|:---|:---|
| 面糊粥 | 把面粉调入水中煮10分钟。最省燃料 |
| 鲜食玉米 | 加少量水蒸20分钟 |
| 余热烹调 | 煮10分钟后用稻草或被子裹住闷一小时 |
| 爆裂玉米 | 放进烧热的锅里，盖上盖子摇几分钟 |
| 干籽粒直接煮 | 泡一夜，煮一小时以上。最费燃料 |

&nbsp;&nbsp;&nbsp;兼顾储存的加工有：碱处理后晒干（密封1年）、炒面（3-6个月）、淀粉（数年，不生虫）、干鲜食玉米（1年）、玉米糖浆。苞叶可替代绳子，花丝晒干后泡茶。

## 10. 全年作业计划
| 月 | 作业 |
|:---|:---|
| 1-2月 | 检查储存、确认种子、制定堆肥计划并翻堆、发芽试验 |
| 3月 | 深耕、排水沟、基肥、撒草木灰 |
| 4月 | 播种（地温12℃以上，每隔1-2周） |
| 5月 | 间苗、第1次除草、监测玉米螟第一代 |
| 6月 | 追肥、第2次除草、培土、播豆 |
| 7月 | 吐丝期集中灌水、人工授粉 |
| 8月 | 收获鲜食玉米、驱鸟 |
| 9-10月 | 收获干籽粒（确认黑层）、剥开苞叶悬挂晾干、处理茎秆残茬 |
| 11-12月 | 脱粒、最后干燥、储存、种子单独保管、碱处理与磨粉 |

> **不能忘记的五件事：施肥计划、禁止连作、多行成块种植、储备固定品种、碱处理。**
