## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;トウモロコシの貯蔵性はSSです。FAOの食料ロス指数で貯蔵段階の観測1,577件を見ると、損失率の中央値は3.00%で、乾燥させた子実は常温で3年を超えて保存できます。ただし、この等級は完全に乾いた子実に限った話です。若採りトウモロコシは常温で3日、冷蔵があっても1-2週間が限界です。同じ作物で貯蔵期間が千倍も違うことになり、その差を生むのが乾燥です。

### 15-1. 貯蔵の三つの敵

| 敵 | 条件 | 結果 | 対策の軸 |
|---|---|---|---|
| カビ | 水分15%以上 | アフラトキシンが発生、全量廃棄 | 乾燥 |
| 虫 | 温度20℃以上、水分12%以上 | 粒の中身を食い荒らし、粉だけが残ります | 密閉と低温、防除 |
| ネズミ | 近づける容器 | 粒が大きいため特によく食べられます | 物理的な遮断 |

&nbsp;&nbsp;&nbsp;トウモロコシは粒が大きく、ネズミが特に好みます。袋やビニールは簡単に食い破られ、一度穴が開くと、その穴から湿気と虫がいっしょに入り込みます。トウモロコシの貯蔵で金属缶や壺の価値がほかの穀物より大きいのは、このためです。

### 15-2. 貯蔵条件

| 条件 | 目標 | 外れた場合 |
|---|---|---|
| 水分 | 13-14%、種子は12-13% | 15%を超えるとアフラトキシンのリスクが急激に高まります |
| 温度 | 15℃以下が理想、できるだけ低く | 25℃を超えると虫の繁殖が速くなります |
| 湿度 | 周囲の空気が65%以下 | 乾いた子実が再び水分を吸い込みます |
| 光 | 完全に遮る | 温度が上がり、品質が落ちます |
| 形態 | 穂ごと、または子実 | 穂ごとだと通気が良く、子実だと省スペースです |
| 点検 | 2か月に1回 | 早期に発見すれば損失を防げます |

### 15-3. 穂ごとの貯蔵と子実の貯蔵

| 方式 | 長所 | 短所 | 向いている状況 |
|---|---|---|---|
| 穂ごとの貯蔵 | 通気が良く、カビが生えにくくなります。粒が傷みにくくなります | 容積が3倍以上になります。ネズミが近づきやすくなります | 場所に余裕があり、乾燥が不完全なとき |
| 子実の貯蔵 | 容積が小さく、密閉しやすくなります | 完全に乾いていないと、カビが急速に広がります | 完全に乾燥したことを確認したとき |

&nbsp;&nbsp;&nbsp;伝統的な方法は、穂ごと吊るしておくものでした。軒下や納屋に編んで掛けておくと冬のあいだずっと乾き続け、必要なときに数本ずつ外して粒をこき落として使います。乾燥が完全でなくても安全だという点が最大の利点です。短所は容積とネズミです。

&nbsp;&nbsp;&nbsp;最も安全な折衷案は、両者を分けることです。春までに食べる分は穂ごと吊るしておき、夏を越えて翌年まで持たせる分は十分に乾かしてから粒をこき落とし、密閉容器に入れます。こうすると、すぐに使う分は乾燥を続けながら消費され、長期の備蓄分は完全な密閉で守られます。

### 15-4. 貯蔵容器

| 容器 | 密閉 | 防鼠 | 期間 | 備考 |
|---|:---:|:---:|---|---|
| 金属缶 | 非常に良い | 完全 | 3年以上 | トウモロコシに最も適しています |
| 壺（オンギ、韓国の伝統的な陶器） | 良い | 完全 | 2-3年 | 温度が一定で、ネズミがかじり抜けません |
| ガラス瓶 | 非常に良い | 完全 | 3年以上 | 暗い場所に置く必要があります |
| 厚手のビニール | 普通 | 悪い | 1年 | ネズミに簡単に食い破られます |
| 叺（かます）・麻袋 | 悪い | 悪い | 6か月 | ネズミと虫に対して無防備です |
| 吊るしておく | なし | 普通 | 6か月-1年 | 通気が良く、カビは生えにくくなります |
| 地中の貯蔵穴 | 良い | 良い | 2-3年 | 温度が一定です。水が染み込むと全量を失います |
| トウモロコシ倉庫（コーンクリブ） | なし | 普通 | 1年 | 板をまばらに組んで通気させる伝統的な構造物です |

&nbsp;&nbsp;&nbsp;トウモロコシ倉庫は、アメリカや中南米で古くから使われてきた構造物です。壁をまばらな木の桟で組んで風が通るようにし、床を地面から浮かせ、ネズミが登れないよう柱に皿状のネズミ返しを取り付けます。穂ごと積み込めば、冬のあいだ乾き続けながら保管されます。災害時に大量のトウモロコシを扱うなら作ってみる価値のある設備で、板と柱さえあれば一日か二日で建てられます。

### 15-5. 貯蔵中の虫の防除 - 薬を使わずに

&nbsp;&nbsp;&nbsp;穀物貯蔵における実質的な最大の敵は虫です。ココクゾウムシ、ノシメマダラメイガ、コクヌストモドキの仲間などが、収穫直後の子実にすでに卵の状態で入り込んでおり、貯蔵庫の中で孵化します。ココクゾウムシは卵を粒の中に産むため、外見は何ともなかった粒がある日穴が開き、虫が出てきます。1匹が2か月で数十匹に増え、半年もすれば容器ひとつが粉と殻で満たされます。

| 方法 | 原理 | 適用 | 効果 |
|---|---|---|---|
| 完全密閉 | 酸素を断って虫を窒息させます | 容器いっぱいに詰めて封をします | 最も確実です。空きが少ないほど効果的です |
| 草木灰を混ぜる | 灰の微細な粒子が虫の外骨格を削り、脱水させます | 穀物の容積の2-5%を均一に混ぜます | 古くから実績のある方法です。食べる前に洗い流します |
| 珪藻土 | 微細なケイ酸質の殻が外骨格を傷つけます | 穀物1kgに1-3gを混ぜます | 灰より効果が高くなります。乾いた状態でしか働きません |
| 細かい砂・黄土 | 粒が隙間を埋めて虫の移動を妨げます | 層状に重ねて入れます | トウモロコシは粒が大きく隙間が多いため、効果が大きくなります |
| 乾燥トウガラシ | カプサイシンが忌避剤として働きます | 容器の中に何本か入れます | トウモロコシの貯蔵に伝統的に使われてきました |
| ヨモギ・ショウブ・エンジュの葉 | 精油成分が産卵を抑えます | 乾燥させて層状に重ねて入れます | 補助的な手段です |
| 炒った塩 | 湿気を吸着して虫の生存条件をなくします | 布に包んで入れます | 乾燥剤を兼ねます |
| 炭 | 湿気とにおいを吸い取ります | 焼いて乾かした炭を布に包んで入れます | カビの予防にも役立ちます |
| 低温処理 | 氷点下で卵と幼虫が死にます | 真冬に数日間外に出してから取り込みます | 取り込むときは結露に注意します |
| 高温処理 | 60度で卵と幼虫が死にます | 日なたに薄く広げて数時間置きます | 種子用には使いません |

&nbsp;&nbsp;&nbsp;最も重要なのは1つ目の方法です。完全密閉は、薬がなくても使える最も強力な手段です。虫も呼吸をしているため、密閉した容器の中で穀物と虫が酸素を消費すると、二酸化炭素がたまって酸素が減り、虫が死にます。容器をいっぱいに満たして空きを最小限にするほど、効果は早く現れます。トウモロコシは粒が大きく、粒のあいだに空気が多く残るので、ほかの穀物よりしっかり詰め込む必要があります。いっぱいに入れたら揺すって沈め、また足すという作業を2、3回繰り返します。

&nbsp;&nbsp;&nbsp;草木灰と珪藻土は原理が同じです。どちらも化学的ではなく物理的に虫を殺します。微細で鋭い粒子が虫の体を覆うワックス層を削り取ると、虫は水分を失って干からびます。この方式には二つの利点があります。虫が耐性を獲得できないことと、人体に無害なことです。食べる前に水で洗えば済みます。短所は、湿気があると働かないことです。穀物がしけると灰も珪藻土も効果がなくなるため、結局は乾燥が先決です。

&nbsp;&nbsp;&nbsp;灰を使うときは、ふるいにかけて小麦粉のように細かい部分だけを選んで使います。穀物の容積の2から5%、つまりトウモロコシ1斗に灰1升ほどを混ぜ、手でかき混ぜて、すべての粒の表面に薄くまぶします。トウモロコシは粒が大きく表面積が相対的に小さいので、灰が少量で済み、あとで洗い流すのも簡単です。しかもトウモロコシの場合、この灰はほかの用途にも使われます。調理のときのアルカリ処理に使う灰と同じ灰だからです。

&nbsp;&nbsp;&nbsp;乾燥トウガラシも、トウモロコシの貯蔵に伝統的に広く使われてきました。子実のあいだにトウガラシを何本か差し込んでおくと、虫が近づくのを嫌がります。単独では効果が限られますが、密閉や灰と併用すれば補助手段として役立ちます。

### 15-6. 定期点検

| 時期 | 確認事項 | 異常時の対処 |
|---|---|---|
| 2か月ごと | 容器の外側の結露、カビのにおい | すぐに開けて広げ、乾かします |
| 2か月ごと | 粒に開いた小さな穴、底にたまった粉 | ゾウムシ類です。全量を日に干して、ふるって取り除きます |
| 2か月ごと | 表面のクモの巣のような糸 | ノシメマダラメイガです |
| 2か月ごと | 手でつかんだときの温かさ | 発熱は水分過多のサインです |
| 2か月ごと | 容器の周りのネズミの痕跡 | 糞やかじった跡がないか確認します |
| 春と秋 | 丸ごと開けてにおいと色を確認 | 異臭がしたら小分けにして調べます |

## 16. 調理と加工

### 16-1. アルカリ処理（ニシュタマリゼーション） - トウモロコシ調理の要

&nbsp;&nbsp;&nbsp;トウモロコシを主食にするなら、この節が文書全体で最も重要です。乾燥したトウモロコシを、灰や石灰を溶かした水で煮る処理で、三つの問題を同時に解決します。

| 効果 | 内容 |
|---|---|
| ナイアシンの遊離 | 結合型ナイアシンが吸収可能な形に変わり、ペラグラを防ぎます |
| 皮の除去 | 粒の外皮が柔らかくなり、こすると剥がれます |
| 製粉が容易に | 粒が柔らかくなり、石臼や臼でずっと簡単に挽けます |

| 手順 | 内容 | 備考 |
|---|---|---|
| 1 | 乾燥したトウモロコシの粒1升に対して水3升を用意します | たっぷり浸かるようにします |
| 2 | 草木灰をトウモロコシの容積の5%ほど入れます | 石灰（生石灰）があれば1%で足ります |
| 3 | 沸騰させたあと火を弱め、30-50分しっかり煮ます | 粒がふくらみ、皮が浮いてきます |
| 4 | 火を止め、そのまま一晩置きます | この時間がアルカリ作用の要です |
| 5 | 水を捨て、手でこすって皮をむきます | 黄色い皮がはがれ落ちます |
| 6 | 澄んだ水が出るまで3、4回すすぎます | 灰とアルカリを完全に洗い流します |
| 7 | この状態で調理するか、搗いて粉にして使います | 乾燥させておけば長く保存できます |

> **灰を入れて煮る、この一手間がトウモロコシを安全な主食に変えます。中南米の人々が数千年にわたってトウモロコシばかり食べても健康でいられた理由です。**

&nbsp;&nbsp;&nbsp;使えるアルカリ源はいくつかあります。広葉樹を燃やした草木灰が最も手に入りやすく、貝殻や骨を焼いて作った石灰も使えます。消石灰や生石灰があれば最も少ない量で効果が出ますが、量を誤ると苦味が出るので注意が必要です。灰を使うときは、目で灰が見えるくらいたっぷり入れ、煮汁がぬるぬるした感触になればアルカリが十分に効いています。

&nbsp;&nbsp;&nbsp;処理したトウモロコシは、そのまま粥やご飯にして食べられますし、搗いてこねれば、伝統的なトウモロコシの薄焼きの生地になります。乾燥させておけば長く保存でき、必要なときに水で戻して搗けば済みます。燃料がかかるのが唯一の負担ですが、一度に大量に処理して乾燥させておけば燃料を節約できます。

### 16-2. 製粉 - 粉にする

| 方法 | 道具 | 特徴 |
|---|---|---|
| 石臼 | 上下2枚の石 | 最も細かい粉が挽けます |
| 臼 | 臼と杵 | トウモロコシは粒が硬いため、かなりの重労働です |
| 石板で挽く | 平らな石と棒状の石 | 中南米のメタテと同じ原理です |
| アルカリ処理後に搗く | どれでも可 | 粒が柔らかくなり、ずっと楽になります |
| 炒ってから搗く | どれでも可 | 組織がもろくなって労力が減り、香ばしく仕上がります |
| 水に浸して挽く | 石臼 | 水といっしょに挽けば、生地がそのまま得られます |

&nbsp;&nbsp;&nbsp;乾燥したトウモロコシは穀物のなかでも最も硬い部類なので、そのまま搗くのは非常に大変です。臼で搗こうとすると粒が跳ね飛び、腕のほうが先に疲れてしまいます。そのため、トウモロコシの製粉には必ず前処理が必要です。アルカリ処理をすると粒が柔らかくなり、力が半分以下で済みます。炒ると組織がもろくなり、ずっと簡単に挽けます。水に一晩浸してから、石臼で水といっしょに挽く方法も有効です。乾いた粉の代わりに生地がそのまま得られますが、その場で食べるのであれば問題ありません。

&nbsp;&nbsp;&nbsp;石臼がなければ、自作することもできます。硬い石を2つ選び、向かい合う面を叩いてざらざらにし、上の石の中央に穴を開けて穀物が入るようにし、取っ手を取り付ければ完成です。精巧でなくても動作します。災害が長引きそうなら、作っておく価値の大きい道具です。

&nbsp;&nbsp;&nbsp;粉は子実よりずっと早く傷みます。トウモロコシの粉は、胚芽から出た脂肪が混ざるので、とくにその傾向が強くなります。1か月で食べ切れる分だけ搗き、残りは子実のままにしておきます。

### 16-3. 燃料を節約する調理

| 方法 | 燃料 | 手順 | 備考 |
|---|:---:|---|---|
| 若採りトウモロコシをゆでる | 少ない | 水を少なめに入れて20分蒸します | ゆでるより蒸すほうが燃料が少なくて済みます |
| 乾燥した子実をゆでる | 多い | 一晩水に浸してから1時間以上煮ます | 燃料が最も多くかかります |
| アルカリ処理後の調理 | 中程度 | 処理の過程ですでに火が通ります | 一度にまとめて処理すると効率的です |
| 粉粥 | 非常に少ない | 粉を水に溶いて10分煮ます | 最も効率が良い方法です |
| 薄焼き | 少ない | 生地を薄く焼きます | 厚いと中まで火が通りません |
| 余熱調理 | 非常に少ない | 10分煮たあと火を止め、藁や毛布で包んで1時間置きます | 燃料を半分以下に減らせます |
| ティバプ（穀物をはぜさせた菓子）・ポップコーン | 非常に少ない | 熱した鍋に入れ、蓋をして振ります | 数分でできます |
| 灰の中で焼く | 非常に少ない | 生地のかたまりを熱い灰に埋めます | ほかの調理の余熱を利用します |

&nbsp;&nbsp;&nbsp;乾燥したトウモロコシの子実をそのままゆでるのは、燃料の面では最も悪い選択です。1時間以上煮る必要があり、それでも完全には柔らかくなりません。アルカリ処理をするか、粉に搗いて使うほうが、燃料をはるかに節約できます。とくに粉粥は10分でできるため、燃料が極端に不足している状況でトウモロコシを食べるうえでの最善の形です。

&nbsp;&nbsp;&nbsp;ポップコーンは意外にも理にかなった調理法です。爆裂種（ポップコーン用のトウモロコシ品種）を植えてあれば、熱した鍋に入れて蓋をし、振るだけで、数分で容積が数十倍にふくらんだ食べ物になります。燃料はほとんど要らず、精白も製粉も必要なく、すぐに食べられます。トウモロコシのなかで最も調理効率のよい形です。ただし、爆裂種は別に植える必要があります。

&nbsp;&nbsp;&nbsp;保温調理は、乾燥したトウモロコシでとくに価値が大きくなります。水に浸した子実を10分だけ煮て火から下ろし、藁やもみ殻を詰めた箱、あるいは厚い布団に鍋ごと包んでおくと、内部の温度が1時間以上80℃を上回ったままとなり、調理が続きます。1時間煮なければならないものが、10分に短縮されます。

### 16-4. 貯蔵を兼ねた加工

| 加工 | 手順 | 保管 | 備考 |
|---|---|---|---|
| アルカリ処理後に乾燥 | 処理したトウモロコシを乾燥させます | 密閉で1年 | 水で戻してすぐ使えます |
| 炒り粉 | 炒ってから搗きます | 密閉で3-6か月 | 水に溶いてそのまま食べます |
| トウモロコシでんぷん | 水に浸して挽き、沈殿させたでんぷんを乾燥させます | 数年 | 容積が減り、虫がつきません |
| 乾燥した若採りトウモロコシ | 湯通しして粒を外し、乾燥させます | 1年 | 水で戻して汁物や粥に入れます |
| トウモロコシの酒 | アルカリ処理したトウモロコシにヌルク（韓国の麹）を混ぜて発酵させます | 密封して保管 | カロリーの保存と水の消毒を兼ねます |
| トウモロコシ水あめ（チョチョン） | 麦芽（ヨッキルム）で糖化させて煮詰めます | 涼しい場所で1年 | 甘味と濃縮されたカロリーが得られます |
| トウモロコシのひげ茶 | ひげを乾燥させておきます | 密閉で1年 | 捨てられがちな部位を活用します |

&nbsp;&nbsp;&nbsp;トウモロコシのでんぷん抽出は、災害時にとくに有用です。虫に少し食われた粒、割れた粒、保存しにくい端材をすべてでんぷんに回せるからです。一晩水に浸したトウモロコシを挽いて布に包み、水の中でもむと、白い水が出てきます。沈殿させて上澄みを捨て、新しい水を注ぐ作業を3、4回繰り返し、最後に残った沈殿物を乾燥させればトウモロコシでんぷんです。容積と重量が大幅に減り、虫がほとんどつかず、数年もちます。熱湯に溶くとすぐに火が通るので、調理燃料もほとんど要りません。

### 16-5. 副産物の活用

| 副産物 | 用途 |
|---|---|
| 穂軸 | 火力の強い薪。燃やした灰はカリウム肥料に。細かく砕いて堆肥に |
| 皮（苞葉） | 紐の代用、草履やむしろの材料、餃子の皮の代わりやトック（餅）の包みに |
| 茎と葉 | 家畜の粗飼料、堆肥の材料。ただしアワノメイガがいるため、焼却したほうが無難です |
| ひげ | 乾燥させて茶にします |

&nbsp;&nbsp;&nbsp;トウモロコシは非食用価値がEと評価されましたが、実際の災害時には副産物の使い道は少なくありません。とくに穂軸は火力が強く、煮炊き用の薪として重宝しますし、燃やした灰はアルカリ処理や貯蔵時の防虫にそのまま使えます。トウモロコシという一つの作物から、穀物、燃料、アルカリ、防虫剤がすべて得られるわけです。

## 17. 年間作業スケジュール

| 月（韓国の気候基準） | 作業 | ポイント |
|---|---|---|
| 1月 | 貯蔵の点検、種子の確認、道具の手入れ | カビのにおいとゾウムシの穴を確認します |
| 2月 | 畑の計画、堆肥の切り返し、発芽試験 | トウモロコシ畑に堆肥をどれだけ入れるか計算します |
| 3月 | 深耕（18cm以上）、排水溝、元肥、草木灰の散布 | 肥料の運搬が最も大きな作業です |
| 4月 | 播種（韓国南部は上旬、韓国中部は中旬）、1-2週間間隔で分散 | 土壌温度が12℃以上あることを確認します |
| 5月 | 間引き（草丈15cm）、1回目の除草、アワノメイガ第1世代発生期の監視 | 雑草が損失の最大の要因です |
| 6月 | 5-7葉期の追肥、2回目の除草、土寄せ、豆類の播種 | 3つの作業を一度に行います |
| 7月 | 絹糸抽出・開花期の集中灌水、人工授粉、アワノメイガ第2世代発生期 | この2週間が収量全体を決めます |
| 8月 | 若採りトウモロコシの収穫、登熟管理、鳥よけ | 若採りは絹糸抽出後22-25日です |
| 9月 | 子実用の収穫開始、皮をむいて吊るし乾燥 | 黒色層を確認してから収穫します |
| 10月 | 収穫の仕上げ、乾燥、茎の残渣処理 | 茎を焼いてアワノメイガの越冬を防ぎます |
| 11月 | 脱穀、仕上げ乾燥、貯蔵、種子の別保管 | 水分13-14%を確認してから密閉します |
| 12月 | アルカリ処理と製粉、貯蔵の点検、翌年の計画 | 1か月で食べ切れる分だけ加工します |

### 17-1. 忘れてはならない5つのこと

| 項目 | 内容 |
|---|---|
| 肥料 | トウモロコシは多肥性です。堆肥の計画なしに植えれば、収穫もありません |
| 連作禁止 | 豆類との輪作、またはスリーシスターズ（三姉妹）農法が前提です。3年目に破綻します |
| 配置 | 1列に長く植えず、複数の列をまとめて植えます。風媒による受粉のためです |
| 種子 | F1は翌年には使えません。必ず固定種か在来種を確保します |
| アルカリ処理 | トウモロコシだけ食べているとペラグラになります。灰を入れて煮るか、豆類といっしょに食べます |
