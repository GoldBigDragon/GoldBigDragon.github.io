## はじめに
&nbsp;&nbsp;&nbsp;トウモロコシ(Zea mays)は、メキシコの野生の草テオシントを、人が数千年かけて改良した作物です。種子が殻に包まれて自力では散らばれないため、人が植えなければ存在できません。災害時の条件で最大の強みは、面積当たりの熱量です。1,000㎡で600kg(1㎡当たり2,148kcal)を収穫でき、自給ラインの0.82倍と、穀物の中で最も高い値です。代償は、多くの肥料、地力の消耗、F1種子の問題、ペラグラの危険です。この文書は、これらの条件を整える方法に重点を置きます。

## 2. 植物の概要
&nbsp;&nbsp;&nbsp;イネ科トウモロコシ属の一年草で、中南米の熱帯の高原が原産です。C4光合成を行うため日射が収量を直接決め、霜と冠水、日陰に弱いです。茎は高さ1.5-3mで、根元の支柱根が草丈を支えます。雄花は茎の先に、雌花は葉の付け根に別々に付き、雌花の絹糸1本が粒1個につながっています。絹糸が花粉を受けられなかった場所は、中身のない粒になります。

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 発芽・幼苗期 | 播種後3週間 | リン酸、窒素が重要です |
| 栄養成長期 | 3-6週 | 茎と葉が急激に増えます |
| 絹糸抽出・開花期 | 6-8週 | 受粉の時期です。干ばつ、35℃以上の高温、養分不足は不稔の穂になります |
| 登熟期 | 8-12週 | 粒にデンプンが詰まります |
| 成熟期 | 12週以降 | 粒が硬くなり、根元に黒色層ができます |

> **絹糸抽出期の前後2週間が、収穫のすべてを決めます。水をやれる機会が一度しかないなら、そのときにやります。**

| 100g当たりの栄養 | 含量 |
|:---|:---|
| 熱量 | 358kcal(乾燥した子実)。蒸した若採りのトウモロコシは132kcal |
| 炭水化物 / 脂肪 | 約70g / 約4g(脂肪は胚芽に集中) |
| タンパク質 | 9.94g(P:E 11.1%) |
| 豊富なもの | 食物繊維、カリウム、リン |
| 不足するもの | リシン、トリプトファン、吸収できるナイアシン |

## 3. 栽培環境と品種
| 条件 | 最適 | 限界と影響 |
|:---|:---|:---|
| 生育温度 | 20-30℃ | 12℃以下で生長が止まり、霜で枯れる |
| 発芽 | 32-34℃ | 地温13℃で出芽まで18-20日、15-18℃で8-10日 |
| 絹糸抽出期 | 25-28℃ | 35℃を超えると花粉が死んで穂が不稔になる |
| 光量 | 1日8-10時間の直射日光 | 6時間以上が必要。40%遮光で収量は45% |
| 水 | 合計550mm | 400-700mm。絹糸抽出期の干ばつが最も致命的 |
| 土壌 | 排水のよい砂壌土-壌土、pH 6.0-6.8 | pH 5.5未満でリン酸が固定される |
| 冠水 | あってはならない | 3日まで。4日以上で収量が崩れる |

&nbsp;&nbsp;&nbsp;最も肥沃で日当たりのよい平地や、堆肥の山や畜舎に近い畑をトウモロコシに充て、やせた端の土地はモロコシやアワに回します。日陰になる場所や、水がたまる低地は避けます。

| 品種 | 熟期 | 用途と災害の観点 |
|:---|:---:|:---|
| モチトウモロコシ | 80-90日 | 若採り用。夏の一時期の食料 |
| スーパースイート種 | 70-80日 | 生食可能、貯蔵が難しい |
| コダンオク(高糖玉) | 約80日 | 二期作が可能 |
| 子実用・飼料用 | 90-100日 | 乾燥して貯蔵、製粉。長期の備蓄はこの品種だけ |
| 爆裂種(ポップコーン) | - | 弾けさせれば燃料がほとんど要らない |

&nbsp;&nbsp;&nbsp;市販の種子の多くはF1の交配種で、そこから採った種を植えると近交弱勢で収穫が半分以下に落ちます。災害が長引くことを前提にするなら、在来種や固定種を確保します。モチトウモロコシは他の品種から200m以上離すか、播種を3週間以上ずらします。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 土づくり | 18cm以上(できれば25-30cm)耕し、周囲と畝間に排水路を掘り、畝の高さは15-20cm |
| 酸度 | pH 6.0-6.8。酸性なら木灰で矯正 |
| 窒素 N | 1,000㎡当たり10-15kg。元肥50%、5-7葉期に追肥50% |
| リン酸 P / カリウム K | 各8-10kg。リン酸は全量を元肥に、カリウムは分けて施す |
| 堆肥 | 1,000-1,500kg。完熟堆肥を全量元肥に |

| 代替の肥料 | 方法 |
|:---|:---|
| マメ科の緑肥 | 前作にヘアリーベッチ・レンゲをすき込むと窒素8-12kg。効果が最も大きい |
| マメの混作 | トウモロコシの間にマメを一緒に植える |
| 尿 | 水で10倍に薄め、5-7葉期に畝間へ流す。追肥の主力 |
| 木灰 | 40-60kgを散布。カリウムとリン酸を補い、酸度も矯正 |
| 腐熟堆肥 | 落ち葉・草・糞尿を3-6か月腐らせる。前年の秋から積み始める |
| 人糞堆肥 | おがくずや籾殻と混ぜ、6か月以上完全に腐らせる。腐熟が不十分だと病原菌が残る |

&nbsp;&nbsp;&nbsp;窒素10-15kgは完熟堆肥2-3トンに相当するので、肥料の計画なしにトウモロコシを植えるのは、植えるふりをしているにすぎません。

| 播種 | 基準 |
|:---|:---|
| 時期 | 南部は4月上旬、中部は4月中旬。地温12℃以上が基準。後作は7月上旬で、限界は6月下旬。1-2週間間隔に分けて植える |
| 種子の選別 | 穂の中ほどの大きくそろった粒。水に浮く粒は除く |
| 種子の消毒 | 木灰をまぶす(鳥とアリを避ける効果も)、50-55℃の湯に10分、木酢液500倍に6-12時間 |
| 植え方 | 深さ3-5cm、条間70cm、株間25cm、1穴2粒 |
| 配置 | 最低4条以上をまとめて四角く。1条だと花粉が畑の外へ飛んでしまう |
| 間引き | 草丈15cmで1株だけ残す。抜かず、根元から切る |

## 5. 水と栽培管理、病害虫
| 管理 | 内容 |
|:---|:---|
| 水 | 発芽期は乾かさず、栄養成長期と登熟期は十分に、**絹糸抽出・開花期は必ず十分に**、成熟期は切り、梅雨は排水が管理 |
| 1回目の草取り | 出芽後2週間 |
| 2回目の草取り | 5-7葉期。土寄せ(根元に土を20cm)と追肥を一度に |
| 人工授粉 | 結実が悪ければ、露が乾いた後に雄花を揺すって花粉を落とす。数日かけて何度も |
| その他 | 分げつと下葉は除かない。倒れたら起こして土寄せ。熟す頃、鳥よけに紙袋をかぶせる |

&nbsp;&nbsp;&nbsp;トウモロコシの無防除の潜在損失68.5%のうち、40.3ポイントは雑草によるものです。雑草は農薬ではなく手で解決でき、播種後30-45日に草取りを集中します。

| 病害虫 | 症状と時期 | 農薬を使わない対応 |
|:---|:---|:---|
| 穂腐れ病 | 登熟期の雨。カビ毒の危険 | 早く収穫、皮をむいて乾燥、病んだ穂は廃棄 |
| 黒穂病 | 穂や茎に白いこぶができ、黒い粉になって破裂 | 破裂する前に切って焼却、輪作 |
| 茎腐れ病・根腐れ病 | 汚染水、過湿 | 排水の改善、畝間かん水 |
| ごま葉枯病・紋枯病 | 高温多湿、密植 | 風通しの確保、病んだ葉は焼却 |
| アワノメイガ | 年3回(5月末-10月初め)。幼虫が茎の中に潜る | 収穫後に茎を焼くか細かく砕いて埋めるのが最も効果的。卵塊の除去、寄生バチの保護 |
| アブラムシ | 汁を吸い、すす病を誘発 | 石けん水(水1Lに純石けん5-10g)を散布 |
| 鳥・ネズミ | 登熟期、貯蔵期 | 紙袋、ネット、金属容器 |

| 欠乏の症状 | 原因と処置 |
|:---|:---|
| 下葉の中央が葉脈に沿ってV字に黄変 | 窒素欠乏。尿の希釈液、腐熟堆肥 |
| 葉が濃い紫色 | リン酸欠乏または低温。骨粉、木灰 |
| 葉の縁が枯れ込む | カリウム欠乏。株間に木灰をまく |
| 穂の先に粒がない | 絹糸抽出期の養分・水分の不足。追肥を前倒しし、かん水 |

## 6. 混植と輪作
| 作物 | 役割 |
|:---|:---|
| トウモロコシ | 支柱。つる性のマメがよじ登る |
| マメ | 根粒菌が空気中の窒素を固定 |
| カボチャ | 広い葉が地面を覆い、雑草と蒸発を抑える |

&nbsp;&nbsp;&nbsp;北米先住民のスリーシスターズ(三姉妹)農法です。トウモロコシを先に植え、膝の高さになったらマメを、次にカボチャを植えます。マメを早く植えすぎると、トウモロコシに巻きついて倒してしまいます。トウモロコシに不足するリシンとトリプトファンをマメが補うので、栄養も互いに補完されます。トウガラシやパプリカと一緒に植えると、ウイルス病が72%減りました。モロコシとアワは同じイネ科で病害虫を共有するので避けます。

| 輪作 | 作物 |
|:---|:---|
| 1年目 | トウモロコシ(マメの混作) |
| 2年目 | マメ科の単作(ダイズ、アズキ、ササゲ) |
| 3年目 | 葉菜または根菜 |
| 4年目 | 穀物(モロコシ、アワ、エンバク) |
| 5年目 | トウモロコシに戻る |

> **トウモロコシの連作は3年目に崩れます。土地が狭くても、せめてトウモロコシとマメを毎年交互に植えなければなりません。**

## 7. 収穫、乾燥、採種
| 区分 | 時期と判断 |
|:---|:---|
| 若採り | 絹糸抽出後22-25日。押すと白い汁が出てチーズのような状態。早朝に収穫。適期が数日しかないので、分けて植える |
| 子実 | 絹糸抽出後50-60日。根元に黒色層ができ、爪が入らない |

&nbsp;&nbsp;&nbsp;穂を下へ折り曲げてひねり取り、皮は2、3枚だけ残して互いに編み、軒下に吊るします。カビが見える穂は別に選り分けて廃棄し、収穫が終わった畑の茎は焼くか、細かく切って埋めます。

| 乾燥 | 方法 |
|:---|:---|
| 目標 | 水分25-35%を13-14%に。15%を超えるとカビが育つ |
| 順序 | 吊るして乾燥3-6週間 → 穂のまま日光乾燥3-5日 → 脱穀 → 子実を日光乾燥2-4日 → 日陰で1日置いてそろえる |
| 判定 | ひねると粒がバラバラと落ちる、爪の跡が付かない、噛むとパリッと割れる |
| 熱乾燥 | 50℃以下。超えると種子が死に、味が落ちる |

&nbsp;&nbsp;&nbsp;脱穀は、親指で最初の1列を外して空の溝を作り、残りを横へ押す方法が最も実用的です。乾いた穂を2本合わせてこすり合わせる、袋に入れて踏む、瓶のふたや釘を打った板にこすりつけるのでもかまいません。穂軸は火力のよい薪になり、灰はカリウムの肥料になります。殻や穂軸のくずは箕であおるか、ふるいで分け、カビた粒と虫食いの粒は手で選り分けます。

| 採種 | 基準 |
|:---|:---|
| F1 | 自家採種は不可能。固定種・在来種のみ可能 |
| 隔離 | 他の品種と200m以上、または播種を3週間以上ずらす、または絹糸が出る前に穂に紙袋をかぶせ、同じ品種の花粉を振り入れる |
| 選抜 | 病気がなく倒れていない20-30株からまんべんなく。穂の中ほどの粒だけを使う |
| 保管 | 水分12-13%、密閉して涼しく暗い所に。常温で2-3年 |
| 発芽試験 | 濡れた布に20粒を包んで5-7日。18粒以上なら正常、14-17粒なら1穴3粒、12粒以下なら取り替える |

## 8. 貯蔵
&nbsp;&nbsp;&nbsp;貯蔵性はSSですが、完全に乾燥した子実に限った等級です。若採りのトウモロコシは常温で3日が限界です。貯蔵の敵は、カビ(水分15%以上、アフラトキシン)、虫(20℃以上、水分12%以上)、ネズミです。

| 項目 | 基準 |
|:---|:---|
| 条件 | 水分13-14%(種子は12-13%)、温度15℃以下、周囲の湿度65%以下、遮光、2か月ごとに点検 |
| 穂のままの貯蔵 | 風通しがよくカビが生えにくいが、体積が3倍以上でネズミが近づきやすい。春までに食べる分 |
| 子実の貯蔵 | 体積が小さく密閉しやすい。完全な乾燥を確認したとき。翌年まで持たせる分 |
| 容器 | 金属缶、ガラス瓶は3年以上 / 陶器の壺は2-3年 / 厚手のビニールは1年 / 麻袋は6か月 |

| 虫の防除 | 方法 |
|:---|:---|
| 完全密閉 | 容器をいっぱいに満たし、揺すって沈めてまた満たす。酸素が使い果たされて虫が死ぬ |
| 木灰 | 細かい灰を穀物の体積の2-5%混ぜる。食べる前に洗い流す |
| 珪藻土 | 穀物1kgに1-3g。乾いた状態でのみ働く |
| 補助 | 乾燥トウガラシ、炭、炒り塩、ヨモギの葉 |
| 高温・低温 | 60℃の日なたに薄く広げて数時間(種子用は除く)、真冬に数日外へ出す |

&nbsp;&nbsp;&nbsp;2か月ごとに、容器の表面の結露とカビの臭い、粒の小さな穴と底の粉(ゾウムシ)、表面のクモの巣のような糸(ノシメマダラメイガ)、手で握ったときの温かさ(水分過多)、ネズミの痕跡を確認します。

## 9. 調理と注意事項
> **トウモロコシを主食にしながら、マメもなく、アルカリ処理もしなければ、数か月後にペラグラ(ナイアシン欠乏症)になります。**

&nbsp;&nbsp;&nbsp;トウモロコシのナイアシンは吸収できない結合型で、トリプトファンも不足しています。症状は、日光に当たる皮膚の炎症、下痢、精神異常で、死に至ることもあります。マメと一緒に食べるか、アルカリ処理をすれば防げます。

| 順序 | アルカリ処理(ニシュタマリゼーション) |
|:---:|:---|
| 1 | 乾燥した粒1に対して水3、木灰を粒の体積の5%(生石灰は1%)加える |
| 2 | 煮立ててから火を弱め、30-50分煮る |
| 3 | 火を止めて一晩置く |
| 4 | 湯を捨て、手でもんで皮をむく |
| 5 | 澄んだ水が出るまで3、4回すすぐ |
| 6 | そのまま調理する、挽く、または乾燥させる |

&nbsp;&nbsp;&nbsp;この処理は、ナイアシンを吸収できるようにし、皮をむき、粒を柔らかくして製粉を楽にします。乾燥したトウモロコシはとても硬く、そのままでは挽きにくいので、アルカリ処理か焙煎を経て、粉は1か月に食べる分だけ挽きます。乾燥した子実は必ず水に戻して火を通します。

> **カビが生えたトウモロコシは、洗っても、茹でても、炒っても安全になりません。人にも家畜にも与えず、廃棄します。**

| 調理 | 燃料とコツ |
|:---|:---|
| 粉がゆ | 粉を水に溶いて10分。燃料が最も少なくてすむ |
| 若採り | 水を少し入れて20分蒸す |
| 余熱調理 | 10分煮てから、わらや布団でくるんで1時間 |
| 爆裂種 | 熱した鍋に入れ、ふたをして数分振る |
| 乾燥した子実をそのまま煮る | 一晩浸して1時間以上。燃料が最も多くかかる |

&nbsp;&nbsp;&nbsp;貯蔵を兼ねた加工には、アルカリ処理後の乾燥(密閉で1年)、炒り粉(3-6か月)、デンプン(数年、虫がつかない)、乾燥した若採りのトウモロコシ(1年)、トウモロコシの水あめがあります。皮はひもの代わりに、絹糸は乾燥して茶に使います。

## 10. 年間の作業予定
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵の点検、種子の確認、堆肥の計画と切り返し、発芽試験 |
| 3月 | 深耕、排水路、元肥、木灰の散布 |
