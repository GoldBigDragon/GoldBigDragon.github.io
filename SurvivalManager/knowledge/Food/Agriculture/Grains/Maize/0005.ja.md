## 12. 収穫と脱穀

### 12-1. 二通りの収穫 - 若どりと穀粒

&nbsp;&nbsp;&nbsp;トウモロコシの収穫は、目的によってまったく異なります。ゆでて食べる若どりトウモロコシは、粒がまだ柔らかいうちに収穫しなければならず、貯蔵する穀粒は、完全に乾くまで置いておかなければなりません。時期は一か月以上違います。

| 目的 | 時期 | 判断基準 |
|---|---|---|
| 若どりトウモロコシ | 絹糸抽出後22-25日 | 粒を押すと白い汁が出て、チーズのような状態です |
| 子実用の穀粒 | 絹糸抽出後50-60日 | 粒が硬くなり、基部に黒色層ができます |

| 区分 | 状態 | 判定 |
|---|---|---|
| 早すぎる状態 | 粒の中身が水のようにさらさらしています | まだ早いです |
| 若どりの適期 | 糊やチーズのような中身、品種本来の色 | 今収穫すべきです |
| 過熟 | 中身が固まり、皮が硬くなります | 若どりとしては遅すぎます。穀粒用に回します |
| 穀粒の適期 | 爪が入らず、皮がからからに乾いています | 収穫します |

&nbsp;&nbsp;&nbsp;若どりトウモロコシの適期は、わずか数日にすぎません。一、二日遅れただけでも甘みが落ち、皮が硬くなります。そのため、若どり用は必ず1-2週間間隔に分けて植える必要があり、収穫は早朝がよいです。一晩のうちにつくられた糖が、まだデンプンに変わる前だからです。

&nbsp;&nbsp;&nbsp;穀粒用の判断基準は、黒色層です。粒を一つ外して基部を見ると、穂軸に付いていた部分に黒い点ができています。これが見えたら、それ以降は畑に置いておいても粒は大きくなりません。残るのは乾くことだけで、その乾燥は、畑よりも軒下のほうが安全です。

> **登熟期に雨が続くときは、黒色層ができた直後に収穫し、皮をむいて乾燥させます。トウモロコシは皮に包まれているため、一度濡れるとなかなか乾きません。**

### 12-2. 収穫のコツ

| 順序 | 内容 | 理由 |
|---|---|---|
| 1 | 晴れた日の午前中に始めます | 濡れた穂はカビの出発点です |
| 2 | 穂を下に折り曲げ、ひねって外します | 引っ張ると茎が傷みます |
| 3 | 皮をむきますが、二、三枚は残しておきます | 残した皮で互いに結んで編むことができます |
| 4 | カビが見える穂は別に選り分けて廃棄します | 混ぜておくと貯蔵庫全体が汚染されます |
| 5 | 穂を二、三本、残した皮で束ねます | 吊るし乾燥の準備です |
| 6 | 軒下や納屋に吊るします | 風通しのよい吊るし方が乾燥を左右します |
| 7 | 収穫が終わった畑の茎は集めて焼くか、切って埋めます | アワノメイガの越冬場所をなくします |

&nbsp;&nbsp;&nbsp;皮を二、三枚残すコツは、伝統的な方法です。残した皮を互いに編んだり結んだりすると、穂が何本も一列につながって、吊るしやすくなります。トウモロコシの束が軒下にずらりと吊り下げられた風景がそれで、この吊るし方は、風通しと水はけを同時に満たす最適な乾燥の形です。ひもが貴重な状況で、トウモロコシ自身の皮をひもとして使えることも利点です。

### 12-3. 乾燥

&nbsp;&nbsp;&nbsp;穀物の貯蔵のすべては、水分で決まります。水分が15%を超えるとカビが生え、13%を下回るとカビも虫も活動をほとんど止めます。収穫したてのトウモロコシの水分は25-35%です。これを13-14%まで下げることが、収穫直後の唯一にして最も重要な課題です。トウモロコシは粒が大きいため、ほかの穀物より乾くのに時間がかかります。

| 段階 | 方法 | 期間 | 到達水分 |
|---|---|---|---|
| 1. 皮むき | 皮を二、三枚だけ残してむきます | - | 乾燥速度が大きく変わります |
| 2. 吊るし乾燥 | 穂のまま軒下や納屋に吊るします | 3-6週間 | 16-18% |
| 3. 天日乾燥 | 穂のままむしろに広げて日に当てます | 3-5日 | 15% |
| 4. 脱穀 | 粒が外れやすくなったら外します | 1日 | - |
| 5. 仕上げ乾燥 | 穀粒を広げて日に干します | 2-4日 | 13-14% |
| 6. 寝かせ | 日陰に一日置いて水分を均一にします | 1日 | 均一化 |

&nbsp;&nbsp;&nbsp;トウモロコシの乾燥で核心となるのは皮です。皮を残しておくと内側が乾かず、湿気が閉じ込められてカビが生えます。貯蔵中のカビの半分以上は、皮をきちんとむかなかったことに由来します。束ねるために二、三枚残す場合でも、残りは必ずむく必要があり、特に穂の先を覆っている部分は完全に開けておかなければなりません。

&nbsp;&nbsp;&nbsp;吊るし乾燥には3-6週間かかります。ほかの穀物よりはるかに長い期間です。粒が大きく穂軸に付いているため、空気に触れる面積が狭いからです。急がずに十分な時間をかけ、その間、雨に当てないようにすることがすべてです。軒下、納屋、ウォンドゥマク（畑に建てる高床の見張り小屋）など、屋根があって四方が開けた場所ならどこでもよいです。

&nbsp;&nbsp;&nbsp;水分計がなくても水分を見当づける方法があります。

| 方法 | 手順 | 判定 |
|---|---|---|
| 爪テスト | 粒に爪を立てて押してみます | 跡がつかなければ乾いています |
| ひねりテスト | 穂を両手でひねります | 粒がぽろぽろ落ちれば、脱穀できるほど乾いています |
| かみテスト | 粒を奥歯でかみます | ぱきっと割れて粉が出れば13-14%です |
| 塩テスト | 乾いた塩と穀粒をびんに入れて振り、15分置きます | 塩がびんの壁に付けば水分が高いです |
| びんテスト | ガラスびんに半分ほど入れて密封し、一日置きます | びんの内側が曇れば、さらに乾燥が必要です |
| 重量テスト | 穂を一本決めて毎日重さを量ります | 重さがそれ以上減らなければ乾ききっています |

&nbsp;&nbsp;&nbsp;ひねりテストは、トウモロコシにだけ使える便利な方法です。十分に乾いた穂は、両手でひねるだけで粒がばらばらと落ちます。手に力を入れても粒が穂軸に付いたままなら、まだ湿っており、その状態で貯蔵すれば必ず傷みます。

&nbsp;&nbsp;&nbsp;火力を使うときは、50度を超えないようにします。それ以上になると種子として使えなくなり、デンプンが変質して味も落ちます。かまどの上の屋根裏や、オンドル（床下暖房）の部屋の上座（火口から遠い側）に置きますが、手を当てて温かいと感じる程度までにとどめます。

### 12-4. 脱穀

&nbsp;&nbsp;&nbsp;トウモロコシの脱穀は、ほかの穀物とは異なります。粒が穂軸にびっしりと埋まっているため、たたいたり踏んだりする方法は通用しません。そのかわり、粒の一つ一つが大きいので、手でも外せます。コツは、最初の一列を取り除いて空間をつくることです。

| 方法 | 手順 | 規模 | 備考 |
|---|---|---|---|
| 親指で押す | 親指で一列を押して外し、空いた溝をつくってから、残りを横に押し出します | 少量 | 最初の一列さえ外せば、残りは簡単に押し出せます |
| 穂を二本こすり合わせる | 乾いた穂二本を突き合わせて、互いにこすります | 中程度 | 道具なしで最も速い方法です |
| 袋の中でこする | 麻袋に穂を入れ、足で踏んで転がします | 多量 | 粒が飛び散りません |
| びんのふた板 | 板にびんのふたや釘を打ち付けて作った板に、穂をこすり付けます | 中程度 | 簡単に作れる脱穀器です |
| 木臼に入れて搗く | 穂のまま入れて軽く搗きます | 中程度 | 穂軸が砕けて混ざる欠点があります |
| 鉄棒でしごく | 穂の中心に鉄棒を差し込んで回します | 中程度 | 穂軸に穴をあけながら粒を押し出します |

&nbsp;&nbsp;&nbsp;最も実用的な方法は、親指で最初の一列を取り除き、残りを押していくことです。トウモロコシの粒は列になって付いているため、横に空間ができると、押されて落ちます。最初の一列だけ親指の爪で一粒ずつ外せば、そのあとは手のひらで押して、ずっと速く外せます。手が痛くなったら、厚い手袋をはめるか、穂二本を突き合わせてこすり合わせる方法に切り替えます。

&nbsp;&nbsp;&nbsp;びんのふた板は、作っておく価値のある簡易な道具です。板に王冠型のびんのふたを、ぎざぎざが上を向くように何個も打ち付けるか、太い釘をびっしりと打ち込んで作ります。乾いた穂をその上に当てて、押しながら回すと、粒がこすり落とされます。一人が一日に処理する量が、手で行うときの三、四倍になります。

&nbsp;&nbsp;&nbsp;穂軸（芯）は捨てません。乾かした穂軸は火力の強い薪になり、焼いた灰はカリウムが豊富な肥料になります。細かく砕けば堆肥の炭素源として使われ、昔は栓やブラシの代わりにも使われました。災害時には、トウモロコシの穂軸は穀物に劣らない資源です。

### 12-5. 風選（くず飛ばし）

| 方法 | 手順 | 条件 |
|---|---|---|
| 風に流す | 風のある日に高い所からゆっくり注ぎ落とします | トウモロコシの粒は重く、並の風では飛ばされません |
| 箕でのあおり | 箕に入れ、前に押し出しては引いて浮かせます | 皮の破片や砕けた穂軸を取り除きます |
| ふるい分け | 目の粗いふるいで穂軸の破片を、細かいふるいでくずを選り分けます | トウモロコシは粒が大きいので、ふるい分けが特に簡単です |
| 手選別 | カビの生えた粒、虫に食われた粒を選り出します | 貯蔵前の最後の関門です |

&nbsp;&nbsp;&nbsp;トウモロコシは粒が大きくて重いため、選別がほかの穀物より簡単です。そのかわり、手で選り出す作業が特に重要です。カビの生えた粒が数粒あるだけで、貯蔵庫全体を汚染しかねないからです。色が変わった粒、先端が黒い粒、虫食いの穴がある粒は、惜しまずに選り出します。

## 13. 採種

### 13-1. F1と固定種 - 最初に確認すること

&nbsp;&nbsp;&nbsp;トウモロコシの採種で、ほかのすべてより先に確認すべきことは、植えた品種がF1雑種なのか固定種なのかです。

| 区分 | 自家採種 | 翌年の結果 |
|---|---|---|
| F1雑種 | 不可能です | 自殖弱勢で草丈や穂がまちまちになり、収穫が半分以下に落ちます |
| 固定種・在来種 | 可能です | 隔離さえ守れば同じ性質が維持されます |

&nbsp;&nbsp;&nbsp;自殖弱勢は、トウモロコシで最も激しく現れる現象です。F1の種子は、性質の異なる二つの系統を交配して作ったもので、その第一世代でのみ雑種強勢が現れます。そこから採った種を植えると、遺伝子が分離して、大きいものと小さいもの、早く熟すものと遅く熟すものが入り混じり、全体の収穫が崩れます。

> **災害が長引くことを前提とするなら、収量が少し低くても、必ず固定種か在来種を確保しなければなりません。F1では二年目がありません。**

### 13-2. 隔離

| 方法 | 内容 | 効果 |
|---|---|---|
| 距離隔離 | 他の品種から200m以上離します | 最も確実ですが、狭い土地では難しいです |
| 時期隔離 | 播種時期を3週間以上ずらします | 開花期が重ならなければ混ざりません |
| 袋がけ | 絹糸が出る前の穂に紙袋をかぶせます | 小規模に適しています |
| 人工授粉 | 同じ品種の雄穂の花粉を袋の中に振り入れます | 袋がけと併用します |
| 遮蔽物 | 間に背の高い別の作物を植えます | 部分的にしか効果がありません |

&nbsp;&nbsp;&nbsp;トウモロコシは、風で花粉を運ぶ他家受精作物です。隣の畑に別の品種があると、その花粉が飛んできて混ざり、その結果はその年の穂にすぐ現れます。もちトウモロコシ（ワキシーコーン）の畑の隣にスイートコーンがあると、もちトウモロコシの穂にもち性のない粒が混ざって付きます。

&nbsp;&nbsp;&nbsp;狭い土地で最も実用的な方法は、袋がけです。絹糸が出る直前の穂に紙袋をかぶせ、同じ品種の雄穂から採った花粉を袋の中に振り入れたあと、もう一度口を結びます。穂を三、四本だけこのように管理すれば、翌年の種子として十分です。トウモロコシの穂一本には、粒が数百個付いているからです。

### 13-3. 採種個体の選抜と保管

| 基準 | 内容 | 理由 |
|---|---|---|
| 個体の選抜 | 病徴がなく、倒れておらず、穂が大きい株 | 形質が受け継がれます |
| 複数の株から | 最低20-30株から満遍なく採ります | 他家受精作物なので遺伝的多様性が必要です |
| 粒の位置 | 穂の中央部の粒だけを使います | 先端と基部の粒は発芽が不揃いです |
| 収穫時期 | 完全に熟して黒色層ができたあと | 未熟な種子は発芽力が落ちます |
| 乾燥 | 穂のまま十分に乾かしたあと、手で外します | 機械的な損傷を避けます |
| 水分 | 12-13% | 食用より少し乾燥させます |
| 保管 | 密閉容器に入れ、涼しく暗い場所に置きます | 灰や乾燥トウガラシを一緒に入れます |
| 寿命 | 常温密閉で2-3年 | 涼しければもっともちます |

&nbsp;&nbsp;&nbsp;トウモロコシの採種が、アワやモロコシのような自家受精作物と異なる点は、複数の株から採らなければならないということです。トウモロコシは他家受精作物なので、遺伝的に多様な集団を維持してこそ健全です。最も良い穂一本だけから採り続けると、数世代で近交弱勢が現れます。最低20-30株の穂を満遍なく混ぜて翌年の種子とするのが原則です。

### 13-4. 発芽試験

&nbsp;&nbsp;&nbsp;古い種子を植える前には、発芽力を確認します。濡れた布に粒を20個包んで暖かい場所に置き、5-7日待ちます。20個のうち18個以上ならそのまま使い、14-17個なら1穴あたり3粒に増やし、12個を下回るなら新しい種子を入手しなければなりません。トウモロコシは1穴あたり2粒を植えるのが基準なので、発芽率がそのまま株数に反映されます。

## 14. 毒性と注意事項

### 14-1. ペラグラ - トウモロコシの主食化の最大のリスク

&nbsp;&nbsp;&nbsp;トウモロコシ自体に毒性はありません。しかし、トウモロコシを主食にしたときに生じる問題があり、これが歴史的に数十万人の命を奪いました。ナイアシン欠乏症であるペラグラです。

| 項目 | 内容 |
|---|---|
| 原因 | トウモロコシのナイアシンは、吸収できない結合型で存在します |
| 悪化要因 | トウモロコシはトリプトファンも不足しています。トリプトファンは、体内でナイアシンに変わる材料です |
| 症状 | 日光に当たる皮膚の炎症、下痢、精神異常、そして死 |
| 発症条件 | トウモロコシ以外のタンパク源がほとんどない食事が数か月続いたとき |
| 歴史 | 19世紀に南ヨーロッパとアメリカ南部で大規模に発生しました |

&nbsp;&nbsp;&nbsp;この病気が恐ろしいのは、トウモロコシが優れた食料だからです。お腹がいっぱいになり、熱量も十分なのに、数か月後に病気が現れます。原因を知らなければ、トウモロコシのせいだとは思いません。実際、19世紀のヨーロッパでは、長い間、伝染病だと考えられていました。

> **トウモロコシを主食にしながら、マメがなく、アルカリ処理もしないなら、その食事は数か月後に人を病気にします。**

&nbsp;&nbsp;&nbsp;対応は二つあり、どちらも難しくありません。第一に、マメと一緒に食べることです。マメにはトリプトファンとリジンが豊富で、不足分をちょうど補います。トウモロコシとマメを一緒に食べれば、ペラグラ（Pellagra）にはなりません。第二に、アルカリ処理です。トウモロコシを灰や石灰を溶かした水で煮ると、結合が切れて、ナイアシンが吸収できる形になります。これをニクスタマリゼーションといい、中南米の先住民が数千年にわたって用いてきた方法です。具体的な手順は16節にあります。

&nbsp;&nbsp;&nbsp;トウモロコシをヨーロッパに持ち帰った人々が、作物だけを持ち帰り、この調理法を持ち帰らなかったことが、ペラグラ大流行の原因でした。災害時には、この知識の有無が同じ結果を生みかねません。

### 14-2. カビ毒

| 危険要素 | 危険度 | 対応 |
|---|:---:|---|
| 正常な乾燥した穀粒 | なし | 安全です |
| 穂にカビが生えたもの | 非常に高い | 全量廃棄します。家畜にも与えません |
| 貯蔵中にしけって臭いがするもの | 非常に高い | 廃棄します。洗っても炒っても毒素は残ります |
| 色が変わって固まっているもの | 高い | その部分を含めて広めに取り除きます |
| 先端だけが黒く変色した粒 | 高い | 選り出します |

&nbsp;&nbsp;&nbsp;トウモロコシは、穀物の中でもアフラトキシン汚染が最も起こりやすい部類です。粒が大きくて乾くのに時間がかかり、皮に包まれていて、中が濡れるとなかなか乾かないからです。アフラトキシンは強力な肝毒性物質で発がん性があり、加熱しても消えません。特に子どもに危険です。

&nbsp;&nbsp;&nbsp;対応は、もっぱら予防です。皮を十分にむいて乾燥させ、水分13から14%を確認してから貯蔵し、貯蔵中は二か月に一度、においを確認します。すでにカビが生えたものは、どれほどもったいなくても、人の口には入れません。堆肥の山に入れれば分解されて、翌年の肥料になります。

| 乾燥した穀粒 | 必ず水に浸して火を通します。そのままでは消化されません |
