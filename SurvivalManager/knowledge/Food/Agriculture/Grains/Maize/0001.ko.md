## 들어가며
&nbsp;&nbsp;&nbsp;옥수수(Zea mays)는 멕시코의 야생 풀 테오신테를 사람이 수천 년 개량한 작물입니다. 씨앗이 껍질에 싸여 스스로 흩어지지 못하므로 사람이 심어야만 존재합니다. 재난 조건에서 가장 큰 강점은 면적당 열량입니다. 1,000㎡에서 600kg(㎡당 2,148kcal)을 거두어 자급선의 0.82배이며, 곡물 가운데 가장 높습니다. 대가는 많은 거름, 지력 소모, F1 종자 문제, 펠라그라 위험입니다. 이 문서는 그 조건을 갖추는 방법에 무게를 둡니다.

## 1. 재난 대비 평가
| 구분 | 등급 | 점수 |
|:---|:---:|:---:|
| 종합 | B | 46.8 |
| 단기 | B | 48.0 |
| 장기 | B | 45.6 |
| 부식 | A | 49.1 |

| 평가 | 항목 |
|:---|:---|
| 강점 (SS-S) | 시설물 부담 SS(노지 직파), 저장성 SS(마른 알곡 상온 3년 이상), 맛 S, 국내 보급도 S |
| 강점 (A) | 면적당 열량(열량 회수 16.8배), 병해충 압력(무방제 감수율 28.2%), 연작 적응성, 자가 채종 |
| 약점 (E) | 태양광(40% 차광 시 상대수량 45%), 내한성(서리에 고사), 비식용 가치 |
| 약점 (D) | 영속성(1년 1회), 시비(㎡당 40g의 다비성), 무합성투입 수량 유지율(50.4%), 수량 안정성(변동률 24.8%) |

&nbsp;&nbsp;&nbsp;조건을 갖추면 어느 국면에서나 제 몫을 하지만 그 조건이 다른 곡물보다 훨씬 까다롭습니다. 연작 적응성 A는 병해충 측면의 값일 뿐 지력 측면에서는 연작에 가장 부적합한 작물입니다. 항목별 등급 전체는 재난 대비 작물 평가 결과 문서에 있습니다.

## 2. 식물 개요
&nbsp;&nbsp;&nbsp;벼과 옥수수속의 한해살이풀로 중남미 열대 고원에서 왔습니다. C4 광합성을 하므로 볕이 수량을 직접 결정하고, 서리와 침수, 그늘에 약합니다. 줄기는 높이 1.5-3m이며 밑동의 지지근이 키를 지탱합니다. 수꽃은 줄기 끝에, 암꽃은 잎겨드랑이에 따로 달리며 암꽃의 수염 한 가닥이 알 한 개에 이어집니다. 수염이 꽃가루를 받지 못한 자리는 빈 알이 됩니다.

| 단계 | 시기 | 핵심 |
|:---|:---|:---|
| 발아·유묘기 | 파종 후 3주 | 인산, 질소가 중요합니다 |
| 영양생장기 | 3-6주 | 줄기와 잎이 급격히 늘어납니다 |
| 출사·개화기 | 6-8주 | 수분 시기입니다. 가뭄, 35℃ 이상 고온, 양분 부족은 빈 이삭이 됩니다 |
| 등숙기 | 8-12주 | 알에 전분이 찹니다 |
| 성숙기 | 12주 이후 | 알이 단단해지고 밑동에 검은층이 생깁니다 |

> **출사기 전후 2주가 수확 전체를 결정합니다. 물을 쓸 기회가 한 번뿐이라면 그때 써야 합니다.**

| 100g당 영양 | 함량 |
|:---|:---|
| 열량 | 358kcal (말린 알곡). 찐 풋옥수수는 132kcal |
| 탄수화물 / 지방 | 약 70g / 약 4g (지방은 배아에 몰려 있음) |
| 단백질 | 9.94g (P:E 11.1%) |
| 풍부한 것 | 식이섬유, 칼륨, 인 |
| 부족한 것 | 라이신, 트립토판, 흡수 가능한 나이아신 |

## 3. 재배 환경과 품종
| 조건 | 최적 | 한계와 영향 |
|:---|:---|:---|
| 생육 기온 | 20-30℃ | 12℃ 이하에서 생장이 멈추고 서리에 고사 |
| 발아 | 32-34℃ | 토양 13℃에서 출아 18-20일, 15-18℃에서 8-10일 |
| 출사기 | 25-28℃ | 35℃ 초과 시 꽃가루가 죽어 이삭이 빔 |
| 광량 | 하루 8-10시간 직사광 | 6시간 이상 필요. 40% 차광 시 수량 45% |
| 물 | 총 550mm | 400-700mm. 출사기 가뭄이 가장 치명적 |
| 토양 | 배수 양호한 사양토-양토, pH 6.0-6.8 | pH 5.5 미만에서 인산이 묶임 |
| 침수 | 없어야 함 | 3일까지. 4일 이상이면 수량이 무너짐 |

&nbsp;&nbsp;&nbsp;가장 기름지고 볕 좋은 평지, 퇴비 더미나 축사에서 가까운 밭을 옥수수에 배정하고, 척박한 자투리땅은 수수나 조에 돌립니다. 그늘진 자리와 물이 고이는 저지대는 피합니다.

| 품종 | 숙기 | 용도와 재난 관점 |
|:---|:---:|:---|
| 찰옥수수 | 80-90일 | 풋옥수수용. 여름 한철 식량 |
| 초당옥수수 | 70-80일 | 생식 가능, 저장 어려움 |
| 고당옥 | 약 80일 | 2기작 가능 |
| 종실·사료용 | 90-100일 | 말려 저장, 제분. 장기 비축은 이 품종만 가능 |
| 폭립종 | - | 튀기면 연료가 거의 들지 않음 |

&nbsp;&nbsp;&nbsp;시판 종자의 상당수는 F1 교배종이라 받은 씨앗을 심으면 자식열세로 수확이 절반 이하로 떨어집니다. 재난이 길어질 것을 전제한다면 재래종이나 고정종을 확보합니다. 찰옥수수와 다른 품종은 200m 이상 떨어뜨리거나 파종을 3주 이상 어긋나게 합니다.

## 4. 밭 준비와 파종
| 항목 | 기준 |
|:---|:---|
| 땅 만들기 | 18cm 이상(가능하면 25-30cm) 갈고, 둘레와 고랑에 배수로, 두둑 높이 15-20cm |
| 산도 | pH 6.0-6.8. 산성이면 나무재로 교정 |
| 질소 N | 1,000㎡당 10-15kg. 밑거름 50%, 5-7엽기 웃거름 50% |
| 인산 P / 칼륨 K | 각 8-10kg. 인산은 전량 밑거름, 칼륨은 분할 |
| 퇴비 | 1,000-1,500kg. 완숙 퇴비를 전량 밑거름으로 |

| 대체 비료 | 방법 |
|:---|:---|
| 콩과 녹비 | 앞그루로 헤어리베치·자운영을 갈아엎으면 질소 8-12kg. 효과가 가장 큼 |
| 콩 혼작 | 옥수수 사이에 콩을 함께 심음 |
| 오줌 | 물 10배 희석, 5-7엽기에 고랑으로. 웃거름의 주력 |
| 나무재 | 40-60kg 살포. 칼륨, 인산, 산도 교정 |
| 부숙 퇴비 | 낙엽·풀·분뇨를 3-6개월 썩힘. 전해 가을에 쌓기 시작 |
| 인분 퇴비 | 톱밥·왕겨와 섞어 6개월 이상 완전히 썩힘. 덜 썩으면 병원균이 남음 |

&nbsp;&nbsp;&nbsp;질소 10-15kg은 완숙 퇴비 2-3톤에 해당하므로, 거름 계획 없이 옥수수를 심는 것은 심는 시늉에 그칩니다.

| 파종 | 기준 |
|:---|:---|
| 시기 | 남부 4월 상순, 중부 4월 중순. 토양 12℃ 이상이 기준. 후작은 7월 상순, 한계는 6월 하순. 1-2주 간격으로 나누어 심음 |
| 종자 선별 | 이삭 가운데 부분의 굵고 고른 알. 물에 뜨는 알은 제거 |
| 종자 소독 | 나무재 분의(새·개미 방지 겸용), 50-55℃ 물 10분, 목초액 500배 6-12시간 |
| 심기 | 깊이 3-5cm, 줄 간격 70cm, 포기 간격 25cm, 구멍당 2립 |
| 배치 | 최소 네 줄 이상 뭉쳐 네모꼴로. 한 줄로 심으면 꽃가루가 밭 밖으로 날아감 |
| 솎기 | 키 15cm에 1포기만 남김. 뽑지 말고 밑동을 잘라 냄 |

## 5. 물과 재배 관리, 병해충
| 관리 | 내용 |
|:---|:---|
| 물 | 발아기는 마르지 않게, 영양생장기와 등숙기는 충분히, **출사·개화기는 반드시 충분히**, 성숙기는 끊음, 장마철은 배수가 관리 |
| 1차 김매기 | 출현 후 2주 |
| 2차 김매기 | 5-7엽기. 북주기(밑동에 흙 20cm), 웃거름을 한 번에 |
| 인공 수분 | 결실이 나쁘면 이슬이 마른 뒤 수꽃을 흔들어 꽃가루를 떨어뜨림. 며칠에 걸쳐 여러 번 |
| 기타 | 곁가지와 아래 잎은 제거하지 않음. 쓰러지면 세워 북주기. 익을 무렵 새를 막으려 종이봉투를 씌움 |

&nbsp;&nbsp;&nbsp;옥수수의 무방제 잠재 손실 68.5% 가운데 40.3%포인트가 잡초에서 옵니다. 잡초는 약이 아니라 손으로 해결되며, 파종 후 30-45일에 김매기를 집중합니다.

| 병해충 | 증상과 시기 | 약 없이 하는 대응 |
|:---|:---|:---|
| 이삭썩음병 | 등숙기 비. 곰팡이독소 위험 | 조기 수확, 껍질을 벗겨 말림, 병든 이삭 폐기 |
| 깜부기병 | 이삭·줄기에 흰 혹이 생겨 검은 가루로 터짐 | 터지기 전에 잘라 소각, 윤작 |
| 줄기·뿌리썩음병 | 오염수, 과습 | 배수 개선, 고랑관수 |
| 깨씨무늬병, 잎집무늬마름병 | 고온다습, 밀식 | 통풍 확보, 병든 잎 소각 |
| 조명나방 | 연 3회(5월 말-10월 초). 애벌레가 줄기 속으로 파고듦 | 수확 후 줄기를 태우거나 잘게 부수어 묻기가 가장 효과적. 알 덩어리 제거, 기생벌 보호 |
| 진딧물 | 즙을 빨고 그을음병 유발 | 비눗물(물 1L에 순비누 5-10g) 분무 |
| 새, 쥐 | 등숙기, 저장기 | 종이봉투, 그물, 금속 용기 |

| 결핍 증상 | 원인과 조치 |
|:---|:---|
| 아래 잎 가운데 잎맥을 따라 V자로 노랗게 변함 | 질소 결핍. 오줌 희석액, 부숙 퇴비 |
| 잎이 짙은 보라색 | 인산 결핍 또는 저온. 뼛가루, 나무재 |
| 잎 가장자리가 타 들어감 | 칼륨 결핍. 나무재를 포기 사이에 뿌림 |
| 이삭 끝에 알이 없음 | 출사기 양분·수분 부족. 웃거름을 앞당기고 관수 |

## 6. 사이짓기와 윤작
| 작물 | 역할 |
|:---|:---|
| 옥수수 | 지주. 덩굴콩이 타고 오름 |
| 콩 | 뿌리혹박테리아가 공기 중 질소를 고정 |
| 호박 | 넓은 잎이 땅을 덮어 잡초와 증발을 억제 |

&nbsp;&nbsp;&nbsp;북미 원주민의 세 자매 농법입니다. 옥수수를 먼저 심고 무릎 높이가 되면 콩을, 그다음 호박을 심습니다. 콩을 너무 일찍 심으면 옥수수를 감아 쓰러뜨립니다. 옥수수에 부족한 라이신과 트립토판을 콩이 채워 주므로 영양도 서로 보완됩니다. 고추·파프리카와 함께 심으면 바이러스병이 72% 줄었습니다. 수수와 조는 같은 벼과라 병해충을 공유하므로 피합니다.

| 윤작 | 작물 |
|:---|:---|
| 1년차 | 옥수수(콩 혼작) |
| 2년차 | 콩과 단작(대두, 팥, 동부) |
| 3년차 | 잎채소 또는 뿌리채소 |
| 4년차 | 곡물(수수, 조, 귀리) |
| 5년차 | 옥수수로 복귀 |

> **옥수수 연작은 셋째 해에 무너집니다. 땅이 좁아도 최소한 옥수수와 콩을 해마다 번갈아 심어야 합니다.**

## 7. 수확, 건조, 채종
| 구분 | 시기와 판단 |
|:---|:---|
| 풋옥수수 | 출사 후 22-25일. 눌렀을 때 흰 즙이 나오고 치즈 같은 상태. 이른 아침에 수확. 적기가 며칠뿐이므로 나누어 심음 |
| 알곡 | 출사 후 50-60일. 밑동에 검은층이 생기고 손톱이 들어가지 않음 |

&nbsp;&nbsp;&nbsp;이삭을 아래로 꺾어 비틀어 떼고, 껍질은 두세 장만 남겨 서로 엮어 처마 밑에 매답니다. 곰팡이가 보이는 이삭은 따로 골라 폐기하고, 수확이 끝난 줄기는 태우거나 잘게 잘라 묻습니다.

| 건조 | 방법 |
|:---|:---|
| 목표 | 수분 25-35%를 13-14%로. 15%를 넘으면 곰팡이가 자람 |
| 순서 | 걸어 말리기 3-6주 → 이삭째 볕 건조 3-5일 → 탈곡 → 알곡 볕 건조 2-4일 → 그늘에 하루 두어 고르게 함 |
| 판정 | 비틀면 알이 우수수 떨어짐, 손톱 자국이 남지 않음, 깨물면 톡 갈라짐 |
| 열 건조 | 50℃ 이하. 넘으면 종자가 죽고 맛이 떨어짐 |

&nbsp;&nbsp;&nbsp;탈곡은 엄지로 첫 줄을 떼어 빈 골을 만든 뒤 나머지를 옆으로 미는 방법이 가장 실용적입니다. 마른 이삭 두 개를 맞대고 비비거나, 마대에 넣고 밟거나, 병뚜껑·못을 박은 판에 문질러도 됩니다. 속대는 화력 좋은 땔감이고 재는 칼륨 거름입니다. 쭉정이는 키질이나 체 치기로 가르고, 곰팡이 알과 벌레 먹은 알은 손으로 골라 냅니다.

| 채종 | 기준 |
|:---|:---|
| F1 | 자가 채종이 불가능합니다. 고정종·재래종만 가능 |
| 격리 | 다른 품종과 200m 이상, 또는 파종을 3주 이상 어긋나게, 또는 수염이 나오기 전 종이봉투를 씌우고 같은 품종 꽃가루를 털어 넣음 |
| 선발 | 병이 없고 쓰러지지 않은 포기 20-30개에서 고루. 이삭 가운데 알만 사용 |
| 보관 | 수분 12-13%, 밀폐해 서늘하고 어두운 곳에. 상온에서 2-3년 |
| 발아 시험 | 젖은 천에 20알을 싸 5-7일. 18알 이상 정상, 14-17알 구멍당 3립, 12알 이하 교체 |

## 8. 저장
&nbsp;&nbsp;&nbsp;저장성은 SS이지만 완전히 마른 알곡에 한한 등급입니다. 풋옥수수는 상온에서 사흘이 한계입니다. 저장의 적은 곰팡이(수분 15% 이상, 아플라톡신), 벌레(20℃ 이상, 수분 12% 이상), 쥐입니다.

| 항목 | 기준 |
|:---|:---|
| 조건 | 수분 13-14%(종자 12-13%), 온도 15℃ 이하, 주변 습도 65% 이하, 빛 차단, 두 달마다 점검 |
| 이삭째 저장 | 통풍이 좋아 곰팡이가 덜 피나 부피가 세 배 이상이고 쥐가 접근하기 쉬움. 봄까지 먹을 몫 |
| 알곡 저장 | 부피가 작고 밀폐가 쉬움. 완전 건조를 확인했을 때. 이듬해까지 갈 몫 |
| 용기 | 금속 통, 유리병 3년 이상 / 항아리 2-3년 / 두꺼운 비닐 1년 / 마대 6개월 |

| 벌레 방제 | 방법 |
|:---|:---|
| 완전 밀폐 | 용기를 가득 채워 흔들어 가라앉히고 다시 채움. 산소가 소진되어 벌레가 죽음 |
| 나무재 | 고운 재를 곡물 부피의 2-5% 섞음. 먹기 전 씻어 냄 |
| 규조토 | 곡물 1kg에 1-3g. 마른 상태에서만 작동 |
| 보조 | 말린 고추, 숯, 볶은 소금, 쑥잎 |
| 고온·저온 | 60℃로 볕에 얇게 펴 몇 시간(종자용 제외), 한겨울에 며칠 내놓음 |

&nbsp;&nbsp;&nbsp;두 달마다 용기 겉면의 결로와 곰팡이 냄새, 알에 난 작은 구멍과 바닥의 가루(바구미), 표면의 거미줄 같은 실(화랑곡나방), 손으로 쥐었을 때의 온기(수분 과다), 쥐 흔적을 확인합니다.

## 9. 조리와 주의사항
> **옥수수를 주식으로 삼되 콩이 없고 알칼리 처리도 하지 않으면 몇 달 뒤 펠라그라(나이아신 결핍증)가 옵니다.**

&nbsp;&nbsp;&nbsp;옥수수의 나이아신은 흡수할 수 없는 결합 형태이고 트립토판도 부족합니다. 증상은 햇볕에 닿는 피부의 염증, 설사, 정신 이상이며 죽음에 이를 수 있습니다. 콩과 함께 먹거나 알칼리 처리를 하면 막을 수 있습니다.

| 순서 | 알칼리 처리(닉스타말화) |
|:---:|:---|
| 1 | 마른 알 1 되에 물 3 되, 나무재를 알 부피의 5%(생석회는 1%) 넣음 |
| 2 | 끓이다가 불을 줄여 30-50분 삶음 |
| 3 | 불을 끄고 하룻밤 둠 |
| 4 | 물을 버리고 손으로 비벼 껍질을 벗김 |
| 5 | 맑은 물이 나올 때까지 서너 번 헹굼 |
| 6 | 이대로 조리하거나 빻거나 말려 둠 |

&nbsp;&nbsp;&nbsp;이 처리는 나이아신을 흡수 가능하게 하고, 껍질을 벗기며, 알을 부드럽게 해 제분을 쉽게 합니다. 마른 옥수수는 매우 단단해 그대로 빻기 어려우므로 알칼리 처리나 볶기를 거치고, 가루는 한 달 먹을 만큼만 빻습니다. 마른 알곡은 반드시 불려 익힙니다.

> **곰팡이가 핀 옥수수는 씻어도, 삶아도, 볶아도 안전해지지 않습니다. 사람도 가축도 먹이지 말고 폐기합니다.**

| 조리 | 연료와 요령 |
|:---|:---|
| 가루죽 | 가루를 물에 풀어 10분. 연료가 가장 적게 듦 |
| 풋옥수수 | 물을 조금 넣고 20분 찜 |
| 잔열 조리 | 10분 끓인 뒤 짚이나 이불로 감싸 한 시간 |
| 폭립종 | 달군 솥에 넣고 뚜껑을 덮어 몇 분 |
| 마른 알곡 그대로 삶기 | 하룻밤 불려 한 시간 이상. 연료가 가장 많이 듦 |

&nbsp;&nbsp;&nbsp;저장을 겸한 가공으로는 알칼리 처리 후 건조(밀폐 1년), 볶은 가루(3-6개월), 전분(수년, 벌레가 들지 않음), 말린 풋옥수수(1년), 옥수수 조청이 있습니다. 껍질은 끈 대용으로, 수염은 말려 차로 씁니다.

## 10. 연간 작업 일정
| 월 | 작업 |
|:---|:---|
| 1-2월 | 저장 점검, 종자 확인, 퇴비 계획과 뒤집기, 발아 시험 |
| 3월 | 깊이갈이, 배수로, 밑거름, 나무재 살포 |
| 4월 | 파종(토양 12℃ 이상, 1-2주 간격) |
| 5월 | 솎기, 1차 김매기, 조명나방 1화기 감시 |
| 6월 | 웃거름, 2차 김매기, 북주기, 콩 파종 |
| 7월 | 출사기 집중 관수, 인공 수분 |
| 8월 | 풋옥수수 수확, 새 쫓기 |
| 9-10월 | 알곡 수확(검은층 확인), 껍질 벗겨 걸어 말리기, 줄기 잔재 처리 |
| 11-12월 | 탈곡, 마무리 건조, 저장, 종자 별도 보관, 알칼리 처리와 제분 |

> **잊지 말아야 할 다섯 가지: 거름 계획, 연작 금지, 여러 줄 뭉쳐 심기, 고정종 확보, 알칼리 처리.**
