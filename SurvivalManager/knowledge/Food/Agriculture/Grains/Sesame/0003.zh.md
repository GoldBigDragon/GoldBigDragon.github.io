## 2. 这是一种什么样的植物

### 2-1. 两种植物，一个名称

&nbsp;&nbsp;&nbsp;归在“kkae”这一名称之下的两种植物，在分类上相距甚远。

| 类别 | 芝麻 | 紫苏 |
|---|---|---|
| 学名 | Sesamum indicum | Perilla frutescens |
| 科 | 胡麻科（Pedaliaceae） | 唇形科（Lamiaceae） |
| 原产地 | 从非洲到印度的干旱地区 | 东亚 |
| 主要用途 | 种子榨芝麻油 | 种子榨紫苏油，叶子作为kkaennip（紫苏叶）食用 |
| 油的性质 | 酸败慢，属于半干性油 | 酸败快，属于干性油 |
| 叶 | 窄披针形，有毛。也可食用，但不是主要用途 | 宽心形，边缘有锯齿。是主要的蔬菜 |
| 花期 | 在韩国为7-8月 | 在韩国为8-9月 |
| 渍害 | 极不耐受 | 较为耐受 |
| 干旱 | 非常耐旱 | 一般 |

&nbsp;&nbsp;&nbsp;二者同属唇形目，都有茎呈四棱形、叶对生的共同点。但在栽培上，必须把它们当作不同的作物来对待。芝麻要安排在干燥向阳的地方，紫苏则可以安排在稍湿的地方。芝麻需要休作3-4年，紫苏没有那么挑剔。

&nbsp;&nbsp;&nbsp;此外还需要再做一项区分。紫苏分为以收籽为目的的油用紫苏和以收叶为目的的叶用紫苏。二者品种不同，栽培方法也不同。油用紫苏的叶片偏老，难以用作ssam（用叶片包裹米饭和配菜食用的吃法），叶用紫苏的种子产量则较少。需要先确定目的，再选择与之相应的品种。

### 2-2. 芝麻的形态

| 器官 | 特征 |
|---|---|
| 叶 | 窄披针形。下部较宽，越往上越窄。表面有细毛，质地较厚 |
| 茎 | 四棱形，挺直生长。高60-150cm。有单秆生长的品系和分枝的品系 |
| 根 | 笔直的主根向深处扎入。在干燥土地上寻找水分的能力强 |
| 花 | 白色或淡粉色的筒状花。每个叶腋的花由下向上依次开放 |
| 果实 | 蒴果。长2-3cm的圆筒形，每个叶腋都着生。成熟时上部缝合线裂开 |
| 种子 | 长约3mm的扁平水滴形。有白色、黄色、褐色、黑色等品系 |

&nbsp;&nbsp;&nbsp;芝麻叶片上有细毛且质地较厚，这是造就这种作物耐旱性的结构之一。细毛在叶面上留住一层空气，避免风直接吹到叶面，厚叶则能储存水分。这是沙漠和干旱地区植物中常见的构造。

&nbsp;&nbsp;&nbsp;最重要的结构是蒴果。芝麻的果实成熟后，顶端会纵向裂开。此时碰一下茎秆，种子就会撒落出来。这称为开裂，是野生植物传播种子的正常方式。栽培品种中，这一特性几乎原样保留着。第12节的收获要领，全部源于这一个事实。

> **芝麻的蒴果成熟后裂开是正常现象。收获就是要抢在这一裂开之前一步完成，晚了就会把种子全撒在田里。**

### 2-3. 无限花序这一特性

&nbsp;&nbsp;&nbsp;芝麻的另一个重要特性是花不会同时开放。茎下部叶腋处的花先开，然后向上依次开放。只要茎尖的生长点持续生长，就会不断开花。这称为无限花序。

| 结果 | 会发生什么 |
|---|---|
| 花期很长 | 花在30-40天内陆续开放 |
| 成熟不整齐 | 下部蒴果全部成熟时，上部蒴果仍是绿色 |
| 收获时机难以把握 | 等上部成熟，下部就撒落；以下部为准，上部又不够饱满 |
| 资源被分散 | 植株把资源也分给后开的花，导致籽粒普遍偏小 |

&nbsp;&nbsp;&nbsp;解决这一问题的办法是摘心。把茎尖切掉后，其上不再开花，植株所拥有的资源会集中到已经结成的蒴果上。结果是籽粒变大，成熟期趋于集中，收获变得容易。首花开放后35-40天就是摘心的时机，将在第8节详细讨论。

### 2-4. 紫苏的形态

| 器官 | 特征 |
|---|---|
| 叶 | 宽心形，边缘有锯齿。正反两面都有细毛，带有特有的香气 |
| 茎 | 四棱形，挺直生长。高60-150cm |
| 根 | 直根上有很多细根 |
| 花 | 白色的小花聚成穗状。在韩国8-9月开放 |
| 果实 | 小蒴果，每个内有4粒种子 |
| 种子 | 直径1.5-2mm的圆粒。灰褐色至黑色 |

&nbsp;&nbsp;&nbsp;紫苏叶的香气来自紫苏醛这种成分。这种香气因人而异，有人觉得好闻，有人觉得难闻，评价表中口味D所附的“气味与香气令人排斥”这条说明指的就是这一点。同样的成分也能驱赶害虫和野兽，成为非食用价值C的依据。紫苏中还含有迷迭香酸这种抗氧化成分。

### 2-5. 生育阶段

| 阶段 | 芝麻 | 紫苏（叶用） | 重要养分 |
|---|---|---|---|
| 发芽·幼苗期 | 播种后3周 | 播种后3周 | 磷、少量氮 |
| 营养生长期 | 3周至8周 | 3周至8周 | 氮 |
| 开花·结实期 | 8周至12周 | 叶片采收期（在韩国为6月下旬至9月下旬） | 芝麻为磷和钾，紫苏为氮和钾 |
| 成熟·收获期 | 12周至16周 | 再生与再次采收持续进行 | 钾 |

&nbsp;&nbsp;&nbsp;芝麻一年只收一次种子，收完就结束了，而叶用紫苏则不同。摘掉下部的大叶后，上部会不断长出新叶，因此整个夏天都能采收。评价表中的持续性B指的就是这一点。在同一块田里分开种植芝麻和叶用紫苏，夏天有叶可收，秋天有油可得。

### 2-6. 每100g的营养

| 营养素 | 芝麻（炒熟的） | 紫苏叶（生） |
|---|:---:|:---:|
| 热量 | 539kcal | 38-47kcal |
| 蛋白质 | 21.3g | 3.69g |
| 脂肪 | 45-55g | 极少 |
| 碳水化合物 | 27.4g | 大部分是膳食纤维 |
| 膳食纤维 | 10-12g | 4.5g |
| 钙 | 丰富 | 296mg |
| 铁 | 丰富 | 丰富 |
| 镁 | 丰富 | 一般 |
| 维生素E | 非常丰富 | 丰富 |
| β-胡萝卜素 | 较少 | 7,565 μg |
| 特有成分 | 芝麻素、芝麻林素 | 迷迭香酸、紫苏醛 |

&nbsp;&nbsp;&nbsp;芝麻45-55%的脂肪含量，说是这种作物的全部价值也不为过。这些脂肪的组成是：油酸约占40%，亚油酸约占45%，饱和脂肪较少。亚油酸是人体自身无法合成的必需脂肪酸，因此必须从饮食中摄取。

&nbsp;&nbsp;&nbsp;芝麻素和芝麻林素是芝麻独有的成分，在灾害情境中具有特殊价值。这两种成分有很强的抗氧化作用，能减缓油脂接触空气后变质的速度。这是芝麻油比其他植物油更耐放的原因，也是在没有冰箱的情况下能把油存放好几个月继续使用的依据。紫苏油中没有这类成分，而且含有易氧化的α-亚麻酸，含量超过60%，常温下几周气味就会改变。

&nbsp;&nbsp;&nbsp;紫苏叶中的β-胡萝卜素7,565μg，相当于胡萝卜的1.4倍。它在体内可转化为维生素A，而缺乏这种维生素就会得夜盲症，在暗处看不清东西。不过，β-胡萝卜素必须溶解在油中才能被吸收，所以不加油食用紫苏叶，实际获得的比所含的要少。芝麻油和紫苏叶出自同一块田，这一点在此就有了意义。

## 3. 栽培环境

### 3-1. 温度

| 类别 | 芝麻 | 紫苏 |
|---|---|---|
| 发芽温度 | 20-25℃，最低15℃ | 15-25℃ |
| 生长适温 | 20-30℃ | 20-25℃ |
| 结实适温 | 20-28℃ | 20-25℃ |
| 高温极限 | 超过35℃，只要有水也能忍受 | 超过30℃叶片会变老 |
| 低温极限 | 10℃时停止生长 | 相同 |
| 致死温度 | 一次霜冻就会死亡 | 相同 |

&nbsp;&nbsp;&nbsp;评价表中的温度适应幅度C，来自结实区间20-28℃、幅度10℃。这意味着，仅仅生长的温度范围较宽，而要让种子成熟，范围就较窄。超出这一区间，即使开花也结不出种子，或者籽粒不饱满。在韩国，芝麻的播种期晚至5月中旬到6月上旬，是为了让开花和成熟落在夏季的这一温度区间内。

### 3-2. 光照

| 类别 | 标准 | 备注 |
|---|---|---|
| 芝麻所需日照 | 每天6小时以上 | 在日照不足的高海拔地区难以栽培 |
| 紫苏所需日照 | 每天6小时以上 | 半阴处也能生长 |
| 40%遮光时 | 相对产量86% | 为叶菜类通用值，是评价表中B级的依据 |

&nbsp;&nbsp;&nbsp;评价表中的遮光值是以叶片为基准得出的，所以与叶用紫苏很吻合，与芝麻种子则不太吻合。芝麻要让种子成熟需要消耗大量能量，光照不足时，蒴果数量和籽粒大小都会同时下降。把阴凉的地方让给叶用紫苏，把向阳的好地方留给芝麻，这样的布局是合理的。

&nbsp;&nbsp;&nbsp;关于紫苏，还需要了解一个特性。紫苏是日照变短时才开花的短日照植物。在韩国，从8月下旬起白天变短，花茎抽出，从那时起叶片就变小变老。要想长期采收叶片，夜间有灯光照到的位置反而有利，但在没有电的情况下，这种办法无法使用。因此，露地叶片的采收期被固定在9月下旬以前。

### 3-3. 水分与土壤

| 项目 | 芝麻 | 紫苏 |
|---|---|---|
| 总蒸散量 | 每个生长季约400mm | 相近 |
| 干旱 | 非常耐旱 | 一般。缺水时叶片会萎蔫 |
| 过湿 | 极不耐受。被淹一两天也会遭受严重损害 | 较为耐受 |
| 土壤质地 | 排水良好的砂壤土至壤土 | 有机质充足、排水良好的土壤 |
| 土层深度 | 30cm以上 | 20cm以上 |
| pH | 6.0-7.0 | 6.0-7.0 |
| 畦高 | 20-30cm以上 | 15-20cm |

> **芝麻栽培中最常见的失败原因不是干旱，而是水。在积水排不掉的地块上，不管其他条件多么好，都不要种芝麻。**

&nbsp;&nbsp;&nbsp;它为什么会脆弱到这种程度，要从根的特性说起。芝麻的根为了在干燥土地中寻找水分，长成了又深又粗的形态，代价是对氧气的需求很大。土壤孔隙被水充满、空气被挤出时，根系立刻就会窒息。此时疫病菌随水扩散，侵入受损的根。一两天的淹水就能毁掉整块田，其机理就在于此。这个问题将在第7节中讨论。

## 4. 品种

### 4-1. 芝麻品种

| 品种 | 特征 | 产量 | 适用情形 |
|---|---|:---:|---|
| Oedae-kkae（单秆型） | 不分枝，单秆生长 | 中等 | 在狭小的地方密植时。管理简单 |
| Gaji-kkae（分枝型） | 长出侧枝。单株较大 | 高 | 场地宽裕时。株数少一些也可以 |
| Daheuk-kkae（Miryang 28号） | 黑芝麻品系 | 中等 | 既可入药，也可榨油 |

&nbsp;&nbsp;&nbsp;选择Oedae-kkae还是Gaji-kkae，取决于田地的情况。Oedae-kkae单株较小，可以密植，而且不分枝，蒴果集中在一根茎秆上，收获简单。Gaji-kkae单株产量高，但各分枝的成熟期不一，收获时机更难判断。种子充足时，密植Oedae-kkae更有利；种子珍贵时，稀植Gaji-kkae更有利。

&nbsp;&nbsp;&nbsp;黑芝麻与白芝麻的含油量没有太大差别。黑芝麻的种皮中除色素外还含有更多草酸，会轻微妨碍钙的吸收，这个问题将在第14节中讨论。

### 4-2. 紫苏品种

| 类型 | 品种 | 特征 |
|---|---|---|
| 叶用紫苏 | Ipdeulkkae 1号、Donggeul 2号、Pungnyeon-deulkkae、Namcheon-deulkkae | 叶片宽而柔软。耐反复采收 |
| 油用紫苏 | 多为地方传统品种 | 结籽多。叶片偏老，难以用作ssam |

> **要获得紫苏叶，必须种植叶用紫苏品种。油用紫苏的叶片老韧、香气过浓，难以用作ssam，而叶用紫苏结籽少，不够榨油。**

### 4-3. 按情形选择什么

| 情形 | 芝麻 | 紫苏 | 理由 |
|---|---|---|---|
| 以榨油为目的时 | Oedae-kkae、Gaji-kkae | 油用紫苏 | 芝麻的油更耐放。紫苏油容易变质 |
| 以油灯用油为目的时 | 芝麻 | - | 芝麻油油烟少，沿灯芯上升顺畅 |
| 以夏季叶菜为目的时 | - | Ipdeulkkae 1号、Donggeul 2号 | 在韩国，6月下旬至9月下旬都可采收 |
| 地方狭小时 | Oedae-kkae | 叶用紫苏 | 可以密植 |
| 排水不良的田块 | 不种 | 紫苏 | 芝麻会毁于渍害 |
| 想驱赶野兽时 | 芝麻 | 紫苏 | 强烈的香气使獐子和野猪不愿靠近 |

&nbsp;&nbsp;&nbsp;在韩国的任何一个道，都能获得芝麻和紫苏的种子，而且各地还保留着适应当地气候、长期栽培下来的地方传统品种。在物流中断的情况下，能够从邻居那里得到种子，这是这种作物的一大优点。
