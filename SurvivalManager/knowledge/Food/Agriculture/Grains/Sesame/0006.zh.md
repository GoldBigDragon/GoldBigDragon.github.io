## 14. 毒性与需注意的成分

### 14-1. 没有毒性

&nbsp;&nbsp;&nbsp;芝麻和紫苏中没有对人体有害的毒性成分。没有马铃薯的龙葵素或木薯的氰苷之类的物质，种子生吃也没有问题。不过有几点需要了解。

### 14-2. 过敏

&nbsp;&nbsp;&nbsp;芝麻被列为主要的致敏食物之一。因人而异，会出现荨麻疹、口腔肿胀感、呼吸困难等反应，少数情况下还会发展为严重的全身反应。在难以获得医疗救治的灾害情境中，这一点比平时更为重要。

| 怎么做 | 内容 |
|---|---|
| 第一次吃的人要少吃 | 尤其是第一次给儿童吃时，从少量开始，观察反应 |
| 有反应就停用 | 连芝麻油和芝麻盐（kkaesogeum）也要全部停用。微量也会引起反应 |
| 改用紫苏 | 对芝麻过敏的人不一定对紫苏过敏 |

### 14-3. 种皮中的草酸与植酸

| 成分 | 存在于哪里 | 有什么问题 | 怎么做 |
|---|---|---|---|
| 草酸 | 种皮，尤其是黑芝麻 | 与钙结合，妨碍吸收。这就是芝麻钙含量很高却无法充分利用的原因 | 炒制可使其部分减少。去皮后会大幅减少，但钙也随之减少 |
| 植酸 | 整粒种子 | 与铁、锌、钙结合，妨碍吸收 | 浸泡、炒制或发酵可使其减少 |

&nbsp;&nbsp;&nbsp;是否去皮需要权衡。钙的大部分在种皮里，去皮就会损失钙；带皮吃，草酸又会阻碍这些钙的吸收。实际上，还是带皮炒着吃更好。炒制过程中草酸会分解一部分，即使有吸收不了的钙，也比完全没有强。

### 14-4. 油的酸败

&nbsp;&nbsp;&nbsp;芝麻真正构成危险的不是毒性成分，而是变质的油。油接触空气氧化后会产生过氧化物和醛类，这些物质不仅气味难闻，而且对身体有害，会刺激消化道。

| 判别 | 内容 |
|---|---|
| 气味 | 香味消失，出现酸味或油漆般的气味 |
| 味道 | 出现苦味或呛喉的涩味 |
| 颜色 | 颜色变深，变得浑浊 |
| 黏性 | 瓶口或容器底部黏稠结块 |

> **气味变了的油不能吃。但也不要扔掉。可以用作油灯的灯油，或用来做肥皂。已经不能吃的油，仍然有它的用处。**

&nbsp;&nbsp;&nbsp;芝麻油因含有芝麻素和芝麻林素，酸败较慢。紫苏油的α-亚麻酸超过60%，变质要快得多，但作为交换，它具有在空气中干结的性质，可用来涂抹浸渍木头和纸张。油纸和木器涂饰的原理就在于此。

### 14-5. 其他注意事项

| 项目 | 内容 |
|---|---|
| 脂肪过多 | 芝麻每100g超过500kcal。在热量不足的情况下这是优点，但一次吃很多会腹泻 |
| kkaennip（紫苏叶）中的硝酸盐 | 在施肥多的叶片中积累。焯水后把水倒掉，也不要给婴儿大量食用 |
| 紫苏叶生食 | 洗净后可以直接吃。但如果田里用作肥料的是粪便，就要煮熟后再吃 |
| 炒芝麻的保存 | 炒过的芝麻香味更好，但酸败也更快。吃多少炒多少 |

## 15. 无冰箱贮藏

### 15-1. 原则是以种子形态存放

&nbsp;&nbsp;&nbsp;芝麻的贮藏有一条原则：以种子形态存放，比榨成油存放要持久得多。

| 形态 | 常温保存期限 | 原因 |
|---|:---:|---|
| 未炒的种子 | 1年左右 | 油被锁在细胞内，与空气接触较少 |
| 炒过的种子 | 3-6个月 | 细胞破裂，油暴露在空气中 |
| 捣碎的芝麻 | 1个月以内 | 表面积大增，迅速变质 |
| 榨好的芝麻油 | 6个月到1年 | 得益于芝麻素，在植物油中算是耐放的 |
| 榨好的紫苏油 | 2-3个月 | α-亚麻酸含量高，变质快 |

> **芝麻是这样一种作物：以种子形态堆放在仓库里，用多少就临时炒多少、榨多少。一次全榨出来存着，半年就不能吃了。**

### 15-2. 种子贮藏

| 步骤 | 方法 | 原因 |
|---|---|---|
| 完全晾干 | 晾到含水量12%以下。用手抓握时沙沙作响，用牙咬时发出“啪”的一声就算好了 | 留有水分会发霉，酸败也会加快 |
| 放凉 | 晒干后在阴凉处完全放凉再装 | 带着热气装的话，容器里会凝结露水 |
| 密封 | 装进陶罐、玻璃瓶、金属桶后盖严 | 隔绝氧气和湿气 |
| 装满 | 容器尽量装满 | 容器里空隙中的空气会使油变质 |
| 干燥剂 | 把炒过放凉的盐或木炭用布包好放进去 | 吸收残余的湿气 |
| 位置 | 放在凉爽、黑暗、温度变化小的地方 | 土窖、地下、朝北的房间都合适 |
| ÷ | 分装到多个容器中 | 丢了一个容器，也不至于全部损失 |

&nbsp;&nbsp;&nbsp;要求把容器装满这一条，是与其他谷物贮藏不同的地方。油多的种子，减少与空气接触的面更有利。陶罐只装一半的话，上面的空气会使油变质，所以最好分装到几个小容器里，每个都装满。

&nbsp;&nbsp;&nbsp;储粮害虫也是个问题。首先是密封，同时放进干辣椒、花椒或草木灰，虫害会少一些。发现有虫时，摊到太阳下把虫赶走，再晾干后重新装入。

### 15-3. 油的贮藏

| 方法 | 内容 |
|---|---|
| 分装到小瓶里 | 每次开瓶都会进入空气，所以只打开当次用量的瓶子 |
| 装满并把塞子塞紧 | 减少瓶中的空隙 |
| 使用深色的瓶子或陶罐 | 光会促进氧化 |
| 放在凉爽的地方 | 不要放在厨房靠近火的地方 |
| 另外保存未经炒制榨出的油 | 香味较弱，但保存时间长 |

### 15-4. 紫苏叶的贮藏

| 方式 | 方法 | 期限 |
|---|---|:---:|
| 原样放置 | 不洗，甩掉水分，放在凉爽的地方 | 2-3天 |
| 晾干 | 在阴凉通风处完全晾干后密封 | 数月 |
| 酱菜 | 一层层码入酱油或大酱中 | 数月 |
| 盐腌 | 用盐腌后压住 | 数月 |
| 韩式泡菜 | 加调料后装入陶罐 | 2-3个月 |
| 冷冻 | 焯水、挤干水分后冷冻 | 数月 |

&nbsp;&nbsp;&nbsp;紫苏叶香味浓烈，很适合做酱菜和腌渍。泡在酱油里的紫苏叶本身就是一道小菜，酱油也染上香味，一举两得。晾干的紫苏叶香味会散失，但放进汤或粥里仍然有用。

## 16. 烹饪与加工 - 榨油

### 16-1. 炒还是不炒

&nbsp;&nbsp;&nbsp;榨油之前要决定的是炒还是不炒。这个选择会彻底改变榨出来的油的性质。

| 类别 | 炒后榨的油 | 不炒榨的油 |
|---|---|---|
| 香味 | 香味浓郁 | 几乎没有香味 |
| 颜色 | 深褐色 | 清澈的黄色 |
| 出油量 | 出油更多 | 出油较少 |
| 发烟点 | 低。不适合炒菜 | 高。可用于油炸 |
| 耐存放程度 | 炒制过程中会生成芝麻酚，反而更耐放 | 一般 |
| 主要用途 | 拌菜、最后淋在菜上的油 | 炒菜、油炸、油灯、肥皂 |

&nbsp;&nbsp;&nbsp;炒过之后出油更多，是因为热使细胞壁变软，细胞里的油滴相互合并。被困住的油在受压时有了出路；同样的道理，不炒就榨的话，残留在种子里的油会更多。

| 炒制要点 | 内容 |
|---|---|
| 火力 | 小火到中火 |
| 翻炒 | 不停翻炒。只有一边焦的话会有苦味 |
| 信号 | 发出噼噼啪啪的爆裂声，颜色变成浅褐色，散发出香味 |
| 收火时机 | 一开始上色就马上离火。靠余热也会继续熟下去 |
| 放凉 | 摊开放凉。堆着的话里面会继续熟而烧焦 |

### 16-2. 榨油的原理

&nbsp;&nbsp;&nbsp;榨油的原理很简单：把细胞里的油滴取到外面，汇集到一起使其流出。为此要捣碎、加热、压榨。

| 步骤 | 做什么 | 原因 |
|---|---|---|
| 捣碎 | 用臼或石磨把种子捣碎 | 必须破坏细胞壁，油才能出来。捣得越细，出油越好 |
| 加热 | 把捣碎的芝麻放在蒸笼里蒸，或在锅里加热 | 油的黏度降低，容易流动。蛋白质凝固，渣滓结成团 |
| 包裹 | 装进麻布或棉布袋 | 留住渣滓，只让油流出 |
| 压榨 | 用杠杆或楔子用力压 | 压力越大，出油越多 |
| 接油 | 用容器接住流出的油 | |
| 沉淀 | 放一两天，让渣滓沉下去 | 渣滓留着的话，油会很快变质 |
| 倒出 | 只倒出上面清澈的部分 | |

| 压榨方式 | 做法 | 出油量 |
|---|---|---|
| 杠杆压榨 | 把一根长圆木的一端卡在柱子上，另一端吊上重石。把袋子放在中间 | 种子重量的30-40% |
| 楔子压榨 | 把袋子放进圆木框中，用锤子把木楔打进去来压 | 35-45% |
| 螺旋压榨 | 用粗螺杆把板往下压。需要铁 | 40-50% |
| 手工扭绞 | 把袋子夹在两根棒子之间扭绞挤压 | 20-30% |

&nbsp;&nbsp;&nbsp;芝麻种子的含油量为45-55%，所以传统压榨相当于取出其中所含油的三分之二到75%。1kg可榨出350-450g，剩下的留在麻饼（芝麻饼）里。残留的油提高了麻饼作为饲料的价值，所以并不一定是损失。

### 16-3. 不压榨的方法

&nbsp;&nbsp;&nbsp;在做不出压榨工具的情况下，有一种方法可用，就是利用水把油浮出来。

| 步骤 | 方法 | 原理 |
|---|---|---|
| 捣碎 | 把炒过的芝麻捣细，做成糊状 | 破坏细胞 |
| 加水 | 一点一点加水，不断研磨 | 成为油和水混合的糊状 |
| 煮沸 | 倒入宽口锅，用小火煮 | 水沸腾时油滴相互合并 |
| 撇出 | 用勺子撇取浮到上面的油 | 油比水轻，所以会浮起来 |
| 熬干 | 把撇出的油再用小火加热，蒸发掉剩余水分 | 留有水的话油会变质 |

&nbsp;&nbsp;&nbsp;这是在非洲和印度长期使用的方法，优点是几乎不需要工具。缺点是出油量比压榨少，而且要消耗燃料；剩下的东西仍然可以当作麻饼使用。

### 16-4. 麻饼的用途

&nbsp;&nbsp;&nbsp;榨油后剩下的麻饼不是该丢弃的东西。原本种子的一半以上会作为麻饼留下，其中含有35-40%的蛋白质。

| 用途 | 内容 | 注意 |
|---|---|---|
| 人的口粮 | 捣碎后掺进粥或年糕里 | 蛋白质多，价值高。口感粗糙，放多了难以下咽 |
| 牲畜饲料 | 对鸡、猪、牛来说是良好的蛋白质来源 | 一次喂太多，会因为油而腹泻 |
| 肥料 | 氮约5-6%，磷酸约2%，钾约1% | 一定要沤熟后施用。生的在土里会发热，伤害根系 |
| 钓鱼窝料、诱饵 | 气味强烈，能引来鱼和虫子 | |
| 柴火 | 晒干后烧 | 还含有油，所以很好烧。有其他用途时不要烧 |

> **一袋芝麻可以分成油、饲料和肥料三份。丢掉麻饼，等于把榨出来的油那么多的价值又丢掉了一次。**

### 16-5. 灯油

&nbsp;&nbsp;&nbsp;在停电的夜晚，植物油可用来点灯照明。芝麻油自古就被用作油灯的灯油。

| 项目 | 内容 |
|---|---|
| 灯芯 | 用棉线、麻线或布搓成。越粗越亮，油也消耗得越快 |
| 容器 | 在浅碟或小碟中倒入油，把灯芯的一端浸入 |
| 原理 | 油沿灯芯线缝间被吸上去，火焰在灯芯顶端燃烧油 |
| 哪种油好 | 芝麻油油烟少，沿灯芯上升顺畅。紫苏油油烟多，灯芯上会结痂 |
| 用哪种油 | 先用难以食用的油和气味变了的油 |
| 亮度 | 一盏油灯约相当于一支蜡烛。把几盏聚在一起，可以照亮一个房间 |

&nbsp;&nbsp;&nbsp;需要事先定好顺序。油要先吃，难以食用的拿去点灯，再放过了这个阶段就做成肥皂。把好好的芝麻油一开始就拿去烧，等于是在烧热量。

### 16-6. 制作肥皂

&nbsp;&nbsp;&nbsp;油与强碱相遇就成了肥皂。这个反应在灾害情境中的意义重大。卫生一旦崩溃，腹泻病和皮肤病就会蔓延，而这往往比饥饿更早夺走人的性命。

| 步骤 | 方法 | 发生了什么 |
|---|---|---|
| 滤取草木灰水 | 把阔叶树的灰放进水中搅开，放一天后取上层清水 | 灰中所含的碳酸钾溶于水中析出。这就是草木灰水 |
| 苛化 | 在草木灰水中加入用贝壳或石灰石烧成的生石灰，搅拌后静置沉淀 | 碳酸钾变成氢氧化钾。白色沉淀是碳酸钙，让它沉下去后弃去 |
| 检验浓度 | 放入鸟羽毛或马铃薯，看它们的状态 | 羽毛开始溶蚀，或马铃薯浮出水面约硬币大小，就说明浓度足够 |
| 混合 | 把油加热，一点一点倒入草木灰水，不停搅拌 | 油中的脂肪遇碱分解为肥皂和甘油 |
| 熬煮 | 用小火边搅拌边煮几个小时 | 持续到反应结束。变得黏稠，颜色也随之改变 |
| 凝固 | 加盐后，肥皂凝结浮到上面 | 溶在水里的肥皂因盐而分离出来 |
| 收尾 | 捞出放进模具中凝固，或直接作为软皂使用 | 用草木灰水做的是软皂，加盐则会变硬 |

| 注意 | 内容 |
|---|---|
| 草木灰水会伤害皮肉 | 不要溅到眼睛和皮肤上。溅到时用水长时间冲洗，再用稀释的醋冲洗 |
| 避开金属容器 | 铝制容器会被腐蚀。要用铸铁锅或陶罐 |
| 未熟成的肥皂刺激性很强 | 残留碱会伤皮肤。放置几周熟成后再用 |
| 针叶树的灰较弱 | 阔叶树的灰碱性成分更多 |

> **做肥皂用油的顺序很明确。已经不能吃的油、动物油、从麻饼里榨出的残余油排在前面，好好的芝麻油排在最后。一升（韩国单位，约1.8升）油在变成肥皂之前，应当先变成饭桌上的菜。**

### 16-7. 直接吃种子的方法

| 方法 | 内容 | 燃料 |
|---|---|---|
| 炒后直接吃 | 把炒过的芝麻撒在饭或凉拌野菜（namul）上 | 几分钟 |
| 芝麻盐 | 把炒过的芝麻与盐一起捣碎 | 仅炒制的时间 |
| 芝麻粥 | 把炒过捣碎的芝麻在水里调开，加入大米煮 | 煮粥的时间 |
| 芝麻糖（kkaegangjeong） | 把炒过的芝麻拌上谷物糖浆（jocheong）使其凝固 | 熬糖浆的时间 |
| 磨碎放进汤里 | 把捣碎的芝麻放进汤或拌菜里 | 无 |

&nbsp;&nbsp;&nbsp;如果没有榨油的工具，捣碎后直接吃效率最高。因为这样在榨取过程中没有任何损失，蛋白质和纤维也一并吃下。不过整粒吞下的话种皮不会被消化，所以必须捣碎。

### 16-8. 紫苏叶的烹调

| 方法 | 内容 |
|---|---|
| 包菜（ssam） | 洗净后直接使用 |
| 酱菜 | 泡进酱油或大酱里。兼具贮藏作用 |
| 煎饼（jeon） | 裹上面粉糊煎 |
| 蒸菜（jjim） | 一层层抹上调料蒸熟 |
| 汤和炖菜（jjigae） | 最后放入。煮久了香味会散失 |
| 晾干的叶子 | 用水泡发后放进汤里 |

### 17-2. 贯穿一年的主线

&nbsp;&nbsp;&nbsp;芝麻的一年有三道关口：5月的起畦、7月的梅雨季、9月底的收获时机。

&nbsp;&nbsp;&nbsp;5月的起畦是一道看不见的关口。播种时，畦的高度似乎没有造成任何差别，这种差别要到两个月后的梅雨季才会显现。为省一锹土而把畦起得低，7月就会损失整块田。

&nbsp;&nbsp;&nbsp;7月的梅雨季是决定这种作物命运的时刻。能做的只有疏通排水沟、清除病株，其余的在5月就已经定了。

&nbsp;&nbsp;&nbsp;9月底的收获是要争分夺秒的关口。标准是下部蒴果有两三个裂开的那一刻，错过那几天，一年的收成就洒落在田里。养成从9月中旬起每隔三四天看一看下部蒴果的习惯，是最有价值的。

> **种芝麻，5月把畦起高，9月凭眼力判断时机收割。畦起得多高占一半，能察觉下部蒴果裂开的那一天占另一半。**
