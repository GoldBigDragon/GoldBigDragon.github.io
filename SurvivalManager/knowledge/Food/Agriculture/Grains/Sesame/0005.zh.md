## 9. 病虫害 - 不靠农药的防治方法

### 9-1. 芝麻是靠预防来保护的作物

&nbsp;&nbsp;&nbsp;芝麻一旦发病，实际上无法治疗，而且蔓延速度快。有报告称，病害流行时产量会下降25%左右，严重时整块田都会绝收。即使有农药也很难应对，因此在没有农药的情况下，除了预防别无他法。

| 病害 | 症状 | 何时发生 | 不用农药的应对 |
|---|---|---|---|
| 疫病 | 根和茎基部发黑腐烂，植株萎蔫 | 韩国的梅雨季（6月下旬至7月），积水时 | 把畦做高并保证排水。病株连土一起清走，拿到田外 |
| 枯萎病 | 先从一侧叶片开始萎蔫，剖开茎秆可见内部变褐 | 高温期、连作的田 | 无法治疗。3-4年轮作是唯一的对策 |
| 叶枯病 | 叶片上出现褐色斑点并扩大、干枯 | 湿度大时 | 保证通风，摘除病叶。不要密植 |
| 立枯病 | 幼芽的基部缢缩并倒伏 | 幼苗期 | 种子消毒是关键。不要密播，避免使用未腐熟的肥料 |
| 白粉病 | 叶片上出现白色粉末 | 夏末 | 保证通风。危害不大时可以不管 |

> **芝麻的病害对策，实际上可以概括为两点：把畦做高排水，以及休作3-4年。做到这两点，其余的病害就不会成为大问题。**

&nbsp;&nbsp;&nbsp;枯萎病值得单独说一说。这是土壤中的真菌从根部侵入并堵塞导管而引起的病害，这种真菌一旦定殖，就会在土中残留多年。评价表中连作适应性C所附的“芝麻因枯萎病病原残留，需休作3-4年”这条依据，指的就是这种病。无法用药剂治疗，抗病品种也并不完全可靠。除了换地，别无他法。

### 9-2. 主要害虫

| 害虫 | 危害 | 不用农药的应对 |
|---|---|---|
| 蚜虫 | 吸食嫩芽和叶背的汁液。干燥时增多 | 用强水流冲洗掉。喷洒肥皂水。保护瓢虫和草蛉 |
| 蝽象 | 把口针刺入正在成熟的蒴果，吸走里面的内容物 | 清晨用手捉。清理田边杂草 |
| 棉铃虫幼虫 | 啃食叶片和茎，并在蒴果上咬出洞 | 傍晚用手捉。把卵块连叶片一起摘除 |
| 斜纹夜蛾幼虫 | 啃食叶片。紫苏上也会有 | 方法相同 |
| 紫苏锈病 | 叶片上出现褐色斑点 | 保证通风，摘除病叶 |

### 9-3. 不用农药自制的防治材料

| 材料 | 制作方法 | 用于什么 | 原理 |
|---|---|---|---|
| 肥皂水 | 把20g无香料肥皂溶于1L水 | 蚜虫、螨 | 肥皂溶解虫体表面的油膜，堵住气门 |
| 草木灰 | 过筛后撒在叶片和地面上 | 爬行类害虫 | 灰会吸走虫体的水分 |
| 蒜水 | 把100g大蒜捣碎，泡入1L水中后滤出 | 驱避害虫 | 含硫化合物的气味能驱赶害虫 |
| 木醋液 | 稀释500-1,000倍 | 驱避、抑制霉菌 | 酸性和酚类成分起作用 |
| 波尔多液 | 把硫酸铜和生石灰溶于水中配成 | 预防叶枯病 | 铜能抑制孢子萌发 |
| 紫苏叶浸出液 | 把紫苏叶捣烂后泡在水中 | 驱避 | 紫苏醛的浓烈香气能驱赶害虫 |

&nbsp;&nbsp;&nbsp;最后一行是在这种作物内部实现循环闭合的例子。摘叶后剩下的老紫苏叶，或摘心时剪下的部分，不要丢弃，浸泡后使用就成了防治材料。它的效果不是杀死害虫，而是让害虫不来附着，但在一无所有的情况下是有价值的。

### 9-4. 种植前的预防方法

| 方法 | 内容 |
|---|---|
| 种子消毒 | 温汤处理和草木灰。立枯病是随种子传入的 |
| 轮作 | 芝麻要休作3-4年。这是应对枯萎病和疫病的全部办法 |
| 排水 | 把畦做高、把沟挖深。这是应对疫病的全部办法 |
| 不密植 | 通风可以防止霉菌类病害 |
| 覆盖防溅泥 | 铺上稻草或干草，可防止雨滴溅起泥土、把病传到叶片上 |
| 病株清出田外 | 把病株丢在田里，病原菌就会原样留下 |

## 10. 营养缺乏与过量

### 10-1. 解读缺素症状

| 症状 | 最先出现在哪里 | 原因 | 为什么 | 天然材料的处理 |
|---|---|---|---|---|
| 整片叶子发黄，植株矮小 | 从下部老叶开始 | 缺氮 | 氮在体内可以转移，会从老叶中抽出送往新叶 | 稀释尿液、发酵好的麻饼（芝麻饼）、腐熟堆肥 |
| 叶缘变褐焦枯 | 从下部叶片开始 | 缺钾 | 钾的移动性也很大，老叶先被牺牲 | 少量撒草木灰 |
| 叶色暗并带紫色，生长缓慢 | 整株 | 缺磷 | 有时是低温下磷吸收下降所致 | 骨粉、草木灰 |
| 花开后直接掉落 | 花 | 缺磷或缺硼 | 花粉发育不良，或无法完成受精 | 混合多种材料的堆肥、骨粉 |
| 新叶发黄而叶脉仍为绿色 | 从上部新叶开始 | 缺铁 | 铁不易转移，新叶先挨饿 | 减少草木灰，施入有机物 |
| 嫩芽尖端干枯扭曲 | 生长点 | 缺钙或缺硼 | 随水流移动，很难到达嫩芽 | 烧制的贝壳、蛋壳粉 |
| 结了蒴果但籽粒空瘪 | 蒴果 | 缺钾或蝽象危害 | 用于成熟的养分不足，或被吸走了 | 草木灰。先检查有无蝽象 |

&nbsp;&nbsp;&nbsp;解读症状时最有用的线索，是症状最先出现在哪里。如果从老叶开始受损，说明缺的是在植物体内容易移动的养分（氮、磷、钾、镁）；如果从新叶开始受损，说明缺的是不易移动的养分（铁、钙、硼）。

&nbsp;&nbsp;&nbsp;不过，芝麻有一个陷阱。上述症状中相当一部分与疫病或枯萎病的初期症状无法区分。整株萎蔫时，应首先怀疑是病害而不是养分问题，尤其是从一侧叶片开始萎蔫的，几乎都是枯萎病。把茎纵向剖开，若内部变褐，就是病害。分不清这一点而去施肥，只会助长病害。

### 10-2. 过量症状

| 症状 | 原因 | 为什么 | 处理 |
|---|---|---|---|
| 只长高，茎发软倒伏 | 氮过量 | 细胞壁被拉薄，组织变弱 | 停止施氮。用培土来支撑 |
| 叶片茂盛但蒴果少 | 氮过量 | 资源偏向茎叶，没有用于结实 | 提前摘心 |
| 叶色墨绿，蚜虫聚集 | 氮过量 | 汁液中氨基酸增多，蚜虫喜好 | 同样的处理 |
| 开花晚，成熟期拉长 | 氮过量 | 营养生长持续，无法转入生殖生长 | 停止施氮并摘心 |
| 叶缘干枯，根变褐 | 肥料浓度过高 | 土壤盐分浓度升高，水从根部渗出 | 充分浇水冲洗 |

> **芝麻出现的养分问题，大部分不是缺乏，而是氮过量。只施一次基肥、不再追肥，是这种作物的基本做法。**

### 10-3. 叶用紫苏则相反

&nbsp;&nbsp;&nbsp;叶用紫苏的叶片本身就是收获物，所以要持续供氮。每摘一次叶，植株就失去一部分身体，需要重新长出来，而其材料就是氮。标准是每隔10-15天少量施用，稀释尿液或浸草液肥比较合适。不过氮过多会使叶片积累硝酸盐，所以收获前不要施用。

## 11. 间作与轮作

### 11-1. 搭配是否合宜

| 搭配度 | 作物 | 会发生什么 |
|---|---|---|
| 好 | 豆科（豇豆、绿豆、大豆） | 根瘤固定的氮有一部分释放到土中。芝麻需氮少，竞争小 |
| 好 | 沿田边环植 | 芝麻和紫苏的浓烈香气使獐子和野猪不愿靠近 |
| 好 | 甘薯、马铃薯 | 根的深度不同，根层不重叠 |
| 一般 | 玉米、高粱 | 植株高大，会遮挡芝麻。布置在北侧就没问题 |
| 差 | 连续种芝麻 | 枯萎病和疫病会在土中积累 |
| 差 | 与需要灌水的作物并排 | 从旁边渗来的水会浸湿芝麻的畦 |
| 差 | 紧接在茄科（辣椒、番茄、马铃薯）之后 | 土壤病害有重叠之处 |

&nbsp;&nbsp;&nbsp;环植在灾害情境下能带来实实在在的好处。评价表中非食用价值C所附的“强烈的香气有驱避效果”这条依据，说的就是这件事。在既没有围栏也没有网的情况下，保护田地的手段并不多。沿着田边种一圈芝麻或紫苏，可以在一定程度上减少獐子和野猪进入。虽不能完全挡住，但总比什么都不做强，还能顺带得到油。

### 11-2. 轮作

&nbsp;&nbsp;&nbsp;评价表中的连作适应性为C，依据是“芝麻因枯萎病病原残留，需休作3-4年。在油料作物中连作障碍偏大”。在本文所涉及的作物中，它的休作期属于最长之列。叶菜类为1-2年，籽粒苋为2年，而芝麻为3-4年。

| 年 | 种植的作物 | 有什么收益 |
|---|---|---|
| 第1年 | 芝麻 | 得到油。深根使土壤深层疏松 |
| 第2年 | 豆科（大豆、豇豆、绿豆） | 补回芝麻消耗的氮 |
| 第3年 | 十字花科或葫芦科 | 属于不同类群，病原菌不会延续 |
| 第4年 | 谷物（高粱、粟（谷子）、玉米） | 属于禾本科，土壤病害不同 |
| 第5年 | 回到种芝麻 | |

&nbsp;&nbsp;&nbsp;如果田地太小，无法轮作四年，可以逐年挪换种芝麻的位置。把田分成四个区块，每年只在一个区块种芝麻，那么每个区块每4年才轮到一次芝麻。全部面积中只有25%种芝麻，但如果目的是取油，这样的面积往往已经足够。

&nbsp;&nbsp;&nbsp;紫苏不像芝麻那么挑剔，休作2年左右即可。于是人们会想把芝麻和紫苏在同一块地上交替种植，但这最好避免。二者虽不同科，却有重叠的土壤病害，而且最重要的是，对芝麻所需要的3年休养来说，紫苏起不到帮助作用。

## 12. 收获 - 下部蒴果开裂时

### 12-1. 何时收割

&nbsp;&nbsp;&nbsp;芝麻栽培全过程中最难的判断就是收获时机。因为蒴果由下向上依次成熟，而成熟的蒴果会自行裂开，把种子撒落出来。

| 判断标准 | 内容 |
|---|---|
| 蒴果 | 茎下部的两三个蒴果开始裂开 |
| 叶 | 下部叶片变黄并开始脱落 |
| 茎的颜色 | 绿色褪去，从下部开始转黄 |
| 时期 | 在韩国大致为9月底至10月初 |
| 种子 | 掰开蒴果，若种子呈现本来的颜色且坚硬，就是成熟了 |

> **收获的标准不是上部蒴果是否全部成熟，而是下部蒴果是否开始裂开。等上部成熟，下部就全丢了。**

&nbsp;&nbsp;&nbsp;在这个时点收割，上部蒴果还没有完全成熟。不过，在割下后竖立晾干的过程中，上部蒴果会靠茎里剩余的养分继续成熟。这称为后熟，也是把芝麻连根拔起或用镰刀割下、捆成束竖起晾放的做法长期沿用的原因。

### 12-2. 收割要领

| 项目 | 内容 | 原因 |
|---|---|---|
| 天气 | 选阴天 | 阳光强烈时蒴果会晒得干透，一碰就会爆裂 |
| 时刻 | 在清晨或傍晚收割 | 露水使蒴果潮软，不易爆裂 |
| 割取位置 | 贴近地面处割 | 茎秆长才便于捆成束竖起 |
| 处理方式 | 不要放倒，保持站立姿势收拢 | 一放倒或摇晃，种子就当场撒出 |
| 承接 | 搬运时在下面垫布或袋子 | 接住搬运过程中掉落的种子 |

&nbsp;&nbsp;&nbsp;选阴天的清晨或傍晚，这一点是这种作物收获的核心。芝麻的蒴果干了就裂开，吸了潮气又会合拢。有露水的早晨，蒴果是闭合的，容易处理；而在正午被阳光晒得干透的状态下，稍一擦碰就会撒落。同一块田、同一个人去割，因时刻不同，损失也会相差好几倍。

### 12-3. 竖立晾干与脱粒

| 步骤 | 方法 | 原因 |
|---|---|---|
| 捆束 | 每五六株一束，在下部用稻草或绳子捆住 | 防止散开，也便于竖立 |
| 竖立 | 三四束互相靠拢，竖成圆锥形 | 即使下雨，水也能顺势流下，里面也能通风 |
| 地点 | 竖在阳光充足、通风良好的院子或田头 | 放在阴处不易干，容易发霉 |
| 承接 | 下面铺上草席（稻草编的席子）或布 | 接住晾干期间自然掉落的种子 |
| 时间 | 7天至15天 | 放到蒴果大部分裂开为止 |
| 防雨 | 有降雨预报时就盖上或收进屋里 | 一旦淋湿，蒴果会重新合拢，种子会变质 |

| 脱粒步骤 | 方法 |
|---|---|
| 第1次 | 在草席上把束倒提，用木棒轻轻敲打茎秆 |
| 第2次 | 重新竖起再晾两三天，然后重复 |
| 第3次 | 上部蒴果裂开后再敲打一次 |
| 收尾 | 用手把剩下的蒴果捋下来，或连茎搓揉下来 |

&nbsp;&nbsp;&nbsp;一次打不干净是正常的。下部的蒴果第一次就全部出来了，上部的要再晾几天才会裂开。嫌两三次重复麻烦，一次用力敲打的话，茎和叶的碎屑会一起掉下来，反而使挑拣更费力。轻敲多次才是要领。

### 12-4. 清选

| 方法 | 内容 |
|---|---|
| 过筛 | 用粗筛筛去茎和蒴果碎片 |
| 簸扬 | 装进簸箕里扬簸，轻的壳就会飞走。芝麻种子比籽粒苋重，簸扬效果很好 |
| 借风力 | 在有风的日子从高处缓缓倒下，壳会被吹向一边 |
| 水洗 | 放入水中搅拌，壳和灰尘浮起，种子沉底 |
| 晾干 | 水洗过的要马上摊开，彻底晾干 |

> **芝麻用水洗过之后，必须当天晾干。含油量高的种子带着水分堆放，就会发热、长霉，一旦如此，油就会发出异味而无法使用。**

### 12-5. 叶用紫苏的采收

| 项目 | 内容 |
|---|---|
| 开始 | 从真叶长到四片左右时开始 |
| 适期 | 叶片完全展开，叶面呈鲜绿色，叶脉带紫色时，大小7-10cm |
| 方法 | 一定要留下上部尚未完全展开的幼叶两到四片，只摘下部的大叶 |
| 间隔 | 夏季每3天至5天一次 |
| 期间 | 在韩国为6月下旬至9月下旬 |

&nbsp;&nbsp;&nbsp;留下上部的两到四片幼叶，是反复采收的关键。这些叶片持续进行光合作用，长出后续的叶子。贪心把顶部也全摘光，植株就无法恢复，从此停滞。

## 13. 留种与种子保存

### 13-1. 留种

| 步骤 | 方法 | 原因 |
|---|---|---|
| 选株 | 选没有病害、结蒴果多、没有倒伏的植株 | 种子像它的亲本。得过枯萎病的植株绝对不能用 |
| 做标记 | 在开花期预先做好标记 | 到收获时难以分辨 |
| 从哪里取种 | 取茎中部的蒴果 | 下部的先撒落，上部的不够饱满。中部的最充实 |
| 充分成熟 | 放到蒴果完全干成褐色为止 | 未成熟的种子发芽力低 |
| 套袋 | 在要留种的茎上套布袋并扎紧 | 接住自行裂开撒落的种子 |
| 晾干 | 在阴凉处晾到水分12%以下 | 在阳光下放久了油会变质 |
| 保存 | 装入密封容器，放在阴凉黑暗处 | 光、热和空气会使油变质 |

&nbsp;&nbsp;&nbsp;评价表中的自家留种S，依靠的是芝麻和紫苏都以自花授粉为主这一点。蜂类虽然也会传粉，但大部分在自己的花内就完成了受精，所以品种不会大量混杂。即使把几个品种放在同一块田里，也能分别留种。

&nbsp;&nbsp;&nbsp;不过，选留种用的植株时，有一点需要特别留意。有枯萎病迹象的植株，绝对不能留种。这种病也会通过种子传播，所以把病株上收的种子在第二年播到新田里，连那块新田也会被污染。即便严格地按3年、4年轮作，也会因为这一点而前功尽弃。

### 13-2. 保存

| 条件 | 发芽力保持的时间 |
|---|:---:|
| 彻底晾干后密封，放在阴凉黑暗处 | 1-2年 |
| 直接放在常温下 | 不足1年 |
| 受阳光或热源照射的地方 | 几个月 |

&nbsp;&nbsp;&nbsp;评价表中的种子寿命C，即“油料种子寿命短，常温下1-2年”，是这种作物最沉重的制约之一。这与籽粒苋种子能保存3-5年、羽衣甘蓝能保存4-5年大不相同。原因在于油。种子里的油接触空气氧化后会产生过氧化物，损伤种子内的胚。含油越多的种子寿命越短，是整个油料作物通用的规律。

> **芝麻是种子不能久存的作物。必须年年留种、年年播种，跳过一年，再下一年就不会出苗了。**

| 延长寿命的方法 | 原理 |
|---|---|
| 彻底晾干后再装 | 残留水分会加快氧化 |
| 密封以隔绝空气 | 有氧气，油才会氧化 |
| 放在阴凉处 | 温度每升高10℃，氧化速度就加倍 |
| 避光放置 | 光会促进氧化 |
| 使用未炒过的 | 炒过后细胞破裂，油暴露在空气中。留种用的绝对不要炒 |
| 多留一些 | 考虑到发芽率会下降，按所需量的两倍留种 |
