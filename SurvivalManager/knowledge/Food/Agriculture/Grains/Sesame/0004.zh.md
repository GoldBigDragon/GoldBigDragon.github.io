## 5. 整地与施肥

### 5-1. 选地

&nbsp;&nbsp;&nbsp;选择芝麻的种植地，第一个也是几乎唯一的条件是排水是否良好。光照和肥力排在其后。在容易积水的水田地块、低洼地和黏质土的田里，不管其他条件多么好，都不种。坡地的上部、掺有沙的田地、略有坡度的地方，对芝麻来说是上等的地块。

&nbsp;&nbsp;&nbsp;紫苏的情况稍好一些。它对湿度有一定的耐受力，因此可以把紫苏安排在不适合芝麻的地方。不过紫苏被水淹后根也会受损，所以这只是相对较好，并不意味着可以随便种在任何地方。

### 5-2. 把畦做高

| 项目 | 芝麻 | 原因 |
|---|---|---|
| 耕深 | 20-30cm | 主根扎得深，才能耐旱 |
| 畦高 | 20-30cm以上 | 使根系所在的土层不被水淹 |
| 畦宽 | 55-60cm | 每畦种一行或两行 |
| 沟 | 开得又深又宽 | 供雨水不积存、顺利排走的通道 |
| 排水沟 | 沿田边围一圈开挖 | 挡住外面流入的水，排出田内的水 |
| 田外水道 | 把上方流下来的水引开 | 在坡地上尤其重要 |

&nbsp;&nbsp;&nbsp;要留意的是，20-30cm的畦高标准高于其他作物。大白菜为15cm，辣椒为20cm左右，而芝麻比它们都高。原因很简单：大雨后即使沟里积满了水，畦上的根系层也必须留在水面之上。

> **芝麻田里最重要的作业，既不是播种，也不是施肥，而是把畦做高、把沟挖深。这一点决定了田地能否撑过韩国的梅雨季（6月下旬至7月）。**

&nbsp;&nbsp;&nbsp;如果能弄到塑料薄膜，把它覆盖在畦上会有帮助。它能提高地温，加快早期生长，防止雨水直接渗入畦内，并抑制杂草。没有薄膜的情况下，可以用稻草或干草代替，但没有提高地温的效果，只能起到抑制杂草和防止泥土溅起的作用。防止泥土被雨滴溅到叶片上，这件事比想象的更重要，因为疫病菌存在于土壤中，会随溅起的泥土转移到叶片上。

### 5-3. 施肥量

| 肥料 | 芝麻（1,000㎡） | 叶用紫苏（1,000㎡） |
|---|:---:|:---:|
| 堆肥 | 1,000-2,000kg | 1,500kg |
| 复合肥 | 30-35kg | 20-30kg |
| 基肥 | 播种前2周全部施入 | 全部 |
| 追肥 | 一般省略 | 到采收期为止，每隔10-15天少量施用 |

&nbsp;&nbsp;&nbsp;引人注目的是，芝麻和叶用紫苏的施肥方式正好相反。芝麻只施一次基肥，几乎不追肥。叶用紫苏则是每次摘叶后都少量补施。这是因为二者的目的不同。芝麻氮肥过多，茎叶就会徒长，蒴果发育不良，也容易倒伏。叶用紫苏的叶片茂盛就是收获，所以需要持续供氮。

&nbsp;&nbsp;&nbsp;评价表中的施肥需求A（每㎡18g）属于较少的。与无合成投入产量保持率A（56%）一并来看，就能明确这种作物并不太依赖肥料。它原本生长在贫瘠干旱地区的来历，依然保留着。

### 5-4. 没有化肥时

| 替代资源 | 提供的养分 | 使用方法 | 注意事项 |
|---|---|---|---|
| 腐熟堆肥 | 综合 | 作基肥足量施入 | 未腐熟的会伤根并引发疫病 |
| 草木灰 | 钾、磷、钙 | 每㎡取一把拌入基肥 | 呈碱性，施多了会使pH升高 |
| 麻饼（芝麻饼） | 氮、磷 | 将榨油后剩下的渣发酵后作基肥 | 未发酵的施入后会在土中发热，伤根 |
| 稀释尿液 | 氮、钾 | 稀释10至20倍后喷洒 | 芝麻只在早期少量使用 |
| 骨粉 | 磷、钙 | 烧后捣碎拌入基肥 | 见效缓慢 |
| 浸草液肥 | 氮 | 发酵2周后稀释使用 | 适合作叶用紫苏的追肥 |

&nbsp;&nbsp;&nbsp;把麻饼用作肥料这一点值得单独说一说。榨油后剩下的麻饼含氮5-6%，比一般的有机肥料更好。不过直接施入田中，会在土里迅速腐烂，产生热和气体，伤害根系。要先加水沤制一个月以上，或者掺入堆肥堆中一起沤熟后再用。把麻饼再施回芝麻田，等于让循环闭合，但由于必须避免连作，实际上还是用在别的作物上更好。

## 6. 播种

### 6-1. 种植时期

| 作物 | 播种时期（韩国） | 收获时期（韩国） | 标准 |
|---|---|---|---|
| 芝麻 | 5月中旬至6月上旬 | 9月底至10月初 | 气温15℃以上，地温接近20℃时 |
| 叶用紫苏 | 4月下旬至5月上旬 | 6月下旬至9月下旬 | 霜冻风险过去之后 |
| 油用紫苏 | 5月至6月 | 10月 | 晚种也可以 |

&nbsp;&nbsp;&nbsp;在韩国，芝麻播种晚到5月中旬以后，有两个原因。一是地温。土壤不够暖，出苗就会延迟且不整齐，还会发生立枯病。二是要让开花和成熟的时期相匹配。芝麻的花期在7-8月，成熟需要20-28℃。种得太早，开花会碰上梅雨，花就会掉落；种得太晚，成熟又会遇上秋季的凉爽天气。

### 6-2. 芝麻播种

| 项目 | 标准 | 原因 |
|---|---|---|
| 畦距 | 55-60cm | 保证通风，减少湿气 |
| 株距 | 15-20cm | Oedae-kkae（单秆型）取窄，Gaji-kkae（分枝型）取宽 |
| 播种深度 | 2-3cm | 种子虽小，但不像籽粒苋那样小，能承受这个深度 |
| 每穴粒数 | 5-6粒 | 之后只留一株壮苗 |
| 播种量 | 每1,000㎡0.3-0.6kg | 种子小，用量少就能种很大面积 |
| 镇压 | 播种后轻轻压实 | 种子与土壤贴紧，才能吸收水分 |

### 6-3. 叶用紫苏播种

| 项目 | 标准 | 原因 |
|---|---|---|
| 种植间距 | 10 × 5cm或7 × 7cm | 以摘叶为目的的栽培，所以密植 |
| 播种深度 | 0.5-1cm | 比芝麻浅 |
| 每穴粒数 | 5-6粒 | 间苗后留一株 |
| 发芽管理 | 盖上稻草、布或报纸 | 目的是保持表土不干。出芽后立即揭去 |

&nbsp;&nbsp;&nbsp;揭开覆盖物的时机很重要。出芽之后如果仍盖着，幼茎会为了找光而细长徒长，进而倒伏。掀开土层看到芽开始露头时，当天就要揭掉。

### 6-4. 种子处理

| 方法 | 步骤 | 效果 |
|---|---|---|
| 浸水选种 | 浸水3-4小时，只用沉底的 | 空心的瘪籽会浮起来。发芽率提高 |
| 温汤处理 | 在50-55℃的水中浸10-15分钟 | 减少种皮上附着的病原菌。对预防立枯病尤其重要 |
| 拌草木灰 | 把洗净甩干水的种子拌上细灰 | 兼起消毒作用，并使种子不互相粘连 |

> **对芝麻来说，种子消毒不是可选项。立枯病是通过种子传播的病害，幼苗期一旦蔓延，那块地就得整片重种。没有农药时，就用温汤处理和草木灰来代替。**

&nbsp;&nbsp;&nbsp;温汤处理中，温度是关键。超过55℃，种子的胚会死亡；低于45℃，病原菌会存活下来。没有温度计的话，就把开水和冷水兑在一起，以把手伸进去时觉得烫但不至于烫伤、也就是难以长时间浸泡的程度为准。处理过的种子要立即摊开晾干后再播。

### 6-5. 间苗

| 作物 | 次数 | 时期 | 保留的株 |
|---|---|---|---|
| 芝麻 | 第1次 | 真叶2-4片 | 每穴留最壮的一株 |
| 叶用紫苏 | 第1次 | 真叶1-2片 | 大致调整间距 |
| 叶用紫苏 | 第2次 | 真叶4-6片 | 每穴留一株 |

&nbsp;&nbsp;&nbsp;芝麻只间一次苗就完事。间苗时机晚了，幼苗会相互争光而徒长变细，这样长出来的茎之后承受不住蒴果的重量而倒伏。真叶长到2片至4片之间正是时机，错过这个时机，拔苗时会连旁边植株的根也被带起来。

## 7. 水分管理 - 比干旱更可怕的渍害

### 7-1. 渍害为何致命

&nbsp;&nbsp;&nbsp;芝麻是耐旱怕水作物的典型。这两种特性源自同一种根系结构。要在干燥土地中寻找水分，根就得又深又粗地向下扎，而这样的根活动旺盛，耗氧也多。土壤孔隙被水占满、空气被挤出时，根细胞立刻就会窒息。

| 时间 | 会发生什么 |
|---|---|
| 淹水数小时 | 根部的氧气耗尽，养分吸收停止 |
| 一天 | 叶片开始萎蔫。明明水很多，看上去却像缺水 |
| 两天 | 根尖变褐并开始腐烂 |
| 三天以上 | 疫病菌侵入受损的根，一直蔓延到茎基部 |
| 水退之后 | 一出太阳，剩下的根承受不了，反而急剧萎蔫 |

&nbsp;&nbsp;&nbsp;最后一行是最常见的失败场景。梅雨季结束、太阳出来后，田地常常一下子全面崩溃，这并不是因为水退了情况好转，而是因为受损的根承受不了骤然增大的蒸腾。这时能做的事不多。从一开始就把畦做高，使水到不了根系层，是唯一的对策。

### 7-2. 分时期的水分管理

| 时期 | 芝麻 | 叶用紫苏 |
|---|---|---|
| 播种至发芽 | 保持表土不干 | 充分浇透 |
| 幼苗期 | 节约用水。让根为找水而向下扎 | 保持不干 |
| 营养生长期 | 听任自然降雨。只要不积水就行 | 表土发白时浇透 |
| 开花·结实期 | 只在严重干旱时补水 | 保持叶片不萎蔫 |
| 梅雨季 | 整修沟和排水沟 | 相同 |
| 成熟期 | 不浇水 | 不适用 |

&nbsp;&nbsp;&nbsp;幼苗期要节约用水，这一点与其他作物不同。给幼小的芝麻频繁浇水，根就会停留在表土而不向下扎。这样长大的植株，以后一遇干旱就会立刻垮掉。出苗之后，反而让土壤稍干一些，使根为找水而向下伸展，效果更好。

### 7-3. 梅雨季的防备工作

| 作业 | 时期 | 内容 |
|---|---|---|
| 清沟 | 梅雨季前 | 清除沟里堆积的土和草，疏通水路 |
| 挖排水沟 | 梅雨季前 | 沿田边围一圈开沟，开出排水的通道 |
| 开截水沟 | 梅雨季前 | 在坡地上，把从上方流下的水引向一侧 |
| 培土 | 在韩国为6月 | 把土聚拢到植株基部，重新把畦培高。把被雨水冲掉的部分补回来 |
| 扶起倒伏的植株 | 刚下过雨后 | 趁土壤松软时扶正并踩实 |
| 清除病株 | 一经发现立即处理 | 患疫病的植株要拔起并拿到田外 |

&nbsp;&nbsp;&nbsp;最后一行尤为重要。疫病蔓延速度快，实际上没有治疗的办法。一旦在某一株上发现，就要把这一株连同周围的土一起清走，运到田外烧掉或深埋。若留在田里，就会被雨水冲刷，蔓延到下方的植株。

### 7-4. 缺水时

| 症状 | 发生了什么 |
|---|---|
| 中午叶片下垂，傍晚恢复 | 暂时性缺水，尚未造成损伤 |
| 下部叶片先变黄并脱落 | 长期缺水。植株舍弃叶片以减少蒸腾 |
| 花开后直接掉落 | 开花期干旱。蒴果数量减少 |
| 结了蒴果但籽粒不饱满 | 成熟期干旱。含油量也会随之下降 |
| 植株矮小，节间短 | 从早期起就持续缺水 |

&nbsp;&nbsp;&nbsp;芝麻最需要水的时期是开花期和成熟初期。这一时期的干旱会直接减少蒴果数量和籽粒大小，还会降低含油量。如果有条件浇水，在这一时期浇一两次，比其他任何时候都更有效。不过要避免往沟里灌水，在根的周围浇灌更为安全。往沟里灌满水，水会渗进畦内，带来渍害的风险。

## 8. 栽培管理 - 以摘心统一成熟期的原理

### 8-1. 为什么要摘心

&nbsp;&nbsp;&nbsp;芝麻栽培管理中最重要的一项作业就是摘心。原因在于第2节中讲到的无限花序这一特性。只要茎尖还在生长，芝麻就会不断开新花。花由下向上依次开放，在下部蒴果成熟的同时，上部仍在开新花。

| 不摘心 | 摘心 |
|---|---|
| 花期持续30-40天以上 | 从切除之时起就停止开花 |
| 资源也被分给后开的花 | 资源集中到已结的蒴果上 |
| 籽粒普遍偏小 | 籽粒变大 |
| 成熟期相差很大 | 成熟期集中 |
| 收获时机难判断，损失大 | 收获一次就能完成 |
| 植株长高，容易倒伏 | 植株较矮，不易倒伏 |

&nbsp;&nbsp;&nbsp;用一句话概括这一原理就是：植物总想开出超过自己所能结实的花，人则要在某一时点将其截断，让种子只充实到这一时点为止。截断得晚，效果就小；截断得早，就会损失本来能结的蒴果。

| 项目 | 标准 |
|---|---|
| 时期 | 首花开放后35-40天 |
| 方法 | 用手摘掉或用剪刀剪去茎尖的嫩芽 |
| 剪切位置 | 在最上面的花蕾下方截断 |
| Gaji-kkae的情况 | 侧枝的顶端也一并剪去 |
| 天气 | 选晴天上午进行。切口愈合快 |

> **芝麻摘心，就是替植物掐断它的贪心。若要把后开的花也全部充实，所有籽粒都会变小，只有在某一界限处截断，先结的那些才能真正成熟饱满。**

&nbsp;&nbsp;&nbsp;还有另一种确定摘心时机的办法。如果不记得首花开放的日子，就从茎的下部开始数蒴果，以结了20到25个左右时为准。结得比这更多，也无法全部成熟。

### 8-2. 叶用紫苏的摘心

&nbsp;&nbsp;&nbsp;叶用紫苏摘心的目的不同。不是为了让种子长大，而是通过增加侧芽来增加长叶的位置，并降低株高以防倒伏。

| 项目 | 标准 |
|---|---|
| 时期 | 株高超过1m时 |
| 方法 | 剪去顶芽 |
| 效果 | 侧芽增多，叶片采收量增加，倒伏减少 |

### 8-3. 防止倒伏

&nbsp;&nbsp;&nbsp;芝麻株高超过1m，茎又细，遇到风雨很容易倒伏。一旦倒下，蒴果触地，种子就会腐烂或埋入土中，茎折断的地方还会染病。

| 方法 | 时期 | 内容 |
|---|---|---|
| 培土 | 株高30-40cm | 把土聚拢堆到植株基部。同时也是把畦重新培高的作业 |
| 减少氮肥 | 从一开始 | 氮多了茎会发软，容易倒伏 |
| 不密植 | 播种时 | 过密则相互争光，长得又细又长 |
| 摘心 | 首花后35-40天 | 降低株高 |
| 拉绳 | 株高80cm以上 | 在行的两端打桩，横向拉绳支撑 |

&nbsp;&nbsp;&nbsp;在没有工具的情况下，最省钱的对策是培土和减少氮肥。两者都不需要材料，尤其是培土与重新把畦培高是同一个动作，因此兼顾了梅雨季的防备。

### 8-4. 杂草管理

| 时期 | 方法 | 备注 |
|---|---|---|
| 播种前 | 翻耕，待杂草萌芽后再浅刮除去 | 大大减轻前期负担 |
| 幼苗期 | 用手或homi（韩国的小锄头）在行间浅刮 | 芝麻根浅的时期，不要刮得太深 |
| 真叶5片以后 | 结合培土除草 | 一个动作完成两件事 |
| 植株封行后 | 几乎不需要 | 芝麻形成荫蔽，抑制杂草 |
