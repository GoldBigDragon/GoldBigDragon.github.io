## 2. どんな植物か

### 2-1. 二つの植物、一つの名前

&nbsp;&nbsp;&nbsp;「ケ（kkae）」という名前でひとくくりにされる二つの植物は、分類上かなり離れています。

| 区分 | ゴマ | エゴマ |
|---|---|---|
| 学名 | Sesamum indicum | Perilla frutescens |
| 科 | ゴマ科（Pedaliaceae） | シソ科（Lamiaceae） |
| 原産地 | アフリカからインドにかけての乾燥地 | 東アジア |
| 主な用途 | 種子からゴマ油 | 種子からエゴマ油、葉はケンニプ（エゴマの葉） |
| 油の性質 | 酸敗が遅く、半乾性油です | 酸敗が早く、乾性油です |
| 葉 | 細い披針形で毛があります。食べることもありますが、主な用途ではありません | 幅の広いハート形で、縁に鋸歯があります。主要な野菜です |
| 開花 | 韓国では7-8月 | 韓国では8-9月 |
| 湿害 | 極端に弱いです | 比較的耐えます |
| 干ばつ | きわめて強いです | 普通です |

&nbsp;&nbsp;&nbsp;二つは同じシソ目に属し、茎が四角く葉が対生するという共通点があります。しかし、栽培では別々の作物として扱う必要があります。ゴマには乾いて日当たりのよい場所を、エゴマにはやや湿っていてもよい場所を割り当てます。ゴマは3-4年休ませなければなりませんが、エゴマはそこまで厳しくありません。

&nbsp;&nbsp;&nbsp;ここにもう一つ区別を加える必要があります。エゴマは、種子を採る油用エゴマと、葉を採る葉用エゴマに分かれます。品種が異なり、栽培方法も異なります。油用エゴマの葉は硬くてサム（葉で包んで食べる料理）には使いにくく、葉用エゴマは種子の収量が少なくなります。目的を決め、それに合った品種を選ぶ必要があります。

### 2-2. ゴマの形態

| 器官 | 特徴 |
|---|---|
| 葉 | 細い披針形です。下のほうは幅が広く、上に行くほど細くなります。表面に細かい毛があり、厚みがあります |
| 茎 | 四角く、まっすぐに立ちます。高さは60-150cmです。一本立ちで育つ系統と、枝分かれする系統があります |
| 根 | まっすぐな主根が深く伸びます。乾いた土地で水を探す力が強いです |
| 花 | 白色または淡いピンク色の筒状です。葉腋ごとに、下から上へ順に咲きます |
| 果実 | 蒴果です。長さ2-3cmの円筒形で、葉腋ごとにつきます。熟すと上部の縫合線が裂けます |
| 種子 | 長さ3mm前後の平たい水滴形です。白、黄、茶、黒の系統があります |

&nbsp;&nbsp;&nbsp;ゴマの葉に細かい毛があり厚いことは、この作物の耐乾性を生み出す構造の一つです。毛は葉の表面に空気の層をとどめて風が直接当たるのを防ぎ、厚い葉は水を蓄えます。砂漠や乾燥地の植物によく見られる造りです。

&nbsp;&nbsp;&nbsp;もっとも重要な構造は蒴果です。ゴマの果実は熟すと先端が縦に割れて開きます。その状態で茎に触れると種子がこぼれます。これを裂開といい、野生植物が種子を散らす正常な方法です。栽培品種でもこの性質はほとんどそのまま残っています。第12節の収穫の要領は、すべてこの一つの事実から出てきます。

> **ゴマの蒴果は、熟すと開くのが正常です。収穫とは、この開きより一歩先に行う作業であり、遅れると畑にすべてこぼしてしまいます。**

### 2-3. 無限花序という性質

&nbsp;&nbsp;&nbsp;ゴマのもう一つの重要な性質は、花が一斉には咲かないことです。茎の下のほうの葉腋から先に花が咲き、上に向かって順に咲いていきます。茎の先端の生長点が伸び続ける限り、花は咲き続けます。これを無限花序といいます。

| 結果 | 何が起こるのか |
|---|---|
| 開花期が長くなります | 30-40日にわたって花が咲きます |
| 登熟がそろいません | 下の蒴果がすべて熟したとき、上の蒴果はまだ緑色です |
| 収穫時期が定めにくくなります | 上を待てば下がこぼれ、下に合わせれば上が熟しきりません |
| 資源が分散します | 株が遅く咲いた花にも資源を分け与えるため、粒がそろって小さくなります |

&nbsp;&nbsp;&nbsp;この問題を解く方法が摘心です。茎の先端を切り取ると、それより上には花がもう咲かず、株が持つ資源がすでについている蒴果のほうへ集まります。その結果、粒が大きくなり、熟す時期がそろって収穫が楽になります。最初の花が咲いてから35-40日がその時期で、第8節で詳しく扱います。

### 2-4. エゴマの形態

| 器官 | 特徴 |
|---|---|
| 葉 | 幅の広いハート形で、縁に鋸歯があります。表裏に細かい毛があり、特有の香りがします |
| 茎 | 四角く、まっすぐに立ちます。高さは60-150cmです |
| 根 | まっすぐな根に細根が多くあります |
| 花 | 白い小さな花が穂状に集まります。韓国では8-9月に咲きます |
| 果実 | 小さな蒴果で、種子が4個ずつ入っています |
| 種子 | 直径1.5-2mmの丸い粒です。灰褐色から黒色です |

&nbsp;&nbsp;&nbsp;エゴマの葉の香りは、ペリルアルデヒドという成分に由来します。この香りは人によって好ましくも不快にも感じられ、評価表の味Dに付いた「におい・香りに抵抗感」という但し書きはこれを指しています。同じ成分は虫や獣を遠ざける役割も果たし、非食用価値Cの根拠になります。エゴマにはロスマリン酸という抗酸化成分も含まれています。

### 2-5. 生育段階

| 段階 | ゴマ | エゴマ（葉用） | 重要な養分 |
|---|---|---|---|
| 発芽・幼苗期 | 播種から3週 | 播種から3週 | リン酸、少量の窒素 |
| 栄養生長期 | 3週から8週 | 3週から8週 | 窒素 |
| 開花・結実期 | 8週から12週 | 葉の収穫期（韓国では6月下旬から9月下旬） | ゴマはリン酸とカリウム、エゴマは窒素とカリウム |
| 登熟・収穫期 | 12週から16週 | 再生と再収穫が続きます | カリウム |

&nbsp;&nbsp;&nbsp;ゴマは一年に一度、種子を収穫して終わりですが、葉用エゴマは違います。下のほうの大きな葉を摘み取ると、上から新しい葉が次々と出てくるため、夏のあいだずっと収穫できます。評価表の永続性Bは、この事実を指しています。一つの畑でゴマと葉用エゴマを分けて植えると、夏には葉が、秋には油が得られます。

### 2-6. 100g当たりの栄養

| 栄養素 | ゴマ（炒ったもの） | エゴマの葉（生） |
|---|:---:|:---:|
| 熱量 | 539kcal | 38-47kcal |
| タンパク質 | 21.3g | 3.69g |
| 脂質 | 45-55g | ごくわずかです |
| 炭水化物 | 27.4g | ほとんどが食物繊維です |
| 食物繊維 | 10-12g | 4.5g |
| カルシウム | 多いです | 296mg |
| 鉄 | 多いです | 多いです |
| マグネシウム | 多いです | 普通です |
| ビタミンE | とても多いです | 多いです |
| β-カロテン | 少ないです | 7,565 μg |
| 特有の成分 | セサミン、セサモリン | ロスマリン酸、ペリルアルデヒド |

&nbsp;&nbsp;&nbsp;ゴマの脂質含有量45-55%が、この作物のすべてだと言っても過言ではありません。この脂質の組成は、オレイン酸が40%前後、リノール酸が45%前後で、飽和脂肪酸は少なめです。リノール酸は体内で自ら作ることのできない必須脂肪酸なので、必ず食べて摂る必要があります。

&nbsp;&nbsp;&nbsp;セサミンとセサモリンはゴマにしかない成分で、災害時に特別な価値を持ちます。この二つは強い抗酸化作用を発揮し、油が空気に触れて傷む速度を遅くします。ゴマ油がほかの植物油より長持ちする理由であり、冷蔵庫がない状況で油を何か月も置いて使える根拠です。エゴマ油にはこの成分がなく、代わりに酸化しやすいα-リノレン酸が60%を超えるため、常温では数週間でにおいが変わります。

&nbsp;&nbsp;&nbsp;エゴマの葉のβ-カロテン7,565μgは、ニンジンの1.4倍に当たる値です。体内でビタミンAに変わる成分で、このビタミンが不足すると、暗い場所でよく見えなくなる夜盲症が起こります。ただし、β-カロテンは油に溶けてはじめて吸収されるため、エゴマの葉を油なしで食べると、含まれている量に比べて得られるものが少なくなります。ゴマ油とエゴマの葉が同じ畑から得られるという点が、ここで意味を持ちます。

## 3. 栽培環境

### 3-1. 温度

| 区分 | ゴマ | エゴマ |
|---|---|---|
| 発芽温度 | 20-25℃、最低15℃ | 15-25℃ |
| 生育適温 | 20-30℃ | 20-25℃ |
| 結実適温 | 20-28℃ | 20-25℃ |
| 高温限界 | 35℃を超えても水さえあれば耐えます | 30℃を超えると葉が硬くなります |
| 低温限界 | 10℃で生長が止まります | 同じです |
| 致死温度 | 霜が一度降りると枯れます | 同じです |

&nbsp;&nbsp;&nbsp;評価表の温度適応幅Cは、結実域20-28℃、幅10℃から出た値です。育つだけなら幅は広いものの、種子を実らせるには狭いという意味です。この範囲を外れると、花が咲いても種子が実らなかったり、粒が充実しなかったりします。韓国でゴマの播種時期が5月中旬から6月上旬と遅いのは、開花と登熟が夏のこの温度域に入るようにするためです。

### 3-2. 光

| 区分 | 基準 | 備考 |
|---|---|---|
| ゴマに必要な日照 | 1日6時間以上 | 日照が足りない高地では栽培が難しくなります |
| エゴマに必要な日照 | 1日6時間以上 | 半日陰でも育ちます |
| 40%遮光時 | 相対収量86% | 葉菜類に共通の値で、評価表のB等級の根拠です |

&nbsp;&nbsp;&nbsp;評価表の遮光の値は葉を基準にしたものなので、葉用エゴマにはよく合いますが、ゴマの種子にはあまり合いません。ゴマは種子を実らせるのに多くのエネルギーを要するため、日照が不足すると蒴果の数と粒の大きさがともに減ります。日陰の場所は葉用エゴマに、日当たりのよい場所はゴマに割り当てる配置が理にかなっています。

&nbsp;&nbsp;&nbsp;エゴマについては、もう一つ性質を知っておく必要があります。エゴマは日が短くなると花が咲く短日植物です。韓国では8月下旬から日が短くなって花茎が立ち、そのころから葉が小さく硬くなります。葉を長く収穫するには、夜に明かりが当たる場所のほうがかえって有利ですが、電気がない状況では使えない方法です。そのため、露地での葉の収穫期間は9月下旬までと決まってしまいます。

### 3-3. 水と土壌

| 項目 | ゴマ | エゴマ |
|---|---|---|
| 総蒸発散量 | 作期当たり約400mm | 同程度です |
| 干ばつ | きわめて強いです | 普通です。乾くと葉がしおれます |
| 過湿 | 極端に弱いです。一日二日冠水しても大きな被害が出ます | 比較的耐えます |
| 土性 | 排水のよい砂壌土から壌土 | 有機物が豊富で水はけのよい土 |
| 土層の深さ | 30cm以上 | 20cm以上 |
| pH | 6.0-7.0 | 6.0-7.0 |
| 畝の高さ | 20-30cm以上 | 15-20cm |

> **ゴマ栽培で失敗のもっとも多い原因は、干ばつではなく水です。水が抜けない土地には、ほかの条件がどれほど良くてもゴマを植えません。**

&nbsp;&nbsp;&nbsp;なぜそこまで弱いのかは、根の性質に由来します。ゴマの根は、乾いた土地で水を探すために深く太く伸びるようにできており、その代償として酸素の要求量が大きくなっています。土のすき間に水が満ちて空気が押し出されると、根はたちまち息ができなくなります。そこへ疫病菌が水に乗って広がり、傷んだ根に入り込みます。一日二日の冠水が畑全体を崩壊させる仕組みはこれです。この問題は第7節で扱います。

## 4. 品種

### 4-1. ゴマの品種

| 品種 | 特徴 | 収量 | 適した状況 |
|---|---|:---:|---|
| ウェデケ（一本立ち型） | 枝を出さず、一本立ちで育ちます | 普通 | 狭い場所に密植するとき。管理が単純です |
| カジケ（分枝型） | 側枝を出します。一株が大きくなります | 多い | 場所に余裕があるとき。株数が少なくても済みます |
| ダフッケ（ミリャン28号） | 黒ゴマ系統です | 普通 | 薬材としても使い、油も搾ります |

&nbsp;&nbsp;&nbsp;ウェデケとカジケのどちらを選ぶかは、畑の事情しだいです。ウェデケは一株が小さいので密植でき、枝を出さないため蒴果が茎一本に集まって収穫が単純です。カジケは一株から多く収穫できますが、枝ごとに熟す時期がずれるため、収穫の判断がより難しくなります。種子に余裕があればウェデケを密に植えるほうが、種子が貴重であればカジケを疎らに植えるほうが有利です。

&nbsp;&nbsp;&nbsp;黒ゴマと白ゴマは、油の含有量に大きな差がありません。黒ゴマの種皮には色素とともにシュウ酸がより多く含まれていて、カルシウムの吸収をわずかに妨げますが、この問題は第14節で扱います。

### 4-2. エゴマの品種

| 類型 | 品種 | 特徴 |
|---|---|---|
| 葉用エゴマ | イプトゥルケ1号、トングル2号、プンニョンドゥルケ、ナムチョンドゥルケ | 葉が広くて柔らかいです。繰り返しの収穫によく耐えます |
| 油用エゴマ | 地域の在来種が多くあります | 種子がたくさんつきます。葉が硬く、サムには使いにくいです |

> **エゴマの葉を得るには、必ず葉用エゴマの品種を植える必要があります。油用エゴマの葉は硬く香りが強すぎてサムには使いにくく、葉用エゴマは種子の付きが少なく、油を搾るには足りません。**

### 4-3. 状況別に何を選ぶか

| 状況 | ゴマ | エゴマ | 理由 |
|---|---|---|---|
| 油が目的のとき | ウェデケ、カジケ | 油用エゴマ | ゴマのほうが油が長持ちします。エゴマ油は早く傷みます |
| 灯火用の油が目的のとき | ゴマ | - | ゴマ油は煤が少なく、灯心によく上ります |
| 夏の葉野菜が目的のとき | - | イプトゥルケ1号、トングル2号 | 韓国では6月下旬から9月下旬まで収穫します |
| 場所が狭いとき | ウェデケ | 葉用エゴマ | 密植できます |
| 水はけの悪い畑 | 植えません | エゴマ | ゴマは湿害で崩れます |
| 獣を遠ざけたいとき | ゴマ | エゴマ | 強い香りでキバノロやイノシシが近寄りにくくなります |

&nbsp;&nbsp;&nbsp;韓国のどの道でもゴマとエゴマの種子を入手でき、地域ごとに、その地域の気候に合わせて長く栽培されてきた在来種が残っています。物流が途絶えた状況で、隣人から分けてもらえる種子であるという点が、この作物の大きな利点です。
