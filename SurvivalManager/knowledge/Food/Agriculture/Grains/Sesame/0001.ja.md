## はじめに
&nbsp;&nbsp;&nbsp;韓国語では、1つの名前(kkae)が2つの異なる植物を指します。ゴマ(Sesamum indicum)はゴマ科の一年草で、種子からゴマ油を採り、エゴマ(Perilla frutescens)はシソ科の一年草で、種子からエゴマ油を採り、葉をエゴマの葉として食べます。評価表では、この作物は面積当たりの熱量がE(自給ラインの15%未満)で、食料作物から除外されており、この判定は正確です。しかし、この作物の価値は熱量ではなく油にあります。種子の45-55%が油で、1kgを搾ると400g前後の油が出ます。搾った後の油かすにもタンパク質が35-40%残り、飼料と肥料になります。数畝あれば1年分の油をまかなえます。弱点は湿気です。ゴマは干ばつに非常に強い一方、1-2日冠水しただけで根が傷み、疫病が広がります。梅雨のある韓国では、畝をどれだけ高く立て、排水路をどれだけうまくつくるかが成否を分けます。収穫は下の蒴果が裂け始めたときに行わなければならず、時期を逃すと種子が畑にこぼれ落ちます。

## 1. 災害への備えの評価
| 区分 | 内容 |
|:---|:---|
| 判定 | 除外(面積当たりの熱量E、自給ラインの15%未満)。ゲート未適用スコア35.7(有効183種中162位相当) |
| 評価の基準 | エゴマの葉(生)。80kg/1,000㎡ × 38kcal/100g = 30kcal/㎡、自給ラインの0.01倍 |
| 種子の基準 | ゴマの種子539-573kcal/100g、1,000㎡当たり60-100kg、1㎡当たり350kcal前後で、自給ラインの2,616kcalの13% |
| 強み | SS: タンパク質密度、微量栄養素、施設の負担。S: 貯蔵性、国内での栽培の普及度(どの道でも種子を確保できる)、自家採種。A: 施肥、水の消費量、調理・加工、合成資材を投入しない場合の収量維持率(56.0%)、収量の安定性 |
| 弱み | E: 面積当たりの熱量、耐寒性(霜が1度降りただけで枯れる)。D: 整地・掘削エネルギー、味(においと香りへの抵抗感)。C: 収穫速度、温度幅、病害虫圧、防除の自立度、連作への適応性(3-4年の休作)、種子の寿命 |

> **この作物の熱量の等級が最下位だという事実と、災害時に役に立たないという判断は、まったく別の話です。この作物が生み出すのは熱量ではなく油です。**

&nbsp;&nbsp;&nbsp;油は、炒めたり揚げたりする調理、脂溶性ビタミン(A、D、E、K)の吸収、必須脂肪酸、停電した夜のあかり、石けん、木・革・紙の防水と防腐、金属の潤滑に使われます。穀物と野菜とイモ類は、これらのどれも代わりになりません。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 区分 | ゴマ | エゴマ |
|:---|:---|:---|
| 原産地 | アフリカからインドの乾燥地 | 東アジア |
| 主な用途 | 種子からゴマ油 | 種子からエゴマ油、葉はエゴマの葉 |
| 油の性質 | 酸敗が遅い | 酸敗が早い |
| 葉 | 細い披針形で毛がある | 幅広いハート形で縁に鋸歯 |
| 干ばつ、湿害 | 干ばつに非常に強く、湿害に極端に弱い | 干ばつには普通、湿害には比較的耐える |

&nbsp;&nbsp;&nbsp;どちらも茎が四角く、高さ60-150cmで、自家受粉が主です。ゴマはまっすぐな直根が深く伸びて、乾いた土の中で水を探し、果実は長さ2-3cmの蒴果で、熟すと上側の縫合線が裂けます。種子は、ゴマが長さ3mm前後、エゴマが直径1.5-2mmです。ゴマの花は下から上へ30-40日かけて順に咲くので、下の蒴果が熟したときに上の蒴果はまだ緑色で、植物が遅く咲いた花にも資源を分けるため、粒がそろって小さくなります。摘芯がこの問題を解決します。

| 100g当たりの栄養 | ゴマ(炒ったもの) | エゴマの葉(生) |
|:---|:---|:---|
| 熱量 | 539kcal | 38-47kcal |
| タンパク質 / 脂肪 | 21.3g / 45-55g | 3.69g / わずか |
| 炭水化物 / 食物繊維 | 27.4g / 10-12g | ほとんどが食物繊維 / 4.5g |
| その他 | カルシウム、鉄、マグネシウム、ビタミンEが多い。セサミンとセサモリン(酸敗を遅らせる) | カルシウム296mg、βカロテン7,565μg |

## 3. 栽培環境と品種
| 条件 | ゴマ | エゴマ |
|:---|:---|:---|
| 温度 | 発芽20-25℃(最低15℃)、生育20-30℃、結実20-28℃。10℃で生長が止まり、霜で枯れる | 発芽15-25℃、生育・結実20-25℃。30℃を超えると葉が硬くなる |
| 光 | 1日6時間以上 | 6時間以上、半日陰でも可能 |
| 水 | 総蒸発散量およそ400mm | 同程度 |
| 土壌 | 水はけのよい砂壌土-壌土、pH 6.0-7.0、土の深さ30cm以上 | 有機物が豊富で水はけのよい土、pH 6.0-7.0、土の深さ20cm以上 |
| 畝の高さ | 20-30cm以上 | 15-20cm |

> **ゴマ栽培で失敗する最も多い原因は、干ばつではなく水です。水の抜けない土地には、ほかの条件がよくても、ゴマを植えません。**

| 品種 | 特徴 |
|:---|:---|
| 一本立ち型のゴマ | 1本立ち。狭い場所に密に植えるとき、管理が単純 |
| 枝分かれ型のゴマ | 側枝を出す。1株が大きく収量が多い。場所に余裕があるとき |
| ダフク(ミリャン28号) | 黒ゴマ系統。薬用と油用を兼ねる |
| 葉用エゴマ(葉用エゴマ1号、トングル2号、プンニョン、ナムチョン) | 葉が幅広く柔らかく、繰り返しの収穫に強い。種子はあまりつかない |
| 油用エゴマ(在来種) | 種子がたくさんつく。葉が硬く、包んで食べるには不向き |

&nbsp;&nbsp;&nbsp;油と灯油にはゴマ(長持ちし、すすが少ない)、夏の葉物には葉用エゴマ、水はけの悪い畑にはエゴマです。

## 4. 畑の準備と播種
| 項目 | ゴマ | 葉用エゴマ |
|:---|:---|:---|
| 畝 | 高さ20-30cm以上、幅55-60cm。畝間は深く広く、畑の周囲に排水路、傾斜畑には上からの水をそらす山側の溝 | 高さ15-20cm |
| 堆肥、化成肥料(1,000㎡当たり) | 1,000-2,000kg、30-35kg。播種2週間前に全量を元肥、追肥は省略 | 1,500kg、20-30kg。収穫期まで10-15日おきに少量ずつ追肥 |
| 播種 | 5月中旬-6月上旬(気温15℃以上)。1,000㎡当たり0.3-0.6kg | 4月下旬-5月上旬(霜の心配が過ぎてから)。油用エゴマは5-6月 |
| 間隔、深さ | 畝間55-60cm、株間15-20cm、深さ2-3cm、1穴5-6粒。播種後に軽く押さえる | 10 × 5cmまたは7 × 7cm、深さ0.5-1cm。わら・布・新聞紙で覆い、芽が出たらすぐにはずす |
| 間引き | 本葉2-4枚で、1穴に丈夫な1本 | 本葉1-2枚、4-6枚の2回 |

&nbsp;&nbsp;&nbsp;化学肥料がないときは、完熟堆肥(未熟なものは疫病を呼ぶ)、木灰(1㎡当たりひとつかみ)、発酵させた油かす(生のものは土の中で発熱する)、尿の10-20倍希釈液(ゴマには初期にだけ少量)、骨粉、草を漬け込んだ液肥(葉用エゴマの追肥)を使います。

| 種子の処理 | 方法 |
|:---|:---|
| 沈んだ種子だけ使う | 3-4時間水に浸し、浮いたしいなを取り除く |
| 温湯処理 | 50-55℃の湯に10-15分。苗立枯病の予防 |
| 木灰をまぶす | 消毒を兼ね、種子がくっつかないようにする |

> **ゴマで種子消毒は選択ではありません。苗立枯病は種子を介して伝わり、幼苗期に広がると、その場所を丸ごと植え直さなければなりません。**

## 5. 水管理と栽培管理
&nbsp;&nbsp;&nbsp;冠水が数時間から1日続くと、根の酸素がなくなり、葉がしおれ始めます。2日で根の先が腐り始め、3日以上で疫病菌が茎の株元まで広がります。水が引いた後に日が差すと、残った根では耐えられず、かえって急激にしおれます。

| 時期 | ゴマ | 葉用エゴマ |
|:---|:---|:---|
| 発芽-幼苗期 | 表土が乾かないようにし、その後は水を控えて根を深く伸ばす | 乾かないように保つ |
| 栄養生長期 | 自然の降水に任せる。水をためないことがすべて | 表土が白っぽくなったらたっぷり与える |
| 開花・結実期 | ひどい干ばつのときだけ補う(開花期と登熟初期が最も貴重) | 葉がしおれないように保つ |

&nbsp;&nbsp;&nbsp;梅雨の前に畝間の土と草を取り除き、6月に株元に土を寄せて畝をもう一度高くし、雨の直後に倒れた株を起こして踏み固めます。疫病にかかった株は見つけ次第、畑の外へ出し、登熟期には水を与えません。

| 管理 | 内容 |
|:---|:---|
| 摘芯(ゴマ) | 最初の花が咲いて35-40日後、晴れた日の午前に、最上部の花のつぼみの下で切る(枝分かれ型は側枝の先も)。開花が止まり、粒が大きくなり、熟す時期がそろい、背が低くなって倒れにくくなる |
| 摘芯(葉用エゴマ) | 草丈が1mを超えたら上の芽を切り、わき芽を増やす |
| 倒伏防止 | 草丈30-40cmで土寄せ、最初から窒素を控える、密に植えない、80cm以上ならひも張り |
| 雑草 | 播種前に耕して雑草の芽を出させてから浅く削る。幼苗期は畝間だけを浅く削る。株が覆った後はほとんど不要 |

## 6. 病害虫と養分の問題
| 病害 | 症状と条件 | 対応 |
|:---|:---|:---|
| 疫病 | 根と茎の株元が黒く腐り、しおれる。梅雨、水がたまるとき | 畝を高くして排水を確保。病んだ株は土ごと取り、畑の外へ |
| 萎凋病 | 片側の葉からしおれ、茎の中が褐変。高温期、連作した畑 | 治療法なし。3-4年の輪作が唯一の対策 |
| 苗立枯病 | 幼い芽の株元がくびれて倒れる | 種子消毒。密にまかず、未熟な肥料を避ける |

> **ゴマの病害対策は、畝を高くして水を抜くことと、3-4年休ませることの2つに集約されます。**

&nbsp;&nbsp;&nbsp;葉の褐色の斑点(葉枯病、さび病)は、通風を確保し、病んだ葉を取り除きます。アブラムシは強い水流や石けん水で洗い落とし、カメムシと蛾の幼虫(オオタバコガ、ハスモンヨトウ)は早朝か日暮れに手で捕り、卵塊は葉ごと取ります。防除資材は、石けん水(無香料の石けん20gを水1Lに)、木灰、ニンニクの浸出液(ニンニク100gを水1Lに)、木酢液の500-1,000倍、ボルドー液(葉枯病の予防)です。

| 症状 | 原因と対応 |
|:---|:---|
| 葉全体が黄色く、株が小さい | 窒素不足。薄めた尿、発酵させた油かす、完熟堆肥 |
| 花が咲いてもそのまま落ちる | リン酸またはホウ素の不足。いろいろな材料を混ぜた堆肥、骨粉 |
| 新しい葉が黄色く、葉脈だけ緑 | 鉄不足。木灰を減らし、有機物を入れる |
| 蒴果はついたが中身が空 | カリ不足またはカメムシ。木灰、カメムシの点検 |
| 背ばかり高く倒れ、葉だけ茂る | 窒素過多。窒素を断ち、土寄せ、摘芯を早める |

&nbsp;&nbsp;&nbsp;ゴマの養分の問題は、たいてい不足ではなく窒素過多なので、元肥1回で済ませます。葉用エゴマは葉が収穫物なので、窒素を与え続けます。

## 7. 間作と輪作
| 相性 | 作物 |
|:---|:---|
| よい | マメ科(ササゲ、リョクトウ、ダイズ)、サツマイモ・ジャガイモ(根の深さが違う)、畑の縁の周囲植え(強い香りがノロジカやイノシシを遠ざける) |
| 普通 | トウモロコシ・モロコシ(日陰をつくるので北側に配置) |
| 悪い | ゴマの連作、水を引く作物と並べる、ナス科(トウガラシ・トマト・ジャガイモ)の直後 |

&nbsp;&nbsp;&nbsp;1年目ゴマ、2年目マメ科、3年目アブラナ科かウリ科、4年目穀物(モロコシ・アワ・トウモロコシ)を経て、5年目にゴマへ戻ります。畑が狭ければ、植える場所を毎年移します。エゴマは2年でよいのですが、ゴマと同じ場所に交互に植えるのは避けます。

## 8. 収穫、脱穀、採種
| 段階 | 内容 |
|:---|:---|
| 時期 | 9月末-10月初め。茎の下のほうの蒴果が2、3個裂け始め、下の葉が黄色くなって落ちるとき。上が熟すのを待つと、下をすべて失う |
| 刈り取り | 曇りの日の早朝か夕方に、地面近くで刈る。寝かせたり揺らしたりせず、立てたままの姿勢でまとめ、運ぶときは下に布を当てる |
| 乾燥 | 5、6株ずつ下を束ね、3、4束を円錐形に立てる。下にむしろを敷いて7-15日。雨の予報があれば覆うか、取り込む |
| 脱穀、選別 | むしろの上で束を逆さにして棒でたたき、2、3日さらに乾かして繰り返す。篩、箕あおぎ、風、水洗いで選り分ける(洗ったらその日のうちに完全に乾かす。ぬれたまま積むとカビが生えて使えなくなる) |
| 葉用エゴマ | 本葉4枚ほどから、葉が開いて大きさ7-10cmのとき。上のほうの若い葉2-4枚を必ず残し、下の大きい葉だけを摘む。夏は3-5日おき、6月下旬-9月下旬 |

| 採種 | 基準 |
|:---|:---|
| 株 | 病気がなく、蒴果がたくさんつき、倒れていない株を開花期に印づけする。萎凋病が出た株は使わない |
| 採る場所 | 茎の中ほどの蒴果。完全に褐色に乾くまで置き、布袋をかぶせてこぼれ落ちるものを受ける |
| 保管 | 日陰で水分12%以下に乾燥し、密閉容器に入れて涼しく暗い場所に置く。必要量の2倍。播種用は炒らない |
| 寿命 | 密閉・涼しく暗い場所で1-2年、そのまま常温では1年未満、日光や熱が当たる場所では数か月。毎年採って毎年植える |

## 9. 貯蔵
| 形態 | 常温での保存 | 理由 |
|:---|:---|:---|
| 炒っていない種子 | 1年前後 | 油が細胞の中に閉じ込められ、空気に触れにくい |
| 炒った種子 | 3-6か月 | 細胞が壊れ、油が空気にさらされる |
| すりごま | 1か月以内 | 表面積が増え、急激に傷む |
| 搾ったゴマ油 / エゴマ油 | 6か月-1年 / 2-3か月 | ゴマ油はセサミンのおかげで長持ちし、エゴマ油はα-リノレン酸が多くて早く傷む |

> **ゴマは種子のまま積んでおき、使う分だけその都度炒って搾る作物です。一度にすべて搾っておくと、半年で食べられなくなります。**

| 対象 | コツ |
|:---|:---|
| 種子 | 水分12%以下に乾燥し、日陰で完全に冷ましてから、かめ・ガラス瓶・金属缶にいっぱいに詰めて密閉する(空きスペースの空気が油を傷める)。涼しく暗く、温度変化の少ない場所に、複数の容器に分けて置く |
| 油 | 小さな瓶に分けていっぱいに詰め、栓をしっかり閉め、暗い瓶・かめに入れて涼しい場所へ。使う分だけ入った瓶を開ける |
| エゴマの葉 | そのまま2-3日、乾燥して密閉・醤油漬け・塩漬けで数か月、キムチ2-3か月 |

## 10. 油搾りと加工
| 区分 | 炒って搾った油 | 炒らずに搾った油 |
|:---|:---|:---|
| 香り、色 | 香ばしい香り、濃い茶色 | 香りがほとんどない、澄んだ黄色 |
| 搾れる量 | より多く出る | 少なめ |
| 発煙点 | 低い。炒め物には不向き | 高い。揚げ物に使える |
| 用途 | あえ物、仕上げにかける油 | 炒め物、揚げ物、灯油、石けん |

&nbsp;&nbsp;&nbsp;炒るときは、弱火から中火で休まずにかき混ぜます。パチパチとはじける音がして、薄い茶色に変わり、香ばしいにおいがしたら、すぐに火から下ろし、広げて冷まします。種子は細かくつぶして蒸し器で蒸すか鍋で温めた後、麻布か木綿の袋に入れて押して搾り、1-2日置いて沈殿させ、澄んだ上の部分だけを注ぎ分けます。

| 圧搾の方式 | 種子の重さに対する収量 |
|:---|:---|
| ねじ式(鉄が必要) | 40-50% |
| くさび式(丸太の枠に袋を入れ、木のくさびをハンマーで打ち込む) | 35-45% |
| てこ式(長い丸太の一端を柱にかけ、反対側に重い石をつるす) | 30-40% |
| 手でねじる(袋を2本の棒の間に挟んでねじる) | 20-30% |

&nbsp;&nbsp;&nbsp;圧搾の道具がないときは、炒ったゴマを細かくつぶして、水を少しずつ加えながらどろどろにすりつぶし、広い鍋で弱火で煮て、浮いてきた油をお玉ですくい、もう一度弱火で温めて水分を飛ばします。水が残ると油が傷みます。

| 副産物と用途 | 内容 |
|:---|:---|
| 油かす | 人はつぶして粥や餅に混ぜ(粗くて、たくさん入れると食べにくい)、ニワトリ・ブタ・ウシのタンパク源として使う(一度にたくさん与えると下痢)。肥料としては窒素5-6%、リン酸2%、カリ1%前後で、必ず発酵させてから入れる |
| 灯油 | 綿糸・麻糸・布をよってつくった芯を、浅い皿に入れた油に差す。ゴマ油はすすが少なく、エゴマ油は芯にかさぶたができる。食べにくくなった油から使う |

| 石けんづくり | 方法 |
|:---|:---|
| 灰汁と苛性化 | 広葉樹の灰を水に溶いて1日置き、上の水を取る(針葉樹の灰は弱い)。生石灰(貝殻や石灰石を焼いてつくる)を入れてかき混ぜ、沈殿させる |
| 強さ | 新しい羽根が溶け始めるか、ジャガイモが硬貨ほど浮き上がれば十分 |
| 混ぜる、煮る | 油を温め、灰汁を少しずつ注ぎながら休まずにかき混ぜ、弱火で数時間煮る |
| 固める | 塩を入れると、石けんが固まって浮く。すくい取って型に入れて固め、数週間熟成させる |
| 注意 | 灰汁が目や皮膚についたら水で長く洗い、薄めた酢ですすぐ。アルミの鍋は溶けるので、鋳鉄や陶器を使う。未完成の石けんにはアルカリが残っている |

> **石けんに使う油は、食べられなくなった油、動物の脂、油かすの搾りかすの油が先で、傷んでいない上質なゴマ油は最後です。**

&nbsp;&nbsp;&nbsp;種子は、炒って振りかけたり、ごま塩、ごま粥、ごまおこしにして食べ、圧搾の道具がなければ、すりつぶしてそのまま食べるのがいちばん効率的です。エゴマの葉は、包み菜、醤油漬け、チヂミ、蒸し物にして食べ、汁物には最後に入れます。

## 11. 毒性と注意事項
| 注意 | 内容 |
|:---|:---|
| 毒性 | ゴマとエゴマには、人に有害な毒成分がない |
| アレルギー | ゴマは主要なアレルギー誘発食品。初めて食べさせる人には少量から始め、反応があればゴマ油とごま塩まですべてやめる。エゴマは必ずしも反応しない |
| シュウ酸、フィチン酸 | 外皮(特に黒ゴマ)がカルシウム・鉄・亜鉛の吸収を妨げる。炒る、浸す、発酵させると減る。カルシウムが外皮に多いので、むかずに炒って食べるほうがよい |
| 酸敗した油 | 酸っぱいかペンキのようなにおい、苦味、濁った色、べとつきが出る。食べず、灯油か石けんに使う |
| その他 | 脂肪が多く、一度にたくさん食べると下痢。エゴマの葉は肥料を多く与えると硝酸塩がたまるので、乳児にたくさん食べさせない |

## 12. 年間作業日程
| 月 | ゴマ | エゴマ |
|:---|:---|:---|
| 1-3月 | 種子と油の貯蔵状態の確認、種子消毒、堆肥の準備、植える場所(輪作の順序)の決定 | 種子の準備 |
| 4月 | 畑を耕す、畝立て、元肥 | 下旬に葉用エゴマを播種 |
| 5月 | 中旬から播種、畝を高く立てる | 上旬までに播種を終える、間引き |
| 6月 | 間引き、除草、土寄せ、畝間・排水路の手入れ | 下旬から葉を収穫 |
| 7月 | 開花開始、梅雨の排水管理と疫病の点検 | 葉の収穫、追肥 |
| 8月 | 最初の花から35-40日後に摘芯、カメムシ・蛾の点検 | 葉の収穫 |
| 9月 | 下旬から下の蒴果を点検、採種用の茎に袋をかぶせる | 下旬に葉の収穫を終える |
| 9月末-10月 | 収穫、立てて乾燥、脱穀、選別 | 油用エゴマの収穫と脱穀 |
| 11-12月 | 貯蔵、油搾り、油かすを発酵させて肥料に | 貯蔵 |

> **ゴマ栽培は、5月に畝を高くし、9月に目分量で収穫します。畝をどれだけ高く立てたかが半分で、下の蒴果が裂ける日に気づくことが残りの半分です。**
