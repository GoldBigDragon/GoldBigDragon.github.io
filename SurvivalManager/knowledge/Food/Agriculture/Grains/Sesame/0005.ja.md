## 9. 病害虫 - 農薬なしで防ぐ方法

### 9-1. ゴマは予防で守る作物です

&nbsp;&nbsp;&nbsp;ゴマは、病気がいったん出ると治療が事実上不可能で、広がる速度も速い作物です。病気が流行すると収量が25%ほど減るという報告があり、ひどい場合は畑全体を失います。農薬があっても難しいことなので、農薬がない状況では、予防のほかに道はありません。

| 病気 | 症状 | いつ発生するか | 農薬なしでの対応 |
|---|---|---|---|
| 疫病 | 根と茎の株元が黒く腐り、株がしおれます | 韓国の梅雨（チャンマ、6月下旬～7月）、水がたまるとき | 畝を高くして排水を確保します。病気の株は土ごと取り除いて畑の外へ出します |
| 萎凋病 | 片側の葉からしおれ、茎を割ってみると中が褐変しています | 高温期、連作した畑 | 治療法はありません。3-4年の輪作が唯一の対策です |
| 葉枯病 | 葉に褐色の斑点ができて広がり、枯れます | 湿度が高いとき | 風通しを確保し、病気の葉を取り除きます。密植しません |
| 立枯病 | 幼い芽の株元がくびれて倒れます | 幼苗期 | 種子消毒が要です。密にまかず、未熟な肥料を避けます |
| うどんこ病 | 葉に白い粉がつきます | 夏の終わり | 風通しを確保します。被害が大きくなければ放っておいてもかまいません |

> **ゴマの病害対策は、事実上二つに要約されます。畝を高くして水を抜くことと、3-4年休ませることです。この二つを守れば、残りの病気は大きな問題になりません。**

&nbsp;&nbsp;&nbsp;萎凋病は、別に取り上げる価値があります。土の中にすむカビが根から入って導管を詰まらせる病気で、このカビは一度定着すると何年も土に残ります。評価表の連作適応性Cに付いた「ゴマは萎凋病が残るため3-4年休作」という根拠が、この病気を指しています。薬剤で治療することはできず、抵抗性品種も完全ではありません。畑を変えるほかに方法がありません。

### 9-2. 主な害虫

| 害虫 | 被害 | 農薬なしでの対応 |
|---|---|---|
| アブラムシ | 新芽や葉の裏で汁を吸います。乾燥するときに増えます | 強い水流で洗い流します。石けん水をまきます。テントウムシやクサカゲロウを守ります |
| カメムシ | 熟していく蒴果に口針を刺して、中身を吸い取ります | 早朝に手で捕まえます。畑の周りの雑草を整理します |
| オオタバコガの幼虫 | 葉や茎をかじり、蒴果に穴をあけます | 夕方に手で捕まえます。卵塊を葉ごと取り除きます |
| ハスモンヨトウの幼虫 | 葉をかじります。エゴマにも付きます | 同じ方法です |
| エゴマのさび病 | 葉に褐色の斑点ができます | 風通しを確保し、病気の葉を取り除きます |

### 9-3. 農薬なしで作る防除資材

| 資材 | 作り方 | 何に使うか | 原理 |
|---|---|---|---|
| 石けん水 | 無香料の石けん20gを水1Lに溶かします | アブラムシ、ハダニ | 石けんが虫の油膜を溶かし、気門をふさぎます |
| 草木灰 | ふるいにかけて葉と地面にまきます | 地面を這う害虫 | 灰が虫の体の水分を奪います |
| ニンニクの浸出液 | ニンニク100gをすりおろし、水1Lに漬けてから濾します | 害虫の忌避 | 硫黄化合物のにおいが虫を遠ざけます |
| 木酢液 | 500-1,000倍に薄めます | 忌避、カビの抑制 | 酸性とフェノール成分が作用します |
| ボルドー液 | 硫酸銅と生石灰を水に溶いて作ります | 葉枯病の予防 | 銅が胞子の発芽を妨げます |
| エゴマの葉の浸出液 | エゴマの葉をすりつぶして水に浸します | 忌避 | ペリルアルデヒドの強い香りが虫を遠ざけます |

&nbsp;&nbsp;&nbsp;最後の行は、この作物の中で循環が閉じる例です。葉を摘んだあとに残った硬いエゴマの葉や、摘心で切り取ったものを捨てずに浸出して使えば、防除資材になります。殺すのではなく寄せつけない程度の効果ですが、何もない状況では価値があります。

### 9-4. 植え付け前に防ぐ方法

| 方法 | 内容 |
|---|---|
| 種子消毒 | 温湯処理と草木灰。立枯病は種子を介して入ります |
| 輪作 | ゴマは3-4年休ませます。萎凋病と疫病対策のすべてです |
| 排水 | 畝を高くし、畝間を深く掘ります。疫病対策のすべてです |
| 密植しない | 風通しがカビ病を防ぎます |
| 泥はね防止の被覆 | 藁や枯れ草を敷くと、雨粒で土が跳ね上がって葉に病気を移すのを防げます |
| 病気のものは畑の外へ | 病気の株を畑に捨てると、病原菌がそのまま残ります |

## 10. 栄養素の欠乏と過剰

### 10-1. 欠乏症状の読み方

| 症状 | どこに最初に現れるか | 原因 | なぜそうなるのか | 自然資材での対処 |
|---|---|---|---|---|
| 葉全体が黄色くなり、株が小さい | 下の古い葉から | 窒素不足 | 窒素は体内を移動するため、古い葉から抜き取って新しい葉へ送ります | 薄めた尿、熟成させた油かす、完熟堆肥 |
| 葉の縁が褐色に焦げる | 下の葉から | カリウム不足 | カリウムも移動性が大きいため、古い葉がまず犠牲になります | 草木灰を少量まきます |
| 葉が暗く紫色を帯び、生長が遅い | 全体 | リン酸不足 | 低温でリン酸の吸収が落ちて現れることもあります | 骨粉、草木灰 |
| 花が咲いてもそのまま落ちる | 花 | リン酸またはホウ素の不足 | 花粉がきちんとできないか、受精が行われません | さまざまな材料を混ぜた堆肥、骨粉 |
| 新しい葉が黄色く、葉脈だけが緑 | 上の新しい葉から | 鉄不足 | 鉄はあまり移動しないため、新しい葉が先に飢えます | 草木灰を減らし、有機物を入れます |
| 新芽の先が枯れてねじれる | 生長点 | カルシウムまたはホウ素の不足 | 水の流れに乗って移動するため、新芽には届きにくいのです | 貝殻や卵の殻を焼いた粉 |
| 蒴果はついたが中身が空 | 蒴果 | カリウム不足またはカメムシ | 登熟に使う養分が足りないか、吸い取られたのです | 草木灰。まずカメムシを確認します |

&nbsp;&nbsp;&nbsp;症状を読み取るとき、もっとも役に立つ手がかりは、どこに最初に現れるかです。古い葉から傷む場合は、植物体内でよく動く養分（窒素、リン酸、カリウム、マグネシウム）が不足しており、新しい葉から傷む場合は、あまり動かない養分（鉄、カルシウム、ホウ素）が不足しています。

&nbsp;&nbsp;&nbsp;ただし、ゴマには落とし穴が一つあります。上の症状の多くは、疫病や萎凋病の初期症状と見分けがつきません。株全体がしおれたら、養分ではなく病気をまず疑うべきで、とくに片側の葉からしおれる場合は、ほぼ萎凋病です。茎を縦に割ってみて、中が褐変していれば病気です。この区別ができずに肥料を与えると、病気を育てるだけになります。

### 10-2. 過剰症状

| 症状 | 原因 | なぜそうなるのか | 対処 |
|---|---|---|---|
| 背ばかり高く、茎が軟らかくて倒れます | 窒素過多 | 細胞壁が薄く伸びて組織が弱くなります | 窒素を断ちます。土寄せで支えます |
| 葉は茂るのに蒴果が少なくなります | 窒素過多 | 資源が茎葉に偏り、結実に回りません | 摘心を早めます |
| 葉が濃い緑色になり、アブラムシが集まります | 窒素過多 | 汁液にアミノ酸が増え、アブラムシが好みます | 同じ対処 |
| 開花が遅れ、登熟が長引きます | 窒素過多 | 栄養生長が続いて、生殖生長に移れません | 窒素を断ち、摘心をします |
| 葉の縁が枯れ、根が褐変します | 肥料濃度過多 | 土の塩類濃度が高くなり、水が根から出ていきます | 水を十分に与えて洗い流します |

> **ゴマに現れる養分の問題の大半は、不足ではなく窒素過多です。元肥一回で済ませ、追肥を施さないことが、この作物の基本です。**

### 10-3. 葉用エゴマは逆です

&nbsp;&nbsp;&nbsp;葉用エゴマは葉そのものが収穫物なので、窒素を継続的に供給しなければなりません。葉を摘むたびに、植物は体の一部を失って作り直す必要があり、その材料が窒素です。10-15日間隔で少量ずつ与えるのが基準で、薄めた尿や草を漬けた液肥が向いています。ただし、窒素が過剰になると葉に硝酸塩がたまるため、収穫の直前には与えません。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 作物 | 何が起こるのか |
|---|---|---|
| 良い | マメ科（ササゲ、リョクトウ、ダイズ） | 根粒で固定した窒素の一部が土に出てきます。ゴマは窒素をあまり必要としないため、競合が少なくなります |
| 良い | 畑の縁の周囲植え | ゴマとエゴマの強い香りがキバノロやイノシシに嫌われます |
| 良い | サツマイモ、ジャガイモ | 根の深さが違うため、層が重なりません |
| 普通 | トウモロコシ、モロコシ（タカキビ） | 背が高くてゴマに日陰をつくります。北側に配置すれば問題ありません |
| 悪い | ゴマの連作 | 萎凋病と疫病が土に蓄積します |
| 悪い | 水を引く作物と並べる | 隣からしみ込んだ水がゴマの畝まで濡らします |
| 悪い | ナス科（トウガラシ、トマト、ジャガイモ）の直後 | 土壌病害が重なる部分があります |

&nbsp;&nbsp;&nbsp;周囲植えは、災害時に実質的な利点をもたらします。評価表の非食用価値Cに「強い香りによる忌避効果」という根拠が付いていますが、これがその話です。柵も網もない状況で畑を守る手段は多くありません。畑の縁に沿ってゴマやエゴマを一列に巡らせると、キバノロやイノシシの侵入をある程度減らせます。完全には防げませんが、何もしないよりましで、油も得られます。

### 11-2. 輪作

&nbsp;&nbsp;&nbsp;評価表の連作適応性はCで、根拠は「ゴマは萎凋病が残るため3-4年休作。油糧作物の中では連作障害が大きいほう」です。この文書が扱う作物の中で、休作期間がもっとも長い部類に入ります。葉菜類が1-2年、アマランサスが2年であるのに対し、ゴマは3-4年です。

| 年 | 植えるもの | 何が得られるか |
|---|---|---|
| 1年目 | ゴマ | 油。深い根が地中に通り道をあけます |
| 2年目 | マメ科（ダイズ、ササゲ、リョクトウ） | ゴマが使った窒素を戻します |
| 3年目 | アブラナ科またはウリ科 | 系統が違うため、病原菌が引き継がれません |
| 4年目 | 穀物（モロコシ、アワ、トウモロコシ） | イネ科なので、土壌病害が異なります |
| 5年目 | ゴマに戻ります | |

&nbsp;&nbsp;&nbsp;畑が狭くて四年のローテーションを回せない場合は、ゴマを植える場所を毎年移す方法があります。畑を四つの区画に分け、毎年一区画ずつゴマを植えれば、各区画がゴマを迎えるのは4年に一度だけです。全面積のうち25%だけがゴマになりますが、油を得る目的なら、それでも十分な場合が多くあります。

&nbsp;&nbsp;&nbsp;エゴマはゴマほど厳しくなく、2年ほどで済みます。そのため、ゴマとエゴマを同じ場所で交互に植えたくなりますが、これは避けるほうがよいでしょう。科は異なりますが、重なる土壌病害があり、何よりゴマが必要とする3年の休みに、エゴマは役立ちません。

## 12. 収穫 - 下の蒴果が裂けるとき

### 12-1. いつ刈り取るか

&nbsp;&nbsp;&nbsp;ゴマ栽培の全体を通じて、もっとも難しい判断が収穫の時期です。蒴果が下から上へ順に熟し、熟した蒴果は自然に裂けて種子をこぼすからです。

| 判断基準 | 内容 |
|---|---|
| 蒴果 | 茎の下のほうの蒴果が二、三個裂け始めます |
| 葉 | 下の葉が黄色くなって落ち始めます |
| 茎の色 | 緑色が抜け、下のほうから黄色くなっていきます |
| 時期 | 韓国ではおおむね9月末から10月初めです |
| 種子 | 蒴果を割ってみて、種子が本来の色を帯びて硬ければ、実っています |

> **収穫の基準は、上の蒴果がすべて熟したかではなく、下の蒴果が裂け始めたかどうかです。上を待てば、下をすべて失います。**

&nbsp;&nbsp;&nbsp;この時点で刈ると、上の蒴果はまだ十分に実っていない状態です。しかし、刈って立てて干しているあいだに、茎に残った養分で上の蒴果が引き続き熟していきます。これを後熟といい、ゴマを根ごと引き抜いたり鎌で刈ったりして、束にして立てておく方法が長く受け継がれてきた理由です。

### 12-2. 刈り取りの要領

| 項目 | 内容 | なぜそうするのか |
|---|---|---|
| 天気 | 曇りの日を選びます | 日差しが強いと蒴果がからからに乾き、触れただけで裂けてしまいます |
| 時刻 | 早朝か夕方に刈ります | 露で蒴果がしっとりしていて、裂けにくくなります |
| 刈る位置 | 地面の近くで刈ります | 茎が長いほうが、束ねて立てやすいからです |
| 扱い方 | 寝かせず、立った姿勢のまま集めます | 寝かせたり揺すったりすると、その場でこぼれます |
| 受け止め | 運ぶときは下に布や袋を当てます | 運んでいる間に落ちるものを受け止めます |

&nbsp;&nbsp;&nbsp;曇りの日の早朝か夕方を選ぶようにという点が、この作物の収穫の核心です。ゴマの蒴果は、乾くと開き、湿気を吸うとまた閉じます。露の降りた朝は蒴果が閉じていて扱いやすく、日中に日差しを受けてからからに乾いた状態では、かすめただけでこぼれます。同じ畑を同じ人が刈っても、時刻によって損失が何倍も違ってきます。

### 12-3. 立てて干し、打ち落とす

| 段階 | 方法 | なぜそうするのか |
|---|---|---|
| 束ねる | 五、六株ずつ、下のほうを藁やひもで束ねます | ばらけないようにし、立てやすくします |
| 立てる | 三、四束を互いにもたせかけて円錐形に立てます | 雨が降っても水が流れ落ち、中を風が通ります |
| 場所 | 日当たりと風通しのよい庭先や畑の端に立てます | 日陰に置くと乾かず、カビが生えやすくなります |
| 受け止め | 下にむしろ（藁のござ）や布を敷いておきます | 乾く間に自然に落ちるものを受け止めます |
| 期間 | 7日から15日 | 蒴果の大半が裂けるまで置きます |
| 雨への備え | 雨の予報があれば覆うか、取り込みます | 濡れると蒴果がまた閉じ、種子が傷みます |

| 打ち落としの段階 | 方法 |
|---|---|
| 1回目 | むしろの上で束を逆さに持ち、棒で茎を軽くたたきます |
| 2回目 | 再び立てて二、三日さらに乾かしてから、繰り返します |
| 3回目 | 上の蒴果が裂けたら、もう一度行います |
| 仕上げ | 残った蒴果を手でしごくか、茎ごともみほぐして落とします |

&nbsp;&nbsp;&nbsp;一度にすべて落ちないのが正常です。下の蒴果は一回目でほとんど出きり、上のほうは数日さらに乾かしてはじめて裂けます。二度三度の繰り返しを面倒に思い、一度に強くたたくと、茎や葉のくずが一緒に落ちて、選別の手間だけが増えます。軽く何度も、というのが要領です。

### 12-4. 選別

| 方法 | 内容 |
|---|---|
| ふるい分け | 目の粗いふるいで、茎や蒴果のかけらを取り除きます |
| 箕あおり | 箕に入れてあおると、軽い殻が飛んでいきます。ゴマの種子はアマランサスより重いので、箕あおりがよく効きます |
| 風の利用 | 風の吹く日に高いところからゆっくり注ぐと、殻が横へ飛んでいきます |
| 水洗い | 水に入れてかき混ぜると、殻やほこりが浮き、種子が沈みます |
| 乾燥 | 水洗いしたものはすぐに広げて、完全に乾かします |

> **ゴマを水で洗ったら、その日のうちに必ず乾かさなければなりません。油分の多い種子が水気を含んだまま積まれていると、熱が出てカビが生え、一度そうなると、油から悪臭が出て使えなくなります。**

### 12-5. 葉用エゴマの収穫

| 項目 | 内容 |
|---|---|
| 開始 | 本葉が4枚ほどになった時から |
| 適期 | 葉が完全に開いて表面が鮮やかな緑色になり、葉脈が紫色を帯びたとき。大きさは7-10cm |
| 方法 | 上のまだ開ききっていない若い葉2枚から4枚を必ず残し、下の大きな葉だけを摘みます |
| 間隔 | 夏は3日から5日 |
| 期間 | 韓国では6月下旬から9月下旬 |

&nbsp;&nbsp;&nbsp;上の若い葉を2枚から4枚残すことが、繰り返し収穫の要です。それらの葉が光合成を続けて、次の葉をつくり出します。欲張って上まですべて摘むと、株は回復できず、そのまま止まってしまいます。

## 13. 採種と種子の保管

### 13-1. 採種

| 段階 | 方法 | なぜそうするのか |
|---|---|---|
| 株を選ぶ | 病気がなく、蒴果がたくさんつき、倒れていない株を選びます | 種子は親に似ます。萎凋病があった株は決して使いません |
| 印をつける | 開花期にあらかじめ印をつけておきます | 収穫のときには見分けるのが難しくなります |
| どこから採るか | 茎の中ほどの蒴果から採ります | 下のほうは先にこぼれ、上のほうは十分に実っていません。中ほどがもっとも充実しています |
| 完全に熟させる | 蒴果が完全に褐色に乾くまで置きます | 熟し切っていない種子は発芽力が低いからです |
| 袋をかぶせる | 採種する茎に布の袋をかぶせて結んでおきます | 自然に裂けてこぼれ落ちる種子を受け止めます |
| 乾燥 | 日陰で水分12%以下まで乾かします | 日に長く当てると油が傷みます |
| 保管 | 密閉容器に入れ、涼しく暗い場所に置きます | 光と熱と空気が油を傷めます |

&nbsp;&nbsp;&nbsp;評価表の自家採種Sは、ゴマもエゴマもともに自家受粉が中心であるという点に支えられています。ハチが花粉を運ぶこともありますが、ほとんどは自分の花の中で受精が終わるため、品種が大きく混ざることはありません。複数の品種を一つの畑に置いても、種子を別々に採ることができます。

&nbsp;&nbsp;&nbsp;ただし、採種用の株を選ぶときには、とくに確認すべき点が一つあります。萎凋病の痕跡がある株からは、決して種を採りません。この病気は種子を通じても伝わるため、病気の株から採った種子を翌年、新しい畑にまくと、その畑まで汚染されます。3年、4年と守って輪作をしても、この一点で台無しになります。

### 13-2. 保管

| 条件 | 発芽力が保たれる期間 |
|---|:---:|
| 完全に乾かして密閉し、涼しく暗い場所 | 1-2年 |
| そのまま常温に置いた場合 | 1年未満 |
| 日光や熱が当たる場所 | 数か月 |

&nbsp;&nbsp;&nbsp;評価表の種子寿命C、「油糧種子のため短命、常温で1-2年」は、この作物のもっとも重い制約の一つです。アマランサスの種子が3-5年、ケールが4-5年もつのとは大きく異なります。理由は油です。種子の中の油が空気に触れて酸化すると過酸化物が生じ、それが種子の中の胚を傷めます。油の多い種子ほど寿命が短いというのは、油糧作物全体に当てはまる規則です。

> **ゴマは、種子を寝かせておけない作物です。毎年採って毎年植えなければならず、一年飛ばすと、その次の年には芽が出ません。**

| 寿命を延ばす方法 | 原理 |
|---|---|
| 完全に乾かして入れます | 水分が残ると酸化が速くなります |
| 空気が触れないよう密閉します | 酸素があってはじめて油が酸化します |
| 涼しい場所に置きます | 温度が10℃上がるごとに酸化速度が倍になります |
| 暗くして置きます | 光が酸化を促進します |
| 炒っていないものを使います | 炒ると細胞が壊れ、油が空気にさらされます。種子用は決して炒りません |
| 多めに採っておきます | 発芽率が落ちることを見込んで、必要量の2倍を採ります |
