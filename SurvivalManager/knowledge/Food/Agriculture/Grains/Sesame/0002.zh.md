## 1. 灾害应对评价

&nbsp;&nbsp;&nbsp;芝麻因单位面积热量为E，即达不到自给线的15%，而被判定为排除。这意味着它不能成立为粮食作物。如果不适用这一排除关卡，得分为35.7分，在有效的183种中排名第162位。区分“排除”这一判定说明了什么、没有说明什么，是本节的任务。

### 1-3. 单位面积热量E衡量的是什么

&nbsp;&nbsp;&nbsp;在这张表里，造成排除判定的只是第一行：每1,000㎡80kg，每100g 38kcal，每㎡30kcal，相当于自给线的0.01倍。必须读懂这一计算是针对什么对象进行的。成分数据来源是紫苏叶（生），分类是唇形科紫苏属，光照响应组被设定为叶菜类。也就是说，这项评价衡量的不是种子，而是叶子。

&nbsp;&nbsp;&nbsp;以叶子为基准，结果是理所当然的。紫苏叶每100g为38kcal，而且紫苏叶并不是一次吃很多的蔬菜，只摘叶子的栽培方式所能收获的重量也不大。只能得出自给线的1%这样的数值。排除这一判定是准确的。靠紫苏叶是填不饱肚子的。

> **芝麻的热量等级处于最低这一事实，与芝麻在灾害情境中毫无用处这一判断，是完全不同的两回事。这种作物产出的不是热量而是油，而油的价值不会体现在热量表上。**

&nbsp;&nbsp;&nbsp;那么，种子方面的数字如何，需要另外来看。芝麻种子每100g为539-573kcal，紫苏种子也超过550kcal。这相当于谷物的1.5倍、马铃薯的7倍，在所有食物中属于最高之列。芝麻的产量为每1,000㎡约60-100kg，数量不多，但换算成热量，每㎡在350kcal左右。与以叶子为基准的30kcal相比，相差10倍以上。

&nbsp;&nbsp;&nbsp;即便如此，它也只占自给线2,616kcal的13%，所以仍然成不了主食。判定不会改变。只是，这13%是什么性质的13%，情况有所不同。那是由脂肪构成的热量，是其他任何作物都无法替代的一类热量。

### 1-4. 油的价值

&nbsp;&nbsp;&nbsp;评价表中没有衡量油的栏目。但是，只要把油在灾害情境下的家庭生活中所起的作用一一列出，就能看出为什么不能把这种作物从田里划掉。

| 用途 | 带来什么变化 |
|---|---|
| 烹饪 | 可以炒、煎、炸。只靠煮和蒸无法食用的食材，也变得可以食用 |
| 脂溶性维生素的吸收 | 维生素A、D、E、K和β-胡萝卜素必须有脂肪才能进入身体。这就是凉拌野菜（namul）要拌油的缘故 |
| 必需脂肪酸 | 亚油酸和α-亚麻酸身体无法合成，必须从饮食中摄取 |
| 热量浓缩 | 脂肪每1g含9kcal，是碳水化合物的两倍多。在需要少吃多得热量时价值很大 |
| 灯火 | 插上灯芯点燃，就成了灯火。这是停电夜晚唯一的光亮 |
| 肥皂 | 与草木灰水相遇就成了肥皂。可防止卫生状况崩溃 |
| 防水与防腐 | 给木材、皮革和纸张上油后，水就渗不进去 |
| 润滑 | 涂在金属件、合页和工具上，减少锈蚀和摩擦 |

&nbsp;&nbsp;&nbsp;在这八项用途中，谷物、薯类（块茎/块根）或蔬菜能够替代的，一项也没有。如果有牲畜，可以用动物油脂替代一部分，但在连喂养牲畜的饲料都不足的情况下，很难把牲畜当作油的来源。能在田里生产出油的途径只有油料作物，而其中芝麻的种子含油量属于最高之列。

### 1-5. 如何解读优势

&nbsp;&nbsp;&nbsp;获得SS的项目有蛋白质密度、微量营养素、设施负担三项。S级给了耐储性、韩国国内栽培普及度、自家留种，A级给了施肥需求、耗水量、烹饪·加工、无合成投入产量保持率、产量稳定性。

&nbsp;&nbsp;&nbsp;最实际的优势是韩国国内栽培普及度S。由于韩国8个道全境均有商业栽培，无论在哪个地区都能获得种子。这与蕹菜（空心菜）和籽粒苋的普及度为B、在主产区以外难以获得种子的情况大不相同。在灾害发生时能否拿到手这个问题上，这一差别具有决定性意义。

&nbsp;&nbsp;&nbsp;无合成投入产量保持率A（56.0%）也是值得留意的数值。它的意思是在断绝化肥后仍能保住一半以上的产量，与叶菜类的40.8%相比要好得多。这种作物本来就生长在贫瘠的土地上，不太依赖肥料。施肥需求A（每㎡18g）这一较低的需求量，说的也是同一件事。

&nbsp;&nbsp;&nbsp;耗水量A和产量稳定性A也要一并来看。芝麻是耐旱作物的代表，总蒸散量400mm相当于水稻的1/3左右。年际变动率6.3%意味着每年的收成不会大幅波动。不过，这种稳定性是有前提的。在韩国的梅雨季（6月下旬至7月）持续很长、田地被淹的年份，这一数值完全不适用。

&nbsp;&nbsp;&nbsp;自家留种S依靠的是以自花授粉为主这一特性。品种不易混杂，即使把几个品种放在同一块田里，也能分别留种。在买不到种子袋的情况下，这是一道重要的保险。

### 1-6. 如何解读劣势

&nbsp;&nbsp;&nbsp;获得E的项目有单位面积热量和耐寒性两项，D级给了整地·挖掘能耗和口味，C级给了收获速度、温度适应幅度、病虫害压力、防治自立度、连作适应性和种子寿命。

&nbsp;&nbsp;&nbsp;连作适应性C是实际操作中最沉重的项目。芝麻的枯萎病和疫病病原菌会长期残留在土壤中，所以需要休作3-4年。在田地狭小的情况下，这一限制相当大。年年种在同一个地方，最初一两年还没问题，从第三年起就会突然崩溃。第11节的轮作计划将处理这个问题。

&nbsp;&nbsp;&nbsp;种子寿命C同样必须牢记。在常温下，1-2年发芽力就会下降。这是含油量高的种子难以逃脱的宿命。油脂接触空气会氧化，氧化的油脂会损伤种子里的胚。这与籽粒苋种子能保存3-5年大不相同。

> **芝麻是必须年年重新留种的作物。指望陈年种子而跳过一年，再下一年就没有可种的东西了。**

&nbsp;&nbsp;&nbsp;耐储性S所附的说明也是同一回事。其中写明种子在常温下可保存1年，达不到3年的原因是油脂酸败。其他谷物能撑好几年，而芝麻的极限是一年。不过，芝麻中含有芝麻素和芝麻林素这两种天然抗氧化成分，因此酸败比其他植物油慢。这一差别在第15节和第16节中会实际用到。

&nbsp;&nbsp;&nbsp;整地·挖掘能耗D（热量回收倍数2.8倍）意味着，相对于耕地所耗费的力气，回收的热量很少。在没有机械、必须靠人力翻地的情况下，这个数值是实实在在的负担。不过，这项计算同样依赖以叶子为基准的热量，若换算成油，情况就不同了。

&nbsp;&nbsp;&nbsp;口味D源自“气味与香气令人排斥”这条说明。这是针对紫苏叶的强烈香气给出的数值，而且这种香气确实让人好恶不一。然而，同样的香气也是非食用价值C的依据。因为强烈的香气能驱赶野兽和害虫。把芝麻种在田边或其他作物之间，獐子和野猪就会少进来一些。对食用者来说是负担的特性，在守护田地方面却派上了用场。

&nbsp;&nbsp;&nbsp;最后，还有两项在评价表中完全没有体现的隐患。一是渍害。芝麻一旦积水，几天之内就可能毁掉整块田，但这一风险没有被纳入任何一栏。另一个是落粒。蒴果成熟后会自行裂开，把种子撒落，所以错过收获时机，种子就会撒在田里。这两项是实际栽培中最常造成损失的原因，分别在第7节和第12节中讨论。
