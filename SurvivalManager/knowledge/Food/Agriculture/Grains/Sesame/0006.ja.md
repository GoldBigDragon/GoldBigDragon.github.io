## 14. 毒性と注意すべき成分

### 14-1. 毒性はありません

&nbsp;&nbsp;&nbsp;ゴマとエゴマには、人体に有害な毒成分はありません。ジャガイモのソラニンやキャッサバのシアン配糖体のようなものはなく、種子を生で食べても問題になりません。ただし、知っておくべきことがいくつかあります。

### 14-2. アレルギー

&nbsp;&nbsp;&nbsp;ゴマは、主要なアレルギー誘発食品の一つに分類されています。人によって、じんましん、口の中が腫れる感じ、呼吸困難といった反応が現れ、まれに重い全身反応に至ることもあります。医療を受けにくい災害時には、この点が平時よりも重要になります。

| どうするか | 内容 |
|---|---|
| 初めて食べる人には少量から | 特に子どもに初めて与えるときは、少量から始めて反応を見ます |
| 反応が出たらやめます | ゴマ油やゴマ塩（ケソグム）まですべてやめます。ごく微量でも反応が出ます |
| エゴマで代用します | ゴマのアレルギーがエゴマで必ず現れるとは限りません |

### 14-3. 種皮のシュウ酸とフィチン酸

| 成分 | どこにあるか | 何が問題か | どうするか |
|---|---|---|---|
| シュウ酸 | 種皮、特に黒ゴマ | カルシウムと結合して吸収を妨げます。ゴマにカルシウムが多いのに使い切れない理由です | 炒ると一部が減ります。皮をむくと大きく減りますが、カルシウムも一緒に減ります |
| フィチン酸 | 種子全体 | 鉄、亜鉛、カルシウムと結合して吸収を妨げます | 水に浸す、炒る、発酵させると減ります |

&nbsp;&nbsp;&nbsp;皮をむくかどうかは、天秤にかけて決めることです。カルシウムの大部分は種皮に含まれているため、むくとカルシウムを失い、皮ごと食べるとシュウ酸がそのカルシウムの吸収を妨げます。実際には、皮ごと炒って食べるほうがよいです。炒る過程でシュウ酸がある程度分解され、吸収されないカルシウムがあったとしても、まったくないよりはましだからです。

### 14-4. 油の酸敗

&nbsp;&nbsp;&nbsp;ゴマで実際に危険になるのは、毒成分ではなく傷んだ油です。油が空気に触れて酸化すると、過酸化物とアルデヒドが生じます。これらは臭いが悪いだけでなく、体に有害で、消化器を刺激します。

| 見分け方 | 内容 |
|---|---|
| におい | 香ばしい香りが消え、酸っぱいにおいやペンキのようなにおいがします |
| 味 | 苦味やえぐ味が出ます |
| 色 | 色が濃くなり、濁ります |
| ねばつき | 瓶の口や容器の底にべたべたとこびりつきます |

> **においが変わった油は食べません。ただし、捨てもしません。灯火用の油として使うか、石けん作りに使います。食べられなくなった油にも、なお使い道が残っています。**

&nbsp;&nbsp;&nbsp;ゴマ油は、セサミンとセサモリンのおかげで酸敗がゆっくりです。エゴマ油はα-リノレン酸が60%を超えていてはるかに早く傷みますが、その代わり空気中で固まる性質があり、木や紙にしみ込ませる用途に使われます。油紙や木材の仕上げの原理は、これです。

### 14-5. その他の注意

| 項目 | 内容 |
|---|---|
| 脂肪の摂りすぎ | ゴマは100gで500kcalを超えます。熱量が足りない状況では長所ですが、一度にたくさん食べると下痢をします |
| エゴマの葉の硝酸塩 | 肥料を多く施した葉にたまります。ゆでた湯は捨て、乳児には多く食べさせません |
| エゴマの葉の生食 | 洗ってそのまま食べられます。ただし、畑で肥料として使ったのが糞便だった場合は、加熱して食べます |
| 炒ったゴマの保管 | 炒ると香りはよくなりますが、酸敗が早まります。食べる分だけ炒ります |

## 15. 冷蔵庫なしの貯蔵

### 15-1. 種子のまま置くのが原則です

&nbsp;&nbsp;&nbsp;ゴマの貯蔵には原則が一つあります。油に搾って置くより、種子のまま置くほうがはるかに長持ちするということです。

| 形態 | 常温での保存期間 | 理由 |
|---|:---:|---|
| 炒っていない種子 | 1年前後 | 油が細胞の中に閉じ込められていて、空気に触れにくいためです |
| 炒った種子 | 3-6か月 | 細胞が壊れて、油が空気にさらされるためです |
| すりゴマ | 1か月以内 | 表面積が大きく増え、急激に傷むためです |
| 搾ったゴマ油 | 6か月から1年 | セサミンのおかげで、植物油の中では長持ちするほうです |
| 搾ったエゴマ油 | 2-3か月 | α-リノレン酸が多く、早く傷みます |

> **ゴマは、倉庫に種子のまま積んでおき、使う分だけその都度炒って搾る作物です。一度にすべて搾っておくと、半年で食べられなくなります。**

### 15-2. 種子の貯蔵

| 段階 | 方法 | 理由 |
|---|---|---|
| 十分に乾燥させる | 水分12%以下まで乾かします。手で握るとさらさらと音がし、歯で噛んでぱきっと音がすれば、乾燥は十分です | 水分が残るとカビが生え、酸敗が早まります |
| 冷ます | 日に干したあと、日陰で完全に冷ましてから入れます | 温かいまま入れると、容器の中に露がつきます |
| 密閉 | 甕、ガラス瓶、金属缶に入れて蓋をします | 酸素と湿気を防ぎます |
| いっぱいに詰める | 容器をできるだけいっぱいに満たします | 容器内の空きスペースにある空気が油を傷めます |
| 乾燥剤 | 炒って冷ました塩や炭を布に包んで入れます | 残った湿気を吸い取ります |
| 置き場所 | 涼しく暗く、温度変化の少ない場所に置きます | 土室、地下、北向きの部屋が適しています |
| ÷ | 複数の容器に分けて入れます | 一つの容器を失っても、すべてを失わずにすみます |

&nbsp;&nbsp;&nbsp;容器をいっぱいに満たすという項目が、ほかの穀物の貯蔵と異なる点です。油の多い種子は、空気に触れる面を減らすほうが有利です。甕に半分だけ入れておくと、その上の空気が油を傷めるため、小さな容器を複数用意して、それぞれをいっぱいに満たす方式のほうがよいです。

&nbsp;&nbsp;&nbsp;穀物につく虫も問題になります。密閉が第一で、乾燥トウガラシやサンショウ、灰を一緒に入れておくと、虫がつきにくくなります。虫が入っているのを見つけたら、日に広げて追い出したあと、もう一度乾かして入れ直します。

### 15-3. 油の貯蔵

| 方法 | 内容 |
|---|---|
| 小さな瓶に分けて入れます | 開けるたびに空気が入るので、使う分だけ入った瓶を開けます |
| いっぱいに満たして栓をしっかり閉めます | 瓶の中の空きスペースを減らします |
| 暗い色の瓶や甕を使います | 光が酸化を促進します |
| 涼しい場所に置きます | 台所の火の近くには置きません |
| 炒らずに搾った油を別に取っておきます | 香りは弱いですが、長持ちします |

### 15-4. エゴマの葉の貯蔵

| 方式 | 方法 | 期間 |
|---|---|:---:|
| そのまま置く | 洗わずに水気を切って、涼しい場所に | 2-3日 |
| 干す | 日陰の風通しのよい場所で完全に乾かし、密閉します | 数か月 |
| チャンアチ（醤油漬け） | 醤油やテンジャン（韓国味噌）に一枚ずつ重ねて漬け込みます | 数か月 |
| 塩漬け | 塩に漬けて重しをしておきます | 数か月 |
| キムチ | ヤンニョム（合わせ調味料）で味付けして甕に入れます | 2-3か月 |
| 冷凍 | ゆでて水気を絞り、凍らせます | 数か月 |

&nbsp;&nbsp;&nbsp;エゴマの葉は香りが強く、チャンアチや漬物によく合います。醤油に漬け込んだエゴマの葉はそのままおかずになり、醤油にも香りが移るので、二つを得られます。乾燥させたエゴマの葉は香りが飛びますが、汁物やお粥に入れれば、なお役に立ちます。

## 16. 調理と加工 - 油を搾る作業

### 16-1. 炒るか、炒らないか

&nbsp;&nbsp;&nbsp;油を搾る前に決めることは、炒るか炒らないかです。この選択が、できる油の性格をまったく変えてしまいます。

| 区分 | 炒って搾った油 | 炒らずに搾った油 |
|---|---|---|
| 香り | 香ばしい香りが強いです | 香りがほとんどありません |
| 色 | 濃い茶色です | 澄んだ黄色です |
| 搾れる量 | より多く出ます | あまり出ません |
| 煙が出る温度 | 低いです。炒め物には向きません | 高いです。揚げ物に使えます |
| 長持ちの度合い | 炒る間にセサモールが生じ、かえって長持ちします | 普通です |
| 主な使い道 | 和え物、仕上げにかける油 | 炒め物、揚げ物、灯火、石けん |

&nbsp;&nbsp;&nbsp;炒ると油がよく出る理由は、熱が細胞壁を軟らかくし、細胞内の油滴が互いに合わさるためです。閉じ込められていた油が、押されたときに出る道を得るわけで、同じ理由から、炒らずに搾ると種子の中に残る油が多くなります。

| 炒り方のコツ | 内容 |
|---|---|
| 火 | 弱火から中火で |
| かき混ぜ | 休まずかき混ぜます。片側だけ焦げると苦味が出ます |
| 目安 | ぱちぱちとはじける音がし、色が薄い茶色に変わり、香ばしいにおいがします |
| 仕上げのタイミング | 色づき始めたらすぐに火から下ろします。余熱でも加熱が進みます |
| 冷まし方 | 広げて冷まします。積んでおくと、中で加熱が進んで焦げます |

### 16-2. 油を搾る原理

&nbsp;&nbsp;&nbsp;油搾りの原理は単純です。細胞の中にある油滴を外に取り出して一つに集め、流れ出させることです。そのために、砕き、温め、押します。

| 段階 | 何をするか | 理由 |
|---|---|---|
| 砕く | 臼や石臼で種子をつき砕きます | 細胞壁を壊さなければ油が出ません。細かくつくほどよく出ます |
| 温める | つき砕いたものを蒸し器で蒸すか、鍋で温めます | 油の粘度が下がって流れやすくなります。タンパク質が固まり、かすがまとまります |
| 包む | 麻布や木綿の袋に入れます | かすは閉じ込め、油だけを通します |
| 押す | てこやくさびで力いっぱい押します | 圧力が強いほどよく出ます |
| 受ける | 流れ出た油を容器に受けます | |
| 沈殿させる | 一日二日置いて、かすを沈めます | かすが残ると油が早く傷みます |
| 移し取る | 澄んだ上の部分だけを注ぎ分けます | |

| 圧搾方式 | 作り方 | 得られる量 |
|---|---|---|
| てこ圧搾 | 長い丸太の一端を柱にかけ、反対側に重い石をつり下げます。中ほどに袋を置きます | 種子重量の30-40% |
| くさび圧搾 | 丸太の枠の中に袋を入れ、木のくさびをハンマーで打ち込んで押します | 35-45% |
| ねじ圧搾 | 太いねじで板を押し下げます。金属が必要です | 40-50% |
| 手でねじる | 袋を二本の棒の間に挟んでねじり、絞ります | 20-30% |

&nbsp;&nbsp;&nbsp;ゴマの種子の油分は45-55%なので、伝統的な圧搾では、含まれている油の3分の2から75%を取り出す計算です。1kgから350-450gが得られ、残りは油かすに残ります。残った油が油かすの飼料価値を高めるので、必ずしも損ではありません。

### 16-3. 押さずに搾る方法

&nbsp;&nbsp;&nbsp;圧搾の道具を作れない状況で使える方法があります。水を利用して油を浮かせて取り出す方式です。

| 段階 | 方法 | 原理 |
|---|---|---|
| つく | 炒ったゴマを細かくついて、どろどろにします | 細胞を壊します |
| 水を入れる | 水を少しずつ加えながら、すり続けます | 油と水が混ざった、どろりとした状態になります |
| 煮る | 広い鍋に移し、弱火で煮ます | 水が沸くにつれて、油滴が互いに合わさります |
| すくい取る | 上に浮いてきた油をお玉ですくいます | 油は水より軽いので浮きます |
| 煮詰める | すくった油を再び弱火で温め、残った水分を飛ばします | 水が残ると油が傷みます |

&nbsp;&nbsp;&nbsp;アフリカとインドで古くから使われてきた方法で、道具がほとんど要らないのが長所です。得られる量が圧搾より少なく、燃料がかかるのが短所で、残ったものはやはり油かすとして使います。

### 16-4. 油かすの使い道

&nbsp;&nbsp;&nbsp;油を搾って残った油かすは、捨てるものではありません。もとの種子の半分以上が油かすとして残り、その中にタンパク質が35-40%含まれています。

| 使い道 | 内容 | 注意 |
|---|---|---|
| 人の食料 | つき砕いて、お粥やトック（餅）に混ぜます | タンパク質が多く、価値が高いです。粗いので、たくさん入れると食べにくくなります |
| 家畜の飼料 | ニワトリ、ブタ、ウシに良いタンパク源です | 一度にたくさん与えると、油のせいで下痢をします |
| 肥料 | 窒素5-6%、リン酸2%、カリウム1%前後 | 必ず腐熟させて施します。生のままだと、土の中で熱を出して根を傷めます |
| 釣りの撒き餌、誘引剤 | においが強く、魚や虫を引き寄せます | |
| 薪 | 乾かして燃やします | 油が残っているのでよく燃えます。ほかの使い道があるなら、燃やしません |

> **一袋のゴマは、油と飼料と肥料の三つに分かれます。油かすを捨てるのは、搾り取った油と同じだけの価値を、もう一度捨てることです。**

### 16-5. 灯火用の油

&nbsp;&nbsp;&nbsp;電気が止まった夜に明かりをともすのに、植物油が使われます。ゴマ油は昔から灯火用の油として使われてきました。

| 項目 | 内容 |
|---|---|
| 灯心 | 木綿糸、麻糸、布をよって作ります。太いほど明るく、油が早く減ります |
| 容器 | 浅い皿や小皿に油を注ぎ、灯心の一端を浸します |
| 原理 | 灯心の糸の隙間を伝って油が吸い上げられ、炎がその先端で油を燃やします |
| どの油がよいか | ゴマ油は煤が少なく、よく上がります。エゴマ油は煤が多く、灯心にかさぶたのようなものがつきます |
| どの油を使うか | 食べにくくなった油、においが変わった油を先に使います |
| 明るさ | 灯火一つでロウソク一本ほどです。いくつか集めれば部屋一つを照らせます |

&nbsp;&nbsp;&nbsp;順序を決めておく必要があります。油はまず食べ、食べにくくなったものを灯火に使い、それも過ぎたら石けんにします。傷んでいないゴマ油を最初から燃やすのは、熱量を燃やすことになります。

### 16-6. 石けん作り

&nbsp;&nbsp;&nbsp;油と強いアルカリが出会うと、石けんになります。この反応が災害時にもつ意味は大きいです。衛生が崩れると、下痢を伴う病気や皮膚病が広がり、それが飢えよりも先に人の命を奪うことも珍しくありません。

| 段階 | 方法 | 何が起こるか |
|---|---|---|
| 灰汁を取る | 広葉樹の灰を水に溶いて一日置き、上澄みを取ります | 灰に含まれる炭酸カリウムが水に溶け出します。これが灰汁です |
| 苛性化 | 灰汁に、貝殻や石灰石を焼いて作った生石灰を入れてかき混ぜ、沈殿させます | 炭酸カリウムが水酸化カリウムに変わります。白い沈殿は炭酸カルシウムなので、沈めて捨てます |
| 濃さの確認 | 鳥の羽根やジャガイモを浮かべてみます | 羽根が溶け始めるか、ジャガイモが硬貨ほどの大きさだけ水面に浮かび上がれば、十分な濃さです |
| 混ぜる | 油を温め、灰汁を少しずつ注ぎながら休まずかき混ぜます | 油の脂肪がアルカリと出会い、石けんとグリセリンに分かれます |
| 煮る | 弱火でかき混ぜながら数時間煮ます | 反応が終わるまで続けます。どろりとして、色が変わっていきます |
| 固める | 塩を入れると、石けんが固まって上に浮きます | 水に溶けていた石けんが、塩によって分離します |
| 仕上げ | すくい上げて型に入れて固めるか、そのまま軟らかい石けんとして使います | 灰の灰汁で作ったものは軟らかい石けんになり、塩を入れると硬くなります |

| 注意 | 内容 |
|---|---|
| 灰汁は皮膚や肉を傷めます | 目や皮膚につかないようにします。ついたら水で長く洗い、薄めた酢ですすぎます |
| 金属の容器を避けます | アルミの容器は腐食します。鋳鉄の鍋か、オンギ（韓国の陶製の甕）を使います |
| 未完成の石けんは刺激が強いです | アルカリが残っていると肌を傷めます。数週間置いて熟成させてから使います |
| 針葉樹の灰は弱いです | 広葉樹の灰のほうがアルカリ成分が多いです |

> **石けんに使う油の順序は明確です。食べられなくなった油、動物の脂、油かすから出た残りの油が先で、傷んでいないゴマ油は最後です。油一升は、石けんになる前に、まずおかずにならなければなりません。**

### 16-7. 種子をそのまま食べる方法

| 方法 | 内容 | 燃料 |
|---|---|---|
| 炒ってそのまま | 炒ったゴマをご飯やナムル（野菜の和え物）にふりかけます | 数分 |
| ゴマ塩 | 炒ったゴマを塩と一緒につきます | 炒る時間だけ |
| ゴマ粥 | 炒ってつき砕いたゴマを水に溶き、米を入れて煮ます | お粥を煮る時間 |
| ケガンジョン（ゴマの固め菓子） | 炒ったゴマをチョチョン（穀物の水あめ）で和えて固めます | チョチョンを煮る時間 |
| すって汁物に | つき砕いたゴマを汁物や和え物に入れます | なし |

&nbsp;&nbsp;&nbsp;油を搾る道具がなければ、つき砕いてそのまま食べるのがもっとも効率が高いです。搾る過程で失うものがなく、タンパク質や繊維まで一緒に食べられるからです。ただし、丸のまま飲み込むと皮が消化されないので、必ずつき砕かなければなりません。

### 16-8. エゴマの葉の調理

| 方法 | 内容 |
|---|---|
| サム（包み野菜） | 洗ってそのまま使います |
| チャンアチ | 醤油やテンジャンに漬け込みます。貯蔵を兼ねます |
| ジョン（衣焼き） | 小麦粉の衣をつけて焼きます |
| チム（蒸し物） | 一枚ずつヤンニョムを塗り重ねて蒸し上げます |
| スープ（国）とチゲ | 最後に入れます。長く煮ると香りが飛びます |

### 17-2. 一年を貫く軸

&nbsp;&nbsp;&nbsp;韓国でのゴマ栽培の一年には、三つの山場があります。5月の畝立て、7月の梅雨、9月末の収穫時期です。

&nbsp;&nbsp;&nbsp;5月の畝立ては、目に見えない山場です。植えるときは、畝の高さがまったく差を生まないように見え、その差は二か月後の梅雨になって初めて表れます。シャベル一杯の土を惜しんで畝を低く立てると、7月に畑全体を失います。

&nbsp;&nbsp;&nbsp;7月の梅雨は、この作物の運命が分かれるときです。できることは、畝間の水を流し、病んだ株を抜き取ることだけで、残りは5月にすでに決まっています。

&nbsp;&nbsp;&nbsp;9月末の収穫は、数日を争う山場です。下のほうの蒴果が二、三個裂ける瞬間が目安で、その数日を逃すと、一年分の農作業の成果を畑にこぼしてしまいます。9月中旬から三、四日に一度、下のほうの蒴果を確かめる習慣が、何よりも価値があります。

> **ゴマ栽培は、5月に畝を高くし、9月に目で見極めて収穫します。畝をどれだけ高く立てたかが半分で、下の蒴果が裂ける日に気づくことが残りの半分です。**
