# 芝麻·紫苏
- 来源: 韩国农村振兴厅 农事路（Nongsaro）、韩国国家标准食品成分表、FAO ECOCROP、Wiki、Gemini、Claude、Chat-GPT
- 编者: GoldBigDragon
---
## 引言
&nbsp;&nbsp;&nbsp;在韩语中，同一个名字（kkae）指的是两种不同的植物。芝麻（Sesamum indicum）是胡麻科一年生草本，种子可榨芝麻油；紫苏（Perilla frutescens）是唇形科一年生草本，种子可榨紫苏油，叶子作为紫苏叶食用。在评价表中，这种作物因单位面积热量为E（低于自给线的15%）而被排除出粮食作物，这个判定是准确的。但这种作物的价值不在热量，而在油。种子的45-55%是油，榨1kg可得400g左右，榨后剩下的油饼里仍有35-40%的蛋白质，可作饲料和肥料。几垄地就够供应一年的用油。它的弱点是潮湿。芝麻极耐旱，但田里积水一两天，根就会受损，疫病随之蔓延，所以在有梅雨季的韩国，垄筑得多高、排水沟开得多好，决定成败。收获必须在下部蒴果刚开始裂开时进行，错过这个时机，种子就会撒落在田里。

---
## 1. 灾害应对评估
| 类别 | 内容 |
|:---|:---|
| 判定 | 排除（单位面积热量E，低于自给线的15%）。未适用关卡得分35.7（相当于有效183种中的第162位） |
| 评估依据 | 紫苏叶（生）。80kg/1,000㎡ × 38kcal/100g = 30kcal/㎡，为自给线的0.01倍 |
| 种子依据 | 芝麻种子539-573kcal/100g，每1,000㎡产60-100kg，每㎡约350kcal，为自给线2,616kcal的13% |
| 优势 | SS：蛋白质密度、微量营养素、设施负担。S：耐储性、国内种植普及度（在任何一个道都能买到种子）、自留种。A：施肥、水消耗量、烹调·加工、无合成投入产量保持率（56.0%）、产量稳定性 |
| 劣势 | E：单位面积热量、耐寒性（一次霜冻就会枯死）。D：整地·挖掘能量、口味（对气味和香气有抵触）。C：收获速度、温度幅度、病虫害压力、防治自立度、连作适应性（需休耕3-4年）、种子寿命 |

> **这种作物的热量等级最低，与它在灾害中毫无用处，是完全不同的两回事。这种作物产出的不是热量，而是油。**

&nbsp;&nbsp;&nbsp;油可用于煎炒油炸的烹调、脂溶性维生素（A、D、E、K）的吸收、必需脂肪酸、断电之夜的灯火、肥皂、木材·皮革·纸张的防水和防腐，以及金属的润滑。谷物、蔬菜和薯类都无法替代其中任何一项。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 类别 | 芝麻 | 紫苏 |
|:---|:---|:---|
| 原产地 | 非洲至印度的干旱地带 | 东亚 |
| 主要用途 | 种子榨芝麻油 | 种子榨紫苏油，叶子作紫苏叶 |
| 油的性质 | 酸败慢 | 酸败快 |
| 叶 | 窄披针形，有毛 | 宽心形，边缘有锯齿 |
| 干旱、涝害 | 极耐旱，极怕涝 | 耐旱一般，较耐涝 |

&nbsp;&nbsp;&nbsp;二者茎均为方形，高60-150cm，以自花授粉为主。芝麻有笔直的主根深扎，能在干土中找水，果实是长2-3cm的蒴果，成熟时上部缝线裂开。种子芝麻长约3mm，紫苏直径1.5-2mm。芝麻的花自下而上用30-40天依次开放，所以下部蒴果成熟时上部蒴果还是绿的，植株还要把资源分给晚开的花，结果籽粒普遍偏小。打顶可以解决这个问题。

| 每100g营养 | 芝麻（炒的） | 紫苏叶（生） |
|:---|:---|:---|
| 热量 | 539kcal | 38-47kcal |
| 蛋白质 / 脂肪 | 21.3g / 45-55g | 3.69g / 微量 |
| 碳水化合物 / 膳食纤维 | 27.4g / 10-12g | 大部分是膳食纤维 / 4.5g |
| 其他 | 钙、铁、镁、维生素E丰富。芝麻素和芝麻林素（延缓酸败） | 钙296mg，β-胡萝卜素7,565μg |

## 3. 栽培环境与品种
| 条件 | 芝麻 | 紫苏 |
|:---|:---|:---|
| 温度 | 发芽20-25℃（最低15℃），生长20-30℃，结实20-28℃。10℃时停止生长，遇霜枯死 | 发芽15-25℃，生长·结实20-25℃。超过30℃叶子变硬 |
| 光照 | 每天6小时以上 | 6小时以上，半阴也可 |
| 水 | 总蒸散量约400mm | 相近 |
| 土壤 | 排水良好的砂壤土至壤土，pH 6.0-7.0，土层厚30cm以上 | 有机质丰富、排水良好的土，pH 6.0-7.0，土层厚20cm以上 |
| 垄高 | 20-30cm以上 | 15-20cm |

> **种芝麻最常见的失败原因不是干旱，而是水。排不了水的地，即使其他条件再好，也不要种芝麻。**

| 品种 | 特点 |
|:---|:---|
| 单秆型芝麻 | 单秆。在狭窄的地方密植时用，管理简单 |
| 分枝型芝麻 | 分出侧枝。单株大，产量高。地方宽裕时用 |
| 多黑（密阳28号） | 黑芝麻系统。药用和榨油兼用 |
| 叶用紫苏（叶用紫苏1号、Donggeul 2号、丰年、南川） | 叶宽而软，耐反复采摘。结籽少 |
| 油用紫苏（地方品种） | 结籽多。叶子硬，不适合包着吃 |

&nbsp;&nbsp;&nbsp;榨油和做灯油用芝麻（耐放，烟灰少），夏季叶菜用叶用紫苏，排水不好的田用紫苏。

## 4. 田地准备与播种
| 项目 | 芝麻 | 叶用紫苏 |
|:---|:---|:---|
| 垄 | 高20-30cm以上，宽55-60cm。垄沟要深而宽，田周开排水沟，坡地在上方开拦水沟，把上坡来的水引开 | 高15-20cm |
| 堆肥、复合肥（每1,000㎡） | 1,000-2,000kg，30-35kg。播种前2周全部作基肥，不追肥 | 1,500kg，20-30kg。到采收期每隔10-15天少量追肥 |
| 播种 | 5月中旬至6月上旬（气温15℃以上）。每1,000㎡ 0.3-0.6kg | 4月下旬至5月上旬（霜冻风险过后）。油用紫苏5-6月 |
| 间距、深度 | 垄距55-60cm，株距15-20cm，深2-3cm，每穴5-6粒。播后轻轻压实 | 10 × 5cm或7 × 7cm，深0.5-1cm。盖上稻草、布或报纸，出苗后立即揭掉 |
| 间苗 | 真叶2-4片时，每穴留最壮的一株 | 真叶1-2片和4-6片时分两次 |

&nbsp;&nbsp;&nbsp;没有化肥时，用腐熟堆肥（未腐熟的会招致疫病）、草木灰（每㎡一把）、发酵过的油饼（生的在土里会发热）、稀释10-20倍的尿液（芝麻只在前期少量用）、骨粉、泡草液肥（叶用紫苏追肥）。

| 种子处理 | 方法 |
|:---|:---|
| 只用沉底的种子 | 泡3-4小时，捞掉浮起的秕粒 |
| 温水处理 | 50-55℃的水泡10-15分钟。预防立枯病 |
| 裹草木灰 | 兼作消毒，使种子不粘在一起 |

> **芝麻的种子消毒不是可选项。立枯病随种子传播，在幼苗期一旦蔓延，整块地都得重播。**

## 5. 水分管理与栽培管理
&nbsp;&nbsp;&nbsp;受淹几小时到一天，根里的氧气耗尽，叶子开始萎蔫；两天后根尖开始腐烂；三天以上，疫病菌蔓延到茎基部。水退之后一出太阳，剩下的根承受不住，反而会急剧萎蔫。

| 时期 | 芝麻 | 叶用紫苏 |
|:---|:---|:---|
| 发芽至幼苗期 | 不让表土干，之后省水，让根往深处扎 | 保持不干 |
| 营养生长期 | 靠自然降雨。不积水就是全部 | 表土发白时浇透 |
| 开花·结实期 | 只在严重干旱时补水（开花期和灌浆初期最珍贵） | 保持叶子不萎蔫 |

&nbsp;&nbsp;&nbsp;梅雨前清掉垄沟里的土和草，6月把土培到茎基部再把垄筑高，雨后立刻把倒伏的植株扶起踩实。得疫病的植株一经发现就拔出田外，灌浆期不浇水。

| 管理 | 内容 |
|:---|:---|
| 打顶（芝麻） | 第一朵花开后35-40天，选晴天上午，在最上面的花蕾下面掐断（分枝型的侧枝顶端也掐）。开花停止，籽粒变大，成熟期集中，植株变矮，不易倒伏 |
| 打顶（叶用紫苏） | 株高超过1m时掐掉顶芽，增加侧芽 |
| 防倒伏 | 株高30-40cm时培土，一开始就少施氮，不密植，超过80cm时拉绳固定 |
| 杂草 | 播前翻地让杂草发芽后浅锄掉。幼苗期只在行间浅锄。植株封行后基本不需要 |

## 6. 病虫害与养分问题
| 病害 | 症状与条件 | 对策 |
|:---|:---|:---|
| 疫病 | 根和茎基部发黑腐烂，植株萎蔫。梅雨季，积水时 | 筑高垄并保证排水。病株连土挖出，运到田外 |
| 枯萎病 | 先从一侧叶子萎蔫，茎内变褐。高温期，连作的田 | 无药可治。轮作3-4年是唯一的办法 |
| 立枯病 | 幼芽基部缢缩而倒伏 | 种子消毒。不密播，避开未腐熟的肥 |

> **芝麻的病害对策可归结为两点：筑高垄排水，以及休耕3-4年。**

&nbsp;&nbsp;&nbsp;叶上的褐色斑点（叶枯病、锈病），要保证通风并摘除病叶。蚜虫用强水流或肥皂水冲洗；蝽和蛾类幼虫（棉铃虫、斜纹夜蛾）在清晨或傍晚用手捉，卵块连叶摘掉。防治材料有肥皂水（无香肥皂20g加水1L）、草木灰、大蒜浸出液（大蒜100g加水1L）、稀释500-1,000倍的木醋液、波尔多液（预防叶枯病）。

| 症状 | 原因与对策 |
|:---|:---|
| 整片叶发黄，植株矮小 | 缺氮。稀释的尿液、发酵的油饼、腐熟堆肥 |
| 花开后直接掉落 | 缺磷或缺硼。多种材料混合的堆肥、骨粉 |
| 新叶发黄，只有叶脉是绿的 | 缺铁。少用草木灰，增施有机物 |
| 结了蒴果，里面却是空的 | 缺钾或蝽危害。草木灰，检查蝽 |
| 光长个子并倒伏，只有叶子茂盛 | 氮过多。停止施氮，培土，提前打顶 |

&nbsp;&nbsp;&nbsp;芝麻的养分问题大多不是缺乏，而是氮过多，所以基肥一次施完即可。叶用紫苏收获的是叶子，所以要持续供氮。

## 7. 间作与轮作
| 搭配 | 作物 |
|:---|:---|
| 好 | 豆科（豇豆、绿豆、大豆）、甘薯·马铃薯（根的深度不同）、田边环种（浓烈的气味让獐和野猪不敢靠近） |
| 一般 | 玉米·高粱（会遮阴，所以放在北侧） |
| 差 | 芝麻连作、与灌溉作物并排、紧接茄科（辣椒·番茄·马铃薯）之后 |

&nbsp;&nbsp;&nbsp;第1年芝麻，第2年豆科，第3年十字花科或葫芦科，第4年谷物（高粱·粟·玉米），第5年回到芝麻。地小的话，每年换种植的位置。紫苏2年就行，但避免与芝麻在同一块地上交替种植。

## 8. 收获、脱粒、留种
| 步骤 | 内容 |
|:---|:---|
| 时期 | 9月底至10月初。茎下部两三个蒴果开始裂开、下部叶子变黄脱落时。等上部成熟，下部就全损失了 |
| 割 | 阴天的清晨或傍晚，贴近地面割。不要放倒或摇晃，保持站立姿势收拢，搬运时在下面垫布 |
| 晾晒 | 每五六株在下部扎成一捆，三四捆搭成圆锥形立起。下面铺草席，晾7-15天。预报有雨就盖上或收进屋 |
| 脱粒、清选 | 在草席上把捆倒过来用木棒敲打，再晾两三天后重复。用筛选、扬簸、借风、水洗来分选（洗过的当天必须晒干。湿着堆放会发霉，没法用） |
| 叶用紫苏 | 从真叶四片左右开始，叶片完全展开、长7-10cm时。必须留下上部2-4片嫩叶，只摘下部的大叶。夏天每隔3-5天，6月下旬至9月下旬 |

| 留种 | 标准 |
|:---|:---|
| 植株 | 在开花期标记无病、蒴果多、没有倒伏的植株。得过枯萎病的植株不用 |
| 取种位置 | 茎中部的蒴果。放到完全变褐变干，套上布袋接住撒落的种子 |
| 保管 | 在阴凉处晾到含水量12%以下，装入密闭容器，放在阴凉黑暗处。留需要量的两倍。播种用的不要炒 |
| 寿命 | 密闭、阴凉、黑暗处1-2年，直接放常温不到1年，有阳光或热的地方只有几个月。每年留种，每年播种 |

## 9. 储存
| 形态 | 常温保存 | 原因 |
|:---|:---|:---|
| 未炒的种子 | 1年左右 | 油被锁在细胞里，与空气接触少 |
| 炒过的种子 | 3-6个月 | 细胞破裂，油暴露在空气中 |
| 磨碎的芝麻 | 1个月以内 | 表面积增大，迅速变质 |
| 压榨的芝麻油 / 紫苏油 | 6个月至1年 / 2-3个月 | 芝麻油靠芝麻素耐放，紫苏油α-亚麻酸多，很快变质 |

> **芝麻要以种子形式存放，用多少炒多少、榨多少。一次全部榨出来，半年就不能吃了。**

| 对象 | 要点 |
|:---|:---|
| 种子 | 晾到含水量12%以下，在阴凉处完全放凉后，装满瓮、玻璃瓶或金属桶并密封（空隙里的空气会使油变质）。放在阴凉、黑暗、温度变化小的地方，分装在多个容器里 |
| 油 | 分装到小瓶里装满，把塞子塞紧，放进深色瓶或瓮，放在阴凉处。每次只开一瓶够用的量 |
| 紫苏叶 | 原样放2-3天，晾干密封、酱腌、盐渍可存数月，做泡菜2-3个月 |

## 10. 榨油与加工
| 类别 | 炒后榨的油 | 不炒榨的油 |
|:---|:---|:---|
| 香气、颜色 | 香气浓，深褐色 | 几乎没有香气，澄清的黄色 |
| 出油量 | 出得多 | 出得少 |
| 烟点 | 低。不适合炒菜 | 高。可用于油炸 |
| 用途 | 凉拌，最后淋的油 | 炒菜、油炸、灯油、肥皂 |

&nbsp;&nbsp;&nbsp;炒的时候，用小火到中火不停地翻动。听到噼啪声、变成浅褐色、散发香味时，立刻离火，摊开放凉。种子磨细后用蒸笼蒸或在锅里加热，装进麻布或棉布袋压榨，放一两天使其沉淀，只倒出上面澄清的部分。

| 压榨方式 | 占种子重量的出油率 |
|:---|:---|
| 螺旋压榨（需要铁） | 40-50% |
| 楔子压榨（把袋子放进圆木框，用锤子打入木楔） | 35-45% |
| 杠杆压榨（长圆木一端架在柱子上，另一端吊重石） | 30-40% |
| 手拧（把袋子夹在两根棍子之间拧） | 20-30% |

&nbsp;&nbsp;&nbsp;没有压榨工具时，把炒过的芝麻磨细，一点点加水研成稠糊，在宽口锅里用小火煮，用勺撇起浮上来的油，再用小火加热撇出的油，把水分蒸干。水分残留，油就会变质。

| 副产物与用途 | 内容 |
|:---|:---|
| 油饼 | 人可以捣碎后拌进粥或糕里（粗糙，放多了难以下咽），也是鸡、猪、牛的蛋白质来源（一次喂多会腹泻）。作肥料时含氮约5-6%、磷2%、钾1%，必须发酵后再用 |
| 灯油 | 把棉线、麻线或布捻成的灯芯，插进浅碟里的油中。芝麻油烟灰少，紫苏油会在灯芯上结痂。先用已经难以食用的油 |

| 制作肥皂 | 方法 |
|:---|:---|
| 草木灰碱液与苛化 | 把阔叶树的灰放进水里搅开，放一天后取上层的水（针叶树的灰较弱）；加入生石灰（烧贝壳或石灰石制成），搅拌后使其沉淀 |
| 浓度 | 新鲜羽毛开始溶解，或土豆浮起到硬币大小就够了 |
| 混合、熬煮 | 把油加热，一点点倒入碱液，不停地搅拌，再用小火熬几小时 |
| 凝固 | 加盐后，肥皂会凝结上浮。捞出放进模具凝固，熟化几周 |
| 注意 | 碱液沾到眼睛或皮肤上，要用水长时间冲洗，再用稀释的醋冲洗。铝锅会被腐蚀，要用铸铁或陶器。没做好的肥皂里还残留着碱 |

> **做肥皂用的油，先用已不能吃的油、动物油和榨油后油饼残渣里的油，完好的芝麻油放在最后。**

&nbsp;&nbsp;&nbsp;种子炒熟后撒在饭菜上，或做成芝麻盐、芝麻粥、芝麻糖块来吃，没有压榨工具时，磨碎后直接吃效率最高。紫苏叶可包着吃，也可做酱腌菜、煎饼、蒸菜，放进汤里则最后再放。

## 11. 毒性与注意事项
| 注意 | 内容 |
|:---|:---|
| 毒性 | 芝麻和紫苏不含对人有害的毒性成分 |
| 过敏 | 芝麻是主要的食物过敏原。第一次吃的人从少量开始，有反应就连芝麻油和芝麻盐一起全部停掉。紫苏不一定会有反应 |
| 草酸、植酸 | 种皮（尤其是黑芝麻）妨碍钙、铁、锌的吸收。炒、浸泡、发酵可以减少。钙多在种皮里，所以带皮炒着吃比去皮好 |
| 酸败的油 | 出现酸味或油漆般的气味、苦味、颜色浑浊、发黏。不要吃，用作灯油或做肥皂 |
| 其他 | 脂肪多，一次吃太多会腹泻。紫苏叶施肥多时会积累硝酸盐，不要让婴儿多吃 |

| 月份 | 芝麻 | 紫苏 |
