## はじめに
&nbsp;&nbsp;&nbsp;アマランサス(Amaranthus spp.)は、ヒユ科ヒユ属の一年草で、雑草のヒユと同じ属です。中央アメリカとアンデスが原産で、ソバやキヌアとともに、穀物ではないのに穀物のように使われる擬穀類にまとめられます。1株から葉(野菜)と種子(穀物)の両方が採れるので、播種の40日後から葉を摘んで食べ、秋に種子を収穫します。種子のタンパク質は100g当たり17gを超え、穀物に足りないリシンが豊富なので、トウモロコシ・コメ・コムギに混ぜて食べると、穀物のタンパク質の不足を補います。ただし、種子がきわめて小さく、熟すと自然にこぼれ落ちる脱粒性があるため、収量が少なく、収穫も難しいです。アマランサスは、倉庫を満たす作物ではなく、穀物の栄養を整える作物です。

## 2. 植物の概要
&nbsp;&nbsp;&nbsp;双子葉植物では珍しく、C4光合成を行います。気温が高く日差しが強いほど効率が上がるため、暑さと干ばつに強く、窒素も少なくてすみますが、日陰ではその費用だけがかかって収量が大きく落ちます。葉は互生で長さ5-15cm、茎は直立して2mまで伸びます。まっすぐな主根は、播種70日で深さ2.4mまで伸びます。種子は直径1-1.5mmで、1,000粒が0.6-0.9g、精米の必要がなく、栄養が種子全体に均一にあります。

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 発芽・幼苗期 | 播種後3週間 | 芽が糸のように細く遅いため、雑草に負けやすい、最も危険な時期 |
| 栄養成長期 | 3-8週 | 葉の収穫が始まります |
| 開花期 | 8-12週 | 穂が立ち、風で花粉が運ばれます |
| 登熟期 | 12-16週 | 熟したものからこぼれ始めます |

| 100g当たりの栄養(乾燥した種子) | 含量 |
|:---|:---|
| 熱量 | 383kcal |
| タンパク質 | 17.09g(コメの2倍以上) |
| 炭水化物 / 脂肪 / 食物繊維 | 60-65g / 6-7g / 6-7g |
| カルシウム / 鉄 / マグネシウム | 150-160mg / 7-8mg / 240-250mg |

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 発芽温度 | 15℃以上(最適20-25℃)。播種の時期は気温ではなく地温で決める |
| 生育温度 | 15-35℃(最適20-32℃)。10℃で生長が止まり、霜1回で枯れる |
| 光 | 1日6-8時間以上。最も日当たりのよい場所に植え、日陰の土地は避ける |
| 水 | 作期当たり約250mm。初期の水分が重要で、干ばつより過湿のほうが危険 |
| 土壌 | 排水のよい砂壌土-壌土、土の深さ30cm以上、pH 5.0-7.0、畝の高さ20cm以上 |

| 種 | 特徴と用途 |
|:---|:---|
| Amaranthus cruentus | 子実用の代表。収量が多く、葉も使えるので最も無難 |
| Amaranthus hypochondriacus | 粒が大きい子実用 |
| Amaranthus caudatus | 穂が長く垂れ下がる。涼しい高地に向く |
| Amaranthus tricolor | 葉菜用 |

&nbsp;&nbsp;&nbsp;粒の大きな系統(RRC 1027は韓国国内の試験で1,000㎡当たり465kg、ゴールデンジャイアントなど)を選びます。アマランサスで最も大変なのは育てることではなく、収穫後に脱穀して選別することで、粒が大きいほど楽になります。韓国で育成された品種はなく、ほとんどが海外からの導入種です。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 土づくり | 20-30cm耕し、排水路を掘り、土を細かく砕いて平らにし、播種の前後に鎮圧する |
| 窒素 N / リン酸 P / カリウム K | 1,000㎡当たり8kg / 12kg / 12kg。リン酸とカリウムは全量を元肥に |
| 堆肥 | 1,000kg。完熟堆肥 |
| 代替資源 | 木灰(1㎡当たり一握り)、尿の10-20倍希釈液(穂が立つ前まで)、骨粉、草の液肥(2週間発酵させ5-10倍に薄める、初期のみ) |

> **アマランサスに窒素を多めに与えるという判断は、ほとんどの場合間違いです。草丈は伸びて葉は茂りますが、穂が軽くなり、一度の風雨で畑全体が倒れます。**

| 播種 | 基準 |
|:---|:---|
| 時期 | 4月下旬-5月上旬の直まき。地温15℃以上で、霜が完全に終わった後 |
| 深さ | 0.5-1cm。それより深いと芽が出られない。播種後は必ず板や足で押さえ、土と密着させる |
| 間隔 | 条間20-30cm、株間40-50cm。条まきまたは点まき |
| 種子の量 | 1,000㎡当たり200-400g。水に浸す必要はない |
| 種子の処理 | 50-55℃の湯に10-15分、または細かい灰をまぶす。水に浮くものは捨てる |
| 間引き | 本葉2-3枚で株間20cm、4-5枚で40-50cm。間引いた若い株は山菜として食べる |

## 5. 水と栽培管理、病害虫
| 時期 | 水の管理 |
|:---|:---|
| 播種-幼苗期 | 表土が乾かないよう1日に1、2回湿らせる。薄いわらのマルチ(土が透けて見える程度) |
| 栄養成長期 | 自然の降雨に任せる |
| 開花・登熟期 | 激しい干ばつのときだけ補う |

&nbsp;&nbsp;&nbsp;失敗の大半は、播種後の3週間に起こります。播種の前に畑を一度耕して雑草の種を発芽させ、再び浅く掻いて取り除き、条まきにして条の外のものはすべて抜きます。その3週間を越えれば、アマランサスが日陰を作り、雑草は勝てなくなります。

| 管理 | 内容 |
|:---|:---|
| 倒伏の防止 | 草丈30-50cmで土寄せ、50cmで支柱、1mで縄張り。窒素を減らす |
| 摘心 | 草丈60-80cmで先を切ると、側枝が増えて葉の収穫に有利。しなければ大きな穂が一つできて、種子の収穫に有利 |
| 葉と種子の兼用 | 播種40日から開花前まで、下の葉を、一度に株の3分の1以下で摘む。穂が立ったら、葉の収穫と窒素の施用を止める |

| 病害虫 | 時期と被害 | 農薬を使わない対応 |
|:---|:---|:---|
| カメムシ類 | 5月中旬-10月。子実の収量が69.8%減で最大 | 早朝に手で捕り、畑の周囲の雑草を整理 |
| アブラムシ類 | 4月下旬-6月初め。子実が51.9%減 | 強い水流、石けん水(水1Lに石けん20g)、天敵の保護 |
| ガ類 | 8月中旬-10月中旬。葉が72.5%減 | 夕暮れに手で捕る、卵塊の除去、誘蛾灯 |
| 立枯病、根腐れ病、葉枯病、うどんこ病、穂腐れ | 幼苗期と梅雨、排水不良 | 密に播かない、排水と風通し、病んだものは畑の外へ |

&nbsp;&nbsp;&nbsp;木灰、ニンニクの浸出液、木酢液(500-1,000倍)、ボルドー液も使えます。ヒユ科を続けて植えず、2年休ませます。

| 欠乏・過剰 | 症状と処置 |
|:---|:---|
| 窒素不足 | 下葉から黄変。薄めた尿、完熟堆肥 |
| カリウム不足 | 下葉の縁が褐色に枯れる。木灰を少量 |
| リン酸不足 | 葉が紫がかり、生長が遅い。骨粉、木灰 |
| 鉄不足 | 新葉が黄色で葉脈だけ緑。pHが高いとき。木灰を減らし有機物を入れる |
| 窒素過剰 | アマランサスの養分の問題の大半。草丈ばかり伸びて倒れ、穂が貧弱で、アブラムシが集まる。窒素を止める |

&nbsp;&nbsp;&nbsp;窒素を多く与えた葉には硝酸塩が溜まるので、収穫の2週間前から窒素を止め、日当たりのよい日の午後に摘み、茹で汁を捨てます。乳児にはたくさん食べさせません。

## 6. 混植と輪作
| 相性 | 作物 |
|:---|:---|
| よい | マメ科(窒素を分けてくれる)、トウモロコシ・モロコシ(一緒に食べるとアミノ酸が補い合う)、ヒマワリ |
| 悪い | ヒユ科(ホウレンソウ、フダンソウ、テンサイ)は病害虫を共有。レタスやハクサイなど涼しい環境の葉菜は、アマランサスの日陰で育たない |

&nbsp;&nbsp;&nbsp;1年目にアマランサス、2年目にマメ科(ダイズ、ササゲ、リョクトウ)を植え、アマランサスが使った窒素を戻します。畑での相性だけでなく、食器の中での相性も見ます。

## 7. 収穫、選別、採種
| 区分 | 方法 |
|:---|:---|
| 葉 | 播種40日から開花前まで、1-2週間間隔で、下の十分に育った葉を摘む。若い葉ほど柔らかく、シュウ酸が少ない |
| 種子を刈る時期 | 穂を手のひらでしごいて、粒が少しこぼれ始める瞬間。一つも落ちなければ早く、ばらばらと落ちれば遅い |
| 補助の目安 | 柱頭が褐色に枯れる、穂が褐色か赤褐色になる、下葉が黄色くなって落ちる、爪が入らないほど硬い |
| 刈り取り | 晴れた日の朝、露が乾いた後に、穂の付いた花茎を切る。袋や布で受けて、こぼさないように運ぶ |
| 乾燥 | 逆さに吊るすか、むしろに広げて5-10日。下に布を敷いて、自然に落ちる種を受ける |
| 脱穀 | 袋に入れて叩くか、むしろの上で棒で打つ。一度では終わらないので、裏返して繰り返す |

| 選別 | 方法と限界 |
|:---|:---|
| 粗いふるい、細かいふるい | 小枝やくずを除く。ふるいの目は1mm以下が必要 |
| 箕であおる、うちわ | 軽い殻を飛ばす。種子も軽く、損失がある |
| 水選 | 水に注いで浮くしいなを取る。最も確実だが、すくった直後に乾かすこと(数時間で発芽する) |
| 傾斜板 | 斜めの板に注ぐと、丸い種だけが転がり落ちる |

&nbsp;&nbsp;&nbsp;完璧に選別する必要はありません。採種のため、病気がなく、穂が大きく、倒れていない株を開花期に前もって目印を付けておき、穂が完全に褐色に乾くまで置きます。穂に布の袋をかぶせると、落ちる種を受けられ、鳥も防げます。日陰で水分10%以下まで乾かし、密閉します。

## 8. 貯蔵
| 項目 | 方法 |
|:---|:---|
| 種子 | 水分10%以下(噛むとパキッと音がして割れる程度)まで乾かし、日陰で冷ましてから、壺・ガラス瓶・金属缶に密閉。炒って冷ました塩や炭を布に包んで一緒に入れ、涼しく暗い所に置く。複数の容器に分ける |
| 保管期間 | 完全に乾燥して密閉すれば3-5年、常温に放置で1-2年、湿気が出入りする場所では1年未満 |
| 葉 | そのままで3-5日。茹でて乾燥すれば6か月-1年、重さの3-5%の塩で漬ければ2-3か月、漬物は数か月、茹でて冷凍すれば数か月 |

&nbsp;&nbsp;&nbsp;貯蔵性SSと種子の寿命が重なるため、食べるものと植えるものを同じ袋に入れておける、珍しい作物です。貯蔵中に最も多い失敗は、穀物の害虫です。

## 9. 調理と注意事項
| 調理 | 内容 |
|:---|:---|
| 炒って弾けさせる | 数十秒でポップコーンのように白く弾け、それ以上加熱せずに食べられる。燃料が最も少なくてすむ |
| 茹でる | 水を種子の2、3倍にして20-30分 |
| 混ぜて炊く | コメ・オオムギ・トウモロコシに、穀物対アマランサス4:1-10:1で混ぜて炊く。最も実用的 |
| 粉 | グルテンがないので小麦粉の代わりにはならない |
| 葉 | 沸騰した湯で30秒-1分茹で、冷水ですすいで水気を絞り、和え物・汁・炒め物・粥に使う。茹で汁は捨てる |

| 成分 | 問題と対応 |
|:---|:---|
| 葉のシュウ酸 | カルシウムの吸収を妨げ、結石の原因になる。茹でて汁を捨て、若い葉を使い、生でたくさん食べない。結石の既往があれば控える |
| 葉の硝酸塩 | 5章の対策。茎と葉柄にはさらに多い |
| 種子のサポニン、フィチン酸 | 水で洗う、水に浸すか発酵させる。発芽させた種子は何度もすすいで短く加熱する |
| 種子のレクチン、トリプシンインヒビター | 加熱でなくなる。生で食べない |
| その他 | 花粉アレルギーに注意。食物繊維が多いので、他の穀物と混ぜて食べる |

> **アマランサスの葉は、茹でて茹で汁を捨てて食べるのが基本です。種子は生で食べず、加熱すれば問題になりません。**

## 10. 年間の作業予定
| 月 | 作業 |
|:---|:---|
| 1-2月 | 休み。種子の保管状態(湿気、虫)を確認 |
| 3月 | 堆肥と木灰を入れて畑を耕しておく |
| 4月 | 耕して雑草の種を発芽させた後、浅く掻いて取り除く。4月下旬-5月上旬に播種(浅くまき、必ず押さえる) |
| 5月 | 表土が乾かないようにする。1回目の間引き。初期の3週間が山場 |
| 6月 | 2回目の間引き、土寄せ、支柱立て、葉の収穫開始 |
| 7月 | 縄張り、雑草整理、アブラムシ・カメムシの監視 |
| 7月下旬-8月 | 穂が立ったら、葉の収穫と窒素を止める。カメムシが最大の脅威 |
| 8月下旬-9月中旬 | 種子の収穫。粒が少しこぼれ始めたときに刈る |
| 9-10月 | 乾燥、脱穀、選別、採種用の選抜、完全乾燥後に密閉して貯蔵 |
| 11-12月 | 茎を切って堆肥や薪に。貯蔵状態の確認 |

> **アマランサスは育てるのは簡単で、収穫するのが難しい作物です。種子が小さいという一点から、この作物のすべての苦労が生まれます。**
