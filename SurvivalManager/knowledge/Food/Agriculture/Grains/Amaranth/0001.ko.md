## 들어가며
&nbsp;&nbsp;&nbsp;아마란스(Amaranthus spp.)는 비름과 비름속의 한해살이풀로, 잡초 비름과 같은 속입니다. 중앙아메리카와 안데스가 원산지이며 메밀, 퀴노아와 함께 곡물이 아니면서 곡물처럼 쓰이는 의사곡물로 묶입니다. 한 포기에서 잎(채소)과 씨앗(곡물)이 모두 나오므로, 파종 40일 뒤부터 잎을 따 먹다가 가을에 씨앗을 거둡니다. 씨앗 단백질은 100g에 17g이 넘고 곡물에 모자란 라이신이 넉넉해, 옥수수·쌀·밀과 섞어 먹으면 곡물 단백질의 빈 자리를 메웁니다. 다만 씨앗이 지나치게 작고 익으면 저절로 떨어지는 탈립 성질 때문에 수량이 적고 거두는 일이 어렵습니다. 아마란스는 창고를 채우는 작물이 아니라 곡식의 영양을 고쳐 주는 작물입니다.

## 1. 재난 대비 평가
| 구분 | 등급 | 점수 |
|:---|:---:|:---:|
| 종합 | D | 36.5 |
| 단기 | E | 35.1 |
| 장기 | D | 38.1 |
| 부식 | S | 56.5 |

| 평가 | 항목 |
|:---|:---|
| 강점 (SS) | 시설물 부담, 저장성 |
| 강점 (S) | 단백질 밀도, 시비(척박지 적응), 물 소비량(총 증발산량 250mm), 맛, 자가 채종 |
| 약점 (E) | 태양광(40% 차광 시 상대수량 45%), 내한성(서리 한 번에 고사), 비식용 가치 |
| 약점 (D) | 면적당 열량(1,000㎡에서 약 200kg, ㎡당 766kcal로 자급선의 0.29배), 영속성, 수량 안정성(변동률 24.8%) |

&nbsp;&nbsp;&nbsp;주식으로는 벼와 옥수수의 20-25%밖에 나오지 않아 밥을 대신할 수 없습니다. 대신 곡물에 부족한 아미노산을 채우는 부식 작물로 가치가 높습니다. 병해충 압력은 C(무방제 감수율 50.6%), 확증계수는 0.986입니다. 항목별 등급은 재난 대비 작물 평가 결과 문서에 있습니다.

| 곡물 | 가장 모자란 필수아미노산 |
|:---|:---|
| 쌀, 밀, 수수 | 라이신 |
| 옥수수 | 라이신, 트립토판 |
| 콩 | 메티오닌 (라이신은 넉넉) |
| 아마란스 | 뚜렷한 제한 아미노산 없음. 라이신이 특히 넉넉 |

## 2. 식물 개요
&nbsp;&nbsp;&nbsp;쌍떡잎식물로는 드물게 C4 광합성을 합니다. 기온이 높고 볕이 셀수록 효율이 올라 더위와 가뭄에 강하고 질소를 적게 쓰지만, 그늘에서는 그 비용만 나가 수량이 크게 떨어집니다. 잎은 어긋나기로 길이 5-15cm이고, 줄기는 곧게 서서 2m까지 자랍니다. 곧은 원뿌리가 파종 70일에 깊이 2.4m까지 뻗습니다. 씨앗은 지름 1-1.5mm이고 1,000알이 0.6-0.9g이며, 도정이 필요 없고 영양이 씨 전체에 고르게 있습니다.

| 단계 | 시기 | 핵심 |
|:---|:---|:---|
| 발아·유묘기 | 파종 후 3주 | 싹이 실낱 같고 느려 잡초에 지기 쉬운 가장 위험한 시기 |
| 영양생장기 | 3-8주 | 잎 수확이 시작됩니다 |
| 개화기 | 8-12주 | 이삭이 서고 바람으로 꽃가루가 옮겨 갑니다 |
| 등숙기 | 12-16주 | 익은 것부터 떨어지기 시작합니다 |

| 100g당 영양 (건조 종실) | 함량 |
|:---|:---|
| 열량 | 383kcal |
| 단백질 | 17.09g (쌀의 두 배 이상) |
| 탄수화물 / 지방 / 식이섬유 | 60-65g / 6-7g / 6-7g |
| 칼슘 / 철 / 마그네슘 | 150-160mg / 7-8mg / 240-250mg |

## 3. 재배 환경과 품종
| 조건 | 기준 |
|:---|:---|
| 발아 온도 | 15℃ 이상 (최적 20-25℃). 파종 시기는 기온이 아니라 지온으로 정함 |
| 생육 온도 | 15-35℃ (최적 20-32℃). 10℃에서 생장이 멈추고 서리 한 번에 고사 |
| 빛 | 하루 6-8시간 이상. 가장 볕 좋은 자리에 심고 그늘진 땅은 피함 |
| 물 | 작기당 약 250mm. 초기 수분이 중요하고 과습이 가뭄보다 위험 |
| 토양 | 배수 좋은 사양토-양토, 토심 30cm 이상, pH 5.0-7.0, 두둑 20cm 이상 |

| 종 | 특징과 용도 |
|:---|:---|
| Amaranthus cruentus | 종실용의 대표. 수량이 많고 잎도 쓸 수 있어 가장 무난 |
| Amaranthus hypochondriacus | 알이 굵은 종실용 |
| Amaranthus caudatus | 이삭이 길게 늘어짐. 서늘한 고지에 적합 |
| Amaranthus tricolor | 잎채소용 |

&nbsp;&nbsp;&nbsp;알이 굵은 계통(RRC 1027은 국내 시험에서 1,000㎡당 465kg, Golden Giant 등)을 고릅니다. 아마란스에서 가장 힘든 일은 기르는 것이 아니라 거둔 뒤 털고 고르는 것이고, 알이 굵을수록 쉬워집니다. 국내 육성 품종은 없고 대부분 해외 도입종입니다.

## 4. 밭 준비와 파종
| 항목 | 기준 |
|:---|:---|
| 땅 만들기 | 20-30cm 갈고, 배수로를 내고, 흙을 곱게 부수어 평평하게 한 뒤 파종 전후로 눌러 다짐 |
| 질소 N / 인산 P / 칼륨 K | 1,000㎡당 8kg / 12kg / 12kg. 인산과 칼륨은 전량 밑거름 |
| 퇴비 | 1,000kg. 완숙 퇴비 |
| 대체 자원 | 나무재(㎡당 한 줌), 오줌 10-20배 희석액(이삭이 서기 전까지), 뼛가루, 풀 액비(2주 발효 후 5-10배 희석, 초기만) |

> **아마란스에 질소를 넉넉히 주는 판단은 거의 언제나 잘못입니다. 키는 커지고 잎은 무성해지지만 이삭이 가벼워지고 한 번 비바람에 온 밭이 눕습니다.**

| 파종 | 기준 |
|:---|:---|
| 시기 | 4월 말-5월 초 직파. 지온 15℃ 이상, 서리가 완전히 끝난 뒤 |
| 깊이 | 0.5-1cm. 더 깊으면 싹이 나오지 못함. 파종 후 반드시 판자나 발로 눌러 흙과 밀착시킴 |
| 간격 | 줄 간격 20-30cm, 포기 간격 40-50cm. 줄뿌림 또는 점뿌림 |
| 씨앗 양 | 1,000㎡당 200-400g. 불릴 필요 없음 |
| 씨앗 처리 | 50-55℃ 물에 10-15분 또는 고운 재 묻히기. 물에 띄워 뜨는 것은 버림 |
| 솎기 | 본잎 2-3매에 포기 사이 20cm, 4-5매에 40-50cm. 솎은 어린 포기는 나물로 먹음 |

## 5. 물과 재배 관리, 병해충
| 시기 | 물 관리 |
|:---|:---|
| 파종-유묘기 | 겉흙이 마르지 않게 하루 한두 번 적심. 얇은 짚 멀칭(흙이 비칠 정도) |
| 영양생장기 | 자연 강우에 맡김 |
| 개화·등숙기 | 심한 가뭄일 때만 보충 |

&nbsp;&nbsp;&nbsp;실패의 대부분은 파종 후 3주에 나옵니다. 파종 전에 밭을 한 번 갈아 잡초 씨앗을 싹틔운 뒤 다시 얕게 긁어 없애고, 줄뿌림으로 심어 줄 밖의 것은 모두 뽑습니다. 그 3주를 넘기면 아마란스가 그늘을 만들어 잡초가 이기지 못합니다.

| 관리 | 내용 |
|:---|:---|
| 쓰러짐 방지 | 키 30-50cm에 북주기, 50cm에 지주, 1m에 줄매기. 질소를 줄임 |
| 순지르기 | 키 60-80cm에 끝을 자르면 곁가지가 늘어 잎 수확에 유리, 하지 않으면 큰 이삭 하나로 씨앗 수확에 유리 |
| 잎과 씨앗 겸용 | 파종 40일부터 개화 전까지 아래 잎을 한 번에 3분의 1 이하로 땀. 이삭이 서면 잎 수확과 질소 공급을 멈춤 |

| 병해충 | 시기와 피해 | 약 없이 하는 대응 |
|:---|:---|:---|
| 노린재류 | 5월 중순-10월. 종실 수량 69.8% 감소로 가장 큼 | 이른 아침에 손으로 잡고 밭 둘레의 잡초 정리 |
| 진딧물류 | 4월 하순-6월 초. 종실 51.9% 감소 | 센 물줄기, 비눗물(물 1L에 비누 20g), 천적 보호 |
| 나방류 | 8월 중순-10월 중순. 잎 72.5% 감소 | 해 질 녘 손으로 잡기, 알 덩어리 제거, 유인등 |
| 잘록병, 뿌리썩음병, 잎마름병, 흰가루병, 이삭 썩음 | 유묘기와 장마철, 배수 불량 | 배게 뿌리지 않기, 배수와 통풍, 병든 것은 밭 밖으로 |

&nbsp;&nbsp;&nbsp;나무재, 마늘 우린 물, 목초액(500-1,000배), 보르도액도 쓸 수 있습니다. 비름과를 이어 심지 않고 2년을 쉽니다.

| 결핍·과잉 | 증상과 조치 |
|:---|:---|
| 질소 부족 | 아래 잎부터 노래짐. 묽힌 오줌, 완숙 퇴비 |
| 칼륨 부족 | 아래 잎 가장자리가 갈색으로 탐. 나무재 소량 |
| 인산 부족 | 잎이 자줏빛, 생장 느림. 뼛가루, 나무재 |
| 철 부족 | 새잎이 노랗고 잎맥만 초록. pH가 높을 때. 나무재를 줄이고 유기물 |
| 질소 과다 | 아마란스 양분 문제의 대부분. 키만 크고 눕고 이삭이 부실하며 진딧물이 몰림. 질소를 끊음 |

&nbsp;&nbsp;&nbsp;질소를 많이 준 잎에는 질산염이 쌓이므로 수확 2주 전부터 질소를 끊고, 볕 좋은 날 오후에 따며, 데친 물을 버립니다. 젖먹이에게는 많이 먹이지 않습니다.

## 6. 사이짓기와 윤작
| 궁합 | 작물 |
|:---|:---|
| 좋음 | 콩과(질소를 나눠 줌), 옥수수·수수(함께 먹으면 아미노산 보완), 해바라기 |
| 나쁨 | 비름과(시금치, 근대, 사탕무)는 병해충 공유, 상추·배추 등 서늘한 잎채소는 아마란스의 그늘 때문에 자라지 못함 |

&nbsp;&nbsp;&nbsp;1년차 아마란스, 2년차 콩과(대두, 동부, 녹두)로 아마란스가 쓴 질소를 되돌립니다. 밭의 궁합만이 아니라 그릇의 궁합도 봅니다.

## 7. 수확, 정선, 채종
| 구분 | 방법 |
|:---|:---|
| 잎 | 파종 40일부터 개화 전까지 1-2주 간격으로 아래쪽 다 자란 잎을 땀. 어린잎일수록 부드럽고 옥살산이 적음 |
| 종실 베는 때 | 이삭을 손바닥으로 훑어 알이 조금 떨어지기 시작하는 순간. 하나도 안 떨어지면 이르고 우수수 쏟아지면 늦음 |
| 보조 징후 | 꽃술이 갈색으로 마름, 이삭이 갈색이나 붉은 갈색, 아래 잎이 노랗게 짐, 손톱이 들어가지 않을 만큼 단단함 |
| 벨 때 | 맑은 날 아침 이슬이 마른 뒤 이삭이 달린 꽃대를 자름. 자루나 천에 받쳐 흘리지 않게 옮김 |
| 말리기 | 거꾸로 매달거나 멍석에 펴서 5-10일. 아래에 천을 깔아 저절로 떨어지는 씨를 받음 |
| 털기 | 자루에 넣고 두들기거나 멍석 위에서 막대로 침. 한 번으로 안 되므로 뒤집어 되풀이 |

| 정선 | 방법과 한계 |
|:---|:---|
| 굵은 체, 고운 체 | 잔가지와 부스러기를 거름. 체 구멍이 1mm 이하여야 함 |
| 키질, 부채 | 가벼운 껍질을 날림. 씨앗도 가벼워 손실이 있음 |
| 물 선별 | 물에 부어 뜨는 쭉정이를 걷음. 가장 확실하지만 건진 즉시 말려야 함 (몇 시간 안에 싹이 틈) |
| 경사판 | 비스듬한 판에 쏟으면 둥근 씨앗만 굴러 내려감 |

&nbsp;&nbsp;&nbsp;완벽하게 고를 필요는 없습니다. 채종은 병이 없고 이삭이 크며 쓰러지지 않은 포기를 개화기에 미리 표시해 두었다가, 이삭이 완전히 갈색으로 마를 때까지 둡니다. 이삭에 천 자루를 씌우면 떨어지는 씨를 받고 새를 막을 수 있습니다. 그늘에서 수분 10% 이하로 말려 밀폐합니다.

## 8. 저장
| 구분 | 방법 |
|:---|:---|
| 씨앗 | 수분 10% 이하(깨물어 딱 소리가 나며 부서질 정도)까지 말려 그늘에서 식힌 뒤, 항아리·유리병·금속통에 밀폐. 볶아 식힌 소금이나 숯을 천에 싸서 함께 넣고 서늘하고 어두운 곳에 둠. 여러 그릇에 나누어 담음 |
| 보관 기간 | 완전 건조·밀폐 시 3-5년, 상온 방치 1-2년, 습기가 드나들면 1년 미만 |
| 잎 | 그대로 3-5일. 데쳐 말리면 6개월-1년, 무게의 3-5% 소금에 절이면 2-3개월, 장아찌 수개월, 데쳐 얼리면 수개월 |

&nbsp;&nbsp;&nbsp;저장성 SS와 종자 수명이 겹쳐, 먹을 것과 심을 것을 같은 자루에 둘 수 있는 드문 작물입니다. 저장 중 가장 흔한 실패는 곡식벌레입니다.

## 9. 조리와 주의사항
| 조리 | 내용 |
|:---|:---|
| 볶아 튀기기 | 수십 초면 팝콘처럼 하얗게 터져 더 익히지 않고 먹음. 연료가 가장 적게 듦 |
| 삶기 | 물을 씨앗의 두세 배 잡고 20-30분 |
| 섞어 짓기 | 쌀·보리·옥수수에 곡물 대 아마란스 4:1-10:1로 섞어 지음. 가장 실용적 |
| 가루 | 글루텐이 없어 밀가루를 대신하지 못함 |
| 잎 | 끓는 물에 30초-1분 데쳐 찬물에 헹구고 물기를 짠 뒤 무침·국·볶음·죽에 씀. 데친 물은 버림 |

| 성분 | 문제와 대응 |
|:---|:---|
| 잎의 옥살산 | 칼슘 흡수를 방해하고 결석의 원인. 데쳐서 물을 버리고, 어린잎을 쓰며, 날로 많이 먹지 않음. 결석 병력이 있으면 삼감 |
| 잎의 질산염 | 5절의 대응. 줄기와 잎자루에 더 많음 |
| 씨앗의 사포닌, 피틴산 | 물에 씻고, 불리거나 발효. 싹 틔운 씨앗은 여러 번 헹구고 짧게 익힘 |
| 씨앗의 렉틴, 트립신 저해제 | 가열하면 없어짐. 날로 먹지 않음 |
| 그 밖 | 꽃가루 알레르기 주의, 식이섬유가 많아 다른 곡물과 섞어 먹음 |

> **아마란스 잎은 데쳐서 그 물을 버리고 먹는 것이 기본입니다. 씨앗은 날로 먹지 않고 익히면 문제가 되지 않습니다.**

## 10. 연간 작업 일정
| 월 | 작업 |
|:---|:---|
| 1-2월 | 휴식. 씨앗 보관 상태(습기, 벌레) 확인 |
| 3월 | 퇴비와 나무재를 넣고 밭을 갈아 둠 |
| 4월 | 밭을 갈아 잡초 싹을 틔운 뒤 얕게 긁어 없앰. 4월 말-5월 초에 파종(얕게 뿌리고 반드시 눌러 줌) |
| 5월 | 겉흙이 마르지 않게 함. 1차 솎기. 초기 3주가 고비 |
| 6월 | 2차 솎기, 북주기, 지주 세우기, 잎 수확 시작 |
| 7월 | 줄매기, 잡초 정리, 진딧물·노린재 감시 |
| 7월 하순-8월 | 이삭이 서면 잎 수확과 질소 공급 중단. 노린재가 가장 큰 위협 |
| 8월 하순-9월 중순 | 종실 수확. 알이 조금 떨어지기 시작할 때 벰 |
| 9-10월 | 말리기, 털기, 정선, 채종용 선별, 완전 건조 후 밀폐 저장 |
| 11-12월 | 줄기를 잘라 퇴비나 땔감으로. 저장 상태 확인 |

> **아마란스를 기르는 일은 쉽고 거두는 일은 어렵습니다. 씨앗이 작다는 한 가지 사실에서 이 작물의 모든 수고가 나옵니다.**
