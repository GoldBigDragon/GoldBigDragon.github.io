## 9. 病虫害——不用药的防治方法

### 9-1. 韩国国内已确认的害虫

&nbsp;&nbsp;&nbsp;评价表中的病虫害压力为C，估计减产率50.6%。这是从纲级锚点推算出的数值，并非籽粒苋本身的实测数据，但韩国国内的籽粒苋田间调查中已确认有7科18种害虫，其危害并不轻。

| 害虫类群 | 种类 | 发生时期 | 危害程度 |
|---|---|---|---|
| 蚜虫类 | 蚕豆蚜、棉蚜、桃蚜等3种 | 4月下旬至6月上旬 | 籽粒产量减少51.9% |
| 蝽象类 | 长蝽、盲蝽等12种 | 5月中旬至10月下旬 | 籽粒产量减少69.8% |
| 蛾类 | 白带野螟、甜菜夜蛾等4种 | 8月中旬至10月中旬 | 叶片生物量减少72.5% |

&nbsp;&nbsp;&nbsp;这张表中危害最重的是蝽象类。69.8%这个数字意味着放任不管会损失七成籽粒。蝽象不是啃食叶片，而是把口针刺入正在灌浆的籽粒吸取内容物。表面看起来完好的穗，实际上籽粒已被吸空。已确认12个种，且从5月一直到10月都会出现，是籽粒苋栽培中最需要留意的对象。

| 害虫 | 不用药的应对方法 | 原理 |
|---|---|---|
| 蚜虫 | 用强水流冲洗，喷洒肥皂水，保护瓢虫和草蛉 | 肥皂能溶解虫体油膜，堵塞气孔 |
| 蝽象 | 清晨用手捕捉清除，清理地块周围的杂草 | 气温低的清晨行动迟缓，容易捕捉；杂草会成为其栖息地 |
| 蛾类幼虫 | 傍晚用手捕捉，连叶一起摘除卵块 | 幼虫白天藏匿，傍晚才出来活动 |
| 蛾类成虫 | 夜间使用灯光诱集 | 利用其趋光性 |

&nbsp;&nbsp;&nbsp;诱集灯即便在断电的情况下也能使用。在油灯或篝火上方放一个盛水的宽口容器，被灯光吸引来的蛾会掉进水里。水面滴一点油效果更好。不过这种方法不仅会捕到有害的蛾，也会一并捕到夜间活动的其他昆虫，因此不宜每晚都点。

### 9-2. 主要病害

| 病害 | 症状 | 何时发生 | 不用药的应对方法 |
|---|---|---|---|
| 猝倒病 | 幼苗基部缢缩后倒伏 | 幼苗期，播种过密时 | 不密植，避免使用未腐熟堆肥，对种子进行温水处理 |
| 叶枯病 | 叶片出现褐色斑点并扩散 | 梅雨季 | 将病叶清出地块，保持通风 |
| 根腐病 | 根系变褐，植株萎蔫 | 积水时 | 改善排水，加高垄 |
| 白粉病 | 叶片附着白粉 | 晚夏干燥时 | 保持通风，去除病叶 |
| 穗腐病 | 灌浆期穗部发黑腐烂 | 灌浆期连续降雨时 | 不密植，扶正倒伏的植株 |

&nbsp;&nbsp;&nbsp;最后一行的穗腐病，是造成产量稳定性D的主要原因之一。籽粒苋的穗由密集的小花组成，内部不易干燥。灌浆期若连续降雨数天，穗内就会积存水分，滋生霉菌。这种风险只能通过种植间距和收获时机来调节。40cm到50cm这样较宽的株距，虽然会降低产量，却能降低这一风险。

### 9-3. 不用药自制的防治材料

| 材料 | 制作方法 | 用途 |
|---|---|---|
| 肥皂水 | 将20g无香皂溶于1L水中 | 蚜虫、螨类 |
| 草木灰 | 过筛后撒在叶片和地面 | 防治爬行害虫，兼补充钾肥 |
| 大蒜浸出液 | 将100g大蒜捣碎浸入1L水中后过滤 | 驱避害虫 |
| 木醋液 | 稀释500-1,000倍 | 驱避害虫、抑制霉菌 |
| 波尔多液 | 将硫酸铜与生石灰溶于水中制成 | 预防真菌病害 |
| 烟叶浸出液 | 将烟叶浸泡在水中萃取 | 防治蚜虫，收获前不使用 |

### 9-4. 种植前的预防方法

| 方法 | 内容 |
|---|---|
| 稀植 | 保持株距40-50cm，通风可预防真菌病害 |
| 轮作 | 不连续种植苋科作物，休作2年 |
| 清理地块周边 | 清除蝽象藏身的杂草 |
| 及早发现 | 蚜虫从4月下旬起、蝽象从5月中旬起须留意观察 |
| 病株清出地块 | 不把病叶和病穗丢弃在地里 |
| 保护天敌 | 不杀死瓢虫、草蛉、蜘蛛 |

## 10. 营养缺乏与过量

### 10-1. 判读缺乏症状

| 症状 | 最先出现在何处 | 原因 | 为什么 | 天然材料应对方法 |
|---|---|---|---|---|
| 全株叶片发黄，植株矮小 | 从下部老叶开始 | 缺氮 | 氮素会在体内转移，从老叶抽出送往新叶 | 稀释尿液、沤草液肥、腐熟堆肥 |
| 叶缘焦褐 | 从下部叶片开始 | 缺钾 | 钾的移动性也强，老叶先被牺牲 | 撒施少量草木灰 |
| 叶色暗紫，生长缓慢 | 全株 | 缺磷 | 低温也会因磷吸收下降而出现此症状 | 骨粉、草木灰 |
| 新叶发黄，只有叶脉保持绿色 | 从上部新叶开始 | 缺铁 | 铁不易转移，新叶先挨饿。pH偏高时即使土壤中有铁也无法利用 | 减少草木灰用量，增施有机质 |
| 新梢顶端枯萎扭曲 | 生长点 | 缺钙 | 钙随水分流动转移，难以到达新梢 | 贝壳·蛋壳烧制的粉末 |
| 不抽穗或籽粒空瘪 | 穗部 | 缺磷钾或蝽象为害 | 结实所需养分不足，或已被吸食 | 草木灰、骨粉，先排查蝽象 |

&nbsp;&nbsp;&nbsp;判读症状时最有用的线索是最先出现在哪个部位。若从老叶开始受损，说明植物体内移动性强的养分（氮、磷、钾、镁）不足；若从新叶开始受损，说明移动性差的养分（铁、钙、硼）不足。

&nbsp;&nbsp;&nbsp;不过籽粒苋有一个陷阱。红叶品种很难靠颜色来判断。红色系品种本身叶片就是红色的，无法与缺磷时的紫色区分开。对这类品种，应改看叶片大小和生长速度，而不是颜色。

### 10-2. 过量症状

| 症状 | 原因 | 为什么 | 应对措施 |
|---|---|---|---|
| 只长个头，茎秆软弱倒伏 | 氮素过量 | 细胞壁被拉薄，组织变弱 | 停施氮肥，靠培土与支柱支撑 |
| 叶片繁茂但穗发育不良 | 氮素过量 | 养分偏向叶片，无法供给籽粒 | 从抽穗前就停施氮肥 |
| 叶色深青，蚜虫聚集 | 氮素过量 | 汁液中氨基酸增多，招蚜虫喜食 | 应对措施同上 |
| 叶缘枯萎、根系变褐 | 肥料浓度过高 | 土壤盐类浓度升高，导致水分从根部反向流出 | 大量浇水冲洗 |
| 叶片发黄、生长停滞、土壤板结 | 草木灰过量导致碱化 | pH升高使铁和锰无法被利用 | 停用草木灰，增施有机质 |

> **籽粒苋出现的养分问题，大多不是不足，而是氮素过量。这种作物耐饥饿，却不耐"吃太饱"。**

### 10-3. 积累在叶片中的硝酸盐

&nbsp;&nbsp;&nbsp;施氮过多的籽粒苋叶片会积累硝酸盐。苋科植物本身就容易蓄积硝酸盐，菠菜和莙荙菜也存在同样的问题。硝酸盐本身毒性不高，但在口腔和肠道中转化为亚硝酸盐后，会妨碍血液的携氧能力，对婴儿尤其危险。

| 减少方法 | 原理 |
|---|---|
| 收获前2周起停施氮肥 | 让植物有时间自行消耗已积累的硝酸盐 |
| 在晴天下午采摘 | 硝酸盐在光照下会转化为蛋白质，白天含量随之下降 |
| 焯水后倒掉焯水 | 硝酸盐易溶于水，大部分会随之流失 |
| 不给婴儿大量食用 | 这一阶段对亚硝酸盐特别敏感 |
| 多用叶片、少用茎秆 | 硝酸盐更多积累在茎和叶柄中 |

## 11. 间作与轮作

### 11-1. 搭配关系

| 搭配关系 | 作物 | 会发生什么 |
|---|---|---|
| 好 | 豆科（豇豆、绿豆、大豆） | 根瘤固氮的一部分会释放到土壤中供籽粒苋利用，籽粒苋需氮量少，竞争也少 |
| 好 | 玉米、高粱 | 两者都株高且是C4作物，需求条件相近，更重要的是食用时氨基酸能相互互补 |
| 好 | 向日葵 | 株高相近，不会互相遮阴 |
| 一般 | 南瓜、甘薯 | 覆盖地面能压制杂草，但若在籽粒苋生长初期覆盖则有害 |
| 差 | 苋科（菠菜、莙荙菜、甜菜） | 同科作物会共享病原菌和害虫 |
| 差 | 生菜、大白菜等喜凉叶菜 | 会落入籽粒苋的阴影中而无法生长 |

&nbsp;&nbsp;&nbsp;把玉米和高粱列为好搭档，原因不在于田间的相性，而在于餐桌上的搭配。玉米和高粱的蛋白质中赖氨酸不足，籽粒苋则含量充足。若在同一块地里一起收获、盛在同一个碗里搭配食用，留在体内的蛋白质会比分开食用时更多。在灾害情况下选择作物时，记住这种搭配组合，其重要性不亚于扩大种植面积。

> **不仅要看田间的搭配，也要看碗里的搭配。把玉米和籽粒苋种在一起，一半的原因是为了搭配着吃。**

### 11-2. 轮作

&nbsp;&nbsp;&nbsp;评价表中连作适应性为A，依据是"苋科，建议休作2年"。若在同一地块连续种植，针对苋科的病原菌和害虫就会不断积累。尤其是蝽象类，只要同一地方持续有食物来源，种群数量就会逐年增加。

| 年份 | 种植内容 | 收获什么 |
|---|---|---|
| 第1年 | 籽粒苋 | 籽粒与叶片，深根能疏松地下土层 |
| 第2年 | 豆科（大豆、豇豆、绿豆） | 归还籽粒苋消耗掉的氮素 |
| 第3年 | 十字花科或葫芦科 | 科属不同，病原菌不会延续 |
| 第4年 | 回到籽粒苋 | |

&nbsp;&nbsp;&nbsp;籽粒苋在轮作中还有一项特殊作用。主根扎入2m以上时会穿透硬层，根系腐烂后留下的空隙成为水和空气进出的通道。若地块因连续种植浅根作物而变得板结，种一季籽粒苋就能疏松下层土壤。这相当于靠根系来耕地，在没有机械也没有燃料的情况下，是很有价值的特性。

## 12. 收获——与落粒的较量

### 12-1. 采叶

| 项目 | 内容 |
|---|---|
| 时期 | 播种约40天后到开花前 |
| 采什么 | 用手摘取或用剪刀剪下下部已长成的叶片 |
| 采多少 | 每次不超过全株的三分之一 |
| 间隔 | 1到2周 |
| 结束时机 | 抽穗开始后停止 |

&nbsp;&nbsp;&nbsp;叶片越嫩越柔软，草酸也越少。长成变厚的叶片又硬又涩，因此长到手掌大小时是最佳采摘期。若是专门用来采叶的植株，可通过摘心降低株高、增加侧枝，从而增加可采摘的部位。

### 12-2. 为什么籽粒收获很难

&nbsp;&nbsp;&nbsp;籽粒苋栽培中最难判断的是何时收割。原因是落粒。野生植物一旦种子成熟就立即脱落传播，籽粒苋虽已成为栽培种，仍在很大程度上保留着这一特性，而且整个穗也不会同时成熟。

| 情况 | 会发生什么 |
|---|---|
| 收割过早 | 未成熟籽粒多，颗粒小、秕粒增多，发芽力也下降 |
| 适时收割 | 下部已略有脱落，上部刚好成熟，这是损失最小的时机 |
| 收割过晚 | 成熟的籽粒全部落入田中，只剩空穗 |
| 被雨淋到 | 穗内会发芽或长霉而无法使用 |

| 判断标准 | 内容 |
|---|---|
| 花柱 | 穗顶端的白色花柱消失，变为褐色干枯 |
| 穗色 | 绿色褪去，转为褐色或红褐色 |
| 手捋测试 | 用手掌轻捋穗部时，籽粒开始容易脱落的时刻 |
| 叶片状态 | 下部叶片变黄并开始脱落 |
| 籽粒硬度 | 用指甲按压不留痕迹、质地坚硬即为完全成熟 |

> **用手掌捋穗时，籽粒开始有少许脱落的那一刻，就是收割的时机。一粒都不掉说明太早，哗啦啦大量脱落则已经太晚。**

### 12-3. 收割、晾晒、脱粒的顺序

| 阶段 | 方法 | 原因 |
|---|---|---|
| 收割 | 晴天早晨露水干后，剪下带穗的花茎 | 带露水堆积会使穗内发热、发霉、发芽 |
| 搬运 | 底下垫上袋子或布，小心搬运 | 搬运过程中晃动脱落的量相当可观 |
| 晾晒 | 倒挂或摊在草席上，在阳光和风中晾晒5-10天 | 须晒到穗内部都干透，籽粒才容易脱落 |
| 承接 | 悬挂晾晒时，下方铺开布或袋子 | 承接晾晒过程中自然脱落的籽粒 |
| 脱粒 | 装入袋中拍打，或在草席上用木棍敲打 | 与给芝麻脱粒的方式相同 |
| 再次脱粒 | 一次无法脱净，须翻面反复进行 | 穗内部残留的籽粒较多 |

&nbsp;&nbsp;&nbsp;收割后倒挂晾晒比直接留在田里晾晒更好，原因是能接住脱落的籽粒。若任其在地里站立成熟，脱落的籽粒就都进了土里。种过籽粒苋的地方第二年会自发冒出成片的幼苗，原因正在于此，看看这些幼苗的数量，就能知道当初流失了多少籽粒。

### 12-4. 精选——最麻烦的工作

&nbsp;&nbsp;&nbsp;脱粒出来的不只是种子，还夹杂着碎萼片、小枝和外壳碎屑。问题在于这些碎屑的大小和重量都与种子相近，常见的方法很难将两者分开。

| 方法 | 怎么做 | 筛除什么 | 局限性 |
|---|---|---|---|
| 粗筛 | 用孔径大于种子的筛子筛 | 小枝和较大碎屑 | 细小碎屑会和种子一起漏下 |
| 细筛 | 放在孔径小于种子的筛子上筛 | 灰尘和极细的碎屑 | 筛孔须在1mm以下，很难找到 |
| 簸扬 | 放入簸箕中上下颠簸，借风扬去杂质 | 轻质外壳碎屑 | 种子也轻，会一起被吹走，只能在风力较弱时进行 |
| 扇风 | 从高处缓缓倾倒，同时在旁扇风 | 外壳碎屑 | 须接受一定的种子损耗 |
| 水选 | 倒入水中，捞去漂浮物 | 秕粒与外壳 | 种子会吸水，须立即晾干 |
| 斜板法 | 倒在斜板上使其滚动 | 只有圆形种子会滚落下来 | 需要反复调整斜板角度 |

&nbsp;&nbsp;&nbsp;最可靠的方法是水选。种子与碎屑的重量差异虽小，但放入水中后二者的性质差异就会显现出来。饱满的种子会下沉，秕粒和外壳会漂浮。倒入盛满水的容器中搅拌，先捞去漂浮物，再把沉底的捞出后立即摊开晾干。

> **水选中最重要的是捞出后的速度。籽粒苋种子一旦吸水，几个小时之内就会开始发芽。捞出后若不立刻摊晾，整袋种子都会报废。**

&nbsp;&nbsp;&nbsp;斜板法利用的是种子呈圆形凸透镜状、容易滚动的特性。把木板或草席斜立起来，从上方缓缓倾倒，种子会滚落集中到下方承接的容器中，而扁平的外壳碎屑则会附着留在板上。这种方法几乎不需要工具，很适合灾害情况下使用。

&nbsp;&nbsp;&nbsp;知道不必挑选得十全十美，心里也会轻松一些。混入少量外壳碎屑并不影响食用，烹调后大多也分辨不出来。只对留作种子的那部分仔细挑选，食用的那部分适当挑选即可，这样才能省力气。
