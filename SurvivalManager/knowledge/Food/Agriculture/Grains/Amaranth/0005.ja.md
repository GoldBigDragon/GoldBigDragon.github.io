## 9. 病害虫 - 薬を使わない防ぎ方

### 9-1. 韓国国内で確認された害虫

&nbsp;&nbsp;&nbsp;評価表の病害虫圧はC、推定減収率50.6%です。綱単位のアンカーから引いた値のためアマランサス自体の実測ではありませんが、韓国国内のアマランサス圃場調査では7科18種の害虫が確認され、その被害は軽くありませんでした。

| 害虫群 | 種類 | 発生時期 | 被害程度 |
|---|---|---|---|
| アブラムシ類 | ソラマメヒゲナガアブラムシ、ワタアブラムシ、モモアカアブラムシなど3種 | 4月下旬から6月上旬 | 種実収量51.9%減少 |
| カメムシ類 | ナガカメムシ類、カスミカメムシ類など12種 | 5月中旬から10月下旬 | 種実収量69.8%減少 |
| ガ類 | シロオビノメイガ、シロイチモジヨトウなど4種 | 8月中旬から10月中旬 | 葉の生体量72.5%減少 |

&nbsp;&nbsp;&nbsp;この表で最も重いのはカメムシ類です。69.8%という数字は、放置すれば種子の7割を失うという意味です。カメムシは葉をかじるのではなく、実り始めた種子に口針を刺して中身を吸い取ります。見た目は無事そうな穂が、中身の空っぽな状態になります。12種も確認されており5月から10月までずっと現れるため、アマランサス栽培で最も気を配るべき対象です。

| 害虫 | 薬を使わない対応 | 原理 |
|---|---|---|
| アブラムシ | 強い水流で洗い流します。石けん水を散布します。テントウムシとクサカゲロウを守ります | 石けんが虫の油膜を溶かし気門をふさぎます |
| カメムシ | 朝早く手で捕まえて駆除します。畑の周りの雑草を片付けます | 気温が低い早朝は動きが鈍く捕まえやすいです。雑草がすみかになります |
| ガの幼虫 | 夕方に手で捕まえます。卵塊を葉ごと取り除きます | 幼虫は昼間は隠れ、夕方に出てきます |
| ガの成虫 | 夜に明かりをつけて集める誘引灯を使います | 光に集まる性質を利用します |

&nbsp;&nbsp;&nbsp;誘引灯は電気が止まった状況でも使えます。ランプやたき火の上に水を張った広い器を置いておくと、明かりに集まったガが水に落ちます。油を少し浮かべるとより捕まえやすくなります。ただしこの方法は害のあるガだけでなく夜に活動する他の昆虫も一緒に捕まえてしまうため、毎晩つけておかないほうがよいです。

### 9-2. 主な病害

| 病気 | 症状 | いつ来るか | 薬を使わない対応 |
|---|---|---|---|
| 立枯病 | 幼い芽の根元がくびれて倒れます | 幼苗期、密に播いたとき | 密に播きません。未熟な堆肥を避けます。種子の温湯処理をします |
| 葉枯病 | 葉に褐色の斑点ができて広がります | 梅雨の時期 | 病気の葉を畑の外に出します。通風を確保します |
| 根腐病 | 根が褐変し株がしおれます | 水がたまるとき | 排水を改善します。畝を高くします |
| うどんこ病 | 葉に白い粉が付きます | 晩夏の乾燥時 | 通風を確保します。病気の葉を取り除きます |
| 穂腐れ | 登熟期に穂が黒く腐ります | 登熟期に雨が続くとき | 密に植えません。倒れた株は起こします |

&nbsp;&nbsp;&nbsp;最後の行の穂腐れが、収量安定性Dを生む主な原因の一つです。アマランサスの穂は小さな花が密集した構造のため、内側が乾きにくいです。登熟期に雨が数日続くと穂の中に水分が閉じ込められ、カビが広がります。この危険は植え付け間隔と収穫時期でしか調整できません。40cmから50cmという広い株間は、収量を減らす代わりにこの危険を下げます。

### 9-3. 薬を使わずに作る防除資材

| 材料 | 作り方 | 何に使うか |
|---|---|---|
| 石けん水 | 無香料の石けん20gを水1Lに溶かします | アブラムシ、ダニ |
| 草木灰 | ふるいにかけて葉と地面にまきます | 這う害虫、カリウム供給も兼ねます |
| ニンニク浸出液 | ニンニク100gをすりつぶし水1Lに浸してこします | 害虫忌避 |
| 木酢液 | 500-1,000倍に薄めます | 忌避、カビ抑制 |
| ボルドー液 | 硫酸銅と生石灰を水に溶かして作ります | カビ病予防 |
| タバコ浸出液 | タバコの葉を水に浸して成分を出します | アブラムシ。収穫直前には使いません |

### 9-4. 植え付け前に防ぐ方法

| 方法 | 内容 |
|---|---|
| 広く植える | 株間40-50cmを守ります。通風がカビ病を防ぎます |
| 輪作 | ヒユ科を続けて植えません。2年休みます |
| 畑の周囲の整理 | カメムシが隠れる雑草を片付けます |
| 早期発見 | アブラムシは4月下旬から、カメムシは5月中旬から見回ります |
| 病気のものは畑の外へ | 病気の葉や穂を畑に捨てません |
| 天敵を守る | テントウムシ、クサカゲロウ、クモを殺しません |

## 10. 栄養素の欠乏と過剰

### 10-1. 欠乏症状の読み方

| 症状 | どこに先に現れるか | 原因 | なぜそうなるか | 自然素材での対処 |
|---|---|---|---|---|
| 葉全体が黄ばみ株が小さい | 下部の古い葉から | 窒素不足 | 窒素は体内を移動し、古い葉から抜いて新しい葉へ送ります | 薄めた尿、草を漬けた液肥、完熟堆肥 |
| 葉の縁が褐色に焼ける | 下部の葉から | カリウム不足 | カリウムも移動性が高く、古い葉から先に犠牲になります | 草木灰を少量まきます |
| 葉が暗く紫がかり、生長が遅い | 全体 | リン酸不足 | 低温でリン酸吸収が落ちて現れることもあります | 骨粉、草木灰 |
| 新葉が黄色く葉脈だけ緑 | 上部の新しい葉から | 鉄不足 | 鉄は移動しにくく新しい葉が先に飢えます。pHが高いと土にあっても使えません | 草木灰を減らし有機物を入れます |
| 新芽の先端が枯れてねじれる | 生長点 | カルシウム不足 | カルシウムは水の流れに乗って移動するため新芽に届きにくいです | 貝殻・卵殻を焼いた粉 |
| 穂が立たない、または実が空 | 穂 | リン酸・カリウム不足またはカメムシ | 結実に使う養分が足りないか、吸われたものです | 草木灰、骨粉。まずカメムシを確認します |

&nbsp;&nbsp;&nbsp;症状を読み取るとき最も役立つ手がかりは、どこに先に現れるかです。古い葉から傷めば植物の体内でよく移動する養分（窒素、リン酸、カリウム、マグネシウム）が不足しており、新しい葉から傷めば移動しにくい養分（鉄、カルシウム、ホウ素）が不足しています。

&nbsp;&nbsp;&nbsp;ただし、アマランサスには一つ落とし穴があります。葉が赤い品種では色で判断するのが難しいのです。赤色系統はもともと葉が赤いため、リン酸不足の紫がかった色と区別できません。こうした品種では色の代わりに葉の大きさと育つ速さを見ます。

### 10-2. 過剰症状

| 症状 | 原因 | なぜそうなるか | 対処 |
|---|---|---|---|
| 丈ばかり伸びて茎が軟弱になり倒れます | 窒素過多 | 細胞壁が薄く伸びて組織が弱くなります | 窒素を止めます。土寄せと支柱で支えます |
| 葉は茂るが穂が貧弱です | 窒素過多 | 資源が葉に偏り種子に回りません | 穂が立つ前から窒素を止めます |
| 葉が濃い青緑色で、アブラムシが群がります | 窒素過多 | 汁にアミノ酸が増えアブラムシが好みます | 同じ対処 |
| 葉の縁が枯れ根が褐変 | 肥料濃度過多 | 土の塩類濃度が高まり水が根から抜け出します | 水をたっぷり与えて洗い流します |
| 葉が黄色く生育が止まり土が固まる | 草木灰過多によるアルカリ化 | pHが上がり鉄とマンガンを使えなくなります | 草木灰を止め有機物を入れます |

> **アマランサスに現れる養分問題の大半は、不足ではなく窒素過多です。この作物は飢えには強く、満腹には弱いのです。**

### 10-3. 葉に蓄積する硝酸塩

&nbsp;&nbsp;&nbsp;窒素を多く与えたアマランサスの葉には硝酸塩がたまります。ヒユ科植物はもともと硝酸塩をため込みやすい系統で、ホウレンソウとフダンソウも同じ問題を抱えています。硝酸塩自体の毒性は低いものの、口の中や腸で亜硝酸塩に変わると血液の酸素運搬を妨げます。乳児には特に危険です。

| 減らす方法 | 原理 |
|---|---|
| 窒素肥料を収穫2週間前から止めます | たまった硝酸塩を植物が自ら消費する時間を与えます |
| 天気のよい日の午後に摘む | 硝酸塩は光を受けている間にタンパク質へ変わり、日中に減ります |
| ゆでた湯を捨てます | 硝酸塩は水によく溶けかなりの部分が抜け出ます |
| 乳児に多く食べさせません | 亜硝酸塩に特に弱い時期です |
| 茎より葉を使います | 硝酸塩は茎と葉柄により多くたまります |

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 作物 | 何が起こるか |
|---|---|---|
| よい | マメ科（ササゲ、リョクトウ、ダイズ） | 根粒で固定した窒素の一部が土に出てアマランサスが使います。アマランサスは窒素をあまり必要とせず競合が少ないです |
| よい | トウモロコシ、モロコシ | どちらも背が高くC4のため要求条件が似ています。何より食べるときにアミノ酸が互いを補います |
| よい | ヒマワリ | 背丈が似ており互いに日陰を作りません |
| 普通 | カボチャ、サツマイモ | 地面を覆って雑草を抑えます。ただしアマランサスの初期に覆うと害になります |
| 悪い | ヒユ科（ホウレンソウ、フダンソウ、テンサイ） | 同じ科のため病原菌と害虫を共有します |
| 悪い | サンチュ、ハクサイなど涼しい葉野菜 | アマランサスの陰に入り育ちません |

&nbsp;&nbsp;&nbsp;トウモロコシとモロコシをよい組み合わせに挙げる理由は、畑での相性よりも食卓での相性にあります。トウモロコシとモロコシのタンパク質にはリジンが不足しており、アマランサスには豊富です。同じ畑で一緒に収穫して同じ器に混ぜて食べれば、それぞれを別々に食べるときより体に残るタンパク質が増えます。災害時に作物を選ぶ際、こうした組み合わせを念頭に置くことは、面積を増やすことに劣らず重要です。

> **畑の相性だけでなく器の相性も見ます。トウモロコシとアマランサスを一緒に植える理由の半分は、一緒に食べるためです。**

### 11-2. 輪作

&nbsp;&nbsp;&nbsp;評価表の連作適応性はAで、根拠は「ヒユ科、2年の休作を推奨」です。同じ場所に続けて植えると、ヒユ科を狙う病原菌と害虫がたまっていきます。特にカメムシ類は同じ場所に餌が続くと個体数が年々増えます。

| 年 | 植えるもの | 何を得るか |
|---|---|---|
| 1年目 | アマランサス | 種実と葉。深い根が地中をほぐします |
| 2年目 | マメ科（ダイズ、ササゲ、リョクトウ） | アマランサスが使った窒素を土に戻します |
| 3年目 | アブラナ科かウリ科 | 系統が異なり病原菌が続きません |
| 4年目 | アマランサスに戻ります | |

&nbsp;&nbsp;&nbsp;アマランサスが輪作で果たす特別な役割が一つあります。主根が2mを超えて伸びる際に硬い層を突き破り、その根が朽ちた跡に水と空気の通り道が残ります。浅く根を張る作物ばかりを続けて植えて固まった畑でアマランサスを一年立てると、その下の層がほぐれます。根で土を耕すようなものであり、機械も燃料もない状況で価値のある性質です。

## 12. 収穫 - 脱粒との戦い

### 12-1. 葉の収穫

| 項目 | 内容 |
|---|---|
| 時期 | 播種40日ごろから開花前まで |
| 何を | 下部の育ちきった葉を手で摘むかはさみで切ります |
| どれだけ | 一度に株の3分の1を超えません |
| 間隔 | 1週間から2週間 |
| 終える時期 | 穂が立ち始めたらやめます |

&nbsp;&nbsp;&nbsp;葉は若いほど柔らかくシュウ酸が少ないです。育ちきって厚くなった葉は硬くて渋いため、手のひらほどの大きさに育ったときが最も良い時期です。葉専用に育てる株なら、摘心で丈を低くし側枝を増やして摘み取る場所を増やします。

### 12-2. 種実収穫が難しい理由

&nbsp;&nbsp;&nbsp;アマランサス栽培で最も難しい判断が、いつ刈るかです。原因は脱粒です。野生植物は種子が熟すとすぐに落として広げますが、アマランサスは栽培種になってもこの性質をかなりの部分残しています。そして穂全体が一度に熟すわけでもありません。

| 状況 | 何が起こるか |
|---|---|
| 早く刈りすぎる | 未熟な種子が多く粒が小さく、しいなが増えます。発芽力も落ちます |
| 適期に刈る | 下部はすでに少し落ち、上部はちょうど熟した状態です。損失が最も少ない時点です |
| 遅く刈りすぎる | 熟した種子が畑にすべて落ち、空の穂だけが残ります |
| 雨に当てる | 穂の中で発芽したりカビが生えたりして使えなくなります |

| 判断基準 | 内容 |
|---|---|
| 花柱 | 穂の先端まで白い花柱が消え、褐色に枯れます |
| 穂の色 | 緑色が抜け、褐色や赤褐色に変わります |
| 手でしごく | 穂を手のひらで軽くしごいたとき、粒が簡単に落ち始める時期です |
| 葉の状態 | 下部の葉が黄色くなり落ち始めます |
| 種子の硬さ | 爪で押しても跡がつかず硬ければ、完全に熟したものです |

> **手のひらで穂をしごいたとき、粒が少し落ち始める瞬間が刈り時です。一つも落ちなければ早すぎ、どっと落ちるならすでに遅すぎます。**

### 12-3. 刈り取り・乾燥・脱穀の順序

| 段階 | 方法 | なぜそうするのか |
|---|---|---|
| 刈り取り | 晴れた日の朝、露が乾いた後に穂の付いた花茎を切ります | 濡れたまま積むと穂の中で熱がこもりカビが生え発芽してしまいます |
| 運搬 | 袋や布を下に敷いて注意して運びます | 運ぶ間に揺れて落ちる量がかなりあります |
| 乾燥 | 逆さに吊るすか、むしろに広げて日と風で5-10日乾かします | 穂の内側まで乾いてこそ種子がよく落ちます |
| 受け | 吊るすときは下に布や袋を広げておきます | 乾く間に自然に落ちるものを受け止めます |
| 脱穀 | 袋に入れてたたくか、むしろの上で棒で打ちます | ゴマを脱穀するのと同じ方式です |
| 再脱穀 | 一度ではすべて落ちないため、裏返して繰り返します | 穂の内側に残るものが多いです |

&nbsp;&nbsp;&nbsp;刈り取って逆さに吊るして乾かす方式が、畑でそのまま乾かすより優れている理由は、落ちる種子を受け止められるからです。畑に立てたまま熟させると、落ちたものはすべて土に帰ります。アマランサスを植えていた場所で翌年ひとりでに芽が大量に出るのはこのためで、その量を見れば、どれだけ多く落としたかがわかります。

### 12-4. 選別 - 最も面倒な作業

&nbsp;&nbsp;&nbsp;脱穀して出てくるのは種子だけではありません。砕けた萼、小枝、殻の破片が一緒に出てきます。問題は、この屑の大きさと重さが種子と似ているため、よく使われる方法ではうまく分けられないという点です。

| 方法 | どうするか | 何をこすか | 限界 |
|---|---|---|---|
| 粗いふるい | 種子より大きな穴のふるいでふるいます | 小枝と大きな屑 | 小さな屑は種子と一緒に落ちます |
| 細かいふるい | 種子より小さな穴のふるいに載せてふるいます | ほこりとごく細かい屑 | ふるいの穴が1mm以下である必要があり入手が難しいです |
| 箕であおる | 箕に入れて上下に振りながら風に飛ばします | 軽い殻の破片 | 種子も軽いため一緒に飛んでいきます。風が弱いときしかできません |
| 扇・送風 | 高い所からゆっくり注ぎながら横であおぎます | 殻の破片 | 種子の損失を覚悟する必要があります |
| 水選 | 水に入れて浮いたものを取り除きます | しいなと殻 | 種子が水を吸うため必ずすぐに乾かす必要があります |
| 傾斜板 | 斜めの板に注いで転がします | 丸い種子だけが転がり落ちます | 板と角度を合わせるのに試行錯誤が要ります |

&nbsp;&nbsp;&nbsp;最も確実なのは水選です。種子と屑の重さの差は小さいですが、水に入れると性質の違いが現れます。実の詰まった種子は沈み、しいなと殻は浮きます。水をたっぷり張った器に入れてかき混ぜ、浮いたものを取り除いたうえで、沈んだものをすくい上げてすぐに広げて乾かします。

> **水選で最も重要なのは、すくい上げた後の速さです。アマランサスの種子は水を吸うと数時間以内に発芽し始めます。すくってすぐに広げなければ、その袋をまるごと失います。**

&nbsp;&nbsp;&nbsp;傾斜板方式は、種子が丸いレンズ状でよく転がるという性質を利用します。板やむしろを斜めに立てて上からゆっくり注ぐと、種子は転がり落ちて下に置いた器に集まり、平たい殻の破片は板に張り付いたまま残ります。道具がほとんど要らず、災害時によく合う方法です。

&nbsp;&nbsp;&nbsp;完璧に選別する必要はないという点を知っておくと気が楽になります。殻の破片が少し混じっていても食べるのに支障はなく、調理すればほとんど見分けがつきません。種子として残す分だけ念入りに選び、食べる分は適当に選ぶのが、労力を惜しむ方法です。
