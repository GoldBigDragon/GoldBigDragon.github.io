# 籽粒苋
- 来源: 韩国农村振兴厅 农事路（Nongsaro）、韩国国家标准食品成分表、FAO ECOCROP、Wiki、Gemini、Claude、Chat-GPT

## 引言
&nbsp;&nbsp;&nbsp;苋类作物（Amaranthus spp.）是苋科苋属的一年生草本，与杂草野苋属于同一属。原产于中美洲和安第斯山区，与荞麦、藜麦一同被归入“假谷物”，即不是谷物却当作谷物来用的作物。一株既能产叶（蔬菜）又能产籽（粮食），所以播种40天后就可以摘叶食用，秋天再收种子。种子蛋白质每100g超过17g，且富含谷物所缺乏的赖氨酸，与玉米、稻米、小麦混合食用，可以弥补谷物蛋白质的不足。但种子极小，成熟后会自行脱落，所以产量低，收获也困难。苋类不是用来填满粮仓的作物，而是用来改善谷物营养的作物。

| 评估 | 项目 |
|:---|:---|
| 优势（SS） | 设施负担、耐储性 |
| 优势（S） | 蛋白质密度、施肥（适应贫瘠地）、水消耗量（总蒸散量250mm）、口味、自留种 |

&nbsp;&nbsp;&nbsp;作为主食，它的产量只有水稻、玉米的20-25%，无法代替主食。作为补充谷物所缺氨基酸的副食作物，它的价值则很高。病虫害压力为C（无防治减产率50.6%），确证系数为0.986。各项目的等级见“灾害应对作物评价结果”文档。

| 谷物 | 最缺乏的必需氨基酸 |
|:---|:---|
| 稻米、小麦、高粱 | 赖氨酸 |
| 玉米 | 赖氨酸、色氨酸 |
| 豆类 | 蛋氨酸（赖氨酸充足） |
| 籽粒苋 | 没有明显的限制性氨基酸。赖氨酸尤其充足 |

## 2. 植物概述
&nbsp;&nbsp;&nbsp;它在双子叶植物中少见地进行C4光合作用。气温越高、阳光越强，效率越高，所以耐热、耐旱，需氮也少，但在阴处只是白白付出代价，产量大幅下降。叶互生，长5-15cm，茎直立，高可达2m。笔直的主根在播种70天时可深入2.4m。种子直径1-1.5mm，1,000粒重0.6-0.9g，不需要碾米，营养均匀分布于整粒种子。

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 发芽·幼苗期 | 播种后3周 | 幼芽细如丝且生长慢，容易输给杂草，是最危险的时期 |
| 营养生长期 | 3-8周 | 开始采收叶片 |
| 开花期 | 8-12周 | 穗子立起，花粉靠风传播 |
| 灌浆期 | 12-16周 | 成熟的种子开始脱落 |

| 每100g营养（干种子） | 含量 |
|:---|:---|
| 热量 | 383kcal |
| 蛋白质 | 17.09g（稻米的两倍以上） |
| 碳水化合物 / 脂肪 / 膳食纤维 | 60-65g / 6-7g / 6-7g |
| 钙 / 铁 / 镁 | 150-160mg / 7-8mg / 240-250mg |

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 发芽温度 | 15℃以上（最适20-25℃）。播种时期以地温而不是气温来定 |
| 生长温度 | 15-35℃（最适20-32℃）。10℃时停止生长，遇霜一次即枯死 |
| 光 | 每天6-8小时以上。种在日照最好的位置，避开背阴地 |
| 水 | 每季约250mm。初期水分很重要，过湿比干旱更危险 |
| 土壤 | 排水良好的沙壤土-壤土，土层深度30cm以上，pH 5.0-7.0，垄高20cm以上 |

| 种 | 特点与用途 |
|:---|:---|
| Amaranthus cruentus | 籽粒用的代表。产量高，叶也能用，最稳妥 |
| Amaranthus hypochondriacus | 籽粒较大的籽粒用种 |
| Amaranthus caudatus | 穗子长长下垂。适合凉爽的高地 |
| Amaranthus tricolor | 叶菜用 |

&nbsp;&nbsp;&nbsp;选择籽粒大的品系（RRC 1027在韩国国内试验中每1,000㎡产465kg，还有Golden Giant等）。籽粒苋最费力的不是栽培，而是收获后的脱粒和筛选，籽粒越大越容易。韩国没有自主培育的品种，大部分是从国外引进的。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 耕深20-30cm，挖排水沟，把土打碎整平，播种前后镇压 |
| 氮 N / 磷 P / 钾 K | 每1,000㎡ 8kg / 12kg / 12kg。磷和钾全部作基肥 |
| 堆肥 | 1,000kg。腐熟堆肥 |
| 替代资源 | 草木灰（每㎡一把）、尿液稀释10-20倍（仅限穗子立起之前）、骨粉、草液肥（发酵2周后稀释5-10倍，仅限初期） |

> **认为籽粒苋要多施氮肥，几乎总是错误的判断。植株会长高、叶子会茂盛，但穗子变轻，一场风雨就会让整块地倒伏。**

| 播种 | 标准 |
|:---|:---|
| 时期 | 4月下旬-5月上旬直播。地温15℃以上，霜完全结束之后 |
| 深度 | 0.5-1cm。再深幼芽就出不来。播种后务必用木板或脚踩实，使土与种子贴紧 |
| 间距 | 行距20-30cm，株距40-50cm。条播或点播 |
| 种子量 | 每1,000㎡ 200-400g。无需浸泡 |
| 种子处理 | 50-55℃热水10-15分钟，或拌细灰。水中浮起的丢弃 |
| 间苗 | 2-3片真叶时株距20cm，4-5片时40-50cm。间下来的幼苗当野菜吃 |

## 5. 水与栽培管理、病虫害
| 时期 | 水管理 |
|:---|:---|
| 播种-幼苗期 | 每天湿润一两次，不让表土变干。铺一层薄稻草覆盖（薄到能透出土色） |
| 营养生长期 | 交给自然降雨 |
| 开花·灌浆期 | 仅在严重干旱时补水 |

&nbsp;&nbsp;&nbsp;大多数失败发生在播种后的3周内。播种前先耕一遍，让杂草种子发芽，再浅浅地刮掉，条播，行外的全部拔掉。度过这3周，籽粒苋自己形成荫蔽，杂草就赢不了了。

| 管理 | 内容 |
|:---|:---|
| 防倒伏 | 株高30-50cm时培土，50cm时立支柱，1m时拉绳。减少氮肥 |
| 摘心 | 株高60-80cm时掐去顶端，侧枝增多，利于采叶；不摘心则形成一个大穗，利于收种子 |
| 叶与种子兼用 | 从播种40天到开花前，摘取下部叶片，每次不超过全株的三分之一。穗子立起后，停止采叶和供氮 |

| 病虫害 | 时期与危害 | 不用农药的应对 |
|:---|:---|:---|
| 蝽类 | 5月中旬-10月。籽粒减产69.8%，最严重 | 清晨用手捉，清理田边杂草 |
| 蚜虫类 | 4月下旬-6月初。籽粒减产51.9% | 强水流冲洗、肥皂水（每1L水加肥皂20g）、保护天敌 |
| 蛾类 | 8月中旬-10月中旬。叶片减产72.5% | 傍晚用手捉、清除卵块、诱虫灯 |
| 猝倒病、根腐病、叶枯病、白粉病、穗腐 | 幼苗期与雨季、排水不良 | 不密播、排水与通风、病株移出田外 |

&nbsp;&nbsp;&nbsp;草木灰、大蒜浸出液、木醋液（稀释500-1,000倍）、波尔多液也可以用。不要连续种植苋科作物，要休耕2年。

| 缺素·过量 | 症状与处理 |
|:---|:---|
| 缺氮 | 从下部叶片开始变黄。稀释尿液、腐熟堆肥 |
| 缺钾 | 下部叶缘焦枯呈褐色。少量草木灰 |
| 缺磷 | 叶片发紫，生长缓慢。骨粉、草木灰 |
| 缺铁 | 新叶发黄而叶脉保持绿色。pH较高时。减少草木灰并增施有机物 |
| 氮过量 | 籽粒苋养分问题的大部分。只长个子、倒伏、穗子不饱满，并招来蚜虫。停止施氮 |

&nbsp;&nbsp;&nbsp;施氮多的叶片会积累硝酸盐，所以采收前2周停止施氮，选晴天下午采摘，并倒掉焯水的水。不要给婴儿多吃。

## 6. 间作与轮作
| 搭配 | 作物 |
|:---|:---|
| 好 | 豆科（分给氮素）、玉米·高粱（一起吃时氨基酸互补）、向日葵 |
| 差 | 苋科（菠菜、莙荙菜、甜菜）共有病虫害；生菜、白菜等喜凉的叶菜在籽粒苋的荫蔽下长不好 |

&nbsp;&nbsp;&nbsp;第1年种籽粒苋，第2年种豆科（大豆、豇豆、绿豆），补回籽粒苋用掉的氮。不仅要看田里的搭配，也要看碗里的搭配。

## 7. 收获、筛选、留种
| 类别 | 方法 |
|:---|:---|
| 叶 | 从播种40天到开花前，每隔1-2周摘取下部长足的叶片。叶越嫩越柔软，草酸越少 |
| 割取种子的时机 | 用手掌捋穗子，有少量籽粒开始脱落的那一刻。一粒都不掉说明太早，哗哗掉落则太晚 |
| 辅助迹象 | 柱头干枯变褐，穗子呈褐色或红褐色，下部叶片变黄脱落，种子硬到指甲掐不进去 |
| 割取 | 晴天早晨露水干后，割下带穗的花茎。用麻袋或布兜住，小心搬运，不让种子洒落 |
| 干燥 | 倒挂或摊在草席上5-10天。下面铺布，接住自行脱落的种子 |
| 脱粒 | 装进麻袋拍打，或在草席上用棍子敲打。一次打不完，要翻过来反复进行 |

| 筛选 | 方法与局限 |
|:---|:---|
| 粗筛、细筛 | 筛除小枝与碎屑。筛孔需在1mm以下 |
| 扬筛、扇风 | 吹走轻的壳。种子也轻，会有损失 |
| 水选 | 倒入水中，捞去浮起的秕粒。最可靠，但捞出后必须立刻晒干（几小时内就会发芽） |
| 斜板 | 倒在倾斜的板上，只有圆形的种子会滚下来 |

&nbsp;&nbsp;&nbsp;不必筛得十全十美。留种时，在开花期预先标记无病、穗大、未倒伏的植株，等穗子完全干成褐色再收。给穗子套上布袋，可以接住掉落的种子并防鸟。在阴凉处晒到水分10%以下，然后密封。

## 8. 储存
| 项目 | 方法 |
|:---|:---|
| 种子 | 晒到水分10%以下（咬一下啪地一声碎裂），在阴凉处放凉后，装入陶罐、玻璃瓶或金属罐密封。把炒过放凉的盐或木炭用布包好一起放入，置于阴凉黑暗处。分装在多个容器里 |
| 保存期限 | 完全干燥并密封3-5年，常温放置1-2年，有湿气进出则不足1年 |
| 叶 | 原样放3-5天。焯水后晒干6个月-1年，按重量3-5%的盐腌2-3个月，酱菜数月，焯水后冷冻数月 |

&nbsp;&nbsp;&nbsp;耐储性SS加上种子寿命，使它成为少见的、吃的和种的可以放在同一个袋子里的作物。储存中最常见的失败是粮食害虫。

## 9. 烹调与注意事项
| 烹调 | 内容 |
|:---|:---|
| 炒爆 | 几十秒就像爆米花一样爆成白色，无需再加热即可吃。最省燃料 |
| 煮 | 水量为种子的两三倍，煮20-30分钟 |
| 掺煮 | 与稻米、大麦、玉米以谷物比苋4:1-10:1掺在一起煮。最实用 |
| 面粉 | 不含面筋，不能代替小麦粉 |
| 叶 | 在沸水中焯30秒-1分钟，用冷水冲洗，挤去水分，用于凉拌、汤、炒菜、粥。焯过的水倒掉 |

| 成分 | 问题与应对 |
|:---|:---|
| 叶中的草酸 | 妨碍钙吸收并引起结石。焯水后倒掉水，用嫩叶，不要大量生吃。有结石病史者慎用 |
| 叶中的硝酸盐 | 见第5章的对策。茎和叶柄中更多 |
| 种子中的皂苷、植酸 | 用水洗净，浸泡或发酵。发芽的种子要多次冲洗并短时间加热 |
| 种子中的凝集素、胰蛋白酶抑制剂 | 加热即可消除。不要生吃 |
| 其他 | 注意花粉过敏；膳食纤维多，要与其他谷物混合食用 |

> **籽粒苋的叶子，基本做法是焯水后倒掉水再吃。种子不要生吃，煮熟就没有问题。**

## 10. 全年作业计划
| 月 | 作业 |
|:---|:---|
| 1-2月 | 休息。检查种子保存状态（湿气、虫害） |
| 3月 | 施堆肥和草木灰，把地耕好 |
| 4月 | 耕地使杂草种子发芽，再浅浅刮除。4月下旬-5月初播种（浅播，务必压实） |
| 5月 | 保持表土不干。第1次间苗。最初的3周是关键 |
| 6月 | 第2次间苗、培土、立支柱、开始采叶 |
| 7月 | 拉绳、清理杂草、监测蚜虫和蝽 |
| 7月下旬-8月 | 穗子立起后，停止采叶和施氮。蝽是最大威胁 |
| 8月下旬-9月中旬 | 收获种子。在少量籽粒开始脱落时割取 |
| 9-10月 | 晾晒、脱粒、筛选、挑选留种、完全干燥后密封储存 |
| 11-12月 | 把茎秆切断，作堆肥或柴火。检查储存状态 |

> **种籽粒苋很容易，收获却很难。这种作物所有的辛苦，都出自种子小这一个事实。**
