## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

&nbsp;&nbsp;&nbsp;籽粒苋是苋科（Amaranthaceae）苋属（Amaranthus）的一年生草本植物。全世界约有六十个种，其中作为食用栽培的仅有几种。同科植物还包括菠菜、莙荙菜、甜菜和藜麦。了解这一谱系，就能自然明白籽粒苋叶片中会积累草酸和硝酸盐的原因。菠菜和莙荙菜存在同样的问题，原因正是如此。

&nbsp;&nbsp;&nbsp;韩国田间和路边常见的杂草苋菜、反枝苋也是同属植物。二者外形相似，幼苗阶段很难分辨，实际种植中如果苋菜杂草混入籽粒苋地里，间苗时容易混淆。选择叶色明显偏红或带花纹的品种，可以减少这个问题。杂草苋菜的叶子也能当野菜食用，混入并非完全没有用处，但留种时就会成为问题。

&nbsp;&nbsp;&nbsp;籽粒苋原产于中美洲和安第斯高地。在阿兹特克，它与玉米、豆类并列为三大作物之一，还用于宗教仪式。西班牙征服之后栽培几乎被禁止而近乎中断，20世纪后半叶因营养价值被重新发现而复兴。这一出身决定了它的栽培条件。第一，作为热带高地植物，它不知霜为何物，耐热性强。第二，作为旱季雨季分明地区的植物，它耐旱，但积水会伤根。第三，它在强烈的赤道阳光下演化出C4方式，因此不耐阴。

### 2-2. C4是什么意思

&nbsp;&nbsp;&nbsp;籽粒苋是双子叶植物中少见的采用C4光合作用方式的植物，这一点与这种作物几乎所有的特性都有关联，值得单独说明。

&nbsp;&nbsp;&nbsp;一般植物通过叶片气孔吸入的二氧化碳，由一种酶直接固定。但这种酶不能很好地区分二氧化碳和氧气。天气炎热、光照强烈时，叶片内氧气浓度升高，酶捕获氧气而非二氧化碳的情况就会增多。处理由此生成的产物需要消耗能量，结果就等于把光合作用赚来的东西当场吃掉。这个过程叫作光呼吸，天气越热越严重。生菜和大白菜在盛夏停止生长，原因之一就在于此。

&nbsp;&nbsp;&nbsp;C4植物通过改变叶片结构避开了这个问题。外层细胞先把二氧化碳固定成一种含四个碳原子的化合物，运送到内层细胞后再重新释放出来。内层细胞的二氧化碳浓度因此升高，酶几乎没有机会错误地捕获氧气，光呼吸几近消失。

| 结果 | 有何不同 |
|---|---|
| 高温下更有利 | 超过25℃光合作用反而加快。夏季是其全盛期 |
| 节省用水 | 由于能浓缩二氧化碳，气孔无需大开。这是蒸散量250mm的依据 |
| 节省氮素 | 所需酶较少，叶片消耗的氮素也少。这是适应贫瘠土地的依据 |
| 阴凉处不利 | 运转浓缩机制需要消耗能量。光照不足时，这部分成本白白支出，反而造成损失 |

> **籽粒苋的优点和缺点都来自同一种结构。它耐热耐旱的原因，和它在阴凉处会垮掉的原因是同一个。**

### 2-3. 形态特征

| 器官 | 特征 |
|---|---|
| 叶 | 互生。呈宽卵形，长5-15cm。有绿色、红色以及两色混合的类型 |
| 茎 | 有直立型和匍匐型两种。直立型可长到2m高，粗度有时超过3cm |
| 根 | 以笔直的主根为主。播种70天后可深达2.4m，横向扩展至1.8m |
| 花 | 极小的花朵密集聚生成穗状。通常一株上同时着生雌花和雄花，花粉靠风传播 |
| 种子 | 直径1-1.5mm，呈凸透镜状。千粒重0.6-0.9g，有白色、黄色、黑色等类型 |

&nbsp;&nbsp;&nbsp;根系能扎到2m以上，这一点具有很大的实用意义。即便表土完全干透，它也能汲取深层水分。干旱之年，玉米叶片卷曲枯萎之时，籽粒苋依然青翠挺立的场景确实会出现。不过要扎出这样深的根，土壤须不能过于坚实，若地下存在硬层，这一能力就会减半。

&nbsp;&nbsp;&nbsp;种子的结构与谷物完全不同。水稻和小麦的种子中心由淀粉块状的胚乳占据，胚芽则小小地附着在一角。因此去掉外壳和麸皮后只剩淀粉，蛋白质、脂肪和维生素都随被去掉的部分一起流失，这就是精米营养少于糙米的原因。籽粒苋的淀粉聚集在种子正中央，胚芽像一个圈一样将其环绕。没有麸皮可去，也没有必要去除。

| 比较项目 | 水稻·小麦 | 籽粒苋 |
|---|---|---|
| 碾磨 | 需要 | 不需要 |
| 碾磨损耗 | 20-30% | 无 |
| 碾磨设备 | 需要碾米机或石臼 | 不需要 |
| 营养分布 | 集中在外层，碾磨后会流失 | 均匀分布于整粒种子 |
| 淀粉颗粒大小 | 10-30μm | 1-3μm，非常细小 |

&nbsp;&nbsp;&nbsp;最后一行提到的细小淀粉颗粒说明两点。一是容易消化，二是放入热锅中时，颗粒内部的水分会瞬间汽化，像爆米花一样爆开。这个特性在烹饪中起着关键作用，将在第16节讲述。

### 2-4. 生长阶段

| 阶段 | 时期 | 核心生理 | 重要养分 |
|---|---|---|---|
| 发芽·幼苗期 | 播种后3周 | 幼苗出土极小，生长缓慢，容易被杂草压制 | 磷肥，少量氮肥 |
| 营养生长期 | 3周至8周 | 茎叶迅速增多，开始采收叶片 | 氮肥 |
| 开花期 | 8周至12周 | 抽穗，花粉借风传播 | 磷肥、钾肥 |
| 灌浆成熟期 | 12周至16周 | 籽粒成熟，成熟者开始脱落 | 钾肥 |

&nbsp;&nbsp;&nbsp;这张表中最危险的一栏是第一个阶段。籽粒苋种子小，刚出土的幼苗也很小。子叶细如丝线，很多时候过了3周仍长不过一指节。同一时期杂草长得快得多。籽粒苋栽培的成败，很大程度上取决于如何挺过这3周，这个问题将在第8节讲述。

&nbsp;&nbsp;&nbsp;灌浆成熟期的特性也须提前了解。籽粒苋的穗并非自上而下或自下而上均匀成熟。同一穗中成熟时间也会参差不齐，先成熟的籽粒不等其他籽粒就会脱落。这种特性称为落粒，是野生植物传播种子的正常方式，栽培种中这一特性也没有完全消失。第12节的收获要领，全都源于这个事实。

### 2-5. 每100克营养成分

| 营养素 | 含量 | 备注 |
|---|:---:|---|
| 热量 | 383kcal | 以韩国国家标准食品成分表干燥种实为准，与谷物相当 |
| 蛋白质 | 17.09g | 超过大米的两倍 |
| 赖氨酸 | 丰富 | 弥补谷物的限制性氨基酸 |
| 碳水化合物 | 60-65g | 淀粉颗粒非常细小 |
| 脂肪 | 6-7g | 作为谷物含量偏高，以不饱和脂肪为主 |
| 膳食纤维 | 6-7g | 含量偏高 |
| 糖类 | 1.65g | 几乎没有甜味 |
| 钙 | 150-160mg | 在谷物中名列前茅 |
| 铁 | 7-8mg | 在谷物中含量偏高 |
| 镁 | 240-250mg | 含量非常高 |
| 总酚类化合物 | 994-1,732mg/kg | 具有抗氧化作用 |

&nbsp;&nbsp;&nbsp;评价表中的微量营养素A就来自这张表。每日摄入相当于2,100kcal的548g时，超过推荐量10%的营养素有14种，尤其钙、镁、铁较为突出。在缺少牛奶和鳀鱼干的饮食中，钙的来源会急剧减少，而籽粒苋种实虽是谷物，却含有相当可观的钙。

&nbsp;&nbsp;&nbsp;不过这里有一点需要说明。籽粒苋中同时含有草酸和植酸，会使部分钙和铁未被吸收就直接排出体外，也就是说，实际摄入体内的量并不如表中数字那么多。减少这种损失的方法将在第14节和第16节介绍。

&nbsp;&nbsp;&nbsp;叶片的营养与种实性质不同。每100g叶片热量只有20kcal左右，偏低，但β-胡萝卜素、维生素C、铁和钙含量丰富，可以看作与菠菜地位相近。所谓"一株能同时产出谷物和叶菜"，实际内容正是如此。

## 3. 栽培环境

### 3-1. 温度

| 类别 | 极限值 | 最适值 | 备注 |
|---|:---:|:---:|---|
| 发芽温度 | 15℃以上 | 20-25℃ | 低于15℃几乎不发芽 |
| 生长温度 | 15-35℃ | 20-32℃ | 评价表中的温度适应幅度B就来自这12℃的幅度 |
| 光合作用最适 | 25℃以上 | - | 属于C4作物，越热效率越高 |
| 高温极限 | 35℃以上 | - | 只要有水就能耐受，是叶菜类中最耐热的一类 |
| 低温极限 | 10℃ | - | 生长停止 |
| 致死温度 | 0℃ | - | 一次霜冻即可致死 |

&nbsp;&nbsp;&nbsp;决定籽粒苋播种时期的基准不是气温，而是地温。土壤须超过15℃种子才会发芽，超过20℃才能出苗整齐。若操之过急提早播种，细小的种子会直接在土里腐烂。在韩国中部，达到这一条件的时期是4月末到5月初。

### 3-2. 光照

| 类别 | 标准 | 备注 |
|---|---|---|
| 所需日照 | 每天6-8小时 | 低于此值生长会明显变差 |
| 最低日照 | 每天6小时 | 不足6小时会徒长，穗部发育不良 |
| 40%遮光时 | 相对产量45% | C4作物的共同数值，也是评价表中E等级的依据 |

&nbsp;&nbsp;&nbsp;不耐遮阴这一点决定了田块的布局。籽粒苋不适合种在墙根、树荫或建筑物之间的边角地。必须留出整天有日照的位置；反过来，由于籽粒苋本身能长到2m高，应把它种在北侧，以免给其他作物遮阴。

### 3-3. 水分与土壤

| 项目 | 标准 | 备注 |
|---|---|---|
| 总蒸散量 | 每个生长期约250mm | 是评价表中耗水量S的依据 |
| 前期水分 | 从播种到长出2-3片真叶前须保持不干 | 挺过这段时期后就很耐旱 |
| 过湿 | 会伤根 | 涝害比干旱更危险 |
| 土质 | 排水良好的砂壤土至壤土 | 不积水是首要条件 |
| 土层深度 | 30cm以上，越深越好 | 主根可深入2m以上 |
| pH值 | 5.0-7.0 | 可耐受4.3到7.5，耐酸性较强 |
| 垄高 | 20cm以上 | 目的是排水 |

&nbsp;&nbsp;&nbsp;耐旱的作物往往不耐涝，这种组合并不少见。粗壮的深根有利于在干燥土地中寻找水分，但一旦被水淹没就无法呼吸。之所以要求把垄做高到20cm以上、让水从沟中排走，原因就在这里。在韩国的梅雨季（6月下旬至7月）里连续几天积水的地块，并不适合种植籽粒苋。

## 4. 品种

### 4-1. 籽用与叶用

&nbsp;&nbsp;&nbsp;籽粒苋种类繁多，用途因种而异。大体可分为以收获种子为目的的籽用类型，和以收获叶片为目的的蔬菜用类型。

| 种 | 特征 | 主要用途 | 灾害情况下的用法 |
|---|---|---|---|
| Amaranthus cruentus | 籽用的代表品种，产量高，适应范围广 | 籽粒与叶片 | 最稳妥的选择 |
| Amaranthus hypochondriacus | 籽用品种，籽粒偏大 | 籽粒与叶片 | 以种子为主要目标时 |
| Amaranthus caudatus | 穗长而下垂，属安第斯系统 | 籽粒与观赏 | 较适合凉爽高地 |
| Amaranthus tricolor | 蔬菜用品种，叶片柔软，颜色多样 | 叶菜 | 以叶片为主要目标时 |

&nbsp;&nbsp;&nbsp;韩国国内没有自主培育的品种，大多为国外引进种。评价表中韩国国内栽培普及度为B，即只在三四个道种植，原因就在于此。在物流中断的情况下很难新获得种子，因此一旦到手就靠自家留种延续下去，是唯一的办法。所幸正如自家留种S所示，这项工作本身并不难。

### 4-2. 主要品种

| 品种 | 产量 | 特征 |
|---|:---:|---|
| RRC 1027 | 每1,000㎡产465kg | 韩国国内试种中产量最高的品系 |
| goldengiant | 每株400g以上 | 籽粒大、穗大，适合籽粒生产 |
| Kerala Red | 无数据 | 千粒重0.42g，特别轻，抗氧化成分含量高 |
| Chinesemulticolor | 无数据 | 叶片带花纹，用作蔬菜 |

&nbsp;&nbsp;&nbsp;评价表中单位面积热量D是以每1,000㎡产200kg为基准计算的，而韩国国内试验中产量在125kg到465kg之间浮动，这两点须一并来看。这意味着品种和栽培条件不同，产量可相差三四倍，这也是产量稳定性D的实质内容。如果有条件挑选种子，仅仅选用产量已获验证的品系，结果就会大不相同。

### 4-3. 按情况选择品种

| 情况 | 适合的品系 | 理由 |
|---|---|---|
| 想要补充粮食自给时 | Amaranthus cruentus、Amaranthus hypochondriacus | 产量高、籽粒大，脱粒挑选相对容易 |
| 以夏季叶菜为目的时 | Amaranthus tricolor | 叶片柔软，耐反复采收 |
| 想要籽粒与叶片兼用时 | Amaranthus cruentus | 叶片品质也不差，适合兼用 |
| 凉爽山区 | Amaranthus caudatus | 属安第斯高地系统，较适合凉爽地区 |
| 需要籽粒粗大时 | goldengiant系列 | 可减轻精选作业的负担 |

> **选择籽粒粗大的品系，不只是为了产量。栽培籽粒苋最费力的环节不是种植，而是收获后的脱粒与挑选，籽粒越大，这项工作就越轻松。**
