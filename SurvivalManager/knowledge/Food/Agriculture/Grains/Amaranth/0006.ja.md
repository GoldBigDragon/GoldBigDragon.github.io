## 13. 採種と種子の保管

### 13-1. 採種

| 段階 | 方法 | なぜそうするのか |
|---|---|---|
| 株選び | 病気がなく穂が大きく倒れていない株を選びます | 種子は親に似ます |
| 印を付ける | 開花期にあらかじめ印を付けておきます | 収穫時にはどの株がよかったか分かりにくいです |
| 完全に熟させる | 穂が完全に褐色に枯れるまで置きます | 未熟な種子は発芽力が低いです |
| 袋掛け | 穂に布袋をかぶせて縛っておきます | 落ちる種子を受け止め、鳥に取られません |
| 脱穀と選別 | 12節と同じ方法で、より念入りに行います | 種子用はしいなが混じると発芽率が落ちます |
| 乾燥 | 日陰で水分10%以下まで乾かします | 爪で押しても跡がつかない状態にします |
| 保管 | 密閉容器に入れ涼しく暗い場所に置きます | 湿気と光と熱が発芽力を落とします |

&nbsp;&nbsp;&nbsp;評価表の自家採種Sは二つの理由に基づいています。一つは自家受粉が中心のため品種が混じりにくいこと、もう一つは種子があまりにも多く大量確保が容易なことです。一株から数千粒から数万粒が採れるため、数株残すだけで翌年の畑を埋め尽くせます。

&nbsp;&nbsp;&nbsp;ただし注意すべき点が一つあります。畑の周りに雑草のヒユが生えていると、風に運ばれた花粉が混じることがあります。同じ属のため交雑が起こり、そうして得た種子には雑草のヒユの性質が現れます。粒が小さくなり黒ずみ、脱粒がひどくなります。採種用の株の周りの雑草のヒユは、花が咲く前に抜いておく必要があります。

### 13-2. 保管

| 条件 | 発芽力が保たれる期間 |
|---|:---:|
| 完全に乾燥させ密閉、涼しく暗い場所 | 3-5年 |
| そのまま常温に置いた場合 | 1-2年 |
| 湿気が出入りする場所 | 1年未満 |

| 保管方法 | 内容 |
|---|---|
| 容器 | ガラス瓶、甕、金属缶のように空気が通らないもの |
| 乾燥剤 | 炒って冷ました塩、炭、炒った米を布に包んで一緒に入れます |
| 場所 | 地下や北向きの部屋のように涼しく温度変化が少ない所 |
| ÷ | 複数の容器に分けて入れます。一つの容器を失っても全部は失いません |
| 表示 | 品種と採種した年を書いておきます |

&nbsp;&nbsp;&nbsp;貯蔵性SSと種子寿命Aが重なり、アマランサスは食べる分と植える分を同じ袋に入れておいてよい、数少ない作物です。3年たっても発芽率が大きく落ちないため、一年不作になっても古い種子でまた始められます。複数年を見据えた自給計画において価値の高い性質です。

## 14. 毒性と注意すべき成分

### 14-1. 葉のシュウ酸

&nbsp;&nbsp;&nbsp;アマランサスの葉にはシュウ酸が含まれています。同じ科のホウレンソウとフダンソウも同じ問題を抱えており、その理由はこの科の植物が体内に余ったカルシウムをシュウ酸と結び付けて結晶にすることで処理しているためです。

| 何が問題か | 内容 |
|---|---|
| カルシウム吸収の妨げ | シュウ酸がカルシウムと結び付いて結晶になると、体は吸収できずそのまま排出します。アマランサスにカルシウムが多いのに使い切れない理由です |
| 結石 | シュウ酸カルシウムは腎臓結石の主な成分です。結石を患ったことがある人は多く食べないほうがよいです |
| 渋み | シュウ酸が多いと口の中がざらつきます |

| 減らす方法 | 原理 |
|---|---|
| 熱湯でゆでてその湯を捨てます | シュウ酸は水によく溶け、かなりの部分が抜け出ます。最も確実な方法です |
| 若い葉を使います | 葉が育つほどシュウ酸が増えます |
| カルシウムを含むものと一緒に食べます | シュウ酸が器の中で先にカルシウムと結び付けば、腸での吸収の妨げが少なくなります |
| 生で多く食べません | ゆでていない葉にはシュウ酸がそのまま残っています |

> **アマランサスの葉はゆでてその湯を捨ててから食べるのが基本です。ゆで汁を汁物に使う他のナムルとは異なります。**

### 14-2. 葉の硝酸塩

&nbsp;&nbsp;&nbsp;10節で扱った硝酸塩の問題が、毒性の項目でも繰り返されます。ヒユ科植物は硝酸塩をため込みやすい系統で、肥料を多く与えた畑で育った葉ほど多くたまります。亜硝酸塩に変わると血液の酸素運搬を妨げ、乳児には特に危険です。窒素肥料を減らすこと、ゆで汁を捨てること、天気のよい日の午後に摘むことの三つが減らす方法です。

### 14-3. 種子のサポニンとその他の成分

| 成分 | どこにあるか | 何が問題か | どうするか |
|---|---|---|---|
| サポニン | 種子の殻側にごく微量 | 苦味があり多く食べると胃腸の不快感が出ることがあります。キヌアよりはるかに少なく実質的な問題は大きくありません | 水で洗い流します。サポニンは水によく溶け石けんのように泡立ちます |
| 発芽中のサポニン増加 | 発芽させた直後の種子 | 発芽させると防御物質が増えます。スプラウトとして食べるとき苦味が強くなります | 発芽させて食べるときは何度もすすぎ短時間加熱します |
| フィチン酸 | 種子全体 | 鉄、亜鉛、カルシウムと結び付き吸収を妨げます | 水に浸すか発酵させると減ります |
| レクチン、トリプシン阻害物質 | 種子に微量 | 生の状態でのみ作用し、加熱すればなくなります | 必ず加熱して食べます |

&nbsp;&nbsp;&nbsp;まとめると、アマランサスの種子は生で食べず加熱して食べれば問題になりません。豆のように8時間浸して1時間煮なければならないほどの毒性はまったくありません。洗って20分から30分煮るか、乾いたフライパンで炒って弾けさせれば十分です。

### 14-4. そのほかの注意点

| 項目 | 内容 |
|---|---|
| 花粉 | 穂から出る花粉が多く、アレルギーのある人は開花期に近づかないほうがよいです |
| 雑草のヒユとの混同 | 雑草のヒユも食べられますが、育ったものはシュウ酸と硝酸塩がより多いです |
| 種子の割合 | 種子だけで食事を満たすと食物繊維が過剰になりお腹が不快になることがあります。他の穀物と混ぜて食べます |
| 子どもと乳児 | 葉の硝酸塩のため多く食べさせません。種子は加熱すれば問題ありません |

## 15. 冷蔵庫なしの貯蔵

### 15-1. 種子の貯蔵

&nbsp;&nbsp;&nbsp;評価表の貯蔵性SSはこの項目から来ています。よく乾燥させた種実は常温で3年を超えてもちます。この作物が災害対策品種として値打ちを持つ最大の理由の一つです。

| 段階 | 方法 | なぜそうするのか |
|---|---|---|
| 完全乾燥 | 水分10%以下まで乾かします。種子を歯で噛んでパキッと音がして砕ければ完了です | 水分が残ると貯蔵中にカビが生え熱がこもります |
| 冷ます | 天日で乾かした後、日陰で完全に冷ましてから詰めます | 温かいまま詰めると容器の内側に露がつきます |
| 密閉 | 甕、ガラス瓶、金属缶に入れて閉じます | 湿気と虫を防ぎます |
| 乾燥剤 | 炒って冷ました塩や炭を布に包んで入れます | 残った湿気を吸い取ります |
| 場所 | 涼しく暗く温度変化が少ない所に置きます | 地下や北向きの部屋が適しています |
| ÷ | 複数の容器に分けて入れます | 一つの容器に虫が入っても全部は失いません |

&nbsp;&nbsp;&nbsp;貯蔵中に最もよくある失敗は穀物害虫です。コクゾウムシのような虫が入ると数か月で袋を空にしてしまいます。防ぐ方法はまず密閉、次ににおいです。乾燥トウガラシ、ニンニク、サンショウ、月桂樹の葉、灰を一緒に入れておくと虫が減ります。すでに虫が入ったものは天日に干して虫を追い出したうえで、再び乾かして詰め直します。

### 15-2. 葉の貯蔵

| 方式 | 方法 | 期間 |
|---|---|:---:|
| そのまま置く | 洗わずに涼しい場所に | 3-5日 |
| 乾燥 | ゆでて水気を絞り、日陰でしっかり乾かします | 6か月から1年 |
| 塩漬け | 重量の3-5%の塩で漬けて重石をします | 2-3か月 |
| チャンアチ（醤油漬け） | ゆでて醤油やテンジャン（韓国味噌）に漬け込みます | 数か月 |
| 冷凍 | ゆでて水気を絞り、凍らせます | 数か月 |

&nbsp;&nbsp;&nbsp;葉を乾燥させるとき、ゆでる工程を必ず入れる必要があります。目的は二つです。一つは酵素の働きを止めて色と味が変わるのを防ぐこと、もう一つはシュウ酸を抜き出すことです。生のまま乾燥させたアマランサスの葉にはシュウ酸がそのまま残り、水分が抜けた分だけ濃度がむしろ高くなります。

## 16. 調理と加工

### 16-1. 種子を調理する三つの方法

| 方法 | 時間 | 燃料 | 結果 |
|---|:---:|:---:|---|
| 煮る | 20-30分 | 多くかかります | 種子が水を吸いねっとりした粥のようになります。水は種子の2-3倍を目安にします |
| 炒って弾けさせる | 数十秒 | 最も少なくて済みます | ポップコーンのように白く弾けます。香ばしくなりかさが増えます |
| 他の穀物と混ぜて炊く | ご飯を炊く時間のまま | 追加の燃料が要りません | 米や大麦に混ぜて一緒に炊きます。最も実用的です |

&nbsp;&nbsp;&nbsp;燃料が貴重な状況で最もよいのは炒って弾けさせる方法です。熱した乾いた鍋や鉄板に種子をスプーン一杯ずつ入れると、数秒でパチパチと弾けて白く膨らみます。アマランサスのでんぷん粒が1-3μmと非常に小さく、熱が瞬時に内側まで届くためです。一度に多く入れると温度が下がって弾けずに焦げるので、少しずつ何度も行うのがこつです。

> **弾けさせたアマランサスは、さらに加熱しなくてもそのまま食べられます。一度の火で数秒、これが燃料が絶たれた状況でこの作物が持つ最も実質的な利点です。**

&nbsp;&nbsp;&nbsp;弾けさせたものは、はちみつや水あめを混ぜて固めると塊になります。メキシコで古くから食べられてきた方法で、持ち運べる非常食になります。粉に挽いておけばスープや粥に溶かし入れやすく、水に溶けばそのまま重湯になります。

### 16-2. 小麦粉の代わりに使う

&nbsp;&nbsp;&nbsp;アマランサス粉にはグルテンがありません。そのためこれだけではパンが膨らまず、麺が切れてしまいます。小麦粉に3割程度まで混ぜれば大きな問題なく使え、それ以上だと生地がぼろぼろになります。グルテンが要らないクレープ、チヂミ、粥、すいとんの生地には制限なく使えます。

### 16-3. 葉の調理

| 方法 | 内容 |
|---|---|
| ゆでて和える | 熱湯で30秒から1分ゆで、冷水にさらして水気を絞り和えます。ゆで汁は捨てます |
| 汁物 | テンジャン（韓国味噌）汁に入れます。長く煮ると柔らかくなりすぎるので最後に入れます |
| 炒め物 | ゆでてから油で炒めます。ゆでずにそのまま炒めるとシュウ酸が残ります |
| 粥 | 細かく刻んで穀物粥に入れます |
| 乾燥葉 | 水で戻して汁物やナムルに使います |

### 16-4. 穀物と混ぜて食べる理由

&nbsp;&nbsp;&nbsp;アマランサスを他の穀物と混ぜて食べることは、量を増やす方便ではなく、タンパク質の組成を整えることです。

| 組み合わせ | 何が補われるか |
|---|---|
| トウモロコシ＋アマランサス | トウモロコシに不足するリジンとトリプトファンをアマランサスが補います |
| 米＋アマランサス | 米に不足するリジンを補い、タンパク質の総量も上げます |
| モロコシ＋アマランサス | モロコシのリジン不足を埋めます |
| 小麦＋アマランサス | リジンを補います。ただし生地の性質が悪くなるため割合を調節します |
| 豆＋アマランサス | どちらもリジンが豊富なため補完効果は大きくありません。総量は増えます |

&nbsp;&nbsp;&nbsp;混ぜる比率は、穀物対アマランサスでおよそ4対1から10対1で十分です。アマランサスを多く入れても効果が比例して大きくなるわけではありません。不足するアミノ酸が満たされたら、その先はただ穀物が一つ増えるのと同じになります。

## 17. 年間作業スケジュール

### 17-1. 月別表

| 月 | 作業 | 注目点 |
|---|---|---|
| 1-2月 | 休みます | 種子の保管状態を確認します。湿気と虫を見ます |
| 3月 | 畑の準備を始めます | 堆肥と草木灰を入れて耕しておきます。育苗するならこの月の初めに播種します |
| 4月初め・中旬 | 畑を耕して雑草の芽を出させた後、浅くかいて取り除きます | この一手間が初期の雑草負担を大きく減らします |
| 4月末-5月初め | 播種します。浅く播き必ず鎮圧します | 地温15度以上、霜が完全に終わった後です |
| 5月 | 表土を乾かさないようにします。1回目の間引き | 初期の3週間が山場です。雑草との戦いです |
| 6月 | 2回目の間引き、土寄せ、支柱立て | 草丈50cmが支柱を立てる時期です |
| 6月 | 葉の収穫を始めます | 播種40日ごろからです |
| 7月 | 縄張り、雑草の片付け、葉の収穫を続けます | アブラムシとカメムシを見回ります |
| 7月下旬-8月 | 穂が立ちます。葉の収穫をやめます | この時から窒素を与えません |
| 8月 | 開花と登熟。ガ類が現れます | カメムシが最大の脅威です |
| 8月下旬-9月中旬 | 種実収穫 | しごいて粒が少し落ち始めたときに刈ります |
| 9月-10月 | 乾燥、脱穀、選別 | 最も手間がかかる時期です |
| 10月 | 採種用の選別、貯蔵 | 完全に乾かして密閉します |
| 11月 | 畑の片付け | 茎は切って堆肥の山に入れるか薪に使います |
| 12月 | 休みます | 貯蔵状態を確認します |

### 17-2. 一年を貫く軸

&nbsp;&nbsp;&nbsp;アマランサスの一年には山場が二つあります。一つは5月の3週間で、もう一つは9月の十日間です。

&nbsp;&nbsp;&nbsp;5月の3週間は、種子が小さいという事実が生み出す山場です。浅く植える、鎮圧する、表土を乾かさない、雑草を抑えるという四つをこの期間に守れば、その後はほとんど手がかかりません。この3週間に失敗すると、その年の畑は雑草畑になります。

&nbsp;&nbsp;&nbsp;9月の十日間は、脱粒が生み出す山場です。数日早ければ未熟なものを収穫することになり、数日遅ければ畑にすべてこぼれ落ちます。この判断を助けるのはカレンダーではなく手のひらです。毎日一度穂をしごいてみることが、この作物における最も価値ある習慣です。

> **アマランサスを育てるのはやさしく、収穫するのは難しいです。種子が小さいというただ一つの事実が、この作物のあらゆる苦労が生まれる源です。**
