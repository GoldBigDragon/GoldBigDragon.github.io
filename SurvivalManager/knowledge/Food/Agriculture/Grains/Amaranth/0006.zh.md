## 13. 留种与种子保存

### 13-1. 留种

| 阶段 | 方法 | 原因 |
|---|---|---|
| 选株 | 挑选无病、穗大且未倒伏的植株 | 种子会像亲本 |
| 做标记 | 在开花期提前做好标记 | 到收获时很难分辨哪株表现好 |
| 充分成熟 | 待穗完全变褐干枯后再处理 | 未成熟籽粒发芽力低 |
| 套袋 | 给穗套上布袋并扎紧 | 能接住脱落的籽粒，也防止被鸟啄食 |
| 脱粒精选 | 方法与第12节相同，但须更加仔细 | 留种用的籽粒若混入秕粒会降低发芽率 |
| 晾干 | 在阴凉处晾至含水率10%以下 | 须晾到用指甲按压不留痕迹的程度 |
| 保存 | 装入密封容器，放在阴凉黑暗处 | 湿气、光照和高温都会降低发芽力 |

&nbsp;&nbsp;&nbsp;评价表中的自家留种S基于两点。一是以自花授粉为主，品种不易混杂；二是种子数量极多，容易大量获取。一株就能收获数千到数万粒，留下几株就足以种满第二年的整片地。

&nbsp;&nbsp;&nbsp;不过有一点须注意。若田块周围生长着杂草苋菜，风传的花粉可能会混入。由于同属，会发生杂交，这样得到的种子会表现出杂草苋菜的特性：籽粒变小、颜色变黑、落粒加剧。留种用植株周围的杂草苋菜，须在开花前拔除。

### 13-2. 保存

| 条件 | 发芽力维持的时间 |
|---|:---:|
| 充分晾干后密封，放在阴凉黑暗处 | 3-5年 |
| 直接常温放置 | 1-2年 |
| 湿气进出的地方 | 不到1年 |

| 保存方法 | 内容 |
|---|---|
| 容器 | 玻璃瓶、陶罐、金属罐等不透气的容器 |
| 干燥剂 | 把炒过晾凉的盐、炭或炒米用布包好一起放入 |
| 存放位置 | 地下室或北向房间等阴凉、温度变化小的地方 |
| ÷ | 分装在多个容器中，即使丢失一个容器也不会全部损失 |
| 标注 | 记录品种和留种年份 |

&nbsp;&nbsp;&nbsp;耐储性SS与种子寿命A相叠加，使籽粒苋成为少数可以把食用份和留种份放在同一个袋子里的作物。即使过了3年，发芽率也不会大幅下降，因此哪怕遇上一年歉收，也能用陈年种子重新开始。这对着眼多年的自给计划而言，是很有价值的特性。

## 14. 毒性与需注意的成分

### 14-1. 叶片中的草酸

&nbsp;&nbsp;&nbsp;籽粒苋叶片中含有草酸。同科的菠菜和莙荙菜也有同样的问题，原因是这一科的植物会把体内多余的钙与草酸结合，以结晶的形式加以处理。

| 问题所在 | 内容 |
|---|---|
| 阻碍钙吸收 | 草酸与钙结合成结晶后，身体无法吸收，会直接排出体外。这就是籽粒苋钙含量虽高却无法全部利用的原因 |
| 结石 | 草酸钙是肾结石的主要成分。曾患结石的人最好不要大量食用 |
| 涩味 | 草酸多会使口腔产生涩感 |

| 减少方法 | 原理 |
|---|---|
| 用沸水焯烫后倒掉焯水 | 草酸易溶于水，大部分会随之流失，是最可靠的方法 |
| 使用嫩叶 | 叶片越老，草酸含量越高 |
| 与含钙食物同食 | 草酸若先在餐具中与钙结合，对肠道吸收的干扰就会减小 |
| 不大量生食 | 未焯烫的叶片中草酸会原样保留 |

> **籽粒苋叶片的基本吃法是焯烫后倒掉焯水再食用，这一点与用焯水做汤的其他野菜不同。**

### 14-2. 叶片中的硝酸盐

&nbsp;&nbsp;&nbsp;第10节讨论过的硝酸盐问题，在毒性这一项目中再次出现。苋科植物本身就容易积累硝酸盐，施氮越多的地里长出的叶片积累也越多。转化为亚硝酸盐后会妨碍血液携氧，对婴儿尤其危险。减少氮肥、倒掉焯水、在晴天下午采摘，这三点是降低硝酸盐的方法。

### 14-3. 籽粒中的皂苷及其他成分

| 成分 | 存在于何处 | 问题所在 | 应对方法 |
|---|---|---|---|
| 皂苷 | 种皮部位含微量 | 有苦味，大量食用可能引起肠胃不适。含量远低于藜麦，实际问题不大 | 用水洗净即可。皂苷易溶于水，会像肥皂一样起泡 |
| 发芽过程中皂苷增加 | 刚发芽的籽粒 | 发芽会使防御物质增多，作为芽苗食用时苦味会加重 | 发芽后食用时须多次冲洗并短时加热 |
| 植酸 | 遍布整粒籽粒 | 与铁、锌、钙结合，阻碍其吸收 | 浸泡或发酵可以降低含量 |
| 凝集素、胰蛋白酶抑制剂 | 籽粒中含微量 | 只在生的状态下起作用，加热后即失效 | 务必煮熟后食用 |

&nbsp;&nbsp;&nbsp;总结来说，籽粒苋种子只要不生吃、加热食用就不会有问题。它完全没有像豆类那样需要浸泡八小时、再煮一小时的毒性。只需洗净后煮20到30分钟，或用干锅炒爆，就已足够。

### 14-4. 其他注意事项

| 项目 | 内容 |
|---|---|
| 花粉 | 穗上花粉量大，有过敏体质的人最好在开花期避免靠近 |
| 与杂草苋菜混淆 | 杂草苋菜也可食用，但长老后草酸和硝酸盐含量更高 |
| 籽粒的比例 | 若全靠籽粒填饱饮食，膳食纤维会过量而导致肠胃不适，须与其他谷物混食 |
| 儿童与婴儿 | 因叶片硝酸盐问题不宜大量喂食，籽粒煮熟后则没有问题 |

## 15. 无冰箱贮藏

### 15-1. 种子贮藏

&nbsp;&nbsp;&nbsp;评价表中的耐储性SS正来自这一点。晾晒得当的种实在常温下可保存3年以上。这是这种作物作为灾害应对作物具有价值的最重要原因之一。

| 阶段 | 方法 | 原因 |
|---|---|---|
| 充分晾干 | 晾至含水率10%以下。用牙齿咬籽粒，发出脆响并碎裂即为合格 | 若残留水分，贮藏过程中会发霉发热 |
| 晾凉 | 晒干后须在阴凉处完全放凉再装入容器 | 若趁热装入，容器内壁会凝结水珠 |
| 密封 | 装入陶罐、玻璃瓶或金属罐后封闭 | 可防潮防虫 |
| 干燥剂 | 把炒过晾凉的盐或炭用布包好放入 | 吸收残留的湿气 |
| 存放位置 | 放在阴凉、黑暗、温度变化小的地方 | 地下室或北向房间较为合适 |
| ÷ | 分装在多个容器中 | 即使一个容器生虫，也不会全部损失 |

&nbsp;&nbsp;&nbsp;贮藏中最常见的失败是谷物害虫。米象之类的害虫一旦侵入，几个月内就能把一袋粮食吃空。预防方法首先是密封，其次是气味。放入干辣椒、大蒜、花椒、月桂叶、草木灰能减少虫害。已经生虫的粮食，应摊在阳光下把虫驱走，再重新晾干装存。

### 15-2. 叶片贮藏

| 方式 | 方法 | 期限 |
|---|---|:---:|
| 直接存放 | 不清洗，放在阴凉处 | 3-5天 |
| 晾干 | 焯烫后挤干水分，在阴凉处彻底晒干 | 6个月到1年 |
| 盐腌 | 用相当于重量3-5%的盐腌渍并压实 | 2-3个月 |
| 酱菜 | 焯烫后腌入酱油或大酱中 | 数月 |
| 冷冻 | 焯烫后挤干水分再冷冻 | 数月 |

&nbsp;&nbsp;&nbsp;晾晒叶片时必须先经过焯烫这道工序，目的有两个：一是让酶失活，防止变色变味；二是去除草酸。生晒的籽粒苋叶片中草酸会原样保留，而且随着水分蒸发，浓度反而会升高。

## 16. 烹饪与加工

### 16-1. 加热籽粒的三种方法

| 方法 | 时间 | 燃料 | 结果 |
|---|:---:|:---:|---|
| 煮 | 20-30分钟 | 耗费较多 | 籽粒吸水后变成黏稠的粥状，用水量为籽粒的两三倍 |
| 炒爆 | 数十秒 | 耗费最少 | 像爆米花一样爆开变白，香气浓郁，体积膨大 |
| 与其他谷物同煮 | 与煮饭时间相同 | 不需额外燃料 | 与大米或大麦混合同煮，最为实用 |

&nbsp;&nbsp;&nbsp;在燃料稀缺的情况下，最好的办法是炒爆。把烧热的干锅或铁板上每次放一勺籽粒，几秒钟内就会噼啪爆开、膨胀变白。这是因为籽粒苋的淀粉颗粒只有1-3μm，非常细小，热量能瞬间传到内部。一次放太多会导致温度下降而无法爆开、只是烧焦，所以少量多次是诀窍所在。

> **爆好的籽粒苋无需再加热即可直接食用。一次点火只需几秒钟，这是断绝燃料的情况下这种作物所具有的最实际的优势。**

&nbsp;&nbsp;&nbsp;把爆好的籽粒拌上蜂蜜或糖稀揉合，凝固后就能结成块状，这是墨西哥长期以来的传统吃法，也是便于携带的应急口粮。磨成粉后便于化入汤或粥中，用水调开就成了米汤状的糊糊。

### 16-2. 替代面粉使用

&nbsp;&nbsp;&nbsp;籽粒苋粉不含麸质，因此单独使用时面包发不起来，面条也容易断。掺入面粉中约到三成时问题不大，超过这个比例面团就会松散破碎。而在不需要麸质的煎饼、烙饼、粥、面疙瘩这类面糊中，则可以不受限制地使用。

### 16-3. 叶片烹饪

| 方法 | 内容 |
|---|---|
| 焯拌 | 沸水焯烫30秒到1分钟，过凉水后挤干水分再拌。焯水须倒掉 |
| 汤 | 放入大酱汤中，久煮会变软烂，须最后放入 |
| 炒制 | 焯烫后再用油炒。若不焯烫直接炒，草酸会残留 |
| 粥 | 切碎后放入谷物粥中 |
| 干叶 | 用水泡发后做汤或凉拌菜 |

### 16-4. 为什么要与谷物混食

&nbsp;&nbsp;&nbsp;把籽粒苋与其他谷物混食，并不是为了增加食量，而是为了改善蛋白质的构成。

| 组合 | 补充了什么 |
|---|---|
| 玉米+籽粒苋 | 籽粒苋补足玉米所缺的赖氨酸和色氨酸 |
| 大米+籽粒苋 | 补足大米所缺的赖氨酸，同时提高蛋白质总量 |
| 高粱+籽粒苋 | 弥补高粱赖氨酸不足 |
| 小麦+籽粒苋 | 补充赖氨酸，但会使面团性质变差，须调节比例 |
| 豆类+籽粒苋 | 两者赖氨酸都充足，互补效果不大，但蛋白质总量会增加 |

&nbsp;&nbsp;&nbsp;混合比例大致为谷物与籽粒苋4比1到10比1即可，籽粒苋加得越多，效果并不会成比例增大。一旦缺乏的氨基酸被补足，之后再加就等同于只是多加了一种普通谷物。

## 17. 全年作业日程

### 17-1. 月度表

| 月份 | 作业 | 须留意的事项 |
|---|---|---|
| 1-2月 | 休整 | 检查种子保存状态，留意湿气与虫害 |
| 3月 | 开始整地 | 施入堆肥和草木灰后耕地。若要育苗，本月初播种 |
| 4月上中旬 | 耕地诱发杂草发芽后浅刮除去 | 这一次操作能大幅减轻前期的杂草负担 |
| 4月末-5月初 | 播种，浅播并务必镇压 | 地温15度以上，霜期完全结束之后 |
| 5月 | 保持表土不干，第1次间苗 | 前期3周是关键，是与杂草的较量 |
| 6月 | 第2次间苗、培土、立支柱 | 株高50cm是立支柱的时机 |
| 6月 | 开始采叶 | 从播种约40天后开始 |
| 7月 | 拉绳固定、清理杂草、继续采叶 | 留意蚜虫和蝽象 |
| 7月下旬-8月 | 抽穗，停止采叶 | 从此时起不再施氮肥 |
| 8月 | 开花与灌浆，蛾类开始出现 | 蝽象是最大威胁 |
| 8月下旬-9月中旬 | 收获籽粒 | 手捋时籽粒开始有少许脱落即可收割 |
| 9月-10月 | 晾晒、脱粒、精选 | 最费工夫的时期 |
| 10月 | 留种精选、贮藏 | 须充分晾干后密封 |
| 11月 | 清理地块 | 茎秆切断后堆入堆肥或用作柴火 |
| 12月 | 休整 | 检查贮藏状态 |

### 17-2. 贯穿全年的主线

&nbsp;&nbsp;&nbsp;籽粒苋的一年中有两个关键期。一个是5月的3周，另一个是9月的十天。

&nbsp;&nbsp;&nbsp;5月的3周，是种子细小这一特性造成的关键期。浅播、镇压、保持表土不干、压制杂草，só要在这段时间做到这四点，之后就几乎不用再费心。若这3周失败，当年的地就会变成一片杂草地。

&nbsp;&nbsp;&nbsp;9月的十天，是落粒造成的关键期。早收几天会收到未成熟的籽粒，晚收几天籽粒就会全部落入田中。帮助判断这一时机的不是日历，而是手掌。每天用手捋一次穗，是这种作物栽培中最值得养成的习惯。

> **种植籽粒苋容易，收获籽粒苋却很难。种子细小这一件事，就是这种作物所有辛劳的根源。**
