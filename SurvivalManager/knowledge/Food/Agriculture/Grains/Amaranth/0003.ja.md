## 2. どんな植物か

### 2-1. 分類と原産地

&nbsp;&nbsp;&nbsp;アマランサスはヒユ科（Amaranthaceae）ヒユ属（Amaranthus）の一年草です。世界に60種ほどあり、そのうち食用として栽培されるのはわずか数種にすぎません。同じ科にはホウレンソウ、フダンソウ、テンサイ、キヌアが含まれます。この系統を知れば、アマランサスの葉にシュウ酸と硝酸塩が蓄積する理由も自然にわかります。ホウレンソウとフダンソウが同じ問題を抱えているのと同じ理由です。

&nbsp;&nbsp;&nbsp;韓国の畑や道端でよく見かける雑草のヒユやアオゲイトウも同じ属です。見た目が似ているため幼苗の段階では見分けが難しく、実際にアマランサス畑に雑草のヒユが混じって生えると、間引きの際に紛らわしくなります。葉の色がはっきり赤い品種や斑（ふ）入りの品種を選べば、この問題は減ります。雑草のヒユも葉をナムルとして食べられるので、混じったからといって無駄になるわけではありませんが、種子を採るときには問題になります。

&nbsp;&nbsp;&nbsp;原産地は中央アメリカとアンデス高地です。アステカではトウモロコシ、マメ類とともに三大作物の一つであり、宗教儀礼にも使われました。スペインによる征服後は栽培がほぼ禁止同然となって途絶えましたが、20世紀後半に栄養価が再発見されて復活しました。この出自が栽培条件を決めています。第一に、熱帯高地の植物なので霜を知らず暑さに強いことです。第二に、乾季と雨季がはっきりした土地の植物なので乾燥に耐える一方、水がたまると根が傷むことです。第三に、強い赤道直下の日差しの下で進化してC4方式を備えたため、日陰に弱いことです。

### 2-2. C4とはどういうことか

&nbsp;&nbsp;&nbsp;アマランサスが双子葉植物としては珍しくC4光合成を行うという点は、この作物のほぼすべての性質とつながっているため、あらためて説明するだけの価値があります。

&nbsp;&nbsp;&nbsp;普通の植物は、葉の気孔から入った二酸化炭素を一つの酵素でそのまま捕まえます。ところがこの酵素は二酸化炭素と酸素をうまく区別できません。気温が高く日差しが強くなると葉の中の酸素濃度が上がり、酵素が二酸化炭素の代わりに酸素を捕まえることが多くなります。そうしてできたものを処理し直すのにエネルギーがかかり、結果として光合成で稼いだ分をその場で食いつぶしてしまいます。これを光呼吸といい、暑いほどひどくなります。真夏にサンチュやハクサイの生長が止まる理由の一つがこれです。

&nbsp;&nbsp;&nbsp;C4植物は葉の構造を変えてこの問題を避けました。外側の細胞でまず二酸化炭素を炭素四個の化合物として捕まえて内側の細胞へ運び、そこで改めて放出します。内側の細胞の二酸化炭素濃度が高まるため、酵素が誤って酸素を捕まえる余地がありません。光呼吸はほぼ消えます。

| 結果 | 何が変わるのか |
|---|---|
| 高温で有利 | 25℃を超えるとむしろ光合成が速くなります。夏が最盛期です |
| 水を節約します | 二酸化炭素を濃縮するため気孔をあまり開かずに済みます。蒸発散量250mmの根拠です |
| 窒素を節約します | 酵素を少なく使えばよいため葉に必要な窒素が少なくなります。痩せ地適応の根拠です |
| 日陰では不利 | 濃縮装置を動かすのにエネルギーがかかります。光が足りないとその分の費用だけがかさみ、損になります |

> **アマランサスの強みと弱みは、すべて同じ一つの仕組みから生まれています。暑さと乾燥に強い理由と、日陰で弱る理由は同じです。**

### 2-3. 形態

| 器官 | 特徴 |
|---|---|
| 葉 | 互生します。広い卵形で長さ5-15cmです。緑色、赤色、二色が混じった系統があります |
| 茎 | 直立する系統と匍匐する系統があります。直立するものは2mまで育ち、太さが3cmを超えることもあります |
| 根 | まっすぐな主根が中心です。播種70日で深さ2.4m、幅1.8mまで伸びます |
| 花 | ごく小さな花が穂状に密集して咲きます。一株に雌花と雄花がともに付くのが普通で、花粉は風で運ばれます |
| 種子 | 直径1-1.5mmの凸レンズ形です。千粒重0.6-0.9gで、白色、黄色、黒色の系統があります |

&nbsp;&nbsp;&nbsp;根が2mを超えて伸びるという点には大きな実用的意味があります。表土が完全に乾いても、深い場所の水を引き上げて使います。日照りの年に、トウモロコシの葉が巻き込んでしまう横で、アマランサスが青々と立っている光景が実際に見られます。ただし、この深い根を張るには土が固すぎないことが条件で、下に硬い層があると能力は半分に落ちます。

&nbsp;&nbsp;&nbsp;種子の構造は穀物とはまったく異なります。イネやコムギは種子の中心をでんぷんの塊である胚乳が占め、胚芽は片隅に小さく付いているだけです。そのため殻と糠を取り除くとでんぷんだけが残り、タンパク質・脂肪・ビタミンは取り除かれた側について行ってしまいます。精米が玄米より栄養が少ない理由です。アマランサスはでんぷんが種子の中心にまとまっており、胚芽がその周りを輪のように取り囲んでいます。取り除くべき糠がなく、取り除く理由もありません。

| 比較項目 | イネ・コムギ | アマランサス |
|---|---|---|
| 精白 | 必要です | 不要です |
| 精白損失 | 20-30% | ありません |
| 精白設備 | 精米機や臼が必要です | 不要です |
| 栄養の分布 | 表層に偏っており精白すると失われます | 種子全体に均等です |
| でんぷん粒の大きさ | 10-30μm | 1-3μmと非常に小さい |

&nbsp;&nbsp;&nbsp;最後の行の小さなでんぷん粒が意味することは二つです。一つは消化がよいということ、もう一つは熱したフライパンに入れると粒の中の水分が一瞬で水蒸気になり、ポップコーンのようにはじけるということです。この性質が調理で決定的に生かされ、16節で扱います。

### 2-4. 生育段階

| 段階 | 時期 | 主な生理 | 重要な養分 |
|---|---|---|---|
| 発芽・幼苗期 | 播種から3週間 | 芽がごく小さく出て生長速度が遅いです。雑草に負けやすい時期です | リン酸、少量の窒素 |
| 栄養生長期 | 3週間から8週間 | 茎と葉が急速に増えます。葉の収穫が始まります | 窒素 |
| 開花期 | 8週間から12週間 | 穂が立ち、花粉が風で運ばれます | リン酸、カリウム |
| 登熟期 | 12週間から16週間 | 種子が実ります。熟したものから落ち始めます | カリウム |

&nbsp;&nbsp;&nbsp;この表で最も危険な段階は最初の欄です。アマランサスは種子が小さい分、最初に出る芽も小さいです。子葉が糸のように細く、3週間たっても指の一節を超えないことが多いです。同じ期間に雑草ははるかに速く育ちます。アマランサス栽培の成否は、この3週間をどう乗り切るかで大きく分かれ、この問題は8節で扱います。

&nbsp;&nbsp;&nbsp;登熟期の性質もあらかじめ知っておく必要があります。アマランサスの穂は上から下へ、あるいは下から上へ均一に熟すわけではありません。一つの穂の中でも熟す時期にばらつきがあり、先に熟した種子は待ってくれずに落ちてしまいます。この性質を脱粒といい、野生植物が種子を広げる正常な方式です。栽培種でもこの性質は完全には消えていません。12節の収穫のこつは、すべてこの事実から来ています。

### 2-5. 100gあたりの栄養

| 栄養素 | 含有量 | 備考 |
|---|:---:|---|
| 熱量 | 383kcal | 韓国国家標準食品成分表の乾燥種実基準です。穀物と同水準です |
| タンパク質 | 17.09g | 米の2倍を超えます |
| リジン | 豊富 | 穀物の制限アミノ酸を補います |
| 炭水化物 | 60-65g | でんぷん粒が非常に小さいです |
| 脂質 | 6-7g | 穀物にしては多めで、不飽和脂肪が主です |
| 食物繊維 | 6-7g | 多めです |
| 糖類 | 1.65g | 甘みはほとんどありません |
| カルシウム | 150-160mg | 穀物の中でも屈指の多さです |
| 鉄 | 7-8mg | 穀物の中では多めです |
| マグネシウム | 240-250mg | 非常に多いです |
| 総フェノール化合物 | 994-1,732mg/kg | 抗酸化作用があります |

&nbsp;&nbsp;&nbsp;評価表の微量栄養素Aはこの表から出ています。1日2,100kcalに相当する548gを食べた場合、推奨量の10%を超える栄養素が14種です。特にカルシウム、マグネシウム、鉄が目立ちます。牛乳やカタクチイワシが手に入らない食事ではカルシウムの供給源が急激に減りますが、アマランサスの種実は穀物でありながらカルシウムをかなりの量含んでいます。

&nbsp;&nbsp;&nbsp;ただし、ここに一つ注意書きが付きます。アマランサスにはシュウ酸とフィチン酸も含まれているため、カルシウムと鉄の一部は吸収されずそのまま排出されます。表の数字どおりに体に取り込まれるわけではないということです。この損失を減らす方法があり、14節と16節で扱います。

&nbsp;&nbsp;&nbsp;葉の栄養は種実とは性格が異なります。葉100gの熱量は20kcal台と低く、その代わりベータカロテン、ビタミンC、鉄、カルシウムが豊富です。ホウレンソウに近い位置づけと考えればよいです。一株から穀物と葉野菜がともに得られるという話の実際の中身がこれです。

## 3. 栽培環境

### 3-1. 温度

| 区分 | 限界値 | 最適値 | 備考 |
|---|:---:|:---:|---|
| 発芽温度 | 15℃以上 | 20-25℃ | 15℃未満ではほとんど発芽しません |
| 生育温度 | 15-35℃ | 20-32℃ | 評価表の温度適応幅Bはこの12℃の幅から出ています |
| 光合成最適 | 25℃以上 | - | C4作物なので暑いほど効率が上がります |
| 高温限界 | 35℃以上 | - | 水さえあれば耐えます。葉菜類の中でも最も強い部類です |
| 低温限界 | 10℃ | - | 生長が止まります |
| 致死温度 | 0℃ | - | 霜が一度降りると枯死します |

&nbsp;&nbsp;&nbsp;アマランサスの播種時期を決める基準は気温ではなく地温です。土が15℃を超えて初めて発芽し、20℃を超えて初めて生育が揃います。焦って早くまくと、小さな種子は土の中でそのまま腐ってしまいます。韓国中部でこの条件が整うのは4月末から5月初めです。

### 3-2. 光

| 区分 | 基準 | 備考 |
|---|---|---|
| 必要日照 | 1日6-8時間 | これを下回ると生育が明らかに悪くなります |
| 最小日照 | 1日6時間 | 6時間未満だと徒長し穂が貧弱になります |
| 40%遮光時 | 相対収量45% | C4作物共通の値であり、評価表のE等級の根拠です |

&nbsp;&nbsp;&nbsp;遮光に弱いという点が畑の配置を決めます。アマランサスは塀の下や木陰、建物の間の余った土地に植える作物ではありません。一日中日が当たる場所を割り当てる必要があり、逆にアマランサス自身が2mまで育つため、北側に配置して他の作物に日陰を作らないようにしなければなりません。

### 3-3. 水と土壌

| 項目 | 基準 | 備考 |
|---|---|---|
| 総蒸発散量 | 作期あたり約250mm | 評価表の水消費量Sの根拠です |
| 初期水分 | 播種から本葉2-3枚までは乾かさないこと | この時期さえ越えれば乾燥によく耐えます |
| 過湿 | 根が傷みます | 乾燥より湿害の方が危険です |
| 土性 | 排水のよい砂壌土から壌土 | 水がたまらないことが第一条件です |
| 土壌深度 | 30cm以上、深いほどよいです | 主根が2mを超えて伸びます |
| pH | 5.0-7.0 | 4.3から7.5まで耐えます。酸性への適応力が高い方です |
| 畝の高さ | 20cm以上 | 排水が目的です |

&nbsp;&nbsp;&nbsp;乾燥に強い作物が過湿に弱いというのはよくある組み合わせです。深く太い主根は乾いた土地で水を探すには有利ですが、水に浸かると呼吸ができません。畝を20cm以上高くし、畝間へ水を逃がすようにという基準はこのためです。韓国の梅雨（チャンマ、6月下旬~7月）の時期に何日も水がたまる場所は、アマランサスには向きません。

## 4. 品種

### 4-1. 種子用と葉用

&nbsp;&nbsp;&nbsp;アマランサスには複数の種があり、種によって用途が分かれます。大きく見ると、種子を得るために育てる種実用の系統と、葉を得るために育てる野菜用の系統に分かれます。

| 種 | 特徴 | 主な用途 | 災害時の活用 |
|---|---|---|---|
| Amaranthus cruentus | 種実用の代表です。収量が多く適応幅が広いです | 種実と葉 | 最も無難な選択です |
| Amaranthus hypochondriacus | 種実用で粒が大きめです | 種実と葉 | 種子を主目的にするとき |
| Amaranthus caudatus | 穂が長く垂れ下がります。アンデス系統です | 種実と観賞 | 涼しい高地に比較的よく合います |
| Amaranthus tricolor | 野菜用です。葉が柔らかく色が多様です | 葉野菜 | 葉を主目的にするとき |

&nbsp;&nbsp;&nbsp;韓国国内で育成された品種はなく、ほとんどが海外からの導入種です。評価表の韓国国内での栽培普及度B、つまり3-4道でしか栽培されていないという根拠はここにあります。物流が途絶えた状況で新たに種子を入手するのは難しいため、一度確保したら自家採種で続けていくことが唯一の道です。幸い自家採種Sが示すとおり、その作業自体は簡単です。

### 4-2. 主要品種

| 品種 | 収量 | 特徴 |
|---|:---:|---|
| RRC 1027 | 1,000㎡あたり465kg | 韓国国内の試験栽培で最も高い収量を出した系統です |
| goldengiant | 1株あたり400g以上 | 粒が大きく穂も大きいです。種実生産に向いています |
| Kerala Red | データなし | 千粒重0.42gと特に軽く、抗酸化成分が多いです |
| Chinesemulticolor | データなし | 葉に模様があり野菜用に使います |

&nbsp;&nbsp;&nbsp;評価表の面積当たり熱量Dが1,000㎡あたり200kgを基準に計算されている点と、韓国国内の試験で125kgから465kgまで開きがあった点を並べて見る必要があります。品種と栽培条件によって3-4倍の差が出るということであり、収量安定性Dの実質的な中身でもあります。種子を選べる立場にあるなら、収量が実証された系統を選ぶだけで結果が大きく変わります。

### 4-3. 状況別の選び方

| 状況 | 適した系統 | 理由 |
|---|---|---|
| 穀物の自給を補いたい場合 | Amaranthus cruentus、Amaranthus hypochondriacus | 収量が多く粒も大きいため、脱穀と選別がまだ楽です |
| 夏の葉野菜が目的の場合 | Amaranthus tricolor | 葉が柔らかく、繰り返しの収穫によく耐えます |
| 種子と葉を両方使いたい場合 | Amaranthus cruentus | 葉の品質も悪くなく兼用に向いています |
| 涼しい山間地域 | Amaranthus caudatus | アンデス高地系統のため比較的涼しい場所に合います |
| 粒が大きい方がよい場合 | goldengiant系列 | 選別作業の負担が減ります |

> **粒が大きい系統を選ぶのは収量のためだけではありません。アマランサスで最も大変な作業は育てることではなく、収穫後に脱穀し選別することであり、粒が大きいほどその作業が楽になります。**
