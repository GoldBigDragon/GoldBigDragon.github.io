## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;燕麦的耐储性为SS。在FAO食品损失指数的贮藏阶段观测中，燕麦损失率的中位数仅为1.30%，带壳晒干的籽粒在常温下可存放3年以上。不过，这一等级附有一个重要的前提：它只适用于带壳状态。燕麦的脂肪含量为3.8%到6.9%，在谷物中属于最高之列，所以碾磨后胚芽外露，酸败就会加快。碾磨后的燕麦米最多只能存放3-6个月。

### 15-1. 贮藏的四大敌害

| 敌害 | 条件 | 后果 | 应对要点 |
|---|---|---|---|
| 霉菌 | 水分15%以上 | 变质、产生毒素、整批报废 | 干燥 |
| 虫害 | 温度20度以上、水分12%以上 | 蛀食籽粒 | 密封与低温、防治 |
| 老鼠 | 能够接近的容器 | 啃食并排泄，造成污染 | 物理隔绝 |
| 酸败 | 氧气、光、热 | 产生哈喇味，出现苦味 | 带壳保存、遮光、低温 |

&nbsp;&nbsp;&nbsp;其他谷物只有三种敌害，燕麦却有四种。第四种酸败，是燕麦贮藏特有的难题。酸败不像霉菌或虫害那样肉眼可见，而是悄悄地逐渐发展，某一天打开一看，气味已经变了。防止的办法只有隔绝氧气、光和热。

### 15-2. 贮藏条件

| 条件 | 目标 | 偏离时 |
|---|---|---|
| 水分 | 13-14%，种子12-13% | 超过15%就会长霉 |
| 温度 | 15℃以下，越低越好 | 温度高则酸败和虫害同时加快 |
| 湿度 | 周围空气65%以下 | 干燥的谷物会重新吸收水分 |
| 光 | 完全隔绝 | 光会直接促进脂肪氧化 |
| 氧气 | 尽量隔绝 | 酸败的直接原因 |
| 形态 | 皮燕麦带壳保存，裸燕麦尽快食用 | 碾磨后的状态，寿命缩短到一半以下 |
| 检查 | 每两个月一次，闻气味 | 酸败只能靠气味发现 |

> **燕麦带壳贮藏，吃多少碾磨多少。外壳是隔绝氧气的天然包装。**

### 15-3. 贮藏容器

| 容器 | 密封 | 遮光 | 期限 | 备注 |
|---|:---:|:---:|---|---|
| 金属罐 | 极好 | 完全 | 3年以上 | 最适合燕麦。同时隔绝光和氧气 |
| 陶罐（onggi，韩国传统陶器） | 好 | 完全 | 2-3年 | 温度稳定，老鼠咬不穿 |
| 玻璃瓶 | 极好 | 无 | 2-3年 | 务必放在暗处，或用布包裹 |
| 厚塑料袋 | 一般 | 部分 | 1-2年 | 老鼠能咬穿，氧气也会缓慢透入 |
| 稻草袋（gamani）·麻袋 | 差 | 部分 | 6个月 | 对酸败和虫害毫无防御力 |
| 地下贮藏窖 | 好 | 完全 | 2-3年 | 温度低且稳定，酸败缓慢 |

&nbsp;&nbsp;&nbsp;燕麦尤其适合用金属罐或陶罐这类能完全遮光的容器。玻璃瓶密封性好，但会透光、促进脂肪氧化，所以务必放在暗处，或用布、纸包起来。玻璃瓶可以用眼睛查看内部状态的优点，用在燕麦上反而成了缺点。

&nbsp;&nbsp;&nbsp;地下贮藏窖很适合燕麦。因为地下温度全年稳定且较低，酸败的速度会变慢。选一处不渗水的高地，挖1m以上，在底部和四壁厚厚地围上一层干稻草，再连同密封容器一起埋入，盖上土。容器一旦打开就很难再次密封，所以要按一次取出的分量分开，做成多个。

### 15-4. 贮藏期间的虫害防治 - 不用药剂

&nbsp;&nbsp;&nbsp;谷物贮藏中真正的主要敌人是虫害。谷蛾、印度谷螟、米象、赤拟谷盗之类的害虫，在收获后不久的谷物中就已经以虫卵的形式混入，到了贮藏库里再孵化。一只虫两个月就能繁殖到几十只，半年后一个罐子就会被粉末和虫粪填满。在没有杀虫剂的条件下，可以采用的方法如下。

| 方法 | 原理 | 用法 | 效果 |
|---|---|---|---|
| 完全密封 | 隔绝氧气，使虫窒息 | 把容器装满后封口 | 最可靠。同时还能防止酸败 |
| 拌入草木灰 | 灰的微细颗粒刮伤虫的外骨骼，使其脱水 | 均匀拌入谷物体积的2-5% | 久经验证的方法。食用前淘洗干净 |
| 硅藻土 | 微小的硅质外壳损伤外骨骼 | 每1kg谷物拌入1-3g | 效果比草木灰好。只有在干燥状态下才起作用 |
| 细沙·黄土 | 颗粒填满缝隙，阻止虫移动 | 一层一层分层放入 | 体积会增加 |
| 干辣椒·花椒 | 辛辣成分起驱避作用 | 在容器里放几个 | 辅助手段 |
| 艾蒿·菖蒲·槐树叶 | 挥发油成分抑制产卵 | 晒干后一层一层夹在谷物之间 | 传统上广泛使用 |
| 炒盐 | 吸附潮气，消除虫的生存条件 | 用布包好放入 | 兼作干燥剂 |
| 木炭 | 吸收潮气和异味 | 把烧制后晒干的木炭用布包好放入 | 也能部分去除酸败的气味 |
| 低温处理 | 零下温度会使虫卵和幼虫死亡 | 隆冬时放到室外几天后再收回 | 对燕麦还能起到抑制酸败的作用 |
| 高温处理 | 60度时虫卵和幼虫死亡 | 在阳光下摊薄晾晒几个小时 | 燕麦脂肪多，所以温度要定得低一些 |

&nbsp;&nbsp;&nbsp;最重要的是第一种。完全密封是没有药剂也能用的最强手段，而且对燕麦还有一个特别的好处：隔绝氧气后，不仅虫会死，酸败也会一同停止。虫害和酸败一次防住，所以对燕麦来说，密封的价值比其他谷物更大。容器装得越满、空隙越少，效果越好。只装一半的罐子，远不如装满的罐子耐久。把谷物分装进多个小容器并各自装满，比只用一个大罐装一半要好。

&nbsp;&nbsp;&nbsp;草木灰和硅藻土的原理相同。二者都不是靠化学方式，而是靠物理方式杀虫。细小而锋利的颗粒刮掉覆盖虫体的蜡质层后，虫子就会失水干死。这种方式有两个优点：虫子不会产生抗药性，而且对人体无害。食用前用水冲洗即可。缺点是遇到潮气就不起作用。谷物一旦受潮，草木灰和硅藻土都会失效，所以归根结底还是要先干燥。

&nbsp;&nbsp;&nbsp;使用草木灰时，要先过筛，只挑选像面粉一样细的部分。拌入谷物体积的2-5%，也就是每斗（约18升）燕麦拌入一升（约1.8升）左右的草木灰，用手翻拌，使每粒表面都薄薄地裹上一层。燕麦如果还留有芒，灰就沾不均匀，所以最好先把芒充分筛除再进行。表面看上去会变成灰蒙蒙的灰色，但用水淘洗三四遍就干净了。

### 15-5. 延缓酸败的方法

| 方法 | 原理 | 效果 |
|---|---|---|
| 带壳保存 | 外壳隔绝氧气 | 效果最大。差别就在于3年与6个月 |
| 炒制 | 用热杀灭脂肪分解酶 | 碾磨后的燕麦也能多存放几个月 |
| 蒸或焯 | 杀灭酶 | 商业燕麦片采用的方法 |
| 遮光 | 防止光引起的氧化 | 使用金属罐或陶罐 |
| 低温 | 减慢化学反应速度 | 温度降低10度，反应速度减半 |
| 少量碾磨 | 缩短暴露时间 | 只碾磨一个月吃的量 |

&nbsp;&nbsp;&nbsp;炒制的方法在灾害情境下尤其有用。燕麦中的脂肪变质，不只是因为氧气，也是因为燕麦自身所含的一种叫脂肪酶的酶。这种酶会分解脂肪，产生哈喇味。用小火炒到出现香味，酶就会被灭活，酸败会大大延缓。商业生产的燕麦片是用蒸汽蒸制后出售的，原理也是一样的。炒过的燕麦还可以直接用水冲调食用，连烹饪燃料都能节省。

### 15-6. 定期检查

| 时间 | 检查事项 | 发现异常时的措施 |
|---|---|---|
| 每两个月 | 气味。有没有哈喇味 | 已经酸败。先食用掉 |
| 每两个月 | 容器外表的结露、霉味 | 立即打开，摊开晾干 |
| 每两个月 | 表面的粉末或蛛丝般的丝 | 是印度谷螟。全部拿到太阳下晒干并筛除 |
| 每两个月 | 用手攥时的温热感 | 发热是水分过多的信号 |
| 春秋季 | 整罐打开，检查气味和颜色 | 排好顺序，先吃酸败快的 |

&nbsp;&nbsp;&nbsp;燕麦贮藏中，管理食用顺序很重要。事先排定顺序：先吃碾磨过的、磨成粉的、裸燕麦这类酸败快的形态，最后才吃带壳贮藏的皮燕麦，这样可以大大减少损失。如果总是先吃好吃的，结果就会把本该久放的先吃掉，所以最好事先做好标记。

## 16. 烹饪与加工

### 16-1. 碾磨 - 不用工具去壳

&nbsp;&nbsp;&nbsp;如果种的是裸燕麦，可以跳过这一节，因为脱粒的同时外壳就脱落了。如果是皮燕麦，就需要碾磨，而且燕麦的壳比其他谷物更牢固地附着在籽粒上，格外费工。

| 方法 | 工具 | 步骤 | 效率 |
|---|---|---|---|
| 臼舂 | 石臼和杵 | 放入干燥的籽粒舂捣。每5分钟取出簸扬一次 | 最常见，但很费力 |
| 加水润湿后舂 | 石臼 | 舂前洒少许水，放置30分钟 | 外壳容易脱落 |
| 炒后舂 | 锅和石臼 | 用小火炒，使外壳变脆后再舂 | 最适合燕麦 |
| 石磨脱壳 | 石磨 | 把上扇抬起一点，缓慢转动 | 关键在于调节间隙 |
| 脚踏臼 | 踏碓 | 用脚踩踏，使杵抬起再落下 | 省力得多 |

&nbsp;&nbsp;&nbsp;燕麦碾磨最有效的窍门是炒后再舂。用小火炒几分钟，外壳的水分蒸发变脆，籽粒与外壳之间裂开缝隙，脱落起来容易得多。而且炒的过程中脂肪酶被灭活，酸败也随之延缓。可以说一次就解决了碾磨和贮藏两个问题。不过炒过的燕麦不能再当种子用，所以种用的要另外留出来。

&nbsp;&nbsp;&nbsp;碾磨的窍门是不要想一次完成。用力大、时间长，外壳还没脱落，籽粒就先碎了。舂5分钟取出，簸扬把糠吹走，再放回去舂，如此反复四五次。中途要把糠清除掉，力量才能真正传到剩下的籽粒上。

&nbsp;&nbsp;&nbsp;糠不要扔。它富含膳食纤维和矿物质，是很好的牲畜饲料，没有牲畜的话就放进堆肥。

### 16-2. 压片 - 压成扁平状

&nbsp;&nbsp;&nbsp;吃燕麦最好的形态不是整粒，而是压扁的。这叫压片燕麦，也叫燕麦片。压扁后表面积增大，水分渗入更快，烹饪时间大幅缩短，也更易消化。在燃料珍贵的灾害情境下，这种差别不容小觑。

| 方法 | 工具 | 步骤 |
|---|---|---|
| 用擀面杖擀 | 擀面杖、瓶子、圆木 | 把碾磨后的燕麦用布包好，用擀面杖压着擀 |
| 两块石头之间压 | 两块平整的石头 | 摊成一层，从上面压着搓 |
| 用锤子敲 | 木锤 | 用布包好，轻轻敲打 |
| 把石磨间隙调大转动 | 石磨 | 把上扇抬得高一些再转动，压扁后出来 |
| 蒸后压 | 甑（siru，陶制蒸器）和擀面杖 | 用蒸汽蒸10分钟后再压，会好压得多 |

&nbsp;&nbsp;&nbsp;蒸后压的方法最好。用蒸汽蒸10分钟左右，籽粒变软，不费多大力气就能压扁，而且蒸的过程中脂肪酶被灭活，酸败得以延缓。压完之后要重新晒干。这和商业生产燕麦片的方式原理相同。

&nbsp;&nbsp;&nbsp;压片燕麦把烹饪时间缩短到整粒的三分之一以下。整粒燕麦要煮40分钟到一小时，而压片燕麦5-10分钟就熟。如果压得很薄，只要倒入沸水、盖上盖子放着就能吃。考虑到燃料消耗，收获后提前做成压片燕麦是合理的。不过压片燕麦比整粒坏得快得多，所以只做一两个月吃的量。

### 16-3. 磨粉 - 磨成粉

| 方法 | 工具 | 特点 |
|---|---|---|
| 石磨 | 上下两扇石头 | 磨出的粉最细 |
| 石臼 | 石臼和杵 | 磨出的粉较粗。过筛后再舂 |
| 石板研磨 | 宽扁的石头和滚压用的石头 | 适合少量 |
| 炒后捣碎 | 任意工具 | 省力得多，酸败也会延缓 |

&nbsp;&nbsp;&nbsp;燕麦脂肪多，磨碎后粉有结块的特性。石磨有时也会被粘住堵塞。先炒干水分再磨，就好磨得多，粉也变得松散。

&nbsp;&nbsp;&nbsp;燕麦粉不含麸质，和成的面团没有黏性。很难做成面包或面条，一般用来煮粥、做煎饼（buchim），或与其他面粉混合后和面使用。不过由于含有β-葡聚糖，加水调开后会变得黏稠，所以最适合煮粥。

&nbsp;&nbsp;&nbsp;粉比整粒坏得快得多，燕麦尤其如此。只磨一个月吃的量，其余保持整粒。

### 16-4. 节省燃料的烹饪

| 方法 | 燃料 | 步骤 | 备注 |
|---|:---:|---|---|
| 煮整粒 | 多 | 浸泡一夜后煮40-60分钟 | 最耗燃料 |
| 压片燕麦粥 | 少 | 加水煮5-10分钟 | 最实用的形态 |
| 燕麦粉粥 | 很少 | 把粉在水中调开，煮5分钟 | 最省燃料 |
| 泡软直接吃 | 无 | 把压片燕麦用水或汤泡几个小时 | 不用火也能吃 |
| 余热烹饪 | 很少 | 煮10分钟后关火，用稻草或毯子包住，放置40分钟 | 燃料减少一半以上 |
| 炒粉 | 几乎没有 | 把事先炒好的粉用水冲调 | 不需要烹饪燃料 |
| 混合煮饭 | 中等 | 在米或大麦中掺入2-3成 | 抵触感小 |

&nbsp;&nbsp;&nbsp;在谷物中，燕麦是少数不用火也能吃的。把压得很薄的压片燕麦用水泡几个小时，就可以直接吃。味道差一些，但在燃料彻底断绝、无法生火、或者在途中移动的情况下，这是很大的优势。其他谷物必须煮熟，燕麦却有选择。

&nbsp;&nbsp;&nbsp;保温烹饪的效果也很大。把整粒燕麦只煮10分钟，从火上取下，连锅一起放进装满稻草或稻壳的箱子，或者用厚被子整个包起来，内部温度会在一个多小时里保持在80度以上，烹饪得以继续。原本要煮40分钟的东西，缩短为10分钟。

### 16-5. 兼顾贮藏的加工

| 加工 | 步骤 | 保存 | 备注 |
|---|---|---|---|
| 炒粉 | 炒后磨碎 | 密封6个月 | 用水冲调即可食用 |
| 压片燕麦 | 蒸后压扁并晒干 | 密封2-3个月 | 大幅减少烹饪燃料 |
| 麦芽 | 使其发芽，晒干后磨碎 | 密封1年 | 用于制作糖稀（jocheong，谷物熬制的糖浆）和酒 |
| 燕麦糖稀 | 用麦芽糖化后熬浓 | 阴凉处1年 | 获得甜味和浓缩的热量 |
| 燕麦酒 | 把蒸熟的燕麦拌入酒曲，发酵 | 密封保存 | 兼具保存热量和净化水的作用 |
| 发酵粥 | 把粉用水调开，放置2-3天 | 几天 | 营养吸收更好 |

&nbsp;&nbsp;&nbsp;麦芽也可以用燕麦制作。把籽粒浸水，使其稍微发芽，再晒干磨碎即可。发芽时产生的酶会把淀粉转化为糖，所以有了这种麦芽，用任何谷物都能制作糖稀和酒。这是在没有砂糖的情况下，自给甜味和浓缩热量的关键。

## 17. 全年作业日程

| 月份（以韩国气候为准） | 作业 | 要点 |
|---|---|---|
| 1月 | 检查贮藏的谷物、确认种子、保养工具 | 检查有无哈喇味和霉味 |
| 2月 | 规划田地、翻堆堆肥、发芽试验、准备春播 | 提前准备好，以便土壤一解冻就能播种 |
| 3月 | 春燕麦播种（上旬-中旬）、秋播田镇压 | 哪怕早播一天，也会左右产量 |
| 4月 | 除草、清除野燕麦、管理分蘖 | 最初一个月的杂草管理很重要 |
| 5月 | 追肥（株高20cm）、抽穗、监控病害 | 错过追肥时机就没有效果 |
| 6月 | 春燕麦收获、晾干、脱粒 | 目标是在韩国的梅雨季（6月下旬至7月）之前完成 |
| 7月 | 整理贮藏、后茬播种（大豆·粟（谷子））、高寒地区夏播 | 收割后的空地不要闲置 |
| 8月 | 秋燕麦播种（中旬-下旬）、整地 | 使其在入冬前完成分蘖 |
