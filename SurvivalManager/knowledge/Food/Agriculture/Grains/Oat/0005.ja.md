## 12. 収穫と脱穀

### 12-1. 時期の判断

| 基準 | 内容 | 判定 |
|---|---|---|
| 春の栽培 | 韓国では6月上旬-中旬 | 韓国の梅雨（チャンマ、6月下旬～7月）が来る前に終えるのが目標です |
| 秋の栽培 | 韓国では11月上旬-中旬 | 霜が降りる前に収穫します |
| 種子用 | 出穂後45日以上 | 十分に完熟させてこそ発芽力が高まります |
| 茎の色 | 茎と葉が黄色く変わります | 成熟が近づいています |
| 粒の硬さ | 爪で押しても跡が残りません | 完熟です |
| 穂の姿勢 | 穂の枝が垂れ下がり、粒が下を向きます | 収穫期です |
| 脱粒（粒落ち） | 穂を揺らすと粒が落ちます | 適期を過ぎています。直ちに刈ります |

&nbsp;&nbsp;&nbsp;エンバク（オーツ麦）の収穫時期を判断するうえで最も重要な変数は、粒の状態ではなく天気です。エンバクは中空の茎に穂が垂れ下がってついているため、風雨で倒れやすく、倒れた穂は地面に触れて穂発芽します。雨の予報が出ていれば、多少早くても刈り取って取り込むのが正解です。少し未熟な粒は、屋内で乾く間にある程度充実しますが、倒れて芽が出た粒は元に戻りません。

> **エンバクは、熟すのを待っているうちに失う場合のほうが、少し早く刈って損をする場合よりはるかに多いです。**

### 12-2. 収穫のコツ

| 順序 | 内容 | 理由 |
|---|---|---|
| 1 | 晴れた日の午前、露が乾いてから始めます | 濡れた穂はカビの発生源になります |
| 2 | 株元近くを鎌で刈ります | わらも一緒に収集して、マルチングや飼料に使います |
| 3 | 刈るときに穂を揺らしません | エンバクは脱粒しやすい穀物です |
| 4 | 刈ったものを束ねます | 10株ほどが適当です |
| 5 | 畑でたがいに立てかけておきます | 雨に当たらないようにし、風通しを確保します |
| 6 | 数日後、納屋や軒下に移します | 露と雨を避けなければなりません |
| 7 | 赤く変色した穂は別に選り分けて廃棄します | 赤かび病は毒素を作ります |

&nbsp;&nbsp;&nbsp;刈ったエンバクを畑に立てて置く方法は、麦類で古くから使われてきた方法です。束をたがいに立てかけて円錐形にすると、雨水は外側を流れ落ち、内側は風が通って乾きます。ただし、韓国の6月はいつ梅雨の雨が降り出すか分からないので、長く置かず、数日のうちに屋内に移すのが安全です。

### 12-3. 穀物の乾燥 - 水分13-14%まで

&nbsp;&nbsp;&nbsp;穀物の貯蔵は、すべて水分で決まります。水分が15%を超えるとカビが生え、13%を下回るとカビも虫も活動をほぼ止めます。刈りたてのエンバクの水分は20-30%です。これを13-14%まで下げることが、収穫直後の唯一にして最も重要な課題です。

| 段階 | 方法 | 期間 | 到達水分 |
|---|---|---|---|
| 1. 予備乾燥 | 刈った束を畑に立てておきます | 2-4日 | 18-20% |
| 2. 掛け干し | 納屋や軒下につるすか積みます | 1-2週間 | 15-16% |
| 3. 脱穀 | 十分に乾いてから打ち落とします | 1日 | - |
| 4. 仕上げ乾燥 | むしろや布に広げて日なたで干します | 2-3日 | 13-14% |
| 5. 寝かせ | 日陰に1日置いて水分を均一にします | 1日 | 均一化 |

&nbsp;&nbsp;&nbsp;エンバクは脂肪含量が高いため、乾燥温度にはとくに注意が必要です。50℃を超えて乾かすと脂肪が酸化し始め、酸化臭が出て、種子として使うこともできなくなります。日なたで干すのが最も安全で、火力を使う必要がある場合は、手を当てて温かいと感じる程度までにとどめます。熱いと感じるなら、すでに高すぎます。

&nbsp;&nbsp;&nbsp;日なたで干すときの原則は、どの穀物でも同じです。第一に、地面に直接広げないこと。土の湿気が下側を再びぬらします。第二に、3-5cmを超えて積まず、1日に3、4回ひっくり返すこと。第三に、日が傾いたら取り込むか、覆いをかけること。夜露に当たると、昼間に抜けた水分が元に戻ってしまいます。第四に、急いで乾かさないこと。表面だけが乾いて内部に水分が閉じ込められると、後でカビが生えます。

&nbsp;&nbsp;&nbsp;水分計がなくても水分を見積もる方法があります。

| 方法 | 手順 | 判定 |
|---|---|---|
| かむ | 粒を奥歯でかみます | パチッと割れて粉が出れば13-14%です。つぶれるなら、まだ湿っています |
| 塩試験 | 乾いた塩ひとさじと穀物ひとつかみを瓶に入れて振り、15分置きます | 塩が瓶の壁にくっつけば、水分が高いです |
| 手触り | ひとつかみ握ってから開きます | すべるようにばらければ乾いており、固まれば湿っています |
| 音 | 両手に取って揺らします | 乾いた粒同士がぶつかる澄んだ音がします |
| 瓶試験 | ガラス瓶に半分ほど入れて密封し、1日置きます | 瓶の内側に曇りが生じたら、さらに乾かす必要があります |

&nbsp;&nbsp;&nbsp;瓶試験は、貯蔵に入る前の最終確認として最も信頼できます。密閉した瓶の中で穀物と空気が水分平衡に達しますが、水分が14%を超えると瓶内の湿度が70%を超え、気温が下がる明け方に曇りが生じます。

### 12-4. 脱穀 - 道具なしでする方法

&nbsp;&nbsp;&nbsp;エンバクは脱穀しやすい穀物です。穂の枝の先に粒がゆるくついているため、乾けば軽い衝撃でも落ちます。むしろ、あまりに簡単に落ちて、収穫や運搬の途中で損失が出るほうが問題です。

| 方法 | 手順 | 規模 | 備考 |
|---|---|---|---|
| 手でこく | 穂の柄を持ち、手袋をした手でしごき下ろします | 少量 | 損失が最も少なく、種子用に使います |
| たたく | むしろの上に穂を広げ、殻竿や棒でたたきます | 多い | 最も一般的です |
| 袋の中で打つ | 丈夫な袋に入れ、袋ごと地面に打ち付けます | 中程度 | 粒が飛び散りません |
| 踏む | むしろに広げ、足でこするように踏みます | 多い | 力が少なくてすみます |
| 桶の中でもむ | 大きな桶に入れ、棒でかき混ぜながらもみます | 中程度 | 手が痛みにくいです |

&nbsp;&nbsp;&nbsp;殻竿は自分で作れます。長い柄の先に短い棒を、革ひもや丈夫な縄でゆるく結びつければできあがりです。柄を振り回すと、先の棒が回って穀物を打ちます。腕力でたたくより3、4倍効率が高く、一日中続けても疲れにくいです。麦類の脱穀にとくに向いた道具で、災害時に真っ先に作っておくべき農具の一つです。

&nbsp;&nbsp;&nbsp;裸エンバク（脱穀と同時に殻が外れる品種）を植えていれば、この段階で大きな利点が現れます。脱穀と同時に殻が落ちるので、箕でふるうだけですぐに食べられる状態になります。殻付きエンバクの場合は、脱穀の後に精白という工程がもう一段階残ります。

### 12-5. しいな飛ばし - 唐箕と箕

&nbsp;&nbsp;&nbsp;打ち落としたエンバクには、穂の枝、芒、葉の切れ端、ほこりが混じっています。エンバクの芒は長くて硬いため特に多く混入し、これをそのまま貯蔵すると、しいなに付着した水分や虫の卵が貯蔵庫全体をだめにします。

| 方法 | 手順 | 条件 |
|---|---|---|
| 風に流す | 風のある日に高い所からゆっくり注ぎ落とします | 秒速2-4mの安定した風 |
| 箕でふるう | 箕に入れて前に押したり引いたりしながら宙に浮かせます | 風がなくてもできます |
| あおぐ | 一人が注ぎ、もう一人がうちわや板であおいで風を起こします | 二人必要です |
| ふるい分け | 目の粗いふるいで芒と枝を、細かいふるいでほこりを取り除きます | エンバクは芒があるため、ふるい分けが特に有効です |
| もんで芒を取る | 手や足でもんで芒を折ってから飛ばします | 芒が長い場合は最初に行います |

&nbsp;&nbsp;&nbsp;エンバクの芒は、貯蔵で実際に問題になります。長くて硬いため、容器の中で穀物の間に空間を作り、その空間が虫の隠れ家になります。しかも芒自体が水分を含みます。箕でのふるいをもう一度行ってでも、芒をできるだけ取り除くほうが貯蔵寿命が延びます。足でもんで芒を折ってから飛ばすと、はるかにきれいになります。

&nbsp;&nbsp;&nbsp;箕は自作できます。竹やハギの枝を割って編むか、薄い合板を三方だけ立てて作っても機能します。箕でふるうコツは、上下に振るのではなく、前に押したり引いたりしながら穀物を宙に少しの間浮かせることです。浮いている間に、軽いものが遅れて前のほうに集まります。

## 13. 採種

### 13-1. 採種個体の選抜

| 基準 | 内容 | 理由 |
|---|---|---|
| 選抜時期 | 出穂期から畑を回って目印を付けます | 収穫後には見分けられません |
| 個体の条件 | 病徴がなく、倒れておらず、穂が大きいもの | 形質が受け継がれます |
| 収穫時点 | 出穂後45日以上、完全に熟してから | 未熟な種子は発芽率が低くなります |
| 除外対象 | 黒穂病や赤かび病が見られた株 | 種子伝染を防ぎます |
| 野生エンバク | 芒が長く色の濃い粒を取り除きます | 混ざると年々増えます |
| 形態 | 必ず殻付きのまま保管します | 精白すると発芽力と寿命が急激に低下します |
| 量 | 必要量の2倍 | 播種量が多いため、あらかじめ多めに確保します |

&nbsp;&nbsp;&nbsp;エンバクは自家受粉する作物なので、純系がよく維持されます。ほかの品種が近くにあっても混ざる確率は低く、採った種子は親と同じ性質を示します。自家採種の等級がSである理由です。災害に備える観点から、これは大きな財産です。一度確保した系統を何年も受け継いでいけます。

&nbsp;&nbsp;&nbsp;注意すべきは野生エンバクです。栽培エンバクとほとんど区別がつかず、採種の過程で混入すると、年々その割合が増えます。野生エンバクは熟すと自然に落ちるので収穫損失が大きくなり、発芽も不揃いで畑がそろわなくなります。生育期に穂の形で見分けて抜き取っておくのが最も確実で、種子を選ぶときは、芒が長くねじれた粒や、色が際立って濃い粒を取り除きます。

&nbsp;&nbsp;&nbsp;エンバクの種子は、必ず殻付きのまま保管しなければなりません。裸エンバクを育てている場合でも、種子用だけは殻の残っている個体を選ぶか、裸エンバクなら精白をしていない状態のまま置きます。脂肪の多い穀物なので、胚が露出すると酸化が早く進み、発芽力が急激に低下します。

### 13-2. 種子の保管

| 条件 | 基準 | 理由 |
|---|---|---|
| 水分 | 12-13% | 種子は水分が低いほど寿命が長くなります |
| 温度 | 10度以下が理想的です | 脂肪が多いため、温度が高いと酸敗が速く進みます |
| 容器 | ガラス瓶、金属缶、甕 | 湿気と虫を同時に防げます |
| 光 | 完全に遮断 | 光は脂肪の酸化を促進します |
| 形態 | 殻付きのまま | 精白すると寿命が急激に短くなります |
| 寿命 | 常温・密閉で2-3年 | 涼しければもっと長くもちます |

&nbsp;&nbsp;&nbsp;エンバクの種子は、ほかの穀物より寿命が短めです。脂肪含量のためです。2-3年がたつと発芽率が目に見えて下がるので、毎年新しく採種して系統を更新するのが安全です。何年も間をあけて古い種子を使う計画なら、最も涼しい場所に置く必要があります。

### 13-3. 発芽試験

&nbsp;&nbsp;&nbsp;古い種子を植える前には、発芽力を確認します。濡らした布に粒を20個包んで暖かい場所に置き、5日待ちます。20個のうち16個以上ならそのまま使い、12-15個なら播種量を1.5倍に増やし、10個未満なら新しい種子を手に入れる必要があります。エンバクは播種量の多い作物なので、発芽率の低下がそのまま収量の減少につながります。

## 14. 毒性と注意事項

### 14-1. 穀粒の毒性 - なし

&nbsp;&nbsp;&nbsp;エンバクは、通常の摂取量では毒性がありません。モロコシ（タカキビ）のように、葉に問題になるほどのシアン配糖体が含まれておらず、穀粒にも取り除くべき成分はありません。洗って火を通せばそのまま安全です。むしろ穀物の中では消化がやさしい部類なので、子どもや高齢者、回復期の患者に向いています。

### 14-2. 注意が必要な場合

| 項目 | 内容 | 対処 |
|---|---|---|
| カビが生えたもの | 赤かび病の毒素は加熱しても消えません | 全量廃棄します。家畜にも与えません |
| 酸敗したもの | 酸化臭がして苦味があります | 食べません。脂肪の酸化生成物は体に有害です |
| グルテン過敏 | エンバク自体にはグルテンがありませんが、コムギとの交差汚染が起こりうります | 重い過敏症の人は注意します |
| 過剰摂取 | 食物繊維が多く、消化の不調が起こることがあります | 少しずつ量を増やします |
| 加熱不足のもの | でんぷんが消化されません | 十分に浸水させてから火を通します |

> **カビの生えた穀物は、洗っても、ゆでても、炒っても安全になりません。捨てることが唯一の方法です。**

&nbsp;&nbsp;&nbsp;エンバクで実際により頻繁に出会う問題は、カビではなく酸敗です。脂肪含量の高い穀物なので、精白したり粉に挽いたりしておいたエンバクは、数か月で酸化臭がし始めます。この酸化臭は脂肪が酸化してできたにおいで、その酸化生成物は体によくありません。ただし、カビ毒と違って急性の危険はないため、ひどく飢えた状況であれば食べることはできます。判断基準が異なるという点を知っておけば十分です。

&nbsp;&nbsp;&nbsp;酸敗を防ぐ方法は第15節で詳しく扱います。要点は、殻付きのまま貯蔵し、食べる分だけ精白し、炒って酵素を失活させておくことです。

### 14-3. 家畜に与えるとき

| 項目 | 内容 |
|---|---|
| エンバクの穀粒 | ウマやウシによい飼料です。とくにウマの標準的な飼料です |
| エンバクのわら | 麦類のわらの中では柔らかく、粗飼料として使えます |
| 青刈りエンバク | 飼料作物として広く使われます。毒性はありません |
| 注意 | カビの生えたものは、家畜にとっても毒です |

&nbsp;&nbsp;&nbsp;エンバクにはモロコシのようなシアン配糖体の問題がないため、若い状態の青刈りエンバクをそのまま家畜に与えることができます。飼料作物として広く使われる理由です。災害時に家畜を維持しようとするなら、エンバクは穀物と粗飼料を一つの作物から得られる、数少ない選択肢になります。
