## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;エンバク（オーツ麦）の貯蔵性はSSです。FAO食品損失指数の貯蔵段階の観測では、エンバクの損失率の中央値は1.30%と低く、皮付きのまま乾燥させた種実は常温で3年以上もちます。ただし、この等級には重要な但し書きが付きます。皮付きのままの場合の話だ、ということです。エンバクは脂質の含有量が3.8から6.9%と穀物の中で最も高い部類に入るため、精白して胚芽が露出すると酸敗が早く進みます。精白したエンバクの粒（エンバク米）は3-6か月が限度です。

### 15-1. 貯蔵の四つの敵

| 敵 | 条件 | 結果 | 対策の軸 |
|---|---|---|---|
| カビ | 水分15%以上 | 変質、毒素の生成、全量廃棄 | 乾燥 |
| 虫 | 温度20度以上、水分12%以上 | 粒の中身を食い荒らします | 密閉と低温、防除 |
| ネズミ | 近づける容器 | 食べ荒らし、フンで汚染します | 物理的な遮断 |
| 酸敗 | 酸素、光、熱 | 酸敗臭がし、苦みが出ます | 皮付きのまま保管、遮光、低温 |

&nbsp;&nbsp;&nbsp;ほかの穀物では三つしかない敵が、エンバクでは四つあります。四つ目の酸敗が、エンバク貯蔵に特有の課題です。酸敗はカビや虫と違って目に見えず、徐々に進行して、ある日開けてみるとにおいが変わっています。防ぐ方法は、酸素と光と熱を遮断することだけです。

### 15-2. 貯蔵条件

| 条件 | 目標 | 外れたとき |
|---|---|---|
| 水分 | 13-14%、種子は12-13% | 15%を超えるとカビが生えます |
| 温度 | 15℃以下、低いほど良い | 高いと酸敗と虫の増殖がともに速まります |
| 湿度 | 周囲の空気で65%以下 | 乾いた穀物が再び水分を吸ってしまいます |
| 光 | 完全に遮断 | 光が脂質の酸化を直接促進します |
| 酸素 | できる限り遮断 | 酸敗の直接の原因です |
| 形態 | 皮付きエンバクは皮付きのまま、裸エンバクはできるだけ早く消費 | 精白した状態では寿命が半分以下になります |
| 点検 | 2か月に1回、においの確認 | 酸敗はにおいでしか分かりません |

> **エンバクは皮付きのまま貯蔵し、食べる分だけ精白します。皮は酸素を防ぐ天然の包装材です。**

### 15-3. 貯蔵容器

| 容器 | 密閉 | 遮光 | 期間 | 備考 |
|---|:---:|:---:|---|---|
| 金属缶 | 非常に良い | 完全 | 3年以上 | エンバクに最も適しています。光と酸素を同時に防げます |
| 壺（オンギ、韓国伝統の陶器） | 良い | 完全 | 2-3年 | 温度が一定で、ネズミがかじって穴を開けることもできません |
| ガラス瓶 | 非常に良い | なし | 2-3年 | 必ず暗い所に置くか、布で包みます |
| 厚手のビニール | 普通 | 部分的 | 1-2年 | ネズミに食い破られ、酸素もゆっくり通します |
| カマニ（わら袋）・麻袋 | 悪い | 部分的 | 6か月 | 酸敗や虫に対して無防備です |
| 地下の貯蔵穴 | 良い | 完全 | 2-3年 | 温度が低く一定で、酸敗が遅くなります |

&nbsp;&nbsp;&nbsp;エンバクには、金属缶や壺のように光が完全に遮断される容器が特に適しています。ガラス瓶は密閉性が高いものの、光を通して脂質の酸化を促進してしまうため、必ず暗い所に置くか、布や紙で包む必要があります。中の状態を目で確認できるというガラス瓶の長所が、エンバクではかえって短所になります。

&nbsp;&nbsp;&nbsp;地下の貯蔵穴はエンバクによく合います。温度が1年を通して一定で低いため、酸敗の進みが遅くなるからです。水がしみ込まない高い場所を選んで1m以上掘り、底と壁に乾いたわらを厚く巡らせたうえで、密閉容器ごと埋めて土をかぶせます。一度開けると再び密閉するのが難しいので、一度に取り出す分量ごとに分けて、いくつも作ります。

### 15-4. 貯蔵中の虫の防除 - 薬を使わずに

&nbsp;&nbsp;&nbsp;穀物貯蔵で実質的に最大の敵は虫です。バクガ、ノシメマダラメイガ、コクゾウムシ、コクヌストモドキなどが、収穫直後の穀物にすでに卵の状態で入り込んでいて、貯蔵庫の中で孵化します。1匹が2か月で数十匹に増え、半年もたてば缶一つが粉とフンで埋まってしまいます。殺虫剤がない条件で使える方法は次のとおりです。

| 方法 | 原理 | 適用 | 効果 |
|---|---|---|---|
| 完全密閉 | 酸素を断って虫を窒息させます | 容器いっぱいに詰めて封をします | 最も確実です。酸敗も同時に防ぎます |
| 草木灰を混ぜる | 灰の微細な粒子が虫の外骨格を傷つけ、脱水させます | 穀物の容積の2-5%を均等に混ぜます | 古くから実証されてきた方法です。食べる前に洗い流します |
| 珪藻土 | 微細なケイ酸の殻が外骨格を傷つけます | 穀物1kgに1-3gを混ぜます | 灰より効果が高いです。乾いた状態でしか働きません |
| 細かい砂・黄土 | 粒が隙間を埋めて虫の移動を妨げます | 層状に重ねて入れます | かさが増えます |
| 乾燥トウガラシ・サンショウ | 辛み成分が忌避剤として働きます | 容器の中に数個入れておきます | 補助的な手段です |
| ヨモギ・ショウブ・エンジュの葉 | 精油成分が産卵を抑えます | 乾燥させて穀物の間に層状に入れます | 伝統的に広く使われてきました |
| 炒った塩 | 湿気を吸着して、虫が生きられる条件をなくします | 布に包んで入れます | 乾燥剤も兼ねます |
| 炭 | 湿気とにおいを吸い取ります | 焼いて乾かした炭を布に包んで入れます | 酸敗臭もある程度抑えます |
| 低温処理 | 氷点下で卵と幼虫が死にます | 真冬に数日間屋外に出してから取り込みます | エンバクでは酸敗を抑える効果まであります |
| 高温処理 | 60度で卵と幼虫が死にます | 日なたに薄く広げて数時間置きます | エンバクは脂質が多いので、温度は低めに設定します |

&nbsp;&nbsp;&nbsp;最も重要なのは、最初の完全密閉です。完全密閉は薬がなくても使える最も強力な手段で、エンバクでは特別な利点がもう一つあります。酸素を遮断すると、虫が死ぬだけでなく酸敗も同時に止まります。虫と酸敗を一度に防げるので、ほかの穀物より密閉の価値が大きくなります。容器にいっぱいに詰めて空きを最小限にするほど効果が高まります。半分しか入れていない缶より、いっぱいに詰めた缶のほうがはるかに長くもちます。大きな缶一つに半分入れるより、小さな容器をいくつも使って、それぞれいっぱいに分け入れるほうが優れています。

&nbsp;&nbsp;&nbsp;草木灰と珪藻土の原理は同じです。どちらも化学的にではなく、物理的に殺します。微細で鋭い粒子が虫の体を覆うワックス層を削り取ると、虫は水分を失って干からびます。この方式には二つの利点があります。虫が抵抗性を獲得できないことと、人体に無害なことです。食べる前に水で洗えば済みます。欠点は、湿気があると働かないことです。穀物がしけると灰も珪藻土も効果がなくなるので、結局は乾燥が先決です。

&nbsp;&nbsp;&nbsp;灰を使うときは、ふるいにかけて小麦粉のように細かい部分だけを選んで使います。穀物の容積の2-5%、つまりエンバク一斗に灰一升ほどを混ぜ、手でかき混ぜてすべての粒の表面に薄くまぶします。エンバクは芒（のぎ）が残っていると灰が均等につかないので、芒を十分にふるい分けてから行うのがよいです。見た目は灰色にくすんで見えますが、水で三、四回すすげばきれいになります。

### 15-5. 酸敗を遅らせる方法

| 方法 | 原理 | 効果 |
|---|---|---|
| 皮付きのまま保管 | 皮が酸素を防ぎます | 最も効果が大きいです。3年と6か月の差があります |
| 炒っておく | 脂肪分解酵素を熱で失活させます | 精白したエンバクでも、さらに数か月もちます |
| 蒸す・ゆでる | 酵素を失活させます | 市販のオートミールが使っている方法です |
| 遮光 | 光による酸化を防ぎます | 金属缶や壺を使います |
| 低温 | 化学反応の速度を遅くします | 10度下げると、反応が半分の速さになります |
| 少量ずつ精白 | さらされる時間を短くします | 1か月で食べる分だけつきます |

&nbsp;&nbsp;&nbsp;炒っておく方法は、災害時に特に役立ちます。エンバクの脂質が傷むのは、酸素のせいだけでなく、エンバク自体に含まれるリパーゼという酵素のせいでもあります。この酵素が脂質を分解して、酸敗臭のもとをつくります。弱火で香ばしいにおいがするまで炒ると酵素が失活し、酸敗が大きく遅れます。市販のオートミールが蒸気で蒸されてから出荷されるのも、同じ原理です。炒ったエンバクはそのまま水に溶いて食べることもできるため、調理燃料まで節約できます。

### 15-6. 定期点検

| 時期 | 確認事項 | 異常時の対処 |
|---|---|---|
| 2か月ごと | におい。酸敗臭がしないか | 酸敗です。先に消費します |
| 2か月ごと | 容器の外側の結露、カビ臭 | すぐに開けて広げ、乾燥させます |
| 2か月ごと | 表面の粉やクモの巣のような糸 | ノシメマダラメイガです。全量を日に干し、ふるい分けます |
| 2か月ごと | 手で握ったときの温かさ | 発熱は水分過多のサインです |
| 春と秋 | 丸ごと開けて、においと色を確認 | 順番を決め、酸敗の早いものから食べます |

&nbsp;&nbsp;&nbsp;エンバクの貯蔵では、消費の順番を管理することが重要です。精白したもの、挽いたもの、裸エンバクのように酸敗が早い形態を先に食べ、皮付きのまま貯蔵した皮付きエンバクを最後に食べる順番を決めておくと、損失が大きく減ります。食べやすいものから食べていくと、肝心の長く置くべきものを先に消費してしまうことになるので、あらかじめ印を付けておくほうがよいです。

## 16. 調理と加工

### 16-1. 精白 - 道具なしで皮をむく

&nbsp;&nbsp;&nbsp;裸エンバクを栽培したのであれば、この節は飛ばしてかまいません。脱穀と同時に皮が外れるからです。皮付きエンバクなら精白が必要で、エンバクの皮はほかの穀物より粒にしっかり付いているため、特に手間がかかります。

| 方法 | 道具 | 手順 | 効率 |
|---|---|---|---|
| 臼つき | 臼と杵 | 乾いた粒を入れてつきます。5分ごとに取り出して箕（み）であおります | 最も一般的ですが、重労働です |
| 湿らせてつく | 臼 | つく前に水を少しふりかけて30分置きます | 皮がむけやすくなります |
| 炒ってからつく | 釜と臼 | 弱火で炒って皮をぱりっとさせてからつきます | エンバクに最も向いています |
| 石臼でむく | 石臼 | 上臼を浮かせて、ゆっくり回します | 隙間の調整がカギです |
| 足踏み臼 | 唐臼 | 足で踏んで杵を上げ下ろしします | 力がはるかに少なくて済みます |

&nbsp;&nbsp;&nbsp;エンバクの精白で最も効果的なコツは、炒ってからつくことです。弱火で数分炒ると皮の水分が飛んでぱりっとなり、粒と皮の間にすき間ができて、ずっと簡単にはがれます。しかも炒る過程でリパーゼが失活し、酸敗まで遅くなります。精白と貯蔵対策を一度に解決できるわけです。ただし、炒ったエンバクは種として使えないので、種子用は別に取っておく必要があります。

&nbsp;&nbsp;&nbsp;精白のコツは、一度に終わらせようとしないことです。強く長くつくと、皮がむける前に粒が割れてしまいます。5分つくと取り出し、箕であおって殻やぬかを飛ばし、また入れてつくという作業を、四、五回繰り返します。殻やぬかを途中で取り除いてやらないと、残った粒に力がきちんと伝わりません。

&nbsp;&nbsp;&nbsp;殻やぬかは捨てません。食物繊維とミネラルが多いので家畜の飼料に向いていて、飼料にしない場合は堆肥に入れます。

### 16-2. ロールドオーツ - 平らにつぶす

&nbsp;&nbsp;&nbsp;エンバクを食べる最もよい形は、丸粒ではなく平らにつぶしたものです。これを押しエンバク、つまりロールドオーツ、またはオートミールと呼びます。つぶすと表面積が広がって水が早くしみ込み、調理時間が大きく短縮され、消化もよくなります。燃料が貴重な災害時には、この違いは小さくありません。

| 方法 | 道具 | 手順 |
|---|---|---|
| めん棒で伸ばす | めん棒、瓶、丸い木 | 精白したエンバクを布に包み、めん棒で押しながら転がします |
| 石二つで挟んでつぶす | 平らな石二つ | 一層に広げ、上から押してこすり合わせます |
| 木づちでたたく | 木づち | 布に包んで軽くたたきます |
| 石臼を広げて回す | 石臼 | 上臼を大きく浮かせて回すと、つぶれて出てきます |
| 蒸してつぶす | 甑（シル、陶製の蒸し器）とめん棒 | 蒸気で10分蒸してからつぶすと、ずっとつぶれやすくなります |

&nbsp;&nbsp;&nbsp;蒸してつぶす方法が最もよい方法です。蒸気で10分ほど蒸すと粒がやわらかくなり、力をあまり使わなくても平らになるうえ、蒸す過程でリパーゼが失活して酸敗が遅くなります。つぶしたあとは再び乾燥させなければなりません。これは市販のオートミールを作る方式と同じ原理です。

&nbsp;&nbsp;&nbsp;ロールドオーツは、調理時間を丸粒の3分の1以下に短縮します。丸粒のエンバクは40分から1時間煮なければなりませんが、ロールドオーツは5-10分で火が通ります。ごく薄くつぶしておけば、熱湯を注いでふたをしておくだけでも食べられます。燃料の消費を考えれば、収穫後にあらかじめロールドオーツにしておくのが合理的です。ただし、ロールドオーツは丸粒よりはるかに早く傷むので、1、2か月で食べる分だけ作ります。

### 16-3. 製粉 - 粉にする

| 方法 | 道具 | 特徴 |
|---|---|---|
| 石臼 | 上下二枚の石 | 最も細かい粉になります |
| 臼 | 臼と杵 | 粗い粉になります。ふるいにかけ、残りをもう一度つきます |
| 石板ですりつぶす | 平たい石と、転がし用の丸い石 | 少量に向いています |
| 炒ってから挽く | どれでも | ずっと楽で、酸敗も遅くなります |

&nbsp;&nbsp;&nbsp;エンバクは脂質が多いため、挽くと粉がかたまりやすい性質があります。石臼がべたついて詰まることもあります。炒って水分を飛ばしてから挽くと、ずっとよく挽け、粉もさらさらになります。

&nbsp;&nbsp;&nbsp;エンバクの粉はグルテンがないため、生地に粘りが出ません。パンや麺にするのは難しく、粥や薄焼き（プチム）、ほかの粉と混ぜた生地に使います。その代わり、βグルカンのために水に溶くととろみが出る性質があり、粥には最もよく合います。

&nbsp;&nbsp;&nbsp;粉は丸粒よりはるかに早く傷みます。エンバクは特にそうです。1か月で食べる分だけ挽き、残りは丸粒のままにしておきます。

### 16-4. 燃料を節約する調理

| 方法 | 燃料 | 手順 | 備考 |
|---|:---:|---|---|
| 丸粒をゆでる | 多い | 一晩水に浸してから40-60分煮ます | 燃料が最もかかります |
| ロールドオーツの粥 | 少ない | 水を注いで5-10分煮ます | 最も実用的な形です |
| 粉粥 | 非常に少ない | 粉を水に溶いて5分煮ます | 燃料が最も少なくて済みます |
| 浸してそのまま | なし | ロールドオーツを水やスープに数時間浸します | 火を使わなくても食べられます |
| 余熱調理 | 非常に少ない | 10分煮たら火を止め、わらや毛布で包んで40分置きます | 燃料を半分以下に減らせます |
| 炒り粉 | ほぼなし | あらかじめ炒っておいた粉を水に溶きます | 調理用の燃料は不要です |
| 混ぜ炊き | 中程度 | 米や麦に2-3割混ぜます | 抵抗感が少ないです |

&nbsp;&nbsp;&nbsp;エンバクは、穀物の中で火を使わずに食べられる数少ない部類です。薄くつぶしたロールドオーツを水に数時間浸せば、そのまま食べられます。味は劣りますが、燃料がまったく途絶えた状況、火をおこせない状況、移動中の状況では、これは大きな利点です。ほかの穀物は必ず加熱しなければなりませんが、エンバクには選択肢があります。

&nbsp;&nbsp;&nbsp;保温調理も効果が大きいです。丸粒のエンバクを10分だけ煮て火からおろし、わらやもみ殻を詰めた箱、あるいは厚手の布団にそのまま包んでおくと、内部の温度が1時間以上80度より上に保たれ、調理が続きます。40分煮なければならないものが、10分に短縮されます。

### 16-5. 貯蔵を兼ねた加工

| 加工 | 手順 | 保存 | 備考 |
|---|---|---|---|
| 炒り粉 | 炒って挽きます | 密閉で6か月 | 水に溶いてすぐ食べられます |
| ロールドオーツ | 蒸してつぶし、乾燥させます | 密閉で2-3か月 | 調理燃料を大きく減らせます |
| 麦芽（ヨッキルム） | 発芽させて乾燥させ、挽きます | 密閉で1年 | 水あめ（チョチョン）や酒を作るのに使います |
| エンバクの水あめ | 麦芽で糖化させて煮詰めます | 涼しい所で1年 | 甘味と濃縮された熱量が得られます |
| エンバクの酒 | 蒸したエンバクにヌルク（韓国の麹）を混ぜて発酵させます | 密封して保管 | 熱量の保存と水の消毒を兼ねます |
| 発酵粥 | 粉を水で練って2-3日置きます | 数日 | 栄養の吸収がよくなります |

&nbsp;&nbsp;&nbsp;麦芽はエンバクからも作れます。穀粒を水に浸して少し発芽させたあと、乾燥させて挽けばよいのです。発芽の際に作られる酵素がデンプンを糖に変えてくれるため、この麦芽があればどんな穀物からでも水あめや酒を作れます。砂糖がなくなった状況で、甘味と濃縮された熱量を自給するための鍵です。

## 17. 年間作業スケジュール

| 月（韓国の気候基準） | 作業 | 要点 |
|---|---|---|
| 1月 | 貯蔵穀物の点検、種子の確認、道具の手入れ | 酸敗臭とカビ臭を確認します |
| 2月 | 畑の計画、堆肥の切り返し、発芽試験、春播きの準備 | 凍結が解けたらすぐ播けるよう、前もって準備します |
| 3月 | 春エンバクの播種（上旬-中旬）、秋播き分の麦踏み | 1日でも早く播くことが収量を左右します |
| 4月 | 草取り、野生エンバクの除去、分げつの管理 | 最初の1か月の雑草管理が重要です |
| 5月 | 追肥（草丈20cm）、出穂、病害の監視 | 追肥の時期を逃すと効果がありません |
| 6月 | 春エンバクの収穫、乾燥、脱穀 | 韓国の梅雨（チャンマ、6月下旬～7月）の前に終えることが目標です |
| 7月 | 貯蔵の整理、後作の播種（ダイズ・アワ）、高冷地での夏播き | 刈り取った跡を遊ばせません |
| 8月 | 秋エンバクの播種（中旬-下旬）、畑の準備 | 冬になる前に分げつを終えさせます |
| 9月 | 秋エンバクの生育管理、草取り | 越冬前に株の勢いを高めます |
| 10月 | 生育管理、早生品種の収穫開始 | 霜が降りる前に登熟を終えさせます |
| 11月 | 秋エンバクの収穫、乾燥、脱穀、貯蔵 | 水分13-14%を確認してから密閉します |
| 12月 | 精白とロールドオーツ作り、貯蔵の点検、翌年の計画 | 1、2か月で食べる分だけ加工します |

### 17-1. 忘れてはならない五つのこと

| 項目 | 内容 |
|---|---|
| 夏を避ける | エンバクは暑さと湿気に弱いです。春の早播き、秋播き、高冷地の三つのうち一つを選びます |
| 播種時期 | 韓国では、春は凍結が解けた直後、遅くとも3月中旬までです。1日の差が収量を変えます |
| 追肥 | 草丈20cmに合わせます。遅れると倒伏を招くだけです |
| 収穫のタイミング | 雨の予報があれば、完熟を待たずに刈ります |
| 皮付きのまま | 脂質が多く、精白すると半年ともちません。皮付きのまま置き、食べる分だけつきます |
