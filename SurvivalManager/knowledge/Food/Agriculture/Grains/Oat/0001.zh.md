## 引言
&nbsp;&nbsp;&nbsp;燕麦（Avena sativa）是在北欧扎下根的谷物。它原本是混在麦田里的杂草，后来在小麦长不好的寒冷、潮湿、酸性的土地上，一再只有燕麦活了下来，于是被接纳为谷物。因此它不要求好地，在酸性或贫瘠的土壤里也能生长，还能耐受其他谷物会冻死的低温。秋季播种可在-10℃越冬，在夏季作物全军覆没的年份也不让田地闲置，春天最早有收成；它属于C3谷类，遮光40%仍能保持产量的88%，无投入产量维持率高达51.8%。弱点是炎热和潮湿：超过30℃就会出现生长障碍，梅雨季赤霉病蔓延，必须避开夏季。每1,000㎡产300kg，每㎡1,164kcal，是自给线的0.44倍，而且脂肪含量高，碾过之后很快就会酸败。燕麦不是热量的主力，而是填补种植日历空白的作物。

## 2. 植物概述
&nbsp;&nbsp;&nbsp;禾本科燕麦属的一年生草本。茎直立、中空，高60-150cm，易倒伏。根系浅而广。花为圆锥花序，小穗单个垂在枝端，自花授粉。果实是颖果，皮燕麦被壳包裹，裸燕麦的壳容易脱落。野燕麦（Avena fatua）也属同一属。

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 发芽·出苗期 | 播种后3周 | 磷、氮 |
| 分蘖期 | 出苗后3-6周 | 侧茎分出，株数确定 |
| 拔节期 | 分蘖后4-6周 | 茎急剧伸长 |
| 抽穗期 | 播种后60-80天 | 穗子抽出 |
| 灌浆·成熟期 | 抽穗后30-40天 | 籽粒充满淀粉 |

> **燕麦生育期短，前期的养分供应决定收成。追肥一晚，就没有时间恢复了。**

| 每100g营养 | 含量 |
|:---|:---|
| 热量 | 334-389kcal（干籽粒） |
| 碳水化合物 | 66.3-70.4g（水溶性膳食纤维β-葡聚糖占相当一部分） |
| 蛋白质 | 9.9-14.3g（约为糙米的两倍） |
| 脂肪 | 3.8-6.9g（谷物中最高的一类） |
| 其他 | 膳食纤维、铁、B族维生素、维生素E |

## 3. 栽培环境与品种
| 条件 | 最适 | 极限与影响 |
|:---|:---|:---|
| 生长温度 | 18-25℃ | 4-30℃。超过30℃出现生长障碍 |
| 发芽 | 15-20℃ | 最低1-3℃。可在早春播种 |
| 灌浆期 | 10-22℃ | 高温时籽粒干瘪 |
| 耐寒性 | - | 秋播可在-10℃越冬。低于-15℃长期持续则冻死 |
| 光照 | 每天6小时以上 | 4小时以上。遮光40%时产量仍为88% |
| 水 | 合计400mm | 300-500mm。怕过湿和严重干旱 |
| 土壤 | 沙壤土，排水良好 | pH 5.8-6.5（5.0-7.5）。麦类中耐酸能力最强。黏土会伤根 |

&nbsp;&nbsp;&nbsp;海拔500m以上的山区高冷地最好（甚至可以夏季种植），其次是朝南缓坡地和平地。它耐荫，其他作物种不了的半阴处也能用。由水田改成的旱地必须保证排水，低洼地会有涝害和赤霉病，应避开。

| 类型 | 特点 | 对灾害的适应性 |
|:---|:---|:---|
| 皮燕麦 | 壳附得很牢，需要碾米 | 带壳可储存3年以上。到能吃之前要费很多功夫 |
| 裸燕麦 | 脱粒后壳自然脱落，不需要碾米 | 好吃好做，但储存寿命为6个月到1年 |

> **合理的做法是分别备下：长期储备用皮燕麦，近期要吃的用裸燕麦。**

| 品种 | 熟期 | 产量（t/ha） | 适宜茬口 |
|:---|:---|:---:|:---|
| 三韩（Samhan） | 早·中熟 | 7.1 | 春秋两用。栽培稳定性高，适合统一为一个品种 |
| Hi-Speed | 极早熟 | 6.3 | 春·夏。高冷地夏季栽培 |
| Cayuse | 中晚熟 | 8.4 | 春·秋 |
| Foothill | 晚熟 | 9.3 | 仅春播。产量最高 |
| Suwan、West | 极早熟、早熟 | 5.7、4.3 | 仅秋播 |

## 4. 田地准备与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 籽粒小，要把土块打碎整平。田边和沟里挖排水沟。腐熟堆肥1,000-1,500kg。播种后镇压 |
| 施肥 | 每1,000㎡氮6.6kg（基肥50%，追肥50%）、磷5.3kg、钾2.8kg（磷、钾全部作基肥） |
| 追肥 | 看株高而不是看日期。株高20cm时施。过了这个时候，产量补不回来，只会招致倒伏 |
| 替代资源 | 草木灰20-40kg（兼作调酸）、稀释10倍的尿液（株高20cm前后） |

&nbsp;&nbsp;&nbsp;燕麦耐酸，无法施用石灰时，比其他麦类有利。

| 茬口 | 播种 | 收获 |
|:---|:---|:---|
| 春播 | 3月上旬-中旬。解冻后尽快 | 6月上旬-中旬 |
| 秋播 | 8月中旬-下旬 | 11月上旬-中旬。南部越冬后，也可在翌年初夏收获 |
| 夏播（高冷地） | 7月底-8月中旬 | 10-11月。仅在海拔500m以上成立 |

| 播种 | 标准 |
|:---|:---|
| 种子 | 用筛子挑出粗大均匀的籽粒，筛掉小粒和秕粒。挑出野燕麦（芒长、颜色深的籽粒）。条播每1,000㎡15-16kg，撒播20kg |
| 消毒 | 50-55℃温水浸10-15分钟（防黑穗病）、拌细灰、用没有病症的植株上采的种子 |
| 播法 | 行距20-25cm，深2-3cm。覆土后用脚踩或用木板压实（发芽率大幅提高）。撒播后用耙子盖土 |

## 5. 水、栽培管理与病虫害
| 时期 | 水分管理 |
|:---|:---|
| 播种-发芽 | 不要干 |
| 分蘖期 | 靠自然降水 |
| 拔节期、抽穗·灌浆期 | 干旱时补水 |
| 收获期 | 完全停水。淋雨会倒伏、穗发芽 |
| 梅雨季 | 排水就是管理 |

> **燕麦种植中的水分管理，大多是排水。收获期的雨尤其是最大的损失因素。**

| 管理 | 内容 |
|:---|:---|
| 杂草 | 前期生长慢，所以播前翻耕把杂草埋掉，出苗后2-3周第一次除草。分蘖结束后燕麦就能覆盖地面。野燕麦最难对付 |
| 防倒伏 | 氮肥不超过标准量、遵守播种量、株高20cm时追肥、矮而粗壮的品种、排水。倒了以后能做的事不多 |
| 越冬 | 秋播的植株根会被冻拔起来，3月初冻土融化时，要踩压植株 |
| 其他 | 穗子下垂，鸟容易停落，所以拉线。燕麦秸秆用作覆盖、家畜垫料、饲料、堆肥 |

| 病虫害 | 不用药的应对 |
|:---|:---|
| 赤霉病（开花·灌浆期湿度大，穗子发红或发粉） | 排水通风、提早收获、销毁病穗 |
| 黑穗病（种子传染） | 温汤浸种、选用健康种子、烧毁病穗 |
| 叶斑病 | 遵守播种量、控制施肥、摘除病叶 |
| 冠锈病、白粉病 | 抗性品种、保证通风、牛奶稀释液 |
| 粘虫、蚜虫、螨虫 | 人工捕捉、肥皂水、保护天敌、喷水 |
| 鸟、田鼠 | 拉线、拉网、清理田边、管理好储存容器 |

> **穗子变红或变粉红的燕麦，洗了、煮了也不会变安全。丢掉是唯一的办法。**

&nbsp;&nbsp;&nbsp;防治的关键是避开病害流行的时期。避开夏季梅雨，就是燕麦防治的一半，控制氮肥、通风、排水是其余部分。也可使用草木灰和大蒜浸出液。

| 症状 | 原因与处理 |
|:---|:---|
| 整体发黄，植株矮小 | 缺氮。用腐熟堆肥，株高20cm前后施稀释10倍的尿液 |
| 叶缘焦枯 | 缺钾。草木灰 |
| 叶脉间发黄，叶脉仍绿 | 缺镁。白云石粉 |
| 新叶发白 | 缺锰或缺铁。停止过量使用草木灰，施腐叶土 |
| 叶尖枯成灰色 | 缺铜（泥炭土或沙土）。堆肥材料要多样化 |
| 只长叶子并倒伏 | 氮过量。停止施氮 |

## 6. 间作与轮作
| 搭配 | 作物 |
|:---|:---|
| 非常好 | 大豆、红小豆、豇豆（后茬，恢复氮素）、马铃薯·甘薯（后茬，燕麦的化感物质可降低线虫密度） |
| 好 | 三叶草·紫云英（绿肥兼饲料）、6月收获后的地块种夏季蔬菜 |
| 一般 | 大麦、小麦（栽培方法相同，但共有病害） |
| 差 | 燕麦连作（能耐连作，但病害密度会累积） |

&nbsp;&nbsp;&nbsp;第1年燕麦，第2年豆科，第3年马铃薯或根菜，第4年再回到燕麦。春燕麦在6月收获后，离秋天还有四个月，可以接着种大豆、粟或夏季蔬菜，不让田地闲着。

## 7. 收获、脱粒、留种
| 步骤 | 内容 |
|:---|:---|
| 时期 | 春播6月上旬-中旬（梅雨前结束），秋播11月上旬-中旬（霜前）。茎叶变黄，穗子下垂、籽粒朝下，用指甲按压不留痕迹时。摇穗时籽粒会掉，就立即割 |
| 割 | 用镰刀在近根处割，不要晃动植株。十株左右捆成一束，在田里互相靠着立起，几天后移到棚屋或屋檐下。变红的穗子单独挑出销毁 |
| 干燥 | 预干燥2-4天（18-20%）→ 挂晒1-2周（15-16%）→ 脱粒 → 最后干燥 → 13-14%。脂肪多，干燥温度要低 |
| 判断 | 咬籽粒时清脆地裂开并留下粉末；两手捧着摇，干籽粒相互碰撞发出清脆的声音；装进瓶里密封，过一两天不起雾 |
| 脱粒 | 在草席上用连枷或木棒敲打、在袋里敲打、在桶里搓。裸燕麦容易 |
| 秕粒·杂质 | 让每秒2-4m的稳定风吹走、扇、过筛。芒长时先用手或脚搓断芒再扬 |

| 留种 | 标准 |
|:---|:---|
| 选择 | 从抽穗期起在田里巡视并做记号。没有病症、没有倒伏、穗子大的植株。排除出现过黑穗病或赤霉病的植株。抽穗后让其完全成熟45天以上 |
| 野燕麦 | 挑出芒长、颜色深的籽粒。混进来后会逐年增多 |
| 保管 | 一定要带壳（碾过之后发芽力和寿命急剧下降），水分12-13%，10℃以下，完全避光。留需要量的两倍 |

&nbsp;&nbsp;&nbsp;燕麦是自花授粉作物，容易保持纯系。燕麦种子的寿命比其他谷物偏短，所以旧种子在种植前要做发芽试验。

## 8. 储存
&nbsp;&nbsp;&nbsp;耐储性为SS，但脂肪多，除了霉菌、虫、鼠之外，酸败是第四个敌人。酸败只能靠气味分辨。

| 项目 | 标准 |
|:---|:---|
| 条件 | 水分13-14%，温度15℃以下（越低越好），周围湿度65%以下，尽量隔绝光和氧气，每两个月检查一次气味 |
| 形态 | 带壳（3年以上）。碾过的裸燕麦要尽快吃完（寿命不到一半）。管理食用顺序，让容易酸败的先吃 |
| 容器 | 金属桶3年以上（同时隔绝光和氧气）、玻璃瓶2-3年（放在暗处或用布包裹）、地下储藏窖2-3年、厚塑料袋1-2年、麻袋6个月 |

| 延缓酸败的方法 | 原理与效果 |
|:---|:---|
| 带壳保管 | 壳隔绝氧气。3年与6个月的差别 |
| 提前炒 | 用热杀死脂肪分解酶。碾过的燕麦也能多放几个月 |
| 蒸或焯 | 杀死酶。市售燕麦片采用的方法 |
| 避光、低温 | 降低10℃，反应速度减半 |
| 少量碾米 | 只舂一个月的量 |

&nbsp;&nbsp;&nbsp;防虫以装满的完全密封最可靠（也能同时防酸败），也可用草木灰2-5%、硅藻土（每1kg谷物1-3g）、细沙·黄土、木炭，以及隆冬时拿到外面放几天（低温）。高温处理因为脂肪多，温度要定得低一些。

## 9. 烹调与注意事项
| 烹调准备 | 方法 |
|:---|:---|
| 碾米（皮燕麦） | 用臼舂；洒少许水放30分钟再舂；小火炒到壳变脆再舂（最合适）。不要想一次完成，每5分钟取出簸一次。糠不要扔 |
| 压片 | 吃燕麦的最佳形态。把碾过的燕麦蒸10分钟，再用擀面杖压的方法最好，也可以用布包着用擀面杖·瓶子·锤子压，或在两块平石之间压。烹调时间不到整粒的三分之一 |
| 磨粉 | 炒过后再磨，省力得多，也延缓酸败。没有面筋，面团没有黏性。粉比整粒坏得快得多 |

| 烹调 | 燃料与要领 |
|:---|:---|
| 泡开直接吃 | 压片用水或汤泡几个小时。不用火也能吃 |
| 粉粥 | 粉用水调开煮5分钟。最省燃料 |
| 压片粥 | 加水煮5-10分钟。最实用 |
| 余热烹调 | 煮10分钟后，用稻草或毯子包40分钟。燃料减少一半以上 |
| 杂粮饭 | 在米或大麦里掺两三成 |
| 整粒煮 | 泡一夜，煮40-60分钟。最费燃料 |

&nbsp;&nbsp;&nbsp;兼作储存的加工有压片（密封2-3个月）、麦芽（密封1年）、燕麦糖稀（阴凉处1年）、燕麦酒、发酵粥。

| 注意 | 内容 |
|:---|:---|
| 毒性 | 正常摄入量下没有 |
| 发霉的 | 赤霉病的毒素加热也不会消失。全部丢弃，也不要给家畜吃 |
| 酸败的 | 有哈喇味，留下苦味。脂肪氧化产物有害，不要吃 |
| 面筋 | 燕麦本身不含面筋，但可能与小麦发生交叉污染。重度敏感者要注意 |
| 过量摄入 | 膳食纤维多，增加消化负担。逐渐增加量 |

&nbsp;&nbsp;&nbsp;燕麦籽粒是马和牛的好饲料，燕麦秸秆柔软，可用作粗饲料，青燕麦无毒，可以直接喂家畜。

## 10. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存谷物（哈喇味、霉味）、确认种子、翻堆堆肥、发芽试验、准备春播 |
| 3月 | 春燕麦播种（上旬-中旬），踩压秋播的植株。早一天播种就决定产量 |
| 4月 | 除草、拔除野燕麦。前期一个月的杂草管理很重要 |
| 5月 | 追肥（株高20cm）、抽穗、监视病害 |
| 6月 | 春燕麦收获、干燥、脱粒。梅雨前结束 |
| 7月 | 整理储存、播后茬（大豆·粟）、高冷地夏播 |
| 8月 | 秋燕麦播种（中旬-下旬）、整地 |
| 9-10月 | 秋燕麦的生长管理、除草、早熟品种开始收获 |
| 11月 | 秋燕麦收获、干燥、脱粒、储存（确认水分13-14%后密封） |
| 12月 | 碾米和压片（只做一两个月的量）、检查储存、制定明年计划 |

> **不能忘记的五件事：避开夏季、解冻后立即播种、株高20cm时追肥、预报有雨就提早收获、带壳储存。**
