## はじめに
&nbsp;&nbsp;&nbsp;エンバク(Avena sativa)は北ヨーロッパで根づいた穀物です。もともとはコムギ畑に混じる雑草でしたが、コムギが育たない寒くて湿った酸性の土地でエンバクだけが生き残ることが繰り返され、穀物として受け入れられました。そのため良い土地を要求せず、酸性でもやせた土地でも育ち、ほかの穀物が凍え死ぬ温度に耐えます。秋にまくと-10℃で越冬し、夏の作物が全滅した年にも畑を遊ばせず、春に最も早く収穫が出ます。C3の穀類なので40%を遮光しても収量の88%を保ち、無投入での収量維持率は51.8%と高いです。弱点は暑さと湿気です。30℃を超えると生育障害が起こり、梅雨には赤かび病が広がるので、夏を避けなければなりません。1,000㎡で300kg、1㎡当たり1,164kcalで自給ラインの0.44倍であり、脂肪が多いため、精白すると酸敗が早く来ます。エンバクは熱量の主軸ではなく、作付けカレンダーの空白を埋める作物です。

## 2. 植物の概要
&nbsp;&nbsp;&nbsp;イネ科エンバク属の一年草です。茎は直立して中空で、高さ60-150cm、倒れやすいです。根は浅く広がります。花は円錐花序で、小穂が枝の先に1つずつ垂れ下がってつき、自家受粉です。果実は穎果で、殻付きエンバクは殻に包まれ、裸エンバクは殻が簡単にはずれます。野生エンバク(Avena fatua)も同じ属です。

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 発芽・出芽期 | 播種後3週間 | リン酸、窒素 |
| 分げつ期 | 出芽後3-6週 | 側茎が分かれ、株数が決まる |
| 伸長期 | 分げつ後4-6週 | 茎が急激に伸びる |
| 出穂期 | 播種後60-80日 | 穂が出る |
| 登熟・成熟期 | 出穂後30-40日 | 粒にデンプンが詰まる |

> **エンバクは栽培期間が短いので、初期の養分供給が収穫を決めます。追肥が遅れると、回復する時間がありません。**

| 100g当たりの栄養 | 含量 |
|:---|:---|
| 熱量 | 334-389kcal(乾燥した粒) |
| 炭水化物 | 66.3-70.4g(水溶性食物繊維のβ-グルカンがかなりの部分を占める) |
| タンパク質 | 9.9-14.3g(玄米の2倍の水準) |
| 脂肪 | 3.8-6.9g(穀物の中で最も高い部類) |
| その他 | 食物繊維、鉄、ビタミンB群、ビタミンE |

## 3. 栽培環境と品種
| 条件 | 最適 | 限界と影響 |
|:---|:---|:---|
| 生育温度 | 18-25℃ | 4-30℃。30℃を超えると生育障害 |
| 発芽 | 15-20℃ | 最低1-3℃。早春の播種が可能 |
| 登熟期 | 10-22℃ | 高温だと粒がしわしわになる |
| 耐寒性 | - | 秋まきで-10℃越冬。-15℃を下回る状態が長く続くと凍死 |
| 光 | 1日6時間以上 | 4時間以上。40%遮光でも収量88% |
| 水 | 合計400mm | 300-500mm。過湿と極端な干ばつに弱い |
| 土壌 | 砂壌土、水はけがよい | pH 5.8-6.5(5.0-7.5)。ムギ類の中で酸性への適応力が最も高い。粘土質では根が傷む |

&nbsp;&nbsp;&nbsp;標高500m以上の山間高冷地が最もよく(夏の栽培まで可能)、南向きの緩斜面の畑と平地の畑がその次です。日陰に強く、ほかの作物を植えられない半日陰も使えます。水田から転換した畑は排水を確保しなければならず、低地は湿害と赤かび病が来るので避けます。

| 区分 | 特徴 | 災害への適合性 |
|:---|:---|:---|
| 殻付きエンバク | 殻がしっかり付いていて精白が必要 | 殻のままなら3年以上貯蔵できる。食べるまでに手間がかかる |
| 裸エンバク | 脱穀すると殻が自然に落ち、精白が不要 | 食べやすいが、貯蔵寿命は6か月-1年 |

> **長期備蓄用には殻付きエンバクを、すぐ食べる分には裸エンバクを、分けて確保するのが合理的です。**

| 品種 | 熟期 | 収量(t/ha) | 適した作型 |
|:---|:---|:---:|:---|
| サムハン | 早・中生 | 7.1 | 春・秋兼用。栽培の安定性が高く、1つに統一するのに向く |
| ハイスピード | 極早生 | 6.3 | 春・夏。高冷地での夏栽培 |
| カイユース | 中晩生 | 8.4 | 春・秋 |
| フットヒル | 晩生 | 9.3 | 春専用。収量が最大 |
| スワン、ウエスト | 極早生、早生 | 5.7、4.3 | 秋専用 |

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 土づくり | 粒が小さいので、土塊を細かく砕いてならす。畑の周囲と畝間に排水溝。完熟堆肥1,000-1,500kg。播種後に鎮圧する |
| 施肥 | 1,000㎡当たり窒素6.6kg(元肥50%、追肥50%)、リン酸5.3kg、カリ2.8kg(リン酸とカリは全量元肥) |
| 追肥 | 日付ではなく草丈で判断。草丈20cmで施す。過ぎると収量に戻らず、倒伏を招くだけ |
| 代替資源 | 木灰20-40kg(酸度の矯正を兼ねる)、尿の10倍希釈液(草丈20cmのころ) |

&nbsp;&nbsp;&nbsp;エンバクは酸性に強いので、石灰を入れられないとき、ほかのムギ類より有利です。

| 作型 | 播種 | 収穫 |
|:---|:---|:---|
| 春栽培 | 3月上旬-中旬。解凍直後にできるだけ早く | 6月上旬-中旬 |
| 秋栽培 | 8月中旬-下旬 | 11月上旬-中旬。南部では越冬後、翌年の初夏の収穫も可能 |
| 夏栽培(高冷地) | 7月末-8月中旬 | 10-11月。標高500m以上でのみ成り立つ |

| 播種 | 基準 |
|:---|:---|
| 種子 | 大きくそろった粒を篩でより分け、小さい粒としいなを除く。野生エンバク(芒が長く色の濃い粒)は取り除く。条播き1,000㎡当たり15-16kg、ばらまき20kg |
| 消毒 | 50-55℃の湯に10-15分(黒穂病)、細かい灰をまぶす、病徴のなかった株から採った種子 |
| 播き方 | 条間20-25cm、深さ2-3cm。覆土後に足で踏むか板で押さえる(発芽率が大きく上がる)。ばらまきの後は熊手で土をかぶせる |

## 5. 水と栽培管理、病害虫
| 時期 | 水管理 |
|:---|:---|
| 播種-発芽 | 乾かないように |
| 分げつ期 | 自然の降水に任せる |
| 伸長期、出穂・登熟期 | 乾燥したら補う |
| 収穫期 | 完全に止める。雨に当たると倒れ、穂発芽する |
| 梅雨 | 水を抜くのが管理 |

> **エンバク栽培での水管理は、たいてい水を抜く作業です。特に収穫期の雨が最大の損失要因です。**

| 管理 | 内容 |
|:---|:---|
| 雑草 | 初期生育が遅いので、播種前に耕して雑草をすき込み、出芽後2-3週に1回目の除草。分げつが終わるとエンバクが地面を覆う。野生エンバクが最も厄介 |
| 倒伏防止 | 窒素は標準量以下、播種量を守る、追肥は草丈20cmで、短くて丈夫な品種、排水。倒れた後はできることが多くない |
| 越冬 | 秋まきは霜柱で根が浮くので、3月初めに凍土が解けるとき、株を踏んで押さえる |
| その他 | 穂が垂れて鳥がとまりやすいので、糸を張る。エンバクのわらは、マルチ、家畜の敷きわら、飼料、堆肥に使う |

| 病害虫 | 薬を使わない対応 |
|:---|:---|
| 赤かび病(開花・登熟期の多湿、穂が赤またはピンク) | 排水と通風、早めの収穫、病んだ穂の廃棄 |
| 黒穂病(種子伝染) | 温湯浸法、健全な種子の選別、病んだ穂の焼却 |
| 葉斑病 | 播種量を守る、施肥を控える、病葉の除去 |
| 冠さび病、うどんこ病 | 抵抗性品種、通風の確保、牛乳の希釈液 |
| アワヨトウ、アブラムシ、ハダニ | 手で捕る、石けん水、天敵の保護、水を撒く |
| 鳥、野ネズミ | 糸を張る、ネット、畑周辺の整理、貯蔵容器の管理 |

> **穂が赤やピンクに変わったエンバクは、洗っても、ゆでても安全にはなりません。捨てるのが唯一の方法です。**

&nbsp;&nbsp;&nbsp;防除の核心は、病気が広がる時期を避けることです。夏の梅雨を避けるのがエンバク防除の半分であり、窒素を控えること、通風、排水が残りです。木灰とニンニクの浸出液も使います。

| 症状 | 原因と措置 |
|:---|:---|
| 全体が黄色く色あせ、株が小さい | 窒素欠乏。腐熟堆肥、尿の10倍希釈液を草丈20cmのころに |
| 葉の縁が焼けたように枯れる | カリ欠乏。木灰 |
| 葉脈の間だけ黄色く、葉脈は緑 | マグネシウム欠乏。ドロマイト粉末 |
| 新しい葉が白くなる | マンガンまたは鉄の欠乏。木灰の使いすぎをやめ、腐葉土 |
| 葉先が灰色に枯れる | 銅欠乏(泥炭土や砂質土)。堆肥の材料を多様にする |
| 葉だけ茂って倒れる | 窒素過剰。窒素を断つ |

## 6. 間作と輪作
| 相性 | 作物 |
|:---|:---|
| 非常によい | ダイズ、アズキ、ササゲ(後作、窒素の回復)、ジャガイモ・サツマイモ(後作、エンバクのアレロパシー物質がセンチュウ密度を下げる) |
| よい | クローバー・レンゲ(緑肥と飼料を兼ねる)、6月に収穫した跡地の夏野菜 |
| 普通 | オオムギ、コムギ(栽培法が同じだが病害を共有する) |
| 悪い | エンバクの連作(連作耐性はあるが病気の密度が積み上がる) |

&nbsp;&nbsp;&nbsp;1年目エンバク、2年目マメ科、3年目ジャガイモまたは根菜、4年目にエンバクへ戻ります。春エンバクを6月に収穫した後は、秋まで4か月残るので、ダイズ、アワ、夏野菜を続けて植え、畑を遊ばせません。

## 7. 収穫、脱穀、採種
| 段階 | 内容 |
|:---|:---|
| 時期 | 春栽培は6月上旬-中旬(梅雨前に終える)、秋栽培は11月上旬-中旬(霜の前)。茎と葉が黄色くなり、穂が垂れて粒が下を向き、爪で押しても跡が残らないとき。穂を振って粒が落ちるようなら、すぐに刈る |
| 刈り取り | 鎌で株元近くを、株を揺らさずに刈る。10株ほどずつ束ね、畑で互いにもたせかけて立て、数日後に納屋や軒下に移す。赤く変わった穂は別によりわけて廃棄 |
| 乾燥 | 予備乾燥2-4日(18-20%) → 掛け干し1-2週(15-16%) → 脱穀 → 仕上げの乾燥 → 13-14%。脂肪が多いので乾燥温度は低く |
| 判定 | 粒をかむと、ぱきっと割れて粉が残る。両手に入れて振ると、乾いた粒同士がぶつかる澄んだ音がする。瓶に密封して1日ほどたっても曇らない |
| 脱穀 | むしろの上で殻竿や棒でたたく、袋の中でたたく、桶の中でこする。裸エンバクは簡単 |
| しいな・くず | 秒速2-4mの安定した風に飛ばす、あおぐ、篩にかける。芒が長いときは、手や足でこすって芒を折ってから飛ばす |

| 採種 | 基準 |
|:---|:---|
| 選抜 | 出穂期から畑を回って印をつける。病徴がなく、倒れておらず、穂が大きい株。黒穂病や赤かび病が見えた株は除く。出穂後45日以上かけて完全に熟させる |
| 野生エンバク | 芒が長く色の濃い粒をよりわけて取り除く。混ざると毎年増える |
| 保管 | 必ず殻のまま(精白すると発芽力と寿命が急激に落ちる)、水分12-13%、10℃以下、光を完全に遮断。必要量の2倍 |

&nbsp;&nbsp;&nbsp;エンバクは自家受粉の作物なので、純系が保たれやすいです。エンバクの種子はほかの穀物より寿命が短めなので、古い種子は植える前に発芽試験を行います。

## 8. 貯蔵
&nbsp;&nbsp;&nbsp;貯蔵性はSSですが、脂肪が多いので、カビ、虫、ネズミのほかに、酸敗が4つ目の敵です。酸敗は、においでしか分かりません。

| 項目 | 基準 |
|:---|:---|
| 条件 | 水分13-14%、温度15℃以下(低いほどよい)、周囲の湿度65%以下、光と酸素をできるだけ遮断、2か月ごとににおいを点検 |
| 形態 | 殻のまま(3年以上)。精白した裸エンバクはできるだけ早く消費する(寿命が半分以下)。酸敗が早いものから食べるように、消費の順序を管理 |
| 容器 | 金属缶3年以上(光と酸素を同時に遮断)、ガラス瓶2-3年(暗所に置くか布で包む)、地下貯蔵穴2-3年、厚手のビニール1-2年、麻袋6か月 |

| 酸敗を遅らせる方法 | 原理と効果 |
|:---|:---|
| 殻のまま保管 | 殻が酸素を遮断。3年と6か月の差 |
| 炒っておく | 脂肪分解酵素を熱で殺す。精白したエンバクもさらに数か月もつ |
| 蒸す、または湯通し | 酵素を殺す。市販のオートミールが使う方法 |
| 遮光、低温 | 10℃下げると反応速度が半分になる |
| 少量ずつ精白 | 1か月分だけ搗く |

&nbsp;&nbsp;&nbsp;虫の防除は、いっぱいに詰めた完全密閉が最も確実で(酸敗も同時に防ぐ)、木灰2-5%、珪藻土(穀物1kgに1-3g)、細かい砂・黄土、炭、真冬に数日外に出しておく(低温)を使います。高温処理は、脂肪が多いので温度を低めに設定します。

## 9. 調理と注意事項
| 調理の準備 | 方法 |
|:---|:---|
| 精白(殻付きエンバク) | 臼で搗く、水を少量ふりかけて30分置いてから搗く、弱火で炒めて殻をぱりっとさせてから搗く(最も合う)。一度で終わらせようとせず、5分ごとに取り出して箕で煽る。ぬかは捨てない |
| 圧ぺん(ロールドオーツ) | エンバクを食べる最良の形。精白したエンバクを10分蒸して、麺棒で押す方法が最もよく、布に包んで麺棒・瓶・金づちで押したり、平らな石2つの間で押してもよい。調理時間は粒のままの3分の1以下 |
| 製粉 | 炒ってから挽くと、はるかに楽で、酸敗も遅れる。グルテンがないので、生地に粘りがない。粉は粒よりはるかに早く傷む |

| 調理 | 燃料とコツ |
|:---|:---|
| 浸してそのまま | 圧ぺんを水やだし汁に数時間浸す。火なしで食べられる |
| 粉がゆ | 粉を水に溶いて5分。燃料が最も少なくてすむ |
| 圧ぺんがゆ | 水を注いで5-10分。最も実用的 |
| 余熱調理 | 10分煮てから、わらや毛布で包んで40分。燃料を半分以下に |
| 混ぜご飯 | 米や麦に2-3割混ぜる |
| 粒のままゆでる | 一晩浸して40-60分。燃料が最も多くかかる |

&nbsp;&nbsp;&nbsp;貯蔵を兼ねる加工には、圧ぺん(密閉で2-3か月)、麦芽(密閉で1年)、エンバクの水あめ(涼しい場所で1年)、エンバクの酒、発酵がゆがあります。

| 注意 | 内容 |
|:---|:---|
| 毒性 | 通常の摂取量ではない |
| カビが生えたもの | 赤かび病の毒素は加熱しても消えない。全量を廃棄し、家畜にも与えない |
| 酸敗したもの | 古びたにおいがして、苦味が残る。脂肪の酸化物は有害なので食べない |
| グルテン | エンバク自体にはグルテンがないが、コムギと交差汚染される可能性がある。重い過敏症の人は注意 |
| 過剰摂取 | 食物繊維が多く、消化の負担になる。少しずつ量を増やす |

&nbsp;&nbsp;&nbsp;エンバクの粒はウマやウシのよい飼料で、わらは柔らかく粗飼料として使えます。青刈りエンバクは毒性がなく、家畜にそのまま与えられます。

## 10. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵穀物の点検(古びたにおい、カビのにおい)、種子の確認、堆肥の切り返し、発芽試験、春の播種準備 |
| 3月 | 春エンバクの播種(上旬-中旬)、秋まき分の麦踏み。1日でも早くまくことが収量を決める |
| 4月 | 除草、野生エンバクの除去。初期1か月の雑草管理が重要 |
| 5月 | 追肥(草丈20cm)、出穂、病害の監視 |
