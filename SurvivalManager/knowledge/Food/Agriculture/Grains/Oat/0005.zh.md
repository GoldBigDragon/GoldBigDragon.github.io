## 12. 收获与脱粒

### 12-1. 时期的判断

| 标准 | 内容 | 判定 |
|---|---|---|
| 春季栽培 | 在韩国为6月上旬-中旬 | 目标是在韩国的梅雨季（6月下旬至7月）到来之前完成 |
| 秋季栽培 | 在韩国为11月上旬-中旬 | 在下霜之前收获 |
| 种子用 | 抽穗后45天以上 | 要充分成熟，发芽力才好 |
| 茎的颜色 | 茎和叶变黄 | 接近成熟 |
| 籽粒硬度 | 用指甲按压不留痕迹 | 完熟 |
| 穗的姿态 | 穗枝下垂，籽粒朝下 | 是收获期 |
| 落粒 | 摇动穗子，籽粒就会掉落 | 已过适期。立即收割 |

&nbsp;&nbsp;&nbsp;燕麦收获时机的判断中，最重要的变量不是籽粒的状态，而是天气。燕麦的茎是空心的，穗子下垂着长在上面，容易被风雨吹倒，倒伏的穗子接触地面就会穗发芽。如果天气预报有雨，哪怕稍早一点也应该割回来，这才是正确的做法。稍欠成熟的籽粒在室内变干的过程中会在一定程度上充实，但倒伏后已经发芽的籽粒无法恢复。

> **燕麦因等待成熟而造成的损失，远比稍微早割而吃亏的情形多得多。**

### 12-2. 收获要领

| 顺序 | 内容 | 理由 |
|---|---|---|
| 1 | 选晴天上午，露水干了以后开始 | 潮湿的穗子是霉菌的源头 |
| 2 | 用镰刀在靠近基部处割下 | 把秸秆一并收回，用作覆盖材料和饲料 |
| 3 | 割的时候不要摇动穗子 | 燕麦是容易落粒的谷物 |
| 4 | 把割下的燕麦捆成束 | 十来株为宜 |
| 5 | 在田里互相靠着立放 | 避免淋雨，并保证通风 |
| 6 | 几天后移到棚屋或屋檐下 | 必须避开露水和雨水 |
| 7 | 变红的穗子要单独挑出丢弃 | 赤霉病会产生毒素 |

&nbsp;&nbsp;&nbsp;把割下的燕麦立放在田里的做法，是麦类作物长期使用的方法。把麦捆互相靠着立成圆锥形，雨水会顺着外面流下，里面通风而变干。不过，韩国的6月说不准梅雨季的雨什么时候会来，所以不要放得太久，几天之内搬到室内更安全。

### 12-3. 谷物干燥 - 含水量降到13-14%

&nbsp;&nbsp;&nbsp;谷物贮藏的一切都取决于含水量。含水量超过15%，霉菌就会滋生；降到13%以下，霉菌和害虫几乎都停止活动。刚割下的燕麦含水量为20-30%。把它降到13-14%，是收获后唯一也是最重要的任务。

| 阶段 | 方法 | 时间 | 达到含水量 |
|---|---|---|---|
| 1. 预干燥 | 把割下的麦捆立放在田里 | 2-4天 | 18-20% |
| 2. 挂晒 | 悬挂或堆放在棚屋或屋檐下 | 1-2周 | 15-16% |
| 3. 脱粒 | 充分干燥后打落 | 1天 | - |
| 4. 收尾干燥 | 摊在草席或布上，在阳光下晒干 | 2-3天 | 13-14% |
| 5. 缓苏 | 放在阴凉处一天，使水分均匀 | 1天 | 均匀化 |

&nbsp;&nbsp;&nbsp;燕麦脂肪含量高，干燥温度要特别注意。如果超过50℃烘干，脂肪就会开始氧化，产生哈喇味，也不能再用作种子。在阳光下晾晒最安全，必须用火力时，也只加热到用手触摸时感觉温热的程度。如果感觉烫手，就已经太高了。

&nbsp;&nbsp;&nbsp;在阳光下晾晒的原则，各种谷物都一样。第一，不要直接摊在地上，因为土里的湿气会把下层重新弄潮。第二，堆放厚度不要超过3-5cm，每天翻动三四次。第三，太阳偏西时要收起或盖好，因为夜里沾上露水，白天晒掉的水分会重新回来。第四，不要操之过急，如果只有表面干了而水分被困在内部，之后就会长霉。

&nbsp;&nbsp;&nbsp;没有水分仪也有办法估测含水量。

| 方法 | 步骤 | 判定 |
|---|---|---|
| 咬 | 用臼齿咬籽粒 | “啪”地裂开并出粉，就是13-14%。如果被咬扁，说明还是潮的 |
| 盐试验 | 把一勺干盐和一把谷物放进瓶里摇晃，静置15分钟 | 盐粘在瓶壁上，说明含水量高 |
| 手感 | 抓一把再摊开 | 像滑落一样散开说明是干的，结成团说明是潮的 |
| 声音 | 捧在双手里摇晃 | 会发出干籽粒互相碰撞的清脆声音 |
| 瓶试验 | 在玻璃瓶里装一半，密封静置一天 | 瓶内壁出现雾气，就需要继续干燥 |

&nbsp;&nbsp;&nbsp;瓶试验是入库贮藏前最后的确认，也是最可靠的方法。在密闭的瓶里，谷物与空气达到水分平衡，如果含水量超过14%，瓶内湿度就会超过70%，在气温下降的凌晨就会出现雾气。

### 12-4. 脱粒 - 不用工具的方法

&nbsp;&nbsp;&nbsp;燕麦是容易脱粒的谷物。籽粒松松地长在穗枝的末端，干燥后受到轻微的冲击就会掉落。反倒是因为掉得太容易，在收获和搬运过程中造成损失，这才是问题。

| 方法 | 步骤 | 规模 | 备注 |
|---|---|---|---|
| 用手捋 | 握住穗柄，戴手套用手向下捋 | 少量 | 损失最少。用于种子 |
| 敲打 | 在草席上摊开穗子，用连枷或木棍敲打 | 多 | 最常用 |
| 袋内摔打 | 装进结实的袋子，连袋往地上摔打 | 中等 | 籽粒不会散落 |
| 踩踏 | 摊在草席上，用脚像搓揉一样踩 | 多 | 比较省力 |
| 桶内搓揉 | 放进大桶，用木棍搅动搓揉 | 中等 | 手不那么疼 |

&nbsp;&nbsp;&nbsp;连枷可以自己制作。在长柄的末端，用皮绳或结实的麻绳松松地拴上一根短棍就行。挥动长柄，末端的短棍就会转动着击打谷物。比用手臂的力量敲打效率高三四倍，干一整天也不那么累。它特别适合麦类脱粒，是灾难情况下最先要做好的农具之一。

&nbsp;&nbsp;&nbsp;如果种的是裸燕麦（莜麦），在这个阶段就能体现出很大的优势。脱粒的同时外壳就脱落了，所以只要用簸箕簸一簸，就能立刻吃。如果是皮燕麦，脱粒之后还多一道碾磨（去壳）的工序。

### 12-5. 扬去秕粒 - 风车与簸箕

&nbsp;&nbsp;&nbsp;脱下来的燕麦里混有穗枝、芒、叶片碎屑和灰尘。燕麦的芒又长又硬，混入的特别多，如果就这样贮藏，秕粒上附着的水分和虫卵会毁掉整个仓库。

| 方法 | 步骤 | 条件 |
|---|---|---|
| 迎风倾倒 | 在有风的日子，从高处慢慢倒下 | 风速每秒2-4m的稳定风 |
| 簸扬 | 盛在簸箕里，向前推再拉回，把谷物抛到空中 | 没有风也可以 |
| 扇风 | 一人倾倒，另一人用扇子或木板扇风 | 需要两个人 |
| 过筛 | 用粗筛筛出芒和枝，用细筛筛出灰尘 | 燕麦因为有芒，过筛特别有效 |
| 搓去芒 | 用手或脚搓断芒，再扬去 | 芒长的话要先做这一步 |

&nbsp;&nbsp;&nbsp;燕麦的芒在贮藏时会真正成为问题。它又长又硬，会在容器里谷物之间制造空隙，这些空隙成为害虫的藏身之处。而且芒本身还会吸收水分。即使多簸一遍，也要尽量把芒筛除干净，这样能延长贮藏寿命。用脚搓断芒后再扬去，会干净得多。

&nbsp;&nbsp;&nbsp;簸箕可以自制。把竹子或胡枝子的枝条劈开编成，或者用薄胶合板只立三面做成，也能起作用。簸扬的要领不是上下摇动，而是向前推再拉回，让谷物在空中短暂悬浮。悬浮期间，较轻的会落后，向前方聚集。

## 13. 留种

### 13-1. 留种株选拔

| 标准 | 内容 | 理由 |
|---|---|---|
| 选拔时期 | 从抽穗期起巡视田地并做标记 | 收获以后就无法区分了 |
| 个体条件 | 没有病症、没有倒伏、穗子大的 | 性状会遗传下去 |
| 收获时点 | 抽穗后45天以上，完全成熟之后 | 未成熟的种子发芽率低 |
| 排除对象 | 出现黑穗病或赤霉病的植株 | 防止种子传染 |
| 野燕麦 | 挑出芒长、颜色深的籽粒 | 混入后会逐年增多 |
| 形态 | 一定要带壳保管 | 碾磨后发芽力和寿命急剧下降 |
| 数量 | 需要量的两倍 | 播种量大，所以事先多留一些 |

&nbsp;&nbsp;&nbsp;燕麦是自花授粉作物，容易保持纯系。即使附近有其他品种，混杂的概率也很低，收下的种子会表现出与亲本相同的性状。这就是自家留种等级为S的原因。从灾害应对的角度看，这是一大资产。一旦确保了一个品系，就可以连续沿用好几年。

&nbsp;&nbsp;&nbsp;需要注意的是野燕麦。它与栽培燕麦几乎无法区分，一旦在留种过程中混入，比例就会逐年增加。野燕麦成熟后会自行脱落，因此收获损失增大，而且发芽不整齐，会使田里长势参差不齐。在生育期按穗形区分并拔除是最可靠的办法，挑选种子时，要把芒长而扭曲的籽粒和颜色格外深的籽粒挑出来。

&nbsp;&nbsp;&nbsp;燕麦种子一定要带壳保管。即使种的是裸燕麦，留种用的也要选择仍带壳的个体，或者如果是裸燕麦，就保持未经碾磨的原样。因为这是脂肪含量高的谷物，胚一旦暴露，氧化就会加快，发芽力急剧下降。

### 13-2. 种子保管

| 条件 | 标准 | 理由 |
|---|---|---|
| 含水量 | 12-13% | 种子含水量越低，寿命越长 |
| 温度 | 10度以下为理想 | 脂肪多，温度高时酸败快 |
| 容器 | 玻璃瓶、金属罐、陶罐 | 同时防潮和防虫 |
| 光 | 完全遮光 | 光会促进脂肪氧化 |
| 形态 | 带壳 | 碾磨后寿命急剧缩短 |
| 寿命 | 常温密封2-3年 | 在阴凉处能保存更久 |

&nbsp;&nbsp;&nbsp;燕麦种子的寿命比其他谷物短。这是脂肪含量造成的。过了2-3年，发芽率会明显下降，所以每年重新留种来更新品系比较稳妥。如果打算隔好几年再使用陈种子，就必须放在最阴凉的地方。

### 13-3. 发芽试验

&nbsp;&nbsp;&nbsp;种植陈种子之前，要先确认发芽力。用湿布包20粒籽粒，放在温暖处，等待5天。20粒中有16粒以上就照常使用，有12-15粒就把播种量增加到1.5倍，不足10粒就要另寻新种子。燕麦是播种量大的作物，所以发芽率下降会直接导致减产。

## 14. 毒性与注意事项

### 14-1. 籽粒的毒性 - 无

&nbsp;&nbsp;&nbsp;燕麦在一般食用量下没有毒性。它不像高粱那样叶片中含有足以造成问题的氰苷，籽粒中也没有需要去除的成分。洗净煮熟就可以安全食用。相反，它在谷物中属于消化较为温和的一类，适合儿童、老人和康复期患者。

### 14-2. 需要注意的情况

| 项目 | 内容 | 措施 |
|---|---|---|
| 发霉的 | 赤霉病的毒素加热也不会消失 | 全部丢弃。也不要给家畜吃 |
| 酸败的 | 有哈喇味，味苦 | 不要吃。脂肪氧化产物对身体有害 |
| 麸质敏感 | 燕麦本身不含麸质，但可能与小麦发生交叉污染 | 严重敏感者要小心 |
| 过量食用 | 膳食纤维多，可能引起消化不适 | 逐渐增加食用量 |
| 未煮熟的 | 淀粉无法消化 | 充分浸泡后煮熟 |

> **发霉的粮食，洗过、煮过、炒过也不会变得安全。丢掉是唯一的办法。**

&nbsp;&nbsp;&nbsp;燕麦实际上更常遇到的问题不是霉菌，而是酸败。它是脂肪含量高的谷物，碾磨或磨成粉存放的燕麦，几个月就会开始发出哈喇味。哈喇味是脂肪氧化产生的气味，其氧化产物对身体不好。不过与霉菌毒素不同，它不属于急性危险，在极度饥饿的情况下是可以吃的。只需要知道，两者的判断标准不同。

&nbsp;&nbsp;&nbsp;防止酸败的方法在第15节中详细介绍。要点是带壳贮藏，只碾磨要吃的量，并通过炒制使酶失活。

### 14-3. 用作家畜饲料时

| 项目 | 内容 |
|---|---|
| 燕麦籽粒 | 是马和牛的好饲料。尤其是马的标准饲料 |
| 燕麦秸 | 在麦类秸秆中较柔软，可用作粗饲料 |
| 青燕麦 | 作为饲料作物被广泛使用。没有毒性 |
| 注意 | 发霉的对家畜也是毒物 |

&nbsp;&nbsp;&nbsp;燕麦不存在高粱那样的氰苷问题，所以幼嫩状态的青燕麦可以直接喂给家畜。这就是它被广泛用作饲料作物的原因。在灾难情况下，如果想维持家畜，燕麦是难得的选择，一种作物就能同时提供谷物和粗饲料。
