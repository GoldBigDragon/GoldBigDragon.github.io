## 들어가며
&nbsp;&nbsp;&nbsp;귀리(Avena sativa)는 북유럽에서 자리 잡은 곡물입니다. 원래 밀밭에 섞이는 잡초였는데, 밀이 자라지 못하는 춥고 습하고 산성인 땅에서 귀리만 살아남는 일이 되풀이되며 곡물로 받아들여졌습니다. 그래서 좋은 땅을 요구하지 않고, 산성이든 척박하든 자라며, 다른 곡물이 얼어 죽는 온도를 견딥니다. 가을에 심으면 영하 10℃에서 월동해 여름 작물이 전멸한 해에도 밭을 놀리지 않고 봄에 가장 먼저 수확이 나오며, C3 곡류라 40%를 가려도 수량의 88%를 유지하고, 무투입 수량 유지율이 51.8%로 높습니다. 약점은 더위와 습기입니다. 30℃가 넘으면 생장 장애가 오고 장마철에는 붉은곰팡이병이 번지므로 여름을 피해야 합니다. 1,000㎡에서 300kg, ㎡당 1,164kcal로 자급선의 0.44배이고, 지방이 많아 도정하고 나면 산패가 빨리 옵니다. 귀리는 열량의 주축이 아니라 시간표의 빈자리를 채우는 작물입니다.

## 1. 재난 대비 평가
| 구분 | 등급 | 점수 |
|:---|:---:|:---:|
| 종합 | A | 50.1 |
| 단기 | A | 48.4 |
| 장기 | S | 51.8 |
| 부식 | SS | 63.9 |

| 평가 | 항목 |
|:---|:---|
| 강점 (S 이상) | 내한성, 시설물 부담, 저장성, 연작 적응성, 맛(곡물 중 거부감이 가장 적음), 자가 채종 |
| 약점 | E가 붙은 항목은 없음. 면적당 열량 C가 가장 무거운 제약이고 조리·가공 C는 품종(겉귀리·쌀귀리)에 따라 크게 다름 |

> **귀리는 최고 수확을 내는 작물이 아니라, 조건이 나빠져도 잘 무너지지 않는 작물입니다.**

&nbsp;&nbsp;&nbsp;항목별 등급은 재난 대비 작물 평가 결과 문서에 있습니다.

## 2. 식물 개요
&nbsp;&nbsp;&nbsp;벼과 귀리속의 한해살이풀입니다. 줄기는 곧게 서며 속이 비어 있고 높이 60-150cm이며 쓰러지기 쉽습니다. 뿌리는 얕고 넓게 퍼집니다. 꽃은 원추화서로 작은 이삭이 가지 끝에 하나씩 늘어져 달리고 자가수정입니다. 열매는 영과이며 겉귀리는 껍질에 싸여 있고 쌀귀리는 껍질이 쉽게 떨어집니다. 야생 귀리(Avena fatua)도 같은 속입니다.

| 단계 | 시기 | 핵심 |
|:---|:---|:---|
| 발아·출현기 | 파종 후 3주 | 인산, 질소 |
| 분얼기 | 출현 후 3-6주 | 곁줄기가 갈라져 포기 수가 결정됨 |
| 신장기 | 분얼 후 4-6주 | 줄기가 급격히 길어짐 |
| 출수기 | 파종 후 60-80일 | 이삭이 나옴 |
| 등숙·성숙기 | 출수 후 30-40일 | 낟알에 전분이 참 |

> **귀리는 재배 기간이 짧아 초기 양분 공급이 수확을 결정합니다. 웃거름이 늦으면 회복할 시간이 없습니다.**

| 100g당 영양 | 함량 |
|:---|:---|
| 열량 | 334-389kcal (마른 알곡) |
| 탄수화물 | 66.3-70.4g (수용성 식이섬유 베타글루칸이 상당 부분) |
| 단백질 | 9.9-14.3g (현미의 두 배 수준) |
| 지방 | 3.8-6.9g (곡물 중 가장 높은 축) |
| 그 밖 | 식이섬유, 철, 비타민 B군, 비타민 E |

## 3. 재배 환경과 품종
| 조건 | 최적 | 한계와 영향 |
|:---|:---|:---|
| 생육 기온 | 18-25℃ | 4-30℃. 30℃를 넘으면 생장 장애 |
| 발아 | 15-20℃ | 최저 1-3℃. 이른 봄 파종 가능 |
| 등숙기 | 10-22℃ | 고온이면 낟알이 쭈그러듦 |
| 내한성 | - | 가을 파종 시 영하 10℃ 월동. 영하 15℃ 아래로 오래 가면 동사 |
| 빛 | 하루 6시간 이상 | 4시간 이상. 40% 차광에서도 수량 88% |
| 물 | 총 400mm | 300-500mm. 과습과 극심한 가뭄에 약함 |
| 토양 | 사양질, 배수 양호 | pH 5.8-6.5(5.0-7.5). 맥류 중 산성 적응력이 가장 좋음. 점질토에서 뿌리가 상함 |

&nbsp;&nbsp;&nbsp;해발 500m 이상의 산간 고랭지가 가장 좋고(여름 재배까지 가능), 남향 완경사 밭과 평지 밭이 그다음입니다. 차광에 강해 다른 작물을 못 심는 반그늘도 쓸 수 있습니다. 논을 전환한 밭은 배수를 확보해야 하고, 저지대는 습해와 붉은곰팡이병이 오므로 피합니다.

| 구분 | 특징 | 재난 적합성 |
|:---|:---|:---|
| 겉귀리(피맥) | 껍질이 단단히 붙어 도정이 필요 | 껍질째면 3년 이상 저장. 먹기까지 손이 많이 감 |
| 쌀귀리(나맥) | 탈곡하면 껍질이 저절로 떨어져 도정이 필요 없음 | 먹기는 편하나 저장 수명 6개월-1년 |

> **장기 비축용으로는 겉귀리를, 당장 먹을 몫으로는 쌀귀리를 나누어 확보하는 것이 합리적입니다.**

| 품종 | 숙기 | 수량(t/ha) | 적합 작형 |
|:---|:---|:---:|:---|
| 삼한귀리 | 조·중생 | 7.1 | 봄·가을 겸용. 재배 안정성이 높아 하나로 통일할 때 적합 |
| 하이스피드 | 극조생 | 6.3 | 봄·여름. 고랭지 여름 재배 |
| 카이유스 | 중만생 | 8.4 | 봄·가을 |
| 푸트힐 | 만생 | 9.3 | 봄 전용. 수량 최대 |
| 수완, 웨스트 | 극조생, 조생 | 5.7, 4.3 | 가을 전용 |

## 4. 밭 준비와 파종
| 항목 | 기준 |
|:---|:---|
| 땅 만들기 | 낟알이 작으므로 흙덩이를 잘게 부수고 고름. 밭 둘레와 고랑에 배수로. 완숙 퇴비 1,000-1,500kg. 파종 후 눌러 줌 |
| 시비 | 1,000㎡당 질소 6.6kg(밑거름 50%, 웃거름 50%), 인산 5.3kg, 칼륨 2.8kg(인산과 칼륨은 전량 밑거름) |
| 웃거름 | 날짜가 아니라 키로 판단. 초장 20cm에 줌. 넘기면 수량으로 돌아오지 않고 도복만 부름 |
| 대체 자원 | 나무재 20-40kg(산도 교정 겸용), 오줌 10배 희석액(초장 20cm 무렵) |

&nbsp;&nbsp;&nbsp;귀리는 산성에 강해 석회를 넣지 못할 때 다른 맥류보다 유리합니다.

| 작형 | 파종 | 수확 |
|:---|:---|:---|
| 봄 재배 | 3월 상순-중순. 해빙 직후 가능한 한 빨리 | 6월 상순-중순 |
| 가을 재배 | 8월 중순-하순 | 11월 상순-중순. 남부는 월동 후 이듬해 초여름 수확도 가능 |
| 여름 재배(고랭지) | 7월 말-8월 중순 | 10-11월. 해발 500m 이상에서만 성립 |

| 파종 | 기준 |
|:---|:---|
| 종자 | 굵고 고른 낟알을 체로 골라 작은 것과 쭉정이를 거름. 야생 귀리(까락이 길고 색이 짙은 알)는 골라 냄. 줄뿌림 1,000㎡당 15-16kg, 흩어뿌림 20kg |
| 소독 | 50-55℃ 물에 10-15분(깜부기병), 고운 재 묻히기, 병징이 없던 포기에서 받은 종자 |
| 심기 | 줄 간격 20-25cm, 깊이 2-3cm. 복토 후 발이나 널판으로 눌러 줌(발아율이 크게 오름). 흩어뿌림 후에는 갈퀴로 흙을 덮음 |

## 5. 물과 재배 관리, 병해충
| 시기 | 물 관리 |
|:---|:---|
| 파종-발아 | 마르지 않게 |
| 분얼기 | 자연 강수에 맡김 |
| 신장기, 출수·등숙기 | 가물면 보충 |
| 수확기 | 완전히 끊음. 비를 맞으면 쓰러지고 수발아 |
| 장마철 | 물을 빼는 것이 관리 |

> **귀리 농사에서 물 관리는 대개 물을 빼는 일입니다. 특히 수확기의 비가 가장 큰 손실 요인입니다.**

| 관리 | 내용 |
|:---|:---|
| 잡초 | 초기 생장이 느리므로 파종 전에 갈아 잡초를 묻고, 출현 후 2-3주에 1차 김매기. 분얼이 끝나면 귀리가 땅을 덮음. 야생 귀리가 가장 까다로움 |
| 도복 방지 | 질소를 표준량 이하로, 파종량 준수, 웃거름은 초장 20cm에, 짧고 단단한 품종, 배수. 쓰러진 뒤에는 할 수 있는 일이 많지 않음 |
| 월동 | 가을 파종은 서릿발에 뿌리가 들뜨므로 3월 초 언 땅이 녹을 때 포기를 밟아 눌러 줌 |
| 기타 | 이삭이 늘어져 새가 앉기 쉬우므로 실을 늘임. 귀리짚은 멀칭, 가축 깔짚, 사료, 퇴비로 씀 |

| 병해충 | 약 없이 하는 대응 |
|:---|:---|
| 붉은곰팡이병(개화·등숙기 다습, 이삭이 붉거나 분홍) | 배수와 통풍, 조기 수확, 병든 이삭 폐기 |
| 깜부기병(종자 전염) | 온탕침법, 건전 종자 선발, 병든 이삭 소각 |
| 잎반점병 | 파종량 준수, 시비 절제, 이병엽 제거 |
| 관녹병, 흰가루병 | 저항성 품종, 통풍 확보, 우유 희석액 |
| 멸강나방, 진딧물, 응애 | 손으로 잡기, 비눗물, 천적 보호, 물 뿌리기 |
| 조류, 들쥐 | 실 늘이기, 그물, 밭 주변 정리, 저장 용기 관리 |

> **이삭이 붉거나 분홍으로 변한 귀리는 씻어도, 삶아도 안전해지지 않습니다. 버리는 것이 유일한 방법입니다.**

&nbsp;&nbsp;&nbsp;방제의 핵심은 병이 도는 시기를 피하는 것입니다. 여름 장마를 피하는 것이 귀리 방제의 절반이며, 질소 절제, 통풍, 배수가 나머지입니다. 나무재와 마늘 우린 물도 씁니다.

| 증상 | 원인과 조치 |
|:---|:---|
| 전체가 누렇게 뜨고 포기가 작음 | 질소 결핍. 부숙 퇴비, 오줌 10배 희석액을 초장 20cm 무렵에 |
| 잎 가장자리가 타 들어감 | 칼륨 결핍. 나무재 |
| 잎맥 사이만 노랗고 잎맥은 녹색 | 마그네슘 결핍. 백운석 가루 |
| 새 잎이 하얗게 뜸 | 망간 또는 철 결핍. 나무재 과용 중단, 부엽토 |
| 잎끝이 회색으로 마름 | 구리 결핍(이탄토나 사질토). 퇴비 재료 다양화 |
| 잎만 무성하고 쓰러짐 | 질소 과잉. 질소를 끊음 |

## 6. 사이짓기와 윤작
| 궁합 | 작물 |
|:---|:---|
| 매우 좋음 | 콩, 팥, 동부(뒷그루, 질소 회복), 감자·고구마(뒷그루, 귀리의 타감물질이 선충 밀도를 낮춤) |
| 좋음 | 클로버·자운영(녹비와 사료 겸용), 6월에 거둔 자리의 여름 채소 |
| 보통 | 보리, 밀(재배법이 같으나 병해 공유) |
| 나쁨 | 귀리 연작(연작 내성은 있으나 병 밀도가 쌓임) |

&nbsp;&nbsp;&nbsp;1년차 귀리, 2년차 콩과, 3년차 감자 또는 뿌리채소, 4년차 귀리로 복귀합니다. 봄 귀리를 6월에 거둔 뒤에는 가을까지 넉 달이 남으므로 콩, 조, 여름 채소를 이어 심어 밭을 놀리지 않습니다.

## 7. 수확, 탈곡, 채종
| 단계 | 내용 |
|:---|:---|
| 시기 | 봄 재배 6월 상순-중순(장마 전에 끝냄), 가을 재배 11월 상순-중순(서리 전). 줄기와 잎이 누렇게 변하고 이삭이 늘어져 낟알이 아래를 향하며 손톱으로 눌러 자국이 남지 않을 때. 이삭을 흔들어 낟알이 떨어지면 즉시 벰 |
| 베기 | 낫으로 밑동 가까이에서 흔들지 않고 벰. 열 포기 남짓씩 묶어 밭에서 서로 기대어 세우고 며칠 뒤 헛간이나 처마 밑으로 옮김. 붉게 변한 이삭은 따로 골라 폐기 |
| 건조 | 예비 건조 2-4일(18-20%) → 걸어 말리기 1-2주(15-16%) → 탈곡 → 마무리 건조 → 13-14%. 지방이 많아 건조 온도는 낮게 |
| 판정 | 낟알을 깨물면 톡 갈라지며 가루가 남음, 두 손에 담아 흔들면 마른 낟알끼리 부딪는 맑은 소리, 병에 밀봉해 하루 두어 김이 서리지 않음 |
| 탈곡 | 멍석 위에서 도리깨나 막대로 두드리기, 자루 안에서 치기, 통 안에서 비비기. 쌀귀리는 쉬움 |
| 쭉정이 | 초속 2-4m의 꾸준한 바람에 흘리기, 부채질, 체 치기. 까락이 길면 손이나 발로 비벼 까락을 부러뜨린 뒤 날림 |

| 채종 | 기준 |
|:---|:---|
| 선발 | 출수기부터 밭을 돌며 표시. 병징이 없고 쓰러지지 않았으며 이삭이 큰 포기. 깜부기병이나 붉은곰팡이병이 보인 포기 제외. 출수 후 45일 이상 완전히 익힘 |
| 야생 귀리 | 까락이 길고 색이 짙은 알을 골라 냄. 섞이면 해마다 늘어남 |
| 보관 | 반드시 껍질째(도정하면 발아력과 수명이 급격히 떨어짐), 수분 12-13%, 10℃ 이하, 빛 완전 차단. 필요량의 두 배 |

&nbsp;&nbsp;&nbsp;귀리는 자가수정 작물이라 순계가 잘 유지됩니다. 귀리 종자는 다른 곡물보다 수명이 짧은 편이므로 묵은 종자는 심기 전에 발아 시험을 합니다.

## 8. 저장
&nbsp;&nbsp;&nbsp;저장성은 SS이지만, 지방이 많아 곰팡이, 벌레, 쥐 외에 산패가 네 번째 적입니다. 산패는 냄새로만 알 수 있습니다.

| 항목 | 기준 |
|:---|:---|
| 조건 | 수분 13-14%, 온도 15℃ 이하(낮을수록 좋음), 주변 습도 65% 이하, 빛과 산소 최대한 차단, 두 달마다 냄새 점검 |
| 형태 | 껍질째(3년 이상). 도정한 쌀귀리는 최대한 빨리 소비(수명이 절반 이하). 산패가 빠른 것부터 먹도록 소비 순서를 관리 |
| 용기 | 금속 통 3년 이상(빛과 산소를 함께 막음), 유리병 2-3년(어두운 곳이나 천으로 감쌈), 땅속 저장굴 2-3년, 두꺼운 비닐 1-2년, 마대 6개월 |

| 산패를 늦추는 방법 | 원리와 효과 |
|:---|:---|
| 껍질째 보관 | 껍질이 산소를 막음. 3년 대 6개월의 차이 |
| 볶아 두기 | 지방 분해 효소를 열로 죽임. 도정한 귀리도 몇 달 더 감 |
| 찌거나 데치기 | 효소를 죽임. 상업용 오트밀이 쓰는 방법 |
| 차광, 저온 | 10℃ 낮추면 반응이 절반으로 느려짐 |
| 소량씩 도정 | 한 달 먹을 만큼만 찧음 |

&nbsp;&nbsp;&nbsp;벌레 방제는 가득 채운 완전 밀폐가 가장 확실하고(산패도 함께 막음), 나무재 2-5%, 규조토 곡물 1kg에 1-3g, 고운 모래·황토, 숯, 한겨울에 며칠 바깥에 내놓기(저온)를 씁니다. 고온 처리는 지방이 많아 온도를 낮게 잡습니다.

## 9. 조리와 주의사항
| 조리 준비 | 방법 |
|:---|:---|
| 도정(겉귀리) | 절구 찧기, 물을 조금 뿌려 30분 둔 뒤 찧기, 약한 불에 볶아 껍질을 바삭하게 한 뒤 찧기(가장 잘 맞음). 한 번에 끝내려 하지 않고 5분마다 꺼내 키질. 겨는 버리지 않음 |
| 압맥 | 귀리를 먹는 가장 좋은 형태. 도정한 귀리를 10분 쪄서 밀대로 누르는 방법이 가장 좋고, 천에 싸 밀대·병·망치로 누르거나 평평한 돌 두 개 사이에서 눌러도 됨. 조리 시간이 통알의 3분의 1 이하 |
| 제분 | 볶은 뒤 빻으면 훨씬 덜 힘들고 산패도 늦어짐. 글루텐이 없어 반죽에 점성이 없음. 가루는 통알보다 훨씬 빨리 상함 |

| 조리 | 연료와 요령 |
|:---|:---|
| 불려서 그냥 | 압맥을 물이나 국물에 몇 시간 불림. 불 없이 먹을 수 있음 |
| 가루죽 | 가루를 물에 풀어 5분. 연료가 가장 적게 듦 |
| 압맥 죽 | 물을 붓고 5-10분. 가장 실용적 |
| 잔열 조리 | 10분 끓인 뒤 짚이나 담요로 감싸 40분. 연료를 절반 이하로 |
| 혼반 | 쌀이나 보리에 2-3할 섞음 |
| 통알 삶기 | 하룻밤 불려 40-60분. 연료가 가장 많이 듦 |

&nbsp;&nbsp;&nbsp;저장을 겸한 가공으로는 압맥(밀폐 2-3개월), 엿기름(밀폐 1년), 귀리 조청(서늘한 곳 1년), 귀리술, 발효 죽이 있습니다.

| 주의 | 내용 |
|:---|:---|
| 독성 | 일반적인 섭취량에서 없음 |
| 곰팡이가 핀 것 | 붉은곰팡이병의 독소는 가열해도 사라지지 않음. 전량 폐기하고 가축에게도 주지 않음 |
| 산패한 것 | 쩐내가 나고 쓴맛이 남. 지방 산화 산물은 해로우므로 먹지 않음 |
| 글루텐 | 귀리 자체는 글루텐이 없으나 밀과 교차 오염될 수 있음. 심한 민감자는 주의 |
| 과다 섭취 | 식이섬유가 많아 소화 불편. 서서히 양을 늘림 |

&nbsp;&nbsp;&nbsp;귀리 알곡은 말과 소의 좋은 사료이고, 귀리짚은 부드러워 조사료로 쓸 만하며, 풋귀리는 독성이 없어 가축에게 그대로 먹일 수 있습니다.

## 10. 연간 작업 일정
| 월 | 작업 |
|:---|:---|
| 1-2월 | 저장 곡물 점검(쩐내, 곰팡이 냄새), 종자 확인, 퇴비 뒤집기, 발아 시험, 봄 파종 준비 |
| 3월 | 봄 귀리 파종(상순-중순), 가을 파종분 답압. 하루라도 빨리 심는 것이 수량을 결정 |
| 4월 | 김매기, 야생 귀리 제거. 초기 한 달의 잡초 관리가 중요 |
| 5월 | 웃거름(초장 20cm), 출수, 병해 감시 |
| 6월 | 봄 귀리 수확, 건조, 탈곡. 장마 전에 끝냄 |
| 7월 | 저장 정리, 뒷그루 파종(콩·조), 고랭지 여름 파종 |
| 8월 | 가을 귀리 파종(중순-하순), 밭 준비 |
| 9-10월 | 가을 귀리 생육 관리, 김매기, 조생종 수확 시작 |
| 11월 | 가을 귀리 수확, 건조, 탈곡, 저장(수분 13-14% 확인 후 밀폐) |
| 12월 | 도정과 압맥(한두 달 먹을 만큼만), 저장 점검, 이듬해 계획 |

> **잊지 말아야 할 다섯 가지: 여름 회피, 해빙 직후의 파종, 초장 20cm의 웃거름, 비 예보 시 조기 수확, 껍질째 저장.**
