### 1-3. 強みをどう読むか

&nbsp;&nbsp;&nbsp;S以上がついた項目は、耐寒性、施設負担、貯蔵性、連作適応性、味、自家採種の六つです。その下のAは、施肥、水消費量、微量栄養素、防除自立度、無合成投入での収量維持率、韓国国内での普及度についています。最上位が集中しているわけではありませんが、底のない構造です。どんな条件でも大きく失敗しない作物です。

&nbsp;&nbsp;&nbsp;耐寒性Sがもっとも実質的な強みです。秋に播いて氷点下10℃で越冬するということは、韓国の中部以南では冬の畑を遊ばせなくてよいという意味です。災害時には、この意味は単なる生産量以上のものになります。冬を越す作物があれば、春に穀物がもっとも底をついたとき、つまりポリッコゲ（麦の収穫前の春の端境期）と呼ばれた時期に、いちばん先に収穫が得られます。1年分の食糧を一度に収穫して十二か月に分けて食べる仕組みよりも、春と秋の二度収穫が入る仕組みのほうがはるかに安全です。

&nbsp;&nbsp;&nbsp;日照Bは、モロコシやトウモロコシと比べると際立ちます。同じ40%遮光の条件で、C4作物が45%まで落ち込むとき、エンバクは88%を維持します。火山噴火、大規模な山火事、長引く曇天のような条件では、エンバクはほとんど唯一、平年並みに収穫できる穀物になります。穀物構成を組むときにC4とC3を混ぜておくべき理由がここにあります。

&nbsp;&nbsp;&nbsp;無合成投入での収量維持率Aも重要です。51.8%は、肥料なしでも平時の半分以上を収穫できるという意味です。ジャガイモが同じ条件で17.6%まで落ち込むのと比べると、三倍の差です。そのうえエンバクは酸性土壌によく耐え、石灰を入れられず土が酸性に傾いていく長期災害の状況で、ほかの麦類より長く持ちこたえます。

> **エンバクは最高の収穫を上げる作物ではなく、条件が悪化しても崩れにくい作物です。**

&nbsp;&nbsp;&nbsp;味Sも実戦で重みがあります。エンバクはにおいも食感もほとんど抵抗感がありません。同じ評価でモロコシとアワが食感のためにBにとどまったのとは対照的です。災害が数か月を超えて数年に及ぶと、食べること自体が苦役になりますが、そのときに食欲を保ってくれる穀物があることは、実質的な資産です。とりわけ子どもや高齢者のように粗い穀物を消化しにくい人にとって、エンバク粥はほとんど代替のきかない食べ物です。

### 1-4. 弱点をどう読むか

&nbsp;&nbsp;&nbsp;Eがついた項目がひとつもない点がまず目を引きます。もっとも低いのは永続性Dと非食用価値Dで、実質的な制約は、面積当たり熱量C、調理・加工C、収量安定性Cにあります。

&nbsp;&nbsp;&nbsp;面積当たり熱量Cがもっとも重い制約です。㎡あたり1,164kcalは自給ラインの0.44倍で、一人の1年分の熱量をエンバクだけでまかなうには、230㎡、70坪近くが必要です。トウモロコシの二倍を超える面積です。エンバクを熱量の中心に据える計画は、土地がよほど潤沢なときにだけ成り立ちます。

&nbsp;&nbsp;&nbsp;調理・加工Cは、品種によって大きく変わります。皮付きエンバクは殻が粒に固く付いているため必ず精白しなければならず、その精白がほかの穀物より厄介です。一方、裸エンバクは脱穀すると殻がひとりでに外れ、精白が要りません。道具がない災害状況を前提にすると、この違いは決定的で、品種選びでまず考慮すべき項目です。

&nbsp;&nbsp;&nbsp;評価表に直接は表れない弱点がさらに二つあります。一つ目は高温多湿への脆弱性です。温度適応幅Bは登熟期の10-22℃を意味しますが、これは韓国の夏の気温とまったく合いません。30℃を超えると生育に障害が出て、韓国の梅雨（チャンマ、6月下旬～7月）の多湿では赤かび病が広がります。そのため、エンバクの栽培は夏を避けて時期を決めることがほとんどすべてです。二つ目は脂質の含量です。3.8-6.9%と穀物のなかで高く、精白した後は酸敗が早く進みます。貯蔵性SSはあくまで殻付きの場合の話で、精白したエンバク米は3-6か月が限度です。

## 2. どんな植物か

### 2-1. 分類と原産地

&nbsp;&nbsp;&nbsp;エンバクはイネ科（Poaceae）エンバク属（Avena）の一年草です。オオムギ、コムギ、ライムギと同じ麦類に属します。原産地は西アジアからヨーロッパにかけての地域とされますが、エンバクの来歴はほかの穀物とは異なります。最初から人が選んで育てた作物ではなく、コムギ畑やオオムギ畑に紛れ込む雑草から出発しました。

&nbsp;&nbsp;&nbsp;その来歴がエンバクの性質を説明します。雑草だっただけに土を選ばず、酸性土壌に耐え、冷涼で湿った条件ではむしろ競争相手よりもよく育ちます。コムギが育たない北ヨーロッパや高山地帯でエンバクが主食になったのは、人が選んだというより、そこにエンバクだけが残ったからです。災害という条件がまさにそのような状況です。条件が悪化するほど、エンバクの相対的な位置は上がります。

&nbsp;&nbsp;&nbsp;エンバク属には野生のエンバク（Avena fatua）もあります。韓国の麦畑にも雑草として生え、栽培エンバクとそっくりです。野生エンバクは粒が熟すとひとりでに落ち、芒が長く、発芽が不規則です。採種のときに混入しないよう注意が必要です。

### 2-2. 形態

| 器官 | 特徴 |
|---|---|
| 葉 | 細長い線形です。葉鞘が茎を包み、表面は滑らかです |
| 茎 | まっすぐに立ち、中空です。高さは60-150cmです |
| 根 | ひげ根が浅く広く広がります |
| 花 | 円錐花序です。小穂が枝の先に一つずつ垂れ下がってつきます。自家受粉です |
| 果実 | 穎果です。皮付きエンバクは殻に包まれており、裸エンバクは殻が簡単に外れます |

&nbsp;&nbsp;&nbsp;エンバクの穂の形は、オオムギやコムギとはっきり異なります。オオムギとコムギは穂がひとつの太い塊をなしますが、エンバクは枝が四方に分かれ、その先ごとに粒が一つ二つぶら下がって垂れます。この構造は風通しがよく、穂にカビが生えにくいという利点がありますが、粒が熟すと揺れで落ちやすいという欠点もあります。収穫の時期を逃してはならない理由です。

&nbsp;&nbsp;&nbsp;茎が中空である点にも実務上の意味があります。軽くて折れやすいため、風雨で倒れやすいのです。収穫期に台風が一度通ると畑全体が倒れます。窒素を与えすぎず、播種量を守ることが、倒伏対策のほとんどすべてです。

### 2-3. 生育段階

| 段階 | 時期 | 主な生理 | 重要な養分 |
|---|---|---|---|
| 発芽・出芽期 | 播種から3週間 | 発芽して最初の葉が出ます | リン酸、窒素 |
| 分げつ期 | 出芽後3-6週間 | 側枝（分げつ）が分かれます。株数が決まります | 窒素 |
| 伸長期 | 分げつ後4-6週間 | 茎が急激に伸びます | 窒素、カリウム |
| 出穂期 | 播種後60-80日 | 穂が出ます | リン酸、カリウム |
| 登熟・成熟期 | 出穂後30-40日 | 粒にデンプンが充実します | カリウム |

> **エンバクは栽培期間が短いため、初期の養分供給が収穫を決めます。追肥が遅れると、回復する時間がありません。**

&nbsp;&nbsp;&nbsp;エンバク栽培でもっともよくある失敗は、追肥の時期を逃すことです。生育期間が75日から110日と短いため、分げつ期を過ぎてから肥料を与えても、すでに株数が決まった後なので収量に反映されません。むしろ茎だけが徒長して倒れます。追肥の目安は日付ではなく草丈です。背丈が20cmほどになったときが適期です。

&nbsp;&nbsp;&nbsp;秋播きの場合、生育段階は冬をはさんで途切れます。秋に分げつまで済ませ、冬に止まり、春に伸長期から再開します。冬に入るときに分げつが十分に進んでいてこそ越冬率が高くなるので、秋播きは遅すぎてはいけません。

### 2-4. 100g当たりの栄養

| 栄養素 | 含量 | 備考 |
|---|:---:|---|
| 熱量 | 334-389kcal | 乾燥した子実を基準にした値です |
| 炭水化物 | 66.3-70.4g | β-グルカンがかなりの部分を占めます |
| タンパク質 | 9.9-14.3g | 品種と精白の程度によって異なります。玄米の二倍の水準です |
| 脂質 | 3.8-6.9g | 穀物のなかで最も高い部類です |
| 食物繊維 | 非常に豊富 | 水溶性のβ-グルカンが特徴です |
| カルシウム | 豊富 | 穀物としては高いほうです |
| 鉄 | 豊富 | 貧血の予防に寄与します |
| ビタミンB群 | チアミン、リボフラビン、B6、パントテン酸、葉酸 | 胚芽に集中しています |
| ビタミンE | 含有 | 脂質と共存しているため酸敗を遅らせます |

&nbsp;&nbsp;&nbsp;エンバクの特徴は脂質にあります。穀物のなかで脂質含量がもっとも高い部類で、これが両刃の剣として働きます。よい面は、熱量密度が高く、油気がほとんど消えた災害時の食事で脂質を供給する数少ない穀物になることです。脂質は単なる熱量ではなく、脂溶性ビタミンの吸収やホルモンの合成に必要な成分なので、長期災害ではその不足が徐々に体に現れます。悪い面は酸敗です。精白して胚芽が露出すると、脂質が酸素と出会い、数か月で酸敗臭がしてきます。

&nbsp;&nbsp;&nbsp;β-グルカンはエンバク特有の水溶性食物繊維です。水に溶けると粘りが出て粥がとろりとしますが、この粘りが満腹感を長く保ち、血糖値の上昇を緩やかにします。食糧が足りず一日二食でしのがなければならない状況で、この性質は実質的な助けになります。同じ熱量を食べても、空腹が遅く来ます。

&nbsp;&nbsp;&nbsp;タンパク質も穀物のなかでは上位です。ただし熱量比に換算すると10.2%で、要求ラインをかろうじて超える水準なので、アワやモロコシよりは低くなります。穀物に共通の限界としてリシンが不足しているため、豆類と一緒に食べてはじめてアミノ酸の組成が整います。
