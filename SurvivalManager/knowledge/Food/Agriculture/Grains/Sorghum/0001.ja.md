## はじめに
&nbsp;&nbsp;&nbsp;モロコシ(Sorghum bicolor)は、アフリカ北東部、今日のエチオピアとスーダンの一帯から来た穀物です。乾季が長く、土が浅くて養分が少なく、日中の気温が40℃を超える土地で5,000年以上、人を養ってきた作物なので、水が足りなければ葉を巻いて蒸散を減らし、もっと足りなければ生長を止め、雨が降れば再び伸びます。水は総蒸発散量250mmで足り、トウモロコシの半分以下です。肥料は窒素・リン酸・カリウムを合わせて1㎡当たり18gで足り、トウモロコシの半分強です。イネ科なので連作しても崩れず、乾燥した粒は常温で3年以上もちます。肥料がなくても平年収量の45%を保つので、物流が途絶え、肥料工場が止まり、畑に水を引けなくなった状況では、モロコシは2年目から真価を発揮します。弱点は4つです。面積当たりの熱量は1㎡当たり1,309kcalで、1人の1年分の熱量に約200㎡が必要です。40%遮光しただけで収量が半分を下回るほど日陰に弱いです。霜が1度降りただけで枯れます。そして、必ず精白してタンニンを洗い流さなければ食べられません。穀物を失うのはたいてい畑ではなく倉庫なので、モロコシは育てるより貯蔵するほうが難しい穀物です。

## 2. 植物の概要
&nbsp;&nbsp;&nbsp;イネ科モロコシ属の一年草です。葉は細長い線形で、表面のろう質の層が水分の蒸発を減らします。茎は直立して中が詰まっており、高さ80-120cm(品種によっては3m以上)です。繊維状の根が深く密に伸びます。花は茎の先に円錐花序でつき、1つの穂に粒が1,000-3,000個実ります。果実は穎果で、もち性とうるち性に分かれます。

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 発芽・幼苗期 | 播種後3週間 | リン酸、窒素 |
| 栄養生長期 | 3-6週 | 窒素 |
| 出穂期 | 6-8週 | リン酸、カリウム |
| 開花・結実期 | 8-10週 | カリウム |
| 登熟・成熟期 | 10-14週 | カリウム |

> **干ばつに耐えるモロコシも、出穂期と開花期だけは違います。この2週間に水が途切れると、穂は出ても粒がつかず、空の穂になります。**

| 100g当たりの栄養 | 含量 |
|:---|:---|
| 熱量 | 358-374kcal(乾燥した粒) |
| 炭水化物 | 74-79.3g(ほとんどがデンプン) |
| タンパク質 | 11-11.8g(米より明らかに高い) |
| 脂肪 | 2-3.5g(エンバクより少なく、酸敗の危険が低い) |
| その他 | 食物繊維6.6g、鉄4.4mg、マグネシウム165mg、ビタミンB群、ポリフェノール・タンニン。グルテンなし |

## 3. 栽培環境と品種
| 条件 | 最適 | 限界と影響 |
|:---|:---|:---|
| 生育温度 | 25-30℃ | 12-48℃。12℃を下回ると生長が止まり、0℃で枯れる |
| 発芽 | 21-35℃ | 最低15℃。それを下回ると発芽が遅れ、種子が腐る |
| 光 | 日中の強い日差し | C4作物。40%遮光で相対収量45%(エンバクのようなC3の穀類は88%) |
| 水 | 合計250mm前後 | 150-400mm。極端な干ばつには生長を止めて耐える |
| 土壌 | 砂壌土-埴壌土 | ほとんどの土性。pH 5.5-7.5(5.0-8.5)。水がたまる粘土質では根が傷む |

&nbsp;&nbsp;&nbsp;場所を選ぶときは、水よりも日当たりを先に見ます。南向きの緩斜面が最もよく、平地の畑は畝を高くすれば使えます。砂利の多いやせ地でも実ります。水田から転換した畑は、排水層を壊して畝を高く立てる必要があり、建物や大きな木の日陰、北向きの斜面、谷底(日照が短く、霜が早く降りる)は不向きです。

| 区分 | 特徴 | 災害の観点 |
|:---|:---|:---|
| もち性モロコシ | 胚乳デンプンはアミロペクチン90-100%。粘りがあって軟らかい。混ぜご飯、餅、酒 | ご飯に混ぜやすく、抵抗感が少ない。韓国に普及した品種の大半 |
| うるち性モロコシ | アミロース22-24%。ぱさぱさしている。ご飯、粥、粉 | 粉に挽いて使うのに向く |

| 品種 | 草丈 | 収量(kg/1,000㎡) | 特徴 |
|:---|:---|:---:|:---|
| ミリャン15号 | 中 | 484 | 韓国で最高の収量。機械収穫ができる草型 |
| コウンチャル | 約100cm | 374 | 倒れにくく、穂かび病を避けるのに有利 |
| ソダムチャル | 91-117cm | 296 | 赤褐色の粒。抗酸化活性が高く、倒伏に強い |
| チュンモ(もち性) | 88cm | - | 最も短い短稈種。白い粒。風の被害が少ない |
| ナムプンチャル(ミリャン4号) | 中 | - | 中生のもち性モロコシ。耐倒伏性、耐災害性、多収 |

&nbsp;&nbsp;&nbsp;収量が目的ならミリャン15号、人手が足りなければソダムチャル・コウンチャル、風の強い場所ならチュンモ・ソダムチャル、霜が早い場所なら早生系です。災害が長引くほど、収量よりも、自家採種で受け継いでいける在来種が重要になります。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 土づくり | 20-30cmの深さに耕し、土塊を砕いてならす(粒が小さく、土塊の間に落ちると発芽しない)。畑の周囲と畝間に排水溝、畝の高さ15-20cm |
| 施肥(1,000㎡当たり) | 堆肥1,000-1,500kg、窒素10-15kg(元肥50%、追肥50%)、リン酸5kg、カリウム4.5kg。堆肥・リン酸・カリウムは全量元肥 |
| 時期 | 元肥は播種の1-2週間前、追肥は5-10葉期に間引きと土寄せを兼ねて |
| 代替資源 | 木灰20-40kg(広葉樹の灰)、腐熟堆肥(3-6か月)、尿の10倍希釈液(畝間に流す。収穫の3週間前から中止)、骨粉、マメ科の緑肥(すき込んで2-3週間後に播種) |

> **モロコシに窒素をさらに与えると、背ばかり伸びて倒れます。肥料が豊富でも、標準量を超えないほうが収穫には有利です。**

| 地域・作型 | 播種 |
|:---|:---|
| 中部地方 | 5月中旬-6月上旬 |
| 南部地方 | 5月上旬-中旬 |
| ムギ類の後作 | 6月中旬-下旬 |

&nbsp;&nbsp;&nbsp;災害時には、一度にすべてをまかず、2週間おきに分けてまきます。

| 播種 | 基準 |
|:---|:---|
| 種子の選別 | 塩水(水1Lに塩51g、比重1.035)に入れてかき混ぜ、沈んだものだけを使う。秤がなければ、生卵が浮く濃度 |
| 消毒 | 50-55℃の湯に10-15分(60℃を超えると胚が死ぬ)、細かい木灰をまぶす、木酢液500倍に6-12時間、播種の2-3日前に日光に2-3時間 |
| 播き方 | 1,000㎡当たり1-2kg、深さ2-5cm。1条植えは条間60cm、株間20cm、1株7-8粒。2条植えは畝幅110cm、条間30cm、株間15cm |
| 移植 | 128穴トレーに1穴2-3粒、育苗15-20日。前作の終わりが遅いとき |
| 仕上げ | 覆土後に足で踏むか板で押さえる(発芽率が大きく上がる。干ばつが予想されるときに特に効果的) |

## 5. 水と栽培管理、病害虫
| 時期 | 水管理 |
|:---|:---|
| 播種-発芽 | 土が乾かないように保つ |
| 幼苗期 | 灌水は不要(根を深く伸ばすよう促す) |
| 栄養生長期 | 自然の降水に任せる。1か月乾いても枯れない |
| 出穂期-開花期 | 乾燥したら必ず水を与える。この2週間が収量を決める |
| 登熟期 | 徐々に減らす |
| 成熟期 | 完全に止める。水が多いと収穫後の乾燥が難しい |

&nbsp;&nbsp;&nbsp;日中に葉が巻くのは正常な防御反応で、朝にも巻いたままなら実質的な干ばつです。下の葉から黄色く枯れ上がるのは長期の干ばつで、穂が出たのに粒が空なのは、出穂・開花期の水不足であり、回復できません。葉が黄色くなり根が黒いのは過湿なので、すぐに排水溝を掘り、株元が柔らかくなって倒れるのは根腐れです。

| 管理 | 内容 |
|:---|:---|
| 間引き | 本葉3-4枚で弱い株を抜き、5-10葉期に最も充実した1-2本だけを残す。抜いた幼苗は家畜の飼料か堆肥にするが、青酸配糖体が多いので大量には与えない |
| 除草 | 雑草が指の長さのときに始め、最後は膝の高さのとき。播種後30-45日が山場で、その後はモロコシが雑草を覆う |
| 土寄せ | 間引きと同時に、その後もう1回。新しい根を出させ、倒伏を防ぐ |
| 倒伏 | 標準量以上の窒素を与えない、土寄せをしっかり行う、短稈種を選ぶ。倒れた後は3、4株ずつひもで束ねて立てる |
| 株出し栽培 | 最初の収穫で株元を10-15cm残して刈ると、新しい茎が伸びて、半分ほどの2回目の収穫ができる。霜の前に登熟を終えられる南部で、最初の収穫が8月中に終わるときだけ可能 |
| 鳥 | 穂が実るころ(3週間)から、ネット、紙袋や古い布をかぶせる、糸を張る。守れないと収穫の3分の1が失われることもある |

| 病害虫 | 薬を使わない対応 |
|:---|:---|
| 穂かび病(登熟期に雨が多いとき、穂が黒またはピンク) | 早生種、早めの収穫、すぐに乾燥、病んだ穂の廃棄 |
| 粒黒穂病(種子伝染) | 塩水選、木灰をまぶす、温湯浸法、病んだ穂の焼却 |
| 炭疽病、紋枯病、茎腐病 | 通風と株間の確保、輪作、排水の改善、病葉の除去、窒素過多を避ける、木酢液 |
| アブラムシ、ハダニ | 石けん水(水1Lに純石けん5-10g、朝か夕方に)、テントウムシ・クサカゲロウの保護 |
| アワノメイガなどの蛾、アワヨトウ | 被害茎の除去・焼却、手で捕る、収穫後の刈り株の処理、ひどければ早めに収穫 |
| カメムシ | 早朝に手で捕る、周辺の雑草の除去 |

> **カビの生えた穀物は、洗っても、ゆでても、炒っても安全にはなりません。捨てるのが唯一の方法です。**

&nbsp;&nbsp;&nbsp;最も危険な病気は穂かび病で、予防はすべて乾燥にかかっています。病んだ株から種を採らず、病気が広がる時期を避けて播種と収穫を行い、病んだ残渣と刈り株は畑から片づけます。木灰(露の降りた朝)、木酢液の500-1,000倍、タバコの葉やトウガラシの浸出液も使います。

| 症状 | 原因と対応 |
|:---|:---|
| 下の葉から黄色くなり、背が低い | 窒素欠乏。腐熟堆肥、尿の10倍希釈液 |
| 葉の縁が焼けたように褐変 | カリウム欠乏。木灰 |
| 生育が遅く、葉が黒みを帯びた濃い青緑 | リン酸欠乏。骨粉を堆肥に混ぜる |
| 葉脈の間だけ黄色く、葉脈は緑 | マグネシウム欠乏。ドロマイト粉末 |
| 新しい葉が白くなる | 鉄欠乏(アルカリ過多)。木灰を中止し、腐葉土 |
| 背ばかり高く、葉が濃く、倒れる | 窒素過剰。窒素を断ち、土寄せで支える |

## 6. 間作と輪作
| 相性 | 作物 |
|:---|:---|
| 非常によい | ダイズ、アズキ、ササゲ(根粒菌が固定した窒素を分けてくれる。混植するときは間隔を広めに) |
| よい | ラッカセイ、カボチャ(地面を覆って蒸発と雑草を減らす)、ジャガイモ(生育時期がずれる) |
| 後作によい | オオムギ、コムギ(モロコシのアレロパシー物質が雑草を減らした畑) |
| 悪い | トウモロコシ、アワ、キビ(同じイネ科で病害虫を共有し、養分の競合が大きい) |

&nbsp;&nbsp;&nbsp;1年目モロコシ、2年目マメ科、3年目葉菜類か根菜類を経て、4年目にモロコシへ戻ります。モロコシは連作に耐えますが、病気の密度は積み上がります。

## 7. 収穫、乾燥、脱穀、採種
| 段階 | 内容 |
|:---|:---|
| 時期 | 播種後120-150日。穂が品種固有の色に濃くなり、粒を割ると中が白くて硬く、粒の基部に黒い点(黒色層)ができ、下の葉が枯れて茎が黄色くなるとき。登熟期に雨が続くなら、完熟を待たずに刈る |
| 刈り取り | 晴れた日の露が乾いた後、穂の下20-30cmで鎌で刈る。病んだ穂と健全な穂はその場で分ける。穂6、7本を1束にくくり、雨の当たらない場所に逆さにつるす |
| 乾燥 | 予備乾燥2-3日(20%前後) → 軒下につるして1-2週(15-16%) → むしろに広げて日に干す2-4日 → 13-14% |
| 水分の確認 | 粒をかむと、ぱきっと割れて粉が出れば13-14%。両手に入れて振ると小石がぶつかる音がし、瓶に半分入れて密封して1日ほどたっても曇らなければ合格 |
| 脱穀 | 手でしごく(種子用)、むしろの上で棒や殻竿でたたく、袋の中でたたく、むしろに広げて足でもむ、溝を彫った板にこする、桶の中でもむ |
| しいな・くずの除去 | 秒速2-4mの安定した風に飛ばす、箕でふるう、うちわなどであおぐ、篩にかける(粗い篩でしいな、細かい篩でほこりと小粒) |

| 採種 | 基準 |
|:---|:---|
| 選抜 | 登熟期に畑を回って印をつける。病徴がなく、倒れておらず、穂が充実した株の、太くそろった主穂。粒黒穂病が出た株は除く |
| 隔離 | 他殖率が5-10%あるので、ほかの品種から離す。畑が狭ければ、開花時期をずらして植える |
| 保管 | 殻のまま、水分12-13%、10℃以下、光を完全に遮断、密閉容器。常温の密閉で2-3年。食用の穀物とは別に置く |
| 発芽試験 | 湿らせた布に粒20個を包み、5日置く。16個以上ならそのまま、12-15個なら播種量を増やし、10個未満なら新しい種子 |

## 8. 貯蔵
&nbsp;&nbsp;&nbsp;貯蔵性はSSですが、敵は3つあります。カビ(水分15%以上、変質と毒素で全量廃棄)、虫(20℃以上、水分12%以上)、ネズミ(近づける容器)で、1つが崩れると残りも続いて崩れるので、同時に防がなければなりません。

| 項目 | 基準 |
|:---|:---|
| 条件 | 水分13-14%、温度15℃以下(25℃を超えると虫が早く繁殖)、周囲の湿度65%以下、光の遮断、2か月に1回点検 |
| 形態 | 殻のまま(3年)。精白したモロコシ米は6か月もたない。1か月分だけ搗く |
| 容器 | ガラス瓶・金属缶3年以上、かめ2-3年(口を和紙か布でおおい、ふたをのせて粘土で縁を封じる)、地下貯蔵穴2-3年以上、厚手のビニール1-2年、かます・麻袋6か月-1年 |

> **穀物は殻のまま貯蔵し、食べる分だけ精白します。殻は自然がくれた包装材です。**

&nbsp;&nbsp;&nbsp;虫の防除は、いっぱいに詰めた完全密閉が最も確実で、木灰(細かい灰を穀物の体積の2-5%)、珪藻土(穀物1kgに1-3g)、細かい砂・黄土、乾燥した塩、炭、乾燥トウガラシ・サンショウ、ヨモギ・ショウブの葉も使います。真冬に数日外に出しておく(低温)か、日向に薄く広げて数時間置く(60℃、種子用は除く)方法もあります。灰と珪藻土は穀物が湿っていると効果がなくなるので、乾燥が先です。穀物の表面に粉やクモの巣のような糸が見えたらノシメマダラメイガなので、全量を日に干して篩い分けます。

## 9. 調理と注意事項
| 調理の準備 | 方法 |
|:---|:---|
| 精白 | 臼に乾燥した粒を入れて搗き、5-10分ごとに取り出して箕であおいでぬかを飛ばす。搗く前に水を少しふりかけて30分置くと、殻がむけやすく、粒が割れにくい。石臼は上の石を少し浮かせて回す。足踏み式の杵つきは、はるかに楽。ぬかは捨てない |
| タンニンの除去 | 精白した粒をたっぷりの水でもみ洗いして濁った水を捨てることを3、4回繰り返し、最後に30分から一晩浸して、その水を捨てる。渋みがほとんどなくなる |
| 製粉 | 石臼が最も細かく、臼は粗い。炒ってから搗くと、はるかに楽。粉は粒よりはるかに早く傷む |

| 調理 | 燃料とコツ |
|:---|:---|
| モロコシ飯 | 水に30分以上浸してから炊く(浸さないと中が生煮えで、燃料だけ使う) |
| 混ぜご飯 | 米やほかの穀物に2-3割混ぜる。抵抗感が少ない |
| 粥 | 粉を水に溶いて10分。燃料が最も少なくてすむ |
| 灰の中で焼く | 生地の塊を、ほかの調理を終えたかまどの熱い灰に埋める |

&nbsp;&nbsp;&nbsp;貯蔵を兼ねる加工には、炒り粉(ミッスッカル、密閉で6か月)、モロコシ水あめ(麦芽で糖化して煮詰める、涼しい場所で1年)、発酵生地(2-3日、タンニンが減って吸収がよくなる)、モロコシ酒、ポン菓子(密閉で1-2か月)があります。甘いモロコシを一緒に植えたなら、茎をつぶして汁を搾り、長く煮詰めてシロップを得ます。

| 注意 | 内容 |
|:---|:---|
| 青酸配糖体(ドゥリン) | 乾燥した粒にはほとんどなく安全。若い葉や芽、干ばつの後に再び伸びた葉、霜に当たった直後の葉(1週間は禁止)、株出しで再び出た若い茎(膝の高さを超えてから使う)に多いので、人にも家畜にも与えない。十分に育った茎と葉は、乾燥させるかサイレージにするとより安全 |
| タンニン | 外皮と種皮に集中し、赤褐色の系統に多い。渋みを出し、タンパク質と鉄の吸収を妨げるが、抗酸化作用や、鳥・カビの被害を減らす利点もある |
| カビ毒 | 200℃以上でもかなり残るので、ゆでる、炒める、蒸すだけでは除けない。カビが見える、またはにおう穀物は廃棄し、堆肥の山に入れて分解させる |

## 10. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵穀物の点検(結露、カビのにおい)、種子の確認と発芽試験、堆肥の切り返し、道具の手入れ |
| 3-4月 | 木灰を集める、堆肥の仕上げ、耕起、排水溝と深い畝間、元肥 |
| 5月 | 塩水選、種子消毒、播種(中部は中旬から)。2週間おきに分けてまくと、収穫期が分散する |
| 6月 | 残りの播種、1回目の間引き、除草。初期1か月の雑草管理が収量を左右する |
| 7月 | 2回目の間引き、追肥、土寄せ、出穂開始。乾燥したら必ず水を引く |
| 8月 | 開花と登熟、鳥追い、病害の監視 |
| 9月 | 収穫開始、予備乾燥、つるして乾燥。雨の知らせがあれば完熟を待たない |
| 10月 | 収穫の仕上げ、脱穀、仕上げの乾燥、貯蔵(水分13-14%を確認してから密閉) |
| 11-12月 | 種子の選別と別保管、刈り株を片づけて蛾の越冬場所をなくす、1か月分だけ精白と製粉 |

> **忘れてはならない5つのこと: 最も日当たりのよい場所、畝間と排水、標準量を超えない窒素、水分13-14%までの乾燥、殻のままの貯蔵。**
