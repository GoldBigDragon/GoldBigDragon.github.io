## 들어가며
&nbsp;&nbsp;&nbsp;수수(Sorghum bicolor)는 아프리카 동북부, 오늘날의 에티오피아와 수단 일대에서 온 곡물입니다. 건기가 길고 흙이 얕고 양분이 적으며 한낮 기온이 40℃를 넘나드는 땅에서 오천 년 넘게 사람을 먹여 온 작물이라, 물이 모자라면 잎을 말아 증산을 줄이고 더 모자라면 생장을 멈추었다가 비가 오면 다시 자랍니다. 물은 총 증발산량 250mm면 되어 옥수수의 절반 이하이고, 거름은 질소·인산·칼륨을 합쳐 ㎡당 18g이면 되어 옥수수의 절반 남짓이며, 벼과라 연작해도 무너지지 않고, 말린 알곡은 상온에서 3년 넘게 버팁니다. 비료 없이도 평시 수량의 45%를 유지하므로, 물류가 끊기고 비료 공장이 멈추고 밭에 물을 댈 수 없게 된 상황에서 수수는 둘째 해부터 진가를 냅니다. 약점은 네 가지입니다. 면적당 열량이 ㎡당 1,309kcal라서 한 사람의 일 년치 열량에 약 200㎡가 필요하고, 40%만 가려도 수량이 절반 아래로 떨어질 만큼 그늘에 약하며, 서리 한 번에 죽고, 반드시 도정하고 탄닌을 씻어 내야 먹을 수 있습니다. 곡식을 잃는 자리는 대개 밭이 아니라 창고이므로, 수수는 기르기보다 갈무리하기가 어려운 곡물입니다.

## 1. 재난 대비 평가
| 구분 | 등급 | 점수 |
|:---|:---:|:---:|
| 종합 | A | 50.2 |
| 단기 | B | 48.1 |
| 장기 | S | 52.5 |
| 부식 | SS | 57.8 |

| 평가 | 항목 |
|:---|:---|
| 강점 (S 이상) | 물 소비량, 시설물 부담, 저장성, 연작 적응성(SS), 자가 채종 |
| 강점 (A) | 시비(㎡당 18g), 방제 자립도 |
| 약점 | E: 태양광 반응(40% 차광 시 상대수량 45%), 내한성. D: 조리·가공(도정과 탄닌 제거), 수량 안정성 |

> **수수의 장점은 수확량이 아니라, 조건이 나빠져도 수량이 급격히 떨어지지 않는다는 점에 있습니다.**

&nbsp;&nbsp;&nbsp;항목별 등급은 재난 대비 작물 평가 결과 문서에 있습니다.

## 2. 식물 개요
&nbsp;&nbsp;&nbsp;벼과 수수속의 한해살이풀입니다. 잎은 좁고 긴 선형이며 표면의 왁스층이 수분 증발을 줄입니다. 줄기는 곧게 서며 속이 차 있고 높이 80-120cm(품종에 따라 3m 이상)입니다. 섬유상 뿌리가 깊고 촘촘하게 뻗습니다. 꽃은 줄기 끝에 원추화서로 달리고 한 이삭에 씨알이 1,000-3,000개 맺힙니다. 열매는 영과이며 찰수수와 메수수로 나뉩니다.

| 단계 | 시기 | 핵심 |
|:---|:---|:---|
| 발아·유묘기 | 파종 후 3주 | 인산, 질소 |
| 영양생장기 | 3-6주 | 질소 |
| 출수기 | 6-8주 | 인산, 칼륨 |
| 개화·결실기 | 8-10주 | 칼륨 |
| 등숙·성숙기 | 10-14주 | 칼륨 |

> **가뭄을 견디는 수수도 출수기와 개화기만은 다릅니다. 이 2주에 물이 끊기면 이삭이 나오고도 씨알이 앉지 않아 빈 이삭이 됩니다.**

| 100g당 영양 | 함량 |
|:---|:---|
| 열량 | 358-374kcal (마른 알곡) |
| 탄수화물 | 74-79.3g (대부분 전분) |
| 단백질 | 11-11.8g (쌀보다 눈에 띄게 높음) |
| 지방 | 2-3.5g (귀리보다 적어 산패 위험이 낮음) |
| 그 밖 | 식이섬유 6.6g, 철 4.4mg, 마그네슘 165mg, 비타민 B군, 폴리페놀·탄닌. 글루텐이 없음 |

## 3. 재배 환경과 품종
| 조건 | 최적 | 한계와 영향 |
|:---|:---|:---|
| 생육 기온 | 25-30℃ | 12-48℃. 12℃ 아래에서 생장이 멈추고 0℃에서 고사 |
| 발아 | 21-35℃ | 최저 15℃. 그 아래에서는 발아가 지연되고 종자가 썩음 |
| 빛 | 한낮의 강한 볕 | C4 작물. 40% 차광 시 상대수량 45%(귀리 같은 C3 곡류는 88%) |
| 물 | 총 250mm 안팎 | 150-400mm. 극심한 가뭄에는 생장을 멈추고 견딤 |
| 토양 | 사양토-식양토 | 거의 모든 토성. pH 5.5-7.5(5.0-8.5). 물이 고이는 점질토에서 뿌리가 상함 |

&nbsp;&nbsp;&nbsp;자리는 물보다 볕을 먼저 봅니다. 남향 완경사지가 가장 좋고, 평지 밭은 두둑을 높이면 됩니다. 자갈이 많은 척박지에서도 결실합니다. 논을 전환한 밭은 배수층을 깨고 두둑을 높이 세워야 하며, 건물이나 큰 나무 그늘, 북향 사면, 계곡 바닥(일조가 짧고 서리가 일찍 내림)은 부적합합니다.

| 구분 | 특징 | 재난 관점 |
|:---|:---|:---|
| 찰수수 | 배유 전분이 아밀로펙틴 90-100%. 차지고 부드러움. 혼반, 떡, 술 | 밥에 섞기 좋아 거부감이 적음. 국내 보급 품종 대부분 |
| 메수수 | 아밀로스 22-24%. 푸슬푸슬함. 밥, 죽, 가루 | 가루로 빻아 쓰기에 나음 |

| 품종 | 키 | 수량(kg/1,000㎡) | 특징 |
|:---|:---|:---:|:---|
| 밀양15호 | 중간 | 484 | 국내 최고 수량. 기계 수확이 가능한 초형 |
| 고은찰 | 약 100cm | 374 | 쓰러짐에 강하고 이삭곰팡이병 회피에 유리 |
| 소담찰 | 91-117cm | 296 | 적갈색 알곡. 항산화 활성이 높고 도복에 강함 |
| 중모찰수수 | 88cm | - | 가장 짧은 단간종. 백색 알곡. 바람 피해가 적음 |
| 남풍찰(밀양4호) | 중간 | - | 중생 찰수수. 내도복, 내재해, 다수성 |

&nbsp;&nbsp;&nbsp;수량이 목적이면 밀양15호, 일손이 부족하면 소담찰·고은찰, 바람이 센 곳은 중모찰수수·소담찰, 서리가 이른 곳은 조생 계열입니다. 재난이 길어질수록 수량보다 자가채종으로 이어 갈 수 있는 재래종이 중요해집니다.

## 4. 밭 준비와 파종
| 항목 | 기준 |
|:---|:---|
| 땅 만들기 | 20-30cm 깊이로 갈고 흙덩이를 부수어 고름(씨알이 작아 흙덩이 사이로 빠지면 발아하지 않음). 밭 둘레와 고랑에 배수로, 두둑 높이 15-20cm |
| 시비 (1,000㎡) | 퇴비 1,000-1,500kg, 질소 10-15kg(밑거름 50%, 웃거름 50%), 인산 5kg, 칼륨 4.5kg. 퇴비·인산·칼륨은 전량 밑거름 |
| 시기 | 밑거름은 파종 1-2주 전, 웃거름은 5-10엽기에 솎기와 북주기를 함께 |
| 대체 자원 | 나무재 20-40kg(활엽수 재), 부숙 퇴비(3-6개월), 오줌 10배 희석액(고랑에 흘림, 수확 3주 전부터 중단), 뼛가루, 콩과 녹비(갈아엎고 2-3주 뒤 파종) |

> **수수에 질소를 더 주면 키만 커지고 쓰러집니다. 거름이 넉넉해도 표준량을 넘기지 않는 편이 수확에는 유리합니다.**

| 지역·작형 | 파종 |
|:---|:---|
| 중부지방 | 5월 중순-6월 상순 |
| 남부지방 | 5월 상순-중순 |
| 맥류 뒷그루 | 6월 중하순 |

&nbsp;&nbsp;&nbsp;재난 상황에서는 한 번에 다 심지 않고 2주 간격으로 나누어 심습니다.

| 파종 | 기준 |
|:---|:---|
| 종자 선별 | 소금물(물 1L에 소금 51g, 비중 1.035)에 넣어 저은 뒤 가라앉은 것만 씀. 저울이 없으면 날달걀이 뜨는 농도 |
| 소독 | 50-55℃ 물에 10-15분(60℃를 넘기면 배가 죽음), 고운 나무재 묻히기, 목초액 500배에 6-12시간, 파종 2-3일 전 볕에 2-3시간 |
| 심기 | 1,000㎡당 1-2kg, 깊이 2-5cm. 1조식은 조간 60cm, 주간 20cm, 포기당 7-8립. 2조식은 이랑 폭 110cm, 조간 30cm, 주간 15cm |
| 이식 | 128구 트레이에 구멍당 2-3립, 육묘 15-20일. 앞그루가 늦게 끝날 때 |
| 마무리 | 복토 후 발로 밟거나 널판으로 눌러 줌(발아율이 크게 오름. 가뭄이 예상될 때 특히 효과적) |

## 5. 물과 재배 관리, 병해충
| 시기 | 물 관리 |
|:---|:---|
| 파종-발아 | 흙이 마르지 않게 유지 |
| 유묘기 | 관수가 필요 없음(뿌리를 깊이 내리도록 유도) |
| 영양생장기 | 자연 강수에 맡김. 한 달을 말라도 죽지 않음 |
| 출수기-개화기 | 가물면 반드시 물을 줌. 이 2주가 수량을 결정 |
| 등숙기 | 서서히 줄임 |
| 성숙기 | 완전히 끊음. 물이 많으면 수확 후 건조가 어려움 |

&nbsp;&nbsp;&nbsp;한낮에 잎이 말리는 것은 정상적인 방어 반응이고, 아침에도 말려 있으면 실질적인 가뭄입니다. 아래 잎부터 누렇게 마르면 장기 가뭄이고, 이삭이 나왔는데 씨알이 비어 있으면 출수·개화기의 수분 부족이라 회복할 수 없습니다. 잎이 노랗게 뜨고 뿌리가 검으면 과습이므로 즉시 배수로를 내고, 밑동이 물러져 쓰러지면 뿌리 부패입니다.

| 관리 | 내용 |
|:---|:---|
| 솎기 | 본잎 3-4매에 약한 개체를 뽑고, 5-10엽기에 가장 충실한 1-2본만 남김. 뽑은 어린 수수는 가축 먹이나 퇴비로 쓰되 청산 배당체가 많아 대량으로 먹이지 않음 |
| 김매기 | 잡초가 손가락 길이일 때 시작하고, 마지막은 무릎 높이일 때. 파종 후 30-45일이 고비이며, 그 뒤에는 수수가 잡초를 덮음 |
| 북주기 | 솎기와 동시에, 이후 한 차례 더. 새 뿌리를 내게 하고 도복을 막음 |
| 도복 | 표준량 이상의 질소를 주지 않고, 북주기를 충실히 하고, 단간종을 고름. 쓰러진 뒤에는 서너 포기씩 끈으로 묶어 세움 |
| 라투닝 | 첫 수확 때 밑동을 10-15cm 남기고 베면 새 줄기가 올라와 절반쯤의 두 번째 수확이 가능함. 서리 전에 등숙을 마칠 수 있는 남부에서, 첫 수확이 8월 안에 끝날 때만 가능 |
| 새 | 이삭이 여물 무렵(3주)부터 그물, 종이봉투나 헌 천 씌우기, 실 늘이기. 못 지키면 수확의 3분의 1이 사라지기도 함 |

| 병해충 | 약 없이 하는 대응 |
|:---|:---|
| 이삭곰팡이병(등숙기에 비가 잦을 때, 이삭이 검거나 분홍) | 조생종, 조기 수확, 즉시 건조, 병든 이삭 폐기 |
| 겉깜부기병(종자 전염) | 소금물 선별, 나무재 묻히기, 온탕침법, 병든 이삭 소각 |
| 탄저병, 잎집무늬마름병, 줄기썩음병 | 통풍과 재식 간격 확보, 윤작, 배수 개선, 병든 잎 제거, 질소 과다 피하기, 목초액 |
| 진딧물, 응애 | 비눗물(물 1L에 순비누 5-10g, 아침이나 저녁에), 무당벌레·풀잠자리 보호 |
| 조명나방 등 나방, 멸강나방 | 피해 줄기 제거·소각, 손으로 잡기, 수확 후 그루터기 처리, 심하면 조기 수확 |
| 노린재 | 이른 아침 손으로 잡기, 주변 잡초 제거 |

> **곰팡이가 핀 곡식은 씻어도, 삶아도, 볶아도 안전해지지 않습니다. 버리는 것이 유일한 방법입니다.**

&nbsp;&nbsp;&nbsp;가장 위험한 병은 이삭곰팡이병이고 예방은 전적으로 건조에 달려 있습니다. 병든 개체에서 씨를 받지 않고, 병이 도는 시기를 피해 심고 거두며, 병든 잔재와 그루터기는 밭에서 치웁니다. 나무재(이슬 맺힌 아침), 목초액 500-1,000배, 담뱃잎·고추 우린 물도 씁니다.

| 증상 | 원인과 대응 |
|:---|:---|
| 아래 잎부터 누렇게 뜨고 키가 작음 | 질소 결핍. 부숙 퇴비, 오줌 10배 희석액 |
| 잎 가장자리가 타들어 가듯 갈변 | 칼륨 결핍. 나무재 |
| 생육이 더디고 잎이 검푸름 | 인산 결핍. 뼛가루를 퇴비에 섞음 |
| 잎맥 사이만 노랗고 잎맥은 녹색 | 마그네슘 결핍. 백운석 가루 |
| 새 잎이 하얗게 뜸 | 철 결핍(알칼리 과다). 나무재 중단, 부엽토 |
| 키만 크고 잎이 짙으며 쓰러짐 | 질소 과잉. 질소를 끊고 북주기로 버팀 |

## 6. 사이짓기와 윤작
| 궁합 | 작물 |
|:---|:---|
| 매우 좋음 | 콩, 팥, 동부(뿌리혹박테리아가 고정한 질소를 나눠 줌. 섞어 심을 때는 간격을 넉넉히) |
| 좋음 | 땅콩, 호박(지면을 덮어 증발과 잡초를 줄임), 감자(생육 시기가 어긋남) |
| 뒷그루로 좋음 | 보리, 밀(수수의 타감물질이 잡초를 줄여 놓은 밭) |
| 나쁨 | 옥수수, 조, 기장(같은 벼과라 병해충을 공유하고 양분 경합이 큼) |

&nbsp;&nbsp;&nbsp;1년차 수수, 2년차 콩과, 3년차 잎채소나 뿌리채소를 거쳐 4년차에 수수로 복귀합니다. 수수는 연작 내성이 있지만 병 밀도는 쌓입니다.

## 7. 수확, 건조, 탈곡, 채종
| 단계 | 내용 |
|:---|:---|
| 시기 | 파종 후 120-150일. 이삭이 품종 고유의 색으로 짙어지고, 씨알을 갈라 보아 속이 희고 단단하며, 씨알 밑동에 검은 점(검은층)이 생기고, 아래 잎이 마르고 줄기가 누렇게 변할 때. 등숙기에 비가 이어지면 완숙을 기다리지 않고 벰 |
| 베기 | 맑은 날 이슬이 마른 뒤, 이삭 아래 20-30cm에서 낫으로 벰. 병든 이삭과 성한 이삭은 그 자리에서 나눔. 이삭 예닐곱을 한 다발로 묶어 비를 맞지 않는 곳에 거꾸로 매닮 |
| 건조 | 예비 건조 2-3일(20% 안팎) → 처마 밑에 걸어 말리기 1-2주(15-16%) → 멍석에 펴 볕에 말리기 2-4일 → 13-14% |
| 수분 확인 | 씨알을 깨물어 톡 갈라지며 가루가 나면 13-14%. 두 손에 담아 흔들어 자갈 부딪는 소리가 나고, 병에 반쯤 담아 밀봉해 하루 두어 김이 서리지 않으면 통과 |
| 탈곡 | 손으로 훑기(종자용), 멍석 위에서 막대나 도리깨로 두드리기, 자루 안에서 치기, 멍석에 펴 발로 비비기, 홈 판 널판에 문지르기, 통 안에서 비비기 |
| 쭉정이 날리기 | 초속 2-4m의 꾸준한 바람에 흘리기, 키질, 부채질, 체 치기(굵은 체로 쭉정이, 고운 체로 먼지와 잔알) |

| 채종 | 기준 |
|:---|:---|
| 선발 | 등숙기에 밭을 돌며 표시. 병징이 없고 쓰러지지 않았으며 이삭이 충실한 포기의 굵고 고른 주이삭. 겉깜부기병이 보인 포기는 제외 |
| 격리 | 타식률이 5-10%이므로 다른 품종과 떨어뜨림. 밭이 좁으면 개화 시기를 어긋나게 심음 |
| 보관 | 껍질째, 수분 12-13%, 10℃ 이하, 빛 완전 차단, 밀폐 용기. 상온 밀폐에서 2-3년. 식용 곡식과 따로 둠 |
| 발아 시험 | 젖은 천에 씨알 20개를 싸서 닷새 둠. 16개 이상이면 그대로, 12-15개면 파종량을 늘리고, 10개 아래면 새 종자 |

## 8. 저장
&nbsp;&nbsp;&nbsp;저장성은 SS이지만, 적은 셋입니다. 곰팡이(수분 15% 이상, 변질과 독소로 전량 폐기), 벌레(20℃ 이상, 수분 12% 이상), 쥐(접근 가능한 용기)이며, 하나가 무너지면 나머지가 따라 무너지므로 동시에 막아야 합니다.

| 항목 | 기준 |
|:---|:---|
| 조건 | 수분 13-14%, 온도 15℃ 이하(25℃가 넘으면 벌레가 빨리 번식), 주변 습도 65% 이하, 빛 차단, 두 달에 한 번 점검 |
| 형태 | 껍질째(3년). 도정한 수수쌀은 6개월을 넘기기 어려움. 한 달 먹을 만큼만 찧음 |
| 용기 | 유리병·금속 통 3년 이상, 항아리 2-3년(입구를 한지나 천으로 덮고 뚜껑을 얹어 진흙으로 봉함), 땅속 저장굴 2-3년 이상, 두꺼운 비닐 1-2년, 가마니·마대 6개월-1년 |

> **곡물은 껍질째 저장하고 먹을 만큼만 도정합니다. 껍질은 자연이 준 포장재입니다.**

&nbsp;&nbsp;&nbsp;벌레 방제는 가득 채운 완전 밀폐가 가장 확실하고, 나무재(고운 재를 곡물 부피의 2-5%), 규조토(곡물 1kg에 1-3g), 고운 모래·황토, 마른 소금, 숯, 말린 고추·산초, 쑥·창포 잎을 씁니다. 한겨울에 며칠 바깥에 내놓거나(저온), 볕에 얇게 펴 몇 시간 두는(60℃, 종자용 제외) 방법도 있습니다. 재와 규조토는 곡물이 눅눅하면 효과가 사라지므로 건조가 먼저입니다. 곡물 표면에 가루나 거미줄 같은 실이 보이면 화랑곡나방이므로 전량을 볕에 말려 걸러 냅니다.

## 9. 조리와 주의사항
| 조리 준비 | 방법 |
|:---|:---|
| 도정 | 절구에 마른 알곡을 넣고 찧어 5-10분마다 꺼내 키질로 겨를 날림. 찧기 전 물을 조금 뿌려 30분 두면 껍질이 잘 벗겨지고 알이 덜 깨짐. 맷돌은 위짝을 살짝 띄워 돌림. 디딜방아는 힘이 훨씬 덜 듦. 겨는 버리지 않음 |
| 탄닌 빼기 | 도정한 알을 넉넉한 물에 비벼 씻고 뿌연 물을 버리기를 서너 번, 마지막에 30분에서 하룻밤 담갔다 그 물을 버림. 떫은맛이 거의 사라짐 |
| 제분 | 맷돌이 가장 곱고, 절구는 굵음. 볶은 뒤 빻으면 훨씬 덜 힘듦. 가루는 알곡보다 훨씬 빨리 상함 |

| 조리 | 연료와 요령 |
|:---|:---|
| 수수밥 | 물에 30분 이상 불린 뒤 지음(불리지 않으면 속이 안 익고 연료만 먹음) |
| 혼반 | 쌀이나 다른 곡물에 2-3할 섞음. 거부감이 적음 |
| 죽 | 가루를 물에 풀어 10분. 연료가 가장 적게 듦 |
| 재 속 굽기 | 반죽 덩이를 다른 조리를 마친 화덕의 뜨거운 재에 묻음 |

&nbsp;&nbsp;&nbsp;저장을 겸한 가공에는 볶은 가루(미숫가루, 밀폐 6개월), 수수엿·조청(엿기름으로 삭혀 졸임, 서늘한 곳 1년), 발효 반죽(2-3일, 탄닌이 줄고 흡수가 좋아짐), 수수술, 튀밥(밀폐 1-2개월)이 있습니다. 단수수를 함께 심었다면 줄기를 짓이겨 즙을 짜 오래 졸여 시럽을 얻습니다.

| 주의 | 내용 |
|:---|:---|
| 청산 배당체(두린) | 마른 알곡에는 거의 없어 안전함. 어린 잎과 순, 가뭄 뒤 다시 자란 잎, 서리 맞은 직후의 잎(1주 금지), 라투닝으로 다시 난 어린 줄기(무릎 높이를 넘긴 뒤 사용)에 많아 사람도 가축도 먹이지 않음. 충분히 자란 줄기와 잎은 말리거나 사일리지로 만들면 더 안전함 |
| 탄닌 | 껍질과 종피에 집중, 적갈색 계열에 많음. 떫은맛을 내고 단백질·철 흡수를 방해하며, 항산화 작용과 새·곰팡이 피해를 줄이는 이점도 있음 |
| 곰팡이독소 | 200℃ 이상에서도 상당 부분 남아 삶고 볶고 찌는 것으로 없앨 수 없음. 곰팡이가 보이거나 냄새가 나는 곡식은 폐기하고, 퇴비 더미에 넣어 분해시킴 |

## 10. 연간 작업 일정
| 월 | 작업 |
|:---|:---|
| 1-2월 | 저장 곡물 점검(결로, 곰팡이 냄새), 종자 확인과 발아 시험, 퇴비 뒤집기, 도구 손질 |
| 3-4월 | 나무재 모으기, 퇴비 마무리, 밭갈이, 배수로와 깊은 고랑, 밑거름 |
| 5월 | 소금물 선별, 종자 소독, 파종(중부는 중순부터). 2주 간격으로 나누어 심으면 수확기가 분산됨 |
| 6월 | 남은 파종, 1차 솎기, 김매기. 초기 한 달의 잡초 관리가 수량을 좌우 |
| 7월 | 2차 솎기, 웃거름, 북주기, 출수 시작. 가물면 반드시 물을 댐 |
| 8월 | 개화와 등숙, 새 쫓기, 병해 감시 |
| 9월 | 수확 시작, 예비 건조, 걸어 말리기. 비 소식이 있으면 완숙을 기다리지 않음 |
| 10월 | 수확 마무리, 탈곡, 마무리 건조, 저장(수분 13-14% 확인 후 밀폐) |
| 11-12월 | 종자 선별과 별도 보관, 그루터기를 치워 나방 월동처 제거, 한 달 먹을 만큼만 도정과 제분 |

> **잊지 말아야 할 다섯 가지: 가장 볕 좋은 자리, 고랑과 배수, 표준량을 넘기지 않는 질소, 수분 13-14% 건조, 껍질째 저장.**
