## 12. 收获与脱粒

### 12-1. 判断时期

| 标准 | 内容 | 判定 |
|---|---|---|
| 天数 | 播种后120-150天 | 因品种和当年气温而异 |
| 穗的颜色 | 整个穗变深，呈品种固有的颜色 | 接近成熟 |
| 籽粒硬度 | 用指甲掐不留痕迹 | 完熟 |
| 籽粒断面 | 掰成两半，里面白而硬 | 灌浆完成 |
| 黑色层 | 籽粒基部出现黑点 | 生理成熟的可靠信号 |
| 叶片状态 | 下部叶片干枯，茎变黄 | 收获期 |
| 天气 | 连续晴天2-3天之后 | 含水量低，容易干燥 |

&nbsp;&nbsp;&nbsp;灌浆成熟按乳熟期、糊熟期、黄熟期、完熟期的顺序进行。乳熟期按压籽粒会流出牛奶般的汁液，糊熟期呈面糊状，到了黄熟期，要用指甲掐才勉强留下痕迹。收获适期是黄熟期末到完熟期初。再等下去，籽粒会脱落，鸟害增加，穗腐病的风险变大。

&nbsp;&nbsp;&nbsp;籽粒基部的黑色层（BlackLayer）是最可靠的信号。籽粒不再从茎秆获得养分时，其连接部位会形成黑色细胞层。看到这个之后，即使留在田里，籽粒也不会再长大。剩下的只是变干，而这个干燥放在屋檐下比放在田里更安全。

> **灌浆成熟期连续下雨时，不要等完全成熟，要割回来。损失百分之几的籽粒，比因穗腐病损失全部要好。**

### 12-2. 收获要领

| 顺序 | 内容 | 原因 |
|---|---|---|
| 1 | 选晴天上午，露水干了之后开始 | 湿穗是发霉的起点 |
| 2 | 在穗下20-30cm处用镰刀割下 | 留有秆柄，便于捆扎悬挂 |
| 3 | 要做再生栽培的田，留10-15cm茎基 | 茬桩上会长出新茎 |
| 4 | 割下的穗要当场把有病的和完好的分开 | 混放会传播霉菌 |
| 5 | 每六七个穗捆成一束 | 束太大里面干不了 |
| 6 | 倒挂在淋不到雨的地方 | 通风的姿势决定干燥效果 |

### 12-3. 谷物晾干 - 干到含水量13-14%

&nbsp;&nbsp;&nbsp;谷物贮藏的一切都取决于水分。含水量超过15%霉菌就会生长，降到13%以下，霉菌和害虫的活动几乎都停止。这两三个百分点之间，系着一年农事的命运。刚割下的高粱含水量为20-30%。把它降到13-14%，是收获后唯一也是最重要的任务。

| 阶段 | 方法 | 时间 | 达到的含水量 |
|---|---|---|---|
| 1. 预干燥 | 把割下的束立在田里或院子里 | 2-3天 | 20%左右 |
| 2. 悬挂晾干 | 倒挂在屋檐下或棚屋里 | 1-2周 | 15-16% |
| 3. 收尾干燥 | 摊在草席或布上晒干 | 2-4天 | 13-14% |
| 4. 静置 | 放在阴凉处一天，使水分均匀 | 1天 | 均一化 |

&nbsp;&nbsp;&nbsp;晒干时要注意几点。第一，不要直接摊在地上。从土里上来的湿气会把下层的谷物重新打湿。草席、布、木板，无论哪种，都要垫一层。第二，不要堆得太厚。不超过两个指节，即3-5cm，每天用耙子或手翻动三四次。第三，太阳偏西时就收起来或盖好。受了夜露，白天排出的水分又会回去。第四，不要在盛夏的烈日下急着晒。只有表面干了，里面的水分被封住，以后会发霉。

&nbsp;&nbsp;&nbsp;没有水分仪时，有估计含水量的方法。不需要工具，熟悉之后相当准确。

| 方法 | 步骤 | 判定 |
|---|---|---|
| 咬 | 用臼齿咬籽粒 | 啪地一声裂开并有粉末出来，就是13-14%。被压扁或变形，说明还是湿的 |
| 盐试验 | 把一勺干盐和一把谷物放进玻璃瓶，摇晃后放置15分钟 | 盐粘在瓶壁上或结块，说明含水量高 |
| 手感 | 抓一把再摊开 | 从手上像滑落一样散开，是干的。结成团，是湿的 |
| 声音 | 捧在两手中摇晃 | 发出像小石子碰撞的声音，是干的；声音发闷，是湿的 |
| 瓶试验 | 在玻璃瓶中装半瓶，密封放置一天 | 瓶子内侧出现雾气，说明还需要晾干 |

&nbsp;&nbsp;&nbsp;瓶试验尤为可靠。在密封的瓶中，谷物与空气达到水分平衡，含水量超过14%时，瓶内湿度超过70%，到了气温下降的凌晨就会起雾。适合在入库贮藏前作最后一次确认。如果是有凉爽夜晚的秋天，则显示得更明显。

&nbsp;&nbsp;&nbsp;也有连续下雨、用不上阳光的年份。这时就用火力。薄薄地摊在灶台或炉子上方的搁板、暖炕房间里离灶口最远的一侧地面上，几天就会干。不过温度不能超过50度。超过的话就不能当种子用，淀粉也会变质，饭味也变差。把手放上去觉得烫，就已经太高了。温热的程度才合适。

### 12-4. 脱粒 - 没有工具时的做法

&nbsp;&nbsp;&nbsp;高粱比水稻或大麦更容易脱粒。穗上的籽粒着生稀疏，充分干燥后轻轻一碰就会掉落。关键是干燥程度。没干透的穗，无论怎么敲，籽粒也不掉，只是被压烂。脱粒前，穗应当干到发出沙沙声的程度。

| 方法 | 步骤 | 规模 | 备注 |
|---|---|---|---|
| 手捋 | 握住穗柄，用戴手套的手向下捋 | 少量 | 损失最小。用于留种 |
| 敲打 | 把穗摊在草席上，用棍子或连枷敲打 | 中等 | 最常用 |
| 袋内摔打 | 把穗装进结实的袋子，连袋子一起往地面摔 | 中等 | 籽粒不会蹦散 |
| 踩踏 | 摊在草席上，用脚搓揉着踩 | 大量 | 比较省力。鞋底必须干净 |
| 搓衣板刮 | 把穗抵在有凹槽的板上摩擦 | 少量 | 用瓦楞板或刻了槽的木板代替 |
| 桶内搓揉 | 把穗放进大桶里，用棍子搅动搓揉 | 中等 | 手不容易疼 |

&nbsp;&nbsp;&nbsp;连枷可以自己做。在长柄的一端，用皮绳或结实的麻绳松松地吊上一根短棍即可。挥动长柄，末端的短棍就会转动着击打谷物。比单靠臂力敲打效率高三四倍，干一整天也不那么累。这是灾害情境下最先该做好的农具之一。

### 12-5. 扬去秕粒 - 风车与簸箕

&nbsp;&nbsp;&nbsp;脱下来的谷物里混有穗屑、碎粒和灰尘。就这样贮藏的话，秕粒上附带的水分和虫卵会毁掉整个仓库。必须用风来筛选。

| 方法 | 步骤 | 条件 |
|---|---|---|
| 顺风倾倒 | 在有风的日子从高处缓缓倒下。重的籽粒落在正下方，秕粒被吹到远处 | 每秒2-4m的稳定风 |
| 簸箕簸 | 装在簸箕里向上簸起再接住。反复进行，轻的就被推到前面 | 没有风也可以 |
| 扇风 | 一人缓缓倾倒，另一人用扇子或木板扇风 | 需要两个人 |
| 过筛 | 用粗筛筛出秕粒，用细筛筛出灰尘和碎粒 | 需要两种筛子 |

&nbsp;&nbsp;&nbsp;簸箕是灾害情境下可以自制的工具。把竹子或胡枝子劈开编织，或把薄胶合板只竖起三面做成，也能起作用。簸的要领不是上下抖动，而是向前推出再拉回，让谷物在空中短暂悬浮。悬浮期间，轻的落在后面，向前聚集。学会它半天就足够，一旦学会就是一生受用的技术。

## 13. 留种

### 13-1. 选择留种植株

| 标准 | 内容 | 原因 |
|---|---|---|
| 选择时期 | 灌浆成熟期在田里巡视，提前做好标记 | 收获后就分不清是哪一株的了 |
| 植株条件 | 无病症、未倒伏、穗饱满的 | 性状会传给下一代 |
| 穗的位置 | 植株上最粗壮整齐的主穗 | 侧穗成熟不均匀 |
| 收获时点 | 比一般收获稍晚，让其完全成熟 | 未成熟的种子发芽率下降 |
| 排除对象 | 出现过坚黑穗病的植株 | 会通过种子传染 |

&nbsp;&nbsp;&nbsp;高粱基本上是自花授粉，但异交率有5-10%。也就是说，100粒籽粒中有五到十粒接受了邻株的花粉。只种一个品种的话没有问题，但把糯高粱和粳高粱紧挨着种，几年内性状就会混杂。要保持品种，至少要隔开200m以上，或者把花期错开2周以上播种。

&nbsp;&nbsp;&nbsp;现实中田地狭小、难以隔离时，还有别的办法。对选定作留种的植株，在开花前给穗套上纸袋或稀疏的布。高粱以自花授粉为主，所以在袋子里也能正常结实。只要这样管理两三个穗，来年就能保持纯正的种子品系。

### 13-2. 种子保存

| 条件 | 标准 | 原因 |
|---|---|---|
| 含水量 | 12-13%。比食用的稍干一些 | 种子含水量越低寿命越长 |
| 温度 | 低而稳定。10℃以下最理想 | 温度高，胚会因呼吸而消耗 |
| 容器 | 玻璃瓶、金属桶、陶罐等密封容器 | 同时防潮和防虫 |
| 光 | 完全避光 | 光和热会降低发芽力 |
| 形态 | 带壳保存 | 碾制过的寿命要短得多 |
| 寿命 | 常温密封2-3年 | 条件好的话，4-5年也能发芽 |

&nbsp;&nbsp;&nbsp;种子必须与食用粮食分开存放。冬深了、吃的减少时，人就会去动种子，一旦动手，来年就没有庄稼了。把它们放在物理上不同的地方、不同的容器里，并在外面做上标记，比相信人的判断力更可靠。所需种子量为每1,000㎡ 1-2kg，所以留出实际所需量的两倍左右就足够了。

### 13-3. 发芽试验

&nbsp;&nbsp;&nbsp;播种陈种子之前，必须确认发芽力。把二十粒籽粒包在湿布里，放在温暖处，等五天。数一数有几粒发芽，二十粒中十六粒以上的可以照常使用，十二至十五粒的要增加播种量，不足十粒的就必须另找新种子。这个简单的试验，可以避免一整年的农事全部落空。

## 14. 毒性与注意事项

### 14-1. 氰苷 - 叶片与幼嫩茎秆

&nbsp;&nbsp;&nbsp;高粱有一种需要了解的毒性。问题不在籽粒，而在叶片和幼嫩茎秆。高粱的叶片中含有名为蜀黍氰苷（dhurrin）的氰苷，植物组织受损时，酶发生作用，生成氢氰酸（氰化氢）。

| 条件 | 危险度 | 原因 | 措施 |
|---|:---:|---|---|
| 干燥籽粒 | 无 | 籽粒中几乎没有蜀黍氰苷 | 可以放心食用 |
| 幼嫩叶片和嫩芽 | 高 | 蜀黍氰苷浓度最高的时期 | 人和牲畜都不吃 |
| 干旱后重新长出的叶片 | 很高 | 受到胁迫时浓度会骤升 | 禁止放牧牲畜 |
| 刚受霜冻的叶片 | 很高 | 细胞被破坏，释放氢氰酸 | 霜后1周内不要喂食 |
| 再生栽培后重新长出的幼茎 | 高 | 是幼嫩组织 | 长过膝盖高度后再使用 |
| 充分长大的茎和叶 | 低 | 浓度大幅下降 | 晒干或制成青贮饲料更安全 |

> **人吃的高粱籽粒是安全的。危险的是幼嫩的叶和茎，主要受害者不是人，而是放牧的牲畜。**

&nbsp;&nbsp;&nbsp;灾害情境下，有时会需要这一知识。一是食物不足，想把高粱嫩芽当凉拌野菜（namul）吃的时候；二是想把高粱叶喂给牲畜的时候。前者不该做，后者要挑时期。氢氰酸中毒进展很快，牛几个小时就可能死亡。不过，把叶片完全晒干后，蜀黍氰苷会分解，风险大大降低。做成干草来喂是安全的。

### 14-2. 单宁

| 项目 | 内容 |
|---|---|
| 位置 | 集中在外壳和种皮中 |
| 品种差异 | 红褐色系列多，白色系列少 |
| 问题 | 产生涩味，妨碍蛋白质和铁的吸收 |
| 有益的一面 | 有抗氧化作用，减轻鸟和霉菌的危害 |
| 去除 | 通过碾制去掉外壳，换水多次清洗 |
| 进一步去除 | 浸泡一夜后倒掉水。发酵也有效果 |

&nbsp;&nbsp;&nbsp;单宁与其说是毒，不如说是抗营养因子。少量没有问题，但如果以高粱为主食、持续每天吃500g以上，情况就不同了。因为这是一种富含铁的谷物，却自己妨碍了铁的吸收。认真碾制和水洗之所以不只是口感问题，原因就在这里。

### 14-3. 霉菌

| 危险因素 | 危险度 | 措施 |
|---|:---:|---|
| 正常的干燥籽粒 | 无 | 安全 |
| 穗上长了霉的 | 很高 | 全部废弃。也不要给牲畜 |
| 贮藏中受潮发出气味的 | 很高 | 废弃。洗过或炒过，毒素仍然残留 |
| 变色并结块的 | 高 | 连同该部分一起大范围清除 |

&nbsp;&nbsp;&nbsp;霉菌毒素耐热性极强，在200℃以上仍有相当一部分残留。靠煮、炒、蒸是除不掉的。看得见霉的粮食、有霉味的粮食，即使可惜，也不要放进人的口中，这是唯一的防御。不过也并非完全不能用，放进堆肥堆会被分解，成为来年的肥料。
