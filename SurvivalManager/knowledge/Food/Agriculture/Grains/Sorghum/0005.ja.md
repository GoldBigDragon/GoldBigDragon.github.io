## 12. 収穫と脱穀

### 12-1. 時期の判断

| 基準 | 内容 | 判定 |
|---|---|---|
| 日数 | 播種後120-150日 | 品種とその年の気温によって変わります |
| 穂の色 | 穂全体が品種固有の色に濃くなります | 成熟が近づいています |
| 実の硬さ | 爪で押しても跡が残りません | 完熟です |
| 実の断面 | 半分に割って中が白く硬いです | 登熟完了です |
| 黒色層 | 実の基部に黒い点ができます | 生理的成熟の確かなサインです |
| 葉の状態 | 下の葉が枯れ、茎が黄色く変わります | 収穫期です |
| 天気 | 晴れた日が2-3日続いた後 | 水分が低く、乾燥しやすくなります |

&nbsp;&nbsp;&nbsp;登熟は、乳熟期、糊熟期、黄熟期、完熟期の順に進みます。乳熟期には実を押すと牛乳のような液が出て、糊熟期には練り粉のような状態になり、黄熟期に至ると爪で押してようやく跡がつく程度になります。収穫適期は、黄熟期の終わりから完熟期の初めです。それ以上待つと、実が落ち、鳥害が増え、穂かび病の危険が高まります。

&nbsp;&nbsp;&nbsp;実の基部にできる黒色層（BlackLayer）は、最も確実なサインです。実が茎からもう養分を受け取らなくなると、その接続部に黒い細胞層ができます。これが見えたら、その後は畑に置いておいても実は大きくなりません。残るのは乾くことだけで、その乾燥は畑より軒下のほうが安全です。

> **登熟期に雨が続くときは、完熟を待たずに刈り取って取り込んでください。実の数%を失うほうが、穂かび病で全量を失うよりましです。**

### 12-2. 収穫のコツ

| 順序 | 内容 | 理由 |
|---|---|---|
| 1 | 晴れた日の午前、露が乾いてから始めます | 濡れた穂はかびの出発点です |
| 2 | 穂の下20-30cmの位置で鎌で刈ります | 柄になる部分があると、束ねて吊るしやすいからです |
| 3 | ラトゥーニングをする畑は、株元を10-15cm残します | 切り株から新しい茎が伸びてきます |
| 4 | 刈った穂は、病気のものと健全なものをその場で分けます | 混ぜておくと、かびがうつります |
| 5 | 穂6、7本を一束に縛ります | 束が大きいと中が乾きません |
| 6 | 雨のかからない場所に逆さに吊るします | 風通しのよい姿勢が乾燥を左右します |

### 12-3. 穀物の乾燥 - 水分13-14%まで

&nbsp;&nbsp;&nbsp;穀物の貯蔵は、すべて水分で決まります。水分が15%を超えるとかびが育ち、13%を下回るとかびも虫もほとんど活動を止めます。この2、3ポイントの間に、一年の農作業の運命がかかっています。刈りたてのモロコシの水分は20-30%です。これを13-14%まで下げることが、収穫直後の唯一にして最も重要な課題です。

| 段階 | 方法 | 期間 | 到達水分 |
|---|---|---|---|
| 1. 予備乾燥 | 刈った束を畑や庭に立てておきます | 2-3日 | 20%前後 |
| 2. 吊るし乾燥 | 軒下や納屋に逆さに吊るします | 1-2週間 | 15-16% |
| 3. 仕上げ乾燥 | むしろや布に広げて日に干します | 2-4日 | 13-14% |
| 4. 寝かせ | 日陰で1日置き、水分を均一にします | 1日 | 均一化 |

&nbsp;&nbsp;&nbsp;日に干すときに守るべきことが、いくつかあります。第一に、地面に直接広げません。土から上がってくる湿気が、下の穀物を再び濡らします。むしろ、布、板のどれでもよいので、一枚敷く必要があります。第二に、層を厚く積みません。指の2節分、3-5cmを超えないようにし、1日に3、4回、熊手や手で返してやります。第三に、日が傾いたら取り込むか覆います。夜露に当たると、昼間に抜いた水分が戻ってきてしまいます。第四に、真夏の炎天下で急いで干しません。表面だけが乾いて中に水分が閉じ込められ、後でかびが生えます。

&nbsp;&nbsp;&nbsp;水分計がないときに水分を見積もる方法があります。道具なしで使え、慣れればかなり正確です。

| 方法 | 手順 | 判定 |
|---|---|---|
| 噛む | 実を奥歯で噛みます | ぱきっと割れて粉が出れば13-14%です。つぶれたりへこんだりするなら、まだ湿っています |
| 塩テスト | 乾いた塩をスプーン1杯と穀物ひとつかみをガラス瓶に入れて振り、15分置きます | 塩が瓶の壁にくっついたり固まったりしたら、水分が高いです |
| 手触り | ひとつかみ握って開きます | 手から滑るようにばらばらになれば乾いています。固まれば湿っています |
| 音 | 両手に取って振ります | 小石がぶつかるような音がすれば乾いていて、鈍い音がすれば湿っています |
| 瓶テスト | ガラス瓶に半分ほど入れて密封し、1日置きます | 瓶の内側に曇りが出たら、まだ乾燥が必要です |

&nbsp;&nbsp;&nbsp;瓶テストは特に信頼できます。密閉した瓶の中で穀物と空気が水分平衡に達しますが、水分が14%を超えると瓶の中の湿度が70%を超え、気温が下がる明け方に曇りが出ます。貯蔵に入る前の最終確認に使うのに適しています。涼しい夜がある秋なら、よりはっきりと現れます。

&nbsp;&nbsp;&nbsp;雨が続いて日光を使えない年もあります。そのときは火力を使います。かまどやストーブの上の棚、オンドルの部屋の焚き口から遠い側の床に薄く広げておくと、数日かけて乾きます。ただし、温度が50度を超えないようにしなければなりません。それ以上になると種子として使えなくなり、デンプンが変質して、ご飯の味も落ちます。手を当てて熱いと感じるなら、すでに高すぎます。ぬくもりを感じる程度が適当です。

### 12-4. 脱穀 - 道具なしでする方法

&nbsp;&nbsp;&nbsp;モロコシは、イネやオオムギより脱穀が楽なほうです。穂に粒がまばらについていて、十分に乾けば軽い衝撃でも落ちます。鍵は乾燥状態です。乾き足りない穂は、いくら叩いても粒が落ちず、つぶれるだけです。脱穀の前に、穂がかさかさと音を立てるほど乾いている必要があります。

| 方法 | 手順 | 規模 | 備考 |
|---|---|---|---|
| 手でこく | 穂の柄を持ち、手袋をした手で下へしごき落とします | 少量 | 最も損失が少ない方法です。種子用に使います |
| 叩く | むしろの上に穂を広げ、棒や殻竿で叩きます | 中程度 | 最も一般的です |
| 袋の中で叩く | 丈夫な袋に穂を入れ、袋ごと床に打ちつけます | 中程度 | 粒が飛び散りません |
| 踏む | むしろに広げ、足でこすりつけるように踏みます | 多量 | 力が少なくて済みます。靴底がきれいでなければなりません |
| 洗濯板でこすり落とす | 溝の彫られた板に穂を当ててこすります | 少量 | 波板や、木の板に溝を彫ったもので代用します |
| 桶の中でもむ | 大きな桶に穂を入れ、棒でかき回しながらもみます | 中程度 | 手が痛くなりにくいです |

&nbsp;&nbsp;&nbsp;殻竿は自分で作れます。長い柄の先に短い棒を、革紐や丈夫な縄でゆるく結びつければできあがりです。柄を振り回すと、先の棒が回って穀物を打ちます。腕の力だけで叩くより3、4倍効率が高く、一日中続けても疲れにくいです。災害時に真っ先に作っておくべき農具の一つです。

### 12-5. しいなを飛ばす - 唐箕と箕

&nbsp;&nbsp;&nbsp;脱穀した穀物には、穂のくず、割れた粒、ほこりが混じっています。これをそのまま貯蔵すると、しいなについた水分や虫の卵が貯蔵庫全体をだめにします。風で選別する作業が必ず必要です。

| 方法 | 手順 | 条件 |
|---|---|---|
| 風に流す | 風のある日に高い所からゆっくり注ぎ落とします。重い子実は真下に、しいなは遠くに飛びます | 秒速2-4mの安定した風 |
| 箕であおる | 箕に入れて上に跳ね上げては受けます。繰り返すと、軽いものが前に押し出されていきます | 無風でもできます |
| うちわであおぐ | 一人がゆっくり注ぎ、もう一人がうちわや板で風を起こします | 二人必要です |
| ふるいにかける | 目の粗いふるいでしいなを、細かいふるいでほこりと小粒を選り分けます | ふるいが2種類必要です |

&nbsp;&nbsp;&nbsp;箕は、災害時に自作できる道具です。竹やハギを割いて編んだり、薄い合板を三方だけ立てて作ったりしても機能します。箕であおるコツは、上下に振るのではなく、前に押し出してから引き戻し、穀物を空中に一瞬浮かせることです。浮いている間に、軽いものが遅れて前のほうに集まります。身につけるのに半日あれば十分で、一度身につければ一生使える技術です。

## 13. 採種

### 13-1. 採種個体の選抜

| 基準 | 内容 | 理由 |
|---|---|---|
| 選抜の時期 | 登熟期に畑を回って、あらかじめ印をつけておきます | 収穫後は、どの株のものか分からなくなります |
| 個体の条件 | 病徴がなく、倒れておらず、穂が充実したもの | 形質が次世代に受け継がれます |
| 穂の位置 | 株で最も太く揃った主穂 | 側穂は実り方が不揃いです |
| 収穫の時点 | 一般の収穫より少し長く置き、完全に熟させます | 未熟な種子は発芽率が落ちます |
| 除外対象 | 堅黒穂病が見られた株 | 種子で伝染します |

&nbsp;&nbsp;&nbsp;モロコシは自家受粉が基本ですが、他殖率が5-10%あります。つまり、100粒のうち5粒から10粒は、隣の株の花粉を受けたものです。1品種だけ植えるなら問題ありませんが、もち性モロコシとうるち性モロコシを隣り合わせて植えると、数年で性質が混ざります。品種を維持するには、最低でも200m以上離すか、開花期を2週間以上ずらして植える必要があります。

&nbsp;&nbsp;&nbsp;現実的に畑が狭くて隔離が難しいなら、別の方法があります。採種用に決めた株の穂に、開花前に紙袋や目の粗い布をかぶせておくのです。モロコシは自家受粉が基本なので、袋の中でも正常に結実します。穂を2、3本だけこのように管理すれば、翌年も純粋な種子の系統を維持できます。

### 13-2. 種子の保管

| 条件 | 基準 | 理由 |
|---|---|---|
| 水分 | 12-13%。食用より少し乾燥させます | 種子は水分が低いほど寿命が長くなります |
| 温度 | 低く一定に。10℃以下が理想です | 温度が高いと、呼吸で胚が消耗します |
| 容器 | ガラス瓶、金属缶、甕などの密閉容器 | 湿気と虫を同時に防ぎます |
| 光 | 完全に遮断 | 光と熱は発芽力を低下させます |
| 形態 | 殻つきのまま保管します | 精白したものは寿命がはるかに短くなります |
| 寿命 | 常温密閉で2-3年 | 条件がよければ4-5年でも発芽します |

&nbsp;&nbsp;&nbsp;種子は、食用の穀物と必ず別に置かなければなりません。冬が深まって食べ物が減ると種子に手が伸び、一度手をつけたら翌年の農作業はなくなります。物理的に別の場所、別の容器に置き、外側に表示しておくほうが、人の判断力を信じるよりも確実です。必要な種子量は1,000㎡当たり1-2kgなので、実際の必要量の2倍ほどを取り分けておけば十分です。

### 13-3. 発芽試験

&nbsp;&nbsp;&nbsp;古い種子を植える前には、発芽力を確認しなければなりません。濡らした布に実を20粒包んで暖かい場所に置き、5日待ちます。何粒が芽を出したかを数え、20粒のうち16粒以上ならそのまま使い、12粒から15粒なら播種量を増やし、10粒を下回るなら新しい種子を手に入れなければなりません。この簡単な試験一つが、一年の農作業をまるごと失う事態を防いでくれます。

## 14. 毒性と注意事項

### 14-1. シアン配糖体 - 葉と若い茎

&nbsp;&nbsp;&nbsp;モロコシには、知っておくべき毒性が一つあります。子実ではなく、葉と若い茎の問題です。モロコシの葉にはドゥーリン（dhurrin）というシアン配糖体が含まれていて、植物組織が傷つくと酵素が働いて、青酸（シアン化水素）が作られます。

| 条件 | 危険度 | 理由 | 対処 |
|---|:---:|---|---|
| 乾燥した子実 | なし | 実にはドゥーリンがほとんどありません | 安心して食べられます |
| 若い葉と芽 | 高い | ドゥーリンの濃度が最も高い時期です | 人にも家畜にも食べさせません |
| 干ばつの後に再び伸びた葉 | 非常に高い | ストレスを受けると濃度が急上昇します | 家畜の放牧を禁じます |
| 霜に当たった直後の葉 | 非常に高い | 細胞が破壊されて青酸が放出されます | 霜の後1週間は食べさせません |
| ラトゥーニングで再び出た若い茎 | 高い | 若い組織だからです | 膝の高さを超えてから使います |
| 十分に育った茎と葉 | 低い | 濃度が大きく下がります | 乾燥させるかサイレージにすると、より安全です |

> **人が食べるモロコシの子実は安全です。危険なのは若い葉と茎であり、主な被害者は人ではなく放牧された家畜です。**

&nbsp;&nbsp;&nbsp;災害時に、この知識が必要になる場面があります。食べ物が足りず、モロコシの若い芽をナムルにして食べてみようとするとき、そして家畜にモロコシの葉を与えようとするときです。前者はしてはならず、後者は時期を選ばなければなりません。青酸中毒は急速に進み、牛が数時間で死ぬこともあります。ただし、葉を完全に乾燥させればドゥーリンが分解され、危険が大きく減ります。干し草にして与えるのは安全です。

### 14-2. タンニン

| 項目 | 内容 |
|---|---|
| 場所 | 殻と種皮に集中しています |
| 品種による違い | 赤褐色の系統に多く、白色の系統に少ないです |
| 問題点 | 渋みを出し、タンパク質・鉄分の吸収を妨げます |
| 有益な面 | 抗酸化作用があり、鳥やかびの被害を減らします |
| 除去 | 精白で殻を取り除き、水を替えながら何度も洗います |
| さらなる除去 | 一晩水に浸けて、その水を捨てます。発酵にも効果があります |

&nbsp;&nbsp;&nbsp;タンニンは毒というより、抗栄養因子です。少量なら問題ありませんが、モロコシを主食にして1日500g以上を食べ続ける状況では、話が違ってきます。鉄分が豊富な穀物なのに、その鉄分の吸収を自ら妨げることになるからです。精白と水洗いをしっかり行うことが、単なる食感の問題ではない理由です。

### 14-3. かび

| 危険要因 | 危険度 | 対処 |
|---|:---:|---|
| 正常な乾燥した子実 | なし | 安全です |
| 穂にかびが生えたもの | 非常に高い | 全量廃棄します。家畜にも与えません |
| 貯蔵中に湿って、においがするもの | 非常に高い | 廃棄します。洗っても炒っても毒素は残ります |
| 色が変わって固まっているもの | 高い | その部分を含めて、広めに取り除きます |

&nbsp;&nbsp;&nbsp;カビ毒は熱に非常に強く、200℃以上でもかなりの部分が残ります。茹でる、炒る、蒸すといった程度では取り除けません。かびが見える穀物、かびのにおいがする穀物は、もったいなくても人の口に入れないことが唯一の防御です。ただし、まったく使えないわけではなく、堆肥の山に入れれば分解されて、翌年の肥料になります。
