## 引言
&nbsp;&nbsp;&nbsp;高粱（Sorghum bicolor）是来自非洲东北部、即今天埃塞俄比亚和苏丹一带的谷物。它在旱季漫长、土层浅薄、养分贫瘠、正午气温常在40℃上下的土地上养活人类五千多年，所以缺水时会卷起叶子减少蒸腾，再缺水就停止生长，等下雨再继续长。总蒸散量250mm就够，不到玉米的一半；氮、磷、钾合计每㎡只需18g，略多于玉米的一半；它是禾本科作物，连作也不会垮，干燥的籽粒在常温下可放3年以上。不施肥也能保持平时产量的45%，所以在物流中断、化肥厂停工、农田无法灌溉的情况下，高粱从第二年起显出价值。弱点有四个。单位面积热量为每㎡1,309kcal，一个人一年的热量约需200㎡；只遮光40%，产量就降到一半以下，极怕阴；一次霜冻就会枯死；必须碾米并洗掉单宁才能食用。丢粮食的地方往往不在田里而在仓库，所以高粱储藏比种植更难。

## 2. 植物概述
&nbsp;&nbsp;&nbsp;禾本科高粱属的一年生草本。叶细长呈线形，表面的蜡质层减少水分蒸发。茎直立、实心，高80-120cm（因品种而异可超过3m）。须根深而密地伸展。花在茎顶组成圆锥花序，一个穗上结1,000-3,000粒籽粒。果实是颖果，分为糯高粱和粳高粱。

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 发芽·幼苗期 | 播种后3周 | 磷、氮 |
| 营养生长期 | 3-6周 | 氮 |
| 抽穗期 | 6-8周 | 磷、钾 |
| 开花·结实期 | 8-10周 | 钾 |
| 灌浆·成熟期 | 10-14周 | 钾 |

> **耐旱的高粱在抽穗期和开花期也不一样。这2周如果断水，穗子抽出来了也不结籽，成为空穗。**

| 每100g营养 | 含量 |
|:---|:---|
| 热量 | 358-374kcal（干籽粒） |
| 碳水化合物 | 74-79.3g（大部分是淀粉） |
| 蛋白质 | 11-11.8g（明显高于大米） |
| 脂肪 | 2-3.5g（比燕麦少，酸败风险低） |
| 其他 | 膳食纤维6.6g，铁4.4mg，镁165mg，B族维生素，多酚·单宁。不含麸质 |

## 3. 栽培环境与品种
| 条件 | 最适 | 极限与影响 |
|:---|:---|:---|
| 生长温度 | 25-30℃ | 12-48℃。低于12℃停止生长，0℃枯死 |
| 发芽 | 21-35℃ | 最低15℃。低于此温度发芽延迟，种子腐烂 |
| 光照 | 正午强光 | C4作物。遮光40%时相对产量45%（燕麦等C3谷类为88%） |
| 水 | 合计250mm左右 | 150-400mm。极端干旱时停止生长来忍耐 |
| 土壤 | 砂壤土至黏壤土 | 几乎所有土质。pH 5.5-7.5（5.0-8.5）。积水的黏土会伤根 |

&nbsp;&nbsp;&nbsp;选地先看光再看水。朝南的缓坡地最好，平地的田把垄筑高就行。多砾石的贫瘠地也能结实。由水田改成的旱地要破开排水层并把垄筑高，建筑物或大树的阴影处、朝北的坡、谷底（日照短，霜来得早）都不适合。

| 类型 | 特点 | 灾害角度 |
|:---|:---|:---|
| 糯高粱 | 胚乳淀粉为支链淀粉90-100%。黏而软。杂粮饭、糕、酒 | 容易掺进饭里，抵触感小。韩国推广的品种大多是 |
| 粳高粱 | 直链淀粉22-24%。松散。饭、粥、粉 | 更适合磨粉使用 |

| 品种 | 株高 | 产量（kg/1,000㎡） | 特点 |
|:---|:---|:---:|:---|
| 密阳15号 | 中 | 484 | 韩国产量最高。株型适合机械收获 |
| Goeunchal | 约100cm | 374 | 抗倒伏，有利于避开穗霉病 |
| Sodamchal | 91-117cm | 296 | 红褐色籽粒。抗氧化活性高，抗倒伏 |
| Jungmo（糯） | 88cm | - | 最矮的矮秆种。白色籽粒。受风害少 |
| Namphungchal（密阳4号） | 中 | - | 中熟糯高粱。抗倒伏、抗灾害、高产 |

&nbsp;&nbsp;&nbsp;以产量为目的用密阳15号，人手不足用Sodamchal·Goeunchal，风大的地方用Jungmo·Sodamchal，霜来得早的地方用早熟系。灾害持续越久，比起产量，越是能靠自留种延续下去的地方品种更重要。

## 4. 田地准备与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 翻耕20-30cm深，把土块打碎整平（籽粒小，掉进土块缝里就不发芽）。田周和垄沟开排水沟，垄高15-20cm |
| 施肥（每1,000㎡） | 堆肥1,000-1,500kg，氮10-15kg（基肥50%，追肥50%），磷5kg，钾4.5kg。堆肥·磷·钾全部作基肥 |
| 时期 | 基肥在播种前1-2周，追肥在5-10叶期结合间苗和培土 |
| 替代资源 | 草木灰20-40kg（阔叶树灰），腐熟堆肥（3-6个月），稀释10倍的尿液（浇进垄沟，收获前3周停止），骨粉，豆科绿肥（翻压后2-3周播种） |

> **给高粱多施氮只会让它光长个子并倒伏。即使肥料充足，不超过标准量对收获更有利。**

| 地区·茬口 | 播种 |
|:---|:---|
| 中部地区 | 5月中旬至6月上旬 |
| 南部地区 | 5月上旬至中旬 |
| 麦类后茬 | 6月中下旬 |

&nbsp;&nbsp;&nbsp;灾害时不要一次全播完，而是每隔2周分批播种。

| 播种 | 标准 |
|:---|:---|
| 选种 | 放进盐水（1L水加盐51g，比重1.035）搅拌，只用沉底的。没有秤的话，用能让生鸡蛋浮起的浓度 |
| 消毒 | 50-55℃的水泡10-15分钟（超过60℃胚会死），裹细草木灰，稀释500倍的木醋液泡6-12小时，播种前2-3天晒2-3小时 |
| 播法 | 每1,000㎡ 1-2kg，深2-5cm。单行种植行距60cm，株距20cm，每穴7-8粒。双行种植垄宽110cm，行距30cm，株距15cm |
| 移栽 | 128穴育苗盘每穴2-3粒，育苗15-20天。前茬结束得晚时用 |
| 收尾 | 覆土后用脚踩或用木板压实（发芽率大幅提高。预计干旱时尤其有效） |

## 5. 水分、栽培管理与病虫害
| 时期 | 水分管理 |
|:---|:---|
| 播种-发芽 | 保持土壤不干 |
| 幼苗期 | 不需要灌溉（引导根向深处扎） |
| 营养生长期 | 靠自然降水。干一个月也不会死 |
| 抽穗期-开花期 | 干旱时一定要浇水。这2周决定产量 |
| 灌浆期 | 逐渐减少 |
| 成熟期 | 完全停水。水多则收获后难以干燥 |

&nbsp;&nbsp;&nbsp;中午叶子卷起是正常的防御反应，早晨还卷着才是实质性干旱。叶子从下往上变黄枯死是长期干旱；抽出了穗但籽粒是空的，是抽穗·开花期缺水，无法挽回。叶子发黄、根发黑是过湿，要立刻开排水沟；茎基变软倒伏是烂根。

| 管理 | 内容 |
|:---|:---|
| 间苗 | 真叶3-4片时拔掉弱株，5-10叶期只留最壮的1-2株。拔下的幼苗可作饲料或堆肥，但含氰苷多，不要大量喂 |
| 除草 | 杂草有手指长时开始，最后一次在长到齐膝高时。播种后30-45天是关键，之后高粱会盖住杂草 |
| 培土 | 与间苗同时进行，之后再来一次。促发新根，防止倒伏 |
| 倒伏 | 不施超过标准量的氮，培土要扎实，选矮秆种。倒伏之后，三四株一捆用绳扎起扶正 |
| 再生栽培 | 第一次收获时留10-15cm茬割下，会长出新茎，再收一次，产量约为一半。只限于霜前能完成灌浆的南部，且第一次收获在8月内结束时 |
| 鸟 | 从穗子快成熟时（3周）起，用网、给穗子套纸袋或旧布、在田上拉线。守不住的话，会损失三分之一的收成 |

| 病虫害 | 不用药的应对 |
|:---|:---|
| 穗霉病（灌浆期多雨，穗子发黑或发粉） | 早熟品种、提早收获、立即干燥、销毁病穗 |
| 坚黑穗病（种子传染） | 盐水选种、裹草木灰、温汤浸种、烧毁病穗 |
| 炭疽病、纹枯病、茎腐病 | 保证通风和株距、轮作、改善排水、摘除病叶、避免氮过多、木醋液 |
| 蚜虫、螨 | 肥皂水（1L水加纯肥皂5-10g，早晨或傍晚喷）、保护瓢虫·草蛉 |
| 玉米螟等蛾类、粘虫 | 清除并烧毁被害茎、人工捕捉、收获后处理残茬、严重时提前收获 |
| 蝽 | 清晨人工捕捉、清除周围杂草 |

> **发霉的粮食，洗了、煮了、炒了也不会变安全。丢掉是唯一的办法。**

&nbsp;&nbsp;&nbsp;最危险的病是穗霉病，预防完全取决于干燥。不从病株上留种，避开病害流行的时期播种和收获，把病残体和残茬从田里清走。也用草木灰（露水未干的早晨）、稀释500-1,000倍的木醋液、烟叶或辣椒浸出液。

| 症状 | 原因与对策 |
|:---|:---|
| 从下部叶子开始发黄，植株矮小 | 缺氮。腐熟堆肥、稀释10倍的尿液 |
| 叶缘像烧焦一样变褐 | 缺钾。草木灰 |
| 生长迟缓，叶色黑绿 | 缺磷。把骨粉掺进堆肥 |
| 叶脉间发黄，叶脉仍绿 | 缺镁。白云石粉 |
| 新叶发白 | 缺铁（碱性过多）。停用草木灰，施腐叶土 |
| 光长个子，叶色深，倒伏 | 氮过量。停止施氮，靠培土支撑 |

## 6. 间作与轮作
| 搭配 | 作物 |
|:---|:---|
| 非常好 | 大豆、红小豆、豇豆（根瘤菌固定的氮会分给高粱。混种时间距要放宽） |
| 好 | 花生、南瓜（覆盖地面，减少蒸发和杂草）、马铃薯（生长期错开） |
| 适合作后茬 | 大麦、小麦（高粱的化感物质减少了杂草的田） |
| 差 | 玉米、粟、黍（同为禾本科，共有病虫害，养分竞争大） |

&nbsp;&nbsp;&nbsp;第1年高粱，第2年豆科，第3年叶菜或根菜，第4年再回到高粱。高粱能耐连作，但病害密度会累积。

## 7. 收获、干燥、脱粒、留种
| 步骤 | 内容 |
|:---|:---|
| 时期 | 播种后120-150天。穗子变成品种固有的深色，剖开籽粒里面发白而硬，籽粒基部出现黑点（黑层），下部叶子枯萎、茎变黄时。灌浆期连日下雨，不等完全成熟就割 |
| 割 | 晴天露水干后，在穗下20-30cm处用镰刀割。病穗与好穗当场分开。六七个穗扎成一捆，倒挂在淋不到雨的地方 |
| 干燥 | 预干燥2-3天（20%左右）→ 挂在屋檐下晾1-2周（15-16%）→ 摊在草席上晒2-4天 → 13-14% |
| 水分检查 | 咬籽粒时清脆地裂开并出粉，就是13-14%。双手捧着摇，发出小石子碰撞的声音，装半瓶密封放一两天不起雾，就合格 |
| 脱粒 | 用手捋（留种用）、在草席上用木棒或连枷敲打、在袋里敲打、摊在席上用脚搓、在刻槽的板上擦、在桶里搓 |
| 秕粒·杂质清除 | 让每秒2-4m的稳定风吹走、簸箕簸、用扇子扇、过筛（粗筛筛秕粒，细筛筛灰尘和碎粒） |

| 留种 | 标准 |
|:---|:---|
| 选择 | 灌浆期在田里巡视并做记号。无病症、没倒伏、穗子充实的植株上粗壮整齐的主穗。出过黑穗病的植株排除 |
| 隔离 | 异交率有5-10%，要与其他品种隔开。地小的话，错开花期播种 |
| 保管 | 带壳，含水量12-13%，10℃以下，完全避光，密闭容器。常温密闭可存2-3年。与食用粮食分开放 |
| 发芽试验 | 把20粒籽粒包在湿布里放五天。16粒以上就照常用，12-15粒就加大播种量，不到10粒就换新种子 |

## 8. 储存
&nbsp;&nbsp;&nbsp;耐储性为SS，但敌人有三个。霉菌（水分15%以上，变质并产毒，全部丢弃）、虫（20℃以上，水分12%以上）、鼠（能接近的容器），一个防线崩溃其余也随之崩溃，所以必须同时堵住。

| 项目 | 标准 |
|:---|:---|
| 条件 | 水分13-14%，温度15℃以下（超过25℃虫繁殖加快），周围湿度65%以下，避光，每两个月检查一次 |
| 形态 | 带壳（3年）。碾过的高粱米撑不过6个月。每次只舂一个月的量 |
| 容器 | 玻璃瓶·金属桶3年以上，陶瓮2-3年（口上盖纸或布，放上盖子，用泥封边），地下储藏窖2-3年以上，厚塑料袋1-2年，草袋·麻袋6个月至1年 |

> **谷物带壳储存，吃多少碾多少。壳是大自然给的包装。**

&nbsp;&nbsp;&nbsp;防虫以装满的完全密封最可靠，也可用草木灰（细灰占谷物体积的2-5%）、硅藻土（每1kg谷物1-3g）、细沙·黄土、干盐、木炭、干辣椒·花椒、艾蒿·菖蒲叶。还可以在隆冬拿到外面放几天（低温），或薄薄摊在太阳下晒几个小时（60℃，留种用的除外）。谷物潮湿时，灰和硅藻土就没有效果，所以先要干燥。谷物表面出现粉末或蛛丝般的丝，就是印度谷螟，要把全部谷物晒干后筛出来。

## 9. 烹调与注意事项
| 烹调准备 | 方法 |
|:---|:---|
| 碾米 | 把干籽粒放进臼里舂，每5-10分钟取出簸一次，去掉糠。舂前洒少许水放30分钟，壳容易脱，籽粒也不易碎。石磨把上扇稍微抬起来转。脚踏碓省力得多。糠不要扔 |
| 去除单宁 | 把碾好的籽粒放进足量的水里搓洗，倒掉浑水，重复三四次，最后泡30分钟到一夜，再把水倒掉。涩味几乎消失 |
| 磨粉 | 石磨磨得最细，臼则较粗。炒过后再舂省力得多。粉比籽粒坏得快得多 |

| 烹调 | 燃料与要领 |
|:---|:---|
| 高粱饭 | 用水泡30分钟以上再煮（不泡的话里面不熟，白费燃料） |
| 杂粮饭 | 在米或其他谷物里掺两三成。抵触感小 |
| 粥 | 粉用水调开煮10分钟。最省燃料 |
| 灰烬中烤 | 把面团埋进已做完其他烹调的灶里的热灰中 |

&nbsp;&nbsp;&nbsp;兼作储存的加工有炒粉（misutgaru，密封6个月）、高粱麦芽糖稀（用麦芽糖化后熬浓，阴凉处1年）、发酵面团（2-3天，单宁减少，吸收更好）、高粱酒、爆米花式的膨化粮（密封1-2个月）。如果同时种了甜高粱，可以把茎捣碎榨汁，长时间熬成糖浆。

| 注意 | 内容 |
|:---|:---|
| 氰苷（蜀黍苷） | 干籽粒中几乎没有，是安全的。嫩叶和嫩芽、干旱后重新长出的叶子、刚受霜冻的叶子（1周内禁用）、再生栽培后重新长出的嫩茎（长过齐膝高后再用）中含量高，人和家畜都不要吃。长足的茎叶晒干或制成青贮更安全 |
| 单宁 | 集中在皮和种皮，红褐色品系中较多。产生涩味，妨碍蛋白质和铁的吸收，但也有抗氧化作用，并能减少鸟和霉菌的危害 |
| 霉菌毒素 | 在200℃以上仍大量残留，煮、炒、蒸都除不掉。见到霉斑或闻到霉味的粮食要丢弃，放进堆肥堆里分解 |

## 10. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存谷物（结露、霉味）、确认种子并做发芽试验、翻堆堆肥、保养工具 |
| 3-4月 | 收集草木灰、完成堆肥、翻耕、开排水沟和深垄沟、施基肥 |
| 5月 | 盐水选种、种子消毒、播种（中部从中旬起）。每隔2周分批播种，收获期可以错开 |
| 6月 | 补播、第一次间苗、除草。前期一个月的杂草管理左右产量 |
| 7月 | 第二次间苗、追肥、培土、开始抽穗。干旱时一定要浇水 |
| 8月 | 开花与灌浆、赶鸟、监视病害 |
| 9月 | 开始收获、预干燥、挂着晾晒。有雨的消息就不等完全成熟 |
| 10月 | 收尾收获、脱粒、最后干燥、储存（确认水分13-14%后密封） |
| 11-12月 | 挑选种子并单独保管、清走残茬以去除蛾类越冬场所、每次只碾米和磨一个月的量 |

> **不能忘记的五件事：日照最好的地、垄沟与排水、不超过标准量的氮、干燥到水分13-14%、带壳储存。**
