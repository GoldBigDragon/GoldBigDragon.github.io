## 4. 品種

### 4-1. 系統別の特徴

&nbsp;&nbsp;&nbsp;スベリヒユには、育種された品種と呼べるものがほとんどありません。商業作物として扱われた歴史が短く、大部分の地域で雑草に分類されてきたからです。区分は、野生型と栽培型、それに葉の大きさ程度にとどまります。

| 系統 | 葉と草姿 | 収量 | 災害時の適性 |
|---|---|:---:|---|
| 野生型（野スベリヒユ） | 葉が小さく、茎が完全に地面に張りつきます | 少ない | どこにでもひとりでに生えるので、確保に手間がかかりません |
| 大葉種（大葉スベリヒユ） | 葉が広くて厚く、株が大きいです | 多い | 同じ面積から収穫できる量が野生型の2倍近くになります |
| 小葉種 | 葉が小さく、成分が濃いです | 少ない | 薬用やお茶に向いており、味が濃いです |
| 直立型（黄金スベリヒユなど） | 茎が立って育ちます | 中程度 | 切りやすく、土がつきにくいので、下処理が簡単です |

&nbsp;&nbsp;&nbsp;ヨーロッパや中東では、スベリヒユは古くから野菜として栽培されてきており、そちらの系統が、葉が大きく茎が立つ栽培型です。韓国国内で種子として入手できるものも、たいていはこの系統です。ただ、災害を前提にするなら、この区別にこだわる理由はあまりありません。畑にひとりでに生えた野生型も、食べるうえで何の支障もありませんし、栽培型の種子が落ちて数年たてば、野生型と混ざって、どのみち区別はあいまいになります。

### 4-2. 状況別の選択基準

| 状況 | 選択 | 理由 |
|---|---|---|
| 畑にすでにスベリヒユが生えている | それをそのまま使う | その場所の環境にすでに適応した系統です |
| 収穫量を増やしたい | 大葉種 | 葉が大きく茎が太いため、一度に収穫できる量が多いです |
| 狭い場所で管理したい | 直立型 | 横に広がらないので、境界を守りやすいです |
| 薬用やお茶にする目的 | 小葉種 | 成分が濃いです |
| 種子を長く保管する予定 | どの系統でもよい | スベリヒユの種子は寿命がきわめて長いです |

&nbsp;&nbsp;&nbsp;ほかの作物では固定種と交配種の違いを見分けることが重要ですが、スベリヒユではそうではありません。スベリヒユは自分で受粉する自家受粉植物で、種子を採って植えれば、親とほとんど同じものが育ちます。評価表の自家採種SSは、ここから来ています。種子の確保を心配しなくてよい数少ない作物で、実際には、心配しなくてもひとりでに種が落ち、翌年に生えてきます。

> **スベリヒユでは、品種選びよりはるかに重要なのは、どこで摘むかです。道端や空き地で育ったスベリヒユは、排気ガスや除草剤や重金属にさらされており、この植物にはそうした物質を組織にためこむ性質があります。**

## 5. 畑の準備と肥料

### 5-1. 畑づくり

| 項目 | 基準 | 備考 |
|---|---|---|
| 耕す深さ | 10-15cmと浅く | 根が浅いので、深く耕す必要がありません |
| 畝 | 低くても立てます | 排水の確保が唯一の目的です |
| 酸度矯正 | 行いません | pH 5.6-7.8にそのまま耐えます |
| 有機物 | 入れません | 肥料が多いと、葉だけがやわらかくなり、徒長します |
| 場所 | 一日じゅう日が当たる場所 | 日陰は収量を半分に落とします |

&nbsp;&nbsp;&nbsp;ほかの作物の畑の準備の項目が、何をさらに加えるかを扱うとすれば、スベリヒユの場合は、何を入れないかを扱います。堆肥をたっぷり入れて深く耕し、ふかふかにした畑にスベリヒユを植えると、茎が軟弱になり、葉は大きくなるものの、倒れやすく腐りやすくなります。やせた土地に合わせてできたつくりなので、養分があり余ると、かえってバランスが崩れます。

&nbsp;&nbsp;&nbsp;整地・掘削エネルギーDという評価も、この文脈で読みます。スベリヒユ一つのために土を耕すと、費やした労力に比べて得られるものが少なくなります。そのため実際の運用では、ほかの作物のためにすでに耕してある畑の縁を使うか、まったく耕していない空き地をそのまま使います。固い土地なら、熊手で表面だけをひっかいて、種が土に触れるようにしてやれば十分です。

### 5-2. 施肥量

&nbsp;&nbsp;&nbsp;評価表の施肥等級がSSなのは、入れるものがないという意味です。標準施肥量と呼べる基準は別に立てられておらず、次の表は、収穫を何度か繰り返すときに再生を助ける最小限を記したものです。

| 成分 | 基準 | 備考 |
|---|---|---|
| 窒素（N） | 刈り取り後にごく少量 | 新芽の再生を助けます。なくても再生はします |
| リン酸（P） | 入れない | やせ地への適応 |
| カリウム（K） | 入れない | やせ地への適応 |
| 堆肥 | 入れない | 多すぎると徒長して軟弱になります |
| 石灰 | 入れない | 広い酸度への適応 |

&nbsp;&nbsp;&nbsp;窒素を「ごく少量」と書いたのには理由があります。スベリヒユは、硝酸塩を組織にためこむ性質のある植物です。窒素肥料を十分に与えた畑で育ったスベリヒユは、葉に硝酸塩が高く蓄積します。ナムル（味付けした野菜の和え物）を一、二皿食べて問題になる量ではありませんが、わざわざ肥料を入れてまでその濃度を上げる理由は、なおさらありません。肥料を節約することは、この作物では収量の損失ではなく、品質上の利益です。

### 5-3. 災害時の代替肥料

&nbsp;&nbsp;&nbsp;化学肥料が途絶えた状況でスベリヒユが特別なのは、この節で扱う内容がほとんどないという事実そのものにあります。ただし、収穫を3回、4回と重ねながら同じ場所で取り続けようとするときは、少しの補いが役に立ちます。

| 代替資源 | 供給成分 | 使い方 | 注意 |
|---|---|---|---|
| 人の尿 | 窒素、カリウム | 水で10-15倍に薄め、刈り取り直後に畝間に注ぎます | ほかの作物より薄めに使います。硝酸塩の蓄積を招きます |
| 完熟堆肥 | さまざまな成分 | ごく薄く、ひとつかみ程度だけ載せます | 厚く覆うと茎が触れて軟弱になります |
| 草木灰 | カリウム、カルシウム | 刈り取り後にひとつかみまきます | アルカリ性です。スベリヒユは耐えますが、隣の作物に影響が及びます |
| 草の液肥 | 窒素、カリウム | 10倍に薄めて土にやります | 葉にかかると跡が残ります |
| 腐葉土 | 有機物、微量要素 | 発芽する場所に薄く | 発芽期の水分保持も兼ねます |

&nbsp;&nbsp;&nbsp;ここで、肥料の役割がほかの作物と異なるという点を指摘しておきます。ケールや長ネギでは、肥料は収量をつくる材料です。スベリヒユでは、肥料は、切り取った場所から新芽がどれだけ速く出てくるかを調節するスイッチに近いものです。肥料を与えれば再生が速くなり、与えなければゆっくり出てきます。どちらにしても、結局は出てきます。

&nbsp;&nbsp;&nbsp;肥料が貴重な状況なら、その肥料はスベリヒユではなく、ケールやハクサイや長ネギのほうに回すほうが、全体の収穫を増やします。無合成投入での収量維持率100%という値が、まさにその判断の根拠です。スベリヒユは肥料をやらなくても失うものがなく、ほかの作物はやらなければ半分を失います。

## 6. 播種

### 6-1. 播種時期

| 作型 | 播種（韓国） | 収穫（韓国） | 備考 |
|---|---|---|---|
| 露地・春まき | 4月中旬から5月 | 5月下旬から10月 | 霜の心配が完全になくなった後が基準です |
| 露地・夏まき | 6月から7月初め | 7月から10月 | 地温が高く、発芽がもっとも速いです |
| 自然発芽 | まかない | 6月から10月 | 前年に種が落ちた場所から、ひとりでに生えてきます |

&nbsp;&nbsp;&nbsp;霜の心配がなくなった後という条件のほかに、制約はありません。むしろ、早くまきすぎると地温が15℃に届かず、種はそのまま土の中で待ち続けます。枯れることはなく、暖かくなるまで待ってから発芽します。この待つこと自体がスベリヒユの種子の特徴であり、土の中で数十年耐える性質の日常版です。

&nbsp;&nbsp;&nbsp;三行目の自然発芽が、実際の運用の中心になります。一年スベリヒユを育てて種を落とした場所は、翌年から播種が要りません。災害時に種子の袋を節約でき、播種の労力もなくせるという点でこれ以上のものはなく、その代わり、どこに何株生えるかを人が決められないという代償が伴います。収量安定性Dの実体がこれです。

### 6-2. 播種方法

| 項目 | 基準 | 理由 |
|---|---|---|
| 播種の深さ | 0.2-0.5cm、ほとんど覆土しない | 種子がきわめて小さく、光を受けてはじめてよく発芽します |
| まき方 | ばらまきまたは条まき | 種子が小さく、均一にまくのが難しいからです |
| 条間 | 20-30cm | 条まきの場合 |
| 最終の株間 | 10-15cm | 間引きして合わせます |
| 発芽日数 | 地温20-30℃で3-7日 | |
| 播種後 | 手のひらや板で軽く押さえます | 種子が土に密着してはじめて水分を吸えます |

&nbsp;&nbsp;&nbsp;深く埋めてはいけないということが、スベリヒユの播種のほぼすべてです。種子は直径0.5mmほどで、粉コショウよりも小さく、その中に含まれる養分で伸び上がれる距離は、数mmにすぎません。1cmの深さに埋まった種は、芽を出そうとして力尽きて死にます。さらに、スベリヒユの種子には、光を受けると発芽が促される性質があるため、土をかけずにまいてから押さえるほうが、かえって発芽率が高くなります。

&nbsp;&nbsp;&nbsp;種子が小さすぎて手で均一にまきにくいときは、乾いた砂や細かい土に混ぜてかさを増やしてからまきます。種子ひとさじに砂十さじほどにすれば、手に取る感覚がつかめ、密度も目に見えます。灰を混ぜると、まいた場所が白く見えて、どこを通ったか確認できます。

### 6-3. 種子処理

| 方法 | 手順 | 効果 |
|---|---|---|
| 灰まぶし | 種子にふるいにかけた草木灰を軽くまぶします | 表面の消毒になると同時に、まいた場所が目に見えます |
| 砂混ぜ | 砂で10倍に薄めてまきます | 密度を目で見て調節します |

&nbsp;&nbsp;&nbsp;ほかの作物で行う温湯浸漬や薬剤消毒は、スベリヒユには必要ありません。種子を通じてうつる深刻な病害は知られておらず、そもそも種が小さすぎて、水に浸けると取り出すのが困難です。水に浸してふやかす処理も、効果ははっきりしません。この作物では、種子処理とは事実上、いかに均一にまくかという問題です。

## 7. 水管理

### 7-1. 生育段階別の水

| 時期 | 管理 | 備考 |
|---|---|---|
| 播種から発芽まで | 表土を乾かさないように | この2週間だけ人の手が必要です |
| 幼苗期 | 2-3日に1回 | その後、急激に強くなります |
| 栄養成長期 | やらなくてもかまいません | 日照りが続けば、葉が厚くなるだけです |
| 収穫期 | 刈り取り直後に1回 | 新芽の再生が速くなります |
| 開花・結実期 | かえって止めます | 乾燥するほど種がよく実ります |

&nbsp;&nbsp;&nbsp;ほかの作物の水管理の表が、いつどれだけやるかを扱うとすれば、スベリヒユの表は、いつ手を引くかを扱います。総消費量は1㎡あたり250L未満で、ケールの400mmや、ヨウサイ（空芯菜）の1,500Lと比べると、桁が違います。評価表の水消費量SSの実体です。

&nbsp;&nbsp;&nbsp;水が貴重な災害時に、この性質が持つ意味は大きいです。井戸が涸れ、天秤棒で水を担いで運ぶ立場になれば、畑にやれる水の総量が、そのまま育てられる作物の総量になります。その計算で、スベリヒユは分母に入りません。食べられる葉を出してくれながら、水の配分表の一行を占めない作物であり、こうした作物はめったにありません。

### 7-2. 水不足と水過多の症状

| 症状 | 原因 | 何が起こっているか |
|---|---|---|
| 葉が小さく厚くなり、赤みを帯びる | 水不足 | 正常な適応反応です。枯れません |
| 明け方に摘んだ葉がとりわけ酸っぱい | 干ばつでCAMに切り替わった | 夜に集めた有機酸がたまった状態です |
| 茎が細く長くなり、色が薄い | 光不足 | 水の問題ではありません。場所を移す必要があります |
| 株元から褐色に軟化する | 過湿、根腐れ | 数日のうちに株全体が崩れます |
| 葉が黄色くなって落ちる | 根の酸素不足 | 水がたまっている場所です |
| 葉が軟らかく大きくなり、倒れやすい | 水と肥料の過剰 | 貯蔵性と食感が悪くなります |

&nbsp;&nbsp;&nbsp;最初の行と四行目の違いを見分けることが、この表の要点です。スベリヒユが赤くなってしぼむのは、問題ではなく対処です。水が足りなくなると、葉のワックス層を厚くし、赤い色素を増やして、強い光から組織を守ります。この状態のスベリヒユは、味が濃くなり、成分の濃度が高くなります。一方、株元が褐色に軟化し始めたら、すでに手遅れです。根が腐る速さは、地上部がしおれる速さよりはるかに速いのです。

### 7-3. マルチング

&nbsp;&nbsp;&nbsp;スベリヒユは、マルチングが要らないだけでなく、マルチングを妨げと感じる数少ない作物です。種子は光を受けてはじめてよく発芽するのに、わらや落ち葉で覆うとその光が遮られますし、茎が地面に張りついてはう植物なので、覆いの上に横たわることになり、かえって風通しが悪くなります。自然発芽を期待する場所なら、土をそのままむき出しにしておくほうがよいです。

&nbsp;&nbsp;&nbsp;ただし、向きを逆にすれば役に立ちます。スベリヒユ自体がマルチングの役割を果たします。地面をはって密に覆う性質のため、その下の土は直射日光で熱せられず、水分の蒸発が減ります。トマトやトウガラシの畝の空いた地面にスベリヒユが敷きつめられれば、生きた覆いになるわけで、根が浅いので、作物の水とも大きくは競合しません。この関係は第11節でもう一度扱います。
