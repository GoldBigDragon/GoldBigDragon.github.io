## 8. 栽培管理 - 管理された放任

### 8-1. 栽培ではなく境界の管理

&nbsp;&nbsp;&nbsp;スベリヒユの管理の性格は、他の作物とは根本的に異なります。他の作物で管理とは、育つのを助けることです。スベリヒユでの管理とは、どこまで育つのを許すかを決めることです。助けが必要な植物ではなく、線を引いてやらなければならない植物です。

| 管理項目 | 他の葉菜類 | スベリヒユ |
|---|---|---|
| 水 | 定期的な灌水 | 発芽期を除いて行わない |
| 肥料 | 元肥と追肥 | 施さない、または刈り取り後にごく少量 |
| 間引き | 必要 | 必要。唯一手間のかかる作業 |
| 雑草 | 抜いてやる | スベリヒユが他の草を抑える |
| 支柱 | 必要な場合がある | なし |
| 防除 | 必要 | 事実上なし |
| 境界 | 問題にならない | 最も重要な作業 |

&nbsp;&nbsp;&nbsp;最後の行が要点です。スベリヒユを畑に迎え入れると決めた瞬間から、この植物は毎年ひとりでに生えてきて、人が決めた区画を守ってくれません。種は雨水に流されて移動し、靴に付いて運ばれていきます。数年たつと畑全体に広がり、幼いニンジンや植え替えたばかりの苗を覆ってしまうことが起こります。雑草として扱われてきたのには、それだけの理由があります。

> **スベリヒユは、植える瞬間よりも、広がり始めたあとが問題です。迎え入れる場所を最初から狭く決め、その外側では花が咲く前に抜き取ってしまうことが、この作物の管理のすべてです。**

&nbsp;&nbsp;&nbsp;花が咲く前という条件が重要です。スベリヒユは、抜いて畑に放り出しておくと、根がなくても数日持ちこたえ、そのあいだにすでについた果実を熟させて種を落とします。抜いて放り出すことが、かえって種をまき散らす結果になります。花が咲いたあとに抜いたなら、畑の外へ運び出すか、乾かして焼くか、いっそ食べてしまうほうがよいでしょう。

### 8-2. 間引き

| 回 | 時期 | 残す間隔 | 備考 |
|---|---|---|---|
| 1回目 | 本葉2-3枚 | 5cm | 間引いたものは食べられます |
| 2回目 | 本葉4-5枚 | 10-15cm | 最終的な間隔です |

&nbsp;&nbsp;&nbsp;種がきわめて小さいため、ばらまくと必ず密生して生えます。そのままにしておくと、茎が互いに絡まって上へ伸び、下のほうが腐ります。ただし、他の作物と違って、間引きを急ぐ理由はありません。間引いた幼いスベリヒユそのものが、最も柔らかくておいしい状態だからです。本葉が2、3枚の幼いスベリヒユはサラダにするのに最適で、この時期が事実上の最初の収穫になります。

### 8-3. 摘心と再生

&nbsp;&nbsp;&nbsp;茎の先を切り取ると、節ごとに眠っていた芽が目を覚まし、側枝がいくつも伸びてきます。これがスベリヒユを何度も収穫できる原理であり、評価表の永続性Aの根拠です。

| 項目 | 基準 |
|---|---|
| 最初の刈り取り | 播種後6-8週間、茎が15-20cm |
| 切る位置 | 株元から2-3節上 |
| 再生期間 | 10-20日 |
| 繰り返す回数 | 霜が降りるまでに3-4回 |
| 刈り取り後の措置 | 水を1回、肥料はごく少量またはなし |

&nbsp;&nbsp;&nbsp;株元から2-3節を必ず残さなければならない理由は、新芽が節からしか出ないからです。根の近くまでぎりぎりに切ると、残る芽がなくて再生しないか、非常に遅くなります。逆に、上のほうだけを軽く切ると、株元に近い芽が目を覚まさず、株が上へ長く伸びるだけになります。中間の高さで切る理由はここにあります。

&nbsp;&nbsp;&nbsp;再生を繰り返すほど、茎は細くなり、葉は小さくなります。3回目、4回目の刈り取り分は、最初の収穫の半分ほどです。畑から養分を取り出し続けているのに、返すものがないので当然の結果で、肥料を少し入れれば和らぎはします。ただ、先に述べたとおり、肥料を入れると硝酸塩の濃度が上がるため、このあたりでその株を放っておいて、花を咲かせて採種する方向に切り替える判断も理にかなっています。

### 8-4. 越冬はできない

&nbsp;&nbsp;&nbsp;耐寒性Eが示すとおり、スベリヒユは冬を越せません。初霜で地上部が軟化して枯れ、根も生き残りません。ニラや長ネギのように、畑に立てたまま冬を越すことはできません。

&nbsp;&nbsp;&nbsp;その代わり、種子が冬を越します。秋に落ちた種は、土の中で凍っては解けるのを繰り返すうちに、むしろ休眠が破れ、翌年に地温が15℃を超えると発芽します。人がすべきことはひとつだけです。秋にその場所を耕し返さないことです。深く耕すと、種が発芽できない深さに埋まり、そうなると翌年には生えません。もちろん、その種は死なずに、数年後に再び掘り起こされたときに生えてきます。スベリヒユの種子の寿命が数十年といわれることの、実感できる姿がこれです。

&nbsp;&nbsp;&nbsp;冬にもスベリヒユを手に入れたいなら、方法は貯蔵しかありません。施設を暖めて育てることは、災害時の状況では成り立ちません。秋に干したり漬けたりしておいたものが冬の分で、その方法は第15節で扱います。

## 9. 病害虫 - ほとんどないということの意味

### 9-1. 評価等級と現場がずれる理由

&nbsp;&nbsp;&nbsp;評価表で病害虫圧C、防除自立度Cを見て、スベリヒユは病害虫に悩まされる作物だと考えたなら、それは読み違いです。この二つの等級は、スベリヒユを直接観察した結果ではありません。信頼度L6という表示が、その事情を物語っています。スベリヒユについての病害虫の研究資料がほとんどないため、双子葉植物綱全体の平均減収率50.6%を代わりに借りてきた値です。

&nbsp;&nbsp;&nbsp;実際には、スベリヒユに経済的な被害を与える病害虫はほとんど報告されていません。そもそもこの植物は、病害虫から守る対象ではなく、防除される雑草の側にあり、除草剤抵抗性が研究されたことはあっても、病害が研究されたことはまれです。防除自立度の項目の根拠欄に「防除不要」と書かれているほうが、現場にはるかに近いのです。

> **スベリヒユの病害虫等級がCなのは、この作物が弱いからではなく、これまで誰もこの作物を見守ってこなかったからです。**

### 9-2. それでも現れる問題

| 問題 | 症状 | 条件 | 薬剤に頼らない対応 |
|---|---|---|---|
| 根腐れ | 株元が褐色に軟化し、株が崩れます | 水がたまった場所、韓国の梅雨（チャンマ、6月下旬～7月） | 畝を立てて排水溝を作ります。すでに腐った株は取り除きます |
| ナメクジ | 葉に不規則な穴、粘液の跡 | 湿っぽく日陰になる場所、マルチの下 | 草木灰や珪藻土を周囲にまいて通り道をふさぎます。夜に手で取ります |
| アブラムシ | 新芽の先に群がってつきます | 窒素過多、乾燥 | 水で洗い流すか、石けん水をかけます |
| 灰色かび病 | 密植した株の内側が灰色にかびます | 密生して風通しが悪いとき | 間引いて間隔を広げ、下のほうの枯れ葉を取り除きます |
| カメムシ | 茎に針で刺したような跡、生育停止 | 周囲の雑草が茂っているとき | 畑の周りの古い草を片づけます |

&nbsp;&nbsp;&nbsp;五つを挙げましたが、このうち実際に収穫をだめにするのは、最初の行の一つだけです。残りは葉を数枚失う程度で、たいていはひとりでに過ぎ去ります。スベリヒユ栽培における失敗とは、病気にかかることではなく水に浸かることだとまとめても、大きくは間違っていません。

### 9-3. 薬剤に頼らない防除が簡単な理由

| 方法 | スベリヒユでの位置づけ |
|---|---|
| 排水管理 | 唯一、必ず行うべき防除です |
| 間引きによる風通しの確保 | カビの問題の大部分はこれで解決します |
| 手で捕まえる | 株が低く葉が大きいので、虫が目につきやすいです |
| 石けん水 | アブラムシとハダニに使います。葉が厚いので薬害が少ないです |
| 草木灰 | 株元の周りに巻いて、ナメクジを防ぎます |
| 木酢液 | 300-500倍に希釈してまきます。予防目的です |
| ボルドー液 | つくる必要がほとんどありません |

&nbsp;&nbsp;&nbsp;最後の行に注目します。ボルドー液は硫酸銅と生石灰でつくる伝統的な殺菌剤で、災害時の畑で最も貴重な防除手段です。ただし、材料を手に入れるのが難しく、つくるのに手間がかかります。その貴重な資源をスベリヒユに使うことはありません。ジャガイモの疫病やハクサイの軟腐病のように、1年の作柄を丸ごと台なしにする病気のために取っておくのが正しいやり方です。

&nbsp;&nbsp;&nbsp;葉が厚く、ワックス層が発達していることも、防除を容易にしています。石けん水や木酢液のような刺激性のある液体をかけても、柔らかい葉菜類のように葉が焼けません。濃度を少し間違えても、たいていは耐えてくれます。

### 9-4. スベリヒユが畑にあること自体が防除になる場合

&nbsp;&nbsp;&nbsp;スベリヒユ自体が、他の作物の防除に関わる方向もあります。二つのことが知られています。

&nbsp;&nbsp;&nbsp;一つ目は、おとり作物としての効果です。スベリヒユは、アブラムシやアザミウマをはじめとする一部の害虫が好む植物なので、そばにあると害虫がそちらに集まります。主作物が受けるはずだった被害を肩代わりしてくれるわけです。ただし、スベリヒユの上で害虫が増えて、結局は主作物に移るという逆の結果もありうるため、おとり作物として使うなら、害虫が集まったスベリヒユを定期的に取り除かなければなりません。

&nbsp;&nbsp;&nbsp;二つ目は、地表被覆の効果です。地面を覆って泥はねを防ぐと、土の中の病原菌が雨粒で跳ね上がって葉に移る経路が減ります。トマトやトウガラシの疫病や炭疽病は、この経路で広がる場合が多く、畝の表面が覆われているだけでも発病が減ります。ビニールマルチが担っていた役目を生きた草が代わりに果たすということで、ビニールがない状況では、この代替には実際的な価値があります。

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然素材での対処 |
|---|---|---|
| 葉全体が淡い緑色で、株が小さい | 窒素不足、または土地が極端にやせている | 尿を15倍に薄めた液を土に1回。そのままにしておいても収穫はできます |
| 葉が異様に大きく軟らかく、倒れやすい | 窒素過多 | 肥料をやめます。硝酸塩が蓄積した状態です |
| 葉が赤い、または紫がかって濃くなる | 低温、リン不足、または強い光と乾燥 | 大部分は正常な反応です。春先の低温期によく見られます |
| 古い葉の縁から枯れ込み、焼けたようになる | カリウム不足、または塩類過多 | 草木灰を少量ふりまきます。塩類が疑われる場合は、水をたっぷりやって洗い流します |
| 新芽が固まって奇形になる | カルシウムまたはホウ素の不足 | 貝殻と卵の殻を焼いて砕いたものを入れます |
| 茎が細く長く、節の間が開く | 光不足 | 栄養の問題ではありません。日陰から移さなければなりません |
| 葉に黄色い斑点が広がる | マグネシウム不足 | スベリヒユではまれです。過湿をまず疑います |

&nbsp;&nbsp;&nbsp;この表を読むときには、一つの前提を覚えておく必要があります。スベリヒユは、欠乏症状が見えにくい植物です。やせた土地に合わせてできた体なので、たいていの不足は、生育が少し遅れる程度で済んでしまいます。他の作物なら欠乏と診断する状態が、スベリヒユではただの普段の姿であることが多いのです。

&nbsp;&nbsp;&nbsp;そのため、実際により多く出会う問題は、不足ではなく過剰です。2行目の、葉が大きく軟らかく倒れる状態がそれです。見た目にはよく育ったようですが、組織が弱くて腐りやすく、貯蔵がいっそう難しくなり、硝酸塩が蓄積します。肥料を与えた手が、かえって品質を下げてしまった場合です。

&nbsp;&nbsp;&nbsp;3行目の赤みも、欠乏と誤診しやすい項目です。スベリヒユの茎が赤いのはもともとそういうもので、葉まで赤くなるのは、強い光と乾燥と低温に対する正常な色素反応です。むしろこの状態のスベリヒユのほうが、成分の濃度が高く、味が濃いです。リン不足と判断して肥料を入れる必要はありません。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 作物 | 理由 |
|:---:|---|---|
| 良い | トマト、トウガラシ、ナス | 畝を覆って泥はねと蒸発を防ぎます。背丈が違うので光を奪い合いません |
| 良い | トウモロコシ | どちらもC4なので、夏の高温でも一緒によく育ちます。ただし、トウモロコシの陰は避けなければなりません |
| 良い | カボチャ、マクワウリ | どちらも地面を這いますが、層が違うので共存できます |
| 普通 | マメ科の作物 | 争いは少ないものの、互いに与える利益も少ないです |
| 悪い | ニンジン、ホウレンソウ、ダイコン | 幼いときの生育が遅く、スベリヒユに覆われます |
| 悪い | 植え替えたばかりのすべての苗 | 活着する前に覆われると、そのまま枯れます |
| 悪い | 頻繁に水をやる作物 | スベリヒユのほうが過湿で腐ります |

&nbsp;&nbsp;&nbsp;この表で良し悪しを分ける基準は、背丈と時期です。スベリヒユは地面に張りついて横に広がるため、すでに育って背丈が立っている作物の下では何の害も及ぼさず、むしろ土を覆ってくれます。逆に、植えたばかりの苗や、幼いときの生育が遅い作物のそばでは、数日で覆い尽くしてしまいます。同じ植物が同じ畑で、助けになることもあれば災いになることもある理由が、ここにあります。

&nbsp;&nbsp;&nbsp;ヨウサイ（空芯菜）とは正反対の場所にいる、という点も知っておく価値があります。ヨウサイは水がたまる場所を受け持ち、スベリヒユは水はけのよい場所を受け持ちます。畑の中で湿ったところと乾いたところが分かれているなら、二つの作物を分けて配置するだけで、使えない土地がほとんどなくなります。

### 11-2. 輪作

&nbsp;&nbsp;&nbsp;評価表の連作適応性はSSです。同じ場所で毎年生えるのが正常な状態で、連作による被害は報告されていません。スベリヒユのための輪作計画は必要ありません。

&nbsp;&nbsp;&nbsp;ただし、他の作物の輪作計画の中で、スベリヒユがどんな役割を果たせるかは、別に考える理由があります。

| 配置 | 内容 | 効果 |
|---|---|---|
| 前作のあとの空き期間 | ジャガイモやニンニクを掘り上げたあとの夏の空き畑 | むき出しの地面を覆い、表土の流出と乾燥を防ぎます |
| 畝の肩と畝間 | 主作物が使わない場所 | 遊んでいる面積から食べ物が得られます |
| 畑の縁 | 境界の帯 | おとり作物と採取源を兼ねます |
| 新たに開墾したやせ地 | 初年度の作物 | ほかの作物が根づけない土地で、唯一収穫が得られます |

&nbsp;&nbsp;&nbsp;最後の行が、災害時には特に貴重です。砂利が多く有機物のない土地、長く放置されて固まった土地、建築の残土をかぶせた土地では、どんな野菜も初年度にはまともに育ちません。そんな土地でもスベリヒユは生えます。その場所で数年間スベリヒユを育て、刈り倒して敷くことを繰り返すと、表土に有機物が蓄積し、そうこうするうちに、他の作物を迎えられる土地に変わります。食べ物を得ながら同時に土地をつくる役割であり、緑肥作物の機能を兼ねるようなものです。
