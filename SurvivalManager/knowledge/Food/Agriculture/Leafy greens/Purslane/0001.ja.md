## はじめに
&nbsp;&nbsp;&nbsp;スベリヒユ(Portulaca oleracea)はスベリヒユ科の多肉質の一年草で、畑のあぜ、道端のコンクリートの割れ目、砂利地など、誰も世話をしない土地でひとりでに生えてきます。漢字名の馬歯莧は、葉が馬の歯に似ていることに由来します。総合等級はC(42.1点、有効183種中85位)ですが、副食はSS(69.2点)です。1株が数万粒の種をまき散らし、その種が土の中で数十年生き残るため、個体は一年草でも場所は事実上永続的です。そのため連作への適応性、種子の寿命、自家採種がSSで、施肥、水の消費量、施設の負担もSSです。栽培というより管理された放任に近く、人がすることは、どこに生やすかを決め、ほかの作物を押しのけないよう境界を守り、種が落ちるまで数株を残しておくことです。栄養では、葉物としては異例のオメガ3脂肪酸であるα-リノレン酸(ALA)を100g当たり300-400mg含む点が目立ちます。魚と油が消えた食事でまっさきに途切れるこの栄養素を、穀物、イモ類、葉物だけで満たす道はほとんどなく、スベリヒユはその数少ない通路です。弱点は、100g当たり16-20kcalで面積当たりの熱量がD、霜1回で枯れて耐寒性がE、常温で2-3日で傷んで貯蔵性がE、C4植物のため40%遮光で相対収量が約45%に落ちて日射がEであることです。シュウ酸がホウレンソウ並みに多くてたくさんは食べられず、似た毒草(トウダイグサ科のニシキソウ類)を見分ける必要があります。スベリヒユは畑の主役ではなく、畑の縁と空き地を受け持つ作物です。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | ナデシコ目スベリヒユ科スベリヒユ属の一年草。別名は馬歯莧(マチヒョン)、五行草(オヘンチョ)、長命菜(チャンミョンチェ)、トェジプル。原産地はインドまたは地中海東部と推定され、世界中に帰化。自然のこぼれ種で毎年同じ場所に再び生える |
| 葉、茎 | 葉は厚くつやのある多肉質のへら形(縁はなめらか)で、茎の先に集まってつく。茎は赤みから紫色の円柱形で、地面をはって20-30cm広がる。切ると透明な汁が出て、白い汁は決して出ない |
| 根、花、果実 | 太い白い根が1本に浅い側根で、切られても節からまた根が出る。直径5mmほどの黄色い花(花弁5枚)が6-9月の晴れた日の午前にだけ開く。果実はふたのように横に割れる蓋果で、黒く小さな種が数十粒 |

| 段階 | 時期(播種後) | 要点 |
|:---|:---|:---|
| 発芽、幼苗期 | 2週間まで | ごく小さな子葉が2枚。この時期だけが唯一弱い |
| 栄養成長期 | 2-6週間 | 茎が地面をはって広がり、葉が厚くなる |
| 収穫適期 | 6-8週間 | 茎15-20cm、葉と茎がもっとも軟らかい |
| 開花、結実期 | 8-12週間 | 節ごとに花が咲いて実がつき、茎が硬くなる |

> **スベリヒユは、水があるときはC4で速く育ち、水が途絶えるとCAMに乗り換えて成長を止めて耐えます。畑に水を引けない状況では、この切り替えがそのまま生存です。**

&nbsp;&nbsp;&nbsp;CAMは夜に気孔を開けて二酸化炭素を取り込むため、水の損失がごく少なくなります。C4は強い光と高温で効率がよく、光が弱いと損が大きいので、スベリヒユは夏をもっとも好み、日陰に弱いのです。

&nbsp;&nbsp;&nbsp;100g当たり熱量16-20kcal(資料によって7-20kcal)、水分約93g、タンパク質約2.0g(熱量比40.6%)、脂質約0.4g、α-リノレン酸300-400mg、カリウム494mg、マグネシウム68mg、カルシウム65mg(シュウ酸のため吸収率が下がる)、鉄0.9-2.0mg、ビタミンC21mg(ゆでると半分以上が失われる)です。ビタミンEは山菜・野菜類の中で高く、チアミン、ナイアシン、ビタミンB6、葉酸もあります。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽の最低は約15℃、適温20-30℃(3-7日)。生育適温20-35℃、可能範囲10-35℃(幅25℃)。40℃以上でも枯れず、5℃以下で生育が止まり、0℃や霜1回で地上部が軟らかくなって枯れる |
| 光 | 1日じゅう日の当たる場所。40%遮光で相対収量約45%。半日陰では茎が細く長くなり、深い日陰では発芽もしにくい |
| 水、土壌 | ほぼどんな土でも(砂利地、砂地、固い道端)。pH5.6-7.8、有機物は不要、塩分にかなり強い。灌水は発芽期以外は不要(合計250L/㎡未満でも育つ)。気にするのは排水だけで、枯れる原因はほとんどいつも水が足りないからではなく、水が抜けないから |

| 系統 | 特徴 |
|:---|:---|
| 野生型(トゥルスェビルム) | 葉が小さく茎が地面に張りつき、収量が少ない。どこでもひとりでに生えるので、確保に手間がかからない |
| 大葉種(クンニプスェビルム) | 葉が広くて厚い大きな株で、同じ面積から野生型の2倍近く収穫できる |
| 小葉種、直立型 | 小葉種は成分が濃く薬用と茶に向き、直立型(黄金スベリヒユなど)は茎が立って切りやすく、横に広がりにくいので境界を守りやすい |

> **スベリヒユでは、品種選びよりはるかに重要なのは、どこで摘むかです。道端や空き地で育ったスベリヒユは排気ガス、除草剤、重金属にさらされており、この植物はそうした物質を組織にためる性質があります。**

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 土づくり | 根が浅いので10-15cmだけ耕し、排水のため低くてもよいので畝を立てる。酸度の矯正と有機物は行わない(肥料が多いと葉だけ軟らかくなって徒長する)。1日じゅう日の当たる場所 |
| 施肥 | 入れるものはない。窒素だけ刈り取り後にごく少量(新芽の再生を助けるだけで、なくても再生する)。リン酸、カリウム、堆肥、石灰は入れない |
| 代替資源 | 人の尿の10-15倍希釈液(刈り取り直後に溝へ、ほかの作物より薄く)、完熟堆肥一つかみ(厚くかぶせると茎が触れて傷む)、木灰一つかみ、草の液肥の10倍希釈、腐葉土(発芽する場所に薄く)。肥料が乏しいときは、ケール、ハクサイ、長ネギに回すほうが全体の収穫が増える |

| 時期 | 播種 | 収穫 | 備考 |
|:---|:---|:---|:---|
| 露地の春 | 4月中旬-5月 | 5月下旬-10月 | 霜の心配が完全になくなってから |
| 露地の夏 | 6月-7月初め | 7-10月 | 地温が高く発芽が最も速い |
| 自然発芽 | まかない | 6-10月 | 前年に種が落ちた場所からひとりでに生える。実際の運用の中心 |

| 播種 | 基準 |
|:---|:---|
| 方法 | 深さ0.2-0.5cmでほとんど覆わず、手のひらや板で押さえて種と土を密着させる(光を受けて発芽しやすいので深く埋めてはいけない)。種がごく小さいので乾いた砂や細かい土に10倍に混ぜてばらまきか条まきにする。条間20-30cm、地温20-30℃で3-7日で発芽 |
| 種子の処理 | 温湯浸漬や薬剤消毒は不要。ふるった木灰を軽くまぶすと表面の消毒になり、まいた場所が見える |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から発芽 | 表土が乾かないように(この2週間だけ人の手が必要) |
| 幼苗期 | 2-3日に1回。その後は急に強くなる |
| 栄養成長期 | 与えなくてよい(乾くと葉が厚くなるだけ) |
| 収穫期 | 刈り取り直後に1回(新芽の再生が速くなる) |
| 開花、結実期 | むしろ止める(乾燥するほど種がよく実る) |

&nbsp;&nbsp;&nbsp;葉が小さく厚くなって赤みを帯びるのは水不足への正常な適応で、干ばつでCAMに切り替わると、明け方に摘んだ葉はとくに酸っぱくなります。茎が細く長く色が薄ければ光不足なので場所を移し、株元から褐色に軟らかくなれば過湿で腐っているので数日で株全体が崩れます。マルチは不要でむしろ邪魔であり、スベリヒユ自体が地面を覆うマルチの役をします。

| 管理 | 内容 |
|:---|:---|
| 境界 | 最も重要な作業。使う場所を最初から狭く決め、その外では花が咲く前に引き抜く |
| 間引き | 1回目は本葉2-3枚で5cm、2回目は4-5枚で10-15cm(最終)。間引いたものは食べる。種が小さくばらまきだと密に生えるため、唯一手がかかる作業 |
| 摘心、再生 | 最初の刈り取りは播種後6-8週間、茎15-20cm。株元から2-3節上で切ると(新芽は節からしか出ない)10-20日で再生し、霜が来るまで3-4回。繰り返すほど茎が細く葉が小さくなる |
| 越冬 | 冬を越せず、種が冬を越す。冬に得るには貯蔵しかない |

> **スベリヒユは、植える瞬間よりも広がり始めたあとが問題です。使う場所を最初から狭く決め、その外では花が咲く前に引き抜くのが、この作物の管理のすべてです。**

## 6. 病害虫と養分の問題
| 問題 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| 根腐れ | 株元が褐色に軟らかくなり、株が崩れる。水がたまる場所、梅雨 | 畝と排水溝、腐った株は取り除く |
| ナメクジ | 葉に不規則な穴と粘液の跡。湿って日陰の場所 | 灰や珪藻土を周りにまく、夜に手で捕る |
| アブラムシ、灰色かび病 | 新芽の先に群がる(窒素過多、乾燥) / 密植した株の内側が灰色にかびる(風通しが悪い) | 水で洗い流すか石けん水 / 間引いて間隔を広げ、枯れ葉を取る |
| カメムシ | 茎に針の跡、成長が止まる。周りの雑草が茂っているとき | 畑の周りの古い草を片付ける |

> **スベリヒユの病害虫の等級がCなのは、この作物が弱いからではなく、誰もこの作物を見守ったことがないからです。**

&nbsp;&nbsp;&nbsp;実際に収穫をだめにするのは根腐れだけで、あとは排水、間引きによる風通し、手で捕る、石けん水(葉が厚くて薬害が少ない)、木灰の帯、木酢液の300-500倍で片づきます。スベリヒユが畑にあること自体が防除になることもあります。主作物の代わりに虫を引き受ける捕獲作物になり、裸地を覆って泥はねと蒸発を防ぎます。

| 症状 | 原因と対処 |
|:---|:---|
| 葉が淡い緑色で株が小さい | 窒素不足または極端な痩せ地。尿の15倍希釈液を1回(そのまま置いても収穫はできる) |
| 葉がとくに大きく軟らかく倒れやすい | 窒素過多(硝酸塩がたまった状態)。肥料をやめる |
| 葉が赤や紫色に濃くなる | 低温、リン酸不足、強い光と乾燥。たいてい正常な反応 |
| 古い葉の縁が枯れて焦げる | カリウム不足または塩類過多。木灰を少量、塩類は水で洗い流す |
| 新芽が固まって奇形になる | カルシウムまたはホウ素の不足。貝殻と卵の殻を焼いて砕いて入れる |

&nbsp;&nbsp;&nbsp;茎が細く長ければ光不足であって、栄養の問題ではありません。スベリヒユは不足より過剰に出会うことのほうが多いので、迷ったらまず肥料をやめます。

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | トマト・トウガラシ・ナス(畝を覆って泥はねと蒸発を防ぎ、背丈が違うので光を奪い合わない)、トウモロコシ(どちらもC4で夏の高温でよく育つが、トウモロコシの陰は避ける)、カボチャ・マクワウリ(どちらも地をはうが層が違うので共存できる) |
| 悪い | ニンジン・ホウレンソウ・ダイコン(若いうちは遅くてスベリヒユに覆われる)、植えたばかりの苗(根づく前に覆われるとしおれる)、水を頻繁にやる作物(スベリヒユが過湿で腐る) |

&nbsp;&nbsp;&nbsp;連作への適応性がSSなので輪作は不要ですが、ほかの作物の輪作の中では、ジャガイモやニンニクを掘ったあとの夏の空き畑を覆う作物、主作物が使わない畝の肩と溝、捕獲作物と採取源を兼ねる畑の縁の帯として使えます。ほかの作物が根づけない新しく開いた痩せ地では、初年度に唯一収穫できる作物です。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 若葉は4-5週間(間引きと兼ねる、最も軟らかい)、通常の収穫は6-8週間(茎15-20cm、花が咲く前)、再収穫は刈り取り後10-20日(新芽が15cmになったとき)、薬用・茶用は開花期の前後(成分が最も濃い) |
| 要領 | 株元から2-3節上をはさみや鎌で、茎先10-15cmずつ切る(根が浅く、手で摘むと根ごと抜ける)。葉の裏に土がたくさんつくので、水に浸して振り、流水ですすぐ |
| 刈り取り回ごとの収量 | 1回目が最も多く、2回目は70%、3回目は50%で、4回目(3回目から20日以上後)は少なく硬いので、たいていここで終える |

| 採種 | 基準 |
|:---|:---|
| 特性 | 自家受粉なのでほかの株と混ざる心配がなく、1株が数千から数万粒の種をつけ、種子は土の中で数十年発芽力を保つ。ほとんどひとりでに進むので、採種は任意 |
| 手順 | 刈り取りをやめ、花を咲かせる株を数株決める。果実が褐色に乾いて上部がふたのように開きそうなとき(9-10月)に茎ごと切り、紙や布の上で逆さにして干し、乾いた茎を手でもんで種を落とし、密閉容器に入れて涼しく暗い所に置く |
| 保存の寿命 | 土の中の自然状態で数十年、常温で密閉して5年以上、涼しく乾燥していれば10年以上。湿るとかびて使えなくなる |

> **スベリヒユの果実は熟すとふたのように横に割れて種をこぼします。完全に乾くまで待つと、種はすでに地面に落ちたあとです。**

## 9. 貯蔵
| 方法 | 手順と期間 |
|:---|:---|
| 畑に置く | 刈らずに霜が来るまで置き、必要な分だけ切る。事実上唯一の本当の答え。根ごと抜いて日陰に置けば3-5日、株元を水に浸せば2-3日 |
| 乾燥 | 洗って土を落とし、沸騰した湯で30秒-1分ゆで(色が残りシュウ酸が減る)、できるだけ絞って水気を切る。日陰の風通しのよい所に広げ(直射日光で干すと成分が壊れる)、灰や炭と一緒に密閉容器で保存 |
| 漬物、発酵 | 塩3-5%で層に重ねて涼しい所で2-3か月 / 2-3%の塩水に沈めて押さえ1-2週間発酵させてから涼しい所で1-2か月 / 醤油や味噌に漬けて数か月 |

&nbsp;&nbsp;&nbsp;貯蔵性E、常温で2-3日がスベリヒユの最大の弱点なので、畑そのものが貯蔵庫です。干したスベリヒユは生とは性質が変わり、冬にナムルや茶として使います。乳酸発酵は塩を節約しながら貯蔵期間を稼ぐ方法で、スベリヒユは粘りがあるので漬けるとぬめりが強まります。

## 10. 調理と注意事項
| 方法 | 要領 |
|:---|:---|
| 生食 | 洗ってそのまま。燃料がいらず、酸味と粘りが特徴で、ビタミンCが丸ごと残る |
| ゆでナムル | 沸騰した湯で30秒-1分(それ以上はゆでない)、冷水ですすいで和える。シュウ酸が減り、かさが減ってたくさん食べられる |
| 炒め物、汁物、お粥 | 油で2-3分炒めるとβカロテンの吸収がよくなる / 汁物や鍋物には最後に入れる(長く煮ると溶ける) / 穀物のお粥に刻んで入れると粘りでとろみがつく |
| 茶 | 干したものを煮出す。冬の利用法 |

| 成分 | 問題と対応 |
|:---|:---|
| シュウ酸 | 生100g当たりおよそ1,000-1,700mgで、ホウレンソウと同程度かそれ以上。カルシウム、鉄、マグネシウムと結合して吸収を妨げ、食べ過ぎると腎結石の危険がある。腎結石の既往がある人や腎機能の悪い人はとくに注意。ゆでて湯を捨てれば30-50%が抜けるので、生では1日100g前後、それ以上はゆでて食べる |
| 似た毒草(ニシキソウ類) | トウダイグサ科のニシキソウ類は切り口に白い乳のような汁が出て、葉が薄く紙のようで、必ず対生で、縁に細かい鋸歯があり、中央に紫色の斑点があることが多い。スベリヒユは汁が透明で、葉が厚い多肉質で互生、縁がなめらか。食べると口と喉が焼けるようになり、嘔吐と下痢を起こす |
| 汚染 | 自分の畑や菜園は安心。道路の縁は鉛などの重金属と排気ガスの沈着で危険が高く、田畑の縁は除草剤の心配があり、長く放置された空き地は以前の用途がわからなければ避ける。工場・廃棄物の敷地では採らない |

> **茎を切ったり葉をちぎったりして白い汁が出たら、スベリヒユではありません。この1点を確かめるだけで、トウダイグサ科の毒草をほぼすべて除けます。**

&nbsp;&nbsp;&nbsp;見分けに自信がつくまでは、必ず1株ずつ茎を折って確かめます。名前の似たヒユ類はスベリヒユとは別の仲間ですが、どれも食べられるので、取り違えても危険はありません。伝統的にスベリヒユは性質が冷たい植物とされ、体が冷えやすい人には勧められてきませんでした。

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 種を涼しく乾燥した所で保管、干したスベリヒユでナムルと茶 |
| 3-4月 | 3月に日当たりがよく水がたまらない場所を決める。4月に霜が完全に過ぎてから、土をほとんどかぶせず押さえて播種 |
| 5-6月 | 5月に発芽期の水管理と1回目の間引き(間隔5cm、間引いたものは食べる)。6月に2回目の間引き(10-15cm)、前年に種が落ちた場所から自然発芽が始まる |
| 7-8月 | 7月に1回目の刈り取り(株元に2-3節を残す)、高温期の最盛期。8月に2回目、3回目の刈り取りを繰り返す |
| 9-10月 | 9月に刈り取りを終え、採種用の株を残して花を咲かせる。10月に果実が褐色になったら茎ごと刈って日陰で干して種を採り、残りはゆでて干す |
| 11-12月 | 11月に初霜で地上部が枯れ、その場所は耕さずに置く。12月に干したものと漬けたものを利用し、種を点検 |

> **スベリヒユが食卓を守るのは、ほかの野菜が暑さで崩れる7月と8月です。この2か月が、この作物を植える実質的な理由です。**
