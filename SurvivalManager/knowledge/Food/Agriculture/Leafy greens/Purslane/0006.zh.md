## 12. 收获 - 割了再割

### 12-1. 判断时期

| 用途 | 播种后 | 状态 |
|---|:---:|---|
| 嫩叶（沙拉） | 4-5周 | 兼作间苗。最柔嫩 |
| 一般收获 | 6-8周 | 茎长15-20cm，开花之前 |
| 再次收获 | 收割后10-20天 | 新芽再次长到15cm时 |
| 药用·茶用 | 开花期前后 | 成分最浓的时候 |
| 留种用 | 在韩国为9-10月 | 果实变褐干枯时 |

&nbsp;&nbsp;&nbsp;开花之前这个条件是最实用的标准。马齿苋一开始开花，茎中的纤维就会增多变老，叶片也会变小。黄色的花一开始显眼，就可以认为这一株已经从食用转向了留种。

&nbsp;&nbsp;&nbsp;采收的时间也会影响味道。因干旱而发生CAM转换的植株，整夜积累的有机酸在黎明时达到最高点。这就是黎明时摘的马齿苋格外酸的原因，想减少酸味，最好在日出后几小时再摘。反过来，想保留酸味用于沙拉，则以清晨为好。不过，在正午烈日下摘的，组织很快变软，不利于贮藏。

### 12-2. 收获要领

| 项目 | 内容 |
|---|---|
| 剪切高度 | 从基部往上2-3节 |
| 工具 | 剪刀或镰刀。用手掰会连根拔起 |
| 一次收获的部位 | 茎尖10-15cm |
| 收获后的泥土 | 是匍匐生长的植物，叶背会沾上很多泥土 |
| 清洗 | 泡在水里晃洗后，再用流水冲洗 |

&nbsp;&nbsp;&nbsp;根浅而软，用手掰的话常常整株被连根拔起。如果打算收一次就结束，倒无所谓，但若期待再生，就一定要用工具剪。没有工具的话，一只手按住基部，另一只手把茎折断。

&nbsp;&nbsp;&nbsp;沾泥多是比想象中更麻烦的问题。叶片厚而内凹，泥粒容易嵌进去，茎又贴地生长，所以每个节上都沾着泥。在缺水的情况下，清洗所用的水也不是小数目。替代办法是先在田里抖掉。割下来后当场抖几下再装进篮子，洗涤用水就能减半。选择直立型品系的话，这个问题会大大减轻。

### 12-3. 一处能收获多少

| 次序 | 时期 | 产量 |
|---|---|---|
| 间苗收获 | 播种后4-5周 | 少。柔嫩 |
| 第1次收割 | 6-8周 | 最多 |
| 第2次收割 | 第1次后10-20天 | 约为第1次的70% |
| 第3次收割 | 第2次后15-20天 | 约为第1次的50% |
| 第4次收割 | 第3次后20天以上 | 少而老韧。通常到此为止 |

&nbsp;&nbsp;&nbsp;次数越多，产量越少，也越老韧。田里的养分只出不进，这是理所当然的结果。与其勉强拖到第4次，不如在第3次就停下，让那一株开花。这样种子才会落下，来年这个位置才能保住。

## 13. 留种 - 协助自然完成的方法

### 13-1. 留种容易的原因

&nbsp;&nbsp;&nbsp;在评价表中，自家留种和种子寿命都拿到SS的作物非常罕见。原因有三。

| 原因 | 内容 |
|---|---|
| 自花授粉 | 自己授粉。不用担心与其他植株混杂 |
| 多产 | 一株结出几千到几万粒种子 |
| 长寿 | 在土中数十年保持发芽力 |

&nbsp;&nbsp;&nbsp;大葱或羽衣甘蓝所面临的杂交问题，马齿苋没有。花还没开，就已经用自己的花粉完成了受精，所以旁边无论是什么品系，种子都不会混杂。这意味着既不用测量隔离距离，也不用罩网，从种子自给的角度看，是最省事的作物之一。

### 13-2. 留种方法

| 步骤 | 内容 |
|---|---|
| 选定留种植株 | 停止收割，选几株留着开花 |
| 判断成熟 | 果实变褐干枯，上部快要像盖子一样裂开时 |
| 收获 | 连茎剪下，在纸或布上倒置晾干 |
| 分离 | 用手搓干枯的茎，把种子抖落下来 |
| 精选 | 用筛子筛，或迎风吹，去掉秕粒 |
| 干燥 | 在阴凉处彻底晾干 |
| 保存 | 装入密闭容器，放在阴凉避光处 |

> **马齿苋的果实成熟后，会像盖子一样横向裂开，把种子洒出来。等到完全干透，种子早已掉到地上了。**

&nbsp;&nbsp;&nbsp;由于这个特性，留种最重要的是时机。在果实刚开始变褐、尚未裂开时，连茎割下，倒挂在阴凉处。下面铺上布或纸，干燥时果实会自己裂开，种子就落下来了。种子非常小又是黑色的，一旦掉在土上，就再也捡不回来了。

&nbsp;&nbsp;&nbsp;不过要指出的是，这一切作业其实都是可选项。不留种、直接放着不管，种子也会落在田里，来年自己长出来。人要留种的理由只有两个：一是为了移到别的地方去种，二是那块地有翻耕的计划。

### 13-3. 保存与寿命

| 条件 | 发芽力保持 |
|---|---|
| 土中自然状态 | 数十年。本表中最高 |
| 常温密闭保存 | 5年以上没有问题 |
| 阴凉干燥处 | 10年以上 |
| 潮湿处 | 一旦长霉就彻底不能用了 |

&nbsp;&nbsp;&nbsp;其他作物的种子保存，通常以发芽率逐年下降为前提，制定每隔几年更新一次的计划。马齿苋没有这个必要。一次留下的一袋种子，足以支撑人的一代。在不知道灾难会持续几年的情况下，这一特性近似于保险。它几乎不占体积，一勺的量就够种几千株。

## 14. 毒性与需注意的成分 - 草酸与相似的毒草

### 14-1. 草酸

&nbsp;&nbsp;&nbsp;马齿苋是食用植物，只要吃正常的量就是安全的。不过，有一种成分对摄入量划了界线。那就是草酸。

| 项目 | 内容 |
|---|---|
| 含量 | 每100g鲜品约1,000-1,700mg。与菠菜相近或更高 |
| 在体内的作用 | 与钙、铁、镁结合，阻碍吸收 |
| 过量摄入时 | 肾脏中可能形成草酸钙结石 |
| 特别需要注意的人 | 有肾结石病史的人、肾功能不好的人 |
| 减少的方法 | 用沸水焯后倒掉焯水，可去除30-50% |

&nbsp;&nbsp;&nbsp;灾难情况特有的处境叠加了进来。平时马齿苋只是作为配菜吃上一两筷子就完了，但食物不足时，人们会把田里白得的这种草当作主食大量地吃。草酸问题真正凸显的就是这种情况。而且这种情况通常也是钙摄入同时不足的时候。在牛奶和连骨吃的鱼都没了的饮食中，仅有的一点钙再被草酸束缚住，损失就很大。

> **马齿苋可以每天吃，但不是适合每餐吃饱的作物。生吃时每天100g左右，吃得比这更多时，焯水并倒掉焯水，是安全的界线。**

&nbsp;&nbsp;&nbsp;焯水为什么有效，也值得了解。草酸是易溶于水的成分，用沸水焯过之后，相当一部分会溶到水里。如果把焯水当汤用就毫无意义，所以必须倒掉。不过，维生素C也会一起流失，所以如果想摄取维生素C，合理的做法是生吃一点，需要吃够量时则焯水后再吃。发酵也能减少一部分草酸。

&nbsp;&nbsp;&nbsp;传统上把马齿苋看作性寒的植物，不推荐给体寒的人，这一点也有文献记载。实际上，它含钾多，有利尿作用，并向降低血压的方向起作用，所以有低血压或常拉肚子的人，最好减少食用量。

### 14-2. 相似的毒草 - 大戟科与地锦草类

&nbsp;&nbsp;&nbsp;这一节是本文中最重要的部分。在田里或路边采集马齿苋时，有一种毒草几乎在同样的地方、以几乎相同的样子生长。那就是大戟科（Euphorbiaceae）的地锦草类，也就是斑地锦和大地锦之类的草。

| 类别 | 马齿苋 | 地锦草类（大戟科） |
|---|---|---|
| 切口处的汁液 | 清澈透明 | 流出白色乳汁般的汁液 |
| 叶片厚度 | 厚而肉质 | 薄如纸片 |
| 叶序 | 互生，聚生于茎端 | 一定是对生 |
| 叶缘 | 光滑 | 有细锯齿 |
| 叶面斑纹 | 没有 | 中间常有紫红色斑点 |
| 茎 | 粗壮多汁 | 细而坚韧，有细毛 |
| 花 | 黄色花瓣5片，直径5mm | 看似花瓣的部分白色或红色，非常小 |
| 吃下去之后 | 可食用 | 口腔和喉咙灼痛，引起呕吐和腹泻 |

> **割断茎或摘下叶片时，如果流出白色汁液，那就不是马齿苋。只确认这一点，就几乎能把大戟科毒草全部排除。**

&nbsp;&nbsp;&nbsp;大戟科植物白色汁液中所含的成分会刺激皮肤和黏膜。汁液进入眼睛会引起严重炎症，吃下去则口腔和喉咙像烧着一样疼，并伴有呕吐和腹泻。致命的情况罕见，但在灾难情况下，连续几天既吃不下东西又无法活动，本身就是危险。白色汁液沾到手上也必须洗掉，采集时如果碰到了，就不能用那只手揉眼睛。

&nbsp;&nbsp;&nbsp;学会分辨最可靠的方法是：在没有把握之前，一定要一株一株地把茎掐断看看。马齿苋粗壮的茎带着水分利落地折断，只渗出少许清澈的汁液。地锦草细细的茎会坚韧地撕裂，断口处凝出白色的小滴。这是看过一次就很难忘记的差别。

&nbsp;&nbsp;&nbsp;顺带一提，名字相近的凹头苋和苋菜属于苋科植物，与马齿苋不是同一类，但都可以食用，所以即使混淆也没有危险。危险的只有会流出白色汁液的那一类。

### 14-3. 因生长地点造成的污染

| 采集地点 | 风险 | 判断 |
|---|---|---|
| 自家田地、菜园 | 低 | 可放心使用 |
| 车道边 | 高 | 铅等重金属和尾气沉降 |
| 农田边 | 中等 | 可能喷过除草剂 |
| 工厂·废弃物场地 | 非常高 | 不要采集 |
| 长期撂荒的空地 | 中等 | 不清楚以前用途的话要避开 |

&nbsp;&nbsp;&nbsp;已知马齿苋是一种会把土壤中的重金属积聚在组织里的植物，甚至被研究用于净化污染的土地。这一特性对植物来说是生存策略，对吃它的人来说却是危险。长势良好并不能证明那个地方是干净的。相反，正因为它在无人照管的土地上也能长得好，在人最不该碰的土地上，反而可能长得最茂盛。

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;耐储性E，常温下2-3天，这是马齿苋最大的弱点。含水量93%的肉质组织，从被割下的那一刻起就开始崩溃。在没有电的情况下，没有办法正面解决这个弱点，只有改变其性状，或把田地当作储藏库使用这类迂回办法。

### 15-1. 田地就是储藏库

| 方法 | 期限 | 条件 |
|---|---|---|
| 不割，留在田里 | 到霜降前 | 需要时只割需要的量 |
| 连根拔起放在阴凉处 | 3-5天 | 带着泥土放着能放得更久 |
| 用湿布包好放在阴凉处 | 3-5天 | 有地窖或土窖的话能放得更久 |
| 基部泡在水里 | 2-3天 | 到叶片变软之前 |

&nbsp;&nbsp;&nbsp;第一行实际上是唯一像样的答案。对于耐储性差的作物，解决办法就是不贮藏，而马齿苋在韩国从6月到10月，四个多月都立在田里承担这个角色。在这段时间里没有必要贮藏马齿苋，而这段时间一过，贮藏起来的也放不久。所以实际的运作方式是：夏天一直摘着吃，秋天只晒干冬天要吃的那一份。

### 15-2. 干燥

| 步骤 | 内容 |
|---|---|
| 整理 | 洗净，抖掉泥土，沥干水分 |
| 焯水 | 沸水中30秒到1分钟。也可以省略，但焯水能保住颜色，并减少草酸 |
| 去除水分 | 尽量挤干。水分残留的话，干燥过程中会发霉 |
| 摊晾 | 阴凉通风处。直接在阳光下晒会破坏成分 |
| 判断完成 | 用手搓能搓碎为止 |
| 保存 | 放入密闭容器，同时放入草木灰或木炭吸湿 |

&nbsp;&nbsp;&nbsp;干燥适合马齿苋是有原因的。水分多，晒干后体积缩小到10%以下，一筐变成一把。这意味着几乎不占保管空间，在贮藏资源不足的情况下是很大的优势。晒得透、密封好的，可以放半年到一年。

&nbsp;&nbsp;&nbsp;不过，干马齿苋与鲜品的性质完全不同。维生素C几乎不剩，口感变得韧。作为补偿，矿物质、脂肪酸和膳食纤维都保留下来，反而被浓缩。因此，干马齿苋的定位不是冬季的维生素来源，而是矿物质和脂肪酸的补充来源，同时也是熬汤的材料。可以用水泡发后拌成凉拌野菜（namul），放进汤里，或者煮成茶喝。

### 15-3. 腌制与发酵

| 方法 | 步骤 | 期限 |
|---|---|---|
| 盐腌 | 用重量3-5%的盐一层层腌 | 阴凉处2-3个月 |
| 咸菜（jjanji，重盐腌菜） | 浸入10%以上的浓盐水中，使其淹没 | 半年以上。吃之前泡水去咸味 |
| 乳酸发酵 | 浸在2-3%的盐水中，压住使其淹没 | 发酵1-2周后，在阴凉处放1-2个月 |
| 酱菜 | 用酱油或大酱腌渍 | 几个月 |

&nbsp;&nbsp;&nbsp;乳酸发酵是节省盐的同时延长贮藏期的方法。2-3%的盐水是既抑制杂菌又保留乳酸菌的浓度，乳酸菌产生的酸使pH下降，使腐败菌无法生长。把材料压住使其淹没、不接触空气，是成败的关键。表面漂浮的白色霉层可以撇掉，但如果长出黑色或青色的霉，就必须扔掉。

&nbsp;&nbsp;&nbsp;马齿苋本来就带有黏性，腌过之后滑腻的口感会变强。有人不喜欢这一点，也有地区恰恰因为这种口感而喜欢吃。放进盐水前先稍微焯一下，黏性就会减少。

## 16. 烹饪与加工

| 方法 | 燃料 | 步骤 | 备注 |
|---|:---:|---|---|
| 生吃 | 0 | 洗净直接吃 | 特点是酸味和黏性。维生素C完好 |
| 焯水凉拌野菜（namul） | 少 | 沸水中30秒到1分钟，用冷水冲洗后凉拌 | 草酸减少，体积变小，能吃得更多 |
| 炒 | 少 | 用油炒2-3分钟 | β-胡萝卜素吸收更好 |
| 汤与炖菜（jjigae） | 中等 | 最后放入 | 久煮会化掉 |
| 粥 | 中等 | 剁碎放入谷物粥中 | 黏性能使粥变得浓稠 |
| 茶 | 少 | 煮干制品 | 冬季的利用方式 |
| 发酵 | 0 | 参见第15节 | 兼具贮藏和烹饪 |

&nbsp;&nbsp;&nbsp;评价表中烹饪·加工为SS，意思是洗净就能直接吃，在燃料珍贵的情况下，这一项的价值很大。不过，由于前一节讲到的草酸，不建议大量生吃。实际运作分成两部分：每天少量生吃，需要吃够量时则焯水并倒掉焯水。

&nbsp;&nbsp;&nbsp;焯水时，要领是不超过30秒到1分钟。因为是肉质组织，一受热转眼就软烂了。水再次烧开的那一刻，就是捞出的时候。焯完用冷水冲洗，既能保住颜色，又能防止因余热而进一步变软。

&nbsp;&nbsp;&nbsp;怎样处理黏性，是马齿苋烹饪的分岔口。马齿苋含有称为黏液质（mucilage）的黏性物质，焯过之后会有滑溜溜的口感。评价表中口味等级为S，但口感却因人而异、好恶分明，原因就在于此。如果不喜欢，焯水后用冷水多冲洗几遍，就能大大减少；反过来，如果利用这种黏性，它就成了让粥和汤变浓稠的材料。在淀粉珍贵的情况下，可以把它当作给汤增稠的材料。

&nbsp;&nbsp;&nbsp;与油一起吃的烹饪方式尤其有价值。马齿苋的β-胡萝卜素和维生素E是脂溶性的，要有油才能充分吸收。而且这种植物所含的α-亚麻酸本身就是脂肪，用油炒的话，这种成分更容易从组织中释放出来。如果有紫苏油，它本身就是ω-3脂肪酸的来源，搭配得很合适。

## 17. 全年作业日程

| 月份（以韩国气候为准） | 作业 |
|---|---|
| 1-2月 | 把种子保存在阴凉干燥处。用干马齿苋做凉拌野菜（namul）和茶 |
| 3月 | 选定种植的地方。向阳且不积水的地方 |
| 4月 | 霜完全过去后播种。几乎不覆土，只轻轻压实 |
| 5月 | 发芽期的水分管理。第1次间苗（间距5cm）。间下来的苗食用 |
| 6月 | 第2次间苗（间距10-15cm）。前一年落种的地方开始自然发芽 |
| 7月 | 开始第1次收割。留下基部2-3节剪切。高温期的全盛期 |
| 8月 | 反复进行第2次、第3次收割。其他蔬菜被酷暑压垮的空档期的主力 |
| 9月 | 收割收尾。留出留种用的植株，让它们开花 |
| 10月 | 果实变褐后连茎割下，在阴凉处晾干取种。剩下的焯水晒干 |
| 11月 | 初霜使地上部分枯死。那块地不翻耕，放着 |
| 12月 | 利用干制和腌制的。检查种子 |

&nbsp;&nbsp;&nbsp;这张表中值得留意的是11月那一行。不翻耕那块地，就是来年农事的全部。秋天落下的种子必须靠近表土，来年春天才能受光发芽。深翻的话，种子被埋住，当年就不会长出来。

&nbsp;&nbsp;&nbsp;还有，7月和8月这两行是种这种作物的实际理由。盛夏是生菜、菠菜和大白菜全部垮掉的时期，也是灾难情况下田里新鲜叶菜断档的阶段。而马齿苋正好在那时进入全盛期。什么都不给它，也不浇水，它依然在那里。
