## 12. 収穫 - 切って、また切る

### 12-1. 時期の判断

| 用途 | 播種後 | 状態 |
|---|:---:|---|
| 若葉（サラダ） | 4-5週間 | 間引きを兼ねます。最も柔らかいです |
| 通常の収穫 | 6-8週間 | 茎が15-20cm、花が咲く前 |
| 再収穫 | 刈り取り後10-20日 | 新芽が再び15cmに達したとき |
| 薬用・茶用 | 開花期の前後 | 成分が最も濃いときです |
| 採種用 | 韓国では9-10月 | 果実が褐色に乾くとき |

&nbsp;&nbsp;&nbsp;花が咲く前という条件が、最も実用的な基準です。スベリヒユは花が咲き始めると、茎に繊維が増えて硬くなり、葉が小さくなります。黄色い花が目につき始めたら、その株は食べる側から種を採る側へ移ったと考えればよいでしょう。

&nbsp;&nbsp;&nbsp;収穫する時刻も味に影響します。干ばつでCAMへの切り替えが起きた株は、一晩かけてためた有機酸が明け方に最高点に達します。明け方に摘んだスベリヒユが格別に酸っぱい理由はこれで、酸味を抑えたいなら、日が昇って数時間たってから摘むほうがよいです。逆に、酸味を生かしてサラダに使うなら、早朝がよいでしょう。ただし、真昼の照りつける日差しの下で摘んだものは、組織がすぐに軟らかくなり、貯蔵に不利です。

### 12-2. 収穫のコツ

| 項目 | 内容 |
|---|---|
| 切る高さ | 株元から2-3節上 |
| 道具 | はさみや鎌。手でちぎると根ごと抜けてしまいます |
| 一度に収穫する部位 | 茎の先10-15cm |
| 収穫後の土 | 地面を這う植物なので、葉の裏に土がたくさん付きます |
| 洗い方 | 水に浸けて振り洗いしたあと、流水ですすぎます |

&nbsp;&nbsp;&nbsp;根が浅くて柔らかいため、手でちぎると丸ごと抜けてしまうことがよくあります。一度収穫して終わりにするつもりなら構いませんが、再生を期待するなら、必ず切らなければなりません。道具がなければ、片手で株元を押さえ、もう一方の手で茎を折ります。

&nbsp;&nbsp;&nbsp;土がたくさん付くという点は、思ったより厄介な問題です。葉が厚くてくぼんでいるため土の粒が挟まりやすく、茎が地面に触れて育つので、節ごとに土がつきます。水が貴重な状況では、この洗浄に使う水も馬鹿になりません。代替策は、畑であらかじめ払い落とすことです。刈り取ったあと、その場で何度か振るってからかごに入れれば、洗う水が半分に減ります。直立型の系統を選べば、この問題は大きく減ります。

### 12-3. 一か所からどれだけ収穫できるか

| 回 | 時期 | 収量 |
|---|---|---|
| 間引き収穫 | 播種後4-5週間 | 少ない。柔らかい |
| 1回目の刈り取り | 6-8週間 | 最も多い |
| 2回目の刈り取り | 1回目の10-20日後 | 1回目の70%程度 |
| 3回目の刈り取り | 2回目の15-20日後 | 1回目の50%程度 |
| 4回目の刈り取り | 3回目の20日以上後 | 少なくて硬いです。たいていはここで終わりにします |

&nbsp;&nbsp;&nbsp;回を重ねるほど、量が減って硬くなります。畑から取り出し続けるだけなので、当然の結果です。4回目を無理に引っ張るよりも、3回目で止めて、その株に花を咲かせるほうがよいでしょう。そうすれば種が落ちて、翌年も同じ場所が維持されます。

## 13. 採種 - ひとりでに進むことを手助けする方法

### 13-1. 採種が簡単な理由

&nbsp;&nbsp;&nbsp;評価表で自家採種SS、種子寿命SSを獲得した作物は非常にまれです。理由は三つあります。

| 理由 | 内容 |
|---|---|
| 自家受精 | 自分で受粉します。他の株と混ざる心配がありません |
| 多産 | 1株が数千から数万粒の種をつけます |
| 長寿 | 土の中で数十年間、発芽力を保ちます |

&nbsp;&nbsp;&nbsp;長ネギやケールが抱える交雑の問題は、スベリヒユにはありません。花が開く前にすでに自分の花粉で受精が終わっているため、隣にどんな系統があっても種が混ざりません。隔離距離を測ったり、網をかぶせたりする必要がないという意味で、種子の自給という観点では、最も楽な作物の一つです。

### 13-2. 採り方

| 段階 | 内容 |
|---|---|
| 採種株の選定 | 刈り取りをやめ、花を咲かせる株をいくつか決めます |
| 成熟の判断 | 果実が褐色に乾き、上の部分が蓋のように開こうとするとき |
| 収穫 | 茎ごと切り、紙や布の上で逆さにして乾かします |
| 分離 | 乾いた茎を手でもんで種を落とします |
| 精選 | ふるいにかけるか、風に当てて、実の入っていないしいなを飛ばします |
| 乾燥 | 日陰で完全に乾かします |
| 保管 | 密閉容器に入れて、涼しく暗い場所に置きます |

> **スベリヒユの果実は、熟すと蓋のように横に割れて、種をこぼしてしまいます。完全に乾くまで待つと、すでに種は地面に落ちたあとです。**

&nbsp;&nbsp;&nbsp;この性質のため、採種で最も重要なのはタイミングです。果実が褐色に変わり始め、まだ開いていないうちに、茎ごと刈り取って、日陰に逆さに吊るしておきます。下に布や紙を敷いておけば、乾くにつれてひとりでに開き、種が落ちます。種はきわめて小さく黒いので、土の上に落ちると、もう拾い集められません。

&nbsp;&nbsp;&nbsp;ただし、これらの作業はすべて、実は選択事項であることを押さえておきます。採種をせずにそのままにしておけば、種は畑に落ちて、翌年にひとりでに生えてきます。人が種を採る理由は、ちょうど二つです。別の場所に移し植えるため、そして、その場所を耕し返す予定があるためです。

### 13-3. 保管と寿命

| 条件 | 発芽力の維持 |
|---|---|
| 土の中の自然状態 | 数十年。この表で最上位 |
| 常温での密閉保管 | 5年以上は問題なし |
| 涼しく乾燥した場所 | 10年以上 |
| 湿った場所 | カビが生えるとそのまま使えなくなります |

&nbsp;&nbsp;&nbsp;他の作物の種子保管では、毎年発芽率が下がることを前提に、数年周期で更新する計画を立てます。スベリヒユにはその必要がありません。一度採っておいた種の一袋が、人の一世代をもたせます。災害が何年続くかわからない状況では、この性質は保険に近いものです。かさもほとんど取らず、ひとさじあれば数千株を植えられる量になります。

## 14. 毒性と注意すべき成分 - シュウ酸と、よく似た毒草

### 14-1. シュウ酸

&nbsp;&nbsp;&nbsp;スベリヒユは食用植物で、通常の量を食べる限り安全です。ただ、一つの成分が摂取量に線を引きます。シュウ酸です。

| 項目 | 内容 |
|---|---|
| 含有量 | 生100gにおよそ1,000-1,700mg。ホウレンソウと同程度かそれ以上 |
| 体内での働き | カルシウム、鉄、マグネシウムと結合して吸収を妨げます |
| 過剰摂取時 | 腎臓にシュウ酸カルシウム結石ができることがあります |
| 特に注意が必要な人 | 腎結石の既往がある人、腎機能が低下している人 |
| 減らす方法 | 沸騰した湯でゆでて、その湯を捨てると30-50%が抜けます |

&nbsp;&nbsp;&nbsp;ここに、災害時特有の事情が重なります。普段であれば、スベリヒユはおかずとしてひと口ふた口食べて終わりですが、食べ物が不足してくると、畑でただ同然に手に入るこの草を、主食のようにたくさん食べることになります。シュウ酸の問題が実際に表面化するのは、そうした状況です。そして、その状況はたいてい、カルシウムの摂取も同時に不足しているときです。牛乳や骨ごと食べる魚が食卓から消えた食事で、わずかなカルシウムまでシュウ酸に結びつかれてしまうと、損失が大きくなります。

> **スベリヒユは毎日食べてもかまいませんが、毎食おなかいっぱい食べる作物ではありません。生で食べるときは1日100g前後、それ以上を食べるときは、ゆでてその湯を捨てるのが安全なラインです。**

&nbsp;&nbsp;&nbsp;ゆでることがなぜ効果的なのかも、知っておく価値があります。シュウ酸は水によく溶ける成分なので、沸騰した湯でゆでると、かなりの量が湯に抜け出ます。ゆで汁をスープに使っては何の意味もないので、必ず捨てなければなりません。その代わり、ビタミンCも一緒に抜けるため、ビタミンCを狙うなら、生で少し食べ、量を満たすときはゆでて食べるというように使い分けるのが合理的です。発酵もシュウ酸を一部減らします。

&nbsp;&nbsp;&nbsp;伝統的に、スベリヒユを性質の冷たい（寒性の）植物とみなして、体が冷えやすい人には勧められなかったことも、記録に残っています。実際、カリウムが多く利尿作用があり、血圧を下げる方向に働くため、低血圧のある人や下痢をしやすい人は、量を減らしたほうがよいでしょう。

### 14-2. 似た毒草 - トウダイグサ科のニシキソウ類

&nbsp;&nbsp;&nbsp;この節が、この文書で最も重要な部分です。畑や道端でスベリヒユを採取するとき、スベリヒユとほとんど同じ場所で、ほとんど同じ姿で生える毒草があります。トウダイグサ科（Euphorbiaceae）のニシキソウ類、つまりコニシキソウやオオニシキソウのような草です。

| 区分 | スベリヒユ | ニシキソウ類（トウダイグサ科） |
|---|---|---|
| 切り口の汁 | 澄んで透明です | 白い牛乳のような汁が出ます |
| 葉の厚さ | 厚くて多肉質です | 薄く、紙のようです |
| 葉のつき方 | 互生で、茎の先に集まってつきます | 必ず対生です |
| 葉の縁 | なめらかです | 細かい鋸歯があります |
| 葉の模様 | ありません | 中央に紫色の斑点があることが多いです |
| 茎 | 太くて水気が多いです | 細くて硬く、細かい毛があります |
| 花 | 黄色い花びら5枚、直径5mm | 花びらのように見えるものは白や赤で、とても小さいです |
| 食べたとき | 食用になります | 口とのどが焼けるように痛み、嘔吐と下痢を起こします |

> **茎を切ったり葉をちぎったりしたときに白い汁が出たら、スベリヒユではありません。この一点を確認するだけで、トウダイグサ科の毒草をほとんど選り分けることができます。**

&nbsp;&nbsp;&nbsp;トウダイグサ科の植物の白い汁に含まれる成分は、皮膚や粘膜を刺激します。汁が目に入ると重い炎症を起こし、食べると口とのどが焼けるように痛み、嘔吐と下痢が続きます。命に関わる例はまれですが、災害時に何日も食べることも動くこともできなくなること自体が危険です。白い汁は手についても洗い流さなければならず、採取中に触れたなら、その手で目をこすってはいけません。

&nbsp;&nbsp;&nbsp;見分けを身につける最も確実な方法は、確信が持てるまでは、必ず1株ずつ茎を折ってみることです。スベリヒユは、ふっくらした茎が水気を帯びてぽきんと折れ、澄んだ汁がうっすらとにじみ出ます。ニシキソウ類は、細い茎が硬く裂けるように切れ、切れたところに白いしずくがたまります。一度見たら忘れにくい違いです。

&nbsp;&nbsp;&nbsp;参考までに、名前の似たイヌビユやヒユはヒユ科の植物で、スベリヒユとは別の仲間ですが、どちらも食べられるので、取り違えても危険はありません。危険なのは、白い汁が出る仲間だけです。

### 14-3. 生えている場所による汚染

| 採取場所 | 危険 | 判断 |
|---|---|---|
| 自分の畑、家庭菜園 | 低い | 安心して使います |
| 車道の端 | 高い | 鉛をはじめとする重金属と、排ガスの沈着 |
| 田畑の縁 | 中程度 | 除草剤がまかれている可能性があります |
| 工場・廃棄物用地 | 非常に高い | 採取しません |
| 長く放置された空き地 | 中程度 | 以前の用途がわからなければ避けます |

&nbsp;&nbsp;&nbsp;スベリヒユは、土の中の重金属を組織にためこむ性質がある植物として知られています。汚染された土地を浄化する用途で研究されるほどです。この性質は、植物にとっては生き残るための戦略ですが、食べる人にとっては危険です。よく育っているという事実は、その場所がきれいだという証拠にはなりません。むしろ、誰も世話をしない土地でよく育つ性質のせいで、人が最も手を出してはならない土地で最も茂っていることがあります。

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;貯蔵性E、常温で2-3日というのが、スベリヒユの最大の弱点です。水分が93%の多肉質の組織は、切られた瞬間から崩れ始めます。電気がない状況で、この弱点を正面から解決する方法はなく、性質を変えるか、畑を貯蔵庫として使うという迂回路しかありません。

### 15-1. 畑が貯蔵庫

| 方法 | 期間 | 条件 |
|---|---|---|
| 刈らずに畑に置く | 霜が降りるまで | 必要なときに必要な分だけ切ります |
| 根ごと抜いて日陰に置く | 3-5日 | 土がついたままにしておくと長くもちます |
| 濡れた布に包んで涼しい場所に置く | 3-5日 | 室（むろ）や土室があれば、もっともちます |
| 株元を水に浸けておく | 2-3日 | 葉が軟らかくなる前までです |

&nbsp;&nbsp;&nbsp;最初の行が、事実上唯一のまともな答えです。貯蔵性の悪い作物の解決策は貯蔵しないことで、スベリヒユは韓国では6月から10月まで4か月以上、畑に立ったままこの役割を果たします。その期間はスベリヒユを貯蔵する理由がなく、その期間が終わると、貯蔵しておいたものも長くもちません。そのため、実際の運用は、夏の間は摘み続けて食べ、秋に冬の分だけを干しておくという形になります。

### 15-2. 乾燥

| 段階 | 内容 |
|---|---|
| 下ごしらえ | 洗って土を落とし、水気を切ります |
| 下ゆで | 沸騰した湯で30秒から1分。省いてもかまいませんが、ゆでると色が残り、シュウ酸が減ります |
| 水気の除去 | 絞ってできるだけ抜きます。水気が残ると、乾く途中でカビが生えます |
| 広げる | 日陰の風通しのよい場所。直射日光で干すと成分が壊れます |
| 仕上がりの判断 | 手でもんだときに砕けるまで |
| 保管 | 密閉容器に草木灰か炭を一緒に入れて、湿気を取ります |

&nbsp;&nbsp;&nbsp;乾燥がスベリヒユによく合う理由があります。水分が多いため、乾くとかさが10%以下に減り、ひと籠がひと握りになります。保管場所をほとんど取らないという意味で、これは貯蔵資源が不足した状況では大きな利点です。よく乾燥させて密閉したものは、半年から1年もちます。

&nbsp;&nbsp;&nbsp;ただし、乾燥させたスベリヒユは、生のものとは性格がまったく変わります。ビタミンCはほとんど残らず、食感は歯ごたえが強くなります。その代わり、ミネラルと脂肪酸と繊維はそのまま残り、むしろ濃縮されます。つまり、乾燥スベリヒユは、冬のビタミン源ではなく、ミネラルと脂肪酸の補給源であり、だしや汁の具としての位置づけになります。水で戻してナムル（韓国風の和え物）にしたり、汁物に入れたり、煮出してお茶として飲んだりします。

### 15-3. 塩漬けと発酵

| 方法 | 手順 | 期間 |
|---|---|---|
| 塩漬け | 重量の3-5%の塩で層状に漬け込みます | 涼しい場所で2-3か月 |
| チャンジ（塩辛い漬物） | 10%以上の濃い塩水に浸かるように漬けます | 半年以上。食べる前に水に浸けて塩気を抜きます |
| 乳酸発酵 | 2-3%の塩水に浸かるよう重しをします | 1-2週間発酵させたあと、涼しい場所で1-2か月 |
| チャンアチ（醤油漬け） | 醤油やテンジャン（韓国味噌）に漬け込みます | 数か月 |

&nbsp;&nbsp;&nbsp;乳酸発酵は、塩を節約しながら貯蔵期間を稼ぐ方法です。2-3%の塩水は、雑菌は抑えつつ乳酸菌は生かしておく濃度で、乳酸菌がつくる酸がpHを下げて、腐敗菌が育たないようにします。材料が空気に触れないよう、押さえて漬かった状態にすることが、成否を分けます。表面に浮く白いカビは取り除けばよいですが、黒や青のカビが生えたら捨てなければなりません。

&nbsp;&nbsp;&nbsp;スベリヒユはもともと粘りのある植物なので、漬けるとぬめりのある食感が強くなります。これを嫌う人もいれば、むしろこの食感のために好んで食べる地域もあります。塩水に漬ける前に軽くゆでると、粘りが減ります。

## 16. 調理と加工

| 方法 | 燃料 | 手順 | 備考 |
|---|:---:|---|---|
| 生食 | 0 | 洗ってそのまま | 酸味と粘りが特徴です。ビタミンCがそのまま残ります |
| ゆでナムル | 少ない | 沸騰した湯で30秒から1分、冷水ですすいで和えます | シュウ酸が減り、かさも減るので、たくさん食べられるようになります |
| 炒め物 | 少ない | 油で2-3分 | ベータカロテンの吸収がよくなります |
| 汁物とチゲ（煮込み鍋） | 中程度 | 最後に入れます | 長く煮ると溶けてしまいます |
| 粥 | 中程度 | 穀物粥に刻んで入れます | 粘りがとろみをつけてくれます |
| お茶 | 少ない | 乾燥させたものを煮出します | 冬の利用方法です |
| 発酵 | 0 | 第15節を参照 | 貯蔵と調理を兼ねます |

&nbsp;&nbsp;&nbsp;評価表で調理・加工がSSなのは、洗ってすぐに食べられるという意味で、燃料が貴重な状況では、この項目の価値は大きいです。ただし、前の節で見たシュウ酸のために、多量を生で食べることはおすすめできません。実際の運用は、毎日少しずつは生で、量を満たすときはゆでてその湯を捨てるという形に分かれます。

&nbsp;&nbsp;&nbsp;ゆでるときは、30秒から1分を超えないのがコツです。多肉質の組織なので、熱が入るとあっという間にくたくたになります。湯が再び沸き上がる瞬間が、そのまま引き上げどきです。ゆでたあと冷水ですすぐと、色が残り、余熱でさらに軟らかくなるのを防げます。

&nbsp;&nbsp;&nbsp;粘りをどう扱うかが、スベリヒユ調理の分かれ道です。スベリヒユにはムシレージと呼ばれる粘液質があり、ゆでるとぬるぬるした食感が出ます。評価表の味の等級がSでありながら、食感の好みが分かれる理由はこれです。嫌なら、ゆでて冷水で何度もすすぐとかなり減り、逆にこの粘りを活用すれば、粥や汁物にとろみをつける材料になります。でんぷんが貴重な状況で、汁にとろみをつける材料として使えます。

&nbsp;&nbsp;&nbsp;油と一緒に食べる調理法が、特に価値があります。スベリヒユのベータカロテンとビタミンEは脂溶性なので、油があってはじめて吸収が十分に行われます。また、この植物が含むα-リノレン酸はそれ自体が脂肪なので、油で炒めると、その成分が組織からより抜け出しやすくなります。エゴマ油があれば、それ自体がオメガ3の供給源なので、相性がよいです。

## 17. 年間作業スケジュール

| 月（韓国の気候基準） | 作業 |
|---|---|
| 1-2月 | 種子を涼しく乾燥した場所で保管。乾燥スベリヒユでナムルとお茶 |
| 3月 | 植える場所を決めます。日当たりがよく、水がたまらない場所 |
| 4月 | 霜が完全に過ぎてから播種。土をほとんどかぶせず、押さえておきます |
| 5月 | 発芽期の水分管理。1回目の間引き（間隔5cm）。間引いたものを食べます |
| 6月 | 2回目の間引き（間隔10-15cm）。前年に種が落ちた場所で自然発芽が始まります |
| 7月 | 1回目の刈り取り開始。株元の2-3節を残して切ります。高温期の最盛期 |
| 8月 | 2回目、3回目の刈り取りを繰り返します。他の野菜が暑さで弱る空白期の主力 |
| 9月 | 刈り取りを締めくくります。採種用の株を残して花を咲かせます |
| 10月 | 果実が褐色になったら茎ごと刈り取り、日陰で乾かして種を採ります。残りはゆでて干します |
| 11月 | 初霜で地上部が枯死。その場所は耕さずにおきます |
| 12月 | 干したものと漬けたものを利用します。種子を点検します |

&nbsp;&nbsp;&nbsp;この表で注目すべきは、11月の行です。その場所を耕さないことが、翌年の農作業のすべてです。秋に落ちた種が表土の近くにあってこそ、翌春に光を受けて発芽します。深く耕し返すと、種が埋まって、その年には生えません。

&nbsp;&nbsp;&nbsp;そして、7月と8月の二つの行が、この作物を植える実質的な理由です。真夏は、サンチュ（リーフレタス）やホウレンソウ、ハクサイがすべて弱ってしまう時期で、災害時の畑で新鮮な葉が途切れる区間です。スベリヒユは、まさにそのときが最盛期です。何も与えなくても、水をやらなくても、その場所にあります。
