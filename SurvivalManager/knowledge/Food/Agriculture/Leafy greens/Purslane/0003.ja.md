## 2. どんな植物か

### 2-1. 分類と原産地

| 項目 | 内容 |
|---|---|
| 学名 | Portulaca oleracea |
| 分類 | ナデシコ目 スベリヒユ科 スベリヒユ属 |
| 別名 | 馬歯莧、テジプル（dwaejipul、「豚の草」の意）、五行草、長命菜 |
| 原産地 | インドまたは地中海東部と推定。現在は世界中に帰化 |
| 生活型 | 一年草。自然の自己播種で同じ場所に毎年再び出現 |
| 光合成の方式 | C4。干ばつストレス時にCAMへ切り替え |

&nbsp;&nbsp;&nbsp;スベリヒユの原産地については諸説ありますが、今ではその論争自体が意味を失っています。南極を除くすべての大陸で育ち、人が住む場所ならほとんど例外なく見られるからです。これほど広く分布した植物は、たいてい二つの条件を備えています。種子が小さくて数が多く、生育条件を選ばないことです。スベリヒユはこの二つの条件を、どちらも極端なまでに満たしています。1株が数万個の種子をつくり、その種子は土に混じって、靴底や荷車の車輪、家畜の腹の中に乗って移動します。

&nbsp;&nbsp;&nbsp;これに加えて、この植物の性格を決めたもうひとつの来歴があります。スベリヒユが主に育つ場所は、砂漠の縁、川辺の砂利地、海辺の砂地、人に踏み固められた道端など、水も養分も乏しく、日光だけがあり余る土地です。ほかの植物が耐えられずに場所が空いている一方、そこで生き残るには水を節約し、強い光に耐えなければなりません。多肉質の組織も、C4光合成も、根が切れてもまた根づく生命力も、すべてその場所から生まれました。

### 2-2. 形態

| 器官 | 特徴 |
|---|---|
| 葉 | 厚くてつやのある多肉質の卵形。へら状で先端が丸く、縁はなめらかです |
| 葉序 | 互生、またはほぼ対生。茎の先端では数枚が集まってつきます |
| 茎 | 円柱形で、赤みを帯びた色から紫がかった色。地面をはって四方に広がり、長さ20-30cm |
| 根 | 太い白い根が1本に、浅い側根。切れても節からまた根が出ます |
| 花 | 直径5mm前後の黄色い花。花弁5枚。韓国では6月から9月、晴れた日の午前中だけ開きます |
| 果実 | ふたのように横に裂ける蓋果。1つの果実に黒くごく小さな種子が数十粒 |
| 汁液 | 切ると透明な汁が出ます。白い汁は絶対に出ません |

&nbsp;&nbsp;&nbsp;最後の行がこの表で最も重要です。スベリヒユの茎を切ると、透明でわずかに粘りのある、澄んだ汁が出ます。白い牛乳のような汁が出るなら、それはスベリヒユではなくトウダイグサ科の別の草であり、食べてはいけません。この見分け方は、第14節でもう一度詳しく説明します。

&nbsp;&nbsp;&nbsp;花が晴れた日の午前中だけ開くという点も、知っておく価値があります。曇りの日や午後に畑を見回ると、花を一輪も見ないまま通り過ぎてしまうことがあります。採種をするなら、花がいつ咲いたかを見ておくよりも、茎の節にふた付きの小さな壺形の果実がついているかどうかを確かめるほうが確実です。

### 2-3. C4とCAMを行き来する光合成

&nbsp;&nbsp;&nbsp;スベリヒユがほかの葉菜と根本的に異なるのは、この点です。大部分の植物は一般的なC3光合成を行い、トウモロコシやモロコシ（タカキビ）のような一部の植物がC4光合成を行い、サボテンやリュウゼツランのような砂漠の植物がCAM光合成を行います。スベリヒユは普段はC4で回し、干ばつが厳しくなるとCAMに切り替えます。二つの方式をどちらも備えた植物は非常にまれで、この切り替えがスベリヒユの極端な耐乾性を生み出します。

| 方式 | 二酸化炭素を取り込む時間 | 気孔を開く時間帯 | 水分の損失 | 長所と短所 |
|---|---|---|---|---|
| C3 | 昼 | 昼 | 多い | 大部分の野菜。光が弱くても損失が少ないです |
| C4 | 昼 | 昼 | 中程度 | 強い光と高温で効率が高いです。光が弱いと損失が大きくなります |
| CAM | 夜 | 夜 | 非常に少ない | 成長は遅いが、極端な干ばつの中でも生き残ります |

&nbsp;&nbsp;&nbsp;植物が水を失う経路は気孔です。二酸化炭素を取り込むには気孔を開かなければならず、気孔を開くと水蒸気が逃げていきます。昼は暑くて乾燥しているため、昼に開く側の損失が大きくなります。CAM植物は、このジレンマを時間を分けて解決します。夜の涼しいときだけ気孔を開いて二酸化炭素を取り込み、有機酸の形で蓄えておき、昼は気孔をしっかり閉じたまま、蓄えておいた二酸化炭素を取り出して光合成を行います。

> **スベリヒユは、水があるときはC4で速く育ち、水が途絶えるとCAMに切り替えて成長を止め、耐え忍びます。畑に水を引けない状況では、この切り替えがそのまま生存を意味します。**

&nbsp;&nbsp;&nbsp;この切り替えには代償が伴います。CAMに切り替えたスベリヒユは、ほとんど成長しません。生きてはいても、収穫できるものは増えないという意味です。また、有機酸が葉にたまるため、明け方に摘んだスベリヒユは酸味が強くなります。実際、長く日照りが続いたあとに朝早く摘んだスベリヒユは酸っぱいものです。これは傷んだのではなく正常な状態で、昼が過ぎるにつれて酸が消費され、午後には酸味が薄くなります。

&nbsp;&nbsp;&nbsp;C4であるという事実が生むもうひとつの結果が、先に見た日照のEです。C4植物は、二酸化炭素を細胞の中でもう一度濃縮する追加の工程を回しており、その工程にはエネルギーが必要です。光が十分にあれば儲けが出ますが、光が足りなければ、そのコストがそのまま赤字になります。スベリヒユを日陰に植えると、枯れはしませんが、収穫は半分に減ります。

### 2-4. 生育段階

| 段階 | 時期 | 何が起こるか | 主に必要なもの |
|---|---|---|---|
| 発芽・幼苗期 | 播種から2週間 | ごく小さな子葉が2枚出ます。この時期だけが唯一弱い時期です | 表土の水分、地温20℃以上 |
| 栄養成長期 | 2-6週 | 茎が地面をはって四方に広がり、葉が厚くなります | 日光、少量の窒素 |
| 収穫適期 | 6-8週 | 茎が15-20cmになり、葉と茎が最もやわらかい時期です | バランス |
| 開花・結実期 | 8-12週 | 節ごとに花が咲き、果実がつきます。茎が硬くなります | リン、カリウム |

&nbsp;&nbsp;&nbsp;幼苗期が唯一の弱点の区間であることを、ここで指摘しておきます。十分に育ったスベリヒユは、足で踏んでも引き抜いて放り出しても生き返りますが、芽生えたばかりの子葉は、表土がたった一日からからに乾いただけで枯れてしまいます。自然状態でスベリヒユが雨の直後にいっせいに生えてくるのは、このためです。人が手をかける必要があるとすればこの2週間がすべてで、その後は手をかけることがありません。

&nbsp;&nbsp;&nbsp;花が咲き始めると、茎に繊維が増えて硬くなり、葉も小さくなります。食べるための収穫なら開花前に切るのがよく、種子を採る目的なら、数株を別に残して最後まで置いておかなければなりません。この二つの目的は、1株で同時にかなえることができません。

### 2-5. 100gあたりの栄養

| 栄養素 | 含有量 | 備考 |
|---|:---:|---|
| 熱量 | 16-20kcal | 資料により7-20kcalと幅が大きいです |
| 水分 | 約93g | 熱量が低い最大の理由です |
| タンパク質 | 約2.0g | 熱量に占めるタンパク質の割合（P:E）は40.6% |
| 脂質 | 約0.4g | そのうちかなりの部分がα-リノレン酸 |
| α-リノレン酸（ALA） | 300-400mg | 葉菜としては異例の数値 |
| カリウム | 494mg | ナトリウムの排出と血圧の調節に関与 |
| マグネシウム | 68mg | 葉菜の中で上位 |
| カルシウム | 65mg | シュウ酸のため吸収率が下がります |
| 鉄 | 0.9-2.0mg | 資料によって差が大きいです |
| ビタミンC | 21mg | ゆでると半分以上が失われます |
| ビタミンA | β-カロテンの形で多量 | 油と一緒に食べると吸収がよくなります |
| ビタミンE | 高い | ナムル（野菜・山菜の和え物）類の中で指折りの水準 |
| ビタミンB群 | チアミン、ナイアシン、ビタミンB6、葉酸 | |
| シュウ酸 | 高い | 第14節で別に扱います |

&nbsp;&nbsp;&nbsp;熱量の数値が資料ごとに7-20kcalまで開くのは、不思議なことではありません。多肉質の植物なので、水分含量が育った環境によって大きく変わるからです。雨の多い年に水分の多い土地で育ったスベリヒユはほとんど水ですし、日照りの年に乾いた土地で育ったスベリヒユは、同じ重さに含まれる乾物量が2倍になります。評価に使った20kcalは、その中の高いほうの値です。どの値を使っても結論は同じです。この植物で熱量を計算すること自体、意味がありません。

&nbsp;&nbsp;&nbsp;α-リノレン酸の項目が、この表の核心です。オメガ3系の脂肪酸は、体内でつくれないため必ず食べ物から摂らなければならない必須脂肪酸で、主な供給源は青魚、エゴマ、アマニ、クルミです。災害時には、このリストの大部分が消えます。漁業が止まり、油をしぼることも難しくなります。葉菜は本来この穴を埋められませんが、スベリヒユは例外的に100gあたり300-400mgを含んでいます。1日の推奨摂取量はおよそ1,600-2,000mgなので、スベリヒユだけで満たすのは難しいものの、完全に0の食事と、いくらかは入ってくる食事とでは、まったく別の話です。

## 3. 栽培環境

### 3-1. 温度

| 区分 | 温度 | 結果 |
|---|:---:|---|
| 発芽の下限 | 約15℃ | これより下ではほとんど発芽しません |
| 発芽適温 | 20-30℃ | 3-7日でそろって芽が出ます |
| 生育適温 | 20-35℃ | 真夏がもっともよく育つ時期です |
| 生育可能範囲 | 10-35℃ | 幅25℃。温度適応幅SSの根拠 |
| 高温の限界 | 40℃以上でも生存 | 成長は遅くなりますが、枯れません |
| 低温の限界 | 5℃以下で生育停止 | |
| 致死 | 0℃、霜が一度 | 地上部がぐったりと傷んで枯れます |

&nbsp;&nbsp;&nbsp;スベリヒユは、この文書で扱う野菜の中で、夏をもっとも好む部類です。サンチュ（リーフレタス）、ハクサイ、ホウレンソウが暑さでとろけ、抽だいしてしまう韓国の7月と8月は、スベリヒユにとっての全盛期です。災害時の畑では、真夏のひと月が野菜の空白期になることがよくありますが、スベリヒユはまさにその空白を埋めます。これが、熱量もなく貯蔵もできないこの草を、それでも確保しておくべき理由のひとつです。

&nbsp;&nbsp;&nbsp;反対側の端は非情です。氷点下に一度下がれば終わりです。ケールのように霜に当たってかえって甘くなる作物とは正反対で、初霜が降りた翌朝には、畑のスベリヒユはすべて黒くぐったりと傷んでいます。このとき惜しむ必要はありません。その前に、種子がすでに土に落ちているからです。

### 3-2. 光

| 条件 | 相対収量 | 解釈 |
|---|:---:|---|
| 終日直射光 | 100% | これが基準です |
| 40%遮光 | 約45% | 信頼区間37-56%。日照Eの根拠 |
| 半日陰 | 大きく減少 | 生きてはいますが、茎が細く長くなります |
| 深い日陰 | ほとんど育たない | 発芽さえうまくいきません |

&nbsp;&nbsp;&nbsp;スベリヒユについて最もよくある誤解が、ここにあります。雑草のようにどこでも育つので、光も選ばないだろうと思われがちですが、実際にはこの文書のどの作物よりも光に敏感です。先に見たC4光合成のためです。

&nbsp;&nbsp;&nbsp;この事実が栽培に持つ意味は明らかです。スベリヒユは、トウモロコシの下やトマトの間、木陰に置く作物ではありません。畝の端、畑の縁の遊んでいる土地、塀の下の日の当たる場所、道端の斜面のように、一日じゅう日が当たる場所が適所です。ほかの作物と競合せずに、日当たりのよい場所を見つけることが、スベリヒユの管理のほとんどすべてだと言っても過言ではありません。

### 3-3. 水と土壌

| 項目 | 基準 | 備考 |
|---|---|---|
| 土性 | ほぼあらゆる土 | 砂利地、砂地、固く締まった道端でも育ちます |
| 土壌酸度 | pH 5.6-7.8 | 幅がきわめて広いです |
| 有機物 | 不要 | やせた土地に適応した植物です |
| 排水 | 重要 | 唯一気を配るべき項目です |
| 灌水 | 発芽期以外は不要 | 総量250L/㎡未満でも育ちます |
| 塩分 | かなり耐える | 海辺の砂地でも自生します |

> **スベリヒユが枯れる原因は、ほとんどの場合、水が足りないからではなく、水が抜けないからです。**

&nbsp;&nbsp;&nbsp;多肉質の植物に共通する弱点が過湿です。組織そのものが水を含んでいるため、根の周りまで水に浸かると酸素が途絶え、すぐに腐り始めます。韓国の梅雨（チャンマ、6月下旬～7月）のころ、数日間水がたまった場所のスベリヒユは、丸ごと腐ってしまいます。逆に、ひと月日照りが続いても、葉が少ししぼむだけで枯れません。この非対称性を知れば、管理の方向が決まります。水をやることを考えるより、水がたまらない場所を選ぶほうがはるかに効果的です。

&nbsp;&nbsp;&nbsp;土壌酸度の幅が広いという点も、災害時には大きな価値があります。石灰が尽きて酸性に傾いた畑で、アブラナ科の作物が根こぶ病に倒れ、マメ科の作物が根粒をつくれなくなっても、スベリヒユはまったく影響を受けません。酸度矯正に使える資源がない状況で、そのまま使える数少ない作物です。
