## 引言
&nbsp;&nbsp;&nbsp;马齿苋（Portulaca oleracea）是马齿苋科的多肉质一年生草本，田埂、路边水泥裂缝、砾石地这类无人照管的地方，它都会自己长出来。汉字名“马齿苋”来自叶片像马的牙齿。综合等级为C（42.1分，有效183种中第85名），但副食为SS（69.2分）。一棵植株撒下数万粒种子，种子能在土里存活几十年，所以个体是一年生，而地点几乎是永久的。因此连作适应性、种子寿命、自留种为SS，施肥、水消耗量、设施负担也是SS。它更接近有管理的放任而不是栽培：人要做的就是决定让它长在哪里，守住边界，别挤掉其他作物，并留下几棵植株直到种子落下。营养方面最突出的是，作为叶菜，它每100g含有300-400mg罕见的ω-3脂肪酸——α-亚麻酸（ALA）。鱼和油消失的饮食里，最先断掉的就是这种营养素，只靠谷物、薯类、叶菜几乎没有补上它的渠道，而马齿苋是那少有的渠道之一。弱点是每100g只有16-20kcal所以单位面积热量为D，遇一次霜就死所以耐寒性为E，常温下2-3天就坏所以耐储性为E，作为C4植物，遮光40%时相对产量降到约45%，所以光照为E。草酸与菠菜一样多，不能大量吃，还要分清长得像的毒草（大戟科地锦草类）。马齿苋不是田里的主角，而是负责田边和空地的作物。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 石竹目马齿苋科马齿苋属一年生草本。别名有马齿苋（machihyeon）、五行草（ohaengcho）、长命菜（jangmyeongchae）、dwaejipul。推测原产于印度或地中海东部，已在全世界归化。靠自然落种，每年在同一处再次长出 |
| 叶、茎 | 叶片厚实有光泽，多肉质匙形（边缘光滑），聚生在茎端。茎红色至紫色，圆柱形，匍匐地面向四周铺开20-30cm。切开流出清汁，绝不会流出白汁 |
| 根、花、果实 | 一条粗白根，侧根浅，被切断后节上还会长出根。直径5mm左右的黄花（花瓣5片），6-9月只在晴天上午开放。果实是像盖子一样横向裂开的盖果，内有几十粒黑色小种子 |

| 阶段 | 时期（播种后） | 要点 |
|:---|:---|:---|
| 发芽、幼苗期 | 2周以内 | 两片极小的子叶。唯独这个时期脆弱 |
| 营养生长期 | 2-6周 | 茎匍匐地面向四周铺开，叶片变厚 |
| 最佳收获期 | 6-8周 | 茎15-20cm，叶和茎最嫩 |
| 开花、结实期 | 8-12周 | 节节开花结果，茎变韧 |

> **马齿苋有水时以C4方式快速生长，水断了就改成CAM，停止生长，硬撑过去。在无法给田地灌水的情况下，这种转换就是生存本身。**

&nbsp;&nbsp;&nbsp;CAM在夜里打开气孔吸收二氧化碳，水分损失极少。C4在强光和高温下效率高，光弱则损失大，所以马齿苋最喜欢夏天，怕阴。

&nbsp;&nbsp;&nbsp;每100g含热量16-20kcal（因资料而异为7-20kcal）、水分约93g、蛋白质约2.0g（占热量的40.6%）、脂质约0.4g、α-亚麻酸300-400mg、钾494mg、镁68mg、钙65mg（因草酸吸收率下降）、铁0.9-2.0mg、维生素C 21mg（焯水会损失一半以上）。维生素E在野菜类中较高，还有硫胺素、烟酸、维生素B6、叶酸。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽下限约15℃，适温20-30℃（3-7天）。生长适温20-35℃，可达范围10-35℃（幅度25℃）。40℃以上也不会死，5℃以下停止生长，0℃或一次霜冻就会让地上部变软枯死 |
| 光 | 全天有阳光的地方。遮光40%时相对产量约45%。半阴处茎变细变长，深阴处几乎不发芽 |
| 水、土壤 | 几乎任何土壤（砾石地、沙地、板结的路边）。pH 5.6-7.8，不需要有机质，相当耐盐。除发芽期外不需要灌溉（总量不到250L/㎡也能长）。只需关注排水，致死原因几乎总是水排不出去而不是缺水 |

| 品系 | 特点 |
|:---|:---|
| 野生型（deul-soebireum） | 叶小，茎紧贴地面，产量低。哪里都能自己长出来，获取毫不费力 |
| 大叶种（keunnip-soebireum） | 叶片宽厚的大型植株，同样面积的产量接近野生型的两倍 |
| 小叶种、直立型 | 小叶种成分浓，适合药用和泡茶；直立型（金黄马齿苋等）茎直立，好割，向旁边铺得少，容易守住边界 |

> **对马齿苋来说，比选品种重要得多的是在哪里采。长在路边和空地上的马齿苋暴露于尾气、除草剂和重金属之中，而这种植物有把这些物质积聚在组织里的习性。**

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 根浅，只翻10-15cm，为排水起低垄也行。不调酸度、不加有机质（肥料多则只有叶片变软徒长）。选全天有阳光的位置 |
| 施肥 | 没有要加的。只在收割后施极少量的氮（只是帮助新芽再生，没有也能再生）。不施磷、钾、堆肥、石灰 |
| 替代资源 | 稀释10-15倍的人尿（收割后立即浇在沟里，比其他作物更稀）、一把腐熟堆肥（盖厚了会碰到茎而变软）、一把草木灰、稀释10倍的草液肥、腐叶土（薄薄铺在发芽处）。肥料紧缺时，把它给羽衣甘蓝、大白菜、大葱，总收获反而更多 |

| 时期 | 播种 | 收获 | 备注 |
|:---|:---|:---|:---|
| 露地春季 | 4月中旬-5月 | 5月下旬-10月 | 在霜冻风险完全过去之后 |
| 露地夏季 | 6月-7月初 | 7-10月 | 地温高，发芽最快 |
| 自然发芽 | 不播种 | 6-10月 | 在上一年种子落下的位置自己长出来。实际运作的核心 |

| 播种 | 标准 |
|:---|:---|
| 方法 | 深0.2-0.5cm，几乎不覆土，用手掌或木板压实使种子与土壤贴紧（见光才容易发芽，不能深埋）。种子极小，要与干沙或细土按1比10混合后撒播或条播。行距20-30cm，地温20-30℃下3-7天发芽 |
| 种子处理 | 不需要温汤浸种或药剂消毒。轻轻裹上筛过的草木灰，可消毒表面，还能看清播种的位置 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种至发芽 | 保持表土不干（只有这2周需要人照料） |
| 幼苗期 | 每2-3天一次。此后迅速变强 |
| 营养生长期 | 不浇也行（干了只是叶片变厚） |
| 收获期 | 收割后立即浇一次（新芽再生更快） |
| 开花、结实期 | 反而停水（越干燥种子结得越好） |

&nbsp;&nbsp;&nbsp;叶片变小、变厚、发红，是对缺水的正常适应，干旱时转为CAM，清晨摘的叶片格外酸。茎又细又长、颜色浅，说明缺光，要换位置；从基部开始变褐发软，说明过湿烂根，几天内整株就垮了。不需要覆盖物，甚至覆盖还碍事，马齿苋自己就起着覆盖地面的作用。

| 管理 | 内容 |
|:---|:---|
| 边界 | 最重要的工作。从一开始就把要用的地方划窄，在它之外，趁开花前拔掉 |
| 间苗 | 2-3片真叶时留5cm做第一次，4-5片真叶时留10-15cm做第二次（最终）。间下的可以吃。种子小，撒播会长得很密，所以这是唯一需要动手的工作 |
| 摘心、再生 | 第一次收割在播种后6-8周、茎15-20cm时。在基部上方2-3节处割（新芽只从节上长出），10-20天后再生，霜前可收3-4次。每重复一次，茎就更细、叶更小 |
| 越冬 | 不能过冬，是种子过冬。冬天想吃只能靠储存 |

> **对马齿苋来说，麻烦不在种下去的那一刻，而在它开始扩散之后。从一开始就把要用的地方划窄，在它之外趁开花前拔掉，这就是管理这种作物的全部。**

## 6. 病虫害与养分问题
| 问题 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 烂根 | 基部变褐发软，植株垮掉。积水处、雨季 | 起垄并开排水沟，清除烂掉的植株 |
| 蛞蝓 | 叶上有不规则孔洞和粘液痕迹。潮湿阴暗处 | 在四周撒灰或硅藻土，夜里徒手捉 |
| 蚜虫、灰霉病 | 聚在新芽顶端（氮过多、干旱） / 过密植株内部长出灰霉（通风差） | 用水冲掉或喷肥皂水 / 间苗拉开间距，清除干叶 |
| 蝽 | 茎上有针刺痕，停止生长。周围杂草茂盛时 | 清理田边的陈年杂草 |

> **马齿苋的病虫害等级是C，不是因为这种作物脆弱，而是因为从来没有人看护过它。**

&nbsp;&nbsp;&nbsp;真正毁掉收成的只有烂根，其余靠排水、间苗保证通风、徒手捉、肥皂水（叶片厚，药害少）、草木灰带、稀释300-500倍的木醋液就能解决。马齿苋长在田里本身也算一种防治：它成了替主作物承受害虫的诱集作物，还覆盖裸地防止泥水飞溅和蒸发。

| 症状 | 原因与处理 |
|:---|:---|
| 叶片浅绿，植株矮小 | 缺氮或极度贫瘠。稀释15倍的尿液浇一次（放着不管也能收获） |
| 叶片格外大而软，容易倒伏 | 氮过量（硝酸盐积累的状态）。停止施肥 |
| 叶片变红或深紫 | 低温、缺磷、强光和干燥。大多是正常反应 |
| 老叶边缘干枯焦黄 | 缺钾或盐分过多。少量草木灰，盐分用水冲洗 |
| 新芽聚拢畸形 | 缺钙或缺硼。把贝壳和蛋壳烧后捣碎加入 |

&nbsp;&nbsp;&nbsp;茎又细又长是缺光，不是营养问题。马齿苋遇到过量比不足更常见，所以拿不准时先停肥。

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 番茄·辣椒·茄子（覆盖垄面，防止泥水飞溅和蒸发，高度不同不争光），玉米（二者都是C4，在夏季高温下长得好，但要避开玉米的阴影），南瓜·香瓜（都爬地面但层次不同，可以共存） |
| 差 | 胡萝卜·菠菜·萝卜（幼时慢，会被马齿苋盖住），刚移栽的幼苗（缓苗前被盖住就会萎蔫），常浇水的作物（马齿苋会因过湿烂掉） |

&nbsp;&nbsp;&nbsp;连作适应性是SS，所以不需要轮作，但在其他作物的轮作中，可以用作挖了土豆或大蒜后覆盖夏季空地的作物、主作物不用的垄肩和沟、兼作诱集作物和采摘来源的田边带。在其他作物站不住脚的新开垦的贫瘠地，它是第一年唯一有收成的作物。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 嫩叶4-5周（与间苗结合，最嫩），常规收获6-8周（茎15-20cm，开花前），再收获在收割后10-20天（新芽长到15cm时），药用·泡茶在开花前后（成分最浓） |
| 要领 | 在基部上方2-3节处用剪刀或镰刀割下，每次取茎端10-15cm（根浅，用手摘会连根拔起）。叶背沾的土很多，要泡在水里晃一晃，再用流水冲洗 |
| 各次收割的产量 | 第一次最多，第二次约70%，第三次约50%，第四次（第三次后20天以上）少而韧，一般到此为止 |

| 留种 | 标准 |
|:---|:---|
| 特性 | 自花授粉，不用担心与其他植株混杂，一棵结几千到几万粒种子，种子在土里能保持发芽力几十年。大部分是自己完成的，所以留种是可选的 |
| 步骤 | 停止收割，选几棵让它开花。果实干成褐色、上部将要像盖子一样裂开时（9-10月）连茎割下，在纸或布上倒挂晾干，用手搓干茎抖出种子，装入密封容器，放在凉爽黑暗处 |
| 保存寿命 | 在土里的自然状态下几十年，常温密封5年以上，凉爽干燥则10年以上。受潮会发霉不能用 |

> **马齿苋的果实成熟后会像盖子一样横向裂开，把种子洒出来。等到完全干透，种子早已落到地上了。**

## 9. 储存
| 方法 | 步骤与期限 |
|:---|:---|
| 留在田里 | 不割，留到霜前，需要多少割多少。实际上是唯一真正的办法。连根拔起放在阴凉处3-5天，基部泡水2-3天 |
| 干燥 | 洗净抖掉泥土，用沸水焯30秒到1分钟（保留颜色并减少草酸），尽量挤干水分。摊在阴凉通风处晾干（直接晒会破坏成分），与草木灰或木炭一起装入密封容器保存 |
| 腌渍、发酵 | 用3-5%的盐层层码放，在凉爽处放2-3个月 / 压在2-3%盐水下发酵1-2周，再在凉爽处放1-2个月 / 放进酱油或大酱里腌几个月 |

&nbsp;&nbsp;&nbsp;耐储性E、常温2-3天是马齿苋最大的弱点，所以田地本身就是仓库。晒干的马齿苋与鲜品性质不同，冬天当凉拌菜和茶来用。乳酸发酵是省盐又能延长储存期的方法，马齿苋有黏性，所以腌渍后黏滑感会增强。

## 10. 烹调与注意事项
| 方式 | 要领 |
|:---|:---|
| 生吃 | 洗净直接吃。不用燃料，带酸味和黏性，维生素C完好 |
| 焯水凉拌 | 沸水30秒到1分钟（不要超过），冷水冲洗后拌调料。草酸减少，体积缩小，吃得更多 |
| 炒、汤、粥 | 用油炒2-3分钟，β-胡萝卜素吸收更好 / 汤和炖菜最后放（煮久了会化掉） / 切碎放进谷物粥里，黏性使粥变稠 |
| 茶 | 煮晒干的叶子。冬季的利用方式 |

| 成分 | 问题与对策 |
|:---|:---|
| 草酸 | 每100g鲜品约1,000-1,700mg，与菠菜相当或更高。与钙、铁、镁结合，妨碍吸收，吃过量有肾结石风险。有肾结石病史或肾功能差的人要特别注意。焯水后倒掉水可去除30-50%，所以生吃每天约100g，更多则焯水后吃 |
| 长得像的毒草（地锦草类） | 大戟科地锦草类切口流出白色乳汁般的汁液，叶片薄如纸，一定是对生，边缘有细锯齿，中央常有紫红色斑点。马齿苋汁液清澈，叶片厚实多肉，互生，边缘光滑。吃了地锦草会口腔和喉咙灼痛，呕吐腹泻 |
| 污染 | 自己的田地、菜园放心。路边有铅等重金属和尾气沉积，风险高；田边可能喷过除草剂；长期撂荒的空地若不知道以前的用途就避开。工厂、废弃物场地不采 |

> **切断茎或撕下叶片时流出白汁，就不是马齿苋。只确认这一点，就能把大戟科毒草几乎全部筛掉。**

&nbsp;&nbsp;&nbsp;在对分辨有把握之前，一定要一棵一棵掐断茎来确认。名字相近的苋属野菜与马齿苋不是一类，但都能吃，所以弄混也没有危险。传统上认为马齿苋性寒，不建议体寒的人吃。

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 把种子保存在凉爽干燥处，用晒干的马齿苋做凉拌菜和茶 |
| 3-4月 | 3月选定向阳且不积水的位置。4月霜冻完全过去后，几乎不覆土，压实播种 |
| 5-6月 | 5月发芽期水分管理和第一次间苗（间距5cm，间下的吃掉）。6月第二次间苗（10-15cm），在上一年种子落下的位置开始自然发芽 |
| 7-8月 | 7月第一次收割（基部留2-3节），高温期的鼎盛。8月重复第二、第三次收割 |
| 9-10月 | 9月结束收割，留下留种株让它开花。10月果实变褐后连茎割下，在阴凉处晾干取种，剩下的焯水后晒干 |
| 11-12月 | 11月初霜后地上部枯死，那块地不翻动。12月利用晒干的和腌渍的，检查种子 |

> **马齿苋守住餐桌的时候，是其他蔬菜被酷暑压垮的7月和8月。这两个月才是种这种作物的真正理由。**
