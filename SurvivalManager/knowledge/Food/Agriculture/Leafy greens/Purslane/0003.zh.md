## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

| 项目 | 内容 |
|---|---|
| 学名 | Portulaca oleracea |
| 分类 | 石竹目 马齿苋科 马齿苋属 |
| 别名 | 马齿苋、dwaejipul（意为“猪草”）、五行草、长命菜 |
| 原产地 | 推测为印度或地中海东部，现已在全世界归化 |
| 生活型 | 一年生。靠自然自播在同一位置每年重新出现 |
| 光合作用类型 | C4。受干旱胁迫时转为CAM |

&nbsp;&nbsp;&nbsp;关于马齿苋的原产地有多种说法，但如今这场争论本身已经失去了意义。因为它在除南极洲之外的所有大陆上都有生长，只要有人居住的地方，几乎无一例外都会出现。像这样分布广泛的植物，通常具备两个条件：种子小而多，对生长条件不挑剔。马齿苋对这两个条件的满足程度都达到了极致。一棵植株能产生数万粒种子，这些种子混在泥土里，随鞋底、运货大车的车轮和牲畜的肚子四处迁移。

&nbsp;&nbsp;&nbsp;此外，还有一段决定了这种植物性格的经历。马齿苋主要生长的地方，是沙漠边缘、河边砾石地、海边沙地、被人踩实的路边这样水分和养分都匮乏、只有阳光充足的土地。别的植物撑不下去，所以位置空了出来；而要在这里活下去，就得节约用水、承受强光。肉质组织、C4光合作用、根被切断后仍能重新长上的生命力，全都来自这样的地方。

### 2-2. 形态

| 器官 | 特征 |
|---|---|
| 叶 | 厚而有光泽的肉质卵形。呈匙状，先端圆钝，边缘光滑 |
| 叶序 | 互生，或近于对生。茎端处数片叶聚生 |
| 茎 | 圆柱形，红色至紫红色。匍匐地面向四周蔓延，长20-30cm |
| 根 | 一条粗壮的白色根，带有浅层侧根。被切断后节上还会重新生根 |
| 花 | 直径5mm上下的黄花。花瓣5片。在韩国，6月至9月，只在晴天上午开放 |
| 果实 | 像盖子一样横向裂开的盖果。每个果实内有数十粒黑色极小的种子 |
| 汁液 | 切开会流出清澈的汁液。白色的汁液绝对不会流出 |

&nbsp;&nbsp;&nbsp;最后一行是这张表中最重要的。切断马齿苋的茎，流出的是透明、略带黏性的清澈汁液。如果流出的是像白牛奶一样的汁液，那就不是马齿苋，而是大戟科的另一种草，不能吃。关于这种区别，第14节还会再详细说明。

&nbsp;&nbsp;&nbsp;花只在晴天上午开放这一点，也值得了解。在阴天或下午去查看田地，可能连一朵花都看不到就走过去了。想要留种的话，与其记下花是什么时候开的，不如看茎节上有没有结出带盖的小罐状果实，这样更可靠。

### 2-3. 在C4与CAM之间切换的光合作用

&nbsp;&nbsp;&nbsp;马齿苋与其他叶菜的根本区别就在这里。大多数植物进行普通的C3光合作用，玉米和高粱等少数植物进行C4光合作用，仙人掌和龙舌兰等沙漠植物进行CAM光合作用。马齿苋平时以C4方式运转，干旱严重时则转为CAM。两种方式兼备的植物非常罕见，正是这种转换造就了马齿苋极端的耐旱性。

| 方式 | 吸收二氧化碳的时间 | 气孔开放的时间 | 水分损失 | 优缺点 |
|---|---|---|---|---|
| C3 | 白天 | 白天 | 多 | 大多数蔬菜。光弱时损失也较小 |
| C4 | 白天 | 白天 | 中等 | 强光和高温下效率高。光弱时损失很大 |
| CAM | 夜间 | 夜间 | 极少 | 生长缓慢，但能在极端干旱中存活 |

&nbsp;&nbsp;&nbsp;植物失去水分的通道是气孔。要吸入二氧化碳就必须打开气孔，而气孔一开，水蒸气就会逸出。白天炎热干燥，所以在白天开启气孔的一方损失更大。CAM植物通过错开时间来化解这一两难：只在夜间凉爽时打开气孔吸收二氧化碳，并以有机酸的形式储存起来；白天则将气孔紧紧关闭，取出储存的二氧化碳进行光合作用。

> **马齿苋在有水时以C4方式快速生长，水源断绝后则转为CAM，停止生长，硬撑过去。在无法给田地灌水的情况下，这种转换就等于生存。**

&nbsp;&nbsp;&nbsp;这种转换是有代价的。转入CAM的马齿苋几乎不再生长，也就是说，它虽然活着，可收获的东西并不会增加。而且，有机酸会积累在叶中，所以黎明时采摘的马齿苋酸味很重。事实上，久旱之后一大早采下的马齿苋是发酸的。这不是变质，而是正常现象；随着白天过去，酸被消耗，到了下午酸味就会变淡。

&nbsp;&nbsp;&nbsp;C4这一特点带来的另一个结果，就是前面看到的光照项目E。C4植物要运转一道在细胞内再次浓缩二氧化碳的额外工序，而这道工序需要消耗能量。光照充足时，这笔投入是划算的；光照不足时，这笔成本就原样变成亏损。把马齿苋种在阴处，它不会死，但收获会减少一半。

### 2-4. 生育阶段

| 阶段 | 时期 | 发生什么 | 主要需求 |
|---|---|---|---|
| 发芽·幼苗期 | 播种后2周 | 长出两片极小的子叶。只有这个时期是唯一的脆弱期 | 表土水分，地温20℃以上 |
| 营养生长期 | 2-6周 | 茎匍匐地面向四周蔓延，叶片变厚 | 阳光，少量氮 |
| 最佳收获期 | 6-8周 | 茎长15-20cm，叶和茎最为嫩软的时候 | 均衡 |
| 开花·结实期 | 8-12周 | 每个节上开花结果。茎变得老韧 | 磷，钾 |

&nbsp;&nbsp;&nbsp;在此指出，幼苗期是唯一的薄弱阶段。长成的马齿苋，哪怕用脚踩、拔出来扔掉也能活过来，但刚刚长出的子叶，只要表土干透一天就会死。自然状态下马齿苋往往在下雨之后一下子成片冒出来，原因就在于此。如果需要人手介入，那就只有这2周，此后就无需再动手了。

&nbsp;&nbsp;&nbsp;开花之后，茎中纤维增多而变老变韧，叶片也变小。如果是为了食用而收获，最好在开花前割取；如果是为了采种，就要另外留下几棵，一直留到最后。这两个目的无法在同一棵植株上同时实现。

### 2-5. 每100g的营养成分

| 营养素 | 含量 | 备注 |
|---|:---:|---|
| 热量 | 16-20kcal | 不同资料中为7-20kcal，差异很大 |
| 水分 | 约93g | 热量低的最主要原因 |
| 蛋白质 | 约2.0g | 蛋白质占热量的比例（P:E）为40.6% |
| 脂质 | 约0.4g | 其中相当一部分是α-亚麻酸 |
| α-亚麻酸（ALA） | 300-400mg | 对叶菜而言是罕见的数值 |
| 钾 | 494mg | 参与钠的排出和血压调节 |
| 镁 | 68mg | 在叶菜中名列前茅 |
| 钙 | 65mg | 因草酸而吸收率下降 |
| 铁 | 0.9-2.0mg | 不同资料差异很大 |
| 维生素C | 21mg | 焯水后损失一半以上 |
| 维生素A | 以β-胡萝卜素形式大量存在 | 与油一起食用，吸收更好 |
| 维生素E | 高 | 在凉拌野菜（namul）类中名列前茅 |
| 维生素B族 | 硫胺素、烟酸、维生素B6、叶酸 | |
| 草酸 | 高 | 第14节另行讨论 |

&nbsp;&nbsp;&nbsp;热量数值在不同资料中相差到7-20kcal，并不奇怪。因为它是肉质植物，含水量会随生长环境而大幅变化。雨水多的年份、在水多的地里长出的马齿苋几乎全是水，而干旱年份、在干地里长出的马齿苋，同等重量中所含的干物质是前者的两倍。评价中使用的20kcal是其中偏高的一端。无论采用哪个值，结论都一样：用这种植物来计算热量没有意义。

&nbsp;&nbsp;&nbsp;α-亚麻酸这一项是这张表的核心。ω-3系脂肪酸是人体自己无法合成、必须从食物中获取的必需脂肪酸，主要来源是青背鱼、紫苏（荏）籽、亚麻籽和核桃。在灾难情形下，这份清单大多会消失：渔业停摆，榨油也变得困难。叶菜原本补不上这个缺口，而马齿苋却是个例外，每100g含有300-400mg。每日推荐摄入量大约是1,600-2,000mg，所以光靠马齿苋很难满足，但完全为0的膳食与多少有一些摄入的膳食，完全是两回事。

## 3. 栽培环境

### 3-1. 温度

| 类别 | 温度 | 结果 |
|---|:---:|---|
| 发芽最低温 | 约15℃ | 低于此温度几乎不发芽 |
| 发芽适温 | 20-30℃ | 3-7天内整齐萌发 |
| 生长适温 | 20-35℃ | 盛夏是长得最好的时候 |
| 可生长范围 | 10-35℃ | 幅度25℃。温度适应幅度SS的依据 |
| 高温极限 | 40℃以上也能存活 | 生长变慢，但不会死亡 |
| 低温极限 | 5℃以下停止生长 | |
| 致死 | 0℃，一次霜冻 | 地上部分软烂而死 |

&nbsp;&nbsp;&nbsp;在本文档所讲的蔬菜中，马齿苋属于最喜欢夏天的一类。在韩国，生菜、大白菜和菠菜被暑热蒸得瘫软、纷纷抽薹的7月和8月，正是马齿苋的全盛期。灾难情形下的田里，盛夏的一个月常常成为蔬菜的空档期，而马齿苋恰好填进这段空档。这就是为什么即便它热量低、又不能贮藏，也仍然值得备下的理由之一。

&nbsp;&nbsp;&nbsp;另一端则毫不留情。只要气温降到零下一次，就到头了。这与羽衣甘蓝那样挨了霜反而变甜的作物截然相反，初霜降下的第二天早晨，田里的马齿苋已全部发黑软烂。这时不必惋惜，因为在此之前，种子早已落进土里了。

### 3-2. 光照

| 条件 | 相对产量 | 解读 |
|---|:---:|---|
| 全天直射光 | 100% | 以此为基准 |
| 40%遮光 | 约45% | 置信区间37-56%。光照E的依据 |
| 半阴 | 大幅减少 | 虽能存活，但茎变得细长 |
| 深阴 | 几乎不生长 | 连发芽都不太顺利 |

&nbsp;&nbsp;&nbsp;关于马齿苋最常见的误解就出在这里。人们以为它像杂草一样哪儿都能长，对光照想必也不挑剔，实际上它比本文档中的任何作物都更敏感于光照。原因就是前面讲过的C4光合作用。

&nbsp;&nbsp;&nbsp;这个事实对栽培的意义很明确：马齿苋不是该种在玉米下面、番茄之间或树荫里的作物。垄的尽头、田边的闲地、围墙下向阳的地方、路边的坡地这类整天都有阳光的位置，才是它该待的地方。说找到一处不与其他作物争地、日照又好的位置，几乎就是马齿苋管理的全部，也并不过分。

### 3-3. 水分与土壤

| 项目 | 标准 | 备注 |
|---|---|---|
| 土壤质地 | 几乎所有土壤 | 在砾石地、沙地、板结的路边也能生长 |
| 土壤酸度 | pH 5.6-7.8 | 范围很宽 |
| 有机质 | 不需要 | 是适应贫瘠土地的植物 |
| 排水 | 重要 | 唯一需要留意的项目 |
| 灌溉 | 除发芽期外不需要 | 总量不足250L/㎡也能生长 |
| 盐分 | 相当耐受 | 在海边沙地也能自生 |

> **马齿苋死亡的原因，几乎总是水排不出去，而不是缺水。**

&nbsp;&nbsp;&nbsp;多肉植物的共同弱点是过湿。由于组织本身就含着水，一旦根部周围也被水淹没，氧气中断，很快就会开始腐烂。在韩国的梅雨季（6月下旬至7月），积水几天的地方，马齿苋会整株烂掉。反过来，一个月干旱，也只是叶子稍微皱缩，不会死。了解这种不对称，管理的方向也就定下来了：与其想着浇水，不如选一块不会积水的位置，要有效得多。

&nbsp;&nbsp;&nbsp;土壤酸度范围宽，在灾难情形下同样价值很大。石灰用尽、田地偏酸时，十字花科作物倒在根肿病上，豆科作物长不出根瘤，而马齿苋却丝毫不受影响。在没有资源用于调节酸度的情况下，它是为数不多可以直接利用的作物。
