## 引言
&nbsp;&nbsp;&nbsp;韭菜（Allium tuberosum）是石蒜科葱属的多年生草本，在与葱、大蒜、洋葱同属的这一类里，是唯一不挖根、只割叶来用的。地下的鳞茎和短根状茎在叶子被割之后还会长出新叶，一旦扎下根就年年回来，所以不需要种子，不需要播种，也不需要育苗。在评价表中它因持续性SS和连作适应性SS而获得综合S（52.2分，有效183种中第10位），副食为SS（61.1分）。耐寒性SS是指零下20℃以下根也能存活，而且一次种下用5年，所以每年的挖掘能量低到每㎡26kcal。弱点出人意料地是微量营养素D（满足每日推荐量10%的营养素有8种，羽衣甘蓝是18种）。种韭菜的理由不是营养密度，而是香味和时间。含硫化合物的香味能给缺盐缺酱的餐桌提味（口味D是对气味的排斥），4月到10月每隔10-20天割一次，一年可割5-7次来吃，而且早春最先带来绿色。耐储性E（割下的叶子在常温下2-3天）和种子寿命D（常温下撑不过一年）靠分株、把活的株丛传下去来解决。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | S | 52.2 |
| 短期 | S | 52.4 |
| 长期 | S | 51.9 |
| 副食 | SS | 61.1 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：持续性、烹调·加工要求度、温度幅度、耐寒性、连作适应性、国内种植普及度、自留种。A：收获速度、设施负担、整地·挖掘能量、产量稳定性。B：单位面积热量、蛋白质密度、施肥、水消耗量、光照、病虫害压力、防治自立度 |
| 劣势 | E：耐储性。D：微量营养素、非食用价值、口味、种子寿命。C：无合成投入产量保持率（40.8%） |

> **灾害会持续多久无法预测时，最有价值的作物不是在某个时点最好的作物，而是在任何时点都不差的作物。韭菜就在这个位置上。**

&nbsp;&nbsp;&nbsp;短期（52.4）与长期（51.9）几乎相同，是因为它从头到尾都稳定地长出来。自留种SS的依据不是留种，而是分株。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 天门冬目石蒜科葱属。原产于中国北部到东北亚 |
| 生活型 | 宿根性多年生（地上部在冬季枯萎，根越冬）。繁殖既可用种子也可分株，但实际上以分株为主 |
| 叶、地下部 | 扁平线形，长20-40cm，宽0.5-1cm。短鳞茎和向侧面延伸的短根状茎上长出新株丛，须根集中在深20cm以内 |
| 花、种子 | 8-9月开伞状的白色小花。花茎比叶粗而硬，里面是实心的。种子是黑色有棱角的小粒 |

&nbsp;&nbsp;&nbsp;叶子扁平而且实心，是区分韭菜与大葱（圆而中空）的第一标准。

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 发芽·幼苗期、初期生长 | 播种后12周 | 一片细如丝的叶子非常缓慢地长出。磷、氮 |
| 株丛扩大 | 定植后1年 | 向侧面长出新株，连成一团。氮、钾 |
| 收获期 | 第2年起4-10月 | 每隔10-20天长出叶子。氮、钾 |

> **第一年的韭菜不是收获的一年，而是长根的一年。第一年贪心地割很多次，株丛站不稳，第二年的产量就会大大下降。**

&nbsp;&nbsp;&nbsp;每100g热量22-46kcal，水分88-92g，蛋白质1.2-3.0g（占热量的10.4%），膳食纤维约2.5g，钾、钙、铁、磷多，富含β-胡萝卜素、维生素C（焯水后损失一半以上）、维生素K和叶酸。气味和抗菌作用的来源是含硫化合物（蒜氨酸类）。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽最低10℃（适温20℃左右，7-14天），生长适温18-20℃，可生长5-30℃（幅度25℃）。25℃以上叶子变老，5℃以下停止生长。地上部在初霜前后枯死，但根在零下20℃以下也能存活 |
| 光 | 每天6小时以上（实用的最低线）。遮光40%时产量约86%。半阴下叶子嫩、颜色淡、香味弱 |
| 水、土壤 | 总蒸散量约500mm（对干旱较耐受）。排水良好的砂壤土至壤土，pH 6.0-6.5（6.3-6.5最佳），腐熟堆肥要足。垄高15-20cm以上（排水差的地块25cm） |

> **韭菜在冬天消失，不是死了，而是退了。地上部干枯变褐了，把那块地翻掉，第二年就什么也长不出来。**

> **毁掉韭菜种植的原因，几乎总是过湿而不是干旱。雨季积水的地方，养了5年的株丛也会在几周内整丛消失。**

| 品系 | 特征 |
|:---|:---|
| 宽叶韭、台湾韭菜 | 叶宽，分蘖旺盛，抗病，产量高；休眠浅，醒得早（早春先收获） |
| 地方品种、蒙古韭、满洲韭 | 地方品种香味浓，越冬可靠，对露地适应力好。蒙古韭耐寒性特别强，满洲韭休眠深，收获间隔长 |

&nbsp;&nbsp;&nbsp;比选品种更重要的是弄到活的株丛，而不是种子。从邻居或附近分来韭菜，第一年就能收获已经适应当地的品系；只有种子的话，就放弃第一年的收获，先长根。

## 4. 田地准备、播种与定植
| 项目 | 标准 |
|:---|:---|
| 整地 | 深耕20-30cm（要用5年的地方，一开始就深翻），垄高15-20cm（排水差则25cm以上），宽90-120cm（种两三行），一定要有排水沟（过湿是最大的失败原因）。提前拣出石头和多年生杂草的根。种前2-3周用石灰把pH调到6.0-6.5 |
| 施肥（1,000㎡） | 氮20-25kg，磷12-15kg（全部作基肥），钾15-20kg，石灰100-150kg。基肥在种前1-2周施入：堆肥全量、磷全量、氮和钾的一半 |
| 追肥 | 每次割后以氮、钾为主（关键）。11月越冬前以钾为主（提高耐寒性），3月春天醒来时以氮为主 |
| 替代资源 | 尿的8-10倍稀释液（割后立刻浇在沟里，沾到叶子会烧叶，等一天让割口愈合），腐熟堆肥（没腐熟的会招来根蛆），木灰每㎡一两把（提供钾，使土壤接近韭菜喜欢的中性），油饼、骨粉、草液肥，以及前一年种豆并把残体翻入土中（要用5年的地方，种前是唯一的机会） |

| 繁殖 | 时期与方法 |
|:---|:---|
| 分株（正统） | 3-4月新芽冒出时或9月，用铁锹把根周围宽宽地挖起，3-5株一团分开。地上部只留10cm剪掉，修整过长的根尖，为了不埋住生长点，栽5-8cm深，行距20cm，株距15-20cm，浇足水。成活一个月后首次收获 |
| 播种 | 春季（3月中旬至4月初）或秋季（8月中旬至9月初），行距20cm，每穴2-3粒（20℃左右，7-14天发芽）。真叶2-3片时间苗到5cm，4-5片时间到15-20cm，第一年不割。苗在雨季前（5月至6月中旬）移栽 |
| 种子处理 | 在50-55℃的水里泡10-15分钟后用冷水降温（去除表面病原菌），给湿种子裹上筛过的木灰，或用常温水泡一夜使发芽提前几天 |

> **分株是起步种韭菜的正统方法。从种子开始，到第一次收获要一年；从株丛开始，一个月就够。**

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 刚栽后、成活期（2-3周） | 浇透一次使根与土贴紧。之后表土干了再浇 |
| 生长期 | 每周1-2次，每次浇深（浅而勤的浇水使根变浅） |
| 刚割后 | 一天后浇一次（割口愈合之后） |
| 雨季、休眠期 | 不浇（雨季的水分管理就是整修排水沟，湿土结冰会伤根） |

&nbsp;&nbsp;&nbsp;叶尖干枯变细是缺水，叶子突然发黄倒伏是过湿造成的烂根。没有塑料膜，就用稻草、干草、落叶、稻壳覆盖（夏季抑制杂草，冬季保温）。

| 管理 | 内容 |
|:---|:---|
| 去花茎 | 8月前后，比叶粗而硬、实心的花茎冒出来，就每隔7-10天见到就从基部掰断或割掉（养分集中到花和种子上，株丛长势变弱。留种株另外保留，掰下的花茎花蕾不要丢，可以吃）。错过的话，当年秋季和次年春季的收获都会减少 |
| 株丛更新 | 每3-4年的早春或9月，叶子变细、株丛变密、中间开始空了，就把株丛整丛挖起，分成3-5株一团，尽量栽到别的区块（更新不是损失而是增殖：3-4年后三四团，6-8年后十团以上） |
| 杂草 | 唯一的根本对策是栽前彻底拣出多年生杂草的根。用稻草和干草盖住沟，在割后或早春拔草 |
| 越冬 | 10月下旬结束最后一次割（霜前3-4周起停止割，才能让根积累养分，决定来年的收成）。11月施钾肥，12月把干叶原样留着或盖稻草，2月下旬至3月揭掉覆盖 |

## 6. 病虫害与养分问题
| 病虫害 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 菌核病 | 基部变软，有白色菌丝和黑色颗粒。过湿、低温 | 连土一起清除病株。菌核留在土里，那块地好几年不用 |
| 霜霉病 | 叶子发黄，背面有灰色霉。低温高湿（葱属的最大制约） | 保证排水和通风，株距15-20cm |
| 叶枯病、锈病、灰霉病 | 叶尖干枯 / 橙色粉状斑点 / 基部有灰霉 | 摘掉病叶拿到田外，拉开株距，割后晾一天 |
| 软腐病 | 基部变软发臭（细菌从割口侵入） | 避免雨天割 |
| 根蛆 | 幼虫啃食地下部，植株萎蔫死亡（春秋、过湿） | 不施没腐熟的堆肥，改善排水。在基部撒木灰 |
| 斑潜蝇、蚜虫、蓟马 | 叶内隧道和白线 / 吸汁并诱发煤污病 / 白斑 | 摘除受害叶并用网 / 用水冲洗或肥皂水 / 避免干燥，蓝色粘虫板 |

&nbsp;&nbsp;&nbsp;大部分病害与过湿相连，所以不用药就能做的核心是保证排水（把垄做高、把排水沟挖深）、株距15-20cm、割后干燥一天、摘除病叶。此外还可用肥皂水、300-500倍木醋液（预防）、防虫网（春秋的斑潜蝇、根蛆成虫）。

| 症状 | 原因与处理 |
|:---|:---|
| 整片叶子淡绿、细而短 | 缺氮。割后第二天把尿的8-10倍稀释液浇在沟里，把腐熟堆肥放在株间 |
| 叶子特别大而嫩，容易倒伏 | 氮过剩。停止施肥（已变得不抗病） |
| 老叶边缘焦褐 | 缺钾。每㎡撒一两把木灰 |
| 生长迟缓，叶色深绿发紫 | 缺磷（低温期也有同样症状）。骨粉、木灰 |
| 新叶扭曲，叶尖干枯 | 缺钙。烧过捣碎的蛋壳和贝壳粉 |
| 春天叶子明显变细，或割得越多越细 | 秋季割得过多、缺钾、累积的氮被消耗。10月下旬以后不再割，11月施钾，每次割后追肥 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 番茄·茄子·辣椒（韭菜根系分泌物抑制枯萎病和疫病），草莓（减少烂根），胡萝卜（互相驱赶对方的害虫），生菜·菠菜（利用韭菜之间的空地，互不争夺） |
| 差 | 豆科作物（大豆、豌豆、菜豆：葱属分泌物抑制根瘤菌），同属的葱属（大葱、大蒜、洋葱：病原菌和害虫积累） |

&nbsp;&nbsp;&nbsp;韭菜的连作适应性为SS，所以不需要轮作。更新时移到相邻的区块，发生过菌核病的地方5年以上不种葱属。好的地点是不积水、常经过的路口、在每年翻耕的区块之外、每天日照6小时以上（果菜类垄边则兼有间作效果）。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 以分株开始的，成活后一个月、叶长20-25cm时（以种子开始的，次年春天。第一年不割）。此后每隔10-20天，在露地一年割5-7次（春季2-3次，夏季1-2次，秋季2次）。10月下旬停止 |
| 割的高度 | 第一次在离地面3-4cm处留桩割，此后每次比上一次的割口再提高1-1.5cm，次年春天再降到3-4cm开始 |
| 要领 | 用锋利的刀或剪刀，一次把一丛整齐割下（钝刀会压烂割面而引病）。在露水干后的上午割，避开雨天。割后一天不浇水不施肥。基部会沾泥土，所以掰开冲洗 |

> **收获韭菜几乎唯一会失败的方式是割得太贴地。不留3-4cm而割到地面，生长点被割掉，下一茬叶子就不长或晚很多。**

| 留种 | 标准 |
|:---|:---|
| 方针 | 种子寿命不到一年，所以囤积种子的策略不成立。韭菜的种子仓库不是袋子而是田，所以把活的株丛分栽在几个地方 |
| 步骤 | 另外选定几株第三年以上的健康植株，当年不割，让花茎留着（8-9月开花）。荚果干成褐色裂开、露出黑色种子时（会自己掉落，所以不要错过时机），连花茎割下倒挂，搓下种子，用筛子或风吹去瘪粒，在阴凉处晾干，放进密封容器并配草木灰或木炭，放在凉爽阴暗处 |
| 寿命 | 常温密封不到一年（极限是次年春天），凉爽干燥处1-2年，潮湿或炎热处几个月内就急剧下降。因为种子里的脂肪容易氧化 |

## 9. 储存
| 方法 | 期间 | 条件 |
|:---|:---|:---|
| 留在田里（仓库） | 整个4-10月 | 不割，需要的那天割需要的量 |
| 用湿布包着放凉爽处 | 3-5天 | 在窖或地窖里更久 |
| 立着把基部泡在水里 | 2-3天 | 平放的话叶子会弯，很快变坏 |
| 干燥 | 半年至1年 | 洗净并彻底沥干，切成3-5cm（整根晒里面不干），在阴凉通风处晾到一捏就碎。晒太阳会损失颜色和香味。放进密封容器并配草木灰或木炭保存 |

| 腌渍、发酵 | 方法 |
|:---|:---|
| 韭菜泡菜（kimchi） | 用盐腌软后拌辣椒粉，在凉爽处放1-2个月 |
| 盐渍、咸菜 | 按重量5-10%的盐层层腌，3-6个月。浸在10%以上的浓盐水里能放半年以上（吃前用水泡去盐味） |
| 酱菜 | 酱油渍、大酱渍能放几个月。把8月摘的花茎花蕾泡在盐水或酱油里做成的花茎酱菜也能放几个月 |

&nbsp;&nbsp;&nbsp;晒干韭菜最大的损失是香味。

## 10. 烹调与注意事项
| 方法 | 燃料 | 要领 |
|:---|:---|:---|
| 生吃、凉拌 | 无 | 洗净直接拌或配着卷着吃；用盐稍腌一下再拌。香味和维生素C完整 |
| 焯水凉拌菜 | 少 | 沸水中20-30秒（焯久了会变软，香味散失） |
| 汤、炖菜、煎饼 | 中等 | 关火前加入（煮久了香味消失）。煎饼拌进面粉或杂粮粉面糊里煎 |
| 炒、泡菜 | 少、无 | 大火1-2分钟（β-胡萝卜素和维生素K是脂溶性的，有油才能好好吸收）。泡菜兼具储存和烹调 |

> **烹调韭菜的原则只有一个：尽量晚放，尽量短时间加热。韭菜的香味怕热，煮久了，放韭菜的理由就没有了。**

&nbsp;&nbsp;&nbsp;正常食用量是安全的，但吃得过多或空腹生吃，含硫化合物会刺激胃黏膜，引起烧心和腹泻。它含维生素K多，影响血液凝固，整个葱属对狗、猫和部分牲畜有毒，所以别让宠物吃。

| 类别 | 葱属（韭菜、茖葱、野蒜） | 铃兰 | 水仙·石蒜类 |
|:---|:---|:---|:---|
| 切开的叶子的气味 | 一定有葱或蒜的气味 | 没有气味 | 没有气味，或只有草味 |
| 叶 | 薄而软，基部几片叶重叠成叶鞘。平行脉不明显 | 厚而硬挺，有光泽。两片叶相对抱着长出 | 厚而光滑。扁平的叶子重叠着长出 |
| 吃了之后 | 可食用 | 呕吐、头晕、心跳异常 | 严重呕吐、腹痛、腹泻 |

> **切下一片叶子搓一搓闻一闻，没有葱或蒜的气味就不是葱属。这一项确认几乎能筛掉所有与葱属相似的毒草。**

&nbsp;&nbsp;&nbsp;田里种的韭菜没有这个风险。

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 以根的状态越冬。检查覆盖物，不要踩那块地 |
| 3月 | 揭掉覆盖物并清理干叶。以氮为主施第一次肥。分株的适期 |
| 4-5月 | 首次收获，离地面3-4cm留桩割（割后一天再施肥浇水）。5月第2次、第3次收获，每次提高1-1.5cm割。每次割后追肥 |
| 6-7月 | 继续收获。雨季前整修排水沟。7月高温期叶子变老，要煮熟吃或做成泡菜 |
| 8-9月 | 花茎冒出就每隔7-10天去除，花蕾采收来吃（留种株保留）。9月恢复秋季收获（品质最好），分株的适期 |
| 10-12月 | 10月下旬结束最后一次收获，留种用的花茎干了就采种。11月以钾为主的越冬肥。12月把干叶留作覆盖或盖稻草，靠储存的泡菜过冬 |

> **不能忘记的五件事：弄到活的株丛而不是种子，离地面留3-4cm割，8月去除花茎，10月下旬停止割、11月施钾，选不积水的地方。**
