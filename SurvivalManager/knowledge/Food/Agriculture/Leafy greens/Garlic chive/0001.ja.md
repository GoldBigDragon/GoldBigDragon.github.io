## はじめに
&nbsp;&nbsp;&nbsp;ニラ(Allium tuberosum)はヒガンバナ科ネギ属の多年草で、ネギ・ニンニク・タマネギと同じ仲間のうち、唯一、根ではなく葉だけを刈って使います。地下の鱗茎と短い地下茎から、葉を刈った後にも新しい葉が上がり、一度根づけば毎年戻ってくるので、種も播種も育苗も必要ありません。評価表で永続性SSと連作への適応性SSを得て、総合S(52.2点、有効183種中10位)、副食はSS(61.1点)です。耐寒性SSは-20℃を下回っても根が生き残るという意味で、一度植えれば5年使うので、年間の掘削エネルギーが1㎡当たり26kcalと低いです。弱みは意外にも微量栄養素Dです(1日の推奨量の10%を満たす栄養素が8種、ケールは18種)。ニラを植える理由は、栄養密度ではなく、香りと時間です。硫黄化合物の香りが、塩やみそが足りない食卓の味を立て(味Dはにおいへの抵抗感)、4月から10月まで10日から20日間隔で年に5-7回刈って食べられ、早春に最初に青いものを出します。貯蔵性E(刈った葉は常温で2-3日)と種子の寿命D(常温で1年をもたない)は、生きた株を分けてつなぐことで解決します。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | キジカクシ目ヒガンバナ科ネギ属。原産地は中国北部から東北アジア |
| 生活型 | 宿根性の多年草(地上部は冬に枯れ、根が越冬する)。繁殖は種と株分けのどちらも可能だが、実際には株分けが中心 |
| 葉、地下部 | 平たい線形で、長さ20-40cm、幅0.5-1cm。短い鱗茎と横に伸びる短い地下茎から新しい株が出て、ひげ根は深さ20cm以内に集まっている |
| 花、種子 | 8-9月に白い小さな花が傘状に咲く。花茎は葉より太くて硬く、中が詰まっている。種子は黒くて角ばった小さな粒 |

&nbsp;&nbsp;&nbsp;葉が平たくて中が詰まっていることが、長ネギ(丸くて中が空洞)とニラを分ける第一の基準です。

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 発芽・幼苗期、初期生育 | 播種から12週間 | 糸のように細い葉が1枚、とても遅く出る。リン、窒素 |
| 株の拡大 | 定植後1年 | 横に新しい株ができて塊になる。窒素、カリウム |
| 収穫期 | 2年目から4-10月 | 10-20日間隔で葉を出す。窒素、カリウム |

> **1年目のニラは、収穫する年ではなく、根をつくる年です。1年目に欲張って何度も刈ると、株が根づかず、翌年の収量が大きく落ちます。**

&nbsp;&nbsp;&nbsp;100g当たり熱量22-46kcal、水分88-92g、タンパク質1.2-3.0g(熱量比10.4%)、食物繊維約2.5gで、カリウム・カルシウム・鉄・リンが多く、βカロテン、ビタミンC(ゆでると半分以上が失われる)、ビタミンK、葉酸が豊富です。においと抗菌作用のもとは、硫黄化合物(アリイン系)です。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽の最低10℃(適温は20℃前後、7-14日)、生育適温18-20℃、生育可能5-30℃(幅25℃)。25℃以上だと葉が硬くなり、5℃以下では生育が止まる。地上部は初霜のころに枯れるが、根は-20℃以下でも生きる |
| 光 | 1日6時間以上(実用的な最低ライン)。40%遮光で収量は約86%。半日陰では葉が柔らかく色が淡く、香りが弱くなる |
| 水、土壌 | 総蒸発散量は約500mm(乾燥には比較的強い)。水はけのよい砂壌土-壌土、pH 6.0-6.5(6.3-6.5が最適)、完熟堆肥をたっぷり。畝の高さは15-20cm以上(水はけの悪い土地は25cm) |

> **ニラが冬に姿を消すのは、枯れるのではなく、退くのです。地上部が枯れて茶色になっても、その場所を耕してしまうと、翌年は何も出ません。**

> **ニラ栽培をだめにする原因は、ほとんどいつも、干ばつではなく過湿です。梅雨に水がたまる場所では、5年育てた株も数週間で丸ごと消えます。**

| 系統 | 特徴 |
|:---|:---|
| 大葉種、台湾ニラ | 葉が広く、分げつが旺盛で病気に強く収量が多く、休眠が浅くて早く目覚める(早春に先に収穫) |
| 在来種、モンゴルニラ、満州ニラ | 在来種は香りが濃く、越冬が確実で、野外への適応力がよい。モンゴルニラは耐寒性が特に強く、満州ニラは休眠が深く収穫間隔が長い |

&nbsp;&nbsp;&nbsp;品種選びより大切なのは、種ではなく生きた株を手に入れることです。近所のニラを株分けしてもらえば、その地域にすでに適応した系統を1年目から収穫でき、種しかなければ、1年目の収穫をあきらめて根をつくります。

## 4. 畑の準備と播種、定植
| 項目 | 基準 |
|:---|:---|
| 土づくり | 20-30cmの深さに耕し(5年使う場所なので最初に深く)、畝の高さ15-20cm(水はけが悪ければ25cm以上)、幅90-120cm(2、3列植え)、排水溝は必須(過湿が最大の失敗原因)。石と多年生雑草の根をあらかじめ取り除く。植える2-3週間前に石灰でpH 6.0-6.5に整える |
| 施肥(1,000㎡) | 窒素20-25kg、リン酸12-15kg(全量元肥)、カリウム15-20kg、石灰100-150kg。元肥は植える1-2週間前に、堆肥の全量、リン酸の全量、窒素とカリウムの半分 |
| 追肥 | 刈り取りのたびに窒素・カリウム中心(要点)。11月の越冬前はカリウム中心(耐寒性を高める)、3月の春に目覚めるときは窒素中心 |
| 代替資源 | 尿の8-10倍希釈液(刈り取り直後に溝へ注ぐ。葉にかかると焼ける。切り口がふさがるよう1日待つ)、完熟堆肥(未熟だとネギバエを呼ぶ)、木灰を1㎡に一つかみ二つかみ(カリウムの供給、ニラが好む中性に近づける)、油かす・骨粉・草の液肥、前年にマメを育ててその残渣をすき込む(5年使う場所なので、植える前が唯一の機会) |

| 繁殖 | 時期と方法 |
|:---|:---|
| 株分け(王道) | 3-4月に新芽が上がるとき、または9月に、スコップで根の周りを広く掘り上げて、3-5株ずつ1つの塊に分ける。地上部を10cmだけ残して切り、長い根の先を整え、成長点が埋まらないよう5-8cmの深さで、条間20cm、株間15-20cmに植え、水をたっぷりやる。活着の1か月後に最初の収穫 |
| 種まき | 春(3月中旬-4月初め)か秋(8月中旬-9月初め)に、条間20cm、1穴当たり2-3粒をまく(20℃前後、7-14日で発芽)。本葉2-3枚で5cm、4-5枚で15-20cmに間引き、1年目は刈らない。苗は梅雨前(5月-6月中旬)に移す |
| 種子の処理 | 50-55℃の湯に10-15分浸してから冷水で冷ます(表面の病原菌を除く)、濡らした種に木灰をふるってまぶす、常温の水に一晩浸して発芽を数日早める |

> **株分けがニラを始める王道です。種から始めると最初の収穫まで1年かかり、株から始めれば1か月で済みます。**

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 植えた直後、活着期(2-3週間) | たっぷり1回やって根と土を密着させる。以後は表土が乾いたら |
| 生育期 | 週1-2回、1回ごとに深く(浅く頻繁な水やりは根を浅くする) |
| 刈り取り直後 | 1日後に1回(切り口がふさがった後) |
| 梅雨、休眠期 | やらない(梅雨は排水溝の整備が水管理、濡れた土が凍ると根が傷む) |

&nbsp;&nbsp;&nbsp;葉先が枯れて細くなったら水不足、葉が急に黄色くなって倒れたら過湿による根腐れです。ビニールがなければ、わら、枯れ草、落ち葉、もみ殻でマルチします(夏は雑草の抑制、冬は断熱)。

| 管理 | 内容 |
|:---|:---|
| 花茎の除去 | 8月ごろ、葉より太くて硬く中が詰まった花茎が上がってきたら、7-10日おきに見つけしだい根元から折るか切る(花と種に養分が集まり、株の勢いが落ちる。採種株は別に残し、折った花茎のつぼみは捨てずに食べる)。逃すと、その年の秋と翌春の収穫がともに減る |
| 株の更新 | 3-4年ごとに早春か9月に、葉が細くなり、株が密になって真ん中が空き始めたら、株を丸ごと掘り上げて3-5株ずつに分け、できれば別の区画に植える(更新は損失ではなく増殖。3-4年後に3、4塊、6-8年後に10塊以上) |
| 雑草 | 植える前に多年生雑草の根を徹底的に取り除くのが、唯一の根本対策。溝をわらと枯れ草で覆い、刈り取り直後や早春に草を取る |
| 越冬 | 10月下旬に最後の刈り取りを終える(霜の3-4週間前から刈るのをやめると、根に養分がたまり、翌年の栽培を左右する)。11月にカリウム肥料、12月は枯れ葉をそのまま置くかわらをかぶせ、2月下旬-3月に覆いを取る |

## 6. 病害虫と養分の問題
| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| 菌核病 | 株元が軟らかくなり、白い菌糸と黒い粒。過湿、低温 | 病んだ株を土ごと取り除く。菌核が土に残るので、その場所は何年も使わない |
| べと病 | 葉が黄色くなり裏に灰色のカビ。低温多湿(ネギ属の最大の制約) | 排水と通風の確保、株間15-20cm |
| 葉枯病、さび病、灰色かび病 | 葉先が枯れる / オレンジ色の粉の斑点 / 株元に灰色のカビ | 病葉を取って畑の外へ、株間を広げる、刈り取り後に1日乾かす |
| 軟腐病 | 株元が軟らかくなり悪臭(刈り取りの傷から細菌が侵入) | 雨の日の刈り取りを避ける |
| ネギバエ | 幼虫が地下部を食べて株がしおれて枯れる(春と秋、過湿) | 未熟な堆肥を入れず、排水を直す。木灰を株元にまく |
| ハモグリバエ、アブラムシ、アザミウマ | 葉の中のトンネルと白い筋 / 汁を吸いすす病 / 白い斑点 | 被害葉の除去とネット / 水で洗い流すか石けん水 / 乾燥させない、青色粘着トラップ |

&nbsp;&nbsp;&nbsp;病気の大半は過湿とつながっているので、薬を使わずにできる要点は、排水の確保(畝を高くして排水溝を深く)、株間15-20cm、刈り取り後1日の乾燥、病葉の除去です。そのほか、石けん水、木酢液300-500倍(予防)、防虫網(春と秋のハモグリバエ、ネギバエの成虫)を使います。

| 症状 | 原因と対処 |
|:---|:---|
| 葉全体が淡い緑色で細く短い | 窒素不足。尿の8-10倍希釈液を刈り取りの翌日に溝に与え、完熟堆肥を株の間にのせる |
| 葉が異様に大きく軟らかく、倒れやすい | 窒素過剰。肥料を止める(病気に弱くなった状態) |
| 古い葉の縁が褐色に焼ける | カリウム不足。木灰を1㎡に一つかみ二つかみ |
| 生育が遅く、葉が濃い緑で紫がかる | リン不足(低温期にも同じ症状)。骨粉、木灰 |
| 新しい葉がねじれて先が枯れる | カルシウム不足。貝殻と卵の殻を焼いて砕いた粉 |
| 春に葉が目立って細くなる、回を重ねるほど細くなる | 秋の刈りすぎ、カリウム不足、蓄積した窒素の収奪。10月下旬以降は刈らず、11月にカリウム、刈り取りのたびに追肥 |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | トマト・ナス・トウガラシ(ニラの根の分泌物が萎凋病と疫病を抑える)、イチゴ(根腐れの減少)、ニンジン(互いの害虫を追い払う)、レタス・ホウレンソウ(ニラの間の空き地を使い、争わない) |
| 悪い | マメ科作物(ダイズ、エンドウ、インゲンマメ: ネギ属の分泌物が根粒菌を抑える)、同じネギ属(長ネギ、ニンニク、タマネギ: 病原菌と害虫がたまる) |

&nbsp;&nbsp;&nbsp;ニラは連作への適応性がSSなので、輪作は必要ありません。更新するときは隣の区画に移し、菌核病が出た場所には5年以上ネギ属を植えません。よい場所は、水がたまらず、よく通る道筋で、毎年耕す区画の外側にあり、1日6時間以上日が当たる場所です(果菜類の畝の端なら間作の効果も兼ねます)。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 株分けで始めたなら、活着の1か月後、葉の長さ20-25cm(種から始めたなら翌春。1年目は刈らない)。以後は10-20日間隔で、野外で年に5-7回(春2-3回、夏1-2回、秋2回)。10月下旬に中止 |
| 刈る高さ | 最初の収穫は地面から3-4cm残して刈り、以後は回ごとに前回の切り口から1-1.5cmずつ上げて刈り、翌春にまた3-4cmに下げて始める |
| 要領 | よく切れるナイフかはさみで、1株をそろえて一度に切る(鈍い刃は切り口をつぶして病気が入る)。露が乾いた午前に行い、雨の日は避ける。刈った後1日は水と肥料をやらない。株元に土がつくので、裂いてすすぐ |

> **ニラの収穫で失敗するほぼ唯一のやり方は、短く刈りすぎることです。3-4cmを残さずに地面まで刈ると、成長点が切れて、次の葉が出ないか、大きく遅れます。**

| 採種 | 基準 |
|:---|:---|
| 方針 | 種子の寿命が1年未満なので、種を備蓄する戦略は成り立たない。ニラの種の倉庫は袋ではなく畑なので、生きた株を何か所かに分けて植えておく |
| 手順 | 3年目以上の健康な株を数株、別に決めて、その年は刈らずに花茎をそのまま置く(8-9月に開花)。さやが褐色に乾いて割れ、黒い種が見えたら(自然に落ちるので時期を逃さない)、花茎ごと切って逆さにつるし、こすって種を取り、ふるいや風でしいなを飛ばし、日陰で乾かして、密閉容器に灰や炭と一緒に入れて涼しく暗い場所に置く |
| 寿命 | 常温で密封して1年未満(翌春までが限界)、涼しく乾いた場所で1-2年、湿った場所や暑い場所では数か月で急激に落ちる。種に含まれる脂肪分が酸化しやすいため |

## 9. 貯蔵
| 方法 | 期間 | 条件 |
|:---|:---|:---|
| 畑に置く(貯蔵庫) | 4-10月の間ずっと | 刈らずに、必要な日に必要な分だけ刈る |
| 濡れた布に包んで涼しい場所 | 3-5日 | 貯蔵穴や土間の蔵ではもっともつ |
| 立てて根元を水に浸す | 2-3日 | 寝かせると葉が曲がって早く傷む |
| 乾燥 | 半年-1年 | 洗って水気を完全に切り、3-5cmに切り(丸ごと干すと中が乾かない)、日陰の風通しのよい場所でぱりぱりに崩れるまで乾かす。日なたで干すと色と香りが飛ぶ。密閉容器に灰や炭と一緒に保管 |

| 漬ける、発酵 | 方法 |
|:---|:---|
| ニラキムチ | 塩で漬けてしんなりさせてから唐辛子粉と和え、涼しい場所で1-2か月 |
| 塩漬け、チャンジ | 重さの5-10%の塩で層にして漬け、3-6か月。10%以上の濃い塩水に浸けておくと半年以上(食べる前に水に浸して塩気を抜く) |
| 漬け物 | しょうゆ漬け、みそ漬けは数か月。8月に摘んだ花茎のつぼみを塩水やしょうゆに漬けた花茎の漬け物も数か月 |

&nbsp;&nbsp;&nbsp;ニラの乾燥で最大の損失は香りです。

## 10. 調理と注意事項
| 方法 | 燃料 | 要領 |
|:---|:---|:---|
| 生食、即席の和え物 | なし | 洗ってそのまま和えるか、巻いて食べるものに添える。塩で軽く漬けてから和える。香りとビタミンCがそのまま残る |
| ゆでてナムル | 少ない | 熱湯で20-30秒(長くゆでると軟らかくなって香りが飛ぶ) |
| 汁物、鍋、チヂミ | 中程度 | 火を止める直前に入れる(長く煮ると香りが消える)。チヂミは小麦粉や穀粉の生地に混ぜて焼く |
| 炒め物、キムチ | 少ない、なし | 強火で1-2分(βカロテンとビタミンKは脂溶性なので、油があってこそ吸収される)。キムチは貯蔵と調理を兼ねる |

> **ニラの調理の原則はひとつです。できるだけ遅く入れ、できるだけ短く火を通します。ニラの香りは熱に弱く、長く煮ると、ニラを入れた理由がなくなります。**

&nbsp;&nbsp;&nbsp;通常の摂取量では安全ですが、食べすぎや空腹時の生食は、硫黄化合物が胃粘膜を刺激して、胸やけと下痢が出ることがあります。ビタミンKが多く、血液の凝固に関わり、ネギ属全体が犬・猫と家畜の一部に有毒なので、ペットが食べないようにします。

| 区分 | ネギ属(ニラ、ギョウジャニンニク、ノビル) | スズラン | スイセン・ヒガンバナ類 |
|:---|:---|:---|:---|
| 切った葉のにおい | ネギやニンニクのにおいが必ずする | においがない | においがないか、草のにおいだけ |
| 葉 | 薄くて柔らかく、根元で数枚が重なって葉鞘をなす。平行脈がはっきりしない | 厚くて硬く、艶がある。2枚が向かい合って抱き合うように立ち上がる | 厚くてなめらか。平たい葉が重なって出る |
| 食べたとき | 食用 | 嘔吐、めまい、心拍の異常 | ひどい嘔吐と腹痛、下痢 |

> **葉を1枚切ってこすり、においをかいで、ネギやニンニクのにおいがしなければ、ネギ属ではありません。この確認ひとつで、ネギ属に似た毒草がほとんどふるい落とされます。**

&nbsp;&nbsp;&nbsp;畑で育てたニラには、この危険はありません。

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 根の状態で越冬中。覆いを確認し、場所を踏まないようにする |
| 3月 | 覆いを取って枯れ葉を片づける。窒素中心に最初の肥料。株分けの適期 |
| 4-5月 | 最初の収穫は地面から3-4cm残して刈る(刈った1日後に肥料と水)。5月に2回目、3回目の収穫で、回ごとに1-1.5cmずつ上げて刈る。刈り取りのたびに追肥 |
| 6-7月 | 収穫を続ける。梅雨前に排水溝を整備。7月の高温期は葉が硬くなるので、火を通して食べるかキムチにする |
| 8-9月 | 花茎が上がったら7-10日間隔で取り除き、つぼみは収穫して食べる(採種株は残す)。9月に秋の収穫を再開(品質が最もよい)、株分けの適期 |
| 10-12月 | 10月下旬に最後の収穫を終え、採種用の花茎が乾いたら種を採る。11月にカリウム中心の越冬肥料。12月に枯れ葉を覆いとして置くかわらをかぶせ、貯蔵したキムチでしのぐ |

> **忘れてはならない5つのこと: 種より生きた株を手に入れる、地面から3-4cm残して刈る、8月の花茎の除去、10月下旬に刈るのをやめて11月にカリウム、水がたまらない場所。**
