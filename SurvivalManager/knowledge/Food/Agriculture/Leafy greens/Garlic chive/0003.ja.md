## 2. どんな植物か

### 2-1. 分類と原産地

| 項目 | 内容 |
|---|---|
| 学名 | Allium tuberosum |
| 分類 | クサスギカズラ目ヒガンバナ科ネギ属 |
| 別名 | チョングジ、ソル、チョル、プチェ、クチェ（韭菜） |
| 原産地 | 中国北部から東北アジア |
| 生活形 | 宿根性の多年草。地上部は冬に枯れ、根が越冬する |
| 繁殖 | 種と株分けのどちらも可能。実際には株分けが中心 |

&nbsp;&nbsp;&nbsp;ネギ属はネギ、ニンニク、タマネギ、ワケギ、ノビル、ギョウジャニンニクをすべて含む大きな仲間です。この仲間を一つにまとめるのは硫黄を含む特有のにおい成分であり、その成分はもともと植物が自分をかじる虫や菌から身を守るために作った化学兵器です。組織が傷を受けると酵素が働いてにおい成分が作られ、それが微生物の増殖を防ぎます。ニラを切った瞬間ににおいが一気に立ち上がるのはこのためです。

&nbsp;&nbsp;&nbsp;この事実が栽培に与える意味は二つです。一つはニラ自体に病害虫が比較的少ないという点、もう一つはニラがあった場所の土にその分泌物が残り、次の作物の土壌病を抑えるという点です。評価表の非食用価値Dが害虫防除の項目一つで満たされているのは、この二番目の効果を指しています。

&nbsp;&nbsp;&nbsp;原産地が中国北部と東北アジアであるという事実は、ニラの耐寒性をそのまま説明します。冬に土が深く凍りつく地域で生き残るよう作られた植物であり、葉をそっくり捨てて根に退くという戦略がその答えでした。零下20℃に耐えるという評価表の値は特別な能力ではなく、故郷の条件です。

### 2-2. 形の特徴

| 器官 | 特徴 |
|---|---|
| 葉 | 平たい線形。長さ20-40cm、幅0.5-1cm。断面が平たいです |
| 地下部 | 短い鱗茎と横に伸びる短い地下茎。ここから新しい株が生まれます |
| 根 | ひげ根。深さ20cm以内に集まっています |
| 花 | 白い小さな花が傘の形に集まって咲きます。8月から9月 |
| 花茎 | 葉より太く硬く、中が詰まっています |
| 種子 | 黒く角ばった小さな種 |

&nbsp;&nbsp;&nbsp;葉が平たいという点が、長ネギとニラを分ける第一の基準です。長ネギの葉は中が空洞の円筒で、ニラの葉は中が詰まった平たい帯です。手で押してみればすぐに分かります。ニラの葉を切ると断面が線のように薄く、長ネギの葉を切ると丸い穴が見えます。

&nbsp;&nbsp;&nbsp;地下茎が横に伸びて新しい株を作るという点が、ニラ栽培のほぼすべてを決めます。一株植えるとその横に新しい株ができ、それがまた横に広がって数年後には一つの塊になります。この広がりが株分けの材料になり、同時に数年経つと株が密集しすぎて勢いが落ちる原因にもなります。後で出てくる株の更新が必要な理由がこれです。

### 2-3. ネギ属の仲間との区別

| 名前 | 学名 | 葉の断面 | 食べる部位 | 特徴 |
|---|---|---|---|---|
| ニラ | Allium tuberosum | 平たく中が詰まる | 葉、花茎 | 多年草。葉を繰り返し刈ります |
| 長ネギ | Allium fistulosum | 丸く中が空洞 | 軟白部、葉 | 二年草。土寄せで白い部分を作ります |
| ワケギ | Allium × wakegi | 丸く中が空洞 | 葉、鱗茎 | 種を結ばず鱗茎でのみ繁殖します |
| ノビル | Allium monanthum | 細く丸い | 葉、球根 | 野生。早春に出ます |
| ギョウジャニンニク | Allium microdictyon | 広く平たい | 葉 | 山地の自生。葉が手のひらほどあります |

&nbsp;&nbsp;&nbsp;この表が必要な理由は、災害時には畑ではなく山や野でネギ属の植物を探すことになる可能性が高いからです。ネギ属はすべて食べられ、どれを見つけても損はありません。ただ一つ注意すべきことがあり、14節で扱います。

### 2-4. 生育段階

| 段階 | 時期 | 何が起こるか | 主に必要なもの |
|---|---|---|---|
| 発芽・幼苗期 | 播種から4週 | 糸のように細い葉が一枚出ます。非常に遅いです | リン、少量の窒素 |
| 初期生育 | 4週から12週 | 葉数が増え地下茎が定着します | 窒素 |
| 分株拡大 | 定植後1年 | 横に新しい株ができて塊になります | 窒素、カリウム |
| 収穫期 | 2年目から | 4月から10月、10日から20日おきに葉を出します | 窒素、カリウム |
| 開花・結実期 | 8月から9月 | 花茎が上がり種ができます。株の勢いが落ちます | リン、カリウム |
| 越冬期 | 11月から翌年3月 | 地上部が枯れ、根が冬を越します | カリウム |

> **初年度のニラは収穫する年ではなく根を作る年です。初年度に欲を出して何度も刈ると株が定着できず、翌年の収量が大きく落ちます。**

&nbsp;&nbsp;&nbsp;種から始めたニラの初年度の成長は、じれったいほど遅いです。数か月経っても糸のように細い葉が数枚あるだけです。これはニラが地上部より地下部を先に作る順序で育つためです。目に見えないところで鱗茎と地下茎が育っており、それが完全に作られてから葉が太くなります。本格的な収穫は2年目からです。このじれったさが、ニラを災害の直前ではなく災害の前に植えておくべき作物にしています。

&nbsp;&nbsp;&nbsp;株分けで始めればこの順序を飛び越えます。すでに作られた地下茎と根を移し植えるので、活着した後すぐに葉を出します。これが評価表の自家採種SSが採種ではなく株分けを根拠にしている理由でもあります。

&nbsp;&nbsp;&nbsp;熱量の数値が22-46kcalまで開くのは、ネギ属の中に種が複数あり、季節によって組織の硬さが変わるためです。春に最初に刈った柔らかいニラは水分が多く熱量が低く、夏に育った太くて硬いニラは乾物量が多く高くなります。評価に使われた46kcalは高い方の値です。

&nbsp;&nbsp;&nbsp;最後の行の硫化化合物が、ニラをニラたらしめる成分です。この成分は組織が切られることで酵素の働きによって作られ、抗菌と抗酸化の作用をします。昔からニラを肝の野菜と呼び、体を温める食べ物として見なしてきたのも、この成分と無関係ではありません。ただし熱に弱く、長く加熱するとかなりの部分が飛んでしまいます。ニラを最後に入れて火を止める調理法が習わしとして定着したのには理由があります。

## 3. 栽培環境

### 3-1. 温度

| 区分 | 温度 | 結果 |
|---|:---:|---|
| 発芽最低 | 10℃ | これより下では発芽しません |
| 発芽適温 | 20℃前後 | 7-14日で発芽します。遅い方です |
| 生育適温 | 18-20℃ | 春と秋が最もよく育つ時期です |
| 生育可能範囲 | 5-30℃ | 幅25℃。温度適応幅SSの根拠 |
| 高温障害 | 25℃以上 | 葉が硬くなり繊維が増えます |
| 低温生育停止 | 5℃以下 | |
| 地上部枯死 | 初霜の頃 | 根は生きています |
| 根の越冬限界 | 零下20℃以下でも生存 | 耐寒性SSの根拠 |

&nbsp;&nbsp;&nbsp;ニラが最もよく育つ温度が18-20℃であるという点が、収穫のリズムを決めます。春の4月から6月、秋の9月から10月がその区間で、実際にこの二つの時期に収穫回数が集中します。真夏には育つものの、葉が硬くなり香りが粗くなります。

> **ニラが冬に姿を消すのは死ぬのではなく退くのです。地上部が枯れて茶色になっても、その場所を掘り返してはいけません。**

&nbsp;&nbsp;&nbsp;この点を知らずに冬に枯れたニラの場所を掘り返してしまい、翌年何も出てこないということがよくあります。畑に印を付けておくか、枯れた葉を刈らずにそのまま覆っておけば場所を失いません。枯れた葉を覆っておくことは根の周りを断熱する効果もあり、一石二鳥です。

### 3-2. 光

| 条件 | 相対収量 | 解釈 |
|---|:---:|---|
| 直射光終日 | 100% | これが基準です |
| 一日6時間以上 | ほぼ100% | 実用的な最低ラインです |
| 40%遮光 | 約86% | 信頼区間61-120%。日照Bの根拠 |
| 半日陰 | 収量減少、葉は柔らかくなる | 香りが弱まり色が薄くなります |

&nbsp;&nbsp;&nbsp;日照Bは、比較的日陰に強いという意味です。40%を遮っても収量は86%程度を維持します。スベリヒユが同じ条件で45%と半分に落ち込むのとは対照的です。この違いは配置に実用的な余地を与えます。塀の下や背の高い作物の北側のように終日日が当たらない場所にも、ニラを置くことができます。

&nbsp;&nbsp;&nbsp;ただし日陰で育ったニラは葉が柔らかく色が薄く、香りが弱いです。柔らかいものを得るという観点では利点ですが、ニラを植える理由が香りであることを考えると損でもあります。実際、軟白ニラと呼んで光を意図的に遮り黄色く育てる方式もあり、その場合は香りと辛味が減って柔らかくなります。

### 3-3. 水と土壌

| 項目 | 基準 | 備考 |
|---|---|---|
| 土性 | 排水の良い砂質土から埴土 | 土質を大きく選びません |
| 土壌酸度 | pH 6.0-6.5 | 6.3-6.5が最も良いです |
| 有機物 | 完熟堆肥をたっぷり | 多肥性の作物です |
| 排水 | 非常に重要 | 湿害に最も弱い作物の一つです |
| 灌水 | 総ET約500mm | 乾燥には比較的強いです |
| 畝の高さ | 15-20cm以上 | 排水の悪い土地では25cm |

> **ニラの栽培を失敗させる原因は、ほとんどいつも乾燥ではなく過湿です。梅雨時に水がたまる場所では、5年育てた株も数週間でそっくり姿を消します。**

&nbsp;&nbsp;&nbsp;ニラの根は深さ20cm以内に集まったひげ根で、この浅い根の層が水に浸かると酸素が絶たれます。ここにネギ属特有の事情が重なります。水に浸かって弱った地下部は菌核病と根腐病の標的になり、これらの病気は土の中で何年も生き残る菌なので、一度居着くとその区域全体が長い間使えなくなります。同じ場所で5年使う作物なので、病気が入ると損失は5年分になります。

&nbsp;&nbsp;&nbsp;そのため、ニラの場所を決めるときにまず見るべきは、その場所に雨が降った後に水がたまるかどうかです。畑の中で最も高く水はけの良い区域をニラに割り当てるのが正しく、この判断が5年を左右します。畝を高く作り排水路を深く掘る作業も最初の一度だけで済むので、その場所に関しては惜しまない方がよいです。

&nbsp;&nbsp;&nbsp;酸度の面ではpH 6.0-6.5、つまりほぼ中性を好みます。韓国の畑は雨が多く自然に酸性へ傾きやすいので、石灰があれば植える前に入れて矯正するのが有利です。石灰がなければ貝殻と卵の殻を焼いて砕いたもの、そして木灰で代えます。木灰はカリウムも一緒に与えるので、ニラに特に合います。
