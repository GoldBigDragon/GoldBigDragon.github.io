## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

| 项目 | 内容 |
|---|---|
| 学名 | Allium tuberosum |
| 分类 | 天门冬目石蒜科葱属 |
| 别名 | jeongguji、sol、jol、buchae、gucai（韭菜） |
| 原产地 | 中国北部至东北亚 |
| 生活型 | 宿根多年生。地上部分冬季枯萎，根部越冬 |
| 繁殖方式 | 种子与分株均可，实际以分株为主 |

&nbsp;&nbsp;&nbsp;葱属是一个庞大的类群，涵盖大葱、大蒜、洋葱、分葱、野蒜、茖葱。将这一类群统一起来的是含硫的特有气味成分，这种成分原本是植物为抵御啃食自己的害虫和病菌而制造的化学武器。组织一旦受伤，酶就会发挥作用生成气味成分，从而抑制微生物繁殖。这就是为什么韭菜一被切开，气味会立刻冲出来。

&nbsp;&nbsp;&nbsp;这一事实对栽培有两点意义。一是韭菜本身病虫害相对较少；二是韭菜生长过的地方，土壤中会残留这种分泌物，从而抑制下一茬作物的土壤病害。评价表中非食用价值为D、仅凭防治害虫这一项撑起，指的正是第二种效果。

&nbsp;&nbsp;&nbsp;原产地是中国北部与东北亚这一事实，直接说明了韭菜的耐寒性。它是为了在冬季土壤深度冻结的地区存活而演化出来的植物，舍弃整片叶子退守根部就是它的应对策略。评价表中"能耐零下20℃"这个数值不是什么特殊能力，只是它故乡的条件。

### 2-2. 外观特征

| 器官 | 特征 |
|---|---|
| 叶 | 扁平线形。长20-40cm，宽0.5-1cm，横截面扁平 |
| 地下部分 | 短小的鳞茎与横向延伸的短地下茎，新株由此长出 |
| 根 | 须根，多集中在深度20cm以内 |
| 花 | 白色小花聚成伞状开放，花期为8月到9月 |
| 花茎 | 比叶粗硬，内部充实 |
| 种子 | 黑色带棱角的小种子 |

&nbsp;&nbsp;&nbsp;叶片扁平是区分大葱与韭菜的第一个标准。大葱的叶是中空的圆筒，韭菜的叶是内部充实的扁平带状。用手一按就能立刻分辨。切开韭菜叶，截面像一条线一样薄；切开大葱叶，则能看到一个圆孔。

&nbsp;&nbsp;&nbsp;地下茎横向延伸生出新株，这一点几乎决定了韭菜栽培的一切。种下一株后，旁边会长出新株，新株又继续向外扩展，数年后便结成一整片。这种扩展正是分株的材料来源，但同时，数年后株丛过于密集也会导致长势下降，这正是后面要讲的"更新分株"之所以必要的原因。

### 2-3. 与葱属其他成员的区别

| 名称 | 学名 | 叶横截面 | 食用部位 | 特征 |
|---|---|---|---|---|
| 韭菜 | Allium tuberosum | 扁平且内部充实 | 叶、花茎 | 多年生。反复割取叶片 |
| 大葱 | Allium fistulosum | 圆形且中空 | 软白部、叶 | 两年生。通过培土制作白色部分 |
| 分葱 | Allium × wakegi | 圆形且中空 | 叶、鳞茎 | 不结种，只能靠鳞茎繁殖 |
| 野蒜 | Allium monanthum | 细长且圆 | 叶、球根 | 野生。早春长出 |
| 茖葱 | Allium microdictyon | 宽而扁平 | 叶 | 野生于山地，叶片大如手掌 |

&nbsp;&nbsp;&nbsp;需要这份表格的原因是，在灾难情境下，很可能要到山野而非田地里去寻找葱属植物。葱属植物全部可以食用，找到任何一种都不算白费。但有一点需要留意，第14节会加以说明。

### 2-4. 生长阶段

| 阶段 | 时期 | 发生的变化 | 主要需求 |
|---|---|---|---|
| 发芽·幼苗期 | 播种后4周内 | 长出一片细如线的叶子，非常缓慢 | 磷，少量氮 |
| 初期生长 | 4周至12周 | 叶片数增加，地下茎开始定型 | 氮 |
| 分株扩展 | 定植后1年 | 旁侧长出新株，结成一片 | 氮、钾 |
| 收获期 | 第2年起 | 4月至10月，每隔10到20天长出新叶 | 氮、钾 |
| 开花结实期 | 8月至9月 | 花茎长出、结种，株势下降 | 磷、钾 |
| 越冬期 | 11月至翌年3月 | 地上部分枯死，根部过冬 | 钾 |

> **韭菜的第一年不是收获之年，而是长根之年。若第一年贪心多割几次，株就无法扎稳，来年产量会大幅下降。**

&nbsp;&nbsp;&nbsp;以种子起步的韭菜，第一年的生长慢得让人心焦。过了几个月，也只有几片细如线的叶子。这是因为韭菜的生长顺序是先长地下部分，后长地上部分。看不见的地方，鳞茎和地下茎正在生长，等它们完全长成之后，叶子才会变粗。真正的收获要从第2年开始。正是这种"慢"，让韭菜成为一种应该在灾难来临之前就种下、而不是灾难迫近才种的作物。

&nbsp;&nbsp;&nbsp;若以分株方式起步，就能跳过这个顺序。移栽的是已经长成的地下茎和根，扎根后便能立即长出叶子。这也是评价表中自家留种被评为SS、且依据不是留种而是分株的原因。

### 2-5. 每100g的营养成分

| 营养素 | 含量 | 备注 |
|---|:---:|---|
| 热量 | 22-46kcal | 因品种和季节而有差异 |
| 水分 | 88-92g | |
| 蛋白质 | 1.2-3.0g | 占热量的比例（P:E）为10.4% |
| 膳食纤维 | 约2.5g | 在叶菜类中属于较多的一类 |
| 钾 | 高 | 参与钠的排出 |
| 钙 | 高 | |
| 铁 | 高 | |
| 磷 | 高 | |
| 维生素A | 以β-胡萝卜素形式大量存在 | 与油脂同食吸收更好 |
| 维生素C | 大量 | 焯水后会损失一半以上 |
| 维生素K | 大量 | 参与凝血与骨骼健康 |
| 叶酸 | 大量 | |
| 硫胺素、核黄素 | 含有 | |
| 含硫化合物（蒜氨酸类） | 含有 | 气味与抗菌作用的来源 |

&nbsp;&nbsp;&nbsp;热量数值之所以在22-46kcal之间波动，是因为葱属内部品种多样，且组织的软硬程度随季节而变化。春天第一次割取的嫩韭菜水分多、热量低；夏天长成的粗韧韭菜干物质多、热量高。评价所用的46kcal取的是偏高的数值。

&nbsp;&nbsp;&nbsp;表格最后一行的含硫化合物，正是让韭菜成为韭菜的成分。这种成分是组织被切开时经酶作用生成的，具有抗菌和抗氧化的作用。自古以来把韭菜称为"补肝的蔬菜"、视其为暖身食物，也与这种成分不无关系。不过它不耐热，长时间加热会挥发掉相当一部分。韭菜最后放、随即关火的做法之所以成了惯例，是有道理的。

## 3. 栽培环境

### 3-1. 温度

| 区分 | 温度 | 结果 |
|---|:---:|---|
| 发芽最低温度 | 10℃ | 低于此温度不会发芽 |
| 发芽适温 | 20℃左右 | 7-14天发芽，偏慢 |
| 生长适温 | 18-20℃ | 春季与秋季长势最好 |
| 可生长范围 | 5-30℃ | 幅度25℃，是温度适应幅度SS的依据 |
| 高温障碍 | 25℃以上 | 叶片变硬，纤维增多 |
| 低温生长停止 | 5℃以下 | |
| 地上部分枯死 | 初霜前后 | 根部仍存活 |
| 根部越冬极限 | 零下20℃以下仍可存活 | 是耐寒性SS的依据 |

&nbsp;&nbsp;&nbsp;韭菜生长最适宜的温度是18-20℃，这决定了收获的节律。春季4月到6月、秋季9月到10月正处在这个区间，实际收获次数也集中在这两个时期。盛夏虽然也能生长，但叶片会变硬、香气变粗糙。

> **韭菜在冬天消失，不是死亡，而是撤退。即便地上部分枯萎变成褐色，也不能把那块地翻掘掉。**

&nbsp;&nbsp;&nbsp;不知道这一点、在冬天把枯萎的韭菜地翻掘掉，结果来年什么都不长，这种情况并不少见。在地里做个标记，或者不割枯叶、直接留着盖住，就不会失去那块地。留着枯叶盖住还能起到给根部隔热的效果，可谓一举两得。

### 3-2. 光照

| 条件 | 相对产量 | 解读 |
|---|:---:|---|
| 全天直射光 | 100% | 以此为基准 |
| 每天6小时以上 | 接近100% | 实用的最低标准 |
| 40%遮光 | 约86% | 置信区间61-120%，是光照B的依据 |
| 半阴处 | 产量下降，叶片变嫩 | 香气变弱，颜色变浅 |

&nbsp;&nbsp;&nbsp;光照B意味着韭菜相对耐阴。即便遮光40%，产量仍能维持在86%左右。这与马齿苋在同样条件下产量减半（45%）形成对照。这一差异为田地布局带来了实用的余地。像墙根下，或高株作物的北侧那种整天照不到太阳的地方，也可以用来种韭菜。

&nbsp;&nbsp;&nbsp;不过阴处长成的韭菜叶片较嫩、颜色较浅、香气较弱。从获得柔嫩口感的角度看是优点，但考虑到种韭菜正是为了那股香气，这也算是一种损失。实际上还有一种"软白韭菜"的做法，就是故意遮光把它养得发黄，此时香气与辛辣味都会减弱，口感变得柔和。

### 3-3. 水分与土壤

| 项目 | 标准 | 备注 |
|---|---|---|
| 土质 | 排水良好的砂质土至壤土 | 对土质要求不严 |
| 土壤酸度 | pH 6.0-6.5 | 6.3-6.5最为理想 |
| 有机质 | 充足的完熟堆肥 | 属于喜肥作物 |
| 排水 | 极其重要 | 是最怕涝的作物之一 |
| 灌溉 | 总ET约500mm | 相对耐旱 |
| 垄高 | 15-20cm以上 | 排水不良的地块需25cm |

> **毁掉韭菜地的原因几乎总是积水而不是干旱。梅雨季节积水的地方，种了5年的韭菜株也可能在几周内彻底消失。**

&nbsp;&nbsp;&nbsp;韭菜的根是集中在深度20cm以内的须根，这层浅根一旦泡水就会缺氧。再叠加上葱属特有的问题：泡水后虚弱的地下部分会成为菌核病和根腐病的目标，而这些病菌能在土壤中存活多年，一旦扎根，那片区域就会长期无法再用。由于是要在同一块地用5年的作物，病害一旦入侵，损失就是5年的份量。

&nbsp;&nbsp;&nbsp;因此，选定韭菜种植地时首先要看的，是下雨之后那块地会不会积水。应该把地里最高、排水最好的区域留给韭菜，这个判断会左右接下来的5年。起高垄、挖深排水沟这类工作也只需在最初做一次，因此在这块地上不必省力气。

&nbsp;&nbsp;&nbsp;在酸度方面，韭菜偏好pH 6.0-6.5，接近中性。韩国的地由于雨水多，容易自然偏向酸性，如果有石灰，最好在种植前加入调节。没有石灰的话，可以用烧过磨碎的贝壳和蛋壳，或者草木灰来代替。草木灰还能同时提供钾，因此特别适合韭菜。
