## 4. 品種

### 4-1. 系統別の特徴

| 系統 | 葉 | 耐寒性 | 収量 | 災害適合性 |
|---|---|:---:|:---:|---|
| 大葉種（幅広ニラ） | 広くて厚いです | 普通 | 多い | 一度に収穫できる量が多く、下処理が簡単です |
| 在来種（小葉種、朝鮮ニラ） | 狭く香りが濃いです | 強い | 中程度 | 露地適応力が最も良く、越冬も確実です |

| 品種 | 特徴 | 収量 | 適合環境 |
|---|---|:---:|---|
| 台湾ニラ | 分げつが盛んで病気に強いです | 多い | 露地と施設のどちらも |
| モンゴルニラ | 耐寒性が特に強いです | 中程度 | 寒い地域 |
| 在来種（朝鮮ニラ） | 香りが濃く越冬も確実です | 中程度 | 韓国全土 |
| 満州ニラ | 休眠が深く収穫間隔が長いです | 中程度 | 露地 |

&nbsp;&nbsp;&nbsp;ニラの品種区分は、他の野菜ほど明確ではありません。長い間、種を売り買いする作物ではなく、近所から株をもらって植える作物だったためです。ある村で何十年も回ってきた系統がその地域の名前を掲げている場合が多く、その系統はすでにその地域の気候に合うようふるいにかけられたものです。

&nbsp;&nbsp;&nbsp;休眠という概念について押さえておきます。ニラは冬に地上部を捨てて根だけが残りますが、このときどれだけ深く眠るかは系統によって異なります。休眠が深い満州ニラ系統は春に遅く目覚め、一度目覚めた後も再生が遅いです。代わりに冬の寒さにはより安全です。休眠が浅い台湾ニラ系統は春に早く出て再生も速いですが、暖かい冬に中途半端に目覚めた後、再び寒さに見舞われて傷むこともあります。

### 4-2. 状況別の選択基準

| 状況 | 選択 | 理由 |
|---|---|---|
| 近所や付近にニラがある | その株を分けてもらう | その地域にすでに適応した系統で、初年度から収穫できます |
| 収穫量を増やしたい | 台湾ニラ、大葉種 | 分げつが盛んで葉が広いです |
| 韓国中部以北、寒い地域 | モンゴルニラ、在来種 | 休眠が深く越冬が確実です |
| 香りと味を重視 | 在来種 | 硫化化合物含量が高く香りが濃いです |
| 早春にいち早く収穫したい | 台湾ニラ | 休眠が浅く早く目覚めます |
| 種しかない | どの系統でも | ただし初年度は収穫をあきらめ根を作ります |

> **ニラにおいて品種選択よりずっと重要なのは、種ではなく生きた株を手に入れることです。種子寿命が1年未満なので、蓄えておいた種は災害が来たときにはすでに死んでいる可能性が高いです。**

&nbsp;&nbsp;&nbsp;この言葉が意味するところは明確です。ニラは災害が始まった後に確保する作物ではなく、その前に植えておく作物です。一坪でも場所を割いて株を生かしておけば、その株は毎年増え、数年後には分けて植えられるほどになります。種の袋十個より、畑に生きているニラ一区画のほうが確実です。

## 5. 畑の準備と肥料

### 5-1. 畑作り

| 項目 | 基準 | 備考 |
|---|---|---|
| 耕す深さ | 20-30cm | 5年使う場所なので最初に深く耕します |
| 畝の高さ | 15-20cm | 排水の悪い土地では25cm以上 |
| 畝の幅 | 90-120cm | 二、三列植えを基準にしています |
| 排水路 | 必ず確保 | 湿害が最大の失敗原因です |
| 酸度矯正 | pH 6.0-6.5を目標 | 植える2-3週間前にあらかじめ入れます |
| 石と根 | あらかじめ取り除きます | 5年間掘り返さない場所です |

&nbsp;&nbsp;&nbsp;ニラの畑準備が他の作物と違う点は、この作業を5年に一度しか行わないということです。評価表の整地・掘削エネルギーAはこの事実から出ています。代わりに、その一度をおろそかにすると5年間苦労します。多年生作物の畑準備は一年の農作業ではなく数年間の基盤を作る仕事なので、労働を惜しまない方が結果的に得になります。

&nbsp;&nbsp;&nbsp;特に多年生雑草の根を取り除く作業が重要です。スギナやヒルガオのように根で広がる草がニラ畑の中に入り込むと、ニラの株の間に絡みついて抜き取る方法がなくなります。ニラは5年間畑を耕さないため、雑草を土に埋めて処分する機会がなく、そのため最初にきれいにしておくことが特に価値を持ちます。

### 5-2. 施肥量

&nbsp;&nbsp;&nbsp;ニラは多肥性の作物です。生育期間が長く、一年に五、六回も葉を刈り取るため、畑から出ていく養分が多いです。評価表の施肥等級Bは、NとPとKを合わせて1㎡当たり約24g必要という値から出ています。

| 成分 | 1,000㎡当たり | 1㎡当たり | 備考 |
|---|:---:|:---:|---|
| 窒素（N） | 20-25kg | 20-25g | 元肥と追肥に分けます |
| リン酸（P） | 12-15kg | 12-15g | 全量元肥 |
| カリウム（K） | 15-20kg | 15-20g | 元肥と追肥に分けます |
| 堆肥 | 1,500-2,000kg | 1.5-2kg | 完熟堆肥 |
| 石灰 | 100-150kg | 100-150g | 酸性土矯正用 |

| 区分 | 時期 | 内容 |
|---|---|---|
| 元肥 | 植え付け1-2週間前 | 堆肥全量、リン酸全量、窒素とカリウムの半分 |
| 追肥 | 刈り取るたびに | 窒素とカリウム中心 |
| 越冬前 | 11月 | カリウム中心 |
| 春の芽出し時 | 3月 | 窒素中心 |

&nbsp;&nbsp;&nbsp;刈り取るたびに追肥を入れるということが、ニラの施肥の要です。葉を刈るという行為は畑から窒素を持ち出す行為であり、回を重ねるほどこの搬出が積み重なります。補充せずに刈り続けると、三回目、四回目の刈り取り分から葉が細くなり色が薄くなります。評価表の無合成投入での収量維持率C、40.8%という値が意味するのはこの現象です。

&nbsp;&nbsp;&nbsp;11月にカリウム中心で入れることにも理由があります。カリウムは細胞内の浸透圧を高めて凝固点を下げ、細胞壁を厚くします。人がキムジャン（越冬用キムチ漬け）を準備するように、植物が冬を準備するために必要な成分であり、これが不足すると耐寒性が実際に落ちます。零下20℃に耐える能力は生まれつきのものですが、その能力が十分に発揮されるには秋にカリウムがなければなりません。

### 5-3. 災害時の代替肥料

&nbsp;&nbsp;&nbsp;化学肥料が絶たれると、ニラで最初に表れるのは葉の太さです。細くなり、短くなり、色が薄くなります。同じ場所で5年収穫する作物なので、還す循環を作らなければ年を追うごとに悪化します。

| 代替資源 | 供給成分 | 使い方 | 注意 |
|---|---|---|---|
| 人の尿 | 窒素（主）、カリウム、リン酸 | 水で8-10倍に希釈し、刈り取り直後に畝間に注ぎます | 葉に触れると焼けます。切り口が乾くまで一日待ちます |
| 完熟堆肥 | 窒素、リン酸、カリウム、有機物 | 元肥にたっぷりと。追肥は株の間に置きます | 未熟な堆肥は根食いバエを呼びます |
| 木灰 | カリウム、カルシウム、リン酸 | 刈り取り後1㎡に一、二握り | アルカリ性です。ニラが好む中性に近づけてくれます |
| 油かす | 窒素、リン酸 | 刈り取り後、株の間に振るか、発酵させた液を使います | そのまま振ると発酵熱で根が傷みます |
| 骨粉 | リン酸、カルシウム | 焼いて砕き元肥に混ぜます | 効果はゆっくり現れます |
| 草液肥 | 窒素、カリウム | 刈った草を水に浸け2-3週間発酵させた後5倍に希釈 | においが強いです |
| 貝殻・卵の殻 | カルシウム | 焼いて砕き酸度矯正に使います | 石灰の代用です |
| マメ科の前作 | 窒素 | ニラを植える前年に豆を育てて残渣を埋め込みます | 5年使う場所なので植える前が唯一の機会です |

&nbsp;&nbsp;&nbsp;最後の行に注目します。ニラを植えた後はその場所を5年間掘り返さないので、緑肥をすき込んだり前作を使ったりする機会は植える前の一度しかありません。そのため、ニラの場所を決めたなら、その前年に大豆やエンドウを育てて根粒で窒素を残しておき、その残渣を埋め込んだ後にニラを植えるという順序が合理的です。こうして蓄えた窒素が5年間かけて少しずつ放出されます。

&nbsp;&nbsp;&nbsp;木灰がニラに特に合うという点も押さえておきます。ニラはpH 6.0-6.5を好み、韓国の畑の土はおおむねそれより酸性です。木灰はアルカリ性なので、酸度を上げつつ同時にカリウムを与えます。刈り取った後、切り口に灰をまき散らせば、傷口の殺菌効果まで得られます。ただし一度にたくさん入れるとホウ素と鉄の吸収が妨げられるので、1㎡に一、二握り、一年に三、四回を超えない線を守ります。

## 6. 植え付け - 種と株分け

### 6-1. 時期

| 繁殖方法 | 植える時期 | 初収穫 | 備考 |
|---|---|---|---|
| 種の播種（春） | 3月中旬から4月初め | 翌年の春 | 初年度は根を作る年です |
| 種の播種（秋） | 8月中旬から9月初め | 翌年の春 | 幼い状態で越冬します |
| 苗の移植 | 5月から6月中旬 | その年の秋または翌年の春 | 梅雨前に終えます |
| 株分け | 3月から6月、または9月 | 活着後1か月 | 最も速く確実です |

> **株分けがニラを始める際の定石です。種から始めると初収穫まで1年かかり、株から始めれば1か月で済みます。**

&nbsp;&nbsp;&nbsp;この違いが災害時には決定的です。近くのどこかにニラがあれば、それを掘り出して分けて植える方が、種をまくより十倍ほど速いです。ニラは非常に広く行き渡った作物で、評価表の韓国国内普及度SSがその事実を物語っています。放置された家庭菜園、空き家の庭、田んぼのあぜ、畑の縁にニラの株が残っている場合がよくあります。冬は地上部が枯れて見えませんが、春になれば現れます。

### 6-2. 株分け

| 項目 | 基準 |
|---|---|
| 掘り出す時期 | 3-4月に新芽が上がる頃、または9月 |
| 掘り出し方 | シャベルで根の周りを広く掘り、丸ごと取り出します |
| 分ける単位 | 3-5株ずつ一塊 |
| 葉の整理 | 地上部を10cmほど残して切ります |
| 根の整理 | 長すぎる根の先を少し整えます |
| 植える深さ | 5-8cm。生長点が土に埋まらないようにします |
| 条間 | 20cm |
| 株間 | 15-20cm |
| 植えた後 | 土を押さえ、水をたっぷり与えます |

&nbsp;&nbsp;&nbsp;地上部を切ってから植える理由があります。移し植えると根が切れて水を吸い上げる能力が大きく落ちますが、その状態で葉がそのまま残っていると、葉から出る水分が入ってくる水分より多くなり株が枯れてしまいます。葉を減らせばこの均衡が取れます。木を移植するときに枝を切り落とすのと同じ原理です。

&nbsp;&nbsp;&nbsp;生長点を埋めないようにすることも重要です。ニラの生長点は鱗茎の上側、葉が出始める地点にあります。この部分が土に深く埋まると、新しい葉が土を突き破るのに力を使うか、そのまま腐ってしまいます。根は埋めて、生長点は土の表面と揃える高さにするのが基準です。

&nbsp;&nbsp;&nbsp;3-5株ずつまとめて植える理由は、ニラが塊で育つ植物だからです。一株ずつ別々に植えると定着に時間がかかり、複数の株が一緒にあると互いに支え合って速く勢いを作ります。この塊が育ち、数年後に再び分ける材料になります。

### 6-3. 種の播種

| 項目 | 基準 |
|---|---|
| 播種の深さ | 0.5-1cm |
| 発芽日数 | 20℃で7-14日 |
| 発芽温度 | 20℃前後。10℃以下では発芽しません |
| 条間 | 20cm |
| 1穴当たり | 2-3粒 |
| 1回目の間引き | 本葉2-3枚、間隔5cm |
| 2回目の間引き | 本葉4-5枚、最終間隔15-20cm |
| 初年度の管理 | 刈らずに育てます |

&nbsp;&nbsp;&nbsp;ニラの種は発芽が遅くばらつきます。播種して二週間経っても何も出てこず、失敗したと思って再び種をまくことがよくありますが、たいていはまだ出てくる途中です。表土が乾かないよう保ちながら、3週間までは待ちます。

&nbsp;&nbsp;&nbsp;種の鮮度が決定的であるという点も記憶しておきます。種子寿命Dが示すとおり、ニラの種は常温で1年を持ちません。前年に採った種は発芽率が大きく落ち、2年経った種はほとんど出ません。種から始めるしかない場合は、その年に採ったもの、あるいはその年に手に入れたものを使う必要があります。

### 6-4. 種子処理

| 方法 | 手順 | 効果 |
|---|---|---|
| 温湯浸漬 | 50-55℃の水に10-15分浸けた後、冷水で冷やします | 表面の病原菌を殺します |
| 灰まぶし | 濡れた種にふるった木灰をまぶします | 表面の消毒も兼ねます |
| 水浸け | 常温の水にひと晩 | 発芽が数日早まります |

&nbsp;&nbsp;&nbsp;温湯浸漬は温度がすべてです。60℃を超えると種が死に、45℃より低いと殺菌になりません。温度計がなければ、沸騰した湯と冷水をおおよそ半分ずつ混ぜ、手を浸けたときに熱いが我慢できる程度が50℃前後です。ただし感覚だけで行う処理は種を全部失う危険があるので、持っている種の一部だけを処理して分けて植える方が安全です。

## 7. 水管理

### 7-1. 生育段階別の水管理

| 時期 | 管理 | 備考 |
|---|---|---|
| 植えた直後 | たっぷり一度 | 根と土を密着させます |
| 活着期（2-3週間） | 表土が乾いたら | 根が定着する時期です |
| 生育期 | 週1-2回、一度に深く | 浅く頻繁な灌水は根を浅くします |
| 刈り取り直後 | 一日後に一度 | 切り口が乾いてから与えます |
| 梅雨時 | 与えません | 排水路の整備がこの時期の水管理です |
| 越冬期 | 与えません | 濡れた土が凍ると根が傷みます |

&nbsp;&nbsp;&nbsp;刈り取り直後にすぐ水をやらない理由があります。葉を刈った跡は開いた傷であり、その傷から水と一緒に菌が入り込みます。菌核病と軟腐病が刈り取り直後に多く発生するのはこのためです。一日ほど置いて傷口が乾いて塞がった後に水や肥料を与えるのが安全です。雨の日の刈り取りを避けるのも同じ理由です。

### 7-2. 水不足と過剰の症状

| 症状 | 原因 | 何が起こるか |
|---|---|---|
| 葉先が枯れて細くなる | 水不足 | 回復はしますが、その葉は元には戻りません |
| 葉が短く硬い | 持続的な水不足 | 繊維が増えて食感が悪くなります |
| 葉が突然黄色くなり倒れる | 過湿、根腐れ | 地下部がすでに傷んでいる状態です |
| 株元に白いカビと黒い粒 | 菌核病 | 土の中に菌核が残り何年も続きます |
| 葉の根元が柔らかくなり臭う | 軟腐病 | 刈り取りの傷から菌が入った場合です |
| 根の付近に小さな白い幼虫 | 根食いバエ | 未熟な堆肥と過湿が原因です |

&nbsp;&nbsp;&nbsp;この表の下の四行がすべて過湿につながっているという点が、ニラの水管理の性格を物語っています。水が足りなければ葉が小さくなるだけですが、水が過剰になれば株そのものが丸ごと消えてしまいます。損害の大きさが非対称です。そのためニラでは常に乾いた側に管理を傾けるのが安全であり、これが他の葉菜類と異なる点です。

### 7-3. マルチング

&nbsp;&nbsp;&nbsp;ビニールがない状況でのマルチング材料は、藁、乾草、落ち葉、もみ殻です。ニラにおいてマルチングは、夏と冬でそれぞれ異なる役割を果たします。

&nbsp;&nbsp;&nbsp;夏のマルチングは雑草抑制が主な目的です。ニラは5年間畑を耕さないので雑草が積み重なり続け、ニラの株の間に生えた草は根が絡んで抜くのが難しくなります。株の間の畝間を藁で覆っておくと、この問題は大きく減ります。ただしニラの株の上を覆うと通風が悪くなり病気を招くので、畝間だけに敷くべきです。

&nbsp;&nbsp;&nbsp;冬のマルチングは断熱が目的です。11月に地上部が枯れたら、その枯れ葉を刈らずにそのまま残すか、藁と落ち葉を5-10cmの厚さで覆います。零下20度に耐える作物なので死にはしませんが、凍結と融解を繰り返すと土が持ち上がり、根が地表に押し上げられる凍上害が起こります。覆いがこれを防ぎます。春に新芽が上がる前に取り除けば、地温が早く上がり収穫が数日早まります。
