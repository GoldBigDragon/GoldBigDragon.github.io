## 8. 栽培管理——花茎与更新分株

### 8-1. 摘除花茎

| 项目 | 内容 |
|---|---|
| 时期 | 8月前后，花茎开始抽出时 |
| 辨认 | 比叶片粗壮坚实、内部充实的茎挺直立起 |
| 方法 | 每隔7-10天，看到就从基部折断或剪掉 |
| 原因 | 养分集中到开花结籽上，导致株势下降 |
| 例外 | 留种用的株另行选定保留 |

&nbsp;&nbsp;&nbsp;植物开花意味着进入了生殖阶段。从那时起，积累在根和叶中的养分会转向花和种子。从人的角度看，这相当于本该用来长出可食叶片的资源流向了种子；若放任开花结籽直到成熟，当年剩下的收成几乎就没有了。根的势力也会随之下降，影响会延续到来年春天。

> **错过8月的花茎清除，当年秋季收获与来年春季收获会一起减少。在韭菜管理中，误时造成损失最大的作业就是这一项。**

&nbsp;&nbsp;&nbsp;不过剪下的花茎不必丢弃。韭菜花茎在花还未开、仍是花蕾状态时是很好的蔬菜。它口感脆嫩、带甜味，可用于炒菜和酱菜，耐储性也比叶片更好。清除作业本身就相当于多收了一次。花一旦开成白色，茎就会变韧难吃，所以窍门是在花蕾还合拢时采收。

### 8-2. 更新分株

| 项目 | 内容 |
|---|---|
| 周期 | 每3-4年 |
| 时期 | 早春（3-4月）或秋季（9月） |
| 信号 | 叶片变细，株丛变密，中心开始出现空心 |
| 方法 | 将整丛挖出，每3-5株分成一份，重新栽种到新位置 |
| 位置 | 尽可能换到别的区域 |

&nbsp;&nbsp;&nbsp;评价中"韭菜在同一位置能维持5年以上"与管理指南中"每3-4年更新一次"看似矛盾，实际上说的是同一件事。韭菜不会死，会持续存活，但随着时间推移势力会下降。地下茎向旁边扩展，株数不断增多，而这些株一直在同一丛内增多，最终会彼此争夺空间。密度升高后，单株获得的养分和光照减少，叶片就会变细。

&nbsp;&nbsp;&nbsp;与此同时，地下茎每年都会稍微往上移动一些。这是因为新长出的地下茎会长在原来的上面，几年后根部就会升到接近地表，直接暴露在冬天的寒冷和夏天的干旱之下。当韭菜地中间变空、呈现出甜甜圈状时，就说明到了该更新的时候。

&nbsp;&nbsp;&nbsp;更新不是损失，而是繁殖。挖出一丛分开后会变成三四丛，韭菜地也随之扩大。每3年经历一次这个过程，最初的一坪几年后就会变成好几坪。这是一种不靠种子扩大面积的方法，也是正面绕开"种子寿命D"这一弱点的途径。

| 轮次 | 时点 | 结果 |
|---|---|---|
| 首次栽种 | 0年 | 一丛 |
| 第1次更新 | 3-4年 | 三四丛 |
| 第2次更新 | 6-8年 | 十丛以上 |
| 第3次更新 | 9-12年 | 多到要为分栽地点发愁 |

### 8-3. 杂草管理

&nbsp;&nbsp;&nbsp;这是多年生作物的命运。因为没有翻耕的机会，杂草会一年年积累。尤其是钻进韭菜丛里的杂草，根系会与韭菜纠缠在一起，拔草时连韭菜也会被带出来。

| 方法 | 内容 |
|---|---|
| 种植前 | 彻底清除多年生杂草的根，这是唯一的根本对策 |
| 垄沟覆盖 | 用稻草和干草覆盖垄沟，阻止杂草发芽 |
| 刈割后 | 割叶后株丛变低，杂草容易看清 |
| 早春 | 在韭菜长出之前，先清除先长出的杂草 |
| 冬季 | 清理干叶时一并清除 |

&nbsp;&nbsp;&nbsp;"抓住刈割后"这一条很实用。平时韭菜叶茂密，看不清中间的杂草，但割完叶子后地面豁然显露，杂草一眼就能看到。剪割、拔草、施肥、放一天后再浇水，这个顺序就是韭菜地的基本作业流程。

### 8-4. 越冬管理

| 时期 | 作业 | 原因 |
|---|---|---|
| 10月下旬 | 结束最后一次刈割 | 需在初霜前3-4周停止刈割，养分才能积累到根部 |
| 11月 | 以钾为主追肥 | 提高耐寒性 |
| 11月下旬 | 地上部分枯死 | 这是自然过程 |
| 12月 | 保留枯叶或覆盖稻草 | 防止霜冻拱土和干燥 |
| 2月下旬-3月 | 撤去覆盖物 | 地温回升更快，收获提前 |

&nbsp;&nbsp;&nbsp;10月下旬停止刈割，决定着来年的收成。深秋割过的韭菜会动用根部储存的养分去长新叶，可新叶还没长成，霜就降下来把它冻死了。结果只是白白耗掉了储存的养分，什么也没留下。这样过冬后，来年春天长出的叶子会明显变细。

## 9. 病虫害——不用药的防治方法

### 9-1. 主要病害

| 病名 | 症状 | 条件 | 不用药的应对方法 |
|---|---|---|---|
| 菌核病 | 基部变软，出现白色菌丝和黑色颗粒（菌核） | 过湿、低温、通风不良 | 连土一起挖除病株。菌核会留在土中，因此该处多年不再使用 |
| 叶枯病 | 从叶尖开始变褐枯萎 | 通风不良、氮肥过多 | 清除病叶，拉大株间距离 |
| 锈病 | 叶片上出现橙色粉状斑点 | 晚夏多湿 | 清除病叶并带出田外 |
| 霜霉病 | 叶片发黄，背面有灰色霉层 | 低温多湿，春季和秋季 | 保证排水和通风。这是葱属最大的限制因素 |
| 灰霉病 | 灰色霉层长在叶片基部 | 过湿、伤口部位 | 刈割后晾一天再浇水 |
| 软腐病 | 基部变软并散发恶臭 | 细菌从刈割伤口侵入 | 避免在雨天刈割 |

&nbsp;&nbsp;&nbsp;评价表中防治自立度为B，这个数值是根据德国六篇有机洋葱实证文献评定的，其中霜霉病被指出是葱属作物最大的限制因素。数据显示，未防治对照组的发病严重度为96%，也就是说不防治的话几乎全部会染病。不过发病严重度并不等于减产。即便叶片受损，根仍能存活，来年会重新长出。这就是多年生作物的缓冲能力。

&nbsp;&nbsp;&nbsp;那些文献提出的应对方法也不是药剂。全部内容就是使用抗病品系、拉大种植间距使空气流通、以及保证排水。这三项在没有药剂的情况下也能做到，可以原样应用在灾害情境下的田地里。

### 9-2. 主要害虫

| 害虫 | 危害 | 时期 | 不用药的应对方法 |
|---|---|---|---|
| 韭蛆 | 幼虫蛀食地下部，导致株丛萎蔫死亡 | 春季和秋季、过湿时 | 不施未腐熟的堆肥，修好排水 |
| 潜叶蝇 | 在叶片内钻食形成白色条纹 | 春季、秋季 | 清除受害叶片，覆盖防虫网最为可靠 |
| 蚜虫 | 附着在叶片上吸食汁液，引发煤污病 | 春季、秋季 | 用水冲洗或喷洒肥皂水 |
| 蓟马 | 叶片出现白色斑点并呈银白色 | 高温干燥期 | 注意保湿管理，蓝色粘虫板有帮助 |
| 韭菜潜叶蛾 | 幼虫啃食叶片 | 夏季 | 徒手捕捉即可，对韭菜的危害不大 |

&nbsp;&nbsp;&nbsp;韭菜的害虫问题大体较轻，因为含硫化合物的气味本身就起到驱避作用。评价表中病虫害压力为B级，比羽衣甘蓝的C级高出一档，反映的正是这一情况。真正有实质危险的只有表格第一行这一项。

&nbsp;&nbsp;&nbsp;韭蛆之所以尤其危险，是因为危害在看不见的地方进行。等地上部分开始萎蔫时，地下部分往往已经被吃掉了相当一部分。而且这种虫子会把卵产在未腐熟的有机物里。在没有化肥、必须依赖堆肥的灾害情境下，这一点会变成实质性的风险。堆肥必须完全腐熟、不再发热并带有土壤气味时才能使用，并且要施在离株丛稍远而不是紧贴株丛的地方。

### 9-3. 不用药的防治方法

| 方法 | 制作方法与使用方法 | 对象 |
|---|---|---|
| 保证排水 | 加高垄台，深挖排水沟 | 菌核病、韭蛆、霜霉病 |
| 保证种植间距 | 株间保持15-20cm | 霜霉病、叶枯病、灰霉病 |
| 刈割后晾干 | 割后一天内不浇水不施肥 | 软腐病、灰霉病 |
| 清除病叶 | 带出田外烧毁或深埋 | 锈病、霜霉病 |
| 草木灰 | 刈割后撒在基部周围 | 韭蛆、基部腐烂、蛞蝓 |
| 肥皂水 | 在1L水中溶入几克肥皂后喷洒 | 蚜虫、蓟马 |
| 木醋液 | 稀释300-500倍后喷洒 | 用于预防 |
| 波尔多液 | 用硫酸铜和生石灰配制 | 锈病、霜霉病，仅在有材料时使用 |
| 防虫网 | 春秋两季覆盖 | 潜叶蝇、韭蛆成虫 |

&nbsp;&nbsp;&nbsp;这个表格里前四行是不用药剂就能做到的核心措施，涵盖了占韭菜病害绝大多数的湿气相关病害。即便没有配药的材料，这四项也随时都能做到，只要有铁铲和双手就够了。

&nbsp;&nbsp;&nbsp;草木灰对韭蛆有效，是因为成虫有在潮湿土面产卵的习性。在基部周围撒灰后，表面变得干燥且呈碱性，产卵会减少。它还兼具刈割后伤口的杀菌效果与钾肥供给的作用，因此草木灰是韭菜地里用处最多的资源。

### 9-4. 韭菜本身作为防治手段的情况

&nbsp;&nbsp;&nbsp;评价表中非食用价值为D，正是由"病虫害防治"这一项构成的。这意味着葱属植物分泌的含硫化合物能够抑制土壤中病原菌的繁殖。

&nbsp;&nbsp;&nbsp;在实际田间，这一效果被用在两个方向上。一是间作：长期以来的观察显示，在番茄、茄子、草莓等作物旁种韭菜，能减少枯萎病和疫病的发生。二是后作效应：韭菜被清除后的地块，因为多年来韭菜根系持续分泌物质，土壤病害密度已经降低，种在这块地上的作物会因此受益。第11节将讨论这种布局。

## 10. 营养缺乏与过量

| 症状 | 原因 | 用天然材料应对的措施 |
|---|---|---|
| 整叶浅绿、细而短 | 缺氮 | 刈割次日在垄沟中施用稀释8-10倍的尿液。在株间铺上完全腐熟的堆肥 |
| 叶片异常大、软而易倒伏 | 氮肥过量 | 停止施肥。此时植株抗病力已变弱 |
| 老叶边缘开始变褐焦枯 | 缺钾 | 每1㎡撒一两把草木灰 |
| 整体生长迟缓，叶色深绿带紫 | 缺磷 | 施骨粉与草木灰。低温期也会出现同样症状 |
| 新叶扭曲、叶尖枯萎 | 缺钙 | 将贝壳和蛋壳烧后捣碎施入 |
| 叶脉间发黄、只有叶脉保持绿色 | 缺镁 | 草木灰中含有镁。若有钙镁石灰可施用 |
| 过冬后春天叶片明显变细 | 秋季刈割过度或缺钾 | 10月下旬以后不再刈割，11月施钾肥 |
| 每收割一次叶片就变细一次 | 累积性氮素消耗 | 建立每次刈割后追肥的循环 |

&nbsp;&nbsp;&nbsp;最后两行是韭菜特有的项目。其他作物的缺素问题在一年之内出现并结束，但韭菜是多年生作物，一年管理不到位会延续到下一年。秋天过度刈割的后果会在来年春天显现，历经数年累积的氮素消耗会在第4年、第5年集中暴露出来。因为这是一种时间跨度长的作物，原因与症状之间的间隔也长。

&nbsp;&nbsp;&nbsp;因此，韭菜的养分管理不应是看到症状再补救，而应是提前建立"取走多少就补回多少"的循环。每次割叶后都补充一些东西的习惯，就是这种循环；即便能补的只有稀释尿液，也比什么都不补要好。

&nbsp;&nbsp;&nbsp;还要指出的是，第四行的缺磷症状容易与低温期症状混淆。早春地温低时，即使土壤中磷含量充足，根系也无法吸收，会出现相同的症状。气温回升后会自行恢复，所以3月出现的紫色大多只需耐心等待即可。

## 11. 间作与轮作

### 11-1. 搭配关系

| 搭配 | 作物 | 原因 |
|:---:|---|---|
| 良好 | 番茄、茄子、辣椒 | 韭菜根系分泌物能抑制枯萎病和疫病 |
| 良好 | 草莓 | 长期以来的观察显示能减少根腐病 |
| 良好 | 胡萝卜 | 彼此驱赶对方的害虫 |
| 良好 | 生菜、菠菜 | 利用韭菜间的空隙生长，互不争夺 |
| 不良 | 豆科作物（大豆、豌豆、菜豆） | 葱属分泌物会抑制根瘤菌 |
| 不良 | 同为葱属（大葱、大蒜、洋葱） | 病原菌与害虫会累积 |

&nbsp;&nbsp;&nbsp;第五行是特别实用的信息。葱属植物释放的含硫化合物不仅抑制病原菌，还会影响豆科作物根部的根瘤菌。豆类自身制造氮素的能力正是来自这种细菌，所以种在韭菜旁边的豆类不容易形成根瘤，固氮量会减少。在没有化肥的情况下，豆科作物的固氮是维持整片田地地力的支柱，因此避开这种组合不只是简单的搭配问题。

&nbsp;&nbsp;&nbsp;这看似与前面第5节"种韭菜前一年先种豆类"的说法矛盾，但其实不同。隔开时间前后安排是可以的，问题在于同一时期并排种植。收完豆类并将残茬翻入土中后再种韭菜，韭菜就能接收到那部分氮素。

### 11-2. 轮作

&nbsp;&nbsp;&nbsp;评价表中连作适应性为SS，因此就韭菜本身而言不需要轮作，在同一位置维持5年是正常的。但那5年结束之后，以及病害发生的情况下，就需要换地。

| 情况 | 应对 |
|---|---|
| 正常更新 | 每3-4年分栽一次，并移到旁边区域 |
| 发生过菌核病的地块 | 5年以上不再种植葱属作物 |
| 清除韭菜后的地块 | 土壤病害密度已降低，对下一茬作物有利 |

&nbsp;&nbsp;&nbsp;轮作顺序的一个例子是：种韭菜4年后，种一年豆科作物恢复氮素，接下来一年种叶菜或果菜，之后再重新引入韭菜。这样一来，一个区域轮回到韭菜的周期就是6-7年，足够让葱属土壤病害沉寂下来。

&nbsp;&nbsp;&nbsp;不过在实际灾害情境下的小块田地里，这种轮换往往很难做到。这时可以直接把韭菜区域固定下来，转而彻底做好排水和通风，防止病害进入。韭菜本身并不怕连作，只要不发病，在同一位置种上十年也没有问题。

### 11-3. 位置安排的实际考量

&nbsp;&nbsp;&nbsp;韭菜是多年生作物，会在田地的规划中成为一块固定区域。把这块区域放在哪里，会左右接下来好几年的情况，因此把标准整理如下。

| 标准 | 内容 |
|---|---|
| 不积水的地方 | 这是最优先的条件 |
| 经常经过的路口 | 这是要少量多次采收的作物，越近越好 |
| 每年翻耕区域之外 | 这是5年内不会翻耕的地方 |
| 每天6小时以上日照 | 不必整天都有阳光 |
| 果菜垄的边缘 | 兼具间作效果 |

&nbsp;&nbsp;&nbsp;第二行的重要性出乎意料。韭菜不是一次收获大量的作物，而是要经常拿一把用来煮一碗汤、煎一张饼的作物。如果种在田地最远的角落，每次为了这一把都要走一趟，结果就会用得越来越少。放在门口或靠近厨房的地方，能大幅提高实际使用量。
