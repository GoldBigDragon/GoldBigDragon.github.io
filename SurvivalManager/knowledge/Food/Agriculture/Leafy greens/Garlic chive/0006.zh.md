## 12. 收获——剪割高度决定一切

### 12-1. 收割时期判断

| 类别 | 标准 |
|---|---|
| 首次收获（种子育苗） | 种植后第二年春天。第一年不刈割 |
| 首次收获（分株） | 活株后一个月，叶长20-25cm |
| 之后的收获间隔 | 10-20天。按评价表标准为25-30天 |
| 年收获次数 | 露地栽培5-7次 |
| 季节分配 | 春季4-6月2-3次，夏季7-8月1-2次，秋季9-10月2次 |
| 收获终止 | 10月下旬。初霜前3-4周 |

&nbsp;&nbsp;&nbsp;叶长20-25cm是实用的标准。留得太久，叶尖会干枯、纤维增多变韧；割得太早，株丛没有喘息的时间，势力会下降。夏天生长速度快，十天就能达到这个长度，春秋两季则需要半个月到二十天。

&nbsp;&nbsp;&nbsp;夏季收获分配得比春秋两季少，不是因为长得不好，而是出于品质的考虑。超过25℃后，韭菜生长虽快，但纤维会变粗、香气也会变得粗糙刺鼻。这时割下的韭菜又韧又辣，生吃困难。夏天收的韭菜最好煮熟吃，或者做成泡菜和酱菜。

### 12-2. 剪割高度

| 轮次 | 剪割位置 |
|---|---|
| 首次收获 | 距地面留3-4cm剪割 |
| 第二次以后 | 在上次剪割位置上方1-1.5cm处 |
| 之后 | 每次上移1-1.5cm |
| 来年春天 | 重新回到距地面3-4cm处开始 |

> **韭菜收获中几乎唯一会失败的做法，就是割得太狠。不留3-4cm而直接割到地面，会切断生长点，导致下一轮叶片长不出来或严重延迟。**

&nbsp;&nbsp;&nbsp;韭菜的生长点位于靠近地面的基部。新叶就是在这个位置生成，再向上顶出。所以不管在生长点上方哪里剪，下一轮叶子都会继续长出；但如果把生长点本身剪掉，这株就失去了长出新叶的地方。3-4cm这个数字，就是在生长点上方安全保留的余量。

&nbsp;&nbsp;&nbsp;每次都把剪割高度提高一点，原因也在于此。割过的地方会留下变硬的叶鞘残端，如果再剪到那个变硬的部分，切口会变得粗糙，容易招病。而且如前所述，地下茎每年都会稍微往上移动，生长点也随之上移。每次上移1-1.5cm，正是跟随这个变化的方式。

&nbsp;&nbsp;&nbsp;这样一年不断上移下来，到秋天时剪割高度已经相当高了。冬天地上部分枯死，来年新叶又从基部重新长出，所以春天会回到最初的高度重新开始。这个一年一轮的周期，就是韭菜收获的节律。

### 12-3. 采收要领

| 项目 | 内容 |
|---|---|
| 工具 | 锋利的刀或剪刀。刀刃不利会把切口挤压变形 |
| 时间 | 露水干后的上午。避开雨天 |
| 剪割方向 | 一丛一次性整齐剪下 |
| 割后 | 一天内不浇水不施肥 |
| 清洗 | 基部容易夹带泥土，需掰开冲洗 |

&nbsp;&nbsp;&nbsp;使用锋利工具这一条，其实是卫生问题。用不利的刀剪割，切口会被撕裂挤压，留下较大的伤口，病菌和灰霉菌就会从这个伤口侵入。刈割后几天内基部变软腐烂的事故，大多就是从这里开始的。把工具磨利再用，效果比喷药更大。

&nbsp;&nbsp;&nbsp;避开雨天和露水未干的清晨，也是同样的原因。潮湿状态下形成的伤口不容易干燥，正好方便病菌落脚。

## 13. 留种——种子活不过一年的作物

### 13-1. 留种不如分株

&nbsp;&nbsp;&nbsp;评价表中自家留种为SS，种子寿命为D。这两个等级并列摆在一起，正说明了韭菜的繁殖策略：繁殖非常容易，而种子几乎无法保存。

| 方法 | 所需时间 | 保存可能性 | 实用性 |
|---|---|---|---|
| 分株 | 一个月后可收获 | 以活株形式保存 | 最为可靠 |
| 采种后次年播种 | 一年后收获 | 不足1年 | 必须在当年内用完 |
| 采种后保存数年 | 几乎不发芽 | 不可行 | 不能作为一种策略 |

> **韭菜的种子仓库不是纸袋，而是田地。对这种作物来说，储备的方式不是攒种子，而是把活株分开栽种到几个地方。**

&nbsp;&nbsp;&nbsp;不过这不代表采种毫无意义。种子体积小便于远距离携带，在需要跨越难以挖株搬运的距离时很有用。而且如果只靠反复分株，所有的株最终都会成为基因相同的同一个体，一旦新的病害传入，可能会以同样的方式全部倒下。用种子延续世代的话，每代都会有些许基因混合，这种风险就会降低。

### 13-2. 采种方法

| 步骤 | 内容 |
|---|---|
| 选留种株 | 另外选定几株3年以上健壮的株丛 |
| 管理 | 这些株当年不刈割，保留花茎 |
| 开花 | 8月至9月，白色花朵呈伞状开放 |
| 判断成熟 | 花凋落处的果荚变褐干枯并裂开，露出黑色种子时 |
| 收获 | 连花茎一起剪下，倒挂在纸或布上方 |
| 脱粒 | 用手搓揉干燥的花茎，抖落种子 |
| 精选 | 用筛子筛选或借风力吹去空壳 |
| 干燥 | 在阴凉处彻底晒干 |
| 保存 | 放入密闭容器，与灰或炭一起置于阴凉黑暗处 |

&nbsp;&nbsp;&nbsp;之所以要另外划定并管理留种株，是因为养分的关系。开花结籽消耗的养分不少，留种的株到来年势力会明显下降。如果想在同一株上又收获又留种，两者都会变差。在地里一角留出三四株专门用来留种、完全不刈割，是最干净的做法。

&nbsp;&nbsp;&nbsp;果荚干透后会自动裂开落籽，一旦错过时机种子就会散落在地上。在快要完全干透之前，连花茎一起剪下倒挂，是比较安全的做法，下面铺一块布，就能接住干燥过程中掉落的种子。

### 13-3. 保存与寿命

| 条件 | 发芽力保持 |
|---|---|
| 常温密闭 | 不足1年，到来年春天为极限 |
| 阴凉干燥处 | 1-2年 |
| 潮湿或炎热处 | 数月内急剧下降 |

&nbsp;&nbsp;&nbsp;葱属种子格外短命，据说是因为种子中所含的脂肪成分容易氧化。随着时间推移，这种成分发生变化，胚就会死亡。低温和低湿度能延缓氧化，所以应尽量放在阴凉干燥处，并在密闭容器中加入灰或炭来吸湿。

&nbsp;&nbsp;&nbsp;实用的结论只有一个：韭菜种子要在采收当年秋天或来年春天用掉。不要把韭菜列入为几年后准备的种子清单，而是让韭菜株一直活在地里，以此代替。

## 14. 毒性与需注意的成分

### 14-1. 韭菜本身的安全性

&nbsp;&nbsp;&nbsp;韭菜在一般食用量下是安全的食品，生吃或煮熟吃都可以。不过有两点值得了解。

| 项目 | 内容 |
|---|---|
| 过量食用 | 含硫化合物会刺激胃黏膜，可能引起烧心和腹泻 |
| 空腹生食 | 空腹大量生吃韭菜，刺激会更强 |
| 维生素K | 含量较高，参与血液凝固 |
| 狗和猫 | 整个葱属对宠物和部分家畜有毒 |

&nbsp;&nbsp;&nbsp;最后一行是灾害情境下真正需要注意的事项。韭菜、大葱、大蒜、洋葱等葱属植物会破坏狗和猫的红细胞，引起贫血。对人无害的成分，对这些动物却是毒素。在把剩饭喂给家畜或狗变得常见的情况下，含韭菜的食物必须排除在外。牛和马大量食用也可能出现同类型的贫血。

### 14-2. 相似的毒草——靠气味辨别

&nbsp;&nbsp;&nbsp;在山野而非田地寻找葱属植物时，只看叶子采摘会有危险。与韭菜、茖葱、野蒜相似的毒草确实存在，每年都有中毒事故的报告。

| 区分 | 葱属（韭菜、茖葱、野蒜） | 铃兰 | 水仙、忽地笑类 |
|---|---|---|---|
| 折断叶片的气味 | 一定带有葱蒜气味 | 没有气味 | 没有气味或只有草味 |
| 叶片基部 | 多片叠合形成叶鞘 | 两片相对包合而生 | 扁平的叶片层叠而生 |
| 叶片质感 | 薄而柔软 | 厚而挺硬，有光泽 | 厚而光滑 |
| 叶脉 | 平行脉不明显 | 平行脉明显 | 平行脉明显 |
| 地下部分 | 鳞茎或根茎 | 细根茎 | 圆形鳞茎（洋葱状） |
| 误食后果 | 可食用 | 呕吐、眩晕、心律异常 | 剧烈呕吐、腹痛、腹泻 |

> **剪下一片叶子搓揉后闻一闻，如果没有葱蒜气味，那就不是葱属植物。仅凭这一点确认，就能几乎筛除所有与葱属相似的毒草。**

&nbsp;&nbsp;&nbsp;铃兰尤其需要注意。它早春长出的叶子与茖葱非常相似，又生长在同样的山地，采野菜时混杂在一起的事故一直反复发生。铃兰所含的成分作用于心脏，会扰乱心律，少量也很危险。水仙和忽地笑类的鳞茎长得像洋葱或大蒜，挖球茎时容易认错而引发事故。

&nbsp;&nbsp;&nbsp;靠气味辨别之所以可靠，是因为让葱属之所以是葱属的成分，正是那种气味成分本身。揉搓或切断叶片时组织破裂、酶被激活，气味会立刻出现，这个反应没有例外。不过如果鼻塞或嗅觉失灵，就无法进行这项检验，这种情况下不进行野外采摘会更安全。

&nbsp;&nbsp;&nbsp;田地里种植的韭菜没有这种风险，因为知道种在哪里。不过如果在韭菜地边缘种了水仙或铃兰，春天可能会混杂在一起，所以不在韭菜种植区附近放置这类植物，是一个简单的预防办法。

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;耐储性E、常温下只能放2-3天，这是韭菜确实的弱点。不过这个弱点与永续性SS搭配后，很大程度上被抵消了，因为从4月到10月这七个月里，田地本身就充当了贮藏库。

### 15-1. 田地就是贮藏库

| 方法 | 期限 | 条件 |
|---|---|---|
| 不割留在地里 | 4月至10月全程 | 需要时按需割取 |
| 连根挖出埋入土中 | 数周 | 临时假植在阴凉处的土中 |
| 用湿布包好放阴凉处 | 3-5天 | 若有地窖或土窖能存放更久 |
| 竖放并将基部浸水 | 2-3天 | 平放会导致叶片弯曲，更快变坏 |

&nbsp;&nbsp;&nbsp;第四行有个小窍门。韭菜平放时叶片会想向上弯曲，这个力会消耗能量，组织也会更快崩解。竖放的话就不会出现这种反应，能多撑一两天。做法是把基部竖立放入陶罐或桶中，底部倒入少量水。

### 15-2. 干燥

| 步骤 | 内容 |
|---|---|
| 处理 | 洗净去土，充分沥干水分 |
| 切段 | 切成3-5cm长。整根晒干内部干不透 |
| 摆晒 | 通风良好的阴凉处。日晒会使颜色和香气散失 |
| 判断完成 | 用手搓揉至碎裂为止 |
| 保存 | 放入密闭容器，与灰或炭同放 |
| 期限 | 充分晒干并密封的可保存半年到一年 |

&nbsp;&nbsp;&nbsp;韭菜干燥过程中损失最大的是香气。作为气味来源的含硫化合物具有挥发性，干燥过程中大部分会散失。较准确的看法是把干韭菜视为与鲜韭菜不同的食材，其用途逐渐固定为放入汤中取其颜色和纤维。在阴凉处慢慢晒干可以减少一些损失，晒干后立即密封则能保住剩余的香气。

### 15-3. 腌渐与发酵

| 方法 | 步骤 | 期限 |
|---|---|---|
| 韭菜泡菜 | 用盐渐软后，与辣椒粉一起拌匀 | 阴凉处存放1-2个月 |
| 盐渐 | 按重量5-10%的盐分层渐制 | 3-6个月 |
| 浓盐渐 | 浸没在浓度10%以上的浓盐水中渐制 | 半年以上。食用前泡水去除盐味 |
| 酱油腌菜 | 浸入酱油中 | 数月 |
| 大酱腌菜 | 埋入大酱中 | 数月 |
| 花茎腌菜 | 将8月采下的花茎花蕾浸入盐水或酱油中 | 数月 |

&nbsp;&nbsp;&nbsp;韭菜特别适合腌渐是有原因的。韭菜所含的含硫化合物本身就有抗菌作用，所以用比其他蔬菜更少的盐也不会变坏。在食盐珍贵的灾害情境下，这种差异并不小。用大白菜泡菜所需盐量的一半，韭菜泡菜也能撑得住。

&nbsp;&nbsp;&nbsp;最后一行的花茎腌菜特别实用。因为8月清除花茎是每年都必须做的工作，那时产出的花茎一次就有相当的量。它的组织比叶片更结实，腌渐后能长期保持脆爽的口感，冬天的一道小菜就这样自然而然地准备好了。

## 16. 烹饪与加工

| 方法 | 燃料 | 步骤 | 备注 |
|---|:---:|---|---|
| 生食 | 0 | 洗净后直接拌食，或用于包菜 | 香气与维生素C保持完整 |
| 简易凉拌 | 0 | 用盐略渐后拌匀 | 不用燃料就能做出一道菜 |
| 焯拌 | 少量 | 沸水中焯20-30秒 | 焯太久会变软，香气也会散失 |
| 汤和锅类 | 中等 | 关火前放入 | 久煮会使香气消失 |
| 煎饼 | 中等 | 拌入面粉或谷物粉面糊中煎制 | 少量就能做成一餐 |
| 炒制 | 少量 | 大火1-2分钟 | 有利于β-胡萝卜素的吸收 |
| 泡菜 | 0 | 参见第15节 | 兼具贮藏与烹饪的功能 |

&nbsp;&nbsp;&nbsp;评价表中烹饪·加工为SS，意味着洗净后即可直接食用，在燃料珍贵的情况下这一点价值很大。仅凭简易凉拌这一种做法，不用火就能做出一道菜，这也是实际操作中最常用的方式。

> **韭菜烹饪的原则只有一条：尽量晚放，尽量短时间加热。韭菜的香气不耐高温久煮，煮得太久，放韭菜的意义就没了。**

&nbsp;&nbsp;&nbsp;前面提到的味道等级D、气味和香气令人排斥的判定，在灾害情境下需要反过来理解。平时浓烈的香气会造成喜好分歧，但在调味料、油和肉都消失的餐桌上，这种香气几乎成了唯一能立起味道的手段。用盐调味、用韭菜增香，能让平淡的谷物食物变得可以下咽。

&nbsp;&nbsp;&nbsp;这里还要加上抗菌作用。在没有冷藏的情况下，做好的食物几小时内就会开始变质。含韭菜的食物变质速度会稍慢一些，因为韭菜的含硫化合物能抑制细菌繁殖。夏季剩饭需要留到下一餐时，这种差异就有了实际意义。传统上夏季料理中大量使用韭菜和大蒜，不仅仅是为了味道。

&nbsp;&nbsp;&nbsp;β-胡萝卜素和维生素K是脂溶性的，需要有油才能充分吸收。加一勺油炒制或煎成饼，能让同样分量的韭菜提供更多营养。相反，维生素C溶于水且不耐热，因此把生吃的部分和煮熟吃的部分分开来安排比较合理。

## 17. 全年作业日程

| 月份 | 作业 |
|---|---|
| 1-2月 | 以根的状态越冬。检查覆盖物，注意不要踩踏栽种处 |
| 3月 | 撤去覆盖物，清理枯叶。施以氮为主的第一次肥。此时是分株的适宜时期 |
| 4月 | 首次收获。距地面留3-4cm剪割。割后放置一天再施肥浇水 |
| 5月 | 第二次、第三次收获。每次上移1-1.5cm剪割。每次刈割后追肥 |
| 6月 | 继续收获。梅雨季前整修排水沟。也可以分株 |
| 7月 | 高温期。叶片变韧，宜煮熟食用或做成泡菜 |
| 8月 | 抽出花茎。每隔7-10天清除一次，花蕾采下食用。留种用的株予以保留 |
| 9月 | 恢复秋季收获，是品质最好的时期。也是分株的适宜时期 |
| 10月 | 10月下旬结束最后一次收获。留种用的花茎干枯后采收种子 |
| 11月 | 施以钾为主的越冬肥。地上部分枯萎 |
| 12月 | 保留枯叶作覆盖，或覆盖稻草。靠贮存的泡菜和腌菜过冬 |

&nbsp;&nbsp;&nbsp;这个表格里最容易疏漏的两行是8月和10月。若拖延8月的花茎清除，当年秋天和来年春天都会变差；若10月下旬以后还继续刈割，养分就无法积累到根部，来年春天就会显现出来。这两项作业当下都看不出任何损失，要等几个月后才会显现结果，因此第一次接触多年生作物的人最容易疏忽。

&nbsp;&nbsp;&nbsp;3月这一行的分株也值得留意。这是扩大韭菜地唯一切实可行的方法，只要每3年不漏做一次这项作业，韭菜的种植面积就会年年扩大。对于种子活不过一年的这种作物来说，3月和9月这两次挖土分株的活儿，本身就等于种子的储备。
