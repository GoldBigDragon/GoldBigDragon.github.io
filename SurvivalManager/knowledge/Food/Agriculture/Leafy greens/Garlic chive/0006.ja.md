## 12. 収穫 - 切る高さがすべて

### 12-1. 収穫時期の判断

| 区分 | 基準 |
|---|---|
| 初収穫（種から開始） | 植えた翌年の春。初年は刈りません |
| 初収穫（株分け） | 活着後1か月、葉の長さ20-25cm |
| その後の収穫間隔 | 10-20日。評価表基準では25-30日 |
| 年間回数 | 露地で5-7回 |
| 季節別の配分 | 春4-6月に2-3回、夏7-8月に1-2回、秋9-10月に2回 |
| 収穫の終了 | 10月下旬。初霜の3-4週間前 |

&nbsp;&nbsp;&nbsp;葉の長さ20-25cmが実用的な基準です。それより長く置くと葉先が枯れて繊維が増えて硬くなり、それより早く刈ると株が休む間がなく勢いが落ちます。夏は生長が速く十日でこの長さに達しますが、春と秋は半月から二十日ほどかかります。

&nbsp;&nbsp;&nbsp;夏の収穫が春秋より少なく配分されている理由は、よく育たないからではなく品質のためです。25℃を超えるとニラは速く育ちますが繊維が太くなり香りが荒くなります。この時期に刈ったニラは硬くて辛みが強く、生では食べにくくなります。夏のものは火を通して食べるか、キムチや漬け物に回すほうがよいでしょう。

### 12-2. 切る高さ

| 回数 | 切る位置 |
|---|---|
| 初収穫 | 地面から3-4cm残して切ります |
| 2回目以降 | 前回切った位置から1-1.5cm上 |
| それ以降 | 回ごとに1-1.5cmずつ上げていきます |
| 翌年の春 | 再び地面から3-4cmに下げて始めます |

> **ニラの収穫で失敗するほぼ唯一のやり方は、切りすぎて低く刈ることです。3-4cmを残さず地面まで刈ると生長点が切られ、次の葉が出なくなったり大きく遅れたりします。**

&nbsp;&nbsp;&nbsp;ニラの生長点は地面近くの根元にあります。新しい葉はこの地点で作られ、上へ押し上げられます。そのため上のどこを切っても次の葉は出続けますが、生長点自体を切ってしまうと、その株は新しい葉を作る場所を失います。3-4cmという数字は、生長点の上に安全に残す余裕分です。

&nbsp;&nbsp;&nbsp;回を重ねるごとに切る高さを上げていく理由もここにあります。切った跡は切れた葉鞘が残って硬くなりますが、その硬くなった部分をまた切ると切り口が荒れて病気が入りやすくなります。そして先に見たとおり地下茎は毎年少しずつ上に上がってくるので、生長点も一緒に上がっていきます。1-1.5cmずつ上げていくのは、その動きに合わせるやり方です。

&nbsp;&nbsp;&nbsp;そうして一年の間ずっと上げていくと、秋頃には切る高さがかなり上がっています。冬に地上部が枯れ、翌年新しい葉が根元から再び上がってくるので、春には最初の高さに戻って始めます。この一年周期がニラ収穫のリズムです。

### 12-3. 収穫のコツ

| 項目 | 内容 |
|---|---|
| 道具 | よく切れる刃物やはさみ。刃が鈍いと切り口を押しつぶします |
| 時刻 | 露が乾いた午前。雨の日は避けます |
| 切る向き | 一株を一度にまとめてきれいに切ります |
| 刈った後 | 一日は水や肥料を与えません |
| 洗い方 | 根元側に土が付くので割って洗います |

&nbsp;&nbsp;&nbsp;よく切れる道具を使うという項目は衛生の問題です。鈍い刃で切ると切り口が裂けて押しつぶされ、大きな傷が残り、その傷から軟腐病菌や灰色カビが入り込みます。刈り取り直後の数日で根元が腐る事故は、大半がここから始まります。刃物を研いで使うことは、薬をまくことより効果が大きいのです。

&nbsp;&nbsp;&nbsp;雨の日や露が残る早朝を避けるのも同じ理由です。濡れた状態でできた傷はなかなか乾かず、菌が定着しやすくなります。

## 13. 採種 - 種が1年もたない作物

### 13-1. 採種より株分け

&nbsp;&nbsp;&nbsp;評価表の自家採種はSS、種子寿命はDです。この二つの等級が並んでいること自体が、ニラの繁殖戦略をそのまま説明しています。繁殖はとても簡単で、種の保管はほぼ不可能です。

| 方法 | 所要時間 | 保管の可能性 | 実用性 |
|---|---|---|---|
| 株分け | 1か月後に収穫 | 生きた株のまま保管 | 最も確実です |
| 採種後翌年播種 | 1年後に収穫 | 1年未満 | その年のうちに使う必要があります |
| 採種後数年保管 | 発芽ほぼ不可 | 不可 | 戦略として成り立ちません |

> **ニラの種子倉庫は袋ではなく畑です。種を集めて保管する代わりに、生きた株をいくつかの場所に分けて植えておくことが、この作物における備蓄です。**

&nbsp;&nbsp;&nbsp;だからといって採種が無意味というわけではありません。種は体積が小さく遠くへ運びやすいので、株を掘って運ぶには難しい距離を越える必要があるときに役立ちます。また株分けだけを繰り返すと、すべての株が遺伝的に同じ一個体になってしまうため、新しい病気が入ってきたときに全部が同じように崩れる恐れがあります。種でつないでいけば世代ごとに少しずつ混ざり合い、その危険が減ります。

### 13-2. 種の採り方

| 段階 | 内容 |
|---|---|
| 採種株の選定 | 3年目以上の健康な株をいくつか別に決めておきます |
| 管理 | その株はその年は刈らず、花茎をそのまま残します |
| 開花 | 8月から9月、白い花が傘状に咲きます |
| 成熟の判断 | 花が終わった跡の莢が茶色く枯れて割れ、黒い種が見えるとき |
| 収穫 | 花茎ごと切り、紙や布の上に逆さに吊るします |
| 分離 | 乾いた花茎を手でもみながら振るい落とします |
| 精選 | ふるいにかけるか、風に飛ばしてくず種を除きます |
| 乾燥 | 陰で完全に乾かします |
| 保管 | 密閉容器に灰や炭を一緒に入れ、涼しく暗い場所に置きます |

&nbsp;&nbsp;&nbsp;採種用の株を別に決めて管理するのは、養分のためです。花と種を作るのに使う養分は少なくないため、採種した株は翌年の勢いが目に見えて落ちます。収穫用の株から種まで採ろうとすると、両方とも悪くなります。畑の片隅に三、四株を採種専用として置き、その株はまったく刈らないのがすっきりした方法です。

&nbsp;&nbsp;&nbsp;莢は乾くと自然に開いて種が落ちるので、時期を逃すと地面にこぼれてしまいます。完全に乾く直前に花茎ごと切って逆さに吊るしておくのが安全で、下に布を敷いておけば、乾く途中で落ちる種をそのまま受け止められます。

### 13-3. 保存と寿命

| 条件 | 発芽力の維持 |
|---|---|
| 常温密閉 | 1年未満。翌年の春までが限度です |
| 涼しく乾いた場所 | 1-2年 |
| 湿気が多いか暑い場所 | 数か月で急激に落ちます |

&nbsp;&nbsp;&nbsp;ネギ属の種が特に短命な理由は、種に含まれる脂肪成分が酸化しやすいためと知られています。時間が経つとこの成分が変化し、胚が死んでしまいます。低温と低湿度は酸化を遅らせるので、できるだけ涼しく乾いた場所に置き、密閉容器に灰や炭を一緒に入れて湿気を抑えます。

&nbsp;&nbsp;&nbsp;実用的な結論は一つです。ニラの種はその年の秋か翌年の春に使います。数年後のために集めておく種のリストにニラは入れず、代わりにニラの株を畑に生かしておくことで代えます。

## 14. 毒性と注意すべき成分

### 14-1. ニラ自体の安全性

&nbsp;&nbsp;&nbsp;ニラは通常の摂取量では安全な食品です。生で食べても、茹でて食べてもかまいません。ただし二つ知っておくとよい点があります。

| 項目 | 内容 |
|---|---|
| 過剰摂取 | 硫化化合物が胃粘膜を刺激し、胃もたれや下痢が起こることがあります |
| 空腹での生食 | 空腹時に生のニラを多く食べると刺激がより強くなります |
| ビタミンK | 含量が高く、血液凝固に関わります |
| 犬と猫 | ネギ属全体がペットや一部の家畜に有毒です |

&nbsp;&nbsp;&nbsp;最後の行が災害時に実質的な注意点になります。ニラ、ネギ、ニンニク、タマネギをはじめとするネギ属の植物は、犬や猫の赤血球を破壊し貧血を引き起こします。人には何の問題もない成分が、これらの動物には毒になります。残った食べ物を家畜や犬に与えることが多くなる状況では、ニラが入った食べ物はその対象から外す必要があります。牛や馬も多量に食べると同種の貧血が起こることがあります。

### 14-2. 似た毒草 - においで見分ける

&nbsp;&nbsp;&nbsp;畑ではなく山や野でネギ属の植物を探すとき、葉だけを見て採ると危険な場合があります。ニラやギョウジャニンニク、ノビルに似た毒草が実際に存在し、毎年中毒事故が報告されています。

| 区分 | ネギ属（ニラ、ギョウジャニンニク、ノビル） | スズラン | スイセン・ヒガンバナ類 |
|---|---|---|---|
| 切った葉のにおい | ネギやニンニクのにおいが必ずします | においがありません | においがないか、草のにおいだけです |
| 葉の根元 | 何枚も重なって葉鞘を作ります | 2枚が向かい合って包むように伸びます | 平たい葉が重なって出ます |
| 葉の質感 | 薄くて柔らかいです | 厚くて硬く、つやがあります | 厚くて滑らかです |
| 葉脈 | 平行脈がはっきりしません | 平行脈がはっきりしています | 平行脈がはっきりしています |
| 地下部 | 鱗茎または根茎 | 細い根茎 | 丸い鱗茎（タマネギ状） |
| 食べた場合 | 食用 | 嘔吐、めまい、心拍異常 | 激しい嘔吐と腹痛、下痢 |

> **葉を一枚切ってもみ、においを確かめて、ネギやニンニクのにおいがしなければネギ属ではありません。この一点の確認だけで、ネギ属に似た毒草をほぼすべてふるい落とせます。**

&nbsp;&nbsp;&nbsp;スズランは特に注意が必要です。早春に出る葉がギョウジャニンニクと非常によく似ており、同じ山地に生えるため、山菜採りの際に混じる事故が繰り返し起きています。スズランに含まれる成分は心臓に作用して拍動を乱すため、少量でも危険です。スイセンやヒガンバナ類は鱗茎がタマネギやニンニクに似ているため、球根を掘っているときに取り違える事故が起きます。

&nbsp;&nbsp;&nbsp;においで見分ける方法が確実な理由は、ネギ属をネギ属らしくしている成分こそがそのにおいの成分だからです。葉をもんだり切ったりすると組織が壊れて酵素が働き、すぐにおいが出ます。この反応に例外はありません。ただし鼻が詰まっていたりにおいを感じられない状態では、この確認ができないので、そのときは野生採取をしないほうが安全です。

&nbsp;&nbsp;&nbsp;畑で育てたニラにはこの危険はありません。植えた場所がわかっているからです。ただしニラ畑の縁にスイセンやスズランを植えていた場合、春に混じる可能性があるので、ニラの場所の近くにそうした植物を置かないことが簡単な予防になります。

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;貯蔵性E、常温で2-3日というのはニラの確かな弱点です。ただしこの弱点は永続性SSと組み合わさることでかなりの部分が相殺されます。4月から10月までの七か月間、畑が貯蔵庫の役割を果たすためです。

### 15-1. 畑が貯蔵庫

| 方法 | 期間 | 条件 |
|---|---|---|
| 刈らずに畑に置く | 4月から10月まで | 必要な日に必要な分だけ刈ります |
| 根ごと掘って土に埋めておく | 数週間 | 涼しい場所の土に仮植えします |
| 濡れた布に包んで涼しい場所 | 3-5日 | 室や土室があればもっと持ちます |
| 立てて根元を水に浸す | 2-3日 | 横にすると葉が曲がって早く傷みます |

&nbsp;&nbsp;&nbsp;四行目に小さなコツがあります。ニラは横にしておくと葉が上に曲がろうとして、その力にエネルギーを使い、組織が早く崩れます。立てておくとこの反応が起きないため、一、二日長く持たせられます。かめや容器に根元を立てて入れ、底に少し水を入れておく方法です。

### 15-2. 乾燥

| 段階 | 内容 |
|---|---|
| 手入れ | 洗って土を落とし、水気を完全に取ります |
| 切る | 3-5cmの長さに切ります。丸ごと乾かすと中まで乾きません |
| 干す | 陰の風通しのよい場所。日に当てて干すと色と香りが飛びます |
| 完了の判断 | 手でもんで崩れるまで |
| 保管 | 密閉容器に灰や炭を一緒に入れます |
| 期間 | よく乾いて密閉されたものは半年から1年 |

&nbsp;&nbsp;&nbsp;ニラの乾燥で最も大きく失われるのは香りです。においの元である硫化化合物は揮発性が高く、乾く間にかなりの部分が飛んでしまいます。乾燥ニラは生のニラとは別の食材と見るほうが正確で、汁物に入れて色と繊維を得るための用途に落ち着きます。陰でゆっくり乾かすと損失が少し減り、乾き切った直後に密閉すれば残った香りを守れます。

### 15-3. 漬け物と発酵

| 方法 | 手順 | 期間 |
|---|---|---|
| ニラキムチ | 塩で漬けてしんなりさせた後、唐辛子粉と一緒に和えます | 涼しい場所で1-2か月 |
| 塩漬け | 重さの5-10%の塩で層にして漬けます | 3-6か月 |
| 強塩漬け | 10%以上の濃い塩水に浸して漬けます | 半年以上。食べる前に水に浸けて塩気を抜きます |
| 醤油漬け | 醤油に浸けます | 数か月 |
| テンジャン（韓国味噌）漬け | テンジャンに埋め込みます | 数か月 |
| 花茎の漬け物 | 8月に採った花茎のつぼみを塩水か醤油に浸けます | 数か月 |

&nbsp;&nbsp;&nbsp;ニラが漬け物に特によく合う理由があります。ニラの硫化化合物自体が抗菌作用を持つため、他の野菜より少ない塩でも傷みません。塩が貴重な災害時にはこの差は小さくありません。白菜キムチに使う塩の半分でも、ニラキムチは持ちこたえます。

&nbsp;&nbsp;&nbsp;最後の行の花茎の漬け物が特に実用的です。8月に花茎を取り除く作業は毎年必ず行うことなので、そのとき出る花茎が一度にかなりの量になります。葉より組織が硬いため漬けておくとコリコリした歯ごたえが長く残り、冬のおかずになる材料が自然に生まれるわけです。

## 16. 調理と加工

| 方法 | 燃料 | 手順 | 備考 |
|---|:---:|---|---|
| 生食 | 0 | 洗ってそのまま和えるか、包み野菜に添えます | 香りとビタミンCがそのまま残ります |
| 浅漬け和え | 0 | 塩に少し漬けてから和えます | 燃料なしでおかずが一品できます |
| 湯通しあえ物 | 少ない | 沸騰した湯に20-30秒 | 長く茹でると柔らかくなり香りが飛びます |
| 汁物・鍋料理 | 中程度 | 火を止める直前に入れます | 長く煮ると香りが消えます |
| チヂミ（ジョン） | 中程度 | 小麦粉や穀物粉の生地に混ぜて焼きます | 少量で一食になります |
| 炒め物 | 少ない | 強火で1-2分 | βカロテンの吸収がよくなります |
| キムチ | 0 | 15節参照 | 貯蔵と調理を兼ねます |

&nbsp;&nbsp;&nbsp;評価表で調理・加工がSSなのは、洗ってすぐ食べられるという意味で、燃料が貴重な状況では価値が大きくなります。浅漬け和え一品だけでも火を使わずにおかずが成立し、これが実際の運用で最もよく使われる方法になります。

> **ニラ料理の原則は一つです。できるだけ後に入れ、できるだけ短く火を通します。ニラの香りは熱に弱いため、長く煮るとニラを入れた理由がなくなってしまいます。**

&nbsp;&nbsp;&nbsp;先に見た味の等級D、においと香りに抵抗感があるという判定は、災害時には逆に読む必要があります。平常時は強い香りが好みを分けますが、調味料や油、肉が消えた食卓では、その香りがほぼ唯一味を立てる手段になります。塩で味付けしてニラで香りをつければ、味気ない穀物料理も食べられるようになります。

&nbsp;&nbsp;&nbsp;ここに抗菌作用が加わります。冷蔵のない状況で調理した食べ物は数時間で傷み始めます。ニラが入った食べ物はその速度が少し遅くなります。ニラの硫化化合物が細菌の増殖を抑えるためで、夏場に残った食べ物を次の食事まで持たせる必要があるとき、この差は実質的な意味を持ちます。伝統的に夏の料理にニラやニンニクを多く入れてきたのは、味のためだけではありませんでした。

&nbsp;&nbsp;&nbsp;βカロテンとビタミンKは脂溶性なので、油がなければ十分に吸収されません。油一さじと一緒に炒めたりチヂミにして焼いたりすると、同じ量のニラから得られる栄養が増えます。反対にビタミンCは水に溶けて熱に弱いため、生で食べる分と火を通して食べる分を分けるのが合理的です。

## 17. 年間作業スケジュール

| 月 | 作業 |
|---|---|
| 1-2月 | 根の状態で越冬中です。覆いを確認し、株の場所を踏まないようにします |
| 3月 | 覆いを外して枯れ葉を整理します。窒素中心の初回の肥料を入れます。株分けの適期です |
| 4月 | 初収穫。地面から3-4cm残して切ります。刈った後一日置いてから肥料と水を与えます |
| 5月 | 2回目、3回目の収穫。回ごとに1-1.5cmずつ上げて切ります。刈るたびに追肥します |
| 6月 | 収穫を続けます。梅雨前に排水路を整備します。株分けも可能です |
| 7月 | 高温期。葉が硬くなるので火を通して食べるかキムチに回します |
| 8月 | 花茎が上がってきます。7-10日おきに取り除き、つぼみは収穫して食べます。採種用の株は残します |
| 9月 | 秋の収穫を再開します。最も品質のよい時期です。株分けの適期です |
| 10月 | 最後の収穫を10月下旬に終えます。採種用の花茎が乾いたら種を採ります |
| 11月 | カリウム中心の越冬肥料を入れます。地上部が枯れます |

&nbsp;&nbsp;&nbsp;この表で最も見落としやすい二行は8月と10月です。8月の花茎除去を後回しにすると、その年の秋と翌年の春がともに悪くなり、10月下旬以降も刈り続けると根に養分が蓄えられず翌年の春に影響が出ます。どちらも今すぐには何の損害も見えず、数か月後に結果が現れる作業なので、多年生作物を初めて扱う人が最もよく見落とします。

&nbsp;&nbsp;&nbsp;3月の行の株分けにも注目します。ニラ畑を広げる唯一の実質的な方法であり、3年に一度この作業を欠かさなければ、ニラの場所は年々広がっていきます。種が1年もたない作物において、この3月と9月のシャベル仕事がそのまま種子の保存になるのです。
