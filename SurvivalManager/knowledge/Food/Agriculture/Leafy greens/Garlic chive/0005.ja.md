## 8. 栽培管理 - 花茎と株の更新

### 8-1. 花茎の除去

| 項目 | 内容 |
|---|---|
| 時期 | 8月頃、花茎が上がり始める時期 |
| 見分け方 | 葉より太く硬く中が詰まった茎が真っ直ぐ立ちます |
| 方法 | 7-10日おきに見つけたら根元から折るか切ります |
| 理由 | 花と種を作るのに養分が集中し、株の勢いが落ちます |
| 例外 | 採種する株は別に定めて残しておきます |

&nbsp;&nbsp;&nbsp;植物が花を咲かせるということは、生殖の段階に移るという意味です。その時から根と葉に蓄えた養分が花と種の方へ流れ出ていきます。人の立場からすれば、食べる葉を作るための資源が種へ流れていくことになり、花が咲いて種が熟すまで放っておくと、その年の残りの収穫がほとんど消えてしまいます。根の勢いも一緒に落ち、翌年の春に影響が残ります。

> **8月の花茎を見逃すと、その年の秋の収穫と翌年の春の収穫が共に減ります。ニラの管理の中で、時期を逃すと最も損害が大きい作業がこれです。**

&nbsp;&nbsp;&nbsp;ただし、切り取った花茎は捨てません。ニラの花茎は、まだ花が開く前のつぼみの状態のときにとても良い野菜になります。しゃきしゃきして甘みがあり、炒め物や漬物に使われ、葉より貯蔵性も優れています。除去作業がそのまま、もう一つの収穫になるわけです。花が白く開いてしまうと茎が硬くなり食べにくくなるので、つぼみがまだ閉じている状態のときに収穫するのがコツです。

### 8-2. 株の更新

| 項目 | 内容 |
|---|---|
| 周期 | 3-4年ごと |
| 時期 | 早春（3-4月）または秋（9月） |
| 兆候 | 葉が細くなり、株が密集し、中央が空き始めます |
| 方法 | 株を丸ごと掘り出し3-5株ずつに分けて新しい場所に植え直します |
| 場所 | 可能であれば別の区域に移します |

&nbsp;&nbsp;&nbsp;ニラが同じ場所で5年以上続くという評価と、3-4年ごとに更新するという管理指針は矛盾しているように見えますが、二つは同じ話です。ニラは死なずに生き続けますが、時間が経つほど勢いは落ちていきます。地下茎が横に広がって株が増えますが、それが一つの塊の中で増え続けると結局互いに場所を奪い合うようになります。密度が高くなると個々の株が受け取る養分と光が減り、葉が細くなります。

&nbsp;&nbsp;&nbsp;ここに、地下茎が毎年少しずつ上に上がってくる現象が重なります。新しい地下茎が以前のものの上に乗るように育つためで、数年経つと根の部分が地表近くまで上がり、冬の寒さと夏の乾燥にそのままさらされます。ニラ畑の真ん中が空いてドーナツのようになる姿が現れたら、更新の時期が来たということです。

&nbsp;&nbsp;&nbsp;更新は損失ではなく増殖です。一塊を掘り出して分けると三、四塊になり、それだけニラ畑が広がります。3年ごとにこの過程を経ると、最初の一坪が数年後には何坪にもなります。種を使わずに面積を増やす方法であり、種子寿命Dという弱点を正面から回避する道です。

| 回次 | 時点 | 結果 |
|---|---|---|
| 最初の植え付け | 0年 | 一塊 |
| 1回目の更新 | 3-4年 | 三、四塊 |
| 2回目の更新 | 6-8年 | 十塊以上 |
| 3回目の更新 | 9-12年 | 分ける場所に困るほど |

### 8-3. 雑草管理

&nbsp;&nbsp;&nbsp;多年生作物の宿命です。畑を掘り返す機会がないので、雑草が毎年積み重なります。特にニラの株の中に入り込んだ草は根が絡み合い、抜くとニラまで一緒に抜けてしまいます。

| 方法 | 内容 |
|---|---|
| 植える前 | 多年生雑草の根を徹底的に取り除きます。唯一の根本対策です |
| 畝間マルチング | 藁と乾草で畝間を覆い発芽を防ぎます |
| 刈り取り直後 | 葉を刈った直後は株が低く草がよく見えます |
| 早春 | ニラが上がる前に先に出た草を取り除きます |
| 冬 | 枯れた葉を取り除くと同時に一緒に整理します |

&nbsp;&nbsp;&nbsp;刈り取り直後を狙うという項目は実用的です。普段はニラの葉が茂ってその間の草が見えませんが、葉を刈ると畑の地面がすっかり見えて草が一目で分かります。切り、草を抜き、肥料を与え、一日置いてから水をやるという順序が、ニラ畑の基本的な作業の流れになります。

### 8-4. 越冬管理

| 時期 | 作業 | 理由 |
|---|---|---|
| 10月下旬 | 最後の刈り取りを終えます | 霜の3-4週間前には刈るのをやめないと、根に養分が蓄積しません |
| 11月 | カリウム中心の肥料を入れます | 耐寒性を高めます |
| 11月下旬 | 地上部が枯れます | 自然な過程です |
| 12月 | 枯れた葉をそのままにするか藁を覆います | 凍上害と乾燥を防ぎます |
| 2月下旬-3月 | 覆いを取り除きます | 地温が早く上がり収穫が早まります |

&nbsp;&nbsp;&nbsp;10月下旬に刈り取りをやめることが、翌年の農作業を左右します。晩秋に刈ったニラは新しい葉を出すために根に貯蔵した養分を取り出して使いますが、その葉が育つ前に霜が降りて枯れてしまいます。貯蔵養分だけを失い何も残らないことになります。その状態で冬を越すと、翌年の春に上がってくる葉が目に見えて細くなります。

## 9. 病害虫 - 薬を使わずに防ぐ法

### 9-1. 主な病害

| 病名 | 症状 | 条件 | 薬を使わない対応 |
|---|---|---|---|
| 菌核病 | 株元が柔らかくなり白い菌糸と黒い粒（菌核）ができます | 過湿、低温、通風不良 | 病気の株を土ごと取り除きます。菌核が土に残るのでその場所は何年も使いません |
| 葉枯病 | 葉先から茶色く枯れます | 通風不良、窒素過多 | 病気の葉を取り除き株間を広げます |
| さび病 | 葉に橙色の粉が生じる斑点 | 晩夏の多湿 | 病気の葉を取り除き畑の外へ運び出します |
| べと病 | 葉が黄色くなり裏面に灰色のかびが出ます | 低温多湿、春と秋 | 排水と通風の確保。ネギ属最大の制約です |
| 灰色かび病 | 灰色のかびが葉の根元に生じます | 過湿、傷口部分 | 刈り取り後一日乾かしてから水をやります |
| 軟腐病 | 株元が柔らかくなり悪臭がします | 刈り取りの傷から細菌が侵入 | 雨の日の刈り取りを避けます |

&nbsp;&nbsp;&nbsp;評価表の防除自立度Bは、ドイツの有機タマネギ実証文献六編を根拠に付けられた値であり、そこでべと病がネギ属最大の制約として指摘されました。無防除対照区の発病深刻度が96%だったという数値は、防除をしなければ事実上ほぼ全部がかかるという意味です。ただし発病深刻度がそのまま収量損失を意味するわけではありません。葉が傷んでも根は生きて翌年また上がってきます。これが多年生作物の緩衝能力です。

&nbsp;&nbsp;&nbsp;その文献が示した対応も薬剤ではありませんでした。抵抗性系統を使い、株間を広げて空気を通し、排水を確保することがすべてでした。この三つは薬がなくてもできることであり、災害時の畑にそのまま当てはまります。

### 9-2. 主な害虫

| 害虫 | 被害 | 時期 | 薬を使わない対応 |
|---|---|---|---|
| 根食いバエ | 幼虫が地下部を食い荒らし株が萎れて枯れます | 春と秋、過湿の時 | 未熟な堆肥を入れません。排水を直します |
| ネギハモグリバエ | 葉の中に穴を掘り白い筋ができます | 春、秋 | 被害葉を取り除きます。網をかければ確実です |
| アブラムシ | 葉に付いて汁を吸い、すす病を招きます | 春、秋 | 水で洗い流すか石けん水をかけます |
| アザミウマ | 葉に白い斑点ができ銀色になります | 高温乾燥期 | 乾燥しないよう管理します。青色の粘着シートが役立ちます |
| ネギコガ | 幼虫が葉を食害します | 夏 | 手で捕まえます。ニラでは被害は大きくありません |

&nbsp;&nbsp;&nbsp;ニラの害虫問題は総じて軽いです。硫化化合物のにおいそれ自体が忌避剤の役割を果たすためです。評価表の病害虫圧Bという等級がケールのCより一段高いのも、この事情を反映しています。実質的に危険なのは最初の一行だけです。

&nbsp;&nbsp;&nbsp;根食いバエが特に危険な理由は、被害が目に見えない場所で進むためです。地上部が萎れ始めたときには、すでに地下部がかなり食われた後です。そしてこの虫は未熟な有機物に卵を産みます。化学肥料がなく堆肥に頼らざるを得ない災害時には、この点が実質的な危険になります。堆肥は必ず完全に熟成させ、熱がもう出ず土のにおいがするようになってから使い、株のすぐ横ではなく少し離れた場所に入れます。

### 9-3. 薬を使わない防除

| 方法 | 作り方と使い方 | 対象 |
|---|---|---|
| 排水確保 | 畝を高くし排水路を深く掘ります | 菌核病、根食いバエ、べと病 |
| 株間確保 | 株の間15-20cmを守ります | べと病、葉枯病、灰色かび病 |
| 刈り取り後の乾燥 | 刈った後一日は水と肥料を与えません | 軟腐病、灰色かび病 |
| 病葉の除去 | 畑の外に運んで燃やすか深く埋めます | さび病、べと病 |
| 木灰 | 刈り取り後株元の周りにまき散らします | 根食いバエ、株元の腐敗、ナメクジ |
| 石けん水 | 水1Lに石けん数gを溶かして噴きます | アブラムシ、アザミウマ |
| 木酢液 | 300-500倍に希釈して噴きます | 予防目的 |
| ボルドー液 | 硫酸銅と生石灰で作ります | さび病、べと病。材料がある時のみ |
| 防虫網 | 春と秋に掛けます | ネギハモグリバエ、根食いバエの成虫 |

&nbsp;&nbsp;&nbsp;この表の前の四行が薬剤なしでできる核心であり、実際にニラの病害の大部分を占める湿気関連の病気をすべて扱います。薬を作る材料がない状況でも、この四つは常に可能です。シャベルと手だけあれば済みます。

&nbsp;&nbsp;&nbsp;木灰が根食いバエに効果がある理由は、成虫が湿った土の表面に卵を産む習性のためです。株元の周りに灰をまき散らすと、表面が乾燥してアルカリ性になり産卵が減ります。刈り取り後の傷口の殺菌効果とカリウムの供給まで兼ねるので、灰はニラ畑で最も使い道の多い資源です。

### 9-4. ニラそのものが防除手段になる場合

&nbsp;&nbsp;&nbsp;評価表では非食用価値Dが害虫防除の項目一つで満たされました。ネギ属の植物が分泌する硫化化合物が、土の中の病原菌の増殖を抑えるという意味です。

&nbsp;&nbsp;&nbsp;実際に畑ではこの効果は二つの方向で使われます。一つは間作です。トマト、ナス、イチゴのような作物のそばにニラを植えると、萎凋病と疫病の発生が減るという観察が長く続いてきました。もう一つは後作効果です。ニラを取り除いた場所は、何年もの間ニラの根が分泌物を出してきた場所なので土壌病の密度が下がっており、そこに植える作物が利益を得ます。11節でこの配置を扱います。

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然の材料でできる対処 |
|---|---|---|
| 葉全体が薄い緑色で細く短い | 窒素不足 | 尿の8-10倍希釈液を刈り取りの翌日に畝間に与えます。完熟堆肥を株の間に置きます |
| 葉が異様に大きく柔らかく倒れやすい | 窒素過剰 | 肥料を絶ちます。病気に弱くなった状態です |
| 古い葉の縁から茶色く焼けたようになる | カリウム不足 | 木灰を1㎡に一、二握りまき散らします |
| 全体的に生育が遅く葉の色が濃い青緑で紫がかる | リン不足 | 骨粉と木灰を入れます。低温期にも同じ症状が出ます |
| 新しい葉がねじれ先端が枯れる | カルシウム不足 | 貝殻と卵の殻を焼いて砕いて入れます |
| 葉脈の間が黄色くなり葉脈だけ緑 | マグネシウム不足 | 木灰にマグネシウムが含まれています。苦土石灰があれば使います |
| 冬を越して春に葉が目に見えて細くなる | 秋の刈り取り過多またはカリウム不足 | 10月下旬以降は刈りません。11月にカリウムを入れます |
| 回を重ねるほど葉が細くなる | 蓄積した窒素の搬出 | 刈り取るたびに追肥を入れる循環を作ります |

&nbsp;&nbsp;&nbsp;最後の二行はニラ特有の項目です。他の作物は一年の中で欠乏が現れて終わりますが、ニラは多年生なので一年の管理不足が翌年に持ち越されます。秋に無理に刈った結果が翌年の春に現れ、数年にわたる窒素の搬出が4年目、5年目に積み重なって表れます。時間軸の長い作物なので、原因と症状の間の間隔も長くなります。

&nbsp;&nbsp;&nbsp;そのため、ニラの栄養管理は症状を見て直す方式ではなく、出ていく分だけ入れる循環を前もって作る方式であるべきです。葉を刈るたびに何かを入れる習慣がその循環であり、入れるものが尿の希釈液だけであっても、入れないよりはましです。

&nbsp;&nbsp;&nbsp;四行目のリン不足の症状は、低温期の症状と混同しやすい点も押さえておきます。早春に地温が低いときは、土にリンが十分あっても根が吸収できず同じ症状が現れます。気温が上がれば自然に回復するので、3月に見える紫色は大抵待てば済みます。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 作物 | 理由 |
|:---:|---|---|
| 良い | トマト、ナス、トウガラシ | ニラの根の分泌物が萎凋病と疫病を抑えます |
| 良い | イチゴ | 根腐れを減らすという観察が長く続いてきました |
| 良い | ニンジン | 互いの害虫を追い払います |
| 良い | サンチュ、ホウレンソウ | ニラの間の空いた空間を使い、互いに競合しません |
| 悪い | マメ科作物（大豆、エンドウ、インゲンマメ） | ネギ属の分泌物が根粒菌を抑えます |
| 悪い | 同じネギ属（ネギ、ニンニク、タマネギ） | 病原菌と害虫が積み重なります |

&nbsp;&nbsp;&nbsp;五行目が特に実用的な情報です。ネギ属の植物が出す硫化化合物は病原菌だけを抑えるのではなく、マメ科作物の根に住む根粒菌にも影響を与えます。マメが自ら窒素を作る能力はこの菌から生まれるので、ニラのそばに植えたマメは根粒ができにくくなり、窒素固定が減ります。化学肥料がない状況では、マメ科作物の窒素固定は畑全体の地力を維持する柱なので、この組み合わせを避けることは単なる相性の問題ではありません。

&nbsp;&nbsp;&nbsp;先の5節で、ニラを植える前年に大豆を育てるようにと言ったことと矛盾しているように見えるかもしれませんが、違います。時間を置いて前後に配置するのは問題なく、同じ時期に並べて植えることが問題なのです。大豆を収穫して残渣を埋め込んだ後にニラを植えれば、ニラがその窒素を受け取ります。

### 11-2. 輪作

&nbsp;&nbsp;&nbsp;評価表の連作適応性がSSなので、ニラ自体のための輪作は必要ありません。同じ場所で5年維持するのが正常です。ただし、その5年が終わった後、そして病気が入った場合には場所を移す必要があります。

| 状況 | 対応 |
|---|---|
| 正常な更新 | 3-4年ごとに分けて植え、隣の区域に移します |
| 菌核病が発生した場所 | 5年以上ネギ属を植えません |
| ニラを取り除いた場所 | 土壌病の密度が下がっており次の作物に有利です |

&nbsp;&nbsp;&nbsp;輪作順序の一例は、ニラを4年育てた後にマメ科作物を一年植えて窒素を回復し、その次の年に葉菜類や果菜類を植え、その後再びニラを入れるという流れです。こうすると、ある区域がニラに戻ってくる周期が6-7年になり、ネギ属の土壌病が収まる時間が十分に取れます。

&nbsp;&nbsp;&nbsp;ただし、実際の災害時の小さな畑ではこのような循環が難しい場合が多いです。そのときはニラの区域をそのまま固定しておき、代わりに病気が入らないよう排水と通風を徹底して守る方を選びます。ニラは連作そのものが害にならない作物なので、病気さえなければ十年間同じ場所で使っても構いません。

### 11-3. 場所配置の実際

&nbsp;&nbsp;&nbsp;ニラは多年生なので畑の地図の上で固定区域になります。この区域をどこに置くかが数年を左右するので、基準を整理しておきます。

| 基準 | 内容 |
|---|---|
| 水がたまらない場所 | 最も優先すべき条件です |
| よく通る通り道 | 少しずつ頻繁に刈って使う作物なので、近いほど良いです |
| 毎年掘り返す区域の外 | 5年間耕さない場所です |
| 一日6時間以上の日照 | 終日の日当たりでなくてもかまいません |
| 果菜類の畝の縁 | 間作の効果も兼ねます |

&nbsp;&nbsp;&nbsp;二行目が意外に重要です。ニラは一度に多く収穫する作物ではなく、汁物一杯、チヂミ一枚に使う一握りを頻繁に取ってくる作物です。畑の一番端にあると、その一握りのために毎回歩いていかなければならず、結局あまり使わなくなります。門口や台所の近くに置くことが、実際の利用量を大きく増やします。
