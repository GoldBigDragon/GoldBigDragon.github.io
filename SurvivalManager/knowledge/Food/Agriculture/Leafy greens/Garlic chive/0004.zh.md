## 4. 品种

### 4-1. 各系统的特征

| 系统 | 叶 | 耐寒性 | 产量 | 灾害适用性 |
|---|---|:---:|:---:|---|
| 大叶种（宽叶韭菜） | 宽厚 | 一般 | 多 | 一次收获量大，整理也方便 |
| 本地种（小叶种，朝鲜韭菜） | 叶窄、香气浓 | 强 | 中等 | 露地适应力最好，越冬也稳定 |

| 品种 | 特征 | 产量 | 适宜环境 |
|---|---|:---:|---|
| 台湾韭菜 | 分蘖旺盛，抗病性强 | 多 | 露地和设施均可 |
| 蒙古韭菜 | 耐寒性特别强 | 中等 | 寒冷地区 |
| 本地种（朝鲜韭菜） | 香气浓，越冬稳定 | 中等 | 韩国全国 |
| 满洲韭菜 | 休眠深，收获间隔较长 | 中等 | 露地 |

&nbsp;&nbsp;&nbsp;韭菜的品种划分不像其他蔬菜那样清晰。因为长期以来它不是靠买卖种子来种的作物，而是从邻居那里要来一株再种下的作物。在一个村子里流传了几十年的系统，往往就以那个地区的名字命名，而这个系统早已经过筛选，适应了当地的气候。

&nbsp;&nbsp;&nbsp;这里说明一下"休眠"这个概念。韭菜冬天会舍弃地上部分只留根，而这时休眠有多深，各系统之间是不同的。休眠较深的满洲韭菜系统春天苏醒得晚，苏醒之后再生也慢，但相应地在冬季严寒中更安全。休眠较浅的台湾韭菜系统春天出得早、再生也快，但若冬天偏暖，它会半苏醒过来，之后再遇上寒潮就容易受损。

### 4-2. 按情况选择的标准

| 情况 | 选择 | 理由 |
|---|---|---|
| 邻居或附近有韭菜 | 分一些株过来 | 已经适应当地的系统，第一年就能收获 |
| 想提高产量 | 台湾韭菜、大叶种 | 分蘖旺盛，叶片宽大 |
| 韩国中部以北、寒冷地区 | 蒙古韭菜、本地种 | 休眠深，越冬稳定 |
| 重视香气与味道 | 本地种 | 含硫化合物含量高，香气浓郁 |
| 想在早春最先收获 | 台湾韭菜 | 休眠浅，苏醒得早 |
| 只有种子 | 任何系统均可 | 但第一年要放弃收获，专心长根 |

> **对韭菜而言，比选品种重要得多的是找到活的株，而不是种子。种子寿命不到一年，囤起来的种子等灾难真正到来时，很可能已经失效了。**

&nbsp;&nbsp;&nbsp;这句话的意思很明确。韭菜不是灾难发生之后才去找来种的作物，而是应该在那之前就种下的作物。哪怕只留出一坪（约3.3㎡）的地方让它活下去，这一株也会年年增多，几年后就足够分开来种了。比起十袋种子，地里活着的一片韭菜更靠得住。

## 5. 整地与施肥

### 5-1. 整地

| 项目 | 标准 | 备注 |
|---|---|---|
| 翻耕深度 | 20-30cm | 这块地要用5年，一开始就要深耕 |
| 垄高 | 15-20cm | 排水不良的地块需25cm以上 |
| 垄宽 | 90-120cm | 以种两三行为标准 |
| 排水沟 | 务必留出 | 湿害是最大的失败原因 |
| 酸度调节 | 目标pH 6.0-6.5 | 种植前2-3周提前施入 |
| 石块与根 | 提前清除干净 | 这块地5年内不会再翻动 |

&nbsp;&nbsp;&nbsp;韭菜整地与其他作物不同的地方，在于这项工作5年才做一次。评价表中整地·挖掘能耗A正是由此而来。但反过来说，如果这一次做得马虎，接下来5年都会吃苦。多年生作物的整地不是一年的农活，而是打下数年基础的工作，因此不吝惜劳力最终反而划算。

&nbsp;&nbsp;&nbsp;特别重要的是要把多年生杂草的根清理干净。像问荆、打碗花这类靠根扩散的杂草一旦混入韭菜地，就会和韭菜的根缠在一起，根本没法拔除。韭菜地5年内不会翻耕，因此没有机会把杂草埋进土里消灭掉，所以一开始就彻底清理干净格外值得。

### 5-2. 施肥量

&nbsp;&nbsp;&nbsp;韭菜是喜肥作物。它生长期长，一年要割五六次叶子，从地里带走的养分很多。评价表中施肥等级B，正是根据每㎡需要合计约24g的N、P、K而得出的。

| 成分 | 每1,000㎡ | 每1㎡ | 备注 |
|---|:---:|:---:|---|
| 氮（N） | 20-25kg | 20-25g | 分为基肥与追肥 |
| 磷（P） | 12-15kg | 12-15g | 全部作基肥 |
| 钾（K） | 15-20kg | 15-20g | 分为基肥与追肥 |
| 堆肥 | 1,500-2,000kg | 1.5-2kg | 完熟堆肥 |
| 石灰 | 100-150kg | 100-150g | 用于矫正酸性土 |

| 区分 | 时期 | 内容 |
|---|---|---|
| 基肥 | 种植前1-2周 | 堆肥全量、磷全量，氮和钾各一半 |
| 追肥 | 每次割取后 | 以氮和钾为主 |
| 越冬前 | 11月 | 以钾为主 |
| 春季萌芽时 | 3月 | 以氮为主 |

&nbsp;&nbsp;&nbsp;每次割取都要追肥，这是韭菜施肥的关键。割叶这一行为本身就是在把氮从地里带走，割的次数越多，这种消耗就越累积。若不补充继续割，从第三、第四次割取开始，叶片就会变细、颜色变浅。评价表中无合成投入产量保持率C、40.8%这个数值，指的正是这一现象。

&nbsp;&nbsp;&nbsp;11月以钾为主施肥也是有原因的。钾能提高细胞内的渗透压，从而降低冰点，并使细胞壁变厚。这就像人准备越冬泡菜（kimjang）一样，是植物为过冬做准备所需的成分，一旦缺乏，耐寒性就会实际下降。耐受零下20℃的能力是天生的，但要让这种能力充分发挥出来，秋天就必须有钾。

### 5-3. 灾害替代肥料

&nbsp;&nbsp;&nbsp;一旦断了化肥，韭菜最先显现出来的就是叶片的粗细。叶子会变细、变短、颜色变浅。由于是在同一块地上收获5年的作物，如果不建立"取多少还多少"的循环，情况会一年比一年糟。

| 替代资源 | 供给成分 | 使用方法 | 注意事项 |
|---|---|---|---|
| 人尿 | 氮（主）、钾、磷 | 用水稀释8-10倍，割取后立即浇入沟中 | 沾到叶片会烧伤。要等割口愈合一天后再用 |
| 完熟堆肥 | 氮、磷、钾、有机质 | 作基肥要充足施用，追肥则铺在株间 | 未腐熟的堆肥会招来根蛆 |
| 草木灰 | 钾、钙、磷 | 割取后每㎡撒一两把 | 属碱性，能让土壤更接近韭菜喜欢的中性 |
| 麻饼（芝麻饼） | 氮、磷 | 割取后撒在株间，或使用发酵后的液肥 | 直接撒会因发酵热损伤根部 |
| 骨粉 | 磷、钙 | 烧后磨碎，混入基肥 | 效果显现较慢 |
| 草液肥 | 氮、钾 | 将割下的草泡水发酵2-3周后稀释5倍 | 气味很重 |
| 贝壳·蛋壳 | 钙 | 烧后磨碎，用于调节酸度 | 可代替石灰 |
| 豆科前茬 | 氮 | 在种韭菜的前一年种豆类，收后把残茬埋入土中 | 这块地要用5年，种植前是唯一的机会 |

&nbsp;&nbsp;&nbsp;最后一行值得注意。韭菜种下之后，那块地5年内不会再翻，因此翻入绿肥或利用前茬的机会只有种植前这一次。所以，一旦确定了韭菜的种植地，比较合理的顺序是：前一年先种大豆或豌豆，靠根瘤留住氮，再把残茬埋入土中，然后种下韭菜。这样积存下来的氮会在5年里慢慢释放出来。

&nbsp;&nbsp;&nbsp;草木灰特别适合韭菜，这一点也值得记住。韭菜偏好pH 6.0-6.5，而韩国的地一般比这更偏酸性。草木灰属碱性，能在提高酸度的同时补充钾。割取之后把灰撒在割口上，还能起到伤口杀菌的效果。不过一次施用太多会妨碍硼和铁的吸收，因此要控制在每㎡一两把、一年不超过三四次。

## 6. 种植——种子与分株

### 6-1. 时期

| 繁殖方式 | 种植时期 | 首次收获 | 备注 |
|---|---|---|---|
| 播种（春季） | 3月中旬至4月初 | 次年春天 | 第一年是长根之年 |
| 播种（秋季） | 8月中旬至9月初 | 次年春天 | 以幼苗状态越冬 |
| 移栽幼苗 | 5月至6月中旬 | 当年秋天或次年春天 | 要在梅雨季前完成 |
| 分株 | 3月至6月，或9月 | 扎根后1个月 | 最快也最可靠 |

> **分株是种韭菜的正规做法。用种子起步，要等一年才能第一次收获；用株起步，一个月就够了。**

&nbsp;&nbsp;&nbsp;这个差异在灾难情境下至关重要。如果附近哪里有韭菜，把它挖出来分开种，比撒种子快上十倍左右。韭菜是分布极为广泛的作物，评价表中韩国国内普及度SS说明的正是这一事实。荒废的菜园、空屋院子、田埂、地边，常常还留着韭菜株。冬天地上部分枯萎看不出来，但一到春天就会显露出来。

### 6-2. 分株

| 项目 | 标准 |
|---|---|
| 挖取时期 | 3-4月新芽长出时，或9月 |
| 挖取方法 | 用铁铲围绕根部大范围挖起，整个取出 |
| 分株单位 | 每3-5株一丛 |
| 修剪叶片 | 地上部分只留约10cm，其余剪去 |
| 修剪根部 | 过长的根尖稍作修整 |
| 种植深度 | 5-8cm，注意不要让生长点埋入土中 |
| 行距 | 20cm |
| 株距 | 15-20cm |
| 种植后 | 压实土壤，充分浇水 |

&nbsp;&nbsp;&nbsp;先剪掉地上部分再种，是有原因的。移栽会切断根部，吸水能力大幅下降，若此时叶子还保留原样，叶片蒸发出去的水分会超过吸进来的，株就会因此枯萎。减少叶片就能让这个平衡重新成立。这和移栽树木时要剪掉枝条是同一个道理。

&nbsp;&nbsp;&nbsp;不让生长点被埋住也很重要。韭菜的生长点位于鳞茎上方、叶片开始长出的地方。这个部位如果被埋得太深，新叶就要费力才能顶破土层，甚至会直接腐烂。标准做法是根部埋入土中，而生长点与地表齐平。

&nbsp;&nbsp;&nbsp;之所以要3-5株捆成一丛种植，是因为韭菜是成丛生长的植物。单株分开种，扎根需要很长时间；多株在一起，则能相互支撑，更快形成一定的势头。这一丛长大后，几年后又会成为再次分株的材料。

### 6-3. 播种

| 项目 | 标准 |
|---|---|
| 播种深度 | 0.5-1cm |
| 发芽天数 | 20℃下7-14天 |
| 发芽温度 | 20℃左右，10℃以下不发芽 |
| 行距 | 20cm |
| 每穴 | 2-3粒 |
| 第一次间苗 | 真叶2-3片，间距5cm |
| 第二次间苗 | 真叶4-5片，最终间距15-20cm |
| 第一年管理 | 不割取，只养根 |

&nbsp;&nbsp;&nbsp;韭菜种子发芽慢且不整齐。播种两周后仍不见任何动静，误以为失败又重新播种的情况很常见，但大多数时候只是还在发芽途中。要保持表土湿润，耐心等到3周为止。

&nbsp;&nbsp;&nbsp;还要记住种子的新鲜度是决定性的。正如种子寿命D所示，韭菜种子在常温下撑不过一年。上一年留的种子发芽率会大幅下降，隔了两年的种子几乎不发芽。如果必须从种子起步，就要使用当年留的或当年获取的种子。

### 6-4. 种子处理

| 方法 | 步骤 | 效果 |
|---|---|---|
| 温水浸种 | 浸入50-55℃的水中10-15分钟后，用冷水冷却 | 可杀灭表面病原菌 |
| 拌灰 | 把过筛的草木灰粘裹在湿种子表面 | 兼具表面消毒的作用 |
| 浸水 | 常温水中浸泡一夜 | 可使发芽提早几天 |

&nbsp;&nbsp;&nbsp;温水浸种，温度就是一切。超过60℃种子会死，低于45℃则杀不了菌。没有温度计的话，用大约一半沸水一半冷水混合，手伸进去感觉烫但能忍受的程度大致就是50℃左右。不过凭感觉处理有可能损失全部种子，因此比较安全的做法是只处理手头种子的一部分，分批种植。

## 7. 水分管理

### 7-1. 各生长阶段的水分管理

| 时期 | 管理 | 备注 |
|---|---|---|
| 种植后立即 | 充分浇一次 | 让根与土壤紧密贴合 |
| 扎根期（2-3周） | 表土干了就浇 | 是根部扎稳的时期 |
| 生长期 | 每周1-2次，每次浇透 | 浅而频繁的浇水会使根变浅 |
| 割取后立即 | 隔一天再浇一次 | 待割口愈合后再浇 |
| 梅雨季 | 不浇水 | 这个时期的水分管理就是整修排水沟 |
| 越冬期 | 不浇水 | 湿土结冰会伤根 |

&nbsp;&nbsp;&nbsp;割取后不马上浇水，是有原因的。割叶留下的切口是敞开的伤口，水会连同病菌一起从伤口进入。菌核病和软腐病之所以多在割取后不久发生，正是因为这个。安全的做法是放置一天左右，等伤口干燥愈合之后再浇水或施肥。雨天避免割取，也是同样的道理。

### 7-2. 缺水与积水的症状

| 症状 | 原因 | 会发生什么 |
|---|---|---|
| 叶尖枯萎、变细 | 缺水 | 之后能恢复，但这片叶子已无法复原 |
| 叶片短且韧 | 长期缺水 | 纤维增多，口感变差 |
| 叶片突然发黄倒伏 | 积水、烂根 | 地下部分已经受损 |
| 根基处出现白色霉丝和黑色颗粒 | 菌核病 | 菌核会留在土里，持续多年 |
| 叶基变软并发臭 | 软腐病 | 病菌是从割取的伤口侵入的 |
| 根部附近有细小的白色蛆虫 | 根蛆 | 由未腐熟堆肥和积水引起 |

&nbsp;&nbsp;&nbsp;这份表格下面四行全都和积水有关，这说明了韭菜水分管理的特性。缺水最多只是叶子变小，而积水过多则会让整株彻底消失。损害的程度是不对称的。因此在管理韭菜时，宁可偏干一些才安全，这也是它与其他叶菜类不同的地方。

### 7-3. 覆盖

&nbsp;&nbsp;&nbsp;在没有塑料薄膜的情况下，覆盖材料可以用稻草、干草、落叶、稻壳。对韭菜而言，覆盖在夏季和冬季各起着不同的作用。

&nbsp;&nbsp;&nbsp;夏季覆盖的主要目的是抑制杂草。韭菜地5年内不翻耕，杂草会不断积累，长在韭菜株之间的杂草根系纠缠在一起，很难拔除。用稻草覆盖株间的沟，能大大减少这个问题。但如果盖在韭菜株上方，会导致通风变差而招致病害，因此只应铺在沟里。

&nbsp;&nbsp;&nbsp;冬季覆盖的目的是保温隔热。11月地上部分枯萎后，可以不割掉枯叶直接留着，或者铺上5-10cm厚的稻草和落叶。这种作物能耐零下20度，不会被冻死，但反复冻融会使土壤松动拱起，导致根部被顶到地表，造成冻拔害。覆盖物能防止这种情况。春天新芽长出前把覆盖物撤掉，地温回升更快，收获也能提前几天。
