## 2. どんな植物か

### 2-1. 分類と近縁種

| 項目 | 内容 |
|:---|:---|
| 学名 | Beta vulgaris subsp. cicla |
| 科 | ヒユ科（アカザ科が統合されました） |
| 属 | フダンソウ属（Beta） |
| 同じ種 | ビーツ（赤フダンソウとは別物です）、テンサイ、飼料用ビート、野生のビート |
| 生活史 | 二年生 |
| 別名 | スイスチャード、フダンソウのナムル、白フダンソウ |

&nbsp;&nbsp;&nbsp;フダンソウとビーツとテンサイが同じ種であるという事実は、栽培と採種の両面で重要です。栽培では、病害虫と連作障害を共有するという意味であり、採種では、花粉が互いにやり取りされるという意味です。この三つの作物は、一つのグループとしてまとめて管理しなければなりません。

&nbsp;&nbsp;&nbsp;ホウレンソウも同じヒユ科に入ります。属が違うので交雑はしませんが、病害をかなりの部分で共有するため、輪作では一緒に計算します。

&nbsp;&nbsp;&nbsp;祖先は、地中海や大西洋沿岸の海辺に生えていた野生のビート（Beta vulgaris subsp.maritima）です。塩分を含む砂地や断崖に生えていた植物で、その出自がフダンソウの性格をほぼすべて説明します。ナトリウムに耐える能力、やせた土でも持ちこたえる太くて深い根、暑さと寒さの両方に耐える幅広い適応性は、いずれもその海辺に由来します。

### 2-2. 耐塩性はどのように働くのか

&nbsp;&nbsp;&nbsp;ほとんどの植物が塩分に弱い理由は二つあります。第一に、土に塩分が多いと、浸透圧のために根が水を吸い上げられなくなります。土が湿っていても、植物は喉が渇いてしおれます。第二に、細胞内に入り込んだナトリウムが酵素の働きを妨げます。細胞が化学的に損なわれるのです。

&nbsp;&nbsp;&nbsp;フダンソウ属の植物は、この二つの問題をそれぞれ解決しました。吸収したナトリウムを、細胞内の液胞、つまり大きな水袋に閉じ込めて、細胞質から隔離します。酵素のある細胞質はきれいに保たれ、液胞にたまったナトリウムは、むしろ細胞全体の浸透圧を高めて、土から水を引き寄せる力になります。ほかの植物にとっては毒であるものを、自分のものに変えたようなものです。

| 作物 | 耐塩限界（土壌電気伝導度基準） | 備考 |
|:---|:---|:---|
| フダンソウ、ビーツ、テンサイ | 非常に高い | 葉菜の中で最上位クラス |
| オオムギ | 高い | 穀物の中で最も強いです |
| ホウレンソウ | 中程度 | 同じ科ですが、フダンソウより弱いです |
| サンチュ、ハクサイ、ダイコン | 低い | 塩害地では育ちません |
| 豆類 | 非常に低い | 真っ先に枯れます |

> **津波や浸水で塩分を含んだ土地、地下水灌漑で塩類がたまった畑で、フダンソウはほぼ唯一生き残る葉菜です。その土地でビタミンとミネラルを供給できるかどうかが、この作物の存在理由です。**

&nbsp;&nbsp;&nbsp;ただし、耐塩性が無限ではないという点は、はっきりさせておく必要があります。塩分がきわめて高いと、フダンソウでも生育が落ち、葉が小さくなります。耐えるというのは、枯れずに何かを収穫できるという意味であって、普段どおりに育つという意味ではありません。塩害地では、収穫量が減ることを見込んで面積を広めにとります。そして、雨水が土の塩分を下へ洗い流すため、排水のよい状態をつくっておけば、年を追うごとに条件がよくなります。畝を立てると塩分が畝の表面に上がってきて集まるので、畝間に植えて畝の肩を空けておく配置が、塩害地では有利です。

### 2-3. 外観と生育段階

| 器官 | 特徴 |
|:---|:---|
| 葉 | 幅の広い卵形で光沢があり、葉脈が太くはっきりしています。葉面はでこぼこと縮れています |
| 葉柄 | 太くて水分が多いです。白、赤、黄、ピンクと、品種によって異なります |
| 茎 | 圧縮されてほとんどなく、葉が株元から放射状に出ます |
| 根 | 直根が深く下ります。ビーツと違って肥大せず、細いです |
| 花 | 2年目に花茎が立ち、緑色の小さな花が穂状につきます |
| 果実 | 複数の種子が集まった種子球（seed ball） |

| 段階 | 時期 | 起こること |
|:---|:---|:---|
| 発芽 | 播種後7-14日 | 種子球一つから複数の芽が一緒に出ます |
| 幼苗期 | 発芽後2週間 | 本葉2-3枚。1回目の間引きの時期 |
| 栄養成長期 | 播種後3-7週間 | 葉が急速に大きくなります |
| 初回収穫 | 播種後40-60日 | 外側の葉が20-30cm |
| 繰り返し収穫期 | その後ずっと | 外側から摘むと、中心から新しい葉が上がってきます |
| 抽だい | 翌年の春 | 低温を経験したあとに花茎が立ちます |

&nbsp;&nbsp;&nbsp;フダンソウの生長点は、圧縮された茎の先端、株の真ん中に一つあります。そこから新しい葉が次々に上がってきて、外側へ押し出されていきます。したがって、外側の十分に育った葉を摘み取っても、植物は古くなった葉を失うだけで、生長点はそのまま残ります。これが永続性Aの構造的な根拠であり、第12節で詳しく扱います。

&nbsp;&nbsp;&nbsp;葉柄が太くて水分が多いことが、フダンソウの特徴です。葉だけを食べるほかの葉菜と違い、フダンソウは葉柄が別個の食材になります。歯ごたえはしゃきしゃきとしていて、加熱すると柔らかくなり、葉より重さがあるため、収穫量に実質的に貢献します。

### 2-4. 100gあたりの栄養

| 成分 | 含有量 | 備考 |
|:---|:---:|:---|
| 熱量 | 18kcal | 低いです |
| 水分 | 90%以上 | |
| タンパク質 | 1.78g | 熱量に占める割合が39.6%と非常に高いです |
| 炭水化物 | 3.5-4.0g | |
| 食物繊維 | 1.5-2.0g | |
| 糖類 | 0.00g | 甘みがほとんどありません |
| ビタミンA | 豊富 | 濃い緑色の葉に集中しています |
| ビタミンC | 豊富 | 下茹でするとかなりの量を失います |
| ビタミンE | 含有 | |
| ビタミンK | 非常に豊富 | 葉菜の中で上位クラス |
| 葉酸 | 豊富 | |
| カルシウム | 豊富 | シュウ酸のため吸収率は低いです |
| 鉄 | 豊富 | 同じ理由で吸収率が制限されます |
| カリウム | 豊富 | |
| マグネシウム | 豊富 | |
| シュウ酸 | 高い | 第14節で扱います |

&nbsp;&nbsp;&nbsp;カルシウムと鉄が豊富なのに吸収率が低いという点が、フダンソウの栄養の核心です。成分表に書かれた量が、そのまま体に入るわけではありません。シュウ酸がカルシウムと結合して水に溶けない結晶をつくり、その結晶は吸収されず、そのまま排出されます。鉄も、一部は同じ影響を受けます。

&nbsp;&nbsp;&nbsp;そのため、フダンソウをカルシウム供給源として計算するのは正確ではありません。カルシウムが必要なら、シュウ酸の少ないケールのほうがはるかによい選択です。フダンソウの強みはビタミンK、ビタミンA、葉酸の側にあり、これらはシュウ酸の影響を受けません。

&nbsp;&nbsp;&nbsp;糖類0.00gという成分値も目を引きます。甘みがまったくないという意味ですが、それでも味の等級がSなのは、においと食感に抵抗感がないからです。淡白であることは、災害時にはむしろ長所になります。香りの強い野菜は数日で飽きてしまいますが、淡白なものは毎日食べても飽きません。

## 3. 栽培環境――耐塩性という武器

### 3-1. 温度

| 区分 | 温度 | 備考 |
|:---|:---:|:---|
| 生育範囲 | 5-30℃ | 幅25℃で葉菜の最上位クラス |
| 生育適温 | 15-18℃ | 昼間23-25℃、夜間は最低5-6℃ |
| 発芽適温 | 20-25℃ | 10℃以上でも発芽します |
| 発芽限界 | 10℃未満、35℃超 | |
| 高温耐性 | 30℃まで育ちます | 葉が少し硬くなります |
| 低温耐性 | 氷点下5℃まで生育を維持 | わらをかけるとさらに耐えます |

&nbsp;&nbsp;&nbsp;フダンソウの温度特性で最も実用的なのは、夏を越せるという点です。サンチュと玉レタスが25℃で崩れ、アブラナ科の葉菜も夏に病害虫で崩れるなか、フダンソウは30℃まで育ちます。真夏に畑に緑のものが残っているかという問題で、フダンソウは、スベリヒユ、ヨウサイ（空芯菜）とともに、答えになる数少ない作物です。

&nbsp;&nbsp;&nbsp;ただし、高温期の葉は硬くなり、シュウ酸が増えます。夏のフダンソウは、生で食べるより下茹でして食べるほうが適しており、水を十分に与えると、硬くなる程度が軽くなります。半日陰をつくってやると、葉が柔らかく保たれます。

&nbsp;&nbsp;&nbsp;低温側では、氷点下5℃まで生育を維持します。霜に当たっても葉が枯れず、韓国中部以南では、わらや落ち葉をかけると越冬します。冬は成長を止めますが、残っている葉を一枚ずつ摘んで食べることができ、春が来ればまた葉を出します。ただし、低温を経験すると春化が起こり、翌年の春に花茎が立つため、越冬させた株は春に長くはもちません。

### 3-2. 光と日陰

| 項目 | 基準 |
|:---|:---|
| 必要日照 | 1日6時間以上 |
| 半日陰 | 耐えます。生育は遅くなりますが、葉は柔らかいです |
| 40%遮光 | 相対収量86%（信頼区間 61-120） |
| 夏の遮光 | 葉が硬くなるのを遅らせます |

&nbsp;&nbsp;&nbsp;フダンソウが半日陰に耐えるという点は、都市環境や狭い庭で実質的な意味があります。建物の影、塀の北側、背の高い作物の間のように、日が半日しか当たらない場所でも、フダンソウは育ちます。育つ速度は遅くなり、葉も少し薄くなりますが、食べるものは収穫できます。サンチュも日陰には耐えますが夏に枯れてしまい、フダンソウは夏にも生きているという点が違います。

### 3-3. 水と土壌

| 項目 | 基準 | 備考 |
|:---|:---|:---|
| 総蒸発散量 | 約500mm | サンチュの350mmより多いです |
| 灌水 | 表土が乾いたらたっぷりと | 根が深いため、干ばつにはサンチュより強いです |
| 過湿 | 根腐れ | 畝を立てます |
| 土壌 | 選びません | 有機物が多いとより良いです |
| 土壌酸度 | pH 6.0-6.8 | 6.5付近が最もよいです |
| 耐塩性 | 非常に高いです | 塩害地で使えます |

&nbsp;&nbsp;&nbsp;総蒸発散量500mmはサンチュより多いですが、二つの事情を合わせて見る必要があります。第一に、フダンソウは栽培期間が長いために総量が積み上がっただけで、1日の水の要求量が特に大きいわけではありません。第二に、フダンソウの根はまっすぐ深く下ります。サンチュの浅い根は、表土が乾くとすぐにしおれますが、フダンソウは下のほうの水を引いて使います。干ばつが来たときに実際に持ちこたえる力は、フダンソウのほうが優れています。

&nbsp;&nbsp;&nbsp;土壌を選ばないことも、実質的な長所です。砂地でも育ち、粘土質でも育ちます。ただし、水がたまるのは嫌うので、畝を立てて排水溝を設けます。塩害地では、先に見たとおり、畝間に植えて塩分が畝の肩に上がるようにする配置が有利です。

&nbsp;&nbsp;&nbsp;pHは6.0-6.8、6.5付近を好みます。酸性が強い畑では生育が落ちるため、草木灰や、貝殻を焼いた粉、卵の殻の粉で上げます。フダンソウはホウ素を比較的多く必要とする作物で、pHが高すぎるとホウ素が吸収されず、葉が裂けて芯が黒くなる症状が出ます。石灰を一度に多く入れない理由が、ここにあります。

## 4. 品種

### 4-1. 色で分かれる品種

| 品種 | 葉柄の色 | 特徴 |
|:---|:---|:---|
| 青フダンソウ（白フダンソウ） | 白から黄緑 | 最も一般的で収量が安定しており、食感に弾力があります |
| 赤フダンソウ | 赤からピンク | アントシアニンが多いです。葉は柔らかいです |
| 黄フダンソウ | 黄色から黄緑 | βカロテンが多いです。葉は柔らかいです |
| フォードフック | 白 | 代表的な白色品種。葉が大きくて厚いです |
| ルビー | 赤 | 赤系統の代表品種。耐寒性が良好です |
| レインボー系統 | 複数の色が混ざる | 複数の色の品種を混ぜた種子です |

&nbsp;&nbsp;&nbsp;フダンソウの品種選びで知っておきたいのは、色の違いが栽培の難易度や収量にあまり影響しないという点です。どの品種でも育てやすく、収量は同程度です。色は主に、栄養成分の構成と食感に関係します。

&nbsp;&nbsp;&nbsp;ただし、災害時に色が持つ別の意味が一つあります。赤色と黄色の葉柄は、それぞれアントシアニンとベタキサンチンという色素を含んでおり、これらの色素は抗酸化物質です。白い品種にはない成分です。複数の色を混ぜて植えると、同じ面積から得られる成分の種類が増えます。労力や資源を余計に使わずに栄養の幅を広げる方法である点で、価値があります。

### 4-2. 状況別の選択

| 状況 | 選択 | 理由 |
|:---|:---|:---|
| 収量が最優先 | 青フダンソウ、フォードフック | 葉が大きく、葉柄が太いです |
| 栄養の幅を広げたいとき | 赤フダンソウと黄フダンソウを混ぜて | 色素成分が加わります |
| 越冬を狙うとき | ルビー、フォードフック | 耐寒性が優れています |
| 塩害地 | どの品種でも | 種全体が耐塩性を持っています |
| 夏の栽培 | どの品種でも | すべて30℃まで耐えます |
| 種を採り続ける計画 | 固定種 | 交配種は形質がばらつきます |

&nbsp;&nbsp;&nbsp;フダンソウは、品種選びが成否を分けない数少ない作物です。玉レタスで、品種と時期の選択が結球の成否を左右したのとは対照的です。入手できる種子が何であれ、植えれば育ちます。これ自体が、災害時の一つの長所です。選択の余地がない状況では、選択が必要ない作物は、それだけ失敗の余地もありません。
