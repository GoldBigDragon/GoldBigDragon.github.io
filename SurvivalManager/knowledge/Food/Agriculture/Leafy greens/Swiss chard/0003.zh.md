## 2. 这是一种什么样的植物

### 2-1. 分类与近缘种

| 项目 | 内容 |
|:---|:---|
| 学名 | Beta vulgaris subsp. cicla |
| 科 | 苋科（藜科已并入） |
| 属 | 甜菜属（Beta） |
| 同种 | 红菜头（与红莙荙菜不同）、甜菜、饲用甜菜、野生甜菜 |
| 生活史 | 二年生 |
| 别名 | 瑞士甜菜、莙荙菜凉拌野菜（namul）、白莙荙菜 |

&nbsp;&nbsp;&nbsp;莙荙菜、红菜头和甜菜是同一个种，这一事实对栽培和留种都很重要。在栽培上，意味着它们共有病虫害和连作障碍；在留种上，意味着花粉会相互传播。这三种作物必须归为一类来管理。

&nbsp;&nbsp;&nbsp;菠菜也属于同一个苋科。属不同，所以不会杂交，但相当一部分病害是共有的，因此在轮作中要一并计算。

&nbsp;&nbsp;&nbsp;其祖先是生长在地中海和大西洋沿岸海边的野生甜菜（Beta vulgaris subsp.maritima）。它是生活在含盐沙地和悬崖上的植物，这样的出身几乎解释了莙荙菜的全部特性。耐受钠的能力、在贫瘠土壤中坚持生长的粗壮深根、既耐热又耐寒的广泛适应性，都来自那片海边。

### 2-2. 耐盐性是如何起作用的

&nbsp;&nbsp;&nbsp;大多数植物怕盐分的原因有两个。第一，土壤盐分多时，由于渗透压的关系，根无法吸水。即使土壤是湿的，植物也会因干渴而枯萎。第二，进入细胞内的钠会妨碍酶的作用。细胞会在化学层面遭到破坏。

&nbsp;&nbsp;&nbsp;甜菜属植物分别解决了这两个问题。它把吸收的钠封存在细胞内的液泡，也就是大水囊中，使其与细胞质隔离。含有酶的细胞质得以保持洁净，而积聚在液泡中的钠反倒提高了整个细胞的渗透压，成为从土壤中吸水的动力。可以说，它把对别人是毒药的东西变成了自己的资源。

| 作物 | 耐盐极限（以土壤电导率为标准） | 备注 |
|:---|:---|:---|
| 莙荙菜、红菜头、甜菜 | 很高 | 叶菜中处于最高水平 |
| 大麦 | 高 | 谷物中最强 |
| 菠菜 | 中等 | 同科，但比莙荙菜弱 |
| 生菜、大白菜、萝卜 | 低 | 无法在盐害地生长 |
| 豆类 | 很低 | 最先死亡 |

> **在因海啸或淹水而含盐的土地、因地下水灌溉而积聚盐类的田里，莙荙菜是几乎唯一留存下来的叶菜。能否在那样的土地上提供维生素和矿物质，就是这种作物存在的理由。**

&nbsp;&nbsp;&nbsp;不过需要明确的是，耐盐性并不是无限的。盐分极高时，莙荙菜的生长也会下降，叶片变小。所谓耐受，是指不死、还能产出一些东西，并不是说能长得和平时一样好。在盐害地要考虑到收获量会减少，把面积留得大一些。而且雨水会把土壤中的盐分向下冲刷，所以只要把排水条件做好，条件会逐年好转。起垄后盐分会上升聚集到垄的表面，因此在盐害地，把苗种在沟里、把垄肩空出来的布置更有利。

### 2-3. 形态与生长阶段

| 器官 | 特征 |
|:---|:---|
| 叶 | 宽卵形，有光泽，叶脉粗而清晰。叶面凹凸皱褶 |
| 叶柄 | 厚实多汁。有白色、红色、黄色、粉色，因品种而异 |
| 茎 | 被压缩得几乎看不见，叶片从基部呈放射状长出 |
| 根 | 直根向深处延伸。与红菜头不同，不膨大，较细 |
| 花 | 第二年抽出花茎，绿色小花呈穗状着生 |
| 果实 | 由多粒种子聚成的种子球（seed ball） |

| 阶段 | 时期 | 发生的事情 |
|:---|:---|:---|
| 发芽 | 播种后7-14天 | 一个种子球会同时长出多个芽 |
| 幼苗期 | 发芽后2周 | 真叶2-3片。第1次间苗的时期 |
| 营养生长期 | 播种后3-7周 | 叶片迅速长大 |
| 首次收获 | 播种后40-60天 | 外叶20-30cm |
| 反复收获期 | 此后持续 | 从外侧采摘，中心会长出新叶 |
| 抽薹 | 翌年春季 | 经历低温后抽出花茎 |

&nbsp;&nbsp;&nbsp;莙荙菜的生长点在被压缩的茎顶端、植株正中央，只有一个。新叶不断从那里长出，把旧叶推向外侧。因此，把外侧长足的叶片摘掉，植物只是失去已经变老的叶片，生长点原样保留。这就是持续性A的结构性依据，将在第12节中详细介绍。

&nbsp;&nbsp;&nbsp;叶柄厚实多汁，是莙荙菜的特点。与只吃叶片的其他叶菜不同，莙荙菜的叶柄可以单独成为一种食材。口感脆嫩，煮熟后变软，而且比叶片重，因此对收获量有实质性的贡献。

### 2-4. 每100g的营养

| 成分 | 含量 | 备注 |
|:---|:---:|:---|
| 热量 | 18kcal | 低 |
| 水分 | 90%以上 | |
| 蛋白质 | 1.78g | 占热量的比例为39.6%，非常高 |
| 碳水化合物 | 3.5-4.0g | |
| 膳食纤维 | 1.5-2.0g | |
| 糖类 | 0.00g | 几乎没有甜味 |
| 维生素A | 丰富 | 集中在深绿色的叶片中 |
| 维生素C | 丰富 | 焯水后会损失相当一部分 |
| 维生素E | 含有 | |
| 维生素K | 非常丰富 | 在叶菜中处于上位 |
| 叶酸 | 丰富 | |
| 钙 | 丰富 | 因草酸，吸收率低 |
| 铁 | 丰富 | 出于同样的原因，吸收率受限 |
| 钾 | 丰富 | |
| 镁 | 丰富 | |
| 草酸 | 高 | 在第14节中介绍 |

&nbsp;&nbsp;&nbsp;钙和铁含量丰富但吸收率低，这是莙荙菜营养的关键所在。成分表上写的量并不会原样进入人体。草酸与钙结合，形成不溶于水的结晶，这种结晶不会被吸收，而是原样排出体外。铁也有一部分受到同样的影响。

&nbsp;&nbsp;&nbsp;所以，把莙荙菜当作钙的供给来源来计算并不准确。如果需要钙，草酸含量少的羽衣甘蓝是好得多的选择。莙荙菜的优势在于维生素K、维生素A和叶酸，而它们不受草酸影响。

&nbsp;&nbsp;&nbsp;糖类0.00g这一成分数值也引人注目。它意味着完全没有甜味，但口味等级仍然是S，是因为气味和口感都没有令人排斥之处。味道平淡，在灾害情境下反而成了优点。香气浓烈的蔬菜吃几天就腻了，而平淡的蔬菜天天吃也不会厌倦。

## 3. 栽培环境——耐盐性这一利器

### 3-1. 温度

| 类别 | 温度 | 备注 |
|:---|:---:|:---|
| 生长范围 | 5-30℃ | 幅度25℃，在叶菜中处于最高水平 |
| 生长适温 | 15-18℃ | 白天23-25℃，夜间最低5-6℃ |
| 发芽适温 | 20-25℃ | 10℃以上也能发芽 |
| 发芽极限 | 低于10℃，高于35℃ | |
| 耐高温 | 可生长到30℃ | 叶片会稍微变韧 |
| 耐低温 | 零下5℃仍能维持生长 | 盖上稻草更耐寒 |

&nbsp;&nbsp;&nbsp;莙荙菜温度特性中最实用的一点是能够度夏。生菜和结球生菜在25℃就垮掉，十字花科叶菜在夏季也会因病虫害而垮掉，而莙荙菜能生长到30℃。在盛夏田里还能不能留有绿色这个问题上，莙荙菜与马齿苋、蕹菜（空心菜）一起，是能给出答案的为数不多的作物。

&nbsp;&nbsp;&nbsp;不过高温期的叶片会变韧，草酸也会增加。夏季的莙荙菜与其生吃，不如焯水后食用更合适，水浇得充足的话，变韧的程度会轻一些。给它创造半阴的条件，叶片就能保持柔嫩。

&nbsp;&nbsp;&nbsp;在低温方面，零下5℃仍能维持生长。遇到霜冻叶片也不会死亡，在韩国中部以南地区，盖上稻草和落叶就能越冬。冬季虽然停止生长，但仍可以把现有的叶片一片一片摘来吃，春天来临后又会重新长叶。不过经历低温后会发生春化，翌年春天抽出花茎，所以越冬的植株在春天撑不了多久。

### 3-2. 光照与遮荫

| 项目 | 标准 |
|:---|:---|
| 所需日照 | 每天6小时以上 |
| 半阴 | 能耐受。生长变慢，但叶片柔嫩 |
| 40%遮光 | 相对产量86%（置信区间61-120） |
| 夏季遮光 | 延缓叶片变韧 |

&nbsp;&nbsp;&nbsp;莙荙菜能耐半阴这一点，对城市环境或狭小的院子有实际意义。在建筑物的阴影里、围墙北侧、高秆作物之间这类只有半天日照的地方，莙荙菜也能生长。生长速度会变慢，叶片稍微变薄，但还是有可吃的东西产出。生菜也能耐阴，但夏天会死，而莙荙菜夏天也活着，这是它们的区别。

### 3-3. 水分与土壤

| 项目 | 标准 | 备注 |
|:---|:---|:---|
| 总蒸散量 | 约500mm | 比生菜的350mm多 |
| 灌水 | 表土干了就浇透 | 根深，耐旱性比生菜强 |
| 过湿 | 烂根 | 起垄 |
| 土壤 | 不挑 | 有机质多更好 |
| 土壤酸度 | pH 6.0-6.8 | 6.5左右最好 |
| 耐盐性 | 很高 | 可用于盐害地 |

&nbsp;&nbsp;&nbsp;总蒸散量500mm比生菜多，但需要同时看两点情况。第一，莙荙菜的栽培期长，总量是累积起来的，并不是每天的需水量特别大。第二，莙荙菜的根笔直且向深处延伸。生菜的浅根在表土干了之后很快就会萎蔫，而莙荙菜能吸取下层的水。遇到干旱时，真正撑得住的是莙荙菜。

&nbsp;&nbsp;&nbsp;不挑土壤也是实实在在的优点。沙地能长，黏土也能长。不过它不喜欢积水，所以要起垄并开挖排水沟。在盐害地，如前面所见，种在沟里、让盐分升到垄肩的布置更有利。

&nbsp;&nbsp;&nbsp;pH喜欢6.0-6.8，6.5左右。酸性严重的田里生长会下降，所以用草木灰、烧过的贝壳粉、蛋壳粉来提高pH。莙荙菜是对硼需求较多的作物，pH过高时硼无法被吸收，会出现叶片开裂、心部发黑的症状。这就是不一次性大量施用石灰的原因。

## 4. 品种

### 4-1. 按颜色区分的品种

| 品种 | 叶柄颜色 | 特点 |
|:---|:---|:---|
| 青莙荙菜（白莙荙菜） | 白色至浅绿色 | 最常见，产量稳定，口感有嚼劲 |
| 红莙荙菜 | 红色至粉红色 | 花青素多。叶片柔嫩 |
| 黄莙荙菜 | 黄色至浅绿色 | β-胡萝卜素多。叶片柔嫩 |
| Fordhook | 白色 | 代表性的白色品种。叶片大而厚 |
| Ruby | 红色 | 红色系的代表品种。耐寒性好 |
| 彩虹系 | 多种颜色混合 | 是把多种颜色的品种混合而成的种子 |

&nbsp;&nbsp;&nbsp;选择莙荙菜品种时需要了解的是，颜色差异对栽培难度和产量没有太大影响。无论哪个品种都容易栽培，产量也相近。颜色主要与营养成分的构成和口感有关。

&nbsp;&nbsp;&nbsp;不过，在灾害情境下，颜色还有另一层意义。红色和黄色的叶柄分别含有花青素和甜菜黄素这两种色素，这些色素都是抗氧化物质。白色品种则没有这些成分。把多种颜色混合种植，同样面积上获得的成分种类就会增加。这是一种不多花劳力和资源就能拓宽营养范围的方法，这一点很有价值。

### 4-2. 按情境选择

| 情境 | 选择 | 理由 |
|:---|:---|:---|
| 产量优先 | 青莙荙菜、Fordhook | 叶片大，叶柄厚 |
| 想拓宽营养范围时 | 混合红莙荙菜和黄莙荙菜 | 增加色素成分 |
| 想让其越冬时 | Ruby、Fordhook | 耐寒性较好 |
| 盐害地 | 任何品种 | 整个种都具有耐盐性 |
| 夏季栽培 | 任何品种 | 都能耐受到30℃ |
| 打算连续留用种子 | 固定品种 | 杂交种的性状会分离 |

&nbsp;&nbsp;&nbsp;莙荙菜是少数几种品种选择不决定成败的作物。这与结球生菜中品种和时期的选择左右结球成败形成对比。无论能弄到什么种子，种下去就能长。这本身就是灾害情境下的一个优点。在没有选择余地的情况下，不需要选择的作物，失败的余地也就相应地少。
