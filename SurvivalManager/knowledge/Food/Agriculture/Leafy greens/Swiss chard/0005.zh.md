## 8. 栽培管理

### 8-1. 不太费工的作物

| 作业 | 是否必要 | 内容 |
|:---|:---|:---|
| 间苗 | 必需 | 因种球之故，必须进行 |
| 除草 | 仅限初期 | 叶片覆盖地面后，杂草就会受到抑制 |
| 培土 | 一般不需要 | 栽培时间长时，在基部轻轻盖上一层土 |
| 摘心 | 不需要 | 不会长出侧枝 |
| 支柱 | 不需要 | 植株矮小 |
| 摘花 | 抽薹时 | 花茎抽出后剪掉，可以争取时间 |
| 清理枯叶 | 随时 | 摘除下部发黄干枯的叶片 |

&nbsp;&nbsp;&nbsp;莙荙菜的栽培管理清单很短。间苗、浇水和采叶几乎就是全部，其余只在需要时才做。十字花科作物得在防虫网和捉虫上耗费精力，结球生菜则要为满足结球条件而争抢时机，相比之下，莙荙菜省工很多。灾害情境下劳动力是最宝贵的资源，所以这一差别在实际中影响很大。

&nbsp;&nbsp;&nbsp;除草只在初期需要。莙荙菜长大后，叶片覆盖地面，光线照不到下面，杂草便受到抑制。幼苗期只要不让杂草压住它，之后它自己就能守住地盘。不过也有根系较浅的部分，所以在靠近植株的地方不要深锄，用手拔除即可。

&nbsp;&nbsp;&nbsp;摘除下部发黄干枯的叶片，最好还是做一下。濒死的组织会成为灰霉病的温床，其下方也会变潮湿，引来蛞蝓。摘除时握住叶柄向侧面掰，让它干净利落地从茎上脱落。

### 8-2. 应对抽薹的方法

&nbsp;&nbsp;&nbsp;莙荙菜是二年生植物，正常情况下在翌年春天抽出花茎。经历低温是触发因素，这被称为春化。问题在于，这种春化有可能比预期更早发生。

| 条件 | 结果 |
|:---|:---|
| 幼苗长时间经历10℃以下的低温 | 当年内就会抽出花茎 |
| 早春播种后遇倒春寒 | 会发生同样的情况 |
| 越冬后的春天 | 正常抽薹。那一株就此结束 |
| 极度干旱或高温胁迫 | 抽薹可能提前 |

&nbsp;&nbsp;&nbsp;花茎抽出后，叶片变韧，并带上苦味。这是因为植物的优先级从叶转向种子，叶中的养分流向花茎，同时组织中积累了木质素。这种转变无法逆转。

&nbsp;&nbsp;&nbsp;不过，剪掉花茎可以稍微争取一些时间。在花茎刚开始长出时，从靠近基部处剪掉，植株会再次长叶，这期间还能多收获几周。很快又会有别的花茎长出来，所以并非彻底解决，但作为稍微延长采收季节的办法还算可用。只留下要采种的植株，其余都这样处理。

> **要防止早春播种的植株抽出花茎，就不要让幼苗长时间经历低温。要等霜完全过去之后再播种；如果提前播种，则覆盖稻草或干草来保持地温。已经抽出的花茎无法挽回。**

### 8-3. 让一株用得更久的管理

| 项目 | 内容 |
|:---|:---|
| 采叶后 | 浇水。长出新叶需要水分 |
| 补充养分 | 新叶变小时，施入稀薄的肥料 |
| 保留的叶片 | 始终保留中心的6片以上叶片 |
| 夏季 | 提供半阴环境，叶片可保持柔嫩 |
| 秋季 | 覆盖稻草，为越冬做准备 |
| 冬季 | 把现有的叶片一片一片摘来吃。几乎不再长新叶 |

&nbsp;&nbsp;&nbsp;想把莙荙菜用过一年以上，关键在于怎样熬过冬天。在韩国中部及以南地区，给基部培土，再盖上稻草和落叶，一般都能存活。在韩国中部以北地区可能失败，那样的话，就把计划改为秋季播种、入冬前收完。

&nbsp;&nbsp;&nbsp;成功越冬的植株春天会再次长叶，但持续不了多久。因为冬季的低温起到春化作用，春天很快就会抽出花茎。所以，越冬植株春季的收获应当看作只有几周的额外收获，从那一株上采种后再重新播种，这样的流程才对。

## 9. 病虫害 - 不用药的防治方法

&nbsp;&nbsp;&nbsp;评价表“防治自立度”的依据中写的“几乎不需要防治”这句话，就是本节的概括。莙荙菜属于最容易不用药栽培的叶菜之一。原因在于它所属的科。

| 作物类群 | 主要害虫 | 会来莙荙菜上吗 |
|:---|:---|:---|
| 十字花科 | 菜粉蝶、小菜蛾、跳甲、根肿病 | 不会来 |
| 菊科 | 菌核病、霜霉病 | 不会来 |
| 茄科 | 疫病、烟青虫 | 不会来 |
| 苋科（莙荙菜自身） | 蚜虫、叶螨、叶甲 | 会来 |

&nbsp;&nbsp;&nbsp;给田里带来最大病虫害压力的是十字花科和菊科。这是因为越冬泡菜腌制（kimjang）用的蔬菜和叶菜集中在这两大类里。莙荙菜不属于任何一边，处在摆脱了这种压力的位置。即使在大白菜被虫子啃食的年份，莙荙菜也安然无恙。

### 9-1. 主要病害

| 病害 | 症状 | 发生条件 | 不用药的应对 |
|:---|:---|:---|:---|
| 褐斑病 | 叶上出现褐色圆形斑点，中央变为灰色 | 高温高湿 | 摘除病叶、通风、轮作 |
| 霜霉病 | 叶背有白色霉层，叶面发黄 | 凉爽潮湿时 | 通风、早晨浇水、摘除病叶 |
| 白粉病 | 叶面出现白色粉状物 | 干燥且昼夜温差大时 | 通风和光照、稀释牛奶 |
| 根腐病 | 基部变褐，植株萎蔫 | 过湿、排水不良 | 加高垄、排水 |
| 猝倒病 | 幼苗在基部缢缩并倒伏 | 过湿、密播 | 排水、间苗、温汤浸种 |
| 黄化病 | 叶片变黄，叶脉突出 | 连作、病毒 | 防治蚜虫、轮作、拔除病株 |

&nbsp;&nbsp;&nbsp;莙荙菜上最常见的病害是褐斑病。夏季韩国的梅雨季（6月下旬至7月）叶上会出现褐色斑点，严重时整片叶子干枯。不过，这种病只会让当年损失几片叶子，不会致使植株死亡。把病叶摘下来拿到田外，蔓延速度就会放慢，此后长出的新叶是健康的。持续采摘食用的收获方式，等于同时起到了防治这种病的作用。

&nbsp;&nbsp;&nbsp;黄化病需要多加注意。病因是病毒，由蚜虫传播。染病的植株不会恢复，所以要拔除销毁，而减少蚜虫数量是唯一的应对办法。红菜头和甜菜会感染同一种病毒，所以可能从那边传过来。

> **莙荙菜的大多数病害只是让叶片受损，不会让植株死亡。这就是莙荙菜在不用药的农事中表现强健的根本原因。摘下病叶，新叶就会长出来，这样周而复始就是防治。**

### 9-2. 主要害虫

| 害虫 | 危害 | 不用药的防治 |
|:---|:---|:---|
| 蚜虫 | 在叶背吸食汁液并传播病毒 | 用强水流冲洗、肥皂水、保护天敌 |
| 叶螨 | 在叶背吸食汁液并结网 | 喷水、提高湿度 |
| 莙荙菜叶甲类 | 啃食叶片 | 用手捉 |
| 潜叶蝇 | 钻入叶内，形成白色线状纹路 | 摘除受害叶片 |
| 蛞蝓 | 把叶片咬出孔洞 | 夜间捕捉、草木灰带或稻壳带 |
| 地老虎幼虫 | 咬断幼苗基部 | 夜间在土中寻找并捉除 |

&nbsp;&nbsp;&nbsp;蚜虫是莙荙菜上最常见的害虫。它和叶螨一样在干燥条件下增多，所以只要浇足水，并偶尔对着叶背用力喷水，就能控制住相当一部分。叶螨尤其喜欢干燥，光是喷水本身就是一种防治。

&nbsp;&nbsp;&nbsp;潜叶蝇的幼虫钻入叶组织内部，留下白色线条。因为它在叶内，在表面喷什么都够不到，所以即使有药也是难对付的害虫。应对办法只有摘下可见线条的叶片，拿到田外。对莙荙菜来说，这不是什么大负担。反正它是摘叶来吃的作物，挑选受害叶片摘除这件事和收获是重叠的。

### 9-3. 天然防治剂与农业防治

| 防治剂 | 配制方法 | 对象 |
|:---|:---|:---|
| 肥皂水 | 将无香味肥皂20g溶于1L水中 | 蚜虫、叶螨 |
| 稀释牛奶 | 牛奶与水按1比9混合 | 白粉病 |
| 喷撒草木灰 | 把过筛的灰撒在叶片和田里 | 驱避害虫、补充钾 |
| 草木灰带 | 在植株周围撒上干灰 | 阻隔蛞蝓 |
| 木醋液 | 稀释300-500倍后喷雾 | 驱避效果 |
| 强水流 | 喷在叶背 | 蚜虫、叶螨 |

| 原则 | 内容 |
|:---|:---|
| 轮作 | 与菠菜、红菜头、甜菜归为一组，休作2年以上 |
| 通风 | 通过间苗确保株距 |
| 排水 | 把垄筑高。这是防治根腐的根本对策 |
| 浇水时间 | 在清晨浇水，使叶片白天能干 |
| 覆盖 | 防止雨水溅起，切断土壤传染途径 |
| 残体处理 | 病叶拿到田外或烧掉 |
| 健康种子 | 温汤浸种可减少种子传病 |
| 兼顾收获的防治 | 优先摘除病叶和受害叶 |

&nbsp;&nbsp;&nbsp;最后一项是莙荙菜独有的防治方式。因为是持续采摘食用的作物，只要在采叶时定好顺序，那就是防治。先摘有病斑的叶片、可见潜叶蝇线条的叶片、附着蚜虫的叶片并加以处理。能吃的洗净食用，不能吃的拿到田外。不必另外花时间，收获和防治一次完成。

## 10. 营养缺乏与过量

| 症状 | 原因 | 用天然材料采取的措施 |
|:---|:---|:---|
| 整片叶子发黄，植株矮小 | 缺氮 | 腐熟堆肥、稀释10-20倍的尿液 |
| 叶缘变褐干枯 | 缺钾 | 少量施用草木灰 |
| 生长不良，叶片带紫色 | 缺磷 | 骨粉、草木灰。地温低时也会出现同样症状 |
| 叶脉间发黄 | 缺镁 | 增加堆肥 |
| 新叶扭曲开裂，生长点变黑 | 缺硼 | 干海藻、充分腐熟的堆肥。减少石灰 |
| 叶片小而薄 | 水分和养分不足 | 同时增加浇水和施肥 |
| 叶片过分柔软，蚜虫聚集 | 氮过量 | 停止供氮 |
| 叶尖干枯，生长停止 | 盐分过多 | 充分浇水，把盐分淋洗下去 |

&nbsp;&nbsp;&nbsp;在莙荙菜上需要特别留意的是缺硼。甜菜属植物对硼的需求大，这种在其他作物上不太出现的症状，在莙荙菜上确实会出现。新长出的叶片皱缩扭曲，叶脉间开裂，严重时生长点附近变黑死亡。生长点一死，那一株就结束了，所以这是各种缺素中最致命的。

&nbsp;&nbsp;&nbsp;硼不足的条件有两种。一是在沙地被雨水冲走，二是大量施入石灰或草木灰使pH升高。后者更常见。即使土壤中有硼，在碱性条件下也会变成植物无法吸收的形态。草木灰是方便的钾源，但一次施入过多就会引发这个问题，所以莙荙菜尤其要少量分次施入。干海藻含有硼，可作为补充材料。

&nbsp;&nbsp;&nbsp;最后一行的盐分过多，换作其他作物是会死的条件。莙荙菜能耐相当高的盐分，但并非没有限度，超过限度叶尖就会干枯、生长停止。应对办法是充分浇水，把根周围的盐分向下淋洗。如果放任干燥，盐分会在根附近浓缩，反而会恶化。这就是在盐害地栽培莙荙菜时，省水并不总是正确的原因。

## 11. 间作与轮作

| 搭配 | 对象 | 效果 |
|:---:|:---|:---|
| 好 | 豆科作物（豌豆、菜豆、豇豆） | 固定氮素并留给莙荙菜 |
| 好 | 生菜、茼蒿等菊科 | 不共有病虫害 |
| 好 | 萝卜、大白菜等十字花科 | 不共有病虫害 |
| 好 | 大葱、分葱、大蒜 | 气味扰乱害虫 |
| 好 | 玉米等高秆作物 | 夏季提供半阴 |
| 不好 | 菠菜、红菜头、甜菜 | 同科或同种，共有病害 |
| 不好 | 莙荙菜连作 | 病原菌积累 |

&nbsp;&nbsp;&nbsp;莙荙菜间作搭配良好，理由很简单。因为藜科，也就是苋科的作物在田里并不常见，所以与大多数作物不共有病虫害。种在十字花科旁边，或种在菊科旁边，都没有彼此不利之处。规划田间布局时，莙荙菜是放在哪里都稳妥的一块拼图。

&nbsp;&nbsp;&nbsp;需要避开的只有菠菜、红菜头和甜菜。尤其红菜头和甜菜与莙荙菜是同一个种，病虫害完全共有，后文要讲到的留种问题也会叠加。这三者归为一组，同一年不放在同一个位置，轮作时也一并计算。

| 轮作顺序示例 | 年次 | 作物 | 田里发生的事 |
|:---|:---:|:---|:---|
| 3年周期 | 第1年 | 莙荙菜等苋科 | 病原菌开始积累 |
| | 第2年 | 豆科（大豆、豌豆、豇豆） | 氮被固定并积累 |
| | 第3年 | 十字花科或禾本科 | 苋科病原菌挨饿 |
| | 再回到第1年 | 莙荙菜 | 在病原菌密度降低的状态下开始 |

&nbsp;&nbsp;&nbsp;连作适应性A、休作2年的标准，比生菜和结球生菜的2-3年更宽松。如果田地狭小，难以严格轮作，至少换个位置也会有差别。

&nbsp;&nbsp;&nbsp;把莙荙菜安排在豆科作物之后尤其合适。莙荙菜喜氮，又因不断长叶而持续消耗氮，豆科作物留下的氮正好满足这一需求。对结球生菜来说，豆科作物留下的氮会妨碍结球，反而成了问题，但对不结球的莙荙菜则没有这种副作用。氮多则叶片变大，而这就是产量。

## 12. 收获 - 持续采摘的技术

| 用途 | 播种后 | 状态 |
|:---|:---:|:---|
| 第1次间苗的嫩叶 | 25-30天 | 真叶2-3片。做沙拉或韩式现拌泡菜（geotjeori） |
| 第2次间苗 | 35-40天 | 真叶4-5片。焯水后做凉拌野菜（namul） |
| 首次收获 | 40-60天 | 外叶长20-30cm |
| 反复收获 | 此后持续 | 每周1-2次 |
| 冬季收获 | 韩国的11月-翌年3月 | 不再生长，所以把现有的叶片一片一片摘 |

### 12-1. 为什么从外侧开始采

&nbsp;&nbsp;&nbsp;莙荙菜的生长点只有一个，位于压缩的短茎顶端、植株正中央。新叶不断从那里长出，被向外推挤着生长。因此，摘掉外侧已长成的叶片，植物失去的只是光合能力已经下降的老叶，生长点原样保留，继续长出新叶。

&nbsp;&nbsp;&nbsp;反过来，如果把中心剪掉，那一株就结束了。生长点一消失，长叶的地方也就没有了。连根拔起莙荙菜，或把基部整个割掉的收获方式，只在决定放弃那一株时才采用。

| 项目 | 要领 |
|:---|:---|
| 采摘的叶片 | 从外侧开始，已长成的叶片 |
| 剪切位置 | 在叶柄与茎相接处留3-5cm后剪断 |
| 一次采摘量 | 全部叶片的三分之一到一半以内 |
| 保留的叶片 | 始终保留中心的6片以上叶片 |
| 工具 | 不要用手撕扯，用刀或剪刀剪断 |
| 采摘时间 | 清晨。一夜吸足水分，最新鲜 |
| 采收周期 | 每周1-2次 |
| 采后 | 浇水 |

> **始终保留中心的六片以上叶片。留下的叶片就是光合作用工厂，这座工厂会制造下一批叶片。贪心全部摘光，那一株就会就此停滞。**

&nbsp;&nbsp;&nbsp;叶柄留3-5cm再剪是有原因的。如果紧贴着茎剪，生长点附近会产生伤口，病原菌就从那里侵入。稍微留一点，剩下的叶柄干枯后会自己脱落，伤口也会愈合。不要用手撕扯也是同样的原因。一撕，叶柄会从茎上撕裂，留下纵向的长伤口。

### 12-2. 一株能收获多少

| 项目 | 值 |
|:---|:---|
| 每株月产量 | 1-1.5kg |
| 收获期 | 春播的话，在韩国从5月到10月，越冬则可到翌年春天 |
| 所需株数 | 以成年人每人计，5-10株 |

&nbsp;&nbsp;&nbsp;每株每月能收获1-1.5kg这个数值，显示出莙荙菜的实际生产力。这是因为叶柄粗厚多汁，有分量。与只吃叶片的生菜相比，同样的体积分量更重。

&nbsp;&nbsp;&nbsp;把评价表中的持续性A和收获速度S放在一起看，就能看出莙荙菜的时间表。播种后50-60天首次收获，此后一直持续到霜来。在韩国，春天播种的莙荙菜若能坚持到10月，就能收获五个月，成功越冬的话则更长。一次播种所得的总量，与生菜完全不在一个量级。

&nbsp;&nbsp;&nbsp;把叶柄单独利用，也对产量有贡献。把叶片和叶柄分开，就有两种食材，烹调方法不同，吃起来就不会觉得是在吃同样的东西。在需要每天吃的处境下，这一差别确实有意义。
