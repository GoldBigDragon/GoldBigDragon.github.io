## はじめに
&nbsp;&nbsp;&nbsp;フダンソウ(Beta vulgaris subsp. cicla)は、現在の分類ではヒユ科(アカザ科が統合)に属する葉物野菜で、ビートやテンサイと同じ種の別の亜種です。ビートとテンサイは根を太らせる方向に、フダンソウは葉と葉柄を育てる方向に分かれました。祖先は地中海と大西洋沿岸の海辺に生えていた野生ビートで、その出自のおかげで葉物の中でも耐塩性が最も高い部類です。総合等級はD(39.4点、有効183種中118位)、副食はSS(64.4点)です。注目すべき項目は温度幅SS(生育5-30℃、幅25℃)で、夏にも育ち氷点下5℃まで耐えるので、季節の空白がほとんどありません。外葉を摘み続ける永続性A、防除がほとんど不要という評価、常温で密閉して5年の種子の寿命(S)も強みです。弱点は、100g当たり18kcalで面積当たりの熱量がD、シュウ酸が多く生で大量に食べにくくゆでる必要があること(調理・加工A)、二年生で風で花粉が飛びビートやテンサイと交雑する採種(A)です。派手な項目はありませんが崩れる項目もなく、ほかの葉物がすべて失敗する塩分を含んだ土地でほぼ唯一残る、最後まで立っている作物です。

| 評価 | 項目 |
|:---|:---|

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | ヒユ科フダンソウ属の二年草。ビート、テンサイ、飼料用ビート、野生ビートと同じ種なので互いに交雑し、ホウレンソウも同じヒユ科。別名はスイスチャード、クンデナムル、ペククンデ |
| 葉、茎 | 葉は広い卵形でつやがあり、葉脈が太く、葉面がでこぼこに縮れる。葉柄は厚く汁が多く、白、赤、黄、ピンクがある。茎は圧縮されてほとんどなく、葉が株元から放射状に出る |
| 根、花、果実 | 主根は深く下りるが、ビートと違って太らず細い。2年目に花茎が立ち、緑色の小さな花が穂状につく。果実は種子が数個固まった種子球 |

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 発芽 | 播種後7-14日 | 種子球1つから複数の芽が一緒に出る |
| 幼苗期 | 発芽後2週間 | 本葉2-3枚。1回目の間引きの時期 |
| 栄養成長期 | 播種後3-7週間 | 葉が急に大きくなる |
| 収穫、繰り返し収穫 | 40-60日から | 外葉20-30cm。外側から摘むと中心から新しい葉が上がる |
| とう立ち | 翌春 | 低温を経験したあと花茎が立つ |

&nbsp;&nbsp;&nbsp;100g当たり熱量18kcal、水分90%以上、タンパク質1.78g(熱量比39.6%)、炭水化物3.5-4.0g、食物繊維1.5-2.0gで、糖類が0.00gのため甘みはほとんどありません。ビタミンA、C、E、K、葉酸、カルシウム、鉄、カリウム、マグネシウムが豊富ですが、シュウ酸のためカルシウムと鉄の吸収率は低く、フダンソウをカルシウム源として計算するのは正確ではありません。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 生育範囲5-30℃(幅25℃)、生育適温15-18℃。発芽適温20-25℃(10℃より低い所と35℃より高い所が限界)。30℃まで育つが葉が硬くなりシュウ酸が増え、氷点下5℃まで生育を保つ(わらを覆うとさらに耐える) |
| 光 | 1日6時間以上。半日陰に耐え(生育は遅いが葉は軟らかい)、夏の遮光は葉が硬くなるのを遅らせる |
| 水、土壌 | 総蒸発散量は約500mm。根が深く、乾燥にはサンチュより強い。土を選ばず、pH6.0-6.8(6.5前後が最適)。過湿には根腐れ |

| 作物 | 耐塩性 |
|:---|:---|
| フダンソウ、ビート、テンサイ | 非常に高い。葉物の中で最上位圏 |
| ホウレンソウ | 中程度。同じ科だがフダンソウより弱い |
| サンチュ、ハクサイ、ダイコン | 低い。塩害地では育たない |
| マメ類 | 非常に低い。真っ先に枯れる |

> **津波や冠水で塩分を含んだ土地、地下水灌漑で塩類がたまった畑で、フダンソウはほぼ唯一残る葉物です。その土地でビタミンとミネラルを供給できるかどうかが、この作物の存在理由です。**

&nbsp;&nbsp;&nbsp;フダンソウはナトリウムを液胞に閉じ込めて細胞質を守り、むしろ浸透圧の調節に利用します。ただし耐塩性は無限ではありません。

| 品種 | 特徴 |
|:---|:---|
| 青フダンソウ(白フダンソウ) | 葉柄が白から黄緑色。最も一般的で収量が安定し、歯ごたえがもちもちしている |
| 赤フダンソウ、黄フダンソウ | 葉柄が赤からピンク(アントシアニン)、黄から黄緑色(βカロテン)。葉が軟らかい |
| フォードフック、ルビー | フォードフックは葉が大きく厚い代表的な白い品種、ルビーは赤い系統の代表で耐寒性がよい |

&nbsp;&nbsp;&nbsp;色は栽培の難しさや収量にほとんど影響せず、品種選びが成否を分けない数少ない作物です。収量を優先するなら青フダンソウとフォードフック、越冬を狙うならルビーを選び、栄養の幅を広げたいなら赤と黄を混ぜます。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 土づくり | 20-30cmの深さに耕し(主根が深く下りる)、畝の高さ15-20cm、幅90-120cm、排水溝を確保する。長く収穫する作物なので有機物をたっぷり入れる |
| 施肥(1,000㎡) | 窒素8-10kg、完熟堆肥1,000-1,500kg。播種の10日前に堆肥、リン酸、カリウムの全量と窒素を元肥として入れ、追肥はおおむね省く。新しく出る葉が小さく色が薄くなれば養分が切れたしるしなので、そのときに薄い肥料をやる。ホウ素が重要な微量要素 |
| 代替資源 | 木灰(1株に一つかみ、多いとホウ素欠乏)、尿の10-20倍希釈液(株の間に、葉に触れると焼ける)、乾燥海藻(カリウムとホウ素を供給、フダンソウは洗わなくても耐える)、発酵させた油かす |

| 作型 | 播種 | 収穫 | 備考 |
|:---|:---|:---|:---|
| 春作 | 3月中旬-5月初め | 5月中旬から続く | 最も一般的。とても早くまくと低温でその年にとう立ち |
| 夏作 | 6-7月 | 8-9月 | 高温にも比較的強い |
| 秋作 | 8-9月 | 10-11月 | 葉が軟らかい |
| 越冬作 | 9-10月 | 翌春 | 中部以南 |

&nbsp;&nbsp;&nbsp;フダンソウの種子は1粒ではなく、種子2-5個が固まった種子球です。1か所から芽が複数出るので間引きが必須で、殻に発芽抑制物質があるため、水に浸すと発芽がよくなります。

> **フダンソウでは間引きは選択ではなく必須です。種子球1つから芽が3つ4つ出るので、そのままにすると1か所で複数の株が互いを押さえつけて育ちます。どれも小さく弱くなり、どれもまともに育てません。**

| 播種 | 基準 |
|:---|:---|
| 種子の処理 | 水に2-3時間(長くても一晩)浸し、水を1、2回替える。50-55℃のお湯に10-15分浸して表面の病原菌を殺し、乾いた木灰をまぶして扱いやすくする。浸した種は処理後すぐにまく |
| 播種 | 深さ1-2.5cm(種子球が大きいのでサンチュより深く)、条間30-50cm、点まきなら1か所に2-3球。発芽7-14日 |
| 間引き | 本葉2-3枚で5cmに1回目(若葉として食べる)、4-5枚で10-15cmに2回目(ナムルとして食べる)。大きく育てるなら最終20cm。抜かずにはさみで切る |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から発芽 | 土が乾かないように(種子球が水を十分に吸わないと発芽しない) |
| 幼苗期、生育期 | 表土が乾いたらたっぷり(頻繁に少しずつより、ときどきたっぷりがよく、根を下へ導く) |
| 繰り返し収穫期 | 葉を摘んだあとに水をやる |
| 梅雨、冬 | 梅雨には排水溝を整え、冬はほとんどやらない |

&nbsp;&nbsp;&nbsp;葉が小さく硬ければ継続的な水不足で、下の葉が黄色くなり株元が軟らかくなれば過湿です。葉柄が縦に裂けるのは、乾いたあとに急にたくさん水をやったためです。わらや枯れ草のマルチは蒸発を大きく減らし、塩害地では塩の上昇も遅らせ、半日陰への配置は夏の蒸発を減らして葉を軟らかくします。

| 管理 | 方法 |
|:---|:---|
| 間引き、草取り | 間引きは必須。草取りは葉が地面を覆えば雑草が抑えられるので初期だけ。土寄せ、摘心、支柱はおおむね不要 |
| 枯れ葉の整理 | 下の黄色く枯れた葉をこまめに取り除く |
| とう立ち | 若い苗が10℃より低い低温に長くさらされるか、早春の遅霜にあうと、その年のうちに花茎が立つ。霜が完全に過ぎてからまくか、早くまくならわらや枯れ草で地温を保つ。立ってしまった花茎は元に戻せない |
| 長く使う | 摘んだあとに水をやり、新しい葉が小さくなれば薄い肥料を入れる。常に中心の葉を6枚以上残す。夏は半日陰に、秋はわらを覆って越冬に備える。冬はある葉を1枚ずつ摘んで食べる(新しい葉はほとんど出ない) |

## 6. 病害虫と養分の問題
&nbsp;&nbsp;&nbsp;アブラナ科の害虫(モンシロチョウ、コナガ、ノミハムシ、根こぶ病)、キク科の病気(菌核病)、ナス科の病害虫はフダンソウにはつかず、ヒユ科自身のアブラムシ、ハダニ、ハムシがつきます。

| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| 褐斑病 | 葉に褐色の円形の斑点ができ、中央が灰色になる(最も一般的)。高温多湿 | 病葉の除去、風通し、輪作 |
| べと病、うどんこ病 | 葉の裏の白いかびと表の黄変 / 葉の表面の白い粉。涼しく湿っているとき / 乾燥して昼夜の差が大きいとき | 風通し、朝の水やり / 風通しと日当たり、牛乳の希釈液 |
| 根腐病、立枯病 | 株元が褐変してしおれる / 若い苗が株元でくびれて倒れる。過湿、密播 | 畝を高くする、排水、間引き、温湯浸漬 |
| 萎黄病 | 葉が黄色くなり葉脈が目立つ。連作、アブラムシが運ぶウイルス | アブラムシ防除、輪作、病株の除去 |
| アブラムシ、ハダニ、ハモグリバエ | 葉の裏で汁を吸いウイルスを運ぶ(アブラムシが最も一般的) / 糸を張る / 葉の中に潜って白い筋模様 | 強い水流で洗う、石けん水、天敵を守る / 水をかける、湿度を上げる / 被害葉の除去 |
| ナメクジ、ネキリムシ | 葉に穴 / 若い苗の株元を切る | 夜に捕る、灰やもみ殻の帯 / 夜に土の中を探して捕る |

> **フダンソウの病気の大半は葉を失わせるだけで、株を枯らしません。これがフダンソウが薬を使わない農業で強い根本の理由です。病葉を取れば新しい葉が上がり、その繰り返しがそのまま防除になります。**

&nbsp;&nbsp;&nbsp;ふるった木灰を葉と畑にまくか、木酢液の300-500倍を使い、輪作はホウレンソウ、ビート、テンサイとまとめて2年以上休ませます。畝を立てて排水を確保するのが根腐れの根本対策で、病葉は畑の外へ出すか焼き、収穫しながら病葉や被害葉を先に摘むのがフダンソウ独自の防除です。

| 症状 | 原因と対処 |
|:---|:---|
| 葉全体が黄色く株が小さい | 窒素欠乏。完熟堆肥、尿の10-20倍希釈液 |
| 新葉がねじれて裂け、成長点が黒くなる | ホウ素欠乏。乾燥海藻、よく熟した堆肥、石灰を減らす |
| 葉が小さく薄い | 水分と養分の不足。水やりと施肥をともに増やす |
| 葉が軟らかすぎてアブラムシが集まる | 窒素過剰。窒素の供給をやめる |
| 葉先が枯れて成長が止まる | 塩分過多。水をたっぷりやって洗い流す |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | レタス・シュンギクなどキク科、ダイコン・ハクサイなどアブラナ科(病害虫を共有しない)、長ネギ・ワケギ・ニンニク(においが害虫を惑わす)、トウモロコシなど背の高い作物(夏に半日陰) |
| 悪い | ホウレンソウ、ビート、テンサイ(同じ科か同じ種で病気を共有する)、フダンソウの連作(病原菌がたまる) |

&nbsp;&nbsp;&nbsp;3年周期で、フダンソウなどヒユ科→マメ科(窒素を固定)→アブラナ科またはイネ科(ヒユ科の病原菌が飢える)の順に回すと、病原菌の密度が下がった状態でフダンソウをまた始められます。連作への適応性Aの基準は2年の休作で、サンチュや玉レタスの2-3年より寛容です。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 1回目の間引きの若葉は25-30日(本葉2-3枚、サラダや浅漬け)、2回目の間引きは35-40日(本葉4-5枚、ゆでてナムル)、最初の収穫は40-60日(外葉の長さ20-30cm)、その後は週1-2回繰り返す |
| 摘み方 | 外側から育ちきった葉をナイフやはさみで、葉柄が茎と接する所から3-5cm残して切る。一度に全体の葉の3分の1から半分以下だけ摘み、常に中心の葉を6枚以上残す。摘んだあとに水をやる |
| 収量 | 1株で1か月に1-1.5kg。春まきなら5月から10月まで、越冬すれば翌春まで。大人1人に5-10株 |

> **常に中心の葉を6枚以上残します。残した葉が光合成の工場であり、その工場が次の葉をつくります。欲張ってすべて摘むと、その株はそのまま止まります。**

| 採種 | 基準 |
|:---|:---|
| 2つの壁 | 二年生で低温を経験しないと花茎が立たず、風が花粉を遠くへ運ぶ風媒の他家受粉。ビート、テンサイ、飼料用ビート、ほかの品種のフダンソウ、野生ビートと完全に交雑し、ホウレンソウ、アカザ、ヒユとは交雑しない |
| 交雑の防止 | ほかのBeta vulgarisの開花株と1,000m以上隔離する(隣の畑まで管理できず難しい)。時期をずらした栽培が最も現実的で、狭い畑では開花前に花茎に布袋をかぶせる |
| 手順 | 秋に葉が大きく病気がなく品種の色がはっきりした株を選ぶ。越冬(中北部は露地越冬が難しいので掘り上げて貯蔵し、春に植え直す)、3-4月にとう立ち(支柱)、5-6月に開花、7-8月に種子球が褐色に乾いたら茎ごと刈り、日陰で1-2週間干してからしごくかもんで落とし、箕で選別して密閉 |
| 収量、寿命 | 1株から種子球が数百から数千個、種子球1つに種子2-5個。種子の寿命は常温で密閉して5年で、毎年20球で発芽を確認する |

> **フダンソウの採種は毎年するものではなく、4-5年に1回、その年にきちんと隔離して行うものです。採種用の株は最低5株、できれば10株以上を残します。他家受粉の作物は、1、2株だけから種を採ると、数世代で近交弱勢が現れます。**

## 9. 貯蔵
| 方法 | 手順と期間 |
|:---|:---|
| 水気を取って涼しい所 | 洗わずに土だけ落とす。3-5日 |
| 紙や布で包んで立てる | 新聞紙や乾いた布で包んで立てておく(布が濡れすぎると傷む)。5-7日 |
| 茎の水挿し | 葉柄の根元を水に浸して立てる(水を毎日替える)。5-7日 |
| 貯蔵穴、地下室 | 涼しい地下空間に立てておく。1-2週間 |
| 干し菜 | 葉と葉柄を分け、沸騰した湯で葉は1-2分、葉柄は3-5分ゆでて冷水ですすぎ、干す。炭や炒った米と一緒に密閉容器で。6か月-1年以上 |
| 葉柄の漬物 | 塩漬け(形が残る)、塩2-3%の乳酸発酵(ビタミンCがかなり残る)、醤油や味噌に漬ける(数か月) |

> **干し菜にするとビタミンCはほとんど失われますが、ビタミンA、ビタミンK、ミネラル、食物繊維は残ります。冬のビタミンCは、干した葉ではなく、畑に立っている生の葉や発酵食品から得られます。**

&nbsp;&nbsp;&nbsp;フダンソウの貯蔵は事実上、干し菜ひとつに行き着き、しっかり干したものはもんで粉にして置けます。

## 10. 調理と注意事項
| 部位 | 性質 | 用途 |
|:---|:---|:---|
| 若葉 | 軟らかくシュウ酸が少ない | 生食、浅漬け、サラダ |
| 成葉 | 厚くシュウ酸が多い | ゆでて和える、汁物、干し菜 |
| 葉柄 | シャキシャキして汁が多い | 炒め物、漬物、塩漬け |
| 太い葉脈 | 硬い | 細かく刻んで汁物やお粥に |

| 処理 | シュウ酸の減少 |
|:---|:---|
| 生食 | 減らない(若葉は含有量が少ない) |
| ゆでて湯を捨てる | かなり減って最も確実。ビタミンCは半分以下になり、葉酸も一部が抜ける |
| ゆで汁を汁物に、炒め物 | 減らない(シュウ酸が汁に入っている) |
| 蒸す、乳酸発酵 | 少し減る。発酵はビタミンCがかなり保たれる |

> **要点はゆでること自体ではなく、ゆで汁を捨てることです。シュウ酸は壊れるのではなく、水に移るのです。その湯を汁物に使えば、シュウ酸もいっしょに入ってきます。**

&nbsp;&nbsp;&nbsp;フダンソウとホウレンソウのシュウ酸は100g当たり数百mgで、ケール(20-50mg)やサンチュ(数十mg)より高く、カルシウムと結合して吸収を妨げます。カルシウムの多い食材といっしょに食べるのも一つの対応です。フダンソウは味噌汁の具として長く使われてきており、油を少し混ぜると栄養上有利で、甘みがなく香りも弱いです。フダンソウに急性毒性はありません。

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 越冬株の冬の葉の収穫、種子の点検。2月に堆肥の切り返し |
| 3-4月 | 3月中旬から春の播種(元肥、畝立て)、採種株がとう立ちを始める。4月に1回目の間引き(若葉の収穫)、草取り、採種株の支柱 |
| 5-6月 | 5月に2回目の間引きと最初の収穫、採種株の開花と隔離管理。6月に本格的な繰り返し収穫、任意の夏まき、採種株の結実 |
| 7-8月 | 7月に繰り返し収穫、梅雨の排水管理、採種株の種子の収穫。8月に繰り返し収穫、下旬から秋まき、褐斑病の観察 |
| 9-10月 | 9月に秋まき分の間引き、春の株の収穫を継続。10月に収穫の最盛期(葉が最もよい月)、干し菜づくり |
| 11-12月 | 11月に収穫を続け、採種株の選抜、越冬準備(土寄せ、わらで覆う)。12月にある葉を1枚ずつ収穫、貯蔵品の点検 |

&nbsp;&nbsp;&nbsp;春まきは5月中旬から10月まで収穫でき、夏に葉が硬くなり、晩夏まき(8月下旬-9月初め)は10月中旬から収穫でき、最後まで軟らかく、とう立ちの危険が低くなります。2回まけば事実上1年じゅう収穫できます。

> **フダンソウを植える理由は、華やかな何か一つの項目ではありません。暑さにも寒さにも病害虫にも塩気にも崩れず、一度植えれば長く収穫でき、種が5年もち、毎日食べても飽きないこと。どんな条件でも最悪にならないこの性質が、災害が長引くほど輝きます。**
