## 13. 採種 - 二年草と風媒受粉

&nbsp;&nbsp;&nbsp;評価表の自家採種の等級はAで、根拠は「他家受精、テンサイ・ビーツとの交雑に注意」です。サンチュ（リーフレタス）のSと分かれるところです。フダンソウの採種には二つの壁があります。

| 障壁 | 内容 | 対策 |
|:---|:---|:---|
| 二年草 | 低温を経験しないと花茎が立ちません | 越冬させるか、抜き取って貯蔵したあと、春に植え直します |
| 風媒の他家受精 | 風が花粉を遠くまで運びます | 隔離距離、時期ずらし栽培、袋かけ |

### 13-1. 何と交雑するのか

| 作物 | 学名 | フダンソウとの交雑 |
|:---|:---|:---:|
| ビーツ、テンサイ、飼料用ビート | Beta vulgaris | 完全に交雑します |
| 別品種のフダンソウ | Beta vulgaris subsp. cicla | 完全に交雑します |
| 野生ビート | Beta vulgaris subsp.maritima | 交雑します |
| ホウレンソウ | Spinacia oleracea | 属が違うので交雑しません |
| アカザ、ヒユ | | 交雑しません |

&nbsp;&nbsp;&nbsp;フダンソウのそばでビーツが花を咲かせると、その年に採れた種子はフダンソウでもビーツでもない雑種になります。根が中途半端にふくらみ、葉柄も薄い、どちらの用途にも向かないものができます。テンサイも同様です。

&nbsp;&nbsp;&nbsp;問題をいっそう難しくしているのが受粉の方式です。フダンソウは風で花粉を運ぶ風媒受粉です。ハチが運ぶ虫媒受粉なら網をかけて防げますが、風はそう簡単には扱えません。花粉は軽くて小さく、数百mから1km以上も飛びます。ケールが500m、ダイコンが1kmを求めるのと同程度か、それ以上です。

| 方法 | 内容 | 現実性 |
|:---|:---|:---|
| 隔離距離 | 他のBeta vulgarisの開花株から1,000m以上 | 隣の畑まで管理できないため難しいです |
| 時期ずらし栽培 | 1年に1種類だけ花を咲かせます | 最も現実的です |
| 袋かけ | 開花前に花茎に布袋をかぶせます | 小規模なら確実です |

&nbsp;&nbsp;&nbsp;最も現実的な解決策は時期ずらし栽培です。今年はフダンソウからだけ採種し、ビーツはすべて食べてしまって花を咲かせません。翌年は逆にします。フダンソウの種子は常温・密閉で5年もつので、1年に1種ずつ交代で採種しても種子が途切れません。種子寿命Sが採種の難しさを相殺するのがここです。

> **フダンソウの採種は毎年行うものではなく、4-5年に1度、その年にきちんと隔離して行うものです。種子寿命が5年であるという事実が、この方式を可能にします。**

&nbsp;&nbsp;&nbsp;袋かけは、畑が狭く隣が近いときに使う方法です。つぼみがつく前に、採種する株3、4本の花茎をまとめて目の粗い布袋で覆い、外からの花粉を防ぎます。ただしフダンソウは自分の花粉ではうまく受精しない自家不和合性があるため、袋の中に複数の株の花茎が一緒に入っている必要があります。1株だけ覆うと、種子はほとんどつきません。

> **採種用の株は最低5株、できれば10株以上残します。他家受精の作物は、1、2株からだけ採種すると数世代で近交弱勢が現れ、勢いが弱くなります。**

### 13-2. 越冬と採種の手順

| 段階 | 時期（韓国の場合） | 内容 |
|:---|:---|:---|
| 採種株の選抜 | 秋 | 葉が大きく病気がなく、品種の色がはっきりした株を選びます |
| 越冬 | 11月-2月 | 株元に土を寄せ、藁と落ち葉で覆います |
| 抽だい | 3-4月 | 花茎が1m以上伸びます。支柱を立てます |
| 開花 | 5-6月 | 緑色の小さな花が穂状に咲きます。この時期に隔離を守ります |
| 結実 | 6-7月 | 種子球がつきます |
| 収穫 | 7-8月 | 種子球が褐色に枯れたら、茎ごと刈り取ります |
| 後熟・種子の取り出し | 収穫直後 | 日陰で1-2週間乾燥させたあと、しごいたり揉んだりして種子を落とします |
| 選別・保管 | 完全乾燥後 | 箕でふるってくずを飛ばし、密閉して涼しい所に置きます |

&nbsp;&nbsp;&nbsp;韓国の中北部のように冬が厳しい地域では、畑での越冬が失敗することがあります。その場合は、霜が降りる前に根ごと抜き取り、少し土をつけたまま室（むろ）や涼しい貯蔵庫に埋めておき、翌春に植え直します。0-5℃、つまり凍らず、かつ芽が動かない条件を保ちます。貯蔵中に低温にあうことがそのまま春化にあたるため、この過程を経た株は、植えるとすぐに花茎を立てます。

&nbsp;&nbsp;&nbsp;フダンソウの種子は、サンチュのように冠毛がついて飛んでいくことはありません。種子球は重く、茎にしっかりついているため、自然に落ちることが少ないです。採種がサンチュより扱いやすいところです。ただし、完全に枯れるまで置くと下のほうのものが落ちるので、3分の2が褐色になった時点で茎ごと刈り取り、日陰で後熟させます。

| 項目 | 基準 |
|:---|:---|
| 1株の種子球の数 | 数百から数千個 |
| 種子球1個あたりの種子 | 2-5個 |
| 種子寿命 | 常温・密閉で5年 |
| 保管 | 密閉容器、涼しく暗く乾燥した場所 |
| 乾燥剤 | 炒って冷ましたコメ、炭、乾いた草木灰 |
| 確認 | 毎年、種子球20個を濡れた布に置き、発芽数を数えます |

&nbsp;&nbsp;&nbsp;1株から採れる種子球は数百から数千で、各種子球に種子が複数入っているため、10株から採種すれば数年分の種子が一度に確保できます。これに5年という寿命が加わるので、一度の採種が長くもちます。

## 14. 毒性と注意すべき成分 - シュウ酸

&nbsp;&nbsp;&nbsp;フダンソウに急性毒性はありません。ただしシュウ酸の含有量が高いため、この成分を理解して扱うことが、フダンソウを使いこなす技術の一部になります。

| 作物 | シュウ酸（100gあたりおよそ） |
|:---|:---|
| フダンソウ、ホウレンソウ | 数百mg |
| スベリヒユ | 数百mg |
| ケール | 20-50mg |
| サンチュ | 数十mg |

### 14-1. シュウ酸とは何か、なぜ問題になるのか

&nbsp;&nbsp;&nbsp;シュウ酸は、植物が自分でつくる有機酸です。いくつかの役割がありますが、その一つが、細胞内の過剰なカルシウムを捕まえて結晶にして蓄えることです。植物にとっては有用な仕組みです。

&nbsp;&nbsp;&nbsp;人が食べると、二つの結果が生じます。第一に、シュウ酸が食べ物の中のカルシウムと結合して水に溶けないシュウ酸カルシウムになり、これは吸収されずにそのまま排出されます。フダンソウはカルシウムが豊富なのに、カルシウムの供給源として計算しにくいのはこのためです。鉄も一部、同様の影響を受けます。第二に、吸収されたシュウ酸は腎臓でカルシウムと結合し、結石の材料になることがあります。腎結石の既往がある人はシュウ酸の多い野菜に注意するように、という話はここから来ています。

&nbsp;&nbsp;&nbsp;ただし、大きさを正確に見る必要があります。ふつうの人がフダンソウをおかずとして食べる程度では、問題になりません。ホウレンソウとフダンソウは長い年月にわたって人が食べてきた野菜で、その摂取で得られるビタミンやミネラルの利益が、シュウ酸の負担を上回ります。心配すべき状況は、腎結石の既往がある場合と、フダンソウやホウレンソウをほかの野菜なしで毎日大量に食べる場合です。災害時には後者の条件が実際に生じうるので、いろいろな野菜を混ぜて食べるのが原則です。

### 14-2. ゆでると減る仕組み

&nbsp;&nbsp;&nbsp;シュウ酸には、水に溶ける形と溶けない形があります。問題になるのは水に溶ける側で、幸いなことに、そちらはゆでる過程で抜け出ます。

| 処理 | シュウ酸の減少 | 備考 |
|:---|:---|:---|
| 生食 | なし | |
| ゆでてゆで汁を捨てる | かなり減少 | 最も確実な方法です |
| ゆで汁を汁物に使う | 減少しない | シュウ酸が汁に入っています |
| 蒸す | 少し減少 | 水に溶け出る先がありません |
| 炒める | ほとんど減少しない | |

> **要点はゆでること自体ではなく、ゆで汁を捨てることです。シュウ酸は壊れるのではなく、水に移るだけです。その水を汁物に使えば、シュウ酸も一緒に入ってきます。**

&nbsp;&nbsp;&nbsp;評価表の調理・加工の等級A、根拠「下ゆで5分」が、この手順を指しています。サンチュがSSでフダンソウがAである理由は、この5分にあります。ただし5分は短いです。沸騰した湯に入れ、しんなりするまで、葉なら1分から2分、厚い葉柄なら3-5分で十分です。ほかのものを煮る火にかければ、追加の燃料はほとんどかかりません。

&nbsp;&nbsp;&nbsp;ゆでると、ビタミンCや葉酸も一部が水に抜けます。シュウ酸を減らす代わりに、水溶性ビタミンの一部を失うことになります。そのため、若い葉は生で、成長した葉はゆでて食べるというように分けるのが、バランスのよい方法です。若い葉はシュウ酸が比較的少なく、やわらかいので、生食に向いています。

&nbsp;&nbsp;&nbsp;カルシウムの多い食材と一緒に食べることも、一つの対策です。豆腐、カタクチイワシ、骨ごと食べる魚を添えると、シュウ酸が腸の中でそのカルシウムと先に結合して排出され、体に吸収されるシュウ酸が減ります。食材のカルシウムの一部を失う代わりに、腎臓に向かうシュウ酸を減らす方法です。

&nbsp;&nbsp;&nbsp;生育条件もシュウ酸の量に影響します。窒素をたくさん与えた葉、高温期に育った葉、古くて大きな葉にシュウ酸が多く含まれます。逆に、涼しい季節の若い葉は少なくなります。夏のフダンソウはゆでて食べ、秋のフダンソウの若い葉は生で食べる、という使い分けはここから来ています。

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;評価表の貯蔵性はDで、電力なし・常温で1週間です。サンチュの2-3日よりよく、玉レタスと同じ水準です。葉柄が厚く、水分を抱えているおかげです。

| 方法 | 手順 | 期間 | 限界 |
|:---|:---|:---:|:---|
| 水気をとって涼しい所に置く | 洗わず、土だけ払っておきます | 3-5日 | 乾くとしおれます |
| 紙や布で包む | 新聞紙や乾いた布で包み、立てて置きます | 5-7日 | 布が濡れすぎると傷みます |
| 茎の水挿し | 葉柄の根元を水に浸して立てます | 5-7日 | 水を毎日替える必要があります |
| 土室・室 | 涼しい地下空間に立てて置きます | 1-2週間 | 室が必要です |

&nbsp;&nbsp;&nbsp;フダンソウは立てて保管するのがこつです。葉柄がまっすぐで厚いため、寝かせて置くと曲がろうとして組織が傷みます。立てて置けば、その力がかかりません。水気を除いて保管するというのは、洗ったあとの水気のことで、葉の水分のことではありません。洗うと表面の水が腐敗の起点になるので、食べる直前に洗います。

### 15-1. ムンナムル（干してとっておくナムル）- フダンソウの貯蔵法

| 段階 | 方法 |
|:---|:---|
| 下準備 | 葉と葉柄を分けます |
| ゆでる | 沸騰した湯に、葉は1-2分、葉柄は3-5分 |
| すすぐ | 冷水ですすいで熱を冷まします |
| 水気を絞る | 手でしっかり絞ります |
| 干す | 日陰の風通しのよい所に広げるか、ひもに掛けます |
| 完全乾燥 | 手で砕けるまで |
| 保管 | 密閉容器に、炭や炒ったコメと一緒に入れます |
| 期間 | 6か月から1年以上 |

&nbsp;&nbsp;&nbsp;フダンソウの貯蔵は、事実上ムンナムルひとつに集約されます。ゆでて干す過程が、二つのことを同時に行います。シュウ酸を減らし、貯蔵期間を延ばします。ゆでる過程でシュウ酸が水に抜けるので、干したフダンソウは、生のものよりシュウ酸が少ない状態で保管されます。

> **ムンナムルにすると、ビタミンCはほとんど失われますが、ビタミンAとビタミンK、ミネラル、食物繊維は残ります。冬のビタミンCは、干したものではなく、畑に立っている生の葉や発酵食品から得ます。この区別を知ったうえで貯蔵計画を立てます。**

&nbsp;&nbsp;&nbsp;からからに干したフダンソウは、手で揉んで粉にしておくこともできます。かさが大きく減って保管しやすく、汁物やお粥にひとさじずつ入れると栄養が加わります。丸ごと干したものは、水で戻してナムルとして和えたり炒めたりします。戻すときは、ぬるま湯に2時間ほどつけてから一度ゆでると、やわらかくなります。

| その他の方法 | 内容 | 評価 |
|:---|:---|:---|
| 塩漬け | 葉柄を塩に漬けます | 葉柄は漬けても形が残ります |
| 乳酸発酵 | 2-3%の塩でキムチのように | ビタミンCがかなり残ります |
| チャンアチ（醤油漬け） | 葉柄を塩漬けにしてから、テンジャン（韓国味噌）か醤油に漬け込みます | 数か月もちます |

&nbsp;&nbsp;&nbsp;葉柄が厚いという性質が、貯蔵では有利に働きます。葉は塩漬けにするとくたくたになりますが、葉柄はシャキシャキ感が残るため、チャンアチや塩漬けが成り立ちます。葉と葉柄を分けて、それぞれ別の方法で貯蔵するのが、フダンソウを使いこなすこつです。葉はゆでて干し、葉柄は塩漬けにするかチャンアチに漬けます。

## 16. 調理と加工

| 方法 | 燃料 | ビタミンC保存 | シュウ酸 |
|:---|:---:|:---:|:---|
| 若い葉の生食 | なし | 最大 | 減りませんが、若い葉は少ないです |
| ゆでて和える | 少ない | 半分以下 | かなり減ります |
| 汁物に入れる | ほかの調理と兼用 | 汁ごと食べれば保たれる | 減りません |
| 炒める | 少ない | 中程度 | 減りません |
| 乳酸発酵 | なし | かなり維持 | 少し減ります |
| 干して粉にする | 乾燥時に日光と風 | ほとんどなし | ゆでて干せば減ります |

&nbsp;&nbsp;&nbsp;フダンソウ調理の基本は、葉と葉柄を分けることです。厚みが違うので、火の通る時間が違います。一緒に入れると、葉は崩れて葉柄は生煮えになります。葉柄を先に入れ、少ししてから葉を入れる順にすれば、両方ちょうどよく火が通ります。

| 部位 | 性質 | 使い方 |
|:---|:---|:---|
| 若い葉 | やわらかく、シュウ酸が少ないです | 生食、コッチョリ（発酵させない和えたてのキムチ）、サラダ |
| 成長した葉 | 厚く、シュウ酸が多いです | ゆでて和え物、汁物、ムンナムル |
| 葉柄 | シャキッとして水分が多いです | 炒め物、チャンアチ、塩漬け |
| 太い葉脈 | 硬いです | 細かく刻んで汁物やお粥に |

&nbsp;&nbsp;&nbsp;フダンソウは、韓国の食卓でテンジャン汁の具として長く使われてきました。テンジャン汁に入れる方法は、災害時にも理にかなっています。すでに煮ている火に入れるので追加の燃料がかからず、テンジャンの塩気とうま味がフダンソウの淡白さを補い、テンジャンに含まれるタンパク質とフダンソウの微量栄養素が互いを補完します。ただし汁ごと食べるとシュウ酸も一緒に入ってくるので、汁物ばかり毎日食べるより、ゆでて湯を捨てる調理と交互に使うほうがバランスがとれます。

&nbsp;&nbsp;&nbsp;油を少し混ぜるのが栄養面で有利です。フダンソウに含まれるビタミンAとビタミンKとビタミンEは脂溶性なので、油があってはじめて吸収されます。エゴマやゴマをすって入れたり、豆をすりつぶしてつくった汁に入れたりしても、同じ効果が得られます。昔からフダンソウのナムルをエゴマ粉で和えてきたのは、味だけの問題ではありません。

&nbsp;&nbsp;&nbsp;糖類0.00gという成分値が示すように、フダンソウは甘味がなく、香りも弱いです。淡白だという意味ですが、これが災害時にはむしろ強みです。香りの強い野菜は数日で飽きますが、淡白なものはほかの味を受け入れる土台になります。テンジャン、醤油、エゴマ、トウガラシ、ニンニクのどれとも合い、毎日食べても飽きません。味の等級Sはここから来ています。

&nbsp;&nbsp;&nbsp;韓国の気候に合わせたこの表から読み取るべきなのは、空白がないという点です。12か月のうち収穫が書かれていない月は2月だけで、それも越冬に成功した株があれば埋まります。サンチュが4か月、玉レタスが1、2か月しか食卓に上らないのと比べると、フダンソウの位置づけがはっきりします。

&nbsp;&nbsp;&nbsp;10月は葉が最もよい月です。気温が下がるにつれて葉がやわらかくなり、シュウ酸が減って、甘味が少し増します。夏の間ずっと硬い葉をゆでて食べていたのが、秋になると生で食べられるようになります。ムンナムルをつくる時期もこのころがよいです。葉が多く、空気が乾燥していてよく乾きます。

| 区分 | 春まき | 晩夏まき |
|:---|:---|:---|
| 播種 | 3月中旬-5月初め | 8月下旬-9月初め |
| 初収穫 | 5月中旬 | 10月中旬 |
| 収穫期間 | 5月-10月 | 10月-11月、越冬すれば翌春まで |
| 葉の質 | 夏に硬くなります | 最後までやわらかいです |
| 抽だいの危険 | 早まきすると低温でその年に抽だい | 低いです |
| 採種 | 越冬させて翌年 | 越冬させて翌年 |

&nbsp;&nbsp;&nbsp;春と晩夏の2回まけば、韓国では事実上、一年中収穫できます。春まき分が夏の暑さで葉が硬くなるころ、晩夏まき分が育ってきて、その株が秋のやわらかい葉をつけます。その中の数株を越冬させて、翌年の採種株として使います。この循環が軌道に乗れば、フダンソウはほとんど手をかけずに、畑の一隅で回り続けます。

> **フダンソウを植える理由は、華やかな何か一つの項目のためではありません。暑さにも寒さにも病害虫にも塩分にも崩れず、一度植えれば長く収穫でき、種子が5年もち、毎日食べても飽きないということ。どの条件でも最悪にならないこの性質が、災害が長引くほど光を放ちます。**
