## 5. 畑の準備と肥料

### 5-1. 畑づくり

| 項目 | 基準 | 理由 |
|:---|:---|:---|
| 耕す深さ | 20-30cm | 直根が深く下ります |
| 畝の高さ | 15-20cm | 過湿を防ぎます |
| 畝の幅 | 90-120cm | 条間に合わせます |
| 排水溝 | 確保します | 韓国の梅雨（チャンマ、6月下旬～7月）の時期に根腐れを防ぎます |
| 有機物 | たっぷりと | 長く収穫する作物なので、地力で支える必要があります |

&nbsp;&nbsp;&nbsp;フダンソウの畑で特に気を配るべきなのは、深さです。フダンソウの直根は30cmを超えて下り、この深い根が、干ばつに耐える力ややせた土から養分を引き寄せる力の源です。硬い層があると、根が横に曲がり、その能力が低下します。スコップで一度深く掘り返しておけば、その後の数年が楽になります。

&nbsp;&nbsp;&nbsp;塩害地では、配置を変えます。水が蒸発するにつれて、塩分は上に上がってきて、畝の表面と肩に集まります。そのため、畝の頂上ではなく、畝の側面の下のほうや畝間の近くに植えると、根が届く場所の塩分が少なくなります。雨水が塩分を下へ洗い流すので、排水のよい状態を保つことが、年を追うごとに条件をよくします。稲わらや枯れ草を厚くかぶせて蒸発を減らせば、塩分が表面に上がってくる速度そのものが遅くなります。

### 5-2. 施肥量

&nbsp;&nbsp;&nbsp;評価表の施肥等級はBで、㎡あたりN、P、Kを合わせて約22gです。サンチュと同じ水準です。

| 肥料 | 1,000㎡あたり | ㎡換算 | 備考 |
|:---|:---:|:---:|:---|
| 窒素（N） | 8-10kg | 8-10g | 元肥中心 |
| リン酸（P） | 6-8kg | 6-8g | 全量元肥 |
| カリウム（K） | 6-8kg | 6-8g | 全量元肥 |
| 堆肥 | 1,000-1,500kg | 1-1.5kg | 完熟堆肥 |

| 区分 | 時期 | 内容 |
|:---|:---|:---|
| 元肥 | 播種10日前 | 堆肥の全量、リン酸とカリウムの全量、窒素 |
| 追肥 | おおむね省略 | 生育が不振なときや、収穫を長く続けるときだけ少量 |

&nbsp;&nbsp;&nbsp;フダンソウは、追肥がほとんど必要ない作物に分類されます。元肥をきちんと入れれば、それでおおむね十分です。ただし、この原則には但し書きがあります。摘み続ける方式で何か月も収穫すると、その分だけ土から養分が抜けていきます。葉を摘み取った重さの分だけ、窒素が畑の外へ出ていくことになります。

> **フダンソウで追肥が必要になる時期は、決まった日付ではなく、葉の状態が教えてくれます。新しく出てくる葉が小さくなり、色が薄くなったら、養分が切れたのです。このとき薄めた肥料を与えると、再び大きくなります。このサインを読み取れれば、フダンソウは一年中収穫できます。**

&nbsp;&nbsp;&nbsp;フダンソウで注目したい微量元素が、ホウ素です。フダンソウ属の植物は、ホウ素の要求量が比較的大きいです。ホウ素が不足すると、葉脈の間が裂け、新しい葉がねじれ、ひどい場合は生長点付近が黒く枯れます。ホウ素が不足する条件は二つあります。砂地で雨に流されてしまう場合と、石灰を多く入れてpHが高くなり、ホウ素が吸収されない形に変わってしまう場合です。天然資材の中では、よく腐熟した堆肥と、海由来の材料、つまり海藻を乾燥させて入れたものが、ホウ素を含んでいます。石灰質を一度にたくさん入れないことが予防になります。

### 5-3. 災害時の代替肥料

| 資材 | 供給成分 | 使い方 | 注意 |
|:---|:---|:---|:---|
| 草木灰 | カリウム、リン酸、カルシウム | 1株に一つかみずつ土に混ぜます | アルカリ性なので、多すぎるとホウ素欠乏を招きます |
| 完熟堆肥 | 総合 | 元肥としてたっぷりと | 未熟なものは根を傷めます |
| 薄めた尿 | 窒素、カリウム | 水で10-20倍に薄めて株の間に | 葉にかかると焼けます |
| 骨粉 | リン酸、カルシウム | 元肥として土に混ぜます | 効果がゆっくり現れます |
| 乾燥海藻 | カリウム、ホウ素、微量元素 | 水ですすいで塩分を抜いてから堆肥に混ぜます | フダンソウは、すすがなくても耐えるほうです |
| 油かす | 窒素、リン酸 | 発酵させてから元肥として | 生のものは発酵熱で根を焼きます |
| 卵の殻の粉 | カルシウム | 元肥に混ぜます | 細かく砕かないと分解されません |

&nbsp;&nbsp;&nbsp;乾燥海藻は、フダンソウと特に相性のよい資材です。カリウムと微量元素が豊富で、ホウ素も含んでいます。ほとんどの作物では塩分のために水ですすいで使う必要がありますが、フダンソウは耐塩性があるため、その手間が軽くなります。海辺に近い地域で打ち上げられた海藻を集めて使えるなら、フダンソウに最もふさわしい肥料です。

&nbsp;&nbsp;&nbsp;評価表の無合成投入での収量維持率は、C、40.8%です。化学肥料なしで育てると、収量が大きく落ちるという意味です。フダンソウでは、この低下は、枯れるのではなく、葉が小さくなり、育つ速度が遅くなるという形で現れます。玉レタスのように全量損失につながらない点が違います。天然資材だけを使うなら、収穫量が減ることを見込んで、面積を広げるか、株数を増やす方向で対応します。

## 6. 播種――種子球と間引き

### 6-1. 作型

| 作型（韓国） | 播種 | 収穫 | 備考 |
|:---|:---|:---|:---|
| 春栽培 | 3月中旬-5月初め | 5月中旬から継続 | 最も一般的です |
| 夏栽培 | 6-7月 | 8-9月 | 高温にも比較的強いです |
| 秋栽培 | 8-9月 | 10-11月 | 葉が柔らかいです |
| 越冬栽培 | 9-10月 | 翌年の春 | 韓国中部以南。翌年に抽だいします |

&nbsp;&nbsp;&nbsp;フダンソウの作型表に空欄がほとんどないという点が、この作物の性格です。サンチュが春と秋の二つの区間に閉じ込められ、玉レタスがそれよりもさらに狭いのとは違い、フダンソウは、韓国では3月から10月までいつ播いても育ちます。春に一度、晩夏に一度播けば、事実上一年中収穫できます。

&nbsp;&nbsp;&nbsp;ただし、春にとても早く播くことには注意が必要です。幼い苗が10度未満の低温に長くさらされると、春化が起こり、その年のうちに花茎が立ってしまいます。二年生なのに一年生のようにふるまうわけで、花茎が立つと葉が硬くなり、収穫は終わりです。霜が完全に過ぎ去ってから播くか、早く播くなら、わらをかけて低温を避けさせます。

### 6-2. 種子球という特殊な種子

&nbsp;&nbsp;&nbsp;フダンソウの種子は、一つの種ではありません。複数の種が萼の組織に包まれて一塊になったもので、これを種子球、または種子塊と呼びます。外から見るとでこぼこした茶色の粒一つですが、その中に種が2個から5個入っています。

&nbsp;&nbsp;&nbsp;この構造は、栽培に二つの結果をもたらします。

| 結果 | 内容 |
|:---|:---|
| 一か所から複数の芽 | 種子球を一つ植えると、芽が複数出ます。間引きが必ず必要です |
| 発芽抑制物質 | 殻に発芽を抑える物質があり、水に浸すと発芽がよくなります |

> **フダンソウでは、間引きは選択ではなく必須です。種子球一つから芽が三つ四つ出るので、そのままにしておくと、一か所で複数の株が互いに押し合いながら育ちます。どれも小さく弱くなり、どれもまともに育ちません。**

&nbsp;&nbsp;&nbsp;殻の発芽抑制物質は、もともと野生で種が一斉に発芽しないようにする仕組みです。一度雨が降っただけですべてが芽を出してしまうと、その後に干ばつが来たときに全滅するため、水で何度も洗い流されてはじめて発芽するように調整されています。栽培では、この仕組みが発芽を遅らせる要因になるので、あらかじめ水に浸して抑制物質を洗い流します。

| 前処理 | 方法 | 効果 |
|:---|:---|:---|
| 浸水 | 2-3時間、長ければ一晩 | 抑制物質が洗い流され、発芽が早まります |
| 水の交換 | 浸している間に水を1、2回替えます | 洗い出された物質を捨てます |
| 温湯浸漬 | 50-55℃の水に10-15分 | 種子表面の病原菌を殺します |
| 灰まぶし | 浸したあと、乾いた草木灰をまぶします | 消毒と乾燥を兼ね、扱いやすくなります |

&nbsp;&nbsp;&nbsp;浸した種子は乾くと死んでしまうので、処理したあとはすぐに播き、土が乾かないようにします。種子消毒剤がなくても、フダンソウは発芽率が高いほうなので、大きな問題にはなりません。

### 6-3. 播種と間引き

| 項目 | 基準 | 備考 |
|:---|:---|:---|
| 播種の深さ | 1-2.5cm | 種子球が大きいので、サンチュより深く埋めます |
| 条間 | 30-50cm | |
| 株間（最終） | 10-15cm | 大きく育てるなら20cm |
| 播種方法 | すじまきまたは点まき | |
| 播種量 | 点まきなら1か所に2-3球 | 種子球一つに種が複数入っているので、十分です |
| 発芽期間 | 7-14日 | サンチュより遅いです |

| 間引きの回 | 時期 | 残す間隔 | 間引いたもの |
|:---|:---|:---:|:---|
| 1回目 | 本葉2-3枚 | 5cm | ベビーリーフとして食べます |
| 2回目 | 本葉4-5枚 | 10-15cm | ナムルにして食べます |

&nbsp;&nbsp;&nbsp;間引いたものを捨てないことがコツです。1回目の間引きで出る若い芽は、そのままサラダやゴッチョリ（生キムチ）になり、2回目の間引きで出るものは、下茹でしてナムルとして食べます。播種後1か月で最初の間引きが来るので、本格的な収穫の40-60日よりずっと早い時点で、すでに食べるものが得られます。災害の初期に、畑に何もない状態で播くなら、この時間差には意味があります。

&nbsp;&nbsp;&nbsp;間引くときは、引き抜かずに、はさみで地面近くを切るほうがよいです。引き抜くと、隣に残す株の根まで揺れてしまいます。種子球から出た芽は、根が互いに絡み合っているので、特にそうです。

&nbsp;&nbsp;&nbsp;最終的な間隔をどのくらいにするかは、何を望むかによります。10cmに狭めれば小さな葉がたくさん得られ、20cmに広げれば大きな葉と太い葉柄が得られます。摘み続けながら長く育てる計画なら、広くとるほうがよいです。一つの株が長く生きなければならず、そのためには根が伸びる場所が必要だからです。

## 7. 水管理

| 時期 | 水管理 | 理由 |
|:---|:---|:---|
| 播種-発芽 | 土を乾かさない | 種子球が水を十分に吸ってこそ発芽します |
| 幼苗期 | 表土が乾いたら | 根を下へ導きます |
| 生育期 | 表土が乾いたらたっぷりと | 頻繁に少しずつより、ときどきたっぷりのほうがよいです |
| 繰り返し収穫期 | 葉を摘んだあとに与えます | 新しい葉をつくるのに水が要ります |
| 梅雨の時期 | 排水溝を整備します | 過湿が根腐れを招きます |
| 冬 | ほとんど与えません | 育たないので、必要が少ないです |

&nbsp;&nbsp;&nbsp;ときどきたっぷり与える方式が、フダンソウに合います。頻繁に少しずつ与えると、水が表土にしかとどまらず、根が上のほうに集中してしまい、そうなると、フダンソウの強みである深い根ができません。一度に深くしみ込むよう十分に与え、次までに間隔をあければ、根が水を追って下へ伸びていきます。そうして育った株が、干ばつに耐えます。

| 症状 | 原因 | 対応 |
|:---|:---|:---|
| 昼にしおれて夕方に回復 | 一時的な不足 | 正常な範囲です |
| 夕方にも回復しない | ひどい不足 | すぐにたっぷり与えます |
| 葉が小さく硬い | 継続的な水不足 | 灌水を増やし、マルチングします |
| 下葉が黄色くなり、株元が軟らかくなる | 過湿 | 排水溝を切り、灌水を止めます |
| 葉柄が裂ける | 乾いたあとに突然大量の水 | 灌水の間隔を均一にします |

&nbsp;&nbsp;&nbsp;葉柄が縦に裂ける現象は、水分の供給にむらがあるときに現れます。長く乾いた状態が続いたあとに大雨が降ると、太い葉柄の内側の細胞が急に膨らんで、外側を押し破ります。食べるのに支障はありませんが、裂けた箇所から病原菌が入る可能性があるため、裂けた葉柄は先に摘んで食べます。マルチングが水分を均一に保ち、この問題を大きく減らします。

| 節水方法 | 効果 |
|:---|:---|
| わらや枯れ草のマルチング | 蒸発を大きく減らします。塩害地では塩分の上昇も遅らせます |
| 早朝の灌水 | 日中の蒸発を避け、葉が日中に乾きます |
| 深く耕す | 根が深く下りて、下のほうの水を使います |
| 半日陰への配置 | 夏に蒸発が減り、葉が柔らかくなります |
| 畝間灌水 | 葉を濡らさないので、病気が減ります |

&nbsp;&nbsp;&nbsp;マルチングがフダンソウで特に重要な理由が、もう一つあります。塩害地でわらや枯れ草を厚くかぶせると、土の表面からの蒸発が減り、蒸発が減れば、塩分が上へ上がってくる速度が遅くなります。塩害を和らげる最も安上がりな手段であり、水を節約する手段でもあります。
