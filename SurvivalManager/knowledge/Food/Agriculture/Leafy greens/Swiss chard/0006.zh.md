## 13. 留种 - 二年生与风媒授粉

&nbsp;&nbsp;&nbsp;评价表中的自家留种等级为A，依据是“异花授粉，注意与甜菜、红菜头杂交”。这是它与生菜的S拉开差距之处。莙荙菜留种有两道壁垒。

| 障碍 | 内容 | 解决办法 |
|:---|:---|:---|
| 二年生 | 必须经历低温才会抽出花茎 | 使其越冬，或拔起贮藏后在春天重新栽种 |
| 风媒异花授粉 | 风会把花粉传到很远的地方 | 隔离距离、错年栽培、套袋 |

### 13-1. 与什么杂交

| 作物 | 学名 | 与莙荙菜杂交 |
|:---|:---|:---:|
| 红菜头、甜菜、饲料甜菜 | Beta vulgaris | 完全杂交 |
| 其他品种的莙荙菜 | Beta vulgaris subsp. cicla | 完全杂交 |
| 野生甜菜 | Beta vulgaris subsp.maritima | 会杂交 |
| 菠菜 | Spinacia oleracea | 属不同，不杂交 |
| 藜、苋 | | 不杂交 |

&nbsp;&nbsp;&nbsp;如果红菜头在莙荙菜旁边开花，那年收到的种子既不是莙荙菜也不是红菜头，而是杂种。长出来的东西根部不上不下地膨大，叶柄也很薄，两种用途都不太合用。甜菜也是同样。

&nbsp;&nbsp;&nbsp;让问题更难办的是授粉方式。莙荙菜是靠风传送花粉的风媒授粉。如果是靠蜜蜂传粉的虫媒授粉，还可以罩上网来阻隔，但风就没那么好应付了。花粉轻而小，能飞出数百米乃至1km以上。这与羽衣甘蓝要求500m、萝卜要求1km相近，或者更远。

| 方法 | 内容 | 可行性 |
|:---|:---|:---|
| 隔离距离 | 与其他Beta vulgaris开花株相距1,000m以上 | 无法管控邻近地块，因此很难做到 |
| 错年栽培 | 一年只让一种开花 | 最为现实 |
| 套袋 | 开花前给花茎套上布袋 | 小规模时可靠 |

&nbsp;&nbsp;&nbsp;最现实的办法是错年栽培。今年只从莙荙菜上采种，红菜头全部吃掉，不让其开花。来年则反过来。莙荙菜种子在常温密封条件下可保存5年，所以即使一年只轮换一种留种，种子也不会断档。种子寿命S抵消留种难度之处，就在这里。

> **莙荙菜留种不是每年都要做的事，而是每4-5年做一次，并且在那一年做好隔离。种子寿命为5年这一事实使这种方式成为可能。**

&nbsp;&nbsp;&nbsp;套袋是田地狭小、邻居很近时使用的方法。在花蕾形成之前，把要留种的三四株的花茎一起用网眼稀疏的布袋罩住，挡住外来花粉。不过，莙荙菜具有用自身花粉不易受精的自交不亲和性，所以袋子里必须同时装有多株的花茎。只罩一株的话，几乎不结种子。

> **留种用的植株至少留5株，最好10株以上。异花授粉作物如果只从一两株上采种，几代之后就会出现近交衰退，长势变弱。**

### 13-2. 越冬与留种步骤

| 阶段 | 时期（韩国） | 内容 |
|:---|:---|:---|
| 选留种株 | 秋季 | 选择叶片大、无病、品种颜色鲜明的植株 |
| 越冬 | 11月-2月 | 给基部培土，用稻草和落叶覆盖 |
| 抽薹 | 3-4月 | 花茎长到1m以上。立上支架 |
| 开花 | 5-6月 | 绿色小花呈穗状开放。此时要做好隔离 |
| 结实 | 6-7月 | 结出种球 |
| 收获 | 7-8月 | 种球干枯变褐后，连茎割下 |
| 后熟·脱粒 | 收获后立即 | 在阴凉处晾1-2周，然后用手捋或搓，把种子抖落 |
| 精选·保存 | 完全干燥后 | 簸扬去除碎屑，密封后放在阴凉处 |

&nbsp;&nbsp;&nbsp;在韩国中北部这类冬季严酷的地区，露地越冬可能失败。这时采用的办法是：在下霜前连根拔起，带着少许泥土埋入地窖或阴凉的库房，来年春天再栽。保持0-5℃，即不结冰、又不发芽的条件。贮藏期间经历低温就相当于春化，所以经过这一过程的植株一栽下去就会抽出花茎。

&nbsp;&nbsp;&nbsp;莙荙菜的种子不像生菜那样带有冠毛而飞散。种球沉重，牢牢附着在茎上，很少自行脱落。这是留种比生菜更好管理的地方。不过，如果等到完全干枯，下部的种球会掉落，所以在三分之二变成褐色时就连茎割下，放在阴凉处后熟。

| 项目 | 标准 |
|:---|:---|
| 每株种球数 | 数百到数千个 |
| 每个种球的种子 | 2-5粒 |
| 种子寿命 | 常温密封5年 |
| 保存 | 密封容器，阴凉、黑暗、干燥处 |
| 干燥剂 | 炒后放凉的大米、木炭、干燥的草木灰 |
| 检查 | 每年取20个种球放在湿布上，统计发芽数 |

&nbsp;&nbsp;&nbsp;一株结出的种球有数百到数千个，每个种球里又有多粒种子，所以留种10株就能一次性储备好几年的种子量。再加上5年的寿命，一次留种可以管很久。

## 14. 毒性与需注意的成分 - 草酸

&nbsp;&nbsp;&nbsp;莙荙菜没有急性毒性。不过它的草酸含量高，理解并妥善处理这一成分，也就成了使用莙荙菜的技术的一部分。

| 作物 | 草酸（每100g大约） |
|:---|:---|
| 莙荙菜、菠菜 | 数百mg |
| 马齿苋 | 数百mg |
| 羽衣甘蓝 | 20-50mg |
| 生菜 | 数十mg |

### 14-1. 草酸是什么，为什么会成为问题

&nbsp;&nbsp;&nbsp;草酸是植物自身合成的有机酸。它有多种作用，其中之一是捕获细胞内过剩的钙，使其形成结晶加以储存。这对植物来说是一种有用的装置。

&nbsp;&nbsp;&nbsp;人吃下后会产生两种结果。第一，草酸与食物中的钙结合，形成不溶于水的草酸钙，它不会被吸收，直接排出体外。这就是莙荙菜钙含量丰富，却难以把它算作钙来源的原因。铁也会受到部分同样的影响。第二，被吸收的草酸会在肾脏中与钙结合，可能成为结石的原料。有肾结石病史的人应当留意草酸含量高的蔬菜，这种说法就是由此而来。

&nbsp;&nbsp;&nbsp;不过，要准确看待其程度。普通人把莙荙菜当作配菜食用的程度，不会构成问题。菠菜和莙荙菜是人类长期食用的蔬菜，食用它们所获得的维生素和矿物质的益处超过草酸的负担。值得担心的情况，是有肾结石病史，以及不配其他蔬菜、每天大量吃莙荙菜或菠菜的情况。灾害情境下，后一种条件有可能真实出现，所以混合食用多种蔬菜是原则。

### 14-2. 焯水为什么能减少草酸

&nbsp;&nbsp;&nbsp;草酸分为可溶于水的形态和不溶于水的形态。成为问题的是可溶于水的那一部分，所幸这一部分会在焯水过程中流失。

| 处理 | 草酸减少 | 备注 |
|:---|:---|:---|
| 生食 | 无 | |
| 焯水后倒掉焯菜水 | 大幅减少 | 最可靠的方法 |
| 把焯菜水当汤用 | 不减少 | 草酸留在汤里 |
| 蒸 | 略有减少 | 没有能让草酸溶出的水 |
| 炒 | 几乎不减少 | |

> **关键不在于焯水本身，而在于把焯过菜的水倒掉。草酸并没有被破坏，只是转移到了水里。用这些水煮汤，草酸也会一并进来。**

&nbsp;&nbsp;&nbsp;评价表中烹饪·加工的等级A、依据“焯水5分钟”指的就是这一步骤。生菜为SS而莙荙菜为A，原因就在这5分钟。不过5分钟其实不长。放入沸水，煮到变软为止，叶片只需1分钟到2分钟，厚叶柄则需3-5分钟。放在煮其他食物的火上顺带焯，几乎不需要额外燃料。

&nbsp;&nbsp;&nbsp;焯水时，维生素C和叶酸也有一部分流失到水中。这相当于以损失部分水溶性维生素为代价来减少草酸。所以，把嫩叶生吃、长成的叶片焯后食用，这样分开处理比较均衡。嫩叶的草酸相对较少，质地柔软，适合生吃。

&nbsp;&nbsp;&nbsp;与含钙丰富的食材一起吃，也是一种应对办法。搭配豆腐、鳀鱼、连骨吃的鱼，草酸会先在肠道中与这些钙结合并排出，被身体吸收的草酸就会减少。这是以损失食材中一部分钙为代价，减少流向肾脏的草酸的方式。

&nbsp;&nbsp;&nbsp;生长条件也影响草酸的量。施氮多的叶片、高温期生长的叶片、老而大的叶片，草酸含量较高。反之，凉爽季节的嫩叶较少。夏季的莙荙菜焯后吃、秋季莙荙菜的嫩叶生吃，这种区分就是由此而来。

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;评价表中的耐储性为D，即无电力、常温下可放1周。比生菜的2-3天好，与结球生菜处于同一水平。这得益于叶柄厚实，能够保住水分。

| 方法 | 步骤 | 时间 | 局限 |
|:---|:---|:---:|:---|
| 去除水分后放阴凉处 | 不洗，只抖掉泥土 | 3-5天 | 干了会蔫 |
| 用纸或布包裹 | 用报纸或干布包好，竖放 | 5-7天 | 布太湿会烂 |
| 茎部水插 | 把叶柄基部泡在水里竖放 | 5-7天 | 必须每天换水 |
| 土窖·地窖 | 竖放在阴凉的地下空间 | 1-2周 | 须有地窖 |

&nbsp;&nbsp;&nbsp;竖着保存莙荙菜是个窍门。叶柄挺直而粗厚，平放的话它会想要弯曲，组织就会受损。竖放就不会有这种受力。所谓“去除水分后保存”，说的是洗后的水气，而不是叶片自身的水分。清洗后表面的水会成为腐烂的起点，所以要在吃之前才洗。

### 15-1. 干菜（mungnamul，晒干贮存的凉拌野菜）- 莙荙菜的贮藏法

| 步骤 | 方法 |
|:---|:---|
| 处理 | 把叶片和叶柄分开 |
| 焯水 | 沸水中叶片1-2分钟，叶柄3-5分钟 |
| 冲洗 | 用冷水冲洗降温 |
| 挤水 | 用手挤干 |
| 晾晒 | 摊在阴凉通风处，或挂在绳上 |
| 完全干燥 | 直到用手能捏碎 |
| 保存 | 与木炭或炒米一起放入密封容器 |
| 期限 | 6个月到1年以上 |

&nbsp;&nbsp;&nbsp;莙荙菜的贮藏实际上归结为干菜一种。焯后晒干的过程同时做了两件事：减少草酸，延长贮藏期。焯水时草酸流失到水中，所以干制的莙荙菜是以比鲜菜草酸更少的状态保存的。

> **做成干菜后，维生素C大部分消失，但维生素A、维生素K、矿物质和膳食纤维得以保留。冬季的维生素C不是来自晒干的菜，而是来自田里立着的鲜叶或发酵食品。要在了解这一区别的基础上制订贮藏计划。**

&nbsp;&nbsp;&nbsp;晒得干透的莙荙菜可以用手搓成粉备用。体积大幅缩小便于保存，往汤或粥里每次放一勺就能补充营养。整片晒干的则用水泡发后拌成凉拌野菜或炒食。泡发时先放在温水中两个小时左右，再煮一次就会变软。

| 其他方法 | 内容 | 评价 |
|:---|:---|:---|
| 盐渍 | 用盐腌渍叶柄 | 叶柄腌后仍保持形状 |
| 乳酸发酵 | 用2-3%的盐，像韩式泡菜那样 | 维生素C保留相当一部分 |
| 酱菜 | 叶柄腌过后，浸入大酱或酱油中 | 可存放几个月 |

&nbsp;&nbsp;&nbsp;叶柄粗厚的特性在贮藏中很有利。叶片一腌就软塌塌的，叶柄却仍保持脆感，所以能做成酱菜或腌菜。把叶片和叶柄分开，用不同方式贮藏，是使用莙荙菜的窍门。叶片焯后晒干，叶柄则盐渍或做成酱菜。

## 16. 烹饪与加工

| 方法 | 燃料 | 维生素C保留 | 草酸 |
|:---|:---:|:---:|:---|
| 嫩叶生吃 | 无 | 最高 | 不减少，但嫩叶草酸本来就少 |
| 焯后凉拌 | 少 | 一半以下 | 大幅减少 |
| 放入汤中 | 与其他烹饪兼用 | 连汤一起吃则可保留 | 不减少 |
| 炒 | 少 | 中等 | 不减少 |
| 乳酸发酵 | 无 | 保持相当多 | 略有减少 |
| 晒干磨粉 | 干燥时靠阳光和风 | 几乎没有 | 焯后晒干则会减少 |

&nbsp;&nbsp;&nbsp;莙荙菜烹饪的基本做法是把叶片和叶柄分开。两者厚度不同，熟的时间也不同。一起下锅的话，叶片会煮烂而叶柄还没熟。按先下叶柄、稍后再下叶片的顺序，两者都能熟得恰到好处。

| 部位 | 特性 | 用途 |
|:---|:---|:---|
| 嫩叶 | 柔软，草酸少 | 生吃、韩式现拌泡菜（geotjeori）、沙拉 |
| 成长的叶片 | 厚，草酸多 | 焯后凉拌、汤、干菜 |
| 叶柄 | 脆嫩多汁 | 炒菜、酱菜、盐渍 |
| 粗叶脉 | 老韧 | 切碎放入汤或粥中 |

&nbsp;&nbsp;&nbsp;莙荙菜在韩国的餐桌上长期被用作大酱汤的食材。放进大酱汤的做法，在灾害情境下同样合理。放进本来就在煮的火上，不需要额外燃料；大酱的咸味和鲜味弥补了莙荙菜的清淡；大酱中的蛋白质与莙荙菜中的微量营养素互相补充。不过连汤一起吃的话，草酸也会一并摄入，所以与其每天只喝汤，不如与焯后倒掉水的烹饪方式交替使用，这样更均衡。

&nbsp;&nbsp;&nbsp;加一点油，在营养上更有利。莙荙菜所含的维生素A、维生素K和维生素E是脂溶性的，有油才能吸收。加入磨碎的紫苏（荏）籽或芝麻，或放进用大豆磨成的汤汁里，也有同样的效果。自古以来用紫苏（荏）籽粉拌莙荙菜凉拌野菜，并不只是口味的问题。

&nbsp;&nbsp;&nbsp;正如糖类0.00g这个成分值所显示的，莙荙菜没有甜味，香气也弱。这意味着它清淡，但在灾害情境下这反而是优点。香气浓的蔬菜几天就会吃腻，清淡的则能成为接纳其他味道的底子。它与大酱、酱油、紫苏（荏）、辣椒、大蒜都搭配，每天吃也不腻。口味等级S就是由此而来。

## 17. 全年作业日程

| 月份 | 作业 |
|:---|:---|
| 1月 | 收获冬季叶片（越冬植株）。检查种子并规划田块 |
| 2月 | 翻堆堆肥。准备基肥 |
| 3月 | 中旬起春播。施基肥并起垄。留种株开始抽薹 |
| 4月 | 第1次间苗（收获嫩叶）。除草。给留种株立支架 |
| 5月 | 第2次间苗。开始首次收获。留种株开花，做好隔离管理 |
| 6月 | 进入反复收获期。夏播（可选）。留种株结实 |
| 7月 | 反复收获。韩国的梅雨季（6月下旬至7月）做好排水管理。收获留种株的种子 |
| 8月 | 反复收获。下旬起秋播。监测褐斑病 |

| 11月 | 继续收获。选定留种株。做越冬准备（培土、覆盖稻草） |
| 12月 | 把现有的叶片一片一片收获。检查贮藏品 |

&nbsp;&nbsp;&nbsp;从这张按韩国气候编排的表中应当看到的是没有空白。十二个月当中没有写收获的月份只有2月，而且只要有成功越冬的植株，这一格也会被填上。与生菜只有四个月、结球生菜只有一两个月能上餐桌相比，莙荙菜的地位就清楚了。

&nbsp;&nbsp;&nbsp;10月是叶片最好的月份。随着气温下降，叶片变柔嫩，草酸减少，甜味略有上升。整个夏天都在焯着吃老叶，到了秋天就可以生吃了。制作干菜的时间也以这个时候为宜。叶子多，天气干燥，容易晒干。

| 类别 | 春播 | 夏末播种 |
|:---|:---|:---|
| 播种 | 3月中旬-5月初 | 8月下旬-9月初 |
| 首次收获 | 5月中旬 | 10月中旬 |
| 收获期 | 5月-10月 | 10月-11月，越冬则到翌年春天 |
| 叶片品质 | 夏季变老韧 | 始终柔嫩 |
| 抽薹风险 | 早播时因低温当年抽薹 | 低 |

&nbsp;&nbsp;&nbsp;春季和夏末各播一次，在韩国实际上可以全年都有收获。春播的植株在夏季高温下叶片变老的时候，夏末播种的植株长了起来，由它们长出秋季的柔嫩叶片。再从中选几株使其越冬，来年作为留种株。这个循环一旦步入正轨，莙荙菜几乎不用费工，就在田边一角持续运转。

> **种莙荙菜的理由，不在于某一项出众的指标。不被炎热、寒冷、病虫害和盐分击垮，种一次就能长期收获，种子可保存5年，天天吃也不腻。在任何条件下都不会沦为最差的这一特性，灾害持续得越久就越显出价值。**
