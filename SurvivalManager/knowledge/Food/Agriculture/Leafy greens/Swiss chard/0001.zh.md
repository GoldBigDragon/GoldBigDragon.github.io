## 引言
&nbsp;&nbsp;&nbsp;莙荙菜（Beta vulgaris subsp. cicla）按现今的分类属于苋科（藜科并入其中），是叶菜，与红菜头、甜菜是同一物种的不同亚种。红菜头和甜菜朝着让根膨大的方向分化，莙荙菜则朝着培育叶和叶柄的方向分化。祖先是地中海和大西洋沿岸海边的野生甜菜，凭这一出身，它的耐盐性在叶菜中居于最高之列。综合等级为D（39.4分，有效183种中第118名），副食为SS（64.4分）。值得留意的项目是温度幅度SS（生长5-30℃，幅度25℃），夏天也能生长，能耐受零下5℃，几乎没有季节空白。不断掰取外叶的持续性A、几乎不需要防治这一评价、常温密封5年的种子寿命（S）也是优势。弱点是每100g只有18kcal，单位面积热量为D；草酸含量高，不宜大量生吃，需要焯水（烹调·加工A）；它是两年生植物，花粉随风飞散，会与红菜头、甜菜杂交，留种（A）受到限制。没有哪一项出众，但也没有哪一项崩溃，在其他叶菜全部失败的含盐土地上，它几乎是唯一留下来的、站到最后的作物。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | D | 39.4 |
| 短期 | D | 39.9 |
| 长期 | D | 39.0 |
| 副食 | SS | 64.4 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：蛋白质密度、设施负担、温度幅度。S：微量营养素（17种）、收获速度、口味、国内种植普及度、种子寿命。A：持续性、烹调·加工要求度、耐寒性、连作适应性、产量稳定性、自留种。B：施肥、水消耗量、光照 |
| 劣势 | E：非食用价值。D：单位面积热量、耐储性。C：病虫害压力、防治自立度、无合成投入产量保持率、整地·挖掘能量 |

> **耐储性D是掰下叶片之后的数值，立在田里的莙荙菜不计入这一计算。只要当天摘取需要的量，就不必储存。**

&nbsp;&nbsp;&nbsp;防治自立度C并不是说不用药就难以种植，而是说作为依据的资料不足。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 苋科甜菜属两年生草本。与红菜头、甜菜、饲用甜菜、野生甜菜是同一物种，因此相互杂交，菠菜也同属苋科。别名有瑞士甜菜、牛皮菜、厚皮菜 |
| 叶、茎 | 叶片呈宽卵形、有光泽，叶脉粗，叶面起皱。叶柄厚实多汁，有白、红、黄、粉色。茎被压缩得几乎看不见，叶从株基部呈放射状长出 |
| 根、花、果实 | 直根深扎，但与红菜头不同，不膨大而较细。第二年抽薹，绿色小花呈穗状着生。果实是几粒种子聚在一起的种球 |

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 发芽 | 播种后7-14天 | 一个种球会同时出多个芽 |
| 幼苗期 | 发芽后2周 | 真叶2-3片。第一次间苗的时期 |
| 营养生长期 | 播种后3-7周 | 叶片迅速长大 |
| 收获、反复采收 | 40-60天起 | 外叶20-30cm。从外侧掰取，中心会长出新叶 |
| 抽薹 | 翌年春 | 经历低温后抽出花茎 |

&nbsp;&nbsp;&nbsp;每100g热量18kcal、水分90%以上、蛋白质1.78g（占热量的39.6%）、碳水化合物3.5-4.0g、膳食纤维1.5-2.0g，糖类为0.00g，所以几乎没有甜味。富含维生素A、C、E、K、叶酸、钙、铁、钾、镁，但因草酸，钙和铁的吸收率低，把莙荙菜当作钙来源来计算并不准确。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 生长范围5-30℃（幅度25℃），生长适温15-18℃。发芽适温20-25℃（低于10℃和高于35℃为极限）。到30℃仍能生长，但叶片变韧、草酸增多，可维持生长到零下5℃（盖稻草更耐寒） |
| 光 | 每天6小时以上。耐半阴（生长慢但叶片柔嫩），夏季遮光可延缓叶片变韧 |
| 水、土壤 | 总蒸散量约500mm。根深，比生菜耐旱。不挑土壤，pH 6.0-6.8（6.5左右最佳）。过湿则烂根 |

| 作物 | 耐盐性 |
|:---|:---|
| 莙荙菜、红菜头、甜菜 | 非常高。叶菜中居最上位 |
| 菠菜 | 中等。虽同科但比莙荙菜弱 |
| 生菜、大白菜、萝卜 | 低。盐害地里长不了 |
| 豆类 | 非常低。最先枯死 |

> **在被海啸或淹水带入盐分的土地、因地下水灌溉积累盐分的田里，莙荙菜几乎是唯一留下来的叶菜。在那样的土地上能否供给维生素和矿物质，就是这种作物存在的理由。**

&nbsp;&nbsp;&nbsp;莙荙菜把钠封存在液泡中以保护细胞质，反而将其用于调节渗透压。不过耐盐性并非无限。

| 品种 | 特点 |
|:---|:---|
| 青莙荙菜（白莙荙菜） | 叶柄白色至黄绿色。最常见，产量稳定，口感筋道 |
| 红莙荙菜、黄莙荙菜 | 叶柄红色至粉色（花青素）、黄色至黄绿色（β-胡萝卜素）。叶片柔嫩 |
| 福特胡克、红宝石 | 福特胡克是叶片大而厚的代表性白柄品种，红宝石是红色系，耐寒性好 |

&nbsp;&nbsp;&nbsp;颜色对栽培难度和产量影响不大，品种选择决定不了成败，是为数不多的这类作物。产量优先就选青莙荙菜和福特胡克，想越冬就选红宝石，想拓宽营养面就把红莙荙菜和黄莙荙菜混着种。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 耕深20-30cm（直根扎得深），垄高15-20cm、宽90-120cm，保证排水沟。是长期收获的作物，所以多施有机质 |
| 施肥（1,000㎡） | 氮8-10kg，腐熟堆肥1,000-1,500kg。播种前10天将堆肥、磷、钾全量和氮作基肥施入，追肥大体省略。新长的叶变小、颜色变淡就是养分耗尽了，这时再施稀肥。硼是重要的微量元素 |
| 替代资源 | 草木灰（每株一小撮，过量则缺硼）、稀释10-20倍的人尿（施在株间，沾到叶上会烧叶）、干海藻（供给钾和硼，莙荙菜不冲洗也耐受）、发酵过的油饼 |

| 栽培类型 | 播种 | 收获 | 备注 |
|:---|:---|:---|:---|
| 春播 | 3月中旬-5月初 | 5月中旬起持续 | 最常见。播得很早则因低温当年抽薹 |
| 夏播 | 6-7月 | 8-9月 | 对高温也较耐受 |
| 秋播 | 8-9月 | 10-11月 | 叶片柔嫩 |
| 越冬栽培 | 9-10月 | 翌年春 | 中部以南 |

&nbsp;&nbsp;&nbsp;莙荙菜的种子不是一粒种子，而是2-5粒种子聚成的种球。同一处会出多个芽，所以间苗必不可少，果皮上有抑制发芽的物质，用水浸泡后发芽更好。

> **在莙荙菜上，间苗不是可选项，而是必须。一个种球会冒出三四个芽，不管的话，同一处的几棵植株互相挤压着生长。个个又小又弱，没有一棵能长好。**

| 播种 | 标准 |
|:---|:---|
| 种子处理 | 水中浸泡2-3小时（长则一夜），期间换一两次水。在50-55℃的水中浸10-15分钟杀死表面病原菌，沾上干草木灰便于处理。浸过的种子处理后立即播下 |
| 播种 | 深1-2.5cm（种球大，比生菜播得深），行距30-50cm，穴播则每穴2-3个种球。7-14天发芽 |
| 间苗 | 真叶2-3片时按5cm第一次（当嫩叶吃），4-5片时按10-15cm第二次（作凉拌菜吃）。想长大的话最终20cm。不要拔，用剪刀剪断 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种至发芽 | 不让土壤变干（种球要吸足水才会发芽） |
| 幼苗期、生长期 | 表土变干时浇透（与其经常少浇，不如偶尔浇透，引导根向下） |
| 反复采收期 | 掰取叶片后浇水 |
| 雨季、冬季 | 雨季整修排水沟，冬季几乎不浇 |

&nbsp;&nbsp;&nbsp;叶片小而韧是持续缺水，下部叶片发黄、基部变软是过湿。叶柄纵向开裂，是干透后突然浇了大量水所致。稻草和干草覆盖能大幅减少蒸发，在盐害地还能延缓盐分上升，摆在半阴处能减少夏季蒸发并使叶片柔嫩。

| 管理 | 方法 |
|:---|:---|
| 间苗、除草 | 间苗必须做。除草只在前期，因为叶片盖满后杂草会受到抑制。培土、摘心、立支柱大体不需要 |
| 清理枯叶 | 随时摘掉下部发黄枯萎的叶片 |
| 抽薹 | 幼苗长期经历10℃以下的低温，或遇到早春倒春寒，当年内就会抽薹。霜冻完全过去后再播，或早播时用稻草或干草保持地温。已经抽出的花茎无法逆转 |
| 长期采收 | 掰取后浇水，新叶变小就施稀肥。始终保留中心叶6片以上。夏天放半阴处，秋天盖稻草准备越冬。冬天逐片掰取现有叶片食用（新叶几乎不再长） |

## 6. 病虫害与养分问题
&nbsp;&nbsp;&nbsp;十字花科的害虫（菜粉蝶、小菜蛾、跳甲、根肿病）、菊科的病害（菌核病）、茄科的病虫害不会找上莙荙菜，来的是苋科自己的蚜虫、叶螨、叶甲。

| 病虫害 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 褐斑病 | 叶片出现褐色圆形斑点，中央变灰（最常见）。高温高湿 | 清除病叶、通风、轮作 |
| 霜霉病、白粉病 | 叶背白色霉层与叶面发黄 / 叶面白粉。凉爽潮湿时 / 干燥且昼夜温差大时 | 通风、早晨浇水 / 通风与光照、稀释牛奶 |
| 根腐病、立枯病 | 基部褐变并萎蔫 / 幼苗在基部缢缩倒伏。过湿、密播 | 提高垄面、排水、间苗、温水浸种 |
| 萎黄病 | 叶片发黄，叶脉凸显。连作、蚜虫传播的病毒 | 防治蚜虫、轮作、清除病株 |
| 蚜虫、叶螨、潜叶蝇 | 在叶背吸汁并传播病毒（蚜虫最常见） / 结蛛网 / 钻进叶内形成白色条纹 | 用强水流冲洗、肥皂水、保护天敌 / 喷水、提高湿度 / 清除受害叶 |
| 蛞蝓、地老虎幼虫 | 叶片出现孔洞 / 咬断幼苗基部 | 夜间捕捉、撒灰或稻壳带 / 夜间在土里找出来捕捉 |

> **莙荙菜的病大多只让叶片受损，不会让整株死亡。这就是莙荙菜在不用药的农业中表现强劲的根本原因。摘掉病叶，新叶就会长出来，这种反复本身就是防治。**

&nbsp;&nbsp;&nbsp;把过筛的草木灰撒在叶片和田里，或使用稀释300-500倍的木醋液，轮作要与菠菜、红菜头、甜菜一起算，休耕2年以上。起垄保证排水是治烂根的根本对策，病叶要搬出田外或烧掉，收获时优先摘除病叶和受害叶是莙荙菜独有的防治。

| 症状 | 原因与对策 |
|:---|:---|
| 整片叶发黄、植株矮小 | 缺氮。腐熟堆肥、稀释10-20倍的人尿 |
| 新叶扭曲开裂、生长点变黑 | 缺硼。干海藻、充分腐熟的堆肥、减少石灰 |
| 叶片小而薄 | 水分和养分不足。同时增加浇水和施肥 |
| 叶片过于松软、蚜虫聚集 | 氮过量。停止供氮 |
| 叶尖干枯、生长停滞 | 盐分过多。浇足水冲洗 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 生菜、茼蒿等菊科，萝卜、大白菜等十字花科（不共有病虫害），大葱、小葱、大蒜（气味扰乱害虫），玉米等高秆作物（夏天遮出半阴） |
| 差 | 菠菜、红菜头、甜菜（同科或同种，共有病害）、莙荙菜连作（病原菌积累） |

&nbsp;&nbsp;&nbsp;以3年为周期，按莙荙菜等苋科→豆科（固氮）→十字花科或禾本科（苋科病原菌断粮）的顺序轮换，就能在病原菌密度降低的状态下重新种莙荙菜。连作适应性A的标准是休耕2年，比生菜和结球生菜的2-3年宽松。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 第一次间苗的嫩叶25-30天（真叶2-3片，沙拉或生拌），第二次间苗35-40天（真叶4-5片，焯水凉拌），首次收获40-60天（外叶长20-30cm），此后每周反复1-2次 |
| 采摘方法 | 从外侧起，用刀或剪刀剪下长足的叶片，在叶柄与茎相接处留3-5cm。一次只摘全部叶片的三分之一至一半以下，始终保留中心叶6片以上。摘后浇水 |
| 收获量 | 一株一个月1-1.5kg。春播的从5月到10月，越冬的到翌年春。每位成年人5-10株 |

> **始终保留中心叶6片以上。留下的叶片是光合作用的工厂，这座工厂会长出下一批叶片。贪心全摘光，那棵植株就会就此停住。**

| 留种 | 标准 |
|:---|:---|
| 两道难关 | 两年生，要经历低温才抽薹，而且是风把花粉传到远处的风媒异花授粉。与红菜头、甜菜、饲用甜菜、其他品种的莙荙菜、野生甜菜完全杂交，不与菠菜、藜、苋杂交 |
| 防杂交 | 与其他Beta vulgaris开花株隔离1,000m以上（邻家的田难以管控）。错开时间种植最现实，田小的话在开花前给花茎套上布袋 |
| 步骤 | 秋天选叶片大、无病、品种颜色鲜明的植株。越冬（中北部露地越冬困难，拔出储存后春天再栽）、3-4月抽薹（立支柱）、5-6月开花，7-8月种球变褐干燥后连茎割下，在阴凉处晾1-2周后捋下或搓揉脱粒，簸选后密封 |
| 产量、寿命 | 一株可得数百至数千个种球，一个种球含2-5粒种子。种子寿命常温密封5年，每年用20个种球确认发芽情况 |

> **莙荙菜留种不是每年要做的事，而是4-5年一次，且在那一年好好隔离着做。留种用的植株最少5棵，尽量留10棵以上。异花授粉的作物只从一两棵植株上采种，没几代就会出现近交衰退。**

## 9. 储存
| 方法 | 步骤与期限 |
|:---|:---|
| 去除水分后放凉爽处 | 不洗，只抖掉泥土。3-5天 |
| 用纸或布包好立放 | 用报纸或干布包好立放（布太湿会烂）。5-7天 |
| 茎插水 | 叶柄基部泡在水里立放（每天换水）。5-7天 |
| 地窖、土窖 | 立放在凉爽的地下空间。1-2周 |
| 干菜 | 叶和叶柄分开，在沸水里叶焯1-2分钟、叶柄焯3-5分钟，用冷水冲洗后晾干。与木炭或炒米一起放入密封容器。6个月-1年以上 |
| 叶柄腌渍 | 盐腌（保留形状）、2-3%盐的乳酸发酵（保留相当多的维生素C）、酱渍（数月） |

> **做成干菜后，维生素C大多消失，但维生素A、维生素K、矿物质和膳食纤维还在。冬天的维生素C不是来自晒干的，而是来自立在田里的鲜叶或发酵食品。**

&nbsp;&nbsp;&nbsp;莙荙菜的储存事实上只归结为干菜这一种，晒得很干的可以搓成粉存放。

## 10. 烹调与注意事项
| 部位 | 性质 | 用途 |
|:---|:---|:---|
| 嫩叶 | 柔嫩，草酸少 | 生吃、生拌、沙拉 |
| 成熟叶 | 厚实，草酸多 | 焯水凉拌、汤、干菜 |
| 叶柄 | 脆而多汁 | 炒、酱菜、腌渍 |
| 粗叶脉 | 韧 | 切碎放进汤或粥里 |

| 处理 | 草酸减少 |
|:---|:---|
| 生吃 | 不减少（嫩叶含量少） |
| 焯水后弃水 | 大幅减少，最为可靠。维生素C减少到一半以下，叶酸也有一部分流失 |
| 焯水的水做汤、炒 | 不减少（草酸在汤里） |
| 蒸、乳酸发酵 | 略有减少。发酵能较多保留维生素C |

> **关键不在于焯水本身，而在于把焯过的水倒掉。草酸不是被破坏，而是转移到了水里。那水拿来做汤，草酸也会跟着进来。**

&nbsp;&nbsp;&nbsp;莙荙菜和菠菜的草酸每100g有数百mg，比羽衣甘蓝（20-50mg）和生菜（数十mg）高，会与钙结合而阻碍吸收。与富含钙的食材一起吃也是一种应对。莙荙菜长期用作大酱汤的材料，加一点油在营养上有利，没有甜味，香气也淡。莙荙菜没有急性毒性。

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 收获越冬株的冬季叶片，检查种子。2月翻堆堆肥 |
| 3-4月 | 3月中旬起春播（基肥、起垄），留种株开始抽薹。4月第一次间苗（收获嫩叶）、除草、给留种株立支柱 |
| 5-6月 | 5月第二次间苗和首次收获，留种株开花与隔离管理。6月进入正式的反复采收，可选择夏播，留种株结实 |
| 7-8月 | 7月反复采收、雨季排水管理，收获留种株的种子。8月反复采收，下旬起秋播，观察褐斑病 |
| 9-10月 | 9月对秋播部分间苗，继续收获春播植株。10月收获旺季（叶片最好的月份），制作干菜 |
| 11-12月 | 11月继续收获，选留种株，做越冬准备（培土、盖稻草）。12月逐片采收现有叶片，检查储存品 |

&nbsp;&nbsp;&nbsp;春播的从5月中旬收获到10月，夏天叶片变韧；夏末播种（8月下旬-9月初）的从10月中旬开始收获，到最后都柔嫩，抽薹风险低。播两次，事实上全年都有得收。

> **种莙荙菜，不是因为哪一项出众。不被炎热、寒冷、病虫害、盐分击垮，种一次就能收获很久，种子能保存5年，天天吃也不腻。在任何条件下都不会垫底的这一特性，灾难拖得越久越能发光。**
