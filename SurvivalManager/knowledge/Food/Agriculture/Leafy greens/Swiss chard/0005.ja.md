## 8. 栽培管理

### 8-1. 手間のかからない作物

| 作業 | 必要かどうか | 内容 |
|:---|:---|:---|
| 間引き | 必須 | 種子球のため、必ず行います |
| 草取り | 初期のみ | 葉が覆えば雑草が抑えられます |
| 土寄せ | おおむね不要 | 長く育てるなら、株元に土を軽くかけます |
| 摘心 | 不要 | 側枝が出ません |
| 支柱 | 不要 | 草丈が低いです |
| 摘花 | 抽だい時 | 花茎が立ったら切って時間を稼ぎます |
| 枯れ葉の整理 | 随時 | 下のほうの黄色く枯れた葉を取り除きます |

&nbsp;&nbsp;&nbsp;フダンソウの栽培管理は、リストが短いのが特徴です。間引きと水やりと葉摘みがほぼすべてで、あとは必要なときだけ行います。アブラナ科の作物が防虫ネットと虫取りに追われ、玉レタスが結球条件を合わせるために時期を競うのと比べると、手間が大幅に少なくて済みます。災害時には労働が最も貴重な資源であるため、この差は実際には大きいのです。

&nbsp;&nbsp;&nbsp;草取りは初期にだけ必要です。フダンソウが育って葉が地面を覆うと、その下には光が届かず、雑草が抑えられます。幼いころに雑草に押されないようにしてやれば、その後は自力で場所を守ります。ただし、根が浅い部分もあるため、株の近くでは深く耕さず、手で抜きます。

&nbsp;&nbsp;&nbsp;下のほうの黄色く枯れた葉を取り除く作業は、しておいたほうがよいです。枯れかけた組織が灰色かび病の足場になり、その下が湿ってナメクジが集まります。取り除くときは、葉柄をつかんで横に折り、茎からきれいに外れるようにします。

### 8-2. 抽だいへの対処法

&nbsp;&nbsp;&nbsp;フダンソウは二年生なので、正常であれば翌年の春に花茎が立ちます。低温を経験することが引き金で、これを春化と呼びます。問題は、この春化が予定より早く起こることがあるという点です。

| 条件 | 結果 |
|:---|:---|
| 幼い苗が10℃未満の低温に長くさらされる | その年のうちに花茎が立ちます |
| 早春に播種したあとの寒の戻り | 同じことが起こります |
| 越冬後の春 | 正常な抽だい。その株は終わりです |
| 極端な乾燥や暑さのストレス | 抽だいが早まることがあります |

&nbsp;&nbsp;&nbsp;花茎が立つと、葉が硬くなり、苦みが出てきます。植物の優先順位が葉から種子へと切り替わり、葉の養分が花茎に抜けていき、組織にリグニンがたまるためです。この切り替わりは元に戻せません。

&nbsp;&nbsp;&nbsp;ただし、花茎を切り取れば、少し時間を稼ぐことができます。花茎が上がり始めたときに株元近くで切ると、植物は再び葉を出そうとし、その間に数週間余分に収穫できます。やがて別の花茎が上がってくるため、完全な解決ではありませんが、シーズンを少し延ばす方法としては使えます。種を採る株だけを残し、残りはこのように扱います。

> **早春まきで花茎が立つのを防ぐには、幼い苗が低温に長くさらされないようにします。霜が完全に過ぎ去ってから播くか、早く播くなら、わらや枯れ草をかぶせて地温を保ちます。すでに立ってしまった花茎は元に戻せません。**

### 8-3. 一株を長く使う管理

| 項目 | 内容 |
|:---|:---|
| 葉を摘んだあと | 水を与えます。新しい葉をつくるのに水分が要ります |
| 養分の補給 | 新しい葉が小さくなったら、薄めた肥料を与えます |
| 残す葉 | 常に中心の葉を6枚以上 |
| 夏 | 半日陰をつくってやると、葉が柔らかく保たれます |
| 秋 | わらをかけて越冬に備えます |
| 冬 | 残っている葉を一枚ずつ摘んで食べます。新しい葉はほとんど出ません |

&nbsp;&nbsp;&nbsp;フダンソウを1年以上使うには、冬をどう越すかが鍵です。韓国中部以南では、株元に土を盛り、わらや落ち葉をかけると、たいてい生き残ります。韓国中部以北では失敗することがあり、その場合は、秋に播いて冬の前に収穫する方向に計画を変更します。

&nbsp;&nbsp;&nbsp;越冬に成功した株は、春に再び葉を出しますが、長くはもちません。冬の低温が春化として作用し、春にすぐ花茎が立つためです。したがって、越冬株の春の収穫は数週間分のおまけと考え、その株から種を採ったあと、新しく播種する流れが適切です。

## 9. 病害虫――薬を使わずに防ぐ方法

&nbsp;&nbsp;&nbsp;評価表の防除自立度の根拠に書かれた「防除ほぼ不要」という文言が、この節の要約です。フダンソウは、薬なしで育てるのが最も容易な葉菜に入ります。理由は、その所属にあります。

| 作物群 | 主な害虫 | フダンソウに来るか |
|:---|:---|:---|
| アブラナ科 | モンシロチョウ、コナガ、ノミハムシ、根こぶ病 | 来ません |
| キク科 | 菌核病、べと病 | 来ません |
| ナス科 | 疫病、タバコガ | 来ません |
| ヒユ科（フダンソウ自身） | アブラムシ、ハダニ、ハムシ | 来ます |

&nbsp;&nbsp;&nbsp;畑で最も大きな病害虫の圧力を生み出すのは、アブラナ科とキク科です。キムジャン（越冬用キムチ漬け）用の野菜と葉菜が、その二つのグループに集中しているからです。フダンソウはどちらにも属さないため、その圧力から外れた位置にあります。ハクサイが虫に食われる年にも、フダンソウは無事です。

### 9-1. 主な病害

| 病害 | 症状 | 発生条件 | 薬を使わない対応 |
|:---|:---|:---|:---|
| 褐斑病 | 葉に褐色の円形の斑点ができ、中心が灰色に変わります | 高温多湿 | 病葉の除去、風通し、輪作 |
| べと病 | 葉の裏に白いカビ、表は黄変 | 涼しく湿っているとき | 風通し、朝の灌水、病葉の除去 |
| うどんこ病 | 葉の表面に白い粉 | 乾燥して日較差が大きいとき | 風通しと日照、牛乳の希釈液 |
| 根腐病 | 株元が褐変し、株がしおれます | 過湿、排水不良 | 畝を高くする、排水 |
| 苗立枯病 | 幼い苗が株元でくびれて倒れます | 過湿、密播 | 排水、間引き、温湯浸漬 |
| 萎黄病 | 葉が黄色くなり、葉脈が目立ちます | 連作、ウイルス | アブラムシの防除、輪作、罹病株の除去 |

&nbsp;&nbsp;&nbsp;フダンソウで最もよく見られる病気は、褐斑病です。夏の韓国の梅雨（チャンマ、6月下旬～7月）の時期に、葉に褐色の斑点ができ、ひどいと葉全体が枯れます。ただ、この病気は、その年の葉を数枚失わせるだけで、株を枯らすことはありません。病葉を取って畑の外へ持ち出せば、広がる速度が遅くなり、その後に出てくる新しい葉は健康です。摘み続ける収穫方式が、この病気に対する防除の役割を兼ねるわけです。

&nbsp;&nbsp;&nbsp;萎黄病は注意が必要なほうです。ウイルスが原因で、アブラムシが媒介します。かかった株は回復しないので抜いて処分し、アブラムシの個体数を減らすことが唯一の対応です。ビーツとテンサイが同じウイルスにかかるため、そちらから移ってくることがあります。

> **フダンソウの病気の大部分は、葉を失わせるにとどまり、株を枯らしません。これが、フダンソウが薬を使わない農業に強い根本的な理由です。病葉を取り除けば新しい葉が上がってきて、その繰り返しがそのまま防除になります。**

### 9-2. 主な害虫

| 害虫 | 被害 | 薬を使わない防除 |
|:---|:---|:---|
| アブラムシ | 葉の裏で汁を吸い、ウイルスを媒介します | 強い水流で洗い流す、石けん水、天敵の保護 |
| ハダニ | 葉の裏で汁を吸い、クモの巣のような糸を張ります | 水の噴霧、湿度を上げる |
| フダンソウにつくハムシ類 | 葉をかじります | 手で捕殺 |
| ハモグリバエ | 葉の中に潜り込み、白い筋模様をつけます | 被害葉の除去 |
| ナメクジ | 葉に穴を開けます | 夜に捕る、灰や籾殻の帯 |
| ネキリムシ（ヤガ類の幼虫） | 幼い苗の株元を切り倒します | 夜に土の中から探して捕る |

&nbsp;&nbsp;&nbsp;アブラムシが、フダンソウで最もよく見られる害虫です。ハダニと同様に乾燥した条件で増えるため、水を十分に与え、ときどき葉の裏に水を強くかけてやるだけでも、かなりの部分が抑えられます。ハダニは特に乾燥を好むので、水をかけること自体が防除になります。

&nbsp;&nbsp;&nbsp;ハモグリバエは、幼虫が葉の組織の中に潜り込み、白い筋を残します。葉の中にいるため、表面に何を散布しても届かず、そのため薬があっても厄介な害虫です。対応は、筋が見える葉を摘んで畑の外へ持ち出すことだけです。フダンソウでは、これが大きな負担ではありません。もともと葉を摘んで食べる作物で、被害葉を選んで取り除く作業が収穫と重なるからです。

### 9-3. 天然の防除資材と耕種的防除

| 防除資材 | 調製法 | 対象 |
|:---|:---|:---|
| 石けん水 | 香りのない石けん20gを水1Lに溶かします | アブラムシ、ハダニ |
| 牛乳の希釈液 | 牛乳と水を1対9で混ぜます | うどんこ病 |
| 草木灰の散布 | ふるいにかけた灰を葉と畑にまきます | 害虫の忌避、カリウムの供給 |
| 草木灰の帯 | 株の周りに乾いた灰をまきます | ナメクジの遮断 |
| 木酢液 | 300-500倍に薄めて噴霧します | 忌避効果 |
| 強い水流 | 葉の裏にかけます | アブラムシ、ハダニ |

| 原則 | 内容 |
|:---|:---|
| 輪作 | ホウレンソウ、ビーツ、テンサイとひとまとめにして、2年以上休作します |
| 風通し | 間引きで間隔を確保します |
| 排水 | 畝を立てます。根腐れの根本的な対策です |
| 灌水の時間帯 | 早朝に与えて、日中のあいだに葉が乾くようにします |
| マルチング | 雨のはね返りを防いで、土壌伝染の経路を断ちます |
| 残渣処理 | 病葉は畑の外へ持ち出すか、焼却します |
| 健全な種子 | 温湯浸漬で種子伝染を減らします |
| 収穫を兼ねた防除 | 病葉と被害葉を優先して摘み取ります |

&nbsp;&nbsp;&nbsp;最後の項目が、フダンソウならではの防除方式です。摘み続ける作物なので、葉を摘むときに順序を決めれば、それがそのまま防除になります。病斑のある葉、ハモグリバエの筋が見える葉、アブラムシがついた葉を、先に摘んで処理します。食べられるものは洗って食べ、そうでないものは畑の外へ持ち出します。別に時間を割くことなく、収穫と防除を一度に終えます。

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 天然素材による対処 |
|:---|:---|:---|
| 葉全体が黄色く、株が小さいです | 窒素欠乏 | 完熟堆肥、薄めた尿（10-20倍） |
| 葉の縁が茶色く枯れます | カリウム欠乏 | 草木灰を少量 |
| 生育が不振で、葉が紫色を帯びます | リン酸欠乏 | 骨粉、草木灰。地温が低いときも同じ症状が出ます |
| 葉脈の間が黄色くなります | マグネシウム欠乏 | 堆肥を増やします |
| 新しい葉がねじれて裂け、生長点が黒くなります | ホウ素欠乏 | 乾燥海藻、よく腐熟した堆肥。石灰を減らします |
| 葉が小さくて薄いです | 水分と養分の不足 | 灌水と施肥をあわせて増やします |
| 葉が軟弱すぎてアブラムシが集まります | 窒素過剰 | 窒素の供給を止めます |
| 葉先が枯れて生育が止まります | 塩分過多 | 水を十分に与えて洗い流します |

&nbsp;&nbsp;&nbsp;フダンソウで特徴的に見ておくべきものが、ホウ素欠乏です。フダンソウ属の植物はホウ素の要求量が大きいため、ほかの作物ではあまり現れないこの症状が、フダンソウでは実際に出ます。新しく出てくる葉が縮れてねじれ、葉脈の間が裂け、ひどい場合は生長点付近が黒く枯れます。生長点が枯れるとその株は終わりなので、欠乏症の中で最も致命的です。

&nbsp;&nbsp;&nbsp;ホウ素が不足する条件は二つあります。砂地で雨水に流されてしまう場合と、石灰や草木灰を多く入れてpHが高くなった場合です。後者のほうがよくあります。土にホウ素があっても、アルカリ条件では、植物が吸収できない形に変わります。草木灰は手軽なカリウム源ですが、一度にたくさん入れるとこの問題を招くので、フダンソウでは特に少量ずつ分けて入れます。乾燥海藻はホウ素を含んでいるので、補う材料になります。

&nbsp;&nbsp;&nbsp;最後の行の塩分過多は、ほかの作物なら枯れてしまう条件です。フダンソウはかなり高い塩分まで耐えますが、無限ではなく、限界を超えると葉先が枯れて生育が止まります。対応は、水を十分に与えて、根の周りの塩分を下へ洗い流すことです。乾いた状態で放置すると、塩分が根の近くに濃縮されて、かえって悪化します。塩害地でフダンソウを育てるとき、水を節約することが必ずしも正しくない理由です。

## 11. 間作と輪作

| 相性 | 対象 | 効果 |
|:---:|:---|:---|
| 良い | マメ科の作物（エンドウ、インゲンマメ、ササゲ） | 窒素を固定して残してくれます |
| 良い | サンチュ、シュンギクなどのキク科 | 病害虫を共有しません |
| 良い | ダイコン、ハクサイなどのアブラナ科 | 病害虫を共有しません |
| 良い | 長ネギ、ワケギ、ニンニク | においが害虫を惑わせます |
| 良い | トウモロコシなどの背の高い作物 | 夏に半日陰をつくってくれます |
| 悪い | ホウレンソウ、ビーツ、テンサイ | 同じ科、または同じ種で、病害を共有します |
| 悪い | フダンソウの連作 | 病原菌がたまります |

&nbsp;&nbsp;&nbsp;フダンソウの間作の相性がよい理由は単純です。アカザ科、つまりヒユ科に属する作物は畑に多くないので、大半の作物と病害虫を共有しないからです。アブラナ科のそばに植えても、キク科のそばに植えても、互いに悪いことはありません。畑の配置を考えるとき、フダンソウはどこに入れても無難なピースです。

&nbsp;&nbsp;&nbsp;避けるべきなのは、ホウレンソウとビーツとテンサイだけです。特にビーツとテンサイは、フダンソウと同じ種なので病害虫を完全に共有し、あとで見る採種の問題まで重なります。この三つは一つのグループとして扱い、同じ年には同じ場所に置かず、輪作でもまとめて計算します。

| 輪作順序の例 | 年次 | 作物 | 畑で起こること |
|:---|:---:|:---|:---|
| 3年周期 | 1年目 | フダンソウなどのヒユ科 | 病原菌がたまり始めます |
| | 2年目 | マメ科（ダイズ、エンドウ、ササゲ） | 窒素が固定されて蓄積されます |
| | 3年目 | アブラナ科またはイネ科 | ヒユ科の病原菌が飢えます |
| | 再び1年目 | フダンソウ | 病原菌の密度が下がった状態で始まります |

&nbsp;&nbsp;&nbsp;連作適応性A、2年休作という基準は、サンチュと玉レタスの2-3年より寛容です。畑が狭くて厳密な輪作が難しいなら、最低限、場所を移すだけでも違いが出ます。

&nbsp;&nbsp;&nbsp;フダンソウをマメ科の後に置く配置が、特によく合います。フダンソウは窒素を好み、葉を出し続けるために窒素を絶えず使いますが、マメ科が残した窒素がその要求を満たします。玉レタスでは、マメ科が残した窒素が結球を妨げ、かえって問題になりますが、結球しないフダンソウでは、そのような副作用がありません。窒素が多ければ葉が大きくなり、それがそのまま収穫量です。

## 12. 収穫――摘み続ける技術

| 用途 | 播種後 | 状態 |
|:---|:---:|:---|
| 1回目の間引きの若葉 | 25-30日 | 本葉2-3枚。サラダやゴッチョリ（生キムチ） |
| 2回目の間引き | 35-40日 | 本葉4-5枚。下茹でしてナムル |
| 初回収穫 | 40-60日 | 外側の葉の長さ20-30cm |
| 繰り返し収穫 | その後ずっと | 週1-2回 |
| 冬の収穫 | 11月-翌年3月（韓国） | 育たないので、残っている葉を一枚ずつ |

### 12-1. 外側から摘む理由

&nbsp;&nbsp;&nbsp;フダンソウの生長点は、圧縮された短い茎の先端、株の真ん中に一つだけあります。そこから新しい葉が次々に上がってきて、外側へ押し出されながら育ちます。したがって、外側の十分に育った葉を摘み取っても、植物が失うのは、すでに光合成能力が落ちた古い葉だけで、生長点はそのまま残って新しい葉をつくり続けます。

&nbsp;&nbsp;&nbsp;逆に、真ん中を切り落としてしまうと、その株は終わりです。生長点がなくなれば、葉をつくる場所が失われます。フダンソウを根ごと引き抜いたり、株元ごと刈り取ったりする収穫は、その株を捨てると決めた場合にだけ行います。

| 項目 | コツ |
|:---|:---|
| 摘む葉 | 外側から、十分に育った葉 |
| 切る位置 | 葉柄が茎と接する部分から3-5cm残して切ります |
| 一度に摘む量 | 全体の葉の3分の1から半分以下 |
| 残す葉 | 常に中心の葉を6枚以上 |
| 道具 | 手でちぎらず、ナイフやはさみで切ります |
| 摘む時間帯 | 早朝。一晩かけて水分を含み、最も新鮮です |
| 収穫の周期 | 週1-2回 |
| 摘んだあと | 水を与えます |

> **常に中心の葉を6枚以上残します。残した葉が光合成の工場であり、その工場が次の葉をつくります。欲張ってすべて摘んでしまうと、その株はそのまま止まってしまいます。**

&nbsp;&nbsp;&nbsp;葉柄を3-5cm残して切るのには理由があります。茎にぴったりつけて切ると、生長点の近くに傷ができ、そこから病原菌が入ります。少し残しておけば、残った葉柄が乾きながら自然に落ち、傷が癒えます。手でちぎってはいけないというのも、同じ理由です。ちぎると、葉柄が茎から裂けて、縦に長い傷が残ります。

### 12-2. 一株からどのくらい採れるか

| 項目 | 値 |
|:---|:---|
| 1株あたりの月間収穫量 | 1-1.5kg |
| 収穫期間 | 春まきなら韓国では5月から10月まで、越冬すれば翌年の春まで |
| 必要な株数 | 大人1人あたり5-10株 |

&nbsp;&nbsp;&nbsp;1株から1か月に1-1.5kgが採れるという値が、フダンソウの実質的な生産力を示しています。葉柄が太くて水分が多く、重さがあるからです。葉だけを食べるサンチュと比べると、同じ体積でも重さが勝ります。

&nbsp;&nbsp;&nbsp;評価表の永続性Aと収穫速度Sをあわせて読むと、フダンソウのタイムテーブルが見えてきます。播種後50-60日で初回収穫となり、その後は霜が降りるまで続きます。春に播いたフダンソウが10月まで続くなら、5か月間収穫することになり、越冬に成功すればそれより長くなります。一度播いて得られる総量が、サンチュとは次元が違います。

&nbsp;&nbsp;&nbsp;葉柄を別に使うことも、収穫量に貢献します。葉と葉柄を分けておくと二つの食材が得られ、調理法が異なるため、同じものを食べているという感覚が薄れます。毎日食べなければならない状況では、この差には実際に意味があります。
