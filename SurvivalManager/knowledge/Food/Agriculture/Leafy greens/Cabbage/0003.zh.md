## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

&nbsp;&nbsp;&nbsp;结球甘蓝是十字花科（Brassicaceae）芸薹属（Brassica）的二年生草本植物。学名为Brassica oleracea var. capitata，与羽衣甘蓝、西兰花、花椰菜、苤蓝、抱子甘蓝同属一个物种的不同变种。人类从野生甘蓝中选育出叶片层层包卷这一性状，历经数千年培育，才有了今天的结球。

&nbsp;&nbsp;&nbsp;同属一个物种，在实际操作上意味着两件事。第一，会与羽衣甘蓝、西兰花、苤蓝相互传粉，导致种子混杂，这是留种时必须考虑的限制，也是第13节的主题。第二，整个十字花科作物共用同一批病虫害：菜粉蝶、小菜蛾、跳甲、根肿病会同时侵袭羽衣甘蓝、大白菜、萝卜和芥菜。

&nbsp;&nbsp;&nbsp;结球甘蓝原产于地中海沿岸和西欧大西洋沿岸。由于源自凉爽的海洋性气候，它不耐高温：超过25℃就不结球，持续30℃时已经形成的菜球甚至会裂开。因为出身石灰岩地带，它喜钙，忌酸性土壤。必须经历冬季低温才能抽薹开花的二年生特性，同样源自那种气候。

### 2-2. 形态

| 器官 | 特征 |
|---|---|
| 外叶 | 呈宽厚的卵形，表面有一层白色蜡质。既是形成结球的"工厂"，也是贮藏期间的保护膜 |
| 结球（菜球） | 是内叶层层卷合而成的球状体。因品种不同，有扁形、尖形、圆形之分 |
| 芯（中心柱） | 纵贯菜球中心的粗短茎，生长点位于其顶端 |
| 茎 | 极短极粗，叶柄密集附着，看起来不像茎 |
| 根 | 笔直的主根可深入40-60cm，须根则浅浅铺展 |
| 花 | 4片黄色花瓣呈十字形排列，在第二年春天开放 |
| 荚果·种子 | 细长的角果中包着红褐色的种子 |

&nbsp;&nbsp;&nbsp;理解了结球的结构，结球甘蓝栽培的几乎一切都能得到解释。最外层的五六片外叶展开接受阳光，这些叶片制造的养分汇集到中心，把内叶向外推。内叶因为得不到光照，颜色浅、质地软，无法向上展开，只能向内卷曲。层层叠压的内叶相互挤压，菜球就随之变得紧实。

> **是外叶造就了结球。外叶长得不够大，就没有足够的养分把内叶推出来，菜球也就无法形成。把五六片外叶养得又大又健壮，就是结球管理的全部。**

&nbsp;&nbsp;&nbsp;芯是纵贯菜球中心的粗茎，生长点位于其顶端。收获时会把芯切掉，但如果在根部留下部分芯和外叶，那里的侧芽有时会重新长出几个小结球甘蓝。个头只有拳头大小，数量也不多，但如果正好长在别无他物可吃的时期，价值就会很高。不过正如评价表中持续性D所示，这只是额外收入，并非正式的再次收获。

### 2-3. 生长阶段

| 阶段 | 时期 | 核心生理 | 重要养分 |
|---|---|---|---|
| 发芽·育苗期 | 播种后40天 | 长至4-5片真叶 | 磷肥，少量氮肥 |
| 缓苗期 | 定植后1-2周 | 断根重新伸展 | 磷肥 |
| 营养生长期（外叶形成） | 定植后3-6周 | 形成10-15片外叶 | 氮肥 |
| 结球期 | 定植后6-12周 | 内叶向内卷合，菜球逐渐增大 | 钾肥、钙肥、氮肥 |
| 成熟期 | 结球后2-3周 | 菜球变得紧实 | 停止灌水与施肥 |
| 抽薹·开花期 | 第二年春天 | 菜球裂开，花薹抽出 | 磷肥、钾肥、硼肥 |

&nbsp;&nbsp;&nbsp;营养生长期与结球期的分界，是结球甘蓝栽培的分水岭。定植约6周后，外叶长到10-15片左右，植株就会转变方向：不再舒展新叶，而是开始向内卷合。这一转变要发生，条件必须齐备——气温须在15-20℃之间，养分和水分也要充足。条件不齐，转变就不会发生，只会不停地长叶片，也就是常说的结球不良。

&nbsp;&nbsp;&nbsp;关于抽薹，还有一点需要了解。结球甘蓝的幼苗一旦长到一定粗度以上再遇到低温，就会发生春化。茎粗超过铅笔粗细（约6mm）的幼苗，只要经历10℃以下、持续3周以上，这个信号就会被记录下来。这正是春播时播种过早、或定植的幼苗过大会有危险的原因：植株当年春天不结球，只顾抽薹。幼小的苗还感知不到低温，因此把小苗晚一点定植，反而更安全。

### 2-4. 每100g营养成分

| 营养素 | 含量 | 备注 |
|---|:---:|---|
| 热量 | 29kcal | 按韩国国家标准食品成分表生食计 |
| 水分 | 约92% | 绝大部分是水 |
| 蛋白质 | 1.36g | 占热量的18.8% |
| 碳水化合物 | 5-6g | 糖类为4.40g，在叶菜中属偏甜的一类 |
| 脂肪 | 0.1g | 几乎没有 |
| 膳食纤维 | 2-3g | 参与肠道蠕动 |
| 维生素C | 30-40mg | 一颗就能超过多人一天所需 |
| 维生素K | 含量高 | 参与血液凝固与骨骼形成 |
| 维生素U（S-甲基蛋氨酸） | 含有 | 一种据报道与保护胃黏膜有关的氨基酸衍生物 |
| 叶酸 | 含量丰富 | 参与造血 |
| 钙 | 40-50mg | 比羽衣甘蓝少，但吸收率好 |
| 钾 | 约200mg | 在盐分摄入增加时有助于平衡 |

&nbsp;&nbsp;&nbsp;关于维生素C，有一个实用的事实值得指出：结球甘蓝的维生素C以外叶含量最高，越往里越少，这是因为照到阳光的叶片会合成更多维生素C。外叶质地老、颜色深，常被丢弃，但从营养角度看并不该丢。切碎放进汤里，或一起腌进酸菜中，都能把它保留下来。

&nbsp;&nbsp;&nbsp;维生素U正式名称为S-甲基蛋氨酸，是一种氨基酸衍生物，因观察到结球甘蓝汁对胃黏膜有作用而得名。它不耐热，加热会损失相当一部分，因此生食或榨汁更能保留这一成分。

&nbsp;&nbsp;&nbsp;此外，发酵会改变营养这一点，在结球甘蓝身上尤为重要。发酵成酸菜后，维生素C大体得以保留，甚至有所增加，还会新生成B族维生素，并添加乳酸菌。加热或晒干的贮藏方式会损失维生素C，发酵却不会。第15节将讲述这部分内容。

## 3. 栽培环境

### 3-1. 温度

| 类别 | 极限值 | 最适值 | 备注 |
|---|:---:|:---:|---|
| 发芽温度 | 15-30℃ | 25℃ | 25℃时3-4天即可发芽 |
| 生育温度 | 5-27℃ | 15-20℃ | 评价表中温度适应幅度B，来自以结球为基准的12℃幅度 |
| 结球适温 | 15-27℃ | 15-18℃ | 超出此范围就不会卷合 |
| 高温极限 | 25℃以上 | - | 结球不良、提早抽薹、菜球开裂 |
| 低温极限 | 零下5℃ | - | 韩国南部可露地越冬，更低则菜球会受冻害 |
| 春化诱导 | 茎粗6mm以上时，10℃以下持续3周 | - | 不是次年，而是当年春天就会抽薹 |

> **结球是个温度问题。肥料和水分再充足，只要25℃持续不退，也不会结球。计算播种时期时，要看的不是收获时的气温，而是结球时的气温。**

&nbsp;&nbsp;&nbsp;栽培方式正是由这一原则决定的。春播在3-4月定植，6月下旬至7月收获，但结球期落在5-6月，颇为惊险。秋播在7-8月定植，10月下旬至11月收获，结球期落在9-10月，气温正好合适。这正是秋播在品质和耐储性上都更胜一筹的原因。

### 3-2. 光照

| 类别 | 标准 | 备注 |
|---|---|---|
| 所需日照 | 每天6小时以上 | 外叶充分长大才能结球 |
| 最低日照 | 每天4小时 | 另有耐弱光结球的品种 |
| 40%遮光时 | 相对产量86% | 叶菜类通用值，也是评价表中B等级的依据 |

&nbsp;&nbsp;&nbsp;即便在遮光条件下也能保持86%产量，这个数字是按叶片重量算的。但结球品质对光照更敏感。光照不足时，外叶会长得又薄又大，输往内部的养分随之减少，菜球就会变小、变松散。即便把向阳的好地方让给热量作物，也最好给结球甘蓝留出每天五六个小时的直射光。

### 3-3. 水分与土壤

| 项目 | 标准 | 备注 |
|---|---|---|
| 总蒸散量 | 每个生长期约550mm | 在叶菜中属偏多的一类，也是评价表中B等级的依据 |
| 土壤水分 | 最大持水量的70-80% | 在结球期尤为重要 |
| 土质 | 保水性好的壤土、黏壤土 | 沙质土在结球期容易缺水 |
| 土层深度 | 30cm以上 | 主根会向下深扎 |
| pH | 6.0-6.8 | 6.5左右最为适宜 |
| pH下限 | 5.5 | 低于此值根肿病会急剧增多 |

&nbsp;&nbsp;&nbsp;结球甘蓝比羽衣甘蓝更耗水。总蒸散量550mm，比羽衣甘蓝的400mm多1.4倍。结球期一旦断水，菜球就会变小；若断水后又突然供水，内部会急速膨大而外部跟不上，导致菜球开裂。均匀的水分供应对结球甘蓝而言，比对任何其他作物都更重要；在没有灌溉设施的条件下，只能依靠覆盖来减少水分蒸发。

&nbsp;&nbsp;&nbsp;调节酸度，本质上就是在防治根肿病。将pH维持在6.5以上，能大幅抑制病原菌活动。没有石灰时，可用草木灰，或烧过碾碎的贝壳、蛋壳、牡蛎壳粉代替。不过结球甘蓝一旦pH明显超过7.0，硼的吸收就会受阻，出现内部褐变的症状，因此不能一味提高酸度。
