# 结球甘蓝
- 来源: 韩国农村振兴厅 农事路（Nongsaro）、韩国国家标准食品成分表、FAO ECOCROP、Wiki、Gemini、Claude、Chat-GPT

---
## 引言
&nbsp;&nbsp;&nbsp;结球甘蓝（Brassica oleracea var. capitata）与羽衣甘蓝是同一个种，把叶子向内卷起的结球决定了这两种作物的性格。外叶包住内叶，形成阻止水分蒸发和病原菌侵入的天然包装，所以虽然是叶菜，耐储性却是C：整颗在常温下能放2-3个月，在储存窖里能放3-4个月，发酵成酸菜（sauerkraut）后能超过一年。综合等级为A（48.6分，有效183种中第28位），副食为SS（58.8分）。单位面积热量为B（每㎡6kg，每100g 29kcal，自给线的0.67倍），但它是叶菜，光靠结球甘蓝填不饱肚子，承担的是餐桌的另一半。弱点是时间（收获速度C，含40天育苗，折合直播需120-150天）、割一次就不再长的持续性D、肥料（施肥C，无合成投入产量保持率40.8%），以及结球本身。超过25℃，或结球期肥料、水不足，叶子就卷不起来。所以它是从一开始就瞄准冬天的作物：夏天种，秋天收，把球放进窖里吃到次年春天。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | A | 48.6 |
| 短期 | A | 49.4 |
| 长期 | B | 47.7 |
| 副食 | SS | 58.8 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：设施负担、烹调·加工要求度。S：蛋白质密度、微量营养素（维生素C）、口味、国内种植普及度。A：耐寒性、连作适应性、产量稳定性、自留种、种子寿命。B：单位面积热量、光照、水消耗量、温度幅度、防治自立度 |
| 劣势 | E：非食用价值。D：持续性。C：收获速度、施肥、病虫害压力、耐储性、无合成投入产量保持率、整地·挖掘能量 |

> **结球甘蓝与其他叶菜的分界在于，它能把维生素C整个冬天都留住。生菜的维生素C三天就没了，结球甘蓝的维生素C在窖里能保持三个月。**

&nbsp;&nbsp;&nbsp;叶菜类中储存期以月计的只有结球甘蓝。收获速度C与持续性D配成一对，构成最大的制约，施肥C则是实实在在的风险。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 部位 | 特征 |
|:---|:---|
| 外叶 | 宽而厚的卵形，有白色蜡层。是制造叶球的工厂，也是储存期间的保护膜 |
| 叶球、茎 | 内叶层层卷起的球形（因品种而有扁平、尖形、圆形）。茎（中心柱）是纵贯叶球正中的短粗茎，生长点在其顶端 |
| 根、花 | 直根向下伸40-60cm，须根浅浅铺开。第二年春天开出四瓣的黄色花，长长的荚果里有红褐色种子 |

> **外叶造出叶球。外叶不够大，就没有把内叶顶出来的养分，也就结不出球。把10-15片外叶养得又大又健康，几乎就是结球管理的全部。**

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 育苗·成活期 | 播种后40天（真叶4-5片），定植后1-2周 | 磷 |
| 营养生长期 | 定植后3-6周。长出10-15片外叶 | 氮 |
| 结球期 | 定植后6-12周。内叶向内卷，叶球变大 | 钾、钙、氮 |
| 成熟期、抽薹 | 结球后2-3周叶球变紧实（停止浇水和施肥）。次年春天抽花茎 | 磷、钾、硼 |

&nbsp;&nbsp;&nbsp;每100g热量29kcal，水分约92%，蛋白质1.36g（占热量的18.8%），糖类4.40g，膳食纤维2-3g，维生素C 30-40mg（一颗超过几个人一天的量），钙40-50mg，钾200mg左右，富含维生素K和叶酸。维生素U（S-甲基甲硫氨酸）据报道与保护胃黏膜有关。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽15-30℃（25℃下3-4天），生长5-27℃（15-20℃），结球适温15-27℃（15-18℃）。25℃以上会结球不良、提早抽薹、裂球。能耐-5℃，再低叶球就冻坏。茎粗6mm以上时，10℃以下持续3周，当年春天就会抽薹 |
| 光 | 每天6小时以上（最少4小时，另有弱光也能结球的品种） |
| 水、土壤 | 每季总蒸散量约550mm，结球期土壤水分为最大持水量的70-80%。保水力好的壤土，pH 6.0-6.8（6.5左右最佳），pH低于5.5根肿病剧增 |

> **结球是温度问题。肥料和水再充足，只要25℃持续，就卷不起来。计算播种时期，要看结球时的气温，而不是收获时的气温。**

| 类别 | 内容 |
|:---|:---|
| 熟期 | 早熟种80-100天（球1-1.5kg，耐储性低，春季栽培），中熟种100-120天（1.5-2.5kg），晚熟种120-150天（2.5-4kg，耐储性最高。用于秋季栽培和冬季储存，水分少、组织硬，发酵中不会变软，适合做酸菜） |
| 栽培类型 | 春季：3-4月播种，4月中旬至5月中旬定植，6月下旬至7月收获（早熟种、晚抽薹）。秋季：7-8月播种，8月中旬至9月定植，10月下旬至11月收获（晚熟种）。越冬：9月播种，10-11月定植，次年4-5月收获（仅限南部）。夏季栽培需要耐热性，不在高寒地容易失败 |

&nbsp;&nbsp;&nbsp;种子袋上写着F1的是杂交种，留种后性状会分离。打算把种代代传下去，就找固定品种、地方品种、开放授粉（OP）品种。

## 4. 田地准备、播种与定植
| 项目 | 标准 |
|:---|:---|
| 整地 | 深耕25-30cm，垄高20cm以上（排水差则30cm），宽120-140cm（双行种植），一定要有排水沟（过湿会招来软腐病和根肿病）。定植前2-3周施石灰，把pH调到6.5 |
| 施肥（1,000㎡） | 氮10-12kg（基肥50%，追肥50%），磷7-8kg（全部作基肥），钾8-10kg（基肥60%，追肥40%），石灰150-200kg。基肥在定植前1-2周施入：堆肥全量、磷全量、氮和钾的一半 |
| 追肥 | 第1次在定植后20天左右（氮、钾），第2次在开始结球时（氮、钾，最重要），第3次在第2次后15-20天（以钾为主） |
| 替代资源 | 尿的8-10倍稀释液（浇在株间，沾到叶子会烧叶，收获前3周停用），腐熟堆肥（没腐熟的会烧根），木灰每㎡一两把（结球期有用，但pH超过7会阻碍硼的吸收），烧过捣碎的蛋壳、贝壳粉（钙），前茬豆科绿肥（豌豆、紫云英、毛野豌豆翻压后放3-4周再定植），油饼和米糠，草液肥（割下的草在水里泡2-3周，稀释5倍） |

> **结球期的追肥决定结球甘蓝种植的成败。这个时期养分不足，就没有力气把内叶顶出来，叶球结不出来，或者松松垮垮地结束。**

| 种植 | 标准 |
|:---|:---|
| 育苗 | 在箱或穴盘里按1-2cm间距、0.5-1cm深播种。25℃下3-4天、15℃下7-10天发芽。育苗30-40天，真叶4-5片时定植，定植前1周起逐渐放到阳光和风中炼苗。种子用50℃的水泡20分钟后立即用冷水降温，可预防黑腐病等种传病害 |
| 定植 | 栽到子叶下方（不要把生长点埋住）。早熟种60×35cm，中晚熟种70×40cm（每1,000㎡ 4,500-5,000株）。在阴天的下午或傍晚栽，栽后马上浇透水 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 刚定植后至成活 | 先浇透一次，之后每2-3天一次 |
| 营养生长期 | 表土干了就浇，每周1-2次，每次浇深 |
| 结球期 | 持续不断，不要让它干（最重要） |
| 收获前10天 | 停止浇水（耐储性提高，叶球不裂） |

&nbsp;&nbsp;&nbsp;结球期缺水会直接表现在叶球大小上，但更糟的是干了以后突然浇水。里面急速长大，外叶跟不上，叶球就纵向裂开，裂开的球无法储存，要先吃掉。早晨外叶仍然下垂就是缺水；外叶发黄、基部变软是过湿和软腐病；下部叶片先萎蔫、白天耷拉下来要怀疑根肿病，挖开根部确认有没有肿瘤。没有塑料膜，就用稻草、干草、落叶、稻壳覆盖，但覆盖物下面是蛞蝓躲藏的地方。

| 管理 | 内容 |
|:---|:---|
| 结球失败的原因 | 高温（结球期超过25℃：调整播种期，使结球期落在15-20℃），养分不足（外叶小而色淡：结球期追肥），缺水（球小而硬：持续浇水并覆盖），过密（外叶重叠受不到光：70×40cm），生长点受损（蛾类幼虫吃了菜心就不开始结球：结球前罩防虫网并除去幼虫） |
| 植株管理 | 定植1周后补苗，3-4周后第1次培土（根部培土5cm），结球开始前第2次培土，只随时清理有病发黄的外叶。风大的田地要支撑。杂草在定植后2-6周是关键期 |

## 6. 病虫害与养分问题
&nbsp;&nbsp;&nbsp;害虫有菜粉蝶幼虫（4-6月、9-10月：人工捉，防虫网，擦掉叶背的黄色卵）、小菜蛾（5-10月：防虫网，木醋液稀释液）、菜心野螟（定植初期啃食生长点就不结球：早发现早清除）、甘蓝夜蛾和斜纹夜蛾（白天躲在土里或外叶背面，夜里出来：夜里人工捉）、黄曲条跳甲（撒灰，垄上盖稻草）、蚜虫（传播病毒：肥皂水，用水柱冲洗，保护瓢虫）、蛞蝓（雨季：夜里捉，撒一圈灰或稻壳）。防虫网（孔径1mm左右的网罩在拱架上，边缘用土压封，注意通风）要在开始结球前罩上，并且要先把叶子上的卵和幼虫全部除掉；结球后才罩，就等于把害虫关在里面养。防治用的材料有肥皂水（20g无香料肥皂溶于1L水，傍晚喷洒，次日冲洗掉）、大蒜辣椒浸出液（100g大蒜和干辣椒加1L水磨碎泡一天，驱避剂）、500-1,000倍木醋液、木灰。

| 病害 | 症状与条件 | 对策 |
|:---|:---|:---|
| 根肿病 | 根上长肿瘤，白天萎蔫。酸性土壤，过湿 | 无法治愈（在土里活7年以上）。pH 6.5以上，排水，7年轮作 |
| 软腐病 | 基部和叶球变软发臭。高温高湿，伤口 | 排水，不留伤口，立即清除病株（对储存的结球甘蓝尤其致命） |
| 霜霉病 | 叶上有黄斑，背面有灰白色霉。凉爽潮湿时 | 通风，保证间距，清除病叶 |
| 菌核病、黑腐病、黑斑病 | 基部有白色菌丝和黑色颗粒 / 叶缘呈V字形发黄 / 同心圆状斑点 | 排水·清除病株·轮作 / 种子温汤消毒 / 通风并清除残体 |

> **根肿病无法用药治好，在土里能活7年以上。十字花科的田，只能靠酸碱度、排水和轮作三样提前预防。**

&nbsp;&nbsp;&nbsp;农艺防治方面，十字花科至少2年（有根肿病则7年）不连作，收获后不把基部和外叶留在田里（它们是来年病原菌的寄主），混种莳萝、芫荽、胡萝卜花以招来寄生蜂和食蚜蝇，并保护瓢虫、草蛉和蜘蛛。

| 症状 | 原因与处理 |
|:---|:---|
| 下部叶先发黄，植株小 | 缺氮。尿的8-10倍稀释液，腐熟堆肥，草液肥 |
| 叶缘焦褐 | 缺钾。在植株周围撒木灰 |
| 内叶叶缘焦枯（心腐） | 缺钙或水分骤变（不是病，而是生理障碍）。蛋壳、贝壳粉，均匀浇水 |
| 球内变褐并空心 | 缺硼（灰施得太多的田里常见）。腐熟堆肥 |
| 叶片嫩软，害虫聚集 | 氮过剩（耐储性也下降）。停止施氮 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 豆科（豌豆、菜豆、蚕豆：固氮），大葱、洋葱、大蒜（气味让蛾和蚜虫迷惑），莳萝、芫荽、胡萝卜花（寄生蜂、食蚜蝇），马铃薯、甜菜、芹菜（根的深度不同，竞争少） |
| 差 | 羽衣甘蓝、大白菜、萝卜、芥菜、西兰花（共有病虫害），草莓、番茄（互相妨碍生长） |

&nbsp;&nbsp;&nbsp;按结球甘蓝（十字花科，多肥）、豌豆和菜豆（豆科，恢复氮）、马铃薯和甘薯、大葱和洋葱的顺序轮作，结球甘蓝要隔4年才会回到同一块地。种结球甘蓝之前，最好先种豆。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 用手掌按叶球，硬实顶得住就成熟了（软的说明内叶还没长满）。春季栽培6月下旬至7月，秋季栽培10月下旬至11月。晚了叶球会纵向裂开，里面抽出花茎。收获前10天起停止浇水，在晴天清晨收获 |
| 要领 | 一手抓住，用刀割断基部（储存用的连根拔起更好）。留2-3片外叶（防止储存中水分蒸发，吸收冲击，外面坏了只剥那片叶子，里面完好）。小心不留伤口，在田里放半天阴凉处晾干表面水汽（预干），再移到凉爽阴暗处。留下基部的话，侧芽有时会长出几个小结球甘蓝 |

| 留种 | 标准 |
|:---|:---|
| 难点 | 二年生，要经历低温才抽花茎（露地越冬，或放进储存窖，春天再栽）。花茎顶不穿坚硬的叶球，所以春天在球顶面划深3-5cm的十字口。异花授粉且自交不亲和，所以留种株至少5株，最好10株以上（只靠一两株传代，几代内就会出现近交衰退，结球散乱） |
| 杂交 | 与羽衣甘蓝、西兰花、花椰菜、球茎甘蓝、抱子甘蓝（B. oleracea）完全杂交。与大白菜、青菜、芜菁、油菜（B. rapa），芥菜、芥（B. juncea）几乎不杂交，萝卜（Raphanus）属不同，不杂交 |
| 防止 | 错期栽培（一年只让一种开花，最现实），隔离500m以上（邻田无法控制，很难），套网（开花前罩上网，在里面用毛笔转移花粉） |
| 步骤 | 收获期选叶球硬实、大且无病的植株。越冬只有南部可以在露地（根部培土，盖稻草和落叶），中部以北连根拔起埋入0-5℃的窖里。3月重新栽植，3-4月划口，4月抽薹（立支架），4-5月开花，6-7月荚果三分之二变褐时连茎割下，在阴凉处晾1-2周，装进袋子敲打 |
| 寿命 | 常温密封4-5年。每年把20粒种子放在湿布上检查发芽率 |

## 9. 储存
| 方式 | 条件 | 期间 | 维生素C |
|:---|:---|:---|:---|
| 常温阴凉处 | 凉爽阴暗处 | 2-4周 | 逐渐减少 |
| 窖藏 | 0-4℃，湿度85-95% | 3-4个月 | 大部分保留 |
| 酸菜（sauerkraut） | 常温发酵后放凉爽处 | 6个月至1年以上 | 保留或增加 |
| 干燥、盐渍 | 切丝焯水后阴干 / 盐10-15% | 6个月至1年 / 几个月 | 几乎消失 / 大幅减少 |

&nbsp;&nbsp;&nbsp;窖藏的做法是：在排水好的地方挖深1-1.5m的坑，底部铺10cm稻草或干草，叶球倒放或平放并留出间隔使其互不接触，盖上稻草再堆30-50cm土，在中间立起草捆或管子通气，每2周打开一次，挑出坏的。目标是既不结冰也不发芽的0-4℃（太浅会冻，太深会因潮湿而烂）。

| 酸菜 | 方法 |
|:---|:---|
| 处理、加盐 | 留出两三片外叶，挖掉菜心，尽量切成细丝（越细越容易出汁）。撒上重量2-2.5%（每kg加20-25g）的盐，用手揉30分钟左右，直到出很多汁 |
| 装坛、覆盖 | 压实装进坛子或玻璃瓶，不留空气，使盐水升到材料之上，用留出的外叶盖住，再压上重物，使材料完全浸在盐水里 |
| 发酵、保管 | 在15-20℃下发酵1-3周（盖上布使空气能排出）。出现酸味后移到凉爽处（窖、地下室、朝北的库房），保管6个月至1年以上 |

> **决定成败的唯一条件，是材料是否完全浸在盐水里。霉只在接触空气的部分长出来。**

&nbsp;&nbsp;&nbsp;表面漂着的白膜通常是产膜酵母，无害。

## 10. 烹调与注意事项
| 方法 | 燃料 | 维生素C保存 |
|:---|:---|:---|
| 生吃（切丝） | 无 | 最大（维生素U也保持活性） |
| 发酵（酸菜） | 无 | 保留或增加。兼具储存和烹调 |
| 焯水1-2分钟 | 极少 | 一半以下（体积缩小，致甲状腺肿物质减少） |
| 汤、炖菜 | 与其他烹调合用 | 连汤一起吃则保留 |
| 炒、蒸 | 少至中等 | 中等（炒会提高甜味，蒸适合卷着吃） |

| 注意 | 内容 |
|:---|:---|
| 胀气、致甲状腺肿物质 | 没有急性毒性。低聚糖（棉子糖）在大肠里发酵，产生胀气，所以开始时少吃，煮熟吃。十字花科共有的致甲状腺肿物质可能妨碍碘的吸收，但煮熟后会减少，可以一起吃海藻，含量也比羽衣甘蓝低 |
| 变坏的 | 变色、发黏、发臭时，只有外叶坏了就剥掉，软烂到里面就扔掉 |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存窖（每2周一次），吃酸菜，规划田地，翻堆堆肥，确认留种株越冬 |
| 3-4月 | 开始春季播种和育苗，留种株重新栽植并划口。4月春季苗炼苗并定植，管理留种株开花和隔离 |
| 5-6月 | 营养生长期管理，第1次追肥，开始观察蝴蝶并罩防虫网（5月）。结球期第2次追肥，下旬开始收获（6月） |
| 7-8月 | 结束春季收获并留种，开始秋季播种和育苗（7月）。秋季育苗和定植，高温期覆盖和浇水（8月） |
| 9-10月 | 营养生长期管理和追肥，蛾类第2次高峰期罩防虫网（9月）。结球期管理和追肥，下旬开始收获（10月） |
| 11-12月 | 秋季收获和预干，窖藏，腌酸菜（11月）。检查窖，采取留种株越冬措施（12月） |

> **不能忘记的五件事：把结球期安排在15-20℃，结球期追肥，结球前罩上防虫网，把晚熟种放进窖，用酸菜守住冬天的维生素C。**
