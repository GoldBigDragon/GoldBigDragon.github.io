## 8. 栽培管理 - 结球的形成

### 8-1. 为什么会结球失败

&nbsp;&nbsp;&nbsp;结球甘蓝栽培中最常见的失败，既不是病害也不是虫害，而是结球不良：叶片长得很茂盛，菜球却不形成，或者形成了也只有拳头大小、松松垮垮。原因大体不出以下五种之一。

| 原因 | 表现形式 | 应对 |
|---|---|---|
| 高温 | 结球期气温超过25℃，叶片会不停舒展 | 调整播种期，使结球期落在15-20℃ |
| 缺肥 | 外叶小、颜色浅，内叶推不出来 | 结球期必须追肥 |
| 缺水 | 菜球虽紧实却长不大 | 结球期持续灌溉并覆盖 |
| 密植 | 外叶相互重叠，晒不到光 | 保持70×40cm的株距 |
| 生长点受损 | 蛾类幼虫啃食芯部，结球根本无法开始 | 结球前覆盖防虫网，并捕捉幼虫 |

> **结球，就是把外叶制造的养分推向内部的过程。把十到十五片外叶养得又大又浓绿，结球管理的工作几乎就完成了。**

&nbsp;&nbsp;&nbsp;这个原理，衍生出实际操作的指导方针。定植后6周内，重点是养大外叶：充分施氮，保持株距，让光照均匀照到每片叶子。这段时间不能摘外叶来吃。若像对待羽衣甘蓝那样习惯性地摘下部叶片，结球就会失败。外叶是结球甘蓝的"工厂"，把工厂拆了吃掉，自然产不出产品。

&nbsp;&nbsp;&nbsp;定植6周后，内叶开始卷合时，就要转变管理方向：继续施氮，但增加钾肥用量，并保持水分均匀。从这时到收获的四到六周，决定着菜球的大小和紧实程度。

### 8-2. 培土与植株管理

| 作业 | 时期 | 内容 |
|---|---|---|
| 补苗 | 定植后1周 | 在缺苗处补种备用苗 |
| 第1次培土 | 定植后3-4周 | 在基部堆5cm厚的土 |
| 第2次培土 | 结球开始前夕 | 再堆一次土保护根部 |
| 清理外叶 | 随时 | 只摘除病叶和发黄的外叶 |
| 支撑 | 风大的地块 | 菜球变大后可能因过重而倾倒 |

&nbsp;&nbsp;&nbsp;培土能保护根系，稳固植株。结球甘蓝的须根分布很浅，除草或风雨很容易使其外露，外露的根会干枯或受损。在基部堆土后，该处还会长出新根，有时能提高养分的吸收能力。

&nbsp;&nbsp;&nbsp;清理外叶要谨慎，这不是像对待羽衣甘蓝那样勤于采摘的作业。只摘除病叶和已完全发黄的叶片，还呈绿色的外叶要保留。收获时也要留两三片外叶，因为它们在贮藏期间能起到保护作用。

### 8-3. 杂草管理

&nbsp;&nbsp;&nbsp;关键时期是定植后2-6周。这段时间如果杂草长得比外叶还高，就会在争光中处于劣势，结球随之变难。每隔2周，用锄头浅浅刮除表层2-3cm即可；挖得太深会切断浅层分布的须根。等外叶长到能覆盖垄面，阴影自会压制杂草，此后只需拔除较大的杂草。

## 9. 病虫害 - 不用农药的防治方法

### 9-1. 主要虫害

| 害虫 | 危害表现 | 发生时期 | 不用农药的防治方法 |
|---|---|---|---|
| 菜粉蝶幼虫 | 绿色幼虫啃食叶片，只留下叶脉 | 4-6月、9-10月 | 人工捕捉、防虫网、擦除叶背黄色虫卵 |
| 小菜蛾（Diamondback Moth） | 小幼虫啃食叶背，留下一层薄膜 | 5-10月 | 防虫网、勤查勤看、稀释木醋液 |
| 菜心野螟 | 蛀食幼苗生长点，导致结球根本无法进行 | 定植初期 | 早发现早清除，覆盖防虫网 |
| 甘蓝夜蛾·斜纹夜蛾 | 大龄幼虫会大量啃食叶片和菜球 | 夏季-秋季 | 夜间人工捕捉，清晨捕杀 |
| 跳甲 | 在幼苗叶片上咬出粟粒大小的孔洞 | 4-6月 | 防虫网、撒草木灰、垄面覆稻草 |
| 蚜虫 | 聚集在叶背和菜球内部吸食汁液，还会传播病毒 | 4-6月、9-10月 | 肥皂水、水流冲洗、保护瓢虫 |
| 蛞蝓 | 在外叶和菜球表面咬出孔洞 | 韩国梅雨季（6月下旬至7月） | 夜间捕捉，撒草木灰或稻壳围带 |

### 9-2. 为什么必须在结球前加以防范

&nbsp;&nbsp;&nbsp;结球甘蓝的虫害防治有一个截止期限。叶片一旦开始卷合，就没有办法再捕捉钻进里面的幼虫。表面看起来完好的菜球，剖开后里面满是虫粪和孔洞的情况，正是由此而来。这样的菜球既不能吃，也无法贮藏。

> **要在结球开始之前覆盖防虫网，覆网之前先把叶片上的虫卵和幼虫全部清除。若等结球开始后才覆网，等于把害虫关在里面继续喂养。**

&nbsp;&nbsp;&nbsp;菜心野螟尤其在初期阶段危险。这种害虫的幼虫一旦蛀食幼苗的生长点，那株苗就无法开始结球。表现为茎异常分叉，或长出好几个细小的新芽。定植后2周内若发现这样的植株，应拔除并用备用苗补种。

### 9-3. 防虫网与物理隔离

&nbsp;&nbsp;&nbsp;用孔径1mm左右的防虫网架在拱架上，覆盖整个垄面，边缘用土压实密封，就能阻止蝶蛾产卵。有机栽培的实证文献中，覆盖防虫网也被记录为最可靠的手段。没有防虫网时，可用孔眼细密的蚊帐、薄布、旧窗帘代替。

&nbsp;&nbsp;&nbsp;要注意通风。结球甘蓝在结球期一旦闷湿，软腐病就会爆发。不要完全密封，白天可以打开一侧，或者把拱架架高留出空气层。长时间下雨之后，要掀开防虫网晾晒一天左右。

### 9-4. 人工捕捉与天然防治剂

&nbsp;&nbsp;&nbsp;在二十株左右规模的结球甘蓝地里，光靠人工捕捉就能起到相当不错的防治效果。菜粉蝶幼虫个头大、行动慢，很容易发现，沿着叶片上的孔洞找过去，虫子就在附近。效率更高的是抓虫卵阶段：看到白蝶飞舞的第二天，在叶背找出细长的黄色虫卵并擦掉，就能提前消灭一只幼虫。

&nbsp;&nbsp;&nbsp;甘蓝夜蛾和斜纹夜蛾的大龄幼虫，白天躲在土里或外叶背面，夜间才出来活动。想在白天找到它们，可以轻轻刨开受害严重植株的根部泥土。日落后打着灯出去找，会容易抓到得多。

| 防治剂 | 制作方法 | 防治对象 | 注意事项 |
|---|---|---|---|
| 肥皂水 | 将20g无香皂溶于1L水中 | 蚜虫、螨虫 | 傍晚喷洒，第二天冲洗掉 |
| 蒜辣水 | 将100g大蒜与干辣椒放入1L水中打碎，静置一天 | 驱避剂 | 仅用于预防，无法杀死已经附着的害虫 |
| 木醋液 | 稀释500-1,000倍 | 各类驱避 | 浓度过高会伤叶 |
| 草木灰 | 过筛后撒在叶片和土壤上 | 跳甲、蛞蝓 | 下雨后需重新撒施 |

### 9-5. 主要病害

| 病害 | 症状 | 条件 | 应对 |
|---|---|---|---|
| 根肿病（俗称瘤病） | 根部长瘤，白天萎蔫 | 酸性土壤、过湿 | 无法治疗。保持pH 6.5以上、排水、轮作7年 |
| 软腐病 | 基部和菜球变软腐烂，散发恶臭 | 高温多湿、有伤口 | 排水、避免造成伤口、立即清除病株 |
| 霜霉病 | 叶片出现黄斑，背面有灰白色霉层 | 凉爽潮湿时 | 通风、保持株距、清除病叶 |
| 菌核病 | 基部软化，出现白色菌丝与黑色菌核 | 低温多湿 | 排水、清除病株、轮作 |
| 黑腐病 | 叶缘出现V字形黄化 | 高温多湿 | 种子温汤消毒、清除病株 |
| 黑斑病 | 叶片出现同心圆状斑点 | 潮湿 | 通风、清除田间残株 |

> **根肿病无法用药物治愈，病原能在土壤中存活7年以上。十字花科作物地只能靠调节酸度、排水、轮作这三项预先加以防范。**

&nbsp;&nbsp;&nbsp;软腐病对以贮藏为目标的结球甘蓝而言尤其致命。田里已经感染的菜球，放进地窖后会腐烂，一颗坏球就能连累旁边的好球一起遭殃。伤口是病菌的入侵通道，因此收获时不要抛掷或磕碰菜球，雨后初晴也不要立即收获。贮藏前要逐个检查菜球，基部发软或有异味的要单独挑出，优先食用。

### 9-6. 农业防治原则

| 原则 | 内容 |
|---|---|
| 调整播种期 | 避开蛾类发生高峰期。秋播若8月定植，会与9月的产卵期重叠 |
| 轮作 | 不连续种植十字花科作物，至少间隔2年，有根肿病则需7年 |
| 保持株距 | 遵守70×40cm的株距，通风能减少真菌性病害 |
| 清除残株 | 收获后不把根茬和外叶留在田里，否则会成为来年病原菌的寄主 |
| 混种 | 莳萝、香菜、胡萝卜的花能招来寄生蜂和食蚜蝇 |
| 保护天敌 | 不要杀死瓢虫、草蛉、蜘蛛、寄生蜂 |

&nbsp;&nbsp;&nbsp;清除残株对结球甘蓝而言尤为重要。收获后留在地里的根茬和根系会一直存活到第二年并抽出新芽，这些新芽会成为蛾类、蚜虫和病毒过冬的藏身之处。收获结束后要把根茬挖出、带离田块，做堆肥或喂给家畜。如果这块地出现过根肿病，就不能拿去做堆肥，而要烧掉，或运到远处深埋。

## 10. 营养缺乏与过量

| 症状 | 原因 | 天然材料应对措施 |
|---|---|---|
| 从下部叶片开始发黄，植株矮小 | 缺氮 | 尿液稀释8-10倍、腐熟堆肥、杂草液肥 |
| 叶缘出现褐色焦枯 | 缺钾 | 在株周撒草木灰 |
| 叶片呈深青绿色，生长停滞 | 缺磷 | 骨粉、草木灰 |
| 不结球或菜球松散 | 缺氮缺钾 | 结球期必须追肥 |
| 内叶边缘出现褐色焦枯（芯部褐变） | 缺钙或水分剧烈变化 | 蛋壳·贝壳粉、均匀灌溉 |
| 菜球内部变褐并出现空心 | 缺硼 | 腐熟堆肥；草木灰施用过量的地块常见此症状 |
| 新叶叶脉间发黄，叶脉仍为绿色 | 缺镁或缺铁 | 检查pH是否过高，并减少草木灰用量 |
| 叶片柔嫩松软，招虫聚集 | 氮肥过量 | 停止施氮，耐储性也会因此下降 |

&nbsp;&nbsp;&nbsp;芯部褐变是结球甘蓝常见的生理性障害，并非病害，是因为钙无法到达菜球内部所致。钙随水分流动而移动，而结球内部的叶片几乎不蒸腾，水分很难到达那里。这正是土壤中即便钙充足，症状仍可能出现的原因。骤然的干燥与过湿交替会使症状加重，因此比起补钙，均匀灌溉往往更为有效。

&nbsp;&nbsp;&nbsp;缺硼在大量施用草木灰的地块中较常见。草木灰呈碱性，会提高pH，一旦超过7.5，硼就会固定成水中不溶的形态，根系便无法吸收。若出现菜球内部褐变并空心的症状，不应再追加草木灰，而应停止施用，改用腐熟堆肥补充有机质，让土壤慢慢恢复。

## 11. 间作与轮作

| 相性 | 对象 | 效果 |
|:---:|---|---|
| 良好 | 豆科（豌豆、菜豆、蚕豆） | 固氮，为结球甘蓝留下可用的氮 |
| 良好 | 大葱、洋葱、大蒜 | 气味能扰乱蛾类和蚜虫的定位 |
| 良好 | 莳萝、香菜、胡萝卜花 | 招来寄生蜂和食蚜蝇，减少蚜虫 |
| 良好 | 马铃薯、甜菜根、芹菜 | 根系深度不同，竞争较少 |
| 一般 | 生菜、菠菜 | 初期能覆盖垄间，抑制杂草 |
| 不良 | 羽衣甘蓝、大白菜、萝卜、芥菜、西兰花 | 共用病虫害，会逐年累积 |
| 不良 | 草莓、番茄 | 彼此妨碍生长 |

```
结球甘蓝（十字花科，需肥量大） → 豌豆·菜豆（豆科，恢复氮素） → 马铃薯·甘薯（茄科·旋花科） →
大葱·洋葱（百合科） → 再次种结球甘蓝
```

&nbsp;&nbsp;&nbsp;按这个顺序轮作，结球甘蓝回到同一块地需要4年。评价表中连作适应性A，意味着建议休作2年，但若确认地块有根肿病，就要延长到7年以上。关键是不要因为萝卜、芥菜、羽衣甘蓝同属十字花科，就把它们安排进轮作序列中间。

&nbsp;&nbsp;&nbsp;在种植结球甘蓝之前，最好先种一茬豆类。结球甘蓝是本文档所涉叶菜中最"吃肥"的作物，而豆科能自行固氮。把豌豆或蚕豆从冬天种到春天，在开花前后翻压入土，根瘤中储存的氮就会归还土壤。翻压后腐熟3-4周再定植结球甘蓝，就能替代基肥的相当一部分。在没有化肥的条件下，仅凭这一种植顺序，往往就能决定结球的成败。
