## 12. 収穫

### 12-1. 収穫時期の判断

| 基準 | 内容 |
|---|---|
| 触感 | 球を手のひらで押したとき硬く押し返せば完成です |
| 時期 | 春栽培6月下旬-7月、秋栽培10月下旬-11月 |
| 遅れると | 球が縦に裂け、内側から花茎が伸びてきます |
| 収穫前 | 10日前から灌水を中止します |
| 収穫の時間帯 | 晴れた日の早朝 |

&nbsp;&nbsp;&nbsp;押したときに柔らかければ、内葉がまだ十分に詰まっていません。もう少し待ちます。逆に長く置きすぎると、内側で成長し続ける内葉が外側を押し出し、球が裂けます。裂けた球はその隙間から菌が入り込んで貯蔵できないため、すぐに食べるか発酵に回します。

&nbsp;&nbsp;&nbsp;晴れた日の早朝に収穫するのには理由があります。雨上がり直後や露が乾いていない状態で収穫すると、外葉の間に水気が残り、その水気が貯蔵中の腐敗の出発点になります。逆に日中に収穫すると球の温度が高く、貯蔵庫に入れたときに呼吸が活発になって早く傷みます。朝の涼しい球をそのまま涼しい場所に入れるのが最もよい方法です。

### 12-2. 収穫のコツ

| 段階 | 方法 |
|---|---|
| 1 | 株を片手でつかみ、根元を包丁で切ります。貯蔵用なら根ごと引き抜くこともあります |
| 2 | 外葉を2-3枚残し、残りは取り除きます |
| 3 | 傷がつかないように扱います。投げたり積み重ねて押しつぶしたりしません |
| 4 | 畑に半日ほど置いて表面の水気を乾かします（予乾） |
| 5 | 涼しく暗い場所に移します |

> **外葉2-3枚は必ず残します。貯蔵中の水分蒸発を防ぎ物理的な衝撃を吸収し、外側が傷んでもその葉だけを剥がせば中身は無事です。**

&nbsp;&nbsp;&nbsp;貯蔵を狙うなら、根ごと引き抜く方法のほうが優れています。根に残った水分が球へゆっくりと移動し、乾く速度を遅らせます。土を払い落としますが根は切らず、そのまま逆さに吊るすか、土に再び埋める方法で貯蔵します。

&nbsp;&nbsp;&nbsp;予乾、つまり収穫した球を半日ほど日陰で乾かす工程を省いてはいけません。表面が濡れたまま貯蔵庫に入れると水気が閉じ込められ、軟腐病の出発点になります。直射日光の当たる場所に長く置くと外葉が焼けるので、日陰で乾かします。

### 12-3. 収穫後の株元管理

&nbsp;&nbsp;&nbsp;株元を畑に残しておくと、側芽から小さなキャベツがいくつか出てくることもあります。握りこぶし程度の大きさで数量も少ないですが、他に何もない時期に出てくれば一食分のおかずになります。ただし、この株元が蛾やアブラムシやウイルスの冬の隠れ家になることもあります。病害虫の圧力が高い畑では、側芽からの収穫はあきらめ、株元を掘り出して片づけたほうが、翌年のためにはよいでしょう。

## 13. 採種 - 二年生と他家受粉の壁

### 13-1. 二重の難しさ

&nbsp;&nbsp;&nbsp;キャベツの採種は、この文書が扱う作物の中でも特に手間のかかる部類に入ります。二年草なので冬を越さなければ花が咲かず、他家受粉なので同じ種の別変種と容易に交雑します。しかも結球という構造そのものが採種を妨げます。花茎が幾重にも巻いた葉を突き破って出てこなければならないからです。

| 壁 | 内容 | 解決法 |
|---|---|---|
| 二年草 | 低温を経なければ花茎が立ちません | 露地越冬、または室貯蔵後に春に再定植 |
| 結球 | 花茎が硬い球を突き破れません | 春に球の上面に十字に切れ目を入れます |
| 他家受粉 | ハチが花粉を運び、別の変種と交雑します | 隔離距離、時差栽培、網掛け |
| 自家不和合性 | 自分の花粉ではうまく受精しません | 採種株を複数株残します |

### 13-2. 何と交雑するか

| 作物 | 学名 | キャベツとの交雑 |
|---|---|:---:|
| ケール、ブロッコリー、カリフラワー、コールラビ、芽キャベツ | Brassica oleracea | 完全に交雑します |
| ハクサイ、チンゲンサイ、カブ、アブラナ（ナタネ） | Brassica rapa | ほとんど交雑しません |
| カラシナ、マスタード | Brassica juncea | ほとんど交雑しません |
| ダイコン | Raphanus sativus | 属が異なり交雑しません |

&nbsp;&nbsp;&nbsp;キャベツの種を採る年に、ハクサイやダイコンやカラシナが一緒に花を咲かせても問題ありません。種が異なるからです。問題になるのは、Brassica oleraceaの仲間、つまりケールやブロッコリーやコールラビだけです。

### 13-3. 交雑を防ぐ三つの方法

| 方法 | 内容 | 現実性 |
|---|---|---|
| 隔離距離 | 他のBrassica oleracea開花株と500m以上 | 隣の畑まではコントロールできず難しいです |
| 時差栽培 | 一年に一種類だけ花を咲かせます | 最も現実的です |
| 網掛け | 開花前にネットをかけ、中で筆を使って花粉を移します | 小規模なら確実です |

&nbsp;&nbsp;&nbsp;時差栽培が最も現実的です。今年はキャベツだけから種を採り、ケールは全部食べて花を咲かせないようにします。翌年は逆にします。キャベツの種は4-5年もつため、一年に一種類ずつ交代で採っても種が途切れません。

&nbsp;&nbsp;&nbsp;網掛けをする際に必ず覚えておくべきは、キャベツが自家不和合性だという点です。自分の花粉ではうまく受精しないため、網の中に複数の株を一緒に入れ、筆で花の間を行き来させてこすってやる必要があります。一株だけを覆っておくと、莢がほとんど付きません。

> **採種株は最低5株、できれば10株以上を残します。他家受粉作物で1-2株だけで代を継ぐと、数世代のうちに近交弱勢が現れて勢いが弱まり、結球も乱れます。**

### 13-4. 越冬と採種の手順

| 段階 | 時期 | 内容 |
|---|---|---|
| 採種株の選抜 | 収穫期 | 球が硬く大きく、品種特性がはっきりしていて病気のない株を選びます |
| 越冬（露地） | 11-2月 | 韓国南部のみ。株元に土を盛り、わらと落ち葉で覆います |
| 越冬（貯蔵） | 11-2月 | 韓国中部以北。根ごと引き抜き、0-5℃の室に埋めておきます |
| 再定植 | 3月 | 貯蔵した株を再び植えます |
| 切れ目入れ | 3-4月 | 球の上面に十字に3-5cmの深さの切れ目を入れます |
| 抽だい | 4月 | 花茎が切れ目を通って伸びます。支柱を立てます |
| 開花 | 4-5月 | 黄色い花が咲きます。この時期は隔離を守ります |
| 結莢 | 5-6月 | 莢がつきます |
| 収穫 | 6-7月 | 莢の3分の2が茶色くなったら、茎ごと刈り取ります |
| 追熟・脱粒 | 収穫直後 | 日陰で1-2週間乾かした後、袋に入れて叩きます |

&nbsp;&nbsp;&nbsp;切れ目入れはキャベツ採種に特有の作業です。春になって花茎が伸び始めても、球があまりに硬いと突き破れず、中で曲がって腐ってしまいます。球の上面に十字形に3-5cmの深さの切れ目を入れてやると、花茎がその道を通って伸び出します。深く切りすぎると中から腐敗が始まるため、外側の葉を数枚割る程度にとどめます。

&nbsp;&nbsp;&nbsp;韓国中部以北での越冬は、露地では失敗しやすいです。氷点下5℃までは耐えますが、それより下の温度が長く続くと球が凍結・解凍を繰り返して軟化します。本格的な霜が降りる前に根ごと引き抜き、土を少し付けたまま室や涼しい納屋に埋め、0-5℃を保ちます。この貯蔵期間がそのまま春化の過程になるため、春に再び植えるとすぐに花茎が伸び始めます。

&nbsp;&nbsp;&nbsp;莢を完全に乾くまで畑に置いておいてはいけません。アブラナ科の莢は完全に乾くと自然に裂けて種を地面にこぼします。下方の3分の2が茶色くなった時点で茎ごと刈り取り、布や袋の上で追熟させれば、裂けて落ちる種まで回収できます。

| 項目 | 基準 |
|---|---|
| 種子寿命 | 常温密閉4-5年 |
| 保管条件 | 涼しく暗く乾燥した場所、密閉容器 |
| 乾燥剤 | 炒って冷ました米、炭、乾いた灰 |
| 発芽確認 | 毎年20粒を濡れた布に置いて発芽率を数えます |
| 1株あたりの収穫量 | 種子数千粒 |

## 14. 毒性と注意すべき成分

&nbsp;&nbsp;&nbsp;キャベツに急性毒性はありません。洗ってそのまま食べられ、評価表の調理・加工SSがその事実を反映しています。注意すべき点は二つです。

| 項目 | 内容 | 対応 |
|---|---|---|
| ガスと膨満感 | ラフィノースのようなオリゴ糖が大腸で発酵します | 最初は少なめに、加熱して食べると軽減します |
| ゴイトロゲン | アブラナ科共通。ヨウ素の吸収を妨げることがあります | 加熱すると減ります。海藻類と一緒に食べます |
| 傷んだもの | 変色、ぬめり、悪臭 | 外葉だけが傷んでいれば剥がし、中まで軟らかければ廃棄します |

&nbsp;&nbsp;&nbsp;ゴイトロゲンはケールと同じ成分で、キャベツはケールより含有量が低めです。ヨウ素を十分に摂っている人が普通の量を食べる分には問題になりません。危険になる条件は、ヨウ素が不足した食事で生のキャベツを毎日大量に、特に搾り汁として長期間摂り続けた場合です。災害時に海から遠ざかりワカメやコンブが手に入らなくなると、実際に起こりうる条件なので、加熱した形態と交互に食べ、海藻類が手に入るなら一緒に食べます。ザワークラウトに発酵させても、ゴイトロゲンはかなり減ります。

&nbsp;&nbsp;&nbsp;シュウ酸はキャベツでは問題になりません。ホウレンソウやフダンソウとは異なり含有量が非常に低く、カルシウムの吸収を妨げません。

## 15. 冷蔵庫なしの貯蔵 - 室とザワークラウト

&nbsp;&nbsp;&nbsp;キャベツがこの文書に収録された最大の理由は、この節にあります。葉物野菜でありながら月単位で貯蔵でき、発酵させれば年を越します。

### 15-1. 貯蔵方式の比較

| 方式 | 条件 | 期間 | ビタミンC |
|---|---|:---:|---|
| 室温の日陰 | 涼しく暗い場所 | 2-4週間 | 徐々に減ります |
| 室貯蔵 | 0-4℃、湿度85-95% | 3-4か月 | かなりの部分が維持されます |
| 砂埋め | 涼しい納屋、湿った砂 | 2-3か月 | 維持されます |
| ザワークラウト | 常温発酵後に涼しい場所 | 6か月-1年以上 | 維持されるか増えます |
| 乾燥 | 千切りにして日陰干し | 6か月-1年 | ほぼ失われます |
| 塩漬け | 塩10-15% | 数か月 | 大きく減ります |

### 15-2. 室貯蔵

| 項目 | 方法 |
|---|---|
| 場所 | 排水のよい場所に1-1.5mの深さで穴を掘ります |
| 底 | わらか枯れ草を10cm敷きます |
| 入れ方 | 根を上に向けて逆さに置くか、横に寝かせます。互いに触れないよう間隔を空けます |
| 覆い | わらをかぶせ、土を30-50cm盛ります |
| 換気 | 中央にわら束や筒を立てて空気が通るようにします |
| 点検 | 2週間に1回開けて傷んだものを取り除きます |

> **室の目標は、凍らずかつ芽も出ない温度、つまり0℃から4℃です。浅すぎれば凍り、深すぎれば湿気がこもって腐ります。**

&nbsp;&nbsp;&nbsp;室の代わりに使える場所も多くあります。北向きの軒下、床下、地下倉庫、井戸端の日陰、納屋の北側の隅が候補になります。条件は同じです。凍らず、温度が大きく上下せず、光が入らず、空気がごくわずかに通うことです。

&nbsp;&nbsp;&nbsp;球同士が触れ合わないようにすることが重要です。一玉が腐り始めると、接触しているものが次々とそれに続きます。わらを間に挟んだり、棚に間隔を空けて並べたり、根ごと引き抜いたものなら根を束ねて逆さに吊るしたりします。吊るす方式が通風には最も優れています。

&nbsp;&nbsp;&nbsp;2週間に1回の点検を怠ると、貯蔵全体が崩れます。外葉が傷んでいるものはその葉だけを剥がせばよいですが、株元が軟らかくにおいがするものは、すぐに取り出して食べるか廃棄します。一つが十を台無しにする構造です。

### 15-3. ザワークラウト - 塩だけで行う1年貯蔵

&nbsp;&nbsp;&nbsp;災害状況でキャベツを扱う最も強力な方法です。塩と甕さえあればよく、火も冷蔵も必要なく、発酵の過程でビタミンCが維持されるか、むしろ増えます。

| 段階 | 方法 | 注意 |
|---|---|---|
| 1. 下処理 | 外葉を2-3枚取って別にしておき、芯をくり抜き、残りをできるだけ細く千切りにします | 細いほど汁が出やすくなります |
| 2. 計量 | 切ったキャベツの重さを量り、その2-2.5%にあたる塩を用意します | 1kgに塩20-25g |
| 3. 揉み込み | 塩を振り、手で30分ほど揉みます | 汁がたっぷり出るまで |
| 4. 詰め込み | 甕やガラス瓶に押し込んで詰めます。空気が残らないよう層ごとにしっかり押します | 汁が材料の上まで上がってくる必要があります |
| 5. 覆い | 取っておいた外葉で表面を覆い、その上に重石を乗せます | 材料が汁に完全に浸っている必要があります |
| 6. 発酵 | 15-20℃で1-3週間。気泡が上がってきます | 空気が抜けるよう布で覆います |
| 7. 保管 | 酸味が出たら涼しい場所（室、地下、北向きの納屋）に移します | 6か月から1年以上 |

> **成功と失敗を分けるただ一つの条件は、材料が汁に完全に浸っているかどうかです。空気に触れた部分にだけカビが生えます。**

&nbsp;&nbsp;&nbsp;原理を知っておけば応用が利きます。キャベツの葉にはもともと乳酸菌が付着しています。塩は細胞から水を引き出して汁をつくり、同時に雑菌の繁殖を抑えつつ乳酸菌は耐えられる濃度をつくります。乳酸菌が糖を食べて乳酸をつくると酸性になり、他の菌が生きられなくなります。この酸が防腐剤の役割を果たすため、冷蔵なしでも長くもつのです。韓国のキムチと同じ原理です。

&nbsp;&nbsp;&nbsp;塩分濃度が最も重要な変数です。2%を下回ると雑菌が優勢になり、3%を超えると乳酸菌も抑えられて発酵が遅くなります。はかりがなければ、キャベツ1個（おおよそ1.5kg）に対して塩大さじ1杯半から2杯程度が目安です。精製塩より天日塩のほうがよいですが、なければ精製塩でも構いません。

&nbsp;&nbsp;&nbsp;表面に白い膜が浮くことがありますが、たいていは産膜酵母で害はありません。取り除いてそのまま続ければよいです。逆に黒や青のカビが生えたら、その部分は確実に取り除き、においが酸っぱく爽やかなものではなく腐敗臭であれば、全部廃棄します。正常なザワークラウトは酸っぱくて塩気があり、キャベツの香りが残っています。

&nbsp;&nbsp;&nbsp;冬のビタミンC供給源としてのザワークラウトの価値は、歴史が証明しています。長い航海で壊血病を防いだのはこの漬けキャベツであり、中央ヨーロッパと東アジアの冬の食卓が発酵野菜に頼ってきたのも同じ理由からです。乾燥させればビタミンCは失われ、煮れば水に溶け出しますが、発酵はそれを残します。キャベツを10個収穫したなら、半分は室に入れ、半分は発酵に回すという配分が合理的です。

### 15-4. 乾燥と塩漬け

&nbsp;&nbsp;&nbsp;千切りにして湯通しした後、日陰で完全に乾かせば6か月から1年もちます。体積が10%に減るため保管と運搬に有利で、スープや粥にひとつかみずつ入れて使います。ただしビタミンCはほとんど失われます。干しキャベツは食物繊維とミネラルを残す貯蔵法であって、ビタミンCを残す貯蔵法ではないことをはっきりさせておきます。

&nbsp;&nbsp;&nbsp;塩10-15%で濃く漬け込めば数か月もちます。発酵がほとんど起こらない濃度なので塩漬けに近く、食べる前に水にさらす必要があります。塩に余裕があり、発酵を管理する余裕がないときに使う方法です。

## 16. 調理と加工

| 方法 | 燃料 | ビタミンC保存 | 備考 |
|---|:---:|:---:|---|
| 生食（千切りで食べる） | なし | 最大 | ビタミンUも生きています |
| 発酵（ザワークラウト） | なし | 維持または増加 | 貯蔵と調理を兼ねます |
| 湯通し1-2分 | 非常に少ない | 半分以下 | 体積が減り、ゴイトロゲンも減少します |
| 汁物・鍋に入れる | 他の調理と兼用 | 汁ごと食べれば保存されます | 燃料を別に使いません |
| 炒める | 少ない | 中程度 | 甘みが増します |
| 蒸す | 中程度 | 中程度 | 包んで食べるのに向いています |

&nbsp;&nbsp;&nbsp;燃料が貴重な条件下でのキャベツ最大の利点は、加熱しなくてもよいという点です。千切りにして塩を軽く振るだけでも一食のおかずになり、葉をそのままちぎってご飯を包んで食べてもよいです。すでに他のものを煮ている火に最後に投げ入れる方法は、燃料を追加で使わずに加熱した形を得る道です。

&nbsp;&nbsp;&nbsp;捨てられがちな部分を活かすことも実用的です。外葉は硬いですが、ビタミンCが最も多い部位です。細かく刻んでスープに入れたり、ザワークラウトに混ぜたりすれば、そのまま使えます。芯はシャキシャキとして甘みがあり、薄く削いで食べたりスープに入れたりします。キャベツ1個で実際に捨てるべきものは、土が付いた外側の1-2枚だけです。

&nbsp;&nbsp;&nbsp;ザワークラウトはそのまま食べることもありますが、調理にも使われます。汁ごとスープに入れると酸味のあるスープになり、炒めると酸味が和らぎます。ただし熱を加えると乳酸菌は死に、ビタミンCも減るため、冬にビタミンを狙うなら加熱せずそのまま食べるほうがよいです。

## 17. 年間作業スケジュール

| 月 | 作業 |

&nbsp;&nbsp;&nbsp;この日程の中で最も重要な欄は11月です。収穫したものをどう振り分けるかが、冬全体を左右します。硬く傷のない球は室へ、裂けたり傷ついたりした球はすぐにザワークラウトに回します。貯蔵に向かないものを貯蔵庫に入れると隣のものまで台無しにしますが、発酵に回せば逆に一年もちます。この仕分けを収穫の現場でその場で行うのがコツです。
