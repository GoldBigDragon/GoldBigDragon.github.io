## 12. 收获

### 12-1. 判断收获时机

| 标准 | 内容 |
|---|---|
| 触感 | 用手掌按压菜球，若坚实有弹力即已成熟 |
| 时期 | 春播6月下旬-7月，秋播10月下旬-11月 |
| 延迟收获 | 菜球会纵向开裂，内部还会抽出花薹 |
| 收获前 | 提前10天停止灌溉 |
| 收获时间 | 晴天清晨 |

&nbsp;&nbsp;&nbsp;如果按压时感觉发软，说明内叶还没长满，需要再等一等。反之若放置过久，内部持续生长的内叶会把外部撑裂，导致菜球开裂。开裂的菜球会因裂缝进菌而无法贮藏，应立即食用或用来发酵。

&nbsp;&nbsp;&nbsp;选在晴天清晨收获，是有原因的。若在雨后不久或露水未干时收获，外叶之间会残留水分，这些水分会成为贮藏期间腐烂的起点。反之，若在正午收获，菜球温度偏高，放入贮藏处后呼吸作用会变得旺盛，很快就会变质。把清晨凉爽的菜球直接放进阴凉处，是最好的做法。

### 12-2. 收获要领

| 步骤 | 方法 |
|---|---|
| 1 | 一手握住植株，用刀切断基部；若用于贮藏，也可以连根拔起 |
| 2 | 保留2-3片外叶，其余摘除 |
| 3 | 小心搬运，避免造成伤口，不要抛掷或堆压 |
| 4 | 在地里放置约半天，晾干表面水分（预晾） |
| 5 | 移至阴凉背光处 |

> **务必保留两三片外叶。它们能在贮藏期间阻挡水分蒸发、吸收物理冲击，外部一旦受损，只需剥掉那层叶片，里面依然完好。**

&nbsp;&nbsp;&nbsp;若以贮藏为目标，连根拔起的方式更好：根部残留的水分会缓慢输送到菜球，延缓其干枯的速度。抖掉泥土但不剪断根，直接倒挂，或重新埋入土中贮藏。

&nbsp;&nbsp;&nbsp;不要省略预晾这道工序，也就是把收获的菜球在阴凉处晾晒半天。表面带湿气进入贮藏处，水分会被封闭在里面，成为软腐病的起点。长时间放在阳光直射处会灼伤外叶，因此要在阴凉处晾干。

### 12-3. 收获后的基部管理

&nbsp;&nbsp;&nbsp;把根茬留在地里，侧芽有时会长出几个小结球甘蓝，个头只有拳头大小，数量也不多，但要是正好长在别无他物可吃的时期，也能凑成一顿菜。不过这个根茬也可能成为蛾类、蚜虫和病毒过冬的藏身之处。若地块的病虫害压力较大，放弃侧芽收成、把根茬挖出清理掉，对来年会更有利。

## 13. 留种 - 两年生与异花授粉的难关

### 13-1. 双重难关

&nbsp;&nbsp;&nbsp;结球甘蓝的留种，在本文档所涉作物中属于最棘手的一类。因为是二年生，必须越冬才能开花；因为是异花授粉，很容易与同一物种的其他变种混杂。更麻烦的是，结球这一结构本身就妨碍留种：花薹必须冲破层层卷合的叶片才能长出来。

| 障碍 | 内容 | 解决办法 |
|---|---|---|
| 二年生 | 必须经历低温才能抽薹 | 露地越冬，或窖藏后春天重新定植 |
| 结球 | 花薹无法穿透坚实的菜球 | 春天在菜球顶部划十字形切口 |
| 异花授粉 | 蜜蜂会传粉，导致与其他变种混杂 | 隔离距离、错期栽培、覆网 |
| 自交不亲和 | 自身花粉难以完成受精 | 留种株保留多株 |

### 13-2. 会与什么杂交

| 作物 | 学名 | 与结球甘蓝的杂交 |
|---|---|:---:|
| 羽衣甘蓝、西兰花、花椰菜、苤蓝、抱子甘蓝 | Brassica oleracea | 完全杂交 |
| 大白菜、青江菜、芜菁、油菜 | Brassica rapa | 几乎不杂交 |
| 芥菜、芥末 | Brassica juncea | 几乎不杂交 |
| 萝卜 | Raphanus sativus | 属不同，不会杂交 |

&nbsp;&nbsp;&nbsp;在给结球甘蓝留种的那一年，大白菜、萝卜或芥菜同时开花是没有问题的，因为物种不同。真正会带来麻烦的，只有Brassica oleracea这一类，也就是羽衣甘蓝、西兰花、苤蓝这些。

### 13-3. 防止杂交的三种方法

| 方法 | 内容 | 可行性 |
|---|---|---|
| 隔离距离 | 与其他开花的Brassica oleracea保持500m以上 | 邻近地块无法控制，难以实现 |
| 错期栽培 | 每年只让一个品种开花 | 最为可行 |
| 覆网 | 开花前罩上网罩，在网内用毛刷人工授粉 | 小规模种植时最可靠 |

&nbsp;&nbsp;&nbsp;错期栽培最为可行。今年只从结球甘蓝上留种，把羽衣甘蓝全部吃掉，不让它开花；第二年反过来。结球甘蓝种子能保存4到5年，因此每年轮流只留一个品种的种，也不会造成种子断供。

&nbsp;&nbsp;&nbsp;覆网时务必记住，结球甘蓝是自交不亲和的。用自身花粉难以完成受精，因此要把好几株一起罩在网内，用毛刷在花与花之间来回蘸抹授粉。如果只罩住一株，角果几乎不会结出来。

> **留种株至少保留5株，最好10株以上。异花授粉作物如果只靠一两株延续世代，用不了几代就会出现近交衰退，长势变弱，结球也会紊乱。**

### 13-4. 越冬与留种流程

| 阶段 | 时期 | 内容 |
|---|---|---|
| 选留种株 | 收获期 | 挑选菜球紧实硕大、品种特征明显、无病害的植株 |
| 越冬（露地） | 11-2月 | 仅限韩国南部，在基部培土，用稻草和落叶覆盖 |
| 越冬（窖藏） | 11-2月 | 韩国中部以北地区，连根拔起，埋入0-5℃的地窖中 |
| 重新定植 | 3月 | 把贮藏的植株重新种下 |
| 划切口 | 3-4月 | 在菜球顶部划十字形切口，深3-5cm |
| 抽薹 | 4月 | 花薹从切口处抽出，需立支柱固定 |
| 开花 | 4-5月 | 开出黄色花朵，此时要严格隔离 |
| 结荚 | 5-6月 | 结出角果 |
| 收获 | 6-7月 | 角果三分之二变褐色时，连茎一起割下 |
| 后熟·脱粒 | 收获后立即进行 | 在阴凉处晾1-2周后，装入袋中拍打脱粒 |

&nbsp;&nbsp;&nbsp;划切口是结球甘蓝留种特有的一道工序。春天花薹开始生长时，若菜球过于坚实，花薹就无法钻出，只能在里面弯曲、腐烂。在菜球顶部划出十字形、深3-5cm的切口，花薹便会顺着这条路径抽出。切得太深会导致内部开始腐烂，因此只划开外层的几片叶子即可。

&nbsp;&nbsp;&nbsp;韩国中部以北地区在露地越冬容易失败。虽能耐零下5℃，但若长时间低于这个温度，菜球会反复冻融而变软。应在霜冻正式来临前连根拔起，带着少量泥土埋入地窖或阴凉的库房中，维持0-5℃。这段贮藏期本身就是春化过程，因此春天重新定植后会立刻抽薹。

&nbsp;&nbsp;&nbsp;不要等角果在地里完全晒干。十字花科的角果一旦完全干燥，就会自行裂开，把种子撒落到地上。应在下部三分之二变褐色时连茎割下，放在布或袋子上后熟，这样连裂开脱落的种子也能一并收集。

| 项目 | 标准 |
|---|---|
| 种子寿命 | 常温密封4-5年 |
| 保存条件 | 阴凉、避光、干燥处，密封容器 |
| 干燥剂 | 炒过晾凉的大米、木炭、干草木灰 |
| 检查发芽率 | 每年取20粒种子放在湿布上，统计发芽率 |
| 单株产种量 | 数千粒种子 |

## 14. 毒性与需注意的成分

&nbsp;&nbsp;&nbsp;结球甘蓝没有急性毒性，洗净即可直接食用，评价表中烹饪·加工SS正体现了这一点。需要留意的有两点。

| 项目 | 内容 | 应对 |
|---|---|---|
| 胀气与腹胀 | 棉子糖之类的低聚糖会在大肠中发酵 | 初期少量食用，加热食用可减轻症状 |
| 致甲状腺肿物质 | 十字花科作物共有的成分，可能妨碍碘的吸收 | 加热后含量降低，可与海藻类一起食用 |
| 变质迹象 | 变色、发黏、恶臭 | 若只是外叶变质则剥除，若内部也已变软则整颗丢弃 |

&nbsp;&nbsp;&nbsp;致甲状腺肿物质与羽衣甘蓝中的成分相同，但结球甘蓝的含量比羽衣甘蓝更低。碘摄入充足的人正常食用不会有问题。真正危险的情形是：在碘摄入不足的饮食结构下，每天大量食用生结球甘蓝，尤其是长期饮用其榨汁。在灾害情境下远离海洋、裙带菜和海带断供时，这种情形确实可能出现，因此最好与熟食形式交替食用，若能获得海藻类食材就一并食用。发酵成酸菜后，致甲状腺肿物质也会大幅减少。

&nbsp;&nbsp;&nbsp;草酸在结球甘蓝中不构成问题。与菠菜或莙荙菜不同，其含量极低，不会妨碍钙的吸收。

## 15. 无冰箱贮藏 - 地窖与酸菜

&nbsp;&nbsp;&nbsp;结球甘蓝之所以被收录进本文档，最大的理由就在这一节：作为叶菜，它能以月为单位贮藏，发酵之后更能跨年保存。

### 15-1. 贮藏方式比较

| 方式 | 条件 | 期限 | 维生素C |
|---|---|:---:|---|
| 常温阴凉处 | 阴凉背光处 | 2-4周 | 逐渐减少 |
| 窖藏 | 0-4℃，湿度85-95% | 3-4个月 | 大部分得以保留 |
| 埋沙 | 阴凉库房，湿沙 | 2-3个月 | 得以保留 |
| 酸菜 | 常温发酵后移至阴凉处 | 6个月-1年以上 | 保留或增加 |
| 晒干 | 切丝后阴干 | 6个月-1年 | 几乎全部流失 |
| 盐渍 | 盐10-15% | 数月 | 大幅减少 |

### 15-2. 窖藏

| 项目 | 方法 |
|---|---|
| 选址 | 在排水良好处挖1-1.5m深的坑 |
| 坑底 | 铺10cm厚的稻草或干草 |
| 放置方式 | 根朝上倒放，或侧放；彼此留出间距，避免接触 |
| 覆盖 | 盖上稻草，再堆30-50cm厚的土 |
| 通风 | 在中央竖立草捆或管子，保持空气流通 |
| 检查 | 每2周打开一次，挑出变质的菜球 |

> **地窖的目标温度，是既不结冰又不发芽的区间，也就是0℃到4℃。挖得太浅会结冰，挖得太深则会积湿而腐烂。**

&nbsp;&nbsp;&nbsp;可以代替地窖的地方也有不少：朝北的屋檐下、地板下、地下室、井边阴凉处、库房北侧角落，都是候选。条件是一样的：不结冰、温度波动不大、不见光、还要有极其微弱的空气流通。

&nbsp;&nbsp;&nbsp;让菜球彼此不接触很重要。一颗一旦开始腐烂，与它接触的其他菜球会相继遭殃。可以在中间夹稻草，也可以在架子上留出间距摆放，若是连根拔起的，则可以把根捆起来倒挂。倒挂的方式通风效果最好。

&nbsp;&nbsp;&nbsp;一旦漏掉每两周一次的检查，整批贮藏就可能全盘崩溃。外叶受损的只需剥掉那层叶片即可，但基部发软、有异味的要立即取出食用或丢弃——这是"一颗坏十颗"的结构。

### 15-3. 酸菜 - 仅靠盐就能贮藏一年

&nbsp;&nbsp;&nbsp;这是灾害情境下处理结球甘蓝最有效的方法。只需要盐和坛子，不需要用火也不需要冷藏，发酵过程中维生素C能够保留，甚至有所增加。

| 步骤 | 方法 | 注意事项 |
|---|---|---|
| 1. 处理 | 摘下两三片外叶另放，挖去菜芯，其余部分尽量切得细一些 | 切得越细越容易出汁 |
| 2. 称量 | 称出切好的结球甘蓝的重量，准备相当于其2-2.5%的盐 | 每1kg配盐20-25g |
| 3. 揉搓 | 撒盐后用手揉搓约30分钟 | 揉到大量出汁为止 |
| 4. 装坛 | 压实装入坛子或玻璃罐，一层一层压紧，不留空气 | 汤汁要没过食材表面 |
| 5. 覆盖 | 用留出的外叶盖住表面，上面压一块压石 | 食材必须完全浸没在汤汁中 |
| 6. 发酵 | 15-20℃下发酵1-3周，会冒出气泡 | 用布盖住坛口，让气体能够排出 |
| 7. 保存 | 出现酸味后移至阴凉处（地窖、地下室、朝北库房） | 6个月至1年以上 |

> **决定成败的唯一条件，是食材是否完全浸没在汤汁里。只有接触空气的部分才会长霉。**

&nbsp;&nbsp;&nbsp;了解原理之后，举一反三就容易了。结球甘蓝叶片上本来就附着着乳酸菌。盐会从细胞中析出水分形成汤汁，同时营造出一个能抑制杂菌繁殖、却让乳酸菌能够耐受的浓度。乳酸菌分解糖分生成乳酸后，环境变酸，其他细菌便无法存活。这种酸就起到了防腐的作用，因此即便不冷藏也能长期保存。这与韩式泡菜的原理是一样的。

&nbsp;&nbsp;&nbsp;盐的浓度是关键变量。低于2%杂菌会占上风，超过3%则连乳酸菌也会受抑制，发酵变慢。没有秤的话，可以按一颗结球甘蓝（约1.5kg）配一勺半到两大勺盐来估算。天日盐比精制盐更好，但没有的话精制盐也可以。

&nbsp;&nbsp;&nbsp;表面有时会浮起一层白膜，多半是产膜酵母，无害，撇掉继续放置即可。反之，如果长出黑色或青色的霉斑，就要把那部分彻底挖除；如果气味不是酸爽而是腐臭，就要整坛丢弃。正常的酸菜应当是酸咸适口，并保留着结球甘蓝本身的香气。

&nbsp;&nbsp;&nbsp;历史已经证明了酸菜作为冬季维生素C来源的价值。在漫长的航海途中防止坏血病的，正是这种腌渍的结球甘蓝；中欧和东亚的冬季餐桌长期依赖发酵蔬菜，也是同样的道理。晒干会使维生素C消失，水煮会让它溶入水中流失，而发酵则能把它保留下来。如果收获了十棵结球甘蓝，比较合理的分配是一半放入地窖，一半用来发酵。

### 15-4. 晒干与盐渍

&nbsp;&nbsp;&nbsp;切丝后焯水，再在阴凉处彻底晒干，可保存6个月到1年。体积缩小到10%，便于存放和搬运，可以一把一把地加进汤或粥里。但维生素C几乎会全部流失。需要明确一点：晒干结球甘蓝是一种保留膳食纤维和矿物质的贮藏法，而不是保留维生素C的贮藏法。

&nbsp;&nbsp;&nbsp;用10-15%的高浓度盐腌渍，可保存数月。这个浓度几乎不会发酵，更接近咸菜，食用前需要用水浸泡去咸。这是在盐充足、却没有余力管理发酵时采用的方法。

## 16. 烹饪与加工

| 方法 | 燃料 | 维生素C保留 | 备注 |
|---|:---:|:---:|---|
| 生食（切丝食用） | 无 | 最多 | 维生素U也保留完整 |
| 发酵（酸菜） | 无 | 保留或增加 | 兼具贮藏与烹饪功能 |
| 焯水1-2分钟 | 极少 | 一半以下 | 体积缩小，致甲状腺肿物质减少 |
| 加入汤·锅中同煮 | 与其他烹饪共用燃料 | 连汤一起喝则可保留 | 不额外耗费燃料 |
| 炒制 | 少 | 中等 | 甜味会提升 |
| 蒸制 | 中等 | 中等 | 适合用来包裹食物食用 |

&nbsp;&nbsp;&nbsp;在燃料紧缺的条件下，结球甘蓝最大的优点就是不加热也能吃。切丝后只撒点盐，就是一道菜；也可以整片撕下叶子包饭吃。把它最后丢进已经在煮其他东西的锅里，是不额外耗费燃料、又能吃到熟食的办法。

&nbsp;&nbsp;&nbsp;把容易被丢弃的部分利用起来也很实用。外叶质地虽老，却是维生素C含量最高的部位，切碎放进汤里，或拌进酸菜中，都能物尽其用。芯部爽脆带甜，可以削成薄片直接吃，也可以放进汤里。一颗结球甘蓝里真正该丢的，其实只有沾着泥土的最外面一两片叶子。

&nbsp;&nbsp;&nbsp;酸菜既可以直接吃，也可以用于烹饪。连汤汁一起加进汤里，会做成带酸味的汤；炒过之后酸味会变得柔和。不过加热会杀死乳酸菌，维生素C也会减少，因此若是在冬天以摄取维生素为目的，不加热直接食用会更好。

## 17. 全年作业日程

| 月份 | 作业 |
|---|---|
| 1月 | 检查窖藏（每2周一次），食用酸菜，规划田地 |
| 2月 | 检查地窖，准备春播、翻堆肥，检查留种株的越冬情况 |
| 3月 | 开始春播·育苗，留种株重新定植并划切口 |
| 4月 | 春苗炼苗与定植，留种株开花，做好隔离管理 |

&nbsp;&nbsp;&nbsp;这份日程中最重要的一格是11月。收获物如何分配，决定着整个冬天。紧实无损的菜球放进地窖，开裂或有伤的菜球立即拿去做酸菜。把不适合贮藏的放进贮藏处，会连累旁边的一起遭殃；而拿去发酵，反倒能保存一整年。诀窍就在于在收获现场当场完成这种分类。
