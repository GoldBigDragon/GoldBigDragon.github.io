## 8. 栽培管理 - 結球をつくる作業

### 8-1. 結球はなぜ失敗するか

&nbsp;&nbsp;&nbsp;キャベツ栽培で最もよくある失敗は、病気でも害虫でもなく結球不良です。葉は茂っているのに球ができない、あるいはできても握りこぶし程度でゆるいままということが起こります。原因はおおむね次の五つのうちのどれかです。

| 原因 | どう現れるか | 対応 |
|---|---|---|
| 高温 | 結球期の気温が25℃を超えると葉が広がり続けます | 播種期を調整し、結球期が15-20℃になるよう合わせます |
| 養分不足 | 外葉が小さく色が薄く、内葉が押し出されません | 結球期の追肥を必ず施します |
| 水不足 | 球は硬いが小さいまま大きくなりません | 結球期に絶えず灌水し、マルチングします |
| 密植 | 外葉同士が重なって光を受けられません | 70×40cmの間隔を守ります |
| 生長点の損傷 | 蛾の幼虫が芯を食べると結球がそもそも始まりません | 結球前に防虫網をかけ、幼虫を取り除きます |

> **結球とは、外葉がつくった養分を内側へ押し込む作業です。外葉10-15枚を大きく濃い色に育てておくことが、結球管理のほぼすべてです。**

&nbsp;&nbsp;&nbsp;この原理から実務上の指針が導かれます。定植後6週間までは外葉を育てることに集中します。窒素をたっぷり与え、株間を守って光がまんべんなく入るようにします。この時期に外葉を摘んで食べてはいけません。ケールのように下葉を摘む習慣でキャベツに接すると、結球が崩れます。外葉はキャベツの工場であり、工場を壊して食べてしまえば製品は出てきません。

&nbsp;&nbsp;&nbsp;定植後6週間が過ぎて内側が巻き始めたら、方向を変えます。窒素は与え続けますが、カリウムを増やします。水は均一に保ちます。この時期から収穫までの4-6週間が、球の大きさと硬さを決めます。

### 8-2. 土寄せと株の管理

| 作業 | 時期 | 内容 |
|---|---|---|
| 欠株補充 | 定植後1週間 | 枯れた場所に予備の苗を補います |
| 1回目の土寄せ | 定植後3-4週間 | 株元に土を5cm盛ります |
| 2回目の土寄せ | 結球開始直前 | もう一度盛って根を保護します |
| 外葉の整理 | 随時 | 病気や黄変した外葉だけを取り除きます |
| 支柱 | 風の強い畑 | 球が大きくなると重みで傾くことがあります |

&nbsp;&nbsp;&nbsp;土寄せは根を保護し、株を安定させます。キャベツの細根は浅く広がるため、除草や風雨で簡単に露出し、露出した根は乾いたり傷んだりします。株元に土を盛ると、その部分から新しい根が出て、養分の吸収力が高まることもあります。

&nbsp;&nbsp;&nbsp;外葉の整理は慎重に行います。ケールのようにまめに摘み取る作業ではありません。病気の葉と完全に黄変した葉だけを取り除きます。まだ緑色の外葉は残します。収穫のときも外葉を2-3枚付けたままにしますが、貯蔵中の保護膜になるためです。

### 8-3. 雑草管理

&nbsp;&nbsp;&nbsp;決定的な時期は定植後2-6週間です。この時期に雑草が外葉より大きくなると、光をめぐる競争に負けて結球が難しくなります。2週間おきに、くわで表面2-3cmだけ浅く削ります。深く掘ると浅く広がった細根が切れてしまいます。外葉が畝を覆うほど大きくなれば、日陰が自然と雑草を抑えるので、その後は大きいものだけ抜けば十分です。

## 9. 病害虫 - 薬に頼らず防ぐ方法

### 9-1. 主な害虫

| 害虫 | 被害の様子 | 発生時期 | 薬に頼らず防ぐ方法 |
|---|---|---|---|
| モンシロチョウの幼虫 | 緑色の幼虫が葉脈だけを残して食べます | 4-6月、9-10月 | 手で捕る、防虫網、葉裏の黄色い卵をこすり落とす |
| コナガ（ダイヤモンドバックモス） | 小さな幼虫が葉裏を食べ、薄い膜を残します | 5-10月 | 防虫網、こまめな見回り、木酢液の希釈液 |
| ハイマダラノメイガ | 幼苗の生長点を食い荒らし、結球がそもそもできなくなります | 定植初期 | 早期発見と除去、防虫網 |
| ヨトウガ・ハスモンヨトウ | 大きな幼虫が葉と結球を食い荒らします | 夏-秋 | 夜に手で捕る、早朝の捕殺 |
| ノミハムシ | 幼苗の葉に粟粒大の穴を開けます | 4-6月 | 防虫網、草木灰をまく、畝にわらを敷く |
| アブラムシ | 葉裏や内側に群がり汁を吸います。ウイルスも媒介します | 4-6月、9-10月 | 石けん水、水流で洗い流す、テントウムシの保護 |
| ナメクジ | 外葉と結球の表面に穴を開けます | 韓国の梅雨時（チャンマ、6月下旬-7月） | 夜に捕る、灰やもみ殻の帯 |

### 9-2. なぜ結球前に防がねばならないのか

&nbsp;&nbsp;&nbsp;キャベツの害虫管理には期限があります。葉が巻き始めると、その中に入り込んだ幼虫を捕る方法がありません。外から見ると無事に見える球を割ってみると、中が糞と穴だらけということがここから起こります。そのような球は食べることも貯蔵することもできません。

> **結球が始まる前に防虫網をかけ、その前に葉に付いた卵と幼虫をすべて取り除きます。結球が始まった後にかけると、害虫を中に閉じ込めて育てるようなものになります。**

&nbsp;&nbsp;&nbsp;ハイマダラノメイガは特に初期に危険です。この害虫の幼虫が幼苗の生長点を食い荒らすと、その株は結球そのものを始められなくなります。茎が異常に枝分かれしたり、小さな芽がいくつも出てきたりする形で現れます。定植後2週間以内にこのような株が見られたら、抜き取って予備の苗で補います。

### 9-3. 防虫ネットと物理的な遮断

&nbsp;&nbsp;&nbsp;目合い1mm前後の防虫ネットを支柱にかけて畝全体を覆い、端を土で押さえて密閉すると、チョウやガの産卵を防げます。有機栽培の実証文献でも、防虫網の被覆が最も確実な手段として記録されています。ネットがなければ、目の細かい蚊帳、薄い布、古いカーテンで代用します。

&nbsp;&nbsp;&nbsp;注意すべき点は通風です。キャベツは結球期に湿気がこもると軟腐病が爆発的に広がります。完全に密閉せず、日中は片側を開けるか、支柱を高く立てて空気の層を確保します。長雨の後はネットを外して1日ほど乾かします。

### 9-4. 手による捕殺と自然防除剤

&nbsp;&nbsp;&nbsp;キャベツ20株規模の畑であれば、手で捕る方法だけでもかなりの防除になります。モンシロチョウの幼虫は大きくて動きが遅いので目に付きやすく、葉にできた穴をたどればその近くにいます。もっと効率的なのは卵の段階です。白いチョウが飛んでいるのを見た翌日、葉裏で細長い黄色い卵を探して指でこすり落とせば、幼虫1匹を先回りして消せます。

&nbsp;&nbsp;&nbsp;ヨトウガとハスモンヨトウの大きな幼虫は、昼間は土の中や外葉の裏に隠れていて、夜に出てきます。昼間に見つけたいときは、被害のひどい株の根元の土を軽く掘ってみます。日が沈んだ後に明かりを持って出れば、はるかに捕まえやすくなります。

| 防除剤 | 作り方 | 対象 | 注意 |
|---|---|---|---|
| 石けん水 | 無香料の石けん20gを水1Lに溶かします | アブラムシ、ダニ | 夕方にまき、翌日洗い流します |
| ニンニク・トウガラシ浸出液 | ニンニク100gと乾燥トウガラシを水1Lですりつぶし、1日寝かせます | 忌避剤 | 予防用で、すでに付いた害虫は殺せません |
| 木酢液 | 500-1,000倍希釈 | 忌避剤全般 | 濃いと葉が傷みます |
| 草木灰 | ふるいにかけて葉と土にまきます | ノミハムシ、ナメクジ | 雨の後は再度まきます |

### 9-5. 主な病害

| 病害 | 症状 | 条件 | 対応 |
|---|---|---|---|
| 根こぶ病（いぼ病） | 根にこぶ、日中にしおれる | 酸性土壌、過湿 | 治療不可。pH6.5以上、排水、7年輪作 |
| 軟腐病 | 株元と球が軟化し、悪臭がします | 高温多湿、傷 | 排水、傷をつけない、病株の即時除去 |
| べと病 | 葉に黄色い斑点、裏面に灰白色のカビ | 涼しく湿っているとき | 通風、間隔確保、病葉の除去 |
| 菌核病 | 株元が軟化し、白い菌糸と黒い菌核 | 低温多湿 | 排水、罹病株の除去、輪作 |
| 黒腐病 | 葉の縁がV字状に黄変します | 高温多湿 | 種子の温湯消毒、病株の除去 |
| 黒斑病 | 葉に同心円状の斑点 | 多湿 | 通風、残渣の除去 |

> **根こぶ病は薬では治せず、土の中で7年以上生き続けます。アブラナ科の畑は、酸度と排水と輪作の三つであらかじめ防ぐしかありません。**

&nbsp;&nbsp;&nbsp;軟腐病は、貯蔵を狙うキャベツにおいて特に致命的です。畑ですでに感染していた球は、室に入れた後で腐り、その一玉が隣の球まで一緒に傷めてしまいます。傷が侵入経路になるため、収穫の際に球を投げたり打ちつけたりせず、雨が上がった直後には収穫しません。貯蔵前に球を一つひとつ確認し、株元が軟らかかったりにおいがしたりするものは別にして先に食べます。

### 9-6. 耕種的防除の原則

| 原則 | 内容 |
|---|---|
| 播種期の調整 | 蛾の発生最盛期を避けます。秋栽培では8月定植が9月の産卵期と重なります |
| 輪作 | アブラナ科を連作しません。最低2年、根こぶ病があれば7年 |
| 間隔確保 | 70×40cmを守ります。通風がカビ性の病気を減らします |
| 残渣の除去 | 収穫後の株元と外葉を畑に残しません。翌年の病原菌の宿主になります |
| 混植 | ディル、コリアンダー、ニンジンの花が寄生バチやハナアブを呼び寄せます |
| 天敵の保護 | テントウムシ、クサカゲロウ、クモ、寄生バチを殺しません |

&nbsp;&nbsp;&nbsp;残渣の除去はキャベツにおいて特に重要です。収穫後に畑に残った株元と根は翌年まで生き延びて新芽を出し、その新芽が蛾やアブラムシやウイルスの冬の隠れ家になります。収穫が終わったら株元を掘り出して畑の外に持ち出し、堆肥にするか家畜に与えます。根こぶ病が出た畑であれば、堆肥にもせず、焼くか遠くに深く埋めます。

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然素材による対策 |
|---|---|---|
| 下の葉から黄色くなり株が小さい | 窒素欠乏 | 尿8-10倍希釈液、完熟堆肥、草の液肥 |
| 葉の縁が茶色く焦げたようになる | カリウム欠乏 | 草木灰を株の周りにまきます |
| 葉が濃い青緑色で生育が止まる | リン酸欠乏 | 骨粉、草木灰 |
| 結球しない、またはゆるい | 窒素とカリウムの不足 | 結球期の追肥を必ず施します |
| 内葉の縁が茶色く焦げたようになる（芯腐れ） | カルシウム欠乏または急激な水分変化 | 卵・貝殻の粉、均一な灌水 |
| 球の内部が茶色くなり空洞化する | ホウ素欠乏 | 完熟堆肥。草木灰を与えすぎた畑で多く見られます |
| 新葉の葉脈の間が黄色く、葉脈は緑のまま | マグネシウムまたは鉄の欠乏 | pHが高すぎないか確認し、草木灰を減らします |
| 葉が柔らかく軟弱で害虫が集まる | 窒素過剰 | 窒素を断ちます。貯蔵性も落ちます |

&nbsp;&nbsp;&nbsp;芯腐れはキャベツでよく見られる生理障害であり、病気ではありません。カルシウムが球の内部まで届かないために起こります。カルシウムは水の流れに乗って移動しますが、結球の中の葉はほとんど蒸散しないため、水があまり行き渡りません。土にカルシウムが十分あっても現れることがあるのはこのためです。急な乾燥と過湿を行き来すると悪化するため、カルシウムを与えることより、均一な灌水のほうが効果的な場合が多いです。

&nbsp;&nbsp;&nbsp;ホウ素欠乏は草木灰を多く使った畑でよく起こります。灰はアルカリ性でpHを上げますが、7.5を超えるとホウ素が水に溶けない形に固定され、根が吸収できなくなります。球の内部が褐変して空洞化する症状が出たら、灰をさらに入れるのではなく中止し、腐熟堆肥で有機物を補いながらゆっくり元に戻します。

## 11. 間作と輪作

| 相性 | 対象 | 効果 |
|:---:|---|---|
| よい | マメ科（エンドウ、インゲンマメ、ソラマメ） | 窒素を固定し、キャベツが使える窒素を残します |
| よい | 長ネギ、タマネギ、ニンニク | においが蛾やアブラムシを混乱させます |
| よい | ディル、コリアンダー、ニンジンの花 | 寄生バチやハナアブを呼び寄せ、アブラムシを減らします |
| よい | ジャガイモ、ビーツ、セロリ | 根の深さが異なり競合が少ないです |
| 普通 | サンチュ、ホウレンソウ | 初期に畝の間を覆って雑草を抑えます |
| 悪い | ケール、ハクサイ、ダイコン、カラシナ、ブロッコリー | 病害虫を共有し、蓄積します |
| 悪い | イチゴ、トマト | 互いの生育を妨げます |

```
キャベツ（アブラナ科、多肥） → エンドウ・インゲンマメ（マメ科、窒素回復） → ジャガイモ・サツマイモ（ナス科・ヒルガオ科） →
長ネギ・タマネギ（ユリ科） → 再びキャベツ
```

&nbsp;&nbsp;&nbsp;この順序で回すと、同じ場所にキャベツが戻ってくるまで4年かかります。評価表の連作適応性Aは2年の休作を推奨するという意味ですが、根こぶ病が確認された畑では7年以上に延ばす必要があります。ダイコンやカラシナやケールを、同じアブラナ科だからという理由でその間に入れないことが肝心です。

&nbsp;&nbsp;&nbsp;キャベツを栽培する前に、まず豆類を植えるとよいでしょう。キャベツはこの文書が扱う葉菜の中で最も肥料を多く要求し、マメ科は窒素を自ら作り出します。エンドウやソラマメを冬から春にかけて育て、花が咲く頃にすき込むと、根粒に蓄えられた窒素が土に返ります。すき込んで3-4週間腐熟させた後にキャベツを定植すれば、元肥のかなりの部分を代替できます。化学肥料がない条件では、この順序一つが結球の成否を分けることもあります。
