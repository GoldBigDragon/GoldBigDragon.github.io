## 2. どんな植物か

### 2-1. 分類と原産地

&nbsp;&nbsp;&nbsp;キャベツはアブラナ科（Brassicaceae）アブラナ属（Brassica）の二年草です。学名はBrassica oleracea var. capitataで、ケール、ブロッコリー、カリフラワー、コールラビ、芽キャベツと同じ種の別変種にあたります。人が野生キャベツから葉が重なり合って巻く性質を選び、数千年かけて育ててきた結果が今日の結球です。

&nbsp;&nbsp;&nbsp;同じ種であるという事実が実務上意味することは二つあります。第一に、ケールやブロッコリーやコールラビと花粉をやり取りして種子が交雑します。採種の際に必ず考慮すべき制約で、第13節のテーマです。第二に、アブラナ科全体で病害虫を共有します。モンシロチョウ、コナガ、ノミハムシ、根こぶ病がケールとハクサイとダイコンとカラシナをともに襲います。

&nbsp;&nbsp;&nbsp;原産地は地中海沿岸と西ヨーロッパの大西洋岸です。涼しい海洋性気候の出身なので高温に弱く、25℃を超えると結球せず、30℃が続くとすでにできた球が裂けることもあります。石灰岩地帯の出身なのでカルシウムを好み、酸性土壌を嫌います。冬の低温を経なければ花茎が伸びない二年草の性質も、その気候に由来します。

### 2-2. 形態

| 器官 | 特徴 |
|---|---|
| 外葉 | 幅広く厚い卵形で、表面に白いろう層があります。結球をつくる工場であり、貯蔵中の保護膜でもあります |
| 結球（球） | 内葉が幾重にも巻いた球状です。品種によって扁平だったり、とがっていたり、丸かったりします |
| 芯（中心柱） | 球の真ん中を縦に貫く短くて太い茎です。先端に生長点があります |
| 茎 | 非常に短く太いです。葉柄が密に付いているため、茎のようには見えません |
| 根 | まっすぐな主根が40-60cmまで伸び、細根は浅く広がります |
| 花 | 黄色い花弁4枚が十字状に付きます。2年目の春に咲きます |
| さや・種子 | 細長い角果の中に赤褐色の種子が入っています |

&nbsp;&nbsp;&nbsp;結球の構造を理解すれば、キャベツ栽培のほとんどすべてが説明できます。外側の外葉5-6枚は広がって日光を受けます。これらの葉がつくった養分が中心に集まり、内葉を押し出します。内葉は光を受けずに育つため色が薄く柔らかく、上に広がることができず内側に巻き込みます。幾重にも重なった内葉が互いを押し合うことで球が締まっていきます。

> **外葉が結球をつくります。外葉が十分に大きくなければ、内葉を押し出す養分がなく、球はできません。外葉5-6枚を大きく健康に育てることが、結球管理のすべてです。**

&nbsp;&nbsp;&nbsp;芯は球の真ん中を縦に通る太い茎で、その先端に生長点があります。収穫の際に芯を切り取りますが、株元に芯の一部と外葉を残しておくと、そこの側芽から小さなキャベツがいくつか新しく出てくることもあります。大きさは握りこぶし程度で数量も少ないですが、他に何もない時期に出てくれば価値は高くなります。ただし評価表の永続性Dが示す通り、これはあくまで副収入であって本格的な再収穫ではありません。

### 2-3. 生育段階

| 段階 | 時期 | 主な生理 | 重要な養分 |
|---|---|---|---|
| 発芽・育苗期 | 播種から40日 | 本葉4-5枚まで育てます | リン酸、少量の窒素 |
| 活着期 | 定植後1-2週間 | 切れた根が新しく伸びます | リン酸 |
| 栄養生長期（外葉形成） | 定植後3-6週間 | 外葉10-15枚をつくります | 窒素 |
| 結球期 | 定植後6-12週間 | 内葉が内側に巻いて球が大きくなります | カリウム、カルシウム、窒素 |
| 成熟期 | 結球後2-3週間 | 球が締まります | 灌水と施肥を中止 |
| 抽だい・開花期 | 翌年の春 | 球が裂けて花茎が伸びます | リン酸、カリウム、ホウ素 |

&nbsp;&nbsp;&nbsp;栄養生長期と結球期の境目が、キャベツ栽培の分水嶺です。定植後6週間ほどで外葉が10-15枚ほど育つと、植物は方向を変えます。新しい葉を広げる代わりに、内側へ巻き始めるのです。この転換が起こるには条件がそろわなければなりません。気温が15-20℃の間であり、養分と水が十分でなければなりません。条件がそろわなければ転換は起こらず、葉が広がり続けるだけです。いわゆる結球不良です。

&nbsp;&nbsp;&nbsp;抽だいについても知っておくべきことがあります。キャベツは幼苗が一定の太さ以上に育った状態で低温に当たると、春化が起こります。茎の直径が鉛筆ほどの太さ（約6mm）を超えた苗が、10℃以下を3週間以上経験すると、その信号が記録されます。春栽培で早すぎる播種や大きすぎる苗の定植が危険なのはこのためです。その年の春に球をつくらず、花茎だけを伸ばしてしまいます。幼い苗はまだ低温を感知しないため、小さい苗を遅めに植えるほうがかえって安全です。

### 2-4. 100gあたりの栄養

| 栄養素 | 含有量 | 備考 |
|---|:---:|---|
| 熱量 | 29kcal | 韓国国家標準食品成分表の生の値です |
| 水分 | 約92% | ほとんどが水です |
| タンパク質 | 1.36g | 熱量に占める割合は18.8%です |
| 炭水化物 | 5-6g | 糖類が4.40gで、葉物野菜の中では甘みがあるほうです |
| 脂質 | 0.1g | ほとんどありません |
| 食物繊維 | 2-3g | 腸の働きに関わります |
| ビタミンC | 30-40mg | 1個で複数人の1日量を超えます |
| ビタミンK | 高い | 血液凝固と骨形成に関わります |
| ビタミンU（S-メチルメチオニン） | 含有 | 胃粘膜保護との関連が報告されているアミノ酸誘導体です |
| 葉酸 | 豊富 | 造血に関わります |
| カルシウム | 40-50mg | ケールより少ないですが、吸収はよいです |
| カリウム | 200mg前後 | 塩分摂取が増えたときのバランスに関わります |

&nbsp;&nbsp;&nbsp;ビタミンCについて、実用上重要な事実を一つ挙げておきます。キャベツのビタミンCは外葉に最も多く、内側にいくほど減っていきます。日光を受けた葉でより多く合成されるためです。外葉は硬く色が濃いのでよく捨てられますが、栄養面では捨てるべき部分ではありません。細かく刻んでスープに入れたり、ザワークラウトに一緒に漬け込んだりすれば、そのまま活かせます。

&nbsp;&nbsp;&nbsp;ビタミンUは正式名称をS-メチルメチオニンというアミノ酸誘導体で、キャベツの搾り汁が胃粘膜に働きかけるという観察から名付けられました。熱に弱く、加熱するとかなりの部分が失われるため、生で食べるか搾り汁にするほうがこの成分を活かせます。

&nbsp;&nbsp;&nbsp;さらに、発酵が栄養を変えるという点がキャベツでは特に重要です。ザワークラウトに発酵させると、ビタミンCはおおむね維持されるかむしろ増え、ビタミンB群が新たにつくられ、乳酸菌が加わります。加熱したり乾燥させたりする貯蔵はビタミンCを失いますが、発酵はそうではありません。第15節でこの内容を扱います。

## 3. 栽培環境

### 3-1. 気温

| 区分 | 限界値 | 最適値 | 備考 |
|---|:---:|:---:|---|
| 発芽温度 | 15-30℃ | 25℃ | 25℃なら3-4日で発芽します |
| 生育温度 | 5-27℃ | 15-20℃ | 評価表の温度適応幅Bは、結球基準の12℃幅から出ています |
| 結球適温 | 15-27℃ | 15-18℃ | この範囲を外れると巻きません |
| 高温限界 | 25℃以上 | - | 結球不良、早期抽だい、球の裂開 |
| 低温限界 | 氷点下5℃ | - | 韓国南部では露地越冬が可能。これより下がると球が凍害を受けます |
| 春化誘導 | 茎の直径6mm以上で10℃以下を3週間 | - | 翌年ではなくその年の春に抽だいします |

> **結球は温度の問題です。肥料と水がどれほど十分でも、25℃が続けば巻きません。播種時期を計算するときは、収穫するときではなく結球するときの気温を見ます。**

&nbsp;&nbsp;&nbsp;この原則から作型が決まります。春栽培は3-4月に植えて6月下旬から7月に収穫しますが、結球期が5-6月にあたるためぎりぎりです。秋栽培は7-8月に植えて10月下旬から11月に収穫し、結球期が9-10月にあたるので気温がぴったり合います。秋栽培が品質と貯蔵性の両方で優れているのはこのためです。

### 3-2. 光

| 区分 | 基準 | 備考 |
|---|---|---|
| 必要日照 | 1日6時間以上 | 外葉が大きく育ってこそ結球します |
| 最低日照 | 1日4時間 | 低日照でも結球する品種が別にあります |
| 40%遮光時 | 相対収量86% | 葉菜類共通の値で、評価表のB等級の根拠です |

&nbsp;&nbsp;&nbsp;遮光下でも収量の86%を維持するというこの値は、葉の重さを基準にしたものです。ただし結球品質はそれよりも敏感です。光が足りないと外葉が薄く大きく広がり、内側に送る養分が減って、球が小さくゆるくなります。日当たりのよい場所を熱量作物に譲るとしても、キャベツには1日5-6時間の直射日光は確保してやるほうがよいでしょう。

### 3-3. 水と土壌

| 項目 | 基準 | 備考 |
|---|---|---|
| 総蒸発散量 | 作期あたり約550mm | 葉菜の中では多いほうで、評価表のB等級の根拠です |
| 土壌水分 | 最大容水量の70-80% | 結球期に特に重要です |
| 土性 | 保水力のよい壌土、埴壌土 | 砂地では結球期に水が不足します |
| 土壌の深さ | 30cm以上 | 主根が深く伸びます |
| pH | 6.0-6.8 | 6.5前後が最も適します |
| pH下限 | 5.5 | これを下回ると根こぶ病が急増します |

&nbsp;&nbsp;&nbsp;キャベツはケールより水を多く使います。総蒸発散量550mmはケールの400mmより1.4倍多くなります。結球期に水が途切れると球が小さくなり、水が途切れた後に急に与えられると、内部が急激に大きくなって外側が追いつかず、球が裂けます。均一な水分供給はキャベツにおいて他のどの作物よりも重要で、灌水設備がない条件ではマルチングで蒸発を減らす方法に頼るしかありません。

&nbsp;&nbsp;&nbsp;酸度管理は根こぶ病を防ぐことと同義です。pH6.5以上を保てば、病原菌の活動は大きく抑えられます。石灰がなければ、草木灰や、焼いて砕いた貝殻・卵殻、カキ殻の粉で代用します。ただしキャベツはpHが7.0を大きく超えるとホウ素の吸収が妨げられ、内部が褐変する症状が出るため、酸度をむやみに上げてはいけません。
