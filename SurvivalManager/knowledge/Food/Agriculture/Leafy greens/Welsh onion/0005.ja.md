## 8. 栽培管理 - 土寄せと分げつ

### 8-1. 土寄せの原理

&nbsp;&nbsp;&nbsp;土寄せは、育っている長ネギの株元に土を盛り上げてかぶせる作業です。長ネギ栽培でもっとも重要な管理であり、事実上、この作業が長ネギを長ネギたらしめています。

&nbsp;&nbsp;&nbsp;原理は単純です。植物の葉は光を受けると葉緑素をつくって緑色になり、光を受けられないと葉緑素をつくらず白いまま残ります。長ネギの葉鞘が幾重にも重なった柱のうち、土に埋まった部分は光を受けられないので白く残り、その部分が軟白部になります。土を高く盛るほど、軟白部が長くなります。

&nbsp;&nbsp;&nbsp;ところが白い色は結果にすぎず、人にとって意味のある変化は別にあります。光を受けない組織は、硬い繊維をあまりつくらず、その代わりに糖を蓄えます。軟白部がやわらかく甘みがあるのは、このためです。緑の葉が辛くて硬いのに対し、白い部分がやわらかく甘く感じられる違いは、ここから生まれます。

> **軟白部の長さと太さは、種が決めるのではなく、人が土を何回、どれだけ盛ったかによって決まります。土寄せを一度もしていない一本立ちネギは、小ネギに近いものです。**

### 8-2. 土寄せの時期と高さ

| 回数 | 時期 | 土を盛る高さ | 同時に行うこと |
|---|---|:---:|---|
| 1回目 | 定植後1か月 | 5-6cm | 肥料を溝に入れ、その上に土を寄せます |
| 2回目 | 1回目の1か月後 | 10cm | 肥料を入れて土を寄せます |
| 3回目 | 2回目の1か月後 | 葉の分かれた部分が10cmほど覆われる程度 | 肥料を入れて土を寄せます |
| 仕上げ | 収穫の3-4週間前、または越冬前 | 必要に応じて | 冬の断熱を兼ねます |

&nbsp;&nbsp;&nbsp;もっとも重要な基準線は、葉が分かれる地点です。長ネギの葉鞘は柱をなし、ある高さで葉が外側へ分かれて出てきますが、その分かれる地点を土で覆ってしまってはいけません。そこに土が入ると、葉鞘の間の隙間に土と水がしみ込み、その湿って空気の通らない空間から軟腐病が始まります。

| 誤った土寄せ | 結果 |
|---|---|
| 始めるのが早すぎる | まだ幼い株が土に押さえつけられ、生育が遅れます |
| 一度に高く盛りすぎる | 葉の分かれ目が埋まり、軟腐病が出ます |
| 浅くしか盛らない | 軟白部が短く、食べられる部分が少なくなります |
| 濡れた土を盛る | 土が固まって空気が通らなくなります |
| 肥料なしで土だけ盛る | 新しい根が出ても、吸収するものがありません |

&nbsp;&nbsp;&nbsp;三回に分けて少しずつ盛る理由はここにあります。一度に30cmをかぶせると軟白部が長くなりそうですが、その高さでは、すでに葉の分かれ目が埋まってしまいます。長ネギが育つにつれて葉の分かれ目も上へ上がっていくので、その動きに合わせて少しずつかぶせなければなりません。植物が育つ速さと、人が土を盛る速さを合わせる作業だと考えれば正確です。

&nbsp;&nbsp;&nbsp;乾いた土を盛るという条件にも触れておきます。雨が降った直後の濡れた土を盛ると、それが固まって塊になり、空気が通らず軟白部が傷みます。晴れた日が数日続いて土がぱらぱらになったときが、土寄せの適期です。

### 8-3. 分げつ株の株分け

&nbsp;&nbsp;&nbsp;評価表の永続性Sを実際に実現する作業が、これです。長ネギは二年草ですが、分げつした株を切り離して植え直せば、種がなくても株が代々続きます。

| 項目 | 内容 |
|---|---|
| 時期 | 韓国では早春（3-4月）または秋（9-10月） |
| 対象 | 株元から複数の茎が分かれて出た株 |
| 方法 | 株ごと掘り上げて、手で裂いて分けます |
| 分ける単位 | 一本ずつ、または二、三本ずつ |
| 整え方 | 葉を半分ほど切り、長い根の先を整えます |
| 植え直し | 新しい溝に、定植と同じ方法で植えます |

&nbsp;&nbsp;&nbsp;葉を半分ほど切って植える理由は、ニラと同じです。植え替えると根が切れて水を吸い上げる能力が落ちますが、葉がそのままだと、出ていく水分が入ってくる水分より多くなり、株が枯れてしまいます。葉を減らして、このバランスをとります。

&nbsp;&nbsp;&nbsp;この循環がもたらす結果は、災害への備えにおいて重要です。一株が八本に分かれたら、そのうち半分を食べ、半分を植え直します。翌年には、その半分がまた複数の茎に分かれます。種の袋がなくても畑が自ら種苗をつくる仕組みであり、種子寿命Dという弱点を正面から回避します。

| 回 | 時点 | 結果 |
|---|---|---|
| 最初の定植 | 0年 | 一株 |
| 1回目の株分け | 1年 | 三、四株、そのうち半分は食用 |
| 2回目の株分け | 2年 | 十数株 |
| 3回目の株分け | 3-4年 | 畑ひと区画 |

### 8-4. 雑草と越冬の管理

| 時期（韓国） | 作業 | 理由 |
|---|---|---|
| 生育初期 | 雑草が幼いうちに抜きます | 長ネギは葉が細く地面を覆えないため、雑草に弱いのです |
| 土寄せのたび | 土を盛りながら一緒に埋めます | 雑草管理と土寄せが一つの作業になります |
| 10月下旬 | 最後の土寄せを終えます | 軟白部が土に覆われて断熱されます |
| 11月 | カリウム中心に肥料を入れます | 耐寒性を高めます |
| 12月から2月 | わらや落ち葉をかぶせます | 韓国中部以北でとくに必要です |
| 冬のあいだずっと | 必要なときに一本ずつ抜きます | 畑が貯蔵庫です |

&nbsp;&nbsp;&nbsp;土寄せが雑草管理を兼ねるという点は、長ネギ栽培の効率的な面です。溝の土をかき寄せて株元に盛る過程で、その場所の幼い雑草が一緒に埋まったり、根ごと切れたりします。一回の作業で、軟白部をつくり、肥料を埋め、雑草をなくす、三つの仕事を同時にこなします。

&nbsp;&nbsp;&nbsp;長ネギが雑草に弱いという点も、知っておく価値があります。葉が細く上にだけ立って地面を覆えないので、その間の空いた地面に日光がそのまま入ります。スベリヒユのように地面をはう草が入ってくると、あっという間に覆われてしまいます。初期の一、二か月の草取りを怠ると、その後は手のつけようがなくなります。

## 9. 病害虫 - 農薬に頼らない防ぎ方

### 9-1. 主な病害

| 病名 | 症状 | 条件 | 農薬を使わない対応 |
|---|---|---|---|
| べと病 | 葉に灰色のカビと黄色い筋が出て、葉が折れます | 低温多湿、春と秋 | 排水と通風の確保。病気の葉を取り除きます |
| さび病 | 葉にオレンジ色の粉を吹いた斑点が出ます | 韓国の梅雨（チャンマ、6月下旬～7月）、窒素過多 | 病気の葉を畑の外へ持ち出します。カリウムを補います |
| 軟腐病 | 軟白部の中が軟らかく腐り、悪臭がします | 過湿、傷、土が葉の間に入ること | 治療不可。排水と土寄せの高さで予防します |
| 葉枯病 | 葉先から枯れ、黒い点が出ます | 通風不良 | 病気の葉を取り除き、栽植距離を広げます |
| 黒斑病 | 葉に楕円形の黒い斑点が出ます | 高温多湿 | 病気の葉を取り除きます |
| 黒腐菌核病 | 株元が腐り、黒い粒ができます | 低温多湿、連作 | その場所には何年もネギ属を植えません |

&nbsp;&nbsp;&nbsp;評価表の防除自立度Bは、ドイツの有機タマネギ実証文献六編を根拠につけられた値で、そこではべと病がネギ属の最大の制約として挙げられました。無防除の対照区の発病度が96%だったという数値は、農薬を使わなければほぼすべてが発病するという意味です。長ネギでも事情は同じです。

&nbsp;&nbsp;&nbsp;ただし、それらの文献が示した対応が薬剤ではなかったという点が重要です。抵抗性系統を使い、栽植距離を広げて風通しをよくし、排水を確保することが、そのすべてでした。薬がなくてもできることであり、この三つで発病を完全に防ぐことはできなくても、進行の速さと被害の規模を大きく減らします。

&nbsp;&nbsp;&nbsp;そして、葉物野菜と違い、長ネギでは葉が傷んでも食べられる部分が残るという点が、緩衝材になります。べと病で葉が半分傷んでも、軟白部は無事なことが多く、軟白部が長ネギの主な収穫物です。ケールで葉が傷むことがそのまますべてを失うことになるのとは違います。

### 9-2. 主な害虫

| 害虫 | 被害 | 時期 | 農薬を使わない対応 |
|---|---|---|---|
| タマネギバエ | 幼虫が株元と地下部を食害し、株が枯れます | 春、秋 | 未熟な堆肥を使いません。灰を株元にまきます |
| ネギハモグリバエ | 葉の中にトンネルを掘り、白い筋ができます | 春、秋 | 被害葉を取り除きます。防虫ネットをかければ確実です |
| シロイチモジヨトウ | 幼虫が葉をかじり、葉の中へ入り込みます | 夏から秋 | 卵塊と若齢幼虫を手で捕殺します |
| ネギアザミウマ | 葉に白い斑点ができ、銀色になります | 高温乾燥期 | 乾燥させないよう管理します。青色粘着板が役に立ちます |
| ネダニ | 地下部に付いて汁を吸い、腐敗を招きます | 過湿のとき | 排水を改善し、病気の株を取り除きます |

> **長ネギの害虫のうち、実質的に株を枯らすのはタマネギバエただ一種です。そして、その虫を呼び寄せる最大の原因は、未熟な堆肥です。**

&nbsp;&nbsp;&nbsp;化学肥料がなく堆肥に頼らなければならない災害時には、この点がとくに危険です。堆肥が貴重だと、十分に熟していないものでも使いたくなりますが、長ネギでは、それはすなわちタマネギバエを畑に呼び込むことになります。この虫の成虫は、腐りかけた有機物のにおいをかぎつけて飛んできて、その付近の土に卵を産みます。堆肥が足りないときは、量を減らしてでも、未熟なものは使わないほうがましです。

&nbsp;&nbsp;&nbsp;シロイチモジヨトウは、手で捕殺する防除がよく効くほうです。親の蛾が葉に卵を塊で産みつけるため、その塊を一つこすり落とすことが、数十匹を捕まえることになります。幼虫が育って葉の中へ入ってしまうと手が届かなくなるので、幼いうちに葉の表面に集まっている時期を逃さないことがコツです。

### 9-3. 農薬を使わない防除

| 方法 | 作り方と使い方 | 対象 |
|---|---|---|
| 排水の確保 | 畝を高くし、溝を深く掘ります | 軟腐病、べと病、ネダニ、タマネギバエ |
| 栽植距離の確保 | 株間隔を守り、密植しません | べと病、葉枯病 |
| 完熟堆肥のみ使用 | 熱が出なくなり、土のにおいがするまで腐熟させます | タマネギバエ |
| 草木灰 | ふるいにかけて、株元の周囲と葉にまきます | タマネギバエ、ナメクジ。カリウムの供給を兼ねます |
| 病気の葉の除去 | 畑の外へ持ち出して焼くか、深く埋めます | さび病、べと病、黒斑病 |
| 石けん水 | 水1Lに無香料の石けん20g | アブラムシ、ダニ |
| ニンニク希釈液 | ニンニク100gを水1Lですりおろし、こして使います | 害虫忌避 |
| シナモン抽出液 | シナモン50gを水1Lに浸出して使います | 害虫忌避、カビの抑制 |
| 木酢液 | 300-500倍に薄めて散布します | 予防目的 |
| ボルドー液 | 硫酸銅と生石灰でつくります | べと病、さび病。材料があるときだけ |
| 防虫ネット | 春と秋にかけます | タマネギバエ成虫、ネギハモグリバエ |

&nbsp;&nbsp;&nbsp;ここに、長ネギ特有の障害が一つあります。長ネギの葉の表面のロウ質の層のために、液体の防除資材がうまく付着せず、そのまま流れ落ちてしまうのです。石けん水や木酢液をまいても、葉に残らなければ効果がありません。この問題を解決する方法が石けんです。石けんは、それ自体がアブラムシに作用するだけでなく、液体の表面張力を下げて葉に広げる展着剤の役割を果たします。ニンニク希釈液や木酢液を使うときに、石けんをごく少量混ぜると、葉に付着して残ります。

&nbsp;&nbsp;&nbsp;草木灰が長ネギ畑でとくに役立つことも、改めて指摘しておきます。株元の周囲にまくと、表面が乾いてアルカリ性になり、タマネギバエの産卵が減ると同時に、カリウムが供給されて耐病性と耐寒性が高まります。土寄せの前に溝にまいて土で覆えば、地下部の殺菌と施肥の二つの働きを一度に果たします。

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然素材でできる対処 |
|---|---|---|
| 葉全体が淡い緑色で短く、軟白部が細い | 窒素不足 | 尿の8-10倍希釈液を土寄せの前に溝に注ぎ、土で覆います |
| 葉が異常に大きくやわらかく、倒れやすい | 窒素過多 | 肥料を止めます。さび病と軟腐病に弱くなっている状態です |
| 古い葉の先から茶色く焼けていく | カリウム不足 | 草木灰を1㎡に一、二握りまきます |
| 生育が遅く、葉の色が濃い青緑で紫がかる | リン不足 | 骨粉と草木灰を入れます。低温期にも同じ症状が出ます |
| 新しい葉がねじれ、先が枯れる | カルシウム不足 | 貝殻と卵の殻を焼いて砕き、入れます |
| 葉脈の間が黄色くなり、葉脈だけ緑色に残る | マグネシウム不足 | 草木灰にマグネシウムが含まれています |
| 軟白部が太らず、葉だけが長くなる | 土寄せ不足または光不足 | 栄養の問題ではありません。土寄せと場所を点検します |
| さび病がとくにひどい | 窒素過多、カリウム不足 | 窒素を減らし、草木灰を入れます |

&nbsp;&nbsp;&nbsp;最後の二行が、長ネギ特有の項目です。七行目は、欠乏症状と誤解しやすい最たるものです。軟白部が細くて葉だけが長い場合、たいていは肥料の問題ではなく、土寄せを十分にしなかったか、密植して光が足りないかのどちらかです。このとき窒素をさらに入れると、葉だけがもっと長くなり、組織が軟弱になって病気に弱くなります。原因を取り違えると、損害が二倍になります。

&nbsp;&nbsp;&nbsp;八行目は、病気と栄養のつながりを示しています。窒素が過剰だと細胞壁が薄くなり、組織が軟弱になって、その状態でさび病と軟腐病が急激に増えます。カリウムは反対に、細胞壁を厚くし、組織を硬くします。ですから、長ネギ畑で病気がひどいときは、薬を探す前に、まず肥料のバランスを見るべきです。窒素だけを入れてカリウムを入れなかった畑で、病気がとりわけひどく出ることがよくあります。

&nbsp;&nbsp;&nbsp;四行目のリン不足の症状が、低温期の症状と区別できないという点にも触れておきます。早春で地温が低いときは、土にリンが十分にあっても根が吸収できず、葉が紫色を帯びます。気温が上がれば自然に回復するので、韓国の3月と4月に見られる紫色は、たいてい待てばよいものです。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 作物 | 理由 |
|:---:|---|---|
| 良い | ニンジン | ニンジンのにおいがハエ類を遠ざけ、長ネギのにおいがニンジンサビバエを遠ざけます |
| 良い | トマト、ナス、トウガラシ | ネギ属の根の分泌物が萎凋病と疫病を抑えます |
| 良い | イチゴ | 根腐れを減らすという観察が長く受け継がれてきました |
| 良い | サンチュ（リーフレタス）、ホウレンソウ | 畝間の空いた空間を使い、互いに競合しません |
| 悪い | マメ科作物（ダイズ、エンドウ、インゲンマメ） | ネギ属の分泌物が根粒菌を抑えます |
| 悪い | 同じネギ属（ニラ、ニンニク、タマネギ） | 病原菌と害虫が一緒に蓄積します |

&nbsp;&nbsp;&nbsp;一行目のニンジンと長ネギの組み合わせは、互いが互いを守る珍しい例です。ニンジンにつくニンジンサビバエは、ニンジンのにおいをかぎつけてやって来ますが、ネギのにおいに邪魔され、長ネギにつくタマネギバエは、ネギのにおいをかぎつけて来ますが、ニンジンのにおいに邪魔されます。二つの作物を列ごとに交互に植えれば、双方とも被害が減ります。農薬を使わない防除のなかでもっとも効率のよい方式であり、畑の面積を余分に使うこともありません。

&nbsp;&nbsp;&nbsp;五行目は、必ず守るべき禁忌です。ネギ属の植物が出す硫黄化合物は、病原菌だけでなく、マメ科作物の根に住む根粒菌にも影響を与えます。マメが自ら窒素をつくる能力はこの細菌に由来するため、長ネギのそばに植えたマメは根粒がうまくできず、窒素固定が減ります。化学肥料がない状況では、マメの窒素固定は畑全体の地力を維持する柱なので、この組み合わせを避けることは、単なる相性の問題ではありません。

&nbsp;&nbsp;&nbsp;ただし、時間をおいて前後に配置するのは別です。マメを収穫して残渣をすき込んだ後、その場所に長ネギを植えれば、長ネギがその窒素を受け取ります。問題なのは同じ時期に並べて植えることであり、順番につなぐのはむしろ有益です。

### 11-2. 輪作

&nbsp;&nbsp;&nbsp;評価表の連作適応性はSで、その根拠はネギ属が連作無害群であるという点です。同じ場所に続けて植えても大きな被害がなく、むしろネギ属がいた場所は土壌病害の密度が下がり、次の作物に有利です。

| 状況 | 対応 |
|---|---|
| 通常の連作 | 同じ場所に続けて植えても差し支えありません |
| 黒腐菌核病が出た場所 | 何年もネギ属を植えません |
| タマネギバエの被害がひどかった場所 | 一年休ませ、堆肥の管理を改めます |
| 長ネギを収穫し終えた場所 | 土壌病害が減っているので、次の作物に有利です |

&nbsp;&nbsp;&nbsp;輪作の順序の一例は、長ネギを収穫した場所にマメ科作物を植えて窒素を回復させ、その次に葉物野菜や果菜類を入れ、その後でまた長ネギに戻る流れです。この順序では、長ネギが土を整える役割を果たし、マメが窒素を補う役割を果たし、果菜類がその成果を使います。

&nbsp;&nbsp;&nbsp;ただし、ネギ属が連作無害群であるという事実が災害時に持つ意味は、別にとりあげておくに値します。畑が狭く、輪作表を組む余裕がないとき、一区画を決めて長ネギを植え続けてよい作物は、まれです。計画が崩れた状況でも、ただ植えればよい作物があるということ自体が、安全装置です。

### 11-3. 場所の配置の実際

| 基準 | 内容 |
|---|---|
| 水がたまらない場所 | もっとも優先する条件です |
| 土層が深く、石が少ない場所 | 土寄せをするには、土が十分に必要です |
| 畝間を広く使える場所 | 土寄せ用の土を横から持ってきます |
| 冬に雪が積もりにくく、近づきやすい場所 | 冬のあいだずっと、抜いて使う場所です |
| ニンジンや果菜類の畝のそば | 間作の効果を兼ねます |

&nbsp;&nbsp;&nbsp;四行目が、長ネギにだけある基準です。長ネギは冬にも畑に立っており、その時期がもっとも肝心なので、雪が深く積もったり道が凍ったりして近づきにくい場所に置くと、肝心な季節に使えません。家から近く、日当たりがよくて雪が早く溶ける場所が、冬用の長ネギに向いています。
