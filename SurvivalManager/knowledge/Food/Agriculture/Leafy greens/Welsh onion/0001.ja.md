## はじめに
&nbsp;&nbsp;&nbsp;長ネギ(Allium fistulosum)はヒガンバナ科ネギ属の二年草ですが、花が咲く前に収穫し、土を寄せて白い部分を伸ばし、脇から分かれた子株を切り分けて植え直すという人の手の介入によって、畑で2-4年続きます(永続性S)。総合等級はC(44.2点、有効183種中68位)で、短期C(44.0)より長期B(44.4)が高く、副食はSS(61.0点)です。最大の弱みは収穫速度Dで、播種から収穫まで200日以上かかり、災害が始まってから植えてもその年に得られるものがありません。その代わり、氷点下10℃まで畑に立てたまま冬を越し、必要なときに一本ずつ抜いて使えるうえ、タンパク質密度SSと微量栄養素A(15種)をそなえた立派な野菜です。そのほかの弱みは施肥C(1㎡に30g)、湿害、種子の寿命D(常温で1年未満)です。長ネギはあらかじめ植えておき、分げつした株を分けて植え継いでいく作物です。

## 1. 災害への備えの評価
| 区分 | 等級 | スコア |
|:---|:---:|:---:|
| 総合 | C | 44.2 |
| 短期 | C | 44.0 |
| 長期 | B | 44.4 |
| 副食 | SS | 61.0 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: タンパク質密度、施設の負担、調理・加工の要求度、温度幅、国内での栽培の普及度。S: 永続性、耐寒性、連作への適応性。A: 微量栄養素、整地・掘削エネルギー、収量の安定性、自家採種。B: 水の消費量、日射、病害虫圧、防除の自立度 |
| 弱み | D: 収穫速度、貯蔵性、非食用の価値、味、種子の寿命。C: 面積当たりの熱量、施肥、合成資材を投入しない場合の収量維持率 |

> **長ネギは、災害が始まってから植えてその年に食べられる作物ではありません。災害への備えにおける長ネギの価値は、すでに畑に立っているときにだけ成り立ちます。**

&nbsp;&nbsp;&nbsp;ニラより総合点が8点低いのはほぼ収穫速度D(200日)によるもので、スベリヒユやヨウサイの30日に比べると7倍です。貯蔵性Dは同じ属のFAO貯蔵損失率6.50%のため一段階下がった値で、無電力の常温で1か月というのはケールの1週間よりはるかに長いです。整地・掘削エネルギーAは熱量回収倍率43.0倍で、連作への適応性Sはネギ属が連作の害が出にくい群であることに基づきます。味Dは匂いと香りに抵抗があるという判定で、香りを添える使い方は含まれていません。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | ヒガンバナ科ネギ属の二年草。学名のfistulosumは中空の管という意味で、平たくて中が詰まった葉のニラと区別される。原産地は中国西部からシベリアの寒冷な内陸 |
| 葉、軟白部 | 葉は中空の円筒形で、表面の白いろう質の層で水がはじかれる。軟白部は葉鞘が幾重にも重なった白い部分で、本当の茎ではなく、本当の茎は一番下の平たい円盤。タマネギと違って鱗茎を太らせず、葉鞘を積み上げる |
| 根、花 | 白いひげ根が深さ20-30cmに集まる。花は白から淡い紫の球状で、2年目の春に咲く |

> **土で覆った部分は光を受けられず、葉緑素をつくらず白いまま残ります。軟白部の長さは植物自身が決めるのではなく、人がどれだけ土を寄せたかが決めます。**

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 育苗期 | 播種後40-60日 | 糸のような葉が1枚、曲がったまま出て、本葉が増える |
| 栄養成長期、収穫適期 | 定植後1-6か月 | 葉が増え、軟白部が長く、太く、硬くなる |
| とう立ち、結実 | 2年目の春 | 花茎が立ち、種ができる |

&nbsp;&nbsp;&nbsp;とう立ちは、苗が鉛筆の太さ(直径6-7mm)以上に育った状態で13℃以下の低温に一定期間あうと起こり、花茎が軟白部の真ん中を貫いて食べられなくなります。100g当たり熱量23-34kcal、タンパク質1.78g(熱量比31.0%)、炭水化物5-7g、糖類2.63g、カリウム181mgで、ビタミンAとKは緑の葉に集中しているため、葉を捨てると栄養上の損です。硫黄化合物は組織が傷つくときに生じ、においと抗菌作用と辛みのもとになり、熱に弱いので、加熱すると甘みが出ます。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽適温は20℃前後、生育適温は20℃前後で、25℃以上になると生育が遅くなり病気が増える。氷点下10℃まで露地で越冬し、枯れた外葉は内側を守るので、冬は取り除かない。中部以北や寒い年には土寄せとわらで覆う |
| 光 | 40%遮光でも収量の86%を維持。光が足りないと葉が垂れ、組織が軟らかくなって倒れやすい |
| 水、土壌 | 土が深く水はけのよい土地、pH5.7-7.4。総蒸発散量は約550mmで、乾燥には比較的強い |

> **長ネギ栽培を丸ごと失う原因は、ほとんどいつも水がたまることです。梅雨に数日冠水した畑では、育ちきった長ネギが根元から軟らかくなって倒れます。**

| 系統 | 特徴 |
|:---|:---|
| 一本ネギ(茎ネギ) | 分げつせず、軟白部が長くて太く、土寄せが必須。1本の体積が大きく貯蔵効率はよいが、抜けばそれで終わりなので毎年種が必要 |
| 葉ネギ(分げつネギ) | 8-10本以上に分げつし、軟白部は短くて細く、土寄せは不要。株を分けて種なしで継ぎ、土が浅い土地や小石の多い土地に向く |
| 朝鮮ネギ(在来種) | 分げつと軟白部が中間で、越冬が確実で、その地域の気候に適応しているため、中部以北に向く |

&nbsp;&nbsp;&nbsp;種の供給を期待できないなら葉ネギと朝鮮ネギを、冬の貯蔵資源が目的なら一本ネギを選び、現実的には両方の系統を一緒に置きます。実質的な自立の手段は種ではなく分げつした株なので、F1か固定種かより、分げつの程度のほうが重要です。

## 4. 畑の準備、播種、定植
| 項目 | 基準 |
|:---|:---|
| 畑づくり | 20-30cmの深さに耕し、石を取り除く。畝間は一本ネギ75-85cm、葉ネギ1.5mと広くとって土寄せ用の土を確保し、深さ15-20cmの溝を掘ってその底に植える |
| 施肥(1,000㎡) | 窒素は尿素25kg相当、リン酸はようりん6.6kg相当(全量元肥)、カリウムは塩化カリ14kg相当、完熟堆肥1,500kg。追肥は定植後1か月ごとに3回、土寄せとともに行い、肥料を先に溝に入れてから土を後で寄せる |
| 代替資源 | 尿を8-10倍に薄めた液(土寄せ前に溝に注いで土をかぶせる)、完熟堆肥(未熟なものはタマネギバエを呼ぶ)、木灰(土寄せ前に溝に一、二つかみ)、発酵させた油かす |

| 作型 | 播種 | 定植 | 収穫 |
|:---|:---|:---|:---|
| 春まき | 3月初め-4月末 | 5月初め-6月末 | 9月中旬-翌年4月末 |
| 秋まき | 8月末-9月末 | 10月初め-11月末 | 翌年4月中旬-5月末 |

> **秋まきでは播種時期を守ることが特に重要です。早くまきすぎて冬の前に苗が鉛筆の太さを超えると、低温にあって花芽分化が起こり、翌年の春に花茎だけが立ちます。**

| 段階 | 方法 |
|:---|:---|
| 育苗 | 苗床にばらまきするか10cm間隔の条まき、深さ5-6mm。20℃で7-10日で発芽し、40-60日育て、表土が乾かないようにする。浮く種は取り除き、50℃前後の温湯に浸すが、60℃を超えると死ぬ |
| 定植 | 本葉4-5枚、茎の太さ5-7mmのとき(細いと植え替えに耐えられず、太いととう立ちの危険)。株間は一本ネギ7-12cm、葉ネギ12-15cmで2-3本ずつ、根だけが埋まる程度(約3cm)に溝の底に斜めに寝かせて植え、土を押さえて水をやる |

&nbsp;&nbsp;&nbsp;深く埋めないのは、成長点が底の円盤のすぐ上にあり、深く埋めると新しい葉が苦労するか腐るためで、軟白部は育つあいだに少しずつ土をかけてつくります。

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から育苗期 | 発芽まで表土が乾かないように毎日、育苗期は2-3日に1回 |
| 定植直後 | 週2回たっぷり |
| 活着後の生育期 | 週1回、一度に深く(浅くて頻繁な水やりは根を浅くする)、土寄せの直後にも1回 |
| 越冬期 | やらない(濡れた土が凍ると軟白部が傷む) |

&nbsp;&nbsp;&nbsp;長ネギは乾燥すると成長が遅くなるだけで簡単には枯れないので、水を節約しなければならないときは灌水の優先順位を後ろに回せます。

| 土寄せ | 時期 | 高さ | 備考 |
|:---|:---|:---|:---|
| 1回目 | 定植後1か月 | 5-6cm | 肥料を溝に入れ、その上に土を寄せる |
| 2回目 | 1回目の1か月後 | 10cm | 同じ |
| 3回目 | 2回目の1か月後 | 葉が分かれる部分が10cmほど埋まる程度 | 同じ |
| 仕上げ | 収穫の3-4週間前、越冬前(10月下旬) | 必要に応じて | 冬の断熱を兼ねる |

> **軟白部の長さと太さは、種が決めるのではなく、人が土を何回、どれだけ寄せたかが決めます。一度も土寄せをしない一本ネギは小ネギに近いです。**

&nbsp;&nbsp;&nbsp;最も重要な基準線は葉が分かれる地点で、そこを覆うと葉鞘のあいだに土と水が染み込んで軟腐病が始まります。そのため、長ネギが育つ速さに合わせて3回に分けて寄せ、晴天が続いてさらさらに乾いた土を使います(濡れた土は固まって空気が通らない)。土寄せは、軟白部をつくり、肥料を埋め、雑草を取り除くことを一度に行い、葉が細くて地面を覆えない長ネギは雑草に弱いので、最初の1、2か月の草取りを怠りません。

| 管理 | 方法 |
|:---|:---|
| 株分け | 早春(3-4月)か秋(9-10月)に、根元から何本も分かれた株を丸ごと掘り上げ、1本ずつ、または2、3本ずつに分ける。葉を半分ほど切り、長い根の先を整えて(水分のバランス)、新しい溝に定植と同じ方法で植える。1株が8本に分かれたら、半分は食べ、半分は植え直して、種なしで続く |
| 越冬管理 | 最後の土寄せを10月下旬に終え、12-2月にわらや落ち葉を5-10cm覆う(特に中部以北) |

## 6. 病害虫と養分の問題
&nbsp;&nbsp;&nbsp;防除の自立度Bはドイツの有機タマネギの実証文献6編に基づき、そこでべと病がネギ属の最大の制約で、無防除の対照区の発病程度は96%でした。対応は抵抗性系統、広い株間、排水の確保で、葉が傷んでも主な収穫物である軟白部が残るため緩衝になります。葉のろう質の層で液体の防除剤が流れ落ちるので、石けん(水1Lに無香料の石けん20g)をごく少し混ぜて展着剤として使います。

| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| べと病、さび病、葉枯病、黒斑病 | 灰色のかびと黄色い筋(低温多湿) / オレンジ色の粉状の斑点(梅雨、窒素過多) / 黒い斑点(風通し不良、高温多湿) | 排水と風通し、株間の確保、病葉は畑の外に出して焼くか埋める、カリウムの補給 |
| 軟腐病 | 軟白部の内部が軟らかくなり悪臭。過湿、傷、葉の間に土が入ったとき | 治療不可。排水と土寄せの高さで予防 |
| 黒腐菌核病 | 根元が腐り、黒い粒ができる。低温多湿、連作 | その場所には数年ネギ属を植えない |
| タマネギバエ | 幼虫が根元と地下部を食べて株が枯れる。未熟な堆肥が原因 | 完熟堆肥だけを使い、木灰を根元にまく、防虫ネット |
| ヨトウムシ、アザミウマ | 葉をかじる / 葉に白い斑点(高温乾燥) | 卵塊と若い幼虫を手で取る / 乾燥させないように管理 |

&nbsp;&nbsp;&nbsp;軟腐病は軟白部の内側で進行して外からは見えないので、外葉が黄色くなり茎が傾いたときにはすでに手遅れです。

| 症状 | 原因と対処 |
|:---|:---|
| 葉全体が薄い緑で短く、軟白部が細い | 窒素欠乏。尿を8-10倍に薄めた液を土寄せ前に溝に注ぎ、土をかぶせる |
| 葉が異様に大きく軟らかく、倒れ、さび病がひどい | 窒素過剰、カリウム欠乏。施肥をやめ、木灰を入れる |
| 軟白部が太らず葉だけ伸びる | 土寄せ不足や密植による光不足。栄養の問題ではないので、土寄せと場所を点検 |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | ニンジン(互いのにおいがハエ類を遠ざけるので、条を交互に植える)、トマト、ナス、トウガラシ(根の分泌物が萎凋病と疫病を抑える)、レタス、ホウレンソウ(畝間を使う) |
| 悪い | マメ科作物(ダイズ、エンドウ、インゲン: ネギ属の分泌物が根粒菌を抑え、窒素固定が減る)、同じネギ属(ニラ、ニンニク、タマネギ: 病原菌と害虫がいっしょにたまる) |

&nbsp;&nbsp;&nbsp;問題はマメ科と長ネギを同じ時期に並べて植えることで、ダイズを収穫して残渣を埋めた場所に長ネギを植える順序は、むしろ有益です。連作への適応性Sは、ネギ属が連作の害が出にくい群であることによるもので、同じ場所に続けて植えてもよく、土壌病害の密度も下がります。ただし黒腐菌核病が出た場所は数年休み、タマネギバエの被害がひどかった場所は一年休んで堆肥の管理を改めます。冬にも抜いて使う場所なので、土が深く石が少なく、雪があまり積もらず近づきやすい所が向きます。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 糸ネギは定植後40-50日(細いがそのまま食べられる)、中ネギは2-3か月、長ネギは3-6か月(軟白部が太くしっかりしたとき)。冬の収穫は霜のあとから翌春まで必要なときに、期限は春に花茎が立つ前 |
| 方法 | 根ごと抜く(軟白部を丸ごと得られるが、その株は終わり) / 葉だけ切る(地面から3-4cm残す。新しい葉が出るが軟白部は得られない) / 分げつ株を分ける(一塊を掘って分け、半分だけ食べて植え直す) |
| 冬の運用 | 秋に育ちきった長ネギを抜かずに置き、必要なときに一本ずつ抜く。凍った地面は脇を崩して氷と土を割ってから持ち上げる。3月末-4月に花茎の兆しが見えたら、残りを一度に抜いて干すか漬物に回す |
| 手入れ | 土を払い、枯れて傷んだ外葉を1、2枚だけむく。すぐ使うものだけ洗い(洗うと早く傷む)、貯蔵するものは根を切らない。緑の葉は捨てずに干しておく |

> **長ネギは、いつ収穫するかではなく、いつまで置いておけるかが肝心な作物です。育ちきったあとも畑に立ったまま冬を越し、その状態がそのまま貯蔵です。**

| 採種 | 基準 |
|:---|:---|
| 障壁 | 二年草なので冬を越して2年目の春のとう立ちを待たなければならず、その株の軟白部は食べられない。他家受粉で近くの別のネギ属と混ざり、種子の寿命は1年未満 |
| 交雑の防止 | 他のネギ属の採種株と500m以上離すか、ネットをかぶせて筆で花粉を移す。小さな畑ではその年に一種類だけ花を咲かせ、残りは花茎を切り取る |
| 採り方 | 秋にいちばん太くてまっすぐで病気のない株をいくつか印をつけ、抜かずに越冬させる(土をたっぷりかぶせる)。4-5月にとう立ち、5-6月に球状の白い花。さやが茶色く乾いて一部が裂け始めたら花茎ごと刈り、逆さに吊るして下に布を敷いて受ける。水に浸けて浮く実のない種を取り除き、沈んだ種をすぐ完全に乾かす |
| 保管 | 常温で密閉して1年未満。涼しく乾いた場所の密閉容器に灰か炭と一緒に入れる。種はその年に使う分だけ採り、分げつ株をいくつかの場所に分けて植えておくのが備蓄 |

## 9. 貯蔵
&nbsp;&nbsp;&nbsp;貯蔵性はDですが、無電力の常温で1か月もち、畑に立てたままの越冬貯蔵が可能です。

| 方法 | 手順と期間 |
|:---|:---|
| 畑にそのまま | 秋から翌年のとう立ち前まで。氷点下10℃まではそのままで、それより寒ければわらをかける |
| 土に埋め直す | 2、3か月。根ごと抜いて、涼しく日陰の土に斜めに寝かせ、軟白部が埋まるように埋める(根がついているので生きたまま) |
| 涼しい所に立てておく | 2-4週間。寝かせると葉が曲がって早く傷む |
| 乾燥 | 土を払って洗い、水気を完全に切ってから、葉は3-5cm、軟白部は薄い斜め切りか輪切りにして干す。粉に砕いて塩と混ぜると調味料になる。香りの多くが飛ぶので日陰でゆっくり干し、乾ききったらすぐに密閉 |
| 漬ける | 味噌漬け(数か月)、ネギキムチ(涼しい所で1-2か月)。硫黄化合物が抗菌作用をもつため、少ない塩でも傷まない |

## 10. 調理と注意事項
| 方式 | 内容 |
|:---|:---|
| 生食 | 洗って細切りにして和えるか添える。辛みとビタミンCがそのまま残る |
| ネギ油 | 油で刻んだ長ネギを弱火でゆっくり炒めて香りを移す。ひとさじで何食分もの味をつける |
| 焼き | 丸ごと焼くと辛み成分が分解して糖が現れ、大きく甘くなる。熾火に放り込み、焦げた外皮をむく |
| チヂミ、乾燥粉 | 生地に混ぜて焼く / 保存と調味を兼ねる |

> **長ネギの調理の核心は二つに分かれます。香りを得るには最後に入れ、甘みを得るには最初から長く火を通します。同じ材料が、まったく違う二つの働きをします。**

&nbsp;&nbsp;&nbsp;ビタミンAとKは緑の葉にしかないので、葉は細かく切ってスープに入れるか、干して粉にして使います。

| 危険 | 内容 |
|:---|:---|
| 食べすぎ、空腹時の生食 | 硫黄化合物が胃粘膜を刺激して胸やけを起こす |
| 犬、猫、家畜 | ネギ属全体が赤血球を壊して貧血を起こす。牛や馬も大量に食べれば同じなので、長ネギの入った残り物は与えない |
| 似た毒草 | 野でネギ属を探すとき、スイセン、ナツズイセン類(地下部がタマネギに似る。嘔吐、腹痛)やスズラン(嘔吐、不整脈)と取り違える。切った葉ににおいがなく、葉が平たく中が詰まっている |

> **葉を一枚切ってこすり、ネギやニンニクのにおいがしなければ、ネギ属ではありません。この一つの確認が、ネギ属に似た毒草をほとんどふるい落とします。**

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 畑に立てておいた長ネギを必要なときに抜いて使い、覆いを確認 |
| 3-4月 | 3月に春まき、株分け。4月に育苗管理、越冬した長ネギは花茎が立つ前に全部収穫 |
| 5-6月 | 5月に春の定植、採種用の株は花茎をそのまま残す。6月に1回目の土寄せ(肥料を溝に入れて土を寄せる)、梅雨前の排水溝の整備 |
| 7-8月 | 7月に2回目の土寄せ、べと病とさび病の観察。8月に3回目の土寄せ、月末から秋まき、シロイチモジヨトウの卵塊の確認 |
| 9-10月 | 9月に春に植えた長ネギの収穫開始、株分け。10月に秋の定植、最後の土寄せ |
| 11-12月 | 11月にカリウム中心の越冬肥料を施す。12月にわらや落ち葉で覆い、冬の収穫区画への通路を確保 |

&nbsp;&nbsp;&nbsp;最も重要な二つの行は4月と8月です。4月に越冬した長ネギを収穫し終えなければ花茎が立ってすべて使えなくなり、8月末以降の秋まきは時期を外すと早期とう立ちで翌年の作が消えます。3月と9月の株分けは、この作物の自立、つまり種子の貯蔵です。

> **災害が始まってから植えても得られるものはありませんが、すでに畑に立っている長ネギは、冬のあいだずっと凍らない倉庫になります。長ネギはあらかじめ植えておき、分けて植え継いでいく作物です。**
