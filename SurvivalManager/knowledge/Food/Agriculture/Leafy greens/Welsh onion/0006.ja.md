## 12. 収穫 - 畑がそのまま倉庫

### 12-1. 時期の判断

| 区分 | 基準 |
|---|---|
| 小ネギ | 定植後40-50日。細いがそのまま食べられます |
| 中ネギ | 定植後2-3か月 |
| 長ネギ | 定植後3-6か月、軟白部が太くて締まったとき |
| 冬の収穫 | 霜が降りてから翌年の春まで、必要なときに随時 |
| 締め切り | 翌年の春、花茎が立つ前 |

> **長ネギは、いつ収穫するかではなく、いつまで置いておいてよいかが肝心な作物です。育ち切った後も畑に立ったまま冬を越し、その状態がそのまま貯蔵です。**

&nbsp;&nbsp;&nbsp;最後の行の締め切りの時点が重要です。2年目の春に花茎が立つと、軟白部のまん中を硬い茎が貫いて、食べられなくなります。外見は無傷に見えますが、割ってみると、中に木のような芯が通っています。畑に立てたまま使う戦略には、この春の締め切りの線がついてまわり、その線を越えると、それまでに残っていた長ネギはすべて使いものにならなくなります。

&nbsp;&nbsp;&nbsp;そのため、冬の長ネギの運用はこうなります。秋に育ち切った長ネギを抜かずに、そのまま置いておきます。冬のあいだずっと、必要なときに一本ずつ抜いて使います。韓国では翌年の3月末か4月に花茎が立ちそうな兆しが見えたら、残りを一度に抜いて乾燥させたり、塩漬けにしたりして、貯蔵に回します。この時点が、畑での貯蔵から加工による貯蔵へ移る境界線です。

### 12-2. 収穫のコツ

| 方式 | 方法 | 結果 |
|---|---|---|
| 根ごと抜く | ホミ（韓国の小型手鍬）で株元の周りの土をほぐして持ち上げます | その株は終わりです。軟白部を丸ごと得られます |
| 葉だけ切る | 地面から3-4cm残して切ります | 新しい葉がまた出ます。軟白部は得られません |
| 分げつ株を切り離す | ひと塊を掘り上げて分け、半分だけ食べます | 残りを植え直して続けます |

&nbsp;&nbsp;&nbsp;この三つは、目的によって使い分けます。太い軟白部を得たいなら根ごと抜く必要があり、そうすればその株は終わりです。収穫を続けたいなら、葉だけを切りますが、軟白部はあきらめなければなりません。分げつする系統であれば、三つ目の方式で、二つを半分ずつ得られます。

&nbsp;&nbsp;&nbsp;葉だけを切る方式で、地面から3-4cmを残すという基準は、ニラと同じ理由によります。長ネギの生長点は基部の円盤のすぐ上にあり、それを切ってしまうと、新しい葉をつくる場所がなくなります。3-4cmは、その上に安全に残す余裕分です。

&nbsp;&nbsp;&nbsp;土が凍っている冬に抜くときには、コツが必要です。そのまま引っ張ると、軟白部が途中で切れて土の中に残ります。ホミやスコップで脇を掘り崩して、氷と土を先に砕いてから持ち上げなければなりません。冬に使う長ネギは、秋のうちに一列ほどだけ浅く埋めておくか、わらを厚くかぶせておくと、この作業がずっと楽になります。

### 12-3. 収穫後の手入れ

| 項目 | 内容 |
|---|---|
| 土を落とす | 抜いた場所で振って、根の土を払い落とします |
| 外葉 | 枯れたり傷んだりした外葉を一、二枚だけむきます |
| 洗う | すぐ使うものだけを洗います。洗ったものは傷みが早いです |
| 根 | 貯蔵するものは根を切りません |
| 葉の部分 | 捨てずに別に集めて乾燥させます |

&nbsp;&nbsp;&nbsp;貯蔵する長ネギの根を切らないのには理由があります。根が付いていれば、長ネギは生きた状態を保って水分を維持し、切り口がないので、菌が入り込む入り口も減ります。根ごと土に埋め戻しておく貯蔵法が効果的なのも、同じ理由です。

&nbsp;&nbsp;&nbsp;最後の行も、災害時に見落としてはならない項目です。長ネギの緑色の葉の部分は普段は捨てられることが多いのですが、微量栄養素Aという等級をつくった15種のかなりの数が、この部分にあります。ビタミンAとビタミンKは軟白部にほとんどなく、緑色の葉に集中しています。刻んで乾燥させておけば、冬の汁物の具や粉末の調味料になります。

## 13. 採種 - 2年目の抽だいを待つ

### 13-1. 二つの障壁

&nbsp;&nbsp;&nbsp;評価表では、自家採種がA、種子寿命がDです。種を採ることはできますが、二つの障壁があります。

| 障壁 | 内容 |
|---|---|
| 二年草 | 種を採るには冬を越して、2年目の春の抽だいを待たなければなりません |
| 他家受粉 | ハチが花粉を運ぶため、近くの別のネギ属と交雑します |
| 種子が短命 | 採った種は1年以内に使わなければなりません |

&nbsp;&nbsp;&nbsp;一つ目の障壁は、時間の問題です。食べる長ネギを収穫することと、種を採ることは、同じ株では両立しません。種を採る株は、秋に抜かずに冬を越させ、翌年の春に花茎を立てさせなければならず、その株の軟白部は食べられなくなります。採種は、食べるものをあきらめて得るものです。

&nbsp;&nbsp;&nbsp;二つ目の障壁のほうが厄介です。長ネギは自分の花粉ではうまく受精せず、ほかの株の花粉を受けます。そのため、近くで別のネギ属が花を咲かせていると、ハチがその花粉を運んできます。ニラと同じ時期に花が咲くわけではありませんが、チョクパ（ワケギ）やタマネギ、別系統の長ネギが一緒にあると、交雑します。

| 隔離方法 | 内容 | 確実性 |
|---|---|---|
| 距離隔離 | 別のネギ属の採種株と500m以上離します | 高いが、現実的には難しい |
| 時期隔離 | 開花時期が重ならないよう、植える時期を調整します | 中程度 |
| ネット掛け | 花のつぼみが開く前にネットをかけます | 高いです。その代わり、人が筆で花粉を移さなければなりません |
| 一系統のみ採種 | その年は一種類だけ花を咲かせます | もっとも現実的です |

> **小さな畑でもっとも現実的な方法は、その年に種を採るネギ属を一つに決め、残りはすべて花茎を切り取ってしまうことです。**

### 13-2. 種の採り方

| 段階 | 内容 |
|---|---|
| 採種株の選定 | 秋に、もっとも太くてまっすぐで病気のない株をいくつか決めて印をつけます |
| 越冬 | 抜かずにそのまま冬を越させます。土を十分にかぶせます |
| 抽だい | 韓国では翌年の4月から5月に花茎が立ちます |
| 開花 | 5月から6月、球状に白い花が咲きます |
| 成熟の判断 | 花が終わり、蒴果が茶色く乾いて、黒い種が見えるとき |
| 収穫 | 花茎ごと切り、紙や布の上で逆さにつるします |
| 分離 | 乾いた花茎を手でもんで種を落とします |
| 選別 | 水に浸けて、浮いたものを取り除きます。沈むものが充実した種です |
| 乾燥 | 日陰で完全に乾かします |
| 保管 | 密閉容器に草木灰や炭と一緒に入れ、涼しく暗い場所に置きます |

&nbsp;&nbsp;&nbsp;水に浸けて選別する方法は、長ネギの種でとくに有用です。中身のないしいなは浮き、胚が無傷の種は沈みます。種子寿命が短い作物なので、発芽率を少しでも上げておくことには価値があります。ただし、水に浸けた種はすぐに完全に乾かさなければならず、濡れたままにしておくと、そのまま使えなくなります。

&nbsp;&nbsp;&nbsp;蒴果は乾くと自然に開いて種が落ちるので、時期を逃すと地面にこぼれてしまいます。蒴果が茶色くなり、いくつかが開き始めたころに花茎ごと刈り取って逆さにつるしておくのが安全で、下に布を敷いておけば、乾きながら落ちる種をそのまま受け止められます。

### 13-3. 保管と寿命

| 条件 | 発芽力の維持 |
|---|---|
| 常温で密閉 | 1年未満 |
| 涼しく乾燥した場所 | 1-2年 |
| 湿気の多い、または暑い場所 | 数か月で急激に低下します |

&nbsp;&nbsp;&nbsp;ネギ属の種が際立って短命な理由は、種に含まれる脂肪分が酸化しやすいためだと知られています。低い温度と低い湿度が酸化を遅らせるので、涼しく乾いた場所に置き、密閉容器に草木灰や炭を一緒に入れて湿気を取ります。

&nbsp;&nbsp;&nbsp;実用的な結論は、ニラと同じです。長ネギの種子の倉庫は、袋ではなく畑です。種を集めておく代わりに、分げつ株を生かして、いくつかの場所に分けて植えておくことが、この作物における備蓄です。種は、その年のうちに使う分だけ採ります。

## 14. 毒性と注意すべき成分

### 14-1. 長ネギ自体の安全性

&nbsp;&nbsp;&nbsp;長ネギは、通常の摂取量であれば安全な食品です。生で食べても、加熱して食べてもかまいません。ただし、三つのことは知っておくとよいでしょう。

| 項目 | 内容 |
|---|---|
| 過剰摂取 | 硫黄化合物が胃粘膜を刺激し、胸やけが起こることがあります |
| 空腹時の生食 | 空腹時に生の長ネギをたくさん食べると、刺激がより強くなります |
| 犬と猫 | ネギ属全体がペットと一部の家畜に有毒です |

&nbsp;&nbsp;&nbsp;三行目が、災害時に実際に注意すべき事項です。長ネギ、ニラ、ニンニク、タマネギをはじめとするネギ属の植物は、犬と猫の赤血球を破壊して貧血を起こします。人には何の問題もない成分が、これらの動物には毒になります。残り物を家畜や犬に与えることが普通になる状況では、長ネギが入った食べ物は、その対象から外さなければなりません。牛や馬も、大量に食べれば同じ種類の貧血を起こすことがあります。

### 14-2. 似た毒草 - においで見分ける

&nbsp;&nbsp;&nbsp;畑ではなく野原でネギ属の植物を探すときには、危険な場合があります。ネギに似た毒草が実際に存在し、毎年、中毒事故が報告されています。

| 区分 | ネギ属（長ネギ、ニラ、ノビル） | スイセン・ナツズイセン類 | スズラン |
|---|---|---|---|
| 切った葉のにおい | ネギやニンニクのにおいが必ずします | においがありません | においがありません |
| 葉の断面 | 長ネギは中空の円筒です | 平たく中が詰まっています | 平たく中が詰まっています |
| 葉の質感 | やわらかく汁気が多い | 厚くてなめらか | 厚くてこわばり、つやがあります |
| 地下部 | 鱗茎または平たい円盤 | 丸い鱗茎（タマネギ型） | 細い根茎 |
| 食べたとき | 食用 | ひどい嘔吐と腹痛、下痢 | 嘔吐、めまい、心拍の異常 |

> **葉を一枚切ってこすり、ネギやニンニクのにおいがしなければ、ネギ属ではありません。この一つの確認で、ネギ属に似た毒草のほとんどを除外できます。**

&nbsp;&nbsp;&nbsp;スイセンやナツズイセンの仲間がとくに危険な理由は、地下部がタマネギに似ているからです。庭や古い花壇で球根を掘っていて、タマネギやネギの根と取り違える事故が繰り返されてきました。葉を見るだけでも区別がつきます。長ネギの葉は中空の円筒なので、指で押すとぐにゃりとへこみ、スイセンの葉は平たい帯状なので、押してもそのままです。

&nbsp;&nbsp;&nbsp;スズランは心臓に作用する成分を持ち、少量でも危険です。葉が幅広いため、長ネギと取り違えることは少ないのですが、ギョウジャニンニクを摘むときに混ざる事故が多く起きています。ネギ属の植物を野生で探すときは、いつもまずにおいを確認します。

&nbsp;&nbsp;&nbsp;畑で育てた長ネギには、この危険はありません。ただし、長ネギ畑の近くにスイセンを植えていた場合、春に若い葉が混ざることがあるので、ネギ属の場所の近くにそのような植物を置かないことが、簡単な予防になります。

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;評価表の貯蔵性はDですが、無電力の常温で一か月という値と、畑に立てたまま越冬貯蔵ができるという但し書きがついています。葉菜類としては非常に良い条件であり、この文書が扱う四つの作物のなかで、貯蔵の面でもっとも優れているのが長ネギです。

### 15-1. 畑が貯蔵庫

| 方法 | 期間 | 条件 |
|---|---|---|
| 抜かずに畑に置く | 秋から翌年の春、抽だい前まで | 氷点下10℃まではそのまま。それより寒ければわらをかぶせます |
| 土に埋め戻す | 二、三か月 | 根ごと抜いて、涼しい場所の土に斜めに埋めます |
| 室貯蔵 | 二、三か月 | 地面を掘り、土と交互に重ねてから、わらで覆います |
| 涼しい場所に立てておく | 2-4週間 | 寝かせると葉が曲がって、傷みが早くなります |

&nbsp;&nbsp;&nbsp;二行目の埋め戻す方式が実用的です。春に抽だいが始まる前に、残った長ネギを一度に抜かなければならないとき、それを涼しい日陰の土に斜めに寝かせ、軟白部が覆われるように埋めておきます。根が付いているので長ネギは生きた状態を保ち、土が温度と湿度を一定に保ってくれます。キムジャン（越冬用キムチ漬け）に使うダイコンを地面に埋めるのと同じ原理です。

&nbsp;&nbsp;&nbsp;四行目の「立てておく」というコツは、長ネギとニラに共通する性質から来ています。寝かせておくと、葉が上へ曲がろうとして、その力にエネルギーを使い、組織が早く崩れます。立てておけばこの反応が起こらないので、数日から一、二週間ほど長くもたせられます。

### 15-2. 乾燥

| 段階 | 内容 |
|---|---|
| 下処理 | 土を払い、洗った後、水気を完全に切ります |
| 切る | 葉は3-5cm、軟白部は薄く斜め切りにするか、輪切りにします |
| 広げる | 日陰の風通しのよい場所。日光で乾かすと色と香りが飛びます |
| 仕上がりの判断 | 手でもんだときにぱりぱりと砕けるまで |
| 粉にする | 完全に乾いたものを臼でつきます |
| 保管 | 密閉容器に草木灰や炭と一緒に入れます |
| 期間 | よく乾いて密閉されたものは、半年から一年 |

&nbsp;&nbsp;&nbsp;長ネギを粉にしておく方式は、災害時にとくに価値があります。体積が大きく減って保管場所をほとんど取らず、汁物やお粥にひとさじ入れれば香りが立ちます。塩と混ぜておけば、調味料の一つになります。調味料がなくなった状況では、乾燥した長ネギの粉がひと容器あれば、食卓を耐えられるものにする資源になります。

&nbsp;&nbsp;&nbsp;ただし、乾燥の過程で香りの相当な部分が飛んでしまうことは知っておいてください。においのもとである硫黄化合物が揮発性だからです。日陰でゆっくり乾かせば損失が少し減り、乾ききった後すぐに密閉すれば、残った香りを守れます。

### 15-3. 漬物と発酵

| 方法 | 手順 | 期間 |
|---|---|---|
| 塩漬け | 重量の5-10%の塩で、層にして漬け込みます | 3-6か月 |
| チャンジ（塩漬け） | 10%以上の濃い塩水に沈むように漬けます | 半年以上。食べる前に水に浸けて塩気を抜きます |
| チャンアチ（醤油漬け） | 醤油に漬けます | 数か月 |
| テンジャン（韓国味噌）漬け | 軟白部をテンジャンに漬け込みます | 数か月 |
| パキムチ（ネギのキムチ） | 塩漬けにしてから和えます | 涼しい場所で1-2か月 |

&nbsp;&nbsp;&nbsp;長ネギが漬物に向いている理由は、硫黄化合物そのものが抗菌作用を持つからです。ほかの野菜より少ない塩でも傷まず、塩が貴重な状況では、この差は小さくありません。そして、漬けた長ネギは辛味が抜けて甘みとうま味が立ち上がり、生のものとはまったく別のおかずになります。

## 16. 調理と加工

| 方法 | 燃料 | 手順 | 備考 |
|---|:---:|---|---|
| 生食 | 0 | 洗って細切りにし、和えたり添えたりします | 辛味とビタミンCがそのまま残ります |
| コッチョリ（浅漬け風の和え物） | 0 | 塩に短時間漬けてから和えます | 燃料なしでおかずが一品できます |
| 汁物とチゲ（鍋料理） | 中程度 | 火を止める直前に入れます | 長く煮ると香りが消えます |
| ネギ油 | 少ない | 油でゆっくり炒めて香りを移します | 少量の油で何食分もの味付けができます |
| 焼き | 少ない | 丸ごと火で焼きます | 甘みが大きく引き立ちます |
| ジョン（チヂミ風のお焼き） | 中程度 | 生地に混ぜて焼きます | 少量で一食になります |
| 乾燥粉末 | 0 | 第15節を参照 | 保存と調味料を兼ねます |

&nbsp;&nbsp;&nbsp;評価表で調理・加工がSSなのは、洗えばすぐ食べられるという意味です。ただし、長ネギの価値は、単独で食べるときではなく、ほかの食材に香りを添えるときに現れます。味の等級がDと低くつけられたのは、長ネギそのものを評価した結果であり、その使い方まで含めた値ではありません。

> **長ネギの調理の要点は二つに分かれます。香りを得たいなら最後に入れ、甘みを得たいなら最初から長く火を通します。同じ食材が、二つのまったく異なる働きをします。**

&nbsp;&nbsp;&nbsp;四行目のネギ油は、燃料が貴重な状況でとくに役立ちます。油を少しひいて、切った長ネギを弱火でゆっくり炒めると、長ネギの香り成分が油に移ります。この油ひとさじで、味気ない穀物料理の何食分もに味をつけられます。一度火を使って何食分もの味を確保する方式であり、炒めた後に残った長ネギの具もそのまま食べます。

&nbsp;&nbsp;&nbsp;五行目の焼きも知っておく価値があります。長ネギの軟白部を丸ごと火で焼くと、辛味のもとになる成分が分解され、中にあった糖が現れて、かなり甘くなります。熾火に放り込んでおいて、表面の焦げた皮をむくと、中がやわらかく火が通っています。調理器具がなく、火だけがあるときに使える方法です。

&nbsp;&nbsp;&nbsp;ここに抗菌作用が加わります。冷蔵がない状況では、調理した食べ物は数時間で傷み始めますが、長ネギが入った食べ物は、その速度が少し遅くなります。夏場に残り物を次の食事まで持ち越さなければならないとき、この差が実質的な意味を持ちます。

&nbsp;&nbsp;&nbsp;最後に、緑色の葉を捨てないという問題を、改めて指摘しておきます。ビタミンAとビタミンKは緑色の葉にしかなく、白い軟白部にはほとんどありません。葉が硬くてそのまま食べにくければ、細かく刻んで汁物に入れるか、乾燥させて粉にすればよいのです。微量栄養素Aという等級の半分は、その捨てられていた部分にあります。

## 17. 年間作業スケジュール

| 月（韓国） | 作業 |
|---|---|
| 1-2月 | 畑に立てておいた長ネギを必要なときに抜いて使います。覆いを確認します |
| 3月 | 春まき（3月初めから4月末）。秋に植えた長ネギは引き続き収穫します。分げつ株の株分け |
| 4月 | 育苗管理。冬を越した長ネギは、花茎が立つ前にすべて収穫します |
| 5月 | 春の定植（5月初めから6月末）。採種用の株は花茎をそのまま残します |
| 6月 | 1回目の土寄せ（定植後ひと月）。肥料を溝に入れて土を寄せます。韓国の梅雨（チャンマ、6月下旬～7月）の前に排水路を整備 |
| 7月 | 2回目の土寄せ。高温期で生育が遅くなります。べと病とさび病に注意します |
| 8月 | 3回目の土寄せ。秋まき（8月末から9月末）。シロイチモジヨトウの卵塊を探します |
| 9月 | 春に植えた長ネギの収穫開始。分げつ株の株分け |
| 10月 | 秋の定植（10月初めから11月末）。最後の土寄せを終えます |
| 11月 | カリウム中心に越冬用の肥料を入れます。抜かないものはそのまま置きます |
| 12月 | わらや落ち葉で覆います。冬の収穫区画を決めて、近づく通路を確保します |

&nbsp;&nbsp;&nbsp;この表でもっとも重要な二行が、4月と8月です。4月に、冬を越した長ネギを収穫し切らなければ、花茎が立って、すべて使えなくなります。8月の秋まきは、時期を守らないと早期の抽だいで、翌年の収穫がなくなります。どちらも、数日遅れたからといってすぐには表に出ず、数か月後に結果が現れることなので、初めて栽培する人がもっともよく見落とします。

&nbsp;&nbsp;&nbsp;そして、6月、7月、8月の三行が、長ネギを長ネギたらしめる作業です。土寄せを三回していない長ネギは小ネギに近く、三回した長ネギは太くて白い柱を持ちます。月に一度、三回のスコップ作業が、その違いを生みます。

&nbsp;&nbsp;&nbsp;最後に、3月と9月の分げつ株の株分けが、この作物の自立を決めます。種が1年ともたない作物において、畑で生きている株を分けて植えるこの二度の作業が、そのまま種子の貯蔵です。
