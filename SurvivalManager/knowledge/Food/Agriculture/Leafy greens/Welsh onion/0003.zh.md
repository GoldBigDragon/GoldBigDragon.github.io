## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

| 项目 | 内容 |
|---|---|
| 学名 | Allium fistulosum |
| 分类 | 天门冬目（Asparagales）石蒜科（Amaryllidaceae）葱属（Allium） |
| 别名 | 葱（pa）、窖葱（umpa，在窖中培育的葱）、细葱（silpa）；为与分葱（jjokpa）区分而称作大葱（daepa） |
| 原产地 | 推测为中国西部至西伯利亚一带 |
| 生活型 | 二年生。利用分蘖可连续使用2-4年 |
| 繁殖 | 种子和分蘖株分株 |

&nbsp;&nbsp;&nbsp;学名中的fistulosum意为“中空的管”。这个名称直接指出了大葱的叶子是中空圆筒这一事实，也是区分大葱与韭菜的第一个标准。韭菜的叶子扁平而实心，大葱的叶子圆而中空。用手捏一下叶子，大葱会瘪下去，韭菜则依然挺住。

&nbsp;&nbsp;&nbsp;原产地是从中国西部到西伯利亚的寒冷内陆，这一点解释了大葱的特性。要在夏季短、冬季长的地区生存下来，需要两样东西：一是耐寒的能力，二是一套时间安排——在短暂的夏季里把植株长好，熬过冬天，到第二年春天早早结籽。大葱的耐寒性S和二年生的生活史，都来源于此。

&nbsp;&nbsp;&nbsp;与洋葱不同，大葱不把鳞茎养得粗大。它不是把养分储存在圆形的鳞茎里，而是把叶鞘一层层叠起来向上长。这些叠起来的叶鞘就是葱白，也就是白色部分。这一差别使栽培方式完全不同。洋葱是养鳞茎的农事，大葱是拉长叶鞘的农事，而拉长叶鞘的手段就是培土。

### 2-2. 形态

| 器官 | 特征 |
|---|---|
| 叶 | 中空圆筒形。表面有白色蜡质层，水珠会滚落 |
| 葱白（假茎） | 叶鞘层层叠起的白色部分。不是真正的茎 |
| 茎（茎盘） | 葱白最下端扁平的圆盘。根和叶都从这里长出 |
| 根 | 白色须根。集中分布在20-30cm深处 |
| 花 | 白色至淡紫色。聚成球状开放。第2年春天 |
| 种子 | 黑色、表面有皱纹的小种子 |

&nbsp;&nbsp;&nbsp;葱白不是真正的茎，这一点很重要。大葱真正的茎只有最底部的一个扁平圆盘，其上看到的白色圆柱，是叶的基部——叶鞘——层层叠起而成。这就好比把剥洋葱皮时看到的那种层状结构，沿纵向拉长了一样。

> **被土盖住的部分接受不到光，不会生成叶绿素，保持白色。葱白的长度不是由植物自己决定的，而是取决于人盖了多少土。**

&nbsp;&nbsp;&nbsp;这一事实几乎解释了大葱栽培的全部。造就葱白的不是种子或品种，而是培土这项作业。即使播下同样的种子，培了三次土的大葱和一次也没培过土的大葱，会成为截然不同的东西。第8节将详细介绍这项作业。

&nbsp;&nbsp;&nbsp;叶表面的蜡质层也值得一提。用手一搓就会像白粉一样脱落的那一层，是大葱为了防止水分蒸发、阻挡病原菌侵入而形成的保护膜。因此，即使往大葱叶上喷药液或肥皂水，也很难附着，会顺着流下来。在不能用农药来防治的情况下，这一特性会带来不利影响，第9节将讨论这一点。

### 2-3. 分蘖 - 把二年生植物当作多年生植物来用的方法

&nbsp;&nbsp;&nbsp;大葱底部的圆盘上，长出来的不只有叶，还有新的植株。这种从侧面分出来的新植株叫作分蘖，不同品系的分蘖程度差别很大。

| 类别 | 分蘖 | 葱白 | 培土 | 利用方式 |
|---|---|---|---|---|
| 单茎葱（茎用葱） | 几乎不分蘖 | 长而粗 | 必须 | 一棵一棵拔来用 |
| 叶葱（分蘖葱） | 8-10个以上 | 短而细 | 不需要 | 分株延续 |
| 朝鲜大葱（地方品种） | 中等程度 | 中等 | 最好进行 | 可越冬，延续数年 |

&nbsp;&nbsp;&nbsp;评价表中“持续性S，利用分蘖可连续收获2-4年”这一项所指的，就是表中的第二行和第三行。把分蘖出来的植株在春天或秋天掰下来重新栽种，即使没有种子，植株也能代代延续。一株变成八株，其中一半食用、一半重新栽种，就形成了一个循环。

&nbsp;&nbsp;&nbsp;灾害应对中的实际判断就取决于此。想要得到粗壮洁白的大葱，就得对单茎葱品系进行培土，但单茎葱不分蘖，拔了就到头了。每年都需要种子，而这些种子保存不了1年。相反，会分蘖的品系葱白短、可吃的部分少，但不需要种子就能延续下去。不必在二者之中选其一，两个品系都种上才是现实的答案。

### 2-4. 生育阶段与抽薹

| 阶段 | 时期 | 发生什么 | 主要需要 |
|---|---|---|---|
| 发芽·幼苗期 | 播种后30天 | 一片丝线般的叶子弯曲着长出 | 磷、氮 |
| 育苗期 | 30-60天 | 真叶增多，茎变粗 | 氮 |
| 定植·缓苗期 | 定植后1-2周 | 断掉的根重新长出 | 磷 |
| 营养生长期 | 定植后1-3个月 | 叶片增多，葱白变长 | 氮、钾 |
| 最佳收获期 | 定植后3-6个月 | 葱白变粗变结实 | 氮、钾均衡 |
| 越冬 | 在韩国为11月至3月 | 外叶枯萎，内部和葱白仍然存活 | 钾 |
| 抽薹·结实 | 第2年春天 | 花茎抽出，结出种子 | 磷、钾 |

&nbsp;&nbsp;&nbsp;最后一行的抽薹，是大葱栽培中最需要注意的地方。花茎一旦抽出，一根坚硬的茎会从葱白正中贯穿，使其无法食用。外表看起来完好，剖开后却会发现里面插着一根木头般的硬芯。

&nbsp;&nbsp;&nbsp;抽薹需要两个条件同时具备。第一，幼苗必须长到一定粗度以上，大致相当于铅笔的粗细，直径6-7mm是基准线。第二，在这种状态下经历一段时间13℃以下的低温。这两个条件碰到一起，植物就会判断自己已经过了一次冬天，开始准备开花。年幼的细苗，无论经历多少寒冷，都不会抽薹。

> **秋天播种过早，冬前幼苗长得过粗，第二年春天就吃不成，只会抽出花茎。要严守秋季播种时期，原因就在这里。**

&nbsp;&nbsp;&nbsp;把这一原理反过来用，就成了留种的方法。想要留种，只需让养得粗壮的大葱越冬即可。第13节会讨论。

### 2-5. 每100g的营养

| 营养素 | 含量 | 备注 |
|---|:---:|---|
| 热量 | 23-34kcal | 因资料和部位而异 |
| 水分 | 约90g | |
| 蛋白质 | 1.78g | 占热量的比例（P:E）为31.0% |
| 碳水化合物 | 5-7g | |
| 糖类 | 2.63g | 煮熟后甜味明显 |
| 钾 | 181mg | |
| 钙 | 含有 | |
| 铁 | 含有 | |
| 维生素A | 绿叶中较多 | 葱白中几乎没有 |
| 维生素C | 大量 | 葱白中也有相当的量 |
| 维生素K | 大量 | 集中在绿叶中 |
| 叶酸、硫胺素、核黄素、泛酸 | 含有 | |
| 含硫化合物（大蒜素类） | 含有 | 气味、抗菌作用、辛辣味的来源 |

&nbsp;&nbsp;&nbsp;这张表中值得注意的是，绿叶与白色葱白的成分不同。维生素A和维生素K是与叶绿素一起合成的，因此集中在绿叶中，葱白里几乎没有。相反，糖类在葱白中更多，煮熟后会出现甜味。

&nbsp;&nbsp;&nbsp;所以，像通常那样丢掉绿叶、只用白色部分，从营养上看是一种损失。使微量营养素得到A等级的15种营养素中，有相当一部分来自绿叶。在灾害情况下，把叶子部分单独切碎晒干收存，用来放进汤里或磨成粉，是更合理的做法。

&nbsp;&nbsp;&nbsp;含硫化合物是在组织受伤时通过酶的作用生成的。切大葱时眼睛会被辣到，就是这一反应所致，而这种成分具有抗菌作用。它怕热，煮久了就会挥发；而煮熟之后，辛辣味消失，甜味浮现。这正是同一根大葱，生用和煮熟后用会成为完全不同的食材的原因。

## 3. 栽培环境

### 3-1. 温度

| 类别 | 温度 | 结果 |
|---|:---:|---|
| 可发芽温度 | 15-25℃ | 超出此范围，发芽率会下降 |
| 发芽适温 | 20℃左右 | 7-10天出芽 |
| 生长适温 | 20℃上下 | 喜欢凉爽的气候 |
| 可生长范围 | 5-30℃ | 幅度25℃。温度适应幅度SS的依据 |
| 高温伤害 | 25℃以上 | 生长变慢，病害增多 |
| 低温生长停滞 | 5℃以下 | |
| 外叶枯死 | 低于零下10℃ | 内部和葱白仍然存活 |
| 露地越冬极限 | 零下10℃ | 耐寒性S的依据 |
| 花芽分化条件 | 13℃以下持续一段时间 | 仅限幼苗达到铅笔粗细以上时 |

&nbsp;&nbsp;&nbsp;生长适温在20℃上下，意味着大葱不喜欢盛夏。韩国7月和8月的大葱虽然能生长，但速度缓慢，也容易生病。霜霉病和锈病集中发生在韩国的梅雨季（6月下旬至7月），也是这个缘故。在韩国，实际的栽培节奏分为两路：春天种、秋天收，以及夏末种、第二年春天收，原因就在这里。

&nbsp;&nbsp;&nbsp;耐寒性S和露地越冬，是大葱最实用的特性。它可以在零下10℃的低温下原样立在地里，在韩国中部以南地区无需特别保护就能越冬。在韩国中部以北地区或格外寒冷的年份，充分培土、用土盖住葱白，这层土就会成为隔热材料，帮助大葱挺过去。

&nbsp;&nbsp;&nbsp;外叶被霜打得枯萎，很容易被误以为是死了。实际上只是外面的几片叶子枯萎，里面的叶子和葱白都完好无损。把枯萎的外叶剥掉，下面就会露出完好无损的白色部分。相反，枯萎的外叶包在里面起保护作用，所以冬天最好不要剥掉，留着为好。

### 3-2. 光照

| 条件 | 相对产量 | 解读 |
|---|:---:|---|
| 全天直射光 | 100% | 这是基准 |
| 每天6小时以上 | 接近100% | 实用的最低线 |
| 40%遮光 | 约86% | 置信区间61-120%。光照B的依据 |
| 半阴 | 能生长 | 葱白变细，叶片变长 |

&nbsp;&nbsp;&nbsp;大葱算是比较耐阴的。遮光40%，产量仍能保持在86%。不过，大葱缺光时出现的症状不只是产量下降。光线不足时，植物会向上徒长去追逐光线，结果叶片松垂，组织变得柔嫩。柔嫩的组织容易倒伏，也容易感病。

&nbsp;&nbsp;&nbsp;另一方面，有意遮光竟是大葱栽培的核心技术，这一点很有意思。培土就是这项作业。让地上部分充分受光，同时用土把地下部分完全盖住，同时做到这两点，就是大葱田的结构。

### 3-3. 水分与土壤

| 项目 | 标准 | 备注 |
|---|---|---|
| 土质 | 土层深厚、排水良好的土地 | 要培土，土就得充足 |
| 土壤酸碱度 | pH 5.7-7.4 | 范围比较宽 |
| 有机质 | 充足的腐熟堆肥 | 是喜肥作物 |
| 排水 | 非常重要 | 是最不耐渍害的作物之一 |
| 灌溉 | 总ET约550mm | 比较耐旱 |
| 垄高 | 15-20cm以上 | 排水不良的土地上为25cm |
| 畦的结构 | 把沟挖深 | 相当于提前备好培土要用的土 |

> **大葱整季绝收的原因，几乎总是积水。在梅雨季里被淹了几天的田里，长成的大葱会从基部开始腐烂倒伏。**

&nbsp;&nbsp;&nbsp;大葱特别不耐渍害，原因在于其结构。葱白是由叶鞘层层叠成的圆柱，一旦水渗进层与层之间，就会形成不通气的密闭潮湿空间，这对软腐病菌的生长来说是再完美不过的条件。而且，因为培土已经把这一部分埋进了土里，从外面根本看不出里面是不是已经在腐烂。直到看到地上部分变黄倒伏才会发觉，而那时已经太晚了。

&nbsp;&nbsp;&nbsp;最后一行“把沟挖深”这一项，是大葱田的特征。其他作物是起垄，种在垄上；而大葱是把沟挖深，种在沟底，再一点点把两侧的土推进沟里，边培土边让它生长。这样一来，不用另外运土来培土，同时沟还起到排水沟的作用。一项作业解决了两个问题。

&nbsp;&nbsp;&nbsp;土层必须深厚这一条件，也源自这种结构。要把葱白培到接近30cm，就需要有相应的土量，在砾石多或土层浅的地方无法培土。在这样的地块，放弃葱白、改种会分蘖的品系并以利用叶子为主，是更合理的选择。
