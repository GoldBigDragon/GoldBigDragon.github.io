## 4. 品种

### 4-1. 各品系的特点

| 品系 | 分蘖 | 葱白 | 培土 | 灾害适用性 |
|---|---|---|---|---|
| 单茎葱（茎用葱） | 不分蘖 | 长而粗 | 必须 | 单棵体积大，储藏效率高 |
| 叶葱（分蘖葱） | 8-10个以上 | 短而细 | 不需要 | 不需要种子，靠植株延续 |

| 品种 | 特点 | 产量 | 适宜环境 |
|---|---|:---:|---|
| 朝鲜大葱（地方品种） | 越冬可靠，全年都能收获 | 中等至较高 | 韩国全国 |
| Geummaek | 可提早收获，葱白长 | 高 | 韩国全国 |
| Beullaekdokkui | 粗壮挺直，形状整齐 | 高 | 韩国全国 |
| 普通单茎葱 | 分布最广的品系 | 中等 | 韩国全国 |

&nbsp;&nbsp;&nbsp;这些表中对灾害应对最重要的，是第一张表中两行出现分歧的地方。单茎葱是一棵一棵拔来用的作物，拔了这一株就到头了。想在次年再种，就得有种子，而大葱种子保存不了1年。叶葱不拔，而是分株使用，因此不需要种子就能延续。代价是葱白短，一次得到的量少。

&nbsp;&nbsp;&nbsp;像朝鲜大葱这样兼具两种特性但都不太极端的地方品种，之所以适合灾害情况，原因就在这里。它有一定程度的分蘖，加上培土，也能得到相当可观的葱白。它在哪一方面都不是最好，但哪一方面也都没有放弃。而且地方品种是在当地经过漫长岁月筛选出来的品系，早已适应了当地的气候。

### 4-2. 按情况选择的标准

| 情况 | 选择 | 理由 |
|---|---|---|
| 指望不上种子供应 | 叶葱、朝鲜大葱 | 把分蘖株分开，不需要种子就能延续 |
| 打算作为冬季储备资源 | 单茎葱 | 葱白粗，单棵体积和重量大 |
| 韩国中部以北、寒冷地区 | 朝鲜大葱 | 越冬可靠 |
| 土层浅或砾石多的土地 | 叶葱 | 不需要培土 |
| 想尽快收获 | 任何品系都收成小葱 | 40-50天就长到小葱的粗细 |
| 打算持续留种自用 | 固定种、地方品种 | 杂交种次年性状会分离 |

> **种子袋上写着F1的是杂交种。第一年产量不错，但留种再种，性状就会分离。以灾害为前提的话，是不是固定品种，比品种本身优秀与否更重要。**

&nbsp;&nbsp;&nbsp;不过，对大葱来说，这条原则并不像对其他作物那样绝对。因为种子寿命不足1年，原本就不存在长期储备种子的策略。大葱实际的自立手段不是种子，而是分蘖株，从这一点来看，比起是固定品种还是杂交种，该品系分蘖多少更为重要。

## 5. 整地与施肥

### 5-1. 整备田地

| 项目 | 标准 | 备注 |
|---|---|---|
| 耕翻深度 | 20-30cm | 目的是把培土用的土翻松 |
| 畦间距 | 单茎葱75-85cm，叶葱1.5m | 要培土，畦与畦之间必须宽 |
| 栽植沟深度 | 15-20cm | 种在沟底，然后逐步把土推进沟里 |
| 排水沟 | 必须保证 | 渍害是最大的失败原因 |
| 酸度调节 | pH 5.7-7.4 | 范围宽，不必大动 |
| 捡石 | 事先捡出 | 会妨碍培土，使葱白弯曲 |

&nbsp;&nbsp;&nbsp;大葱整地与其他作物不同之处，在于畦与畦之间留得很宽。乍看像是浪费土地的布置，但这块空出来的地方恰恰是培土用土的储备库。要分三次培土，旁边就得备好相应的土量，畦间太窄，就没有土可培，葱白也就会变短。

&nbsp;&nbsp;&nbsp;把沟挖深、种在沟底，是大葱栽培的基本结构。起初，苗种在沟底，位置很低，随着生长，两侧的土一点点被推进来，最后沟变成了垄的样子，到秋天，原来是沟的地方成了最高处。田地的高低在一年之中整个翻转了过来。

### 5-2. 施肥量

&nbsp;&nbsp;&nbsp;大葱是喜肥作物。评价表中施肥需求等级C，来自N、P、K合计每1㎡约需30g这一数值，是本文档所涉及的四种作物中用量最大的。

| 成分 | 每1,000㎡ | 每1㎡ | 备注 |
|---|:---:|:---:|---|
| 氮（N） | 相当于尿素25kg | 约11g | 分基肥和追肥施用 |
| 磷酸（P） | 相当于钙镁磷肥6.6kg | 约3g | 全部作基肥 |
| 钾（K） | 相当于氯化钾14kg | 约8g | 分基肥和追肥施用 |
| 堆肥 | 1,500kg | 1.5kg | 只用腐熟堆肥 |
| 石灰 | 需要时100-150kg | 100-150g | 仅在酸性严重时施用 |

| 类别 | 时期 | 内容 |
|---|---|---|
| 基肥 | 定植前1-2周 | 堆肥全部、磷酸全部、氮和钾的一半 |
| 第1次追肥 | 定植后1个月 | 与第1次培土同时进行 |
| 第2次追肥 | 第1次后1个月 | 与第2次培土同时进行 |
| 第3次追肥 | 第2次后1个月 | 与第3次培土同时进行 |
| 越冬前 | 在韩国为11月 | 以钾为主 |

> **大葱的追肥与培土是一体的。把肥料施入沟里，再在上面盖土，肥料被土盖住，不会挥发流失，新长出的根也能立即吸收到。**

&nbsp;&nbsp;&nbsp;这个顺序之所以重要，是有原因的。培土之后，大葱会在新盖上的土里长出新根。如果事先把肥料施在这个位置，新根就会立刻吸收。反过来，先培土、之后再往表面撒肥料，肥料往下渗透需要时间，氮素还有相当一部分会挥发到空气中。先施肥、后盖土的顺序，用同样的肥料量能取得更好的效果。

&nbsp;&nbsp;&nbsp;只用腐熟堆肥这一条件，对大葱来说也格外严格。未腐熟的堆肥会招来葱地种蝇，这种害虫会啃食大葱的地下部分，把整株弄死。堆肥是否已经完全腐熟，可以用手抓一把来判断：不发热，有泥土的气味，认不出原材料的形态，就说明已经腐熟。

### 5-3. 灾害时的替代肥料

&nbsp;&nbsp;&nbsp;化肥断供后，大葱最先出现的变化是葱白变细。无合成投入产量保持率C、40.8%这个数值所指的就是这种现象。大葱是需肥量大的作物，所以这种损失表现得尤其明显。

| 替代资源 | 提供成分 | 用法 | 注意 |
|---|---|---|---|
| 人尿 | 氮（主）、钾、磷酸 | 加水稀释8-10倍，培土前浇入沟中 | 碰到叶子会灼伤叶片。用土盖住，以免气味和养分损失 |
| 腐熟堆肥 | 氮、磷酸、钾、有机质 | 基肥要足量。追肥在培土前施入沟中 | 未腐熟的堆肥会招来葱地种蝇 |
| 草木灰 | 钾、钙、磷酸 | 培土前往沟里撒一两把 | 呈碱性。大葱可耐受到pH 7.4 |
| 骨粉 | 磷酸、钙 | 烧后捣碎，混入基肥 | 见效缓慢 |
| 麻饼（芝麻饼） | 氮、磷酸 | 沤成发酵液使用，或混入基肥 | 直接撒施，发酵产生的热会伤根 |
| 草液肥 | 氮、钾 | 把割下的草泡在水里沤2-3周，再稀释5倍 | 气味很重 |
| 豆科前茬 | 氮 | 前一年种大豆或豌豆，把残茬翻埋入土 | 葱属不与豆科一起种 |
| 贝壳·蛋壳 | 钙 | 烧后捣碎，用于调节酸度 | 可代替石灰 |

&nbsp;&nbsp;&nbsp;稀释尿液特别适合大葱，是有原因的。大葱的追肥方式是在培土的同时施入沟里、再用土盖住，液体肥料可以直接渗进土里，上面又有土盖着，气味和损失都随之减少。沾到叶子上的担心也小。健康人的尿液每1L含有以尿素形式存在的氮7-10g，稀释8-10倍后，就成了稀薄的氮肥。

&nbsp;&nbsp;&nbsp;草木灰在提供钾的同时，还能提高土壤pH。大葱可耐受到pH 7.4，所以比其他作物可以多用一些灰。培土前在沟里撒灰，再在上面盖土，就能同时完成供钾和地下部杀菌。葱地种蝇的成虫有在潮湿土壤里产卵的习性，而灰能让表面变干、变成碱性，它的效果在这里也能派上用场。

&nbsp;&nbsp;&nbsp;倒数第二行之所以附有说明，原因将在第11节讨论。葱属植物会抑制豆科作物的根瘤菌，因此不能与豆科一起种，但隔开一段时间、前后茬衔接安排，反而更有利。

## 6. 播种、育苗与定植

### 6-1. 栽培茬口

| 茬口（韩国的时期） | 播种 | 定植 | 收获 |
|---|---|---|---|
| 春季栽培 | 3月初至4月底 | 5月初至6月底 | 9月中旬至次年4月底 |
| 秋季栽培 | 8月底至9月底 | 10月初至11月底 | 次年4月中旬至5月底 |

&nbsp;&nbsp;&nbsp;韩国的春季栽培，是在秋季收获、并让大葱撑过冬季继续收获的方式，秋季栽培则是以幼苗状态越冬、次年春天提早收获的方式。从灾害应对的角度看，把两种茬口叠加安排比较安全。这样一来，从4月到次年4月，实际上全年地里都立着大葱。

> **秋季栽培中，严守播种时期尤其重要。播得太早，冬前幼苗粗过铅笔，经历低温后就会发生花芽分化，次年春天只会抽出花茎。**

&nbsp;&nbsp;&nbsp;这种过早抽薹，是秋季播种中最常见的失败。看起来播得早长得好，结果却恰恰相反。韩国的8月底至9月底这段时间，是为了让冬天到来之前的幼苗长得恰到好处——既长到足以存活，又不至于长到满足春化条件——而定下来的时期。

### 6-2. 育苗

| 项目 | 标准 |
|---|---|
| 播种方法 | 在苗床上撒播，或按10cm间距条播 |
| 播种深度 | 5-6mm，宜浅 |
| 发芽天数 | 20℃下7-10天 |
| 育苗期 | 40-50天。长的可达60天 |
| 定植适期 | 真叶4-5片，茎粗5-7mm |
| 苗床管理 | 保持表土不干 |

&nbsp;&nbsp;&nbsp;大葱种子刚出土时，呈钩环状弯曲着长出来。这是因为子叶的尖端还粘在种皮上，中间部分先拱了出来。在这种状态下，幼苗非常脆弱，所以保持表土不干，几乎就是育苗的全部。

&nbsp;&nbsp;&nbsp;把定植适期定在茎粗5-7mm，有两个原因叠加在一起。一是比这更细，移栽时经受不住；二是比这更粗，遇到低温时抽薹的风险会增大。春季定植时第二个原因不成问题，但在秋季定植时却是决定性的。

### 6-3. 定植

| 项目 | 单茎葱 | 叶葱 |
|---|---|---|
| 畦间距 | 75-85cm | 畦宽1.5m |
| 株距 | 每隔7-12cm栽2-3株 | 每隔12-15cm栽2-3株 |
| 栽植深度 | 刚好盖住根部，约3cm | 相同 |
| 栽植姿势 | 在沟底斜卧着栽 | 相同 |
| 栽后 | 轻轻压实土壤并浇水 | 相同 |

&nbsp;&nbsp;&nbsp;不深栽这一点，起初看起来有些奇怪。想让葱白变长，似乎就得深埋，但那样做会失败。大葱的生长点就在底部圆盘的正上方，一旦被深埋，新叶要费力顶开泥土才能钻出来，甚至干脆烂掉。葱白不是一开始就靠深埋做成的，而是在生长过程中一点一点地盖土做成的。

&nbsp;&nbsp;&nbsp;斜卧着栽的要领，也是同样的道理。斜卧着栽，根部埋得浅，而茎接触土壤的长度却变长了。大葱几天之内就会自己直立起来，所以不必担心姿态，而且等它直立起来时，已经有相当长的一段处在贴近土面的位置，培土的起点就提高了。

&nbsp;&nbsp;&nbsp;每处两三株合栽，也是有道理的。几棵葱互相依靠，笔直生长，彼此遮阴，下部不那么粗，却会向上长得更长。如果一棵一棵分开栽，就会向旁边铺开、变粗，葱白反而变短。

### 6-4. 种子处理

| 方法 | 步骤 | 效果 |
|---|---|---|
| 温汤浸种 | 在50-55℃的水中浸10-15分钟，再用冷水冷却 | 杀死表面的病原菌 |
| 拌草木灰 | 把过筛的草木灰拌到湿润的种子上 | 兼起表面消毒的作用 |
| 种子筛选 | 浸入水中，捞走浮起的 | 剔除空心的种子 |

&nbsp;&nbsp;&nbsp;在买不到药剂的情况下，只挑选健康的种子并进行温汤浸种，就是现实中的最佳办法。如果没有温度计，把开水和冷水大致各半混合，手伸进去时觉得烫但还能忍受的程度，就在50℃左右。超过60℃种子就会死，所以只处理手头种子的一部分，分开播种比较安全。

## 7. 水分管理

### 7-1. 各生育阶段的浇水

| 时期 | 管理 | 备注 |
|---|---|---|
| 播种至发芽 | 每天浇水，保持表土不干 | 是苗床管理的关键 |
| 育苗期 | 每2-3天一次 | 过量会使幼苗徒长 |
| 定植刚结束 | 每周2次，浇足 | 是断掉的根重新长出的时期 |
| 缓苗后的生长期 | 每周1次，一次浇透 | 浅而频繁的灌溉会使根扎得浅 |
| 培土刚结束 | 一次 | 新土与根紧密贴合 |
| 韩国的梅雨季（6月下旬至7月） | 不浇水 | 整修排水沟就是这一时期的水分管理 |
| 越冬期 | 不浇水 | 湿土一冻，葱白就会受损 |

&nbsp;&nbsp;&nbsp;大葱算是比较耐旱的。叶表面的蜡质层能防止水分流失，叶子又是圆筒形，相对于表面积，体积较小。天旱时只是生长速度变慢，不会轻易死掉。所以在需要节约用水的情况下，大葱是可以把灌溉的优先顺序往后排的作物。

### 7-2. 缺水与水分过多的症状

| 症状 | 原因 | 发生什么 |
|---|---|---|
| 叶尖干枯变褐 | 缺水或盐分过多 | 这片叶子无法恢复，但植株能活 |
| 叶片细短，葱白不变粗 | 持续缺水或缺肥 | 产量下降 |
| 叶片变黄，从基部倒伏 | 湿度过大、软腐病 | 葱白内部已经烂软了 |
| 拔起时基部有恶臭 | 软腐病 | 属细菌性。这块地要避开好几年 |
| 根部附近有蛆 | 葱地种蝇 | 原因是未腐熟的堆肥和过湿 |
| 叶上有灰色霉层和黄色条纹 | 霜霉病 | 条件是低温高湿 |

&nbsp;&nbsp;&nbsp;第三行和第四行，是大葱最可怕的症状。软腐病是由细菌引起的病害，在葱白内部的叶鞘之间发展，所以从外面看不出来。等外叶变黄、葱株开始倾斜时，里面早已烂得像粥一样了。拔起来会有特有的恶臭，这种气味只要闻过一次，下次光凭气味就能认出来。

&nbsp;&nbsp;&nbsp;有必要明确一点：这种病没有治疗方法。即使有药，一旦从内部开始的软腐，也无法逆转。对策只有预防，所谓预防，就是不让田里积水，以及培土时不要让土盖到叶片分叉处以上。

### 7-3. 覆盖

&nbsp;&nbsp;&nbsp;大葱需要不断培土，所以把垄面整个盖住的覆盖方式不适合。因为每次培土都得先把覆盖物掀开。取而代之的做法是，只在畦间的沟里，也就是不从那里取培土用土的地方，铺上稻草和干草，这样既能抑制杂草，又不会妨碍作业。

&nbsp;&nbsp;&nbsp;到了冬天，情况就不同了。最后一次培土让葱白被充分盖住之后，再在上面盖一层5-10cm厚的稻草或落叶，就能起到隔热作用。零下10℃以内，大葱本身就能扛住，但在比这更冷的地区或格外寒冷的年份，这层覆盖物能保护立在地里的大葱。只要覆盖物下面的土不结冻，整个冬天都可以随时拔来用，这是大葱最大的实用价值。

&nbsp;&nbsp;&nbsp;不过，覆盖物下面是蛞蝓和老鼠容易藏身的地方，所以要时常掀开检查。冬天的田里，大葱是为数不多显眼的可吃之物，有时也会成为野兽的目标。
