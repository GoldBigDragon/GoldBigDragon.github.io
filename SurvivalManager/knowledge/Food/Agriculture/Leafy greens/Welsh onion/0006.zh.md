## 12. 收获 - 田地就是仓库

### 12-1. 时期的判断

| 类别 | 标准 |
|---|---|
| 小葱 | 定植后40-50天。虽细但可直接食用 |
| 中葱 | 定植后2-3个月 |
| 大葱 | 定植后3-6个月，葱白粗壮结实时 |
| 冬季收获 | 从下霜后到次年春天，需要时随时收 |
| 截止时点 | 次年春天抽出花茎之前 |

> **对大葱来说，关键不在于什么时候收，而在于最晚可以留到什么时候。长成之后仍然立在地里过冬，这种状态本身就是贮藏。**

&nbsp;&nbsp;&nbsp;最后一行的截止时点很重要。第2年春天花茎一旦抽出，一根坚硬的茎会从葱白正中贯穿，使其无法食用。外表看起来完好，剖开后里面却插着一根木头般的硬芯。把大葱立在地里留用的策略，附带着这条春季的截止线，一旦越过这条线，到那时还剩下的大葱就全部不能用了。

&nbsp;&nbsp;&nbsp;所以，冬季大葱的运用方式是这样的：秋天长成的大葱不拔，原样留着。整个冬天，需要时一棵一棵拔来用。在韩国，到了次年3月底或4月，如果看到有要抽出花茎的迹象，就把剩下的一次性拔出来，晒干或腌渍，转入加工贮藏。这个时点就是从田间贮藏转向加工贮藏的分界线。

### 12-2. 收获要领

| 方式 | 方法 | 结果 |
|---|---|---|
| 连根拔 | 用小锄头（homi）刨松基部周围的土，再提起来 | 这一株就到头了。能完整得到葱白 |
| 只割叶 | 在离地面3-4cm处留茬割下 | 新叶会再长出来。得不到葱白 |
| 掰取分蘖株 | 挖出一丛，分开后只吃一半 | 其余的重新栽种，继续延续 |

&nbsp;&nbsp;&nbsp;这三种方式因目的不同而取舍。想得到粗壮的葱白，就得连根拔起，那么这一株就到头了。想持续收获，就只割叶子，但必须放弃葱白。如果是会分蘖的品系，第三种方式可以把两者各得一半。

&nbsp;&nbsp;&nbsp;只割叶子的方式中，要求离地面留3-4cm，理由与韭菜相同。大葱的生长点就在底部圆盘的正上方，一旦把它割掉，就没有长新叶的地方了。3-4cm就是在其上方安全保留的余量。

&nbsp;&nbsp;&nbsp;在土壤结冻的冬天拔葱，需要掌握要领。直接硬拔，葱白会从中间折断，留在土里。必须先用小锄头或铁锹把旁边刨开，破开冰和土之后再提起来。冬天要用的大葱，如果在秋天预先只浅埋一行左右，或者厚厚地盖上稻草，这项作业就会容易得多。

### 12-3. 收获后的处理

| 项目 | 内容 |
|---|---|
| 抖土 | 在拔出的地方抖动，抖掉根上的土 |
| 外叶 | 只剥掉一两片干枯或受损的外叶 |
| 清洗 | 只洗马上要用的。洗过的容易坏 |
| 根 | 要贮藏的不要剪根 |
| 叶子部分 | 不要扔掉，单独收集晒干 |

&nbsp;&nbsp;&nbsp;要贮藏的大葱不剪根，是有原因的。根还连着，大葱就依然保持存活状态，能留住水分，也没有切口，病菌侵入的口子也随之减少。把大葱连根重新埋进土里的贮藏方法之所以有效，也是同样的道理。

&nbsp;&nbsp;&nbsp;最后一行也是灾害情况下不能忽视的项目。大葱的绿叶部分平时常被扔掉，但使微量营养素得到A等级的15种营养素中，相当一部分就在这一部分。维生素A和维生素K在葱白中几乎没有，集中在绿叶中。切碎晒干存起来，冬天就能当汤料，也能磨成粉做调味料。

## 13. 留种 - 等待第2年抽薹

### 13-1. 两道障碍

&nbsp;&nbsp;&nbsp;评价表中，自家留种为A，种子寿命为D。虽然可以留种，但有两道障碍。

| 障碍 | 内容 |
|---|---|
| 二年生 | 想留种，就得熬过冬天，等待第2年春天抽薹 |
| 异花授粉 | 蜜蜂传递花粉，会与附近的其他葱属植物混杂 |
| 种子寿命短 | 留下的种子必须在1年内用掉 |

&nbsp;&nbsp;&nbsp;第一道障碍是时间问题。收获食用大葱和留种，不能在同一株上同时完成。留种的植株，秋天不拔，让它越冬，到次年春天抽出花茎，而这一株的葱白就不能吃了。留种是以放弃可吃之物为代价换来的。

&nbsp;&nbsp;&nbsp;第二道障碍更棘手。大葱不太能用自己的花粉受精，而是接受其他植株的花粉。所以，附近如果有其他葱属植物在开花，蜜蜂就会把那些花粉带过来。虽然与韭菜花期不同，但如果分葱（jjokpa）、洋葱和其他品系的大葱放在一起，就会混杂。

| 隔离方法 | 内容 | 可靠性 |
|---|---|---|
| 距离隔离 | 与其他葱属采种株相隔500m以上 | 高，但现实中难以做到 |
| 时期隔离 | 调整种植时期，使花期不重叠 | 中等 |
| 套网 | 在花苞绽开之前套上网 | 高。但需要人用毛笔传递花粉 |
| 只留一个品系的种 | 当年只让一种开花 | 最现实 |

> **在小块田地里，最现实的办法是当年只确定一种葱属植物留种，其余的全部剪掉花茎。**

### 13-2. 留种方法

| 步骤 | 内容 |
|---|---|
| 选定留种株 | 秋天选定几棵最粗、最直、无病的植株并做上标记 |
| 越冬 | 不拔，让它原样越冬。多盖些土 |
| 抽薹 | 在韩国，次年4月至5月花茎抽出 |
| 开花 | 5月至6月，开出球状的白色花朵 |
| 判断成熟 | 花谢后，蒴果变褐干枯，露出黑色种子时 |
| 收获 | 连花茎剪下，倒挂在纸或布上方 |
| 分离 | 用手搓干枯的花茎，把种子搓下来 |
| 精选 | 浸入水中，捞走浮起的。沉底的是饱满的种子 |
| 干燥 | 在阴凉处完全晾干 |
| 保存 | 装入密闭容器，同放草木灰或木炭，置于阴凉黑暗处 |

&nbsp;&nbsp;&nbsp;用水浸泡来选种，对大葱种子特别有用。空心的秕籽会浮起，胚完好的种子会沉底。对种子寿命短的作物来说，哪怕把发芽率提高一点也很有价值。不过，泡过水的种子必须马上彻底晒干，如果湿着放置，就会直接作废。

&nbsp;&nbsp;&nbsp;蒴果干了会自行裂开，种子随之掉落，所以错过时机，种子就会撒在地上。等蒴果变褐、有几个开始裂开时，连花茎一起割下来倒挂起来最为稳妥，下面铺块布，就能直接接住边干边掉落的种子。

### 13-3. 保存与寿命

| 条件 | 发芽力保持 |
|---|---|
| 常温密闭 | 不足1年 |
| 阴凉干燥处 | 1-2年 |
| 潮湿或炎热处 | 几个月内急剧下降 |

&nbsp;&nbsp;&nbsp;葱属种子之所以格外短命，据说是因为种子里含有的脂肪成分容易氧化。低温和低湿能延缓氧化，所以要放在阴凉干燥处，并在密闭容器中同放草木灰或木炭来吸湿。

&nbsp;&nbsp;&nbsp;实用的结论与韭菜相同。大葱的种子仓库不是袋子，而是田地。与其把种子攒起来，不如让分蘖株活下去，分成几处种下，这才是这种作物的储备。种子只留当年能用的量。

## 14. 毒性与需注意的成分

### 14-1. 大葱本身的安全性

&nbsp;&nbsp;&nbsp;在一般摄入量下，大葱是安全的食物。生吃可以，煮熟吃也可以。不过有三点值得了解。

| 项目 | 内容 |
|---|---|
| 摄入过量 | 含硫化合物刺激胃黏膜，可能引起烧心 |
| 空腹生吃 | 空腹时大量生吃大葱，刺激更大 |
| 狗和猫 | 整个葱属对宠物和部分家畜有毒 |

&nbsp;&nbsp;&nbsp;第三行是灾害情况下实际需要注意的事项。包括大葱、韭菜、大蒜、洋葱在内的葱属植物，会破坏狗和猫的红细胞，引起贫血。对人毫无问题的成分，对这些动物却是毒物。在用剩饭喂家畜或狗变得普遍的情况下，含有大葱的食物应当排除在外。牛和马如果大量食用，也可能出现同样类型的贫血。

### 14-2. 形似的毒草 - 凭气味区分

&nbsp;&nbsp;&nbsp;在野外而不是在田里寻找葱属植物时，有可能遇到危险。形似葱的毒草确实存在，每年都有中毒事故的报告。

| 类别 | 葱属（大葱、韭菜、野蒜） | 水仙·夏水仙类 | 铃兰 |
|---|---|---|---|
| 切开叶的气味 | 一定有葱或蒜的气味 | 没有气味 | 没有气味 |
| 叶的断面 | 大葱是中空圆筒 | 扁平且实心 | 扁平且实心 |
| 叶的质地 | 柔软多汁 | 厚而光滑 | 厚而挺硬，有光泽 |
| 地下部 | 鳞茎或扁平的圆盘 | 圆形鳞茎（洋葱状） | 细长的根状茎 |
| 食用后 | 可食用 | 严重呕吐、腹痛、腹泻 | 呕吐、头晕、心跳异常 |

> **掐下一片叶子搓一搓，如果没有葱或蒜的气味，就不是葱属植物。仅这一项检查，就能排除几乎所有形似葱属的毒草。**

&nbsp;&nbsp;&nbsp;水仙和夏水仙之类之所以特别危险，是因为地下部很像洋葱。人们在院子里或老花坛里挖球根时，把它误当成洋葱或葱根，这类事故屡屡发生。只看叶子也能分辨：大葱的叶子是中空圆筒，用手指一按就会瘪下去；水仙的叶子是扁平的带状，按下去也依然如故。

&nbsp;&nbsp;&nbsp;铃兰含有作用于心脏的成分，少量也很危险。它的叶片宽大，与大葱混淆的可能性不大，但在采摘茖葱时混进去的事故很常见。在野外寻找葱属植物时，总是要先确认气味。

&nbsp;&nbsp;&nbsp;田里种出来的大葱没有这种危险。不过，如果在大葱田附近种了水仙，春天幼叶可能混进来，所以不要在葱属植物的地块附近放这类植物，就是简单的预防。

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;评价表中的耐储性是D，但附有在无电力的常温下可存放一个月这一数值，以及可以立在地里越冬贮藏的说明。对叶菜类来说这是非常好的条件，在本文档所涉及的四种作物中，贮藏方面最好的就是大葱。

### 15-1. 田地就是贮藏库

| 方法 | 期限 | 条件 |
|---|---|---|
| 不拔，留在田里 | 从秋天到次年春天抽薹前 | 零下10℃以内可原样留着。更冷时盖稻草 |
| 重新埋入土中 | 两三个月 | 连根拔起，斜埋在阴凉处的土里 |
| 窖藏 | 两三个月 | 挖地，与土层层相间堆放，再用稻草盖上 |
| 立放在阴凉处 | 2-4周 | 平放的话叶子会弯曲，腐坏得快 |

&nbsp;&nbsp;&nbsp;第二行的重新埋入方式很实用。春天抽薹开始之前，需要一次性拔出剩下的大葱时，就把它们斜放在阴凉处的土里，让葱白被土盖住埋好。根还连着，大葱就依然保持存活状态，土能使温度和湿度保持稳定。这与把越冬泡菜腌制（kimjang）用的萝卜埋进地里是同样的原理。

&nbsp;&nbsp;&nbsp;第四行“立放”的要领，来自大葱和韭菜共有的特性。平放时，叶子会设法向上弯曲，把能量耗费在这上面，组织也会很快崩坏。立放则不会发生这种反应，可以多撑几天到一两周。

### 15-2. 干燥

| 步骤 | 内容 |
|---|---|
| 处理 | 抖掉土，洗净后把水分彻底沥干 |
| 切 | 叶子切成3-5cm，葱白斜切成薄片或切成圈 |
| 摊晒 | 放在通风良好的阴凉处。晒太阳会使颜色和香气散失 |
| 判断完成 | 用手一搓能碎成粉末为止 |
| 磨粉 | 把完全干透的放进石臼里捣碎 |
| 保存 | 装入密闭容器，同放草木灰或木炭 |
| 期限 | 干透并密封良好的，可保存半年到一年 |

&nbsp;&nbsp;&nbsp;把大葱磨成粉存起来，在灾害情况下特别有价值。体积大大缩小，几乎不占存放空间，往汤里或粥里放一勺就有香味。和盐混在一起存放，就成了一种调味料。在调味品消失的情况下，一罐干大葱粉就是让饭桌变得可以忍受的资源。

&nbsp;&nbsp;&nbsp;不过，要知道在干燥过程中，相当一部分香气会散失，因为气味的来源——含硫化合物——具有挥发性。在阴凉处慢慢晾干，损失会少一些；完全干透后立即密封，就能保住剩下的香气。

### 15-3. 腌渍与发酵

| 方法 | 步骤 | 期限 |
|---|---|---|
| 盐渍 | 用重量5-10%的盐，一层层腌渍 | 3-6个月 |
| 咸菜（jjanji） | 浸没在10%以上的浓盐水中 | 半年以上。食用前用水浸泡去除咸味 |
| 酱油酱菜 | 泡在酱油里 | 几个月 |
| 大酱腌 | 把葱白埋进大酱里腌 | 几个月 |
| 葱泡菜（pagimchi） | 先用盐腌，再拌上调料 | 在阴凉处1-2个月 |

&nbsp;&nbsp;&nbsp;大葱很适合腌渍，是因为含硫化合物本身具有抗菌作用。用比其他蔬菜更少的盐也不会变质，在盐稀缺的情况下，这一差别并不小。而且腌过的大葱辣味褪去，甜味和鲜味浮现，成了与生葱完全不同的下饭菜。

## 16. 烹饪与加工

| 方法 | 燃料 | 步骤 | 备注 |
|---|:---:|---|---|
| 生吃 | 0 | 洗净后切丝，凉拌或作配菜 | 辛辣味和维生素C完整保留 |
| 凉拌鲜菜（geotjeori） | 0 | 用盐稍腌一下再拌 | 不用燃料就能做出一道菜 |
| 汤和韩式炖锅（jjigae） | 中等 | 在关火前放入 | 久煮香气会消失 |
| 葱油 | 少 | 用油慢慢翻炒，让香气转移到油里 | 用少量油就能给多餐调味 |
| 烤 | 少 | 整根放在火上烤 | 甜味大大提升 |
| 煎饼（jeon） | 中等 | 拌入面糊煎制 | 少量就能做成一餐 |
| 干粉 | 0 | 参见第15节 | 兼作保存和调味 |

&nbsp;&nbsp;&nbsp;评价表中烹饪·加工为SS，意思是洗一洗就能直接吃。不过，大葱的价值不是在单吃时显现，而是在给其他食材增添香气时显现。口味等级被评为较低的D，评价的是大葱本身，并不包含它的用法。

> **大葱烹饪的要点分为两个。想要香气，就在最后放；想要甜味，就从一开始久煮。同样一种食材，能起两种完全不同的作用。**

&nbsp;&nbsp;&nbsp;第四行的葱油，在燃料稀缺时特别有用。放少许油，把切好的大葱用小火慢慢翻炒，大葱的香气成分就会转移到油里。这一勺油就能给寡淡的谷物食物调好多餐的味。这是用一次火就确保多餐味道的方式，炒完剩下的葱渣也可以直接吃。

&nbsp;&nbsp;&nbsp;第五行的烤也值得了解。把大葱的葱白整根放在火上烤，产生辣味的成分会被分解，里面的糖显露出来，变得相当甜。把它丢进余烬中，然后剥掉外面烧焦的皮，里面已经烤得软嫩。这是没有炊具、只有火时可以用的办法。

&nbsp;&nbsp;&nbsp;此外还有抗菌作用。在没有冰箱的情况下，做好的食物几个小时后就开始变质，而含有大葱的食物变质速度会稍慢一些。夏天需要把剩菜留到下一餐时，这一差别就有实际意义。

&nbsp;&nbsp;&nbsp;最后再次强调不要扔掉绿叶的问题。维生素A和维生素K只存在于绿叶中，白色葱白里几乎没有。如果叶子太老，不好直接吃，就切碎放进汤里，或者晒干磨成粉就行。微量营养素A这个等级的一半，就在那些被扔掉的部分里。

## 17. 全年作业日程

| 月份（韩国） | 作业 |
|---|---|
| 1-2月 | 需要时从田里拔取立着的大葱来用。检查覆盖物 |
| 3月 | 春季播种（3月初至4月底）。秋天种的大葱继续收获。分蘖株分株 |
| 4月 | 育苗管理。越冬的大葱在花茎抽出之前全部收获 |
| 5月 | 春季定植（5月初至6月底）。留种用的植株保留花茎 |
| 6月 | 第1次培土（定植后一个月）。把肥料施入沟中并培土。在韩国梅雨季（6月下旬至7月）来临前整修排水沟 |
| 7月 | 第2次培土。高温期生长变慢。留意霜霉病和锈病 |
| 8月 | 第3次培土。秋季播种（8月底至9月底）。寻找甜菜夜蛾的卵块 |
| 9月 | 春季种的大葱开始收获。分蘖株分株 |
| 10月 | 秋季定植（10月初至11月底）。完成最后一次培土 |
| 11月 | 以钾为主施入越冬肥。不拔的就原样留着 |
| 12月 | 用稻草或落叶覆盖。划定冬季收获区段，保证通道畅通 |

&nbsp;&nbsp;&nbsp;这张表中最重要的两行是4月和8月。4月如果不把越冬的大葱收完，花茎就会抽出，全部不能用了。8月的秋季播种如果不守时期，就会因过早抽薹而导致次年的收成消失。这两件事晚了几天，当时并看不出问题，几个月后才显现结果，所以初次种植的人最常错过。

&nbsp;&nbsp;&nbsp;此外，6月、7月、8月这三行，是把大葱变成大葱的作业。没有培满三次土的大葱，更接近小葱；培了三次土的大葱，则有粗壮洁白的葱柱。每月一次，三次铲土，造就了这种差别。

&nbsp;&nbsp;&nbsp;最后，3月和9月的分蘖株分株，决定了这种作物的自立。对于种子保存不了1年的作物，在田里把活着的植株分开栽种的这两次作业，就是种子的贮藏。
