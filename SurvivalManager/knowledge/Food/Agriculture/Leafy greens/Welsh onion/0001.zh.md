- 来源: 韩国农村振兴厅 农事路（Nongsaro）、韩国国家标准食品成分表、FAO ECOCROP、Wiki、Gemini、Claude、Chat-GPT

---
## 引言
&nbsp;&nbsp;&nbsp;大葱（Allium fistulosum）是石蒜科葱属的二年生草本，但靠人的介入——花开前收获、培土使白色部分变长、把从旁边分出的子株切下来重栽——能在田里延续2-4年（持续性S）。综合等级为C（44.2分，有效183种中第68名），长期B（44.4）高于短期C（44.0），副食为SS（61.0分）。最大的弱点是收获速度D，从播种到收获要200天以上，灾难开始之后再种，当年什么也得不到。作为交换，它能在田里立着越冬，耐到零下10℃，需要时一棵一棵拔来用，并且是具备蛋白质密度SS和微量营养素A（15种）的像样蔬菜。其他弱点是施肥C（每㎡30g）、湿害、种子寿命D（常温不足1年）。大葱是要提前种下，并靠分蘖株分株重栽来延续的作物。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | C | 44.2 |
| 短期 | C | 44.0 |
| 长期 | B | 44.4 |
| 副食 | SS | 61.0 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：蛋白质密度、设施负担、烹调·加工要求度、温度幅度、国内种植普及度。S：持续性、耐寒性、连作适应性。A：微量营养素、整地·挖掘能量、产量稳定性、自留种。B：水消耗量、光照、病虫害压力、防治自立度 |
| 劣势 | D：收获速度、耐储性、非食用价值、口味、种子寿命。C：单位面积热量、施肥、无合成投入产量保持率 |

> **大葱不是灾难开始之后种下、当年就能吃到的作物。在灾害应对中，大葱的价值只有在它已经立在田里时才成立。**

&nbsp;&nbsp;&nbsp;综合得分比韭菜低8分，几乎全来自收获速度D（200天），是马齿苋和蕹菜30天的七倍。耐储性D是因同属的FAO储存损失率6.50%而下调一级的数值，无电力常温下一个月远长于羽衣甘蓝的1周。整地·挖掘能量A的热量回收倍数为43.0倍，连作适应性S的依据是葱属为不易受连作危害的类群。口味D是气味和香气令人抵触的判定，没有计入作为香料添加到其他食材中的用途。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 石蒜科葱属二年生草本。学名fistulosum意为中空的管，与叶扁平且实心的韭菜区别开来。原产于中国西部到西伯利亚的寒冷内陆 |
| 叶、葱白 | 叶为中空圆筒形，表面的白色蜡质层使水珠滚落。葱白是叶鞘层层叠起的白色部分，不是真正的茎，真正的茎是最下面的扁平圆盘。与洋葱不同，它不膨大鳞茎，而是把叶鞘向上堆叠 |
| 根、花 | 白色须根集中在深20-30cm处。花为白色至淡紫色的球形，在第二年春天开放 |

> **被土盖住的部分得不到光，不制造叶绿素，保持白色。葱白的长度不是植物自己决定的，而是由人培了多少土决定的。**

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 育苗期 | 播种后40-60天 | 一片线状的叶弯曲着长出，真叶增多 |
| 营养生长期、收获适期 | 定植后1-6个月 | 叶增多，葱白变长、变粗、变硬 |
| 抽薹、结实 | 第二年春 | 花茎抽出，结出种子 |

&nbsp;&nbsp;&nbsp;抽薹发生在幼苗长到铅笔粗细（直径6-7mm）以上、又经历一段13℃以下低温的情况下，花茎会贯穿葱白正中，使其无法食用。每100g热量23-34kcal，蛋白质1.78g（占热量的31.0%），碳水化合物5-7g，糖类2.63g，钾181mg，维生素A和K集中在绿叶中，所以丢掉叶子在营养上是损失。硫化合物在组织受伤时生成，是气味、抗菌作用和辛辣味的来源，怕热，所以加热后会出甜味。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽适温20℃上下，生长适温20℃左右，25℃以上则生长变慢、病害增多。可耐零下10℃露地越冬，枯干的外叶保护内部，所以冬天不要剥掉。中部以北或寒冷年份要培土并盖稻草 |
| 光 | 遮光40%仍保持产量的86%。光不足则叶下垂、组织变软而易倒伏 |
| 水、土壤 | 土层深、排水好的土地，pH 5.7-7.4。总蒸散量约550mm，相对耐旱 |

> **整片大葱全军覆没的原因几乎总是积水。在雨季被淹几天的田里，长成的大葱会从基部变软倒下。**

| 类型 | 特点 |
|:---|:---|
| 独秆葱（茎葱） | 不分蘖，葱白长而粗，必须培土。单棵体积大，储存效率好，但拔掉就完了，所以每年都需要种子 |
| 叶葱（分蘖葱） | 分蘖8-10个以上，葱白短而细，不需要培土。靠分株延续而无需种子，适合土层浅或砾石多的土地 |
| 朝鲜大葱（地方品种） | 分蘖和葱白居中，越冬可靠，适应当地气候，适合中部以北 |

&nbsp;&nbsp;&nbsp;指望不上种子供应的话选叶葱和朝鲜大葱，目的是冬季储存资源的话选独秆葱，现实中两个类型一起种。真正的自立手段不是种子而是分蘖株，所以比起是F1还是固定品种，分蘖程度更重要。

## 4. 整地、播种与定植
| 项目 | 标准 |
|:---|:---|
| 整地 | 耕20-30cm深并拣出石块。垄距独秆葱75-85cm、叶葱1.5m，放宽以备培土用的土，挖深15-20cm的沟，种在沟底 |
| 施肥（1,000㎡） | 氮相当于尿素25kg，磷相当于钙镁磷肥6.6kg（全量作基肥），钾相当于氯化钾14kg，腐熟堆肥1,500kg。追肥在定植后每隔1个月共3次，与培土同时进行，先把肥料放进沟里，再培土 |
| 替代资源 | 稀释8-10倍的人尿（培土前倒入沟中并盖土）、腐熟堆肥（未腐熟的会招来葱蝇）、草木灰（培土前往沟中撒一两把）、发酵过的油饼 |

| 栽培类型 | 播种 | 定植 | 收获 |
|:---|:---|:---|:---|
| 春季栽培 | 3月初-4月底 | 5月初-6月底 | 9月中旬-翌年4月底 |
| 秋季栽培 | 8月底-9月底 | 10月初-11月底 | 翌年4月中旬-5月底 |

> **秋季栽培中守住播种时间尤其重要。播得太早，冬前幼苗超过铅笔粗细，经历低温后花芽分化，翌年春天就只会抽出花茎。**

| 步骤 | 方法 |
|:---|:---|
| 育苗 | 在苗床撒播或按10cm间隔条播，深5-6mm。20℃下7-10天发芽，培育40-60天，保持表土不干。拣出浮起的种子，放在50℃上下的温水中浸泡，但超过60℃种子就会死 |
| 定植 | 真叶4-5片、茎粗5-7mm时（太细经不起移栽，太粗则有抽薹风险）。株距独秆葱7-12cm、叶葱12-15cm，每处2-3株，仅盖住根部（约3cm），斜放在沟底种下，压实土并浇水 |

&nbsp;&nbsp;&nbsp;不深埋，是因为生长点就在底部圆盘的正上方，埋深了新叶会费力或腐烂，葱白是在生长过程中一点点培土做成的。

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种至育苗期 | 发芽前每天浇水使表土不干，育苗期每2-3天一次 |
| 定植刚结束 | 每周2次，浇足 |
| 缓苗后的生长期 | 每周1次，一次浇透（浅而频繁的浇水会使根变浅），培土之后再浇一次 |
| 越冬期 | 不浇（湿土结冰会伤葱白） |

&nbsp;&nbsp;&nbsp;大葱遇旱只是生长变慢，不会轻易死去，所以需要节约用水时，可以把它的灌溉排到后面。

| 培土 | 时期 | 高度 | 备注 |
|:---|:---|:---|:---|
| 第1次 | 定植后1个月 | 5-6cm | 把肥料放进沟里，再在上面培土 |
| 第2次 | 第1次后1个月 | 10cm | 同上 |
| 第3次 | 第2次后1个月 | 盖住叶片分叉处约10cm | 同上 |
| 收尾 | 收获前3-4周、越冬前（10月下旬） | 视需要 | 兼作冬季保温 |

> **葱白的长度和粗细不是由种子决定的，而是由人培了几次土、培了多少决定的。一次都没培过土的独秆葱接近小葱。**

&nbsp;&nbsp;&nbsp;最重要的基准线是叶片分叉的位置，盖住这里，泥土和水会渗入叶鞘之间而引发软腐病。所以要配合大葱生长的速度分三次培土，并使用连晴几天后松散的干土（湿土会板结，空气不通）。培土一次就同时做成葱白、埋下肥料、除掉杂草，而叶子窄、盖不住地面的大葱抗草能力弱，所以头一两个月的除草不能偷懒。

| 管理 | 方法 |
|:---|:---|
| 分株 | 早春（3-4月）或秋季（9-10月），把基部分出多棵的株整丛挖起，分成一棵一棵，或两三棵一组。剪去约一半的叶，修整长根的根尖（保持水分平衡），按定植的方式种进新沟。一株分成八棵的话，一半吃、一半重栽，无需种子即可延续 |
| 越冬管理 | 10月下旬完成最后一次培土，12-2月盖5-10cm厚的稻草或落叶（中部以北尤其需要） |

## 6. 病虫害与养分问题
&nbsp;&nbsp;&nbsp;防治自立度B依据的是德国有机洋葱的6篇实证文献，其中霜霉病是葱属的最大制约，不防治的对照区发病严重度为96%。对策是抗性品系、较宽的株距、保证排水，而且叶片受损时主要收获物葱白仍然留着，可起缓冲作用。叶片的蜡质层使液体防治剂流走，所以要加极少量的肥皂（每1L水加无香肥皂20g）作展着剂。

| 病虫害 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 霜霉病、锈病、叶枯病、黑斑病 | 灰色霉层和黄色条纹（低温高湿） / 橙色粉状斑点（雨季、氮过多） / 黑斑（通风差、高温高湿） | 保证排水、通风和株距，把病叶带出田外烧掉或深埋，补充钾 |
| 软腐病 | 葱白内部变软并有恶臭。过湿、伤口、泥土进入叶间时 | 无法治疗。靠排水和培土高度预防 |
| 黑腐菌核病 | 基部腐烂并出现黑色颗粒。低温高湿、连作 | 该地块数年不种葱属 |
| 葱蝇 | 幼虫啃食基部和地下部使植株死亡。由未腐熟的堆肥引起 | 只用腐熟堆肥，在基部撒草木灰，防虫网 |
| 甜菜夜蛾、葱蓟马 | 啃食叶片 / 叶上出现白斑（高温干燥） | 徒手捉卵块和低龄幼虫 / 避免干燥 |

&nbsp;&nbsp;&nbsp;软腐病在葱白内部发展，外表看不出来，所以等到外叶发黄、葱秆倾斜时已经晚了。

| 症状 | 原因与对策 |
|:---|:---|
| 整片叶浅绿且短，葱白细 | 缺氮。把稀释8-10倍的人尿在培土前倒入沟中并盖土 |
| 叶片异常大而软、倒伏、锈病严重 | 氮过量、缺钾。停止施肥并加入草木灰 |
| 葱白不增粗而叶子徒长 | 培土不足或密植导致光照不足。不是营养问题，所以检查培土和位置 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 胡萝卜（彼此的气味驱赶蝇类，所以行与行交替种）、番茄、茄子、辣椒（根系分泌物抑制枯萎病和疫病）、生菜、菠菜（利用垄间） |
| 差 | 豆科作物（大豆、豌豆、菜豆：葱属的分泌物抑制根瘤菌，使固氮减少）、同属的葱属（韭菜、大蒜、洋葱：病原菌和害虫一起积累） |

&nbsp;&nbsp;&nbsp;问题在于豆科和大葱同一时期并排种，而在收获大豆并埋下残茬的地块种大葱，这个顺序反而有益。连作适应性S的依据是葱属为不易受连作危害的类群，同一地块连续种也行，土传病害的密度还会下降。不过出现过黑腐菌核病的地块要休耕数年，葱蝇危害严重的地块要休耕一年并改进堆肥管理。因为冬天也要拔来用，所以土层深、石块少、积雪较少而便于接近的地方比较合适。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 小葱在定植后40-50天（虽细但可直接吃），中葱2-3个月，大葱3-6个月（葱白粗而结实时）。冬季收获从霜降后到翌年春按需进行，截止期是春天花茎抽出之前 |
| 方式 | 连根拔起（完整获得葱白，但那株就完了） / 只割叶（留离地面3-4cm，会长新叶但得不到葱白） / 掰取分蘖株（挖起一丛分开，只吃一半，其余重栽） |
| 冬季使用 | 秋天不拔长足的大葱，需要时一棵一棵拔。冻土要先把旁边挖松，敲开冰和土再提起。3月底-4月见到花茎迹象时，把剩下的一次拔光，晒干或腌渍 |
| 处理 | 抖掉泥土，只剥掉一两片干枯或受损的外叶。只洗马上要用的（洗过的容易坏），要储存的不剪根。绿叶不要扔，晒干备用 |

> **对大葱来说，关键不是什么时候收，而是能留到什么时候。长成之后仍立在田里越冬，这种状态本身就是储存。**

| 留种 | 标准 |
|:---|:---|
| 障碍 | 二年生，必须越冬并等到第二年春天抽薹，那一株的葱白就不能吃了。异花授粉，会与附近别的葱属混杂，种子寿命不足1年 |
| 防杂交 | 与其他葱属的留种株相距500m以上，或罩上网并用毛笔转移花粉。小块田里当年只让一种开花，其余的剪掉花茎 |
| 采种方法 | 秋天把最粗、最直、无病的几株做上记号，不拔，让它越冬（多盖土）。4-5月抽薹，5-6月开白色球形花。豆荚变褐干燥、有些裂开时连花茎一起割下，倒挂并在下面铺布接住。用水浸泡捞去浮起的空瘪种子，把沉底的种子立即彻底晒干 |
| 保存 | 常温密封不足1年。放在凉爽干燥处的密封容器中，加草木灰或木炭。种子只采当年要用的量，把分蘖株分成几处种下就是储备 |

## 9. 储存
&nbsp;&nbsp;&nbsp;耐储性虽为D，但在无电力的常温下可放一个月，也可以立在田里越冬储存。

| 方法 | 步骤与期限 |
|:---|:---|
| 留在田里 | 从秋天到翌年抽薹前。到零下10℃都原样，更冷则盖稻草 |
| 重新埋入土中 | 两三个月。连根拔起，斜放在凉爽背阴的土里，使葱白被盖住（带着根，所以保持活着） |
| 立放在凉爽处 | 2-4周。放倒的话叶会弯曲而坏得快 |
| 干燥 | 抖掉泥土、洗净并彻底沥干后，叶切成3-5cm，葱白斜切薄片或切圈晒干。磨成粉与盐混合就成了调味料。香气大部分会散失，所以在阴凉处慢慢晒干，干透后立即密封 |
| 腌渍 | 大酱腌渍（数月）、葱泡菜（凉爽处1-2个月）。硫化合物有抗菌作用，所以盐少也不会坏 |

## 10. 烹调与注意事项
| 方式 | 内容 |
|:---|:---|
| 生吃 | 洗净切丝凉拌或作配菜。辣味和维生素C完整保留 |
| 葱油 | 把切好的大葱放在油里小火慢炒，使香气转入油中。一勺就能给好几顿饭增味 |
| 烤 | 整根烤的话，辣味成分分解，糖分显现，变得很甜。扔进炭火余烬里，再剥掉烧焦的外皮 |
| 煎饼、干燥粉 | 拌进面糊煎 / 兼作储存和调味 |

> **大葱烹调的关键分为两点。要香气就最后放，要甜味就从一开始久煮。同一种食材做着两件完全不同的事。**

&nbsp;&nbsp;&nbsp;维生素A和K只存在于绿叶中，所以叶子要切碎放进汤里，或晒干磨粉使用。

| 风险 | 内容 |
|:---|:---|
| 过量摄入、空腹生吃 | 硫化合物刺激胃黏膜，引起烧心 |
| 狗、猫、家畜 | 整个葱属会破坏红细胞而引起贫血。牛和马吃多了也一样，所以不要把含大葱的剩饭给它们 |
| 相似的毒草 | 在野外找葱属时，会与水仙、夏水仙类（地下部像洋葱；呕吐、腹痛）或铃兰（呕吐、心跳异常）混淆。切开的叶子没有气味，叶子扁平且实心 |

> **切下一片叶子搓一搓，如果没有葱或蒜的气味，就不是葱属。仅这一项确认，就能筛掉几乎所有长得像葱属的毒草。**

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 把立在田里的大葱按需拔来用，检查覆盖物 |
| 3-4月 | 3月春播、分株。4月管理育苗，越冬的大葱在花茎抽出前全部收完 |
| 5-6月 | 5月春季定植，留种株的花茎原样保留。6月第1次培土（把肥料放进沟里再培土），雨季前整修排水沟 |
| 7-8月 | 7月第2次培土，观察霜霉病和锈病。8月第3次培土，月底起秋播，检查甜菜夜蛾卵块 |
| 9-10月 | 9月开始收获春季种的大葱，分株。10月秋季定植，最后一次培土 |
| 11-12月 | 11月施以钾为主的越冬肥。12月盖稻草或落叶，并保证通往冬季收获区的通道 |

&nbsp;&nbsp;&nbsp;最重要的两行是4月和8月。4月不把越冬的大葱收完，花茎就会抽出而全部废掉；8月底以后的秋播如果错过时间，就会因提前抽薹而使翌年的收成泡汤。3月和9月的分株是这种作物的自立，也就是种子储存。

> **灾难开始之后再种什么也得不到，但已经立在田里的大葱，会成为整个冬天都不结冻的仓库。大葱是要提前种下，并靠分株重栽来延续的作物。**
