## 8. 栽培管理 - 培土与分蘖

### 8-1. 培土的原理

&nbsp;&nbsp;&nbsp;培土，就是把土盖到正在生长的大葱基部、一层层堆高的作业。这是大葱栽培中最重要的管理，实际上正是这项作业把大葱变成了大葱。

&nbsp;&nbsp;&nbsp;原理很简单。植物的叶子见光就会生成叶绿素而变绿，见不到光就不生成叶绿素，保持白色。大葱的叶鞘层层叠成的圆柱，被土埋住的部分见不到光，因此保持白色，这部分就成了葱白。土堆得越高，葱白就越长。

&nbsp;&nbsp;&nbsp;不过，白色只是结果，对人来说有意义的变化另有所在。没有见光的组织会少生成坚韧的纤维，转而积累糖分。葱白之所以柔软、有甜味，原因就在这里。绿叶辛辣而坚韧，白色部分却让人觉得柔软而甘甜，这种差别正是由此而来。

> **葱白的长度和粗细不是由种子决定的，而是取决于人培了几次土、培了多少土。一次土也没培过的单茎葱，更接近小葱。**

### 8-2. 培土的时期与高度

| 次数 | 时期 | 培土高度 | 同时进行的作业 |
|---|---|:---:|---|
| 第1次 | 定植后1个月 | 5-6cm | 把肥料施入沟中，再在上面培土 |
| 第2次 | 第1次后1个月 | 10cm | 施肥后培土 |
| 第3次 | 第2次后1个月 | 以叶片分叉处被盖住10cm左右为度 | 施肥后培土 |
| 收尾 | 收获前3-4周或越冬前 | 视需要而定 | 兼作冬季保温 |

&nbsp;&nbsp;&nbsp;最重要的基准线是叶片分叉的位置。大葱的叶鞘组成圆柱，到了某个高度，叶片向外分叉长出，这个分叉处不能被土盖住。一旦那里进了土，土和水就会渗进叶鞘之间的缝隙，在这个潮湿又不通气的空间里，软腐病就会开始发生。

| 错误的培土 | 结果 |
|---|---|
| 开始过早 | 还幼小的植株被土压住，生长迟缓 |
| 一次培得太高 | 叶片分叉处被埋住，发生软腐病 |
| 培得太浅 | 葱白短，可食部分少 |
| 培湿土 | 土壤板结，不通气 |
| 不施肥只培土 | 新根长出来也没有养分可吸收 |

&nbsp;&nbsp;&nbsp;分三次、每次少量地培土，原因就在这里。一次盖上30cm，似乎能让葱白变长，但在这个高度，叶片分叉处早已被埋住了。大葱生长时，叶片分叉的位置也会随之上移，所以必须跟着这个变化一点点地盖土。把它看作让人培土的速度与植物生长的速度相匹配的作业，就很准确。

&nbsp;&nbsp;&nbsp;还要强调一下“要培干土”这个条件。刚下过雨就培湿土，土会结成块，不通气，葱白就会受损。连续几个晴天、土变得松散的时候，才是培土的最佳时机。

### 8-3. 分蘖株的分株

&nbsp;&nbsp;&nbsp;评价表中的持续性S，实际上就是靠这项作业实现的。大葱虽是二年生，但把分蘖的植株掰下来重新栽种，不需要种子也能代代延续。

| 项目 | 内容 |
|---|---|
| 时期 | 在韩国为早春（3-4月）或秋季（9-10月） |
| 对象 | 基部分出多棵的植株 |
| 方法 | 把整丛挖出来，用手掰开 |
| 分株单位 | 单棵，或两三棵一组 |
| 修整 | 剪去约一半的叶子，修齐过长的根尖 |
| 重新栽种 | 按定植的方式栽到新沟里 |

&nbsp;&nbsp;&nbsp;剪掉约一半叶子再栽的原因，与韭菜相同。移栽时根被切断，吸水能力下降，如果叶子原样保留，蒸发出去的水分就多于吸进来的水分，植株就会干枯。减少叶量，就是为了让两者保持平衡。

&nbsp;&nbsp;&nbsp;这个循环带来的结果，对灾害应对很重要。一株分成八棵，其中一半吃掉，一半重新栽种。到了第二年，这一半又会分成许多棵。这是一种不需要种子袋、田地自己生产种苗的结构，正面绕开了种子寿命D这一弱点。

| 次数 | 时点 | 结果 |
|---|---|---|
| 首次定植 | 0年 | 一株 |
| 第1次分株 | 1年 | 三四株，其中一半食用 |
| 第2次分株 | 2年 | 十来株 |
| 第3次分株 | 3-4年 | 一块地 |

### 8-4. 杂草与越冬管理

| 时期（韩国） | 作业 | 理由 |
|---|---|---|
| 生长初期 | 趁杂草幼小时拔掉 | 大葱叶子窄，盖不住地面，不耐杂草 |
| 每次培土时 | 培土时顺带把杂草埋掉 | 杂草管理与培土合为一项作业 |
| 10月下旬 | 完成最后一次培土 | 葱白被土盖住，起到保温作用 |
| 11月 | 以钾为主施肥 | 提高耐寒性 |
| 12月至2月 | 盖上稻草或落叶 | 在韩国中部以北尤其需要 |
| 整个冬天 | 需要时一棵一棵拔 | 田地就是贮藏库 |

&nbsp;&nbsp;&nbsp;培土同时兼顾杂草管理，是大葱栽培讲究效率的一面。把沟里的土刮起来堆到基部的过程中，那里的幼小杂草会被一起埋掉，或者连根被切断。一次作业就能同时完成三件事：培出葱白、把肥料埋进去、清除杂草。

&nbsp;&nbsp;&nbsp;大葱不耐杂草，这一点也值得了解。叶子细，又只向上直立，盖不住地面，所以株间的空地上阳光直接照进来。像马齿苋这样贴着地面蔓生的草一旦侵入，转眼就会被覆盖。如果前期一两个月疏于除草，之后就很难下手了。

## 9. 病虫害 - 不用农药的防治方法

### 9-1. 主要病害

| 病名 | 症状 | 条件 | 不用农药的应对 |
|---|---|---|---|
| 霜霉病 | 叶上出现灰色霉层和黄色条纹，叶片折断 | 低温高湿，春秋季 | 保证排水和通风。清除病叶 |
| 锈病 | 叶上出现冒出橙色粉末的斑点 | 韩国的梅雨季（6月下旬至7月）、氮过多 | 把病叶移出田外。补充钾 |
| 软腐病 | 葱白内部烂软，发出恶臭 | 湿度过大、伤口、土进入叶片之间 | 无法治疗。靠排水和培土高度来预防 |
| 叶枯病 | 从叶尖开始干枯，出现黑点 | 通风不良 | 清除病叶，加大种植间距 |
| 黑斑病 | 叶上出现椭圆形黑色斑点 | 高温高湿 | 清除病叶 |
| 黑腐菌核病 | 基部腐烂，长出黑色颗粒 | 低温高湿、连作 | 这块地多年不种葱属植物 |

&nbsp;&nbsp;&nbsp;评价表中的防治自立度B，是依据德国有机洋葱实证文献六篇评定的数值，在这些文献中，霜霉病被指为葱属的最大制约。无防治对照区发病严重度为96%这一数字，意味着不用药几乎全部都会发病。大葱的情况也一样。

&nbsp;&nbsp;&nbsp;不过，重要的是这些文献提出的应对措施并不是药剂。使用抗性品系、加大种植间距使空气流通、保证排水，仅此而已。这些都是没有药也能做的事，这三者虽然不能完全阻止发病，但能大幅减缓病情发展的速度，缩小受害规模。

&nbsp;&nbsp;&nbsp;此外，与叶菜不同，大葱即使叶子受损，仍有可吃的部分留下，这起到了缓冲作用。因霜霉病叶子损伤一半，葱白往往仍然完好，而葱白正是大葱的主要收获物。这与羽衣甘蓝叶子受损就等于全部损失不同。

### 9-2. 主要害虫

| 害虫 | 危害 | 时期 | 不用农药的应对 |
|---|---|---|---|
| 葱地种蝇 | 幼虫啃食基部和地下部，使植株死亡 | 春季、秋季 | 不用未腐熟的堆肥。把灰撒在基部 |
| 葱潜叶蝇 | 在叶内钻蛀隧道，形成白色条纹 | 春季、秋季 | 清除受害叶。罩上防虫网最可靠 |
| 甜菜夜蛾 | 幼虫啃食叶片并钻进叶内 | 夏季至秋季 | 用手捉卵块和幼龄幼虫 |
| 葱蓟马 | 叶上出现白色斑点，变成银白色 | 高温干燥期 | 注意不要让环境干燥。蓝色粘虫板有帮助 |
| 根螨 | 附着在地下部吸取汁液，引起腐烂 | 过湿时 | 改善排水，清除病株 |

> **大葱的害虫中，真正能把植株弄死的只有葱地种蝇一种。而招来这种虫子的最大原因，就是未腐熟的堆肥。**

&nbsp;&nbsp;&nbsp;在没有化肥、必须依赖堆肥的灾害情况下，这一点尤其危险。堆肥稀缺时，人就会想把没沤透的也拿来用，可在大葱上，这等于是把葱地种蝇招进了田里。这种虫子的成虫闻到腐烂有机物的气味就会飞来，在附近的土里产卵。堆肥不够时，宁可减少用量，也不要使用未腐熟的。

&nbsp;&nbsp;&nbsp;对甜菜夜蛾，用手捉的防治办法比较有效。雌蛾把卵成块产在叶上，所以抹掉一块卵，就相当于消灭了几十只。幼虫长大钻进叶内后，手就够不着了，所以要领是不要错过幼虫还小、聚集在叶表面的那段时间。

### 9-3. 不用农药的防治

| 方法 | 制作与使用方法 | 对象 |
|---|---|---|
| 保证排水 | 把垄做高，把沟挖深 | 软腐病、霜霉病、根螨、葱地种蝇 |
| 保证种植间距 | 遵守株距，不密植 | 霜霉病、叶枯病 |
| 只用腐熟堆肥 | 沤到不发热、有泥土气味为止 | 葱地种蝇 |
| 草木灰 | 过筛后撒在基部周围和叶上 | 葱地种蝇、蛞蝓。兼供钾 |
| 清除病叶 | 移出田外烧掉或深埋 | 锈病、霜霉病、黑斑病 |
| 肥皂水 | 1L水加20g无香料肥皂 | 蚜虫、螨 |
| 大蒜稀释液 | 100g大蒜加1L水磨碎，过滤后使用 | 驱避害虫 |
| 桂皮浸出液 | 50g桂皮用1L水浸泡后使用 | 驱避害虫、抑制霉菌 |
| 木醋液 | 稀释300-500倍后喷洒 | 预防 |
| 波尔多液 | 用硫酸铜和生石灰配制 | 霜霉病、锈病。仅在有材料时使用 |
| 防虫网 | 春季和秋季罩上 | 葱地种蝇成虫、葱潜叶蝇 |

&nbsp;&nbsp;&nbsp;这里有一个大葱特有的障碍。由于大葱叶表面有蜡质层，液体防治药剂很难附着，会直接流下来。即使喷了肥皂水或木醋液，如果留不在叶上，也就没有效果。解决这个问题的办法是肥皂。肥皂不仅本身对蚜虫起作用，还能降低液体的表面张力，使其在叶面上铺展开来，起到展着剂的作用。使用大蒜稀释液或木醋液时，只要混入极少量肥皂，就能附着在叶上并留住。

&nbsp;&nbsp;&nbsp;还要再次强调，草木灰在大葱田里特别有用。撒在基部周围，表面变干并呈碱性，葱地种蝇的产卵就会减少，同时还能供给钾，提高抗病性和耐寒性。培土前撒进沟里再用土盖住，地下部杀菌和施肥这两件事就一次完成了。

## 10. 营养缺乏与过量

| 症状 | 原因 | 用天然材料采取的措施 |
|---|---|---|
| 整个叶片颜色浅绿且短，葱白细 | 缺氮 | 把稀释8-10倍的尿液在培土前浇入沟中，再用土盖上 |
| 叶片格外大、嫩，容易倒伏 | 氮过多 | 停止施肥。此时对锈病和软腐病的抵抗力变弱 |
| 老叶叶尖开始变褐焦枯 | 缺钾 | 每1㎡撒一两把草木灰 |
| 生长迟缓，叶色深绿并带紫色 | 缺磷 | 施入骨粉和草木灰。低温期也会出现同样的症状 |
| 新叶扭曲，叶尖干枯 | 缺钙 | 把贝壳和蛋壳烧后捣碎施入 |
| 叶脉之间变黄，只有叶脉保持绿色 | 缺镁 | 草木灰中含有镁 |
| 葱白不变粗，只有叶子变长 | 培土不足或光照不足 | 不是营养问题。检查培土和种植位置 |
| 锈病格外严重 | 氮过多、缺钾 | 减少氮，施入草木灰 |

&nbsp;&nbsp;&nbsp;最后两行是大葱特有的项目。第七行是最容易被误当作缺素症状的情形。如果葱白细而叶子偏长，通常不是肥料问题，而是培土不够，或者因密植而光照不足。这时再多施氮，叶子只会更长，组织变嫩，更容易生病。把原因判断错了，损失就会加倍。

&nbsp;&nbsp;&nbsp;第八行显示了病害与营养的联系。氮过剩时，细胞壁变薄，组织变得柔软，在这种状态下锈病和软腐病会急剧增多。钾则相反，能使细胞壁变厚，组织变得结实。所以，如果大葱田里病害严重，在去找药之前，应该先看肥料是否均衡。只施氮、不施钾的田里，病害格外严重的情况很常见。

&nbsp;&nbsp;&nbsp;还要指出，第四行的缺磷症状与低温期的症状分辨不出来。早春地温低时，即使土里的磷充足，根也吸收不了，叶子会带上紫色。气温升高后会自行恢复，所以在韩国的3月和4月看到的紫色，通常等一等就行。

## 11. 间作与轮作

### 11-1. 搭配宜忌

| 搭配 | 作物 | 理由 |
|:---:|---|---|
| 宜 | 胡萝卜 | 胡萝卜的气味驱赶蝇类，大葱的气味驱赶胡萝卜茎蝇 |
| 宜 | 番茄、茄子、辣椒 | 葱属根系分泌物能抑制枯萎病和疫病 |
| 宜 | 草莓 | 长期以来的观察表明可以减少根腐 |
| 宜 | 生菜、菠菜 | 利用畦间空地，互不争夺 |
| 忌 | 豆科作物（大豆、豌豆、菜豆） | 葱属分泌物会抑制根瘤菌 |
| 忌 | 同为葱属的作物（韭菜、大蒜、洋葱） | 病原菌和害虫会一起积累 |

&nbsp;&nbsp;&nbsp;第一行的胡萝卜与大葱的组合，是彼此相互保护的少见情形。危害胡萝卜的胡萝卜茎蝇，是循着胡萝卜的气味找来的，却被葱的气味干扰；危害大葱的葱地种蝇，是循着葱的气味找来的，却被胡萝卜的气味干扰。把两种作物一行隔一行地交替种植，两边的受害都会减轻。这是不用农药的防治方法中效率最高的一种，也不需要额外占用田地面积。

&nbsp;&nbsp;&nbsp;第五行是必须遵守的禁忌。葱属植物释放的含硫化合物，不仅作用于病原菌，也会影响生活在豆科作物根部的根瘤菌。豆类自己固氮的能力来自这种细菌，所以种在大葱旁边的豆子，根瘤不易形成，固氮量减少。在没有化肥的情况下，豆类固氮是维持整块田地地力的支柱，所以避开这种组合，并不只是搭配宜忌的问题。

&nbsp;&nbsp;&nbsp;不过，隔开时间、前后茬安排则不一样。收了豆子、把残茬翻埋入土之后，在那块地上种大葱，大葱就能得到这些氮。问题在于同一时期并排种植，而依次衔接反而有益。

### 11-2. 轮作

&nbsp;&nbsp;&nbsp;评价表中的连作适应性为S，依据是葱属属于连作无害组。在同一块地里接连种植也没有大的危害，反而是种过葱属的地块，土传病害的密度会降低，对下一茬作物有利。

| 情况 | 应对 |
|---|---|
| 正常的连作 | 在同一块地里继续种也无妨 |
| 出现过黑腐菌核病的地块 | 多年不种葱属植物 |
| 葱地种蝇危害严重的地块 | 休耕一年，改进堆肥管理 |
| 拔除大葱后的地块 | 土传病害已经减少，对下一茬作物有利 |

&nbsp;&nbsp;&nbsp;轮作顺序的一个例子是：在收完大葱的地块上种豆科作物以恢复氮素，接着种叶菜或果菜，然后再回到大葱。在这个顺序中，大葱起整理土壤的作用，豆类起补充氮的作用，果菜则享用这些成果。

&nbsp;&nbsp;&nbsp;此外，葱属属于连作无害组这一事实在灾害情况下的价值，也值得单独指出。当田地狭小、没有余力编排轮作表时，能够划定一块地、一直种大葱也无妨的作物很少见。即使计划崩溃，仍有一种只管种下去就行的作物，这本身就是一道安全保障。

### 11-3. 地块布置的实际做法

| 标准 | 内容 |
|---|---|
| 不积水的地方 | 是最优先的条件 |
| 土层深厚、石头少的地方 | 要培土，土就得充足 |
| 畦间能留得宽的地方 | 培土用的土从旁边取 |
| 冬季积雪较少、易于到达的地方 | 是整个冬天要拔来用的地方 |
| 胡萝卜或果菜的畦旁 | 兼有间作的效果 |

&nbsp;&nbsp;&nbsp;第四行是只有大葱才有的标准。大葱在冬天也立在地里，而那时恰恰是最需要它的时候，所以如果种在积雪很深或道路结冰、难以到达的地方，到了真正需要的季节就用不上了。离家近、阳光充足、积雪化得快的地方，最适合冬用大葱。
