## 2. どんな植物か

### 2-1. 分類と原産地

| 項目 | 内容 |
|---|---|
| 学名 | Allium fistulosum |
| 分類 | キジカクシ目（Asparagales）ヒガンバナ科（Amaryllidaceae）ネギ属（Allium） |
| 別名 | パ（ネギ）、ウムパ（室で育てたネギ）、シルパ（細ネギ）。チョクパ（ワケギ）と区別してテパ（長ネギ）と呼ぶ |
| 原産地 | 中国西部からシベリアに至る地域と推定 |
| 生活型 | 二年草。分げつを利用すれば2-4年続けて使えます |
| 繁殖 | 種子と、分げつ株の株分け |

&nbsp;&nbsp;&nbsp;学名のfistulosumは「中空の管」という意味です。長ネギの葉が中空の円筒であるという事実をそのまま指した名前で、これが長ネギをニラと見分ける第一の基準です。ニラの葉は平たくて中が詰まっており、長ネギの葉は丸くて中が空洞です。葉を押してみると、長ネギはぐにゃりとへこみ、ニラはそのまま持ちこたえます。

&nbsp;&nbsp;&nbsp;原産地が中国西部からシベリアにかけての寒冷な内陸であるという点が、長ネギの性格を説明しています。夏が短く冬が長い地域で生き延びるには、二つのことが必要です。一つは寒さに耐える能力、もう一つは、短い夏のあいだに体をつくっておき、冬を越して翌年の春早くに種子を結ぶ時間割です。長ネギの耐寒性Sと二年草という生活史は、どちらもここに由来します。

&nbsp;&nbsp;&nbsp;タマネギと違い、長ネギは鱗茎を太らせません。養分を丸い球として貯める代わりに、葉鞘を幾重にも重ねて上へ伸ばします。その重なった葉鞘がまさに軟白部、白い部分です。この違いが栽培方法を完全に分けます。タマネギは球を育てる農業であり、長ネギは葉鞘を伸ばす農業で、その葉鞘を伸ばす手段が土寄せです。

### 2-2. 形態

| 器官 | 特徴 |
|---|---|
| 葉 | 中空の円筒形。表面に白いロウ質の層があり、水がころころと流れ落ちます |
| 軟白部（偽茎） | 葉鞘が幾重にも重なった白い部分。本当の茎ではありません |
| 茎（茎盤） | 軟白部のいちばん下にある平たい円盤。ここから根と葉が出ます |
| 根 | 白いひげ根。深さ20-30cmに集中しています |
| 花 | 白色から淡い紫色。球状に集まって咲きます。2年目の春 |
| 種子 | 黒くて表面にしわのある小さな種 |

&nbsp;&nbsp;&nbsp;軟白部が本当の茎ではないという点が重要です。長ネギの本当の茎は、いちばん下にある平たい円盤ひとつだけで、その上に見える白い柱は、葉の基部である葉鞘が重なり合ったものです。タマネギの皮をむくと層が出てくるのと同じ構造を、縦に長く引き伸ばしたようなものです。

> **土で覆った部分は光を受けられず、葉緑素をつくらないまま白く残ります。軟白部の長さは、植物が自ら決めるのではなく、人がどれだけ土をかぶせたかによって決まります。**

&nbsp;&nbsp;&nbsp;この事実が、長ネギ栽培のほとんどすべてを説明します。軟白部をつくるのは、種子や品種ではありません。土寄せという作業がつくります。同じ種をまいても、土を三回寄せた長ネギと、一度も寄せなかった長ネギは、まったく別のものになります。第8節でこの作業を詳しく扱います。

&nbsp;&nbsp;&nbsp;葉の表面のロウ質の層も押さえておく価値があります。手でこすると白い粉のようにはがれるその層は、長ネギが水分の蒸発と病原菌の侵入を防ぐためにつくった保護膜です。そのため長ネギの葉には、薬液や石けん水を散布してもよく付着せず、流れ落ちてしまいます。農薬なしで防除をしなければならない状況では、この性質が不利に働きます。第9節で扱います。

### 2-3. 分げつ - 二年草を多年草のように使う方法

&nbsp;&nbsp;&nbsp;長ネギの基部の円盤からは、葉だけでなく新しい株も出ます。横に分かれて出たこの新しい株を分げつと呼び、系統によって分げつの程度は大きく異なります。

| 区分 | 分げつ | 軟白部 | 土寄せ | 利用方法 |
|---|---|---|---|---|
| 一本立ちネギ（茎ネギ） | ほとんどしません | 長く太い | 必須 | 一本ずつ抜いて使います |
| 葉ネギ（分げつネギ） | 8-10本以上 | 短く細い | 不要 | 株分けして続けます |
| 朝鮮長ネギ（在来種） | 中程度 | 中程度 | するとよい | 越冬しながら何年か続きます |

&nbsp;&nbsp;&nbsp;評価表の「永続性S、分げつを利用すれば2-4年継続して収穫」という項目が指しているのは、表の二行目と三行目です。分げつした株を春か秋に切り離して植え直せば、種がなくても株が代々続きます。一株が八株になり、そのうち半分を食べ、半分を植え直す循環ができます。

&nbsp;&nbsp;&nbsp;ここに、災害への備えとしての実際的な判断がかかっています。太くて白い長ネギを得るには、一本立ち系統に土寄せをしなければなりませんが、一本立ちの長ネギは分げつしないので、抜いてしまえばそれで終わりです。毎年種が必要で、その種は1年ともちません。反対に、分げつする系統は軟白部が短く食べられる部分は少ないものの、種がなくても続きます。どちらか一方を選ぶ必要はなく、二つの系統を併せて植えておくのが現実的な答えです。

### 2-4. 生育段階と抽だい

| 段階 | 時期 | 何が起こるか | 主に必要なもの |
|---|---|---|---|
| 発芽・幼苗期 | 播種から30日 | 糸のような葉が一枚、折れ曲がったまま立ち上がります | リン、窒素 |
| 育苗期 | 30-60日 | 本葉が増え、茎が太くなります | 窒素 |
| 定植・活着期 | 定植後1-2週間 | 切れた根が再び出ます | リン |
| 栄養成長期 | 定植後1-3か月 | 葉が増え、軟白部が長くなります | 窒素、カリウム |
| 収穫適期 | 定植後3-6か月 | 軟白部が太くなり、締まります | 窒素とカリウムのバランス |
| 越冬 | 韓国では11月から3月 | 外葉が枯れ、内側と軟白部は生きています | カリウム |
| 抽だい・結実 | 2年目の春 | 花茎が立ち、種子がつきます | リン、カリウム |

&nbsp;&nbsp;&nbsp;最後の行の抽だいが、長ネギ栽培でもっとも注意すべき点です。花茎が立つと、軟白部のまん中を硬い茎が貫き、食べられなくなります。外見は無傷に見えますが、割ってみると、中に木のような芯が通っています。

&nbsp;&nbsp;&nbsp;抽だいが起こるには、二つの条件が重なる必要があります。第一に、苗が一定の太さ以上に育っていること。おおよそ鉛筆の太さ、直径6-7mmが基準線です。第二に、その状態で13℃以下の低温に一定期間あうことです。この二つの条件がそろうと、植物は冬を一度越したと判断して花の準備を始めます。若い苗は、どれだけ寒さにあっても抽だいしません。

> **秋に種をあまり早くまいて、冬の前に苗が太くなってしまうと、翌年の春に食べられないまま花茎だけが立ちます。秋まきの時期を守る理由はここにあります。**

&nbsp;&nbsp;&nbsp;この原理を逆にすれば、採種の方法になります。種を採りたいなら、太く育てた長ネギを冬越しさせればよいのです。第13節で扱います。

### 2-5. 100g当たりの栄養

| 栄養素 | 含有量 | 備考 |
|---|:---:|---|
| 熱量 | 23-34kcal | 資料や部位によって差があります |
| 水分 | 90g前後 | |
| タンパク質 | 1.78g | 熱量に対する割合（P:E）は31.0% |
| 炭水化物 | 5-7g | |
| 糖類 | 2.63g | 加熱すると甘みが際立ちます |
| カリウム | 181mg | |
| カルシウム | 含有 | |
| 鉄 | 含有 | |
| ビタミンA | 緑色の葉に多い | 軟白部にはほとんどありません |
| ビタミンC | 多量 | 軟白部にも相当量あります |
| ビタミンK | 多量 | 緑色の葉に集中しています |
| 葉酸、チアミン、リボフラビン、パントテン酸 | 含有 | |
| 硫黄化合物（アリシン系） | 含有 | におい、抗菌作用、辛味のもと |

&nbsp;&nbsp;&nbsp;この表で注目すべきは、緑色の葉と白い軟白部で成分が異なる点です。ビタミンAとビタミンKは葉緑素とともにつくられるため、緑色の葉に集中していて、軟白部にはほとんどありません。反対に糖類は軟白部のほうが多く、加熱すると甘みが出ます。

&nbsp;&nbsp;&nbsp;ですから、よくあるように緑色の葉を捨てて白い部分だけを使うのは、栄養面では損です。微量栄養素Aという等級をつくった15種のうち、かなりの数が緑色の葉に由来します。災害時には、葉の部分を別に刻んで乾燥させておき、汁物に入れたり粉にしたりするのが合理的です。

&nbsp;&nbsp;&nbsp;硫黄化合物は、組織が傷ついたときに酵素の働きでつくられます。長ネギを切るときに目にしみるのはこの反応のためで、その成分が抗菌作用を持ちます。熱に弱く、長く加熱すると飛んでしまい、その代わり加熱すると辛味が消えて甘みが立ってきます。同じ長ネギが、生で使うときと加熱して使うときで、まったく別の食材になる理由です。

## 3. 栽培環境

### 3-1. 温度

| 区分 | 温度 | 結果 |
|---|:---:|---|
| 発芽可能 | 15-25℃ | この範囲を外れると発芽率が下がります |
| 発芽適温 | 20℃前後 | 7-10日で芽を出します |
| 生育適温 | 20℃前後 | 涼しい気候を好みます |
| 生育可能範囲 | 5-30℃ | 幅25℃。温度適応幅SSの根拠 |
| 高温障害 | 25℃以上 | 生育が遅くなり、病気が増えます |
| 低温での生育停止 | 5℃以下 | |
| 外葉の枯死 | 氷点下10℃未満 | 内側と軟白部は生きています |
| 露地越冬の限界 | 氷点下10℃ | 耐寒性Sの根拠 |
| 花芽分化の条件 | 13℃以下に一定期間 | 苗が鉛筆の太さ以上のときだけ |

&nbsp;&nbsp;&nbsp;生育適温が20℃前後であるということは、長ネギが真夏を嫌うという意味です。韓国の7月と8月の長ネギは、育つことは育つものの、速度が遅く、病気にもかかりやすくなります。べと病とさび病が韓国の梅雨（チャンマ、6月下旬～7月）の時期に集中するのもこのためです。韓国での実際の栽培のリズムが、春に植えて秋に収穫するものと、晩夏に植えて翌年の春に収穫するものの二つに分かれる理由は、ここにあります。

&nbsp;&nbsp;&nbsp;耐寒性Sと露地越冬が、長ネギのもっとも実用的な性質です。氷点下10℃まで畑にそのまま立っていることができ、韓国中部以南では、特別な保護なしで冬を越します。韓国中部以北や、とくに寒い年には、土寄せを十分に行って土で軟白部を覆ってやれば、その土が断熱材となって耐えられます。

&nbsp;&nbsp;&nbsp;外葉が霜で枯れるのを、枯死したものと誤解しやすいものです。実際には外側の数枚が枯れるだけで、内側の葉と軟白部は無事です。枯れた外葉をはがすと、その下から無傷の白い部分が現れます。むしろ枯れた外葉が内側を包んで守る役割をするので、冬のあいだははがさずにそのままにしておくほうがよいでしょう。

### 3-2. 光

| 条件 | 相対収量 | 解釈 |
|---|:---:|---|
| 終日直射光 | 100% | これが基準です |
| 1日6時間以上 | ほぼ100% | 実用上の最低ラインです |
| 40%遮光 | 約86% | 信頼区間61-120%。日照Bの根拠 |
| 半日陰 | 育つことは育ちます | 軟白部が細くなり、葉が長くなります |

&nbsp;&nbsp;&nbsp;長ネギは比較的日陰に強いほうです。40%をさえぎっても収量が86%を保ちます。ただし、長ネギで光が不足したときに現れる症状は、収量の減少だけではありません。光が足りないと植物は光を求めて上へ伸びようとし、その結果、葉が垂れ下がり、組織が軟弱になります。軟弱になった組織は倒れやすく、病気にも弱くなります。

&nbsp;&nbsp;&nbsp;一方で、光をわざと遮ることが長ネギ栽培の核心技術であるという点は興味深いところです。土寄せがまさにその作業です。地上部には日光を十分に当て、地下部は土で完全に覆う、この二つを同時に成し遂げるのが長ネギ畑の構造です。

### 3-3. 水と土壌

| 項目 | 基準 | 備考 |
|---|---|---|
| 土性 | 土層が深く水はけのよい土地 | 土寄せをするには土が十分に必要です |
| 土壌酸度 | pH 5.7-7.4 | 幅は比較的広いです |
| 有機物 | 完熟堆肥をたっぷり | 多肥性の作物です |
| 排水 | 非常に重要 | 湿害にもっとも弱い作物のひとつです |
| 灌水 | 総ET 約550mm | 乾燥には比較的強いです |
| 畝の高さ | 15-20cm以上 | 水はけの悪い土地では25cm |
| 畝の構造 | 溝を深く掘っておきます | 土寄せに使う土をあらかじめ確保することになります |

> **長ネギ栽培を丸ごと失う原因は、ほとんどの場合、水がたまることです。梅雨の時期に数日冠水した畑では、育ち切った長ネギが株元から腐って倒れます。**

&nbsp;&nbsp;&nbsp;長ネギが湿害にとくに弱い理由は、構造にあります。軟白部は葉鞘が幾重にも重なった柱で、その層の間に水がしみ込むと、空気が通らない密閉された湿った空間ができます。軟腐病菌が育つには完璧な条件です。しかも土寄せでその部分を土に埋めてあるので、外から見ても、中で腐っているのかどうか分かりません。地上部が黄色くなって倒れるのを見て初めて気づきますが、そのときにはもう手遅れです。

&nbsp;&nbsp;&nbsp;最後の行の「溝を深く掘る」という項目が、長ネギ畑の特徴です。ほかの作物は畝を立ててその上に植えますが、長ネギは溝を深く掘ってその底に植え、両側の土を少しずつ寄せ入れながら育てます。こうすれば土寄せに使う土を別に運んでくる必要がなく、同時に溝が排水路の役割を果たします。一つの作業で二つの問題を解決します。

&nbsp;&nbsp;&nbsp;土層が深くなければならないという条件も、この構造から出てきます。軟白部を30cm近くにするには、それだけの土が必要で、砂利が多い土地や浅い土地では土寄せができません。そのような土地では、軟白部をあきらめ、分げつする系統を植えて葉を使う方向に切り替えるのが合理的です。
