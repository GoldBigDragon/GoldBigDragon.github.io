## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

&nbsp;&nbsp;&nbsp;蕹菜是旋花科（Convolvulaceae）番薯属（Ipomoea）的多年生蔓生草本。学名为Ipomoea aquatica，种加词aquatica的意思是“水的”。同属植物中有甘薯（Ipomoea batatas）和牵牛花（Ipomoea nil）。把这三种植物并排来看，谱系一目了然：叶子都是心形或箭头形，花都是喇叭形，茎都是匍匐蔓延。只是甘薯朝着在地下根中积累淀粉的方向分化，而蕹菜则朝着漂浮在水面上、把茎伸得很长的方向分化。

&nbsp;&nbsp;&nbsp;这一谱系实际意味着三件事。第一，与甘薯一样，把茎剪下来扦插就能生根。每个节都能长出不定根的能力是整个属共有的特性，蕹菜的繁殖有一半要靠它。第二，与甘薯共有一部分病虫害。把旋花科作物连续种在同一块地里，病原菌就会积累。评价表中连作适应性A所附的“休作2年”说的就是这件事。第三，与牵牛花一样，在白昼变短的条件下开花。在韩国，8月下旬以后白昼开始变短，蕹菜就会抽出花薹，对于收获叶子的人来说，这是收获期即将结束的信号。

&nbsp;&nbsp;&nbsp;原产地是从印度到东南亚、中国南部的热带、亚热带地区的沼泽和河岸边。野生状态的蕹菜至今仍漂浮着覆盖在那一带的水渠和水库水面上。这种出身几乎决定了蕹菜的全部栽培条件。第一，作为热带植物，它不知霜为何物，所以耐寒性是E。第二，它是生活在水面上的植物，身体构造以根被水浸泡为前提。第三，流动或积存的水中总有养分被带来，所以它不需要把根深深扎进土里去挖取养分。这就是它根浅且以须根为主的原因，因此在旱地栽培时，稍微缺水就会立刻萎蔫。

### 2-2. 形态

| 器官 | 特征 |
|---|---|
| 叶 | 长心形至箭头形。有光泽，绿色至深绿色，长5-15cm，互生。因品种不同，分为叶片宽阔的品系和叶片窄长的品系 |
| 茎 | 中空。为直径0.5-1.5cm的圆柱形，节间很长。能浮在水面上，在水面匍匐可延伸数m |
| 根 | 以须根为主，浅浅铺开。接触土壤或水的每个节上都会长出不定根 |
| 花 | 直径3-5cm的喇叭形，白色或浅粉色，内侧带紫红色。在白昼变短的条件下开放 |
| 果实 | 直径1cm左右的蒴果。成熟后变成褐色并干枯，内含2-4粒种子 |
| 种子 | 直径4-6mm的有棱角的颗粒，灰褐色至黑色，种皮坚硬 |

&nbsp;&nbsp;&nbsp;茎是空心的这一事实是这种作物一切特性的出发点，值得单独说明。大多数植物在被水淹的土地上死亡，原因是根得不到氧气。土粒之间的空隙一旦被水充满，空气就被挤出去，而溶解在水中的氧气对根来说远远不够用。根细胞无法呼吸，吸收养分的活动也就停止，这种状态持续几天，根就会腐烂。在韩国的梅雨季（6月下旬至7月）被淹的田里，作物萎蔫死亡，并不是因为水太多，而是因为窒息。

&nbsp;&nbsp;&nbsp;蕹菜用结构解决了这个问题。茎中的空腔，以及一直通到叶柄和根的海绵状通气组织，能把水面上方的空气直接输送到水下的根部。用人来比喻，就相当于潜水员的呼吸管。所以蕹菜的根即使泡在水里也能呼吸。同样的结构还产生浮力，使茎不会下沉，而是浮在水面上向外伸展。

> **蕹菜被水淹没也不会死，原因不是它能很好地耐受水淹，而是它通过茎中的空腔把空气送到根部。**

&nbsp;&nbsp;&nbsp;每个节都能生根这一点，实用意义也很大。在水面上匍匐的茎，无论哪个节碰到水或湿土，都会立刻在那里生根，像一个新的独立个体一样生长。在野外，它就是用这种方式迅速覆盖水面的。在栽培中，这一特性就成了扦插这种繁殖手段，也成了没有种子也能延续到次年的第二条路。

### 2-3. 生育阶段

| 阶段 | 时期 | 核心生理 | 重要营养 |
|---|---|---|---|
| 发芽·幼苗期 | 播种后7天 | 坚硬的种皮吸水开裂，子叶展开 | 磷，少量氮 |
| 营养生长期 | 7-25天 | 茎和叶迅速增加。节间伸长 | 氮，水 |
| 首次收获期 | 25-35天 | 茎长到30-40cm | 氮与钾的平衡 |
| 再生期 | 收获后7-14天 | 剩余节上的侧芽苏醒，长出新梢 | 氮，水 |
| 开花期 | 8月下旬以后 | 白昼变短时抽出花薹，茎变硬 | 磷，钾 |

&nbsp;&nbsp;&nbsp;这张表中值得留意的是各阶段之间的间隔。从发芽到首次收获一个月，此后每隔1-2周重复一次。其他叶菜一个生长季要按两三个月计算，相比之下，时间的单位本身就不同。这种速度在灾害初期的价值，正如前面所说。

&nbsp;&nbsp;&nbsp;理解了再生期的生理，收获的要领就自然明白了。植物的茎尖有生长点，生长点会向下输送激素，抑制下方节上的侧芽苏醒，这叫作顶端优势。把茎尖剪掉后，这种抑制就消失了，剩余节上的侧芽会同时苏醒。所以蕹菜越割分枝越多，增加的分枝就成为下一次的收获物。所谓从基部留下5-10cm，意思就是要留下至少两个节上将会苏醒的芽。

&nbsp;&nbsp;&nbsp;开花期的意义恰恰相反。开始开花后，植物会把身体的资源转向种子。茎的纤维变硬，叶子变小，口味变差。所以，如果目的是吃叶和茎，开花就是必须避免的事故；如果目的是留种，开花则是需要等待的信号。要在同一块地里同时达成两个目的，就必须把植株分开，这正是第13节的主题。

### 2-4. 每100g的营养

| 营养素 | 含量 | 备注 |
|---|:---:|---|
| 热量 | 26kcal | 以韩国国家标准食品成分表的生品为准。根据不同资料，也有按19-20kcal计算的 |
| 水分 | 90%以上 | 茎中的含量高于叶。这是耐储性E的直接原因 |
| 蛋白质 | 1.67-2.5g | 更集中在叶中。相对热量为25.7%，密度较高 |
| 碳水化合物 | 3.2g左右 | 相当一部分是膳食纤维 |
| 膳食纤维 | 1.9-2.1g | 茎的纤维变硬后会更多 |
| 糖类 | 0.66g | 几乎没有甜味 |
| 钾 | 489mg | 在叶菜中属于较高水平 |
| 维生素A（β-胡萝卜素） | 411 μg | 绿色越深含量越多 |
| 维生素C | 24.6mg | 加热后会损失相当一部分 |
| 铁 | 2.4mg | 在叶菜中属于较高水平 |
| 钙 | 87mg | 少于羽衣甘蓝，但数量不少 |

&nbsp;&nbsp;&nbsp;评价表中的微量营养素SS就是由这张表得出的。尤其是铁2.4mg，是值得注目的数值。植物性铁不是血红素铁而是非血红素铁，吸收率本来就低，但有维生素C同时存在时，吸收会大幅提高。蕹菜把铁和维生素C放在同一片叶子里，所以这种组合是自然形成的。不过，在下一段中还要补充一个注意事项。

&nbsp;&nbsp;&nbsp;维生素C不耐热。由于第14节将要讲到的原因，蕹菜是必须煮熟后才能吃的作物，而煮熟后维生素C会损失相当一部分。这是无法避免的损失，但可以减少。用旺火短时间快炒，比长时间煮保留得多得多；焯水的水不倒掉而当作汤汁来用，就能把溶到水里的那一部分找回来。β-胡萝卜素、铁和钾耐热，煮熟后几乎原样保留。

## 3. 栽培环境

### 3-1. 温度

| 类别 | 极限值 | 最适值 | 备注 |
|---|:---:|:---:|---|
| 发芽温度 | 15-35℃ | 20-30℃ | 浸泡一夜后，1-2天即可发芽 |
| 生长温度 | 15-35℃ | 25-32℃ | 评价表中的温度适应幅度C来自最适区间10℃ |
| 高温极限 | 35℃以上 | - | 只要水分充足，超过35℃也能生长 |
| 低温极限 | 10℃ | - | 低于此温度生长停止 |
| 致死温度 | 0℃附近 | - | 一次霜冻地上部就会全部死亡 |

&nbsp;&nbsp;&nbsp;蕹菜的温度特性严重偏向一侧。向高温一侧几乎没有上限。盛夏超过35℃的天气里，只要水分充足，它反而长得旺盛。这与其他叶菜刚过25℃就叶片变老、发苦、抽薹的情形正好相反。生菜、大白菜和菠菜在夏季败下阵来的那段时间，恰恰是蕹菜的鼎盛期。

&nbsp;&nbsp;&nbsp;向低温一侧则极为脆弱。10℃时停止生长，在零上5℃左右叶片开始受损，一旦下霜，当天就完了。由于这一特性，在韩国，蕹菜的露地栽培期被限定在霜冻完全结束的5月中旬到初霜来临的10月初之间。韩国中部比这略短，韩国南部略长。

> **夏季叶菜全面败退的季节，对蕹菜来说却是最好的时节。蕹菜不是春秋蔬菜的替代品，而是填补夏季蔬菜空缺的作物。**

### 3-2. 光照

| 类别 | 标准 | 备注 |
|---|---|---|
| 所需日照 | 每天6小时以上 | 茎粗，叶厚 |
| 最低日照 | 每天4小时 | 能生长，但节间变长，叶片变薄 |
| 40%遮光时 | 相对产量86% | 为叶菜类通用值，是评价表中B级的依据 |

&nbsp;&nbsp;&nbsp;相对耐遮光这一点，适合利用零星空地。在40%的遮阴下仍能保持86%的产量，意味着即使是一整天晒不到太阳的地方也能使用。不过，就蕹菜而言，要充分发挥这一优势，温度也必须配合。背阴处通常比较凉，而凉正是这种作物的弱点。与其选大树的树荫，不如选白天只有半天有阳光的朝南位置，或建筑物之间明亮的阴凉处。

### 3-3. 水与土壤

| 项目 | 标准 | 备注 |
|---|---|---|
| 淹水栽培水深 | 15-20cm | 始终保持这个深度。水干了产量会骤减 |
| 旱地栽培土壤含水量 | 最大持水量的80-90% | 表土不干的状态 |
| 年需水量 | 每㎡1,500L以上 | 以淹水栽培为准，包含渗漏和蒸发 |
| 土壤质地 | 有机质多的壤土、砂壤土 | 对砂土和黏土也能适应 |
| 有机质含量 | 3%以上 | 淹水条件下分解缓慢而积累 |
| 土层深度 | 15-20cm | 根浅，不需要深耕 |
| pH | 6.0-7.0 | 弱酸性至中性 |
| 耐盐性 | 弱至中等 | 半咸水区域的品系有一定耐受力 |

&nbsp;&nbsp;&nbsp;土层可以很浅，这一点看起来可能与评价表中整地·挖掘能耗为C相矛盾。评价表是按全面深耕15cm计算的，其中包含了为淹水栽培把底面整平夯实的作业。如果实际上只做旱地栽培，把表土刨平就足够了。不过在淹水栽培中，如果底面不平，各处水深就不一样，水浅的一侧会干，水深的一侧嫩梢被水淹没而腐烂。如果是不用机械、靠铁锹完成的作业，这一整平工作就是最费力的活。

## 4. 品种

### 4-1. 大致分为两类

&nbsp;&nbsp;&nbsp;蕹菜的品种名称虽多，但按特性可分为两类。一类是适应水中生长的水生型，另一类是在旱地里也长得好的陆生型。这一区分比其他任何特性都重要。

| 类型 | 茎 | 叶 | 适宜环境 | 种子 |
|---|---|---|---|---|
| 水生型（青梗系） | 粗，中空部分大，浮力大 | 宽阔，接近心形 | 淹水、稻田、水边、水培 | 多数品系不易结籽，靠扦插繁殖 |
| 陆生型（白骨系） | 细而硬，直立 | 窄而长，接近箭头形 | 旱地、垄、花盆 | 种子容易成熟 |

&nbsp;&nbsp;&nbsp;不了解这一差异就去弄种子，会吃亏。想利用被水淹的土地而引进蕹菜，手里拿到的却是陆生型，产量就达不到预期。反过来，想种在旱地里却弄来水生型，就得整天忙着浇水。以种子形式流通的大多是陆生型，水生型多靠插穗延续。

### 4-2. 主要品种

| 品种 | 特点 | 产量 | 适宜环境 | 口感 | 主要用途 |
|---|---|:---:|---|---|---|
| 青梗大叶蕹菜 | 叶大而宽，茎粗。在淹水条件下长得最好 | 高 | 湿地、淹水 | 脆嫩 | 炒菜、汤 |
| 中叶青骨柳叶 | 叶片中等大小。适应旱地和水中两种环境 | 中等 | 旱地、湿地均可 | 脆嫩 | 多种用途 |
| 白骨蕹菜 | 茎呈白色。适合旱地栽培 | 中等 | 旱地 | 脆嫩 | 多种用途 |
| 红梗蕹菜 | 茎呈红色。含有花青素 | 中等 | 旱地、湿地均可 | 脆嫩 | 炒菜、韩式鲜拌泡菜（geotjeori） |

### 4-3. 不同情形下如何选择

| 情形 | 适合的类型 | 理由 |
|---|---|---|
| 淹水地、稻田、水排不出去的土地 | 青梗大叶等水生型 | 在被水淹的条件下产量最高 |
| 一般菜园、需要提水浇灌的土地 | 白骨、中叶等陆生型 | 对水的需求相对较少，直立生长，便于管理 |
| 每年都要留种延续的情形 | 陆生型 | 开花结实良好，留种有保障 |
| 靠插穗越冬延续的情形 | 哪种都可以 | 节上生根的能力是共有的 |
| 屋顶、阳台、没有土壤的地方 | 水生型 | 与漂浮在水面上的栽培方式相匹配 |

&nbsp;&nbsp;&nbsp;评价表中的韩国国内栽培普及度为B，也就是说只在韩国的三四个道种植，这一点也要在此一并记住。在非主产区不容易弄到种子，在物流中断的情况下更是如此。趁能弄到手的时候多储备一些种子，这是比较现实的做法，而一旦引进之后，靠扦插和留种这两条路自己延续下去，就是这种作物的自立方式。
