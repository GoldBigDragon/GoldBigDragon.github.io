## はじめに
&nbsp;&nbsp;&nbsp;ヨウサイ(Ipomoea aquatica)は、ヒルガオ科サツマイモ属の多年生のつる草です。茎の中が空洞で根まで空気を送るため、冠水した土地でも枯れません。原産地はインドから東南アジア、中国南部の沼や水路で、韓国では霜で枯れて一年草として育ちます。総合等級はC(41.9点、有効183種中88位)、副食はSS(59.5点)で、冠水地、排水の悪い低地、水を抜けない田など、ほかの作物が枯れる土地でおかずの役割を担う作物です。強みは収穫速度SS(播種後30日)と刈っても再び伸びる永続性A、弱みは耐寒性E(霜が一度降りれば全滅)と貯蔵性E(常温で2-3日)です。植物自体に毒はありませんが、水中の重金属と寄生虫をそのまま取り込むため、最も重要な決定は種ではなく、どの水に植えるかです。

## 1. 災害への備えの評価

|:---|:---:|:---:|
| 総合 | C | 41.9 |
| 短期 | C | 41.7 |
| 長期 | C | 42.1 |
| 副食 | SS | 59.5 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: タンパク質密度、微量栄養素、収穫速度。S: 施肥、自家採種。A: 永続性、施設の負担、調理・加工の要求度、連作への適応性、収量の安定性、種子の寿命。B: 日射、味、国内での栽培の普及度 |
| 弱み | E: 水の消費量、耐寒性、貯蔵性、非食用の価値。C: 面積当たりの熱量、温度幅、病害虫圧、防除の自立度、合成資材を投入しない場合の収量維持率、整地・掘削エネルギー |

> **ヨウサイの水の消費量Eは、この作物が水をたくさん使うという意味でもありますが、すでに水がたまっている土地なら、その水を新たに引かなくてよいという意味でもあります。**

&nbsp;&nbsp;&nbsp;水の消費量Eは湛水栽培で1㎡当たり年間1,500L以上で、漏水と蒸発を含むため、水を汲んできて入れなければならない土地では最悪の選択です。副食SSは熱量が小さいためにタンパク質密度と微量栄養素が大きく計算された値で、面積当たりの熱量C(自給ラインの0.50倍)なので、ヨウサイで腹を満たすことはできません。病害虫圧C(推定感受率50.3%)は同じ目の値を引いてきた推定で、実際には病害虫はとても少ないです。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | ヒルガオ科サツマイモ属の多年生のつる草。サツマイモ、アサガオと同じ属なので、茎を挿すと節から根が出て、病害虫を一部共有し、日が短くなると花が咲く |
| 葉、茎 | 葉は長いハート形から矢じり形で長さ5-15cm。茎は中空の円筒で、空洞と根までつながる通気組織が空気を根に送り浮力をつくるので、水の上を数m伸びる |
| 根、花、果実 | 細い根中心に浅く広がり、水や湿った土に触れる節ごとに不定根が出る。花は白から淡いピンクのラッパ形(直径3-5cm)。種子は殻が硬い |

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 発芽、幼苗期 | 播種後7日 | 硬い殻が水を吸って割れ、子葉が開く |
| 初収穫期 | 25-35日 | 茎30-40cm |
| 再生期 | 収穫後7-14日 | 残した節の側芽が目覚めて新しい芽が伸びる |
| 開花期 | 8月下旬以降 | 花茎が立ち、茎が硬くなり、葉が小さくなって味が落ちる |

&nbsp;&nbsp;&nbsp;茎の先の成長点は下の節の側芽を抑えているので(頂芽優勢)、先を切ると側芽が一斉に目覚め、増えた枝が次の収穫物になります。100g当たり熱量26kcal、水分90%以上、タンパク質1.67-2.5g、炭水化物3.2g、食物繊維1.9-2.1g、糖類0.66g、カリウム489mg、ビタミンA(βカロテン)411μg、ビタミンC24.6mg、鉄2.4mg、カルシウム87mgです。鉄とビタミンCが一枚の葉にあり、植物性の鉄の低い吸収率を補いますが、ビタミンCは加熱するとかなり失われます。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽適温20-30℃(土が20℃より低いとほとんど芽が出ない)、生育15-35℃(最適25-32℃、幅10℃)。35℃を超えても水が十分なら旺盛で、10℃で成長が止まり、5℃前後で葉が傷み、霜が一度降りれば全滅。ほかの葉物が崩れる真夏が最盛期 |
| 光 | 1日6時間以上が適する(4時間だと節が間延びして葉が薄くなる)。40%の日陰でも収量の86%を維持。日陰は涼しく温度の弱点と重なるので、半日日が当たる場所がよい |
| 水、土壌 | 湛水の水深は15-20cmを維持、畑は土壌水分を最大容水量の80-90%に。土の深さ15-20cm、pH6.0-7.0、耐塩性は弱から中 |

| 系統 | 特徴 |
|:---|:---|
| 水生型(チョンギョン系) | 茎が太く中が大きく空洞で浮力が大きく、葉は広いハート形。湛水田、水田、水辺に向く。種子が実りにくく挿し木で継ぎ、チョンギョン大葉は湛水栽培で収量が最も多い |
| 陸生型(ペゴル系) | 茎が細くて硬く真っすぐ立ち、葉は細長い。畑、畝、鉢に向き、種子がよく実る。ペゴル(茎が白い)、ジョッキョン(茎が赤い)、中葉チョンゴル系(畑と水の両方に適応) |

&nbsp;&nbsp;&nbsp;冠水した土地に陸生型を入れると収量が期待に届かず、畑に水生型を入れると水を引く作業に追われます。国内での栽培の普及度がB(三、四つの道でしか栽培されない)で種子を入手しにくいため、手に入れたときに十分確保し、挿し木と採種で自ら継いでいく必要があります。

## 4. 畑の準備、播種、挿し木
| 項目 | 基準 |
|:---|:---|
| 場所選び | 水が抜けない土地が一等地(低地、梅雨に冠水する田の区画、排水路が詰まった隅、雨水がたまるくぼみ)。ただし水の出所を必ず確認 |
| 湛水用の床 | 田のように平らにならす(高低差が3cm以上あると浅い側は乾き、深い側は腐る)。縁に高さ25-30cmの土手を築き、底を踏み固めて漏水を減らす(砂地は粘土を敷いて固める)。植える2-3日前に水を張る |
| 畑の床 | 15-20cmの深さに耕し、低い畝か平らにし(高いと水が早く抜ける)、溝を水路に使う。完熟堆肥をたっぷり入れ、わら、枯れ草、落ち葉を厚く覆うと水やりの回数が半分以下になる |
| 施肥(1,000㎡) | 窒素、リン酸、カリウム各15-20kg、堆肥10トン。植える2週間前に堆肥の全量、リン酸とカリウムの全量、窒素の半分を元肥として入れ、追肥は刈るたびにすぐ窒素を少量 |
| 代替資源 | 木灰(1㎡当たり一つかみ程度、多いとpHが上がる)、完熟堆肥(未熟なものは水を腐らせる)、尿を10-20倍に薄めた液(収穫の2週間前から中止)、草を漬けた液肥の5-10倍液、アヒルや魚を育てた水(糞便汚染の危険) |

| 栽培型 | 播種 | 備考 |
|:---|:---|:---|
| 露地の畑 | 5月中旬-6月 | 霜が完全に終わってから(土が15℃より低いとほとんど芽が出ず腐る)。収穫は6-9月 |
| 露地の湛水田 | 5月下旬-6月 | 水が温まるのを待つ |
| 屋内育苗 | 4月下旬 | 霜が終われば外に出す。6月から収穫 |

| 始め方 | 方法 |
|:---|:---|
| 播種 | ぬるま湯に12-24時間浸す。深さ0.5-1cm、条間20cm(湛水は25-30cm)、株間は最終10-15cm。湛水では水を抜いてまき、土をかぶせ、芽が5cmほどに伸びたら水を少しずつ上げ、芽の先は常に水面から出しておく。初収穫まで25-35日 |
| 挿し木 | 健康で太い茎を15-20cm(節4-5個)に切り、埋める側の葉をしごき取って、3-4節が埋まるように斜めに挿す。水の入れ物に挿すと3-5日で根が見える。活着5-7日(乾かさない)、初収穫まで20-25日 |
| 間引き | 本葉2-3枚で5cm、4-5枚で10-15cm。間引いた若い株は植え替えるか、加熱して食べる |

## 5. 水管理と栽培管理
| 時期 | 湛水栽培 | 畑栽培 |
|:---|:---|:---|
| 発芽、幼苗期 | 水を抜いて土だけ湿らせ、芽の先が沈まない高さまで徐々に上げる | 表土が乾かないように1日1、2回 |
| 栄養成長期 | 15-20cmを維持 | 表土が乾いたらたっぷり、1日1-2回 |
| 収穫の前後 | そのまま維持 | 刈った直後に十分に |

&nbsp;&nbsp;&nbsp;水が十分だと茎は軟らかく、足りないと繊維が硬くなって筋っぽくなります。水不足で花茎が早く立つのは乾燥ストレスが開花を促したもので、採種に利用できます。逆に、若い芽が完全に水没すると数日で溶け、水がよどんで腐ると黒くなって臭い、根が褐変し、浅い水は日中に40℃を超えるほど温まって根が煮えます。水は15cm以上にして、補充は朝に行います。

| 方式 | 特徴 |
|:---|:---|
| 湛水栽培 | 15-20cmの水をためて育てる。収量が最も多く、水が雑草の発芽と土の中の害虫、カビを防ぐので、草取り、水やり、土壌病害虫の労働が一度になくなり、労働は地面を固めるときの一度だけ |
| 畑栽培 | 畝に植えて水をやる。収量は湛水の60-80%で、草取りと毎日の水やりが必要で、根腐病と土の中の害虫がある |
| 浮き栽培 | 深い水でいかだを組み、水草、わら、アシ、腐葉土を載せて挿し穂を挿し、杭や石で固定する。肥料は不要だが、汚染された水の重金属と病原体を直接取り込む |

| 管理 | 方法 |
|:---|:---|
| 摘心、誘引 | 茎が20-25cmのとき先を切って側枝を増やし、茎を均等に広げて風通しを確保する(カビの病気が減る) |
| 蕾の摘み取り | 8月下旬以降、見つけ次第摘むと収穫期間が2-3週間延びる |

## 6. 病害虫と養分の問題
&nbsp;&nbsp;&nbsp;ヨウサイは病害虫がとても少ない作物です。湛水が土の中の害虫と土壌伝染性のカビを排除し、生育期間が30日と短く、刈るたびに葉に付いた害虫も一緒に取り除かれるためです。

| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| べと病、白さび病 | 葉の裏に灰白色のカビや白い膨らみ、表に黄色い斑点。涼しく湿っているとき、混み合っているとき、梅雨 | 茎を整理して風通しをよくする、病葉の除去(ひどければ株ごと除去)、水は根元に |
| 根腐病、立枯病 | 根が褐変して株がしおれる / 若い芽が根元でくびれて倒れる。水がよどんだり腐ったりしたとき、密播 | 畑は排水の改善、湛水は水の入れ替え、密にまかない、未熟な肥料を避ける |
| アブラムシ、ハダニ | 汁を吸って葉が縮れ、すす病が続く / 葉が白っぽくなり、クモの巣状の糸(乾燥時) | 強い水流で洗う、石けん水、天敵を守る / 水をこまめに散布して湿度を上げる |
| ガの幼虫、カタツムリ | 葉をかじる | 夕方に手で捕る、木灰の帯 |

&nbsp;&nbsp;&nbsp;湛水の田では、石けん水のようなものを散布するとたまって根を傷め、魚が先に死ぬので、手で捕って病葉を取り除く方法を優先します。

| 症状 | 原因と対処 |
|:---|:---|
| 下の古い葉から黄色くなり株が小さい | 窒素欠乏。薄めた尿、草を漬けた液肥、完熟堆肥 |
| 新しい葉が黄色く葉脈だけ緑 | 鉄欠乏(pHが高いと土にあっても使えない)。pHを下げ、木灰を減らす |
| 葉だけ茂り茎が軟らかく折れ、虫が集まる | 窒素過剰。窒素を止め、水で洗い流す |
| 葉の縁が枯れ根が褐変する | 肥料の濃度過多。水をたっぷり与えて洗い流す |

&nbsp;&nbsp;&nbsp;古い葉から傷む場合は、植物の体内でよく動く養分(窒素、リン酸、カリウム、マグネシウム)が、新しい葉から傷む場合は、あまり動かない養分(鉄、カルシウム、ホウ素)が足りません。窒素を多く与えた葉物の硝酸塩は亜硝酸塩に変わって乳児に危険なので、天気のよい日の午後に収穫し、肥料を多く与えたものはゆで汁を捨てます。

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | マメ類(ササゲ、リョクトウ)、イネ(畦の内側と水路の場所を使い、イネが熱量、ヨウサイがおかずを担う)、セリ、クレソン(同じ水を使う) |
| 悪い | サツマイモ、アサガオなどのヒルガオ科(病原菌と害虫を共有)、根菜(ダイコン、ニンジン、ゴボウ)、ニンニク、タマネギ(水がたまると腐り、水の要求が正反対) |

&nbsp;&nbsp;&nbsp;連作への適応性Aの根拠はヒルガオ科の2年休作です。畑はヨウサイ → マメ科 → アブラナ科またはウリ科 → ヨウサイの順に、湛水田はヨウサイ → イネまたはヨウサイ → 水を抜いたあとマメ科 → ヨウサイの順に回します。長く水に浸かった土は酸素がなく有機物が腐りにくく、鉄とマンガンが根に有害な形に変わるので、一年は水を抜いて乾かします。

## 8. 収穫と採種、越冬
| 収穫 | 基準 |
|:---|:---|
| 時期 | 初収穫は播種後25-35日、挿し木後20-25日(茎30-40cm)。その後は7-14日ごと(側芽20-30cm)、霜が降りるまで夏のうちに4回以上 |
| 判断 | 長さより硬さが基準。茎を指で押して簡単にへこめば軟らかい。40cmを超えると根元から硬くなり、蕾が見えると繊維が急速に硬くなる |
| 切り方 | 根元から5-10cm(節2、3個)を残し、よく切れる刃物やはさみで斜めに切る(ねじって折ると茎が裂けて病気が入る)。早朝に切ると最もみずみずしく、しおれるのが遅い |
| 収穫後 | すぐ日陰に移し、流水で何度もすすいで水気を切る。硬い根元と傷んだ葉は堆肥に、太くて健全な茎は挿し穂として取り分けておく |

> **ヨウサイの収穫の核心は、どれだけ多く切るかではなく、どれだけ残すかです。残した節の数が次の収穫の大きさを決めます。**

| 継ぐ方法 | 方法 |
|:---|:---|
| 二つの道 | 霜が一度降りれば根まで枯れるので、種子と生きた茎の両方を残し、互いに保険にする |
| 採種 | 特性がはっきりした健康な株を8月初めに決めて刈らずに残す。水を減らすと開花が早まる(開花から結実まで1か月以上かかり、9月に咲くと初霜までに熟さないことがある)。さやが茶色く乾いたら摘んで日陰で乾かし、もんで箕で選別する。自家受粉が中心で品種が混ざりにくい。涼しく乾燥した暗い場所で密閉すれば2-3年 |
| 挿し穂での越冬 | 霜の2週間前に、健康な茎20-30cmを何本か水の入れ物に挿して日の当たる窓辺に置く。10℃より下がらないようにし(5℃より下がると枯れる)、最も暖かい場所に小さな入れ物をいくつかに分け、3-5日ごとに水を替え、伸びた茎は切って挿し直して増やす。霜が終わった5月中旬に、数日間、昼だけ外に出して慣らしてから移す |

## 9. 貯蔵
&nbsp;&nbsp;&nbsp;貯蔵性Eは、水分が90%を超えて組織が軟らかいためです。最も確実な答えは貯蔵しないことで、畑に立っているあいだは傷まないので、その日に食べる分だけ刈ります。貯蔵が必要なのは、霜の直前に残りを一度に処理するときだけです。

| 方法 | 手順と期間 |
|:---|:---|
| 日陰に置く | 洗わず水気を払って日陰に置く。1-2日 |
| 根元を水に浸して立てる | 茎が水を吸い上げる(根元が腐らないよう水をこまめに替える)。2-3日 |
| 干す | 沸騰した湯で30秒ゆで、冷水ですすいで絞り、日陰と風で薄く広げてしっかり干し(容積10%)、密閉。ビタミンCはほとんど失われるので汁物の具向き。6か月-1年 |
| 漬ける | 重量の3-5%の塩で層にして漬け重しをする(2-3か月)、キムチやしょうゆ漬けにする(数か月) |

## 10. 調理と注意事項
| 方法 | 時間と特徴 |
|:---|:---|
| 強火の炒め物 | 2-5分。燃料が最も少なく、ビタミンCが比較的残り、油がβカロテンの吸収を助ける |
| ゆでる、汁物 | ゆでるのは30秒-1分(水溶性ビタミンが抜けるので、そのゆで汁をスープに使う)、汁物や鍋は5分(最後に入れる) |

&nbsp;&nbsp;&nbsp;茎を先に1分ほど火を通し、葉をあとから入れます。硬い茎は斜め薄切りにするか半分に割って入れると食感がよくなります。

| 危険 | 内容 |
|:---|:---|
| 重金属 | カドミウム(工場排水、鉱山排水、リン酸質肥料、下水汚泥: 腎臓と骨の損傷、排出に数十年)、鉛(水道管、塗料、バッテリー、道路の粉じん: 神経系、子どもの脳の発達)、ヒ素、水銀。洗ったり加熱したりして除けず、見た目でもわからない |
| 肥大吸虫、肝蛭、住血吸虫 | 前の二つは被嚢幼虫が水生植物の表面に付き、生で食べると腸や肝臓と胆管に住みつく(下痢、腹痛 / 発熱、右上腹部の痛み)。住血吸虫は水中の幼虫が皮膚を破って入り、素足や素手で水に入る作業中に感染する |
| 糞便汚染の細菌 | 糞便が混ざった水(アヒルや魚を育てた水を含む)で育ったものは特にしっかり加熱する |

> **ヨウサイで最も重要な決定は、種を選ぶときでも肥料をやるときでもなく、どの水に植えるかを決めるときに下されます。その水がどこから来たのかわからなければ、その場所は使わないほうがよいです。**

| 水 | 判断 |
|:---|:---|
| 雨水がたまった場所、井戸水、山から下りてくる渓流水、田の灌漑水 | 比較的安全(田の灌漑水は上流を確認) |
| 河川の下流、都市の排水路、道路脇の水たまり | 避ける(道路の粉じん由来の鉛と生活排水) |
| 工場、鉱山、埋立地の下流側の水、長くよどんだ水、油膜が浮いた水 | 絶対に使わない |

&nbsp;&nbsp;&nbsp;被嚢幼虫は熱に弱く、沸騰した湯で軽くゆでるだけで死ぬので十分に加熱し、すすぐだけでは不十分です。水に入って作業するときは、長靴と衣服で素肌を覆います。シュウ酸はホウレンソウやフダンソウよりずっと少なく、カリウムは100gに489mgなので、腎機能が低下している人はゆでて湯を捨てるほうがよいです。

> **ヨウサイは必ず加熱して食べる野菜です。レタスのように洗ってそのまま食べる習慣をこの作物に当てはめてはいけません。加熱して食べる損失はビタミンCの一部で、加熱しない損失は寄生虫です。**

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 休み。屋内での挿し穂の管理(水替え、10℃以上を維持、伸びた茎を切って挿し直す) |
| 3-4月 | 堆肥の準備、種子の状態確認。4月に湛水田は場所の整理と土手の補修、畑は耕して堆肥を入れ、屋内で育苗を始める |
| 5-6月 | 5月中旬以降に水を張り、播種または挿し木、挿し穂を慣らす。6月に水を15-20cmに維持、マルチ、摘心、初収穫 |
| 7-8月 | 7月に繰り返し収穫、収穫後の追肥、梅雨の風通しの確保、べと病の観察。8月初めに採種用の株を決めて収穫を止め、下旬から蕾を摘む |
| 9-10月 | 9月に採種株の花とさやを観察し、水を減らして開花を助ける。10月に初霜前に収穫を終え、種子を集め、挿し穂を取り込み、残りをゆでて干す |
| 11-12月 | 11月に湛水田は水を抜いて地面を乾かし、畑は残った茎を堆肥にし、種子を保管。12月に屋内での挿し穂の管理を始める |

&nbsp;&nbsp;&nbsp;ヨウサイの一年は、5か月の畑と7か月の屋内に分かれます。8月初めに採種用の株を分けておかなければ種がなく、10月に挿し穂を取り込まなければ生きた茎がありません。

> **夏の5か月の収穫は、8月初めに何株かを残す判断と、10月に茎を何本か切って取り込む手にかかっています。この作物は、収穫する技術より、継いでいく技術のほうが難しいです。**
