## 13. 採種と越冬 - 翌年につなぐ二つの道

### 13-1. なぜ二つの道なのか

&nbsp;&nbsp;&nbsp;ヨウサイは原産地では多年草ですが、韓国では冬を越せません。霜が一度降りただけで地上部が全滅し、根も生き残れません。したがって、翌年につなぐには必ず何かを残しておかなければならず、残せるものは種子か、生きている茎です。

| 道 | 残すもの | 長所 | 短所 |
|---|---|---|---|
| 採種 | 種子 | 保管が容易で、3年まで持ちます。場所をほとんど取りません | 花が咲いて種子が熟す時間が必要なため、その株の収穫を諦めなければなりません。霜が早く来ると失敗します |
| 挿し穂の越冬 | 生きている茎 | 確実です。翌年のスタートが早くなります | 冬の間ずっと室内で10度以上を保たなければなりません。手間がかかります |

&nbsp;&nbsp;&nbsp;両方やっておくほうが安全です。霜が早く来て種子が熟さないこともあれば、冬に温度を保てず挿し穂が枯れることもあるので、お互いがお互いの保険になります。

### 13-2. 採種

| 手順 | 方法 | 理由 |
|---|---|---|
| 採種株を選ぶ | 病気がなく、茎が太く、品種の特性がよく現れた株を選びます | 種子は親に似ます。良いものから採れば、良いものができます |
| 収穫の中止 | 8月初めからは、その株を刈らずにおきます | 花が咲いて種子が熟すのに時間がかかります。刈り続けると花が咲けません |
| 開花を促す | 水を減らしてストレスを与えます | 乾燥ストレスが繁殖へ向かう引き金になります。日長が短くなる条件と重なると、より確実です |
| 種子を熟させる | さやが褐色に乾くまでおきます | 熟し切っていない種子は発芽しません |
| 収穫 | 乾いたさやごと摘み取り、日陰に広げて乾かします | 直射日光で乾かすと種子が傷みます |
| 種子を取り出す | さやを揉んで砕き、あおって殻を飛ばします | 殻が軽く、風で飛びます |
| 乾燥 | 日陰で完全に乾かします。爪で押して跡がつかなければ乾いています | 水気が残ると、保管中にカビが生え、発芽力が落ちます |
| 保管 | 密閉容器に入れ、涼しく暗い場所に置きます | 湿気、光、熱が発芽力を削ぎます |

| 保管条件 | 発芽力が保たれる期間 |
|---|:---:|
| 涼しく乾燥した暗い場所、密閉 | 2-3年 |
| そのまま常温に置いた場合 | 1-2年 |

&nbsp;&nbsp;&nbsp;評価表の自家採種Sは、ヨウサイが自家受粉中心であることに支えられています。ハチが花粉を運んでも品種が大きく混ざらないため、複数の品種を一つの畑に置いても、種子を品種ごとに別々に採ることができます。アブラナ科の作物が交雑のために採種に苦労するのと比べると、はるかに楽です。

&nbsp;&nbsp;&nbsp;ただし、韓国の気候では、採種には時間の制約があります。日が短くなって花が咲き、その花が散ってから種子が熟すまでにひと月以上かかるため、9月に花が咲くと、10月初めの初霜までに熟せない可能性があります。採種用の株を8月初めから別に分けて管理し、必要なら水を減らして開花を早めるのは、そのためです。韓国南部が有利で、室内で仕上げることができれば、さらに確実です。

### 13-3. 挿し穂の越冬

&nbsp;&nbsp;&nbsp;水生型の品種のように種子がよく熟さない系統では、茎を生かして冬を越させる方法が唯一の道です。

| 手順 | 方法 | 理由 |
|---|---|---|
| 挿し穂を選ぶ | 霜が降りる2週間前に、健康な茎を20-30cmに切って数本用意します | 霜に当たった後ではすでに手遅れです |
| 発根させる | 水を入れた容器に挿し、明るい室内に置きます | 土より管理が容易で、根の状態が目で見えます |
| 温度の維持 | 10℃を下回らないようにします。15℃以上ならさらに良いです | 10℃を下回ると育たず、5℃を下回ると枯れます |
| 光 | 日が当たる窓辺に置きます | 暗いと節間が伸びて弱くなります |
| 水の入れ替え | 3-5日ごとに水を入れ替えます | 水が腐ると茎の株元が軟らかくなります |
| 冬の管理 | 伸びた茎は切って挿し直します | 切って挿し直し続けると個体数が増えます |
| 春の植え付け | 霜が完全に終わった5月中旬に外に出します | 急に外に出さず、数日間、日中だけ外に出して慣らします |

&nbsp;&nbsp;&nbsp;暖房が途絶えた状況で、室内の10℃を保つことは容易ではありません。そのようなときは、人が過ごす空間で最も暖かい場所、つまり台所や火鉢の近くに置き、小さな容器をいくつかに分けておいて、一つの容器が凍っても全部を失わないようにします。種子の保管と挿し穂の越冬を両方行うようにという言葉の実質的な意味が、ここにあります。

> **韓国でヨウサイは、毎年人が受け継がなければ消えてしまう作物です。畑に自然に残るものがないため、秋の採種と冬の挿し穂の管理が、そのまま翌年の栽培の始まりです。**

## 14. 毒性と注意すべき成分 - 水がもたらす危険

### 14-1. 植物自体に毒はありません

&nbsp;&nbsp;&nbsp;ヨウサイという植物自体には、人に有害な毒成分はありません。ジャガイモのソラニン、キャッサバのシアン配糖体、ダイズのトリプシンインヒビターのようなものはありません。ただし、この作物にはほかの野菜にない種類の危険が付いており、その危険は植物ではなく水に由来します。

### 14-2. 重金属の蓄積

&nbsp;&nbsp;&nbsp;ヨウサイは水中の金属イオンを非常によく吸収し、汚染された水の浄化に使えるほどです。問題は、浄化に使えるということが、すなわちその汚染物質が植物体に蓄積するという意味だという点にあります。

| 物質 | どこから来るか | 体にどのように作用するか |
|---|---|---|
| カドミウム | めっき・電池・顔料工場の廃水、鉱山の排水、リン酸肥料、下水汚泥 | 腎臓に蓄積して腎機能を損ないます。骨からカルシウムを奪い、骨が軟らかくなって折れやすくなります。体外に排出されるまでに数十年かかります |
| 鉛 | 古い水道管、塗料、バッテリー、道路の粉じん、銃弾 | 神経系に作用します。子どもの脳の発達を妨げ、大人には貧血と神経障害を引き起こします |
| ヒ素 | 鉱山の排水、木材防腐剤、一部の地下水 | 慢性中毒により、皮膚の病変や複数の臓器の障害を引き起こします |
| 水銀 | 工場の廃水、廃蛍光灯、廃電池 | 神経系を損傷します |

&nbsp;&nbsp;&nbsp;この危険について最も重要な事実は、洗ったり加熱したりしても取り除けないということです。重金属は細胞の中に結合した状態で含まれているため、水で洗い流されることも、熱で分解されることもありません。見た目でも分かりません。汚染された水で育ったヨウサイは、むしろより旺盛で青々と育つことが多いのですが、金属の一部が微量で生長を刺激するからです。

> **ヨウサイで最も重要な決定は、種子を選ぶときでも肥料を与えるときでもなく、どの水に植えるかを決めるときに下されます。その水がどこから来たのか分からなければ、その場所は使わないほうがよいです。**

| 場所 | 判断 |
|---|---|
| 雨水がたまった場所、井戸水、山から流れ下った渓流水 | 相対的に安全です |
| 田んぼで使っていた灌漑水 | たいてい安全ですが、上流を確認します |
| 河川の下流、都市の排水路、道路脇の水たまり | 避けます。道路の粉じんの鉛や生活廃水が混じります |
| 工場、鉱山、廃棄物埋立地の下流側の水 | 絶対に使いません |
| よどんで古くなった水、油膜が浮いていたり異常な色を帯びていたりする水 | 使いません |

&nbsp;&nbsp;&nbsp;災害時には、事情がさらに悪くなります。管理が途絶えると、工場や倉庫、ガソリンスタンドから物質が漏れ出し、雨水に洗い流されて低地のたまり水に集まります。洪水の後にできた水たまりは、ヨウサイにとって良い場所のように見えますが、その水がどこを通ってきたのかを先に考えなければなりません。

### 14-3. 水系感染の寄生虫

&nbsp;&nbsp;&nbsp;二つ目の危険は寄生虫です。糞便が混じる水で育った水生植物は、吸虫類が体を付着させる場所になります。

| 寄生虫 | どのように感染するか | 症状 |
|---|---|---|
| 肥大吸虫（Fasciolopsis buski） | 淡水産の巻貝を経た幼虫が、殻をかぶった状態（被嚢幼虫）で水生植物の表面に付着します。その植物を生で食べると、人の腸に定着します | 下痢、腹痛、消化障害。数が多いと栄養不良と浮腫 |
| 肝蛭（Fasciola） | 同じ経路で水生植物に付着します。飲み込むと腸壁を突き破って肝臓と胆管に向かいます | 発熱、右上腹部の痛み、肝障害、胆管閉塞 |
| 住血吸虫（Schistosoma） | 食べて感染するのではなく、水中の幼虫が皮膚を突き破って入り込みます。素足や素手で水に入る作業中に感染します | 発熱、血尿や血便、長期化すると肝臓と膀胱の障害 |
| 糞便汚染細菌 | 人や家畜の糞便が水に混じり、植物の表面に残ります | 大腸菌や赤痢菌などによる下痢と腹痛 |

&nbsp;&nbsp;&nbsp;前の二つは経口感染の経路であり、住血吸虫は経皮感染の経路であるという点が異なり、そのため対応も分かれます。経口の経路は、加熱することで断ち切れます。被嚢幼虫は熱に弱く、沸騰した湯にさっと通しただけでも死にます。経皮の経路は加熱とは関係がなく、水中で作業するときに素肌が長く水に触れないようにすることでしか減らせません。

| 対応 | 何を防ぐか |
|---|---|
| 必ず加熱して食べます。ゆでる、炒める、汁物のいずれでも十分に加熱します | 肥大吸虫、肝蛭、糞便由来の細菌 |
| 茎の中と葉の付け根まで流水で何度もすすぎます | 表面に付いたものを減らします。ただし、これだけでは不十分です |
| 水に入って作業するときは、長靴と衣服で素肌を覆います | 住血吸虫 |
| 糞便が混じる水や、畜舎の下流側の水を使いません | 三つすべての根源を断ちます |
| アヒルや魚を一緒に飼った水で育ったものは、特に徹底的に加熱します | 糞便経路の危険が高いためです |

> **ヨウサイは必ず加熱して食べる野菜です。サンチュ（リーフレタス）のように洗ってそのまま食べる習慣を、この作物に当てはめてはいけません。加熱して食べる場合の損失はビタミンCの一部であり、加熱しない場合の損失は寄生虫です。**

&nbsp;&nbsp;&nbsp;評価表の調理・加工がAで、洗ってそのまま食べられる作物のSSより一段階低い理由が、ここにあります。ヨウサイは必ず火を使わなければならず、燃料が貴重な状況では、これは実際のコストです。ただし、炒め物なら5分以内に終わるため、豆を一時間ゆでるのとは比べものにならないほど軽い負担です。

### 14-4. そのほかの注意

| 項目 | 内容 |
|---|---|
| 硝酸塩 | 窒素肥料を多く与えた葉菜類に蓄積します。減らす方法は第10節にあります |
| シュウ酸 | 微量含まれていますが、ホウレンソウやフダンソウよりはるかに少なく、実質的な問題にはなりません |
| カリウム | 100gに489mgと多めです。腎機能が低下した人には、ゆでてゆで汁を捨てたものがよいです |
| 過剰摂取 | 通常の量では、特に副作用は報告されていません |

## 15. 冷蔵庫なしの貯蔵

### 15-1. なぜこれほど難しいのか

&nbsp;&nbsp;&nbsp;評価表の貯蔵性はEで、無電力の常温で2-3日です。原因は単純です。水分が90%を超え、組織が柔らかいからです。収穫後も細胞はしばらく生きて呼吸し、自分の体の糖を燃焼させますが、根から水がそれ以上来ないため、乾いていき、同時に細菌やカビが柔らかい組織に入り込みます。茎の中が空洞で空気が内側まで届く構造も、傷む速度を高めます。

| 方式 | 方法 | 期間 |
|---|---|:---:|
| そのまま置く | 洗わずに水気を払った状態で、日陰に | 1-2日 |
| 紙に包む | 湿らせた紙や布に包んで、涼しい場所に | 2-3日 |
| 株元を水に浸す | 生け花のように株元を水に浸して立てておきます | 2-3日 |
| 土室や井戸端 | 涼しい場所に置くと、もう少し長持ちします | 3-4日 |

&nbsp;&nbsp;&nbsp;株元を水に浸して立てておく方法は、茎が水を吸い上げ続けるようにして、しおれるのを遅らせる原理です。一、二日は稼げますが、水が温まると株元から腐るため、水をこまめに入れ替える必要があります。

### 15-2. 畑がそのまま貯蔵庫です

> **ヨウサイの貯蔵問題に対する最も確実な答えは、貯蔵しないことです。畑に立っている間は傷まないので、その日に食べる分だけをその日に刈り取ります。**

&nbsp;&nbsp;&nbsp;一度にすべて収穫しなければならない作物なら、貯蔵性Eは致命的でしょうが、ヨウサイは刈るほど再び生えてきます。二十株を立てておいて毎日数本ずつ刈れば、貯蔵という問題そのものが生じません。貯蔵が必要になるのは、ただ一つ、霜の直前に残ったものを一度に処理しなければならないときです。

### 15-3. 長く保存する方法

| 方式 | 手順 | 期間 | 原理 |
|---|---|:---:|---|
| 乾燥 | 沸騰した湯で30秒ゆでた後、冷水ですすぎ、水気を絞って日陰でからからに乾かします | 6か月から1年 | 水分を抜くと、細菌やカビが繁殖できません。ゆでるのは、酵素の働きを止めて色や味が変わるのを防ぐためです |
| 塩漬け | 重量の3-5%の塩で層状に漬け、重しをかけておきます | 2-3か月 | 塩が水分を引き出し、浸透圧で微生物を抑えます |
| キムチに漬ける | 塩漬けにして味付けし、甕に入れて涼しい場所に置きます | 2-3か月 | 乳酸菌が酸をつくり、ほかの微生物を抑えます |
| チャンアチ（醤油漬け） | ゆでて、醤油またはテンジャン（韓国味噌）に漬け込みます | 数か月 | 塩分と発酵がともに作用します |
| 冷凍 | ゆでて水気を絞り、凍らせます | 数か月 | 電気があるときだけ可能です。真冬の寒さで代用できますが、そのときにはすでに作物がありません |

&nbsp;&nbsp;&nbsp;災害時に最も実用的なのは乾燥です。電気も塩も甕も必要なく、日差しと風さえあればよく、体積が10%に減るため、保管場所もあまり取りません。ただし、乾燥の過程でビタミンCがほとんど失われ、ベータカロテンもかなり減ります。残るのは繊維とミネラルと少量のタンパク質なので、冬の汁の具としてはよくても、ビタミンの供給源としては期待しにくいです。

| 乾燥で守るべきこと | 理由 |
|---|---|
| 直射日光で乾かさず、日陰で風に当てて乾かします | 直射日光が色素とビタミンを破壊します |
| 薄く広げ、重ならないように置きます | 重なると、その間が乾かず、カビが生えます |
| 完全に乾くまで乾かします。手で揉んで砕ければ完成です | 水気が残ると、保管中にカビが生えます |
| 密閉して、暗く涼しい場所に置きます | 湿気を再び吸うと傷みます |

## 16. 調理と加工

### 16-1. 燃料を節約する方法

&nbsp;&nbsp;&nbsp;ヨウサイは必ず加熱しなければなりませんが、長く加熱する必要はありません。組織が柔らかく、熱がすぐに通り、長く加熱するとかえって軟らかくなりすぎます。燃料が貴重な状況では、この性質は利点です。

| 方法 | 時間 | 燃料 | 残る栄養 |
|---|:---:|:---:|---|
| 強火で炒める | 2-5分 | 最も少ない | ビタミンCが比較的多く残ります。ベータカロテンは油と一緒になるため、吸収が良くなります |
| ゆでる | 30秒から1分 | 少ない | 水溶性ビタミンが湯に抜け出ます。その湯を使えば取り戻せます |
| 汁物やチゲ（煮込み鍋料理） | 5分 | 普通 | 抜け出た栄養がスープに残り、いっしょに食べることになります |
| 蒸す | 3-5分 | 少ない | 水に溶け出る損失が、ゆでるより少なくなります |

&nbsp;&nbsp;&nbsp;東南アジアでヨウサイを主に炒めて食べるのには、理由があります。短時間で済んで燃料が少なくて済み、栄養の損失が少なく、油がベータカロテンの吸収を助け、茎のシャキシャキした食感が残るからです。油がなければ、水を少しだけ入れてふたをし、蒸すように炒めてもかまいません。

&nbsp;&nbsp;&nbsp;茎と葉を分けて入れるのがコツです。茎を先に1分ほど加熱し、葉を後から入れれば、どちらもちょうどよく火が通ります。いっぺんに入れると、葉がくたくたになるまで茎に火が通りません。

### 16-2. どのように食べるか

| 方式 | 内容 |
|---|---|
| 炒め物 | ニンニクと一緒に強火で炒めます。最も一般的で、最も効率的です |
| 汁物とチゲ | テンジャンの汁物や澄まし汁に入れます。長く煮ると軟らかくなりすぎるため、最後に入れます |
| 和え物 | ゆでて水気を絞り、調味料で和えます。ナムル（和え物の副菜）として食べる方法です |
| 粥 | 細かく刻んで穀物の粥に入れます。消化力の弱い人に向いています |
| キムチ | 塩漬けにして漬け込みます。貯蔵を兼ねます |
| 乾燥品の戻し方 | ぬるま湯に20-30分浸して戻し、汁物や炒め物に使います |

&nbsp;&nbsp;&nbsp;評価表の味の等級に付いている「食感に抵抗感」という但し書きは、大部分が茎に由来します。筋っぽい茎を切り落とすか、斜めに薄く切って繊維を断ち切ると、かなり改善され、太い茎は半分に割って入れると、早く火が通り、噛みやすくなります。

### 16-3. 栄養を守る調理

| 原則 | 理由 |
|---|---|
| 切る前に洗います | 切った後に洗うと、切り口からビタミンが水に抜け出ます |
| 洗った後は水に長く浸けません | 水溶性の栄養が抜け出し続けます |
| ふたをして短時間で加熱します | 蒸気が閉じ込められて早く火が通り、燃料が少なくて済みます |
| ゆで汁をスープに使います | 抜け出たものを取り戻せます。ただし、硝酸塩が心配な場合は捨てます |
| 油を少しでも使います | ベータカロテンは油に溶けてはじめて吸収されます |

### 17-2. 一年を貫く軸

&nbsp;&nbsp;&nbsp;ヨウサイの一年は、五か月の畑と七か月の室内に分かれます。韓国では5月中旬から10月初めまでは畑で旺盛に働き、残りの七か月は、種子の袋の中や窓辺の水の入った容器の中で、翌年を待ちます。この構造を見落とすと、ある年は成功しても、翌年には何も残りません。

&nbsp;&nbsp;&nbsp;そのため、この表で最も重要な欄は、夏の収穫欄ではなく、8月初めと10月です。8月初めに採種用の株を取り分けておかなければ種子がなく、10月に挿し穂を切って取り込まなければ、生きている茎がありません。

> **夏の五か月の収穫は、8月初めに数株を残しておく判断と、10月に茎を数本切って取り込む手作業の上に成り立っています。この作物は、収穫する技術よりも、受け継いでいく技術のほうが難しいのです。**
