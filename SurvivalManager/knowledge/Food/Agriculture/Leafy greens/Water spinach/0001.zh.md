## 引言
&nbsp;&nbsp;&nbsp;蕹菜（Ipomoea aquatica）是旋花科番薯属的多年生藤本草本，茎中空，能把空气送到根部，所以在被水淹的土地上也不会死。原产地是从印度经东南亚到中国南部的沼泽和水渠，在韩国遇霜即死，作一年生栽培。综合等级为C（41.9分，有效183种中第88名），副食为SS（59.5分），是在被水淹的地块、排水不畅的洼地、排不了水的稻田等其他作物会死的土地上担起配菜角色的作物。优势是收获速度SS（播种后30天）和割后再生的持续性A，劣势是耐寒性E（一次霜冻就全灭）和耐储性E（常温下2-3天）。植物本身无毒，但会把水中的重金属和寄生虫原样吸入，所以最重要的决定不是选种子，而是种在哪里的水里。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | C | 41.9 |
| 短期 | C | 41.7 |
| 长期 | C | 42.1 |
| 副食 | SS | 59.5 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：蛋白质密度、微量营养素、收获速度。S：施肥、自留种。A：持续性、设施负担、烹调·加工要求度、连作适应性、产量稳定性、种子寿命。B：光照、口味、国内种植普及度 |
| 劣势 | E：水消耗量、耐寒性、耐储性、非食用价值。C：单位面积热量、温度幅度、病虫害压力、防治自立度、无合成投入产量保持率、整地·挖掘能量 |

> **蕹菜的水消耗量E，既意味着这种作物用水多，也意味着在本来就积着水的土地上，不必另外引水。**

&nbsp;&nbsp;&nbsp;水消耗量E按淹水栽培计为每㎡每年1,500L以上，包含渗漏和蒸发，所以在必须打水来灌的土地上是最差的选择。副食SS是因为热量小而使蛋白质密度和微量营养素被算得很大的数值，单位面积热量为C（自给线的0.50倍），所以不可能靠蕹菜填饱肚子。病虫害压力C（推定感受率50.3%）是引用同一目的数值得出的推定，实际上病虫害非常少。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 旋花科番薯属多年生藤本草本。与红薯、牵牛花同属，所以插茎时节上会长根，与它们有部分共有的病虫害，日照变短时开花 |
| 叶、茎 | 叶为长心形至箭头形，长5-15cm。茎是中空的圆筒，中空的腔和通到根部的通气组织把空气送到根部并产生浮力，因此能在水面上蔓延数米 |
| 根、花、果实 | 以须根为主，浅浅铺开，接触水或湿土的每个节上都会长出不定根。花为白色至淡粉色喇叭形（直径3-5cm）。种子的种皮坚硬 |

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 发芽、幼苗期 | 播种后7天 | 坚硬的种皮吸水裂开，子叶展开 |
| 首次收获期 | 25-35天 | 茎30-40cm |
| 再生期 | 收获后7-14天 | 留下节上的侧芽苏醒，长出新梢 |
| 开花期 | 8月下旬以后 | 花茎抽出，茎变硬，叶变小，口味下降 |

&nbsp;&nbsp;&nbsp;茎端的生长点会压制下方节上的侧芽（顶端优势），所以剪去顶端，侧芽就会一齐苏醒，增加的枝条成为下一次的收获物。每100g热量26kcal，水分90%以上，蛋白质1.67-2.5g，碳水化合物3.2g，膳食纤维1.9-2.1g，糖类0.66g，钾489mg，维生素A（β-胡萝卜素）411μg，维生素C 24.6mg，铁2.4mg，钙87mg。铁和维生素C同在一片叶中，弥补了植物性铁吸收率低的不足，但维生素C加热后大量流失。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽适温20-30℃（土壤低于20℃几乎不发芽），生长15-35℃（最适25-32℃，幅度10℃）。超过35℃只要水充足也长势旺盛，10℃时停止生长，5℃上下叶片受损，一次霜冻就全灭。其他叶菜崩溃的盛夏是它的鼎盛期 |
| 光 | 每天6小时以上为宜（4小时则节间变长、叶片变薄）。40%遮光下仍保持产量的86%。阴处凉爽，与温度弱点叠加，所以半天有阳光的位置更好 |
| 水、土壤 | 淹水水深保持15-20cm，旱地土壤水分为最大持水量的80-90%。土层深15-20cm，pH 6.0-7.0，耐盐性弱至中等 |

| 类型 | 特点 |
|:---|:---|
| 水生型（青茎系） | 茎粗且中空大、浮力大，叶为宽心形。适合淹水田、稻田、水边。结籽差，靠扦插延续，青茎大叶在淹水栽培中产量最高 |
| 陆生型（白骨系） | 茎细而硬、直立，叶窄而长。适合旱地、垄、花盆，种子成熟良好。白骨（茎白色）、赤茎（茎红色）、中叶青骨柳叶系（旱地与水中皆宜） |

&nbsp;&nbsp;&nbsp;在被水淹的土地上用陆生型，产量达不到预期，在旱地上用水生型，则要被引水之事缠住。国内种植普及度为B（仅在三四个道种植），种子不易获得，所以得到时要多备，并通过扦插和留种自行延续。

## 4. 整地、播种与扦插
| 项目 | 标准 |
|:---|:---|
| 选址 | 排不出水的土地是上佳位置（低洼地、雨季被淹的稻田地块、排水沟堵塞的角落、雨水汇聚的洼处）。但务必确认水的来源 |
| 淹水田床 | 像稻田一样整平（高低差3cm以上则浅处干、深处烂）。在边缘筑高25-30cm的田埂，把底部踩实以减少渗漏（沙地则铺黏土夯实）。栽种前2-3天灌水 |
| 旱地床 | 耕15-20cm深，做低垄或整平（垄高则水流失快），沟作水道。多施腐熟堆肥，用稻草、干草、落叶厚盖，浇水次数可减到一半以下 |
| 施肥（1,000㎡） | 氮、磷、钾各15-20kg，堆肥10吨。栽种前2周把堆肥全量、磷钾全量、氮的一半作基肥施入，追肥在每次割后立即少量施氮 |
| 替代资源 | 草木灰（每㎡一小撮左右，过量则pH升高）、腐熟堆肥（未腐熟的会使水发臭）、稀释10-20倍的人尿（收获前2周停用）、草沤液肥稀释5-10倍、养鸭或养鱼的水（有粪便污染风险） |

| 栽培类型 | 播种 | 备注 |
|:---|:---|:---|
| 露地旱地 | 5月中旬-6月 | 霜冻完全结束后（土壤低于15℃几乎不发芽且会烂）。6-9月收获 |
| 露地淹水田 | 5月下旬-6月 | 等水变暖 |
| 室内育苗 | 4月下旬 | 霜冻结束后移出。6月起收获 |

| 开始方式 | 方法 |
|:---|:---|
| 播种 | 温水浸泡12-24小时。深0.5-1cm，行距20cm（淹水田25-30cm），株距最终10-15cm。淹水栽培时先排水再播种并覆土，芽长到约5cm后再一点点加水，芽尖始终露出水面。至首次收获25-35天 |
| 扦插 | 把健壮粗茎剪成15-20cm（4-5个节），撸去要埋入部分的叶，斜插使3-4个节入土。插在水盆里3-5天可见根。成活5-7天（不能干），至首次收获20-25天 |
| 间苗 | 真叶2-3片时留5cm，4-5片时留10-15cm。间下的幼苗可移栽或煮熟吃 |

## 5. 水分管理与栽培管理
| 时期 | 淹水栽培 | 旱地栽培 |
|:---|:---|:---|
| 发芽、幼苗期 | 排水后只保持土壤湿润，再逐渐升到不淹没芽尖的高度 | 不让表土变干，每天一两次 |
| 营养生长期 | 保持15-20cm | 表土干了就浇透，每天1-2次 |
| 收获前后 | 保持不变 | 割后立即充分浇水 |

&nbsp;&nbsp;&nbsp;水充足则茎嫩，不足则纤维变硬发韧。缺水时花茎提早抽出，是干旱胁迫引起开花，可用于留种。反过来，幼芽被完全淹没会在几天内溶烂，水滞留腐败会发黑发臭、根变褐，浅水在中午会升温到40℃以上把根烫熟。水保持15cm以上，补水在早晨进行。

| 方式 | 特点 |
|:---|:---|
| 淹水栽培 | 蓄15-20cm水栽培。产量最高，水能阻止杂草萌发、土中害虫和霉菌，除草、浇水、土传病虫害的劳动一并消失，劳动只在夯实地面时一次 |
| 旱地栽培 | 种在垄上并浇水。产量为淹水栽培的60-80%，需要除草和每天浇水，有根腐病和土中害虫 |
| 浮床栽培 | 在深水上扎筏，铺上水草、稻草、芦苇、腐叶土，插入插穗，用木桩或石头固定。不需要施肥，但会直接吸入被污染水中的重金属和病原体 |

| 管理 | 方法 |
|:---|:---|
| 摘心、引蔓 | 茎长20-25cm时剪去顶端以增加侧枝，并把茎均匀摆开以保证通风（减少霉菌病害） |
| 摘除花蕾 | 8月下旬以后见蕾就摘，可使收获期延长2-3周 |

## 6. 病虫害与养分问题
&nbsp;&nbsp;&nbsp;蕹菜的病虫害非常少。淹水排除了土中害虫和土传霉菌，生长期只有30天，每次割取时叶上的害虫也被一并带走。

| 病虫害 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 霜霉病、白锈病 | 叶背灰白色霉层或白色脓疱，叶面黄斑。凉爽潮湿时、过密时、雨季 | 理顺茎蔓以通风，清除病叶（严重则拔除整株），水浇在根部 |
| 根腐病、猝倒病 | 根变褐、植株萎蔫 / 幼芽基部缢缩倒伏。水滞留或腐败时、播种过密 | 旱地改善排水，淹水田换水，不过密播种，避免未腐熟的肥料 |
| 蚜虫、叶螨 | 吸汁使叶卷曲并引发煤污病 / 叶片发白并结蛛网（干燥时） | 用强水流冲洗、肥皂水、保护天敌 / 多喷水提高湿度 |
| 蛾类幼虫、蜗牛 | 啃食叶片 | 傍晚徒手捕捉、草木灰带 |

&nbsp;&nbsp;&nbsp;在淹水田里，喷洒肥皂水之类的东西会积聚而伤根，并且鱼先死，所以优先徒手捕捉和摘除病叶。

| 症状 | 原因与对策 |
|:---|:---|
| 从下部老叶开始发黄、植株矮小 | 缺氮。稀释的人尿、草沤液肥、腐熟堆肥 |
| 新叶发黄、仅叶脉保持绿色 | 缺铁（pH高时土里有铁也用不了）。降低pH，减少草木灰 |
| 叶片茂盛、茎软易折、虫子聚集 | 氮过量。停氮并用水冲洗 |
| 叶缘干枯、根变褐 | 肥料浓度过高。浇足水冲洗 |

&nbsp;&nbsp;&nbsp;若从老叶开始受损，是植物体内容易移动的养分（氮、磷、钾、镁）不足；若从新叶开始受损，则是不易移动的养分（铁、钙、硼）不足。施氮多的叶菜中的硝酸盐会转变成亚硝酸盐，对婴儿有危险，所以要在晴天的下午收获，施肥多的要把焯水的水倒掉。

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 豆类（豇豆、绿豆）、水稻（使用田埂内侧和水渠的位置，水稻供热量、蕹菜供配菜）、水芹、豆瓣菜（用同样的水） |
| 差 | 红薯、牵牛花等旋花科（共有病原菌和害虫）、根菜（萝卜、胡萝卜、牛蒡）、大蒜、洋葱（积水就烂，对水的需求正相反） |

&nbsp;&nbsp;&nbsp;连作适应性A的依据是旋花科休耕2年。旱地按蕹菜 → 豆科 → 十字花科或葫芦科 → 蕹菜的顺序轮换，淹水田按蕹菜 → 水稻或蕹菜 → 排水后种豆科 → 蕹菜的顺序轮换。长期泡水的土壤缺氧，有机物腐解不彻底，铁和锰会变成对根有害的形态，所以要有一年排水晒田。

## 8. 收获、留种与越冬
| 收获 | 标准 |
|:---|:---|
| 时期 | 首次收获为播种后25-35天、扦插后20-25天（茎30-40cm）。此后每7-14天一次（侧枝20-30cm），到霜降前一个夏天可收四次以上 |
| 判断 | 以硬度而不是长度为准。用手指按茎，容易凹下就是嫩的。超过40cm会从基部变老，花蕾一出现纤维就迅速变硬 |
| 剪法 | 从基部留5-10cm（两三个节），用锋利的刀或剪刀斜着剪（拧断会撕裂茎而引病）。清晨剪最饱满，萎蔫也慢 |
| 收获后 | 立即移到阴凉处，用流水多次冲洗并沥干。老硬的基部和受损的叶做堆肥，粗壮完好的茎挑出留作插穗 |

> **蕹菜收获的关键不在于剪多少，而在于留多少。留下的节数决定下一次收获的大小。**

| 延续方式 | 方法 |
|:---|:---|
| 两条路 | 一次霜冻就会连根冻死，所以种子和活茎两样都要留下，互为保险 |
| 留种 | 在8月初选定性状鲜明的健康植株，不再割取。减少浇水可使开花提前（从开花到结实要一个多月，9月开的花可能在初霜前熟不了）。豆荚变褐干燥后摘下，在阴凉处晾干，搓揉后簸选。以自花授粉为主，品种不易混杂。密封于凉爽干燥的暗处可保存2-3年 |
| 插穗越冬 | 霜冻前2周，把健康的茎20-30cm剪几根，插在水盆里放在向阳的窗边。不要降到10℃以下（5℃以下会死），放在最暖和的位置并分装在几个小容器里，每3-5天换水，长长的茎剪下重插来增加数量。霜冻结束后的5月中旬，先只在白天拿出去几天适应，再移出 |

## 9. 储存
&nbsp;&nbsp;&nbsp;耐储性E是因为水分超过90%、组织娇嫩。最可靠的答案是不储存：立在田里时不会坏，所以只割当天要吃的量。只有在霜降前要一次处理剩余的时候才需要储存。

| 方法 | 步骤与期限 |
|:---|:---|
| 放在阴凉处 | 不洗，抖掉水放在阴凉处。1-2天 |
| 茎基泡水立放 | 茎会不断吸水（勤换水以免茎基烂掉）。2-3天 |
| 晒干 | 在沸水中焯30秒，用冷水冲洗后挤干，在阴凉通风处摊薄晒透（体积变为10%），密封。维生素C几乎流失，适合做汤料。6个月-1年 |
| 腌渍 | 用重量3-5%的盐层层腌后压住（2-3个月），或做成泡菜、酱菜（数月） |

## 10. 烹调与注意事项
| 方法 | 时间与特点 |
|:---|:---|
| 大火快炒 | 2-5分钟。耗燃料最少，维生素C保留相对较多，油有助于吸收β-胡萝卜素 |
| 焯水、做汤 | 焯水30秒-1分钟（水溶性维生素会流失，所以把焯水的水当汤用），汤和炖菜5分钟（最后放） |

&nbsp;&nbsp;&nbsp;先把茎煮1分钟左右，叶后放；老茎斜切成薄片或对半剖开放入，口感会更好。

| 风险 | 内容 |
|:---|:---|
| 重金属 | 镉（工厂废水、矿山排水、磷肥、污水污泥：损伤肾脏和骨骼，排出需数十年）、铅（水管、油漆、电池、道路粉尘：神经系统、儿童脑发育）、砷、汞。无法靠洗或煮除去，也无法从外观判断 |
| 姜片虫、肝片吸虫、血吸虫 | 前两者的囊蚴附着在水生植物表面，生吃就会在肠或肝脏和胆管内寄生（腹泻、腹痛 / 发热、右上腹疼痛）。血吸虫是水中的幼虫穿透皮肤，在光脚光手下水的作业中感染 |
| 粪便污染的细菌 | 在混有粪便的水（包括养鸭或养鱼的水）中长出的，要特别彻底地煮熟 |

> **蕹菜最重要的决定，既不是在挑种子时，也不是在施肥时，而是在决定种在哪里的水时做出的。如果不知道那水来自哪里，最好不要用那个位置。**

| 水 | 判断 |
|:---|:---|
| 积的雨水、井水、山上流下的溪水、稻田灌溉水 | 相对安全（稻田灌溉水要确认上游） |
| 河流下游、城市排水沟、路边水坑 | 避开（含道路粉尘中的铅和生活污水） |
| 工厂、矿山、垃圾填埋场下游的水、长期积滞的水、浮有油膜的水 | 绝对不用 |

&nbsp;&nbsp;&nbsp;囊蚴怕热，在沸水中稍微焯一下就会死，所以要充分加热，只靠冲洗不够。下水作业时，用长靴和衣服遮住裸露的皮肤。草酸远比菠菜或莙荙菜少，钾每100g含489mg，所以肾功能下降的人最好焯水后倒掉水。

> **蕹菜是必须煮熟吃的蔬菜。不要把像生菜那样洗了就生吃的习惯用在这种作物上。煮熟吃的损失是一部分维生素C，不煮熟的损失是寄生虫。**

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 休息。室内插穗管理（换水、保持10℃以上、把长长的茎剪下重插） |
| 3-4月 | 准备堆肥，检查种子状态。4月淹水田整理地块并修田埂，旱地翻耕施堆肥，室内开始育苗 |
| 5-6月 | 5月中旬以后灌水、播种或扦插、让插穗适应。6月保持水深15-20cm、覆盖、摘心、首次收获 |
| 7-8月 | 7月反复收获、收获后追肥、雨季保证通风、观察霜霉病。8月初选定留种植株并停止收获，下旬起摘除花蕾 |
| 9-10月 | 9月观察留种株的花和豆荚，减少水分以促开花。10月霜前结束收获，收种子、把插穗搬进室内、把剩下的焯水晒干 |
| 11-12月 | 11月淹水田排水晒地，旱地把剩下的茎做堆肥，保存种子。12月开始室内插穗管理 |

&nbsp;&nbsp;&nbsp;蕹菜的一年分为五个月的田间和七个月的室内。8月初不把留种植株分出来就没有种子，10月不把插穗搬进室内就没有活茎。

> **夏季五个月的收获，取决于8月初留下几株的判断，和10月剪几根茎搬进室内的那双手。这种作物，延续的技术比收获的技术更难。**
