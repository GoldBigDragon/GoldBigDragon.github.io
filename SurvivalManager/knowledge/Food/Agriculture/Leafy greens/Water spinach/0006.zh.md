## 13. 留种与越冬 - 延续到来年的两条路

### 13-1. 为什么是两条路

&nbsp;&nbsp;&nbsp;蕹菜在原产地是多年生，但在韩国无法越冬。一次霜冻地上部就会全部死亡，根也活不下来。所以要延续到来年，就必须留下点什么，而能留下的要么是种子，要么是活的茎。

| 路径 | 留下的东西 | 优点 | 缺点 |
|---|---|---|---|
| 留种 | 种子 | 容易保管，可保存3年。几乎不占地方 | 需要时间开花并让种子成熟，所以必须放弃该植株的收获。霜冻来得早就会失败 |
| 插穗越冬 | 活的茎 | 可靠。次年开始得早 | 整个冬天都要在室内保持10度以上。费工夫 |

&nbsp;&nbsp;&nbsp;两种都做比较稳妥。霜冻来得早，种子可能来不及成熟，冬天保不住温度，插穗也可能死掉，所以两者互为保险。

### 13-2. 留种

| 步骤 | 方法 | 原因 |
|---|---|---|
| 选留种株 | 选没有病害、茎粗、品种特性表现好的植株 | 种子像它的亲本。从好的植株上留种，才能长出好的 |
| 停止收获 | 从8月初起，这一株不再割，留着 | 开花和种子成熟需要时间。一直割的话，花开不了 |
| 诱导开花 | 减少水分，施加胁迫 | 干旱胁迫会成为转向繁殖的扳机。与白昼变短的条件叠加时更有把握 |
| 种子成熟 | 留到果荚变褐干枯为止 | 未成熟的种子不会发芽 |
| 采收 | 连同干枯的果荚一起摘下，摊在阴凉处晾干 | 直接在阳光下晒，种子会受损 |
| 取出种子 | 把果荚搓碎，扬去杂物 | 外壳很轻，会被风吹走 |
| 干燥 | 在阴凉处彻底晾干。用指甲按压不留痕迹就是干透了 | 水分残留，保管中会长霉，发芽力下降 |
| 保管 | 装入密闭容器，放在凉爽阴暗处 | 湿气、光和热会削弱发芽力 |

| 保管条件 | 发芽力保持的时间 |
|---|:---:|
| 凉爽干燥的阴暗处，密闭 | 2-3年 |
| 直接放在常温下 | 1-2年 |

&nbsp;&nbsp;&nbsp;评价表中的自家留种S，依靠的是蕹菜以自花授粉为主这一点。即使蜜蜂传递花粉，品种也不会大量混杂，所以多个品种放在同一块地里，也可以分别留种。与十字花科作物因杂交而在留种上伤脑筋相比，要轻松得多。

&nbsp;&nbsp;&nbsp;不过，在韩国的气候下，留种存在时间压力。白昼变短后开花，花谢后种子成熟还需要一个月以上，所以如果9月才开花，就可能赶不上10月初的初霜之前成熟。这就是为什么要从8月初起把留种用的植株单独分开管理，必要时减少水分以提前开花。韩国南部更有利，如果能在室内完成成熟，则更有把握。

### 13-3. 插穗越冬

&nbsp;&nbsp;&nbsp;对于水生型品种那样种子不易成熟的品系，让茎存活下来越冬是唯一的办法。

| 步骤 | 方法 | 原因 |
|---|---|---|
| 选插穗 | 在霜冻来临前2周，把健康的茎截成20-30cm，剪取多根 | 遭了霜冻之后就已经晚了 |
| 生根 | 插在盛水的容器里，放在明亮的室内 | 比用土更容易管理，根的状况看得见 |
| 保持温度 | 不要低于10℃。15℃以上更好 | 10℃以下不生长，5℃以下会死亡 |
| 光照 | 放在有阳光的窗边 | 太暗节间会变长而变弱 |
| 换水 | 每3-5天换一次水 | 水腐败的话茎的基部会变软 |
| 冬季管理 | 长长了的茎剪下来重新插 | 不断剪下再插，个体数量就会增加 |
| 春季种植 | 在霜冻完全结束的5月中旬拿到室外 | 不要突然拿出去，先只在白天拿出去几天，让它适应 |

&nbsp;&nbsp;&nbsp;在暖气中断的情况下，要在室内保持10℃并不容易。这时可以把它放在人活动的空间里最暖和的地方，也就是厨房或火盆附近，并分装在几个小容器里，这样即使一个容器冻了，也不会全部损失。同时做好种子保管和插穗越冬这两件事，其实际意义就在这里。

> **在韩国，蕹菜是每年没有人去延续就会消失的作物。田里不会自然留下任何东西，所以秋季的留种和冬季的插穗管理，就是来年栽培的开始。**

## 14. 毒性与需注意的成分 - 水带来的风险

### 14-1. 植物本身没有毒

&nbsp;&nbsp;&nbsp;蕹菜这种植物本身没有对人有害的毒素。它没有马铃薯的茄碱（龙葵素）、木薯的氰苷、大豆的胰蛋白酶抑制剂这类东西。不过，这种作物带有一种其他蔬菜所没有的风险，这种风险来自水，而不是来自植物。

### 14-2. 重金属积累

&nbsp;&nbsp;&nbsp;蕹菜吸收水中金属离子的能力极强，甚至可以用来净化被污染的水。问题在于，能用来净化，就意味着那些污染物会积累在植物体内。

| 物质 | 来源 | 对人体的作用 |
|---|---|---|
| 镉 | 电镀、电池、颜料工厂的废水，矿山排水，磷肥，污水污泥 | 在肾脏中蓄积，破坏肾功能。把钙从骨骼中夺走，使骨骼变软、易折。排出体外需要数十年 |
| 铅 | 老旧水管、油漆、电池、道路粉尘、枪弹 | 作用于神经系统。损害儿童的大脑发育，导致成年人贫血和神经损伤 |
| 砷 | 矿山排水、木材防腐剂、部分地下水 | 慢性中毒会引起皮肤病变和多个器官的损伤 |
| 汞 | 工厂废水、废荧光灯、废电池 | 损伤神经系统 |

&nbsp;&nbsp;&nbsp;这种风险最重要的事实是，无法通过清洗或煮熟来消除。重金属以结合状态存在于细胞内，不会被水冲走，也不会被热分解。从外表上也看不出来。在被污染的水中生长的蕹菜，反而往往长得更茂盛、更绿，因为其中一部分金属在微量时会刺激生长。

> **种植蕹菜时最重要的决定，既不是选种子的时候，也不是施肥的时候，而是决定种在什么水里的时候。如果不知道那些水是从哪里来的，最好就不要用那块地方。**

| 位置 | 判断 |
|---|---|
| 积有雨水的地方、井水、从山上流下的溪水 | 相对安全 |
| 稻田用过的灌溉水 | 通常安全，但要确认上游 |
| 河流下游、城市排水沟、路边水坑 | 避免。会混入道路粉尘中的铅和生活污水 |
| 工厂、矿山或废弃物填埋场下游的水 | 绝对不用 |
| 积滞已久的死水、浮有油膜或颜色异常的水 | 不用 |

&nbsp;&nbsp;&nbsp;在灾害情况下，状况会更糟。管理中断后，工厂、仓库和加油站里的物质会泄漏出来，被雨水冲刷，汇集到低洼地的积水中。洪水之后形成的水洼，对蕹菜来说看起来像是好位置，但必须先想一想那些水流经了哪些地方。

### 14-3. 水媒寄生虫

&nbsp;&nbsp;&nbsp;第二种风险是寄生虫。在混有粪便的水中生长的水生植物，会成为吸虫类附着的地方。

| 寄生虫 | 如何传播 | 症状 |
|---|---|---|
| 姜片吸虫（Fasciolopsis buski） | 经淡水螺发育的幼虫以带壳状态（囊蚴）附着在水生植物表面。生吃这种植物，就会在人的肠道里定居 | 腹泻、腹痛、消化障碍。数量多时出现营养不良和水肿 |
| 肝片吸虫（Fasciola） | 通过同样的途径附着在水生植物上。吞下后穿透肠壁，到达肝脏和胆管 | 发热、右上腹疼痛、肝损伤、胆管阻塞 |
| 血吸虫（Schistosoma） | 不是通过吃传播，而是水中的幼虫穿透皮肤侵入。在赤脚、赤手下水作业时感染 | 发热、血尿或血便，时间久了会损害肝脏和膀胱 |
| 粪便污染细菌 | 人和家畜的粪便混入水中，残留在植物表面 | 大肠杆菌和痢疾杆菌等引起的腹泻和腹痛 |

&nbsp;&nbsp;&nbsp;前两种是经口传播途径，而血吸虫是经皮肤途径，这一点不同，所以应对方式也不同。经口途径可以通过煮熟来切断。囊蚴不耐热，在沸水中稍微焯一下就会死亡。经皮肤途径与煮熟无关，只能通过在水中作业时避免裸露的皮肤长时间接触水来减少。

| 应对措施 | 防止什么 |
|---|---|
| 一定要煮熟后食用。焯、炒、做汤，无论哪种都要充分加热 | 姜片吸虫、肝片吸虫、粪便细菌 |
| 用流水把茎内和叶腋也多次冲洗干净 | 减少表面附着的东西。但仅靠这一点是不够的 |
| 下水作业时用长筒靴和衣服遮住裸露的皮肤 | 血吸虫 |
| 不使用混有粪便的水和畜舍下游的水 | 切断这三者共同的根源 |
| 在养鸭或养鱼的水里长出来的，要格外彻底地煮熟 | 粪便途径的风险高 |

> **蕹菜是必须煮熟后才能吃的蔬菜。不能把像生菜那样洗一洗就生吃的习惯用在这种作物上。煮熟吃的损失只是一部分维生素C，不煮熟的损失则是寄生虫。**

&nbsp;&nbsp;&nbsp;评价表中的烹饪·加工之所以是A，比洗净即可直接食用的作物的SS低一级，原因就在这里。蕹菜必须用火，在燃料紧缺的情况下，这是实实在在的成本。不过，炒制5分钟内就能完成，与豆子煮一个小时相比，轻松得无法相提并论。

### 14-4. 其他注意事项

| 项目 | 内容 |
|---|---|
| 硝酸盐 | 在施氮肥较多的叶菜中积累。减少的方法见第10节 |
| 草酸 | 含有微量，但比菠菜或莙荙菜少得多，实际上不成问题 |
| 钾 | 每100g含489mg，属于较多。对肾功能下降的人来说，焯水后把水倒掉的更好 |
| 过量摄入 | 在正常量下没有报告过明显的副作用 |

## 15. 无冰箱贮藏

### 15-1. 为什么这么难

&nbsp;&nbsp;&nbsp;评价表中的耐储性为E，在无电力常温下为2-3天。原因很简单：水分超过90%，组织娇嫩。收获之后，细胞仍会存活一段时间，进行呼吸并消耗自身的糖分，由于根部不再供水，植株逐渐干枯，同时细菌和霉菌钻进娇嫩的组织。茎是空心的、空气能到达内部的结构，也加快了腐坏的速度。

| 方式 | 方法 | 时长 |
|---|---|:---:|
| 直接放置 | 不洗，甩掉水分，放在阴凉处 | 1-2天 |
| 用纸包裹 | 用湿纸或湿布包好，放在凉爽处 | 2-3天 |
| 基部泡水 | 像插花一样，把基部泡在水里竖着放 | 2-3天 |
| 土窖或井边 | 放在凉爽处能多放一点 | 3-4天 |

&nbsp;&nbsp;&nbsp;把基部泡在水里竖着放的方法，原理是让茎持续吸水，延缓萎蔫。能多撑一两天，但水一变温，基部就会先烂，所以要经常换水。

### 15-2. 田地就是贮藏库

> **蕹菜贮藏问题最可靠的答案是不贮藏。它在田里立着的时候不会腐坏，所以当天吃多少就当天割多少。**

&nbsp;&nbsp;&nbsp;如果是必须一次性全部收完的作物，耐储性E会是致命的，但蕹菜越割越长。立着二十株，每天割几根，就根本不会出现贮藏这个问题。需要贮藏的时候只有一个，就是霜冻前夕必须一次性处理剩余部分的时候。

### 15-3. 长期保存的方法

| 方式 | 步骤 | 时长 | 原理 |
|---|---|:---:|---|
| 晒干 | 在沸水中焯30秒后用冷水冲洗，挤掉水分，放在阴凉处彻底晾干 | 6个月至1年 | 去掉水分，细菌和霉菌就无法繁殖。焯水是为了灭活酶，防止颜色和味道改变 |
| 盐腌 | 用重量3-5%的盐一层层腌好并压住 | 2-3个月 | 盐把水分析出，并通过渗透压抑制微生物 |
| 做韩式泡菜 | 腌好后加调料，装入坛子，放在凉爽处 | 2-3个月 | 乳酸菌产酸，抑制其他微生物 |
| 酱菜 | 焯水后泡进酱油或大酱里 | 数月 | 盐分和发酵共同起作用 |
| 冷冻 | 焯水后挤掉水分，冷冻 | 数月 | 只有有电时才能做。可以用隆冬的严寒代替，但那时已经没有作物了 |

&nbsp;&nbsp;&nbsp;在灾害情况下最实用的是晒干。既不需要电，也不需要盐和坛子，只要有阳光和风就行，体积缩小到10%，占用的保管空间也小。不过，在晒干的过程中维生素C几乎全部消失，β-胡萝卜素也会大幅减少。剩下的是纤维、矿物质和少量蛋白质，作为冬天煮汤的材料不错，但很难指望它作为维生素的来源。

| 晒干时要遵守的事项 | 原因 |
|---|---|
| 不要直接在阳光下晒，而是在阴凉通风处晾干 | 直射阳光会破坏色素和维生素 |
| 摊薄，不要重叠摆放 | 重叠的话，中间不会干，还会长霉 |
| 晾到完全干透为止。用手搓能碎就是好了 | 水分残留的话，保管中会长霉 |
| 密封后放在阴暗凉爽处 | 重新吸潮就会变质 |

## 16. 烹饪与加工

### 16-1. 节省燃料的方法

&nbsp;&nbsp;&nbsp;蕹菜必须煮熟，但不需要煮很久。组织娇嫩，热量很快就能透入，煮久了反而会烂。在燃料紧缺的情况下，这一特性是个优势。

| 方法 | 时间 | 燃料 | 保留的营养 |
|---|:---:|:---:|---|
| 旺火快炒 | 2-5分钟 | 最少 | 维生素C保留较多。β-胡萝卜素与油在一起，吸收更好 |
| 焯水 | 30秒至1分钟 | 少 | 水溶性维生素会流失到水中。用那些水就能找回来 |
| 汤或韩式炖汤（jjigae） | 5分钟 | 中等 | 流失的营养留在汤里，一起吃下去 |
| 蒸 | 3-5分钟 | 少 | 水溶性损失比焯水少 |

&nbsp;&nbsp;&nbsp;东南亚主要把蕹菜炒着吃，是有原因的。时间短，耗燃料少，营养损失小，油能帮助β-胡萝卜素的吸收，茎脆嫩的口感也得以保留。没有油的话，只放一点水，盖上锅盖，像蒸一样炒也可以。

&nbsp;&nbsp;&nbsp;把茎和叶分开下锅是个要领。先把茎煮1分钟左右，再放叶子，两者都能熟得恰到好处。一起下锅的话，等叶子烂掉了，茎还没熟透。

### 16-2. 如何食用

| 方式 | 内容 |
|---|---|
| 炒 | 与大蒜一起旺火快炒。最常见，也最高效 |
| 汤和炖汤 | 放进大酱汤或清汤里。煮久了会烂，所以最后放 |
| 凉拌 | 焯水后挤掉水分，用调料拌。这是当作凉拌野菜（namul）食用的方式 |
| 粥 | 切碎放进谷物粥里。适合消化能力弱的人 |
| 泡菜 | 腌渍后做成韩式泡菜。兼具贮藏作用 |
| 干品复水 | 用温水泡20-30分钟，用于做汤或炒菜 |

&nbsp;&nbsp;&nbsp;评价表中口味等级所附的“口感令人排斥”这一说明，大部分来自茎。把老硬的茎切掉，或者斜着切成薄片以切断纤维，会改善很多；粗茎对半劈开再下锅，熟得快，也容易咀嚼。

### 16-3. 保住营养的烹饪

| 原则 | 理由 |
|---|---|
| 先洗后切 | 切后再洗，维生素会从切口流失到水里 |
| 洗后不要在水里久泡 | 水溶性营养会不断流失 |
| 盖上锅盖，短时间煮熟 | 蒸汽被封在里面，熟得快，耗燃料少 |
| 把焯水的水当汤用 | 能找回流失的营养。不过有硝酸盐顾虑时要倒掉 |
| 哪怕少量也要用油 | β-胡萝卜素要溶于油才能被吸收 |

## 17. 全年作业日程

### 17-1. 月度表（以韩国气候为准）

| 月份 | 淹水栽培 | 旱地栽培 | 其他工作 |
|---|---|---|---|
| 1月 | 休息 | 休息 | 室内插穗管理。换水，保持10度以上 |
| 2月 | 休息 | 休息 | 室内插穗管理。把长长了的茎剪下重新插，增加株数 |
| 3月 | 休息 | 休息 | 准备堆肥。确认种子状态 |
| 4月 | 整理场地，修补田埂 | 翻耕并施堆肥 | 可以在室内开始育苗 |
| 5月 | 中旬以后灌水，播种或扦插 | 中旬以后播种或扦插 | 确认霜冻结束。让室内的插穗适应室外 |
| 6月 | 保持水深15-20cm，首次收获 | 浇水、覆盖、首次收获 | 首次摘心，增加侧枝 |
| 7月 | 反复收获，收获后追肥 | 反复收获，每天浇水1-2次 | 韩国的梅雨季（6月下旬至7月）要保证通风。留意霜霉病 |

### 17-2. 贯穿全年的主线

&nbsp;&nbsp;&nbsp;蕹菜的一年分为五个月在田里和七个月在室内。在韩国，从5月中旬到10月初在田里旺盛生长，其余七个月在种子袋里或窗边的水碗里等待来年。忽视这一结构，就会这一年成功了，到了次年却什么都没有。

&nbsp;&nbsp;&nbsp;所以，这张表中最重要的格子不是夏季的收获栏，而是8月初和10月。8月初不把留种用的植株分出来，就没有种子；10月不把插穗剪下来拿进室内，就没有活的茎。

> **夏季五个月的收获，建立在8月初留下几株的判断，以及10月剪下几根茎拿进室内的这双手上。这种作物，延续的技术比收获的技术更难。**
