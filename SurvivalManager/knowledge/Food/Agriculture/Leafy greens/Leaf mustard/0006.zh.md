## 13. 留种 - 一年生的优势与杂交的陷阱

### 13-1. 芥菜不必越冬

&nbsp;&nbsp;&nbsp;使十字花科作物留种变得困难的最大因素，是二年生的习性。结球甘蓝、羽衣甘蓝、大白菜、萝卜要想收到种子，必须经历冬季的低温，才会抽出花茎。第一年只长叶片或根，越冬之后，到第二年春天才开花。这样要在田里占用一年半的时间，而且期间还得承担冻死的风险。

&nbsp;&nbsp;&nbsp;对芥菜来说，这道门槛很低。春天播种的芥菜，随着气温升高、日照变长，当年内就会抽出花茎、开花、结籽。必须经历低温这一绝对条件，对它要么不存在，要么作用很弱。实际上可以把它当作一年生植物来对待，这是芥菜在灾害情况下最大的战略优势。

| 作物 | 生活型 | 到留种所需时间 | 冬季管理 |
|:---|:---|:---|:---|
| 芥菜 | 一年生（易抽薹） | 春播后约100天 | 不需要 |
| 萝卜 | 二年生 | 播种后一年半 | 须让根越冬 |
| 大白菜·结球甘蓝·羽衣甘蓝 | 二年生 | 播种后一年半 | 须让植株越冬 |
| 生菜 | 一年生 | 播种后约100天 | 不需要 |

&nbsp;&nbsp;&nbsp;因此，在灾害第一年的种子计划中，芥菜的地位很特别。把春天播种的几株芥菜不拔掉，就那样留着，在韩国到6月至7月就会产出种子。由于种子寿命为5年，收一次就能管上好几年。秋天播种的芥菜情况不同，它要越冬，到第二年春天才抽出花茎。春播留种和秋播越冬留种，两条路都是敞开的。

### 13-2. 会与什么杂交

&nbsp;&nbsp;&nbsp;芥菜留种的难关是杂交。芥菜是可以自花授粉的作物，用自己的花粉也能结籽，但蜂类和苍蝇往来飞动，会使相当比例的花发生异花授粉。评价表中自家留种A、隔离500m这一标准就源于此。它比羽衣甘蓝或结球甘蓝这类存在自交不亲和性、必须有其他植株才能结籽的作物容易，但比生菜这种实际上完全自花授粉的作物要麻烦。

| 作物 | 学名 | 与芥菜的杂交 |
|:---|:---|:---|
| 芥菜、芥菜类叶菜（gyeojachae）、速生芥菜类 | Brassica juncea | 完全杂交 |
| 大白菜、青梗菜、芜菁、油菜 | Brassica rapa | 可能以较低频率杂交 |
| 黑芥 | Brassica nigra | 可能以较低频率杂交 |
| 结球甘蓝、羽衣甘蓝、西兰花、球茎甘蓝 | Brassica oleracea | 基本不会杂交 |
| 萝卜 | Raphanus sativus | 属不同，不会自然杂交 |

&nbsp;&nbsp;&nbsp;这张表的依据是染色体。芥菜是同时拥有白菜的一套染色体（A基因组）和黑芥的一套染色体（B基因组）的复二倍体。因此，它与拥有A基因组的白菜类、拥有B基因组的黑芥之间，染色体可以部分配对，于是会以较低的概率产生杂种。相反，结球甘蓝类拥有C基因组这种完全不同的染色体构成，因此在自然状态下不会发生杂交。

&nbsp;&nbsp;&nbsp;从实际操作来总结，情况是这样的。在收芥菜种子的那一年，羽衣甘蓝、结球甘蓝或西兰花同时开花，不必在意。真正成为问题的，第一是其他品种的芥菜，第二是大白菜、芜菁和油菜。尤其是其他品种的芥菜，会100%混杂。如果把绿叶芥菜和红叶芥菜并排种着并让两者都开花，第二年就会长出颜色混杂、来历不明的芥菜。

### 13-3. 防止杂交的三种方法

| 方法 | 内容 | 现实性 |
|:---|:---|:---|
| 隔离距离 | 与其他开花植株相距500m以上 | 无法控制邻近田块，因此很难做到 |
| 错年栽培 | 每年只让一个品种开花 | 最为现实 |
| 罩网 | 开花前罩上网，阻止蜂类进出 | 芥菜可以自花授粉，所以效果确切 |

&nbsp;&nbsp;&nbsp;对芥菜来说，罩网尤其有效。羽衣甘蓝或结球甘蓝存在自交不亲和性，需要人在网内用毛笔转移花粉；而芥菜用自己的花粉就能受精，所以罩上网放着不管也能结籽。蜂进不去，纯度就能得到保证；没有蜂，结实也没有问题。这样的组合在十字花科作物中是难得的条件。

&nbsp;&nbsp;&nbsp;如果没有网，就采用错年栽培。今年只让绿叶芥菜开花，红叶芥菜全部收割食用；明年则反过来。由于种子寿命为5年，每个品种即使每3年才留一次种，也不会断档。这种方式能以最少的功夫保持纯度。

&nbsp;&nbsp;&nbsp;隔离距离500m是原则，但在狭小的土地上很难做到。不过，即使不是完全隔离也有意义。距离越远，杂交率越低；如果中间有建筑物、树木或山丘等阻挡蜂类移动的障碍物，有效距离就会增加。

> **留种用的植株至少要留十株以上。即使是能自花授粉的作物，如果一直只从一两株上收种，遗传多样性就会变窄，植株长势随之减弱。**

### 13-4. 留种程序

| 步骤 | 时期 | 内容 |
|:---|:---|:---|
| 选留种株 | 收获期 | 选择叶片大、品种特性明显、无病的植株 |
| 抽薹 | 韩国春播为5-6月，秋播为第二年3-4月 | 花茎抽起。立支柱防止倒伏 |
| 开花 | 抽薹后2-3周 | 开出黄色的花。此时要做好隔离 |
| 结角 | 开花后 | 结出细长的角果 |
| 收获 | 开花后50-55天 | 2/3的角果变成褐色干枯时，连茎割下 |
| 后熟·脱粒 | 收获后立即 | 在阴凉处晾干1-2周后装入袋中拍打 |
| 精选 | 完全干燥后 | 用簸箕簸掉秕粒 |
| 保管 | 含水量10%以下 | 装入密封容器，放在凉爽阴暗处 |

&nbsp;&nbsp;&nbsp;不能把角果留在田里等到全部干枯。十字花科的角果完全干枯后会自行裂开，把种子撒落在地上。芥菜这一特性尤其强，晚一两天就没有什么可收的了。要领是在下部2/3的角果变成褐色、上部还是绿色的时候，连茎割下，在阴凉处后熟。把割下的茎放在布或袋子上晾干，就连裂开掉落的种子也能收回。

| 项目 | 标准 |
|:---|:---|
| 种子寿命 | 常温密封5年 |
| 最佳保存 | 凉爽、阴暗、干燥处，密封容器 |
| 干燥剂 | 炒后放凉的大米、木炭、干燥的草木灰 |
| 发芽检查 | 每年取20粒放在湿布上，几天后统计发芽率 |
| 每株产量 | 种子数千粒 |
| 留种周期 | 每3-4年一次，当年要严格做好隔离 |

&nbsp;&nbsp;&nbsp;一株芥菜能产出数千粒种子，十株就能一次性备足好几年的种子。再加上5年的种子寿命，留种就不是每年都要做的事了。每3-4年一次，只在那一年做好隔离后留种即可。其余年份，所有芥菜都可以用来食用。

## 14. 毒性与需注意的成分

&nbsp;&nbsp;&nbsp;芥菜没有急性毒性。洗净后可以直接食用，评价表中烹饪·加工等级为SS就反映了这一点。不过，在大量且长期食用时，有一些需要考虑的成分。

| 成分 | 是什么物质 | 会造成什么问题 | 减少的方法 |
|:---|:---|:---|:---|
| 芥子油苷（黑芥子苷） | 十字花科辛辣味和香气的来源 | 吃多了会刺激胃肠 | 加热会破坏酶，不再产生辛辣味 |
| 致甲状腺肿素 | 芥子油苷的部分分解产物 | 妨碍碘的吸收，可能降低甲状腺功能 | 焯水、摄入海藻类 |
| 草酸 | 植物与钙结合后储存的有机酸 | 吃多了会提高肾结石的风险 | 芥菜的含量偏低。焯水后倒掉水，还能进一步降低 |
| 硝酸盐 | 在施氮多的叶片中积累 | 摄入过量时会成问题 | 不过量施氮，避免在收获前不久施肥 |

### 14-1. 辛辣味在多大程度上是安全的

&nbsp;&nbsp;&nbsp;芥子油苷在一般摄入量下是安全的。成问题的是量和状态。一次生吃大量芥菜，烯丙基异硫氰酸酯会刺激胃黏膜，可能引起胃灼热。胃弱的人，与生吃相比，煮熟或腌制后食用更安全。

> **第一次吃时要从少量开始。对辛辣味的反应个体差异很大，而在灾害情况下，因新的食物而出问题，本身就是危险的事。**

### 14-2. 致甲状腺肿素与碘

&nbsp;&nbsp;&nbsp;芥子油苷分解时产生的物质中，有一部分会干扰甲状腺利用碘的过程。这类物质被称为致甲状腺肿素（Goitrogen）。摄入足够碘的人吃普通量的芥菜，不会有问题。会变得危险的条件，是在缺碘的饮食中长期大量生吃十字花科蔬菜。

&nbsp;&nbsp;&nbsp;在灾害情况下，这个条件是真有可能出现的。物流中断、远离大海后，裙带菜、海带和紫菜就会消失，而精制盐中也往往不含碘。在这种状态下如果主要只吃十字花科蔬菜，甲状腺功能可能会下降。应对办法有两种。一是掺入煮熟食用的形式。加热会破坏黑芥子酶，致甲状腺肿素的生成本身就会减少，倒掉焯水的水，水溶性成分也会随之流失。另一种是在能弄到海藻类时先储备起来。干裙带菜和海带在常温下能放很久，少量就足够了。

## 15. 无冰箱贮藏 - 芥菜的本领

&nbsp;&nbsp;&nbsp;芥菜的耐储性等级为D，在无电力的常温下很难超过一周。不过，这个等级说的是把生叶原样放置的情况。芥菜从一开始就不是以鲜品保存的作物，而是用来腌制的作物，一遇到盐，贮藏期就会从几个月延长到一年以上。

### 15-1. 鲜品短期保存

| 方式 | 方法 | 期间 |
|:---|:---|:---:|
| 阴凉处存放 | 不洗，晾干水分后放在通风阴凉处 | 3-5天 |
| 湿布包裹存放 | 用湿布包好，放在地窖、土洞或朝北的屋檐下 | 5-7天 |
| 留在田里 | 初霜之前一直立在田里，只割取需要的量 | 到初冬 |

&nbsp;&nbsp;&nbsp;最后一行实际上是最有用的方法。芥菜能耐受零下5℃的低温，所以可以一直留在田里到初冬，需要时再割回来。田地本身就起到了仓库的作用。不过它不像羽衣甘蓝那样能熬过隆冬，所以要在真正的严寒到来之前收拾好，转入腌制。

### 15-2. 芥菜泡菜（gatkimchi）

&nbsp;&nbsp;&nbsp;在芥菜的各种贮藏方法中，核心是韩式泡菜。芥菜泡菜比大白菜泡菜保存更久是有原因的。芥菜的烯丙基异硫氰酸酯起抗菌作用，抑制杂菌的增殖，而主导发酵的乳酸菌受到的妨碍相对较小。腌得好的芥菜泡菜在凉爽处能放几个月到一年以上。

| 步骤 | 内容 |
|:---|:---|
| 腌渍 | 在3-4%的盐水中浸泡3-4小时。茎能弯曲的程度即可 |
| 漂洗 | 漂洗一两次，沥干水分 |
| 调料 | 拌入辣椒粉、大蒜、生姜、咸鱼虾酱（jeotgal） |
| 装坛 | 压紧装入坛中，使汤汁没过材料 |
| 熟成 | 放在凉爽处使其成熟 |

&nbsp;&nbsp;&nbsp;必须以没有调料的情况为前提。即使没有辣椒粉和jeotgal，也能腌制韩式泡菜。把盐浓度调到2-3%，并使材料完全浸没在汤汁里，乳酸发酵就会进行。芥菜本身有辛辣味，所以即使没有其他调料，味道也不会寡淡。

> **乳酸发酵的关键有两点：材料必须完全浸没在汤汁之下，盐浓度不能降到2%以下。这两个条件得到保证，生长的就是乳酸菌，而不是杂菌。**

&nbsp;&nbsp;&nbsp;乳酸发酵在灾害情况下最大的价值是保存维生素C。晾干或煮制的贮藏方法会损失大部分维生素C，而发酵能保留相当多的量。在冬季漫长的地区，腌渍文化发达并非偶然。

### 15-3. 盐藏

| 方式 | 方法 | 期间 |
|:---|:---|:---:|
| 盐腌 | 按10-15%的盐量层层码放，压紧装入坛中 | 几个月-1年以上 |
| 使用方法 | 使用前在水中浸泡两三次，去除盐分 | |

&nbsp;&nbsp;&nbsp;盐藏是最简单、保存最久的贮藏方法。盐浓度超过10%，连乳酸菌也无法活动，所有微生物都会停止。既不发酵也不腐败，进入静止状态，因此能撑过一年。代价是几乎不剩维生素C。

&nbsp;&nbsp;&nbsp;备有多少盐，决定了在盐藏和泡菜之间如何选择。盐充足就用盐藏来长期保存，盐珍贵就采用2-3%的泡菜式发酵。因为两者的用盐量相差五倍。

### 15-4. 干燥与陈年干菜（mungnamul）

| 步骤 | 方法 |
|:---|:---|
| 焯水 | 在沸水中焯30秒，用冷水冲洗 |
| 挤水 | 用手用力挤干 |
| 干燥 | 摊晾在阴凉通风处，彻底晾干 |
| 保管 | 装入密封容器，同时放入木炭或炒米 |
| 期间 | 6个月-1年以上 |
| 使用 | 用水泡发煮熟后，拌成凉拌野菜（namul）或放入汤中 |

&nbsp;&nbsp;&nbsp;焯过再晒干有两个原因。一是破坏酶，防止保管期间变色变质；二是使组织变软，以后泡发时容易松开。没有焯水就晒干的芥菜会变黄，泡发后也很韧。不过，晒干的芥菜几乎不会保留维生素C。干燥后留下的是膳食纤维、矿物质，以及相对耐热的β-胡萝卜素。在冬季饮食中，干制品是缩小体积来贮藏的手段，维生素C则来自发酵食品和田里留下的生叶。

### 15-5. 酱菜（jangajji）

&nbsp;&nbsp;&nbsp;如果有酱油或大酱，酱菜就是另一条路。把芥菜粗壮的茎用盐稍微腌一下、沥干水分后，埋入酱中放着，能保存几个月。原理与盐藏相同，高盐浓度和酱类的抗菌成分使微生物停止活动。

| 方式 | 预计期间 | 所需材料 | 特点 |
|:---|:---:|:---|:---|
| 鲜品短期 | 3-5天 | 无 | 新鲜度最高 |
| 芥菜泡菜 | 几个月-1年以上 | 盐和调料 | 保留相当多的维生素C |
| 盐藏 | 几个月-1年以上 | 盐（大量） | 最简单也最可靠 |
| 干燥·陈年干菜 | 6个月-1年 | 无 | 体积和重量大幅减小 |
| 酱菜 | 几个月 | 酱油或大酱 | 咸味小菜。兼作盐的来源 |

## 16. 烹饪与加工

| 方法 | 燃料 | 辛辣味 | 维生素C保留 | 备注 |
|:---|:---:|:---|:---:|:---|
| 生食（叶菜包饭ssam、现拌凉菜geotjeori） | 无 | 最强 | 最大 | 适合嫩叶 |
| 焯水30秒-1分钟 | 极少 | 大幅减弱 | 一半以上 | 致甲状腺肿素也随之减少 |
| 放入汤或粥中 | 与其他烹饪同时进行 | 减弱 | 连汤一起吃则得以保留 | 不另外耗用燃料 |
| 炒 | 少 | 减弱 | 中等 | 有助于β-胡萝卜素吸收 |
| 泡菜·发酵 | 无 | 转化为鲜味 | 保留相当多的量 | 兼具贮藏与烹饪 |
| 晒干磨粉 | 干燥时用阳光和风 | 几乎消失 | 几乎没有 | 矿物质和β-胡萝卜素得以保留 |

&nbsp;&nbsp;&nbsp;在燃料珍贵的情况下设计芥菜的烹饪方式时，基准是对辛辣味的处理。如果难以承受生芥菜的辛辣味，有两条路：加热，或者发酵。加热耗费燃料，发酵耗费时间。灾害情况下通常时间比燃料更充裕，所以从结构上看，发酵一方更有利。

&nbsp;&nbsp;&nbsp;加热使辛辣味消失的原理是破坏酶。烯丙基异硫氰酸酯要在黑芥子苷与黑芥子酶相遇后才会产生，而这种酶是蛋白质，不耐热。放进沸水里哪怕只泡30秒，大部分也会失去活性。所以焯过水的芥菜几乎不辣。反过来，如果想保留辛辣味，就把叶片捣碎或切开，在常温下放一会儿再烹饪。在这期间酶会发挥作用，辛辣物质已经生成，之后即使加热，这种物质本身也会大部分保留下来。

&nbsp;&nbsp;&nbsp;制作芥末酱的原理也相同。把芥菜的种子捣碎，用温水调开放置，10-15分钟内酶就会发挥作用，辛辣味随之产生。这时加入醋，酶就会停止，当时的辛辣程度被固定下来。如果用热水调，酶会被杀死，就不辣，只有苦味。连种子也利用的话，从一株芥菜上就能同时得到叶子和调味料。

&nbsp;&nbsp;&nbsp;只要有一点油，就最好掺入炒制的烹饪方式，这在营养上更有利。芥菜的β-胡萝卜素是脂溶性的，必须有油才能被吸收。没有油时，可以把紫苏（荏）籽或芝麻捣碎拌入来代替。

| 月份 | 作业 |

&nbsp;&nbsp;&nbsp;从这张表中应当读出的是，在韩国，芥菜的一年由两个高峰构成。春季的高峰短而早：3月下旬播种，5月收获，留着不拔，7月收种。秋季的高峰长而厚：从8月下旬起分批播种，10月和11月收获，收获物转入泡菜和盐藏，越过冬天。

&nbsp;&nbsp;&nbsp;两个高峰的作用不同。春播芥菜更接近以获取种子为目的的农事，秋播芥菜则是获取食物的农事。在灾害第一年，这一区分尤其重要。

> **灾害第一年的春播芥菜，一半吃掉，另一半留作种子。留下的那一半，决定了当年秋天和第二年的全部。**
