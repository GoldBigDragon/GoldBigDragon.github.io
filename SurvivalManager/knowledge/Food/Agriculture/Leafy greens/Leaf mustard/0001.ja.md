## はじめに
&nbsp;&nbsp;&nbsp;カラシナ(Brassica juncea)は、中央アジアでハクサイ(Brassica rapa)とクロガラシ(Brassica nigra)が自然交雑してできた複二倍体の葉物野菜です。総合等級はB(44.3点、有効183種中65位)、副食はSS(58.7点)です。100g当たり36kcalしかなく、1日2,100kcalをカラシナだけで満たそうとすると5.8kgを食べなければならないため、カラシナはご飯茶碗ではなく食卓のほかの部分を満たす作物であり、生の葉よりも塩と出会って保存食になる方向に特化しています。辛味成分のシニグリンとその分解物アリルイソチオシアネートは雑菌にとって殺菌剤なので、カラシナキムチ(カッキムチ)はハクサイキムチより遅く酸っぱくなり、長くもちます。弱点は、微量栄養素D(21種のうち8種)、味D(においと香りへの抵抗感)、永続性C(1回収穫すれば終わり)です。一方で、播種から収穫まで45-60日(若葉は20-30日)という速さ、常温で密閉して5年という種子の寿命、冬を越さなくても種が採れる一年草の性質があり、災害の初年度に種の自立を果たせる数少ないアブラナ科作物です。カラシナは畑の主役ではなく、畑の保険です。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | アブラナ科アブラナ属の一年草(とう立ちしやすい)で、秋にまくと冬を越す越冬一年草。ハクサイとクロガラシの染色体をともに持つため、これらとは低い頻度で交雑し、キャベツの仲間とは交雑しない |
| 葉、茎 | 縁がぎざぎざで表面がやや縮れ、緑色、赤紫色、混合色がある |
| 根、花、莢 | 主根は大部分が地表から10-15cmの範囲に浅く分布する。黄色い花が咲き、細長い莢に直径1-2mmの褐色-赤褐色の種子が並ぶ |

| 段階 | 時期(播種後) | 要点 |
|:---|:---|:---|
| 発芽、初期の栄養成長期 | 20日まで | 種子が水を吸って子葉が開き、本葉が出て根が定着する。窒素 |
| 急速な栄養成長期 | 20-45日 | 葉と茎が急に大きくなる。窒素、カリウム |
| 収穫適期 | 45-60日 | 葉が育ちきって、まだ硬くなっていない |
| とう立ち、開花期 | 60-100日 | 花茎が立ち、葉が硬くなる。リン酸、カリウム |

> **カラシナは生育期間が短いため、初期の養分供給が収量をほぼ決めます。追肥で取り戻す時間がないので、元肥の段階で勝負がつきます。**

&nbsp;&nbsp;&nbsp;花茎は、一定期間の低温(0-10℃)を経験したあと日が長くなるとき(春に早くまいたカラシナ)と、高温・乾燥ストレスを受けたとき(真夏にまいたカラシナ)に立ち、どちらも葉が硬くなって辛味だけが強まり、食べにくくなります。そのため作型は春と秋に分かれ、夏が空いています。

&nbsp;&nbsp;&nbsp;100g当たり熱量36kcal、タンパク質3.50g(熱量比38.9%)、食物繊維2.6g、βカロテン533㎍です。タンパク質の比率が高いのは熱量が小さいからですが、米やジャガイモ(タンパク質比率8-9%)が中心の食事に添えると、熱量を増やさずにタンパク質の比率を上げます。βカロテンは脂溶性なので、油や、すったエゴマ・ゴマを添えると吸収がよくなります。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 生育適温15-20℃(可能10-25℃)。発芽は6-35℃(最適25℃で3-5日)。25℃以上になると葉が薄く硬くなって辛味が強くなりすぎ、氷点下5℃より低いと葉が凍って軟らかくなる |
| 光 | 1日6時間以上の直射日光。40%遮光で相対収量86%。好光性種子なので、深く埋めると発芽率が急落する |
| 水、土壌 | 総蒸発散量は約300mm。根が浅く、表土が乾くと生育が止まり、過湿には根腐れ。肥沃で保水力のよい土壌、pH6.0-7.5(6.0より低いと根こぶ病がひどくなる) |

| 品種 | 特徴と用途 |
|:---|:---|
| 青カラシナ(チョンガッ) | 葉が青く辛味が強く、耐寒性と耐病性が強い。キムチ用として最も広く使われる |
| 赤カラシナ(ジョッガッ、ホンガッ) | 葉が赤くアントシアニンが多く、辛味は中程度。キムチ、包み野菜、漬物 |
| トルサンカラシナ(トルサンガッ) | 葉が大きく幅広い晩生種で軟らかい。カラシナキムチ専用 |
| 耐寒青カラシナ(オルチョンガッ) | 寒さに強く、マイルドな味。冬の栽培と早春の収穫 |
| 野生カラシナ(トゥルガッ) | 野生種に近く、香りが強くて粗い。病害虫に強く、自分で種を落とす |

&nbsp;&nbsp;&nbsp;辛味の強さがそのまま貯蔵力の強さです。アリルイソチオシアネートが多いカラシナで漬けたキムチは腐敗菌の増殖が遅く、冬じゅう食べるキムチには青カラシナが、初冬にすぐ食べるキムチにはトルサンカラシナが合います。災害時の品種選びの第一基準は、収量ではなくリスクの分散です。青カラシナと赤カラシナのように性質の違う2、3品種を混ぜてまくと、どれかが病気にやられてもほかの品種が生き残り、収穫時期も2-3週間に分かれます。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 土づくり | 20-30cmの深さに耕し、土塊を砕いて平らにならす(土塊が大きいと好光性の種子が埋まる)。畝の高さ15-20cmと排水溝。pHを6.0-7.5に合わせ、酸性なら木灰を混ぜる |
| 施肥(1,000㎡) | 窒素8-10kg、リン酸6-8kg、カリウム6-8kg、堆肥1,000-1,500kgを、播種の1-2週間前に全量元肥として入れる(未熟な堆肥は若い根を傷める)。追肥は、効果が出るころにはすでに収穫期なので省き、生育が目に見えて悪いときだけ少量 |
| 代替資源 | 完熟堆肥(1㎡当たり1-1.5kg)、木灰(1㎡当たり一つかみ。カリウムの供給・酸度の矯正・根こぶ病の抑制・害虫の忌避を兼ねるが、多いと微量要素の吸収が妨げられる)、尿の10-15倍希釈液(本葉5-6枚のときに1回、収穫の2週間前から中止)、骨粉 |

| 作型 | 播種 | 収穫 | 備考 |
|:---|:---|:---|:---|
| 秋作 | 8月下旬-9月中旬 | 9月下旬-10月末 | 最も安定。40-60日 |
| 越冬作 | 10月下旬-11月中旬 | 翌春 | 南部で可能。中部はわらや落ち葉で覆うか風よけ |
| 春作 | 3月下旬-4月上旬 | 4月中旬-5月上旬 | 雪解け後すぐに。遅れるととう立ち |
| 夏作、高冷地 | 6月上旬-7月上旬 | 7-8月 | 標高400m以上でのみ。中低地の露地では花茎が先に上がり、種と労力だけが失われる |

&nbsp;&nbsp;&nbsp;災害時は秋作が中心です。気温が下がる方向なのでとう立ちの危険がなく、害虫の活動が減り、収穫物がそのままキムジャン(越冬用キムチの漬け込み)と貯蔵につながり、夏作物が終わった畑の空きを埋めます。

| 播種 | 基準 |
|:---|:---|
| 方法 | 深さ0.5-1cmで、細かい土を種が隠れる程度だけかぶせ、手や板で軽く押さえて種と土を密着させる。条間15-20cm、最終の株間10-15cm、播種量は1,000㎡当たり2-3kg |
| 時期をずらした播種 | 10日から15日おきに分けてまく(秋なら8月下旬、9月上旬、9月中旬)。1回収穫すれば終わる永続性Cを補う唯一の方法 |
| 種子の処理 | しいなを除き、水に3-4時間浸して沈んだものだけを使う。50-55℃のお湯に10-15分浸してから冷水で冷ます(60℃を超えると種が死に、45℃より低いと病原菌が生き残る) |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から発芽 | 表土が乾かないように軽く頻繁に(水を吸って膨らんだあと乾くとそのまま死ぬ) |
| 幼苗期、急速な成長期 | 表土が乾いたら濡らす(根が浅く乾燥にとても弱く、この時期の水分が葉の大きさを決める) |
| 収穫直前、梅雨 | 収穫直前はやや控え(葉が締まって貯蔵に有利)、梅雨には排水溝を確保する(過湿による根腐れのほうが大きな危険) |

&nbsp;&nbsp;&nbsp;昼にしおれて夕方に回復すれば一時的な不足、葉が小さく厚くなって辛味が強まれば継続的な乾燥です。下の葉が黄色くなれば根の酸素不足で、株元が軟らかくなってにおいがすれば、その株は救いにくくなります。乾燥ストレスは辛味を強めるので、キムチ用は収穫の1週間前から水を控えます。マルチにはわら、枯れ草・落ち葉、もみ殻を使い、夏の昼に表土が40℃を超えると根が働かなくなるので、1層あるだけで大きな差になります。

| 管理 | 方法 |
|:---|:---|
| 間引き | 本葉2-3枚で3-5cmに1回目、4-5枚で10-15cmに2回目(最終)。必須の作業(密植すると茎だけが伸び、風通しが悪くなってべと病や灰色かび病が出る)。抜かず、はさみや爪で地面近くから切り、隣の株の浅い根を守る。間引いた若いカラシナは最初の収穫で、播種20日ごろは軟らかく、包み野菜や浅漬けで食べる |
| 雑草 | 最初の3週間が勝負。本葉3-4枚以降はわらや枯れ草でマルチ。小さな鍬は浅くかく(根が浅い) |

&nbsp;&nbsp;&nbsp;とう立ちした株は元に戻せず、花茎を切っても脇からまた上がるので、花茎が立つ前に収穫が終わるように播種時期を決めるのが唯一確実な方法です。つぼみがついた若い花茎はナノハナやブロッコリーに似た味で、春に野菜が乏しい時期に重宝し、種を採る株だけを残して摘んで食べます。

## 6. 病害虫と養分の問題
| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| ノミハムシ | 葉に針で刺したような穴が密にできる。子葉と若い本葉の段階でやられると枯れる | 発芽直後から本葉3-4枚まで防虫ネット、木灰 |
| アブラムシ | 葉の裏に群がって汁を吸い、葉が縮れる | 石けん水、木灰、テントウムシを守る |
| モンシロチョウの幼虫、コナガ | 葉に大きな穴 / 葉の裏に半透明の跡 | 防虫ネット(成虫に産卵させない)、手で捕る、葉の裏の黄色い卵をこすり落とす |
| 根こぶ病 | 根にこぶができて株がしおれる。酸性土壌、アブラナ科の連作 | 治療不可。酸度の矯正、排水、輪作 |
| べと病、灰色かび病、軟腐病 | 葉の裏の白色-灰色のかびと表の黄変 / 灰色のかび(涼しく湿っているとき) / 株元が軟らかくなって悪臭(高温多湿、傷) | 風通し、間隔の確保、病葉や病株の除去 / 排水、傷をつけない |

> **根こぶ病には治療法がありません。入れないことがすべてで、入ったあとは輪作で待つしかありません。**

&nbsp;&nbsp;&nbsp;シニグリンはそれ自体は無味ですが、葉が傷つく瞬間に酵素と出会ってアリルイソチオシアネートに変わる防御物質です。ふつうの草食昆虫やカビ・細菌はこれを避けますが、ノミハムシやコナガのように適応した害虫は、かえってこのにおいをたどってきます。根こぶ病の休眠胞子は土の中で7-10年生き残るので、アブラナ科を2年以上休ませるのが原則で、病気の株は堆肥に入れずに焼くか遠くに埋めます。チョウやガは、播種直後からネットをかけるか、播種を遅らせて避けます。石けん水は無香料の石けん20gを水1Lに溶かし、葉の裏までぬらして、数日おきに2、3回繰り返します。収穫後に残った茎と根を細かく刻んですき込むと、分解物が土壌の病原菌と線虫を抑えます。

| 症状 | 原因と対処 |
|:---|:---|
| 葉全体が黄色く株が小さい | 窒素欠乏。完熟堆肥、尿の10-15倍希釈液 |
| 葉の縁が褐色に枯れる | カリウム欠乏。木灰を1㎡当たり一つかみ |
| 生育不良で葉が紫色を帯びる | リン酸欠乏(地温が低いときも同じ症状)。骨粉、木灰 |
| 葉が大きく濃い緑色だが組織が軟らかく味が単調 | 窒素過剰(欠乏より気づきにくい。アブラムシと軟腐病・べと病に弱くなる)。窒素の供給をやめる |

&nbsp;&nbsp;&nbsp;辛味成分は硫黄を含むため、有機資源だけを使うと硫黄が不足することがあり、味が年々単調になってきたら、動物の排せつ物が混じった堆肥、油かす、鶏ふんで補います。

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | マメ科(エンドウ、インゲンマメ、ササゲ: 窒素を固定)、レタス・ホウレンソウ(生育期間と根の深さが違い、競争が少ない)、長ネギ・ニラ(においが互いの害虫を惑わす) |
| 悪い | ハクサイ、ダイコン、キャベツ、ケールなどアブラナ科(病害虫を共有し、交雑の危険もある)、イチゴ(互いの生育を抑えるといわれる) |

&nbsp;&nbsp;&nbsp;4年周期で、カラシナ・ハクサイなどアブラナ科(窒素を多く消耗)→マメ科(窒素を固定)→ジャガイモ・サツマイモ→トウモロコシ・モロコシなどイネ科(深い根が下層の養分を引き上げる)の順に回すと、病原菌の密度が下がった状態でアブラナ科をまた始められます。根こぶ病がある畑は4年でも足りません。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 播種後15-20日に若葉(葉の長さ5-10cm、間引きと兼ねる)、25-35日に中間収穫(15-20cm)、45-60日に本収穫(20-30cm、汁気が多くまだ硬くないとき)。長く置くと硬くなって辛味だけが残るので、遅く収穫するより少し早めに収穫する |
| 要領 | 晴れた日の早朝に根ごと抜くか、ナイフで地面から1-2cm残して切る。再生収穫はほとんどできないので、時期をずらした播種に頼る。洗わず、日陰で表面の水気を飛ばす |

| 採種 | 基準 |
|:---|:---|
| 一年草の利点 | 冬を越す必要がなく、春にまくと100日前後でその年の6-7月に種をつける(ダイコン・ハクサイ・キャベツ・ケールは播種後1年半)。秋にまいた株は冬を越して翌年の3-4月にとう立ちする |
| 交雑 | 自家受粉するが、ハチやハエによる他家受粉もかなりある。ほかの品種のカラシナとは100%混ざり(青カラシナと赤カラシナを並べて開花させると色が混ざる)、ハクサイ・カブ・ナタネ・クロガラシとは低い頻度で交雑し、キャベツ・ケール・ブロッコリー・ダイコンとは交雑しない |
| 交雑の防止 | 隔離距離は500m以上。ネットかけが特に有効(自家受粉なのでハチがいなくても実る)。ネットがなければ時期をずらした栽培で、今年は青カラシナだけ花を咲かせて赤カラシナは食べきり、翌年は逆にする |
| 手順 | 葉が大きく病気のない株を選び、とう立ち後に支柱を立てる。開花後50-55日に莢の3分の2が褐色になったら茎ごと刈って日陰で追熟させる(完全に乾くとひとりでに裂ける)。十分に乾かしてから箕で選別し、水分10%以下で密閉する |

> **採種用の株は最低10株以上を残します。自家受粉する作物でも、1、2株だけから採り続けると遺伝的多様性が狭まって勢いが弱まります。**

&nbsp;&nbsp;&nbsp;種子の寿命は常温で密閉して5年で、1株から数千粒が採れるので、採種は3-4年に1回、きちんと隔離して行えば足ります。

## 9. 貯蔵
| 方法 | 条件と期間 |
|:---|:---|
| 生のまま短期 | 洗わずに水気を飛ばして涼しい所に3-5日、濡れた布で包んで貯蔵穴や北向きの軒下に5-7日 |
| 畑に置く | 氷点下5℃まで耐えるので、初冬まで立てておき、必要な分だけ刈る。本格的な寒さの前に漬物に回す |
| カラシナキムチ | 3-4%の塩水に3-4時間漬け、1、2回すすいで水気を切る。薬味を和えて甕に押し込み、漬け汁がかぶるようにする。数か月-1年以上。薬味がなくても、塩2-3%で材料が漬け汁に沈んでいれば乳酸発酵が進む |
| 塩漬け | 塩10-15%で層状に重ねて甕に押し込む。数か月-1年以上。使う前に水に2、3回浸して塩気を抜く |
| 乾燥、干し菜 | 沸騰した湯で30秒ゆでて冷水ですすぎ、固く絞って日陰で完全に干す。6か月-1年以上。水で戻してゆでたあと、ナムルや汁物にする |

> **乳酸発酵の要点は2つです。材料が漬け汁の下に完全に沈んでいること、そして塩の濃度が2%を下回らないこと。**

&nbsp;&nbsp;&nbsp;カラシナの貯蔵性はDで、生の葉は常温で1週間もたせるのが難しいです。発酵はビタミンCをかなり残しますが、塩漬けと乾燥はほとんど残せず、乾燥品には食物繊維、ミネラル、βカロテンが残ります。塩が十分なら塩漬けに、乏しければキムチ型の発酵にします。

## 10. 調理と注意事項
| 方法 | 燃料と辛味 |
|:---|:---|
| 生食(包み野菜、浅漬け) | 燃料不要。辛味が最も強く、ビタミンCの保存が最大。若葉が向く |
| 30秒-1分の湯通し | 燃料はごく少ない。熱に弱い酵素が壊れて辛味が大きく減り、ゴイトロゲンも減る |
| 汁物、お粥に入れる | 他の調理と兼ねる。汁ごと食べれば栄養が保たれる |
| 炒める | βカロテンの吸収がよくなる |
| キムチ、発酵 | 燃料不要。辛味がうま味に変わり、ビタミンCがかなり保たれる |

&nbsp;&nbsp;&nbsp;災害時は、たいてい時間のほうが燃料より豊富なので、発酵が構造的に有利です。辛味を生かすには、葉をつぶすか刻んで常温にしばらく置いてから調理します。

| 成分 | 問題と対応 |
|:---|:---|
| カラシ油配糖体(シニグリン) | たくさん食べると胃を刺激する。加熱すると酵素が壊れる。最初は少量から食べ、胃が弱ければ加熱したものや漬けたものを食べる |
| ゴイトロゲン | ヨウ素が不足した食事で、アブラナ科の野菜を生で大量に長く食べると、甲状腺の機能を下げることがある。加熱したものを混ぜ(ゆで汁は捨てる)、乾燥ワカメ・昆布を確保する |
| シュウ酸、硝酸塩 | シュウ酸は含有量が低く、ゆでて湯を捨てればさらに減る。硝酸塩は窒素を多く与えた葉にたまるので、窒素を与えすぎず、収穫直前の施肥を避ける |

&nbsp;&nbsp;&nbsp;カラシナに急性毒性はありません。

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵キムチと塩漬け品、種子の発芽率の点検。2月に堆肥の切り返し、木灰集め |
| 3-4月 | 3月下旬に春のカラシナの播種、越冬カラシナの覆いを外す。4月に間引きと若葉の収穫、越冬カラシナの収穫、越冬採種株のとう立ち |
| 5-6月 | 5月に春のカラシナの本収穫、採種株の開花と隔離。6月に採種株の結莢、高冷地での夏まき |
| 7-8月 | 7月に採種、追熟。8月下旬から秋のカラシナの播種と元肥 |
| 9-10月 | 9月に秋のカラシナの時期をずらした播種、間引き、ノミハムシとガの観察。10月に秋のカラシナの収穫開始、下旬に越冬カラシナの播種(南部) |
| 11-12月 | 11月に本収穫とキムジャン(カラシナキムチと塩漬け)、越冬カラシナの被覆。12月に貯蔵品の管理、畑の片付け、収穫残さのすき込み |

> **カラシナの1年は2つの山でできています。春のカラシナは種を得る農業に近く、秋のカラシナは食料を得る農業です。災害の初年度は、春のカラシナの半分を食べて半分を種として残し、残した半分がその年の秋と翌年全体を決めます。**
