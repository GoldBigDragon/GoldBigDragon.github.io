## 9. 病虫害——不用药物的防治方法

&nbsp;&nbsp;&nbsp;芥菜的病虫害压力等级为C，无防治减产率估计为51.7%。这意味着如果完全不做任何防治，将损失近一半的产量，而且这个数值对整个十字花科作物都适用。不过，芥菜有一种其他十字花科作物所没有的防御机制。

### 9-1. 辛辣味为何是防御物质

&nbsp;&nbsp;&nbsp;芥菜的叶片中含有一种名为黑芥子苷（Sinigrin）的芥子油苷。这种物质本身既不辛辣，也没有任何味道。当叶片受伤、细胞破裂的瞬间，原本被分隔在另一个区室中的黑芥子酶与黑芥子苷相遇，将其转变为烯丙基异硫氰酸酯（Allyl isothiocyanate）。辛辣味和冲鼻的刺激感正是由此而来。

&nbsp;&nbsp;&nbsp;从植物的角度看，这是一套极为精巧的防御系统。平时它以不耗费任何成本的安全物质形式储存，只有在被啃食的瞬间才转变为有毒物质。啃食叶片的昆虫会突然遭遇口中迸发的刺激性物质，随即退却。在被割伤的伤口处，这种物质还起到杀菌剂的作用，阻止真菌和细菌入侵。

| 对象 | 芥菜辛辣味的作用 |
|:---|:---|
| 一般食草昆虫 | 不少昆虫会回避。在同一块田里，受害时间比大白菜晚 |
| 已适应的害虫 | 小菜蛾等反而把这种气味当作信号，循味而来 |
| 真菌·细菌 | 受到抑制。这也是腌制食品耐储存的原因之一 |
| 土壤病原菌 | 将芥菜翻耕入土后，分解产物具有土壤消毒效果 |

&nbsp;&nbsp;&nbsp;最后一行在灾害情况下应用价值很大。收获芥菜后剩下的茎和根，或因抽薹而无法食用的植株，切碎后翻耕入土，芥子油苷在分解过程中会抑制土壤中的病原菌和线虫。商业农业中把这种方法称为生物熏蒸（Biofumigation），它是不用药品而调控土壤的少数手段之一。翻入土中后浇水并覆盖几天，效果会更好。

### 9-2. 主要害虫

| 害虫 | 症状 | 不用药的防治方法 |
|:---|:---|:---|
| 蚜虫 | 成群聚集在叶背吸食汁液，叶片卷曲皱缩。传播病毒 | 喷洒肥皂水、撒草木灰、保护瓢虫和蚜茧蜂、设置银色反光物 |
| 菜叶蜂（幼虫） | 啃食叶片，咬出孔洞 | 人工捕捉、防虫网、调整播种期 |
| 小菜蛾（又称菜蛾） | 在叶背浅浅啃食，留下半透明的痕迹 | 防虫网最为可靠。同时辅以人工捕捉 |
| 菜粉蝶幼虫 | 在叶片上咬出大孔洞 | 覆盖防虫网使蝴蝶无法停落，并搓掉叶背的黄色虫卵 |
| 跳甲 | 叶片上密密麻麻出现针刺般的小孔 | 幼苗期受害严重。早期覆盖防虫网、撒草木灰 |

&nbsp;&nbsp;&nbsp;跳甲是芥菜上特别常见的害虫。它们受十字花科植物芥子油苷的气味吸引而来，所以这是芥菜的防御物质反而成为引诱信号的一个例子。长成的植株即使被咬出一些孔洞也能撑住，但如果在子叶和幼小真叶阶段遭到危害，就会直接死亡。从刚出苗到长出三四片真叶的这段时间覆盖防虫网最为有效，只要度过这一时期，危害就会大幅减轻。

### 9-3. 物理阻隔为何最可靠

| 方法 | 内容 | 局限 |
|:---|:---|:---|
| 覆盖防虫网 | 播种后立即覆盖网，阻止蛾类和蝶类产卵 | 没有网就无法实施 |
| 无纺布·蚊帐 | 旧蚊帐或布料也可以代用 | 通风不良会引发病害 |
| 调整播种期 | 避开害虫发生高峰期播种 | 可选的季节受到限制 |
| 人工捕捉 | 清晨检查叶背，清除虫卵和幼虫 | 费工费力 |

&nbsp;&nbsp;&nbsp;在没有药剂的情况下，防虫网为什么具有压倒性的效果，从害虫的生活史就能看出来。无论是菜粉蝶还是小菜蛾，都是成虫飞来产卵，造成危害的是从卵中孵化出的幼虫。因此，只要不让成虫接触到叶片，就根本不会出现幼虫阶段。与捕捉已经出现的幼虫相比，阻止成虫产卵所花的功夫要少得多。

&nbsp;&nbsp;&nbsp;如果没有网，调整播种期就是替代办法。蝶类和蛾类的活动受气温左右，所以播种越晚，危害越轻。在韩国，就虫害而言，9月中旬播种比8月下旬播种更有利。不过，推迟播种会使生育期相应缩短，产量下降，并增加遭遇霜冻的风险。如何权衡这两方面，实质上就是决定秋播时间的关键。

### 9-4. 天然防治剂

| 防治剂 | 配制方法 | 对象 |
|:---|:---|:---|
| 草木灰浸出液 | 在15kg草木灰中倒入75kg水，浸泡24小时后过滤使用 | 蚜虫、蝽象 |
| 肥皂水 | 将无香味的肥皂20g溶于1L水中 | 蚜虫、螨 |
| 撒草木灰 | 趁清晨有露水时，把过筛的细灰撒在叶片上 | 驱避害虫、补充钾 |
| 木醋液 | 稀释300-500倍后喷雾 | 驱避效果、抑制病害 |
| 芥菜自身提取液 | 将芥菜叶捣碎，浸泡在水中后过滤，喷洒在其他作物上 | 驱避效果 |

&nbsp;&nbsp;&nbsp;肥皂水对蚜虫起效的原理不是毒性，而是物理作用。肥皂中的表面活性成分会溶解蚜虫体表的蜡质层，使水分流失，并堵住呼吸孔——气门。因此只有被药液直接接触到的个体才会死亡，且没有残留效果。必须把叶背也仔细喷湿，并每隔几天重复两三次。浓度提高后芥菜叶片也会受损，所以应以每1L水20g为限。

&nbsp;&nbsp;&nbsp;草木灰浸出液的效果来自碱性和钾。把草木灰浸泡在水中，碳酸钾会溶解出来，形成碱性溶液，这种溶液会刺激身体柔软的昆虫。同时，残留在叶片上的钾还能起到叶面施肥的作用。喷洒的时间应选在清晨或傍晚。如果在正午喷洒，水滴会起到透镜的作用，灼伤叶片。

### 9-5. 主要病害

| 病害 | 症状 | 条件 | 不用药的应对措施 |
|:---|:---|:---|:---|
| 霜霉病 | 叶背长出白色至灰色的霉层，叶面变黄 | 凉爽潮湿时 | 保证通风、避免密植、摘除病叶 |
| 软腐病 | 基部软烂并发出恶臭 | 高温高湿、有伤口 | 保证排水、避免造成伤口、立即清除病株 |
| 根肿病 | 根上长出肿瘤，植株萎蔫 | 酸性土壤、十字花科连作 | 用草木灰调节酸度、实行2年以上轮作 |
| 病毒病 | 叶片出现花叶斑纹并皱缩 | 由蚜虫传播 | 防治蚜虫、拔除病株并烧毁 |
| 灰霉病 | 叶片和茎上长出灰色霉层 | 低温高湿、通风不良 | 通风、清除病变部位 |

&nbsp;&nbsp;&nbsp;这张表中最需要严肃对待的是根肿病。其他病害至多只是毁掉当年的收成，而根肿病会毁掉整块田。这是因为病原菌的休眠孢子能在土壤中存活7-10年。一旦侵入，这块田就长期无法再种十字花科作物。

> **根肿病无法治疗。唯一的办法就是防止它侵入，一旦侵入，就只能靠轮作等待。**

&nbsp;&nbsp;&nbsp;预防方法有三种。第一是酸度管理。病原菌在pH 6.0以下时活跃，而在pH 7.2以上时活动会大幅减弱。持续施入草木灰，把酸度保持在偏中性，就能抑制发病。第二是排水。病原菌会在积水的地方扩散。第三是轮作。原则上十字花科作物要停种2年以上，已经发病的田块则需要更长时间。

&nbsp;&nbsp;&nbsp;病原菌随土壤和水传播。在病田里用过的锄头和鞋会把病带到健康的田里，坡上方田块的病原菌也会随水流向下方。在灾害情况下，这类卫生管理很容易被忽视，但这关系到会不会失去一整块田。

### 9-6. 农业防治原则

| 原则 | 内容 |
|:---|:---|
| 健康种子 | 不使用从病株上采收的种子。通过温汤浸种切断种子传病 |
| 轮作 | 十字花科作物停种2年以上是基本要求 |
| 通风 | 间苗和保持株距是减少真菌病害最廉价的手段 |
| 排水 | 起垄并保持排水沟畅通 |
| 残体处理 | 病叶和病株不要放入堆肥，应烧毁或埋到远处 |
| 调整播期 | 避开害虫发生期播种 |
| 多品种混植 | 混种特性不同的品种，降低全军覆没的风险 |

&nbsp;&nbsp;&nbsp;农业防治是指不使用药剂，而是依靠栽培方式本身来抑制病虫害。在无法进行化学防治的情况下，这就是防治的全部。它的效果不会立竿见影，也不显眼，但经过几年的积累，田地的状态就会不同。反过来，如果疏忽大意，病原菌和害虫就会年复一年地积累，到了某个时点，这块田就种不成庄稼了。

## 10. 营养缺乏与过量

| 症状 | 原因 | 用天然材料采取的措施 |
|:---|:---|:---|
| 整片叶子发黄，植株矮小 | 缺氮 | 将腐熟堆肥施在植株之间，或把尿液稀释10-15倍后浇施 |
| 叶缘变褐干枯 | 缺钾 | 每㎡撒一把草木灰，并与土混匀 |
| 生长不良，叶片带紫色 | 缺磷 | 施入骨粉或草木灰。地温低时也会出现同样的症状 |
| 叶脉之间发黄，叶脉仍保持绿色 | 缺镁 | 没有含镁资源时，增加堆肥用量 |
| 新叶叶尖干枯并向内卷曲 | 缺钙或水分失衡 | 用草木灰补充钙，并使灌水均匀 |
| 只有叶片茂盛，辛辣味和香气偏弱 | 氮过量 | 停止供氮。植株对病虫害的抵抗力会减弱 |
| 叶片呈深绿色，且厚而发硬 | 氮过量 | 提前收获，下一茬减少施肥 |
| 不生长，根上长出肿瘤 | 根肿病 | 不是营养问题。参见第9节 |

&nbsp;&nbsp;&nbsp;根据芥菜判断缺素症状时，有一点需要注意：由于生育期短，等症状出现时已经来不及应对了。即使看到叶片发黄再施肥，到被吸收见效也要十天，而到那时已是收获期。因此，芥菜的营养管理只能是在基肥阶段提前备足，而不能是看症状再补救。

&nbsp;&nbsp;&nbsp;氮过量比缺氮更难察觉，因为叶片又大又浓绿，看上去长势很好。然而，吸收了过多氮的芥菜，细胞壁薄，组织松软。蚜虫更容易吸食汁液，真菌的菌丝也更容易穿透侵入。这就是软腐病和霜霉病在氮过量的田里更严重的原因。此外，合成辛辣味成分芥子油苷需要硫，如果氮多而硫不足，就会长成叶片虽大而味道平淡的芥菜。这样的芥菜用来做韩式泡菜，价值就会大打折扣。

&nbsp;&nbsp;&nbsp;关于硫，还要补充一点。十字花科作物比其他作物需要更多的硫，因为芥子油苷本身就是含硫化合物。在使用化肥的农业中，硫会通过硫酸铵或硫酸钾自然得到供应，但在只用有机资源的情况下可能会不足。混有动物粪便的堆肥、麻饼（芝麻饼）和鸡粪中含有硫，草木灰中也有少量。如果芥菜的味道逐年变得平淡，就值得怀疑是缺硫。

## 11. 间作与轮作

| 搭配 | 对象 | 效果 |
|:---:|:---|:---|
| 适宜 | 豆科作物（豌豆、菜豆、豇豆） | 根瘤菌固定氮并留在土中 |
| 适宜 | 生菜、菠菜 | 生育期和根系深度不同，竞争较少 |
| 适宜 | 大葱、韭菜 | 气味会互相扰乱对方的害虫 |
| 适宜 | 马铃薯、番茄地的边缘 | 芥菜的气味使一部分害虫回避 |
| 不宜 | 大白菜、萝卜、结球甘蓝、羽衣甘蓝等十字花科 | 共有相同的病虫害 |
| 不宜 | 草莓 | 据说两者的生长会相互受到抑制 |

&nbsp;&nbsp;&nbsp;不要把十字花科作物并排种植，这一原则出于两个理由。第一是病虫害。根肿病、菜粉蝶、小菜蛾、跳甲都会危害整个十字花科，把十字花科作物集中种在一处，害虫就会来回转移、不断繁殖。第二是杂交。如果打算留种，附近就不能有同一时期开花的十字花科作物。这个问题将在第13节另行讨论。

| 轮作顺序示例 | 年次 | 作物 | 田里发生的变化 |
|:---|:---:|:---|:---|
| 4年周期 | 第1年 | 芥菜、大白菜等十字花科 | 大量消耗氮 |
| | 第2年 | 豆科（大豆、豌豆、豇豆） | 氮被固定并积累 |
| | 第3年 | 马铃薯、甘薯等薯类（块茎/块根） | 翻动地下土层，改善土壤物理性状 |
| | 第4年 | 玉米、高粱等禾本科 | 深根将下层养分带到上层 |
| | 再回到第1年 | 十字花科 | 在病原菌密度降低的状态下开始 |

&nbsp;&nbsp;&nbsp;评价表中连作适应性为A，意味着建议休作2年，而上面的4年周期是比这更宽裕的安排。如果是已经有根肿病的田块，4年也可能不够，因为这种病的休眠孢子能撑过7-10年。在这样的田里，现实的做法是把十字花科彻底换到另一个地块去种。

&nbsp;&nbsp;&nbsp;把豆科安排在芥菜之前或之后，尤其高效。芥菜是在短时间内消耗大量氮就离开的作物，而豆科是把空气中的氮固定下来留在土壤里的作物。比如春天收获豌豆，在原地种夏季作物，秋天再播种芥菜，这样的安排可以在一年之内完成循环。在没有化肥的情况下，确保氮来源几乎唯一的结构性方法，就是豆科的合理配置。

&nbsp;&nbsp;&nbsp;也可以把芥菜当作绿肥使用，这就是前面提到的生物熏蒸。在深秋或早春把芥菜密密地播下，在花茎抽起之前整株翻耕入土，分解中的芥子油苷会抑制土壤病原菌和线虫，同时这些植株也变成了有机物。这种用法放弃了获取食物，换来的是改良田地，适合在种子充足时采用。

## 12. 收获

| 用途 | 播种后 | 状态 |
|:---|:---:|:---|
| 嫩叶（叶菜包饭ssam、现拌凉菜geotjeori） | 15-20天 | 叶长5-10cm。可与间苗一并进行 |
| 中期收获 | 25-35天 | 叶长15-20cm。口感柔嫩 |
| 正式收获（凉拌野菜namul、韩式泡菜） | 45-60天 | 叶长20-30cm。汁多且尚未变老时 |
| 留种用 | 80-100天 | 花茎抽起，角果变干 |

&nbsp;&nbsp;&nbsp;判断收获适期的标准不是叶片的大小，而是叶片的状态。用手握住时厚实有弹性，折断时渗出水分，就是适期。过了这个时点，叶脉会变粗硬，辛辣味也会变得过于强烈。晚几天并不会变得不能吃，但做namul则嫌韧，做韩式泡菜则嫌粗硬。

> **叶片充分长大、汁多、辛辣味适中的时候就是适期。放得太久会变韧，只剩下辛辣味。芥菜与其晚收，不如稍早一点收获。**

| 项目 | 要点 |
|:---|:---|
| 收获时间 | 晴天清晨。经过一夜吸足水分，最为新鲜 |
| 收获方法 | 连根拔起，或用刀在离地面1-2cm处留茬割下 |
| 再生 | 即使留下基部，也几乎无法再生收获 |
| 整理 | 抖掉泥土，摘除变黄的叶片 |
| 预干 | 不要用水洗，摊放在阴凉处，晾干表面水分 |
| 贮藏准备 | 准备用于腌制的，不要清洗，保持原样 |

&nbsp;&nbsp;&nbsp;收获后不立即清洗的原因是，表面的水分会成为腐烂的起点。叶菜的细胞在收获的同时就开始死亡，伤口部位和潮湿的表面会滋生细菌。不洗而在阴凉处晾干表面水分，能多保存几天。要转入腌制的芥菜更是如此，因为在用盐腌渍的过程中，本来就会出水，同时也完成了清洗。

&nbsp;&nbsp;&nbsp;芥菜几乎无法再生收获，这是它与羽衣甘蓝和莙荙菜的决定性区别。羽衣甘蓝的生长点只有一个，位于茎的顶端，即使摘掉下部叶片，也会不断长出新叶；而芥菜整株作为一个单位生长，一旦割掉基部就到此为止。侧芽虽然也会长出小叶，但长不到可作商品的大小。持续性C这一等级指的就是这种特性。因此，芥菜栽培的设计不依靠反复收获，而是依靠分批错期播种。
