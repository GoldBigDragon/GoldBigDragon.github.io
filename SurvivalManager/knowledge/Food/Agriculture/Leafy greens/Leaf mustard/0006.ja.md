## 13. 採種 - 一年草であることの利点と交雑という落とし穴

### 13-1. 芥は冬を越す必要がない

&nbsp;&nbsp;&nbsp;アブラナ科作物の採種を難しくしている最大の要因は、二年草という性質です。キャベツ、ケール、ハクサイ、ダイコンは種を採るには必ず冬の低温を経験しなければ花茎が立ちません。最初の年は葉や根だけを作り、冬を越したあとの翌春になってようやく花を咲かせます。畑を一年半占有し、その間は凍死の危険を負わなければなりません。

&nbsp;&nbsp;&nbsp;芥はこの壁が低いです。春に種をまいた芥は気温が上がり日が長くなると、その年のうちに花茎を伸ばし、花を咲かせ、種を結びます。低温を経験しなければならないという絶対条件がないか、あってもごく弱くしか働きません。実質的に一年草に近い扱いができ、これが災害状況で芥が持つ最大の戦略的利点です。

| 作物 | 生活形 | 採種までかかる期間 | 冬の管理 |
|:---|:---|:---|:---|
| 芥 | 一年草（抽だい性） | 春まきから100日前後 | 不要です |
| ダイコン | 二年草 | 播種から1年半 | 根を越冬させる必要があります |
| ハクサイ・キャベツ・ケール | 二年草 | 播種から1年半 | 株を越冬させる必要があります |
| サンチュ | 一年草 | 播種から100日前後 | 不要です |

&nbsp;&nbsp;&nbsp;したがって、災害初年度の種子計画において芥の位置づけは特別です。春にまいた芥を数株抜かずにそのまま残しておけば、6月から7月に種ができます。種子寿命が5年なので、一度採っておけば数年をもたせられます。秋にまいた芥は事情が異なり、冬を越して翌春に花茎を伸ばします。春まき採種と秋まき越冬採種、二つの道がともに開かれているわけです。

### 13-2. 何と交雑するか

&nbsp;&nbsp;&nbsp;芥の採種の難関は交雑です。芥は自家受精が可能な作物なので自分の花粉でも種を結びますが、ハチやハエが行き来することでかなりの割合で他家受精も起こります。評価表の自家採種A、隔離500mという基準はここから来ています。ケールやキャベツのように自家不和合性があって必ず別の株が必要な作物よりは易しいものの、サンチュのように事実上完全な自家受精作物よりは厄介です。

| 作物 | 学名 | 芥との交雑 |
|:---|:---|:---|
| 芥、カラシナ菜、若採り用カラシナ類 | Brassica juncea | 完全に交雑します |
| ハクサイ、チンゲンサイ、カブ、アブラナ | Brassica rapa | 低頻度で交雑する場合があります |
| クロガラシ | Brassica nigra | 低頻度で交雑する場合があります |
| キャベツ、ケール、ブロッコリー、コールラビ | Brassica oleracea | 事実上交雑しません |
| ダイコン | Raphanus sativus | 属が異なるため自然交雑しません |

&nbsp;&nbsp;&nbsp;この表の根拠は染色体です。芥はハクサイの染色体一組（Aゲノム）とクロガラシの染色体一組（Bゲノム）を併せ持つ複二倍体です。そのため、Aゲノムを持つハクサイ類、Bゲノムを持つクロガラシとは染色体が部分的に対を成すことができ、低い確率で雑種が生じます。一方、キャベツ類はCゲノムという全く異なる染色体構成を持つため、自然状態では交雑は起こりません。

&nbsp;&nbsp;&nbsp;実務的にまとめるとこうなります。芥の種を採る年に、ケールやキャベツやブロッコリーが一緒に花を咲かせても気にする必要はありません。問題になるのは第一に別品種の芥、第二にハクサイとカブとアブラナです。特に別品種の芥は100%混じります。青芥と赤芥を並べて植え、両方とも花を咲かせると、翌年には色が入り混じった得体の知れない芥ができます。

### 13-3. 交雑を防ぐ三つの方法

| 方法 | 内容 | 現実性 |
|:---|:---|:---|
| 隔離距離 | 他の開花株と500m以上離します | 隣の畑まで統制できず難しいです |
| 時差栽培 | 一年に一品種だけ花を咲かせます | 最も現実的です |
| 網掛け | 開花前に網をかけてハチの出入りを防ぎます | 自家受精するため芥では確実に効果があります |

&nbsp;&nbsp;&nbsp;芥では網掛けが特に有効です。ケールやキャベツは自家不和合性があるため網の中で人が筆で花粉を移してやる必要がありますが、芥は自分の花粉で受精するので、網をかけてそのままにしておいても種ができます。ハチが入れなければ純度が守られ、ハチがいなくても結実に問題はありません。この組み合わせはアブラナ科作物の中でも珍しい条件です。

&nbsp;&nbsp;&nbsp;網がなければ時差栽培でいきます。今年は青芥だけ花を咲かせ、赤芥は全部収穫して食べます。来年は逆にします。種子寿命が5年なので、一品種につき3年に一度だけ採種しても途切れません。この方式が最も少ない労力で純度を守ります。

&nbsp;&nbsp;&nbsp;隔離距離500mは原則ですが、狭い土地では守りにくいです。ただ、完全な隔離でなくても意味はあります。距離が遠いほど交雑率は下がり、間に建物や木や丘のようにハチの移動を妨げる障害物があれば実効距離が延びます。

> **採種用の株は最低でも十株以上残します。自家受精する作物であっても一、二株だけから採り続けると遺伝的多様性が狭まり、勢いが弱くなります。**

### 13-4. 採種の手順

| 段階 | 時期 | 内容 |
|:---|:---|:---|
| 採種株選抜 | 収穫期 | 葉が大きく品種の特性が明確で病気のない株を選びます |
| 抽だい | 春まきは5-6月、秋まきは翌年3-4月 | 花茎が立ちます。倒れないよう支柱を立てます |
| 開花 | 抽だい後2-3週 | 黄色い花が咲きます。この時期に隔離を守ります |
| 結実 | 開花後 | 細長いさやがつきます |
| 収穫 | 開花後50-55日 | さやの3分の2が茶色く乾いたら茎ごと刈り取ります |
| 後熟・脱粒 | 収穫直後 | 陰干しで1-2週間乾かした後、袋に入れて叩きます |
| 選別 | 完全乾燥後 | 唐箕（とうみ）でしいなを飛ばします |
| 保管 | 水分10%以下 | 密閉容器に入れ、涼しく暗い場所に置きます |

&nbsp;&nbsp;&nbsp;さやが完全に乾くまで畑に置いてはいけません。アブラナ科のさやは完全に乾くと自然に裂けて種を地面にこぼします。芥はこの性質が特に強く、一、二日遅れると収穫できるものが残りません。下側のさやの3分の2が茶色になり上側はまだ緑色の時点で茎ごと刈り取り、陰で後熟させるのがコツです。刈り取った茎を布や袋の上に置いて乾かせば、裂けて落ちる種まで集められます。

| 項目 | 基準 |
|:---|:---|
| 種子寿命 | 常温密閉で5年 |
| 最適保管 | 涼しく暗く乾燥した場所、密閉容器 |
| 乾燥剤 | 炒って冷ました米、炭、乾いた木灰 |
| 発芽確認 | 毎年20粒を濡れた布に置き、数日後に発芽率を数えます |
| 一株の収穫量 | 種数千粒 |
| 採種周期 | 3-4年に一度、その年はしっかり隔離を守って |

&nbsp;&nbsp;&nbsp;芥一株から採れる種は数千粒で、十株あれば数年分の種子が一度に確保できます。ここに5年という種子寿命が重なると、採種は毎年やることではなくなります。3-4年に一度、その年だけしっかり隔離して採れば済みます。残りの年はすべての芥を食用に使えます。

## 14. 毒性と注意すべき成分

&nbsp;&nbsp;&nbsp;芥に急性毒性はありません。洗ってそのまま食べられ、評価表の調理・加工等級SSがその事実を反映しています。ただし、多量かつ長期間食べる場合に考慮すべき成分があります。

| 成分 | どんな物質か | どんな問題になるか | 減らす方法 |
|:---|:---|:---|:---|
| 芥子油配糖体（シニグリン） | アブラナ科の辛味と香りの源 | 多量に食べると胃腸を刺激します | 加熱すると酵素が壊れて辛味が生じません |
| ゴイトロゲン | 芥子油配糖体の分解物の一部 | ヨウ素の吸収を妨げ、甲状腺機能を低下させる場合があります | 湯通し、海藻類の摂取 |
| シュウ酸 | 植物がカルシウムと結合させて貯蔵する有機酸 | 多量に食べると腎臓結石のリスクが上がります | 芥は含量が低めです。湯通しして湯を捨てるとさらに減ります |
| 硝酸塩 | 窒素を多く与えた葉に蓄積します | 過剰摂取すると問題になります | 窒素を与えすぎず、収穫直前の施肥を避けます |

### 14-1. 辛味はどこまで安全か

&nbsp;&nbsp;&nbsp;芥子油配糖体は通常の摂取量では安全です。問題になるのは量と状態です。生の芥を一度に多量に食べると、アリルイソチオシアネートが胃の粘膜を刺激し、胸やけが起こることがあります。胃が弱い人は生よりも加熱したり漬けた形が安全です。

> **初めて食べるときは少量から始めます。辛味への反応は個人差が大きく、災害状況で新しい食べ物によって体調を崩すこと自体が危険なことです。**

### 14-2. ゴイトロゲンとヨウ素

&nbsp;&nbsp;&nbsp;芥子油配糖体が分解される際に生じる物質の一部は、甲状腺でヨウ素が使われる過程を妨げます。このような物質をゴイトロゲン（Goitrogen）と呼びます。ヨウ素を十分に摂っている人が通常量の芥を食べることは問題になりません。危険になる条件は、ヨウ素が不足した食事でアブラナ科野菜を生で大量かつ長期間食べる場合です。

&nbsp;&nbsp;&nbsp;災害状況ではこの条件が実際に生じる可能性があります。物流が絶たれて海から遠くなるとワカメやコンブや海苔が手に入らなくなり、精製塩にもヨウ素が含まれていないことが多いです。その状態でアブラナ科野菜ばかりを主に食べると、甲状腺機能が低下することがあります。対応は二つです。一つは加熱して食べる形を混ぜることです。加熱するとミロシナーゼ酵素が壊れてゴイトロゲンの生成自体が減り、湯通しした湯を捨てると水溶性成分が抜けます。もう一つは海藻類を入手できるときに確保しておくことです。乾燥ワカメとコンブは常温で長く保存でき、少量で十分です。

## 15. 冷蔵庫なしの貯蔵 - 芥の本領

&nbsp;&nbsp;&nbsp;芥の貯蔵性等級はDで、無電力常温では一週間を超えるのが難しいです。しかしこの等級は生葉のまま置いた場合の話です。芥はそもそも生のまま保管する作物ではなく漬ける作物で、塩と出会った瞬間、貯蔵期間は数ヶ月から一年以上へと延びます。

### 15-1. 生の状態での短期保管

| 方式 | 方法 | 期間 |
|:---|:---|:---:|
| 涼所保管 | 洗わず水気を飛ばしたあと、風通しのよい涼しい場所に置きます | 3-5日 |
| 濡れ布保管 | 濡れた布で包み、室や土窟、北向きの軒下に置きます | 5-7日 |
| 畑に置く | 霜が降りるまでは畑に立てたままにし、必要な分だけ刈ります | 初冬まで |

&nbsp;&nbsp;&nbsp;最後の行が実質的に最も有用な方法です。芥はマイナス5度まで耐えるので、初冬まで畑にそのまま置いて必要なときに刈ってきます。畑そのものが貯蔵庫の役割をします。ただし、ケールのように厳冬を越すことはできないので、本格的な寒さが来る前に整理して漬け物に移す必要があります。

### 15-2. 芥キムチ

&nbsp;&nbsp;&nbsp;芥の貯蔵法の中心はキムチです。芥キムチが白菜キムチより長持ちするのには理由があります。芥のアリルイソチオシアネートが抗菌作用を発揮して雑菌の増殖を抑え、発酵を主導する乳酸菌は相対的に妨げられにくいからです。うまく漬けた芥キムチは涼しい場所で数ヶ月から一年以上もちます。

| 段階 | 内容 |
|:---|:---|
| 塩漬け | 3-4%の塩水に3-4時間浸けます。茎が曲がる程度になれば十分です |
| すすぎ | 一、二回すすいで水気を切ります |
| 薬味 | 唐辛子粉、ニンニク、ショウガ、塩辛を和えます |
| 詰め込み | 甕に押し込んで詰め、汁が材料を覆うようにします |
| 熟成 | 涼しい場所で熟成させます |

&nbsp;&nbsp;&nbsp;薬味の材料がない状況を前提とすべきです。唐辛子粉や塩辛がなくてもキムチは漬けられます。塩分濃度を2-3%に合わせ、材料が汁に完全に浸るようにすれば乳酸発酵が進みます。芥自体に辛味があるので、他の薬味がなくても味が単調にはなりません。

> **乳酸発酵の要点は二つです。材料が汁の下に完全に沈んでいること、そして塩分濃度が2%を下回らないこと。この二つの条件が守られれば、雑菌ではなく乳酸菌が育ちます。**

&nbsp;&nbsp;&nbsp;乳酸発酵が災害状況で持つ最大の価値はビタミンCの保存です。乾燥させたり煮たりする貯蔵法はビタミンCの大部分を失いますが、発酵はかなりの量を残します。冬が長い地域で漬け物文化が発達したのは偶然ではありません。

### 15-3. 塩蔵

| 方式 | 方法 | 期間 |
|:---|:---|:---:|
| 塩漬け | 塩10-15%で層状に重ね、甕に押し込んで詰めます | 数ヶ月-1年以上 |
| 使用法 | 使う前に水に二、三回浸けて塩気を抜きます | |

&nbsp;&nbsp;&nbsp;塩蔵は最も単純で最も長持ちする貯蔵法です。塩分濃度が10%を超えると乳酸菌さえ活動できず、微生物全体が停止します。発酵も腐敗も起こらない停止状態になり、そのため一年を超えてもちます。代わりにビタミンCはほとんど残りません。

&nbsp;&nbsp;&nbsp;塩をどれだけ確保できているかが、塩蔵とキムチの選択を左右します。塩が十分あれば塩蔵で長くもたせ、貴重なら2-3%のキムチ型発酵にします。塩の使用量が五倍違うからです。

### 15-4. 乾燥と干し野菜

| 段階 | 方法 |
|:---|:---|
| 湯通し | 沸騰した湯に30秒通し、冷水にさらします |
| 水気絞り | 手でしっかり絞ります |
| 乾燥 | 陰で風通しのよい場所に広げて完全に乾かします |
| 保管 | 密閉容器に入れ、炭や炒った米を一緒に入れます |
| 期間 | 6ヶ月-1年以上 |
| 使用 | 水で戻して煮たあと、和え物にしたり汁物に入れます |

&nbsp;&nbsp;&nbsp;湯通ししてから乾かす理由は二つです。一つは酵素を壊して保管中の変色と変質を防ぐこと、もう一つは組織を柔らかくして後で水に戻したときにほどけやすくすることです。湯通しせずに乾かした芥は色が黄ばみ、戻しても硬いままです。ただし乾燥させた芥はビタミンCをほとんど残せません。乾燥で残るのは食物繊維とミネラル、そして熱に比較的強いベータカロテンです。冬の食事において乾燥品はかさを減らして貯蔵する手段であり、ビタミンCは発酵食品と畑に残った生葉から得ます。

### 15-5. 醤油漬け

&nbsp;&nbsp;&nbsp;醤油や味噌があれば、醤油漬けもまた一つの道です。芥の太い茎を塩で軽く漬けて水気を抜いたあと、醤や味噌に漬け込んでおけば数ヶ月もちます。原理は塩蔵と同じで、高い塩分濃度と醤類の抗菌成分が微生物の働きを止めます。

| 方式 | 予想期間 | 必要な資材 | 特徴 |
|:---|:---:|:---|:---|
| 生の短期 | 3-5日 | なし | 鮮度が最大 |
| 芥キムチ | 数ヶ月-1年以上 | 塩と薬味 | ビタミンCがかなり残ります |
| 塩蔵 | 数ヶ月-1年以上 | 塩（多量） | 最も単純で確実です |
| 乾燥・干し野菜 | 6ヶ月-1年 | なし | かさと重さが大きく減ります |
| 醤油漬け | 数ヶ月 | 醤油または味噌 | 塩辛いおかず。塩分補給も兼ねます |

## 16. 調理と加工

| 方法 | 燃料 | 辛味 | ビタミンC保存 | 備考 |
|:---|:---:|:---|:---:|:---|
| 生食（包み野菜、和え） | なし | 最も強いです | 最大 | 若葉が適しています |
| 湯通し30秒-1分 | 非常に少ない | 大きく減ります | 半分以上 | ゴイトロゲンも一緒に減ります |
| 汁物や粥に入れる | 他の調理と兼用 | 減ります | 汁ごと食べれば保存 | 別に燃料を使いません |
| 炒める | 少ない | 減ります | 中間 | ベータカロテンの吸収がよくなります |
| キムチ・発酵 | なし | うま味に変わります | かなりの量を維持 | 貯蔵と調理を兼ねます |
| 乾燥して粉にする | 乾燥時は日光と風 | ほぼ消えます | ほとんどありません | ミネラルとベータカロテンは残ります |

&nbsp;&nbsp;&nbsp;燃料が貴重な状況で芥の調理を組み立てる際に基準となるのは辛味の処理です。生の芥の辛味に耐えられないなら二つの道があります。加熱するか発酵させるかです。加熱は燃料を使い、発酵は時間を使います。災害状況では大抵、時間の方が燃料より豊富なので、発酵の方が構造的に有利です。

&nbsp;&nbsp;&nbsp;加熱で辛味が消える原理は酵素の破壊です。アリルイソチオシアネートはシニグリンがミロシナーゼと出会うことで生じますが、この酵素はタンパク質なので熱に弱いです。沸騰した湯に30秒浸けるだけでほとんど活性を失います。そのため湯通しした芥はほとんど辛くありません。反対に辛味を生かしたいなら、葉をつぶすか切って常温にしばらく置いてから調理します。その間に酵素が働いて辛味物質がすでに作られ、その後加熱してもその物質自体はかなりの部分が残ります。

&nbsp;&nbsp;&nbsp;マスタードソースを作る原理も同じです。芥の種を挽いてぬるま湯で溶いておくと、10-15分の間に酵素が働いて辛味が上がってきます。このとき酢を加えると酵素が止まり、その時点の辛味が固定されます。熱い湯で溶くと酵素が死んで辛くならず、苦味だけになります。種まで使えば、芥一株から葉と調味料を同時に得ることになります。

&nbsp;&nbsp;&nbsp;油が少しでもあれば、炒める調理を混ぜる方が栄養面で有利です。芥のベータカロテンは脂溶性なので、油があってこそ吸収されます。油がなければ、エゴマやゴマを挽いて混ぜることで代用できます。

## 17. 年間作業スケジュール

| 月 | 作業 |
|:---|:---|
| 1月 | 貯蔵キムチと塩蔵品の状態を確認します。種子の発芽率を点検します |
| 2月 | 堆肥を切り返し、春まき用の畑を準備します。木灰を集めておきます |
| 3月 | 下旬に春芥を播種。越冬芥の覆いを外します |
| 4月 | 春芥の間引きと若葉の収穫。越冬芥の収穫。越冬採種株の抽だい |
| 5月 | 春芥の本収穫。採種株の開花、隔離管理 |
| 6月 | 春まき採種株の開花と結実。夏の高冷地播種（海抜400m以上） |
| 7月 | 採種。さやの3分の2が茶色になったら刈り取ります。後熟と脱粒 |
| 8月 | 下旬から秋芥の播種を開始。元肥を入れます |
| 9月 | 秋芥の播種を継続（時差播種）。間引き。ノミハムシと蛾の予察 |
| 10月 | 秋芥の収穫開始。下旬に越冬芥を播種（韓国南部） |
| 11月 | 本収穫とキムジャン。芥キムチと塩蔵作業。越冬芥の被覆 |
| 12月 | 貯蔵品の管理。畑の整理と残渣処理。収穫残渣を漉き込みます |

&nbsp;&nbsp;&nbsp;この表から読み取るべきは、芥の一年が二つの山でできているという点です。春の山は短く早いです。3月下旬にまいて5月に収穫し、そのまま残して7月に種を採ります。秋の山は長く厚いです。8月下旬から分けてまき、10月と11月に収穫し、その収穫物がキムチと塩蔵に移って冬を越します。

&nbsp;&nbsp;&nbsp;二つの山の役割は異なります。春芥は種子を得る農作業に近く、秋芥は食料を得る農作業です。災害初年度であれば、この区別が特に重要です。

> **災害初年度の春芥は半分を食べ、半分を種として残します。残した半分がその年の秋と翌年全体を決めます。**
