## 9. 病害虫 - 薬を使わずに防ぐ方法

&nbsp;&nbsp;&nbsp;カラシナの病害虫圧の等級はC、無防除減収率は推定51.7%です。何も防除しなければ半分近くを失うという意味で、アブラナ科作物全体に共通して当てはまる値です。ただし、カラシナには他のアブラナ科作物にはない防御装置が一つあります。

### 9-1. 辛味が防御物質である理由

&nbsp;&nbsp;&nbsp;カラシナの葉には、シニグリン(Sinigrin)というからし油配糖体が含まれています。この物質自体は辛くもなく、何の味もしません。葉が傷を受けて細胞が壊れた瞬間、別の場所に保管されていたミロシナーゼという酵素がシニグリンと出会い、アリルイソチオシアネート(Allyl isothiocyanate)に変わります。これが辛味と鼻を刺す刺激の正体です。

&nbsp;&nbsp;&nbsp;この仕組みは、植物にとって非常に精巧な防御システムです。普段はコストのかからない安全な物質として保管しておき、食べられた瞬間だけ毒性物質に変わります。葉を食べていた昆虫は、口の中で突然刺激物質が爆発する経験をして退散します。切れた傷口では、この物質が殺菌剤として働き、カビや細菌の侵入を防ぎます。

| 状況 | カラシナの辛味が果たす役割 |
|:---|:---|
| 一般の草食昆虫 | かなりの数が避けます。同じ畑ではハクサイより被害が遅く出ます |
| 適応した害虫 | コナガなどは、むしろこの匂いを目印にして寄ってきます |
| カビ・細菌 | 抑制されます。漬物の貯蔵性が高い理由でもあります |
| 土壌病原菌 | カラシナをすき込むと、分解物が土壌消毒の効果を出します |

&nbsp;&nbsp;&nbsp;最後の行は、災害時に応用価値が大きいものです。カラシナを収穫した後に残った茎と根、あるいは抽だいして食べられなくなった株を細かく切って畑にすき込むと、からし油配糖体が分解されながら土壌の病原菌と線虫を抑制します。商業農業でバイオフューミゲーション(Biofumigation)と呼ばれる方法で、薬品なしで土壌を管理できる数少ない手段です。すき込んだ後に水を与えて数日覆っておくと効果が大きくなります。

### 9-2. 主な害虫

| 害虫 | 症状 | 薬を使わない防除 |
|:---|:---|:---|
| アブラムシ | 葉の裏側に群がって汁を吸い、葉が縮みます。ウイルスを媒介します | 石けん水の噴霧、草木灰の散布、テントウムシとアブラバチの保護、銀色反射物の設置 |
| カブラハバチ(幼虫) | 葉を食べて穴をあけます | 手で取る、防虫網、播種時期の調整 |
| コナガ | 葉の裏側を薄く食べて半透明の跡を残します | 防虫網が最も確実です。手で取ることも併用します |
| モンシロチョウの幼虫 | 葉に大きな穴をあけます | 蝶が止まれないように網をかけ、葉の裏の黄色い卵をこすって取り除きます |
| ノミハムシ | 葉に針で刺したような小さな穴が密に生じます | 幼い時期の被害が大きいです。初期の防虫網、草木灰 |

&nbsp;&nbsp;&nbsp;ノミハムシはカラシナで特に頻繁に見られる害虫です。アブラナ科植物のからし油配糖体の匂いに引き寄せられる昆虫であるため、カラシナの防御物質がむしろ誘引信号になってしまう例です。育ち切った株は穴が多少あいても持ちこたえますが、子葉や幼い本葉の段階でやられるとそのまま枯れてしまいます。発芽直後から本葉3-4枚までの期間に防虫網をかけるのが最も効果的で、この時期を過ぎれば被害は大きく減ります。

### 9-3. 物理的な遮断が最も確実な理由

| 方法 | 内容 | 限界 |
|:---|:---|:---|
| 防虫網の被覆 | 播種直後から網をかけ、蛾と蝶の産卵を防ぎます | 網がなければ不可能です |
| 不織布・蚊帳 | 古い蚊帳や布でも代用できます | 通風が悪いと病気が発生します |
| 播種時期の調整 | 害虫の発生最盛期を避けて播種します | 季節の選択が限られます |
| 手で取る | 早朝に葉の裏を確認し、卵と幼虫を取り除きます | 労力がかかります |

&nbsp;&nbsp;&nbsp;薬がない状況で防虫網がなぜ圧倒的に有効なのかは、害虫の生活史を見るとわかります。モンシロチョウもコナガも、成虫が飛んできて卵を産み、被害を与えるのは卵から出た幼虫です。したがって成虫が葉に触れられないようにすれば、幼虫の段階自体が発生しません。すでに発生した幼虫を捕まえるより、卵を産ませないほうがはるかに少ない労力で済みます。

&nbsp;&nbsp;&nbsp;網がないなら、播種時期の調整が代替策です。蝶や蛾の活動は気温に左右されるため、遅く播くほど被害が減ります。8月下旬より9月中旬の播種が害虫被害の面では有利です。ただし遅らせるとその分生育期間が短くなり収量が減り、霜に遭う危険が大きくなります。この天秤にかけることが、秋播きの時期を決める実質的な内容です。

### 9-4. 自然防除剤

| 防除剤 | 調製法 | 対象 |
|:---|:---|:---|
| 草木灰液 | 草木灰15kgに水75kgを注いで24時間浸し、濾して使います | アブラムシ、カメムシ |
| 石けん水 | 無香料の石けん20gを水1Lに溶かします | アブラムシ、ハダニ |
| 草木灰の散布 | ふるった細かい灰を、朝露があるときに葉にかけます | 害虫忌避、カリウム供給 |
| 木酢液 | 300-500倍に希釈して噴霧します | 忌避効果、病気の抑制 |
| カラシナ自体の抽出液 | カラシナの葉をつぶして水に浸し、濾して他の作物にかけます | 忌避効果 |

&nbsp;&nbsp;&nbsp;石けん水がアブラムシに効く原理は、毒性ではなく物理作用です。石けんの界面活性成分がアブラムシの体表のろう層を溶かして水分を逃がし、呼吸孔である気門をふさぎます。そのため薬液が直接触れた個体だけが死に、残効性はありません。葉の裏側までしっかり濡らす必要があり、数日おきに2-3回繰り返す必要があります。濃度を上げるとカラシナの葉も一緒に傷むため、1Lに20gの線を守ります。

&nbsp;&nbsp;&nbsp;草木灰液の効果はアルカリ性とカリウムから来ます。灰を水に浸しておくと炭酸カリウムが溶け出してアルカリ性の溶液になり、この溶液が柔らかい体を持つ昆虫にとって刺激になります。同時に葉に残ったカリウムが葉面施肥の効果を発揮します。散布の時刻は早朝か夕方です。真昼に散布すると水滴がレンズの役割をして葉を焼いてしまいます。

### 9-5. 主な病害

| 病害 | 症状 | 条件 | 薬を使わない対応 |
|:---|:---|:---|:---|
| べと病 | 葉の裏側に白色から灰色のカビが生じ、表側は黄色く変わります | 涼しく湿っているとき | 通風の確保、密植の回避、病葉の除去 |
| 軟腐病 | 株元が軟らかくなり悪臭がします | 高温多湿、傷 | 排水の確保、傷をつけない、罹病株の即時除去 |
| 根こぶ病 | 根にこぶができ、株が萎れます | 酸性土壌、アブラナ科の連作 | 草木灰で酸度を矯正、2年以上の輪作 |
| ウイルス病 | 葉にモザイク模様ができ、縮れます | アブラムシが媒介します | アブラムシの防除、罹病株を抜いて燃やす |
| 灰色かび病 | 葉と茎に灰色のカビが生じます | 低温多湿、通風不良 | 通風、病部の除去 |

&nbsp;&nbsp;&nbsp;この表で最も重く扱うべきは根こぶ病です。他の病気はその年の作を台無しにするだけですが、根こぶ病は畑そのものを台無しにします。病原菌の休眠胞子が土壌の中で7-10年生き残るためです。一度入り込むと、その畑では長い間アブラナ科作物を植えられなくなります。

> **根こぶ病には治療法がありません。侵入を防ぐことがすべてであり、入り込んでしまった後は輪作で待つしかありません。**

&nbsp;&nbsp;&nbsp;防ぐ方法は三つです。第一に、酸度の管理です。病原菌はpH6.0以下で活発になり、pH7.2以上では活動が大きく減ります。草木灰を継続的に施して酸度を中性側に保てば発病が抑えられます。第二に、排水です。水がたまる場所で病原菌が広がります。第三に、輪作です。アブラナ科作物を2年以上休むのが原則で、すでに病気のある畑ならそれ以上が必要です。

&nbsp;&nbsp;&nbsp;病原菌は土や水に乗って移動します。病気の畑で使った鍬や靴が健全な畑に病気を運び、斜面の上の畑から下の畑へ水とともに流れ落ちます。災害時にはこうした衛生管理がおろそかになりやすいですが、畑一つを失うかどうかがかかっている問題です。

### 9-6. 耕種的防除の原則

| 原則 | 内容 |
|:---|:---|
| 健全な種子 | 病気の株から採った種は使いません。温湯浸漬で種子伝染を断ちます |
| 輪作 | アブラナ科を2年以上休むのが基本です |
| 通風 | 間引きと間隔の確保が、カビ病を減らす最も安価な手段です |
| 排水 | 畝を立てて排水路を維持します |
| 残渣処理 | 病気の葉や株は堆肥に入れず、燃やすか遠くに埋めます |
| 時期の調整 | 害虫の発生期を避けて播種します |
| 多品種混植 | 性質の異なる品種を混ぜて全滅の危険を減らします |

&nbsp;&nbsp;&nbsp;耕種的防除とは、薬を使わず栽培方法そのものによって病害虫を抑えることを指します。化学的防除が不可能な状況では、これが防除のすべてになります。効果は即効性がなく目に見えにくいものですが、数年にわたって積み重なれば畑の状態が変わります。反対に怠れば、病原菌と害虫が年々積み重なり、ある時点から農業ができなくなります。

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然の材料による対処 |
|:---|:---|:---|
| 葉全体が黄色くなり、株が小さいです | 窒素欠乏 | 完熟堆肥を株の間に入れるか、尿を10-15倍に希釈して与えます |
| 葉の縁が茶色く枯れます | カリウム欠乏 | 草木灰を㎡あたり一握り施し、土と混ぜます |
| 生育が振るわず、葉が紫色を帯びます | リン酸欠乏 | 骨粉や草木灰を入れます。地温が低いときも同じ症状が出ます |
| 葉脈の間が黄色くなり、葉脈は緑のまま残ります | マグネシウム欠乏 | 苦土資源がなければ堆肥を増やします |
| 新しい葉の先端が枯れ、内側に巻きます | カルシウム欠乏または水分の不均衡 | 草木灰でカルシウムを補い、灌水を均一にします |
| 葉ばかり茂り、辛味と香りが弱いです | 窒素過剰 | 窒素の供給を止めます。病気と害虫に弱くなります |
| 葉が濃い緑色で、厚くて硬いです | 窒素過剰 | 収穫を早め、次の作期には施肥を減らします |
| 育たず、根にこぶができます | 根こぶ病 | 栄養の問題ではありません。9節を参照してください |

&nbsp;&nbsp;&nbsp;カラシナで欠乏症状を読み取るときに注意すべき点があります。生育期間が短いため、症状が出た時点ではもう対応する時間がないということです。葉が黄色くなったのを見て肥料を入れても、吸収されて効果が出るまでに10日かかり、その頃には収穫期です。したがって、カラシナの栄養管理は症状を見て直す方式ではなく、元肥の段階であらかじめ満たしておく方式しかありえません。

&nbsp;&nbsp;&nbsp;窒素過剰は欠乏よりも見分けにくいです。葉が大きく濃い緑色で、よく育っているように見えるからです。しかし窒素を過剰に摂ったカラシナは細胞壁が薄く組織が軟らかくなります。アブラムシが汁を吸いやすくなり、カビの菌糸が入り込みやすくなります。軟腐病とべと病が窒素過剰の畑でより重くなる理由です。さらに、辛味成分であるからし油配糖体の合成には硫黄が必要なので、窒素だけ多くて硫黄が不足すると、葉だけ大きくて味が薄いカラシナになります。キムチ用としては使い勝手が落ちます。

&nbsp;&nbsp;&nbsp;硫黄について一つ付け加えます。アブラナ科作物は他の作物より硫黄を多く必要とします。からし油配糖体自体が硫黄を含む化合物だからです。化学肥料を使う農業では硫酸アンモニウムや硫酸カリウムを通じて自然に供給されますが、有機資源だけを使う状況では不足することがあります。動物の排泄物が混じった堆肥、油かす、鶏糞には硫黄が含まれており、草木灰にも少量あります。カラシナの味が年々薄くなっていくなら、硫黄不足を疑ってみる価値があります。

## 11. 間作と輪作

| 相性 | 対象 | 効果 |
|:---:|:---|:---|
| 良い | マメ科作物(エンドウ、インゲンマメ、ササゲ) | 根粒菌が窒素を固定して残してくれます |
| 良い | サンチュ、ホウレンソウ | 生育期間と根の深さが異なり、競合が少ないです |
| 良い | 長ネギ、ニラ | 匂いが互いの害虫を混乱させます |
| 良い | ジャガイモ、トマトの脇 | カラシナの匂いが一部の害虫を遠ざけます |
| 悪い | ハクサイ、ダイコン、キャベツ、ケールなどアブラナ科 | 同じ病害虫を共有します |
| 悪い | イチゴ | 互いの生育を抑制すると言われています |

&nbsp;&nbsp;&nbsp;アブラナ科同士を並べて植えないという原則は、二つの理由から来ています。第一は病害虫です。根こぶ病、モンシロチョウ、コナガ、ノミハムシはいずれもアブラナ科全体を攻撃するため、一か所に集めておくと害虫が移動しながら増殖します。第二は交雑です。種を採る計画があるなら、同じ時期に花を咲かせるアブラナ科作物が近くにあってはいけません。この問題は13節で別途扱います。

| 輪作順序の例 | 年次 | 作物 | 畑に起こること |
|:---|:---:|:---|:---|
| 4年周期 | 1年目 | カラシナ、ハクサイなどアブラナ科 | 窒素を多く消費します |
| | 2年目 | マメ科(ダイズ、エンドウ、ササゲ) | 窒素が固定されて蓄積します |
| | 3年目 | ジャガイモ、サツマイモなどいも類(塊茎・塊根) | 土の中を掘り返し、物理性が改善します |
| | 4年目 | トウモロコシ、モロコシ(タカキビ)などイネ科 | 深い根で下層の養分を引き上げます |
| | 再び1年目 | アブラナ科 | 病原菌密度が下がった状態から始まります |

&nbsp;&nbsp;&nbsp;評価表の連作適応性Aは2年の休作を推奨するという意味で、上の4年周期はそれより余裕を持たせた構成です。根こぶ病が既にある畑であれば、4年でも不十分な場合があります。この病気の休眠胞子は7-10年持ちこたえるためです。そのような畑では、アブラナ科を別の区域に移すことが現実的です。

&nbsp;&nbsp;&nbsp;マメ科をカラシナの前か後に置く配置が特に効率的です。カラシナは短期間に窒素を多く使って去る作物で、マメ科は空気中の窒素を固定して土壌に残す作物です。エンドウを春に収穫し、その場所に夏作物を植え、秋にカラシナを播くという配置なら、一年の中で循環が成立します。化学肥料がない状況で窒素を確保するほぼ唯一の構造的な方法が、マメ科の配置です。

&nbsp;&nbsp;&nbsp;カラシナを緑肥として使う方法もあります。先に述べたバイオフューミゲーションです。晩秋か早春にカラシナを密に播いておき、花茎が立つ直前にそのまま丸ごとすき込むと、分解されるからし油配糖体が土壌の病原菌と線虫を抑制しながら、同時に有機物にもなります。食料を得られない代わりに畑を治す用途で、種が十分にあるときに使える方法です。

## 12. 収穫

| 用途 | 播種後 | 状態 |
|:---|:---:|:---|
| 幼葉(包み野菜、浅漬け) | 15-20日 | 葉の長さ5-10cm。間引きと兼ねます |
| 中間収穫 | 25-35日 | 葉の長さ15-20cm。柔らかいです |
| 本収穫(ナムル、キムチ) | 45-60日 | 葉の長さ20-30cm。汁が多く、まだ硬くなっていないとき |
| 採種用 | 80-100日 | 花茎が立ち、鞘が枯れます |

&nbsp;&nbsp;&nbsp;収穫の適期を判断する基準は、葉の大きさではなく葉の状態です。手に取ったとき厚みと弾力があり、折ると水気がにじみ出る状態が適期です。この時点を過ぎると葉脈が硬くなり、辛味が過剰に強くなります。数日遅れても食べられなくなるわけではありませんが、ナムルには硬く、キムチには筋っぽくなります。

> **葉が十分に育ち、汁が多く、辛味が適度なときが適期です。長く置くと硬くなり、辛味だけが残ります。カラシナは遅く収穫するより、少し早めに収穫するほうがよいです。**

| 項目 | 要点 |
|:---|:---|
| 収穫時刻 | 晴れた日の早朝。一晩水分を含んで最も新鮮です |
| 収穫方法 | 根ごと引き抜くか、刃物で地面から1-2cm残して切ります |
| 再生 | 株元を残しても再生収穫はほとんどできません |
| 手入れ | 土を落とし、黄変した葉を取り除きます |
| 予乾 | 水で洗わず、陰に広げて表面の水気を飛ばします |
| 貯蔵の準備 | 漬物にする分は洗わないままにします |

&nbsp;&nbsp;&nbsp;収穫後すぐに洗わない理由は、表面の水気が腐敗の出発点になるからです。葉物野菜の細胞は収穫と同時に死に始め、傷口や濡れた表面で細菌が増殖します。洗わずに陰で表面の水気を飛ばせば、さらに数日長持ちします。漬物に回すカラシナならなおさらです。塩に漬ける過程でどのみち水が抜け、洗浄も行われます。

&nbsp;&nbsp;&nbsp;カラシナが再生収穫をほとんどできないという点が、ケールやフダンソウと決定的に異なる点です。ケールは生長点が茎の先端に一つあり、下葉を摘み取っても新しい葉を次々と出しますが、カラシナは株全体が一つの単位として育つため、株元を切ればそれで終わりです。わき芽から小さな葉が出ることはありますが、商品になるほどの大きさには育ちません。永続性Cという等級が、この性質を示しています。そのため、カラシナ栽培の設計は繰り返し収穫ではなく、時差播種に頼ります。
