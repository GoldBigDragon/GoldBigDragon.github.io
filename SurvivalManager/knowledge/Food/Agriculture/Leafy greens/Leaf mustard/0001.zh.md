---
## 引言
&nbsp;&nbsp;&nbsp;芥菜（Brassica juncea）是在中亚由大白菜（Brassica rapa）与黑芥（Brassica nigra）自然杂交产生的异源四倍体叶菜。综合等级为B（44.3分，有效183种中第65名），副食为SS（58.7分）。每100g只有36kcal，要只靠芥菜满足每天2,100kcal需要吃5.8kg，所以芥菜不是填满饭碗的作物，而是填补餐桌其他部分的作物，与其说是吃鲜叶，不如说专门用来遇盐变成保存食品。辛辣成分芥子油苷（sinigrin）及其分解物异硫氰酸烯丙酯对杂菌是杀菌剂，所以芥菜泡菜（kimchi）比大白菜泡菜酸得晚、耐存放。弱点是微量营养素D（21种中有8种）、口味D（对气味和香气的排斥感）、持续性C（收一次就结束）。另一方面，它有从播种到收获45-60天的速度（嫩叶20-30天）、常温密封5年的种子寿命，以及不必越冬就能留种的一年生习性，是灾害第一年能实现种子自立的少数十字花科作物。芥菜不是田里的主角，而是田里的保险。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 十字花科芸苔属一年生草本（易抽薹），秋播则为越冬一年生。同时具有大白菜和黑芥的染色体，所以与它们低频杂交，不与甘蓝类群杂交 |
| 叶、茎 | 叶缘呈锯齿状，表面略皱，有绿色、红紫色和混合色 |
| 根、花、荚果 | 直根大部分浅浅分布在地表10-15cm内。开黄花，细长的荚果里排着直径1-2mm的褐色至红褐色种子 |

| 阶段 | 时期（播种后） | 要点 |
|:---|:---|:---|
| 发芽、前期营养生长期 | 20天以内 | 种子吸水，子叶展开，真叶长出，根扎稳。氮 |
| 快速营养生长期 | 20-45天 | 叶和茎快速长大。氮、钾 |
| 最佳收获期 | 45-60天 | 叶片长足，还没变硬 |
| 抽薹、开花期 | 60-100天 | 花茎抽起，叶片变硬。磷、钾 |

> **芥菜生长期短，前期养分供应几乎决定产量。没有时间靠追肥弥补，所以胜负在基肥阶段就定了。**

&nbsp;&nbsp;&nbsp;花茎在经历一段时间的低温（0-10℃）后日照变长时（早春早播的芥菜）和受到高温干旱胁迫时（盛夏播种的芥菜）抽起，两种情况下叶片都会变硬、只剩辛辣加重，难以食用。所以栽培类型分成春季和秋季，夏季空着。

&nbsp;&nbsp;&nbsp;每100g含热量36kcal、蛋白质3.50g（占热量的38.9%）、膳食纤维2.6g、β-胡萝卜素533㎍。蛋白质占比高是因为热量小，但搭配以稻米或土豆（蛋白质占比8-9%）为主的饮食，可以在不增加热量的情况下提高蛋白质占比。β-胡萝卜素是脂溶性的，搭配油或磨碎的紫苏籽、芝麻吸收更好。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 生长适温15-20℃（可达10-25℃）。发芽6-35℃（25℃最适，3-5天）。25℃以上叶片变薄变硬、辛辣过强，零下5℃以下叶片冻结变软 |
| 光 | 每天6小时以上直射光。遮光40%时相对产量86%。种子需光发芽，埋得深发芽率会骤降 |
| 水、土壤 | 总蒸散量约300mm。根浅，表土干了生长就停，过湿则烂根。肥沃、保水好的土壤，pH 6.0-7.5（低于6.0根肿病会变严重） |

| 品种 | 特点与用途 |
|:---|:---|
| 青芥（cheonggat） | 叶青，辛辣强，耐寒耐病力强。最广泛用于做泡菜 |
| 红芥（jeokgat、honggat） | 叶红，花青素多，辛辣中等。泡菜、包菜、腌渍 |
| 突山芥（dolsangat） | 叶大而宽的晚熟品种，质地柔软。专用于芥菜泡菜 |
| 耐寒青芥（eolcheonggat） | 耐寒，味道温和。冬季栽培和早春收获 |
| 野芥（deulgat） | 接近野生种，香气强而粗。抗病虫害，自己落种 |

&nbsp;&nbsp;&nbsp;辛辣的强度就是耐储能力的强度。用异硫氰酸烯丙酯多的芥菜腌的泡菜，腐败菌增殖慢，整个冬天吃的泡菜适合青芥，初冬马上吃的泡菜适合突山芥。灾害情况下，选品种的第一标准不是产量而是分散风险。把青芥和红芥这样性质不同的两三个品种混着播，其中一个遭病害，其余的还在，收获时间也分散到2-3周。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 深耕20-30cm，打碎土块整平（土块大了，需光发芽的种子会被埋住）。垄高15-20cm并开排水沟。pH调到6.0-7.5，酸性就掺草木灰 |
| 施肥（1,000㎡） | 氮8-10kg，磷6-8kg，钾6-8kg，堆肥1,000-1,500kg，在播种前1-2周全部作基肥施入（未腐熟的堆肥会伤幼根）。追肥因见效时已是收获期而省略，只在生长明显不良时少量施用 |
| 替代资源 | 腐熟堆肥（每1㎡ 1-1.5kg），草木灰（每1㎡一把，兼具供钾、纠正酸度、抑制根肿病、驱避害虫的作用，但过量会妨碍微量元素吸收），稀释10-15倍的尿液（5-6片真叶时一次，收获前2周停用），骨粉 |

| 类型 | 播种 | 收获 | 备注 |
|:---|:---|:---|:---|
| 秋季栽培 | 8月下旬-9月中旬 | 9月下旬-10月底 | 最稳定。40-60天 |
| 越冬栽培 | 10月下旬-11月中旬 | 次年春天 | 南部可行。中部要盖稻草或落叶，或设防风障 |
| 春季栽培 | 3月下旬-4月上旬 | 4月中旬-5月上旬 | 解冻后尽快。晚了会抽薹 |
| 夏季、高冷地 | 6月上旬-7月上旬 | 7-8月 | 仅限海拔400m以上。中低海拔露地花茎先抽出，只白白损失种子和劳力 |

&nbsp;&nbsp;&nbsp;灾害情况下以秋季栽培为主。气温走低，没有抽薹风险，害虫活动减少，收获物直接接上越冬腌泡菜（kimjang）和储存，还能填补夏季作物收完后的空地。

| 播种 | 标准 |
|:---|:---|
| 方法 | 深0.5-1cm，只覆盖刚能遮住种子的细土，用手或木板轻压使种子与土壤贴紧。行距15-20cm，最终株距10-15cm，播种量每1,000㎡ 2-3kg |
| 错期播种 | 每隔10到15天分批播种（秋季为8月下旬、9月上旬、9月中旬）。弥补持续性C（收一次就结束）的唯一办法 |
| 种子处理 | 挑出秕粒，用水泡3-4小时，只用沉底的。用50-55℃的水泡10-15分钟后用冷水降温（超过60℃种子会死，低于45℃病原菌会存活） |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种至发芽 | 轻浇勤浇，不让表土干（种子吸水膨胀后再干就会死） |
| 幼苗期、快速生长期 | 表土干了就浇（根浅，极怕干，这个时期的水分决定叶的大小） |
| 收获前、雨季 | 收获前稍微减少（叶片变紧实，利于储存），雨季要保证排水沟畅通（过湿烂根是更大的风险） |

&nbsp;&nbsp;&nbsp;中午萎蔫、傍晚恢复是暂时缺水，叶片小而厚、辛辣加重则是持续干旱。下部叶片发黄是根缺氧，基部变软发臭的植株就很难救活了。干旱胁迫会加重辛辣，所以做泡菜用的在收获前1周减少浇水。覆盖物用稻草、干草·落叶、稻壳，夏天中午表土超过40℃时根就停止工作，所以哪怕铺一层也差别很大。

| 管理 | 方法 |
|:---|:---|
| 间苗 | 2-3片真叶时留3-5cm做第一次，4-5片真叶时留10-15cm做第二次（最终）。必做的工作（过密则茎只会拉长，通风受阻，出现霜霉病和灰霉病）。不要拔，用剪刀或指甲贴近地面剪断，保护邻株的浅根。间下来的嫩芥菜是第一次收获，播种20天左右很嫩，可包着吃或做凉拌 |
| 杂草 | 最初3周决定成败。3-4片真叶以后用稻草或干草覆盖。小锄头浅刮（根浅） |

&nbsp;&nbsp;&nbsp;已抽薹的植株无法逆转，剪掉花茎旁边还会再抽，所以唯一可靠的办法是确定播种时间，让收获在花茎抽起之前结束。结了花蕾的嫩花茎味道像油菜薹或西兰花，在春天蔬菜短缺时很有用，只留下准备留种的植株，其余的摘来吃。

## 6. 病虫害与养分问题
| 病虫害 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 跳甲 | 叶片上密布针刺般的小孔。在子叶和幼嫩真叶阶段受害会死 | 发芽后立即到3-4片真叶用防虫网，草木灰 |
| 蚜虫 | 成群聚在叶背吸汁，叶片卷曲 | 肥皂水，草木灰，保护瓢虫 |
| 菜青虫、小菜蛾 | 叶片上有大孔 / 叶背有半透明痕迹 | 防虫网（阻止成虫产卵），手捉，擦掉叶背的黄色虫卵 |
| 根肿病 | 根上长肿瘤，植株萎蔫。酸性土壤、十字花科连作 | 无法治疗。纠正酸度、排水、轮作 |
| 霜霉病、灰霉病、软腐病 | 叶背白色至灰色霉层、叶面发黄 / 灰色霉（凉爽潮湿时） / 基部变软发臭（高温高湿、伤口） | 通风、保证间距、摘除病叶和病株 / 排水、避免伤口 |

> **根肿病没有治疗办法。不让它进来就是全部，进来之后只能靠轮作等待。**

&nbsp;&nbsp;&nbsp;芥子油苷本身没有味道，叶片受伤的瞬间遇到酶，就变成防御物质异硫氰酸烯丙酯。一般食草昆虫和霉菌、细菌会躲开它，但跳甲、小菜蛾这类适应了的害虫反而循着这个气味而来。根肿病的休眠孢子能在土壤里存活7-10年，所以原则是十字花科至少休耕2年，病株不要放进堆肥，要烧掉或埋到远处。防蝴蝶和蛾，从播种后立即罩防虫网，或推迟播种来避开。肥皂水是把20g无香肥皂溶进1L水，连叶背一起喷湿，隔几天重复两三次。把收获后剩下的茎和根切碎翻压进去，分解产物会抑制土壤病原菌和线虫。

| 症状 | 原因与处理 |
|:---|:---|
| 整片叶发黄，植株矮小 | 缺氮。腐熟堆肥，稀释10-15倍的尿液 |
| 叶缘枯成褐色 | 缺钾。每1㎡撒一把草木灰 |
| 生长不良，叶片带紫色 | 缺磷（地温低时也是同样症状）。骨粉、草木灰 |
| 叶大而深绿，但组织软、味道寡淡 | 氮过量（比缺氮更难察觉；植株对蚜虫、软腐病和霜霉病变弱）。停止供氮 |

&nbsp;&nbsp;&nbsp;辛辣成分含硫，只用有机资源时硫可能不足，如果味道一年比一年寡淡，就用掺有动物粪便的堆肥、油饼、鸡粪来补充。

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 豆科（豌豆、菜豆、豇豆：固氮），生菜·菠菜（生长期和根深不同，竞争少），大葱·韭菜（气味互相迷惑对方的害虫） |
| 差 | 大白菜、萝卜、甘蓝、羽衣甘蓝等十字花科（共有病虫害，还有杂交风险），草莓（据说互相抑制生长） |

&nbsp;&nbsp;&nbsp;按4年周期，芥菜·大白菜等十字花科（大量消耗氮）→豆科（固氮）→土豆·红薯→玉米·高粱等禾本科（深根把下层养分带上来）的顺序轮作，就能在病原菌密度降低的状态下重新开始种十字花科。有根肿病的田，4年也不够。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 播种后15-20天收嫩叶（叶长5-10cm，与间苗结合），25-35天中期收获（15-20cm），45-60天主收获（20-30cm，多汁且尚未变硬时）。放久了叶片变硬、只剩辛辣，所以宁可稍早也不要晚收 |
| 要领 | 晴天清晨连根拔起，或用刀在离地面1-2cm处割下。几乎不能再生收获，所以靠错期播种。不要洗，在阴凉处晾干表面水分 |

| 留种 | 标准 |
|:---|:---|
| 一年生的优势 | 不需要越冬，春天播种100天左右就在当年6-7月结籽（萝卜、大白菜、甘蓝、羽衣甘蓝要播种后一年半）。秋播的植株越冬后在次年3-4月抽薹 |
| 杂交 | 自花授粉，但蜜蜂和苍蝇造成的异花授粉也相当多。与其他品种的芥菜100%混杂（青芥和红芥并排开花，颜色就混了），与大白菜、芜菁、油菜、黑芥低频杂交，不与甘蓝、羽衣甘蓝、西兰花、萝卜杂交 |
| 防止杂交 | 隔离距离500m以上。罩网特别有效（自花授粉，没有蜜蜂也能结实）。没有网就错期栽培：今年只让青芥开花、红芥全部吃掉，明年反过来 |
| 步骤 | 选叶片大、无病的植株，抽薹后立支柱。开花后50-55天，荚果三分之二变褐时连茎割下，在阴凉处后熟（完全干透会自己裂开）。完全干燥后扬净，含水量10%以下密封 |

> **留种的植株至少留十棵以上。即使是自花授粉的作物，只从一两棵上持续留种，遗传多样性也会变窄、长势变弱。**

&nbsp;&nbsp;&nbsp;种子寿命是常温密封5年，一棵能收几千粒，所以每3-4年做一次好好隔离的留种就够了。

## 9. 储存
| 方法 | 条件与期限 |
|:---|:---|
| 鲜品短期 | 不洗，晾干水分，放在阴凉处3-5天；用湿布包好，放在窖里或朝北屋檐下5-7天 |
| 留在田里 | 耐零下5℃，初冬前一直立在田里，需要多少割多少。严寒来临前转入腌渍 |
| 芥菜泡菜 | 用3-4%的盐水泡3-4小时，冲洗一两遍并沥干水分。拌上调料压进坛子，让汤汁没过菜。几个月至1年以上。即使没有调料，盐2-3%、材料沉在汤汁下就能进行乳酸发酵 |
| 盐渍 | 用10-15%的盐层层码放，压进坛子。几个月至1年以上。使用前用水泡两三次去咸味 |
| 干燥、干菜 | 沸水焯30秒，冷水冲洗，用力挤干，在阴凉处完全晾干。6个月至1年以上。用水泡发煮过后，做凉拌菜或放进汤里 |

> **乳酸发酵的要点有两个：材料要完全沉在汤汁之下，盐浓度不能低于2%。**

&nbsp;&nbsp;&nbsp;芥菜的耐储性是D，鲜叶在常温下很难撑过一周。发酵能保留相当多的维生素C，而盐渍和干燥几乎保不住，干制品留下膳食纤维、矿物质和β-胡萝卜素。盐充足就盐渍，盐稀缺就做泡菜式发酵。

## 10. 烹调与注意事项
| 方式 | 燃料与辛辣 |
|:---|:---|
| 生吃（包菜、凉拌） | 不用燃料。辛辣最强，维生素C保留最多。适合嫩叶 |
| 焯30秒到1分钟 | 燃料极少。怕热的酶被破坏，辛辣大减，致甲状腺肿素也减少 |
| 放进汤或粥 | 与其他烹调兼顾。连汤一起吃能保住营养 |
| 炒 | β-胡萝卜素吸收变好 |
| 泡菜、发酵 | 不用燃料。辛辣变成鲜味，保留相当多的维生素C |

&nbsp;&nbsp;&nbsp;灾害情况下，时间通常比燃料充裕，所以发酵在结构上更有利。想保留辛辣，就把叶片捣碎或切碎，在常温下放一会儿再烹调。

| 成分 | 问题与对策 |
|:---|:---|
| 芥子油苷类（sinigrin） | 吃多了刺激胃。加热会破坏酶。先从少量吃起，胃弱的话吃煮熟的或腌渍的 |
| 致甲状腺肿素 | 在缺碘的饮食中，长期大量生吃十字花科蔬菜可能降低甲状腺功能。混着吃熟的（焯水的水倒掉），并备好干海带、裙带菜 |
| 草酸、硝酸盐 | 草酸含量低，焯水后倒掉水会更少。硝酸盐积累在施氮多的叶片里，所以不要过量施氮，避免收获前施肥 |

&nbsp;&nbsp;&nbsp;芥菜没有急性毒性。

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存的泡菜和盐渍品、种子发芽率。2月翻堆堆肥，收集草木灰 |
| 3-4月 | 3月下旬春播芥菜，揭开越冬芥菜的覆盖物。4月间苗和收嫩叶，收获越冬芥菜，越冬留种株抽薹 |
| 5-6月 | 5月春芥菜主收获，留种株开花和隔离。6月留种株结荚，高冷地夏播 |
| 7-8月 | 7月采种、后熟。8月下旬起秋播芥菜和施基肥 |
| 9-10月 | 9月秋芥菜错期播种、间苗，观察跳甲和蛾类。10月开始收获秋芥菜，下旬越冬芥菜播种（南部） |
| 11-12月 | 11月主收获和越冬腌泡菜（kimjang）（芥菜泡菜和盐渍），给越冬芥菜覆盖。12月管理储存品、清理田地、翻压收获残余物 |

> **芥菜的一年有两个高峰。春芥菜更接近为取种而种，秋芥菜是为取得食物而种。灾害第一年，春芥菜一半吃掉、一半留作种子，留下的那一半决定当年秋天和第二年的全部。**
