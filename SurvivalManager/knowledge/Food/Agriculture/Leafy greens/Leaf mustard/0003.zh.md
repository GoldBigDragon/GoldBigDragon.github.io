## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

| 项目 | 内容 |
|:---|:---|
| 学名 | Brassica juncea |
| 分类 |Magnoliophyta Magnoliopsida / Brassicales / Brassicaceae / Brassica |
| 别名 | 芥末、芥菜、印度芥菜、青菜 |
| 生活型 | 一年生(具抽薹性)。秋播时为越冬的越年生一年生植物 |
| 原产地 | 从中亚到喜马拉雅一带的地区 |
| 起源 | 白菜(Brassica rapa)与黑芥(Brassica nigra)的自然杂交 |

&nbsp;&nbsp;&nbsp;芥菜的族谱在十字花科作物中也很特别,因为它不是在野外独自演化而来的物种,而是两个物种相遇后产生的物种。白菜的一组染色体(A染色体组)与黑芥的一组染色体(B染色体组)共处一体并稳定下来,这种同时携有两个物种染色体的状态称为复二倍体。油菜(Brassica napus)由白菜与结球甘蓝杂交而来,原理相同。十字花科中三个基本种与三个杂交种所构成的关系被称为"禹氏三角",芥菜正位于这个三角形的一边。

&nbsp;&nbsp;&nbsp;这一事实在栽培上有两点意义。一是芥菜混合了白菜与黑芥的特性:像白菜那样叶片展开快、质地柔软,又像黑芥那样合成大量黑芥子苷而辛辣。二是杂交的界限:芥菜与白菜、黑芥都共享染色体,因此存在与它们杂交的可能,但与完全不共享染色体的结球甘蓝类(Brassica oleracea)实际上不会杂交。这一区分正是第13节留种的关键。

### 2-2. 外观

| 器官 | 特征 |
|:---|:---|
| 叶 | 边缘呈锯齿状,表面略有皱褶。绿色·紫红色·复合色等因品种而异 |
| 茎 | 直立生长,生长后期开始分枝 |
| 根 | 主根向下生长,但分布相对较浅 |
| 花 | 黄色四片花瓣呈十字排列,是典型的十字花科花型 |
| 果实 | 细长的荚果(长角果)。成熟后变褐色并干燥,内部种子排成一列 |
| 种子 | 直径1-2mm的圆粒。褐色至红褐色 |

&nbsp;&nbsp;&nbsp;芥菜根系分布浅这一事实,直接关系到水分管理。由于无法吸取深层的水分,表土一干就会立即停止生长。反过来说,它也不是特别耗水的作物。根系浅、但生长期短,总需水量仅300mm。少量多次浇水的方式适合芥菜,一次性深浇的方式则不合适。

&nbsp;&nbsp;&nbsp;叶色因品种而异,这种差异也是成分上的差异。红芥(Jeokgat)的红色来自花青素这种色素,遇紫外线和低温会变得更深。同一块地里,秋天种的红芥比春天种的颜色更深,原因就在这里。这种色素具有抗氧化作用,因此若在地里混种青芥(Cheonggat)与红芥,同一面积能获得的成分种类就更广。

### 2-3. 生长阶段

| 阶段 | 时期(以播种为基准) | 主要生理变化 | 主要吸收的养分 |
|:---|:---|:---|:---|
| 发芽·幼苗期 | 播种-7天 | 种子吸水,子叶展开 | 磷、氮 |
| 初期营养生长期 | 7-20天 | 真叶长出,根系扎稳 | 氮 |
| 快速营养生长期 | 20-45天 | 叶片和茎迅速增大 | 氮、钾 |
| 收获适期 | 45-60天 | 叶片已长成,尚未变老变硬 | 氮与钾的平衡 |
| 抽薹·开花期 | 60-100天 | 花茎抽出,开黄花,叶片变老 | 磷、钾 |
| 结实·灌浆成熟期 | 开花后50-55天 | 荚果成熟,种子成熟饱满 | 磷、钾 |

&nbsp;&nbsp;&nbsp;这张表中值得留意的一点是,整个生命周期在100天左右就结束了,这也意味着人能介入调整的时间窗口很窄。若最初20天内养分和水分不足,后面就没有时间挽回这一损失。芥菜之所以把一切都押在基肥上、几乎不用追肥,原因就在这张时间表里。

> **芥菜生长期短,前期养分供应几乎决定了产量。由于没有时间靠追肥补救,胜负在基肥阶段就已经决定。**

&nbsp;&nbsp;&nbsp;抽薹的时机也很重要。芥菜的花茎会在两种条件下抽出:一种是经历一段低温后日照变长时,另一种是受到高温和干旱应激时。春天早播的芥菜还没长成就抽出花茎,是前一种情况;盛夏播种的芥菜叶片还没舒展开就抽出花茎,是后一种情况。这两种情况都会使叶片变老、只剩辛味变强,变得难以食用。这就是芥菜的栽培方式分为春播和秋播、夏季空档的原因。

### 2-4. 每100克的营养

| 成分 | 含量 | 备注 |
|:---|:---:|:---|
| 热量 | 36kcal | 因品种和部位而异,为24-36kcal |
| 水分 | 87.8g | |
| 蛋白质 | 3.50g | 占热量比例38.9% |
| 碳水化合物 | 4.5-7.3g | |
| 膳食纤维 | 2.6g | |
| β-胡萝卜素 | 533 μg | 在体内转化为维生素A |
| 维生素B1(硫胺素) | 0.07mg | |
| 糖类 | 1.51g | 以同属实测8种的中位数插补 |
| 钙·铁·磷·钾 | 达到RDA 10%的项目 | 绝对含量处于叶菜平均水平 |

&nbsp;&nbsp;&nbsp;读这张表时要抓住的数字,是蛋白质3.50g与热量36kcal的比例。这衡量的是每1kcal热量中含有多少蛋白质,芥菜为38.9%,接近人体所需10%的四倍。这并不代表芥菜的蛋白质含量高——绝对量3.5g连大豆的10%都不到,只是因为作为分母的热量本身很小,比例才显得大。

&nbsp;&nbsp;&nbsp;尽管如此,这个比例仍有意义。灾害情境下的饮食大多靠谷物和薯类(块茎/块根)填补热量,而这些食物的蛋白质占热量比例较低——大米约8%,马铃薯约9%,勉强达到或达不到人体所需的10%这条线。这时如果搭配像芥菜这样比例高的蔬菜,整体饮食的比例就会提升。这是一种在不增加热量的前提下单独提高蛋白质比例的方法,也是叶菜在谷物为主的饮食中扮演的隐性角色。

&nbsp;&nbsp;&nbsp;β-胡萝卜素533μg也值得留意。维生素A不溶于水而溶于油,不加油食用会大大降低吸收率。用紫苏油或芝麻油拌芥菜的做法,不仅是为了味道,也是为了提高吸收率。灾害情况下即使油很珍贵,把紫苏籽或芝麻捣碎混入,也能获得类似的效果。

## 3. 栽培环境

### 3-1. 温度

| 类别 | 温度 | 说明 |
|:---|:---:|:---|
| 生长适温 | 15-20℃ | 叶片最柔嫩,产量最高 |
| 可生长范围 | 10-25℃ | 评价表中幅度超过15℃,但因抽薹限制按12℃计 |
| 发芽最低温度 | 6℃ | 低于此温度发芽会极慢 |
| 发芽最适温度 | 25℃ | 3-5天即可发芽 |
| 发芽最高温度 | 35℃ | 高于此温度发芽率会下降 |
| 高温限界 | 25℃以上 | 辛味变强,叶片变老变硬 |
| 低温限界 | -5℃ | 低于此温度叶片会冻伤软烂 |
| 诱导抽薹低温 | 0-10℃持续一段时间 | 之后日照变长便会抽薹 |

&nbsp;&nbsp;&nbsp;关于芥菜的温度条件,最实用的信息是发芽范围极宽:6-35℃都能发芽。这意味着从早春到晚夏,不论什么时候播种基本都能发芽,在灾害情境下这是相当大的灵活性。田里一旦出现空地,不必太顾虑季节就能撒下去的种子,芥菜就是其中之一。

&nbsp;&nbsp;&nbsp;问题在于发芽之后。在超过25℃的条件下长大的芥菜,叶片会变薄变老,辛味会过重。这对植物来说是正常反应:炎热和干旱是一种应激,受到应激的十字花科植物会制造更多作为防御物质的芥子油苷,结果是朝着不利于人食用的方向变化。"夏天的芥菜不好吃"这一经验之谈,背后正是这种生理机制。

&nbsp;&nbsp;&nbsp;相反,在凉爽的条件下,尤其是秋季昼夜温差大的时期长成的芥菜,辛味与甜味会达到平衡。因为夜间气温下降时,呼吸消耗的糖分减少,糖分就会积累在叶片中。人们说腌越冬泡菜(kimjang)时节的芥菜最好吃,指的正是这一现象。

> **芥菜是喜凉作物。夏天也能发芽,但长不出能吃的叶子。灾害情境下夏季播种芥菜,很容易变成浪费种子和劳力。**

### 3-2. 光照

| 项目 | 标准 | 备注 |
|:---|:---|:---|
| 光照需求 | 每天6小时以上直射光 | |
| 半阴环境适应 | 可以 | 40%遮光时叶菜类相对产量86% |
| 种子发芽 | 需光萌发性 | 见光才能提高发芽率 |
| 光照不足症状 | 植株徒长,茎变长,叶变薄 | |

&nbsp;&nbsp;&nbsp;芥菜种子属于需光萌发型,这一点是播种时最常出错的地方。这种种子需要见光才能促进发芽,覆土太厚会使发芽率急剧下降。合适的覆土厚度是0.5至1cm,刚好盖住种子即可。这与生菜的性质相同,而与需要深埋的马铃薯或豆类正好相反。

&nbsp;&nbsp;&nbsp;遮光条件下相对产量为86%这一数值,在灾害情境下也有意义。即便是建筑物阴影或树下这类整天不见阳光的地方,芥菜也能有一定产量。这是叶菜类的普遍特性,因为叶片本身就是收获物,不需要把光合产物运往根部或果实。不过在阴处长大的芥菜辛味较弱、叶片较薄。这算优点还是缺点,取决于用途:若是要腌泡菜的芥菜,阳光充足的地方更好;若是要柔嫩的叶子做凉拌菜(namul),半阴处也不错。

### 3-3. 水分与土壤

| 项目 | 标准 | 备注 |
|:---|:---|:---|
| 总蒸散量 | 约300mm | 在叶菜中偏少 |
| 土壤水分 | 保持良好的保水状态 | 根系浅,表土一干就立即停止生长 |
| 过湿 | 有烂根风险 | 需确保排水沟畅通 |
| 土壤 | 富含有机质、保水力好的肥沃土地 | 在黏质肥沃土壤中产量与品质最佳 |
| 土壤酸度 | pH 6.0-7.5 | 弱酸性至中性 |
| 垄高 | 15-20cm | 用于确保排水 |
| 深耕 | 20-30cm | 评价表中的挖掘能耗按全面10cm计算 |

&nbsp;&nbsp;&nbsp;pH降到6.0以下,芥菜的长势会明显变差,因为十字花科作物共通的根肿病在酸性土壤中会大大加重。引起根肿病的原生生物在pH6.0以下活跃,在pH7.2以上活动大幅减少。在没有石灰的灾害情境下,应对这一问题的办法是草木灰。烧木头后留下的灰含有碳酸钾和氧化钙,呈碱性,撒入田里能提高酸碱度。不过草木灰见效快、效力强,用多了会使土壤偏向碱性,阻碍微量元素的吸收。每平方米一小把左右是一年内能承受的量,撒后要与土充分混合。

&nbsp;&nbsp;&nbsp;在水分方面,芥菜有两个相互矛盾的需求:它喜欢湿润,却又怕过湿。根系浅浅铺展,对表土的水分状态很敏感;同时这浅根一旦泡在水里就得不到氧气,很快开始腐烂。解决办法是起垄。种在15-20cm高的垄上,根部周围的水能向下排出,垄内部又能保持湿润。在梅雨季节确认排水沟是否畅通,是芥菜栽培中最实际的水分管理。

&nbsp;&nbsp;&nbsp;在没有地膜的情况下,可用稻草、干草、落叶、稻壳代替。对像芥菜这样根系浅的作物,有机物覆盖的效果很大:能防止表土水分蒸发,防止雨滴打在土面上形成硬壳,腐烂后还能变成养分。不过播种后不能马上覆盖,因为这是需光萌发型种子,遮光会影响发芽。正确的顺序是等长出三四片真叶后,再铺在植株之间。

## 4. 品种

### 4-1. 各品系特点

| 品种 | 特点 | 口味与口感 | 主要用途 |
|:---|:---|:---|:---|
| 青芥(Cheonggat) | 叶片青绿,辛味强。耐寒性和耐病性强 | 辛味浓 | 最广泛用于制作泡菜 |
| 红芥(Jeokgat,又称Honggat) | 叶片带红色,花青素含量高 | 辛味中等 | 泡菜、包菜叶食用、突出颜色的腌渍 |
| 突山芥(Dolsangat,全罗南道突山地区特产品种) | 叶片大而宽的晚熟品种 | 口感柔软 | 专用于芥菜泡菜 |
| 耐寒青芥(Eolcheonggat) | 耐寒,可越冬栽培 | 味道温和 | 冬季栽培与早春收获 |
| 野芥(Deulgat,近野生种) | 接近野生种 | 香气强烈、口感粗糙 | 贫瘠地与粗放栽培 |

&nbsp;&nbsp;&nbsp;品种之间的差异归结起来可以整理成两个轴:辛味的强弱和耐寒的能力。青芥偏向辛味强的一端,突山芥偏向柔软的一端,耐寒青芥偏向耐寒的一端。这一选择在灾害情境下之所以重要,是因为辛味的强弱直接等同于贮藏能力的强弱。

&nbsp;&nbsp;&nbsp;芥子油苷的分解产物烯丙基异硫氰酸酯具有抗菌作用,这本是理所当然的,因为它正是植物为抵御细菌和霉菌而制造的物质。用这种物质含量高的芥菜腌的泡菜,腐败菌繁殖得慢,能保存更久。相反,用柔软品种腌的泡菜虽然好吃,但很快就会变酸、变软。因此,要在整个冬天慢慢吃的贮藏泡菜适合用青芥,而冬初就要马上吃的泡菜适合用突山芥。

&nbsp;&nbsp;&nbsp;野芥在商业栽培中被淘汰,但在灾害情境下值得重新审视。因为改良程度低,它反而更抗病虫害,施肥少也能长到一定程度,还会自行落籽,第二年再生。把野芥放在田边或路边这类无人管理的地方,即使没人照料也能延续好几年。味道粗糙但能吃,最重要的是种子不会断绝。

### 4-2. 按情况选择的标准

| 情况 | 选择 | 理由 |
|:---|:---|:---|
| 灾害初期,追求最短期收获 | 青芥、红芥 | 生长快,20-30天即可收获嫩叶 |
| 泡菜与长期贮藏 | 青芥、突山芥 | 青芥辛味强、耐储性好,突山芥叶片大、便于处理 |
| 想拓宽营养覆盖面时 | 红芥 | 能额外获得花青素 |
| 冬季栽培与越冬 | 耐寒青芥 | 耐寒性最强 |
| 贫瘠地、粗放栽培 | 野芥 | 省事,能靠自然落籽延续下去 |
| 想分散风险时 | 混播青芥与红芥 | 抽薹时期与抗病性不同,可降低全军覆没的风险 |

&nbsp;&nbsp;&nbsp;最后一行的混种,在灾害情境下价值特别大。只种一个品种时,一旦出现该品种脆弱的病害,整块地就会全垮。混种两三个特性不同的品种,即使某一个受害,其余的还能保留下来。收获期分散也是一个优点:把晚熟的突山芥和早熟的青芥一起种下,收获就会分散在2-3周内进行。

> **在灾害情境下,选择品种的第一标准不是产量,而是分散风险。比起单一最优品种,特性不同的两三个品种存活下来的概率更高。**
