## 2. どんな植物か

### 2-1. 分類と原産地

| 項目 | 内容 |
|:---|:---|
| 学名 | Brassica juncea |
| 分類 |Magnoliophyta Magnoliopsida / Brassicales / Brassicaceae / Brassica |
| 別名 | からし、カラシナ、インドガラシ、青菜(チンツァイ) |
| 生活形 | 一年草(抽だい性)。秋播きの場合は冬を越す越年草になります |
| 原産地 | 中央アジアからヒマラヤに至る地域 |
| 起源 | ハクサイ(Brassica rapa)とクロガラシ(Brassica nigra)の自然交雑 |

&nbsp;&nbsp;&nbsp;カラシナの系譜はアブラナ科作物の中でも特異です。野生で独自に進化した種ではなく、二つの種が出会って生まれた種だからです。ハクサイの染色体一組(Aゲノム)とクロガラシの染色体一組(Bゲノム)が一つの体に収まって定着し、このように二つの種の染色体を両方持つ状態を複二倍体と呼びます。セイヨウアブラナ(Brassica napus)がハクサイとキャベツの交雑で生まれたのと同じ仕組みです。アブラナ科の中で三つの基本種と三つの交雑種が作る関係は「Uの三角形」と呼ばれ、カラシナはその三角形の一辺に位置します。

&nbsp;&nbsp;&nbsp;この事実が栽培において持つ意味は二つです。一つは、カラシナがハクサイとクロガラシの性質を併せ持つということです。ハクサイのように葉が早く開いて柔らかい一方、クロガラシのようにシニグリンを多く作って辛くなります。もう一つは交雑の境界線です。カラシナはハクサイともクロガラシとも染色体を共有しているため、これらとの交雑が起こる余地がありますが、染色体を全く共有しないキャベツ類(Brassica oleracea)とは実質的に交雑しません。この区別が13節の採種の要点です。

### 2-2. 見た目

| 器官 | 特徴 |
|:---|:---|
| 葉 | ぎざぎざの縁、表面にわずかなしわ。緑色・赤紫色・複合色など品種によって多様 |
| 茎 | 直立して育ち、生育後期に枝分かれします |
| 根 | 直根が下に伸びますが、比較的浅く分布します |
| 花 | 黄色い4枚の花弁が十字に並ぶ、アブラナ科特有の形 |
| 果実 | 細長い鞘(長角果)。熟すと茶色く乾き、中に種子が並んでいます |
| 種子 | 直径1-2mmの丸い粒。茶色から赤茶色 |

&nbsp;&nbsp;&nbsp;カラシナの根が浅く分布するという事実は、水管理に直結します。深いところの水を吸い上げられないため、表土が乾くとすぐに生育が止まります。反対に、水をとても多く使う作物でもありません。根が浅い代わりに生育期間が短く、総要求量は300mmにとどまります。少量を頻繁に与える方式がカラシナに合い、一度に深く与える方式は向きません。

&nbsp;&nbsp;&nbsp;葉の色は品種によって異なり、その違いは成分の違いでもあります。チョッカット(赤がらし系)の赤色はアントシアニンという色素で、紫外線と低温に反応してより濃くなります。同じ畑で秋に育てたチョッカットが春に育てたものより色が濃い理由です。この色素は抗酸化物質として働くため、畑にチョンガット(青がらし系)とチョッカットを混ぜて植えると、同じ面積で得られる成分の幅が広がります。

### 2-3. 生育段階

| 段階 | 時期(播種基準) | 主な生理 | 多く使う養分 |
|:---|:---|:---|:---|
| 発芽・幼苗期 | 播種-7日 | 種子が水を吸収し、子葉が開きます | リン、窒素 |
| 初期栄養生長期 | 7-20日 | 本葉が出て根が定着します | 窒素 |
| 急速栄養生長期 | 20-45日 | 葉と茎が急速に大きくなります | 窒素、カリウム |
| 収穫適期 | 45-60日 | 葉が十分に育ち、まだ硬くなっていない状態 | 窒素とカリウムの均衡 |
| 抽だい・開花期 | 60-100日 | 花茎が立ち、黄色い花が咲きます。葉は硬くなります | リン、カリウム |
| 結実・登熟期 | 開花後50-55日 | 鞘が熟し、種子が実ります | リン、カリウム |

&nbsp;&nbsp;&nbsp;この表で注目すべき点は、生涯全体が100日前後で終わるということです。人が介入できる間隔が狭いという意味でもあります。最初の20日以内に養分と水が不足すると、その損失を後で取り戻す時間がありません。カラシナが元肥にすべてを賭け、追肥をほとんど使わない作物になった理由は、このスケジュールの中にあります。

> **カラシナは生育期間が短いため、初期の養分供給が収量をほぼ決定します。追肥で取り戻す時間がないため、元肥の段階で勝負が決まります。**

&nbsp;&nbsp;&nbsp;抽だいの時期がいつ来るかも重要です。カラシナの花茎は二つの条件で立ちます。一つは一定期間低温を経た後に日が長くなったとき、もう一つは高温と乾燥のストレスを受けたときです。春に早く播いたカラシナが育ちきる前に花茎を上げるのが前者の場合で、真夏に播いたカラシナが葉もまだ十分に広がらないうちに花茎を上げるのが後者の場合です。どちらの場合も葉が硬くなり辛味だけが強くなって食べにくくなります。カラシナの作型が春と秋に分かれ、夏が空いている理由です。

### 2-4. 100gあたりの栄養

| 成分 | 含量 | 備考 |
|:---|:---:|:---|
| 熱量 | 36kcal | 品種と部位により24-36kcal |
| 水分 | 87.8g | |
| タンパク質 | 3.50g | 熱量に占める割合38.9% |
| 炭水化物 | 4.5-7.3g | |
| 食物繊維 | 2.6g | |
| β-カロテン | 533 μg | 体内でビタミンAに変換 |
| ビタミンB1(チアミン) | 0.07mg | |
| 糖類 | 1.51g | 同属の実測8種の中央値で代入 |
| カルシウム・鉄・リン・カリウム | RDA10%を満たす項目 | 絶対量は葉物野菜の平均的な水準 |

&nbsp;&nbsp;&nbsp;この表を読むときにつかむべき数字は、タンパク質3.50gと熱量36kcalの比率です。熱量1kcalあたりタンパク質がどれだけ含まれているかを見る値で、カラシナは38.9%と、人が必要とする10%の4倍近くになります。これはカラシナにタンパク質が多いという意味ではありません。絶対量の3.5gはダイズの10%にも届きません。分母である熱量が非常に小さいために比率が大きくなっているのです。

&nbsp;&nbsp;&nbsp;それでもこの比率には意味があります。災害時の食事は多くの場合、穀類やいも類(塊茎・塊根)で熱量を満たしますが、これらの食品は熱量に対するタンパク質の割合が低いのです。米が8%前後、ジャガイモが9%前後で、人が必要とする10%というラインにかろうじて届くか、届かないかです。このとき、カラシナのように比率が高い野菜を添えると、食事全体の比率が上がります。熱量を増やさずにタンパク質の比率だけを上げる方法であり、葉物野菜が穀物中心の食事の中で果たす隠れた役割です。

&nbsp;&nbsp;&nbsp;β-カロテン533μgも押さえておきたい項目です。ビタミンAは水に溶けず油に溶ける性質のため、油なしで食べると吸収率が大きく落ちます。カラシナをエゴマ油やゴマ油で和える調理法は、味だけでなく吸収率のためでもあります。災害時に油が貴重であっても、エゴマやゴマを砕いて混ぜる程度で同様の効果を得られます。

## 3. 栽培環境

### 3-1. 温度

| 区分 | 温度 | 説明 |
|:---|:---:|:---|
| 生育適温 | 15-20℃ | 葉が最も柔らかく、収量も高くなります |
| 生育可能範囲 | 10-25℃ | 評価表上は幅15℃以上だが、抽だいの制約により12℃を適用 |
| 発芽最低温度 | 6℃ | これより低いと発芽が極端に遅くなります |
| 発芽最適温度 | 25℃ | 3-5日で芽が出ます |
| 発芽最高温度 | 35℃ | これより高いと発芽率が下がります |
| 高温限界 | 25℃以上 | 辛味が強くなり、葉が硬くなります |
| 低温限界 | -5℃ | これより下では葉が凍って傷みます |
| 抽だい誘導低温 | 0-10℃を一定期間 | その後日が長くなると花茎が立ちます |

&nbsp;&nbsp;&nbsp;カラシナの温度条件で最も実用的な情報は、発芽の範囲が極めて広いという点です。6-35℃まで芽が出ます。春の早い時期から晩夏まで、いつ種をまいても一応発芽するという意味で、災害時にはかなりの柔軟性になります。畑に空いた場所ができたとき、季節をあまり気にせず投入できる種がカラシナです。

&nbsp;&nbsp;&nbsp;問題は発芽した後です。25℃を超える条件で育ったカラシナは、葉が薄く硬くなり、辛味が過剰に強くなります。植物にとっては正常な反応です。暑さと乾燥はストレスであり、ストレスを受けたアブラナ科植物は防御物質であるからし油配糖体をより多く作ります。人が食べるには不利な方向へ変わるわけです。夏のカラシナはまずいという経験則には、この生理が背景にあります。

&nbsp;&nbsp;&nbsp;反対に、涼しい条件、特に秋の昼夜の気温差が大きい時期に育ったカラシナは、辛味と甘味がバランスを取ります。夜に気温が下がると呼吸で消費される糖が減り、葉に糖が蓄積するためです。キムジャン(越冬用キムチ漬け)の季節のカラシナが最もおいしいと言われるのは、この現象を指しています。

> **カラシナは涼しい季節の作物です。夏でも発芽はしますが、食べられる葉にはなりません。災害時に夏に種をまくのは、種と労力を無駄にする結果になりやすいです。**

### 3-2. 光

| 項目 | 基準 | 備考 |
|:---|:---|:---|
| 日照要求 | 1日6時間以上の直射光 | |
| 半日陰への適応 | 可能 | 40%遮光時の葉菜類相対収量86% |
| 種子発芽 | 光発芽性 | 光を受けると発芽率が高くなります |
| 不足時の症状 | 徒長して茎が伸び、葉が薄くなります | |

&nbsp;&nbsp;&nbsp;カラシナの種子が光発芽性であるという事実は、播種で最もよく間違いが起きる点です。光を受けることで発芽が促される種子なので、土を厚く覆うと発芽率が急激に下がります。0.5cmから1cm、種がかろうじて隠れる程度が適当です。サンチュと同じ性質で、ジャガイモや豆のように深く埋める作物とは正反対です。

&nbsp;&nbsp;&nbsp;遮光条件での相対収量86%という値も、災害時には意味があります。建物の陰や木の下のように一日中日が当たらない場所でも、カラシナはある程度の収量を出します。これは葉物野菜全般の特性で、葉そのものが収穫物であるため、光合成産物を根や果実に移す必要がないからです。ただし、陰で育ったカラシナは辛味が弱く、葉が薄くなります。これを欠点と見るか長所と見るかは用途によります。キムチ用のカラシナなら日当たりの良い場所が良く、ナムルとして食べる柔らかい葉が目的なら半日陰も悪くありません。

### 3-3. 水と土壌

| 項目 | 基準 | 備考 |
|:---|:---|:---|
| 総蒸発散量 | 約300mm | 葉物野菜の中では少ないほう |
| 土壌水分 | 保水力の良い状態を維持 | 根が浅いため表土が乾くとすぐ生育が止まります |
| 過湿 | 根腐れの危険 | 排水路を確保します |
| 土壌 | 有機質が豊富で保水力の良い肥沃な土 | 粘質の肥沃な土壌で収量と品質が優れます |
| 土壌酸度 | pH6.0-7.5 | 弱酸性から中性 |
| 畝の高さ | 15-20cm | 排水確保用 |
| 深耕 | 20-30cm | 評価表上の掘削エネルギー算定は全面10cm基準 |

&nbsp;&nbsp;&nbsp;pH6.0を下回ると、カラシナは目に見えて悪くなります。アブラナ科作物共通の問題である根こぶ病が、酸性土壌でずっと悪化するためです。根こぶ病を引き起こす原生生物はpH6.0以下で活発になり、pH7.2以上では活動が大きく減ります。石灰がない災害時にこの問題に対処する方法は草木灰です。木を燃やした後に残る灰は炭酸カリウムと酸化カルシウムを含んでアルカリ性を示すため、畑に振ると酸度が上がります。ただし草木灰は効果が速く強い一方、与えすぎると土壌がアルカリ側に偏り、微量元素の吸収が妨げられます。㎡あたり一握り程度が1年に施せる量で、振った後は土としっかり混ぜる必要があります。

&nbsp;&nbsp;&nbsp;水に関しては、二つの相反する要求があります。カラシナは水分を好みますが、過湿には弱いのです。根が浅く広がっているため表土の水分状態に敏感であり、同時にその浅い根が水に浸かると酸素を得られずすぐに腐り始めます。解決策は畝を立てることです。15-20cmの高さの畝の上に植えると、根の周りの水が下に抜けつつ、畝の内側は湿った状態が保たれます。梅雨の時期に排水路が詰まっていないか確認することが、カラシナ栽培において最も実質的な水管理です。

&nbsp;&nbsp;&nbsp;ビニールマルチがない状況では、藁、乾草、落ち葉、籾殻が代わりになります。カラシナのように根が浅い作物には有機物マルチの効果が大きく、表土の水分蒸発を防ぎ、雨粒が土を叩いて表面が固まるのを防ぎ、腐ることで養分にもなります。ただし、播種直後には覆いません。光発芽性の種子なので、光を遮ると発芽が悪くなるからです。本葉が3-4枚出た後に株の間に敷くのが正しい順序です。

## 4. 品種

### 4-1. 系統別の特徴

| 品種 | 特徴 | 味と食感 | 主な用途 |
|:---|:---|:---|:---|
| チョンガット(青がらし系) | 葉が青く、辛味が強い。耐寒性と耐病性が強い | 辛味が強い | キムチ用として最も広く使われます |
| チョッカット(赤がらし系、ホンガットとも) | 葉が赤色を帯び、アントシアニンが多い | 辛味は中程度 | キムチ、包み野菜、色を活かした漬物 |
| トルサンガット(全羅南道突山特産の大葉品種) | 葉が大きく広い晚生種 | 柔らかい | カラシナキムチ専用 |
| オルチョンガット(耐寒性の青がらし系) | 寒さに強く越冬栽培ができます | 穏やかな味 | 冬栽培と早春の収穫 |
| トゥルガット(野生系) | 野生種に近い | 香りが強く粗い | 貧しい土地や放任栽培 |

&nbsp;&nbsp;&nbsp;品種間の違いは結局二つの軸に整理できます。辛味の強さと、寒さに耐える力です。チョンガットは辛味の方向に、トルサンガットは柔らかさの方向に、オルチョンガットは耐寒性の方向に位置します。災害時にこの選択が重要な理由は、辛味の強さがそのまま貯蔵能力の強さになるからです。

&nbsp;&nbsp;&nbsp;からし油配糖体の分解物であるアリルイソチオシアネートは抗菌作用を持ちます。植物が細菌やカビを防ぐために作った物質ですから当然のことです。この物質が多いカラシナで漬けたキムチは腐敗菌の増殖が遅く、長く持ちます。反対に、柔らかい品種で漬けたキムチは食べやすい一方、早く酸っぱくなり早く傷みます。そのため、冬の間ずっと食べる貯蔵用キムチにはチョンガットが、冬の初めにすぐ食べるキムチにはトルサンガットが向いています。

&nbsp;&nbsp;&nbsp;トゥルガットは商業栽培では退けられた系統ですが、災害時には見直す価値があります。改良が少ない分、病害虫に強く、肥料が少なくてもある程度育ち、自ら種を落として翌年また生えてきます。畑の端や道端のような管理されない場所にトゥルガットを放しておけば、人が手を入れなくても数年続いていきます。味は粗いですが食べられますし、何より種が絶えません。

### 4-2. 状況別の選択基準

| 状況 | 選択 | 理由 |
|:---|:---|:---|
| 災害初期、最短期の収穫 | チョンガット、チョッカット | 生育が早く、幼葉を20-30日で収穫できます |
| キムチと長期貯蔵 | チョンガット、トルサンガット | チョンガットは辛味が強く貯蔵性が良く、トルサンガットは葉が大きく扱いやすい |
| 栄養の幅を広げたいとき | チョッカット | アントシアニンが加わります |
| 冬栽培と越冬 | オルチョンガット | 耐寒性が最も強い |
| 貧しい土地、放任栽培 | トゥルガット | 手がかからず、自然に種が落ちて続いていきます |
| リスクを分散したいとき | チョンガットとチョッカットを混ぜて播種 | 抽だいの時期と病気への抵抗性が異なるため、全滅の危険が減ります |

&nbsp;&nbsp;&nbsp;最後の行にある混植は、災害時に特に価値が大きいです。一つの品種だけを植えると、その品種が弱い病気が入ってきたときに畑全体が崩れます。性質の異なる二三品種を混ぜれば、どれか一つが被害を受けても残りが生き延びます。収穫時期が分散するのも利点です。晚生種のトルサンガットと早生のチョンガットを一緒に植えると、収穫が2-3週間に分かれます。

> **災害時における品種選択の第一の基準は、収量ではなくリスクの分散です。最も優れた品種一つよりも、性質の異なる二三品種のほうが生き残る確率が高いのです。**
