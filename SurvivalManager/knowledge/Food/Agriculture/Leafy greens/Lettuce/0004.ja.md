## 5. 畑の準備と肥料

### 5-1. 畑づくり

| 項目 | 方法 |
|:---|:---|
| 耕起 | 20-30cmの深さに耕し、土塊を砕いて細かく整地します |
| 畝 | 高さ15-20cm。排水溝も一緒に作ります |
| 土壌酸度 | pH 6.0-6.6に調整します |
| 有機物 | 完熟堆肥を播種の1-2週間前に施して混ぜます |
| 表面の整え | 種子が非常に小さいため、表面を細かくならします |

&nbsp;&nbsp;&nbsp;サンチュの畑の準備で、他の作物と違う点は表面をならすことです。サンチュの種子は長さ3mmほどときわめて小さく、播種の深さも2-3mmにすぎません。土塊が大きいと、種子がその隙間に落ちて深く埋もれ、好光性種子なので芽が出ません。播種する場所だけでも、土をふるいにかけるように細かく砕いてならすことが、発芽率を左右します。

&nbsp;&nbsp;&nbsp;深く耕す作業そのものは、サンチュには必須ではありません。根が浅く広がる作物だからです。評価表の整地・掘削エネルギーが深耕10cmを基準に算定されているのも、そのためです。労力を節約しなければならない状況なら、表土10cmだけをよく砕いておけば、サンチュは育ちます。ただし、排水の悪い畑では、畝を立てる作業は省けません。

### 5-2. 施肥量

| 肥料 | 1,000㎡当たり | ㎡換算 | 施用時期 |
|:---|:---:|:---:|:---|
| 窒素（N） | 10-12kg | 10-12g | 全量を元肥 |
| リン酸（P） | 6-8kg | 6-8g | 全量を元肥 |
| カリウム（K） | 6-8kg | 6-8g | 全量を元肥 |
| 堆肥 | 1,000-1,500kg | 1-1.5kg | 播種の1-2週間前 |
| 石灰 | 100-150kg | 100-150g | 酸性土の矯正用 |

| 区分 | 時期 | 内容 |
|:---|:---|:---|
| 元肥 | 播種の1-2週間前 | 堆肥と肥料の全量 |
| 追肥 | 原則として省略 | やせた畑や再生収穫が長引くときだけ少量 |

&nbsp;&nbsp;&nbsp;サンチュは生育期間が短く、根が深く伸びないため、肥料は元肥として十分に施し、追肥はほとんど与えません。評価表の施肥の項目がB、窒素・リン酸・カリウムの合計約22gと設定されているのが、この値です。

> **サンチュに追肥を与えると、かえって味が落ちます。窒素濃度が高くなると、葉が軟弱になり、苦味が強まり、病気にも弱くなります。やせた土地でなければ、元肥だけで十分です。**

&nbsp;&nbsp;&nbsp;ただし、再生収穫を長く続ける場合は例外です。2か月以上葉を摘み続けると、畑の養分が実際に抜けていきます。このときは2-3週間に一度、薄めた追肥を与えますが、葉を摘んだ直後に与え、収穫の数日前には与えません。窒素を与えてすぐに摘んだ葉には、硝酸塩が残ることがあるからです。

### 5-3. 災害時の代替肥料

| 代替資源 | 供給できる栄養素 | 使い方 | 注意 |
|:---|:---|:---|:---|
| 完熟堆肥 | 窒素・リン酸・カリウムと微量元素全般 | ㎡当たり1-1.5kgを元肥として施します | 未熟なものは若い根を傷めます |
| 草木灰 | カリウム、リン酸、カルシウム | ㎡当たりひとつかみを撒いて土と混ぜます | アルカリ性なので、pH 6.6を超えないよう調整します |
| 薄めた尿 | 窒素 | 水で15倍から20倍に薄めます | サンチュは窒素に敏感なので、他の作物より薄めて使います |
| 骨粉 | リン酸、カルシウム | 堆肥に混ぜて元肥として施します | 分解が遅いので、前もって施す必要があります |
| 卵の殻の粉 | カルシウム | 細かく砕いて畑に混ぜます | 葉先枯れ症状の予防に使われます |
| 落ち葉・草の腐葉土 | 有機物 | 畑にすき込むか、マルチングに使います | 完全に腐熟したものを使います |

&nbsp;&nbsp;&nbsp;サンチュに薄めた尿を使うときは、他の作物より薄くします。大半の葉菜には10-15倍が勧められますが、サンチュは15倍から20倍が無難です。窒素が多すぎると、葉が軟弱になって苦味が強まり、アブラムシが集まるからです。しかもサンチュは生で食べる野菜なので、硝酸塩の蓄積にいっそう気を配る必要があります。

&nbsp;&nbsp;&nbsp;草木灰はカリウムとカルシウムを供給しますが、アルカリ性が強いです。サンチュが求めるpH 6.0-6.6はアブラナ科作物より低めなので、草木灰をダイコンの場合のように多めに施すと、pHが上がりすぎます。少なめに施して様子を見るのが正解です。

## 6. 播種 - 光と温度に左右される種子

### 6-1. 作型

| 作型（韓国） | 播種時期 | 収穫時期 | 備考 |
|:---|:---|:---|:---|
| 春栽培 | 3月下旬-5月中旬 | 4月下旬-6月下旬 | 最も一般的です |
| 秋栽培 | 8月上旬-9月上旬 | 9月上旬-11月上旬 | 災害時に最も有利です |
| 夏栽培 | 勧めません | | 発芽の失敗と早期のとう立ち |
| 冬栽培 | 韓国南部の保温条件下のみ | | 生育がきわめて遅いです |

&nbsp;&nbsp;&nbsp;秋栽培が災害時に有利な理由は三つあります。第一に、育っている間ずっと気温が下がっていく方向なので、とう立ちの圧力がありません。春栽培は逆に気温が上がっていくため、どこかの時点で必ずとうが立ちます。第二に、涼しい条件で育ったサンチュは、葉が厚く、甘味が増します。第三に、再生収穫の期間が長くなります。春のサンチュが1か月ほどで終わるとすれば、秋のサンチュは2か月以上続きます。

&nbsp;&nbsp;&nbsp;ただし、秋の播種には落とし穴があります。韓国では8月上旬はまだ暑く、その暑さがまさに高温休眠を招きます。播種時点の地温が25度を超えると、種子が眠ってしまいます。そのため、秋播きの実際の技術は、暑さをどうかわして発芽させるかにあります。

### 6-2. 高温休眠を乗り越える方法

| 方法 | 手順 | 原理 |
|:---|:---|:---|
| 低温プライミング | 種子を水に4-6時間浸したあと、濡れた布に包んで涼しい場所に一日置きます | 水を吸った種子が低温を経験して休眠が解けます |
| 事前の催芽 | 濡れた布の間で芽がわずかに出てから、慎重に移して播きます | 発芽の段階を畑の外で済ませます |
| 夕方の播種 | 日が沈んでから播いて、水をたっぷり与えます | 夜の間に地温が下がる隙を使います |
| 遮光 | すだれ、木の枝、わらで播種場所に日陰をつくります | 地温を数度下げます |
| 水での冷却 | 播種直後と日中に冷たい水を撒きます | 気化熱で地温を下げます |

&nbsp;&nbsp;&nbsp;低温プライミングが最も確実で、手間もかかりません。種子が水を吸った状態で低温を経験すると、発芽を抑えていたホルモンのシグナルが解け、その後は暑い土に播いても芽が出ます。冷蔵庫がなくても、井戸水や地下室、北向きの日陰のような涼しい場所があれば足ります。ただし、水を吸った種子は乾くと死んでしまうため、処理後はすぐに播き、土が乾かないように保たなければなりません。

&nbsp;&nbsp;&nbsp;遮光は、播種場所だけを覆っても効果があります。種子が好光性なので完全に暗くしてはいけません。薄い日陰になるように、すだれや木の枝をまばらに載せます。芽が出たらすぐに取り除きます。

### 6-3. 播種の方法

| 項目 | 基準 | 備考 |
|:---|:---|:---|
| 播種の深さ | 2-3mm | 好光性。深く埋めると発芽しません |
| 覆土 | 細かい土を、種子がかろうじて隠れる程度だけ | まったく覆土せず、押さえるだけにすることもあります |
| 条間 | 20cm | |
| 播種方法 | 筋まきまたは点まき | 若い葉の収穫が目的なら、ばらまきも可能です |
| 播種量 | 密に播いてから間引きます | 発芽率が低い場合があるので、余裕を持たせます |
| 鎮圧 | 手や板で軽く押さえます | 種子と土が密着して初めて水を吸収します |

&nbsp;&nbsp;&nbsp;覆土をまったくせず、播いたあとに軽く押さえるだけの方法も使われます。好光性種子にはこのほうがよい場合もありますが、その代わり、種子が乾いたり雨で流されたりする危険があります。その折衷が2-3mmです。その上に枯れ草をごく薄くまいておけば、蒸発を減らしながら光は通します。

&nbsp;&nbsp;&nbsp;一度に全部は播かないというのが、サンチュ栽培の基本技術です。貯蔵できない作物なので、収穫が集中すると捨てることになります。10日から15日間隔に分けて播けば、収穫もそれだけ長く続きます。韓国での秋播きなら、8月上旬、8月中旬、9月上旬と三回に分ける、といった具合です。

### 6-4. 種子の処理と保管

| 処理 | 手順 | 効果 |
|:---|:---|:---|
| 選別 | ふっくらして色のそろった種子を選びます | 発芽率が上がります |
| 温湯浸漬 | 50-55℃の湯に10-15分浸してから、冷水で冷まします | 種子伝染性の病原菌を死滅させます |
| 低温保管 | 0-4℃の涼しい場所に密閉して置きます | 種子の寿命が延びます |
| 乾燥剤 | 炒って冷ました米や炭を一緒に入れます | 湿気を防ぎます |

&nbsp;&nbsp;&nbsp;サンチュの種子の寿命は、常温・密閉で2-3年と短めです。キク科の種子は皮が薄く、脂質を含んでいるため酸化が早いからです。涼しく保管すれば、寿命は目に見えて延びます。冷蔵庫がない状況では、室（むろ）や土の洞窟、北向きの地下空間、井戸の近くなど、一年中涼しい場所を探します。ただし、湿気があるとかえって早く死んでしまうため、密閉と乾燥剤はセットで使う必要があります。

## 7. 水管理

### 7-1. 生育段階別の水やり

| 時期 | 管理 | 備考 |
|:---|:---|:---|
| 播種-発芽 | 表土が乾かないよう、軽く頻繁に | 種子が浅いところにあるため乾きやすいです |
| 幼苗期 | 軽く頻繁に | 根が浅いです |
| 生育期 | 春と秋は3-5日間隔、夏は2-3日間隔 | 土の状態を見て調整します |
| 再生収穫期 | 葉を摘んだあとに水を与えます | 新しい葉が出てくるのに水分が必要です |
| 収穫直前 | やや控えます | 葉がしまって、しおれる速度が遅くなります |
| 韓国の梅雨（チャンマ、6月下旬～7月） | 排水溝を確保します | 菌核病と灰色かび病が過湿から始まります |

&nbsp;&nbsp;&nbsp;サンチュの水管理で覚えておきたいのは、乾燥と苦味の関係です。水が不足すると、サンチュは葉を厚くし、ラクチュカリウムの濃度を上げます。ストレスを受けた植物が防御物質を増やす一般的な反応で、人の口には苦味として現れます。サンチュが苦いなら、水が足りなかったか、暑かったか、とう立ちが始まったかのどれかです。

&nbsp;&nbsp;&nbsp;水やりの時間帯は、早朝が最適です。葉についた水気が日中に乾くからです。夕方に水を与えると、葉が一晩中濡れたままになり、その状態がカビの病気の条件となります。サンチュでは、べと病と灰色かび病が、葉が濡れている時間の長さにほぼ比例して発生します。

### 7-2. 水が不足するとき、多すぎるとき

| 状態 | 症状 | 結果 |
|:---|:---|:---|
| 不足 | 葉が昼にしおれ、夕方に回復します | 一時的。まだ回復できます |
| 不足 | 葉が小さく厚くなり、苦味が強まります | ラクチュカリウムが増えます |
| 不足 | 葉の縁が枯れ、とうが立ちます | 回復が困難です |
| 過多 | 下の葉が黄色くなります | 根の酸素不足 |
| 過多 | 株元に白いカビと黒い粒が見られます | 菌核病。その株は廃棄しなければなりません |
| 過多 | 葉が軟らかくなり、灰色のカビが生えます | 灰色かび病 |

&nbsp;&nbsp;&nbsp;株元に黒くて硬い粒が見えたら、菌核病です。この粒が菌核で、土壌に落ちると何年も生き延びて、次の作物に感染します。見つけたら、その株を周りの土ごとすくい取って畑の外へ運び、堆肥に入れずに焼却するか、遠くに埋めます。

### 7-3. マルチング

| 資材 | 効果 | 注意 |
|:---|:---|:---|
| わら | 水分の保持、雑草の抑制、雨水の跳ね返りの遮断 | 播種直後は薄くしか使いません |
| 枯れ草・落ち葉 | わらと同じ効果 | 種が混じった草は雑草を呼びます |
| もみ殻 | 軽くて長持ちします | 土に混ぜず、上に敷くだけにします |

&nbsp;&nbsp;&nbsp;サンチュでマルチングの最大の利点は、雨水の跳ね返りを防ぐことにあります。菌核病や灰色かび病の胞子は土壌にあり、雨粒が土を叩くときに跳ね上がって葉の裏面に付きます。地面と葉の間にわらの層が一つあれば、この経路は断たれます。サンチュは葉が地面の近くに付いて育つ作物なので、この問題が特に深刻で、そのためマルチングの効果が他の作物より大きいのです。

&nbsp;&nbsp;&nbsp;ただし、評価の根拠で指摘されているように、マルチングだけではべと病を防げません。べと病は空気中の胞子で広がるからです。マルチングは数ある手段の一つであり、通風、排水、品種の混植と併せて使って初めて意味があります。

## 8. 栽培管理

### 8-1. 間引き

| 回数 | 時期 | 残す間隔 |
|:---|:---|:---:|
| 1回目 | 本葉2-3枚 | 5cm |
| 2回目 | 本葉4-5枚 | 15-20cm（最終） |

&nbsp;&nbsp;&nbsp;間引きを適期に行わないと、サンチュは上にばかり伸びます。隣の株と光を取り合って葉柄を長く伸ばし、結果は細長い茎に小さな葉が数枚付いただけの姿になります。しかも密植された状態では葉が重なって風通しが悪くなり、その湿った空気がべと病や灰色かび病の条件となります。農薬が使えない状況では、株間を確保することは防除の手段でもあります。

> **間引いた若いサンチュは、捨てるものではなく最初の収穫です。播種から25日ごろの若い葉は柔らかく、苦味がほとんどないので、そのままサム（葉で包んで食べる韓国の料理）やサラダになります。**

&nbsp;&nbsp;&nbsp;間引くときは引き抜かず、はさみや爪で地面近くから切ります。サンチュの細根は浅く、互いに絡み合っているため、一株を引き抜くと隣の株も一緒に揺さぶられます。根が浮いた株は回復に数日を費やし、そのストレスがとう立ちを早めることもあります。

### 8-2. 雑草と土寄せ

&nbsp;&nbsp;&nbsp;サンチュには土寄せは必要ありません。土の中で収穫物が育つわけでもなく、生育期間が短いため、倒れるほど大きくなる前に収穫が終わります。むしろ株元に土が上がると、そこから菌核病が始まることがあるので、株元の周りは風通しがよくなるよう空けておくほうがよいです。

| 雑草管理 | 方法 | 時期 |
|:---|:---|:---|
| 手取り除草 | 株の間の草を抜きます | 間引きと同時に |
| マルチング | わらや枯れ草で覆います | 本葉3-4枚以降 |
| 浅い草取り | ホミ（韓国の小型の手鍬）を浅く入れて、表面だけを削ります | 雑草が小さいうちに |

&nbsp;&nbsp;&nbsp;草取りをするときは、ホミを深く入れないように気をつけます。サンチュの細根は大部分が地表から5-10cm以内にあり、この根が切れると株がしおれて回復が遅れます。株から遠い側から浅く削り、株のすぐ脇の草は手で抜きます。

### 8-3. とう立ちを遅らせる管理

| 要因 | とう立ちへの影響 | 対策 |
|:---|:---|:---|
| 高温 | 最も強いシグナル | 遮光、マルチング、灌水で地温を下げます |
| 長日 | 日が長くなると促進されます | 春栽培では収穫を急ぎます |
| 乾燥ストレス | 急いで種を残そうとします | 水を均等に与えます |
| 根の損傷 | ストレスとして働きます | 間引きと草取りを慎重に行います |
| 密植 | 競争ストレス | 適期に間引きます |
| 窒素不足 | 生殖生長への切り替えが早まります | 元肥を十分に施します |

&nbsp;&nbsp;&nbsp;とう立ちが始まると、元には戻せません。真ん中から茎が立ち上がり、葉が上向きに立ち始めたら、その株の収穫は終わったと考えるのが正しいです。花茎を切り取っても、脇からまた上がってきて、その間に葉はどんどん苦くなっていきます。

&nbsp;&nbsp;&nbsp;とう立ちしたサンチュをすべて捨てる必要はありません。まだ若い花茎とその上の葉は、湯がいて水にさらすと、苦味がかなり抜けます。沸騰した湯でゆで、冷水に浸しておいてから水気を絞れば、ナムル（味付けした野菜の和え物）として食べられます。そして、数株はそのまま残して種を採ります。13節で扱います。

&nbsp;&nbsp;&nbsp;夏を越さなければならない状況での実質的な対策は、遮光と配置です。背の高い作物の北側の日陰、建物の陰、木の下にサンチュを置けば、地温が数度下がり、その分とう立ちが遅れます。トウモロコシやヒマワリの間にサンチュを植えるという昔ながらの配置は、この原理の上に成り立っています。
