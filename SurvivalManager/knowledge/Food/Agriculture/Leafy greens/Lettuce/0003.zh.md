## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

| 项目 | 内容 |
|:---|:---|
| 学名 | Lactuca sativa |
| 分类 | Magnoliophyta Magnoliopsida / Asterales / Asteraceae / Lactuca |
| 生活型 | 一年生 |
| 原产地 | 从地中海沿岸到西亚的地区 |
| 野生祖先 | 野莴苣（Lactuca serriola） |
| 同科植物 | 蒲公英、艾草、向日葵、牛蒡、菊苣 |

&nbsp;&nbsp;&nbsp;生菜属于菊科，这一事实在实际操作中有三层含义。第一，它与十字花科作物不共有病虫害。菜粉蝶、跳甲和根肿病都不会侵扰生菜。在十字花科作物集中的田里，生菜起到安全区的作用。第二，相应地，它有菊科特有的病害，即菌核病和霜霉病，这些病害也会传给菊苣、茼蒿和牛蒡。第三，切断茎会流出白色乳汁。这与折断蒲公英时流出的白色汁液是同一类东西，是菊科植物的共同特征。

&nbsp;&nbsp;&nbsp;学名中的Lactuca来自拉丁语中意为“乳汁”的Lac，指的就是这种白色乳汁。乳汁的主要成分是莴苣素（lactucin）和莴苣苦素（lactucopicrin）这两种苦味物质，二者合称莴苣鸦片（lactucarium）。其本来的目的是驱赶食草动物。这正是生菜比其他叶菜受虫害更轻的原因，同时也是抽薹之后就不能吃的原因。第14节将详细介绍这一成分。

### 2-2. 形态

| 器官 | 特征 |
|:---|:---|
| 叶 | 因品种而异，有圆叶、皱叶和长条形叶。有绿色、红色和复色 |
| 茎 | 平时极短，叶片看起来像簇生在一起。抽薹后笔直向上生长 |
| 根 | 主根向下生长，须根则浅浅地铺展开 |
| 花 | 黄色。是菊科特有的由许多小花聚集而成的头状花序 |
| 果实 | 瘦果。褐色或黑色，顶端带有冠毛 |
| 乳汁 | 切断茎和叶脉会流出白色汁液 |

&nbsp;&nbsp;&nbsp;生菜的茎平时几乎看不见，这是再生收获的基础。茎被极度压缩得很短，生长点位于其顶端，叶片呈放射状轮生并相互重叠。越靠外侧的叶片越是先长出的老叶，越靠内侧越是新叶。因此，从外侧开始摘取，植株只失去老叶，生长点原样保留，不断向上抽出新叶。反过来，如果把中间切掉，这棵植株就完了。

&nbsp;&nbsp;&nbsp;生菜种子顶端的冠毛，与蒲公英种子的冠毛结构相同。这是借风传播的装置，留种时这些冠毛反而成了麻烦。种子成熟后很容易被风吹走，错过时机就没有东西可收了。同时，多亏冠毛，用簸箕簸扬来分选秕粒也相对容易。

### 2-3. 生育阶段

| 阶段 | 时期（以播种为基准） | 核心生理 | 主要消耗的养分 |
|:---|:---|:---|:---|
| 发芽·幼苗期 | 播种-7天 | 种子确认光照与温度后萌发 | 磷、氮 |
| 营养生长期 | 7-30天 | 叶片迅速增多，形成株丛 | 氮 |
| 最佳收获期 | 30-60天 | 外层叶片先长足 | 氮钾均衡 |
| 再生收获期 | 40-110天 | 摘去外层叶片后，内侧长出新叶 | 氮 |
| 抽薹·开花期 | 60-100天 | 茎秆抽起，叶片变苦 | 磷、钾 |
| 结实期 | 开花后2-3周 | 带冠毛的种子成熟 | 磷、钾 |

&nbsp;&nbsp;&nbsp;这张表中决定性的转折点是抽薹。在此之前，生菜把全部资源都用来长叶；抽薹一旦开始，就转向抽茎和开花。此时叶片中留存的养分转移到茎和花上，同时莴苣鸦片的浓度急剧上升。叶片变老变韧，苦味增强，无法再食用。

> **抽薹不是病，而是生菜正常的生命历程。人们食用的生菜只是它生命的前半段，栽培技术的一半就在于能把这一转折点推迟多久。**

&nbsp;&nbsp;&nbsp;诱发抽薹的条件有三个。第一是高温。气温超过25度的日子持续出现时，生菜就会转入生殖生长。第二是长日照。日照变长，同样的信号会增强。第三是胁迫。缺水、根系受伤或因密植而竞争激烈时，植物会急于留下种子。三个条件叠加的正是盛夏，所以夏季种生菜行不通。

### 2-4. 每100g的营养

| 成分 | 含量 | 备注 |
|:---|:---:|:---|
| 热量 | 20kcal | 因品种而异，为13-20kcal |
| 水分 | 约95% | 耐储性差的根本原因 |
| 蛋白质 | 1.88g | 占热量的比例37.6% |
| 糖类 | 1.22g | |
| 维生素A（β-胡萝卜素换算） | 354-717 μg | 品种间差异很大 |
| 叶酸 | 49 μg | |
| 维生素K | 含有 | 参与血液凝固和骨代谢 |
| 钾 | 含有 | |

&nbsp;&nbsp;&nbsp;维生素A含量因品种不同相差一倍，这一点在实用上很重要。叶色越深，β-胡萝卜素越多。深绿色叶片比浅绿色叶片多，外侧叶片比内侧的浅色叶片多。像结球生菜那样内部包成白色的品种，其白色部分几乎不含β-胡萝卜素。在灾害情境下，如果以营养为目的种植生菜，选择叶色浓、叶片张开的类型更有利。

&nbsp;&nbsp;&nbsp;红叶生菜的红色来自花青素。它起抗氧化物质的作用，在低温和强光下颜色更深。这就是同一块地里秋季种出的红叶生菜比春季种出的颜色更深的原因。把绿叶生菜和红叶生菜混种，同样面积上获得的成分种类更为丰富。

&nbsp;&nbsp;&nbsp;生菜的镇静作用早已为人所知。有报告称莴苣鸦片具有轻微的镇静效果，吃生菜会犯困的经验之谈即由此而来。不过，我们平时吃的嫩生菜中莴苣鸦片的浓度很低，达不到可期待实际药理效果的水平。浓度高的是抽薹后生菜茎中流出的乳汁。

## 3. 栽培环境

### 3-1. 温度

| 类别 | 温度 | 说明 |
|:---|:---:|:---|
| 发芽适温 | 15-20℃ | 3-5天即可出芽 |
| 发芽极限 | 25℃以上 | 发芽率急剧下降 |
| 生育适温 | 15-20℃ | 叶片柔嫩，产量高 |
| 可生育范围 | 15-22℃ | 幅度仅10℃，十分狭窄 |
| 诱发抽薹 | 持续25度以上时 | 抽薹并产生苦味 |
| 低温极限 | 能耐轻霜 | 气温深入零下，叶片会冻伤变软烂 |

&nbsp;&nbsp;&nbsp;生菜的温度条件中，最特别的是发芽方面。大多数作物温度越高发芽越快，而生菜恰恰相反，超过一定温度就会停止发芽。这种现象称为高温休眠。

&nbsp;&nbsp;&nbsp;这不是故障，而是设计。站在生长于地中海气候中的野生莴苣的立场上去想，就能理解了。那里夏季炎热干燥，雨水从秋季一直下到春季。夏天萌发的种子，显然会干死。因此生菜种子在土壤温暖时不会发芽，而是等待。等到气温下降、开始下雨，才会发芽。这套判断机制被原样保留了下来，所以盛夏播下生菜，种子就会在土里沉睡不醒。

| 对策 | 方法 | 原理 |
|:---|:---|:---|
| 种子引发 | 把种子在水中浸泡几个小时后，放在阴凉处放置一天，再播种 | 种子经历低温，休眠得以解除 |
| 傍晚播种 | 日落后播种，并浇足水 | 利用夜间地温下降的时机 |
| 遮光 | 在播种处用竹帘或树枝遮出阴凉 | 使地温降低几度 |
| 湿布预先催芽 | 在阴凉处催芽后，再移出播种 | 把发芽阶段放在田外完成 |
| 调整时间 | 放弃夏季播种，等到秋季 | 最为可靠 |

> **夏季播种生菜失败，不是因为土壤不好或缺水，而是因为种子因高温而沉睡。弄清原因，对策就会不同。**

### 3-2. 光照

| 项目 | 标准 | 备注 |
|:---|:---|:---|
| 日照需求 | 每天6-8小时 | |
| 耐半阴性 | 良好 | 40%遮光时叶菜类相对产量86% |
| 种子发芽 | 需光发芽 | 必须见光才能发芽 |
| 夏季 | 反而遮光更有利 | 降低地温，推迟抽薹 |

&nbsp;&nbsp;&nbsp;生菜种子需光发芽，这是播种中最容易出错的地方。种子要见光才会开始发芽，所以覆土太厚就会一直沉睡。播种深度2-3mm，刚好把种子盖住即可。与萝卜要埋1-2cm相比，完全不是一个量级。

&nbsp;&nbsp;&nbsp;需光发芽和高温休眠，是同一套判断机制的两个侧面。种子处在光线能照到的浅处、土壤凉爽时才会发芽；埋得太深或天气太热时就等待。相当于一个必须两个条件都满足才能发芽的双重锁。

&nbsp;&nbsp;&nbsp;耐半阴性好这一点，可以用在灾害情境下的田块布局上。把生菜安排在建筑物的阴影里、树下、不是整天都有阳光照射的地方，把阳光充足的位置让给萝卜或马铃薯。临近夏季的时候，阴凉反而能延长生菜的寿命。在韩国，把生菜种在玉米或向日葵等高秆作物的北侧，这种布局就是由此而来的。

### 3-3. 水分与土壤

| 项目 | 标准 | 备注 |
|:---|:---|:---|
| 总蒸散量 | 约350mm | 在叶菜中偏少 |
| 灌溉间隔 | 春秋两季3-5天，夏季2-3天 | 根据土壤状况调整 |
| 土壤酸碱度 | pH 6.0-6.6 | pH 5以下或8以上时生长变差 |
| 土壤 | 有机质丰富、排水良好的土地 | 对土壤的适应性较广 |
| 垄高 | 15-20cm | 保证排水 |
| 根系深度 | 浅浅地铺展 | 表土一干就会立刻受到影响 |

&nbsp;&nbsp;&nbsp;生菜对土壤不太挑剔。只要是透气、能保持水分的土壤，一般都能生长。在灾害情境下，这一特性价值很大。在不是田地的地方，比如庭院、花坛或破花盆里，生菜也能生长。不过，由于根系浅浅铺展，它对表土的状态很敏感。土壤变干时，叶片变老变韧，苦味增强，这种状态持续下去，抽薹会提前。

&nbsp;&nbsp;&nbsp;水分管理的原则是均匀。生菜的叶片是含水量95%的组织，水分供应会直接反映在叶片状态上。干旱时间一长，叶片就会变小、变厚、变苦。反过来，积水会让根系得不到氧气，在茎基部引发软腐病和菌核病。起垄并用稻草或干草覆盖，是同时应对这两个问题的办法。

&nbsp;&nbsp;&nbsp;覆盖对生菜的效果尤其显著。一是因为根系浅，对地温变化敏感；二是因为它能防止雨滴溅起泥土沾到叶片背面。菌核病和灰霉病的孢子存在于土壤中，被雨水溅起后附着到叶片上。在地面和叶片之间铺一层稻草，就能切断这条途径。

## 4. 品种

### 4-1. 各类型的特点

| 类型 | 特点 | 在灾害情境下的适用性 |
|:---|:---|:---|
| 散叶生菜（裙叶生菜） | 不结球，叶片张开 | 可再生收获，最为有利 |
| 结球生菜 | 内部包得紧实。需要30cm以上的间距 | 仅可收获1次。另有专门文档介绍 |
| 罗马生菜 | 直立型，叶片细长 | 半结球。可在一定程度上再生收获 |
| 奶油生菜 | 柔软地半结球 | 叶片嫩，耐储性更差 |

| 品种 | 特点 | 适宜环境 |
|:---|:---|:---|
| Cheongchima | 绿色叶片。使用最广泛的类型 | 春季、秋季 |
| Jeokchima | 红色叶片。花青素含量高 | 春季、秋季 |
| Cheongchukmyeon·Jeokchukmyeon | 叶片宽大，皱褶多 | 春季、秋季 |
| Jangsu | 在光线较弱的条件下也能生长 | 半阴处、室内 |
| Tomalin | 叶片厚、纤维多，不易萎蔫 | 需要贮藏和运输时 |

&nbsp;&nbsp;&nbsp;在灾害情境下，处于中心位置的是散叶生菜类型，原因就是再生收获。结球生菜是整颗收走包紧的叶球、只能收获1次的作物，拔掉就结束了；而散叶生菜只摘外层叶片，可以持续两到三个月。同样面积上总收获量更多，而且收获分散，没有贮藏负担。

&nbsp;&nbsp;&nbsp;像Tomalin类型那样叶片厚、纤维多的品种，口感稍逊，但耐储性更好。它是能把耐储性E这一等级稍微往上提一点的选择。如果田地离家很远，或者无法每天下地，就值得考虑。

&nbsp;&nbsp;&nbsp;像Jangsu类型那样在阴处也能生长的品种，在非田地的地方种植时才真正物有所值。在楼房之间、墙根下、室内窗边这类光照不足的位置，也能有一定的产量。如果是在城市里遭遇灾害，这一特性可能起决定性作用。

### 4-2. 按情境选择的标准

| 情境 | 选择 | 理由 |
|:---|:---|:---|
| 灾害初期，最短时间收获 | Cheongchima、Jeokchima | 25-30天即可收获嫩叶 |
| 长期采摘食用 | 各类散叶生菜 | 再生收获可持续2-3个月 |
| 光照不足的位置 | Jangsu等耐阴类型 | 在半阴处也能生长 |
| 需要放几天再吃时 | Tomalin等叶片厚的类型 | 不易萎蔫 |
| 想拓宽营养种类时 | Jeokchima | 增加花青素 |
| 优先种子自立 | 固定品种、地方品种 | 自花授粉，留种后性状得以保持 |
| 分散风险 | 混种两三个品种 | 抽薹时间和抗病性各不相同，可降低全军覆没的风险 |

&nbsp;&nbsp;&nbsp;把多个品种混种，对防治霜霉病很有用。评价依据中提到的有机生菜实证文献里，也试验过品种混植。各品种对病害的抗性不同，所以只种一个品种的话，一旦遇上该品种易感的病原菌类型，整块田就会垮掉。混种的话，即使其中一个中招，其余的还能保住。

> **生菜是自花授粉作物，把多个品种并排种植，种子也不会混杂。十字花科作物在混种与留种之间难以兼顾，而生菜可以同时做到这两点。**
