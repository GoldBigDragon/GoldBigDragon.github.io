## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;评价表中耐储性为E、无电力常温下2-3天，是本文档所涉及的全部作物中最低的数值。本节并不是要介绍如何推翻这一事实的方法。生菜是不能贮藏的。准确区分哪些做得到、哪些做不到，才是本节的目的。

&nbsp;&nbsp;&nbsp;三个因素叠加，才造成这样的结果。第一，含水量超过95%，叶片薄而宽，相对体积的表面积大，水分蒸发很快。第二，支撑组织的主要是细胞内的水压，所以只要失去一点水分就会马上萎蔫。它不像大白菜那样有粗厚的叶脉来保持形态。第三，切口会流出乳汁，切口处褐变，成为腐烂的起点。因此，让生菜撑过几天的技术，归根结底只有两条：不让它失水，以及降低温度、减缓呼吸。

| 方法 | 步骤 | 期限 | 局限 |
|:---|:---|:---:|:---|
| 茎基水插 | 把茎基切去1cm，立在盛有浅水的容器中 | 3-5天 | 需要每天换水，且占地方 |
| 湿布包裹 | 不洗，直接用湿布包好，放在凉爽处 | 3-4天 | 布干了就失效 |
| 埋入湿稻草 | 在湿稻草之间一层层平放 | 3-5天 | 稻草脏了会长霉 |
| 土窖·地窖 | 与湿布一起放在凉爽的地下空间 | 5-7天 | 必须有地窖 |
| 坛子密封 | 放入铺了湿布的坛子，置于阴凉处 | 3-5天 | 不透气会变软烂 |

&nbsp;&nbsp;&nbsp;水插的原理很简单：切断的导管持续向上吸水，维持叶片的膨压。不过，浸在水里的切面会滋生细菌堵塞导管，所以每天换水，每次换水时再把茎基切去几mm，能保持更久。不洗就保存，这一原则也很重要。一洗，叶片表面会形成水膜，腐败菌便在水膜下迅速繁殖。叶片表面的角质层和蜡质是生菜自身的防护膜，洗的过程中有时会被擦掉一部分。

&nbsp;&nbsp;&nbsp;土窖或地窖的温度，在地下1.5-2m处全年保持在10-15℃之间。即使在夏天，也比外面低10℃以上。仅此一点，呼吸速率就明显下降，两天的保鲜期延长到五天。不过窖内湿度高，容易长霉，所以不要完全堵死通风，还要避免混入烂叶。一片烂叶释放的乙烯会让旁边完好的叶片衰老。

| 加工贮藏 | 步骤 | 期限 | 评价 |
|:---|:---|:---:|:---|
| 焯后晒干 | 在沸水中焯20-30秒，放在阴凉处晾干 | 6个月-1年 | 可行，但体积极度缩小，口感崩坏 |
| 直接晒干 | 不洗，铺开晾干 | 几个月 | 会褐变并碎裂 |
| 水泡菜（mulgimchi，汤汁多的泡菜） | 浸入2-3%的盐水中发酵 | 1-2周 | 只能在凉爽处进行。叶片会变软烂 |
| 咸菜（jjanji）式腌制 | 盐10%以上 | 几个月 | 形态完全崩坏，只能用来煮汤 |

&nbsp;&nbsp;&nbsp;焯后晒干在物理上可行，但成品并不令人满意。95%是水，所以晒干1kg只剩不到50g，而且组织薄，一碰就碎。泡发后也恢复不了原来的口感。把它看作夏天抽薹开始、必须一次性处理时为了不浪费生菜而采取的最后手段，才比较恰当。

&nbsp;&nbsp;&nbsp;盐腌的局限来自结构。大白菜和萝卜腌过之后细胞壁仍能保持形态，而生菜一腌就立刻蔫软，变得软塌塌的。做成泡菜也留不下脆爽感，几天就腌过头变软了。这就是生菜水泡菜只能作为腌好几天内就吃掉的食物而存在的原因。

> **解决生菜贮藏问题的办法，不在贮藏技术，而在播种计划。每隔十天到半个月分批播种，只摘外叶食用，就根本不会出现需要贮藏的情况。长在田里的生菜，就是最好的贮藏库。**

## 16. 烹饪与加工

&nbsp;&nbsp;&nbsp;评价表中烹饪·加工的等级为SS，依据是“洗净后生食”五个字。在灾难情况下，有必要准确掂量一下这五个字的分量。

| 作物 | 食用前所需处理 | 燃料 |
|:---|:---|:---:|
| 生菜 | 清洗 | 无 |
| 大豆 | 浸泡8小时，煮1小时以上 | 多 |
| 马铃薯 | 煮或烤20-30分钟 | 中等 |
| 大米 | 煮饭30分钟 | 中等 |
| 莙荙菜 | 焯水5分钟 | 少 |

&nbsp;&nbsp;&nbsp;在电力和燃气中断的情况下，烹饪燃料是木柴或木炭，而这些东西需要人去砍伐、晾干、劈开。一日三餐烧煮所需的木材量比想象中多，在城市近郊，几个月周边的干柴就会用光。在这种条件下，田里有一种完全不用火就能吃的蔬菜，这是热量表上体现不出来的一类优势。

&nbsp;&nbsp;&nbsp;营养方面的优势也叠加在这里。维生素C、叶酸和部分B族维生素怕热且易溶于水，焯水的一瞬间就会大量流失，溶进汤水里。生菜没有这种损失。微量营养素为S、21种中满足16种的评价，几乎原样转化为实际摄入量，这样的作物为数不多。

| 方式 | 要领 | 备注 |
|:---|:---|:---|
| 叶包饭（ssam） | 用整片叶子包着米饭和小菜吃 | 打破以谷物为主的饮食单调感的最简单办法 |
| 浅腌拌菜（geotjeori） | 切成粗块，用盐稍腌一下，再用调料拌匀 | 蔫软后体积缩小，能吃得更多 |
| 沙拉 | 拌入油或紫苏籽粉 | 提高脂溶性维生素的吸收 |
| 水泡菜 | 浸入2-3%的盐水中放一两天 | 乳酸发酵使维生素C保留相当一部分 |
| 焯水 | 在沸水中焯20-30秒 | 苦味溶于水中，质地变软 |

&nbsp;&nbsp;&nbsp;geotjeori在灾难情况下尤其实用。生叶体积大，一次能吃的量有限，但用盐稍微腌一下就会蔫软，同样的量吃起来要轻松得多。生菜最大的弱点是热量密度，因此这种增加实际摄入量的简单处理，会在营养供给上带来差别。如果盐很珍贵，就用极少的盐稍腌片刻，腌出的水用来煮汤。哪怕拌一点油也有好处。维生素A、维生素E和维生素K是脂溶性的，不加油吃，吸收率会大大下降，把紫苏籽或芝麻磨碎撒上，也能起到同样的效果。

&nbsp;&nbsp;&nbsp;也有煮熟了吃的办法。把生菜煮熟虽然让人感觉陌生，但在抽薹开始、叶片变老、泛出苦味的时期，这反而更好。在沸水中焯20秒到30秒，相当多的苦味成分会溶入水中，质地也变软。放在煮汤的火上，最后下锅，就不必另外耗费燃料。

### 16-1. 生菜薹的利用

&nbsp;&nbsp;&nbsp;把已经抽出花茎的生菜直接拔掉丢弃，实在可惜。抽薹生菜的茎，也就是生菜薹，本身就可以食用。在中国，人们专门栽培以食茎为目的的品种；在韩国，也从很早以前就把生菜茎做成凉拌野菜（namul）或酱菜（jangajji）。

| 部位 | 处理 | 口味与用途 |
|:---|:---|:---|
| 粗茎 | 去皮，斜切，浸入盐水去除苦味后炒或拌 | 脆爽清淡 |
| 茎皮 | 坚韧且乳汁集中，要剥掉 | 还入堆肥 |
| 花蕾 | 取尚未开放的，焯水后拌 | 略带苦味 |
| 茎酱菜 | 切开用盐腌过后，放入大酱（doenjang）或酱油中腌制 | 可保存几个月 |

&nbsp;&nbsp;&nbsp;关键是一定要去皮。外皮集中了最多的莴苣乳，纤维也坚韧。剥掉之后，里面的茎肉反而苦味少且脆爽。切好后放进盐水或淘米水里浸泡30分钟左右，残留的苦味会进一步去除。做成酱菜可以保存几个月。这等于说，叶子绝对做不到的贮藏形式，用茎却可以做到。留种株上长出的侧枝茎也可以用同样的方法处理，所以把留种和收茎结合起来，就能降低留种株占地四个月的机会成本。

## 17. 全年作业日程

| 月 | 春季栽培 | 秋季栽培 |
|:---:|:---|:---|
| 1月 | 检查种子、管理堆肥、制定轮作计划 | 田地空着 |
| 2月 | 确认发芽率、翻堆肥、准备基肥 | |
| 3月 | 下旬播种。施基肥、起垄 | |
| 4月 | 间苗与定植。收获嫩叶。监测蛞蝓 | |
| 5月 | 正式收获，每隔10-14天再生收获。追肥 | |
| 6月 | 开始抽薹。标记留种株后清理其余植株 | |
| 7月 | 留种株开花结实。空出的地方种夏季作物 | |
| 8月 | 上旬收获种子并精选 | 上旬起播种。应对高温休眠 |
| 9月 | | 间苗与定植，第2次播种。监测霜霉病 |
| 10月 | | 正式收获。再生收获最长的月份 |
| 11月 | | 继续收获。盖稻草并设挡风障。下旬清理 |
| 12月 | | 整理田地并处理残体。病株运出田外 |

&nbsp;&nbsp;&nbsp;按韩国气候编制的这张表，纵向读下来，生菜的特性就显现出来了。春季栽培收获期短，以抽薹收尾。5月收得正好，6月气温升高，就仓促结束。但只有春季栽培才能留下种子，因为从播种到留种需要四个月，而能保证这段时间的只有春季。

&nbsp;&nbsp;&nbsp;秋季栽培则相反。生长全程气温不断下降，没有抽薹的压力，直到下霜，再生收获可以持续两个多月。叶片也厚实，甜味增加。只是收不到种子。

| 类别 | 春季栽培 | 秋季栽培 |
|:---|:---|:---|
| 收获期 | 4-6周 | 8-10周 |
| 结束原因 | 抽薹 | 霜冻 |
| 叶片品质 | 越到后期越苦 | 始终柔嫩，并带甜味 |
| 病害压力 | 起初较低，后期上升 | 霜霉病压力大 |
| 留种 | 可行 | 困难 |
| 发芽条件 | 无大碍 | 需要应对高温休眠 |

&nbsp;&nbsp;&nbsp;所以实际的安排是这样：春季种是为了保住种子，秋季种是为了吃。两个茬口之间夏季的两个月和冬季的三个月，是没有生菜的时期，这段空白由其他作物来填补。夏季由马齿苋和蕹菜（空心菜）这类耐高温的叶菜顶上，冬季则由羽衣甘蓝和芥菜这类耐寒的作物顶上。

> **一年十二个月中，生菜能上餐桌的月份只有四个月出头。知道这一点，并规划好其余八个月用什么来填补，在灾难情况下比把生菜种好的技术更重要。**

&nbsp;&nbsp;&nbsp;最后，再强调一遍分期播种的原则。生菜不能贮藏，一次全部播下，必然会有浪费掉的部分。每隔十天到半个月，分三到四次播种，收获也能相应地持续，即使某一茬因病失败，下一批播种的还在。对于不能贮藏的作物，错开播期不是图方便，而是分散风险。
