## 5. 整地与施肥

### 5-1. 田块整备

| 项目 | 方法 |
|:---|:---|
| 耕翻 | 耕深20-30cm，把土块打碎，整平耙细 |
| 垄 | 高15-20cm。同时开挖排水沟 |
| 土壤酸碱度 | 调整到pH 6.0-6.6 |
| 有机质 | 在播种前1-2周施入腐熟堆肥并混匀 |
| 表面整理 | 种子非常小，所以要把表面整平耙细 |

&nbsp;&nbsp;&nbsp;生菜整地与其他作物不同的地方在于表面的平整。生菜种子长约3mm，非常小，播种深度也不过2-3mm。土块一大，种子就会掉进缝隙里被深埋，而它又是需光发芽的种子，就不会出苗。哪怕只是播种的位置，也要把土像过筛一样打碎整平，这直接决定发芽率。

&nbsp;&nbsp;&nbsp;深耕本身对生菜并非必需，因为它是根系浅浅铺展的作物。评价表中的整地·挖掘能耗按深耕10cm为基准来计算，原因也在于此。在需要节省劳动力的情况下，只要把表土10cm打碎整好，生菜就能生长。不过，如果是排水不良的田，起垄这道工序就不能省。

### 5-2. 施肥量

| 肥料 | 每1,000㎡ | 折合每㎡ | 施用时期 |
|:---|:---:|:---:|:---|
| 氮（N） | 10-12kg | 10-12g | 全部作基肥 |
| 磷（P） | 6-8kg | 6-8g | 全部作基肥 |
| 钾（K） | 6-8kg | 6-8g | 全部作基肥 |
| 堆肥 | 1,000-1,500kg | 1-1.5kg | 播种前1-2周 |
| 石灰 | 100-150kg | 100-150g | 用于改良酸性土壤 |

| 类别 | 时期 | 内容 |
|:---|:---|:---|
| 基肥 | 播种前1-2周 | 堆肥和肥料全量 |
| 追肥 | 原则上省略 | 仅在贫瘠田或再生收获时间较长时少量施用 |

&nbsp;&nbsp;&nbsp;生菜生育期短，根系不深扎，所以肥料以基肥的形式足量施入，几乎不追肥。评价表中施肥需求项目为B，氮、磷、钾合计约22g，就是这个数值。

> **给生菜追肥，反而会让口味变差。氮浓度一高，叶片就会变得松软，苦味增强，抗病性变弱。除非是贫瘠的土地，只靠基肥就足够了。**

&nbsp;&nbsp;&nbsp;不过，长期持续再生收获的情况是例外。连续摘叶超过两个月，田里的养分确实会被带走。这时每2-3周追一次稀薄的肥，但要在刚摘完叶后施用，收获前几天不要施。因为施氮后马上采摘的叶片，可能残留硝酸盐。

### 5-3. 灾害情境下的替代肥料

| 替代资源 | 提供的营养素 | 使用方法 | 注意事项 |
|:---|:---|:---|:---|
| 腐熟堆肥 | 氮·磷·钾及各种微量元素 | 每㎡施入1-1.5kg作基肥 | 未腐熟的会伤害幼根 |
| 草木灰 | 钾、磷、钙 | 每㎡撒一把，与土混匀 | 呈碱性，要控制在pH 6.6以下 |
| 稀释尿液 | 氮 | 用水稀释15到20倍 | 生菜对氮敏感，比其他作物稀释得更淡 |
| 骨粉 | 磷、钙 | 拌入堆肥作基肥施用 | 分解慢，必须提前施入 |
| 蛋壳粉 | 钙 | 研成细粉混入田中 | 用于预防叶尖干枯症状 |
| 落叶·草类腐殖土 | 有机质 | 施入田中或用作覆盖 | 要使用完全腐熟的 |

&nbsp;&nbsp;&nbsp;给生菜用稀释尿液时，要比其他作物稀释得更淡。对大多数叶菜推荐稀释10-15倍，而生菜以15到20倍为宜。因为氮过多会使叶片变软、苦味增强，还会招来蚜虫。此外，生菜是生吃的蔬菜，更要注意硝酸盐的积累。

&nbsp;&nbsp;&nbsp;草木灰能提供钾和钙，但碱性很强。生菜要求的pH 6.0-6.6比十字花科作物偏低，所以如果像对萝卜那样大量施用草木灰，pH会升得过高。应当少量施用并观察状况。

## 6. 播种 - 受光与温度左右的种子

### 6-1. 栽培茬口

| 栽培茬口（韩国） | 播种时期 | 收获时期 | 备注 |
|:---|:---|:---|:---|
| 春季栽培 | 3月下旬-5月中旬 | 4月下旬-6月下旬 | 最为常见 |
| 秋季栽培 | 8月上旬-9月上旬 | 9月上旬-11月上旬 | 在灾害情境下最为有利 |
| 夏季栽培 | 不推荐 | | 发芽失败和过早抽薹 |
| 冬季栽培 | 仅限韩国南部有保温条件时 | | 生长极其缓慢 |

&nbsp;&nbsp;&nbsp;秋季栽培在灾害情境下有利，原因有三。第一，整个生长期气温都在下降，没有抽薹压力。春季栽培则相反，气温不断升高，到某个时点必然抽薹。第二，在凉爽条件下长大的生菜，叶片厚，甜味提升。第三，再生收获的时间变长。春季生菜一个多月就结束的话，秋季生菜能持续两个多月。

&nbsp;&nbsp;&nbsp;不过，秋季播种有个陷阱。在韩国，8月上旬仍然炎热，而这种炎热恰恰会引发高温休眠。播种时的地温超过25度，种子就会沉睡。因此秋播的真正技术，在于如何避开炎热让种子发芽。

### 6-2. 克服高温休眠的方法

| 方法 | 步骤 | 原理 |
|:---|:---|:---|
| 低温引发 | 把种子在水中浸泡4-6小时后，用湿布包好，放在阴凉处一天 | 吸足水的种子经历低温，休眠得以解除 |
| 预先催芽 | 在湿布之间让种子微微萌芽后，小心地移出播种 | 把发芽阶段放在田外完成 |
| 傍晚播种 | 日落后播种，并浇足水 | 利用夜间地温下降的时机 |
| 遮光 | 用竹帘、树枝、稻草在播种处遮出阴凉 | 使地温降低几度 |
| 用水降温 | 播种后立即以及白天期间洒冷水 | 利用蒸发吸热降低地温 |

&nbsp;&nbsp;&nbsp;低温引发最可靠，也最省事。种子吸水后经历低温，抑制发芽的激素信号就会解除，此后即使播进炎热的土壤也能出苗。没有冰箱也没关系，井水旁、地下室、朝北的阴处这类凉爽的位置就行。不过，吸过水的种子一旦变干就会死亡，所以处理后要立即播种，并保持土壤不干。

&nbsp;&nbsp;&nbsp;遮光只遮住播种的位置也有效果。种子需光发芽，所以不能完全遮黑，要把竹帘或树枝稀疏地搭上去，形成淡淡的阴影。出苗后要立即撤去。

### 6-3. 播种方法

| 项目 | 标准 | 备注 |
|:---|:---|:---|
| 播种深度 | 2-3mm | 需光发芽。埋得深就不会发芽 |
| 覆土 | 只用细土刚好盖住种子即可 | 有时完全不覆土，只是压实 |
| 行距 | 20cm | |
| 播种方法 | 条播或穴播 | 如果以收获嫩叶为目的，也可以撒播 |
| 播种量 | 播得密一些，之后再间苗 | 发芽率可能偏低，所以要留有余量 |
| 镇压 | 用手或木板轻轻压实 | 种子与土壤紧密接触才能吸水 |

&nbsp;&nbsp;&nbsp;也有完全不覆土、播后只轻轻压实的做法。对需光发芽的种子，这样也许更好，但代价是种子有干掉或被雨水冲走的风险。折中的办法就是覆土2-3mm。再在上面撒一层极薄的干草，既能减少蒸发，又能透光。

&nbsp;&nbsp;&nbsp;不要一次全部播完，这是生菜栽培的基本技术。它是无法贮藏的作物，收获一旦集中，就只能丢弃。每隔10到15天分批播种，收获也就相应地持续下去。以韩国的秋播为例，可以分成8月上旬、8月中旬、9月上旬三次。

### 6-4. 种子处理与保存

| 处理 | 步骤 | 效果 |
|:---|:---|:---|
| 筛选 | 挑选饱满、颜色均匀的种子 | 发芽率提高 |
| 温汤浸种 | 在50-55℃的水中浸10-15分钟后，用冷水冷却 | 杀死种传病原菌 |
| 低温保存 | 密封后放在0-4℃的阴凉处 | 种子寿命延长 |
| 干燥剂 | 同时放入炒过并放凉的大米或木炭 | 防潮 |

&nbsp;&nbsp;&nbsp;生菜种子在常温密封条件下的寿命只有2-3年，偏短。这是因为菊科种子种皮薄且含有脂肪，氧化较快。如果凉爽保存，寿命会明显延长。在没有冰箱的情况下，可以找地窖、土洞、朝北的地下空间、井边这类全年凉爽的位置。不过，有湿气的话种子反而死得更快，所以密封和干燥剂必须配合使用。

## 7. 水分管理

### 7-1. 各生育阶段的水分

| 时期 | 管理 | 备注 |
|:---|:---|:---|
| 播种-发芽 | 少量多次浇水，不让表土变干 | 种子位置浅，容易干 |
| 幼苗期 | 少量多次 | 根系浅 |
| 生育期 | 春秋两季每隔3-5天，夏季每隔2-3天 | 根据土壤状况调整 |
| 再生收获期 | 摘叶后浇水 | 新叶生长需要水分 |
| 收获前夕 | 适当减少 | 叶片变得结实，萎蔫速度变慢 |
| 韩国的梅雨季（6月下旬至7月） | 确保排水沟畅通 | 菌核病和灰霉病由过湿引发 |

&nbsp;&nbsp;&nbsp;生菜水分管理中要记住的是干旱与苦味的关系。缺水时，生菜会让叶片变厚，并提高莴苣鸦片的浓度。这是受到胁迫的植物增加防御物质的普遍反应，对人的口感来说就表现为苦味。生菜发苦，说明要么缺水，要么太热，要么已经开始抽薹。

&nbsp;&nbsp;&nbsp;浇水的时间最好是清晨，因为叶片上沾的水分在白天就会晾干。傍晚浇水的话，叶片会整夜保持潮湿，而这种状态正是真菌性病害的发生条件。生菜上的霜霉病和灰霉病，其发生几乎与叶片保持潮湿的时间长度成正比。

### 7-2. 缺水或水过多时

| 状态 | 症状 | 结果 |
|:---|:---|:---|
| 水分不足 | 叶片白天下垂，傍晚恢复 | 暂时性的。仍可恢复 |
| 水分不足 | 叶片变小变厚，苦味增强 | 莴苣鸦片增多 |
| 水分不足 | 叶缘干枯并抽薹 | 难以恢复 |
| 水分过多 | 下部叶片变黄 | 根系缺氧 |
| 水分过多 | 茎基部出现白色霉层和黑色颗粒 | 菌核病。这棵植株必须丢弃 |
| 水分过多 | 叶片变软，长出灰色霉层 | 灰霉病 |

&nbsp;&nbsp;&nbsp;茎基部如果出现黑色坚硬的颗粒，就是菌核病。这种颗粒就是菌核，落入土壤后能存活好几年，感染下一茬作物。发现后，要把这棵植株连同周围的土一起挖出，移到田外，不要放进堆肥里，而要烧掉或埋到远处。

### 7-3. 覆盖

| 材料 | 效果 | 注意 |
|:---|:---|:---|
| 稻草 | 保水、抑制杂草、阻挡雨水溅起 | 播种后立即使用时只铺薄薄一层 |
| 干草·落叶 | 与稻草效果相同 | 混有种子的草会招来杂草 |
| 稻壳 | 轻而耐久 | 不要混入土中，只用来覆盖 |

&nbsp;&nbsp;&nbsp;对生菜来说，覆盖最大的好处在于阻挡雨水溅起。菌核病和灰霉病的孢子存在于土壤中，雨滴打在土上时被溅起，附着到叶片背面。如果地面和叶片之间有一层稻草，这条途径就被切断了。生菜的叶片紧贴地面生长，这个问题尤为严重，所以覆盖的效果比其他作物更大。

&nbsp;&nbsp;&nbsp;不过，正如评价依据所指出的，仅靠覆盖无法防住霜霉病，因为霜霉病靠空气中的孢子传播。覆盖只是多种手段之一，必须与通风、排水和品种混植配合使用才有意义。

## 8. 栽培管理

### 8-1. 间苗

| 次数 | 时期 | 保留间距 |
|:---|:---|:---:|
| 第1次 | 真叶2-3片 | 5cm |
| 第2次 | 真叶4-5片 | 15-20cm（最终） |

&nbsp;&nbsp;&nbsp;如果不及时间苗，生菜就只会向上长。它与相邻植株争夺光照，把叶柄拉得很长，结果就变成细长的茎上只挂着几片小叶子。而且在密植状态下，叶片相互重叠，通风不良，这种潮湿的空气就成了霜霉病和灰霉病的发生条件。在没有农药的情况下，保证株距本身也是一种防治手段。

> **间苗间下来的幼嫩生菜不是废弃物，而是第一茬收获。播种后25天左右的嫩叶柔软，几乎没有苦味，可以直接做成菜叶包裹料理（ssam）或沙拉。**

&nbsp;&nbsp;&nbsp;间苗时不要拔，而要用剪刀或指甲在贴近地面处掐断。生菜的须根浅而且相互缠绕，拔掉一棵，旁边的植株也会跟着晃动。根被松动的植株要花几天才能恢复，这种胁迫有时还会让抽薹提前。

### 8-2. 杂草与培土

&nbsp;&nbsp;&nbsp;生菜不需要培土。收获物并不在土里生长，生育期又短，在长到会倒伏之前收获就已结束。相反，如果茎基部被土埋住，菌核病可能就从那里开始，所以茎基部周围最好留空，保持通风。

| 杂草管理 | 方法 | 时期 |
|:---|:---|:---|
| 人工除草 | 拔除植株之间的杂草 | 与间苗同时进行 |
| 覆盖 | 用稻草、干草覆盖 | 真叶3-4片以后 |
| 浅锄除草 | 把homi（韩国的小手锄）浅浅插入，只刮表面 | 杂草还小的时候 |

&nbsp;&nbsp;&nbsp;锄草时要小心，不要把homi插得太深。生菜的须根大部分在离地表5-10cm以内，这些根一旦被切断，植株就会萎蔫，恢复缓慢。要从离植株较远的一侧开始浅浅地刮，紧挨植株的杂草则用手拔除。

### 8-3. 推迟抽薹的管理

| 因素 | 对抽薹的影响 | 对策 |
|:---|:---|:---|
| 高温 | 最强的信号 | 通过遮光、覆盖、灌溉降低地温 |
| 长日照 | 日照变长会促进抽薹 | 春季栽培要抓紧收获 |
| 干旱胁迫 | 植株急于留下种子 | 均匀浇水 |
| 根系损伤 | 构成胁迫 | 间苗和锄草时要小心 |
| 密植 | 竞争胁迫 | 及时间苗 |
| 氮不足 | 转入生殖生长的速度加快 | 足量施入基肥 |

&nbsp;&nbsp;&nbsp;抽薹一旦开始就无法逆转。当中心长出茎秆、叶片开始向上直立时，就应当认为这棵植株的收获已经结束。即便把花茎剪掉，旁边还会再长出来，而这期间叶片会越来越苦。

&nbsp;&nbsp;&nbsp;抽薹的生菜并不需要全部丢弃。还很嫩的花茎及其上的叶片，焯水后浸泡，苦味能去掉不少。用沸水焯过，再泡在冷水里，挤干水分，就可以做成凉拌野菜（namul）食用。另外，要留几棵不动，用来留种。第13节会讲到这部分。

&nbsp;&nbsp;&nbsp;在必须熬过夏天的情况下，切实可行的对策是遮光和布局。把生菜放在高秆作物北侧的阴影里、建筑物的阴影里或树下，地温会降低几度，抽薹也就相应推迟。在玉米或向日葵之间种生菜这种古老的布局，就是建立在这一原理之上的。
