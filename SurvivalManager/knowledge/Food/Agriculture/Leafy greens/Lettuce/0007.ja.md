## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;評価表の貯蔵性E、無電力の常温で2-3日という値は、この文書が扱う作物全体の中で最も低い値です。この節は、その事実を覆す方法を紹介する場ではありません。サンチュは貯蔵できません。何が可能で何が不可能かを正確に見分けることが、この節の目的です。

&nbsp;&nbsp;&nbsp;三つの要因が重なって、このような結果になります。第一に、水分含量が95%を超え、葉が薄くて広く、体積に対する表面積が大きいため、水分が速く蒸発します。第二に、組織を支えているのは主に細胞内の水の圧力なので、水が少し抜けただけですぐにしおれます。ハクサイのように厚い葉脈が形を保つ構造がありません。第三に、切り口から乳液が出て、その部分が褐変し、腐敗の起点になります。したがって、サンチュを数日もたせる技術のすべては、水分を失わせないことと、温度を下げて呼吸を遅らせることの二つです。

| 方法 | 手順 | 期間 | 限界 |
|:---|:---|:---:|:---|
| 茎の水挿し | 株元を1cm切り、水を浅く入れた器に立てます | 3-5日 | 水を毎日替える必要があり、場所を取ります |
| 濡れ布で包む | 洗わないまま濡れた布で包み、涼しい所に置きます | 3-4日 | 布が乾くと効果がなくなります |
| 濡れたわらに埋める | 濡れたわらの間に何層にも重ねて寝かせておきます | 3-5日 | わらが汚れているとカビが生えます |
| 土室・室（むろ） | 涼しい地下空間に濡れた布と一緒に置きます | 5-7日 | 室が必要です |
| 甕に密封 | 濡れた布を敷いた甕に入れ、日陰に置きます | 3-5日 | 通気がないと軟らかくなります |

&nbsp;&nbsp;&nbsp;水挿しは原理が単純です。切られた導管が水を吸い上げ続け、葉の膨圧を保ちます。ただし、水に浸かった断面で細菌が増えて導管を詰まらせるため、水を毎日替え、替えるたびに株元を数mmずつ切り直してやると、より長くもちます。洗わずに保管するという原則も重要です。洗うと葉の表面に水の膜ができ、その下で腐敗菌が急速に広がります。葉の表面のクチクラ層とワックスはサンチュ自身の防御膜ですが、洗う過程で一部がはがれてしまうこともあります。

&nbsp;&nbsp;&nbsp;土室や室の温度は、地下1.5-2mで年間を通じて10-15℃の間に保たれます。夏でも外より10℃以上低くなります。この程度でも呼吸速度が目に見えて落ち、二日が五日になります。ただし、室の中は湿度が高くカビが生えやすいので、通気を完全にはふさがず、傷んだ葉が混ざらないようにします。傷んだ葉一枚が出すエチレンが、隣の無事な葉を老化させます。

| 加工貯蔵 | 手順 | 期間 | 評価 |
|:---|:---|:---:|:---|
| ゆでて干す | 沸騰した湯で20-30秒ゆで、日陰で干します | 6か月-1年 | 可能ですが、かさが極端に減り、食感が崩れます |
| そのまま干す | 洗わずに広げて干します | 数か月 | 褐変してぼろぼろになります |
| ムルキムチ（水キムチ） | 2-3%の塩水に漬けて発酵させます | 1-2週間 | 涼しい場所でのみ。葉が軟らかくなります |
| チャンジ（塩辛い漬物）型の塩漬け | 塩10%以上 | 数か月 | 形が完全に崩れ、汁物の具にしか使えません |

&nbsp;&nbsp;&nbsp;ゆでて干すことは物理的には可能ですが、仕上がりは満足のいくものではありません。95%が水なので、1kgを干しても50gに満たず、しかもその組織は薄くてぼろぼろに砕けます。水で戻しても、元の食感は戻りません。夏に抽だいが始まって一度に処理しなければならなくなったサンチュを、捨てないための最後の手段と考えるのが適切です。

&nbsp;&nbsp;&nbsp;塩漬けの限界は構造に由来します。ハクサイやダイコンは漬けても細胞壁が形を保ちますが、サンチュは漬けたとたんにしんなりして、くたくたになります。キムチに漬けてもシャキシャキ感は残らず、数日でくたくたに熟れすぎてしまいます。サンチュのムルキムチが、漬けてから数日以内に食べる料理としてしか存在しない理由です。

> **サンチュの貯蔵問題を解く方法は、貯蔵技術ではなく播種計画にあります。十日から十五日間隔に分けてまき、外葉だけを摘んで使えば、そもそも貯蔵する必要が生じません。畑に立っているサンチュが、最も優れた貯蔵庫です。**

## 16. 調理と加工

&nbsp;&nbsp;&nbsp;評価表の調理・加工の等級はSSで、根拠は「洗って生食」の五文字です。災害時に、この五文字が持つ重みを正確に量ってみる必要があります。

| 作物 | 食べるまでに必要な処理 | 燃料 |
|:---|:---|:---:|
| サンチュ | 洗う | なし |
| ダイズ | 8時間浸水し、1時間以上煮る | 多い |
| ジャガイモ | 20-30分ゆでるか焼く | 中程度 |
| 米 | 30分炊飯 | 中程度 |
| フダンソウ | 5分ゆでる | 少ない |

&nbsp;&nbsp;&nbsp;電気とガスが止まった状況では、調理用の燃料は薪や炭であり、それは人が切り出し、乾かし、割らなければならないものです。一日三食を煮炊きするのに要する木の量は思ったより多く、都市近郊では数か月で周辺の乾いた木がなくなります。こうした条件で、火をまったく使わずに食べられる野菜が畑にあるということは、熱量表には現れない種類の利点です。

&nbsp;&nbsp;&nbsp;ここに栄養面の利点が重なります。ビタミンCと葉酸と一部のビタミンB群は熱に弱く水に溶けるため、ゆでた瞬間にかなりの量が失われ、ゆで汁に流れ出ます。サンチュにはその損失がありません。微量栄養素S、21種のうち16種を満たすという評価が、実際の摂取量にほぼそのまま反映される、数少ない作物です。

| 方式 | 要領 | 備考 |
|:---|:---|:---|
| サム（葉で包んで食べる料理） | 葉をそのまま使い、ご飯やおかずを包んで食べます | 穀物中心の食事の単調さを破る、最も簡単な方法 |
| コッチョリ（浅漬けの和え物） | 粗く切って塩でさっと漬けたあと、調味料で和えます | しんなりしてかさが減り、たくさん食べられます |
| サラダ | 油やエゴマの粉を混ぜます | 脂溶性ビタミンの吸収が上がります |
| ムルキムチ | 2-3%の塩水に漬けて一、二日置きます | 乳酸発酵でビタミンCがかなり残ります |
| ゆでる | 沸騰した湯に20-30秒 | 苦味が湯に流れ出て、食感が柔らかくなります |

&nbsp;&nbsp;&nbsp;コッチョリは、災害時に特に実用的です。生の葉はかさが大きく、一度に食べられる量に限りがありますが、塩で軽く漬けるとしんなりして、同じ量がずっと食べやすくなります。サンチュの最大の弱点が熱量密度である以上、実際の摂取量を増やすこの単純な処理が、栄養供給に差をもたらします。塩が貴重な場合は、ごく少量でさっと漬け、出た漬け汁は汁物に使います。油を少しでも混ぜるのも有利です。ビタミンAとビタミンEとビタミンKは脂溶性なので、油なしで食べると吸収率が大きく下がりますが、エゴマやゴマをすって振りかけることで、同じ効果が得られます。

&nbsp;&nbsp;&nbsp;火を通して食べる方法もあります。サンチュに火を通すのは馴染みがありませんが、抽だいが始まって葉が硬くなり、苦味が出る時期には、むしろこちらのほうが優れています。沸騰した湯に20秒から30秒ゆでると、苦味成分がかなり湯に流れ出て、食感が柔らかくなります。汁物を煮る火の最後に入れれば、燃料を別に使うこともありません。

### 16-1. サンチュの「とう」の利用

&nbsp;&nbsp;&nbsp;花茎が伸びてきたサンチュを、そのまま引き抜いて捨てるのはもったいないことです。抽だいしたサンチュの茎、いわゆる「とう」は、それ自体を食べることができます。中国では、そもそも茎を食べるための品種を別に栽培しており、韓国でも昔からサンチュの茎をナムル（野菜の和え物）やチャンアチ（醤油漬け）にして使ってきました。

| 部位 | 処理 | 味と使い方 |
|:---|:---|:---|
| 太い茎 | 皮をむき、斜めに切って塩水に漬けて苦味を抜いたあと、炒めるか和えます | シャキシャキして淡白です |
| 茎の皮 | 硬く、乳液が集まっているため、むいて取り除きます | 堆肥に回します |
| つぼみ | まだ咲いていないものをゆでて和えます | ほろ苦いです |
| 茎のチャンアチ | 切って塩で漬けたあと、テンジャン（韓国味噌）や醤油に漬け込みます | 数か月もちます |

&nbsp;&nbsp;&nbsp;皮を必ずむくのがコツです。外皮にラクツカリウムが最も多く集まっており、繊維も硬いからです。むいてしまえば、中の身はむしろ苦味が少なくシャキシャキしています。切ったあと、塩水や米のとぎ汁に30分ほど浸けておくと、残った苦味がさらに抜けます。チャンアチに漬ければ数か月もちます。葉ではとても作れない貯蔵の形が、茎では可能になるわけです。採種株から出る側枝の茎も同じように使えるので、採種と茎の収穫を兼ねれば、四か月間場所をふさぐ採種株の機会費用が減ります。

## 17. 年間作業スケジュール

| 月 | 春栽培 | 秋栽培 |
|:---:|:---|:---|
| 1月 | 種子の点検、堆肥の管理、輪作計画 | 畑は空いている |
| 2月 | 発芽率の確認、堆肥の切り返し、元肥の準備 | |
| 3月 | 下旬に播種。元肥と畝立て | |
| 4月 | 間引きと定植。若葉の収穫。ナメクジの発生予察 | |
| 5月 | 本格的な収穫、10-14日間隔の再生収穫。追肥 | |
| 6月 | 抽だい開始。採種株に印を付けて残りを片付ける | |
| 7月 | 採種株の開花と結実。空いた場所に夏の作物 | |
| 8月 | 上旬に種子の収穫と精選 | 上旬から播種。高温休眠への対応 |
| 9月 | | 間引きと定植、2回目の播種。べと病の発生予察 |
| 10月 | | 本格的な収穫。再生収穫が最も長い月 |
| 11月 | | 収穫継続。わら掛けと風よけ。下旬に片付け |
| 12月 | | 畑の片付けと残渣処理。病気の株は畑の外へ |

&nbsp;&nbsp;&nbsp;韓国の気候を基準にしたこの表を縦に読むと、サンチュの性格が見えてきます。春栽培は収穫期間が短く、抽だいで幕を閉じます。5月によく収穫できていても、6月に気温が上がると急に終わります。そのかわり、種を残せるのは春栽培だけです。播種から採種まで四か月が必要で、その時間を確保できるのは春だけだからです。

&nbsp;&nbsp;&nbsp;秋栽培はその逆です。育つ間ずっと気温が下がっていくので抽だいの圧力がなく、霜が降りるまで二か月以上、再生収穫が続きます。葉も厚く、甘みが増します。ただし、種子は採れません。

| 区分 | 春栽培 | 秋栽培 |
|:---|:---|:---|
| 収穫期間 | 4-6週 | 8-10週 |
| 終わる理由 | 抽だい | 霜 |
| 葉の質 | 後半になるほど苦味が出る | 最後まで柔らかく、甘みが付く |
| 病害の圧力 | 低いが、後半に上がります | べと病の圧力が大きい |
| 採種 | 可能です | 難しいです |
| 発芽条件 | 問題ありません | 高温休眠への対応が必要です |

&nbsp;&nbsp;&nbsp;そのため、実際の配置はこうなります。春は種子を確保するために植え、秋は食べるために植えます。二つの作型の間の夏の二か月と冬の三か月は、サンチュのない期間で、その空白は別の作物が埋めます。夏にはスベリヒユやヨウサイ（空芯菜）のように高温に強い葉菜類が、冬にはケールやカラシナのように寒さに耐える作物が、その場所に入ります。

> **一年十二か月のうち、サンチュが食卓に上るのは四か月余りです。この事実を知り、残りの八か月を何で埋めるかを計画することのほうが、サンチュをうまく育てる技術よりも、災害時にはより重要です。**

&nbsp;&nbsp;&nbsp;最後に、播種時期を分ける原則をもう一度確認しておきます。サンチュは貯蔵できないので、一度にすべてまくと、必ず捨てる部分が出ます。十日から十五日間隔で三回から四回に分けてまけば、収穫もそれだけ続き、ある作期が病気で失敗しても、次の播種分が残ります。貯蔵のきかない作物では、時期をずらした播種は便宜ではなくリスクの分散です。
