## はじめに
&nbsp;&nbsp;&nbsp;サンチュ(Lactuca sativa)はキク科の葉物野菜で、アブラナ科のケールやカラシナとは違い、タンポポ、ヨモギ、ヒマワリと同じ仲間です。地中海と西アジアに自生していたトゲチシャが祖先です。総合等級はD(37.7点、有効183種中135位)、副食はSS(62.1点)です。面積当たりの熱量はD(1,000㎡で3,000kgを収穫しても自給ラインの0.23倍)、貯蔵性はE(無電力の常温で2-3日)と、評価した作物の中で最も低く、温度幅もC(15-22℃)です。しかしサンチュは、倉庫に積んでおく食料ではなく、畑から直接口に入る食料です。洗ってそのまま食べるので燃料がいらず(調理・加工SS)、外葉だけ摘めば2-3か月育ち続け(永続性A)、自家受粉なので種を採っても性質が保たれます(自家採種S)。弱点は、25℃を超えると発芽しない高温休眠、暑さで立つ花茎と苦味、2-3年という種子の寿命、キク科の菌核病による2-3年の休作です。サンチュは畑の柱ではなく、畑の日々の糧です。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | キク科アキノノゲシ属の一年草。アブラナ科の害虫や根こぶ病はつかないが、キク科特有の菌核病とべと病がチコリ、シュンギク、ゴボウにも移る |
| 葉、茎 | 緑色、赤色、混合色の丸い葉、縮れ葉、細長い葉がある。茎は普段ごく短く、葉が束になって出ているように見え、とう立ちするとまっすぐ伸びる。切ると白い乳液(ラクツカリウム)が出る |
| 根、花、果実 | 主根は下りるが細根は浅く広がる。黄色い頭花。先端に冠毛(綿毛)がついた痩果 |

| 段階 | 時期(播種後) | 要点 |
|:---|:---|:---|
| 発芽、幼苗期 | 7日まで | 種子が光と温度を確かめてから発芽する |
| 栄養成長期 | 7-30日 | 葉が急速に増えて株をつくる。窒素 |
| 収穫、再生収穫期 | 30-110日 | 外葉から育ちきり、摘むと内側から新しい葉が上がる |
| とう立ち、開花期 | 60-100日 | 茎が伸び、葉が苦味に変わる。リン酸、カリウム |

> **とう立ちは病気ではなく、サンチュの正常な一生の過程です。人が食べるサンチュはその一生の前半にすぎず、栽培技術の半分は、この転換点をどれだけ遅らせられるかにあります。**

&nbsp;&nbsp;&nbsp;とう立ちの条件は、25℃を超える日が続く高温、日が長くなる長日、水不足・根の損傷・密植といったストレスの3つで、この3つが重なる真夏にはサンチュが成り立ちません。とう立ちが始まるとラクツカリウムの濃度が急激に上がり、葉が硬く苦くなります。

&nbsp;&nbsp;&nbsp;100g当たり熱量20kcal、水分約95%(貯蔵性が悪い根本原因)、タンパク質1.88g(熱量比37.6%)、葉酸49㎍、ビタミンA(βカロテン換算)354-717㎍です。βカロテンは葉の色が濃いほど、外葉ほど多いので、栄養が目的なら葉が濃く開いた系統が有利です。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽適温15-20℃(3-5日)で、25℃以上では発芽率が急落する。生育適温15-20℃、可能範囲15-22℃で、25℃以上が続くととう立ちと苦味が出る |
| 光 | 1日6-8時間。40%遮光で相対収量86%。好光性。夏はむしろ遮光が有利(地温を下げてとう立ちを遅らせる) |
| 水、土壌 | 総蒸発散量は約350mm。水はけがよく有機物の多い土、pH6.0-6.6、畝の高さ15-20cm。根が浅く、表土が乾くとすぐ影響を受ける |

&nbsp;&nbsp;&nbsp;サンチュの種子は、ある温度を超えると発芽をやめます。夏が暑く乾燥する地中海で、夏に出た芽が枯れるのを避ける設計で、好光性とあわせ、光が届く浅い所で土が涼しいときだけ芽が出る二重の鍵です。半日陰への適応がよいので、建物の陰、木の下、トウモロコシやヒマワリなど背の高い作物の北側に置き、日当たりのよい場所はほかの作物に譲ります。

| 品種 | 特徴 |
|:---|:---|
| 葉サンチュ(チマ系) | 葉が開いて再生収穫ができるので、災害時の中心。青チマ(最も広く使われる)、赤チマ(アントシアニン)、青・赤のチュクミョン(縮れ葉) |
| 結球レタス、ロメイン、バターヘッド | 結球レタスは1回抜けば終わりの一回きり、ロメインは半結球で再生収穫がある程度でき、バターヘッドは葉が軟らかく貯蔵性がさらに悪い |
| ジャンス、トマリン | ジャンスは半日陰や屋内でも育ち、トマリンは葉が厚く繊維が多くてしおれにくい |

&nbsp;&nbsp;&nbsp;災害初期の最短の収穫には青チマ、赤チマ(若葉は25-30日)を、種の自立には固定種と在来種を選びます。サンチュは自家受粉なので、複数の品種を並べて植えても種が混ざらず、2、3品種を混ぜて植えると、とう立ちの時期と病気への抵抗性が違うため全滅の危険が減り、べと病への対応にも役立ちます。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 土づくり | 20-30cmの深さに耕し、土塊を細かく砕いて平らにならす(種が3mmほどしかなく、土塊のすき間に落ちて深く埋まると芽が出ない)。根が浅く、表土10cmだけ砕いても育つが、水はけが悪ければ畝を立てる |
| 施肥(1,000㎡) | 窒素10-12kg、リン酸6-8kg、カリウム6-8kg、堆肥1,000-1,500kg、石灰100-150kgを、播種の1-2週間前に全量元肥として入れる。追肥は原則として省く(窒素が多いと葉が軟らかくなり、苦くなって病気に弱くなる)。再生収穫が2か月を超えて続くときだけ、葉を摘んだ直後に薄くやる |
| 代替資源 | 完熟堆肥(1㎡当たり1-1.5kg)、木灰(1㎡当たり一つかみ、pHが6.6を超えないように)、尿の15-20倍希釈液(ほかの葉物より薄く)、卵の殻の粉 |

| 作型 | 播種 | 収穫 | 備考 |
|:---|:---|:---|:---|
| 春作 | 3月下旬-5月中旬 | 4月下旬-6月下旬 | 最も一般的。収穫は4-6週間でとう立ちで終わる。種は春にしか採れない |
| 秋作 | 8月上旬-9月上旬 | 9月上旬-11月上旬 | 災害時に最も有利。8-10週間で霜で終わる |
| 夏作、冬作 | 勧めない | | 夏は発芽失敗と早期とう立ち、冬は南部の保温条件でのみ |

&nbsp;&nbsp;&nbsp;秋作の落とし穴は、8月上旬の暑さで地温が25℃を超えると種が眠ってしまうことで、秋まきの実際の技術は、暑さを避けて発芽させることです。

| 高温休眠への対応 | 方法 |
|:---|:---|
| 低温プライミング | 種を水に4-6時間浸し、濡れた布に包んで涼しい所(井戸水、地下室、北向きの日陰)に1日置く。最も確実。処理後すぐにまき、土を乾かさない(水を吸った種は乾くと死ぬ) |
| そのほかの方法 | 濡れた布で先に芽出しして移しまく、日が沈んでからまく、すだれ・枝・わらで薄い日陰をつくる(芽が出たら外す)、昼に冷水をかけて地温を下げる |

| 播種 | 基準 |
|:---|:---|
| 方法 | 深さ2-3mmで、細かい土を種がやっと隠れる程度だけかぶせるか、押さえるだけにする。条間20cm。密にまいてから間引く |
| 時期をずらした播種 | 貯蔵できないので、10日から15日おきに3-4回に分けてまく。1回の作が病気で失敗しても次の播種分が残る |
| 種子の処理 | 種を50-55℃のお湯に10-15分浸してから冷水で冷ます。採りたての種は高温休眠がより強いので、2年分を重ねて持ち、古いほうから使う |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から幼苗期 | 表土が乾かないように軽く頻繁に |
| 生育期 | 春と秋は3-5日おき、夏は2-3日おき。葉を摘んだ後にも水をやる(乾くと回復が遅れ、とう立ちが早まることがある) |
| 収穫直前、梅雨 | 収穫直前はやや控え、梅雨には排水溝を確保する |

&nbsp;&nbsp;&nbsp;水が不足するとサンチュは葉を厚くしてラクツカリウムの濃度を上げ、苦くなります。株元に白いかびと黒い粒が見えれば菌核病なので、その株は捨てます。水は早朝にやり、昼のあいだに葉を乾かします(かび病は葉がぬれている時間に比例して出る)。わらのマルチは、雨が土をはね上げて胞子を葉の裏につける経路を断ちますが、ナメクジの隠れ家になるので、風通しや排水と合わせて使います。

| 管理 | 方法 |
|:---|:---|
| 間引き | 本葉2-3枚で5cmに1回目、4-5枚で15-20cmに2回目(最終)。遅れると上にばかり伸び、風通しが悪くなってかび病が出る。抜かず、はさみや爪で地面近くから切る。間引いた若いサンチュが最初の収穫(25日ごろは苦味がほとんどなく、包み野菜やサラダにする) |
| 雑草 | 土寄せは不要。本葉3-4枚以降はわらや枯れ草でマルチし、雑草が小さいうちに小さな鍬を浅く入れて表面だけかく |

&nbsp;&nbsp;&nbsp;とう立ちが始まって中心から茎が伸びると、その株の収穫は終わりで、花茎を切っても脇からまた上がってきます。若い花茎とその上の葉は、ゆでてあくを抜けば和え物になり、数株は残して種を採ります。とう立ちを遅らせるには、遮光、マルチ、水やりで地温を下げ、乾燥ストレス、根の損傷、密植を避け、夏を越すなら背の高い作物の北側や建物の陰に置きます。

## 6. 病害虫と養分の問題
| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| 菌核病 | 株元が軟らかくなり、白い菌糸と黒い粒(菌核)ができる。低温多湿、キク科の連作 | 深耕、マルチ、2-3年の輪作、病株の除去 |
| べと病 | 葉の表に黄褐色の斑点、裏に白いかび。涼しいとき、葉が長くぬれているとき | 風通し、朝の水やり、品種の混植、病葉の除去 |
| 灰色かび病、株腐れ病、斑点細菌病 | 灰色のかび(低温多湿) / 株元の褐変と倒伏(過湿) / 葉縁の黒褐色の斑点(高温多湿、傷) | 湿度管理、間隔の確保 / 排水、株元まわりを空ける / 風通し |
| アブラムシ、アザミウマ | 汁を吸いウイルスを媒介 / 銀白色の跡 | 石けん水、テントウムシを守る / 黄色い粘着トラップ、雑草の除去 |
| ガの幼虫、ナメクジ | 葉をかじる / 穴と粘液の跡 | 早朝に捕る、防虫ネット / 夜に捕る、灰・もみ殻・卵の殻の帯 |

> **菌核病にかかった株を見つけたら、根のまわりの土ごとすくって畑の外へ出します。堆肥の山に入れてはいけません。菌核は堆肥の発酵熱に耐えて生き残り、畑全体に広がります。**

&nbsp;&nbsp;&nbsp;サンチュの問題は虫ではなくかびです。菌核がたまった畑では、シュンギク、チコリ、ゴボウも避け、3-5年のあいだイネ科やマメ科を入れます。石けん水は葉が軟らかいので1Lに20gを超えず、昼間を避けてまき、数時間後にきれいな水ですすぎます。

| 症状 | 原因と対処 |
|:---|:---|
| 葉全体が黄色く株が小さい | 窒素欠乏。完熟堆肥、尿の15-20倍希釈液 |
| 内側の葉先が褐色に枯れる(チップバーン) | 水分移動の不均衡でカルシウムが新しい葉の先まで届かない。水やりを均一にし、間隔を確保 |
| 葉が軟らかく、または濃い緑色で苦味が強い | 窒素過剰または乾燥ストレス。花茎、土の乾き、葉の色で見分け、窒素を止めるか水をやる |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | ワケギ・長ネギ・ニンジン(においが害虫を惑わす)、ダイコン(サンチュは40-60日で場所を空ける)、トウモロコシ・ヒマワリ(北側に置くと陰がとう立ちを遅らせる) |
| 悪い | シュンギク、チコリ、ゴボウなどキク科(菌核病とべと病を共有)、サンチュの連作(菌核がたまる) |

&nbsp;&nbsp;&nbsp;4年周期で、サンチュなどキク科→マメ科(窒素を固定)→トウモロコシ・モロコシなどイネ科→ダイコン・ハクサイなどアブラナ科の順に回すと、菌核の密度が下がった状態でサンチュをまた始められます。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 若葉(サラダ、包み野菜)は25-30日(間引きと兼ねる)、葉摘み収穫は30-40日(外葉の長さ15-20cm)、株ごとの収穫は40-60日 |
| 摘み方 | 下の外側から育ちきった葉を、一度に全体の半分以下だけ、常に中心の葉を6枚以上残して、はさみで茎の近くから切る(手でちぎると傷が病原菌の入口になる)。摘んだあとは水をやる |
| 繰り返し収穫 | 10-14日おきに平均2-3回、条件がよければ4-5回。1株で2、3か月で、花茎が立てば終わり。10株から20株で1人の毎日をまかなう |

> **常に中心の葉を6枚以上残します。残した葉が光合成の工場であり、その工場が次の葉をつくります。欲張ってすべて摘むと、その株はそのまま止まります。**

&nbsp;&nbsp;&nbsp;成長点は株の中心にある短い茎の先端にあるので、外葉を摘んでも残りますが、中心を切るとその株は終わりです(結球レタスが一回きりの理由)。秋のサンチュは霜が来るまで続くので、春のサンチュより長くもちます。

| 採種 | 基準 |
|:---|:---|
| 受粉の仕方 | 花が開く前のつぼみの段階で受粉が終わる自家受粉なので、他家受粉率は0-5%(たいてい1%前後)。隔離は1-2mで足り、1株でも可能 |
| 日程 | とう立ちは播種後60-80日に始まり、開花は90-110日、種子の成熟は開花後12-24日、収穫は120-150日。秋作は霜が先に来て種が熟さないので、採種は春作で行う |
| 冠毛 | 冠毛が膨らむと1、2日で散り、1株の中でも熟す時期が3週間以上ずれる。2-3日に1回、膨らんだ花だけをしごいて採る(回収率が最も高い)、綿毛が見える直前に通気性のある紙袋や布袋をかぶせる(バランスが最もよい、ビニールは避ける)、半分以上膨らんだら花茎ごと刈って逆さにつるして後熟させる |
| 選別、貯蔵 | 1株から3,000-10,000粒が採れる。十分に乾かし、密閉容器に入れて涼しく暗く湿気のない所に置く。寿命は常温で密閉して2-3年、涼しく乾燥していれば3-5年。毎年20粒で発芽を確認する |

> **採種株は、最も遅く花茎が立った株から選びます。晩抽性、つまり暑さの中で遅くまでもちこたえる性質が遺伝するからです。数年このやり方で選び続けると、その畑のサンチュが少しずつ夏に強くなります。**

## 9. 貯蔵
| 方法 | 手順と期間 |
|:---|:---|
| 茎の水挿し | 株元を1cm切り、水が浅く入った器に立てる。3-5日。水を毎日替え、株元を切り直す |
| 濡れた布、濡れたわら | 洗わずに濡れた布で包み涼しい所に3-4日 / 濡れたわらの間に層にして寝かせて3-5日 |
| 貯蔵穴、地下室 | 涼しい地下空間(年間10-15℃)で濡れた布と一緒に5-7日。通気を完全にはふさがず、傷んだ葉を混ぜない |
| 加工 | ゆでて干す(6か月-1年、食感が崩れる)、水キムチ(1-2週間)、塩漬け型(塩10%以上、数か月、汁物の具にしか使えない) |

> **サンチュの貯蔵問題を解く方法は、貯蔵技術ではなく播種計画にあります。10日から15日おきに分けてまき、外葉だけ摘んで使えば、貯蔵する必要がそもそも生じません。畑に立っているサンチュが最良の貯蔵庫です。**

&nbsp;&nbsp;&nbsp;サンチュは水分が95%を超え、葉が薄く広くて蒸発が速く、組織を支えているのが細胞内の水の圧力なので少し抜けただけでしおれ、切り口の乳液が褐変して腐敗が始まります。数日もたせる技術は、水分を守ることと温度を下げることだけで、洗うと水の膜ができて腐敗菌が広がるので、食べる直前に洗います。

## 10. 調理と注意事項
| 方法 | 要領 |
|:---|:---|
| 包み野菜 | 葉をそのまま使ってご飯やおかずを包んで食べる。穀物中心の食事の単調さを破る最も簡単な方法 |
| 浅漬け | 粗く切って塩で軽く漬け、調味料で和える。しんなりしてかさが減り、たくさん食べられるので、災害時にとくに実用的 |
| サラダ、水キムチ | 油やエゴマ粉を混ぜると脂溶性のビタミンA・E・Kの吸収が上がる / 2-3%の塩水に1、2日置くと、ビタミンCがかなり残る |
| 湯通し、サンチュの茎 | 沸騰した湯で20-30秒ゆでると苦味が抜けて軟らかくなり、とう立ちで硬くなった時期によい / 茎は皮をむき、塩水に浸して苦味を抜いてから炒めるか和え、塩で漬けて味噌や醤油に漬ければ数か月もつ |

&nbsp;&nbsp;&nbsp;サンチュは洗うだけで食べられるので、調理の燃料がいりません。ビタミンC、葉酸、一部のビタミンB群は熱に弱く水に溶けるため、ゆでるとかなり失われますが、サンチュにはその損失がありません。

| 成分 | 影響と対応 |
|:---|:---|
| ラクツカリウム | 茎を切ると出る白い乳液の苦味成分。軽い鎮静作用があるが、食べる量では実感できない。とう立ち直後に急に上がり、開花期には食べにくい。苦味は毒性ではなく、時期が過ぎたという合図 |
| 硝酸塩 | 日陰、低光量、窒素過多で増える。窒素を多く与えた日陰の畑のサンチュを、ほかの野菜なしで毎日大量に食べるときに問題になる。窒素源は収穫の数日前から止め、日の当たる場所をサンチュに優先して割り当て、午後に収穫し、ほかの葉物と交互に食べる |
| シュウ酸 | 含有量が低く、実際の問題にならない |

&nbsp;&nbsp;&nbsp;サンチュに急性毒性はありません。

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 種子の点検と発芽率の確認、堆肥の切り返し、輪作計画 |
| 3-4月 | 3月下旬に春の播種(元肥、畝立て)。4月に間引きと定植、若葉の収穫、ナメクジの観察 |
| 5-6月 | 5月に本格的な収穫、10-14日おきの再生収穫。6月にとう立ちが始まり、採種株に印をつけて残りを片付ける |
| 7-8月 | 7月に採種株の開花と結実、空いた場所に夏作物。8月に種子の収穫と選別、上旬から秋まき(高温休眠への対応) |
| 9-10月 | 9月に間引きと定植、2回目の播種、べと病の観察。10月に本格的な収穫、再生収穫が最も長い月 |
| 11-12月 | 11月に収穫を続け、わらで覆い、風よけを設けて、下旬に片付け。12月に畑の整理と残さの処理(病株は畑の外へ) |

&nbsp;&nbsp;&nbsp;春は種を確保するために、秋は食べるために植え、その間の夏と冬は、スベリヒユやヨウサイ、ケールやカラシナのようなほかの作物が埋めます。

> **1年12か月のうち、サンチュが食卓に上るのは4か月余りです。このことを知り、残りの8か月を何で埋めるかを計画することが、サンチュをうまく育てる技術よりも災害時には重要です。**
