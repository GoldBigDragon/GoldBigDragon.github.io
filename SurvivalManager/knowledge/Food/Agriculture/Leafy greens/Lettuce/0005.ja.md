## 9. 病害虫 - 薬なしで防ぐ方法

&nbsp;&nbsp;&nbsp;サンチュ（リーフレタス）の病害虫圧の等級はC、無防除時の減収率は推定50.6%です。防除自立度はBですが、評価の根拠には重い但し書きが付いています。有機栽培のサンチュを扱った実証文献では、べと病に対して品種の混植を試みたものの、マルチングだけでは商業的な防除は不可能であり、中等度の発病でも損失は最低10%、収益の減少は25%を超えたと報告されています。薬なしでサンチュを育てるのは決して楽ではない、ということです。

&nbsp;&nbsp;&nbsp;ただし、サンチュには有利な点が一つあります。キク科であるため、アブラナ科作物の害虫が付かないことです。モンシロチョウ、コナガ、ノミハムシ、根こぶ病は、サンチュには手を出しません。畑にアブラナ科作物が集中している状況でも、サンチュはその圧力から外れた位置にあります。サンチュの問題は虫ではなく、カビです。

### 9-1. 主な病害

| 病害 | 症状 | 発生条件 | 薬を使わない対応 |
|:---|:---|:---|:---|
| 菌核病 | 株元が軟らかくなって白い菌糸に覆われ、ハエの糞のような黒い粒ができます | 低温多湿、キク科の連作 | 深耕、マルチング、2-3年の輪作、罹病株の完全な除去 |
| べと病 | 葉の表に黄褐色の斑点、裏に白いカビが生えます | 涼しくて湿っているとき、葉が長く濡れているとき | 風通しの確保、朝の灌水、品種の混植、病葉の除去 |
| 灰色かび病 | 褐色の斑点ができ、灰色のカビに覆われます | 低温多湿、風通しが悪いとき | 湿度管理、株間の確保、病変部の除去 |
| 細菌性斑点病 | 葉の縁に黒褐色の斑点ができ、広がって枯れ死にます | 高温多湿、傷 | 湿度を下げ、風通しを確保します |
| すそ腐病 | 地際部が褐変し、株が倒れます | 過湿、株元に土がかぶさったとき | 排水、株元の周りを空けておきます |

&nbsp;&nbsp;&nbsp;菌核病は、サンチュで最も重い病気です。ほかの病気はその年の収穫を減らす程度にとどまりますが、菌核病は畑を汚染します。病気にかかった株の株元から伸びた菌糸が黒くて硬い塊をつくり、これが菌核です。菌核は土壌に落ちて何年も生き延び、条件が合えば再び発芽して新しい株に感染します。

> **菌核病にかかった株を見つけたら、根の周りの土ごと掘り取って畑の外へ運び出します。堆肥の山に入れてはいけません。菌核は堆肥の発酵熱に耐えて生き残り、畑全体に広がります。**

&nbsp;&nbsp;&nbsp;評価表の連作適応性B、2-3年の休作という基準は、まさにこの菌核のためです。菌核がすでにたまっている畑では、サンチュだけでなく、シュンギク、チコリ、ゴボウといったキク科作物も一緒に避けなければなりません。代わりにイネ科やマメ科を数年入れます。菌核がひどい畑で3-5年のイネ科輪作が必要なのも、同じ理由です。

&nbsp;&nbsp;&nbsp;べと病は胞子が空気で広がるため、完全には防げません。ただし発生条件は明確で、葉が濡れている時間が長いほど悪化します。したがって対応も明確です。水は早朝に与えて日中のうちに乾かし、間引きで株間を広げて風を通し、密植と過湿を避けます。品種を混ぜて植えると、一つの系統に弱い病原菌が畑全体に広がるのを遅らせることができます。

### 9-2. 主な害虫

| 害虫 | 被害 | 薬を使わない防除 |
|:---|:---|:---|
| アブラムシ | 葉の裏で汁を吸い、ウイルスを媒介します | 石けん水の散布、テントウムシとアブラバチの保護、銀色の反射資材 |
| アザミウマ | 葉をひっかいて汁を吸い、銀白色の痕を残します | 黄色の粘着トラップ、雑草の除去 |
| ガ類の幼虫 | 葉をかじります | 早朝の手取り、防虫ネット |
| ナメクジ | 葉に穴をあけ、粘液の跡を残します | 夜の手取り、草木灰やもみ殻の帯を巡らせる |
| ネダニ | 根をかじって株がしおれます | 輪作、排水の改善 |

&nbsp;&nbsp;&nbsp;ナメクジは、サンチュにとって特に厄介な存在です。葉が地面に近く、柔らかいからです。昼間はわらの下や石の下に隠れていて、夜に出てきてかじるため、昼に探しても見つかりません。夜に明かりを持って出て捕まえるのが最も確実で、株の周りに乾いた草木灰ともみ殻や卵の殻を帯のように巡らせると、体が乾くのを嫌って越えてきません。ただし雨が降ると効果がなくなるので、巡らせ直す必要があります。

&nbsp;&nbsp;&nbsp;マルチングがナメクジの隠れ場所になる点が悩ましいところです。マルチングは雨の跳ね返りを防いでカビによる病気を減らしますが、同時にナメクジを呼び寄せます。ナメクジの被害がひどい畑では、わらの代わりにもみ殻のように粗くて乾いた資材を使うか、株のすぐそばは空けておき、少し離れた場所だけを覆うという形で折り合いをつけます。

### 9-3. 自然素材の防除剤

| 防除剤 | 作り方 | 対象 |
|:---|:---|:---|
| 石けん水 | 香料の入っていない石けん20gを水1Lに溶かします | アブラムシ、ハダニ |
| 草木灰液 | 草木灰を水に浸して24時間置き、濾して使います | アブラムシ |
| 草木灰の帯 | 株の周りに乾いた灰をまきます | ナメクジの遮断 |
| 黄色粘着板 | 黄色い板に粘着性のものを塗って立てます | アザミウマ、有翅のアブラムシ |
| 木酢液 | 300-500倍に薄めて散布します | 忌避効果、病気の抑制 |

&nbsp;&nbsp;&nbsp;サンチュに石けん水を使うときは、ほかの作物より注意が必要です。葉が薄くて柔らかく、濃度が少し高いだけでも傷むからです。1Lあたり20gを超えないようにし、散布して数時間後にきれいな水で一度すすいでやると、葉の傷みを減らせます。真昼を避け、早朝か日没後に散布します。

&nbsp;&nbsp;&nbsp;黄色が飛ぶ虫を引き寄せる性質は、アザミウマやアブラムシの発生予察に使われます。黄色い板に粘着性のものを塗って畑に立てておけば、どんな虫がいつから入ってくるのかが分かります。薬がない状況では、防除の第一歩は、いつ何が来るのかを知ることであり、こうした単純な仕掛けがその役割を果たします。

### 9-4. 耕種的防除の原則

| 原則 | 内容 |
|:---|:---|
| 輪作 | キク科は2-3年、菌核病があるならそれ以上休ませます |
| 風通し | 間引きで株間を確保します。サンチュで最も安上がりな防除手段です |
| 排水 | 畝を立て、水がたまらないようにします |
| 灌水の時刻 | 早朝に与え、日中に葉が乾くようにします |
| マルチング | 雨の跳ね返りを防ぎ、土壌伝染性病原菌の経路を断ちます |
| 窒素管理 | 多すぎると葉が軟弱になり、アブラムシが集まります |
| 残渣処理 | 病気の株は土ごと掘り取って焼くか、遠くに埋めます |
| 高温期の回避 | 夏の栽培を避けること自体が防除です |
| 品種の混植 | 抵抗性の異なる品種を混ぜて、全滅を防ぎます |

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然素材でできる対処 |
|:---|:---|:---|
| 葉全体が黄色くなり、株が小さくなります | 窒素欠乏 | 完熟堆肥を施すか、尿を15-20倍に薄めて与えます |
| 葉の縁が褐色に枯れます | カリウム欠乏 | 草木灰を少量まきます |
| 生育が悪く、葉が紫色を帯びます | リン酸欠乏 | 骨粉や草木灰を施します。地温が低いときも同じ症状が出ます |
| 内側の葉の先が褐色に枯れます | カルシウム欠乏または水分の不均衡 | 卵の殻の粉、均一な灌水 |
| 葉脈の間が黄色くなります | マグネシウム欠乏 | 堆肥を増やします |
| 葉が柔らかすぎて軟弱になります | 窒素過剰 | 窒素の供給を止めます |
| 葉が濃い緑色で苦味が強くなります | 窒素過剰または乾燥ストレス | 原因を見分けて対応します |

&nbsp;&nbsp;&nbsp;サンチュに特徴的に現れる欠乏症状は、内側の葉の先が褐色に焼けたように枯れることです。チップバーンと呼ばれ、カルシウムが新しく伸びる葉の先まで届かないために起こります。土のカルシウムが不足して起こる場合よりも、水分の移動が円滑でないために起こる場合のほうが多くあります。カルシウムは水の流れに乗って移動する元素ですが、内側の葉は外側の葉に隠れて蒸散が少なく、水の流れが弱いからです。

&nbsp;&nbsp;&nbsp;そのため、チップバーンへの対応は、カルシウムを入れることよりも、水分を均一に保ち、湿度が高すぎないようにすることにあります。密植で内側の葉が閉じ込められているとさらにひどくなるため、株間を確保することも助けになります。卵の殻を細かく砕いて入れるのは長期的なカルシウム補給として意味がありますが、即効性は期待できません。

&nbsp;&nbsp;&nbsp;窒素過剰は、サンチュで特に気をつけるべき問題です。葉が大きくて濃い緑色なので、よく育ったように見えますが、組織が軟らかく細胞壁が薄いため、カビによる病気に弱くなり、アブラムシが集まります。しかもサンチュは生で食べる野菜なので、葉にたまった硝酸塩がそのまま口に入ります。窒素を遅くまで与えないこと、特に収穫の数日前には与えないことが原則です。

&nbsp;&nbsp;&nbsp;苦味が出る原因は、二つに分けて考える必要があります。一つは、抽だいと乾燥ストレスでラクツカリウムが増えたもの、もう一つは、窒素過剰で組織が変化したものです。前者は水と温度の管理で、後者は施肥の調整で対応します。花茎が見えるか、土が乾いているか、葉の色が濃すぎないかを見れば、区別がつきます。

## 11. 間作と輪作

| 相性 | 対象 | 効果 |
|:---:|:---|:---|
| 良い | マメ科作物（エンドウ、インゲンマメ、ササゲ） | 窒素を固定して残してくれます |
| 良い | ワケギ、長ネギ、ニンジン | においが害虫を惑わせます |
| 良い | ダイコン、ハクサイなどのアブラナ科 | 病害虫を共有せず、根の深さが違います |
| 良い | トウモロコシ、ヒマワリなど背の高い作物 | 日陰をつくって抽だいを遅らせます |
| 悪い | シュンギク、チコリ、ゴボウなどのキク科 | 菌核病とべと病を共有します |
| 悪い | サンチュの連作 | 菌核がたまります |

&nbsp;&nbsp;&nbsp;サンチュとダイコンを混ぜて植える配置は、空間の活用面で効率的です。サンチュは根が浅く地表近くに広がり、40-60日で場所を空けますが、ダイコンは根が深く伸び、70日から90日かかります。ダイコンの葉がまだ小さいうちはその間でサンチュが地面を覆って雑草を抑え、サンチュを収穫し終える頃にはダイコンが大きくなって場所を占めます。同じ面積で二つの作物が得られます。病害虫を共有しないという点も有利です。

&nbsp;&nbsp;&nbsp;背の高い作物の北側にサンチュを置く配置は、夏を乗り切る方法です。トウモロコシやヒマワリが午後の強い日差しを遮るので地温が数度下がり、その分だけ抽だいが遅れます。ただし暗すぎるとサンチュが徒長するため、完全な日陰ではなく半日陰になるように距離を取ります。

| 輪作順序の例 | 年次 | 作物 | 畑で起こること |
|:---|:---:|:---|:---|
| 4年周期 | 1年目 | サンチュなどのキク科 | 菌核病のリスクがたまり始めます |
| | 2年目 | マメ科（ダイズ、エンドウ、ササゲ） | 窒素が固定されてたまります |
| | 3年目 | トウモロコシ、モロコシなどのイネ科 | キク科の病原菌が飢えます |
| | 4年目 | ダイコン、ハクサイなどのアブラナ科 | 深い根で土を掘り返します |
| | 再び1年目 | サンチュ | 菌核の密度が下がった状態で始めます |

&nbsp;&nbsp;&nbsp;イネ科をキク科の後に入れる配置が特に有効です。菌核病の病原菌は宿主範囲が広いものの、イネ科にはうまく感染できないからです。イネ、トウモロコシ、モロコシ、コムギ、オオムギがここに入ります。菌核がすでにたまっている畑で3-5年のイネ科輪作が必要な根拠は、これです。

&nbsp;&nbsp;&nbsp;畑が狭くて輪作が難しい場合でも、せめて場所を移すだけで違いが出ます。菌核は土の中で動かないので、昨年サンチュを植えた場所と今年の場所を入れ替えるだけで、感染の機会が減ります。鉢や箱で育てるなら、土を入れ替えるのが最も確実です。

## 12. 収穫 - 再生収穫の原理

### 12-1. 収穫時期

| 用途 | 播種後 | 状態 |
|:---|:---:|:---|
| 若葉（サラダ、サム：葉で包んで食べる料理） | 25-30日 | 柔らかい若葉。間引きを兼ねます |
| 葉の摘み取り収穫 | 30-40日 | 外葉の長さ15-20cm |
| 株ごとの収穫 | 40-60日 | 十分に育った状態 |
| 採種用 | 60-100日 | 花茎が立ち、種が熟します |

&nbsp;&nbsp;&nbsp;評価表の収穫速度Sは、播種から最初の収穫まで50-60日と設定されていますが、実際にははるかに早く食べ始められます。間引きを兼ねた若葉の収穫が25日頃から可能だからです。災害の初期に、畑に何もない状態でサンチュをまけば、一か月以内に何か緑のものが口に入ります。

### 12-2. 外葉だけを摘む理由

&nbsp;&nbsp;&nbsp;サンチュの生長点は、圧縮された短い茎の頂部、株の真ん中にあります。そこから新しい葉が次々と上がってきて、外側へ押し出されながら育ちます。したがって、外側の育ち切った葉を摘み取っても、植物が失うのは、すでに光合成能力が落ちた古い葉だけです。生長点はそのまま残り、引き続き新しい葉をつくります。

&nbsp;&nbsp;&nbsp;逆に、真ん中を切ってしまうと、その株は終わりです。生長点がなくなって、もう葉をつくれません。脇芽から小さな葉が数枚出ることもありますが、商品になる大きさには育ちません。結球レタスが一回限りの収穫である理由も同じです。結球した塊を収穫するには、生長点ごと持ち去らなければならないからです。

| 項目 | コツ |
|:---|:---|
| 摘む葉 | 下の外側から、育ち切った葉 |
| 一度に摘む量 | 全体の葉の半分以下 |
| 残す葉 | 常に中心の葉を六枚以上 |
| 摘む道具 | 手でちぎらず、ハサミで茎の近くを切ります |
| 摘む時刻 | 早朝。夜の間に水分を含み、最も新鮮です |
| 再収穫の間隔 | 10-14日 |
| 繰り返せる回数 | 平均2-3回、条件が良ければ4-5回 |

> **常に中心の葉を六枚以上残します。残した葉が光合成の工場であり、その工場が次の葉をつくります。欲張ってすべて摘んでしまうと、その株はそのまま止まります。**

&nbsp;&nbsp;&nbsp;手でちぎらずハサミを使うようにと言うのには、理由があります。手でちぎると葉柄が茎から裂けて縦に傷が残り、その傷が病原菌の入り口になります。特に菌核病と灰色かび病は傷から入ります。ハサミできれいに切ると断面が小さく、早く癒合します。切ったあとの切り口に、乾いた草木灰を軽くつけておくと、さらに安全です。

&nbsp;&nbsp;&nbsp;葉を摘んだあとは水を与えます。葉を失った植物は、新しい葉をつくるのに水分と養分を使い、このとき土が乾くと回復が遅れ、ストレスで抽だいが早まることがあります。再生収穫を長く続けるには、摘むたびに水を与え、2-3週間に一度は薄めた追肥を施すとよいでしょう。

### 12-3. 一株でどれくらい持つか

&nbsp;&nbsp;&nbsp;評価表の永続性Aは、リーフレタス（サンチュ）の外葉を繰り返し収穫して2-3か月持続するという意味です。10-14日間隔で2-3回、条件が良ければ4-5回収穫します。この期間を決めるのは、結局のところ抽だいです。花茎が立った瞬間、再生収穫は終わります。

&nbsp;&nbsp;&nbsp;秋のサンチュが春のサンチュより長く持つ理由はここにあります。春は育つ間に気温が上がるため、一か月から一か月半で抽だいが始まりますが、秋は気温が下がるため、霜が降りるまで続きます。災害時には秋の栽培を中心に据えるべきだと言われるのは、この期間の差から来ています。

&nbsp;&nbsp;&nbsp;一人が一日にサンチュを五、六枚食べるとすると、再生収穫中のサンチュ十株から二十株で一人の毎日をまかなえます。一度に収穫して積んでおく作物ではなく、毎日少しずつ取ってくる作物なので、必要な株数は食べる量ではなく再生速度で計算しなければなりません。
