## 2. どんな植物か

### 2-1. 分類と原産地

| 項目 | 内容 |
|:---|:---|
| 学名 | Lactuca sativa |
| 分類 | Magnoliophyta Magnoliopsida / Asterales / Asteraceae / Lactuca |
| 生活型 | 一年生 |
| 原産地 | 地中海沿岸から西アジアにかけての地域 |
| 野生の祖先 | トゲチシャ（Lactuca serriola） |
| 同じ仲間 | タンポポ、ヨモギ、ヒマワリ、ゴボウ、チコリ |

&nbsp;&nbsp;&nbsp;サンチュがキク科であるという事実は、実務の上で三つの意味を持ちます。第一に、アブラナ科の作物と病害虫を共有しません。モンシロチョウもノミハムシも根こぶ病も、サンチュには手を出しません。アブラナ科の作物が集まっている畑では、サンチュが安全地帯の役目を果たします。第二に、その代わりキク科に固有の病気があります。菌核病とべと病がそれで、これらの病気はチコリやシュンギク、ゴボウにもうつります。第三に、茎を切ると白い乳液が出ます。タンポポを折ったときに出てくる白い汁と同じもので、キク科の植物に共通する特徴です。

&nbsp;&nbsp;&nbsp;学名のLactucaは、ラテン語で「乳」を意味するLacに由来し、この白い乳液を指しています。乳液の主成分はラクチュシン（lactucin）とラクチュコピクリン（lactucopicrin）という苦味物質で、この二つを合わせてラクチュカリウム（lactucarium）と呼びます。本来の目的は草食動物を追い払うことです。サンチュが他の葉菜より虫の被害を受けにくい理由はここにあり、同時に、とうが立つと食べられなくなる理由でもあります。14節でこの成分を詳しく扱います。

### 2-2. 形態

| 器官 | 特徴 |
|:---|:---|
| 葉 | 品種によって、丸い葉、縮れた葉、細長い葉とさまざまです。緑色、赤色、混合色 |
| 茎 | 普段はきわめて短く、葉が束になって生えているように見えます。とう立ちすると真っすぐに伸びます |
| 根 | 直根が下に伸びますが、細根は浅く広がります |
| 花 | 黄色。キク科特有の、小さな花が多数集まった頭状花序です |
| 果実 | 痩果。褐色または黒色で、先端に冠毛が付きます |
| 乳液 | 茎や葉脈を切ると白い汁が出ます |

&nbsp;&nbsp;&nbsp;サンチュの茎が普段ほとんど見えないという点が、再生収穫の基盤です。茎がきわめて短く圧縮されていて、その先端に生長点があるため、葉は放射状にぐるりと出て重なり合います。外側の葉ほど先に出た古い葉で、内側ほど新しい葉です。したがって外側から摘み取っていくと、植物は古い葉を失うだけで生長点はそのまま残り、新しい葉を次々と押し上げ続けます。逆に真ん中を切り落としてしまうと、その株は終わりです。

&nbsp;&nbsp;&nbsp;サンチュの種子の先端に付いている冠毛は、タンポポの種子のそれと同じ構造です。風に飛ばされて広がるための仕掛けで、採種のときにはこの冠毛が厄介な存在になります。種子が熟すと風で簡単に飛んでしまうため、時期を逃すと収穫できるものが残りません。一方で、冠毛のおかげで、箕であおって中身のない種子を選り分けることが比較的容易です。

### 2-3. 生育段階

| 段階 | 時期（播種基準） | 主な生理 | よく使う養分 |
|:---|:---|:---|:---|
| 発芽・幼苗期 | 播種-7日 | 種子が光と温度を確かめてから芽を出します | リン、窒素 |
| 栄養生長期 | 7-30日 | 葉が急速に増え、株を形づくります | 窒素 |
| 収穫適期 | 30-60日 | 外側の葉から十分に育ちます | 窒素とカリウムのバランス |
| 再生収穫期 | 40-110日 | 外側の葉を摘むと、内側から新しい葉が出てきます | 窒素 |
| とう立ち・開花期 | 60-100日 | 茎が立ち上がり、葉が苦くなります | リン、カリウム |
| 結実期 | 開花後2-3週間 | 冠毛の付いた種子が熟します | リン、カリウム |

&nbsp;&nbsp;&nbsp;この表で決定的な転換点は、とう立ちです。それまでサンチュは葉をつくるためにすべての資源を使いますが、とう立ちが始まると、茎を立てて花を咲かせる方向へ舵を切ります。このとき葉に残っていた養分が茎と花へ移動し、同時にラクチュカリウムの濃度が急激に上がります。葉は硬くなり、苦味が強くなって、食べられなくなります。

> **とう立ちは病気ではなく、サンチュの正常なライフサイクルの一部です。人が食べるサンチュはその生涯の前半にすぎず、栽培技術の半分は、この転換点をどれだけ遅らせられるかにあります。**

&nbsp;&nbsp;&nbsp;とう立ちを招く条件は三つあります。第一は高温です。気温が25度を超える日が続くと、サンチュは生殖生長に切り替わります。第二は長日です。日が長くなると、同じシグナルが強まります。第三はストレスです。水が足りない、根が傷む、密植で競争が激しいといった状況では、植物は急いで種を残そうとします。三つの条件が重なるのがまさに真夏であり、だから夏のサンチュは成り立ちません。

### 2-4. 100g当たりの栄養

| 成分 | 含量 | 備考 |
|:---|:---:|:---|
| 熱量 | 20kcal | 品種により13-20kcal |
| 水分 | 約95% | 貯蔵性が悪い根本的な原因 |
| タンパク質 | 1.88g | 熱量に占める割合37.6% |
| 糖類 | 1.22g | |
| ビタミンA（βカロテン換算） | 354-717 μg | 品種による差が大きいです |
| 葉酸 | 49 μg | |
| ビタミンK | 含有 | 血液凝固と骨代謝に関与します |
| カリウム | 含有 | |

&nbsp;&nbsp;&nbsp;ビタミンAの含量が品種によって二倍も違うという点は、実用上重要です。βカロテンは葉の色が濃いほど多く含まれます。濃い緑の葉は淡い緑の葉より、外側の葉は内側の淡い葉より多く含みます。玉レタスのように中が白く詰まる品種は、その白い部分にβカロテンがほとんどありません。災害時に栄養を目的にサンチュを育てるなら、葉が濃く、結球せずに開いた系統を選ぶほうが有利です。

&nbsp;&nbsp;&nbsp;赤サンチュの赤い色はアントシアニンです。抗酸化物質として働き、低温と強い光の下でより濃くなります。同じ畑で秋に育てた赤サンチュが、春に育てたものより色が濃くなるのは、このためです。青サンチュと赤サンチュを混ぜて植えると、同じ面積から得られる成分の幅が広がります。

&nbsp;&nbsp;&nbsp;サンチュの鎮静作用は古くから知られています。ラクチュカリウムに軽い鎮静効果があると報告されたことがあり、サンチュを食べると眠くなるという経験則はここから生まれました。ただし、私たちが食べる若いサンチュのラクチュカリウム濃度は非常に低く、実際の薬理効果を期待できる水準ではありません。濃度が高いのは、とう立ちしたサンチュの茎から出る乳液です。

## 3. 栽培環境

### 3-1. 温度

| 区分 | 温度 | 説明 |
|:---|:---:|:---|
| 発芽適温 | 15-20℃ | 3-5日で芽が出ます |
| 発芽限界 | 25℃以上 | 発芽率が急激に下がります |
| 生育適温 | 15-20℃ | 葉が柔らかく、収量が高くなります |
| 生育可能範囲 | 15-22℃ | 幅10℃と狭い範囲です |
| とう立ちの誘発 | 25度以上が続くとき | とうが立ち、苦味が出ます |
| 低温限界 | 軽い霜には耐えます | 氷点下に大きく下がると、葉が凍ってやわらかく崩れます |

&nbsp;&nbsp;&nbsp;サンチュの温度条件で最も特異なのは発芽の面です。大半の作物は温度が高いほど発芽が早まりますが、サンチュは逆に、一定の温度を超えると発芽が止まります。高温休眠と呼ばれる現象です。

&nbsp;&nbsp;&nbsp;これは故障ではなく設計です。地中海性気候で育った野生のレタスの立場で考えれば理解できます。その地域は夏が暑くて乾燥し、雨は秋から春にかけて降ります。夏に芽を出した種子は、枯れて死ぬに決まっています。そのためサンチュの種子は、土が温かいうちは芽を出さずに待ちます。気温が下がり、雨が降り始めると、そのときに発芽します。この判断の仕組みがそのまま残っているので、真夏にサンチュの種を播くと、種子は土の中で眠り込んでしまいます。

| 対策 | 方法 | 原理 |
|:---|:---|:---|
| 種子プライミング | 種子を水に数時間浸したあと、涼しい場所に一日置いてから播きます | 種子が低温を経験して休眠が解けます |
| 夕方の播種 | 日が沈んでから播いて、水をたっぷり与えます | 夜の間に地温が下がる隙を利用します |
| 遮光 | 播種場所にすだれや木の枝で日陰をつくります | 地温を数度下げます |
| 濡れた布での事前催芽 | 涼しい場所で芽出しをしてから、移して播きます | 発芽の段階を畑の外で済ませます |
| 時期の変更 | 夏の播種はあきらめて、秋を待ちます | 最も確実です |

> **夏にサンチュの播種が失敗するのは、土が悪いからでも水が足りないからでもなく、種子が暑さのために眠ってしまうからです。原因を知れば、対策が変わります。**

### 3-2. 光

| 項目 | 基準 | 備考 |
|:---|:---|:---|
| 日照の要求 | 1日6-8時間 | |
| 半日陰への適応 | 良好です | 40%遮光時の葉菜類の相対収量は86% |
| 種子の発芽 | 好光性 | 光を受けて初めて発芽します |
| 夏季 | むしろ遮光が有利です | 地温を下げてとう立ちを遅らせます |

&nbsp;&nbsp;&nbsp;サンチュの種子が好光性であるという事実は、播種で最も失敗が起きやすいポイントです。光を受けて初めて発芽が始まるため、土を厚くかぶせるとそのまま眠ってしまいます。播種の深さは2-3mm、種子がかろうじて隠れる程度が適当です。ダイコンを1-2cm埋めるのと比べると、次元が違います。

&nbsp;&nbsp;&nbsp;好光性と高温休眠は、同じ判断の仕組みの二つの側面です。種子は、光が届く浅い場所にあり、土が涼しいときに芽を出します。深く埋もれているときや暑いときは待ちます。二つの条件がそろって初めて発芽する、二重ロックのようなものです。

&nbsp;&nbsp;&nbsp;半日陰への適応が良いという点は、災害時の畑の配置に活かせます。建物の陰や木の下、一日中は日が当たらない場所にサンチュを置き、日当たりの良い場所はダイコンやジャガイモに譲ります。夏に近い時期なら、むしろ日陰がサンチュの寿命を延ばします。韓国では、トウモロコシやヒマワリのような背の高い作物の北側にサンチュを植える配置が、ここから出てきます。

### 3-3. 水と土壌

| 項目 | 基準 | 備考 |
|:---|:---|:---|
| 総蒸発散量 | 約350mm | 葉菜の中では少ないほうです |
| 灌水間隔 | 春と秋は3-5日、夏は2-3日 | 土の状態に応じて調整します |
| 土壌酸度 | pH 6.0-6.6 | pH 5以下や8以上では生育が悪くなります |
| 土壌 | 有機物が豊富で排水のよい土地 | 土壌への適応力は広いほうです |
| 畝の高さ | 15-20cm | 排水の確保 |
| 根の深さ | 浅く広がります | 表土が乾くとすぐに影響を受けます |

&nbsp;&nbsp;&nbsp;サンチュは土壌をあまり選びません。通気性があって水分が保たれる土であれば、おおむね育ちます。災害時には、この性質の価値が大きくなります。畑でない場所、庭や花壇、割れた鉢でもサンチュは育ちます。ただし根が浅く広がるため、表土の状態に敏感です。乾くと葉が硬くなって苦味が強まり、その状態が続くととう立ちが早まります。

&nbsp;&nbsp;&nbsp;水管理の原則は、むらをなくすことです。サンチュの葉は水分95%の組織なので、水の供給がそのまま葉の状態に表れます。乾燥する期間が長くなると、葉は小さく、厚く、苦くなります。逆に水がたまると、根が酸素を得られず、株元から軟腐病と菌核病が始まります。畝を立て、わらや枯れ草でマルチングするのが、この二つの問題を同時に扱う方法です。

&nbsp;&nbsp;&nbsp;マルチングはサンチュで特に効果が大きいです。根が浅くて地温の変動に敏感なためであり、もう一つは、雨粒が土を跳ね上げて葉の裏に付くのを防ぐためです。菌核病や灰色かび病の胞子は土の中にあり、雨水に跳ねて葉にくっつきます。地面と葉の間にわらを一層敷くと、この経路が断たれます。

## 4. 品種

### 4-1. 系統別の特徴

| 系統 | 特徴 | 災害時の位置づけ |
|:---|:---|:---|
| リーフレタス（チマサンチュ） | 結球せず、葉が開きます | 再生収穫ができ、最も有利です |
| 玉レタス | 中がしっかりと詰まります。株間30cm以上が必要 | 1回限りの収穫。別の文書で扱います |
| ロメインレタス | 直立型で葉が細長いです | 半結球。ある程度は再生収穫ができます |
| バターヘッドレタス | やわらかく半結球します | 葉が柔らかく、貯蔵性がさらに悪いです |

| 品種 | 特徴 | 適した環境 |
|:---|:---|:---|
| チョンチマ | 緑色の葉。最も広く使われる系統 | 春、秋 |
| チョクチマ | 赤い葉。アントシアニンが多く含まれます | 春、秋 |
| チョンチュンミョン・チョクチュンミョン | 葉が広く、しわが多いです | 春、秋 |
| チャンス | 光が少ない条件でも育ちます | 半日陰、室内 |
| トマリン | 葉が厚く繊維質が多いため、しおれにくいです | 貯蔵や運搬が必要なとき |

&nbsp;&nbsp;&nbsp;災害時に中心となるのは、リーフレタス系統です。理由は再生収穫です。玉レタスは、中が詰まった塊をまるごと収穫する1回限りの作物なので、一度引き抜けば終わりですが、リーフレタスは外側の葉だけを摘みながら、2か月から3か月続きます。同じ面積での総収穫量が多く、収穫が分散するので貯蔵の負担もありません。

&nbsp;&nbsp;&nbsp;トマリン系統のように、葉が厚く繊維質が多い品種は、口当たりは劣りますが、貯蔵性は優れています。貯蔵性Eという等級を少しだけでも引き上げてくれる選択肢です。畑から家までの距離が遠い場合や、毎日畑に出られない状況であれば、検討する価値があります。

&nbsp;&nbsp;&nbsp;チャンス系統のように日陰でも育つ品種は、畑以外の場所で育てるときに真価を発揮します。建物の間、塀の下、室内の窓辺のように日差しが不足する場所でも、ある程度の収量が得られます。都市で災害に遭った状況であれば、この性質が決定的になることもあります。

### 4-2. 状況別の選択基準

| 状況 | 選択 | 理由 |
|:---|:---|:---|
| 災害の初期、最短での収穫 | チョンチマ、チョクチマ | 若い葉を25-30日で収穫します |
| 長く摘んで食べる | リーフレタス系統全般 | 再生収穫で2-3か月 |
| 日当たりが不足する場所 | チャンスなど耐陰性の系統 | 半日陰でも育ちます |
| 数日置いて食べる必要があるとき | トマリンなど葉の厚い系統 | しおれにくいです |
| 栄養の幅を広げたいとき | チョクチマ | アントシアニンが加わります |
| 種子の自立を優先 | 固定種、在来種 | 自家受粉なので、種を採っても性質が保たれます |
| リスク分散 | 二、三品種の混植 | とう立ちの時期や病気への抵抗性が異なるため、全滅の危険が減ります |

&nbsp;&nbsp;&nbsp;複数の品種を混ぜて植える配置は、べと病への対策として有用です。評価の根拠で言及した有機サンチュの実証文献でも、品種の混植が試験されました。病気への抵抗性は品種ごとに異なるため、一つの品種だけを植えると、その品種が弱い系統の病原菌が入ってきたときに畑全体が崩れてしまいます。混ぜて植えれば、どれか一つがやられても残りが残ります。

> **サンチュは自家受粉作物なので、複数の品種を並べて植えても種子が混ざりません。アブラナ科作物が混植と採種の間で板挟みになるのとは異なり、サンチュはその両方を同時に行えます。**
