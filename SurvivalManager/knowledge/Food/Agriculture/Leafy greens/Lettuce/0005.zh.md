## 9. 病虫害 - 不用药的防治方法

&nbsp;&nbsp;&nbsp;生菜的病虫害压力等级为C，无防治减产率估计为50.6%。防治自立度为B，但评价依据中附有一条分量很重的限定条件：在有机生菜的实证文献中，针对霜霉病试验了品种混植，但仅靠覆盖无法实现商业化防治，中等程度发病时损失至少为10%，收益减少超过25%。这意味着不用药种生菜并非易事。

&nbsp;&nbsp;&nbsp;不过，生菜有一个有利之处：它属于菊科，十字花科作物的害虫不会找上它。菜粉蝶、小菜蛾、跳甲、根肿病都不会碰生菜。在田里十字花科作物集中的情况下，生菜处于避开这种压力的位置。生菜的麻烦不在虫，而在真菌。

### 9-1. 主要病害

| 病害 | 症状 | 发生条件 | 不用药的应对 |
|:---|:---|:---|:---|
| 菌核病 | 茎基部变软并被白色菌丝覆盖，长出蝇粪状的黑色颗粒 | 低温高湿，菊科作物连作 | 深翻、覆盖、2-3年轮作、彻底清除病株 |
| 霜霉病 | 叶片正面出现黄褐色斑点，背面生出白色霉层 | 凉爽潮湿时，叶片长时间潮湿时 | 保证通风、早晨浇水、品种混植、摘除病叶 |
| 灰霉病 | 出现褐色斑点，并被灰色霉层覆盖 | 低温高湿，通风不良 | 控制湿度、保持间距、清除病变部位 |
| 细菌性斑点病 | 叶缘出现黑褐色斑点，扩散后枯死 | 高温高湿，伤口 | 降低湿度，保证通风 |
| 底腐病 | 近地面部位褐变，植株倒伏 | 过湿，茎基部被土覆盖时 | 排水，茎基部周围保持空开 |

&nbsp;&nbsp;&nbsp;菌核病是生菜最严重的病害。其他病害只是减少当年的收成，而菌核病会污染田地。病株茎基部长出的菌丝结成黑色坚硬的团块，这就是菌核。菌核落入土壤后能存活数年，条件适宜时再次萌发，感染新的植株。

> **发现感染菌核病的植株时，连同根部周围的土一起挖出，运到田外。不能放进堆肥堆。菌核能耐受堆肥发酵产生的热而存活下来，扩散到整块田地。**

&nbsp;&nbsp;&nbsp;评价表中连作适应性为B、需休作2-3年的标准，正是因为这种菌核。已经积累了菌核的田块，不仅要避开生菜，茼蒿、菊苣、牛蒡等菊科作物也要一并避开。改种禾本科或豆科作物若干年。菌核严重的田块需要3-5年的禾本科轮作，也是同样的原因。

&nbsp;&nbsp;&nbsp;霜霉病的孢子随空气传播，因此无法完全阻止。不过它的发生条件很明确：叶片潮湿的时间越长，病情越重。所以应对措施也很明确：在清晨浇水，让叶片白天能晒干；通过间苗拉开间距，使空气流通；避免过密和过湿。把不同品种混合种植，可以延缓对某一品系敏感的病原菌蔓延到整块田地。

### 9-2. 主要害虫

| 害虫 | 危害 | 不用药的防治 |
|:---|:---|:---|
| 蚜虫 | 在叶背吸取汁液并传播病毒 | 喷洒肥皂水、保护瓢虫和蚜茧蜂、银色反光物 |
| 蓟马 | 刮伤叶片吸食汁液，留下银白色痕迹 | 黄色粘虫板、清除杂草 |
| 蛾类幼虫 | 啃食叶片 | 清晨人工捕捉、防虫网 |
| 蛞蝓 | 在叶片上咬出孔洞，留下黏液痕迹 | 夜间人工捕捉、围一圈草木灰或稻壳 |
| 根螨 | 啃食根部，植株萎蔫 | 轮作、改善排水 |

&nbsp;&nbsp;&nbsp;蛞蝓对生菜来说尤其麻烦，因为生菜的叶片贴近地面而且柔嫩。蛞蝓白天躲在稻草下或石头底下，夜间出来啃食，所以白天去找是找不到的。夜里提着灯出去捕捉最为可靠；在植株周围围一圈干燥的草木灰、稻壳或蛋壳，蛞蝓怕身体变干，就不会爬过来。不过下雨后效果就没有了，需要重新围一圈。

&nbsp;&nbsp;&nbsp;麻烦之处在于，覆盖会成为蛞蝓的藏身处。覆盖可以挡住雨水溅起的泥点从而减少真菌病害，但同时也会招来蛞蝓。蛞蝓危害严重的田块，可以用稻壳这类粗糙干燥的材料代替稻草，或者紧挨植株的地方留空，只覆盖稍远一些的位置，以此折中。

### 9-3. 天然防治剂

| 防治剂 | 配制方法 | 对象 |
|:---|:---|:---|
| 肥皂水 | 将20g无香料肥皂溶于1L水 | 蚜虫、螨类 |
| 草木灰液 | 将草木灰浸泡在水中24小时，过滤后使用 | 蚜虫 |
| 草木灰带 | 在植株周围撒一圈干燥的草木灰 | 阻隔蛞蝓 |
| 黄色粘虫板 | 在黄色板上涂抹粘性物质后竖立 | 蓟马、有翅蚜虫 |
| 木醋液 | 稀释300-500倍后喷洒 | 驱避效果、抑制病害 |

&nbsp;&nbsp;&nbsp;给生菜使用肥皂水时，要比其他作物更加小心，因为叶片薄而嫩，浓度稍高就会受伤。每1L不要超过20g，喷洒后过几个小时用清水冲洗一遍，可以减轻叶片损伤。避开正午，在清晨或日落后喷洒。

&nbsp;&nbsp;&nbsp;黄色能吸引飞虫的特性，可用于监测蓟马和蚜虫。在黄色板上涂抹粘性物质，竖在田里，就能知道什么害虫、从什么时候开始飞来。在没有农药的情况下，防治的第一步就是了解什么时候来什么虫，这种简单的装置就起到了这个作用。

### 9-4. 农业防治原则

| 原则 | 内容 |
|:---|:---|
| 轮作 | 菊科作物休作2-3年，有菌核病则更久 |
| 通风 | 通过间苗保持间距。这是生菜上最廉价的防治手段 |
| 排水 | 起垄，不让水积存 |
| 浇水时间 | 清晨浇水，让叶片白天晒干 |
| 覆盖 | 挡住雨水溅泥，切断土传病原菌的传播途径 |
| 氮肥管理 | 过量会使叶片松软，招来蚜虫 |
| 残体处理 | 病株连土挖出烧掉，或埋到远处 |
| 避开高温期 | 避开夏季栽培本身就是一种防治 |
| 品种混植 | 混种抗性不同的品种，防止全军覆没 |

## 10. 营养缺乏与过量

| 症状 | 原因 | 用天然材料采取的措施 |
|:---|:---|:---|
| 整张叶片变黄，植株矮小 | 缺氮 | 施入腐熟堆肥，或将尿液稀释15-20倍后浇施 |
| 叶缘枯焦呈褐色 | 缺钾 | 少量撒施草木灰 |
| 生长不良，叶片带紫色 | 缺磷 | 施入骨粉或草木灰。地温低时也会出现同样的症状 |
| 心叶叶尖枯焦呈褐色 | 缺钙或水分失衡 | 蛋壳粉、均匀浇水 |
| 叶脉之间发黄 | 缺镁 | 增施堆肥 |
| 叶片过于松软柔嫩 | 氮过量 | 停止供氮 |
| 叶片深绿色且苦味重 | 氮过量或干旱胁迫 | 分清原因后再应对 |

&nbsp;&nbsp;&nbsp;生菜上具有代表性的缺素症状，是心叶叶尖变褐枯焦。这叫作干烧心（tipburn），是钙没能到达新长出的叶尖而引起的。与土壤缺钙相比，由水分运输不畅引起的情况更为常见。钙是随水流移动的元素，而心叶被外层叶片遮住，蒸腾少，水流较弱。

&nbsp;&nbsp;&nbsp;所以应对干烧心，重点不在于补钙，而在于保持水分均匀、避免湿度过高。过密使心叶被困住时会更严重，因此保持间距也有帮助。把蛋壳碾成细粉施入，对长期补钙有意义，但不能指望立竿见影。

&nbsp;&nbsp;&nbsp;氮过量是生菜上尤其要当心的问题。叶片又大又浓绿，看上去长得很好，但组织松软、细胞壁薄，容易感染真菌病害，也会招来蚜虫。况且生菜是生吃的蔬菜，叶片中积累的硝酸盐会原样进入口中。原则是不要把氮肥施到太晚，尤其是收获前几天不要施。

&nbsp;&nbsp;&nbsp;苦味的成因要分成两类来看：一类是抽薹和干旱胁迫使莴苣乳（lactucarium）增多，另一类是氮过量使组织发生变化。前者通过水分和温度管理来应对，后者通过调整施肥来应对。看有没有花茎、土壤是否干燥、叶色是否过深，就能区分。

## 11. 间作与轮作

| 搭配 | 对象 | 效果 |
|:---:|:---|:---|
| 适宜 | 豆科作物（豌豆、菜豆、豇豆） | 固氮并留在土中 |
| 适宜 | 分葱、大葱、胡萝卜 | 气味扰乱害虫 |
| 适宜 | 萝卜、大白菜等十字花科 | 不共有病虫害，根的深度不同 |
| 适宜 | 玉米、向日葵等高秆作物 | 制造遮荫，推迟抽薹 |
| 不宜 | 茼蒿、菊苣、牛蒡等菊科 | 共有菌核病和霜霉病 |
| 不宜 | 生菜连作 | 菌核积累 |

&nbsp;&nbsp;&nbsp;生菜和萝卜混种的布局，在空间利用上很高效。生菜根浅，贴近地面铺开，40-60天就腾出位置；萝卜根扎得深，要长70天到90天。萝卜叶还小的时候，生菜在其间覆盖地面，抑制杂草；等生菜收完时，萝卜已长大，占据这块地方。同样的面积可以收获两种作物。两者不共有病虫害，这一点也是有利之处。

&nbsp;&nbsp;&nbsp;把生菜种在高秆作物北侧的布局，是帮助生菜度夏的办法。玉米或向日葵遮住午后强烈的日照，地温下降几度，抽薹也相应推迟。不过太暗时生菜会徒长，所以要保持一定距离，使其处于半阴而不是完全遮荫的状态。

| 轮作顺序示例 | 年次 | 作物 | 田里发生的事 |
|:---|:---:|:---|:---|
| 4年周期 | 第1年 | 生菜等菊科 | 菌核病风险开始积累 |
| | 第2年 | 豆科（大豆、豌豆、豇豆） | 固定的氮不断积累 |
| | 第3年 | 玉米、高粱等禾本科 | 菊科病原菌因断粮而衰亡 |
| | 第4年 | 萝卜、大白菜等十字花科 | 深根翻松土壤 |
| | 再回到第1年 | 生菜 | 在菌核密度降低的状态下重新开始 |

&nbsp;&nbsp;&nbsp;禾本科作物接在菊科之后种植，尤其有效。菌核病病原菌的寄主范围虽然广，却很难感染禾本科作物。水稻、玉米、高粱、小麦、大麦都属于这一类。菌核已经积累的田块需要3-5年的禾本科轮作，依据就在于此。

&nbsp;&nbsp;&nbsp;如果田地狭小、难以轮作，至少换个位置也会有差别。菌核在土壤中不会移动，只要把今年的种植位置与去年种生菜的位置对调，感染的机会就会减少。如果在花盆或箱子里种，换土最为可靠。

## 12. 收获 - 再生收获的原理

### 12-1. 收获时期

| 用途 | 播种后 | 状态 |
|:---|:---:|:---|
| 嫩叶（沙拉、叶包饭 ssam） | 25-30天 | 柔嫩的幼叶。与间苗结合进行 |
| 摘叶收获 | 30-40天 | 外叶长15-20cm |
| 整株收获 | 40-60天 | 充分长大的状态 |
| 留种用 | 60-100天 | 花茎抽起，种子成熟 |

&nbsp;&nbsp;&nbsp;评价表中收获速度为S，是按从播种到第一次收获50-60天计算的，但实际上开始食用要早得多。因为与间苗结合的嫩叶收获从25天左右就可以进行。灾难初期，在田里一无所有的情况下撒下生菜种子，一个月之内就能吃到一些绿色的东西。

### 12-2. 为什么只摘外叶

&nbsp;&nbsp;&nbsp;生菜的生长点位于被压缩的短茎顶端，即植株正中央。新叶不断从那里长出，并向外推挤着生长。因此，摘掉外侧已长成的叶片，植物失去的只是光合能力已经下降的老叶。生长点原样保留，继续长出新叶。

&nbsp;&nbsp;&nbsp;反过来，如果把中间切掉，这棵植株就完了。生长点没有了，再也长不出叶片。侧芽虽然也会长出几片小叶，但长不到能当商品的大小。结球生菜只能收获一次，原因也相同：要收获结球的叶球，就必须把生长点整个带走。

| 项目 | 要领 |
|:---|:---|
| 摘取的叶片 | 从下方外侧开始，摘已长成的叶片 |
| 每次摘取量 | 不超过全部叶片的一半 |
| 保留的叶片 | 始终保留中心的叶片六片以上 |
| 摘取工具 | 不要用手撕，用剪刀在靠近茎处剪下 |
| 摘取时间 | 清晨。经过一夜吸足水分，最新鲜 |
| 再次收获间隔 | 10-14天 |
| 可重复次数 | 平均2-3次，条件好时4-5次 |

> **始终保留中心的叶片六片以上。留下的叶片是光合作用的工厂，这座工厂会长出下一批叶片。贪心全部摘光，这棵植株就会就此停止生长。**

&nbsp;&nbsp;&nbsp;不要用手撕而要用剪刀，是有道理的。用手撕会使叶柄从茎上撕裂，留下纵向的伤口，这个伤口会成为病原菌的入口。尤其是菌核病和灰霉病，都是从伤口侵入的。用剪刀干净利落地剪下，切面小，愈合得快。剪完后在切口处轻轻蘸一点干燥的草木灰，则更安全。

&nbsp;&nbsp;&nbsp;摘叶之后要浇水。失去叶片的植物要用水分和养分长出新叶，这时如果土壤干了，恢复就会变慢，还可能因胁迫而提前抽薹。要想长期持续再生收获，最好每次摘叶后都浇水，每2-3周施一次稀薄的追肥。

### 12-3. 一棵植株能持续多久

&nbsp;&nbsp;&nbsp;评价表中持续性为A，指的是散叶生菜通过反复采收外叶可持续2-3个月。每隔10-14天收获，2-3次，条件好时收获4-5次。决定这个期限的，归根结底是抽薹。花茎一抽起，再生收获就结束了。

&nbsp;&nbsp;&nbsp;秋季生菜比春季生菜持续更久，原因就在这里。春季在生长过程中气温不断上升，所以一个月到一个半月就开始抽薹；秋季气温不断下降，因此可以一直持续到下霜。在灾难情况下要以秋季栽培为中心，这种说法就源自这一期限上的差异。

&nbsp;&nbsp;&nbsp;如果一个人每天吃五六片生菜，那么处于再生收获期的生菜十到二十株，就能满足一个人每天的需要。生菜不是一次收获后囤积的作物，而是每天取一点的作物，所以所需株数应当按再生速度来计算，而不是按食用量。
