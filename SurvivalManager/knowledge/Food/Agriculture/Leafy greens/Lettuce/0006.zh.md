## 13. 留种 - 自花授粉这一优势

&nbsp;&nbsp;&nbsp;评价表中自家留种的等级为S，依据栏里写着“自花授粉，保持纯系”这样一句简短的话。这一行字几乎说明了生菜留种的全部。羽衣甘蓝要求500m隔离和多株同时开花，萝卜要求1km隔离，而生菜只要留下一株就能收到种子，而且这些种子长出来的还是同样的生菜。

### 13-1. 为什么不会混杂

&nbsp;&nbsp;&nbsp;生菜的花是菊科特有的头状花序。十到二十朵小花聚在一起，构成一个黄色的花序，整个花序只在早晨开放一两个小时便闭合。关键在于它开放的时间点。生菜在花开放之前、花蕾尚未张开的阶段，雄蕊就已经散出花粉，下方的雌蕊随即接受了花粉。花开放时，受精已经完成。因此即使有蜜蜂来访，基因也几乎不会混杂。实测的异花授粉率因条件而异，在0-5%之间，大多在1%左右。

| 作物 | 授粉方式 | 实用隔离距离 | 留种株最少株数 |
|:---|:---|:---:|:---:|
| 生菜 | 自花授粉（近于闭花受精） | 1-2m | 1株也可以 |
| 羽衣甘蓝·结球甘蓝 | 异花授粉（虫媒），自交不亲和 | 500m以上 | 5-10株 |
| 萝卜 | 异花授粉（虫媒），自交不亲和 | 1,000m以上 | 10株以上 |
| 莙荙菜·甜菜根 | 异花授粉（风媒） | 1,000m以上 | 10株以上 |

> **生菜留种所需的隔离距离为1-2m，只要与其他品种的花茎互不接触就足够了。这意味着在狭小的田里，也可以在同一年里收取多个品种的种子。**

&nbsp;&nbsp;&nbsp;由于并非完全是0%，要想长期保持品种，还要再做两件事：一是在留种株之间夹种一行其他作物以拉开间距，二是次年长出的幼苗中如果发现与品种特性不同的个体，就拔除。把这项工作重复几年，纯度反而会提高。

### 13-2. 从抽薹到种子的时间

| 阶段 | 播种后 | 状态 |
|:---|:---:|:---|
| 叶片收获期 | 40-60天 | 供食用的时期 |
| 抽薹开始 | 60-80天 | 中心隆起，茎向上抽出 |
| 花茎形成 | 80-100天 | 高60-120cm，分出枝杈 |
| 开花 | 90-110天 | 由下而上依次开放，持续20-30天 |
| 种子成熟 | 开花后12-24天 | 以单朵花为单位计算 |
| 种子收获 | 播种后120-150天 | 冠毛开始张开 |

&nbsp;&nbsp;&nbsp;这里要读懂的是最后一行。从播种到收种需要四个月到五个月。在韩国，3月底播种的春季生菜要到7月底至8月才能收到种子，而秋季栽培则因霜冻先到，种子无法成熟。所以留种要在春季栽培中进行。秋季生菜是用来吃的，春季生菜中的几株才是为了留种。

&nbsp;&nbsp;&nbsp;这个时间表也影响田间布局。留种株所占的位置要被占用四个多月，长到1m以上的花茎还会给旁边的作物投下阴影。把留种株集中到田边或北端这类遮荫无碍的位置，比较合理。

### 13-3. 与冠毛的较量

&nbsp;&nbsp;&nbsp;生菜的种子与蒲公英的种子结构相同。种子顶端带有冠毛，即白色的绒毛，一旦展开，就会乘风飞走。同属菊科，用的是同样的策略。问题在于，这些冠毛既是种子成熟的信号，同时也是种子即将丢失的时刻。花谢后十天到二十天左右，原本闭合的花萼张开，白色的绒毛团膨胀起来。再放一两天就会散开。而且花是从下方依次开谢的，所以同一株内种子成熟的时间相差3周以上。等全部成熟再收，就会丢掉先熟的那些。

| 方法 | 步骤 | 特点 |
|:---|:---|:---|
| 分批捋取 | 每2-3天一次，只用手捋取绒毛已膨胀的花序并收集 | 回收率最高，但费工 |
| 套袋 | 把纸袋或布袋套在花茎上，扎紧下口 | 即使飞散也留在袋内 |
| 整枝割取 | 花序一半以上膨胀时，连花茎一起割下 | 一次完成，但会混入未成熟的种子 |
| 铺布 | 在花茎下方铺布或草席 | 辅助手段。只在无风的日子有效 |

&nbsp;&nbsp;&nbsp;套袋在用工与回收率之间的平衡最好。要用透气的纸袋或稀疏的布袋，避免用塑料袋。因为塑料袋里会积湿气，种子会在袋内腐烂或发芽。套袋的时间在花谢后、绒毛即将出现之前；套得太早会长霉。整枝割下的花茎要倒挂起来，在麻袋或布上后熟一周到十天，那些看上去不够成熟的种子，也有相当一部分靠茎秆里剩余的养分而充实起来。

### 13-4. 精选与产量

&nbsp;&nbsp;&nbsp;抖落下来的是种子、冠毛和花萼碎屑混在一起的状态。冠毛比种子轻得多，所以可以借风分离。在有风的日子，放两个宽口容器，从高处慢慢倒下，重的种子落在下面，绒毛则被吹走。先用手搓揉把冠毛搓断，分离效果更好。

| 项目 | 数值 |
|:---|:---|
| 单株种子数 | 3,000-10,000粒 |
| 种子千粒重 | 约0.8-1.2g |
| 1㎡播种所需量 | 0.3-0.5g |
| 种子寿命 | 常温密封2-3年，凉爽干燥时3-5年 |
| 发芽率实用下限 | 70% |

&nbsp;&nbsp;&nbsp;一株能收几千粒种子，这一点很重要。一家人一年用的生菜种子，即使留得宽裕也只有几克，也就是一两株留种株的产量。留种并不需要腾出很大的地块。只要在春季生菜中选出叶片大、无病、直到很晚都没有抽薹的植株做好标记，然后原样留下即可。

> **留种株要从最晚抽薹的植株中挑选。晚抽薹性，也就是在高温中坚持到最后的性状，是可以遗传的。按这个标准连续挑选几年，这块田里的生菜就会逐渐更耐夏。**

### 13-5. 贮藏与高温休眠

| 项目 | 标准 |
|:---|:---|
| 干燥程度 | 用手搓能碎，用牙咬会发出“啪”的一声 |
| 保存容器 | 玻璃瓶、坛子、可密封的金属罐 |
| 干燥剂 | 炒过晾凉的大米、木炭、干燥的草木灰 |
| 保存位置 | 凉爽、阴暗、不潮湿的地方。地窖、朝北的储藏室、地下 |
| 检查 | 每年取20粒放在湿布上，几天后数发芽数 |

&nbsp;&nbsp;&nbsp;生菜种子的贮藏有一点需要特别注意：刚收的种子反而表现出较强的高温休眠。刚成熟的种子生理后熟尚未完成，仍残留发芽抑制物质，这提高了对温度的敏感性。因此，收获当年和次年年初的种子，比陈种子在更低的温度下就会停止发芽。

&nbsp;&nbsp;&nbsp;这一事实在实际操作中意味着什么，很清楚。在韩国，8月的秋播时地温已经很高，正好与高温休眠迎头相撞，而偏偏这时用的又是几个月前收的新种子。两个条件叠加，发芽率会大幅下降。种子可以保存2年到3年，所以把两年的种子叠放着、先用陈种子，这个冲突就会自然化解。如果必须马上使用新种子，就在完全干燥的状态下放在30-40℃的干燥处几天，让后熟提前完成。带着湿气加热会直接把种子烫死，所以一定要在彻底干透之后再做。

## 14. 毒性与需注意的成分

&nbsp;&nbsp;&nbsp;生菜没有急性毒性。它是洗净后直接食用的蔬菜，评价表中烹饪·加工的SS反映了这一事实。不过，有一种生菜特有的成分和一个叶菜类普遍存在的问题，值得了解一下。

| 成分 | 是什么物质 | 有什么影响 | 什么时候成为问题 |
|:---|:---|:---|:---|
| 莴苣乳（莴苣素、莴苣苦素） | 切断茎时流出的白色乳汁中的苦味成分 | 轻微的镇静作用和苦味 | 抽薹后急剧增加，变得难以入口 |
| 硝酸盐 | 根吸收的氮储存在叶中的形态 | 摄入过量时会成为问题 | 遮荫、光照不足、氮过多 |
| 草酸 | 与钙结合的有机酸 | 大量食用有结石风险 | 生菜含量低，实际上不构成问题 |

### 14-1. 莴苣乳

&nbsp;&nbsp;&nbsp;切断生菜的茎或叶脉，会渗出白色汁液。这种干燥后变成褐色并凝固的乳汁就是莴苣乳（lactucarium），学名Lactuca便由此而来。它原本的作用是防御：让啃食叶片的对象尝到苦味，并封住伤口。主要成分是莴苣素（lactucin）和莴苣苦素（lactucopicrin）这类倍半萜内酯，对人体有轻微的镇静和镇痛作用。19世纪的欧洲有把生菜乳汁凝固后制成的制剂用作镇静剂的记载，吃了生菜会犯困的说法也由此而来。不过，餐桌上吃的叶片中所含的量，远不足以让人感受到这种效果。

&nbsp;&nbsp;&nbsp;实际操作中重要的不是药效，而是苦味。乳汁浓度随生育阶段变化很大。

| 阶段 | 乳汁浓度 | 口味 |
|:---|:---:|:---|
| 嫩叶 | 极低 | 柔嫩，带点甜味 |
| 长成的叶片（抽薹前） | 低 | 适口 |
| 抽薹刚开始 | 急剧上升 | 后味发苦 |
| 开花期 | 极高 | 难以入口 |

&nbsp;&nbsp;&nbsp;为什么苦味会随抽薹而升高？答案在于植物优先目标的转换。花茎抽起的那一刻，生菜的目标从长叶转为结种子。从那时起，叶片成了为种子供应养分的来源，植物为了保护这笔资产，会增加防御物质的生产。同时，叶细胞中积累木质素而变得坚韧。这就是苦味和坚韧一同出现的原因。干旱胁迫和高温也朝同一个方向起作用，水分不足时，即使在抽薹之前，防御物质也会增加。夏季没有及时浇水的生菜格外苦，原因就在这里；凉爽且水分均匀的秋季生菜几乎没有苦味，也是同样的道理。

> **苦味不是毒性的信号，而是过了时节的信号。吃了并无危害，但难以继续吃下去，而这一刻就是这棵植株收获结束的节点。**

### 14-2. 硝酸盐

&nbsp;&nbsp;&nbsp;生菜在叶菜类中属于比较容易积累硝酸盐的一类。根吸收的氮以硝酸盐的形态上行，储存在叶片的液泡中，有光照时，在酶的作用下转化为氨基酸和蛋白质。这一转化需要光合作用产生的能量。因此，光照不足时，硝酸盐无法转化，就原样留在叶片中。

| 条件 | 硝酸盐积累 |
|:---|:---|
| 氮肥施用过多 | 大幅增加 |
| 阴天持续时 | 增加 |
| 在遮荫处栽培时 | 增加 |
| 清晨收获 | 夜间转化停止，含量高 |
| 晴天下午收获 | 白天已转化，含量低 |
| 外叶和叶柄 | 高于心叶 |

&nbsp;&nbsp;&nbsp;这里有一点需要说清楚：吃正常栽培的生菜，按普通的量食用，不成问题。硝酸盐本身不是毒物，人摄入的硝酸盐有相当一部分本来就来自蔬菜，而食用蔬菜的益处远远超过这一负担，这是目前的普遍认识。需要担心的是某种特定的组合：在氮肥施得过多的田里，在不太向阳的位置种出的生菜，不搭配其他蔬菜，每天大量食用。

&nbsp;&nbsp;&nbsp;在灾难情况下，这种组合比想象中更容易形成。稀释尿液频繁浇施，氮就会集中；在建筑物的阴影或狭小院子这类光照受限的位置种植；可吃的蔬菜只有生菜，饮食因而偏颇。应对办法就是不让这三个条件叠加。收获前几天停止氮源，把向阳的位置优先分给生菜，下午收获，并与其他叶菜轮换着吃。把叶片打成汁当主食一样喝，浓度会升高，要避免。

&nbsp;&nbsp;&nbsp;草酸在生菜中实际上不构成问题。莙荙菜和菠菜每100g含数百mg，而生菜只有几十mg的水平。这是不焯水、生吃也可以的原因之一。反倒是实际中更常见的风险不在成分，而在卫生。因为生吃，沾在泥土上的东西会原样入口。施了未充分发酵的粪肥的田地、洪水退去后的土地上长出的生菜，生食是危险的。生食是生菜的最大优点，同时也成了它的最大弱点，对此的应对办法就是把堆肥充分腐熟。
