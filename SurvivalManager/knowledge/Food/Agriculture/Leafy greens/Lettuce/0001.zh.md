## 引言
&nbsp;&nbsp;&nbsp;生菜（Lactuca sativa）是菊科叶菜，与十字花科的羽衣甘蓝、芥菜不同，和蒲公英、艾草、向日葵同科。祖先是自生于地中海和西亚一带的刺莴苣。综合等级为D（37.7分，有效183种中第135名），副食为SS（62.1分）。单位面积热量为D（每1,000㎡收获3,000kg也只有自给线的0.23倍），耐储性为E（无电力常温下2-3天），是所评作物中最低的，温度幅度也是C（15-22℃）。但生菜不是堆在仓库里的粮食，而是从田里直接进嘴的粮食。洗净就能直接吃，所以不用燃料（烹调·加工SS），只摘外叶可以连续长两三个月（持续性A），自花授粉，留种后性状也能保持（自留种S）。弱点是超过25℃就不发芽的高温休眠、遇热抽出的花茎和苦味、只有2-3年的种子寿命，以及菊科菌核病造成的2-3年休耕。生菜不是田里的支柱，而是田里的日常口粮。

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：蛋白质密度、设施负担、烹调·加工要求度。S：微量营养素（16种）、收获速度、口味、国内种植普及度、自留种。A：持续性、水消耗量、产量稳定性。B：施肥、光照、耐寒性、防治自立度、连作适应性、种子寿命 |

> **种生菜的目的不是填满仓库，而是让今晚的餐桌上有一抹绿色。仅就这个目的而言，可替代的作物并不多。**

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 菊科莴苣属一年生草本。十字花科的害虫和根肿病不会侵染，但菊科特有的菌核病和霜霉病也会传给菊苣、茼蒿、牛蒡 |
| 叶、茎 | 有绿色、红色、混合色的圆叶、皱叶、长叶。茎平时极短，叶片看起来像一簇簇长出，抽薹后才笔直长高。切开会流出白色乳汁（莴苣素，lactucarium） |
| 根、花、果实 | 直根向下，须根浅浅铺开。黄色头状花序。顶端带冠毛（白絮）的瘦果 |

| 阶段 | 时期（播种后） | 要点 |
|:---|:---|:---|
| 发芽、幼苗期 | 7天以内 | 种子确认光和温度后才发芽 |
| 营养生长期 | 7-30天 | 叶片快速增多，形成植株。氮 |
| 收获、再生收获期 | 30-110天 | 外叶先长足，摘后内侧长出新叶 |
| 抽薹、开花期 | 60-100天 | 茎抽起，叶片转苦。磷、钾 |

> **抽薹不是病，而是生菜生命中的正常过程。人吃的生菜只是那一生的前半段，栽培技术的一半在于能把这个转折点推迟多久。**

&nbsp;&nbsp;&nbsp;抽薹有三个条件：气温超过25℃的天数持续的高温，日照变长的长日照，以及缺水、伤根、过密等胁迫。这三者重叠的盛夏，生菜种不成。抽薹一开始，莴苣素浓度急剧升高，叶片变得又韧又苦。

&nbsp;&nbsp;&nbsp;每100g含热量20kcal、水分约95%（耐储性差的根本原因）、蛋白质1.88g（占热量的37.6%）、叶酸49㎍、维生素A（按β-胡萝卜素换算）354-717㎍。β-胡萝卜素在叶色越深、越靠外的叶片中越多，所以以营养为目的时，选叶色深、叶片散开的品系更有利。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽适温15-20℃（3-5天），25℃以上发芽率骤降。生长适温15-20℃，可达范围15-22℃，25℃以上持续则抽薹并变苦 |
| 光 | 每天6-8小时。遮光40%时相对产量86%。需光发芽。夏季遮光反而有利（降低地温，推迟抽薹） |
| 水、土壤 | 总蒸散量约350mm。排水好、有机质丰富的土壤，pH 6.0-6.6，垄高15-20cm。根浅，表土一干就立刻受影响 |

&nbsp;&nbsp;&nbsp;生菜种子超过一定温度就停止发芽。这是为了避免夏天萌发的幼苗在炎热干燥的地中海干死的设计，与需光性一起构成双重锁：只有在光线能到的浅处、土壤凉爽时才发芽。它耐半阴，所以放在楼房阴影、树下，或玉米、向日葵等高秆作物的北侧，把向阳的地方让给其他作物。

| 品种 | 特点 |
|:---|:---|
| 散叶生菜（chima类型） | 叶片散开，可再生收获，是灾害情况下的核心。青chima（cheongchima，最广泛栽培）、红chima（jeokchima，花青素）、青·红chukmyeon（皱叶） |
| 结球生菜、罗马生菜、奶油生菜 | 结球生菜拔一次就结束，是一次性作物；罗马生菜为半结球，可一定程度再生收获；奶油生菜叶片柔嫩，耐储性更差 |
| Jangsu、Tomalin | Jangsu在半阴和室内也能生长；Tomalin叶片厚、纤维多，不易萎蔫 |

&nbsp;&nbsp;&nbsp;灾害初期要最快收获，选青chima、红chima（嫩叶25-30天）；要种子自立，选定型种和地方品种。生菜自花授粉，并排种多个品种种子也不会混杂，混种两三个品种，抽薹时间和抗病性各异，能降低全军覆没的风险，对霜霉病也有用。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 深耕20-30cm，把土块打细整平（种子只有3mm多，掉进土块缝隙被深埋就不会发芽）。根浅，只打碎表层10cm也能长，排水差就起垄 |
| 施肥（1,000㎡） | 氮10-12kg，磷6-8kg，钾6-8kg，堆肥1,000-1,500kg，石灰100-150kg，在播种前1-2周全部作基肥施入。原则上不追肥（氮高则叶片变软、变苦、易感病），只有再生收获持续两个月以上时，才在摘叶后立即少量薄施 |
| 替代资源 | 腐熟堆肥（每1㎡ 1-1.5kg），草木灰（每1㎡一把，使pH不超过6.6），稀释15-20倍的尿液（比其他叶菜更稀），蛋壳粉 |

| 类型 | 播种 | 收获 | 备注 |
|:---|:---|:---|:---|
| 春季栽培 | 3月下旬-5月中旬 | 4月下旬-6月下旬 | 最常见。收获4-6周，以抽薹结束。种子只能在春天留 |
| 秋季栽培 | 8月上旬-9月上旬 | 9月上旬-11月上旬 | 灾害情况下最有利。8-10周，以霜冻结束 |
| 夏季、冬季 | 不推荐 | | 夏季发芽失败并过早抽薹，冬季只有南部保温条件下可行 |

&nbsp;&nbsp;&nbsp;秋季栽培的陷阱是8月上旬的炎热使地温超过25℃，种子就会休眠，所以秋播的真正技术是避开炎热让种子发芽。

| 高温休眠对策 | 方法 |
|:---|:---|
| 低温引发 | 种子用水泡4-6小时，用湿布包好，放在凉爽处（井水、地下室、朝北阴凉处）一天。最可靠。处理后立即播种并保持土壤不干（吸过水的种子干了会死） |
| 其他方法 | 先用湿布催芽再移出播种、日落后播种、用帘子、树枝、稻草搭出薄荫（出苗后撤去）、白天洒冷水降低地温 |

| 播种 | 标准 |
|:---|:---|
| 方法 | 深2-3mm，覆一层刚能遮住种子的细土，或只压实不覆土。行距20cm。密播后间苗 |
| 错期播种 | 不耐储存，所以每隔10到15天分三到四次播种。即使有一茬因病害失败，还有下一批 |
| 种子处理 | 种子用50-55℃的水泡10-15分钟再用冷水降温。刚收的种子高温休眠更强，所以备足两年的量交叠存放，先用旧种子 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种至幼苗期 | 轻浇勤浇，不让表土干 |
| 生长期 | 春秋每3-5天，夏季每2-3天。摘叶后也要浇水（干了恢复慢，可能加速抽薹） |
| 收获前、雨季 | 收获前稍微减少，雨季要保证排水沟畅通 |

&nbsp;&nbsp;&nbsp;缺水时生菜会让叶片变厚并提高莴苣素浓度，所以变苦。基部出现白霉和黑色颗粒就是菌核病，要丢弃这棵植株。浇水选在清晨，让叶片白天能干（霉菌病的发生与叶片潮湿的时间成正比）。稻草覆盖切断了雨滴溅起泥土、把孢子粘到叶背的途径，但会成为蛞蝓的藏身处，所以要与通风、排水配合使用。

| 管理 | 方法 |
|:---|:---|
| 间苗 | 2-3片真叶时留5cm做第一次，4-5片真叶时留15-20cm做第二次（最终）。迟了就只往上长，通风受阻而发生霉菌病。不要拔，用剪刀或指甲贴近地面剪断。间下的嫩生菜是第一次收获（25天左右几乎没有苦味，可包着吃或做沙拉） |
| 杂草 | 不需要培土。3-4片真叶以后用稻草或干草覆盖，杂草小时把小锄头浅浅放下，只刮表面 |

&nbsp;&nbsp;&nbsp;抽薹开始、中心抽出茎，这棵植株的收获就结束了，剪掉花茎，旁边还会再抽。嫩花茎和上面的叶片焯水泡去苦味后可以做凉拌菜，留几棵植株采种。要推迟抽薹，就用遮阴、覆盖、浇水降低地温，避免干旱胁迫、伤根和过密；要度夏的话，就放在高秆作物的北侧或楼房的阴影里。

## 6. 病虫害与养分问题
| 病虫害 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 菌核病 | 基部变软，出现白色菌丝和黑色颗粒（菌核）。低温高湿，菊科连作 | 深耕、覆盖、2-3年轮作、清除病株 |
| 霜霉病 | 叶面黄褐色斑点，叶背白霉。凉爽、叶片长时间潮湿时 | 通风、早晨浇水、品种混种、摘除病叶 |
| 灰霉病、基腐病、细菌性斑点病 | 灰色霉层（低温高湿） / 根颈变褐并倒伏（过湿） / 叶缘黑褐色斑点（高温高湿、伤口） | 湿度管理、保证间距 / 排水、基部周围留空 / 通风 |
| 蚜虫、蓟马 | 吸汁并传播病毒 / 银白色痕迹 | 肥皂水、保护瓢虫 / 黄色粘虫板、清除杂草 |
| 蛾类幼虫、蛞蝓 | 啃食叶片 / 孔洞和粘液痕迹 | 清晨捉虫、防虫网 / 夜间捉，撒灰、稻壳、蛋壳带 |

> **发现得了菌核病的植株，要连根周围的土一起挖起，搬出田外。不能放进堆肥堆。菌核能熬过堆肥的发酵热而存活，扩散到整块田。**

&nbsp;&nbsp;&nbsp;生菜的问题不在虫，而在霉菌。菌核积累的田里，也要避开茼蒿、菊苣、牛蒡，3-5年内种禾本科或豆科。生菜叶片柔嫩，肥皂水每1L不超过20g，避开中午喷洒，几小时后用清水冲洗。

| 症状 | 原因与处理 |
|:---|:---|
| 整片叶发黄，植株矮小 | 缺氮。腐熟堆肥，稀释15-20倍的尿液 |
| 内层叶尖枯成褐色（干烧心） | 水分运输不均，钙到不了新叶叶尖。均匀浇水，保证间距 |
| 叶片软嫩，或深绿色而苦味重 | 氮过量或干旱胁迫。按花茎、土壤干湿、叶色区分，停氮或浇水 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 小葱·大葱·胡萝卜（气味迷惑害虫），萝卜（生菜40-60天就腾出地方），玉米·向日葵（种在北侧，阴影可推迟抽薹） |
| 差 | 茼蒿、菊苣、牛蒡等菊科（共有菌核病和霜霉病），生菜连作（菌核积累） |

&nbsp;&nbsp;&nbsp;按4年周期，生菜等菊科→豆科（固氮）→玉米·高粱等禾本科→萝卜·大白菜等十字花科的顺序轮作，就能在菌核密度降低的状态下重新开始种生菜。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 嫩叶（沙拉、包菜）25-30天（与间苗结合），摘叶收获30-40天（外叶长15-20cm），整株收获40-60天 |
| 摘法 | 从下面外侧摘长足的叶片，每次不超过全部叶片的一半，始终留下中心叶六片以上，用剪刀在靠近茎处剪下（用手撕会留下伤口，成为病原菌入口）。摘后浇水 |
| 重复收获 | 每10-14天一次，平均2-3次，条件好时4-5次。一棵能收两三个月，花茎抽起就结束。十到二十棵能供一个人每天所需 |

> **始终留下六片以上的中心叶。留下的叶片是光合作用的工厂，这个工厂制造下一批叶片。贪心全摘光，这棵植株就会就此停住。**

&nbsp;&nbsp;&nbsp;生长点在植株中心短茎的顶端，摘外叶时依然保留，但把中心剪掉，这棵植株就完了（结球生菜是一次性作物的原因）。秋生菜一直持续到霜降，所以比春生菜持久。

| 留种 | 标准 |
|:---|:---|
| 授粉方式 | 在花开之前的花蕾阶段就完成授粉的自花授粉，异花授粉率为0-5%（通常1%左右）。隔离1-2m就够，一棵也可以 |
| 时间表 | 播种后60-80天开始抽薹，90-110天开花，开花后12-24天种子成熟，120-150天收获。秋季栽培霜冻先来、种子熟不了，所以留种在春季栽培进行 |
| 冠毛 | 冠毛一鼓起，一两天就散开，同一棵植株内成熟时间也相差3周以上。每2-3天只捋取鼓起的花（回收率最高），在白絮将现之前套上透气的纸袋或布袋（最均衡，避免塑料袋），或鼓起一半以上时连花茎割下倒挂后熟 |
| 精选、保存 | 一棵能收3,000-10,000粒。充分干燥后装入密封容器，放在凉爽、黑暗、不潮湿处。寿命常温密封2-3年，凉爽干燥则3-5年。每年用20粒检查发芽 |

> **留种株要从花茎抽得最晚的植株中选。因为晚抽薹，也就是在高温中撑到最后的性状是遗传的。按这个标准连选几年，那块田的生菜就会逐渐更耐夏。**

## 9. 储存
| 方法 | 步骤与期限 |
|:---|:---|
| 茎插水 | 把基部切掉1cm，立在盛着浅水的容器里。3-5天。每天换水并重新切基部 |
| 湿布、湿稻草 | 不洗，用湿布包好放在凉爽处3-4天 / 层层平放在湿稻草之间3-5天 |
| 地窖、土窖 | 凉爽的地下空间（全年10-15℃）里与湿布一起放5-7天。不要完全堵住通气，也不要混入烂叶 |
| 加工 | 焯水晒干（6个月至1年，口感崩坏）、水泡菜（1-2周）、盐渍型（盐10%以上，几个月，只能做汤料） |

> **解决生菜储存问题的办法不在储存技术，而在播种计划。每隔10到15天分批播种、只摘外叶来吃，就根本不需要储存。站在田里的生菜是最好的仓库。**

&nbsp;&nbsp;&nbsp;生菜含水量超过95%，叶片薄而宽、蒸发快，支撑组织的是细胞内的水压，稍有流失就萎蔫，切口的乳汁变褐，腐败就开始了。让它撑几天的技术只有保住水分和降低温度，而洗过之后会形成水膜、腐败菌扩散，所以吃之前再洗。

## 10. 烹调与注意事项
| 方式 | 要领 |
|:---|:---|
| 包菜 | 整片叶子包饭和小菜吃。打破以谷物为主的饮食单调的最简单办法 |
| 凉拌 | 切粗块用盐略腌，用调料拌。叶子变软、体积缩小，吃得更多，所以在灾害情况下特别实用 |
| 沙拉、水泡菜 | 拌入油或紫苏籽粉可提高脂溶性维生素A·E·K的吸收 / 在2-3%盐水里放一两天，维生素C能保留相当一部分 |
| 焯水、生菜茎 | 用沸水焯20-30秒，苦味去掉、质地变软，适合因抽薹而变韧的时期 / 茎去皮，泡在盐水里去掉苦味后炒或拌，用盐腌后放进酱里能保存几个月 |

&nbsp;&nbsp;&nbsp;生菜洗净就能吃，不需要烹调燃料。维生素C、叶酸和部分B族维生素怕热又溶于水，焯水会流失很多，而生菜没有这种损失。

| 成分 | 问题与对策 |
|:---|:---|
| 莴苣素 | 切开茎流出的白色乳汁中的苦味成分。有轻微镇静作用，但吃的量感觉不到。抽薹后急剧升高，开花期难以食用。苦味不是毒性，而是时期已过的信号 |
| 硝酸盐 | 在阴暗、光照不足、氮过量时增加。把施氮过多的阴暗田里的生菜不配其他蔬菜、每天大量吃时才成问题。收获前几天停止氮源，把向阳处优先留给生菜，下午收获，并与其他叶菜交替食用 |
| 草酸 | 含量低，不是实际问题 |

&nbsp;&nbsp;&nbsp;生菜没有急性毒性。

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查种子和发芽率，翻堆堆肥，制定轮作计划 |
| 3-4月 | 3月下旬春播（基肥、起垄）。4月间苗和定植，收嫩叶，观察蛞蝓 |
| 5-6月 | 5月正式收获，每10-14天再生收获。6月开始抽薹，标记留种株后清理其余 |
| 7-8月 | 7月留种株开花结实，空地种夏季作物。8月收种子并精选，月初起秋播（应对高温休眠） |
| 9-10月 | 9月间苗和定植，第二次播种，观察霜霉病。10月正式收获，是再生收获最长的月份 |
| 11-12月 | 11月继续收获，盖稻草、设防风障，下旬清理。12月清理田地和处理残余物（病株移出田外） |

&nbsp;&nbsp;&nbsp;春天为了留种而种，秋天为了吃而种，中间的夏季和冬季由马齿苋、蕹菜、羽衣甘蓝、芥菜等其他作物填补。

> **一年十二个月里，生菜上餐桌的月份只有四个多月。知道这一点，并规划另外八个月用什么来填，在灾害情况下比把生菜种好的技术更重要。**
