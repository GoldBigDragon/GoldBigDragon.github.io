## 13. 採種 - 自家受精という利点

&nbsp;&nbsp;&nbsp;評価表の自家採種の等級はSで、根拠欄には「自家受精、純系維持」という短い一文が書かれています。この一行が、サンチュの採種のほとんどすべてを説明しています。ケールが500mの隔離と複数株の同時開花を求め、ダイコンが1kmの隔離を求めるところで、サンチュは一株だけ残しても種が採れ、その種から同じサンチュが育ちます。

### 13-1. なぜ混ざらないのか

&nbsp;&nbsp;&nbsp;サンチュの花は、キク科特有の頭状花序です。小さな小花が十個から二十個集まって一つの黄色い花の塊をつくり、その花の塊がまるごと、朝の一、二時間だけ開いて閉じます。大事なのは、その開く時点です。サンチュは花が開く前、まだつぼみが閉じている段階で、すでにおしべが花粉を出し、その下のめしべが受け取ってしまいます。花が開いたときには、受精が終わっています。そのため、ハチが訪れても遺伝子はほとんど混じりません。実測の他家受精率は条件によって0-5%の間で、おおむね1%前後です。

| 作物 | 受精方式 | 実用的な隔離距離 | 採種株の最小個体数 |
|:---|:---|:---:|:---:|
| サンチュ | 自家受精（閉花受精に近い） | 1-2m | 1株でも可能 |
| ケール・キャベツ | 他家受精（虫媒）、自家不和合性 | 500m以上 | 5-10株 |
| ダイコン | 他家受精（虫媒）、自家不和合性 | 1,000m以上 | 10株以上 |
| フダンソウ・ビーツ | 他家受精（風媒） | 1,000m以上 | 10株以上 |

> **サンチュの採種に必要な隔離は1-2m、他の品種の花茎と互いに触れ合わない程度で十分です。狭い畑でも、複数の品種の種を同じ年に採れるという意味です。**

&nbsp;&nbsp;&nbsp;完全な0%ではないため、品種を長く維持するには二つのことを加えます。採種用の株の間に別の作物を一列挟んで間隔を空けること、そして翌年育った苗の中に品種の特性と異なる個体が見えたら抜き取ることです。この作業を数年繰り返すと、純度はむしろ上がります。

### 13-2. 抽だいから種子までの時間

| 段階 | 播種後 | 状態 |
|:---|:---:|:---|
| 葉の収穫期 | 40-60日 | 食べるための時期 |
| 抽だい開始 | 60-80日 | 中心が盛り上がり、茎が伸びてきます |
| 花茎の完成 | 80-100日 | 高さ60-120cm、枝が分かれます |
| 開花 | 90-110日 | 下から上へ順に、20-30日かけて咲きます |
| 種子の成熟 | 開花後12-24日 | 花一つを単位に数えます |
| 種子の収穫 | 播種後120-150日 | 冠毛がほころび始めます |

&nbsp;&nbsp;&nbsp;ここで読み取るべきなのは最後の行です。播種から種子まで四か月から五か月かかります。韓国では、3月末にまいた春のサンチュは7月末から8月に種が採れることになりますが、秋の栽培では霜が先に降りて種子が熟しません。したがって採種は春の栽培で行います。秋のサンチュは食べるためのものであり、春のサンチュのうち数株が種のためのものです。

&nbsp;&nbsp;&nbsp;この時間表は畑の配置にも影響します。採種株が立つ場所は四か月以上ふさがり、1m以上に伸びた花茎が隣の作物に影を落とします。畑の縁や北の端のように、日陰が問題にならない場所に採種株を集めるのが合理的です。

### 13-3. 冠毛との闘い

&nbsp;&nbsp;&nbsp;サンチュの種子はタンポポの種と同じ構造です。種の先に冠毛、つまり綿毛と呼ばれる白い毛が付いていて、これが広がると風に乗って飛んでいきます。同じキク科なので、同じ戦略を使います。問題は、この冠毛が、種が熟したという合図であると同時に、種を失う瞬間でもあるという点です。花が終わって十日から二十日ほどたつと、閉じていた萼が開き、白い綿の塊がふくらんできます。あと一、二日置けば散ってしまいます。しかも下の花から順に咲いて終わるため、一株の中で熟す時期が3週間以上にわたってずれます。すべて熟すのを待つと、先に熟したものを失います。

| 方法 | 手順 | 特徴 |
|:---|:---|:---|
| 分けてしごき取る | 2-3日に一度、綿毛がふくらんだ花だけを手でしごいて容器に入れます | 回収率が最も高い方法です。手間がかかります |
| 袋がけ | 紙袋や布袋を花茎にかぶせ、下を結びます | 飛んでも袋の中に残ります |
| 丸ごと刈る | 花の半分以上がふくらんだら花茎ごと刈ります | 一度で終わりますが、未熟な種が混じります |
| 布を敷く | 花茎の下に布やむしろを敷きます | 補助手段。風のない日にだけ有効です |

&nbsp;&nbsp;&nbsp;袋がけは、労力と回収率のバランスが最もよい方法です。通気性のある紙袋や目の粗い布袋を使い、ビニールは避けます。ビニールの中では湿気がこもり、種が袋の中で腐ったり、芽が出たりするからです。袋をかぶせる時期は、花が終わって綿毛が見える直前で、早すぎるとカビが生えます。丸ごと刈った花茎は、逆さに吊るして、袋や布の上で一週間から十日追熟させると、未熟に見えた種も、茎に残った養分でかなりの数が充実します。

### 13-4. 精選と収量

&nbsp;&nbsp;&nbsp;振るい落としたものは、種と冠毛と萼のくずが混ざった状態です。冠毛は種よりはるかに軽いので、風で選り分けられます。風のある日に広い器を二つ置き、高い所からゆっくり注ぎ落とすと、重い種は下に落ち、綿毛は飛んでいきます。手でもんで冠毛をあらかじめ折っておくと、さらによく選り分けられます。

| 項目 | 値 |
|:---|:---|
| 一株の種子数 | 3,000-10,000粒 |
| 種子1,000粒の重さ | 約0.8-1.2g |
| 1㎡の播種に必要な量 | 0.3-0.5g |
| 種子寿命 | 常温密閉で2-3年、涼しく乾燥していれば3-5年 |
| 発芽率の実用下限 | 70% |

&nbsp;&nbsp;&nbsp;一株から数千粒が採れるという事実が重要です。一家族が一年に使うサンチュの種は、多めに見積もっても数gで、採種株一、二株から採れる量です。採種は、畑を大きく割く作業ではありません。春のサンチュのうち、葉が大きく、病気がなく、遅くまで花茎が立たなかった株に印を付けておき、そのまま残せばよいのです。

> **採種株は、最も遅く花茎が立った株から選びます。晩抽性、つまり暑さの中で遅くまでもちこたえる性質が遺伝するからです。数年この基準で選ぶことを繰り返すと、その畑のサンチュが少しずつ夏に強くなります。**

### 13-5. 貯蔵と高温休眠

| 項目 | 基準 |
|:---|:---|
| 乾燥の程度 | 手でもむと砕け、歯で噛むとパチッと音がするまで |
| 保管容器 | ガラス瓶、甕、密閉できる金属缶 |
| 乾燥剤 | 炒って冷ました米、炭、乾いた草木灰 |
| 保管場所 | 涼しくて暗く、湿気のない場所。室（むろ）、北向きの物置、地下 |
| 確認 | 毎年20粒を濡れた布に置き、数日後に発芽数を数えます |

&nbsp;&nbsp;&nbsp;サンチュの種子の貯蔵には、特に注意すべき点が一つあります。採りたての種子のほうが、かえって高温休眠が強く現れるということです。採りたての種子は生理的な追熟が終わっておらず、発芽抑制物質が残っていて、これが温度感受性を高めます。そのため、収穫した年とその翌年の初めの種子は、古い種子よりも低い温度で発芽が止まります。

&nbsp;&nbsp;&nbsp;この事実が実務で意味することは明らかです。韓国での8月の秋まきは、地温がすでに高く、高温休眠と真正面からぶつかる時期ですが、よりによってそのときに使うのが数か月前に採った新しい種子です。二つの条件が重なると、発芽率が大きく落ちます。種子は2年から3年もつので、二年分を重ねて置き、古いものから使えば、この衝突は自然に解消されます。どうしても新しい種子をすぐ使う必要がある場合は、完全に乾燥させた状態で、30-40℃ほどの乾いた場所に数日置いて追熟を早めます。湿気を含んだまま温めるとそのまま死んでしまうので、必ずからからに乾いてから行います。

## 14. 毒性と注意すべき成分

&nbsp;&nbsp;&nbsp;サンチュに急性毒性はありません。洗ってそのまま食べる野菜であり、評価表の調理・加工SSがその事実を反映しています。ただし、サンチュ特有の成分一つと、葉菜類全般の問題一つは、知っておく必要があります。

| 成分 | どんな物質か | どんな影響があるか | いつ問題になるか |
|:---|:---|:---|:---|
| ラクツカリウム（ラクツシン、ラクツコピクリン） | 茎を切ると出る白い乳液の苦味成分 | 軽い鎮静作用と苦味 | 抽だい後に急激に増えて食べにくくなります |
| 硝酸塩 | 根が吸収した窒素を葉に蓄えた形 | 過剰に摂取すると問題になります | 日陰、低光量、窒素過多 |
| シュウ酸 | カルシウムと結合する有機酸 | 大量に食べると結石のリスク | サンチュは含有量が低く、実質的な問題ではありません |

### 14-1. ラクツカリウム

&nbsp;&nbsp;&nbsp;サンチュの茎や葉脈を切ると、白い汁がにじみ出ます。乾くと褐色に固まるこの乳液がラクツカリウムで、学名のLactucaはここから来ています。本来の目的は防御です。葉をかじるものに苦味を与え、傷口をふさぎます。主成分はラクツシンとラクツコピクリンというセスキテルペンラクトン類で、人に軽い鎮静と鎮痛の作用をもたらします。19世紀のヨーロッパでは、サンチュの乳液を固めて作った製剤が鎮静剤として使われた記録があり、サンチュを食べると眠くなるという通念もここから生まれました。ただし、食卓で食べる葉に含まれる量は、その効果を体感できる水準にはるかに及びません。

&nbsp;&nbsp;&nbsp;実務で重要なのは薬効ではなく苦味です。濃度は生育段階によって大きく変わります。

| 段階 | 乳液の濃度 | 味 |
|:---|:---:|:---|
| 若葉 | 非常に低い | 柔らかく甘みがあります |
| 育ち切った葉（抽だい前） | 低い | 食べやすいです |
| 抽だい直後 | 急激に上昇 | 後味が苦いです |
| 開花期 | 非常に高い | 食べにくいです |

&nbsp;&nbsp;&nbsp;なぜ抽だいとともに苦味が増すのかという問いの答えは、植物の優先順位の転換にあります。花茎が立つ瞬間、サンチュの目標は、葉を育てることから、種をつくることへと切り替わります。その時点から葉は種のための養分の供給源となり、植物はその資産を守ろうと、防御物質の生産を増やします。同時に、葉の細胞にリグニンが蓄積して硬くなります。苦味と硬さが一緒に現れる理由です。乾燥ストレスと高温も同じ方向に働き、水が足りないと、抽だい前でも防御物質が増えます。夏に水を適時に与えられなかったサンチュが格別に苦いのはこのためであり、涼しくて水が均一な秋のサンチュに苦味がほとんどないのも、同じ理由です。

> **苦味は毒性のサインではなく、時期が過ぎたというサインです。食べて害になるわけではありませんが、食べ続けるのは難しく、その時点がその株の収穫の終わりです。**

### 14-2. 硝酸塩

&nbsp;&nbsp;&nbsp;サンチュは、葉菜類の中では硝酸塩を比較的ためやすいほうです。根が吸収した窒素は硝酸塩の形で上がってきて葉の液胞に蓄えられ、光があるときに酵素の働きでアミノ酸やタンパク質に変わります。この転換には、光合成がつくるエネルギーが必要です。したがって光が足りないと、硝酸塩が転換されず、葉にそのまま残ります。

| 条件 | 硝酸塩の蓄積 |
|:---|:---|
| 窒素施肥の過多 | 大きく増えます |
| 曇りの日が続くとき | 増えます |
| 日陰で育てるとき | 増えます |
| 早朝の収穫 | 夜の間に転換が止まるため高くなります |
| 晴れた日の午後の収穫 | 昼に転換されて低くなります |
| 外葉と葉柄 | 内側の葉より高くなります |

&nbsp;&nbsp;&nbsp;ここではっきりさせておくべきことがあります。通常どおりに育てたサンチュを普通の量で食べることは、問題になりません。硝酸塩そのものは毒ではなく、人が摂取する硝酸塩のかなりの部分はもともと野菜に由来し、野菜を摂るメリットがその負担をはるかに上回るというのが、現在の一般的な理解です。心配すべきなのは、特定の組み合わせです。窒素肥料を過剰に与えた畑で、日当たりのよくない場所で育てたサンチュを、ほかの野菜なしで毎日大量に食べる場合です。

&nbsp;&nbsp;&nbsp;災害時には、この組み合わせは思いのほか簡単にできあがります。薄めた尿を頻繁に与えると窒素が集中し、建物の陰や狭い庭のように日当たりが限られた場所で育てることになり、食べる野菜がサンチュしかなくて偏ります。三つの条件が重ならないようにすることが対応です。窒素源は収穫の数日前から断ち、日の当たる場所をサンチュに優先的に割り当て、午後に収穫し、ほかの葉菜類と交互に食べます。葉をすりつぶして作った汁を主食のように飲む方法は、濃度が高くなるので避けます。

&nbsp;&nbsp;&nbsp;シュウ酸は、サンチュでは実質的な問題になりません。フダンソウとホウレンソウが100gあたり数百mgを含むのに対し、サンチュは数十mg程度です。ゆでずに生で食べてもよい理由の一つです。むしろ実務でより頻繁な危険は、成分ではなく衛生です。生で食べるため、土に付いたものがそのまま口に入ります。し尿を十分に発酵させずに与えた畑や、洪水が通り過ぎた土地で育ったサンチュは、生食が危険です。サンチュの最大の長所である生食が同時に最大の弱点にもなる点であり、堆肥を十分に腐熟させることがその対応です。
