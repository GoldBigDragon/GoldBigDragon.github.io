## 8. 栽培管理 - 結球を作る条件

&nbsp;&nbsp;&nbsp;玉レタス栽培において、他のすべての作業は一つの目的のために行われます。結球を成立させることです。結球しなければ三か月の労働が無に帰すため、この節は実質的にこの作物の成否を扱います。

### 8-1. 結球が失敗する条件

| 原因 | どうなるか | なぜそうなるか |
|:---|:---|:---|
| 高温 | 葉が開いたまま育ち、花茎が立ちます | 葉の下面と上面の生長速度の差がなくなります |
| 窒素過多 | 葉が大きく茂っているのに中が空いています | 栄養生長が止まらず、巻く段階に移れません |
| 定植の遅れ | 外葉が不十分で結球を始められません | 根が絡んだ苗が活着に時間を使います |
| リン酸不足 | 結球が緩く軽いです | リン酸は細胞分裂とエネルギー代謝に必要です |
| 結球期の水分不足 | 中が詰まりません | 細胞を膨らませる水がありません |
| 光量不足 | 結球が緩いです | 糖が足りず葉が軽いです |
| 密植 | 互いを覆い合い、光と養分を奪い合います | |

&nbsp;&nbsp;&nbsp;この表で最も頻繁に起こるのは前の三つです。高温、窒素過多、定植の遅れ。三つとも結球期には手を打てず、それ以前に決まります。

> **結球失敗は結球期に起きる事故ではなく、それ以前の二か月の結果が現れる瞬間です。葉が開き始めた後にできることはほとんどありません。播種日を決める時点、苗を植え替える時点、窒素を止める時点で既に決まっています。**

### 8-2. 三つを合わせる方法

&nbsp;&nbsp;&nbsp;高温への対応は時期の選択のみです。結球が始まる頃の平均気温が15-18℃になるように播種日を逆算します。播種から結球開始までおよそ二か月なので、その地域で気温が18℃を下回る時点の二か月前が秋播種の基準日になります。韓国中部では8月下旬、南部では9月初旬あたりです。年ごとに天候が違うので、この基準日には安全策を取りつつ、霜が来る前に結球を終えられる限界線も併せて見る必要があります。

&nbsp;&nbsp;&nbsp;窒素への対応は時期を分けることです。外葉が育つ定植後2-5週の間に窒素を集中して与え、結球が始まる頃には完全に止めます。自然資材は効果が遅く出るので、薄めた尿は定植後3週の1回目の追肥が最後と見るのが安全です。発酵の浅い堆肥を元肥として多く入れた場合、それ自体が結球期まで窒素を出し続けることがあるので、堆肥は必ず完全に発酵したものを使います。

&nbsp;&nbsp;&nbsp;定植時期への対応は、苗を見る目にかかっています。本葉4-5枚、根が育苗トレーの土を軽くつかんでいる状態が適期です。天候が悪くて移せない状況なら、育苗トレーを涼しい場所に移し水を減らして生長を遅らせますが、その遅れが一週間を超えると結球の時点がずれ始めます。

### 8-3. その他の管理

| 作業 | 時期 | 内容 |
|:---|:---|:---|
| 欠株補植 | 定植後1週 | 枯れた場所に新しい苗を入れます |
| 除草 | 初期 | 雑草が小さいうち。根が浅いため深く除草すると傷みます |
| 土寄せ | 生育中期に1回 | 株元に土を軽く。塊が重くなって倒れるのを防ぎます |
| 外葉整理 | 随時 | 黄色く枯れた下葉を取り除きます |
| マルチングの点検 | 随時 | 風でめくれた場所を覆います |

&nbsp;&nbsp;&nbsp;土寄せは過剰にするとむしろ害になります。株元が土に埋まると、そこから軟腐病が始まるからです。株が倒れない程度に、ごく浅く行います。

&nbsp;&nbsp;&nbsp;黄色く枯れた下葉を取り除く作業は、思うより重要です。死んでいく組織は灰色かび病の足場になり、そこで育った菌が健康な葉へ移っていきます。ただ、取り除く際に株元に傷をつけると、その傷が病気の入り口になるので、葉柄をつかんで横に折り、きれいに取り除きます。取り除いた葉は畑に捨てず、遠くへ運ぶか堆肥の山の深くに埋めます。

## 9. 病害虫 - 薬を使わずに防ぐ方法

&nbsp;&nbsp;&nbsp;玉レタスの病害虫圧はC、無防除時の減収率推定50.6%でサンチュと同じです。同じ種なので当然です。ただ、結球という形態が二つの違いを生みます。一つは結球の内側が湿って空気が通らず、細菌性の軟腐病に弱いということ、もう一つは病気が結球の中で進行すると外から見えず発見が遅れるということです。

### 9-1. 主な病害

| 病害 | 症状 | 発生条件 | 薬を使わない対応 |
|:---|:---|:---|:---|
| べと病 | 葉の表面に黄褐色の斑点、裏面に白いかび | 涼しく湿っているとき、葉が長く濡れているとき | 通風、朝の灌水、抵抗性品種、病葉の除去 |
| 軟腐病 | 株元と中が軟らかくなって崩れ、悪臭がします | 高温多湿、排水不良、傷 | 畝を高くする、排水、傷をつけない |
| 菌核病 | 株元が軟らかくなり、白い菌糸と黒い粒 | 低温多湿、キク科の連作 | 深耕、マルチング、2-3年の輪作、罹病株の完全な除去 |
| 灰色かび病 | 褐色斑点の上に灰色のかび | 低温多湿、通風不良 | 湿度管理、間隔の確保、枯れ葉の除去 |
| うどんこ病 | 葉の表面に白い粉 | 乾燥して日較差が大きいとき | 通風と日照の確保、牛乳の希釈液 |
| 株腐病 | 地際部が褐変し株が倒れます | 過湿、深植えしたとき | 浅植え、排水 |

&nbsp;&nbsp;&nbsp;玉レタスで最も特徴的な病気は軟腐病です。細菌が引き起こす病気で、傷と水がある場所から始まります。結球の内側は湿気がこもりやすく空気が通らないため、細菌が育ちやすい環境です。外葉は問題なさそうでも切ってみると中が軟らかくなっているのがこれで、こうなると手の打ちようがありません。

> **軟腐病は治療ではなく、条件管理の問題です。水を溜めないこと、株元を土に埋めないこと、収穫時に傷をつけないこと、雨が降った直後には収穫しないこと。この四つが、薬なしでできることの全てであり、実際に効果のあることの全てです。**

&nbsp;&nbsp;&nbsp;べと病は玉レタスで最も多い病気です。評価表の防除自立度Bに付いた根拠は、まさにこの病気に関するものです。有機栽培の実証で品種混植を試験しましたが、マルチングだけでは商業的な防除は不可能で、中程度に発生すると損失は最低10%だったという内容です。薬なしでべと病を防ぐのは容易ではないという意味です。

&nbsp;&nbsp;&nbsp;ただ、発生条件がはっきりしているので対応の方向もはっきりしています。葉が濡れている時間が長いほど悪化します。そのため水は早朝に与えて日中に乾かし、溝に注いで葉を濡らさず、間隔を十分に取って空気を通します。抵抗性品種があれば、それが最も確実な手段です。品種を混植すると、一つの系統に弱い病原菌が畑全体に広がる速度を遅らせることができます。

&nbsp;&nbsp;&nbsp;菌核病はサンチュと共有する土壌伝染病です。病株の株元にできる黒く硬い菌核が土に落ちて数年生き残り、条件が合えば再び発芽します。連作適応性B、2年から3年の休作という基準は、この菌核のためです。

> **菌核病にかかった株は、根の周りの土まで一緒にすくって畑の外へ運びます。堆肥の山に入れてはいけません。菌核は堆肥の発酵熱に耐えて生き残り、畑全体に広がります。**

### 9-2. 主な害虫

| 害虫 | 被害 | 薬を使わない防除 |
|:---|:---|:---|
| アブラムシ | 葉の裏で汁を吸い、ウイルスを媒介します | 石鹼水の噴霧、テントウムシとアブラバチの保護、抵抗性品種 |
| アザミウマ | 葉を削って汁を吸い、銀白色の跡を残します | 黄色粘着トラップ、周辺雑草の除去 |
| 蛾の幼虫 | 葉を食べ、結球の中に入り込みます | 早朝の手による捕殺、防虫網 |
| ナメクジ | 葉に穴を開け、粘液の跡を残します | 夜間の手による捕殺、灰や籾殻の帯 |
| ネダニ | 根を食べて株がしおれます | 輪作、排水の改善 |

&nbsp;&nbsp;&nbsp;結球型で特に厄介なのは蛾の幼虫です。葉が巻き始めると幼虫がその中に入り込み、その後は手が届きません。外からは見えないまま内部を食べ、糞を残し、その糞と傷が軟腐病を招きます。対応は、結球が始まる前に個体数を減らしておくことです。定植直後から葉の裏を見て卵塊を探して取り除き、余裕があれば結球開始前まで目の粗い網をかけて蛾の産卵そのものを防ぎます。結球が始まった後では遅すぎます。

&nbsp;&nbsp;&nbsp;ナメクジはサンチュと同様に厄介です。日中は藁の下や石の下に隠れていて夜に出てくるので、夜に灯りを持って出て捕まえるのが最も確実です。株の周りに乾いた草木灰や籾殻や卵の殻を帯のように巡らせると、体が乾くのを嫌って越えてきませんが、雨が降ると効果が消えます。マルチングが隠れ家になる問題も同じなので、株元周りは手のひら程度の広さを空けておく折衷策を使います。

### 9-3. 天然防除剤と耕種的防除

| 防除剤 | 調製法 | 対象 |
|:---|:---|:---|
| 石鹼水 | 無香料の石鹼20gを水1Lに溶かします | アブラムシ、ダニ |
| 牛乳の希釈液 | 牛乳と水を1対9で混ぜます | うどんこ病 |
| 草木灰液 | 草木灰を水に24時間浸けてろ過して使います | アブラムシ |
| 草木灰の帯 | 株の周りに乾いた灰を撒きます | ナメクジの遮断 |
| 黄色粘着トラップ | 黄色い板に粘着剤を塗って立てます | アザミウマ、有翅アブラムシ |
| 木酢液 | 300-500倍に希釈して噴霧します | 忌避効果、病気の抑制 |

| 原則 | 内容 |
|:---|:---|
| 輪作 | キク科を2-3年、菌核病があった場合はそれ以上休みます |
| 通風 | 植栽間隔を狭めません。最も安価な防除手段です |
| 排水 | 畝を高くします。軟腐病対策の根本です |
| 灌水の時刻と位置 | 早朝に溝へ与えます |
| マルチング | 雨水の跳ねを防ぎ、土壌伝染の経路を断ちます |
| 窒素管理 | 過剰だと組織が軟らかくなり、アブラムシが集まります |
| 残渣処理 | 病株は土まで含めて遠くへ運ぶか焼却します |
| 高温期の回避 | 夏栽培を避けること自体が防除です |
| 抵抗性品種 | 種子にあらかじめ組み込まれた防除手段です |

&nbsp;&nbsp;&nbsp;玉レタスに石鹼水を使うときは濃度を守らなければなりません。葉が薄くて柔らかいため、濃度が少し高いだけでも傷み、傷んだ場所が軟腐病の入り口になります。1Lに20gを超えないようにし、撒いた後数時間経ってから清潔な水で洗い流すと傷みが減ります。真昼を避け、早朝か日が沈んだ後に撒きます。

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 天然素材による対処 |
|:---|:---|:---|
| 葉全体が黄色く株が小さいです | 窒素欠乏 | 完熟堆肥、尿15-20倍希釈。結球期前まで |
| 葉の縁が茶色く枯れます | カリウム欠乏 | 草木灰を少量 |
| 生育が悪く葉が紫色を帯びます | リン酸欠乏 | 骨粉、草木灰。地温が低いときも同じ症状が出ます |
| 結球が緩く軽いです | リン酸とカリウムの不足 | 元肥の段階で決まります |
| 内葉の先端が茶色く枯れます | カルシウム移動の障害 | 均一な灌水、通風の確保。卵の殻は長期対策 |
| 葉脈の間が黄色くなります | マグネシウム欠乏 | 堆肥を増やします |
| 葉が大きく濃い青色なのに中が空いています | 窒素過剰 | 窒素の供給を止めます |

&nbsp;&nbsp;&nbsp;玉レタスで特徴的な欠乏症状は二つです。一つはチップバーンで、もう一つは結球不良です。どちらも外から見えにくいという共通点があります。

&nbsp;&nbsp;&nbsp;チップバーンは内葉の先端が茶色く焼けるように枯れる症状です。カルシウムが新しく育つ葉の先端まで届かずに起こり、土にカルシウムがないからというより、水の流れがそこまで届かないために起こります。カルシウムは蒸散によって生じる流れに乗って移動しますが、結球の内側の葉は幾重にも包まれて蒸散がほとんど起こりません。玉レタスがサンチュよりチップバーンがひどい理由がこれです。対応は土にカルシウムを入れることではなく、水分を均一に保ち、湿度が高すぎないようにし、密植を避けることです。

&nbsp;&nbsp;&nbsp;結球不良はリン酸とカリウムが不足しているとき、または窒素が過剰なときに現れます。見た目はよく育っているように見えても、収穫して押してみるとぐっと沈み、重さが出ません。この時点では手を打てないので、判断は元肥の段階で行わなければなりません。リン酸は土の中で動かないので耕すときに混ぜ込む必要があり、窒素は自然資材の効果が遅く出ることを考慮して早めに止めなければなりません。

&nbsp;&nbsp;&nbsp;窒素過剰は玉レタスにおいて欠乏より危険な場合が多いです。葉が大きく濃い緑なのでよく育っているように見えますが、組織が軟らかく細胞壁が薄いため軟腐病や灰色かび病に弱くなり、アブラムシが集まります。何より栄養生長が止まらず結球に移れません。茂っているのに中が空いている株は、たいていここから来ます。

## 11. 間作と輪作

| 相性 | 対象 | 効果 |
|:---:|:---|:---|
| 良い | マメ科作物（エンドウ、インゲンマメ、ササゲ） | 窒素を固定して残してくれます |
| 良い | アサツキ、長ネギ、ニンニク | 匂いが害虫を混乱させます |
| 良い | ダイコン、ハクサイなどアブラナ科 | 病害虫を共有せず、根の深さが異なります |
| 良い | ディル、コリアンダーなど香りの強いもの | アブラムシの天敵を呼び込みます |
| 悪い | サンチュ、シュンギク、チコリ、ゴボウなどキク科 | 菌核病とべと病を共有します |
| 悪い | 玉レタスの連作 | 菌核が蓄積します |

&nbsp;&nbsp;&nbsp;玉レタスとサンチュを同じ畑に隣接させて植えるのは避けた方がよいです。同じ種なので病害虫を完全に共有し、べと病が一方で始まるとすぐにもう一方へ広がります。二つの作物を一緒に育てるなら、畑の両端に離して置きます。

&nbsp;&nbsp;&nbsp;玉レタスは定植間隔が広く、初期には空いた土地が多くあります。この空間を使う方法が間作です。ただ、間に植える作物が玉レタスより大きくなると光を遮り結球を妨げるので、背が低く早く終わるものでなければなりません。ベビーリーフ用のサンチュやアサツキ、ホウレンソウ程度が合います。キク科の病気を共有する点から、間にサンチュを入れるのは慎重を要し、代わりにアブラナ科の若い野菜が無難です。

| 輪作順の例 | 年次 | 作物 | 畑に起こること |
|:---|:---:|:---|:---|
| 4年周期 | 1年目 | 玉レタスなどキク科 | 菌核病のリスクが積もり始めます |
| | 2年目 | マメ科（ダイズ、エンドウ、ササゲ） | 窒素が固定されて蓄積します |
| | 3年目 | トウモロコシ、モロコシなどイネ科 | キク科の病原菌が餓えます |
| | 4年目 | ダイコン、ハクサイなどアブラナ科 | 深い根で土をかき乱します |
| | 再び1年目 | 玉レタス | 菌核密度が下がった状態で始まります |

&nbsp;&nbsp;&nbsp;イネ科をキク科の後に入れる配置は特に有効です。菌核病の病原菌は宿主範囲が広いものの、イネ科にはうまく感染できないためです。イネ、トウモロコシ、モロコシ、コムギ、オオムギがここに入ります。

&nbsp;&nbsp;&nbsp;玉レタスの前に豆科を置く配置は、窒素の点で注意が必要です。豆科が残す窒素が多いと、玉レタスが結球期まで窒素を受け続け、栄養生長を止められなくなることがあります。豆科の翌年に玉レタスを植えるときは、窒素の追肥をまったく省くか大きく減らす方が安全です。
