## 12. 収穫 - 一度限りの収穫

### 12-1. 収穫時期の判断

| 区分 | 基準 |
|:---|:---|
| 秋栽培 | 定植後50-60日 |
| 春栽培 | 定植後60日前後 |
| 冬栽培 | 定植後90日 |
| 結球判定 | 上から押して固く抵抗すれば良いです |
| 収穫の時刻 | 早朝。水分を含んで最も重いです |
| 避けるべき時 | 雨が降った直後、葉が濡れているとき |

&nbsp;&nbsp;&nbsp;押してみるのが最も確実な判断法です。ぐっと沈むならまだ中が詰まっていないか、そもそも詰まらない株で、固く抵抗するなら適期です。硬すぎると感じたら、もう遅く、内部で花茎が立ち始めている可能性があります。結球の中で花茎が立つと、外からは見えないまま中が円錐状に盛り上がり苦味が出てくるので、結球が完成した後は長く置かないのがこつです。

> **雨が降った直後には収穫しません。葉の間に水が残ったまま切ると、その水が貯蔵中の軟腐病の始点になります。雨が止んで一、二日経ち、葉が乾いた後に収穫します。**

### 12-2. 収穫のこつ

| 順序 | 内容 | 理由 |
|:---:|:---|:---|
| 1 | 晴れた日の早朝に収穫します | 水分を含んで重く新鮮です |
| 2 | 株元を刃物で一度に切ります | 何度も切ると切り口が粗くなり傷みます |
| 3 | 外葉2-3枚を残します | 貯蔵中に中を保護する皮になります |
| 4 | 切った断面を陰で乾かします | 濡れた断面が腐敗の始点です |
| 5 | 洗わずに保管します | 水気が残るとすぐに軟らかくなります |

&nbsp;&nbsp;&nbsp;外葉を残すことが、玉レタス収穫における最も実質的な技術です。流通する玉レタスは外葉がすべて取り除かれていますが、貯蔵を前提にするなら逆にしなければなりません。外葉の二、三枚はそれ自体が包装材であり、貯蔵中に外葉が乾いて褐変する間、内葉は保護されます。食べるときに剥けば中は無傷です。

&nbsp;&nbsp;&nbsp;切った断面からは、サンチュと同様に白い乳液が出ます。この乳液が乾いて茶色く固まると、むしろ傷をふさぐ蓋の役割を果たします。陰で一、二時間置いて断面を乾かした後に貯蔵場所へ移すと貯蔵期間が延び、濡れたまますぐに入れるとその場所で細菌が育ちます。

### 12-3. 一度限りという意味

&nbsp;&nbsp;&nbsp;評価表の永続性Dが意味することを、収穫の段階で改めて確認しておきます。結球を収穫するには株元を切るしかなく、そうすると生長点も一緒になくなります。その株はそこで終わりです。

&nbsp;&nbsp;&nbsp;そのため玉レタスの収穫では、時期を分散させることが貯蔵よりも先に来る問題になります。二十株を同じ日に植えれば、二十個の結球が同じ週に一度に出てきて、常温一週間では対応できません。十日から半月の間隔をあけて分けて植えれば、収穫もそれだけ分散します。ただ、秋栽培では霜という締め切りがあるため、この時差には限界があります。初霜が10月下旬なら、それより50-60日前の9月初旬までに定植を終える必要があるので、分けられる幅は2-3週間です。

&nbsp;&nbsp;&nbsp;切った跡に残った株元から側芽が出て、小さな葉が数枚育つこともあります。結球せず大きさも小さいですが、食べることはできます。これを再生収穫と呼ぶのは難しく、畑を片付けるまで捨てない程度と見るのが正確です。

## 13. 採種 - 結球が作る障壁

&nbsp;&nbsp;&nbsp;評価表の自家採種等級はS、根拠は自家受精です。玉レタスもサンチュのように花が開く前に自分の花粉で受精を終えるため、蜂が訪れても遺伝子はほとんど混ざらず、実用的な隔離距離は1-2mで十分です。ところが玉レタスの採種には、サンチュにはない問題が一つあります。花茎が結球を突き破って出てこなければならないということです。

### 13-1. 花茎が閉じ込められる問題

&nbsp;&nbsp;&nbsp;玉レタスは葉が幾重にも巻いて硬い塊をなします。その中に生長点があり、抽だいが始まると花茎はその層を押し分けて出てこなければなりません。結球が硬いほどこれが難しくなり、花茎が内部で曲がって育ちながら腐ることが起こり、その状態で内部に水が溜まると軟腐病が続いて起こります。

| 問題 | どうなるか | 対応 |
|:---|:---|:---|
| 花茎が結球を突き破れない | 内部で曲がって育ちながら腐ります | 結球の頂部に十字に浅く切れ目を入れて道を作ります |
| 内部に水が溜まる | 軟腐病が来ます | 雨を避けられるなら避け、排水を確保します |
| 結球がなかなか解けない | 開花が遅れ種子が熟しません | 採種株は結球が緩い個体を選びます |

&nbsp;&nbsp;&nbsp;結球の頂部に刃物で十字に浅く切れ目を入れるのが伝統的な対応です。深さは1-2cm、外葉二、三層だけを裂く程度で、深く切ると生長点を傷めそのまま終わります。ただ、切った場所は傷なので、雨が多いとそこから病気が入ります。手を加えずに置いても、かなりの数は自力で突き破って出てくるので、複数の株を採種株として残し、うまく出てきたものを使う方が安全です。

&nbsp;&nbsp;&nbsp;ここに玉レタス採種の構造的な矛盾があります。食べるのに良いのは硬く巻いたものですが、種を採るのに良いのは緩く巻いたものです。毎年、種を採りやすい個体だけを選んで続けると、数世代後には結球が緩い系統に流れていきます。

> **この流れを止めるには、採種株を選ぶときに二つの基準を併せて使います。結球がきちんとできた株の中で、花茎が無事に出てきたものから種を採ります。結球に失敗した株から種を採ると、その性質がそのまま引き継がれます。**

### 13-2. 時間表

| 段階 | 時点 | 状態 |
|:---|:---|:---|
| 収穫適期 | 定植後50-60日 | この時、採種株は収穫せずに残します |
| 抽だい | その後3-5週 | 花茎が結球を突き破って伸び上がります |
| 開花 | 抽だい後3-4週 | 黄色い花が朝に開きます |
| 種子成熟 | 開花後12-24日 | 冠毛が膨らんできます |
| 種子収穫 | 播種後150-180日 | サンチュより一か月ほど長いです |

&nbsp;&nbsp;&nbsp;この表で明らかになるのが、玉レタス採種の実質的な難点です。播種から種子まで五か月から六か月が必要なので、秋に植えると冬が先に来てしまい不可能で、春に植える必要があります。2-3月に播種すると7-8月に種子を得ることになりますが、その間の6-7月は高温と梅雨の時期です。花茎が立つ時期と梅雨が重なると、結球の中に水が溜まって腐りやすくなります。自家受精という利点はそのまま生きていますが、その利点を使うまでの道は長く、失敗する箇所が多くあります。

### 13-3. 種子の採取と保管

&nbsp;&nbsp;&nbsp;花茎が伸び上がった後はサンチュと同じです。種子には冠毛が付いており、熟すと風で飛ばされ、下の花から順に熟すため、一株の中で熟す時期が3週間以上ずれます。

| 方法 | 手順 | 特徴 |
|:---|:---|:---|
| 袋かけ | 通気性のある紙袋や布袋を花茎にかけます | 労力と回収率のバランスが良いです |
| 分けて摘み取り | 2-3日に一度、膨らんだ花だけを摘んで集めます | 回収率が最も高いです |
| 一括刈り取り | 半分以上膨らんだら花茎ごと刈り取り後熟させます | 一度で終わりますが未熟な種が混ざります |

| 項目 | 基準 |
|:---|:---|
| 一株の種子数 | 数千粒 |
| 種子寿命 | 常温密閉で2-3年、涼しく乾燥していればさらに長持ちします |
| 保管 | 密閉容器、涼しく暗く乾燥した場所 |
| 乾燥剤 | 炒って冷ました米、炭、乾いた草木灰 |
| 確認 | 毎年20粒を濡れた布に置いて発芽数を数えます |

&nbsp;&nbsp;&nbsp;玉レタスの種子も、採ったばかりのものでは高温休眠がより強く現れます。後熟が終わっておらず発芽抑制物質が残っているためです。8月の秋播種にその年の7月に採った種子を使うと発芽率が大きく落ちるので、二年分を重ねて置き、古いものから使います。交配種から種を採ると次世代で形質が分離し、あるものは結球し、あるものは開いてしまうという点も併せて覚えておきます。

## 14. 毒性と注意すべき成分

&nbsp;&nbsp;&nbsp;玉レタスに毒性はありません。サンチュと同じ種なので成分構成も同じですが、結球という形態のために強さが変わる点があります。

| 成分 | サンチュとの比較 | 理由 |
|:---|:---|:---|
| ラクツカリウム（乳液） | 少ないです | 内葉は光を受けず防御物質の生産が少ないです |
| 硝酸塩 | 内葉によりたまりやすいです | 光がないと硝酸塩がタンパク質に変換されません |
| シュウ酸 | 低いです | 実質的な問題ではありません |

### 14-1. ラクツカリウム

&nbsp;&nbsp;&nbsp;玉レタスを切るとサンチュと同様に白い乳液が出ますが、これがラクツシンとラクツセリンを含むラクツカリウムです。苦味の元であり、軽い鎮静作用を持つ成分です。ただ、玉レタスの内葉にはこの成分がサンチュより少ないです。光を受けない組織では防御物質の生産が少ないためです。玉レタスの内側が淡く苦味がほとんどない理由であり、同時に栄養が薄い理由でもあります。外葉にはサンチュと同程度に含まれているため、外葉は苦めです。食べると眠くなるという話がありますが、食卓で食べる量ではその効果を実感できる水準には遠く及びません。結球の中で花茎が立ち始めた株は苦味が目立って強くなりますが、これは毒性が生じたわけではなく、時期が過ぎたという信号です。

### 14-2. 硝酸塩

&nbsp;&nbsp;&nbsp;硝酸塩の問題は、玉レタスではサンチュより注意して見る必要があります。根が吸収した窒素は硝酸塩として葉に貯蔵された後、光があるときに光合成エネルギーを使ってアミノ酸に変わりますが、結球の内葉は光を受けられないためその変換が起こらず、硝酸塩のまま残ることがあります。

| 条件 | 硝酸塩の蓄積 |
|:---|:---|
| 窒素施肥過多 | 大きく増えます |
| 結球の内葉 | 光を受けられず変換が進みません |
| 曇りの日が続くとき | 増えます |
| 早朝の収穫 | 夜間に変換が止まり高いです |
| 晴れた日の午後の収穫 | 日中に変換されて低いです |

&nbsp;&nbsp;&nbsp;ただ、正常に育てた玉レタスを普通の量で食べることは問題になりません。硝酸塩自体が毒ではなく、野菜摂取の利益がその負担を上回るというのが現在の一般的な理解です。心配すべき組み合わせは、窒素を過剰に与えた畑で日照が足りない条件で育ったものを、他の野菜なしに毎日大量に食べる場合です。

&nbsp;&nbsp;&nbsp;結球期に窒素を止めることが、結球を成立させるためにも、硝酸塩を減らすためにも正しいというのは幸いです。二つの目的が同じ方向を指しているので判断は難しくありません。成分以外の危険は衛生です。生で食べる野菜なので畑の状態がそのまま口に入り、特に玉レタスは結球の内側に土や水が入ると洗い落としにくいです。外葉を一枚ずつ剥がしながら洗うのが確実で、糞尿を十分に発酵させずに与えた畑や洪水が通った土地で育ったものは、茹でて食べる方が安全です。

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;評価表の貯蔵性D、無電力常温1週間が、玉レタスを植える唯一の理由です。この節がこの作物の文書における核心です。

### 15-1. なぜサンチュより長持ちするのか

&nbsp;&nbsp;&nbsp;理由は純粋に構造にあります。葉一枚がそのまま空気にさらされるサンチュと違い、結球した玉レタスは外葉が幾重にも内側を包んでいます。貯蔵中に水分が抜けるのも、細菌が触れるのも、酸素が入って呼吸が続くのも、まず外側で起こります。外葉が乾き、褐変し、軟らかくなる間、内葉はその内側で保護されます。表面積対体積の比も有利です。広く広がった葉は同じ重さでも表面積が大きく、それだけ水分の損失が速いですが、球状にまとまった塊は表面積が最小になる形です。

| 条件 | 貯蔵期間 |
|:---|:---:|
| 常温のまま | 5-7日 |
| 涼しい陰（15℃前後） | 1-2週 |
| 土室・室（10℃前後） | 2-3週 |
| 室で湿った砂や藁と一緒に | 3-4週 |

### 15-2. 貯蔵方法

| 方法 | 手順 | 注意 |
|:---|:---|:---|
| 外葉を残す | 外葉2-3枚を付けたままにします | 包装材の役割をします |
| 断面を乾かす | 切った後陰で1-2時間 | 濡れた断面が腐敗の始まりです |
| 洗わない | 土だけ払い水は当てません | 水気が残るとすぐに傷みます |
| 濡れた布で包む | 通気性のある布を湿らせて緩く巻きます | 密着させると潰れます |
| 室に埋める | 湿った砂や藁の間に根の方を下にして | 互いに触れないよう間隔を空けます |
| 逆さに吊るす | 株元に紐を結んで涼しい場所に掛けます | 底に接する面がなく押されません |
| 甕 | 濡れた布を敷いて入れた後、ゆるく覆います | 完全に密閉すると軟らかくなります |

&nbsp;&nbsp;&nbsp;室に貯蔵する際は、互いに触れないよう間隔を空けることが重要です。接した面は空気が通らず湿気がたまって、そこから軟らかくなり、一個が軟らかくなり始めるとエチレンと細菌が隣へ移っていきます。数日に一度確認し、傷み始めたものを取り出すことが、貯蔵期間を大きく左右します。

> **貯蔵するものと先に食べるものを、収穫の時点で分けておきます。裂けた結球、押された跡があるもの、虫が入った跡があるもの、雨が降った直後に収穫したものは、貯蔵せず先に食べます。傷んだ一つが隣の無傷なものを引き下げます。**

&nbsp;&nbsp;&nbsp;室や土室がなければ、北向きの軒下、縁の下、井戸端、石垣の陰のように、日が当たらず風が通る場所を探します。温度そのものより、温度が一定であることが重要です。昼に暑く夜に寒い場所では結露が生じ、その水分が腐敗を招きます。

### 15-3. 加工貯蔵

| 方法 | 手順 | 期間 | 評価 |
|:---|:---|:---:|:---|
| 茹でて干す | 外葉を茹でて陰で干します | 数か月 | 外葉の処理に使えます |
| 水キムチ | 2-3%の塩水に浸けます | 1-2週 | しゃきしゃき感が少し残ります |
| 浅漬け和え | 塩で漬けて味付けします | 2-3日 | 貯蔵というより調理です |

&nbsp;&nbsp;&nbsp;玉レタスは加工貯蔵にあまり適しません。水分が95%近くあるため乾燥させるとほとんど残らず、塩漬けにするとしゃきしゃき感が消えます。この作物の貯蔵戦略は加工ではなく、結球のまま置いておくことです。ただ、収穫時に取り除いた外葉は干しておけば捨てずに済みます。外葉は濃い緑色で内側より栄養が優れており、硬くて生で食べにくい分、干しておいて汁物に入れる用途が合っています。結球一つから出る外葉は少なくないので、この習慣一つで実際の収穫量が増えます。

## 16. 調理と加工

| 方法 | 燃料 | 備考 |
|:---|:---:|:---|
| 生食（サム、サラダ） | なし | 内葉がしゃきしゃきして淡いです |
| 浅漬け和え | なし | しんなりして体積が減り、たくさん食べられます |
| 水キムチ | なし | 発酵によりビタミンCがかなり残ります |
| 茹でる | 少ない | 外葉を処理する方法です |
| 汁物や炒め物 | 他の調理と併用 | 外葉と芯を使います |

&nbsp;&nbsp;&nbsp;玉レタスの調理・加工SSも、サンチュと同じ理由から来ています。洗ってそのまま食べるので燃料がかからず、熱に弱いビタミンCと葉酸がそのまま入ってきます。ただ、この利点をしっかり使うには一つの習慣を変える必要があります。外葉を捨てないことです。外葉は濃い緑色でベータカロチンとビタミンKが集中しており、白い内側だけを食べると、玉レタスの微量栄養素は表に記された15種より実際にはさらに薄くなります。外葉が硬ければ、茹でるか細かく切って汁物に入れればよいのです。

| 部位 | 性質 | 用途 |
|:---|:---|:---|
| 内葉 | しゃきしゃきして淡く、栄養が薄いです | 生食、サム、サラダ |
| 中間の葉 | 適度にしゃきしゃきしています | 生食、浅漬け和え |
| 外葉 | 濃い緑色で硬く、少し苦いです。栄養が最も優れています | 茹でる、汁物、炒め物、干しておく |
| 芯 | 硬く甘みがあります | 薄く切って生食するか炒めます |

&nbsp;&nbsp;&nbsp;真ん中の芯も捨てるものではありません。結球の中心にある短く硬い茎ですが、表面の硬い部分を剥いて薄く削ると、しゃきしゃきしてほのかな甘みがあり、生でも食べられ、炒めたり汁物に入れたりしてもよいです。浅漬け和えは体積を減らして実際の摂取量を増やす方法です。熱量14kcalの作物で食べる量が増えることは、栄養供給において違いを生みます。

&nbsp;&nbsp;&nbsp;玉レタスは加熱するとしゃきしゃき感が消えて軟らかくなるので、長く煮ません。汁物を煮ている火に最後に入れてしんなりさせるだけで、燃料を別に使わずに加熱した状態が得られます。油を少し混ぜるとベータカロチンとビタミンKとビタミンEの吸収が上がるので、エゴマやゴマを挽いて加えると助けになります。

&nbsp;&nbsp;&nbsp;この表で目立つのは、玉レタスが畑を占める期間の長さです。春栽培は2月から6月までの五か月、採種まで続けると八か月で、秋栽培も三か月です。その間その場所では他のものを育てられず、結球が失敗するとその時間全体が失われます。そのため実際の配置は、畑の小さな一角に秋栽培だけを植え、春栽培は種を継続するために数株だけを置く形になります。残りの場所はサンチュやフダンソウやケールのように、継続して摘み取れる葉物野菜に譲ります。

> **玉レタスは畑の柱ではなく、冬へ渡る橋です。霜がすべての葉物野菜を終わらせた後、室にいくつかの塊が残っていること、その数週間がこの作物が果たす仕事のすべてです。そのために三か月と500mmの水を使う価値があるかどうかを判断することが、この作物を植えるかどうかを決める基準です。**

&nbsp;&nbsp;&nbsp;最後に、リスク分散の原則を確認しておきます。玉レタスは失敗したときに残るものがほとんどない作物です。そのため、畑全体を玉レタスで埋める配置はどんな場合でも避けます。同じ場所にサンチュも一緒に植えておけば、玉レタスが失敗してもサンチュからは何かが得られます。結球が成立しない年は数年に一度必ず来るもので、その年に畑に他のものがあるかどうかが、その季節の食卓を左右します。
