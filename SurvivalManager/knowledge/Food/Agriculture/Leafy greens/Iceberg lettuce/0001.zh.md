# 结球生菜
- 来源: 韩国农村振兴厅 农事路（Nongsaro）、韩国国家标准食品成分表、FAO ECOCROP、Wiki、Gemini、Claude、Chat-GPT
- 编者: GoldBigDragon
---
## 引言
&nbsp;&nbsp;&nbsp;结球生菜（Lactuca sativa var. capitata）与生菜是同一个种，叶子向内卷成像头一样的圆球，这个结球决定了两种作物的命运。综合等级为E（35.7分，有效183种中第161位），比生菜的D（37.7分）低。持续性、温度幅度、水消耗量、收获速度等六项全都朝同一个方向下降，原因就是结球这一个特性。结球需要外叶先长好，所以生长期变长；要把生长点整个拿走，所以无法再生收获；要把大球撑起来，需要更多的水；结球的温度区间比叶子生长的区间窄。结球失败的话，养了四个月的地里几乎没有可用的东西，一季的粮食计划就垮了。优点只有一个，就是耐储性（D，常温1周；生菜是E，2-3天），因为几层外叶包住内叶，使内叶不接触空气。秋天种、初冬收几颗叶球放进储存窖，霜把所有叶菜都终结之后，还能再留几周新鲜蔬菜，这就是这种作物的用法。它不是可以把整块地交给它的作物，更不是灾害初期要赶紧种的作物。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | E | 35.7 |
| 短期 | D | 36.4 |
| 长期 | E | 35.1 |
| 副食 | S | 57.1 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：蛋白质密度、设施负担、烹调·加工要求度。S：口味、自留种。A：微量营养素（15种）、收获速度、产量稳定性、国内种植普及度。B：施肥、水消耗量、光照、耐寒性、防治自立度、连作适应性、种子寿命 |
| 劣势 | E：非食用价值。D：单位面积热量、持续性、温度幅度、耐储性。C：病虫害压力、无合成投入产量保持率、整地·挖掘能量 |

| 与生菜比较 | 生菜 | 结球生菜 | 原因 |
|:---|:---|:---|:---|
| 持续性 | A（2-3个月） | D（一次性） | 收获叶球后生长点就没了 |
| 温度幅度 | C（15-22℃） | D（15-20℃） | 结球条件比生长条件窄 |
| 耐储性 | E（2-3天） | D（1周） | 外叶包住内部加以保护 |

> **结球生菜不是生菜的升级版。它是从同一个种分出来的另一种策略，在灾害条件下大体处于不利的一边。如果非要有种结球生菜的理由，只有一个：为了在下霜之后的几周里留住新鲜蔬菜。**

&nbsp;&nbsp;&nbsp;各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 菊科莴苣属。一年生（视条件为二年生）。别名有球生菜、脆头生菜（crisphead）、卷心生菜（iceberg） |
| 叶 | 圆而宽，边缘深裂呈波浪形。外叶深绿色，厚而韧，是保护内部的外皮；内叶得不到光，呈淡黄至白色，脆嫩多汁，味道温和 |
| 茎、根、花 | 茎极短而压缩，位于叶球中心。直根较浅，只有20-30cm。黄色头状花序组成圆锥花序，果实是长3-4mm的瘦果（顶端有冠毛） |

| 阶段 | 定植后 | 要点 |
|:---|:---|:---|
| 成活 | 1-2周 | 根在新土里安顿下来。15-20℃ |
| 外叶形成 | 2-6周 | 展开10-15片外叶。15-20℃ |
| 结球开始、充实 | 6-7周、7-10周 | 新叶开始向内弯（15-18℃最好），内部充实变硬（10-18℃） |
| 收获期 | 10周以后 | 按压发硬就是适期 |

> **结球只在外叶充分长大之后才开始。外叶形成期长得不好，那一株就进入不了结球阶段。相当一部分结球失败，不是在结球期，而是在此前的阶段就已经决定了。**

&nbsp;&nbsp;&nbsp;每100g热量14kcal，水分94-96%，蛋白质0.90g（占热量的比例高），碳水化合物2.3g，膳食纤维1.2g，糖类1.97g，维生素C 7mg，β-胡萝卜素96㎍（集中在外叶，维生素K也是如此），叶酸66.7㎍，钾167mg，钙32mg。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽适温18-21℃（6-8天），26℃以上因高温休眠不发芽。生长适温15-20℃，结球适温15-18℃，可结球10-20℃，25℃以上叶子张开并抽薹。-5℃时外叶受损，严重时叶球裂开 |
| 光 | 每天8-10小时。能耐半阴，但结球会变松。遮光40%时相对产量86%。种子需光发芽，埋得深就不发芽 |
| 水、土壤 | 总蒸散量约500mm（生菜350mm）。结球期不要让它干（这个时期的干旱是结球失败的主要原因）。过湿会招来烂根和软腐病，所以要把垄做高。排水良好的砂壤土至壤土，pH 6.0-6.8，有机质越多越好 |

> **种结球生菜的核心问题只有一个：开始结球的时候气温是不是15-18℃。把播种日倒推回去来回答这个问题，说是这种作物全部的技术也不为过。**

&nbsp;&nbsp;&nbsp;秋季栽培有利，春季栽培因结球期气温升高容易失败。品种分为脆头型（叶缘深裂，叶球结实，耐储性最好，符合种这种作物的目的）和奶油型（半结球型，叶子柔软、叶球松，失败风险低，但储存上的优势也小）。有抗蚜虫和霜霉病的引进品种，但灾害拖长后，它们的种子无法补充。以储存为目的就选脆头型早熟种（霜前结球完成），担心结球失败就选奶油型或散叶生菜（失败了也能吃叶子），打算把种子留下去就选固定品种。

## 4. 田地准备、播种与定植
| 项目 | 标准 |
|:---|:---|
| 整地 | 深耕25-30cm，垄高20cm以上（防止过湿和软腐病），宽100-120cm（双行种植），一定要有排水沟（结球期积水整株会烂掉），把表面整平 |
| 施肥（1,000㎡） | 氮12-15kg，磷8-10kg（全部作基肥，直接参与结球），钾8-10kg，石灰150kg。基肥在定植前1-2周施入：堆肥全量、磷全量、氮和钾的一半。第1次追肥在定植后3周左右，氮、钾（养外叶）；第2次在开始结球前后，钾、磷（充实内部并使其变硬） |
| 替代资源 | 木灰每株一把（碱性，过量会使pH升高），腐熟堆肥（没腐熟的会伤根），尿的10-20倍稀释液（浇在株间，开始结球后不再施），骨粉，蛋壳·贝壳粉（钙），发酵过的油饼（生的会因发酵热烧根） |

> **结球期氮多，叶子会一直想长大而不向内卷。看上去茂盛、里面却是空的植株，最常见的原因就是结球期氮过多。**

| 类型 | 播种 | 定植 | 收获 |
|:---|:---|:---|:---|
| 秋季栽培 | 8-9月 | 9-10月 | 11-12月。灾害情况下实际上是唯一的选择 |
| 春季栽培 | 2-3月 | 3-4月 | 6-7月。结球期气温升高，失败风险大 |

&nbsp;&nbsp;&nbsp;夏季栽培发芽和结球都被堵住，不推荐。秋播的难处是8月的炎热（26℃以上高温休眠），应对办法有低温引发（种子泡4-6小时，用湿布包好，放在凉爽处一天）、提前催芽再播、日落后播种、做薄薄的遮阴、在凉爽处育苗。

| 种植 | 标准 |
|:---|:---|
| 育苗 | 深度0.5-1cm（需光发芽，埋深了不出苗），18-21℃下6-8天发芽，育苗20-30天，真叶4-5片时定植。定植前几天减少浇水并放到室外空气中炼苗，成活会更快 |
| 定植 | 株距30-35cm，行距50-60cm（每1,000㎡ 3,000-3,500株）。真叶基部不要埋进土里（埋了基部会烂），在阴天或傍晚栽，栽后立刻浇透水。把间距缩小通常是吃亏 |

> **定植晚了，结球就会失败。真叶超过6片的苗，根已经缠在狭小的地方，移栽后要花时间恢复，来不及按时长出外叶。**

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 刚定植后至成活 | 浇透（根必须贴住新土） |
| 成活后至外叶形成期 | 表土干了再浇（引导根向下扎） |
| 结球期 | 不要让它干（结球生菜的水分管理全看结球期） |
| 收获前1周 | 减少或停止（组织变硬，耐储性提高） |

&nbsp;&nbsp;&nbsp;白天蔫、傍晚恢复是暂时缺水；傍晚也不恢复，就立刻浇足。叶球松而轻是结球期缺水，已无法挽回；内叶尖端褐色干枯的干烧心，是水分不均导致钙转运受阻，所以要均匀浇水；叶球开裂是干了之后突然浇大量水造成的；外叶发黄、基部变软是过湿，要开沟排水并停止浇水。节水可用稻草和干草覆盖（最便宜的节水手段）、清晨沟灌、防风。

| 结球失败的条件 | 结果 |
|:---|:---|
| 高温 | 叶子张开着长，然后抽花茎（叶片背面与正面的生长速度差消失） |
| 氮过多 | 叶大而茂盛，里面却是空的（营养生长停不下来） |
| 定植延迟 | 外叶不壮，无法开始结球 |
| 缺磷、结球期缺水、光不足、过密 | 叶球松而轻 / 内部不充实 / 叶球松散 / 互相遮挡，争夺光和养分 |

> **结球失败不是结球期发生的事故，而是此前两个月的结果显现的那一刻。叶子开始张开之后，几乎什么也做不了。在决定播种日的时候、移栽苗的时候、停氮的时候，就已经定了。**

&nbsp;&nbsp;&nbsp;此外，定植1周后补苗，杂草小时就除（根浅，锄深了会伤根），生长中期培土一次，摘除发黄枯干的下部叶片。

## 6. 病虫害与养分问题
| 病害 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 霜霉病 | 叶片正面黄褐色斑点，背面有白霉。凉爽潮湿时（结球生菜上最常见） | 通风，清晨浇水，抗病品种，摘除病叶 |
| 软腐病 | 基部和内部软烂并发臭。高温高湿、排水差、有伤口 | 把垄做高，排水，不留伤口 |
| 菌核病 | 基部变软，有白色菌丝和黑色颗粒。低温高湿、菊科连作 | 深耕，覆盖，2-3年轮作，彻底清除病株 |
| 灰霉病、白粉病、基腐病 | 灰色霉层 / 叶面白粉 / 茎基褐变并倒伏 | 控湿、保证间距 / 通风、光照、牛奶稀释液 / 浅栽、排水 |

> **软腐病不是治疗的问题，而是管理条件的问题。不让水积着，不把基部埋进土里，收获时不弄出伤口，下雨后不马上收获。这四条是不用药能做的全部，也是真正有效的全部。**

&nbsp;&nbsp;&nbsp;得了菌核病的植株，连根周围的土一起挖起，搬到田外。不能放进堆肥堆（菌核能扛住堆肥的发酵热活下来，扩散到整块田）。害虫有蚜虫（肥皂水，保护瓢虫和蚜茧蜂，抗性品种）、蓟马（黄色粘虫板，清除周边杂草）、蛾类幼虫（钻进叶球里：清晨人工捉，防虫网）、蛞蝓（夜里捉，撒一圈灰或稻壳）、根螨（轮作，改善排水）。防治材料有肥皂水（20g无香料肥皂溶于1L水）、牛奶稀释液（牛奶和水1比9，用于白粉病）、木灰浸出液（木灰在水里泡24小时后过滤使用）、300-500倍木醋液。农艺上，菊科作物休耕2-3年，不缩小间距，用覆盖物防止雨水溅起，减少氮，避开高温期栽培。

| 症状 | 原因与处理 |
|:---|:---|
| 整株叶子发黄，植株小 | 缺氮。腐熟堆肥，尿的15-20倍稀释液（只在结球期之前） |
| 叶缘褐色干枯 | 缺钾。少量木灰 |
| 生长不良，叶片发紫 | 缺磷（地温低时也有同样症状）。骨粉、木灰 |
| 叶球松而轻 | 磷和钾不足（在基肥阶段就已决定） |
| 叶子大而深绿，里面却是空的 | 氮过剩（在结球生菜上往往比缺氮更危险）。停止供氮 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 豆科作物（豌豆、菜豆、豇豆：固氮），小葱·大葱·大蒜（气味让害虫迷惑），萝卜·大白菜等十字花科（不共有病虫害，根的深度不同），莳萝·芫荽（招来蚜虫的天敌） |
| 差 | 生菜·茼蒿·菊苣·牛蒡等菊科（共有菌核病和霜霉病），结球生菜连作（菌核积累） |

&nbsp;&nbsp;&nbsp;结球生菜和生菜最好不要挨着种在同一块地里；定植间距宽，初期空地多，可以用小葱或莳萝把空隙填上。按4年一个周期，经过结球生菜等菊科、豆科（固氮）、玉米·高粱等禾本科（使菊科病原菌挨饿）、萝卜·大白菜等十字花科，就能在菌核密度降低的状态下重新开始种结球生菜。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 定植后，秋季栽培50-60天，春季栽培60天左右，冬季栽培90天。从上面按压，硬实顶得住就成熟了。在清晨（含水最多、最重）收获，避开刚下完雨或叶子湿的时候（叶片间残留的水会成为储存中软腐病的起点）。等雨停一两天、叶子干了之后再收 |
| 要领 | 用刀一刀割断基部（割多刀切面会粗糙而变坏），留2-3片外叶（储存中保护内部的外皮），把切面放在阴凉处晾干，不洗直接保管。切面会像生菜一样渗出白色乳汁 |
| 只有一次 | 持续性D，收了就结束，所以分散收获时间比储存更先成为问题。割过的基部有时会从侧芽长出几片小叶 |

| 留种 | 标准 |
|:---|:---|
| 难点 | 叶球结实，花茎顶不穿叶球，在里面弯曲生长而腐烂。在叶球顶部划一道浅浅的十字，为它开路；避雨使里面不积水，并保证排水。留种株要从结球良好、花茎顺利抽出的植株中选（从结球失败的植株留种，这个性状会遗传下去） |
| 时间表 | 收获适期（定植后50-60天）把留种株留下，3-5周后抽薹，再过3-4周开花，12-24天后种子成熟。从播种起150-180天，比生菜长一个月左右 |
| 采种 | 给花茎套上透气的纸袋或布袋，或每2-3天只撸取鼓起的花（回收率最高），或超过一半鼓起就连花茎割下后熟（会混入未熟的种子） |
| 寿命 | 常温密封2-3年（凉爽干燥则更久）。放进密封容器，置于凉爽阴暗干燥处。每年把20粒种子放在湿布上数发芽数。刚收的种子高温休眠更强 |

## 9. 储存
| 条件 | 储存期 |
|:---|:---|
| 常温原样 | 5-7天 |
| 凉爽阴处（15℃左右） | 1-2周 |
| 地窖·窖（10℃左右） | 2-3周 |
| 窖里配湿沙或稻草 | 3-4周 |

&nbsp;&nbsp;&nbsp;留着2-3片外叶，把切面在阴凉处晾1-2小时，不洗，用透气的湿布松松地包起来；在窖里则在湿沙或稻草之间根朝下放，留出间隔使其互不接触；或在基部系绳，倒挂在凉爽处；陶罐里铺上湿布并松松地盖住（完全密封会变软）。

> **在收获的时候就把要储存的和要先吃的分开。开裂的叶球、有压痕的、有虫蛀痕迹的、刚下完雨就收的，都不储存，先吃掉。坏了一个，会把旁边完好的也拖下水。**

&nbsp;&nbsp;&nbsp;结球生菜不太适合加工储存。外叶焯水后阴干能放几个月（处理外叶用），2-3%盐水的水泡菜能放1-2周（还留一点脆感），盐腌凉拌能放2-3天（与其说是储存，不如说是烹调）。

## 10. 烹调与注意事项
| 部位 | 性质 | 用途 |
|:---|:---|:---|
| 内叶、中间的叶 | 脆嫩温和，营养淡薄 | 生吃、包着吃、沙拉、盐腌凉拌（会变蔫、体积缩小、能多吃） |
| 外叶 | 深绿色，韧，略苦。营养最好 | 焯水、汤、炒、晒干留存 |
| 菜心 | 硬而带甜味 | 切薄片生吃或炒 |

&nbsp;&nbsp;&nbsp;水泡菜靠发酵能保留相当一部分维生素C。煮熟后脆感消失、变软，所以不要久煮。

| 成分 | 内容 |
|:---|:---|
| 毒性、莴苣乳汁 | 结球生菜没有毒性。切开会像生菜一样渗出白色乳汁（莴苣素），但内叶得不到光，防御物质产生少，所以比生菜少。草酸也低 |
| 硝酸盐 | 内叶中可能比生菜积累得更多（没有光，就不能转化为蛋白质）。氮肥过多、阴天、清晨收获时会增加，晴天下午收获时较低。正常种出的结球生菜按普通量吃没有问题，结球期停氮对结球和降低硝酸盐都是对的 |

## 11. 全年作业日程
| 月份 | 春季栽培 | 秋季栽培 |
|:---|:---|:---|
| 1-2月 | 检查种子，规划田地，管理堆肥。2月播种育苗（需保温） | |
| 3-4月 | 继续育苗，3月下旬定植并施基肥。4月成活与外叶形成，第1次追肥 | |
| 5-6月 | 结球期（水分管理最重要）。6月收获，留种株保留 | |
| 7-8月 | 留种株抽薹开花，8月收种子并精选 | 8月下旬播种（应对高温休眠） |
| 9-10月 | | 9月育苗与定植（上旬前结束）。10月外叶形成与开始结球，追肥 |
| 11-12月 | | 11月叶球完成并收获，开始储存。12月检查储存品，整理田地并处理残体 |

> **结球生菜不是田里的支柱，而是通往冬天的桥。霜把所有叶菜终结之后，窖里还留着几颗，这几周就是这种作物做的全部事情。为了这件事，值不值得花上三个月和500mm的水，是决定种不种它的标准。**
