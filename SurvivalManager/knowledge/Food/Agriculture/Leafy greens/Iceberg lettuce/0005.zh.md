## 8. 栽培管理 - 形成结球的条件

&nbsp;&nbsp;&nbsp;在结球生菜栽培中，其他所有作业都服务于一个目的：让结球得以成立。结球不成，三个月的劳动就化为乌有，因此本节实际上谈的正是这种作物的成败。

### 8-1. 结球失败的条件

| 原因 | 结果如何 | 为何如此 |
|:---|:---|:---|
| 高温 | 叶片一直散开生长，最终抽薹 | 叶片上下表面的生长速度差异消失 |
| 氮过多 | 叶片大而繁茂，但内部空虚 | 营养生长不停止，无法进入卷合阶段 |
| 定植延迟 | 外叶不健壮，无法开始结球 | 根系盘绕的苗要花时间才能活棵 |
| 缺磷 | 结球松散且轻 | 磷是细胞分裂与能量代谢所需的元素 |
| 结球期水分不足 | 内部无法填满 | 没有水可以让细胞膨大 |
| 光照不足 | 结球松散 | 糖分不足，叶片轻薄 |
| 密植 | 相互遮挡，争夺光照与养分 | |

&nbsp;&nbsp;&nbsp;在这张表中，最常发生的是前三种：高温、氮过多、定植延迟。这三者都无法在结球期挽救，而是在此之前就已经决定了。

> **结球失败不是发生在结球期的事故，而是此前两个月结果显现出来的那一刻。叶片一旦开始散开，能做的事几乎没有。它早在决定播种日、移栽苗、停施氮的那些时刻就已经确定了。**

### 8-2. 如何把三件事对准

&nbsp;&nbsp;&nbsp;应对高温唯一的办法就是选择时期。倒推播种日期，使结球开始前后的平均气温落在15-18℃。从播种到结球开始大约需要两个月，因此该地区气温降到18℃以下那个时间点往前推两个月，就是秋播的基准日。韩国中部大约在8月下旬，南部在9月初前后。由于每年天气不同，这个基准日应留出安全余量，同时也要兼顾能在霜冻来临前完成结球的最晚界限。

&nbsp;&nbsp;&nbsp;应对氮的办法是分清时期。在外叶生长的定植后2-5周之间集中施氮，结球开始前后就要彻底停止。天然材料的肥效来得较晚，因此可以认为稀释尿液最迟只能用到定植后3周的第一次追肥。如果基肥中施用了较多未充分腐熟的堆肥，它本身可能持续释放氮直到结球期，因此堆肥一定要用完全腐熟的。

&nbsp;&nbsp;&nbsp;应对定植时期，关键在于识别苗的状态。真叶4-5片、根系刚轻轻抓住育苗盘土壤，就是适宜的时机。如果天气不好无法移栽，可以把育苗盘移到凉爽处并减少浇水以延缓生长，但这种延迟一旦超过一周，结球的时点就会开始错位。

### 8-3. 其他管理

| 作业 | 时期 | 内容 |
|:---|:---|:---|
| 缺株补苗 | 定植后1周 | 在死苗处补种新苗 |
| 除草 | 初期 | 在杂草尚小时进行。根系浅，除草过深会伤根 |
| 培土 | 生长中期1次 | 在基部轻轻培土，防止球体变重后倒伏 |
| 清理外叶 | 随时 | 摘除发黄枯干的下部叶片 |
| 检查覆盖物 | 随时 | 补盖被风吹开的地方 |

&nbsp;&nbsp;&nbsp;培土过度反而有害，因为基部一旦埋入土中，就会从那里开始发生软腐病。只需极浅地培土，做到株不倒伏的程度即可。

&nbsp;&nbsp;&nbsp;摘除发黄枯干的下部叶片，这项工作比想象中更重要。逐渐枯死的组织会成为灰霉病的立足点，在那里滋生的病菌会转移到健康的叶片上。不过摘除时若弄伤基部，伤口会成为病害的入口，因此要抓住叶柄向侧面折断，干净地摘下。摘下的叶片不要丢在地里，应运到远处或深埋进堆肥堆里。

## 9. 病虫害 - 不用药物的防治方法

&nbsp;&nbsp;&nbsp;结球生菜的病虫害压力为C，无防治减产率估计为50.6%，与生菜相同，这是同一物种理所当然的结果。不过结球这种形态带来了两点不同。一是结球内部潮湿、空气不流通，容易感染细菌性软腐病；二是病害若在结球内部发展，外表看不出来，发现得晚。

### 9-1. 主要病害

| 病害 | 症状 | 发生条件 | 不用药的应对 |
|:---|:---|:---|:---|
| 霜霉病 | 叶正面出现黄褐色斑点，背面生白色霉层 | 凉爽潮湿、叶片长时间潮湿时 | 通风、清晨灌水、抗性品种、清除病叶 |
| 软腐病 | 基部与内部软化溃烂并发出恶臭 | 高温潮湿、排水不良、有伤口 | 提高垄高、排水、避免造成伤口 |
| 菌核病 | 基部软化，出现白色菌丝和黑色菌核 | 低温潮湿、菊科连作 | 深耕、覆盖、2-3年轮作、彻底清除病株 |
| 灰霉病 | 褐色斑点上生灰色霉层 | 低温潮湿、通风不良 | 控制湿度、保持间距、清除枯叶 |
| 白粉病 | 叶面出现白色粉状物 | 干燥且昼夜温差大时 | 确保通风与光照、喷施稀释牛奶 |
| 基腐病 | 近地面处变褐，植株倒伏 | 过湿、栽植过深 | 浅栽、排水 |

&nbsp;&nbsp;&nbsp;结球生菜最具特征性的病害是软腐病。这是细菌引起的病害，从有伤口和积水的地方开始。结球内部容易积湿、空气不流通，是细菌生长的良好环境。外叶看起来完好，切开却发现内部已经软化，正是这种情况，一旦发展到这个地步就无计可施。

> **软腐病不是治疗的问题，而是条件管理的问题。不让水积存、不把基部埋入土中、收获时不造成伤口、雨后不马上收获——这四点就是不用药能做的全部，也是真正有效的全部。**

&nbsp;&nbsp;&nbsp;霜霉病是结球生菜上最常见的病害。评价表中防治自立度B所附的依据，正是关于这种病害的。有机栽培的实证试验中试过品种混种，但仅靠覆盖无法实现商业化防治，中度发生时损失至少为10%。这说明不用药物防治霜霉病并不容易。

&nbsp;&nbsp;&nbsp;不过发生条件很明确，应对方向也就明确。叶片潮湿的时间越长，病情就越重。因此浇水应在清晨进行，让叶片在白天变干；灌水时倒入沟中而不打湿叶片；并留出足够的间距以保持通风。如果有抗性品种，那是最可靠的手段。混合种植不同品种，可以延缓某一系统易感的病原菌蔓延到全田的速度。

&nbsp;&nbsp;&nbsp;菌核病是与生菜共有的土传病害。病株基部形成的黑色硬质菌核落入土中能存活数年，条件适合时会再次萌发。连作适应性评为B、需要休作2到3年，正是因为这种菌核。

> **感染菌核病的株，要连同根部周围的土一起挖出，运到地外。绝不能放入堆肥堆，因为菌核能耐受堆肥的发酵热而存活，进而扩散到全田。**

### 9-2. 主要害虫

| 害虫 | 危害 | 不用药的防治 |
|:---|:---|:---|
| 蚜虫 | 在叶背吸食汁液并传播病毒 | 喷洒肥皂水、保护瓢虫与蚜茧蜂、抗性品种 |
| 蓟马 | 刮食叶片汁液，留下银白色痕迹 | 黄色粘虫板诱杀、清除周边杂草 |
| 蛾类幼虫 | 啃食叶片并钻入结球内部 | 清晨人工捕捉、防虫网 |
| 蛞蝓 | 在叶片上留下孔洞与黏液痕迹 | 夜间人工捕捉、草木灰或稻壳隔离带 |
| 根螨 | 啃食根部导致植株萎蔫 | 轮作、改善排水 |

&nbsp;&nbsp;&nbsp;结球型作物中特别麻烦的是蛾类幼虫。叶片一开始卷合，幼虫就会钻进里面，之后就无法用手触及。它在看不见的内部啃食并留下粪便，这些粪便和伤口会招来软腐病。应对办法是在结球开始之前就把虫口数量降下来。从定植后就要开始检查叶背，找到并清除卵块；如果有条件，在结球开始前罩上稀疏的网，直接阻止蛾类产卵。结球一旦开始，就为时已晚。

&nbsp;&nbsp;&nbsp;蛞蝓和在生菜上一样令人头疼。它们白天躲在稻草下或石头下，夜里才出来活动，因此夜里提灯出去捕捉最为可靠。在株周撒一圈干草木灰、稻壳或蛋壳做成隔离带，蛞蝓因不愿让身体变干而不会越过，但一下雨效果就会消失。覆盖物成为藏身之处的问题也是一样，因此常用的折中办法是在基部周围留出巴掌大小的空间不覆盖。

### 9-3. 天然防治剂与农艺防治

| 防治剂 | 配制方法 | 对象 |
|:---|:---|:---|
| 肥皂水 | 将20g无香型肥皂溶于1L水中 | 蚜虫、螨虫 |
| 稀释牛奶液 | 牛奶与水按1比9混合 | 白粉病 |
| 草木灰浸出液 | 将草木灰浸入水中24小时后过滤使用 | 蚜虫 |
| 草木灰隔离带 | 在株周撒上干草木灰 | 阻隔蛞蝓 |
| 黄色粘虫板 | 在黄色板上涂粘胶后竖立 | 蓟马、有翅蚜虫 |
| 木醋液 | 稀释300-500倍后喷洒 | 驱避效果、抑制病害 |

| 原则 | 内容 |
|:---|:---|
| 轮作 | 菊科作物休作2-3年，若发生过菌核病则休作更长时间 |
| 通风 | 不缩小种植间距，是最廉价的防治手段 |
| 排水 | 提高垄高，是软腐病防治的根本 |
| 灌水时间与位置 | 清晨灌入沟中 |
| 覆盖 | 阻止雨水飞溅，切断土壤传播的途径 |
| 氮肥管理 | 过量会使组织变软，招来蚜虫聚集 |
| 残株处理 | 病株连土一起挖出运到远处，或加以焚烧 |
| 避开高温期 | 避免夏季栽培本身就是一种防治 |
| 抗性品种 | 是预先装进种子里的防治手段 |

&nbsp;&nbsp;&nbsp;在结球生菜上使用肥皂水时，必须严格控制浓度。叶片薄而柔嫩，浓度稍高就会受损，受损处会成为软腐病的入口。每1L水中肥皂不超过20g，喷洒数小时后用清水冲洗，能减少损伤。要避开正午，选在清晨或日落后喷洒。

## 10. 营养缺乏与过量

| 症状 | 原因 | 用天然材料采取的措施 |
|:---|:---|:---|
| 叶片整体发黄，植株矮小 | 缺氮 | 腐熟堆肥、尿液稀释15-20倍。只在结球期之前使用 |
| 叶缘变褐干枯 | 缺钾 | 少量施用草木灰 |
| 生长不良，叶片带紫色 | 缺磷 | 骨粉、草木灰。地温低时也会出现同样症状 |
| 结球松散且轻 | 磷和钾不足 | 在基肥阶段就已决定 |
| 内叶叶尖变褐干枯 | 钙移动受阻 | 均匀灌水、确保通风。蛋壳粉是长期对策 |
| 叶脉间发黄 | 缺镁 | 增加堆肥施用量 |
| 叶片大而深绿，内部却空虚 | 氮过量 | 停止供氮 |

&nbsp;&nbsp;&nbsp;结球生菜特有的缺乏症状有两种。一是干烧心，二是结球不良。两者的共同点是从外表都不容易看出来。

&nbsp;&nbsp;&nbsp;干烧心是内叶叶尖像被烧焦一样变褐干枯的症状。它是因为钙无法到达新长出叶片的顶端而产生的，与土壤中缺钙的关系不大，主要是水流未能到达那里所致。钙是随着蒸腾产生的水流移动的，而结球内部的叶片层层包裹，几乎不发生蒸腾。这就是结球生菜比生菜更容易出现干烧心的原因。应对办法不是往土里加钙，而是保持水分均匀、避免湿度过高、避免密植。

&nbsp;&nbsp;&nbsp;结球不良出现在磷和钾不足，或氮过量的时候。外表看起来长势不错，但收获后一按就明显凹陷，也没有分量。到了这个阶段已经无法挽救，因此判断必须在基肥阶段就做出。磷在土壤中不移动，所以翻地时就要混入；氮则要考虑到天然材料肥效偏晚的特点，提早停止施用。

&nbsp;&nbsp;&nbsp;氮过量在结球生菜上往往比缺氮更危险。叶片大而深绿，看起来长势良好，但组织软、细胞壁薄，容易感染软腐病和灰霉病，还会招来蚜虫聚集。最重要的是营养生长不会停止，无法转入结球。繁茂却内部空虚的株，大多就是这样产生的。

## 11. 间作与轮作

| 搭配 | 对象 | 效果 |
|:---:|:---|:---|
| 良好 | 豆科作物（豌豆、菜豆、豇豆） | 能固定氮素并留存于土中 |
| 良好 | 分葱、大葱、大蒜 | 气味能扰乱害虫 |
| 良好 | 萝卜、大白菜等十字花科 | 不共享病虫害，且根系深度不同 |
| 良好 | 茴香、香菜等气味浓烈的作物 | 能招来蚜虫的天敌 |
| 不良 | 生菜、茼蒿、菊苣、牛蒡等菊科 | 会共享菌核病与霜霉病 |
| 不良 | 结球生菜连作 | 菌核会不断累积 |

&nbsp;&nbsp;&nbsp;最好避免把结球生菜和生菜种在同一块地里相邻的位置。因为是同一物种，病虫害会完全共通，霜霉病一旦在一边开始，很快就会传到另一边。如果要同时种这两种作物，应把它们分别放在地的两端。

&nbsp;&nbsp;&nbsp;结球生菜的定植间距较大，初期地里有很多空地。利用这部分空间的方法就是间作。不过间种的作物如果长得比结球生菜高，会遮光妨碍结球，因此必须选个头矮小、生长期短的作物。适合的大致有嫩叶用生菜、分葱、菠菜之类。由于共享菊科病害，间种生菜需要谨慎，换成十字花科的幼嫩蔬菜则比较稳妥。

| 轮作顺序示例 | 年份 | 作物 | 地里发生的情况 |
|:---|:---:|:---|:---|
| 4年周期 | 第1年 | 结球生菜等菊科 | 菌核病风险开始累积 |
| | 第2年 | 豆科（大豆、豌豆、豇豆） | 氮素被固定并积累 |
| | 第3年 | 玉米、高粱等禾本科 | 菊科病原菌因缺乏宿主而衰减 |
| | 第4年 | 萝卜、大白菜等十字花科 | 用深根疏松土壤 |
| | 再回到第1年 | 结球生菜 | 在菌核密度降低的状态下重新开始 |

&nbsp;&nbsp;&nbsp;把禾本科安排在菊科之后种植的做法尤其有效。因为菌核病病原菌的宿主范围虽广，却难以有效感染禾本科作物。这一类包括水稻、玉米、高粱、小麦、大麦。

&nbsp;&nbsp;&nbsp;在结球生菜之前安排豆科作物时，需要留意氮素问题。豆科留下的氮如果较多，可能导致结球生菜一直吸收氮直到结球期，无法停止营养生长。在豆科之后的一年种结球生菜时，最好完全省略氮肥追肥或大幅减少用量，会更安全。
