## 2. 这是一种什么样的植物

### 2-1. 分类与来历

| 项目 | 内容 |
|:---|:---|
| 学名 |Lactuca sativa var. capitata |
| 科 | 菊科（Asteraceae） |
| 属 | 莴苣属（Lactuca） |
| 同种 | 生菜、罗马生菜、茎用生菜均为Lactuca sativa |
| 生活史 | 一年生（视条件可为二年生） |
| 别名 | 结球生菜、脆叶型、冰山生菜 |

&nbsp;&nbsp;&nbsp;结球生菜是从地中海沿岸传播到欧洲的生菜中，由人们挑选叶片向内卷曲的个体聚集而成的品系。16世纪的欧洲文献中出现了会结球的生菜，如今坚实的脆叶型则是19世纪末到20世纪初在美国培育完成的。冰山（Iceberg）这个名字并非来自这种生菜的性质，而是来自运输方式。20世纪初从美国西部经铁路运往东部时，装在装满冰块的货车车厢中，由此得来这个别称。

&nbsp;&nbsp;&nbsp;这一由来准确说明了结球生菜的性格。结球生菜不是在地里现吃的蔬菜，而是被培育成用于长途运输的品系。它结实紧密，即使受压也不易损伤，外叶保护内部，久放依然保持爽脆。这些都是以大量流通为前提选育出来的性状，因此营养密度或风味的深度并未列入选育标准。在物流中断的情况下评价这种作物时，需要牢记这一点。结球生菜是为流通而培育的作物，一旦流通条件消失，它就失去了培育目的的一半。不过另一半，也就是耐贮藏的结构，依然保留着。

### 2-2. 什么是结球

&nbsp;&nbsp;&nbsp;结球是叶片生长过程中向内弯曲、层层叠合的现象。它不是自然而然发生的，而是需要条件契合才会启动的生理转变。

&nbsp;&nbsp;&nbsp;顺序如下。首先外叶展开生长10到15片，这些叶片起到光合作用工厂的作用。接着新长出的叶片开始在外叶围成的篱笼内生长，这时叶片下表面与上表面的生长速度出现差异。下表面生长更快时，叶片就向内卷拢。这些弯曲的叶片相互叠合形成球状，内部不断有新叶挤入，使得球心逐渐变得紧实。

&nbsp;&nbsp;&nbsp;这里的关键在于，上下表面生长速度的差异在很大程度上受温度左右。气温升高时，这种差异会消失，甚至反转，使叶片向外张开。这正是结球适宜温度比生长适宜温度更低、区间更窄的原因。

| 阶段 | 定植后 | 发生的情况 | 温度条件 |
|:---|:---:|:---|:---|
| 活棵 | 1-2周 | 根系在新土中扎稳 | 15-20℃ |
| 外叶形成 | 2-6周 | 外叶展开10-15片 | 15-20℃ |
| 结球开始 | 6-7周 | 新叶开始向内弯曲 | 以15-18℃最为适宜 |
| 结球充实 | 7-10周 | 内部填满并变得紧实 | 10-18℃ |
| 收获期 | 10周以后 | 按压紧实即为适宜期 | |

> **结球只在外叶充分长大之后才会开始。外叶形成期长势不良的株，根本无法进入结球阶段。结球失败中的很大一部分，并非在结球期，而是在此前的阶段就已经决定了。**

### 2-3. 形态特征

| 器官 | 特点 |
|:---|:---|
| 叶 | 圆而宽，边缘深裂呈波浪状，向内卷曲结球 |
| 外叶 | 深绿色，厚而韧，起到保护内部的外壳作用 |
| 内叶 | 因未受光而呈淡黄至白色，爽脆多汁，口味清淡 |
| 茎 | 极短且压缩，位于结球的中心 |
| 根 | 直根系，20-30cm，相对较浅 |
| 花 | 黄色头状花序组成圆锥花序 |
| 果实 | 瘦果，长3-4mm，宽0.8-1mm，顶端带冠毛 |

&nbsp;&nbsp;&nbsp;外叶与内叶的颜色差异，直接反映了这种作物的营养结构。外叶呈深绿色，因此叶绿素、胡萝卜素和维生素K含量较多；内叶发白，含量则相应较少。然而人们主要吃的却是爽脆的内部。外叶常因质地粗韧而被丢弃。在灾害情境下，这是一个应当扭转的习惯。外叶含有大部分营养，如果太韧，焯一下或放进汤里就可以了。

&nbsp;&nbsp;&nbsp;14kcal的热量，在本文档所涉作物中属于最低的一档。若只靠结球生菜满足成年人一天2,100kcal的热量，需要吃下15kg，这不是人能吞下的量。指望从结球生菜中获取热量，从一开始就是不成立的算法。

&nbsp;&nbsp;&nbsp;不过蛋白质密度SS值得一提。每100g蛋白质0.90g，从绝对量看不算多，但除以热量14kcal后，蛋白质占热量的比例达到25.7%，是需求线10%的两倍半。这个数字之所以出现，是因为热量本身很低，并不意味着结球生菜是蛋白质来源，更准确的理解是：无论吃多少结球生菜，蛋白质比例都不会变差。

&nbsp;&nbsp;&nbsp;94%到96%的水分具有实际意义。在缺水的情况下，含水量高的蔬菜本身就成为一种水分来源。但这些水其实是从地里汲取来的水换了一种形态，因此在饮用水不足的情况下种植结球生菜，并不能算是节水的办法。总蒸散量500mm绝不是一个小数目。

## 3. 栽培环境

### 3-1. 温度

| 区分 | 温度 | 结果 |
|:---|:---:|:---|
| 发芽适温 | 18-21℃ | 6-8天发芽 |
| 发芽极限 | 26℃以上 | 因高温休眠而不发芽 |
| 生长适温 | 15-20℃ | 叶片生长良好 |
| 结球适温 | 15-18℃ | 结球效果最佳 |
| 可结球范围 | 10-20℃ | 超出此区间就会有风险 |
| 结球失败 | 25℃以上 | 叶片散开并抽薹 |
| 耐寒极限 | 零下5℃ | 外叶受损，严重时结球会散裂 |

&nbsp;&nbsp;&nbsp;这张表要读出的重点是，三个温度区间彼此不同。发芽喜好18-21℃，叶片生长适宜15-20℃，结球则以15-18℃最佳。在一个作期内必须依次经过这三个区间，而自然状态下的气温只朝一个方向变化：春天上升，秋天下降。

&nbsp;&nbsp;&nbsp;秋季栽培的优势由此而来。8月末到9月初播种时，发芽期气温仍暖，在18-21℃左右；叶片生长的9-10月为15-20℃；结球发生的10-11月则降到10-18℃。气温下降的方向恰好与作物所需温度下降的方向一致。

&nbsp;&nbsp;&nbsp;春季栽培则恰恰相反。2-3月的播种期发芽温度不足，需要保温；5-6月的结球期气温超过20℃，脱离结球条件。这就是春季栽培失败率高于秋季、产量也更低的原因。韩国国内的试验中，同一品种春季的产量有时会高于秋季，但那是在有保温设施和灌溉支持的条件下得出的数值。在既无设施也无地膜的情况下，秋季具有压倒性的优势。

> **结球生菜栽培的核心问题只有一个：结球开始时的气温是否为15-18℃。可以说，倒推播种日期以回答这个问题，就是这种作物的全部栽培技术。**

### 3-2. 光照

| 项目 | 标准 |
|:---|:---|
| 所需光照 | 每天8-10小时 |
| 半阴 | 能耐受，但结球会变松散 |
| 40%遮光 | 相对产量86%（置信区间61-120） |
| 光敏发芽性 | 有。种子埋得过深则不发芽 |

&nbsp;&nbsp;&nbsp;光照不足会使结球变得松散。光合作用产生的糖不足时，叶片会变薄变轻，即便这些叶片叠合，也无法形成应有的重量与密度。按压时明显凹陷的结球，通常是光照或养分不足的信号。不过遮光试验的结果显示，叶菜类整体即使遮光40%，相对产量仍能保持86%，因此半天左右的阴影并非致命。像建筑物阴影或树下这类一天只有一半时间有阳光的地方，也是能结球的。

### 3-3. 水分与土壤

| 项目 | 标准 | 备注 |
|:---|:---|:---|
| 总蒸散量 | 约500mm | 高于生菜的350mm |
| 结球期水分 | 保持不干 | 此时的干旱是结球失败的主要原因 |
| 过湿 | 根腐病与软腐病 | 提高垄高 |
| 土壤 | 排水良好的砂壤土至壤土 | 也需要一定的保水力 |
| 土壤酸度 | pH 6.0-6.8 | 酸性土中生长变差 |
| 有机质 | 越多越好 | 同时提升保水力与养分 |

&nbsp;&nbsp;&nbsp;总蒸散量500mm是结球生菜栽培中最实际的负担。比生菜的350mm多43%，这一差距会换算成挑水的劳动量。如果自来水中断，必须从井里或溪流中挑水，那么这多出的43%就会原样加到每天的劳动时间上。

&nbsp;&nbsp;&nbsp;结球生菜耗水量大的原因有两个。一是生长期长，总用水量随之累积；二是结球期需要用水填满大量细胞。结球期缺水会导致内部无法填满，而这时的失败即便之后再浇水也无法恢复，因为细胞分裂结束之后，剩下的只有让这些细胞膨大这一件事。

&nbsp;&nbsp;&nbsp;土壤酸度降到pH6.0以下时，生长会明显变差。酸性土壤中磷会被铝和铁固定，变成根系无法利用的形态，而磷是直接参与结球的元素。没有石灰时，草木灰、烧过的贝壳粉、蛋壳粉都可以作为提高酸度的天然材料。不过一次施用过多会使微量元素被固定，因此应少量分次施入。

## 4. 品种

### 4-1. 两个类型

| 类型 | 特点 | 在灾害情境下 |
|:---|:---|:---|
| 脆叶型 | 叶缘深裂，结球紧实 | 耐储性最好，最符合种植这种作物的目的 |
| 奶油型 | 半结球型，叶片柔软，结球松散 | 结球失败风险较低，但储藏优势也较小 |

&nbsp;&nbsp;&nbsp;两个类型的选择实际上是把风险放在哪里的问题。脆叶型一旦结球成功，就会形成紧实的球体，能保存一周以上，但结球条件苛刻，失败风险较大。奶油型卷合松散，条件稍有偏差也能大致成形，但正因为松散，储藏性下降，与生菜相差不大。

&nbsp;&nbsp;&nbsp;如果种结球生菜的目的是储藏，脆叶型更合适。如果目的不是储藏，那么种结球生菜的理由本身就不充分。因此实际的选择会偏向脆叶型，相应地也要更用心地满足结球条件。

&nbsp;&nbsp;&nbsp;这张表中值得关注的是抗性品种的存在。在没有药剂的情况下，抗性就是预先装进种子里的防治手段。如果备有抗霜霉病的品种，对这种病就什么都不用做，这比任何天然防治剂都更可靠。

&nbsp;&nbsp;&nbsp;不过灾害持续下去，引进品种的种子就得不到补充。这样一来，剩下的就只有自己留下的种子，抗性能否遗传就成了问题。结球生菜是自花授精作物，如果抗性由单一显性基因决定，就会原样传给下一代。但如果是作为F1杂交种出售的品种，留种后性状就会分离。查看种子袋上是否标有杂交种字样，对这种作物来说具有实际意义。

### 4-3. 按情形选择

| 情形 | 选择 | 理由 |
|:---|:---|:---|
| 以储藏为目的 | 脆叶型早熟品种 | 紧实的结球带来耐储性 |
| 担心结球失败 | 奶油型或生菜 | 即使失败也能吃到叶片 |
| 秋季栽培 | 早熟品种 | 必须在霜降前完成结球 |
| 春季栽培 | 晚抽薹品种 | 需要在气温上升期间维持住 |
| 蚜虫多的地块 | 抗性品种 | 是不用药防治最可靠的方法 |
| 计划连续留种使用 | 固定种 | 杂交种性状会分离 |

&nbsp;&nbsp;&nbsp;秋季栽培选早熟品种，是出于时间上的计算。定植到收获需要50-60天，必须从霜降的时间点倒推，确保这段时间。韩国中部初霜在10月下旬到11月初，因此9月初就必须完成定植。如果选晚熟品种，结球还没完成就会遇上霜冻。
