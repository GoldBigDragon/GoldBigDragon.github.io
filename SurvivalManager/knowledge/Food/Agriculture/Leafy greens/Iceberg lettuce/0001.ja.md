## はじめに
&nbsp;&nbsp;&nbsp;玉レタス(Lactuca sativa var. capitata)はサンチュと同じ種で、葉が内側に巻いて頭のように丸い塊になる結球が、2つの作物の運命を分けます。総合等級はE(35.7点、有効183種中161位)で、サンチュのD(37.7点)より低いです。永続性、温度幅、水の消費量、収穫速度など6項目がすべて同じ方向に下がり、その原因は結球というひとつの性質です。結球には外葉が先に育つ必要があるので生育期間が長くなり、成長点を丸ごと持っていくので再生収穫ができず、大きな塊を膨らませるために水がより必要で、結球の温度区間が葉の育つ区間より狭いです。結球に失敗すると、4か月育てた畑から使えるものがほとんど残らず、1作期の食料計画が崩れます。長所は貯蔵性のひとつです(D、常温で1週間。サンチュはE、2-3日)。外葉が何枚も内側の葉を包み、空気にさらされないからです。秋に植えて初冬に収穫した結球を数個、貯蔵穴に入れて、霜がすべての葉物を終わらせた後も数週間、新鮮なものを残すのが、この作物の使い方です。畑全体を任せる作物ではなく、災害の初期に急いで植える作物は、なおさらそうではありません。

## 1. 災害への備えの評価
| 区分 | 等級 | スコア |
|:---|:---:|:---:|
| 総合 | E | 35.7 |
| 短期 | D | 36.4 |
| 長期 | E | 35.1 |
| 副食 | S | 57.1 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: タンパク質密度、施設の負担、調理・加工の要求度。S: 味、自家採種。A: 微量栄養素(15種)、収穫速度、収量の安定性、国内での栽培の普及度。B: 施肥、水の消費量、日射、耐寒性、防除の自立度、連作への適応性、種子の寿命 |
| 弱み | E: 非食用の価値。D: 面積当たりの熱量、永続性、温度幅、貯蔵性。C: 病害虫圧、合成資材を投入しない場合の収量維持率、整地・掘削エネルギー |

| サンチュとの比較 | サンチュ | 玉レタス | 理由 |
|:---|:---|:---|:---|
| 永続性 | A (2-3か月) | D (1回きり) | 結球を収穫すると成長点がなくなる |
| 温度幅 | C (15-22℃) | D (15-20℃) | 結球の条件が生育の条件より狭い |
| 貯蔵性 | E (2-3日) | D (1週間) | 外葉が内側を包んで守る |

> **玉レタスはサンチュの上位互換ではありません。同じ種から分かれた別の戦略であり、災害という条件では、たいてい不利な側にあります。玉レタスを植える理由があるとすれば、ただひとつ、霜が来た後の数週間、新鮮な野菜を残すためです。**

&nbsp;&nbsp;&nbsp;項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | キク科アキノノゲシ属。一年草(条件により二年草)。別名は結球レタス、クリスプヘッド、アイスバーグ |
| 葉 | 丸くて広く、縁が深く切れ込んで波形。外葉は濃い緑色で厚くて硬く、内側を守る皮の役目をし、内側の葉は光を受けられず淡黄色-白色で、シャキシャキして水分が多く、味がおだやか |
| 茎、根、花 | 茎はとても短く圧縮されて結球の中心にある。主根は20-30cmと浅い。黄色い頭花が円錐花序をつくり、果実は長さ3-4mmの痩果(先端に冠毛) |

| 段階 | 定植後 | 要点 |
|:---|:---|:---|
| 活着 | 1-2週間 | 根が新しい土に落ち着く。15-20℃ |
| 外葉の形成 | 2-6週間 | 外葉10-15枚が広がる。15-20℃ |
| 結球の開始、充実 | 6-7週間、7-10週間 | 新しい葉が内側に曲がり始め(15-18℃が最もよい)、中が詰まって硬くなる(10-18℃) |
| 収穫期 | 10週間以降 | 押して硬ければ適期 |

> **結球は、外葉が十分に育った後にだけ始まります。外葉の形成期に生育が不十分だと、その株は結球そのものに入れません。結球失敗の相当部分は、結球期ではなく、その前の段階ですでに決まっています。**

&nbsp;&nbsp;&nbsp;100g当たり熱量14kcal、水分94-96%、タンパク質0.90g(熱量比は高い)、炭水化物2.3g、食物繊維1.2g、糖類1.97g、ビタミンC 7mg、βカロテン96㎍(外葉に集まっており、ビタミンKも同様)、葉酸66.7㎍、カリウム167mg、カルシウム32mgです。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽適温18-21℃(6-8日)、26℃以上は高温休眠で発芽しない。生育適温15-20℃、結球適温15-18℃、結球可能10-20℃、25℃以上だと葉が開いてとう立ちする。-5℃で外葉が傷み、ひどいと結球が割れる |
| 光 | 1日8-10時間。半日陰には耐えるが、結球がゆるくなる。40%遮光で相対収量86%。好光性種子なので、種を深く埋めると発芽しない |
| 水、土壌 | 総蒸発散量は約500mm(サンチュ350mm)。結球期に乾かさない(この時期の干ばつが結球失敗の主な原因)。過湿は根腐れと軟腐病を呼ぶので畝を高くする。水はけのよい砂壌土-壌土、pH 6.0-6.8、有機物は多いほどよい |

> **玉レタス栽培の核心的な問いはひとつです。結球が始まる時点の気温は15-18℃か。この問いに答えるよう播種日を逆算することが、この作物の技術のすべてと言っても過言ではありません。**

&nbsp;&nbsp;&nbsp;秋作が有利で、春作は結球期に気温が上がって失敗しやすいです。品種は、クリスプヘッド(葉の縁が深く切れ込み、結球が硬く、貯蔵性が最もよく、この作物を植える目的に合う)とバターヘッド(半結球型で葉が柔らかく結球がゆるいので、失敗の危険は低いが、貯蔵の利点も小さい)に分かれます。アブラムシやべと病に抵抗性のある導入品種もありますが、災害が長引くと種は補充されません。貯蔵が目的ならクリスプヘッドの早生種(霜の前に結球を終える)、結球の失敗が心配ならバターヘッドやリーフレタス(失敗しても葉を食べられる)、種をつなぐ計画なら固定種です。

## 4. 畑の準備と播種、定植
| 項目 | 基準 |
|:---|:---|
| 土づくり | 25-30cmの深さに耕し、畝の高さ20cm以上(過湿と軟腐病を防ぐ)、幅100-120cm(2列植え)、排水溝は必須(結球期に水がたまると丸ごと腐る)、表面を平らにならす |
| 施肥(1,000㎡) | 窒素12-15kg、リン酸8-10kg(全量元肥、結球に直接関わる)、カリウム8-10kg、石灰150kg。元肥は定植の1-2週間前に、堆肥の全量、リン酸の全量、窒素とカリウムの半分。追肥の1回目は定植後3週間ごろ、窒素・カリウム(外葉を育てる)、2回目は結球開始のころ、カリウム・リン酸(中を詰めて硬くする) |
| 代替資源 | 木灰を1株に一つかみ(アルカリ性なので、多いとpHが上がる)、完熟堆肥(未熟だと根を傷める)、尿の10-20倍希釈液(株の間に、結球開始後はやらない)、骨粉、卵の殻・貝殻の粉(カルシウム)、発酵させた油かす(生だと発酵熱で根を焼く) |

> **窒素は結球期に多いと、葉が大きくなり続けようとして内側に巻きません。見た目は茂っているのに中が空洞の株が出る最も多い原因が、結球期の窒素過多です。**

| 作型 | 播種 | 定植 | 収穫 |
|:---|:---|:---|:---|
| 秋作 | 8-9月 | 9-10月 | 11-12月。災害時には事実上唯一の選択 |
| 春作 | 2-3月 | 3-4月 | 6-7月。結球期に気温が上がり、失敗の危険が大きい |

&nbsp;&nbsp;&nbsp;夏作は発芽も結球もともに妨げられるので勧めません。秋まきの難しさは8月の暑さ(26℃以上の高温休眠)で、種を4-6時間浸して濡れた布に包み涼しい場所に1日置く低温プライミング、あらかじめ芽出しして播く、日が沈んでから播種する、薄い日陰をつくる、涼しい場所で育苗する、といった方法で対応します。

| 植え方 | 基準 |
|:---|:---|
| 育苗 | 深さ0.5-1cm(好光性なので、深く埋めると出ない)、18-21℃で6-8日で発芽、20-30日育苗して本葉4-5枚で定植。定植の数日前から水を減らし、外気に出して硬くすると活着が早い |
| 定植 | 株間30-35cm、条間50-60cm(1,000㎡当たり3,000-3,500株)。本葉の根元が土に埋まらないように(埋まると根元が腐る)曇りの日か夕暮れに植え、すぐたっぷり水をやる。間隔を狭めるとたいてい損 |

> **定植が遅れると結球は失敗します。本葉が6枚を超えた苗は、根がすでに狭い場所で絡まっており、移した後は回復に時間を使って、外葉を適時に育てられません。**

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 定植直後-活着 | たっぷり(根が新しい土に付く必要がある) |
| 活着後-外葉形成期 | 表土が乾いたら(根を下へ導く) |
| 結球期 | 乾かさないように(玉レタスの水管理は結球期ひとつにかかっている) |
| 収穫の1週間前 | 減らすか止める(組織が硬くなって貯蔵性が上がる) |

&nbsp;&nbsp;&nbsp;昼にしおれて夕方に回復すれば一時的な不足、夕方にも回復しなければ、すぐ十分にやります。結球がゆるくて軽ければ結球期の水不足で、元には戻せません。内側の葉の先が褐色に枯れるチップバーンは、水分の不均衡によるカルシウムの移動障害なので、水を均等にやります。結球が割れるのは、乾いた後に急に多くの水をやったためで、外葉が黄色くなり株元が軟らかくなれば過湿なので、排水溝を切って水やりを止めます。水を節約するには、わらと枯れ草のマルチ(最も安い節水手段)、早朝の溝かん水、風よけを使います。

| 結球失敗の条件 | どうなるか |
|:---|:---|
| 高温 | 葉が開いたまま育って花茎が立つ(葉の裏面と表面の成長速度の差がなくなる) |
| 窒素過多 | 葉が大きく茂るが中が空洞(栄養生長が止まらない) |
| 定植の遅れ | 外葉が不十分で、結球を始められない |
| リン酸不足、結球期の水不足、光量不足、密植 | 結球がゆるくて軽い / 中が詰まらない / 結球がゆるい / 互いに遮って光と養分を奪い合う |

> **結球の失敗は、結球期に起こる事故ではなく、その前の2か月の結果が表れる瞬間です。葉が開き始めた後にできることはほとんどありません。播種日を決める時点、苗を移す時点、窒素を止める時点で、すでに決まっています。**

&nbsp;&nbsp;&nbsp;そのほか、定植の1週間後に欠株を補い、雑草が小さいうちに草取りをし(根が浅いので深く削ると傷む)、生育中期に1回土寄せをし、黄色く枯れた下の葉を取り除きます。

## 6. 病害虫と養分の問題
| 病害 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| べと病 | 葉の表に黄褐色の斑点、裏に白いカビ。涼しく湿っているとき(玉レタスで最も多い) | 通風、朝のかん水、抵抗性品種、病葉の除去 |
| 軟腐病 | 株元と中が軟らかく崩れて悪臭。高温多湿、排水不良、傷 | 畝を高くする、排水、傷をつけない |
| 菌核病 | 株元が軟らかくなり、白い菌糸と黒い粒。低温多湿、キク科の連作 | 深耕、マルチ、2-3年の輪作、病株の完全な除去 |
| 灰色かび病、うどんこ病、すそ腐病 | 灰色のカビ / 葉の表の白い粉 / 株元の褐変と倒伏 | 湿度管理・間隔の確保 / 通風・日照・牛乳の希釈液 / 浅植え・排水 |

> **軟腐病は、治療ではなく条件管理の問題です。水をためない、株元を土に埋めない、収穫のときに傷をつけない、雨の直後には収穫しない。この4つが、薬を使わずにできるすべてであり、実際に効果があるすべてです。**

&nbsp;&nbsp;&nbsp;菌核病にかかった株は、根の周りの土ごと掘り上げて畑の外へ運びます。堆肥の山に入れてはいけません(菌核が堆肥の発酵熱に耐えて生き残り、畑全体に広がる)。害虫は、アブラムシ(石けん水、テントウムシとアブラバチを守る、抵抗性品種)、アザミウマ(黄色粘着トラップ、周辺の雑草の除去)、ガの幼虫(結球の中にもぐり込む: 早朝に手で捕る、防虫網)、ナメクジ(夜に捕る、灰やもみ殻の帯)、ネダニ(輪作、排水の改善)です。防除資材は、石けん水(無香料の石けん20gを水1Lに)、牛乳の希釈液(牛乳と水を1対9、うどんこ病)、木灰の浸出液(木灰を水に24時間浸してこして使う)、木酢液300-500倍です。耕種的には、キク科を2-3年休ませ、間隔を狭めず、マルチで雨の跳ね返りを防ぎ、窒素を減らし、高温期の栽培を避けます。

| 症状 | 原因と対処 |
|:---|:---|
| 葉全体が黄色く株が小さい | 窒素欠乏。完熟堆肥、尿の15-20倍希釈(結球期までだけ) |
| 葉の縁が褐色に枯れる | カリウム欠乏。木灰を少量 |
| 生育不良、葉が紫がかる | リン酸欠乏(地温が低いときにも同じ症状)。骨粉、木灰 |
| 結球がゆるくて軽い | リン酸とカリウムの不足(元肥の段階で決まる) |
| 葉が大きく濃い緑だが中が空洞 | 窒素過剰(玉レタスでは欠乏より危険な場合が多い)。窒素の供給を止める |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | マメ科作物(エンドウ、インゲンマメ、ササゲ: 窒素を固定)、ワケギ・長ネギ・ニンニク(においが害虫を惑わす)、ダイコン・ハクサイなどアブラナ科(病害虫を共有せず、根の深さが違う)、ディル・コリアンダー(アブラムシの天敵を呼ぶ) |
| 悪い | サンチュ・シュンギク・チコリ・ゴボウなどキク科(菌核病とべと病を共有)、玉レタスの連作(菌核がたまる) |

&nbsp;&nbsp;&nbsp;玉レタスとサンチュは同じ畑に並べて植えないほうがよく、定植の間隔が広くて初期に空き地が多いので、その間をワケギやディルで埋められます。4年周期で、玉レタスなどキク科、マメ科(窒素固定)、トウモロコシ・モロコシなどイネ科(キク科の病原菌が飢える)、ダイコン・ハクサイなどアブラナ科を経ると、菌核の密度が下がった状態で、再び玉レタスを始められます。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 定植後、秋作は50-60日、春作は60日前後、冬作は90日。上から押して硬く踏ん張れば完成。早朝(水分を含んで最も重い)に収穫し、雨の直後や葉が濡れているときは避ける(葉の間に残った水が、貯蔵中の軟腐病の始まりになる)。雨がやんで1、2日たち、葉が乾いてから収穫する |
| 要領 | 株元をナイフで一度に切り(何度も切ると切り口が荒れて傷む)、外葉2-3枚を残し(貯蔵中に内側を守る皮)、切り口を日陰で乾かし、洗わずに保管する。切り口からはサンチュと同じく白い乳液が出る |
| 一度きり | 永続性Dで収穫したら終わりなので、時期の分散が、貯蔵より先に来る問題。切った株元から脇芽が出て、小さな葉が数枚育つこともある |

| 採種 | 基準 |
|:---|:---|
| 難点 | 結球が硬いので花茎が結球を突き破れず、中で曲がって育って腐る。結球の頂上に十字の浅い切れ込みを入れて道をつくり、中に水がたまらないよう雨を避け、排水を確保する。採種株は、結球がきちんとできた株のうち、花茎が無事に出たものから選ぶ(結球に失敗した株から採ると、その性質が受け継がれる) |
| 日程 | 収穫適期(定植後50-60日)に採種株を残すと、3-5週間後にとう立ち、その3-4週間後に開花、12-24日後に種子が成熟。播種後150-180日で、サンチュより1か月ほど長い |
| 種の採り方 | 花茎に通気性のある紙袋や布袋をかぶせるか、2-3日に1回、ふくらんだ花だけをしごいて採る(回収率が最も高い)、半分以上ふくらんだら花茎ごと刈って後熟させる(未熟な種が混ざる) |
| 寿命 | 常温で密封して2-3年(涼しく乾いていればもっと持つ)。密閉容器に入れ、涼しく暗く乾いた場所に置く。毎年20粒を濡れた布に置いて発芽数を数える。採りたての種は高温休眠がより強い |

## 9. 貯蔵
| 条件 | 貯蔵期間 |
|:---|:---|
| 常温のまま | 5-7日 |
| 涼しい日陰(15℃前後) | 1-2週間 |
| 土間の蔵・貯蔵穴(10℃前後) | 2-3週間 |
| 貯蔵穴で濡れた砂やわらと一緒に | 3-4週間 |

&nbsp;&nbsp;&nbsp;外葉2-3枚を付けたままにし、切り口を日陰で1-2時間乾かし、洗わず、通気性のある濡れた布でゆるく包むか、貯蔵穴では濡れた砂やわらの間に根を下にして互いに触れないよう間隔を空けて置き、株元にひもを結んで涼しい場所に逆さにつるし、かめには濡れた布を敷いてゆるくふたをします(完全に密封すると軟らかくなる)。

> **貯蔵するものと先に食べるものを、収穫の時点で分けておきます。割れた結球、押された跡のあるもの、虫が入った跡のあるもの、雨の直後に収穫したものは、貯蔵せず先に食べます。傷んだひとつが、隣の無事なものを引きずり下ろします。**

&nbsp;&nbsp;&nbsp;玉レタスは加工による貯蔵にあまり向きません。外葉を湯通しして日陰で干せば数か月(外葉の処理用)、2-3%の塩水の水キムチは1-2週間(シャキシャキ感が少し残る)、即席の塩漬けサラダは2-3日(貯蔵というより調理)です。

## 10. 調理と注意事項
| 部位 | 性質 | 用途 |
|:---|:---|:---|
| 内側の葉、中間の葉 | シャキシャキして穏やか、栄養は薄い | 生食、巻いて食べる、サラダ、即席の塩漬け(しんなりして、かさが減り、たくさん食べられる) |
| 外葉 | 濃い緑色、硬くてやや苦い。栄養が最もよい | 湯通し、汁物、炒め物、干して保管 |
| 芯 | 硬くて甘みがある | 薄く切って生食するか、炒める |

&nbsp;&nbsp;&nbsp;水キムチは発酵でビタミンCの相当部分が残ります。火を通すとシャキシャキ感がなくなって軟らかくなるので、長く煮ません。

| 成分 | 内容 |
|:---|:---|
| 毒性、ラクツカリウム | 玉レタスに毒性はない。切るとサンチュと同じく白い乳液(ラクツカリウム)が出るが、内側の葉は光を受けず防御物質の産生が少ないので、サンチュより少ない。シュウ酸も低い |
| 硝酸塩 | 内側の葉にサンチュより多くたまることがある(光がないとタンパク質に転換されない)。窒素の施肥過多、曇りの日、早朝の収穫で増え、晴れた日の午後の収穫では低い。正常に育てた玉レタスを普通の量で食べるのは問題なく、結球期に窒素を止めることは、結球のためにも硝酸塩を減らすためにも正しい |

## 11. 年間作業日程
| 月 | 春作 | 秋作 |
|:---|:---|:---|
| 1-2月 | 種子の点検、畑の計画、堆肥の管理。2月に播種と育苗(保温が必要) | |
| 3-4月 | 育苗を続ける、3月下旬に定植と元肥。4月に活着と外葉の形成、1回目の追肥 | |
| 5-6月 | 結球期(水管理が最も重要)。6月に収穫、採種株は残す | |
| 7-8月 | 採種株のとう立ちと開花、8月に種子の収穫と選別 | 8月下旬に播種(高温休眠への対応) |
| 9-10月 | | 9月に育苗と定植(上旬までに終える)。10月に外葉の形成と結球の開始、追肥 |
| 11-12月 | | 11月に結球が完成して収穫、貯蔵を始める。12月に貯蔵品の点検、畑の整理と残渣の処理 |

> **玉レタスは畑の柱ではなく、冬へ渡る橋です。霜がすべての葉物を終わらせた後、貯蔵穴に数個が残っていること、その数週間が、この作物の仕事のすべてです。その仕事のために3か月と500mmの水を使う価値があるかを判断することが、この作物を植えるかどうかを決める基準です。**
