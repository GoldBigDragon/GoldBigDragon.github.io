## 5. 整地与施肥

### 5-1. 整地

| 项目 | 标准 | 理由 |
|:---|:---|:---|
| 耕深 | 25-30cm | 根系可深达20-30cm |
| 垄高 | 20cm以上 | 防止过湿与软腐病 |
| 垄宽 | 100-120cm (双行种植) | |
| 排水沟 | 必须留出 | 结球期积水会导致整球腐烂 |
| 整地 | 使地表平整 | 避免水分偏向一侧积聚 |

&nbsp;&nbsp;&nbsp;在结球生菜地里把垄做高，与其说是可选项，更接近于必需。结球后的球体几乎贴着地面，底部一旦积水，就会从基部开始发生软腐病。软腐病是细菌性病害，一旦发生就会向内部侵蚀，几天之内整个球体就会腐烂溃烂。种了三个月的作物可能在三天内化为乌有，而这背后的原因大多是排水不良。

&nbsp;&nbsp;&nbsp;在没有地膜的情况下，覆盖材料可用稻草、干草、落叶、稻壳。覆盖能防止雨水飞溅把土中的病原菌带到叶片上，延缓地温过度升高，并减少水分蒸发。对于像结球生菜这种在结球期需要大量水分的作物，最后一项效果尤其明显。不过稻草覆盖会成为蛞蝓的藏身之处，因此常用的折中办法是在基部周围留出巴掌大小的空间不覆盖。

### 5-2. 施肥量

&nbsp;&nbsp;&nbsp;评价表中的施肥需求等级为B，依据是每㎡的N、P、K合计约24g，略高于生菜的22g。按1,000㎡折算如下。

| 肥料 | 按1,000㎡ | 折算每㎡ | 备注 |
|:---|:---:|:---:|:---|
| 氮(N) | 12-15kg | 12-15g | 分为基肥与追肥 |
| 磷(P) | 8-10kg | 8-10g | 全部作基肥，直接参与结球 |
| 钾(K) | 8-10kg | 8-10g | 分为基肥与追肥 |
| 堆肥 | 1,500-2,000kg | 1.5-2kg | 腐熟堆肥 |
| 石灰 | 150kg | 150g | 用于改良酸性土 |

| 区分 | 时期 | 施用内容 | 目的 |
|:---|:---|:---|:---|
| 基肥 | 定植前1-2周 | 全部堆肥、全部磷、氮和钾各一半 | 根系触及时必须已经分解 |
| 第一次追肥 | 定植后约3周 | 以氮和钾为主 | 促进外叶生长 |
| 第二次追肥 | 结球开始前后 | 以钾和磷为主 | 使内部填满并变得紧实 |

&nbsp;&nbsp;&nbsp;把磷全部作为基肥施入是有原因的。磷在土壤中几乎不移动。如果施在表面，就会停留在原地，根系无法接触到。因此在翻地时必须与土混合，提前施入根系将要生长的土层。结球生菜缺磷时，结球会变得松散，内部无法填满。磷缺乏在初期不容易从外观上察觉，往往到结球期才以结果的形式显现出来，因此可以说这是在基肥阶段就已经决定了的事。

> **氮则恰恰相反。结球期氮过多时，叶片会持续想要长大，而不向内卷合。外观繁茂却内部空虚的株，最常见的原因就是结球期氮过量。**

&nbsp;&nbsp;&nbsp;这个原理在灾害情境下尤其重要，是有原因的。没有化肥时，用作氮源的是稀释尿液和腐熟度较低的堆肥，这两者的氮都会缓慢释放到较晚的阶段。结果就可能出现基肥中施入的氮，反而在结球期才发挥作用的情况。因此使用天然材料时，应把氮源反而提前施入，并计划在结球开始前后彻底停止追氮。

### 5-3. 灾害应对替代肥料

| 材料 | 供给成分 | 使用方法 | 注意 |
|:---|:---|:---|:---|
| 草木灰 | 钾、磷、钙 | 每株一把混入土中 | 呈碱性，过量会使pH升高 |
| 腐熟堆肥 | 综合养分 | 作基肥充足施用 | 未充分腐熟会伤根 |
| 稀释尿液 | 氮、钾 | 用水稀释10-20倍施于株间 | 结球开始后不再施用 |
| 骨粉 | 磷、钙 | 作基肥混入土中 | 见效缓慢 |
| 蛋壳粉 | 钙 | 混入基肥 | 需磨细才能分解 |
| 油渣、豆饼 | 氮、磷 | 发酵后作基肥 | 未发酵的会因发酵热烧伤根系 |
| 烧贝壳粉 | 钙 | 代替石灰 | 应少量分次施入 |

&nbsp;&nbsp;&nbsp;草木灰是灾害情境下最容易获得的钾源，因为烧火必定会产生。但草木灰中钙含量也高，碱性较强，容易把结球生菜偏好的pH 6.0-6.8范围推高。因此应限制在每株一把左右的量，若不是酸性很重的地，不必每年都施。保存时要避免受潮，否则钾会流失。

&nbsp;&nbsp;&nbsp;尿液同时含有氮和钾，很有用，但在结球生菜上必须遵守使用时期。只能用到定植后约3周的第一次追肥为止，结球开始后就要停用。稀释倍数为10-20倍，接触叶片会造成灼伤，因此应倒入株间的沟中。放置数日后尿素会转化为氨，气味变重、浓度也会改变，因此当天接取当天使用更为稳妥。

&nbsp;&nbsp;&nbsp;评价表中的无合成投入产量保持率为C，40.8%。这意味着不用合成肥料栽培时，产量会跌到40%左右的水平，而蔬菜组是全部作物组中这个差距最大的一组。在结球生菜上，这种下降不仅表现为产量减少，还表现为结球失败。养分不足时外叶长不好，外叶不健壮就无法进入结球阶段。因此用天然材料栽培时，比其他作物多施一些堆肥，同时适当加大种植间距以确保单株获得的资源，是更现实的做法。

## 6. 播种与定植

### 6-1. 作型

| 作型 | 播种 | 定植 | 收获 | 备注 |
|:---|:---|:---|:---|:---|
| 春季栽培 | 2-3月 | 3-4月 | 6-7月 | 结球期气温上升，失败风险大 |
| 秋季栽培 | 8-9月 | 9-10月 | 11-12月 | 在灾害情境下实际上是唯一的选择 |
| 夏季栽培 | 不推荐 | | | 发芽和结球都会受阻 |

&nbsp;&nbsp;&nbsp;秋季栽培的优势正如前面温度部分所述。再补充一点，秋季栽培得到的结球恰好出现在最需要的时候。11月和12月是地里能收获的东西急剧减少的时期，而这时正好有可以贮藏的叶菜可用。

&nbsp;&nbsp;&nbsp;秋播的难点在于8月的酷热。发芽极限是26℃，而8月下旬的地温比这更高。这与生菜相同的高温休眠问题，应对方法也相同。

| 方法 | 步骤 | 原理 |
|:---|:---|:---|
| 低温引发 | 将种子浸水4-6小时后用湿布包好，放在凉爽处一天 | 吸水的种子经历低温，休眠得以解除 |
| 预先催芽 | 在湿布之间稍微露白后再移出播种 | 让发芽过程在田外完成 |
| 傍晚播种 | 日落后播种并充分浇水 | 利用夜间降低的地温 |
| 遮光 | 用竹帘或树枝在播种处制造薄阴 | 使地温降低几度 |
| 在凉爽处育苗 | 在朝北的屋檐下或树荫下育苗 | 比地里低几度 |

&nbsp;&nbsp;&nbsp;结球生菜与生菜不同，通常要经过育苗再定植，这一点在应对高温休眠上反而更有利。因为无法降低整块地的地温，但把一个育苗盘搬到凉爽处并不难。在朝北的屋檐下或树荫下发芽，长出真叶后再移到地里，就能避开8月的酷热。

### 6-2. 育苗

| 阶段 | 标准 | 备注 |
|:---|:---|:---|
| 播种深度 | 0.5-1cm | 具光敏发芽性，埋得过深不发芽 |
| 发芽温度 | 18-21℃ | |
| 发芽期 | 6-8天 | |
| 育苗期 | 20-30天 | |
| 定植适期 | 真叶4-5片 | 不能超过这个时点 |
| 育苗盘 | 育苗盘、木箱、装土的容器均可 | |

> **定植延迟会导致结球失败。真叶超过6片的苗，根系已经在狭小的空间里纠结在一起，移栽后要花时间恢复，无法按时长好外叶。外叶不健壮就无法进入结球阶段，季节也就这样错过了。**

&nbsp;&nbsp;&nbsp;这是结球生菜栽培中最常见的失败原因之一。苗看起来越大似乎越健壮，实际却恰恰相反。根系已经盘绕的苗，移栽后近两周不会生长，而这两周会把结球时点向后推，导致与所需气温错位。真叶4-5片、根系刚轻轻抓住育苗盘土壤的程度，才是适宜的定植时机。

&nbsp;&nbsp;&nbsp;定植前几天开始减少浇水，并让苗接触室外空气使其变得结实，这样能加快活棵。只在室内或阴处长大的苗，叶片薄而软，一放到地里就容易被晒伤或被风吹萎。花四到五天逐渐让苗适应阳光和风即可。

### 6-3. 定植

| 项目 | 标准 | 备注 |
|:---|:---|:---|
| 株距 | 30-35cm | 需要留出结球所需的空间 |
| 行距 | 50-60cm | 确保通风 |
| 种植密度 | 每1,000㎡种3,000-3,500株 | 每㎡3-3.5株 |
| 栽种深度 | 使真叶基部不被埋入土中 | 埋入会导致基部腐烂 |
| 定植时间 | 阴天或日落前后 | 正午定植会导致萎蔫 |
| 定植后 | 立即浇透水 | 需使根系与土壤紧密接触 |

&nbsp;&nbsp;&nbsp;栽种深度很重要。结球生菜的茎几乎被压缩到近乎消失，叶片直接连在基部上。栽得太深使基部埋入土中，水和土接触到那里，就会引发软腐病和基腐病。原则是按育苗盘中原来的深度种下，或比那个深度略浅一点。

&nbsp;&nbsp;&nbsp;缩小种植间距会增加单位面积的株数，但对结球生菜来说通常是不利的。间距过密会导致通风变差，霜霉病和灰霉病蔓延；光照不足会使结球松散；而最重要的是，在只能依靠天然材料栽培的条件下，每株获得的养分会不足。这种作物的产量取决于每个结球的大小，因此几个像样的球体胜过许多个小球。

## 7. 水分管理

### 7-1. 各阶段的水分管理

| 时期 | 水分管理 | 理由 |
|:---|:---|:---|
| 定植后-活棵 | 浇透水 | 需要让根系附着在新土中 |
| 活棵后-外叶形成期 | 表土发干时浇水 | 引导根系向下生长 |
| 结球期 | 持续保持不干 | 是最重要的时期 |
| 收获前1周 | 减少或停止浇水 | 组织变得紧实，耐储性提高 |

&nbsp;&nbsp;&nbsp;结球生菜的水分管理，关键就在结球期这一个阶段。此时若土壤干燥，内部就无法填满，一旦没能填满，之后再怎么浇水也无法弥补。结球是细胞分裂、再由这些细胞吸水膨大的过程，一旦错过分裂发生的时期，就没有可供膨大的细胞了。

&nbsp;&nbsp;&nbsp;相反，收获前应该减少浇水。一直浇水到收获前的结球，细胞充满水分容易破裂，贮藏期间也更快变软。大约提前一周开始减少浇水，组织会略微变紧实，贮藏时间也会延长。在追求常温下能放一周的情况下，这几天的差别是有意义的。

### 7-2. 水分不足与过多

| 症状 | 原因 | 应对 |
|:---|:---|:---|
| 白天萎蔫、傍晚恢复 | 暂时性缺水 | 属于正常范围，可略增加灌水量 |
| 傍晚仍不恢复 | 严重缺水 | 立即充分浇水 |
| 结球松散且轻 | 结球期水分不足 | 无法挽回 |
| 内叶叶尖变褐干枯 | 水分不均导致钙移动受阻 | 均匀浇水 |
| 外叶发黄、基部变软 | 过湿 | 疏通排水沟并停止灌水 |
| 结球开裂 | 干旱后突然大量浇水 | 使灌水间隔均匀 |

&nbsp;&nbsp;&nbsp;结球开裂的现象出现在水分供给忽多忽少的时候。长期干旱之后突降大雨，或一次浇太多水，内部细胞会急速膨大，把已经变硬的外层撑破。裂开的地方会让病原菌侵入，在贮藏期间开始腐烂，因此开裂的结球不要贮藏，应优先食用。预防的关键不是勤浇少量，而是保持均匀。覆盖对实现这种均匀有很大帮助。

&nbsp;&nbsp;&nbsp;内叶叶尖变褐干枯的干烧心，与生菜一样，是因为钙无法到达新叶的顶端而产生的。结球生菜上出现得更频繁，因为内叶层层包裹，几乎不发生蒸腾。钙是随着水流移动的元素，没有蒸腾就无法到达。外表看起来完好，切开却发现内部已经褐变，就是这种情况。比起往土里加钙，保持水分均匀、避免密植以确保通风，效果更大。

### 7-3. 节水方法

| 方法 | 效果 |
|:---|:---|
| 稻草与干草覆盖 | 大幅减少蒸发，是结球生菜最廉价的节水手段 |
| 清晨灌水 | 避开正午蒸发，叶片能在白天变干 |
| 株周做成凹形 | 水会汇聚到根部 |
| 沟灌 | 不打湿叶片，能减少病害 |
| 防风 | 风会大幅增加蒸发 |
| 生活废水再利用 | 只使用皂分与油脂较少的水 |

&nbsp;&nbsp;&nbsp;把总蒸散量500mm换算成每㎡，一个作期需要500L。1㎡能长3株结球生菜就需要500L，如果种10株，一个作期就需要将近1.7吨的水。当然，其中很大一部分由降雨代替，但在不下雨的年份，这些水就得靠人力挑运。决定要不要种结球生菜时，应该先算清这个数字。

&nbsp;&nbsp;&nbsp;覆盖能明显减轻这一负担。裸露地面产生的蒸发占总蒸散量的相当一部分，用稻草或干草覆盖后，这部分会减少，只剩下根系实际利用的部分。在没有地膜的条件下，稻草覆盖同时是节水手段、抑制杂草的手段，也是防病手段。在结球生菜栽培中，这是花费最少却效果最多的一项作业。
