## 2. どんな植物か

### 2-1. 分類と由来

| 項目 | 内容 |
|:---|:---|
| 学名 |Lactuca sativa var. capitata |
| 科 | キク科（Asteraceae） |
| 属 | アキノノゲシ属（Lactuca） |
| 同じ種 | サンチュ、ロメイン、ステムレタスがすべてLactuca sativa |
| 生活史 | 一年草（条件によっては二年草） |
| 別名 | 結球レタス、クリスプヘッド、アイスバーグ |

&nbsp;&nbsp;&nbsp;玉レタスは地中海沿岸からヨーロッパへ広がったサンチュの中で、葉が内側に巻く個体を人が選び集めた系統です。16世紀のヨーロッパの文献に結球するサンチュが登場し、今日の硬いクリスプヘッド型は19世紀末から20世紀初頭にアメリカで完成しました。アイスバーグ、つまり氷山という名前はこのサンチュの性質からではなく輸送方法から来ています。20世紀初頭にアメリカ西部から東部へ鉄道で送る際、氷をいっぱいに詰めた貨車に載せたことから付いたあだ名です。

&nbsp;&nbsp;&nbsp;この由来が玉レタスの性格を正確に語っています。玉レタスは畑で食べる野菜ではなく、遠くへ送る野菜として仕立てられた系統です。硬く締まっていて押されても傷まず、外葉が内側を保護し、長く置いてもしゃきしゃき感が残ります。大量流通を前提に選抜された形質であり、そのため栄養密度や味の深さは選抜の基準に入っていませんでした。物流が絶たれた状況でこの作物を評価する際には、この事実を念頭に置く必要があります。玉レタスは流通のために作られた作物であり、その流通が失われた条件では、作られた目的の半分を失います。ただ、残りの半分、つまり貯蔵中に持ちこたえる構造はそのまま残ります。

### 2-2. 結球とは何か

&nbsp;&nbsp;&nbsp;結球は葉が生長しながら内側に曲がり、幾重にも重なる現象です。自然に起こるものではなく、条件が合わなければ始まらない生理的な転換です。

&nbsp;&nbsp;&nbsp;順序はこうです。まず外葉が10枚から15枚展開して育ちます。これらの葉が光合成工場の役割を果たします。次に新しく出る葉が外葉が作る垣根の内側で育ち始めますが、このとき葉の下面と上面の生長速度が異なってきます。下面がより速く育つと、葉は内側にすぼまります。この曲がった葉が重なることで球形が作られ、内側から新しい葉が次々と押し込まれることで中が固くなります。

&nbsp;&nbsp;&nbsp;ここで重要なのは、下面と上面の生長速度の差が温度に大きく左右されるという点です。気温が高いとこの差が消えるか、逆に反転して葉が外側に開いてしまいます。結球の適温が生育の適温より低く、かつ狭い理由がここにあります。

| 段階 | 定植後 | 起こること | 温度条件 |
|:---|:---:|:---|:---|
| 活着 | 1-2週 | 根が新しい土に定着します | 15-20℃ |
| 外葉形成 | 2-6週 | 外葉10-15枚が展開します | 15-20℃ |
| 結球開始 | 6-7週 | 新しい葉が内側に曲がり始めます | 15-18℃が最適です |
| 結球充実 | 7-10週 | 中が詰まり固くなります | 10-18℃ |
| 収穫期 | 10週以降 | 押して固ければ適期です | |

> **結球は外葉が十分に育った後にのみ始まります。外葉形成期の生育が不十分だと、その株は結球そのものに入ることができません。結球失敗の多くは結球期ではなく、その前の段階で既に決まっています。**

### 2-3. 姿と形

| 器官 | 特徴 |
|:---|:---|
| 葉 | 丸く広く、縁が深く切れ込んで波状。内側に巻いて結球します |
| 外葉 | 濃い緑色で、厚く硬いです。内側を保護する皮の役割を果たします |
| 内葉 | 光を受けられず淡黄色から白色。しゃきしゃきしていて水分が多く、味は淡いです |
| 茎 | 非常に短く圧縮されており、結球の中心にあります |
| 根 | 直根性。20-30cmと比較的浅いです |
| 花 | 黄色い頭状花が円錐花序をなします |
| 果実 | 痩果。長さ3-4mm、幅0.8-1mm、先端に冠毛が付きます |

&nbsp;&nbsp;&nbsp;外葉と内葉の色の違いが、この作物の栄養構造をそのまま示しています。外葉は濃い緑色で、それだけクロロフィルとベータカロチンとビタミンKが多いです。内葉は白く、それだけ少ないです。ところが人が主に食べるのはしゃきしゃきした内側です。外葉は硬いという理由で捨てられることが多いです。災害の状況ではこれは覆すべき習慣です。外葉が栄養の大部分を含んでおり、硬ければ茹でるか汁物に入れればよいのです。

&nbsp;&nbsp;&nbsp;熱量14kcalは、この文書が扱う作物の中でも最も低い部類です。成人一人の一日の熱量2,100kcalを玉レタスだけで満たすには15kgを食べる必要があり、人が飲み込める量ではありません。玉レタスに熱量を期待するのは、そもそも成立しない計算です。

## 3. 栽培環境

### 3-1. 温度

| 区分 | 温度 | 結果 |
|:---|:---:|:---|
| 発芽適温 | 18-21℃ | 6-8日で芽が出ます |
| 発芽限界 | 26℃以上 | 高温休眠のため発芽しません |
| 生育適温 | 15-20℃ | 葉がよく育ちます |
| 結球適温 | 15-18℃ | 最もよく巻きます |
| 結球可能 | 10-20℃ | この範囲を外れると危うくなります |
| 結球失敗 | 25℃以上 | 葉が開き抽だいが来ます |
| 耐寒限界 | 零下5℃ | 外葉が傷み、ひどい場合は結球が崩れます |

&nbsp;&nbsp;&nbsp;この表から読み取るべきことは、三つの温度域が互いに異なるという事実です。発芽は18-21℃を好み、葉の生長は15-20℃、結球は15-18℃が最も良いです。一作期の中でこの三つの区間を順に通過しなければなりませんが、自然の気温は一方向にしか動きません。春には上がり、秋には下がります。

&nbsp;&nbsp;&nbsp;秋栽培が有利な理由がここから出てきます。8月末から9月初めに播種すると、発芽期はまだ暖かく18-21℃前後で、葉が育つ9-10月は15-20℃、結球が起こる10-11月は10-18℃まで下がります。気温が下がる方向と作物が必要とする温度が下がる方向とが一致します。

&nbsp;&nbsp;&nbsp;春栽培はその逆です。2-3月の播種期には発芽温度が足りず保温が必要で、5-6月の結球期には気温が20℃を超えて結球条件から外れます。春栽培が秋栽培より失敗率が高く収穫量も少ない理由です。韓国国内の試験では同じ品種の春の収穫量が秋より高く出ることもありますが、それは保温施設と灌水に支えられた条件での値です。施設もビニールもない状況では、秋が圧倒的に有利です。

> **玉レタス栽培の核心的な問いは一つです。結球が始まる時点で気温が15-18℃かどうか。この問いに答えられるように播種日を逆算することが、この作物の技術のすべてだと言っても過言ではありません。**

### 3-2. 光

| 項目 | 基準 |
|:---|:---|
| 必要日照 | 1日8-10時間 |
| 半日陰 | 耐えますが結球が緩くなります |
| 40%遮光 | 相対収量86%（信頼区間61-120） |
| 光発芽性 | あります。種を深く埋めると発芽しません |

&nbsp;&nbsp;&nbsp;光が足りないと結球が緩くなります。光合成で作られる糖が不足すると葉が薄く軽くなり、その葉が重なっても重さと密度が出ません。押したときにぐっと沈む結球は、たいてい光か養分が足りなかった信号です。ただ、遮光試験の結果では葉菜類全般で40%を遮っても相対収量86%が残るとされているので、半日程度の日陰は致命的ではありません。建物の陰や木の下のように一日の半分だけ日が当たる場所でも、結球はします。

### 3-3. 水と土壌

| 項目 | 基準 | 備考 |
|:---|:---|:---|
| 総蒸発散量 | 約500mm | サンチュの350mmより多いです |
| 結球期の水分 | 乾かさないよう維持 | この時期の乾燥が結球失敗の主な原因です |
| 過湿 | 根腐れと軟腐病 | 畝を高くします |
| 土壌 | 排水の良い砂壌土から壌土 | 保水力も併せて必要です |
| 土壌酸度 | pH 6.0-6.8 | 酸性土では生育が落ちます |
| 有機物 | 多いほど良いです | 保水力と養分を同時に高めます |

&nbsp;&nbsp;&nbsp;総蒸発散量500mmは、玉レタス栽培において最も現実的な負担です。サンチュの350mmより43%多く、この差は水を運ぶ労働に換算されます。水道が止まり井戸や川から水を担いで来なければならない状況なら、この43%がそのまま毎日の労働時間に加わります。

&nbsp;&nbsp;&nbsp;玉レタスが水を多く使う理由は二つあります。一つは生育期間が長く総量が積み重なることで、もう一つは結球期に大きな塊の細胞を水で満たさなければならないことです。結球期に水が足りないと中が詰まらず、この時の失敗は後で水をやっても回復しません。細胞分裂が終わった後は、その細胞を膨らませることしか残っていないからです。

&nbsp;&nbsp;&nbsp;土壌酸度がpH6.0を下回ると、生育が目に見えて落ちます。酸性土ではリン酸がアルミニウムと鉄に捕捉され、根が使えない形になりますが、リン酸は結球に直接関わる元素です。石灰がなければ、草木灰や貝殻を焼いた粉、卵の殻の粉が酸度を上げる自然の資材になります。ただ、一度に多く入れると微量元素が固定されてしまうので、少量ずつ分けて入れます。

## 4. 品種

### 4-1. 二つの系統

| 系統 | 特徴 | 災害時には |
|:---|:---|:---|
| クリスプヘッド | 葉の縁が深く切れ込み、結球が硬いです | 貯蔵性が最も良く、この作物を植える目的に合います |
| バターヘッド | 半結球型。葉が柔らかく結球が緩いです | 結球失敗のリスクは低いですが、貯蔵の利点も小さいです |

&nbsp;&nbsp;&nbsp;二つの系統の選択は、実質的にリスクをどこに置くかという問題です。クリスプヘッドは結球に成功すれば硬い塊になり、一週間以上持ちます。その代わり結球条件が厳しく、失敗のリスクが大きいです。バターヘッドは緩く巻くため、条件が少しずれてもある程度形を保ちますが、緩い分だけ貯蔵性が落ち、サンチュと大きく変わらなくなります。

&nbsp;&nbsp;&nbsp;玉レタスを植える目的が貯蔵であるなら、クリスプヘッドが適しています。目的が貯蔵でないなら、そもそも玉レタスを植える理由が弱くなります。したがって実質的な選択肢はクリスプヘッドの方に傾き、その代わり結球条件を合わせることにより注意を払う必要があります。

| 品種 | 系統 | 収穫量(kg/1,000㎡) | 特徴 |
|:---|:---|:---:|:---|
| ゴシナ4号 | 韓国国内育成 | 4,530(春) / 3,997(秋) | 既存品種比20%増収 |

&nbsp;&nbsp;&nbsp;この表で注目すべきは、抵抗性品種の存在です。薬がない状況では、抵抗性は種子にあらかじめ組み込まれた防除手段です。べと病に抵抗性のある品種を確保しておけば、その病気については何もしなくてよく、これはどんな自然の防除剤よりも確実です。

&nbsp;&nbsp;&nbsp;ただし、災害が長引くと導入品種の種は補充されません。そうなると残るのは自分が採った種だけで、抵抗性が遺伝するかどうかが問題になります。玉レタスは自家受精なので、抵抗性が単一優性遺伝子で決まっている場合は次世代にもそのまま引き継がれます。ただ、F1交配種として販売されている品種であれば、種を採ったときに形質が分離します。種袋に交配種の表示があるかどうかを確認しておくことは、この作物では実質的な意味があります。

### 4-3. 状況別の選択

| 状況 | 選択 | 理由 |
|:---|:---|:---|
| 貯蔵が目的 | クリスプヘッドの早生種 | 硬い結球が貯蔵性を生み出します |
| 結球失敗が心配 | バターヘッドまたはサンチュ | 失敗しても葉を食べられます |
| 秋栽培 | 早生種 | 霜が来る前に結球を終える必要があります |
| 春栽培 | 晩抽性品種 | 気温が上がる間持たせる必要があります |
| アブラムシが多い畑 | 抵抗性品種 | 薬なしで防ぐ最も確実な方法です |
| 種を継続して使う計画 | 固定種 | 交配種は形質が分離します |

&nbsp;&nbsp;&nbsp;秋栽培で早生種を選ぶのは、時間の計算のためです。定植から収穫まで50-60日かかりますが、霜が降りる時点から逆算してその期間を確保しなければなりません。韓国中部では初霜が10月下旬から11月初旬なので、9月初めには定植が終わっていなければなりません。晩生種を選ぶと、結球が完成する前に霜に遭います。
