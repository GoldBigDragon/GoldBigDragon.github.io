## 12. 采收——只有一次的采收

### 12-1. 采收时机判断

| 类别 | 标准 |
|:---|:---|
| 秋季栽培 | 定植后50-60天 |
| 春季栽培 | 定植后60天左右 |
| 冬季栽培 | 定植后90天 |
| 结球判定 | 从上方按压时能坚实地顶住 |
| 采收时间 | 清晨，此时含水量最大，最重 |
| 应避开的时机 | 刚下过雨、叶片潮湿之时 |

&nbsp;&nbsp;&nbsp;按压是最可靠的判断方法。若明显凹陷，说明球心尚未长实，或者这株本就不会结实；若坚实地顶住，就是最佳时机。若感觉过于坚硬，可能已经偏晚，球心里可能已经开始抽薹。一旦结球内部开始抽薹，外表看不出来，但内部会呈锥状隆起并泛出苦味，所以结球完成后不宜久留，这是关键的要领。

> **刚下过雨时不要采收。**若叶片间残留着水分就切下保存，这些水分就会成为贮藏期间软腐病的起点。要等雨停一两天、叶片变干之后再采收。

### 12-2. 采收要领

| 顺序 | 内容 | 原因 |
|:---:|:---|:---|
| 1 | 在晴天清晨采收 | 此时含水充分，重量足、最新鲜 |
| 2 | 用刀一次性切断基部 | 反复切割会让切面粗糙而容易变质 |
| 3 | 保留2-3片外叶 | 能在贮藏期间充当保护球心的外壳 |
| 4 | 把切面放在阴凉处晾干 | 潮湿的切面是腐败的起点 |
| 5 | 不清洗直接保存 | 一旦残留水分马上就会变软腐烂 |

&nbsp;&nbsp;&nbsp;保留外叶是结球生菜采收中最实用的技巧。市面流通的结球生菜外叶都已摘除，但若以贮藏为前提，就该反过来做。两三片外叶本身就是一层包装材料：贮藏期间外叶变干、变褐的同时，内部叶片得到保护。食用时剥掉外叶，里面依然完好。

&nbsp;&nbsp;&nbsp;切面上会像生菜一样流出白色乳液。这种乳液干燥后凝成褐色，反而能起到封住伤口的塞子作用。放在阴凉处晾一两个小时，等切面干燥后再转移到贮藏处，贮藏期就会延长；若带着湿气直接存放，细菌就会在那个位置滋生。

### 12-3. "只有一次"的含义

&nbsp;&nbsp;&nbsp;评价表中持续性为D，其含义在采收阶段值得再次强调。要收获结球，就只能切断基部，而生长点也会随之消失。那一株就此结束。

&nbsp;&nbsp;&nbsp;因此，在结球生菜的采收上，时间分散比贮藏更早成为一个问题。如果二十株同一天种下，二十个球就会在同一周一起成熟，常温一周根本处理不完。若按十天到半月的间隔分批种植，采收也会相应分开。不过秋季栽培有霜冻这个最终期限，这种分批的空间有限。假设初霜在10月下旬，那么定植就必须在比它早50-60天的9月初旬之前完成，能分批的幅度只有2-3周。

&nbsp;&nbsp;&nbsp;切割后留下的基部有时会长出侧芽，抽出几片小叶。这些叶子不会结球，个头也小，但可以食用。这很难称为"再生采收"，更准确的说法是：在清理田地之前不必浪费它们。

## 13. 留种——结球造成的障碍

&nbsp;&nbsp;&nbsp;评价表中自家留种等级为S，依据是自花授粉。结球生菜也和生菜一样，在花朵开放之前就已用自身花粉完成授粉，所以即便有蜂类造访，基因也几乎不会混杂，实用隔离距离1-2m就足够。不过结球生菜留种有一个生菜没有的问题：花茎必须先突破结球才能长出来。

### 13-1. 花茎被困住的问题

&nbsp;&nbsp;&nbsp;结球生菜的叶片层层包裹，形成坚实的球体。生长点就在其中，一旦开始抽薹，花茎就必须顶开这些叶层才能长出来。结球越紧实，这件事就越难，花茎有时会在内部弯曲生长直至腐烂，一旦在这种状态下球心积水，软腐病就会随之而来。

| 问题 | 会怎样 | 应对 |
|:---|:---|:---|
| 花茎无法顶开结球 | 在内部弯曲生长直至腐烂 | 在结球顶部浅浅划出十字形开口引路 |
| 球心积水 | 引发软腐病 | 尽量避雨，并确保排水良好 |
| 结球松开得晚 | 开花延迟，种子无法成熟 | 留种株要挑选结球较松的个体 |

&nbsp;&nbsp;&nbsp;用刀在结球顶部浅浅划出十字形切口，是传统的应对方法。深度1-2cm，只划开外层的两三层叶片即可，划得太深会伤到生长点，那株就此结束。不过划开的地方本身是伤口，雨水频繁时病害就会从那里侵入。即便不去动它，相当一部分也会自行顶破而出，所以留出多株作为留种株，选用长势好的那些，会更安全。

&nbsp;&nbsp;&nbsp;这里存在结球生菜留种的结构性矛盾：好吃的是包得紧实的，而好留种的却是包得松散的。如果每年都只挑选便于留种的个体延续下去，几代之后品系就会滑向结球松散的方向。

> **要阻止这种趋势，挑选留种株时要同时采用两个标准：从结球本来就长得好、且花茎顺利长出的株上取种。若从结球失败的株上取种，那种性状就会原样延续下去。**

### 13-2. 时间表

| 阶段 | 时间点 | 状态 |
|:---|:---|:---|
| 采收适期 | 定植后50-60天 | 此时留种株不采收，继续留在地里 |
| 抽薹 | 此后3-5周 | 花茎顶开结球向上长出 |
| 开花 | 抽薹后3-4周 | 黄色花朵在清晨开放 |
| 种子成熟 | 开花后12-24天 | 冠毛膨起 |
| 种子采收 | 播种后150-180天 | 比生菜长出大约一个月 |

&nbsp;&nbsp;&nbsp;这张表所显示的，正是结球生菜留种的实际难点。从播种到种子成熟需要五到六个月，若秋天种下，冬天会先到来而无法完成，所以必须在春天播种。2-3月播种的话，会在7-8月收到种子，而其间的6-7月正是高温梅雨季。抽薹时期若与梅雨重叠，结球内部就容易积水腐烂。自花授粉这个优势本身仍然成立，但要走到能用上这个优势的那一步，路途漫长，失败的环节也很多。

### 13-3. 采种与保存

&nbsp;&nbsp;&nbsp;花茎长出之后，就和生菜一样了。种子带有冠毛，成熟后会随风飘散，而且从下方的花朵开始依次成熟，同一株内成熟的时间跨度能超过3周。

| 方法 | 步骤 | 特点 |
|:---|:---|:---|
| 套袋 | 给花茎套上透气的纸袋或布袋 | 劳动量与回收率之间平衡较好 |
| 分批捋取 | 每2-3天一次，只捋取已膨起的花朵收集起来 | 回收率最高 |
| 整株割取 | 半数以上膨起时，连花茎一起割下后熟 | 一次性完成，但会混入未成熟的种子 |

| 项目 | 标准 |
|:---|:---|
| 单株种子数 | 数千粒 |
| 种子寿命 | 常温密封2-3年，凉爽干燥的条件下可以更久 |
| 保存 | 密闭容器，置于凉爽、阴暗、干燥处 |
| 干燥剂 | 炒过放凉的大米、木炭、干草木灰 |
| 检验 | 每年取20粒放在湿布上，统计发芽数量 |

&nbsp;&nbsp;&nbsp;结球生菜的种子也是刚采收的高温休眠现象更强，因为后熟尚未完成，发芽抑制物质还残留着。若在8月的秋播中使用当年7月刚采的种子，发芽率会大幅下降，所以最好同时储备两年的种子，先用陈的。还要记住，从杂交品种上采种，下一代性状会分散，有的会结球，有的则会散开不结球。

## 14. 毒性与需注意的成分

&nbsp;&nbsp;&nbsp;结球生菜没有毒性。因为和生菜是同一物种，成分构成也相同，但由于结球这种形态，有些地方的强度会有所不同。

| 成分 | 与生菜相比 | 原因 |
|:---|:---|:---|
| 莱苦素（Lactucarium，乳液） | 较少 | 内层叶片不见光，防御物质生成较少 |
| 硝酸盐 | 内层叶片可能积累更多 | 没有光照，硝酸盐就无法转化为蛋白质 |
| 草酸 | 较低 | 不构成实际问题 |

### 14-1. 莱苦素（Lactucarium）

&nbsp;&nbsp;&nbsp;切开结球生菜时，会像生菜一样流出白色乳液，这就是含有lactucerin和lactucin等成分的莱苦素（Lactucarium）。它是苦味的来源，也带有轻微的镇静作用。不过结球生菜内层叶片中这种成分比生菜少，因为不见光的组织生成防御物质较少。这正是结球生菜内心口味清淡、几乎不苦的原因，同时也是营养偏淡的原因。外层叶片中这种成分含量与生菜相近，所以外叶偏苦。有说法称食用后会犯困，但按餐桌上的食用量，远远达不到能感受到那种效果的程度。若结球内部已经开始抽薹，苦味会明显上升，这并不是产生了毒性，而是时机已经过去的信号。

### 14-2. 硝酸盐

&nbsp;&nbsp;&nbsp;硝酸盐问题在结球生菜上比在生菜上更需要留意。根系吸收的氮以硝酸盐的形式储存在叶片中，有光照时会利用光合能量转化为氨基酸，而结球内层叶片见不到光，这一转化不会发生，硝酸盐可能就原样残留下来。

| 条件 | 硝酸盐积累 |
|:---|:---|
| 氮肥施用过量 | 会大幅增加 |
| 结球内层叶片 | 见不到光，转化不充分 |
| 连续阴天时 | 会增加 |
| 清晨采收 | 夜间转化停止，含量偏高 |
| 晴天午后采收 | 白天已经转化，含量偏低 |

&nbsp;&nbsp;&nbsp;不过，正常栽培的结球生菜按普通食用量摄入并无问题。硝酸盐本身不是毒素，目前普遍的理解是，摄取蔬菜带来的益处超过了这一负担。真正需要担心的组合，是在氮肥过量又缺乏阳光的地里种出来的菜，每天不搭配其他蔬菜就大量食用的情况。

&nbsp;&nbsp;&nbsp;幸运的是，结球期停止施氮，既是为了让结球顺利形成，也是为了减少硝酸盐，两个目的方向一致，判断起来并不困难。除了成分之外的风险在于卫生。这是生食的蔬菜，田地的状况会直接进入口中，而结球生菜一旦泥土和水进入结球内部，特别难以洗净。一层一层剥开外叶清洗才可靠；如果是施了未充分发酵的粪肥的地，或是洪水淹过的地里长出来的，焯水后再吃更安全。

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;评价表中贮藏性为D，无电力常温下能放1周，这正是种植结球生菜的唯一理由。本节是这份作物文档的核心所在。

### 15-1. 为什么比生菜更耐放

&nbsp;&nbsp;&nbsp;原因纯粹在于结构。生菜的叶片直接暴露在空气中，而结球生菜则有好几层外叶包裹着球心。贮藏期间，水分流失、细菌接触、氧气进入维持呼吸，这些都会先在外层发生。外叶变干、变褐、变软的同时，内层叶片在其中受到保护。表面积与体积的比例也更有利：平展的叶片在同等重量下表面积更大，水分流失也就更快，而团成球状的结构则是表面积最小的形态。

| 条件 | 贮藏期限 |
|:---|:---:|
| 常温放置 | 5-7天 |
| 阴凉处（15℃左右） | 1-2周 |
| 土窖·地窖（10℃左右） | 2-3周 |
| 地窖中配合湿沙或稻草 | 3-4周 |

### 15-2. 贮藏方法

| 方法 | 步骤 | 注意事项 |
|:---|:---|:---|
| 保留外叶 | 保留2-3片外叶不摘除 | 起到包装材料的作用 |
| 晾干切面 | 切下后在阴凉处放1-2小时 | 潮湿的切面是腐败的开端 |
| 不清洗 | 只拍掉泥土，不沾水 | 一旦残留水分马上就会变软腐烂 |
| 包裹湿布 | 用透气的布浸湿后松松地包裹 | 包得太紧会压烂 |
| 埋入地窖 | 根部朝下，埋在湿沙或稻草之间 | 彼此之间留出间隔，不要接触 |
| 倒挂 | 在基部系上绳子，挂在凉爽处 | 没有接触地面的部位，不会受压 |
| 瓦罐 | 铺上湿布放入后，松松地盖上 | 完全密封会导致变软腐烂 |

&nbsp;&nbsp;&nbsp;在地窖贮藏时，彼此留出间隔十分重要。相互接触的地方不透气、容易积湿，会从那个位置开始变软；一旦一个球开始变软，乙烯和细菌就会传播到旁边。每隔几天查看一次，把开始变质的取出，这个习惯对贮藏期限的影响很大。

> **在采收时就把要贮藏的和要先吃的分开。**结球有裂口的、有压痕的、有虫蛀痕迹的，以及刚下过雨时采收的，都不要贮藏，先吃掉。一个变质的会拖累旁边好好的。

&nbsp;&nbsp;&nbsp;如果没有地窖或土窖，可以找朝北的屋檐下、地板下、井边、石墙阴影处这类不见阳光又通风的地方。比起温度本身，温度是否稳定更重要。白天热、夜里冷的地方会产生结露，那些水分会招致腐败。

### 15-3. 加工贮藏

| 方法 | 步骤 | 期限 | 评价 |
|:---|:---|:---:|:---|
| 焯水晒干 | 把外叶焯水后在阴凉处晒干 | 数月 | 适合用来处理外叶 |
| 水泡菜（mulkimchi） | 浸入2-3%的盐水中 | 1-2周 | 还能保留一点脆感 |
| 现拌泡菜（geotjeori） | 用盐腌过后拌调味料 | 2-3天 | 与其说是贮藏，更像是烹调 |

&nbsp;&nbsp;&nbsp;结球生菜不太适合加工贮藏。含水量接近95%，晒干后几乎什么都不剩；用盐腌渍则会失去脆感。这种作物的贮藏策略不是加工，而是保持结球原样。不过采收时摘下的外叶，晒干保存的话就不必浪费。外叶颜色深绿，营养胜过球心，又因质地韧硬难以生食，正适合晒干后用于煮汤。一颗结球摘下的外叶数量并不算少，光靠这一个习惯，实际收获量就会增加。

## 16. 烹饪与加工

| 方法 | 燃料 | 备注 |
|:---|:---:|:---|
| 生食（ssam包饭、沙拉） | 无 | 内层叶片脆嫩清爽 |
| 现拌泡菜 | 无 | 变软后体积缩小，能吃下更多 |
| 水泡菜 | 无 | 发酵能保留相当一部分维生素C |
| 焯煮 | 少 | 是处理外叶的方法 |
| 煮汤或炒制 | 与其他烹饪合并进行 | 用到外叶和菜心 |

&nbsp;&nbsp;&nbsp;结球生菜的烹饪加工评级为SS，原因和生菜相同。洗净就能直接吃，不需要燃料，怕热的维生素C和叶酸也能原样摄入。不过要真正用好这个优势，需要改掉一个习惯：不要把外叶丢掉。外叶颜色深绿，集中了β-胡萝卜素和维生素K，如果只吃发白的球心，结球生菜的微量营养素实际上会比表中列出的15种更加稀薄。如果外叶太韧，焯水或切碎放进汤里就可以了。

| 部位 | 性质 | 用途 |
|:---|:---|:---|
| 内层叶片 | 脆嫩清爽，营养偏淡 | 生食、ssam、沙拉 |
| 中层叶片 | 适中的脆感 | 生食、现拌泡菜 |
| 外层叶片 | 深绿色，韧硬且略苦，营养最好 | 焯煮、煮汤、炒制、晒干保存 |
| 菜心 | 坚实带甜味 | 切薄片生食或炒制 |

&nbsp;&nbsp;&nbsp;中间的菜心也不该丢弃。它是结球中心那段短而坚实的茎，削去外层韧硬的部分后切薄片，脆嫩中带着淡淡甜味，生吃、炒制或放进汤里都合适。现拌泡菜是通过缩小体积来增加实际摄入量的方法。对于一种热量只有14kcal的作物来说，食用量的增加，能在营养供给上带来实质差异。

&nbsp;&nbsp;&nbsp;结球生菜一旦煮熟，脆感就会消失变软，所以不宜久煮。在煮汤的火上最后放入，稍微烫软即可，这样不用额外耗费燃料就能得到熟制的形态。拌入少量油脂能提高β-胡萝卜素、维生素K和维生素E的吸收率，因此磨入一些紫苏籽或芝麻会有帮助。

&nbsp;&nbsp;&nbsp;这张表里显眼的一点，是结球生菜占用田地的时间之长。春季栽培从2月到6月共五个月，若延续到留种则是八个月，秋季栽培也要三个月。这段时间里那块地上无法种别的东西，一旦结球失败，这整段时间就白白浪费了。因此实际的安排通常是：田里只留一小块地做秋季栽培，春季栽培只留几株用于延续种子。其余的地方，让给生菜、莙荙菜、羽衣甘蓝这类可以持续采摘食用的叶菜类。

| 类别 | 春季栽培 | 秋季栽培 |
|:---|:---|:---|
| 结球成功率 | 较低，结球期气温会上升 | 较高，气温会下降 |
| 发芽条件 | 温度低，需要保温 | 需要应对高温休眠 |
| 贮藏价值 | 较低，正值夏季容易很快变质 | 较高，能延续到冬季 |
| 病害压力 | 与梅雨重叠，有软腐病风险 | 有霜霉病风险 |
| 留种 | 可行 | 困难 |
| 灾害情况下的建议 | 仅用于留种 | 这一季才是正戏 |

> **结球生菜不是田地的支柱，而是通往冬天的一座桥。**霜冻结束所有叶菜之后，地窖里还剩几个球——这几周，就是这种作物所做的全部事情。判断为此花费三个月时间和500mm的水是否值得，就是决定要不要种它的标准。

&nbsp;&nbsp;&nbsp;最后要强调风险分散的原则。结球生菜是一旦失败几乎什么都剩不下的作物，因此无论如何都要避免让整块地都种满结球生菜。如果在同一块地里搭配种上散叶生菜，即便结球生菜失败，散叶生菜那边总还能有些收获。结球不成功的年份，每隔几年必定会出现一次，那一年田里是否还有别的东西，决定了那一季的饭桌。
