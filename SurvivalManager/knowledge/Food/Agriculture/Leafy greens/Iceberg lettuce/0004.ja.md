## 5. 畑の準備と肥料

### 5-1. 畑作り

| 項目 | 基準 | 理由 |
|:---|:---|:---|
| 耕深 | 25-30cm | 根が20-30cmまで伸びます |
| 畝の高さ | 20cm以上 | 過湿と軟腐病を防ぎます |
| 畝の幅 | 100-120cm (2条植え) | |
| 排水路 | 必ず確保 | 結球期に水が溜まると丸ごと腐ります |
| 整地 | 表面を均一に | 水が一方に偏らないようにします |

&nbsp;&nbsp;&nbsp;玉レタス畑で畝を高くすることは、選択ではなくほぼ必須です。結球した塊は地面にほぼ接しており、底に水が溜まると株元から軟腐病が始まります。軟腐病は細菌性なので、一度始まると内側へ食い込み、数日で塊全体が腐って崩れます。三か月かけて育てたものが三日で失われることもあり、その原因の大半は排水不良です。

&nbsp;&nbsp;&nbsp;ビニールがない状況でのマルチング材料は、藁、乾草、落ち葉、籾殻です。マルチングは雨水が跳ねて土中の病原菌が葉に移るのを防ぎ、地温が上がりすぎるのを遅らせ、水分の蒸発を減らします。玉レタスのように結球期に水が必要な作物では、最後の効果が特に大きいです。ただ、藁マルチングはナメクジの隠れ家になるので、株元周りは手のひら程度の広さを空けておく折衷策を使います。

### 5-2. 施肥量

&nbsp;&nbsp;&nbsp;評価表の施肥等級はBで、根拠は㎡当たりNとPとKを合わせて約24gです。サンチュの22gより少し多いです。1,000㎡基準に換算すると以下のとおりです。

| 肥料 | 1,000㎡基準 | ㎡換算 | 備考 |
|:---|:---:|:---:|:---|
| 窒素(N) | 12-15kg | 12-15g | 元肥と追肥に分けます |
| リン酸(P) | 8-10kg | 8-10g | 全量元肥。結球に直接関わります |
| カリウム(K) | 8-10kg | 8-10g | 元肥と追肥に分けます |
| 堆肥 | 1,500-2,000kg | 1.5-2kg | 完熟堆肥 |
| 石灰 | 150kg | 150g | 酸性土の改良用 |

| 区分 | 時期 | 何を | 目的 |
|:---|:---|:---|:---|
| 元肥 | 定植1-2週前 | 堆肥全量、リン酸全量、窒素とカリウムの半分 | 根が触れる時にはすでに分解されている必要があります |
| 追肥1回目 | 定植後3週頃 | 窒素とカリウムが中心 | 外葉を育てます |
| 追肥2回目 | 結球開始の頃 | カリウムとリン酸が中心 | 中を詰めて固くします |

&nbsp;&nbsp;&nbsp;リン酸を全量元肥として入れるのには理由があります。リン酸は土の中でほとんど動きません。表面に施すとその場に留まり、根が届きません。そのため耕す際に土と混ぜて、根が伸びる層にあらかじめ入れておく必要があります。玉レタスでリン酸が不足すると結球が緩くなり、中が詰まりません。リン酸欠乏は初期には表面に出にくく、結球期になって結果としてのみ現れるため、元肥の段階で決まると見るのが正しいです。

> **窒素は反対です。結球期に窒素が多いと、葉が引き続き大きくなろうとして内側に巻きません。見た目は茂っているのに中が空いている株が出る最も多い原因は、結球期の窒素過多です。**

&nbsp;&nbsp;&nbsp;この原理が災害の状況で特に重要な理由があります。化学肥料がなければ窒素源として使うのは薄めた尿と発酵の浅い堆肥ですが、どちらも窒素が遅くまでゆっくりと出ます。元肥として入れたものが結球期になって効果を出してしまうことが起こります。そのため自然資材を使うときは、窒素源をむしろ早めに入れ、結球が始まる頃には完全に止める方向で計画しなければなりません。

### 5-3. 災害時の代替肥料

| 資材 | 供給成分 | 使い方 | 注意 |
|:---|:---|:---|:---|
| 草木灰 | カリウム、リン酸、カルシウム | 一株にひとつかみずつ土に混ぜます | アルカリ性なので過ぎるとpHが上がります |
| 完熟堆肥 | 総合 | 元肥にたっぷりと | 発酵が浅いものは根を傷めます |
| 薄めた尿 | 窒素、カリウム | 水で10-20倍に薄めて株間に | 結球開始後は与えません |
| 骨粉 | リン酸、カルシウム | 元肥として土に混ぜます | 効果がゆっくり出ます |
| 卵の殻の粉 | カルシウム | 元肥に混ぜます | 細かく砕かないと分解しません |
| 油かす、大豆油かす | 窒素、リン酸 | 発酵させてから元肥として | 生のものは発酵熱で根を傷めます |
| 貝殻を焼いた粉 | カルシウム | 石灰の代用 | 少量ずつ分けて入れます |

&nbsp;&nbsp;&nbsp;草木灰は災害の状況で最も手に入りやすいカリウム源です。火を焚けば必ず出るからです。ただ、カリウムとともにカルシウムが多くアルカリ性が強く、玉レタスが好むpH6.0-6.8を超えてしまいやすいです。一株にひとつかみ程度に制限し、酸性が強い畑でなければ毎年入れることはしません。湿らせずに保管しないとカリウムが流れ出てしまいます。

&nbsp;&nbsp;&nbsp;尿は窒素とカリウムを両方含んでいて有用ですが、玉レタスでは使う時期を守らなければなりません。定植後3週頃の1回目の追肥までにとどめ、結球が始まったら止めます。希釈倍率は10-20倍で、葉に触れると傷むので株間の溝に注ぎます。数日置くと尿素がアンモニアに変わって臭いが強くなり濃度も変わるので、採った日にすぐ使う方が安定します。

&nbsp;&nbsp;&nbsp;評価表の無合成投入での収量維持率はC、40.8%です。合成肥料なしで育てると収量が40%水準まで落ちるという意味で、野菜群は全作物群の中でこの差が最も大きいです。玉レタスでは、この低下は収量減少だけでなく結球失敗としても現れます。養分が足りないと外葉が十分に育たず、外葉が不十分だと結球の段階に進めません。そのため自然資材で育てるときは、堆肥を他の作物より多めに入れ、その代わり植え付け間隔を少し広げて株当たりの資源を確保する方が現実的です。

## 6. 播種と定植

### 6-1. 作型

| 作型 | 播種 | 定植 | 収穫 | 備考 |
|:---|:---|:---|:---|:---|
| 春栽培 | 2-3月 | 3-4月 | 6-7月 | 結球期に気温が上がり失敗のリスクが大きいです |
| 秋栽培 | 8-9月 | 9-10月 | 11-12月 | 災害の状況では実質的に唯一の選択です |
| 夏栽培 | 勧めません | | | 発芽と結球がどちらも妨げられます |

&nbsp;&nbsp;&nbsp;秋栽培が有利な理由は、先の温度の項目で見たとおりです。ここに一つ加えるなら、秋栽培で得られる結球は最も必要な時期に出てくるということです。11月と12月は畑で収穫できるものが急激に減る時期であり、そのときに貯蔵可能な葉物野菜が手に入ります。

&nbsp;&nbsp;&nbsp;秋播種の難しさは8月の暑さです。発芽限界が26℃であるのに対し、8月下旬の地温はそれより高くなります。サンチュと同じ高温休眠の問題であり、対応も同じです。

| 方法 | 手順 | 原理 |
|:---|:---|:---|
| 低温プライミング | 種を4-6時間水に浸した後、濡れた布に包んで涼しい場所に1日置きます | 水を吸った種が低温を経験して休眠が解けます |
| 先出し発芽 | 濡れた布の間で芽が少し出た後、移して播きます | 発芽を畑の外で終わらせます |
| 夕方播種 | 日が沈んだ後に播き、水を十分に与えます | 夜間に下がった地温を利用します |
| 遮光 | すだれや木の枝で播種場所に薄い陰を作ります | 地温を数度下げます |
| 涼しい場所での育苗 | 北向きの軒下や木陰で苗を育てます | 畑より数度低いです |

&nbsp;&nbsp;&nbsp;玉レタスはサンチュと違い、育苗を経て定植するのが一般的で、この点が高温休眠への対応にはむしろ有利です。畑全体の地温を下げることはできませんが、苗床一つを涼しい場所に移すのは難しくないからです。北向きの軒下や木陰で発芽させ、本葉が出た後に畑へ移すと、8月の暑さを飛び越えられます。

### 6-2. 育苗

| 段階 | 基準 | 備考 |
|:---|:---|:---|
| 播種深さ | 0.5-1cm | 光発芽性のため深く埋めると出ません |
| 発芽温度 | 18-21℃ | |
| 発芽期間 | 6-8日 | |
| 育苗期間 | 20-30日 | |
| 定植適期 | 本葉4-5枚 | この時点を過ぎてはいけません |
| 育苗トレー | トレー、木箱、土を入れた器など何でも | |

> **定植が遅れると結球が失敗します。本葉が6枚を超えた苗は根がすでに狭い場所で絡み合っており、移植後の回復に時間を使うため外葉を適時に育てられません。外葉が不十分だと結球の段階に進めず、そのまま季節が過ぎていきます。**

&nbsp;&nbsp;&nbsp;この点が玉レタス栽培で最もよくある失敗原因の一つです。苗が大きく見えるほど丈夫に見えますが、実際は逆です。根が絡んだ苗は植え替えた後2週間近く生長せず、その2週間が結球の時期を後ろにずらし、気温がずれてしまいます。本葉4-5枚、根が育苗トレーの土を軽くつかんでいる程度が適期です。

&nbsp;&nbsp;&nbsp;定植の数日前から水を減らし、外気に当てて丈夫にする過程を経ると活着が早くなります。室内や日陰だけで育った苗は葉が薄く軟らかく、畑に出すとすぐに日焼けしたり風でしおれたりします。四日から五日かけて少しずつ日光と風に慣らせば十分です。

### 6-3. 定植

| 項目 | 基準 | 備考 |
|:---|:---|:---|
| 株間 | 30-35cm | 結球するための空間が必要です |
| 条間 | 50-60cm | 通風を確保します |
| 植栽密度 | 1,000㎡当たり3,000-3,500株 | ㎡当たり3-3.5株 |
| 植える深さ | 本葉の付け根が土に埋まらないように | 埋まると付け根が腐ります |
| 定植の時刻 | 曇りの日や日暮れ頃 | 真昼に植えるとしおれます |
| 定植直後 | 水をたっぷり与えます | 根と土を密着させる必要があります |

&nbsp;&nbsp;&nbsp;植える深さが重要です。玉レタスの茎は圧縮されてほとんど無いに等しく、葉が付け根に直接付いています。深く植えて付け根が土に埋まると、そこに水と土が触れて軟腐病や株腐病が始まります。育苗トレーで育っていた深さのまま、あるいはそれよりごくわずかに浅く植えるのが原則です。

&nbsp;&nbsp;&nbsp;植栽間隔を狭めると面積当たりの株数は増えますが、玉レタスではたいてい損になります。狭いと通風が悪くなってべと病と灰色かび病が広がり、光が足りず結球が緩くなり、何より自然資材だけで育てる条件では株当たりの養分が不足します。結球一つの大きさがそのまま収穫量になる作物なので、小さな塊がいくつもあるより、きちんとした塊が数個ある方が良いのです。

## 7. 水管理

### 7-1. 段階別の水管理

| 時期 | 水管理 | 理由 |
|:---|:---|:---|
| 定植直後-活着 | たっぷり与えます | 根が新しい土に付く必要があります |
| 活着後-外葉形成期 | 表土が乾いたら与えます | 根を下へ誘導します |
| 結球期 | 乾かさないよう絶えず | 最も重要な時期です |
| 収穫1週間前 | 減らすか止めます | 組織が締まり貯蔵性が上がります |

&nbsp;&nbsp;&nbsp;玉レタスの水管理は結球期一つにかかっています。この時期に土が乾くと中が詰まらず、一度詰まらなかった中は後で水をやっても満たされません。結球は細胞が分裂し、その細胞が水で膨らむ過程ですが、分裂が起こる時期を逃すと膨らませる細胞そのものがないからです。

&nbsp;&nbsp;&nbsp;逆に、収穫直前の水は減らす方が良いです。収穫直前まで水を十分に与えた結球は細胞が水で満たされて破れやすく、貯蔵中に傷む速度が速いです。一週間ほど前から水を減らすと組織がやや締まり、貯蔵期間が延びます。常温で一週間を目指す状況では、この数日が意味を持ちます。

### 7-2. 水不足と過多

| 症状 | 原因 | 対応 |
|:---|:---|:---|
| 昼にしおれ夕方に回復 | 一時的な不足 | 正常範囲です。灌水量を少し増やします |
| 夕方になっても回復しない | 深刻な不足 | 直ちに十分に与えます |
| 結球が緩く軽い | 結球期の水分不足 | 元に戻せません |
| 内葉の先端が茶色く枯れる | 水分の不均衡によるカルシウム移動の障害 | 水を均一に与えます |
| 外葉が黄色くなり株元が軟らかくなる | 過湿 | 排水路を開け灌水を止めます |
| 結球が裂ける | 乾いた後の急な大量の水 | 灌水の間隔を均一にします |

&nbsp;&nbsp;&nbsp;結球が裂ける現象は、水分供給が不均一なときに現れます。長く乾いた状態が続いた後に大雨が降ったり、一度に多くの水を与えたりすると、内部で細胞が急に膨らみ、すでに固くなった外側を押し破ります。裂けた部分から病原菌が入り貯蔵中に腐り始めるので、裂けた結球は貯蔵せず先に食べます。予防は頻繁に少しずつではなく、均一にすることです。マルチングはこの均一化に大きく貢献します。

&nbsp;&nbsp;&nbsp;内葉の先端が茶色く枯れるチップバーンは、サンチュと同様にカルシウムが新しい葉の先端まで届かないために生じます。玉レタスではより頻繁に現れますが、それは内葉が幾重にも包まれて蒸散がほとんど起こらないためです。カルシウムは水の流れに乗って移動する元素なので、蒸散がなければ届きません。外見は問題なさそうでも切ってみると内部が褐変しているのがこれです。土にカルシウムを入れるよりも、水分を均一に保ち、密植を避けて通風を確保する方が効果が大きいです。

### 7-3. 水を節約する方法

| 方法 | 効果 |
|:---|:---|
| 藁と乾草のマルチング | 蒸発を大きく減らします。玉レタスで最も安価な節水手段です |
| 早朝の灌水 | 真昼の蒸発を避け、葉が日中に乾きます |
| 株の周りを凹ませる | 水が根の方に集まります |
| 溝への灌水 | 葉を濡らさないので病気を減らします |
| 防風 | 風は蒸発を大きく増やします |
| 生活排水の再利用 | 石鹼と油分が少ない水だけを使います |

&nbsp;&nbsp;&nbsp;総蒸発散量500mmを㎡に換算すると、一作期で500Lです。結球3株が育つ1㎡に500Lなので、10株を育てると一作期で1.7トン近い水が必要という計算になります。もちろん多くは雨が代わってくれますが、雨が降らない年にはこの量を人が担いで運ばなければなりません。玉レタスを植えるかどうかを決める際には、まずこの数字を検討するのが順序です。

&nbsp;&nbsp;&nbsp;マルチングはこの負担を目に見えて減らします。裸地で起こる蒸発が全体の蒸発散のかなりの部分を占めますが、藁や乾草で覆うとその分が減り、根が使う分だけが残ります。ビニールがない条件では、藁マルチングは節水手段であり、雑草抑制手段であり、病気予防手段でもあります。玉レタス栽培において、最も少ない費用で最も多くの効果を生む作業です。
