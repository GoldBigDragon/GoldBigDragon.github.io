## 12. 収穫 - 続けて摘み取る技術

| 用途 | 時期 | 状態 |
|---|:---:|---|
| 幼葉(ベビーリーフ) | 播種後30-40日 | 手のひらより小さい葉 |
| 初回収穫 | 播種後60-70日 | 本葉8枚以上、葉の長さ20-25cm |
| 繰り返し収穫 | それ以降1-2週間おき | 下から育ちきった葉 |
| 冬の収穫 | 11月-翌年3月 | 生長しないためあるだけの葉を一枚ずつ |

### 12-1. 下から摘む理由

&nbsp;&nbsp;&nbsp;ケールの生長点は茎の頂点に一つだけです。そこから新しい葉が次々と上がってきて、下に行くほど古い葉になります。そのため下側の育ちきった葉を摘み取っても、株が失うものはほとんどありません。すでに光合成の能力が落ちた老いた葉を持っていくようなもので、株はそこに使っていた養分を新しい葉に回します。

&nbsp;&nbsp;&nbsp;反対に頂点を切ると、その株は終わりです。生長点がなくなり、これ以上葉を作れなくなります。側芽が出て何本かに分かれることもありますが、葉が小さくなり収量が大きく落ちます。株をまるごと切り取る収穫は、その株を処分すると決めた場合にのみ行います。

| 項目 | コツ |
|---|---|
| 摘む葉 | 下から育ちきった葉3-5枚 |
| 残す葉 | 常に上側に6-8枚以上 |
| 摘み方 | 葉柄を茎の方へ折り下げます。切り口がきれいでないと腐ります |
| 摘む時刻 | 早朝。一晩水分を含んで最も新鮮です |
| 摘んだ後 | 水を与え、3-4週間に1回は追肥を入れます |

> **常に上側に葉を六枚から八枚残します。残した葉が光合成の工場であり、その工場が次の葉を作ります。欲張って全部摘んでしまうと、その株はそのまま止まってしまいます。**

### 12-2. 一株がどれほど長く持つか

&nbsp;&nbsp;&nbsp;秋に植えたケールは、翌年の春に花茎が上がってくるまで、およそ7-9か月収穫できます。韓国の南部地方や冬が温暖な年には、二年目の夏まで続くこともあります。評価表の永続性Sはこの持続性を指しています。一株から週に3、4枚ずつ30週収穫すれば100枚を超え、成人一人が1日に大きな葉を3、4枚食べるとすれば、ケール十株から二十株で一人の冬の青物をまかなえます。

&nbsp;&nbsp;&nbsp;春が来て花茎が上がってくると、葉が硬くなり苦味が強くなります。この時がその株の終わりです。ただし上がってきた花茎自体は食べられます。まだ花が咲く前、つぼみがついた状態の花茎はブロッコリーに似た味がして柔らかいです。冬の終わりから春の野菜が出てくるまでの空白期間、いわゆる春の食糧不足の時期にこの花茎が一役買います。種を採る株を数株だけ残し、残りの花茎は摘んで食べます。

## 13. 採種 - 二年生と他家受粉の壁

### 13-1. 二つの壁

&nbsp;&nbsp;&nbsp;ケールの採種には二つの壁があります。第一に、二年生なので冬を越さないと花が咲きません。第二に、他家受粉なので近くのアブラナ科作物と無差別に交雑します。評価表の自家採種の等級がAに留まる理由です。ダイズが自家受粉でSを得るのとは対照的です。

| 壁 | 内容 | 解決法 |
|---|---|---|
| 二年生 | 低温を経験しないと花茎が立ちません | 越冬させるか、抜いて貯蔵した後春に再び植えます |
| 他家受粉 | 蜂が花粉を運び他の品種と混じります | 隔離距離、時期をずらした栽培、網かけ |

### 13-2. 何と交雑するか

&nbsp;&nbsp;&nbsp;ケール(Brassica oleracea)は同じ種のすべての変種と完全に交雑します。キャベツ、ブロッコリー、カリフラワー、コールラビ、芽キャベツ、ケールはすべて一つの種なので何の障壁もありません。ケールの隣でキャベツが花を咲かせると、その年に採れた種はケールでもキャベツでもない雑種になります。

| 作物 | 学名 | ケールとの交雑 |
|---|---|:---:|
| キャベツ、ブロッコリー、カリフラワー、コールラビ、芽キャベツ | Brassica oleracea | 完全に交雑します |
| ハクサイ、チンゲンサイ、カブ、ナタネ | Brassica rapa | ほとんど交雑しません |
| カラシナ、マスタード | Brassica juncea | ほとんど交雑しません |
| ダイコン | Raphanus sativus | 属が異なるため交雑しません |

&nbsp;&nbsp;&nbsp;この表が実務上重要です。ケールの種を採る年に、ハクサイやダイコンやカラシナが一緒に花を咲かせても構いません。種が違うからです。問題になるのはBrassica oleraceaの仲間、つまりキャベツやブロッコリーやコールラビのほうだけです。

### 13-3. 交雑を防ぐ三つの方法

| 方法 | 内容 | 現実性 |
|---|---|---|
| 隔離距離 | 他のBrassica oleracea開花株と500m以上離します | 隣の畑まで制御できないため難しいです |
| 時期をずらした栽培 | 一年に一種類だけ花を咲かせます | 最も現実的です |
| 網かけ | 開花前に網をかぶせ、内側で筆で花粉を移します | 小規模では確実です |

&nbsp;&nbsp;&nbsp;最も現実的な解決法は時期をずらした栽培です。今年はケールだけから種を採り、キャベツは全部食べてしまって花を咲かせないようにします。翌年は反対にします。ケールの種子は4年から5年持つので、1年に1種ずつ順番に採っても種子が途切れません。この方式が最も少ない労力で純度を守ります。

&nbsp;&nbsp;&nbsp;網かけは畑が狭く隣が近いときに使う方法です。つぼみができる前に採種する株三、四本をまとめて網で覆い、蜂の出入りを防ぎます。すると花粉は入ってきませんが、同時に受粉もされません。ケールは自分の花粉ではうまく受精しない自家不和合性があるため、網の中で別の株同士で花粉を移してやる必要があります。筆や刷毛で花の間を行き来してこすればできます。そのため採種株は必ず複数本でなければなりません。

> **採種用の株は最低5本、できれば10本以上残します。他家受粉の作物は一、二株だけから種を採ると、数世代のうちに近交弱勢が現れて勢いが弱くなります。**

### 13-4. 越冬と採種の手順

| 段階 | 時期 | 内容 |
|---|---|---|
| 採種株の選定 | 秋 | 葉が大きく病気がなく品種特性がはっきりしている株を選びます |
| 越冬 | 11月-2月 | 根元に土を盛り藁と落ち葉で覆います |
| 抽だい | 3-4月 | 花茎が上がってきます。倒れないよう支柱を立てます |
| 開花 | 4-5月 | 黄色い花が咲きます。この時期に隔離を守ります |
| 結実 | 5-6月 | さやがつきます |
| 収穫 | 6-7月 | さやの3分の2が茶色く乾いたら茎ごと刈り取ります |
| 後熟・脱粒 | 収穫直後 | 陰干しで1-2週間乾かした後、袋に入れて叩きます |
| 選別・保管 | 完全に乾燥した後 | 唐箕でさやの殻を飛ばし、密閉して涼しい場所に置きます |

&nbsp;&nbsp;&nbsp;韓国中北部のように冬が厳しい地域では、露地での越冬が失敗することがあります。この場合は霜が降りる前に根こそぎ抜き、土を少し付けたまま室(むろ)や涼しい貯蔵庫に埋めておき、翌年の春に再び植える方法を使います。温度0-5℃、凍らず芽も出ない条件を保つ必要があります。貯蔵中に低温を経験することがそのまま春化になるため、この過程を経た株は植えるとすぐに花茎を上げます。

&nbsp;&nbsp;&nbsp;さやが全部乾くまで畑に置いてはいけません。アブラナ科のさやは完全に乾くと自然に裂けて種を地面にこぼします。下側のさやの3分の2が茶色になった時点で、上側はまだ緑色の状態のうちに茎ごと刈り取り、陰で後熟させるのがコツです。刈り取った茎を布や袋の上に置いて乾かせば、裂けて落ちる種まで集めることができます。

| 項目 | 基準 |
|---|---|
| 種子寿命 | 常温密閉4-5年 |
| 最適な保管 | 涼しく暗く乾燥した場所、密閉容器 |
| 乾燥剤 | 炒って冷ました米、炭、乾いた灰 |
| 発芽確認 | 毎年20粒を湿った布に置き数日後に発芽率を数えます |
| 一株の収穫量 | 種数千粒 |

&nbsp;&nbsp;&nbsp;ケール一株から出る種は数千粒です。十株から採種すれば、数年分の種を一度に確保できます。採種は毎年行うことではなく、3-4年に一度、その年にきちんと隔離して行うことです。

## 14. 毒性と注意すべき成分

&nbsp;&nbsp;&nbsp;ケールに急性毒性はありません。洗ってそのまま食べられ、評価表の調理・加工等級SSがその事実を反映しています。ただし、多く長期間食べると問題になりうる成分が二つあります。ゴイトロゲンとシュウ酸です。

| 成分 | どのような物質か | どのような問題になるか | 減らす方法 |
|---|---|---|---|
| ゴイトロゲン(グルコシノレート分解物) | アブラナ科特有の辛い香りと苦味の元 | ヨウ素の吸収を妨げて甲状腺機能を下げる可能性があります | 茹でたり加熱すればかなりの部分が分解されます |
| シュウ酸 | 植物がカルシウムと結合させて貯蔵する有機酸 | 多く食べると腎臓結石のリスクが上がります | ケールは含有量が低い方です。茹でて湯を捨てるとさらに減ります |
| 硝酸塩 | 窒素肥料を多く与えた葉に蓄積します | 過剰摂取時に問題になります | 窒素を過剰に与えず午後に収穫します |

### 14-1. ゴイトロゲン

&nbsp;&nbsp;&nbsp;アブラナ科の植物はグルコシノレートという硫化合物を持っています。葉が傷を受けると酵素が働いてこの物質を辛味のある化合物に変えますが、本来の目的は自分を食べる虫を追い払うことです。この分解物の一部が人の甲状腺でヨウ素が使われる過程を妨げます。ゴイトロゲンと呼ばれる理由です。

&nbsp;&nbsp;&nbsp;現実的な危険の大きさは条件次第です。ヨウ素を十分に摂っている人が普通の量のケールを食べるのは問題になりません。危険になる条件は、ヨウ素が不足した食事の中で生のケールを毎日大量に、特にジュースにして長期間食べる場合です。災害の状況で海から離れてワカメやコンブや塩が絶たれると、実際にヨウ素欠乏が起こり得て、その状態でケールを主力の野菜にすると問題が重なります。

> **対応は簡単です。茹でるとグルコシノレート分解酵素が破壊され、ゴイトロゲンのかなりの量が水に溶け出します。生ばかり食べずに、加熱した形と交互に食べればよいのです。**

&nbsp;&nbsp;&nbsp;海藻類が手に入るなら一緒に食べるのが根本的な解決です。ワカメ、コンブ、海苔はヨウ素の供給源であり、少量で十分です。甲状腺機能がすでに低い人は生のケールの摂取を減らし、加熱して食べる方が安全です。

### 14-2. シュウ酸

&nbsp;&nbsp;&nbsp;シュウ酸はホウレンソウやフダンソウやスベリヒユで問題になる成分で、ケールはその仲間に比べると含有量が著しく低いです。ホウレンソウ100gに700mg前後含まれているのに対し、ケールは20mgから50mgの水準で、一桁の差ではなく十倍以上の差があります。ケールのカルシウム吸収率が高い理由がここにあります。シュウ酸が少なくカルシウムが結合されず自由な状態で残るためです。ただしケールだけを1日1kg近く毎日食べるような極端な食事であれば、総量が積み重なります。複数の野菜を混ぜて食べるのが常に安全です。

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;ケールの貯蔵性等級はDです。摘み取った葉は無電力の常温で一週間を超えません。しかしこの弱点は畑でかなりの部分が解決されます。必要な分だけその日に摘めば、貯蔵する必要がないからです。

### 15-1. 畑がそのまま貯蔵庫

| 方法 | 条件 | 期間 |
|---|---|---|
| 畑に立てておく | マイナス10℃まで | 11月-翌年3月 |
| 藁・落ち葉掛け | 韓国中部以北 | 越冬成功率が上がります |
| 風よけ設置 | 北西側 | 冬の乾燥害を減らします |

&nbsp;&nbsp;&nbsp;冬に雪が深く積もって畑に出られない日が続くことがあります。その数日分だけ前もって摘んでおけばよいのです。洗わないまま湿った布に包んで涼しい納屋や床下、北向きの軒下に置けば5日から7日は持ちます。洗うと表面の水気が腐敗の始まりになるので、食べる直前に洗います。

### 15-2. 乾燥

| 段階 | 方法 |
|---|---|
| 下処理 | 洗って水気を完全に振り落とします |
| 湯通し | 沸騰した湯に30秒から1分。色が鮮やかになったら取り出します |
| 干す | 陰で風通しの良い場所に広げるか、縄に掛けます |
| 完全乾燥 | 手で崩れるくらいまで |
| 保管 | 密閉容器に入れ、炭や炒った米を一緒に入れます |
| 期間 | 6か月から1年 |

&nbsp;&nbsp;&nbsp;茹でてから干すと色と栄養の損失が減り、保管中の変色も少なくなります。ただしビタミンCは乾燥の過程で大半が失われます。乾燥ケールはビタミンAとカルシウムと鉄と食物繊維を残す貯蔵法であって、ビタミンCを残す貯蔵法ではありません。この区別が重要です。冬のビタミンCは干したものからではなく、畑に立つ生の葉と、後で述べる漬物から得られます。

&nbsp;&nbsp;&nbsp;しっかり乾かしたケールは手でもんで粉にしておくことができます。スープやお粥に一さじずつ入れると、かさが小さいまま栄養が入ります。干し野菜と同じように水で戻してあえ物にしたり炒めたりしても構いません。

### 15-3. 塩漬けと発酵

| 方法 | 塩の濃度 | 期間 | 特徴 |
|---|:---:|---|---|
| 塩辛型漬け | 塩10-15% | 数か月 | 長持ちしますが、食べる前に水にさらす必要があります |
| 乳酸発酵(キムチ型) | 塩2-3% | 数週間-数か月 | ビタミンCがかなり残ります |

&nbsp;&nbsp;&nbsp;冬のビタミンCのもう一つの経路が乳酸発酵です。ハクサイでキムチを漬けるように、ケールも漬けることができます。葉を粗く切り、重さの2-3%の塩で漬け、しんなりしたら押し込んで漬け汁が材料を覆うようにします。空気に触れない状態で乳酸菌が育って酸を作り、その酸が雑菌を防ぎます。

> **塩漬けにして煮る貯蔵法はビタミンCの大半を失いますが、乳酸発酵はかなりの量を残します。冬に新鮮なものがないとき、発酵食品が壊血病を防いできた歴史的な理由がこれです。**

&nbsp;&nbsp;&nbsp;ドイツのザワークラウトと韓国のキムチは同じ原理であり、冬が長い地域でこうした食べ物が発達したのは偶然ではありません。ケールはキャベツより葉が硬いため発酵がやや遅いですが、細かく切って十分にもめば問題ありません。甕やガラス瓶に入れ、石や水を入れた袋で押して汁の下に沈めるのがコツです。表面に白い産膜酵母が浮いたら取り除き、酸っぱく爽やかな匂いではなく腐った匂いがしたら捨てます。

## 16. 調理と加工

| 方法 | 燃料 | ビタミンCの保存 | 備考 |
|---|:---:|:---:|---|
| 生食(サム・サラダ) | なし | 最大 | 最も効率的です。硬い葉脈は取り除きます |
| 湯通し30秒-1分 | 非常に少ない | 半分以上 | ゴイトロゲンが減りかさが大きく減ります |
| 汁物・お粥に入れる | 他の調理と兼用 | 汁ごと食べれば保存されます | 別に燃料を使わない方法です |
| 炒める | 少ない | 中間 | 脂溶性のビタミンAとKの吸収が良くなります |
| 発酵 | なし | 相当量を維持 | 貯蔵と調理を兼ねます |
| 乾燥させて粉にする | 乾燥時は日光・風 | ほとんどなし | ミネラルとビタミンAは残ります |

&nbsp;&nbsp;&nbsp;燃料が乏しい状況でのケールの最大の長所は、加熱しなくても構わないという点です。大豆が8時間浸水させ1時間煮なければならないのと比べると差が大きいです。ただし先に見たようにゴイトロゲンのため全部生でだけ食べるのは勧められず、すでに他の料理を煮ている火に最後に投げ入れる方式が、燃料を追加で使わずに加熱した形を得る方法です。

&nbsp;&nbsp;&nbsp;油が少しでもあれば、炒める調理を混ぜるのが栄養上有利です。ケールが持つビタミンA(ベータカロテン)とビタミンKとルテインは脂溶性なので、油があってこそ吸収されます。油なしで食べると、これらの成分が体に入る割合が大きく落ちます。エゴマやゴマをすって入れたり、豆をすって作った汁物に入れたりするのも同じ効果を生みます。

&nbsp;&nbsp;&nbsp;硬い中心の葉脈は取り除くのが普通ですが、捨てる必要はありません。細かく切って汁物やお粥で長く煮ると柔らかくなり、食物繊維とミネラルはそのまま入っています。太い茎も同様に皮をむいて切って煮れば食べられます。

## 17. 年間作業スケジュール

| 月 | 作業 |
|---|---|
| 1月 | 冬の葉の収穫。風よけと覆いの状態を確認します |
| 2月 | 冬の葉の収穫。春の播種準備と堆肥の切り返し |
| 3月 | 下旬に春の播種。採種株の抽だい開始、支柱立て |
| 4月 | 春の播種苗の育苗管理。採種株の開花、隔離管理。花茎の収穫 |
| 5月 | 春苗の定植。モンシロチョウの見回り開始。防虫網の設置 |
| 6月 | 春ケールの初回収穫。採種株のさや形成。害虫の最盛期 |
| 7月 | 上旬に採種。高温期の管理(マルチング、灌水)。秋の播種開始 |
| 8月 | 秋の播種を継続。育苗管理。春の株の整理 |
| 9月 | 秋苗の定植。害虫の第2の最盛期。追肥 |
| 10月 | 秋ケールの収穫開始。越冬準備(土寄せ) |
| 11月 | 霜の後に糖度が上がる。藁・落ち葉掛け、風よけ設置 |
| 12月 | 冬の葉の収穫。採種株の越冬確認 |

&nbsp;&nbsp;&nbsp;この表から読み取るべきことは、ケールに休む月がないという点です。一年中畑に立ち、一年中収穫します。他の野菜がない1月と2月にも、ケールの欄には収穫と書かれています。ケールを畑の片隅に置く理由は、まさにこの二つの欄にあります。
