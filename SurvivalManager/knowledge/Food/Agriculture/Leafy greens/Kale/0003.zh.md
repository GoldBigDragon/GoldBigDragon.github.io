## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

&nbsp;&nbsp;&nbsp;羽衣甘蓝是十字花科芸薹属的二年生草本植物。学名为Brassica oleracea var. acephala，acephala意为"没有头"。同为一个物种Brassica oleracea，人类通过培育不同器官所形成的变种分别是：结球甘蓝(叶片层层包合形成叶球)、西蓝花(花芽聚合成团)、菜花(花茎膨大)、球茎甘蓝(茎部膨大)和球芽甘蓝(侧芽聚合成团)。羽衣甘蓝则是其中任何器官都没有特别膨大、最接近原始形态的一支。

&nbsp;&nbsp;&nbsp;这一血缘关系实际上意味着两件事。一是羽衣甘蓝、结球甘蓝和西蓝花之间会互相传播花粉，种子因而混杂。因为是同一物种，杂交没有任何障碍，这是留种时必须考虑的限制，也是第13节的主题。二是它们共享病虫害。菜粉蝶、小菜蛾、跳甲和根肿病会攻击整个十字花科。大白菜、萝卜、芥菜、油菜也属同科，因此共担同样的病害。在同一块地里连续种植十字花科作物，病原菌和害虫就会不断累积。

&nbsp;&nbsp;&nbsp;它的原产地是地中海沿岸和西欧大西洋一侧的海岸。野生甘蓝至今仍生长在英国和法国海边的石灰岩悬崖上。这个出身决定了羽衣甘蓝的栽培条件。

&nbsp;&nbsp;&nbsp;第一，它是凉爽海洋性气候的植物，不耐夏季高温。超过25℃，叶片就会变硬并出现苦味。

&nbsp;&nbsp;&nbsp;第二，它是石灰岩地带的植物，喜钙而厌酸性土壤。pH 6.0到7.0为适宜范围，酸性过重会导致根肿病大爆发。

&nbsp;&nbsp;&nbsp;第三，它是冬季温和却会降霜之地的植物，因此耐寒性强，必须经历冬季低温才会抽出花茎。这一现象称为春化，也是它二年生这一特性的原因。

### 2-2. 外观

| 器官 | 特征 |
|---|---|
| 叶 | 大而厚，表面有蜡质层。因品种不同，有的平展，有的严重卷皱。基本为绿色，也有红紫色系 |
| 茎 | 竖立一根粗壮结实的主茎。摘叶后留下的节痕使下部看起来像棕榈树的树干。高60-150cm |
| 根 | 主根可深入30-60cm，须根向两侧扩展。比大白菜或生菜扎根更深，更耐旱 |
| 花 | 4片黄色花瓣呈十字形排列，在第二年春天以总状花序开放 |
| 荚 | 细长的角果，成熟后变干呈褐色，纵向裂开 |
| 种子 | 直径1.5-2mm的圆粒，颜色为红褐色至黑色 |

&nbsp;&nbsp;&nbsp;要记住叶片的蜡质层。覆盖在羽衣甘蓝叶片表面的这层白色滑腻的物质，是一种防止水分蒸发、阻碍病原菌侵入的防御结构。这既是羽衣甘蓝比较耐旱的原因，也是喷水或喷药后药液会从叶面直接流走的原因。用肥皂水对付蚜虫时掺入少量肥皂，目的不是清洁，而是让药液能附着在这层蜡质上。

&nbsp;&nbsp;&nbsp;叶片以螺旋状排列在一根主茎上的结构，决定了羽衣甘蓝的采收方式。生长点始终只有一个，位于茎的顶端，新叶不断从那里长出。越靠下的叶子越老。因此从下往上采摘，植株就会不断向上生长并持续长出新叶；反之，若把顶端的生长点切掉，这株就到此为止了。第12节的采收要领全部由此而来。

&nbsp;&nbsp;&nbsp;根系扎得深，也有实用意义。像生菜那样根系浅的叶菜，一旦表土变干就会立即萎蔫，而羽衣甘蓝能从30cm以下吸取水分，即使灌溉延后几天也能撑住。耗水量等级被评为A，这一结构功不可没。

### 2-3. 生长阶段

| 阶段 | 时期 | 关键生理 | 重要养分 |
|---|---|---|---|
| 发芽·幼苗期 | 播种至长出2-3片真叶(2-3周) | 子叶展开，主根向下生长 | 磷、少量氮 |
| 营养生长期 | 长出4至8片真叶(3-8周) | 叶片数量快速增加，茎变粗 | 氮 |
| 收获期 | 长出8片真叶以后(自8-10周起) | 下部叶片长成，顶部持续长出新叶 | 氮与钾的平衡 |
| 越冬期 | 11月至次年2月 | 生长几乎停止，细胞中积累糖分 | 停止灌溉·施肥 |
| 抽薹·开花期 | 次年3-5月 | 茎迅速伸长，开出黄色花朵 | 磷、钾、硼 |

> **羽衣甘蓝抽薹的条件不是白昼长度，而是冬季的寒冷。幼苗经历10℃以下的低温数周后，这个信号就会被记录在体内，到次年春天气温回升时便会抽出花茎。**

&nbsp;&nbsp;&nbsp;这种被称为春化的现象，对留种而言是必经的过程，但对采叶而言却是要避免的事故。如果春天播种过早，幼苗长时间经历晚寒，当年春天就会直接抽出花茎。这称为早期抽薹，一旦抽薹，叶片就会变硬、产生苦味，不再长出新叶。韩国中部把春播定在3月下旬以后，原因就在这里。

&nbsp;&nbsp;&nbsp;越冬期的生理机制也值得了解。气温降到5℃以下时，羽衣甘蓝几乎不再生长，但也不会死。叶片细胞内的水一旦结冰，细胞膜就会破裂致使植株死亡，而羽衣甘蓝会在细胞液中溶入糖和氨基酸之类的溶质来降低冰点。直到零下10度，细胞内的水都不会结冰，叶片因此得以存活。霜打后的羽衣甘蓝变甜，正是这种糖的作用。只是冬天不再长出新叶，所以实际上是整个冬天一片一片地摘食秋天已经养好的那些叶子。

### 2-4. 每100g的营养成分

| 营养素 | 含量 | 备注 |
|---|:---:|---|
| 热量 | 28kcal | 按韩国国家标准食品成分表生品数据，非常低 |
| 蛋白质 | 3.35g | 占热量的47.9%。绝对量不高，但密度居于最高水平 |
| 碳水化合物 | 5-9g | 其中相当一部分是膳食纤维 |
| 脂肪 | 0.6-1.0g | 含量极少 |
| 膳食纤维 | 3-4g | 含量偏多 |
| 维生素C | 约90mg | 100g即可超过每日推荐量 |
| 维生素A(β-胡萝卜素) | 非常高 | 在蔬菜中居最高之列 |
| 维生素K | 非常高 | 100g即达推荐量的数倍 |
| 钙 | 200-330mg | 在蔬菜中处于最高水平 |
| 铁 | 1.5-2mg | 与维生素C共存，吸收率相对较好 |
| 钾 | 400-500mg | 参与钠的平衡调节 |
| 叶酸 | 丰富 | 参与造血 |
| 叶黄素·玉米黄质 | 丰富 | 是沉积在眼睛黄斑部的色素 |

&nbsp;&nbsp;&nbsp;正是这张表造就了评价表上微量营养素的SS。21种营养素中有18种超过每日推荐量的10%。尤其值得关注的是维生素C、维生素A、钙、维生素K这四项。在由谷物、薯类(块茎/块根)和豆类组成的饮食结构中，这四项正是空缺最大的地方。大米、马铃薯和豆类里几乎不含维生素C，或在烹调过程中大部分流失；维生素A的前体β-胡萝卜素在谷物中几乎不存在。至于钙，一旦没有牛奶和银鱼干，植物性来源就会急剧减少。

&nbsp;&nbsp;&nbsp;关于钙，需要加一条说明。羽衣甘蓝的钙含量在蔬菜中处于最高水平，吸收率也相对不错。菠菜或莙荙菜中的钙会与草酸结合而难以吸收，但羽衣甘蓝草酸含量低，情况有所不同。据报道，菠菜的钙吸收率在5%上下，而羽衣甘蓝可超过50%。这正是在乳制品断绝的条件下，羽衣甘蓝作为钙来源具有特殊价值的原因。

&nbsp;&nbsp;&nbsp;铁的情况也是同样的结构。植物性铁(非血红素铁)本身吸收率低，但如果同时有维生素C，吸收率会大幅提升。羽衣甘蓝在同一片叶子里同时含有铁和维生素C，有助于在没有肉类的饮食中延缓贫血的发生。

## 3. 栽培环境

### 3-1. 温度

| 项目 | 极限值 | 最适值 | 备注 |
|---|:---:|:---:|---|
| 发芽温度 | 5-30℃ | 20-25℃ | 15℃以下发芽会变慢 |
| 生长温度 | 5-30℃ | 15-20℃ | 评价表中温度适应幅度SS正是源自这25℃的跨度 |
| 高温极限 | 30℃以上 | - | 叶片变硬，苦味加重 |
| 低温极限 | 零下10℃ | - | 叶片仍存活，但生长停止 |
| 诱发春化 | 10℃以下持续数周 | - | 是引发抽薹的触发条件 |

&nbsp;&nbsp;&nbsp;羽衣甘蓝的温度范围达到25℃这一跨度，意味着一年四季里除了盛夏那一段，任何时候都能生长。春天种下能持续到秋天，秋天种下能持续到次年春天。只是在两端，品质会出现分化。超过30℃的夏天，叶片会变厚变硬，硫苷增多，苦味加重；反之遭霜打后则会变甜。所以即便是同一株羽衣甘蓝，8月的叶子和12月的叶子完全是两种不同的食物。

### 3-2. 光照

| 项目 | 标准 | 备注 |
|---|---|---|
| 所需日照 | 每日6小时以上 | 叶片变厚、颜色变深 |
| 最低日照 | 每日3-4小时 | 能生长，但叶片薄且徒长 |
| 40%遮光时 | 相对产量86% | 是叶菜类的共通数值，也是评价表B等级的依据 |

&nbsp;&nbsp;&nbsp;耐遮光这一点在灾难状况下价值很大。哪怕在40%的遮荫下也能维持86%的产量，这与大豆(50%)或马齿苋(45%)相比明显更有优势。这是因为吃叶子的作物本来就不需要把阳光转化为果实或根的这一转换环节。可以把羽衣甘蓝安排在墙根下、大树南侧边缘、建筑物之间的窄地这类整天晒不到太阳的边角空间，把光照好的地方留给谷物或豆类，这样的布局才合理。

### 3-3. 水分与土壤

| 项目 | 标准 | 备注 |
|---|---|---|
| 总蒸散量 | 每作约400mm | 在叶菜中偏少，也是评价表A等级的依据 |
| 土壤水分 | 最大持水量的70-80% | 既不干燥也不泥泞的状态 |
| 土质 | 富含有机质的壤土、砂壤土 | 需兼具排水性与保水性 |
| 土层深度 | 30cm以上 | 主根会向下深扎 |
| pH | 6.0-7.0 | 以6.5左右最为理想 |
| pH下限 | 5.5 | 低于此值根肿病会急剧增多 |
| 耐盐性 | 中等 | 因原产于海岸，在叶菜中属较强的一类 |

&nbsp;&nbsp;&nbsp;要记住，pH管理在羽衣甘蓝栽培中直接关系到病害管理。根肿病会在十字花科作物的根部形成瘤状物，堵塞水分和养分的通道，一旦侵入，会在土壤中存活7年以上。这种病无法用药治愈，且在酸性土壤中会爆发性蔓延。把pH提高到6.5以上，能大幅抑制病原菌的活动。在无法获得石灰的情况下，草木灰、贝壳和蛋壳烧后磨成的粉、牡蛎壳粉都可以替代。这个方法在第5节介绍。
