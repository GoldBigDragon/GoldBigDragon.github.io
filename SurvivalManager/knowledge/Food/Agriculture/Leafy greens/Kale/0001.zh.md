# 羽衣甘蓝
- 来源: 韩国农村振兴厅 农事路（Nongsaro）、韩国国家标准食品成分表、FAO ECOCROP、Wiki、Gemini、Claude、Chat-GPT
- 编者: GoldBigDragon
---
## 引言
&nbsp;&nbsp;&nbsp;羽衣甘蓝（Brassica oleracea var. acephala）与甘蓝是同一个种，是不结球的品系，也是最接近野生甘蓝的叶菜。综合等级为A（50.0分，有效183种中第17名），副食为SS（71.1分）。生羽衣甘蓝每100g热量只有28kcal，要只靠它满足每天2,100kcal，需要吃7.5kg，所以单位面积热量为C。羽衣甘蓝不是主食，而是补上谷物和薯类补不上的营养空缺的作物。微量营养素为SS，21种中有18种超过每日推荐量的10%。即便用稻米、土豆、豆类解决了热量和蛋白质，维生素A、C、K、叶酸、钙仍然是空的，这个空缺拖久了就会得坏血病、夜盲症、骨软化症。摘取茎下部长足的叶片，顶端就不断长出新叶，一棵可以从春天一直收获到来年春天，能耐零下10℃，遇霜后叶片积累糖分而变甜。它是冬季田里供应维生素C的活仓库。弱点是十字花科共有的病虫害（不防治时估计损失51.7%）、常温下撑不过1周的耐储性（D）、肥料一断就骤减的产量（无合成投入产量保持率40.8%），以及因二年生和异花授粉而困难的留种。它不是占满整块田的作物，而是在田角留十到二十棵的作物。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 十字花科芸苔属二年生草本。原产于地中海沿岸和西欧大西洋沿岸，所以怕夏季高温，喜钙，不喜酸性土壤 |
| 叶、茎 | 叶大而厚，覆有蜡质层，有平展的，也有强烈皱缩的（以绿色为基本，也有红紫色品系）。一根粗壮的中心茎笔直立起，高60-150cm，摘叶的位置留下茎节 |
| 根、花、荚果 | 直根深达30-60cm，对抗旱有利。第二年春天开黄色花，排成总状花序，成熟的荚果变成褐色干枯并纵向裂开 |

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 发芽至营养生长期 | 播种至8片真叶（约8周） | 直根下扎，叶数增加，茎变粗。磷、氮 |
| 收获期 | 8片真叶以后 | 下部叶长足，顶端不断长出新叶。氮与钾的平衡 |
| 抽薹、开花期 | 次年3-5月 | 茎急速生长，开黄色花。磷、钾、硼 |

> **促使羽衣甘蓝抽花茎的条件不是日照长度，而是冬季的寒冷。幼苗在10℃以下的低温中度过几周，来年春天气温回升时就会抽出花茎。**

&nbsp;&nbsp;&nbsp;春化对留种是必需的，但对想收叶片的人来说是要避免的事故。5℃以下几乎不生长，但细胞液中溶有糖和氨基酸，冰点降低，所以叶片到零下10℃都不会结冰。

&nbsp;&nbsp;&nbsp;每100g含热量28kcal、蛋白质3.35g（占热量的47.9%）、膳食纤维3-4g、维生素C约90mg、钙200-330mg、铁1.5-2mg、钾400-500mg。维生素A（β-胡萝卜素）和K在蔬菜中居最高之列，叶黄素、玉米黄质也很丰富。草酸少，钙的吸收率高（据报道菠菜约5%，羽衣甘蓝超过50%），铁与维生素C同在而容易吸收，所以在没有乳制品和肉类的条件下是钙和铁的来源。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽5-30℃（适温20-25℃），生长5-30℃（适温15-20℃）。30℃以上叶片变硬，苦味变重。零下10℃也不会死 |
| 光 | 6小时以上为佳，3-4小时则叶薄徒长。遮光40%仍保持86%的产量，所以适合围墙下、树荫下、楼房之间的零碎空地 |
| 水、土壤 | 每季总蒸散量约400mm，土壤水分为最大持水量的70-80%。富含有机质的壤土、砂壤土。耐盐性中等。pH 6.5以上（低于5.5时根肿病剧增） |

&nbsp;&nbsp;&nbsp;温度幅度达到25℃，除了盛夏几乎任何时候都能生长，但同样是羽衣甘蓝，8月的叶片和12月的叶片完全是两种食物。以冬季维生素为目的时选卷叶羽衣甘蓝（耐寒性很强，普及最广）或红色品系（特别耐寒，但产量低）；以总产量为目的时选榨汁用大型品种（是卷叶品种的1.5倍）；需要夏季收获时选托斯卡纳类型（比较耐热）。想持续留种，就要选定型品种而不是杂交种（F1）。杂交种从第二年起性状分离，种子包装上没有F1标注，或标明定型种、地方品种、开放授粉（OP）的种子才能世代沿用。

## 4. 田地准备、播种与定植
| 项目 | 标准 |
|:---|:---|
| 整地 | 深耕20-30cm（给直根开出下扎的路），垄宽90-120cm（双行种植），一定要有排水沟（过湿是根腐和根肿病的诱因） |
| 施肥（1,000㎡） | 氮10-12kg，磷6-8kg，钾8-10kg，腐熟堆肥1,500-2,000kg，石灰100-150kg（没有的话用草木灰，或烧过再捣碎的贝壳、蛋壳、牡蛎壳粉）。基肥在定植前1-2周施入，堆肥和磷全量，氮和钾的一半。追肥在定植后3-4周（以氮为主）、首次收获后（氮、钾），之后每3-4周少量追施 |
| 替代资源 | 稀释8-10倍的尿液（浇在植株间的沟里，碰到叶片会烧伤，收获前2周停用）、腐熟堆肥、草木灰（每1㎡一两把，每年不超过2-3次，过量会妨碍硼、铁、锰的吸收）、豆科绿肥（翻压后3-4周再定植）、草液肥（发酵2-3周后稀释5倍） |

> **摘叶就是把氮从田里带走。每次收获不少量补回肥料，新叶就会越来越小、颜色越来越淡。**

| 类型 | 播种 | 定植 | 收获 |
|:---|:---|:---|:---|
| 秋季栽培 | 7-8月 | 8-9月 | 9月至来年春天。品质最好 |
| 越冬栽培 | 8-9月 | 9-10月 | 11月至次年4月。中部以南 |
| 春季栽培 | 3月下旬-4月 | 4月下旬-5月 | 6-10月。夏季品质下降 |

&nbsp;&nbsp;&nbsp;灾害情况下以秋季栽培为主。它越冬后一直供叶到来年春天，而那段时期正是其他蔬菜全部消失的时期。春播推迟到3月下旬以后，是为了避免过早抽薹：幼苗在10℃以下度过3周以上，当年春天就会抽出花茎。

| 种植 | 标准 |
|:---|:---|
| 播种 | 深0.5-1cm，20-25℃下4-7天发芽。育苗30-40天（4-5片真叶），直播行距40-50cm（直根不被切断，所以更抗旱） |
| 间苗、定植 | 直播分两次间苗：2-3片真叶时留10cm，4-5片真叶时留30-40cm。定植株距30-40cm。间下来的幼苗可以直接吃 |
| 种子消毒 | 用50℃的水泡20分钟，随即用冷水降温（超过55℃种子会死） |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种至幼苗期 | 发芽前每天浇，保持表土不干；幼苗期每2-3天一次，稍微让它干一点，促使根向下扎 |
| 营养生长期、收获期 | 每周1-2次，每次浇透；收获期在摘叶后浇一次（浅而频繁地浇水会让根变浅） |
| 越冬期 | 几乎不浇（湿土冻结会伤根） |

&nbsp;&nbsp;&nbsp;中午萎蔫、傍晚恢复属于正常，早晨仍萎蔫是缺水，叶片小、厚、韧则是持续缺水。下部叶片发黄变软是过湿，要挖排水沟并停止浇水；整株突然萎蔫，就把根挖出来检查有没有肿瘤。过湿几天就会让植株倒下，所以要把垄做高，从结构上预防。用稻草、干草、落叶、稻壳覆盖（5-10cm）能减少蒸发，使浇水次数减少近一半，还能压制杂草，冬天防止冻结。下面容易藏蛞蝓，要时常掀开看看。

| 管理 | 方法 |
|:---|:---|
| 培土 | 定植后3-4周，在植株基部培5cm的土（摘叶使植株长高，容易被风吹倒，靠不定根固定） |
| 杂草 | 定植后4-6周是关键期。定植后立即覆盖，之后每2周用小锄头只刮表面2-3cm（挖深了会切断须根，还会把杂草种子翻上来） |
| 越冬 | 基部培土，盖稻草或落叶，在西北侧用高粱秆、玉米秆做防风障，中北部用无纺布拱棚 |

> **羽衣甘蓝的冬季受害来自风而不是气温。冷风夺走叶片的水分，而地面冻结、根又吸不上水时，叶片就会干枯。挡风要比覆盖更优先。**

## 6. 病虫害与养分问题
| 病虫害 | 症状与时期 | 不用药的对策 |
|:---|:---|:---|
| 菜青虫（菜粉蝶幼虫） | 只剩叶脉其余吃光。4-6月、9-10月 | 清晨或傍晚翻看叶背用手捉，擦掉叶背的黄色虫卵 |
| 小菜蛾、菜螟类 | 啃食叶背留下薄膜，或钻进心部。5-10月 | 防虫网、稀释的木醋液、勤观察、拔除受害株 |
| 跳甲 | 叶片上有小米粒大的孔。幼苗期 | 铺稻草，薄薄撒一层干灰（雨后重撒），防虫网 |
| 蚜虫、蓟马、蛞蝓 | 吸食嫩芽汁液 / 银白色伤痕 / 夜间出现不规则孔洞 | 肥皂水和水流冲洗，保护瓢虫 / 浇水保持湿度，清除杂草 / 夜间捉，撒灰或稻壳带 |
| 根肿病 | 根上长肿瘤，白天萎蔫。酸性土壤、过湿 | 无法治疗。pH 6.5以上、排水、轮作 |
| 霜霉病、白粉病、软腐病 | 叶片黄斑和叶背霉层 / 白色粉末 / 组织变软发臭 | 通风、保证间距、摘除病叶 / 稀释的牛奶（牛奶与水1:5） / 避免伤口、排水 |

> **根肿病用药治不好，会在土壤里存活7年以上。种十字花科作物的田，只能靠土壤pH、排水、轮作这三件事提前预防。**

&nbsp;&nbsp;&nbsp;把萎蔫的植株拔起来，根上有棍棒状肿瘤，就是根肿病。这块田至少5年、最好7年内不要种十字花科（羽衣甘蓝、甘蓝、大白菜、萝卜、芥菜、油菜、西兰花），病株不要放进堆肥，要烧掉或埋到远处深处。防蝴蝶和蛾产卵，最可靠的办法是在拱架上罩网眼1mm左右的网（蚊帐、旧窗帘也可以），边缘用土压严；罩之前先清除虫卵和幼虫，白天打开一侧通风。肥皂水是把20g无香肥皂溶进1L水里，喷到能直接碰到蚜虫（蜡质层会让液体流走，所以浓度稍微调高一点或分几次喷）；大蒜辣椒浸出液当驱避剂，木醋液稀释500-1,000倍使用。大范围喷洒会先杀死繁殖慢的天敌，所以要保护瓢虫、草蛉、蜘蛛和寄生蜂。

| 症状 | 原因与处理 |
|:---|:---|
| 下部叶片发黄，植株矮小 | 缺氮。稀释的尿液、腐熟堆肥、草液肥 |
| 新叶畸形，生长点枯死 | 缺硼（草木灰施得过多的田里常见）。停用草木灰，用腐熟堆肥提高有机质 |
| 新叶叶脉绿色、叶脉之间发黄 | 缺铁或缺镁。检查pH是否过高（超过7.5，硼、铁、锰吸收不了） |
| 叶片软大、柔弱，招来害虫 | 氮过量。停止供氮 |

&nbsp;&nbsp;&nbsp;氮、磷、钾、镁能在植物体内转移，所以缺乏症先出现在下部叶片；钙、硼、铁无法移动，所以先出现在新叶上。

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 豆科（豌豆、菜豆：固氮），大葱·洋葱·大蒜（气味让蝴蝶和蚜虫迷惑），土豆·甜菜（根的深度不同，养分竞争少） |
| 差 | 大白菜、萝卜、芥菜、西兰花等十字花科（共有病虫害，会不断积累），草莓（互相妨碍生长） |

&nbsp;&nbsp;&nbsp;羽衣甘蓝会带走大量的氮，所以后面接豆科。按羽衣甘蓝（十字花科）→豌豆·菜豆（豆科）→土豆·红薯→大葱·洋葱→再回到羽衣甘蓝的顺序轮作，羽衣甘蓝要隔4年才回到同一块地。在羽衣甘蓝垄间的沟里种豌豆或菜豆，收获后把茎叶翻压进去，不用化肥就能在田里自己制造氮。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 嫩叶在播种后30-40天，首次收获在60-70天（8片以上真叶，叶长20-25cm），之后每1-2周重复。冬季（11月至次年3月）不生长，所以把现有叶片一片一片摘 |
| 要领 | 清晨从下往上摘长足的叶片3-5片，把叶柄向茎的方向掰下来（切口干净才不会腐烂）。顶部始终留6-8片以上，摘后浇水 |
| 持续期 | 秋天种的可以收到来年春天抽花茎，共7-9个月，十到二十棵就能供一个人的冬季青菜 |
| 花茎 | 花蕾状态的花茎味道像西兰花，成为青黄不接时的蔬菜。只留下留种株，其余的摘来吃 |

> **生长点只有一个，在茎的顶端，所以顶端被切掉，这棵植株就完了。留下的叶片是光合作用的工厂，这个工厂制造下一批叶片。**

| 留种 | 标准 |
|:---|:---|
| 两道难关 | 二年生，要过一个冬天才开花。异花授粉，与整个Brassica oleracea类群（甘蓝、西兰花、花椰菜、球茎甘蓝、抱子甘蓝）完全杂交。大白菜、萝卜、芥菜是不同的种，没有关系 |
| 防止杂交 | 错开种植时间最现实：今年只让羽衣甘蓝开花，把甘蓝全部吃掉，明年反过来（种子寿命4-5年）。隔离距离500m以上。田小时，在花蕾形成之前用网罩住三四棵留种株，用毛笔转移花粉（自交不亲和，所以需要多棵植株） |
| 步骤 | 秋天选叶片大、无病的植株。11-2月越冬（基部培土，盖稻草和落叶），3-4月抽薹（立支柱），6-7月下部荚果的三分之二变褐时连茎割下，在阴凉处后熟。完全干燥后扬净、密封 |
| 中北部 | 露地越冬困难时，霜前连根带土挖起，埋进0-5℃的窖或库房，春天再栽 |

> **留种的植株至少5棵，最好10棵以上。异花授粉作物只从一两棵上留种，几代内就会出现近交衰退。**

&nbsp;&nbsp;&nbsp;种子要密封保存在阴凉黑暗处，每年取20粒放在湿布上检查发芽率。每3-4年留一次种，并做好隔离。

## 9. 储存
| 方法 | 条件与期限 |
|:---|:---|
| 留在田里 | 零下10℃以内，11月至次年3月（覆盖物和防风障能提高越冬成功率） |
| 提前摘下 | 提前摘几天的量，不洗，用湿布包好，放在阴凉的库房或朝北屋檐下，可保存5-7天（洗了就会开始腐败） |
| 干燥 | 洗净甩掉水分，用沸水焯30秒到1分钟，在阴凉处晾到用手能搓碎。和木炭或炒米一起装进密封容器，保存6个月到1年。磨成粉，每次舀一勺放进汤或粥里 |
| 乳酸发酵 | 盐2-3%，几周到几个月。切粗块腌渍，变软后压实，让汁液没过菜。维生素C保留相当一部分 |

> **干燥能保留维生素A、钙、铁和膳食纤维，但维生素C大部分会流失。冬天的维生素C不是来自干叶，而是来自田里站着的鲜叶和乳酸发酵。**

&nbsp;&nbsp;&nbsp;发酵物表面浮起白色的产膜酵母要撇掉，如果不是酸爽的气味而是腐臭味就要丢弃。羽衣甘蓝的叶子比甘蓝韧，要切细并充分揉搓。

## 10. 烹调与注意事项
| 方式 | 燃料与营养 |
|:---|:---|
| 生吃（包菜、沙拉） | 不用燃料，营养保留最多。去掉硬的叶脉 |
| 焯30秒到1分钟 | 燃料极少。致甲状腺肿素减少，体积大大缩小 |
| 放进汤或粥 | 最后放进已经在烧的锅里。连汤一起吃，营养得以保留 |
| 炒 | 维生素A（β-胡萝卜素）、K、叶黄素是脂溶性的，有油时吸收更好。放入磨碎的紫苏籽或芝麻、豆浆也有同样效果 |

| 成分 | 问题与对策 |
|:---|:---|
| 致甲状腺肿素（硫代葡萄糖苷的分解物） | 会妨碍碘的利用，可能降低甲状腺功能。在缺碘的饮食中，每天大量吃生羽衣甘蓝、尤其是榨汁长期饮用时有风险。生熟交替食用，配上海带、裙带菜、紫菜，甲状腺功能低的人要煮熟吃 |
| 草酸 | 羽衣甘蓝每100g为20-50mg，远低于菠菜（约700mg）。每天只吃近1kg羽衣甘蓝会积累，所以要搭配多种蔬菜 |
| 硝酸盐 | 积累在施氮多的叶片里。不要过量施氮，下午收获 |

&nbsp;&nbsp;&nbsp;羽衣甘蓝没有急性毒性，洗净后可以直接吃。

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 收获冬季叶片，检查防风障和覆盖物，2月翻堆堆肥 |
| 3-4月 | 3月下旬春播，给留种株立支柱。4月留种株开花并做好隔离，收获花茎 |
| 5-6月 | 5月定植春季幼苗，架设防虫网。6月首次收获，害虫高峰期 |
| 7-8月 | 7月上旬采种，覆盖保墒和浇水，开始秋播。8月育苗，清理春季植株 |
| 9-10月 | 9月定植秋季幼苗，第二次害虫高峰，追肥。10月开始收获秋季羽衣甘蓝，做越冬准备（培土） |
| 11-12月 | 11月霜后糖分升高时，盖稻草和落叶并架设防风障。12月收获冬季叶片，检查留种株越冬情况 |

> **羽衣甘蓝没有休息的月份。它一整年站在田里，一整年都在收获。在没有其他蔬菜的1月和2月，羽衣甘蓝那一栏也写着收获，把羽衣甘蓝留在田角的理由就在这两栏里。**
