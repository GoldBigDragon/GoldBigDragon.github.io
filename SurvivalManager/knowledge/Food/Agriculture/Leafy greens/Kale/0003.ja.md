## 2. どんな植物か

### 2-1. 分類と原産地

&nbsp;&nbsp;&nbsp;ケールはアブラナ科アブラナ属の二年生草本です。学名はBrassica oleracea var. acephalaで、acephalaは「頭がない」という意味です。同じ種であるBrassica oleraceaから人が互いに異なる器官を肥大させて作った変種が、キャベツ(葉が重なって結球したもの)、ブロッコリー(花芽が集まったもの)、カリフラワー(花茎が肥大したもの)、コールラビ(茎が膨らんだもの)、芽キャベツ(側芽が集まったもの)です。ケールはそのどの器官も特に肥大させていない、原形に最も近い系統です。

&nbsp;&nbsp;&nbsp;この系譜が実際に意味することは二つあります。一つは、ケールとキャベツとブロッコリーが互いに花粉をやり取りして種が混じり合うということです。種が同じなので交雑に何の障壁もありません。採種の際に必ず考慮すべき制約であり、13節の主題です。もう一つは病害虫を共有するということです。モンシロチョウとコナガとノミハムシと根こぶ病はアブラナ科全体を攻撃します。ハクサイ、ダイコン、カラシナ、ナタネも同じ科なので同じ病害を分け持ちます。アブラナ科の作物を同じ場所に続けて植えると、病原菌と害虫が蓄積します。

&nbsp;&nbsp;&nbsp;原産地は地中海沿岸と西ヨーロッパの大西洋側の海岸です。野生キャベツは今もイギリスとフランスの海辺の石灰岩の断崖に自生しています。この出自がケールの栽培条件を決めています。

&nbsp;&nbsp;&nbsp;第一に、涼しい海洋性気候の植物なので夏の高温に弱いです。25℃を超えると葉が硬くなり苦味が出ます。

&nbsp;&nbsp;&nbsp;第二に、石灰岩地帯の植物なのでカルシウムを好み、酸性土壌を嫌います。pH 6.0から7.0が適正で、酸性が強いと根こぶ病が爆発的に増えます。

&nbsp;&nbsp;&nbsp;第三に、冬は温暖でも霜が降りる土地の植物なので耐寒性が強く、冬の低温を経験してこそ花茎が上がってきます。これを春化といい、二年生という性質の原因です。

### 2-2. 見た目

| 器官 | 特徴 |
|---|---|
| 葉 | 大きく厚みがあり、表面にワックス層があります。品種により平らなものや激しく縮れたものがあります。緑色が基本で、赤紫系のものもあります |
| 茎 | 太くて丈夫な中心の茎を一本まっすぐに立てます。葉を摘んだ跡が節として残り、下部はヤシの木の幹のように見えます。高さ60-150cm |
| 根 | 直根が30-60cmまで下に伸び、細根が横に広がります。ハクサイやサンチュより深く伸びるため乾燥に有利です |
| 花 | 黄色い4枚の花弁が十字形に並びます。二年目の春に総状花序で咲きます |
| さや | 細長い角果です。熟すと茶色く乾き、縦に裂けます |
| 種子 | 直径1.5-2mmの丸い粒で、赤褐色から黒色です |

&nbsp;&nbsp;&nbsp;葉のワックス層を覚えておく必要があります。ケールの葉の表面を覆うこの白くて滑らかな層は、水分の蒸発を防ぎ病原菌の侵入を難しくする防御構造です。ケールが乾燥に比較的よく耐える理由であり、水や薬をかけても葉からそのまま流れ落ちる理由でもあります。石けん水でアブラムシを退治するときに石けんを少し混ぜるのは、洗浄が目的ではなくこのワックス層の上に液を付着させておくためです。

&nbsp;&nbsp;&nbsp;一本の中心の茎に葉がらせん状に付く構造が、ケールの収穫の仕方を決めています。生長点は常に茎の頂点に一つだけあり、そこから新しい葉が次々と出てきます。下側の葉ほど古い葉です。そのため下から上へと摘み取っていけば、株は上に伸び続けながら葉を作り出します。反対に頂点の生長点を切り落とすと、その株はそこで終わります。12節の収穫のコツはすべてこの構造から来ています。

&nbsp;&nbsp;&nbsp;根が深く伸びるという点にも実用的な意味があります。サンチュのように浅く根を張る葉物は表土が乾くとすぐに萎れますが、ケールは30cmより下の水を引き上げられるため、灌水が数日遅れても持ちこたえます。水消費量の等級がAと評価されたのには、この構造が一役買っています。

### 2-3. 生育段階

| 段階 | 時期 | 主な生理 | 重要な栄養 |
|---|---|---|---|
| 発芽・育苗期 | 播種から本葉2-3枚(2-3週) | 子葉が開き主根が下に伸びます | リン酸、少量の窒素 |
| 栄養生長期 | 本葉4枚から8枚(3-8週) | 葉数が急速に増え茎が太くなります | 窒素 |
| 収穫期 | 本葉8枚以降(8-10週から) | 下の葉が育ちきり、上から新しい葉が続けて出ます | 窒素とカリウムの均衡 |
| 越冬期 | 11月から翌年2月 | 生長がほぼ止まり細胞に糖が蓄積します | 灌水・施肥の中止 |
| 抽だい・開花期 | 翌年3-5月 | 茎が急速に伸び黄色い花が咲きます | リン酸、カリウム、ホウ素 |

> **ケールが花茎を上げる条件は日の長さではなく冬の寒さです。幼苗が10℃以下の低温を数週間経験すると、その信号が体に記録され、翌年の春に気温が上がると花茎が上がってきます。**

&nbsp;&nbsp;&nbsp;春化と呼ばれるこの現象は、採種の際には必ず必要な過程であり、葉を収穫する立場からは避けるべき事故です。春にあまり早く播種して幼苗が長く遅霜の寒さを経験すると、その年の春にすぐ花茎が上がってしまいます。これを早期抽だいといい、花茎が立つと葉が硬くなり苦味が出て、それ以上葉を作らなくなります。韓国中部で春の播種を3月下旬以降に定める理由がここにあります。

&nbsp;&nbsp;&nbsp;越冬期の生理も理解しておく価値があります。気温が5℃を下回るとケールはほとんど生長しません。しかし枯れることもありません。葉の細胞内の水が凍ると細胞膜が破れて植物は死にますが、ケールは細胞液に糖やアミノ酸のような溶質を溶かして凝固点を下げます。マイナス10度までは細胞内の水が凍らず、そのため葉が生きています。霜に当たったケールが甘い理由はまさにこの糖です。ただし冬の葉は新しく出てこないので、秋のうちに十分育てておいた葉を冬の間一枚ずつ摘んで食べることになります。

### 2-4. 100gあたりの栄養

| 栄養素 | 含有量 | 備考 |
|---|:---:|---|
| 熱量 | 28kcal | 韓国国家標準食品成分表の生の値です。非常に低いです |
| タンパク質 | 3.35g | 熱量比47.9%です。絶対量は少ないですが密度は最上位です |
| 炭水化物 | 5-9g | かなりの部分が食物繊維です |
| 脂質 | 0.6-1.0g | ごくわずかです |
| 食物繊維 | 3-4g | 多い方です |
| ビタミンC | 90mg前後 | 100gで1日推奨量を超えます |
| ビタミンA(ベータカロテン) | 非常に高い | 野菜の中でも最上位クラスです |
| ビタミンK | 非常に高い | 100gで推奨量の数倍になります |
| カルシウム | 200-330mg | 野菜の中で最高水準です |
| 鉄 | 1.5-2mg | ビタミンCと一緒に含まれているため吸収されやすい方です |
| カリウム | 400-500mg | ナトリウムの均衡に関与します |
| 葉酸 | 豊富 | 造血に関与します |
| ルテイン・ゼアキサンチン | 豊富 | 目の黄斑に蓄積する色素です |

&nbsp;&nbsp;&nbsp;評価表の微量栄養素SSを作ったのがこの表です。21種のうち18種で1日推奨量の10%を超えます。特に注目すべきはビタミンC、ビタミンA、カルシウム、ビタミンKの四つです。この四つは穀物といも類(塊茎・塊根)と豆類で構成された食事で最も大きく空く部分です。米とジャガイモと豆にはビタミンCがほとんどないか調理の過程で大半が失われ、ビタミンAの前駆体であるベータカロテンは穀物にほぼ含まれません。カルシウムは牛乳とカタクチイワシがなくなると植物性の供給源が急激に減ります。

&nbsp;&nbsp;&nbsp;カルシウムについては一つ条件をつけておく必要があります。ケールのカルシウム含有量は野菜の中で最高水準でありながら、吸収率も良い方です。ホウレンソウやフダンソウのカルシウムはシュウ酸と結合して吸収されにくいのですが、ケールはシュウ酸含有量が低いため事情が異なります。ホウレンソウのカルシウム吸収率が5%前後であるのに対し、ケールは50%を超えるという報告があります。乳製品が消える状況でケールがカルシウム供給源として特別な価値を持つ理由です。

&nbsp;&nbsp;&nbsp;鉄も同じ構造です。植物性の鉄(非ヘム鉄)は元々吸収率が低いですが、ビタミンCが一緒にあると吸収が大きく上がります。ケールは鉄とビタミンCを一枚の葉に一緒に含んでおり、肉のない食事で貧血の進行を遅らせるのに役立ちます。

## 3. 栽培環境

### 3-1. 温度

| 区分 | 限界値 | 最適値 | 備考 |
|---|:---:|:---:|---|
| 発芽温度 | 5-30℃ | 20-25℃ | 15℃以下では発芽が遅くなります |
| 生育温度 | 5-30℃ | 15-20℃ | 評価表の温度適応幅SSはこの25℃の幅から出ています |
| 高温限界 | 30℃以上 | - | 葉が硬くなり苦味が強くなります |
| 低温限界 | マイナス10℃ | - | 葉は生きていますが生長は止まります |
| 春化誘発 | 10℃以下で数週間 | - | 花茎が上がってくる引き金です |

&nbsp;&nbsp;&nbsp;ケールの温度範囲が25℃に達するということは、四季の中で夏の一時期を除けばいつでも育つという意味です。春に植えて秋まで、秋に植えて翌年の春まで続きます。ただし両端では品質が分かれます。30℃を超える夏には葉が厚く硬くなり、グルコシノレートが増えて苦味が強くなります。反対に霜に当たると甘くなります。そのため同じケールでも8月の葉と12月の葉はまったく違う食べ物です。

### 3-2. 光

| 区分 | 基準 | 備考 |
|---|---|---|
| 必要日照 | 1日6時間以上 | 葉が厚く色が濃くなります |
| 最小日照 | 1日3-4時間 | 育ちはしますが葉が薄く徒長します |
| 40%遮光時 | 相対収量86% | 葉菜類共通の値であり評価表のB等級の根拠です |

&nbsp;&nbsp;&nbsp;遮光に強いという点は災害の状況で価値が大きいです。40%の陰でも収量の86%を維持するというのは、大豆(50%)やスベリヒユ(45%)と比べて大きく有利です。葉を食べる作物はそもそも日光を果実や根に変える変換段階がないためです。塀の下、大きな木の南側の縁、建物の間の狭い土地のように日が一日中当たらない余った空間にケールを配置し、日当たりの良い場所は穀物や豆に譲るという配置が合理的です。

### 3-3. 水と土壌

| 項目 | 基準 | 備考 |
|---|---|---|
| 総蒸発散量 | 作期当たり約400mm | 葉菜の中では少ない方であり評価表のA等級の根拠です |
| 土壌水分 | 最大容水量の70-80% | 乾きすぎず湿りすぎない状態です |
| 土性 | 有機物の多い埴土、砂質埴土 | 排水と保水が両立している必要があります |
| 土壌深さ | 30cm以上 | 直根が深く伸びます |
| pH | 6.0-7.0 | 6.5前後が最も良いです |
| pH下限 | 5.5 | これより下では根こぶ病が急激に増えます |
| 耐塩性 | 中程度 | 海岸出身のため葉菜の中では強い方です |

&nbsp;&nbsp;&nbsp;pH管理がケール栽培において病害管理と直結しているという点を覚えておく必要があります。根こぶ病はアブラナ科作物の根にこぶを作り、水と養分の通路をふさぐ病気で、一度入り込むと土の中で7年以上生き続けます。薬で治療する病気ではなく、酸性土壌で爆発的に広がります。pHを6.5以上に上げると病原菌の活動が大きく抑えられます。石灰が手に入らない状況では、草木灰、貝殻や卵の殻を焼いて砕いた粉、カキの殻の粉が代用になります。この方法は5節で取り上げます。
