## はじめに
&nbsp;&nbsp;&nbsp;ケール(Brassica oleracea var. acephala)はキャベツと同じ種で、結球しない系統であり、野生のキャベツにもっとも近い葉物です。総合等級はA(50.0点、有効183種中17位)、副食はSS(71.1点)です。生のケールは100gの熱量が28kcalしかなく、1日2,100kcalをケールだけで満たそうとすると7.5kgを食べなければならないため、面積当たりの熱量はCです。ケールは主食ではなく、穀物やイモ類が満たせない栄養の空白を埋める作物です。微量栄養素はSSで、21種のうち18種が1日の推奨量の10%を超えます。米、ジャガイモ、豆で熱量とタンパク質をまかなっても、ビタミンA・C・K、葉酸、カルシウムは空いたままで、この空白が長引くと壊血病、夜盲症、骨軟化症になります。茎の下のほうの育った葉を摘むと先端から新しい葉が出続け、1株で春から翌春まで収穫でき、氷点下10℃まで耐え、霜に当たると葉に糖がたまって甘くなります。冬の畑でビタミンCを供給する、生きた貯蔵庫です。弱点は、アブラナ科共通の病害虫(防除しない場合の推定被害51.7%)、常温で1週間もたない貯蔵性(D)、肥料が途切れると急に減る収量(合成資材を投入しない場合の収量維持率40.8%)、二年生で他家受粉のため難しい採種です。畑全体ではなく、隅に10株から20株を立てておく作物です。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | アブラナ科アブラナ属の二年草。原産地は地中海沿岸と西ヨーロッパの大西洋沿岸で、夏の高温に弱く、カルシウムを好み、酸性土壌を嫌う |
| 葉、茎 | 葉は大きくて厚く、ワックス層に覆われ、平らなものや強く縮れたものがある(緑色が基本で、赤紫色の系統もある)。太い中心の茎が1本、60-150cmにまっすぐ立ち、葉を摘んだ跡に節が残る |
| 根、花、莢 | 主根は30-60cmと深く、干ばつに有利。2年目の春に黄色い花が総状花序で咲き、熟した莢は褐色に乾いて縦に裂ける |

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 発芽から栄養成長期 | 播種から本葉8枚(約8週間) | 主根が下りて葉数が増え、茎が太くなる。リン酸、窒素 |
| 収穫期 | 本葉8枚以降 | 下の葉が育ちきり、先端から新しい葉が出続ける。窒素とカリウムのバランス |
| とう立ち、開花期 | 翌年の3-5月 | 茎が急に伸び、黄色い花が咲く。リン酸、カリウム、ホウ素 |

> **ケールが花茎を立てる条件は、日の長さではなく冬の寒さです。若い苗が10℃以下の低温を数週間経験すると、翌春に気温が上がったときに花茎が立ちます。**

&nbsp;&nbsp;&nbsp;春化は採種には欠かせませんが、葉を収穫する側には避けるべき事故です。5℃より低いとほとんど育ちませんが、細胞液に糖とアミノ酸が溶けて凝固点が下がるため、氷点下10℃まで葉が凍りません。

&nbsp;&nbsp;&nbsp;100g当たり熱量28kcal、タンパク質3.35g(熱量比47.9%)、食物繊維3-4g、ビタミンC約90mg、カルシウム200-330mg、鉄1.5-2mg、カリウム400-500mgです。ビタミンA(βカロテン)とKは野菜の中で最上位圏で、ルテイン・ゼアキサンチンも豊富です。シュウ酸が少なくカルシウムの吸収率が高く(ホウレンソウは5%前後、ケールは50%超という報告)、鉄はビタミンCと一緒にあるため吸収されやすいので、乳製品や肉がない条件でのカルシウム・鉄の供給源です。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽5-30℃(適温20-25℃)、生育5-30℃(適温15-20℃)。30℃以上になると葉が硬くなり、苦味が強くなる。氷点下10℃でも枯れない |
| 光 | 6時間以上がよく、3-4時間だと葉が薄く徒長する。40%遮光でも収量の86%を保つため、塀の下、木陰、建物の間の空き地に向く |
| 水、土壌 | 総蒸発散量は1作で約400mm、土壌水分は最大容水量の70-80%。有機物の多い壌土、砂壌土。耐塩性は中程度。pH6.5以上(5.5より低いと根こぶ病が急増) |

&nbsp;&nbsp;&nbsp;温度幅が25℃に及ぶので、真夏を除けばいつでも育ちますが、同じケールでも8月の葉と12月の葉はまったく別の食べ物です。冬のビタミンが目的ならカーリーケール(耐寒性がとても強く、もっとも広く普及)か赤色系統(寒さに特に強いが収量は少ない)、総収量が目的なら青汁用の大型種(カーリーケールの1.5倍)、夏の収穫が必要ならトスカーナ系(暑さに比較的強い)を選びます。種を採り続けるなら、交配種(F1)ではなく固定種を確保しなければなりません。交配種は翌年から形質が分離し、種の袋にF1の表示がない、または固定種、在来種、開放受粉(OP)と書かれた種が、代々使えます。

## 4. 畑の準備と播種、定植
| 項目 | 基準 |
|:---|:---|
| 土づくり | 20-30cmの深さに耕し(主根が下りる道をつくる)、畝の幅90-120cm(2列植え)、排水溝は必ず(過湿は根腐れと根こぶ病の引き金) |
| 施肥(1,000㎡) | 窒素10-12kg、リン酸6-8kg、カリウム8-10kg、完熟堆肥1,500-2,000kg、石灰100-150kg(なければ木灰、焼いて砕いた貝殻・卵の殻・カキ殻の粉)。元肥は定植の1-2週間前に、堆肥とリン酸の全量、窒素とカリウムの半分。追肥は定植の3-4週間後(窒素中心)、初収穫後(窒素、カリウム)、その後は3-4週間ごとに少しずつ |
| 代替資源 | 尿の8-10倍希釈液(株の間の溝に注ぎ、葉に触れると焼け、収穫2週間前から中止)、完熟堆肥、木灰(1㎡に一つかみか二つかみ、年2-3回まで、多いとホウ素・鉄・マンガンの吸収が妨げられる)、マメ科の緑肥(すき込んで3-4週間後に定植)、草の液肥(2-3週間発酵させ5倍に薄める) |

> **葉を摘むことは、畑から窒素を持ち出すことです。収穫のたびに肥料を少しずつ戻さないと、新しい葉がだんだん小さく、淡くなります。**

| 作型 | 播種 | 定植 | 収穫 |
|:---|:---|:---|:---|
| 秋作 | 7-8月 | 8-9月 | 9月から翌春。品質が最もよい |
| 越冬作 | 8-9月 | 9-10月 | 11月から翌年4月。中部以南 |
| 春作 | 3月下旬-4月 | 4月下旬-5月 | 6-10月。夏に品質が落ちる |

&nbsp;&nbsp;&nbsp;災害時は秋作が中心です。冬を越して翌春まで葉を出し続け、その期間がほかの野菜がすべて消える期間です。春の播種を3月下旬以降に遅らせるのは、若い苗が10℃以下を3週間以上経験すると、その春のうちに花茎が立つ早期とう立ちを避けるためです。

| 植え方 | 基準 |
|:---|:---|
| 播種 | 深さ0.5-1cm、20-25℃で4-7日で発芽。育苗は30-40日(本葉4-5枚)、直播は条間40-50cm(主根が切れないので干ばつに強い) |
| 間引き、定植 | 直播は本葉2-3枚で10cm、4-5枚で30-40cmに2回間引く。定植の株間は30-40cm。間引いた若い苗はそのまま食べられる |
| 種子消毒 | 50℃のお湯に20分浸し、すぐ冷水で冷ます(55℃を超えると種が死ぬ) |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から幼苗期 | 発芽まで表土が乾かないように毎日、幼苗期は2-3日に1回、根が下へ伸びるよう少し乾かす |
| 栄養成長期、収穫期 | 週1-2回、1回でたっぷり。収穫期は葉を摘んだ後に1回(浅く頻繁な水やりは根を浅くする) |
| 越冬期 | ほとんどやらない(濡れた土が凍ると根が傷む) |

&nbsp;&nbsp;&nbsp;昼にしおれて夕方に回復すれば正常、朝もしおれていれば水不足、葉が小さく厚く硬ければ継続的な水不足です。下の葉から黄色くなって軟らかくなれば過湿なので排水溝を掘って水やりを止め、株全体が急にしおれたら根を掘ってこぶがないか確認します。過湿は数日で株を倒すので、畝を高くして構造的に防ぎます。わら、枯れ草、落ち葉、もみ殻のマルチ(5-10cm)は蒸発を減らして水やりの回数をほぼ半分にし、雑草を抑え、冬は凍結を防ぎます。下にナメクジが隠れやすいので、ときどきめくります。

| 管理 | 方法 |
|:---|:---|
| 土寄せ | 定植の3-4週間後に株元へ土を5cm盛る(葉を摘み上げて背が高くなると風で倒れるので、不定根で支える) |
| 雑草 | 定植後4-6週間が決定的な時期。定植直後にマルチをし、その後は2週間おきに小さな鍬で表面2-3cmだけかく(深く掘ると細根が切れ、雑草の種が上がる) |
| 越冬 | 株元の土寄せ、わらや落ち葉で覆う、北西にモロコシやトウモロコシの茎で風よけ、中北部は不織布のトンネル |

> **ケールの冬の被害は、気温よりも風からきます。冷たい風が葉の水分を奪い、地面が凍って根が水を上げられないと、葉が乾いてしまいます。風を防ぐことは、覆うことより先です。**

## 6. 病害虫と養分の問題
| 病害虫 | 症状と時期 | 薬を使わない対処 |
|:---|:---|:---|
| モンシロチョウの幼虫 | 葉脈だけ残して食べる。4-6月、9-10月 | 早朝か夕方に葉の裏を手で捕る、葉の裏の黄色い卵をこすり落とす |
| コナガ、シンクイムシ類 | 葉の裏をかじって薄い膜を残す、または芯に食い込む。5-10月 | 防虫ネット、木酢液の希釈液、こまめな観察、被害株の除去 |
| ノミハムシ | 葉にあわ粒のような穴。幼苗期 | わらを敷く、乾いた灰を薄くまく(雨の後はもう一度)、防虫ネット |
| アブラムシ、アザミウマ、ナメクジ | 新芽の汁を吸う / 銀白色の傷 / 夜に不規則な穴 | 石けん水と水流、テントウムシを守る / 水やりで湿度を保つ、雑草を除く / 夜に捕る、灰やもみ殻の帯 |
| 根こぶ病 | 根にこぶができ、昼にしおれる。酸性土壌、過湿 | 治療不可。pH6.5以上、排水、輪作 |
| べと病、うどんこ病、軟腐病 | 葉の黄色い斑点と裏のカビ / 白い粉 / 組織が軟らかくなり悪臭 | 風通し、間隔の確保、病葉の除去 / 牛乳の希釈液(牛乳と水を1対5) / 傷をつけない、排水 |

> **根こぶ病は薬では治せず、土の中で7年以上生きます。アブラナ科の作物を植える畑は、土のpH、排水、輪作の3つで前もって防ぐしかありません。**

&nbsp;&nbsp;&nbsp;しおれる株を抜いて根に棍棒のようなこぶがあれば、根こぶ病です。その畑には少なくとも5年、できれば7年、アブラナ科(ケール、キャベツ、ハクサイ、ダイコン、カラシナ、ナタネ、ブロッコリー)を植えず、病気の株は堆肥に入れずに焼くか、遠くへ深く埋めます。チョウやガの産卵は、目合い1mm前後のネット(蚊帳や古いカーテンでも可)をフープに張り、縁を土で押さえて防ぐのが最も確実で、かける前に卵と幼虫を取り除き、昼は片側を開けて風を通します。石けん水は無香料の石けん20gを水1Lに溶かし、アブラムシに直接かかるように散布し(ワックス層のせいで流れ落ちるので、濃度を少し高めるか何回かに分けて散布)、ニンニクと唐辛子の浸出液は忌避剤として、木酢液は500-1,000倍で使います。広く散布すると繁殖の遅い天敵が先にいなくなるので、テントウムシ、クサカゲロウ、クモ、寄生バチを守ります。

| 症状 | 原因と対処 |
|:---|:---|
| 下の葉から黄色くなり、株が小さい | 窒素欠乏。尿の希釈液、完熟堆肥、草の液肥 |
| 新葉が奇形で成長点が枯れる | ホウ素欠乏(灰を多く入れた畑で多い)。灰をやめ、完熟した堆肥で有機物を増やす |
| 新葉の葉脈は緑で、その間が黄色 | 鉄またはマグネシウムの欠乏。pHが高すぎないか確認(7.5を超えるとホウ素・鉄・マンガンが吸収されない) |
| 葉が軟らかく大きく、柔弱で害虫が集まる | 窒素過剰。窒素の供給をやめる |

&nbsp;&nbsp;&nbsp;窒素、リン酸、カリウム、マグネシウムは植物の中で移動できるため欠乏は下の葉から、カルシウム、ホウ素、鉄は動けないため新しい葉から先に現れます。

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | マメ科(エンドウ、インゲンマメ: 窒素を固定)、ワケギ・長ネギ・タマネギ・ニンニク(においがチョウやアブラムシを惑わす)、ジャガイモ・ビート(根の深さが違い、養分の競争が少ない) |
| 悪い | ハクサイ、ダイコン、カラシナ、ブロッコリーなどアブラナ科(病害虫を共有して蓄積する)、イチゴ(互いの生育を妨げる) |

&nbsp;&nbsp;&nbsp;ケールは窒素を多く持ち出すので、その後にマメ科を置きます。ケール(アブラナ科)→エンドウ・インゲンマメ(マメ科)→ジャガイモ・サツマイモ→長ネギ・タマネギ→ふたたびケールの順で回すと、ケールが同じ場所に戻るまで4年かかります。ケールの畝の間の溝にエンドウやインゲンマメを植え、収穫後に茎と葉をすき込めば、化学肥料なしで畑の中で窒素をつくれます。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | ベビーリーフは播種30-40日後、初収穫は60-70日(本葉8枚以上、葉の長さ20-25cm)で、その後は1-2週間おきに繰り返す。冬(11月から翌年3月)は育たないので、ある葉を1枚ずつ摘む |
| 要領 | 早朝に、下から育ちきった葉を3-5枚、葉柄を茎のほうへ折り下げて摘む(切り口がきれいだと腐らない)。常に上に6-8枚以上を残し、摘んだ後に水をやる |
| 継続期間 | 秋に植えると翌春に花茎が立つまで7-9か月収穫でき、10株から20株で1人の冬の青菜がまかなえる |
| 花茎 | つぼみの状態の花茎はブロッコリーに似た味で、春先の端境期の野菜になる。採種株だけを残して摘んで食べる |

> **成長点は茎の先端に1つしかないので、先端を切るとその株は終わりです。残した葉は光合成の工場であり、その工場が次の葉をつくります。**

| 採種 | 基準 |
|:---|:---|
| 2つの壁 | 二年生で、冬を越さないと花が咲かない。他家受粉で、Brassica oleracea全体(キャベツ、ブロッコリー、カリフラワー、コールラビ、メキャベツ)と完全に交雑する。ハクサイ、ダイコン、カラシナは種が違うので問題ない |
| 交雑の防止 | 時期をずらす栽培が最も現実的: 今年はケールだけ花を咲かせてキャベツは食べきり、翌年は逆にする(種子の寿命4-5年)。隔離距離は500m以上。狭い畑では、花のつぼみができる前に採種株3-4株をネットで覆い、筆で花粉を移す(自家不和合性なので複数の株が必要) |
| 手順 | 秋に葉が大きく病気のない株を選ぶ。11-2月に越冬(株元に土を盛り、わらと落ち葉で覆う)、3-4月にとう立ち(支柱)、6-7月に下のほうの莢の3分の2が褐色になったら茎ごと刈り、日陰で追熟させる。十分に乾かしてから、箕で選別して密閉する |
| 中北部 | 野外での越冬が難しければ、霜の前に根ごと土をつけて掘り上げ、0-5℃の穴や納屋に埋めておき、春に植え直す |

> **採種用の株は最低5株、できれば10株以上を残します。他家受粉の作物は、1、2株だけから種を採ると、数世代で近交弱勢が現れます。**

&nbsp;&nbsp;&nbsp;種は密閉して涼しく暗い所に置き、毎年20粒を濡れた布に置いて発芽率を確認します。採種は3-4年に1回、きちんと隔離して行います。

## 9. 貯蔵
| 方法 | 条件と期間 |
|:---|:---|
| 畑に立てておく | 氷点下10℃まで、11月から翌年3月(覆いと風よけで越冬の成功率が上がる) |
| 摘み置き | 数日分を前もって摘み、洗わずに濡れた布で包み、涼しい納屋や北向きの軒下に置けば5-7日(洗うと傷みが始まる) |
| 乾燥 | 洗って水気を切り、沸騰した湯で30秒-1分ゆで、日陰で手で砕けるまで干す。炭や炒った米と一緒に密閉容器で6か月-1年。粉にして汁物やお粥に一さじずつ入れる |
| 乳酸発酵 | 塩2-3%、数週間-数か月。粗く切って塩漬けし、しんなりしたら押さえ込んで汁に浸す。ビタミンCがかなり残る |

> **乾燥はビタミンA、カルシウム、鉄、食物繊維を残しますが、ビタミンCはほとんど失われます。冬のビタミンCは、干した葉ではなく、畑に立っている生の葉と乳酸発酵から得られます。**

&nbsp;&nbsp;&nbsp;発酵の表面に白い産膜酵母が浮いたらすくい取り、酸っぱくさわやかなにおいではなく腐ったにおいがしたら捨てます。ケールの葉はキャベツより硬いので、細かく切って十分にもみます。

## 10. 調理と注意事項
| 方法 | 燃料と栄養 |
|:---|:---|
| 生食(包み野菜、サラダ) | 燃料不要、栄養の保存が最大。硬い葉脈は取る |
| 30秒-1分の湯通し | 燃料はごく少ない。ゴイトロゲンが減り、かさが大きく減る |
| 汁物、お粥に入れる | すでに煮ている火の最後に入れる。汁ごと食べれば栄養が保たれる |
| 炒める | ビタミンA(βカロテン)、K、ルテインは脂溶性なので、油があると吸収がよくなる。エゴマやゴマをすって入れたり豆乳を使っても同じ効果 |

| 成分 | 問題と対応 |
|:---|:---|
| ゴイトロゲン(グルコシノレートの分解物) | ヨウ素の利用を妨げ、甲状腺の機能を下げることがある。ヨウ素が不足した食事で、生のケールを毎日大量に、とくに搾り汁にして長く食べるときに危険。生と加熱を交互に食べ、ワカメ・昆布・海苔を添え、甲状腺機能が低ければ加熱して食べる |
| シュウ酸 | ケールは100g当たり20-50mgで、ホウレンソウ(700mg前後)よりはるかに少ない。ケールだけを毎日1kg近く食べると蓄積するので、いろいろな野菜を混ぜる |
| 硝酸塩 | 窒素を多く与えた葉にたまる。窒素を与えすぎず、午後に収穫する |

&nbsp;&nbsp;&nbsp;ケールに急性毒性はなく、洗ってそのまま食べられます。

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 冬の葉の収穫、風よけと覆いの確認、2月に堆肥の切り返し |
| 3-4月 | 3月下旬に春の播種、採種株の支柱。4月に採種株の開花と隔離、花茎の収穫 |
| 5-6月 | 5月に春の苗の定植、防虫ネット設置。6月に初収穫、害虫の最盛期 |
| 7-8月 | 7月上旬に採種、マルチと水やり、秋の播種開始。8月に育苗、春の株の片付け |
| 9-10月 | 9月に秋の苗の定植、害虫の2回目の最盛期、追肥。10月に秋のケールの収穫開始、越冬準備(土寄せ) |
| 11-12月 | 11月に霜の後で糖度が上がったら、わらと落ち葉で覆い風よけを設置。12月に冬の葉の収穫、採種株の越冬確認 |

> **ケールに休む月はありません。1年中畑に立ち、1年中収穫します。ほかの野菜がない1月と2月にも、ケールの欄には収穫が書かれており、ケールを畑の隅に置く理由はまさにその2つの欄にあります。**
