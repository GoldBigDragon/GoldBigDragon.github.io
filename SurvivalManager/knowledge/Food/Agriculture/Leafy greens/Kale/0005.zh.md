## 8. 栽培管理

### 8-1. 间苗与培土

| 作业 | 时期 | 内容 |
|---|---|---|
| 第1次间苗 | 2-3片真叶 | 缩小株距至10cm |
| 第2次间苗 | 4-5片真叶 | 最终株距30-40cm |
| 第1次培土 | 定植后3-4周 | 在茎基部堆高5cm的土 |
| 第2次培土 | 株长大之后 | 需要时再培一次 |
| 清理下部叶片 | 随时 | 摘除发黄的叶片和病叶 |

&nbsp;&nbsp;&nbsp;培土在羽衣甘蓝的管理中尤为重要。如果一直往上摘叶，茎会变长，只剩上部有叶片，重心也随之升高。一遇风就容易倒伏，倒伏后茎会折断，那株也就到此结束。往茎基部培土，能让不定根从那里长出来撑住株身。插上竹竿或粗树枝把茎绑住，也是同样的目的。在冬季积雪的地区，这项工作能大幅改变越冬的成功率。

&nbsp;&nbsp;&nbsp;不放任发黄的下部叶片也很重要。老叶几乎不进行光合作用，却仍在消耗养分，还容易成为潮湿天气里霉菌滋生的起点。摘下的叶子要带出田外堆入堆肥堆；如果是病叶，则不能入堆肥，要烧掉或深埋在远处。

### 8-2. 杂草管理

&nbsp;&nbsp;&nbsp;在没有除草剂的情况下，杂草管理全靠时机。定植后4-6周是关键期。这段时间里若杂草长得比羽衣甘蓝快，就会抢走光照和养分，使其难以恢复。反之，只要撑过这段时期，等羽衣甘蓝的叶片覆盖地面，那片阴影自然就能压制杂草。

| 时期 | 方法 |
|---|---|
| 定植后立即 | 用覆盖材料提前压制 |
| 定植后2-6周 | 每隔2周用锄头浅锄一次 |
| 之后 | 只拔除较大的杂草 |

&nbsp;&nbsp;&nbsp;锄地要浅锄。挖得太深会切断羽衣甘蓝的细根，还会把埋在土里的杂草种子翻到表面重新发芽。只需刮松表面2-3cm、切断刚出芽杂草的根就足够了。选晴天上午操作，被切断的杂草当天就会晒干枯死。

### 8-3. 越冬管理

| 方法 | 材料 | 效果 |
|---|---|---|
| 基部培土 | 土 | 保护根部及生长点附近 |
| 覆盖稻草 | 稻草、干草 | 延缓地温下降 |
| 覆盖落叶 | 橡树落叶 | 效果同稻草，到春天可直接化为肥料 |
| 防风屏障 | 高粱秆、玉米秆、芦苇帘 | 挡住西北风。冷害的很大一部分来自风 |
| 覆盖拱棚 | 无纺布、地膜(如有) | 韩国南部可以省略，中北部则能延长采收期 |

> **羽衣甘蓝的冬季受害，风比气温更关键。零下5℃的强风比零下10℃的无风更伤叶。挡风要先于覆盖。**

&nbsp;&nbsp;&nbsp;寒风夺走叶片水分，而地面结冰使根部无法吸水时，叶片就会干枯变褐，这种现象称为冬季旱害。把高粱秆或玉米秆立起来编成帘子挡在西北面，能大幅减少这种损害，而这些材料本就是夏季作物的副产物，无需另外准备。

## 9. 病虫害 - 不打药的防治方法

### 9-1. 主要害虫

| 害虫 | 受害表现 | 发生时期 | 不打药的防治方法 |
|---|---|---|---|
| 菜粉蝶幼虫 | 绿色幼虫啃食叶片，只留下叶脉 | 4-6月、9-10月 | 人工捕捉、覆盖防虫网、擦除叶背的黄色虫卵 |
| 小菜蛾 | 小幼虫啃食叶背，留下一层薄膜 | 5-10月 | 防虫网、稀释木醋液、经常巡查监测 |
| 跳甲 | 黑色小虫在叶片上留下针眼状小孔 | 4-6月 | 幼苗期覆盖防虫网、撒草木灰、垄面覆稻草 |
| 蚜虫 | 聚集在叶背和新芽上吸食汁液，叶片卷缩 | 4-6月、9-10月 | 肥皂水、水流冲洗、保护瓢虫 |
| 甘蓝夜蛾(蛀心类蛾虫) | 钻蛀心叶和新芽 | 夏-秋 | 防虫网、拔除发生株 |
| 蛞蝓 | 夜间在叶片上啃出不规则孔洞 | 梅雨季(在韩国为6月下旬至7月) | 夜间人工捕捉、用灰或稻壳在株周做隔离带 |
| 蓟马 | 叶片出现银白色伤痕 | 高温干燥期 | 灌溉保湿、清除杂草 |

### 9-2. 为什么人工捕捉有效

&nbsp;&nbsp;&nbsp;菜粉蝶幼虫体型大、动作慢。它们贴着叶脉、颜色又和叶片相近，不容易被发现，但只要顺着叶片上的破洞找，大多能在附近发现它们。早晨或黄昏时翻看叶背捕捉，每天花几分钟就能大幅减少数量。在十到二十株规模的小菜园里，光靠这个方法就能达到防治效果。无防治减产率51.7%这个数字是完全不作为时的数值，在每天人工捕捉的地里，这个数字会大幅下降。

&nbsp;&nbsp;&nbsp;更高效的做法是在虫卵阶段就加以阻止。菜粉蝶会在叶背一颗一颗地产下细长的黄色卵。看到白蝶在地里飞舞的第二天检查叶背，就能找到这些卵，用手指一搓就能提前消灭一只幼虫。抹掉一颗卵比捉一只幼虫容易得多，而且损害根本还没发生。

### 9-3. 防虫网与物理阻隔

&nbsp;&nbsp;&nbsp;防住蝴蝶和蛾类最可靠的方法，是不让它们产卵。用网眼约1mm的防虫网罩在支架上覆盖整块地，边缘用土压实封住，就能阻断菜粉蝶和小菜蛾产卵。文献记载的有机栽培实证中，覆盖防虫网也被列为效果最确实的手段。

&nbsp;&nbsp;&nbsp;没有防虫网时，要考虑替代物。细密的蚊帐、旧窗帘、薄布、旧纱网都能用。但通风变差会让霉菌病增多，所以不要完全密封，白天可以开一侧调节。如果盖网之前叶片上已经有虫卵或幼虫，等于把它们关在里面继续养大，所以盖网前一定要先检查叶片。

&nbsp;&nbsp;&nbsp;跳甲需要不同的应对方式。这种虫从土里钻出并跳跃移动，尤其喜欢幼苗。在地表铺上稻草或干草，能堵住它们从土里爬出的路；在叶片上薄薄撒一层干灰，会让叶面变得粗糙，使它们不愿啃食。灰遇雨会被冲掉，雨后需要重新撒。

### 9-4. 天然防治剂

| 防治剂 | 制作方法 | 对象 | 注意 |
|---|---|---|---|
| 肥皂水 | 将20g无香皂溶于1L水中 | 蚜虫、红蜘蛛、蓟马 | 正午喷洒会烧叶。应在傍晚喷洒，次日早上用水冲洗 |
| 大蒜辣椒浸出液 | 将100g大蒜和干辣椒用1L水打碎，浸泡一天后过滤 | 驱避剂，用于蚜虫、成蛾 | 只作预防用，不能杀死已附着的害虫 |
| 木醋液 | 稀释500-1,000倍 | 各类驱避 | 浓度过高会伤叶 |
| 草木灰 | 过筛后薄薄撒在叶片和土壤上 | 跳甲、蛞蝓 | 呈碱性，过量会使土壤酸碱度失衡 |
| 稀释牛奶 | 牛奶与水按1比5混合 | 蚜虫、白粉病 | 仅在能获得牛奶时适用 |

&nbsp;&nbsp;&nbsp;肥皂水对付蚜虫的原理不是毒性，而是物理作用：肥皂会溶解蚜虫气孔和体表的蜡质层，使其窒息。因此药液必须直接接触虫体才有效，喷完一干就失效。要点是瞄准聚集在叶背的蚜虫，从下往上喷。由于羽衣甘蓝叶片有蜡质层，肥皂水容易滑落，可适当调高肥皂浓度，或分两三次喷洒。

### 9-5. 主要病害

| 病害 | 症状 | 条件 | 应对 |
|---|---|---|---|
| 根肿病 | 根部长瘤，白天萎蔫 | 酸性土壤、积水过湿 | 无法治疗。保持pH 6.5以上，做好排水，轮作7年以上 |
| 霜霉病 | 叶片出现黄斑，叶背有灰白色霉层 | 天气凉湿时 | 加强通风、加大株距、清除病叶 |
| 菌核病 | 基部腐软，出现白色菌丝和黑色菌核 | 低温潮湿 | 排水、拔除病株、轮作 |
| 黑腐病 | 叶缘呈V字形变黄 | 高温潮湿 | 种子温水消毒、清除病株 |
| 软腐病 | 组织腐软并散发臭味 | 高温潮湿、有伤口 | 避免造成伤口、做好排水 |
| 白粉病 | 叶片被白粉覆盖 | 干燥凉爽时 | 加强通风、喷稀释牛奶 |

> **根肿病无法用药治愈，会在土壤中存活7年以上。要在种植十字花科作物的地里预先防住它，只能靠酸度、排水和轮作这三件事。**

&nbsp;&nbsp;&nbsp;判断田里是否已感染根肿病的方法很简单：拔起生长中途萎蔫的株，查看根部，若挂着棍状或瘤状的膨大肿块，就是根肿病。这块地至少5年、最好7年内不要种十字花科作物，羽衣甘蓝、卷心菜、大白菜、萝卜、芥菜、油菜、西蓝花全都算在内。病株不能留在原地或放入堆肥，要烧掉或深埋在远离田地的地方，因为肿块里的休眠孢子散入土壤正是传播途径。

### 9-6. 农业防治原则

| 原则 | 内容 |
|---|---|
| 调整播种期 | 避开害虫发生高峰期播种。菜粉蝶在5-6月和9月最多 |
| 轮作 | 不连续种植十字花科。至少2年，若有根肿病则需7年 |
| 保持株距 | 保持30-40cm。过密会阻碍通风，增加霉菌病 |
| 清除残株 | 不把采收完的株和病叶留在地里 |
| 间种 | 茴香、香菜、胡萝卜花等伞形科植物的花能招来寄生蜂和食蚜蝇，减少蚜虫 |
| 保护天敌 | 不杀瓢虫、草蛉和蜘蛛，这正是要避免大范围喷药的原因 |

&nbsp;&nbsp;&nbsp;保护天敌在长期灾难中尤为重要。一只瓢虫一天能吃掉几十只蚜虫；寄生蜂会把卵产在菜粉蝶幼虫体内，从内部将其杀死。在这种关系稳定下来的地里，害虫密度会自行受到抑制。反之，大范围喷药会让繁殖较慢的天敌先消失，只有繁殖快的害虫卷土重来，第二年问题反而更严重。没有农药的状况既是一种限制，同时也是重建这种平衡的条件。

## 10. 营养缺乏与过量

| 症状 | 原因 | 天然材料应对 |
|---|---|---|
| 从下部叶片开始全株发黄，株型偏小 | 缺氮 | 尿液稀释8-10倍液、腐熟堆肥、杂草液肥 |
| 叶缘出现褐色焦枯 | 缺钾 | 在株周撒草木灰 |
| 叶片呈深青绿色且不生长 | 缺磷 | 骨粉、草木灰 |
| 新叶畸形，生长点枯死 | 缺硼 | 用腐熟堆肥补充有机质。灰施用过多的地里常见此症 |
| 新叶叶脉间发黄而叶脉仍绿 | 缺铁或缺镁 | 检查pH是否过高，减少草木灰用量 |
| 叶片薄大而软，招引害虫聚集 | 氮过量 | 停止供氮，同时也更易感病 |
| 叶片出现白斑，生长停滞 | 盐分过量 | 增加灌水量以冲洗，降低尿液浓度 |

&nbsp;&nbsp;&nbsp;缺素症状是从老叶开始还是从新叶开始，是诊断的第一个分岔点。氮、磷、钾、镁是可以在植株体内移动的元素，一旦不足就会从老叶抽调送往新叶，因此症状先出现在下部叶片。反之，钙、硼、铁一旦沉积就不能再移动，所以症状会先出现在新叶上。下部叶片发黄先怀疑缺氮，新叶畸形则先怀疑缺硼或缺钙。

&nbsp;&nbsp;&nbsp;施灰过多的地里常出现缺硼和缺铁。灰属碱性，会提高土壤酸碱度，一旦pH超过7.5，硼、铁、锰就会在土壤中凝结成不溶于水的形态，根系无法吸收。这不是土里没有这些元素，而是有也吸收不到。这种情况下不应再加灰，而要停用，靠腐熟堆肥补充有机质慢慢恢复。

## 11. 间作与轮作

| 搭配 | 对象 | 效果 |
|:---:|---|---|
| 好 | 豆科(豌豆、菜豆) | 固氮，为羽衣甘蓝留下可用的氮 |
| 好 | 大葱、洋葱、大蒜 | 气味能干扰蝴蝶和蚜虫 |
| 好 | 茴香、香菜、胡萝卜花 | 招来寄生蜂和食蚜蝇，减少蚜虫 |
| 好 | 马铃薯、甜菜根 | 根系深度不同，养分竞争较少 |
| 一般 | 生菜、菠菜 | 覆盖地面，压制杂草 |
| 差 | 大白菜、萝卜、芥菜、西蓝花等十字花科 | 共享病虫害，会不断累积 |
| 差 | 草莓 | 彼此妨碍生长 |

&nbsp;&nbsp;&nbsp;轮作顺序的原理是不连续种植同科作物，并在耗养分多的作物之后安排能制造养分的作物。羽衣甘蓝喜肥，会大量抽走地里的氮，因此接下来安排豆科作物。

```
羽衣甘蓝(十字花科，喜肥) → 豌豆·菜豆(豆科，恢复氮) → 马铃薯·甘薯(茄科·旋花科) →
大葱·洋葱(百合科) → 重新种羽衣甘蓝
```

&nbsp;&nbsp;&nbsp;按这个顺序轮转，羽衣甘蓝回到同一块地需要4年。如果确认地里有根肿病，这个周期就要延长到7年以上，期间绝对不能加入十字花科。要点是：萝卜和芥菜同样属于十字花科，因此这一整个轮作周期里都不能安排它们。

&nbsp;&nbsp;&nbsp;在间作中与豆科搭配的组合价值特别大。若在羽衣甘蓝垄间的沟里种上豌豆或菜豆，豆类根瘤所固定的氮，一部分会通过根系分泌物和落叶回到土壤中。豆类收获后若把茎叶就地翻入土中，效果会更大。在没有化肥的条件下，这种搭配是在地里自行制造氮的少数几个办法之一。
