## 12. 收获 - 持续采摘的技巧

| 用途 | 时期 | 状态 |
|---|:---:|---|
| 嫩叶(幼苗叶) | 播种后30-40天 | 比手掌还小的叶片 |
| 初次收获 | 播种后60-70天 | 本叶8片以上，叶长20-25cm |
| 反复收获 | 此后每隔1-2周 | 从下方采摘已长成的叶片 |
| 冬季收获 | 11月-次年3月 | 因不再生长，现有叶片逐片采摘 |

### 12-1. 从下方采摘的原因

&nbsp;&nbsp;&nbsp;羽衣甘蓝的生长点只有茎顶一处。新叶不断从那里长出，越往下的叶片越老。因此，摘掉下方已长成的叶片，植株几乎没有损失。摘掉的是光合能力已经下降的老叶，植株会把原本用在那里的养分转向新叶。

&nbsp;&nbsp;&nbsp;反之，如果剪掉顶端，这株植株就到此为止了。生长点消失，无法再长出新叶。虽然会长出侧芽分成多个枝条，但叶片会变小，产量大幅下降。整株齐根收割的做法，只在决定放弃这株植株时才采用。

| 项目 | 要领 |
|---|---|
| 采摘的叶片 | 从下方起已长成的叶片3-5片 |
| 保留的叶片 | 上方始终保留6-8片以上 |
| 采摘方法 | 将叶柄朝茎的方向折下。断口要干净才不会腐烂 |
| 采摘时间 | 清晨。经过一夜含水，此时最新鲜 |
| 采摘后 | 浇水，每3-4周施一次追肥 |

> **上方始终保留六到八片叶子。保留的叶片就是光合作用工厂，正是这个工厂制造出下一批叶片。若贪心全部摘光，这株植株便会就此停滞。**

### 12-2. 一株能维持多久

&nbsp;&nbsp;&nbsp;秋季种下的羽衣甘蓝可以一直采收到次年春天抽薹为止，大约7-9个月。在韩国南部或冬季温和的年份，有时能延续到第二年夏天。评价表中"持续性"项的S级，指的正是这种持续性。一株每周采摘三四片、坚持30周，可超过100片；按一名成人每天吃三四片大叶计算，十到二十株羽衣甘蓝便能撑起一人一冬的蔬菜。

&nbsp;&nbsp;&nbsp;春天到来、抽薹之后，叶片会变硬，苦味加重，这便是这株植株的终点。不过抽出的花薹本身可以食用。在开花之前、还是花蕾状态的花薹，味道近似西兰花，口感柔软。从冬末到春季蔬菜上市之前的空档期，也就是所谓的春荒期，这种花薹能派上用场。只留下几株用来采种，其余的花薹都可以摘来吃。

## 13. 留种 - 二年生与异花授粉的障碍

### 13-1. 两道障碍

&nbsp;&nbsp;&nbsp;羽衣甘蓝留种存在两道障碍。第一，它是二年生植物，必须经过冬天才能开花。第二，它是异花授粉作物，会与附近的十字花科作物随意杂交。这正是评价表中"自家留种"等级止步于A的原因，与大豆因自花授粉而获得S级形成对照。

| 障碍 | 内容 | 解决办法 |
|---|---|---|
| 二年生 | 必须经历低温才能抽薹 | 让其越冬，或拔起储藏后于春天重新种下 |
| 异花授粉 | 蜜蜂传播花粉，与其他品种混杂 | 隔离距离、错期栽培、覆盖网罩 |

### 13-2. 会与什么杂交

&nbsp;&nbsp;&nbsp;羽衣甘蓝(Brassica oleracea)会与同一物种的所有变种完全杂交。结球甘蓝、西兰花、花椰菜、球茎甘蓝、抱子甘蓝和羽衣甘蓝同属一个物种，彼此之间没有任何障碍。如果羽衣甘蓝旁边的结球甘蓝开花，那一年采下的种子就会既不是羽衣甘蓝也不是结球甘蓝，而是杂交种。

| 作物 | 学名 | 与羽衣甘蓝杂交 |
|---|---|:---:|
| 结球甘蓝、西兰花、花椰菜、球茎甘蓝、抱子甘蓝 | Brassica oleracea | 完全杂交 |
| 大白菜、青梗菜、芜菁、油菜 | Brassica rapa | 几乎不杂交 |
| 芥菜、黄芥 | Brassica juncea | 几乎不杂交 |
| 萝卜 | Raphanus sativus | 属不同，不杂交 |

&nbsp;&nbsp;&nbsp;这张表在实际操作中很重要。在采收羽衣甘蓝种子的那一年，大白菜、萝卜或芥菜同时开花并无妨碍，因为它们是不同的物种。真正成问题的，只有Brassica oleracea这一类，也就是结球甘蓝、西兰花和球茎甘蓝那一边。

### 13-3. 防止杂交的三种方法

| 方法 | 内容 | 可行性 |
|---|---|---|
| 隔离距离 | 与其他开花的Brassica oleracea相距500m以上 | 邻田无法控制，难以做到 |
| 错期栽培 | 一年只让一种开花 | 最为现实 |
| 覆盖网罩 | 开花前罩上网，网内用毛笔人工授粉 | 小规模时确实可靠 |

&nbsp;&nbsp;&nbsp;最现实的解决办法是错期栽培。今年只从羽衣甘蓝上采种，结球甘蓝则全部吃掉，不让它开花；第二年反过来做。由于羽衣甘蓝种子能保存4到5年，即便每年轮流只采一种的种子，也不会断种。这种方式用最少的力气就能守住品种的纯度。

&nbsp;&nbsp;&nbsp;覆盖网罩是地块狭小、邻田靠得很近时使用的方法。在花蕾形成之前，把打算留种的三四株植株一起罩上网，阻止蜜蜂进出。这样外来花粉进不来，但同时也无法授粉。羽衣甘蓝存在自交不亲和的特性，不容易靠自己的花粉受精，因此需要在网内让不同株之间互相传粉。用毛笔或软刷在花朵之间来回轻轻涂抹即可。正因如此，留种株必须是多株而非一株。

> **留种用的植株至少保留5株，最好10株以上。异花授粉作物如果只从一两株上采种，不出几代就会出现近交衰退，长势变弱。**

### 13-4. 越冬与留种流程

| 阶段 | 时期 | 内容 |
|---|---|---|
| 留种株挑选 | 秋季 | 挑选叶片大、无病、品种特征明显的植株 |
| 越冬 | 11月-2月 | 在根部培土，覆盖稻草和落叶 |
| 抽薹 | 3-4月 | 花薹长出。立支架防止倒伏 |
| 开花 | 4-5月 | 开出黄花。此时遵守隔离要求 |
| 结荚 | 5-6月 | 长出果荚 |
| 收获 | 6-7月 | 果荚三分之二变褐干燥后，连茎割下 |
| 后熟·脱粒 | 收获后立即 | 在阴凉处晾1-2周后装入袋中拍打 |
| 精选·保存 | 完全干燥后 | 用簸箕扬去果壳，密封放在阴凉处 |

&nbsp;&nbsp;&nbsp;像韩国中北部那样冬季严寒的地区，露地越冬可能失败。这时可在降霜之前将植株连根拔起，带一点土窖藏在地窖或阴凉的库房里，到次年春天再重新种下。储藏温度须保持在0-5℃，既不结冰又不发芽。储藏期间经历低温本身就相当于春化，因此经过这一过程的植株一旦栽下便会立即抽薹。

&nbsp;&nbsp;&nbsp;不能把果荚留在地里等它全部晒干。十字花科的果荚一旦完全干透，就会自行裂开，把种子撒落在地上。诀窍是在下部果荚三分之二变褐、上部仍是绿色时，连茎割下，放在阴凉处后熟。把割下的茎放在布或袋子上晾晒，就能连开裂脱落的种子也一并收集起来。

| 项目 | 标准 |
|---|---|
| 种子寿命 | 常温密封4-5年 |
| 最佳保存 | 阴凉、避光、干燥处，密封容器 |
| 干燥剂 | 炒过晾凉的米、木炭、干灰 |
| 发芽确认 | 每年取20粒放在湿布上，数天后计算发芽率 |
| 单株采收量 | 数千粒种子 |

&nbsp;&nbsp;&nbsp;一株羽衣甘蓝能结出数千粒种子。若对十株留种，一次就能确保够用好几年的种子。留种不必年年做，而是每3-4年做一次，那一年要认真做好隔离。

## 14. 毒性与需注意的成分

&nbsp;&nbsp;&nbsp;羽衣甘蓝没有急性毒性。洗净即可直接食用，评价表中"烹饪·加工"等级为SS正反映了这一点。不过，长期大量食用时可能出问题的成分有两种：致甲状腺肿素和草酸。

| 成分 | 是什么物质 | 会造成什么问题 | 减少方法 |
|---|---|---|---|
| 致甲状腺肿素(硫代葡糖苷分解产物) | 十字花科特有辛辣香气与苦味的来源 | 会妨碍碘的吸收，可能降低甲状腺功能 | 焯水或加热后大部分会分解 |
| 草酸 | 植物用来与钙结合并储存的有机酸 | 大量食用会增加肾结石风险 | 羽衣甘蓝含量较低。焯水后倒掉水分可进一步减少 |
| 硝酸盐 | 积累于施氮肥过多的叶片中 | 过量摄入会成为问题 | 不过量施氮，并在下午收获 |

### 14-1. 致甲状腺肿素

&nbsp;&nbsp;&nbsp;十字花科植物含有一种叫硫代葡糖苷的含硫化合物。叶片一旦受伤，酶就会被激活，将这种物质转化为带辛辣味的化合物，其本来目的是驱赶啃食自己的虫子。这些分解产物中的一部分会妨碍人体甲状腺利用碘的过程，这就是"致甲状腺肿素"这个名称的由来。

&nbsp;&nbsp;&nbsp;实际风险的大小取决于具体条件。碘摄入充足的人正常量食用羽衣甘蓝并无问题。真正危险的情形是：在缺碘的饮食结构下，每天大量食用生羽衣甘蓝，尤其是长期榨汁饮用。在灾难状况下，若远离海边导致海带、裙带菜和盐断供，确实可能出现碘缺乏，若此时又把羽衣甘蓝当作主力蔬菜，两个问题就会叠加在一起。

> **应对方法很简单。焯水会破坏分解硫代葡糖苷的酶，相当一部分致甲状腺肿素会溶入水中流失。不要只吃生的，与熟食交替食用即可。**

&nbsp;&nbsp;&nbsp;如果能获得海藻类，一起食用是根本的解决办法。裙带菜、海带、紫菜都是碘的来源，少量即可满足需要。甲状腺功能本就偏低的人，减少生食羽衣甘蓝、改以熟食为主更为安全。

### 14-2. 草酸

&nbsp;&nbsp;&nbsp;草酸是菠菜、莙荙菜和马齿苋中会成为问题的成分，而羽衣甘蓝相比这一类蔬菜含量明显偏低。菠菜每100g含700mg左右草酸，而羽衣甘蓝只有20mg到50mg，差距不是几倍，而是十倍以上。这正是羽衣甘蓝钙吸收率较高的原因：草酸少，钙不容易被结合，能以自由状态留存。不过，如果每天几乎只吃将近1kg羽衣甘蓝这种极端饮食，总量仍会积累。混搭多种蔬菜食用始终更安全。

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;羽衣甘蓝的耐储性等级为D。摘下的叶片在无电力常温下撑不过一周。但这一弱点很大程度上可以在田里解决——只要当天只摘需要的量，就不必费心储藏。

### 15-1. 田地即是贮藏库

| 方法 | 条件 | 期间 |
|---|---|---|
| 立于田中 | 至零下10℃ | 11月-次年3月 |
| 覆盖稻草·落叶 | 韩国中部以北 | 提高越冬成功率 |
| 设置防风屏障 | 西北侧 | 减少冬季干旱损害 |

&nbsp;&nbsp;&nbsp;冬天积雪深厚时，可能连续几天无法下地。这种情况下，只需提前把那几天要用的量摘好即可。不用清洗，直接用湿布包好放在阴凉的库房、地板下或朝北的屋檐下，可以保存五到七天。清洗过的叶片表面的水分会成为腐坏的起点，所以要在食用前才洗。

### 15-2. 干燥

| 阶段 | 方法 |
|---|---|
| 处理 | 洗净后彻底甩干水分 |
| 焯水 | 沸水中30秒到1分钟，颜色变鲜亮后捞出 |
| 晾晒 | 挂在阴凉通风处或系在绳上 |
| 完全干燥 | 至用手能捏碎为止 |
| 保存 | 装入密封容器，同时放入木炭或炒米 |
| 期间 | 6个月到1年 |

&nbsp;&nbsp;&nbsp;先焯水后晾干，能减少色泽和营养的损失，储藏期间也不易变色。不过维生素C在干燥过程中大部分会消失。晒干的羽衣甘蓝是一种保留维生素A、钙、铁和膳食纤维的储藏方式，而不是保留维生素C的方式，这一区别很重要。冬天的维生素C，不是来自干货，而是来自田里还立着的鲜叶和后面提到的腌渍食品。

&nbsp;&nbsp;&nbsp;彻底晒干的羽衣甘蓝可以用手搓成粉末保存。每次往汤或粥里加一勺，体积很小却能补充营养。也可以像干菜那样用水泡开后凉拌或炒食。

### 15-3. 盐渍与发酵

| 方法 | 盐浓度 | 期间 | 特点 |
|---|:---:|---|---|
| 咸菜式腌渍 | 盐10-15% | 数月 | 保存期长，但食用前需用水浸泡去盐 |
| 乳酸发酵(泡菜式) | 盐2-3% | 数周至数月 | 维生素C保留较多 |

&nbsp;&nbsp;&nbsp;冬季维生素C的第二条来源是乳酸发酵。就像用大白菜腌泡菜一样，羽衣甘蓝也可以腌制。把叶片切成粗条，用相当于重量2-3%的盐腌制，等叶片变软后压实装罐，让汁水没过原料。在隔绝空气的状态下，乳酸菌会繁殖产酸，这种酸能抑制杂菌。

> **盐渍和水煮的储藏方式会流失大部分维生素C，而乳酸发酵能保留相当一部分。这正是历史上在冬季没有新鲜蔬果时，发酵食品能够预防坏血病的原因。**

&nbsp;&nbsp;&nbsp;德国酸菜与韩式泡菜原理相同，寒冬漫长的地区会发展出这类食物并非偶然。羽衣甘蓝叶片比结球甘蓝更厚实，发酵速度稍慢，但只要切得细一些、充分揉搓就没问题。诀窍是装入坛子或玻璃瓶后，用石头或装水的袋子压住，使原料没入汤汁之下。表面浮起白色的酵膜就撇去，如果闻到的不是酸爽的气味而是腐臭味，就要丢弃。

## 16. 烹饪与加工

| 方法 | 燃料 | 维生素C保存 | 备注 |
|---|:---:|:---:|---|
| 生食(包菜·沙拉) | 无 | 最多 | 最有效率。要去掉粗硬的叶脉 |
| 焯水30秒-1分钟 | 极少 | 一半以上 | 致甲状腺肿素减少，体积大幅缩小 |
| 加入汤·粥 | 与其他烹饪合并 | 连汤喝则可保存 | 不额外耗费燃料的方法 |
| 炒 | 少量 | 中等 | 脂溶性维生素A和K的吸收会更好 |
| 发酵 | 无 | 保留相当量 | 兼具储藏与烹饪的作用 |
| 晒干磨粉 | 干燥时靠日晒·风 | 几乎不剩 | 矿物质和维生素A得以保留 |

&nbsp;&nbsp;&nbsp;在燃料紧缺的情况下，羽衣甘蓝最大的优点是不煮也能吃。与大豆需要浸泡八小时、再煮一小时相比，差距很大。不过如前所述，由于致甲状腺肿素的缘故，完全只吃生的并不值得推荐；把它最后丢进已经在煮其他食物的锅里，是一种不额外耗费燃料就能获得熟食形态的办法。

&nbsp;&nbsp;&nbsp;哪怕只有一点油，搭配炒制在营养上也更有利。羽衣甘蓝所含的维生素A(β-胡萝卜素)、维生素K和叶黄素都是脂溶性的，需要有油脂才能被吸收。没有油脂的话，这些成分进入人体的比例会大幅下降。将紫苏籽或芝麻磨碎加入，或加进用豆子磨成的汤中，也能达到同样的效果。

&nbsp;&nbsp;&nbsp;粗硬的主叶脉通常会被摘除，但并不需要丢弃。切碎后放进汤或粥里长时间熬煮就会变软，膳食纤维和矿物质原样保留。粗茎同样可以去皮切段煮熟后食用。

## 17. 全年作业日程

| 月 | 作业 |
|---|---|
| 1月 | 采收越冬叶。检查防风屏障和覆盖物状态 |
| 2月 | 采收越冬叶。准备春播，翻堆肥 |
| 3月 | 下旬春播。留种株开始抽薹，立支架 |
| 4月 | 管理春播育苗。留种株开花，做好隔离。采收花薹 |
| 5月 | 定植春季苗。开始监测菜粉蝶。设防虫网 |
| 6月 | 春季羽衣甘蓝初次收获。留种株结荚。害虫高峰期 |
| 7月 | 上旬留种。高温期管理(覆盖、灌溉)。开始秋播 |
| 8月 | 继续秋播。管理育苗。清理春季植株 |
| 9月 | 定植秋季苗。害虫第二次高峰期。追肥 |
| 10月 | 开始采收秋季羽衣甘蓝。越冬准备(培土) |
