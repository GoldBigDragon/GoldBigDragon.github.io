## 8. 栽培管理

### 8-1. 間引きと土寄せ

| 作業 | 時期 | 内容 |
|---|---|---|
| 1回目の間引き | 本葉2-3枚 | 株間を10cmに縮めます |
| 2回目の間引き | 本葉4-5枚 | 最終間隔30-40cm |
| 1回目の土寄せ | 定植後3-4週間 | 茎の根元に土を5cm盛ります |
| 2回目の土寄せ | 株が大きくなった後 | 必要なら一度追加で盛ります |
| 下葉の整理 | 随時 | 黄変した葉や病気の葉を取り除きます |

&nbsp;&nbsp;&nbsp;土寄せはケールで特に重要です。葉を摘み続けて上がっていくと茎が長くなり、上の方にしか葉が残らず重心が高くなります。風が吹くと倒れ、倒れた株は茎が折れてそのまま終わってしまいます。根元に土を盛ると、そこから不定根が出て株を支えます。竹や太い木の枝を挿して茎を結びつけるのも同じ目的です。冬に雪が積もる地域では、この作業が越冬の成功率を大きく左右します。

&nbsp;&nbsp;&nbsp;黄変した下葉を放っておかないことも重要です。老いた葉はほとんど光合成をせずに養分だけを消費し、湿った天気ではカビが始まる場所になります。取り除いた葉は畑の外に持ち出して堆肥の山に入れます。病気の葉であれば堆肥にも入れず、燃やすか遠くに埋めます。

### 8-2. 雑草管理

&nbsp;&nbsp;&nbsp;除草剤がない状況では、雑草管理はタイミングがすべてです。定植後4-6週間が決定的な期間です。この期間に雑草がケールより大きくなると、光と養分を奪われて回復が難しくなります。反対にこの時期を越えてケールの葉が地面を覆うようになれば、その陰が自然と雑草を抑えます。

| 時期 | 方法 |
|---|---|
| 定植直後 | マルチングで先に押さえておきます |
| 定植後2-6週間 | 2週間おきに鍬で浅く引っかきます |
| それ以降 | 大きな雑草だけ抜きます |

&nbsp;&nbsp;&nbsp;鍬入れは浅く行います。深く掘るとケールの細根が切れ、土の中に埋まっていた雑草の種が表面に上がって新たに発芽します。表面2-3cmだけをかいて出たての雑草の根を切るだけで十分です。日当たりの良い日の朝に行えば、切られた雑草はその日のうちに乾いて枯れます。

### 8-3. 越冬管理

| 方法 | 材料 | 効果 |
|---|---|---|
| 根元の土寄せ | 土 | 根と生長点付近を保護します |
| 藁掛け | 稲藁、乾草 | 地温の低下を遅らせます |
| 落ち葉掛け | どんぐりの木の落ち葉 | 藁と同じ効果があり、春にそのまま肥料になります |
| 風よけ | ソルガムの茎、トウモロコシの茎、ヨシのすだれ | 北西風を防ぎます。冷害の多くは風から来ます |
| トンネル掛け | 不織布、ビニール(あれば) | 韓国南部ではなくても構わず、中北部では収穫期間が延びます |

> **ケールの冬の被害は気温よりも風から来ます。マイナス10℃の無風よりマイナス5℃の強風で葉のほうが傷みます。風を防ぐことは覆うことより先です。**

&nbsp;&nbsp;&nbsp;冷たい風が葉の水分を奪う一方で、地面が凍って根が水を吸い上げられなくなると、葉が乾いて褐変します。冬の乾燥害と呼ばれる現象です。ソルガムやトウモロコシの茎を立ててすだれのように編み、北西側に立てるとこの被害が大きく減り、その材料は夏作物の副産物なので別に用意する必要がありません。

## 9. 病害虫 - 薬を使わずに防ぐ方法

### 9-1. 主な害虫

| 害虫 | 被害の様子 | 発生時期 | 薬を使わずに防ぐ方法 |
|---|---|---|---|
| モンシロチョウの幼虫 | 緑色の幼虫が葉脈だけを残して食べます | 4-6月、9-10月 | 手による捕殺、防虫網、葉の裏の黄色い卵をこすり落とす |
| コナガ | 小さな幼虫が葉の裏を食べて薄い膜を残します | 5-10月 | 防虫網、木酢液の希釈液、頻繁な見回り |
| ノミハムシ | 小さな黒い虫が葉に粟粒大の穴を開けます | 4-6月 | 幼苗期の防虫網、灰まき、畝への藁掛け |
| アブラムシ | 葉の裏と新芽に群がって汁を吸います。葉が縮れます | 4-6月、9-10月 | 石けん水、水流で洗い流す、テントウムシの保護 |
| ハイマダラノメイガ | 心部と新芽に食い込みます | 夏-秋 | 防虫網、発生株の除去 |
| ナメクジ | 夜に葉に不規則な穴を開けます | 梅雨時(韓国では6月下旬〜7月) | 夜間の手による捕殺、灰や籾殻で株周りに帯を作る |
| アザミウマ | 葉に銀白色の傷が生じます | 高温乾燥期 | 灌水で湿度を保つ、雑草の除去 |

### 9-2. なぜ手による捕殺が効果的か

&nbsp;&nbsp;&nbsp;モンシロチョウの幼虫は大きくて動きが遅いです。葉脈に沿って付いていて葉の色に似ているため目につきにくいですが、葉にできた穴をたどればたいていその近くにいます。早朝や夕暮れに葉の裏を見て回って捕まえれば、1日数分でかなりの個体数を減らせます。ケール十株から二十株規模の家庭菜園では、この方法だけで防除になります。無防除時の減収率51.7%という数値は何もしなかった場合の値であり、毎日手で捕まえる畑ではこの数字が大きく下がります。

&nbsp;&nbsp;&nbsp;さらに効率的なのは卵の段階で防ぐことです。モンシロチョウは葉の裏に細長い黄色の卵を一つずつ付けます。白い蝶が畑の上を飛んでいるのを見た翌日に葉の裏を調べればこの卵を見つけられ、指でこすって取り除けば幼虫一匹を事前に消せます。卵一つを消す作業は幼虫一匹を捕まえるよりずっと簡単で、被害もまだ発生していません。

### 9-3. 防虫網と物理的な遮断

&nbsp;&nbsp;&nbsp;チョウやガを防ぐ最も確実な方法は、卵を産ませないことです。目の大きさが1mm前後の防虫網を支柱にかぶせて畑全体を覆い、縁を土で押さえて塞げば、モンシロチョウとコナガの産卵が遮断されます。文献に記録された有機栽培の実証でも、防虫網の被覆が最も確実な効果を持つ手段として挙げられています。

&nbsp;&nbsp;&nbsp;防虫網がない状況では、代わりのものを考える必要があります。目の細かい蚊帳、古いカーテン、薄い布、古い防虫網もすべて使えます。通風が悪くなるとカビの病気が増えるため、完全に密閉せず日中は一方を開ける形で調節します。網をかぶせる前にすでに卵や幼虫がいると、内側に閉じ込めて育てる格好になるので、かぶせる前に必ず葉を確認します。

&nbsp;&nbsp;&nbsp;ノミハムシには別の対応が必要です。この虫は土の中から出てきて跳びながら移動し、特に幼苗を好みます。畑の表面に藁や乾草を敷くと虫が土から上がってくる道がふさがれ、葉に乾いた灰を薄くまくと葉の表面がざらついて食べるのを嫌がります。灰は雨が降ると洗い流されるので、雨の後に再びまきます。

### 9-4. 天然の防除剤

| 防除剤 | 作り方 | 対象 | 注意 |
|---|---|---|---|
| 石けん水 | 無香料の石けん20gを水1Lに溶かします | アブラムシ、ハダニ、アザミウマ | 日中に撒くと葉が傷みます。夕方に撒き翌朝水で洗い流します |
| ニンニク・トウガラシ水 | ニンニク100gと乾燥トウガラシを水1Lでミキサーにかけ、1日置いて濾します | 忌避剤。アブラムシ、成虫のガ | 予防用であり、すでに付いた害虫は殺せません |
| 木酢液 | 500-1,000倍に希釈します | 忌避剤全般 | 濃いと葉が傷みます |
| 草木灰 | ふるって葉と土に薄くまきます | ノミハムシ、ナメクジ | アルカリ性なので過剰だと土壌の酸度が偏ります |
| 牛乳希釈液 | 牛乳と水を1対5で混ぜます | アブラムシ、うどんこ病 | 入手できる場合のみ該当します |

&nbsp;&nbsp;&nbsp;石けん水がアブラムシに効く仕組みは毒性ではなく物理的な作用です。石けんがアブラムシの気門と体を覆うワックス層を溶かして窒息させます。そのため液が虫の体に直接触れてこそ効果があり、撒いた後乾けばそれで終わりです。葉の裏に群がっているアブラムシを狙って下から上に向けて撒くのがコツです。ケールの葉のワックス層のせいで石けん水が流れ落ちやすいので、石けんの濃度を少し上げるか、二、三回に分けて撒きます。

### 9-5. 主な病害

| 病害 | 症状 | 条件 | 対応 |
|---|---|---|---|
| 根こぶ病 | 根にこぶができ、日中に萎れます | 酸性土壌、過湿 | 治療不可。pH 6.5以上を維持、排水、7年以上の輪作 |
| べと病 | 葉に黄色い斑点、裏に灰白色のカビ | 涼しくて湿っている時 | 通風、株間を広げる、病葉の除去 |
| 菌核病 | 根元が軟化し白い菌糸と黒い菌核 | 低温多湿 | 排水、罹病株の除去、輪作 |
| 黒腐病 | 葉の縁からV字状に黄変します | 高温多湿 | 種子の温湯消毒、病株の除去 |
| 軟腐病 | 組織が軟化し悪臭がします | 高温多湿、傷 | 傷をつけない、排水 |
| うどんこ病 | 葉が白い粉で覆われます | 乾燥して涼しい時 | 通風、牛乳希釈液 |

> **根こぶ病は薬で治せず、土の中で7年以上生き続けます。アブラナ科の作物を植える畑は、酸度と排水と輪作の三つで前もって防ぐしかありません。**

&nbsp;&nbsp;&nbsp;根こぶ病が入り込んだ畑かどうかを確認する方法は簡単です。育つ途中で萎れた株を抜いて根を見ます。棍棒やこぶのように膨らんだ塊がついていれば根こぶ病です。その畑には最低5年、できれば7年間アブラナ科の作物を植えません。ケール、キャベツ、ハクサイ、ダイコン、カラシナ、ナタネ、ブロッコリーがすべて該当します。病気の株はその場に置いたり堆肥に入れたりせず、燃やすか畑から遠く離れた場所に深く埋めます。こぶの中に入っている休眠胞子が土に散らばることが伝播の経路です。

### 9-6. 耕種的防除の原則

| 原則 | 内容 |
|---|---|
| 播種期の調整 | 害虫発生の最盛期を避けて植えます。モンシロチョウは5-6月と9月に最も多いです |
| 輪作 | アブラナ科を続けて植えません。最低2年、根こぶ病があれば7年 |
| 株間の確保 | 30-40cmを守ります。狭いと通風が悪くなりカビの病気が増えます |
| 残渣の除去 | 収穫が終わった株や病気の葉を畑に残しません |
| 混植 | ディル、コリアンダー、ニンジンの花などセリ科の花が寄生バチやハナアブを呼び、アブラムシを減らします |
| 天敵の保護 | テントウムシ、クサカゲロウ、クモを殺しません。広範囲な薬剤散布を避ける理由です |

&nbsp;&nbsp;&nbsp;天敵の保護は長期の災害で特に重要です。テントウムシ1匹が1日にアブラムシ数十匹を食べます。寄生バチはモンシロチョウの幼虫の体に卵を産み、内側から殺します。この関係が定着した畑では、害虫の密度が自然と抑えられます。反対に薬を広く撒くと、繁殖の遅い天敵が先に消え、繁殖の速い害虫だけが戻ってきて、翌年にはより大きな問題になります。薬がない状況は制約でありながら、同時にこの均衡を取り戻す条件でもあります。

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 天然素材での対応 |
|---|---|---|
| 下葉から全体が黄色くなり株が小さい | 窒素欠乏 | 尿の8-10倍希釈液、完熟堆肥、草の液肥 |
| 葉の縁が茶色く焼けたようになる | カリウム欠乏 | 草木灰を株の周りに撒きます |
| 葉が濃い青緑色で生長しない | リン酸欠乏 | 骨粉、草木灰 |
| 新しい葉が奇形で生長点が枯れる | ホウ素欠乏 | 完熟堆肥で有機物を補います。灰を過剰に与えた畑で多く見られます |
| 新しい葉の葉脈の間が黄色く葉脈は緑 | 鉄またはマグネシウム欠乏 | pHが高すぎないか確認します。灰の使用を減らします |
| 葉が薄く大きく軟らかく害虫が群がる | 窒素過剰 | 窒素の供給を止めます。病害にも弱くなります |
| 葉に白い斑点が生じ生育が止まる | 塩類過剰 | 灌水量を増やして洗い流します。尿の濃度を下げます |

&nbsp;&nbsp;&nbsp;欠乏症状が古い葉から始まるか新しい葉から始まるかが、診断の最初の分かれ道です。窒素、リン酸、カリウム、マグネシウムは植物の中を移動できる元素なので、不足すると古い葉から抜き取って新しい葉に送ります。そのため症状は下の葉に先に現れます。反対にカルシウム、ホウ素、鉄は一度定着すると移動できないため、新しい葉に先に症状が出ます。下の葉が黄色ければ窒素、新しい葉が奇形ならホウ素やカルシウムのほうをまず疑います。

&nbsp;&nbsp;&nbsp;灰を過剰に使った畑ではホウ素と鉄の欠乏がよく出ます。灰はアルカリ性で土壌の酸度(pH)を上げますが、pHが7.5を超えるとホウ素と鉄とマンガンが土の中で水に溶けない形に固まり、根が吸収できなくなります。土にその元素がないのではなく、あっても摂れない状態です。この場合は灰をさらに入れるのではなく中止し、完熟堆肥で有機物を補ってゆっくりと戻します。

## 11. 間作と輪作

| 相性 | 対象 | 効果 |
|:---:|---|---|
| 良い | マメ科(エンドウ、インゲンマメ) | 窒素を固定してケールが使う窒素を残します |
| 良い | 長ネギ、タマネギ、ニンニク | 匂いがチョウとアブラムシを混乱させます |
| 良い | ディル、コリアンダー、ニンジンの花 | 寄生バチとハナアブを呼んでアブラムシを減らします |
| 良い | ジャガイモ、ビート | 根の深さが異なり養分の競合が少ないです |
| 普通 | サンチュ、ホウレンソウ | 地面を覆って雑草を抑えます |
| 悪い | ハクサイ、ダイコン、カラシナ、ブロッコリーなどアブラナ科 | 病害虫を共有して蓄積します |
| 悪い | イチゴ | 互いに生育を妨げます |

&nbsp;&nbsp;&nbsp;輪作の順序の原理は、同じ科を続けて植えないことと、養分を多く消費する作物の後に養分を作る作物を置くことです。ケールは多肥性で畑の窒素を大きく持ち出すので、その次にマメ科を置きます。

```
ケール(アブラナ科、多肥) → エンドウ・インゲンマメ(マメ科、窒素回復) → ジャガイモ・サツマイモ(ナス科・ヒルガオ科) →
長ネギ・タマネギ(ユリ科) → 再びケール
```

&nbsp;&nbsp;&nbsp;この順序で回すと、同じ場所にケールが戻ってくるまで4年かかります。根こぶ病が確認された畑であれば、この周期を7年以上に延ばす必要があり、その間は絶対にアブラナ科を入れてはいけません。ダイコンやカラシナをアブラナ科だからという理由で1サイクルに入れないことが要点です。

&nbsp;&nbsp;&nbsp;間作でマメ科と組み合わせる方法は特に価値が大きいです。ケールの畝の間の溝にエンドウやインゲンマメを植えると、豆の根の根粒が作った窒素の一部が根からの分泌物や落ちた葉を通じて土に還ります。豆を収穫した後に茎と葉をその場所にすき込むと効果がさらに大きくなります。化学肥料がない条件では、この組み合わせは畑の中で窒素を作る数少ない方法です。
