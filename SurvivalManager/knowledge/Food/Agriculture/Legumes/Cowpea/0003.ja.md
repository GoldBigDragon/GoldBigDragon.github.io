## 3. 栽培環境

### 3-1. 気温と日照量

| 条件 | 限界値 | 最適値 | 外れた場合 |
|---|---|---|---|
| 発芽温度 | 12-15℃以上 | 25-30℃ | 10℃以下では発芽しません |
| 生育温度 | 15-40℃ | 20-35℃ | 豆類の中で高温に最も強いです |
| 結実温度 | 20-32℃ | 24-30℃ | 幅12℃で豆類の中では広い方です |
| 耐寒性 | ありません | - | 一度の霜で枯れます |
| 日照 | 1日6時間以上 | 1日8時間以上 | 40%遮光で収量が半分に落ちます |
| 降水量 | 年400mmでも生育 | 400-700mm | 水が溜まる方が干ばつより危険です |

> **ササゲは暑さで枯れることのない数少ない作物です。35℃が続き他の豆の花が次々と落ちてしまう夏でも、ササゲは毎朝新しい花を咲かせます。猛暑が増えるほどササゲの相対的な位置は上がります。**

&nbsp;&nbsp;&nbsp;この高温適応力のおかげで、ササゲは真夏の播種が可能です。韓国中部では6月下旬から7月上旬、韓国南部では6月中旬から7月中旬が適期で、韓国全羅南道での試験では7月25日播種が最も高い収量を出した記録もあります。播種の限界は霜が決めます。初霜予想日から90日を逆算すると、その地域の限界日が出ます。

&nbsp;&nbsp;&nbsp;遅く植えられるという点が実務上大きな価値を持ちます。大麦やニンニクやジャガイモを収穫した6月の空いた畑、あるいは韓国の梅雨（チャンマ、6月下旬~7月）で倒れた作物をすき込んだ7月の畑にササゲを植えることができます。リョクトウとともに、ササゲは失敗を立て直す作物です。

### 3-2. 土壌と水

| 条件 | 限界値 | 最適値 | 備考 |
|---|---|---|---|
| 土性 | 砂地から粘質土まで | 水はけの良い砂質土-砂壌土 | 豆類の中で最も適応範囲が広いです |
| pH | 4.5-8.0 | 5.5-7.0 | 強酸性にも耐えます。豆類の中で最も広いです |
| 有効土層 | 30cm以上 | 50cm以上 | 主根が深く入ります |
| 作期蒸発散量 | - | 約250mm | 豆類の中で最も少ない部類です |
| 冠水 | 1日以上浸かると枯れます | - | 豆類の中で湿害に最も弱い部類です |
| 耐塩性 | 低い | - | 塩分のある土地には向きません |
| 畝の高さ | 20cm以上 | 25cm | 湿害防止の要です |

&nbsp;&nbsp;&nbsp;pH4.5まで耐えるという点がササゲのはっきりした利点です。韓国の畑は降雨が多く総じて酸性に傾いており、石灰を入手しにくい条件下ではこれが実質的な差を生みます。エンドウがpH6.0を下回ると崩れ、ダイズが5.5で根粒を失うのに対し、ササゲはそれより低い土壌でも育ちます。何年も作り続けて酸性に傾いた畑、石灰を入れられなかった畑に植えられる数少ない豆です。

> **干ばつに最も強いササゲが、冠水には最も弱いのです。偶然ではありません。乾いたサバンナに適応した根の構造は、水が溜まって酸素のない土に耐えられません。ササゲ畑では畝と排水路は選択肢ではなく前提条件です。**

&nbsp;&nbsp;&nbsp;韓国ではササゲの生育期間がちょうど梅雨と重なります。これがササゲ栽培最大の難点であり、対応は物理的なものです。畝を20cm以上高くし、排水路を深く掘り、梅雨前に水がきちんと抜けるか確認します。畑を選ぶ段階から水が溜まらない場所、傾斜があるなら上側をササゲに割り当てます。

## 4. 品種

### 4-1. 生育形態による分類

| 区分 | 草丈 | 支柱 | 特徴 |
|---|---|---|---|
| 直立型 | 50-80cm | 不要 | 倒伏に強く収穫が楽です |
| 半直立型 | 80-120cm | 大抵不要 | 収量が高く手間が少ないです |
| つる性 | 2-3m | 必要 | 収穫期間は長いですが支柱が要ります |

&nbsp;&nbsp;&nbsp;韓国国内で育成されたササゲ品種としては、チョンナム1号とチョンナム2号が半直立型、オクタンとソニョンが直立型として知られています。直立型は倒伏に強く管理が楽で、半直立型は収量がやや高めです。試験ではチョンナム2号が1,000㎡当たり221kgから224kg、ソニョンが226kg程度の収量を出した記録があります。

&nbsp;&nbsp;&nbsp;災害時には直立型か半直立型が合理的です。支柱が不要で、倒伏しないため収穫の労力が少なく、葉を摘んで食べるのにも便利です。つる性は支柱を立てる資材と労力があるときにのみ検討します。

### 4-2. 状況別の選択基準

| 状況 | 優先順位 | 理由 |
|---|---|---|
| 支柱資材がない | 直立型・半直立型 | 支柱なしで立ちます |
| 畑が痩せていて乾いている | どの系統でもササゲ | この条件でササゲに代わる豆はありません |
| 葉を野菜として使いたい | 葉が多い半直立型 | 葉を摘んでも次々と出てきます |
| 霜が早い地域 | 早生直立型 | 80日で終えられます |
| 畑を良くしたい | どの系統でも、緑肥として | 開花期にすき込めば窒素が残ります |
| 種子が不足している | 直立型 | 植栽密度が決まっていて計算しやすいです |

&nbsp;&nbsp;&nbsp;品種選びの第一の基準は自家採種の可能性です。ササゲはほとんどの栽培系統が固定種で自家受粉のため、採った種をそのまま蒔くことができます。韓国国内での普及度がBで種子を再び入手するのは容易ではないため、確保した系統をつないでいくのが原則です。地域の在来種があれば、それはその土地の条件にすでに適応している可能性が高いです。

## 5. 畑の準備と肥料 - 根粒菌

### 5-1. 窒素固定はどのように起こるか

&nbsp;&nbsp;&nbsp;空気の78%は窒素です。人の頭上に無限の窒素が漂っているのに、植物はそれを使うことができません。空気中の窒素は窒素原子二つが三重結合で固く結びついた分子であり、この結合を切るには莫大なエネルギーが必要だからです。工業的にこの結合を切ってアンモニアを作るのがハーバー・ボッシュ法で、世界の窒素肥料はそこから生まれます。高温と高圧と触媒と大量の化石燃料が必要です。

&nbsp;&nbsp;&nbsp;根粒菌はこの仕事を常温常圧でやってのけます。ニトロゲナーゼという酵素で三重結合を切り、窒素をアンモニアに変えます。ただし代償があります。この反応には多くのエネルギーが必要で、細菌自身は光合成ができません。そこでマメ科植物の根に入り込んで暮らし、植物が光合成で作った糖を受け取り、その見返りに固定した窒素を渡します。取引関係です。

&nbsp;&nbsp;&nbsp;ササゲと組む菌はBradyrhizobiumの仲間です。アズキやリョクトウが使う菌と通じており、この菌は酸性土壌でも比較的よく耐えます。ササゲがpH4.5まで耐えられる理由の一つが、この共生菌の耐酸性です。実用的には、アズキやリョクトウやササゲを育てた畑の土が接種源になります。

| 段階 | 起こること |
|---|---|
| 1. 信号交換 | ササゲの根がフラボノイドを分泌し、土中の細菌がその信号に応えてNodファクターを放出します |
| 2. 感染 | 根毛が内側に曲がって細菌を包み込み、細菌が感染糸をたどって根の中へ入ります |
| 3. 根粒形成 | 根の内部の細胞が分裂して根粒が膨らみ、その中に細菌が住み着きます |
| 4. 窒素固定 | 根粒の中でニトロゲナーゼが働き、空気中の窒素をアンモニアに変えます |
| 5. 分配 | アンモニアがアミノ酸に変わり、茎や葉や莢へ運ばれます |
| 6. 老化 | 登熟期に入ると根粒は機能を失い、根とともに土に還ります |

&nbsp;&nbsp;&nbsp;ニトロゲナーゼは酸素に非常に弱く、酸素に触れるとたちまち機能を失います。そのため根粒の内部にはレグヘモグロビンという赤い色素タンパク質が満ちていて酸素を捕まえておき、酵素周辺の酸素濃度を極めて低く保ちます。人の血が赤いのと同じ原理で、根粒を割ったときに内側が赤や桃色をしているのはこの色素のためです。この事実は実用上たいへん重要です。赤い色は、その根粒が今まさに窒素を固定しているという目に見える証拠だからです。

&nbsp;&nbsp;&nbsp;ササゲはマメ科の中でも窒素固定能力が高い方に属します。痩せた土壌で生き残るために発達した性質で、条件が良ければ1ヘクタール当たり100kg前後を固定します。施肥等級SSと緑肥兼用という評価はここから来ています。

### 5-2. 根粒ができているかの確認方法

&nbsp;&nbsp;&nbsp;接種をしたかどうかにかかわらず、根粒が実際にできているかを確認することは必ず行うべきです。確認しなければ窒素不足の原因が分からず、翌年同じ失敗を繰り返すことになります。

| 順序 | 内容 |
|---|---|
| 1 | 開花が始まる頃、播種後6週間くらいが最も良い時期です |
| 2 | 健康そうな株を二、三株選びます |
| 3 | 引き抜かず、スコップで株の周りを広く掘り、土ごと持ち上げます |
| 4 | 水を張った桶に入れ、土をそっと洗い流します |
| 5 | 主根と太い側根に付いた根粒の数を数えます |
| 6 | 根粒をいくつか爪で割って中の色を見ます |

| 観察結果 | 意味 | 対応 |
|---|---|---|
| 根粒が1株あたり20個以上付いている | 接種がうまくいっています | そのままにします |
| 割った内側が赤や桃色 | 窒素を固定しています | 良い状態です |
| 割った内側が白色や薄緑色 | 根粒はできていますが固定していません | 湿害とリン酸欠乏を確認します |
| 割った内側が茶色や黒色 | すでに老化したか死んでいます | 梅雨明け後なら湿害で死んだ可能性が高いです |
| 根粒が5個以下 | 接種が失敗しています | 葉が黄色ければ少量の窒素を補います |

> **根を掘り出して根粒を割り、赤色を確認するこの一つの習慣こそが、窒素肥料のない世界で豆作りの成否を教えてくれる最も確実な合図です。**

&nbsp;&nbsp;&nbsp;ササゲでは梅雨の前後に二回確認するのがよいです。梅雨前に赤かった根粒が梅雨後に黒く死んでいたら、湿害が原因です。根粒菌は好気性細菌なので、水に浸かると根より先に死んでしまいます。この場合は排水路を整え、葉が黄色ければ薄めた尿をごく少量与えて残りの期間をしのがせます。

### 5-3. 接種源はどこで手に入れるか

&nbsp;&nbsp;&nbsp;市販の接種剤は、生きた細菌を泥炭や粘土に入れて売る製品です。災害時には入手できません。しかしササゲが使う菌はアズキやリョクトウも共通して使うありふれた菌なので、接種源を得るのは比較的簡単です。

| 方法 | 手順 | 効果 | 注意 |
|---|---|---|---|
| アズキ・リョクトウ・ササゲを育てた畑の土をまぶす | 前年これらを植えて根粒がよくできていた畑から、表土5-15cmの深さの土をすくってきます。種子を水で軽く湿らせてこの土をまぶし、すぐに植えます | 最も確実で費用がかかりません | 病気の畑の土は病原菌も一緒に運びます |
| 根粒そのものを使う | 掘り上げた根の根粒を集めてすりつぶし水に溶かし、その水に種子を浸してから引き上げます | 菌密度が最も高いです | 根粒を掘り出したその日のうちに使う必要があります |
| 土を畑にまく | 播種する畝に運んできた土をまき、一緒にすき込みます | 菌が土に広がります | 10㎡当たりスコップ一杯程度が目安です |
| 根の残渣を残す | 収穫時に茎だけを刈り、根は畑に残します | 翌年まで菌が土に残ります | 最も手間のかからない維持方法です |
| 野生アズキの根 | 野原や畦畔の野生アズキの根から根粒を採取します | 同じ属なので菌が通じます | 固定効率は栽培種の系統より低いことがあります |

&nbsp;&nbsp;&nbsp;接種の際に必ず守るべきことがあります。根粒菌は直射日光と乾燥と熱に非常に弱く、紫外線を数分浴びるとかなりの数が死に、乾燥すればさらに早く死にます。種子に土をまぶす作業は日陰で行い、まぶした種子は日に当てずにすぐ植えます。30分以内に植えるのが望ましく、遅くとも数時間以内に終えます。ササゲは真夏に植える作物なので、この点が特に重要です。強い日差しで熱せられた土の表面は60℃を超えることがあり、種子にまぶした菌がたちまち死んでしまいます。早朝か夕方に植えます。

| 接種失敗を招く条件 | 理由 |
|---|---|
| 水が溜まる畑 | 好気性細菌なので酸素がないと死にます。ササゲで最もよくある失敗の原因です |
| 窒素肥料を十分に与えた畑 | 植物が取引の必要を感じず、根粒形成を自ら減らします |
| リン酸が不足する畑 | 窒素固定には多くのエネルギーが必要で、その代謝にリン酸が使われます。痩せ地では特に重要です |
| モリブデン・鉄・コバルトの欠乏 | ニトロゲナーゼの構成成分です |
| 真夏の強い日差しの下での播種 | 土の表面が熱くなり、種子にまぶした菌が死にます |
| 接種した種子を日に干す | 紫外線と乾燥で菌が死にます |
| ダイズやエンドウの畑の土を使う | 菌の系統が異なり効率が落ちます |
