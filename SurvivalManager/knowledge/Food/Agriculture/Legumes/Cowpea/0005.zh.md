## 8. 栽培管理

### 8-1. 头5周决定一切

| 时期 | 作业 | 要点 |
|---|---|---|
| 播种到出苗后2周 | 第一次除草 | 趁杂草小时拔除 |
| 出苗后4-5周 | 第二次除草 | 兼作培土 |
| 开花前 | 完成全部除草 | 开花后除草会降低产量 |
| 真叶2-3片 | 间苗 | 每穴只留最健壮的1株 |

> **豇豆是种下后即便放任不管也能有所收获的作物，但这不意味着可以什么都不做。头5周的除草管理，这一件事必须做到。**

&nbsp;&nbsp;&nbsp;豇豆初期生长缓慢，这是因为它在地上部分长起来之前会先向下深扎根系。这段时间里如果杂草先占据地盘，豇豆就会被压制而无法恢复。反之，一旦过了这5周、叶片开始覆盖地面，之后就不再与杂草竞争。半直立型和蔓生型的叶片会大范围铺开，自行把地面盖住。

&nbsp;&nbsp;&nbsp;除草要浅。豇豆的须根分布在表层，锄头插得太深会把根切断。应把锄头放平，只刮去地表2cm左右来除草，靠近植株的地方要用手拔。播种后薄薄铺一层稻草或稻壳，可以减少除草的次数。

### 8-2. 采叶与摘心

| 作业 | 时期 | 要点 |
|---|---|---|
| 采嫩叶 | 长出数片真叶后到开花前 | 挑选下部成熟的叶片采摘 |
| 摘心 | 蔓生型长到支架顶端时 | 侧枝会增多，摘下的嫩梢可做凉拌菜 |
| 采摘上限 | 单株不超过全部叶片的三分之一 | 采摘过多会降低籽实产量 |
| 停止时机 | 开花开始后 | 此后叶片要用于充实豆荚 |

&nbsp;&nbsp;&nbsp;能采叶食用是豇豆独有的优点，但需要把握好平衡。叶片是光合作用的工厂，采摘过多会降低籽实产量。经验上的标准是单株不超过全部叶片的三分之一，且一旦开花就停止采摘。开花以后的叶片要用来制造充实豆荚所需的养分。

&nbsp;&nbsp;&nbsp;采摘的方法也有讲究。不要摘最上面的嫩梢，而要挑选下方已经长成的叶片，连叶柄一起摘下。不碰生长点，植株才能持续生长。摘下的叶片当天焯烫食用，若量多则焯烫后晒干留到冬天使用。这部分内容将在第16节详细说明。

### 8-3. 倒伏管理

| 原因 | 应对 |
|---|---|
| 氮肥过多 | 遵守施肥量。豇豆几乎不需要氮肥 |
| 密植 | 遵守每1,000㎡ 15,000株的密度 |
| 蔓生型品种 | 搭支架，或改用直立型品种 |
| 风雨 | 在田地四周拉一圈及膝高的绳子固定 |
| 未培土 | 在第二次除草时给根部培土 |

&nbsp;&nbsp;&nbsp;直立型和半直立型豇豆不需要支架，因为茎秆挺直坚韧，能够自立。只有蔓生型会长到2-3m，需要支架，而在灾难条件下，特意选择蔓生型的理由并不充分。节省搭支架的材料和人力，总体上更为合理。

## 9. 病虫害

&nbsp;&nbsp;&nbsp;豇豆的防治自立度为S，在这份作物表中也是屈指可数的高分，意味着即使完全没有农药，仅靠耕作措施也能应对。不过有两种害虫需要留意：田间的豆荚野螟，以及贮藏期间的绿豆象。

### 9-1. 主要病害

| 病名 | 症状 | 发生条件 | 无农药应对方法 |
|---|---|---|---|
| 枯萎病·根腐病 | 植株萎蔫死亡，茎基部变褐软化 | 过湿、连作 | 排水与起高垄几乎是唯一对策 |
| 白粉病 | 叶片表面覆盖白色粉状物 | 干燥且昼夜温差大时 | 保证通风，喷施5-10倍稀释牛奶 |
| 锈病 | 叶片上出现橙色粉状孢子堆 | 生育后期湿度大 | 摘除病叶，保证通风 |
| 花叶病毒病 | 叶片出现斑驳、卷缩，生长停滞 | 由蚜虫传播 | 无法治愈，应拔除烧毁并减少蚜虫 |
| 细菌性叶枯病 | 叶片上出现有棱角的褐色斑点 | 随风雨传播扩散 | 雨后不要进入田地 |

&nbsp;&nbsp;&nbsp;豇豆病害大多与水有关。枯萎病和根腐病最常见、造成损失也最大，二者都源于过湿。把垄做高20cm以上、切实挖好排水沟，这一项措施就占了豇豆病害管理的一半。有时候，用铲子挪土比配药、喷药更有效。

### 9-2. 主要害虫

| 害虫 | 危害 | 无农药防治 |
|---|---|---|
| 豆荚野螟 | 幼虫钻入花及嫩荚内取食籽粒，是田间最大的害虫 | 从开花期起每天早晨检查花和嫩荚，捕捉幼虫；受害豆荚应摘除处理 |
| 绿豆象 | 在田间产卵于豆荚中，贮藏期间蛀食籽粒，半年内可使全部籽实受害 | 适时收获，充分干燥后密封保存，参见第15节 |
| 蝽象类 | 刺吸豆荚汁液，导致籽粒瘪瘦 | 在清晨露水未干时用手捕捉 |
| 蚜虫 | 刺吸汁液并传播病毒 | 喷施肥皂水（1L水加5g肥皂）、用强力水流冲洗 |
| 鸟类 | 啄食浅埋的种子和幼芽 | 发芽前用稻草或网覆盖 |

> **豆荚野螟从花朵内部就开始为害。等豆荚看得见时，它其实早已钻入其中。开花期每天早晨查看花朵的习惯，是应对这种害虫最可靠的办法。**

&nbsp;&nbsp;&nbsp;豆荚野螟是与豇豆一同来自非洲的专性害虫，它把卵产在花瓣内侧，孵化的幼虫会钻入花朵和嫩荚内部。外表完好的豆荚剖开后，往往里面有幼虫而没有卵。无农药应对的方法有三种。第一，在开花期的清晨检查花朵，若内部有幼虫就把该花摘除。第二，一旦发现受害豆荚就立即摘下并带到田外处理。第三，据报道间作罗勒或大豆能减少受害程度。

### 9-3. 无农药防治用的材料

| 材料 | 制作方法 | 对象 | 注意事项 |
|---|---|---|---|
| 肥皂水 | 1L水加5g无香皂 | 蚜虫、红蜘蛛 | 正午高温时喷洒会灼伤叶片 |
| 撒干草木灰 | 在有露水的早晨往叶片上撒细灰 | 食叶害虫、真菌 | 下雨会被冲掉 |
| 草木灰水 | 将灰1升（约1.8升）浸入10L水中一夜，取上层清液使用 | 抑制真菌 | 呈碱性，需稀释后使用 |
| 波尔多液 | 在100L水中分别溶解硫酸铜400g和生石灰400g后混合 | 细菌性病害、真菌病害 | 必须有铜才能配制 |
| 木醋液 | 将烧炭时产生的液体稀释300-500倍 | 驱避、促进生长 | 原液呈强酸性，务必稀释后使用 |
| 辣椒·大蒜水 | 捣碎后用水浸泡、过滤后使用 | 驱避蛾类 | 效果不持久，需经常喷施 |
| 稀释牛奶液 | 将牛奶用水稀释5-10倍 | 白粉病 | 剩余部分放置会变质发臭 |

### 9-4. 农业防治

| 方法 | 原理 |
|---|---|
| 排水与起垄 | 豇豆病害大多与过湿有关，是效果最大的一项措施 |
| 开花期清晨巡查 | 豆荚野螟从花朵内部开始为害，那时是捕捉它的唯一机会 |
| 适时收获 | 成熟豆荚长期留在田里，象鼻虫会附卵其上 |
| 间作罗勒·大豆 | 据报道可减少害虫发生 |
| 遵守种植密度 | 通风良好可使叶片较快变干，真菌难以立足 |
| 种子挑选 | 播种虫蛀种子等于从一开始就引入了害虫 |
| 雨后禁止进入田地 | 人碰到潮湿的叶片会传播细菌性病害 |
| 残体处理 | 病株残体应焚烧，只将健康残体归还田地 |

## 10. 营养缺乏与过量

| 症状 | 原因 | 天然材料应对 |
|---|---|---|
| 整株叶片浅黄、植株矮小 | 缺氮，豇豆中最常见的原因是根瘤因涝害死亡 | 先挖根检查根瘤，改善排水并施用少量10倍稀释尿液 |
| 生长迟缓、叶片带紫色 | 缺磷，贫瘠地最常见的缺素症 | 骨粉、烧过的鱼骨粉，是豇豆最需要优先补充的元素 |
| 叶缘变褐干枯 | 缺钾 | 在植株间撒草木灰并轻轻耙入土中 |
| 开花但不结荚 | 缺硼，或豆荚野螟为害 | 先检查花朵内部，若非虫害则施用多种材料混合的堆肥 |
| 叶脉间发黄 | 缺铁或缺锰，在偏碱性土壤中常见 | 停止使用草木灰，用腐叶土和腐熟堆肥增加有机质 |
| 只长茎叶而少结荚 | 氮过量 | 立即停止供氮 |

&nbsp;&nbsp;&nbsp;豇豆最常见的缺素症是缺磷。因为它是种在贫瘠田地里的作物，那块地往往本就缺磷，而且氮可以自身固定，磷却不能。生长迟缓、叶片带紫色时，应怀疑是缺磷。在没有化学肥料的条件下，获取磷的途径只有骨粉和鱼骨。把兽骨收集起来用火烧至酥脆，再用石臼捣碎拌入堆肥，会在数年间缓慢释放出来。

&nbsp;&nbsp;&nbsp;微量元素的缺乏很难逐一应对。在没有化学肥料的条件下，实际上没有办法获取钼或钴。不过，把菜叶菜梗、果皮、蛋壳、鱼骨、落叶、杂草和草木灰混合在一起腐熟制成的堆肥中，会均衡地含有各种微量元素。"堆肥堆里什么都可以放"这一原则，正是管理微量元素的实际策略。

## 11. 间作与轮作

### 11-1. 搭配相性

| 相性 | 作物 | 理由 |
|---|---|---|
| 良好 | 玉米·高粱·黍 | 豇豆分享氮素，氨基酸组成相互补充 |
| 良好 | 罗勒 | 据报道可明显减少害虫发生 |
| 良好 | 大麦·小麦·大蒜·马铃薯 | 作为前茬时6月田地空出，可后茬种豇豆 |
| 良好 | 大白菜·萝卜 | 种在豇豆之后可利用残留的氮素 |
| 一般 | 大豆 | 虽有减少害虫的效果报告，但同为豆科，病害会重叠 |
| 不良 | 红小豆·绿豆 | 同属，病原菌和绿豆象会直接共享 |
| 不良 | 需水量大的作物 | 豇豆最不耐过湿 |

&nbsp;&nbsp;&nbsp;豇豆与高粱或黍搭配种植，是非洲延续了数千年的种植方式。杂粮利用上方的光照，豇豆覆盖下方，豇豆固定的部分氮素还会流向杂粮。二者在营养上也互补：杂粮缺赖氨酸而豇豆充足，豇豆缺蛋氨酸而杂粮不缺。把同一块地里产出的两种作物盛在同一个碗里，蛋白质组成就完整了。在韩国若种植高粱、黍或粟，在其间套种豇豆的方式同样适用。

&nbsp;&nbsp;&nbsp;最好不要把红小豆和绿豆种在旁边。因为同属豇豆属，会共享病原菌，更重要的是绿豆象会在这三种作物之间往来。若在同一块地里一起种植，贮藏期间的虫害会加倍。

### 11-2. 轮作

| 项目 | 标准 |
|---|---|
| 休作期 | 2-3年，在豆科中属连作耐性最好的一类 |
| 理想周期 | 3年 |
| 连作障碍 | 枯萎病和线虫会累积，但比其他豆科积累得慢 |

| 3年轮作示例 |
|---|
| 第1年：大麦或大蒜（冬）之后接豇豆（夏） |
| 第2年：高粱或玉米 |
| 第3年：大白菜·萝卜类或马铃薯 |
| 再种豇豆 |

&nbsp;&nbsp;&nbsp;豇豆的连作适应性为S，在豆类中最为宽裕。在田地狭小、难以轮作的条件下，这是一大优势。可以把一块贫瘠的地划给豇豆，连续种植数年，某一年收获籽实，第二年则在开花期翻埋作绿肥使用。这样过上两三年，那块地的土壤会有明显改善，届时便可以引入其他作物。

> **豇豆是能修复田地的作物。把其他任何作物都无法生长的地块交给豇豆轮种两三年，氮素和有机质就会积累起来，让那片田地重新焕发生机。**
