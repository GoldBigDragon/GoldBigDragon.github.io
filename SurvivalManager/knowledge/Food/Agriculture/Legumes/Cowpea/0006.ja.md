## 12. 収穫と脱穀

### 12-1. 収穫時期の判断

| 用途 | 収穫時期(播種後) | 判断基準 |
|---|:---:|---|
| 若葉(ナムル用) | 本葉展開後から開花前まで | 下のほうの生長した葉を選んで摘みます |
| 若いさや(野菜用) | 45-60日 | さやがまだ細く柔らかいうち |
| 乾燥種実(早生) | 75-90日 | さやが褐色に変わり、粒が硬くなったとき |
| 乾燥種実(晩生) | 90-125日 | |
| 収穫回数 | 2-3回に分けて | 開花後8-15日で熟します |

&nbsp;&nbsp;&nbsp;ササゲは開花が続くため、一度に収穫することができません。毎朝新しい花が咲き、8-15日でそのさやが熟します。そのため下から上へと熟し上がっていき、二、三回に分けて摘むことになります。熟したさやを長く放置すると裂けて粒を落とし、それより重要なことに、アズキゾウムシがそのさやに卵を付けます。時期を守って摘むことが、収量と貯蔵性を同時に守ります。

> **畑で熟したまま長く垂れ下がったさやが、貯蔵中のゾウムシ被害を生みます。ササゲでは時期を守った収穫は、怠けの問題ではなく、半年後の食料が残るかどうかの問題です。**

### 12-2. 収穫のコツ

| 順序 | 内容 |
|---|---|
| 1 | 晴れて乾いた日、露が乾いたあとに行います |
| 2 | 褐色に変わったさやだけを手でねじって摘みます |
| 3 | 最後の収穫のときは茎ごと刈るか引き抜いて一緒に乾かします |
| 4 | さやを網やむしろに広げ、日に当てて3-5日乾かします |
| 5 | からからに乾いたら叩いて脱穀します |
| 6 | 茎と葉は畑に戻します |

&nbsp;&nbsp;&nbsp;網に入れて乾かす方式はササゲでも有用です。乾く途中で自然に開くさやがありますが、網の中にあれば飛び出した粒が網の底に集まります。タマネギ用の網やハクサイ用の網、なければ目の細かい袋を使います。日当たりの良い日に干して時々振ると、脱穀の半分が自然に終わっています。

### 12-3. 脱穀 - 道具なしで行う方法

| 方法 | 道具 | 手順 | 効率 |
|---|---|---|---|
| 袋を踏む | 厚い麻袋や袋 | 乾いたさやを袋に入れて口を結び、足で踏みます | 少量に最も手軽です |
| 網に入れて叩く | タマネギ用・ハクサイ用の網 | 乾いたさやを網に入れて棒で叩きます | 粒が漏れません |
| 唐竿(からさお) | 長い柄に打棒を付けた道具 | むしろを広げてさやを薄く広げ、打ち下ろします | 中規模に適しています |
| 棒で叩く | 木の棒 | 袋に入れるか、むしろに広げて叩きます | 唐竿がないときの代わりになります |
| 手でむく | 不要 | さやをねじって開きます | 一つのさやに10-20粒入っており、効率は悪くありません |
| 足でもみ出す | 不要 | むしろに広げ、靴を履いた足でもみ回します | 少量に適しています |

&nbsp;&nbsp;&nbsp;ササゲは一つのさやに十から二十の粒が入っているため、手でむいても作業が速く進みます。小規模であれば手でむくことが粒を傷めない最も確実な方法で、特に種子用の分に適しています。唐竿や棒を使うときは力を抜いて何度も打つほうが粒が割れにくくなります。

### 12-4. 選別 - 風で選び出す

| 方法 | 原理 | 手順 |
|---|---|---|
| 風選(風を起こす) | 粒は重く、殻やくずは軽いです | 風のある日に、箕や広い器に入れて高く持ち上げ、ゆっくり注ぎます |
| 箕あおり | 上下に振りながら前にあおります | 重い粒が後ろに残り、軽いものが前へ押し出されます |
| うちわであおぐ | 一人が注ぎ、一人がうちわで風を送ります | 風のない日に使います |
| ふるいがけ | 穴の大きさで分けます | 割れた粒とくずをふるい分けます |
| 水に浮かべる | しいなや虫食いの粒は軽いです | 水桶に注ぎ、浮くものを取り除きます。その日のうちに再び乾かします |
| 手で選る | 目で見ます | ゾウムシの穴がはっきり見えます |

&nbsp;&nbsp;&nbsp;ササゲでは水に浮かべる工程を必ず設けるのがよいです。アズキゾウムシが食い始めた粒は中が空になって浮きます。この段階で取り除けば貯蔵中の被害が大きく減ります。ただし水に浸したササゲはその日のうちに完全に乾かし直す必要があり、種子用には使いません。種子用は目で見て手で選びます。ササゲは粒が大きく、へその部分に黒い縁があるため、ゾウムシの穴が目立ちやすいです。

## 13. 採種

| 項目 | 方法 |
|---|---|
| 採種株の選定 | 病気の症状がなく、さやが多く付き、倒れていない株を畑であらかじめ印しておきます |
| 収穫時期 | さやが完全に褐色に変わった直後に摘みます |
| 分離 | 手でむいて粒が割れないようにします |
| 選別 | 虫食い穴、斑点、割れた粒、変色したものはすべて取り除きます |
| 乾燥 | 水分12%以下 |
| 保管 | 密閉容器に入れ、涼しく暗い場所に置きます。食用とは別の容器にします |
| 保管期間 | 常温密閉で3-4年 |
| 更新 | 入手できるなら3-4年ごとに別の場所の種子を一部混ぜます |

> **ササゲは韓国国内での栽培普及度がBで、主産地の外では種子を再び入手するのが容易ではありません。採種はこの作物を続けて育てるための前提条件です。**

&nbsp;&nbsp;&nbsp;ササゲの採種で特に重要なのは、ゾウムシが入っていない種子を選ぶことです。ゾウムシの卵は外から見えず、殻にごく小さな白い点として付いています。種子用は収穫後すぐに別に選び、完全に乾かしてから密閉し、真冬に数日外に出して凍らせてから取り込む低温処理を行うと、卵と幼虫が死にます。この処理は発芽力を損なわないため、種子用に使える数少ない方法です。

&nbsp;&nbsp;&nbsp;ササゲは自家受粉のため、隔離距離を心配する必要がありません。ただし、アズキやリョクトウが近くにあると種子が混ざらないよう、収穫と保管を確実に分けて管理します。採種用を畑であらかじめ印しておけば、萎凋病抵抗性、さやの数、倒伏抵抗性といった実際に重要な形質も併せて選ぶことができます。

| 種子保管期間と発芽率 |
|---|
| 収穫当年:90%以上 |
| 1年経過:85-90% |
| 2年経過:70-85% |
| 3年経過:50-70% |
| 4年以降:急激に落ちます |

## 14. 毒性と抗栄養成分

&nbsp;&nbsp;&nbsp;ササゲは豆類の中でも毒性の危険が低いほうです。インゲンマメのように生の数粒で中毒を起こす強いレクチンも、ソラマメのように特定の体質で急性溶血を起こす成分もありません。ただし乾燥種実には他の豆と同様に抗栄養成分が含まれているため、十分に加熱する必要があります。

| 成分 | 作用 | 症状 | 取り除く方法 |
|---|---|---|---|
| トリプシン阻害因子 | タンパク質分解酵素の働きを妨げます | 腹痛、下痢、タンパク質利用率の低下 | 6時間浸漬後、沸騰した湯で1時間 |
| レクチン | 腸粘膜に付着して吸収を妨げます | 消化不良 | 加熱で破壊されます。インゲンマメ類よりかなり弱いです |
| フィチン酸 | 鉄、亜鉛、カルシウムと結合して吸収を妨げます | 長く食べると貧血、亜鉛欠乏 | 浸漬、発芽、発酵で60-80%まで減ります |
| オリゴ糖 | 人が消化できず腸内細菌が発酵させます | 腹にガスがたまります | 浸漬後、浸した水を捨てます |
| 葉のシュウ酸 | カルシウムと結合します | 少量は無害です | 茹でて水を捨てると相当量減ります |
| カビ毒 | 貯蔵中にカビが作ります | 危険です | カビが生えたものは洗ったり加熱しても安全になりません。廃棄します |

> **ササゲの葉も生で食べません。シュウ酸と少量の抗栄養成分があるため必ず茹でて食べ、茹でた水は捨てます。**

| 処理 | 時間・温度 | 効果 |
|---|---|---|
| 浸漬 | 常温の水に6時間 | 種皮が柔らかくなり、煮る時間が減ります |
| 浸した水を捨てる | 必ず | 水に溶け出したオリゴ糖と抗栄養成分を一緒に捨てます |
| 煮る | 沸騰した湯で1時間 | 皮をむいて割ったものは20-30分 |
| 葉を茹でる | 沸騰した湯に1-2分 | 茹でた水は捨てます |
| 火の通り確認 | 指で押して簡単に崩れます | 芯が残っていれば煮え足りません |

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;ササゲの貯蔵性はSSです。乾燥種実は常温で3年もち、脂肪が少ないため酸敗も遅いです。しかしアズキゾウムシがササゲ貯蔵の最大の脅威で、何の対策もなく置くと半年以内に全量が被害を受けることがあります。

> **豆は腐って失うのではなく、虫に食われて失います。ササゲでは貯蔵が栽培と同じくらい重要な作業です。**

### 15-1. 乾燥が先です

| 段階 | 方法 | 確認 |
|---|---|---|
| 予備乾燥 | 摘んださやを網に入れて日に当てて3-5日 | 自然に開くものが出てきます |
| 脱穀後の乾燥 | むしろや敷物に薄く広げて日に当てて2-3日 | 頻繁にかき混ぜて均一に乾かします |
| 目標水分 | 食用も種子用もともに12%以下 | 歯で噛んだとき歯が入らず、ぱきっと割れます |
| 塩の試験 | 乾いた塩を瓶に豆と一緒に入れて振ります | 塩が瓶の壁に付けばまだ湿っています |
| 冷ます | 完全に冷ましてから詰めます | 温かい状態で密閉すると結露が生じます |

### 15-2. 貯蔵中のアズキゾウムシ防除

&nbsp;&nbsp;&nbsp;アズキゾウムシは貯蔵ササゲの最大の脅威です。恐ろしいのは畑で既に始まっているという点です。まだ畑に付いているさやに成虫が卵を付け、その卵が貯蔵庫の中で孵化して豆の中へ入り込みます。一世代が一か月もかからず、ササゲは粒が大きいため一粒の中で複数匹が育つことがあります。アフリカでササゲの貯蔵損失が伝統的に深刻な問題だった理由です。

| 方法 | 原理 | 適用 | 効果 |
|---|---|---|---|
| 完全密閉 | 酸素を絶って窒息させます | ガラス瓶や金属缶を満たして密閉します | 最も確実です。3-4週間で卵と幼虫まで死にます |
| 三重袋 | ビニール袋三重で酸素を遮断します | 厚いビニール袋を重ねて入れ、それぞれしっかり結びます | 西アフリカで広く使われ、4か月間ゾウムシの発生が完全に抑えられた例があります |
| 草木灰を混ぜる | 微細な粒子が外骨格のワックス層を削って脱水させます | 豆の量の2-5%を混ぜます | 食べる前に水で洗い流します |
| 珪藻土 | 珪酸の殻が外骨格を傷めます | 豆1kgに1-3g | 灰より効果が大きいです。乾いた状態でのみ働きます |
| 油コーティング | 油の膜が卵の付着と孵化を防ぎます | 豆1kgに食用油2-5mLを入れてもみます | 種子用には使いません |
| 低温処理 | 零下で卵と幼虫が死にます | 真冬に数日外に出してから取り込みます | 種子用に使える数少ない方法です |
| 高温処理 | 60度で卵と幼虫が死にます | 日に薄く広げて半日置きます | 種子用には使いません |
| 乾燥トウガラシ・サンショウ・ヨモギ | 精油成分が産卵を抑えます | 層に重ねて入れます | 補助的な手段です |
| 灰に埋める | 密閉と物理的防除を同時に得ます | 甕に灰と豆を層に重ねて積みます | 伝統的に広く使われました |

&nbsp;&nbsp;&nbsp;三重袋の方式を別途記しておきます。厚いビニール袋の中にさらに袋、その中にさらに袋を入れて、それぞれの口をねじってしっかり結ぶ方法です。内側の空気の酸素が豆と虫の呼吸で消費され、二酸化炭素濃度が上がり、幾重にもなったビニールが外気との交換を妨げて虫が窒息します。西アフリカでササゲの貯蔵損失を大幅に減らした方法として知られ、ガラス瓶や金属缶が不足する条件で現実的な代案になります。ただしネズミがビニールを破るため、袋は必ずネズミが届かない容器の中や棚の上に置きます。

&nbsp;&nbsp;&nbsp;低温処理は種子用に特に価値があります。真冬に種子を入れた容器を数日外に出しておくと、零下の気温が卵と幼虫を死なせます。発芽力は損なわれません。再び取り込むときは容器を開けず、室温に馴染むまで数時間置く必要があります。冷たい豆を暖かい部屋ですぐに開けると表面に結露が生じ、カビの原因になります。

### 15-3. 貯蔵容器と点検

| 容器 | 密閉性 | 期間 | 備考 |
|---|:---:|---|---|
| ガラス瓶 | 非常に良い | 3年以上 | 状態を目で確認できます |
| 金属缶 | 非常に良い | 3年以上 | ネズミと虫を完全に防ぎます |
| 甕 | 良い | 2-3年 | 温度変化が緩やかでネズミが破れません |
| 三重ビニール袋 | 良い | 1-2年 | ネズミが届かない場所に置きます |
| 地中貯蔵穴 | 良い | 2-3年 | 水がしみ込むと全量を失います |

&nbsp;&nbsp;&nbsp;点検で最も頼りになる感覚は聴覚と嗅覚です。容器に耳を当てたときにカサカサという音がすれば虫が活動しており、湿った臭いがすればカビが始まっています。表面に小さく丸い穴が見えればゾウムシが一世代を過ぎた状態です。この時点でも全量を取り出して日に乾かし、水に浮かべて空の粒を取り除き、灰を混ぜて再び密閉すれば残りの分を守れます。ササゲはゾウムシ被害が速く進むため、月に一度の点検が適当です。

## 16. 調理と加工 - 葉のナムルと種実

### 16-1. ササゲの葉 - 夏の野菜

&nbsp;&nbsp;&nbsp;ササゲが他の豆類と区別される最大の理由がここにあります。葉を食べます。乾燥種実にはないビタミンAとビタミンCが若葉に含まれ、鉄分も豊富です。豆が熟すのを待つ夏の間中、同じ畑から野菜が採れるということです。

| 順序 | 内容 | 要点 |
|---|---|---|
| 1. 摘み方 | 下のほうの生長した葉を葉柄ごと摘みます | 生長点は触りません |
| 2. 限度 | 一株で全体の葉の3分の1以内 | 過ぎると種実の収量が減ります |
| 3. 時期 | 開花が始まったらやめます | それ以降の葉はさやを満たすのに使われます |
| 4. 洗う | 流水で洗います | |
| 5. 茹でる | 沸騰した湯に1-2分 | 生で食べません |
| 6. すすぐ | 冷水ですすいで水気を絞ります | 茹でた水は捨てます |
| 7. 和える | 塩、油、ニンニクなどで和えます | テンジャンで和えてもよいです |

&nbsp;&nbsp;&nbsp;ササゲの葉は厚みがあり少し青臭さがあるため、茹でると性質が柔らかくなります。茹でた水を捨てる理由は、シュウ酸と少量の抗栄養成分を一緒に捨てるためです。茹でたあとしっかり絞って水気を抜き、ナムルとして和えると、ホウレンソウやフダンソウと似た位置に置かれます。

&nbsp;&nbsp;&nbsp;量が多いときは茹でて干しておきます。茹でて水気を絞ったあと薄く広げて日にからからに乾かすと冬まで持ちます。食べるときに水で戻して和えたり汁物に入れたりすれば、夏の野菜が冬の食卓に上がります。新鮮な野菜が消える冬に、この乾燥ナムルがビタミンとミネラルの供給源になります。韓国の食文化のムクナムル(干しナムル)がまさにこの方式であり、ササゲの葉も同じ原理で扱います。

### 16-2. 種実の調理と燃料の節約

| 方法 | 燃料 | 手順 |
|---|:---:|---|
| 皮をむいて割る | 少ない | 水に浸して皮をむき割ると20-30分で煮えます |
| 圧力調理 | 最も少ない | 浸した豆を15分加圧します |
| 余熱調理 | 非常に少ない | 15分煮たら火を止め、藁・もみ殻の箱や布団で包んで2-3時間置きます |
| 炒りササゲ粉 | ほとんどなし | 炒って挽いておき、水に溶いて食べます |
| 若いさや | 非常に少ない | 若いさやは数分茹でればよいです |
| 葉 | 非常に少ない | 1-2分茹でればよいです |
| 発芽 | なし | 芽を出させるとビタミンCが生まれます |

&nbsp;&nbsp;&nbsp;皮をむいて割る加工はササゲでも有用です。西アフリカではササゲをすりつぶして皮を飛ばしたあと練って揚げたり蒸して食べる方式が古くから続いてきました。浸したササゲを臼で軽くつぶして皮をむき、半分に割って乾かしておくと調理時間が半分以下に減ります。ただし皮をむいた豆は貯蔵性が落ちるため、一、二か月の間に食べる分だけ加工します。

&nbsp;&nbsp;&nbsp;余熱調理もササゲによく合います。15分煮たあと保温箱に入れておくと内部の温度が二時間以上高く保たれ、調理が続きます。ササゲはインゲンマメのように必ず100度を確保しなければならない強い毒性成分がないため、余熱調理でも安全に煮ることができます。藁やもみ殻を詰めた木箱、または厚い布団で鍋をそのまま包めば、それが保温箱です。

### 16-3. 貯蔵加工

| 加工 | 手順の概要 | 保管 | 価値 |
|---|---|---|---|
| 茹でて干したササゲの葉 | 茹でて水気を絞り、からからに乾かします | 冬まで | 干しナムルとして使います |
| ササゲ粉 | 炒って挽きます | 密閉で3-6か月 | 調理燃料がかかりません |
| 皮をむいて割ったササゲ | 浸して皮をむき割ります | 密閉で1-2か月 | 調理時間が半分に減ります |
| 茹でて干した若いさや | 茹でて乾かします | 数か月 | 冬に汁物や煮物に入れます |
| ササゲ味噌 | 煮てつぶし、発酵させたあと塩水に漬けます | 数年 | 大豆が足りないときの代案です |

## 17. 年間作業スケジュール

| 月 | 作業 | 要点 |
|---|---|---|
| 1月 | 貯蔵点検、低温処理、種子発芽試験 | 真冬に種子を凍らせてゾウムシを殺します |
| 2月 | 畑の計画、やせた区画をササゲに割り当てます | ササゲは悪い畑を任される作物です |
| 3月 | 堆肥の切り返し、骨粉の準備 | リン酸がササゲで最も重要な要素です |
| 4月 | 前作の管理、畝と排水路の計画 | 畝20cmが前提です |
| 5月 | 畑の準備、畝作り、排水路作り | 梅雨前に水が抜けるか確認します |
| 6月 | 播種(韓国中部下旬、南部中旬から)、接種、藁掛け | 早朝か夕暮れに植えます |

| 10月 | 収穫の仕上げ、脱穀、選別、茎葉を戻す | 霜の前に終えます |
| 11月 | 乾燥、貯蔵、干しナムル作り | 三重袋や密閉容器に入れます |
| 12月 | 貯蔵点検、加工、翌年の計画 | 月に一度容器を開けてみます |

### 17-1. 忘れてはならない五つ

| 項目 | 内容 |
|---|---|
| 排水 | 乾燥には最も強く、浸水には最も弱いです。畝20cmが前提です |
| リン酸 | 窒素は自分で作りますが、リン酸は作れません。骨粉と魚の骨を用意します |
| 最初の5週 | 初期の生育が遅く雑草に負けます。この期間の除草が収量を決めます |
| 葉 | 同じ畑から夏の間中野菜が採れます。全体の葉の3分の1まで、開花前まで |
| 貯蔵 | アズキゾウムシは半年で全量を台無しにします。完全な乾燥と密閉が栽培と同じくらい重要です |
