## 12. 收获与脱粒

### 12-1. 收获时期的判断

| 用途 | 收获时期（播种后） | 判断标准 |
|---|:---:|---|
| 嫩叶（凉拌用） | 真叶展开后至开花前 | 挑选下部长成的叶片采摘 |
| 嫩荚（蔬菜用） | 45-60天 | 豆荚还细嫩柔软的时候 |
| 干种子（早熟） | 75-90天 | 豆荚变成褐色、豆粒变硬的时候 |
| 干种子（晚熟） | 90-125天 | |
| 收获次数 | 分2-3次 | 开花后8-15天即可成熟 |

&nbsp;&nbsp;&nbsp;豇豆开花不断，无法一次收完。每天早上开出新花，8-15天后那个豆荚就会成熟。因此从下往上依次成熟，需要分两三次采摘。成熟的豆荚在地里放久了会裂开落粒，更重要的是豆象会在豆荚上产卵。及时采摘既能保住产量，又能保住耐储性。

> **在地里熟透后长时间悬挂的豆荚，会造成储藏中的豆象危害。对豇豆来说，及时收获不是勤懒的问题，而是半年后是否还有粮食的问题。**

### 12-2. 收获要领

| 顺序 | 内容 |
|---|---|
| 1 | 在晴朗干燥、露水干后进行 |
| 2 | 只用手拧下已变褐色的豆荚 |
| 3 | 最后一次收获时连茎割下或拔起一起晒干 |
| 4 | 将豆荚摊在网袋或席子上，在阳光下晒3-5天 |
| 5 | 完全晒干后敲打脱粒 |
| 6 | 茎叶归还田地 |

&nbsp;&nbsp;&nbsp;装进网袋晒干的方式对豇豆同样有用。晒干过程中会有豆荚自然裂开，如果装在网袋里，蹦出的豆粒会聚集在网袋底部。可用洋葱网袋或白菜网袋，没有的话用密织的口袋代替。选晴好的日子摊晒，时常摇动，脱粒工作就自然完成了一半。

### 12-3. 脱粒 - 不用工具的方法

| 方法 | 工具 | 步骤 | 效率 |
|---|---|---|---|
| 踩袋子 | 厚麻袋或布袋 | 把干豆荚装入袋中，扎住袋口后用脚踩 | 少量时最方便 |
| 装网袋敲打 | 洋葱网袋、白菜网袋 | 把干豆荚装入网袋，用木棒敲打 | 豆粒不会散失 |
| 连枷 | 长柄上装有打杖的工具 | 铺开草席，把豆荚薄薄摊开后打击 | 适合中等规模 |
| 棍棒敲打 | 木棍 | 装入袋中或摊在草席上敲打 | 没有连枷时替代使用 |
| 手剥 | 无 | 拧开豆荚 | 一个豆荚有10-20粒，效率并不差 |
| 脚搓 | 无 | 摊在草席上，穿鞋用脚搓动 | 适合少量 |

&nbsp;&nbsp;&nbsp;豇豆一个豆荚里有十到二十粒豆，用手剥也进展很快。规模小的话，手剥是不伤豆粒的最可靠方法，尤其适合留种用的那部分。使用连枷或棍棒时，用力要轻、多打几次，这样豆粒破损更少。

### 12-4. 清选 - 借风分选

| 方法 | 原理 | 步骤 |
|---|---|---|
| 风选（扬风） | 豆粒重，皮壳和碎屑轻 | 有风的日子，装入簸箕或宽口容器高举缓缓倾倒 |
| 簸扬 | 上下抖动并向前簸 | 重的豆粒留在后面，轻的被推向前方 |
| 扇风 | 一人倾倒，一人用扇子送风 | 用于无风的日子 |
| 过筛 | 按孔径大小分开 | 筛出破粒和碎屑 |
| 浮水 | 空壳和虫蛀的豆粒较轻 | 倒入水桶，捞去漂浮的部分。当天要重新晒干 |
| 手工挑选 | 用眼睛看 | 豆象的蛀孔清晰可见 |

&nbsp;&nbsp;&nbsp;对豇豆来说，一定要设置浮水这一步骤。被豆象蛀食的豆粒内部空了会漂浮起来。在这一步清除掉，储藏期间的损失会大大减少。不过浸过水的豇豆必须当天彻底重新晒干，且不能用作种子。种子用的要靠眼看手选。豇豆豆粒大，脐部有黑色环纹，豆象的蛀孔很容易看出来。

## 13. 留种

| 项目 | 方法 |
|---|---|
| 留种株选择 | 提前在地里标记没有病症、结荚多且不倒伏的株 |
| 收获时期 | 豆荚完全变褐后立即采摘 |
| 分离 | 用手剥开，不使豆粒破损 |
| 筛选 | 虫孔、斑点、破粒、变色的全部剔除 |
| 干燥 | 水分12%以下 |
| 保管 | 装入密闭容器，放在阴凉黑暗处。要与食用的分开容器存放 |
| 保管期限 | 常温密闭3-4年 |
| 更新 | 如能获得，每3-4年混入一部分别处的种子 |

> **豇豆的韩国国内栽培普及度为B级，在主产地之外很难再次获得种子。留种是持续种植这种作物的前提条件。**

&nbsp;&nbsp;&nbsp;豇豆留种中特别重要的是挑选没有豆象的种子。豆象的卵从外表看不见，以极小的白点附着在豆壳上。种子用的应在收获后立即另行挑出，彻底晒干后密闭保存，若在寒冬把它放到室外冻上几天再收回进行低温处理，卵和幼虫就会死亡。这种处理不损害发芽力，是少数可用于种子的方法之一。

&nbsp;&nbsp;&nbsp;豇豆是自花授粉，不必担心隔离距离。不过若红小豆和绿豆种在附近，为防止种子混杂，收获和保管要严格分开管理。提前在地里标记留种用的株，还能同时选出枯萎病抗性、结荚数、抗倒伏性等真正重要的性状。

| 种子保管期限与发芽率 |
|---|
| 收获当年：90%以上 |
| 经过1年：85-90% |
| 经过2年：70-85% |
| 经过3年：50-70% |
| 4年以后：急剧下降 |

## 14. 毒性与抗营养成分

&nbsp;&nbsp;&nbsp;豇豆在豆类中属于毒性风险较低的一种。它没有像菜豆那样几粒生豆就能引起中毒的强凝集素，也没有像蚕豆那样在特定体质中引发急性溶血的成分。不过干种子和其他豆类一样含有抗营养成分，必须充分煮熟。

| 成分 | 作用 | 症状 | 去除方法 |
|---|---|---|---|
| 胰蛋白酶抑制剂 | 阻碍蛋白酶的作用 | 腹痛、腹泻、蛋白质利用率下降 | 浸泡6小时后在沸水中煮1小时 |
| 凝集素 | 附着在肠黏膜上妨碍吸收 | 消化不适 | 加热可破坏。比菜豆类弱得多 |
| 植酸 | 与铁、锌、钙结合阻碍吸收 | 长期食用会导致贫血、锌缺乏 | 浸泡、发芽、发酵可减少60-80% |
| 寡糖 | 人体无法消化，由肠道细菌发酵 | 腹部产气 | 浸泡后倒掉浸泡水 |
| 叶片中的草酸 | 与钙结合 | 少量无害 | 焯水后倒掉水可减少相当一部分 |
| 霉菌毒素 | 储藏中霉菌产生 | 危险 | 长霉的部分洗净或加热也不会变安全，须丢弃 |

> **豇豆叶也不生吃。含有草酸和少量抗营养成分，必须焯水后食用，焯水的水要倒掉。**

| 处理 | 时间·温度 | 效果 |
|---|---|---|
| 浸泡 | 常温水中6小时 | 种皮变软，缩短煮熟时间 |
| 倒掉浸泡水 | 必须 | 一并倒掉溶入水中的寡糖和抗营养成分 |
| 煮熟 | 沸水中1小时 | 去皮掰开的只需20-30分钟 |
| 焯叶 | 沸水中1-2分钟 | 焯水的水要倒掉 |
| 确认煮熟 | 用手指按压能轻易压碎 | 若还有硬芯说明没煮熟 |

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;豇豆的贮藏性等级为SS。干种子在常温下能耐3年，脂肪少所以酸败也慢。但豆象是豇豆储藏的最大威胁，如果毫无对策地放置，半年内可能全部受害。

> **豆子不是因为腐烂而损失，而是被虫吃掉而损失的。对豇豆来说，储藏和栽培同样重要。**

### 15-1. 干燥要先做好

| 阶段 | 方法 | 确认 |
|---|---|---|
| 预干燥 | 将摘下的豆荚装入网袋在阳光下晒3-5天 | 会出现自然裂开的荚 |
| 脱粒后干燥 | 薄薄摊在草席或垫子上晒2-3天 | 要经常翻动使其均匀干燥 |
| 目标水分 | 食用和留种都要12%以下 | 用牙咬时咬不进去，会咯地裂开 |
| 盐粒测试 | 把干盐和豆子一起放进瓶里摇晃 | 盐若粘在瓶壁上说明还潮 |
| 冷却 | 完全冷却后再装存 | 温热状态下密闭会产生冷凝水 |

### 15-2. 储藏期间防治豆象

&nbsp;&nbsp;&nbsp;豆象是储藏豇豆的最大威胁。可怕之处在于它在田里就已经开始了。还挂在田里的豆荚上，成虫就已产下卵，那些卵在储藏中孵化并钻入豆粒内部。一代不到一个月，而且豇豆豆粒大，一粒之内可以让好几只幼虫生长。这就是豇豆储藏损失在非洲历来是严重问题的原因。

| 方法 | 原理 | 应用 | 效果 |
|---|---|---|---|
| 完全密闭 | 断绝氧气使其窒息 | 装满玻璃瓶或金属罐并封严 | 最可靠。3-4周内连卵和幼虫都会死亡 |
| 三层塑料袋 | 三层塑料袋阻断氧气 | 套上厚塑料袋三层，每层分别扎紧 | 在西非广泛使用，有过4个月完全抑制豆象发生的案例 |
| 混入草木灰 | 微细颗粒刮伤外骨骼蜡层使其脱水 | 混入豆子体积的2-5% | 食用前用水冲洗掉 |
| 硅藻土 | 硅质外壳损伤外骨骼 | 每1kg豆子加1-3g | 效果比灰更强，只在干燥状态下起作用 |
| 涂油 | 油膜阻止卵附着和孵化 | 每1kg豆子加2-5mL食用油拌匀 | 不用于种子 |
| 低温处理 | 零下低温使卵和幼虫死亡 | 寒冬放到室外数天后收回 | 少数可用于种子的方法之一 |
| 高温处理 | 60度使卵和幼虫死亡 | 在阳光下薄摊半天 | 不用于种子 |
| 干辣椒·花椒·艾草 | 精油成分抑制产卵 | 一层层放入 | 属于辅助手段 |
| 埋入灰中 | 同时获得密闭和物理防治效果 | 在坛子里将灰和豆子层层叠放 | 传统上广泛使用 |

&nbsp;&nbsp;&nbsp;这里单独记一下三层塑料袋的方法。就是在厚塑料袋里再套一个袋，那个袋里再套一个袋，把每层的袋口都拧紧扎实的方法。内部空气中的氧气随着豆子和虫的呼吸而消耗，二氧化碳浓度上升，重重的塑料层阻断了与外部空气的交换，使虫窒息。这一方法在西非被认为大幅减少了豇豆的储藏损失，在缺乏玻璃瓶或金属罐的条件下是一个现实的替代方案。不过老鼠会咬破塑料袋，所以袋子必须放在老鼠碰不到的容器里或架子上。

&nbsp;&nbsp;&nbsp;低温处理对留种用尤其有价值。寒冬把装有种子的容器放到室外几天，零下的气温会使卵和幼虫死亡，而不损害发芽力。再收回时不要马上打开容器，要放置几个小时让它适应室温后再开。若把冰凉的豆子在暖屋里立即打开，表面会结露，成为霉变的原因。

### 15-3. 储藏容器与检查

| 容器 | 密闭性 | 期限 | 备注 |
|---|:---:|---|---|
| 玻璃瓶 | 非常好 | 3年以上 | 可用眼睛确认状态 |
| 金属罐 | 非常好 | 3年以上 | 能完全阻挡老鼠和虫子 |
| 坛子 | 好 | 2-3年 | 温度变化缓慢，老鼠咬不破 |
| 三层塑料袋 | 好 | 1-2年 | 放在老鼠碰不到的地方 |
| 地下储藏坑 | 好 | 2-3年 | 一旦渗水就会全部损失 |

&nbsp;&nbsp;&nbsp;检查时最可靠的感官是听觉和嗅觉。把耳朵贴在容器上如果听到沙沙声，说明有虫在活动；若闻到潮湿的气味，说明霉已经开始了。表面出现小而圆的孔洞，说明豆象已经过了一代。这时也还能把全部取出晒干，浮水去除空粒，再混入灰重新密闭，就能保住剩下的部分。豇豆的豆象危害进展较快，每月检查一次比较合适。

## 16. 烹饪与加工 - 叶菜与种实

### 16-1. 豇豆叶 - 夏季的蔬菜

&nbsp;&nbsp;&nbsp;豇豆区别于其他豆类的最大原因就在这里。它的叶子可以吃。干种子里没有的维生素A和维生素C存在于嫩叶中，铁含量也很丰富。这意味着在等待豆子成熟的整个夏天，同一块地里都能收获蔬菜。

| 顺序 | 内容 | 要点 |
|---|---|---|
| 1. 采摘 | 连叶柄摘下下部长成的叶片 | 不要碰生长点 |
| 2. 限度 | 一株全部叶片的三分之一以内 | 过量会使种实产量减少 |
| 3. 时期 | 开花开始后就停止 | 之后的叶片用于充实豆荚 |
| 4. 洗净 | 用流水冲洗 | |
| 5. 焯水 | 沸水中1-2分钟 | 不生吃 |
| 6. 冲净 | 用冷水冲洗后挤干水分 | 焯水的水要倒掉 |
| 7. 拌菜 | 用盐、油、蒜等拌 | 用大酱拌也可以 |

&nbsp;&nbsp;&nbsp;豇豆叶较厚且带一点青涩味，焯水后性质会变软。倒掉焯水的水，是为了把草酸和少量抗营养成分一并倒掉。焯水后一定要挤干水分再拌成凉拌菜，其地位就和菠菜、莙荙菜相似。

&nbsp;&nbsp;&nbsp;量多的时候可以焯水后晒干保存。焯水挤干水分后薄薄摊开晒到干透，可以放到冬天。吃的时候用水泡开再拌或放进汤里，夏天的蔬菜就能端上冬天的饭桌。在新鲜蔬菜消失的冬天，这种干凉拌菜就成了维生素和矿物质的来源。韩国饮食文化中的陈干菜（muk-namul）正是这种方式，豇豆叶也按同样的原理处理。

### 16-2. 种实的烹调与节省燃料

| 方法 | 燃料 | 步骤 |
|---|:---:|---|
| 去皮掰开 | 少 | 泡水后去皮掰开，20-30分钟就能煮熟 |
| 压力烹调 | 最少 | 把泡好的豆子加压煮15分钟 |
| 余热烹调 | 非常少 | 煮15分钟后关火，用稻草·稻壳箱或被子包住放置2-3小时 |
| 炒豇豆粉 | 几乎不需要 | 炒熟磨成粉，用水冲开食用 |
| 嫩荚 | 非常少 | 嫩荚焯几分钟即可 |
| 叶片 | 非常少 | 焯1-2分钟即可 |
| 发芽 | 不需要 | 发芽后会产生维生素C |

&nbsp;&nbsp;&nbsp;去皮掰开的加工方法对豇豆同样有用。在西非，把豇豆磨碎去皮后和成面团油炸或蒸熟食用的方式流传已久。把泡好的豇豆用臼轻轻捣一下去皮，掰成两半晒干保存，烹调时间会减少到一半以下。不过去皮的豆子耐储性较差，只加工够一两个月内食用的量。

&nbsp;&nbsp;&nbsp;余热烹调也很适合豇豆。煮15分钟后放入保温箱，内部温度能维持两个多小时的高温，让烹调继续进行。豇豆不像菜豆那样含有必须确保达到100度才能破坏的强烈毒性成分，所以用余热烹调也能安全煮熟。用稻草或稻壳填充的木箱，或用厚被子把锅整个包起来，那就是保温箱。

### 16-3. 储藏加工

| 加工 | 步骤概要 | 保存 | 价值 |
|---|---|---|---|
| 焯水晒干的豇豆叶 | 焯水挤干水分后晒到干透 | 可放到冬天 | 用作干凉拌菜 |
| 豇豆粉 | 炒熟磨碎 | 密闭保存3-6个月 | 不需要烹调燃料 |
| 去皮掰开的豇豆 | 泡水去皮掰开 | 密闭保存1-2个月 | 烹调时间减半 |
| 焯水晒干的嫩荚 | 焯水后晒干 | 可放数月 | 冬天放入汤和炖菜中 |
| 豇豆大酱 | 煮熟捣碎发酵后腌入盐水 | 可放数年 | 大豆不足时的替代品 |

## 17. 全年作业日程

| 月份 | 作业 | 要点 |
|---|---|---|
| 1月 | 储藏检查、低温处理、种子发芽试验 | 寒冬把种子冻一下以杀死豆象 |
| 2月 | 地块规划，将贫瘠地块分配给豇豆 | 豇豆是承担劣质田地的作物 |
| 3月 | 翻堆肥，准备骨粉 | 磷是豇豆最重要的元素 |
| 4月 | 管理前作，规划垄和排水沟 | 前提是垄高20cm |
| 5月 | 整地、起垄、挖排水沟 | 确认梅雨前排水是否通畅 |
| 6月 | 播种（韩国中部下旬、南部中旬起）、接种、盖稻草 | 在清晨或黄昏种植 |

| 8月 | 开花，监视豆荚野螟，采叶，检查根瘤 | 每天早上查看花中情况 |
| 9月 | 开始分批收获，装网袋晒干 | 不让成熟的豆荚在地里久留 |

### 17-1. 不能忘记的五件事

| 项目 | 内容 |

| 排水 | 耐旱最强，耐涝最弱。前提是垄高20cm |
