### 1-3. 強みをどう読むか

&nbsp;&nbsp;&nbsp;SSが付いた項目は施肥、施設負担、貯蔵性の三つで、Sはタンパク質密度、微量栄養素、水消費量、防除自立度、連作適応性、味、自家採種の七つに付きました。Sがこれほど多い豆類は珍しいです。

&nbsp;&nbsp;&nbsp;防除自立度Sがこの表の中で最も目を引きます。この作物表でこの項目にSを得た作物はごくわずかです。農薬が全くない条件でも耕種的手段だけで対処できるという意味で、実際にアフリカの小規模農家ではササゲはほとんど何も投入せずに栽培されています。原産地で人と長く共生してきた作物なのでその地域の病害虫と均衡を保っており、韓国では栽培の歴史が長くないため専門の病害虫自体の密度が低いのです。

&nbsp;&nbsp;&nbsp;連作適応性Sも豆類の中では珍しい値です。エンドウが5-7年、インゲンマメとヒヨコマメが3年を必要とするのに対し、ササゲはマメ科の中で連作耐性が最も良い部類に入ります。畑が狭くて輪作が難しい条件では、この差が配置の自由度を大きく広げます。さらに緑肥も兼ねるため、同じ場所に続けて植えつつ、ある年は種実を収穫し、翌年は開花期にすき込むという運用も可能です。

&nbsp;&nbsp;&nbsp;水消費量Sと痩せ地への適応力は合わせて読む必要があります。ササゲは年間降水量400-700mmのサバンナ気候に適応した植物で、pH4.5から8.0まで耐えます。砂地でも、何年も作り続けて痩せた土でも育ちます。この能力は条件の良い場所では表れません。条件が悪くなるほど他の作物との差が広がります。

> **ササゲの価値は、良い畑でどれだけ収穫できるかではなく、悪い畑でも収穫できるかにあります。干ばつの年、肥料が尽きた年、畑の隅の砂地でも、ササゲは依然として何かを実らせます。**

&nbsp;&nbsp;&nbsp;収穫速度Aにも大きな価値があります。80-90日で収穫でき、韓国では7月中旬から下旬まで播種できるため、他の作物が失敗した場所を埋めるのに使えます。リョクトウとともに、失敗した際の立て直し用に種子を残しておく価値のある作物です。

### 1-4. 弱みをどう読むか

&nbsp;&nbsp;&nbsp;Eが付いた項目は耐寒性の一つだけです。Dは面積当たり熱量、永続性、太陽光反応、調理・加工、整地エネルギー、非食用価値に、Cは病害虫圧に、Bは温度適応幅と韓国国内普及度に付きました。

&nbsp;&nbsp;&nbsp;韓国国内普及度Bが実務上まず最初にぶつかる壁です。ササゲは主に3-4道で栽培されており、主産地がはっきりしています。それ以外の地域では種子を入手するのが容易ではありません。ヒヨコマメやレンズマメほど難しくはありませんが、インゲンマメやリョクトウほど簡単でもありません。確保できたら自家採種でつないでいく必要があり、幸い自家受粉なので純系が保たれ、常温で3-4年もちます。

&nbsp;&nbsp;&nbsp;面積当たり熱量Dは1㎡で686kcal、自給ラインの0.26倍です。ササゲだけでは腹を満たせません。ただしこの数値は良い条件を想定したものであり、痩せて乾いた畑では他の作物の方がこれよりずっと大きく落ち込むため、相対的な位置は変わってきます。

&nbsp;&nbsp;&nbsp;耐寒性Eと湿害への弱さが合わさって栽培条件を狭めます。一度の霜で枯れ、逆に水が溜まると豆類の中で最も早く枯れ込みます。乾燥に強い作物が冠水に弱いのは偶然ではありません。乾燥したサバンナに適応した根の構造が、酸素のない土では耐えられないからです。ササゲ畑では畝を20cm以上高くすることは選択肢ではなく必須です。

&nbsp;&nbsp;&nbsp;病害虫圧Cと防除自立度Sが同時に付いているのは不思議に見えるかもしれません。病害虫は来るものの、農薬なしで抑えられるという意味です。ただし実務上注意すべき害虫が二つあります。莢に穴を開けて入り込むマメノメイガと、貯蔵中に豆を食い荒らすアズキゾウムシです。特にアズキゾウムシは半年以内に貯蔵したササゲを全て使い物にならなくすることがあるため、第15節で別途扱います。

## 2. どんな植物か

### 2-1. 分類と原産地

&nbsp;&nbsp;&nbsp;ササゲはマメ科(Fabaceae)ササゲ属(Vigna)の一年草です。アズキ、リョクトウと同じ属で、この三つは互いに近い親戚です。この事実が実用面で重要です。ササゲと組む根粒菌はBradyrhizobiumの仲間で、アズキやリョクトウが使う菌と通じます。アズキを育てた畑の土がそのままササゲの接種源になり、韓国ではアズキが広く栽培されているため接種源の確保は難しくありません。一方で病害虫やゾウムシも共有するため、アズキと隣り合わせに植えたり続けて植えたりしない方がよいでしょう。

&nbsp;&nbsp;&nbsp;原産地は西アフリカのサバンナです。雨季と乾季がはっきりしていて土地が痩せているその環境が、ササゲの性質のすべてを説明します。短い雨季の間に生育を終えようとして生育期間が短くなり、水が乏しいため根が深く伸びて葉が水を節約するようになり、土に養分がないため窒素固定能力が強くなりました。暑さには35℃まで耐え、逆に霜はまったく経験しません。

&nbsp;&nbsp;&nbsp;ササゲは自家受粉します。花は朝に咲きその日のうちに受粉が終わり、花びらが雌しべと雄しべを包みます。複数の品種を並べて植えても形質はほとんど混ざらず、採った種をそのまま蒔けば親と同じものができます。

### 2-2. 形態

| 器官 | 特徴 |
|---|---|
| 葉 | 三枚が一組になった三出複葉です。ハート形で厚みがあり、時に紫色を帯びます |
| 茎 | 直立型は50-80cm、つる性は2-3mまで伸びます。中間型の半直立型もあります |
| 根 | まっすぐな主根が深く入り込み、細根に太い根粒が付きます |
| 花 | 白色、薄紫、紫色の蝶形です。朝に咲きその日のうちにしぼみます |
| 莢 | 細長い円筒形で10-25cmに達します。種が10-20粒入ります |
| 種実 | 腎臓形で、へその部分に黒い縁取りがあるものが多いです。白色、赤色、黒色があります |

&nbsp;&nbsp;&nbsp;ササゲの葉が厚く表面につやがあることが、耐乾性の物理的根拠です。厚いクチクラ層が水分の蒸発を防ぎ、暑いときは葉を立てて日光を受ける面積を減らします。そして、この厚い葉が野菜としての価値も生み出します。茹でると柔らかくなり歯ごたえも良いので、ナムル(和え物)にして食べるのに適しています。

&nbsp;&nbsp;&nbsp;莢が長く種が10個から20個も入っていることも特徴です。一つの莢に一、二粒しか入らないヒヨコマメやレンズマメと比べると、一莢あたりの価値が大きいと言えます。面積当たりの収量が低いのは、着莢する株数が少ないためであり、莢自体が貧弱だからではありません。若い莢はまるごと食べられるため、アジアの一部では長さ30cmを超える専用系統を野菜として栽培しています。

### 2-3. 生育段階

| 段階 | 時期 | 主な生理 | 重要な養分 |
|---|---|---|---|
| 発芽・育苗期 | 播種から2週間 | 発芽が早いです。根が先に深く伸びます | リン酸、少量の窒素 |
| 栄養生長期 | 2-6週間 | 茎と葉が増え、根粒が活発になります | 窒素は根粒が供給 |
| 開花期 | 6-8週間 | 毎朝新しい花が咲きます | リン酸、ホウ素 |
| 莢肥大期 | 8-10週間 | 莢が長くなり、粒が太くなります | カリウム、リン酸 |
| 登熟・成熟期 | 10-13週間 | 下の莢から茶色く枯れていきます | カリウム、灌水停止 |

&nbsp;&nbsp;&nbsp;初期生育が遅いことを知っておく必要があります。ササゲは地上部を伸ばす前に、まず根を深く張ります。植えてから数週間目立って育たず失敗したように見えますが、その間に根はすでにかなり伸びています。この戦略が後の耐乾性につながります。ただし、その期間に雑草が先に居座るとササゲは負けてしまいます。播種後最初の5週間の雑草管理がササゲ栽培のほぼすべてだと言われるのはこのためです。

&nbsp;&nbsp;&nbsp;開花から成熟までは非常に早いです。花が散ってから8-15日で莢が熟します。そのため下の莢が熟している間も上では次々と新しい花が咲き続け、収穫は二、三回に分かれることになります。

&nbsp;&nbsp;&nbsp;初期の窒素について触れておくべきことがあります。根粒は播種直後から働くわけではありません。バクテリアが感染し、根粒ができて窒素を渡すまでに3週間かかります。その間、幼いササゲは種子の養分と土の窒素で持ちこたえます。ただしササゲは痩せ地への適応力に優れているため、この期間を他の豆よりうまく乗り切ります。元肥の窒素は0-2kgと豆類の中でも最も少なく設定されており、まったく施さなくても差し支えないことが多いです。

### 2-4. 100gあたりの栄養

| 栄養素 | 含有量 | 備考 |

| 熱量 | 343kcal | 乾燥種実基準です |
| タンパク質 | 19.61g | 熱量に占める割合は22.9%です |
| 脂質 | 1.5g前後 | 非常に少ないです。貯蔵中の酸敗が遅いです |
| 炭水化物 | 60-65g | 大部分がでんぷんです |
| 食物繊維 | 10-20g | 多いです |
| 糖類 | 0.44g | 甘みはほとんどありません |
| カリウム | 1,100mg前後 | |
| 鉄 | 5-8mg | 肉類がないときの重要な供給源です |
| カルシウム・マグネシウム | 豊富 | 骨と神経機能に関わります |
| 葉酸 | 豊富 | 貧血と胎児の発達に関わります |
| 葉（生） | ビタミンA、ビタミンC、鉄 | 乾燥種実にはない栄養素が葉にあります |

&nbsp;&nbsp;&nbsp;ササゲの栄養を見るとき、葉を除外すると半分しか見ていないことになります。乾燥種実にはビタミンCがありませんが、若葉にはたっぷり含まれており、ビタミンAの前駆体であるカロテンも葉にあります。アフリカでササゲの葉が重要な野菜とされているのはこのためであり、種実だけを数える栄養計算では表れない値です。災害時にササゲを育てるなら、種実を待つ夏の間ずっと葉を摘んで食べるのが正しいやり方です。

&nbsp;&nbsp;&nbsp;アミノ酸組成も見る価値があります。ササゲのタンパク質はリジンが豊富でメチオニンがやや不足しています。モロコシ、キビ、トウモロコシのような雑穀は正反対の特徴を持ちます。アフリカでモロコシとササゲを一緒に食べる食習慣、そして両方の作物を同じ畑に混植する配置は、この補完関係の上に成り立っています。韓国の食卓でも、雑穀ご飯にササゲを混ぜれば同じ効果が得られます。

&nbsp;&nbsp;&nbsp;脂質が1.5%前後と少なく、貯蔵に有利です。酸敗がほとんどないため、粉にしても長持ちします。熱量密度は低い代わりに、保管はしやすい部類です。
