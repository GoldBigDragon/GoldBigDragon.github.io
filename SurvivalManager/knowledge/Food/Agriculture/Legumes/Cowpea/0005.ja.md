## 8. 栽培管理

### 8-1. 最初の5週間がすべてです

| 時期 | 作業 | 要点 |
|---|---|---|
| 播種から出芽後2週間 | 1回目の除草 | 雑草が小さいうちに抜きます |
| 出芽後4-5週間 | 2回目の除草 | 土寄せを兼ねます |
| 開花前 | すべての除草を終えます | 開花後の除草は収量を減らします |
| 本葉2-3枚 | 間引き | 1穴あたり最も丈夫な1本だけを残します |

> **ササゲは植えて放っておいても何かしら収穫できる作物ですが、それは何もしなくてよいという意味ではありません。最初の5週間の雑草管理、これだけは行うべきです。**

&nbsp;&nbsp;&nbsp;ササゲは初期生育が遅いです。地上部を伸ばす前にまず根を深く張るためですが、その期間に雑草が先に居座るとササゲは押さえ込まれて回復できません。逆にこの5週間を過ぎて葉が地面を覆い始めると、その後は雑草と競い合うことはありません。半直立型とつる性は葉が広く広がり、自ら地面を覆ってしまいます。

&nbsp;&nbsp;&nbsp;除草は浅く行います。ササゲの細根は表層に広がっているため、鍬を深く入れると切れてしまいます。鍬を寝かせて土の表面2cmだけを削るようにして雑草を取り、株の近くは手で抜きます。播種後に藁やもみ殻を薄く敷いておくと、除草の回数を減らせます。

### 8-2. 葉摘みと芽摘み

| 作業 | 時期 | 要点 |
|---|---|---|
| 若葉の採取 | 本葉が何枚か出てから開花前まで | 下の方の成熟した葉を選んで摘みます |
| 摘心 | つる性が支柱の先端に達したとき | 側枝が増え、摘んだ芽はナムルになります |
| 採取の上限 | 1株で全体の葉の3分の1以内 | 摘みすぎると種実の収量が減ります |
| 中止する時期 | 開花が始まったら | それ以降は葉が莢を満たすために使われます |

&nbsp;&nbsp;&nbsp;葉を摘んで食べられることはササゲだけにある利点です。ただしバランスが必要です。葉は光合成の工場であるため、摘みすぎると種実の収量が落ちます。経験的な基準は、1株で全体の葉の3分の1を超えないことと、開花が始まったらやめることです。開花以降の葉は莢を満たす養分を作るために使われます。

&nbsp;&nbsp;&nbsp;摘み方にもコツがあります。一番上の新芽ではなく、下の方の育ちきった葉を選んで葉柄ごと摘みます。生長点に触れないようにすることで、株は成長を続けます。摘んだ葉はその日のうちに茹でて食べるか、量が多ければ茹でて干しておき、冬に使います。この話は第16節で詳しく扱います。

### 8-3. 倒伏管理

| 原因 | 対応 |
|---|---|
| 窒素過多 | 施肥量を守ります。ササゲでは窒素はほとんど必要ありません |
| 密植 | 1,000㎡当たり15,000株を守ります |
| つる性品種 | 支柱を立てるか直立型に変えます |
| 風雨 | 畑の周りに膝の高さでひもを張り巡らせます |
| 土寄せをしない | 2回目の除草のときに株元に土を寄せます |

&nbsp;&nbsp;&nbsp;直立型と半直立型のササゲは支柱を必要としません。茎がまっすぐで丈夫なため、自立します。つる性だけが2-3mまで育ち支柱を必要としますが、災害条件下であえてつる性を選ぶ理由は大きくありません。支柱の資材と労力を節約する方が総じて合理的です。

## 9. 病害虫

&nbsp;&nbsp;&nbsp;ササゲの防除自立度はSで、この作物表の中でも指折りの値です。農薬が全くなくても耕種的手段だけで対処できるという意味です。ただし注意すべき害虫が二つあります。畑ではマメノメイガ、貯蔵庫ではアズキゾウムシです。

### 9-1. 主な病害

| 病名 | 症状 | 発生条件 | 農薬なしでの対応 |
|---|---|---|---|
| 萎凋病・根腐れ病 | 株が萎れて枯れ、茎の根元が茶色く軟らかくなります | 過湿、連作 | 排水と畝を高くすることがほぼすべてです |
| うどんこ病 | 葉の表面が白い粉で覆われます | 乾燥していて寒暖差が大きいとき | 風通しの確保、牛乳5-10倍希釈液 |
| さび病 | 葉に橙色の粉の塊ができます | 生育後期の多湿 | 病葉の除去、風通しの確保 |
| モザイクウイルス病 | 葉がまだらになって縮れ、生育が止まります | アブラムシが媒介します | 治療はできません。抜いて燃やし、アブラムシを減らします |
| 細菌性葉枯病 | 葉に角ばった茶色の斑点ができます | 風雨で広がります | 雨の後は畑に入りません |

&nbsp;&nbsp;&nbsp;ササゲの病害の大部分は水に関係します。萎凋病と根腐れ病が最も多くて最大の損失を出しますが、どちらも過湿から来ます。畝を20cm以上高くし、排水路を確実に設けるという一つの対策が、ササゲの病害管理の半分を占めます。薬を作ったり撒いたりするよりも、スコップで土を動かす方が効果の大きい場合です。

### 9-2. 主な害虫

| 害虫 | 被害 | 農薬なしでの防除 |
|---|---|---|
| マメノメイガ | 幼虫が花と若い莢の中に入り込み種実を食べます。畑での最大の害虫です | 開花期から毎朝花と若い莢を確認し、幼虫を捕まえます。被害を受けた莢は摘み取って処分します |
| アズキゾウムシ | 畑で莢に卵を産みつけ、貯蔵中に種実を食い荒らします。半年で全量が被害を受けることもあります | 適期に収穫し、完全に乾燥させてから密閉します。第15節参照 |
| カメムシ類 | 莢を刺して汁を吸い、しいな（不稔粒）にします | 朝露のある早朝に手で捕まえます |
| アブラムシ | 汁を吸い、ウイルスを媒介します | 石けん水（水1Lに石けん5g）、強い水流での洗い流し |
| 鳥 | 浅く埋まった種子や若い芽を食べます | 発芽まで藁や網で覆います |

> **マメノメイガは花の中から始まります。莢が目に見える頃には、すでに中に入り込んでいます。開花期に毎朝花をのぞき込む習慣が、この害虫に対する最も確実な対応です。**

&nbsp;&nbsp;&nbsp;マメノメイガはササゲとともにアフリカから来た専門害虫で、花弁の内側に卵を産みつけ、孵化した幼虫が花と若い莢の中に食い込みます。外見は無事な莢を割ってみると、中に幼虫がいて卵はありません。農薬なしで対処する方法は三つあります。第一に、開花期の早朝に花を調べ、内側に幼虫がいればその花を摘み取ります。第二に、被害を受けた莢を見つけ次第摘み取り、畑の外で処分します。第三に、バジルやダイズを間作すると被害が減るという報告があります。

### 9-3. 農薬なしで行う防除資材

| 資材 | 作り方 | 対象 | 注意 |
|---|---|---|---|
| 石けん水 | 水1Lに無香料石けん5g | アブラムシ、ハダニ | 日中の暑いときに撒くと葉が焼けます |
| 乾いた灰まき | 露のある朝に葉に細かい灰をまきます | 葉を食べる虫、カビ | 雨が降ると洗い流されます |
| 草木灰水 | 灰1升を水10Lに一晩浸け、上澄みを使います | カビの抑制 | アルカリ性なので薄めて使います |
| ボルドー液 | 水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜます | 細菌病、カビ病 | 銅がないと作れません |
| 木酢液 | 炭を焼くときに出る液を300-500倍に希釈します | 忌避、生育促進 | 原液は強酸性なので必ず希釈します |
| 唐辛子・ニンニク水 | すりつぶして水に浸け、こして使います | 蛾の忌避 | 効果が長続きしないため頻繁に散布します |
| 牛乳希釈液 | 牛乳を水で5-10倍に希釈します | うどんこ病 | 残すと傷んで臭いが出ます |

### 9-4. 耕種的防除

| 方法 | 原理 |
|---|---|
| 排水と畝 | ササゲの病害の大部分は過湿に関係します。最も効果の大きい一つです |
| 開花期の朝の見回り | マメノメイガは花の中から始まります。そのときに捕らえるのが唯一の機会です |
| 適期収穫 | 熟した莢を畑に長く置くとゾウムシが卵を付けます |
| バジル・ダイズの間作 | 害虫の発生が減るという報告があります |
| 植栽密度を守る | 風通しが良いと葉が早く乾き、カビが定着できません |
| 種子選別 | 虫食いの種子を植えると最初から害虫を持ち込むことになります |
| 雨の後は畑への立ち入り禁止 | 濡れた葉に人が触れると細菌病が広がります |
| 残渣処理 | 病気の残渣は燃やし、健康な残渣だけを畑に戻します |

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然材料での対応 |
|---|---|---|
| 葉全体が薄い黄色で、個体が小さい | 窒素欠乏。ササゲでは湿害で根粒が死んだ場合が最も多いです | まず根を掘って根粒を確認します。排水を直し、尿10倍希釈液を少量与えます |
| 生育が遅く葉が紫色を帯びる | リン酸欠乏。痩せ地で最も多い欠乏です | 骨粉、焼いた魚の骨の粉。ササゲで最初に確保すべき元素です |
| 葉の縁が茶色く枯れる | カリウム欠乏 | 草木灰を株の間にまき、軽く土に混ぜ込みます |
| 花は咲くが莢が付かない | ホウ素欠乏、またはマメノメイガ | まず花の中を確認します。害虫でなければ複数の材料を混ぜた堆肥を施します |
| 葉脈の間が黄色い | 鉄またはマンガンの欠乏。アルカリに傾いた土壌で多いです | 灰の使用をやめます。腐葉土と完熟堆肥で有機物を増やします |
| 茎と葉ばかり茂って莢が少ない | 窒素過剰 | 窒素の供給を直ちに中止します |

&nbsp;&nbsp;&nbsp;ササゲで最も多い欠乏はリン酸です。痩せた畑に植える作物であるだけに、その畑にリン酸がない場合が多く、窒素は自分で作れてもリン酸はそうできないためです。生育が遅く葉が紫色を帯びたら、リン酸欠乏を疑います。化学肥料なしでリン酸を得る手段は、骨粉と魚の骨しかありません。獣の骨を集めて火で焼いて砕けるようにし、臼で挽いて堆肥に混ぜておくと、何年もかけてゆっくりと放出されます。

&nbsp;&nbsp;&nbsp;微量元素の欠乏は一つずつ対応するのが難しいです。化学肥料なしでモリブデンやコバルトを得る方法は事実上ありません。その代わり、野菜くず、果物の皮、卵の殻、魚の骨、落ち葉、雑草、灰を一緒に混ぜて腐らせた堆肥には微量元素がまんべんなく含まれています。堆肥場に何でも入れるという原則が、微量元素管理の実質的な戦略です。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 作物 | 理由 |
|---|---|---|
| 良い | トウモロコシ・モロコシ・キビ | ササゲが窒素を分け与え、アミノ酸組成が互いを補います |
| 良い | バジル | 害虫の発生がはっきり減るという報告があります |
| 良い | オオムギ・コムギ・ニンニク・ジャガイモ | 前作にしておけば6月に畑が空き、後作としてササゲを植えます |
| 良い | ハクサイ・ダイコン | ササゲの後に植えると残った窒素を使えます |
| 普通 | ダイズ | 害虫減少効果が報告されていますが、同じマメ科なので病気が重なります |
| 悪い | アズキ・リョクトウ | 同じ属なので病原菌とアズキゾウムシをそのまま共有します |
| 悪い | 水を多く与える作物 | ササゲは過湿に最も弱いです |

&nbsp;&nbsp;&nbsp;ササゲとモロコシまたはキビの組み合わせは、アフリカで数千年続いてきた配置です。雑穀が上の光を使い、ササゲが下を覆い、ササゲが固定した窒素の一部が雑穀に流れます。栄養の面でも互いを補います。雑穀はリジンが不足しササゲは豊富であり、ササゲはメチオニンが足りず雑穀はそうではありません。同じ畑から採れた二つの作物を一つの器に盛れば、タンパク質組成が完成します。韓国でモロコシやキビやアワを育てるなら、その間にササゲを入れる配置がそのまま当てはまります。

&nbsp;&nbsp;&nbsp;アズキやリョクトウを隣に置かない方がよいです。同じササゲ属なので病原菌を共有し、何よりアズキゾウムシが三つの作物の間を行き来します。同じ畑で一緒に育てると、貯蔵庫でのゾウムシ被害が倍加します。

### 11-2. 輪作

| 項目 | 基準 |
|---|---|
| 休作期間 | 2-3年。マメ科の中で連作耐性が最も良い部類です |
| 理想的な周期 | 3年 |
| 連作障害 | 萎凋病と線虫が蓄積します。他のマメ科より蓄積が遅いです |

| 3年輪作の例 |
|---|
| 1年目: 大麦またはニンニク（冬）の後にササゲ（夏） |
| 2年目: モロコシまたはトウモロコシ |
| 3年目: ハクサイ・ダイコンの仲間またはジャガイモ |
| 再びササゲ |

&nbsp;&nbsp;&nbsp;ササゲは連作適応性Sで、豆類の中で最も余裕があります。畑が狭くて輪作が難しい条件では、これは大きな利点になります。痩せた一区画をササゲに割り当てて何年か続けて植えながら、ある年は種実を収穫し、次の年は開花期にすき込んで緑肥として使う方式も可能です。そうして二、三年が過ぎると、その区画の土は目に見えて変わり、そのとき他の作物を導入できます。

> **ササゲは畑を立て直す作物です。他のどんな作物も育たない区画をササゲで二、三年回せば、窒素と有機物が蓄積し、その畑がよみがえります。**
