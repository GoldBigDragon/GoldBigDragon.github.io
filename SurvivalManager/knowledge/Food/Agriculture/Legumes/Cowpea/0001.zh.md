## 引言
&nbsp;&nbsp;&nbsp;豇豆（Vigna unguiculata）是在撒哈拉以南干旱的稀树草原被驯化的、原产于西非的豆科一年生草本。它最突出的优点是耐瘠薄、耐干旱：年降水量400mm也能结籽，在pH 4.5的强酸性土里也能生长，总蒸散量250mm即可完成一个生长季，所以水消耗量为S，防治自立度S也是豆类中最高的值。其他豆类所没有的一点是可以吃叶，会依次提供嫩叶、嫩荚和干籽粒。综合等级为C（43.0分，有效183种中第82名），短期C（41.3）、长期B（44.8），副食为SS（64.2分）。单位面积热量为D，每㎡ 686kcal，仅为自给线的0.26倍；耐寒性为E，一次霜冻就会枯死；耐旱的同时，它在豆类中最怕积水。国内种植普及度为B，在3-4个道（韩国行政区）之外不易弄到种子，如果已经确保，就要靠自留种继续种下去。豇豆的位置不是好田的主作物，而是沙地、干燥的坡地、瘠薄地块等其他作物长不了的地方。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | C | 43.0 |
| 短期 | C | 41.3 |
| 长期 | B | 44.8 |
| 副食 | SS | 64.2 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：施肥、设施负担、耐储性。S：蛋白质密度、微量营养素、水消耗量、防治自立度、连作适应性、口味、自留种。A：收获速度、无合成投入产量保持率、产量稳定性、种子寿命 |
| 劣势 | E：耐寒性。D：单位面积热量、持续性、光照、烹调·加工要求度、整地·挖掘能量、非食用价值。C：病虫害压力。B：温度幅度、国内种植普及度 |

> **豇豆的价值不在于好田里能收多少，而在于坏田里能不能收。干旱的年份，肥料用尽的年份，在田角的沙地上，豇豆依然会给出点东西。**

&nbsp;&nbsp;&nbsp;防治自立度S意味着没有药剂也能只靠栽培措施应付，连作适应性S在豆类中最为从容。收获速度A指80-90天即可收获、可播种到7月中下旬，能填补失败的地块。病虫害压力C可以不用药剂控制，但豇豆荚螟和绿豆象这两种害虫需要小心。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 豆科豇豆属一年生草本。原产于西非稀树草原，自花授粉 |
| 叶、茎 | 叶为三小叶一组的三出复叶，厚而有光泽 |
| 根、花 | 笔直的主根深入土中，须根上长着粗大的根瘤。花为白色、淡紫色或紫色的蝶形花，早晨开放，当天凋谢 |
| 荚、籽粒 | 细长圆筒形，10-25cm，每荚10-20粒。籽粒呈肾形，脐周常有黑圈，有白色、红色、黑色 |

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 发芽、幼苗期 | 播种后2周 | 发芽快，但地上部生长慢，根先向深处扎下 |
| 营养生长期 | 2-6周 | 茎叶增多，根瘤活跃起来 |
| 开花期 | 6-8周 | 每天早晨开新花 |
| 鼓荚期 | 8-10周 | 荚变长，籽粒变大 |
| 灌浆、成熟期 | 10-13周 | 从下部的荚开始变成褐色干枯 |

&nbsp;&nbsp;&nbsp;豇豆厚实的叶子能防止水分蒸发，使其耐旱，焯过之后变得柔嫩，成为蔬菜。从开花到成熟只要8-15天，非常快，下部的荚成熟时上部仍不断开新花，所以收获分两三次进行。干籽粒每100g热量343kcal，蛋白质19.61g（占热量的22.9%），脂肪约1.5g，碳水化合物60-65g，膳食纤维10-20g，钾约1,100mg，铁5-8mg，富含钙和镁，脂肪少，所以酸败慢。干籽粒所没有的维生素C和胡萝卜素存在于嫩叶中。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽12-15℃以上（最适25-30℃）。生长15-40℃（最适20-35℃），是豆类中最耐高温的。结实20-32℃。没有耐寒性，一次霜冻就会枯死 |
| 土壤 | 排水良好的沙土或沙壤土（从沙地到黏土都能适应），pH 4.5-8.0（最适5.5-7.0，豆类中最宽），有效土层30cm以上（最适50cm）。被水淹一天以上就会死 |

> **最耐旱的豇豆，却最怕被水淹。为干燥的稀树草原而生的根，受不了积水、没有氧气的土壤。在豇豆田里，垄和排水沟不是选项，而是前提。**

&nbsp;&nbsp;&nbsp;凭借耐高温的能力，可以在盛夏播种，也能种在没有施过石灰的酸性田里。在国内，生育期与雨季重叠是最大的难点，所以要把不积水的地方、坡地的话把上部分配给豇豆。

| 类型 | 株高、支柱 | 特点 |
|:---|:---|:---|
| 直立型 | 50-80cm，不需要 | 抗倒伏，收获方便。早熟型80天即可结束 |
| 半直立型 | 80-120cm，通常不需要 | 产量高，省事，叶多，适合摘叶 |
| 蔓生型 | 2-3m，需要 | 收获期长，但需要支柱材料和劳力 |

&nbsp;&nbsp;&nbsp;已知的国内育成品种有全南1号、全南2号（半直立型）和Okdang、Seonhyeon（直立型）。灾害情况下，不需要支柱的直立型或半直立型比较合理，霜来得早的地区选早熟直立型。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 深耕20-30cm并整平。垄高20cm以上（防涝的关键），排水沟深30cm以上，让水能一直排走，并在雨季前灌水检查。充分腐熟的堆肥1,000-1,500kg/1,000㎡ |
| 施肥（1,000㎡） | 氮0-2kg（豆类中最少，多施则只长茎叶、荚减少、病害增多），磷4-7kg（均作基肥，用骨粉或烤过的鱼骨粉补充），石灰200kg仅在pH 5.5以下时施用（播种前3-4周） |
| 根瘤接种 | 取种过红豆、绿豆、豇豆的田里5-15cm深的表土，在阴凉处裹在用水稍微润湿的种子上，30分钟内播下（菌怕直射阳光、干燥和高温）。野生红豆根上的根瘤也可使用。大豆或豌豆田里的土效率较低，病田里的土还会带来病原菌 |

&nbsp;&nbsp;&nbsp;接种在积水的田、缺磷的田，以及土表超过60℃的盛夏烈日下会失败，所以在清晨或傍晚播种。开花前后（播种后6周左右），用铁锹连土挖起、洗净，剖开根瘤。每株20个以上、内部呈红色，说明接种顺利；白色或浅绿色的，要检查涝害和缺磷；褐色或黑色的已经死亡（雨季之后就是涝害）；5个以下是接种失败，叶发黄时补充少量氮。雨季前后各检查一次。

&nbsp;&nbsp;&nbsp;每公顷固氮量在条件好时为80-120kg（涝害使根瘤死亡时15-30kg），随籽粒带走55-70kg，所以氮平衡在豆类中最为从容，也可用作绿肥。脱粒后剩下的茎叶全部还回田里，不挖根，摘叶带走的那一份要用堆肥还回去。

| 播种 | 标准 |
|:---|:---|
| 时期 | 中部6月下旬-7月上旬（极限7月中旬），南部6月中旬-7月中旬（极限7月下旬）。9月中旬-10月上旬收获。极限日期是从预计初霜日往前倒数90天的日子 |
| 种子准备 | 弃去有虫孔、变色、皱缩的种子。在水中浸3-4小时，只用沉底的，放在50-55℃水中浸10-15分钟消毒。接种不要与消毒同时进行。发芽试验是用湿布包20粒，放三四天后数 |
| 方法 | 深1-3cm（过深则发芽变差），每穴2-3粒，行距60-70cm，目标密度每1,000㎡ 15,000株。每1,000㎡播种量：单作1.5-2kg，后茬·晚播2-3kg |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种至发芽 | 不要让土壤彻底干掉（播得浅，表层一干发芽就会停止） |
| 生长初期至开花前 | 靠自然降水（干燥会把根逼向深处） |
| 雨季 | 挖排水沟（最危险的阶段） |
| 灌浆期 | 停止灌溉（成熟的荚被淋湿会发霉） |

> **豇豆的水分管理不是给的技术，而是排的技术。干旱它自己能扛，但积水几天就会死。**

&nbsp;&nbsp;&nbsp;中午叶片合拢、傍晚展开，是抑制蒸腾的正常反应，早晨还合拢着时才是真的缺水。下部叶发黄、根发黑，是过湿造成的烂根，所以要挖排水沟并培土。

| 管理 | 方法 |
|:---|:---|
| 除草 | 出苗后2周第1次（趁杂草还小），4-5周第2次（与培土同时），开花前完成所有除草，真叶2-3片时每穴只留最壮的1株。须根在表层，所以把锄放平，只刮表面2cm，靠近植株的用手拔。过了5周、叶片盖住地面，就不再与杂草争夺 |
| 摘叶 | 从长出若干真叶之后到开花前，不摘新芽，摘下部长成的叶，连叶柄一起摘（不碰生长点）。每株不超过全部叶片的三分之一，开花开始就停止 |
| 倒伏 | 原因是氮过量和密植，所以要遵守施肥量和密度。担心风雨时，沿田边在膝高处拉绳，并在第2次除草时在基部培土 |

> **豇豆种下后放着不管也会有些收成，但这不等于什么都不用做。头5周的杂草管理，只有这一件事必须做。**

## 6. 病虫害与养分问题
| 病虫害 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 枯萎病、根腐病 | 植株萎蔫枯死，茎基部变褐变软。过湿和连作 | 排水和起高垄几乎就是全部 |
| 锈病、细菌性叶枯病、花叶病毒 | 叶上有橙色粉堆（生长后期湿度大） / 叶上有角状褐斑（随风雨扩散） / 叶片斑驳皱缩，生长停止（由蚜虫传播） | 摘除病叶并保证通风 / 雨后不进田 / 无法治疗，所以拔除烧掉，并用肥皂水（每1L水加肥皂5g）减少蚜虫 |
| 豇豆荚螟 | 产在花瓣内侧的卵孵出的幼虫钻进花和嫩荚里吃籽粒，是田里最大的害虫 | 从开花期起每天早晨检查花和嫩荚，发现幼虫就摘下，在田外处理 |
| 绿豆象 | 在田里于荚上产卵，储存期间蛀食籽粒，半年就会全部受害 | 适时收获，完全晒干后密封（见第9节） |
| 蝽类、鸟 | 刺吸荚果使其成为空荚 / 啄食播得浅的种子和幼芽 | 趁清晨有露水时徒手捉 / 到发芽前盖上稻草或网 |

&nbsp;&nbsp;&nbsp;波尔多液是将硫酸铜400g和生石灰400g分别溶于100L水中再混合，用于细菌病和真菌病；在有露水的早晨撒在叶上的干草木灰，能减少食叶害虫和霉菌。病残体要烧掉，只把健康的残体还回田里。

| 症状 | 原因与对策 |
|:---|:---|
| 整片叶淡黄、植株矮小 | 缺氮（涝害使根瘤死亡的情况最常见）。先挖出根检查根瘤，改善排水后施少量稀释10倍的人尿 |
| 生长迟缓、叶发紫 | 缺磷，在瘠薄地上最常见。首先准备骨粉、烤过的鱼骨粉 |
| 开花却不结荚 | 缺硼、开花期极度干旱，或豇豆荚螟。先查看花里面，不是的话施用多种材料混合的堆肥 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 玉米、高粱、黍（分享氮，豇豆富含赖氨酸而杂粮富含蛋氨酸，互相弥补）、罗勒（有减少害虫的报告）、大麦、小麦、大蒜、马铃薯（作前茬时6月田里空出，可作后茬种豇豆）、大白菜、萝卜（利用豇豆之后残留的氮） |
| 差 | 红豆、绿豆（同属，所以共有病原菌和绿豆象）、需要大量浇水的作物（豇豆最怕过湿） |

&nbsp;&nbsp;&nbsp;休耕为2-3年，理想周期为3年，枯萎病和线虫会积累，但比其他豆科积累得慢。3年轮作的例子是：第1年大麦或大蒜（冬）之后种豇豆（夏） → 第2年高粱或玉米 → 第3年大白菜·萝卜类或马铃薯 → 再种豇豆。在瘠薄地块上，也可以一年收籽粒，次年在开花期翻压作绿肥。

> **豇豆是把田改良回来的作物。把其他任何作物都长不了的地块用豇豆轮种两三年，氮和有机物积累起来，这块田就会复活。**

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 嫩叶在真叶展开之后到开花前；嫩荚在播种后45-60天、荚还细嫩时；干籽粒早熟种75-90天、晚熟种90-125天，荚变褐、籽粒变硬时。开花后8-15天成熟，所以分2-3次摘 |
| 要领 | 在晴朗干燥、露水已干之后，只用手拧摘变成褐色的荚。把荚摊在网或席子上，在阳光下晒3-5天，时常抖动 |
| 脱粒、精选 | 踩踏装袋（少量）、装进网里用棒子敲打（籽粒不会漏）、连枷（不用力、打多次，中等规模）、手剥（每荚10-20粒，进度快，适合留种）。用筛子筛去裂粒，在水中捞去浮起的空瘪粒和虫蛀粒，当天内重新晒干 |

> **在田里熟了还长久挂着的荚，会造成储藏库里的豆象危害。对豇豆来说，适时收获是半年后还有没有粮食的问题。**

| 留种 | 标准 |
|:---|:---|
| 选株、收获 | 预先在田里标记没有病症、荚多、没有倒伏的植株。荚完全变褐后立即摘下，用手剥，使籽粒不破裂 |
| 精选、干燥 | 弃去虫孔、斑点、裂粒、变色的。豆象的卵以极小的白点附着在种皮上，从外面不易看出，所以用眼和手挑选（留种用的不要用水浮选），含水量12%以下，完全晒干 |
| 保存 | 密封后常温3-4年。低温处理（见第9节）能杀死豆象的卵和幼虫，且不损害发芽力。收获和储存要与红豆、绿豆分开，以免种子混杂 |

## 9. 储存
| 步骤 | 方法 |
|:---|:---|
| 干燥 | 食用和留种都要含水量12%以下，用牙咬不留齿痕、脆脆地裂开。完全冷却后再装 |
| 绿豆象防治 | 一代不到一个月，籽粒大的豇豆一粒里能长出好几只。三层袋（三层厚塑料袋，各自把口扎紧）能隔绝氧气使虫窒息，老鼠会咬穿，所以放在老鼠够不到的桶里或架子上。油涂层是每1kg豆加食用油2-5mL（留种用的除外）。低温处理是隆冬放到室外几天再拿回来，拿回来时不要打开容器，放几个小时等到与室温一致 |
| 容器、检查 | 玻璃瓶和金属桶3年以上，三层塑料袋1-2年。把耳朵贴在容器上，有沙沙声说明虫在活动，有霉味是发霉的开始，表面有小圆孔说明豆象已经过了一代。每月检查一次，有危害就全部取出晒干，在水中捞去浮起的空粒，拌入草木灰后重新密封 |

> **豆子不是烂掉而损失，而是被虫吃掉而损失。对豇豆来说，储存和栽培一样重要。**

## 10. 烹调与注意事项
| 成分 | 作用 | 去除方法 |
|:---|:---|:---|
| 胰蛋白酶抑制剂 | 阻碍蛋白质分解酶，引起腹痛、腹泻、蛋白质利用率下降 | 浸泡6小时后，在沸水中煮1小时 |
| 低聚糖 | 肠内细菌发酵，使肚子胀气 | 浸泡后倒掉浸泡的水 |

> **豇豆叶也不能生吃。含有草酸和少量抗营养成分，所以一定要焯过再吃，焯叶子的水要倒掉。**

&nbsp;&nbsp;&nbsp;豇豆在豆类中毒性风险较低，没有菜豆那样强的凝集素，也没有蚕豆那种引起急性溶血的成分，但含有抗营养成分，所以要充分煮熟。

| 处理 | 标准 |
|:---|:---|
| 籽粒基本处理 | 在常温水中浸泡6小时，种皮变软，煮熟时间缩短。在沸水中煮1小时 |
| 去皮掰开 | 泡后在臼里轻轻捣一下去皮，掰成两半晒干，20-30分钟就能煮熟。只加工一两个月吃的量 |
| 节省燃料 | 压力烹调是将泡好的豆加压15分钟。余热烹调是煮15分钟后熄火，用稻草·稻壳箱或被褥把锅整个包起来放2-3小时。炒后磨成的粉冲水喝。发芽后会生成维生素C |
| 叶、嫩荚 | 叶用流水冲洗，在沸水中焯1-2分钟，用冷水冲后用力挤干，用盐、油、大蒜或大酱拌。嫩荚焯几分钟就可以整个吃 |
| 储存加工 | 焯过晒干的叶（到冬天，作干菜）、炒后磨成的豇豆粉（密封3-6个月）、去皮掰开的豇豆（密封1-2个月）、焯过晒干的嫩荚（几个月）、煮烂捣碎发酵的豇豆大酱（大豆不足时的替代品） |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存、低温处理、种子发芽试验。2月做田地规划，把瘠薄地块分配给豇豆 |
| 3-4月 | 3月翻堆堆肥、准备骨粉。4月管理前茬，规划20cm的垄和排水沟 |
| 5-6月 | 5月整地、起垄、开排水沟。6月播种（中部下旬，南部从中旬起）、接种、盖稻草 |
| 7-8月 | 7月第1、2次除草、间苗、晚播极限。8月开花、监视豇豆荚螟（每天早晨检查花里面）、摘叶、检查根瘤 |
| 9-10月 | 9月开始分批收获，装网晾干。10月收获收尾、脱粒、精选、茎叶还田（在霜前结束） |
| 11-12月 | 11月干燥、储存、晒叶子做干菜。12月检查储存、加工、规划来年 |

> **豇豆只要做好排水、备足磷、头5周除草、开花期检查花里面、完全晒干并密封，就是在其他作物长不了的田里，也会依次提供叶、嫩荚和籽粒的作物。**
