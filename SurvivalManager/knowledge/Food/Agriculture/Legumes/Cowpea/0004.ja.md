## 5. 畑の準備と肥料 - 窒素収支と施肥

### 5-4. 窒素固定の落とし穴

&nbsp;&nbsp;&nbsp;豆を植えると土が良くなるという話は、農業の常識として定着しています。半分は正しく、半分は間違っています。この点を正確に理解していないと、マメ科作物を何年も続けて植えた畑がかえって痩せていくということが起こります。

&nbsp;&nbsp;&nbsp;数字で見てみましょう。ササゲがよく育てば、1,000㎡で200kgの乾燥種実を収穫します。ササゲ種実のタンパク質は19.6%で、タンパク質を6.25で割ると窒素量が出ます。19.6 ÷ 6.25は3.14、つまり種実重量の約3.1%が純粋な窒素です。200kgに含まれる窒素は約6.3kgで、ヘクタールに換算すると63kgです。

&nbsp;&nbsp;&nbsp;一方、ササゲの根粒が固定する窒素は、条件が良ければ1ヘクタール当たり80-120kgです。痩せ地に適応した作物らしく、マメ科の中でも高い部類です。出ていくものと入ってくるものを並べると、次のようになります。

| 項目 | ヘクタール当たり窒素 | 方向 |
|---|---|---|
| 根粒固定量（条件が良い場合） | 80-120kg | 入る |
| 根粒固定量（湿害で根粒が死んだ場合） | 15-30kg | 入る |
| 種実として搬出 | 55-70kg | 出る |
| 茎葉（茎と葉）に残る窒素 | 25-40kg | 畑に戻せば残る、燃やすか持ち出せば出る |
| 根と根粒に残る窒素 | 10-20kg | 大抵畑に残ります |

&nbsp;&nbsp;&nbsp;ササゲは豆類の中でも窒素収支が最も余裕のある部類に入ります。固定量が搬出量よりはっきり多く、茎葉だけを畑に戻しても窒素が畑に残ります。評価表で施肥SSと合わせて緑肥兼用と記されている根拠であり、実際にアフリカや米国南部ではササゲが緑肥専用としても広く使われています。

> **マメ科作物が土地を良くするのは、窒素を固定するからではなく、固定した窒素の一部を茎と葉に蓄えて畑に残すからです。その茎と葉を持ち出してしまえば、豆は土地を収奪する作物になります。**

&nbsp;&nbsp;&nbsp;ただしササゲには一つ注意すべき点があります。葉を野菜として摘んで食べるということです。葉には窒素がかなり含まれているため、葉を摘んで畑の外に持ち出した分だけ窒素が出ていきます。少量なら問題になりませんが、葉を主な野菜として摘み続けると、それだけ茎葉に残る窒素が減ります。葉を食べた後に出た生ごみや人の排泄物を堆肥にしてその畑に戻す循環を念頭に置く必要があります。

| 原則 | 内容 |
|---|---|
| 茎葉は必ず畑へ | 脱穀した後に残った茎と葉をすべて畑に戻します |
| 燃やさない | 燃やすと窒素が気体になって飛び、カリウムとリン酸だけが灰に残ります |
| 根は掘り出さない | 根と根粒の窒素は最も手軽に残せる分です |
| 葉を多く摘むなら循環を考える | 葉として出た窒素の分だけ堆肥で戻します |
| 緑肥として使う場合 | 開花期にすき込めば1ヘクタール当たり80-120kgの窒素が畑に残ります |
| 家畜に与えたなら糞を戻す | 茎葉を家畜に与えたなら、その家畜の糞尿を必ずその畑に入れます |

### 5-5. 畑の準備

| 項目 | 方法 | 災害条件下では |
|---|---|---|
| 耕起 | 20-30cmの深さで耕し、均一に整地します | 前作を収穫した跡地なら、畝の部分だけ掘り返しても構いません |
| 畝 | 高さ20cm以上 | 湿害防止の要です |
| 排水路 | 深さ30cm以上、最後まで水が抜けるように | 梅雨前に水を流して確認しておきます |
| 酸度矯正 | pH5.0-8.0に適応 | 適応幅が広く急ぎません |
| 石灰 | pH5.5未満のとき200kg/1,000㎡ | 貝殻や卵の殻を焼いて砕いたもの、または草木灰で代用します |
| 有機物 | 完熟堆肥1,000-1,500kg/1,000㎡ | 痩せ地でも育ちますが、入れると収量が上がります |

&nbsp;&nbsp;&nbsp;ササゲはpH適応幅が4.5-8.0と豆類の中で最も広く、石灰処理の優先順位は低いです。畑がひどく酸性でなければ石灰なしでも育ちます。石灰を節約して他の作物、例えばエンドウやダイズの畑に使う方が全体として合理的です。

&nbsp;&nbsp;&nbsp;代わりに排水に力を入れる必要があります。深く耕して水が下へ抜ける道を作り、畝を高くし、排水路を深く掘ります。畑を選ぶ段階から水が溜まらない場所を選ぶのが最も確実で、傾斜のある畑なら上側がササゲの場所です。

### 5-6. 施肥量

| 肥料 | 1,000㎡基準 | ㎡換算 | 備考 |
|---|---|---|---|
| 窒素 | 0-2kg | 0-2g | 豆類の中で最も少ないです。まったく入れなくても構いません |
| リン酸 | 4-7kg | 4-7g | 全量元肥です。痩せ地での根粒の発達に不可欠です |
| カリウム | 3-5kg | 3-5g | 全量元肥です |
| 堆肥 | 1,000-1,500kg | 1-1.5kg | 完全に発酵したものを使います |
| 石灰 | pH5.5未満に200kg | 200g | 播種3-4週間前 |

> **ササゲは窒素肥料がほとんど要らない作物です。むしろ窒素を与えると茎と葉ばかりが茂り莢が減り、風通しが悪くなって病気が増えます。痩せた畑に植えるのがこの作物の本来の用途です。**

&nbsp;&nbsp;&nbsp;リン酸は違います。痩せた畑でササゲの収量を実際に左右するのはリン酸です。窒素固定には多くのエネルギーが必要で、その代謝にリン酸が使われるため、リン酸が不足すると根粒ができてもその役割を果たせません。化学肥料がない条件でリン酸を得る手段は、事実上骨粉と魚の骨がほぼすべてです。痩せた畑にササゲを植えるとき、何よりもまず確保すべきなのがこのリン酸です。

&nbsp;&nbsp;&nbsp;追肥は原則として必要ありません。生育が明らかに悪いときに限り、尿を水で10倍に薄めて株の間の土にごく少量注ぎます。葉に触れないようにし、葉の色が濃く茂っているなら与えません。

### 5-7. 災害時の代替肥料

| 代替資源 | 供給養分 | 使用法 | 注意 |
|---|---|---|---|
| 骨粉 | リン酸、カルシウム | 焼いて砕き堆肥に混ぜます | 痩せ地のササゲにとって最も重要な資源です |
| 魚の骨・魚の内臓 | リン酸、窒素 | 埋めて腐熟させてから使います | そのまま埋めると動物に掘り出されます |
| 草木灰 | カリウム、リン酸、カルシウム | ㎡当たり100-150gをまいて混ぜます | ササゲはアルカリにも耐えるので余裕があります |
| 完熟堆肥 | 総合 | ㎡当たり1-1.5kgを元肥として入れます | 未熟なものは根を傷め病気を運びます |
| 薄めた尿 | 窒素、カリウム | 水で10倍に薄めて株の間の土に注ぎます | ごく少量のみ。大抵は必要ありません |
| 貝殻・卵の殻 | カルシウム | 焼いて砕いてまきます | pH5.5未満のときのみ |
| 前作の残渣 | 有機物 | 大麦わらやニンニクの茎をマルチングを兼ねた肥料として敷きます | ササゲは後作として植えることが多いです |
| もみ殻・稲わら | カリウム、ケイ酸 | マルチングとして覆います | 土はねと雑草を防ぎます |

## 6. 播種

### 6-1. 播種時期

| 地域・作型 | 播種適期 | 播種限界期 | 収穫時期 |
|---|---|---|---|
| 韓国中部 | 6月下旬-7月上旬 | 7月中旬 | 9月中下旬 |
| 韓国南部 | 6月中旬-7月中旬 | 7月下旬 | 9月下旬-10月上旬 |
| 後作（前作の後） | 6月中旬-7月中旬 | 7月中旬 | 9月下旬 |
| 緑肥栽培 | 6-7月 | - | 開花期にすき込み |

&nbsp;&nbsp;&nbsp;ササゲは遅く植えてもよい作物です。生育期間が80-90日と短く高温を好むため、真夏に植えても問題ありません。韓国全羅南道での試験では7月25日播種が最も高い収量を出した記録があるほどです。播種の限界は霜が決めるため、初霜予想日から90日を逆算すればよいのです。

> **ササゲの遅播きが可能だという点が、実質的な価値を生みます。大麦やニンニクを収穫した6月の空いた畑、梅雨で倒れた作物をすき込んだ7月の畑に植えることができます。リョクトウとともに、ササゲはその年をまるごと失わずに済ませてくれる作物です。**

### 6-2. 種子の準備

| 項目 | 方法 | 災害条件下では |
|---|---|---|
| 選別 | 虫食い穴、変色、しわのある種子を捨てます | まずアズキゾウムシの被害を確認します |
| 水に沈める | 水に3-4時間浸け、沈んだものだけを使います | 浮くものは中が空か虫食いです |
| 温湯消毒 | 50-55度の湯に10-15分浸けます | 種子伝染性の病原菌を殺します |
| 灰処理 | 細かい草木灰をまぶします | 消毒と乾燥を助け、鳥やアリを遠ざける効果があります |
| 根粒接種 | アズキやササゲを育てた畑の土をまぶします | 5-3節を参照。消毒とは同時に行いません |
| 発芽試験 | 濡れた布に20粒を包み、数日置いて数えます | 発芽が早く3-4日で結果が出ます |

### 6-3. 播種方法

| 項目 | 基準 | 理由 |
|---|---|---|
| 播種深さ | 1-3cm | 浅く植えます。深いと発芽が悪くなります |
| 1穴当たりの粒数 | 2-3粒 | 後で1本を残して間引きます |
| 目標植栽密度 | 1,000㎡当たり15,000株 | 韓国国内の試験で確認された最適密度です |
| 株間 | 20-25cm | |
| 条間 | 60-70cm（1条)、畝に2条なら狭くします | 通風と収穫の通路を確保します |
| 播種量（単作） | 1.5-2kg/1,000㎡ | 豆類の中で少ない方です |
| 播種量（後作・遅播き） | 2-3kg/1,000㎡ | 遅く植えるほど密にします |

&nbsp;&nbsp;&nbsp;播種深さが1-3cmと浅いことが他の豆と異なる点です。ササゲは種子が浅く埋まることを好み、深く埋めると出芽が悪くなります。その代わり浅く埋まっている分乾きやすいため、播種直後は表層が乾かないよう気を配る必要があり、藁を薄く敷いておくと助けになります。

&nbsp;&nbsp;&nbsp;真夏の播種のため、強い日差しの下で土の表面が熱くなる点も考慮します。早朝か夕方に植えれば、種子にまぶした根粒菌が生き残り、若い芽が出るときに焼けることもありません。植えた直後に水をたっぷり一度与え、藁を掛けておくと出芽がそろいます。

&nbsp;&nbsp;&nbsp;播種直後の脅威は鳥とアリです。浅く埋まっているためアリが持ち去り、ハトが掘り出して食べます。細かい草木灰を種子にまぶすと近づきにくくなり、播種した畝の上に藁を薄く掛けると鳥と乾燥の両方を防げます。

## 7. 水管理

| 時期 | 水管理 | 理由 |
|---|---|---|
| 播種から発芽まで | 土がからからに乾かないようにします | 浅く埋まっているため表層が乾くと発芽が止まります |
| 生育初期から開花前まで | 自然の降水に任せます | 乾燥が根を深く張らせます |
| 開花期から莢肥大期まで | 干ばつがひどければ灌水します | この時期の水不足が最も収量を減らします |
| 梅雨時 | 排水路を整えます | ササゲ栽培で最も危険な時期です |
| 登熟期 | 灌水を止めます | 熟した莢が濡れるとカビが生えます |

> **ササゲの水管理は与える技術ではなく、抜く技術です。干ばつには自分で耐えますが、水が溜まると数日で枯れます。**

| 症状 | 原因 | 対応 |
|---|---|---|
| 日中に葉が閉じ、夕方に開く | ササゲの正常な水分節約反応です | そのままにします |
| 朝になっても葉が閉じたままである | 深刻な乾燥 | 灌水します。ただしササゲでは稀です |
| 下葉が黄色くなり根が黒い | 過湿による根腐れ | 排水路を整え、土を高くします |
| 株が急に萎れて枯れる | 冠水または萎凋病 | 根を掘って確認します。水が原因なら排水し、病気なら抜いて燃やします |
| 葉全体が薄い黄色だが萎れてはいない | 根粒が湿害で死んで窒素が途絶えました | 根を掘って確認した後、薄めた尿を少量与えます |
| 花は咲くが莢が付かない | 開花期の極度の乾燥、またはマメノメイガ | 灌水し、莢を割って幼虫を確認します |
| 茎ばかり長く伸びて莢が少ない | 窒素過多または過湿 | 窒素を止め、排水を改善します |

&nbsp;&nbsp;&nbsp;ササゲの葉が日中に閉じるのは病気ではなく正常な反応です。葉を立てたり閉じたりして日光を受ける面積を減らし、蒸散を抑えます。夕方になると再び開きます。この動きがササゲが250mmの水で一作を終えられる理由の一つであり、朝になっても閉じたままなら、そのときこそ本当に水が不足しているのです。

&nbsp;&nbsp;&nbsp;マルチングは二つの目的で使います。水を節約することと、土が跳ねないようにすることです。藁やもみ殻を薄く敷くと表面からの蒸発が減り、雨粒が土を跳ね上げて下の莢に付着するのを防ぎます。ただし厚く覆って土がいつも湿った状態だと、逆に根腐れが増えるため、3-5cmほど薄く敷き、梅雨時には畝の肩の部分を少しめくって土が乾けるようにします。
