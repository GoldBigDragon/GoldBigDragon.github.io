## 5. 整地与施肥 - 氮素平衡与施肥

### 5-4. 固氮的陷阱

&nbsp;&nbsp;&nbsp;种豆能让土地变好的说法，已经成为农业上的常识。这话对了一半，也错了一半。如果不能准确理解这一点，就会出现连续种植多年豆科作物的田地反而变得贫瘠的情况。

&nbsp;&nbsp;&nbsp;我们用数字来核算一下。豇豆长势良好时，每1,000㎡可收获200kg干籽实。豇豆籽实的蛋白质含量为19.6%，用蛋白质除以6.25即可得出氮含量。19.6 ÷ 6.25为3.14，也就是说籽实重量的约3.1%是纯氮。200kg中含有的氮约为6.3kg，换算成每公顷则为63kg。

&nbsp;&nbsp;&nbsp;另一方面，豇豆根瘤在条件良好时每公顷可固定80-120kg的氮，作为适应贫瘠土地的作物，这在豆科中属于较高水平。把流出的和流入的并列比较，情况如下。

| 项目 | 每公顷氮量 | 方向 |
|---|---|---|
| 根瘤固氮量（条件良好） | 80-120kg | 流入 |
| 根瘤固氮量（因涝害根瘤死亡时） | 15-30kg | 流入 |
| 随籽实运出 | 55-70kg | 流出 |
| 留在茎叶（茎与叶）中的氮 | 25-40kg | 归还田地则留下，焚烧或运走则流出 |
| 留在根和根瘤中的氮 | 10-20kg | 大多留在田中 |

&nbsp;&nbsp;&nbsp;豇豆在豆类中属于氮素收支最宽裕的一类。固氮量明显多于随籽实带走的量，即使只把茎叶归还田地，田里仍会留下氮。这正是评价表中施肥需求为SS并注明可兼作绿肥的依据，实际上在非洲和美国南部，豇豆也被广泛用作专门的绿肥作物。

> **豆科作物能改良土地，并不是因为它能固氮，而是因为它把固定下来的氮有一部分储存在茎叶中留在了田里。一旦把这些茎叶运走，豆类就会变成掠夺地力的作物。**

&nbsp;&nbsp;&nbsp;不过豇豆有一点需要留意：叶片会被当作蔬菜采摘食用。叶片中含有相当量的氮，采叶带出田外多少，氮就流失多少。少量采摘不成问题，但如果把叶片当作主要蔬菜持续采摘，留在茎叶中的氮就会相应减少。需要考虑把食用叶片后产生的厨余和人的排泄物做成堆肥、归还到这块田地中的循环。

| 原则 | 内容 |
|---|---|
| 茎叶必须归还田地 | 脱粒后剩下的茎叶全部归还田地 |
| 不焚烧 | 焚烧会使氮以气体形式散失，只留下钾和磷在灰中 |
| 不挖出根系 | 根与根瘤中的氮是最容易留住的部分 |
| 大量采叶时要考虑循环 | 把随叶片流失的氮以堆肥形式补还 |
| 作绿肥使用 | 在开花期翻埋，每公顷可为田地留下80-120kg的氮 |
| 喂过家畜就要归还粪便 | 若茎叶喂了家畜，务必把该家畜的粪肥施回这块田地 |

### 5-5. 整地准备

| 项目 | 方法 | 灾难条件下 |
|---|---|---|
| 耕地 | 深耕20-30cm并平整土地 | 若是前茬作物收获后的地块，只翻挖种植行也可以 |
| 起垄 | 高度20cm以上 | 是防止涝害的关键 |
| 排水沟 | 深度30cm以上，确保水能完全排出 | 在梅雨季前灌水测试确认 |
| 酸度调节 | 适应pH5.0-8.0 | 适应范围广，不急于处理 |
| 石灰 | pH低于5.5时施200kg/1,000㎡ | 可用烧过捣碎的贝壳、蛋壳或草木灰代替 |
| 有机质 | 腐熟堆肥1,000-1,500kg/1,000㎡ | 贫瘠地也能生长，但施用后产量会提高 |

&nbsp;&nbsp;&nbsp;豇豆的pH适应范围为4.5-8.0，是豆类中最宽的，因此施石灰的优先级较低。只要田地不是严重酸性，不施石灰也能生长。把石灰省下来用在豌豆或大豆等其他作物的地里，从整体上看更为合理。

&nbsp;&nbsp;&nbsp;取而代之的是要在排水上下功夫：深耕以打通水向下渗透的通道，把垄做高，把排水沟挖深。从选地阶段起就选择不易积水的地块最为可靠，若田地有坡度，上方位置就是豇豆的种植区。

### 5-6. 施肥量

| 肥料 | 每1,000㎡基准 | 折算每㎡ | 备注 |
|---|---|---|---|
| 氮 | 0-2kg | 0-2g | 豆类中最少，完全不施也可以 |
| 磷 | 4-7kg | 4-7g | 全部作基肥。在贫瘠地对根瘤发育不可或缺 |
| 钾 | 3-5kg | 3-5g | 全部作基肥 |
| 堆肥 | 1,000-1,500kg | 1-1.5kg | 使用完全腐熟的堆肥 |
| 石灰 | pH低于5.5时施200kg | 200g | 播种前3-4周 |

> **豇豆是几乎不需要氮肥的作物。反而如果施氮，只会让茎叶徒长、豆荚减少，通风变差、病害增多。种在贫瘠的田地里，才是这种作物本来的用途。**

&nbsp;&nbsp;&nbsp;磷则不同。在贫瘠田地里，真正左右豇豆产量的是磷。固氮需要大量能量，而这一代谢过程要用到磷，因此磷若不足，即使形成了根瘤也无法发挥应有的作用。在没有化学肥料的条件下，获取磷的途径实际上几乎只有骨粉和鱼骨。在贫瘠田地种植豇豆时，比什么都要优先准备的正是这种磷。

&nbsp;&nbsp;&nbsp;原则上不需要追肥。仅在生长明显不良时，把尿液用水稀释10倍，在植株之间的土壤上浇极少量。要避免接触叶片，若叶色浓绿、长势繁茂则不必追施。

### 5-7. 灾难替代肥料

| 替代资源 | 提供的养分 | 用法 | 注意事项 |
|---|---|---|---|
| 骨粉 | 磷、钙 | 烧后捣碎，拌入堆肥 | 是贫瘠地种豇豆最重要的资源 |
| 鱼骨·鱼内脏 | 磷、氮 | 埋入土中腐熟后再用 | 直接埋入会被野兽刨出来 |
| 草木灰 | 钾、磷、钙 | 每㎡撒施100-150g并混入土中 | 豇豆也耐碱，有较大余地 |
| 腐熟堆肥 | 综合 | 每㎡施1-1.5kg作基肥 | 未腐熟的会烧根并传播病害 |
| 稀释尿液 | 氮、钾 | 用水稀释10倍后浇在植株间的土壤上 | 仅需极少量，通常不需要 |
| 贝壳·蛋壳 | 钙 | 烧后捣碎撒施 | 仅在pH低于5.5时使用 |
| 前茬作物残体 | 有机质 | 用大麦秸、蒜秆覆盖，兼作覆盖与肥料 | 豇豆多作为后茬种植 |
| 稻壳·稻草 | 钾、硅酸 | 用作覆盖 | 可防止泥土飞溅和杂草滋生 |

## 6. 播种

### 6-1. 播种时期

| 地区·栽培方式 | 播种适期 | 播种限期 | 收获时期 |
|---|---|---|---|
| 韩国中部 | 6月下旬-7月上旬 | 7月中旬 | 9月中下旬 |
| 韩国南部 | 6月中旬-7月中旬 | 7月下旬 | 9月下旬-10月上旬 |
| 后茬（前茬作物之后） | 6月中旬-7月中旬 | 7月中旬 | 9月下旬 |
| 绿肥栽培 | 6-7月 | - | 开花期翻埋 |

&nbsp;&nbsp;&nbsp;豇豆是可以晚种的作物。生育期短，只有80-90天，且喜高温，即便盛夏播种也没问题。在韩国全罗南道的试验中，甚至有7月25日播种获得最高产量的记录。播种的极限由霜冻决定，只需从预计初霜日倒推90天即可。

> **豇豆能够晚播这一点，创造了实实在在的价值。可以种在收完大麦或大蒜后空出的6月田地里，也可以种在梅雨中倒伏的作物翻埋后的7月田地里。豇豆和绿豆一样，都是能让人不至于彻底失收一整年的作物。**

### 6-2. 种子准备

| 项目 | 方法 | 灾难条件下 |
|---|---|---|
| 挑选 | 剔除有虫眼、变色、皱缩的种子 | 首先检查是否有绿豆象为害 |
| 水选沉淀 | 浸水3-4小时，只使用下沉的种子 | 漂浮的种子多为空心或已被虫蛀 |
| 温汤消毒 | 浸入50-55度的温水中10-15分钟 | 可杀死种传病原菌 |
| 草木灰处理 | 沾裹细草木灰 | 有助于消毒和干燥，并能驱避鸟类和蚂蚁 |
| 根瘤接种 | 沾裹种过红小豆或豇豆的地块土壤 | 参见5-3节，不与消毒同时进行 |
| 发芽试验 | 用湿布包住20粒种子，放置数日后计数 | 发芽快，三四天即可见结果 |

### 6-3. 播种方法

| 项目 | 标准 | 理由 |
|---|---|---|
| 播种深度 | 1-3cm | 宜浅播，过深会影响发芽 |
| 每穴粒数 | 2-3粒 | 之后间苗只留1株 |
| 目标种植密度 | 每1,000㎡ 15,000株 | 是韩国国内试验确认的最适密度 |
| 株距 | 20-25cm | |
| 行距 | 60-70cm（单行），一垄双行时应更窄 | 以保证通风和收获通道 |
| 播种量（单作） | 1.5-2kg/1,000㎡ | 在豆类中属较少的一类 |
| 播种量（后茬·晚播） | 2-3kg/1,000㎡ | 播种越晚应越密 |

&nbsp;&nbsp;&nbsp;播种深度只有1-3cm，比其他豆类浅，这是豇豆的不同之处。豇豆喜欢种子埋得浅，埋得深会导致出苗不良。但埋得浅也容易干燥，因此播种后要注意防止表层变干，薄薄覆盖一层稻草会有帮助。

&nbsp;&nbsp;&nbsp;由于是盛夏播种，还要考虑到烈日下地表温度较高的问题。选在清晨或傍晚播种，能让沾在种子上的根瘤菌存活，也能避免幼芽出土时被灼伤。播种后立即充分浇一次水并覆盖稻草，可使出苗更整齐。

&nbsp;&nbsp;&nbsp;播种后不久面临的威胁是鸟类和蚂蚁。由于埋得浅，蚂蚁会把种子搬走，鸽子会把它挖出来吃掉。给种子沾裹细草木灰能减少这类接近，在播种行上薄薄覆盖一层稻草则能同时防鸟和防止干燥。

## 7. 水分管理

| 时期 | 水分管理 | 理由 |
|---|---|---|
| 播种到发芽 | 防止土壤过度干燥 | 由于埋得浅，表层一干发芽就会停止 |
| 生育初期到开花前 | 交给自然降水即可 | 干燥能促使根系向深处扎根 |
| 开花期到荚膨大期 | 干旱严重时灌溉 | 这一时期缺水对产量的影响最大 |
| 梅雨季 | 疏通排水沟 | 是豇豆栽培中最危险的阶段 |
| 灌浆·成熟期 | 停止灌溉 | 成熟豆荚受潮会长霉 |

> **豇豆的水分管理，不是浇水的技术，而是排水的技术。它能自行扛过干旱，但一旦积水，几天内就会死亡。**

| 症状 | 原因 | 处理 |
|---|---|---|
| 正午叶片合拢，傍晚展开 | 是豇豆正常的节水反应 | 无需处理 |
| 早晨叶片仍处于合拢状态 | 严重干旱 | 需要灌溉，但在豇豆中很少见 |
| 下部叶片发黄、根系发黑 | 因过湿导致的烂根 | 疏通排水沟并培土 |
| 植株突然萎蔫死亡 | 淹水或枯萎病 | 挖根检查：若因积水则排水，若是病害则拔除烧毁 |
| 整株叶片呈浅黄色但不萎蔫 | 根瘤因涝害死亡，氮素供应中断 | 挖根确认后，施用少量稀释尿液 |
| 开花但不结荚 | 开花期严重干旱，或豆荚野螟为害 | 灌溉并剖开豆荚检查幼虫 |
| 只长茎不结荚 | 氮肥过多或土壤过湿 | 停止施氮并改善排水 |

&nbsp;&nbsp;&nbsp;豇豆叶片在正午合拢并非病害，而是正常现象：通过立起或合拢叶片来减少受光面积、抑制蒸腾，到傍晚又会重新展开。这种动作正是豇豆能靠250mm降水完成一季生长的原因之一。如果早晨叶片仍然合拢，那才是真正缺水的信号。

&nbsp;&nbsp;&nbsp;覆盖有两个目的：节约水分和防止泥土飞溅。薄薄铺一层稻草或稻壳，可以减少表面蒸发，也能防止雨滴溅起泥土沾污下方的豆荚。但如果覆盖太厚，导致土壤总是潮湿，反而会增加烂根，因此应铺得薄一些，控制在3-5cm，梅雨季时把垄肩部分稍微掀开，让土壤能够变干。
