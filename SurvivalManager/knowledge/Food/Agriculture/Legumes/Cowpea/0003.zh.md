## 3. 栽培环境

### 3-1. 气温与光照量

| 条件 | 极限值 | 最适值 | 超出范围时 |
|---|---|---|---|
| 发芽温度 | 12-15℃以上 | 25-30℃ | 10℃以下不发芽 |
| 生育温度 | 15-40℃ | 20-35℃ | 豆类中最耐高温 |
| 结实温度 | 20-32℃ | 24-30℃ | 幅度12℃，在豆类中属于较宽的 |
| 耐寒性 | 无 | - | 一次霜冻即死亡 |
| 日照 | 每天6小时以上 | 每天8小时以上 | 40%遮光时产量降至一半 |
| 降水量 | 年降水量400mm也能生长 | 400-700mm | 积水比干旱更危险 |

> **豇豆是少数不会因炎热而死的作物之一。即使在35℃持续、其他豆类花朵纷纷凋落的夏天，豇豆依然每天早晨开出新花。酷暑越频繁，豇豆的相对地位就越高。**

&nbsp;&nbsp;&nbsp;凭借这种耐高温能力，豇豆可以在盛夏播种。韩国中部适期为6月下旬至7月上旬，韩国南部为6月中旬至7月中旬，在韩国全罗南道的试验中，甚至有7月25日播种获得最高产量的记录。播种的极限由霜冻决定：从预计初霜日倒推90天，就是该地区的播种极限日。

&nbsp;&nbsp;&nbsp;能够晚种这一点在实际操作中很有价值。可以把豇豆种在收完大麦、大蒜或马铃薯后空出来的6月田地里，或者在韩国的梅雨季（6月下旬至7月）中倒伏的作物翻埋后腾出的7月田地里。豇豆和绿豆一样，都是用来补种失败作物的作物。

### 3-2. 土壤与水

| 条件 | 极限值 | 最适值 | 备注 |
|---|---|---|---|
| 土质 | 从沙地到黏质土 | 排水良好的砂质土-砂壤土 | 豆类中适应范围最广 |
| pH | 4.5-8.0 | 5.5-7.0 | 耐强酸性，豆类中范围最广 |
| 有效土层 | 30cm以上 | 50cm以上 | 主根扎入较深 |
| 生长期蒸散量 | - | 约250mm | 豆类中最少的一类 |
| 淹水 | 淹没一天以上即死亡 | - | 豆类中最不耐涝的一类 |
| 耐盐性 | 低 | - | 不适合含盐的土地 |
| 垄高 | 20cm以上 | 25cm | 是防止涝害的关键 |

&nbsp;&nbsp;&nbsp;能耐受pH4.5，是豇豆的一大明显优势。韩国的田地降雨较多，大多偏酸性，在难以获得石灰的条件下，这一点会带来实质性的差异。豌豆在pH6.0以下就会垮掉，大豆在5.5时会失去根瘤，而豇豆在比这更低的土壤中依然能生长。它是少数能种在连作多年而偏酸、又无法施加石灰的田地里的豆类。

> **最耐旱的豇豆，却最不耐涝，这并非偶然。适应干燥稀树草原的根系结构，无法忍受积水缺氧的土壤。在豇豆地里，起垄和排水沟不是可选项，而是前提条件。**

&nbsp;&nbsp;&nbsp;在韩国，豇豆的生育期正好与梅雨季重叠。这是豇豆栽培中最大的难点，应对方式是物理性的：把垄做高20cm以上，把排水沟挖深，并在梅雨季前确认排水是否顺畅。从选地阶段起，就应把不易积水的地块、若有坡度则把上方位置分配给豇豆。

## 4. 品种

### 4-1. 按生长形态分类

| 类别 | 株高 | 支架 | 特点 |
|---|---|---|---|
| 直立型 | 50-80cm | 不需要 | 抗倒伏，便于收获 |
| 半直立型 | 80-120cm | 大多不需要 | 产量高，省工 |
| 蔓生型 | 2-3m | 需要 | 采收期长，但需要搭支架 |

&nbsp;&nbsp;&nbsp;在韩国国内育成的豇豆品种中，全南1号和全南2号为半直立型，玉堂和宣贤为直立型。直立型抗倒伏、便于管理，半直立型产量略高。试验记录显示，全南2号每1,000㎡产量为221kg至224kg，宣贤约为226kg。

&nbsp;&nbsp;&nbsp;在灾难情况下，直立型或半直立型更为合理：不需要支架，不易倒伏因此收获省力，也便于采叶食用。只有在有搭支架的材料和人力时，才考虑蔓生型。

### 4-2. 按情况选择的标准

| 情况 | 优先选择 | 理由 |
|---|---|---|
| 没有支架材料 | 直立型·半直立型 | 无需支架即可直立 |
| 田地贫瘠干旱 | 任何品系的豇豆均可 | 在这种条件下没有豆类能替代豇豆 |
| 想把叶片当蔬菜用 | 叶片多的半直立型 | 摘叶后仍会持续长出新叶 |
| 早霜地区 | 早熟直立型 | 80天即可完成生育 |
| 需要改良地力 | 任何品系均可，作绿肥用 | 在开花期翻埋可留下氮素 |
| 种子不足 | 直立型 | 种植密度固定，便于计算 |

&nbsp;&nbsp;&nbsp;选择品种的首要标准是能否自家留种。豇豆的大多数栽培品系都是固定品种，且为自花授粉，因此留下的种子可以直接播种。由于韩国国内普及度为B，再次获得种子并不容易，原则上应延续已获得的品系。如果当地有地方品种，它很可能已经适应了当地的土壤条件。

## 5. 整地与施肥 - 根瘤菌

### 5-1. 固氮是如何发生的

&nbsp;&nbsp;&nbsp;空气中78%是氮气。尽管人们头顶飘浮着无穷无尽的氮气，植物却无法直接利用它。空气中的氮是由两个氮原子通过三键牢牢结合而成的分子，要打破这个键需要巨大的能量。工业上打破这一键来制造氨的方法就是哈伯-博施法，全世界的氮肥都由此而来，这需要高温、高压、催化剂和大量化石燃料。

&nbsp;&nbsp;&nbsp;根瘤菌能在常温常压下完成这项工作。它靠一种叫固氮酶的酶打断三键，把氮转化为氨。不过这是有代价的：这一反应需要大量能量，而细菌自身无法进行光合作用。于是它们生活在豆科植物的根部，从植物那里获得光合作用产生的糖分，作为回报，把固定下来的氮交给植物。这是一种交易关系。

&nbsp;&nbsp;&nbsp;与豇豆共生的菌属于Bradyrhizobium类群，与红小豆和绿豆所用的菌相通，这种菌在酸性土壤中也能相对耐受。豇豆能耐受pH4.5的原因之一，正是共生菌的耐酸性。在实际操作中，种过红小豆、绿豆或豇豆的地块土壤都可以作为接种源。

| 阶段 | 发生的事 |
|---|---|
| 1. 信号交换 | 豇豆根系分泌类黄酮，土壤中的细菌对此信号作出反应，释放结瘤因子 |
| 2. 侵染 | 根毛向内弯曲将细菌包裹住，细菌沿侵染线进入根内部 |
| 3. 根瘤形成 | 根内部细胞分裂使根瘤膨大，细菌在其中定居 |
| 4. 固氮 | 根瘤内固氮酶发挥作用，把空气中的氮转化为氨 |
| 5. 分配 | 氨转化为氨基酸，被运送到茎、叶和豆荚 |
| 6. 衰老 | 进入灌浆期后根瘤失去功能，随根系归还土壤 |

&nbsp;&nbsp;&nbsp;固氮酶对氧气极为敏感，一接触氧气就会立即失去功能。因此根瘤内部充满了一种叫豆血红蛋白的红色色素蛋白，用来抓住氧气，把酶周围的氧浓度维持在极低水平。这与人血呈红色是同一原理，掰开根瘤后内部呈红色或粉红色，正是这种色素的缘故。这一点在实际操作中极为重要，因为红色是该根瘤正在固氮的可见证据。

&nbsp;&nbsp;&nbsp;豇豆在豆科作物中固氮能力较强，这是为在贫瘠土壤中生存而演化出的特性，条件良好时每公顷可固定100kg左右的氮。施肥需求等级SS以及兼作绿肥的评价，正是由此而来。

### 5-2. 如何确认是否形成了根瘤

&nbsp;&nbsp;&nbsp;无论是否进行了接种，都必须确认根瘤是否真的形成了。不确认的话，就无法知道缺氮的原因，第二年还会重蹈覆辙。

| 顺序 | 内容 |
|---|---|
| 1 | 开花开始前后、播种后约6周是最好的时机 |
| 2 | 挑选两三株看起来健康的植株 |
| 3 | 不要拔起，用铲子在植株周围大范围挖取，连土一起铲起 |
| 4 | 放入水桶中，轻轻把土洗掉 |
| 5 | 数一数主根和粗侧根上根瘤的数量 |
| 6 | 用指甲掰开几个根瘤，观察内部颜色 |

| 观察结果 | 含义 | 处理 |
|---|---|---|
| 每株结瘤20个以上 | 接种效果良好 | 保持现状即可 |
| 掰开后内部呈红色或粉红色 | 正在固氮 | 状态良好 |
| 掰开后内部呈白色或浅绿色 | 根瘤已形成但未固氮 | 检查是否涝害或缺磷 |
| 掰开后内部呈褐色或黑色 | 已经衰老或死亡 | 若在梅雨季后，很可能是因涝害而死 |
| 根瘤5个以下 | 接种失败 | 若叶片发黄，补充少量氮肥 |

> **挖出根系、掰开根瘤确认红色，这一个习惯，是在没有氮肥的世界里判断豆类种植成败最可靠的信号。**

&nbsp;&nbsp;&nbsp;豇豆最好在梅雨季前后各检查一次。如果梅雨前还是红色的根瘤，梅雨后变黑死亡，原因就是涝害。根瘤菌是好氧菌，一旦被水淹没，会比根系更早死亡。这时应疏通排水沟，如果叶片发黄，就施用极少量的稀释尿液，帮助植株撑过剩余的生长期。

### 5-3. 接种源从何处获取

&nbsp;&nbsp;&nbsp;商业接种剂是把活菌装入泥炭或黏土中出售的产品，在灾难情况下无法获得。不过豇豆所用的菌是红小豆和绿豆共用的常见菌种，因此获取接种源相对容易。

| 方法 | 步骤 | 效果 | 注意事项 |
|---|---|---|---|
| 沾附种过红小豆·绿豆·豇豆的地块土壤 | 从前一年种过这些作物且结瘤良好的地块中，挖取表土下5-15cm深处的土。将种子稍微用水打湿后沾上这些土，随即播种 | 最可靠且不花费成本 | 带病地块的土壤也会一并带来病原菌 |
| 直接使用根瘤 | 收集挖出根系上的根瘤，捣碎溶于水中，将种子浸入后取出 | 菌密度最高 | 必须在挖出根瘤当天使用 |
| 将土壤撒入田中 | 把取来的土撒在要播种的行上，一起翻入土中 | 菌能扩散到土壤中 | 每10㎡约一铲为基准 |
| 保留根系残体 | 收获时只割茎，把根留在地里 | 菌能在土壤中留存到第二年 | 是最省事的维持方法 |
| 野生红豆的根 | 从野外和田埂上野生红豆的根部采集根瘤 | 同属，菌种相通 | 固氮效率可能低于栽培品系专用的菌 |

&nbsp;&nbsp;&nbsp;接种时有几点必须遵守。根瘤菌对直射阳光、干燥和高温都非常敏感，紫外线照射几分钟就能杀死大量菌体，一旦变干则死得更快。给种子沾土的作业应在阴凉处进行，沾好土的种子不要摊在阳光下晾晒，而要立即播种。最好在30分钟内播种完毕，最晚也要在几个小时内完成。豇豆是盛夏播种的作物，这一点尤其重要：烈日下被晒热的地表温度可能超过60℃，会让沾在种子上的菌立刻死亡，因此应选在清晨或傍晚播种。

| 导致接种失败的条件 | 原因 |
|---|---|
| 积水的田地 | 属好氧菌，缺氧则死亡，是豇豆接种失败最常见的原因 |
| 施足氮肥的田地 | 植物感觉不到交易的必要，会自行减少结瘤 |
| 缺磷的田地 | 固氮需要大量能量，其代谢过程要用到磷。在贫瘠地块中尤为重要 |
| 缺乏钼·铁·钴 | 它们是固氮酶的组成成分 |
| 盛夏烈日下播种 | 地表过热，会杀死沾在种子上的菌 |
| 把接种后的种子放在阳光下晒干 | 紫外线和干燥会杀死菌 |
| 使用大豆或豌豆地里的土壤 | 菌的品系不同，效率会降低 |
