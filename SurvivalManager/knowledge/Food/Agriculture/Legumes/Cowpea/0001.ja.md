## はじめに
&nbsp;&nbsp;&nbsp;ササゲ(Vigna unguiculata)は、サハラ以南の乾燥したサバンナで栽培化された西アフリカ原産のマメ科の一年草です。最も際立った強みはやせ地と干ばつに強いことで、年間降水量400mmでも種子を結び、pH4.5の強酸性の土でも育ち、蒸発散量の合計250mmで1作を終えるため、水の消費量はSであり、防除の自立度Sはマメ類で最も高い値です。ほかのマメ類にない点は葉を食べることで、若葉、若莢、乾燥した子実を順に出してくれます。総合等級はC(43.0点、有効183種中82位)で、短期C(41.3)、長期B(44.8)、副食はSS(64.2点)です。面積当たりの熱量がDで1㎡当たり686kcal、自給ラインの0.26倍にすぎず、耐寒性はEで霜が一度降りれば枯れ、干ばつに強い分、水がたまることにはマメ類で最も弱いです。国内での栽培の普及度がBなので、3-4の道(行政区)の外では種子を入手しにくく、確保できたなら自家採種で続けていく必要があります。ササゲの居場所は、よい畑の主作物ではなく、砂地、乾いた斜面、やせた区画など、ほかの作物が育たないところです。

| 評価 | 項目 |

| 弱み | E: 耐寒性。D: 面積当たりの熱量、永続性、日射、調理・加工の要求度、整地・掘削エネルギー、非食用の価値。C: 病害虫圧。B: 温度幅、国内での栽培の普及度 |

> **ササゲの価値は、よい畑でどれだけ収穫できるかではなく、悪い畑でも収穫できるかにあります。干ばつの年、肥料が底をついた年、畑の隅の砂地でも、ササゲは何かを出してくれます。**

&nbsp;&nbsp;&nbsp;防除の自立度Sは、薬がなくても耕種的な手段だけで対応できるという意味で、連作への適応性Sはマメ類で最も余裕があります。収穫速度Aは80-90日で収穫でき、7月中下旬まで植えられるため、失敗した場所を埋められます。病害虫圧Cは薬なしで抑えられますが、マメノメイガとアズキゾウムシの二つには注意が必要です。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | マメ科ササゲ属の一年草。西アフリカのサバンナ原産で自家受粉 |
| 葉、茎 | 葉は3枚で1組の三出複葉で、厚く光沢がある |
| 根、花 | まっすぐな主根が深く入り、細根に太い根粒がつく。花は白、薄紫、紫の蝶形で、朝に咲いてその日にしぼむ |
| 莢、子実 | 細長い円筒形で10-25cm、粒は10-20個。子実は腎臓の形で、へそのまわりに黒い輪があるものが多く、白、赤、黒がある |

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 発芽、幼苗期 | 播種後2週 | 発芽は速いが地上部はゆっくりで、根が先に深く下りる |
| 栄養成長期 | 2-6週 | 茎と葉が増え、根粒が活発になる |
| 開花期 | 6-8週 | 毎朝新しい花が咲く |
| 莢肥大期 | 8-10週 | 莢が長くなり、粒が太る |
| 登熟、成熟期 | 10-13週 | 下の莢から茶色に乾く |

&nbsp;&nbsp;&nbsp;ササゲの厚い葉は蒸発を防いで干ばつに耐えさせ、ゆでるとやわらかくなって野菜になります。開花から成熟までは8-15日とたいへん速く、下の莢が熟す間も上では新しい花が咲き続けるので、収穫は2、3回に分けます。乾燥した子実100g当たり熱量343kcal、タンパク質19.61g(熱量比22.9%)、脂質1.5g前後、炭水化物60-65g、食物繊維10-20g、カリウム約1,100mg、鉄5-8mgで、カルシウムとマグネシウムが豊富であり、脂質が少なくて酸化が遅いです。乾燥した子実にないビタミンCとカロテンが若葉にあります。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽12-15℃以上(最適25-30℃)。生育15-40℃(最適20-35℃)で、マメ類で最も高温に強い。結実20-32℃。耐寒性がなく、霜が一度降りれば枯れる |
| 土壌 | 水はけのよい砂土か砂壌土(砂地から粘質土まで適応)、pH4.5-8.0(最適5.5-7.0、マメ類で最も広い)、有効土層30cm以上(最適50cm)。1日以上冠水すると枯れる |

> **干ばつに最も強いササゲが、冠水には最も弱いです。乾いたサバンナに合わせた根は、水がたまって酸素のない土に耐えられません。ササゲの畑で、畝と排水溝は選択ではなく前提です。**

&nbsp;&nbsp;&nbsp;高温への適応力のおかげで真夏の播種が可能で、石灰を入れていない酸性の畑にも植えられます。国内では生育期間が梅雨と重なることがもっとも大きな難点なので、水がたまらない場所、斜面なら上の側をササゲに割り当てます。

| 型 | 高さ、支柱 | 特徴 |
|:---|:---|:---|
| 直立型 | 50-80cm、不要 | 倒伏に強く、収穫が楽。早生型は80日で終わる |
| 半直立型 | 80-120cm、おおむね不要 | 収量が高く、手間が少なく、葉が多いので葉摘みに向く |
| つる性 | 2-3m、必要 | 収穫期間が長いが、支柱の資材と労力がかかる |

&nbsp;&nbsp;&nbsp;国内で育成された品種として、チョンナム1号、チョンナム2号(半直立型)、オクタン、ソニョン(直立型)が知られています。災害時には支柱の要らない直立型か半直立型が合理的で、霜が早い地域では早生の直立型を選びます。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 畑づくり | 20-30cmの深さに耕して均一に整地。畝は20cm以上(湿害防止の要)、排水溝は深さ30cm以上で最後まで水が抜けるようにし、梅雨の前に水を流して確認。完熟堆肥1,000-1,500kg/1,000㎡ |
| 施肥(1,000㎡) | 窒素0-2kg(マメ類で最も少なく、多いと茎と葉だけが茂って莢が減り病気が増える)、リン酸4-7kg(すべて元肥、骨粉や焼いた魚の骨の粉で補う)、石灰200kgはpH5.5未満のときだけ(播種の3-4週間前) |
| 根粒の接種 | アズキ、リョクトウ、ササゲを育てた畑の表土5-15cmの土を、水で軽く湿らせた種子に日陰でまぶし、30分以内に播種(菌は直射日光、乾燥、熱に弱い)。野生のアズキの根の根粒も使える。ダイズやエンドウの畑の土は効率が落ち、病気の畑の土は病原菌も運ぶ |

&nbsp;&nbsp;&nbsp;接種は、水がたまる畑、リン酸が足りない畑、土の表面が60℃を超える真夏の炎天下では失敗するので、早朝か夕方に播種します。開花のころ(播種後6週ごろ)にスコップで土ごとすくって洗い、根粒を割ってみます。1株20個以上で内側が赤ければうまくいっており、白か薄い緑なら湿害とリン酸欠乏を調べ、茶色か黒なら死んでおり(梅雨のあとなら湿害)、5個以下なら接種の失敗なので、葉が黄色いときは少量の窒素を補います。梅雨の前後に2回確認します。

&nbsp;&nbsp;&nbsp;1ヘクタール当たりの固定量は条件がよいと80-120kg(湿害で根粒が死ぬと15-30kg)で、子実で55-70kgが出ていくので、窒素収支はマメ類で最も余裕があり、緑肥としても使います。脱穀したあとに残った茎と葉はすべて畑に戻し、根は掘り上げず、葉を摘んで持ち出した分は堆肥にして戻します。

| 播種 | 基準 |
|:---|:---|
| 時期 | 中部は6月下旬-7月上旬(限界は7月中旬)、南部は6月中旬-7月中旬(限界は7月下旬)。収穫は9月中旬-10月上旬。限界日は初霜の予想日から90日さかのぼった日 |
| 種子の準備 | 虫食いの穴、変色、しわのある種子を捨てる。水に3-4時間浸して沈んだものだけを使い、50-55℃の湯に10-15分浸して消毒。接種は消毒と一緒に行わない。発芽試験は濡れた布に20粒を包んで3、4日置いて数える |
| 方法 | 深さ1-3cm(深いと発芽が悪くなる)、1穴2-3粒、条間60-70cm、目標の栽植密度は1,000㎡当たり15,000株。播種量は1,000㎡当たり、単作で1.5-2kg、後作・遅まきで2-3kg |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から発芽 | 土が完全に乾かないように(浅く埋めるので、表層が乾くと発芽が止まる) |
| 生育初期から開花前 | 自然の降水に任せる(乾燥が根を深く下ろさせる) |
| 梅雨 | 排水溝を掘る(もっとも危険な時期) |
| 登熟期 | 灌水を中止(熟した莢が濡れるとカビが生える) |

> **ササゲの水管理は、与える技術ではなく抜く技術です。干ばつには自分で耐えますが、水がたまると数日で枯れます。**

&nbsp;&nbsp;&nbsp;日中に葉が折りたたまれ、夕方に開くのは、蒸散を抑える正常な反応で、朝にも折りたたまれたままのときが本当に水不足です。下の葉が黄色く根が黒ければ、過湿による根腐れなので、排水溝を掘って土を盛ります。

| 管理 | 方法 |
|:---|:---|
| 草取り | 出芽後2週に1回目(雑草が小さいうちに)、4-5週に2回目(土寄せと兼ねる)、開花前にすべての除草を終え、本葉2-3枚で1穴に最も丈夫な1本だけを残す。細根が表層にあるので、鍬を寝かせて表面2cmだけをかき、株の近くは手で抜く。5週を過ぎて葉が地面を覆えば、雑草と争わない |
| 葉摘み | 本葉が何枚か出てから開花前まで、新芽ではなく下の方の育った葉を葉柄ごと摘む(成長点には触れない)。1株で全体の葉の3分の1以内とし、開花が始まったらやめる |
| 倒伏 | 原因は窒素過多と密植なので、施肥量と栽植密度を守る。風雨が心配なら畑の周りにひざの高さで綱を張り、2回目の草取りのときに株元に土を寄せる |

> **ササゲは植えて放っておいても何かを出してくれる作物ですが、それは何もしなくてよいという意味ではありません。最初の5週の雑草管理だけはしなければなりません。**

## 6. 病害虫と養分の問題
| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| 萎凋病、根腐病 | 株がしおれて枯れ、茎の根元が茶色く軟らかくなる。過湿と連作 | 排水と畝を高くすることがほぼすべて |
| さび病、細菌性の葉枯病、モザイクウイルス | 葉にオレンジ色の粉の塊(生育後期の多湿) / 葉に角ばった茶色の斑点(風雨で広がる) / 葉がまだらになって縮れ、生育が止まる(アブラムシが媒介) | 病葉の除去と風通しの確保 / 雨のあとは畑に入らない / 治療できないので抜いて焼き、アブラムシは石けん水(水1Lに石けん5g)で減らす |
| マメノメイガ | 花びらの内側に産みつけられた卵から孵った幼虫が、花と若いさやの中に入って子実を食べる、畑での最大の害虫 | 開花期から毎朝、花と若いさやを調べ、幼虫がいれば摘んで畑の外で処分する |
| アズキゾウムシ | 畑でさやに卵を産み、貯蔵中に子実を食い荒らして、半年で全量が被害を受ける | 適期に収穫し、完全に乾かして密閉(9節参照) |
| カメムシ類、鳥 | さやを刺して空のさやにする / 浅く埋めた種子と芽を食べる | 早朝の露があるうちに手で捕る / 発芽までわらかネットで覆う |

&nbsp;&nbsp;&nbsp;ボルドー液は水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜ、細菌病とカビによる病気に使い、露のある朝に葉にまく乾いた灰は、葉を食べる虫とカビを減らします。病気の残渣は焼き、健全な残渣だけを畑に戻します。

| 症状 | 原因と対処 |
|:---|:---|
| 葉全体が薄い黄色で株が小さい | 窒素欠乏(湿害で根粒が死んだ場合がもっとも多い)。まず根を掘って根粒を確認し、排水を直したうえで尿の10倍希釈液を少量与える |
| 生育が遅く葉が紫色を帯びる | リン酸欠乏で、やせ地でもっとも多い。骨粉、焼いた魚の骨の粉をまず用意する |
| 花が咲いても莢がつかない | ホウ素欠乏、開花期の極度の乾燥、またはマメノメイガ。まず花の中を調べ、そうでなければ複数の材料を混ぜた堆肥 |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | トウモロコシ、ソルガム、キビ(窒素を分け合い、ササゲはリシンが多く雑穀はメチオニンが多いので互いを補う)、バジル(害虫が減るという報告)、オオムギ、コムギ、ニンニク、ジャガイモ(前作にすると6月に畑が空き、後作として植えられる)、ハクサイ、ダイコン(ササゲのあとに残った窒素を使う) |
| 悪い | アズキ、リョクトウ(同じ属なので病原菌とアズキゾウムシを共有)、水を多く与える作物(ササゲは過湿にもっとも弱い) |

&nbsp;&nbsp;&nbsp;休作は2-3年、理想の周期は3年で、萎凋病とセンチュウがたまりますが、ほかのマメ科より遅く蓄積します。3年輪作の例は、1年目はオオムギかニンニク(冬)のあとにササゲ(夏) → 2年目はソルガムかトウモロコシ → 3年目はハクサイ・ダイコンの仲間かジャガイモ → またササゲです。やせた区画では、1年は子実を収穫し、翌年は開花期にすき込んで緑肥にする運用もできます。

> **ササゲは畑を立て直す作物です。ほかのどの作物も育たない区画をササゲで2、3年回すと、窒素と有機物がたまって、その畑がよみがえります。**

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 若葉は本葉が開いてから開花前まで、若莢は播種後45-60日にさやが細くやわらかいうち、乾燥した子実は早生75-90日、晩生90-125日に、さやが茶色になり粒が堅くなったとき。開花後8-15日で熟すので、2-3回に分けて摘む |
| 要領 | 晴れて乾燥した日の露が乾いたあとに、茶色になったさやだけを手でひねって摘む。さやを網やむしろに広げて日に3-5日干し、ときどき揺する |
| 脱穀、選別 | 袋踏み(少量)、網に入れて棒で叩く(粒がこぼれない)、からざお(力を抜いて何度も打つ、中規模)、手でむく(1さやに10-20粒なので進みが速く、種子用に向く)。ふるいで割れた粒を除き、水に浮かべて浮く実のないものと虫食いの粒を取り除いたあと、その日のうちにまた乾かす |

> **畑で熟したまま長くぶら下がっているさやが、貯蔵庫のゾウムシの被害をつくります。ササゲの適期の収穫は、半年後の食料が残るか残らないかの問題です。**

| 採種 | 基準 |
|:---|:---|
| 選抜、収穫 | 病気の症状がなく、莢が多くつき、倒れなかった株を畑であらかじめ印をつける。さやが完全に茶色になったらすぐに摘み、手でむいて粒が割れないようにする |
| 選別、乾燥 | 虫食いの穴、斑点、割れた粒、変色をすべて捨てる。ゾウムシの卵は種皮にごく小さな白い点としてつき、外からは見えにくいので目と手で選び(種子用は水に浮かべない)、水分12%以下に完全に乾かす |
| 保管 | 密閉して常温で3-4年。低温処理(9節参照)はゾウムシの卵と幼虫を殺し、発芽力は損なわない。アズキ、リョクトウとは収穫と貯蔵を分け、種子が混ざらないようにする |

## 9. 貯蔵
| 段階 | 方法 |
|:---|:---|
| 乾燥 | 食用も種子も水分12%以下で、歯でかんでも歯が入らずぱきっと割れる。完全に冷ましてから詰める |
| アズキゾウムシの防除 | 一世代が1か月足らずで、粒の大きいササゲでは1粒の中で何匹も育つ。三重袋(厚いビニール袋を3枚重ね、それぞれの口をしっかり縛る)は酸素を遮断して虫を窒息させ、ネズミがかじり破るので、ネズミの届かない缶の中や棚の上に置く。油のコーティングは豆1kgに食用油2-5mL(種子用は除く)。低温処理は真冬に数日外に出してまた入れるもので、入れるときは容器を開けず、室温になじむまで数時間置く |
| 容器、点検 | ガラス瓶と金属缶は3年以上、三重ビニール袋は1-2年。容器に耳を当ててかさかさと音がすれば虫が活動中で、かび臭いにおいはカビの始まりで、表面の小さな丸い穴はゾウムシが一世代を越えたしるし。月に1回点検し、被害があれば全量を取り出して日に干し、水に浮かべて空の粒をすくい取り、灰を混ぜてまた密閉 |

> **豆は腐って失うのではなく、虫に食べられて失います。ササゲでは、貯蔵は栽培と同じくらい大事な作業です。**

## 10. 調理と注意事項
| 成分 | 働き | 取り除く方法 |
|:---|:---|:---|
| トリプシンインヒビター | タンパク質分解酵素を妨げ、腹痛、下痢、タンパク質の利用率の低下を起こす | 6時間浸したあと、沸騰した湯で1時間 |
| オリゴ糖 | 腸内細菌が発酵させておなかにガスがたまる | 浸したあと、浸し水を捨てる |

> **ササゲの葉も生では食べません。シュウ酸と少量の抗栄養成分があるので、必ずゆでて食べ、ゆで汁は捨てます。**

&nbsp;&nbsp;&nbsp;ササゲはマメ類の中では毒性の危険が低く、インゲンマメの強いレクチンやソラマメのような急性溶血を起こす成分はありませんが、抗栄養成分はあるので十分に火を通します。

| 処理 | 基準 |
|:---|:---|
| 子実の基本 | 常温の水に6時間浸すと種皮がやわらかくなり、煮える時間が短くなる。沸騰した湯で1時間ゆでる |
| 皮をむいて割る | 浸して臼で軽くついて皮をむき、半分に割って乾かしておけば、20-30分で煮える。1、2か月で食べる分だけ加工 |
| 燃料の節約 | 圧力調理は浸した豆を15分加圧。余熱調理は15分煮たあと火を消し、わらやもみ殻の箱か布団で鍋を包んで2-3時間置く。炒ってひいた粉は水に溶いて飲む。発芽させるとビタミンCができる |
| 葉、若莢 | 葉は流水ですすぎ、沸騰した湯で1-2分ゆで、冷水ですすいでしっかり絞り、塩、油、ニンニクやみそで和える。若いさやは数分ゆでれば丸ごと食べられる |
| 貯蔵用の加工 | ゆでて干した葉(冬まで、干し菜)、炒ってひいたササゲの粉(密閉で3-6か月)、皮をむいて割ったササゲ(密閉で1-2か月)、ゆでて干した若莢(数か月)、ゆでてつぶし発酵させたササゲのみそ(ダイズが足りないときの代替) |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵の点検、低温処理、種子の発芽試験。2月に畑の計画を立て、やせた区画をササゲに割り当てる |
| 3-4月 | 3月に堆肥の切り返し、骨粉の準備。4月に前作の管理、畝20cmと排水溝の計画 |
| 5-6月 | 5月に畑の準備、畝づくり、排水溝掘り。6月に播種(中部は下旬、南部は中旬から)、接種、わらかけ |
| 7-8月 | 7月に1回目・2回目の草取り、間引き、遅まきの限界。8月に開花、マメノメイガの監視(毎朝花の中を確認)、葉摘み、根粒の確認 |
| 9-10月 | 9月に分割収穫の開始、網に入れて乾燥。10月に収穫を仕上げ、脱穀、選別、茎葉を戻す(霜の前に終える) |
| 11-12月 | 11月に乾燥、貯蔵、葉の干し菜づくり。12月に貯蔵の点検、加工、翌年の計画 |

> **ササゲは、排水を整え、リン酸を用意し、最初の5週に草取りをし、開花期に花の中を調べ、完全に乾かして密閉すれば、ほかの作物が育たない畑でも、葉と若莢と子実を順に出してくれる作物です。**
