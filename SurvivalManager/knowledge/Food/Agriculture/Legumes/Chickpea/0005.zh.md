## 8. 栽培管理

### 8-1. 杂草管理

| 时期 | 作业 | 要点 |
|---|---|---|
| 出苗后2~3周 | 第1次除草 | 趁杂草还小时拔除，浅浅地刮松表土 |
| 出苗后约45天 | 第2次除草 | 与培土同时进行 |
| 开花前 | 完成所有除草作业 | 此后不再进入田间 |

&nbsp;&nbsp;&nbsp;鹰嘴豆在与杂草的竞争中特别处于劣势。发芽要花10到15天，初期生长又慢，这段时间里杂草会抢先占据地盘。加上株高只有40cm左右，一旦被杂草遮盖就会被夺走光照。说初期6周的除草决定着鹰嘴豆的产量，也不为过。

&nbsp;&nbsp;&nbsp;不过除草也有需要注意的地方。鹰嘴豆的细根广泛分布在表层，锄得太深会切断根系。应将锄头放平，只刮起土表2cm来铲除杂草，靠近植株的部分则用手拔。另外，由于叶片的酸性分泌物，赤手长时间操作会让皮肤刺痛，最好戴手套。

&nbsp;&nbsp;&nbsp;开花后原则上不再进入田间。人一经过就会碰落花朵；露水未干的清晨走动，褐斑病孢子会沾在衣服和鞋子上，扩散到整片田地。尤其是雨后立即进出田间，是传播褐斑病最可靠的途径。

### 8-2. 培土与防倒伏管理

| 作业 | 时期 | 效果 |
|---|---|---|
| 培土 | 播种后约45天，与第2次除草同时进行 | 用土覆盖茎基部形成支撑，垄沟加深也利于排水 |
| 拉绳支撑 | 担心倒伏时 | 在地块四周打桩，在膝盖高度拉一圈绳子 |

&nbsp;&nbsp;&nbsp;鹰嘴豆株高20-100cm，通常在40cm左右，因此不需要支架。茎秆挺直、分枝多，能相互依靠站立。相比豌豆，这是鹰嘴豆的一个明显优势：即使没有竹竿和绳子也能种植。不过若施肥过量导致徒长，或遇上风雨强烈的年份，也可能倒伏，这时用培土和地块四周拉绳的方式应对即可。

## 9. 病虫害

&nbsp;&nbsp;&nbsp;鹰嘴豆的病虫害压力为C。得益于叶片的酸性分泌物，食叶害虫造成的损害比其他豆类少，但有两种真菌病害左右着这种作物的命运。

### 9-1. 主要病害

| 病名 | 症状 | 发生条件 | 不用药的应对 |
|---|---|---|---|
| 褐斑病（Ascochyta） | 叶、茎、荚上出现同心圆状的褐色斑点，茎从患处折断 | 阴雨连绵且凉爽时，经种子和残体传播 | 种子筛选与温水消毒、3年以上轮作、保证通风、焚烧病残体；蔓延时提前收获 |
| 枯萎病（Fusarium） | 开花期从下部叶片开始萎蔫，整株枯死。掰开茎秆内部呈褐色 | 土传病害，可在土壤中存活多年 | 3年以上轮作是唯一的对策，另可选育抗性品系 |
| 根腐病 | 茎基部和根系变褐腐软 | 过湿 | 排水、加高垄 |
| 白粉病 | 叶片表面覆盖白色粉状物 | 干燥且昼夜温差大时 | 保证通风、喷施稀释5-10倍的牛奶液 |
| 菌核病 | 茎秆腐软，出现白色棉絮状菌丝和黑色菌核 | 凉爽潮湿时 | 将病株连土挖出焚烧 |

> **褐斑病和枯萎病，这两者决定着鹰嘴豆种植的成败。褐斑病经由种子和残体传入，随雨势暴发；枯萎病则潜伏在土壤中，静候多年。在没有农药的条件下，能做的只有种子筛选、长期轮作和保证通风这三件事。**

&nbsp;&nbsp;&nbsp;褐斑病可怕之处在于速度。连续下几天雨，叶片上的小斑点几天内就会蔓延到茎部，茎一折断，整株便随之倒伏。严重的年份会损失整片田地。应对顺序如下：第一，因为病害始于种子，须彻底剔除带斑点的种子并进行温水消毒；第二，稀植以便叶片更快干燥；第三，雨后不进入田间；第四，染病的残体不还田而是焚烧；第五，若已经开始蔓延，不必等到完全成熟就提前收获。

&nbsp;&nbsp;&nbsp;枯萎病的性质不同。它以休眠孢子的形式潜伏在土壤中，能撑过许多年，一旦再次种上鹰嘴豆便会苏醒。地块一旦被污染，此后每逢开花期都会反复出现植株枯萎死亡。既没有药可用，也没有办法清除。3年以上、最好是4到5年的轮作是唯一的对策；第二个对策，是从那块地里挑出最终存活并结出种子的个体延续下去。抗性可以遗传，反复几年后就能在这块地上培育出耐受的品系。

### 9-2. 主要害虫

| 害虫 | 危害 | 不用药的防治 |
|---|---|---|
| 豆荚螟（棉铃虫等豆荚食害蛾类） | 幼虫钻入豆荚啃食籽粒，是最大的害虫 | 徒手捕捉卵块和幼虫；在地块四周种诱集作物；提前播种以避开发生高峰期 |
| 地老虎 | 夜间将幼茎从基部咬断 | 早晨在被咬断植株周围挖土能找到幼虫，捕杀即可 |
| 根结线虫 | 根部产生瘤状变形，生长不良 | 轮作、间作万寿菊 |
| 蚜虫 | 吸食汁液并传播病毒 | 肥皂水（1L水配5g肥皂）。得益于叶片的酸性分泌物，受害相对较轻 |
| 鸟 | 播种后啄食种子，灌浆期啄食籽粒 | 发芽前用稻草或网覆盖 |

&nbsp;&nbsp;&nbsp;豆荚螟是鹰嘴豆最大的害虫。叶片的酸性分泌物能击退食叶害虫，却挡不住钻入豆荚的幼虫。表面看豆荚完好，剖开却发现籽粒被吃空或藏着幼虫。不用药的应对方法有三种。第一，从结荚初期开始，清晨在田间巡视，徒手捕捉叶背的卵块和幼龄幼虫。第二，在地块四周种植蛾类更偏爱的作物，把它们吸引过去后集中捕杀。第三，通过提前播种，让结荚期赶在蛾类发生高峰之前。

### 9-3. 不用药的防治资材

| 资材 | 制作方法 | 对象 | 注意事项 |
|---|---|---|---|
| 波尔多液 | 在100L水中分别溶解硫酸铜400g和生石灰400g后混合 | 褐斑病、真菌病害 | 需要有铜才能配制，混合后须立即使用 |
| 肥皂水 | 1L水配5g无香型肥皂 | 蚜虫、红蜘蛛 | 正午高温时喷洒会灼伤叶片 |
| 牛奶稀释液 | 用水将牛奶稀释5-10倍 | 白粉病 | 在晴天上午喷洒 |
| 撒干草木灰 | 在有露水的清晨向叶片撒细灰 | 抑制真菌、驱食叶害虫 | 下雨会被冲掉 |
| 草木灰水 | 将1升（约1.8升）草木灰浸入10L水中一夜，取上层清液使用 | 抑制真菌 | 偏碱性，需稀释使用 |
| 木醋液 | 将烧炭时产生的液体稀释300-500倍 | 驱避、促进生长 | 原液强酸性，务必稀释后使用 |
| 辣椒·大蒜水 | 捣碎后用水浸泡，过滤后使用 | 驱避蛾类 | 药效不持久，需经常喷洒 |

### 9-4. 农业防治

| 方法 | 原理 |
|---|---|
| 种子筛选 | 褐斑病经种子传播，仅剔除有斑点和变色的种子就能大幅减少发病 |
| 温水消毒 | 用50-55℃水处理10-15分钟，杀死种子表面的病原菌 |
| 3年以上轮作 | 等待枯萎病孢子在土壤中逐渐减少 |
| 稀植 | 通风良好时叶片干得快，褐斑病难以立足 |
| 排水 | 鹰嘴豆的多数病害都与过湿有关 |
| 提前播种 | 让灌浆期赶在梅雨之前，并避开豆荚螟的发生期 |
| 雨后禁止进入田间 | 人碰到湿叶会让褐斑病扩散到整片田地 |
| 残体处理 | 染病的残体必须焚烧，只把健康的残体归还田地 |
| 从存活个体留种 | 从枯萎病流行的地块中挑选最终存活的植株延续下去 |

## 10. 营养缺乏与过量

| 症状 | 原因 | 天然材料应对 |
|---|---|---|
| 整株叶片淡黄、植株矮小 | 缺氮，鹰嘴豆中最常见的原因是接种失败 | 先挖根检查根瘤。若无根瘤，当年施极少量稀释10倍的尿液，次年务必接种 |
| 根瘤几乎不形成 | 专用菌缺失，或缺硫、缺钼 | 优先确保接种源。硫可通过畜粪堆肥和十字花科残体补充 |
| 叶缘变褐枯萎 | 缺钾 | 在株间撒草木灰并轻轻耙入土中 |
| 生长缓慢，叶片泛紫 | 缺磷，鹰嘴豆对磷需求高 | 骨粉、烧过的鱼骨粉 |
| 开花却不结荚 | 缺硼，或开花期夜间气温10℃以下 | 混合多种材料的堆肥；若因低温所致，则调整次年播种期 |
| 叶脉间发黄 | 缺铁或缺锰，常见于偏碱性土壤 | 停止使用草木灰，用腐叶土和腐熟堆肥增加有机质 |
| 茎叶徒长而豆荚稀少 | 氮过量 | 立即停止供氮 |

&nbsp;&nbsp;&nbsp;在鹰嘴豆上看到缺氮症状时，第一件该做的事不是施肥，而是挖根查看。韩国的地块几乎没有鹰嘴豆专用菌，未接种就种下的地块常常根本不长根瘤。这种情况下施氮，当年产量会略有改善，但问题的根源并未解决，反而会让原本就不多的根瘤进一步减弱功能。当年靠最少量的氮撑过去，次年通过接种从根本上解决问题，才是正确的顺序。

&nbsp;&nbsp;&nbsp;缺硫是鹰嘴豆需要单独留意的一项。其症状与缺氮相似，容易混淆：缺氮从下部叶片开始发黄，缺硫则从新长出的上部叶片开始变淡。硫不足时，即使形成了根瘤也无法正常发挥功能。掺入畜粪的堆肥、腐熟的鱼内脏、掺有大蒜、洋葱和大白菜残体的堆肥，都是切实可行的供硫来源。

## 11. 间作与轮作

### 11-1. 相宜作物

| 相性 | 作物 | 理由 |
|---|---|---|
| 好 | 小麦·大麦 | 根系深度不同，各自从不同土层吸收水分和养分 |
| 好 | 玉米·高粱 | 能利用鹰嘴豆留下的氮 |
| 好 | 万寿菊 | 根系分泌物能抑制线虫 |
| 好 | 芥菜·油菜 | 残体在土壤中留下含硫化合物，能减少病原菌 |
| 一般 | 叶菜类 | 初期能共同生长，但鹰嘴豆长大后会遮阴 |
| 差 | 其他豆科 | 病原菌和线虫会累积 |
| 差 | 需水量大的作物 | 鹰嘴豆最不耐涝 |

&nbsp;&nbsp;&nbsp;安排鹰嘴豆种植位置时，需要特别考虑水的问题。若与经常灌溉的作物种在同一垄或相邻的沟里，那些水会渗到鹰嘴豆的根部。鹰嘴豆是豆类中最不耐涝的，因此应安排在田里排水最好、灌溉水淋不到的位置。若地块有坡度，上部才是种鹰嘴豆的位置。

&nbsp;&nbsp;&nbsp;把芥菜、油菜等十字花科作物作为前茬，对鹰嘴豆特别合适。这些作物的残体在土壤中分解时会释放含硫化合物，既能降低枯萎病病原菌的密度，又能供给鹰嘴豆所需的硫。一种安排能同时解决两个问题。

### 11-2. 轮作

| 项目 | 标准 |
|---|---|
| 休作期 | 3年以上，因枯萎病会残留在土壤中 |
| 理想周期 | 4-5年 |
| 连作障碍 | 枯萎病和根结线虫会累积 |

| 4年轮作示例 |
|---|
| 第1年：鹰嘴豆 |
| 第2年：谷物（小麦·大麦·玉米） |
| 第3年：芥菜或油菜，接着种叶菜 |
| 第4年：薯类（块茎/块根）或根菜 |
| 再种鹰嘴豆 |

&nbsp;&nbsp;&nbsp;这里还多了一项鹰嘴豆特有的限制：必须维持接种源。若3年以上不种鹰嘴豆，专用菌的密度也会随之下降——在通过轮作减少病原菌的同时，有益菌也在减少。解决办法是单独辟出一块专用于接种源的区域：在地块一角的小块地上，每年连续少量种植鹰嘴豆以维持菌种，再把那块地的土每年用作大田的接种源。那块小区域里枯萎病会不断积累，但目的不是收获种子而是维持菌种，因此是可以承受的。

## 12. 收获与脱粒

### 12-1. 判断收获时期

| 判断标准 | 内容 |
|---|---|
| 叶 | 叶片变黄，大部分已脱落 |
| 荚 | 80%以上已变为褐色 |
| 声音 | 摇晃时能听到荚内籽粒碰撞的声音 |
| 籽粒 | 咬下去牙齿陷不进去，会脆脆地裂开 |
| 水分 | 收获时18%，贮藏时14%以下 |
| 时点 | 播种后100-120天 |

> **有降雨预报时，不必等到完全成熟就收获。鹰嘴豆灌浆期的雨水不仅会导致落粒，还会招来褐斑病。稍欠成熟的豆子晒干后仍可使用，但染病的田地将颗粒无收。**

### 12-2. 收获要领

| 顺序 | 内容 |
|---|---|
| 1 | 选晴朗干燥的日子，在露水干后的上午10点以后进行 |
| 2 | 戴上手套，叶片和豆荚的酸性分泌物会刺激皮肤 |
| 3 | 贴近地面割茎，根留在地里 |
| 4 | 捆成束在阳光下晾晒4-6天，或挂在屋檐下晾干 |
| 5 | 豆荚彻底晒干、摇晃有响声时即可脱粒 |

&nbsp;&nbsp;&nbsp;戴手套在鹰嘴豆收获中并非流于形式的建议。叶片和豆荚上密生的分泌腺会分泌苹果酸和草酸，使植株表面呈酸性，赤手劳作半天，指尖就会刺痛皲裂。尤其是露水未干或雨后不久，分泌物溶于水中刺激性更强。哪怕只是用布裹住手，也会有很大不同。

### 12-3. 脱粒——不用工具的方法

| 方法 | 工具 | 步骤 | 效率 |
|---|---|---|---|
| 踩袋法 | 厚麻袋或布袋 | 把干茎装入袋中扎紧袋口，用脚踩踏 | 最适合少量作业，籽粒不会飞溅出去 |
| 连枷 | 长柄上系着甩杆的工具 | 铺开席子，把茎秆薄薄摊开，从上方抽打 | 适合中等规模。用力过猛籽粒会裂开 |
| 棍棒敲打 | 木棒 | 装入袋中或摊在席子上敲打 | 没有连枷时可替代使用 |
| 脚搓法 | 无 | 摊在席子上，穿鞋的脚踩踏揉搓 | 适合少量作业 |
| 摔打在板上 | 木板或木桶 | 抓住茎束往桶内壁摔打 | 籽粒聚集在桶内，损耗少 |

&nbsp;&nbsp;&nbsp;鹰嘴豆脱粒时需特别注意籽粒容易裂开。虽然种皮厚，但籽粒本身结构容易一分为二，用力敲打会产生大量裂成两半的籽粒。作食用没有问题，但不能作种子用，而且贮藏时虫害会优先从裂口侵入。装袋踩踏的方式损耗最少；使用连枷时，最好减轻力道多打几次。

### 12-4. 精选——用风筛选

| 方法 | 原理 | 步骤 |
|---|---|---|
| 扬风（借风筛选） | 籽粒重，皮壳和碎屑轻 | 在有风的日子，把籽粒装入簸箕或宽口容器，举高后缓缓倒出 |
| 用簸箕颠簸 | 上下晃动并向前颠簸 | 重的籽粒留在后方，轻的被推向前方 |
| 扇风 | 一人倾倒，一人用扇子扇风 | 用于无风的日子 |
| 过筛 | 按孔径大小分级 | 对筛出裂成两半的籽粒特别有效 |
| 水选 | 瘪粒和虫蛀粒较轻 | 倒入水桶，捞去浮起的部分。捞出的部分需当天再次晒干 |
| 斜板滚选 | 圆润的籽粒容易滚动，碎屑则会卡住 | 把木板斜放，让籽粒滚落下来 |

&nbsp;&nbsp;&nbsp;扬风筛选有三个要领：选在风力稳定的清晨或傍晚，不要一次性倒完而是细细地缓缓倒下，并重复两三次。对鹰嘴豆而言，最好再多加一道过筛的工序：脱粒过程中裂成两半的籽粒用细筛筛出单独收集，这类籽粒不适合贮藏，可先食用，把完整的籽粒留作贮藏。
