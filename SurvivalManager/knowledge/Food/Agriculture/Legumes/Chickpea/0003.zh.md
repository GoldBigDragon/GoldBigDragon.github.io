## 3. 栽培环境

### 3-1. 气温与光照量

| 条件 | 极限值 | 最适值 | 超出范围时 |
|---|---|---|---|
| 发芽温度 | 10℃以上 | 20-25℃ | 低温下发芽会更慢，原本也需要10-14天 |
| 生长温度 | 12-35℃ | 21-26℃ | 夜间需要15℃以上 |
| 结实温度 | 15-28℃ | 18-26℃ | 幅度13℃，在豆类中属于较宽的 |
| 开花期低温 | 夜间10℃以下 | - | 花粉发育不良，无法结荚 |
| 开花期高温 | 35℃以上 | - | 落花。不过耐高温性在豆类中算较好的 |
| 耐寒性 | 耐轻霜 | - | 能挺过零下几℃的短时霜冻 |
| 光照 | 每天6小时以上 | 每天8小时以上 | 40%遮光时产量降至一半 |

&nbsp;&nbsp;&nbsp;鹰嘴豆意外棘手的一点是开花期的夜间气温。夜间若降到10℃以下，花粉便发育不良，即便开花也不能结荚。在韩国，若在3月底播种，开花期落在6月，可以避开这一问题；但播得太早，开花期可能撞上5月偏凉的夜晚。反过来，播得太晚又会赶上梅雨季，褐斑病随即大面积暴发。这就是适宜播种期窗口狭窄的原因。

> **种植鹰嘴豆最可怕的不是干旱，而是梅雨。缺水的年份只是减产，但若在豆荚成熟前后连续降雨，褐斑病会让整片田地颗粒无收。**

### 3-2. 土壤与水分

| 条件 | 极限值 | 最适值 | 备注 |
|---|---|---|---|
| 土质 | 从砂质土到壤土 | 排水良好的砂壤土-壤土 | 绝对避开黏质土和积水地 |
| pH | 5.5-8.6 | 6.0-8.0 | 适应幅度在豆类中最宽 |
| 有效土层 | 60cm以上 | 1m以上 | 主根可深入1m |
| 生长期蒸散量 | - | 约250mm | 在豆类中最低 |
| 淹水 | 只淹1天根系就会受损 | - | 在豆类中最不耐涝 |
| 耐盐性 | 低 | - | 不适合含盐分的土地 |
| 地下水位 | 80cm以下 | 1m以下 | 根系深，地下水位一高就立刻受损 |

&nbsp;&nbsp;&nbsp;5.5到8.6的pH适应幅度在豆类中最宽。这意味着无论是酸性还是碱性土壤，鹰嘴豆都相当耐受，在难以获得石灰的条件下，这是一项实际的优势。不过一旦低于5.5，根瘤的形成就会变差，因为植株本身能耐受，但细菌却无法存活。

&nbsp;&nbsp;&nbsp;耐涝性差是种植鹰嘴豆时最该强调的一点。它越耐旱，就越怕涝。由于主根扎得很深，在地下水位高的地块，根尖会始终泡在水里，紧接着就会引发根腐病。起垄20cm以上、挖深排水沟，是种植鹰嘴豆的前提条件。水田改旱地的地块、山谷低处、容易积水的洼地都应避开。

## 4. 品种

### 4-1. 两大类型

| 类型 | 种子 | 特征 | 灾害适合度 |
|---|---|---|---|
| 迪西型（Desi） | 小而带棱角，褐色·黑色，种皮厚 | 耐寒性和抗旱适应力出色，生育期短，耐瘠薄 | 高 |
| 卡布里型（Kabuli） | 大而圆，奶油色·白色，种皮薄 | 条件好时产量高，生育期长，较难伺候 | 中等 |

&nbsp;&nbsp;&nbsp;全世界80%以上的鹰嘴豆是迪西型，我们在市面上常见的那种个大色白的鹰嘴豆则是卡布里型。从灾害应对的角度看，迪西型明显更优：种皮厚，在土里不易腐烂；根系更深；生育期短，能在梅雨之前收获完毕；在贫瘠干旱的地块上减产幅度也更小。而且种皮厚也意味着贮藏期间更耐虫蛀。

&nbsp;&nbsp;&nbsp;迪西型的缺点是籽粒小、皮厚，烹饪起来更费工夫。因此在印度，人们会把迪西型去皮掰成两半，做成恰纳豆（chana dal）。做成这种形态后，烹饪时间反而比卡布里型更短。

&nbsp;&nbsp;&nbsp;韩国实际上没有已登记的鹰嘴豆品种。韩国农村振兴厅的适应性试验显示，引进的地方品系产量在每1,000㎡ 9-217kg之间剧烈波动，也就是说不同品系、不同年份的差距可达20倍以上，能拿到哪个品系直接决定成败。若已确保种子，头两三年宜在小面积上分别试种多个品系，从中挑出适合自家地块的那个，这样更为合理。

### 4-2. 按情形选择的标准

| 情形 | 优先选择 | 理由 |
|---|---|---|
| 地块贫瘠又干旱 | 迪西型 | 在此条件下减产幅度最小 |
| 梅雨来得早 | 迪西早熟品系 | 必须赶在雨季前收获完毕 |
| 种子不足 | 迪西型 | 籽粒小，同样重量可播种2~3倍的面积 |
| 烹饪燃料不足 | 加工成去皮掰半的形态 | 无论哪种品系，烹饪时间都能减半 |
| 首次获得种子 | 分成多个品系分别种植 | 适应性差异极大，需要经过筛选过程 |

## 5. 整地与施肥 — 根瘤菌

### 5-1. 固氮是如何发生的

&nbsp;&nbsp;&nbsp;空气中78%是氮气。尽管人们头顶飘浮着取之不尽的氮，植物却无法利用它。空气中的氮是两个氮原子以三键紧紧结合而成的分子，要打破这个键需要巨大的能量。工业上打破这一键合成氨的方法就是哈伯-博施法，世界上的氮肥皆由此而来，需要高温、高压、催化剂和大量的化石燃料。

&nbsp;&nbsp;&nbsp;根瘤菌能在常温常压下完成这项工作。它用一种叫固氮酶的酶打断三键，把氮转化为氨。不过这是有代价的：这个反应需要大量能量，而细菌本身不能进行光合作用。于是它便住进豆科植物的根里，接受植物通过光合作用制造的糖分，作为回报，把固定下来的氮交给植物。这是一种交易关系。

> **与鹰嘴豆配对的菌种是名为Mesorhizobium ciceri的专用菌。种过大豆、豌豆或菜豆的地块土壤，不能作为鹰嘴豆的接种源。这种作物的接种，比其他任何豆类都更为棘手。**

&nbsp;&nbsp;&nbsp;这一点是种植鹰嘴豆在实务上最大的难点。从未种过鹰嘴豆的地块土壤中，这种菌几乎不存在，韩国大多数田地都是如此。不接种就种植的话，根瘤几乎不会形成，植株无法自行合成氮，叶片会发黄，产量大幅下降。据推测，这正是韩国国内适应性试验中产量波动如此剧烈的原因之一。

| 阶段 | 发生的过程 |
|---|---|
| 1. 信号交换 | 鹰嘴豆根系分泌类黄酮，土壤中的细菌接收到信号后释放结瘤因子 |
| 2. 侵染 | 根毛向内卷曲包住细菌，细菌沿侵染线进入根内部 |
| 3. 根瘤形成 | 根内部细胞分裂使根瘤膨大，细菌在其中定居 |
| 4. 固氮 | 根瘤内固氮酶发挥作用，将空气中的氮转化为氨 |
| 5. 分配 | 氨转化为氨基酸，运往茎、叶和豆荚 |
| 6. 衰老 | 进入灌浆期后根瘤失去功能，随根系一同归还土壤 |

&nbsp;&nbsp;&nbsp;固氮酶对氧气非常敏感，一接触氧气就立刻失去功能。因此根瘤内部充满了一种叫豆血红蛋白的红色色素蛋白，它能抓住氧气，把酶周围的氧浓度维持在极低水平。这和人血呈红色是同一个原理，掰开根瘤后内部呈红色或粉红色，正是这种色素的颜色。这一点在实践中极为重要，因为红色就是该根瘤正在固氮的可见证据。

### 5-2. 如何确认根瘤是否形成

&nbsp;&nbsp;&nbsp;无论是否接种，都必须确认根瘤是否真的形成了。对鹰嘴豆而言，这项确认比其他豆类更重要，因为许多地块没有土著菌，失败的概率更高。

| 顺序 | 内容 |
|---|---|
| 1 | 开花开始前后、播种后约8周是最佳时机 |
| 2 | 挑选2~3株长势健康的植株 |
| 3 | 不要直接拔，用铁锹在植株周围大范围铲挖，连土一起挖出。主根深，需挖得深一些 |
| 4 | 放入水桶中，轻轻将泥土洗掉 |
| 5 | 数一数主根和粗侧根上着生的根瘤数量 |
| 6 | 用指甲掰开几颗根瘤，观察内部颜色 |

| 观察结果 | 含义 | 应对 |
|---|---|---|
| 根瘤每株15个以上，尤其集中在主根上部 | 接种效果良好 | 保持现状 |
| 掰开后内部呈红色或粉红色 | 正在固氮 | 状态良好 |
| 掰开后内部呈白色或浅绿色 | 根瘤已形成但未固氮 | 检查酸度、涝害、磷和硫的缺乏情况 |
| 掰开后内部呈褐色或黑色 | 已经衰老或死亡 | 处于灌浆期属正常，处于开花期则有问题 |
| 几乎没有根瘤 | 说明这是没有土著菌的地块，最常见的情况 | 当年补施氮肥，次年用这块地的土壤作接种源 |

> **挖出根系、掰开根瘤确认红色，这一个习惯，就是在没有氮肥的世界里判断豆类种植成败最可靠的信号。**

### 5-3. 从哪里获取接种源

&nbsp;&nbsp;&nbsp;商用接种剂是把活细菌拌入泥炭或黏土制成的产品，灾害状况下无法取得。鹰嘴豆需要专用菌种，因此接种源的获取比其他豆类更棘手，但并非完全无路可走。

| 方法 | 步骤 | 效果 | 注意事项 |
|---|---|---|---|
| 沾附种过鹰嘴豆的地块土壤 | 从前一年种过鹰嘴豆、根瘤长得好的地块，挖取表土下5-15cm深处的土。将种子用水稍微打湿，蘸上这些土后立即播种 | 最为可靠 | 需要有种过鹰嘴豆的地块 |
| 直接使用根瘤 | 把挖出的根上的根瘤收集起来捣碎，溶于水中，将种子浸入后取出 | 菌密度最高 | 必须在挖出根瘤的当天使用 |
| 第一年不接种 | 第一年不得已不接种直接播种，补施少量氮肥 | 产量虽低，但菌会留在这块地里 | 从次年起这块地的土壤就能作接种源 |
| 建立接种源地块 | 在狭小地块上集中种植鹰嘴豆以扩繁菌种 | 次年可作为大面积田地的接种源 | 种子稀缺时是合理的策略 |
| 将土撒入田中 | 把运来的土撒在播种行上，一起翻入土中 | 菌能在土壤中扩散 | 大致每10㎡撒一铲左右 |
| 保留根系残茬 | 收获时只割茎秆，把根留在地里 | 菌会在土壤中保留到次年 | 是最省事的维持方法 |

&nbsp;&nbsp;&nbsp;建议采取单独建立接种源地块的策略。若是首次获得种子，第一年可先集中种植在狭小地块上，让菌在土壤中定殖，再把这块地的土用作次年的接种源。反正鹰嘴豆本来头两三年就得用于留种，相当于在这段时间里顺带把接种源也建立起来了。菌一旦在某块地定殖，就能维持接种能力达数年之久。

&nbsp;&nbsp;&nbsp;接种时有几点必须遵守。根瘤菌对直射光、干燥和高温都非常敏感，紫外线照射几分钟就会杀死相当一部分，干燥则死得更快。给种子裹土的操作要在阴凉处进行，裹好的种子不要晾晒，应立即播种。传统上会用糖蜜、糖水或淘米水之类黏稠的液体薄薄涂在种子表面，让土更容易附着。还有一点，种子消毒和接种不能同时进行：如果用了热水处理消毒，必须完全放凉后再接种。

| 导致接种失败的条件 | 原因 |
|---|---|
| 使用种过其他豆类地块的土 | 菌种不同，不会侵染鹰嘴豆 |
| 土壤pH 5.5以下 | 细菌无法存活 |
| 施了充足氮肥的地块 | 植株感觉不到交易的必要，自行减少根瘤形成 |
| 积水的地块 | 属好氧菌，缺氧就会死亡 |
| 缺磷的地块 | 固氮需要大量能量，这一代谢过程要用到磷 |
| 缺硫的地块 | 在鹰嘴豆上，缺硫会直接表现为根瘤形成不良 |
| 缺钼·铁·钴 | 它们是固氮酶的组成成分 |
| 把接种过的种子拿去晒干 | 紫外线和干燥会杀死菌 |
