## はじめに
&nbsp;&nbsp;&nbsp;ヒヨコマメ(Cicer arietinum)はトルコ南東部の野生のヒヨコマメに由来する、南西アジアの乾燥地原産のマメ科の一年草で、世界で2番目に多く栽培されているマメ科作物です。最も際立った強みは乾いた土に耐える力で、水の消費量はSであり、蒸発散量の合計250mmで1作を終えます(ダイズ450-700mm、エンドウ400mm)。根が1mより深くまっすぐ下りて、深い土の水を引いて使うためです。総合等級はC(41.2点、有効183種中92位)で、短期D(39.7)、長期C(42.8)、副食はSS(62.2点)です。面積当たりの熱量がDで1,000㎡に180kg、1㎡当たり679kcal、自給ラインの0.26倍にすぎず、国内での栽培の普及度がCなので、一、二の道(行政区)で試験栽培されているだけで、種子を入手するのは事実上難しいです。流通が途絶えれば、手元にない種子は存在しないのと同じなので、今のうちに種子を確保して自家採種で増やしておく必要があり、確保できなければダイズ、アズキ、ササゲで計画を立てるほうが現実的です。自家受粉のため純系が保たれ、常温で密閉して3年もつので、種子を確保したあとは自分で続けていけます。

| 短期 | D | 39.7 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: 施肥、施設の負担、貯蔵性。S: タンパク質密度、微量栄養素、水の消費量、味、自家採種。A: 合成資材を投入しない場合の収量維持率、収量の安定性、種子の寿命。B: 収穫速度、温度幅、耐寒性、防除の自立度、連作への適応性 |

> **ヒヨコマメは腹を満たす作物ではなく、乾いた土でもタンパク質と鉄を出してくれる作物です。雨が降らない年に、ほかの豆が失敗した場所で何かを収穫できること、それがこの作物の居場所です。**

&nbsp;&nbsp;&nbsp;微量栄養素Sが副食等級SSの根拠で、貯蔵性SSは常温で密閉して長くもちます。調理・加工Dは硬い種皮のために毎日払う費用であり、連作への適応性Bと病害虫圧Cはあわせて読んで3年以上の輪作を守らなければなりません。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | マメ科ヒヨコマメ属の一年草。トルコ南東部からシリアにかけての地域原産で自家受粉 |
| 葉、茎 | 葉は羽状複葉で、細かい毛と分泌腺がびっしり。茎はまっすぐ立って根元から枝を多く出し、高さ20-100cm(おおむね40cm前後)で支柱は不要 |
| 根、花 | まっすぐな主根が1mより深く下り、マメ類で最も深い。花は白、淡いピンク、紫色の小さな蝶形で、葉の付け根に1つずつ咲く |
| 莢、子実 | 短くふっくらして細かい毛があり、粒が1-2個しかないため収量の構造的な限界。子実はしわがあり、片側にとがったくちばしがあって鳥の頭に似る |

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 発芽、幼苗期 | 播種後4週 | 発芽に10-14日かかり、その間に根が先に深く下りる |
| 栄養成長期 | 4-8週 | 茎が立ち、枝を多く出す |
| 開花期、莢肥大期 | 8-14週 | 下の節から順に花が咲き、莢がふっくらする |
| 登熟、成熟期 | 12-17週 | 葉が黄色くなり、莢が茶色に乾く |

> **ヒヨコマメの葉の酸性の分泌物は、害虫を退ける天然の防御装置です。この作物がほかの豆より葉をかじる虫の被害を受けにくい理由であり、同時に素手で長く触ると皮膚がひりひりする理由でもあります。**

&nbsp;&nbsp;&nbsp;乾燥した子実100g当たり熱量377kcal、タンパク質17.78g(熱量比18.9%)、脂質6g前後、炭水化物60g前後、食物繊維10-26g、糖類2.55g、カルシウム127-184mg、鉄4.6-8.3mg、リン286-528mgで、葉酸が豊富です。カルシウムと鉄がともに高く、肉がないときの重要な供給源ですが、オリゴ糖が多く、急にたくさん食べるとおなかにガスがたまります。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽10℃以上(最適20-25℃)。生育12-35℃(最適21-26℃、夜間15℃以上)、結実15-28℃。開花期に夜10℃以下だと花粉がうまくできず莢がつかず、35℃以上だと花が落ちる。軽い霜には耐える |
| 光 | 1日6時間以上(8時間以上が最適)、40%遮光で収量が半分 |
| 水、土壌 | 水はけのよい砂壌土か壌土(粘質土と水がたまる土地は絶対に避ける)、pH5.5-8.6(マメ類で最も広い)、有効土層60cm以上。作期の蒸発散量は約250mm。1日冠水しただけでも根が傷み、マメ類で湿害に最も弱く、耐塩性も低い。地下水位は1m以下 |

> **ヒヨコマメの栽培で最も怖いのは干ばつではなく梅雨です。水が足りない年は収量が減りますが、莢が熟すころに雨が長く続くと、アスコキタ病で畑全体を失います。**

| 系統 | 特徴 |
|:---|:---|
| デシ型 | 小さく角ばった茶色か黒の種子で種皮が厚く、耐寒性と干ばつへの適応力に優れ、生育期間が短く、やせ地に強い。災害への適合度が高い。世界のヒヨコマメの80%以上 |
| カブリ型 | 大きく丸いクリーム色か白の種子で種皮が薄く、条件がよければ収量が多いが、生育期間が長く手がかかる。市販の大きく白いヒヨコマメ |

&nbsp;&nbsp;&nbsp;国内には登録された品種が事実上なく、導入系統の収量が1,000㎡当たり9-217kgと極端に分かれるので、初めて種子を入手したら複数の系統に分けて植えて選び出します。畑がやせて乾いているか種子が足りなければデシ型(粒が小さく、同じ重さで2、3倍広く植えられる)を、梅雨が早く来るならデシ型の早生系統を選びます。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 畑づくり | 20-30cmの深さに耕し、畝は20cm以上(湿害防止の前提条件)、排水溝は深さ30-50cm。完熟堆肥1,000-1,500kg/1,000㎡ |
| 施肥(1,000㎡) | 窒素0-2kg(多いと窒素固定が抑えられる)、リン酸20-40kg、カリウム3-5kg、硫黄10-20kg(すべて元肥)。硫黄が不足すると根粒がうまくできず窒素固定が崩れる |
| 代替資源 | 骨粉(リン酸、カルシウム)、魚の骨と内臓(リン酸、窒素、硫黄)、木灰(㎡当たり100-200g)、家畜ふん堆肥とニンニク・タマネギの皮・ハクサイの外葉の堆肥(硫黄)、尿の10倍希釈液(ごく少量) |
| 根粒の接種 | 専用の根粒菌(Mesorhizobium ciceri)が必要で、ダイズ、エンドウ、インゲンマメを育てた畑の土は役に立たない。ヒヨコマメを育てたことのある畑の表土5-15cmの土を水で軽く湿らせた種子にまぶし、すぐに播種。初年は接種なしで少量の窒素を補い、狭い区画に集中して播種して菌を増やし、翌年の接種源に使う |

> **ヒヨコマメと組になる菌は専用の菌です。ダイズやエンドウやインゲンマメを育てた畑の土は、ヒヨコマメの接種源になりません。この作物の接種は、ほかのどのマメ類よりも手がかかります。**

&nbsp;&nbsp;&nbsp;開花のころ(播種後8週)にスコップで深くすくって洗い、根粒を割ってみます。1株15個以上で内側が赤ければ接種がうまくいっており、白か薄い緑なら酸度、湿害、リン酸と硫黄の欠乏を調べ、根粒がほとんどなければ土着の菌がいない畑です。水がたまる畑、窒素肥料の過多、リン酸と硫黄の不足も接種を失敗させます。固定量は1ヘクタール当たり60-100kg(接種に失敗すると5-15kg)ですが、子実で45-60kgが出ていくので、茎葉を20-30cmに切って畑に戻し、焼かず、根も掘り上げないようにしてはじめて、土を収奪せずにすみます。

| 播種 | 基準 |
|:---|:---|
| 時期 | 霜が完全に終わったあとの3月下旬-4月中旬(収穫は7月中旬-8月)。秋まきは冬の寒さを越せない |
| 種子の準備 | 斑点、変色、しわ、虫食いの穴のある種子を捨てる(アスコキタ病は種子で伝染する)。水に浮かべて浮く粒を取り除き、50-55℃の湯に10-15分浸して消毒し、細かい木灰をまぶす。浸漬はしない(種皮が軟らかくなって腐る)。発芽試験は2週間待つ |
| 方法 | 深さ3-5cm、1穴1-2粒、条間25-60cm、株間20-25cm。播種量は1,000㎡当たり、デシ型の小粒種2.5-4kg、カブリ型の大粒種8-12kg。播種後10日から2週間は何も出てこず、鳥を防ぐために発芽までわらかネットで覆う |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から発芽 | 土が完全に乾かないように |
| 生育初期 | 水を与えない(乾いた条件が根を1mより深く押し下げる) |
| 開花期から莢肥大期 | 干ばつがひどければ灌水(この時期の水不足が収量を最も大きく減らす) |
| 登熟期、梅雨 | 灌水を中止(過湿だと脱粒と品質低下)。梅雨は排水溝を掘る |

> **ヒヨコマメの水管理は、与える技術ではなく我慢する技術です。初期に水をたびたび与えると根が浅くなり、浅い根は後の干ばつに耐えられません。**

&nbsp;&nbsp;&nbsp;日中に葉が折りたたまれ、夕方に開くのは、正常な水の節約反応です。朝にも折りたたまれたままなら深刻な乾燥で、下の葉が黄色く根元が茶色く軟らかくなるなら過湿による根腐れなので、排水溝を掘ります。

| 管理 | 方法 |
|:---|:---|
| 草取り | 出芽後2-3週に1回目(浅く削る)、45日ごろに2回目(土寄せと兼ねる)、開花前にすべての除草を終える。雑草との競争に特に弱く、開花以降は畑に入らない |
| 土寄せ、綱の支え | 播種後45日ごろに根元を土で覆って支えをつくり、溝を深くして水がよく抜けるようにする。倒れそうなら畑の周りに杭を打ち、ひざの高さに綱を張る |

## 6. 病害虫と養分の問題
| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| アスコキタ病 | 葉、茎、莢に同心円模様の茶色の斑点ができ、茎が折れる。雨が続き涼しいとき、種子と残渣で伝染 | 種子の選別と温湯消毒、3年以上の輪作、風通しの確保、病気の残渣の焼却。広がったら早めに収穫 |
| 萎凋病 | 開花期に下の葉から萎れ、株ごと枯れて死に、茎の内部が茶色。土の中で何年も生存 | 3年以上の輪作が唯一の対策。生き残った株から採種 |
| 根腐病、菌核病、うどんこ病 | 根元と根が茶色く軟らかくなる(過湿) / 白い綿のような菌糸と黒い粒 / 葉に白い粉 | 排水と畝を高くする / 病株を土ごと掘り上げて焼く / 風通しの確保、牛乳の5-10倍希釈液 |
| 莢食い虫 | 幼虫が莢に穴をあけて入り、子実を食べる最大の害虫 | 卵と幼虫を手で捕り、畑の周りにおとり作物を植え、早まきで発生期を避ける |
| ネキリムシ、ネコブセンチュウ、アブラムシ | 夜に若い茎を根元から切る / 根にこぶ状の変形 / 汁を吸いウイルスを媒介 | 切られた株の周りの土を掘って幼虫を捕る / 輪作、マリーゴールドとの間作 / 石けん水(水1Lに石けん5g) |

> **アスコキタ病と萎凋病、この二つがヒヨコマメ栽培の成否を分けます。アスコキタ病は種子と残渣を通じて来て雨とともに爆発し、萎凋病は土に残って何年も待ちます。薬のない条件での対応は、種子の選別と長い輪作と風通しの確保、この三つだけです。**

&nbsp;&nbsp;&nbsp;ボルドー液は水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜ、すぐ使います。まばらに植える、排水、雨のあとは畑に入らない(濡れた葉に触れるとアスコキタ病が畑全体に広がる)が耕種的な防除です。

| 症状 | 原因と対処 |
|:---|:---|
| 葉全体が薄い黄色で株が小さい | 窒素欠乏(接種の失敗がもっとも多い)。まず根を掘って根粒を確認し、その年は尿の10倍希釈液をごく少量与える |
| 根粒がほとんどできない | 専用の菌の不在、または硫黄・モリブデンの欠乏。接種源の確保が先で、硫黄は家畜ふん堆肥とアブラナ科の残渣で補う |
| 生育が遅く葉が紫色を帯びる | リン酸欠乏。骨粉、焼いた魚の骨 |
| 花が咲いても莢がつかない | ホウ素欠乏、または開花期の夜の気温が10℃以下。翌年は播種期を調整 |
| 茎と葉だけ茂って莢が少ない | 窒素過剰。窒素の供給をすぐ止める |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | コムギ、オオムギ(根の深さが違い、異なる層の水と養分を使う)、トウモロコシ、ソルガム(ヒヨコマメが残した窒素をあとで使う)、カラシナ、ナタネ(残渣の硫黄化合物が病原菌を減らす) |
| 悪い | ほかのマメ科(病原菌とセンチュウがたまる)、水を多く与える作物(ヒヨコマメは過湿にもっとも弱い) |

&nbsp;&nbsp;&nbsp;休作は3年以上、理想の周期は4-5年で、萎凋病とネコブセンチュウがたまります。輪作の例は、ヒヨコマメ → コムギ、オオムギ、トウモロコシ → カラシナかナタネのあとの葉菜類 → ジャガイモか根菜類 → ヒヨコマメです。カラシナやナタネのようなアブラナ科を前作にするのが特によく合います。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 播種後100-120日、葉が黄色くなってほとんど落ち、莢の80%以上が茶色で、かむとぱきっと割れるとき。水分は収穫時18%、貯蔵時14%以下 |
| 要領 | 晴れて乾燥した日の露が乾いた午前10時以降に、葉と莢の酸性の分泌物が皮膚を刺激するので手袋をして地面近くで刈り、根は残す。束にして日に4-6日干すか、軒下に吊るして乾かす |
| 脱穀、選別 | 乾いた茎を袋に入れて踏むか、からざおで打ち(強く打つと粒が割れる)、桶の内側の壁に打ちつけてもよい。風のある日に箕で煽って殻を飛ばし、ふるいで割れた半粒を除き、水に浮かべて浮くものを取り除いたあと、その日のうちにまた乾かす |

> **雨の知らせがあれば完熟を待たずに刈り取ります。ヒヨコマメの登熟期の雨は、脱粒だけでなくアスコキタ病も呼び込みます。少し未熟な豆は乾かして使えますが、病気の畑では何も収穫できません。**

| 採種 | 基準 |
|:---|:---|
| 選抜、収穫 | 病気の症状がなく、莢が多くつき、萎凋病が出た畑で最後まで生き残った株、早く熟す株をあらかじめ印をつける。別に脱穀し、手でむくと粒が割れない |
| 選別、乾燥 | 斑点、割れた粒、しわ、変色を捨て、大きくて完全な粒だけを残す。水分12-13%で、日陰でゆっくり乾かす |
| 保管 | 食用とは別の密閉容器に入れて、涼しく暗い場所に置く。常温で密閉して3年、発芽率は収穫当年85%以上、1年後75-85%、2年後60-75%。入手できれば3-4年ごとにほかの場所の種子を一部混ぜる |

> **ヒヨコマメは国内で種子を再び入手するのが難しい作物です。採種は選択ではなく、この作物を育て続けるための前提条件です。食べる分を減らしてでも種子を先に確保しておきます。**

## 9. 貯蔵
| 段階 | 方法 |
|:---|:---|
| 乾燥 | 茎ごと日に4-6日、脱穀後は薄く広げて2-3日乾かし、水分を食用14%以下、種子12%(かんでも歯が入らない)にする。乾いた瓶に豆と乾いた塩を入れて振り、塩が壁につくならさらに乾かし、完全に冷ましてから詰める |
| マメゾウムシ類の防除 | 完全密閉がもっとも重要。真冬に数日外に出す低温処理(戻すときは結露に注意)と、木灰、珪藻土、油のコーティングを使う。割れた粒は虫が先に入るので、ふるいにかけて先に消費 |
| 容器、場所 | かめと地下貯蔵穴は2-3年(貯蔵穴は水が染みると全量を失う)。カビの生えた豆は洗っても加熱しても安全にならないので捨て、点検は聴覚と嗅覚で行う |

## 10. 調理と注意事項
| 成分 | 働き | 取り除く方法 |
|:---|:---|:---|
| トリプシンインヒビター、レクチン | タンパク質の消化を妨げ、腹痛と下痢を起こす。レクチンはインゲンマメよりはるかに弱い | 8時間浸したあと、沸騰した湯で1時間以上加熱 |
| オリゴ糖、サポニン | 腸内発酵でおなかにガスがひどくたまる / 泡 | 浸した水を必ず捨てる / ゆでながら泡をすくい取る |
| 葉と莢の有機酸、カビ毒素 | リンゴ酸とシュウ酸が皮膚と胃を刺激 / 貯蔵中にカビがつくった毒素 | 葉は食べず、作業のときは手袋をする / カビが生えたものは捨てる |

> **ヒヨコマメで実際に人を害するのは、豆そのものではなく、誤って貯蔵してカビが生えた豆と、火の通りが足りないまま食べた豆です。かび臭いにおいがしたり、表面に青みがかった粉が見えたりしたら、惜しまずに捨てます。**

| 処理 | 基準 |
|:---|:---|
| 基本 | 常温の水に8時間以上浸し(夏は水を替えながら6時間)、浸し水を捨てたあと、沸騰した湯で1時間から1時間半ゆでる。ゆで水に重曹をごく少量入れるか、木灰を溶かした上澄みを使うと皮が早く軟らかくなり、燃料が減る。指で押して簡単につぶれれば煮えた状態 |
| 皮をむいて割る | 水に軽く浸して半日日陰に置き、臼で軽くついて皮をむき、箕で煽って飛ばしたあと、またついて半分に割り、完全に乾かして密閉して保管。浸漬なしで20-30分でかゆのように軟らかくなり、燃料が半分になる |
| 燃料の節約 | 余熱調理は20分煮たあと、わらやもみ殻の箱か布団の中で3-4時間。浸してから乾かした豆を油なしで炒るとそのまま食べられ、炒ってひいた粉は水で練るか飲み物に溶いて飲む |
| 発芽、発酵 | 8時間浸して水を切り、濡れた布で覆って2-3日、芽が1cmほど出たら収穫し、ビタミンCができてフィチン酸が減る(軽くゆでて和えてもよい)。すりつぶして一晩置くと酸っぱく発酵して膨らみ消化しやすくなり、ゆでてつぶして発酵させたヒヨコマメのみそは、ダイズが足りないときの代替 |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵の点検、種子の発芽試験(2週間待つ)、系統別の種子の整理。2月に畑の計画、堆肥の切り返し、接種源の土の確保計画 |
| 3-4月 | 3月に耕うん、畝づくり、排水溝掘り、下旬に播種。4月中旬までに播種を終え、鳥よけ |
| 5-6月 | 5月に1回目の草取り、間引き(水は与えない)。6月に2回目の草取り、土寄せ、開花、根粒の確認 |
| 7-8月 | 7月に莢肥大、莢食い虫の捕殺、アスコキタ病の監視(雨が続けば畑に入らない)。8月に収穫、吊るして乾燥、脱穀 |
| 9-10月 | 9月に選別、乾燥、貯蔵、茎葉を戻す、採種の整理。10月に貯蔵の点検、ヒヨコマメの根があった土を接種源として別に保管 |
| 11-12月 | 11月に皮むきと割り、粉づくり(1、2か月で食べる分だけ)。12月に貯蔵の点検、発芽野菜の栽培、翌年の計画 |

> **ヒヨコマメは、種子を確保し、専用の菌を接種し、水がたまらない畑に植え、初期に水を与えず、3年以上輪作すれば、乾いた土でもタンパク質と鉄を出してくれる作物です。**
