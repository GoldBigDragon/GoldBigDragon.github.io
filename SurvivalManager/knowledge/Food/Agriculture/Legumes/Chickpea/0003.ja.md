## 3. 栽培環境

### 3-1. 気温と光量

| 条件 | 限界値 | 最適値 | 外れた場合 |
|---|---|---|---|
| 発芽温度 | 10℃以上 | 20-25℃ | 低温では発芽がさらに遅くなります。もともと10-14日かかります |
| 生育温度 | 12-35℃ | 21-26℃ | 夜間15℃以上が必要です |
| 結実温度 | 15-28℃ | 18-26℃ | 幅13℃で豆類の中では広いほうです |
| 開花期の低温 | 夜間10℃以下 | - | 花粉がうまく作られず、莢がつきません |
| 開花期の高温 | 35℃以上 | - | 花が落ちます。ただし高温耐性は豆類の中では良いほうです |
| 耐寒性 | 軽い霜に耐える | - | 氷点下数℃の短い霜はしのげます |
| 日照 | 1日6時間以上 | 1日8時間以上 | 40%遮光で収量が半分に落ちます |

&nbsp;&nbsp;&nbsp;ヒヨコマメで意外に厄介なのは、開花期の夜間気温です。夜に10℃を下回ると花粉がうまく作られず、花は咲いても莢がつきません。韓国で3月末に播くと開花期が6月にかかりこの問題を避けられますが、早く播きすぎると5月の肌寒い夜に開花期が重なることがあります。逆に遅く播くと梅雨にかかり、褐斑病が一気に広がります。播種の適期の幅が狭い理由です。

> **ヒヨコマメ栽培で最も恐ろしいのは干ばつではなく梅雨です。水が不足する年は収量が減るだけですが、莢が熟す頃に雨が長く続くと、褐斑病で畑全体を失います。**

### 3-2. 土壌と水

| 条件 | 限界値 | 最適値 | 備考 |
|---|---|---|---|
| 土性 | 砂質土から壌土まで | 排水の良い砂壌土-壌土 | 粘土質土壌や水がたまる土地は絶対に避けます |
| pH | 5.5-8.6 | 6.0-8.0 | 適応幅が豆類の中で最も広いです |
| 有効土層 | 60cm以上 | 1m以上 | 主根が1mまで伸びます |
| 作期蒸発散量 | - | 約250mm | 豆類の中で最も少ない部類です |
| 冠水 | 1日浸かっただけでも根が傷みます | - | 豆類の中で過湿害に最も弱いです |
| 耐塩性 | 低い | - | 塩分のある土地には向きません |
| 地下水位 | 80cm以下 | 1m以下 | 根が深いため地下水位が高いとすぐに傷みます |

&nbsp;&nbsp;&nbsp;pH適応幅5.5から8.6は豆類の中で最も広いです。酸性にもアルカリ性にもかなり耐えるという意味で、石灰の入手が難しい条件では実質的な利点になります。ただし5.5を下回ると根粒の形成が悪くなります。植物自体は耐えても、細菌が生きられないためです。

&nbsp;&nbsp;&nbsp;過湿への弱さは、ヒヨコマメで最も強調すべき条件です。乾いた土地に強い分だけ、湿った土地には弱いのです。主根が深く伸びる構造のため、地下水位が高い土地では根の先端が常に水に浸かった状態になり、それがそのまま根腐病につながります。畝を20cm以上高く盛り、排水路を深く切ることはヒヨコマメ栽培の前提条件です。田を畑に転換した場所、谷の下、水がたまる窪んだ畑は避けます。

## 4. 品種

### 4-1. 二つの系統

| 区分 | 種子 | 特徴 | 災害適合度 |
|---|---|---|---|
| デシ型（Desi） | 小さく角ばり、褐色・黒色。種皮が厚い | 耐寒性と乾燥適応力に優れます。生育期間が短く、痩せ地に強いです | 高いです |
| カブリ型（Kabuli） | 大きく丸く、クリーム色・白色。種皮が薄い | 条件が良ければ収量が多いです。生育期間が長く、栽培に手がかかります | 中程度です |

&nbsp;&nbsp;&nbsp;世界のヒヨコマメの80%以上がデシ型で、私たちが市場で見る大きくて白いヒヨコマメはカブリ型です。災害対策の観点では、デシ型が明らかに優れています。種皮が厚いため土の中で腐りにくく、根がより深く入り、生育期間が短いため梅雨の前に終えられ、痩せて乾いた土地でも収量の落ち込みが小さいです。さらに種皮が厚いということは、貯蔵中の虫害にも強いことを意味します。

&nbsp;&nbsp;&nbsp;デシ型の欠点は、粒が小さく皮が厚いため調理に手間がかかることです。そのためインドではデシ型の皮をむいて半分に割り、チャナ・ダルとして使います。この形にしておくと、調理時間はむしろカブリ型より短くなります。

&nbsp;&nbsp;&nbsp;韓国には登録されたヒヨコマメ品種が事実上なく、農村振興庁の適応性試験では在来導入系統の収量が1,000㎡あたり9-217kgまで激しくばらつきました。系統と年によって20倍以上の差が出るということであり、どの系統を手に入れるかが成否を左右します。種子を確保できたなら、最初の2~3年は小面積で複数の系統を分けて植え、その畑に合うものを選び出すのに使うのが合理的です。

### 4-2. 状況別の選択基準

| 状況 | 優先順位 | 理由 |
|---|---|---|
| 畑が痩せていて乾いている | デシ型 | この条件では収量の落ち込みが最も小さいです |
| 梅雨が早く来る | デシの早生系統 | 雨が来る前に終える必要があります |
| 種子が不足している | デシ型 | 粒が小さいため、同じ重さで2~3倍広く播けます |
| 調理燃料が不足している | 皮をむいて割った形に加工 | 系統にかかわらず調理時間が半分に減ります |
| 初めて種子を入手した | 複数系統に分けて播種 | 適応性のばらつきが激しいです。選び出す過程が必要です |

## 5. 畑の準備と肥料 — 根粒菌

### 5-1. 窒素固定はどのように起こるか

&nbsp;&nbsp;&nbsp;空気の78%は窒素です。人の頭上に無尽蔵の窒素が漂っているのに、植物はそれを使えません。空気中の窒素は窒素原子2個が三重結合で固く結ばれた分子であり、この結合を切るには莫大なエネルギーが必要だからです。工業的にこの結合を切ってアンモニアを作るのがハーバー・ボッシュ法で、世界の窒素肥料はそこから生まれます。高温と高圧と触媒、そして膨大な化石燃料が必要です。

&nbsp;&nbsp;&nbsp;根粒菌はこの仕事を常温常圧でやってのけます。ニトロゲナーゼという酵素で三重結合を切り、窒素をアンモニアに変えます。ただし代償があります。この反応には多くのエネルギーが必要で、細菌自身は光合成ができません。そこでマメ科植物の根に入り込んで暮らし、植物が光合成で作った糖を受け取り、その見返りに固定した窒素を渡します。一種の取引関係です。

> **ヒヨコマメと組む菌はMesorhizobium ciceriという専用の菌です。ダイズやエンドウやインゲンマメを育てた畑の土は、ヒヨコマメの接種源にはなりません。この作物の接種は、他のどの豆類よりも難しいのです。**

&nbsp;&nbsp;&nbsp;この点がヒヨコマメ栽培の最大の実務的な難点です。ヒヨコマメを一度も植えたことのない畑の土には、この菌がほとんどいません。韓国のほとんどの畑がこれに該当します。接種せずに植えると根粒がほとんどできず、窒素を自力で作れないため葉が黄色くなり、収量が大きく落ちます。韓国国内の適応性試験で収量のばらつきが激しかった原因の一つは、これによるものと推定されます。

| 段階 | 起こること |
|---|---|
| 1. シグナル交換 | ヒヨコマメの根がフラボノイドを分泌し、土中の細菌がその信号に応えてノッドファクターを出します |
| 2. 感染 | 根毛が内側に曲がって細菌を包み込み、細菌は感染糸をたどって根の中に入ります |
| 3. 根粒形成 | 根の内側の細胞が分裂して根粒がふくらみ、その中に細菌が定着します |
| 4. 窒素固定 | 根粒の中でニトロゲナーゼが働き、空気中の窒素をアンモニアに変えます |
| 5. 分配 | アンモニアがアミノ酸に変わり、茎や葉や莢へ運ばれます |
| 6. 老化 | 登熟期に入ると根粒は機能を失い、根とともに土に還ります |

&nbsp;&nbsp;&nbsp;ニトロゲナーゼは酸素に非常に弱く、酸素に触れるとすぐに機能を失います。そのため根粒の内部にはレグヘモグロビンという赤い色素タンパク質が満ちていて、酸素を捕まえておき、酵素周辺の酸素濃度を極めて低く保ちます。人の血が赤いのと同じ原理で、根粒を割ったときに内部が赤や桃色をしているのはこの色素によるものです。この事実は実用上たいへん重要です。赤色は、その根粒が今まさに窒素を固定している目に見える証拠だからです。

### 5-2. 根粒ができているかの確認方法

&nbsp;&nbsp;&nbsp;接種した場合もしなかった場合も、根粒が実際にできているかを確認することは必ず行うべきです。ヒヨコマメではこの確認が他の豆類よりも重要です。土着菌のいない畑が多く、失敗する確率が高いためです。

| 順序 | 内容 |
|---|---|
| 1 | 開花が始まる頃、播種後8週間ほどが最も良い時期です |
| 2 | 健康そうな株を2~3株選びます |
| 3 | 引き抜かず、スコップで株の周りを広く掘って土ごと持ち上げます。主根が深いので深く掘ります |
| 4 | 水を張った容器に入れて土を優しく洗い流します |
| 5 | 主根と太い側根についた根粒の数を数えます |
| 6 | 根粒をいくつか爪で割って、内部の色を見ます |

| 観察結果 | 意味 | 対応 |
|---|---|---|
| 根粒が株あたり15個以上、特に主根の上部に集中している | 接種がうまくいっています | そのままにします |
| 割った内部が赤や桃色 | 窒素を固定しています | 良い状態です |
| 割った内部が白色や薄緑色 | 根粒はできているが固定していません | 酸度、過湿害、リン酸と硫黄の欠乏を調べます |
| 割った内部が褐色や黒色 | すでに老化したか死んでいます | 登熟期なら正常、開花期なら問題です |
| 根粒がほとんどない | 土着菌のいない畑です。最もよくある場合です | その年は窒素を補い、翌年はこの畑の土を接種源に使います |

> **根を掘り出して根粒を割り、赤色を確認するというこの一つの習慣こそ、窒素肥料のない世界で豆作りの成否を教えてくれる最も確実なサインです。**

### 5-3. 接種源をどこで手に入れるか

&nbsp;&nbsp;&nbsp;市販の接種剤は、生きた細菌をピートや粘土に混ぜて売る製品です。災害時には入手できません。ヒヨコマメは専用の菌を必要とするため、他の豆類より接種源の確保が難しいものの、方法がないわけではありません。

| 方法 | 手順 | 効果 | 注意 |
|---|---|---|---|
| ヒヨコマメを育てた畑の土をまぶす | 前年ヒヨコマメを植えて根粒がよくできていた畑から、表土5-15cmの深さの土をすくってきます。種子を水で軽く湿らせてこの土をまぶし、すぐに播きます | 最も確実です | ヒヨコマメを育てたことのある畑が必要です |
| 根粒そのものを使う | 掘り出した根の根粒を集めてすりつぶし、水に溶かして、その水に種子を浸してから引き上げます | 菌密度が最も高いです | 根粒を掘り出したその日のうちに使う必要があります |
| 初年度は接種なしで | 初年度はやむを得ず接種せずに植え、少量の窒素を補います | 収量は少ないですが、その畑に菌が残ります | 翌年からその畑の土が接種源になります |
| 接種源用の畑を作る | 狭い区画にヒヨコマメを集中的に植えて菌を増やします | 翌年、広い畑の接種源になります | 種子が貴重なときに合理的な戦略です |
| 土を畑にまく | 播種する条に運んできた土をまき、一緒にすき込みます | 菌が土に広がります | 10㎡あたりスコップ一杯程度が目安です |
| 根の残渣を残す | 収穫時に茎だけを刈り、根は畑に残します | 翌年まで菌が土に残ります | 最も手間のかからない維持方法です |

&nbsp;&nbsp;&nbsp;接種源用の畑を別に作る戦略をお勧めします。種子を初めて確保したなら、初年度は狭い区画にまとめて植えて菌を土に定着させ、その土を翌年の接種源として使います。ヒヨコマメはどのみち最初の2~3年を採種に充てなければならない作物なので、その期間に接種源まで一緒に作っておくことになります。一度菌が定着した畑は、数年間接種能力を保ちます。

&nbsp;&nbsp;&nbsp;接種の際に必ず守るべきことがあります。根粒菌は直射日光と乾燥と熱に非常に弱いです。紫外線を数分浴びるとかなりの数が死に、乾燥すればさらに早く死にます。種子に土をまぶす作業は日陰で行い、まぶした種子は日に当てず、そのまま播きます。伝統的には糖蜜や砂糖水、米のとぎ汁のような粘り気のある液体を種子に薄く塗って、土がよく付くようにしました。もう一つ、種子消毒と接種は同時に行えません。温水処理で消毒した場合は、完全に冷ましてから接種します。

| 接種失敗を招く条件 | 理由 |
|---|---|
| 他の豆を育てた畑の土を使う | 菌の種が異なり、ヒヨコマメには感染しません |
| 土壌pH 5.5以下 | 細菌が生きられません |
| 窒素肥料を十分に与えた畑 | 植物が取引の必要を感じず、根粒形成を自ら減らします |
| 水がたまる畑 | 好気性細菌のため、酸素がないと死にます |
| リン酸が不足している畑 | 窒素固定には多くのエネルギーが必要で、その代謝にリン酸が使われます |
| 硫黄が不足している畑 | ヒヨコマメでは硫黄欠乏が根粒形成不良として直接現れます |
| モリブデン・鉄・コバルトの欠乏 | ニトロゲナーゼの構成成分です |
| 接種した種子を日に当てて乾かす | 紫外線と乾燥で菌が死にます |
