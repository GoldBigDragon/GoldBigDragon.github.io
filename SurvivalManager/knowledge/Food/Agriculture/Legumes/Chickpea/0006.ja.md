## 13. 採種

| 項目 | 方法 |
|---|---|
| 採種個体の選抜 | 病気の症状がなく莢が多くつき、萎凋病が回る畑で最後まで生き残った株を、畑であらかじめ印をつけておきます |
| 収穫時期 | 莢が完全に褐色になってから収穫します。食用より少し遅めに収穫します |
| 分離 | 別に脱穀します。手でむけば実が割れません |
| 選別 | 斑点、割れた実、しわ、変色のあるものは全て取り除きます。大きく完全な実だけを残します |
| 乾燥 | 水分12-13%。日陰でゆっくり乾かします |
| 保管 | 密閉容器に入れて涼しく暗い場所に置きます。食用とは別の容器にします |
| 保管期間 | 常温密閉で3年 |
| 更新 | 入手できるなら3-4年ごとに他所の種子を一部混ぜます |

> **ヒヨコマメは韓国国内で種子を再び入手するのが難しい作物です。採種は選択ではなく、この作物を続けて育てるための前提条件です。食べる分を減らしてでも、種子を先に確保しておきます。**

&nbsp;&nbsp;&nbsp;採種で最も重要な形質は萎凋病抵抗性です。病気が回る畑で周囲の株が全て萎れて枯れる中、一株だけ生き残って種をつけた個体があれば、それが最も価値のある種子です。抵抗性は遺伝するため、こうした個体を選んで受け継いでいけば、数年のうちにその畑で耐える系統ができます。韓国国内の適応性試験で系統ごとの収量が20倍以上も分かれたという事実は、裏を返せば選抜の余地がそれだけ大きいということです。

&nbsp;&nbsp;&nbsp;次に重要な形質は、褐斑病への耐性と早熟性です。梅雨の前に登熟を終える個体は病気を避けられます。畑の中で他より先に莢が褐色になる株に糸を結んでおき、別に収穫する習慣が、数年後に大きな差を生みます。

&nbsp;&nbsp;&nbsp;ヒヨコマメは自家受粉作物のため、隔離距離を心配する必要がありません。複数の系統を並べて植えても形質が混ざりません。これは複数の系統を同時に試験しながら選抜するのに有利な条件です。ただし種子が混ざらないよう系統ごとに別々に収穫して別々に保管し、容器にどの畑のどの年のものかを書いておきます。

| 種子保管期間と発芽率 |
|---|
| 収穫当年：85%以上 |
| 1年経過：75-85% |
| 2年経過：60-75% |
| 3年経過：40-60% |
| 4年以降：急激に低下します |

## 14. 毒性と抗栄養成分

&nbsp;&nbsp;&nbsp;ヒヨコマメは豆類の中でも毒性リスクが低いほうです。インゲンマメのように生の実数粒で中毒を起こす強いレクチンも、ソラマメのように特定の体質で急性溶血を起こす成分もありません。しかし乾燥ヒヨコマメには他の豆と同様に抗栄養成分が含まれており、生で食べると消化されません。

| 成分 | 作用 | 症状 | 取り除く方法 |
|---|---|---|---|
| トリプシンインヒビター | タンパク質分解酵素の働きを妨げます | 腹痛、下痢、タンパク質利用率の低下 | 8時間浸漬後、沸騰した湯で1時間以上加熱 |
| レクチン | 腸粘膜に付着して吸収を妨げます | 消化不良 | 加熱で分解されます。インゲンマメ類よりずっと弱いです |
| フィチン酸 | 鉄、亜鉛、カルシウムと結合して吸収を妨げます | 長く食べ続けると貧血、亜鉛欠乏 | 浸漬、発芽、発酵で60-80%まで減らせます |
| オリゴ糖（ラフィノース・スタキオース） | 人には消化できず、腸内細菌が発酵させます | 腹にひどくガスがたまります | 浸漬後、浸けた水を必ず捨てます |
| サポニン | 泡を立てます | 少量は無害です | 煮ながら泡を取り除きます |
| 葉と莢の有機酸 | リンゴ酸とシュウ酸 | 皮膚刺激。多く食べると胃を刺激します | 葉は食用にしません。作業時は手袋をはめます |
| カビ毒 | 貯蔵中にカビが作ります | 危険です | カビが生えたものは洗っても加熱しても安全になりません。廃棄します |

> **ヒヨコマメで実際に人を害するのは豆そのものではなく、保存を誤ってカビが生えた豆と、十分に加熱せずに食べた豆です。湿っぽい臭いがしたり表面に青みがかった粉が見えたら、惜しまずに捨てます。**

| 処理 | 時間・温度 | 効果 |
|---|---|---|
| 浸漬 | 常温の水に8時間以上。夏は水を替えながら6時間 | 種皮が厚いので十分にふやかす必要があります |
| 浸け水を捨てる | 必ず | 水に溶け出したオリゴ糖と抗栄養成分を一緒に捨てます |
| 煮る | 沸騰した湯で1時間から1時間半 | 豆類の中では調理時間が長いほうです |
| 皮をむいて割る | ふやかして皮をむき、半分に割ります | 調理時間が20-30分に短縮されます |
| 塩の代わりに重曹 | 煮る水にごく少量 | 皮が早く軟らかくなり燃料が節約できます。なければ草木灰を浸した上澄み水で代用できます |
| 火の通り確認 | 指で押すと簡単につぶれます | 芯が残っていれば煮え足りません |

&nbsp;&nbsp;&nbsp;ヒヨコマメのオリゴ糖含量は豆類の中でも高いほうで、急に大量に食べると腹にひどくガスがたまります。長く飢えていた人や子どもには特に注意が必要です。最初は少量から始めて数日かけて増やし、浸け水は必ず捨てます。煮汁も捨てて新しい水で煮直せばさらに減らせますが、栄養素も一緒に抜けてしまうため、状況に応じて判断します。

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;ヒヨコマメの貯蔵性はSSです。FAO食品ロス指数で貯蔵段階の損失率の中央値は0.49%と非常に低く、乾燥種実は常温で3年もちます。種皮が厚く硬く、虫が入り込みにくい構造のおかげです。しかし条件がそろわないとゾウムシが入り込みます。

### 15-1. まず乾燥です

| 段階 | 方法 | 確認 |
|---|---|---|
| 予備乾燥 | 茎ごと日に4-6日干すか、軒下に掛けて乾かします | 莢がしっかり乾きます |
| 脱穀後の乾燥 | むしろや敷物に薄く広げて日に2-3日 | 頻繁に返して均一に乾かします |
| 目標水分 | 食用14%以下、種子用12% | 歯で噛むと歯が入らずぽきっと割れます |
| 塩試験 | 乾いた塩を豆と一緒に瓶に入れて振ります | 塩が瓶の壁に付けば、まだ湿っています |
| 冷却 | 日から取り込んだ後、完全に冷ましてから詰めます | 温かい状態で密閉すると結露が生じます |

&nbsp;&nbsp;&nbsp;乾燥が不十分だと、その後の対策が全て崩れます。水分が15%を超えるとカビが生え、13%を超えるとゾウムシの繁殖が速まります。逆に乾かしすぎると実が割れます。ヒヨコマメはもともと二つに割れやすい構造なので、日差しが強すぎる日に長く干すと自然に割れる実が増えます。午後の強い日差しは避け、午前に干して午後には取り込むほうがよいです。

### 15-2. 貯蔵中のマメゾウムシ防除

&nbsp;&nbsp;&nbsp;マメゾウムシの仲間は貯蔵豆類の最大の脅威です。恐ろしいのは、それが畑ですでに始まっているという点です。まだ畑についている莢に成虫が卵を産み付け、その卵が貯蔵庫の中で孵化して豆の中に潜り込みます。持ち込まれる時点ですでに卵が付いてくる構造であり、一世代が一か月もかからないため、半年もすれば袋一つが穴だらけの殻で満たされます。ヒヨコマメは種皮が厚く他の豆より抵抗力がありますが、安全というわけではありません。

| 方法 | 原理 | 適用 | 効果 |
|---|---|---|---|
| 完全密閉 | 酸素を絶って窒息させます | ガラス瓶や金属缶をいっぱいに満たして封をします | 最も確実です。3-4週間で卵と幼虫まで死にます |
| 草木灰混ぜ | 微細な粒子が外骨格のワックス層を削り取り脱水させます | 豆の体積の2-5%を混ぜます | 食べる前に水で洗い流します |
| 珪藻土 | 珪酸の殻が外骨格を傷つけます | 豆1kgに1-3g | 灰より効果が大きいです。乾いた状態でのみ働きます |
| 油コーティング | 油膜が卵の付着と孵化を防ぎます | 豆1kgに食用油2-5mLを入れてもみます | 豆類に効果が大きいです。種子用には使いません |
| 低温処理 | 氷点下で卵と幼虫が死にます | 真冬に数日外に出してから取り込みます | 取り込むときは結露に注意します |
| 高温処理 | 60度で卵と幼虫が死にます | 日に薄く広げて半日置きます | 種子用には使いません |
| 乾燥トウガラシ・サンショウ・ヨモギ | 精油成分が産卵を抑制します | 層状に入れます | 補助的な手段です |
| 炭・炒り塩 | 湿気を吸い取ります | 布に包んで入れます | カビ予防も兼ねます |
| 灰の中に埋める | 密閉と物理的防除を同時に得られます | 甕に灰と豆を交互に重ねます | 伝統的に広く使われてきました |
| 割れた実を先に食べる | 割れた実には虫が先に入ります | ふるいで選り分けて別に保管し先に消費します | ヒヨコマメで特に有効です |

&nbsp;&nbsp;&nbsp;最も重要なのは完全密閉です。虫も呼吸をします。密閉した容器の中で豆と虫が酸素を使うと酸素が減り、二酸化炭素が増えて虫が死にます。豆は休眠状態なのでこの条件に耐えます。容器をいっぱいに満たして空間を減らすほど効果が早まります。大きな容器一つより小さな容器いくつかにぎっしり詰めるほうがよく、これは一つの容器が傷んだときに全部を失わずに済むという利点も併せ持ちます。

&nbsp;&nbsp;&nbsp;油コーティングは、インドやアフリカの小規模農家で古くから使われてきた方法です。豆1kgに食用油2-3mlを入れて手でもみ、全ての実に薄い膜ができるようにします。油膜は成虫が卵を付けにくくし、すでに付いた卵の気孔をふさいで孵化を妨げます。半年以内に食べる分にのみ使い、種子用には使いません。草木灰はふるいにかけて細かい部分だけを選び、豆の体積の2-5%を混ぜます。虫が耐性を獲得することがなく、人にも無害です。

### 15-3. 貯蔵容器と場所

| 容器 | 密閉性 | 期間 | 長所 | 短所 |
|---|:---:|---|---|---|
| ガラス瓶 | 非常に良い | 3年以上 | 状態を目で確認できます | 容量が小さく光を遮れません |
| 金属缶 | 非常に良い | 3年以上 | ネズミと虫を完全に防ぎます | 結露が生じるとその部分が傷みます |
| 甕 | 良い | 2-3年 | 温度変化が緩やかでネズミが破れません | 重く、割れます |
| 厚手ビニール | 普通 | 1-2年 | 軽くて安価です | ネズミが破ります |
| 地中貯蔵穴 | 良い | 2-3年 | 温度が一定で低いです | 水がしみ込むと全量を失います |

&nbsp;&nbsp;&nbsp;点検で最も頼りになる感覚は聴覚と嗅覚です。容器に耳を当ててかさかさという音がすれば虫が活動しており、湿っぽい臭いがすればカビが始まっています。表面に小さく丸い穴が見えれば、ゾウムシが一世代を越えた状態です。この段階でも全量を取り出して日に干し、水に浮かべて空の実を取り除き、灰や油を混ぜて再び密閉すれば、残りの分を守れます。2か月に一度の点検が目安です。

## 16. 調理と加工

### 16-1. 皮をむいて割った形 — 燃料を半分に

&nbsp;&nbsp;&nbsp;ヒヨコマメの調理で最も価値ある技術は、皮をむいて半分に割っておくことです。インドでチャナ・ダルと呼ばれる形で、調理時間を1時間から20分から30分に縮めます。燃料が貴重な条件では、この差は毎日積み重なります。

| 順序 | 内容 |
|---|---|
| 1 | 乾燥したヒヨコマメを水にさっとくぐらせ、表面を軽く湿らせます |
| 2 | 半日日陰に置き、皮だけが水分を含むようにします |
| 3 | 臼に入れて軽くつきます。実を砕くのではなく、皮をむく程度に |
| 4 | 箕やうちわであおいで、むけた皮を飛ばします |
| 5 | 残った実を再び軽くつくと二つに割れます |
| 6 | 完全に乾かして密閉保管します |

&nbsp;&nbsp;&nbsp;この状態にしておけば、浸漬なしで20分から30分ほどでお粥のように軟らかくなります。ただし皮をむいた豆は貯蔵性が落ちます。種皮という防御壁がなくなるため虫が入りやすくなり、酸化も早まります。そのため一度に全部を加工せず、1~2か月で食べる分だけを作るのが原則です。むいた皮は捨てずに集めて家畜の餌や堆肥に使います。

### 16-2. 燃料を節約する調理

| 方法 | 燃料 | 手順 |
|---|:---:|---|
| 割ったヒヨコマメの粥 | 非常に少ない | 浸漬なしで20-30分で軟らかくなります |
| 圧力調理 | 最も少ない | ふやかした豆を15-20分加圧します |
| 余熱調理 | 非常に少ない | 20分煮た後火を止め、藁・もみ殻の箱や布団で包んで3-4時間置きます |
| 炒りヒヨコマメ | 少ない | ふやかして乾かした豆を油なしで炒ります。そのまま食べられます |
| ヒヨコマメ粉 | ほとんどなし | 炒って挽いておき、水で練るか溶いて食べます |
| 発芽 | なし | 発芽させると熱を加えずに食べられる状態になります |

&nbsp;&nbsp;&nbsp;ヒヨコマメ粉は災害時の条件で特に価値があります。炒って挽いた粉は水で練って薄く伸ばして焼けばパンになり、水で溶いて煮ればお粥になり、野菜にまぶして揚げれば衣になります。インドのベサン粉、中東のファラフェルの生地はどちらもこの粉です。小麦粉がない条件で穀物粉にヒヨコマメ粉を混ぜると、アミノ酸組成が整い、生地の粘りも補われます。ただし脂肪が6%あるため、粉は数か月以内に酸化臭が出るので、食べる分だけ作ります。

&nbsp;&nbsp;&nbsp;余熱調理もヒヨコマメで大きな効果を発揮します。20分だけ煮て保温箱に入れておくと、内部の温度が3時間以上高く保たれ、調理が続きます。藁やもみ殻を詰めた木箱、または厚い布団で鍋を丸ごと包めば、それが保温箱です。調理時間の長いヒヨコマメで、この方法が節約する燃料は相当なものです。

### 16-3. 発芽と発酵

| 方法 | 手順 | 価値 |
|---|---|---|
| 発芽 | 8時間ふやかした後水を切り、濡れた布で覆って2-3日。芽が1cmほど出たら収穫します | ビタミンCが新たに生成され、フィチン酸が減り、消化しやすくなります |
| ゆでナムル | 発芽させたものをさっとゆでて和えます | 冬に野菜がないとき、緑を得られます |
| 発酵生地 | すりつぶして一晩置くと酸っぱく発酵します | ふくらんで軟らかくなり、消化しやすくなります |
| ヒヨコマメテンジャン | 茹でてつぶし、発酵させた後塩水に漬けます | ダイズが不足するときの代替品です |

&nbsp;&nbsp;&nbsp;ヒヨコマメは発芽させやすい豆です。8時間ふやかした後水を切り、濡れた布で覆って2、3日置くと1cmほど芽が出ます。この過程で乾燥豆にはなかったビタミンCが作られ、フィチン酸とトリプシンインヒビターが減り、オリゴ糖が分解されて腹のガスも少なくなります。冬に新鮮な野菜がないとき、この発芽がビタミンC欠乏を防ぐ安価な手段になります。ただし発芽させたヒヨコマメも生では食べず、さっとゆでるか炒って食べます。残っている阻害物質のためです。

## 17. 年間作業スケジュール

| 月 | 作業 | 要点 |
|---|---|---|
| 1月 | 貯蔵点検、種子発芽試験、系統別の種子整理 | 発芽が遅いので試験も2週間待ちます |
| 2月 | 畑計画、堆肥切り返し、接種源の土の確保計画 | 水はけの良い場所をヒヨコマメに割り当てます |
| 3月 | 耕起、畝立て、排水路作り、下旬に播種 | 排水路がヒヨコマメ栽培の半分を占めます |
| 4月 | 播種仕上げ（中旬まで）、鳥よけ | 10日から15日は何も出てきません |
| 5月 | 1回目の除草、間引き | 初期の雑草管理が収量を左右します。水はやりません |
| 6月 | 2回目の除草、土寄せ、開花、根粒確認 | 根を掘って根粒を割り、赤色を確認します |
| 7月 | 莢肥大、莢食い虫の捕殺、褐斑病の監視 | 雨が続いたら畑に入りません |
| 8月 | 収穫、吊るして乾燥、脱穀 | 雨の予報があれば完熟を待ちません |
| 9月 | 精選、乾燥、貯蔵、茎葉の還元、採種の整理 | 病気にかかった残渣だけを焼き、残りは畑に覆います |
| 10月 | 貯蔵点検、接種源の土の保管 | ヒヨコマメの根があった土を別に取っておきます |
| 11月 | 加工（皮むき割り）、粉作り | 1~2か月で食べる分だけ加工します |
| 12月 | 貯蔵点検、発芽野菜作り、翌年の計画 | 冬のビタミンCは発芽から得ます |

### 17-1. 忘れてはならない五つのこと

| 項目 | 内容 |
|---|---|
| 種子の確保 | 韓国国内で再び入手するのが難しい作物です。採種が栽培の前提です |
| 接種 | 専用菌が必要です。他の豆畑の土は役に立ちません。接種源用の区画を別に設けます |
| 排水 | 豆類の中で過湿害に最も弱いです。水がたまる畑には植えません |
| 初期に水をやらない | 乾いた条件が根を1mの深さまで押し下げます。その根が後の干ばつに勝ちます |
| 輪作 | 3年以上。萎凋病は土に残って待ち構えます |
