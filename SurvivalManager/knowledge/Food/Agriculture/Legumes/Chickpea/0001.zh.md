## 引言
&nbsp;&nbsp;&nbsp;鹰嘴豆（Cicer arietinum）源自土耳其东南部的野生鹰嘴豆，是原产于西南亚干旱地区的豆科一年生草本，是世界上种植面积第二大的豆科作物。它最突出的优点是耐旱，水消耗量为S，总蒸散量250mm即可完成一个生长季（大豆450-700mm，豌豆400mm）。这是因为根笔直向下扎到1m以下，吸取深层土壤里的水。综合等级为C（41.2分，有效183种中第92名），短期D（39.7）、长期C（42.8），副食为SS（62.2分）。单位面积热量为D，每1,000㎡ 180kg、每㎡ 679kcal，仅为自给线的0.26倍；国内种植普及度为C，只在一两个道（韩国行政区）试种，实际上很难弄到种子。一旦流通中断，手里没有的种子就等于不存在，所以现在就要确保种子并通过自留种扩繁；如果没能确保，改以大豆、红豆、豇豆做规划更现实。它是自花授粉，纯系得以保持，常温密封可保存3年，所以确保种子之后就能自己继续种下去。

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：施肥、设施负担、耐储性。S：蛋白质密度、微量营养素、水消耗量、口味、自留种。A：无合成投入产量保持率、产量稳定性、种子寿命。B：收获速度、温度幅度、耐寒性、防治自立度、连作适应性 |

> **鹰嘴豆不是填饱肚子的作物，而是在干旱的土地上也能产出蛋白质和铁的作物。在不下雨的年份，在别的豆子歉收的地方还能收到点东西，这就是这种作物的位置。**

&nbsp;&nbsp;&nbsp;微量营养素S是副食等级SS的依据，耐储性SS意味着常温密封可长期保存。烹调·加工D是因坚硬的种皮每天都要付出的成本，连作适应性B与病虫害压力C要放在一起看，必须坚持3年以上的轮作。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 豆科鹰嘴豆属一年生草本。原产于土耳其东南部至叙利亚一带，自花授粉 |
| 叶、茎 | 叶为羽状复叶，密布细毛和腺体。茎直立，基部多分枝，株高20-100cm（多为40cm左右），不需要支柱 |
| 根、花 | 笔直的主根深入1m以下，在豆类中最深。花为白色、淡粉色或紫色的小蝶形花，每个叶腋开一朵 |
| 荚、籽粒 | 短而饱满，有细毛，每荚只有1-2粒，是产量的结构性上限。籽粒皱缩，一侧有尖喙，形似鸟头 |

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 发芽、幼苗期 | 播种后4周 | 发芽需10-14天，其间根先向深处扎下 |
| 营养生长期 | 4-8周 | 茎立起来，大量分枝 |
| 开花期、鼓荚期 | 8-14周 | 从下部节位依次开花，荚果鼓起来 |
| 灌浆、成熟期 | 12-17周 | 叶片变黄，荚果干成褐色 |

> **鹰嘴豆叶片上的酸性分泌物是驱退害虫的天然防御装置。这是这种作物比其他豆类更少受啃叶虫危害的原因，同时也是徒手长时间接触会刺痛皮肤的原因。**

&nbsp;&nbsp;&nbsp;干籽粒每100g热量377kcal，蛋白质17.78g（占热量的18.9%），脂肪约6g，碳水化合物约60g，膳食纤维10-26g，糖类2.55g，钙127-184mg，铁4.6-8.3mg，磷286-528mg，叶酸丰富。钙和铁都高，在没有肉类时是重要的来源，但低聚糖多，突然吃很多会胀气。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽10℃以上（最适20-25℃）。生长12-35℃（最适21-26℃，夜间15℃以上），结实15-28℃。开花期夜间10℃以下则花粉不能正常形成，不结荚，35℃以上则落花。耐轻霜 |
| 光照 | 每天6小时以上（8小时以上最适），遮光40%则产量减半 |
| 水、土壤 | 排水良好的沙壤土或壤土（绝对避开黏土和积水的地方），pH 5.5-8.6（豆类中最宽），有效土层60cm以上。生育期蒸散量约250mm。只被水淹一天根就受伤，在豆类中最怕涝害，耐盐性也低。地下水位1m以下 |

> **种鹰嘴豆最可怕的不是干旱，而是雨季。缺水的年份产量减少，但荚果将熟时如果长时间下雨，整块田都会毁于壳二孢疫病（Ascochyta blight）。**

| 类型 | 特点 |
|:---|:---|
| 德西型（Desi） | 籽粒小而有棱，褐色或黑色，种皮厚，耐寒性和抗旱适应力出色，生育期短，耐瘠薄。灾害适合度高。占世界鹰嘴豆的80%以上 |
| 卡布利型（Kabuli） | 籽粒大而圆，奶油色或白色，种皮薄，条件好时产量高，但生育期长、要求高。市面上常见的大颗白色鹰嘴豆 |

&nbsp;&nbsp;&nbsp;韩国国内几乎没有登记品种，引进品系的产量每1,000㎡在9-217kg之间极端悬殊，所以第一次拿到种子时，要分成多个品系种下去挑选。如果田地瘠薄干燥或种子不足，选德西型（籽粒小，同样重量可多种两三倍面积）；如果雨季来得早，选德西型的早熟品系。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 深耕20-30cm，垄高20cm以上（防涝的前提条件），排水沟深30-50cm。充分腐熟的堆肥1,000-1,500kg/1,000㎡ |
| 施肥（1,000㎡） | 氮0-2kg（多施会抑制固氮）、磷20-40kg、钾3-5kg、硫10-20kg（均作基肥）。缺硫则根瘤形成不良，固氮崩溃 |
| 替代资源 | 骨粉（磷、钙）、鱼骨和内脏（磷、氮、硫）、草木灰（每㎡ 100-200g）、家畜粪堆肥和大蒜·洋葱皮·白菜外叶的堆肥（硫）、稀释10倍的人尿（极少量） |
| 根瘤接种 | 需要专用根瘤菌（Mesorhizobium ciceri），种过大豆、豌豆、菜豆的田里的土没有用。取种过鹰嘴豆的田里5-15cm深的表土，裹在用水稍微润湿的种子上，立即播下。第一年不接种，少量补氮，在小块地上集中密播以繁殖菌，次年作接种源 |

> **与鹰嘴豆配对的是专用的菌。种过大豆、豌豆或菜豆的田里的土，不能成为鹰嘴豆的接种源。这种作物的接种比其他任何豆类都更挑剔。**

&nbsp;&nbsp;&nbsp;开花前后（播种后8周），用铁锹深挖取出、洗净，剖开根瘤查看。每株15个以上、内部呈红色，说明接种成功；白色或浅绿色的，要检查酸度、涝害以及磷和硫的缺乏；根瘤几乎没有，就是没有本地菌的田。积水的田、氮肥过多、磷和硫不足也会使接种失败。每公顷固氮60-100kg（接种失败时5-15kg），而随籽粒带走45-60kg，所以必须把茎叶切成20-30cm还回田里，不烧，不挖根，才不会掠夺土地。

| 播种 | 标准 |
|:---|:---|
| 时期 | 霜冻完全结束后的3月下旬-4月中旬（7月中旬-8月收获）。秋播熬不过冬天的寒冷 |
| 种子准备 | 弃去有斑点、变色、皱缩、虫孔的种子（壳二孢疫病通过种子传染）。用水浮选，捞去浮起的粒，放在50-55℃水中浸10-15分钟消毒，并裹上细草木灰。不要浸种（种皮变软会腐烂）。发芽试验要等2周 |
| 方法 | 深3-5cm，每穴1-2粒，行距25-60cm，株距20-25cm。每1,000㎡播种量：德西型小粒种2.5-4kg，卡布利型大粒种8-12kg。播种后十天到半个月什么也不会长出来，为防鸟，到发芽前盖上稻草或网 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种至发芽 | 不要让土壤彻底干掉 |
| 生长初期 | 不浇水（干燥条件会把根推到1m以下） |
| 开花期至鼓荚期 | 干旱严重时灌溉（这个时期缺水最能使产量大减） |
| 灌浆期、雨季 | 停止灌溉（过湿则炸荚、品质下降）。雨季要挖排水沟 |

> **鹰嘴豆的水分管理不是给的技术，而是忍的技术。初期经常浇水，根就会变浅，而浅根撑不过之后的干旱。**

&nbsp;&nbsp;&nbsp;中午叶片合拢、傍晚展开，是正常的节水反应。早晨也合拢着，就是严重干旱；下部叶发黄、基部发褐变软，则是过湿造成的烂根，要挖排水沟。

| 管理 | 方法 |
|:---|:---|
| 除草 | 出苗后2-3周第1次（浅锄），45天左右第2次（与培土同时），开花前完成所有除草。尤其怕杂草竞争，开花以后不进田 |
| 培土、拉绳支撑 | 播种后45天左右用土盖住基部，形成支撑，并把沟加深，使水排得顺畅。有倒伏之虞时，沿田边打桩，在膝高处拉绳 |

## 6. 病虫害与养分问题
| 病虫害 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 壳二孢疫病 | 叶、茎、荚上出现同心轮纹状褐斑，茎折断。连雨且凉爽时，通过种子和残体传染 | 选种和温水消毒、3年以上轮作、保证通风、烧掉病残体。蔓延时提前收获 |
| 枯萎病 | 开花期从下部叶开始萎蔫，整株干枯死亡，茎内部呈褐色。在土中存活多年 | 3年以上轮作是唯一对策。从存活的植株上留种 |
| 根腐病、菌核病、白粉病 | 基部和根变褐腐烂（过湿） / 白色绵状菌丝和黑色菌核 / 叶上有白粉 | 排水并起高垄 / 把病株连土挖出烧掉 / 保证通风、稀释5-10倍的牛奶 |
| 蛀荚虫 | 幼虫钻进荚里吃籽粒的最大害虫 | 徒手捉卵和幼虫，在田边种诱集作物，并提早播种以避开发生期 |
| 地老虎、根结线虫、蚜虫 | 夜间咬断幼茎基部 / 根上出现瘤状变形 / 吸汁并传播病毒 | 挖开被咬断植株周围的土捉幼虫 / 轮作、与万寿菊间作 / 肥皂水（每1L水加肥皂5g） |

> **壳二孢疫病和枯萎病，这两种病决定了鹰嘴豆栽培的成败。壳二孢疫病经种子和残体而来，随雨水暴发；枯萎病留在土中等上好几年。在没有药剂的条件下，对策只有选种、长期轮作和保证通风这三样。**

&nbsp;&nbsp;&nbsp;波尔多液是将硫酸铜400g和生石灰400g分别溶于100L水中再混合，立即使用。稀植、排水、雨后不进田（碰到湿叶会使壳二孢疫病扩散到整块田）是栽培防治措施。

| 症状 | 原因与对策 |
|:---|:---|
| 整片叶淡黄、植株矮小 | 缺氮（接种失败最常见）。先挖出根检查根瘤，当季施极少量稀释10倍的人尿 |
| 几乎不形成根瘤 | 没有专用菌，或缺硫、缺钼。先确保接种源，硫用家畜粪堆肥和十字花科残体补充 |
| 生长迟缓、叶发紫 | 缺磷。骨粉、烤过的鱼骨 |
| 开花却不结荚 | 缺硼，或开花期夜间气温10℃以下。来年调整播种期 |
| 只有茎叶茂盛、荚少 | 氮过量。立即停止供氮 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 小麦、大麦（根深不同，利用不同层的水和养分）、玉米、高粱（后茬利用鹰嘴豆留下的氮）、芥菜、油菜（残体中的硫化合物能减少病原菌） |
| 差 | 其他豆科（病原菌和线虫积累）、需要大量浇水的作物（鹰嘴豆最怕过湿） |

&nbsp;&nbsp;&nbsp;休耕为3年以上，理想周期4-5年，枯萎病和根结线虫会积累。轮作的例子是鹰嘴豆 → 小麦、大麦、玉米 → 芥菜或油菜之后的叶菜 → 马铃薯或根菜 → 鹰嘴豆。把芥菜、油菜这类十字花科作为前茬尤其合适。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 播种后100-120天，叶片变黄且大部分已落、80%以上的荚果变褐、咬一下会脆脆地裂开时。含水量收获时18%、储存时14%以下 |
| 要领 | 在晴朗干燥、露水已干的上午10点以后，因为叶和荚的酸性分泌物会刺激皮肤，要戴手套，在靠近地面处割下，根留在地里。扎成捆，在阳光下晒4-6天，或挂在屋檐下晾干 |
| 脱粒、精选 | 把干茎装进袋里踩踏或用连枷打（打重了籽粒会裂），也可以在桶内壁上摔打。在有风的日子用簸箕簸去壳，用筛子筛掉裂开的半粒，在水中捞去浮起的，当天内重新晒干 |

> **有下雨的消息就不要等完全成熟，赶紧收。鹰嘴豆灌浆期的雨不仅带来炸荚，还会带来壳二孢疫病。稍微没熟透的豆晒干后还能用，但从病田里什么也收不到。**

| 留种 | 标准 |
|:---|:---|
| 选株、收获 | 预先标记没有病症、荚多、在有枯萎病的田里存活到最后、成熟早的植株。单独脱粒，用手剥则籽粒不会裂 |
| 精选、干燥 | 弃去斑点、裂粒、皱缩、变色的，只留大而完整的籽粒。含水量12-13%，在阴凉处慢慢晾干 |
| 保存 | 装入与食用豆分开的密封容器，放在凉爽阴暗处。常温密封3年，发芽率收获当年85%以上，1年后75-85%，2年后60-75%。如能弄到，每3-4年混入一部分其他地方的种子 |

> **鹰嘴豆是在韩国国内很难再次弄到种子的作物。留种不是选择，而是继续种这种作物的前提条件。即使要减少食用的份额，也要先确保种子。**

## 9. 储存
| 步骤 | 方法 |
|:---|:---|
| 干燥 | 连茎在阳光下晒4-6天，脱粒后薄摊晾2-3天，使含水量食用14%以下、留种12%（咬不动）。在干瓶里放豆和干盐摇一摇，盐粘在瓶壁上就再晒，完全冷却后再装 |
| 豆象防治 | 完全密封最重要。使用隆冬放到室外几天的低温处理（拿回来时注意结露），以及草木灰、硅藻土、油涂层。裂粒会先进虫，所以筛出来先吃 |
| 容器、位置 | 陶罐和地下储藏窖可存2-3年（储藏窖进水则全部损失）。发霉的豆洗了、煮了也不安全，要丢弃，检查靠听声音和闻气味 |

## 10. 烹调与注意事项
| 成分 | 作用 | 去除方法 |
|:---|:---|:---|
| 胰蛋白酶抑制剂、凝集素 | 阻碍蛋白质消化，引起腹痛和腹泻。鹰嘴豆的凝集素比菜豆弱得多 | 浸泡8小时后，在沸水中加热1小时以上 |
| 低聚糖、皂苷 | 肠内发酵使肚子严重胀气 / 泡沫 | 一定要倒掉浸泡的水 / 煮时撇去泡沫 |
| 叶和荚的有机酸、霉菌毒素 | 苹果酸和草酸刺激皮肤和胃 / 储存中霉菌产生的毒素 | 不吃叶，干活时戴手套 / 发霉的丢弃 |

> **鹰嘴豆真正伤人的不是豆本身，而是储存不当而发霉的豆和没煮熟就吃的豆。如果有潮味或表面出现泛青的粉末，不要舍不得，丢掉。**

| 处理 | 标准 |
|:---|:---|
| 基本 | 在常温水中泡8小时以上（夏天换水泡6小时），倒掉泡豆水，再在沸水中煮1小时到1个半小时。煮豆水里加极少量小苏打，或用草木灰水的上清液，皮会很快变软，节省燃料。用手指一按就容易压烂，就是熟了 |
| 去皮掰开 | 用水稍微润湿，在阴凉处放半天，在臼里轻轻捣一下去皮，用簸箕簸走，再捣一下掰成两半，完全晒干后密封保存。不用浸泡，20-30分钟就像粥一样煮软，燃料减半 |
| 节省燃料 | 余热烹调是煮20分钟后放进稻草·稻壳箱或被褥里焖3-4小时。把泡过再晒干的豆不加油炒，可以直接吃，炒后磨成的粉用水和成面糊或冲着喝 |
| 发芽、发酵 | 泡8小时沥水，盖上湿布2-3天，芽长到约1cm时收获，生成维生素C，植酸减少（稍微焯一下凉拌也可以）。磨碎放一夜，会发酵变酸、发起来，更容易消化；煮烂捣碎后发酵的鹰嘴豆大酱，是大豆不足时的替代品 |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存、种子发芽试验（等2周）、按品系整理种子。2月做田地规划、翻堆堆肥、规划确保接种源土 |
| 3-4月 | 3月翻耕、起垄、开排水沟，下旬播种。4月中旬前完成播种，防鸟 |
| 5-6月 | 5月第1次除草、间苗（不浇水）。6月第2次除草、培土、开花、检查根瘤 |
| 7-8月 | 7月鼓荚、捉蛀荚虫、监视壳二孢疫病（连雨则不进田）。8月收获、挂起晾干、脱粒 |
| 9-10月 | 9月精选、晾干、储存、茎叶还田、整理留种。10月检查储存，把长过鹰嘴豆根的土另外保管作接种源 |
| 11-12月 | 11月去皮掰开、磨粉（只做一两个月吃的量）。12月检查储存、培育发芽蔬菜、规划来年 |

> **鹰嘴豆只要确保种子、接种专用菌、种在不积水的田里、初期不浇水、轮作3年以上，就是在干旱的土地上也能产出蛋白质和铁的作物。**
