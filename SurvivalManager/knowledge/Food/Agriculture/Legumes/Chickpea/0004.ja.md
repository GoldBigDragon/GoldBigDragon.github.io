## 5. 畑の準備と肥料 — 窒素収支と施肥

### 5-4. 窒素固定の落とし穴

&nbsp;&nbsp;&nbsp;豆を植えれば土が良くなるという話は、農業の常識として定着しています。半分は正しく、半分は誤りです。この点を正確に理解していないと、マメ科作物を何年も続けて植えた畑がかえって痩せていくということが起こります。

&nbsp;&nbsp;&nbsp;数字で見てみます。ヒヨコマメがよく育てば、1,000㎡で180kgの乾燥種実を収穫します。ヒヨコマメ種実のタンパク質は17.8%で、タンパク質を6.25で割ると窒素量が出ます。17.8 ÷ 6.25は2.85、つまり種実重量の約2.9%が純粋な窒素です。180kgに含まれる窒素は約5.1kgで、ヘクタールに換算すると51kgです。

&nbsp;&nbsp;&nbsp;一方、ヒヨコマメの根粒が固定する窒素は、接種がうまくいった場合1ヘクタールあたり60-100kgです。接種が失敗すると10kgを下回ります。出ていくものと入ってくるものを並べると、次のようになります。

| 項目 | ヘクタール当たり窒素 | 方向 |
|---|---|---|
| 根粒固定量（接種成功） | 60-100kg | 入る |
| 根粒固定量（接種失敗） | 5-15kg | 入る |
| 種実として搬出 | 45-60kg | 出る |
| 茎葉（茎と葉）に残る窒素 | 20-35kg | 畑に戻せば残る、燃やすか持ち出せば出る |
| 根と根粒に残る窒素 | 10-15kg | たいてい畑に残ります |

&nbsp;&nbsp;&nbsp;表から二つのことがわかります。第一に、接種が成功すれば種実を搬出しても窒素は残ります。ヒヨコマメ種実のタンパク質比率が大豆よりずっと低く、搬出量自体が少ないためです。第二に、接種が失敗するとこの関係は完全に逆転します。固定量が10kgなのに種実として50kgを持ち出せば、畑は確実に損をします。ヒヨコマメにおける接種の重要性は、収量だけの問題ではなく畑の持続可能性の問題でもあります。

> **豆科作物が土を育てるのは、窒素を固定するからではなく、固定した窒素の一部を茎と葉に蓄えて畑に残すからです。その茎と葉を持ち出せば、豆は土を収奪する作物になります。**

| 原則 | 内容 |
|---|---|
| 茎葉は必ず畑へ | 脱穀後に残る茎と葉、莢の殻を全て畑に戻します |
| 燃やさない | 燃やすと窒素が気体になって飛び、カリウムとリン酸だけが灰として残ります |
| 根は掘り起こさない | 根が深く、引き抜くのも大変です。茎だけを刈って残すのが正解です |
| 20-30cmに切って覆う | マルチングと肥料を兼ねます |
| 接種を怠らない | 接種の失敗は収量損失であり窒素の収奪でもあります |
| 家畜に与えたなら糞を戻す | 茎葉を家畜に与えたなら、その家畜の糞尿を必ずその畑に入れます |

### 5-5. 畑の準備

| 項目 | 方法 | 災害条件では |
|---|---|---|
| 耕起 | 20-30cmの深さで耕し、均一に整地します | 根が深く入るので深く耕すほうが良いです |
| 畝 | 高さ20cm以上 | 過湿害防止の要です。ヒヨコマメでは前提条件です |
| 排水路 | 深さ30-50cm | 梅雨を見越して深く切ります |
| 酸度矯正 | pH 6.0-8.0 | 適応幅が広いため急ぎません |
| 有機物 | 完熟堆肥1,000-1,500kg/1,000㎡ | 元肥として入れます |

&nbsp;&nbsp;&nbsp;ヒヨコマメはpH適応幅が5.5-8.6と広いため、石灰処理の優先度は他の豆類より低いです。畑がひどい酸性でなければ石灰なしでも育ちます。ただし5.5を下回ると根粒菌が生きられないため、貝殻や卵の殻を焼いて砕いた粉だけでも入れて上げておくほうがよいです。

&nbsp;&nbsp;&nbsp;その代わり、排水には力を入れる必要があります。深く耕して水が下に抜ける道を作り、畝を高くし、排水路を深く切ります。畑を選ぶ段階から水がたまらない場所を選ぶのが最も確実で、傾斜のある畑なら上のほうがヒヨコマメの場所です。

### 5-6. 施肥量

| 肥料 | 1,000㎡基準 | ㎡換算 | 備考 |
|---|---|---|---|
| 窒素 | 0-2kg | 0-2g | ほとんど不要です。多く与えると窒素固定が抑制されます |
| リン酸 | 20-40kg | 20-40g | 全量元肥です。根の発達と開花に必須です |
| カリウム | 3-5kg | 3-5g | 全量元肥です |
| 硫黄 | 10-20kg | 10-20g | 不足すると根粒形成が悪くなります |
| 堆肥 | 1,000-1,500kg | 1-1.5kg | 完全に腐熟したものを使います |

> **ヒヨコマメの施肥で特異なのは硫黄です。硫黄が不足すると根粒がきちんと作られず、そうなると窒素固定そのものが崩れます。他の豆類ではあまり言及されない要素です。**

&nbsp;&nbsp;&nbsp;硫黄が必要な理由は、ニトロゲナーゼ酵素とレグヘモグロビンがいずれも硫黄を含むアミノ酸を使うためです。化学肥料なしで硫黄を供給する経路がいくつかあります。家畜糞尿を入れた堆肥には硫黄が含まれており、アブラナ科作物の残渣を堆肥に入れると硫黄化合物が加わります。ニンニクやタマネギの皮、ハクサイやダイコンの外葉、カラシナの茎のようなものを別途集めて堆肥に混ぜるのが実際的な方法です。ただし、これらはヒヨコマメ畑に直接入れるのではなく、堆肥として腐熟させてから入れる必要があります。

&nbsp;&nbsp;&nbsp;リン酸20から40kgはかなりの量です。ヒヨコマメの深い根の発達と窒素固定のエネルギー代謝が、どちらもリン酸を必要とするためです。化学肥料がない条件では、リン酸は骨粉と魚の骨から得るのが事実上唯一の経路です。

### 5-7. 災害時の代替肥料

| 代替資源 | 供給養分 | 使用法 | 注意 |
|---|---|---|---|
| 骨粉 | リン酸、カルシウム | 焼いて砕き堆肥に混ぜます | ヒヨコマメの高いリン酸要求を満たす要です |
| 魚の骨・魚の内臓 | リン酸、窒素、硫黄 | 埋めて腐熟させてから使います | リン酸と硫黄を同時に供給します |
| 草木灰 | カリウム、リン酸、カルシウム | ㎡あたり100-200gをまいて混ぜます | アルカリ性ですが、ヒヨコマメはpH8.6まで耐えます |
| 完熟堆肥 | 総合 | ㎡あたり1-1.5kgを元肥として入れます | 未熟なものは根を傷め、病気を媒介します |
| アブラナ科残渣堆肥 | 硫黄 | ニンニク・タマネギの皮、ハクサイの外葉を堆肥に混ぜます | 必ず腐熟させてから入れます |
| 家畜糞尿堆肥 | 総合、硫黄 | 完熟させて元肥に | 硫黄供給源として価値があります |
| 薄めた尿 | 窒素、カリウム、硫黄 | 水で10倍に薄めて株間の土に注ぎます | ヒヨコマメにはごく少量のみ。窒素固定を抑制します |
| 貝殻・卵の殻 | カルシウム | 焼いて砕いてまきます | 強酸性土壌にのみ |
| 落ち葉腐葉土 | 総合、有機物 | 土に混ぜ込みます | 保水性を良くします |

## 6. 播種

### 6-1. 播種時期

| 作型 | 播種時期 | 収穫時期 | 備考 |
|---|---|---|---|
| 春栽培（韓国基準） | 3月下旬-4月中旬 | 7月中旬-8月 | 霜が完全に終わった後 |
| 秋播き | 試みないほうがよいです | - | 韓国の冬の寒さを越せません |

&nbsp;&nbsp;&nbsp;ヒヨコマメの播種時期は幅が狭いです。早く播きすぎると開花期が5月の肌寒い夜にかかって花粉ができず、遅く播きすぎると登熟期が梅雨にかかって褐斑病で倒れます。3月下旬から4月中旬というこの期間を守ることが最も重要な決定です。

> **播種時期がヒヨコマメの収穫量を左右します。3月下旬から4月中旬の期間を逃せば、その年の農作業の上限はすでに決まってしまいます。**

&nbsp;&nbsp;&nbsp;原産地では秋に播いて冬を越させる作型が一般的ですが、韓国では冬の寒さがヒヨコマメの耐寒限界を超えるため失敗します。軽い霜に耐えることと冬を越すことは別の話です。ヒヨコマメの耐寒性Bは、春の遅霜を乗り切れるという意味であって、越冬できるという意味ではありません。

### 6-2. 種子の準備

| 項目 | 方法 | 災害条件では |
|---|---|---|
| 選別 | 斑点、変色、しわ、虫食い穴のある種子を捨てます | 褐斑病は種子で伝染します。選別が防除の半分です |
| 粒の大きさ選別 | 大きく重い粒を選んで使います | 水に浮かべて浮くものを取り除きます |
| 温水消毒 | 50-55℃の湯に10-15分浸けます | 種子伝染性の病原菌を殺します |
| 灰処理 | 細かい草木灰をまぶします | 消毒と乾燥を助け、鳥や虫を遠ざける効果があります |
| 根粒接種 | ヒヨコマメを育てた畑の土をまぶします | 5-3節参照。消毒とは同時に行いません |
| 浸漬 | しないほうがよいです | 浸漬すると種皮が軟らかくなり、土の中で腐りやすくなります |
| 発芽試験 | 濡れた布に20粒を包み2週間置いて、発芽した数を数えます | 発芽が遅いので2週間待ちます |

&nbsp;&nbsp;&nbsp;種子選別はヒヨコマメで特に重要です。褐斑病は種子の表面と種皮の内側に付着して翌年へ持ち越されます。病気にかかった種子は表面に褐色や黒の斑点があったり、しなびていたりします。このような種子が一粒あるだけで、翌年畑一枚に病気が広がります。農薬のない条件では、種子選別は防除の最も強力な手段であり、必要なのは明るい光と目と時間だけです。温水消毒を併用すれば、表面の病原菌をかなり殺すことができます。

### 6-3. 播種方法

| 項目 | 基準 | 理由 |
|---|---|---|
| 播種深さ | 3-5cm | 深すぎると発芽がさらに遅くなります |
| 1穴あたり粒数 | 1-2粒 | 発芽が遅いので保険をかけます |
| 条間 | 25-60cm | 枝を多く出すのでゆったり空けます |
| 株間 | 20-25cm | |
| 播種量（デシ小粒種） | 2.5-4kg/1,000㎡ | 粒が小さいため少なくて済みます |
| 播種量（カブリ大粒種） | 8-12kg/1,000㎡ | 粒が大きいため多く要ります |
| 発芽期間 | 10-14日 | 忍耐が必要です |

&nbsp;&nbsp;&nbsp;栽植密度は通風に直結します。ヒヨコマメの最大の病害である褐斑病は、葉が濡れている時間が長いほど悪化するため、密植すると危険性が大きく上がります。種子に余裕があっても、密に植えないほうがよいです。条間をゆったり空けて風を通し、畑の長い辺を風向きに合わせて畝を立てると助けになります。

&nbsp;&nbsp;&nbsp;播種直後の10日から15日ほどは何も出てこないという事実を改めて強調しておきます。この期間に土が固まって硬い表面ができると、幼い芽が突き抜けられません。雨の後に土が固まったら、条の上を熊手で軽くかいて砕いてやります。逆に水を頻繁にやって土が常に湿っていると、種子が腐ります。

## 7. 水管理

| 時期 | 水管理 | 理由 |
|---|---|---|
| 播種から発芽 | 土がからからに乾かないようにします | 発芽に10-14日かかります |
| 生育初期 | 水をやりません | 乾いた条件が根を1mの深さまで押し下げます |
| 開花期から莢肥大期 | 干ばつがひどければ灌水します | この時期の水不足が収量を最も大きく減らします |
| 登熟期 | 灌水を止めます | 過湿だと脱粒や品質低下が起こります |
| 梅雨時 | 排水路を切ります | ヒヨコマメで最も危険な時期です |

> **ヒヨコマメの水管理は与える技術ではなく、こらえる技術です。初期に水を頻繁に与えると根が浅くなり、浅い根は後の干ばつに耐えられません。**

&nbsp;&nbsp;&nbsp;これがヒヨコマメを他の作物と根本的に違うものにしている点です。ヒヨコマメは乾いた土地で根を深く張るように進化しました。初期に表層が常に湿っていると、植物は深く下りる理由を感じず、根を浅く広げます。そして夏に干ばつが来ると、その浅い根では水を見つけられず倒れます。初期の乾燥に耐えさせておくことが、結果的に干ばつに勝つ道です。

| 症状 | 原因 | 対応 |
|---|---|---|
| 日中に葉が閉じ、夕方開く | ヒヨコマメの正常な水分節約反応です | そのままにします |
| 朝になっても葉が閉じている | 激しい乾燥 | 灌水します |
| 葉が下から黄色く枯れる | 激しい干ばつまたは根粒不良 | 根を掘って根粒を確認してから判断します |
| 花が大量に落ちる | 開花期の乾燥、または夜間気温10℃以下 | 灌水。低温が原因なら翌年の播種を調整します |
| 下の葉が黄色くなり、茎の根元が褐色に軟化する | 過湿による根腐れ | 排水路を切ります。ひどければ抜き取ります |
| 葉に褐色の斑点ができ、茎が折れる | 褐斑病。雨が続いた後に現れます | 病株を抜いて焼却します。広がれば早期収穫を検討します |

&nbsp;&nbsp;&nbsp;ヒヨコマメの葉が日中に閉じるのは病気ではなく正常な反応です。小さな葉が上に折りたたまれて向き合うと、日光を受ける面積が減り蒸散が抑えられます。夕方になると再び開きます。この動きは、ヒヨコマメが250mmの水で一作を終えられる理由の一つであり、朝になっても葉が閉じているなら、それこそ本当に水が不足しているときです。

&nbsp;&nbsp;&nbsp;マルチングはヒヨコマメでは慎重に使う必要があります。表面からの蒸発を減らし水を節約する効果はありますが、厚く覆って土が常に湿っていると褐斑病や根腐病が増えます。覆うとしても薄く、そして梅雨が始まったら一部を取り除いて通風を確保するほうがよいです。
