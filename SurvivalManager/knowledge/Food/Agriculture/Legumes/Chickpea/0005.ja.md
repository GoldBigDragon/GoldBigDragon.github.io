## 8. 栽培管理

### 8-1. 雑草管理

| 時期 | 作業 | 要点 |
|---|---|---|
| 出芽後2~3週 | 1回目の除草 | 雑草が小さいうちに抜きます。浅くかきます |
| 出芽後45日頃 | 2回目の除草 | 土寄せと兼ねます |
| 開花前 | 全ての除草作業を終えます | 以降は畑に入りません |

&nbsp;&nbsp;&nbsp;ヒヨコマメは雑草との競争に特に弱いです。発芽に10日から15日かかり初期の生育も遅いため、その間に雑草が先に居場所を確保します。しかも草丈が40cm前後と低いため、雑草に覆われると光を奪われます。初期6週間の除草がヒヨコマメの収量を左右すると言っても言い過ぎではありません。

&nbsp;&nbsp;&nbsp;ただし、除草には注意すべき点があります。ヒヨコマメの細根は表層に広く張っているため、深くかくと根が切れてしまいます。鍬を寝かせて土の表面2cmだけをかいて雑草を浮かせるやり方にし、株の近くは手で抜きます。また、葉の酸性分泌物のせいで素手で長く触ると肌がひりひりするので、手袋をはめるほうがよいです。

&nbsp;&nbsp;&nbsp;開花後は畑に入らないのが原則です。人が通ると花が落ち、露が乾いていない朝に行き来すると褐斑病の胞子が服や靴に付いて畑全体に広がります。特に雨の直後の出入りは、褐斑病を広げる最も確実な方法です。

### 8-2. 土寄せと倒伏管理

| 作業 | 時期 | 効果 |
|---|---|---|
| 土寄せ | 播種後45日頃、2回目の除草と同時に | 株元を土で覆って支えを作り、畝間が深くなって水はけが良くなります |
| 縄支柱 | 倒伏の恐れがあるとき | 畑の周囲に杭を打ち、膝の高さで縄を張り巡らせます |

&nbsp;&nbsp;&nbsp;ヒヨコマメは草丈20-100cm、たいてい40cm前後なので支柱は必要ありません。茎がまっすぐで枝を多く出し、互いに寄りかかって立つためです。これはエンドウと比べてヒヨコマメが持つ明確な利点です。竹や紐がなくても育てられます。ただし施肥が過剰で徒長したり、風雨の激しい年には倒れることがあり、そのときは土寄せと畑周囲の縄程度で対応します。

## 9. 病害虫

&nbsp;&nbsp;&nbsp;ヒヨコマメの病害虫圧はCです。葉の酸性分泌物のおかげで葉を食う害虫の被害は他の豆類より少ないですが、カビ病二つがこの作物の運命を左右します。

### 9-1. 主な病害

| 病名 | 症状 | 発生条件 | 薬なしでの対応 |
|---|---|---|---|
| 褐斑病（Ascochyta） | 葉と茎と莢に同心円模様の褐色斑点ができ、茎がその部分から折れます | 雨が続き涼しいとき。種子と残渣で伝染 | 種子選別と温水消毒、3年以上の輪作、通風確保、病残渣の焼却。広がれば早期収穫 |
| 萎凋病（Fusarium） | 開花期に下の葉から萎れ、株全体が枯れ死にます。茎を割ると中が褐色です | 土壌伝染。土中で何年も生存 | 3年以上の輪作が唯一の対策です。抵抗性系統の選抜 |
| 根腐病 | 茎の根元と根が褐色に軟化します | 過湿 | 排水、畝の嵩上げ |
| うどんこ病 | 葉の表面が白い粉で覆われます | 乾燥して寒暖差が大きいとき | 通風確保、牛乳5-10倍希釈液 |
| 菌核病 | 茎が軟化し、白い綿のような菌糸と黒い菌核ができます | 涼しく湿っているとき | 病株を土ごと掘り出して焼却します |

> **褐斑病と萎凋病、この二つがヒヨコマメ栽培の成否を分けます。褐斑病は種子と残渣を通じてやって来て雨とともに爆発的に広がり、萎凋病は土に残って何年も待ち構えます。薬のない条件での対応は、種子選別と長い輪作と通風、この三つだけです。**

&nbsp;&nbsp;&nbsp;褐斑病の恐ろしさはその速さです。雨が数日続くと、葉の小さな斑点が数日のうちに茎へと広がり、茎が折れて株全体が倒れます。ひどい年には畑全体を失います。対応の順序は次のとおりです。第一に、種子から始まるので斑点のある種子を徹底して取り除き、温水消毒をします。第二に、疎植にして葉が早く乾くようにします。第三に、雨の後は畑に入りません。第四に、病気にかかった残渣は畑に戻さず焼却します。第五に、すでに広がり始めているなら完熟を待たずに収穫します。

&nbsp;&nbsp;&nbsp;萎凋病は性格が異なります。土の中に休眠胞子として残り何年も持ちこたえ、ヒヨコマメが再び植えられると目覚めます。一度汚染された畑では、開花期のたびに株が萎れて枯れることが繰り返されます。薬もなく、洗い流す方法もありません。3年以上、できれば4年から5年の輪作が唯一の対策であり、その畑で最後まで生き残って種をつけた個体を選んで受け継いでいくことが二番目の対策です。抵抗性は遺伝するため、何年か繰り返せばその畑に耐える系統が作られます。

### 9-2. 主な害虫

| 害虫 | 被害 | 薬なしでの防除 |
|---|---|---|
| 莢食い虫（ワタノメイガ・オオタバコガの仲間） | 幼虫が莢に穴を開けて入り込み種実を食べます。最大の害虫 | 卵と幼虫を手で取ります。畑の周囲に誘引作物を植えます。早期播種で発生期を避けます |
| ネキリムシ（カブラヤガなど） | 夜間に若い茎を根元から切り倒します | 朝、切られた株の周りの土を掘ると幼虫がいます。捕まえて駆除します |
| ネコブセンチュウ | 根にこぶ状の変形ができ、生育が振るいません | 輪作、マリーゴールドの間作 |
| アブラムシ | 汁を吸い、ウイルスを媒介します | 石けん水（水1Lに石けん5g）。葉の酸性分泌物のおかげで被害は少ないほうです |
| 鳥 | 播種直後は種子を、登熟期には実を食べます | 発芽まで藁や網で覆います |

&nbsp;&nbsp;&nbsp;莢食い虫がヒヨコマメの最大の害虫です。葉の酸性分泌物は葉を食う害虫を撃退しますが、莢に穴を開けて入り込む幼虫は防げません。外見上は莢が無傷でも、開けてみると実がなかったり幼虫が入っていたりします。薬なしで対処する方法は三つです。第一に、莢がつき始める頃から早朝に畑を回り、葉裏の卵塊と若い幼虫を手で捕まえます。第二に、畑の周囲に蛾がより好む作物を植えて引き寄せ、そこで集中的に捕らえます。第三に、早期播種で莢の時期を蛾の発生ピークより前にずらします。

### 9-3. 薬を使わない防除資材

| 資材 | 作り方 | 対象 | 注意 |
|---|---|---|---|
| ボルドー液 | 水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜます | 褐斑病、カビ病 | 銅がないと作れません。混ぜたらすぐに使います |
| 石けん水 | 水1Lに無香料石けん5g | アブラムシ、ハダニ | 日中の暑い時間にまくと葉が焼けます |
| 牛乳希釈液 | 牛乳を水で5-10倍に希釈します | うどんこ病 | 晴れた日の午前中にまきます |
| 乾いた灰まき | 露のある朝に葉へ細かい灰をまきます | カビ抑制、食葉害虫 | 雨が降ると洗い流されます |
| 草木灰水 | 灰1升（ドェ）を水10Lに一晩浸け、上澄みを使います | カビ抑制 | アルカリ性なので薄めて使います |
| 木酢液 | 炭を焼くときに出る液を300-500倍に希釈します | 忌避、生育促進 | 原液は強酸性なので必ず希釈します |
| 唐辛子・ニンニク水 | すりつぶして水に浸し、こして使います | 蛾の忌避 | 効果が長続きしないので頻繁にまきます |

### 9-4. 耕種的防除

| 方法 | 原理 |
|---|---|
| 種子選別 | 褐斑病は種子で伝染します。斑点や変色を取り除くだけで発生を大きく減らせます |
| 温水消毒 | 50-55℃で10-15分、種子表面の病原菌を殺します |
| 3年以上の輪作 | 萎凋病の胞子が土の中で減るのを待ちます |
| 疎植 | 通風が良いと葉が早く乾き、褐斑病が定着できません |
| 排水 | ヒヨコマメの病害の多くは過湿に関係します |
| 早期播種 | 登熟期を梅雨より前にし、莢食い虫の発生期を避けます |
| 雨後の畑立ち入り禁止 | 濡れた葉に人が触れると、褐斑病が畑全体に広がります |
| 残渣処理 | 病気にかかった残渣は必ず焼却します。健康な残渣だけを畑に戻します |
| 生き残った個体の採種 | 萎凋病が回る畑で最後まで生き残った株を選んで受け継ぎます |

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然材料での対処 |
|---|---|---|
| 葉全体が薄い黄色で、株が小さい | 窒素欠乏。ヒヨコマメでは接種失敗が最も多い原因です | まず根を掘って根粒を確認します。根粒がなければ、当年は尿の10倍希釈液をごく少量与え、翌年は接種を行います |
| 根粒がほとんどできない | 専用菌の不在、または硫黄・モリブデンの欠乏 | 接種源の確保が優先です。硫黄は家畜糞尿堆肥とアブラナ科残渣で補います |
| 葉の縁が褐色に枯れる | カリウム欠乏 | 株間に草木灰をまき、軽くかき込みます |
| 生育が遅く、葉が紫色を帯びる | リン酸欠乏。ヒヨコマメはリン酸要求が高いです | 骨粉、焼いた魚骨の粉 |
| 花は咲くが莢がつかない | ホウ素欠乏、または開花期の夜間気温10℃以下 | 複数の材料を混ぜた堆肥。低温が原因なら翌年の播種時期を調整します |
| 葉脈の間が黄色い | 鉄またはマンガン欠乏。アルカリに傾いた土でよく見られます | 灰の使用をやめます。腐葉土と完熟堆肥で有機物を増やします |
| 茎葉ばかり茂り莢が少ない | 窒素過剰 | 窒素の供給を直ちに中止します |

&nbsp;&nbsp;&nbsp;ヒヨコマメで窒素欠乏の症状を見たとき、最初にすべきことは肥料を与えることではなく、根を掘ってみることです。韓国の畑にはヒヨコマメ専用の菌がほとんどないため、接種せずに植えた畑では根粒がまったくできていない場合が多いです。この場合、窒素を与えれば当年の収量は多少良くなりますが、根本は直りません。それどころか、わずかにある根粒の機能まで減らしてしまいます。当年は最小限でしのぎ、翌年に接種で根本を直すのが正しい順序です。

&nbsp;&nbsp;&nbsp;硫黄欠乏は、ヒヨコマメだけで特別に気をつけるべき項目です。症状が窒素欠乏に似ていて紛らわしいですが、窒素欠乏は下の葉から黄色くなり、硫黄欠乏は新しく出る上の葉から薄くなります。硫黄が不足すると、根粒ができてもきちんと機能しません。家畜糞尿を入れた堆肥、魚の内臓を腐熟させたもの、ニンニクとタマネギとハクサイの残渣を入れた堆肥が実際的な供給源です。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 作物 | 理由 |
|---|---|---|
| 良い | コムギ・オオムギ | 根の深さが異なり、水と養分を異なる層から使います |
| 良い | トウモロコシ・モロコシ | ヒヨコマメが残した窒素を後で使います |
| 良い | マリーゴールド | 根の分泌物が線虫を抑制します |
| 良い | カラシナ・アブラナ | 残渣が土に硫黄化合物を残し、病原菌を減らします |
| 普通 | 葉物野菜 | 初期は一緒に育ちますが、ヒヨコマメが大きくなると陰になります |
| 悪い | 他のマメ科 | 病原菌と線虫が蓄積します |
| 悪い | 水を多くやる作物 | ヒヨコマメは過湿に最も弱いです |

&nbsp;&nbsp;&nbsp;ヒヨコマメの配置で特に考慮すべき点は水です。頻繁に灌水する作物と同じ畝や隣り合う畝間に植えると、その水がヒヨコマメの根まで届いてしまいます。ヒヨコマメは豆類の中で最も過湿に弱いため、畑の中で最も水はけが良く灌水の届かない場所に配置すべきです。畑に傾斜があるなら、上のほうがヒヨコマメの場所です。

&nbsp;&nbsp;&nbsp;カラシナやアブラナのようなアブラナ科を前作にすることは、ヒヨコマメに特によく合います。これらの作物の残渣が土の中で分解される際に硫黄化合物を出し、これが萎凋病の病原菌密度を下げると同時に、ヒヨコマメが必要とする硫黄を供給します。一つの配置で二つの問題に対処できます。

### 11-2. 輪作

| 項目 | 基準 |
|---|---|
| 休作期間 | 3年以上。萎凋病が土に残ります |
| 理想的な周期 | 4-5年 |
| 連作障害 | 萎凋病とネコブセンチュウが蓄積します |

| 4年輪作の例 |
|---|
| 1年目：ヒヨコマメ |
| 2年目：穀物（コムギ・オオムギ・トウモロコシ） |
| 3年目：カラシナまたはアブラナ、次いで葉物野菜 |
| 4年目：いも類（塊茎・塊根）または根菜 |
| 再びヒヨコマメ |

&nbsp;&nbsp;&nbsp;ここにヒヨコマメ特有の制約がもう一つ加わります。接種源を維持しなければならないという点です。3年以上ヒヨコマメを植えないと、専用菌の密度も一緒に下がります。輪作で病原菌を減らす間に、有益菌も減ってしまうのです。解決策は、接種源専用の区画を別に設けることです。畑の片隅の小さな区画で毎年少量のヒヨコマメを続けて植えて菌を維持し、その土を毎年本畑の接種源として使います。その区画では萎凋病が蓄積していきますが、目的は種子を得ることではなく菌を維持することなので、受け入れられる範囲です。

## 12. 収穫と脱穀

### 12-1. 収穫時期の判断

| 判断基準 | 内容 |
|---|---|
| 葉 | 葉が黄色くなり大部分が落ちています |
| 莢 | 全体の80%以上が褐色に変わっています |
| 音 | 振ると莢の中で実がぶつかる音がします |
| 実 | 噛むと歯が入らずぽきっと割れます |
| 水分 | 収穫時18%、貯蔵時14%以下 |
| 時期 | 播種後100-120日 |

> **雨の予報があれば完熟を待たずに収穫します。ヒヨコマメの登熟期の雨は、脱粒だけでなく褐斑病も一緒に呼び込みます。少し未熟な豆は乾燥させて使えますが、病気にかかった畑では何も収穫できません。**

### 12-2. 収穫のコツ

| 順序 | 内容 |
|---|---|
| 1 | 晴れて乾いた日、露が乾いた午前10時以降に行います |
| 2 | 手袋をはめます。葉と莢の酸性分泌物が肌を刺激します |
| 3 | 地面近くで茎を刈ります。根は畑に残します |
| 4 | 束にして日に4-6日干すか、軒下に掛けて乾かします |
| 5 | 莢がしっかり乾き、振ると音がするようになったら脱穀します |

&nbsp;&nbsp;&nbsp;手袋はヒヨコマメの収穫において形式的な勧告ではありません。葉と莢に密生する分泌腺からリンゴ酸とシュウ酸が出て植物の表面が酸性を帯びるため、素手で半日作業すると指先がひりひりして荒れます。特に露が残っていたり雨の直後は、分泌物が水に溶けてさらに刺激が強くなります。布で手を覆うだけでも大きく違います。

### 12-3. 脱穀 — 道具なしで行う方法

| 方法 | 道具 | 手順 | 効率 |
|---|---|---|---|
| 袋踏み | 厚手の麻袋や袋 | 乾いた茎を袋に入れて口を縛り、足で踏みます | 少量に最も向いています。実が飛び散りません |
| 殻竿（からさお） | 長い柄に振り子を付けた道具 | むしろを広げ、茎を薄く広げて上から打ちます | 中規模に適しています。強く打つと実が割れます |
| 棒で叩く | 木の棒 | 袋に入れるかむしろに広げて叩きます | 殻竿がないときの代わりになります |
| 足でもみ転がす | なし | むしろに広げ、靴を履いた足でもみながら転がします | 少量に適しています |
| 板に打ちつける | 板や桶 | 茎の束をつかんで桶の内壁に打ちつけます | 実が桶の中に集まり損失が少ないです |

&nbsp;&nbsp;&nbsp;ヒヨコマメの脱穀で特に注意すべき点は、実が割れやすいことです。種皮は厚いものの、実自体は二つに割れやすい構造のため、強く叩くと半分に割れた実が多く出ます。食用には問題ありませんが種子用には使えず、貯蔵中に虫が先に入り込みます。袋に入れて足で踏む方式が最も損失が少なく、殻竿を使うときは力を抜いて何度も打つほうがよいです。

### 12-4. 精選 — 風で選り分ける

| 方法 | 原理 | 手順 |
|---|---|---|
| 風選（風でふるう） | 実は重く、殻やくずは軽いです | 風のある日に、箕や広い器に入れて高く持ち上げ、ゆっくり注ぎ落とします |
| 箕であおる | 上下に振りながら前方へあおります | 重い実が後ろに残り、軽いものが前へ押し出されます |
| うちわあおぎ | 一人が注ぎ、もう一人がうちわで風を送ります | 風のない日に使います |
| ふるい分け | 穴の大きさで分けます | 割れた半分の実をより分けるのに特に有効です |
| 水に浮かべる | しいなや虫食いの実は軽いです | 水桶に入れて浮くものを取り除きます。引き上げたものはその日のうちに再び乾かします |
| 傾斜板転がし | 丸い実はよく転がり、くずは引っかかります | 板を傾けて置き、転がして落とします |

&nbsp;&nbsp;&nbsp;風選のコツは三つです。風が一定に吹く早朝か夕暮れ時を選び、一度に注がず細く流し落とし、二、三回繰り返します。ヒヨコマメではふるい分けをもう一段階加えるとよいです。脱穀中に割れた半分の実を細かいふるいで選り分けて別に集めておけば、それは貯蔵に向かないので先に食べ、完全な実だけを貯蔵に回せます。
