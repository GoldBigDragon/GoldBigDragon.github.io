## 13. 留种

| 项目 | 方法 |
|---|---|
| 留种植株的挑选 | 提前在田间做好标记：选无病症、结荚多，并且在枯萎病流行的地块中坚持到最后的存活植株 |
| 收获时期 | 待豆荚完全变褐后再收，比食用豆稍晚收获 |
| 分离 | 单独脱粒。用手剥壳籽粒不会裂开 |
| 筛选 | 剔除全部有斑点、裂开、皱缩、变色的籽粒，只留下颗粒饱满完整的 |
| 干燥 | 水分12-13%，在阴凉处慢慢晾干 |
| 保存 | 装入密闭容器，放在阴凉黑暗处，须与食用豆分开存放 |
| 保存期 | 常温密封3年 |
| 更新 | 若能获得，每隔3-4年掺入一些其他产地的种子 |

> **鹰嘴豆是在韩国国内很难再买到种子的作物。留种不是可选项，而是持续种植这种作物的前提条件。哪怕要少吃一些，也要先把种子确保下来。**

&nbsp;&nbsp;&nbsp;留种中最重要的性状是枯萎病抗性。在病害流行的地块，周围植株都已枯死，若唯独有一株存活并结出种子，那便是最珍贵的种子。抗性可以遗传，因此挑选这样的个体延续下去，几年之内就能培育出耐受这块地的品系。韩国国内适应性试验中不同品系的产量相差20倍以上，反过来看，也正说明可供选育的空间有多大。

&nbsp;&nbsp;&nbsp;其次重要的性状是耐褐斑病和早熟性。能在梅雨前完成灌浆的个体能够避开病害。在田里给比别的植株更早变褐的豆荚系上一根线、单独收获，这个习惯几年后会带来很大的差异。

&nbsp;&nbsp;&nbsp;鹰嘴豆是自花授粉作物，不必担心隔离距离，即使把多个品系并排种植，性状也不会混杂，这对同时试验和选育多个品系是有利的条件。不过为避免种子混淆，仍应按品系分别收获、分别装存，并在容器上标明是哪块地、哪一年的种子。

| 种子保存年限与发芽率 |
|---|
| 收获当年：85%以上 |
| 经过1年：75-85% |
| 经过2年：60-75% |
| 经过3年：40-60% |
| 4年以后：急剧下降 |

## 14. 毒性与抗营养成分

&nbsp;&nbsp;&nbsp;鹰嘴豆在豆类中属于毒性风险较低的一种，既没有像菜豆那样生吃几粒就会中毒的强效凝集素，也没有像蚕豆那样在特定体质人群中引发急性溶血的成分。不过干鹰嘴豆和其他豆类一样含有抗营养成分，生食无法消化。

| 成分 | 作用 | 症状 | 消除方法 |
|---|---|---|---|
| 胰蛋白酶抑制剂 | 阻碍蛋白酶的分解作用 | 腹痛、腹泻、蛋白质利用率下降 | 浸泡8小时后，在沸水中加热1小时以上 |
| 凝集素 | 附着在肠黏膜上妨碍吸收 | 消化不适 | 加热可破坏，效力远弱于菜豆类 |
| 植酸 | 与铁、锌、钙结合，妨碍其吸收 | 长期食用会导致贫血、缺锌 | 通过浸泡、发芽、发酵可减少60-80% |
| 低聚糖（棉子糖·水苏糖） | 人体无法消化，由肠道细菌发酵分解 | 腹部严重胀气 | 浸泡后务必倒掉浸泡水 |
| 皂苷 | 会起泡沫 | 少量无害 | 煮制过程中撇去浮沫 |
| 叶片和豆荚的有机酸 | 苹果酸与草酸 | 刺激皮肤，大量食用会刺激胃部 | 叶片不作食用，作业时戴手套 |
| 霉菌毒素 | 由贮藏期间的霉菌产生 | 危险 | 发霉的豆子无论清洗还是加热都无法变安全，须丢弃 |

> **鹰嘴豆真正伤人的，不是豆子本身，而是贮藏不当发霉的豆子，以及没煮熟就吃的豆子。若闻到潮湿霉味，或表面出现发青的粉状物，不要舍不得，直接丢弃。**

| 处理 | 时间·温度 | 效果 |
|---|---|---|
| 浸泡 | 常温水中浸泡8小时以上，夏季需换水，浸6小时 | 种皮厚，须充分泡发 |
| 倒掉浸泡水 | 必须进行 | 连同溶入水中的低聚糖和抗营养成分一起倒掉 |
| 煮制 | 在沸水中煮1小时到1个半小时 | 在豆类中烹饪时间偏长 |
| 去皮掰半 | 泡发后去皮并掰成两半 | 烹饪时间缩短至20-30分钟 |
| 用小苏打代替盐 | 在煮豆水中加极少量 | 能让皮更快软化，节省燃料；若没有，可用草木灰浸泡后的上层清液代替 |
| 检查是否煮熟 | 用手指按压能轻松压碎 | 若还有硬芯，说明尚未煮透 |

&nbsp;&nbsp;&nbsp;鹰嘴豆的低聚糖含量在豆类中也算偏高，突然大量食用会造成严重胀气，对长期饥饿者或儿童尤其需要留意。应从少量开始、经过几天逐渐增加，浸泡水务必倒掉。若把煮豆水也倒掉、换新水重煮，能进一步降低，但营养素也会随之流失，需根据具体情况权衡。

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;鹰嘴豆的耐储性为SS。FAO食品损失指数中，贮藏阶段损失率的中位数仅0.49%，干燥籽粒常温下可存放3年，这得益于种皮厚而坚硬、虫害不易侵入的结构。但一旦条件不当，象鼻虫便会趁虚而入。

### 15-1. 干燥是第一位的

| 阶段 | 方法 | 确认 |
|---|---|---|
| 预干燥 | 连茎在阳光下晾晒4-6天，或挂在屋檐下晾干 | 豆荚彻底晒干 |
| 脱粒后干燥 | 摊在席子或垫子上薄薄一层，晒2-3天 | 需经常翻动以均匀干燥 |
| 目标水分 | 食用14%以下，种用12% | 用牙咬时牙齿陷不进去，会脆脆地裂开 |
| 盐粒测试 | 把干盐和豆子一起放入瓶中摇晃 | 盐若粘在瓶壁上，说明仍然偏潮 |
| 放凉 | 从太阳下收回后，完全放凉再装入容器 | 趁热密封会产生冷凝水 |

&nbsp;&nbsp;&nbsp;干燥不足会让后面的一切措施都失效。水分超过15%霉菌就会滋生，超过13%象鼻虫的繁殖就会加快。反过来，晒得太干籽粒又会裂开。鹰嘴豆本来结构上就容易裂成两半，若在日照过强的日子长时间暴晒，自然裂开的籽粒会增多。应避开下午的强烈日照，最好上午晾晒、下午就收进屋内。

### 15-2. 贮藏期间的豆象防治

&nbsp;&nbsp;&nbsp;豆象一类是贮藏豆类的最大威胁。可怕之处在于，它的侵害其实从田里就已经开始了：成虫会在还挂在田里的豆荚上产卵，这些卵进入贮藏空间后孵化，钻入豆粒之中。也就是说，豆子搬进仓库时卵早已附着其上；一个世代不到一个月，不出半年一袋豆子就会被蛀成满是孔洞的空壳。鹰嘴豆种皮厚，比其他豆类更耐抵抗，但并非绝对安全。

| 方法 | 原理 | 应用 | 效果 |
|---|---|---|---|
| 完全密封 | 隔绝氧气使其窒息 | 将玻璃瓶或金属罐装满并密封 | 最为可靠，3-4周内连卵和幼虫都会死亡 |
| 掺草木灰 | 细小颗粒刮擦外骨骼蜡质层使其脱水 | 按豆子体积的2-5%掺入 | 食用前用水冲洗干净 |
| 硅藻土 | 硅质外壳会损伤外骨骼 | 每1kg豆子加1-3g | 效果比草木灰更好，只在干燥状态下起作用 |
| 涂油法 | 油膜能阻止卵附着和孵化 | 每1kg豆子加2-5mL食用油揉拌 | 对豆类效果显著，种子用豆不可使用 |
| 低温处理 | 零下低温会杀死卵和幼虫 | 在隆冬时节放到室外数日后再收回 | 收回时须注意防止结露 |
| 高温处理 | 60度时卵和幼虫会死亡 | 摊薄放在阳光下晒半天 | 种子用豆不可使用 |
| 干辣椒·花椒·艾草 | 精油成分能抑制产卵 | 一层豆一层香料铺放 | 属于辅助手段 |
| 木炭·炒盐 | 吸收湿气 | 用布包好放入 | 兼有防霉效果 |
| 埋入草木灰中 | 兼具密闭与物理防治的效果 | 在陶缸中一层灰一层豆交替堆放 | 传统上曾被广泛使用 |
| 优先食用裂粒 | 裂开的籽粒最容易被虫蛀 | 用筛子筛出单独存放并优先食用 | 对鹰嘴豆尤其实用 |

&nbsp;&nbsp;&nbsp;最重要的是完全密封。虫子也需要呼吸，在密闭容器中豆子和虫子消耗氧气后，氧气减少、二氧化碳升高，虫子便会死亡。豆子处于休眠状态，能耐受这种环境。容器装得越满、空隙越小，效果就越快。与其用一个大容器，不如用多个小容器装得满满的，这样做还有一个好处：万一其中一个坏了，也不会全部损失。

&nbsp;&nbsp;&nbsp;涂油法是印度和非洲的小农户长期使用的方法。往1kg豆子中加入2-3ml食用油，用手揉搓，让每粒豆子都裹上一层薄膜。油膜能让成虫难以附着产卵，也能堵住已附着卵的气孔，妨碍其孵化。此法只用于半年内要吃的部分，种子用豆不可使用。草木灰则要过筛只取细粉部分，按豆子体积的2-5%掺入，虫子无法对其产生抗性，对人体也无害。

### 15-3. 贮藏容器与场所

| 容器 | 密闭性 | 期限 | 优点 | 缺点 |
|---|:---:|---|---|---|
| 玻璃罐 | 非常好 | 3年以上 | 能用肉眼观察状态 | 容量小，无法遮光 |
| 金属罐 | 非常好 | 3年以上 | 能完全阻挡老鼠和虫子 | 一旦结露，该处会受损 |
| 陶缸 | 好 | 2-3年 | 温度变化缓慢，老鼠咬不穿 | 笨重且易碎 |
| 厚塑料袋 | 一般 | 1-2年 | 轻便且便宜 | 会被老鼠咬破 |
| 地下窖藏 | 好 | 2-3年 | 温度低且稳定 | 一旦渗水会损失全部 |

&nbsp;&nbsp;&nbsp;检查时最可靠的感官是听觉和嗅觉。把耳朵贴在容器上若听到沙沙声，说明虫子正在活动；若闻到潮湿的气味，说明霉菌已经开始滋生。若表面出现小而圆的孔洞，说明象鼻虫已经繁殖了一代以上。即便到了这个阶段，只要把全部豆子取出晒干，用水漂去空壳籽粒，再掺入草木灰或油重新密封，仍能保住剩下的部分。基本标准是每两个月检查一次。

## 16. 烹饪与加工

### 16-1. 去皮掰半的形态——燃料减半

&nbsp;&nbsp;&nbsp;鹰嘴豆烹饪中最有价值的技巧，是预先去皮并掰成两半。这就是印度称为恰纳豆（chana dal）的形态，能把烹饪时间从1小时缩短到20到30分钟。在燃料稀缺的条件下，这个差距会日积月累。

| 顺序 | 内容 |
|---|---|
| 1 | 把干鹰嘴豆在水中稍微一浸，让表面微微沾湿 |
| 2 | 放在阴凉处半天，只让外皮吸收水分 |
| 3 | 放入臼中轻轻捣，力度只到能脱皮，而不是把籽粒捣碎 |
| 4 | 用簸箕或扇子扇去脱下的皮 |
| 5 | 把剩下的籽粒再轻轻捣一次，就会裂成两半 |
| 6 | 彻底晒干后密封保存 |

&nbsp;&nbsp;&nbsp;做成这种状态后，不需浸泡，只要20到30分钟就能煮得像粥一样软烂。不过去皮的豆子耐储性会下降：失去种皮这层防护，虫害容易侵入，氧化也会加快。因此原则上不要一次性全部加工，只加工一两个月内要吃的量。去掉的皮不要丢弃，收集起来可用作牲畜饲料或堆肥。

### 16-2. 省燃料的烹饪方法

| 方法 | 燃料 | 步骤 |
|---|:---:|---|
| 掰半鹰嘴豆粥 | 极少 | 不用浸泡，20-30分钟即可煮软 |
| 高压烹煮 | 最少 | 将泡发的豆子加压15-20分钟 |
| 余热焖煮 | 极少 | 煮20分钟后关火，用稻草·稻壳箱或被子包裹焖3-4小时 |
| 炒鹰嘴豆 | 少 | 将泡发后晾干的豆子不放油炒制，可直接食用 |
| 鹰嘴豆粉 | 几乎不需要 | 炒后磨成粉，用水和成面团或冲泡食用 |
| 发芽 | 无需 | 发芽后即可在不加热的情况下食用 |

&nbsp;&nbsp;&nbsp;鹰嘴豆粉在灾害条件下尤为珍贵。炒熟磨成的粉，加水和成面团擀薄烙制就成了饼，冲水煮开就成了糊，裹在蔬菜外油煎就成了炸衣。印度的鹰嘴豆粉（besan）、中东法拉费的面糊，用的都是这种粉。在没有面粉的条件下，把鹰嘴豆粉掺入谷物粉中，能补全氨基酸组成，也能增强面团的黏性。不过因为脂肪含量为6%，粉放置几个月内就会出现哈喇味，所以应现磨现用。

&nbsp;&nbsp;&nbsp;余热焖煮对鹰嘴豆同样效果显著。只煮20分钟后放入保温箱，内部温度能维持在高位3小时以上，烹煮过程得以继续。用装满稻草或稻壳的木箱，或用厚被子把锅整个包起来，就是简易保温箱。对烹饪时间较长的鹰嘴豆而言，这种方法节省的燃料相当可观。

### 16-3. 发芽与发酵

| 方法 | 步骤 | 价值 |
|---|---|---|
| 发芽 | 浸泡8小时后沥水，用湿布覆盖2-3天，芽长到约1cm时收取 | 会新生成维生素C，植酸减少，更易消化 |
| 焯水凉拌 | 把发芽的豆子稍微焯水后凉拌 | 在冬季没有蔬菜时可获取绿色蔬食 |
| 发酵面糊 | 磨碎后放置一夜会发酵变酸 | 会膨胀变软，更易消化 |
| 鹰嘴豆大酱 | 煮熟捣碎发酵后浸入盐水中 | 是大豆不足时的替代方案 |

&nbsp;&nbsp;&nbsp;鹰嘴豆是很容易发芽的豆类。浸泡8小时后沥水，用湿布覆盖放置两三天，芽便能长到约1cm。这个过程中会新生成干豆所没有的维生素C，植酸和胰蛋白酶抑制剂减少，低聚糖分解，胀气也会减轻。在冬季没有新鲜蔬菜时，这种发芽是预防维生素C缺乏的廉价手段。不过发芽的鹰嘴豆也不能生吃，须稍微焯水或炒过再吃，因为仍残留着抑制剂。

## 17. 全年作业日程

| 月份 | 作业 | 要点 |
|---|---|---|
| 1月 | 贮藏检查、种子发芽试验、按品系整理种子 | 发芽慢，试验也需等待2周 |
| 2月 | 规划田块、翻堆肥、规划接种源土壤的准备 | 把排水好的位置分配给鹰嘴豆 |
| 3月 | 耕地、起垄、挖排水沟，下旬播种 | 排水沟决定了鹰嘴豆种植成败的一半 |
| 4月 | 完成播种（中旬前），防鸟 | 10天到半个月内不会有任何动静 |
| 5月 | 第1次除草、间苗 | 初期杂草管理决定产量，不浇水 |
| 6月 | 第2次除草、培土、开花、检查根瘤 | 挖根掰开根瘤确认是否呈红色 |
| 7月 | 荚果膨大、捕杀豆荚螟、监测褐斑病 | 连续降雨时不进入田间 |
| 8月 | 收获、悬挂晾干、脱粒 | 有降雨预报时不等完全成熟 |
| 9月 | 精选、干燥、贮藏、茎叶还田、整理留种 | 只焚烧染病的残体，其余覆盖还田 |
| 10月 | 贮藏检查、保存接种源土壤 | 单独挖取鹰嘴豆根系所在的土壤保存 |
| 11月 | 加工（去皮掰半）、制粉 | 只加工一两个月内要吃的量 |
| 12月 | 贮藏检查、培育芽菜、规划次年 | 冬季维生素C靠发芽获取 |

### 17-1. 不可忘记的五件事

| 项目 | 内容 |
|---|---|
| 确保种子 | 在韩国国内很难再买到的作物，留种是种植的前提 |
| 接种 | 需要专用菌，其他豆类地块的土没有用，须单独设置接种源区块 |
| 排水 | 在豆类中最不耐涝，不在积水的地块种植 |
| 初期不浇水 | 干燥条件会把根系逼向1m以下，这样的根系能挺过日后的干旱 |
| 轮作 | 3年以上，枯萎病会潜伏在土壤中等待 |
