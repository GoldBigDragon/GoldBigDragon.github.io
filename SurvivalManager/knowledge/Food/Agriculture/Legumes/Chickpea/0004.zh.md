## 5. 整地与施肥 — 氮素平衡与施肥

### 5-4. 固氮的陷阱

&nbsp;&nbsp;&nbsp;种豆能让土地变肥沃，这句话已成为农业常识，但它只对了一半。若不准确理解这一点，连续种植豆科作物多年的地块反而会日渐贫瘠。

&nbsp;&nbsp;&nbsp;我们用数字来算一算。鹰嘴豆长势良好时，每1,000㎡可收获180kg干籽粒。鹰嘴豆籽粒的蛋白质含量为17.8%，用蛋白质除以6.25即可得到含氮量。17.8 ÷ 6.25为2.85，也就是说籽粒重量中约2.9%是纯氮。180kg籽粒中含氮约5.1kg，换算成公顷则为51kg。

&nbsp;&nbsp;&nbsp;另一方面，鹰嘴豆根瘤所固定的氮，在接种成功时每公顷为60-100kg，接种失败则降到10kg以下。把流出与流入并排放在一起，情况如下。

| 项目 | 每公顷氮 | 方向 |
|---|---|---|
| 根瘤固定量（接种成功） | 60-100kg | 流入 |
| 根瘤固定量（接种失败） | 5-15kg | 流入 |
| 随籽粒运出 | 45-60kg | 流出 |
| 留在茎叶（茎和叶）中的氮 | 20-35kg | 还田则留下，焚烧或运走则流出 |
| 留在根和根瘤中的氮 | 10-15kg | 通常留在地里 |

&nbsp;&nbsp;&nbsp;从表中可以看出两点。第一，若接种成功，即便运出籽粒，氮仍有盈余，因为鹰嘴豆籽粒的蛋白质比例远低于大豆，运出量本身就少。第二，若接种失败，这一关系会完全逆转：固定量只有10kg，籽粒却运走了50kg，地块必然亏损。对鹰嘴豆而言，接种的重要性不仅关乎产量，也关乎地力的可持续性。

> **豆科作物之所以能养地，并非因为它固氮，而是因为它把固定下来的一部分氮储存在茎叶中、留在了田地里。一旦把这些茎叶运走，豆类就变成了耗地作物。**

| 原则 | 内容 |
|---|---|
| 茎叶务必还田 | 脱粒后剩下的茎叶和荚壳全部归还田地 |
| 不焚烧 | 焚烧会使氮以气体形式散失，只剩下钾和磷留在灰中 |
| 不挖出根系 | 根系深，拔起也费力，只割茎秆、留下根系才是正确做法 |
| 切成20-30cm覆盖地表 | 兼具覆盖和肥料的作用 |
| 务必做好接种 | 接种失败既是减产也是夺氮 |
| 若喂了牲畜，粪便要归还 | 若用茎叶喂了牲畜，务必把那些牲畜的粪肥施回这块地 |

### 5-5. 整地

| 项目 | 方法 | 灾害条件下 |
|---|---|---|
| 耕地 | 耕深20-30cm并整平 | 根系扎得深，深耕更有利 |
| 起垄 | 高度20cm以上 | 是防涝的关键，对鹰嘴豆而言是前提条件 |
| 排水沟 | 深30-50cm | 需考虑梅雨季，挖得深一些 |
| 酸度调节 | pH 6.0-8.0 | 适应幅度宽，不必急于处理 |
| 有机质 | 腐熟堆肥1,000-1,500kg/1,000㎡ | 作基肥施入 |

&nbsp;&nbsp;&nbsp;鹰嘴豆的pH适应幅度为5.5-8.6，范围较宽，因此施石灰的优先级低于其他豆类。只要地块不是严重酸性，不施石灰也能生长。不过一旦低于5.5，根瘤菌就无法存活，这时哪怕只是把贝壳或蛋壳烧过磨成粉施入，把pH提升一些也是值得的。

&nbsp;&nbsp;&nbsp;相应地，必须在排水上下功夫。深耕以开辟水往下渗的通道，起高垄，挖深排水沟。从选地阶段就挑选不积水的位置最为可靠；若是有坡度的地块，上部才是适合种鹰嘴豆的位置。

### 5-6. 施肥量

| 肥料 | 每1,000㎡ | 折合每㎡ | 备注 |
|---|---|---|---|
| 氮 | 0-2kg | 0-2g | 几乎不需要，施多了会抑制固氮 |
| 磷 | 20-40kg | 20-40g | 全部作基肥，是根系发育和开花的必需元素 |
| 钾 | 3-5kg | 3-5g | 全部作基肥 |
| 硫 | 10-20kg | 10-20g | 不足会使根瘤形成变差 |
| 堆肥 | 1,000-1,500kg | 1-1.5kg | 使用完全腐熟的堆肥 |

> **鹰嘴豆施肥中特殊的一点是硫。硫不足会导致根瘤无法正常形成，进而使固氮本身崩溃。这是在其他豆类中很少被提及的元素。**

&nbsp;&nbsp;&nbsp;之所以需要硫，是因为固氮酶和豆血红蛋白都要用到含硫氨基酸。不施化肥也有几条供硫途径：掺入畜粪的堆肥中含硫，十字花科作物的残体加入堆肥也能带入含硫化合物。把大蒜和洋葱皮、大白菜和萝卜的外叶、芥菜的茎之类单独收集起来掺入堆肥，是切实可行的办法。不过这些材料不能直接施入鹰嘴豆地，必须先在堆肥中腐熟后再施用。

&nbsp;&nbsp;&nbsp;20到40kg的磷是相当大的量，因为鹰嘴豆深根系的发育和固氮的能量代谢都需要磷。在没有化肥的条件下，从骨粉和鱼骨中获取磷实际上是唯一的途径。

### 5-7. 灾害时的替代肥料

| 替代资源 | 供给养分 | 用法 | 注意事项 |
|---|---|---|---|
| 骨粉 | 磷、钙 | 烧后磨碎掺入堆肥 | 是满足鹰嘴豆高磷需求的关键 |
| 鱼骨·鱼内脏 | 磷、氮、硫 | 埋入土中腐熟后使用 | 同时供给磷和硫 |
| 草木灰 | 钾、磷、钙 | 每㎡撒100-200g并混入土中 | 偏碱性，但鹰嘴豆能耐受到pH 8.6 |
| 腐熟堆肥 | 综合 | 每㎡施1-1.5kg作基肥 | 未充分腐熟会烧根并传播病害 |
| 十字花科残体堆肥 | 硫 | 将大蒜·洋葱皮、大白菜外叶掺入堆肥 | 务必腐熟后再施用 |
| 畜粪堆肥 | 综合、硫 | 充分腐熟后作基肥 | 作为供硫来源有价值 |
| 稀释尿液 | 氮、钾、硫 | 用水稀释10倍后浇入株间土壤 | 对鹰嘴豆只能用极少量，会抑制固氮 |
| 贝壳·蛋壳 | 钙 | 烧后磨碎撒施 | 仅用于强酸性土壤 |
| 落叶腐殖土 | 综合、有机质 | 混入土壤中 | 能改善保水性 |

## 6. 播种

### 6-1. 播种时期

| 栽培方式 | 播种时期 | 收获时期 | 备注 |
|---|---|---|---|
| 春季栽培（韩国标准） | 3月下旬-4月中旬 | 7月中旬-8月 | 霜期完全结束后 |
| 秋播 | 最好不要尝试 | - | 无法挺过韩国的冬寒 |

&nbsp;&nbsp;&nbsp;鹰嘴豆的播种期窗口很窄。播得太早，开花期会撞上5月偏凉的夜晚，花粉无法形成；播得太晚，灌浆期又会撞上梅雨，因褐斑病而毁掉。守住3月下旬到4月中旬这段区间，是最重要的决定。

> **播种时期决定着鹰嘴豆的收成。一旦错过3月下旬到4月中旬这个区间，当年收成的上限便已注定。**

&nbsp;&nbsp;&nbsp;在原产地，秋播越冬是常见的栽培方式，但在韩国，冬季严寒会超出鹰嘴豆的耐寒极限而导致失败。耐受轻霜和能够越冬是两回事。鹰嘴豆耐寒性为B，意思是能挺过春季的晚霜，而不是说能够越冬。

### 6-2. 种子准备

| 项目 | 方法 | 灾害条件下 |
|---|---|---|
| 筛选 | 剔除有斑点、变色、皱缩、虫孔的种子 | 褐斑病经种子传播，筛选就占了防治的一半 |
| 挑选粒径 | 挑选颗粒饱满、较重的种子使用 | 放入水中，浮起的剔除 |
| 温水消毒 | 浸入50-55℃温水中10-15分钟 | 杀死经种子传播的病原菌 |
| 拌草木灰 | 蘸裹细草木灰 | 有助消毒和干燥，并有驱避鸟虫的效果 |
| 根瘤接种 | 蘸裹种过鹰嘴豆的地块土壤 | 参见5-3节，不与消毒同时进行 |
| 浸种 | 最好不要进行 | 浸种会使种皮变软，在土中容易腐烂 |
| 发芽试验 | 用湿布包住20粒种子，放置2周后数发芽数 | 发芽慢，需等待2周 |

&nbsp;&nbsp;&nbsp;种子筛选对鹰嘴豆尤为重要。褐斑病附着在种子表面和种皮内侧，随之传到下一年。染病的种子表面会有褐色或黑色斑点，或者干瘪皱缩。哪怕只有一粒这样的种子，也能在次年让整片田地染病。在没有农药的条件下，筛选种子是最有力的防治手段，需要的只是明亮的光线、一双眼睛和时间。若再配合温水消毒，可以杀死相当一部分表面的病原菌。

### 6-3. 播种方法

| 项目 | 标准 | 理由 |
|---|---|---|
| 播种深度 | 3-5cm | 太深会使发芽更慢 |
| 每穴粒数 | 1-2粒 | 发芽慢，多播一粒作保险 |
| 行距 | 25-60cm | 分枝多，需留出充足间距 |
| 株距 | 20-25cm | |
| 播种量（迪西小粒种） | 2.5-4kg/1,000㎡ | 籽粒小，用量少 |
| 播种量（卡布里大粒种） | 8-12kg/1,000㎡ | 籽粒大，用量多 |
| 发芽期 | 10-14天 | 需要耐心等待 |

&nbsp;&nbsp;&nbsp;种植密度直接关系到通风。鹰嘴豆最主要的病害褐斑病，叶片潮湿的时间越长病情越重，密植会大幅提高风险。即使种子充足，也最好不要密植。行距留得宽一些以利通风，并让田块的长边顺应风向布置行列，都有帮助。

&nbsp;&nbsp;&nbsp;再次强调，播种后10天到半个月内不会有任何动静。这段时间里若土壤板结形成硬壳，幼芽便无法顶破出土。雨后如果土壤板结，可用耙子在播种行上轻轻划松。反之，若频繁浇水使土壤长期潮湿，种子则会腐烂。

## 7. 水分管理

| 时期 | 水分管理 | 理由 |
|---|---|---|
| 播种至发芽 | 避免土壤完全干透 | 发芽需10-14天 |
| 生长初期 | 不浇水 | 干燥条件会促使根系扎向1m以下 |
| 开花期至荚果膨大期 | 严重干旱时灌溉 | 此时期缺水对产量的影响最大 |
| 灌浆期 | 停止灌溉 | 过湿会导致落粒和品质下降 |
| 梅雨季 | 挖排水沟 | 是鹰嘴豆种植中最危险的阶段 |

> **鹰嘴豆的水分管理不是浇水的技术，而是忍耐的技术。初期频繁浇水会使根系变浅，而浅根经不起日后的干旱。**

&nbsp;&nbsp;&nbsp;这正是鹰嘴豆与其他作物根本不同之处。鹰嘴豆是为了在干旱土地上扎深根而进化的。若初期表层始终潮湿，植株便感受不到向深处扎根的必要，根系会长得又浅又散。等到夏季干旱来临，那样的浅根找不到水源，植株就会垮掉。让它在初期经受一定的干燥，结果反而是战胜干旱的办法。

| 症状 | 原因 | 应对 |
|---|---|---|
| 正午叶片合拢，傍晚舒展 | 这是鹰嘴豆正常的节水反应 | 保持现状 |
| 早晨叶片仍未舒展 | 严重干旱 | 灌溉 |
| 叶片从下部开始发黄枯萎 | 严重干旱或根瘤不良 | 挖根检查根瘤后再判断 |
| 大量落花 | 开花期干旱，或夜间气温10℃以下 | 灌溉；若因低温所致，则调整次年播种时间 |
| 下部叶片发黄，茎基部变褐腐软 | 过湿引起的根腐 | 挖排水沟；严重时拔除病株 |
| 叶片出现褐色斑点，茎秆折断 | 褐斑病，在持续降雨后出现 | 拔除病株并焚烧；若蔓延则考虑提前收获 |

&nbsp;&nbsp;&nbsp;鹰嘴豆叶片在正午合拢并非病态，而是正常现象。细小的叶片向上合拢、彼此相对，能减少受光面积、抑制蒸腾，到傍晚再重新舒展。这种动作正是鹰嘴豆仅靠250mm降水就能完成一个生长季的原因之一。如果早晨叶片仍然合拢，那才是真正缺水的信号。

&nbsp;&nbsp;&nbsp;覆盖在鹰嘴豆种植中要谨慎使用。虽然能减少地表蒸发、节约水分，但覆盖过厚使土壤长期潮湿，会增加褐斑病和根腐病。即便覆盖，也应尽量薄，并且梅雨季开始后最好撤去一部分以保证通风。
