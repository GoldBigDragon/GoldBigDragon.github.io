## 5. 整地与施肥 - 施肥

### 5-5. 整地

| 项目 | 方法 | 灾害情境下 |
|---|---|---|
| 翻耕 | 翻耕20-30cm深，并整平土地 | 用铁锹翻土，或用锄头刨起。无法整块翻耕时，只翻要播种的行 |
| 垄 | 高度20cm以上 | 这是预防渍害的关键。在水田种植时要30cm以上 |
| 排水沟 | 深度50-80cm | 水田栽培中，排水沟比垄更优先 |
| 酸度调节 | pH 6.0-6.5 | 在播种前3-4周提前进行 |
| 石灰 | 酸性土壤施熟石灰或白云石灰200kg/1,000㎡ | 灾害时，用烧过捣碎的贝壳、蛋壳或草木灰代替 |

&nbsp;&nbsp;&nbsp;之所以要提前施石灰，是因为它的反应需要时间。临近播种时才施，会使局部碱性过强，伤害种子和幼根，而到真正需要的时候，反应又还没有充分进行。此外，如果把石灰和氮肥施在同一处，氨会变成气体挥发，造成氮素损失。要遵守先施石灰、两周后再施肥的顺序。没有石灰时，可以用贝壳和蛋壳。两者都是碳酸钙，原理相同，但直接使用反应非常慢，所以要用火烧到易碎，再放进臼中捣成粉末使用。草木灰同样呈碱性，但主要成分是钾，补充钙的效果不如石灰。

### 5-6. 施肥量

| 肥料 | 以1,000㎡计 | 折合每㎡ | 备注 |
|---|---|---|---|
| 氮 | 3kg | 3g | 只施最低量。仅作根瘤开始工作之前的初期用肥 |
| 磷 | 3.4kg | 3.4g | 全部作基肥。固氮的能量代谢需要磷 |
| 钾 | 3.4kg | 3.4g | 全部作基肥。参与籽粒膨大 |
| 堆肥 | 1,000kg | 1kg | 使用完全腐熟的 |
| 石灰 | 200kg（酸性土壤） | 200g | 播种前3-4周 |

&nbsp;&nbsp;&nbsp;氮3kg，与其他作物相比少得惊人。相比玉米施20kg以上，只有其1/7左右。这就是大豆在“施肥需求”项目中获得SS的原因，同时也是必须守住的上限。氮再多施，会出现两种情况。第一，根瘤形成减少。土壤中氮充足时，植物就会中止拿出糖来换取氮的交易。第二，只有茎叶茂盛，结荚减少。这叫徒长，徒长的大豆容易倒伏，通风变差，病害增多。

> **对大豆来说，少施氮不是节省，而是技术。施得多，产量必然下降。**

&nbsp;&nbsp;&nbsp;原则上不需要追肥。不过，如果开花后10天左右叶片整体呈淡黄色、生长明显不良，就说明根瘤没有正常工作。只在这个时候补充少量氮。常规栽培使用尿素4-6kg，灾害情境下，稀释尿液是最便捷的替代办法。

### 5-7. 灾害情境下的替代肥料

| 替代资源 | 提供的养分 | 使用方法 | 注意 |
|---|---|---|---|
| 草木灰 | 钾、磷、钙 | 每㎡撒100-200g并混匀 | 呈碱性，施多了pH会超过7 |
| 腐熟堆肥 | 多种养分 | 每㎡施1kg作基肥 | 未腐熟的会烧根并传播病害 |
| 稀释尿液 | 氮、钾 | 用水稀释10倍，浇在植株间的土上 | 避免沾到叶片。对大豆只用少量 |
| 骨粉 | 磷、钙 | 烧过后捣碎，混入堆肥 | 见效缓慢 |
| 鱼骨·鱼内脏 | 磷、氮 | 埋入土中使其腐化后使用 | 直接埋的话会被野兽刨出来 |
| 贝壳·蛋壳 | 钙 | 烧后捣碎撒施 | 用来代替石灰。反应慢 |
| 落叶腐殖土 | 多种养分、有机质 | 混入土中 | 改善保水能力 |
| 稻壳·稻草 | 钾、硅 | 作覆盖物铺盖，次年翻入土中 | 把没腐熟的翻入土中会抢走土壤中的氮 |
| 豆科绿肥 | 氮 | 种豇豆或毛叶苕子后翻入土中 | 不宜作大豆田的前茬，因为会积累病害 |

&nbsp;&nbsp;&nbsp;大豆施肥中真正重要的不是氮，而是磷和钾。磷是固氮能量代谢的关键元素，因此在缺磷的田里，即使形成了根瘤，固氮量也会下降。钾与籽粒膨大和茎秆强度有关，缺钾时叶缘会变褐枯干，倒伏增多。没有化肥时，磷从骨粉和鱼骨中获取，钾从草木灰中获取，是最现实的途径。

&nbsp;&nbsp;&nbsp;使用草木灰时要注意几点。往大豆田里撒灰，pH升高，对根瘤菌来说是有利条件，但过量时pH会超过7，阻碍铁、锌、锰的吸收。如果出现叶脉间发黄的症状，就是偏碱的信号，要停止施灰。每㎡100-200g是上限。硼也值得记住。大豆对硼有需求，缺硼时花会脱落，豆荚结不上。没有化学硼砂时，把蔬菜残渣、果皮和落叶一起沤成的堆肥是最现实的替代办法。只用一种材料沤成的堆肥，微量元素不均衡。

## 6. 播种

### 6-1. 播种时期

| 地区·作型 | 适宜播种期 | 播种极限期 | 收获时期 |
|---|---|---|---|
| 韩国中部 一年一熟 | 5月上旬-6月上旬 | 6月下旬 | 10月上中旬 |
| 韩国中部 一年两熟（水田复种） | 6月中下旬 | 7月上旬 | 10月下旬 |
| 韩国南部 一年一熟 | 6月上中旬 | 7月中旬 | 10月中下旬 |
| 韩国南部 一年两熟 | 6月下旬-7月上旬 | 7月下旬 | 10月下旬-11月 |

&nbsp;&nbsp;&nbsp;大豆的播种时期之所以分得这么细，是因为光周期反应。大豆是以白天变短为信号开花的短日照植物，夏至过后白天开始变短，就开始为开花做准备。播得太早，开花前的营养生长期会变长，结果只长个子并倒伏；播得太晚，还没长够就收到开花信号，以弱小的植株开花，产量就会偏低。

> **7月中下旬以后播种的大豆，产量会大幅下降。能播种的日子比想象中短，一旦错过这个窗口期，就只是白白损失种子。**

&nbsp;&nbsp;&nbsp;在适期内每隔2周分两三次播种，花期就会分散，酷暑或干旱就不能一下子把全部收成夺走。这样还有分散劳动的好处。大豆是播种和收获都很费工的作物，一次种下去就得一次收完，在人手不足的情况下，这会让人难以承受。

### 6-2. 种子准备

| 项目 | 方法 | 灾害情境下 |
|---|---|---|
| 筛选 | 剔除有斑点、变色、皱缩、虫眼的种子 | 用手一粒一粒挑选。这是最便宜、效果最大的一项工作 |
| 按大小筛选 | 挑选粒大而重的籽粒使用 | 放入水中，捞掉浮起来的 |
| 温水消毒 | 在50-55℃的水中浸泡10-15分钟，杀死表面病原菌 | 温度过高会降低发芽力。用手探入水中，以感觉烫手的程度为准 |
| 草木灰处理 | 给种子裹上细草木灰 | 有助于消毒和干燥，还有驱避鸟虫的作用 |
| 根瘤接种 | 用种过大豆的田土拌种 | 参见5-3节。不与消毒同时进行 |
| 发芽试验 | 用湿布包20粒种子，放几天，数出芽的粒数 | 陈种子一定要先检验 |

&nbsp;&nbsp;&nbsp;筛选最为重要。大豆的主要病害中，相当一部分是通过种子传播的。感染紫斑病的种子表面有紫色斑纹，感染炭疽病的种子有黑点。这样的种子哪怕只有一粒，也会让第二年的一块田染上病。在没有农药的条件下，种子筛选是最有力的防治手段，需要的只是明亮的光线、一双眼睛和时间。

&nbsp;&nbsp;&nbsp;温水处理的控温有窍门。没有温度计的话，把手伸进去、难以忍受5秒的程度，就是50-55℃的范围。水量要取种子量的10倍以上，这样放入种子时水温才不会骤降。处理结束后立即用冷水冷却，晾干水分后播种。超过60℃会损伤发芽力，所以趁热久放是最危险的。

### 6-3. 播种方法

| 项目 | 标准 | 理由 |
|---|---|---|
| 播种深度 | 3-5cm | 2cm以内的浅度容易干，鸟会啄食；超过7cm则出不了土 |
| 每穴粒数 | 2-3粒 | 考虑到发芽率。之后留2株，其余间掉 |
| 行距 | 60-80cm | 保证通风和管理通道 |
| 株距 | 15-20cm（一年一熟），10-15cm（一年两熟） | 播得越晚，种得越密 |
| 播种量（小粒） | 3-4kg/1,000㎡ | |
| 播种量（中粒） | 5-6kg/1,000㎡ | |
| 播种量（大粒） | 6-7kg/1,000㎡ | |

| 播种时期 | 株行距 |
|---|---|
| 6月上旬 | 70-80cm × 20cm |
| 6月中旬 | 70-80cm × 15-20cm |
| 6月下旬 | 60-70cm × 15cm |

&nbsp;&nbsp;&nbsp;播得越晚种得越密，是因为单株长得小。6月下旬播种的大豆植株体型小，如果间距相同，土地就会有富余。个体变小多少，就把株数增加多少，以维持单位面积的产量。

&nbsp;&nbsp;&nbsp;播种后紧接着的最大威胁是鸟。鸽子、喜鹊和野鸡会啄食刚发芽的大豆子叶，而大豆的养分贮存在子叶里，失去子叶，这棵苗通常就会死亡。可以在播种行上薄薄盖一层树枝或稻草，或者在出苗前罩上网或旧纱窗，或者把闪光的绳子交错拉起来。最可靠的办法，是在出苗初期的10天里，早晚都到田里巡视。

## 7. 水分管理

| 时期 | 水分管理 | 理由 |
|---|---|---|
| 播种至发芽 | 不要让土壤完全干透 | 大豆种子要吸收相当于自身重量的水分才能发芽 |
| 生长初期 | 听凭自然降水 | 这一时期的干燥反而能让根扎得更深 |
| 开花期至豆荚膨大期 | 充分浇水，不让土壤干 | 全生育期所需水分的80%在这一时期用掉 |
| 灌浆成熟期 | 减少水分 | 过湿会使豆荚干不透 |
| 成熟期 | 停止灌溉 | 继续灌溉会造成落粒和过早落叶 |

&nbsp;&nbsp;&nbsp;分清缺水与水分过多的症状很重要。两者都会让叶片萎蔫，但原因相反，所以采取的措施也相反。

| 症状 | 原因 | 措施 |
|---|---|---|
| 中午叶片下垂，傍晚恢复 | 暂时性缺水。属正常范围 | 不用处理 |
| 早晨叶片仍然下垂 | 根系吸不上水 | 充分浇水 |
| 叶片向内卷曲，颜色变深 | 严重干旱 | 立即灌溉 |
| 大量落花 | 花期干旱或高温 | 灌溉的同时，用覆盖降低地温 |
| 豆荚已结出但籽粒小 | 豆荚膨大期缺水 | 这一时期的灌溉直接决定产量 |
| 下部叶片发黄，根发黑 | 过湿造成根系受损 | 疏通排水沟，培土增高 |
| 叶片整体淡黄但不萎蔫 | 根瘤不工作，缺氮 | 挖出根，检查根瘤 |

&nbsp;&nbsp;&nbsp;在水源紧缺的条件下，灌溉策略是有所取舍、集中用水。想在整个生育期均匀浇水，反而在任何时期都不够。前期忍一忍，从开花开始到豆荚鼓起的4周内集中供水，用同样的水能收获多得多的大豆。与其少量多次地浇，不如一次浇到土壤湿透20cm深，再拉开到下次灌溉的间隔，这样能让根扎得更深，更为有利。

&nbsp;&nbsp;&nbsp;覆盖是节水最便宜的手段。没有塑料薄膜也不要紧，用稻草、稻壳、落叶、割下的杂草、锯末覆盖5-10cm厚，地表蒸发就能减少一半以上，地温波动也会缓和。大豆怕花期高温，所以同时还能获得降低地温的效果。不过在韩国的梅雨季（6月下旬至7月），把覆盖物掀开一部分以保证通风，更有利于预防病害。

## 8. 栽培管理

### 8-1. 间苗与除草

| 作业 | 时期 | 方法 |
|---|---|---|
| 间苗 | 1-2片真叶时 | 每穴留2株，拔掉弱苗 |
| 第一次除草 | 播种后2-3周 | 浅浅地耙一遍，注意不要伤到根 |
| 第二次除草 | 播种后5-6周 | 与培土结合进行 |
| 第三次除草 | 开花前 | 此后不再进入田里 |

&nbsp;&nbsp;&nbsp;在大豆上，杂草造成的损失比想象的要大。在Oerke的资料中，无防治时60%的潜在损失里，有37%是杂草造成的。这意味着杂草比病虫害是更大的威胁。大豆叶片相互接触、盖住地面之后，杂草就不会再大量增加，所以只需在最初的1个月里勤于除草。

&nbsp;&nbsp;&nbsp;开花以后原则上不要进入田里。人一走动，花就会掉落；在露水未干的早晨来回走动，病害会传遍整块田。最好在开花前清理杂草，并用覆盖物盖好。

### 8-2. 培土

| 时期 | 方法 | 效果 |
|---|---|---|
| 播种后30-40天，培到第一片真叶的节位 | 把土耙拢到植株基部 | 防倒伏、促进根系发育、改善排水、掩埋杂草 |

&nbsp;&nbsp;&nbsp;培土是大豆栽培中效率最高的一次作业。它同时带来四件好处：茎基部被土埋住，有了支撑，倒伏减少；被埋的茎上长出新根，吸收面积增大；植株间的沟变深，排水顺畅；在此过程中，幼小的杂草被埋进土里。培到第一片真叶的节位为宜，再往高处埋，下部的豆荚就会碰到土壤而腐烂。

### 8-3. 摘心

| 时期 | 方法 | 效果 |
|---|---|---|
| 5-7片真叶时，务必在开花之前 | 用手掐掉茎顶端的生长点 | 侧枝增多，豆荚数量增加 |

> **开花之后再摘心，反而会减产。因为开花后的生长点已不再是让植株长高的部位，而是新豆荚着生的位置。**

&nbsp;&nbsp;&nbsp;摘心并非在所有情况下都有益。在肥料充足、雨水多、容易徒长的条件下效果显著；但在贫瘠的田里，对已经生长不良的大豆摘心，由于没有恢复的力量，产量会更低。巡视田块时，如果植株长过了膝盖、叶色浓绿、节间拉开，就摘心；如果停留在小腿高度、叶色淡，就保持原样。

### 8-4. 倒伏管理

| 原因 | 对策 |
|---|---|
| 氮过量 | 遵守施肥量。这是根本 |
| 过度密植 | 遵守株行距 |
| 没有培土 | 在30-40天时务必培土 |
| 台风·暴雨 | 在田块四周拉绳支撑 |
| 高秆品种 | 选择抗倒伏品种 |

&nbsp;&nbsp;&nbsp;倒伏的大豆，收获用工成倍增加，贴地的豆荚会腐烂，通风受阻，病害也会蔓延。已经倒伏的话，不要硬去扶正，原样放着反而更好，因为扶正的过程中会拉断根、碰落豆荚。不过，完全趴在地上的部分，可以垫上树枝稍微架起一点，以减少腐烂。在田块四周打桩、在齐腰高度围绳扎紧的办法，如果在台风预报发布前提前做好，效果很大。

## 9. 病虫害

&nbsp;&nbsp;&nbsp;大豆的病虫害压力为A。无防治减产率估计为23%，属于较低水平，不像马铃薯疫病那样让整块田颗粒无收的灾难，在大豆上很少见。大豆病害有很多是通过种子传播的，这也意味着，不用药剂也有很大的应对余地。

### 9-1. 主要病害

| 病名 | 症状 | 发生条件 | 不用药的应对办法 |
|---|---|---|---|
| 大豆花叶病 | 叶片出现花叶斑驳并皱缩。籽粒上出现褐色斑点 | 由蚜虫传播 | 无法治疗。发现后立即拔除烧毁，并减少蚜虫。有斑点的种子不能留作种用 |
| 火烧病（细菌性斑点病） | 叶片上出现带棱角的褐色斑点，周围有黄色晕圈 | 细菌。借风雨传播 | 喷洒波尔多液。雨后不要立即进入田里 |
| 炭疽病 | 茎和豆荚上出现黑色溃疡斑 | 真菌。高湿 | 种子筛选和轮作是关键。用波尔多液辅助 |
| 紫斑病 | 籽粒表面出现紫色斑纹 | 真菌。种子传播 | 彻底挑出有斑纹的种子。温水消毒有效 |
| 霜霉病 | 叶片正面出现黄色斑点，背面出现灰白色霉层 | 高湿与密植 | 保证株行距、排水、波尔多液 |
| 菌核病 | 茎变软腐烂，长出白色棉絮状菌丝和黑色颗粒 | 冷凉潮湿的条件 | 4年以上轮作。病株连土挖出烧毁 |
| 褐斑病 | 从下部叶片开始出现褐色斑点，并提前落叶 | 梅雨季后期 | 保证通风、清除残茬 |
| 根腐病 | 下部叶片变黄，根部变褐腐烂 | 过湿、连作 | 排水、增高垄、轮作 |
| 大豆根腐线虫 | 生长不良，根上出现瘤状变形 | 砂质土、连作 | 与万寿菊间作、轮作 |
