## 3. 栽培環境

### 3-1. 気温と光量

| 条件 | 限界値 | 最適値 | 外れたとき |
|---|---|---|---|
| 発芽温度 | 10℃以上 | 25-30℃ | 10℃以下では発芽がほぼ止まり、種子が腐ります |
| 生育温度 | 15-35℃ | 20-25℃ | 15℃以下で生長が止まり、35℃を超えると花が落ちます |
| 結実温度 | 18-32℃ | 20-30℃ | 幅10℃の狭い範囲です |
| 開花期の高温 | 35℃以上が数日 | - | 花と若いさやがそのまま落ちます |
| 積算温度 | 2,500℃以上 | 2,500-3,000℃ | 不足すると、登熟が終わる前に霜が降ります |
| 霜 | 氷点下になると枯死 | - | 耐寒性がありません。初霜の前に収穫を終えます |
| 日照 | 1日6時間以上 | 1日8時間以上 | 40%遮光で収量が半分に落ちます |
| 日長 | 短日植物 | 昼が短くなると開花 | 夜に光が当たる場所は開花が遅れます |

&nbsp;&nbsp;&nbsp;ダイズにとって最も狭い関門は結実温度です。20-30℃、幅はわずか10℃しかありません。これより低いとさやがつかず、高いとすでについた花が落ちます。韓国の夏に35℃を超える日が数日続くと、その時期に咲いた花はたいてい無駄になります。ダイズが咲いた花の半分以上を落とすのは正常な生理現象ですが、高温と乾燥が重なると落花率が80%を超えることもあります。

&nbsp;&nbsp;&nbsp;この弱点への現実的な対応は、播種期を分けることです。一度にすべてを播かず、2週間間隔で2回か3回に分けて播くと、開花期が分散します。そのうちの1回は猛暑の時期を外れます。種子が十分にない状況でも、この戦略は有効です。1年分の収穫のすべてを一つの気候条件に賭けないことが、災害に備える栽培の基本原則です。

### 3-2. 土壌と水

| 条件 | 限界値 | 最適値 | 備考 |
|---|---|---|---|
| 土性 | 粘質土から砂質土まで | 排水のよい砂壌土-壌土 | 水はけの悪い土地が最も不向きです |
| pH | 5.5-7.5 | 6.0-6.5 | 酸性土壌では根粒の形成が大きく減ります |
| 有効土層の深さ | 30cm以上 | 50cm以上 | 主根が深く入ります |
| 作期の蒸発散量 | - | 450-700mm | 豆類の中では水をよく使うほうです |
| 浸水 | 2日以上水に浸かると枯死 | - | 根粒が先に死にます |
| 地下水位 | 50cm以深 | 80cm以深 | 水田に播くときに最も重要な条件です |

> **ダイズのpH要求は、植物自体というより根粒菌の要求です。pH 5.5を下回ると、ダイズはどうにか育ちますが、細菌が生きられず窒素固定が止まります。**

&nbsp;&nbsp;&nbsp;土壌の酸度がダイズで特に重要な理由はここにあります。根粒菌（Bradyrhizobium japonicum）は、酸性土壌では生存率と感染力が急激に落ちます。pH 5.0の畑にダイズを播くと、見かけ上は育ちますが、根を掘ってみると根粒がほとんどなく、葉は淡い黄色を帯びています。窒素を自分でつくれず、飢えている状態です。韓国の畑は降雨が多く、おおむね酸性に傾いているため、ダイズ畑では石灰の施用が肥料よりも先に行うべき作業です。

&nbsp;&nbsp;&nbsp;湿害に弱いことも強調しておかなければなりません。根粒菌は酸素を必要とする好気性細菌です。畑が水に浸かると土の中の酸素がなくなり、根より先に根粒が機能を失います。2日間水に浸かった豆畑は、水が引いた後も葉が黄色くなりますが、これは根が傷んだからだけでなく、窒素の供給源が断たれたからでもあります。水田にダイズを播くときに、排水溝を50-80cmと深く掘り、畝を20cm以上高くするのは、選択ではなく必須です。

## 4. 品種

### 4-1. 熟期による分類

| 区分 | 生育日数 | 播種時期（韓国） | 収穫時期（韓国） | 特徴 |
|---|---|---|---|---|
| 早生種（オルコン、夏ダイズ） | 100-120日 | 4-5月 | 7-8月 | 早く収穫できます。収量は少なめです |
| 中生種 | 120-140日 | 5月下旬-6月上旬 | 10月上中旬 | バランスが取れています |
| 中晩生種（秋ダイズ） | 140-180日 | 5月下旬-6月下旬 | 10月下旬-11月 | 収量が最も多くなります。霜の危険があります |

&nbsp;&nbsp;&nbsp;災害時には、熟期の選択はリスク分散の問題です。早生種は7月か8月に食べ物をもたらしてくれます。古い穀物が底をつき、秋の収穫がまだ遠いこの時期は、韓国で「ボリッコゲ（麦の峠）」と呼ばれる端境期にあたり、これを乗り切るうえで早生種のダイズが大きな役割を果たします。収量が少なくても、その時期に収穫できること自体に価値があります。逆に、中晩生種は全体の収量こそ多いものの、霜が早く来る年には登熟が終わりません。種子に余裕があれば、早生種と中晩生種に分けて播き、収穫期をずらしておくほうが安全です。

### 4-2. 用途による分類

| 用途 | 種子の大きさ | 特性 | 知られている品種 |
|---|---|---|---|
| 醤（ジャン）類・豆腐用 | 大粒種 | タンパク質が多く、収量が高いです | テプン2号、テチャン、ソンプン |
| 大豆もやし（コンナムル）用 | 小粒種 | 粒が小さく発芽がよく、もやしがまっすぐ伸びます | 小粒在来種の系統 |
| ご飯に混ぜる用 | 中粒-大粒 | ゆでたときに皮が柔らかく、甘みがあります | 黒豆の系統、ソリテ（青大豆系の黒豆） |
| 搾油用 | 中粒 | 脂肪含量が高いです | 油脂専用の系統 |
| 機械収穫用 | 中粒-大粒 | 最下位のさやが16cm以上の高さにつき、倒伏と裂莢に強いです | チョンジャ5号、テチョン |
| 災害への備え | 問わない | 自家採種ができる在来種が優先です | 地域の在来種 |

&nbsp;&nbsp;&nbsp;災害に備える観点では、品種選びの第一の基準は自家採種ができるかどうかです。交配による一代雑種（F1）品種は、翌年に播くと形質が分離して収量が崩れます。ダイズは幸い、栽培品種の大半が固定種で自家受粉のため、採った種子をそのまま播くことができますが、種子の袋に雑種と書かれている場合は、翌年を期待してはいけません。地域で長く栽培されてきた在来種は、収量が改良品種より少ない代わりに、その地域の気候や病害にすでに適応しており、種子を採って代々つなぐことができます。改良品種1種類に絞り込むよりも、在来種も一緒に確保しておくほうが、長期的には有利です。

&nbsp;&nbsp;&nbsp;第二の基準は、粒の大きさの配分です。大粒種だけを確保した場合、醤類や豆腐は仕込めても、大豆もやしはうまくできません。大粒種は発芽のときに力を大きく使うため、もやしが曲がって柔らかくなりやすいのです。小粒種を1種類、もやし専用として別にとっておくことが、冬の野菜不足を解決する核心的な手段であり、この話は第16節で詳しく扱います。

### 4-3. 状況別の選択基準

| 状況 | 優先順位 | 理由 |
|---|---|---|
| 醤類・豆腐をつくる必要がある | 大粒の中晩生種 | タンパク質が多く、収量が高いです |
| 冬の野菜がない | 小粒種を必ず一部 | もやし用です。ビタミンCの供給源になります |
| 初霜が早い地域 | 早生種または中生種 | 登熟を終えられないと、全量が実の入らない粒になります |
| 畑がやせている | 在来種 | 改良品種は肥料に反応するように育種されています |
| 労働力が足りない | 倒伏に強い品種 | 倒れたダイズは、収穫の労力が何倍にも増えます |
| 種子が足りない | 小粒種 | 同じ重さで、はるかに広い面積に播けます |

## 5. 畑の準備と肥料 - 根粒菌

### 5-1. 窒素固定はどのように起こるのか

&nbsp;&nbsp;&nbsp;空気の78%は窒素です。人の頭上に無限の窒素が漂っているのに、植物はそれを使えません。空気中の窒素は、窒素原子2個が三重結合で固く結ばれた分子（N2）で、この結合を切るには莫大なエネルギーが必要だからです。工業的にこの結合を切ってアンモニアをつくるのがハーバー・ボッシュ法で、世界の窒素肥料はここから生まれます。高温・高圧・触媒と、膨大な化石燃料を必要とする過程です。

&nbsp;&nbsp;&nbsp;根粒菌は、この仕事を常温・常圧でやってのけます。ニトロゲナーゼという酵素で三重結合を切り、窒素をアンモニアに変えます。ただし代償があります。この反応には多くのエネルギーが必要で、細菌は自分で光合成ができません。そこで、マメ科植物の根の中に入って暮らし、植物が光合成でつくった糖を受け取り、その見返りに固定した窒素を植物に渡します。取引の関係です。

| 段階 | 起こること |
|---|---|
| 1. シグナル交換 | ダイズの根がフラボノイドを分泌し、土の中の細菌がそのシグナルに応えてNod因子を出します |
| 2. 感染 | 根毛が内側に曲がって細菌を包み込み、細菌は感染糸に沿って根の内部に入ります |
| 3. 根粒の形成 | 根の内側の細胞が分裂して根粒がふくらみ、その中に細菌が住みつきます |
| 4. 窒素固定 | 根粒の中でニトロゲナーゼが働き、空気中の窒素をアンモニアに変えます |
| 5. 分配 | アンモニアがアミノ酸に変わり、茎・葉・さやへ運ばれます |
| 6. 老化 | 登熟期に入ると根粒が機能を失い、根とともに土に還ります |

&nbsp;&nbsp;&nbsp;ニトロゲナーゼは酸素に非常に弱く、酸素に触れるとすぐに機能を失います。そのため、根粒の内側にはレグヘモグロビンという赤い色素タンパク質が詰まっていて、酸素を捕まえておき、酵素の周囲の酸素濃度を極端に低く保っています。人の血が赤いのと同じ原理で、根粒を割ったときに内側が赤色やピンク色をしているのが、まさにこの色素です。この事実は実用上、きわめて重要です。赤い色は、その根粒がいま窒素を固定していることを示す、目に見える証拠だからです。

### 5-2. 根粒ができたかどうかを確認する方法

&nbsp;&nbsp;&nbsp;接種をしたかどうかにかかわらず、根粒が実際にできているかを確認する作業は必ず行わなければなりません。確認しなければ窒素不足の原因が分からず、翌年にも同じ失敗を繰り返すことになります。

| 順序 | 内容 |
|---|---|
| 1 | 開花が始まる頃、播種後6-8週ごろが最適の時期です |
| 2 | 健康そうな株を2、3株選びます |
| 3 | 引き抜かず、スコップで株の周りを広めに掘り、土ごと持ち上げます。引き抜くと、細根の根粒が土に残ってしまいます |
| 4 | 水を張った桶に入れ、土をそっと洗い落とします |
| 5 | 主根と太い側根についた根粒の数を数えます |
| 6 | 根粒を数個、爪で割って内側の色を見ます |

| 観察結果 | 意味 | 対処 |
|---|---|---|
| 根粒が株あたり20個以上、特に主根の上部に集まっている | 接種がうまくいっています | そのままにします |
| 割った内側が赤色またはピンク色 | 窒素を固定しています | 良好な状態です |
| 割った内側が白色または淡い緑色 | 根粒はできていますが、固定していません | 酸度、湿害、リン酸欠乏を確認します |
| 割った内側が茶色または黒色 | すでに老化したか、死んでいます | 登熟期なら正常、開花期なら問題です |
| 根粒が5個以下 | 接種に失敗しています | 葉が黄色ければ窒素を補います |
| 根粒が細根の先にだけ小さく多数ついている | 土着菌に感染しましたが、効率は低いです | 翌年は接種源を変えます |

> **根を掘り上げ、根粒を割って赤い色を確かめる。この一つの習慣が、窒素肥料のない世界でダイズ栽培の成否を教えてくれる、最も確かなシグナルです。**

&nbsp;&nbsp;&nbsp;根粒のつく位置も手がかりになります。主根の上部、土の表面から10cm以内についた大きな根粒が、最も効率の高い根粒です。接種がうまくいったときにできる位置です。逆に、主根にはなく、細根の先にだけ小さな根粒が散らばっている場合は、土にもともといた土着菌が遅れて感染したケースが多いです。土着菌はダイズと長く共生してきた系統ではないため、固定効率が劣ります。

### 5-3. 接種源をどこで手に入れるか

&nbsp;&nbsp;&nbsp;市販の接種剤は、生きた細菌を泥炭や粘土に含ませて売っている製品です。災害時には手に入りません。しかし根粒菌は土にすむありふれた微生物で、ダイズを栽培していた畑の土がそのまま接種源になります。この事実は、災害への備えにおいてきわめて重要です。

| 方法 | 手順 | 効果 | 注意 |
|---|---|---|---|
| ダイズを栽培した畑の土をまぶす | 前年にダイズを栽培して根粒がよくできた畑から、表土5-15cmの深さの土をすくってきます。種子を水で軽く湿らせ、この土を均一にまぶしてから、すぐに播きます | 最も確実で、費用がかからない方法です | 病気のある畑の土は、病原菌も一緒に運びます |
| 土を畑にまく | 播種する条に、すくってきた土をまき、一緒にすき込みます | 種子にまぶすより量は多くかかりますが、菌が土に広がります | 土は10㎡あたりスコップ1杯程度が目安です |
| 根粒そのものを使う | 掘り取ったダイズの根から根粒を集めてつぶし、水に溶いて、その水に種子を浸してから引き上げます | 菌の密度が最も高くなります | 根粒を掘り取ったその日のうちに使わなければなりません。乾くと菌が死にます |
| ダイズの根の残さをすき込む | 収穫したダイズの根を掘り取らず、畑にそのまま残しておきます | 翌年まで菌が土に残ります | 最も手間のかからない維持方法です |
| 野生のツルマメの根 | 野原や畑のあぜに生えるツルマメの根から根粒を採取します | ダイズと同じ属なので、菌が通用します | 固定効率が栽培種用の系統より低いことがあります |

&nbsp;&nbsp;&nbsp;接種の際に必ず守るべきことがあります。根粒菌は、直射日光、乾燥、熱に非常に弱い細菌です。紫外線を数分浴びるとかなりの数が死に、乾燥するとさらに早く死にます。そのため、種子に土をまぶす作業は日陰で行い、まぶした種子は日なたに広げておかず、すぐに播きます。30分以内に播くのが望ましく、遅くとも数時間以内に終えます。土をまぶした種子を1日以上置いてから播くと、接種の効果はほとんどなくなります。

&nbsp;&nbsp;&nbsp;もう一つ、種子消毒と接種は同時に行えません。殺菌剤を付けた種子に土をまぶすと、細菌が死にます。温湯処理で消毒した場合は、完全に冷ましてから接種します。病害が心配な種子であれば、消毒を選び、接種は土に直接まく方式で分けて行うのが合理的です。

| 接種失敗を招く条件 | 理由 |
|---|---|
| 土壌pH 5.5以下 | 細菌が生きられません |
| 窒素肥料を多めに施した畑 | 植物が取引の必要を感じず、自ら根粒の形成を減らします |
| 水がたまる畑 | 好気性細菌なので、酸素がないと死にます |
| リン酸が不足した畑 | 窒素固定には多くのエネルギーが必要で、そのエネルギー代謝にリン酸が使われます |
| モリブデン・鉄・コバルトの欠乏 | ニトロゲナーゼの構成成分です |
| 接種した種子を日なたで乾かす | 紫外線と乾燥で菌が死にます |
| 殺菌剤処理をした種子に接種する | 細菌が死にます |
| マメ科を長く栽培していなかった畑 | 土着菌がほとんどおらず、接種が必須です |

### 5-4. 窒素固定の落とし穴

&nbsp;&nbsp;&nbsp;ダイズを植えると土地がよくなるという話は、農業の常識として定着しています。半分は正しく、半分は誤りです。この点を正確に理解していないと、ダイズを何年も続けて栽培した畑がかえってやせていく事態になります。

&nbsp;&nbsp;&nbsp;数字で確かめてみましょう。ダイズがよく育てば、1,000㎡から250kgの子実が収穫できます。ダイズ子実のタンパク質は38%で、タンパク質を6.25で割ると窒素量が出ます。38 ÷ 6.25は6.08、つまり子実重の約6%が純粋な窒素です。250kgに含まれる窒素は約15kgです。ヘクタールに換算すると150kgに達します。

&nbsp;&nbsp;&nbsp;一方、根粒が固定する窒素は、条件がよいときでヘクタールあたり100-150kgです。接種がうまくいき、酸度が合い、水分も適切だったときの上限値です。条件が悪ければ50kgにとどまります。出ていくものと入ってくるものを並べると、次のようになります。

| 項目 | ヘクタールあたり窒素 | 方向 |
|---|---|---|
| 根粒の固定量（条件良好） | 100-150kg | 入る |
| 根粒の固定量（条件不良） | 30-60kg | 入る |
| 子実として持ち出し | 130-160kg | 出る |
| 茎葉（茎と葉）に残る窒素 | 25-40kg | 戻せば残る、焼いたり運び出したりすれば出る |
| 根と根粒に残る窒素 | 10-20kg | たいてい畑に残ります |

&nbsp;&nbsp;&nbsp;表を見れば分かります。子実だけを収穫して持ち出し、茎と葉を畑に戻せば、固定量と持ち出し量はほぼ釣り合うか、わずかに残る程度です。しかし、豆がらまで刈り取って薪として使ったり、焼き捨てたり、家畜の飼料として運び出したりすると、窒素収支は確実にマイナスに転じます。つまり、豆畑から出ていく窒素が、入ってくる窒素より多くなります。

> **ダイズが土地を生き返らせるのは、窒素を固定するからではなく、固定した窒素の一部を茎と葉に蓄え、畑に残すからです。その茎と葉を運び出してしまえば、ダイズは土地から収奪する作物になります。**

&nbsp;&nbsp;&nbsp;もう一つ比較をしておきます。ダイズ子実は重量の約6%が窒素で、トウモロコシ子実は約1.4%です。同じ1kgの子実を畑の外へ持ち出すとき、ダイズが持ち去る窒素はトウモロコシの4.5倍に達します。ダイズをタンパク質の工場として使う代償は窒素の持ち出しであり、これは物理的に避けられない収支計算です。したがって、災害時のダイズ栽培の原則は明確です。

| 原則 | 内容 |
|---|---|
| 茎葉は必ず畑へ | 脱穀後に残った豆がらと葉、さやの殻をすべて畑に戻します |
| 焼かない | 焼くと窒素は気体となって飛んでいき、カリウムとリン酸だけが灰として残ります |
| 根は掘り取らない | 根と根粒の窒素は、最も手軽に残せる分です |
| 落ち葉をかき出さない | 登熟期に落ちる葉にも、窒素がかなりの量含まれています |
| 豆がらは切って覆う | 20-30cmに切って畑に敷くと、マルチングを兼ねた肥料になります |
| 家畜に食べさせたら糞を戻す | 豆がらを食べさせたのであれば、その家畜の糞尿を必ずその畑に入れます |

&nbsp;&nbsp;&nbsp;乾いた豆がらはよく燃えるので、薪として使いたいという誘惑が大きいものです。妥協点は、灰を必ずその畑に戻すことです。焼くと窒素は飛んでいきますが、カリウム、リン酸、カルシウムは灰に残ります。ただし、何年も続けて焼くと窒素収支が目に見えて悪化するため、ある年は焼き、ある年は覆うというように、交互に行うのがよいでしょう。
