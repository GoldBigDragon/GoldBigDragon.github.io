## 9. 病虫害 - 害虫与防治

### 9-2. 主要害虫

| 害虫 | 危害 | 不用药的防治 |
|---|---|---|
| 蝽类（点蜂缘蝽等） | 刺吸豆荚汁液，造成秕粒。是大豆的头号害虫 | 清晨有露水时它们行动迟缓，可以用手捉住放进水桶。在田块四周种植诱集作物，集中诱捕 |
| 蚜虫 | 吸食汁液并传播病毒病 | 把肥皂水（1L水加5g肥皂）喷在叶背。保护瓢虫和草蛉 |
| 大豆食心虫 | 幼虫钻进豆荚内啃食籽粒 | 通过早播早收避开发生期。清除残茬，消灭越冬场所 |
| 斜纹夜蛾 | 暴食叶片和豆荚 | 用手捉。发现卵块时连叶摘除 |
| 叶螨 | 在叶背吸食汁液，使叶片出现黄色斑驳 | 干燥时增多。用力向叶片喷水 |
| 鸟（鸽子·喜鹊·野鸡） | 播种后立即啄食子叶 | 出苗前用稻草或网覆盖 |
| 獐·狍 | 啃食嫩叶和茎 | 设置围栏或拉网 |

&nbsp;&nbsp;&nbsp;蝽是大豆最大的害虫。它们刺穿豆荚壳，吸食里面幼嫩的籽粒；从外表看豆荚正常，剥开来才发现籽粒干瘪，甚至根本没有。不用杀虫剂对付蝽的办法有三种。

| 方法 | 内容 | 效果 |
|---|---|---|
| 清晨捕杀 | 气温低的清晨，蝽飞不太动。翻找背阴处的豆荚下面，用手抖落到水桶里接住 | 最可靠。连续做几天，虫口数量会明显下降 |
| 诱集作物 | 在田块四周种植蝽更喜欢的作物（芝麻、粟、高粱）把它们引来，再在那里集中捕杀 | 减轻主田的危害 |
| 调整收获期 | 种早熟种，在蝽数量增加的晚夏之前完成灌浆成熟 | 属于回避策略。在选择品种的阶段就已决定 |

### 9-3. 不用药的防治材料

| 材料 | 制作方法 | 对象 | 注意 |
|---|---|---|---|
| 波尔多液 | 用100L水，把400g硫酸铜和400g生石灰分别溶解后再混合 | 细菌性病害、真菌性病害 | 必须有铜才能配制。混合后立即使用 |
| 肥皂水 | 1L水加5g无香肥皂 | 蚜虫、叶螨 | 中午炎热时喷洒会烧伤叶片 |
| 草木灰水 | 把1升（韩国传统计量单位，约1.8升）草木灰在10L水中浸泡一夜，取上层清液使用 | 抑制真菌、增强叶片 | 呈碱性，可能伤叶，要稀释使用 |
| 撒干灰 | 在有露水的早晨，把细灰撒在叶片上 | 软腐病、食叶害虫 | 下雨会被冲掉 |
| 木醋液 | 收集烧炭时产生的烟气，冷凝成液体，稀释300-500倍 | 驱避、促进生长 | 原液呈强酸性，务必稀释 |
| 烟叶浸出液 | 把干烟叶泡在水里，取浸出液使用 | 蚜虫、蛾类幼虫 | 对人也有毒性，收获前不要使用 |
| 辣椒·大蒜水 | 把辣椒和大蒜磨碎，泡水后过滤使用 | 驱避 | 药效持续时间不长，需要经常喷洒 |
| 牛奶稀释液 | 把牛奶用水稀释5-10倍 | 白粉病、叶螨 | 剩下的会变质发臭 |

### 9-4. 农业防治 - 最有力的手段

| 方法 | 原理 |
|---|---|
| 种子筛选 | 大豆病害有很大一部分通过种子传播。仅仅挑出有斑点和变色的种子，就能大大减少发病 |
| 轮作 | 病原菌没有寄主，就会在土壤中慢慢死亡。让豆科作物空出2-3年 |
| 调整播种期 | 错开害虫发生高峰与作物脆弱期，使两者不重合 |
| 保证株行距 | 通风好，叶片干得快，霉菌就站不住脚 |
| 排水 | 大豆病害的一半以上都与过湿有关 |
| 残茬处理 | 有病的残茬烧掉或深埋。只把健康的残茬还回田里 |
| 雨后禁止进田 | 人碰到湿叶片，病原菌就会被带着传开 |
| 抗性品种 | 在当地存活下来的地方品种，很可能已经适应了当地的病害 |

> **在没有药剂的条件下，防治的重心从喷洒转向回避。选种、轮作、排水、拉开株距，这四件事比任何喷药都更有效。**

&nbsp;&nbsp;&nbsp;区分有病残茬和健康残茬，是与第5节中氮素收支相冲突的地方。要保住氮，就得把茎叶还回田里，可是把有病的茎叶还田，病原菌就会留下。叶片上只有少量斑点的，可以切碎覆盖。得了茎变软腐烂的菌核病、出现黑色溃疡的炭疽病，以及花叶病的植株，要单独收集起来烧掉，或者拿到田外长时间沤烂。

## 10. 营养缺乏与过量

| 症状 | 原因 | 天然材料应对 |
|---|---|---|
| 从下部叶片开始整体呈淡黄色，植株矮小 | 缺氮。大豆上最常见的原因是根瘤不良 | 先挖出根，检查根瘤。如果没有根瘤，下一年要确保接种；当年则少量浇施稀释10倍的尿液 |
| 叶缘变褐枯干并向内卷曲 | 缺钾 | 把草木灰撒在株间，轻轻耙入土中 |
| 生长迟缓，叶片带紫红色 | 缺磷 | 骨粉、鱼骨烧成的粉、草木灰 |
| 开了花却不结荚 | 缺硼，或花期高温干旱 | 用多种材料混合沤制的堆肥。当年用灌溉和覆盖来降温 |
| 叶脉绿色而叶脉间发黄 | 缺铁或缺镁。在偏碱的土壤中常见 | 停止用灰。用腐殖土和充分腐熟的堆肥增加有机质 |
| 新叶小而畸形，生长点枯死 | 缺钙或缺硼 | 烧过的蛋壳粉、贝壳粉 |
| 只有叶片浓绿茂盛，豆荚少 | 氮过量 | 立即停止供氮。通过摘心促发侧枝 |
| 植株徒长而倒伏 | 氮过量或过度密植 | 培土并拉绳支撑。次年减少施肥量 |
| 下部叶片变黄，根部发褐 | 过湿造成根系受损 | 疏通排水沟。这不是肥料问题 |

&nbsp;&nbsp;&nbsp;看到大豆出现缺氮症状时，首先要做的不是施肥，而是把根挖出来看。大豆的氮素来源不是土壤，而是根瘤。如果根瘤长得很好、掰开里面是红色，叶子却发黄，那就不是氮的问题，而是别的问题。如果没有根瘤，或者里面是白色，那就是原因所在，但这种情况下，大量施氮也不能解决问题，因为土壤中的氮增加后，残存的根瘤也会降低功能。当年靠最低限度的氮撑过去，次年通过接种和酸度调节从根本上解决，才是正确的顺序。

&nbsp;&nbsp;&nbsp;微量元素缺乏很难逐一应对。没有化肥，实际上没有办法弄到钼或钴。不过，把蔬菜碎屑、果皮、蛋壳、鱼骨、落叶、杂草和草木灰混在一起沤成的堆肥，微量元素含量均衡。“什么都往堆肥场里放”这一原则，就是管理微量元素的现实策略。

## 11. 间作与轮作

### 11-1. 搭配宜忌

| 宜忌 | 作物 | 理由 |
|---|---|---|
| 适宜 | 玉米、高粱 | 能就近分得大豆固定的一部分氮。株高有差异，可以分享光照 |
| 适宜 | 万寿菊 | 根系分泌物能抑制线虫 |
| 适宜 | 马铃薯 | 病害互不重叠，养分需求也不同 |
| 适宜 | 结球甘蓝·大白菜类 | 种在大豆之后，可以利用残留的氮 |
| 一般 | 黄瓜·南瓜类 | 要保持距离，避免藤蔓盖住大豆 |
| 不宜 | 番茄·辣椒·茄子 | 在同一块田里会共有病虫害 |
| 不宜 | 大蒜·洋葱类 | 有报告称其分泌物会抑制根瘤菌 |
| 不宜 | 与其他豆科连作 | 病原菌和线虫会不断积累 |

&nbsp;&nbsp;&nbsp;玉米与大豆混种，是长期沿用的搭配。玉米利用上层的光，大豆利用下层的光；玉米需氮量大，大豆则自己制造氮。不过，大豆是遮光40%时产量就降到一半的作物，如果深处于玉米的荫蔽之下，产量会大幅下降。可以按玉米两行、大豆两行交替布置，并让玉米行呈南北走向，使阴影不会长时间停留在同一侧。如果像撒播一样把大豆塞在玉米之间，大豆几乎收不到。

&nbsp;&nbsp;&nbsp;与葱类的关系是有争议的地方。多处报告观察到，大蒜和洋葱中的含硫化合物会抑制根瘤菌的活动。虽然这还没有被确立为决定性的证据，但既然固氮是大豆栽培的核心机制，就没有必要冒险，所以要把它们分开布置。

### 11-2. 轮作

| 项目 | 标准 |
|---|---|
| 休作期间 | 1年以上。同一块田里不连续种植豆科作物 |
| 理想周期 | 3-4年 |
| 连作障碍 | 大豆在豆类中属于耐连作性稍好的作物，但线虫和根腐病会不断积累 |

&nbsp;&nbsp;&nbsp;大豆的连作适应性为S，在豆类中属于较好的，按韩国农村振兴厅的标准属于1年休作组。与红小豆需要3年、花生需要4年到5年相比，要宽裕一些。但这只是说能够忍受，并不是说可以连续种植。连作超过3年，大豆孢囊线虫和根腐病就会积累，导致产量下降。

| 4年轮作示例 |
|---|
| 第1年：大豆 |
| 第2年：叶菜类或葱类（利用大豆留下的氮） |
| 第3年：谷物或薯类（块茎/块根）（换成根系深度不同的作物，改变利用的土层） |
| 第4年：根菜或绿肥（让田地休养） |
| 再回到大豆 |

&nbsp;&nbsp;&nbsp;这里写下田地狭小、没有条件轮作时的折中办法。把田地分成四个区块，每年挪一块来种大豆，这是最简单的方式。如果是无法分区的小块田，至少要每年更换种大豆的行的位置。去年的大豆行今年种玉米，去年的玉米行今年种大豆，仅此一点，就能明显延缓线虫的积累。大豆之后，最适合种需氮量大的大白菜和结球甘蓝类，以及玉米。

## 12. 收获与脱粒

### 12-1. 判断收获时期

| 判断标准 | 内容 |
|---|---|
| 叶 | 叶片变黄，几乎全部脱落 |
| 豆荚 | 80%以上的豆荚已变成褐色 |
| 声音 | 在田里摇动，豆荚里会发出籽粒碰撞的声音 |
| 籽粒 | 咬下去咬不进去，会“啪”地裂开 |
| 水分 | 籽粒含水量13-15% |
| 时点 | 叶片落光后7-14天 |

| 地区 | 收获时期 |
|---|---|
| 韩国中部 | 10月上旬-中旬 |
| 韩国南部 | 10月中旬-下旬 |
| 酱曲（meju）用大豆的中晚熟种 | 10月下旬-11月中旬 |

&nbsp;&nbsp;&nbsp;错过收获时期，会在两个方向上造成损失。收得太早，籽粒不饱满、皱缩，贮藏中容易变质。收得太晚，豆荚干裂自行炸开，籽粒掉落到地上，这叫落粒，晚收时甚至会损失近3成。尤其是干豆荚淋雨后再晒干，如此反复，落粒会急剧增加。

> **一旦有下雨的消息，就不要等完全成熟，赶紧收割。稍微没熟透的大豆晒干后还能用，而掉到地上的大豆就收不回来了。**

### 12-2. 收获要点

| 步骤 | 内容 |
|---|---|
| 1 | 选择晴朗干燥的日子。露水干了的上午10点以后为宜 |
| 2 | 用镰刀从茎基部割下；若想保留根瘤，就只割茎、把根留在田里 |
| 3 | 在田里摊晾一到两天，进行预干燥。下雨就立即收回 |
| 4 | 扎成捆，竖着挂在屋檐下或棚屋里，完成最后的干燥 |
| 5 | 豆荚完全干透、摇动有声响时，进行脱粒 |

&nbsp;&nbsp;&nbsp;常规做法有时会连根拔起，但在灾害情境下，最好用镰刀只割茎、把根留在田里。根和根瘤中的氮达到每公顷10到20kg，这些根腐烂后，会成为下一茬作物可以利用的有机质。

### 12-3. 脱粒 - 不用工具的方法

| 方法 | 工具 | 步骤 | 效率 |
|---|---|---|---|
| 踩袋子 | 厚麻袋或布袋 | 把干豆秸装进袋子，扎紧袋口，用脚踩或用手搓 | 少量时最省事。籽粒不会蹦出去 |
| 连枷 | 在长柄上连着一根打棍的工具 | 铺开草席或布，把豆秸薄薄摊开，从上面敲打 | 适合中等规模。要翻两三次边翻边打 |
| 木棒敲打 | 木棒 | 装进袋子里，或摊在草席上敲打 | 没有连枷时用来代替。更费力 |
| 用脚搓 | 无 | 摊在草席上，穿着鞋用脚来回搓转 | 适合少量 |
| 在木板上摔打 | 木板或木桶 | 抓住一束豆秸，往木板内壁上摔打 | 籽粒会集中在桶里。损失少 |

&nbsp;&nbsp;&nbsp;脱粒成败取决于干燥程度。没干透的豆秸，怎么敲打豆荚也不裂开；干过头的大豆，敲打时籽粒会碎裂。用手一捏豆荚就“啪”地裂开的状态是最佳时机，在阳光好的午后进行会轻松得多。

&nbsp;&nbsp;&nbsp;踩袋子是小规模自给最合理的方法。不需要工具，籽粒不会四处蹦出，几乎没有损失，也不太费力。往厚麻袋里装半袋干豆秸，扎紧袋口，放在地上用脚均匀踩踏。踩10下左右，抖一抖袋子换个位置再踩，如此重复三四次，等豆秸被踩成碎段时就脱好了。

### 12-4. 清选 - 借风力分选

| 方法 | 原理 | 步骤 |
|---|---|---|
| 风选（扬风） | 籽粒重，壳和碎屑轻 | 在有风的日子，把豆子盛在簸箕或宽口容器里高高举起，慢慢倒下。籽粒直接落下，壳被吹走 |
| 簸扬 | 上下颠动，向前簸扬 | 重的籽粒留在后面，轻的被推向前面 |
| 扇风 | 一个人倒，一个人用扇子扇风 | 在没有风的日子使用 |
| 过筛 | 按孔眼大小分开 | 用粗筛筛掉豆秸碎片，用细筛漏掉泥土和小粒 |
| 水选 | 秕粒和虫蛀的籽粒较轻 | 倒进水桶，捞掉浮起来的。捞出的豆子必须重新晒干 |
| 斜板滚动 | 圆的籽粒容易滚动，碎屑会被卡住 | 把木板倾斜放置，让豆子滚落下来 |

&nbsp;&nbsp;&nbsp;风选是人类开始处理谷物时就在使用的方法，直到现在，也没有比它更简单的人工清选方法。要领有三点。第一，选择风力稳定的时间和位置。清晨或日落时分的风较好。第二，不要一股脑倒下，而要缓缓地细细流下。倒得粗，壳屑会混在籽粒之间一起落下。第三，重复两三次。

&nbsp;&nbsp;&nbsp;水选法同时完成清选和筛选。被豆象蛀食的籽粒内部是空的，会浮起来，秕粒也会浮起，所以这样挑出来后，贮藏损失会大大减少。不过，泡过水的大豆必须在当天摊薄，彻底重新晒干。湿着装起来放置，几天就会长霉。留种用的大豆不要用这个方法，因为一泡水，发芽的生理过程就启动了，在那种状态下晒干，发芽力会下降。

## 13. 留种

| 项目 | 方法 |
|---|---|
| 留种植株选择 | 在田里提前标记没有病症、结荚多且没有倒伏的植株 |
| 收获时期 | 豆荚完全变成褐色后再收。比食用大豆稍晚收获 |
| 分开 | 单独脱粒。不要与食用大豆混在一起 |
| 筛选 | 带斑点、皱缩、变色的和小粒的全部丢弃。只留下粒大而有光泽的 |
| 干燥 | 含水量12-13%。咬下去咬不进去，会“啪”地裂开 |
| 保存 | 装进密闭容器，放在阴凉黑暗处。与食用大豆用不同的容器 |
| 保存期限 | 常温密闭3年。发芽率逐年下降 |
| 更新 | 每3-4年从别处弄来种子，混入一部分 |

&nbsp;&nbsp;&nbsp;大豆是自花授粉作物，留种非常容易。即使与其他品种混种，性状也不会混杂，也不像玉米那样需要设置隔离距离。这意味着，即便种子公司和流通网络消失了，大豆自己也能一代代延续下去，“自家留种”项目的S等级就来源于此。

&nbsp;&nbsp;&nbsp;不过，连续留种好几年时有需要注意的地方。反复自家留种，种子传播的病害会悄悄积累。紫斑病、炭疽病和花叶病都会随种子传到下一代。把看得见的斑点挑出来，可以防住相当一部分，但没有表现出症状的潜伏侵染是筛不出来的。所以最好每3-4年从邻村或别的山谷里换来大豆，混入一部分。

&nbsp;&nbsp;&nbsp;提前在田里给留种用的大豆做标记，这个习惯会大大改变结果。收获后只看籽粒来挑选，选的只是大小和形状。而在田里挑选，则可以同时选择结荚数、抗倒伏性、抗病性、第一个豆荚的高度这些真正重要的性状。在花期和灌浆成熟期，给好的植株系上线，收获时只单独收这些植株，几年之后，就会形成一个逐渐适应这块田条件、一点点改进的品系。

| 种子保存期限与发芽率 |
|---|
| 收获当年：90%以上 |
| 经过1年：80-90% |
| 经过2年：60-80% |
| 经过3年：40-60% |
| 4年以后：急剧下降 |

&nbsp;&nbsp;&nbsp;大豆的种子寿命为A等级，常温密闭可保存3年。但第3年的发芽率会降到一半，所以应当每年留新种，陈种作为备用。陈种子务必先做发芽试验。发芽率为一半时，把播种量增加一倍来补偿；低于30%，就不要当种子，而是吃掉更好。
