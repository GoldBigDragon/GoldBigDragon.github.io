## 3. 栽培环境

### 3-1. 气温与光照

| 条件 | 临界值 | 最适值 | 超出范围时 |
|---|---|---|---|
| 发芽温度 | 10℃以上 | 25-30℃ | 10℃以下时发芽几乎停止，种子腐烂 |
| 生长温度 | 15-35℃ | 20-25℃ | 15℃以下生长停止，超过35℃花会脱落 |
| 结实温度 | 18-32℃ | 20-30℃ | 温度幅度仅10℃，范围很窄 |
| 花期高温 | 35℃以上持续数日 | - | 花和幼荚会直接脱落 |
| 积温 | 2,500℃以上 | 2,500-3,000℃ | 不足时，籽粒还没灌浆成熟就会降霜 |
| 霜 | 降至零下即死亡 | - | 不耐寒。要在初霜前完成收获 |
| 日照 | 每天6小时以上 | 每天8小时以上 | 遮光40%时产量降到一半 |
| 日长 | 短日照植物 | 白天变短时开花 | 夜间有光照的位置，开花会推迟 |

&nbsp;&nbsp;&nbsp;大豆最窄的一道关口是结实温度。20-30℃，温度幅度只有10℃。低于这个范围，豆荚结不上；高于这个范围，已经坐住的花会脱落。如果韩国的夏季连续几天超过35℃，那段时间开的花大多会白白浪费。大豆会脱落一半以上的花，这是正常的生理现象，但高温与干旱叠加时，落花率有时会超过80%。

&nbsp;&nbsp;&nbsp;应对这一弱点的切实办法是错开播种期。不要一次全部种完，而是每隔2周分两次或三次播种，花期就会分散开，其中有一批会避开酷暑时段。即使种子不太充足，这一策略同样有效。不把一年的收成全部押在同一种气候条件上，是灾害应对栽培的基本原则。

### 3-2. 土壤与水分

| 条件 | 临界值 | 最适值 | 备注 |
|---|---|---|---|
| 土壤质地 | 从黏质土到砂质土 | 排水良好的砂壤土-壤土 | 排水不良的土地最不适宜 |
| pH | 5.5-7.5 | 6.0-6.5 | 在酸性土壤中，根瘤形成大幅减少 |
| 有效土层厚度 | 30cm以上 | 50cm以上 | 主根扎得很深 |
| 生长期蒸散量 | - | 450-700mm | 在豆类中属于耗水较多的一类 |
| 淹水 | 淹没2天以上即死亡 | - | 根瘤首先死亡 |
| 地下水位 | 50cm以下 | 80cm以下 | 在水田种植时最重要的条件 |

> **大豆对pH的要求，与其说是植株本身的要求，不如说是根瘤菌的要求。pH低于5.5时，大豆还能勉强生长，但根瘤菌无法存活，固氮就会停止。**

&nbsp;&nbsp;&nbsp;这就是土壤酸度对大豆格外重要的原因。根瘤菌（Bradyrhizobium japonicum）在酸性土壤中，存活率和侵染力会急剧下降。在pH 5.0的田地里种大豆，表面上能长起来，但把根挖出来看，几乎没有根瘤，叶片呈淡黄色。这是因为植株无法自己制造氮素，正处于饥饿状态。韩国的旱地降雨多，土壤大多偏酸，所以在大豆田里，施石灰要排在施肥之前。

&nbsp;&nbsp;&nbsp;还必须强调大豆易受渍害的弱点。根瘤菌是需要氧气的好氧细菌。田地一旦被水淹没，土壤中的氧气就会消失，根瘤比根系更早丧失功能。被淹两天的豆田，即使水退之后叶片也会变黄，这不仅是因为根系受损，更是因为氮素来源被切断了。在水田种大豆时，把排水沟深挖到50-80cm、把垄起高20cm以上，不是可选项，而是必须做到的。

## 4. 品种

### 4-1. 按成熟期分类

| 类别 | 生育天数 | 播种时期（韩国） | 收获时期（韩国） | 特点 |
|---|---|---|---|---|
| 早熟种（早豆olkong、夏大豆） | 100-120天 | 4-5月 | 7-8月 | 收获早，产量较低 |
| 中熟种 | 120-140天 | 5月下旬-6月上旬 | 10月上中旬 | 各方面比较均衡 |
| 中晚熟种（秋大豆） | 140-180天 | 5月下旬-6月下旬 | 10月下旬-11月 | 产量最高，但有遭遇霜冻的风险 |

&nbsp;&nbsp;&nbsp;在灾害情境下，选择成熟期就是一个分散风险的问题。早熟种在7月或8月就能拿出可吃的粮食。陈粮耗尽、秋收尚远的这段时期，在韩国被称为“boritgogae”（青黄不接的时期），早熟种大豆在填补这段空档上发挥着重要作用。即使产量低，能在那个时期收获这一点本身就很有价值。反过来，中晚熟种总产量高，但在霜来得早的年份，籽粒来不及灌浆成熟。如果种子充足，把早熟种和中晚熟种分开播种，让收获期错开，会更稳妥。

### 4-2. 按用途分类

| 用途 | 种子大小 | 特性 | 代表品种 |
|---|---|---|---|
| 酱类·豆腐用 | 大粒种 | 蛋白质含量高，产量高 | Daepung 2号、Daechan、Seonpung |
| 黄豆芽用 | 小粒种 | 籽粒小，出芽好，豆芽挺直 | 小粒地方品种品系 |
| 掺入米饭用 | 中粒-大粒 | 煮熟后豆皮软，带甜味 | 黑豆品系、青仁黑豆（Seoritae） |
| 榨油用 | 中粒 | 脂肪含量高 | 专用油用品系 |
| 机械收获用 | 中粒-大粒 | 最低结荚高度在16cm以上，抗倒伏、抗裂荚 | Cheongja 5号、Taecheong |
| 灾害应对 | 不限 | 以可自家留种的地方品种为先 | 当地地方品种 |

&nbsp;&nbsp;&nbsp;从灾害应对的角度看，选择品种的第一条标准是能否自家留种。杂交一代（F1）品种，次年种下去性状会分离，产量随之崩塌。幸运的是，大豆的栽培品种大多是固定品种，又属自花授粉，收下的种子可以直接再种；但如果种子包装袋上标明是杂交种，就不要对下一年抱有期待。在当地长期栽培的地方品种，产量虽然低于改良品种，但已经适应了当地的气候和病害，而且可以留种继续传下去。与其把全部希望压在某一种改良品种上，不如同时保有地方品种，从长远来看更有利。

&nbsp;&nbsp;&nbsp;第二条标准是粒型搭配。如果只留大粒品种，虽然可以做酱类和豆腐，却很难发黄豆芽。大粒种发芽时耗力多，豆芽容易弯曲且发软。专门留出一种小粒品种用于发豆芽，是解决冬季蔬菜短缺的关键手段，这部分内容将在第16节详细介绍。

### 4-3. 按情况选择的标准

| 情况 | 优先选择 | 理由 |
|---|---|---|
| 要做酱类、豆腐 | 大粒中晚熟种 | 蛋白质含量高，产量高 |
| 冬季没有蔬菜 | 一定要留一部分小粒种 | 用于发豆芽，可作为维生素C的来源 |
| 初霜较早的地区 | 早熟种或中熟种 | 如果灌浆成熟没有完成，整批都会变成秕粒 |
| 田地贫瘠 | 地方品种 | 改良品种是按对肥料有反应的方向选育的 |
| 劳动力不足 | 抗倒伏品种 | 倒伏的大豆，收获用工会成倍增加 |
| 种子不足 | 小粒种 | 同样重量的种子可以播种面积大得多的田地 |

## 5. 整地与施肥 - 根瘤菌

### 5-1. 固氮是如何发生的

&nbsp;&nbsp;&nbsp;空气中78%是氮气。人的头顶上漂浮着取之不尽的氮，植物却无法利用。这是因为空气中的氮是由两个氮原子以三键牢牢结合而成的分子（N2），要断开这个键需要巨大的能量。工业上断开这个键来制造氨的方法是哈伯-博施法，世界上的氮肥就来自这里。这一过程需要高温、高压、催化剂和大量化石燃料。

&nbsp;&nbsp;&nbsp;根瘤菌在常温常压下就能完成这件事。它借助固氮酶这种酶断开三键，把氮转化为氨。不过这是有代价的：这个反应需要大量能量，而细菌自身不能进行光合作用。因此，它们进入豆科植物的根中生活，从植物那里获得光合作用制造的糖，作为回报，再把固定的氮交给植物。这是一种交易关系。

| 步骤 | 发生的过程 |
|---|---|
| 1. 信号交换 | 大豆根系分泌类黄酮，土壤中的细菌对这一信号作出回应，释放结瘤因子（Nod因子） |
| 2. 侵染 | 根毛向内弯曲，把细菌包裹起来，细菌沿着侵染线进入根内 |
| 3. 根瘤形成 | 根内侧的细胞分裂，根瘤膨大，细菌在其中定居 |
| 4. 固氮 | 根瘤内的固氮酶开始工作，把空气中的氮转化为氨 |
| 5. 分配 | 氨转化为氨基酸，被输送到茎、叶和豆荚 |
| 6. 衰老 | 进入灌浆成熟期后，根瘤丧失功能，随根一起回归土壤 |

&nbsp;&nbsp;&nbsp;固氮酶极怕氧气，一接触氧气就会立刻丧失功能。因此，根瘤内部充满了一种叫豆血红蛋白的红色色素蛋白，它能把氧气牢牢抓住，使酶周围的氧浓度保持在极低的水平。这与人的血液呈红色是同一个道理，把根瘤掰开后看到里面呈红色或粉红色，就是这种色素。这一点在实践中非常重要，因为红色就是这个根瘤此刻正在固氮的肉眼可见的证据。

### 5-2. 如何确认根瘤是否形成

&nbsp;&nbsp;&nbsp;无论是否接种，都必须检查根瘤是否真的形成。不检查，就无从知道缺氮的原因，第二年还会重复同样的错误。

| 步骤 | 内容 |
|---|---|
| 1 | 在刚开始开花的时候，也就是播种后6-8周左右，是最佳时机 |
| 2 | 选两三株看起来健康的植株 |
| 3 | 不要拔，用铁锹在植株周围大范围挖开，连土一起端起来。拔的话，须根上的根瘤会留在土里 |
| 4 | 放进水桶里，轻轻把土洗掉 |
| 5 | 数一数主根和较粗的须根上根瘤的数量 |
| 6 | 用指甲掰开几个根瘤，看里面的颜色 |

| 观察结果 | 含义 | 处理 |
|---|---|---|
| 每株根瘤20个以上，尤其集中在主根上部 | 接种成功 | 保持原样 |
| 掰开后里面呈红色或粉红色 | 正在固氮 | 状态良好 |
| 掰开后里面呈白色或浅绿色 | 根瘤已形成但没有固氮 | 检查酸度、渍害、缺磷 |
| 掰开后里面呈褐色或黑色 | 已经衰老或死亡 | 灌浆成熟期属正常，花期则有问题 |
| 根瘤5个以下 | 接种失败 | 如果叶片发黄，就补充氮 |
| 根瘤只在须根末端大量细碎地分布 | 被土著菌侵染，但效率低 | 次年更换接种源 |

> **挖出根系、掰开根瘤确认是否呈红色，这一个习惯，就是在没有氮肥的世界里判断大豆种植成败最可靠的信号。**

&nbsp;&nbsp;&nbsp;根瘤的位置同样能提供信息。长在主根上部、距土表10cm以内的粗大根瘤，是效率最高的根瘤，这是接种成功时形成根瘤的位置。反过来，如果主根上没有根瘤，只在须根末端零星分布着小根瘤，多半是土壤中原有的土著菌后来才侵染的。土著菌并不是与大豆长期共生的菌系，所以固氮效率较低。

### 5-3. 到哪里获取接种源

&nbsp;&nbsp;&nbsp;商品接种剂是把活的细菌装在泥炭或黏土里出售的产品，灾害情境下是买不到的。然而根瘤菌是土壤中常见的微生物，种过大豆的田地里的土壤本身就是接种源。这一点对灾害应对至关重要。

| 方法 | 步骤 | 效果 | 注意 |
|---|---|---|---|
| 用种过大豆的田土拌种 | 从前一年种过大豆、根瘤形成良好的田里，取表土5-15cm深处的土。把种子稍微用水润湿，均匀地裹上这种土，然后立即播种 | 最可靠且不花钱的方法 | 病田的土会连病原菌一起带过去 |
| 把土撒到田里 | 把取来的土撒在要播种的行里，一并翻入土中 | 比拌种用土量大，但菌能在土壤中扩散 | 每10㎡的田地用一锹左右的土为宜 |
| 直接使用根瘤 | 把拔出的大豆根上的根瘤收集起来捣碎，溶在水里，把种子浸入这种水中再捞出 | 菌的密度最高 | 必须在挖出根瘤的当天用完。干了菌就会死亡 |
| 把大豆根茬翻入土中 | 收获大豆后不挖根，让它原样留在田里 | 菌能在土壤中保留到次年 | 这是最省事的保持方法 |
| 野大豆的根 | 从田野和田埂上的野大豆根上采集根瘤 | 与大豆同属，菌可以通用 | 固氮效率可能低于栽培种专用菌系 |

&nbsp;&nbsp;&nbsp;接种时有一点必须遵守。根瘤菌极怕阳光直射、干燥和高温。受紫外线照射几分钟，相当多的菌就会死亡，干燥时死得更快。因此，给种子拌土的操作要在阴凉处进行，拌好土的种子不能摊在太阳下晒，要立即播种。最好在30分钟内播下，最迟也要在几个小时内完成。拌过土的种子如果放置超过一天再播，接种效果几乎就没有了。

&nbsp;&nbsp;&nbsp;还有一点，种子消毒与接种不能同时进行。给用过杀菌剂的种子拌土，细菌就会死亡。如果是用温水处理消毒的，要完全冷却后再接种。对于担心有病害的种子，选择消毒处理，而把接种改为直接把土撒在地里，两者分开进行才合理。

| 导致接种失败的条件 | 原因 |
|---|---|
| 土壤pH 5.5以下 | 细菌无法存活 |
| 施了大量氮肥的田地 | 植物感觉不到交易的必要，自行减少根瘤形成 |
| 容易积水的田地 | 它是好氧细菌，缺氧就会死亡 |
| 缺磷的田地 | 固氮需要大量能量，而能量代谢要用到磷 |
| 缺钼、铁、钴 | 它们是固氮酶的组成成分 |
| 把接种过的种子晒在太阳下 | 紫外线和干燥会使菌死亡 |
| 给用杀菌剂处理过的种子接种 | 细菌会死亡 |
| 长期没种过豆科作物的田地 | 几乎没有土著菌，必须接种 |

### 5-4. 固氮的陷阱

&nbsp;&nbsp;&nbsp;“种了大豆，地就会变好”这种说法，早已成为农业上的常识。它一半对，一半错。如果对这一点没有准确的理解，连续种了几年大豆的田地，反而会越来越贫瘠。

&nbsp;&nbsp;&nbsp;我们用数字来算一算。大豆长势好的话，1,000㎡能收获250kg籽粒。大豆籽粒的蛋白质含量是38%，把蛋白质含量除以6.25就得到含氮量。38 ÷ 6.25等于6.08，也就是说籽粒重量的约6%是纯氮。250kg籽粒中所含的氮约为15kg。换算成每公顷，则达到150kg。

&nbsp;&nbsp;&nbsp;另一方面，根瘤固定的氮在条件好时为每公顷100-150kg，这是接种成功、酸度适宜、水分合适时的上限值。条件差时只有50kg。把输出和输入并排放在一起，结果如下。

| 项目 | 每公顷氮量 | 方向 |
|---|---|---|
| 根瘤固氮量（条件好） | 100-150kg | 输入 |
| 根瘤固氮量（条件差） | 30-60kg | 输入 |
| 随籽粒带出 | 130-160kg | 输出 |
| 残留在茎叶（茎和叶）中的氮 | 25-40kg | 还田则留下，焚烧或运走则输出 |
| 残留在根和根瘤中的氮 | 10-20kg | 通常留在田里 |

&nbsp;&nbsp;&nbsp;看这张表就能明白。如果只收走籽粒，把茎叶还回田里，固定量与带走量大致相当，或者略有盈余。但如果把豆秸也割走当柴烧、焚烧掉，或者运出去喂牲畜，氮素收支就会明确转为负值。也就是说，从豆田流出的氮比流入的氮更多。

> **大豆能让土地恢复地力，并不是因为它固氮，而是因为它把固定的氮有一部分存在茎叶里并留在田中。如果把这些茎叶运走，大豆就成了掠夺土地养分的作物。**

&nbsp;&nbsp;&nbsp;再做一个对比。大豆籽粒重量的约6%是氮，玉米籽粒约为1.4%。把同样1kg的籽粒运出田外时，大豆带走的氮是玉米的4.5倍。把大豆当作蛋白质工厂来使用，代价就是氮被带出田外，这是在物理上无法避免的账目。因此，灾害情境下的大豆种植原则十分明确。

| 原则 | 内容 |
|---|---|
| 茎叶一定要还田 | 脱粒后剩下的豆秸、叶片和豆荚壳，全部还回田里 |
| 不要焚烧 | 一烧，氮就变成气体飘走，只有钾和磷以灰的形式留下 |
| 不要挖根 | 根和根瘤中的氮，是最容易留在田里的一份 |
| 不要把落叶耙走 | 灌浆成熟期落下的叶子里也含有相当多的氮 |
| 豆秸切碎覆盖 | 切成20-30cm铺在田里，既起覆盖作用，又能当肥料 |
| 喂了牲畜就把粪肥还回去 | 如果用豆秸喂了牲畜，一定要把这些牲畜的粪尿施回这块田 |

&nbsp;&nbsp;&nbsp;干豆秸易燃，很容易让人想拿来当柴烧。折中的办法是，一定要把草木灰还回这块田里。烧过之后氮虽然会挥发，但钾、磷和钙都留在灰里。不过，连续几年都烧的话，氮素收支会明显变差，所以最好有的年份烧、有的年份覆盖还田，交替进行。
