## 9. 病害虫 - 害虫と防除

### 9-2. 主な害虫

| 害虫 | 被害 | 薬を使わない防除 |
|---|---|---|
| カメムシ類（ホソヘリカメムシなど） | さやに口針を刺して汁を吸い、実の入らない粒にします。ダイズ最大の害虫です | 早朝、露があるときは動きが鈍くなるので、手で捕まえて水桶に入れます。畑の周囲に誘引作物を植えて、そこに集めて捕らえます |
| アブラムシ | 汁を吸い、ウイルス病を媒介します | 石けん水（水1Lに石けん5g）を葉の裏にかけます。テントウムシとクサカゲロウを保護します |
| マメシンクイガ | 幼虫がさやの中に入って子実を食べます | 早まきと早採りで発生期を避けます。残さを片づけて越冬場所をなくします |
| ハスモンヨトウ | 葉とさやを食い荒らします | 手で捕まえます。卵塊を見つけたら葉ごと取り除きます |
| ハダニ | 葉の裏から汁を吸い、葉が黄色くまだらになります | 乾燥すると増えます。水を葉に強くかけます |
| 鳥（ハト・カササギ・キジ） | 播種直後に子葉をついばみます | 発芽までわらや網で覆います |
| キバノロ・ノロジカ | 若い葉と茎を食べます | 柵や網を張ります |

&nbsp;&nbsp;&nbsp;カメムシがダイズ最大の害虫です。さやの殻を突き破って中の若い子実を吸いますが、外見上はさやが正常でも、開けてみると粒がしなびているか、まったくありません。殺虫剤を使わずにカメムシに対処する手段は三つあります。

| 方法 | 内容 | 効果 |
|---|---|---|
| 早朝の捕殺 | 気温が低い早朝は、カメムシはうまく飛べません。日陰のさやの下を探り、手で払い落として水桶で受けます | 最も確実です。数日続けると、個体数が目に見えて減ります |
| 誘引作物 | 畑の周囲に、カメムシがより好む作物（ゴマ、アワ、モロコシ）を植えて集め、そこで集中的に捕らえます | 本畑の被害を減らします |
| 収穫期の調整 | 早生種を播き、カメムシが増える晩夏より前に登熟を終えます | 回避戦略です。品種選びの段階で決まります |

### 9-3. 薬を使わない防除資材

| 資材 | 作り方 | 対象 | 注意 |
|---|---|---|---|
| ボルドー液 | 水100Lに硫酸銅400gと生石灰400gを、それぞれ別々に溶かして混ぜます | 細菌病、カビ病 | 銅がないと作れません。混ぜたらすぐに使います |
| 石けん水 | 水1Lに無香料の石けん5g | アブラムシ、ハダニ | 日中の暑いときに散布すると、葉が焼けます |
| 草木灰の水 | 灰1升を水10Lに一晩浸し、上澄みを使います | カビの抑制、葉の強化 | アルカリ性なので葉を傷めることがあり、薄めて使います |
| 乾いた灰の散布 | 露のある朝に、葉に細かい灰をふりかけます | 軟腐病、葉を食べる虫 | 雨が降ると流れ落ちます |
| 木酢液 | 炭を焼くときに出る煙を集めて冷やした液を、300-500倍に薄めます | 忌避、生育促進 | 原液は強酸性なので、必ず薄めます |
| タバコの葉の煮出し汁 | 乾燥したタバコの葉を水に浸して煮出して使います | アブラムシ、ガの幼虫 | 人にも毒性があるので、収穫直前には使いません |
| 唐辛子・ニンニクの水 | 辛い唐辛子とニンニクをすりおろし、水に浸してこして使います | 忌避 | 効果が長続きしないため、頻繁に散布する必要があります |
| 牛乳の希釈液 | 牛乳を水で5-10倍に薄めます | うどんこ病、ハダニ | 余ると傷んで臭います |

### 9-4. 耕種的防除 - 最も強力な手段

| 方法 | 原理 |
|---|---|
| 種子の選別 | ダイズの病害の相当数が種子伝染です。斑点と変色のあるものを取り除くだけで、発生を大きく減らせます |
| 輪作 | 病原菌は、宿主がないと土の中で徐々に死にます。マメ科を2-3年あけます |
| 播種期の調整 | 害虫の発生のピークと、作物の弱い時期が重ならないようにずらします |
| 栽植距離の確保 | 風通しがよいと葉が早く乾き、カビが定着できません |
| 排水 | ダイズの病害の半分以上が、過湿と関係しています |
| 残さの処理 | 病気の残さは焼くか、深く埋めます。健全な残さだけを畑に戻します |
| 雨の後は畑への立ち入り禁止 | 濡れた葉に人が触れると、病原菌がうつります |
| 抵抗性品種 | 地域で生き残ってきた在来種は、すでにその地域の病害に適応している可能性が高いです |

> **薬がない条件では、防除の重心は、散布することから、避けることへと移っていきます。種子を選び、作付けを回し、水を抜き、株の間隔をあける。この四つが、どんな散布よりも効果が大きいのです。**

&nbsp;&nbsp;&nbsp;病気の残さと健全な残さを区別することは、第5節の窒素収支と衝突する点です。窒素を残すには茎葉を畑に戻さなければなりませんが、病気の茎葉を戻すと病原菌が残ります。葉に斑点が少しある程度なら、切って覆っても構いません。茎が軟らかく腐る菌核病、黒い潰瘍ができた炭疽病、モザイク病にかかった株だけは、別に集めて焼くか、畑の外で長く腐らせます。

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 天然材料での対処 |
|---|---|---|
| 下の葉から全体が淡い黄色になり、個体が小さい | 窒素欠乏。ダイズでは根粒の不良が最も多い原因です | まず根を掘り上げて根粒を確認します。根粒がなければ翌年の接種を確実にし、その年は尿の10倍希釈液を少量与えます |
| 葉の縁が茶色く枯れ、内側に巻く | カリウム欠乏 | 草木灰を株の間にまき、軽くかき込みます |
| 生育が遅く、葉が紫色を帯びる | リン酸欠乏 | 骨粉、魚の骨を焼いた粉、草木灰 |
| 花は咲いてもさやがつかない | ホウ素欠乏、または開花期の高温・乾燥 | いろいろな材料を混ぜた堆肥。その年は、かん水とマルチングで温度を下げます |
| 葉脈は緑色なのに、葉脈の間が黄色い | 鉄またはマグネシウムの欠乏。アルカリに傾いた土で多く見られます | 灰の使用をやめます。腐葉土と完熟堆肥で有機物を増やします |
| 新しい葉が小さく奇形で、生長点が枯れる | カルシウムまたはホウ素の欠乏 | 卵の殻を焼いた粉、貝殻の粉 |
| 葉だけが濃い緑色で茂り、さやが少ない | 窒素過剰 | 窒素の供給をすぐに中止します。摘心で側枝を促します |
| 背丈が徒長して倒れる | 窒素過剰または密植 | 土寄せと条の支え。翌年は施肥量を減らします |
| 下の葉が黄色くなり、根が茶色い | 過湿による根の傷み | 排水溝を掘ります。肥料の問題ではありません |

&nbsp;&nbsp;&nbsp;ダイズで窒素欠乏の症状を見たとき、まず最初にすべきことは、肥料を与えることではなく、根を掘って確かめることです。ダイズの窒素供給源は土ではなく根粒です。根粒がよくついていて、割った内側が赤いのに葉が黄色いなら、窒素ではなく別の問題です。根粒がないか、内側が白色なら、それが原因ですが、その場合でも窒素を十分に与えるのは解決になりません。土の窒素が増えると、残っている根粒までが働きを弱めるからです。その年は最小限の量でしのぎ、翌年に接種と酸度矯正で根本を直すのが正しい順序です。

&nbsp;&nbsp;&nbsp;微量元素の欠乏は、一つずつ対応することが困難です。化学肥料なしでモリブデンやコバルトを手に入れる方法は、事実上ありません。その代わり、野菜くず、果物の皮、卵の殻、魚の骨、落ち葉、雑草、灰を一緒に混ぜて腐らせた堆肥には、微量元素がまんべんなく含まれています。堆肥場に何でも入れるという原則が、微量元素管理の現実的な戦略です。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 作物 | 理由 |
|---|---|---|
| 良い | トウモロコシ、モロコシ | ダイズが固定した窒素の一部を、そばで分けてもらえます。背丈の差で光を分け合います |
| 良い | マリーゴールド | 根の分泌物がセンチュウを抑えます |
| 良い | ジャガイモ | 互いに病害が重ならず、養分の要求も異なります |
| 良い | キャベツ・ハクサイの仲間 | ダイズの後に植えると、残った窒素を使います |
| 普通 | キュウリ・カボチャの仲間 | つるがダイズを覆わないよう、距離をとります |
| 悪い | トマト・トウガラシ・ナス | 同じ畑で病害虫を共有します |
| 悪い | ニンニク・タマネギの仲間 | 分泌物が根粒菌を抑えるという報告があります |
| 悪い | 他のマメ科との連作 | 病原菌とセンチュウが蓄積します |

&nbsp;&nbsp;&nbsp;トウモロコシとダイズを混植する方式は、古くから使われてきた組み合わせです。トウモロコシが上層の光を、ダイズが下層の光を使い、トウモロコシは窒素を多く要求するのに対して、ダイズは自分で窒素をつくります。ただし、ダイズは40%遮光で収量が半分に落ちる作物なので、トウモロコシの陰に深く入ると大きく減ります。トウモロコシ2条に対してダイズ2条を交互に配置し、トウモロコシの条を南北方向に通して、陰が一方に長くとどまらないようにします。トウモロコシの間にダイズをばらまくように入れると、ダイズはほとんど収穫できません。

&nbsp;&nbsp;&nbsp;ネギ類との関係は、議論のあるところです。ニンニクとタマネギの含硫化合物が根粒菌の活動を抑えるという観察が、複数の場所から報告されています。決定的な証拠として確立されたわけではありませんが、窒素固定がダイズ栽培の核心的な仕組みである以上、あえてリスクを負う理由がないため、離して配置します。

### 11-2. 輪作

| 項目 | 基準 |
|---|---|
| 休作期間 | 1年以上。同じ畑にマメ科を続けて植えません |
| 理想的な周期 | 3-4年 |
| 連作障害 | ダイズは豆類の中では連作に比較的強いほうですが、センチュウと根腐病が蓄積します |

&nbsp;&nbsp;&nbsp;ダイズの連作適応性はSで、豆類の中では良いほうであり、韓国農村振興庁の基準では1年休作群に属します。アズキが3年、ラッカセイが4年から5年を要求するのと比べると、余裕があります。しかし、耐えられるという意味であって、続けて植えてもよいという意味ではありません。連作を3年以上続けると、ダイズシストセンチュウと根腐病が蓄積し、収量が落ちます。

| 4年輪作の例 |
|---|
| 1年目：ダイズ |
| 2年目：葉菜類またはネギ類（ダイズが残した窒素を使います） |
| 3年目：穀物またはいも類（塊茎・塊根）（根の深さが異なる作物で層を変えます） |
| 4年目：根菜または緑肥（畑を休ませます） |
| 再びダイズ |

&nbsp;&nbsp;&nbsp;畑が狭く、輪作する余裕がないときの妥協策を書いておきます。畑を4つの区画に分け、毎年1区画ずつ移しながらダイズを植える方式が最も簡単です。区画を分けられない小さな畑なら、最低限、ダイズを植える条の位置を毎年ずらします。昨年のダイズの条に今年はトウモロコシを、昨年のトウモロコシの条に今年はダイズを植えるだけでも、センチュウの蓄積はかなり遅くなります。ダイズの後には、窒素を多く要求するハクサイやキャベツの仲間、トウモロコシが最もよく合います。

## 12. 収穫と脱穀

### 12-1. 収穫時期の判断

| 判断基準 | 内容 |
|---|---|
| 葉 | 葉が黄色くなり、ほとんど落ちています |
| さや | 全体の80%以上が茶色に変わっています |
| 音 | 畑で振ると、さやの中で粒がぶつかる音がします |
| 粒 | かむと歯が入らず、パリッと割れます |
| 水分 | 子実の水分13-15% |
| タイミング | 葉がすべて落ちてから7-14日 |

| 地域 | 収穫時期 |
|---|---|
| 韓国中部 | 10月上旬-中旬 |
| 韓国南部 | 10月中旬-下旬 |
| メジュ（味噌玉）用ダイズの中晩生種 | 10月下旬-11月中旬 |

&nbsp;&nbsp;&nbsp;収穫時期を逃すと、二つの方向で損失が出ます。早すぎると、粒の充実が足りずしわしわになり、貯蔵中に傷みやすくなります。遅すぎると、さやが乾いて自然に裂け、粒が地面に落ちます。これを脱粒といい、遅い収穫では3割近くを失うこともあります。特に、乾いたさやが雨にぬれて再び乾くことを繰り返すと、脱粒が急激に増えます。

> **雨の知らせがあれば、完熟を待たずに収穫します。少し未熟なダイズは乾燥させて使えますが、地面に落ちたダイズは収穫できません。**

### 12-2. 収穫のコツ

| 順序 | 内容 |
|---|---|
| 1 | 晴れて乾燥した日を選びます。露が乾いた午前10時以降がよいです |
| 2 | 株元を鎌で刈ります。根粒を残すには、茎だけを刈って根は残します |
| 3 | 畑で1日から2日広げて、予備乾燥します。雨が降ったらすぐに取り込みます |
| 4 | 束ねて、軒下や納屋に立てて掛け、仕上げ乾燥します |
| 5 | さやがからからに乾き、振ると音がしたら脱穀します |

&nbsp;&nbsp;&nbsp;慣行栽培では株ごと引き抜くこともありますが、災害時には、鎌で茎だけを刈って根を畑に残すほうがよいでしょう。根と根粒の窒素はヘクタールあたり10から20kgに達し、その根が腐れば、次の作物が使う有機物になります。

### 12-3. 脱穀 - 道具なしでできる方法

| 方法 | 道具 | 手順 | 効率 |
|---|---|---|---|
| 袋踏み | 厚手の麻袋や袋 | 乾いた豆がらを袋に入れて口を縛り、足で踏むか手でもみます | 少量には最も楽です。粒が飛び散りません |
| 殻竿（からざお） | 長い柄に打ち棒をつないだ道具 | むしろや布を広げ、豆がらを薄く広げて、上から打ちます | 中規模に向いています。2、3回ひっくり返しながら打ちます |
| 棒で叩く | 木の棒 | 袋に入れるか、むしろに広げて叩きます | 殻竿がないときの代わりです。力がより必要です |
| 足でもむ | なし | むしろに広げ、靴を履いた足でもみ回します | 少量に向いています |
| 板に打ちつける | 板か桶 | 豆がらの束を持ち、板の内側の壁に打ちつけます | 粒が桶の中にたまります。損失が少ないです |

&nbsp;&nbsp;&nbsp;脱穀の成否は乾燥にかかっています。乾き方が足りない豆がらは、いくら叩いてもさやが開かず、乾きすぎたダイズは、叩くときに粒が割れます。さやを手で押したときにパチンと開く状態が適期で、日差しのよい日の午後に行うと、ずっと楽です。

&nbsp;&nbsp;&nbsp;袋踏みは、小規模な自給で最も合理的な方法です。道具が要らず、粒が四方に飛び散らないので損失がほとんどなく、力もあまり要りません。厚手の麻袋に乾いた豆がらを半分ほど詰めて口を縛り、地面に置いて、足で満遍なく踏みます。10回ほど踏んだら、袋を振って位置を変え、また踏むことを3、4回繰り返すと、豆がらが短く砕けるころには終わっています。

### 12-4. 精選 - 風で選り分ける

| 方法 | 原理 | 手順 |
|---|---|---|
| 風選（風による選別） | 粒は重く、殻やくずは軽いです | 風のある日に、箕や広い容器に入れて高く持ち上げ、ゆっくりと注ぎます。粒はすぐ落ち、殻は飛んでいきます |
| 箕あおり | 上下に振りながら前へあおります | 重い粒が後ろに残り、軽いものが前へ押し出されます |
| うちわであおぐ | 一人が注ぎ、もう一人がうちわで風を起こします | 風のない日に使います |
| ふるい分け | 穴の大きさで分けます | 粗いふるいで豆がらの破片を取り除き、細かいふるいで土と小さな粒を落とします |
| 水に浮かべる | 実の入らない粒と虫食いの粒は軽いです | 水桶に注いで、浮くものを取り除きます。すくった豆は、必ずもう一度乾かします |
| 傾斜板に転がす | 丸い粒はよく転がり、くずは引っかかります | 板を傾けて置き、転がし落とします |

&nbsp;&nbsp;&nbsp;風選は、人が穀物を扱い始めたころから使われてきた方法で、今でもこれより簡単な手作業の精選法はありません。コツは三つです。第一に、風が一定に吹く時間と場所を選びます。早朝や日暮れ時の風がよいです。第二に、一度に注がず、細く流して落とします。太く注ぐと、殻やくずが粒の間に混じって落ちます。第三に、2、3回繰り返します。

&nbsp;&nbsp;&nbsp;水に浮かべる方法は、精選と選別を同時に行います。マメゾウムシに食べられた粒は中が空洞で浮き、実の入らない粒も浮くので、こうして選り分けると、貯蔵中の損失が大きく減ります。ただし、水に浸けたダイズは、その日のうちに薄く広げて完全に乾かし直さなければなりません。濡れたまま入れておくと、数日でカビが生えます。種子用のダイズには使いません。水に浸けると発芽の生理が始まり、その状態で乾かすと発芽力が落ちるからです。

## 13. 採種

| 項目 | 方法 |
|---|---|
| 採種個体の選抜 | 病気の症状がなく、さやがたくさんつき、倒れていない株を、畑で前もって目印をつけておきます |
| 収穫時期 | さやが完全に茶色に変わってから収穫します。食用より少し遅く収穫します |
| 分離 | 別に脱穀します。食用のダイズと混ざらないようにします |
| 選別 | 斑点、しわ、変色、小さな粒をすべて捨てます。大きくて艶のある粒だけを残します |
| 乾燥 | 水分12-13%。かむと歯が入らず、パリッと割れます |
| 保管 | 密閉容器に入れ、涼しく暗い場所に置きます。食用とは別の容器です |
| 保管期間 | 常温密閉で3年。発芽率は年ごとに落ちます |
| 更新 | 3-4年ごとに別の場所から種子を入手し、一部を混ぜます |

&nbsp;&nbsp;&nbsp;ダイズは自家受粉の作物なので、採種がとても簡単です。ほかの品種と混ざって植えても形質が乱れず、トウモロコシのように隔離距離を置く必要もありません。種苗会社や流通網が消えても、ダイズは自力で世代をつなげるという意味で、自家採種の等級Sはここから来ています。

&nbsp;&nbsp;&nbsp;ただし、何年にもわたって続ける場合には、注意すべき点があります。自家採種を繰り返すと、種子伝染性の病気が静かに蓄積します。紫斑病、炭疽病、モザイク病は、いずれも種子を介して次の世代に伝わります。目に見える斑点を取り除けばかなりの部分は防げますが、症状が現れない潜在感染は選別で取り除けません。そのため、3-4年ごとに隣の村や別の谷からダイズを分けてもらい、一部を混ぜるのがよいでしょう。

&nbsp;&nbsp;&nbsp;採種用のダイズを、畑で前もって目印をつけておく習慣が、結果を大きく変えます。収穫後に粒だけを見て選ぶと、大きさと形しか選べません。畑で選べば、さやの数、倒伏抵抗性、病気への抵抗性、最下位のさやの高さといった、実際に重要な形質を一緒に選べます。開花期と登熟期によい株に糸を結んでおき、収穫のときにその株だけを別に収穫すれば、数年後には、その畑の条件に合わせて少しずつよくなった系統ができます。

| 種子の保管期間と発芽率 |
|---|
| 収穫当年：90%以上 |
| 1年経過：80-90% |
| 2年経過：60-80% |
| 3年経過：40-60% |
| 4年以降：急激に落ちます |

&nbsp;&nbsp;&nbsp;ダイズの種子寿命はA等級で、常温密閉で3年です。しかし3年目の発芽率は半分に落ちるので、毎年新しく採って使い、古いものは予備として置く方式が正しいです。古い種子は、必ず先に発芽試験をします。発芽率が半分なら、播種量を2倍に増やして補正し、30%を下回るなら、種子には使わずに食べるほうがよいでしょう。
