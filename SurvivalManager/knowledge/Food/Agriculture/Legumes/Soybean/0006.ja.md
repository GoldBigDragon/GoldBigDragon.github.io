## 14. 毒性と抗栄養成分

&nbsp;&nbsp;&nbsp;ダイズは加熱すれば安全ですが、生では危険です。マメ科の種子は、食べられないようにするために化学的な防御物質を含んでおり、それらの物質が人の消化を妨げます。幸い、大半は熱に弱く、十分に加熱すれば壊れますが、問題は「十分に」という言葉の基準が思ったより高いことです。

### 14-1. 抗栄養成分の正体

| 成分 | 働き | 症状 | 取り除く方法 |
|---|---|---|---|
| トリプシンインヒビター | タンパク質分解酵素トリプシンの働きを妨げます | 腹痛、嘔吐、下痢、タンパク質利用率の低下、膵臓への負担 | 8時間浸漬した後、100℃で30-60分以上加熱 |
| レクチン（ヘマグルチニン） | 腸粘膜の糖鎖に付着して吸収を妨げ、赤血球を凝集させます | ひどい腹痛、嘔吐、下痢 | 浸漬後、100℃で10-30分以上加熱 |
| フィチン酸 | 鉄、亜鉛、カルシウム、マグネシウムと結合して吸収を妨げます | 長く食べ続けると貧血、亜鉛欠乏 | 浸漬、発芽、発酵で60-80%まで減ります |
| サポニン | 泡立ち、胃腸を刺激します | 少量は無害、多いと胃がもたれます | 浸漬後、ゆでながら泡を取り除きます |
| オリゴ糖（ラフィノース・スタキオース） | 人は消化できず、腸内細菌が発酵させます | おなかにガスがたまります | 浸漬後、漬け水を捨てます。発酵で大きく減ります |
| ゴイトロゲン | ヨウ素の利用を妨げます | ヨウ素が不足した食事では甲状腺に負担 | 加熱で減ります。海藻を一緒に食べると相殺されます |

> **加熱が不十分な豆が、生の豆より危険な場合があります。軽くゆでると細胞壁が壊れて吸収はよくなりますが、インヒビターとレクチンは残っているからです。加熱するときは中途半端にやめず、最後まで火を通します。**

&nbsp;&nbsp;&nbsp;レクチンの危険性は、豆の種類によって大きく異なります。ダイズのレクチンは、インゲンマメ類（Phaseolus）のレクチンより毒性が弱いです。インゲンマメは、生のものを4、5粒食べただけでも数時間以内にひどい嘔吐と下痢が起こり、加熱不足のインゲンマメによる食中毒が何度も報告されています。特にインゲンマメ類は、低い温度で長く温めるとレクチンの活性がかえって上がる温度帯があるため、ぬるま湯に長時間置く調理が最も危険です。ダイズはそこまで極端ではありませんが、原則は同じです。ぐらぐらと煮えた湯で十分な時間加熱する、これが唯一安全な方法です。

### 14-2. 浸漬と加熱の基準

| 処理 | 時間・温度 | 効果 |
|---|---|---|
| 浸漬 | 常温の水に8時間（夏は水を替えながら6時間） | 芯まで熱が入ります。オリゴ糖とサポニンの一部が水に溶け出します |
| 漬け水を捨てる | 必ず | 水に溶け出したオリゴ糖と抗栄養成分を一緒に捨てます |
| 煮る | ぐらぐら煮立った湯で60分以上 | トリプシンインヒビターとレクチンが不活性化されます |
| 蒸す | 100℃の蒸気で60-90分 | 養分の損失が煮る場合より少なくなります |
| 圧力調理 | 120℃で15-20分 | 燃料が最も少なくてすみます |
| 火の通りの確認 | 親指と人差し指で押して、簡単につぶれます | 硬い芯が残っていれば、加熱不足です |

&nbsp;&nbsp;&nbsp;乾燥した豆は表面が硬く、熱が芯まで入りにくいです。浸さずに煮ると、表面だけが煮えて中は加熱不足のまま残りますが、この状態が最も危険です。しかも、2倍以上の燃料がかかります。漬け水は飲んだり調理に使ったりしませんが、畑にまいたり食器洗いに使ったりすれば無駄にはなりません。

&nbsp;&nbsp;&nbsp;夏は気温が高いため、8時間のうちに水が傷んで、豆がぬるぬるしてきます。3時間から4時間ごとに水を替えるか、夕方に浸けて朝に引き上げる方法で、時間を夜に移します。

### 14-3. 発芽と発酵

| 方法 | 減る成分 | 程度 |
|---|---|---|
| 発芽（大豆もやし） | フィチン酸、トリプシンインヒビター、オリゴ糖 | フィチン酸が50-70%、インヒビターが30-40%減少 |
| 発酵（韓国味噌のテンジャン・醤油・発酵大豆のチョングッチャン） | フィチン酸、トリプシンインヒビター、オリゴ糖、レクチン | 大部分が分解され、吸収率が上がります |
| 浸漬のみ | オリゴ糖、フィチン酸の一部 | 20-30%減少 |

&nbsp;&nbsp;&nbsp;発酵は、抗栄養成分の問題を最も根本から解決する方法です。微生物が、インヒビターやレクチンのようなタンパク質をアミノ酸に分解し、フィチン酸を分解する酵素を出します。その結果、抗栄養成分は消え、吸収率はゆでた豆よりも上がります。東アジアが豆を発酵させて食べる方式を発達させたのは、味のためだけでなく、この生理的な利益のためです。

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;ダイズの貯蔵性はSSです。FAOの食品ロス指数で、貯蔵段階の損失率の中央値は0.25%と、この作物表で最も低い数値に入り、乾燥した豆は常温で3年もちます。しかし、条件が外れると、マメゾウムシ1種が、貯蔵した豆のすべてを中身のない殻に変えてしまいます。

> **豆は腐って失うのではなく、虫に食べられて失います。貯蔵の技術とは、すなわち虫を防ぐ技術です。**

### 15-1. 乾燥が先です

| 段階 | 方法 | 確認 |
|---|---|---|
| 予備乾燥 | 豆がらごと畑や軒下で1日から2日 | さやがからからに乾きます |
| 脱穀後の乾燥 | むしろや敷物に薄く広げて、日なたで2-3日 | こまめにかき混ぜて均一に乾かします |
| 目標水分 | 食用12-13%、種子12% | 歯でかんだときに歯が入らず、パリッと割れます |
| 塩の試験 | 乾いた塩を瓶に豆と一緒に入れて振ります | 塩が瓶の壁につけば、豆はまだ湿っています |
| 冷ます | 日なたから取り込んだ後、完全に冷ましてから容器に入れます | 温かいまま密閉すると結露します |

&nbsp;&nbsp;&nbsp;乾燥が足りないと、その後のすべての対策が崩れます。水分が15%を超えるとカビが育ち、13%を超えるとマメゾウムシの繁殖が速まります。逆に10%を下回ると、種皮が裂けて貯蔵中に割れ、種子用であれば発芽力が落ちます。

&nbsp;&nbsp;&nbsp;かんで確かめる方法が最も実用的です。前歯でかんだときに、歯が少しでも食い込めばまだ乾き方が足りず、カチッと音を立てて二つに割れれば十分に乾いています。塩の試験も簡単です。乾いた瓶に豆ひとつかみと炒った塩をひとさじ入れて振り、数分置いたときに、塩が瓶の壁に張りつけば、もっと乾かさなければなりません。

### 15-2. 貯蔵中のマメゾウムシ対策

&nbsp;&nbsp;&nbsp;マメゾウムシ（アズキゾウムシ、リョクトウゾウムシを含むCallosobruchus属の仲間）は、貯蔵豆類にとって最大の脅威です。恐ろしいのは、畑ですでに始まっていることです。まだ畑についているさやに成虫が卵を産みつけ、その卵が貯蔵庫の中でふ化して豆の中に食い込みます。入ってくるときにすでに卵がついてくる仕組みで、1世代が1か月足らずで回り、半年もすれば袋一つが、穴のあいた殻と粉で満たされます。

| 方法 | 原理 | 適用 | 効果 |
|---|---|---|---|
| 完全密閉 | 酸素を断って窒息させます | ガラス瓶や金属缶に満杯に詰めて封をします | 最も確実です。3-4週間で卵と幼虫まで死にます |
| 草木灰を混ぜる | 微細な粒子が外骨格のワックス層を削り、脱水させます | 豆の容積の2-5%を混ぜます | 食べる前に水でゆすいで落とします |
| 珪藻土 | ケイ酸の殻が外骨格を傷つけます | 豆1kgに1-3g | 灰より効果が大きいです。乾いた状態でのみ作用します |
| 油コーティング | 油膜が産卵とふ化を妨げます | 豆1kgに食用油2-5mLを入れてもみ込みます | 豆類に効果が大きいです。種子用には使いません |
| 低温処理 | 氷点下で卵と幼虫が死にます | 真冬に数日間外に出してから取り込みます | 再び取り込むとき、結露に気をつけます |
| 高温処理 | 60度で卵と幼虫が死にます | 日なたに薄く広げて半日置きます | 種子用には使いません |
| 乾燥唐辛子・サンショウ・ヨモギ | 精油成分が産卵を抑えます | 層状に入れます | 補助手段です |
| 炭・炒った塩 | 湿気を吸い取ります | 布に包んで入れます | カビ予防も兼ねます |
| 灰の中に埋める | 密閉と物理的防除を同時に得られます | 甕に灰と豆を交互に重ねます | 伝統的に広く使われてきました |

&nbsp;&nbsp;&nbsp;最も重要なのは完全密閉です。虫も呼吸をします。密閉した容器の中で、豆と虫が酸素を使うと、酸素が減って二酸化炭素が増え、虫が死にます。豆は休眠状態なので、この条件に耐えます。容器をいっぱいに満たして空間を減らすほど、効果が速くなります。大きな缶一つよりも、小さな缶を複数用意してぎっしり詰めるほうがよく、これには、一つの缶がだめになったときにすべてを失わずにすむという利点もあります。

&nbsp;&nbsp;&nbsp;油コーティングは、豆類の貯蔵に特によく合います。豆1kgに食用油2-3ml、つまり小さじ半分ほどを入れ、手でもみ込んで、すべての粒に薄い膜ができるようにします。油膜は、成虫が卵を産みつけにくくし、すでに産みつけられた卵の気門をふさいで、ふ化を妨げます。インドやアフリカの小規模農家で長く使われてきた方法です。ただし、油が酸化すると臭いが出るので、半年以内に食べる分にだけ使い、種子用には使いません。油膜が呼吸を妨げて、発芽力が落ちるからです。

&nbsp;&nbsp;&nbsp;草木灰は、細かいものだけを選んで使います。ふるいにかけて粗い炭の破片を取り除き、細かい部分だけを豆の容積の2-5%混ぜて、すべての粒に薄くまぶします。食べるときに水で3、4回すすげばきれいになります。虫が耐性を獲得することはなく、人体には無害です。

### 15-3. 貯蔵容器と場所

| 容器 | 密閉 | 期間 | 長所 | 短所 |
|---|:---:|---|---|---|
| ガラス瓶 | 非常によい | 3年以上 | 状態を目で確認できます | 容量が小さく、光を遮れません |
| 金属缶 | 非常によい | 3年以上 | ネズミと虫を完全に防ぎます | 結露するとその部分が傷みます |
| 甕 | よい | 2-3年 | 温度変化が遅く、ネズミが穴をあけられません | 重く、割れます |
| 厚手のビニール | 普通 | 1-2年 | 軽くて安価です | ネズミが穴をあけます |
| 地下の貯蔵穴 | よい | 2-3年 | 温度が一定で低いです | 水がしみ込むと全量を失います |

| 保管場所の条件 | 目標 |
|---|---|
| 温度・湿度 | 15℃以下、空気湿度65%以下 |
| 光 | 完全に遮断 |
| 場所 | 地下か北向きの部屋、地面に直接触れないよう台の上 |
| 点検 | 2か月に1回 |

&nbsp;&nbsp;&nbsp;点検で最も頼りになる感覚は、聴覚と嗅覚です。缶に耳を当てたときにカサカサという音がすれば、虫が活動しており、湿っぽいにおいがすれば、カビが始まっています。豆の表面に小さな丸い穴が見えたら、マメゾウムシが1世代を経た状態です。この段階でも、全量を取り出して日に干し、水に浮かべて中身のない粒を取り除き、灰か油を混ぜてもう一度密閉すれば、残りの分は守れます。

## 16. 調理と加工

### 16-1. 大豆もやし - 冬のビタミンC

&nbsp;&nbsp;&nbsp;乾燥した豆には、ビタミンCは事実上ありません。ところが、芽を出させると、なかったビタミンCが作られます。発芽という生理的な転換が起こり、植物が新たに合成するからです。冬に新鮮な野菜がまったくないとき、乾燥した豆ひとつかみと水と暗い場所さえあれば、3、4日で新鮮な野菜が得られます。畑も日光も土も必要ありません。

&nbsp;&nbsp;&nbsp;ビタミンC欠乏は、数か月かけて静かに進行し、歯茎から血が出る、傷が治らない、力が出なくなるといった症状として現れます。大航海時代の船乗りたちが経験したあの病気であり、長い冬を貯蔵食品だけで越した社会で繰り返し現れました。大豆もやしは、この問題に対する安価で確実な答えです。

| 順序 | 内容 | 要点 |
|---|---|---|
| 1. 豆を選ぶ | 小粒種がよいです。割れた粒や虫食いの粒は捨てます | 割れた粒は腐って全体を傷めます |
| 2. 洗う | 何度かすすいで、浮くものを取り除きます | 浮く粒はたいてい死んだ粒です |
| 3. 浸す | ぬるま湯に6-8時間浸します | 豆が2倍にふくらむ必要があります |
| 4. 容器に入れる | 水が抜ける容器やシル（底に穴のあいた素焼きの鉢）に入れ、濡らした布で覆います | 水がたまると腐ります |
| 5. 暗くしておく | 光を完全に遮ります。20-25℃がよいです | 光が当たると緑色に変わって硬くなります |
| 6. 水をやる | 1日3-4回、上から十分に流し落とします | 温度調節と老廃物の除去を兼ねます |
| 7. 収穫 | 4-7日、長さ5-10cm | 根が茶色くなる前に収穫します |

| 条件 | 結果 |
|---|---|
| 光が当たる | もやしの頭が緑色になり、茎が硬くなります |
| 水が少ない | 根が細根をたくさん出して硬くなります |
| 水がたまる | 下のほうから腐って臭います |
| 温度が30度を超える | 早く育ちますが、軟弱で傷みやすくなります |
| 温度が15度を下回る | とてもゆっくり育ちます |
| 重いものをのせる | 茎が太くふっくらします |

&nbsp;&nbsp;&nbsp;水やりが、大豆もやしづくりのほぼすべてです。水は、水分を供給し、発芽の過程で出る熱を冷まし、たまった老廃物を洗い流します。1日3回から4回、上から十分に注いで完全に水を切り、夏は回数を増やし、冬はぬるま湯を使います。細根がたくさん出るのは、水が足りないというサインです。

&nbsp;&nbsp;&nbsp;シルがなければ、底に穴をあけた甕や桶、目の細かいざる、穴をあけたたらいを使います。下に受け皿を置き、上を黒い布で覆えば、それがシルの代わりになります。大切なのは、水が抜ける構造と光の遮断の二つだけです。

&nbsp;&nbsp;&nbsp;乾燥した豆100gは、大豆もやし400gから500gになります。増えた重さの大部分は水なので、熱量は増えませんが、ビタミンCが新たに生まれ、フィチン酸とトリプシンインヒビターが減り、タンパク質の一部が消化されやすい形に分解されます。大豆もやしも生では食べず、ゆでるか炒めて食べます。残っているインヒビターのためです。

### 16-2. 醤の仕込み - 燃料を前払いする貯蔵

| 加工 | 手順の要約 | 保管 | 価値 |
|---|---|---|---|
| メジュ（味噌玉） | 豆をゆでてつぶし、塊に丸めて、わらに包み、1か月以上発酵させます | 干して冬の間じゅう | テンジャンと醤油の原料 |
| テンジャン | 発酵させたメジュを砕き、塩水と混ぜて何か月も熟成させます | 数年 | タンパク質の貯蔵と調味料を兼ねます |
| 醤油 | メジュを濃い塩水に漬けて何か月も置き、出てきた液を煮詰めます | 数年 | アミノ酸の供給源 |
| チョングッチャン | ゆでた豆をわらに包み、40℃前後で2-3日置きます | 数日、乾燥させれば数か月 | 最も早くできる発酵豆 |
| 豆腐 | 浸した豆をすりつぶして煮、こして、にがりで固めます | 数日 | 最も消化しやすいです |
| 大豆油 | 炒って砕き、圧搾します | 数か月 | 搾油率が低いです |
| 炒り豆の粉（きな粉） | 炒って砕きます | 密閉で2-3か月 | 調理燃料が要りません |

&nbsp;&nbsp;&nbsp;災害時に醤を仕込むことの価値は、三重にあります。第一に、抗栄養成分が完全に分解されて、吸収率が上がります。第二に、一度仕込んでおけば、その後は調理燃料がほとんどかかりません。豆をゆでる1時間分の燃料を、1年分に対して一度だけ支払う計算です。第三に、塩とともに貯蔵されるため、何年ももちます。

&nbsp;&nbsp;&nbsp;チョングッチャンは、最も早く得られる発酵豆です。ゆでた豆をわらに包んで暖かい場所に2、3日置くと、稲わらの細菌が繁殖して糸を引きます。メジュのように1か月待つ必要はなく、塩も要りません。においが酸っぱく香ばしければ成功で、腐ったにおいがしたり、黒いカビが見えたりしたら捨てます。

&nbsp;&nbsp;&nbsp;豆腐は、最も消化しやすい形です。食物繊維とオリゴ糖がこし取られるため、おなかにガスがたまらず、高齢者や子ども、病人が食べるのに向いています。残ったおからも捨てずに、チゲ（韓国風の煮込み鍋）にして食べたり、干しておいて使ったりします。固めるのに必要なにがりは、天日塩を積んでおくとしみ出てくる苦い水で、なければ海水を煮詰めて使うか、酢を少し使うこともできます。

### 16-3. 燃料を節約する調理

| 方法 | 燃料 | 手順 |
|---|:---:|---|
| 圧力調理 | 最も少ない | 浸した豆を15-20分加圧します |
| 余熱調理 | 非常に少ない | 10-15分煮た後、火を消し、わら・もみ殻を詰めた箱や布団で包んで2-3時間置きます |
| 炒り豆の粉 | ほとんどなし | あらかじめ炒って砕いておき、水に溶いて飲みます |
| 炒り豆 | 少ない | 乾燥した豆を弱火で炒ります。20-30分でインヒビターがかなり減ります |
| 発酵（醤） | 前払い | 一度仕込めば、以後は燃料がかかりません |
| 大豆もやし | なし | 発芽には熱が要りません |

&nbsp;&nbsp;&nbsp;余熱調理は、ダイズで特に効果が大きいです。10-15分だけ煮て保温箱に入れておくと、内部の温度が2時間以上80℃を超えたまま保たれ、調理が続きます。ただし、80度ではレクチンとトリプシンインヒビターを完全に壊すには不十分なことがあるため、最初に煮る時間を15分以上確保し、取り出したときに豆が指で簡単につぶれるかどうかを確認します。芯が残っていれば、もう一度煮ます。

&nbsp;&nbsp;&nbsp;炒り豆は、調理する余裕がないときの答えです。乾燥した豆を熱した鍋に入れ、弱火で20-30分かき混ぜながら炒めると香ばしいにおいがしますが、この乾熱処理でトリプシンインヒビターがかなり減り、そのまま食べられます。ただし、ゆでたものほど完全ではないので、主食として長く食べ続けることはしません。炒って砕いた豆粉は、水に溶かせばすぐに食べられ、穀物の粉と混ぜればアミノ酸組成が完成します。

## 17. 年間作業スケジュール

| 月 | 作業 | 要点 |
|---|---|---|
| 1月 | 貯蔵豆の点検、種子の発芽試験、道具の手入れ | 缶に耳を当てて、虫の音を確認します |
| 2月 | 畑の計画、堆肥の切り返し、醤の仕込みの準備 | 輪作の順序と、古い種子の発芽率を確認します |
| 3月 | 石灰の散布、堆肥の仕上げ、メジュの発酵 | 石灰は播種の3-4週間前に入れます |
| 4月 | 畑の耕起、畝立て、排水溝づくり、元肥 | 韓国の梅雨（チャンマ、6月下旬～7月）を念頭に、排水溝を深く掘ります |
| 5月 | 種子の選別、温湯消毒、早生種の播種、接種源の土の確保 | ダイズを栽培した畑の土を、前もってすくっておきます |
| 6月 | 本播種（韓国中部は上旬、韓国南部は中下旬）、鳥害対策、1回目の除草 | 2週間間隔で分けて播き、開花期を分散します |
| 7月 | 間引き、除草、土寄せ、摘心、根粒の確認 | 開花前に摘心し、根を掘り上げて根粒を割って見ます |
| 8月 | 開花と莢肥大、集中かん水、カメムシの捕殺 | この時期の水が収量をつくります。早朝にカメムシを捕ります |
| 9月 | 登熟の管理、かん水の中止、採種個体の目印づけ | よい株に糸を結んでおきます |
| 10月 | 収穫、予備乾燥、掛け干し、脱穀 | 雨の知らせがあれば、完熟を待ちません |
| 11月 | 精選、乾燥、貯蔵、茎葉の還元、メジュづくり | 豆がらを切って畑に覆います。焼きません |
| 12月 | 醤の仕込み、貯蔵の点検、大豆もやしづくり | 大豆もやしで冬のビタミンCを得ます |

### 17-1. 忘れてはならない五つのこと

| 項目 | 内容 |
|---|---|
| 窒素 | 多く与えれば、必ず収量が減ります。3kg/1,000㎡を超えないようにします |
| 根粒 | 開花期に根を掘り上げ、根粒を割って赤い色を確認します。ダイズ栽培の計器盤です |
| 茎葉 | 豆がらと葉と根を畑に戻さなければ、ダイズは土地から収奪する作物になります |
| 水 | 開花期から莢肥大期までの4週間が、収量の80%を決めます |
| 加熱 | 8時間浸して、1時間以上煮ます。加熱不足の豆のほうが危険なことがあります |
