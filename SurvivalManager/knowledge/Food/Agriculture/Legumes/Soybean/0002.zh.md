## 1. 灾害应对评价

&nbsp;&nbsp;&nbsp;大豆的综合等级为A，得分49.9分。按情景划分，抵御灾害初期的短期能力为B（47.3），跨越多年的长期自立能力为S（52.8），作为主食之外的副食资源的副食价值为SS（65.1）。副食65.1分在这份作物评价表中位居最上游。短期比长期低5.5分，这一事实概括了大豆的性格。它是一种种下后要等上四个月、也不能填饱肚子，但随着年头增加相对位置不断上升的作物。

### 1-3. 如何解读优势

&nbsp;&nbsp;&nbsp;获得SS的项目有蛋白质密度、施肥需求、设施负担、耐储性四项。在此之上，微量营养素、连作适应性、无合成投入产量保持率、口味、栽培普及度获得了S。这样的排布说明，大豆并不是在某种特定条件下爆发式增产的作物，而是没有任何一项会彻底崩塌的作物。

&nbsp;&nbsp;&nbsp;蛋白质密度的SS是这张表的核心。P:E 37.9%在植物性食品中名列前茅，说明“一把豆子可以顶一块肉”的说法并不夸张。灾害情境下，人最先失去的营养素不是热量，而是优质蛋白质。热量可以靠薯类（块茎/块根）和谷物想办法补足，而蛋白质几乎没有替代途径。田边几行大豆就能改变整个膳食性质，原因就在这里。副食等级SS、65.1分也出自同一处。

&nbsp;&nbsp;&nbsp;施肥需求的SS与零投入保持率的S是一体的。大豆实际上不需要氮肥，因为根瘤菌会固定空气中的氮并交给植株。虽然不能靠根瘤满足全部需求，但植株自己能制造所需氮素的一半到75%。在化肥工厂停产、流通网络中断的条件下，氮是最先消失的资源，而从空气中获取这种资源的能力，其价值高于其他任何项目。DOK试验中的63.4%在豆类中最高，也是这一点再加上低病虫害压力的结果。

&nbsp;&nbsp;&nbsp;病虫害压力的A同样值得关注。无防治减产率估计为23%，在这份作物评价表中算是相当低的。这意味着即使完全不用农药，损失也只在25%左右，与马铃薯疫病或白菜类的病害相比，要容易承受得多。大豆的病害大部分可以通过种子筛选、轮作和调整播期这些农艺措施，在很大程度上避开。

&nbsp;&nbsp;&nbsp;耐储性的SS、自家留种的S和种子寿命的A，把循环的环节补全了。收获的豆子可以保存3年以上，其中一部分可以直接作为来年的种子，而且是自花授粉，品种特性不会混杂。不必像种薯那样，让活的块茎整个冬天都维持存活。把干豆装进坛子里，它既是粮食，又是种子，也是储备。

> **大豆的价值不在于田里产出的数量，而在于这些数量中蛋白质的质量，以及外界什么都不输入也不会中断的循环结构。**

### 1-4. 如何解读短板

&nbsp;&nbsp;&nbsp;获得E的项目只有耐寒性一项，但持续性、光照响应、烹饪·加工获得了D，单位面积热量、收获速度、温度适应幅度、整地能耗、非食用价值获得了C。

&nbsp;&nbsp;&nbsp;单位面积热量的C是最实质性的制约。每1㎡只有1,002kcal，是自给线的0.38倍。一个成年人若想只靠大豆满足每日2,100kcal，每天要吃524g，这相当于将近三杯干豆，实际上很难吃下。消化负担也很大，燃料也难以承担。所以大豆始终应当作为主食作物的搭档来安排：用马铃薯、甘薯或谷物撑起热量，再在其上用大豆补上蛋白质。安排田地面积时，给大豆分配总面积的20-30%，通常是合理的。

&nbsp;&nbsp;&nbsp;光照的D也很沉重。遮光40%时，相对产量降到50%。也就是说，半遮阴的田里收成只有一半，所以要避开围墙的阴影、大树下和朝北的坡面。大豆还是对日长敏感的短日照植物，开花不仅受光照强度调节，还受白昼长度变化调节。夜间有人工光源照射的地方，开花会推迟、结实紊乱，所以这样的地方同样要避开。

&nbsp;&nbsp;&nbsp;烹饪·加工的D是每天都要付出的成本。干大豆要泡8小时，再煮1小时以上。这不是口味问题，而是安全问题。生大豆和未煮熟的大豆含有胰蛋白酶抑制剂和凝集素，会妨碍消化，引起腹痛和腹泻。在燃料珍贵的情况下，1小时的加热是相当大的负担，所以第16节另行讨论减少燃料的方法。同时也会看到，通过发酵腌制酱（jang，大酱、酱油之类），这一负担可以一次性解决。

&nbsp;&nbsp;&nbsp;耐寒性的E与收获速度的C成对出现，压缩了栽培期。遇霜一次就会枯死，却又需要120-150天。这就是为什么在韩国中部，6月上旬播种为宜，而6月下旬被定为极限期。种得晚，灌浆成熟期就会碰上霜冻，最后只剩下秕粒。

&nbsp;&nbsp;&nbsp;非食用价值的C里包含了固氮，但这里藏着一个陷阱。固定氮与让土壤留住氮是两回事。大豆籽粒的含氮量约占重量的6.5%，与玉米籽粒的1.4%相比，高达4.5倍。把豆子收获并运走这一行为本身，就是把氮从田里带走的行为。这个问题将在第5节用数字来解开。

## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

&nbsp;&nbsp;&nbsp;大豆是豆科（Fabaceae）大豆属（Glycine）的一年生草本。它与红小豆、绿豆、豇豆、花生、豌豆、菜豆同属一个大家族。这一事实有两层含义：一是它们共有与根瘤菌共生的固氮能力；二是它们共有豆科共同的病害和害虫，因此豆类之间连续种植会造成病原菌积累。

&nbsp;&nbsp;&nbsp;原产地是从中国东北部到朝鲜半岛的东亚温带地区。野生祖先野大豆（Glycine soja）至今仍生长在韩国的田野和田埂上。这样的出身说明了两点。第一，大豆是已经适应了韩国气候的作物，无需特别的设施或保护，在露地就能生长。第二，其生育周期与夏季降雨集中、冬季下霜的韩国气候节律相吻合。反过来，热带全年高温或寒冷地区的短暂夏季，都是大豆不曾经历过的条件。

&nbsp;&nbsp;&nbsp;还有一点，大豆是对日长敏感的短日照植物。它接收到白昼开始变短的信号后才开花。因此纬度跨度大的话，开花时间会紊乱；错过播期，就会只长叶子而不结荚。如果种子是从远处获得的，就要确认该品种适应的是哪个纬度。

### 2-2. 形态

| 器官 | 特征 |
|---|---|
| 叶 | 三片为一组的三出复叶。接近心形，被细毛覆盖 |
| 茎 | 直立，高60-100cm。会分枝，每个节上长叶和花 |
| 根 | 直立的主根上长出须根。根瘤菌形成的根瘤像珠子一样长在须根上 |
| 花 | 白色或淡紫色。小而不显眼，7-8月开放 |
| 荚 | 褐色，被硬毛覆盖。每个荚内有2-4粒籽粒 |
| 籽粒 | 圆形或扁圆形。以黄白色为主，也有黑色、褐色、绿色的 |

&nbsp;&nbsp;&nbsp;细毛是大豆的防御结构。覆盖在叶和荚上的毛从物理上阻碍小型害虫靠近，并减缓水分蒸发。毛很硬，徒手长时间接触豆荚会被磨得发痛，这就是收获时要戴线手套的原因。

&nbsp;&nbsp;&nbsp;花小且自花授粉，这一点在灾害应对中是重要的优点。即使没有蜜蜂也能结实，与其他品种混种也不会混杂性状。不像玉米那样需要留出隔离距离，传粉昆虫减少的年份产量也不会下降。不过，开花后如果持续高温或断水，花会直接脱落。大豆本就是会自行脱落一半以上已开花朵的作物，所以开花期的管理就等于产量。

&nbsp;&nbsp;&nbsp;根瘤是这种作物的核心结构。长势良好的一株大豆，根上会长出数十个乃至一百多个豌豆粒大小的根瘤。如何确认根瘤以及如何促其良好形成，是第5节的主题。

### 2-3. 生育阶段

| 阶段 | 时期 | 关键生理 | 重要营养 |
|---|---|---|---|
| 发芽·幼苗期 | 从播种到真叶2-3片 | 种子发芽，根瘤开始形成 | 磷、少量氮 |
| 营养生长期 | 从真叶展开到分枝 | 茎叶增多，根瘤活跃 | 氮由根瘤供给 |
| 开花期 | 从初花到盛花 | 开花并完成授粉 | 磷、硼 |
| 鼓荚期 | 荚形成与膨大 | 籽粒增大，大量吸收养分 | 钾、磷 |
| 灌浆成熟期 | 从籽粒充实到变黄 | 叶片变黄，养分转入籽粒 | 停止灌水 |

> **大豆在整个生育期用水的约80%，是在开花期到鼓荚期之间吸收的。这4周一旦断水，产量的崩塌程度比其他任何时期都严重。**

&nbsp;&nbsp;&nbsp;关于早期的氮供给，有一点需要提醒。根瘤并不是播种后马上开始工作的。从种子发芽、根系伸展、细菌侵染、根瘤形成，到开始向植株提供氮，需要3-4周。在此期间，幼小的大豆靠种子里储存的养分和土壤中的氮维持。所以，施入少量氮作基肥是有意义的。但必须是少量。土壤里氮充足时，植株就觉得没有必要与细菌做交易，会自己减少根瘤的形成。这就是为什么施了大量氮肥的大豆田里，根上几乎没有根瘤。

&nbsp;&nbsp;&nbsp;成熟期停止灌水也很重要。叶片开始变黄就要断水。此时水分过多，豆荚不易干，而已经干了的豆荚反复吸水再干，就会炸裂，使籽粒掉到地上。这称为落粒，收获期的雨水就是以这种方式吞噬产量的。

### 2-4. 每100g的营养

| 蛋白质 | 38.02g | 占热量的37.9%。在植物性食品中居首 |
| 脂肪 | 15-20g | 大部分为不饱和脂肪酸。含量高到可以榨油 |
| 碳水化合物 | 30-35g | 比谷物少，含有相当量的低聚糖 |
| 膳食纤维 | 约20g | 偏多。突然大量食用会导致腹胀 |
| 钙 | 约240mg | 在植物性食品中偏高 |
| 铁 | 约7mg | 没有肉类时的重要来源 |
| 钾 | 约1,800mg | 盐摄入增加时起平衡作用 |
| 叶酸 | 丰富 | 与贫血和胎儿发育有关 |
| 异黄酮·皂苷 | 含有 | 抗氧化物质 |

&nbsp;&nbsp;&nbsp;氨基酸组成需要单独来看。大豆蛋白富含赖氨酸。稻米、大麦、小麦、高粱、粟等谷物都缺赖氨酸，相反，大豆的蛋氨酸略显不足。两者恰好互补对方的缺口。米饭和豆子在同一餐里吃，蛋白质的利用率比各自单吃时明显提高。豆饭（kongbap）、豆浆冷面（kongguksu）、大酱汤配米饭，韩国的饮食就建立在这一原理之上。

&nbsp;&nbsp;&nbsp;铁和钙也值得记录。在肉类和乳制品消失的条件下，贫血和骨密度下降是数月内逐渐出现的现实威胁。每100g大豆含铁7mg、钙240mg，在植物性食品中属于较高的数值。不过，植酸会妨碍这两者的吸收，因此通过浸泡、发芽、发酵降低植酸的处理，在营养学上也有意义。第14节将讨论这个问题。

&nbsp;&nbsp;&nbsp;脂肪15-20%，在豆类中仅次于花生。它既是提高热量的因素，也是贮藏中酸败的风险因素。干大豆能存放3年，是指种皮完好、水分低的情况；磨成粉后，几个月就会出现酸败味。原则是粉只磨当次要吃的量。
