## はじめに
&nbsp;&nbsp;&nbsp;ダイズ(Glycine max)は、中国東北部と朝鮮半島一帯の野生の豆を数千年かけて人が改良したマメ科の一年草で、韓国の気候にいちばんよく合うタンパク質作物です。メジュ用の豆(メジュコン)と呼ばれ、テンジャン(みそ)・しょうゆ・豆腐の原料になります。乾燥したダイズは100g当たりタンパク質が38gで、熱量に対するタンパク質の比率は37.9%と、最低ラインの10%の3倍半を超えます。穀物に足りないリジンが豊富で、豆に足りないメチオニンは穀物にあるため、穀物とダイズを一緒に確保すればアミノ酸の組成が完成します。根粒菌で窒素を自分で取り込むため、スイスのDOK長期試験で肥料をまったく与えなかった区画の収量は慣行の63.4%でした(ジャガイモ18%、トウモロコシとコムギは40%台)。さらに、乾燥した子実が常温で3年もつ貯蔵性と、自家受粉で受け継がれる採種の安定性が加わります。総合等級はA(49.9点、有効183種中19位)で、短期B(47.3)、長期S(52.8)、副食はSS(65.1点)です。弱みは、面積当たりの熱量がCで1㎡に1,002kcal、自給ラインの0.38倍にとどまること、120-150日の栽培期間、霜が一度降りただけで枯れること、40%遮光で収量が半分に落ちること、8時間浸して1時間以上煮なければならないことです。

| 総合 | A | 49.9 |
| 短期 | B | 47.3 |
| 長期 | S | 52.8 |
| 副食 | SS | 65.1 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: タンパク質密度、施肥、施設の負担、貯蔵性。S: 微量栄養素、連作への適応性、合成資材を投入しない場合の収量維持率、味、国内での栽培の普及度、自家採種。A: 病害虫圧、収量の安定性、種子の寿命。B: 水の消費量、防除の自立度 |
| 弱み | E: 耐寒性。D: 永続性、日射、調理・加工の要求度。C: 面積当たりの熱量、収穫速度、温度幅、整地・掘削エネルギー、非食用の価値 |

> **ダイズの価値は、畑からとれる量ではなく、その量に含まれるタンパク質の質と、外から何も入ってこなくても循環が途切れない仕組みにあります。**

&nbsp;&nbsp;&nbsp;面積当たりの熱量Cがいちばん現実的な制約です。1日2,100kcalをダイズだけで満たすには524gを食べなければならないため、ダイズは、ジャガイモ・サツマイモ・穀物で熱量を立てて、その上にタンパク質を載せる、組み合わせの作物であり、畑の面積の20-30%を割り当てるのが、おおむね妥当です。日射Dのため、塀の陰、大木の下、北向きの斜面は避けます。調理・加工Dは安全の問題で、発酵させて醤を仕込めば、この負担は一度に解決します。非食用の価値Cに含まれる窒素固定には罠があります(第6節)。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | マメ科ダイズ属の一年草。東アジア原産で自家受粉。日が短くなると花を咲かせる短日植物 |
| 葉、茎 | 細かい毛に覆われた三出複葉。まっすぐ立ち、草丈60-100cmで枝分かれする |
| 根、花 | まっすぐな主根と細根に、玉のような根粒がつく。白色または淡い紫色の小さな花が7-8月に咲く |
| 莢、子実 | 莢は褐色で硬い毛に覆われ、種が2-4粒入る。子実は丸く、黄白色が基本で、黒色・褐色・緑色もある |

> **ダイズは、生育期間全体で使う水の約80%を、開花期から莢の肥大期の間に吸い上げます。この4週間に水が切れると、ほかのどの時期よりも収量が大きく崩れます。**

&nbsp;&nbsp;&nbsp;根粒は播種の3-4週間後にようやく窒素を渡し始めるので、元肥に少量の窒素を入れることに意味がありますが、土に窒素が十分にあると、植物は根粒の形成を自分で減らします。登熟期に過湿だと莢が乾かず、乾いた莢が濡れては乾くことを繰り返すとはじけて粒が落ちます(脱粒)。乾燥したダイズは100g当たり熱量401kcal、タンパク質38.02g、脂質15-20g(マメ類でラッカセイに次いで高い)、炭水化物30-35g、食物繊維約20g、カルシウム約240mg、鉄約7mgです。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽は10℃以上(適温25-30℃、10℃以下では種子が腐る)。生育15-35℃(適温20-25℃)。結実20-30℃で幅は10℃しかなく、35℃以上が数日続くと花と若い莢が落ちる。積算温度2,500℃以上。霜で枯れる。夜に光が当たる所は開花が遅れる |
| 土壌、水 | 排水のよい砂壌土-壌土(水はけの悪い土地が最も悪い)、pH5.5-7.5(適正6.0-6.5)、作期の蒸発散量450-700mm、地下水位50cm以下(適正80cm以下) |

> **ダイズのpHの要求は、植物自体よりも根粒菌の要求です。pH5.5を下回ると、豆はなんとか育ちますが、細菌が生きられず窒素固定が止まります。**

&nbsp;&nbsp;&nbsp;いちばん狭い関門は結実温度で、高温と乾燥が重なると、落花率が80%を超えることもあります。実際的な対応は、一度にすべてをまかず、2週間おきに2、3回に分けてまいて開花期を分散させることです。

| 区分 | 生育日数 | 播種 | 収穫 | 特徴 |
|:---|:---|:---|:---|:---|
| 早生種(早生ダイズ) | 100-120日 | 4-5月 | 7-8月 | 早くとれるが収量が少ない |
| 中生種 | 120-140日 | 5月下旬-6月上旬 | 10月上旬・中旬 | バランスがよい |
| 中晩生種(秋ダイズ) | 140-180日 | 5月下旬-6月下旬 | 10月下旬-11月 | 収量が最も多いが霜の危険がある |

&nbsp;&nbsp;&nbsp;早生種は、古い穀物が尽きて秋の収穫がまだ遠い7-8月を埋めるので、収量が少なくても価値があり、中晩生種は霜が早い年に登熟が終わらないおそれがあるため、分けてまくほうが安全です。品種選びの第一の基準は採種ができる在来種で、第二の基準は大きさの配分です。味噌や豆腐には大粒の中晩生種を使いつつ、もやし用の小粒種を必ず一部別に確保します。霜が早い地域では早生種か中生種を、人手が足りなければ倒伏に強い品種を選び、種を遠くから入手したなら、その品種が合わせて育成された緯度を確認します。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 畑の準備 | 畝の高さ20cm以上(水田は30cm以上)、排水溝の深さ50-80cm。酸性土には播種の3-4週間前に消石灰または苦土石灰200kg/1,000㎡でpH6.0-6.5に合わせる(焼いた貝殻・卵の殻の粉、木灰で代用する) |
| 施肥(1,000㎡) | 窒素3kg、リン酸3.4kg、カリウム3.4kg(全量元肥)。窒素を控えるのが技術で、多く与えると必ず収量が減り、追肥は不要。リン酸は骨粉・魚の骨から、カリウムは木灰(㎡当たり100-200gが上限)から得て、ホウ素が足りないと花が落ちるので、いろいろな材料を混ぜた堆肥を使う |
| 根粒の接種 | ダイズを育てて根粒がよくついた畑の、深さ5-15cmの土を、水で軽く湿らせた種子にまぶして、すぐにまく(野生のツルマメの根粒も同じ属なので使える)。消毒や殺菌剤と併せて行わない。リン酸の足りない畑は効率が落ち、マメ科を長く植えていない畑では接種が必須 |

&nbsp;&nbsp;&nbsp;根粒は、開花が始まるころ(播種後6-8週間)に、根を掘り上げて根粒を割って確認します。赤色なら窒素を固定しており、窒素欠乏の症状が見えたときにまずすべきことは、肥料を与えることではなく、根を掘り上げて見ることです。

| 播種 | 基準 |
|:---|:---|
| 時期 | 中部の単作は5月上旬-6月上旬(限界は6月下旬)、中部の二毛作(水田の裏作)は6月中旬-下旬、南部の単作は6月上旬-中旬(限界は7月中旬)、南部の二毛作は6月下旬-7月上旬。日が短くなることが開花の合図なので、7月中旬-下旬以降にまくと収穫量が大きく落ちる |
| 種子の準備 | 斑点・変色・虫食いの穴のある種子を選んで捨て、50-55℃の湯に10-15分浸して表面の病原菌を殺す(温度を超えると発芽力が落ちる) |
| 方法 | 深さ3-5cm(7cmを超えると出てこられない)、条間60-80cm、株間15-20cm(二毛作は10-15cm)。播種量は1,000㎡当たり小粒3-4kg、中粒5-6kg、大粒6-7kg。遅くまくほど株が小さく育つので密にまき、6月下旬は60-70cm×15cmにする。播種直後に鳥が子葉をついばむので、わらやネットで覆う |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から発芽まで | 土が完全に乾かないようにする(種子は自分の重さと同じだけ水を吸わないと発芽しない) |
| 開花期から莢の肥大期 | 土が乾かないように十分与える(全生育期間の水分の80%) |
| 登熟期 | 水を減らす |

| 管理 | 方法 |
|:---|:---|
| 間引き、草取り | 本葉1-2枚のとき、1か所に2本を残して弱い株を抜く。開花前の最後の草取りの後は畑に入らない |
| 土寄せ | 播種後30-40日、第1本葉の節まで、株元に土をかき寄せる。倒伏防止、根の発達促進、排水の改善、雑草の埋没の効果がある、ダイズ栽培でいちばん効率の高い一度の作業 |
| 摘心 | 本葉5-7枚のとき、必ず開花前に、茎の先の生長点を手で摘み取ると、側枝が増えて莢の数が増える。花が咲いた後に摘むと収量が減り、肥料が十分で雨が多く徒長しそうな条件でだけ行い、やせた畑の生育不良の豆には行わない |
| 倒伏 | 倒れると収穫の手間が何倍にもなり莢が腐るので、株間を守って土寄せをし、台風のときは畑の周りに綱を張って支える |

## 6. 病害虫と養分の問題
| 病害虫 | 症状と条件 | 薬を使わない防除 |
|:---|:---|:---|
| ダイズモザイク病 | 葉がモザイク模様にまだらになり、子実に褐色の斑点。アブラムシが媒介する | 治療不可。見つけたらすぐに抜いて焼き、斑点のある種子は種として使わない |
| 斑点細菌病、炭疽病、べと病 | 葉の角張った褐色の斑点 / 茎と莢の黒い潰瘍 / 葉の裏の灰白色のカビ。多湿 | ボルドー液、種子の選別と輪作、株間の確保と排水 |
| 紫斑病 | 子実の表面が紫色にまだらになる。種子伝染 | まだらの種子を念入りに選り分け、温湯消毒 |
| 菌核病、根腐病、センチュウ | 茎が軟らかくなり白い菌糸と黒い粒ができる / 根が腐る / 根がこぶ状に変形する。涼しく湿っているとき、過湿、連作 | 4年以上の輪作、病気の株は土ごと掘って焼く、排水と畝を高くすること、マリーゴールドとの混植 |
| カメムシ類 | 莢を刺して汁を吸い、しいなにする最大の害虫 | 露のある早朝は動きが鈍いので、莢の下を揺すって水桶に落として捕り、畑の周りのゴマ・アワ・モロコシの誘引作物に集めて捕り、早生種で晩夏より前に登熟を終える |
| アブラムシ、マメシンクイガ、ハスモンヨトウ | 汁を吸ってウイルスを媒介する / 幼虫が莢の中の子実を食べる / 葉と莢をむさぼり食う | 石けん水(水1Lに石けん5g)、早まきと早どり、手で捕って卵塊を取る |

&nbsp;&nbsp;&nbsp;ボルドー液は、水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜ、すぐに使います。

| 症状 | 原因と対処 |
|:---|:---|
| 下の葉から淡い黄色になり、株が小さい | 窒素欠乏(根粒の不良が最も多い原因)。根を掘り上げて根粒を確認し、なければその年は尿の10倍希釈液を少量与えて、翌年の接種を確実に行う |
| 花が咲いても莢がつかない | ホウ素欠乏、または開花期の高温・乾燥。いろいろな材料を混ぜた堆肥、灌水とマルチングで温度を下げる |

&nbsp;&nbsp;&nbsp;「豆を植えると土がよくなる」という言葉は、条件つきの真実です。250kgの子実には窒素が約15kg(1ヘクタール当たり150kg)含まれており、同じ重さのトウモロコシの子実より4.5倍多く、根粒が固定する窒素は、1ヘクタール当たり条件がよければ100-150kg、悪ければ30-60kgで、子実として持ち出される窒素は130-160kgです。茎と葉に25-40kg、根と根粒に10-20kgが残るので、子実だけを収穫して茎葉を戻せば収支はほぼ釣り合いますが、豆がらを焼いたり飼料として持ち出したりすれば確実な赤字です。そのため、豆がら・葉・莢の殻をすべて畑に戻し、根は掘り上げず、豆がらは20-30cmに切ってかぶせ、家畜に与えたなら、その糞尿をその畑に入れます。焼くと窒素が飛ぶので、灰は必ずその畑に戻します。

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | トウモロコシ・モロコシ(豆が固定した窒素の一部をそばで受け取り、背丈の差で光を分け合う)、ジャガイモ(病害が重ならず、養分の要求が違う)、キャベツ・ハクサイ類(豆の後に植えて残った窒素を使う) |
| 悪い | トマト・トウガラシ・ナス(同じ畑で病害虫を共有する)、ニンニク・タマネギのようなネギ類(硫黄化合物が根粒菌を抑えるという報告があり、離して配置する) |

&nbsp;&nbsp;&nbsp;トウモロコシと混ぜるときは、トウモロコシ2条に豆2条を交互に配置し、トウモロコシの条を南北に立てて日陰を避けます。ダイズの連作への適応性はSで1年休作群ですが、センチュウと根腐病がたまるので、マメ科を続けて植えません。4年輪作の例は、ダイズ → 葉物野菜またはネギ類(豆が残した窒素を使う) → 穀物またはいも類 → 根菜または緑肥です。畑が狭いときは、4区画に分けて毎年1区画ずつ移すか、豆の条の位置を毎年変えます。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 葉が黄色くなってほとんど落ち、畑で振ると莢の中で粒がぶつかる音がするとき。早すぎると粒がしわしわになり、遅すぎると脱粒でほぼ3割を失う。雨の知らせがあれば、完熟を待たずに収穫する |
| 要領 | 晴れて乾いた日の、露が乾いた午前10時以降に、茎の根元を鎌で刈り、根は残す。つるして乾かした後に脱穀する |
| 脱穀、選別 | 乾いた豆がらを袋に入れて踏むか、むしろに薄く広げて殻竿でたたくか、棒でたたくか、桶の内側の壁に打ちつけて脱穀する(乾燥が鍵)。唐箕がけは、風が一定の早朝か日暮れに細く流し落として2、3回行う。水に浮かせてしいなや虫食いの粒をすくい取り、必ず乾かし直す |

| 採種 | 基準 |
|:---|:---|
| 選抜、分離 | 病気の症状がなく、莢が多くつき、倒れていない株を畑であらかじめ印をつけ(糸を結んでおく)、食用の豆と混ざらないように別に脱穀する。自家受粉なので隔離は不要 |
| 保管 | 水分12-13%に乾燥させて密閉容器に入れ、涼しく暗い所に置く。発芽率は収穫した年が90%以上、1年後80-90%、2年後60-80%、3年後40-60%で、4年目以降は急落するため、毎年新しく採って使い、古いものは予備にする。古い種子は発芽試験をして、半分なら播種量を2倍に増やし、30%を下回れば食べる |
| 更新 | 紫斑病・炭疽病・モザイク病が種子を通じてたまるので、斑点のある種子を除き、3-4年ごとに別の場所から種子を入手して一部を混ぜる |

## 9. 貯蔵
| 段階 | 方法 |
|:---|:---|
| 乾燥 | 豆がらごと畑や軒下で1-2日予備乾燥する。瓶に乾いた塩と豆を一緒に入れて振り、塩が瓶の壁につけばまだ湿っている。かんで歯が入らずぱきっと割れれば適正 |
| ゾウムシ防除 | 畑の莢にすでに卵がつくので、適期に収穫する。完全な密閉が最も確実で、容器をいっぱいに満たして小さな容器いくつかに分ければ、3-4週間で卵と幼虫まで死ぬ。ふるった木灰を体積の2-5%混ぜる(食べる前にすすぐ)。豆1kgに食用油2-5mLをもみ込む(半年以内に食べる分だけ、種子用は除く) |
| 環境、点検 | 15℃以下、空気の湿度65%以下。容器に耳を当てて、かさかさという音、かび臭いにおい、小さく丸い穴を確認する |

> **豆は腐って失うのではなく、虫に食われて失います。貯蔵の技術は、すなわち虫を防ぐ技術です。**

## 10. 調理と注意事項
| 成分 | 作用 | 除去 |
|:---|:---|:---|
| トリプシンインヒビター | タンパク質分解酵素を妨げ、腹痛・嘔吐・下痢とタンパク質の利用率の低下 | 8時間浸した後、100℃で30-60分以上加熱 |
| レクチン | 腸の粘膜に付着して吸収を妨げ、赤血球を凝集させて激しい腹痛・嘔吐・下痢 | 浸した後、100℃で10-30分以上加熱 |
| フィチン酸 | 鉄・亜鉛・カルシウム・マグネシウムの吸収を妨げる | 浸水・発芽・発酵で60-80%減少 |

> **生煮えの豆が生豆より危険な場合があります。さっとゆでると細胞壁が壊れて吸収はよくなりますが、インヒビターとレクチンは残っているからです。加熱するときは中途半端に止めず、最後まで火を通します。**

&nbsp;&nbsp;&nbsp;乾燥した豆は表面が固く、浸さずにゆでると中が生煮えになって最も危険で、ダイズのレクチンはインゲンマメ類より弱いものの、ぐらぐら煮えた湯で十分に煮ることが唯一の安全な方法です。

| 調理 | 方法 |
|:---|:---|
| 基本 | 室温の水に8時間浸す(夏は水を替えながら6時間)。100℃の蒸気で60-90分蒸すか、圧力調理で120℃で15-20分(燃料が最も少なくてすむ)。親指と人さし指で押して簡単につぶれれば煮えている |
| 燃料の節約 | 15分以上煮た後、火を消して、わらやもみ殻の箱や布団で包んで2-3時間置く(芯が残っていればもう一度煮る)。乾燥した豆を弱火で20-30分炒めるとインヒビターがかなり減り、そのまま食べられる。炒って挽いた豆の粉は密閉して2-3か月 |
| もやし | 乾燥した豆にはビタミンCがないため、小粒種を6-8時間浸して光を遮り、20-25℃で育てると100gが400-500gになり、冬のビタミンCの供給源になる |
| 醤作り | メジュは、豆をゆでてつぶして固めた塊をわらに包んで1か月以上発酵させたもので、テンジャン(みそ)としょうゆは塩水で数か月熟成させて数年保存できる。チョングッチャンは、ゆでた豆をわらに包んで約40℃で2-3日置く、最も早い発酵豆。豆腐は浸した豆を挽いて煮て、こしてにがりで固めた、最も消化しやすい形 |

&nbsp;&nbsp;&nbsp;発酵は、微生物がインヒビターとレクチンをアミノ酸に分解し、フィチン酸を分解して抗栄養成分をなくす、最も根本的な方法で、醤を仕込むことは、豆をゆでる1時間の燃料を1年分についてたった一度払うだけで、塩とともに数年もちます。

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵した豆の点検、種子の発芽試験、道具の手入れ。2月に畑の計画、堆肥の切り返し、醤を仕込む準備 |
| 3-4月 | 3月に石灰の散布(播種の3-4週間前)、堆肥の仕上げ、メジュの発酵 |
| 5-6月 | 5月に種子の選別、温湯消毒、早生種の播種、接種用の土の確保。6月に本播種(中部は上旬、南部は中旬-下旬)、鳥よけ、1回目の草取り、2週間おきに分けてまいて開花期を分散 |
| 7-8月 | 7月に間引き、草取り、土寄せ、摘心、根粒の確認。8月に開花と莢の肥大、集中灌水、早朝のカメムシ捕り |
| 9-10月 | 9月に登熟の管理、灌水の中止、採種株の印付け。10月に収穫、予備乾燥、つるして乾かす、脱穀(雨の知らせがあれば完熟を待たない) |
| 11-12月 | 11月に選別、乾燥、貯蔵、茎葉のすき込み(豆がらを切って畑にかぶせ、焼かない)、メジュ作り。12月に醤の仕込み、貯蔵の点検、もやし作り |

> **ダイズは、窒素を1,000㎡当たり3kgより多く与えず、開花期に根を掘り上げて根粒の赤色を確認し、開花期から莢の肥大期までの4週間に水を与え、収穫後に豆がらを畑に戻すとき、その値打ちを発揮します。**
