## 14. 毒性与抗营养成分

&nbsp;&nbsp;&nbsp;大豆煮熟后是安全的，生吃则有危险。豆科植物的种子为了不被吃掉，含有化学防御物质，这些物质会妨碍人的消化。幸运的是，它们大多不耐热，充分加热就会被破坏，问题在于“充分”这个标准比想象的要高。

### 14-1. 抗营养成分的真面目

| 成分 | 作用 | 症状 | 去除方法 |
|---|---|---|---|
| 胰蛋白酶抑制剂 | 抑制蛋白质分解酶胰蛋白酶的作用 | 腹痛、呕吐、腹泻，蛋白质利用率降低，增加胰腺负担 | 浸泡8小时后，在100℃下加热30-60分钟以上 |
| 凝集素（血凝素） | 附着在肠黏膜的糖链上，妨碍吸收，并使红细胞凝集 | 剧烈腹痛、呕吐、腹泻 | 浸泡后在100℃下加热10-30分钟以上 |
| 植酸 | 与铁、锌、钙、镁结合，阻碍吸收 | 长期食用会导致贫血、缺锌 | 通过浸泡、发芽、发酵可降低60-80% |
| 皂苷 | 起泡沫，刺激胃肠 | 少量无害，多了会觉得胃里难受 | 浸泡后煮时撇去泡沫 |
| 低聚糖（棉子糖·水苏糖） | 人体无法消化，由肠道细菌发酵 | 肚子里胀气 | 浸泡后倒掉浸泡水。发酵可大幅减少 |
| 致甲状腺肿物质 | 妨碍碘的利用 | 在缺碘的饮食中增加甲状腺负担 | 加热可减少。同时吃海藻类可以抵消 |

> **没煮透的豆子有时比生豆子更危险。稍微焯一下，细胞壁被破坏，吸收变好，但抑制剂和凝集素还在。加热时不要半途而废，要一直煮透。**

&nbsp;&nbsp;&nbsp;凝集素的危险性因豆类品种而异，差别很大。大豆的凝集素毒性比菜豆类（Phaseolus）的凝集素弱。菜豆生的只吃4、5粒，几小时内就会出现严重的呕吐和腹泻，因煮得不熟的菜豆引起的食物中毒已有多次报告。尤其是菜豆类，有一个温度区间，用较低的温度长时间加热，凝集素活性反而会升高，所以在温水中长时间放置的烹饪方式最危险。大豆没有那么极端，但原则相同：在滚开的水中充分加热，这是唯一安全的办法。

### 14-2. 浸泡与加热的标准

| 处理 | 时间·温度 | 效果 |
|---|---|---|
| 浸泡 | 常温水中8小时（夏季边换水边泡6小时） | 热能传到豆心。低聚糖和部分皂苷会溶入水中 |
| 倒掉浸泡水 | 务必 | 溶入水中的低聚糖和抗营养成分一并倒掉 |
| 煮 | 在滚开的水中煮60分钟以上 | 胰蛋白酶抑制剂和凝集素被灭活 |
| 蒸 | 100℃蒸汽蒸60-90分钟 | 养分损失比煮少 |
| 压力烹饪 | 120℃，15-20分钟 | 燃料消耗最少 |
| 检查是否煮熟 | 用拇指和食指一捏就容易捏烂 | 如果还留有硬芯，就说明没煮透 |

&nbsp;&nbsp;&nbsp;干豆表皮坚硬，热量不容易传到豆心。不泡就煮，只有表层熟了，里面还是生的，这种状态最危险。而且要多耗2倍以上的燃料。浸泡水不能喝，也不能用来烹饪，但拿去浇田或洗碗，就不算浪费。

&nbsp;&nbsp;&nbsp;夏季气温高，8小时内水会变质，豆子会变得黏滑。每隔3到4小时换一次水，或者傍晚泡上、早上捞出，把浸泡时间挪到夜里。

### 14-3. 发芽与发酵

| 方法 | 减少的成分 | 程度 |
|---|---|---|
| 发芽（黄豆芽） | 植酸、胰蛋白酶抑制剂、低聚糖 | 植酸减少50-70%，抑制剂减少30-40% |
| 发酵（大酱·酱油·清麴酱） | 植酸、胰蛋白酶抑制剂、低聚糖、凝集素 | 大部分被分解，吸收率提高 |
| 仅浸泡 | 低聚糖、部分植酸 | 减少20-30% |

&nbsp;&nbsp;&nbsp;发酵是从根本上解决抗营养成分问题的方法。微生物把抑制剂和凝集素这类蛋白质分解成氨基酸，并分泌分解植酸的酶。结果，抗营养成分消失，吸收率比煮豆还要高。东亚地区发展出发酵吃豆的方式，不仅是为了味道，也是因为这种生理上的益处。

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;大豆的耐储性为SS。在FAO食品损失指数中，贮藏阶段损失率的中位数为0.25%，是这张作物表中最低的数值之一，干豆在常温下可以保存3年。然而，条件一旦失当，只要一种豆象，就能把储存的豆子全部变成空壳。

> **豆子不是因为腐烂而损失，而是因为被虫吃掉而损失。贮藏的技术，说到底就是防虫的技术。**

### 15-1. 首先要干燥

| 阶段 | 方法 | 确认 |
|---|---|---|
| 预干燥 | 连豆秸在田里或屋檐下晾一到两天 | 豆荚完全干透 |
| 脱粒后干燥 | 摊在草席或席子上，薄薄一层，在太阳下晒2-3天 | 经常翻动，使其均匀干燥 |
| 目标含水量 | 食用12-13%，种子12% | 用牙咬时咬不进去，会“啪”地裂开 |
| 盐试验 | 把干盐和豆子一起装进瓶里摇晃 | 盐粘在瓶壁上，说明豆子还潮 |
| 放凉 | 从阳光下收回后，完全放凉再装容器 | 趁热密封会产生结露 |

&nbsp;&nbsp;&nbsp;干燥不足，后面所有的对策都会落空。含水量超过15%，霉菌就会生长；超过13%，豆象的繁殖就会加快。反过来，低于10%，种皮会开裂，在贮藏中碎裂，如果是种子用，发芽力会下降。

&nbsp;&nbsp;&nbsp;咬着检验的方法最实用。用门牙咬时，牙齿哪怕稍微咬进去一点，就说明还没干透；“咔”的一声裂成两半，就说明干透了。盐试验也很简单。在干燥的瓶子里放一把豆子和一勺炒过的盐，摇晃后放几分钟，如果盐粘在瓶壁上，就还需要继续晒。

### 15-2. 贮藏期间豆象的防治

&nbsp;&nbsp;&nbsp;豆象（包括红小豆象、绿豆象在内的Callosobruchus属）是贮藏豆类的最大威胁。可怕之处在于，它从田里就已经开始了。成虫把卵产在还长在田里的豆荚上，这些卵在仓库里孵化，钻进豆子里。这是一种入库时就已经带着卵进来的方式，而且一个世代用不了1个月，半年之内，一袋豆子就会被虫蛀的空壳和粉末填满。

| 方法 | 原理 | 应用 | 效果 |
|---|---|---|---|
| 完全密封 | 切断氧气，使其窒息 | 把玻璃瓶或金属罐装满后封口 | 最可靠。3-4周内连卵和幼虫都会死亡 |
| 拌草木灰 | 细微颗粒刮破外骨骼的蜡质层，使其脱水 | 拌入相当于豆子体积2-5%的灰 | 食用前用水冲洗掉 |
| 硅藻土 | 硅质外壳损伤外骨骼 | 每1kg豆子用1-3g | 比草木灰更有效。只在干燥状态下起作用 |
| 涂油 | 油膜阻碍产卵和孵化 | 每1kg豆子加2-5mL食用油，揉匀 | 对豆类效果大。种子用不要使用 |
| 低温处理 | 零下温度能杀死卵和幼虫 | 隆冬把豆子放在室外几天后收回 | 再次收回时要注意结露 |
| 高温处理 | 60度能杀死卵和幼虫 | 在阳光下摊薄，放半天 | 种子用不要使用 |
| 干辣椒·花椒·艾草 | 精油成分抑制产卵 | 一层层夹放 | 辅助手段 |
| 木炭·炒盐 | 吸收湿气 | 用布包好放入 | 兼有预防霉菌的作用 |
| 埋入灰中 | 同时获得密封和物理防治效果 | 在陶缸里一层灰一层豆子地码放 | 传统上被广泛使用 |

&nbsp;&nbsp;&nbsp;最重要的是完全密封。虫子也要呼吸。在密封的容器里，豆子和虫子消耗氧气，氧气减少、二氧化碳上升，虫子就会死亡。豆子处于休眠状态，能耐受这样的条件。容器装得越满、空隙越少，见效越快。与其用一个大桶，不如用几个小桶装得满满的，这样还有一个好处，就是一桶坏了也不会全部损失。

&nbsp;&nbsp;&nbsp;涂油特别适合豆类贮藏。每1kg豆子加2-3ml食用油，也就是半小勺左右，用手揉匀，让每一粒豆子表面都形成一层薄膜。油膜使成虫难以产卵，并堵住已产下的卵的气孔，妨碍孵化。这是印度和非洲的小农户长期使用的方法。不过，油一旦酸败就会发臭，所以只用于半年内要吃掉的那一部分，不用于种子，因为油膜会妨碍呼吸，使发芽力下降。

&nbsp;&nbsp;&nbsp;草木灰只挑细的使用。先过筛，筛掉粗的炭块，只取细的部分，按豆子体积的2-5%拌入，让每一粒豆子表面都薄薄地裹上一层。吃的时候用水冲洗3、4遍就干净了。虫子不会产生抗性，对人体也无害。

### 15-3. 贮藏容器与场所

| 容器 | 密封性 | 期限 | 优点 | 缺点 |
|---|:---:|---|---|---|
| 玻璃瓶 | 很好 | 3年以上 | 可以用眼睛确认状态 | 容量小，不能遮光 |
| 金属罐 | 很好 | 3年以上 | 完全防鼠防虫 | 结露后，那个位置会变质 |
| 陶缸 | 好 | 2-3年 | 温度变化慢，老鼠咬不穿 | 沉重且易碎 |
| 厚塑料袋 | 一般 | 1-2年 | 轻便、便宜 | 老鼠会咬穿 |
| 地下贮藏窖 | 好 | 2-3年 | 温度恒定且低 | 一旦渗水，会全部损失 |

| 保管场所条件 | 目标 |
|---|---|
| 温度·湿度 | 15℃以下，空气湿度65%以下 |
| 光 | 完全遮光 |
| 位置 | 地下室或朝北的房间，不直接接触地面，放在垫架上 |
| 检查 | 每2个月一次 |

&nbsp;&nbsp;&nbsp;检查时最可靠的感官是听觉和嗅觉。把耳朵贴在桶上，如果听到沙沙声，就说明虫子在活动；如果闻到潮湿的气味，就说明霉菌开始生长了。如果在豆子表面看到小而圆的孔，说明豆象已经繁殖过一代。即使到了这时，只要把全部豆子取出来晒干，放入水中捞掉空壳粒，再拌入草木灰或油后重新密封，也能保住剩下的部分。

## 16. 烹饪与加工

### 16-1. 黄豆芽 - 冬天的维生素C

&nbsp;&nbsp;&nbsp;干豆里实际上没有维生素C。可是一旦让它发芽，原本没有的维生素C就会生成。这是因为发芽这一生理转变发生时，植物会重新合成。冬天完全没有新鲜蔬菜的时候，只要有一把干豆、水和一个黑暗的地方，3、4天就能得到新鲜蔬菜。既不需要田地，也不需要阳光和土壤。

&nbsp;&nbsp;&nbsp;维生素C缺乏会在几个月里悄悄发展，最后表现为牙龈出血、伤口不愈合、浑身乏力等症状。这就是大航海时代的水手们患过的那种病，在只靠储存食物度过漫长冬季的社会里一再出现。黄豆芽就是解决这个问题的廉价而可靠的答案。

| 步骤 | 内容 | 要点 |
|---|---|---|
| 1. 选豆 | 小粒种为佳。破碎或虫蛀的豆子要丢掉 | 破碎的豆子会腐烂，坏掉整批 |
| 2. 清洗 | 多冲洗几次，捞掉浮起来的 | 浮起来的多半是死豆 |
| 3. 浸泡 | 在温水中浸泡6-8小时 | 豆子要膨胀到原来的2倍 |
| 4. 装容器 | 放进能漏水的容器或siru（底部有孔的陶盆），盖上湿布 | 积水就会腐烂 |
| 5. 避光放置 | 完全遮光。20-25℃为宜 | 见光会变绿并变老变硬 |
| 6. 浇水 | 每天3-4次，从上方充分浇下，让水流走 | 兼有调节温度和冲走代谢废物的作用 |
| 7. 收获 | 4-7天，长度5-10cm | 在根变成褐色之前收获 |

| 条件 | 结果 |
|---|---|
| 见光 | 豆芽头变绿，茎变老变硬 |
| 浇水少 | 根上长出很多须根，变老变硬 |
| 积水 | 从下面开始腐烂并发臭 |
| 温度超过30度 | 长得快，但组织柔软，容易变质 |
| 温度低于15度 | 生长非常缓慢 |
| 压上重物 | 茎变粗，变得饱满 |

&nbsp;&nbsp;&nbsp;浇水几乎就是培育黄豆芽的全部。水提供水分，带走发芽过程中产生的热量，冲走积累的代谢废物。每天3到4次，从上方充分浇下并让水完全流净；夏季增加次数，冬季使用温水。须根长得多，说明水不够。

&nbsp;&nbsp;&nbsp;没有siru的话，就用底部凿了孔的陶缸或桶、孔眼细密的筛盘、凿了孔的盆。下面放接水盘，上面盖上黑布，它就成了siru。重要的只有两点：能让水流走的结构，以及遮光。

&nbsp;&nbsp;&nbsp;100g干豆能长成400g到500g黄豆芽。增加的重量大部分是水，所以热量并不增加，但会新生成维生素C，植酸和胰蛋白酶抑制剂减少，部分蛋白质也被分解成易于消化的形态。黄豆芽同样不能生吃，要焯水或炒着吃，这是因为还残留着抑制剂。

### 16-2. 做酱 - 预付燃料的贮藏

| 加工品 | 步骤概要 | 保存 | 价值 |
|---|---|---|---|
| 酱曲（meju） | 把豆子煮烂捣碎，捏成块，用稻草包起来发酵1个月以上 | 晒干后整个冬天备用 | 大酱和酱油的原料 |
| 大酱 | 把发酵好的酱曲捣碎，与盐水混合，熟成几个月 | 几年 | 兼作蛋白质储存和调味料 |
| 酱油 | 把酱曲泡在浓盐水里放几个月，取出浸出的液体煎煮 | 几年 | 氨基酸来源 |
| 清麴酱 | 把煮熟的豆子用稻草包起来，在40℃左右放2-3天 | 几天，晒干可存几个月 | 最快的发酵豆 |
| 豆腐 | 把泡好的豆子磨碎煮沸、过滤，用卤水凝固 | 几天 | 最容易消化 |
| 豆油 | 炒熟捣碎后压榨 | 几个月 | 出油率低 |
| 炒豆粉 | 炒熟后捣碎 | 密封2-3个月 | 无需烹饪燃料 |

&nbsp;&nbsp;&nbsp;在灾害情境下，做酱的价值有三层。第一，抗营养成分被彻底分解，吸收率提高。第二，一旦酿下之后，往后几乎不再需要烹饪燃料。相当于只为煮豆的1个小时燃料，对一整年的量只付一次。第三，与盐一起贮藏，可以存放好几年。

&nbsp;&nbsp;&nbsp;清麴酱是最快能得到的发酵豆。把煮熟的豆子用稻草包起来，放在温暖的地方2、3天，稻草上的细菌繁殖，就会拉出丝来。不像酱曲那样要等1个月，也不需要盐。气味酸中带香就是成功了；如果有腐臭味，或看到黑色霉菌，就要丢掉。

&nbsp;&nbsp;&nbsp;豆腐是最易消化的形态。纤维和低聚糖被滤掉，所以不会胀气，适合老人、孩子和病人食用。剩下的豆腐渣也不要扔，可以做成韩式炖菜（jjigae）吃，或晒干备用。凝固所需的卤水，是把日晒盐堆放时渗出的苦水；没有的话，可以把海水煮浓后使用，也可以用少量醋。

### 16-3. 节省燃料的烹饪

| 方法 | 燃料 | 步骤 |
|---|:---:|---|
| 压力烹饪 | 最少 | 把泡好的豆子加压15-20分钟 |
| 余热烹饪 | 很少 | 煮10-15分钟后熄火，用装有稻草、稻壳的箱子或被子包住，放2-3小时 |
| 炒豆粉 | 几乎不需要 | 事先炒熟捣碎备好，用水冲调食用 |
| 炒豆 | 少 | 把干豆用小火翻炒。20-30分钟后，抑制剂大幅减少 |
| 发酵（酱类） | 预付 | 酿一次之后，往后不再需要燃料 |
| 黄豆芽 | 无 | 发芽不需要热量 |

&nbsp;&nbsp;&nbsp;余热烹饪对大豆的效果特别大。只煮10-15分钟，然后放进保温箱，内部温度能在2个多小时里保持在80℃以上，烹饪因而得以继续。不过，80度可能不足以彻底破坏凝集素和胰蛋白酶抑制剂，所以最初煮的时间要保证在15分钟以上，取出后检查豆子是否能用手指轻松捏烂。如果还有硬芯，就要再煮。

&nbsp;&nbsp;&nbsp;炒豆是没有条件做饭时的解决办法。把干豆放进烧热的锅里，用小火边炒边翻20-30分钟，会散发出香味，这种干热处理能使胰蛋白酶抑制剂大幅减少，可以直接食用。不过，不如煮熟的那么彻底，所以不要长期把它当主食。炒后捣碎的豆粉，用水冲调即可食用，与谷物粉混合后，氨基酸组成就完整了。

## 17. 全年作业日程

| 月份 | 作业 | 要点 |
|---|---|---|
| 1月 | 检查储存的豆子、种子发芽试验、保养工具 | 把耳朵贴在桶上，确认有没有虫声 |
| 2月 | 规划田块、翻堆堆肥、准备做酱 | 确认轮作顺序和陈种子的发芽率 |
| 3月 | 撒石灰、堆肥收尾、发酵酱曲 | 石灰要在播种前3-4周施入 |
| 4月 | 翻耕、起垄、开排水沟、施基肥 | 考虑到韩国的梅雨季（6月下旬至7月），要把排水沟挖深 |
| 5月 | 种子筛选、温水消毒、播种早熟种、备好接种源土壤 | 提前把种过大豆的田土取好 |
| 6月 | 正式播种（韩国中部在上旬，韩国南部在中下旬）、防鸟、第一次除草 | 每隔2周分批播种，使花期分散 |
| 7月 | 间苗、除草、培土、摘心、检查根瘤 | 开花前摘心，并挖出根掰开根瘤查看 |
| 8月 | 开花与豆荚膨大、集中灌溉、捕杀蝽 | 这一时期的水分决定产量。清晨捕蝽 |
| 9月 | 灌浆成熟期管理、停止灌溉、标记留种植株 | 给好的植株系上线 |
| 10月 | 收获、预干燥、挂晒、脱粒 | 有下雨消息就不要等完全成熟 |
| 11月 | 清选、干燥、贮藏、茎叶还田、煮豆做酱曲 | 把豆秸切碎覆盖在田里。不要焚烧 |
| 12月 | 做酱、检查贮藏、发黄豆芽 | 用黄豆芽获得冬季的维生素C |

### 17-1. 不可忘记的五件事

| 项目 | 内容 |
|---|---|
| 氮 | 施得多，产量必然下降。不要超过3kg/1,000㎡ |
| 根瘤 | 花期挖出根，掰开根瘤确认是否呈红色。这是大豆种植的仪表盘 |
| 茎叶 | 如果不把豆秸、叶片和根还回田里，大豆就成了掠夺土地养分的作物 |
| 水 | 从开花期到豆荚膨大期的这4周，决定了80%的产量 |
| 加热 | 泡8小时，煮1小时以上。没煮透的豆子可能更危险 |
