## 引言
&nbsp;&nbsp;&nbsp;大豆（Glycine max）是人们把中国东北部和朝鲜半岛一带的野生豆子经数千年驯化而成的豆科一年生草本植物，是最适合韩国气候的蛋白质作物。在韩国被称为“酱曲豆”，是大酱、酱油和豆腐的原料。干大豆每100g含蛋白质38g，蛋白质占热量的比例为37.9%，超过最低线10%的三倍半。谷物缺少的赖氨酸大豆很充足，豆类缺少的蛋氨酸谷物里有，所以同时备好谷物和大豆，氨基酸组成就齐全了。它靠根瘤菌自己固氮，在瑞士DOK长期试验中，完全不施肥的小区产量是常规的63.4%（土豆18%，玉米和小麦40%多）。再加上干籽粒常温下可保存3年的耐储性，以及靠自花授粉延续的留种稳定性。综合等级为A（49.9分，有效183种中第19位），短期B（47.3）、长期S（52.8）、副食SS（65.1分）。弱点是单位面积热量为C，每1㎡ 1,002kcal，只有自给线的0.38倍；生长期长达120-150天；遇一次霜就死；遮光40%时产量减半；必须浸泡8小时、煮一个多小时。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | A | 49.9 |
| 短期 | B | 47.3 |
| 长期 | S | 52.8 |
| 副食 | SS | 65.1 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：蛋白质密度、施肥、设施负担、耐储性。S：微量营养素、连作适应性、无合成投入产量保持率、口味、国内种植普及度、自留种。A：病虫害压力、产量稳定性、种子寿命。B：水消耗量、防治自立度 |
| 劣势 | E：耐寒性。D：持续性、光照、烹调·加工要求度。C：单位面积热量、收获速度、温度幅度、整地·挖掘能量、非食用价值 |

> **大豆的价值不在于田里收的量，而在于这些量里蛋白质的质量，以及外面什么都不进来循环也不会中断的结构。**

&nbsp;&nbsp;&nbsp;单位面积热量C是最现实的制约。每天2,100kcal光靠大豆要吃524g，所以大豆是个搭档作物：用土豆、甘薯、谷物来撑起热量，再在上面加上蛋白质，分给它田地面积的20-30%一般比较合理。因为光照D，要避开围墙的阴影、大树下和朝北的坡面。烹调·加工D是安全问题，发酵做酱可以一次性解决这个负担。非食用价值C里包含的固氮有个陷阱（第6节）。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 豆科大豆属一年生草本。原产东亚，自花授粉。是日照变短时开花的短日植物 |
| 叶、茎 | 覆盖细毛的三出复叶。直立，株高60-100cm，会分枝 |
| 根、花 | 直立主根和须根上带珠子般的根瘤。白色或浅紫色小花在7-8月开放 |
| 荚、籽粒 | 荚为褐色，覆盖硬毛，内含2-4粒种子。籽粒圆形，以黄白色为主，也有黑色、褐色、绿色 |

> **大豆整个生长期用水量的大约80%是在开花期到荚膨大期之间吸收的。这4周如果断水，产量比任何其他时期都崩得厉害。**

&nbsp;&nbsp;&nbsp;根瘤在播种3-4周之后才开始提供氮，所以基肥中加入少量氮是有意义的，但土里氮充足时，植株会自己减少根瘤的形成。成熟期过湿，荚就不干，干荚反复湿了又干会裂开，籽粒掉落（炸荚）。干大豆每100g含热量401kcal、蛋白质38.02g、脂肪15-20g（豆类中仅次于花生）、碳水化合物30-35g、膳食纤维约20g、钙约240mg、铁约7mg。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽10℃以上（适温25-30℃，10℃以下种子会烂）。生长15-35℃（适温20-25℃）。结实20-30℃，幅度只有10℃，35℃以上持续几天，花和幼荚就会脱落。积温2,500℃以上。遇霜死亡。夜里有光照的地方开花推迟 |
| 土壤、水 | 排水良好的沙壤土-壤土（排水不良的地最差），pH 5.5-7.5（适宜6.0-6.5），作期蒸散量450-700mm，地下水位50cm以下（适宜80cm以下） |

> **大豆对pH的要求，是根瘤菌的要求，而不是植株本身的要求。pH降到5.5以下，豆子勉强还能长，但细菌无法生存，固氮就会停止。**

&nbsp;&nbsp;&nbsp;最窄的一道关是结实温度，高温和干旱叠加时，落花率可能超过80%。实际的应对办法是不要一次种完，而是每隔2周分两三次播种，把花期错开。

| 类型 | 生育天数 | 播种 | 收获 | 特点 |
|:---|:---|:---|:---|:---|
| 早熟种（早熟大豆） | 100-120天 | 4-5月 | 7-8月 | 收得早，产量少 |
| 中熟种 | 120-140天 | 5月下旬-6月上旬 | 10月上旬·中旬 | 均衡 |
| 中晚熟种（秋大豆） | 140-180天 | 5月下旬-6月下旬 | 10月下旬-11月 | 产量最高，但有霜冻风险 |

&nbsp;&nbsp;&nbsp;早熟种填补陈粮耗尽、秋收尚远的7-8月，所以产量少也有价值，中晚熟种在霜来得早的年份可能灌浆不完，所以分批播种比较安全。选品种的第一标准是能留种的地方品种，第二标准是大小的搭配：做酱和豆腐用大粒的中晚熟种，同时一定要另外留一部分做豆芽用的小粒种。霜早的地区选早熟种或中熟种，人手不足就选抗倒伏的品种，种子如果是从远处弄来的，要确认这个品种是针对哪个纬度培育的。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 垄高20cm以上（水田30cm以上），排水沟深50-80cm。酸性土在播种前3-4周施熟石灰或镁石灰200kg/1,000㎡，把pH调到6.0-6.5（可用烧过捣碎的贝壳和蛋壳粉、木灰代替） |
| 施肥（1,000㎡） | 氮3kg、磷3.4kg、钾3.4kg（全部作基肥）。省氮是技术，多施一定减产，且不需要追肥。磷从骨粉和鱼骨获得，钾从木灰获得（每㎡ 100-200g为上限），缺硼会落花，所以用多种材料混合的堆肥 |
| 根瘤接种 | 用种过大豆且根瘤长得好的地块5-15cm深的土，裹在稍用水润湿的种子上，立刻播下（野大豆根上的根瘤同属，也可用）。不要与种子消毒或杀菌剂同时进行。缺磷的田效率会下降，长期没种过豆科的田必须接种 |

&nbsp;&nbsp;&nbsp;根瘤要在开始开花时（播种后6-8周）挖出根，掰开根瘤检查。红色说明在固氮，出现缺氮症状时，首先要做的不是施肥，而是把根挖出来看。

| 播种 | 标准 |
|:---|:---|
| 时期 | 中部单季5月上旬-6月上旬（最晚6月下旬），中部双季（稻后复种）6月中旬-下旬，南部单季6月上旬-中旬（最晚7月中旬），南部双季6月下旬-7月上旬。日照变短是开花的信号，所以7月中旬-下旬以后播种，收获量会大幅下降 |
| 种子准备 | 挑出并扔掉有斑点、变色、虫孔的种子，用50-55℃的水浸泡10-15分钟，杀死表面病原菌（超过这个温度会降低发芽力） |
| 方法 | 深度3-5cm（超过7cm出不了苗），行距60-80cm，株距15-20cm（双季10-15cm）。播种量每1,000㎡：小粒3-4kg，中粒5-6kg，大粒6-7kg。播得越晚植株长得越小，所以要密植，6月下旬用60-70cm×15cm。播种后鸟会啄子叶，所以用稻草或网盖住 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种到发芽 | 不要让土壤完全干掉（种子要吸收自身重量的水才能发芽） |
| 开花期到荚膨大期 | 充分浇水不让土壤干掉（占整个生育期水分的80%） |
| 成熟期 | 减少水 |

| 管理 | 方法 |
|:---|:---|
| 间苗、除草 | 1-2片真叶时每穴留2株，拔掉弱苗。开花前最后一次除草之后不进田 |
| 培土 | 播种后30-40天，培到第1片真叶的节，把土刮到植株基部。有防倒伏、促进根系发育、改善排水、埋掉杂草的效果，是大豆栽培中效率最高的一次作业 |
| 摘心 | 5-7片真叶时，一定要在开花前用手掐掉茎尖的生长点，侧枝增多，荚数增加。开花后摘心会减产，只在肥足雨多、会徒长的条件下才做，对瘠薄田里长势不良的豆子不做 |
| 倒伏 | 倒伏会使收获用工增加好几倍，荚也会腐烂，所以要保持株距并培土，台风时在田边拉绳支撑 |

## 6. 病虫害与养分问题
| 病虫害 | 症状与条件 | 不用药的防治 |
|:---|:---|:---|
| 大豆花叶病 | 叶片出现花叶斑驳，籽粒有褐色斑点。蚜虫传播 | 无法治疗。发现后立即拔掉烧毁，有斑点的种子不能当种子用 |
| 细菌性斑点病、炭疽病、霜霉病 | 叶片的角状褐色斑点 / 茎和荚上的黑色溃疡 / 叶背灰白色霉层。湿度大 | 波尔多液，选种与轮作，保证株距与排水 |
| 紫斑病 | 籽粒表面呈紫色斑驳。种子带菌 | 彻底挑出带斑的种子并用热水消毒 |
| 菌核病、根腐病、线虫 | 茎变软，出现白色菌丝和黑色菌核 / 根腐烂 / 根部变形成瘤状。冷凉潮湿时、过湿、连作 | 轮作4年以上，把病株连土挖出烧掉，排水和起高垄，套种万寿菊 |
| 蝽类 | 刺吸荚汁液使其成为空荚的最大害虫 | 清晨有露水时它们行动迟缓，所以抖落荚下的虫子接进水桶，用田边的芝麻、粟、高粱作诱集作物集中捕捉，并用早熟种在夏末之前完成成熟 |
| 蚜虫、豆荚螟、斜纹夜蛾 | 吸汁并传播病毒 / 幼虫钻进荚里吃籽粒 / 暴食叶片和荚 | 肥皂水（1L水加5g肥皂），早播早收，徒手捉虫并摘掉卵块 |

&nbsp;&nbsp;&nbsp;波尔多液是分别把400g硫酸铜和400g生石灰溶于100L水，混合后立即使用。

| 症状 | 原因与措施 |
|:---|:---|
| 从下部叶片开始浅黄色，植株矮小 | 缺氮（根瘤不良是最常见的原因）。挖出根检查根瘤，如果没有，当年少量浇施稀释10倍的尿液，第二年一定要接种 |
| 开花但不结荚 | 缺硼，或花期高温干旱。用多种材料混合的堆肥，用灌溉和覆盖降低温度 |

&nbsp;&nbsp;&nbsp;“种豆能改良土壤”这句话是有条件的真理。250kg籽粒含氮约15kg（每公顷150kg），比同重量的玉米籽粒多4.5倍，而根瘤固定的氮每公顷条件好时为100-150kg，条件差时为30-60kg，随籽粒带走的氮为130-160kg。茎叶中留下25-40kg，根和根瘤中留下10-20kg，所以只收籽粒、把茎叶还田，收支大致相当，但把豆秸烧掉或运走当饲料就是明确的亏损。因此要把豆秸、叶子、荚壳全部还田，不挖根，把豆秸切成20-30cm铺盖，如果用来喂了牲畜，就把牲畜的粪肥还到这块田里。烧掉会使氮挥发，所以灰一定要还到这块田里。

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 玉米、高粱（分享豆子固定的部分氮，并因株高差分享光照），土豆（病害不重叠，养分需求不同），白菜·甘蓝类（种在豆子之后，利用剩余的氮） |
| 差 | 番茄、辣椒、茄子（在同一块田里共享病虫害），大蒜、洋葱这类葱属植物（有报告说硫化物会抑制根瘤菌，所以要分开） |

&nbsp;&nbsp;&nbsp;与玉米混种时，两行玉米与两行豆子交替排列，并把玉米行朝南北向立起，避免遮阴。大豆的连作适应性为S，属于休耕1年的类别，但线虫和根腐病会累积，所以豆科不要连着种。4年轮作的例子是：大豆 → 叶菜类或葱属植物（利用豆子留下的氮）→ 谷物或薯类 → 根菜类或绿肥。田地窄的话，分成四块，每年移一块，或每年更换豆子行的位置。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 叶子变黄几乎落光，在田里摇晃时荚里的籽粒有碰撞声的时候。太早籽粒干瘪，太晚会炸荚损失近三成。如果预报有雨，不等完全成熟就收 |
| 要领 | 在晴朗干燥、露水干后的上午10点以后，用镰刀割断茎基，留下根。挂起来晾干后脱粒 |
| 脱粒、清选 | 把干豆秸装进麻袋踩踏，或在草席上薄摊用连枷打，或用木棍敲打，或在桶的内壁上摔打脱粒（干燥是关键）。风选在风稳定的清晨或傍晚，细细倒下，进行两三次。放入水中捞出空粒和虫蛀的籽粒，一定要重新晒干 |

| 留种 | 标准 |
|:---|:---|
| 选择、分开 | 事先在田里标出没有病症、荚多、没有倒伏的植株（系上线），单独脱粒，不与食用的豆子混在一起。自花授粉，不需要隔离 |
| 保存 | 晒到含水量12-13%，装入密封容器，放在凉爽阴暗处。发芽率收获当年90%以上，1年后80-90%，2年后60-80%，3年后40-60%，从第4年起急剧下降，所以每年用新留的种子，旧的当作备用。旧种子要做发芽试验，只有一半发芽就把播种量加倍，低于30%就吃掉 |
| 更新 | 紫斑病、炭疽病、花叶病会通过种子累积，所以要剔除有斑点的种子，每3-4年从别处弄来种子，混入一部分 |

## 9. 储存
| 步骤 | 方法 |
|:---|:---|
| 干燥 | 连豆秸在田里或屋檐下预干一两天。把干盐和豆子一起装进瓶里摇晃，盐如果粘在瓶壁上，说明还潮。咬一下牙咬不进去而脆裂就是适宜 |
| 豆象防治 | 田里的荚上已经被产了卵，所以要及时收获。完全密封最可靠：把容器装满，用几个小容器分装，3-4周后卵和幼虫都会死。拌入筛过的木灰，用量为体积的2-5%（食用前冲洗）。每1kg豆子拌入2-5mL食用油（只用于半年内要吃的部分，留种的不用） |
| 环境、检查 | 15℃以下，空气湿度65%以下。把耳朵贴近容器，检查沙沙声、霉味和小圆孔 |

> **豆子不是烂掉而损失的，而是被虫吃掉而损失的。储存的技术，就是防虫的技术。**

## 10. 烹调与注意事项
| 成分 | 作用 | 去除 |
|:---|:---|:---|
| 胰蛋白酶抑制剂 | 抑制蛋白质分解酶，造成腹痛、呕吐、腹泻和蛋白质利用率下降 | 浸泡8小时后在100℃加热30-60分钟以上 |
| 凝集素 | 附着在肠黏膜上妨碍吸收，使红细胞凝集，造成剧烈腹痛、呕吐、腹泻 | 浸泡后在100℃加热10-30分钟以上 |
| 植酸 | 妨碍铁、锌、钙、镁的吸收 | 浸泡、发芽、发酵可减少60-80% |

> **没煮熟的豆子有时比生豆子更危险。稍微焯一下会使细胞壁破裂，吸收虽然更好，但抑制剂和凝集素还在。烹煮时不要半途而止，要一直煮透。**

&nbsp;&nbsp;&nbsp;干豆表面坚硬，不泡就煮会里面夹生，这是最危险的；大豆的凝集素比菜豆类弱，但在滚沸的水里充分煮熟是唯一安全的办法。

| 烹调 | 方法 |
|:---|:---|
| 基本 | 在常温水中浸泡8小时（夏天换水浸泡6小时）。用100℃蒸汽蒸60-90分钟，或用压力烹调在120℃下15-20分钟（最省燃料）。用拇指和食指一按就容易捏烂就是熟了 |
| 节省燃料 | 煮15分钟以上后熄火，用稻草或稻壳箱或棉被包住放2-3小时（如果还有硬心就再煮）。干豆用小火炒20-30分钟，抑制剂会大幅减少，可以直接吃。炒后磨成的豆粉密封可保存2-3个月 |
| 豆芽 | 干豆不含维生素C，所以把小粒种浸泡6-8小时，避光在20-25℃下培育，100g可长成400-500g，成为冬季维生素C的来源 |
| 做酱 | 酱曲是把煮烂捣碎的豆子捏成块，用稻草包好发酵一个月以上；大酱和酱油用盐水熟成数月，可保存多年。清麴酱是把煮熟的豆子用稻草包好，在约40℃下放2-3天，是最快的发酵豆。豆腐是把泡过的豆子磨碎煮开过滤，用卤水点成，是最容易消化的形态 |

&nbsp;&nbsp;&nbsp;发酵是最根本的办法，微生物把抑制剂和凝集素分解成氨基酸，并分解植酸，去除抗营养成分；做酱则是把煮豆的一小时燃料只付一次，管一年的量，加盐后能保存多年。

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存的豆子，做种子发芽试验，修整工具。2月做田地规划，翻堆堆肥，准备做酱 |
| 3-4月 | 3月撒石灰（播种前3-4周），收尾堆肥，发酵酱曲 |
| 5-6月 | 5月选种，热水消毒，播种早熟种，备好接种用的土。6月正式播种（中部上旬，南部中下旬），防鸟，第一次除草，每隔2周分批播种使花期错开 |
| 7-8月 | 7月间苗、除草、培土、摘心，检查根瘤。8月开花与荚膨大，集中灌溉，清晨捕捉蝽类 |
| 9-10月 | 9月成熟期管理，停止灌溉，标记留种植株。10月收获，预干，挂起晾干，脱粒（预报有雨就不等完全成熟） |
| 11-12月 | 11月清选、干燥、储存、茎叶还田（把豆秸切碎铺在田里，不要烧），煮酱曲。12月做酱，检查储存，培育豆芽 |

> **大豆要做到氮肥每1,000㎡不超过3kg，花期挖根确认根瘤的红色，在开花期到荚膨大期的4周里浇水，收获后把豆秸还田，才算物有所值。**
