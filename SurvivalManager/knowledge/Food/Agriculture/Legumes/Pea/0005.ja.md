## 8. 栽培管理 - 支柱と誘引

### 8-1. 支柱はなぜ必要か

&nbsp;&nbsp;&nbsp;エンドウは茎にほとんど木質がなく、中が空洞なので、自力で立つことができません。進化の過程で、エンドウは立つ代わりに寄りかかる道を選び、その代償として葉の先端を巻きひげに変えました。畑でこの事実を無視すると、つるが地面に広がります。地面に広がったエンドウには、四つのことが同時に起こります。葉が重なって下のほうに光が届かなくなり、風通しが悪くなってうどんこ病や褐紋病が広がり、さやが土に触れて腐り、収穫のときにつるをかき分けなければならず、手間が何倍にもなります。

| 方法 | 資材 | 効果 | 災害時の適合度 |
|---|---|---|---|
| 支柱なし | なし | 収量がはっきりと落ち、病気が増えます | 矮性種に限り次善策 |
| ひも誘引 | 杭とひも | 労力は中程度、収量は良好 | 最も現実的です |
| ネット誘引 | 杭とネット | 収量が最も高くなります | ネットがあれば最善 |
| 小枝を挿す | 小枝 | 費用がかかりません | 伝統的な方法。小面積に向く |
| 生きた支柱 | トウモロコシ、ヒマワリ | 支柱が不要になります | 播種時期がずれるため、エンドウには概して向きません |

&nbsp;&nbsp;&nbsp;災害時の条件で最も現実的なのは、ひも誘引です。2m間隔で杭を打ち、地面から20cm、50cm、80cmの高さにひもを水平に張って、二列の間のエンドウがそのひもに寄りかかるようにします。つるが伸びる速さに合わせて、ひもを一段ずつ上に張り直せばよいのです。ひもが足りなければ、クズのつるやわらをなって縄をつくって使います。

&nbsp;&nbsp;&nbsp;小枝を挿す方法は、ヨーロッパと韓国の両方で古くから使われてきました。葉を落とさない小枝を、植える条に沿って斜めに挿しておくと、エンドウの巻きひげがその小枝に巻きついて、自分で登っていきます。シラカバやハギのように小枝がよく分かれたものがよく、ひももネットも必要ありません。冬のうちに枝を切って乾かしておき、春に使えばよいのです。

> **エンドウの巻きひげは、直径5mm前後の細いものをいちばんよくつかみます。太い柱には巻きつけません。支柱を立てるときに太い杭だけを打っておくと、つるは何もつかめないまま倒れてしまいます。**

### 8-2. 間引きと除草

| 作業 | 時期 | 方法 |
|---|---|---|
| 1回目の間引き | 本葉2-3枚 | 混みすぎた場所だけ整理します |
| 2回目の間引き | 草丈10cm | 1穴あたり、生育のよい2本を残します |
| 1回目の除草 | 播種後2-3週間 | 浅くかきます。根を傷めないようにします |
| 2回目の除草 | 播種後5-6週間 | 土寄せを兼ねます |
| それ以降 | 開花後は畑に入りません | つるが絡み合っていて、人が通ると折れます |

&nbsp;&nbsp;&nbsp;エンドウは生育初期がゆっくりで草丈も低く、雑草に負けやすい作物です。反対に、いったんつるが伸びて支柱を登り始めれば、雑草と空間を奪い合うことはありません。そのため、最初の1か月の除草がすべてだと言っても言いすぎではありません。開花後は畑に入らないのが原則です。巻きひげが互いに絡み合っているため、人が通ると何株もがいっせいにちぎれ、露が乾かない朝に行き来すると、病気が畑全体に運ばれてしまいます。

### 8-3. 摘心と芽摘み

| 作業 | 時期 | 効果 |
|---|---|---|
| 芽摘み | つるが支柱の先端に届いたとき | 側枝が増え、下のさやが太ります |
| 若芽の収穫 | 生育中随時 | 野菜として食べながら、同時に摘心の効果も得られます |
| 病葉の除去 | 見つけ次第すぐに | うどんこ病や褐紋病の拡大を遅らせます |

&nbsp;&nbsp;&nbsp;エンドウの芽摘みには、副次的な利点がもう一つあります。アブラムシはたいてい、最も若い生長点の部分に集まっています。芽を摘み取ると、アブラムシの集団の相当な部分も一緒に取り除かれます。摘んだ芽は捨てずに、さっとゆでてナムル（味付けした和え物）として食べます。ソラマメでも同じ方法が使われ、農薬のない条件で、一度の作業で防除と収穫と収量増加を同時に得られる、珍しい例です。

## 9. 病害虫

&nbsp;&nbsp;&nbsp;エンドウの病害虫圧はCです。無防除時の減収率は推定48.9%で、ダイズの2倍を超えます。しかし、エンドウの病害虫の大半は気温が上がるにつれて急増するため、早く播種して早く収穫するという回避戦略がかなり有効です。

### 9-1. 主な病害

| 病名 | 症状 | 発生条件 | 農薬を使わない対応 |
|---|---|---|---|
| うどんこ病 | 葉と茎の表面に、小麦粉をふりかけたような白い粉が覆います | 昼が暑く夜が涼しく乾燥しているとき。生育後期の最大の病害 | 風通しの確保、牛乳を水で5-10倍に薄めて散布、早期収穫による回避 |
| ウイルス病（萎縮病） | 葉が縮れてしわしわになり、まだら模様ができます。生育が止まります | アブラムシが媒介します | 治療できません。見つけ次第すぐ抜き取って焼却し、アブラムシを減らします |
| 褐紋病 | 葉、茎、さやに褐色の斑点ができます | 雨が多く湿度が高いとき。種子伝染もします | 種子の選別、風通しの確保、ボルドー液 |
| 根腐病・萎凋病 | 下の葉から黄色くしおれ、茎の株元と根が褐色に腐ります | 過湿、連作 | 5-7年の輪作が唯一の根本対策です。排水と畝の高上げ |
| さび病 | 葉にオレンジ色の粉の塊ができます | 多湿 | 病葉の除去、風通しの確保 |
| べと病 | 葉の表側に黄色い斑点、裏側に灰白色のカビ | 涼しく湿度が高いとき | 株間の確保、排水、ボルドー液 |

> **エンドウの連作障害は、豆類の中で最も深刻です。萎凋病と根腐病の休眠胞子は、宿主がなくても何年も土の中で耐え抜きます。いったん汚染された畑は農薬では元に戻せず、畑を替える以外に方法はありません。**

### 9-2. 主な害虫

| 害虫 | 被害 | 農薬を使わない防除 |
|---|---|---|
| アブラムシ | 生長点や花柄に集まって汁を吸い、ウイルス病を媒介します。エンドウ最大の害虫 | 芽摘みで集団を物理的に取り除きます。せっけん水（水1Lにせっけん5g）を葉の裏に散布します。テントウムシとクサカゲロウを保護します |
| エンドウゾウムシ | 畑でさやに産卵し、貯蔵中に子実を食い荒らします | 完全に乾燥させてから密閉して貯蔵することが要点です。第15節を参照 |
| ソラマメアブラムシ | 黒いアブラムシが茎にびっしりつきます | 芽摘み、せっけん水 |
| ハモグリバエ類 | 葉の内部にもぐり込み、白い筋模様を残します | 被害を受けた葉を摘み取って処分します |
| 鳥（ハト・カササギ・キジ） | 播種直後の種子や幼い芽を食べます | 発芽までわらやネットで覆います |
| ネズミ | 播いた種子を地中から掘り出して食べます | 種子に草木灰をまぶし、播種の深さを守ります |

### 9-3. 農薬を使わない防除資材

| 資材 | 作り方 | 対象 | 注意 |
|---|---|---|---|
| 牛乳希釈液 | 牛乳を水で5-10倍に薄めます | うどんこ病 | エンドウで最も効果が確認されている天然資材です。晴れた日の午前に散布します |
| せっけん水 | 水1Lに無香料のせっけん5g | アブラムシ、ハダニ | 日中の暑い時間に散布すると葉が焼けます |
| ボルドー液 | 水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜます | 細菌病、カビ病 | 銅がなければ作れません。混ぜたらすぐに使います |
| 草木灰水 | 灰1升を水10Lに一晩浸し、上澄みを使います | カビの抑制 | アルカリ性なので薄めて使います |
| 乾いた灰をふりかける | 露のある朝に、葉にきめ細かい灰をふりかけます | 葉を食べる虫、カビ | 雨が降ると洗い流されます |
| 木酢液 | 炭を焼くときに出る液を300-500倍に薄めます | 忌避、生育促進 | 原液は強酸性なので必ず薄めます |
| トウガラシ・ニンニクの水 | すりおろして水に漬け出し、こして使います | 忌避 | 効果が長続きしないので、こまめに散布します |

### 9-4. 耕種的防除

| 方法 | 原理 |
|---|---|
| 早期播種 | エンドウの病害虫の大半は、気温とともに増えます。暑さが来る前に収穫を終えれば、かなりの部分を避けられます |
| 長期の輪作 | 萎凋病と根腐病には、5-7年の休作が唯一の対策です |
| 種子の選別 | 褐紋病は種子伝染します。斑点や変色のあるものを取り除きます |
| 栽植距離と支柱 | 風通しがよければ葉が早く乾き、カビが定着できません |
| 排水 | エンドウの病害の半分以上が過湿に関連します |
| 芽摘み | アブラムシの集団を物理的に減らします |
| 雨の後は畑に入らない | 濡れた葉に人が触れると、病原菌が付着して運ばれます |
| 残渣の処理 | 病気の残渣は焼くか深く埋めます。健康な残渣だけを畑に戻します |

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 天然素材での対処 |
|---|---|---|
| 下の葉から全体が薄い黄色になり、株が小さい | 窒素欠乏。エンドウでは根粒の不良が最も多い原因です | まず根を掘り上げて根粒を確認します。根粒がなければ、翌年は接種を確実に行い、その年は尿の10倍希釈液を少量与えます |
| 葉の縁が褐色になって枯れる | カリウム欠乏 | 草木灰を株間にまき、軽くかき込みます |
| 生育が遅く、葉が紫色を帯びる | リン酸欠乏。エンドウはリン酸の要求が高いため、よく起こります | 骨粉、魚の骨を焼いた粉、草木灰 |
| 花が咲いてもさやがつかない | ホウ素欠乏、または開花期の高温 | いろいろな材料を混ぜた堆肥。高温が原因なら、翌年は播種を前倒しします |
| 葉脈は緑色なのに葉脈の間が黄色い | 鉄またはマンガンの欠乏。アルカリに傾いた土でよく見られます | 灰の使用をやめます。腐葉土と完熟堆肥で有機物を増やします |
| 新しい葉が小さく奇形で、生長点が枯死する | カルシウムまたはホウ素の欠乏 | 卵の殻を焼いた粉、貝殻の粉 |
| つるばかり茂ってさやが少ない | 窒素過剰 | 窒素の供給をただちに中止します。芽を摘んで側枝を促します |
| 生育が全体的に不振で、根が短い | 酸性土壌 | 石灰、または焼いた貝殻の粉。エンドウはpH 6.0を下回るとはっきり悪くなります |

&nbsp;&nbsp;&nbsp;エンドウの生育が不振なとき、まず疑うべきは肥料ではなく酸度です。エンドウは豆類の中で酸性土壌に最も弱く、pH 6.0を下回ると根の発達と根粒の形成がともに悪くなります。見た目は窒素欠乏のようですが、窒素を与えても回復しません。その次に疑うのが根粒です。根を掘り上げて、根粒がよくついていて、割った内側が赤いのに葉が黄色いなら、窒素ではない別の問題です。

&nbsp;&nbsp;&nbsp;微量元素の欠乏には、一つずつ対応するのが困難です。化学肥料なしでモリブデンやコバルトを入手する方法は、事実上ありません。その代わり、野菜くず、果物の皮、卵の殻、魚の骨、落ち葉、雑草、灰を一緒に混ぜて腐らせた堆肥には、微量元素がまんべんなく含まれています。堆肥場に何でも入れるという原則が、微量元素管理の実質的な戦略です。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 作物 | 理由 |
|---|---|---|
| 良い | サンチュ（リーフレタス）・ホウレンソウ | エンドウの陰で育ち、空間を共有できます。生育期間が同じです |
| 良い | ダイコン・カブ | 根の深さが違うため、養分を取る層が重なりません |
| 良い | ジャガイモ | 互いに病害が重ならず、エンドウを先に収穫できます |
| 良い | ニンジン | エンドウが残した窒素を後から利用します |
| 普通 | トウモロコシ | 理論上は支柱になりますが、播種期が2か月ずれるため、実際には合いません |
| 悪い | ニンニク・タマネギの仲間 | 分泌物が根粒菌を抑制するという報告があります |
| 悪い | ほかのマメ科 | 病原菌と線虫が蓄積します |

&nbsp;&nbsp;&nbsp;エンドウとトウモロコシの組み合わせは、本にはよく出てきますが、実際にはあまり合いません。韓国では、エンドウを播く3月にトウモロコシは播けず、トウモロコシが支柱の役を果たせるほどに育つ6月には、エンドウはすでに老化しつつあります。この組み合わせが機能するのはインゲンマメとトウモロコシの場合で、エンドウには別に支柱を立てるほうがよいです。

&nbsp;&nbsp;&nbsp;エンドウと葉物野菜の組み合わせは、実際によく合います。エンドウの条の間にサンチュやホウレンソウを植えると、春の弱い日差しの下で、二つの作物が互いに邪魔をせずに育ちます。暑くなると、エンドウのつるが作る日陰が、葉物野菜の抽だいを遅らせてくれます。エンドウを収穫するころには葉物野菜も終わって、畑がいっせいに空き、その場所にすぐ夏作物を植えられます。

### 11-2. 輪作

| 項目 | 基準 |
|---|---|
| 休作期間 | 5-7年。豆類の中で最も長いです |
| 理想的な周期 | 6年以上 |
| 連作障害 | 萎凋病と根腐病の病原菌が土壌に残存します。農薬もなく、抵抗性品種の韓国国内での普及も限られています |

&nbsp;&nbsp;&nbsp;エンドウの連作適応性Dは、この文書で最も重く受け止めるべき項目です。ダイズ1年、インゲンマメ3年、ソラマメ2年と比べると、エンドウの5年から7年は圧倒的に長い期間です。畑に余裕がない条件でこの要求を守るのは容易ではありませんが、守らなければ数年のうちにエンドウを植えられない畑になってしまいます。

| 6年輪作の例 |
|---|
| 1年目：エンドウ（春）の後、ハクサイまたはダイコン（秋） |
| 2年目：トウモロコシまたはモロコシ（タカキビ） |
| 3年目：ジャガイモまたはサツマイモ |
| 4年目：ダイズまたはササゲ |
| 5年目：穀物（オオムギ・コムギ）の後、ソバ |
| 6年目：根菜または緑肥 |
| 再びエンドウ |

&nbsp;&nbsp;&nbsp;畑が狭く、6年も回す余裕がない場合の妥協策を書いておきます。畑をいくつかの区画に分け、毎年1区画ずつずらしてエンドウを植える方式が、最も簡単です。区画に分けられない小さな畑なら、最低限、エンドウを植える条の位置を毎年大きく移します。もう一つ、畑の外で育てる方法もあります。エンドウは根が深く入りますが、大きな容器や袋でも育ちます。土を入れた袋に植えれば、土を毎年入れ替えて連作障害を完全に避けられますし、スプラウトや若芽が目的であれば、土がなく水だけでも十分です。

## 12. 収穫と脱穀

### 12-1. 用途別の収穫時期

| 用途 | 収穫時期（播種後） | 判断基準 |
|---|:---:|---|
| スプラウト | 5-7日 | 茎5-10cm。土がなくても水だけでできます |
| 若芽 | 15-20日 | 茎15-20cm。切ってもまた伸びます |
| さやごと（さや実兼用品種） | 50-60日 | さやが平らで、中の豆がまだ小さいとき |
| グリーンピース | 60-80日 | 開花後20-30日。さやが膨らんでいて、まだ緑色のとき |
| 乾燥子実 | 85-95日 | さやが黄色く乾き、豆が硬くなったとき |

&nbsp;&nbsp;&nbsp;一株のエンドウから、この五つがすべて得られます。災害時には、この多様性それ自体に価値があります。畑をつくる前に室内でスプラウトを得て、春が深まれば若芽をナムルにして食べ、初夏にはグリーンピースで新鮮なビタミンを摂り、最後に乾燥した豆を収穫して冬を越します。

&nbsp;&nbsp;&nbsp;グリーンピースの収穫適期を見極めるコツがあります。さやが膨らみつつ、表面がまだなめらかで光沢があるときが、最も甘くなります。少し過ぎると表面に網目模様が現れ、ごつごつしてきますが、このときが豆が最も大きく、しかもまだ食べられる最後のタイミングです。それ以降は、糖がデンプンに変わって甘みが消え、皮が硬くなります。いくつもの節のさやを手で触って比べれば、すぐに感覚がつかめます。

> **エンドウは摘めばさらに実り、放っておくと止まります。熟したさやをそのままにしておくと、株は繁殖を終えたと判断して開花をやめます。3-4日おきにこまめに摘むことが、収量を増やす最も確実な管理です。**

### 12-2. 乾燥子実の収穫

| 判断基準 | 内容 |
|---|---|
| 葉 | 下から黄色く枯れていきます |
| さや | 全体の8割以上が黄色または褐色に変わっています |
| 音 | 振るとさやの中で豆がぶつかる音がします |
| 豆 | 噛むと歯が立たず、パキッと割れます |
| 水分 | 子実の水分13-15% |

&nbsp;&nbsp;&nbsp;エンドウはダイズよりも、さやがはじけて豆が落ちやすい作物です。さやが乾くにつれて自らねじれて開き、特に乾いたさやが雨に濡れてまた乾くことを繰り返すと、あっという間にはじけます。下のほうのさやが褐色になり始めたら毎日観察し、雨の予報があれば完熟を待たず、つるごと刈り取って取り込みます。少し未熟なエンドウは乾燥させて使えますが、地面に落ちたエンドウは収穫できません。

| 手順 | 内容 |
|---|---|
| 1 | 晴れて乾燥した日の、露が乾いた午前10時以降に行います |
| 2 | つるの株元を鎌で刈ります。根は畑に残します |
| 3 | 束ねて、軒下や納屋に逆さに吊るして乾燥させます |
| 4 | 下に布やむしろを敷いて、自然に落ちる豆を受けます |
| 5 | さやがからからに乾き、振ると音がするようになったら脱穀します |

### 12-3. 脱穀 - 道具なしでできる方法

| 方法 | 道具 | 手順 | 効率 |
|---|---|---|---|
| 袋踏み | 厚手の麻袋や袋 | 乾いたつるを袋に入れて口を縛り、足で踏むか手でもみます | 少量なら最も楽です。豆が飛び散りません |
| 殻竿（フレイル） | 長い柄の先に細い棒を取り付けた道具 | むしろや布を広げ、つるを薄く広げて、上から打ちます | 中規模に向きます。2-3回ひっくり返しながら打ちます |
| 棒で叩く | 木の棒 | 袋に入れるか、むしろに広げて叩きます | 殻竿がないときの代用です |
| 足でもむ | なし | むしろに広げ、靴を履いた足でこするように踏み回します | 少量に向きます |
| 板に打ちつける | 板や桶 | つるの束を持ち、桶の内側の壁に叩きつけます | 豆が桶の中に集まるので、ロスが少ないです |
| 手でむく | なし | さやを1つずつひねって開きます | 種子用の少量に使います。豆が傷みません |

&nbsp;&nbsp;&nbsp;脱穀の成否は乾燥にかかっています。乾き方が足りないつるは、いくら叩いてもさやが開かず、乾きすぎたエンドウは、叩いたときに豆が割れます。さやを手で押したときにパチンと開く状態が適期で、日差しのよい日の午後に行うとはるかに楽です。エンドウはダイズよりさやが軟らかくてよく開くため、脱穀がずっと簡単です。袋踏みだけでも、ほとんどすべて落ちます。

### 12-4. 精選 - 風で選り分ける

| 方法 | 原理 | 手順 |
|---|---|---|
| 風選（風で選別） | 豆は重く、殻やくずは軽いです | 風のある日に、箕や広い器に入れて高く持ち上げ、ゆっくり注ぎます。豆はすぐに落ち、殻は飛んでいきます |
| 箕あおり | 上下に揺すりながら前へあおります | 重い豆が後ろに残り、軽いものが前へ押し出されます |
| うちわであおぐ | 一人が注ぎ、もう一人がうちわで風を送ります | 風のない日に使います |
| ふるい分け | 目の大きさで分けます | 目の粗いふるいでつるの切れ端を取り除き、目の細かいふるいで土や小さな豆を落とします |
| 水に浮かせる | しいなや虫に食われた豆は軽いです | 水桶に入れ、浮くものをすくい取ります。引き上げたものは必ず再び乾燥させます |
| 斜面板に転がす | 丸い豆はよく転がり、くずは引っかかります | 板を傾けて置き、転がし落とします。エンドウは丸いので特によくできます |

&nbsp;&nbsp;&nbsp;風選は、人が穀物を扱い始めたときから使われてきた方法です。コツは三つあります。風が一定に吹く早朝か日暮れ前を選ぶこと、一度に注がず細く流し落とすこと、そして2-3回繰り返すことです。

&nbsp;&nbsp;&nbsp;水に浮かせる方法は、精選と選別を同時に行えます。エンドウゾウムシに食われた豆は中が空洞になって浮き、しいなも浮くため、こうして選り分けると貯蔵中の損失が大きく減ります。ただし、水に浸したエンドウはその日のうちに完全に乾燥し直す必要があり、種子用には使いません。
