## 5. 畑の準備と肥料 - 窒素収支と施肥

### 5-4. 窒素固定の落とし穴

&nbsp;&nbsp;&nbsp;「豆を植えると土が良くなる」という話は、農業の常識として定着しています。半分は正しく、半分は誤りです。この点を正確に理解していないと、マメ科を何年も続けて植えた畑が、かえって痩せていくことが起こります。

&nbsp;&nbsp;&nbsp;数字で検証してみましょう。エンドウがよく育てば、1,000㎡から250kgの乾燥子実が収穫できます。エンドウ子実のタンパク質は25.4%で、タンパク質を6.25で割ると窒素量が出ます。25.4 ÷ 6.25は4.06、つまり子実重量の約4%が純粋な窒素です。250kgに含まれる窒素は約10kgで、ヘクタールに換算すると100kgです。

&nbsp;&nbsp;&nbsp;一方、エンドウの根粒が固定する窒素は、条件がよいときでヘクタールあたり80-130kgです。接種がうまくいき、酸度が合い、水が適度だったときの値で、条件が悪ければ30kgにとどまります。出ていくものと入ってくるものを並べると、次のようになります。

| 項目 | ヘクタールあたりの窒素 | 方向 |
|---|---|---|
| 根粒の固定量（条件良好） | 80-130kg | 入る |
| 根粒の固定量（条件不良） | 25-50kg | 入る |
| 子実として持ち出し | 90-110kg | 出る |
| 茎葉（つると葉）に残る窒素 | 25-40kg | 戻せば残り、焼いたり運び出したりすると出る |
| 根と根粒に残る窒素 | 10-20kg | たいてい畑に残ります |

&nbsp;&nbsp;&nbsp;表を見ればわかります。子実だけを収穫して持ち去り、つると葉を畑に戻せば、固定量と持ち出し量はほぼ釣り合うか、少し残る程度です。しかし、エンドウのつるまで片づけて家畜の飼料として運び出したり、焼いてしまったりすると、窒素収支は確実にマイナスに転じます。つまり、エンドウ畑から出ていく窒素が、入ってくる窒素より多くなります。

> **マメ科が土を肥やすのは、窒素を固定するからではなく、固定した窒素の一部を茎や葉に蓄えて畑に残しておくからです。その茎や葉を運び出してしまえば、豆は土から奪う作物になります。**

&nbsp;&nbsp;&nbsp;エンドウには、この問題を解決するのに有利な条件が一つあります。韓国では収穫時期が6月と早いことです。ダイズは10月に収穫して茎葉を戻しても、冬の間はほとんど分解が進みませんが、エンドウの茎葉は6月の暖かく湿った土の中で速く朽ちます。しかもエンドウの茎は中が空洞で水分が多く、組織が軟らかいのです。刻んで覆えば数週間で形がなくなり、その窒素を夏作物がすぐに使います。エンドウを緑肥として使う古くからの慣行は、ここに根拠があります。

| 原則 | 内容 |
|---|---|
| 茎葉は必ず畑へ | 脱穀後に残ったつると葉、さやの殻をすべて畑に戻します |
| 焼かない | 焼くと窒素は気体となって失われ、カリウムとリン酸だけが灰として残ります |
| 根は掘り上げない | 根と根粒の窒素は、最も簡単に残せる分です |
| 20-30cmに刻んで覆う | マルチングを兼ねた肥料になり、夏作物の地温を下げます |
| 緑肥としてすき込む選択 | 開花期に丸ごとすき込むと、窒素が最も多く残ります。子実をあきらめる代わりに、畑を生き返らせます |
| 家畜に与えたなら糞を戻す | エンドウのつるを与えたなら、その家畜の糞尿を必ずその畑に入れます |

### 5-5. 畑の準備

| 項目 | 方法 | 災害時の条件では |
|---|---|---|
| 耕起 | 20-30cmの深さに耕し、平らに整地します | スコップで返すか、くわで掘り起こします。全面耕起が難しければ、播種する条だけを掘り返します |
| 畝 | 高さ20cm以上 | 湿害防止の要です |
| 排水溝 | 深さ30-50cm | 春雨と、韓国の梅雨（チャンマ）の初めにまたがります |
| 酸度矯正 | pH 6.5-7.5 | 播種の15日から3週間前に済ませておきます |
| 石灰 | 酸性土壌に150kg/1,000㎡ | 貝殻・卵の殻を焼いて砕くか、草木灰で代用します |

&nbsp;&nbsp;&nbsp;石灰を事前に入れなければならない理由は、反応に時間がかかるからです。播種の直前に入れると、局所的にアルカリが強くなって種子や幼根が傷み、肝心な時期には反応が十分に進んでいません。また、石灰と窒素肥料を同じ場所に一緒に入れると、アンモニアが気体となって揮散し、窒素を失います。石灰が先、肥料は2週間後、という順序を守ります。石灰がなければ、貝殻と卵の殻を使います。どちらも炭酸カルシウムで原理は同じですが、そのままでは反応が非常に遅いので、火で焼いて砕けやすくしてから、臼でついて粉にして使います。

### 5-6. 施肥量

| 肥料 | 1,000㎡あたり | ㎡あたりに換算 | 備考 |
|---|---|---|---|
| 窒素 | 8.7kg | 8.7g | 全量元肥です。根粒が働き出す前の初期用です |
| リン酸 | 50kg（熔成リン肥基準） | 50g | 全量元肥です。エンドウは豆類の中でリン酸の要求が高いです |
| カリウム | 16.8kg | 16.8g | 全量元肥です |
| 堆肥 | 1,500kg | 1.5kg | 完全に腐熟したものを使います |
| 石灰 | 150kg（酸性土壌） | 150g | 播種の15日前 |

> **エンドウで窒素を控えるのは、節約ではなく技術です。多く与えるとつるばかりが茂ってさやが減り、重くなったつるが倒れて病気が広がります。**

&nbsp;&nbsp;&nbsp;追肥は原則として必要ありません。ただし、開花のころに葉が全体に薄い黄色みを帯び、生育がはっきりと不振な場合は、根粒がきちんと働いていないというサインです。このときに限り、少量を補います。災害時には、尿を水で10倍に薄めて株間の土に注ぐのが、最も手軽な代替策です。葉にかからないようにし、一度に多く与えるより、薄めたものを何回かに分けて与えます。

### 5-7. 災害時の代替肥料

| 代替資源 | 供給される養分 | 使い方 | 注意 |
|---|---|---|---|
| 草木灰 | カリウム、リン酸、カルシウム | ㎡あたり100-200gをまいて混ぜます | アルカリ性です。エンドウはアルカリに比較的強く、ほかの豆類より余裕があります |
| 完熟堆肥 | 各種養分 | ㎡あたり1-1.5kgを元肥として入れます | 未熟なものは根を傷め、病気を持ち込みます |
| 薄めた尿 | 窒素、カリウム | 水で10倍に薄めて株間の土に注ぎます | 葉にかからないようにします。少量だけ |
| 骨粉 | リン酸、カルシウム | 焼いて砕き、堆肥に混ぜます | エンドウの高いリン酸要求を満たす中心的な材料です |
| 魚の骨・魚の内臓 | リン酸、窒素 | 埋めて分解させてから使います | そのまま埋めると獣に掘り返されます |
| 貝殻・卵の殻 | カルシウム | 焼いて砕き、まきます | 石灰の代わりです。反応が遅いです |
| 落ち葉の腐葉土 | 各種養分、有機物 | 土に混ぜ込みます | 保水性をよくします |
| もみ殻・稲わら | カリウム、ケイ酸 | マルチとして覆い、翌年すき込みます | 未分解のものをすき込むと窒素を奪われます |

&nbsp;&nbsp;&nbsp;エンドウの施肥で最も目を引く数値は、リン酸です。1,000㎡に50kgは窒素の6倍にあたる量で、豆類の中では異例の多さです。リン酸は窒素固定のエネルギー代謝の中心となる元素で、エンドウの根粒は、リン酸が不足するとできても本来の働きをしません。化学肥料がない条件でリン酸を得る道は、骨粉と魚の骨が事実上すべてです。獣の骨を集めて火で焼いて砕けやすくし、臼でついて堆肥に混ぜておくと、数年かけてゆっくり溶け出してきます。魚を食べたあとに残った骨や内臓も、畑の一角に埋めて分解させておき、それを使います。

## 6. 播種

### 6-1. 播種時期

| 作型 | 播種時期 | 収穫時期 | 備考 |
|---|---|---|---|
| 春栽培（韓国全土） | 2月下旬-4月上旬 | 6月中旬-7月下旬 | 最も一般的です。早いほどよいです |
| 秋栽培（韓国南部） | 10月上旬-10月末 | 翌年5月中旬-6月中旬 | 越冬栽培です。収穫が早まります |
| スプラウト・若芽の収穫 | 通年 | 播種後5-20日 | 室内でも可能です |

&nbsp;&nbsp;&nbsp;エンドウの播種時期は、逆算で決めます。その地域で日中の最高気温が25℃を超え始める日を探し、そこから85-95日さかのぼれば、播種の限界日が出ます。韓国中部では、おおむね4月上旬が限界で、3月中旬が適期であり、土が解ける2月下旬に播種しても差し支えありません。遅霜に当たって葉先が傷む程度なら、エンドウは自分で回復します。

> **エンドウの播種で失敗の大半は、遅く播くことから生じます。霜を恐れて先延ばしにしているうちに暑さが近づき、開花期が暑さにぶつかると、花がそのまま落ちてしまいます。**

&nbsp;&nbsp;&nbsp;秋播きは、韓国南部の戦略です。10月初めから末までに播種して、本葉2-3枚、草丈10cm前後の状態で冬を越させます。早く播きすぎて大きく育った状態で冬を迎えると、かえって凍死してしまうため、初霜の40-50日前を播種日とするのがコツです。冬にはわらや落ち葉をかぶせて、凍った地面が持ち上がる（凍上）のを防ぎます。韓国中部の内陸ではこの作型は概ね失敗するため、春播きにします。

### 6-2. 種子の準備

| 項目 | 方法 | 災害時の条件では |
|---|---|---|
| 選別 | 斑点、変色、しわ、虫食い穴のある種子を捨てます | 手で1粒ずつ選びます。最も安上がりで効果の大きい作業です |
| 大きさをそろえる | 大きくて重い粒を選んで使います | 水に浮かべて、浮くものを取り除きます |
| 温湯消毒 | 50-55℃の湯に10-15分浸して、表面の病原菌を殺します | 温度が高すぎると発芽力が落ちます |
| 灰の処理 | きめ細かい草木灰をまぶします | 消毒と乾燥を助け、鳥や虫が避ける効果があります |
| 根粒菌の接種 | 同じマメ科を育てた畑の土をまぶします | 5-3節を参照。消毒とは同時に行いません |
| 浸漬 | 播種前に数時間、水に浸します | 発芽は早まりますが、長く浸すと腐ります。6時間を超えないようにします |
| 発芽試験 | 湿らせた布に20粒を包んで数日置き、芽が出る数を数えます | 古い種子は必ず先に確認します |

&nbsp;&nbsp;&nbsp;エンドウはダイズと違って、長く水に浸してはいけません。種皮が薄く組織が軟らかいため、8時間以上浸すと中が軟らかくなり、土の中ですぐに腐ります。土が十分に湿っているなら、まったく浸さずに播くほうが安全で、土が乾いている状態なら、3-4時間程度だけ浸し、水気を乾かしてから播きます。

&nbsp;&nbsp;&nbsp;温湯処理の温度管理にはコツがあります。温度計がなければ、手を入れて5秒耐えるのが難しい程度が、50-55℃の範囲です。水の量を種子の10倍以上にしておかないと、種子を入れたときに温度が急に下がってしまいます。終わったらすぐに冷水で冷まし、水気を乾かしてから播きます。60℃を超えると発芽力が損なわれます。

### 6-3. 播種方法

| 項目 | 基準 | 理由 |
|---|---|---|
| 播種の深さ | 3-5cm | 浅いと乾き、鳥についばまれます。7cmを超えると出てこられません |
| 1穴あたりの粒数 | 2-3粒 | 発芽率を見込みます。後で2本を残して間引きます |
| 条間（1条植え） | 60cm | 風通しと管理用の通路を確保します |
| 株間 | 20-30cm | 矮性種は密に、高性種は広く |
| 2条植え | 畝幅60cm、畝間幅50cm | 2列を向かい合わせに植え、真ん中に支柱を立てます |
| 播種量 | 60-80kg/1,000㎡ | 豆類の中では播種量が多いほうです |

&nbsp;&nbsp;&nbsp;2条植えは、支柱を節約できる配置です。畝1本に2列を植え、真ん中に支柱を1本だけ立てれば、両側のつるが同じ支柱を共用します。資材が足りない条件では、支柱1本で2列をまかなえることが、大きな違いを生みます。

&nbsp;&nbsp;&nbsp;播種直後の最大の脅威は、鳥とネズミです。エンドウの種子は大きくて甘いため、ハトやカササギ、キジが掘って食べ、地中のネズミも見つけ出します。播種した条の上に枝やわらを薄くかぶせるか、発芽するまでネットや古い防虫網をかけるか、きらきら光るひもを交差させて張っておきます。きめ細かい草木灰を種子にまぶすと、においと感触によって避ける効果があります。最も確実なのは、発芽初期の10日間、朝夕に畑を見回ることです。

## 7. 水管理

| 時期 | 水管理 | 理由 |
|---|---|---|
| 播種から発芽まで | 土がからからに乾かないようにします | 種子が水を吸収して初めて発芽するからです |
| 生育初期 | 自然の降水に任せます | この時期の乾燥は、かえって根を深く伸ばします |
| 開花期からさや肥大期 | 土が乾かないよう十分に与えます | この時期が収量を直接決めます |
| 成熟期 | 灌水を中止します | さやが乾かず、カビが生えるからです |
| 梅雨の初め | 排水溝をあらかじめ整えます | エンドウは湿害に非常に弱いからです |

&nbsp;&nbsp;&nbsp;エンドウの水管理は、ほかの豆類とは性格が違います。夏作物は干ばつを心配しますが、エンドウは過湿をより心配します。生育期間が春雨の季節にあたり、茎の中が空洞で組織が軟らかく、根粒菌が好気性だからです。エンドウ畑では、灌水より排水が先です。

| 症状 | 原因 | 対処 |
|---|---|---|
| 日中に葉がしおれ、夕方に回復する | 一時的な水分不足。正常な範囲です | そのままにします |
| 朝になっても葉がしおれている | 根が水を吸い上げられません | 水を十分に与えます |
| 葉が灰白色を帯びて枯れる | ひどい乾燥または高温 | 灌水とマルチングを併せて行います |
| 花が大量に落ちる | 開花期の乾燥、または25℃を超える高温 | 灌水とマルチングで地温を下げます。高温が原因なら回復は難しいです |
| さやはついたのに粒が小さい | さや肥大期の水不足 | この時期の灌水が収量を直接左右します |
| 下の葉が黄色くなり、茎の株元が軟らかくなる | 過湿による根腐れ | 排水溝を掘り、土寄せをします。ひどければ抜き取ります |
| 葉全体が薄い黄色だが、しおれてはいない | 根粒が働かず窒素不足 | 根を掘り上げて根粒を確認します |

&nbsp;&nbsp;&nbsp;水が貴重な条件では、選択と集中が答えです。初期は我慢し、最初の花が見えた時点からさやが膨らむまでの3週間に、水を集中して与えます。少しずつ頻繁に与えるより、一度に土の深さ20cmまで湿るように与え、次の灌水までの間隔をあけるほうが、根が深く張って有利です。マルチングは水を節約する最も安上がりな手段です。ビニールがなくても、わら、もみ殻、落ち葉、刈り取った雑草で5-10cmの厚さに覆えば、表面からの蒸発が半分以下に減り、地温の変動も和らぎます。エンドウは高温に弱いので、地温を下げる効果は特に価値があります。
