## 3. 栽培环境

### 3-1. 气温与光照

| 条件 | 界限值 | 最适值 | 超出范围时 |
|---|---|---|---|
| 发芽温度 | 1-2℃也能发芽 | 18-25℃ | 低温下也能发芽，但非常缓慢 |
| 生长温度 | 4-25℃ | 10-20℃ | 超过25℃，生长停滞，病害暴发 |
| 结实温度 | 13-23℃ | 15-20℃ | 幅度只有10℃，范围很窄 |
| 开花期高温 | 25℃以上持续数日 | - | 花和幼嫩豆荚脱落 |
| 耐寒性 | 低至零下5℃ | - | 幼苗能耐受零下4-7℃ |
| 霜冻 | 开花以后不耐霜冻 | - | 花和豆荚受损 |
| 日照 | 每天6小时以上 | 每天8小时以上 | 遮光40%时，产量降到一半 |

> **豌豆栽培的所有决策，都是朝着躲开炎热的方向做出的。何时播种、选哪个品种、何时收获，全都要从当地第一个炎热日期倒推。**

&nbsp;&nbsp;&nbsp;豌豆的耐寒性与耐热性并不对称。幼龄豌豆能耐受零下5℃，在韩国南部可以在田里越冬。反之，超过25℃花就开始脱落，到30℃叶片枯干，被白粉病覆盖。所以抢早播种几乎总是正确的。在韩国，3月初播种、遭遇1-2次晚霜的损失，远小于4月播种、让花期撞上6月炎热的损失。

&nbsp;&nbsp;&nbsp;秋播只有在韩国南部才可行。10月初到月底播种，让植株带着2-3片真叶越冬，次年3月起重新生长，5月中旬到6月中旬收获。这种栽培类型的价值很大。它比春播根系扎得更深，抗旱能力强，收获提早2-3周，可以完全避开炎热。不过存在越冬失败的风险，所以最好同时留出春播的部分，分散风险。冬季严寒的韩国中部内陆，秋播大多会失败。

### 3-2. 土壤与水分

| 条件 | 界限值 | 最适值 | 备注 |
|---|---|---|---|
| 土壤质地 | 从沙质土到黏质土 | 排水良好的黏壤土-壤土 | 容易积水的地块最差 |
| pH | 6.0-8.0 | 6.5-7.5 | 在酸性土壤中生长明显不良 |
| 有效土层厚度 | 30cm以上 | 50cm以上 | 直根扎得很深 |
| 生长期蒸散量 | - | 约400mm | 在豆类中偏少 |
| 淹水 | 淹水超过一天，根系就会受损 | - | 极不耐渍害 |
| 地下水位 | 50cm以下 | 80cm以下 | 与春雨多的时期重叠 |

&nbsp;&nbsp;&nbsp;豌豆是豆类中对土壤酸碱度要求最高的作物之一。pH 6.5-7.5最适宜，低于6.0时生长明显变差。这一点可由其原产地得到解释：地中海东部多为石灰质土壤。韩国的旱地降雨多，土壤普遍偏酸，所以在豌豆田里，施用石灰是排在施肥之前的作业。而且这一要求，与其说是植株本身的，不如说也是根瘤菌的要求。在酸性土壤中，豆科植株本身还能勉强生长，但根瘤菌无法存活，固氮就会停止。

&nbsp;&nbsp;&nbsp;还需要强调豌豆易受渍害这一弱点。豌豆的生育期横跨春雨和初夏韩国梅雨季（6月下旬至7月）的前段。茎秆中空、组织柔嫩，再加上根瘤菌是好氧细菌，田块只要淹一天，根和根瘤就会一起丧失功能。把垄起高20cm以上、开深排水沟，对豌豆来说不是可选项。

## 4. 品种

### 4-1. 按株高分类

| 类别 | 株高 | 支架 | 收获 | 特点 |
|---|---|---|---|---|
| 矮生种（矮生豌豆） | 30-60cm | 不需要，或简易支撑即可 | 时间短，集中 | 省工。产量较低 |
| 蔓生种（蔓性豌豆） | 1-2m | 必须 | 时间长，分多次 | 产量较高。搭支架和引蔓费工 |
| 中间型 | 60-100cm | 简易支架 | 中等 | 比较均衡 |

&nbsp;&nbsp;&nbsp;在灾害情境下，这一选择取决于劳动力和材料。蔓生种在同样面积上收成多得多，但需要持续地立起2m高的支架、挂网、把藤蔓引上去。如果竹子和绳子充足、人手也有，选蔓生种是对的；如果材料和人手都缺，矮生种更现实。矮生种也可以密植，让植株互相依靠着生长，再沿田块四周拉一圈低矮的绳子，就能在很大程度上防止倒伏。

### 4-2. 按用途分类

| 类型 | 食用部位 | 特点 | 适用情形 |
|---|---|---|---|
| 荚粒兼用（荷兰豆·甜脆豌豆） | 连荚一起吃 | 豆荚不老韧，味甜 | 蔬菜不足时。连皮都吃，没有浪费 |
| 青豌豆用 | 未完全成熟的籽粒 | 籽粒大而甜，含有维生素C | 春季到初夏的新鲜蔬菜 |
| 干籽粒用 | 干燥籽粒 | 耐储性好，蛋白质浓缩 | 用于过冬的储备粮食 |
| 芽苗·嫩苗采收用 | 嫩苗和卷须 | 播种后5-20天采收 | 冬季和早春的新鲜蔬菜 |
| 绿肥用 | 整株茎叶 | 为留下氮素而种植 | 恢复地力时 |

&nbsp;&nbsp;&nbsp;从灾害应对的角度看，最有价值的类型是荚粒兼用型。荚和豆粒一起吃，所以同一块地产出的可食重量增加，也没有需要削掉丢弃的部分。豆荚中含有膳食纤维和维生素，营养面也更广。不过，要连荚吃就必须趁嫩采摘，放着不管，荚皮内侧会长出坚韧的膜，难以下咽。

&nbsp;&nbsp;&nbsp;选择品种的第一条标准是能否自家留种。杂交一代种子，次年再种时性状会分离。好在豌豆的大多数栽培品种都是固定品种，又是自花授粉，收下的种子可以原样播种；但如果种子袋上写着是杂交种，就不要指望来年。地方品种（农家种）虽然产量低，但已经适应了当地的气候和土壤病害，并且能够留种延续。

### 4-3. 不同情形下的选择标准

| 情形 | 优先选择 | 理由 |
|---|---|---|
| 没有支架材料 | 矮生种 | 没有支架也能在一定程度上直立 |
| 地少人多 | 蔓生种 | 向上生长，单位面积产量高 |
| 没有冬季蔬菜 | 芽苗·嫩苗采收兼用 | 不用土，只用水也能发出芽苗 |
| 需要储备粮食 | 干籽粒用，圆粒种子品系 | 比皱粒种子耐储 |
| 炎热来得早的地区 | 早熟矮生种 | 必须在短时间内完成生长 |
| 韩国南部 | 秋播用耐寒品种 | 越冬可使收获提前 |
| 这块地种过豌豆 | 抗枯萎病品系 | 土壤中残留着病原菌 |

## 5. 整地与施肥 - 根瘤菌

### 5-1. 固氮是如何发生的

&nbsp;&nbsp;&nbsp;空气的78%是氮气。人的头顶上飘浮着取之不尽的氮，植物却无法利用。空气中的氮是由两个氮原子以三键牢牢结合而成的分子，要打断这个键需要巨大的能量。工业上打断这个键来制造氨的是哈伯-博施法，世界上的氮肥就来源于此。它需要高温、高压、催化剂和大量化石燃料。

&nbsp;&nbsp;&nbsp;根瘤菌在常温常压下就能完成这件事。它用一种叫固氮酶的酶打断三键，把氮转化为氨。不过这是有代价的。这个反应需要大量能量，而根瘤菌自己不能进行光合作用。因此它进入豆科植物的根中生活，从植物那里获得光合作用制造的糖，作为回报，把固定下来的氮交给植物。这是一种交易关系。

&nbsp;&nbsp;&nbsp;与豌豆配对的菌是Rhizobium leguminosarum bv. viciae。它与大豆的Bradyrhizobium japonicum不是同一个种，两者互不相通。这一点在实践中非常重要：把种过大豆的田里的土沾到豌豆种子上，是没有效果的。反过来，这种菌不仅与豌豆共生，也与蚕豆、小扁豆、野豌豆（苕子）类共生。也就是说，豌豆的接种源，也可以从种过蚕豆、小扁豆或野生野豌豆的田里的土中获得。

| 阶段 | 发生的事 |
|---|---|
| 1. 信号交换 | 豌豆根分泌类黄酮，土壤中的根瘤菌对该信号作出响应，释放结瘤因子（Nod因子） |
| 2. 侵染 | 根毛向内卷曲，把根瘤菌包裹起来，根瘤菌沿着侵染线进入根内 |
| 3. 根瘤形成 | 根内侧的细胞分裂，根瘤膨大，根瘤菌在其中定居 |
| 4. 固氮 | 根瘤内固氮酶开始工作，把空气中的氮转化为氨 |
| 5. 分配 | 氨转变为氨基酸，被输送到藤蔓、叶片和豆荚 |
| 6. 衰老 | 进入灌浆期后，根瘤丧失功能，随根系一同回到土壤中 |

&nbsp;&nbsp;&nbsp;固氮酶极怕氧，一接触氧气就会立即失去活性。因此根瘤内部充满了一种叫豆血红蛋白的红色色素蛋白，它把氧气抓住，使酶周围的氧浓度保持在极低的水平。这与人血呈红色是同一个原理，剖开根瘤时内部呈红色或粉红色，就是这种色素。这一点在实践中非常重要，因为红色是该根瘤此刻正在固氮的肉眼可见的证据。

### 5-2. 如何确认根瘤是否形成

&nbsp;&nbsp;&nbsp;无论是否接种过，都必须确认根瘤是否真的形成了。如果不确认，就无法知道缺氮的原因，来年还会重复同样的失误。

| 步骤 | 内容 |
|---|---|
| 1 | 开花开始的时候，也就是播种后5-7周前后，是最好的时机 |
| 2 | 选取2-3株看起来健康的植株 |
| 3 | 不要直接拔，用铁锹在植株周围大范围挖起，连土一起提起。拔的话，细根上的根瘤会留在土里 |
| 4 | 放入水桶中，轻轻洗去泥土 |
| 5 | 数一数直根和较粗的细根上着生的根瘤个数 |
| 6 | 用指甲掰开几个根瘤，查看内部颜色 |

| 观察结果 | 含义 | 措施 |
|---|---|---|
| 每株根瘤20个以上，尤其集中在直根上部 | 接种成功 | 不用处理 |
| 剖开后内部呈红色或粉红色 | 正在固氮 | 状态良好 |
| 剖开后内部呈白色或浅绿色 | 虽有根瘤，但不固氮 | 检查酸度、渍害和磷缺乏 |
| 剖开后内部呈褐色或黑色 | 已经衰老或死亡 | 若在灌浆期则正常，若在开花期则有问题 |
| 根瘤5个以下 | 接种失败 | 如果叶片发黄，就补充氮素 |
| 根瘤只在细根末端密布，个头细小 | 被土著菌侵染，但效率低 | 来年更换接种源 |

> **挖出根系、剖开根瘤、确认红色，这一个习惯，就是在没有氮肥的世界里判断豆类种植成败最可靠的信号。**

&nbsp;&nbsp;&nbsp;根瘤的位置同样能提供信息。着生在直根上部、距土壤表面10cm以内的粗大根瘤效率最高。这是接种成功时形成根瘤的位置。反过来，如果直根上没有、只有细根末端散布着小根瘤，多半是土壤中原有的土著菌后来才侵染的，固氮效率较低。

### 5-3. 从哪里获取接种源

&nbsp;&nbsp;&nbsp;商品化接种剂，是把活的根瘤菌装在泥炭或黏土中出售的产品。在灾害情境下买不到。但根瘤菌是生活在土壤里的常见微生物，种过同一类豆科作物的田里的土，就是接种源。

| 方法 | 步骤 | 效果 | 注意 |
|---|---|---|---|
| 用种过豌豆的田土拌种 | 从上一年种过豌豆、蚕豆、小扁豆或野豌豆且根瘤生长良好的田里，取表土5-15cm深度的土。把种子稍微用水润湿，均匀地沾上这些土，然后立即播种 | 最可靠，且不花钱 | 有病田块的土会连病原菌一起带过去。发生过豌豆枯萎病的田块绝对要避开 |
| 把土撒到田里 | 在要播种的行上撒上取来的土，一起翻入土中 | 比拌种用量大，但菌能扩散到土壤中 | 参考用量为每10㎡一铁锹左右 |
| 直接使用根瘤 | 把挖出的豌豆根上的根瘤收集起来捣碎，溶在水里，再把种子浸入该水中，然后捞出 | 菌密度最高 | 必须在挖出根瘤的当天用完。干了菌就会死 |
| 留下根茬残体 | 收获时只割茎秆，把根留在田里 | 菌会在土壤中留存到来年 | 这是最省工的维持办法 |
| 野生野豌豆根 | 从田野和田埂上的野豌豆根上采集根瘤 | 与豌豆共生的是同一种菌 | 固氮效率可能低于栽培品种专用的菌系 |

&nbsp;&nbsp;&nbsp;接种时有必须遵守的事项。根瘤菌极怕阳光直射、干燥和高温。受紫外线照射几分钟就会死掉相当一部分，变干后死得更快。给种子拌土要在阴凉处进行，拌好的种子不要摊在太阳下晒，而是立刻播种。最好在30分钟内播下，最迟也要在几小时内完成。放置超过一天再播，效果几乎消失。还有一点，种子消毒和接种不能同时进行。给用过杀菌剂的种子拌土，根瘤菌会死亡。如果是用温水处理消毒的，要等种子完全冷却后再接种。

| 导致接种失败的条件 | 原因 |
|---|---|
| 土壤pH 6.0以下 | 根瘤菌无法存活。豌豆对酸度尤其敏感 |
| 氮肥施得充足的田块 | 植株感觉不到“交易”的必要，自行减少根瘤形成 |
| 容易积水的田块 | 它是好氧细菌，缺氧就会死亡 |
| 缺磷的田块 | 固氮需要大量能量，而其代谢要用到磷 |
| 钼、铁、钴缺乏 | 它们是固氮酶的组成成分 |
| 把接种后的种子放在太阳下晒干 | 紫外线和干燥会使菌死亡 |
| 使用了大豆田的土 | 菌的种不同，不会侵染豌豆 |
