## はじめに
&nbsp;&nbsp;&nbsp;エンドウ(Pisum sativum)は西南アジアと地中海東部原産のマメ科の一年生つる性植物で、最も古い栽培作物の一つです。冬に雨が降り夏に乾く地中海性気候で育った植物なので、涼しいときに育ち、暑くなると枯れ、ほかのマメが夏作物であるのに対して、エンドウだけが春と秋の作物です。3月中旬にまいて6月に収穫し、南部では10月にまいて翌年の5月に収穫するため、マメをまく6月にはエンドウの畑がすでに空いており、1つの畑で1年に2回収穫できます。総合等級はA(48.4点、有効183種中31位)で、短期B(48.2)、長期A(48.6)、副食はSS(64.7点)です。熱量に対するタンパク質の比率が28.7%で、最低ラインの10%の3倍近くあり、播種から収穫まで85-95日、蒸発散量の合計は400mm前後で、マイナス5℃に耐えます。弱点は3つです。面積当たりの熱量がCで、1㎡に885kcal、自給ラインの0.34倍にとどまり、エンドウだけでは腹を満たせません。連作への適応性がDで、5-7年の休作を求めます。つる性なので支柱が必要です。

## 1. 災害への備えの評価
| 区分 | 等級 | スコア |
|:---|:---:|:---:|
| 総合 | A | 48.4 |
| 短期 | B | 48.2 |
| 長期 | A | 48.6 |
| 副食 | SS | 64.7 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: タンパク質密度、施肥、施設の負担、貯蔵性。S: 微量栄養素、味、国内での栽培の普及度、自家採種。A: 収穫速度、水の消費量、耐寒性、合成資材を投入しない場合の収量維持率、収量の安定性。B: 防除の自立度、種子の寿命 |
| 弱み | D: 永続性、日射、連作への適応性。C: 面積当たりの熱量、調理・加工の要求度、温度幅、病害虫圧、整地・掘削エネルギー、非食用の価値 |

> **エンドウの価値は収量ではなく時期にあります。ほかの作物が使えない3月から6月の畑をタンパク質作物で満たすことが、エンドウがA等級を受けた理由です。**

&nbsp;&nbsp;&nbsp;収穫速度Aと耐寒性Aがともに付いたマメ類は珍しいです。早い3月にまいて6月に収穫すると、古い穀物が尽きて秋の収穫がまだ遠い、晩春から初夏のいちばん苦しい時期を埋め、グリーンピースは莢がふくらんだらすぐに摘んで食べられます。温度幅Cは、結実温度が13-23℃しかなく、25℃を超えると花が落ちることから来ています。病害虫圧Cは無防除での被害率が48.9%でダイズ(23%)の2倍ですが、病害虫は気温とともに増えるので、早くまいて早く収穫すれば大部分を避けられ、これが防除の自立度Bの根拠です。いちばん見過ごされやすい弱みは連作への適応性Dです。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | マメ科エンドウ属の一年生つる性植物。自家受粉(花が咲く前に受粉が終わる) |
| 葉、茎 | 羽状複葉で、葉の先が巻きひげに変わる。中空のつる性の茎で、矮性種は30-60cm、高性種は1-2m |
| 根、花 | まっすぐな主根に細根と根粒がつく。白色または赤紫色の蝶形の花 |
| 莢、子実 | 円筒形で5-10cm、種が4-10粒入る。子実は丸いかしわがあり、緑・黄・灰褐色 |

&nbsp;&nbsp;&nbsp;エンドウは下の節から上へ順に花が咲いて熟すため、グリーンピースは3、4日おきに何回も摘まなければなりません。熟した莢をそのままにすると、繁殖を終えたと判断して開花をやめるので、摘むこと自体が収量を増やす管理です。根粒が窒素を渡すまでに3-4週間かかるため、元肥に少量の窒素を入れることに意味があります。乾燥したエンドウは100g当たり熱量354kcal、タンパク質25.37g、脂質1-2.5g、炭水化物約60g、食物繊維20-25g、鉄4-5mgで、ビタミンCはほとんどありません。グリーンピースは80-97kcalでビタミンC 35mgがあり、新鮮な野菜の役割をするので、早いものはグリーンピースとして食べ、遅いものは乾燥させてタンパク質として貯蔵します。穀物に足りないリジンが豊富で、エンドウに足りないメチオニンは穀物にあるため、ご飯と一緒に食べると互いに補い合い、脂質が少ないので粉にしても長持ちします。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽は1-2℃でも可能(適温18-25℃)。生育4-25℃(適温10-20℃)、25℃を超えると生育が止まり病害が増える。結実13-23℃(適温15-20℃)。マイナス5℃まで耐えるが、開花後は霜に弱い |
| 土壌、水 | 排水のよい壌土(水がたまる土地が最も悪い)、pH6.0-8.0(適正6.5-7.5)、地下水位50cm以下(適正80cm以下) |

> **エンドウ栽培のすべての判断は、暑さから逃げる方向で下されます。いつまくか、どの品種を選ぶか、いつ収穫するかは、その地域の最初の暑さの日付から逆算されます。**

&nbsp;&nbsp;&nbsp;エンドウはマメ類のなかで酸度への要求が最も高く、pH6.0を下回ると生育が悪くなり、根粒菌が生きられず窒素固定が止まります。茎が中空で根粒菌が好気性なので、畑が1日冠水しただけで根と根粒がともに機能を失うため、畝を20cm以上高くして排水溝を深く掘ることは選択ではありません。

&nbsp;&nbsp;&nbsp;矮性種(30-60cm)は支柱が要らないか簡単なもので足りて手間が少ない代わりに収量が少なく、高性種(1-2m)は支柱が必須ですが収量が多く、長期間に何回も収穫します。支柱の資材と人手が十分なら高性種、両方とも足りないなら矮性種が現実的です。莢ごと食べるタイプ(サヤエンドウ・スナップエンドウ)は捨てる部分がなくていちばん価値があり、若いうちに摘まないと硬い膜ができます。品種選びの第一の基準は自家採種ができるかどうかで、F1雑種は翌年に形質が分離しますが、ほとんどの栽培品種は固定種なので採った種をそのまま植えられ、在来種はその地域の気候や病害に適応しています。南部では秋まき用の耐寒性品種を、エンドウを植えたことのある畑では萎凋病抵抗性の系統を選びます。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 畑の準備 | 20-30cmの深さに耕し、排水溝は深さ30-50cm。酸性土には播種の15日から3週間前に石灰150kg/1,000㎡(焼いて砕いた貝殻・卵の殻の粉、木灰で代用する)。石灰と肥料は、アンモニアの損失を防ぐために2週間あける |
| 施肥(1,000㎡) | 窒素8.7kg、リン酸50kg(窒素の約6倍)、カリウム16.8kg、堆肥1,500kg(全量元肥)。窒素を控えるのが技術で、多いとつるだけが茂って莢が減り、倒れて病気が広がる。リン酸は骨粉と焼いた魚の骨の粉で補い、木灰は㎡当たり100-200g。追肥は不要だが、開花のころ葉が淡い黄色なら尿の10倍希釈液を少量与える |
| 根粒の接種 | エンドウ・ソラマメ・レンズマメ・カラスノエンドウ類を育てて根粒がよくついた畑の、深さ5-15cmの土を、水で軽く湿らせた種子にまぶし、日陰で30分以内にまく(消毒と併せて行わない)。ダイズ畑の土は菌が違うので無駄で、萎凋病のあった畑の土は避ける |

&nbsp;&nbsp;&nbsp;根粒は、開花のころ(播種後5-7週間)に、株をスコップで土ごと掘り上げて洗い、割って確認します。1株に20個以上あり、内側が赤またはピンク色なら窒素を固定しており、白色や淡い緑色なら固定しておらず、褐色や黒色なら死んでいます(登熟期なら正常)。5個以下なら接種は失敗です。

| 播種 | 基準 |
|:---|:---|
| 時期 | 春まきは2月下旬-4月上旬(中部の適期は3月中旬、早いほど有利)。播種の限界日は、日中の最高気温が25℃を超え始める日から85-95日さかのぼった日。南部の秋まきは10月上旬-下旬で、初霜の40-50日前を目安にして、本葉2-3枚、草丈10cm前後で越冬させ、わらや落ち葉をかぶせる(早くまいて大きく育つと凍死し、中部内陸ではたいてい失敗する) |
| 種子の準備 | 斑点、変色、しわ、虫食いの穴のある種子を捨て、50-55℃の湯に10-15分浸して消毒した後すぐに冷ます(60℃を超えると発芽力が損なわれる)。浸水は6時間以内で、土が湿っていれば浸さない |
| 方法 | 深さ3-5cm、1か所に2-3粒(草丈10cmで勢いのよい2本だけ残す)、条間60cm、株間20-30cm、播種量は1,000㎡当たり60-80kg。畝幅60cm、畝間50cmに2条を向かい合わせにまいて中央の支柱1本を共用する2条植えは、資材が節約できる。鳥とネズミを防ぐために、発芽まで、わらやネットで覆う |

## 5. 水管理と栽培管理
> **エンドウは干ばつよりも過湿を心配する作物なので、灌水より排水が先で、梅雨の前に排水溝をあらかじめ掘ります。水は開花期から莢の肥大期にかけて収量を直接決めるので、水が足りなければこの3週間に集中して与え、少しずつ頻繁に与えるのではなく、一度に土の深さ20cmまでぬらします。**

| 管理 | 方法 |
|:---|:---|
| マルチング | わら・もみ殻・落ち葉を5-10cmの厚さにかぶせると、表面の蒸発が半分以下に減り、地温が下がる(暑さに弱いエンドウにはとくに価値がある) |
| 支柱 | つるが地面に広がると病気が広がり、莢が腐る。巻きひげは直径5mm前後の細いものしかつかめないので、太い杭だけを打たず、細いひもや枝を掛けてやる。ひも誘引がいちばん現実的で、2m間隔で杭を打ち、地面から20cm、50cm、80cmの高さにひもを水平に張り、つるが伸びるにつれて1段ずつ上げる。葉をつけたままの小枝を条に沿って斜めに挿すと、ひももネットも要らず、ネット誘引は収量がいちばん高い |
| 間引き、草取り | 播種後2-3週間に浅くかく1回目、5-6週間に土寄せを兼ねる2回目。最初の1か月の草取りがすべてで、開花後はつるが絡まってちぎれるので畑に入らない |
| 摘心 | つるが支柱の先に届いたときに摘むと、側枝が増え、アブラムシが集まった生長点も取り除かれる。摘んだ芽は、ゆでて和え物にして食べる |

## 6. 病害虫と養分の問題
| 病害虫 | 症状と条件 | 薬を使わない防除 |
|:---|:---|:---|
| うどんこ病 | 葉と茎に小麦粉をふったような白い粉。昼が暑く夜が涼しく乾燥しているとき、生育後期で最大の病害 | 風通しの確保、牛乳を水で5-10倍に薄めて晴れた午前に散布、早めの収穫 |
| 褐斑病 | 葉・茎・莢の褐色の斑点。雨が多く湿っているとき、種子伝染 | 種子の選別、風通しの確保、ボルドー液 |
| 根腐病、萎凋病 | 下の葉から黄色くしおれ、株元と根が褐色に腐る。過湿、連作 | 5-7年の輪作が唯一の根本的な対策、排水と畝を高くすること |
| アブラムシ、ウイルス病 | 生長点と花茎に群がって汁を吸い、ウイルス病(葉が縮んで斑入りになり、生育が止まる)を媒介する最大の害虫 | 摘心、石けん水(水1Lに石けん5g)。ウイルス病は治療できないので、見つけたらすぐに抜いて焼く |
| エンドウゾウムシ | 畑の莢に産卵し、貯蔵中に子実を食い荒らす | 完全に乾燥させてから密閉して貯蔵する(第9節を参照) |

> **エンドウの連作障害は、マメ類のなかで最もひどいです。萎凋病と根腐病の休眠胞子は何年も土の中で生き延び、一度汚染された畑は薬で元に戻すことができず、畑を移すほかに方法はありません。**

&nbsp;&nbsp;&nbsp;ボルドー液は、水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜ、すぐに使います。

| 症状 | 原因と対処 |
|:---|:---|
| 生育が悪く根が短い | 肥料よりも先に酸度を疑う。pH6.0を下回ると窒素を与えても回復しないので、石灰や焼いて砕いた貝殻の粉を与える |
| 下の葉から淡い黄色になり、株が小さい | 窒素欠乏(根粒の不良)。根を掘り上げて根粒を確認し、なければその年は尿の10倍希釈液を少量与え、翌年の接種を確実に行う |
| 花が咲いても莢がつかない | ホウ素欠乏または開花期の高温。いろいろな材料を混ぜた堆肥、高温が原因なら翌年の播種を早める |

&nbsp;&nbsp;&nbsp;根粒が固定する窒素は1ヘクタール当たり80-130kg(条件が悪いと25-50kg)、子実として持ち出される窒素は90-110kgで、つると葉に25-40kgが残ります。つるを戻せば収支はほぼ釣り合いますが、持ち出したり焼いたりすれば確実な損失です。6月の暖かく湿った土ではエンドウの茎葉が早く分解されるので、つるを20-30cmに切ってかぶせると夏作物がその窒素をすぐに使い、開花期に丸ごとすき込むと、子実をあきらめる代わりに窒素が最も多く残ります。つるを家畜に与えたなら、その糞尿を必ずその畑に入れます。

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | レタスとホウレンソウ(エンドウの日陰で育って空間を共有し、生育期間が同じ)、ダイコンとカブ(根の深さが違い、養分の層が重ならない)、ジャガイモ(病害が重ならず、エンドウを先に収穫する)、ニンジン(エンドウが残した窒素を後で使う) |
| 普通 | トウモロコシ(理論上は支柱になるが、播種期が2か月ずれるので、別に支柱を立てる) |

&nbsp;&nbsp;&nbsp;連作すると萎凋病と根腐病がたまり、数年でエンドウを植えられない畑になるので、5-7年以上休ませます。6年輪作の例は、エンドウ(春)とハクサイまたはダイコン(秋) → トウモロコシまたはモロコシ → ジャガイモまたはサツマイモ → ダイズまたはササゲ → オオムギ・コムギの次にソバ → 根菜または緑肥です。畑が狭いときは、区画を分けて毎年1区画ずつ移して植えるか、毎年土を替える袋に植え、スプラウトや若芽が目的なら土なしで水だけで十分です。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 莢ごと、グリーンピース | 莢ごと食べる品種は50-60日で、莢が平たく中の粒がまだ小さいとき。グリーンピースは60-80日(開花後20-30日)で、莢がふくらんで表面がなめらかなときがいちばん甘く、網目模様が現れたら最後の時期。3、4日おきに摘む |
| 乾燥子実 | 85-95日、莢の8割以上が黄色または褐色に変わり、振ると粒の音がして、かむとぱきっと割れるとき(水分13-15%)。脱粒しやすく、乾いた莢が雨に当たると一瞬ではじけるので、雨の知らせがあれば完熟を待たずにつるごと刈る |
| 乾燥、脱穀 | 晴れた日の露が乾いた後に、つるの株元を鎌で刈り、根は畑に残す。束ねて軒下に逆さにつるし、下に布やむしろを敷いて乾かす。押すと莢がぱかっと開くころ、乾いたつるを袋に入れて踏むか、むしろの上に薄く広げて殻竿でたたくか、桶の内側の壁に打ちつけて脱穀する(乾き方が足りないと開かず、乾きすぎると粒が割れる) |
| 選別 | 唐箕がけは、風が一定の早朝か日暮れに細く流し落として2、3回行う。水に浮かせるとエンドウゾウムシに食われた粒としいなが選別できるが、その日のうちに乾かし直し、種子用には使わない |

| 採種 | 基準 |
|:---|:---|
| 選抜 | 病気の症状がなく、莢がたくさんつき、暑さが来る前に早く熟した株を、畑であらかじめ印をつけておく。花が咲く前に受粉が終わるので隔離は不要 |
| 乾燥、保管 | 水分12-13%に乾燥させ、かむとぱきっと割れる状態が適正。常温で密閉して2-3年、条件がよければ4年。褐斑病は種子伝染するので斑点のある種子を除き、3年ごとに別の場所から種子を入手して一部を混ぜる |

## 9. 貯蔵
| 段階 | 方法 |
|:---|:---|
| 乾燥 | つるごと軒下に逆さにつるして2-3日乾かした後、食用は水分12-13%、種子は12%に調整する |
| ゾウムシ防除 | 完全な密閉が最も重要: 容器をいっぱいに満たして空間を減らし、小さな容器いくつかに分ける。ふるった木灰を体積の2-5%混ぜる(食べる前にすすぐ)。エンドウ1kgに食用油2-5mLをもみ込む(半年以内に食べる分だけ、種子用は除く) |
| 容器 | ガラス瓶・金属缶は3年以上、かめ・地下貯蔵穴は2-3年、厚手のビニールは1-2年。金属缶は結露、地下貯蔵穴は浸水、ビニールはネズミの被害に注意 |
| 点検 | 2か月に一度。容器に耳を当てて、かさかさという音(虫)、かび臭いにおい(かび)、小さく丸い穴(ゾウムシ)を確認する。見つけたら全量を取り出して日なたで乾かし、水に浮かせて空の粒をすくい取り、灰や油を混ぜて再び密閉する |
| グリーンピース | 摘んだ直後から甘みが落ちるので、その日に食べるか、ゆでて乾燥させるか(数か月、水に浸して戻す)、ゆでて塩漬けにする(数か月)。莢ごと涼しい所に置けば3-5日 |

## 10. 調理と注意事項
> **エンドウそのものは安全です。実際に人を害するのは、誤って貯蔵してかびが生えた豆です。かび臭いにおいがしたり、表面に青みがかった粉が見えたりしたら、洗っても加熱しても安全にならないので、惜しくても捨てます。**

&nbsp;&nbsp;&nbsp;インゲンマメの強いレクチンも、ソラマメの溶血性の成分もないので、グリーンピースは生で数粒食べても問題なく、乾燥したエンドウのトリプシンインヒビター(タンパク質分解酵素を妨げる)もダイズよりはるかに少ないので、20-30分の加熱で十分です。ただし食物繊維が多いので、長く飢えた人や子どもに急にたくさん食べさせると、腹部の膨満感と下痢が起こるため、最初は少量から始めて数日かけて増やします。

| 調理 | 方法 |
|:---|:---|
| 煮る | 室温の水に4-8時間浸し(浸した水は捨ててオリゴ糖を減らす)、沸騰した湯で20-30分煮る(ダイズの60分に比べると半分以下) |
| 割りエンドウ | 乾燥したエンドウを臼で軽くつき、皮を吹き飛ばすと半分に割れ、浸水せずに20分で粥のように煮える。皮は家畜の飼料と堆肥にする |
| 燃料の節約 | 10分煮た後、火を消して、わらやもみ殻を詰めた箱や布団で鍋ごと包み、1-2時間置く |
| 炒りエンドウ、粉 | 弱火で炒ってそのまま食べるか、挽いて粉にして水に溶いて飲む(密閉して3-6か月、調理燃料が要らない)。ゆでて乾燥させたグリーンピースは、冬に汁物や粥に入れる |

&nbsp;&nbsp;&nbsp;乾燥したエンドウにはビタミンCがありませんが、芽を出すと新しく生じるので、乾燥したエンドウ一握りと水と容器さえあれば、5-7日で新鮮な野菜が得られます。ぬるま湯に6-8時間浸して2倍にふくらませ、水が抜ける容器に入れて湿らせた布をかぶせ、1日2-3回、上から十分に注いで水を抜きます。モヤシと違って、最初の3、4日は暗く置き、2日は明るい所に置いて葉を緑色にするとビタミンが増え、茎が5-10cmになったら収穫して和え物にして食べます。土を浅く入れた箱に密にまくと、15-20cmのしっかりした若芽がとれ、はさみで切って収穫した後にもう一度収穫できます。

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵の点検、種子の発芽試験、支柱資材の手入れ、スプラウト作り。2月に石灰の散布、堆肥の切り返し、下旬に土が解けたら早まき |
| 3-4月 | 3月に本播種、鳥よけ、支柱立て(播種の限界日は最初の暑さから85-95日さかのぼる)。4月に間引き、1回目の草取り、つるの誘引、若芽の収穫 |
| 5-6月 | 5月に開花、灌水を集中、アブラムシの管理、根粒の確認。6月にグリーンピースの順次収穫(3、4日おき)、南部の秋まき分の収穫 |
| 7-8月 | 7月に乾燥子実の収穫、つるして乾かす、脱穀、茎葉のすき込み。8月に選別、乾燥、貯蔵、畑の整理(つるは焼かずに切ってかぶせる) |
| 9-10月 | 9月に秋まきの畑の準備と石灰の散布(南部)。10月に秋まき(初霜の40-50日前)、越冬の準備 |
| 11-12月 | 11月にわら・落ち葉をかぶせる、排水溝の点検。12月に貯蔵の点検、スプラウト作り、翌年の計画 |

> **エンドウは、早くまき、5-7年の休作を守り、細いひもと枝でつるを支え、収穫後につるを畑に戻し、3、4日おきに摘むとき、その値打ちを発揮します。**
