## 13. 留种

| 项目 | 方法 |
|---|---|
| 留种株选拔 | 无病症、结荚多、成熟早的植株，要在田里提前做好标记 |
| 收获时期 | 豆荚完全变成褐色后再收。比食用的稍晚收获 |
| 分开处理 | 单独脱粒。用手剥的话豆粒不会受伤 |
| 筛选 | 有斑点、皱缩、变色的豆粒和小粒全部扔掉。只留下粒大有光泽的 |
| 干燥 | 含水量12-13%。咬下去咬不进去，会“啪”地裂开 |
| 保管 | 装入密封容器，放在阴凉避光处。与食用的分开用不同容器 |
| 保管期限 | 常温密封2-3年。条件好的话可以保存到4年 |
| 更新 | 每3年从别处获取种子，掺入一部分 |

&nbsp;&nbsp;&nbsp;豌豆是最容易留种的作物之一。花开之前，授粉就已在花内完成，花瓣把雌蕊和雄蕊完全包住，外来花粉几乎进不去。这就是孟德尔选豌豆作实验材料的原因，也是即使把多个品种并排种植性状也不会混杂的原因。也就是说，不必担心隔离距离。

&nbsp;&nbsp;&nbsp;需要注意的是种传病害。褐斑病会随着种子传到下一代。把肉眼可见的斑点种子挑出去可以防住相当一部分，但没有表现症状的潜伏感染是筛不掉的。每3年从另一个山谷或邻村获得豌豆，掺入一部分，可以缓解这一问题。

&nbsp;&nbsp;&nbsp;在田里提前给留种株做标记的习惯，会大大改变结果。收获后只看豆粒来挑，选的只是大小和形状。在田里挑，则可以同时选出豆荚数量、抗枯萎病、耐热、早熟这类真正重要的性状。尤其对豌豆来说，在炎热到来之前就先成熟的植株，挑选出来很有价值。只要重复几年，就会形成适应该块田夏季到来时间的品系。

| 种子保管期限与发芽率 |
|---|
| 收获当年：90%以上 |
| 经过1年：80-90% |
| 经过2年：60-80% |
| 经过3年：40-60% |
| 4年以后：急剧下降 |

## 14. 毒性与抗营养成分

&nbsp;&nbsp;&nbsp;豌豆是豆类中毒性风险最低的一类。它既没有像菜豆那样生吃几粒就能引起中毒的凝集素，也没有像蚕豆那样在特定体质者身上引起急性溶血的成分。青豌豆生吃几粒也不会出问题。不过，干豌豆与其他豆类一样含有抗营养成分，大量食用时需要处理。

| 成分 | 作用 | 症状 | 去除方法 |
|---|---|---|---|
| 胰蛋白酶抑制剂 | 抑制蛋白质分解酶的作用 | 腹部不适，蛋白质利用率下降 | 浸泡后在沸水中加热20-30分钟。含量比大豆低得多 |
| 凝集素 | 附着在肠黏膜上，妨碍吸收 | 少量无害 | 加热即可轻易破坏。与菜豆类不同，毒性很弱 |
| 植酸 | 与铁、锌、钙结合，阻碍吸收 | 长期食用会导致贫血、缺锌 | 通过浸泡、发芽、发酵可减少60-80% |
| 低聚糖（棉子糖·水苏糖） | 人体无法消化，由肠道细菌发酵 | 肚子胀气 | 浸泡后倒掉浸泡的水 |
| 皂苷 | 起泡 | 少量无害 | 煮的时候撇去浮沫 |
| 霉菌毒素 | 贮藏期间由霉菌产生 | 危险 | 长霉的豌豆洗了或煮熟了也不会变安全。要扔掉 |

> **豌豆本身是安全的。在豌豆上真正会伤害人的，不是豆子，而是因贮藏不当而长霉的豆子。如果有潮霉味，或者表面出现青绿色粉末，不要舍不得，直接扔掉。**

| 处理 | 时间·温度 | 效果 |
|---|---|---|
| 浸泡 | 常温水中4-8小时 | 热量能透到内部，低聚糖溶入水中 |
| 倒掉浸泡水 | 必须 | 把溶入水中的低聚糖和抗营养成分一并倒掉 |
| 煮 | 沸水中20-30分钟 | 与大豆的60分钟相比不到一半 |
| 去皮劈半豌豆 | 去皮后劈成两半的豌豆 | 不用浸泡，20分钟就能煮熟。耗燃料最少 |
| 确认煮熟 | 用手指一按就容易压烂 | 如果还有硬心，就是没煮熟 |

&nbsp;&nbsp;&nbsp;烹饪·加工等级为C，比大豆的D高一级，这个差别体现在燃料上。大豆要泡8小时、煮1小时以上，而豌豆泡4小时、煮30分钟就够了。去皮劈半的豌豆，不用泡，20分钟就能煮烂。在燃料珍贵的条件下，这个差别每天都在累积。

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;豌豆的耐储性为SS。干籽粒在常温下可存放3年，脂肪含量仅1-2.5%，非常低，所以酸败也慢。但是，一旦条件失当，一种豌豆象就能把储存的豌豆全部变成空壳。

> **豆子不是因腐烂而损失，而是被虫吃掉而损失。贮藏的技术，就是防虫的技术。**

### 15-1. 干燥是第一步

| 阶段 | 方法 | 检查 |
|---|---|---|
| 预干燥 | 连藤倒挂在屋檐下2-3天 | 豆荚干透 |
| 脱粒后干燥 | 薄薄摊在草席或席子上，晒2-3天 | 经常翻动，使其干得均匀 |
| 目标含水量 | 食用12-13%，种子12% | 用牙咬时咬不进去，会“啪”地裂开 |
| 盐试验 | 把干盐和豌豆一起装进瓶子里摇晃 | 盐粘在瓶壁上，说明还潮 |
| 冷却 | 从太阳下收进来后，完全冷却再装入 | 温热状态下密封会产生冷凝水 |

&nbsp;&nbsp;&nbsp;干燥不足，后面所有的对策都会落空。含水量超过15%会长霉，超过13%豆象繁殖会加快。反过来，低于10%时种皮开裂，贮藏中会破碎，如果是种子用，发芽力会下降。

### 15-2. 贮藏期间豆象的防治

&nbsp;&nbsp;&nbsp;豌豆象（Bruchus pisorum）是贮藏豌豆的最大威胁。可怕之处在于，它在田里就已经开始了。成虫把卵产在仍长在田里的豆荚上，这些卵在贮藏库里孵化，钻进豆子里。也就是说，豆子入库时就已经带着卵，而且一代不到一个月，半年就能让一整袋变成满是虫孔的空壳。

| 方法 | 原理 | 应用 | 效果 |
|---|---|---|---|
| 完全密封 | 隔绝氧气使其窒息 | 把玻璃瓶或金属罐装满后封严 | 最可靠。3-4周内连卵和幼虫都会死亡 |
| 掺草木灰 | 微细颗粒刮伤外骨骼的蜡质层，使其脱水 | 掺入豌豆体积的2-5% | 食用前用水冲洗掉 |
| 硅藻土 | 硅质外壳损伤外骨骼 | 每1kg豌豆用1-3g | 比草木灰效果更好。只有在干燥状态下才起作用 |
| 油膜涂层 | 油膜阻止卵附着和孵化 | 每1kg豌豆加2-5mL食用油搓匀 | 对豆类效果显著。不用于种子 |
| 低温处理 | 零下温度会使卵和幼虫死亡 | 隆冬时放到室外几天后再收回 | 收回时注意冷凝水 |
| 高温处理 | 60℃时卵和幼虫会死亡 | 薄薄摊在太阳下放半天 | 不用于种子 |
| 干辣椒·花椒·艾草 | 精油成分抑制产卵 | 一层一层夹放 | 辅助手段 |
| 木炭·炒盐 | 吸收湿气 | 用布包好放入 | 兼有防霉作用 |
| 埋入灰中 | 同时获得密封和物理防治的效果 | 在坛子里一层灰一层豌豆地堆放 | 传统上广泛使用 |

&nbsp;&nbsp;&nbsp;最重要的是完全密封。虫子也要呼吸。在密封的容器里，豆子和虫子消耗氧气，氧气减少、二氧化碳升高，虫子就会死亡。豆子处于休眠状态，能耐受这种条件。容器装得越满、空隙越少，见效越快。与其用一个大桶，不如用几个小桶装得满满的，这样一个桶坏了也不会全部损失，也是一项好处。

&nbsp;&nbsp;&nbsp;油膜涂层是印度和非洲的小农户长期使用的方法。每1kg豌豆加2-3mL食用油，用手搓匀，使每粒豆子都形成一层薄膜。油膜使成虫难以产卵，并堵住已产下的卵的气孔，妨碍孵化。只用于半年内要吃的那部分，不用于种子，因为油膜会妨碍呼吸，使发芽力下降。草木灰要过筛，只选细的部分，按豌豆体积的2-5%掺入。虫子不会产生抗性，对人也无害。

### 15-3. 贮藏容器与场所

| 容器 | 密封性 | 期限 | 优点 | 缺点 |
|---|:---:|---|---|---|
| 玻璃瓶 | 很好 | 3年以上 | 可以用眼睛看到里面的状态 | 容量小，不能挡光 |
| 金属桶 | 很好 | 3年以上 | 能完全挡住老鼠和虫子 | 一旦产生冷凝水，那个位置会变质 |
| 坛子 | 好 | 2-3年 | 温度变化缓慢，老鼠咬不穿 | 重，易碎 |
| 厚塑料袋 | 一般 | 1-2年 | 轻便便宜 | 老鼠能咬穿 |
| 地下贮藏窖 | 好 | 2-3年 | 温度恒定且低 | 一旦渗水就会全部损失 |

&nbsp;&nbsp;&nbsp;检查时最可靠的感官是听觉和嗅觉。把耳朵贴在桶上，如果听到沙沙声，说明虫子在活动；如果有潮霉味，说明已经开始长霉。如果豌豆表面看到小而圆的孔，说明豆象已经繁殖过一代。即便到了这一步，只要把全部豌豆取出来晒干，放入水中捞掉空豆，再掺入草木灰或油后重新密封，仍然可以保住剩下的部分。每两个月检查一次是基准。

### 15-4. 青豌豆的短期贮藏

| 方式 | 方法 | 期限 |
|---|---|---|
| 连荚放在阴凉处 | 不洗，装进通风的篮子里 | 3-5天 |
| 焯后晒干 | 稍微焯一下，沥干水分，在太阳下晒到干透 | 几个月。用水泡发复原 |
| 盐腌 | 焯后一层一层撒盐，装入坛子 | 几个月。食用前用水泡去盐分 |
| 地下贮藏 | 放在阴凉的地窖里 | 1周左右 |

&nbsp;&nbsp;&nbsp;青豌豆从收获的那一刻起，糖就开始转变为淀粉，过一天甜味就明显减少。在没有冰箱的条件下，几乎没有办法长期保存青豌豆。要么当天吃掉，要么焯后晒干，要么用盐腌，三者择一。焯后晒干的豌豆，冬天用水泡发后放进汤或粥里，色泽和味道能恢复不少。

## 16. 烹饪与加工

### 16-1. 豌豆芽苗 - 不用土就能种的冬季蔬菜

&nbsp;&nbsp;&nbsp;干豌豆中实际上没有维生素C。但是让它发芽，原本没有的维生素C就会生成。这是因为发芽这一生理转换发生时，植物重新合成了它。冬天完全没有新鲜蔬菜的时候，只要有一把干豌豆、水和一个容器，5-7天就能得到新鲜蔬菜。既不需要田，也不需要土。

| 步骤 | 内容 | 要点 |
|---|---|---|
| 1. 挑选 | 扔掉破裂或被虫蛀的豆粒 | 破裂的豆粒会腐烂，连累全部 |
| 2. 清洗 | 反复冲洗，捞掉浮起来的 | 浮起来的豆粒多半是死豆 |
| 3. 浸泡 | 在温水中浸泡6-8小时 | 豌豆要膨胀到两倍 |
| 4. 装容器 | 放入能排水的容器，盖上湿布 | 积水就会腐烂 |
| 5. 浇水 | 每天2-3次，从上面充分淋下 | 兼具冲走代谢废物和调节温度的作用 |
| 6. 收获 | 5-7天，茎5-10cm | 与豆芽不同，可以见光 |

&nbsp;&nbsp;&nbsp;豌豆芽苗不同于豆芽。豆芽要完全遮光，培养出白色的茎，而豌豆芽苗反而见光长出绿叶，营养更好。最初3-4天放在暗处，让根和茎伸长，然后移到明亮处放2天，叶片就会变绿，叶绿素和维生素增加。这种绿叶被称为豌豆苗，可作凉拌野菜（namul）食用。

&nbsp;&nbsp;&nbsp;在浅浅装了土的箱子里密密撒上豌豆来培育，可以得到更长更壮的嫩苗。长到15-20cm时，用剪刀从基部剪下收获，留着不动还会再长出一茬。冬季在室内轮流培育2-3个箱子，就能源源不断地得到绿色蔬菜。维生素C缺乏会在几个月里悄悄发展，最后以牙龈出血、伤口不愈合的症状显现出来，而豌豆芽苗是解决这一问题既便宜又可靠的答案。

### 16-2. 节省燃料的烹饪

| 方法 | 燃料 | 步骤 |
|---|:---:|---|
| 劈半豌豆粥 | 很少 | 去皮劈半的豌豆不用浸泡，20分钟就能煮烂 |
| 压力烹饪 | 最少 | 把泡好的豌豆加压10分钟 |
| 余热烹饪 | 很少 | 煮10分钟后熄火，用装了稻草·稻壳的箱子或被子包住，放1-2小时 |
| 炒豌豆 | 较少 | 把干豌豆用小火炒。可以直接吃 |
| 豌豆粉 | 几乎不用 | 炒后捣碎备用，用水冲调食用。脂肪少，能保存很久 |
| 芽苗 | 无 | 发芽不需要热量 |

&nbsp;&nbsp;&nbsp;去皮劈半的豌豆在灾害条件下是特别宝贵的形态。把干豌豆放入臼中轻轻捣一捣，扬去豆皮，豆粒就会自己裂成两半。这样一来，水能直接渗到豆心，不需要浸泡，20分钟就能煮成粥状。印度的达尔（dal）、欧洲的豌豆汤都采用这种形态，是节省燃料的古老智慧。豆皮也不要扔，收集起来，用作牲畜饲料或堆肥。

&nbsp;&nbsp;&nbsp;余热烹饪对豌豆也很有效。只煮10分钟，然后放进保温箱，内部温度能在1小时以上保持较高，烹饪得以继续。豌豆不像大豆那样含有需要彻底破坏的强毒性成分，所以用余热烹饪也能安全煮熟。用装满稻草或稻壳的木箱，或者厚被子把整口锅包起来，那就是保温箱。

### 16-3. 贮藏加工

| 加工 | 步骤概要 | 保管 | 价值 |
|---|---|---|---|
| 豌豆粉 | 炒后捣碎 | 密封3-6个月 | 不需要烹饪燃料 |
| 焯后晒干的青豌豆 | 焯后沥干水分，晒到干透 | 几个月 | 冬天放进汤和粥里 |
| 豌豆大酱 | 煮后捣烂，像酱曲（meju）那样发酵，再浸入盐水 | 数年 | 大豆不足时的替代办法 |
| 豌豆嫩苗腌菜 | 把嫩苗用盐腌 | 几个月 | 把春天的凉拌野菜留到冬天 |
| 炒豌豆 | 用小火炒 | 密封1-2个月 | 既是零食，也是应急食品 |

&nbsp;&nbsp;&nbsp;用豌豆制酱虽然不是广为人知的做法，但原理与大豆相同。煮后捣烂，捏成块，用稻草包好使其发酵，然后浸入盐水。豌豆的蛋白质比大豆少，鲜味较差，但经过发酵，抗营养成分被分解，消化率提高，与盐一起可保存数年。在没能获得大豆的年份，如果豌豆充足，这是值得一试的办法。

### 17-1. 不能忘记的五件事

| 项目 | 内容 |
|---|---|
| 播种时期 | 播得晚是失败的最大原因。哪怕会受一点霜冻，也要早播 |
| 连作 | 需要休作5-7年。在豆类中最长。违反就会失去这块田 |
| 支架 | 卷须只能抓住细的东西。只钉粗木桩是毫无用处的 |
| 茎叶 | 如果不把藤蔓、叶片和根还给田地，豌豆就成了掠夺地力的作物 |
| 收获 | 摘了会结得更多，不摘就会停止。每隔3-4天分批采收 |
