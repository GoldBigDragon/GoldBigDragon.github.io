## 13. 採種

| 項目 | 方法 |
|---|---|
| 採種株の選抜 | 病気の症状がなく、さやが多くつき、早く熟した株に、畑で前もって印をつけておきます |
| 収穫時期 | さやが完全に褐色に変わってから収穫します。食用より少し遅く収穫します |
| 分離 | 別に脱穀します。手でむくと豆が傷みません |
| 選別 | 斑点、しわ、変色、小さい豆をすべて捨てます。大きくてつやのある豆だけを残します |
| 乾燥 | 水分12-13%。噛んだときに歯が立たず、パキッと割れます |
| 保管 | 密閉容器に入れ、涼しく暗い場所に置きます。食用とは別の容器にします |
| 保管期間 | 常温・密閉で2-3年。条件がよければ4年までもちます |
| 更新 | 3年ごとに、よそから種子を入手して一部を混ぜます |

&nbsp;&nbsp;&nbsp;エンドウは、採種が最も簡単な作物の一つです。花が開く前にすでに花の中で受粉が終わっており、花びらが雌しべと雄しべを完全に包み込んで、外部の花粉がほとんど入れません。メンデルがエンドウを実験材料に選んだ理由がこれで、複数の品種を並べて植えても形質は混ざりません。隔離距離を心配する必要がないということです。

&nbsp;&nbsp;&nbsp;注意すべき点は、種子伝染性の病気です。褐紋病は種子を通じて次の世代へ受け継がれます。目に見える斑点を取り除けばかなり防げますが、症状が現れない潜在感染は取り除けません。3年ごとに、別の谷や隣の村からエンドウを手に入れて一部を混ぜると、この問題が和らぎます。

&nbsp;&nbsp;&nbsp;採種用の株を畑で前もって印をつけておく習慣が、結果を大きく変えます。収穫後に豆だけを見て選ぶと、大きさと形しか選べません。畑で選べば、さやの数、萎凋病への抵抗性、暑さへの耐性、早く熟す性質など、実際に重要な形質を一緒に選べます。特にエンドウでは、暑さが来る前に先に熟す個体を選び出すことに価値があります。数年繰り返すだけでも、その畑の夏の訪れる時期に合った系統ができあがります。

| 種子の保管期間と発芽率 |
|---|
| 収穫当年：90%以上 |
| 1年経過：80-90% |
| 2年経過：60-80% |
| 3年経過：40-60% |
| 4年目以降：急激に低下します |

## 14. 毒性と抗栄養成分

&nbsp;&nbsp;&nbsp;エンドウは、豆類の中で毒性のリスクが最も低い部類に入ります。インゲンマメのように生の数粒で中毒を起こすレクチンも、ソラマメのように特定の体質で急性溶血を起こす成分もありません。グリーンピースは、生で数粒食べても問題ありません。ただし、乾燥エンドウには、ほかの豆と同様に抗栄養成分が含まれており、たくさん食べるときには処理が必要です。

| 成分 | 働き | 症状 | 取り除く方法 |
|---|---|---|---|
| トリプシンインヒビター | タンパク質分解酵素の働きを妨げます | 腹部の不快感、タンパク質利用率の低下 | 浸水後、沸騰した湯で20-30分加熱。ダイズよりも含有量がはるかに低いです |
| レクチン | 腸の粘膜に付着して吸収を妨げます | 少量は無害です | 加熱で簡単に破壊されます。インゲンマメ類と違って毒性は非常に弱いです |
| フィチン酸 | 鉄、亜鉛、カルシウムと結合して吸収を妨げます | 長期間食べると貧血、亜鉛欠乏 | 浸水、発芽、発酵で60-80%まで減ります |
| オリゴ糖（ラフィノース・スタキオース） | 人は消化できず、腸内細菌が発酵させます | お腹にガスがたまります | 浸水後、浸した水を捨てます |
| サポニン | 泡を立てます | 少量は無害です | 煮ながら泡（アク）をすくい取ります |
| カビ毒 | 貯蔵中にカビがつくります | 危険です | カビが生えたエンドウは、洗っても加熱しても安全になりません。捨てます |

> **エンドウそのものは安全です。エンドウで実際に人を害するのは、豆ではなく、誤った貯蔵でカビが生えた豆です。湿っぽいにおいがしたり、表面に青みがかった粉が見えたりしたら、もったいながらずに捨てます。**

| 処理 | 時間・温度 | 効果 |
|---|---|---|
| 浸水 | 常温の水に4-8時間 | 中まで熱が通りやすくなり、オリゴ糖が水に溶け出します |
| 浸した水を捨てる | 必ず行う | 水に溶け出したオリゴ糖と抗栄養成分を一緒に捨てます |
| 煮る | 沸騰した湯で20-30分 | ダイズの60分と比べると半分以下です |
| 割りエンドウ | 皮をむいて半分に割ったもの | 浸水なしで20分あれば火が通ります。燃料が最も少なくて済みます |
| 火の通り具合の確認 | 指で押すと簡単につぶれます | 芯が残っていれば、まだ火が通っていません |

&nbsp;&nbsp;&nbsp;調理・加工の等級がCなのは、ダイズのDより一段階よい値で、その差は燃料に現れます。ダイズは8時間浸して1時間以上煮る必要がありますが、エンドウは4時間浸して30分で済みます。皮をむいて半分に割ったエンドウなら、浸さなくても20分で柔らかく煮えます。燃料が貴重な条件では、この差が毎日積み重なっていきます。

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;エンドウの貯蔵性はSSです。乾燥した子実は常温で3年もち、脂質含量が1-2.5%と非常に低いため、酸敗も遅くなります。しかし、条件が外れると、エンドウゾウムシ一種が、貯蔵したエンドウのすべてを抜け殻に変えてしまいます。

> **豆は腐って失うのではなく、虫に食べられて失います。貯蔵の技術とは、すなわち虫を防ぐ技術です。**

### 15-1. まず乾燥が先です

| 段階 | 方法 | 確認 |
|---|---|---|
| 予備乾燥 | つるごと軒下に逆さに吊るして2-3日 | さやがからからに乾きます |
| 脱穀後の乾燥 | むしろやござに薄く広げて日なたで2-3日 | こまめに返して、むらなく乾かします |
| 目標水分 | 食用12-13%、種子12% | 歯で噛んだときに歯が立たず、パキッと割れます |
| 塩テスト | 乾いた塩をエンドウと一緒に瓶に入れて振ります | 塩が瓶の壁にくっつくなら、まだ湿っています |
| 冷ます | 日なたから取り込んだ後、完全に冷ましてから容器に入れます | 温かいまま密閉すると結露が生じます |

&nbsp;&nbsp;&nbsp;乾燥が不足すれば、その後のあらゆる対策が無駄になります。水分が15%を超えるとカビが生え、13%を超えるとゾウムシの繁殖が速まります。逆に10%を下回ると、種皮が割れて貯蔵中に砕け、種子用であれば発芽力が落ちます。

### 15-2. 貯蔵中のマメゾウムシ類の防除

&nbsp;&nbsp;&nbsp;エンドウゾウムシ（Bruchus pisorum）は、貯蔵エンドウに対する最大の脅威です。恐ろしいのは、畑ですでに始まっているという点です。まだ畑についているさやに成虫が卵を産みつけ、その卵が貯蔵庫の中で孵化して、豆の中に食い入ります。収穫物を取り込む時点ですでに卵がついてくる仕組みで、1世代が1か月足らずのため、半年で袋ひとつ分が穴だらけの殻で埋まります。

| 方法 | 原理 | 適用 | 効果 |
|---|---|---|---|
| 完全密閉 | 酸素を断って窒息させます | ガラス瓶や金属缶をいっぱいに満たして封をします | 最も確実です。3-4週間で卵や幼虫まで死にます |
| 草木灰を混ぜる | 微細な粒子が外骨格のワックス層を傷つけて脱水させます | エンドウの容積の2-5%を混ぜます | 食べる前に水で洗い流します |
| ケイソウ土 | ケイ酸質の殻が外骨格を傷つけます | エンドウ1kgに1-3g | 灰より効果が大きいです。乾いた状態でしか働きません |
| 油コーティング | 油膜が卵の付着と孵化を防ぎます | エンドウ1kgに食用油2-5mLを加えてもみ込みます | 豆類に効果が大きいです。種子用には使いません |
| 低温処理 | 氷点下で卵や幼虫が死にます | 真冬に数日間、屋外に出してから取り込みます | 取り込むときに結露に注意します |
| 高温処理 | 60℃で卵や幼虫が死にます | 日なたに薄く広げて半日置きます | 種子用には使いません |
| 乾燥トウガラシ・サンショウ・ヨモギ | 精油成分が産卵を抑制します | 層状に重ねて入れます | 補助的な手段です |
| 炭・炒った塩 | 湿気を吸収します | 布に包んで入れます | カビ予防も兼ねます |
| 灰の中に埋める | 密閉と物理的防除を同時に得られます | 甕に灰とエンドウを層状に積みます | 伝統的に広く使われてきました |

&nbsp;&nbsp;&nbsp;最も重要なのは、完全密閉です。虫も呼吸をします。密閉した容器の中で豆と虫が酸素を使うと、酸素が減って二酸化炭素が増え、虫が死にます。豆は休眠状態にあるため、この条件に耐えられます。容器をいっぱいに満たして空間を減らすほど、効果は早く現れます。大きな容器一つより、小さな容器いくつかにぎっしり詰めるほうがよく、これは一つの容器がだめになったときにすべてを失わずに済むという利点ももたらします。

&nbsp;&nbsp;&nbsp;油コーティングは、インドやアフリカの小規模農家で古くから使われてきた方法です。エンドウ1kgに食用油2-3mLを加え、手でもんで、すべての豆に薄い膜ができるようにします。油膜は、成虫が卵を産みつけにくくし、すでに産みつけられた卵の呼吸孔をふさいで孵化を妨げます。半年以内に食べる分にだけ使い、種子用には使いません。油膜が呼吸を妨げて発芽力が落ちるためです。草木灰はふるいにかけて細かい部分だけを選び、エンドウの容積の2-5%を混ぜます。虫が耐性を獲得することはなく、人体にも無害です。

### 15-3. 貯蔵容器と場所

| 容器 | 密閉性 | 期間 | 長所 | 短所 |
|---|:---:|---|---|---|
| ガラス瓶 | 非常に良い | 3年以上 | 状態を目で確認できます | 容量が小さく、光を遮れません |
| 金属缶 | 非常に良い | 3年以上 | ネズミと虫を完全に防ぎます | 結露が生じるとその部分が傷みます |
| 甕 | 良い | 2-3年 | 温度変化が緩やかで、ネズミがかじり抜けません | 重く、割れます |
| 厚手のビニール袋 | 普通 | 1-2年 | 軽くて安いです | ネズミがかじり抜けます |
| 地下貯蔵穴 | 良い | 2-3年 | 温度が一定で低いです | 水が染み込むと全量を失います |

&nbsp;&nbsp;&nbsp;点検で最も頼りになる感覚は、聴覚と嗅覚です。容器に耳を当てたときにカサカサという音がすれば虫が活動しており、湿っぽいにおいがすればカビが発生し始めています。エンドウの表面に小さく丸い穴が見えたら、ゾウムシが1世代を経た状態です。この段階でも、全量を取り出して日なたで乾かし、水に浮かべて空の豆をすくい取り、灰や油を混ぜて再び密閉すれば、残りの分を守れます。2か月に1回の点検が目安です。

### 15-4. グリーンピースの短期貯蔵

| 方式 | 方法 | 期間 |
|---|---|---|
| さやのまま涼しい場所 | 洗わずに、風通しのよいかごに入れます | 3-5日 |
| ゆでて乾燥 | さっとゆでて水気を切り、日なたでからからに乾かします | 数か月。水で戻して復元します |
| 塩漬け | ゆでた後、塩を層ごとにふって甕に入れます | 数か月。食べる前に水に浸して塩気を抜きます |
| 地中貯蔵 | 涼しい地下の穴に置きます | 1週間前後 |

&nbsp;&nbsp;&nbsp;グリーンピースは、収穫した瞬間から糖がデンプンに変わり始め、1日たつと甘みが目に見えて減ります。冷蔵がない条件でグリーンピースを長く保存する方法は、事実上ありません。その日に食べるか、ゆでて乾燥させるか、塩漬けにするか、この三つのうちのどれかです。ゆでて乾燥させたエンドウは、冬に水で戻して汁物やお粥に入れると、色と味がかなり復活します。

## 16. 調理と加工

### 16-1. エンドウのスプラウト - 土なしで育てる冬の野菜

&nbsp;&nbsp;&nbsp;乾燥エンドウには、ビタミンCが事実上ありません。ところが、芽を出させると、なかったビタミンCがつくられます。発芽という生理的転換が起こり、植物が新たに合成するためです。冬に新鮮な野菜がまったくないとき、乾燥エンドウをひとつかみと、水と、器さえあれば、5-7日で新鮮な野菜が得られます。畑も土も必要ありません。

| 手順 | 内容 | ポイント |
|---|---|---|
| 1. 選ぶ | 割れた豆や虫に食われた豆を捨てます | 割れた豆は腐って全体をだめにします |
| 2. 洗う | 何度かすすいで、浮くものをすくい取ります | 浮く豆はたいてい死んだ豆です |
| 3. 浸す | ぬるま湯に6-8時間浸します | エンドウが2倍にふくらむまで浸します |
| 4. 容器に入れる | 水が抜ける容器に入れ、濡らした布で覆います | 水がたまると腐ります |
| 5. 水やり | 1日2-3回、上から十分に流しかけます | 老廃物の除去と温度調節を兼ねます |
| 6. 収穫 | 5-7日、茎5-10cm | 豆もやしと違って、光に当ててもかまいません |

&nbsp;&nbsp;&nbsp;エンドウのスプラウトは豆もやしとは違います。豆もやしは光を完全に遮って白い茎を育てますが、エンドウのスプラウトは、むしろ光に当てて緑の葉を出させたほうが栄養に優れます。最初の3-4日は暗い場所に置いて根と茎を伸ばさせ、その後明るい場所に移して2日置くと、葉が緑色に変わり、葉緑素とビタミンが増えます。この緑の葉は豆苗と呼ばれ、ナムル（味付けした和え物）のようにして食べます。

&nbsp;&nbsp;&nbsp;土を浅く入れた箱にエンドウを密にまいて育てると、より長くて丈夫な若芽が得られます。15-20cmに育ったら、はさみで株元を切って収穫し、そのままにしておくともう一度伸びてきます。冬の室内で、箱を2-3個ローテーションしながら育てれば、途切れることなく緑の野菜が得られます。ビタミンC欠乏は数か月かけて静かに進行し、歯茎から血が出る、傷が治らないといった症状で表に出てきますが、エンドウのスプラウトは、この問題に対する安価で確実な答えです。

### 16-2. 燃料を節約する調理

| 方法 | 燃料 | 手順 |
|---|:---:|---|
| 割りエンドウのお粥 | 非常に少ない | 皮をむいて割ったエンドウは、浸水なしで20分あれば柔らかくなります |
| 圧力調理 | 最も少ない | 浸したエンドウを10分間加圧します |
| 余熱調理 | 非常に少ない | 10分煮た後に火を止め、わら・もみ殻を入れた箱や布団で包んで1-2時間置きます |
| 炒ったエンドウ | 少ない | 乾燥エンドウを弱火で炒ります。そのまま食べられます |
| エンドウ粉 | ほとんどない | 炒って砕いておき、水に溶いて食べます。脂質が少ないので長持ちします |
| スプラウト | なし | 発芽に熱は必要ありません |

&nbsp;&nbsp;&nbsp;割りエンドウは、災害時の条件で特に価値のある形態です。乾燥エンドウを臼で軽くついて皮を吹き飛ばすと、豆が自然に半分に割れます。この状態では水が中まですぐに入り込むため、浸水が不要で、20分でお粥のようにくずれます。インドのダール、ヨーロッパのエンドウ豆のスープが、いずれもこの形態を使うのは、燃料を節約する古くからの知恵です。皮も捨てずに集めておき、家畜の飼料や堆肥に使います。

&nbsp;&nbsp;&nbsp;余熱調理も、エンドウでは効果が大きいです。10分だけ煮て保温箱に入れておくと、内部の温度が1時間以上高く保たれ、調理が続きます。エンドウはダイズと違って、完全に破壊する必要のある強い毒性成分がないため、余熱調理でも安全に火を通せます。わらやもみ殻を詰めた木箱、または厚い布団で鍋ごと包めば、それが保温箱です。

### 16-3. 保存加工

| 加工 | 手順の要約 | 保管 | 価値 |
|---|---|---|---|
| エンドウ粉 | 炒って砕きます | 密閉して3-6か月 | 調理の燃料がいりません |
| ゆでて乾燥させたグリーンピース | ゆでて水気を切り、からからに乾かします | 数か月 | 冬に汁物やお粥に入れます |
| エンドウのテンジャン（韓国味噌） | 煮てつぶし、メジュ（味噌玉）のように発酵させて、塩水に漬けます | 数年 | ダイズが足りないときの代替策です |
| エンドウ若芽の塩漬け | 若芽を塩に漬けます | 数か月 | 春のナムルを冬まで持ち越します |
| 炒ったエンドウ | 弱火で炒ります | 密閉して1-2か月 | おやつであり、非常食でもあります |

&nbsp;&nbsp;&nbsp;エンドウで醤（ジャン、発酵調味料）を仕込むのは、広く知られた方法ではありませんが、原理はダイズと同じです。煮てつぶし、塊に成形してわらに包んで発酵させたあと、塩水に漬けます。エンドウはダイズよりタンパク質が少なく、うま味は劣りますが、発酵を経ると抗栄養成分が分解されて消化率が上がり、塩とともに数年もちます。ダイズを確保できなかった年にエンドウが豊作なら、試してみる価値のある道です。

| 4月 | 間引き、1回目の除草、つるの誘引、若芽の収穫 | 摘んだ芽はナムルとして食べます。アブラムシも一緒に取り除かれます |
| 5月 | 開花、灌水の集中、アブラムシ管理、根粒の確認 | 根を掘り上げて根粒を割り、赤い色を確かめます |
| 6月 | グリーンピースの順次収穫、秋播き分の収穫（韓国南部） | 3-4日おきにこまめに摘みます。摘めばさらに実ります |
| 7月 | 乾燥子実の収穫、吊るして乾燥、脱穀、茎葉を畑に戻す | 雨の予報があれば、完熟を待ちません |
| 8月 | 精選、乾燥、貯蔵、畑の片づけ | つるは焼かずに、刻んで覆います |
| 9月 | 秋播き用の畑の準備、石灰の散布 | 秋の作型が成り立つのは韓国南部だけです |
| 10月 | 秋播き（韓国南部）、越冬準備 | 初霜の40-50日前を播種日とします |
| 11月 | わら・落ち葉を覆う、排水溝の点検 | 凍った地面が持ち上がる（凍上）のを防ぎます |
| 12月 | 貯蔵の点検、スプラウト栽培、翌年の計画 | 冬のビタミンCはスプラウトから得ます |

### 17-1. 忘れてはならない五つのこと

| 項目 | 内容 |
|---|---|
| 播種時期 | 遅く播くことが失敗の最大の原因です。多少の霜に当たっても、早く播きます |
| 連作 | 5-7年の休作が必要です。豆類の中で最も長い期間です。守らなければ畑を失います |
| 支柱 | 巻きひげは細いものしかつかめません。太い杭だけを打っても、何の役にも立ちません |
| 茎葉 | つる・葉・根を畑に戻さなければ、エンドウは土から奪う作物になります |
| 収穫 | 摘めばさらに実り、放っておくと止まります。3-4日おきに順次収穫します |
