## 5. 整地与施肥 - 氮素收支与施肥

### 5-4. 固氮的陷阱

&nbsp;&nbsp;&nbsp;“种了豆子，地就会变好”这句话，已经成了农业上的常识。它一半对，一半错。如果不能准确理解这一点，连续几年种植豆科作物的田块，反而会越来越贫瘠。

&nbsp;&nbsp;&nbsp;我们用数字来算一算。豌豆长势良好时，每1,000㎡可收获250kg干籽粒。豌豆籽粒的蛋白质含量为25.4%，把蛋白质含量除以6.25就得到氮含量。25.4 ÷ 6.25等于4.06，也就是说，籽粒重量的约4%是纯氮。250kg籽粒中含的氮约10kg，换算成公顷则是100kg。

&nbsp;&nbsp;&nbsp;另一方面，豌豆根瘤固定的氮，在条件良好时为每公顷80-130kg。这是接种顺利、酸度合适、水分适宜时的数值，条件差时只有30kg。把出去的和进来的并排放在一起，就是下面这样。

| 项目 | 每公顷氮量 | 方向 |
|---|---|---|
| 根瘤固氮量（条件良好） | 80-130kg | 进入 |
| 根瘤固氮量（条件不良） | 25-50kg | 进入 |
| 随籽粒带出 | 90-110kg | 带出 |
| 茎叶（藤蔓和叶片）中留存的氮 | 25-40kg | 还田则留下，烧掉或运走则带出 |
| 根和根瘤中留存的氮 | 10-20kg | 通常留在田里 |

&nbsp;&nbsp;&nbsp;看表就能明白。只把籽粒收走，把藤蔓和叶片还给田地，固氮量与带出量大致相当，或略有结余。但如果连豌豆藤蔓也清走，作为饲料运出去或者烧掉，氮素收支就会明确转为负数。也就是说，从豌豆田里出去的氮多于进来的氮。

> **豆科作物之所以能养地，并不是因为固氮本身，而是因为它把固定的氮的一部分存在茎和叶里、留在田中。如果把这些茎叶运走，豆类就成了掠夺地力的作物。**

&nbsp;&nbsp;&nbsp;豌豆有一个有利于解决这一问题的条件：在韩国，它的收获期早，在6月。大豆10月收获，即使把茎叶还田，冬季里也几乎不分解，而豌豆茎叶在6月温暖潮湿的土壤中很快腐烂。此外，豌豆茎中空、含水多、组织柔嫩。切碎覆盖后几周内就会消失形迹，其中的氮立刻被夏季作物吸收利用。把豌豆用作绿肥这一由来已久的习惯，就是以此为依据的。

| 原则 | 内容 |
|---|---|
| 茎叶一定要还田 | 把脱粒后剩下的藤蔓、叶片和荚壳全部还回田里 |
| 不要烧掉 | 一烧，氮就变成气体散失，只剩钾和磷留在灰里 |
| 不要挖根 | 根和根瘤中的氮是最容易留下的那一份 |
| 切成20-30cm覆盖 | 既是覆盖物又是肥料，还能降低夏季作物的地温 |
| 翻压作绿肥的选择 | 在开花期整株翻压入土，留下的氮最多。放弃籽粒，换来田地的恢复 |
| 喂了牲畜就要把粪还田 | 如果用豌豆藤蔓喂过牲畜，那么这些牲畜的粪尿一定要施回这块田 |

### 5-5. 整地

| 项目 | 方法 | 灾害条件下 |
|---|---|---|
| 翻耕 | 翻耕20-30cm深，并整平 | 用铁锹翻土或用锄头刨起。如果无法全面翻耕，就只把要播种的行刨翻 |
| 垄 | 高度20cm以上 | 是预防渍害的关键 |
| 排水沟 | 深度30-50cm | 正好跨越春雨和韩国梅雨季（6月下旬至7月）的初期 |
| 酸度调节 | pH 6.5-7.5 | 在播种前15天到3周提前进行 |
| 石灰 | 酸性土壤 150kg/1,000㎡ | 把贝壳、蛋壳烧后捣碎，或用草木灰代替 |

&nbsp;&nbsp;&nbsp;石灰要提前施入，原因是反应需要时间。如果在播种前一刻才施，局部碱性会变强，伤害种子和幼根，而到真正需要的时候反应又还没充分进行。另外，如果把石灰和氮肥施在同一个位置，氨会变成气体逸失，氮就损失了。要遵守先施石灰、两周后再施肥的顺序。没有石灰的话，就用贝壳和蛋壳。两者都是碳酸钙，原理相同，但直接用的话反应非常慢，所以要先用火烧到易碎，再放入臼中捣成粉末使用。

### 5-6. 施肥量

| 肥料 | 按1,000㎡计 | 折合每㎡ | 备注 |
|---|---|---|---|
| 氮 | 8.7kg | 8.7g | 全部作基肥。用于根瘤开始工作之前的早期阶段 |
| 磷 | 50kg（按钙镁磷肥计） | 50g | 全部作基肥。豌豆对磷的需求在豆类中较高 |
| 钾 | 16.8kg | 16.8g | 全部作基肥 |
| 堆肥 | 1,500kg | 1.5kg | 使用完全腐熟的 |
| 石灰 | 150kg（酸性土壤） | 150g | 播种前15天 |

> **对豌豆来说，少施氮不是节省，而是技术。施多了，藤蔓徒长而豆荚减少，变重的藤蔓倒伏，病害就会蔓延。**

&nbsp;&nbsp;&nbsp;追肥原则上不需要。不过，如果开花前后叶片整体呈浅黄色，生长明显不良，就是根瘤没有正常工作的信号。只有这时才补充少量。在灾害情境下，把尿液用水稀释10倍，浇在植株间的土壤上，是最简便的替代办法。注意不要沾到叶片上，与其一次浇很多，不如稀一点、分几次浇。

### 5-7. 灾害情境下的替代肥料

| 替代资源 | 提供的营养 | 用法 | 注意 |
|---|---|---|---|
| 草木灰 | 钾、磷、钙 | 每㎡撒100-200g并混匀 | 呈碱性。豌豆较耐碱，比其他豆类更有余地 |
| 腐熟堆肥 | 多种营养 | 每㎡施1-1.5kg作基肥 | 未腐熟的会烧根并传播病害 |
| 稀释尿液 | 氮、钾 | 用水稀释10倍后浇在植株间的土壤上 | 不要沾到叶片。只用少量 |
| 骨粉 | 磷、钙 | 烧后捣碎，掺入堆肥 | 是满足豌豆高磷需求的关键材料 |
| 鱼骨·鱼内脏 | 磷、氮 | 埋入土中使其腐化后再使用 | 直接埋的话会被野兽刨出来 |
| 贝壳·蛋壳 | 钙 | 烧后捣碎撒施 | 用来代替石灰。反应慢 |
| 落叶腐殖土 | 多种营养、有机质 | 掺入土中 | 改善保水性 |
| 稻壳·稻草 | 钾、硅 | 作覆盖物铺盖，次年翻入土中 | 未腐熟的翻入土中会夺走氮素 |

&nbsp;&nbsp;&nbsp;豌豆施肥中最引人注目的数字是磷。每1,000㎡施50kg，相当于氮的六倍，在豆类中异常之多。磷是固氮能量代谢的关键元素，豌豆的根瘤缺磷时，即使形成了也无法发挥作用。在没有化肥的条件下，获得磷的途径事实上只有骨粉和鱼骨。把兽骨收集起来用火烧到易碎，再放入臼中捣成粉，掺进堆肥里放着，就会在几年时间里慢慢释放出来。吃完鱼后剩下的骨头和内脏，也可以埋在田边腐化后再使用。

## 6. 播种

### 6-1. 播种时期

| 栽培类型 | 播种时期 | 收获时期 | 备注 |
|---|---|---|---|
| 春季栽培（韩国全国） | 2月下旬-4月上旬 | 6月中旬-7月下旬 | 最为普遍。越早越好 |
| 秋季栽培（韩国南部） | 10月上旬-10月底 | 次年5月中旬-6月中旬 | 越冬栽培。收获提前 |
| 芽苗·嫩苗采收 | 全年 | 播种后5-20天 | 室内也可以 |

&nbsp;&nbsp;&nbsp;豌豆的播种期要倒着算。找到当地白天最高气温开始超过25℃的日期，从那天往前倒数85-95天，就是播种的最晚日期。在韩国中部，一般4月上旬是最晚限度，3月中旬是适期，在土壤解冻的2月下旬播种也无妨。被晚霜冻伤叶尖的程度，豌豆自己就能恢复。

> **豌豆播种失败，大部分是因为播得太晚。担心霜冻而一拖再拖的时候，炎热正在逼近，花期一旦撞上高温，花就会整个脱落。**

&nbsp;&nbsp;&nbsp;秋播是韩国南部地区的策略。在10月初到月底播种，让植株带着2-3片真叶、10cm左右的高度越冬。如果播得太早，长得很大就迎来冬天，反而会冻死，所以要领是把播种日定在初霜前40-50天。冬季铺盖稻草或落叶，防止冻土顶起植株。韩国中部内陆这种栽培类型大多会失败，所以采用春播。

### 6-2. 种子准备

| 项目 | 方法 | 灾害条件下 |
|---|---|---|
| 筛选 | 扔掉有斑点、变色、皱缩、虫孔的种子 | 用手一粒一粒挑选。这是最便宜、效果最大的作业 |
| 按大小挑选 | 选用粒大而重的种子 | 放入水中，把浮起来的捞出去 |
| 温水消毒 | 在50-55℃的水中浸泡10-15分钟，杀死表面病原菌 | 温度过高会降低发芽力 |
| 草木灰处理 | 给种子拌上细草木灰 | 有助于消毒和干燥，并能驱避鸟和虫 |
| 根瘤菌接种 | 给种子拌上种过同类豆科作物的田里的土 | 参见5-3节。不与消毒同时进行 |
| 浸种 | 播种前在水中浸泡几个小时 | 发芽会加快，但泡太久会腐烂。不要超过6小时 |
| 发芽试验 | 用湿布包20粒种子，放几天后数发芽的个数 | 陈种子一定要先检验 |

&nbsp;&nbsp;&nbsp;豌豆不像大豆，不能浸泡太久。种皮薄、组织柔软，浸泡超过8小时，内部就会发软，播到土里很快腐烂。如果土壤足够湿润，干脆不浸种直接播更安全；如果土壤干燥，就只浸泡3-4小时左右，晾干水汽后再播。

&nbsp;&nbsp;&nbsp;温水处理的温度控制有诀窍。没有温度计时，把手伸进去，难以坚持5秒的程度，大约就是50-55℃的范围。水量要取种子的10倍以上，这样放入种子时水温才不会骤降。处理完后立即用冷水冷却，晾干水汽后播种。超过60℃会损伤发芽力。

### 6-3. 播种方法

| 项目 | 标准 | 理由 |
|---|---|---|
| 播种深度 | 3-5cm | 太浅会干，还会被鸟啄食。超过7cm则出不了土 |
| 每穴粒数 | 2-3粒 | 考虑发芽率。之后留2株间苗 |
| 行距（单行） | 60cm | 保证通风和管理通道 |
| 株距 | 20-30cm | 矮生种密一些，蔓生种宽一些 |
| 双行栽培 | 垄宽60cm，沟宽50cm | 两行相对种植，在中间立支架 |
| 播种量 | 60-80kg/1,000㎡ | 在豆类中播种量偏大 |

&nbsp;&nbsp;&nbsp;双行栽培是节省支架的布局。一条垄上种两行，只在中间立一根支架，两边的藤蔓就共用同一根支架。在材料不足的条件下，用一根支架撑起两行，能带来很大的差别。

&nbsp;&nbsp;&nbsp;播种后最大的威胁是鸟和老鼠。豌豆种子个大味甜，鸽子、喜鹊和野鸡会刨出来吃，地下的老鼠也能找到。可以在播种行上薄薄盖一层树枝或稻草，或者在发芽之前罩上网或旧纱窗，或者交叉拉上反光的绳子。给种子拌上细草木灰，靠气味和触感也有驱避效果。最可靠的办法，是在发芽初期的10天里，每天早晚到田里巡视。

## 7. 水分管理

| 时期 | 水分管理 | 理由 |
|---|---|---|
| 播种到发芽 | 不要让土壤干透 | 种子吸足水分才能发芽 |
| 生长初期 | 依靠自然降水 | 这一时期的干燥反而会促使根系深扎 |
| 开花期到豆荚膨大期 | 充分浇水，不让土壤变干 | 这一时期直接决定产量 |
| 成熟期 | 停止灌水 | 否则豆荚不干，还会长霉 |
| 梅雨季初期 | 提前疏通排水沟 | 豌豆极不耐渍害 |

&nbsp;&nbsp;&nbsp;豌豆的水分管理与其他豆类不同。夏季作物担心干旱，而豌豆更担心过湿。因为它的生育期处在春雨季节，茎中空、组织柔嫩，根瘤菌又是好氧的。在豌豆田里，排水比灌溉更优先。

| 症状 | 原因 | 措施 |
|---|---|---|
| 中午叶片下垂，傍晚恢复 | 暂时性缺水。属于正常范围 | 不用处理 |
| 早晨叶片仍然下垂 | 根系吸不上水 | 充分浇水 |
| 叶片呈灰白色并干枯 | 严重干旱或高温 | 同时灌水和覆盖 |
| 花大量脱落 | 开花期干旱，或超过25℃的高温 | 通过灌水和覆盖降低地温。如果原因是高温，则难以恢复 |
| 结了荚但籽粒小 | 豆荚膨大期缺水 | 这一时期的灌水直接左右产量 |
| 下部叶片发黄，茎基部变软 | 过湿引起烂根 | 疏通排水沟并培土。严重时拔除 |
| 整个叶片呈浅黄色，但没有萎蔫 | 根瘤不工作，导致缺氮 | 挖出根系检查根瘤 |

&nbsp;&nbsp;&nbsp;在水源紧缺的条件下，取舍与集中才是答案。前期忍一忍，从看到第一朵花开始到豆荚鼓起的3周内，把水集中浇上。与其少量多次地浇，不如一次浇透、使土壤湿润到20cm深，再拉长到下次灌水的间隔，这样能让根系扎得更深，更有利。覆盖是节水最便宜的手段。即使没有塑料薄膜，用稻草、稻壳、落叶、割下来的杂草铺5-10cm厚，也能使地表蒸发减少一半以上，并缓和地温波动。豌豆不耐高温，所以降低地温的效果尤其宝贵。
