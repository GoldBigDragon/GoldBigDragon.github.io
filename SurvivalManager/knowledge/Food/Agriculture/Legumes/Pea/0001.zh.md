## 引言
&nbsp;&nbsp;&nbsp;豌豆（Pisum sativum）是原产于西南亚和地中海东部的豆科一年生攀缘植物，是最古老的栽培作物之一。它是在冬季有雨、夏季干燥的地中海气候中长成的植物，所以凉爽时生长，天热就死，其他豆类是夏季作物，唯独豌豆是春秋作物。3月中旬播种、6月收获，南部则10月播种、次年5月收获，所以在播种大豆的6月，豌豆地已经空出来，一块田一年可以收获两次。综合等级为A（48.4分，有效183种中第31位），短期B（48.2）、长期A（48.6）、副食SS（64.7分）。蛋白质占热量的比例为28.7%，接近最低线10%的三倍，从播种到收获85-95天，总蒸散量约400mm，耐零下5℃。它有三个弱点。单位面积热量为C，每1㎡只有885kcal，是自给线的0.34倍，光靠豌豆吃不饱；连作适应性为D，要求休耕5-7年；而且因为是攀缘性，需要支架。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | A | 48.4 |
| 短期 | B | 48.2 |
| 长期 | A | 48.6 |
| 副食 | SS | 64.7 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：蛋白质密度、施肥、设施负担、耐储性。S：微量营养素、口味、国内种植普及度、自留种。A：收获速度、水消耗量、耐寒性、无合成投入产量保持率、产量稳定性。B：防治自立度、种子寿命 |
| 劣势 | D：持续性、光照、连作适应性。C：单位面积热量、烹调·加工要求度、温度幅度、病虫害压力、整地·挖掘能量、非食用价值 |

> **豌豆的价值不在产量，而在时机。用蛋白质作物填满其他作物用不了的3月到6月的田地，这就是豌豆获得A等级的原因。**

&nbsp;&nbsp;&nbsp;收获速度A和耐寒性A同时具备的豆类很少见。3月初播种、6月收获，填补的是陈粮耗尽、秋收尚远的晚春到初夏最难熬的阶段，而青豌豆在豆荚鼓起来后就能立刻摘着吃。温度幅度C来自结实温度只有13-23℃，超过25℃就会落花。病虫害压力C的无防治损失率为48.9%，是大豆（23%）的两倍，但病虫害随气温升高而增多，早播早收可以避开大部分，这就是防治自立度B的依据。最容易被忽视的弱点是连作适应性D。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 豆科豌豆属一年生攀缘植物。自花授粉（花开之前授粉就已完成） |
| 叶、茎 | 羽状复叶，叶尖变成卷须。中空的攀缘茎，矮生种30-60cm，高秆种1-2m |
| 根、花 | 直立主根，带须根和根瘤。白色或红紫色的蝶形花 |
| 荚、籽粒 | 圆筒形，5-10cm，内含4-10粒种子。籽粒圆形或皱缩，绿色、黄色或灰褐色 |

&nbsp;&nbsp;&nbsp;豌豆从下面的节依次向上开花、成熟，所以青豌豆要每隔三四天分几次摘。成熟的豆荚如果不摘，植株就认为繁殖已经完成而停止开花，所以摘本身就是提高产量的管理。根瘤要3-4周后才开始提供氮，所以基肥中加入少量氮是有意义的。干豌豆每100g含热量354kcal、蛋白质25.37g、脂肪1-2.5g、碳水化合物约60g、膳食纤维20-25g、铁4-5mg，几乎没有维生素C。青豌豆含80-97kcal热量和35mg维生素C，起到新鲜蔬菜的作用，所以早熟的当青豌豆吃，晚熟的晒干作为蛋白质储存。谷物缺少的赖氨酸豌豆很充足，豌豆缺少的蛋氨酸谷物里有，和米饭一起吃可以互相补足，脂肪少，磨成粉也耐放。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 零下1-2℃也能发芽（适温18-25℃）。生长4-25℃（适温10-20℃），超过25℃生长停止、病害增多。结实13-23℃（适温15-20℃）。耐零下5℃，但开花之后怕霜 |
| 土壤、水 | 排水良好的壤土（积水的地最差），pH 6.0-8.0（适宜6.5-7.5），地下水位50cm以下（适宜80cm以下） |

> **豌豆栽培的所有决定，都朝着躲避炎热的方向做出。什么时候播、选哪个品种、什么时候收，都要从当地第一次变热的日期倒推。**

&nbsp;&nbsp;&nbsp;豌豆是豆类中对酸度要求最高的，pH 6.0以下生长变差，根瘤菌无法生存，固氮就会停止。茎是中空的，根瘤菌又是好氧的，田地被淹一天，根和根瘤就会一起丧失功能，所以把垄起到20cm以上、挖深排水沟并不是可选项。

&nbsp;&nbsp;&nbsp;矮生种（30-60cm）不需要支架或只需简单支架，省事但产量低，高秆种（1-2m）必须有支架，但产量高，要在较长时期里分多次收获。支架材料和人手充足就选高秆种，两者都缺就选矮生种才现实。连荚吃的类型（荷兰豆、甜脆豌豆）没有废弃部分，最有价值，要趁嫩摘，否则会形成老韧的膜。选品种的第一标准是能否自留种：F1杂交种第二年性状会分离，但大部分栽培品种是固定品种，留下的种子可以直接种，地方品种则已适应当地的气候和病害。南部选择秋播用的耐寒品种，种过豌豆的田地选择抗枯萎病的品系。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 深翻20-30cm，排水沟深30-50cm。酸性土在播种前15天到3周施石灰150kg/1,000㎡（可用烧过捣碎的贝壳、蛋壳粉或木灰代替）。石灰和肥料要间隔2周，以防氨损失 |
| 施肥（1,000㎡） | 氮8.7kg、磷50kg（约为氮的6倍）、钾16.8kg、堆肥1,500kg（全部作基肥）。省氮是技术，氮多了只长蔓、荚变少，还会倒伏导致病害蔓延。磷用骨粉和烧过的鱼骨粉补足，木灰每㎡100-200g。不需要追肥，但开花前后叶色浅黄时，少量浇施稀释10倍的尿液 |
| 根瘤接种 | 用种过豌豆、蚕豆、小扁豆、野豌豆且根瘤长得好的地块5-15cm深的土，裹在稍用水润湿的种子上，在阴凉处30分钟内播下（不要与种子消毒同时进行）。大豆地的土细菌种类不同，没有用，有枯萎病的田地的土要避开 |

&nbsp;&nbsp;&nbsp;根瘤要在开花前后（播种后5-7周）检查：用铁锹连土挖起植株，洗净，掰开根瘤。每株20个以上、里面呈红色或粉红色，说明在固氮；白色或浅绿色说明不固氮；褐色或黑色说明已经死亡（成熟期属正常）。5个以下则接种失败。

| 播种 | 标准 |
|:---|:---|
| 时期 | 春播2月下旬-4月上旬（中部适期为3月中旬，越早越有利）。最后播种日期，是从当地日最高气温开始超过25℃的那天往前数85-95天。南部秋播在10月上旬-下旬，以初霜前40-50天为准，让植株带2-3片真叶、株高10cm左右越冬，并盖上稻草或落叶（播得早、长得大会冻死，中部内陆大多失败） |
| 种子准备 | 扔掉有斑点、变色、皱缩、虫孔的种子，用50-55℃的水浸泡10-15分钟消毒后立刻冷却（超过60℃会损伤发芽力）。浸种不超过6小时，土壤湿润时不浸种 |
| 方法 | 深度3-5cm，每穴2-3粒（株高10cm时只留2株长势好的），行距60cm，株距20-30cm，播种量每1,000㎡ 60-80kg。垄宽60cm、沟宽50cm，两行相对种植、共用中间一根支柱的双行种植，可节省材料。为防鸟和老鼠，在发芽前用稻草或网盖住 |

## 5. 水分管理与栽培管理
> **豌豆是比干旱更怕过湿的作物，所以排水先于灌溉，要在雨季到来前提前挖好排水沟。从开花期到荚膨大期，水直接决定产量，所以水不足时集中在这3周浇水，与其少量多次，不如一次浇透到土深20cm。**

| 管理 | 方法 |
|:---|:---|
| 覆盖 | 铺5-10cm厚的稻草、稻壳或落叶，可使地表蒸发减少一半以上并降低地温（对怕热的豌豆尤其有价值） |
| 支架 | 蔓铺在地上会使病害蔓延、豆荚腐烂。卷须只能抓住直径5mm左右的细东西，所以不要只打粗桩，要挂上细绳或树枝。拉绳牵引最现实：每隔2m打一根桩，在离地20cm、50cm、80cm的高度水平拉绳，随着蔓长一层层往上提。带着叶子的细枝沿着行斜插，既不需要绳也不需要网，拉网牵引则产量最高 |
| 间苗、除草 | 播种后2-3周浅锄第一次，5-6周结合培土锄第二次。最初一个月的除草就是全部，开花后蔓缠在一起会被扯断，所以不要进田 |
| 摘心 | 蔓长到支架顶端时摘心，侧枝增多，蚜虫聚集的生长点也一并去掉。摘下的嫩尖焯熟当野菜吃 |

## 6. 病虫害与养分问题
| 病虫害 | 症状与条件 | 不用药的防治 |
|:---|:---|:---|
| 白粉病 | 叶和茎上像撒了面粉一样的白粉。白天热、夜里凉且干燥时，是生长后期最大的病害 | 保证通风，把牛奶用水稀释5-10倍，在晴天上午喷洒，提早收获 |
| 褐斑病 | 叶、茎、荚上的褐色斑点。多雨潮湿时，种子带菌 | 选种、保证通风、波尔多液 |
| 根腐病、枯萎病 | 从下部叶片开始发黄萎蔫，茎基和根变褐腐烂。过湿、连作 | 5-7年轮作是唯一的根本对策，排水和起高垄 |
| 蚜虫、病毒病 | 聚集在生长点和花梗上吸汁，并传播病毒病（叶片卷曲、出现斑驳，生长停止）的最大害虫 | 摘心、肥皂水（1L水加5g肥皂）。病毒病无法治疗，发现后立即拔掉烧毁 |
| 豌豆象 | 在田间的荚上产卵，储存期间蛀食籽粒 | 完全干燥后密封储存（见第9节） |

> **豌豆的连作障碍在豆类中最严重。枯萎病和根腐病的休眠孢子能在土里存活多年，一旦被污染的田地无法用药恢复，除了换地别无他法。**

&nbsp;&nbsp;&nbsp;波尔多液是分别把400g硫酸铜和400g生石灰溶于100L水，混合后立即使用。

| 症状 | 原因与措施 |
|:---|:---|
| 生长不良、根短 | 先怀疑酸度而不是肥料。pH 6.0以下施氮也无法恢复，所以施石灰或烧过捣碎的贝壳粉 |
| 从下部叶片开始浅黄、植株矮小 | 缺氮（根瘤不良）。挖出根检查根瘤，如果没有，当年少量浇施稀释10倍的尿液，第二年一定要接种 |
| 开花但不结荚 | 缺硼或花期高温。用多种材料混合的堆肥，如果原因是高温，第二年提早播种 |

&nbsp;&nbsp;&nbsp;根瘤每公顷固定80-130kg氮（条件差时25-50kg），随籽粒带走的氮为90-110kg，蔓和叶中还剩25-40kg。把蔓还田，收支大致相当，但运走或烧掉就是明确的损失。6月温暖湿润的土里，豌豆茎叶分解很快，把蔓切成20-30cm铺盖，夏季作物就能马上利用这些氮，开花期整株翻入土中，则以放弃籽粒为代价，留下最多的氮。如果蔓用来喂了牲畜，就把牲畜的粪肥还到这块田里。

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 生菜和菠菜（长在豌豆的荫下共享空间，生长期相同）、萝卜和芜菁（根的深度不同，养分层不重叠）、土豆（病害不重叠，豌豆先收）、胡萝卜（利用豌豆留下的氮） |
| 一般 | 玉米（理论上可以当支柱，但播种期相差两个月，所以要另外搭支架） |

&nbsp;&nbsp;&nbsp;连作会积累枯萎病和根腐病，几年内这块地就种不了豌豆，所以要休耕5-7年以上。6年轮作的例子是：豌豆（春）与白菜或萝卜（秋）→ 玉米或高粱 → 土豆或甘薯 → 大豆或豇豆 → 大麦·小麦之后接荞麦 → 根菜类或绿肥。田地窄的话，把地分成几块，每年换一块种，或者种在每年换土的口袋里；如果目的是豆芽和嫩苗，只用水就够了。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 连荚、青豌豆 | 连荚吃的品种在50-60天，豆荚扁平、里面籽粒还小的时候。青豌豆在60-80天（开花后20-30天），豆荚鼓起、表面光滑时最甜，出现网纹就是最后的时机。每隔三四天摘一次 |
| 干籽粒 | 85-95天，8成以上的豆荚变成黄色或褐色，摇动时有籽粒碰撞声，咬一下会脆裂时（含水量13-15%）。容易炸荚，干豆荚被雨淋后会瞬间裂开，所以预报有雨时，不必等完全成熟，整株割下 |
| 干燥、脱粒 | 在晴天露水干后，用镰刀割下蔓的基部，根留在田里。扎成捆倒挂在屋檐下，下面铺布或草席晾干。按压时豆荚能啪地裂开时，把干蔓装进麻袋踩踏，或在草席上薄摊用连枷打，或在桶内壁上摔打脱粒（没干透不会裂开，太干则籽粒会碎） |
| 清选 | 风选在风稳定的清晨或傍晚，细细倒下，进行两三次。放入水中可以分出被豌豆象蛀过的籽粒和空粒，但当天要重新晒干，留种用的不能这样处理 |

| 留种 | 标准 |
|:---|:---|
| 选择 | 事先在田里标出没有病症、荚多、在炎热到来之前早熟的植株。花开之前授粉就已完成，不需要隔离 |
| 干燥、保存 | 晒到含水量12-13%，咬一下会脆裂的状态为宜。常温密封保存2-3年，条件好可到4年。褐斑病是种子带菌的，所以要剔除有斑点的种子，每3年从别处弄来种子，混入一部分 |

## 9. 储存
| 步骤 | 方法 |
|:---|:---|
| 干燥 | 连蔓倒挂在屋檐下晾2-3天后，食用调到含水量12-13%，种子调到12% |
| 豆象防治 | 完全密封最重要：把容器装满以减少空隙，用几个小容器分装。拌入筛过的木灰，用量为体积的2-5%（食用前冲洗）。每1kg豌豆拌入2-5mL食用油（只用于半年内要吃的部分，留种的不用） |
| 容器 | 玻璃瓶、金属罐3年以上，陶罐、地下储藏窖2-3年，厚塑料袋1-2年。金属罐注意结露，地下储藏窖注意进水，塑料袋注意老鼠咬破 |
| 检查 | 每两个月一次。把耳朵贴近容器，检查沙沙声（害虫）、霉味（霉菌）和小圆孔（豆象）。发现后把全部取出晒干，放入水中捞出空籽粒，拌入灰或油后重新密封 |
| 青豌豆 | 摘下后甜味立刻下降，所以当天吃，或者焯水后晒干（可存几个月，浸泡后复原），或者焯水后盐渍（可存几个月）。连荚放在阴凉处可存3-5天 |

## 10. 烹调与注意事项
> **豌豆本身是安全的。真正伤害人的是储存不当发霉的豆子。如果有霉味，或表面有淡青色粉末，洗了、煮了也不会变安全，所以再可惜也要扔掉。**

&nbsp;&nbsp;&nbsp;它既没有菜豆那样的强凝集素，也没有蚕豆那样的溶血成分，所以青豌豆生吃几粒也没事，干豌豆中的胰蛋白酶抑制剂（抑制蛋白质分解酶）也比大豆少得多，加热20-30分钟就够了。但是膳食纤维多，突然给长期挨饿的人或孩子吃很多，会引起腹胀和腹泻，所以要从少量开始，几天里逐渐增加。

| 烹调 | 方法 |
|:---|:---|
| 煮 | 在常温水中浸泡4-8小时（倒掉浸泡水以减少低聚糖），在沸水中煮20-30分钟（不到大豆60分钟的一半） |
| 碎豌豆 | 把干豌豆在臼里轻轻捣一下，吹掉豆皮，就会裂成两半，不用浸泡，20分钟就能煮成粥状。豆皮用作牲畜饲料和堆肥 |
| 节省燃料 | 煮10分钟后熄火，用装满稻草或稻壳的箱子或棉被把锅整个包住，放1-2小时 |
| 炒豌豆、粉 | 用小火炒熟直接吃，或磨成粉冲水喝（密封可保存3-6个月，不需要烹调燃料）。焯后晒干的青豌豆冬天放进汤和粥里 |

&nbsp;&nbsp;&nbsp;干豌豆不含维生素C，但发芽后会重新生成，所以只要有一把干豌豆、水和容器，5-7天就能得到新鲜蔬菜。用温水浸泡6-8小时，胀大一倍，放进能排水的容器，盖上湿布，每天2-3次从上面充分淋水并排净。和豆芽不同，最初三四天保持黑暗，然后放在明亮处两天，让叶子变绿，维生素会增加，茎长到5-10cm时收获当野菜吃。在浅浅装土的箱子里密密撒播，能长出15-20cm的粗壮嫩苗，用剪刀剪下收获后还能再收一次。

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存，做种子发芽试验，修整支架材料，生豆芽。2月撒石灰、翻堆堆肥，下旬土壤解冻后提早播种 |
| 3-4月 | 3月正式播种、防鸟、立支架（最后播种日期从第一次变热往前数85-95天）。4月间苗、第一次除草、牵引蔓、采摘嫩尖 |
| 5-6月 | 5月开花、集中灌溉、蚜虫管理、检查根瘤。6月依次收获青豌豆（每隔三四天）、收获南部秋播的豌豆 |
| 7-8月 | 7月收获干籽粒、挂起晾干、脱粒、茎叶还田。8月风选、干燥、储存、整理田地（蔓不要烧掉，切碎后铺盖） |
| 9-10月 | 9月准备秋播的田地并撒石灰（南部）。10月秋播（初霜前40-50天）、越冬准备 |
| 11-12月 | 11月盖稻草和落叶、检查排水沟。12月检查储存、生豆芽、规划来年 |

> **豌豆要靠早播、遵守5-7年休耕、用细绳和树枝支撑蔓、收获后把蔓还田、每隔三四天摘一次，才算物有所值。**
