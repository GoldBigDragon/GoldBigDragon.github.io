## 8. 栽培管理 - 支架与引蔓

### 8-1. 为什么需要支架

&nbsp;&nbsp;&nbsp;豌豆茎上几乎没有木质，而且中空，无法自己站立。在进化上，豌豆选择了依靠而不是直立，代价是把叶尖变成了卷须。在田里如果无视这一点，藤蔓就会铺倒在地上。铺倒在地的豌豆会同时发生四件事：叶片相互重叠，下部见不到光；通风受阻，白粉病和褐斑病蔓延；豆荚接触土壤而腐烂；采收时必须拨开藤蔓，费工成倍增加。

| 方法 | 材料 | 效果 | 灾害适用度 |
|---|---|---|---|
| 不用支架 | 无 | 产量明显下降，病害增多 | 仅限矮生种，属次选 |
| 拉绳引蔓 | 木桩和绳子 | 用工中等，产量良好 | 最为现实 |
| 挂网引蔓 | 木桩和网 | 产量最高 | 有网的话是最佳选择 |
| 插树枝 | 细树枝 | 不花钱 | 传统方法。适合小面积 |
| 活支架 | 玉米、向日葵 | 无需另备支架 | 播种时间错开，对豌豆大多不合适 |

&nbsp;&nbsp;&nbsp;灾害条件下最现实的是拉绳引蔓。每隔2m钉一根木桩，在离地20cm、50cm、80cm的高度水平系上绳子，让两列之间的豌豆倚靠在绳子上。随着藤蔓生长的速度，把绳子一道一道往上提高系即可。绳子不够的话，就用葛藤或稻草搓成草绳来用。

&nbsp;&nbsp;&nbsp;插树枝在欧洲和韩国都是长期使用的方法。把不摘叶的细树枝沿着要种的行斜插下去，豌豆卷须就会缠住这些细枝，自己爬上去。桦树或胡枝子这种细枝分杈多的最好，既不需要绳子也不需要网。冬天提前修剪枝条晾干，春天拿来用就行。

> **豌豆卷须最容易抓住直径5mm左右的细物，缠不住粗柱子。搭支架时如果只钉粗木桩，藤蔓什么也抓不住，就会倒下。**

### 8-2. 间苗与除草

| 作业 | 时期 | 方法 |
|---|---|---|
| 第一次间苗 | 真叶2-3片 | 只处理过于密集的地方 |
| 第二次间苗 | 株高10cm | 每穴留2株长势好的 |
| 第一次除草 | 播种后2-3周 | 浅浅地刮。不要伤到根 |
| 第二次除草 | 播种后5-6周 | 与培土结合进行 |
| 此后 | 开花以后不要下田 | 藤蔓缠绕，人一走就会折断 |

&nbsp;&nbsp;&nbsp;豌豆生长初期缓慢，植株矮小，容易被杂草压住。反过来，一旦藤蔓伸展开、顺着支架爬上去，就不再与杂草争夺空间。所以说最初一个月的除草就是全部工作也不为过。开花以后不下田是原则。卷须相互缠绕，人一经过，好几株会被同时扯坏；在露水未干的早晨走动，病害还会传遍整块田。

### 8-3. 摘心与掐尖

| 作业 | 时期 | 效果 |
|---|---|---|
| 掐尖 | 藤蔓长到支架顶端时 | 侧枝增多，下部豆荚长得更饱满 |
| 采摘嫩梢 | 生长期间随时 | 既可当蔬菜吃，同时又达到摘心的效果 |
| 摘除病叶 | 发现后立即 | 延缓白粉病和褐斑病的扩散 |

&nbsp;&nbsp;&nbsp;豌豆掐尖还有一项附带的好处。蚜虫大多聚集在最幼嫩的生长点部位。把尖掐掉，蚜虫种群的相当一部分也随之被清除。掐下来的嫩尖不要扔，焯水后做成凉拌野菜（namul）吃。蚕豆也采用同样的做法，这是在没有农药的条件下，一次作业同时实现防治、收获和增产的难得案例。

## 9. 病虫害

&nbsp;&nbsp;&nbsp;豌豆的病虫害压力为C。无防治减产率估计为48.9%，比大豆的两倍还多。但是豌豆病虫害大多随着气温升高而暴增，所以早种早收的规避策略相当管用。

### 9-1. 主要病害

| 病名 | 症状 | 发生条件 | 不用药的应对 |
|---|---|---|---|
| 白粉病 | 叶片和茎表面覆盖一层像撒了面粉一样的白色粉末 | 白天炎热、夜间凉爽且干燥时。生长后期最大的病害 | 保证通风，把牛奶用水稀释5-10倍后喷洒，通过提前收获来规避 |
| 病毒病（萎缩病） | 叶片卷缩皱起，出现斑驳。生长停滞 | 由蚜虫传播 | 无法治疗。发现后立即拔除烧毁，并减少蚜虫 |
| 褐斑病 | 叶片、茎和豆荚上出现褐色斑点 | 多雨潮湿时。也会通过种子传播 | 筛选种子，保证通风，使用波尔多液 |
| 根腐病·枯萎病 | 从下部叶片开始发黄萎蔫，茎基部和根变成褐色腐烂 | 过湿，连作 | 5-7年轮作是唯一的根本对策。做好排水，把垄起高 |
| 锈病 | 叶片上出现橙色粉状疱斑 | 过于潮湿 | 摘除病叶，保证通风 |
| 霜霉病 | 叶片正面出现黄色斑点，背面长灰白色霉层 | 凉爽潮湿时 | 保证种植间距，做好排水，使用波尔多液 |

> **豌豆的连作障碍在豆类中最为严重。枯萎病和根腐病的休眠孢子没有寄主也能在土壤中熬过许多年。一块田一旦被污染，用药是无法挽回的，除了换地别无他法。**

### 9-2. 主要害虫

| 害虫 | 危害 | 不用药的防治 |
|---|---|---|
| 蚜虫 | 聚集在生长点和花梗上吸食汁液，并传播病毒病。是豌豆最大的害虫 | 通过掐尖物理清除种群。把肥皂水（1L水加5g肥皂）喷在叶背。保护瓢虫和草蛉 |
| 豌豆象 | 在田间把卵产在豆荚上，贮藏期间蛀食籽粒 | 关键是彻底干燥后密封贮藏。参见第15节 |
| 蚕豆蚜 | 黑色蚜虫密密麻麻附着在茎上 | 掐尖、肥皂水 |
| 潜叶蝇类 | 钻进叶片内部，留下白色虫道 | 摘除受害叶片并销毁 |
| 鸟类（鸽子·喜鹊·野鸡） | 播种后立即啄食种子和幼芽 | 发芽之前用稻草或网覆盖 |
| 老鼠 | 从土里刨食播下的种子 | 给种子拌上草木灰，并保证播种深度 |

### 9-3. 不用药的防治材料

| 材料 | 制作方法 | 对象 | 注意 |
|---|---|---|---|
| 牛奶稀释液 | 把牛奶用水稀释5-10倍 | 白粉病 | 是对豌豆效果最为明确的天然材料。在晴天上午喷洒 |
| 肥皂水 | 1L水加5g无香肥皂 | 蚜虫、螨类 | 正午炎热时喷洒会烧叶 |
| 波尔多液 | 在100L水中分别溶解400g硫酸铜和400g生石灰后混合 | 细菌病、真菌病 | 必须有铜才能配制。混合后立即使用 |
| 草木灰水 | 把1升（韩国传统单位，约1.8L）草木灰在10L水中浸泡一夜，取上层清液 | 抑制霉菌 | 呈碱性，要稀释后使用 |
| 撒干灰 | 在有露水的早晨，把细灰撒在叶片上 | 食叶害虫、霉菌 | 下雨会被冲掉 |
| 木醋液 | 把烧炭时产生的液体稀释300-500倍 | 驱避、促进生长 | 原液呈强酸性，必须稀释 |
| 辣椒·大蒜水 | 磨碎后用水浸泡，过滤后使用 | 驱避 | 效果持续时间不长，要经常喷洒 |

### 9-4. 农业防治

| 方法 | 原理 |
|---|---|
| 提早播种 | 豌豆病虫害大多随气温升高而增多。在炎热到来之前结束收获，就能避开相当一部分 |
| 长周期轮作 | 对枯萎病和根腐病，休作5-7年是唯一的对策 |
| 种子筛选 | 褐斑病通过种子传播。把有斑点和变色的种子挑出去 |
| 种植间距与支架 | 通风良好，叶片干得快，霉菌就站不住脚 |
| 排水 | 豌豆病害有一半以上与过湿有关 |
| 掐尖 | 从物理上减少蚜虫种群 |
| 雨后禁止下田 | 人碰到湿叶，病原菌就会被带过去 |
| 残体处理 | 病株残体要烧掉或深埋。只把健康的残体还田 |

## 10. 营养缺乏与过量

| 症状 | 原因 | 天然材料措施 |
|---|---|---|
| 从下部叶片开始整体呈浅黄色，植株矮小 | 缺氮。豌豆最常见的原因是根瘤不良 | 先挖出根系检查根瘤。如果没有根瘤，来年要确保接种，当年则少量浇施稀释10倍的尿液 |
| 叶缘变褐干枯 | 缺钾 | 把草木灰撒在植株之间，轻轻耙入土中 |
| 生长迟缓，叶片带紫色 | 缺磷。豌豆对磷的需求高，所以很常见 | 骨粉、鱼骨烧成的粉、草木灰 |
| 开了花却不结荚 | 缺硼，或开花期高温 | 用多种材料混合沤制的堆肥。如果原因是高温，来年提前播种 |
| 叶脉绿色，叶脉之间发黄 | 缺铁或缺锰。在偏碱的土壤中常见 | 停止使用草木灰。用腐殖土和完全腐熟的堆肥增加有机质 |
| 新叶细小畸形，生长点枯死 | 缺钙或缺硼 | 蛋壳烧成的粉、贝壳粉 |
| 只长藤蔓，豆荚很少 | 氮过量 | 立即停止供氮。掐尖以诱导侧枝 |
| 整体生长不良，根短 | 酸性土壤 | 石灰或烧过的贝壳粉。豌豆在pH 6.0以下会明显变差 |

&nbsp;&nbsp;&nbsp;豌豆生长不良时，首先要怀疑的不是肥料，而是酸度。豌豆是豆类中最怕酸性土壤的，pH低于6.0时，根系发育和根瘤形成都会变差。表面上看像缺氮，但施氮也不能恢复。其次要检查根瘤。挖出根系，如果根瘤着生良好、剖开内部呈红色，叶片却发黄，那就不是氮的问题，而是别的问题。

&nbsp;&nbsp;&nbsp;微量元素缺乏很难逐一应对。没有化肥，事实上没有办法获得钼或钴。取而代之的是，把菜渣、果皮、蛋壳、鱼骨、落叶、杂草和草木灰一起混合沤制成的堆肥，其中均匀地含有微量元素。往堆肥场里什么都放这一原则，就是管理微量元素的实际策略。

## 11. 间作与轮作

### 11-1. 搭配相性

| 搭配相性 | 作物 | 理由 |
|---|---|---|
| 好 | 生菜·菠菜 | 在豌豆的荫蔽下生长，可共用空间。生长期相同 |
| 好 | 萝卜·芜菁 | 根的深度不同，吸收养分的土层不重叠 |
| 好 | 马铃薯 | 病害互不重叠，且豌豆先收获 |
| 好 | 胡萝卜 | 后茬利用豌豆留下的氮 |
| 一般 | 玉米 | 理论上可以充当支架，但播种期相差两个月，实际上不合适 |
| 差 | 大蒜·洋葱类 | 有报道称其分泌物会抑制根瘤菌 |
| 差 | 其他豆科作物 | 病原菌和线虫会不断积累 |

&nbsp;&nbsp;&nbsp;豌豆与玉米的搭配在书里经常出现，但实际上并不合适。在韩国，种豌豆的3月玉米还种不了，等到玉米长到能当支架的6月，豌豆已经在衰老了。这种搭配适用的是菜豆与玉米，对豌豆来说，另立支架更好。

&nbsp;&nbsp;&nbsp;豌豆与叶菜的搭配确实很合适。在豌豆行间种生菜或菠菜，在春季较弱的阳光下，两种作物互不妨碍地生长。天气变热后，豌豆藤蔓形成的荫蔽还会延缓叶菜抽薹。收获豌豆的时候，叶菜也结束了，整块地同时空出来，可以马上在原地种夏季作物。

### 11-2. 轮作

| 项目 | 标准 |
|---|---|
| 休作期 | 5-7年。在豆类中最长 |
| 理想周期 | 6年以上 |
| 连作障碍 | 枯萎病和根腐病的病原菌残留在土壤中。没有药可用，抗病品种在韩国国内的推广也很有限 |

&nbsp;&nbsp;&nbsp;豌豆的连作适应性D，是本文中最需要严肃对待的项目。与大豆1年、菜豆3年、蚕豆2年相比，豌豆的5到7年长得惊人。在田地不充裕的条件下，很难做到这一要求，但如果做不到，几年之内这块田就会变成无法再种豌豆的田。

| 6年轮作示例 |
|---|
| 第1年：豌豆（春），之后种大白菜或萝卜（秋） |
| 第2年：玉米或高粱 |
| 第3年：马铃薯或甘薯 |
| 第4年：大豆或豇豆 |
| 第5年：谷物（大麦·小麦），之后种荞麦 |
| 第6年：根菜或绿肥 |
| 再回到豌豆 |

&nbsp;&nbsp;&nbsp;下面记下田地狭小、没有条件轮转6年时的折中办法。把田分成几个地块，每年挪一块来种豌豆，是最简单的方式。如果是无法分块的小块田，至少要每年大幅挪动种豌豆的行的位置。还有一个办法，就是在田外种植。豌豆的根虽然扎得深，但在大桶或袋子里也能生长。种在装了土的袋子里，每年换土就能完全避开连作障碍；如果目的是芽苗和嫩苗，不用土、只用水就足够了。

## 12. 收获与脱粒

### 12-1. 不同用途的收获时期

| 用途 | 收获时期（播种后） | 判断标准 |
|---|:---:|---|
| 芽苗 | 5-7天 | 茎5-10cm。不用土，只用水也可以 |
| 嫩苗 | 15-20天 | 茎15-20cm。剪掉后还会再长 |
| 连荚吃（荚粒兼用品种） | 50-60天 | 豆荚扁平、里面的豆粒还小时 |
| 青豌豆 | 60-80天 | 开花后20-30天。豆荚鼓起、仍为绿色时 |
| 干籽粒 | 85-95天 | 豆荚变黄干枯、豆粒变硬时 |

&nbsp;&nbsp;&nbsp;一株豌豆上就能出这五种产品。在灾害情境下，这种多样性本身就有价值。田还没整好，就能在室内得到芽苗；春意渐浓时，把嫩苗当凉拌野菜吃；初夏用青豌豆获取新鲜的维生素；最后收下干豆粒，用来过冬。

&nbsp;&nbsp;&nbsp;抓准青豌豆最佳收获期是有诀窍的。豆荚鼓起、但表面仍然光滑有光泽时最甜。稍过一些，表面会出现网状纹路，变得凹凸不平，这时豆粒最大，同时也是还能吃的最后时点。此后糖转变为淀粉，甜味消失，荚皮变老。用手摸几个不同节位的豆荚相比较，很快就能找到感觉。

> **豌豆摘了会结得更多，不摘就会停止。如果把成熟的豆荚留在株上，植株会判断繁殖已经完成而停止开花。每隔3-4天勤摘，是增产最可靠的管理办法。**

### 12-2. 干籽粒的收获

| 判断标准 | 内容 |
|---|---|
| 叶片 | 从下部开始变黄干枯 |
| 豆荚 | 全部豆荚中八成以上变为黄色或褐色 |
| 声音 | 摇动时豆荚里传出豆粒碰撞的声音 |
| 豆粒 | 咬不动，会“啪”的一声裂开 |
| 水分 | 籽粒含水量13-15% |

&nbsp;&nbsp;&nbsp;豌豆比大豆更容易落粒。豆荚变干时会自己扭曲裂开，尤其是干透的豆荚被雨淋湿后再次变干，如此反复，转眼就会炸裂。下部豆荚开始变褐时要每天查看，一有下雨的消息，就不要等到完全成熟，连藤割回来。稍微欠熟的豌豆晒干后还能用，掉到地上的豌豆就收不回来了。

| 步骤 | 内容 |
|---|---|
| 1 | 选晴朗干燥的日子，在露水干了的上午10点以后进行 |
| 2 | 用镰刀从藤蔓基部割下。根留在田里 |
| 3 | 捆成束，倒挂在屋檐下或棚屋里晾干 |
| 4 | 下面铺布或草席，接住自然掉落的豆粒 |
| 5 | 豆荚干透、摇动有声响时脱粒 |

### 12-3. 脱粒 - 不用工具的方法

| 方法 | 工具 | 步骤 | 效率 |
|---|---|---|---|
| 装袋踩踏 | 厚麻袋或口袋 | 把干藤蔓装进袋子，扎紧袋口，用脚踩或用手搓 | 少量时最省事。豆粒不会蹦出去 |
| 连枷 | 在长柄上系着细木条的工具 | 铺开草席或布，把藤蔓薄薄摊开，从上面敲打 | 适合中等规模。要翻2-3次来回敲打 |
| 用木棒敲打 | 木棍 | 装进袋子或摊在草席上敲打 | 没有连枷时用来代替 |
| 用脚搓 | 无 | 摊在草席上，穿着鞋用脚搓转 | 适合少量 |
| 在木板上摔打 | 木板或木桶 | 抓住藤蔓束，往桶的内壁上拍打 | 豆粒集中在桶内，损失少 |
| 手剥 | 无 | 把豆荚一个一个拧开 | 用于留种的少量种子。豆粒不会受伤 |

&nbsp;&nbsp;&nbsp;脱粒成败取决于干燥程度。没干透的藤蔓，怎么敲打豆荚也不裂开，而过于干燥的豌豆在敲打时豆粒会破碎。用手一捏豆荚就“啪”地裂开的状态是适期，选阳光好的日子的下午进行会轻松得多。豌豆的豆荚比大豆软、容易裂开，脱粒要容易得多。光靠装袋踩踏，几乎就能全部脱落。

### 12-4. 精选 - 用风选出

| 方法 | 原理 | 步骤 |
|---|---|---|
| 风选（借风扬净） | 豌豆粒重，荚壳和碎屑轻 | 在有风的日子，把豌豆装在簸箕或宽大的容器里高举，缓缓倒下。豆粒直接落下，秕壳被风吹走 |
| 簸扬 | 上下抖动，向前扬簸 | 重的豆粒留在后面，轻的被推到前面 |
| 扇风 | 一人倒，一人用扇子扇风 | 在无风的日子使用 |
| 过筛 | 按孔眼大小分离 | 用粗筛滤掉藤蔓碎片，用细筛筛掉泥土和小粒 |
| 水选 | 秕粒和被虫蛀的豆粒较轻 | 倒入水桶，把浮起来的捞走。捞出的豆粒一定要重新晒干 |
| 斜板滚选 | 圆豆粒滚得顺，碎屑会被挡住 | 把木板倾斜放置，让豆粒滚下去。豌豆是圆的，效果特别好 |

&nbsp;&nbsp;&nbsp;风选是人类开始处理谷物时就在使用的方法。要领有三点：选风向稳定的清晨或傍晚，不要一次倒完，而要细细地往下流，并且重复2-3遍。

&nbsp;&nbsp;&nbsp;水选的方法可以同时完成清选和挑选。被豌豆象蛀过的豆粒里面是空的，会浮起来，秕粒也会浮起来，这样挑出来可大大减少贮藏损失。不过，泡过水的豌豆必须在当天内彻底重新晒干，也不能用作种子。
