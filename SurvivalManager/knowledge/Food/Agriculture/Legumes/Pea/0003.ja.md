## 3. 栽培環境

### 3-1. 気温と光量

| 条件 | 限界値 | 最適値 | 外れたとき |
|---|---|---|---|
| 発芽温度 | 1-2℃でも発芽 | 18-25℃ | 低温でも発芽しますが、非常に遅くなります |
| 生育温度 | 4-25℃ | 10-20℃ | 25℃を超えると生育が止まり、病害が急増します |
| 結実温度 | 13-23℃ | 15-20℃ | 幅10℃の狭い範囲です |
| 開花期の高温 | 25℃以上が数日 | - | 花と幼いさやが落ちます |
| 耐寒性 | 氷点下5℃まで | - | 幼い芽は氷点下4-7℃まで耐えます |
| 霜 | 開花後は霜に弱い | - | 花とさやが傷みます |
| 日照 | 1日6時間以上 | 1日8時間以上 | 40%の遮光で収量が半分に落ちます |

> **エンドウ栽培のあらゆる判断は、暑さから逃げる方向で下されます。いつ播種するか、どの品種を選ぶか、いつ収穫するかは、すべてその地域で最初に暑くなる日付から逆算されます。**

&nbsp;&nbsp;&nbsp;エンドウの耐寒性と耐暑性は非対称です。幼いエンドウは氷点下5℃に耐え、韓国南部では畑で冬を越します。一方、25℃を超えると花が落ち始め、30℃に達すると葉が枯れてうどんこ病に覆われます。そのため、播種を急ぐことはほとんどいつも正しい選択です。韓国では、3月初めに播種して遅霜に1-2回当たる損失のほうが、4月に播種して開花期が6月の暑さにぶつかる損失よりはるかに小さくなります。

&nbsp;&nbsp;&nbsp;秋播きができるのは韓国南部だけです。10月初めから末までに播種して本葉2-3枚の状態で冬を越させ、翌年3月から再び生長して、5月中旬から6月中旬に収穫します。この作型の価値は大きいです。春に播種するより根が深く張るので干ばつに強く、収穫が2-3週間早まって暑さを完全に避けられます。ただし、越冬に失敗する危険があるため、春播き分も併せて確保して危険を分散させるのが安全です。冬の寒さが厳しい韓国中部の内陸では、秋播きは概ね失敗します。

### 3-2. 土壌と水

| 条件 | 限界値 | 最適値 | 備考 |
|---|---|---|---|
| 土性 | 砂質土から粘質土まで | 水はけのよい埴壌土-壌土 | 水がたまる土地が最も悪いです |
| pH | 6.0-8.0 | 6.5-7.5 | 酸性土壌では生育がはっきりと不振になります |
| 有効土層 | 30cm以上 | 50cm以上 | 主根が深く入ります |
| 作期の蒸発散量 | - | 約400mm | 豆類の中では少ないほうです |
| 冠水 | 1日以上水に浸かると根が傷みます | - | 湿害に非常に弱いです |
| 地下水位 | 50cm以下 | 80cm以下 | 春雨の多い時期と重なります |

&nbsp;&nbsp;&nbsp;エンドウは豆類の中で、土壌の酸度に対する要求が最も厳しいほうです。pH 6.5-7.5が最適で、6.0を下回ると生育がはっきりと悪くなります。原産地が石灰質土壌の多い地中海東部であるという事実が、これを説明します。韓国の畑は降雨が多く、概して酸性に傾くため、エンドウ畑では石灰の施用が肥料より先に行う作業になります。しかも、この要求は植物自体というより、根粒菌の要求でもあります。酸性土壌では、豆自体はどうにか育ちますが、根粒菌が生きられず、窒素固定が止まります。

&nbsp;&nbsp;&nbsp;湿害に対する弱さも強調しておく必要があります。エンドウの生育期間は、春雨と、初夏の韓国の梅雨（チャンマ、6月下旬～7月）の初めにかかっています。茎の中が空洞で組織が軟らかい上に、根粒菌が好気性細菌であるため、畑が1日冠水しただけで、根も根粒もともに機能を失います。畝を20cm以上高くし、排水溝を深く掘ることは、エンドウでは選択の余地のない作業です。

## 4. 品種

### 4-1. 草丈による分類

| 区分 | 草丈 | 支柱 | 収穫 | 特徴 |
|---|---|---|---|---|
| 矮性種（ドワーフ種） | 30-60cm | 不要、または簡単なもので十分 | 短期間に集中 | 手間がかかりません。収量は少ないです |
| 高性種（つる性エンドウ） | 1-2m | 必須 | 長期間、複数回 | 収量が多いです。支柱立てと誘引に手間がかかります |
| 中間型 | 60-100cm | 簡単な支柱 | 中程度 | バランスがとれています |

&nbsp;&nbsp;&nbsp;災害時、この選択は労働力と資材の問題になります。高性種は同じ面積からはるかに多く収穫できますが、高さ2mの支柱を立て、ネットを張り、つるを上へ誘引してやる作業が続けて必要です。竹とひもが十分にあり、人手もあるなら高性種が正解で、資材も人手も足りないなら矮性種が現実的です。矮性種でも、株どうしがもたれ合って育つように密に植え、畑の周囲に低くひもを張りめぐらせるだけで、倒伏をかなり防げます。

### 4-2. 用途による分類

| タイプ | 食べる部位 | 特徴 | 向いている場面 |
|---|---|---|---|
| さや実兼用（サヤエンドウ・スナップエンドウ） | さやごと | さやが硬くなく、甘みがあります | 野菜が不足するとき。皮まで食べられるので無駄がありません |
| グリーンピース用 | 未熟な子実 | 粒が大きく甘く、ビタミンCがあります | 春から初夏の新鮮な野菜 |
| 乾燥子実用 | 乾燥した子実 | 貯蔵性がよく、タンパク質が濃縮されています | 冬を越すための備蓄食料 |
| スプラウト・若芽の収穫用 | 若芽と巻きひげ | 播種後5-20日で収穫します | 冬から早春の新鮮な野菜 |
| 緑肥用 | 茎葉全体 | 窒素を残すために育てます | 畑を回復させるとき |

&nbsp;&nbsp;&nbsp;災害への備えという観点で最も価値が高いタイプは、さや実兼用です。さやと豆を一緒に食べるため、同じ畑から得られる食べられる重量が増え、むいて捨てる部分がありません。さやには食物繊維とビタミンが含まれているので、栄養の幅も広がります。ただし、さやごと食べるには若いうちに摘む必要があり、そのままにしておくと、皮の内側に硬い薄皮ができて食べにくくなります。

&nbsp;&nbsp;&nbsp;品種選びの第一の基準は、自家採種ができるかどうかです。交配一代雑種（F1）は、翌年に播くと形質が分離してしまいます。エンドウは幸い、栽培品種の大半が固定種で自家受粉のため、採った種子をそのまま播けますが、種子の袋に雑種と書かれていたら、翌年に期待してはいけません。地域の在来種は収量が少ない代わりに、その地域の気候や土壌病害にすでに適応しており、種子をつないでいくことができます。

### 4-3. 状況別の選択基準

| 状況 | 優先順位 | 理由 |
|---|---|---|
| 支柱の資材がない | 矮性種 | 支柱がなくてもある程度は立ちます |
| 畑は狭いが人手はある | 高性種 | 上に伸びるので、面積当たりの収量が高くなります |
| 冬の野菜がない | スプラウト・若芽の収穫兼用 | 土がなくても、水だけでスプラウトが出ます |
| 貯蔵食料が必要 | 乾燥子実用、丸い種子の系統 | しわのある種子より貯蔵性がよいです |
| 暑さが早く来る地域 | 早生の矮性種 | 短い期間で終わらせる必要があります |
| 韓国南部 | 秋播き用の耐寒性品種 | 越冬によって収穫が早まります |
| 畑にエンドウを植えたことがある | 萎凋病抵抗性の系統 | 土壌病原菌が残っています |

## 5. 畑の準備と肥料 - 根粒菌

### 5-1. 窒素固定はどのように起こるのか

&nbsp;&nbsp;&nbsp;空気の78%は窒素です。人の頭上に無限の窒素が漂っているのに、植物はそれを使えません。空気中の窒素は、窒素原子二つが三重結合で固く結ばれた分子で、この結合を切るには莫大なエネルギーが必要だからです。工業的にこの結合を切ってアンモニアをつくるのがハーバー・ボッシュ法で、世界の窒素肥料はそこから生まれます。高温、高圧、触媒、そして膨大な化石燃料が必要です。

&nbsp;&nbsp;&nbsp;根粒菌は、この仕事を常温常圧でやってのけます。ニトロゲナーゼという酵素で三重結合を切り、窒素をアンモニアに変えます。ただし代償があります。この反応には多くのエネルギーが必要ですが、根粒菌は自分で光合成ができません。そこで、マメ科植物の根に入り込んで暮らし、植物が光合成でつくった糖をもらい、その見返りに固定した窒素を渡します。いわば取引関係です。

&nbsp;&nbsp;&nbsp;エンドウと対をなす菌は、Rhizobium leguminosarum bv. viciaeです。ダイズのBradyrhizobium japonicumとは別の種で、互いに通用しません。この点は実用上、非常に重要です。ダイズを育てた畑の土をエンドウの種子にまぶしても効果がありません。一方、この菌はエンドウだけでなく、ソラマメ、レンズマメ、ベッチ（カラスノエンドウ）の仲間とも共生します。つまり、エンドウの接種源は、ソラマメやレンズマメ、野生のカラスノエンドウを育てた畑の土からも得られます。

| 段階 | 起こること |
|---|---|
| 1. シグナルの交換 | エンドウの根がフラボノイドを分泌し、土の中の根粒菌がそのシグナルに応えてNod因子を放出します |
| 2. 感染 | 根毛が内側に曲がって根粒菌を包み込み、根粒菌は感染糸に沿って根の内部へ入っていきます |
| 3. 根粒の形成 | 根の内側の細胞が分裂して根粒がふくらみ、その中に根粒菌が定着します |
| 4. 窒素固定 | 根粒の中でニトロゲナーゼが働き、空気中の窒素をアンモニアに変えます |
| 5. 分配 | アンモニアがアミノ酸に変わり、つる・葉・さやへと運ばれます |
| 6. 老化 | 登熟期に入ると根粒が機能を失い、根とともに土に還ります |

&nbsp;&nbsp;&nbsp;ニトロゲナーゼは酸素に非常に弱く、酸素に触れるとたちまち機能を失います。そのため、根粒の内側にはレグヘモグロビンという赤い色素タンパク質が満ちていて、酸素をつかまえ、酵素のまわりの酸素濃度を極端に低く保っています。人の血が赤いのと同じ原理で、根粒を割ったときに内側が赤やピンク色をしているのは、この色素によるものです。この事実は、実用上きわめて重要です。赤い色は、その根粒がいま窒素を固定していることを示す、目に見える証拠だからです。

### 5-2. 根粒ができたかどうかを確認する方法

&nbsp;&nbsp;&nbsp;接種をしたかどうかにかかわらず、根粒が実際にできたかどうかを確認する作業は、必ず行う必要があります。確認しなければ窒素不足の原因がわからず、翌年も同じ失敗を繰り返すことになります。

| 手順 | 内容 |
|---|---|
| 1 | 開花が始まるころ、播種後5-7週間ごろが最適な時期です |
| 2 | 健康そうな株を2-3株選びます |
| 3 | 引き抜かず、スコップで株の周りを広めに掘り、土ごと持ち上げます。引き抜くと、細根の根粒が土に残ってしまいます |
| 4 | 水桶に入れて、土をそっと洗い流します |
| 5 | 主根と太い細根についた根粒の数を数えます |
| 6 | 根粒を数個、爪で割って、内側の色を見ます |

| 観察結果 | 意味 | 対処 |
|---|---|---|
| 根粒が1株あたり20個以上あり、特に主根の上部に集まっている | 接種がうまくいっています | そのままにします |
| 割った内側が赤またはピンク色 | 窒素を固定しています | 良好な状態です |
| 割った内側が白色または薄緑色 | 根粒はできているが、固定していません | 酸度、湿害、リン酸欠乏を調べます |
| 割った内側が茶色または黒色 | すでに老化したか、死んでいます | 登熟期なら正常、開花期なら問題です |
| 根粒が5個以下 | 接種が失敗しています | 葉が黄色いなら窒素を補います |
| 根粒が細根の先端にだけ小さく多数ついている | 土着の菌に感染したが、効率は低いです | 翌年は接種源を替えます |

> **根を掘り上げて根粒を割り、赤い色を確かめる。この一つの習慣が、窒素肥料のない世界で豆づくりの成否を教えてくれる、最も確かなサインです。**

&nbsp;&nbsp;&nbsp;根粒のつく位置も情報を与えてくれます。主根の上部、土の表面から10cm以内についた大きな根粒が、最も効率が高いものです。接種がうまくいったときにできる位置です。逆に、主根にはなく、細根の先端にだけ小さな根粒が散らばっている場合は、もともと土にいた土着の菌が遅れて感染したケースが多く、固定の効率は落ちます。

### 5-3. 接種源をどこで手に入れるか

&nbsp;&nbsp;&nbsp;市販の接種剤は、生きた根粒菌を泥炭や粘土に含ませて売っている製品です。災害時には入手できません。しかし根粒菌は土にすむありふれた微生物で、同じマメ科を育てた畑の土が、そのまま接種源になります。

| 方法 | 手順 | 効果 | 注意 |
|---|---|---|---|
| エンドウを育てた畑の土をまぶす | 前年にエンドウ、ソラマメ、レンズマメ、カラスノエンドウを植えて根粒がよくできた畑から、表土5-15cmの深さの土を掘り取ってきます。種子を水で軽く湿らせ、この土を全体にまぶしたら、すぐに播きます | 最も確実で、費用がかかりません | 病気の出た畑の土は、病原菌も一緒に運んでしまいます。エンドウの萎凋病が出た畑は絶対に避けます |
| 土を畑にまく | 播種する条に、掘り取ってきた土をまき、一緒にすき込みます | 種子にまぶすより量が多く必要ですが、菌が土全体に広がります | 10㎡あたりスコップ1杯程度が目安です |
| 根粒そのものを使う | 掘り上げたエンドウの根から根粒を集めてすりつぶし、水に溶かして、その水に種子を浸してから引き上げます | 菌の密度が最も高いです | 根粒を掘り取ったその日のうちに使わなければなりません。乾くと菌が死にます |
| 根の残渣を残す | 収穫のとき茎だけを刈り取り、根を畑に残します | 翌年まで菌が土に残ります | 最も手間のかからない維持方法です |
| 野生のカラスノエンドウの根 | 野原や畑の畦のカラスノエンドウの根から根粒を採取します | エンドウと同じ菌が共生しています | 固定の効率が、栽培種用の系統より低いことがあります |

&nbsp;&nbsp;&nbsp;接種するときに必ず守るべきことがあります。根粒菌は、直射日光、乾燥、熱に非常に弱い菌です。紫外線を数分浴びるとかなりの数が死に、乾くとさらに速く死にます。種子に土をまぶす作業は日陰で行い、まぶした種子は日なたに広げず、すぐに播きます。30分以内に播くのが望ましく、遅くとも数時間以内に終えます。1日以上置いてから播くと、効果はほとんどなくなります。もう一つ、種子消毒と接種は同時にはできません。殺菌剤をつけた種子に土をまぶすと、根粒菌が死んでしまいます。温湯処理で消毒したなら、完全に冷ましてから接種します。

| 接種の失敗を招く条件 | 理由 |
|---|---|
| 土壌pH 6.0以下 | 根粒菌が生きられません。エンドウは特に酸度に敏感です |
| 窒素肥料を十分に施した畑 | 植物が取引の必要を感じず、自ら根粒の形成を減らします |
| 水がたまる畑 | 好気性細菌なので、酸素がないと死にます |
| リン酸が不足する畑 | 窒素固定には多くのエネルギーが必要で、その代謝にリン酸が使われます |
| モリブデン・鉄・コバルトの欠乏 | ニトロゲナーゼの構成成分です |
| 接種した種子を日光で乾かす | 紫外線と乾燥で菌が死にます |
| ダイズ畑の土を使う | 菌の種が違うため、エンドウには感染しません |
