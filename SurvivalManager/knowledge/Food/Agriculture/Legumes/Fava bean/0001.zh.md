## 引言
&nbsp;&nbsp;&nbsp;蚕豆（Vicia faba）又称胡豆，英文名fava bean、broad bean，是豆科一年生或二年生草本，来自地中海东部和西南亚。最大的特点是耐寒性为S：能耐-10℃、在田里越冬的豆科只有蚕豆。在南部于立冬前后播种，次年5月中旬-6月收获，是当年田里最早出来的蛋白质，填补陈粮吃完、夏季作物尚未成熟之前的粮食空档。综合等级为A（50.2分，有效183种中第15名），短期A（48.6）、长期S（51.7），副食为SS（65.9分），蛋白质密度、施肥、耐储性为SS。单位面积热量为C，每㎡ 1,023kcal，仅为自给线的0.39倍，所以不能作主食；国内种植普及度为B，在3-4个道（韩国行政区）之外很难弄到种子。有一个等级表上没有的风险：G6PD缺乏体质者会发生急性溶血的蚕豆病，烹调无法消除，所以在决定种植之前必须先读第10节。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | A | 50.2 |
| 短期 | A | 48.6 |
| 长期 | S | 51.7 |
| 副食 | SS | 65.9 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：蛋白质密度、施肥、设施负担、耐储性。S：耐寒性、口味、自留种。A：微量营养素、水消耗量、温度幅度、连作适应性、无合成投入产量保持率、产量稳定性、种子寿命 |
| 劣势 | D：持续性、光照、烹调·加工要求度。C：单位面积热量、病虫害压力、整地·挖掘能量、非食用价值。B：收获速度、防治自立度、国内种植普及度 |

> **蚕豆的价值不在于产量，而在于栽培的时期和土地。它守住什么也长不了的冬天的田，在春天最先拿出吃的，并给后面的作物留下氮。**

&nbsp;&nbsp;&nbsp;连作适应性A属于休耕2年组，比豌豆的5-7年从容。烹调·加工D是每天要付的成本，因为种皮厚，要泡8小时、煮1小时。防治自立度B是因为危害集中在一种蚜虫上，而它可以靠打顶来控制。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 豆科野豌豆属。以自花授粉为主，但蜜蜂造成的异花授粉占30-50% |
| 叶、茎 | 偶数羽状复叶，小叶2-6对，没有卷须。茎直立、截面呈方形，株高80-120cm，所以不一定需要支柱 |
| 根、花 | 笔直的主根深入土中，粗大的根瘤集中长在主根上部。花为蝶形，白底带黑斑，香味浓，蜜蜂很爱来 |
| 荚、籽粒 | 厚而长，15-30cm，内侧有棉絮状的白膜。籽粒扁平而大，每粒2g，是豆类中最大的，成熟时荚干成黑色而不是褐色 |

&nbsp;&nbsp;&nbsp;大部分花会自行脱落，能成荚的只有十分之一左右，开花期的水分、温度和蜜蜂的访花决定这个比例。干籽粒每100g热量341kcal，蛋白质26.12g（占热量的30.6%），脂肪1.5-2g，碳水化合物约58g，膳食纤维约25g，铁6-7mg，钙约100mg，镁约190mg，叶酸非常丰富，脂肪少，所以酸败慢。嫩荚和嫩芽中左旋多巴（L-多巴）含量高，吃多了可能头晕、恶心。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽5℃以上（最适15-20℃）。生长5-28℃（最适10-20℃），超过25℃生长就会停止。结实10-24℃。开花期25℃以上持续几天，花和嫩荚就会脱落 |
| 耐寒性 | 耐到-10℃，-15℃以下持续就会死亡。越冬前长得太大反而会冻死，所以真叶3-4片、株高10-15cm最能耐寒 |
| 水、土壤 | 排水良好的沙壤土（从沙土到黏土都能适应），pH 5.5-8.0（最适6.0-7.0，低于5.5固氮就会停止），有效土层40cm以上（最适60cm）。被水淹一天以上根就受伤，根瘤先失去功能 |

&nbsp;&nbsp;&nbsp;在中部内陆，-15℃会持续多日，越冬大多失败，所以改为春播。南部沿海和济州岛越冬栽培稳定，中间地带视年份而定，所以把秋播和春播分开种以分散风险。

&nbsp;&nbsp;&nbsp;每粒2g以上的大粒食用种产量高，是食用和储存的基础；每粒0.7-1.5g的小粒地方种耐寒、耐瘠薄，适合田地差、冬天冷或种子不足的情况（同样重量可种得宽得多）。韩国国内几乎没有正式登记的品种，所以提前确保种子并通过自留种继续种下去是唯一的路；头两三年不要指望产量，集中精力扩繁种子，并不断挑选在当地越冬成功的植株。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 深耕20-30cm以上，垄高20cm以上，排水沟深30-50cm。充分腐熟的堆肥2,000-3,000kg/1,000㎡ |
| 施肥（1,000㎡） | 氮3-5kg（起步用的最小量，多了会倒伏、招蚜虫、荚减少），磷10-15kg，钾10-15kg（均作基肥），酸性土施石灰150-200kg（播种前3周）。替代资源有草木灰（每㎡ 100-200g）、骨粉、烤过的贝壳·蛋壳（代替石灰） |
| 根瘤接种 | 取种过蚕豆、豌豆、小扁豆、救荒野豌豆的田里5-15cm深的表土，在阴凉处裹在用水稍微润湿的种子上，30分钟内播下（菌怕直射阳光、干燥和高温，且不与消毒同时进行）。大豆田里的土因菌种不同而无用 |

&nbsp;&nbsp;&nbsp;开花前后用铁锹连土挖起、洗净，剖开根瘤。主根上部集中20个以上、内部呈红色，说明接种顺利；5个以下是失败；只在须根末端零星长着的，是被本地菌感染、效率低，所以次年要更换接种源。

&nbsp;&nbsp;&nbsp;每公顷固氮量在条件好时为150-200kg（差时40-80kg），随籽粒带走110-140kg，茎叶里留下40-60kg。把茎叶切成20-30cm盖在田里，不挖根，如果茎秆喂了牲畜就把粪肥还回这块田，才不会掠夺土地。瘠薄的地块可以放弃籽粒，在开花期翻压，会留下150-200kg的氮，使其恢复生机。

| 播种 | 标准 |
|:---|:---|
| 时期 | 秋播·越冬栽培在预计初霜日前40-50天，即立冬前后（南部11月上旬，次年5月中旬-6月中旬收获）。9月播种会在入冬前长得太大而冻死，12月播种则在扎根前被冻土困住。春播在土壤刚解冻时的2月中下旬-3月上旬（5月下旬-6月下旬收获），过了3月中旬，开花期会遇到高温，产量大幅下降 |
| 种子准备 | 弃去有斑点、变色、皱缩、虫孔的种子。种皮厚，浸种效果大，浸24小时（超过则里面变软腐烂），放在50-55℃水中浸10-15分钟消毒，并裹上细草木灰以防鼠和鸟 |
| 方法 | 深5-7cm（越冬栽培更深），每穴1-2粒，行距45-90cm，株距15-30cm（大粒种要宽），每㎡ 4-8株。到发芽前盖上稻草或网 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种至发芽 | 不要让土壤彻底干掉 |
| 生长初期 | 靠自然降水（干燥会让根扎得深） |
| 冬季（越冬） | 只管排水（结冰又融化时积水最危险，所以隆冬也要时常疏通水道） |
| 开花期至鼓荚期 | 浇足，不让土壤变干（降低落花率最可靠的办法） |
| 成熟期 | 停止灌溉（荚果干不了，会发霉） |

| 管理 | 方法 |
|:---|:---|
| 打顶 | 下部节位开始开花、上部还留着花蕾时，用手摘掉茎端5-10cm。养分集中到已开的花和荚上，产量增加；聚集在最嫩的生长点上的蚜虫被清除；摘下的嫩尖焯后当野菜吃。太早会减少能坐花的节位，太晚蚜虫已经向下扩散。瘠薄、生长不良的植株（停在膝高、叶色淡）不要打顶 |
| 间苗、除草 | 间苗在真叶2-3片时只整理过密处，4-5片时只留健壮的植株。除草在播种后3-4周浅锄，开花前与培土同时再进行一次 |
| 培土、倒伏 | 株高30cm左右时在基部培土，可形成支撑，埋入土中的茎上会长新根，沟加深使水排得顺畅。倒伏的原因是氮过多和密植，风大的地方沿田边打桩，在腰高处拉绳 |
| 冻拔、野兽 | 冬天被顶起的植株用脚踩实，并盖5-10cm的稻草或落叶。冬天的田野里只有蚕豆是绿的时候，獐会来，所以要围篱笆或网，并种在离家近的田里 |

## 6. 病虫害与养分问题
| 病虫害 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 赤斑病（巧克力斑点病） | 叶上出现红褐色小圆斑并扩大，叶子枯死。潮湿而凉爽时蔓延，是蚕豆最大的病害 | 稀植保证通风，把排水沟挖深。缺钾会加重，所以施草木灰 |
| 锈病、炭疽病 | 叶上有橙色粉堆（生长后期湿度大） / 茎和荚上有黑色溃疡（种子传染） | 摘除病叶、保证通风、提早收获 / 选种和轮作 |
| 枯萎病·根腐病、病毒病 | 从下部叶开始萎蔫，根变褐腐烂（过湿、连作） / 叶片呈花叶状斑驳皱缩（由蚜虫传播） | 轮作2年以上、排水、起高垄 / 无法治疗，所以拔除烧掉并减少蚜虫 |
| 黑豆蚜 | 嫩芽和花梗上密密麻麻地附着黑色蚜虫，吸汁并传播病毒，是最大的害虫 | 打顶最有效。把肥皂水（每1L水加肥皂5g）喷在叶背，并保护瓢虫和草蛉 |
| 蚕豆象 | 在田里于荚上产卵，储存期间蛀食籽粒 | 完全晒干后密封（见第9节） |

&nbsp;&nbsp;&nbsp;波尔多液是将硫酸铜400g和生石灰400g分别溶于100L水中再混合，立即使用，用于赤斑病和锈病。在有露水的早晨撒在叶上的细灰能抑制霉菌，同时补钾。碰到湿叶会带来病原菌，所以雨后不进田，病残体烧掉或深埋，只把健康的残体还回田里。

| 症状 | 原因与对策 |
|:---|:---|
| 从下部叶开始整株淡黄、植株矮小 | 缺氮（根瘤不良最常见）。先挖出根检查根瘤，再考虑施肥；若没有根瘤，次年务必接种好，当季施少量稀释10倍的人尿 |
| 叶缘发褐干枯、赤斑病严重 | 缺钾。把草木灰撒在株间并轻轻耙入，每㎡上限200g（超过会妨碍铁和锰的吸收） |
| 落花很多、几乎不结荚 | 缺硼，或开花期高温干燥。施用多种材料混合的堆肥，当季浇水并打顶 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 小麦、大麦（冬季作期相同，谷物分享蚕豆的氮，笔直的茎秆能防止倒伏，但进入遮阴处产量会下降，所以行距要放宽）、马铃薯（在蚕豆收获后的地里种）、甘蓝·大白菜（利用残留的氮） |

&nbsp;&nbsp;&nbsp;蚕豆在5-6月收获，这块地正好与夏季作物的播种期衔接，把茎叶切碎覆盖后，可以种甘薯、玉米、晚播大豆，一年收两茬，第二茬利用残留的氮。休耕为2年以上，连作超过3年会积累枯萎病、炭疽病和线虫。轮作的例子是：第1年蚕豆（越冬）之后种甘薯或玉米（夏） → 第2年大白菜·甘蓝类或叶菜 → 第3年马铃薯或谷物 → 再种蚕豆。地块小时分成四块，每年挪一块，或者至少每年更换行的位置。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 青蚕豆在播种后70-90天，荚饱满有光泽、仍呈绿色、里面的白膜湿润时。干籽粒在播种后100-120天，荚干成黑色、籽粒变硬时 |
| 要领 | 青蚕豆要拧着荚摘（拉扯会伤茎）。干籽粒从下部节位的荚开始变黑，所以由下往上收，用镰刀割断茎基，把根留在田里。扎成捆，倒挂在屋檐下或棚里晾干。有下雨消息就不等完全成熟，赶紧收（反复被淋湿又晒干的荚会炸裂，籽粒掉落） |
| 脱粒、精选 | 荚完全干透后用连枷打或用手剥（籽粒大，手剥效率高）。在有风的日子慢慢倒下，吹去壳，用筛子筛选，在水中捞去浮起的，当天内重新晒干（留种用的除外） |

| 留种 | 标准 |
|:---|:---|
| 选株、收获 | 预先在田里标记没有病症、荚多、越冬良好的植株。荚完全干成黑色后，比食用的晚收，单独脱粒并用手剥 |
| 隔离 | 蜜蜂造成的异花授粉有30-50%，所以要与其他品种相隔数百米，或一年只种一个品种 |
| 精选、干燥 | 弃去斑点、皱缩、变色、小的籽粒，只留大而有光泽的。含水量12%，用牙咬不留齿痕、脆脆地裂开。常温密封下种子寿命3年 |

## 9. 储存
| 步骤 | 方法 |
|:---|:---|
| 干燥 | 连茎倒挂在屋檐下三四天，脱粒后薄摊在阳光下晒3-5天（籽粒大，比大豆耗时长，要常翻动）。含水量12%，外面先干，所以要掰开看看里面 |
| 蚕豆象防治 | 卵在田里就已经粘在荚上带进来，所以半年就会让一袋变成满是虫孔的空壳。完全密封最重要（氧气耗尽，虫就死了），要把容器装满、减少空隙，用几个小容器而不是一个大容器。拌入筛过的草木灰，占体积的2-5%（吃前冲洗），硅藻土每1kg 1-3g（仅在干燥状态下有效），油涂层是每1kg加食用油2-5mL（留种用的除外） |
| 容器、检查 | 玻璃瓶和金属桶3年以上，陶罐和地下储藏窖2-3年，厚塑料袋1-2年（老鼠会咬穿）。把耳朵贴在容器上，有沙沙声是有虫，有霉味是发霉，表面有小圆孔说明象甲已经过了一代。每两个月检查一次 |

## 10. 烹调与注意事项
> **缺乏G6PD酶的人吃了蚕豆，红细胞会急剧破坏，发生急性溶血。这称为蚕豆病（favism）。对儿童可能是致命的，也有仅仅吸入蚕豆花粉就发病的报告。**

| 蚕豆病 | 内容 |
|:---|:---|
| 原因 | 蚕豆中的蚕豆嘧啶葡糖苷（vicine）和伴蚕豆嘧啶葡糖苷（convicine）在肠道中变成强氧化物质（二羟嘧啶、异乌拉米尔），在数小时内大量破坏缺乏G6PD的红细胞 |
| 对象 | G6PD缺乏者（X染色体遗传，男性更常见，在地中海沿岸、中东、非洲、东南亚血统中常见）。儿童最危险 |
| 症状 | 数小时后寒战、发热、头痛、腹和背疼痛 → 尿呈深褐色或可乐色 → 黄疸、严重苍白、气短 → 重症者站不起来、意识模糊、几乎无尿 |
| 去除 | 煮、烤、发酵都不能消除风险（去皮和浸泡只能部分减少） |

&nbsp;&nbsp;&nbsp;灾害情况下没有办法检测G6PD缺乏，所以少量试吃是唯一的安全措施。对新加入的人、孩子和没吃过蚕豆的人，无一例外只给五六粒（孩子两三粒），观察一两天。如果尿变成深褐色或可乐色，立即停止，让其安静休息，再也不要给他吃。如果亲属中有人吃了蚕豆或某些药物后出现黄疸和贫血，或者家里有缺乏者，就改种豌豆或豇豆代替蚕豆，缺乏者在开花期也不要靠近田地。

| 成分 | 作用 | 去除方法 |
|:---|:---|:---|
| 胰蛋白酶抑制剂、凝集素 | 阻碍蛋白质分解酶，附着在肠黏膜上妨碍吸收 | 浸泡8小时后，在沸水中加热1小时 |
| 植酸、低聚糖、霉菌毒素 | 妨碍铁、锌、钙的吸收 / 肠内发酵使肚子胀气 / 储存期间由霉菌产生 | 浸泡、发芽、发酵可减少60-80% / 倒掉浸泡的水 / 发霉的豆子洗了、煮了也不安全，要丢弃 |

| 处理 | 标准 |
|:---|:---|
| 浸泡、去皮、煮 | 在常温水中泡8小时以上（大粒12小时），泡豆水一定要倒掉。用手指捏泡好的豆，皮就会脱落，烹调时间缩短近一半，也更易消化。在沸水中煮1小时（去皮后30-40分钟），容易压烂就是熟了 |
| 节省燃料 | 压力烹调是将泡好的豆加压15分钟。余热烹调是煮15分钟后熄火，用稻草·稻壳箱或被褥把锅包起来放2-3小时。炒蚕豆是把泡过再晒干的豆不加油炒，直接吃 |
| 青蚕豆、嫩芽 | 青蚕豆去皮后焯几分钟。嫩芽焯后当野菜吃，或腌盐，或焯后晒干留到冬天 |
| 储存加工 | 蚕豆粉（密封3-6个月）、腌嫩芽（几个月）、焯过晒干的青蚕豆（几个月）、煮烂捣碎发酵的蚕豆大酱（大豆不足时的替代品，但发酵也消除不了这两种糖苷） |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存、巡视越冬田并踩实被顶起的植株。2月中下旬春播、做田地规划、撒石灰 |
| 3-4月 | 3月给越冬植株培土、除草、检查排水沟。4月开花开始、打顶、蚜虫管理、检查根瘤 |
| 5-6月 | 5月鼓荚、集中灌溉、收获越冬茬的青蚕豆。6月收获越冬茬的干籽粒、春播茬的青蚕豆、挂起晾干 |
| 7-8月 | 7月脱粒、精选、晾干、储存、茎叶还田。8月后茬管理、检查储存 |
| 9-10月 | 9月整理秋季田地、撒石灰（播种前3周）、施堆肥。10月起垄、开排水沟、选种 |
| 11-12月 | 11月秋播。12月盖稻草·落叶、防兽、检查储存 |

> **蚕豆只要先用少量试吃确认蚕豆病，把播种日定在初霜前40-50天，做好排水，开花期打顶，并把茎、叶、根还给田地，就是能在冬天的田里于春天最早产出蛋白质的作物。**
