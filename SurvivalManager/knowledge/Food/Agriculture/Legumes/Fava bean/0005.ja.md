## 8. 栽培管理 - 摘心

### 8-1. なぜ摘心が欠かせないのか

&nbsp;&nbsp;&nbsp;ソラマメ栽培で最も効率の高い作業を一つ挙げるなら、摘心です。下の節で花が咲き始めるころ、茎の先端の柔らかい芽を手で摘み取ります。この一回の作業が三つのことを同時に成し遂げます。

| 効果 | 原理 |
|---|---|
| 収量増加 | 上に伸びていた生長が止まり、養分がすでに咲いた花とさやに集中します。ソラマメは落花率が高いため、この効果が特に大きいです |
| アブラムシ防除 | ソラマメアブラムシは最も若い生長点に集まっています。芽を摘むだけで個体群のかなりの部分が取り除かれます |
| 野菜の確保 | 摘んだ芽はゆでて和え物にして食べます。春に新鮮な葉物野菜が乏しい時期に得られる分です |

> **薬がない条件で、防除と収穫と収量増加を一回の作業で得られることは稀です。ソラマメの摘心はその稀な例です。評価表で防除自立度がBと評価された根拠でもあります。**

&nbsp;&nbsp;&nbsp;時期が重要です。下の節で花が咲き、上にまだつぼみが残っている時が適期です。早すぎると花が着く節そのものが減り、遅すぎるとすでにアブラムシが下まで広がった後になります。手で5-10cmほどをポキッと摘み取ればよく、道具は必要ありません。摘んだ芽はすぐにゆでて食べるか、量が多ければゆでて干しておき、冬に使います。

&nbsp;&nbsp;&nbsp;ただし、すべての状況で摘心が良いわけではありません。畑がやせていてすでに生育が不振なソラマメに摘心をすると、回復する力がなく、むしろ収量が減ります。畑を見回り、腰の高さまで育ち葉の色が濃ければ摘心し、膝の高さで止まっていて葉の色が薄ければそのままにします。

### 8-2. 間引きと除草

| 作業 | 時期 | 方法 |
|---|---|---|
| 1回目の間引き | 本葉2-3枚 | 密集しすぎている所だけ整理します |
| 2回目の間引き | 本葉4-5枚 | 健康な個体だけ残します |
| 1回目の除草 | 播種後3-4週 | 浅く削ります。根を傷めないようにします |
| 2回目の除草 | 開花前 | 土寄せと兼ねます |
| 土寄せ | 丈30cmころ | 株元に土を寄せて倒伏を防ぎます |

&nbsp;&nbsp;&nbsp;土寄せはソラマメにおいて価値が大きい作業です。丈が120cmまで育ち、さやが重いため風で倒れやすいのですが、株元に土を寄せると支えができ、埋まった茎から新しい根が出ます。同時に株間の溝が深くなって水はけが良くなり、若い雑草が土に埋まります。越冬栽培では、春に再び生長し始めるころに一度土寄せをすると、霜柱で浮き上がった株を押さえる効果も同時に得られます。

### 8-3. 倒伏対策

| 原因 | 対応 |
|---|---|
| 窒素過多 | 施肥量を守ります。これが根本です |
| 密植 | 植え付け距離を守ります。ソラマメは体が大きいので疎植します |
| 土寄せをしない | 丈30cmころに必ず行います |
| 風の強い場所 | 畑の周りに支柱を立て、腰の高さで縄を張り巡らせます |
| さやの重さ | 下のさやから熟した順に摘み取ると重さが減ります |

&nbsp;&nbsp;&nbsp;ソラマメはつる性ではなく直立する作物なので、エンドウのような支柱や網は必要ありません。畑の周りに支柱を立て、腰の高さで縄を一、二重に張るだけで大抵は十分で、風のない場所ではそれさえ必要ありません。竹や縄が貴重な条件では、これはエンドウに比べてソラマメが持つ明らかな利点です。

## 9. 病害虫

&nbsp;&nbsp;&nbsp;ソラマメの病害虫圧はCです。無防除時の減収率は推定48.9%で、マメ科全体の平均値が割り当てられています。しかしソラマメでは実際の被害のかなりの部分がアブラムシ一種に集中しており、そのアブラムシは摘心でかなりの部分を抑えられます。防除自立度がBである根拠です。

### 9-1. 主な病害

| 病名 | 症状 | 発生条件 | 薬を使わない対応 |
|---|---|---|---|
| チョコレート斑点病 | 葉に赤褐色の小さな丸い斑点ができ、悪化すると斑点が大きくなって葉が枯れます | 多湿で涼しいとき。ソラマメ最大の病害 | 通風確保、排水、植え付け距離の確保。カリウムが不足すると悪化するので草木灰を与えます |
| さび病 | 葉に橙色の粉状の塊ができます | 生育後期の多湿 | 病葉の除去、通風確保。早期収穫で回避します |
| 炭疽病 | 茎とさやに黒い潰瘍ができます | かび。多湿 | 種子選別と輪作が要です |
| 萎凋病・根腐病 | 下の葉から萎れ、根が茶色く腐ります | 過湿、連作 | 2年以上の輪作、排水、畝を高くします |
| ウイルス病 | 葉がモザイク状にまだらになり縮れます | アブラムシが媒介します | 治療は不可能です。抜いて焼却し、アブラムシを減らします |
| 菌核病 | 茎が軟らかくなり、白い綿のような菌糸ができます | 涼しく湿った条件 | 病株は土ごと掘り出して焼却します |

&nbsp;&nbsp;&nbsp;チョコレート斑点病はソラマメで最も多く、最も重い病気です。名前のとおりチョコレート色の斑点が葉に現れ、湿った年には数日で畑全体に広がり葉が枯れます。薬がない条件での対応は三つです。第一に、疎植にして通風を確保します。第二に、排水路を深く掘り、葉が濡れている時間を減らします。第三に、カリウムを確保します。カリウムが不足したソラマメではこの病気が明らかに悪化するため、株の間に草木灰を撒くことが実質的な予防策になります。

### 9-2. 主な害虫

| 害虫 | 被害 | 薬を使わない防除 |
|---|---|---|
| ソラマメアブラムシ（クロマメアブラムシ） | 新芽と花茎に黒いアブラムシが密集して付き、汁を吸ってウイルスを媒介します。ソラマメ最大の害虫 | 摘心が最も効果的です。石けん水（水1Lに石けん5g）を葉の裏に噴きます。テントウムシとクサカゲロウを保護します |
| ハダニ | 葉の裏で汁を吸い、葉が黄色くまだらになります | 乾燥時に増えます。葉に水を強く噴きかけます |
| ソラマメゾウムシ | 畑でさやに卵を産み、貯蔵中に種実を食い荒らします | 完全乾燥後の密閉貯蔵が要です。15節参照 |
| ハモグリバエ類 | 葉の内部に食い入り、白い筋状の跡を残します | 被害葉を摘んで処分します |
| ネズミ | 植えた種子を地中で掘り出して食べます | 播種の深さを守り、草木灰をまぶします |
| 鳥 | 幼い芽をついばんで食べます | 発芽までわらや網で覆います |
| キバノロ・ノロジカ | 冬に食べ物がなく、越冬中のソラマメを食べます | 柵や網。越冬栽培における実質的な脅威です |

&nbsp;&nbsp;&nbsp;越冬栽培では、キバノロによる被害は思った以上に大きくなります。真冬の野原で青々としているのがソラマメ畑だけという状況が生じるためです。畑の周りに網や縄を張り、匂いの強いものを吊るし、人の手が頻繁に入るようにするのが現実的な対応です。この危険を考えると、越冬栽培は家に近い畑に配置する方が安全です。

### 9-3. 薬を使わない防除資材

| 資材 | 作り方 | 対象 | 注意 |
|---|---|---|---|
| 石けん水 | 水1Lに無香料の石けん5g | アブラムシ、ハダニ | 日中の暑い時間に撒くと葉が焼けます |
| ボルドー液 | 水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜます | チョコレート斑点病、さび病 | 銅がないと作れません。混ぜたらすぐに使います |
| 草木灰の散布 | 露のある朝に葉に細かい灰を撒きます | かび抑制、葉の強化 | カリウム供給も兼ね、斑点病に役立ちます |
| 草木灰水 | 灰1升を水10Lに一晩浸し、上澄みを使います | かび抑制 | アルカリ性なので薄めて使います |
| 木酢液 | 炭を焼く時に出る液を300-500倍に希釈します | 忌避、生育促進 | 原液は強酸性なので必ず希釈します |
| 辛い唐辛子・にんにく水 | すりつぶして水に浸し、こして使います | 忌避 | 効果が長続きしないので頻繁に撒きます |
| 牛乳希釈液 | 牛乳を水で5-10倍に希釈します | うどんこ病、ハダニ | 残すと傷んで臭います |

### 9-4. 耕種的防除

| 方法 | 原理 |
|---|---|
| 摘心 | ソラマメ最大の害虫であるアブラムシの生息場所を物理的に取り除きます |
| 輪作 | 2年以上マメ科を空けます。萎凋病と炭疽病が土の中で減少します |
| 疎植 | 体が大きい作物です。密着させて植えるとチョコレート斑点病が爆発的に広がります |
| 排水 | ソラマメの病害の大部分は過湿と関係しています |
| カリウムの確保 | カリウムが不足すると斑点病に対する抵抗力が大きく落ちます |
| 種子選別 | 炭疽病は種子で伝染します。斑点や変色のあるものを取り除きます |
| 雨の後は畑に入らない | 濡れた葉に人が触れると病原菌が付着して広がります |
| 残渣処理 | 病気の残渣は焼くか深く埋めます。健康な残渣だけを畑に戻します |

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然材料での対処 |
|---|---|---|
| 下の葉から全体が薄い黄色になり、個体が小さい | 窒素欠乏。ソラマメでは根粒の不良が最もよくある原因です | まず根を掘って根粒を確認します。根粒がなければ翌年の接種を確実に行い、その年は尿の10倍希釈液を少量与えます |
| 葉の縁が茶色く枯れ、斑点病が重い | カリウム欠乏 | 草木灰を株の間に撒き、軽く土に混ぜ込みます |
| 生育が遅く、葉が紫色を帯びる | リン酸欠乏 | 骨粉、焼いた魚の骨の粉、草木灰 |
| 花が特に多く落ち、さやがほとんど着かない | ホウ素欠乏、または開花期の高温・乾燥 | 複数の材料を混ぜた堆肥。その年は灌水と摘心で対応します |
| 葉脈は緑色だが葉脈の間が黄色い | 鉄またはマンガン欠乏。アルカリに偏った土でよく見られます | 灰の使用をやめます。腐葉土と完熟堆肥で有機物を増やします |
| 新しい葉が小さく奇形で、生長点が枯れる | カルシウムまたはホウ素欠乏 | 焼いた卵の殻の粉、貝殻の粉 |
| 茎と葉だけが茂り、さやが少ない | 窒素過剰 | 窒素の供給を直ちに中止します。摘心で養分を分配し直します |
| 丈が伸びすぎて倒れる | 窒素過剰または密植 | 土寄せと縄での支持。翌年は施肥量を減らします |

&nbsp;&nbsp;&nbsp;ソラマメで窒素欠乏の症状を見たとき、最初にすべきことは肥料を与えることではなく、根を掘ってみることです。ソラマメの窒素供給源は土ではなく根粒です。根粒がよく着いていて、割った内側が赤いのに葉が黄色いなら、窒素以外の問題です。根粒がない、または内側が白いならそれが原因ですが、その場合でも窒素をたっぷり与えることは解決になりません。土の窒素が増えると、残っている根粒までも働きを弱めてしまうからです。

&nbsp;&nbsp;&nbsp;カリウムはソラマメで特に気を配るべき元素です。不足すると葉の縁が枯れる直接的な症状だけでなく、チョコレート斑点病への抵抗力も同時に落ちます。草木灰が最も手軽なカリウム供給源で、畑から出たものを焼いた灰をその畑に戻す循環が最も確実です。ただし灰を入れすぎるとpHが8を超え、鉄とマンガンの吸収が妨げられるため、㎡当たり200gを上限とします。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 作物 | 理由 |
|---|---|---|
| 良い | コムギ・オオムギ | 冬の作期が同じで一緒に育てられます。ソラマメが固定した窒素を穀物が分けて使います |
| 良い | ジャガイモ | ソラマメを先に収穫し、その場所に植えます。病害が重なりません |
| 良い | キャベツ・ハクサイ類 | ソラマメの後に植えると残った窒素を使えます |
| 良い | ほうれん草・サンチュ | ソラマメの条間で育ち、空間を共有します |
| 普通 | トウモロコシ | ソラマメを収穫した後、夏に植えます。同時に育てるのは難しいです |
| 悪い | ニンニク・タマネギ類 | 分泌物が根粒菌を抑制するという報告があります |
| 悪い | 他のマメ科 | 病原菌と線虫が積み重なります |

&nbsp;&nbsp;&nbsp;ソラマメと穀物の冬の間作は、ヨーロッパで長く使われてきた方式です。コムギやオオムギの条間にソラマメを植えると、二つの作物が同じ冬を越し、春に一緒に育ちます。ソラマメが固定した窒素の一部が根を通じて穀物に流れ込み、穀物の直立した茎がソラマメが風で倒れるのを防ぎます。ただしソラマメは40%遮光で収量が半分に落ちるため、穀物の陰に深く入らないよう条間を十分に空ける必要があります。

&nbsp;&nbsp;&nbsp;ソラマメを5-6月に収穫するという事実が、畑の配置において大きな利点を生みます。その場所が夏作物の播種期にちょうど重なるのです。ソラマメを収穫し、茎葉を切って覆った後、その場所にサツマイモやトウモロコシや遅まきダイズを植えれば、一年に二つの作物を収穫することになり、二番目の作物はソラマメが残した窒素をそのまま使えます。

### 11-2. 輪作

| 項目 | 基準 |
|---|---|
| 休作期間 | 2年以上。韓国農村振興庁の2年休作群です |
| 理想的な周期 | 3-4年 |
| 連作障害 | 萎凋病と炭疽病、線虫が積み重なります |

&nbsp;&nbsp;&nbsp;ソラマメの連作適応性Aは、豆類の中では良い方です。エンドウの5-7年、インゲンマメとヒヨコマメの3年より余裕があります。しかし耐えられるということは、続けて植えてもよいという意味ではありません。連作を3年以上続けると萎凋病が蓄積し、開花期に株が萎れて枯れることが多くなります。

| 4年輪作の例 |
|---|
| 1年目：ソラマメ（越冬）の後にサツマイモまたはトウモロコシ（夏） |
| 2年目：ハクサイ・キャベツ類または葉物野菜 |
| 3年目：ジャガイモまたは穀物 |
| 4年目：根菜または緑肥 |
| 再びソラマメ |

&nbsp;&nbsp;&nbsp;畑が狭く輪作の余裕がないときの妥協策を書いておきます。畑を四つの区画に分け、毎年一区画ずつ移しながらソラマメを植える方式が最も簡単です。区画に分けられない小さな畑なら、少なくともソラマメを植える畝の位置を毎年移します。昨年ソラマメを植えた畝に今年はジャガイモを、昨年ジャガイモを植えた畝に今年はソラマメを植えるだけでも、病原菌の蓄積はかなり遅くなります。

## 12. 収穫と脱穀

### 12-1. 収穫時期の判断

| 用途 | 収穫時期 | 判断基準 |
|---|---|---|
| 若芽（ナムル用） | 開花期、摘心の時 | 茎の先端5-10cmの柔らかい部分 |
| 青ソラマメ（野菜用） | 播種後70-90日 | さやがふっくらとして光沢があり、まだ緑色のとき |
| 乾燥種実 | 播種後100-120日 | さやが黒く枯れ、粒が硬くなったとき |

&nbsp;&nbsp;&nbsp;ソラマメのさやは熟すと茶色ではなく黒く変わります。他の豆と異なる点で、初めて栽培する人は病気と誤解しやすいです。下の節のさやから順に黒くなるため、下から上へ順番に収穫します。

&nbsp;&nbsp;&nbsp;青ソラマメの適期を見極めるコツがあります。さやを手で押して粒の輪郭がはっきり触れるものの、さやにまだ弾力がある時です。割ってみて、粒を包む白い綿のような膜が湿っていれば適期で、その膜が乾いて黄ばみ始めていたらもう遅いということです。青ソラマメは皮をむくと薄緑色の実が出てきて、これをゆでたり炒めたりして食べます。

> **雨の予報があれば、完熟を待たずに収穫します。少し熟し切っていないソラマメは干して使えますが、濡れて乾くことを繰り返したさやは裂けて粒を落とし、残った粒にはカビが生えます。**

### 12-2. 収穫のコツ

| 順序 | 内容 |
|---|---|
| 1 | 晴れて乾燥した日、露が乾いた午前10時以降に行います |
| 2 | 青ソラマメはさやをねじって摘みます。引っ張ると茎が傷みます |
| 3 | 乾燥種実は茎の根元を鎌で刈ります。根は畑に残します |
| 4 | 束ねて軒下や納屋に逆さに吊るして乾かします |
| 5 | さやがからからに乾き、振ると音がするようになったら脱穀します |

&nbsp;&nbsp;&nbsp;茎を刈って根を残すことは、災害時の条件では正しい選択です。ソラマメの根は太く、大きな根粒が着いているため、その中に含まれる窒素はヘクタール当たり15-30kgに達します。引き抜けばその窒素は畑から出ていき、残せば腐って次の作物の養分になります。

### 12-3. 脱穀 - 道具を使わない方法

| 方法 | 道具 | 手順 | 効率 |
|---|---|---|---|
| 袋を踏む | 厚い麻袋や袋 | 乾いた茎を袋に入れ、口を縛って足で踏みます | 少量に最も向いています。粒が飛び散りません |
| 唐竿（からさお） | 長い柄にむちを結んだ道具 | むしろを広げ、茎を薄く敷いて上から打ち付けます | 中規模に適しています |
| 棒で叩く | 木の棒 | 袋に入れるか、むしろに広げて叩きます | 唐竿がない時の代わりになります |
| 手でむく | なし | さやを一つずつねじって開きます | 粒が大きいので他の豆よりずっと速いです |
| 足で擦る | なし | むしろに広げ、靴を履いた足で擦り回します | 少量に適しています |

&nbsp;&nbsp;&nbsp;ソラマメは粒が大きいため、手でむくことが他の豆類よりずっと効率的です。乾いたさや一つに二、三粒しか入っておらず、さやが厚く開きやすいので、小規模なら唐竿を使う必要はありません。ただし、さやが厚い分乾燥が足りないと開きにくいので、叩くにしても手でむくにしても、完全に乾いた後に行います。

### 12-4. 精選 - 風での選別

| 方法 | 原理 | 手順 |
|---|---|---|
| 風選（風を起こす） | ソラマメの粒は重く、殻やくずは軽いです | 風が吹く日に、ざるや広い器に入れて高く持ち上げ、ゆっくりと注ぎ落とします |
| 箕（み）でふるう | 上下に振りながら前にあおります | 重い粒が後ろに残り、軽いものが前に押し出されます |
| うちわであおぐ | 一人が注ぎ、もう一人がうちわで風を送ります | 風がない日に使います |
| ふるいにかける | 穴の大きさで分けます | ソラマメは粒が大きいのでふるいで分けるのが特に簡単です |
| 水に浮かせる | しいなや虫食いの粒は軽いです | 水桶に入れ、浮いたものを取り除きます。すくったものは必ず再び乾かします |
| 手で選ぶ | 目で見ます | 粒が大きいので手で選ぶのが最も正確です |

&nbsp;&nbsp;&nbsp;ソラマメは粒が大きいため、精選が豆類の中で最も簡単です。風選を一回行えばほとんどの殻くずが飛び、残ったものは目で見て手で選べば十分です。風選のコツは三つです。風が一定に吹く早朝か夕暮れ時を選び、一度に注がず細く流し落とし、二、三回繰り返します。水に浮かせる方法は精選と選別を同時に行えますが、浸したソラマメはその日のうちに完全に再乾燥させる必要があり、種子用には使いません。
