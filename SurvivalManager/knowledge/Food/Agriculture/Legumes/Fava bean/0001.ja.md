## はじめに
&nbsp;&nbsp;&nbsp;ソラマメ(Vicia faba)は、蚕豆、ファバビーン、ブロードビーンとも呼ばれるマメ科の一年草または二年草で、地中海東部と西南アジアから来ました。最大の特徴は耐寒性Sで、-10℃に耐えて畑で冬を越すマメ科はソラマメだけです。南部で立冬のころに播くと翌年の5月中旬-6月に収穫でき、その年の畑で最初に出てくるタンパク質として、古い穀物が尽きて夏作物が実る前の食料の空白を埋めます。総合等級はA(50.2点、有効183種中15位)で、短期A(48.6)、長期S(51.7)、副食はSS(65.9点)であり、タンパク質密度、施肥、貯蔵性がSSです。面積当たりの熱量はCで1㎡当たり1,023kcal、自給ラインの0.39倍なので主食にはならず、国内での栽培の普及度がBなので、3-4の道(行政区)の外では種子を入手しにくいです。等級表にない危険が一つあります。G6PD欠損体質で急性溶血を起こすファビズムで、調理でなくせないため、栽培を決める前にまず10節を読む必要があります。

| 総合 | A | 50.2 |
| 短期 | A | 48.6 |
| 長期 | S | 51.7 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: タンパク質密度、施肥、施設の負担、貯蔵性。S: 耐寒性、味、自家採種。A: 微量栄養素、水の消費量、温度幅、連作への適応性、合成資材を投入しない場合の収量維持率、収量の安定性、種子の寿命 |
| 弱み | D: 永続性、日射、調理・加工の要求度。C: 面積当たりの熱量、病害虫圧、整地・掘削エネルギー、非食用の価値。B: 収穫速度、防除の自立度、国内での栽培の普及度 |

> **ソラマメの価値は収量ではなく、栽培の時期と土地にあります。何も育たない冬の畑を守り、春に最初に食べ物を出し、あとに来る作物に窒素を残します。**

&nbsp;&nbsp;&nbsp;連作への適応性Aは2年休作群で、エンドウの5-7年より余裕があります。調理・加工Dは、種皮が厚くて8時間浸し1時間ゆでなければならない毎日の費用です。防除の自立度Bは、病害虫の被害がアブラムシ1種に集中していて、それを摘心で抑えられるためです。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | マメ科ソラマメ属。自家受粉が基本だが、ハチによる他家受粉が30-50% |
| 葉、茎 | 羽状複葉で小葉は2-6対、巻きひげがない。茎はまっすぐで断面が四角く、高さ80-120cmなので支柱は必須ではない |
| 根、花 | まっすぐな主根が深く入り、太い根粒が主根の上部に集まってつく。花は白地に黒い斑点のある蝶形で、香りが強くハチがよく訪れる |
| 莢、子実 | 厚くて長く15-30cmで、内側に綿のような白い膜がある。子実は平たく大きく、1粒が2gとマメ類で最も大きく、熟すと茶色ではなく黒く乾く |

&nbsp;&nbsp;&nbsp;花はほとんどが自然に落ちて、莢になるのは10に1つほどで、開花期の水と温度とハチの訪問がその割合を左右します。乾燥した子実100g当たり熱量341kcal、タンパク質26.12g(熱量比30.6%)、脂質1.5-2g、炭水化物約58g、食物繊維約25g、鉄6-7mg、カルシウム約100mg、マグネシウム約190mgで、葉酸がたいへん豊富であり、脂質が少なくて酸化が遅いです。若いさやと新芽にはレボドパ(L-ドパ)が多く、たくさん食べるとめまいや吐き気が出ることがあります。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽5℃以上(最適15-20℃)。生育5-28℃(最適10-20℃)で、25℃を超えると生育が止まる。結実10-24℃。開花期に25℃以上が数日続くと花と若莢が落ちる |
| 耐寒性 | -10℃まで、-15℃以下が続くと枯れる。冬の前に大きく育ちすぎるとかえって凍死するので、本葉3-4枚、高さ10-15cmがもっともよく耐える |
| 水、土壌 | 水はけのよい砂壌土(砂土から粘質土まで適応)、pH5.5-8.0(最適6.0-7.0、5.5を下回ると窒素固定が止まる)、有効土層40cm以上(最適60cm)。1日以上冠水すると根が傷み、根粒が先に機能を失う |

&nbsp;&nbsp;&nbsp;中部内陸では-15℃が何日も続いて越冬がたいてい失敗するので、春まきにします。南部の海岸と済州は越冬栽培が安定しており、その間の地域は年によって分かれるので、秋まきと春まきに分けて植えて危険を分散します。

&nbsp;&nbsp;&nbsp;1粒2g以上の大粒の食用種は収量が多く食用と貯蔵の基本で、1粒0.7-1.5gの小粒の在来種は寒さとやせ地に強く、畑が悪いとき、冬が寒いとき、種子が足りないときに向きます(同じ重さではるかに広く植えられる)。国内には正式に登録された品種が事実上ないため、あらかじめ種子を確保して自家採種で続けていくことが唯一の道であり、最初の2、3年は収量よりも種子を増やすことに集中し、その地域で冬を越した株を選んで続けます。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 畑づくり | 20-30cm以上の深さに耕し、畝は20cm以上、排水溝は深さ30-50cm。完熟堆肥2,000-3,000kg/1,000㎡ |
| 施肥(1,000㎡) | 窒素3-5kg(初期用の最小量で、多いと倒れ、アブラムシが集まり、莢が減る)、リン酸10-15kg、カリウム10-15kg(すべて元肥)、酸性土に石灰150-200kg(播種の3週間前)。代替資源は木灰(㎡当たり100-200g)、骨粉、焼いた貝殻・卵の殻(石灰の代わり) |
| 根粒の接種 | ソラマメ、エンドウ、レンズマメ、オオカラスノエンドウを育てた畑の表土5-15cmの土を、水で軽く湿らせた種子に日陰でまぶし、30分以内に播種(菌は直射日光、乾燥、熱に弱く、消毒とは一緒に行わない)。ダイズの畑の土は菌の種が違うので役に立たない |

&nbsp;&nbsp;&nbsp;開花のころにスコップで土ごとすくって洗い、根粒を割ってみます。主根の上部に20個以上集まって内側が赤ければうまくいっており、5個以下なら失敗で、細根の先にだけ小さくついていれば土着の菌による感染で効率が低いので、翌年は接種源を替えます。

&nbsp;&nbsp;&nbsp;1ヘクタール当たりの固定量は条件がよいと150-200kg(悪いと40-80kg)で、子実で110-140kgが出ていき、茎葉に40-60kgが残ります。茎葉を20-30cmに切って敷き、根は掘り上げず、茎を家畜に食べさせたならふんをその畑に戻してはじめて、土を収奪しません。やせた区画は、子実を諦めて開花期にすき込めば、150-200kgの窒素が残ってよみがえります。

| 播種 | 基準 |
|:---|:---|
| 時期 | 秋まき・越冬栽培は初霜の予想日の40-50日前にあたる立冬のころ(南部で11月上旬、収穫は翌年の5月中旬-6月中旬)。9月に播くと冬の前に大きくなりすぎて凍死し、12月に播くと根づく前に凍った地面に閉じ込められる。春まきは土が解けたらすぐの2月中下旬-3月上旬(収穫は5月下旬-6月下旬)で、3月中旬を過ぎると開花期が暑さにぶつかって収量が大きく落ちる |
| 種子の準備 | 斑点、変色、しわ、虫食いの穴のある種子を捨てる。種皮が厚くて浸種の効果が大きいので24時間浸し(超えると中が軟らかくなって腐る)、50-55℃の湯に10-15分浸して消毒し、細かい木灰をまぶしてネズミと鳥を防ぐ |
| 方法 | 深さ5-7cm(越冬栽培はさらに深く)、1穴1-2粒、条間45-90cm、株間15-30cm(大粒種は広く)、1㎡当たり4-8株。発芽まではわらかネットで覆う |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から発芽 | 土が完全に乾かないように |
| 生育初期 | 自然の降水に任せる(乾燥が根を深く伸ばす) |
| 冬(越冬) | 排水だけを管理(凍って解ける間に水がたまるのがもっとも危険なので、真冬にもときどき水みちを開ける) |
| 開花期から莢肥大期 | 土が乾かないよう十分に与える(落花率を下げるもっとも確かな手段) |
| 成熟期 | 灌水を中止(莢が乾かずカビが生える) |

| 管理 | 方法 |
|:---|:---|
| 摘心 | 下の節で花が咲き始め、上にまだつぼみが残っているときに、茎の先5-10cmを手で摘む。養分がすでに咲いた花と莢に集まって収量が増え、最も若い成長点に集まったアブラムシが除かれ、摘んだ芽はゆでてナムルにして食べる。早すぎると花がつく節が減り、遅すぎるとアブラムシがすでに下へ広がっている。やせて生育が悪い株(ひざの高さで止まり葉の色が薄い)には行わない |
| 間引き、草取り | 間引きは本葉2-3枚で混みすぎた所だけ、4-5枚で健全な株だけを残す。草取りは播種後3-4週に浅く削り、開花前に土寄せと兼ねてもう一度行う |
| 土寄せ、倒伏 | 高さ30cmごろに株元に土を寄せると支えになり、埋まった茎から新しい根が出て、溝が深くなって水が抜ける。倒伏の原因は窒素過多と密植で、風の強い場所は畑の周りに杭を打って腰の高さに綱を張る |
| 霜柱、獣 | 冬に浮き上がった株は足で踏んで押さえ、わらや落ち葉を5-10cm覆う。真冬の野にソラマメだけが緑だとキバノロが来るので、柵やネットで囲い、家に近い畑に置く |

## 6. 病害虫と養分の問題
| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| チョコレート斑点病 | 葉に赤褐色の小さな丸い斑点ができて大きくなり、葉が枯れて死ぬ。多湿で涼しいときに広がる、ソラマメ最大の病害 | まばらに植えて風通しを確保し、排水溝を深く掘る。カリウムが不足すると悪化するので木灰を与える |
| さび病、炭疽病 | 葉にオレンジ色の粉の塊(生育後期の多湿) / 茎と莢に黒い潰瘍(種子で伝染) | 病葉の除去、風通しの確保、早めの収穫 / 種子の選別と輪作 |
| 萎凋病・根腐病、ウイルス病 | 下の葉からしおれて根が茶色く腐る(過湿、連作) / 葉がモザイク状にまだらになって縮れる(アブラムシが媒介) | 2年以上の輪作、排水、畝を高くする / 治療できないので抜いて焼き、アブラムシを減らす |
| ソラマメのアブラムシ | 新芽と花茎に黒いアブラムシがびっしりつき、汁を吸ってウイルスを媒介する最大の害虫 | 摘心がもっとも効果的。石けん水(水1Lに石けん5g)を葉の裏にまき、テントウムシとクサカゲロウを守る |
| ソラマメゾウムシ | 畑で莢に卵を産み、貯蔵中に子実を食い荒らす | 完全に乾かして密閉(9節参照) |

&nbsp;&nbsp;&nbsp;ボルドー液は水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜ、すぐに使い、チョコレート斑点病とさび病に使います。露のある朝に葉にまく細かい灰はカビを抑え、カリウムも兼ねます。濡れた葉に触れると病原菌が移るので、雨のあとは畑に入らず、病気の残渣は焼くか深く埋め、健全な残渣だけを戻します。

| 症状 | 原因と対処 |
|:---|:---|
| 下の葉から全体が薄い黄色で株が小さい | 窒素欠乏(根粒不良がもっとも多い)。肥料よりも先に根を掘って根粒を確認し、なければ翌年の接種を確実にし、その年は尿の10倍希釈液を少量与える |
| 葉の縁が茶色く枯れ、斑点病がひどい | カリウム欠乏。木灰を株の間にまいて軽くかき入れるが、㎡当たり200gが上限(超えると鉄とマンガンの吸収が妨げられる) |
| 花がたくさん落ちて莢がほとんどつかない | ホウ素欠乏、または開花期の高温・乾燥。複数の材料を混ぜた堆肥、その年は灌水と摘心 |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | コムギ、オオムギ(冬の作期が同じで、ソラマメの窒素を穀物が分け合って使い、まっすぐな茎が倒伏を防ぐが、日陰に入ると収量が落ちるので条を広めに取る)、ジャガイモ(ソラマメを収穫した跡に植える)、キャベツ・ハクサイ(残った窒素を使う) |

&nbsp;&nbsp;&nbsp;ソラマメを5-6月に収穫すると、その場所が夏作物の播種期とちょうどつながり、茎葉を切って敷いたあとにサツマイモ、トウモロコシ、遅まきのダイズを植えれば、1年に2作を収穫でき、2作目は残った窒素を使います。休作は2年以上で、連作を3年以上続けると萎凋病と炭疽病、センチュウがたまります。輪作の例は、1年目はソラマメ(越冬)のあとにサツマイモかトウモロコシ(夏) → 2年目はハクサイ・キャベツの仲間か葉菜類 → 3年目はジャガイモか穀物 → またソラマメです。畑が狭ければ4区画に分けて毎年1区画ずつ移すか、せめて条の位置を毎年替えます。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 青ソラマメは播種後70-90日に、莢がふっくらして光沢があり、まだ緑で、中の白い膜がしっとりしているとき。乾燥した子実は播種後100-120日に、莢が黒く乾いて粒が堅くなったとき |
| 要領 | 青ソラマメは莢をひねって摘む(引っぱると茎が傷む)。乾燥した子実は下の節の莢から黒くなるので下から上へ収穫し、茎の根元を鎌で刈って根は畑に残す。束にして軒下や納屋に逆さに吊るして乾かす。雨の知らせがあれば完熟を待たずに収穫する(濡れて乾くことを繰り返した莢ははじけて粒を落とす) |
| 脱穀、選別 | 莢が完全に乾いたあと、からざおで打つか手でむく(粒が大きいので手でむくほうが効率的)。風のある日にゆっくり流し落として殻を飛ばし、ふるいで選り分け、水に浮かべて浮くものを取り除いたあと、その日のうちにまた乾かす(種子用は除く) |

| 採種 | 基準 |
|:---|:---|
| 選抜、収穫 | 病気の症状がなく、莢が多くつき、冬をよく越した株を畑であらかじめ印をつける。莢が完全に黒く乾いたあと、食用より遅く収穫して別に脱穀し、手でむく |
| 隔離 | ハチによる他家受粉が30-50%なので、ほかの品種と数百m離すか、1年に1品種だけ育てる |
| 選別、乾燥 | 斑点、しわ、変色、小さい粒を捨て、大きくて艶のある粒だけを残す。水分12%で、かんでも歯が入らずぱきっと割れる。常温で密閉して種子の寿命は3年 |

## 9. 貯蔵
| 段階 | 方法 |
|:---|:---|
| 乾燥 | 茎ごと軒下に逆さに吊るして3、4日、脱穀後は薄く広げて日に3-5日(粒が大きくダイズより長くかかるので、よく返す)。水分12%で、外側だけが乾きやすいので、半分に割って中まで確認する |
| ソラマメゾウムシの防除 | 畑ですでに卵がついて入ってくるので、半年で袋一つが穴だらけの殻になる。完全密閉がもっとも重要で(酸素がなくなって虫が死ぬ)、容器をいっぱいに満たして空間を減らし、大きな容器一つより小さな容器を何個も使う。ふるった木灰を体積の2-5%混ぜ(食べる前に洗う)、珪藻土は1kg当たり1-3g(乾いた状態でのみ)、油のコーティングは1kg当たり食用油2-5mL(種子用は除く) |
| 容器、点検 | ガラス瓶と金属缶は3年以上、かめと地下貯蔵穴は2-3年、厚いビニールは1-2年(ネズミがかじり破る)。容器に耳を当ててかさかさ音がすれば虫、かび臭いにおいはカビ、表面の小さな丸い穴はゾウムシが一世代を越えたしるし。2か月に1回点検 |

## 10. 調理と注意事項
> **G6PD酵素が欠けている人がソラマメを食べると、赤血球が急激に壊れる急性溶血が起こります。これをファビズム(favism)といいます。子どもには命にかかわることがあり、ソラマメの花粉を吸い込んだだけで発作が起きた例も報告されています。**

| ファビズム | 内容 |
|:---|:---|
| 原因 | ソラマメのビシンとコンビシンが腸で強い酸化物質(ジビシン、イソウラミル)になり、G6PDが不足した赤血球を数時間で大量に壊す |
| 対象 | G6PD欠損症(X染色体の遺伝で男性にやや多く、地中海沿岸、中東、アフリカ、東南アジアの血筋に多い)。子どもがもっとも危険 |
| 症状 | 数時間後に悪寒、発熱、頭痛、腹と背中の痛み → 尿が濃い茶色かコーラ色 → 黄疸、ひどい青白さ、息切れ → 重症では立てず、意識がもうろうとし、尿がほとんど出ない |
| 除去 | ゆでても焼いても発酵させても危険はなくならない(皮をむくことと浸すことは一部しか減らさない) |

&nbsp;&nbsp;&nbsp;災害時にG6PD欠損を調べる方法はないので、少量での試食が唯一の安全装置です。新しく加わった人、子ども、ソラマメを食べたことのない人には例外なく5、6粒(子どもは2、3粒)だけ食べさせ、1、2日様子を見ます。尿が濃い茶色かコーラ色になったらすぐにやめ、安静にさせ、二度と食べさせません。家族の中にソラマメや特定の薬を口にして黄疸や貧血が出た人がいる場合や欠損者がいる場合は、ソラマメの代わりにエンドウかササゲを育て、欠損者は開花期に畑の近くに行かないようにします。

| 成分 | 働き | 取り除く方法 |
|:---|:---|:---|
| トリプシンインヒビター、レクチン | タンパク質分解酵素を妨げ、腸の粘膜に付着して吸収を妨げる | 8時間浸したあと、沸騰した湯で1時間加熱 |
| フィチン酸、オリゴ糖、カビ毒素 | 鉄、亜鉛、カルシウムの吸収を妨げる / 腸内発酵でガスがたまる / 貯蔵中にカビがつくる | 浸漬、発芽、発酵で60-80%減る / 浸し水を捨てる / カビが生えたものは洗っても加熱しても安全にならないので捨てる |

| 処理 | 基準 |
|:---|:---|
| 浸漬、皮むき、ゆで | 常温の水に8時間以上(大粒は12時間)浸し、浸し水は必ず捨てる。浸した粒を指で押すと皮がむけ、調理時間がほぼ半分になって消化しやすくなる。沸騰した湯で1時間(皮をむくと30-40分)ゆで、簡単につぶれれば煮えた状態 |
| 燃料の節約 | 圧力調理は浸した豆を15分加圧。余熱調理は15分煮たあと火を消し、わらやもみ殻の箱か布団で鍋を包んで2-3時間置く。炒りソラマメは浸して乾かしたものを油なしで炒り、そのまま食べる |
| 青ソラマメ、芽 | 青ソラマメは皮をむいて数分ゆでる。芽はゆでてナムルにするか、塩漬けにするか、ゆでて干して冬に使う |
| 貯蔵用の加工 | ソラマメの粉(密閉で3-6か月)、若芽の塩漬け(数か月)、ゆでて干した青ソラマメ(数か月)、ゆでてつぶし発酵させたソラマメのみそ(ダイズが足りないときの代替だが、発酵してもビシンとコンビシンはなくならない) |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵の点検、越冬畑の見回りと霜柱で浮いた株の踏み込み。2月中下旬に春まき、畑の計画、石灰の散布 |
| 3-4月 | 3月に越冬株の土寄せ、草取り、排水溝の点検。4月に開花開始、摘心、アブラムシの管理、根粒の確認 |
| 5-6月 | 5月に莢肥大、灌水に集中、越冬分の青ソラマメの収穫。6月に越冬分の乾燥子実の収穫、春まき分の青ソラマメの収穫、吊るして乾燥 |
| 7-8月 | 7月に脱穀、選別、乾燥、貯蔵、茎葉を戻す。8月に後作の管理、貯蔵の点検 |
| 9-10月 | 9月に秋の畑の準備、石灰の散布(播種の3週間前)、堆肥の施用。10月に畝づくり、排水溝掘り、種子の選別 |
| 11-12月 | 11月に秋まき。12月にわら・落ち葉でのおおい、獣よけ、貯蔵の点検 |

> **ソラマメは、ファビズムを少量の試食であらかじめ確かめ、播種日を初霜の40-50日前に合わせ、排水を整え、開花期に摘心し、茎と葉と根を畑に戻せば、冬の畑から春にいちばん早くタンパク質を出してくれる作物です。**
