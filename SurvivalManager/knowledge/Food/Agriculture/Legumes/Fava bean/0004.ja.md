## 5. 畑の準備と肥料 - 窒素バランスと施肥

### 5-4. 窒素固定の落とし穴

&nbsp;&nbsp;&nbsp;豆を植えると土が良くなるという言葉は、農業の常識として定着しています。半分は正しく、半分は間違っています。この点を正確に理解していないと、マメ科を数年続けて植えた畑がむしろやせていくという事態が起こります。

&nbsp;&nbsp;&nbsp;数字で見てみましょう。ソラマメがよく育つと、1,000㎡から300kgの乾燥種実を収穫できます。ソラマメの種実のタンパク質は26.1%で、タンパク質を6.25で割ると窒素量が出ます。26.1 ÷ 6.25は4.18、つまり種実の重さの約4.2%が純粋な窒素です。300kgに含まれる窒素は約12.5kgで、ヘクタールに換算すると125kgになります。

&nbsp;&nbsp;&nbsp;一方、ソラマメの根粒が固定する窒素は、条件が良ければヘクタール当たり150-200kgです。マメ科の中でも最も高い水準で、ソラマメが施肥でSS評価を受けた根拠です。条件が悪いと50kgにとどまります。出ていく量と入ってくる量を並べると次のようになります。

| 項目 | ヘクタール当たり窒素 | 方向 |
|---|---|---|
| 根粒固定量（条件良好） | 150-200kg | 入る |
| 根粒固定量（条件不良） | 40-80kg | 入る |
| 種実として持ち出し | 110-140kg | 出る |
| 茎葉（茎と葉）に残る窒素 | 40-60kg | 畑に戻せば残る、燃やすか持ち出せば出る |
| 根と根粒に残る窒素 | 15-30kg | 大抵は畑に残ります |

&nbsp;&nbsp;&nbsp;表を見れば、ソラマメがなぜ緑肥作物として使われるのかが分かります。固定量が持ち出し量より明らかに多いため、茎葉だけ畑に戻しても窒素が畑に残ります。豆類の中でこの余裕を持つ作物は多くありません。しかし条件が悪いと事情が変わります。接種に失敗して固定量が40kgにとどまった畑で種実130kgを持ち出し、茎まで刈り取ってしまえば、窒素バランスは確実にマイナスになります。

> **マメ科が土を肥やすのは、窒素を固定するからではなく、固定した窒素の一部を茎と葉に蓄えて畑に残しておくからです。その茎と葉を持ち出してしまえば、豆は土を奪う作物になります。**

&nbsp;&nbsp;&nbsp;ソラマメには、この計算を逆転させる選択肢がもう一つあります。種実をあきらめ、開花期に丸ごと畑にすき込む方法です。この場合は持ち出しが0になり、固定した窒素の全量が畑に残ります。ヘクタール当たり150-200kgの窒素は、化学肥料が消えた世界で他のどんな方法でも作れない量です。畑全体をそのように使うのは惜しいですが、何年も続けて作付けしたせいで目に見えてやせてきた区画を一つ、ソラマメで立て直す戦略は十分に合理的です。

| 原則 | 内容 |
|---|---|
| 茎葉は必ず畑へ | 脱穀後に残った茎と葉、さやの殻を全部畑に戻します |
| 燃やさない | 燃やすと窒素が気体になって飛び、カリウムとリン酸だけが灰に残ります |
| 根は掘り出さない | ソラマメの太い根と根粒には窒素がかなりの量含まれています |
| 20-30cmに切って覆う | ソラマメの茎は太く水分が多いため、切って覆うと早く分解します |
| 緑肥として使う場合 | 開花期にすき込むとヘクタール当たり150-200kgの窒素が畑に残ります |
| 家畜に食べさせたら糞を戻す | ソラマメの茎を食べさせたら、その家畜の糞尿を必ずその畑に入れます |

### 5-5. 畑の準備

| 項目 | 方法 | 災害時の条件では |
|---|---|---|
| 耕うん | 20-30cmの深さで耕し、平らに整地します | スコップで返すか、くわで掘り起こします。根が深く入るので深く耕うんする方がよいです |
| 畝 | 高さ20cm以上 | 湿害防止の要です |
| 排水路 | 深さ30-50cm | 越冬栽培では冬の排水が特に重要です |
| 酸度調整 | pH 6.0-7.0 | 播種3週間前に済ませておきます |
| 有機物 | 完熟堆肥2,000-3,000kg/1,000㎡ | ソラマメは豆類の中でも有機物要求量が高い方です |
| 石灰 | 酸性土に150-200kg/1,000㎡ | 貝殻・卵の殻を焼いて砕いたもの、または草木灰で代用します |

&nbsp;&nbsp;&nbsp;石灰を前もって入れておく理由は、反応に時間がかかるからです。播種直前に入れると、その場所だけアルカリが強くなって種子や若い根を傷め、しかも本当に必要な時期には反応がまだ十分進んでいません。また、石灰と窒素肥料を同じ場所に一緒に入れると、アンモニアが気体になって飛び、窒素を失います。石灰を先に、肥料はその2週間後という順序を守ります。石灰がなければ、貝殻と卵の殻を火で焼いて崩れやすくしたうえで、すり鉢で砕いて使います。

### 5-6. 施肥量

| 肥料 | 1,000㎡当たり | ㎡換算 | 備考 |
|---|---|---|---|
| 窒素 | 3-5kg | 3-5g | 最小限だけ入れます。根粒が働き出す前の初期用です |
| リン酸 | 10-15kg | 10-15g | 全量を元肥にします。窒素固定のエネルギー代謝に必要です |
| カリウム | 10-15kg | 10-15g | 全量を元肥にします。種実の肥大と茎の強度に関わります |
| 堆肥 | 2,000-3,000kg | 2-3kg | 完全に熟成したものを使います |
| 石灰 | 150-200kg（酸性土） | 150-200g | 播種3週間前 |

> **ソラマメで窒素を控えるのは節約ではなく技術です。多く与えると茎と葉だけが茂って倒れ、アブラムシが群がり、さやはむしろ減ります。**

&nbsp;&nbsp;&nbsp;堆肥2,000-3,000kgは、ダイズの1,000kgと比べると多い量です。ソラマメが多肥性作物と呼ばれる理由ですが、ここで言う肥料は窒素ではなく有機物です。ソラマメは根が太く深く入り、体も大きいため、水と養分を蓄える土の構造を必要とします。完熟堆肥をたっぷり入れると土がふかふかになり、太い根が伸びやすくなって水持ちも良くなります。窒素そのものは依然として最小限で十分です。

&nbsp;&nbsp;&nbsp;追肥は原則として必要ありません。ただし、開花期前後に葉全体が薄い黄色を帯び、生育が明らかに不振であれば、根粒がうまく働いていないという信号です。このときだけ少量を補います。災害時には、尿を水で10倍に薄めて株の間の土に注ぐのが最も手軽な代替策です。葉にかからないようにし、一度に多く与えるより薄めて何回かに分けて与えます。

### 5-7. 災害時の代替肥料

| 代替資源 | 供給される養分 | 使用法 | 注意 |
|---|---|---|---|
| 草木灰 | カリウム、リン酸、カルシウム | ㎡当たり100-200gを撒いて混ぜます | アルカリ性です。ソラマメはpH8.0まで耐えるので余裕があります |
| 完熟堆肥 | 総合、有機物 | ㎡当たり2-3kgを元肥として入れます | ソラマメにおいて最も重要な資源です |
| 薄めた尿 | 窒素、カリウム | 水で10倍に薄めて株の間の土に注ぎます | 葉にかからないようにします。少量だけ |
| 骨粉 | リン酸、カルシウム | 焼いて砕き、堆肥に混ぜます | 効果はゆっくり現れます |
| 魚の骨・魚の内臓 | リン酸、窒素 | 埋めて発酵させてから使います | そのまま埋めると動物が掘り出します |
| 貝殻・卵の殻 | カルシウム | 焼いて砕いて撒きます | 石灰の代わりです。反応が遅いです |
| 落ち葉の腐葉土 | 総合、有機物 | 土に混ぜ込みます | 水持ちを良くします |
| 籾殻・稲わら | カリウム、ケイ酸 | マルチとして覆い、翌年すき込みます | 越冬栽培の防寒マルチも兼ねます |

&nbsp;&nbsp;&nbsp;ホウ素についても覚えておく価値があります。ソラマメはホウ素を要求し、不足すると花が落ち、さやが着きません。ソラマメはもともと落花率が高い作物なので、ホウ素欠乏が重なると収量が大きく崩れます。化学的なホウ砂がないときは、野菜の残りや果物の皮、落ち葉を一緒に入れた堆肥が最も現実的な代替策です。一種類の材料だけで作った堆肥は微量元素が偏ります。

## 6. 播種

### 6-1. 播種時期

| 作型 | 播種時期 | 収穫時期 | 適用地域 |
|---|---|---|---|
| 秋・越冬栽培 | 立冬前後、11月上旬 | 翌年5月中旬-6月中旬 | 韓国南部沿岸、済州島 |
| 春栽培 | 2月中下旬-3月上旬 | 5月下旬-6月下旬 | 韓国中部・北部 |
| 緑肥栽培 | 秋または早春 | 開花期にすき込み | 韓国全土 |

&nbsp;&nbsp;&nbsp;越冬栽培の播種時期の計算には原則があります。冬が来る前に本葉三、四枚、丈10-15cmの状態になっていることが最も耐寒性が高くなります。それより大きいと凍死し、小さいと根を張れません。初霜の予想日から40-50日を逆算すると播種日が出ます。韓国南部で立冬前後の11月初旬が基準になるのは、この計算の結果です。

> **ソラマメの越冬の成否は、植える日にかかっています。早く植えて大きく育ったソラマメの方が、遅く植えた小さなソラマメより先に枯れます。**

&nbsp;&nbsp;&nbsp;春栽培は2月中下旬が適期です。土が緩んだらすぐに植えるのが原則で、3月中旬を過ぎると開花期が暑さに巻き込まれ、収量が大きく落ちます。ソラマメの春播きの失敗は、大抵遅く植えたことによって起こります。霜を恐れて先延ばしにしている間に暑さが近づき、25℃を超える日が続くと花がそのまま落ちてしまいます。ソラマメは零下10℃に耐える作物なので、2月の霜を心配する理由はありません。

### 6-2. 種子の準備

| 項目 | 方法 | 災害時の条件では |
|---|---|---|
| 選別 | 斑点、変色、しわ、虫食い穴のある種子を捨てます | 手で一粒ずつ選びます。粒が大きいので選びやすいです |
| 大きさ選別 | 大きくて重い粒を選んで使います | 水に浮かせて浮いたものを取り除きます |
| 浸種 | 1日程度水に浸けます | 種皮が厚く浸種の効果が大きいです。24時間を超えないようにします |
| 温湯消毒 | 50-55℃の水に10-15分浸けます | 温度を超えると発芽力が落ちます |
| 灰処理 | 細かい草木灰をまぶします | 消毒と乾燥を助け、鳥やネズミの忌避効果があります |
| 根粒接種 | 同じ菌系統のマメ科を育てた畑の土をまぶします | 5-3節参照。消毒と同時には行いません |
| 発芽試験 | 濡れた布に20粒を包んで数日置き、芽が出た数を数えます | 古い種子は必ず先に確認します |

&nbsp;&nbsp;&nbsp;ソラマメは種皮が厚く粒が大きいため、浸種の効果が他の豆類より大きいです。水に1日浸けると粒が目に見えて膨らみ、発芽が数日早まります。ただし24時間を超えると酸素が不足して内部が軟らかくなり、土の中で腐ります。夕方に浸けて翌日の夕方に植えるリズムが適当です。水は種子の体積の3倍以上をたっぷり用意し、途中で一度入れ替えます。

### 6-3. 播種方法

| 項目 | 基準 | 理由 |
|---|---|---|
| 播種深さ | 5-7cm | 粒が大きいので他の豆より深く植えます。越冬栽培はさらに深く |
| 一穴当たり粒数 | 1-2粒 | 粒が大きく発芽率が高いです |
| 条間 | 45-90cm | 通風と管理用の通路を確保します |
| 株間 | 15-30cm | 大粒種は広く、小粒種は密に |
| 面積当たり株数 | 1㎡当たり4-8株 | 体が大きいので他の豆類より疎植です |
| 植える向き | 種の目（へそ）を下に向けて斜めに | 根がすぐ下に伸びます |

&nbsp;&nbsp;&nbsp;ソラマメの種子には、一方の端に黒または白い帯状の跡があります。これが種の目（へそ）の側で、ここから根が出ます。この跡が下を向くように斜めに寝かせて植えると、根が方向を探すのに苦労せず、出芽が一、二日早まります。粒が大きく向きを合わせやすいソラマメだからこそ実用的なコツです。

&nbsp;&nbsp;&nbsp;播種直後の最大の脅威はネズミと鳥です。ソラマメの種子は大きくデンプンが多いため、ネズミが地中で正確に探し出します。越冬栽培では冬の間ずっとさらされるため、被害がさらに大きくなります。播種の深さを守り、細かい草木灰を種子にまぶすと、かなり減らせます。発芽するまでわらや網をかぶせておくのも効果があり、越冬栽培ではそのわらが防寒の役割も兼ねます。

## 7. 水管理

| 時期 | 水管理 | 理由 |
|---|---|---|
| 播種から発芽 | 土がひどく乾かないようにします | 粒が大きく吸収すべき水の量も多いです |
| 生育初期 | 自然降水に任せます | この時期の乾燥はむしろ根を深く伸ばします |
| 冬（越冬作型） | 排水だけ管理します | 凍結と解凍を繰り返して水がたまるのが最も危険です |
| 開花期からさや肥大期 | 土が乾かないよう十分に与えます | 落花率を下げる最も確実な手段です |
| 成熟期 | 灌水を中止します | さやが乾かず、カビが生えます |

&nbsp;&nbsp;&nbsp;ソラマメの水管理は排水が先で、灌水は後です。太い根が水に浸かるとすぐに腐り、根粒菌も酸素がなければ死にます。特に越冬栽培では、冬の間に土が凍結と解凍を繰り返して排水路が崩れることが多いため、真冬でも時々畑を見回って水の通り道を確保する必要があります。

| 症状 | 原因 | 対応 |
|---|---|---|
| 日中に葉がしおれ、夕方に回復する | 一時的な水分不足。正常な範囲です | そのままにします |
| 朝になっても葉がしおれている | 根が水を吸い上げられていません | 水を十分に与えます |
| 花が大量に落ちる | ソラマメはもともと落花率が高いです。乾燥と高温が重なるとさらに悪化します | 灌水とマルチング。摘心で養分を集中させます |
| さやは着いたが粒が小さい | さや肥大期の水不足 | この時期の灌水が収量を直接左右します |
| 下の葉が黄色くなり根が黒い | 過湿による根の損傷 | 排水路を整備し、土を盛ります |
| 葉全体が薄い黄色だが萎れてはいない | 根粒が働かず窒素不足 | 根を掘って根粒を確認します |
| 冬に株が浮き上がり根が露出する | 霜柱で土が浮き上がったものです | 土を踏んで押さえ、わらをかぶせます |

&nbsp;&nbsp;&nbsp;霜柱による被害は、越冬栽培でのみ現れる問題です。地中の水が凍って体積が増え、土を押し上げ、その過程で幼いソラマメが根こそぎ持ち上げられます。露出した根は乾いたり凍死したりします。冬の間、時々畑を見回って浮き上がった株を足で踏んで押さえ、わらや落ち葉で5cm-10cmを覆っておくと、この被害は大きく減ります。このマルチは春に取り除かずそのままにしておくと、雑草を防ぎ水分を保つ役割を続けて果たします。
