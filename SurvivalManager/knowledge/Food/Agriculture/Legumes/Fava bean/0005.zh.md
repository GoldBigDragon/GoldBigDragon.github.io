## 8. 栽培管理 - 摘心

### 8-1. 为什么摘心不可或缺

&nbsp;&nbsp;&nbsp;如果要在蚕豆栽培中选出效率最高的一项作业，那就是摘心。当下部节位的花开始开放时，用手把茎顶端柔软的嫩芽摘掉。这一个动作能同时完成三件事。

| 效果 | 原理 |
|---|---|
| 增加产量 | 向上生长停止，养分集中输送到已开的花和豆荚。蚕豆落花率高，这一效果尤为显著 |
| 防治蚜虫 | 蚕豆蚜聚集在最幼嫩的生长点上，仅靠摘除嫩芽就能清除相当一部分蚜虫种群 |
| 获得蔬菜 | 摘下的嫩芽焯水后可作凉拌菜食用，是春季新鲜叶菜稀缺时的额外收获 |

> **在没有药剂的条件下，能靠一次操作同时获得防治、收获与增产三种效果的情况十分罕见。蚕豆的摘心正是这种罕见的例子，也是评价表中防治自立度被评为B的依据。**

&nbsp;&nbsp;&nbsp;时机很重要。下部节位已经开花，上部还留有花蕾时是最佳时机。摘得太早会减少能开花结荚的节位本身，摘得太晚则蚜虫已经蔓延到下部。用手摘掉约5-10cm即可，不需要工具。摘下的嫩芽可以立即焯水食用，量多时可以焯水晒干储存，留到冬天使用。

&nbsp;&nbsp;&nbsp;不过，摘心并非在所有情况下都有益。如果田地贫瘠，蚕豆本身生长已经不良，摘心后没有恢复的力气，反而会降低产量。巡视田地时，若植株已长到腰部高度且叶色浓绿，就摘心；若只长到膝盖高度且叶色偏浅，则保持原样。

### 8-2. 间苗与除草

| 作业 | 时期 | 方法 |
|---|---|---|
| 第一次间苗 | 本叶2-3片时 | 只疏理过密的地方 |
| 第二次间苗 | 本叶4-5片时 | 只留下健壮的个体 |
| 第一次除草 | 播种后3-4周 | 浅浅地锄松表土，避免伤根 |
| 第二次除草 | 开花前 | 与培土同时进行 |
| 培土 | 株高约30cm时 | 在根部堆土以防止倒伏 |

&nbsp;&nbsp;&nbsp;培土对蚕豆而言价值很大。蚕豆能长到120cm高，豆荚又重，容易被风吹倒，而在根部堆土能起到支撑作用，被埋住的茎部还会长出新根。同时株间的沟会变深，有利于排水，也能把幼小的杂草埋入土中。在越冬栽培中，若在春季重新生长时进行一次培土，还能同时把因霜柱而隆起的植株压实。

### 8-3. 倒伏管理

| 原因 | 应对 |
|---|---|
| 氮肥过多 | 遵守施肥量，这是根本对策 |
| 密植 | 遵守栽植距离，蚕豆株型大，应稀植 |
| 未进行培土 | 株高约30cm时务必进行培土 |
| 风大的地方 | 在田地四周打桩，齐腰高处围绳固定 |
| 豆荚的重量 | 从下部豆荚开始随熟随摘可以减轻重量 |

&nbsp;&nbsp;&nbsp;蚕豆不是藤蔓作物，而是直立生长的作物，因此不需要像豌豆那样搭支架或挂网。通常只需在田地四周打桩，在齐腰高处围一两圈绳子就已足够，无风的地方甚至连这一步都不需要。在竹竿和绳子稀缺的条件下，这是蚕豆相比豌豆的明显优势。

## 9. 病虫害

&nbsp;&nbsp;&nbsp;蚕豆的病虫害压力为C。无防治减产率估计为48.9%，采用的是豆科整体的平均值。但蚕豆的实际受害大部分集中在蚜虫这一种害虫上，而这种蚜虫可以通过摘心在很大程度上加以控制，这正是防治自立度被评为B的依据。

### 9-1. 主要病害

| 病名 | 症状 | 发生条件 | 无药剂应对方法 |
|---|---|---|---|
| 巧克力斑病 | 叶片上出现红褐色的小圆斑，病情加重后斑点扩大，叶片枯死 | 多湿而凉爽时。是蚕豆最主要的病害 | 保证通风、排水、栽植距离。缺钾会加重病情，因此需施草木灰 |
| 锈病 | 叶片上出现橙色粉状颗粒 | 生长后期多湿 | 摘除病叶，保证通风，提早收获以避开 |
| 炭疽病 | 茎和豆荚上出现黑色溃疡状病斑 | 真菌引起，多湿环境 | 种子挑选与轮作是关键 |
| 枯萎病·根腐病 | 从下部叶片开始萎蔫，根变褐腐烂 | 过湿、连作 | 轮作2年以上，注意排水，抬高垄面 |
| 病毒病 | 叶片出现花叶斑纹并卷缩 | 由蚜虫传播 | 无法治疗，需拔除烧毁并减少蚜虫 |
| 菌核病 | 茎变软，出现白色棉絮状菌丝 | 凉爽潮湿的条件 | 病株连土一起挖出烧毁 |

&nbsp;&nbsp;&nbsp;巧克力斑病是蚕豆最常见、也最严重的病害。正如其名，叶片上会出现巧克力色的斑点，潮湿的年份里能在几天内蔓延到整块田地，导致叶片枯死。在没有药剂的条件下，应对方法有三点。第一，稀植以保证通风。第二，深挖排水沟，缩短叶片潮湿的时间。第三，补充钾肥。缺钾的蚕豆这种病会明显加重，因此在株间撒施草木灰是切实可行的预防措施。

### 9-2. 主要害虫

| 害虫 | 危害 | 无药剂防治方法 |
|---|---|---|
| 蚕豆蚜（黑豆蚜） | 黑色蚜虫密集附着在新芽和花梗上吸食汁液并传播病毒，是蚕豆最主要的害虫 | 摘心是最有效的方法。可在叶背喷洒肥皂水（1L水加5g肥皂）。要保护瓢虫和草蛉 |
| 螨虫 | 在叶背吸食汁液，使叶片出现黄色斑纹 | 干燥时会增多，可用水猛力喷洒叶片 |
| 蚕豆象 | 在田间于豆荚上产卵，贮藏期间蛀食籽粒 | 关键是彻底晒干后密闭贮藏，参见第15节 |
| 潜叶蝇类 | 钻入叶片内部蛀食，留下白色条状痕迹 | 摘除受害叶片并清除 |
| 老鼠 | 在地下刨食播下的种子 | 保证播种深度并拌上草木灰 |
| 鸟类 | 啄食幼嫩的芽 | 发芽前用稻草或网覆盖 |
| 獐（河麂）·狍子 | 冬季缺乏食物，会啃食越冬中的蚕豆 | 需设围栏或网，是越冬栽培中实际存在的威胁 |

&nbsp;&nbsp;&nbsp;在越冬栽培中，獐（河麂）造成的损失比想象中更大，因为寒冬的田野上往往只有蚕豆田还是绿色的。现实可行的应对办法是在田地四周围上网或绳子，悬挂有气味的物品，并让人经常出入走动。考虑到这一风险，越冬栽培的田地最好安排在靠近住处的地方。

### 9-3. 无药剂防治材料

| 材料 | 制作方法 | 对象 | 注意 |
|---|---|---|---|
| 肥皂水 | 1L水中加入5g无香型肥皂 | 蚜虫、螨虫 | 在正午高温时喷洒会使叶片灼伤 |
| 波尔多液 | 在100L水中分别溶解400g硫酸铜和400g生石灰后混合 | 巧克力斑病、锈病 | 需要有铜才能配制，混合后须立即使用 |
| 撒草木灰 | 在有露水的早晨把细草木灰撒在叶片上 | 抑制真菌、增强叶片 | 兼具补钾作用，有助于防治斑病 |
| 草木灰水 | 将1升（约1.8升）草木灰浸入10L水中一夜，取上层清液使用 | 抑制真菌 | 呈碱性，需稀释使用 |
| 木醋液 | 将烧炭时产生的液体稀释300-500倍 | 驱避、促进生长 | 原液呈强酸性，务必稀释后使用 |
| 辣椒·大蒜水 | 捣碎后用水浸泡、过滤后使用 | 驱避 | 效果不持久，需经常喷洒 |
| 稀释牛奶 | 将牛奶用水稀释5-10倍 | 白粉病、螨虫 | 剩余部分会变质发臭 |

### 9-4. 农艺防治

| 方法 | 原理 |
|---|---|
| 摘心 | 从物理上消除蚕豆最主要害虫蚜虫的栖息地 |
| 轮作 | 2年以上不种豆科作物，能减少土壤中的枯萎病和炭疽病病原 |
| 稀植 | 蚕豆株型大，种得过密会使巧克力斑病大爆发 |
| 排水 | 蚕豆的大部分病害都与土壤过湿有关 |
| 保证钾肥 | 缺钾会大大降低对斑病的抵抗力 |
| 种子挑选 | 炭疽病会通过种子传播，需剔除有斑点、变色的种子 |
| 雨后不进田 | 人接触潮湿的叶片会传播病原菌 |
| 残株处理 | 患病残株要焚烧或深埋，只将健康的残株还田 |

## 10. 营养缺乏与过量

| 症状 | 原因 | 天然材料应对方法 |
|---|---|---|
| 从下部叶片开始整株呈浅黄色，植株矮小 | 缺氮。在蚕豆中，根瘤不良是最常见的原因 | 先挖根检查根瘤。若无根瘤，次年务必确保接种，当年可少量施用10倍稀释的尿液 |
| 叶缘变褐枯干，斑病严重 | 缺钾 | 在株间撒施草木灰，并轻轻锄入土中 |
| 生长缓慢，叶片带紫色 | 缺磷 | 骨粉、烤鱼骨磨成的粉、草木灰 |
| 落花异常多，几乎不结荚 | 缺硼，或开花期高温干旱 | 施用混合多种材料的堆肥，当年以灌溉和摘心应对 |
| 叶脉仍呈绿色，但脉间发黄 | 缺铁或缺锰，偏碱性的土壤中常见 | 停止使用草木灰，用腐叶土和完全腐熟的堆肥增加有机质 |
| 新叶细小畸形，生长点枯死 | 缺钙或缺硼 | 烤蛋壳磨成的粉、贝壳粉 |
| 茎叶徒长而豆荚稀少 | 氮过量 | 立即停止供氮，通过摘心调配养分 |
| 株高徒长而倒伏 | 氮过量或密植 | 培土并用绳固定，次年减少施肥量 |

&nbsp;&nbsp;&nbsp;在蚕豆上看到缺氮症状时，第一步不是施肥，而是先挖根查看。蚕豆的供氮来源不是土壤，而是根瘤。如果根瘤长势良好、掰开后内部呈红色，叶片却仍发黄，那问题就不在于氮。如果没有根瘤，或内部呈白色，那才是原因所在，但即便如此，大量施氮也不是解决办法，因为土壤中氮增多会让残存的根瘤进一步减弱功能。

&nbsp;&nbsp;&nbsp;钾是蚕豆栽培中需要特别留意的元素。缺钾不仅会直接导致叶缘枯干，还会同时降低对巧克力斑病的抗性。草木灰是最方便的钾肥来源，把田里长出的作物残体烧成灰再还回同一块田，是最可靠的循环方式。但草木灰施用过量会使pH超过8，妨碍铁和锰的吸收，因此每㎡应以200g为上限。

## 11. 间作与轮作

### 11-1. 搭配关系

| 搭配 | 作物 | 理由 |
|---|---|---|
| 良好 | 小麦·大麦 | 冬季生长期相同，可以一起种植，谷物能分享蚕豆固定的氮 |
| 良好 | 马铃薯 | 先收蚕豆再在原地种植，病害不会重叠 |
| 良好 | 结球甘蓝·大白菜类 | 种在蚕豆之后可利用残留的氮 |
| 良好 | 菠菜·生菜 | 可种在蚕豆行间，共用空间 |
| 一般 | 玉米 | 收完蚕豆后于夏季种植，很难同时栽培 |
| 不良 | 大蒜·洋葱类 | 有报告称其分泌物会抑制根瘤菌 |
| 不良 | 其他豆科作物 | 病原菌与线虫会不断累积 |

&nbsp;&nbsp;&nbsp;蚕豆与谷物的冬季间作，是欧洲长期采用的方式。在小麦或大麦的行间种植蚕豆，两种作物能一起越冬，并在春天共同生长。蚕豆固定的部分氮会通过根系流向谷物，而谷物挺直的茎又能防止蚕豆被风吹倒。不过蚕豆在40%遮光下产量会降到一半，因此行距要留得足够宽，以避免蚕豆深陷谷物的阴影中。

&nbsp;&nbsp;&nbsp;蚕豆在5-6月收获这一点，为田地安排带来了很大优势，因为这个时间正好与夏季作物的播种期衔接。收完蚕豆并将茎叶切碎覆盖后，在原地种上甘薯、玉米或晚播大豆，就相当于一年收获两茬作物，而第二茬作物可以直接利用蚕豆留下的氮。

### 11-2. 轮作

| 项目 | 标准 |
|---|---|
| 休作期 | 2年以上，属于韩国农村振兴厅的2年休作组 |
| 理想周期 | 3-4年 |
| 连作障害 | 枯萎病、炭疽病和线虫会不断累积 |

&nbsp;&nbsp;&nbsp;蚕豆的连作适应性A在豆类中属于较好的水平，比豌豆的5到7年、菜豆和鹰嘴豆的3年更有余量。但能耐受并不意味着适合连年种植。若连作超过3年，枯萎病会不断积累，开花期植株枯死的情况会日益增多。

| 4年轮作示例 |
|---|
| 第1年：蚕豆（越冬）后接甘薯或玉米（夏季） |
| 第2年：大白菜·结球甘蓝类或叶菜类 |
| 第3年：马铃薯或谷物 |
| 第4年：根菜或绿肥 |
| 再次种蚕豆 |

&nbsp;&nbsp;&nbsp;这里记录一下田地狭小、没有余地轮作时的折衷办法。最简单的方式是把田地分成四块，每年轮换一块种蚕豆。如果田地小到无法分区，至少要每年更换种蚕豆的行的位置。仅仅是去年种蚕豆的行今年种马铃薯、去年种马铃薯的行今年种蚕豆，也能大幅延缓病原菌的累积。

## 12. 收获与脱粒

### 12-1. 收获时期的判断

| 用途 | 收获时期 | 判断标准 |
|---|---|---|
| 嫩芽（凉拌菜用） | 开花期，摘心时 | 茎顶端5-10cm的柔嫩部分 |
| 鲜蚕豆（蔬菜用） | 播种后70-90天 | 豆荚饱满有光泽，仍呈绿色时 |
| 干籽粒 | 播种后100-120天 | 豆荚变黑干枯，籽粒变硬时 |

&nbsp;&nbsp;&nbsp;蚕豆的豆荚成熟后不是变褐色，而是变黑。这一点和其他豆类不同，初次栽培的人容易误以为是病害。豆荚是从下部节位开始依次变黑的，因此要按从下到上的顺序依次采收。

&nbsp;&nbsp;&nbsp;把握鲜蚕豆的最佳采收期是有诀窍的。用手按压豆荚，能明显摸到籽粒的轮廓，但豆荚仍有弹性时就是最佳时期。剥开看，如果包裹籽粒的白色棉絮状薄膜是湿润的，就正是时候；若这层薄膜已经变干发黄，就已经晚了。鲜蚕豆剥壳后会露出淡绿色的果肉，可以焯水或炒着吃。

> **如果预报有雨，不要等到完全成熟就要收获。稍微没熟透的蚕豆晒干后仍可使用，但反复淋湿又变干的豆荚会裂开落粒，残留的籽粒还会长霉。**

### 12-2. 收获要点

| 顺序 | 内容 |
|---|---|
| 1 | 选晴朗干燥的日子，在露水干后的上午10点以后进行 |
| 2 | 鲜蚕豆要将豆荚扭下采摘，若用力拉拽会伤及茎部 |
| 3 | 收干籽粒时用镰刀从茎的基部割断，根留在田里 |
| 4 | 捆成束，倒挂在屋檐下或仓房内晾干 |
| 5 | 豆荚彻底干透、摇动时能发出声响时进行脱粒 |

&nbsp;&nbsp;&nbsp;割断茎部而保留根系，在灾害条件下是正确的选择。蚕豆的根粗壮，附着的根瘤也大，其中所含的氮每公顷可达15-30kg。拔出的话这些氮就会离开田地，留下的话则会腐烂，成为下一茬作物的养分。

### 12-3. 脱粒 - 无工具的方法

| 方法 | 工具 | 步骤 | 效率 |
|---|---|---|---|
| 踩袋子 | 厚麻袋或布袋 | 把干茎装入袋中，扎紧口后用脚踩踏 | 最适合少量脱粒，籽粒不会溅出 |
| 连枷 | 长柄上系有敲杆的农具 | 铺开草席，将茎摊薄后从上方敲打 | 适合中等规模 |
| 用木棒敲打 | 木棒 | 装入袋中或摊在草席上敲打 | 没有连枷时可替代使用 |
| 用手剥壳 | 无需工具 | 逐个扭开豆荚 | 籽粒大，比其他豆类快得多 |
| 用脚搓踩 | 无需工具 | 摊在草席上，穿鞋用脚搓踩转动 | 适合少量脱粒 |

&nbsp;&nbsp;&nbsp;蚕豆籽粒大，用手剥壳比其他豆类效率高得多。一个干豆荚里只有两三粒籽，而且荚壁厚容易裂开，小规模脱粒完全不必用连枷。不过豆荚厚，如果晒得不够干就不容易裂开，所以无论是敲打还是手剥，都要等完全晒干之后再进行。

### 12-4. 精选 - 借风扬选

| 方法 | 原理 | 步骤 |
|---|---|---|
| 风选（扬风） | 蚕豆籽粒较重，豆壳和碎屑较轻 | 在有风的日子，将其盛入簸箕或宽口容器中，举高后缓缓倒出 |
| 用簸箕颠簸 | 上下颠动并向前扬 | 重的籽粒留在后方，轻的杂物被推向前方 |
| 用扇子扇风 | 一人倾倒，另一人用扇子扇风 | 用于无风的日子 |
| 过筛 | 按孔径大小分级 | 蚕豆籽粒大，用筛子分级尤其容易 |
| 水选 | 空壳和虫蛀的籽粒较轻 | 倒入水桶中捞去漂浮者，捞出的良种必须再次晒干 |
| 手工挑选 | 用眼观察 | 籽粒大，用手挑选最为准确 |

&nbsp;&nbsp;&nbsp;蚕豆籽粒大，精选在豆类中是最容易的。风选一次就能吹去大部分糠壳，剩下的用眼看、用手挑就够了。风选的诀窍有三点：选风力稳定的清晨或黄昏，不要一次倒完，而要细细地缓缓倾倒，并重复两三次。水选的方法能同时完成精选和挑选，但浸过水的蚕豆必须当天彻底重新晒干，且不能用作种子。
