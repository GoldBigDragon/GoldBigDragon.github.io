## 13. 採種

| 項目 | 方法 |
|---|---|
| 採種個体の選抜 | 病気の症状がなく、さやが多く着き、冬をよく越した株を畑であらかじめ目印を付けておきます |
| 隔離 | 他の品種と数百m離すか、一年に一品種だけ育てます |
| 収穫時期 | さやが完全に黒く枯れた後に収穫します。食用より遅く収穫します |
| 分離 | 別に脱穀します。手でむくと粒が傷つきません |
| 選別 | 斑点、しわ、変色、小さい粒はすべて捨てます。大きくて光沢のある粒だけ残します |
| 乾燥 | 水分12%。噛んだときに歯が入らず、パキッと割れます |
| 保管 | 密閉容器に入れ、涼しく暗い場所に置きます。食用とは別の容器にします |
| 保管期間 | 常温密閉で3年 |

> **ソラマメは自家受精が基本ですが、ハチによる他家受精が30-50%に達します。複数の品種を隣り合わせて植えると、翌年の種で形質が混ざって出てきます。純系を守るには隔離が必要です。**

&nbsp;&nbsp;&nbsp;この他家受精性は、ソラマメをエンドウと分ける重要な違いです。エンドウは花びらが雌しべと雄しべを完全に包み込み、外部の花粉が入れませんが、ソラマメの花は大きく香りが強くハチを引き寄せます。そのため複数の品種を並べて植えると雑種ができます。災害の状況でどうせ一つの系統しか育てないのであれば、この問題は自然に解決します。二系統以上を維持したいなら、一年ごとに一つずつ交代で採種するか、畑を大きく離します。

&nbsp;&nbsp;&nbsp;採種用を畑であらかじめ目印を付けておく習慣が、結果を大きく変えます。収穫後に粒だけを見て選ぶと、大きさと形だけで選ぶことになります。畑で選べば、耐寒性、さやの数、斑点病への抵抗性、倒伏への抵抗性といった実際に重要な形質も一緒に選べます。特にソラマメでは、冬をよく越した個体を選び出すことに価値があります。韓国国内に普及した品種が実質的にない作物なので、数年にわたる選抜がそのままその畑の品種を作る過程になります。

| 種子の保管期間と発芽率 |
|---|
| 収穫当年：90%以上 |
| 1年経過：80-90% |
| 2年経過：60-80% |
| 3年経過：40-60% |
| 4年以降：急激に落ちます |

## 14. 毒性と注意事項 - ファビズム

&nbsp;&nbsp;&nbsp;この節は、この文書の中で最も重要です。ソラマメは大多数の人にとって安全で栄養に優れた食品ですが、特定の体質を持つ人にとっては命を脅かすことがあります。この危険は調理でなくなるものではなく、どれだけよく火を通したかとも関係がありません。

> **G6PD酵素が欠乏している人がソラマメを食べると、赤血球が急激に破壊される急性溶血が起こります。これをファビズム（favism）といいます。小児では致命的になることがあり、ソラマメの花粉を吸い込むだけで発作が起きた例も報告されています。**

### 14-1. ファビズムとは何か

&nbsp;&nbsp;&nbsp;人の赤血球は、酸化ストレスから自分を守るためにG6PD（グルコース-6-リン酸脱水素酵素）という酵素を使います。この酵素は赤血球の中で抗酸化物質を絶えず再生する役割を担っています。遺伝的にこの酵素が不足している人は普段は何の症状もありませんが、強い酸化物質が体に入ると赤血球が耐えられずに壊れます。

&nbsp;&nbsp;&nbsp;ソラマメにはビシンとコンビシンという配糖体が含まれています。この物質が腸で分解されると、ジビシンとイソウラミルという強い酸化物質になります。G6PDが正常な人の赤血球はこれを無理なく処理しますが、欠乏している人の赤血球は数時間のうちに大量に破壊されます。破壊された赤血球から出たヘモグロビンが尿をコーラ色に染め、酸素を運ぶ赤血球が不足して重い貧血と黄疸が起こります。

| 項目 | 内容 |
|---|---|
| 原因物質 | ソラマメのビシンとコンビシン、その代謝物であるジビシンとイソウラミル |
| 発症する体質 | G6PD欠乏。X染色体遺伝のため男性に症状がより多く現れます |
| よく見られる血統 | 地中海沿岸、中東、アフリカ、東南アジア |
| 発症までの時間 | 摂取後数時間から2日以内 |
| 曝露経路 | 食べること、そして稀に開花期の花粉吸入 |
| 調理での除去 | 不可能です。煮ても焼いても危険は残ります |
| 最も危険な対象 | 子供。体重に対する摂取量が大きく、重症化しやすいです |

### 14-2. どのような症状が現れるか

| 時期 | 症状 |
|---|---|
| 数時間後 | 悪寒、発熱、頭痛、吐き気、腹部と背中の痛み |
| 半日から1日 | 尿が濃い茶色またはコーラ色に変わります |
| 1日から2日 | 顔と目が黄色くなる黄疸、著しい顔色不良、息切れ、脈拍の増加 |
| 重症 | 力が抜けて立ち上がれず、意識がぼんやりします。尿がほとんど出なくなります |

&nbsp;&nbsp;&nbsp;最も気づきやすい徴候は尿の色です。ソラマメを食べた後に尿が濃い茶色やコーラ色を帯びたら、溶血が起きているという意味なので、直ちに摂取を中止し、可能であれば医療の助けを求めなければなりません。医療が届かない条件でできることは限られていますが、水を十分に飲ませて腎臓が壊れた赤血球のかすを排出するのを助け、絶対安静を取らせ、その人には二度とソラマメを食べさせないことです。

### 14-3. どのように備えるか

| 原則 | 内容 |
|---|---|
| 最初は必ず少量で | 五、六粒程度だけ食べさせ、1日から2日観察します。何も起きなければ少しずつ増やします |
| 子供にはさらに注意 | 子供に初めて食べさせる時は2-3粒から始めます |
| 家族歴の確認 | 血縁の中にソラマメや特定の薬を飲んで黄疸と貧血が出た人がいれば、その家系は避けます |
| 開花期の畑への立ち入り | 欠乏が確認された人は、ソラマメが花を咲かせる時期に畑の近くに行かせないようにします |
| 皮をむく | 種皮にビシンとコンビシンが相対的に多く含まれます。皮をむくと曝露は減りますが、危険がなくなるわけではありません |
| 浸漬と茹でること | 浸した水と茹でた湯を捨てると一部が抜け出します。これも危険がなくなるわけではありません |
| 代替作物 | 欠乏者がいる家庭なら、ソラマメの代わりにエンドウやササゲを育てる方が安全です |

&nbsp;&nbsp;&nbsp;災害の状況ではG6PD欠乏の有無を検査する方法はありません。そのため、少量で試す手順が唯一の実質的な安全策になります。新しく加わった人、子供、これまでソラマメを食べたことがない人には、例外なくこの手順を適用します。一度問題なく食べた人は、その後も大体安全です。

&nbsp;&nbsp;&nbsp;この危険があるにもかかわらずソラマメを育てる価値があるかという問いには、条件付きで答えることができます。韓国国内の人口におけるG6PD欠乏の頻度は、地中海や東南アジアに比べると低い方です。そしてソラマメが与える利益、つまり冬の畑を使い、春に最も早く収穫でき、土に窒素を残す能力は、他の作物で代えるのが難しいです。ただしその判断は、一緒に食べる人たちを知った上で下すべきであり、少量で試すという手順を省略してはなりません。

### 14-4. その他の抗栄養成分

| 成分 | 作用 | 除去する方法 |
|---|---|---|
| トリプシン阻害因子 | タンパク質分解酵素の働きを妨げます | 8時間浸漬後、沸騰した湯で1時間加熱 |
| レクチン | 腸粘膜に付着して吸収を妨げます | 加熱で破壊されます。インゲンマメ類ほど毒性は強くありません |
| フィチン酸 | 鉄、亜鉛、カルシウムと結合して吸収を妨げます | 浸漬、発芽、発酵で60-80%まで減ります |
| オリゴ糖 | 人が消化できず、腸内細菌が発酵させます | 浸漬後、浸した水を捨てます |
| レボドパ（L-ドパ） | 神経伝達物質の前駆体です | 若いさやと新芽に多く含まれます。多く食べるとめまいを感じることがあります |
| かび毒 | 貯蔵中にかびが作ります | かびが生えたソラマメは洗っても加熱しても安全になりません。捨てます |

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;ソラマメの貯蔵性はSSです。乾燥種実は常温で3年もち、脂肪が2%未満なので酸敗も遅いです。しかし条件が悪いと、ゾウムシ一種が貯蔵したソラマメ全部を殻に変えてしまいます。

> **豆は腐って失われるのではなく、虫に食われて失われます。貯蔵の技術とは、すなわち虫を防ぐ技術です。**

### 15-1. 乾燥が先です

| 段階 | 方法 | 確認 |
|---|---|---|
| 予備乾燥 | 茎ごと軒下に逆さに吊るして3-4日 | さやが黒くからからに乾きます |
| 脱穀後の乾燥 | むしろや敷物に薄く広げて日に3-5日 | 粒が大きくダイズより時間がかかります。頻繁にかき混ぜます |
| 目標水分 | 食用と種子とも12% | 歯で噛んだ時、歯が入らずパキッと割れます |
| 塩試験 | 乾いた塩を瓶にソラマメと一緒に入れて振ります | 塩が瓶の壁に付着すればまだ湿っています |
| 冷ます | 日から取り込んだ後、完全に冷ましてから詰めます | 温かい状態で密閉すると結露が生じます |

&nbsp;&nbsp;&nbsp;ソラマメは粒が大きいため、表面は乾いていても内部が乾いていない状態になりやすいです。表面だけ見て詰めると、数週間で容器の中にかびが生えます。粒を半分に割って内部まで均一に乾いた色になっているか確認する習慣が必要で、日に干す日数も他の豆類より一、二日多めに取ります。

### 15-2. 貯蔵中のゾウムシ防除

&nbsp;&nbsp;&nbsp;ソラマメゾウムシ（Bruchus rufimanus）は貯蔵ソラマメにとって最大の脅威です。恐ろしいのは、それが畑ですでに始まっているという点です。まだ畑に着いているさやに成虫が卵を付けておき、その卵が貯蔵庫の中で孵化して豆の中に食い込みます。取り込む時にはすでに卵が付いてくる構造で、半年もすれば袋一つが穴の開いた殻でいっぱいになります。

| 方法 | 原理 | 適用 | 効果 |
|---|---|---|---|
| 完全密閉 | 酸素を断って窒息させます | ガラス瓶や金属缶を満たして封をします | 最も確実です。3-4週間で卵と幼虫まで死にます |
| 草木灰を混ぜる | 微細な粒子が外骨格のワックス層を削り、脱水させます | ソラマメの体積の2-5%を混ぜます | 食べる前に水で洗い流します |
| 珪藻土 | 珪酸の殻が外骨格を傷つけます | ソラマメ1kgに1-3g | 灰より効果が大きいです。乾いた状態でのみ働きます |
| 油コーティング | 油膜が卵の付着と孵化を防ぎます | ソラマメ1kgに食用油2-5mLを入れてもみます | 粒が大きいので表面積に対して油が少なくて済みます。種子用には使いません |
| 低温処理 | 零下で卵と幼虫が死にます | 真冬に数日外に出してから取り込みます | 取り込む時は結露に注意します |
| 高温処理 | 60度で卵と幼虫が死にます | 日に薄く広げて半日置きます | 種子用には使いません |
| 干した唐辛子・サンショウ・ヨモギ | 精油成分が産卵を抑えます | 層になるように入れます | 補助的な手段です |
| 炭・炒り塩 | 湿気を吸い取ります | 布に包んで入れます | かび防止も兼ねます |
| 灰の中に埋める | 密閉と物理的防除を同時に得られます | 甕に灰とソラマメを層になるように積みます | 伝統的に広く使われてきました |

&nbsp;&nbsp;&nbsp;最も重要なのは完全密閉です。虫も呼吸をします。密閉した容器の中で豆と虫が酸素を使うと、酸素が減り二酸化炭素が増えて虫が死にます。豆は休眠状態なのでこの条件に耐えられます。容器を満たして空間を減らすほど効果が早くなります。大きな容器一つより小さな容器複数にぎゅうぎゅうに詰める方がよく、これは一つの容器が傷んだ時に全部を失わない利点も同時に与えてくれます。

&nbsp;&nbsp;&nbsp;油コーティングはインドとアフリカの小規模農家で長く使われてきた方法です。ソラマメ1kgに食用油2-3mlを入れ、手でもんで全ての粒に薄い膜ができるようにします。粒が大きく表面積が相対的に小さいため、他の豆より油が少なくて済みます。半年以内に食べる分だけに使い、種子用には使いません。油膜が呼吸を妨げて発芽力が落ちるからです。草木灰はふるいにかけて細かい部分だけを選び、体積の2-5%を混ぜます。虫が耐性を得ることができず、人には無害です。

### 15-3. 貯蔵容器と場所

| 容器 | 密閉性 | 期間 | 長所 | 短所 |
|---|:---:|---|---|---|
| ガラス瓶 | 非常に良い | 3年以上 | 状態を目で確認できます | 容量が小さく光を防げません |
| 金属缶 | 非常に良い | 3年以上 | ネズミと虫を完全に防ぎます | 結露が生じるとその部分が傷みます |
| 甕 | 良い | 2-3年 | 温度変化が緩やかでネズミが破れません | 重くて割れます |
| 厚手のビニール | 普通 | 1-2年 | 軽くて値段が安いです | ネズミが破ります |
| 地中の貯蔵穴 | 良い | 2-3年 | 温度が一定で低いです | 水が染みると全量を失います |

&nbsp;&nbsp;&nbsp;点検で最も信頼できる感覚は聴覚と嗅覚です。容器に耳を当てた時にカサカサという音がすれば虫が活動しており、湿っぽい臭いがすればかびが始まっています。表面に小さな丸い穴が見えれば、ゾウムシが一世代を経過した状態です。この時点でも全量を取り出して日に干し、水に浮かせて空の粒を取り除き、灰や油を混ぜて再び密閉すれば、残りの分を守れます。2か月に一度の点検が基準です。

## 16. 調理と加工

### 16-1. 皮むきと浸漬

| 処理 | 時間・温度 | 効果 |
|---|---|---|
| 浸漬 | 常温の水に8時間以上。大粒は12時間 | 粒が大きいので他の豆より時間がかかります |
| 浸した水を捨てる | 必ず | オリゴ糖とビシン・コンビシンの一部が一緒に抜けます |
| 皮むき | 戻した後、手で押して皮をむきます | 調理時間が減り、消化しやすくなり、抗栄養成分が減ります |
| 茹でる | 沸騰した湯で1時間 | 皮をむくと30-40分に減ります |
| 火の通り確認 | 指で押すと簡単に潰れます | 芯が残っていれば火が通っていません |

&nbsp;&nbsp;&nbsp;ソラマメは種皮が厚くて丈夫なので、皮をむく方が何かと有利です。水で戻した後、粒を指で押すと皮がすっとむけます。皮をむくと調理時間がほぼ半分に減って燃料の節約になり、消化しやすくなり、種皮に相対的に多いビシンとコンビシンの摂取量も減ります。むいた皮は捨てずに集めておき、家畜の飼料や堆肥に使います。

### 16-2. 燃料を節約する調理

| 方法 | 燃料 | 手順 |
|---|:---:|---|
| 皮をむいて茹でる | 少ない | 戻して皮をむくと30-40分で煮えます |
| 圧力調理 | 最も少ない | 戻したソラマメを15分加圧します |
| 余熱調理 | 非常に少ない | 15分煮た後、火を止めて藁・籾殻の箱や布団で包み、2-3時間置きます |
| 炒りソラマメ | 少ない | 戻して乾かしたソラマメを油なしで炒ります。そのまま食べられます |
| ソラマメ粉 | ほとんどない | 炒って挽いておき、水に溶いて食べます。脂肪が少なく長持ちします |
| 青ソラマメ | 少ない | 皮をむいてゆでれば数分で済みます |

&nbsp;&nbsp;&nbsp;炒りソラマメは地中海と中東で広く食べられている形です。水で戻してから乾かし、油なしで炒ると表面が割れて香ばしくなります。一度炒っておけばそのまま食べられるので、その後燃料がかからず、密閉しておけば一、二か月もちます。ただしこの方法ではビシンとコンビシンを除去できないため、ファビズムの危険がある人には、調理方法にかかわらず危険です。

&nbsp;&nbsp;&nbsp;余熱調理もソラマメで効果が大きいです。15分だけ煮て保温箱に入れておくと、内部の温度が2時間以上高く保たれ、調理が続きます。藁や籾殻を詰めた木箱、または厚い布団で鍋を丸ごと包めば、それが保温箱です。粒が大きく中まで火が通るのに時間がかかるソラマメに特に合った方法です。

### 16-3. 貯蔵加工

| 加工 | 手順の概要 | 保管 | 価値 |
|---|---|---|---|
| ソラマメ粉 | 炒って挽きます | 密閉で3-6か月 | 調理の燃料がかかりません |
| 若芽の塩漬け | 摘心で出た芽を塩に漬けます | 数か月 | 春の若菜を冬まで持たせます |
| ゆでて干した青ソラマメ | ゆでて水気を切り、からからに乾かします | 数か月 | 冬に汁物や粥に入れます |
| ソラマメのテンジャン（韓国味噌） | 茹でてつぶし、メジュ（味噌玉）のように発酵させて塩水に浸けます | 数年 | ダイズが不足した時の代案です |
| 炒りソラマメ | 戻して乾かした後、油なしで炒ります | 密閉で1-2か月 | おやつであり非常食です |

&nbsp;&nbsp;&nbsp;ソラマメで醤（じゃん）を仕込むのは、東洋で長い伝統を持つ方法です。茹でたソラマメにヌルク（韓国の麹）を付けて発酵させ、塩とトウガラシを加えて熟成させます。発酵を経ると抗栄養成分が分解され、消化率が上がり、塩とともに数年もちます。ダイズが確保できなかった年にソラマメが豊富にあるなら、十分に試す価値のある方法です。ただし発酵もビシンとコンビシンを完全にはなくせません。

## 17. 年間作業スケジュール

| 月 | 作業 | 要点 |
|---|---|---|
| 1月 | 貯蔵ソラマメの点検、越冬畑の見回り、霜柱を押さえる | 浮き上がった株を足で踏んで押さえます |

| 3月 | 越冬株の土寄せ、除草、排水路の点検 | 春の雨で水がたまらないようにします |
| 4月 | 開花開始、摘心、アブラムシ管理、根粒確認 | 摘心はソラマメ栽培の中核となる作業です |
| 5月 | さや肥大、灌水集中、青ソラマメの収穫開始（越冬分） | この時期の水が収量を決めます |
| 6月 | 乾燥種実の収穫（越冬分）、春分の青ソラマメ収穫、吊るし乾燥 | 雨の予報があれば完熟を待ちません |
| 7月 | 脱穀、精選、乾燥、貯蔵、茎葉の還元 | 茎は燃やさず切って覆います |
| 8月 | 後作の管理、貯蔵点検 | ソラマメの場所に植えた夏作物が残った窒素を使います |
| 9月 | 秋の畑の準備、石灰の散布、堆肥の投入 | 播種3週間前に石灰を入れます |
| 10月 | 畝作り、排水路の設置、種子選別 | 冬の排水が越冬の成否を決めます |
| 11月 | 秋播種（立冬前後、韓国南部） | 初霜から40-50日前を播種日とします |
| 12月 | 藁・落ち葉の被覆、獣害対策、貯蔵点検 | 冬の野原で青々としているのがソラマメだけだとキバノロが来ます |

### 17-1. 忘れてはならない五つのこと

| 項目 | 内容 |
|---|---|
| ファビズム | G6PD欠乏の人には致命的です。初めて食べる人は必ず五、六粒で試し、1日から2日観察します |
