## 3. 栽培环境

### 3-1. 气温与光照量

| 条件 | 极限值 | 最适值 | 超出范围时 |
|---|---|---|---|
| 发芽温度 | 5℃以上 | 15-20℃ | 在8-10℃下也能缓慢发芽 |
| 生长温度 | 5-28℃ | 10-20℃ | 超过25℃生长停止，病害增多 |
| 结实温度 | 10-24℃ | 13-20℃ | 幅度14℃，在豆类中范围较宽 |
| 开花期高温 | 25℃以上持续数日 | - | 花朵和幼荚会脱落 |
| 耐寒性 | 可耐零下10℃ | - | 在豆科中居首位，可在田间越冬 |
| 越冬极限 | 零下15℃以下持续则会死亡 | - | 在韩国中部内陆地区越冬困难 |
| 光照 | 每天6小时以上 | 每天8小时以上 | 40%遮光时产量降至一半 |

> **将蚕豆与其他豆类区分开来的唯一一个数值就是零下10℃。正因为这一点，蚕豆才能利用冬季田地，并在春天最早提供可食用的收成。**

&nbsp;&nbsp;&nbsp;蚕豆的耐寒性是有条件的。如果在越冬前长得过大，反而会被冻死。本叶三四片、株高10-15cm的状态最耐寒，因此秋播要选在初霜前40-50天。这就是韩国南部以立冬前后，即11月初为播种基准的原因。9月播种会在冬季来临前长到膝盖高度而被冻死，12月播种则会在扎根前被冻土困住。

&nbsp;&nbsp;&nbsp;在韩国中部内陆地区，越冬大多会失败。在零下15℃持续多日的地区，蚕豆也会死亡。这类地区应改为2月中下旬春播。韩国南部沿海和济州岛越冬栽培较为稳定，韩国中部西海岸和南部内陆则因年份而异。如果没有把握，可将秋播和春播分开种植以分散风险。

### 3-2. 土壤与水分

| 条件 | 极限值 | 最适值 | 备注 |
|---|---|---|---|
| 土质 | 从砂质土到黏质土均可 | 排水良好的砂壤土 | 积水的土地最不利 |
| pH值 | 5.5-8.0 | 6.0-7.0 | 酸性土中根瘤会减少 |
| 有效土层深度 | 40cm以上 | 60cm以上 | 主根扎入较深 |
| 生长期蒸散量 | - | 约450mm | 在豆类中属于中等水平 |
| 浸水 | 浸泡超过一天根系会受损 | - | 极不耐涝 |
| 地下水位 | 50cm以下 | 80cm以下 | 冬季田地的水分管理十分重要 |

&nbsp;&nbsp;&nbsp;蚕豆极不耐涝。它的根粗壮且扎得很深，这条粗根一旦被水淹没就会立刻腐烂。而且根瘤菌是需要氧气的好氧菌，田地只要被淹一天，根瘤就会比根本身更早失去功能。在越冬栽培中，这个问题更加棘手，因为冬季冻融交替会使土壤松动、水路堵塞。将垄抬高20cm以上并挖深排水沟，对蚕豆而言不是可选项，而是前提条件。

&nbsp;&nbsp;&nbsp;蚕豆对土壤酸度的容忍范围比豌豆更宽，可耐受pH 5.5到8.0，最适为6.0-7.0。不过这个范围与其说是植株本身的要求，更多是根瘤菌的要求。pH降到5.5以下时，蚕豆本身还能勉强生长，但根瘤菌无法存活，固氮作用停止，叶片会呈现浅黄色。韩国的田地降雨较多，土壤大多偏酸性，因此撒石灰是比施肥更优先要做的工作。

## 4. 品种

### 4-1. 按用途分类

| 类型 | 种子大小 | 特点 | 适合情况 |
|---|---|---|---|
| 大粒食用种 | 单粒2g以上 | 籽粒大，产量高 | 是食用与贮藏的基本选择 |
| 小粒地方种 | 单粒0.7-1.5g | 籽粒小，耐寒耐瘠 | 适合地力差或冬季寒冷的地区 |
| 绿肥·饲料用 | 不限 | 茎叶产量高 | 以恢复地力为目的时 |
| 早熟种 | 不限 | 生长期短 | 春播需避开炎热天气时 |

&nbsp;&nbsp;&nbsp;蚕豆在韩国几乎没有正式登记的品种。目前留存的只有1980年代初以前部分地区栽培的地方品系，最近才出现少量韩国国内培育的品种。"Wonjam 1-ho"这样的辐射育种品系也广为人知，但种子流通有限。市面上能买到的大多是进口种子，或者是以家庭菜园用途小批量流通的种子。

&nbsp;&nbsp;&nbsp;因此，若要将蚕豆纳入种植计划，唯一的办法是提前确保种子，并通过自家留种延续下去。幸运的是，蚕豆籽粒大，一株能收获的种子重量相当可观，常温密闭保存可维持3年。头几年不应期待产量，而应合理地把精力集中在扩繁种子上。选留在当地成功越冬的个体继续繁殖，几年之内就能培育出适合当地土地的品系。

### 4-2. 按情况选择的标准

| 情况 | 优先选择 | 理由 |
|---|---|---|
| 冬季寒冷 | 小粒地方种 | 籽粒越小，越冬能力往往越强 |
| 需要养地 | 绿肥用或任意品系 | 在开花期整株翻耕入土 |
| 种子不足 | 小粒种 | 相同重量可播种更大面积 |
| 需要储备粮 | 大粒食用种 | 相同劳动量能收获更多重量 |
| 只能在春季播种 | 早熟种 | 必须在炎热到来前完成生长 |
| 首次获得种子 | 任何品系均可 | 头两三年集中精力留种 |

&nbsp;&nbsp;&nbsp;蚕豆的种子大小对播种量影响很大。若用单粒2g的大粒种播种100m²，所需的重量可达小粒种的两三倍。种子珍贵的第一年，小粒种或中粒种能够负担更大的种植面积。

## 5. 整地与施肥 - 根瘤菌

### 5-1. 固氮作用是如何发生的

&nbsp;&nbsp;&nbsp;空气中78%是氮气。尽管人们头顶飘浮着无穷无尽的氮气，植物却无法直接利用它。这是因为空气中的氮是由两个氮原子以三重键牢牢结合而成的分子，切断这一化学键需要巨大的能量。工业上切断这一化学键制造氨的方法就是哈伯-博施法，世界上的氮肥都由此而来，它需要高温、高压、催化剂和大量化石燃料。

&nbsp;&nbsp;&nbsp;根瘤菌能够在常温常压下完成这项工作。它通过固氮酶将三重键切断，把氮转化为氨。不过这是有代价的：这一反应需要大量能量，而细菌本身无法进行光合作用。因此它们生活在豆科植物的根内，接受植株光合作用产生的糖分，并以固定的氮作为回报——这是一种交易关系。

&nbsp;&nbsp;&nbsp;与蚕豆共生的根瘤菌是 Rhizobium leguminosarum bv. viciae，与豌豆、小扁豆、野生苕子共生的是同一种菌，与大豆的 Bradyrhizobium japonicum 是不同的种。这一点在实践中很重要：把种过大豆的地里的土壤沾到蚕豆种子上并不会有效果；相反，种过豌豆、小扁豆或野生苕子的地里的土壤，可以直接用作蚕豆的接种源。

| 阶段 | 发生的过程 |
|---|---|
| 1. 信号交换 | 蚕豆根系分泌类黄酮，土壤中的细菌响应该信号释放结瘤因子 |
| 2. 感染 | 根毛向内卷曲包住细菌，细菌沿感染线进入根内 |
| 3. 形成根瘤 | 根内细胞分裂使根瘤膨大，细菌在其中定居 |
| 4. 固氮 | 根瘤内固氮酶发挥作用，将空气中的氮转化为氨 |
| 5. 分配 | 氨转化为氨基酸，运送到茎、叶和豆荚 |
| 6. 衰老 | 进入灌浆期后根瘤失去功能，与根一起归于土壤 |

&nbsp;&nbsp;&nbsp;固氮酶对氧气极为敏感，一接触氧气就会立刻失去功能。因此根瘤内部充满了一种叫作豆血红蛋白的红色色素蛋白，它能捕获氧气，把酶周围的氧气浓度维持在极低水平。这与人血呈红色的原理相同，剖开根瘤后内部呈红色或粉红色，正是这种色素的颜色。这一点在实践上非常重要，因为红色是该根瘤此刻正在固氮的直观证据。

&nbsp;&nbsp;&nbsp;蚕豆的根瘤比其他豆类更大、更显眼。粗壮的主根上方常常聚集着数个豆粒大小的根瘤，很容易辨认。蚕豆在施肥项目上获得SS评级、固氮能力被评为豆科中最高水平，与这一结构特征不无关系。

### 5-2. 确认根瘤是否形成的方法

&nbsp;&nbsp;&nbsp;无论是否接种过，都必须确认根瘤是否真正形成。若不确认，就无法知道缺氮的原因，来年还会重复同样的失误。

| 步骤 | 内容 |
|---|---|
| 1 | 开花开始前后，即播种后约8周是最佳时机 |
| 2 | 挑选两三株看起来健壮的植株 |
| 3 | 不要直接拔出，要用铲子在植株周围大范围铲挖，连土一起抬起。直接拔会使细根上的根瘤留在土里 |
| 4 | 放入水桶中轻轻洗去泥土 |
| 5 | 数一数主根和粗壮侧根上的根瘤数量 |
| 6 | 用指甲掰开几个根瘤，观察内部颜色 |

| 观察结果 | 含义 | 处理 |
|---|---|---|
| 每株根瘤20个以上，尤其集中在主根上部 | 接种效果良好 | 保持原状 |
| 掰开后内部呈红色或粉红色 | 正在固氮 | 状态良好 |
| 掰开后内部呈白色或浅绿色 | 根瘤已形成但未固氮 | 需检查酸度、涝害、磷素缺乏情况 |
| 掰开后内部呈褐色或黑色 | 已经衰老或死亡 | 若在灌浆期属正常，若在开花期则有问题 |
| 根瘤5个以下 | 接种失败 | 若叶片发黄需补充氮肥 |
| 根瘤只在细根末端零星密集分布 | 由土著菌感染，但效率较低 | 来年更换接种源 |

> **挖根、掰开根瘤查看是否呈红色——仅这一个习惯，就是在没有氮肥的世界里判断豆类种植成败最可靠的信号。**

&nbsp;&nbsp;&nbsp;根瘤的位置也能提供信息。主根上部、距地表10cm以内的粗大根瘤效率最高，这是接种效果良好时出现的位置。反之，若主根上没有根瘤，只有细根末端零散分布着小根瘤，多是土壤中原有的土著菌较晚感染所致，固氮效率较低。

### 5-3. 从何处获取接种源

&nbsp;&nbsp;&nbsp;商用接种剂是把活菌装在泥炭或黏土中出售的产品，在灾害情况下无法获得。不过根瘤菌是土壤中常见的微生物，种过与其共生的同种菌豆科作物的田地里的土壤，本身就是接种源。由于蚕豆在韩国国内的栽培历史较短，许多田地并没有相应的土著菌，因此接种的重要性比其他豆类更高。

| 方法 | 步骤 | 效果 | 注意 |
|---|---|---|---|
| 沾同菌系田地的土 | 从种过蚕豆、豌豆、小扁豆或野生苕子且根瘤长势良好的田地里，挖取表土下5-15cm处的土壤。将种子稍微沾湿后蘸上这些土，随即播种 | 最可靠且不花费成本 | 带病田地的土壤也会带来病原菌 |
| 野生苕子的根 | 春季挖取田野和田埂上的野生苕子，检查根瘤。若根瘤呈红色，就连同泥土和根一起使用 | 在没有蚕豆栽培历史的地区最为现实可行 | 固氮效率可能低于栽培专用菌系 |
| 直接使用根瘤 | 收集挖出根上的根瘤，捣碎溶于水中，将种子浸入后取出 | 菌密度最高 | 必须在挖出根瘤当天使用，干燥后细菌会死亡 |
| 把土撒入田地 | 将取来的土撒在播种行上，一起翻耕入土 | 细菌能扩散到土壤中 | 标准约为每10㎡撒一铲土 |
| 保留根系残留物 | 收获时只割茎，把根留在田里 | 细菌能在土壤中保留到来年 | 是最省事的维持方法 |

&nbsp;&nbsp;&nbsp;接种时有几点必须遵守。根瘤菌对直射光、干燥和高温都非常敏感，照射几分钟紫外线就会死掉一大半，一旦干燥死得更快。给种子沾土的操作要在阴凉处进行，沾好土的种子不要摊晒，要立即播种，最好在30分钟内种下，最迟也要在几小时内完成。另外一点，种子消毒和接种不能同时进行：给已沾过杀菌剂的种子沾土会使细菌死亡。如果用温水处理消毒过，必须完全冷却之后才能接种。

| 导致接种失败的条件 | 原因 |
|---|---|
| 土壤pH 5.5以下 | 细菌无法存活 |
| 施氮肥充足的田地 | 植株感受不到交易的必要，会自行减少结瘤 |
| 积水的田地 | 因为是好氧菌，缺氧就会死亡 |
| 缺磷的田地 | 固氮需要大量能量，而该代谢过程需要用到磷 |
| 缺乏钼·铁·钴 | 它们是固氮酶的组成成分 |
| 把接种过的种子晒干 | 紫外线和干燥会使细菌死亡 |
| 使用大豆田的土壤 | 菌种不同，不会感染蚕豆 |
