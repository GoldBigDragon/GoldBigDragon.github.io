## 13. 留种

| 项目 | 方法 |
|---|---|
| 留种个体的选择 | 提前在田里标记没有病症、结荚多且顺利越冬的植株 |
| 隔离 | 与其他品种相距数百米，或每年只种一个品种 |
| 收获时期 | 待豆荚完全变黑干枯后再收获，比食用豆收获得更晚 |
| 分开处理 | 单独脱粒，用手剥壳不会伤到籽粒 |
| 挑选 | 剔除所有有斑点、皱缩、变色及偏小的籽粒，只留下粗大有光泽的籽粒 |
| 干燥 | 含水率12%。咬下去牙齿咬不进去，会啪地裂开 |
| 保存 | 装入密闭容器，放在阴凉黑暗处，须与食用豆分开存放 |
| 保存期限 | 常温密闭可存3年 |

> **蚕豆以自花授粉为主，但蜜蜂造成的异花授粉比例可达30-50%。若把多个品种挨着种植，第二年的种子就会出现性状混杂。要保持纯系就必须隔离。**

&nbsp;&nbsp;&nbsp;这种异花授粉的特性，是蚕豆与豌豆的一个重要区别。豌豆的花瓣完全包裹住雌蕊和雄蕊，外来花粉无法进入，而蚕豆的花朵大、香气浓，会招来蜜蜂。因此把多个品种并排种植就会产生杂交。在灾害情况下，如果本来就只种一个品系，这个问题自然就解决了。若想同时保留两个以上的品系，可以每年轮流留种一个品系，或者把田地拉开较远的距离。

&nbsp;&nbsp;&nbsp;提前在田里做好留种标记这一习惯，会大大改变结果。如果收获后只看籽粒来挑选，就只能挑出大小和形状。而在田里挑选，就能同时选出越冬能力、结荚数量、斑病抗性、抗倒伏性等真正重要的性状。对蚕豆而言，挑选出顺利越冬的个体尤其可贵。由于这是一种在韩国国内几乎没有普及品种的作物，经年累月的选育本身就是在培育出适合这片田地的品系。

| 种子保存期限与发芽率 |
|---|
| 收获当年：90%以上 |
| 经过1年：80-90% |
| 经过2年：60-80% |
| 经过3年：40-60% |
| 4年以后：会急剧下降 |

## 14. 毒性与注意事项 - 蚕豆病

&nbsp;&nbsp;&nbsp;本节是这份文档中最重要的部分。蚕豆对大多数人来说是安全且营养丰富的食物，但对具有特定体质的人来说，可能危及生命。这种风险不会因烹调而消失，也与煮得多熟无关。

> **G6PD酶缺乏的人如果食用蚕豆，会发生红细胞急剧被破坏的急性溶血，这种病症称为蚕豆病（favism）。对儿童可能是致命的，也有仅因吸入蚕豆花粉就诱发发作的病例报告。**

### 14-1. 什么是蚕豆病

&nbsp;&nbsp;&nbsp;人的红细胞会利用一种叫G6PD（葡萄糖-6-磷酸脱氢酶）的酶来保护自己免受氧化应激的伤害。这种酶的作用是在红细胞内不断再生抗氧化物质。遗传性缺乏这种酶的人平时没有任何症状，但当强氧化物质进入体内时，红细胞就会承受不住而破裂。

&nbsp;&nbsp;&nbsp;蚕豆中含有蚕豆嘧啶苷和伴蚕豆嘧啶苷这两种糖苷。这些物质在肠道中分解后，会转变为divicine（迪维辛）和isouramil（异尿拉米）这两种强氧化物质。G6PD正常的人的红细胞能够从容处理这些物质，但G6PD缺乏的人的红细胞会在几小时内大量被破坏。被破坏的红细胞释放出的血红蛋白会把尿液染成可乐色，而能运输氧气的红细胞减少，就会引发严重的贫血和黄疸。

| 项目 | 内容 |
|---|---|
| 致病物质 | 蚕豆中的蚕豆嘧啶苷和伴蚕豆嘧啶苷，及其代谢产物divicine（迪维辛）和isouramil（异尿拉米） |
| 易发体质 | G6PD缺乏症，属X染色体遗传，男性更常出现症状 |
| 常见血统人群 | 地中海沿岸、中东、非洲、东南亚 |
| 发病时间 | 摄入后数小时至两天内 |
| 暴露途径 | 食用，此外少数情况下为开花期吸入花粉 |
| 能否通过烹调去除 | 不能。无论煮还是烤，风险都会残留 |
| 最危险的对象 | 儿童，因相对体重的摄入量更大，容易发展为重症 |

### 14-2. 会出现哪些症状

| 时期 | 症状 |
|---|---|
| 数小时后 | 寒战、发热、头痛、恶心、腹部和背部疼痛 |
| 半天到一天 | 尿液变为深褐色或可乐色 |
| 一天到两天 | 面部和眼睛发黄的黄疸、严重面色苍白、气短、脉搏加快 |
| 重症 | 虚弱到无法站立，意识变得模糊，几乎没有尿液排出 |

&nbsp;&nbsp;&nbsp;最容易察觉的信号是尿液的颜色。吃蚕豆后如果尿液呈深褐色或可乐色，就说明正在发生溶血，应立即停止摄入，并尽可能寻求医疗帮助。在没有医疗条件的情况下能做的事很有限，但应让患者充分饮水，帮助肾脏排出破裂红细胞的残渣，让其绝对静养，并且此后绝不再让这个人吃蚕豆。

### 14-3. 如何做好准备

| 原则 | 内容 |
|---|---|
| 首次务必只吃少量 | 只喂五六粒左右，观察一到两天。若无异常再逐渐增加 |
| 儿童要格外小心 | 第一次给孩子吃时从两三粒开始 |
| 确认家族史 | 若血亲中有人吃蚕豆或服用某些药物后出现过黄疸和贫血，该家族应避免食用 |
| 开花期进出田地 | 已确认缺乏该酶的人，在蚕豆开花时不要靠近田地 |
| 去皮 | 种皮中蚕豆嘧啶苷和伴蚕豆嘧啶苷含量相对较高，去皮能降低暴露量，但风险并不会消失 |
| 浸泡与煮制 | 倒掉浸泡水和煮汤能带走一部分，但同样不能消除风险 |
| 替代作物 | 家中有酶缺乏者的话，种豌豆或豇豆代替蚕豆更安全 |

&nbsp;&nbsp;&nbsp;在灾害情况下，没有办法检测是否存在G6PD缺乏症。因此，用少量试吃的方式，就成了唯一切实可行的安全保障。对新加入的人、孩子，以及此前从未吃过蚕豆的人，都要毫无例外地采用这一程序。只要有一次安然无恙地吃过，此后通常也是安全的。

&nbsp;&nbsp;&nbsp;尽管存在这一风险，蚕豆是否值得栽培这个问题，可以有条件地回答。韩国国内人口中G6PD缺乏症的发生率，相比地中海地区或东南亚而言算是较低的。而且蚕豆带来的好处——利用冬季田地、春天最早收获、并为土地留下氮素——是其他作物难以替代的能力。但这个判断必须在了解一起进食的人的基础上做出，绝不能跳过少量试吃这一程序。

### 14-4. 其他抗营养成分

| 成分 | 作用 | 去除方法 |
|---|---|---|
| 胰蛋白酶抑制剂 | 阻碍蛋白分解酶的作用 | 浸泡8小时后在沸水中加热1小时 |
| 植物凝集素 | 附着在肠黏膜上妨碍吸收 | 加热可破坏，其毒性不如菜豆类强 |
| 植酸 | 与铁、锌、钙结合，阻碍其吸收 | 通过浸泡、发芽、发酵可减少60-80% |
| 寡糖 | 人体无法消化，会被肠道细菌发酵 | 浸泡后倒掉浸泡水 |
| 左旋多巴（L-多巴） | 是神经传导物质的前体 | 幼荚和新芽中含量较多，大量食用可能引起眩晕 |
| 真菌毒素 | 由贮藏期间的霉菌产生 | 已发霉的蚕豆无论清洗还是加热都不会变安全，应丢弃 |

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;蚕豆的耐储性为SS。干籽粒在常温下能保存3年，脂肪含量低于2%，因此氧化变质也较慢。但一旦条件不当，仅凭一种豆象就能把贮藏的蚕豆全部变成空壳。

> **豆子不是因为腐烂而损失，而是被虫子吃掉而损失的。贮藏的技术，本质上就是防虫的技术。**

### 15-1. 干燥是第一步

| 阶段 | 方法 | 确认方法 |
|---|---|---|
| 预干燥 | 连茎倒挂在屋檐下3-4天 | 豆荚变黑并彻底干透 |
| 脱粒后干燥 | 摊薄在草席或垫子上晒3-5天 | 籽粒大，比大豆更耗时，需经常翻动 |
| 目标含水率 | 食用与种子用均为12% | 用牙咬时咬不进去，会啪地裂开 |
| 盐粒测试 | 把干燥的盐和蚕豆一起放入瓶中摇晃 | 若盐粘在瓶壁上，说明仍然潮湿 |
| 晾凉 | 从阳光下收回后要完全放凉再装入容器 | 若在温热状态下密封会产生结露 |

&nbsp;&nbsp;&nbsp;蚕豆籽粒大，容易出现表面干了而内部还没干透的情况。只看表面就装存，几周内容器里就会长霉。需要养成把籽粒掰成两半、检查内部是否也均匀呈干燥色的习惯，晒制的天数也要比其他豆类多留一两天余量。

### 15-2. 贮藏期间的豆象防治

&nbsp;&nbsp;&nbsp;蚕豆象（Bruchus rufimanus）是贮藏蚕豆的最大威胁。可怕之处在于它其实早在田间就已经开始了。成虫会在还长在田里的豆荚上产卵，这些卵会在贮藏仓里孵化并钻入豆粒内部。也就是说，收进来的时候虫卵就已经随之而来，半年后一整袋豆子就会变成满是孔洞的空壳。

| 方法 | 原理 | 应用方式 | 效果 |
|---|---|---|---|
| 完全密封 | 隔绝氧气使其窒息 | 装满玻璃瓶或金属罐后封口 | 最为可靠，3-4周内连虫卵和幼虫都会死亡 |
| 拌入草木灰 | 细微颗粒会刮伤外骨骼蜡质层，使虫体脱水 | 按蚕豆体积的2-5%比例混入 | 食用前需用水冲洗干净 |
| 硅藻土 | 硅质外壳会损伤虫体外骨骼 | 每1kg蚕豆用1-3g | 效果比草木灰更强，只在干燥状态下起作用 |
| 油膜涂覆 | 油膜能阻止虫卵附着与孵化 | 每1kg蚕豆加入2-5mL食用油揉搓 | 籽粒大，相对表面积用油量较少，但不可用于种子 |
| 低温处理 | 零下低温可杀死虫卵与幼虫 | 在寒冬把豆子放到室外数日后再收回 | 收回时要注意防止结露 |
| 高温处理 | 60度可杀死虫卵与幼虫 | 摊薄晒半天 | 不可用于种子 |
| 干辣椒·花椒·艾草 | 精油成分能抑制产卵 | 一层一层地铺放 | 只是辅助手段 |
| 木炭·炒盐 | 能吸收潮气 | 用布包好后放入 | 兼可防霉 |
| 埋入灰中 | 能同时获得密封与物理防治的效果 | 在瓦罐中把灰和蚕豆一层层堆叠 | 是传统上广泛使用的方法 |

&nbsp;&nbsp;&nbsp;最重要的是完全密封。虫子也需要呼吸。在密闭的容器内，豆子和虫子消耗氧气，氧气减少、二氧化碳增多，虫子就会死亡。豆子处于休眠状态，能够耐受这种条件。容器装得越满、留空越少，效果就越快。与用一个大容器相比，用多个小容器紧紧装满更好，这样做还有一个好处：万一某一个容器变质，也不会损失全部豆子。

&nbsp;&nbsp;&nbsp;油膜涂覆是印度和非洲的小规模农户长期使用的方法。每1kg蚕豆加入2-3ml食用油，用手揉搓，让每粒豆子表面都形成一层薄膜。籽粒大、相对表面积小，所以比其他豆类用油更省。这种方法只用于半年内要吃掉的部分，不可用于种子，因为油膜会妨碍呼吸，降低发芽力。草木灰要先过筛，只取细的部分，按体积的2-5%混入。这种方法虫子无法产生抗性，对人体也无害。

### 15-3. 贮藏容器与场所

| 容器 | 密封性 | 期限 | 优点 | 缺点 |
|---|:---:|---|---|---|
| 玻璃瓶 | 非常好 | 3年以上 | 能用眼睛确认内部状态 | 容量小，不能遮光 |
| 金属罐 | 非常好 | 3年以上 | 能完全阻隔老鼠和虫子 | 一旦结露，该处会变质 |
| 瓦罐 | 好 | 2-3年 | 温度变化缓慢，老鼠无法啃穿 | 笨重且易碎 |
| 厚塑料袋 | 一般 | 1-2年 | 轻便且便宜 | 会被老鼠咬破 |
| 地窖 | 好 | 2-3年 | 温度稳定且低 | 若渗水会损失全部 |

&nbsp;&nbsp;&nbsp;检查时最可靠的感官是听觉和嗅觉。把耳朵贴在容器上如果听到沙沙的响动，说明有虫子在活动；如果闻到潮闷的气味，说明霉变已经开始。若表面能看到细小的圆孔，说明豆象已经经过了一代繁殖。即便到了这个阶段，只要把全部豆子取出晒干，用水漂去空壳，再拌入灰或油重新密封，仍能保住剩下的部分。检查的基准是每两个月一次。

## 16. 烹饪与加工

### 16-1. 去皮与浸泡

| 处理 | 时间·温度 | 效果 |
|---|---|---|
| 浸泡 | 常温水中浸泡8小时以上，大粒需12小时 | 籽粒大，比其他豆类耗时更久 |
| 倒掉浸泡水 | 务必如此 | 寡糖以及部分蚕豆嘧啶苷、伴蚕豆嘧啶苷会随之流失 |
| 去皮 | 泡发后用手推搓去皮 | 能缩短烹调时间、更易消化，并减少抗营养成分 |
| 煮制 | 在沸水中煮1小时 | 去皮后可缩短至30-40分钟 |
| 检验是否熟透 | 用手指按压容易压碎 | 若中心仍硬，说明还没熟透 |

&nbsp;&nbsp;&nbsp;蚕豆种皮厚且韧，去皮在多方面都更有利。泡发后用手指一按，皮就能顺势剥下。去皮后烹调时间可缩短近一半，节省燃料，也更易消化，同时还能减少种皮中含量相对较高的蚕豆嘧啶苷和伴蚕豆嘧啶苷的摄入量。剥下的皮不要丢弃，收集起来可用作家畜饲料或堆肥。

### 16-2. 节省燃料的烹调方法

| 方法 | 燃料 | 步骤 |
|---|:---:|---|
| 去皮后煮制 | 较少 | 泡发去皮后30-40分钟即可煮熟 |
| 压力烹调 | 最少 | 将泡发的蚕豆加压烹煮15分钟 |
| 余热焖煮 | 极少 | 煮15分钟后关火，用装有稻草或稻壳的箱子或棉被包裹，放置2-3小时 |
| 炒蚕豆 | 较少 | 将泡发晒干的蚕豆不放油干炒，可直接食用 |
| 蚕豆粉 | 几乎不需要 | 炒熟磨粉存放，用水冲开食用，脂肪少，保存期长 |
| 鲜蚕豆 | 较少 | 去皮焯水，几分钟即可 |

&nbsp;&nbsp;&nbsp;炒蚕豆是地中海和中东地区广泛食用的一种形式。泡水后晒干，不放油干炒，表皮会裂开并散发香气。炒过一次后就可以直接食用，之后不再消耗燃料，密封保存可存放一两个月。但这种方法无法去除蚕豆嘧啶苷和伴蚕豆嘧啶苷，因此对有蚕豆病风险的人来说，无论采用哪种烹调方式都同样危险。

&nbsp;&nbsp;&nbsp;余热焖煮对蚕豆也很有效。只煮15分钟后放入保温箱，内部温度能维持在较高水平两个多小时，让烹煮持续进行。用装满稻草或稻壳的木箱，或用厚棉被把锅整个包起来，就是保温箱。这种方法特别适合籽粒大、需要较长时间才能熟透的蚕豆。

### 16-3. 贮藏加工

| 加工 | 步骤概要 | 保存 | 价值 |
|---|---|---|---|
| 蚕豆粉 | 炒熟后磨粉 | 密封保存3-6个月 | 烹调不需要燃料 |
| 嫩芽腌制 | 将摘心得到的嫩芽用盐腌制 | 可存数月 | 让春季野菜能保存到冬天食用 |
| 焯水晒干的鲜蚕豆 | 焯水后沥干并彻底晒干 | 可存数月 | 冬天可加入汤或粥中 |
| 蚕豆大酱 | 煮熟捣碎后像酱曲（meju）一样发酵，再浸入盐水中 | 可存数年 | 是大豆不足时的替代方案 |
| 炒蚕豆 | 泡发晒干后不放油干炒 | 密封保存1-2个月 | 既是零食也是应急食品 |

&nbsp;&nbsp;&nbsp;用蚕豆做酱，是东亚地区历史悠久的做法。将煮熟的蚕豆压碎后接上酒曲发酵，再加入盐和辣椒进行熟成。经过发酵，抗营养成分会被分解，消化率提高，加盐后可保存数年。若某年未能获得大豆而蚕豆充足，这是完全值得尝试的一条路。不过发酵同样无法彻底去除蚕豆嘧啶苷和伴蚕豆嘧啶苷。

| 2月 | 春播（中下旬）、规划田地、撒施石灰 | 土壤化冻后立即播种，晚了会碰上炎热 |
| 3月 | 为越冬植株培土、除草、检查排水沟 | 避免春雨造成积水 |
| 4月 | 开花开始、摘心、防治蚜虫、检查根瘤 | 摘心是蚕豆栽培的核心作业 |
| 5月 | 荚肥大期、集中灌溉、开始收获鲜蚕豆（越冬部分） | 这个时期的水分决定产量 |
| 6月 | 收获干籽粒（越冬部分）、收获春播鲜蚕豆、悬挂晾干 | 若预报有雨则不等完全成熟 |
| 7月 | 脱粒、精选、干燥、贮藏、茎叶还田 | 茎不要焚烧，切段覆盖即可 |
| 8月 | 管理后茬作物，检查贮藏 | 种在蚕豆原地的夏季作物会利用残留的氮 |
| 9月 | 准备秋播田地、撒施石灰、施入堆肥 | 播种前3周施石灰 |
| 10月 | 起垄、开排水沟、挑选种子 | 冬季排水决定越冬的成败 |
| 11月 | 秋播（立冬前后，韩国南部） | 以初霜前40-50天为播种日 |
| 12月 | 覆盖稻草·落叶，防兽害，检查贮藏 | 若冬季田野上只有蚕豆是绿色的，獐（河麂）就会前来 |

### 17-1. 不可忘记的五件事

| 项目 | 内容 |
|---|---|
| 蚕豆病 | 对G6PD缺乏症患者是致命的。初次食用者务必先用五六粒试吃，观察一到两天 |
| 摘心 | 开花开始后摘除顶端嫩芽，能增加产量、减少蚜虫，还能获得凉拌菜的食材 |
| 越冬播种日 | 初霜前40-50天。种得早、长得大的蚕豆反而会先死 |
| 排水 | 粗根一旦被水淹就会立刻腐烂，垄和排水沟要优先做好 |
| 茎叶 | 若不把茎、叶、根还田，蚕豆就会变成掠夺地力的作物 |
