## 5. 整地与施肥 - 氮素平衡与施肥

### 5-4. 固氮的陷阱

&nbsp;&nbsp;&nbsp;种豆能肥地这句话，已经成为农事常识。这话对了一半，也错了一半。如果不能准确理解这一点，就会出现连续几年种豆科作物的田地反而变得贫瘠的情况。

&nbsp;&nbsp;&nbsp;我们用数字来算一算。蚕豆长势良好时，1,000㎡能收获300kg干籽粒。蚕豆籽粒的蛋白质含量为26.1%，蛋白质除以6.25即可得出含氮量。26.1 ÷ 6.25等于4.18，也就是说籽粒重量的约4.2%是纯氮。300kg籽粒中所含的氮约为12.5kg，折算成每公顷则是125kg。

&nbsp;&nbsp;&nbsp;另一方面，蚕豆根瘤在条件良好时固定的氮，每公顷可达150-200kg，是豆科作物中最高的水平，也是蚕豆在施肥项目上获得SS评级的依据。条件不佳时则只有50kg。将支出与收入并列列出，情况如下。

| 项目 | 每公顷氮量 | 方向 |
|---|---|---|
| 根瘤固定量（条件良好） | 150-200kg | 输入 |
| 根瘤固定量（条件不良） | 40-80kg | 输入 |
| 随籽粒运出 | 110-140kg | 输出 |
| 留在茎叶（茎和叶）中的氮 | 40-60kg | 还田则留下，焚烧或运走则流失 |
| 留在根和根瘤中的氮 | 15-30kg | 大多留在田里 |

&nbsp;&nbsp;&nbsp;从这个表可以看出蚕豆为什么被用作绿肥作物。固定量明显高于运出量，即使只把茎叶还田，田里也仍会剩余氮素。豆类中拥有这种余量的作物并不多。但条件不好时情况就不同了。若接种失败使固定量只有40kg，还从田里运出130kg籽粒并连茎一起收走，氮素平衡必然会变成明显的负值。

> **豆科作物能养地，并不是因为它固定了氮，而是因为它把固定下来的部分氮储存在茎叶中留在了田里。一旦把这些茎叶运走，豆类就会变成掠夺地力的作物。**

&nbsp;&nbsp;&nbsp;蚕豆还有一个能扭转这一账目的选择：放弃收籽，在开花期整株翻耕入土。这样一来运出量为0，固定的氮全部留在田里。每公顷150-200kg的氮，是化肥消失的世界里任何其他方法都无法产生的量。把整块田都这样用未免可惜，但用蚕豆来救活因连续几年耕种而明显变瘦的某一块地，这种策略是完全合理的。

| 原则 | 内容 |
|---|---|
| 茎叶必须还田 | 脱粒后剩下的茎、叶和豆荚壳全部还田 |
| 不焚烧 | 焚烧会使氮以气体形式流失，只剩钾和磷留在灰中 |
| 不挖出根系 | 蚕豆的粗根和根瘤中含有相当多的氮 |
| 切成20-30cm覆盖 | 蚕豆茎粗且含水多，切段覆盖后腐解较快 |
| 选择绿肥利用 | 在开花期翻耕入土，每公顷可为田地留下150-200kg氮 |
| 喂过家畜就把粪肥归还 | 若用蚕豆茎喂过家畜，务必把该家畜的粪肥施回同一块田 |

### 5-5. 整地

| 项目 | 方法 | 灾害条件下 |
|---|---|---|
| 耕地 | 深耕20-30cm并整平 | 用铁铲翻土或用锄头刨起。根扎得深，耕得深一些更好 |
| 垄 | 高度20cm以上 | 是防止涝害的关键 |
| 排水沟 | 深度30-50cm | 越冬栽培中冬季排水尤为重要 |
| 酸度调节 | pH 6.0-7.0 | 提前在播种前3周完成 |
| 有机质 | 完全腐熟堆肥2,000-3,000kg/1,000㎡ | 蚕豆对有机质的需求在豆类中偏高 |
| 石灰 | 酸性土施150-200kg/1,000㎡ | 可用烧过捣碎的贝壳、蛋壳或草木灰代替 |

&nbsp;&nbsp;&nbsp;需要提前施石灰的原因是石灰的反应需要时间。若在播种前才施，会使局部碱性过强，伤害种子和幼根，而到真正需要的时候反应又还没充分进行。另外，如果把石灰和氮肥施在同一位置，氨会以气体形式挥发，造成氮素损失。要遵循先施石灰、两周后再施肥的顺序。如果没有石灰，可以把贝壳和蛋壳用火烤到容易碎裂，再用石臼捣碎使用。

### 5-6. 施肥量

| 肥料 | 每1,000㎡ | 折算每㎡ | 备注 |
|---|---|---|---|
| 氮 | 3-5kg | 3-5g | 只施最少量，用于根瘤发挥作用之前的初期 |
| 磷 | 10-15kg | 10-15g | 全部作基肥施用，固氮的能量代谢需要磷 |
| 钾 | 10-15kg | 10-15g | 全部作基肥施用，关系到籽粒膨大和茎的强度 |
| 堆肥 | 2,000-3,000kg | 2-3kg | 使用完全腐熟的堆肥 |
| 石灰 | 150-200kg（酸性土） | 150-200g | 播种前3周 |

> **在蚕豆栽培中控制氮肥不是为了节约，而是一种技术。施得多只会让茎叶徒长而倒伏，招来蚜虫聚集，结果豆荚反而变少。**

&nbsp;&nbsp;&nbsp;堆肥2,000-3,000kg，相比大豆的1,000kg是比较大的量。这也是蚕豆被称为高需肥作物的原因，但这里说的肥指的是有机质，而不是氮。蚕豆根粗且扎得深，株型也大，需要能够蓄水存肥的土壤结构。充分施入完全腐熟的堆肥，能使土壤变得松软，有利于粗根伸展，也能提高保水性。氮本身仍然只需最少量即可。

&nbsp;&nbsp;&nbsp;追肥原则上不需要。但如果在开花前后叶片整体呈浅黄色，且生长明显不良，这就是根瘤未能正常发挥作用的信号，此时才需要补充少量肥料。灾害情况下，最简便的替代办法是把尿液用水稀释10倍后浇在株间的土壤中，注意不要浇到叶片上，且与一次浇很多相比，更适合稀释后分多次浇灌。

### 5-7. 灾害应急替代肥料

| 替代资源 | 提供的养分 | 使用方法 | 注意 |
|---|---|---|---|
| 草木灰 | 钾、磷、钙 | 每㎡撒100-200g并混入土中 | 呈碱性。蚕豆能耐受到pH 8.0，容忍度较高 |
| 腐熟堆肥 | 综合养分、有机质 | 每㎡施2-3kg作基肥 | 是蚕豆栽培中最重要的资源 |
| 稀释尿液 | 氮、钾 | 用水稀释10倍后浇在株间土壤中 | 不要浇到叶片上，只需少量 |
| 骨粉 | 磷、钙 | 烤过捣碎后混入堆肥 | 见效较慢 |
| 鱼骨·鱼内脏 | 磷、氮 | 埋入土中腐熟后使用 | 直接埋入会被野兽刨出 |
| 贝壳·蛋壳 | 钙 | 烤过捣碎后撒施 | 用作石灰的替代品，反应较慢 |
| 落叶腐叶土 | 综合养分、有机质 | 混入土中 | 能改善保水性 |
| 稻壳·稻草 | 钾、硅酸 | 用作覆盖物覆盖，次年翻耕入土 | 兼作越冬栽培的防寒覆盖 |

&nbsp;&nbsp;&nbsp;硼元素也值得留意。蚕豆对硼有需求，缺硼会导致落花、豆荚无法坐住。蚕豆本身落花率就偏高，若再叠加缺硼，产量会大幅下降。没有化学硼砂时，把蔬菜残渣、果皮和落叶一起堆制而成的堆肥是最现实的替代方案。只用一种材料做成的堆肥，微量元素会偏缺。

## 6. 播种

### 6-1. 播种时期

| 栽培方式 | 播种时期 | 收获时期 | 适用地区 |
|---|---|---|---|
| 秋播·越冬栽培 | 立冬前后，11月上旬 | 次年5月中旬至6月中旬 | 韩国南部沿海、济州岛 |
| 春播栽培 | 2月中下旬至3月上旬 | 5月下旬至6月下旬 | 韩国中部·北部 |
| 绿肥栽培 | 秋季或早春 | 开花期翻耕入土 | 韩国全国 |

&nbsp;&nbsp;&nbsp;越冬栽培的播种时期计算有其原则。入冬前长到本叶三四片、株高10-15cm的状态最耐寒。比这更大会被冻死，比这更小则扎不下根。从预计初霜日往前倒推40-50天，就能得出播种日期。韩国南部以立冬前后、即11月初为基准，正是这一计算的结果。

> **蚕豆越冬的成败取决于播种的日期。种得早、长得大的蚕豆，反而会比种得晚、长得小的蚕豆先死。**

&nbsp;&nbsp;&nbsp;春播的适宜时期是2月中下旬。原则是土壤一化冻就播种，若拖过3月中旬，开花期就会碰上炎热天气，产量大幅下降。蚕豆春播失败的原因大多是种得太晚。因为害怕霜冻而一再拖延，结果炎热提前到来，气温连续超过25℃时，花就会直接脱落。蚕豆是能耐受零下10℃的作物，没有理由担心2月的霜冻。

### 6-2. 种子准备

| 项目 | 方法 | 灾害条件下 |
|---|---|---|
| 挑选 | 剔除有斑点、变色、皱缩、虫孔的种子 | 用手一粒一粒挑选，籽粒大，容易挑选 |
| 挑选大小 | 选用粗大、沉重的籽粒 | 放入水中，捞去漂浮的种子 |
| 浸种 | 在水中浸泡约一天 | 种皮厚，浸种效果显著，但不要超过24小时 |
| 温水消毒 | 浸入50-55℃的水中10-15分钟 | 温度过高会降低发芽力 |
| 拌灰处理 | 拌上细草木灰 | 有助于消毒和干燥，还能驱避鸟类和老鼠 |
| 根瘤接种 | 蘸上种过同菌系豆科作物的田地的土壤 | 参见5-3节，不可与消毒同时进行 |
| 发芽试验 | 用湿布包20粒种子放置数日，数出发芽的粒数 | 陈年种子务必先做此项确认 |

&nbsp;&nbsp;&nbsp;蚕豆种皮厚、籽粒大，浸种效果比其他豆类更明显。浸水一天后籽粒会明显膨胀，发芽也能提早几天。但超过24小时会因缺氧导致内部变软，种到土里后腐烂。傍晚浸种、次日傍晚播种的节奏比较合适。水量要以种子体积三倍以上为准，中途换水一次。

### 6-3. 播种方法

| 项目 | 标准 | 理由 |
|---|---|---|
| 播种深度 | 5-7cm | 籽粒大，比其他豆类种得更深，越冬栽培要更深 |
| 每穴粒数 | 1-2粒 | 籽粒大，发芽率高 |
| 行距 | 45-90cm | 确保通风与管理通道 |
| 株距 | 15-30cm | 大粒种稀植，小粒种密植 |
| 单位面积株数 | 每1㎡ 4-8株 | 株型大，比其他豆类种得更稀疏 |
| 播种方向 | 使种眼朝下斜放 | 根能直接向下伸展 |

&nbsp;&nbsp;&nbsp;蚕豆种子的一端有一道黑色或白色的带状痕迹，这就是种眼所在的位置，根从这里长出。播种时让这道痕迹朝下斜放，根就不用费力寻找方向，出苗能提早一两天。这个技巧只有在籽粒大、容易辨认方向的蚕豆上才实用。

&nbsp;&nbsp;&nbsp;播种后最大的威胁是老鼠和鸟类。蚕豆种子颗粒大、淀粉多，老鼠能在地下精准找到它们。在越冬栽培中，种子整个冬天都暴露在外，受害更严重。只要保证播种深度并给种子拌上细草木灰，就能大幅减少损失。在发芽前覆盖稻草或网也有效果，越冬栽培中这层稻草还能兼作防寒之用。

## 7. 水分管理

| 时期 | 水分管理 | 理由 |
|---|---|---|
| 播种至发芽 | 避免土壤过度干燥 | 籽粒大，需要吸收的水量也多 |
| 生长初期 | 交由自然降水 | 这个时期干燥反而能促使根扎得更深 |
| 冬季（越冬栽培） | 只需管理排水 | 冻融交替导致积水最为危险 |
| 开花期至荚肥大期 | 充分浇水，避免土壤干燥 | 是降低落花率最可靠的手段 |
| 成熟期 | 停止灌溉 | 豆荚不能干燥，还会长霉 |

&nbsp;&nbsp;&nbsp;蚕豆的水分管理，排水优先于灌溉。粗根一旦被水淹就会立刻腐烂，根瘤菌缺氧也会死亡。尤其在越冬栽培中，冬季土壤反复冻融常常导致排水沟损毁，因此即使在寒冬也要时常巡视田地，疏通水路。

| 症状 | 原因 | 处理 |
|---|---|---|
| 白天叶片萎蔫，晚上恢复 | 暂时性缺水，属于正常范围 | 保持原状即可 |
| 早上叶片仍萎蔫 | 根系无法把水分输送上来 | 需充分浇水 |
| 大量落花 | 蚕豆本身落花率就高，干旱与高温叠加会更严重 | 灌溉并覆盖，配合摘心集中养分 |
| 豆荚已坐住但籽粒偏小 | 荚肥大期缺水 | 这个时期的灌溉直接决定产量 |
| 下部叶片发黄、根系发黑 | 因过湿造成根系受损 | 疏通排水沟并培土 |
| 叶片整体呈浅黄色但并未萎蔫 | 根瘤未发挥作用导致缺氮 | 挖根检查根瘤 |
| 冬季植株上浮、根系露出 | 是霜柱使土壤隆起所致 | 踩实土壤并覆盖稻草 |

&nbsp;&nbsp;&nbsp;霜柱受害是越冬栽培中才会出现的问题。地下的水分冻结后体积增大，把土壤向上顶起，在这个过程中幼小的蚕豆连根被顶起。露出的根会干枯或冻死。冬季期间时常巡视田地，把上浮的植株用脚踩实，并用稻草或落叶覆盖5cm-10cm，能大幅减少这种损害。这层覆盖物如果到春天也不撤去，还能继续发挥抑制杂草、保持水分的作用。
