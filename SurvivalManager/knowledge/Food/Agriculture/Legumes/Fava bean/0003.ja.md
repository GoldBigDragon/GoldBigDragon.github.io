## 3. 栽培環境

### 3-1. 気温と光量

| 条件 | 限界値 | 最適値 | 外れた場合 |
|---|---|---|---|
| 発芽温度 | 5℃以上 | 15-20℃ | 8-10℃でもゆっくり発芽します |
| 生育温度 | 5-28℃ | 10-20℃ | 25℃を超えると生育が止まり病害が増えます |
| 結実温度 | 10-24℃ | 13-20℃ | 幅14℃で豆類の中では広い方です |
| 開花期の高温 | 25℃以上が数日 | - | 花と若い莢が落ちます |
| 耐寒性 | マイナス10℃まで | - | マメ科の中で最上位です。畑で越冬します |
| 越冬限界 | マイナス15℃以下が続くと枯れます | - | 韓国中部の内陸では越冬が難しいです |
| 日照 | 1日6時間以上 | 1日8時間以上 | 40%遮光で収量が半分に落ちます |

> **ソラマメを他の豆類と分ける唯一の数値はマイナス10℃です。この一点のおかげでソラマメは冬の畑を使うことができ、春にもっとも早く食べ物を差し出します。**

&nbsp;&nbsp;&nbsp;ソラマメの耐寒性には条件があります。冬を越す前に大きく育ちすぎると、むしろ凍死します。本葉が3-4枚、高さ10-15cmの状態が最も耐えます。そのため秋播種は初霜から40-50日前を目安にします。韓国南部で立冬のころ、つまり11月初めが基準になる理由です。9月に播くと冬前に膝の高さまで育って凍死し、12月に播くと根を張る前に凍った土に閉じ込められます。

&nbsp;&nbsp;&nbsp;韓国中部の内陸では越冬がおおむね失敗します。マイナス15℃が何日も続く地域ではソラマメも枯れます。そうした場所では2月中下旬の春播種にします。韓国南部の海岸と済州島では越冬栽培が安定しており、韓国中部の西海岸と南部の内陸は年によって変わります。確信が持てない場合は、秋播きと春播きに分けて植え、リスクを分散します。

### 3-2. 土壌と水

| 条件 | 限界値 | 最適値 | 備考 |
|---|---|---|---|
| 土性 | 砂質土から埴質土まで | 排水の良い砂壌土 | 水が溜まる土地が最も悪いです |
| pH | 5.5-8.0 | 6.0-7.0 | 酸性土では根粒が減ります |
| 有効土層深 | 40cm以上 | 60cm以上 | 直根が深く入ります |
| 作期蒸発散量 | - | 約450mm | 豆類の中では中程度です |
| 浸水 | 1日以上浸かると根が傷みます | - | 湿害に非常に弱いです |
| 地下水位 | 50cm以下 | 80cm以下 | 冬の畑の水管理が重要です |

&nbsp;&nbsp;&nbsp;ソラマメは湿害に極端に弱いです。根が太く深く入りますが、その太い根が水に浸かるとすぐに腐ります。しかも根粒菌は酸素を必要とする好気性細菌なので、畑が一日浸かるだけで根より先に根粒が機能を失います。越冬栽培ではこの問題がさらに厄介です。冬に凍結と融解を繰り返して土が浮き上がり、水の通り道がふさがるためです。畝を20cm以上高くし、排水路を深く掘ることは、ソラマメにおいては選択ではなく前提です。

&nbsp;&nbsp;&nbsp;土壌の酸度に対してはエンドウより許容範囲が広いです。pH5.5から8.0まで耐え、6.0-7.0が最適です。ただしこの範囲も、植物自体よりむしろ根粒菌の要求によるものです。pH5.5より下がるとソラマメ自体は何とか育ちますが、細菌が生きられず窒素固定が止まり、葉が薄い黄色を帯びます。韓国の畑は降雨が多く総じて酸性に傾きがちなので、石灰処理は施肥より先に行うべき作業です。

## 4. 品種

### 4-1. 用途による分類

| タイプ | 種子の大きさ | 特徴 | 適した状況 |
|---|---|---|---|
| 大粒食用種 | 一粒2g以上 | 粒が大きく収量が多いです | 食用と貯蔵の基本です |
| 小粒在来種 | 一粒0.7-1.5g | 粒が小さく寒さと不良な土に強いです | 畑が悪い、または冬が寒い場所 |
| 緑肥・飼料用 | 無関係 | 茎と葉の生産量が多いです | 畑を生き返らせることが目的のとき |
| 早生種 | 無関係 | 生育期間が短いです | 春播種で暑さを避けたいとき |

&nbsp;&nbsp;&nbsp;ソラマメは韓国で正式に登録された品種が実質的にありません。1980年代初頭まで一部地域で栽培されていた在来系統が残っており、最近になって韓国国内で育成された品種が出た程度です。ウォンジャム1号のような放射線育種系統が知られていますが、種子の流通は限られています。市場で入手できるものは大抵輸入種子か、家庭菜園用に少量流通しているものです。

&nbsp;&nbsp;&nbsp;したがって、ソラマメを計画に入れるなら、あらかじめ種子を確保し自家採種でつないでいくのが唯一の道です。幸いソラマメは粒が大きいため一株から採れる種子の重量がかなりあり、常温密閉で3年もちます。最初の数年は収量を期待せず、種子を増やすことに集中するのが合理的です。その地域で冬を越した個体を選んでつないでいけば、数年のうちにその土地に合った系統ができあがります。

### 4-2. 状況別の選び方

| 状況 | 優先順位 | 理由 |
|---|---|---|
| 冬が寒い | 小粒在来種 | 粒が小さいほど越冬力が高い傾向があります |
| 畑を生き返らせたい | 緑肥用またはどの系統でも | 開花期に丸ごとすき込みます |
| 種子が足りない | 小粒種 | 同じ重さでずっと広い面積に播けます |
| 貯蔵食料が必要 | 大粒食用種 | 同じ労働でより多くの重量を収穫できます |
| 春しか播けない | 早生種 | 暑さが来る前に終える必要があります |
| 種子を初めて確保した | どれでもよい | 最初の2-3年は採種に集中します |

&nbsp;&nbsp;&nbsp;ソラマメの種子の大きさは播種量を大きく左右します。一粒2gの大粒種で100m²を播くには、小粒種の2-3倍に相当する重さが必要です。種子が貴重な最初の年には、小粒種や中粒種の方がずっと広い面積をカバーできます。

## 5. 畑の準備と肥料 - 根粒菌

### 5-1. 窒素固定はどのように起こるか

&nbsp;&nbsp;&nbsp;空気の78%は窒素です。人の頭上に無限の窒素が浮かんでいても、植物はそれを使うことができません。空気中の窒素は窒素原子二つが三重結合でしっかり結びついた分子であり、この結合を切るのに莫大なエネルギーが必要だからです。工業的にこの結合を切ってアンモニアを作るのがハーバー・ボッシュ法で、世界の窒素肥料はそこから作られます。高温と高圧と触媒、そして大量の化石燃料が必要です。

&nbsp;&nbsp;&nbsp;根粒菌はこの仕事を常温常圧でやってのけます。ニトロゲナーゼという酵素で三重結合を切り、窒素をアンモニアに変えます。ただし代償があります。この反応には多くのエネルギーが必要で、細菌自身は光合成をできません。そこでマメ科植物の根の中に入り込んで暮らし、植物が光合成で作った糖をもらい、その代わりに固定した窒素を渡します。これは取引の関係です。

&nbsp;&nbsp;&nbsp;ソラマメと組む菌はRhizobiumLeguminosarum bv. viciaeです。エンドウ、レンズマメ、野生のカラスノエンドウと同じ菌で、ダイズのBradyrhizobium japonicumとは別の種です。この点が実用面で重要です。ダイズを栽培した畑の土をソラマメの種子に付けても効果がありません。一方、エンドウやレンズマメやカラスノエンドウを栽培した畑の土は、そのままソラマメの接種源になります。

| 段階 | 起こること |
|---|---|
| 1. 信号交換 | ソラマメの根がフラボノイドを分泌し、土の中の細菌がその信号に応じてNodファクターを出します |
| 2. 感染 | 根毛が内側に曲がって細菌を包み込み、細菌が感染糸をたどって根の中に入ります |
| 3. 根粒形成 | 根の内側の細胞が分裂して根粒がふくらみ、その中に細菌が定着します |
| 4. 窒素固定 | 根粒の中でニトロゲナーゼが働き、空気中の窒素をアンモニアに変えます |
| 5. 分配 | アンモニアがアミノ酸に変わり、茎と葉と莢へ運ばれます |
| 6. 老化 | 登熟期に入ると根粒が機能を失い、根とともに土に還ります |

&nbsp;&nbsp;&nbsp;ニトロゲナーゼは酸素にとても弱く、酸素が触れるとすぐに機能を失います。そのため根粒の内側にはレグヘモグロビンという赤い色素タンパク質が詰まっていて酸素を捕まえておき、酵素の周りの酸素濃度を極端に低く保ちます。人の血が赤いのと同じ原理で、根粒を割ったときに内側が赤や桃色をしているのはこの色素です。この事実は実用面でとても重要です。赤い色は、その根粒がいま窒素を固定しているという目に見える証拠だからです。

&nbsp;&nbsp;&nbsp;ソラマメの根粒は他の豆類より大きく目立ちます。太い直根の上部に豆粒ほどの大きさの根粒がいくつも束になって付くことが多く、確認しやすいです。ソラマメが施肥でSSを受け、窒素固定がマメ科最上位と評価されるのは、この構造的特徴と無関係ではありません。

### 5-2. 根粒ができたかを確認する方法

&nbsp;&nbsp;&nbsp;接種をしたかどうかにかかわらず、根粒が実際にできているかを確認することは必ずやるべきです。確認しなければ窒素不足の原因が分からず、翌年に同じ間違いを繰り返すことになります。

| 順序 | 内容 |
|---|---|
| 1 | 開花が始まるころ、播種後8週ほどが最も良い時期です |
| 2 | 健康そうな株を二、三株選びます |
| 3 | 引き抜かず、スコップで株の周りを広く掘り、土ごと持ち上げます。引き抜くと細根の根粒が土に残ります |
| 4 | バケツに入れて土をそっと洗い流します |
| 5 | 直根と太い細根に付いた根粒の数を数えます |
| 6 | 根粒をいくつか爪で割って内側の色を見ます |

| 観察結果 | 意味 | 対応 |
|---|---|---|
| 根粒が株当たり20個以上、特に直根の上部に集まっている | 接種がうまくいきました | そのままにします |
| 割った内側が赤や桃色 | 窒素を固定しています | 良い状態です |
| 割った内側が白や薄緑色 | 根粒はできたが固定していません | 酸度、湿害、リン酸不足を確認します |
| 割った内側が茶色や黒色 | すでに老化したか死んでいます | 登熟期なら正常、開花期なら問題です |
| 根粒が5個以下 | 接種が失敗しました | 葉が黄色ければ窒素を補います |
| 根粒が細根の先端だけに小さく多数付いている | 土着菌に感染したが効率が低いです | 翌年に接種源を変えます |

> **根を掘り出し、根粒を割って赤い色を確認するこの一つの習慣が、窒素肥料のない世界で豆作りの成否を教えてくれる最も確かな手がかりです。**

&nbsp;&nbsp;&nbsp;根粒の位置も情報になります。直根の上部、地表から10cm以内に付いた太い根粒が最も効率が高いです。接種がうまくいったときにできる位置です。反対に直根にはなく、細根の先端だけに小さな根粒が散らばっている場合は、土に元からいた土着菌が遅れて感染したことが多く、固定の効率は落ちます。

### 5-3. 接種源をどこで手に入れるか

&nbsp;&nbsp;&nbsp;市販の接種剤は、生きた細菌をピートや粘土に詰めて売る製品です。災害の状況では手に入りません。しかし根粒菌は土に住む身近な微生物であり、同じ菌と共生するマメ科を栽培した畑の土が、そのまま接種源になります。ソラマメは韓国内での栽培歴が少なく、土着菌がいない畑が多いため、接種の重要性が他の豆類より大きいです。

| 方法 | 手順 | 効果 | 注意 |
|---|---|---|---|
| 同じ菌系統の畑の土を付ける | ソラマメ、エンドウ、レンズマメ、カラスノエンドウを植えて根粒がよくできていた畑から、表土5-15cmの深さの土をすくってきます。種子を水で軽く湿らせてこの土を付け、すぐに播きます | 最も確実で費用がかかりません | 病気の畑の土は病原菌も一緒に運びます |
| 野生のカラスノエンドウの根 | 春に野原や畑のあぜのカラスノエンドウを掘り出して根粒を確認します。根粒が赤ければ、その土と根を一緒に使います | ソラマメの栽培歴がない地域で最も現実的です | 固定効率が栽培用系統より低い場合があります |
| 根粒そのものを使う | 掘り出した根の根粒を集めてすりつぶし水に溶かし、その水に種子を浸けてから取り出します | 菌の密度が最も高いです | 根粒を掘り出したその日のうちに使う必要があります。乾くと菌が死にます |
| 土を畑にまく | 播種する筋に運んできた土をまき、一緒にすき込みます | 菌が土に広がります | 10㎡当たりスコップ一杯程度が目安です |
| 根の残りを残す | 収穫時に茎だけを刈り、根は畑に残します | 翌年まで菌が土に残ります | 最も手間のかからない維持方法です |

&nbsp;&nbsp;&nbsp;接種する際には必ず守るべきことがあります。根粒菌は直射日光と乾燥と熱に非常に弱いです。紫外線を数分受けるとかなりの数が死に、乾けばさらに早く死にます。種子に土を付ける作業は日陰で行い、土を付けた種子は日に当てず、すぐに播きます。30分以内に播くのが望ましく、遅くとも数時間以内に終えます。もう一つ、種子消毒と接種は同時にできません。殺菌剤を付けた種子に土を付けると細菌が死にます。温水処理で消毒した場合は、完全に冷ましてから接種します。

| 接種失敗を招く条件 | 理由 |
|---|---|
| 土壌pH5.5以下 | 細菌が生きられません |
| 窒素肥料を十分に与えた畑 | 植物が取引の必要を感じず、根粒形成を自ら減らします |
| 水が溜まる畑 | 好気性細菌のため酸素がないと死にます |
| リン酸が不足した畑 | 窒素固定には多くのエネルギーが必要で、その代謝にリン酸が使われます |
| モリブデン・鉄・コバルトの欠乏 | ニトロゲナーゼの構成成分です |
| 接種した種子を日に当てて乾かす | 紫外線と乾燥で菌が死にます |
| ダイズ畑の土を使う | 菌の種が異なり、ソラマメには感染しません |
