## 8. 栽培管理 - 支柱与摘心

### 8-1. 支柱

&nbsp;&nbsp;&nbsp;对蔓生型菜豆而言，支柱不是可选项。能长到2-3m的藤蔓如果找不到可以攀附的东西，就会相互缠绕倒伏在地，随后叶片重叠遮光、通风受阻，炭疽病蔓延，豆荚接触泥土而腐烂。

| 方法 | 材料 | 特点 |
|---|---|---|
| A字支柱 | 长杆3-4根 | 上端绑成三角形立起。抗风能力强 |
| 网架引蔓 | 木桩和网 | 产量最高。有网的话是最佳选择 |
| 绳架引蔓 | 木桩和绳 | 在木桩之间分多层拉绳 |
| 玉米秆 | 玉米 | 完全不需要额外材料。三姐妹种植法 |
| 插树枝 | 细枝 | 只适合短蔓型 |

> **藤蔓最适合缠绕的支撑物直径在2cm左右，太粗的柱子缠不上去。如果只立起粗木桩，藤蔓会因为抓不住任何东西而倒伏在地。**

&nbsp;&nbsp;&nbsp;搭设的时机很重要。要在播种前或长出一两片真叶时立好。如果等藤蔓已经长大后再打桩，会切断浅层扩展的根系，藤蔓也会折断。提前立好支柱，藤蔓会自己找到并顺着爬上去。

&nbsp;&nbsp;&nbsp;三姐妹种植法是不花材料就能获得支柱的方法。先种玉米，长到膝盖高度后在其根部种下菜豆，再在两种作物之间的空地上种南瓜。玉米充当支柱，菜豆分给它氮素，南瓜的叶子覆盖地面，抑制杂草并保住水分。不过要记住，菜豆是在40%遮光下产量会降到一半的作物。如果玉米种得太密，菜豆就会被埋在阴影里。要把玉米的行距拉宽，并让行朝南北方向排列，避免阴影长时间停留在一侧。

### 8-2. 摘心

| 次数 | 时期 | 方法 | 效果 |
|---|---|---|---|
| 第1次 | 真叶3-5节 | 摘除茎顶端的生长点 | 侧枝增多 |
| 第2次 | 新长出的枝条3-5节 | 再次摘除生长点 | 花和豆荚增多 |
| 停止 | 开花开始后 | 不再进行 | 开花后摘心会降低产量 |

&nbsp;&nbsp;&nbsp;摘心对直立型菜豆效果特别显著。原本向上生长的力量转向两侧，侧枝增多，能开花结荚的节数也增加。蔓生型的目的是向上生长，所以只在藤蔓爬到支柱顶端时摘一次即可。

&nbsp;&nbsp;&nbsp;不过并非在任何情况下都有好处。在贫瘠地里生长本就不佳的菜豆上摘心，会因为没有恢复的力气而使产量更低。巡视田地时，如果叶色浓绿、节间舒展就摘心，如果叶色浅淡、株高停滞不前就任其自然生长。开花之后则不再摘心，因为开花后的生长点不再用于长高，而是新豆荚着生的位置。

### 8-3. 间苗与除草

| 作业 | 时期 | 方法 |
|---|---|---|
| 第1次间苗 | 真叶1-2片 | 只清理过于密集的地方 |
| 第2次间苗 | 真叶3-4片 | 每穴留1-2株 |
| 第1次除草 | 播种后2-3周 | 浅浅地锄。根系浅，锄得太深会切断根 |
| 第2次除草 | 开花前 | 此后不再进入田里 |

&nbsp;&nbsp;&nbsp;菜豆的根系是浅层扩展的。锄头挖得太深会切断细根，反而使生长变差。要把锄头放平，只刮松地表2cm，靠近植株根部的杂草则用手拔。培土通常不是必需的，但如果根基部松动摇晃，就轻轻培一层土。

## 9. 病虫害

&nbsp;&nbsp;&nbsp;菜豆的病虫害压力为C。无防治减产率估计为48.9%，是大豆的两倍以上。其中炭疽病是菜豆最具代表性的病害，会通过种子传播，年年延续。

### 9-1. 主要病害

| 病名 | 症状 | 发生条件 | 无药防治 |
|---|---|---|---|
| 炭疽病 | 叶脉、茎和豆荚上出现暗红色溃疡，豆荚上的凹陷斑点是其特征 | 高温多湿。种子传播 | 种子筛选和温水消毒是关键。3-4年轮作，确保通风，焚烧病残体 |
| 霜霉病 | 叶片正面出现黄斑，背面出现灰白色霉层 | 多湿 | 保证种植间距，排水，波尔多液 |
| 菌核病 | 茎变软，出现白色棉絮状菌丝和黑色菌核 | 凉爽潮湿条件 | 把病株连根挖出焚烧。避免密植 |
| 紫斑病 | 叶片和豆荚上出现紫色斑点 | 多湿 | 确保通风，轮作 |
| 病毒病 | 叶片出现花叶斑驳并皱缩 | 由蚜虫传播 | 无法治疗。拔除焚烧，减少蚜虫 |
| 根腐病 | 茎基部和根变褐软化 | 过湿，连作 | 排水，加高垄台，轮作 |

> **炭疽病会随种子延续到下一年。从豆荚上有凹陷暗红斑点的植株上采下的种子，本身就是下一年的病源。在留种阶段就把它筛选出来，是最省钱的防治办法。**

&nbsp;&nbsp;&nbsp;应对炭疽病有先后顺序。第一，种子筛选：把有斑点的种子一粒一粒挑出丢弃，再进行温水消毒。第二，轮作：病原菌会留在残体中并在土壤里存活多年，因此要空出3-4年。第三，通风：保持种植间距、立好支柱，让叶片尽快干燥。第四，雨后不进入田地：人碰到湿叶会把孢子传播到全田。第五，病残体不归还田地，一律焚烧。

### 9-2. 主要害虫

| 害虫 | 危害 | 无药防治 |
|---|---|---|
| 蚜虫 | 吸食汁液并传播病毒病 | 把肥皂水(1L水配20g无香皂)喷在叶背。保护瓢虫 |
| 蝽象类 | 刺入豆荚吸食汁液，形成秕粒 | 清晨有露水时用手抓入水桶 |
| 螨类 | 在叶背吸食汁液，使叶片出现黄斑 | 干燥时会增多。用水用力喷洒叶片 |
| 根结线虫 | 根部形成瘤状变形，生长不良 | 3-4年轮作，间种万寿菊 |
| 菜豆象 | 在田间于豆荚上产卵，储藏期蛀食籽实 | 储藏管理是关键，参见第15节 |
| 鸟类(鸽子·喜鹊·野鸡) | 发芽后立即啃食子叶 | 发芽前用稻草或网覆盖 |
| 地下害虫(蛴螬·地老虎) | 啃食播下的种子和幼茎 | 种子沾裹木灰，早晨在被咬断的植株周围挖找 |

### 9-3. 无药防治资材

| 资材 | 制作方法 | 对象 | 注意 |
|---|---|---|---|
| 波尔多液 | 100L水中分别溶解1kg硫酸铜和1kg生石灰后混合 | 预防炭疽病、细菌病 | 需要有铜才能制作。混合后立即使用。是预防而非治疗 |
| 肥皂水 | 1L水配20g无香皂 | 蚜虫、螨类 | 中午高温时喷洒会烧伤叶片 |
| 撒干灰 | 在有露水的早晨给叶片撒细灰 | 食叶虫、驱避霉菌 | 兼具补钾作用 |
| 草木灰水 | 1升灰泡入10L水中一夜，取上层清液使用 | 抑制霉菌 | 呈碱性，须稀释使用 |
| 木醋液 | 将烧炭时产生的液体稀释300-500倍 | 驱避、促进生长 | 原液强酸性，必须稀释 |
| 辣椒·大蒜水 | 磨碎后用水浸泡过滤使用 | 驱避 | 效果不持久，需经常喷洒 |
| 牛奶稀释液 | 牛奶用水稀释5-10倍 | 白粉病、螨类 | 剩余会变质发臭 |

### 9-4. 农艺防治

| 方法 | 原理 |
|---|---|
| 种子筛选 | 炭疽病通过种子传播。仅挑出斑点和变色的种子就能大幅减少发生 |
| 温水消毒 | 50-55℃处理10-15分钟，杀死种子表面的病原菌 |
| 3-4年轮作 | 等待炭疽病菌和线虫在土壤中减少 |
| 支柱与种植间距 | 通风良好则叶片干得快，霉菌难以立足 |
| 排水 | 菜豆的多数病害都与过湿有关 |
| 分批播种 | 间隔2周分批种植，分散风险 |
| 雨后禁止进入田地 | 人碰到湿叶会使炭疽病扩散到全田 |
| 残体处理 | 病残体必须焚烧。只有健康的残体才归还田地 |

## 10. 营养缺乏与过量

| 症状 | 原因 | 天然材料对策 |
|---|---|---|
| 从下部叶片开始整株淡黄，个体矮小 | 氮缺乏。根瘤发育不良是常见原因 | 先挖根查看根瘤。如果没有根瘤，少量施用10倍稀释的尿液 |
| 叶缘变褐干枯 | 钾缺乏 | 在植株之间撒草木灰并轻轻锄入土中 |
| 生长迟缓，叶片带紫色 | 磷缺乏 | 骨粉、烤过的鱼骨粉、草木灰 |
| 开花后不结荚 | 硼缺乏，或超过30度的高温 | 混合多种材料的堆肥。在垄沟灌水以降低地温 |
| 叶脉之间发黄 | 镁或铁缺乏 | 停止使用草木灰。用腐叶土和完熟堆肥增加有机质 |
| 新叶细小畸形，生长点枯死 | 钙或硼缺乏 | 烤过的蛋壳粉、贝壳粉 |
| 只有叶片浓绿茂盛而豆荚稀少 | 氮过量 | 立即停止供氮。用摘心引导侧枝生长 |
| 下部叶片发黄脱落 | 梅雨季湿害 | 挖排水沟。这不是肥料问题 |

&nbsp;&nbsp;&nbsp;菜豆叶片发黄的症状原因众多，需要仔细区分。从下部叶片开始逐渐变黄、个体矮小的是氮缺乏。梅雨过后下部叶片一起发黄脱落的是湿害。叶脉仍是绿色、只有叶脉之间发黄的是镁或铁缺乏。由于对策各不相同，在急着施肥之前应先仔细观察症状的形态。

&nbsp;&nbsp;&nbsp;微量元素缺乏很难逐一应对。没有化肥，实际上没有办法获取钼或钴。不过，把菜叶果皮、蛋壳、鱼骨、落叶、杂草和草木灰混在一起腐熟制成的堆肥，各种微量元素都齐全。"堆肥堆里什么都能放"这个原则就是现实可行的策略。

## 11. 间作与轮作

### 11-1. 搭配

| 相性 | 作物 | 理由 |
|---|---|---|
| 好 | 玉米·南瓜 | 三姐妹种植法。互相提供支柱、氮素、地面覆盖 |
| 好 | 万寿菊 | 根系分泌物能抑制线虫 |
| 好 | 生菜·菠菜 | 覆盖地面保持水分。养分竞争较少 |
| 好 | 马铃薯 | 彼此病害不重叠 |
| 一般 | 结球甘蓝·大白菜类 | 种在菜豆之后可利用残留的氮素 |
| 注意 | 番茄·辣椒·茄子 | 可能共享病虫害 |
| 差 | 大蒜·洋葱类 | 有报告称其分泌物会抑制根瘤菌 |
| 差 | 与其他豆科连作 | 炭疽病和线虫会累积 |

&nbsp;&nbsp;&nbsp;这里把三姐妹种植法写得更具体一些。先按30cm间距种下玉米，等玉米长到膝盖高度后，在每株根部约10cm外的位置种下两三粒蔓生型菜豆。在玉米行与行之间宽阔的空地上稀疏地种下南瓜。菜豆的藤蔓缠绕玉米向上生长，南瓜的叶子覆盖地面。玉米需要大量氮素，菜豆供给其中一部分；南瓜宽大的叶片抑制杂草、防止水分蒸发，带刺的茎还能阻碍兽类靠近。

&nbsp;&nbsp;&nbsp;这种配置有一点需要注意，那就是光照。菜豆在40%遮光下产量会降到一半。玉米种得太密，菜豆就会被埋在阴影里，只顾着抽长藤蔓而不结荚。玉米的行距要比常规种植拉得更宽，并让行朝南北方向排列，避免阴影长时间停留在一侧。

### 11-2. 轮作

| 项目 | 标准 |
|---|---|
| 休作期间 | 3-4年。韩国农村振兴厅3年休作组 |
| 理想周期 | 4年 |
| 连作障碍 | 炭疽病和根结线虫累积 |

| 4年轮作示例 |
|---|
| 第1年：菜豆(与玉米·南瓜同种) |
| 第2年：叶菜或葱类 |
| 第3年：根菜或谷物 |
| 第4年：马铃薯或甘薯 |
| 再次种菜豆 |

&nbsp;&nbsp;&nbsp;这里写下地块狭小、没有余地轮作时的折中办法。把地块分成四块，每年轮换一块种菜豆，是最简单的方式。如果地块小到无法分区，至少每年要挪动菜豆种植行的位置。仅仅把去年种菜豆的行改种马铃薯、去年种马铃薯的行改种菜豆，就能相当程度地延缓炭疽病和线虫的累积。

## 12. 收获与脱粒

### 12-1. 收获时期判断

| 用途 | 收获时期(播种后) | 判断标准 |
|---|:---:|---|
| 带荚食用(嫩荚用) | 45-55天 | 豆荚仍柔软，内部籽粒还小时 |
| 鲜菜豆 | 约60天 | 豆荚饱满、籽粒变粗但仍是绿色时 |
| 干籽实(早熟直立型) | 70-80天 | 豆荚变黄干燥、籽粒变硬时 |
| 干籽实(晚熟蔓生型) | 100-130天 | 从下方开始依次成熟 |
| 收获判定 | 豆荚7-8成变干并转为褐色时 | |

&nbsp;&nbsp;&nbsp;蔓生型菜豆是从下往上依次成熟的。下部豆荚全干的时候，上部可能还留有花。从下方依次采摘的话，植株会持续开出新花，使收获期延长；如果放着不管，就会停止开花。直立型成熟比较整齐，一次性割下收获损失也较小。

> **如果有下雨的预报，不要等到完全成熟就收获。干豆荚被雨打湿又反复晒干后会裂开，籽粒掉落在地，潮湿的豆荚还会长霉。**

### 12-2. 收获与干燥

| 顺序 | 内容 |
|---|---|
| 1 | 选晴朗干燥的日子，等露水干后进行 |
| 2 | 从下方豆荚开始采摘，直立型则用镰刀齐根割下 |
| 3 | 根部留在田里 |
| 4 | 带荚在阳光下晒4-5天 |
| 5 | 脱粒后再在阴凉处晾5-7天 |

> **脱粒后的菜豆如果放在阳光直射下晒，会变红褪色、品质下降。带荚晒干时用阳光，取出籽粒后则必须放在阴凉处晾干。**

&nbsp;&nbsp;&nbsp;这两段式干燥对菜豆尤为重要。豆荚厚实坚硬，需要晒太阳才容易裂开，但皮薄色鲜的籽粒一旦暴露在强烈阳光下，就会褪色或变红，种皮开裂。开裂的种皮会成为储藏期间害虫最先钻入的通道。原则是摊薄放在通风的阴凉处慢慢晾干。

### 12-3. 脱粒 - 不用工具的方法

| 方法 | 工具 | 步骤 | 效率 |
|---|---|---|---|
| 踩踏麻袋 | 厚麻袋或口袋 | 把干豆荚装入袋中，扎紧口后用脚踩踏 | 少量时最方便。籽粒不会飞溅 |
| 打谷连枷 | 长柄绑鞭条的工具 | 铺开草席，将豆荚摊薄后从上方敲打 | 适合中等规模。用力过猛会打碎籽粒 |
| 棍棒敲打 | 木棒 | 装入袋中或摊在草席上敲打 | 没有连枷时的替代方法 |
| 手剥 | 无 | 扭开豆荚 | 籽粒大所以速度快。适合留种用 |
| 敲击木桶 | 木板或木桶 | 抓住一束朝桶内壁敲打 | 籽粒集中在桶内，损失较少 |

&nbsp;&nbsp;&nbsp;菜豆籽粒大，用力敲打容易破碎。破碎的籽粒储藏期间会先被虫蛀，也不能用作种子。装入袋中用脚踩的方式损失最少；使用连枷时，放轻力道多打几次比较好。留种用的部分，用手剥开最为可靠。

### 12-4. 精选 - 借风筛选

| 方法 | 原理 | 步骤 |
|---|---|---|
| 扬风 | 籽粒重，皮壳和碎屑轻 | 起风的日子，装入簸箕或大容器高举缓缓倾倒 |
| 簸筛 | 上下晃动向前颠簸 | 重的籽粒留在后面，轻的被推到前面 |
| 扇风 | 一人倾倒，一人用扇子扇风 | 用于没有风的日子 |
| 过筛 | 按孔径大小分开 | 筛掉破碎籽粒和碎屑 |
| 水浮法 | 秕粒和虫蛀粒较轻 | 倒入水桶，捞去浮起的部分。当天要再晒干 |
| 手工挑选 | 用眼睛看 | 籽粒大，容易辨认出炭疽病斑点 |

&nbsp;&nbsp;&nbsp;菜豆一定要在最后加上手工挑选这一步。因为籽粒大，感染炭疽病的种子上暗红色的斑点很容易看清楚。这一道目检能大幅减少来年田里的病害。在明亮的地方铺在白布上查看，斑点会格外清晰。
