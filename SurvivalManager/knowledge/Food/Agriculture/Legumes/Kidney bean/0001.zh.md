## 引言
&nbsp;&nbsp;&nbsp;菜豆（Phaseolus vulgaris）原产于中南美洲，由墨西哥和安第斯山区的野生豆驯化而来，是豆科一年生草本，与玉米、南瓜一起构成了美洲原住民农耕的三大支柱。早熟直立种从播种起70-80天可收干豆，60天可收青菜豆。种子在全国任何地方都能弄到，自花授粉所以纯系得以保持。综合等级为C（40.7分，有效183种中第107名），短期D（39.1）、长期C（42.3），副食为SS（61.4分）。单位面积热量为D，每㎡ 696kcal，仅为自给线的0.27倍，再加上耐寒性D和烹调·加工D，所以它的位置是做配菜，而不是主食，以及与玉米同田搭配。首先必须读的是第10节。

> **只要四五粒生菜豆或没煮透的菜豆，几个小时内就会出现严重的呕吐和腹泻。更危险的是，用80℃左右的低温加热，毒性反而会升到生豆的五倍之多。必须先在水中泡五个小时以上，倒掉泡豆水，再在翻滚的100℃下至少煮10分钟以上才安全。**

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | C | 40.7 |
| 短期 | D | 39.1 |
| 长期 | C | 42.3 |
| 副食 | SS | 61.4 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：施肥、设施负担、耐储性。S：蛋白质密度、微量营养素、口味、国内种植普及度、自留种。A：水消耗量、无合成投入产量保持率、产量稳定性、种子寿命。B：收获速度、防治自立度、连作适应性 |
| 劣势 | D：单位面积热量、持续性、光照、烹调·加工要求度、耐寒性、整地·挖掘能量、非食用价值。C：温度幅度、病虫害压力 |

> **菜豆的位置不在单作，而在搭配。以玉米秆作支柱向上攀缘，不用支柱材料，也不用额外的面积，一小块田里就能多产出蛋白质。**

&nbsp;&nbsp;&nbsp;国内种植普及度S在实际中最有价值：弄到种子之后可以靠自留种继续种，干豆常温下可保存3年。蛋白质密度S和微量营养素S是副食SS的依据。烹调·加工D对菜豆来说不是不方便，而是安全问题。耐寒性D和温度幅度C使栽培期变窄，所以要在晚霜结束后播种，连作适应性B属于休耕3年组。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 豆科菜豆属一年生草本。原产于从墨西哥到安第斯的中南美洲，自花授粉 |
| 叶、茎 | 三小叶一组的三出复叶，心形。蔓生型可缠绕攀升到2-3m，直立型长到40-60cm就停止 |
| 根、花 | 笔直的主根上细根分布较浅，并有根瘤。花为白色、淡粉色或紫色的蝶形花 |
| 荚、籽粒 | 圆筒形或扁平，长10-20cm，每荚4-10粒。籽粒呈肾形而大，有白色、黑色、花斑、红色 |

&nbsp;&nbsp;&nbsp;子叶出土并储存着初期养分，所以鸟啄掉子叶后这棵苗通常会死，发芽后的头十天最危险。干籽粒每100g热量348kcal，蛋白质21.01g（占热量的24.1%），脂肪0.5-1.5g，膳食纤维24.4g，糖类3.32g，维生素B1 0.48mg，钙、铁、镁丰富，黑菜豆含有花青素。蛋白质赖氨酸充足、蛋氨酸略缺，与性质相反的玉米一起吃就能互补。籽粒大而呈肾形，热量要很久才能传到中心，外面煮软而里面还硬的状态最危险。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽10℃以上（最适26-30℃）。生长10-30℃（最适15-21℃），5℃以下停止。结实18-28℃，幅度只有10℃。开花期30℃以上持续几天，花和嫩荚就会脱落。没有耐寒性，遇霜即死 |
| 水、土壤 | 保水且排水良好的沙壤土-壤土，pH 5.5-7.5（最适6.0-7.0），有效土层30cm以上（最适50cm）。生育期蒸散量约400mm。根分布浅，既怕涝又怕旱，被水淹一天以上根就受伤 |

&nbsp;&nbsp;&nbsp;4月播种的话开花期在6月初，正好躲过雨季；5月底播种则会遇上7月底的酷暑，所以春播有利，夏播只有在高寒地才稳定。

| 类型 | 株高、支柱 | 特点 |
|:---|:---|:---|
| 直立型 | 40-60cm，不需要 | 生育50-80天。收获快、省事，但收获期短 |
| 蔓生型 | 2-3m，必须 | 生育100-130天。收获期长，单位面积产量高 |

&nbsp;&nbsp;&nbsp;没有支柱材料就选直立型，与玉米同种就选蔓生型；直立型在6月下旬-7月先收，蔓生型在7-9月长期收获，所以两者都备，就不会因一次灾害而全部损失。连荚吃的食荚型豆粒鼓起后凝集素也会增多，所以成熟的荚要充分煮熟。杂交一代的种子来年性状会分离，所以要选固定品种或地方品种。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 深耕20-30cm，垄高15-20cm以上，排水沟深30cm以上。充分腐熟的堆肥1,500-2,000kg/1,000㎡（为土壤结构提供有机物） |
| 施肥（1,000㎡） | 氮4-6kg（多了只长叶、荚减少），磷7-10kg，钾6-8kg（均作基肥），酸性土施石灰（播种前3-4周）。替代资源有草木灰（每㎡ 100-200g）、稀释10倍的人尿、落叶腐殖土 |
| 根瘤接种 | 取种过菜豆的自家或邻家田里5-15cm深的表土，裹在用水稍微润湿的种子上，立即播下。大豆或豌豆田里的土因菌系不同而效率低，低于10℃不会发生侵染，病田里的土还会带来炭疽病菌 |

> **菜豆随籽粒带走的氮与根瘤固定的氮差不多，甚至更多。如果不把茎叶还回田里，菜豆田几乎肯定会出现氮平衡的负值。**

&nbsp;&nbsp;&nbsp;每公顷固氮量在条件好时为40-70kg（差时15-30kg），而随籽粒带走60-75kg，茎叶里留下20-30kg，所以要把藤、叶和荚壳全部还回田里，如果喂了牲畜，就把粪肥施入这块田。开花前后（播种后5-7周）用铁锹连土挖起、洗净，剖开根瘤，每株15个以上、内部呈红色，就说明接种顺利。

| 播种 | 标准 |
|:---|:---|
| 时期 | 晚霜完全结束之后。蔓生型4月上旬-下旬，直立型4月中旬-5月下旬，南部早熟栽培3月上中旬，高寒地5-7月。极限是6月底-7月初（之后在霜前熟不了）。在适期内隔2周分两三次播种，开花期就会分散，酷暑或雨季就不会一次夺走全部 |
| 种子准备 | 弃去有斑点、变色、皱缩、虫孔的种子（炭疽病通过种子传染，所以选种是防治的一半）。裹上细草木灰以防鸟和地下害虫。浸种不超过12小时（超过则种皮破裂而腐烂，所以土壤潮湿时不浸种） |
| 方法 | 深3-5cm，每穴2-3粒。株行距为直立型早熟种40cm×15cm、晚熟种50cm×15cm，蔓生型75cm×30-40cm。真叶3-4片时留1-2株间苗。蔓生型的支柱要在播种前或真叶一两片时先立好 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种至发芽 | 不要让土壤彻底干掉 |
| 生长初期至开花前 | 偏干管理（过湿会徒长且伤根） |
| 开花期至鼓荚期 | 每10-15天一次浇透至20cm土层（直接关系到荚的膨大） |
| 30℃以上的高温期 | 清晨或傍晚沿垄沟放水降低地温（落花和不育减少，覆盖后效果更持久） |
| 雨季 | 挖排水沟（下部叶发黄脱落就是涝害） |

| 管理 | 方法 |
|:---|:---|
| 支架 | 藤蔓缠绕的对象以直径2cm左右最好，粗柱缠不上。A字形支架（3-4根长杆在顶端捆扎）、网架引蔓（产量最高）、绳索引蔓（在桩之间分多层拉绳）、玉米秆（不需要材料） |
| 打顶 | 第1次在真叶3-5节时摘掉茎端生长点，第2次在新枝长到3-5节时再摘，以增加侧枝和花。开始开花后不再打，生长不良的瘠薄植株也不打。蔓生型只在够到支架顶端时打一次 |
| 间苗、除草 | 间苗在真叶1-2片时只整理过密处，3-4片时每穴留1-2株。除草在播种后2-3周和开花前，把锄放平只刮表面2cm（根浅，锄深了会断根） |

## 6. 病虫害与养分问题
| 病虫害 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 炭疽病 | 叶脉、茎和荚上出现暗红色溃疡，荚上有凹陷的斑点。高温高湿，种子传染 | 选种和温水消毒是核心。轮作3-4年、保证通风、烧掉病残体 |
| 菌核病、根腐病 | 茎变软，出现白色绵状菌丝和黑色菌核（凉爽潮湿时） / 基部和根变褐变软（过湿、连作） | 把病株连土挖出烧掉，避免密植 / 排水、起高垄、轮作 |
| 病毒病 | 叶片呈花叶状斑驳皱缩。由蚜虫传播 | 无法治疗。拔除烧掉并减少蚜虫 |
| 蚜虫、蝽类 | 吸汁并传播病毒 / 刺吸荚果使其成为空荚 | 把肥皂水（每1L水加无香料肥皂20g，正午高温时喷会烧叶）喷在叶背，并保护瓢虫 / 趁清晨有露水时徒手捉 |
| 根结线虫、菜豆象 | 根上出现瘤状变形，生长不良 / 在田里于荚上产卵，储存期间蛀食籽粒 | 轮作3-4年、与万寿菊间作 / 储存管理是关键（见第9节） |
| 鸟、地下害虫 | 发芽后啄食子叶 / 啃食播下的种子和幼茎 | 到发芽前盖上稻草或网 / 种子裹草木灰，挖开被咬断植株周围的土捉虫 |

> **炭疽病会随种子传到来年。从荚上有凹陷暗红斑点的植株上留的种子，本身就是来年的病源。**

&nbsp;&nbsp;&nbsp;波尔多液是将硫酸铜1kg和生石灰1kg分别溶于100L水中再混合，立即使用，用于预防炭疽病和细菌病，而不是治疗。碰到湿叶会使炭疽病扩散到整块田，所以雨后不进田。

| 症状 | 原因与对策 |
|:---|:---|
| 从下部叶开始整株淡黄、植株矮小 | 缺氮（根瘤不良常见）。先挖出根检查根瘤，若没有根瘤，就施少量稀释10倍的人尿 |
| 开花却不结荚 | 缺硼，或30℃以上的高温。施用多种材料混合的堆肥，沿垄沟放水降低地温 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 玉米·南瓜（三姐妹种植）、莴苣·菠菜（覆盖地面保墒）、马铃薯（病害不重叠） |
| 一般 | 甘蓝·大白菜类（利用菜豆之后残留的氮） |
| 差 | 与其他豆科连作（炭疽病和线虫积累） |

&nbsp;&nbsp;&nbsp;三姐妹种植是先以30cm间距种玉米，长到膝高时，在每株脚下约10cm远处播两三粒蔓生菜豆（同时播种的话，菜豆会缠住幼小的玉米把它压倒），并在玉米行间的空地稀疏地种南瓜。玉米当支柱，菜豆分享氮，南瓜叶盖住地面抑制杂草。菜豆遮光40%时产量减半，所以玉米要种得宽些，行向取南北方向。

&nbsp;&nbsp;&nbsp;休耕为3-4年（农村振兴厅的休耕3年组），炭疽病和根结线虫会积累。轮作的例子是：第1年菜豆（与玉米·南瓜同种） → 第2年叶菜或葱类 → 第3年根菜或谷物 → 再种菜豆。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 食荚型连荚吃45-55天，青菜豆约60天（荚饱满、籽粒大但仍呈绿色时），干籽粒早熟直立型70-80天、晚熟蔓生型100-130天，荚的七八成干黄、籽粒变硬时。蔓生型由下往上成熟，所以依次采摘，直立型一次用镰刀割 |
| 干燥 | 连荚在阳光下晒4-5天，脱粒后一定要在通风的阴凉处薄摊再晾5-7天（籽粒受阳光直射会褪色或发红、种皮开裂而招虫）。含水量12-13% |
| 脱粒、精选 | 装袋踩踏（籽粒不会蹦飞）、连枷要不用力多次打（重打会使籽粒破裂）、手剥（留种用）。最后在明亮处铺在白布上手工挑选，弃去有炭疽病暗红斑点的籽粒 |

> **有下雨的消息就不要等完全成熟，赶紧收。干荚被雨淋湿又晒干，反复多次就会炸裂，籽粒掉在地上，湿荚还会长霉。**

| 留种 | 标准 |
|:---|:---|
| 选株、收获 | 预先在田的内侧标记没有炭疽病症状、荚多、成熟早的植株。与其他品种相隔数米，荚完全干成褐色后再收 |
| 精选、保存 | 弃去斑点、裂粒、皱缩、变色的，只留大而有光泽的籽粒，在阴凉处晾5-7天，含水量12-13%。发芽率2年后为65-80%，3年后为45-65%，所以每3-4年从别处弄来种子混入一部分 |

## 9. 储存
| 步骤 | 方法 |
|:---|:---|
| 菜豆象防治 | 卵在田里就已经粘在荚上带进来，一代不到一个月，所以半年就会让一袋变成满是虫孔的空壳。完全密封最重要，草木灰（体积的2-5%）、硅藻土（每1kg 1-3g）、油涂层（每1kg加食用油2-5mL）为辅助。高温处理是薄摊在阳光下半天，使温度达到60℃，杀死卵和幼虫，但必须接受变色，且不用于留种 |
| 容器、检查 | 玻璃瓶可存3年以上，但挡不住光，所以放在暗处。把耳朵贴在容器上，有沙沙声是有虫，有霉味是发霉，表面有小圆孔说明象甲已经过了一代。每两个月检查一次，有危害就全部取出在阴凉处晾干，在水中捞去浮起的空粒，拌入草木灰后重新密封 |

## 10. 烹调与注意事项
| 中毒 | 内容 |
|:---|:---|
| 原因 | 植物血凝素（菜豆凝集素）。红色品系特别高，白色品系约为其三分之一 |
| 中毒量 | 生豆或没煮透的豆4-5粒 |
| 症状 | 吃后1-3小时出现严重恶心、剧烈呕吐、腹痛，随后腹泻。通常数小时到一天内恢复，但脱水有危险，儿童、老人和体弱者尤其危险 |

| 处理 | 凝集素活性 | 安全性 |
|:---|:---|:---|
| 生的 | 基准值 | 危险 |
| 80℃左右长时间加热 | 最高为基准值的5倍 | 比生的更危险 |
| 100℃沸水中10分钟以上 | 几乎为0 | 安全 |

&nbsp;&nbsp;&nbsp;80℃左右的热只会让凝集素更容易释放出来而无法破坏它，容易被吸收的活性凝集素反而增多，到100℃结构才会崩溃。所以在大豆和小扁豆上很好的节省燃料的做法——不先煮沸直接用保温箱余热烹调、用灶膛余火焖、在火盆上整夜加热、在温汤里长时间浸泡、把干豆粉冲水喝——在菜豆上都是禁忌。

| 步骤 | 方法 |
|:---|:---|
| 1. 浸泡 | 在常温水中至少5小时，建议8小时以上（夏天要换水）。不泡的话外面煮熟而里面夹生，最危险，燃料也要多用一倍以上 |
| 2. 倒水、冲洗 | 泡豆水一定要倒掉，并用新水冲洗两三遍 |
| 3. 煮沸 | 加新水煮到翻滚，保持100℃至少10分钟，稳妥起见30分钟（水必须不断翻起大气泡，只是安静地冒热气不算100℃） |
| 4. 检查、倒水 | 用手指按压看是否完全压烂（里面留有硬芯就是没熟），煮豆水也要倒掉 |

| 方法 | 安全条件 |
|:---|:---|
| 压力烹调 | 将泡好的豆加压15-20分钟。最安全且燃料最少 |
| 煮沸后余热烹调 | 必须先在100℃煮10-15分钟，再放进保温箱 |
| 青菜豆 | 嫩的凝集素少，在沸水中煮几分钟即可 |
| 禁止 | 不先煮沸直接余热烹调、炒、生吃豆芽（芽里也有凝集素） |
| 煮后晒干 | 充分煮熟后，晒到一掰就“啪”地断开的程度，可保存数月；以后只需稍泡再加热，不必每次都要确保100℃。盐腌煮豆、煮烂捣碎晒干、晒干的青菜豆、豆沙也是同样的原理 |
| 中毒时 | 立即停止，丢弃所有煮好的豆。把加了极少量盐和糖的凉白开少量多次地让他喝，并让其躺下静养。特别照看脱水快的儿童、老人和体弱者 |
| 其他 | 胰蛋白酶抑制剂在浸泡后要100℃煮30分钟以上，低聚糖要倒掉浸泡水和煮豆水，皂苷要撇去泡沫。发霉的豆洗了、煮了也不安全，要丢弃 |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存、种子发芽试验、整修支架材料。2月做田地规划、翻堆堆肥、挑出有炭疽病斑点的籽粒 |
| 3-4月 | 3月撒石灰、翻耕、起垄和排水沟、南部早播。4月播蔓生型、立支柱（播种前）、防鸟 |
| 5-6月 | 5月播直立型（隔2周）、间苗、除草、第1次打顶。6月开花、第2次打顶后停止、检查根瘤、开始收青菜豆 |
| 7-8月 | 7月鼓荚、高温期垄沟灌溉、收早熟种的干籽粒。8月蔓生型依次收获、捕杀蝽类、监视炭疽病 |
| 9-10月 | 9月收获收尾、连荚晒干、脱粒。10月阴凉处晾干、精选、储存、茎叶还田 |
| 11-12月 | 11月趁有柴火时煮一锅晒干备用、检查储存。12月检查储存、规划来年 |

> **菜豆只要泡5小时以上并倒掉泡豆水、在100℃煮10分钟以上、不用低温长时间加热、挑掉带炭疽病的种子、把茎叶还回田里，与玉米一起种就是能产出蛋白质的作物。**
