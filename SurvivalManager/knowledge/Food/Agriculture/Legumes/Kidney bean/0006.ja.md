| 隔離 | 他の品種と数m離し、採種用は畑の内側から選びます |

&nbsp;&nbsp;&nbsp;インゲンマメは自家受粉なので純系がよく保たれますが、エンドウほど完璧ではありません。蜂による他家受粉がまれに起こるため、複数の品種を育てるなら数m離して植え、採種用は畑の内側の株から選びます。畑の縁の株がもっとも他品種の花粉を受け取る可能性が高いです。

| 収穫当年: 90%以上 |

## 14. 毒性 - インゲンマメレクチン中毒

&nbsp;&nbsp;&nbsp;この節はこの文書の中でもっとも重要です。インゲンマメはしっかり加熱すれば安全で栄養に優れた食品ですが、生や加熱不十分なものは人を実際に病気にします。そして、その危険の大きさと性質は他の豆とは異なります。

### 14-1. フィトヘマグルチニンとは何か

&nbsp;&nbsp;&nbsp;インゲンマメ属(Phaseolus)の種子には、フィトヘマグルチニンというレクチンが含まれています。レクチンは糖鎖に結合するタンパク質で、植物が種子を食べられないようにするために作った化学的防御物質です。この物質が人の腸に入ると、腸粘膜細胞表面の糖鎖に結合して吸収を妨げ、細胞を損傷させます。名前についているヘマグルチニンは赤血球を凝集させるという意味で、この物質の毒性を測る単位として使われます。

&nbsp;&nbsp;&nbsp;問題は含有量です。ダイズやエンドウやレンズマメにもレクチンはありますが、インゲンマメ属はその水準が違います。赤インゲンマメのレクチン活性は他の豆の数十倍に達します。そのためダイズは加熱不足でもお腹の不快感程度で済みますが、インゲンマメはわずか四、五粒で緊急事態になります。

| 項目 | 内容 |
|---|---|
| 原因物質 | フィトヘマグルチニン(インゲンマメレクチン) |
| 中毒発生量 | 生豆または加熱不十分な豆4-5粒 |
| 症状の始まり | 食後1-3時間 |
| 主な症状 | 激しい吐き気、激しい嘔吐、腹痛、続いて下痢 |
| 回復 | 通常数時間から1日以内に回復しますが、脱水が危険です |
| もっとも危険な対象 | 子供、高齢者、すでに衰弱している人。脱水に耐えにくいです |
| 含有量が高い系統 | 赤インゲンマメ系統が特に高いです。白系統は3分の1程度 |

> **インゲンマメ中毒はまれでもなく、軽くもありません。生豆四、五粒、つまり間違ってつまみ食いしてしまう程度の量で、数時間以内に激しい嘔吐と下痢が始まります。医療が届かない状況では、脱水そのものが危険です。**

### 14-2. 低い温度がより危険な理由

&nbsp;&nbsp;&nbsp;この節でもっとも直感に反しつつ、もっとも重要な事実がここにあります。インゲンマメを中途半端な温度で加熱すると、毒性が生の状態よりむしろ強くなります。

| 処理 | レクチン活性 | 安全性 |
|---|---|---|
| 生 | 基準値 | 危険です |
| 80℃前後で長時間加熱 | 基準値の最大5倍 | 生より危険です |
| 100℃の沸騰した湯で10分以上 | ほぼ0 | 安全です |

&nbsp;&nbsp;&nbsp;なぜこのようなことが起きるのか、説明すると次のようになります。乾燥した豆の中でレクチンは他のタンパク質と絡み合っていたり細胞壁の中に閉じ込められていたりして、消化管の中で完全には解放されません。80℃程度の熱は細胞壁とタンパク質構造を緩めてレクチンが外に出やすくしますが、レクチン自体を破壊するほど強くはありません。その結果、吸収されやすい形の活性レクチンが増えます。100℃に達してようやく、レクチンのタンパク質構造そのものが崩れて活性が失われます。

&nbsp;&nbsp;&nbsp;これが災害状況で特に危険な理由があります。燃料が貴重だと、人は自然に火を弱くして長時間煮る方法を選びます。保温箱を使った残熱調理、かまどの残り火に乗せておくこと、炭火の上で一晩温めることは、すべてこれに当たります。これらの方法はダイズやレンズマメでは優れた燃料節約の手段ですが、インゲンマメでは正確に最も危険な調理法になります。

> **燃料を節約するために弱火で長時間煮る方法は、インゲンマメでは禁忌です。残熱調理を使うとしても、必ず先に沸騰した湯で10分以上煮た後に保温箱に入れなければなりません。**

### 14-3. 安全に食べる手順

| 順序 | 内容 | 理由 |
|---|---|---|
| 1. 浸漬 | 常温の水に最低5時間、推奨8時間以上浸けます | 水にレクチンの一部が溶け出し、内部まで熱が入る道が開きます |
| 2. 浸けた水を捨てる | 必ず捨てます。調理には使いません | 水に溶け出したレクチンとオリゴ糖を一緒に捨てます |
| 3. すすぐ | 新しい水で一、二度すすぎます | 表面に残ったものを洗い落とします |
| 4. 強火で煮る | 新しい水を注いで沸騰させます。100℃にならなければなりません | ここでレクチンが破壊されます |
| 5. 10分以上維持する | 沸騰し始めてから最低10分、安全には30分 | 10分が最低基準で、粒が大きいとさらにかかります |
| 6. 火が通ったか確認 | 指で押して完全に潰れるか見ます | 内部に硬い芯が残っていれば加熱不足です |
| 7. 水を捨てる | 煮た湯も捨てる方が安全です | 残ったレクチンとオリゴ糖が一緒に抜けます |

&nbsp;&nbsp;&nbsp;浸漬がなぜ必要なのか、もう一度確認しておきます。戻していない乾燥インゲンマメは表面が硬く、熱が内部まで入りません。表面だけ煮えて内部が加熱不足の状態になりますが、まさにその状態がもっとも危険です。さらに、戻さないと燃料が2倍以上かかります。浸漬は安全と燃料の両面で得になります。夏は水が傷むことがあるので、三、四時間ごとに水を替えるか、夕方に浸けて朝に取り出します。

&nbsp;&nbsp;&nbsp;圧力鍋が使えるなら、もっとも安全で燃料も少なくて済みます。圧力調理は100℃を超える温度に達するため、15分から20分で十分です。ただし圧力鍋がない条件を前提にするなら、大きな鍋にたっぷり水を注ぎ、蓋をして強火で煮るのが基本です。水が沸騰しているかは音と蒸気で確認します。表面が静かに蒸気だけ上がっている状態は100℃ではありません。水が大きな泡で絶えず湧き上がっていなければなりません。

### 14-4. 中毒が起きたとき

| 対処 | 内容 |
|---|---|
| 即時中止 | 残った豆をこれ以上食べさせず、調理したものはすべて廃棄します |
| 水分補給 | 嘔吐と下痢で失った水と塩分を補います。沸かして冷ました水に塩と砂糖をごく少量溶かし、少しずつ何度も飲ませます |
| 安静 | 寝かせて安静にします。通常数時間から1日以内に回復します |
| 注意すべき対象 | 子供と高齢者、衰弱した人は脱水が早く進むため、特に注意深く見守ります |
| 原因の確認 | どの鍋のどの豆だったかを確認し、同じ過ちを繰り返さないようにします |

&nbsp;&nbsp;&nbsp;症状が食物繊維による腹部膨満と混同されることがあります。区別の基準は強さと始まる時点です。食物繊維によるものならお腹がゴロゴロしてガスが張る程度で、半日ほどかけてゆっくり来ます。レクチン中毒は食後1時間から3時間以内に突然の吐き気と激しい嘔吐で始まります。嘔吐が先に来て下痢が後に続く順序が特徴です。

### 14-5. その他の抗栄養成分

| 成分 | 働き | 取り除く方法 |
|---|---|---|
| トリプシンインヒビター | タンパク質分解酵素の働きを妨げます | 浸漬後100℃で30分以上 |
| フィチン酸 | 鉄、亜鉛、カルシウムと結合して吸収を妨げます | 浸漬、発芽、発酵で60-80%まで減ります |
| オリゴ糖 | 人が消化できず腸内細菌が発酵させます | 浸けた水と煮た湯を捨てます |
| サポニン | 泡を出します | 煮ながら泡をすくい取ります |
| カビ毒 | 保管中にカビが作ります | カビが生えたものは洗っても加熱しても安全になりません。捨てます |

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;インゲンマメの貯蔵性はSSです。乾燥種実は常温で3年もち、脂肪が1%前後なので酸敗もほとんどありません。しかし条件が悪いと、コクゾウムシが貯蔵した豆を全部殻に変えてしまいます。

> **豆は腐って失うのではなく、虫に食われて失います。貯蔵の技術とは、すなわち虫を防ぐ技術です。**

### 15-1. 乾燥が先です

| 段階 | 方法 | 確認 |
|---|---|---|
| 1次乾燥 | さやのまま日に当てて4-5日 | さやがからからに乾きます |
| 脱穀 | 乾いた後に行います | 乾きが足りないと開きません |
| 2次乾燥 | 陰で5-7日、通風するよう薄く広げます | 直射日光は変色と種皮の裂けを招きます |
| 目標水分 | 12-13% | 歯で噛んだとき歯が入らずぱきっと割れます |
| 塩試験 | 乾いた塩を瓶に豆と一緒に入れて振ります | 塩が瓶の壁に付けばまだ湿っています |
| 冷ます | 完全に冷ましてから容器に入れます | 温かい状態で密閉すると結露が生じます |

### 15-2. 貯蔵中のコクゾウムシ防除

&nbsp;&nbsp;&nbsp;コクゾウムシの仲間は貯蔵豆類にとって最大の脅威です。恐ろしいのは、畑の段階でもう始まっているという点です。まだ畑についているさやに成虫が卵を付けておき、その卵が貯蔵庫の中で孵化して豆の中に食い込みます。持ち込む時点でもう卵が付いてくる構造で、一世代が1か月とかからないため、半年で袋一つが穴の開いた殻でいっぱいになります。

| 方法 | 原理 | 適用 | 効果 |
|---|---|---|---|
| 完全密閉 | 酸素を断って窒息させます | ガラス瓶や金属缶に満たして封をします | もっとも確実です。3-4週間で卵と幼虫まで死にます |
| 木灰混入 | 微細粒子が外骨格のワックス層を削り脱水させます | 豆の体積の2-5%を混ぜます | 食べる前に水で洗い流します |
| 珪藻土 | 珪酸の殻が外骨格を傷つけます | 豆1kgに1-3g | 灰より効果が大きいです。乾いた状態でのみ働きます |
| 油コーティング | 油膜が卵の付着と孵化を防ぎます | 豆1kgに食用油2-5mLを入れてもみます | 種子用には使いません |
| 低温処理 | 氷点下で卵と幼虫が死にます | 真冬に数日外に出してから取り込みます | 取り込む際の結露に注意します |
| 高温処理 | 60度で卵と幼虫が死にます | 日に薄く広げて半日置きます | 変色は覚悟しなければなりません。種子用には使いません |
| 乾燥した唐辛子・サンショウ・ヨモギ | 精油成分が産卵を抑えます | 層になるよう入れます | 補助的な手段です |
| 炭・炒り塩 | 湿気を吸います | 布に包んで入れます | カビ予防も兼ねます |
| 灰の中に埋める | 密閉と物理的防除を同時に得ます | 甕に灰と豆を交互に積みます | 伝統的に広く使われてきました |

&nbsp;&nbsp;&nbsp;もっとも重要なのは完全密閉です。虫も呼吸をします。密閉した容器の中で豆と虫が酸素を使うと、酸素が減り二酸化炭素が増えて虫が死にます。豆は休眠状態なのでこの条件に耐えます。容器を満たして空間を減らすほど効果が速くなります。大きな缶一つより小さな缶いくつかにぎっしり詰める方がよく、これは一缶が傷んだときに全部を失わない利点も同時に与えます。

&nbsp;&nbsp;&nbsp;油コーティングと木灰混入は、インドとアフリカの小規模農家で長く使われてきた方法です。豆1kgに食用油2-3mlを入れてもみ、すべての粒に薄い膜ができるようにするか、ふるった細かい灰を体積の2-5%混ぜます。虫が耐性を持つことができず、人には無害です。どうせインゲンマメは調理前に5時間以上水に浸すので、灰はその過程で自然に洗い流されます。

| 容器 | 密閉 | 期間 | 備考 |
|---|:---:|---|---|
| ガラス瓶 | 非常に良い | 3年以上 | 光を防げないので暗い場所に置きます |
| 金属缶 | 非常に良い | 3年以上 | ネズミと虫を完全に防ぎます |
| 甕 | 良い | 2-3年 | 温度変化が緩やかでネズミが破れません |
| 厚手のビニール | 普通 | 1-2年 | ネズミが破ります |
| 地中貯蔵穴 | 良い | 2-3年 | 水が染みると全量を失います |

&nbsp;&nbsp;&nbsp;点検でもっとも頼りになる感覚は聴覚と嗅覚です。缶に耳を当てたときにカサカサという音がすれば虫が活動しており、湿っぽい匂いがすればカビが始まった状態です。表面に小さな丸い穴が見えれば、コクゾウムシが一世代を超えた状態です。この時点でも全量を取り出して陰干しし、水に浮かせて空の粒を取り除き、灰を混ぜて再び密閉すれば、残った分を守ることができます。2か月に1回の点検が基準です。

## 16. 調理と加工

### 16-1. 燃料を節約しつつ安全を守る方法

| 方法 | 燃料 | 安全条件 |
|---|:---:|---|
| 圧力調理 | もっとも少ない | 戻した豆を15-20分加圧します。もっとも安全でもっとも経済的です |
| 煮てから残熱調理 | 少ない | 必ず先に100℃で10-15分煮た後、保温箱に入れます |
| いきなり残熱調理 | - | 絶対に行いません。毒性がむしろ上がります |
| 炒める | 少ない | 乾燥豆を炒める方式は安全を保証しにくいです。勧めません |
| 青インゲンマメの湯通し | 非常に少ない | 若いものはレクチンが少なく、沸騰した湯で数分でよいです |
| 発芽 | なし | インゲンマメの芽はレクチンが残っているため生食しません。必ず加熱します |

> **インゲンマメにおける燃料節約の順序はこうです。まず十分に戻して調理時間を減らし、次に必ず100℃で10分以上煮て、その後に残熱で仕上げます。この順序を変えると安全が崩れます。**

&nbsp;&nbsp;&nbsp;浸漬が燃料を節約するもっとも大きな手段であることを覚えておきます。8時間戻したインゲンマメは、戻していないものの半分以下の時間で煮えます。水と時間はかかりますが、火はかかりません。そしてその浸漬が同時に安全性も高めます。災害の状況で毎晩翌日食べる豆を浸けておく習慣一つが、燃料と安全を同時に確保します。

&nbsp;&nbsp;&nbsp;他の豆では有用な方法のうち、インゲンマメに適用してはいけないものを別に書いておきます。第一に、戻した豆をそのまま保温箱に入れる方式です。第二に、かまどの残り火や炭火の上に鍋を乗せて一晩置く方式です。第三に、ぬるいスープに豆を長時間浸けておく方式です。第四に、乾燥豆をすって粉にし、水に溶いて食べる方式です。いずれも100℃に達しない調理なので、インゲンマメでは禁忌です。

### 16-2. 貯蔵加工

| 加工 | 手順概要 | 保管 | 価値 |
|---|---|---|---|
| 煮て乾かす | 十分に煮た後、日にからからに乾かします | 数か月 | 一度煮ておくと以後の調理が短くなります |
| 煮豆の塩漬け | 煮て塩を層になるよう振りかけ甕に入れます | 数か月 | 食べる前に水に浸けて塩気を抜きます |
| 煮豆をつぶして乾かす | 煮てつぶし、薄く広げて乾かします | 数か月 | 水で溶けばそのままお粥になります |
| 青インゲンマメの湯通し乾燥 | 湯通しして水気を抜き乾かします | 数か月 | 冬に汁物やお粥に入れます |
| インゲンマメあん | 煮てつぶし皮を取り除きます | 数日、乾かせば数か月 | 消化しやすく子供や高齢者が食べやすいです |

&nbsp;&nbsp;&nbsp;煮て乾かす加工はインゲンマメにおいて特に価値があります。レクチンを除くのに必要な長時間の加熱を一度に済ませておき、その後は水にさっと浸けて温めるだけでよいからです。燃料を一度にまとめて使い、以後は節約する構造で、何よりも毎回調理するたびに100℃を確保する負担から解放されます。薪が豊富な秋に鍋いっぱい煮て乾かしておけば、冬の間ずっと安全に食べられます。

&nbsp;&nbsp;&nbsp;煮て乾かしたインゲンマメは水気がないため虫やカビにも強いです。ただし、からからに乾かさないとすぐにカビが来るので、折ったときにぱきっと音を立てて割れるまで乾かします。密閉しておけば数か月もちます。

## 17. 年間作業スケジュール

### 17-1. 忘れてはならない五つ

| 項目 | 内容 |
|---|---|
| 調理の安全 | 生4-5粒で中毒が起きます。5時間以上戻して浸けた水を捨てた後、100℃で10分以上煮ます |
| 低温禁止 | 80℃で長時間温めると毒性が生の状態より5倍まで上がります。残熱調理は必ず煮た後に行います |
| 種子選別 | 炭疽病は種子で伝染します。黒みを帯びた赤い斑点がある粒を選んで捨てます |
| 支柱 | つるは直径2cm前後のものに巻きつきます。トウモロコシと一緒に植えれば資材がかかりません |
| 茎葉 | インゲンマメは種実として出ていく窒素が、固定量とほぼ同じです。つるを畑に戻さないと土地を消耗させます |
