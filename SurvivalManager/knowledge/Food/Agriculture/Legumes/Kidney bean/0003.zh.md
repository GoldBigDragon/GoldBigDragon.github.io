## 3. 栽培环境

### 3-1. 气温与光照量

| 条件 | 极限值 | 最适值 | 超出范围时 |
|---|---|---|---|
| 发芽温度 | 10℃以上 | 26-30℃ | 低于10℃不发芽，种子会腐烂 |
| 生长温度 | 10-30℃ | 15-21℃ | 5℃以下时生长停止 |
| 结实温度 | 18-28℃ | 20-25℃ | 幅度仅10℃，范围很窄 |
| 开花期高温 | 30℃以上持续数日 | - | 花和幼荚会脱落 |
| 耐寒性 | 无 | - | 遇霜即死，须在晚霜结束后种植 |
| 光照 | 每天6小时以上 | 每天8小时以上 | 40%遮光时产量降至一半 |

&nbsp;&nbsp;&nbsp;菜豆栽培中最难的判断，是把开花期放在哪里。超过30℃花会脱落，被梅雨淋湿荚会腐烂。韩国的夏季会同时带来这两种情况。4月种下的话，开花期落在6月初，正好在梅雨之前；5月底种下的话，开花期就会撞上7月底的酷暑。一般来说春播更有利，夏播只有在高寒地区才稳定。

> **分批播种在菜豆上尤其值得。每隔2周分两三次播种，可以让开花期分散开来，酷暑或梅雨就不会一次性夺走全部收成。**

&nbsp;&nbsp;&nbsp;在超过30℃的高温期，切实可行的应对办法是往垄沟灌水以降低地温。地温下降后根系就能正常吸水，落花也会减少。用覆盖物覆盖地面同样能起到这种效果。

### 3-2. 土壤与水

| 条件 | 极限值 | 最适值 | 备注 |
|---|---|---|---|
| 土质 | 从砂质土到壤土 | 保水性好且排水良好的砂壤土至壤土 | 积水地最不利 |
| pH | 5.5-7.5 | 6.0-7.0 | 酸性土壤中根瘤会减少 |
| 有效土层深度 | 30cm以上 | 50cm以上 | 根系分布相对较浅 |
| 生育期蒸散量 | - | 约400mm | 在豆类中属中等水平 |
| 积水 | 浸泡超过一天根系就会受损 | - | 不耐湿 |
| 垄高 | 15-20cm以上 | 20cm | 是应对梅雨的关键 |

&nbsp;&nbsp;&nbsp;菜豆对过湿和干燥都很敏感。根系浅，表层一干就立刻萎蔫，反过来一积水根系就腐烂。这正是既保水又排水良好的土壤、也就是有机质充足的砂壤土最理想的原因。施足堆肥来改善土壤结构，比灌溉或排水更是治本的办法。

## 4. 品种

### 4-1. 按生长形态分类

| 类别 | 株高 | 支架 | 生育期 | 特点 |
|---|---|---|---|---|
| 直立型（矮生型） | 40-60cm | 不需要 | 50-80天 | 收获快、省人工，但收获期短 |
| 蔓生型（蔓性种） | 2-3m | 必须搭设 | 100-130天 | 收获期长，单位面积产量高 |

&nbsp;&nbsp;&nbsp;在灾害情况下，这个选择关乎材料和劳动力。蔓生型能在同样面积里收获得多得多，但需要2m以上的支架。没有竹子或长杆的话就选直立型。不过如果同时种玉米，情况就不同了：玉米秆本身就能当支架，不需要额外材料也能种蔓生型。

&nbsp;&nbsp;&nbsp;两种都准备是最理想的。直立型在6月底到7月先收获，填补夏季的粮食空档；蔓生型则从7月一直延续到9月。把收获期错开，就不会因一次气象灾害而损失全部。

### 4-2. 按用途与颜色分类

| 类别 | 特点 | 适合的用途 |
|---|---|---|
| 白菜豆 | 颗粒大、口感松软，耐储性好 | 长期贮藏、煮食 |
| 黑菜豆 | 质地紧实，花青素含量高 | 贮藏、拌入米饭 |
| 花斑菜豆 | 多为早熟品种，豆荚柔软 | 早收、鲜食嫩菜豆 |
| 虎斑菜豆 | 蔓生型，产量高 | 大量收获 |
| 荚用型 | 豆荚不老不韧 | 整荚食用 |

> **即便是整荚食用的荚用型品种，一旦荚内的豆粒开始变粗，凝集素也会增加。煮熟嫩荚食用是安全的，但豆粒已经成熟的荚必须充分煮透。**

&nbsp;&nbsp;&nbsp;从灾害应对的角度看，选择品种的第一标准是能否自家留种。杂交一代(F1)种子第二年种下会性状分散。菜豆的栽培品种大多是固定品种、自花授粉，留下的种子可以直接种下，但如果种子袋上写着杂交种，就不要指望来年了。地方原生种产量较低，但已经适应了当地的气候和病害，而且可以持续留种延续下去。

### 4-3. 按情形选择的标准

| 情形 | 优先选择 | 原因 |
|---|---|---|
| 没有支架材料 | 直立型 | 不需要支架就能立住 |
| 种玉米 | 蔓生型 | 玉米秆可当支架 |
| 需要尽快有得吃 | 早熟直立型 | 60-80天即可收获 |
| 需要储备粮食 | 白菜豆、黑菜豆 | 耐储性好 |
| 燃料不足 | 籽粒小的系统 | 比大粒豆煮熟所需时间短 |
| 地块狭小 | 蔓生型 | 向上生长，单位面积产量高 |
| 梅雨来得早 | 早熟直立型 | 提早灌浆成熟，避开梅雨 |

## 5. 整地与施肥 - 根瘤菌

### 5-1. 固氮作用是如何发生的

&nbsp;&nbsp;&nbsp;空气中78%是氮气。尽管人们头顶飘浮着无穷无尽的氮，植物却无法利用它。这是因为空气中的氮是由两个氮原子以三键紧紧结合而成的分子，要切断这个键需要巨大的能量。工业上切断这个键来制造氨的方法就是哈伯-博施法，世界上的氮肥都由此而来，需要高温、高压、催化剂，以及大量的化石燃料。

&nbsp;&nbsp;&nbsp;根瘤菌能在常温常压下完成这项工作。它用一种叫固氮酶的酶切断三键，把氮转化为氨。但这是有代价的：这个反应需要大量能量，而细菌本身无法进行光合作用。因此它们住进豆科植物的根部，接受植物通过光合作用制造的糖，并以固定下来的氮作为回报。这是一种交易关系。

&nbsp;&nbsp;&nbsp;与菜豆搭配的菌属于Rhizobium类群，与大豆的Bradyrhizobium或豌豆的菌系不同，因此把种过大豆或豌豆的地里的土沾到菜豆种子上，效果并不大。种过菜豆的地里的土才是最可靠的。

| 阶段 | 发生的事 |
|---|---|
| 1. 信号交换 | 菜豆根系分泌类黄酮，土壤中的细菌应答该信号并释放Nod因子 |
| 2. 侵染 | 根毛向内卷曲将细菌包裹，细菌沿感染线进入根内 |
| 3. 根瘤形成 | 根内部细胞分裂使根瘤膨大，细菌在其中定居 |
| 4. 固氮 | 根瘤内固氮酶发挥作用，将空气中的氮转化为氨 |
| 5. 分配 | 氨转化为氨基酸，运往茎、叶和荚 |
| 6. 衰老 | 进入灌浆期后根瘤失去功能，与根一同归于土壤 |

&nbsp;&nbsp;&nbsp;固氮酶对氧气极为敏感，一接触氧气就会立刻失去功能。因此根瘤内部充满了一种叫豆血红蛋白的红色色素蛋白，它能抓住氧气，把酶周围的氧浓度维持在极低水平。这与人血呈红色的原理相同，剖开根瘤后内部呈红色或粉红色的，就是这种色素。这一点在实际操作中极为重要，因为红色是这个根瘤正在固氮的直观证据。

&nbsp;&nbsp;&nbsp;菜豆在豆科作物中固氮效率并不算高，只能自行制造所需氮的一半左右，其余要从土壤中获取。因此它的氮肥施用量比其他豆类定得稍多一些。不过这只是相对而言，与玉米相比仍然只是25%左右的水平。

### 5-2. 如何确认是否结出根瘤

&nbsp;&nbsp;&nbsp;无论是否接种过，都必须确认根瘤是否真的形成了。不确认的话就无法查明氮素不足的原因，来年还会重复同样的失误。

| 顺序 | 内容 |
|---|---|
| 1 | 开花初期，即播种后5-7周左右是最佳时机 |
| 2 | 挑选两三株看起来健康的植株 |
| 3 | 不要拔起，用铁铲从植株周围大范围铲起，连土一起挖出 |
| 4 | 放入水桶中，轻轻把泥土洗掉 |
| 5 | 数一数主根和粗侧根上结的根瘤数量 |
| 6 | 用指甲掰开几个根瘤，观察内部颜色 |

| 观察结果 | 含义 | 应对 |
|---|---|---|
| 每株结瘤15个以上 | 接种效果良好 | 无需处理 |
| 剖开内部呈红色或粉红色 | 正在固氮 | 状态良好 |
| 剖开内部为白色或浅绿色 | 根瘤已形成但未固氮 | 检查酸度、湿害、磷素缺乏情况 |
| 剖开内部为褐色或黑色 | 已经衰老或死亡 | 若处于灌浆期属正常，若处于开花期则有问题 |
| 根瘤5个以下 | 接种失败 | 若叶片发黄需补充氮素 |
| 根瘤只在细根末端密集地小小结出 | 已被土著菌侵染但效率低 | 来年更换接种源 |

> **挖出根系、剖开根瘤、确认是否呈红色——这一个习惯，在没有氮肥的世界里，是判断豆类种植成败最可靠的信号。**

### 5-3. 接种源从哪里获取

&nbsp;&nbsp;&nbsp;市售接种剂是把活菌装入草炭或黏土中出售的产品，灾害情况下无法获得。但菜豆在韩国全国都有种植，因此比较容易找到种过菜豆的地里的土。

| 方法 | 步骤 | 效果 | 注意 |
|---|---|---|---|
| 沾种过菜豆的地里的土 | 从去年种过菜豆、根瘤长得好的地里，铲取表层5-15cm深的土。将种子用水稍微湿润后沾上这些土，随即播种 | 最可靠且不花成本 | 有病地块的土也会把炭疽病菌一起带过来 |
| 直接使用根瘤 | 收集挖出的根瘤，捣碎后溶入水中，将种子浸入这些水中再取出 | 菌密度最高 | 必须在挖出根瘤当天使用 |
| 把土撒进地里 | 将取来的土撒在播种行上，一起翻耕入土 | 菌能扩散到土壤中 | 标准约为每10㎡一铲 |
| 保留根系残体 | 收获时只割茎，根留在地里 | 菌能在土中保留到来年 | 是最省事的维持方法 |
| 邻田的土 | 从种菜豆的邻田要来一铲土 | 因韩国各地都有种植而容易获得 | 需确认该地块是否无病 |

&nbsp;&nbsp;&nbsp;接种时有几点必须遵守。根瘤菌对直射光、干燥和高温都非常敏感，晒几分钟紫外线就会大量死亡，干燥后死得更快。给种子沾土的操作要在阴凉处进行，沾好土的种子不要晒，应立即播种，最好在30分钟内种下，最晚也要在几小时内完成。另外一点，种子消毒和接种不能同时进行：若用温水处理消毒过，须完全放凉后再接种。

| 导致接种失败的条件 | 原因 |
|---|---|
| 土壤pH 5.5以下 | 细菌无法存活 |
| 施足了氮肥的地块 | 植株感觉不到交易的必要，会自行减少结瘤 |
| 积水的地块 | 属好氧菌，缺氧就会死亡 |
| 缺磷的地块 | 固氮需要大量能量，而这一代谢过程要用到磷 |
| 缺钼、铁、钴 | 它们是固氮酶的组成成分 |
| 把接种过的种子拿去晒 | 紫外线和干燥会杀死菌 |
| 使用大豆或豌豆地里的土 | 菌系不同，侵染效率会降低 |
| 播种后低温 | 低于10℃感染根本不会发生 |
