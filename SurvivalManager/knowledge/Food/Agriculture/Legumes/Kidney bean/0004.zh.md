## 5. 整地与施肥 - 氮素平衡与施肥

### 5-4. 固氮的陷阱

&nbsp;&nbsp;&nbsp;种豆能让土地变肥沃这句话，已经成为农业上的常识。这话对了一半，也错了一半。若不能准确理解这一点，就会出现豆科连续种了几年反而地越种越瘦的情况。菜豆在这个问题上比其他豆类更严重，因为它的固氮效率在豆科中属于较低的一类。

&nbsp;&nbsp;&nbsp;菜豆长势良好时，每1,000㎡能收获200kg干籽实。菜豆籽实的蛋白质含量为21%，把蛋白质除以6.25就能得出氮含量。21 ÷ 6.25等于3.36，也就是籽实重量的约3.4%是纯氮。200kg中所含的氮约为6.7kg，换算成公顷则是67kg。

&nbsp;&nbsp;&nbsp;另一方面，菜豆根瘤在条件良好时固定的氮为每公顷40-70kg，明显少于大豆的100-150kg和蚕豆的150-200kg。把流出与流入并列起来，情况如下。

| 项目 | 每公顷氮量 | 方向 |
|---|---|---|
| 根瘤固氮量（条件良好） | 40-70kg | 流入 |
| 根瘤固氮量（条件不佳） | 15-30kg | 流入 |
| 随籽实运出 | 60-75kg | 流出 |
| 留在茎叶中的氮 | 20-30kg | 归还田地则留下，焚烧或运走则流出 |
| 留在根系与根瘤中的氮 | 8-15kg | 大多留在田里 |

> **菜豆随籽实流出的氮，与根瘤固定的氮量相当，甚至更多。如果不把茎叶归还田地，菜豆地几乎肯定会出现氮素负平衡。**

&nbsp;&nbsp;&nbsp;这一点在菜豆上尤其重要。大豆或蚕豆即便运走茎叶也还有一定余地，菜豆却没有这个余地。若把藤蔓收走焚烧，或喂给家畜后运出，那块地就会一年比一年贫瘠。若希望种菜豆的同时让土地变肥沃，归还茎叶不是可选项，而是最低条件。

&nbsp;&nbsp;&nbsp;三姐妹种植法在这个问题上的优势也在于此。与玉米一起生长的菜豆会通过根系把部分氮直接传给玉米，三种作物的残体也都留在那块地里。玉米秆、南瓜藤和菜豆藤在同一处腐熟后，来年的土壤会明显变得松软。

| 原则 | 内容 |
|---|---|
| 茎叶必须归还田地 | 脱粒后剩下的藤蔓、叶片和荚壳全部归还田地 |
| 不焚烧 | 焚烧会使氮变成气体飞散，只剩钾和磷留在灰中 |
| 不挖出根系 | 根与根瘤中的氮，是最容易留下的部分 |
| 切成20-30cm覆盖地面 | 兼具覆盖和施肥的作用 |
| 只挑出染病的残体 | 炭疽病残体要焚烧，其余归还田地 |
| 喂过家畜的话要归还粪肥 | 若用藤蔓喂过家畜，必须把该家畜的粪肥施回那块地 |

### 5-5. 整地

| 项目 | 方法 | 在灾害条件下 |
|---|---|---|
| 耕地 | 深耕20-30cm并整平 | 用铁铲翻地或用锄头刨松 |
| 起垄 | 高度15-20cm以上 | 是应对梅雨的关键 |
| 排水沟 | 深度30cm以上 | 确认排水是否彻底 |
| 酸度调节 | pH 6.0-7.0 | 提前在播种前3-4周进行 |
| 有机质 | 腐熟堆肥1,500-2,000kg/1,000㎡ | 同时获得保水性与排水性 |

&nbsp;&nbsp;&nbsp;施足堆肥对菜豆栽培尤其重要。菜豆对过湿和干燥都很敏感，而有机质丰富的土壤能同时缓解这两种情况：既能蓄水延缓干旱，结构又疏松，能让水迅速排出。1,500-2,000kg的腐熟堆肥在豆类中属偏多的用量，这不是为了供氮，而是为了改善土壤结构。

### 5-6. 施肥量

| 肥料 | 每1,000㎡用量 | 折算每㎡ | 备注 |
|---|---|---|---|
| 氮 | 4-6kg | 4-6g | 过量会导致只长叶不结荚 |
| 磷 | 7-10kg | 7-10g | 全部作基肥施用，对根系和开花很重要 |
| 钾 | 6-8kg | 6-8g | 全部作基肥施用 |
| 堆肥 | 1,500-2,000kg | 1.5-2kg | 须使用完全腐熟的堆肥 |
| 石灰 | 仅限酸性土壤 | - | 播种前3-4周 |

&nbsp;&nbsp;&nbsp;4-6kg的氮肥用量比大豆的3kg多，但远少于玉米的20kg。这是因为菜豆的固氮效率在豆科中偏低，须从土壤中获取接近一半的氮。尽管如此，上限依然明确：施得比这更多，只会让藤蔓和叶片疯长而结荚减少，变重的藤蔓还会倒伏，通风变差，炭疽病随之蔓延。

> **在菜豆上省着用氮不是节约，而是一种技术。施得多，产量必然会减少。**

&nbsp;&nbsp;&nbsp;通常做法是基肥中施入一半的氮，再在开花到荚膨大期根据生长情况追施剩余部分。灾害情况下，可用尿液按1:10的比例稀释后浇入株间土壤作为替代，注意不要沾到叶片。若叶片浓绿茂密，就不必再追施。

### 5-7. 灾害替代肥料

| 替代资源 | 供给的营养素 | 使用方法 | 注意 |
|---|---|---|---|
| 腐熟堆肥 | 综合、有机质 | 每㎡施1.5-2kg作基肥 | 是菜豆栽培中最重要的资源 |
| 草木灰 | 钾、磷、钙 | 每㎡撒施100-200g并混入土中 | 呈碱性，用多了pH会超过7 |
| 稀释尿液 | 氮、钾 | 用水稀释10倍后浇入株间土壤 | 注意不要沾到叶片 |
| 骨粉 | 磷、钙 | 烧后磨碎，拌入堆肥 | 见效较慢 |
| 鱼骨·鱼内脏 | 磷、氮 | 埋入土中腐熟后使用 | 直接埋的话会被野兽刨出来 |
| 贝壳·蛋壳 | 钙 | 烧后磨碎撒施 | 可代替石灰，反应较慢 |
| 落叶腐叶土 | 综合、有机质 | 混入土中 | 能大幅提高保水性 |
| 稻壳·稻秸 | 钾、硅酸 | 用作覆盖 | 能降低地温以减少落花 |

&nbsp;&nbsp;&nbsp;硼也值得记住。菜豆需要硼，若不足会导致落花、不结荚。没有化学硼砂时，把蔬菜残渣、果皮和落叶一起堆制的堆肥是最实际的替代方案。只用单一材料做的堆肥，微量元素会失衡。

## 6. 播种

### 6-1. 播种时期

| 栽培方式 | 地区 | 播种时期 | 收获时期 |
|---|---|---|---|
| 春季露地栽培（蔓生型） | 韩国全国 | 4月上旬至下旬 | 7月至9月 |
| 春季露地栽培（直立型） | 韩国全国 | 4月中旬至5月下旬 | 6月下旬至8月 |
| 早熟栽培 | 韩国南部 | 3月上中旬 | 6月上旬至中旬 |
| 高冷地栽培 | 山区 | 5-7月 | 8-10月 |
| 播种极限期 | 韩国全国 | 6月末至7月初 | 此后种下就无法在霜期前成熟 |

&nbsp;&nbsp;&nbsp;原则上要等晚霜完全结束后才能播种。菜豆一遇霜就会枯死，低于10度甚至连发芽都不会发生。种得太早，种子会在土里腐烂；反之种得太晚，则会让开花期撞上酷暑，或让灌浆期泡在梅雨里。

> **在适宜期内每隔2周分两三次播种，可以让开花期分散，酷暑或干旱就不会一次性夺走全部收成，劳动也随之分摊开来。**

### 6-2. 种子准备

| 项目 | 方法 | 在灾害条件下 |
|---|---|---|
| 挑选 | 剔除有斑点、变色、皱缩、虫孔的种子 | 炭疽病通过种子传播，挑选就占了防治的一半 |
| 挑选大小 | 挑选颗粒饱满、较重的种子使用 | 放入水中，捞去漂浮的部分 |
| 温水消毒 | 浸入50-55度水中10-15分钟 | 可杀死随种子传播的病原菌 |
| 拌灰处理 | 沾上细草木灰 | 有助消毒和干燥，并能驱避鸟类和地下害虫 |
| 根瘤接种 | 沾上种过菜豆的地里的土 | 参见5-3节，不与消毒同时进行 |
| 浸种 | 播种前一天，仅限12小时以内 | 泡太久种皮会破裂，在土中腐烂 |
| 发芽试验 | 用湿布包20粒，放置数天后计数 | 陈种务必先做此项确认 |

&nbsp;&nbsp;&nbsp;浸种要格外谨慎。菜豆种子吸水很快，超过12小时种皮就会开裂、内部变软，这种状态下播入土中会在发芽前腐烂。若土壤足够湿润，最安全的做法是完全不浸泡直接播种；若是干土，则只浸六七个小时，晾干表面水分后再播种。

### 6-3. 播种方法

| 项目 | 标准 | 原因 |
|---|---|---|
| 播种深度 | 3-5cm | 为种子大小的两三倍，太浅会被鸟刨食 |
| 每穴粒数 | 2-3粒 | 需考虑鸟类和地下害虫造成的损失 |
| 直立型种植间距（早熟） | 40cm × 15cm | |
| 直立型种植间距（晚熟） | 50cm × 15cm | |
| 蔓生型种植间距 | 75cm × 30-40cm | 种植稀疏以确保通风 |
| 间苗 | 真叶3-4片时留1-2株 | |

&nbsp;&nbsp;&nbsp;播种后最大的威胁是鸟类和地下害虫。菜豆的子叶会露出地面，而且又大又软，鸽子、喜鹊和野鸡都爱啄食。子叶一旦被吃掉，那株苗大多就会死。可以在播种行上方薄薄盖一层树枝或稻草，或在发芽前罩上网子或旧防虫网，并交叉拉几条反光绳。给种子沾上细草木灰，也能减少地下害虫的靠近。

&nbsp;&nbsp;&nbsp;蔓生型要在播种前或真叶长出一两片时提前立好支架。若等藤蔓长出后再打桩，根系会被切断，藤蔓也会受伤。与玉米同种时，应先种玉米，等长到膝盖高后再在其根部种下菜豆。若同时种下，菜豆会先长起来，缠绕并压倒还幼小的玉米。

## 7. 水分管理

| 时期 | 水分管理 | 原因 |
|---|---|---|
| 播种到发芽 | 不让土壤完全干透 | 种子须吸水才能发芽 |
| 生长初期到开花前 | 适当偏干管理 | 过湿会导致徒长并伤根 |
| 开花到荚膨大期 | 每隔10-15天充分灌溉一次 | 直接关系到豆荚膨大 |
| 超过30度的高温期 | 往垄沟灌水以降低地温 | 减少落花和不育 |
| 梅雨季 | 挖好排水沟 | 否则下部叶片会发黄脱落 |
| 灌浆期 | 停止灌溉 | 过湿会导致裂荚落粒和品质下降 |

&nbsp;&nbsp;&nbsp;菜豆对过湿和干燥都很敏感，水分管理的余地很窄。根系浅，表层一干就立刻萎蔫，一积水根系就会腐烂。与少量勤浇相比，每隔10到15天一次性浇透、让土壤湿到20cm深，更有利于根系向下扎深。

| 症状 | 原因 | 应对 |
|---|---|---|
| 中午叶片萎垂，傍晚恢复 | 暂时性缺水，属正常范围 | 无需处理 |
| 早晨叶片仍未恢复 | 根系无法吸水 | 需充分灌水 |
| 大量落花 | 超过30度的高温，或干旱 | 往垄沟灌水降温并覆盖地面 |
| 已结荚但豆粒偏小 | 荚膨大期水分不足 | 这个阶段的灌溉直接决定产量 |
| 下部叶片发黄脱落 | 梅雨季湿害 | 开排水沟并培土 |
| 茎基部变褐软化 | 因过湿引起根腐 | 严重时须拔除，蔓延会波及全田 |
| 整株叶片浅黄但不萎蔫 | 根瘤未发挥作用致氮素不足 | 挖根检查根瘤状况 |

&nbsp;&nbsp;&nbsp;高温期往垄沟灌水的方法在菜豆上效果特别显著。连续出现超过30度的天气会导致落花，这往往不是气温本身的问题，而是根系附近的地温升高使根无法正常发挥功能所致。在清晨或日落时沿垄沟引水，能让地温下降几度，落花明显减少。若同时配合覆盖，效果会持续更久。

&nbsp;&nbsp;&nbsp;覆盖也是最省钱的省水手段。即便没有塑料薄膜，用稻草、稻壳、落叶或割下的杂草覆盖5到10cm，也能让地表蒸发减少一半以上，并缓和地温波动。不过在梅雨季，掀开一部分以保持通风，更有利于防病。
