## 3. 栽培環境

### 3-1. 気温と光量

| 条件 | 限界値 | 最適値 | 外れた場合 |
|---|---|---|---|
| 発芽温度 | 10℃以上 | 26-30℃ | 10℃未満では発芽せず種子が腐ります |
| 生育温度 | 10-30℃ | 15-21℃ | 5℃以下で生育が止まります |
| 結実温度 | 18-28℃ | 20-25℃ | 幅10℃の狭い範囲です |
| 開花期の高温 | 30℃以上が数日 | - | 花と若い莢が落ちます |
| 耐寒性 | ありません | - | 霜で枯れます。晩霜が終わったあとに植えます |
| 日照 | 1日6時間以上 | 1日8時間以上 | 40%遮光で収量が半分に落ちます |

&nbsp;&nbsp;&nbsp;インゲンマメ栽培でもっとも難しい判断は、開花期をどこに置くかです。30℃を超えると花が落ち、梅雨に濡れると莢が腐ります。韓国の夏はこの二つを同時にもたらします。4月に植えると開花期が6月初めに来て梅雨の前を通り過ぎ、5月末に植えると開花期が7月末の猛暑にかかります。一般に春の播種が有利で、夏の播種は高冷地でのみ安定します。

> **播種時期を分けることが、インゲンマメでは特に価値を持ちます。2週間おきに二三回に分けて植えれば開花期が分散し、猛暑や梅雨が一度に全部を奪うことはなくなります。**

&nbsp;&nbsp;&nbsp;30℃を超える高温期にできる実質的な対応は、畝間に水を引いて地温を下げることです。土の温度が下がれば根が水を吸い上げられるようになり、落花が減ります。マルチングで地面を覆っておくことも同じ効果を生みます。

### 3-2. 土壌と水

| 条件 | 限界値 | 最適値 | 備考 |
|---|---|---|---|
| 土性 | 砂質土から壌土まで | 保水力があり排水の良い砂壌土-壌土 | 水がたまる土地が最も悪いです |
| pH | 5.5-7.5 | 6.0-7.0 | 酸性土では根粒が減ります |
| 有効土層深 | 30cm以上 | 50cm以上 | 根が比較的浅く広がります |
| 作期蒸発散量 | - | 約400mm | 豆類の中では中間です |
| 浸水 | 1日以上浸かると根が傷みます | - | 過湿に弱いです |
| 畝の高さ | 15-20cm以上 | 20cm | 梅雨対策の要です |

&nbsp;&nbsp;&nbsp;インゲンマメは過湿と乾燥の両方に弱い作物です。根が浅く広がるため表層が乾くとすぐに萎れ、逆に水がたまると根が腐ります。保水力があり排水も良い土、つまり有機物を十分に含む砂壌土が理想的である理由がここにあります。堆肥をたっぷり入れて土の構造を作っておくことが、灌水や排水よりも根本的な対策になります。

## 4. 品種

### 4-1. 生育形態による分類

| 区分 | 草丈 | 支柱 | 生育期間 | 特徴 |
|---|---|---|---|---|
| 直立型（矮性種） | 40-60cm | 不要 | 50-80日 | 早く収穫でき、手間も少なくて済みます。収穫期間は短くなります |
| つる性（蔓性種） | 2-3m | 必ず必要 | 100-130日 | 収穫期間が長く、面積当たりの収量も高くなります |

&nbsp;&nbsp;&nbsp;災害時にはこの選択が資材と労働力の問題になります。つる性は同じ面積からずっと多く収穫できますが、2mを超える支柱が必要です。竹や長い棒がなければ直立型を選びます。ただしトウモロコシを一緒に植えるなら事情が変わります。トウモロコシの茎がそのまま支柱になるため、資材なしでつる性を育てられます。

&nbsp;&nbsp;&nbsp;両方を確保しておくのが理想です。直立型は6月末から7月にかけて先に収穫し、夏の食料の空白を埋め、つる性は7月から9月まで長く続きます。収穫期をずらしておけば、一度の気象災害で全部を失うことがありません。

### 4-2. 用途と色による分類

| 区分 | 特徴 | 適した用途 |
|---|---|---|
| 白インゲン | 粒が大きくほろほろしています。貯蔵性が良好です | 長期貯蔵、煮て食べる |
| 黒インゲン | 硬めでアントシアニンが多いです | 貯蔵、ご飯に混ぜる |
| まだら模様のインゲン | 早生が多く莢が柔らかいです | 早期収穫、青インゲン |
| 虎柄のインゲン | つる性で多収です | 大量確保 |
| サヤ用種 | 莢が硬くありません | 莢ごと食べる |

> **莢ごと食べるサヤ用種であっても、莢の中の粒が太り始めるとレクチンが増えます。若い莢を火を通して食べるのは安全ですが、粒が熟した莢は必ず十分に煮なければなりません。**

&nbsp;&nbsp;&nbsp;災害対策の観点から見た品種選びの第一の基準は、自家採種できるかどうかです。交配一代雑種(F1)は翌年植えると形質がばらけてしまいます。インゲンマメは栽培品種の大半が固定種で自家受精なので、採った種をそのまま植えられますが、種子袋に雑種と書かれていれば翌年に期待してはいけません。地域の在来種は収量が少ない代わりに、その地域の気候や病害にすでに適応しており、種を継いでいくことができます。

### 4-3. 状況別の選択基準

| 状況 | 優先順位 | 理由 |
|---|---|---|
| 支柱の資材がない | 直立型 | 支柱なしで自立します |
| トウモロコシを植える | つる性 | トウモロコシの茎が支柱になります |
| 早く食べる物が必要 | 早生の直立型 | 60-80日で収穫できます |
| 貯蔵食料が必要 | 白インゲン、黒インゲン | 貯蔵性が良好です |
| 燃料が不足している | 粒の小さい系統 | 大きい粒より煮える時間が短いです |
| 畑が狭い | つる性 | 上に伸びるため面積当たりの収量が高くなります |
| 梅雨が早く来る | 早生の直立型 | 登熟を早めて梅雨を避けます |

## 5. 畑の準備と肥料 - 根粒菌

### 5-1. 窒素固定はどのように起こるか

&nbsp;&nbsp;&nbsp;空気の78%は窒素です。人の頭上には無限の窒素が浮かんでいるのに、植物はそれを使うことができません。空気中の窒素は窒素原子二つが三重結合で強く結びついた分子であり、この結合を切るには莫大なエネルギーが必要だからです。工業的にこの結合を切ってアンモニアを作るのがハーバー・ボッシュ法で、世界の窒素肥料はそこから作られています。高温と高圧と触媒、そして大量の化石燃料が必要です。

&nbsp;&nbsp;&nbsp;根粒菌はこの仕事を常温常圧でやり遂げます。ニトロゲナーゼという酵素で三重結合を切り、窒素をアンモニアに変えるのです。ただし代償があります。この反応には多くのエネルギーが必要で、細菌自身は光合成ができません。そのため、マメ科植物の根に入り込んで暮らし、植物が光合成で作った糖を受け取り、その見返りに固定した窒素を渡します。取引の関係です。

&nbsp;&nbsp;&nbsp;インゲンマメと組む菌はRhizobiumの仲間です。ダイズのBradyrhizobiumやエンドウの菌とは系統が異なるため、ダイズやエンドウを育てた畑の土をインゲンマメの種子に付けても効果は大きくありません。インゲンマメを育てた畑の土がもっとも確実です。

| 段階 | 起こること |
|---|---|
| 1. 信号交換 | インゲンマメの根がフラボノイドを分泌し、土の中の細菌がその信号に応じてNodファクターを放出します |
| 2. 感染 | 根毛が内側に曲がって細菌を包み込み、細菌が感染糸をたどって根の中に入ります |
| 3. 根粒形成 | 根の内部の細胞が分裂して根粒が膨らみ、その中に細菌が定着します |
| 4. 窒素固定 | 根粒の中でニトロゲナーゼが働き、空気中の窒素をアンモニアに変えます |
| 5. 分配 | アンモニアがアミノ酸に変わり、茎や葉や莢へ運ばれます |
| 6. 老化 | 登熟期に入ると根粒は機能を失い、根とともに土に還ります |

&nbsp;&nbsp;&nbsp;ニトロゲナーゼは酸素にきわめて弱く、酸素に触れると即座に機能を失います。そのため根粒の内部にはレグヘモグロビンという赤い色素タンパク質が詰まっていて酸素を捕まえておき、酵素の周りの酸素濃度を極端に低く保ちます。人の血が赤いのと同じ原理で、根粒を割ったときに内側が赤や桃色をしているのはこの色素によるものです。この事実は実用的に非常に重要です。赤い色は、その根粒が今まさに窒素を固定しているという目に見える証拠だからです。

&nbsp;&nbsp;&nbsp;インゲンマメはマメ科の中で窒素固定効率が高い方ではありません。必要な窒素の半分程度しか自ら作れず、残りは土から取り込みます。そのため他の豆類より窒素の施肥量が少し多めに設定されています。ただしこれは相対的な話であり、トウモロコシに比べればそれでも25%程度にすぎません。

### 5-2. 根粒ができたかを確認する方法

&nbsp;&nbsp;&nbsp;接種したかどうかにかかわらず、根粒が実際にできているかを確認する作業は必ず行うべきです。確認しなければ窒素不足の原因が分からず、翌年に同じ失敗を繰り返すことになります。

| 順序 | 内容 |
|---|---|
| 1 | 開花が始まる頃、播種後5-7週あたりが最も良い時期です |
| 2 | 健康そうな株を二三株選びます |
| 3 | 引き抜かず、シャベルで株の周りを広く掘り、土ごと持ち上げます |
| 4 | 水を入れた容器に入れ、土を丁寧に洗い流します |
| 5 | 主根と太い側根に付いた根粒の数を数えます |
| 6 | 根粒をいくつか爪で割って内側の色を見ます |

| 観察結果 | 意味 | 対処 |
|---|---|---|
| 一株あたり根粒が15個以上付いている | 接種がうまくいっています | そのままにします |
| 割った内側が赤や桃色 | 窒素を固定しています | 良い状態です |
| 割った内側が白や薄緑色 | 根粒はできているが固定していません | 酸度、過湿、リン酸欠乏を確認します |
| 割った内側が茶色や黒色 | すでに老化したか死んでいます | 登熟期なら正常、開花期なら問題です |
| 根粒が5個以下 | 接種に失敗しています | 葉が黄色ければ窒素を補います |
| 根粒が細根の先だけに小さく多数付いている | 土着の菌に感染しているが効率が低いです | 翌年は接種源を変えます |

> **根を掘り出して根粒を割り、赤い色を確認するというこの一つの習慣が、窒素肥料のない世界で豆づくりの成否を教えてくれる、もっとも確実なサインです。**

### 5-3. 接種源をどこで手に入れるか

&nbsp;&nbsp;&nbsp;市販の接種剤は、生きた細菌をピートや粘土に含ませて売る製品です。災害時には入手できません。しかしインゲンマメは韓国全土で栽培されているため、インゲンマメを育てた畑の土を手に入れることは比較的容易です。

| 方法 | 手順 | 効果 | 注意 |
|---|---|---|---|
| インゲンマメを育てた畑の土を付ける | 前年インゲンマメを植えて根粒がよくできた畑から、表土5-15cmの深さの土をすくってきます。種子を水で軽く湿らせてこの土を付け、すぐに植えます | もっとも確実で費用もかかりません | 病気の畑の土は炭疽病菌も一緒に運んでしまいます |
| 根粒そのものを使う | 掘った根の根粒を集めてすり潰し水に溶かし、その水に種子を浸けてから取り出します | 菌の密度がもっとも高いです | 根粒を掘り出したその日のうちに使う必要があります |
| 土を畑にまく | 播種する筋に運んできた土をまき、一緒にすき込みます | 菌が土に広がります | 10㎡あたりひとすくいが目安です |
| 根の残りを残す | 収穫時に茎だけを刈り、根は畑に残します | 翌年まで菌が土に残ります | もっとも手間のかからない維持方法です |
| 近隣の畑の土 | インゲンマメを植えている近隣の畑から一すくいもらってきます | 韓国全土で栽培されているため入手しやすいです | 病気のない畑かどうか確認します |

&nbsp;&nbsp;&nbsp;接種する際に必ず守るべきことがあります。根粒菌は直射日光と乾燥と熱にきわめて弱く、紫外線を数分浴びるだけでかなりの数が死に、乾くとさらに早く死んでしまいます。種子に土を付ける作業は日陰で行い、土を付けた種子は日に当てずにすぐ植えます。30分以内に植えるのが望ましく、遅くとも数時間以内に終えます。もう一つ、種子消毒と接種は同時に行えません。温水処理で消毒した場合は、完全に冷ましたあとで接種します。

| 接種失敗を招く条件 | 理由 |
|---|---|
| 土壌pH5.5以下 | 細菌が生きられません |
| 窒素肥料を十分に与えた畑 | 植物が取引の必要を感じず、根粒形成を自ら減らします |
| 水がたまる畑 | 好気性細菌のため酸素がないと死にます |
| リン酸が不足している畑 | 窒素固定には多くのエネルギーが必要で、その代謝にリン酸が使われます |
| モリブデン・鉄・コバルトの欠乏 | ニトロゲナーゼの構成成分です |
| 接種した種子を日に干す | 紫外線と乾燥で菌が死にます |
| ダイズやエンドウの畑の土を使う | 菌の系統が異なり感染効率が落ちます |
| 播種後の低温 | 10℃未満では感染そのものが起こりません |
