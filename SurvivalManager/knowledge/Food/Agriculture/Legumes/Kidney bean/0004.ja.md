## 5. 畑の準備と肥料 - 窒素収支と施肥

### 5-4. 窒素固定の落とし穴

&nbsp;&nbsp;&nbsp;豆を植えると土が良くなるという言葉は、農業の常識として定着しています。半分は正しく、半分は間違っています。この点を正確に理解していないと、マメ科を何年か続けて植えた畑がむしろ痩せていくということが起こります。インゲンマメはこの問題が他の豆類より深刻な方です。窒素固定効率がマメ科の中で低い部類だからです。

&nbsp;&nbsp;&nbsp;インゲンマメがよく育てば1,000㎡で200kgの乾燥種実が収穫できます。インゲンマメの種実のタンパク質は21%で、タンパク質を6.25で割ると窒素量が出ます。21 ÷ 6.25は3.36、つまり種実の重さの約3.4%が純粋な窒素です。200kgに含まれる窒素は約6.7kgで、ヘクタールに換算すると67kgになります。

&nbsp;&nbsp;&nbsp;一方、インゲンマメの根粒が固定する窒素は、条件が良いときでヘクタール当たり40-70kgです。ダイズの100-150kg、ソラマメの150-200kgに比べると明らかに少なくなります。出ていくものと入ってくるものを並べると、次のようになります。

| 項目 | ヘクタール当たり窒素 | 方向 |
|---|---|---|
| 根粒による固定量（条件が良い場合） | 40-70kg | 入る |
| 根粒による固定量（条件が悪い場合） | 15-30kg | 入る |
| 種実として持ち出し | 60-75kg | 出る |
| 茎葉（茎と葉）に残る窒素 | 20-30kg | 畑に戻せば残り、燃やすか運び出せば出る |
| 根と根粒に残る窒素 | 8-15kg | 大抵は畑に残ります |

> **インゲンマメは種実として出ていく窒素が、根粒が固定する窒素とほぼ同じか、むしろ多くなります。茎葉を畑に戻さなければ、インゲンマメ畑はほぼ確実に窒素収支がマイナスになります。**

&nbsp;&nbsp;&nbsp;この点がインゲンマメにおいて特に重要です。ダイズやソラマメは茎葉を運び出してもある程度の余裕がありますが、インゲンマメにはその余裕がありません。つるを取り払って燃やしたり家畜に食べさせて持ち出したりすると、その畑は年々痩せていきます。インゲンマメを育てながら土が良くなることを期待するなら、茎葉を戻すことは選択ではなく最低条件です。

&nbsp;&nbsp;&nbsp;三姉妹農法がこの問題において有利な理由もここにあります。トウモロコシと一緒に育つインゲンマメは、根を通じて窒素の一部をトウモロコシに直接渡し、三つの作物の残渣がすべてその畑に残ります。トウモロコシの茎とカボチャのつるとインゲンマメのつるが同じ場所で腐れば、翌年の土は目に見えて柔らかくなります。

| 原則 | 内容 |
|---|---|
| 茎葉は必ず畑へ | 脱穀後に残るつると葉、莢の殻をすべて畑に戻します |
| 燃やさない | 燃やすと窒素が気体になって飛び、カリウムとリン酸だけが灰に残ります |
| 根は掘り出さない | 根と根粒の窒素は、もっとも簡単に残せる分です |
| 20-30cmに切って覆う | マルチングと肥料を兼ねます |
| 病気の残渣だけを取り除く | 炭疽病の残渣は燃やし、残りは畑に戻します |
| 家畜に食べさせたなら糞を戻す | つるを食べさせたなら、その家畜の糞尿を必ずその畑に入れます |

### 5-5. 畑の準備

| 項目 | 方法 | 災害条件下で |
|---|---|---|
| 耕耘 | 20-30cmの深さに耕し、均一に整地します | シャベルで掘り返すか、鍬で掘り起こします |
| 畝 | 高さ15-20cm以上 | 梅雨対策の要です |
| 排水路 | 深さ30cm以上 | 水が最後まで抜けるか確認します |
| 酸度矯正 | pH6.0-7.0 | 播種の3-4週間前に済ませます |
| 有機物 | 完熟堆肥1,500-2,000kg/1,000㎡ | 保水力と排水性を同時に得られます |

&nbsp;&nbsp;&nbsp;堆肥を十分に入れることが、インゲンマメ栽培において特に重要です。インゲンマメは過湿と乾燥の両方に弱く、有機物の多い土はこの両方を同時に和らげます。水を含んで乾燥を遅らせ、構造がほろほろしているため水も速く抜けます。完熟堆肥1,500-2,000kgは豆類の中でも多い部類で、これは窒素を与えるためではなく、土の構造を作るためのものです。

### 5-6. 施肥量

| 肥料 | 1,000㎡基準 | ㎡換算 | 備考 |
|---|---|---|---|
| 窒素 | 4-6kg | 4-6g | 過剰だと葉だけが茂り、莢が減ります |
| リン酸 | 7-10kg | 7-10g | 全量を元肥で施します。根と開花に重要です |
| カリウム | 6-8kg | 6-8g | 全量を元肥で施します |
| 堆肥 | 1,500-2,000kg | 1.5-2kg | 完全に腐熟したものを使います |
| 石灰 | 酸性土に限る | - | 播種3-4週間前 |

&nbsp;&nbsp;&nbsp;窒素4-6kgはダイズの3kgより多く、トウモロコシの20kgよりはるかに少ない量です。インゲンマメの窒素固定効率がマメ科の中で低い部類のため、土から半分近くを取り込むからです。それでも上限は明確です。これより多く与えると、つると葉だけが茂って莢が減り、重くなったつるが倒れて風通しが悪くなり、炭疽病が広がります。

> **インゲンマメで窒素を控えることは節約ではなく技術です。多く与えれば必ず収量が減ります。**

&nbsp;&nbsp;&nbsp;追肥は、元肥で窒素の半分を入れ、開花から莢肥大期にかけて生育を見ながら残りを入れるのが慣行です。災害時には、尿を水で10倍に薄めて株の間の土に注ぐのが代替策で、葉に触れないようにします。葉が濃い緑色で茂っているなら与えません。

### 5-7. 災害時の代替肥料

| 代替資源 | 供給栄養素 | 使用法 | 注意 |
|---|---|---|---|
| 完熟堆肥 | 総合、有機物 | ㎡あたり1.5-2kgを元肥として入れます | インゲンマメにおいてもっとも重要な資源です |
| 草木灰 | カリウム、リン酸、カルシウム | ㎡あたり100-200gをまいて混ぜます | アルカリ性のため多く入れるとpHが7を超えます |
| 薄めた尿 | 窒素、カリウム | 水に10倍希釈し株の間の土に注ぎます | 葉に触れないようにします |
| 骨粉 | リン酸、カルシウム | 焼いて挽き、堆肥に混ぜます | 効果はゆっくり現れます |
| 魚の骨・魚の内臓 | リン酸、窒素 | 埋めて発酵させたあとに使います | そのまま埋めると獣が掘り出します |
| 貝殻・卵の殻 | カルシウム | 焼いて挽いてまきます | 石灰の代わりです。反応が遅いです |
| 落ち葉の腐葉土 | 総合、有機物 | 土に混ぜ込みます | 保水力を大きく高めます |
| 籾殻・稲わら | カリウム、ケイ酸 | マルチングとして覆います | 地温を下げて落花を減らします |

&nbsp;&nbsp;&nbsp;ホウ素も記憶しておく価値があります。インゲンマメはホウ素を必要とし、不足すると花が落ち、莢が付きません。化学的なホウ砂がないときは、野菜くずと果物の皮と落ち葉を一緒に入れた堆肥がもっとも現実的な代替策です。一種類の材料だけで作った堆肥は微量元素が偏ります。

## 6. 播種

### 6-1. 播種時期

| 作型 | 地域 | 播種時期 | 収穫時期 |
|---|---|---|---|
| 春の露地栽培（つる性） | 韓国全土 | 4月上旬-下旬 | 7月-9月 |
| 春の露地栽培（直立型） | 韓国全土 | 4月中旬-5月下旬 | 6月下旬-8月 |
| 早熟栽培 | 韓国南部 | 3月上中旬 | 6月上旬-中旬 |
| 高冷地栽培 | 山間部 | 5-7月 | 8-10月 |
| 播種限界期 | 韓国全土 | 6月末-7月初め | これ以降は霜が来る前に熟しません |

&nbsp;&nbsp;&nbsp;晩霜が完全に終わったあとに植えるのが原則です。インゲンマメは霜に当たるとそのまま枯れ、10度未満では発芽すらしません。急いで植えると種子が土の中で腐ります。反対に遅すぎると、開花期が猛暑にかかったり登熟期が梅雨に浸かったりします。

> **適期の範囲内で2週間おきに二三回に分けて植えれば、開花期が分散し、猛暑や干ばつが一度に全部を奪うことはなくなります。労働も同時に分散されます。**

### 6-2. 種子の準備

| 項目 | 方法 | 災害条件下で |
|---|---|---|
| 選別 | 斑点、変色、しわ、虫食い穴のある種子を捨てます | 炭疽病は種子伝染します。選別が防除の半分を占めます |
| 大きさ選び | 太くて重い粒を選んで使います | 水に浮かせて浮いたものを取り除きます |
| 温水消毒 | 50-55度の水に10-15分浸けます | 種子伝染性の病原菌を殺します |
| 灰処理 | 細かい草木灰をまぶします | 消毒と乾燥を助け、鳥や地中の虫を遠ざける効果があります |
| 根粒接種 | インゲンマメを育てた畑の土をまぶします | 5-3節参照。消毒と同時には行いません |
| 浸種 | 植える前日、12時間以内のみ | 長く浸けると種皮が破れ、土の中で腐ります |
| 発芽試験 | 濡れた布に20粒を包み、数日置いて数えます | 古い種子は必ず先に確認します |

&nbsp;&nbsp;&nbsp;浸種は慎重に行う必要があります。インゲンマメの種子は水を急速に吸うため、12時間を超えると種皮が裂けて内部が柔らかくなります。その状態で土に入れると発芽する前に腐ります。土が十分に湿っているなら、まったく浸けずに植える方が安全で、乾いた土であれば六七時間ほど浸けてから水気を乾かして植えます。

### 6-3. 播種方法

| 項目 | 基準 | 理由 |
|---|---|---|
| 播種の深さ | 3-5cm | 種子の大きさの二三倍です。浅いと鳥が掘って食べます |
| 一穴あたりの粒数 | 2-3粒 | 鳥や地中の虫による被害を考慮します |
| 直立型の植付け距離（早生） | 40cm × 15cm | |
| 直立型の植付け距離（晩生） | 50cm × 15cm | |
| つる性の植付け距離 | 75cm × 30-40cm | 広く植えて通風を確保します |
| 間引き | 本葉3-4枚の頃に1-2本を残します | |

&nbsp;&nbsp;&nbsp;播種直後の最大の脅威は鳥と地中の虫です。インゲンマメは子葉が地上に出て、その子葉が大きく柔らかいため、ハトやカササギやキジが好んでついばみます。子葉を失うと、その株はたいてい枯れます。播種した筋の上に木の枝や藁を薄く覆うか、発芽するまでネットや古い防虫網をかぶせ、光る紐を交差させて張っておきます。細かい草木灰を種子にまぶすと、地中の虫の接近も減ります。

&nbsp;&nbsp;&nbsp;つる性は、播種前か本葉一二枚の頃に支柱を先に立てておきます。つるが伸びたあとに支柱を挿すと根が切れ、つるが傷みます。トウモロコシと一緒に植える場合は、トウモロコシを先に植えて膝の高さまで育ったあとに、その根元にインゲンマメを植えます。同時に植えると、インゲンマメが先に育ってまだ幼いトウモロコシに巻き付いて倒してしまいます。

## 7. 水管理

| 時期 | 水管理 | 理由 |
|---|---|---|
| 播種から発芽まで | 土が乾き切らないようにします | 種子が水を吸って初めて発芽します |
| 生育初期から開花前まで | やや乾燥気味に管理します | 過湿だと徒長し、根が傷みます |
| 開花から莢肥大期まで | 10-15日おきに十分に与えます | 莢の肥大に直結します |
| 30度を超える高温期 | 畝間に水を引いて地温を下げます | 落花と不稔を減らします |
| 梅雨の時期 | 排水路を作ります | 下葉が黄色くなって落ちます |
| 登熟期 | 灌水を中止します | 過湿だと脱粒や品質低下が起こります |

&nbsp;&nbsp;&nbsp;インゲンマメは過湿と乾燥のどちらにも弱く、水管理の幅が狭い作物です。根が浅く広がるため表層が乾くとすぐに萎れ、水がたまると根が腐ります。少量を頻繁に与えるより、10日から15日おきに土の深さ20cmまで湿るよう一度にたっぷり与える方が、根を深くのばして有利です。

| 症状 | 原因 | 対処 |
|---|---|---|
| 日中に葉がしおれ夕方に回復する | 一時的な水分不足。正常な範囲です | そのままにします |
| 朝になっても葉がしおれている | 根が水を吸い上げられていません | 水をたっぷり与えます |
| 花が大量に落ちる | 30度を超える高温、または乾燥 | 畝間に水を引いて地温を下げ、マルチングします |
| 莢は付いているが粒が小さい | 莢肥大期の水不足 | この時期の灌水が収量を直接左右します |
| 下葉が黄色くなって落ちる | 梅雨時期の過湿 | 排水路を作り、土を盛ります |
| 茎の根元が茶色く軟らかくなる | 過湿による根腐れ | ひどい場合は抜き取ります。広がると畑全体に及びます |
| 葉全体が薄い黄色だが萎れてはいない | 根粒が機能せず窒素不足 | 根を掘って根粒を確認します |

&nbsp;&nbsp;&nbsp;高温期に畝間に水を引く方法は、インゲンマメにおいて特に効果が大きくなります。30度を超える日が続くと花が落ちますが、これは気温そのものよりも根の周りの地温が上がって根がうまく機能しなくなることが原因である場合が多いです。早朝や日暮れ時に畝間に沿って水を流すと、地温が数度下がり、落花が目に見えて減ります。マルチングを併用すると効果が長持ちします。

&nbsp;&nbsp;&nbsp;マルチングは水を節約するもっとも安価な手段でもあります。ビニールがなくても、藁、籾殻、落ち葉、刈り取った雑草で5cmから10cm覆えば、表面からの蒸発が半分以下に減り、地温の変動も緩やかになります。ただし梅雨の時期には一部を取り除いて通風を確保する方が、病害予防に有利です。
