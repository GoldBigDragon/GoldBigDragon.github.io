## 8. 栽培管理 - 支柱と摘心

### 8-1. 支柱

&nbsp;&nbsp;&nbsp;つる性のインゲンマメにおいて支柱は選択ではありません。2-3mまで伸びるつるが巻きつく対象を見つけられないと、互いに絡み合って地面に倒れ込み、そこから葉が重なって光を失い、風通しが悪くなって炭疽病が広がり、莢が土に触れて腐ります。

| 方法 | 資材 | 特徴 |
|---|---|---|
| A字支柱 | 長い棒3-4本 | 上部を束ねて三角形に立てます。風に強いです |
| 網誘引 | 支柱と網 | 収量がもっとも高くなります。網があるなら最善です |
| 縄誘引 | 支柱と縄 | 支柱の間に縄を何段にも張ります |
| トウモロコシの茎 | トウモロコシ | 資材がまったくかかりません。三姉妹農法 |
| 木の枝挿し | 小枝 | 短いつる性にのみ適します |

> **つるが巻きつく対象は直径2cm前後がもっとも良く、太い柱には巻きつけません。太い支柱だけを立てておくと、つるが何もつかめないまま地面に倒れ込みます。**

&nbsp;&nbsp;&nbsp;設置の時期が重要です。播種前か本葉一二枚の頃に立てます。つるが既に伸びたあとに支柱を挿すと、浅く広がった根が切れ、つるが折れます。あらかじめ立てておけば、つるが自分で見つけて登っていきます。

&nbsp;&nbsp;&nbsp;三姉妹農法は、資材なしで支柱を得る方法です。トウモロコシを先に植えて膝の高さまで育てたあと、その根元にインゲンマメを植え、二つの作物の間の空いた場所にカボチャを植えます。トウモロコシは支柱となり、インゲンマメは窒素を分け与え、カボチャの葉が地面を覆って雑草を防ぎ水分を守ります。ただし、インゲンマメは40%遮光で収量が半分に落ちる作物であることを覚えておく必要があります。トウモロコシを密植しすぎると、インゲンマメが陰に埋もれてしまいます。トウモロコシの間隔を十分に空け、畝を南北方向に立てて、影が一方に長くとどまらないようにします。

### 8-2. 摘心

| 回数 | 時期 | 方法 | 効果 |
|---|---|---|---|
| 1回目 | 本葉3-5節 | 茎の先端の生長点を摘み取ります | 側枝が増えます |
| 2回目 | 新しく出た枝が3-5節 | 再び生長点を摘み取ります | 花と莢が増えます |
| 中止 | 花が咲き始めたら | 行いません | 開花後の摘心は収量を減らします |

&nbsp;&nbsp;&nbsp;摘心は直立型のインゲンマメで特に効果が大きくなります。上に伸びる力が横に転じて側枝が増え、花が付く節の数が増えます。つる性は上に伸びることが目的なので、支柱の先端に達したときに一度だけ摘み取ります。

&nbsp;&nbsp;&nbsp;ただし、どんな状況でも良いわけではありません。痩せた畑で既に生育が振るわないインゲンマメに摘心をすると、回復する力がなく収量がさらに減ります。畑を見回して、葉の色が濃く節間が広がっていれば摘心し、葉の色が薄く生育が止まっていればそのままにします。そして花が咲いたあとは行いません。開花後の生長点は、もはや草丈を伸ばす場所ではなく、新しい莢が付く場所だからです。

### 8-3. 間引きと除草

| 作業 | 時期 | 方法 |
|---|---|---|
| 1回目の間引き | 本葉1-2枚 | 密集しすぎている場所だけを整理します |
| 2回目の間引き | 本葉3-4枚 | 一穴あたり1-2本を残します |
| 1回目の除草 | 播種後2-3週 | 浅く土をかきます。根が浅いため深く入れると切れます |
| 2回目の除草 | 開花前 | これ以降は畑に入りません |

&nbsp;&nbsp;&nbsp;インゲンマメの根は浅く広がっています。鍬を深く入れると細根が切れ、むしろ生育が悪くなります。鍬を寝かせて土の表面2cmだけをかく方法にし、株の近くは手で抜きます。土寄せは通常必要ありませんが、株元が揺れるようなら軽く土を寄せてやります。

## 9. 病害虫

&nbsp;&nbsp;&nbsp;インゲンマメの病害虫圧はCです。無防除時の減収率は推定48.9%で、ダイズの二倍を超えます。特に炭疽病がインゲンマメの代表的な病害で、種子で伝染し毎年繰り返されます。

### 9-1. 主な病害

| 病名 | 症状 | 発生条件 | 無農薬での対応 |
|---|---|---|---|
| 炭疽病 | 葉脈と茎と莢に黒みを帯びた赤い潰瘍ができます。莢にくぼんだ斑点が生じるのが特徴です | 高温多湿。種子伝染 | 種子選別と温水消毒が要です。3-4年輪作、通風確保、病株残渣の焼却 |
| べと病 | 葉の表面に黄色い斑点、裏面に灰白色のかびが生じます | 多湿 | 植付け距離の確保、排水、ボルドー液 |
| 菌核病 | 茎が軟らかくなり、白い綿のような菌糸と黒い粒が生じます | 冷涼で湿った条件 | 病株を土ごと掘り出して焼きます。密植を避けます |
| 紫斑病 | 葉と莢に紫色の斑点が生じます | 多湿 | 通風確保、輪作 |
| ウイルス病 | 葉がモザイク状にまだらになり縮れます | アブラムシが媒介します | 治療は不可能です。抜いて焼却し、アブラムシを減らします |
| 根腐れ病 | 茎の根元と根が茶色く軟らかくなります | 過湿、連作 | 排水、畝を高くする、輪作 |

> **炭疽病は種子について翌年へ持ち越されます。莢にくぼんだ黒みを帯びた赤い斑点がある株から採った種子は、それ自体が翌年の病原です。採種の段階で選り出すことが、もっとも安価な防除です。**

&nbsp;&nbsp;&nbsp;炭疽病への対応には順序があります。第一に種子選別です。斑点のある種子を一粒ずつ選んで捨て、温水消毒を行います。第二に輪作です。病原菌が残渣に残って土の中で何年も生き延びるため、3-4年畑を空けます。第三に通風です。植付け距離を守り、支柱を立てて葉を早く乾かします。第四に、雨の後は畑に入りません。濡れた葉に人が触れると胞子が畑全体に広がります。第五に、病気の残渣は畑に戻さず焼却します。

### 9-2. 主な害虫

| 害虫 | 被害 | 無農薬での防除 |
|---|---|---|
| アブラムシ | 汁を吸い、ウイルス病を媒介します | 石けん水（水1Lに無香料石けん20g）を葉の裏に噴きます。テントウムシを保護します |
| カメムシ類 | 莢を刺して汁を吸い、しいなにします | 早朝、露があるうちに手で捕まえて水を入れた容器に入れます |
| ハダニ | 葉の裏で汁を吸い、葉が黄色くまだらになります | 乾燥時に増えます。葉に水を強く吹きかけます |
| ネコブセンチュウ | 根にこぶ状の変形が生じ、生育が振るわなくなります | 3-4年輪作、マリーゴールドの間作 |
| インゲンマメゾウムシ | 畑で莢に卵を産み、貯蔵中に種実を食い荒らします | 貯蔵管理が要です。15節参照 |
| 鳥（ハト・カササギ・キジ） | 発芽直後に子葉をついばみます | 発芽まで藁や網で覆います |
| 地中の虫（コガネムシの幼虫・ネキリムシ） | 植えた種子や幼い茎を食べます | 種子に草木灰をまぶし、朝に切られた株の周りを掘って捕まえます |

### 9-3. 無農薬の防除資材

| 資材 | 作り方 | 対象 | 注意 |
|---|---|---|---|
| ボルドー液 | 水100Lに硫酸銅1kgと生石灰1kgをそれぞれ別々に溶かして混ぜます | 炭疽病、細菌病の予防 | 銅がないと作れません。混ぜたらすぐに使います。治療ではなく予防です |
| 石けん水 | 水1Lに無香料石けん20g | アブラムシ、ハダニ | 日中の暑い時間に撒くと葉が焼けます |
| 乾いた灰まき | 露のある朝に葉に細かい灰をまきます | 葉を食べる虫、かびの忌避 | カリウム供給も兼ねます |
| 草木灰水 | 灰1升を水10Lに一晩浸し、上澄みを使います | かびの抑制 | アルカリ性なので薄めて使います |
| 木酢液 | 炭を焼くときに出る液を300-500倍に希釈します | 忌避、生育促進 | 原液は強酸性のため必ず希釈します |
| 辛い唐辛子・ニンニク水 | すりおろして水に浸し、こして使います | 忌避 | 効果が長く続かないため頻繁に撒きます |
| 牛乳希釈液 | 牛乳を水で5-10倍に希釈します | うどんこ病、ハダニ | 残すと傷んでにおいが出ます |

### 9-4. 耕種的防除

| 方法 | 原理 |
|---|---|
| 種子選別 | 炭疽病は種子伝染です。斑点と変色を選り出すだけで発生を大きく減らせます |
| 温水消毒 | 50-55℃で10-15分行い、種子表面の病原菌を殺します |
| 3-4年輪作 | 炭疽病菌と線虫が土の中で減るのを待ちます |
| 支柱と植付け距離 | 通風が良いと葉が早く乾き、かびが定着できません |
| 排水 | インゲンマメの病害の多くは過湿と関係します |
| 播種期の分散 | 2週間おきに分けて植え、リスクを分散します |
| 雨の後の畑への立ち入り禁止 | 濡れた葉に人が触れると炭疽病が畑全体に広がります |
| 残渣処理 | 病気の残渣は必ず焼却します。健全な残渣だけを畑に戻します |

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然材料での対処 |
|---|---|---|
| 下葉から全体が薄い黄色になり、株が小さい | 窒素欠乏。根粒不良がよくある原因です | まず根を掘って根粒を確認します。根粒がなければ尿の10倍希釈液を少量与えます |
| 葉の縁が茶色く枯れる | カリウム欠乏 | 草木灰を株の間にまき、軽くかき込みます |
| 生育が遅く葉が紫がかる | リン酸欠乏 | 骨粉、魚の骨を焼いた粉、草木灰 |
| 花は咲くが莢が付かない | ホウ素欠乏、または30度を超える高温 | 複数の材料を混ぜた堆肥。畝間に水を引いて地温を下げます |
| 葉脈の間が黄色い | マグネシウムまたは鉄欠乏 | 灰の使用をやめます。腐葉土と完熟堆肥で有機物を増やします |
| 新しい葉が小さく奇形で生長点が枯れる | カルシウムまたはホウ素欠乏 | 卵の殻を焼いた粉、貝殻の粉 |
| 葉だけが濃い緑色で茂り莢が少ない | 窒素過剰 | 窒素の供給を即刻中止します。摘心で側枝を誘導します |
| 下葉が黄色くなって落ちる | 梅雨時期の過湿 | 排水路を作ります。肥料の問題ではありません |

&nbsp;&nbsp;&nbsp;インゲンマメで葉が黄色くなる症状は原因が複数あるため、見分けが必要です。下葉から徐々に黄色くなりながら株が小さければ窒素欠乏です。梅雨のあとに下葉が一気に黄色くなって落ちれば過湿です。葉脈は緑色なのにその間だけが黄色ければマグネシウムか鉄の欠乏です。対処が互いに異なるため、あわてて肥料を与える前に症状の形をよく見る必要があります。

&nbsp;&nbsp;&nbsp;微量元素の欠乏には一つずつ対応するのが難しいものです。化学肥料なしにモリブデンやコバルトを手に入れる方法は事実上ありません。その代わり、野菜くず、果物の皮、卵の殻、魚の骨、落ち葉、雑草、灰を一緒に混ぜて腐らせた堆肥には、微量元素が一通り入っています。堆肥場に何でも入れるという原則が、微量元素管理の実質的な戦略になります。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 作物 | 理由 |
|---|---|---|
| 良い | トウモロコシ・カボチャ | 三姉妹農法。支柱、窒素、地面被覆を互いに与え合います |
| 良い | マリーゴールド | 根の分泌物が線虫を抑えます |
| 良い | サンチュ・ホウレンソウ | 地面を覆って水分を守ります。養分の競合が少ないです |
| 良い | ジャガイモ | 互いの病害が重なりません |
| 普通 | キャベツ・ハクサイ類 | インゲンマメの後に植えると残った窒素を使えます |
| 注意 | トマト・トウガラシ・ナス | 病害虫を共有する可能性があります |
| 悪い | ニンニク・タマネギ類 | 分泌物が根粒菌を抑制するという報告があります |
| 悪い | 他のマメ科との連作 | 炭疽病と線虫が蓄積します |

&nbsp;&nbsp;&nbsp;三姉妹農法をもう少し具体的に記しておきます。トウモロコシを30cm間隔で先に植え、トウモロコシが膝の高さになったら、各株の根元から10cmほど離れた場所につる性のインゲンマメを二三粒植えます。トウモロコシの列と列の間の広い空き地にカボチャをまばらに植えます。インゲンマメのつるがトウモロコシに巻き付いて登り、カボチャの葉が地面を覆います。トウモロコシは窒素を多く要求しますが、インゲンマメがその一部を供給し、カボチャの広い葉が雑草を抑え水分の蒸発を防ぎ、とげのある茎が獣の接近を妨げます。

&nbsp;&nbsp;&nbsp;この配置で一つ注意すべき点は光です。インゲンマメは40%遮光で収量が半分に落ちます。トウモロコシを密植すると、インゲンマメが陰に埋もれてつるだけが長く伸び、莢を付けません。トウモロコシの間隔を慣行より広めに取り、畝を南北方向に立てて、影が一方に長くとどまらないようにします。

### 11-2. 輪作

| 項目 | 基準 |
|---|---|
| 休作期間 | 3-4年。韓国農村振興庁の3年休作群です |
| 理想的な周期 | 4年 |
| 連作障害 | 炭疽病とネコブセンチュウが蓄積します |

| 4年輪作の例 |
|---|
| 1年目：インゲンマメ（トウモロコシ・カボチャと一緒に） |
| 2年目：葉物野菜またはネギ類 |
| 3年目：根菜類または穀物 |
| 4年目：ジャガイモまたはサツマイモ |
| 再びインゲンマメへ |

&nbsp;&nbsp;&nbsp;畑が狭くて輪作の余裕がないときの折り合いの付け方を記しておきます。畑を四区画に分け、毎年一区画ずつ移しながらインゲンマメを植える方法がもっとも簡単です。区画を分けられない小さな畑なら、少なくともインゲンマメを植える畝の位置を毎年移します。去年インゲンマメを植えた畝に今年はジャガイモを、去年ジャガイモを植えた畝に今年はインゲンマメを植えるだけでも、炭疽病と線虫の蓄積はかなり遅くなります。

## 12. 収穫と脱穀

### 12-1. 収穫時期の判断

| 用途 | 収穫時期（播種後） | 判断基準 |
|---|:---:|---|
| 莢ごと（サヤ用） | 45-55日 | 莢がまだ柔らかく中の粒が小さいとき |
| 青インゲン | 約60日 | 莢がふっくらして粒は太ったがまだ緑色のとき |
| 乾燥種実（早生の直立型） | 70-80日 | 莢が黄色く枯れ粒が硬くなったとき |
| 乾燥種実（晩生のつる性） | 100-130日 | 下から順に熟します |
| 収穫の判定 | 莢の7-8割が枯れて茶色に変わったとき | |

&nbsp;&nbsp;&nbsp;つる性のインゲンマメは下から上へと熟していきます。下の莢が完全に乾く頃、上にはまだ花が残っています。下から順に摘み取ると、株は新しい花を咲かせ続けて収穫期間が長くなり、そのままにしておくと開花が止まります。直立型は比較的均一に熟すため、一度に刈り取っても損失は少なくなります。

> **雨の予報があれば完熟を待たずに収穫します。乾いた莢が雨に濡れて再び乾くことを繰り返すと、はじけて粒が地面に落ち、濡れた莢にはかびが付きます。**

### 12-2. 収穫と乾燥

| 順序 | 内容 |
|---|---|
| 1 | 晴れて乾いた日、露が乾いたあとに行います |
| 2 | 下の莢から摘むか、直立型は根元を鎌で刈ります |
| 3 | 根は畑に残します |
| 4 | 莢のまま日に4-5日干します |
| 5 | 脱穀したあと陰で5-7日さらに干します |

> **脱穀したインゲンマメを直射日光で乾かすと赤く変色し、品質が落ちます。莢ごと乾かすときは日に当て、粒を取り出したあとは必ず陰で乾かします。**

&nbsp;&nbsp;&nbsp;この二段階の乾燥がインゲンマメにおいて特に重要です。莢は厚く硬いため日に当てて乾かさないとうまく開きませんが、皮が薄く色鮮やかな粒は強い日差しに晒されると色が褪せたり赤く変色したりして種皮が裂けます。裂けた種皮は貯蔵中に虫が最初に入り込む通り道になります。通風のある陰に薄く広げてゆっくり乾かすのが原則です。

### 12-3. 脱穀 - 道具なしでする方法

| 方法 | 道具 | 手順 | 効率 |
|---|---|---|---|
| 袋踏み | 厚い麻袋や袋 | 乾いた莢を袋に入れ、口を結んでから足で踏みます | 少量にもっとも向いています。粒が飛び散りません |
| 殻竿（からざお） | 長い柄に枝を結んだ道具 | むしろを敷き、莢を薄く広げて上から打ちます | 中規模に適します。強く打つと粒が割れます |
| 棒で叩く | 木の棒 | 袋に入れるか、むしろに広げて叩きます | 殻竿がないときの代わりになります |
| 手で剥く | なし | 莢をねじって開きます | 粒が大きいため速いです。種子用に適します |
| 板に打ちつける | 板や桶 | 束をつかんで桶の内側の壁に打ちつけます | 粒が桶の中に集まり損失が少ないです |

&nbsp;&nbsp;&nbsp;インゲンマメは粒が大きいため、強く叩くと割れやすくなります。割れた粒は貯蔵中に虫が先に入り込み、種子にも使えません。袋に入れて足で踏む方式がもっとも損失が少なく、殻竿を使うときは力を抜いて何度も打つ方が良いです。種子用の分は手で剥くのが確実です。

### 12-4. 選別 - 風で選り分ける

| 方法 | 原理 | 手順 |
|---|---|---|
| 風選 | 粒は重く、殻やくずは軽いです | 風のある日に、箕や広い器に入れて高く持ち上げゆっくりと注ぎます |
| 箕であおる | 上下に振りながら前にあおります | 重い粒が後ろに残り、軽いものが前へ押し出されます |
| うちわであおぐ | 一人が注ぎ、一人がうちわで風を送ります | 風のない日に使います |
| 篩(ふるい)にかける | 穴の大きさで分けます | 割れた粒とくずをろ過します |
| 水に浮かせる | しいなや虫食いの粒は軽いです | 水を入れた容器に入れ、浮いたものを取り除きます。その日のうちに再び乾かします |
| 手で選ぶ | 目で見ます | 粒が大きく炭疽病の斑点を見分けやすいです |

&nbsp;&nbsp;&nbsp;インゲンマメでは最後に手で選ぶ段階を必ず設けます。粒が大きいため、炭疽病に感染した種子の黒みを帯びた赤い斑点がよく見えるからです。この一度の目視が、翌年の畑の病気を大きく減らします。明るい場所で白い布の上に広げて見ると、斑点がはっきりと現れます。
