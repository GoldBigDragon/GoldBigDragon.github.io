## はじめに
&nbsp;&nbsp;&nbsp;インゲンマメ(Phaseolus vulgaris)は、メキシコとアンデスの野生のマメから生まれた中南米原産のマメ科の一年草で、トウモロコシ、カボチャとともにアメリカ先住民の農耕の三本柱を成しました。早生の直立種は播種から70-80日で乾燥豆を、60日で青インゲンを収穫できます。種子は全国どこでも入手でき、自家受粉なので純系が保たれます。総合等級はC(40.7点、有効183種中107位)で、短期D(39.1)、長期C(42.3)、副食はSS(61.4点)です。面積当たりの熱量がDで1㎡当たり696kcal、自給ラインの0.27倍で、耐寒性Dと調理・加工Dも重なるため、ごはんではなく副菜の位置と、トウモロコシ畑にいっしょに乗せる位置がインゲンマメの役割です。何よりも先に読むべきなのは10節です。

> **生のインゲンマメや火の通りが足りないインゲンマメは、たった4、5粒で数時間のうちに激しい嘔吐と下痢が起こります。さらに危険なのは、80℃ほどの低い温度で温めると、毒性が生の最大5倍まで上がる点です。必ず5時間以上水に浸し、浸し水を捨てて、ぐらぐらと煮立つ100℃で最低10分以上ゆでてはじめて安全です。**

| 評価 | 項目 |
|:---|:---|
| 強み | SS: 施肥、施設の負担、貯蔵性。S: タンパク質密度、微量栄養素、味、国内での栽培の普及度、自家採種。A: 水の消費量、合成資材を投入しない場合の収量維持率、収量の安定性、種子の寿命。B: 収穫速度、防除の自立度、連作への適応性 |
| 弱み | D: 面積当たりの熱量、永続性、日射、調理・加工の要求度、耐寒性、整地・掘削エネルギー、非食用の価値。C: 温度幅、病害虫圧 |

> **インゲンマメの居場所は単独栽培ではなく組み合わせにあります。トウモロコシの茎を支柱にして上へ伸びれば、支柱の資材も追加の面積も使わずに、畑ひと区画でタンパク質がさらに得られます。**

&nbsp;&nbsp;&nbsp;国内での栽培の普及度Sが実務上もっとも価値があり、一度入手した種子は自家採種で続けられ、乾燥した豆は常温で3年もちます。タンパク質密度Sと微量栄養素Sが副食SSの根拠です。調理・加工Dは、インゲンマメでは不便ではなく安全の問題です。耐寒性Dと温度幅Cは栽培期間を狭めるので、遅霜が終わってから播き、連作への適応性Bは3年休作群です。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | マメ科インゲンマメ属の一年草。メキシコからアンデスにかけての中南米原産で自家受粉 |
| 葉、茎 | 3枚で1組の三出複葉でハート形。つる性は2-3mまで巻きついて上り、直立型は40-60cmで止まる |
| 根、花 | まっすぐな主根に細根が比較的浅く広がり、根粒がつく。花は白、薄いピンク、紫の蝶形 |
| 莢、子実 | 円筒形または平たく長さ10-20cm、粒は4-10個。子実は腎臓の形で大きく、白、黒、まだら、赤がある |

&nbsp;&nbsp;&nbsp;子葉が地上に出て初期の養分を蓄えているので、鳥がついばむとその株はたいてい枯れ、発芽直後の10日間がもっとも危険です。乾燥した子実100g当たり熱量348kcal、タンパク質21.01g(熱量比24.1%)、脂質0.5-1.5g、食物繊維24.4g、糖類3.32g、ビタミンB1 0.48mgで、カルシウム、鉄、マグネシウムが豊富であり、黒インゲンにはアントシアニンがあります。タンパク質はリシンが多くメチオニンがやや足りないので、反対の性質のトウモロコシといっしょに食べると互いを補います。粒が大きく腎臓の形なので芯まで熱が通るのに時間がかかり、外側だけやわらかくて中が堅い状態がもっとも危険です。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽10℃以上(最適26-30℃)。生育10-30℃(最適15-21℃)で、5℃以下で止まる。結実18-28℃で幅は10℃。開花期に30℃以上が数日続くと花と若莢が落ちる。耐寒性がなく霜で枯れる |
| 水、土壌 | 保水力があり水はけのよい砂壌土-壌土、pH5.5-7.5(最適6.0-7.0)、有効土層30cm以上(最適50cm)。作期の蒸発散量は約400mm。根が浅く広がるため湿害にも乾燥にも弱く、1日以上冠水すると根が傷む |

&nbsp;&nbsp;&nbsp;4月に播くと開花期が6月初めになって梅雨の前を通り過ぎ、5月末に播くと7月末の猛暑にぶつかるので、春まきが有利で、夏まきは高冷地でのみ安定します。

| 型 | 高さ、支柱 | 特徴 |
|:---|:---|:---|
| 直立型 | 40-60cm、不要 | 生育50-80日。早く収穫でき手間が少ないが、収穫期間が短い |
| つる性 | 2-3m、必ず必要 | 生育100-130日。収穫期間が長く、面積当たりの収量が高い |

&nbsp;&nbsp;&nbsp;支柱の資材がなければ直立型、トウモロコシをいっしょに植えるならつる性が原則で、直立型は6月末-7月に先に収穫し、つる性は7-9月に長く収穫するので、両方を確保すれば一度の災害で全部を失いません。莢ごと食べるサヤインゲン用でも、豆が太ってくるとレクチンが増えるので、実の入った莢は十分にゆでます。交配第1代の雑種は翌年に形質が散らばるので、固定種や在来種を選びます。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 畑づくり | 20-30cmの深さに耕し、畝は15-20cm以上、排水溝は深さ30cm以上。完熟堆肥1,500-2,000kg/1,000㎡(土の構造のための有機物) |
| 施肥(1,000㎡) | 窒素4-6kg(多いと葉だけが茂って莢が減る)、リン酸7-10kg、カリウム6-8kg(すべて元肥)、酸性土に石灰(播種の3-4週間前)。代替資源は木灰(㎡当たり100-200g)、尿の10倍希釈液、落ち葉の腐葉土 |
| 根粒の接種 | インゲンマメを育てた自分の畑か隣の畑の表土5-15cmの土を、水で軽く湿らせた種子にまぶし、すぐに播種。ダイズやエンドウの畑の土は菌の系統が違うので効率が落ち、10℃を下回ると感染が起こらず、病気の畑の土は炭疽病菌も運ぶ |

> **インゲンマメは、子実で出ていく窒素が根粒の固定する窒素とほぼ同じか、むしろ多いです。茎葉を畑に戻さなければ、インゲンマメの畑はほぼ確実に窒素収支がマイナスになります。**

&nbsp;&nbsp;&nbsp;1ヘクタール当たりの固定量は条件がよいと40-70kg(悪いと15-30kg)ですが、子実で60-75kgが出ていき、茎葉に20-30kgが残るので、つると葉とさやの殻をすべて畑に戻し、家畜に食べさせたならふんをその畑に入れます。開花のころ(播種後5-7週)にスコップで土ごとすくって洗い、根粒を割ってみて、1株15個以上で内側が赤ければ接種がうまくいっています。

| 播種 | 基準 |
|:---|:---|
| 時期 | 遅霜が完全に終わったあと。つる性は4月上旬-下旬、直立型は4月中旬-5月下旬、南部の早まきは3月上中旬、高冷地は5-7月。限界は6月末-7月初め(それ以降は霜の前に熟さない)。適期の中で2週間おきに2、3回に分けて播けば、開花期が分散して猛暑や梅雨が一度に全部を奪えない |
| 種子の準備 | 斑点、変色、しわ、虫食いの穴のある種子を捨てる(炭疽病は種子で伝染するので、選別が防除の半分)。細かい木灰をまぶして鳥と地虫を防ぐ。浸種は12時間以内(超えると種皮が破れて腐るので、土が湿っていれば浸さない) |
| 方法 | 深さ3-5cm、1穴2-3粒。栽植距離は直立型の早生40cm×15cmと晩生50cm×15cm、つる性75cm×30-40cm。本葉3-4枚で1-2本を残して間引く。つる性は支柱を播種前か本葉1、2枚のときに先に立てる |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から発芽 | 土が完全に乾かないように |
| 生育初期から開花前 | やや乾燥気味に(過湿だと徒長し根が傷む) |
| 開花期から莢肥大期 | 10-15日おきに土の深さ20cmまで濡れるよう一度に十分に与える(莢の肥大に直結) |
| 30℃を超える高温期 | 早朝か夕方に畝の間に水を流して地温を下げる(落花と不稔が減り、マルチをすると長持ちする) |
| 梅雨 | 排水溝を掘る(下の葉が黄色く落ちたら湿害) |

| 管理 | 方法 |
|:---|:---|
| 支柱 | つるが巻きつく対象は直径2cm前後がもっともよく、太い柱には巻きつけない。A字支柱(長い棒3-4本を上で束ねる)、ネット誘引(収量がもっとも高い)、紐誘引(杭の間に紐を何段にも張る)、トウモロコシの茎(資材が要らない) |
| 摘心 | 1回目は本葉3-5節で茎先の成長点を、2回目は新しい枝が3-5節のときに摘み取って、側枝と花を増やす。花が咲き始めたら行わず、やせて生育が悪い株にも行わない。つる性は支柱の先に届いたときに1回だけ |
| 間引き、草取り | 間引きは本葉1-2枚で混みすぎた所だけ、3-4枚で1穴1-2本。草取りは播種後2-3週と開花前に、鍬を寝かせて表面2cmだけをかく(根が浅く、深く入れると切れる) |

## 6. 病害虫と養分の問題
| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| 炭疽病 | 葉脈、茎、莢に暗赤色の潰瘍ができ、莢にはくぼんだ斑点。高温多湿で、種子で伝染 | 種子の選別と温湯消毒が核心。3-4年の輪作、風通しの確保、病気の残渣の焼却 |
| 菌核病、根腐病 | 茎が軟らかくなり、白い綿のような菌糸と黒い粒(涼しく湿っているとき) / 根元と根が茶色く軟らかくなる(過湿、連作) | 病株を土ごと掘り上げて焼き、密植を避ける / 排水、畝を高くする、輪作 |
| ウイルス病 | 葉がモザイク状にまだらになって縮れる。アブラムシが媒介 | 治療できない。抜いて焼き、アブラムシを減らす |
| アブラムシ、カメムシ類 | 汁を吸いウイルスを媒介する / 莢を刺して空のさやにする | 石けん水(水1Lに無香料の石けん20g、真昼に散布すると葉が焼ける)を葉の裏にまき、テントウムシを守る / 早朝の露があるうちに手で捕る |
| ネコブセンチュウ、インゲンマメゾウムシ | 根にこぶ状の変形と生育不良 / 畑で莢に卵を産み、貯蔵中に子実を食い荒らす | 3-4年の輪作、マリーゴールドとの間作 / 貯蔵の管理が核心(9節参照) |
| 鳥、地虫 | 発芽直後に子葉をついばむ / 播いた種子と若い茎を食べる | 発芽までわらかネットで覆う / 種子に木灰をまぶし、切られた株の周りを掘って捕る |

> **炭疽病は種子について翌年へ受け継がれます。莢にくぼんだ暗赤色の斑点がある株から採った種子は、それ自体が翌年の病気のもとです。**

&nbsp;&nbsp;&nbsp;ボルドー液は水100Lに硫酸銅1kgと生石灰1kgをそれぞれ別に溶かして混ぜ、すぐに使い、炭疽病と細菌病を治すためではなく予防するために使います。濡れた葉に触れると炭疽病が畑全体に広がるので、雨のあとは畑に入りません。

| 症状 | 原因と対処 |
|:---|:---|
| 下の葉から全体が薄い黄色で株が小さい | 窒素欠乏(根粒不良が多い)。まず根を掘って根粒を確認し、なければ尿の10倍希釈液を少量与える |
| 花が咲いても莢がつかない | ホウ素欠乏、または30℃を超える高温。複数の材料を混ぜた堆肥、畝の間に水を流して地温を下げる |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | トウモロコシ・カボチャ(三姉妹栽培)、レタス・ホウレンソウ(地面を覆って水分を守る)、ジャガイモ(病害が重ならない) |
| 普通 | キャベツ・ハクサイの仲間(インゲンマメのあとに残った窒素を使う) |
| 悪い | ほかのマメ科との連作(炭疽病とセンチュウがたまる) |

&nbsp;&nbsp;&nbsp;三姉妹栽培は、トウモロコシを30cm間隔で先に植え、ひざの高さになったら各株の根元から10cmほど離れた所につる性のインゲンマメを2、3粒播き(同時に播くとインゲンマメが若いトウモロコシに巻きついて倒す)、トウモロコシの条の間の空いた所にカボチャをまばらに植える配置です。トウモロコシは支柱になり、インゲンマメは窒素を分け、カボチャの葉が地面を覆って雑草を抑えます。インゲンマメは40%の遮光で収量が半分になるので、トウモロコシを広めに植え、条を南北方向に立てます。

&nbsp;&nbsp;&nbsp;休作は3-4年(農村振興庁の3年休作群)で、炭疽病とネコブセンチュウがたまります。輪作の例は、1年目はインゲンマメ(トウモロコシ・カボチャと)→ 2年目は葉菜類かネギの仲間 → 3年目は根菜類か穀物 → またインゲンマメです。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | サヤインゲン用の莢ごとは45-55日、青インゲンは約60日(莢がふっくらして粒が太いがまだ緑のとき)、乾燥した子実は早生の直立型70-80日・晩生のつる性100-130日に、莢の7-8割が黄色く乾いて粒が堅くなったとき。つる性は下から熟すので順に摘み、直立型は一度に鎌で刈る |
| 乾燥 | 莢ごと日に4-5日干し、脱穀したあとは必ず風通しのよい日陰で薄く広げてさらに5-7日干す(粒が直射日光を受けると色があせたり赤くなったりして種皮が割れ、虫が入る)。水分12-13% |
| 脱穀、選別 | 袋に入れて踏む(粒が飛ばない)、からざおは力を抜いて何度も打つ(強く打つと粒が割れる)、手でむく(種子用)。最後に明るい所で白い布の上に広げ、手で選んで炭疽病の暗赤色の斑点がある粒を捨てる |

> **雨の知らせがあれば完熟を待たずに収穫します。乾いた莢が雨に濡れてまた乾くことを繰り返すと、はじけて粒が地面に落ち、濡れた莢にはカビが生えます。**

| 採種 | 基準 |
|:---|:---|
| 選抜、収穫 | 炭疽病の症状がなく、莢が多くつき、早く熟した株を畑の内側であらかじめ印をつける。ほかの品種と数m離し、莢が完全に茶色く乾いてから収穫する |
| 選別、保管 | 斑点、割れた粒、しわ、変色を捨てて大きくて艶のある粒だけを残し、日陰で5-7日干して水分12-13%にする。発芽率は2年後65-80%、3年後45-65%なので、3-4年ごとに別の場所の種子を入手して一部を混ぜる |

## 9. 貯蔵
| 段階 | 方法 |
|:---|:---|
| マメゾウムシの防除 | 畑ですでに莢に卵がついて入ってくるうえ、一世代が1か月足らずなので、半年で袋が穴だらけの殻になる。完全密閉がもっとも重要で、木灰(体積の2-5%)、珪藻土(1kg当たり1-3g)、油のコーティング(1kg当たり食用油2-5mL)は補助。高温処理は日に薄く広げて半日、60℃にして卵と幼虫を殺すが、変色を受け入れなければならず、種子用には使わない |
| 容器、点検 | ガラス瓶は3年以上もつが光を遮れないので、暗い所に置く。容器に耳を当ててかさかさ音がすれば虫、かび臭いにおいはカビ、表面の小さな丸い穴はゾウムシが一世代を越えたしるし。2か月に1回点検し、被害があれば全量を取り出して日陰で干し、水に浮かべて空の粒をすくい取り、灰を混ぜてまた密閉 |

## 10. 調理と注意事項
| 中毒 | 内容 |
|:---|:---|
| 原因 | フィトヘマグルチニン(フェゼオルス・レクチン)。赤い系統が特に高く、白い系統はその3分の1ほど |
| 中毒量 | 生の豆または火の通りが足りない豆4-5粒 |
| 症状 | 食べて1-3時間後に激しい吐き気、嘔吐の繰り返し、腹痛、続いて下痢。たいてい数時間から1日で回復するが脱水が危険で、子ども、高齢者、衰弱した人が特に危険 |

| 処理 | レクチンの活性 | 安全性 |
|:---|:---|:---|
| 生 | 基準値 | 危険 |
| 80℃前後で長く加熱 | 基準値の最大5倍 | 生より危険 |
| 100℃の沸騰した湯で10分以上 | ほぼ0 | 安全 |

&nbsp;&nbsp;&nbsp;80℃ほどの熱はレクチンが外へ出やすくなるだけで壊せず、吸収されやすい活性のあるレクチンが増え、100℃に達してはじめて構造が崩れます。そのため、ダイズやレンズマメでは優れた燃料節約法である、いきなりの保温箱での余熱調理、いろりの残り火、火鉢の上での一晩の加熱、ぬるい汁に長く浸すこと、乾燥した豆の粉を水に溶いて飲むことは、インゲンマメでは禁物です。

| 段階 | 方法 |
|:---|:---|
| 1. 浸漬 | 常温の水に最低5時間、8時間以上を推奨(夏は水を替える)。浸さないと外側だけ煮えて中が生煮えになりもっとも危険で、燃料も2倍以上かかる |
| 2. 水を捨てる、すすぐ | 浸し水は必ず捨て、新しい水で2、3回すすぐ |
| 3. ゆでる | 新しい水を入れてぐらぐらと煮立て、100℃で最低10分、安全のためには30分保つ(水が大きな泡で絶えず湧き上がらなければならず、静かに湯気が立つだけの状態は100℃ではない) |
| 4. 確認、水を捨てる | 指で押して完全につぶれるか確かめ(中に芯が残っていれば生煮え)、ゆで汁も捨てる |

| 方法 | 安全の条件 |
|:---|:---|
| 圧力調理 | 浸した豆を15-20分加圧。もっとも安全で燃料が最も少ない |
| ゆでてからの余熱調理 | 必ず先に100℃で10-15分ゆでてから保温箱に入れる |
| 青インゲン | 若いものはレクチンが少なく、沸騰した湯で数分でよい |
| 禁止 | いきなりの余熱調理、炒ること、芽の生食(芽にもレクチンが残る) |
| ゆでて干す | 十分にゆでたあと、折るとぱきっと音がするまで日にからからに干せば数か月保存でき、以後は水に短く浸して温めるだけでよいので、毎回100℃を確保する負担がなくなる。ゆでた豆の塩漬け、ゆでてつぶして干したもの、ゆでて干した青インゲン、あんも同じ原理 |
| 中毒のとき | すぐにやめ、調理したものをすべて廃棄する。ゆでて冷ました水にごく少量の塩と砂糖を溶かして少しずつ頻繁に飲ませ、横にして安静にする。脱水が早い子ども、高齢者、衰弱した人を特に見守る |
| その他 | トリプシンインヒビターは浸したあと100℃で30分以上、オリゴ糖は浸し水とゆで汁を捨て、サポニンは泡をすくい取る。カビの生えた豆は洗っても加熱しても安全にならないので捨てる |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵の点検、種子の発芽試験、支柱資材の手入れ。2月に畑の計画、堆肥の切り返し、炭疽病の斑点がある粒の選別 |
| 3-4月 | 3月に石灰の散布、耕うん、畝と排水溝、南部の早まき。4月につる性の播種、支柱を立てる(播種前)、鳥よけ |
| 5-6月 | 5月に直立型の播種(2週間おき)、間引き、草取り、1回目の摘心。6月に開花、2回目の摘心のあと中止、根粒の確認、青インゲンの収穫開始 |
| 7-8月 | 7月に莢肥大、高温期の畝間灌水、早生種の乾燥した子実の収穫。8月につる性の順次収穫、カメムシの捕殺、炭疽病の監視 |
| 9-10月 | 9月に収穫の仕上げ、莢ごと日に干して乾燥、脱穀。10月に日陰での乾燥、選別、貯蔵、茎葉を戻す |
| 11-12月 | 11月にまきがあるうちに一鍋ゆでて干しておく、貯蔵の点検。12月に貯蔵の点検、翌年の計画 |

> **インゲンマメは、5時間以上浸して浸し水を捨て、100℃で10分以上ゆで、低い温度で長く温めず、炭疽病の種子を選り分け、茎葉を畑に戻せば、トウモロコシといっしょに植えてタンパク質を出してくれる作物です。**
