## 13. 留种

| 项目 | 方法 |
|---|---|
| 留种个体挑选 | 在田间预先标记没有炭疽病症状、结荚多、成熟较早的植株 |
| 隔离 | 与其他品种相距数米，留种用的植株从地块内侧挑选 |
| 收获时期 | 待豆荚完全变褐干燥后收获 |
| 分离 | 用手剥开，避免籽粒破损 |
| 筛选 | 有斑点、破损、皱缩、变色的籽粒全部剔除，只留下颗粒饱满、有光泽的 |
| 干燥 | 阴凉处5-7天。水分12-13% |
| 保存 | 装入密封容器，放在阴凉避光处。与食用豆分开存放 |
| 保存期限 | 常温密封3-4年 |
| 更新 | 每3-4年从别处获取种子，混入部分新种 |

> **菜豆留种中最重要的工作是挑出感染炭疽病的种子。一粒带有暗红色斑点的籽粒，就能在来年让整片田都染上病害。这项只需要充足光线、眼力和时间的工作，是无药条件下最有效的防治手段。**

&nbsp;&nbsp;&nbsp;菜豆是自花授粉作物，纯系容易保持，但不如豌豆那样完美。蜜蜂造成的异花授粉偶尔会发生，因此若同时种植多个品种，应相距数米，留种用的植株从地块内侧挑选。地块边缘的植株最有可能接受到其他品种的花粉。

&nbsp;&nbsp;&nbsp;在田间提前标记留种植株的习惯，会大大改变结果。如果收获后只看籽粒来挑选，选出的只是大小和形状。若在田间挑选，就能同时选出抗炭疽病性、结荚数、耐热性、抗倒伏性这些真正重要的性状。尤其是在病害流行的年份，唯独一株保持洁净的植株，是最珍贵的种子。

| 种子保存期限与发芽率 |
|---|
| 收获当年：90%以上 |
| 经过1年：80-90% |
| 经过2年：65-80% |
| 经过3年：45-65% |
| 4年以后：急剧下降 |

## 14. 毒性 - 菜豆凝集素中毒

&nbsp;&nbsp;&nbsp;本节是本文档中最重要的一节。菜豆只要充分煮熟就是安全且营养出色的食品，但生的或未煮熟的会让人真正生病。而且这种风险的大小和性质与其他豆类不同。

### 14-1. 植物血凝素是什么

&nbsp;&nbsp;&nbsp;菜豆属(Phaseolus)的种子中含有一种叫植物血凝素的凝集素。凝集素是能与糖链结合的蛋白质，是植物为防止种子被吃掉而制造的化学防御物质。这种物质一旦进入人的肠道，就会与肠黏膜细胞表面的糖链结合，阻碍吸收并损伤细胞。名称中的"血凝素"意为使红细胞凝集，被用作衡量这种物质毒性的单位。

&nbsp;&nbsp;&nbsp;问题在于含量。大豆、豌豆和小扁豆中也含有凝集素，但菜豆属的水平不同。红菜豆的凝集素活性可达其他豆类的数十倍。因此大豆没煮熟顶多是肠胃不适，而菜豆仅四五粒就会造成紧急状况。

| 项目 | 内容 |
|---|---|
| 致病物质 | 植物血凝素(菜豆凝集素) |
| 中毒发生量 | 生豆或未煮熟的豆4-5粒 |
| 症状开始 | 食后1-3小时 |
| 主要症状 | 剧烈恶心、剧烈呕吐、腹痛，随后腹泻 |
| 恢复 | 通常数小时到一天内恢复，但脱水很危险 |
| 最危险的对象 | 儿童、老人、已经体弱的人。他们难以承受脱水 |
| 含量较高的品系 | 红菜豆品系含量特别高，白色品系约为三分之一水平 |

> **菜豆中毒既不罕见也不轻微。生豆四五粒，也就是不小心就能顺手吃下的量，几个小时内就会引发剧烈呕吐和腹泻。在缺乏医疗条件下，脱水本身就很危险。**

### 14-2. 低温反而更危险的原因

&nbsp;&nbsp;&nbsp;本节中最反直觉却也最重要的事实就在这里。把菜豆加热到不高不低的温度，毒性反而会比生豆更强。

| 处理 | 凝集素活性 | 安全性 |
|---|---|---|
| 生的 | 基准值 | 危险 |
| 在80℃左右长时间加热 | 基准值的最多5倍 | 比生的更危险 |
| 在100℃沸水中煮10分钟以上 | 几乎为0 | 安全 |

&nbsp;&nbsp;&nbsp;为什么会发生这种情况，原因如下。在干豆中，凝集素与其他蛋白质结合在一起，或被困在细胞壁内，无法在消化道中完全释放出来。80℃左右的热量会松开细胞壁和蛋白质结构，让凝集素更容易释放出来，但还不足以破坏凝集素本身。结果是，容易被吸收的活性凝集素反而增多。只有达到100℃，凝集素的蛋白质结构本身才会崩解，活性才会消失。

&nbsp;&nbsp;&nbsp;这就是它在灾难状况下特别危险的原因。燃料稀缺时，人自然会选择小火慢炖的方式。利用保温箱进行余热烹饪、放在灶灰余火上、放在炭炉上过夜加热，都属于这一类。这些方法对大豆或小扁豆而言是很好的省燃料手段，但对菜豆来说恰恰是最危险的烹饪方式。

> **为了省燃料而用小火长时间炖煮，对菜豆来说是禁忌。即使要用余热烹饪，也必须先在沸水中煮10分钟以上，然后才能放入保温箱。**

### 14-3. 安全食用的步骤

| 顺序 | 内容 | 原因 |
|---|---|---|
| 1. 浸泡 | 在常温水中浸泡至少5小时，建议8小时以上 | 部分凝集素会溶入水中，也为热量传入内部打开通道 |
| 2. 倒掉浸泡水 | 必须倒掉，不用于烹饪 | 连同溶入水中的凝集素和寡糖一起倒掉 |
| 3. 冲洗 | 用清水冲洗一两次 | 洗去表面残留的物质 |
| 4. 大火煮沸 | 倒入新水煮沸，必须达到100℃ | 凝集素在此时被破坏 |
| 5. 保持10分钟以上 | 沸腾后至少10分钟，安全起见可煮30分钟 | 10分钟是最低标准，籽粒大则需要更长时间 |
| 6. 确认煮熟 | 用手指按压看是否完全变软 | 内部若残留硬芯就是没煮熟 |
| 7. 倒掉煮豆水 | 煮豆的水也倒掉比较安全 | 残留的凝集素和寡糖会随之排出 |

&nbsp;&nbsp;&nbsp;这里再强调一次为什么需要浸泡。没有泡过的干菜豆表皮坚硬，热量传不到内部，会出现表面煮熟而内部未熟的状态，而这恰恰是最危险的状态。而且不浸泡的话，燃料消耗会翻倍以上。浸泡在安全和燃料两方面都有好处。夏天水容易变质，要每隔三四个小时换水，或者晚上泡好、早上取出。

&nbsp;&nbsp;&nbsp;如果能用高压锅，是最安全、耗燃料也最少的方式。高压烹饪能达到超过100℃的温度，15到20分钟就足够。但如果前提是没有高压锅，基本做法是往大锅里倒足量的水，盖上锅盖大火煮。要通过声音和蒸汽判断水是否在沸腾，表面只是静静冒着水汽的状态不是100℃，水必须持续翻起大水泡。

### 14-4. 发生中毒时

| 处置 | 内容 |
|---|---|
| 立即停止 | 不再让人吃剩下的豆，煮熟的部分也全部丢弃 |
| 补充水分 | 补充因呕吐和腹泻流失的水分和盐分。用煮开晾凉的水加极少量盐和糖，让患者少量多次饮用 |
| 静养 | 让患者躺下静养。通常数小时到一天内会恢复 |
| 需特别留意的对象 | 儿童、老人、体弱者脱水进展较快，要格外仔细观察 |
| 确认原因 | 查清是哪一锅、哪批豆子出了问题，避免重复同样的失误 |

&nbsp;&nbsp;&nbsp;这种症状可能与膳食纤维引起的腹胀混淆。区分的标准在于强度和发作时间。若是膳食纤维引起的，只是肚子咕咕作响、胀气，且要经过半天才慢慢出现。凝集素中毒则是在食后一到三小时内，突然恶心并剧烈呕吐。呕吐在先、腹泻随后，这个顺序是它的特征。

### 14-5. 其他抗营养成分

| 成分 | 作用 | 去除方法 |
|---|---|---|
| 胰蛋白酶抑制剂 | 阻碍蛋白质分解酶的作用 | 浸泡后在100℃煮30分钟以上 |
| 植酸 | 与铁、锌、钙结合，阻碍吸收 | 通过浸泡、发芽、发酵可减少60-80% |
| 寡糖 | 人体无法消化，由肠道细菌发酵 | 倒掉浸泡水和煮豆水 |
| 皂苷 | 产生泡沫 | 煮制时把泡沫撇去 |
| 霉菌毒素 | 储藏期间由霉菌产生 | 长霉的豆子清洗或加热都不会变安全，须丢弃 |

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;菜豆的耐储性为SS。干籽实在常温下能保存3年，脂肪含量约1%，几乎不会氧化变质。但一旦条件不当，豆象会把储藏的豆子全部变成空壳。

> **豆子不是因为腐烂而损失，而是被虫吃掉而损失。储藏的技术，说到底就是防虫的技术。**

### 15-1. 首先要干燥

| 阶段 | 方法 | 确认 |
|---|---|---|
| 一次干燥 | 带荚在阳光下晒4-5天 | 豆荚彻底晒干 |
| 脱粒 | 在干透之后进行 | 干得不够就不会裂开 |
| 二次干燥 | 阴凉处5-7天，摊薄以便通风 | 直射阳光会导致变色和种皮开裂 |
| 目标水分 | 12-13% | 用牙咬时不会陷进去，而是啪地裂开 |
| 盐粒测试 | 把干盐和豆子一起放入瓶中摇晃 | 盐粒粘在瓶壁上说明还潮湿 |
| 冷却 | 完全冷却后再装入容器 | 温热状态下密封会产生冷凝水 |

### 15-2. 储藏期间的豆象防治

&nbsp;&nbsp;&nbsp;豆象类是储藏豆类的最大威胁。可怕之处在于它在田间就已经开始。成虫会在还长在田里的豆荚上产卵，这些卵进入储藏后孵化，钻进豆粒内部。也就是说，豆子被带进储藏时卵已经附着在上面，一代繁殖不到一个月，半年就能让一袋豆子变成满是孔洞的空壳。

| 方法 | 原理 | 应用 | 效果 |
|---|---|---|---|
| 完全密封 | 隔绝氧气使其窒息 | 装满玻璃瓶或金属罐后封闭 | 最可靠。3-4周内连卵和幼虫都会死亡 |
| 混入草木灰 | 细微颗粒刮伤外骨骼蜡层使其脱水 | 按豆子体积的2-5%混入 | 食用前用水冲洗干净 |
| 硅藻土 | 硅质外壳损伤外骨骼 | 每1kg豆子加1-3g | 效果比草木灰更强，只在干燥状态下起作用 |
| 油脂涂层 | 油膜阻止卵附着与孵化 | 每1kg豆子加2-5mL食用油拌匀 | 留种用的豆子不使用此法 |
| 低温处理 | 零下温度会杀死卵和幼虫 | 寒冬时放在室外数日后再取入 | 取入时要注意防止冷凝水 |
| 高温处理 | 60度可杀死卵和幼虫 | 在阳光下摊薄晒半天 | 须接受豆子变色的代价。留种用不使用此法 |
| 干辣椒·花椒·艾草 | 精油成分抑制产卵 | 一层一层放入 | 属于辅助手段 |
| 木炭·炒盐 | 吸收湿气 | 用布包好放入 | 兼具防霉作用 |
| 埋入草木灰中 | 同时获得密封与物理防治效果 | 在坛子里把草木灰和豆子一层层堆放 | 传统上广泛使用 |

&nbsp;&nbsp;&nbsp;最重要的是完全密封。虫子也要呼吸。在密封容器里，豆子和虫子共同消耗氧气，氧气减少、二氧化碳升高后虫子就会死亡。豆子处于休眠状态，能耐受这种条件。容器装得越满、空隙越少，效果就越快。与一个大罐子相比，分装进几个塞得满满的小罐子更好，这样做还有一个好处：万一一个罐子出问题，也不会损失全部。

&nbsp;&nbsp;&nbsp;油脂涂层和混入草木灰，是印度和非洲小农户长期使用的方法。每1kg豆子加入2-3ml食用油拌匀，让每粒豆子都裹上一层薄膜，或者混入过筛后的细灰，占体积的2-5%。这样虫子无法产生抗性，对人也无害。反正菜豆在烹饪前要泡水五小时以上，草木灰会在这个过程中自然被冲洗掉。

| 容器 | 密封性 | 期限 | 备注 |
|---|:---:|---|---|
| 玻璃瓶 | 非常好 | 3年以上 | 不能遮光，须放在阴暗处 |
| 金属罐 | 非常好 | 3年以上 | 能完全防止老鼠和虫害 |
| 陶坛 | 好 | 2-3年 | 温度变化缓慢，老鼠咬不穿 |
| 厚塑料袋 | 一般 | 1-2年 | 老鼠能咬穿 |
| 地下窖 | 好 | 2-3年 | 一旦渗水会损失全部 |

&nbsp;&nbsp;&nbsp;检查时最可靠的感觉是听觉和嗅觉。把耳朵贴在罐子上如果听到沙沙声，说明虫子在活动；闻到闷湿的气味，说明霉菌已经开始滋生。表面出现细小的圆孔，说明豆象已经繁殖过一代。即便到了这个阶段，把全部豆子取出阴干，放入水中捞去空粒浮起的部分，再混入草木灰重新密封，仍能保住剩下的部分。基准是每两个月检查一次。

## 16. 烹饪与加工

### 16-1. 省燃料同时保证安全的方法

| 方法 | 燃料 | 安全条件 |
|---|:---:|---|
| 高压烹饪 | 最少 | 将泡好的豆子加压15-20分钟。最安全也最省燃料 |
| 煮沸后余热烹饪 | 少 | 必须先在100℃煮10-15分钟，再放入保温箱 |
| 直接余热烹饪 | - | 绝对不能这样做。毒性反而会升高 |
| 炒 | 少 | 炒干豆的方式难以保证安全，不推荐 |
| 鲜菜豆焯水 | 极少 | 嫩豆凝集素含量少，沸水煮几分钟即可 |
| 发芽 | 无 | 菜豆芽仍残留凝集素，不生食，必须煮熟 |

> **菜豆节省燃料的顺序是这样的：先充分浸泡以缩短烹煮时间，然后必须在100℃煮10分钟以上，之后再用余热收尾。颠倒这个顺序，安全就会崩溃。**

&nbsp;&nbsp;&nbsp;要记住，浸泡是节省燃料最主要的手段。泡了八小时的菜豆，煮熟所需时间不到未泡发豆子的一半。费的是水和时间，而不是火。而这种浸泡同时也提高了安全性。在灾难状况下，每晚提前泡好次日要吃的豆子，这一个习惯就能同时兼顾燃料和安全。

&nbsp;&nbsp;&nbsp;这里单独列出对其他豆类有用、但不能用在菜豆上的方法。第一，把泡好的豆子直接放进保温箱。第二，把锅放在灶灰余火或炭炉上过夜。第三，把豆子长时间泡在温热的汤水里。第四，把干豆磨成粉后用水冲开食用。这些都是达不到100℃的烹饪方式，对菜豆来说都是禁忌。

### 16-2. 储藏加工

| 加工 | 步骤概要 | 保存 | 价值 |
|---|---|---|---|
| 煮熟晒干 | 充分煮熟后在阳光下晒至干透 | 数月 | 提前煮一次，之后烹饪时间会缩短 |
| 煮豆盐渍 | 煮熟后一层豆一层盐地装入坛子 | 数月 | 食用前泡水去除盐分 |
| 煮豆捣碎晒干 | 煮熟捣碎后摊薄晒干 | 数月 | 用水化开即成粥 |
| 鲜菜豆焯水晒干 | 焯水沥干后晒干 | 数月 | 冬天加入汤或粥中 |
| 菜豆豆沙 | 煮熟捣碎后过滤去皮 | 数天，晒干后数月 | 易消化，适合儿童和老人食用 |

&nbsp;&nbsp;&nbsp;煮熟晒干这种加工方式对菜豆特别有价值。因为去除凝集素所需的长时间加热已经一次性完成，之后只需用水稍微泡开加热即可。这是一种把燃料集中一次用掉、之后就能节省的结构，尤其能让人摆脱每次烹饪都要确保达到100℃的负担。柴火充足的秋天煮满满一锅晒干储备，就能让整个冬天都吃得安全。

&nbsp;&nbsp;&nbsp;煮熟晒干的菜豆没有水分，因此也更耐虫蛀和霉变。不过如果晒得不够透，霉菌很快就会出现，所以要晒到掰断时发出清脆的响声、断面干脆为止。密封保存可以维持数月。

| 5月 | 直立型播种，间苗，除草，第1次摘心 | 分批间隔2周播种 |
| 6月 | 开花，第2次摘心后停止，检查根瘤，鲜菜豆开始收获 | 开花后停止摘心 |
| 7月 | 豆荚膨大，高温期垄沟灌水，早熟品种收获干籽实 | 超过30℃时给垄沟灌水以降低地温 |
| 8月 | 蔓生型依次收获，捕杀蝽象，监视炭疽病 | 雨后不要进入田地 |
| 9月 | 收尾收获，一次干燥(阳光)，脱粒 | 脱粒后的籽粒放在阴凉处晾干 |
| 10月 | 二次干燥(阴凉)，精选，储藏，茎叶归还田地 | 藤蔓不要焚烧，割下后用作覆盖 |
| 11月 | 加工(煮熟晒干)，检查储藏 | 有柴火时煮满满一锅晒干储备 |
| 12月 | 检查储藏，规划来年 | 每两个月打开罐子检查一次 |

### 17-1. 绝不能忘记的五件事

| 项目 | 内容 |
|---|---|
| 烹饪安全 | 生豆4-5粒就会中毒。浸泡5小时以上、倒掉浸泡水后，在100℃煮10分钟以上 |
| 禁止低温 | 在80℃长时间加热，毒性会比生豆升高至多5倍。余热烹饪必须在煮沸之后才能进行 |
| 种子筛选 | 炭疽病通过种子传播。挑出带暗红色斑点的籽粒并丢弃 |
| 支柱 | 藤蔓缠绕的支撑物直径以2cm左右为宜。与玉米同种则不需要额外材料 |
| 茎叶 | 菜豆随籽实流出的氮，与固氮量大致相当。若不把藤蔓归还田地，就会耗竭地力 |
