## 5. 畑の準備と肥料 - 窒素収支と施肥

### 5-4. 窒素固定の落とし穴

&nbsp;&nbsp;&nbsp;「豆を植えると土地が肥える」という話は、農業の常識として定着しています。半分は正しく、半分は間違いです。この点を正確に理解していないと、マメ科を何年も続けて植えた畑が、かえって痩せていくことになります。

&nbsp;&nbsp;&nbsp;数字で計算してみましょう。リョクトウがよく育てば、1,000㎡から120kgの乾燥した子実が収穫できます。リョクトウの子実のタンパク質は24.5%で、タンパク質を6.25で割ると窒素量が出ます。24.5 ÷ 6.25は3.92、つまり子実の重さの約3.9%が純粋な窒素です。120kgに含まれる窒素は約4.7kgで、ヘクタールに換算すると47kgです。

&nbsp;&nbsp;&nbsp;一方、リョクトウの根粒が固定する窒素は、条件がよいときでヘクタール当たり50～80kgです。生育期間が短いため、絶対量はダイズやソラマメより少なくなります。出ていくものと入ってくるものを並べると、次のようになります。

| 項目 | ヘクタール当たり窒素 | 方向 |
|---|---|---|
| 根粒の固定量（条件が良い場合） | 50-80kg | 入る |
| 根粒の固定量（湿害で根粒が死んだ場合） | 10-20kg | 入る |
| 子実として持ち出し | 40-50kg | 出る |
| 茎葉（茎と葉）に残る窒素 | 20-30kg | 戻せば残り、焼いたり持ち出したりすれば出る |
| 根と根粒に残る窒素 | 8-15kg | たいてい畑に残ります |

&nbsp;&nbsp;&nbsp;リョクトウでこの計算が特別な意味を持つ理由があります。リョクトウは数回に分けて収穫する作物なので、莢だけを何度も摘み取り、茎と葉は畑に立ったままの状態で作期が終わります。構造上、茎葉を土に戻すのが最も簡単な豆です。収穫が終わった後、茎をその場に寝かせておくか、すき込むだけでよく、茎が細くて軟らかいため、数日で朽ちます。元になった文献でリョクトウの刈り株が土壌改良に役立つと記されているのは、このためです。

> **マメ科が土地を生き返らせるのは、窒素を固定するからではなく、固定した窒素の一部を茎と葉に蓄えて畑に残すからです。その茎と葉を持ち出してしまうと、豆は土地から収奪する作物になります。**

&nbsp;&nbsp;&nbsp;ただし、湿害で根粒が死んだ年には、この関係が逆転します。固定量が15kgなのに、子実として45kgを持ち出せば、畑は確実に損をします。韓国の梅雨（チャンマ、6月下旬～7月）に水没したリョクトウ畑は、収量を失うだけでなく、窒素も失います。排水管理は、地力管理でもあるわけです。

| 原則 | 内容 |
|---|---|
| 茎葉は必ず畑へ | 莢を摘んだ後に残った茎と葉を、そのまま畑に寝かせるか、すき込みます |
| 焼かない | 焼くと窒素は気体になって飛び去り、カリウムとリン酸だけが灰として残ります |
| 根は掘り取らない | 根と根粒の窒素は、最も簡単に残せる分です |
| 排水を守る | 根粒が湿害で死ぬと、固定量そのものがなくなります |
| 後作をすぐに続けて植える | リョクトウが残した窒素を、次の作物がすぐに使います |
| 家畜に与えたら糞を戻す | 茎葉を家畜に与えたなら、その家畜の糞尿を必ずその畑に入れます |

### 5-5. 畑の準備

| 項目 | 方法 | 災害時の条件では |
|---|---|---|
| 耕起 | 20-30cmの深さに耕し、平らに整地します | 前作を収穫した跡なら、播く列だけ掘り返すのでも構いません |
| 畝 | 高さ20-25cm | リョクトウ栽培の成否を分ける条件です |
| 排水路 | 深さ30cm以上、最後まで水が抜けるように | 梅雨の前に水を流して確認しておきます |
| 酸度矯正 | pH 6.0-7.0 | 播種の3-4週間前に済ませておきます |
| 石灰 | 酸性土壌に100-200kg/1,000㎡ | 貝殻・卵の殻を焼いて砕くか、草木灰で代用します |
| マルチング | わら、もみ殻、落ち葉、ビニール | 出芽率16%、収量54%増加の効果 |

&nbsp;&nbsp;&nbsp;マルチングの効果がリョクトウで特に大きいのは、3つの理由が重なるからです。第一に、梅雨時の雨粒が土の表面を打って固めるのを防ぎます。リョクトウは播種の深さが2-4cmと浅いため、表面が固まると若い芽が突き破って出てくることができません。第二に、雑草を抑えます。リョクトウは雑草に弱く、開花後は畑に入りにくいため、初期の雑草管理がすべてです。第三に、泥はねが莢に付くのを防いで、病気を減らします。ビニールがなくても、わらやもみ殻、落ち葉で、同じ効果をかなりの部分で得られます。

### 5-6. 施肥量

| 肥料 | 1,000㎡当たり | ㎡換算 | 備考 |
|---|---|---|---|
| 窒素 | 2-4kg | 2-4g | 最小限の量だけ。多すぎると徒長して倒れます |
| リン酸 | 4-7kg | 4-7g | 全量を元肥にします |
| カリウム | 4-6kg | 4-6g | 全量を元肥にします |
| 堆肥 | 1,000kg | 1kg | 完熟したものを使います |
| 石灰 | 100-200kg（酸性土壌） | 100-200g | 播種の3-4週間前 |

> **リョクトウで窒素を節約するのは、倹約ではなく技術です。もともと茎が弱い作物なので、窒素が多いと徒長して倒れ、倒れると何度も摘まなければならない収穫が何倍も難しくなります。**

&nbsp;&nbsp;&nbsp;追肥は、原則として必要ありません。ただし、生育期間が短く、初期に生育が振るわないと、挽回する時間がありません。開花期と開花15日後に生育がはっきり悪ければ、窒素を1,000㎡当たり2kg程度のごく少量だけ補います。災害時には、尿を水で10倍に薄めて株間の土に注ぐのが代替策で、葉にかからないようにします。

### 5-7. 災害時の代替肥料

| 代替資源 | 供給する養分 | 使い方 | 注意 |
|---|---|---|---|
| 草木灰 | カリウム、リン酸、カルシウム | 1㎡当たり100-150gをまいて混ぜます | アルカリ性なので、入れすぎるとpHが7を超えます |
| 完熟堆肥 | 養分全般 | 1㎡当たり1kgを元肥として入れます | 未熟なものは根を傷め、病気を運びます |
| 薄めた尿 | 窒素、カリウム | 水で10倍に薄めて株間の土に注ぎます | ごく少量だけ。徒長に注意します |
| 骨粉 | リン酸、カルシウム | 焼いて砕き、堆肥に混ぜます | 効果はゆっくり現れます |
| 魚の骨・内臓 | リン酸、窒素 | 埋めて腐熟させてから使います | そのまま埋めると、獣に掘り返されます |
| 貝殻・卵の殻 | カルシウム | 焼いて砕き、まきます | 石灰の代わりです。反応が遅いです |
| 前作の残渣 | 有機物 | オオムギのわら、ニンニクの茎、ジャガイモの茎を敷いて、マルチングと肥料を兼ねます | リョクトウは後作として植えることが多く、活用度が高いです |
| もみ殻・稲わら | カリウム、ケイ酸 | マルチングとして敷きます | マルチングの効果はリョクトウで特に大きいです |

&nbsp;&nbsp;&nbsp;リョクトウは前作を収穫した後に続けて植えることが多いため、前作の残渣をそのまま活用するのが最も自然です。オオムギを収穫した畑ならオオムギのわらを、ニンニクを収穫した畑ならニンニクの茎を、その場に敷いてマルチングに使います。この残渣が朽ちて有機物になり、その上でリョクトウが育って窒素を固定し、リョクトウを収穫した後にその茎葉がまた残ります。外から何も持ち込まず、畑の中で循環が続く配置です。

## 6. 播種 - 2期作と遅まき

### 6-1. 播種時期

| 地域・作型 | 播種適期 | 播種限界期 | 収穫時期 |
|---|---|---|---|
| 韓国中部 単作 | 6月上旬-中旬 | 7月中旬 | 9月上旬-中旬 |
| 韓国南部 単作 | 6月中旬-下旬 | 7月下旬 | 9月中旬-下旬 |
| 後作（前作の後） | 6月中旬-7月上旬 | 7月中旬 | 9月下旬-10月上旬 |
| 韓国南部 2期作 1作目 | 4月下旬-5月上旬 | - | 7月上旬 |
| 韓国南部 2期作 2作目 | 7月上旬-中旬 | 7月下旬 | 9月下旬 |

&nbsp;&nbsp;&nbsp;リョクトウの播種可能期間は、韓国では4月上旬から7月下旬までの4か月に及びます。豆類の中で最も広く、これがリョクトウの実質的な価値です。ただし、限界線は霜が決めます。初霜の予想日から90日さかのぼると、その地域の播種限界日が出ます。

> **農業が計画どおりにいかなかったとき、リョクトウの強みが表れます。春作物が冷害で枯れたとき、梅雨で畑が水に浸かって植え直さなければならないとき、7月中旬でもまだ播ける子実作物は、リョクトウのほかにほとんどありません。**

### 6-2. 2期作をどう組むか

&nbsp;&nbsp;&nbsp;韓国南部では、リョクトウの2期作は理論上は可能ですが、実際には条件がつきます。4月下旬に1回目を播くと、登熟期が6月下旬から7月初め、つまり梅雨の入り口にかかります。リョクトウは、熟した莢が雨に当たると、中で芽が出たり腐ったりするため、この時期は危険です。そのため、純粋な2期作よりも、次の2つの配置のほうが現実的です。

| 配置 | 内容 | 長所 |
|---|---|---|
| 前作の後作 | オオムギ・コムギ・ニンニク・タマネギ・ジャガイモを6月に収穫した後、その跡地にリョクトウ | 畑を2回使いながら、梅雨の危険を避けられます |
| リョクトウの次の秋作物 | 9月にリョクトウを収穫した後、ハクサイ・ダイコン・ホウレンソウ | リョクトウが残した窒素を秋作物が使います |
| リョクトウの2期作 | 4月下旬に播種した後、7月上旬に再播種 | 韓国南部の海岸地域のみ。1作目の登熟が梅雨と重なる危険あり |
| 失敗の挽回用 | ほかの作物がだめになった跡に7月まで播種 | その年を丸ごと失わずに済みます |

&nbsp;&nbsp;&nbsp;前作の後作が、最も安定していて、最もよく使われる配置です。オオムギ、ニンニク、ジャガイモを収穫した6月の畑は、すでに耕されていて、肥料もある程度残っています。畝だけを整え直して排水路をさらえば、すぐにリョクトウを植えられます。畑を耕し返すエネルギーを前作と分担して負担することになるため、整地・掘削エネルギーのDという弱点も、かなりの部分が相殺されます。

### 6-3. 種子の準備と播種方法

| 項目 | 方法 | 災害時の条件では |
|---|---|---|
| 選別 | 虫食い穴、変色、しわのある種子を捨てます | 粒が小さく選ぶのが面倒ですが、必ず行います |
| 水に沈める | 水に3-4時間浸し、沈んだものだけを使います | 浮くものは中が空洞か、虫に食われたものです |
| 温湯消毒 | 50-55℃の湯に10-15分浸します | 種子伝染する病原菌を殺します |
| 灰の処理 | 細かい草木灰をまぶします | 消毒と乾燥を助け、鳥を遠ざける効果があります |
| 根粒の接種 | アズキやリョクトウを育てた畑の土をまぶします | 5-3節を参照。消毒とは同時に行いません |
| 発芽試験 | 濡らした布に20粒を包んで数日置き、発芽した数を数えます | 発芽が速いので、3～4日で結果が出ます |

| 項目 | 基準 | 理由 |
|---|---|---|
| 播種の深さ | 2-4cm | 粒が小さく、深いと出てこられません |
| 1穴当たりの粒数 | 2-4粒 | 後で2本を残して間引きます |
| 条間（単作） | 60cm | 風通しと、何度も摘みに通る通路を確保します |
| 条間（後作） | 40-60cm | 個体が小さく育つため、狭めても構いません |
| 株間 | 10-15cm | 密植すると徒長して倒れます |
| 播種量（単作） | 1.5-2kg/1,000㎡ | 豆類の中で最も少ないです |
| 播種量（後作） | 2-3kg/1,000㎡ | 遅く播くほど密に |

&nbsp;&nbsp;&nbsp;条間を広くとる理由は、リョクトウでは特別です。3～4回畑に入って熟した莢を摘まなければならないのに、列が狭いと、人が通るときに茎を折り、まだ熟していない莢を落としてしまいます。収穫用の通路をあらかじめ確保しておくことが、結果として収量を守ります。

&nbsp;&nbsp;&nbsp;播種直後の脅威は鳥です。リョクトウは発芽が4～5日と速く、鳥に狙われる期間は短いのですが、子葉が大きくて柔らかいため、ハトやキジがついばみます。播種列の上にわらを薄く敷くか、網や古い防虫網をかぶせ、発芽初期の数日間は朝夕に畑を見回ります。

## 7. 水管理

| 時期 | 水管理 | 理由 |
|---|---|---|
| 播種から発芽まで | 土がからからに乾かないようにします | 浅く埋まっているため、表層が乾くと発芽が止まります |
| 本葉が展開した後 | やや乾燥気味に管理します | 過湿だと徒長して根が腐ります |
| 開花・結莢期 | 干ばつがひどければ灌水します | この時期の水不足が収量を最も大きく減らします |
| 梅雨時 | 排水路をさらいます | リョクトウ栽培で最も危険な時期です |
| 登熟期 | 灌水を中止します | 熟した莢が雨に濡れると、中で芽が出ます |

> **リョクトウの水管理は、与える技術ではなく、抜く技術です。豆類の中で湿害に最も弱く、栽培期間がちょうど梅雨と重なります。**

| 症状 | 原因 | 対処 |
|---|---|---|
| 日中に葉がしおれ、夕方に回復する | 一時的な水分不足。正常な範囲です | そのままにします |
| 朝にも葉がしおれている | 強い乾燥 | 灌水します |
| 下の葉が黄色くなり、根が黒い | 過湿による根腐れ | 排水路をさらい、土寄せをします |
| 葉全体が淡い黄色だが、しおれてはいない | 根粒が湿害で死に、窒素が途絶えました | 根を掘って確認した後、薄めた尿を少量与えます |
| 花は咲くのに莢がつかない | 開花期の乾燥、またはアブラムシの被害 | 灌水し、葉の裏を調べます |
| 茎だけが長く伸びて倒れる | 窒素過多または過湿 | 水を減らし、翌年の施肥を減らします |
| 熟した莢の中で芽が出た | 登熟期に雨に当たりました | 黒くなったらすぐに摘むしかありません |

&nbsp;&nbsp;&nbsp;最後の項目が、リョクトウ栽培で最も悔しい損失です。すっかり熟した莢が雨に当たると、中で種子が発芽を始め、食べることも播くこともできなくなります。これを防ぐ唯一の方法は、黒くなったらすぐに摘むことです。梅雨が続く時期に熟しつつある莢があるなら、完全に黒くなる少し前であっても摘み取って、室内で乾かすほうがよいでしょう。

&nbsp;&nbsp;&nbsp;マルチングは、水管理の面でも価値が大きいです。表面からの蒸発を減らして干ばつに備え、同時に雨が土をはね上げるのを防いで病気を減らします。ただし、厚く覆って常に湿っていると、逆に根腐れが増えるため、5cm前後で覆い、梅雨時には畝の肩のあたりを少しめくって、土が乾けるようにします。
