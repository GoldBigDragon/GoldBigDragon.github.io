## はじめに
&nbsp;&nbsp;&nbsp;リョクトウ(Vigna radiata)はインド原産のマメ科の一年草で、真夏にまいて初秋に収穫する短く速い作物です。播種から収穫まで60-90日とマメ類で最も短く、収穫速度Aを受けました。そのおかげで、オオムギ・ジャガイモ・ニンニクを収穫した6月の空いた畑に続けてまくことができ、夏作物が梅雨で全滅した7月中旬にもまける、ほぼ唯一の子実作物です。乾燥したリョクトウ一握りと水と暗い場所さえあれば3-5日でもやしができ、発芽中に新しく生じるビタミンCが、新鮮な野菜のない冬の壊血病を防ぎます。総合等級はC(42.0点、有効183種中86位)で、短期C(40.7)、長期C(43.3)、副食はSS(63.7点)です。面積当たりの熱量がDで、1,000㎡に120kg、1㎡当たり422kcal、自給ラインの0.16倍にとどまってマメ類で最も低いため、リョクトウで畑を埋めるのは損です。そのうえ霜に当たると枯れ、湿害に最も弱く、莢が熟すそばからはじけるので、3、4回に分けて収穫しなければなりません。リョクトウは畑の主役ではなく、すき間を埋める作物であり、冬の野菜の問題を解決する作物です。

## 1. 災害への備えの評価
| 区分 | 等級 | スコア |
|:---|:---:|:---:|
| 総合 | C | 42.0 |
| 短期 | C | 40.7 |
| 長期 | C | 43.3 |
| 副食 | SS | 63.7 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: タンパク質密度、施肥、施設の負担、貯蔵性。S: 微量栄養素、水の消費量、味、国内での栽培の普及度、自家採種。A: 収穫速度、防除の自立度、合成資材を投入しない場合の収量維持率、収量の安定性、種子の寿命。B: 連作への適応性 |
| 弱み | E: 耐寒性。D: 面積当たりの熱量、永続性、日射、調理・加工の要求度、整地・掘削エネルギー、非食用の価値。C: 温度幅、病害虫圧 |

> **災害時には、計画は必ず狂います。遅霜で苗を失ったり、梅雨で畑が水没したりしても、7月下旬まで再びまける、ほぼ唯一のマメ類がリョクトウです。**

&nbsp;&nbsp;&nbsp;面積当たりの熱量Dはダイズの半分にも届かず、整地・掘削エネルギーDもここから生じます(畑を耕すエネルギーに対する回収熱量は2.6倍)。そのため主作物ではなく、前作を収穫した空き畑や畑の隅のように、すでに準備された場所に載せます。耐寒性Eは霜が一度降りただけで枯れるという意味で、初霜の予想日から90日さかのぼった日が播種の限界日です(中部は7月中旬、南部は7月下旬)。等級表にない弱みは湿害で、マメ類のなかで水がたまることに最も弱いうえ、栽培期間が梅雨と重なります。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | マメ科ササゲ属の一年草。インド原産で自家受粉 |
| 葉、茎 | 細かい毛のある三出複葉。草丈60-80cmで枝分かれするが、茎が細くて軟らかく倒れやすい |
| 根、花 | まっすぐな主根に細根と根粒がつく。小さな黄色い花が生育後半を通じて咲く |
| 莢、子実 | 細長い円筒形で5-10cm、熟すと黒くなる。子実は小さく丸い濃緑色 |

> **リョクトウの莢は熟すと褐色ではなく黒くなり、黒くなって数日のうちに自らねじれてはじけます。黒い莢はその日か翌日に摘まなければなりません。**

&nbsp;&nbsp;&nbsp;1株に黒い莢、緑の莢、花が同時にあるため、3、4回に分けて摘まなければならず、一度に刈り倒すと半分以上を失います。発芽は4-5日で、マメ類のなかで最も速い部類です。播種後3-4週間の初期管理が収量をほぼ決めます。根粒が窒素を渡すまでに3週間かかり、これは生育期間の4分の1を超えるため、元肥に少量の窒素を入れることに意味があります。100g当たり熱量352kcal、タンパク質24.51g(熱量の27.9%)、脂質1g前後、鉄6mg前後、カリウム1,200mg前後で、糖類は0gです。タンパク質はリジンが豊富でメチオニンがやや足りないので、正反対の穀物と一緒に食べると互いに補い合います。脂質がマメ類で最も少ないため酸化がほとんど起こらず、粉にしても長持ちし、でんぷんを取ってチョンポムク(緑豆でんぷんのゼリー)を作ることもできます。乾燥したリョクトウにはビタミンCがありませんが、芽を出すと新しく生じるため、乾燥したリョクトウともやしは事実上別の食品です。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽は15℃以上(適温25-30℃、15℃を下回ると種子が腐る)。生育15-40℃(適温28-30℃)。結実20-30℃。35℃を超えても耐える |
| 土壌、水 | 排水のよい砂壌土-壌土(水がたまる土地が最も悪い)、地下水位50cm以下 |

> **リョクトウは猛暑に耐えるほぼ唯一のマメ類で、ダイズの花が落ちる35℃でも花を咲かせます。最大の敵は湿害で、畝を20cm以上高くし、排水溝を深く掘る作業がほかのどの管理よりも先です。**

&nbsp;&nbsp;&nbsp;播種の時期は4月上旬から7月下旬までの4か月に及び、ダイズの1か月余りとは比べものになりません。畝を高くしてマルチングを併用すると、出芽率が16%、収量が54%増えます。排水溝は低い側へ水が最後まで抜けるように掘り、梅雨の前に畝間に水を流して確かめます。

| 品種 | 特徴 | 用途 |
|:---|:---|:---|
| ナムピョン | 小粒で莢が多く、収量が高い | 子実ともやしの兼用 |
| ソソン | 小粒種 | もやし専用 |
| チャンアン | 病気とゾウムシに強い | 長期貯蔵 |
| タヒョン | 倒伏と病害に強く、莢が多い | 手間の少ない栽培 |
| チェフン | 成熟がそろい、もやしの収量が高い | もやし、一度に収穫 |

> **災害時の品種選びの優先順位は、収量ではなく、成熟のそろい方と莢がはじけない性質です。摘みに行く人がいなければ、摘めなかった莢ははじけて失われます。**

&nbsp;&nbsp;&nbsp;その次に、ゾウムシへの抵抗性(チャンアン系統)、倒伏への抵抗性、早生性を見ます。もやし用の小粒種は必ず一部を別に確保します。粒が小さいほどもやしがまっすぐふっくらと育ち、大粒種は曲がって軟らかくなります。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 畑の準備 | 畝の高さ20-25cmが成否を分ける。酸性土には播種の3-4週間前に石灰100-200kg/1,000㎡(焼いて砕いた貝殻、卵の殻、木灰で代用する) |
| 施肥(1,000㎡) | 窒素2-4kg、リン酸4-7kg、カリウム4-6kg(全量元肥)、完熟堆肥1,000kg。災害時は木灰㎡当たり100-150g(多いとpH7を超える)と、前作の残渣(麦わら、ニンニクの茎、ジャガイモの茎)をかぶせて肥料にする。窒素を控えるのが技術で、多いと徒長して倒れ、何回にも分けて摘む収穫が何倍も難しくなる。追肥は不要だが、開花期に生育がはっきり悪いときは、尿の10倍希釈液をごく少量与える |
| 根粒の接種 | アズキ・リョクトウ・ササゲを育てて根粒がよくついた畑の、深さ5-15cmの土を、水で軽く湿らせた種子にまぶし、日陰で30分以内にまく(日に当てたり、消毒と併せて行ったりしない)。失敗する条件: pH5.5以下、窒素過多、水がたまること(最も多い原因)、リン酸不足、真夏の炎天下での播種 |

&nbsp;&nbsp;&nbsp;根粒は、開花のころ(播種後5-6週間)と梅雨の後に確認します。株をスコップで土ごと掘り上げて洗い、根粒を割って、1株に15個以上あり、内側が赤またはピンク色なら窒素を固定しており、白色や淡い緑色なら固定しておらず、褐色や黒色なら死んでいます。梅雨の前に赤かった根粒が後で死んでいたら、湿害が原因です。

| 播種 | 基準 |
|:---|:---|
| 時期 | 中部の単作は6月上旬-中旬、南部の単作は6月中旬-下旬、後作(前作の後)は6月中旬-7月上旬。南部の二期作(4月下旬-5月上旬、7月上旬-中旬)は、1作目の登熟が梅雨と重なるおそれがあり、後作のほうが安全 |
| 方法 | 虫食いの穴、変色、しわのある種子を捨て、細かい木灰をまぶす。深さ2-4cm、1か所に2-4粒(本葉1-2枚で2本だけ残して間引く)、条間60cm(後作は40-60cm)、株間10-15cm、播種量は1,000㎡当たり1.5-2kg(後作は2-3kg)。条間は、莢を摘みに通る通路になるので、ゆったり取る。播種直後はハトやキジが子葉をついばむので、わらやネットで覆う |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から発芽まで | 表層が乾かないようにする |
| 本葉が開いた後 | やや乾かし気味に管理する |
| 開花・結莢期 | 干ばつがひどければ灌水する(この時期の水不足が収量を最も大きく減らす) |
| 梅雨、登熟期 | 排水溝を掘り、登熟期には灌水を止める |

> **リョクトウの水管理は、与える技術ではなく、抜く技術です。熟した莢が雨に当たると中で芽が出て、食べることも植えることもできなくなるので、雨の知らせがあれば、まだ十分に黒くなっていなくても摘み、室内で乾かします。**

| 管理 | 方法 |
|:---|:---|
| 草取り | 播種後2週間と4週間(開花前、土寄せを兼ねる)に浅くかく。開花後は根が切れて花が落ちるので行わない。リョクトウに登録された除草剤はなく、ほかのマメ用の除草剤は薬害が出る |
| マルチング | 播種直後に畝間をわら・もみ殻・落ち葉で5cm前後の厚さに覆い、雑草・湿害・泥はねをまとめて防ぐ(梅雨には畝の肩のほうを少し開ける) |
| 支柱 | 草丈が30-40cmのとき、条の両端と2-3mごとに60-80cmの棒や杭を打ち、地面から30-40cmの高さにわら縄を1本回して倒伏を防ぐ(倒れると莢が腐り、熟した莢が見えなくなる) |

## 6. 病害虫と養分の問題
| 病害虫 | 症状と条件 | 薬を使わない防除 |
|:---|:---|:---|
| 根腐病 | 株元と根が褐色になって軟らかくなり、しおれる。過湿 | 畝を高くする、排水溝、石灰で酸度を矯正 |
| 褐斑病、炭疽病 | 葉の褐色の斑点と穴 / 莢と子実の黒い潰瘍(種子伝染)。多湿 | 風通しの確保、病葉の除去、種子の選別、輪作 |
| アブラムシ | 開花期に花茎に群がって汁を吸い、花が落ちて莢がつかない | 3、4日に一度、葉の裏と花茎を調べ、初期に石けん水(水1Lに石けん5g)をかける |
| アズキゾウムシ | 畑の莢に産卵し、貯蔵中に子実を食い荒らす | 熟した莢を長く放置せず、適期に摘む(第9節を参照) |

> **リョクトウの病害の中心には、いつも水があります。薬を作るよりも、畝を高くして排水溝を掘る、スコップ作業のほうが効果が大きいです。**

&nbsp;&nbsp;&nbsp;ボルドー液は、水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜ、褐斑病と炭疽病にすぐ使います。

| 症状 | 原因と対処 |
|:---|:---|
| 葉全体が淡い黄色で、株が小さい | 窒素欠乏。梅雨の後なら湿害で根粒が死んだためで、窒素を与えても回復しないので、まず排水溝を掘って土を乾かし、それでも回復が遅ければ尿の10倍希釈液を少量与える |
| 花が咲いても莢がつかない | ホウ素欠乏、開花期の乾燥、アブラムシの被害。いろいろな材料を混ぜた堆肥、灌水、花茎の点検 |

&nbsp;&nbsp;&nbsp;「豆を植えると土がよくなる」という言葉は、半分しか当たっていません。120kgの子実には窒素が約4.7kg(1ヘクタール当たり47kg)含まれていますが、根粒が固定する窒素は、1ヘクタール当たり条件がよければ50-80kg、湿害で根粒が死ねば10-20kgなので、湿害にあった年は子実を運び出すだけで畑が窒素を失います。土を生かすのは茎と葉に残った窒素なので、莢を摘んだ後は、茎をその場に寝かせるか、すき込みます。

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | トウモロコシとモロコシ(背丈の差で光を分け合い、固定された窒素をそばで受け取る)、オオムギ、コムギ、ニンニク、タマネギ、ジャガイモ(前作にして6月の空き畑に後作)、ハクサイとダイコン(リョクトウの後に植え、残った窒素を使う) |
| 悪い | アズキとササゲ(同じ属なので病原菌とゾウムシを共有するため、隣に置かない) |

&nbsp;&nbsp;&nbsp;リョクトウは、前後を結び付けて配置します。オオムギを6月に収穫してリョクトウをまき、9月に収穫した後にハクサイを植えると、1つの畑で1年に3つの作物がとれ、ハクサイがリョクトウの残した窒素を使います。連作すると根腐病とセンチュウがたまるので、3年以上マメ科を空けます。4年輪作の例は、1年目はオオムギの次にリョクトウ、2年目はトウモロコシまたはモロコシ、3年目はジャガイモまたはサツマイモ、4年目はハクサイ・ダイコン類または葉物野菜です。畑が狭いときは、もやし用の種子をつなぐための数㎡の場所を毎年移します。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 莢が緑色から完全に黒く変わったとき(開花後40-50日、播種後80-90日)。5-7日ごとに畑を回り、黒いものだけを3-4回に分けて摘む。最後の緑の莢は茎ごと刈って日陰で乾かす |
| 要領 | 晴れた日の露が乾いた後に、黒い莢だけをひねって摘む(引っ張ると茎が傷む)。タマネギ用やハクサイ用のネットに入れて日なたで乾かし、ときどき振ると、はじけた粒がネットの底にたまって脱穀の半分が終わる |
| 脱穀、選別 | 乾いた莢をネットごと棒でたたくか、袋に入れて踏むか、布の上に広げて自然にはじけさせる。殻竿でたたくと粒が四方に飛ぶので、むしろの周りをふさぐ。細かいふるいでふるい、傾けた板の上を転がして選別する。唐箕がけは、早朝か日暮れに細く流し落として2、3回行う。水に浮かせるとゾウムシに食われた粒が選別できる(その日のうちに乾かし直し、種子用は除く) |

| 採種 | 基準 |
|:---|:---|
| 選抜 | 莢が一度に熟し、黒くなった後もはじけにくく、倒れていない株を、畑であらかじめ印をつけておく。はじけない形質は遺伝するので、数年選抜するだけで、収穫期が少し遅れても損失の少ない系統になる。自家受粉なので隔離は不要だが、アズキ・ササゲとは収穫と貯蔵を分ける |
| 収穫、保管 | 莢が完全に黒くなった後すぐに摘む。虫食いの穴、変色、しわ、小さな粒を捨て、水分12%以下に乾燥して密閉する。発芽率は収穫した年が95%以上、1年後90%以上、2年後80-90%、3年後70-80%、4-5年後50-70%で、6年目以降は急落する。古い種子は発芽試験をして、発芽率が半分なら播種量を2倍に増やす |

## 9. 貯蔵
| 段階 | 方法 |
|:---|:---|
| 乾燥 | 摘んだ莢をネットに入れて日なたで2-3日、脱穀後はむしろに薄く広げて1-2日 |
| ゾウムシ防除 | 完全な密閉が最も重要(酸素がなくなって虫が死ぬ): 容器をいっぱいに満たして空間を減らし、大きな容器1つより小さな容器いくつかに分ける。ふるった木灰を体積の2-5%混ぜるか(食べる前にすすぐ)、リョクトウ1kgに食用油3-5mLをもみ込む。湯通しは、沸騰した湯に少しつけて冷水で冷まし、もう一度よく乾かす。湯通しと油は種子用には使わない |
| 容器 | ガラス瓶・金属缶は3年以上、かめ・地下貯蔵穴は2-3年、厚手のビニールは1-2年。金属缶は結露、地下貯蔵穴は浸水、ビニールはネズミの被害と小粒の漏れに注意 |
| 点検 | 2か月に一度。容器に耳を当てて、かさかさという音(虫)、かび臭いにおい(かび)、小さく丸い穴(ゾウムシ)を確認する。見つけたら全量を取り出して日なたで乾かし、水に浮かせて空の粒をすくい取り、灰を混ぜて再び密閉する |

> **豆は腐って失うのではなく、虫に食われて失います。貯蔵の技術は、すなわち虫を防ぐ技術です。**

## 10. 調理と注意事項
| 成分 | 作用 | 除去 |
|:---|:---|:---|
| トリプシンインヒビター | タンパク質分解酵素を妨げ、腹部の不快感とタンパク質の利用率の低下 | 4時間浸した後、沸騰した湯で30分-1時間煮る(ダイズよりはるかに少ない) |
| フィチン酸 | 鉄・亜鉛・カルシウムの吸収を妨げる | 浸水と発芽で60-80%減少 |

> **リョクトウで人を害するのは、豆そのものではなく、誤って貯蔵してかびが生えた豆です。かび臭いにおいがしたり、表面に青みがかった粉が見えたりしたら、惜しまずに捨てます。**

&nbsp;&nbsp;&nbsp;強いレクチンも溶血性の成分もないので、マメ類で毒性の危険が最も低く、消化がよいので病人・高齢者・子どもにも安全です。

| 調理 | 方法 |
|:---|:---|
| 浸水、煮る | 室温の水に4時間浸した後、沸騰した湯で30分-1時間煮る。皮をむいて割ったものは20分で、密閉して1-2か月保管できる |
| リョクトウ粥 | 煮てつぶしたリョクトウを米と一緒に炊く(病人食) |
| でんぷん、チョンポムク | 浸して挽き、水に溶いて沈殿させた沈殿物を乾かすとでんぷん粉(数か月保存)になり、水で溶いて煮るとチョンポムクになる(脂質が少なくてよく固まる) |
| その他の加工 | 炒って挽いた粉は密閉して3-6か月保存でき、調理燃料が要らない。皮は家畜の飼料と堆肥にする |

&nbsp;&nbsp;&nbsp;乾燥したリョクトウにはビタミンCがないため、新鮮な野菜のない冬には、数か月かけて壊血病(歯茎からの出血、治らない傷)が静かに進みます。乾燥したリョクトウ100gはもやし500-700gになり、増えた重さはほとんど水なので熱量は増えませんが、なかったビタミンCが生じ、フィチン酸とインヒビターが減ります。

| もやし | 方法 |
|:---|:---|
| 1. 選別、浸水 | 小粒種から、割れたり虫に食われたりした粒(腐って全体を傷める)と、すすぐときに浮く粒(たいてい死んだ粒)を捨て、ぬるま湯に6-8時間浸して2倍にふくらませる |
| 2. 入れる、暗くする | 水が抜ける容器やシル(穴あきの発芽用容器)に入れ、湿らせた布をかぶせて光を完全に遮り、20-25度に置く(光が入ると緑色になって硬く苦くなる) |
| 3. 水やり | 1日3-4回、上から十分に注いで完全に水を抜き、浮いてきた緑の皮を毎回取り除く(そのままにすると腐って、もやし全体を傷める)。細根が多く出たら水が足りないというサイン |
| 4. 重しをする、収穫 | 軽い板や石をのせて茎を太くし、3-5日後、長さ4-7cmで、根が褐色になる前に収穫する |

&nbsp;&nbsp;&nbsp;温度が30℃を超えると軟らかくなってすぐ傷み、15℃を下回るときわめてゆっくり育ちます。シルがなければ、底に穴をあけたかめ・桶・ざるに受け皿を置いて黒い布をかぶせればよく、冬はかまどのそばや、オンドル部屋の火元から最も遠い側のように、20度前後の場所を探します。生で食べても安全ですが、沸騰した湯にさっとくぐらせて冷水ですすぐほうがよく、長くゆでるとビタミンCが抜けます。

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵の点検、種子の発芽試験、もやし作り(冬のビタミンC)。2月に堆肥の切り返し、前作との配置の決定 |
| 3-4月 | 3月に石灰の散布(播種の3-4週間前)。4月下旬に南部の二期作の1作目の播種、マルチング資材の準備 |
| 5-6月 | 5月に畝(20cm以上)と排水溝の整備。6月に本播種(中部は上旬、南部は中旬-下旬)、マルチング、鳥よけ。前作を収穫した場所にすぐまく |
| 7-8月 | 7月に草取り・支柱(開花前に除草を終える)、遅まきの限界期(失敗した畑はこのときまで再びまく)。8月にアブラムシの管理、排水溝の点検、根粒の確認 |
| 9-10月 | 9月に分割収穫の開始、ネットに入れて乾かす。10月に収穫の仕上げ、脱穀、選別、茎葉のすき込み |
| 11-12月 | 11月に乾燥、貯蔵、加工、リョクトウのあとに植えた秋作物の管理。12月に貯蔵の点検、もやし作り、翌年の計画 |

> **リョクトウは、畝20cmで排水を守り、黒い莢を5-7日おきに分けて摘み、遅まきで失敗した畑を埋め、もやしで冬のビタミンCを得て、収穫後に茎を畑に戻すとき、その値打ちを発揮します。**
