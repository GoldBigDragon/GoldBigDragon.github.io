## 8. 栽培管理

### 8-1. 间苗与杂草管理

| 作业 | 时期 | 方法 |
|---|---|---|
| 第1次间苗 | 真叶1-2片 | 每穴留2株 |
| 第2次间苗 | 真叶3-4片 | 拔除病株 |
| 第1次锄草 | 播种后2周 | 浅锄 |
| 第2次锄草 | 播种后4周，开花前 | 与培土一并进行 |
| 开花以后 | 不进行除草作业 | 会伤及根系并导致落花 |

> **在韩国，绿豆上没有登记的除草剂，把用于其他豆类的除草剂用在绿豆上会产生药害。即便在有农药的世界里，绿豆也是必须靠手工除草的作物。**

&nbsp;&nbsp;&nbsp;因此，绿豆的杂草管理从一开始就只能依靠物理手段。最有效的是覆盖。播种后立即用稻草、稻壳或落叶覆盖行间，杂草会大幅减少，同时还能防止湿害和泥土飞溅。如果没有覆盖，就在播种后2周和4周各锄草一次，开花开始后便停止。绿豆的根系浅，开花后下锄会切断根系，反而造成减产。

### 8-2. 倒伏管理 - 支柱

| 项目 | 方法 |
|---|---|
| 时期 | 株高长到30-40cm时 |
| 方法 | 在行的两端插上长60-80cm的木棍，拉绳扶住植株 |
| 间距 | 每隔2-3m立一根桩 |
| 高度 | 离地面30-40cm拉一道绳通常就够了 |

&nbsp;&nbsp;&nbsp;绿豆的茎秆没有力气，容易倒伏。尤其是淋雨后荚果变重，就会整株倒下。倒伏的绿豆会造成三种损失：荚果接触泥土而腐烂，通风受阻导致病害蔓延，多次入田采收时看不清哪里已经成熟。其中第三种实际上是最大的损失。

&nbsp;&nbsp;&nbsp;如果没有竹竿或木棍，在行的两侧打下木桩，再用稻草搓成的草绳在齐膝高度围拉一道，也就足够了。因为绿豆不像豌豆那样需要供藤蔓缠绕攀爬的支柱，只需扶住植株、防止其向旁边倒伏即可。同时培土的话，茎基部被土埋住后有了支撑，效果会成倍增加。

## 9. 病虫害

&nbsp;&nbsp;&nbsp;绿豆的病虫害压力为C，但防治自立度为A。这意味着不用农药，仅靠农艺措施和天然材料就能控制相当大的一部分，在豆类中仅次于豇豆，是第二高的值。绿豆的病害大多与土壤过湿有关，只要做好排水管理，多个问题便会一并减少。

### 9-1. 主要病害

| 病名 | 症状 | 发生条件 | 不用农药的应对办法 |
|---|---|---|---|
| 根腐病 | 茎基部和根系变褐软化，植株萎蔫 | 土壤过湿。整个生育期都会发生 | 加高垄、开排水沟、用石灰调节土壤酸度 |
| 褐斑病 | 叶片出现褐色斑点，病斑处穿孔 | 开花期和荚果膨大期湿度大 | 保证通风、摘除病叶、喷波尔多液 |
| 炭疽病 | 荚果和籽粒上出现黑色溃疡斑 | 湿度大。也通过种子传播 | 精选种子、轮作、波尔多液 |
| 白粉病 | 叶面覆盖一层白色粉末 | 干燥且昼夜温差大时 | 保证通风、牛奶5-10倍稀释液 |
| 病毒病 | 叶片出现花叶斑驳并皱缩 | 由蚜虫传播 | 无法治疗。拔除烧毁，并减少蚜虫 |

&nbsp;&nbsp;&nbsp;绿豆病害的核心始终是水。根腐病最常见，造成的损失也最大，褐斑病和炭疽病在潮湿的年份也会加重。把垄加高到20cm以上，并切实开好排水沟，这一项措施就能同时减轻这三种病。这是难得的一种情形：用铁锹搬土，比配制或喷洒药剂的效果更大。

### 9-2. 主要害虫

| 害虫 | 危害 | 不用农药的防治 |
|---|---|---|
| 蝽象类 | 刺吸荚果汁液，造成瘪粒 | 清晨有露水时用手捉住，放入水桶 |
| 蚜虫 | 花期聚集在花序梗上吸食汁液，导致落花并传播病毒 | 发生初期把肥皂水（1L水加5g肥皂）喷在叶片背面 |
| 斜纹夜蛾 | 啃食叶片和茎秆 | 用手捉。发现卵块时连叶一起摘除 |
| 绿豆象 | 在田间把卵产在荚果上，贮藏期间蛀食籽粒 | 贮藏管理是关键。参见第15节 |
| 鸟类（鸽子·野鸡） | 播种后立即啄食子叶 | 出苗前用稻草或网覆盖 |

&nbsp;&nbsp;&nbsp;花期的蚜虫对绿豆尤其是个问题。绿豆在生育后期一直在开花，蚜虫一旦聚集在花序梗上，花就会直接脱落，无法结荚。关键在于发生初期就将其消灭，开花开始后，养成每三四天检查一次叶背和花序梗的习惯也很重要。

&nbsp;&nbsp;&nbsp;绿豆象看似是贮藏阶段的问题，实际上从田间就开始了。成虫把卵产在田里尚未采收的荚果上，这些卵在仓库中孵化。因此，不让成熟的荚果在田里久放、及时采摘，是减少贮藏损失的第一步。勤于分批采收，能同时保住产量和耐储性。

### 9-3. 不用农药的防治材料

| 材料 | 制作方法 | 对象 | 注意事项 |
|---|---|---|---|
| 波尔多液 | 在100L水中分别溶解400g硫酸铜和400g生石灰后混合 | 褐斑病、炭疽病 | 必须有铜才能配制。混合后立即使用 |
| 肥皂水 | 1L水加5g无香料肥皂 | 蚜虫、叶螨 | 在正午炎热时喷洒会灼伤叶片 |
| 撒干草木灰 | 在有露水的早晨把细草木灰撒在叶片上 | 食叶害虫、霉菌 | 下雨会被冲掉 |
| 草木灰水 | 把1升（约1.8升）草木灰浸入10L水中一夜，取上层清液使用 | 抑制霉菌 | 呈碱性，需稀释后使用 |
| 木醋液 | 将烧炭时产生的液体稀释300-500倍 | 驱避、促进生长 | 原液呈强酸性，必须稀释 |
| 辣椒·大蒜水 | 磨碎后用水浸泡，过滤后使用 | 驱避 | 药效持续时间短，需要经常喷洒 |
| 牛奶稀释液 | 将牛奶用水稀释5-10倍 | 白粉病 | 剩下的会变质发臭 |

### 9-4. 农艺防治

| 方法 | 原理 |
|---|---|
| 排水与起垄 | 绿豆病害有一半以上与土壤过湿有关。这是效果最大的一项措施 |
| 覆盖 | 防止泥土飞溅沾到荚果上，并抑制杂草 |
| 调整播种期 | 晚播可以避开害虫发生的高峰期 |
| 及时采摘 | 成熟的荚果在田里放得太久，象甲会在上面产卵 |
| 轮作 | 豆科作物间隔3年以上 |
| 精选种子 | 炭疽病通过种子传播 |
| 保证株行距 | 通风良好，叶片干得快，霉菌无法立足 |
| 残茬处理 | 病残体烧毁，只把健康的残茬还田 |

## 10. 营养缺乏与过量

| 症状 | 原因 | 天然材料处理措施 |
|---|---|---|
| 整片叶子呈淡黄色，植株矮小 | 缺氮。绿豆最常见的情形是湿害导致根瘤死亡 | 先挖出根系检查根瘤。改善排水，并少量施用稀释10倍的尿液 |
| 叶缘变褐干枯 | 缺钾 | 把草木灰撒在株间，轻轻划入土中 |
| 生长迟缓，叶片带紫色 | 缺磷 | 骨粉、烧过的鱼骨粉、草木灰 |
| 开了花却不结荚 | 缺硼，或蚜虫危害 | 用多种材料混合的堆肥。检查花序梗上的蚜虫 |
| 叶脉间发黄 | 缺铁或缺锰。在偏碱性土壤中常见 | 停止使用草木灰。用腐叶土和腐熟堆肥增加有机质 |
| 只有茎徒长而荚果很少 | 氮过量或土壤过湿 | 停止施氮，改善排水 |
| 倒伏 | 氮过量、种植过密、没有支柱 | 培土并拉绳支撑。次年调整施肥量和株行距 |

&nbsp;&nbsp;&nbsp;绿豆叶片发黄时，首先应怀疑的不是肥料不足，而是水。如果在韩国的梅雨季（6月下旬至7月）过后整块田都发黄，几乎可以肯定是湿害，根瘤因缺氧死亡，氮的供应随之中断。这时施氮也无法使其恢复。应先疏通排水沟，排掉沟里的水，让土壤变干；如果这样做之后恢复仍然缓慢，再少量补充氮。

&nbsp;&nbsp;&nbsp;微量元素缺乏很难逐一应对。没有化肥，实际上没有办法获得钼或钴。取而代之的是，把蔬菜碎屑、果皮、蛋壳、鱼骨、落叶、杂草和草木灰混合在一起沤制的堆肥，里面均衡含有各种微量元素。往堆肥场里什么都放的原则，就是微量元素管理的实际策略。

## 11. 间作与轮作

### 11-1. 搭配宜忌

| 搭配评价 | 作物 | 理由 |
|---|---|---|
| 好 | 玉米·高粱 | 因株高不同而分享光照，并能就近获得绿豆固定的氮 |
| 好 | 大麦·小麦·大蒜·洋葱·马铃薯 | 作前茬，6月田地空出，后茬可种绿豆 |
| 好 | 大白菜·萝卜 | 种在绿豆之后，可利用剩余的氮 |
| 好 | 万寿菊 | 根系分泌物能抑制线虫 |
| 一般 | 甘薯 | 要保持距离，避免藤蔓覆盖绿豆 |
| 差 | 红小豆·豇豆 | 同属，病原菌和象甲会直接共享 |
| 差 | 与其他豆科作物连作 | 病原菌和线虫会不断积累 |

&nbsp;&nbsp;&nbsp;安排绿豆位置时最重要的原则，是把前后茬衔接起来。绿豆本身的单位面积热量低，当不了田里的主角，但用来填补前茬与后茬之间的两个半月，却再合适不过。6月收获大麦后种绿豆，9月收获绿豆，再在原地种大白菜，一块田一年就能产出三茬作物。在这个过程中，绿豆留下的氮被大白菜利用，大白菜的残茬又回到土壤中。

&nbsp;&nbsp;&nbsp;最好不要让红小豆和豇豆与绿豆相邻。因为同属豇豆属，会共享病原菌，更重要的是绿豆象会在这三种作物之间来回传播。如果在同一块田里同时种红小豆和绿豆，仓库里的象甲危害会成倍增加。

### 11-2. 轮作

| 项目 | 标准 |
|---|---|
| 休作期 | 3年以上 |
| 理想周期 | 3-4年 |
| 连作障碍 | 根腐病和线虫不断积累 |

| 4年轮作示例 |
|---|
| 第1年：大麦（冬）之后种绿豆（夏） |
| 第2年：玉米或高粱 |
| 第3年：马铃薯或甘薯 |
| 第4年：大白菜·萝卜类或叶菜 |
| 再回到绿豆 |

&nbsp;&nbsp;&nbsp;这里记下田地狭小、没有余地轮作时的折中办法。绿豆的种植面积可以很小。如果主要目的是留住用于绿豆芽的种子，几㎡就足够了，这样的面积每年都可以换地方。另外，绿豆多作后茬种植，所以只要把它叠加在前茬作物的轮作计划上，让位置自然而然地轮换，就不必另外管理。

## 12. 收获与脱粒 - 分批收获

### 12-1. 收获时期的判断

| 判断标准 | 内容 |
|---|---|
| 荚果颜色 | 由绿色完全变为黑色时 |
| 开花后天数 | 40-50天 |
| 播种后天数 | 约80-90天 |
| 收获次数 | 分3-4次 |
| 间隔 | 每隔5-7天巡视田地，采摘黑色荚果 |

> **绿豆荚果变黑后几天之内就会自行扭曲裂开。看到黑色荚果却置之不理，里面的籽粒就会掉到地上消失。错过收获期是绿豆最常见的损失。**

&nbsp;&nbsp;&nbsp;绿豆的开花和成熟在整个生育后期持续进行，因此无法一次收完。同一株上同时有黑色荚果、绿色荚果和刚开的花。原则上每隔5到7天巡视一次田地，只挑变黑的摘，通常分三四次完成。最后剩下的绿色荚果，连茎一起割下，放在阴凉处晾干，也能在一定程度上充实成熟。

&nbsp;&nbsp;&nbsp;梅雨季或多雨时期，判断标准就不同了。等荚果完全变黑期间若被雨淋，荚果里的籽粒会发芽或腐烂。如果天气预报有雨，最好把刚开始变黑的荚果也一并摘下，在室内或屋檐下继续晾干。稍微欠成熟的绿豆晒干后还能使用，但已经发芽的绿豆既不能吃，也不能当种子。

### 12-2. 收获要领

| 顺序 | 内容 |
|---|---|
| 1 | 选晴朗干燥的日子，在露水干了以后进行 |
| 2 | 只用手拧摘黑色荚果。硬拉会损伤茎秆 |
| 3 | 摘下的荚果装入透气的网袋或篮子 |
| 4 | 装入洋葱网袋或白菜网袋，摊在阳光下晒干 |
| 5 | 晒得干透后，连网用棒槌敲打脱粒 |
| 6 | 最后一次收获后，剩下的茎秆平放在田里或翻耕入土 |

&nbsp;&nbsp;&nbsp;装入网袋晾晒的方式对绿豆特别有用。很多荚果在变干过程中会自行裂开，只要在网袋里，弹出的籽粒就会聚集在网袋底部。在阳光好的日子把网袋摊开，偶尔摇晃几下，脱粒工作就已不知不觉完成了一半。没有网袋的话，装进麻袋，或放进大桶里用布盖好也可以。

### 12-3. 脱粒 - 不用工具的方法

| 方法 | 工具 | 步骤 | 效率 |
|---|---|---|---|
| 装网敲打 | 洋葱网袋·白菜网袋 | 把干荚果装入网袋，用棒槌敲打 | 最适合绿豆。籽粒不会漏掉 |
| 装袋踩踏 | 厚麻袋或布袋 | 把干荚果装入袋中，用脚踩 | 少量时方便 |
| 连枷 | 在长柄上拴着细枝条的工具 | 铺开草席，把荚果摊开后捶打 | 籽粒小，会向四面弹射。要把草席四周围住 |
| 用手搓 | 无 | 用双手搓揉干荚果 | 仅限极少量，适合留种用 |
| 摊在阳光下 | 无 | 薄薄地摊在布上，荚果会自行裂开 | 最省力的方法 |

&nbsp;&nbsp;&nbsp;绿豆荚果容易裂开，脱粒非常容易。晒干透的荚果，只要摊在布上，就有一半会自行裂开。问题是籽粒小，会向四面弹射。可以用布把草席四周围住，或者在大桶里作业，或者装入网袋敲打，把弹出的籽粒拦住。损失的籽粒看上去不多，但这种作物本身产量就低，所以损失比例绝对不小。

### 12-4. 精选 - 用风力分选

| 方法 | 原理 | 步骤 |
|---|---|---|
| 风选（扬风） | 籽粒重，而皮壳和碎屑轻 | 有风的日子，把籽粒盛在簸箕或宽口容器里，高高举起，慢慢倒下 |
| 簸扬 | 上下抖动，向前颠簸 | 重的籽粒留在后面，轻的被推向前面 |
| 扇风 | 一人倒，一人用扇子扇风 | 无风的日子使用 |
| 过筛 | 按孔眼大小分开 | 籽粒小，需要细筛 |
| 水选 | 瘪粒和被虫蛀的籽粒较轻 | 倒入水桶，捞出浮起的。当天内重新晒干 |
| 斜板滚选 | 圆形籽粒容易滚动 | 把木板倾斜放置，让籽粒滚下 |

&nbsp;&nbsp;&nbsp;风选的要领有三点。选风力稳定的清晨或傍晚，不要一下子倒完，而是细细地往下流，并重复两三次。绿豆籽粒小而轻，风太大时连籽粒也会被吹走。刚开始先少量试一试，掂量好风力后再正式进行。水选法对挑出被绿豆象蛀空的籽粒特别有效，能大幅减少贮藏损失。不过浸过水的绿豆必须在当天内完全重新晒干，也不能用作种子。
