## 引言
&nbsp;&nbsp;&nbsp;绿豆（Vigna radiata）是原产于印度的豆科一年生草本植物，是盛夏播种、初秋收获的短而快的作物。从播种到收获只需60-90天，是豆类中最短的，因此获得收获速度A。这使它可以在收获大麦、土豆、大蒜后的6月空地上接着播种，并且是夏季作物被雨季毁掉的7月中旬仍能播种的几乎唯一的籽粒作物。只要有一把干绿豆、水和黑暗的地方，3-5天就能长出绿豆芽，发芽过程中新生成的维生素C可以预防没有新鲜蔬菜的冬季的坏血病。综合等级为C（42.0分，有效183种中第86位），短期C（40.7）、长期C（43.3）、副食SS（63.7分）。单位面积热量为D，每1,000㎡仅120kg，每1㎡422kcal，只有自给线的0.16倍，是豆类中最低的，所以用绿豆种满田地是亏本的。而且遇霜就死，最怕渍害，豆荚随熟随裂，要分三四次收获。绿豆不是田地的主角，而是填补空隙的作物，也是解决冬季蔬菜问题的作物。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | C | 42.0 |
| 短期 | C | 40.7 |
| 长期 | C | 43.3 |
| 副食 | SS | 63.7 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：蛋白质密度、施肥、设施负担、耐储性。S：微量营养素、水消耗量、口味、国内种植普及度、自留种。A：收获速度、防治自立度、无合成投入产量保持率、产量稳定性、种子寿命。B：连作适应性 |
| 劣势 | E：耐寒性。D：单位面积热量、持续性、光照、烹调·加工要求度、整地·挖掘能量、非食用价值。C：温度幅度、病虫害压力 |

> **灾害情况下，计划一定会出错。即使因晚霜损失了幼苗，或田地被雨季淹没，到7月下旬仍能重新播种的几乎唯一的豆类就是绿豆。**

&nbsp;&nbsp;&nbsp;单位面积热量D连大豆的一半都不到，整地·挖掘能量D也由此而来（回收的热量只有翻地能量的2.6倍）。所以它不当主作物，而是放在前茬收获后的空地、田角这类已经整好的地方。耐寒性E意味着一次霜就会死，从预计初霜日往前数90天就是播种的最后期限（中部7月中旬，南部7月下旬）。等级表上没有的弱点是渍害，在豆类中最怕积水，而且生长期与雨季重叠。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 豆科豇豆属一年生草本。原产印度，自花授粉 |
| 叶、茎 | 带细毛的三出复叶。株高60-80cm，会分枝，但茎细而软，容易倒伏 |
| 根、花 | 直立主根，带须根和根瘤。小黄花在生长后期持续开放 |
| 荚、籽粒 | 细长圆筒形，5-10cm，成熟后变黑。籽粒小而圆，深绿色 |

> **绿豆荚成熟后不是变褐，而是变黑，变黑几天内就会自己扭曲裂开。黑荚要在当天或次日摘下。**

&nbsp;&nbsp;&nbsp;一株上同时有黑荚、绿荚和花，所以要分三四次摘，一次割倒会损失一半以上。发芽只要4-5天，是豆类中最快的一类。播种后3-4周的前期管理几乎决定产量。根瘤要经过3周才开始提供氮，超过生长期的四分之一，所以基肥中加入少量氮是有意义的。每100g含热量352kcal、蛋白质24.51g（占热量的27.9%）、脂肪约1g、铁约6mg、钾约1,200mg，糖类为0g。蛋白质赖氨酸充足，蛋氨酸略缺，与正好相反的谷物一起吃，可以互相补足。脂肪是豆类中最少的，几乎不会氧化变质，磨成粉也耐放，还可以提取淀粉做绿豆凉粉。干绿豆不含维生素C，但发芽后会重新生成，所以干绿豆和绿豆芽实际上是不同的食物。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽15℃以上（适温25-30℃，低于15℃种子会烂）。生长15-40℃（适温28-30℃）。结实20-30℃。超过35℃也能耐受 |
| 土壤、水 | 排水良好的沙壤土-壤土（积水的地最差），地下水位50cm以下 |

> **绿豆是几乎唯一耐酷暑的豆类，在大豆花朵脱落的35℃下仍然开花。最大的敌人是渍害，把垄起到20cm以上、挖深排水沟，比任何其他管理都要优先。**

&nbsp;&nbsp;&nbsp;播种期从4月上旬到7月下旬，长达四个月，大豆则只有一个月出头，无法相比。起高垄并配合覆盖，出苗率提高16%，产量提高54%。排水沟要挖得让水一直排到低处，雨季前向垄沟里浇水检查。

| 品种 | 特点 | 用途 |
|:---|:---|:---|
| Nampyeong | 籽粒小，荚多，产量高 | 籽粒与豆芽兼用 |
| Sosun | 小粒种 | 仅用于豆芽 |
| Jangan | 抗病，抗豆象 | 长期储存 |
| Dahyeon | 抗倒伏，抗病害，荚多 | 省工栽培 |
| Chaeheun | 成熟整齐，豆芽产量高 | 豆芽，一次性收获 |

> **灾害情况下选品种的优先顺序不是产量，而是成熟整齐和荚不裂的特性。没人去摘的话，没摘下的荚就会裂开而损失掉。**

&nbsp;&nbsp;&nbsp;其次看抗豆象性（Jangan系）、抗倒伏性和早熟性。一定要另外留一部分做豆芽用的小粒种。籽粒越小，豆芽长得越直越饱满，大粒种则会弯曲发软。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 垄高20-25cm决定成败。酸性土在播种前3-4周施石灰100-200kg/1,000㎡（可用烧过捣碎的贝壳、蛋壳、木灰代替） |
| 施肥（1,000㎡） | 氮2-4kg、磷4-7kg、钾4-6kg（全部作基肥），腐熟堆肥1,000kg。灾害时用木灰每㎡100-150g（过量会使pH超过7）和前茬残茬（麦秆、蒜茎、土豆茎）覆盖作肥。省氮是技术，氮多了会徒长倒伏，使要分多次摘的收获难上好几倍。一般不需要追肥，但花期生长明显不良时，可少量浇施稀释10倍的尿液 |
| 根瘤接种 | 用种过红豆、绿豆、豇豆且根瘤长得好的地块5-15cm深的土，裹在稍用水润湿的种子上，在阴凉处30分钟内播下（不要晒，也不要与消毒同时进行）。失败的条件：pH 5.5以下、氮过多、积水（最常见的原因）、缺磷、盛夏烈日下播种 |

&nbsp;&nbsp;&nbsp;根瘤要在开花前后（播种后5-6周）和雨季之后检查。用铁锹连土挖起植株洗净，掰开根瘤，每株有15个以上、里面呈红色或粉红色，说明在固氮；白色或浅绿色说明不固氮；褐色或黑色说明已经死亡。如果雨季前是红色的根瘤之后死了，原因就是渍害。

| 播种 | 标准 |
|:---|:---|
| 时期 | 中部单季6月上旬-中旬，南部单季6月中旬-下旬，后作（前茬之后）6月中旬-7月上旬。南部双季（4月下旬-5月上旬、7月上旬-中旬）有第一季灌浆期与雨季重叠的风险，后作更安全 |
| 方法 | 挑出有虫孔、变色、皱缩的种子扔掉，裹上细木灰。深度2-4cm，每穴2-4粒（长到1-2片真叶时只留2株），行距60cm（后作40-60cm），株距10-15cm，播种量每1,000㎡ 1.5-2kg（后作2-3kg）。行距要留宽些，因为那是去摘荚的通道。播种后鸽子和野鸡会啄子叶，要用稻草或网盖住 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种到发芽 | 不要让表层干掉 |
| 真叶展开后 | 稍干些管理 |
| 开花·结荚期 | 干旱严重时灌溉（这一时期缺水使产量下降最多） |
| 雨季、灌浆成熟期 | 挖排水沟，成熟期停止灌溉 |

> **绿豆的水分管理不是浇水的技术，而是排水的技术。成熟的荚淋了雨，里面的籽粒会发芽，既不能吃也不能种，所以预报有雨时，即使还没完全变黑也要摘下，放在室内晾干。**

| 管理 | 方法 |
|:---|:---|
| 除草 | 播种后2周和4周（开花前，同时培土）浅锄。开花后不要除草，因为会伤根、落花。没有登记用于绿豆的除草剂，用于其他豆类的除草剂会造成药害 |
| 覆盖 | 播种后立刻在行间铺5cm左右厚的稻草、稻壳或落叶，同时防止杂草、渍害和泥点溅起（雨季把垄肩一侧的覆盖物稍微拨开） |
| 支架 | 株高30-40cm时，在行的两端和每2-3m处插60-80cm的木棍或木桩，在离地面30-40cm的高度围一圈草绳，防止倒伏（倒了荚会烂，成熟的荚也看不见） |

## 6. 病虫害与养分问题
| 病虫害 | 症状与条件 | 不用药的防治 |
|:---|:---|:---|
| 根腐病 | 茎基和根变褐变软，植株萎蔫。过湿 | 起垄、挖排水沟、用石灰调节酸度 |
| 褐斑病、炭疽病 | 叶片褐色斑点和孔洞 / 荚和籽粒上的黑色溃疡（种子带菌）。湿度大 | 保证通风、摘除病叶、选种、轮作 |
| 蚜虫 | 花期聚集在花梗上吸汁，导致落花、不结荚 | 每三四天检查一次叶背和花梗，早期喷肥皂水（1L水加5g肥皂） |
| 绿豆象 | 在田间的荚上产卵，储存期间蛀食籽粒 | 成熟的荚不要长时间留在田里，及时摘下（见第9节） |

> **绿豆病害的中心总是水。比起配药，起垄和挖排水沟的铁锹活效果更大。**

&nbsp;&nbsp;&nbsp;波尔多液是分别把400g硫酸铜和400g生石灰溶于100L水，混合后立即用于褐斑病和炭疽病。

| 症状 | 原因与措施 |
|:---|:---|
| 整片叶子浅黄色，植株矮小 | 缺氮。雨季之后出现，说明根瘤因渍害死亡，施氮也无法恢复，所以先挖排水沟让土壤变干，如果恢复仍然缓慢，再少量浇施稀释10倍的尿液 |
| 开花但不结荚 | 缺硼、花期干旱或蚜虫危害。用多种材料混合的堆肥、灌溉、检查花梗 |

&nbsp;&nbsp;&nbsp;“种豆能改良土壤”这句话只对一半。120kg籽粒含氮约4.7kg（每公顷47kg），而根瘤固定的氮每公顷条件好时为50-80kg，渍害使根瘤死亡时只有10-20kg，所以遇到渍害的年份，光是把籽粒运走，田地就会损失氮。使土壤变好的是留在茎叶中的氮，所以摘完荚后，把茎就地放倒或翻入土中。

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 玉米、高粱（利用株高差分享光照，在旁边得到固定的氮），大麦、小麦、大蒜、洋葱、土豆（作前茬，6月空出的田用作后作），白菜、萝卜（种在绿豆之后，利用剩余的氮） |
| 差 | 红豆、豇豆（同属，共享病原菌和豆象，不要种在邻近） |

&nbsp;&nbsp;&nbsp;绿豆要前后衔接着安排。6月收大麦后播绿豆，9月收获后再种白菜，一块田一年可以出三种作物，白菜利用绿豆留下的氮。连作会积累根腐病和线虫，所以豆科要隔3年以上。4年轮作的例子是：第1年大麦之后接绿豆，第2年玉米或高粱，第3年土豆或甘薯，第4年白菜、萝卜类或叶菜。田地窄的话，每年更换用来留豆芽用种子的几㎡地块。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 荚从绿色完全变黑时（开花后40-50天，播种后80-90天）。每5-7天巡视田地，只摘黑色的荚，分3-4次摘完。最后剩下的绿荚连茎割下，在阴凉处晾干 |
| 要领 | 在晴天露水干后，只拧摘黑荚（硬拉会伤茎）。装进洋葱网袋或白菜网袋放在阳光下晒干，不时摇晃，裂开的籽粒会聚在网袋底部，脱粒就完成了一半 |
| 脱粒、清选 | 把干荚连网袋用棍棒敲打，或装进麻袋踩踏，或摊在布上让它们自己裂开。用连枷打会使籽粒四处飞溅，所以要把草席周围围住。用细筛过筛，放在倾斜的木板上滚动来筛选。风选在清晨或傍晚，细细倒下，进行两三次。放入水中可以分出被豆象蛀过的籽粒（当天要重新晒干，留种用的除外） |

| 留种 | 标准 |
|:---|:---|
| 选择 | 事先在田里标出荚同时成熟、变黑后也不易裂开、没有倒伏的植株。不裂的性状可以遗传，只选择几年，就能得到即使稍晚收获损失也小的品系。自花授粉，不需要隔离，但收获和储存要与红豆、豇豆分开 |
| 收获、保存 | 荚完全变黑后立即摘下。扔掉有虫孔、变色、皱缩和小的籽粒，干燥到含水量12%以下后密封。发芽率收获当年95%以上，1年后90%以上，2年后80-90%，3年后70-80%，4-5年后50-70%，6年后急剧下降。陈种子要做发芽试验，发芽率只有一半就把播种量加倍 |

## 9. 储存
| 步骤 | 方法 |
|:---|:---|
| 干燥 | 摘下的荚装进网袋在阳光下晒2-3天，脱粒后在草席上薄摊1-2天 |
| 豆象防治 | 完全密封最重要（氧气耗尽，害虫死亡）：把容器装满以减少空隙，用几个小容器代替一个大容器。拌入筛过的木灰，用量为体积的2-5%（食用前冲洗），或每1kg绿豆拌入3-5mL食用油。热水处理是在沸水中短暂浸一下，用冷水冷却，再彻底晒干。热水和油不能用于留种 |
| 容器 | 玻璃瓶、金属罐3年以上，陶罐、地下储藏窖2-3年，厚塑料袋1-2年。金属罐注意结露，地下储藏窖注意进水，塑料袋注意老鼠咬破和小籽粒漏出 |
| 检查 | 每两个月一次。把耳朵贴近容器，检查沙沙声（害虫）、霉味（霉菌）和小圆孔（豆象）。发现后把全部取出晒干，放入水中捞出空籽粒，拌入灰后重新密封 |

> **豆子不是烂掉而损失的，而是被虫吃掉而损失的。储存的技术，就是防虫的技术。**

## 10. 烹调与注意事项
| 成分 | 作用 | 去除 |
|:---|:---|:---|
| 胰蛋白酶抑制剂 | 抑制蛋白质分解酶，造成腹部不适和蛋白质利用率下降 | 浸泡4小时后在沸水中煮30分钟-1小时（远少于大豆） |
| 植酸 | 妨碍铁、锌、钙的吸收 | 浸泡和发芽可减少60-80% |

> **绿豆中真正伤害人的不是豆子本身，而是储存不当发霉的豆子。如果有霉味，或表面有淡青色粉末，不要可惜，扔掉。**

&nbsp;&nbsp;&nbsp;它既没有强凝集素，也没有溶血成分，是豆类中毒性风险最低的，容易消化，对病人、老人和孩子也安全。

| 烹调 | 方法 |
|:---|:---|
| 浸泡、煮 | 在常温水中浸泡4小时后，在沸水中煮30分钟-1小时。去皮掰开的20分钟即可，密封可保存1-2个月 |
| 绿豆粥 | 把煮烂捣碎的绿豆与大米一起煮（病人餐） |
| 淀粉、绿豆凉粉 | 浸泡后磨碎，加水搅开，把沉淀下来的淀粉晒干就成淀粉（可保存几个月），加水调开煮熟就成绿豆凉粉（脂肪少，凝固得好） |
| 其他加工 | 炒后磨成的粉密封可保存3-6个月，不需要烹调燃料。豆皮用作牲畜饲料和堆肥 |

&nbsp;&nbsp;&nbsp;干绿豆不含维生素C，所以在没有新鲜蔬菜的冬天，坏血病（牙龈出血、伤口不愈合）会在几个月里悄悄发展。100g干绿豆能变成500-700g绿豆芽，增加的重量大多是水，所以热量不会增加，但会生成原本没有的维生素C，植酸和抑制剂也会减少。

| 绿豆芽 | 方法 |
|:---|:---|
| 1. 挑选、浸泡 | 从小粒种中扔掉裂开或被虫蛀的籽粒（会烂掉并污染整批）和冲洗时浮起的籽粒（多半是死的），用温水浸泡6-8小时，胀大一倍 |
| 2. 装盘、避光 | 放进能排水的容器或发芽用的有孔甑里，盖上湿布，完全遮光，保持20-25度（见光会变绿，变老变苦） |
| 3. 浇水 | 每天3-4次从上面充分淋下并完全排净，每次都捞掉浮起的绿皮（不捞会腐烂，污染全部豆芽）。须根长得多是水不够的信号 |
| 4. 压重、收获 | 放一块轻木板或石头使茎变粗，3-5天后长到4-7cm、根变褐之前收获 |

&nbsp;&nbsp;&nbsp;温度超过30℃会变软、很快变质，低于15℃则生长极慢。没有甑的话，在底部打孔的陶罐、桶或筛子下放接水盘，盖上黑布即可；冬天找灶台旁或温突房间里离火口最远的一端这类20度左右的地方。生吃也安全，但在沸水中略烫一下再用冷水冲洗更好，烫得太久维生素C会流失。

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存，做种子发芽试验，生豆芽（冬季的维生素C）。2月翻堆堆肥，确定与前茬的布局 |
| 3-4月 | 3月撒石灰（播种前3-4周）。4月下旬南部双季的第一季播种，备好覆盖材料 |
| 5-6月 | 5月整理垄（20cm以上）和排水沟。6月正式播种（中部上旬，南部中下旬）、覆盖、防鸟。在收获前茬的地块上立刻播种 |
| 7-8月 | 7月除草·立支架（开花前结束除草），晚播的最后期限（失败的田块到此时为止都可重播）。8月蚜虫管理、检查排水沟、检查根瘤 |
| 9-10月 | 9月开始分批收获，装进网袋晒干。10月收尾收获、脱粒、清选，把茎叶还田 |
| 11-12月 | 11月干燥、储存、加工，管理种在绿豆之后的秋季作物。12月检查储存、生豆芽、规划来年 |

> **绿豆要靠20cm高垄保住排水，每隔5-7天分批摘黑荚，用晚播填补失败的田块，用豆芽获取冬季的维生素C，收获后把茎还田，才算物有所值。**
