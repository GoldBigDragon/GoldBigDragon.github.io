## 3. 栽培環境

### 3-1. 気温と光量

| 条件 | 限界値 | 最適値 | 外れたとき |
|---|---|---|---|
| 発芽温度 | 15℃以上 | 25-30℃ | 15℃を下回ると発芽が止まり、種子が腐ります |
| 生育温度 | 15-40℃ | 28-30℃ | 豆類の中で最も暑さに強いです |
| 結実温度 | 20-30℃ | 25-30℃ | 幅は10℃です |
| 高温の限界 | 35℃を超えても耐えます | - | 猛暑に最も強い豆類です |
| 耐寒性 | ありません | - | 霜に一度当たると枯れます |
| 日照 | 1日6時間以上 | 1日8時間以上 | 40%の遮光で収量が半分に落ちます |
| 積算温度 | 1,600℃以上 | - | 短い生育期間に合わせて、要求量は少なめです |

> **リョクトウは猛暑に耐えるほぼ唯一の豆類です。35℃が続いてダイズの花がぼろぼろ落ちる夏にも、リョクトウは咲き続けます。気候が暑くなるほど、リョクトウの相対的な位置づけは高まります。**

&nbsp;&nbsp;&nbsp;この高温への適応力が、リョクトウの播種可能期間を広げます。韓国では4月上旬から7月下旬まで、気温が15℃を超えるいつでも播けます。ただし、播種限界日は霜から逆算する必要があります。初霜の予想日から90日さかのぼると、その地域の播種限界日が出ます。韓国中部ではおおむね7月中旬、韓国南部では7月下旬です。

&nbsp;&nbsp;&nbsp;2期作が可能なのも、この広い播種可能期間のおかげです。韓国南部では、4月下旬に1回目を播いて7月初めに収穫し、すぐに2回目を播いて9月下旬に収穫できます。ただし、1回目の作期の登熟期が韓国の梅雨（チャンマ、6月下旬～7月）と重なる危険があるため、実際には、オオムギ、ジャガイモ、ニンニクを収穫した後の6月の畑に、後作として1回だけ播く方式のほうが一般的で安全です。

### 3-2. 土壌と水

| 条件 | 限界値 | 最適値 | 備考 |
|---|---|---|---|
| 土性 | 砂質土から壌土まで | 排水のよい砂壌土-壌土 | 水がたまる土地が最も不向きです |
| pH | 5.5-7.5 | 6.0-7.0 | 酸性土壌では根粒が減ります |
| 有効土層の深さ | 30cm以上 | 50cm以上 | |
| 作期の蒸発散量 | - | 約250mm | 豆類の中で最も少ない部類です |
| 冠水 | 1日浸かるだけでも根が傷みます | - | 豆類の中で湿害に最も弱いです |
| 畝の高さ | 20cm以上 | 25cm | 湿害防止の要です |
| 地下水位 | 50cm以下 | 80cm以下 | |

> **リョクトウ栽培の最大の敵は湿害です。しかも、韓国のリョクトウ栽培期間は、ちょうど梅雨と重なります。畝を20cm以上高くして排水路を深く掘ることが、ほかのどの管理よりも先決です。**

&nbsp;&nbsp;&nbsp;畝を高くすることとマルチングの効果は、実測で確認されています。畝を高くしてマルチングを併用すると、出芽率が16%、収量が54%増えます。ビニールがなければ、わらやもみ殻、落ち葉で覆っても、かなりの部分で同じ効果が得られます。雨粒が直接土を打って表面が固まるのを防ぐ、泥はねが莢に付くのを防ぐ、雑草を抑える、という3つの効果が同時に得られます。

&nbsp;&nbsp;&nbsp;排水路は、畑の低い側へ水が抜ける道をしっかり作ることがコツです。畝だけを高くして畝間の端がふさがっていると、畝間に水がたまって、かえって悪くなります。梅雨の前に畝間に沿って水をひしゃく1杯ほど流してみて、最後まで流れ出るかを確認しておくとよいでしょう。

## 4. 品種

### 4-1. 韓国国内で育成された品種

| 品種 | 特徴 | 適した用途 |
|---|---|---|
| ナムピョンノクトゥ | 粒が小さく、莢が多くつくため収量が高いです | 子実ともやしの兼用 |
| クムソンノクトゥ | 莢が曲がらない直立型で、病気に強いです | 子実用 |
| ソソンノクトゥ | 小粒種で、もやしの栽培に最も適しています | もやし専用 |
| チャンアンノクトゥ | 病気とマメゾウムシに強いです | 長期貯蔵用 |
| タヒョンノクトゥ | 倒伏と病害に強く、1株当たりの莢数が多いです | 手間の少ない栽培 |
| チェフン | 成熟が比較的そろっていて、もやしの歩留まりが高いです | もやし用、一括収穫 |

&nbsp;&nbsp;&nbsp;リョクトウは韓国で育成された品種が複数あり、韓国全土で栽培されているため、種子の確保は難しくありません。ヒヨコマメやレンズマメと比べると、大きく有利な条件です。ただし災害時には、どの品種を手に入れるかよりも、どの性質を選んで受け継いでいくかのほうが重要です。

### 4-2. 災害時に重要な性質

| 性質 | なぜ重要か | どう選ぶか |
|---|---|---|
| 成熟の均一性 | 収穫を分ける回数を減らして労力を節約できます | 莢が一斉に黒くなる株を選んで受け継ぎます |
| 莢が裂けにくい性質 | 収穫期を逃しても損失が少なくて済みます | 黒くなって数日たっても裂けていない莢から採種します |
| マメゾウムシへの抵抗性 | 貯蔵中の損失を減らします | チャンアンノクトゥ系統。種皮が厚くて硬いもの |
| 倒伏への抵抗性 | 収穫の労力が数分の一に減ります | 茎が太くてまっすぐな個体 |
| もやしの歩留まり | 同じ重さの豆からより多くのもやしが得られます | 小粒種が概して高いです |
| 早熟性 | 霜の前に終えられ、2期作を可能にします | 先に花が咲き、先に熟す個体 |

> **リョクトウの品種選びで、災害時の優先順位は収量ではなく、成熟の均一性と裂けにくい性質です。人手が足りないときは、3～4回も摘みに行けず、摘みに行けなかった莢は裂けて失われます。**

&nbsp;&nbsp;&nbsp;また、もやし用の小粒種を必ず一部確保しておくことをおすすめします。粒が小さいほど発芽のときに力を使わず、もやしがまっすぐふっくらと育ちます。大粒種でもやしを育てると、曲がって軟らかくなってしまいます。子実用の1種類だけでは、冬の野菜問題をきちんと解決できません。

## 5. 畑の準備と肥料 - 根粒菌

### 5-1. 窒素固定はどのように起こるのか

&nbsp;&nbsp;&nbsp;空気の78%は窒素です。人の頭上には無限の窒素が漂っているのに、植物はそれを使えません。空気中の窒素は、2つの窒素原子が三重結合で固く結ばれた分子であり、この結合を切るのに莫大なエネルギーが必要だからです。工業的にこの結合を切ってアンモニアを作るのがハーバー・ボッシュ法で、世界の窒素肥料はそこから生まれます。高温、高圧、触媒、そして膨大な化石燃料が必要です。

&nbsp;&nbsp;&nbsp;根粒菌は、この仕事を常温・常圧でやってのけます。ニトロゲナーゼという酵素で三重結合を切り、窒素をアンモニアに変えます。ただし、代償があります。この反応には多くのエネルギーが必要で、細菌は自分で光合成ができません。そこでマメ科植物の根の中に入って暮らし、植物が光合成でつくった糖を受け取り、その見返りに固定した窒素を渡します。取引関係です。

&nbsp;&nbsp;&nbsp;リョクトウと組になる菌はBradyrhizobiumの仲間です。アズキやササゲが使う菌と共通で、ダイズの菌とも部分的に共通します。実用上は、アズキを育てた畑の土が最も確実な接種源です。韓国ではアズキが広く栽培されているため、接種源を入手するのは難しくありません。

| 段階 | 起こること |
|---|---|
| 1. シグナル交換 | リョクトウの根がフラボノイドを分泌し、土の中の細菌がそのシグナルに応えてNod因子を出します |
| 2. 感染 | 根毛が内側に曲がって細菌を包み込み、細菌は感染糸に沿って根の中へ入っていきます |
| 3. 根粒の形成 | 根の内側の細胞が分裂して根粒がふくらみ、その中に細菌が定着します |
| 4. 窒素固定 | 根粒の中でニトロゲナーゼが働き、空気中の窒素をアンモニアに変えます |
| 5. 分配 | アンモニアがアミノ酸に変わり、茎、葉、莢へ運ばれていきます |
| 6. 老化 | 登熟期に入ると根粒が機能を失い、根とともに土に還ります |

&nbsp;&nbsp;&nbsp;ニトロゲナーゼは酸素に非常に弱く、酸素に触れるとたちまち機能を失います。そのため、根粒の内側にはレグヘモグロビンという赤い色素タンパク質が満ちていて、酸素を捕まえ、酵素の周りの酸素濃度を極端に低く保っています。人の血が赤いのと同じ原理で、根粒を割ったときに内側が赤やピンク色をしているのは、この色素によるものです。この事実は実用上、きわめて重要です。赤い色は、その根粒がいま窒素を固定していることを示す、目に見える証拠だからです。

&nbsp;&nbsp;&nbsp;リョクトウでこの仕組みが特に弱い理由があります。根粒菌は酸素を必要とする好気性細菌なので、畑が水に浸かると、根よりも先に死んでしまいます。リョクトウの栽培期間が梅雨と重なるという事実と、湿害に最も弱いという事実が、ここで結びつきます。2日間水に浸かったリョクトウ畑の葉が黄色くなるのは、根が傷んだからだけではなく、窒素の供給源が断たれたからです。

### 5-2. 根粒ができたかを確認する方法

&nbsp;&nbsp;&nbsp;接種をしたかどうかにかかわらず、根粒が実際にできたかを確認する作業は必ず行う必要があります。リョクトウは生育期間が短いため、確認の時期も早くなります。

| 順序 | 内容 |
|---|---|
| 1 | 開花が始まるころ、播種後5-6週ごろが最適な時期です |
| 2 | 健康そうな株を2～3株選びます |
| 3 | 引き抜かず、スコップで株の周りを広く掘り、土ごと持ち上げます |
| 4 | 水桶に入れて、土をそっと洗い落とします |
| 5 | 主根と太い細根についた根粒の数を数えます |
| 6 | 根粒をいくつか爪で割って、内側の色を見ます |

| 観察結果 | 意味 | 対処 |
|---|---|---|
| 根粒が1株当たり15個以上ついている | 接種がうまくいっています | そのままにします |
| 割った内側が赤またはピンク色 | 窒素を固定しています | 良好な状態です |
| 割った内側が白または淡い緑色 | 根粒はできているが、固定していません | 酸度、湿害、リン酸欠乏を調べます |
| 割った内側が茶色または黒色 | すでに老化したか、死んでいます | 梅雨の後なら、湿害で死んだ可能性が高いです |
| 根粒が5個以下 | 接種が失敗しています | 葉が黄色ければ、少量の窒素を補います |

> **根を掘り上げ、根粒を割って赤い色を確かめる。この習慣こそが、窒素肥料のない世界で豆作りの成否を教えてくれる、最も確実なサインです。**

&nbsp;&nbsp;&nbsp;リョクトウでは、梅雨の前後に2回確認するのがよいでしょう。梅雨の前に赤かった根粒が、梅雨の後に黒く死んでいたら、原因は湿害です。その場合は、排水路をさらい、葉が黄色ければ薄めた尿をごく少量与えて、残りの期間をしのがせます。そして翌年は、畝をさらに高くします。

### 5-3. 接種源をどこで手に入れるか

&nbsp;&nbsp;&nbsp;市販の接種剤は、生きた細菌を泥炭や粘土に含ませて売っている製品です。災害時には入手できません。しかし、リョクトウが使う菌は、アズキやササゲも共通して使うありふれた菌なので、接種源は比較的簡単に得られます。

| 方法 | 手順 | 効果 | 注意 |
|---|---|---|---|
| アズキ・リョクトウ・ササゲを育てた畑の土をまぶす | 前年にこれらを植えて根粒がよくできた畑から、表土の5-15cmの深さの土を掘り取ってきます。種子を水で軽く湿らせてこの土をまぶし、すぐに播きます | 最も確実で、費用がかかりません | 病気の出た畑の土は、病原菌も一緒に運んでしまいます |
| 根粒そのものを使う | 掘り上げた根の根粒を集めてすりつぶし、水に溶かして、その水に種子を浸してから引き上げます | 菌の密度が最も高いです | 根粒を掘り取ったその日のうちに使う必要があります |
| 土を畑にまく | 播種する列に、運んできた土をまき、一緒に耕して混ぜ込みます | 菌が土に広がります | 10㎡当たりスコップ1杯程度が目安です |
| 根の残渣を残す | 収穫のとき、茎だけを刈り取り、根は畑に残します | 翌年まで菌が土に残ります | 最も手間のかからない維持方法です |
| 野生のヤブツルアズキの根 | 野原や畑のあぜに生えている野生のヤブツルアズキの根から根粒を採取します | 同じ属なので菌が共通します | 固定効率が栽培種向けの系統より低いことがあります |

&nbsp;&nbsp;&nbsp;接種するときに必ず守ることがあります。根粒菌は、直射日光、乾燥、熱に非常に弱いです。紫外線を数分間浴びるとかなりの数が死に、乾くとさらに早く死にます。種子に土をまぶす作業は日陰で行い、まぶした種子は日なたに広げず、すぐに播きます。30分以内に播くのがよく、遅くとも数時間以内に終わらせます。もうひとつ、種子消毒と接種は同時にはできません。温湯処理で消毒したなら、完全に冷ましてから接種します。

| 接種の失敗を招く条件 | 理由 |
|---|---|
| 土壌pH 5.5以下 | 細菌が生きられません |
| 窒素肥料を十分に与えた畑 | 植物が取引の必要を感じず、自ら根粒の形成を減らします |
| 水がたまる畑 | 好気性細菌なので、酸素がないと死にます。リョクトウで最も多い失敗原因です |
| リン酸が不足した畑 | 窒素固定には多くのエネルギーが必要で、その代謝にリン酸が使われます |
| モリブデン・鉄・コバルトの欠乏 | ニトロゲナーゼの構成成分です |
| 接種した種子を日なたで乾かす | 紫外線と乾燥で菌が死にます |
| 真夏の強い日差しの下での播種 | 土の表面温度が高く、種子についた菌が死にます。朝か夕方に播きます |
