## 13. 採種

| 項目 | 方法 |
|---|---|
| 採種個体の選抜 | さやが一斉に熟し、黒くなった後も裂けにくく、倒れていない株に、畑で前もって目印を付けておきます |
| 収穫時期 | さやが完全に黒く変わったら、すぐに摘み取ります |
| 分離 | 別に脱穀します。手でもむと豆が傷つきません |
| 選別 | 虫食い穴、変色、しわ、小粒のものはすべて捨てます |
| 乾燥 | 水分12%以下。日なたに薄く広げて干します |
| 保管 | 密閉容器に入れ、涼しく暗い場所に置きます。食用とは別の容器を使います |
| 保管期間 | 常温・密閉で3-4年。管理が良ければ5-6年まで発芽力が残ります |

> **リョクトウの採種で最も価値のある形質は、収量ではなく成熟の均一性です。何度も摘みに入る人手がないとき、一斉に熟する系統が一つあるだけで、収穫量は2倍になります。**

&nbsp;&nbsp;&nbsp;次に重要なのが、さやが裂けにくい性質です。黒くなって数日たっても裂けずにぶら下がっているさやを見つけたら、その株に目印を付けておいて、別に収穫します。この形質は遺伝するので、数年繰り返すだけでも、収穫期を少し逃しても損失の少ない系統ができます。在来のリョクトウが裂けやすい性質をそのまま持っているのは、それが野生で種子を散らす方法だからですが、人がその反対方向に選抜を続ければ変わってきます。

&nbsp;&nbsp;&nbsp;リョクトウは自家受粉する作物なので、隔離距離を心配する必要はありません。複数の系統を並べて植えても形質が混ざりません。ただし、アズキやササゲが近くにある場合は、種子が混ざらないよう、収穫と貯蔵をきちんと分けて管理します。

&nbsp;&nbsp;&nbsp;種子寿命が長いことも大きな長所です。常温・密閉で3-4年、管理が良ければ5-6年まで発芽力が残ります。毎年採種しなくてもよく、1年の作柄が悪くても、古い種子で翌年を始められます。ただし、古い種子は必ず先に発芽試験を行い、発芽率が半分なら播種量を2倍に増やして補います。

| 種子の保管期間と発芽率 |
|---|
| 収穫した年：95%以上 |
| 1年経過：90%以上 |
| 2年経過：80-90% |
| 3年経過：70-80% |
| 4-5年経過：50-70% |
| 6年目以降：急激に低下します |

## 14. 毒性と抗栄養成分

&nbsp;&nbsp;&nbsp;リョクトウは、豆類の中で毒性のリスクが最も低い部類に入ります。インゲンマメのように生の数粒で中毒を起こす強いレクチンも、ソラマメのように特定の体質で急性溶血を起こす成分もありません。緑豆もやしを生で食べても体を壊さないのが、その証拠です。

| 成分 | はたらき | 症状 | 取り除く方法 |
|---|---|---|---|
| トリプシンインヒビター | タンパク質分解酵素のはたらきを妨げます | 腹部の不快感、タンパク質利用率の低下 | 4時間浸漬した後、沸騰した湯で30分-1時間煮ます。ダイズよりずっと含有量が低いです |
| レクチン | 腸粘膜に付着して吸収を妨げます | 少量なら無害です | 加熱で容易に壊れます。インゲンマメ類と違って毒性はごく弱いです |
| フィチン酸 | 鉄、亜鉛、カルシウムと結合して吸収を妨げます | 長く食べ続けると貧血、亜鉛欠乏 | 浸漬と発芽で60-80%まで減ります |
| オリゴ糖 | 人が消化できず、腸内細菌が発酵させます | おなかにガスがたまります | 豆類の中では含有量が少ない方です。浸漬水を捨てるとさらに減ります |
| カビ毒 | 貯蔵中にカビが作ります | 危険です | カビが生えたものは、洗っても加熱しても安全になりません。捨てます |

> **リョクトウで実際に人の体を害するのは、豆そのものではなく、誤った貯蔵でカビが生えた豆です。湿っぽいにおいがしたり、表面に青みがかった粉が見えたりしたら、もったいながらずに捨てます。**

&nbsp;&nbsp;&nbsp;リョクトウは消化がよく、胃腸への負担が少ない豆として知られています。オリゴ糖の含有量が少なく、レクチンが弱く、組織が柔らかいためです。病人や高齢者、子どもに食べさせるのに豆類の中で最も安全な部類で、伝統的に熱を下げ体を解毒するとされて、緑豆がゆが病人食として使われてきたのも、この性質と無関係ではありません。

| 処理 | 時間・温度 | 効果 |
|---|---|---|
| 浸漬 | 常温の水に4時間 | 皮が柔らかくなり、火の通る時間が短くなります |
| 浸漬水を捨てる | 必ず | 水に溶け出したオリゴ糖と抗栄養成分も一緒に捨てます |
| 煮る | 沸騰した湯で30分-1時間 | 皮をむいて割ったものは20分で済みます |
| 皮むき・割り | 浸水して皮をむき、半分に割ります | 調理時間が半分以下に減ります |
| 発芽（緑豆もやし） | 3-5日 | 抗栄養成分が減り、ビタミンCが生じます |
| 火の通り具合の確認 | 指で押すと簡単につぶれます | 芯が残っていれば、まだ火が通っていません |

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;リョクトウの貯蔵性はSSです。乾燥した種実は常温で3年もち、種子としては5-6年まで保てます。脂肪が1%と豆類の中で最も少なく、酸敗はほとんどありません。しかしアズキゾウムシがリョクトウ貯蔵の最大の脅威で、粒が小さいため、一粒に穴が開くと中がすぐに空っぽになってしまいます。

> **豆は腐って失うのではなく、虫に食べられて失います。貯蔵の技術とは、すなわち虫を防ぐ技術です。**

### 15-1. まず乾燥から

| 段階 | 方法 | 確認 |
|---|---|---|
| 予備乾燥 | 摘んださやをネットに入れて日なたに2-3日 | 自然に裂けるものが半分ほどになります |
| 脱穀後の乾燥 | むしろやござに薄く広げて日なたに1-2日 | 粒が小さいので早く乾きます |
| 目標水分 | 食用・種子とも12%以下 | 歯でかむと、歯が食い込まずにパチンと割れます |
| 塩試験 | 乾いた塩を瓶にリョクトウと一緒に入れて振ります | 塩が瓶の壁にくっつくなら、まだ湿っています |
| 冷ます | 日なたから取り込んだ後、完全に冷ましてから詰めます | 温かいまま密閉すると結露が生じます |

### 15-2. 貯蔵中のマメゾウムシ類の防除

&nbsp;&nbsp;&nbsp;アズキゾウムシ（Callosobruchus chinensis）は、貯蔵したリョクトウの最大の脅威です。恐ろしいのは、すでに畑で始まっているという点です。まだ畑に付いているさやに成虫が卵を産み付け、その卵が貯蔵庫の中で孵化して豆の中に食い入ります。運び込む時点で卵がすでに付いてくる仕組みで、1世代が1か月足らずのため、半年もすれば袋一つが、穴の開いた殻と粉で埋まってしまいます。

| 方法 | 原理 | 適用 | 効果 |
|---|---|---|---|
| 完全密閉 | 酸素を断って窒息させます | ガラス瓶や金属缶をいっぱいに満たして封をします | 最も確実です。3-4週間で卵や幼虫まで死にます |
| 熱湯処理 | 卵と幼虫を殺します | 沸騰した湯に少しの間浸してから冷水で冷まし、再び日なたで干します | 昔から使われてきた方法です。種子用には使いません |
| 草木灰を混ぜる | 微細な粒子が外骨格のワックス層を削り、脱水させます | リョクトウの容積の2-5%を混ぜます | 粒が小さいので灰が均一に付きます。食べる前に水ですすぎます |
| 珪藻土 | ケイ酸質の殻が外骨格を傷つけます | リョクトウ1kgに1-3g | 灰より効果が大きいです。乾いた状態でのみ効きます |
| 油コーティング | 油の膜が卵の付着と孵化を妨げます | リョクトウ1kgに食用油3-5mLを加えてもみ込みます | 粒が小さく表面積が大きいため、油がやや多めに必要です。種子用には使いません |
| 低温処理 | 氷点下で卵と幼虫が死にます | 真冬に数日間屋外に出してから取り込みます | 取り込む際の結露に注意します |
| 高温処理 | 60度で卵と幼虫が死にます | 日なたに薄く広げて半日置きます | 種子用には使いません |
| 乾燥トウガラシ・サンショウ・ヨモギ | 精油成分が産卵を抑えます | 層状に重ねて入れます | 補助的な手段です |
| 炭・炒った塩 | 湿気を吸い取ります | 布に包んで入れます | カビ予防を兼ねます |
| 灰に埋める | 密閉と物理的防除を同時に得られます | 甕に灰とリョクトウを交互に重ねます | 昔から広く使われてきました |

&nbsp;&nbsp;&nbsp;最も重要なのは完全密閉です。虫も呼吸をします。密閉した容器の中で豆と虫が酸素を使うと、酸素が減って二酸化炭素が増え、虫が死にます。豆は休眠状態にあるため、この条件に耐えられます。容器をいっぱいに満たして空間を減らすほど、効果が早く現れます。大きな容器一つより、小さな容器を複数用意してぎっしり詰める方がよく、これには、一つがだめになっても全部を失わずに済むという利点もあります。

&nbsp;&nbsp;&nbsp;熱湯処理は、昔からリョクトウやアズキに使われてきた方法です。沸騰した湯に少しの間浸し、すぐに冷水で冷まして、再び日なたでからからに干します。表面や浅いところにある卵と若い幼虫が死にます。ただし、この処理をすると発芽力を失うので、食べる分にだけ使います。種子用は低温処理か密閉で扱います。草木灰はふるいにかけて細かい部分だけを選び、容積の2から5%を混ぜます。リョクトウは粒が小さく、灰が粒の間に均一に入り込むため、他の豆より効果がよく、どのみち調理前に洗う豆なので、手間も少なくて済みます。

### 15-3. 貯蔵容器と場所

| 容器 | 密閉性 | 期間 | 長所 | 短所 |
|---|:---:|---|---|---|
| ガラス瓶 | 非常に良い | 3年以上 | 状態を目で確認できます | 容量が小さく、光を遮れません |
| 金属缶 | 非常に良い | 3年以上 | ネズミと虫を完全に防ぎます | 結露が生じると、その部分が傷みます |
| 甕 | 良い | 2-3年 | 温度変化が緩やかで、ネズミがかじり抜けません | 重く、割れます |
| 厚手のビニール袋 | 普通 | 1-2年 | 軽くて安価です | ネズミに破られ、粒が小さいので漏れ出します |
| 地中の貯蔵穴 | 良い | 2-3年 | 温度が一定で低いです | 水がしみ込むと全量を失います |

&nbsp;&nbsp;&nbsp;点検で最も頼りになる感覚は、聴覚と嗅覚です。容器に耳を当てたときにカサカサという音がすれば虫が活動しており、湿っぽいにおいがすればカビが生え始めています。表面に小さく丸い穴が見えれば、ゾウムシが1世代を経た状態です。この段階でも、全量を取り出して日なたで干し、水に浮かべて空の粒を取り除き、灰を混ぜて再び密閉すれば、残りを守ることができます。2か月に1回の点検が目安です。

## 16. 調理と加工 - 緑豆もやし

### 16-1. 緑豆もやしはなぜ重要か

&nbsp;&nbsp;&nbsp;乾燥したリョクトウには、ビタミンCは事実上ありません。ところが芽を出させると、なかったビタミンCが作られます。発芽という生理的な転換が起こり、植物が新たに合成するためです。冬に新鮮な野菜がまったくないとき、乾燥リョクトウひとつかみと水と暗い場所さえあれば、3日から5日で新鮮な野菜が手に入ります。畑も日光も土も必要ありません。

&nbsp;&nbsp;&nbsp;ビタミンC欠乏は数か月かけて静かに進行し、歯茎から血が出る、傷が治らない、力が出なくなるといった症状として現れます。大航海時代の船乗りたちが苦しんだ病気であり、長い冬を貯蔵食品だけで乗り切る社会で繰り返し現れてきました。緑豆もやしは、この問題に対する安価で確実な答えです。ダイズから育てるダイズもやし（コンナムル）と原理は同じですが、緑豆もやしは成長が速く、味が柔らかいです。

> **乾燥リョクトウ100gが、緑豆もやし500-700gになります。増えた重さの大半は水なので熱量は増えませんが、なかったビタミンCが生じ、フィチン酸や阻害物質が減り、タンパク質の一部が消化されやすい形に分解されます。**

### 16-2. 緑豆もやしの育て方

| 手順 | 内容 | ポイント |
|---|---|---|
| 1. リョクトウを選ぶ | 小粒種が適しています。割れた粒や虫食いの粒はすべて捨てます | 割れた粒は腐って全体をだめにします |
| 2. 洗う | 何度かすすいで、浮くものを取り除きます | 浮く粒はたいてい死んだ粒です |
| 3. 浸水 | ぬるま湯に6-8時間浸します | リョクトウが2倍にふくらみ、種皮が裂け始めます |
| 4. 容器に入れる | 水が抜ける容器やシル（底に穴のある蒸し器状の容器）に入れ、濡れた布で覆います | 水がたまると腐ります |
| 5. 暗所に置く | 光を完全に遮ります。20-25度が適しています | 光が入ると緑色に変わり、硬くて苦くなります |
| 6. 水をかける | 1日3-4回、上からたっぷりと流しかけます | 温度調節と老廃物の除去を兼ねます |
| 7. 重しをのせる | 軽い板や石をのせます | 茎が太くふっくらとします |
| 8. 収穫 | 3-5日、長さ4-7cm | 根が茶色になる前に収穫します |

| 条件 | 結果 |
|---|---|
| 光が入る | 頭の部分が緑色になり、茎が硬くなって苦味が出ます |
| 水が少ない | 細根がたくさん出て、硬くなります |
| 水がたまる | 下の方から腐り、すっぱいにおいがします |
| 温度が30℃を超える | 早く育ちますが、柔らかく、すぐに傷みます |
| 温度が15℃未満 | 非常に遅く育ちます |
| 重いものをのせる | 茎が太くふっくらとします。市販の緑豆もやしが太い理由です |
| 皮を取り除かない | はがれた緑色の皮が腐って臭います |

&nbsp;&nbsp;&nbsp;水かけが、緑豆もやし栽培のほぼすべてです。水は水分を供給し、発芽の過程で出る熱を冷まし、たまった老廃物を洗い流します。1日に3回から4回、上からたっぷりとかけて完全に水を切り、夏は回数を増やし、冬はぬるま湯を使います。細根がたくさん出るのは、水が足りないというサインです。

&nbsp;&nbsp;&nbsp;緑豆もやしは育つにつれて、緑色の種皮がはがれて浮いてきます。これは水をかけるたびに取り除かなければなりません。そのままにしておくと腐ってにおいが出て、もやし全体をだめにします。水を注ぐときに上に浮く皮を、手やざるですくい取れば済みます。

&nbsp;&nbsp;&nbsp;シルがなければ、底に穴を開けた甕や容器、目の細かいざる、穴を開けたたらいを使います。下に受け皿を置き、上を黒い布で覆えば、それがシルになります。大切なのは、水が抜ける構造と光の遮断の2点だけです。冬は、台所のかまどの脇や、オンドル部屋の焚き口から遠い側のように、20度前後が保てる場所を探します。

&nbsp;&nbsp;&nbsp;緑豆もやしは生で食べても安全ですが、ゆでるか炒めて食べる方がよいです。残っている微量の阻害物質が減り、かさも減って、一度により多く食べられます。ゆでるときは、沸騰した湯にさっと入れて引き上げ、冷水ですすぎます。長くゆでると柔らかくなりすぎ、ビタミンCも一緒に溶け出してしまいます。

### 16-3. その他の調理と加工

| 加工 | 手順の要約 | 保存 | 価値 |
|---|---|---|---|
| 緑豆がゆ | 浸水したリョクトウを煮てつぶし、米と一緒に煮ます | 当日 | 消化しやすく、病人食として使います |
| 緑豆でんぷん（チョンポムク＝でんぷんゼリー） | 浸水して挽き、沈殿させたでんぷんを乾燥させます | でんぷん粉として数か月 | 脂肪が少ないため、でんぷんがよく固まります |
| ピンデトック（緑豆のお焼き） | 浸水したリョクトウを挽いて焼きます | 当日 | 皮付きのまま挽いても構いません |
| 皮むき割りリョクトウ | 浸水して皮をむき、割ります | 密閉して1-2か月 | 調理時間が半分に減ります |
| 炒りリョクトウ粉 | 炒って挽きます | 密閉して3-6か月 | 調理の燃料が要りません |
| リョクトウの皮 | でんぷんを取った後に残る皮 | 乾燥して | 家畜の飼料や堆肥として使います |

&nbsp;&nbsp;&nbsp;緑豆でんぷんは、災害時に思いがけない価値を持ちます。浸水したリョクトウを挽いて水に溶いておくと、重いでんぷんが沈み、上にタンパク質を含んだ水が浮きます。この沈殿を乾燥させると純粋なでんぷん粉になり、水で溶いて煮るとチョンポムクになります。でんぷんは穀物の粉より長く貯蔵でき、上澄みの方に残ったタンパク質は別に集めて焼いて食べます。一つの材料から、貯蔵用のでんぷんとすぐ食べられるタンパク質食品が同時に得られるわけです。脂肪が1%と極めて少ないリョクトウだからこそ可能な加工です。

| 月 | 作業 | ポイント |
|---|---|---|
| 1月 | 貯蔵点検、種子の発芽試験、緑豆もやしの栽培 | 冬のビタミンCは緑豆もやしから得ます |

| 6月 | 本播種（韓国中部は上旬、韓国南部は中旬～下旬）、マルチング、鳥害防止 | 前作を収穫した跡地にすぐ植えます |
| 7月 | 間引き、除草、支柱立て、遅まき播種の限界期 | 開花前に除草を終えます。他の作物が失敗した場合は、この時期までなら植え直せます |
| 8月 | 開花と結莢、アブラムシ対策、排水溝の点検、根粒の確認 | 梅雨で水に浸かると、根粒が先に死にます |
| 9月 | 分割収穫の開始、ネットに入れて干す | 黒くなったさやは、その日か翌日に摘みます |
| 10月 | 収穫の仕上げ、脱穀、選別、茎葉のすき込み | 残った茎はその場に寝かせるか、すき込みます |
| 11月 | 乾燥、貯蔵、加工、秋作物の管理 | リョクトウの跡地に植えたハクサイが、残った窒素を使います |
| 12月 | 貯蔵点検、緑豆もやしの栽培、翌年の計画 | 容器に耳を当てて、虫の音を確認します |

### 17-1. 忘れてはならない五つのこと

| 項目 | 内容 |
|---|---|
| 排水 | 豆類の中で湿害に最も弱く、栽培期間が梅雨と重なります。畝の高さ20cmが前提です |
| 分割収穫 | 黒くなったさやは数日のうちに裂けます。5-7日おきに3、4回摘む必要があります |
| 遅まき播種 | 7月中旬～下旬まで植えられる、ほぼ唯一の穀実作物です。失敗時のやり直し用に種子を残しておきます |
| 緑豆もやし | 冬のビタミンC源としての答えです。小粒種を必ず一部、別に確保しておきます |
| 茎葉 | さやだけを摘み、残った茎を畑に戻さなければ、リョクトウは土地から奪う一方の作物になってしまいます |
