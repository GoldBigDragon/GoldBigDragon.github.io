### 1-3. 強みをどう読み解くか

&nbsp;&nbsp;&nbsp;SSが付いた項目はタンパク質密度、施肥、施設負担、貯蔵性の4つで、Sは微量栄養素、水消費量、味、韓国国内での栽培普及度、自家採種に、Aは収穫速度、防除自立度、無合成投入での収量維持率、収量安定性、種子寿命に付きました。

&nbsp;&nbsp;&nbsp;収穫速度のAがリョクトウの本領です。80-90日、条件が良ければ60日で収穫できます。この短さが生み出すのは、単なる速さではなく、播種時期の余裕です。韓国では4月上旬から7月下旬までいつでも播けるため、播種期間は4か月に及びます。ダイズが6月上旬から下旬までの1か月余りであるのと比べると、次元が違います。

> **災害時には、計画は必ず狂います。遅霜で苗を失い、韓国の梅雨（チャンマ、6月下旬～7月）で畑が冠水し、植えておいたものが病気でだめになります。そのとき、もう一度播ける作物があるかどうかで、その年の明暗が分かれます。リョクトウは7月下旬まででも播き直せる、ほぼ唯一の豆類作物です。**

&nbsp;&nbsp;&nbsp;タンパク質密度のSSも注目に値します。P:E 27.9%はダイズとソラマメに次ぐ水準で、インゲンマメ、ヒヨコマメ、ササゲよりも高い値です。粒が小さく収穫量が少なくても、その中に含まれるタンパク質の質は高いということです。副食等級SS、63.7点はここから出ています。

&nbsp;&nbsp;&nbsp;水消費量のSと防除自立度のAもあわせて読む必要があります。総蒸発散量250mmで水の使用量が少なく、薬剤なしでも耕種的な手段でかなりの部分を抑えられます。手間のかかる作物ですが、その手間は労働であって資材ではありません。外から何も入ってこない条件では、労働で代替できる作物のほうが、資材を必要とする作物よりも優れています。

&nbsp;&nbsp;&nbsp;栽培普及度のSと種子寿命のAも価値が大きい点です。リョクトウは韓国全土で栽培されていて種子を入手しやすく、乾燥した種子は常温で3～4年もちます。管理がよければ5～6年まで発芽力が残ります。種子を確保して毎年つないでいくうえで、ヒヨコマメやレンズマメのような難しさはありません。

### 1-4. 弱みをどう読み解くか

&nbsp;&nbsp;&nbsp;Eが付いた項目は耐寒性ひとつです。Dは面積当たり熱量、永続性、日照への反応、調理・加工、整地エネルギー、非食用価値に、Cは温度適応幅と病害虫圧に付きました。

&nbsp;&nbsp;&nbsp;面積当たり熱量のDが最も重い項目です。1㎡当たり422kcal、自給ラインの0.16倍です。この作物表の豆類の中で最下位で、ダイズの半分にも届きません。整地・掘削エネルギーのDも、ここから派生しています。畑を耕すのに使ったエネルギーに対して回収できる熱量が2.6倍で、畑を耕してリョクトウを播く作業は、エネルギー収支でほとんど利益が残らないということです。リョクトウを畑の主作物にしてはいけません。ほかの作物を収穫した後の空き畑、畑の隅、畝の間のように、すでに準備された場所に上乗せする方式が適しています。

&nbsp;&nbsp;&nbsp;耐寒性のEは、夏の豆類に共通する弱点です。霜に一度当たっただけで枯れます。初霜が9月末から10月初めに来る地域なら、7月中旬が播種の限界です。遅く播けるという長所と霜で枯れるという弱点が絡み合い、播種限界日の算出がリョクトウ栽培の核心的な判断になります。

&nbsp;&nbsp;&nbsp;永続性のDに添えられた説明、つまり成熟が不揃いなため3～4回に分けて収穫するという点は、長所でもあり短所でもあります。長所として見れば、一度にすべてを失うことなく収穫が分散し、そのつど食べるものが得られます。短所として見れば、作業が何度にも分かれ、熟した莢を適期に摘めないと自然に裂けて、豆を地面に落としてしまいます。人手が足りない条件では、この点は実質的な制約です。

&nbsp;&nbsp;&nbsp;そして、等級表には表れない弱点がもうひとつあります。湿害です。リョクトウは豆類の中で水がたまることに最も弱く、韓国のリョクトウ栽培期間はちょうど梅雨と重なります。畝を20cm以上高くして排水路を深く掘ることは、リョクトウでは選択ではなく前提です。実際に、畝を高くしてマルチングをすると、出芽率が16%、収量が54%増えるという試験結果があります。

## 2. どんな植物か

### 2-1. 分類と原産地

&nbsp;&nbsp;&nbsp;リョクトウはマメ科（Fabaceae）ササゲ属（Vigna）の一年草です。アズキ、ササゲと同じ属で、ダイズやエンドウよりも、これらにはるかに近縁です。この事実は実用上重要です。リョクトウと組になる根粒菌はBradyrhizobiumの仲間で、アズキやササゲが使う菌と共通です。アズキやササゲを育てた畑の土を接種源として使えるということです。韓国ではアズキが広く栽培されているため、接種源の確保は難しくありません。

&nbsp;&nbsp;&nbsp;原産地はインドとその周辺です。熱帯・亜熱帯のモンスーン気候で育った植物なので、高温を好み、暑さに強い性質です。生育適温は28-30℃で豆類の中で最も高く、35℃を超えても耐えます。一方、霜に当たるとそのまま枯れ、15℃を下回ると生育が止まります。ダイズと正反対の性質ではなく、ダイズよりも一段階暑い側に寄った性質です。

&nbsp;&nbsp;&nbsp;リョクトウは自家受粉します。花は黄色くて小さく、花弁が雌しべと雄しべを包んでいるため、外部の花粉が入りにくくなっています。複数の品種を並べて植えても形質が混ざらず、採った種子をそのまま播けば、親と同じものができます。

### 2-2. 形態

| 器官 | 特徴 |
|---|---|
| 葉 | 3枚で1組をなす三出複葉です。ハート形に近く、細かい毛があります |
| 茎 | まっすぐ立ちますが、強度が弱いです。草丈60-80cmで、枝分かれします |
| 根 | まっすぐな主根に細根が伸び、根粒がつきます |
| 花 | 黄色で小さいです。生育後半の間じゅう咲き続けます |
| 莢 | 細長い円筒形で、5-10cmです。熟すと黒くなります |
| 子実 | 小さく丸く、濃い緑色です。1粒が0.05g前後で、豆類の中で最も小さい部類です |

> **リョクトウの莢は、熟すと茶色ではなく黒くなります。そして、黒くなってから数日以内に、自らねじれて裂けます。黒い莢を見つけたら、その日か翌日に摘まなければなりません。**

&nbsp;&nbsp;&nbsp;開花と成熟が続くという点が、リョクトウをほかのマメ科作物と最も大きく分けています。ダイズは畑全体が一斉に黄色くなって一度に刈り取れますが、リョクトウは下から上へ花が咲き続けるため、1株の中に黒い莢と緑の莢と花が同時にあります。この性質のために3～4回に分けて摘み取らなければならず、一度に刈り倒す方式では半分以上を失います。

&nbsp;&nbsp;&nbsp;茎に力がないという点も、実用上重要です。リョクトウは草丈が60-80cmまで伸びますが、茎が細くて軟らかく、倒れやすい作物です。特に雨に当たった後や、肥料が多すぎて徒長した場合にそうなります。倒れると莢が土に触れて腐り、何度も摘まなければならない収穫がはるかに難しくなります。

### 2-3. 生育段階

| 段階 | 時期 | 主な生理 | 重要な栄養素 |
|---|---|---|---|
| 発芽・幼苗期 | 播種から4-5日 | 発芽が非常に速いです。豆類の中で最も速い部類です | リン酸、少量の窒素 |
| 栄養成長期 | 3-6週 | 茎が立ち、枝分かれします | 窒素は根粒が供給 |
| 開花・結莢期 | 6-8週 | 花が咲き始め、生育後半の間ずっと続きます | リン酸、カリウム |
| 登熟・成熟期 | 8-12週 | 下の莢から黒く熟します。数回に分けて収穫する期間 | カリウム、灌水の中止 |

&nbsp;&nbsp;&nbsp;発芽が4～5日と非常に速いことも、リョクトウのもうひとつの長所です。ヒヨコマメが10～15日、ダイズが5～7日であるのと比べると、明らかに速いです。播いてから数日で結果が分かるので、失敗したらすぐに播き直せます。短い生育期間に加えて、この速い発芽が、リョクトウを失敗の挽回用の作物にしています。

&nbsp;&nbsp;&nbsp;生育期間が短いので、初期管理が収量をほぼ決めます。播種後3-4週の間に、雑草に押さえ込まれたり、水に浸かったり、養分が不足したりすると、回復する時間がありません。逆に、この時期をうまく乗り切れば、その後はあまり手間がかかりません。

&nbsp;&nbsp;&nbsp;初期の窒素について、押さえておくことがあります。根粒は播種直後からは働きません。細菌が感染して根粒ができ、窒素を渡してくれるようになるまでに3週間かかります。生育期間が80日のリョクトウでは、この3週間は全体の25%を超えます。そのため、元肥に少量の窒素を入れることは、ほかの豆類よりも意味があります。ただし、少量にとどめる必要があります。土に窒素が十分あると、植物は根粒の形成を自ら減らし、茎だけが徒長して倒れます。

### 2-4. 100g当たりの栄養

| 栄養素 | 含有量 | 備考 |

| タンパク質 | 24.51g | 熱量に占める割合は27.9%です。豆類の中で上位です |
| 脂質 | 1g前後 | 非常に少ないです。貯蔵中の酸敗がほとんどありません |
| 炭水化物 | 60-65g | 大部分はでんぷんです。チョンポムク（リョクトウでんぷんのゼリー）の原料になります |
| 食物繊維 | 16g前後 | 多いです |
| 糖類 | 0.00g | 実測値です。甘味はありません |
| 鉄 | 6mg前後 | 肉類がないときの重要な供給源です |
| カリウム | 1,200mg前後 | |
| 葉酸 | 豊富 | 貧血や胎児の発達に関わります |
| ビタミンC（リョクトウもやしの場合） | 新たに生成 | 乾燥したリョクトウにはありませんが、発芽すると作られます |

&nbsp;&nbsp;&nbsp;乾燥したリョクトウともやしは、事実上、別の食品です。乾燥したリョクトウにはビタミンCがありませんが、芽を出させると、発芽の過程で新たに合成されます。同時に、重さが5～6倍に増え、水分が大部分を占めるようになるため、熱量密度は大きく下がります。乾燥したリョクトウはタンパク質とでんぷんの貯蔵庫であり、もやしはビタミンと水分の供給源です。災害時には、この両方を活用する必要があります。

&nbsp;&nbsp;&nbsp;アミノ酸組成は別に見ておく必要があります。リョクトウのタンパク質はリジンとロイシンが豊富で、メチオニンがやや不足しています。穀物はまさにその逆です。ご飯やパンといっしょに食べると、互いの不足を補い合って、タンパク質の利用率が目に見えて上がります。

&nbsp;&nbsp;&nbsp;脂質が1%で豆類の中で最も少ないことは、貯蔵の面で有利です。酸敗がほとんど起こらないため、粉にしても長くもちます。リョクトウのでんぷんを取り出してチョンポムクを作る伝統も、この低い脂質含量のおかげで可能になりました。熱量密度が低い代わりに、最も保管しやすい豆になったのです。
