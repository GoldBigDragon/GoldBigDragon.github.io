## 5. 整地与施肥 - 氮收支与施肥

### 5-4. 固氮的陷阱

&nbsp;&nbsp;&nbsp;“种豆能让土地变好”这种说法，已经成了农事常识。它一半对，一半错。如果不能准确理解这一点，连续几年种植豆科作物的田，反而会越来越贫瘠。

&nbsp;&nbsp;&nbsp;我们用数字来算一算。绿豆长势良好时，1,000㎡可收获120kg干籽粒。绿豆籽粒的蛋白质含量为24.5%，把蛋白质除以6.25就得到氮含量。24.5 ÷ 6.25等于3.92，也就是说籽粒重量的约3.9%是纯氮。120kg中含有的氮约为4.7kg，换算成公顷就是47kg。

&nbsp;&nbsp;&nbsp;另一方面，绿豆根瘤固定的氮，在条件良好时每公顷为50至80kg。由于生育期短，绝对量少于大豆和蚕豆。把输出和输入并排来看，情况如下。

| 项目 | 每公顷氮量 | 方向 |
|---|---|---|
| 根瘤固氮量（条件良好） | 50-80kg | 输入 |
| 根瘤固氮量（湿害导致根瘤死亡时） | 10-20kg | 输入 |
| 随籽粒运出 | 40-50kg | 输出 |
| 茎叶（茎和叶）中残留的氮 | 20-30kg | 还田则留下，焚烧或运出则流失 |
| 根和根瘤中残留的氮 | 8-15kg | 大多留在田里 |

&nbsp;&nbsp;&nbsp;绿豆的这一计算之所以特殊，是有原因的。绿豆是分批收获的作物，只把荚果分多次摘走，茎和叶仍立在田里，生育期就结束了。从结构上说，它是最容易把茎叶还田的豆类。收获结束后，只要把茎秆就地放倒或翻入土中即可，茎又细又软，几天就腐烂了。原始文献中提到绿豆的残茬有助于改良土壤，原因就在于此。

> **豆科作物让土地恢复生机，并不是因为固氮本身，而是因为它把固定的氮的一部分存在茎和叶里，留在了田里。如果把这些茎叶运走，豆类就成了掠夺土地的作物。**

&nbsp;&nbsp;&nbsp;但在湿害使根瘤死亡的年份，这种关系会反过来。固氮量只有15kg，却随籽粒运出45kg，田地就明显吃亏。被韩国梅雨季（6月下旬至7月）淹没的绿豆田，失去的不只是产量，还有氮。可以说，排水管理同时也是地力管理。

| 原则 | 内容 |
|---|---|
| 茎叶一定要还田 | 摘完荚果后，把剩下的茎和叶直接放倒在田里或翻入土中 |
| 不焚烧 | 焚烧后氮变成气体散失，只有钾和磷以灰烬的形式留下 |
| 不挖根 | 根和根瘤中的氮，是最容易留下的一份 |
| 保证排水 | 根瘤因湿害死亡，固氮量本身就没有了 |
| 紧接着种后茬 | 绿豆留下的氮，下一茬作物可以马上利用 |
| 喂了牲畜就把粪还回去 | 如果把茎叶喂了牲畜，就一定要把这些牲畜的粪尿施回这块田 |

### 5-5. 整地

| 项目 | 方法 | 灾害条件下 |
|---|---|---|
| 翻耕 | 翻耕20-30cm深，并整平 | 如果是前茬作物收获后的地块，只翻挖播种行也可以 |
| 垄 | 高20-25cm | 这是决定绿豆栽培成败的条件 |
| 排水沟 | 深30cm以上，保证水能一直排到尽头 | 梅雨季前浇水检验 |
| 酸度调节 | pH 6.0-7.0 | 在播种前3-4周提前进行 |
| 石灰 | 酸性土壤施100-200kg/1,000㎡ | 把贝壳、蛋壳烧后捣碎，或用草木灰代替 |
| 覆盖 | 稻草、稻壳、落叶、塑料薄膜 | 出苗率提高16%、产量提高54%的效果 |

&nbsp;&nbsp;&nbsp;覆盖对绿豆的效果之所以格外显著，是因为三方面的作用叠加在一起。第一，防止梅雨季的雨水击打土壤表面使其板结。绿豆的播种深度只有2-4cm，很浅，表面板结后嫩芽就无法顶出来。第二，抑制杂草。绿豆怕杂草，开花后又很难进入田里，所以前期的杂草管理就是一切。第三，防止泥土溅到荚果上，减少病害。即使没有塑料薄膜，用稻草、稻壳或落叶也能在很大程度上取得同样的效果。

### 5-6. 施肥量

| 肥料 | 按1,000㎡计 | 折合每㎡ | 备注 |
|---|---|---|---|
| 氮 | 2-4kg | 2-4g | 只施最少量。过多会徒长倒伏 |
| 磷 | 4-7kg | 4-7g | 全部作基肥 |
| 钾 | 4-6kg | 4-6g | 全部作基肥 |
| 堆肥 | 1,000kg | 1kg | 使用充分腐熟的 |
| 石灰 | 100-200kg（酸性土壤） | 100-200g | 播种前3-4周 |

> **对绿豆来说，节省氮不是节约，而是技术。它本来就是茎秆较弱的作物，氮多了就会徒长倒伏，倒伏后需要多次采摘的收获会难上数倍。**

&nbsp;&nbsp;&nbsp;原则上不需要追肥。不过，由于生育期短，前期长势不佳就没有时间补救。如果在开花期和开花15天后，长势明显不好，可补充极少量的氮，约为每1,000㎡ 2kg。在灾害情境下，可以把尿液用水稀释10倍后浇在植株间的土壤上作为替代办法，注意不要沾到叶片上。

### 5-7. 灾害情境下的替代肥料

| 替代资源 | 提供的营养素 | 使用方法 | 注意 |
|---|---|---|---|
| 草木灰 | 钾、磷、钙 | 每㎡撒施100-150g并混匀 | 呈碱性，施多了pH会超过7 |
| 腐熟堆肥 | 各类养分 | 每㎡施1kg作基肥 | 未腐熟的会烧根并传播病害 |
| 稀释尿液 | 氮、钾 | 用水稀释10倍后浇在植株间的土壤上 | 只能用极少量。注意防止徒长 |
| 骨粉 | 磷、钙 | 烧后捣碎，掺入堆肥 | 见效缓慢 |
| 鱼骨·鱼内脏 | 磷、氮 | 埋起来发酵腐熟后使用 | 直接埋的话会被野兽刨出来 |
| 贝壳·蛋壳 | 钙 | 烧后捣碎撒施 | 用来代替石灰。作用较慢 |
| 前茬作物残体 | 有机物 | 覆盖大麦秸秆、蒜秆、马铃薯茎蔓，兼作覆盖和肥料 | 绿豆多作后茬种植，所以利用价值高 |
| 稻壳·稻草 | 钾、硅酸 | 作覆盖物铺盖 | 覆盖的效果在绿豆上尤其显著 |

&nbsp;&nbsp;&nbsp;绿豆常常在收获前茬作物之后接着种，因此直接利用前茬作物的残体最为自然。收获大麦的田就把大麦秸秆、收获大蒜的田就把蒜秆，就地铺开作覆盖物。这些残体腐烂后变成有机物，绿豆在其上生长并固氮，收获绿豆后其茎叶又留了下来。这是一种不从外部带入任何东西、在田内形成循环的安排。

## 6. 播种 - 2季种植与晚播

### 6-1. 播种时期

| 地区·栽培类型 | 播种适期 | 播种极限期 | 收获时期 |
|---|---|---|---|
| 韩国中部 单作 | 6月上旬-中旬 | 7月中旬 | 9月上旬-中旬 |
| 韩国南部 单作 | 6月中旬-下旬 | 7月下旬 | 9月中旬-下旬 |
| 后茬（前茬作物之后） | 6月中旬-7月上旬 | 7月中旬 | 9月下旬-10月上旬 |
| 韩国南部 2季种植 第1茬 | 4月下旬-5月上旬 | - | 7月上旬 |
| 韩国南部 2季种植 第2茬 | 7月上旬-中旬 | 7月下旬 | 9月下旬 |

&nbsp;&nbsp;&nbsp;在韩国，绿豆的播种窗口期从4月上旬持续到7月下旬，长达4个月。这是豆类中最宽的，也是绿豆的实际价值所在。不过，极限由霜来决定。从预计初霜日往前数90天，就是该地区的播种截止日。

> **当农事没有按计划进行时，绿豆的优势就显现出来了。春季作物被冷害毁掉时，梅雨季田地被淹需要重种时，到了7月中旬还能播种的籽粒作物，除了绿豆几乎没有。**

### 6-2. 如何安排2季种植

&nbsp;&nbsp;&nbsp;在韩国南部，绿豆2季种植理论上可行，但实际上是有条件的。4月下旬播第一茬的话，灌浆成熟期会落在6月下旬至7月初，也就是梅雨季的开头。绿豆成熟的荚果淋雨后，里面的种子会发芽或腐烂，所以这个时期很危险。因此，比起单纯的2季种植，下面两种安排更为现实。

| 安排 | 内容 | 优点 |
|---|---|---|
| 前茬之后的后茬 | 6月收获大麦·小麦·大蒜·洋葱·马铃薯后，在原地种绿豆 | 一块田用两次，同时避开梅雨季风险 |
| 绿豆之后的秋季作物 | 9月收获绿豆后种大白菜·萝卜·菠菜 | 秋季作物利用绿豆留下的氮 |
| 绿豆2季种植 | 4月下旬播种后，7月上旬再次播种 | 仅限韩国南部沿海。第1茬灌浆成熟有与梅雨季重叠的风险 |
| 补救失败用 | 在其他作物毁掉的地块上，7月之前播种 | 不至于让这一年完全落空 |

&nbsp;&nbsp;&nbsp;前茬之后的后茬，是最稳妥、也是最常用的安排。收获了大麦、大蒜或马铃薯的6月田地，已经翻耕过，肥力也还留有一些。只要重新整理一下垄、疏通排水沟，就可以立即种绿豆。翻耕田地的能耗相当于与前茬作物分摊，因此整地·挖掘能耗D这个弱点也在很大程度上得到了抵消。

### 6-3. 种子准备与播种方法

| 项目 | 方法 | 灾害条件下 |
|---|---|---|
| 筛选 | 剔除有虫孔、变色、皱缩的种子 | 籽粒小，挑选起来麻烦，但一定要做 |
| 水选 | 在水中浸泡3-4小时，只用沉底的 | 浮起来的是空心的或被虫蛀的 |
| 温水消毒 | 在50-55℃的水中浸泡10-15分钟 | 杀死种子传播的病原菌 |
| 草木灰处理 | 给种子裹上细草木灰 | 有助于消毒和干燥，还有驱避鸟类的效果 |
| 根瘤接种 | 用种过红小豆或绿豆的田土拌种 | 参见5-3节。不与消毒同时进行 |
| 发芽试验 | 用湿布包住20粒种子，放置几天后数发芽数 | 发芽快，3至4天就有结果 |

| 项目 | 标准 | 原因 |
|---|---|---|
| 播种深度 | 2-4cm | 籽粒小，太深就顶不出来 |
| 每穴粒数 | 2-4粒 | 之后留2株，其余间苗 |
| 行距（单作） | 60cm | 保证通风，并留出多次采摘所需的通道 |
| 行距（后茬） | 40-60cm | 植株长得较小，可以缩小行距 |
| 株距 | 10-15cm | 过密会徒长倒伏 |
| 播种量（单作） | 1.5-2kg/1,000㎡ | 在豆类中最少 |
| 播种量（后茬） | 2-3kg/1,000㎡ | 播得越晚越要密 |

&nbsp;&nbsp;&nbsp;留出宽松的行距，对绿豆来说有特殊的原因。需要下地3至4次摘取成熟的荚果，如果行距窄，人走过时会折断茎秆，碰落尚未成熟的荚果。提前留出收获通道，最终就是在保住产量。

&nbsp;&nbsp;&nbsp;播种后紧接着的威胁是鸟类。绿豆发芽只需4至5天，暴露期很短，但子叶又大又嫩，鸽子和野鸡会啄食。可以在播种行上薄薄地盖一层稻草，或罩上网、旧纱窗，并在发芽初期的几天里，早晚到田里巡视。

## 7. 水分管理

| 时期 | 水分管理 | 原因 |
|---|---|---|
| 播种到发芽 | 不要让土壤完全干透 | 种子埋得浅，表层干了发芽就会停止 |
| 真叶展开后 | 保持稍干 | 过湿会徒长，根部腐烂 |
| 开花·结荚期 | 干旱严重时灌水 | 这一时期缺水对产量的影响最大 |
| 梅雨季 | 疏通排水沟 | 这是绿豆栽培中最危险的阶段 |
| 灌浆成熟期 | 停止灌水 | 成熟的荚果被雨淋湿，里面的种子会发芽 |

> **绿豆的水分管理不是“给”的技术，而是“排”的技术。它在豆类中最不耐湿害，栽培期又恰好与梅雨季重合。**

| 症状 | 原因 | 措施 |
|---|---|---|
| 中午叶片下垂，傍晚恢复 | 暂时性缺水。属于正常范围 | 不作处理 |
| 早晨叶片仍然下垂 | 严重干旱 | 灌水 |
| 下部叶片发黄，根部发黑 | 过湿引起的烂根 | 疏通排水沟并培土 |
| 整片叶子呈浅黄色，但没有萎蔫 | 根瘤因湿害死亡，氮供应中断 | 挖出根系确认后，浇少量稀释尿液 |
| 开花了却不结荚 | 开花期干旱，或蚜虫危害 | 灌水，并检查叶片背面 |
| 只有茎秆长得很长并倒伏 | 氮过多或过湿 | 减少浇水，第二年减少施肥 |
| 成熟的荚果里种子发芽了 | 灌浆成熟期淋了雨 | 只能在变黑后立即采摘 |

&nbsp;&nbsp;&nbsp;最后一项是绿豆栽培中最令人惋惜的损失。完全成熟的荚果淋雨后，里面的种子会开始发芽，既不能吃也不能种。防止这种情况的唯一办法，就是变黑后立即采摘。如果在梅雨持续的时期有正在成熟的荚果，即使还没有完全变黑，也最好提前摘下来在室内晾干。

&nbsp;&nbsp;&nbsp;覆盖在水分管理方面同样很有价值。它减少地表蒸发，以防干旱，同时阻止雨水溅起泥土，减少病害。不过，如果盖得太厚、土壤总是湿漉漉的，反而会增加烂根，所以覆盖厚度控制在5cm左右，梅雨季时把垄肩一侧稍微扒开一些，让土壤能够变干。
