## 13. 留种

| 项目 | 方法 |
|---|---|
| 留种株选拔 | 事先在田里标记出荚果一起成熟、变黑后也不易裂开、没有倒伏的植株 |
| 收获时期 | 荚果完全变黑后立即采摘 |
| 分离 | 单独脱粒。用手搓揉不会损伤籽粒 |
| 筛选 | 虫孔、变色、皱缩、小粒的全部丢弃 |
| 干燥 | 含水量12%以下。在阳光下薄摊晾晒 |
| 保管 | 装入密封容器，放在阴凉黑暗处。与食用的分开，使用另外的容器 |
| 保管期限 | 常温密封3-4年。管理得好，发芽力可保持到5-6年 |

> **绿豆留种时最宝贵的性状不是产量，而是成熟的一致性。在没有人手去采摘三四次的时候，一个一起成熟的品系就能让收获量翻一番。**

&nbsp;&nbsp;&nbsp;其次重要的是荚果不易裂开的特性。如果看到荚果变黑后过了好几天仍不裂开、还挂在植株上，就给那一株做上标记，单独收获。这一性状可以遗传，所以只需连续选择几年，就能培育出即使稍微错过收获期也损失较小的品系。传统绿豆保留着容易裂开的特性，是因为这是它在野外传播种子的方式，但如果人类朝相反的方向持续选择，情况就会改变。

&nbsp;&nbsp;&nbsp;绿豆是自花授粉作物，不必担心隔离距离。把多个品系并排种植，性状也不会混杂。不过，如果红小豆和豇豆就在附近，要把收获和贮藏明确分开管理，以免种子混杂。

&nbsp;&nbsp;&nbsp;种子寿命长也是一大优点。常温密封可保存3-4年，管理得好，发芽力可保持到5-6年。不必每年留种，即使某一年歉收，也可以用陈年种子开始来年的种植。不过，陈种子一定要先做发芽试验，发芽率只有一半时，就把播种量增加一倍来补偿。

| 种子保管期限与发芽率 |
|---|
| 收获当年：95%以上 |
| 过1年：90%以上 |
| 过2年：80-90% |
| 过3年：70-80% |
| 过4-5年：50-70% |
| 6年以后：急剧下降 |

## 14. 毒性与抗营养成分

&nbsp;&nbsp;&nbsp;绿豆属于豆类中毒性风险最低的一类。它既没有像菜豆那样生吃几粒就会引起中毒的强凝集素，也没有像蚕豆那样在特定体质者身上引起急性溶血的成分。生吃绿豆芽也不会出问题，就是证明。

| 成分 | 作用 | 症状 | 去除方法 |
|---|---|---|---|
| 胰蛋白酶抑制剂 | 阻碍蛋白质分解酶的作用 | 腹部不适，蛋白质利用率下降 | 浸泡4小时后在沸水中煮30分钟-1小时。含量比大豆低得多 |
| 凝集素 | 附着在肠黏膜上，妨碍吸收 | 少量无害 | 加热即可轻易破坏。与菜豆类不同，毒性很弱 |
| 植酸 | 与铁、锌、钙结合，阻碍吸收 | 长期食用会导致贫血、缺锌 | 浸泡、发芽最多可使其减少60-80% |
| 低聚糖 | 人体无法消化，由肠道细菌发酵 | 肚子胀气 | 在豆类中含量偏少。倒掉浸泡水还能进一步减少 |
| 霉菌毒素 | 贮藏期间由霉菌产生 | 危险 | 长霉的豆子即使清洗或煮熟也不会变得安全。应丢弃 |

> **绿豆真正会伤害人的，不是豆子本身，而是因贮藏不当而长霉的豆子。如果闻到潮味，或看到表面有泛青的粉末，不要舍不得，直接丢掉。**

&nbsp;&nbsp;&nbsp;绿豆被认为是消化良好、对肠胃负担小的豆类。这是因为它的低聚糖含量少、凝集素弱、组织柔软。给病人、老人和孩子食用，它是豆类中最安全的一类，传统上认为绿豆能清热解毒，因而用绿豆粥作病人餐，这与它的这一特性也不无关系。

| 处理 | 时间·温度 | 效果 |
|---|---|---|
| 浸泡 | 常温水中4小时 | 豆皮变软，煮熟时间缩短 |
| 倒掉浸泡水 | 必须 | 把溶入水中的低聚糖和抗营养成分一并倒掉 |
| 煮 | 沸水中30分钟-1小时 | 去皮掰开的20分钟即可 |
| 去皮掰开 | 泡开后去皮，掰成两半 | 烹饪时间缩短到一半以下 |
| 发芽（绿豆芽） | 3-5天 | 抗营养成分减少，生成维生素C |
| 熟度确认 | 用手指一按就容易压烂 | 如果还有硬心，就是没熟 |

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;绿豆的耐储性为SS。干籽粒在常温下可保存3年，作种子可保存到5-6年。脂肪含量仅1%，是豆类中最少的，几乎不会发生酸败。然而，绿豆象是绿豆贮藏的最大威胁，而且籽粒很小，一粒被蛀穿，里面很快就会被蛀空。

> **豆子不是因腐烂而损失，而是因被虫子吃掉而损失。贮藏的技术，就是防虫的技术。**

### 15-1. 干燥优先

| 阶段 | 方法 | 确认 |
|---|---|---|
| 预干燥 | 把摘下的荚果装入网袋，在阳光下晒2-3天 | 约有一半会自行裂开 |
| 脱粒后干燥 | 薄薄地摊在草席或凉席上，在阳光下晒1-2天 | 籽粒小，干得快 |
| 目标含水量 | 食用和种子都在12%以下 | 用牙咬时牙咬不进去，会“啪”地一下裂开 |
| 盐试验 | 把干盐和绿豆一起放进瓶里摇晃 | 盐如果粘在瓶壁上，说明还潮 |
| 放凉 | 从阳光下收回后，完全放凉再装 | 温热时密封会产生结露 |

### 15-2. 贮藏期间豆象的防治

&nbsp;&nbsp;&nbsp;绿豆象（Callosobruchus chinensis）是贮藏绿豆的最大威胁。可怕之处在于，它在田里就已经开始了。成虫把卵产在还长在田里的荚果上，这些卵在仓库里孵化，钻进豆子里。这种结构意味着，豆子收进来时卵就已经带进来了，而且一个世代不到一个月，半年下来，一只袋子就会被蛀孔的空壳和粉末填满。

| 方法 | 原理 | 应用 | 效果 |
|---|---|---|---|
| 完全密封 | 隔绝氧气使其窒息 | 把玻璃瓶或金属罐装满后封口 | 最可靠。3-4周内连卵和幼虫都会死亡 |
| 热水处理 | 杀死卵和幼虫 | 在沸水中短暂浸泡后用冷水冷却，再放到阳光下晒干 | 传统上使用的方法。不用于种子 |
| 拌草木灰 | 微细颗粒刮破外骨骼的蜡质层，使其脱水 | 按绿豆体积的2-5%拌入 | 籽粒小，草木灰能均匀附着。食用前用水冲洗 |
| 硅藻土 | 硅质外壳损伤外骨骼 | 每1kg绿豆用1-3g | 效果比草木灰更好。只在干燥状态下起作用 |
| 油膜包裹 | 油膜阻止卵附着和孵化 | 每1kg绿豆加入3-5mL食用油搓拌 | 籽粒小，表面积大，油要稍多一些。不用于种子 |
| 低温处理 | 零下温度使卵和幼虫死亡 | 隆冬时放到室外几天后再收回 | 收回时注意结露 |
| 高温处理 | 60度时卵和幼虫死亡 | 在阳光下薄摊半天 | 不用于种子 |
| 干辣椒·山椒·艾草 | 精油成分抑制产卵 | 一层层夹放 | 辅助手段 |
| 木炭·炒盐 | 吸收湿气 | 用布包好放入 | 兼可预防霉菌 |
| 埋入灰中 | 同时获得密封和物理防治 | 在陶罐里一层草木灰、一层绿豆地堆放 | 传统上广泛使用 |

&nbsp;&nbsp;&nbsp;最重要的是完全密封。虫子也要呼吸。在密封的容器里，豆子和虫子消耗氧气，氧气不断减少，二氧化碳不断升高，虫子便会死亡。豆子处于休眠状态，能耐受这样的条件。把容器装得越满、空隙越少，见效越快。与其用一个大桶，不如用几个小桶塞满装实，这样还有一个好处：即使一桶坏了，也不会全部损失。

&nbsp;&nbsp;&nbsp;热水处理是传统上用于绿豆和红小豆的方法。在沸水中短暂浸泡后，立刻用冷水冷却，再放到阳光下晒到干透。表面和浅层的卵及低龄幼虫会死亡。不过，这种处理会使种子丧失发芽力，所以只用于要吃的那一部分。种子用的则采用低温处理或密封来处理。草木灰要先过筛，只挑细的部分，按体积的2到5%拌入。绿豆籽粒小，草木灰能均匀渗入籽粒之间，比其他豆类效果更好，而且反正这种豆子烹饪前要先洗，所以也不太麻烦。

### 15-3. 贮藏容器与场所

| 容器 | 密封性 | 期限 | 优点 | 缺点 |
|---|:---:|---|---|---|
| 玻璃瓶 | 非常好 | 3年以上 | 可以直接看到内部状态 | 容量小，不能遮光 |
| 金属罐 | 非常好 | 3年以上 | 完全防鼠防虫 | 一旦结露，那个部位就会变质 |
| 陶罐 | 好 | 2-3年 | 温度变化慢，老鼠咬不穿 | 沉重，易碎 |
| 厚塑料袋 | 一般 | 1-2年 | 轻便，价格便宜 | 会被老鼠咬破，籽粒小，易漏出 |
| 地下贮藏窖 | 好 | 2-3年 | 温度恒定且低 | 一旦渗水，全部报废 |

&nbsp;&nbsp;&nbsp;检查时最可靠的感官是听觉和嗅觉。把耳朵贴在桶上，如果听到沙沙声，说明虫子正在活动；如果闻到潮味，说明霉菌已经开始滋生。如果在表面看到小而圆的孔，说明象甲已经繁殖过一代。即使到了这时，只要把全部豆子取出来在阳光下晒干，用水浮选捞出空粒，拌入草木灰后重新密封，仍能保住剩下的部分。标准是每两个月检查一次。

## 16. 烹饪与加工 - 绿豆芽

### 16-1. 绿豆芽为什么重要

&nbsp;&nbsp;&nbsp;干绿豆中实际上没有维生素C。但是一旦让它发芽，原本没有的维生素C就会生成。这是因为发芽这一生理转变发生时，植物会重新合成。冬天完全没有新鲜蔬菜时，只要有一把干绿豆、水和一处黑暗的地方，三到五天就能得到新鲜蔬菜。既不需要田地，也不需要阳光和土壤。

&nbsp;&nbsp;&nbsp;维生素C缺乏会在几个月里悄悄发展，最终表现为牙龈出血、伤口不愈合、浑身乏力等症状。这就是大航海时代的水手所患的那种病，在靠贮藏食品熬过漫长冬季的社会中也反复出现。绿豆芽是解决这一问题的廉价而可靠的办法。它与用大豆培育的黄豆芽原理相同，但绿豆芽生长速度更快，口感更嫩。

> **100g干绿豆能长成500-700g绿豆芽。增加的重量大部分是水，所以热量不会增加，但会生成原本没有的维生素C，植酸和抑制剂减少，部分蛋白质也会分解成易于消化的形态。**

### 16-2. 绿豆芽的培育步骤

| 步骤 | 内容 | 要点 |
|---|---|---|
| 1. 挑选绿豆 | 以小粒品种为宜。破损或被虫蛀的籽粒全部丢弃 | 破损的籽粒会腐烂，使整体变质 |
| 2. 清洗 | 多次冲洗，捞出浮起的 | 浮起的籽粒大多是死籽 |
| 3. 浸泡 | 在温水中泡6-8小时 | 绿豆膨胀到两倍，种皮开始裂开 |
| 4. 装盛 | 放入能漏水的容器或siru（底部有孔的陶制容器）中，盖上湿布 | 积水会腐烂 |
| 5. 置于黑暗处 | 完全遮光。20-25度为宜 | 见光会变绿，变得老硬发苦 |
| 6. 浇水 | 每天3-4次，从上面充分淋下 | 兼起调节温度和冲走废物的作用 |
| 7. 压重 | 压上较轻的板或石头 | 茎变得粗壮饱满 |
| 8. 收获 | 3-5天，长度4-7cm | 在根变成褐色之前收获 |

| 条件 | 结果 |
|---|---|
| 见光 | 头部变绿，茎变老，带苦味 |
| 浇水少 | 须根多，变得老硬 |
| 积水 | 从下面开始腐烂，发出馊味 |
| 温度超过30℃ | 长得快，但发软，很快变质 |
| 温度低于15℃ | 生长非常缓慢 |
| 压重物 | 茎变得粗壮饱满。这就是市售绿豆芽粗的原因 |
| 不清除豆皮 | 脱落的绿色豆皮会腐烂发臭 |

&nbsp;&nbsp;&nbsp;浇水几乎就是培育绿豆芽的全部。水能提供水分，给发芽过程中产生的热量降温，并冲走积存的废物。每天从上面充分浇3到4次，并让水完全排尽，夏天增加次数，冬天用温水。须根多，是水不够的信号。

&nbsp;&nbsp;&nbsp;绿豆芽在生长过程中，绿色的种皮会脱落并浮起来。每次浇水时都必须把它捞掉。若放着不管，就会腐烂发臭，使整个豆芽变质。浇水时用手或筛子把浮到上面的豆皮捞出来即可。

&nbsp;&nbsp;&nbsp;没有siru的话，可以用底部打了孔的陶罐或桶、密眼的竹筛、钻了孔的盆。下面放一个接水盘，上面盖一块黑布，那就是siru了。重要的只有两点：能排水的结构和遮光。冬天要找一个能保持在20度上下的地方，比如厨房灶台旁，或者暖炕房间里远离灶口的一侧。

&nbsp;&nbsp;&nbsp;绿豆芽生吃也安全，但焯水或炒着吃更好。这样残留的微量抑制剂会减少，体积也会缩小，一次能吃得更多。焯水时，放入沸水中稍烫即捞出，用冷水冲洗。焯得太久会变软烂，维生素C也会一起流失。

### 16-3. 其他烹饪与加工

| 加工 | 步骤概要 | 保存 | 价值 |
|---|---|---|---|
| 绿豆粥 | 把泡好的绿豆煮熟捣碎，与大米一起熬煮 | 当天 | 易消化，用作病人餐 |
| 绿豆淀粉（cheongpomuk，绿豆淀粉冻） | 泡开磨碎后，把沉淀下来的淀粉晒干 | 作为淀粉粉末可保存数月 | 脂肪少，所以淀粉容易凝固 |
| bindaetteok（绿豆煎饼） | 把泡好的绿豆磨碎后煎制 | 当天 | 连皮一起磨也可以 |
| 去皮掰开的绿豆 | 泡开后去皮，掰开 | 密封1-2个月 | 烹饪时间缩短一半 |
| 炒绿豆粉 | 炒后捣碎 | 密封3-6个月 | 不需要烹饪燃料 |
| 绿豆皮 | 提取淀粉后剩下的皮 | 晒干 | 用作家畜饲料和堆肥 |

&nbsp;&nbsp;&nbsp;绿豆淀粉在灾难条件下具有出人意料的价值。把泡好的绿豆磨碎后放入水中静置，较重的淀粉会沉下去，上面浮着含蛋白质的水。把沉淀物晒干就成了纯淀粉粉末，用水调开煮熟就成了cheongpomuk。淀粉比谷物粉更耐储存，而留在上层水中的蛋白质可以另外收集起来煎着吃。也就是说，一种原料能同时得到可贮藏的淀粉和可即食的蛋白质食品。这是只有脂肪极少、仅1%的绿豆才能做到的加工。

### 17-1. 不能忘记的五件事

| 项目 | 内容 |
|---|---|
| 排水 | 在豆类中最怕湿害，而且栽培期与梅雨季重叠。垄高20cm是前提 |
| 分批收获 | 变黑的荚果几天之内就会裂开。要每隔5-7天摘三四次 |
| 晚播 | 是几乎唯一能种到7月中下旬的籽实作物。要留出种子，作为失败后的补救用 |
| 绿豆芽 | 是解决冬季维生素C的答案。一定要另外留出一部分小粒品种 |
| 茎叶 | 只摘荚果而不把剩下的茎还给田地，绿豆就成了掠夺土地的作物 |
