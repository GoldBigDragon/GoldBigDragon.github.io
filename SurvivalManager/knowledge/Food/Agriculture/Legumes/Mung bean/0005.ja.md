## 8. 栽培管理

### 8-1. 間引きと雑草管理

| 作業 | 時期 | 方法 |
|---|---|---|
| 1回目の間引き | 本葉1-2枚 | 1穴あたり2本を残します |
| 2回目の間引き | 本葉3-4枚 | 病気の株を取り除きます |
| 1回目の除草 | 播種後2週間 | 浅く掻きます |
| 2回目の除草 | 播種後4週間、開花前 | 土寄せを兼ねます |
| 開花後 | 除草作業はしません | 根が傷み、花が落ちます |

> **韓国ではリョクトウに登録された除草剤がなく、ほかのマメに使う除草剤をリョクトウに使うと薬害が出ます。農薬のある世の中でも、リョクトウは手で草取りをしなければならない作物です。**

&nbsp;&nbsp;&nbsp;そのため、リョクトウの雑草管理は最初から物理的な手段に頼らなければなりません。最も効果的なのはマルチングです。播種の直後に、条間を藁やもみ殻、落ち葉で覆うと雑草が大きく減り、同時に湿害や泥はねも防げます。マルチングをしていない場合は、播種後2週間と4週間の2回草取りをし、開花が始まったらやめます。リョクトウは根が浅く広がっているため、開花後にホミ（草取り用の小さな手鍬）を入れると根が切れて、かえって収量が減ります。

### 8-2. 倒伏の管理 - 支柱

| 項目 | 方法 |
|---|---|
| 時期 | 草丈が30-40cmに伸びたとき |
| 方法 | 長さ60-80cmの棒を列の両端に立て、縄を張って株を支えます |
| 間隔 | 2-3mごとに杭を1本 |
| 高さ | 地面から30-40cmに縄を1段張れば、たいてい十分です |

&nbsp;&nbsp;&nbsp;リョクトウは茎の力が弱く、倒れやすい作物です。とくに雨に打たれて莢が重くなると、そのまま寝てしまいます。倒れたリョクトウは三つの損失を生みます。莢が土に触れて腐ること、風通しが悪くなって病気が広がること、何度も収穫に入るときにどこが熟しているか見えなくなることです。なかでも3つ目が、実質的には最も大きな損失です。

&nbsp;&nbsp;&nbsp;竹や棒がなければ、列の両側に木の杭を打ち、藁をなって作った縄を膝の高さに1段張るだけでも十分です。エンドウのようにつるが巻きついて登るための支柱が必要なのではなく、横に倒れるのを支えるだけでよいからです。土寄せをあわせて行うと、株元が土に埋まって支えができ、効果が倍増します。

## 9. 病害虫

&nbsp;&nbsp;&nbsp;リョクトウの病害虫圧はCですが、防除自立度はAです。薬がなくても、耕種的手段と天然素材でかなりの部分を抑えられるという意味で、豆類のなかではササゲに次いで高い値です。リョクトウの病害の大半は過湿と関連しているため、排水管理ひとつで多くの問題がまとめて減ります。

### 9-1. 主な病害

| 病名 | 症状 | 発生条件 | 薬を使わない対応 |
|---|---|---|---|
| 根腐病 | 茎の株元と根が褐色に軟化し、株がしおれます | 過湿。生育期間を通して現れます | 畝を高くする、排水溝、石灰で酸度を矯正 |
| 褐斑病 | 葉に褐色の斑点ができ、その部分が抜けて穴があきます | 開花期と莢肥大期の多湿 | 風通しの確保、病葉の除去、ボルドー液 |
| 炭疽病 | 莢と子実に黒い潰瘍ができます | 多湿。種子伝染もします | 種子の選別、輪作、ボルドー液 |
| うどんこ病 | 葉の表面が白い粉に覆われます | 乾燥して日較差が大きいとき | 風通しの確保、牛乳の5-10倍希釈液 |
| ウイルス病 | 葉がモザイク状にまだらになり、縮れます | アブラムシが媒介します | 治療はできません。抜き取って焼き、アブラムシを減らします |

&nbsp;&nbsp;&nbsp;リョクトウの病害の中心には、いつも水があります。根腐病が最も多く最も大きな損失を出し、褐斑病と炭疽病も湿った年にひどくなります。畝を20cm以上高くし、排水溝をしっかり切る、この一つの措置でこの3つの病気が同時に減ります。薬を作ったりまいたりするより、シャベルで土を動かす作業のほうが効果の大きい、まれなケースです。

### 9-2. 主な害虫

| 害虫 | 被害 | 薬を使わない防除 |
|---|---|---|
| カメムシ類 | 莢を刺して汁を吸い、しいなにします | 朝早く露のあるうちに手で捕まえて水桶に入れます |
| アブラムシ | 開花期に花梗に群がって汁を吸い、花を落とし、ウイルスを媒介します | 発生初期に石けん水（水1Lに石けん5g）を葉の裏にかけます |
| ハスモンヨトウ | 葉と茎をかじります | 手で捕まえます。卵塊を見つけたら葉ごと取り除きます |
| アズキゾウムシ | 畑で莢に卵を産み、貯蔵中に子実を食い荒らします | 貯蔵管理が要です。15節参照 |
| 鳥（ハト・キジ） | 播種直後に子葉をついばみます | 発芽まで藁やネットで覆います |

&nbsp;&nbsp;&nbsp;開花期のアブラムシは、リョクトウでとくに問題になります。リョクトウは生育後半のあいだずっと花を咲かせますが、アブラムシが花梗に群がると花がそのまま落ちてしまい、莢がつきません。発生初期に捕らえることが重要で、開花が始まったら3、4日に1回、葉の裏と花梗を見て回る習慣が大切です。

&nbsp;&nbsp;&nbsp;アズキゾウムシは貯蔵段階の問題に見えますが、実際には畑から始まります。畑になっている莢に成虫が卵を産みつけ、その卵が貯蔵庫で孵化します。そのため、熟した莢を長く畑に置かず、適期に収穫することが、貯蔵損失を減らす最初の一歩です。分割収穫をこまめに行うことが、収量と貯蔵性をともに守ります。

### 9-3. 薬を使わない防除資材

| 資材 | 作り方 | 対象 | 注意 |
|---|---|---|---|
| ボルドー液 | 水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜます | 褐斑病、炭疽病 | 銅がなければ作れません。混ぜたらすぐに使います |
| 石けん水 | 水1Lに無香料の石けん5g | アブラムシ、ハダニ | 日中の暑い時間にまくと葉が焼けます |
| 乾いた灰の散布 | 露のある朝に葉に細かい灰をまきます | 葉を食べる虫、カビ | 雨が降ると洗い流されます |
| 草木灰の浸出液 | 灰1升を水10Lに一晩浸け、上澄みを使います | カビの抑制 | アルカリ性なので薄めて使います |
| 木酢液 | 炭を焼くときに出る液を300-500倍に希釈します | 忌避、生育促進 | 原液は強酸性なので必ず希釈します |
| 辛いトウガラシ・ニンニクの液 | すりおろして水に浸出させ、こして使います | 忌避 | 効果が長続きしないので、頻繁にまきます |
| 牛乳の希釈液 | 牛乳を水で5-10倍に希釈します | うどんこ病 | 余ると傷んで悪臭を放ちます |

### 9-4. 耕種的防除

| 方法 | 原理 |
|---|---|
| 排水と畝 | リョクトウの病害の半分以上が過湿と関連しています。最も効果の大きい一つの対策です |
| マルチング | 泥はねが莢に付くのを防ぎ、雑草を抑えます |
| 播種期の調整 | 遅く播いて、害虫の発生ピークを外すことができます |
| 適期収穫 | 熟した莢を畑に長く置くと、ゾウムシが卵を産みつけます |
| 輪作 | 3年以上マメ科を空けます |
| 種子の選別 | 炭疽病は種子で伝染します |
| 栽植距離の確保 | 風通しがよいと葉が早く乾き、カビが定着できません |
| 残渣処理 | 病気の残渣は焼き、健全な残渣だけを畑に戻します |

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然素材での対処 |
|---|---|---|
| 葉全体が淡い黄色で、株が小さい | 窒素欠乏。リョクトウでは、湿害で根粒が死んだ場合が最も多くみられます | まず根を掘って根粒を確認します。排水を直し、尿の10倍希釈液を少量与えます |
| 葉の縁が褐色に枯れる | カリウム欠乏 | 草木灰を株間にまき、軽く掻き込みます |
| 生育が遅く、葉が紫色を帯びる | リン酸欠乏 | 骨粉、焼いた魚骨の粉、草木灰 |
| 花が咲いても莢がつかない | ホウ素欠乏、またはアブラムシの被害 | さまざまな材料を混ぜた堆肥。花梗のアブラムシを観察します |
| 葉脈の間が黄色い | 鉄またはマンガン欠乏。アルカリに傾いた土でよく起こります | 灰の使用をやめます。腐葉土と完熟堆肥で有機物を増やします |
| 茎だけが長く伸びて莢が少ない | 窒素過剰または過湿 | 窒素を断ち、排水を直します |
| 倒れる | 窒素過剰、密植、支柱なし | 土寄せと列の支持。翌年、施肥と栽植距離を調整します |

&nbsp;&nbsp;&nbsp;リョクトウで葉が黄色くなる症状を見たとき、まず疑うべきは肥料不足ではなく水です。韓国の梅雨（チャンマ、6月下旬～7月）のあとに畑全体が黄色くなったなら、ほぼ確実に湿害で、根粒が酸素不足で死に、窒素の供給が途絶えた状態です。このとき窒素を与えても回復しません。まず排水溝を掘って畝間の水を抜き、土を乾かしたうえで、それでも回復が遅ければ、そこで少量の窒素を補います。

&nbsp;&nbsp;&nbsp;微量要素の欠乏は、一つずつ対処するのが困難です。化学肥料なしでモリブデンやコバルトを手に入れる方法は、事実上ありません。その代わり、野菜くず、果物の皮、卵の殻、魚の骨、落ち葉、雑草、灰をいっしょに混ぜて腐らせた堆肥には、微量要素がまんべんなく含まれています。堆肥場に何でも入れるという原則が、微量要素管理の実質的な戦略です。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 作物 | 理由 |
|---|---|---|
| 良い | トウモロコシ・モロコシ（タカキビ） | 草丈の差で光を分け合い、リョクトウが固定した窒素を隣で受け取ります |
| 良い | オオムギ・コムギ・ニンニク・タマネギ・ジャガイモ | 前作にすると6月に畑が空くので、後作としてリョクトウを播きます |
| 良い | ハクサイ・ダイコン | リョクトウの次に植えると、残った窒素を利用します |
| 良い | マリーゴールド | 根の分泌物がセンチュウを抑えます |
| 普通 | サツマイモ | つるがリョクトウを覆わないよう距離をとります |
| 悪い | アズキ・ササゲ | 同じ属なので、病原菌とゾウムシをそのまま共有します |
| 悪い | ほかのマメ科との連作 | 病原菌とセンチュウが蓄積します |

&nbsp;&nbsp;&nbsp;リョクトウの配置で最も重要な原則は、前後をつなぐことです。リョクトウ自体は面積当たり熱量が低く、畑の主役にはなれませんが、前作と後作のあいだの2か月半を埋めるのには最適です。オオムギを6月に収穫してリョクトウを播き、9月に収穫して、その跡にハクサイを植えれば、1つの畑で1年に3つの作物が採れます。その過程で、リョクトウが残した窒素をハクサイが使い、ハクサイの残渣が再び土に戻ります。

&nbsp;&nbsp;&nbsp;アズキとササゲを隣に置かないほうがよいです。同じササゲ属で病原菌を共有し、何よりアズキゾウムシが3つの作物の間を行き来します。同じ畑でアズキとリョクトウをいっしょに育てると、貯蔵庫でのゾウムシの被害が倍増します。

### 11-2. 輪作

| 項目 | 基準 |
|---|---|
| 休作期間 | 3年以上 |
| 理想的な周期 | 3-4年 |
| 連作障害 | 根腐病とセンチュウが蓄積します |

| 4年輪作の例 |
|---|
| 1年目: オオムギ（冬）のあとにリョクトウ（夏） |
| 2年目: トウモロコシまたはモロコシ |
| 3年目: ジャガイモまたはサツマイモ |
| 4年目: ハクサイ・ダイコンの仲間または葉菜 |
| 再びリョクトウ |

&nbsp;&nbsp;&nbsp;畑が狭くて輪作の余裕がないときの妥協案を書いておきます。リョクトウは作付面積が小さくてかまいません。スクジュナムル（リョクトウもやしのナムル）用の種子をつないでいくことが主な目的であれば、数㎡でも十分で、その程度の面積なら毎年場所を変えられます。また、リョクトウは後作として植えることが多いので、前作の輪作計画に乗せて、自然に場所が移っていくように組めば、別に管理しなくても済みます。

## 12. 収穫と脱穀 - 分割収穫

### 12-1. 収穫時期の判断

| 判断基準 | 内容 |
|---|---|
| 莢の色 | 緑色から黒色に完全に変わったとき |
| 開花後の日数 | 40-50日 |
| 播種後の日数 | 約80-90日 |
| 収穫回数 | 3-4回に分けて |
| 間隔 | 5-7日ごとに畑を回り、黒い莢を摘みます |

> **リョクトウの莢は、黒くなって数日のうちに自らねじれてはじけます。黒い莢を見ながらそのままにしておくと、その実は地面に落ちて失われます。収穫期を逃すことが、リョクトウで最もよくある損失です。**

&nbsp;&nbsp;&nbsp;リョクトウは開花と成熟が生育後半のあいだずっと続くので、一度に収穫することはできません。1株の中に、黒い莢と緑の莢と、まだ咲いている花が同時にあります。5日から7日間隔で畑を回り、黒く変わったものだけを選んで摘む方式が原則で、たいていは3、4回に分けて終わります。最後に残った緑の莢は、茎ごと刈り取って日陰で干すと、ある程度は実が入ります。

&nbsp;&nbsp;&nbsp;梅雨や雨の多い時期には判断が変わります。完全に黒くなるのを待っていて雨に当たると、莢の中で発芽したり腐ったりします。雨の予報があるときは、黒くなり始めたものまでいっしょに摘み、室内や軒下で仕上げ乾燥をするほうがよいです。少し未熟なリョクトウは乾燥させて使えますが、発芽してしまったリョクトウは食べることも、播くこともできません。

### 12-2. 収穫のコツ

| 手順 | 内容 |
|---|---|
| 1 | 晴れて乾燥した日に、露が乾いてから行います |
| 2 | 黒い莢だけを手でひねって摘みます。引っ張ると茎が傷みます |
| 3 | 摘んだ莢は、風通しのよいネットやかごに入れます |
| 4 | 玉ねぎネットや白菜ネットに入れて、日なたに広げて乾かします |
| 5 | からからに乾いたら、ネットごと棒でたたいて脱穀します |
| 6 | 最後の収穫後に残った茎は、畑に寝かせるか、すき込みます |

&nbsp;&nbsp;&nbsp;ネットに入れて乾かす方法は、リョクトウでとくに役立ちます。乾く過程で自然にはじける莢が多いのですが、ネットの中にあれば、飛び出した豆がネットの底に集まります。天気のよい日にネットを広げ、ときどき揺すってやれば、脱穀の半分は自然に終わっています。ネットがなければ、袋に入れたり、大きな桶に入れて布をかぶせておいたりしてもかまいません。

### 12-3. 脱穀 - 道具なしでできる方法

| 方法 | 道具 | 手順 | 効率 |
|---|---|---|---|
| ネットに入れてたたく | 玉ねぎネット・白菜ネット | 乾いた莢をネットに入れ、棒でたたきます | リョクトウに最も向いています。豆がこぼれません |
| 袋を踏む | 厚手の麻袋や袋 | 乾いた莢を袋に入れ、足で踏みます | 少量に便利です |
| 殻竿 | 長い柄に打ち棒を取り付けた道具 | むしろを敷いて莢を広げ、打ちつけます | 豆が小さいので四方に飛び散ります。むしろの周りを囲います |
| 手でもむ | なし | 乾いた莢を両手でもみます | ごく少量向き、種子用に適しています |
| 日なたに広げておく | なし | 布の上に薄く広げておくと、自然にはじけます | 最も力がかからない方法です |

&nbsp;&nbsp;&nbsp;リョクトウは莢がよくはじけるので、脱穀がとても簡単です。よく乾いた莢は、布の上に広げておくだけで半分ほどは自然にはじけます。問題は、豆が小さいため四方に飛び散ることです。むしろの周りを布で囲って塞ぐ、大きな桶の中で作業する、ネットに入れてたたく、といった方法で、飛び散る豆を閉じ込めます。失う豆は小さく見えますが、そもそも収量が少ない作物なので、損失の割合は決して小さくありません。

### 12-4. 選別 - 風で選り分ける

| 方法 | 原理 | 手順 |
|---|---|---|
| 風選（風で選り分ける） | 豆は重く、殻やくずは軽いです | 風のある日に、箕や広い器に入れて高く持ち上げ、ゆっくり注ぎ落とします |
| 箕であおる | 上下に揺すりながら前へあおります | 重い豆が手前に残り、軽いものが前へ押し出されます |
| うちわであおぐ | 1人が注ぎ、もう1人がうちわで風を起こします | 風のない日に使います |
| ふるいにかける | 穴の大きさで分けます | 豆が小さいので、目の細かいふるいが必要です |
| 水に浮かせる | しいなや虫食いの豆は軽いです | 水桶に注ぎ、浮いてくるものをすくい取ります。その日のうちに再び乾かします |
| 傾斜板で転がす | 丸い豆はよく転がります | 板を傾けて置き、転がし落とします |

&nbsp;&nbsp;&nbsp;風選のコツは3つです。風が安定して吹く早朝や日没前を選ぶこと、一度にあけずに細く流し落とすこと、2、3回繰り返すことです。リョクトウは粒が小さく軽いので、風が強いと豆まで飛んでしまいます。最初は少量で試して風の強さを見極めてから、本格的に行います。水に浮かせる方法は、アズキゾウムシに食われた豆を選り分けるのにとくに効果的で、貯蔵損失を大きく減らします。ただし、水に浸けたリョクトウはその日のうちに完全に乾かし直す必要があり、種子用には使いません。
