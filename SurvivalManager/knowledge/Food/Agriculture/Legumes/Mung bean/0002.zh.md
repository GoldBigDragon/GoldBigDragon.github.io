&nbsp;&nbsp;&nbsp;绿豆的综合等级为C，得分为42.0分。按不同情景划分，撑过灾害初期的短期能力为C（40.7），跨越多年的长期自立能力为C（43.3），作为主食之外的配菜资源来衡量的副食价值为SS（63.7）。只有副食等级格外突出，这一点概括了绿豆的特点。它成不了主食，却是填补餐桌空缺的作物。

### 1-3. 如何解读优势

&nbsp;&nbsp;&nbsp;获得SS的项目有4项，分别是蛋白质密度、施肥需求、设施负担和耐储性；获得S的有微量营养素、耗水量、口味、韩国国内栽培普及度和自家留种；获得A的有收获速度、防治自立度、无合成投入产量保持率、产量稳定性和种子寿命。

&nbsp;&nbsp;&nbsp;收获速度A级是绿豆的本质特征。需要80-90天，条件好时60天即可收获。这种短周期带来的不只是单纯的快，而是播种时间上的宽裕。在韩国，从4月上旬到7月下旬任何时候都能播种，播种期长达4个月。相比之下，大豆的播种期是6月上旬到下旬，只有一个多月，两者完全不在一个量级。

> **在灾害情境下，计划必然会出现偏差。晚霜冻死幼苗，韩国的梅雨季（6月下旬至7月）让田地被淹，种下去的作物被病害毁掉。这时有没有可以补种的作物，决定了这一年的成败。绿豆是到7月下旬仍可补种的几乎唯一的豆类作物。**

&nbsp;&nbsp;&nbsp;蛋白质密度SS同样值得关注。P:E 27.9%仅次于大豆和蚕豆，高于菜豆、鹰嘴豆和豇豆。这意味着籽粒虽小、产量虽低，但其中所含蛋白质的质量很高。副食等级SS、63.7分正是由此而来。

&nbsp;&nbsp;&nbsp;耗水量S和防治自立度A也需要结合起来看。总蒸散量250mm，用水很少，不用药也能靠农艺手段在很大程度上加以防治。这虽是一种费工的作物，但投入的是劳动，而不是物资。在外界什么都进不来的条件下，能够用劳动替代的作物，要比依赖物资的作物更好。

&nbsp;&nbsp;&nbsp;栽培普及度S和种子寿命A的价值同样很大。绿豆在韩国全国都有种植，种子容易获得，干燥的种子在常温下可保存3至4年。保管得当的话，发芽力能保持5至6年。在获取并延续种子方面，不存在鹰嘴豆或小扁豆那样的困难。

### 1-4. 如何解读劣势

&nbsp;&nbsp;&nbsp;获得E的项目只有耐寒性1项。获得D的有单位面积热量、持续性、光照响应、烹饪·加工、整地能耗和非食用价值，获得C的有温度适应幅度和病虫害压力。

&nbsp;&nbsp;&nbsp;单位面积热量D最为严重。每㎡422kcal，是自给线的0.16倍。它在这份作物表的豆类中排在最后，还不到大豆的一半。整地·挖掘能耗D也由此衍生。回收的热量只是翻地所耗能量的2.6倍，这意味着翻地种绿豆在能量核算上几乎没有盈余。不应把绿豆当作田里的主栽作物。更合适的做法，是把它安排在已经整理好的地方，比如收获其他作物后的空地、田边地角、垄间。

&nbsp;&nbsp;&nbsp;耐寒性E是夏季豆类共有的弱点。一次霜冻就会让它死亡。在初霜出现于9月底到10月初的地区，7月中旬就是播种的极限。晚播的优点和遇霜即死的弱点相互交织，因此计算播种截止日就成了绿豆栽培的关键判断。

&nbsp;&nbsp;&nbsp;持续性D旁边附带的说明，即成熟不整齐而需分3至4次收获这一点，既是优点也是缺点。从优点看，不会一次全部损失，收获分散开来，随时都有东西可吃。从缺点看，劳动被拆成多次，成熟的荚果如果不及时采摘，就会自行炸裂，把籽粒撒落在地上。在人手不足的条件下，这一点是实实在在的限制。

&nbsp;&nbsp;&nbsp;此外，还有一个等级表里没有体现的弱点，那就是湿害。绿豆是豆类中最怕积水的，而且韩国的绿豆栽培期恰好与梅雨季重合。把垄筑高到20cm以上、挖深排水沟，对绿豆来说不是选择，而是前提。试验结果显示，实际起高垄并进行覆盖后，出苗率提高16%，产量提高54%。

## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

&nbsp;&nbsp;&nbsp;绿豆是豆科（Fabaceae）豇豆属（Vigna）的一年生草本植物。它与红小豆、豇豆同属，与它们的亲缘关系远比与大豆或豌豆近。这一点在实践中很重要。与绿豆配对的根瘤菌属于Bradyrhizobium类群，与红小豆和豇豆所用的菌可以通用。这意味着种过红小豆或豇豆的田里的土可以用作接种源，而红小豆在韩国十分常见，因此接种源不难获得。

&nbsp;&nbsp;&nbsp;原产地是印度及其周边地区。它是在热带和亚热带季风气候中生长的植物，喜高温，耐热。生长适温为28-30℃，是豆类中最高的，超过35℃也能忍受。反过来，遇霜即死，15℃以下生长就会停止。它的习性并非与大豆相反，而是比大豆更偏向炎热一侧。

&nbsp;&nbsp;&nbsp;绿豆是自花授粉的。花黄色而小，花瓣包住雌雄蕊，外来花粉很难进入。即使把多个品种并排种植，性状也不会混杂，把收下的种子直接播种，长出来的与亲本相同。

### 2-2. 形态特征

| 器官 | 特征 |
|---|---|
| 叶 | 3片小叶为一组的三出复叶。近心形，有细毛 |
| 茎 | 直立但强度弱。株高60-80cm，会分枝 |
| 根 | 直而粗的主根上伸出须根，并着生根瘤 |
| 花 | 黄色，较小。在生育后期持续开放 |
| 荚果 | 细长圆筒形，长5-10cm。成熟后变黑 |
| 籽粒 | 小而圆，深绿色。单粒重0.05g左右，在豆类中属于最小的一类 |

> **绿豆的荚果成熟后不是变成褐色，而是变成黑色。而且变黑后几天之内，就会自行扭曲炸裂。看到黑色的荚果，当天或第二天就要摘下。**

&nbsp;&nbsp;&nbsp;开花和成熟持续不断，是绿豆与其他豆科作物最大的区别。大豆整块田会同时变黄，可以一次割完；而绿豆自下而上不断开花，同一株上黑色荚果、绿色荚果和花同时存在。由于这一特性，必须分3至4次采摘，如果采用一次性割倒放平的方式，会损失一半以上。

&nbsp;&nbsp;&nbsp;茎秆没有力量，这一点在实际中也很重要。绿豆株高可长到60-80cm，但茎细而软，容易倒伏，尤其是在淋雨之后，或施肥过多导致徒长的情况下。倒伏后荚果触到泥土就会腐烂，需要多次采摘的收获作业也变得困难得多。

### 2-3. 生育阶段

| 阶段 | 时期 | 核心生理 | 关键营养 |
|---|---|---|---|
| 发芽·幼苗期 | 播种后4-5天 | 发芽非常快，在豆类中属于最快的一类 | 磷、少量氮 |
| 营养生长期 | 3-6周 | 茎秆直立并分枝 | 氮由根瘤供给 |
| 开花·结荚期 | 6-8周 | 开始开花，并持续整个生育后期 | 磷、钾 |
| 灌浆·成熟期 | 8-12周 | 下部荚果先变黑成熟。分批收获阶段 | 钾、停止灌水 |

&nbsp;&nbsp;&nbsp;发芽只需4至5天，非常快，这是绿豆的又一个优点。鹰嘴豆需要10至15天，大豆需要5至7天，相比之下绿豆明显更快。播种后几天就能看到结果，失败了可以马上重播。再加上生育期短，这种快速发芽使绿豆成为用于补救失败的作物。

&nbsp;&nbsp;&nbsp;由于生育期短，前期管理几乎决定了产量。播种后3-4周内，如果被杂草压制、被水淹或养分不足，就没有时间恢复。反过来，如果平安度过这个时期，之后就不需要太多人工。

&nbsp;&nbsp;&nbsp;关于前期的氮，有一点需要说明。根瘤并不是在播种后立刻开始工作。从细菌侵染、形成根瘤到开始向植株供氮，需要3周。对于生育期80天的绿豆来说，这3周占整个生育期的25%以上。因此，在基肥中施入少量氮，比其他豆类更有意义。但必须是少量。土壤中氮素充足时，植株会自行减少根瘤的形成，结果只有茎秆徒长而倒伏。

### 2-4. 每100g的营养

| 营养素 | 含量 | 备注 |

| 脂肪 | 1g左右 | 非常少，贮藏期间几乎不会酸败 |

| 糖类 | 0.00g | 为实测值，没有甜味 |
| 铁 | 6mg左右 | 没有肉类时的重要来源 |
| 钾 | 1,200mg左右 | |
| 叶酸 | 丰富 | 与贫血和胎儿发育有关 |
| 维生素C（以绿豆芽计） | 新生成 | 干绿豆中没有，发芽后才会生成 |

&nbsp;&nbsp;&nbsp;干绿豆与绿豆芽实际上是不同的食品。干绿豆中没有维生素C，但发芽后会在萌发过程中重新合成。同时，重量会增加到5至6倍，水分占了大部分，热量密度大幅下降。干绿豆是蛋白质和淀粉的储存库，绿豆芽则是维生素和水分的来源。在灾害情境下，这两者都要加以利用。

&nbsp;&nbsp;&nbsp;氨基酸组成需要单独来看。绿豆蛋白质中赖氨酸和亮氨酸充足，蛋氨酸略显不足。谷物则恰恰相反。与米饭或面包一起吃时，两者互补不足，蛋白质利用率会明显提高。

&nbsp;&nbsp;&nbsp;脂肪含量仅1%，是豆类中最低的，这对贮藏有利。几乎不会发生酸败，即使磨成粉也能存放很久。提取绿豆淀粉制作cheongpomuk的传统，也得益于这种低脂肪含量。以热量密度较低为代价，绿豆成了最易保管的豆类。
