## 3. 栽培环境

### 3-1. 气温与光量

| 条件 | 极限值 | 最适值 | 超出范围时 |
|---|---|---|---|
| 发芽温度 | 15℃以上 | 25-30℃ | 低于15℃时发芽停止，种子腐烂 |
| 生育温度 | 15-40℃ | 28-30℃ | 是豆类中最耐热的 |
| 结实温度 | 20-30℃ | 25-30℃ | 幅度为10℃ |
| 高温极限 | 超过35℃也能忍受 | - | 是最耐酷热的豆类 |
| 耐寒性 | 没有 | - | 一次霜冻就会死亡 |
| 日照 | 每天6小时以上 | 每天8小时以上 | 遮光40%时产量降到一半 |
| 积温 | 1,600℃以上 | - | 与生育期短相适应，需求量较少 |

> **绿豆是几乎唯一能忍受酷热的豆类。在35℃持续不退、大豆的花纷纷脱落的夏天，绿豆仍然不断开花。气候越热，绿豆的相对地位就越高。**

&nbsp;&nbsp;&nbsp;这种对高温的适应力拓宽了绿豆的播种窗口期。在韩国，从4月上旬到7月下旬，只要气温超过15℃，任何时候都可以播种。不过，播种截止日必须从霜期倒推。从预计初霜日往前数90天，就是该地区的播种截止日，在韩国中部大多是7月中旬，在韩国南部是7月下旬。

&nbsp;&nbsp;&nbsp;2季种植之所以可行，也是得益于这么宽的播种窗口期。在韩国南部，可以在4月下旬播种第一茬，7月初收获，随后立即播种第二茬，9月下旬收获。不过，第一茬的灌浆成熟期有可能与韩国的梅雨季（6月下旬至7月）重叠，所以实际上更常见也更安全的做法，是在收获大麦、马铃薯或大蒜后的6月田地里，作为后茬只种一次。

### 3-2. 土壤与水

| 条件 | 极限值 | 最适值 | 备注 |
|---|---|---|---|
| 土壤质地 | 从砂土到壤土 | 排水良好的砂壤土-壤土 | 积水的地块最差 |
| pH | 5.5-7.5 | 6.0-7.0 | 酸性土壤中根瘤减少 |
| 有效土层厚度 | 30cm以上 | 50cm以上 | |
| 生育期蒸散量 | - | 约250mm | 在豆类中属于最少的一类 |
| 淹水 | 仅淹一天根系就会受伤 | - | 是豆类中最不耐湿害的 |
| 垄高 | 20cm以上 | 25cm | 是预防湿害的关键 |
| 地下水位 | 50cm以下 | 80cm以下 | |

> **绿豆栽培的头号大敌是湿害。而且韩国的绿豆栽培期恰好与梅雨季重合。把垄筑高到20cm以上、挖深排水沟，比其他任何管理都要优先。**

&nbsp;&nbsp;&nbsp;起高垄和覆盖的效果已有实测确认。起高垄并同时进行覆盖，出苗率提高16%，产量提高54%。没有塑料薄膜的话，用稻草、稻壳或落叶覆盖，也能在很大程度上取得同样的效果。这样可同时带来三重好处：防止雨水直接击打土壤使表面板结，防止泥土溅到荚果上，还能抑制杂草。

&nbsp;&nbsp;&nbsp;排水沟的要领，是确保田块低处有一条畅通的出水通道。如果只把垄筑高，而沟的末端被堵住，水就会积在沟里，反而更糟。梅雨季来临前，可以顺着沟浇一瓢水，确认它能否一直流到尽头。

## 4. 品种

### 4-1. 韩国国内选育品种

| 品种 | 特点 | 适合的用途 |
|---|---|---|
| Nampyeong-nokdu | 籽粒小，结荚多，产量高 | 籽粒与绿豆芽兼用 |
| Geumseong-nokdu | 荚果不弯曲的直立型，抗病 | 籽粒用 |
| Soseon-nokdu | 小粒种，最适合用来生产绿豆芽 | 绿豆芽专用 |
| Jangan-nokdu | 抗病，抗豆象 | 长期贮藏用 |
| Dahyeon-nokdu | 抗倒伏、抗病害，单株荚果多 | 省工栽培 |
| Chaeheun | 成熟相对整齐，绿豆芽得率高 | 绿豆芽用，一次性收获 |

&nbsp;&nbsp;&nbsp;韩国选育出了多个绿豆品种，且在韩国全国都有种植，因此不难获得种子。与鹰嘴豆或小扁豆相比，这是非常有利的条件。不过在灾害情境下，比起找到哪个品种，更重要的是挑选哪种特性并将其延续下去。

### 4-2. 灾害情境下的重要特性

| 特性 | 为什么重要 | 如何选择 |
|---|---|---|
| 成熟的整齐度 | 减少分批收获的次数，节省劳动 | 选择荚果同时变黑的植株留种延续 |
| 荚果不易炸裂的特性 | 即使错过收获期，损失也较小 | 从变黑数日后仍未炸裂的荚果中留种 |
| 抗豆象特性 | 减少贮藏损失 | Jangan-nokdu品系。种皮厚而坚硬者 |
| 抗倒伏特性 | 收获劳动量可减少数倍 | 茎秆粗壮挺直的植株 |
| 绿豆芽得率 | 同样重量能得到更多豆芽 | 小粒种一般较高 |
| 早熟性 | 可在霜前结束，使2季种植成为可能 | 先开花、先成熟的植株 |

> **选择绿豆品种时，灾害情境下的优先顺序不是产量，而是成熟的整齐度和不易炸裂的特性。人手不足时，去不了3至4趟采摘，没能采摘的荚果就会炸裂消失。**

&nbsp;&nbsp;&nbsp;此外，最好务必留出一部分生产绿豆芽用的小粒种。籽粒越小，发芽时消耗的力气越少，豆芽长得又直又饱满。用大粒种生产豆芽，豆芽会弯曲发软。只备有籽粒用的一种，就无法真正解决冬季蔬菜问题。

## 5. 整地与施肥 - 根瘤菌

### 5-1. 固氮是如何发生的

&nbsp;&nbsp;&nbsp;空气的78%是氮气。人头顶上有取之不尽的氮，植物却无法利用它。因为空气中的氮是两个氮原子以三键牢牢结合的分子，要断开这个键需要巨大的能量。工业上断开这个键来制造氨的方法是哈伯-博施法，世界上的氮肥就来自于此。它需要高温、高压、催化剂和大量化石燃料。

&nbsp;&nbsp;&nbsp;根瘤菌在常温常压下就能完成这件事。它用名为固氮酶的酶断开三键，把氮转变为氨。不过这是有代价的。这个反应需要大量能量，而细菌自己不能进行光合作用。所以它们进入豆科植物的根中生活，从植物那里获得光合作用制造的糖，作为回报，把固定的氮交给植物。这是一种交易关系。

&nbsp;&nbsp;&nbsp;与绿豆配对的菌是Bradyrhizobium类群。它与红小豆和豇豆所用的菌可以互通，与大豆的菌也部分互通。在实践中，种过红小豆的田里的土是最可靠的接种源。红小豆在韩国广泛种植，因此接种源不难获得。

| 阶段 | 发生的事 |
|---|---|
| 1. 信号交换 | 绿豆根系分泌类黄酮，土壤中的细菌响应这一信号，释放结瘤因子 |
| 2. 侵染 | 根毛向内卷曲，将细菌包裹起来，细菌沿着侵染线进入根内 |
| 3. 根瘤形成 | 根内侧的细胞分裂使根瘤膨大，细菌在其中安顿下来 |
| 4. 固氮 | 根瘤内的固氮酶发挥作用，把空气中的氮转变为氨 |
| 5. 分配 | 氨转化为氨基酸，运往茎、叶和荚果 |
| 6. 衰老 | 进入灌浆成熟期后，根瘤丧失功能，随根系一同归于土壤 |

&nbsp;&nbsp;&nbsp;固氮酶对氧气极为敏感，一接触氧气就立刻失去功能。因此，根瘤内部充满了一种叫豆血红蛋白的红色色素蛋白，它能抓住氧气，把酶周围的氧浓度维持在极低的水平。这与人的血液呈红色是同一个原理，剖开根瘤时内部呈红色或粉红色，就是这种色素造成的。这一点在实践中极其重要，因为红色是该根瘤此刻正在固氮的肉眼可见的证据。

&nbsp;&nbsp;&nbsp;绿豆的这套机制尤其脆弱，是有原因的。根瘤菌是需要氧气的好氧细菌，田地被水淹后，它们比根系死得更早。绿豆栽培期与梅雨季重叠，以及它最不耐湿害，这两个事实在这里交汇。被淹2天的绿豆田里叶片发黄，不只是因为根系受损，更是因为氮的来源被切断了。

### 5-2. 确认是否形成根瘤的方法

&nbsp;&nbsp;&nbsp;无论是否接种，都必须确认根瘤是否真的形成。绿豆生育期短，检查时间也相应较早。

| 顺序 | 内容 |
|---|---|
| 1 | 开花开始前后，即播种后5-6周左右是最佳时机 |
| 2 | 选取2至3株看起来健康的植株 |
| 3 | 不要拔起，用铲子在植株周围大范围挖取，连土一起掘起 |
| 4 | 放入水桶，轻轻洗去泥土 |
| 5 | 数一数主根和较粗的须根上着生的根瘤数量 |
| 6 | 用指甲掰开几个根瘤，查看内部的颜色 |

| 观察结果 | 含义 | 措施 |
|---|---|---|
| 每株着生15个以上根瘤 | 接种成功 | 不作处理 |
| 掰开后内部呈红色或粉红色 | 正在固氮 | 状态良好 |
| 掰开后内部呈白色或浅绿色 | 虽已形成根瘤，但没有固氮 | 检查酸度、湿害和缺磷情况 |
| 掰开后内部呈褐色或黑色 | 已经衰老或死亡 | 若在梅雨季之后，很可能是死于湿害 |
| 根瘤在5个以下 | 接种失败 | 如果叶片发黄，补充少量氮 |

> **挖出根系，掰开根瘤，确认其中的红色——这一个习惯，就是在没有氮肥的世界里判断种豆成败的最可靠信号。**

&nbsp;&nbsp;&nbsp;对绿豆来说，最好在梅雨季前后各检查一次。如果梅雨季前还是红色的根瘤，梅雨季后变黑死亡，原因就是湿害。这时要疏通排水沟，如果叶片发黄，就浇很少量的稀释尿液，帮助它撑过剩余的生育期。到了第二年，要把垄筑得更高。

### 5-3. 从哪里获得接种源

&nbsp;&nbsp;&nbsp;商品化的接种剂，是把活的细菌载入泥炭或黏土后出售的产品。在灾害情境下买不到。不过绿豆所用的菌，是红小豆和豇豆也共用的常见菌，所以接种源相对容易获得。

| 方法 | 步骤 | 效果 | 注意 |
|---|---|---|---|
| 用种过红小豆·绿豆·豇豆的田土拌种 | 从前一年种过这些作物、根瘤形成良好的田里，挖取表土5-15cm深度的土。将种子稍微用水润湿，裹上这些土后立即播种 | 最可靠，且不花钱 | 有病田块的土会同时带来病原菌 |
| 直接使用根瘤 | 把挖出的根上的根瘤收集起来捣碎，溶于水中，将种子在这水里浸一下再捞出 | 菌密度最高 | 必须在挖出根瘤的当天用完 |
| 把土撒在田里 | 把取来的土撒在要播种的行上，一同翻入土中 | 菌会在土壤中扩散 | 以每10㎡一铲左右为标准 |
| 保留根茬 | 收获时只割茎秆，把根留在田里 | 菌会在土壤中留存到第二年 | 是最省工的维持方法 |
| 野生红小豆（saepat）的根 | 从田野和田埂上的野生红小豆（saepat）根部采集根瘤 | 同属，所以菌可以互通 | 固氮效率可能低于栽培种所用的菌系 |

&nbsp;&nbsp;&nbsp;接种时有几点必须遵守。根瘤菌极怕直射阳光、干燥和高温。受紫外线照射几分钟就会大批死亡，干燥时死得更快。给种子拌土的作业要在阴凉处进行，拌好土的种子不要摊在太阳下晒，要立即播种。最好在30分钟内播完，最迟也要在几个小时内结束。还有一点，种子消毒和接种不能同时进行。如果用温水处理消毒过，要等完全冷却后再接种。

| 导致接种失败的条件 | 原因 |
|---|---|
| 土壤pH 5.5以下 | 细菌无法存活 |
| 施了大量氮肥的田 | 植株感觉不到交易的必要，会自行减少根瘤的形成 |
| 积水的田 | 它们是好氧细菌，没有氧气就会死亡。这是绿豆上最常见的失败原因 |
| 缺磷的田 | 固氮需要大量能量，其代谢要用到磷 |
| 缺钼·铁·钴 | 它们是固氮酶的组成成分 |
| 把接种后的种子放在阳光下晾晒 | 紫外线和干燥会使菌死亡 |
| 在盛夏烈日下播种 | 土壤表面温度高，附着在种子上的菌会死亡。应在早晨或傍晚播种 |
