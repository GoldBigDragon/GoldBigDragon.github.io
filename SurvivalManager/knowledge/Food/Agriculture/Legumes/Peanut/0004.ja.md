## 5. 畑の準備と肥料 - 窒素収支と施肥

### 5-4. 窒素固定の落とし穴

&nbsp;&nbsp;&nbsp;マメを植えると土地が良くなるという話は、農業の常識として定着しています。半分は正しく、半分は間違っています。この点を正確に理解していないと、マメ科を何年も続けて植えた畑がかえって痩せていくことが起こります。

&nbsp;&nbsp;&nbsp;数字で計算してみます。ラッカセイがよく育てば、1,000㎡から250kgの乾燥した子実が収穫できます。ラッカセイの子実のタンパク質は25.7%で、タンパク質を6.25で割ると窒素量が求められます。25.7 ÷ 6.25は4.11、つまり子実の重量の約4.1%が純粋な窒素です。250kgに含まれる窒素は約10.3kgで、ヘクタールに換算すると103kgです。

&nbsp;&nbsp;&nbsp;一方、ラッカセイの根粒が固定する窒素は、条件が良いときで1ヘクタール当たり70-120kgです。出ていくものと入ってくるものを並べると、次のようになります。

| 項目 | 1ヘクタール当たりの窒素 | 方向 |
|---|---|---|
| 根粒の固定量（条件が良い場合） | 70-120kg | 入る |
| 根粒の固定量（条件が悪い場合） | 25-50kg | 入る |
| 子実としての持ち出し | 90-110kg | 出る |
| 茎葉（茎と葉）に残る窒素 | 30-50kg | 戻せば残り、運び出せば出る |
| 根と根粒に残る窒素 | 10-20kg | 引き抜いて掘り上げるため、一緒に出ていくことがあります |

> **ラッカセイには、ほかのマメにはない問題がもう一つあります。収穫方法が引き抜いて掘り上げるものであるため、根や根粒まで一緒に畑の外へ出てしまう点です。ほかのマメは茎だけを刈って根を残せますが、ラッカセイはそうはいきません。**

&nbsp;&nbsp;&nbsp;そのため、ラッカセイでは茎葉を畑に戻すことがいっそう重要になります。引き抜いた株からさやを外したあと、茎と葉と根をそのまま同じ畑に敷いておかなければなりません。一般に「ラッカセイのつる」と呼ばれるこの残渣は、家畜の飼料などに使うために別の場所へ持ち出されやすいのですが、そうすると窒素収支は確実にマイナスになります。家畜に食べさせた場合は、その糞尿を必ず同じ畑に還さなければなりません。

| 原則 | 内容 |
|---|---|
| 茎葉と根を畑へ | さやを外した茎と葉と根を、その畑に敷いておきます |
| 燃やさない | 燃やすと窒素が気体になって飛んでいき、カリウムとリン酸だけが灰として残ります |
| 病気の残渣だけを選り分ける | 白絹病や萎凋病の症状が出た株は燃やします |
| 家畜に食べさせたなら糞を戻す | ラッカセイのつるは良い飼料です。食べさせた場合は、糞尿をその畑に入れます |
| 殻も戻す | ラッカセイの殻は良い有機物です。砕いて畑に敷くか、堆肥に入れます |

&nbsp;&nbsp;&nbsp;ラッカセイの殻については、別に書き留めておきます。収穫量の3分の1ほどが殻で、かさばるため捨てられがちです。しかしこの殻は良い有機物で、カリウムを含んでいます。砕いて畑に敷けばマルチになり、堆肥に入れれば空気が通る構造をつくって発酵を助けます。燃やして灰にするとカリウムはすぐ使えますが、有機物は失われるため、畑の事情に応じて使い分けます。

### 5-5. 畑の準備と石灰

| 項目 | 方法 | 災害時の条件では |
|---|---|---|
| 耕起 | 播種の2週間前に堆肥と石灰を入れて深く耕します | 土が柔らかくなければ子房柄が入れません |
| 畝 | 幅70-80cm、畝間30-40cm、高さ20cm以上 | 排水と柔らかい土を同時に得られます |
| 酸度矯正 | pH 6.5-7.0 | 強酸性は不適です |
| 石灰 | 消石灰150-200kg/1,000㎡ | ラッカセイでは酸度矯正であると同時にカルシウムの供給です |
| 石拾い | 表面の石を取り除きます | 子房柄が石に阻まれ、さやが奇形になります |
| マルチング | ビニールまたはわら | 地温を上げて播種を早めます |

> **ラッカセイにおいて石灰は、酸度を直す資材ではなく肥料です。土の中のさやが殻を通して直接カルシウムを吸収するため、カルシウムがないとさやの中が空になり、子実がしなびます。**

&nbsp;&nbsp;&nbsp;災害時の条件で石灰の代わりになるのは、貝殻と卵の殻です。どちらも炭酸カルシウムなので原理は同じですが、そのままでは反応が非常に遅いため、火で焼いて砕けやすくしてから、臼でついて細かい粉にして使います。カキ殻が特に良く、海辺に近い場所であれば手に入れやすくもあります。骨粉もカルシウムとリン酸を同時に供給します。草木灰はアルカリ性ですが、主成分はカリウムであるため、カルシウムの供給効果は石灰より弱いです。

&nbsp;&nbsp;&nbsp;カルシウムを入れる時期にもコツがあります。元肥として全面に入れるのが基本ですが、ラッカセイでは開花期に株元の周りの土にもう一度まき、土寄せと一緒に混ぜ込む方法が効果的です。子房柄が入っていくまさにその土の層に、カルシウムがなければならないからです。

### 5-6. 施肥量

| 肥料 | 1,000㎡当たり | ㎡換算 | 備考 |
|---|---|---|---|
| 窒素 | 3kg | 3g | 最小量だけ。根粒が働く前の初期用です |
| リン酸 | 10kg | 10g | 全量を元肥にします |
| カリウム | 10kg | 10g | 全量を元肥にします。さやの肥大に関わります |
| 石灰 | 150-200kg | 150-200g | 播種の2週間前。カルシウムの供給が主な目的です |
| 堆肥 | 1,000-1,500kg | 1-1.5kg | 完熟したものを使います |

&nbsp;&nbsp;&nbsp;評価表でラッカセイの施肥の等級がSSではなくSなのは、この石灰のためです。総投入量は1㎡当たり14gで、ほかの豆類の8g未満より多く、その差は石灰から生じます。窒素そのものは依然として3kgで最小量であり、トウモロコシの7分の1の水準です。

&nbsp;&nbsp;&nbsp;追肥は原則として必要ありません。韓国の梅雨（チャンマ、6月下旬～7月）で湿害を受けて生育が目に見えて悪くなったときに限り、尿素2%溶液を葉に散布する葉面施肥が慣行です。災害時の条件では、尿を水で30倍以上にごく薄く希釈して葉に散布するか、10倍に希釈して株間の土に少量注ぎます。ただし、開花期以降は畑に入ること自体が子房柄を切ってしまうおそれがあるため、注意します。

### 5-7. 災害時の代替肥料

| 代替資源 | 供給される栄養素 | 使い方 | 注意 |
|---|---|---|---|
| 焼いた貝殻・カキ殻 | カルシウム | 焼いて砕き、元肥と開花期の土寄せに使います | ラッカセイで最も重要な資源です |
| 卵の殻 | カルシウム | 焼いて砕いて使います | 量が少ないため補助手段です |
| 骨粉 | リン酸、カルシウム | 焼いて砕き、堆肥に混ぜます | リン酸とカルシウムを同時に与えます |
| 草木灰 | カリウム、リン酸、カルシウム | 1㎡当たり150-200gをまいて混ぜます | カリウムの供給に有効です |
| ラッカセイの殻 | カリウム、有機物 | 砕いて畑に敷くか、堆肥に入れます | 畑の中で循環します |
| 完熟堆肥 | 総合 | 1㎡当たり1-1.5kgを元肥として入れます | 土をさらさらにします |
| 魚の骨 | リン酸、カルシウム | 埋めて腐熟させてから使います | 獣に掘り返されないよう深く埋めます |
| 薄めた尿 | 窒素、カリウム | 水で10倍に薄めて少量 | 湿害からの回復期のみ |
| もみ殻・砂 | 物理性の改良 | 粘質土に混ぜて柔らかくします | 子房柄が入る道をつくります |

&nbsp;&nbsp;&nbsp;ホウ素も覚えておく価値があります。ラッカセイにはホウ素の要求があり、不足するとさやの内側に黒い芯ができる症状が現れます。化学的なホウ砂がない場合は、野菜の残渣と果物の皮と落ち葉を一緒に入れた堆肥が、最も現実的な代替手段です。一種類の材料だけでつくった堆肥は、微量元素が偏ります。

## 6. 播種

### 6-1. 播種時期

| 栽培方式 | 地域 | 播種時期 | 収穫時期 |
|---|---|---|---|
| 露地栽培 | 韓国南部 | 4月下旬-5月上旬 | 10月上旬-11月中旬 |
| 露地栽培 | 韓国中部 | 5月上旬-5月中旬 | 10月上旬-11月中旬 |
| マルチ栽培 | 韓国全土 | 4月上旬-5月上旬 | 9月中旬-10月末 |

&nbsp;&nbsp;&nbsp;ラッカセイの播種時期は、二つの条件の間で決まります。地温が15℃を超えていなければならないという条件と、霜が降りる前に積算温度を満たさなければならないという条件です。前の条件が早く播くことを妨げ、後の条件が遅く播くことを妨げます。その間隔は2-3週間しかありません。

> **ラッカセイは、播種に適した期間が狭い作物です。地温15℃になるのを待ち、その後は急ぎます。5月中旬を過ぎると、韓国中部では霜が降りる前に実が熟しきらない危険が大きくなります。**

&nbsp;&nbsp;&nbsp;マルチングは、この問題を解決する手段です。ビニールを被せると地温が2-4℃上がり、播種を2-3週間早められ、その分だけ積算温度を多く確保できます。災害時にビニールを手に入れにくい場合は、黒い布やわらを被せておいて、播く直前に取り除く方法、南向きの斜面を選ぶ方法、畝を東西方向に作って南側の面がより多く日を受けるようにする方法が、部分的に代わりになります。

### 6-2. 種子の準備

| 項目 | 方法 | 災害時の条件では |
|---|---|---|
| 殻むき | 播く直前にむきます | 前もってむいておくと酸敗し、発芽力が落ちます |
| 選別 | 大きくふっくらして、薄皮がなめらかな粒だけを使います | しなびたもの、色が変わったもの、カビ臭いものは捨てます |
| 胚の確認 | 粒が割れたとき、とがった胚の部分が無傷かを確認します | 胚が欠け落ちた粒は芽が出ません |
| 浸種 | しなくてもかまいません。する場合も数時間だけ | 脂質が多く、長く浸すとふやけて傷みます |
| 灰の処理 | 細かい草木灰をまぶします | 消毒と乾燥を助け、地虫を寄せつけにくくする効果があります |
| 根粒菌の接種 | ラッカセイを育てた畑の土をまぶします | 5-3節を参照 |
| 発芽試験 | 湿らせた布に20粒を包んで数日置き、発芽した数を数えます | 種子寿命が短いため、必ず確認します |

> **ラッカセイの種子は殻付きのまま保管し、播く直前にむきます。殻をむいたラッカセイは酸敗が早く、発芽力が急激に落ちます。前もってむいておくのは楽に見えますが、その分だけ芽が出なくなります。**

&nbsp;&nbsp;&nbsp;種子寿命のDの実務上の意味が、ここで表れます。前年の秋に収穫したラッカセイを殻付きのまま涼しい場所に置いておき、翌年の春にむいて播くのが基本で、それより古い種子は発芽率が大きく下がります。播く前に必ず発芽試験をして発芽率を確認し、半分を下回るようなら、播種量を増やして補うか、別の種子を入手します。

### 6-3. 播種方法

| 項目 | 基準 | 理由 |
|---|---|---|
| 播種の深さ | 2-3cm | ごく浅く播きます。深いと芽が出ず、腐ります |
| 畝の幅 | 70-80cm | 2列から3列を播きます |
| 畝間の幅 | 30-40cm | 排水路と通路を兼ねます |
| 株間 | 15-20cm | |
| 1穴当たりの粒数 | 2粒 | 発芽率を見込んでいます |
| 向き | 胚（とがった側）を下に向ける | 出芽が早くなります |

&nbsp;&nbsp;&nbsp;播種の深さが2cmから3cmと非常に浅いことが、ラッカセイの特徴です。種子が大きく脂質が多いため、深く埋まると土を突き破って上がってくる力が足りず、その間に土の中で腐ります。ほかのマメよりはっきり浅く播かなければならず、そのかわり浅く埋めた分だけ鳥や地虫や乾燥にさらされるため、わらや網を被せてやります。

&nbsp;&nbsp;&nbsp;マルチ栽培では順序が異なります。畝を作ってビニールを被せたあとで穴を開けて播くか、播いてからビニールを被せ、芽が上がってくるころにその場所に穴を開けてやります。後者の方式では、芽がビニールの下に閉じ込められて焼け死なないよう、毎日見回らなければなりません。

## 7. 水管理

| 時期 | 水管理 | 理由 |
|---|---|---|
| 播種から発芽まで | 土がからからに乾かないようにします | 浅く埋まっているため、表層が乾くと発芽が止まります |
| 生育初期 | 適度な水分を保ち、過湿を避けます | |
| 開花・着果期 | 湿害に特に弱いです。排水路を整えます | 子房柄が地中に入る時期です |
| 梅雨期 | 排水溝を掘ります | 白絹病は蒸し暑い梅雨の後にやってきます |
| 8月上旬以降の乾燥期 | 10日間隔で2-3回灌水します | さやの肥大に直結します |
| 収穫の2週間前 | 灌水を中止します | 湿った土から掘ったラッカセイにはカビが生えます |

> **ラッカセイの水管理で最も重要な時期は、8月のさやの肥大期です。梅雨が終わって続く乾燥期に水が不足すると、すでに土に入ったさやが大きくなれません。10日間隔で2、3回与えるだけでも、収量が大きく変わります。**

| 症状 | 原因 | 対応 |
|---|---|---|
| 日中に葉が閉じ、夕方に開く | 正常な水分節約の反応です | そのままにします |
| 朝も葉が閉じている | ひどい乾燥 | 灌水します |
| 花はたくさん咲くのにさやができない | 土が固まって子房柄が入れません | 土寄せで土を柔らかくします |
| さやはできたが中が空 | カルシウム不足 | 焼いた貝殻の粉を株元にまき、土寄せをします |
| 茎の根元に白い糸のようなカビ | 白絹病。蒸し暑い梅雨の後に発生します | 病気の株を土ごと掘り上げて燃やします。排水を改善します |
| 下葉が黄色くなり、根が黒い | 過湿による根の傷み | 排水溝を掘ります |
| 葉に茶色の斑点ができ、早く落ちる | 褐斑病 | 風通しの確保、病葉の除去、ボルドー液 |

&nbsp;&nbsp;&nbsp;花は咲くのにさやができない症状が、ラッカセイで最もよくある失敗です。原因はたいてい土にあります。表面が雨に打たれて固まっていたか、粘質土のために子房柄が突き破れなかったか、土寄せをしなかったために子房柄が地面に届くまでの距離が遠すぎたかのいずれかです。開花期に畑を見回り、子房柄が土に刺さっているかどうかを自分の目で確かめるのが確実です。株元の周りをのぞき込むと、細い柄が下に向かって土に刺さっているのが見えます。

&nbsp;&nbsp;&nbsp;収穫前の灌水の中止も重要です。湿った土から掘り上げたラッカセイは、殻に土と水分が付いており、その状態で積んでおくと、1日か2日でカビが生え始めます。アフラトキシンの出発点は、たいていここにあります。収穫の2週間前からは水を与えず、雨が降った直後は、土が乾くまで待ってから掘ります。
