## 5. 整地与施肥 - 氮素收支与施肥

### 5-4. 固氮的陷阱

&nbsp;&nbsp;&nbsp;种了豆类，土地就会变好——这种说法已经成了农业上的常识。它一半对，一半错。如果不能准确理解这一点，连续几年种植豆科作物的田地反而会越来越贫瘠。

&nbsp;&nbsp;&nbsp;我们用数字来算一算。花生长得好时，每1,000㎡能收获250kg干籽粒。花生籽粒的蛋白质含量为25.7%，把蛋白质除以6.25就得到氮含量。25.7 ÷ 6.25等于4.11，也就是说籽粒重量的约4.1%是纯氮。250kg中所含的氮约为10.3kg，换算成公顷就是103kg。

&nbsp;&nbsp;&nbsp;另一方面，花生根瘤在条件好时固定的氮为每公顷70-120kg。把流出的和流入的并排放在一起，结果如下。

| 项目 | 每公顷氮量 | 方向 |
|---|---|---|
| 根瘤固氮量（条件好） | 70-120kg | 进入 |
| 根瘤固氮量（条件差） | 25-50kg | 进入 |
| 随籽粒带出 | 90-110kg | 流出 |
| 残留在茎叶（茎和叶）中的氮 | 30-50kg | 还田则留下，运走则流出 |
| 残留在根和根瘤中的氮 | 10-20kg | 因为是连根拔起收获，可能一并流出 |

> **花生还有一个其他豆类没有的问题。由于收获方式是连根拔起，根和根瘤也会一起被带出田外。其他豆类可以只割茎而把根留在地里，花生却做不到。**

&nbsp;&nbsp;&nbsp;所以，对花生来说，把茎叶还田就更加重要。拔出的植株摘下荚果后，要把茎、叶和根原样铺在这块田里。这种通常称为花生秧的残体，容易被拿去当作牲畜饲料等而运到别处，而一旦这样做，氮素收支就肯定成为负数。如果拿它喂了牲畜，就必须把牲畜的粪尿还到这块田里。

| 原则 | 内容 |
|---|---|
| 茎叶和根还田 | 摘下荚果后的茎、叶和根，铺在这块田里 |
| 不要焚烧 | 焚烧会使氮变成气体飞散，只剩钾和磷留在灰里 |
| 只挑出病害残体 | 有过白绢病或枯萎病症状的植株要烧掉 |
| 喂过牲畜就把粪还田 | 花生秧是很好的饲料。喂过之后，要把粪尿施回这块田里 |
| 果壳也要还田 | 花生壳是很好的有机物。砸碎后铺在田里，或加入堆肥 |

&nbsp;&nbsp;&nbsp;花生壳需要单独记一笔。收获量的1/3左右是壳，体积大，容易被丢掉。但这种壳是很好的有机物，含有钾。砸碎后铺在田里就成了覆盖物，加入堆肥则能形成透气的结构，帮助发酵。烧成灰的话，钾可以立即利用，但有机物就没有了，所以要根据田地的情况分别使用。

### 5-5. 整地与石灰

| 项目 | 方法 | 灾害情况下 |
|---|---|---|
| 翻耕 | 播种前2周施入堆肥和石灰，深耕 | 土壤松软，子房柄才能入土 |
| 垄 | 垄宽70-80cm，沟宽30-40cm，垄高20cm以上 | 同时获得排水和松软的土壤 |
| 酸度调节 | pH 6.5-7.0 | 强酸性不适宜 |
| 石灰 | 熟石灰150-200kg/1,000㎡ | 对花生来说，既是调节酸度，也是补充钙 |
| 捡石 | 捡去表面的石块 | 子房柄会被石头挡住，荚果会变成畸形 |
| 覆盖 | 塑料薄膜或稻草 | 提高地温，使播种提前 |

> **对花生来说，石灰不是用来调节酸度的材料，而是肥料。土中的荚果通过果壳直接吸收钙，没有钙，荚果里面就会空瘪，籽粒也会干瘪。**

&nbsp;&nbsp;&nbsp;在灾害情况下，能代替石灰的是贝壳和蛋壳。二者都是碳酸钙，原理相同，但直接使用反应非常慢，所以要用火烧到容易碎，再用臼捣成细粉来用。牡蛎壳尤其好，靠近海边的地方也容易找到。骨粉也能同时提供钙和磷。草木灰虽然呈碱性，但主要成分是钾，补钙的效果不如石灰。

&nbsp;&nbsp;&nbsp;施钙的时机也有讲究。作为基肥全面施入是基本做法，但对花生来说，在开花期再往植株基部周围的土壤中撒一次，并与培土一起拌入，效果更好。因为子房柄入土的那一层土壤中必须有钙。

### 5-6. 施肥量

| 肥料 | 每1,000㎡用量 | 折合每㎡ | 备注 |
|---|---|---|---|
| 氮 | 3kg | 3g | 仅施最小量。供根瘤开始工作之前的初期使用 |
| 磷 | 10kg | 10g | 全部作基肥 |
| 钾 | 10kg | 10g | 全部作基肥。与荚果膨大有关 |
| 石灰 | 150-200kg | 150-200g | 播种前2周。主要目的是补钙 |
| 堆肥 | 1,000-1,500kg | 1-1.5kg | 使用充分腐熟的 |

&nbsp;&nbsp;&nbsp;评价表中花生的施肥需求等级是S而不是SS，原因就在于这些石灰。总投入量为每㎡14g，比其他豆类不足8g的水平要多，这个差额来自石灰。氮本身仍然只有3kg，是最小量，约为玉米的1/7。

&nbsp;&nbsp;&nbsp;原则上不需要追肥。只有在韩国的梅雨季（6月下旬至7月）受渍害、生长明显变差时，才按惯例向叶面喷施2%尿素溶液，即叶面施肥。在灾害情况下，可以把尿液用水稀释30倍以上，非常稀薄地喷到叶面上，或者稀释10倍后少量浇在植株之间的土壤上。不过，开花期以后，进入田里这件事本身就可能折断子房柄，所以要小心。

### 5-7. 灾害情况下的替代肥料

| 替代资源 | 提供的养分 | 用法 | 注意 |
|---|---|---|---|
| 烧过的贝壳·牡蛎壳 | 钙 | 烧后捣碎，用于基肥和开花期培土 | 对花生来说是最重要的资源 |
| 蛋壳 | 钙 | 烧后捣碎使用 | 量少，只能作辅助手段 |
| 骨粉 | 磷、钙 | 烧后捣碎，拌入堆肥 | 同时提供磷和钙 |
| 草木灰 | 钾、磷、钙 | 每㎡撒150-200g并拌匀 | 对补钾有效 |
| 花生壳 | 钾、有机物 | 砸碎后铺在田里，或加入堆肥 | 在田内循环利用 |
| 腐熟堆肥 | 综合 | 每㎡施1-1.5kg作基肥 | 使土壤变得疏松 |
| 鱼骨 | 磷、钙 | 埋入土中使其腐化后再用 | 要深埋，免得被野兽刨出来 |
| 稀释尿液 | 氮、钾 | 用水稀释10倍，少量使用 | 仅限渍害后的恢复期 |
| 稻壳·沙 | 物理改良 | 掺入黏质土使之松软 | 为子房柄开出入土的通路 |

&nbsp;&nbsp;&nbsp;硼也值得记住。花生对硼有需求，缺硼时荚果内部会出现黑心症状。没有化学硼砂时，把蔬菜残体、果皮和落叶一起放入的堆肥是最现实的替代办法。只用一种材料做的堆肥，微量元素会有所偏颇。

## 6. 播种

### 6-1. 播种时期

| 栽培方式 | 地区 | 播种时期 | 收获时期 |
|---|---|---|---|
| 露地栽培 | 韩国南部 | 4月下旬-5月上旬 | 10月上旬-11月中旬 |
| 露地栽培 | 韩国中部 | 5月上旬-5月中旬 | 10月上旬-11月中旬 |
| 覆盖栽培 | 韩国全国 | 4月上旬-5月上旬 | 9月中旬-10月底 |

&nbsp;&nbsp;&nbsp;花生的播种时期取决于两个条件之间：一是地温必须超过15℃，二是必须在霜前凑足积温。前一个条件阻止过早播种，后一个条件阻止过晚播种。两者之间的间隔只有2-3周。

> **花生是播种窗口期很窄的作物。要等到地温达到15℃，但此后就要抓紧。过了5月中旬，在韩国中部，霜前无法成熟的风险就会加大。**

&nbsp;&nbsp;&nbsp;覆盖是解决这个问题的手段。盖上塑料薄膜可使地温升高2-4℃，使播种提前2-3周，相应地多获得积温。灾害情况下如果难以弄到塑料薄膜，可以先盖上黑布或稻草，到临近播种时再揭掉；也可以选择朝南的坡地；还可以把垄做成东西走向，使南侧一面多受阳光。这些办法可以部分替代地膜。

### 6-2. 种子准备

| 项目 | 方法 | 灾害情况下 |
|---|---|---|
| 剥壳 | 临近播种时再剥 | 提前剥好的话会酸败，发芽力下降 |
| 挑选 | 只用颗粒大而饱满、种皮光滑的籽仁 | 干瘪的、变色的、有霉味的都要丢弃 |
| 检查胚 | 籽仁掰开时，看尖尖的胚部是否完好 | 胚脱落的籽仁不会发芽 |
| 浸种 | 可以不浸。即使浸，也只浸几个小时 | 脂肪多，浸久了会变软腐烂 |
| 草木灰处理 | 给种子拌上细草木灰 | 有助于消毒和干燥，并能驱避地下害虫 |
| 根瘤菌接种 | 用种过花生的田地的土拌种 | 参见5-3节 |
| 发芽试验 | 用湿布包20粒，放几天后数发芽的粒数 | 种子寿命短，务必检查 |

> **花生种子要带壳保存，临近播种时再剥壳。剥了壳的花生酸败很快，发芽力会急剧下降。事先剥好看似省事，但会因此出不了苗。**

&nbsp;&nbsp;&nbsp;种子寿命D的实际意义在这里显现出来。基本做法是，把去年秋天收获的花生带壳放在阴凉处，第二年春天再剥壳播种，比这更陈的种子发芽率会大幅下降。播种前一定要做发芽试验确认发芽率，如果低于一半，就增加播种量来补偿，或者另找种子。

### 6-3. 播种方法

| 项目 | 标准 | 原因 |
|---|---|---|
| 播种深度 | 2-3cm | 要种得很浅。过深则出不了芽，还会腐烂 |
| 垄宽 | 70-80cm | 种两行到三行 |
| 沟宽 | 30-40cm | 兼作排水沟和通道 |
| 株距 | 15-20cm | |
| 每穴粒数 | 2粒 | 考虑到发芽率 |
| 方向 | 胚（尖的一端）朝下 | 出苗更快 |

&nbsp;&nbsp;&nbsp;播种深度只有2cm到3cm，非常浅，这是花生的特点。种子大且脂肪多，埋得深就没有足够的力量顶开土壤钻出来，在此期间就会在土里腐烂。花生必须比其他豆类明显种得更浅，不过种得浅也就更容易受到鸟类、地下害虫和干燥的影响，所以要盖上稻草或网。

&nbsp;&nbsp;&nbsp;覆盖栽培的顺序有所不同。可以先起垄、盖膜，再打孔播种；也可以先播种再盖膜，到幼芽快要顶出来的时候在相应位置打孔。后一种方式要每天查看，以免幼芽被闷在薄膜下面烧死。

## 7. 水分管理

| 时期 | 水分管理 | 原因 |
|---|---|---|
| 从播种到发芽 | 不要让土壤干透 | 种得浅，表层一干，发芽就会停止 |
| 生育初期 | 保持适宜的水分，避免过湿 | |
| 开花·结荚期 | 特别怕渍害。要整修水道 | 此时是子房柄入土的时期 |
| 梅雨期 | 开挖排水沟 | 白绢病在闷热的梅雨之后发生 |
| 8月上旬以后的干旱期 | 每隔10天灌水2-3次 | 直接关系到荚果膨大 |
| 收获前2周 | 停止灌水 | 从湿土里挖出的花生会长霉 |

> **花生水分管理中最重要的时期，是8月的荚果膨大期。梅雨结束后紧接着的干旱期如果缺水，已经入土的荚果就长不大。只要每隔10天浇两三次水，产量就会大不一样。**

| 症状 | 原因 | 措施 |
|---|---|---|
| 中午叶片合拢，傍晚又展开 | 正常的节水反应 | 保持原样 |
| 早晨叶片也合拢着 | 严重干旱 | 灌水 |
| 花开得很多却不结荚果 | 土壤板结，子房柄无法入土 | 通过培土使土壤松软 |
| 结了荚果但里面是空的 | 缺钙 | 把烧过的贝壳粉撒在植株基部并培土 |
| 茎基部有白色丝状霉菌 | 白绢病。在闷热的梅雨之后发生 | 连土挖出病株烧掉。改善排水 |
| 下部叶片发黄，根发黑 | 过湿导致根系受损 | 开挖排水沟 |
| 叶片出现褐色斑点并提早脱落 | 褐斑病 | 保证通风，摘除病叶，喷波尔多液 |

&nbsp;&nbsp;&nbsp;只开花不结荚果，是花生最常见的失败。原因通常出在土壤上：表面被雨水打得板结了，或者是黏质土，子房柄钻不进去，或者没有培土，子房柄离地面太远，够不着。开花期到田里查看，亲自确认子房柄是否插进了土里，是最可靠的办法。仔细看植株基部周围，就能看到细细的柄向下插进土里。

&nbsp;&nbsp;&nbsp;收获前停止灌水也很重要。从湿土中挖出的花生，果壳上带着泥土和水分，就这样堆放，一两天内就会开始长霉。黄曲霉毒素的源头通常就在这里。收获前2周起不再浇水，刚下过雨后，要等土壤变干再挖。
