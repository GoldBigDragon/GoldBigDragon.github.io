## 引言
&nbsp;&nbsp;&nbsp;花生（Arachis hypogaea）是原产于南美洲安第斯山脉东麓的豆科一年生草本植物，在地上开花，在地下结果。受精结束后，子房基部像柄一样长长地伸出，钻入土中，荚在它的末端长大，栽培的几乎所有要领都来自这一生理特性。花生的价值在于热量。干花生每100g含520kcal，是豆类中最高的；单位面积热量为每1㎡ 1,300kcal，是自给线的0.50倍；相对于整地·挖掘能量的热量回收倍数为8.7倍，都是豆类中最高的。脂肪占45-50%，榨了就是油，烹调·加工等级为S，生吃或只需炒10分钟即可，是唯一不需要燃料就能吃的豆类。综合等级为C（43.6分，有效183种中第75位），短期C（43.0）、长期C（44.2）、副食SS（57.6分）。弱点是遇霜就死的130-150天的漫长生长期、常温下不到一年的种子寿命、4-5年的休耕，以及加热也不会消失的霉菌毒素黄曲霉毒素。热量最高的豆子，在储存上也是最难伺候的豆子。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | C | 43.6 |
| 短期 | C | 43.0 |
| 长期 | C | 44.2 |
| 副食 | SS | 57.6 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：设施负担。S：蛋白质密度、施肥、烹调·加工要求度、耐储性、口味、国内种植普及度、自留种。A：微量营养素、水消耗量、无合成投入产量保持率、产量稳定性 |
| 劣势 | E：耐寒性。D：持续性、光照、非食用价值、种子寿命。C：单位面积热量、收获速度、温度幅度、病虫害压力、防治自立度、连作适应性、整地·挖掘能量 |

> **花生是豆类中唯一靠热量取胜的豆子。如果说其他豆子是提供蛋白质的配菜，花生就是提供脂肪和热量的主食。**

&nbsp;&nbsp;&nbsp;烹调·加工S在豆类中只有花生有，所以在无法生火的灾害初期，一把花生比任何豆子都有价值。单位面积热量虽然等级为C，但数值是豆类中最高的，加上水消耗量A（总蒸散量450mm），其他作物长不好的沙地反而适合它。种子寿命D是最显眼的弱点：脂肪氧化变质会损伤胚，所以必须每年留种，一年的农事失败就可能没有来年的种子。连作适应性C和防治自立度C来自根荚腐烂病、枯萎病和褐斑病，而收获速度C与耐寒性E叠加，错过适宜播种期就会损失这一年。等级表中没有的风险是黄曲霉毒素（第10节）。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 豆科落花生属一年生草本。原产南美洲，自花授粉 |
| 叶、茎 | 4片小叶的羽状复叶，夜里合拢。有直立型、半直立型、匍匐型，株高30-50cm |
| 根、花 | 直立主根，带圆形根瘤。黄色蝶形花开在下部的节上，当天就凋谢 |
| 荚、籽粒 | 在土中生长，壳上有网纹，内含2-3粒种子 |

> **花生在地上开花，在地下结果。子房柄如果钻不进土里，花开得再多，花生也一粒都结不出来。**

&nbsp;&nbsp;&nbsp;受精后的子房基部伸长，向下弯曲碰到地面，钻入土中3-7cm之后，末端才膨大成荚。由此得出三条原则。第一，表面板结或石头多，子房柄就钻不进去，所以土要松软，并在开花期培土。第二，荚不是靠根，而是靠荚壳直接从土中吸收钙，所以缺钙就会结出空荚。第三，茎上部开的花在子房柄碰到地面之前就耗尽了力气，所以开花位置要低。开花从6月持续到9月，将近100天，晚开的花结的荚到收获时还没成熟，所以收获时机难以判断。干花生每100g含热量520kcal、蛋白质25.74g（占热量的19.8%）、脂肪45-50g（大部分是不饱和脂肪酸）、碳水化合物16-20g（豆类中最少）、膳食纤维10.5g、钙67mg、铁2mg，维生素E丰富。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽要求5cm深处地温15℃以上（适温20-25℃，低于15℃种子会烂）。生长18-35℃（适温25-30℃）。结实20-30℃（适温24-28℃）。积温早熟种2,800℃，晚熟种3,600℃。日照每天6小时以上（适宜8小时以上） |
| 土壤、水 | 沙壤土（黏土和石头多的地不适合），pH 5.5-7.5（适宜6.5-7.0），有效土层30cm以上，土中钙充足。开花期特别怕渍害，所以垄高20cm以上 |

&nbsp;&nbsp;&nbsp;判断播种的标准是地温而不是气温，没有地温计的话，早晨把手伸进土里，感觉不凉就是标准。地膜覆盖可使播种提前2-3周，多获得积温。抓一把土不成团、松散地散开就适合花生，如果只有黏土，就掺入沙子或稻壳做垄。

| 类型 | 特点 | 灾害适应度 |
|:---|:---|:---|
| 直立型 | 荚集中在植株基部，一拔大部分就带出来 | 最高 |
| 匍匐型 | 荚分散得很广，遗漏很多 | 低 |

&nbsp;&nbsp;&nbsp;在人手不足、霜来得早的地方，直立型早熟种比较合理；要榨油就选籽粒越大越容易榨的大粒种，夏天需要吃的就选鲜食花生用的品种。Saedeul和Daegwang是直立型早熟大粒种，Namgwang对褐斑病相对较强。种子寿命不到一年，所以不管选哪个品种，让这个品系不间断地传下去，比选品种更重要。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 播种前2周施入堆肥和石灰，深翻使土壤松软，并捡去表面的石头。垄宽70-80cm，沟宽30-40cm，高20cm以上 |
| 石灰、钙 | 熟石灰150-200kg/1,000㎡，把pH调到6.5-7.0，在花生上它同时也是钙肥（pH超过7.5会妨碍铁、锰、锌的吸收，叶脉间发黄，所以上限为200kg）。可用烧过捣碎的贝壳·牡蛎壳和蛋壳粉代替，开花期再向植株基部的土里撒一次，与培土混合 |
| 施肥（1,000㎡） | 磷10kg、钾10kg（全部作基肥），氮用最小量，堆肥每㎡ 1-1.5kg。磷用骨粉补足，钾用木灰（每㎡ 150-200g）和捣碎的花生壳补足。缺硼会使荚内侧出现黑心，所以用多种材料混合的堆肥 |
| 根瘤接种 | 用种过花生且根瘤长得好的地块5-15cm深的土，裹在稍用水润湿的种子上，立刻播下。不要用有过根荚腐烂病或枯萎病的田地的土，其他豆科田地的土效率较低 |

&nbsp;&nbsp;&nbsp;根瘤要在开花前后（播种后6-7周）检查，但把植株挖起来检查，这株的子房柄就断了，很难指望收成，所以只看田边的两三株。

| 播种 | 标准 |
|:---|:---|
| 时期 | 南部4月下旬-5月上旬，中部5月上旬-中旬，覆膜栽培全国4月上旬-5月上旬。等地温到15℃，之后要抢时间（余地只有2-3周，过了5月中旬，中部在霜前来不及成熟的风险就变大） |
| 种子准备 | 带壳保存，种前再剥壳（提前剥会氧化变质，发芽力下降）。只用粒大饱满、种皮光滑的种子，扔掉皱缩的和有霉味的。裹上细木灰，用湿布包20粒做发芽试验 |
| 方法 | 深度2-3cm，非常浅，每垄70-80cm种2-3行，株距15-20cm，每穴2粒，尖的一端朝下。为防鸟和土中害虫，用稻草或网盖住。覆膜时打孔播种，开花前后把植株周围的薄膜划破或揭开，让子房柄能钻进去 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 开花·结果期、雨季 | 特别怕渍害，所以要疏通水路并挖排水沟（白绢病出现在闷热的雨季之后） |
| 8月上旬以后的干旱期 | 每隔10天灌溉2-3次 |
| 收获前2周 | 停止灌溉（从湿土里挖出的花生会发霉） |

> **花生水分管理最重要的时期是8月的荚膨大期。雨季之后连着的干旱期如果缺水，已经入土的荚长不大，只要每隔10天浇两三次水，产量就会大不相同。**

| 管理 | 方法 |
|:---|:---|
| 培土 | 第一次在开花开始前后，把植株基部周围的土松软地刮起；第二次在子房柄开始伸出时，再多培些土并混入钙粉。目的不是把土堆厚，而是使其松软，已经伸出的细柄如果被弄断，那个荚就没了 |
| 除草 | 生长初期浅锄，开花前的最后一次除草与培土结合。开花后只拔够得着的大草，不进田（踩踏会弄断子房柄并使土板结） |

## 6. 病虫害与养分问题
| 病虫害 | 症状与条件 | 不用药的防治 |
|:---|:---|:---|
| 褐斑病、黑斑病 | 叶上出现暗褐色斑点和黄色晕圈，叶片早落，产量减少一半到60%。7月中旬到收获期 | 保证通风，从7月中旬起摘掉下部叶片上的病斑并烧毁病残体，每隔10-15天喷波尔多液，轮作，选留抗病品系 |
| 白绢病、根荚腐烂病 | 茎基蔓延白色丝状霉层，植株萎蔫枯死（闷热的雨季之后）/ 根和荚腐烂。土壤传染 | 把病株连同周围的土挖出烧掉，改善排水；4-5年轮作是唯一的根本对策 |
| 蛴螬 | 在土里啃食根和荚的最大害虫。壳上的伤口成为霉菌的通道，是黄曲霉毒素的起点 | 只用完全腐熟的堆肥，翻地时见到就捉 |
| 蚜虫、蓟马、叶螨 | 吸汁并传播病毒病（叶片呈花叶斑驳，无法治疗）（蚜虫、蓟马），或使叶片发黄斑驳（叶螨，雨季后干燥时） | 肥皂水（1L水加5g肥皂），用水猛冲叶片。病毒病植株拔掉烧毁 |

&nbsp;&nbsp;&nbsp;波尔多液是分别把400g硫酸铜和400g生石灰溶于100L水，混合后用作预防。

| 症状 | 原因与措施 |
|:---|:---|
| 花开得多但不结荚 | 被雨打板结的表面、黏土、培土不足使子房柄钻不进土里。通过培土使土松软 |
| 荚结了但里面是空的 | 缺钙：荚生长的土表以下几厘米的层里必须有钙，所以开花期把烧过捣碎的贝壳粉撒在植株基部并培土 |

&nbsp;&nbsp;&nbsp;根瘤每公顷固定70-120kg氮，茎叶中留有30-50kg，但花生是连根拔起收获的，所以根和根瘤（10-20kg）也被带出田外。因此摘掉荚后的茎、叶、根，以及占收获量约三分之一的壳，必须还田。如果蔓用来喂了牲畜，就把牲畜的粪肥还到这块田里。

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 玉米、粟、高粱（不共享病害，并利用花生留下的氮），芝麻，辣椒、西瓜（适合作轮作对象） |
| 差 | 烟草（培养相同的土壤病原菌），花生连作（白绢病、根荚腐烂病使产量大幅下降） |

&nbsp;&nbsp;&nbsp;花生生长期长，开花后又不能进田，所以更适合轮作而不是间作。白绢病和根荚腐烂病会残留在土里，所以要休耕4-5年，5年轮作的例子是：花生 → 玉米或粟 → 芝麻或辣椒 → 西瓜或根菜类 → 谷物或叶菜。田地窄的话，每年换用沙质地块，或隔一年、隔两年才种一次，但因为种子寿命不到一年，每年要另外种几株留种用的。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 播种后130-150天（中部9月底-10月初，南部10月初-11月中旬）。因为在土里，要试挖两三株，剖开荚，内壁呈褐色或黑色的荚占60-80%时就是适期。如有霜冻预报，即使没熟透也要挖 |
| 要领 | 在晴朗干燥的日子挖。雨后湿土会粘在壳上，一两天就开始发霉，所以要等土干了再挖。在植株旁挖开，抓住茎拔起，匍匐型或土板结的田里，要把拔起处再耙一遍找剩下的荚。把荚朝上翻过来在田里预干几天，并挑出坏荚 |
| 干燥 | 预干3-7天后摘下荚，薄薄摊在簸箕或席子上，在通风良好的阴凉处慢慢晾干（强日晒会使壳开裂，成为霉菌的通道）。摇一摇籽粒哗啦作响就是干了（目标含水量10%以下）。扔掉变色的、皱缩的和有孔的，收获的花生不要装袋堆放，要立即摊开晾干 |

| 留种 | 标准 |
|:---|:---|
| 选择 | 选没有病症、荚多、成熟比例高的植株，比食用稍晚、完全成熟后再挖，在阴凉处慢慢晾干 |
| 保存 | 一定要带壳，装进洋葱网袋或通风的袋子，挂在10-15℃的凉爽处（到次年春天为限）。种前再剥壳，用湿布包20粒做发芽试验（70%以上为正常，一半就加大播种量，30%以下不能当种子用） |

> **花生种子撑不过一年。因为脂肪氧化变质，胚就会死亡，所以必须每年留种，哪怕有一年间断，种子就断了。这是花生最大的结构性弱点。**

## 9. 储存
| 方式 | 方法 | 期限 |
|:---|:---|:---|
| 带壳通风保存 | 装进洋葱网袋或袋子，挂在凉爽通风处（留种一定用这种方式） | 6个月-1年 |
| 带壳密封保存 | 完全晒干后装进陶罐或金属罐封好（食用） | 1年左右 |
| 去壳密封、炒后密封 | 装进密封容器，放在凉爽阴暗处（容易氧化变质，炒过的更快） | 1-2个月 |

> **花生储存时，食用和留种的原则正好相反。食用的要完全晒干后密封，留种的要完全晒干后通风。种子如果密封，剩余的湿气被关在里面，会发霉，呼吸受阻，发芽力下降。**

&nbsp;&nbsp;&nbsp;储存场所要在10-15℃（不超过20℃）、湿度低、避光的地方，每月凭气味检查一次。有香味是正常的，油哈喇味是氧化变质，虽然无毒但要尽快吃完，有霉味就把全部摊开，一粒一粒检查，挑出变色的，其余的重新完全晒干后再装。豆象不是大问题，但去壳的花生会招来印度谷蛾之类的储存害虫，所以去了壳的要密封。

## 10. 烹调与注意事项
| 项目 | 黄曲霉毒素 |
|:---|:---|
| 本质 | 曲霉等霉菌产生的毒素，在含水分的花生放在温暖处时形成，刚收获后最危险 |
| 症状 | 一次吃大量会呕吐、腹痛、黄疸、肝功能损伤，少量长期食用也会提高肝癌风险 |

> **黄曲霉毒素超过280℃也不会被完全破坏。炒、煮、炸、榨油后都会残留，没有任何办法能使发霉的花生变安全。扔掉是唯一的办法。**

| 迹象 | 判定 |
|:---|:---|
| 外壳上淡青色或发黄的粉末、种皮上的污斑、皱缩发暗的籽粒、壳上的孔 | 立即扔掉 |
| 苦味或酸味 | 马上吐掉，并把这一把全部扔掉 |
| 潮湿的泥土味或霉味 | 检查全部 |

&nbsp;&nbsp;&nbsp;只要有一粒被污染，霉菌孢子就会在容器里扩散，所以要把那个容器里的全部摊在明亮处一粒一粒检查，对按体重摄入量大的孩子尤其要小心。预防是减少蛴螬危害、收获前2周停止灌溉、雨后不立即挖、挑出坏荚，唯一可靠的方法是在最初几天内晒到含水量10%以下、完全干燥。此外，花生过敏严重时会危及生命，所以第一次吃的人要先少量试吃，四岁以下的孩子不要给整粒花生。

| 烹调 | 方法 |
|:---|:---|
| 生吃、炒 | 生吃也安全；在干锅里带壳或只炒仁炒10-15分钟 |
| 鲜花生 | 把未成熟的连荚用盐水煮30-40分钟，收获季直接吃（可存放几天） |
| 粉、酱 | 炒后磨成的粉（密封可保存1个月）拌进谷物粉中可提高热量，在臼中久捣会出油，成为浓稠的糊（密封可保存1-2个月），适合作恢复餐 |
| 榨油 | 彻底挑出发霉的，去壳，在干锅里用小火炒10-15分钟，捣细，稍微蒸一下。用布包好，用杠杆榨油机压榨，静置几天，把沉淀后的上层油在阴暗凉爽处密封（出油率略高于脂肪的一半） |
| 油饼、壳 | 油饼蛋白质超过40%，但原料哪怕有一点可疑，人就不要吃。壳铺在田里或放进堆肥 |

> **花生是豆类中唯一不用火就能吃的。在燃料完全断绝的情况下，这一点的价值超过其他所有等级。**

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查带壳悬挂保存的种子状态，准备发芽试验。2月做田地规划，确认能保证4-5年休耕的地块 |
| 3-4月 | 3月施石灰和堆肥并深翻，捡石头（在播种前2周完成）。4月起垄、覆盖、南部播种（下旬，确认地温15℃） |
| 5-6月 | 5月中部播种（上旬·中旬）、防鸟、确认发芽。6月除草、开花开始、第一次培土 |
| 7-8月 | 7月第二次培土并补钙，监视褐斑病，检查根瘤（此后不进田）。8月荚膨大期，干燥时每隔10天灌溉 |
| 9-10月 | 9月试挖确认成熟程度，中部开始收获（月底）。10月收获、预干、摘荚、正式干燥（雨后不立即挖） |
| 11-12月 | 11月确认完全干燥、挑选、储存、茎叶还田。12月加工（炒、榨油）、检查储存 |

> **花生要靠扔掉变色或发霉的、晒到哗啦作响、开花期培土、补充钙、每年留种并带壳通风悬挂，才算物有所值。**
