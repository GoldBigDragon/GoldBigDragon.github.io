## 8. 栽培管理 - 培土

### 8-1. 培土就是花生的全部

&nbsp;&nbsp;&nbsp;花生栽培中效率最高的作业是培土。在其他作物上，培土是防止倒伏、帮助排水的辅助作业；而在花生上，它是直接决定有无收成的作业。

| 作业 | 时期 | 方法 | 效果 |
|---|---|---|---|
| 第1次培土 | 开始开花时 | 将植株基部周围的土轻轻刨起，培到基部 | 形成可供子房柄（果针）扎入的松软土层 |
| 第2次培土 | 子房柄开始伸长时 | 再多培一些土，并混入钙粉 | 缩短子房柄入土所需伸展的距离，并补充钙 |
| 之后 | 子房柄入土后 | 不要进入田间 | 一踩就会踩断子房柄 |

> **花生是地上开的花受精后，子房柄向下伸入土中，并在土里结果。土壤板结时，花开得再多也结不出荚果。开花期必须把土壤弄松软，原因就在于此。**

&nbsp;&nbsp;&nbsp;培土的要领有三点。第一，目的不是把土堆得厚，而是让土变得松软。用手锄刮松表土、打碎土块，再把土拢向植株基部。第二，如果子房柄已经开始伸长，就要小心。细细的柄一旦折断，那个荚果就没有了。第三，同时混入烧制的贝壳粉或蛋壳粉，钙就正好落在需要的位置。

&nbsp;&nbsp;&nbsp;覆盖栽培会出现另一个问题，因为地膜会挡住子房柄。因此进行覆盖栽培时，要在开始开花时把植株周围的地膜划破或揭掉。忘了这项作业，靠提高地温得到的好处就会全部丢掉。稻草覆盖的话，子房柄可以穿过去，这个问题就轻一些。

### 8-2. 杂草管理

| 时期 | 方法 | 要点 |
|---|---|---|
| 生育初期 | 中耕除草 | 浅锄 |
| 开花前 | 结合培土进行最后一次除草 | 此后不再进入田间 |
| 开花后 | 只拔手够得着的大杂草 | 注意不要用脚踩 |

&nbsp;&nbsp;&nbsp;开花后不进入田间的原则，对花生尤其严格。人走过踩踏时，正向土中伸展的子房柄会被踩断，已经入土的子房柄也会因土壤被踩实而长不出荚果。杂草再碍眼，开花后也最好忍一忍。所以覆盖和开花前彻底除草就显得更加重要。

## 9. 病虫害

&nbsp;&nbsp;&nbsp;花生的病虫害压力为C，防治自立度也是C。在豆类中属于偏低的一档，意思是不用药很难控制。无防治减产率的估计值为55.8%，高于其他豆类的48.9%。这是因为侵害叶片的真菌病害与土壤传播的土传病害会同时发生。

### 9-1. 主要病害

| 病名 | 症状 | 发生时期 | 不用药的应对 |
|---|---|---|---|
| 褐斑病 | 叶片上出现暗褐色斑点，周围有一圈黄色晕带。叶片提前脱落 | 在韩国为7月中旬至收获期 | 保证通风、摘除病叶、波尔多液、轮作。叶片提前脱落会使产量减少一半以上 |
| 黑斑病 | 与褐斑病相似，但斑点发黑 | 秋季 | 与褐斑病同样处理 |
| 网斑病 | 出现黄褐色网状病斑 | 8月下旬至9月 | 保证通风、摘除病叶 |
| 锈病 | 叶片背面出现橙色隆起 | 韩国的梅雨季（6月下旬至7月）湿度大时 | 保证通风 |
| 白绢病 | 茎基部蔓延出白色丝状霉层，植株萎蔫枯死 | 闷热的梅雨季之后 | 连土一起挖出病株烧掉。改善排水、长期轮作 |
| baekseo病 | 根和荚果腐烂。土壤传播 | 生育中后期 | 4-5年轮作是唯一的对策 |
| 病毒病 | 叶片出现花叶状斑驳 | 由蚜虫、蓟马传播 | 无法治疗。拔除烧毁，并减少传毒昆虫 |

> **褐斑病给花生造成的损失最大。叶片提前脱落，花生就无法充实，产量会减少一半到60%。这是因为培育地下荚果的是地上的叶片。**

&nbsp;&nbsp;&nbsp;不用药应对褐斑病的步骤如下。第一，株行距留得宽裕些，保证通风。叶面潮湿的时间缩短，孢子就难以定着。第二，在韩国从7月中旬起巡查田块，把看得到斑点的下部叶片摘下来，带出田外。第三，如果能配制波尔多液，从7月中旬起每隔10-15天喷一次。第四，不把病残体翻回田里，而是烧掉。第五，选育并继续留用具有抗性的品系。据称Namgwang花生品系对褐斑病相对较抗。

&nbsp;&nbsp;&nbsp;白绢病和baekseo病的性质不同。它们留在土壤里能存活多年，药剂也不太管用。4-5年轮作是唯一的根本对策，出现病情的植株必须连周围的土一起挖出烧掉。花生的连作适应性为C，就是因为这两种病。

### 9-2. 主要害虫

| 害虫 | 危害 | 不用药的防治 |
|---|---|---|
| 蛴螬类 | 在土中啃食根和荚果。花生最大的害虫 | 翻地时见到就捉。不施未腐熟的堆肥。轮作 |
| 蚜虫 | 吸食汁液并传播病毒 | 肥皂水（1L水加5g肥皂）、保护瓢虫 |
| 蓟马 | 吸食汁液并传播病毒 | 在白纸上抖花，确认发生情况 |
| 叶螨 | 在叶背吸食汁液，使叶片出现黄色斑驳 | 梅雨季过后天气干燥时增多。用水猛喷叶片 |
| 田鼠·鼹鼠 | 啃食土中的荚果 | 清理田边，堵住通道 |
| 鸟类 | 刨食播种后覆土较浅的种子 | 出苗前用稻草或网覆盖 |

&nbsp;&nbsp;&nbsp;蛴螬之所以对花生格外成问题，是因为收获物就在土中。在其他作物上，顶多是啃掉一点根，而在花生上，它吃的是收获物本身。挖出来一看，荚壳上有洞，里面是空的。更糟的是，这些伤口会成为霉菌的入口，成为黄曲霉毒素的起点。施用未腐熟的堆肥会招来蛴螬，所以一定要用腐熟堆肥，翻地时见到蛴螬就捉掉。

### 9-3. 不用药的防治材料

| 材料 | 配制方法 | 对象 | 注意 |
|---|---|---|---|
| 波尔多液 | 用100L水分别溶解400g硫酸铜和400g生石灰，再混合 | 褐斑病、黑斑病、锈病 | 必须有铜才能配制。用于预防 |
| 肥皂水 | 1L水加5g无香肥皂 | 蚜虫、叶螨、蓟马 | 中午高温时喷洒会灼伤叶片 |
| 撒干草木灰 | 在有露水的早晨，把细草木灰撒在叶片上 | 抑制霉菌、防治食叶害虫 | 兼可补充钾 |
| 草木灰水 | 将1升（约1.8升）草木灰在10L水中浸泡一夜，取上清液使用 | 抑制霉菌 | 呈碱性，需稀释后使用 |
| 木醋液 | 将烧炭时产生的液体稀释300-500倍 | 驱避、促进生长 | 原液呈强酸性，必须稀释 |
| 稀释牛奶 | 将牛奶用水稀释5-10倍 | 白粉病、叶螨 | 剩下的会变质发臭 |

### 9-4. 农业防治

| 方法 | 原理 |
|---|---|
| 4-5年轮作 | 等待白绢病和baekseo病的病原菌在土壤中减少。最为重要 |
| 前后茬不种豆科和烟草 | 会养出相同的土壤病原菌 |
| 排水与起垄 | 白绢病在闷热的梅雨季之后发生 |
| 保证株行距 | 通风良好，褐斑病蔓延就晚 |
| 只用腐熟堆肥 | 未腐熟的堆肥会招来蛴螬 |
| 清除病叶和病株 | 一发现就带出田外烧掉 |
| 筛选种子 | 有霉味的种子不种 |
| 选育抗性品系 | 在病害流行的田里，留用保持健康的植株 |

## 10. 营养缺乏与过量

| 症状 | 原因 | 天然材料的处理 |
|---|---|---|
| 荚果已形成但里面是空的 | 缺钙。花生上最具特征的症状 | 把烧制的贝壳粉和蛋壳粉撒在植株基部并培土 |
| 籽粒小而皱缩 | 缺钾或缺钙 | 草木灰与烧制的壳粉一起使用 |
| 整株叶片呈淡黄色，植株矮小 | 缺氮。可能是根瘤发育不良所致 | 先挖出根来检查根瘤 |
| 生长迟缓，叶片带紫色 | 缺磷 | 骨粉、烧制的鱼骨粉 |
| 叶缘变褐枯干 | 缺钾 | 在植株之间撒草木灰 |
| 荚果内侧出现黑心 | 缺硼 | 掺入多种材料的堆肥 |
| 叶脉之间发黄 | 缺铁或缺锰。在偏碱性的土壤中常见 | 停止施用石灰和草木灰。用腐叶土增加有机质 |
| 茎叶茂盛但荚果少 | 氮过量 | 立即停止供氮 |

> **空荚果是花生上最常见、也最令人惋惜的失败。田里长得好，荚果也结得多，挖出来剥开一看却是空的。原因几乎总是钙，对策是在开花期往土里施钙。**

&nbsp;&nbsp;&nbsp;这种症状与其他作物缺素的不同之处在于吸收途径。花生的荚果不是利用根送来的钙，而是用自己的壳直接从周围土壤中吸收。因此即使根系周围的深层有钙也没有用，荚果发育的土壤表面以下几cm的土层中必须有钙。这就是开花期培土时混入钙粉最有效的原因。

&nbsp;&nbsp;&nbsp;石灰施用过量会引起相反的问题。pH超过7.5时，铁、锰、锌的吸收受阻，会出现叶脉之间发黄的症状。作为基肥，每1,000㎡以150-200kg为上限，超过部分只在开花期局部施用。

## 11. 间作与轮作

### 11-1. 搭配宜忌

| 搭配 | 作物 | 理由 |
|---|---|---|
| 适宜 | 玉米·粟（谷子）·高粱 | 不共有病害，且可利用花生留下的氮 |
| 适宜 | 芝麻 | 作为前后茬很合适 |
| 适宜 | 辣椒·西瓜 | 适合作为轮作对象 |
| 不宜 | 烟草 | 会养出相同的土壤病原菌 |
| 不宜 | 其他豆科 | 病原菌和线虫会不断积累 |
| 不宜 | 花生连作 | 白绢病和baekseo病会使产量大幅下降 |

&nbsp;&nbsp;&nbsp;相比间作，花生更适合纳入轮作体系。它生育期长，开花期以后又不能进入田间，所以很难与其他作物共用一块地。非要混种的话，在田边种上玉米挡风，这种程度比较现实。

&nbsp;&nbsp;&nbsp;这里再强调一下前后茬不种烟草的原则。烟草和花生共有一部分土传病害，在种过烟草的田里种花生，白绢病的发生会增多。豆科作物同样要避开。

### 11-2. 轮作

| 项目 | 标准 |
|---|---|
| 休作期 | 4-5年 |
| 理想周期 | 5年 |
| 连作障碍 | 白绢病和baekseo病残留在土壤中，产量大幅下降 |

| 5年轮作示例 |
|---|
| 第1年：花生 |
| 第2年：玉米或粟（谷子） |
| 第3年：芝麻或辣椒 |
| 第4年：西瓜或根菜类 |
| 第5年：谷物或叶菜类 |
| 再回到花生 |

&nbsp;&nbsp;&nbsp;花生的连作适应性C，是豆类中仅次于豌豆的较重制约。要遵守4-5年的休作，就得把田分成五个地块，在田地狭小的条件下并不容易。折中的办法有两种：一是每年轮换使用田角那块掺沙的地；二是不每年种花生，而是隔年或每三年种一次。种子寿命不足1年，隔年种植会使种子中断，所以这种情况下，即使量少，也要每年另外种几株作留种用。

> **花生种子寿命短，必须年年播种；连作障碍严重，又不能种在同一块地上。同时受这两项制约的作物只有花生，因此必须提前规划好田块布局。**

## 12. 收获与干燥

### 12-1. 判断收获时期

| 判断依据 | 内容 |
|---|---|
| 叶片 | 从下部叶片开始变黄枯萎 |
| 荚果 | 试挖的荚果中，60-80%的网纹清晰 |
| 壳内侧 | 剥开荚果时，内壁已变为褐色或黑色 |
| 籽粒 | 种皮已呈现品种固有的鲜明颜色 |
| 播种后天数 | 130-150天 |
| 时期 | 韩国中部9月末-10月初，韩国南部10月初至11月期间 |

> **花生长在土里，从外表看不出成熟程度。收获前一定要试挖两三株，剥开荚果查看内壁颜色。这一次确认就是判断收获时期的全部。**

&nbsp;&nbsp;&nbsp;荚果内壁的颜色是最可靠的指标。未成熟的荚果内侧白而光滑，成熟的荚果内侧呈褐色或黑色斑驳。这种颜色变化不会逆转，所以很少会看错。把从多株上挖出的荚果剥开，如果60-80%已经成熟，就是收获的适期。

&nbsp;&nbsp;&nbsp;判断收获时期之所以棘手，是因为开花要持续将近100天。晚开的花结出的荚果还没成熟，早开的花结出的荚果则子房柄已经腐朽，快要掉落到土里了。挖得太早，未成熟的多；挖得太晚，成熟良好的荚果掉进土里，就这样损失了。60-80%这个标准就是二者之间的折中点。

&nbsp;&nbsp;&nbsp;霜冻也要考虑进去。花生遇霜叶片会死，叶片一死，荚果就不再成熟。如果有霜冻预报，即使还没成熟也最好先挖。未成熟的花生用来煮食或尽早吃掉，只挑成熟良好的贮藏。

### 12-2. 收获要领

| 顺序 | 内容 |
|---|---|
| 1 | 选晴朗干燥的日子。刚下过雨时，要等土干了再挖 |
| 2 | 用手锄或铁锹在植株旁挖开，把土掀起后，抓住茎拔出 |
| 3 | 抖掉泥土，但不要用力摇晃，否则荚果会掉落 |
| 4 | 把拔出的植株翻转，使荚果朝上，在田里摊晒几天进行预干燥 |
| 5 | 变色或受损的荚果，在这一步挑出 |
| 6 | 倒挂或摊放在屋檐下或棚屋里，进行正式干燥 |
| 7 | 摘掉荚果后的茎、叶和根，还回田里 |

> **刚下过雨不能挖花生。湿土会粘在壳上，就这样堆着，一两天就会开始发霉。黄曲霉毒素的起点大多就在这里。**

&nbsp;&nbsp;&nbsp;直立型品种一拔，大部分荚果会跟着带出来。匍匐型品种或土壤板结的田里，子房柄会折断，荚果留在土里，所以要在拔出的地方用手或手锄再摸一遍，找出剩下的荚果。这项作业会让收获量明显不同。

&nbsp;&nbsp;&nbsp;在田里摊晒几天的预干燥很重要。把拔出的植株翻转，使荚果朝上，表面的泥土和水分在阳光和风的作用下很快就干了。不过一有下雨的消息就得马上收回，夜露重的时期，只在白天晾晒、傍晚收回比较稳妥。

### 12-3. 干燥 - 防止黄曲霉毒素的唯一方法

| 阶段 | 方法 | 确认 |
|---|---|---|
| 预干燥 | 连植株一起放在田里或阴凉处3-7天 | 表面的泥土和水分变干 |
| 荚果分离 | 用手摘下或抖落 | 此时挑出受损的 |
| 正式干燥 | 薄薄地摊在竹筛或席子上，放在通风良好的阴凉处晾干 | 强光会使壳开裂 |
| 干燥判定 | 摇动荚果时，里面的籽粒哗啦作响 | 最可靠的判定方法 |
| 目标含水量 | 10%以下 | 高于此值，霉菌就会滋生 |
| 挑选 | 剔除变色的、皱缩的、有孔洞的 | 一粒就会污染全部 |

&nbsp;&nbsp;&nbsp;摇一摇听哗啦声来判断，是不借助工具时最可靠的方法。没干透的荚果，里面的籽粒贴在壳上，不会出声；干透后籽粒收缩，在壳里能够活动。多摇几个，大部分都出声，就说明干燥结束了。

&nbsp;&nbsp;&nbsp;不在强光下久晒也是要领。长时间直射阳光会使壳开裂，脂肪开始酸败，种皮颜色也会褪去。开裂的壳会成为霉菌的入口。最好在通风良好的阴凉处或屋檐下慢慢晾干，这样花费的时间更长，所以必须早点开始。
