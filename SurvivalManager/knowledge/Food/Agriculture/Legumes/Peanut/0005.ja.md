## 8. 栽培管理 - 土寄せ

### 8-1. 土寄せがラッカセイのすべてです

&nbsp;&nbsp;&nbsp;ラッカセイ栽培で最も効率の高い作業は土寄せです。他の作物では、土寄せは倒伏を防いで排水を助ける補助的な作業ですが、ラッカセイでは収穫できるかどうかそのものを決める作業です。

| 作業 | 時期 | 方法 | 効果 |
|---|---|---|---|
| 1回目の土寄せ | 開花が始まるころ | 株元の周りの土を柔らかく掻き上げます | 子房柄が入り込む柔らかい土の層をつくります |
| 2回目の土寄せ | 子房柄が伸び始めるとき | 土をさらに寄せ集め、カルシウムの粉を一緒に混ぜます | 子房柄が届くまでの距離を縮め、カルシウムを供給します |
| その後 | 子房柄が土に入ったあと | 畑に入りません | 踏むと子房柄が切れます |

> **ラッカセイは、地上で咲いた花が受精したあと、子房柄が地中へ伸びて入り込み、実を結びます。土が固まっていると、花がいくら多く咲いても莢ができません。開花期に土を柔らかくしてやることが欠かせない理由は、ここにあります。**

&nbsp;&nbsp;&nbsp;土寄せのコツは三つあります。第一に、土を厚く積むのではなく、柔らかくすることが目的です。手鍬で表面を掻いて土塊を砕き、株元に寄せ集めます。第二に、子房柄がすでに伸び始めている場合は注意します。細い柄を切ってしまうと、その莢は失われます。第三に、焼いた貝殻や卵殻の粉を一緒に混ぜておくと、カルシウムがちょうど必要な場所に置かれます。

&nbsp;&nbsp;&nbsp;マルチ栽培では別の問題が生じます。ビニールが子房柄をふさいでしまうからです。そのため、マルチをした場合は、開花が始まるころに株の周りのビニールを破るか、取り除く必要があります。この作業を忘れると、地温を上げて得た利点がそっくり失われます。わらマルチは子房柄が突き抜けられるため、この問題は小さくて済みます。

### 8-2. 雑草管理

| 時期 | 方法 | ポイント |
|---|---|---|
| 生育初期 | 草取り | 浅く掻きます |
| 開花前 | 土寄せを兼ねた最後の草取り | 以後は畑に入りません |
| 開花後 | 手の届く大きな雑草だけを抜きます | 足で踏まないよう注意します |

&nbsp;&nbsp;&nbsp;開花後は畑に入らないという原則は、ラッカセイでは特に厳格です。人が通りがかりに踏むと、土の中へ伸びていた子房柄が切れますし、すでに入り込んだ子房柄も、土が踏み固められることで莢が育たなくなります。雑草が目障りでも、開花後は我慢するほうがよいでしょう。だからこそ、マルチや開花前の徹底した除草がいっそう重要になります。

## 9. 病害虫

&nbsp;&nbsp;&nbsp;ラッカセイの病害虫圧はCで、防除自立度もCです。豆類の中では低い部類で、薬剤に頼らずに抑えるのは容易ではないという意味です。無防除時の減収率の推定値は55.8%で、他の豆類の48.9%より高くなっています。葉を侵すカビ病と、土の中の土壌伝染病が同時に発生するためです。

### 9-1. 主な病害

| 病名 | 症状 | 発生時期 | 薬剤に頼らない対応 |
|---|---|---|---|
| 褐斑病 | 葉に暗褐色の斑点ができ、そのまわりを黄色い輪が取り巻きます。葉が早く落ちます | 韓国では7月中旬から収穫期 | 風通しの確保、病葉の除去、ボルドー液、輪作。葉が早く落ちると収量が半分以上減ります |
| 黒渋病 | 褐斑病に似ていますが、斑点が黒っぽいです | 秋 | 褐斑病と同じように対応します |
| 網斑病 | 黄褐色の網目状の病斑ができます | 8月下旬から9月 | 風通しの確保、病葉の除去 |
| さび病 | 葉の裏にオレンジ色の隆起ができます | 韓国の梅雨（チャンマ、6月下旬～7月）の多湿期 | 風通しの確保 |
| 白絹病 | 茎の株元に白い糸のようなカビが広がり、株がしおれて枯れます | 蒸し暑い梅雨のあと | 病んだ株を土ごと掘り上げて焼却します。排水の改善、長期の輪作 |
| ペクソ病 | 根と莢が腐ります。土壌伝染 | 生育中～後期 | 4-5年の輪作が唯一の対策です |
| ウイルス病 | 葉がモザイク状にまだらになります | アブラムシ・アザミウマが媒介 | 治療はできません。抜き取って焼却し、媒介虫を減らします |

> **褐斑病がラッカセイで最も大きな損失をもたらします。葉が早く落ちるとラッカセイが充実できず、収量が半分から60%まで減ります。地中の莢を育てるのは、地上の葉だからです。**

&nbsp;&nbsp;&nbsp;薬剤に頼らずに褐斑病に対応する手順は次のとおりです。第一に、栽植距離を十分にとって風通しを確保します。葉が濡れている時間が短くなれば、胞子が定着できません。第二に、韓国では7月中旬から畑を見回り、斑点が見える下葉を摘み取って畑の外へ出します。第三に、ボルドー液をつくれるなら、7月中旬から10-15日おきに散布します。第四に、病気にかかった残渣を畑に戻さず、焼却します。第五に、抵抗性のある系統を選抜して代々受け継いでいきます。ナムグァンラッカセイの系統は褐斑病に比較的強いことが知られています。

&nbsp;&nbsp;&nbsp;白絹病とペクソ病は性格が異なります。土の中に残って何年も生き延び、薬剤もよく効きません。4-5年の輪作が唯一の根本対策で、病気が出た株は周りの土ごと掘り上げて焼却しなければなりません。ラッカセイの連作適応性がCなのは、この二つの病気のためです。

### 9-2. 主な害虫

| 害虫 | 被害 | 薬剤に頼らない防除 |
|---|---|---|
| 地虫類（コガネムシ類の幼虫） | 土の中で根と莢をかじります。ラッカセイ最大の害虫 | 耕うんのとき、目につくたびに捕殺します。未熟な堆肥を入れません。輪作 |
| アブラムシ | 汁を吸い、ウイルスを運びます | 石けん水（水1Lに石けん5g）、テントウムシの保護 |
| アザミウマ | 汁を吸い、ウイルスを運びます | 白い紙の上で花をたたき、発生を確認します |
| ハダニ | 葉の裏で汁を吸い、葉が黄色くまだらになります | 梅雨のあと乾燥すると増えます。水を葉に強く吹きかけます |
| ノネズミ・モグラ | 土の中の莢を食べます | 畑の周りを整理し、通り道をふさぎます |
| 鳥 | 播種直後の浅く埋めた種子を掘り出して食べます | 発芽までわらやネットで覆います |

&nbsp;&nbsp;&nbsp;地虫がラッカセイで特に問題になる理由は、収穫物が土の中にあるからです。他の作物では根を少しかじる程度で済みますが、ラッカセイでは収穫物そのものを食べてしまいます。掘ってみると、殻に穴があいていて中が空っぽです。さらに悪いのは、その傷がカビの入り口になり、アフラトキシンの出発点になるという点です。未熟な堆肥を入れると地虫が集まるため、必ず完熟堆肥を使い、畑を耕すときに目につく地虫は捕まえて取り除きます。

### 9-3. 薬剤に頼らない防除資材

| 資材 | つくり方 | 対象 | 注意 |
|---|---|---|---|
| ボルドー液 | 水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜます | 褐斑病、黒渋病、さび病 | 銅がなければつくれません。予防用です |
| 石けん水 | 水1Lに無香料の石けん5g | アブラムシ、ハダニ、アザミウマ | 日中の暑いときに散布すると葉が焼けます |
| 乾いた草木灰の散布 | 露のある朝に、葉に細かい草木灰をふりかけます | カビの抑制、葉を食べる虫 | カリウムの供給も兼ねます |
| 草木灰水 | 草木灰1升を水10Lに一晩浸し、上澄みを使います | カビの抑制 | アルカリ性なので薄めて使います |
| 木酢液 | 炭を焼くときに出る液を300-500倍に希釈します | 忌避、生育促進 | 原液は強酸性のため、必ず希釈します |
| 牛乳の希釈液 | 牛乳を水で5-10倍に希釈します | うどんこ病、ハダニ | 余ると傷んでにおいが出ます |

### 9-4. 耕種的防除

| 方法 | 原理 |
|---|---|
| 4-5年の輪作 | 白絹病とペクソ病の病原菌が土の中で減るのを待ちます。最も重要です |
| マメ科とタバコを前後作にしない | 同じ土壌病原菌を育てます |
| 排水と畝 | 白絹病は蒸し暑い梅雨のあとに発生します |
| 栽植距離の確保 | 風通しがよければ褐斑病の広がりが遅くなります |
| 完熟堆肥だけを使用 | 未熟な堆肥は地虫を呼び寄せます |
| 病葉と病株の除去 | 見つけしだい畑の外へ出して焼却します |
| 種子の選別 | カビくさい種子は播きません |
| 抵抗性系統の選抜 | 病気が広がる畑できれいに残った株を受け継ぎます |

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然素材での対処 |
|---|---|---|
| 莢はできたが中が空っぽ | カルシウム欠乏。ラッカセイで最も特徴的な症状です | 焼いた貝殻と卵殻の粉を株元にまき、土寄せします |
| 粒が小さく、しわが寄る | カリウムまたはカルシウムの不足 | 草木灰と焼いた殻の粉を併せて使います |
| 葉全体が淡い黄色で、株が小さい | 窒素欠乏。根粒の着生不良が原因のことがあります | まず根を掘り上げて根粒を確認します |
| 生育が遅く、葉が紫色を帯びる | リン酸欠乏 | 骨粉、魚の骨を焼いた粉 |
| 葉の縁が褐色に枯れる | カリウム欠乏 | 草木灰を株の間にまきます |
| 莢の内側に黒い芯ができる | ホウ素欠乏 | さまざまな材料を混ぜた堆肥 |
| 葉脈の間が黄色い | 鉄またはマンガンの欠乏。アルカリに傾いた土でよく見られます | 石灰と草木灰を入れるのをやめます。腐葉土で有機物を増やします |
| 茎葉ばかり茂って莢が少ない | 窒素過剰 | 窒素の供給をただちに中止します |

> **空の莢は、ラッカセイで最もよくあり、最も惜しい失敗です。畑でよく育ち、莢もたくさんついたのに、掘って殻をむいてみると中が空っぽです。原因はほとんどの場合カルシウムで、対策は開花期に土へカルシウムを入れることです。**

&nbsp;&nbsp;&nbsp;この症状が他の作物の欠乏と異なる点は、吸収経路にあります。ラッカセイの莢は、根が送ってくれたカルシウムを使うのではなく、自分の殻で周囲の土から直接吸い込みます。そのため、根の周りの深いところにカルシウムがあっても役に立たず、莢が育つ土の表面から数cm下の層にカルシウムがなければなりません。開花期の土寄せにカルシウムの粉を一緒に混ぜるのが最も効果的である理由です。

&nbsp;&nbsp;&nbsp;石灰を入れすぎると、逆の問題が生じます。pHが7.5を超えると、鉄とマンガンと亜鉛の吸収が妨げられ、葉脈の間が黄色くなる症状が現れます。元肥としては1,000㎡当たり150-200kgを上限とし、それ以上は開花期に局所的にだけ使います。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 作物 | 理由 |
|---|---|---|
| 良い | トウモロコシ・アワ・モロコシ | 病害を共有せず、ラッカセイが残した窒素を使います |
| 良い | ゴマ | 前作・後作としてよく合います |
| 良い | トウガラシ・スイカ | 輪作の相手として適しています |
| 悪い | タバコ | 同じ土壌病原菌を育てます |
| 悪い | 他のマメ科 | 病原菌とセンチュウが蓄積します |
| 悪い | ラッカセイの連作 | 白絹病とペクソ病で収量が大きく落ちます |

&nbsp;&nbsp;&nbsp;ラッカセイは、間作よりも輪作で居場所を得る作物です。生育期間が長く、開花期以降は畑に入れないため、他の作物と一つの畑を分け合って使うのは困難です。あえて混植するなら、トウモロコシを畑の縁に立てて風を防ぐ程度が現実的です。

&nbsp;&nbsp;&nbsp;タバコを前後作にしないという原則を押さえておきます。タバコとラッカセイは土壌伝染病の一部を共有しており、タバコを植えていた畑にラッカセイを植えると、白絹病の発生が増えます。マメ科作物も同様に避けます。

### 11-2. 輪作

| 項目 | 基準 |
|---|---|
| 休作期間 | 4-5年 |
| 理想的な周期 | 5年 |
| 連作障害 | 白絹病とペクソ病が土に残り、収量が大きく落ちます |

| 5年輪作の例 |
|---|
| 1年目：ラッカセイ |
| 2年目：トウモロコシまたはアワ |
| 3年目：ゴマまたはトウガラシ |
| 4年目：スイカまたは根菜 |
| 5年目：穀物または葉菜 |
| 再びラッカセイ |

&nbsp;&nbsp;&nbsp;ラッカセイの連作適応性Cは、豆類の中ではエンドウに次いで重い制約です。4-5年の休作を守るには、畑を五つの区画に分けなければならず、畑が狭い条件では容易ではありません。妥協策としては、畑の片隅の砂混じりの場所を毎年移しながら使う方法や、ラッカセイを毎年は植えず、隔年か3年に1回だけ植える方法があります。種子寿命が1年未満のため、隔年で植えると種子が途絶えます。その場合は、少量でも毎年、種子用に数株を別に植えておかなければなりません。

> **ラッカセイは種子寿命が短いため毎年植えなければならず、連作障害が深刻なため同じ場所には植えられません。この二つの制約が同時にかかる作物はラッカセイだけで、だからこそ畑の配置をあらかじめ計画しておく必要があります。**

## 12. 収穫と乾燥

### 12-1. 収穫時期の判断

| 判断基準 | 内容 |
|---|---|
| 葉 | 下葉から黄色くなり、枯れていきます |
| 莢 | 試し掘りした莢の60-80%で網目模様がはっきりしています |
| 殻の内側 | 莢を割ったとき、内壁が褐色か黒色に変わっています |
| 粒 | 薄皮の色が品種固有の色にはっきりなっています |
| 播種後の経過日数 | 130-150日 |
| 時期 | 韓国中部は9月末-10月初め、韓国南部は10月初め-11月中 |

> **ラッカセイは土の中にあるため、外見から熟し具合を知ることができません。収穫前に必ず2、3株を試し掘りし、莢を割って内壁の色を確認します。この一度の確認が、収穫時期の判断のすべてです。**

&nbsp;&nbsp;&nbsp;莢の内壁の色が最も信頼できる指標です。未熟な莢は内側が白くつるりとしており、熟した莢は内側が褐色や黒色にまだらになっています。この色の変化は元に戻らないため、見誤る余地が少ないです。複数の株から掘った莢を割ってみて、60-80%が熟していれば収穫適期です。

&nbsp;&nbsp;&nbsp;収穫時期の判断が難しいのは、開花が100日近く続くからです。遅く咲いた花からできた莢はまだ未熟で、早く咲いた花からできた莢はすでに子房柄が朽ちて土に落ちる準備をしています。早く掘りすぎると未熟なものが多く、遅く掘りすぎると、よく熟したものが土に落ちてそのまま失われます。60-80%という基準は、その折衷点です。

&nbsp;&nbsp;&nbsp;霜も判断に関わってきます。ラッカセイは霜で葉が枯れ、葉が枯れると莢はそれ以上熟しません。霜の予報があれば、未熟でも掘り上げたほうがよいです。未熟なラッカセイは茹でて食べるか早めに消費し、よく熟したものだけを選んで貯蔵します。

### 12-2. 収穫のコツ

| 順序 | 内容 |
|---|---|
| 1 | 晴れて乾燥した日を選びます。雨の直後は、土が乾くまで待ちます |
| 2 | 手鍬やスコップで株の脇を掘って土を持ち上げ、茎を持って引き抜きます |
| 3 | 土を払い落としますが、強く振らないようにします。莢が落ちます |
| 4 | 抜いた株を莢が上になるようひっくり返し、畑に数日並べて予備乾燥します |
| 5 | 色が変わった莢や傷んだ莢は、この段階で選び出します |
| 6 | 軒下や納屋に逆さに吊るすか並べて、本乾燥します |
| 7 | 莢を取り外したあとの茎と葉と根は、畑に戻します |

> **雨の直後にラッカセイを掘ってはいけません。濡れた土が殻に付着し、その状態で積んでおくと、1、2日でカビが始まります。アフラトキシンの出発点は、たいていここです。**

&nbsp;&nbsp;&nbsp;直立型の品種は、抜くと莢の大部分が一緒についてきます。匍匐型の品種や土が固い畑では、子房柄が切れて莢が土に残るため、抜いた跡を手や手鍬でもう一度さらって、残った莢を探します。この作業で収穫量が目に見えて変わります。

&nbsp;&nbsp;&nbsp;畑で数日並べて干す予備乾燥が重要です。抜いた株を莢が上になるようひっくり返しておくと、日差しと風で表面の土と水分が早く乾きます。ただし、雨の知らせがあればすぐに取り込まなければならず、夜露がひどい時期なら、昼だけ並べて夕方に取り込むほうが安全です。

### 12-3. 乾燥 - アフラトキシンを防ぐ唯一の方法

| 段階 | 方法 | 確認 |
|---|---|---|
| 予備乾燥 | 抜いた株のまま畑や日陰で3-7日 | 表面の土と水分が乾きます |
| 莢の分離 | 手でもぎ取るか、払い落とします | このとき傷んだものを選び出します |
| 本乾燥 | 竹ざるやむしろに薄く広げ、風通しのよい日陰で乾かします | 強い日差しは殻を割れさせます |
| 乾燥の判定 | 莢を振ったとき、中で粒がカラカラ鳴ります | 最も確実な判定法です |
| 目標水分 | 10%以下 | これより高いとカビが生えます |
| 選別 | 色が変わったもの、しわの寄ったもの、穴のあいたものを捨てます | 1粒が全体を汚染します |

&nbsp;&nbsp;&nbsp;振ってカラカラという音で判定する方法が、道具なしでは最も確実です。乾ききっていない莢は、中の粒が殻に付いているので音がせず、すっかり乾くと粒が縮んで殻の中で動きます。いくつも振ってみて、大部分が音を立てれば、乾燥は終わりです。

&nbsp;&nbsp;&nbsp;強い日差しで長く干さないことも、コツです。直射日光に長く当てると殻が割れ、脂肪が酸敗し始め、薄皮の色があせます。割れた殻はカビの入り口になります。風通しのよい日陰や軒下でゆっくり乾かすほうがよく、その分時間がかかるので、早めに始めなければなりません。
