### 1-3. 如何解读强项

&nbsp;&nbsp;&nbsp;带SS的项目只有设施负担一项，但S出现在蛋白质密度、施肥需求、烹饪·加工、耐储性、口味、韩国国内栽培普及度、自家留种这七项上。A出现在微量营养素、耗水量、无合成投入产量保持率、产量稳定性上。

&nbsp;&nbsp;&nbsp;烹饪·加工的S在豆类中是唯一的。其他豆类不是C就是D，只有花生是S。依据很简单：可以生吃，炒的话10分钟就够了。既不需要浸泡，也不需要加热一小时以上。在燃料完全中断的情况下，能够直接食用的豆类只有花生。灾害初期，在无法生火的那几天里，一把花生比任何其他豆类都珍贵。

&nbsp;&nbsp;&nbsp;单位面积热量的C，单看等级与其他豆类相近，但数值并不相同。每1㎡达1,300kcal，是自给线的0.50倍，在豆类中最高。与大豆的0.38倍、绿豆的0.16倍相比，差距十分明显。整地·挖掘能耗的热量回收倍数8.7倍同样是豆类中最高，这意味着相对于耕地的劳动，它回报的热量最多。

> **花生是豆类中唯一靠热量取胜的豆。如果说其他豆类是提供蛋白质的配菜，那么花生就是提供脂肪和热量的粮食。无需燃料也能食用，进一步提升了它的价值。**

&nbsp;&nbsp;&nbsp;韩国国内栽培普及度的S在实际操作中同样重要。花生在韩国全国都有种植，韩国国立粮食科学院也培育出多个品种，种子容易获得。与鹰嘴豆或小扁豆不同，种子的获取不会构成限制。

&nbsp;&nbsp;&nbsp;耗水量的A与无合成投入产量保持率的A也要一并来看。总蒸散量为450mm，比大豆少，即使没有化学投入，也能保持常规栽培一半以上的产量。能在沙质土中生长也是一个优点。其他作物难以生长的含沙田地，反而适合花生。

### 1-4. 如何解读弱项

&nbsp;&nbsp;&nbsp;带E的项目只有耐寒性一项，D则出现在持续性、光照（遮光时相对产量）、非食用价值以及种子寿命上。C出现在单位面积热量、收获速度、温度适应幅度、病虫害压力、防治自立度、连作适应性、整地·挖掘能耗上。

&nbsp;&nbsp;&nbsp;种子寿命的D是这张表中最显眼的弱点。常温下不足1年。与其他豆类可保存3-4年相比，短得多。原因在于脂肪。占45%至50%的脂肪发生酸败，会损伤胚，使发芽力迅速下降。实际意义很明确：花生必须每年留种，不能囤积种子。这意味着一旦某一年种植失败，第二年就可能没有种子可播，这正是花生难以成为规划核心的最大原因。

&nbsp;&nbsp;&nbsp;连作适应性的C和防治自立度的C同样分量不轻。白绢病和枯萎病等土传病害会残留在土壤中，需要休作4-5年。这在豆类中仅次于豌豆，是第二长的期间，在田地狭小的条件下是相当大的限制。此外，褐斑病和黑斑病会使叶片提早脱落，可使产量减少一半以上，不用药很难控制。

&nbsp;&nbsp;&nbsp;收获速度的C与耐寒性的E共同压缩了栽培期。花生需要130-150天，遇霜即死。在韩国中部，5月上旬播种、10月初收获正合适，播种晚了，收获前就会下霜。错过播种适期，这一年就白费了。

&nbsp;&nbsp;&nbsp;此外，还有一项没有被列为等级表项目的风险，那就是黄曲霉毒素。耐储性S的旁边特意注明“为防止黄曲霉毒素，必须彻底干燥”，原因就在于此。干燥不足的花生，问题就不再是储存期限，而是安全。第14节会详细讨论。

## 2. 这是一种什么样的植物 - 子房柄与地下结实

### 2-1. 分类与原产地

&nbsp;&nbsp;&nbsp;花生是豆科（Fabaceae）落花生属（Arachis）的一年生草本植物。虽然同属豆科，它结果的方式却与其他任何豆类都不同。原产地是南美洲安第斯山脉东麓，即今天玻利维亚和阿根廷北部一带。该地区生长着多种野生落花生属植物，其中两个种发生自然杂交，形成了今天的栽培花生。

&nbsp;&nbsp;&nbsp;与花生共生的根瘤菌属于Bradyrhizobium类群，但是专门适应花生的菌系。种过其他豆科作物的田地土壤，往往不太适合作为接种源，种过花生的田地土壤最为可靠。幸运的是，花生在韩国广泛种植，获取接种源并不太困难。

&nbsp;&nbsp;&nbsp;花生是自花受精的。多数情况下，花开放之前花内就已完成受精，因此即使把多个品种并排种植，性状也不会混杂。不过，种子寿命短、必须每年留种这一限制，削弱了自家留种S这一等级的实际价值。

### 2-2. 子房柄 - 花生在地下结果的原理

&nbsp;&nbsp;&nbsp;先弄懂花生最特殊的生理特性，才能理解栽培。过程如下。

| 阶段 | 发生的事情 |
|---|---|
| 1. 开花 | 黄色蝶形花在茎下部的节上开放。早晨开放，当天凋谢 |
| 2. 受精 | 受精在花内完成。花瓣脱落 |
| 3. 子房柄伸长 | 受精后的子房基部开始伸长，呈柄状。这被称为子房柄，也叫果针 |
| 4. 到达地面 | 子房柄顶端向下弯曲生长，触到地面。顶端尖而硬，能刺入土中 |
| 5. 入土 | 子房柄钻入土中3-7cm |
| 6. 荚果形成 | 进入土中之后，顶端才会膨大成为荚果 |
| 7. 膨大与成熟 | 荚果在土中长大，果壳上形成网纹 |

> **花生在地上开花，在地下结果。子房柄如果不能入土，花开得再多，也结不出一粒花生。栽培上几乎所有的要领，都在于帮助实现这一点。**

&nbsp;&nbsp;&nbsp;由这一生理特性可以得出三条实用原则。第一，土壤必须疏松。表面板结或石块多，子房柄就无法钻入。沙质土适合花生是这个原因，开花期要培土也是这个原因。第二，土壤中必须有钙。花生的荚果在土中生长时，直接从土壤中吸收钙，靠的不是根，而是荚果的果壳。缺钙时，荚果即使形成，里面也会空瘪，或者籽粒干瘪。第三，开花位置必须低。茎上部开的花，子房柄还没触到地面就耗尽了力气，白白浪费。

&nbsp;&nbsp;&nbsp;还需要知道，花生的花期持续近100天。在韩国，从6月开始一直到9月都会不断开出新花，而晚开的花结出的荚果直到收获时也无法成熟。因此，从一株上挖出的花生里，成熟的与未成熟的混在一起。这就是判断收获时机比较棘手的原因。

### 2-3. 外形与生育阶段

| 器官 | 特征 |
|---|---|
| 叶 | 羽状复叶，四片小叶成两对着生。夜间叶片合拢 |
| 茎 | 有直立型、半直立型、匍匐型。株高30-50cm |
| 根 | 直立的主根上着生根瘤 |
| 花 | 黄色蝶形。生于茎下部的节上 |
| 子房柄 | 受精后，子房基部像柄一样伸长，伸入地下 |
| 荚果 | 在土中生长。果壳上有网纹，内含2-3粒种子 |

| 阶段 | 时期（韩国） | 关键生理 | 重要养分 |
|---|---|---|---|
| 播种·发芽期 | 4-5月 | 发芽约需10天 | 磷 |
| 营养生长期 | 5-6月 | 茎叶增多，形成根瘤 | 氮由根瘤供给 |
| 开花·结荚期 | 6-9月，持续约100天 | 开花，子房柄入土 | 磷、钙 |
| 荚果膨大·成熟期 | 8-10月 | 荚果在土中长大 | 钾、钙 |

&nbsp;&nbsp;&nbsp;直立型与匍匐型的差别在实际操作中很重要。直立型茎秆挺直，花相对集中在较小的范围内开放，子房柄集中入土于植株基部附近。收获时拔起一株，大部分荚果都会随之带出。匍匐型的茎向侧面蔓延，子房柄入土的范围很广，因此收获时遗漏的较多。在必须靠人手挖掘的条件下，直立型有明显的优势。

&nbsp;&nbsp;&nbsp;花生的营养构成与其他豆类有本质区别。其他豆类的碳水化合物约占60%，脂肪仅1-2%，而花生的碳水化合物为16-20%，脂肪则接近一半。它实际上是一种油料作物。这样的构成使热量提高到近两倍，同时也带来了储存上的困难。脂肪遇到氧气会酸败，酸败的油有异味，营养价值下降，对身体也不好。

&nbsp;&nbsp;&nbsp;氨基酸组成与其他豆类相似。赖氨酸充足，蛋氨酸略显不足。与谷物一起吃，两者可以互补。而且花生脂肪多，与谷物同食时热量会急剧升高，因此用作饥饿者的恢复期食物时尤为合适。实际上，在国际救援现场，以花生为基础的高热量糊状食品被广泛用于治疗严重营养不良。

&nbsp;&nbsp;&nbsp;种皮中所含的白藜芦醇和多酚也值得一记。炒花生的那层薄薄的红色外皮常被剥掉丢弃，但抗氧化成分恰恰集中在这层皮里。它有些涩味，不过从营养角度看，连皮一起吃更好。
