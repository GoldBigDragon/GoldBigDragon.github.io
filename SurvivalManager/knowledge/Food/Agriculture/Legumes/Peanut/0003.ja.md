## 3. 栽培環境

### 3-1. 気温と光量

| 条件 | 限界値 | 最適値 | 外れた場合 |
|---|---|---|---|
| 発芽温度 | 地温15℃以上 | 20-25℃ | 15℃を下回ると発芽せず、種子が腐ります |
| 生育温度 | 18-35℃ | 25-30℃ | 熱帯原産のため暑さに強いです |
| 結実温度 | 20-30℃ | 24-28℃ | 幅は10℃です |
| 積算温度 | 早生2,800℃、晩生3,600℃ | - | 不足すると、登熟が終わる前に霜が降ります |
| 耐寒性 | ありません | - | 霜が一度降りただけで枯れます |
| 日照 | 1日6時間以上 | 1日8時間以上 | 日照が多いほど収量が増えます |

&nbsp;&nbsp;&nbsp;ラッカセイの播種時期を判断するとき、基準になるのは気温ではなく地温です。土の中5cmの深さの温度が15℃を超えている必要があります。種子が大きく脂質が多いため、低い温度のまま長く土の中にあると腐ってしまうからです。地温計がない場合は、朝、土に手を入れて冷たく感じない程度が目安になります。

> **ラッカセイで積算温度が重要な理由は、生育期間が130-150日と長いためです。早生種で2,800℃、晩生種で3,600℃が必要ですが、韓国中部の年間の積算温度には、それほど余裕がありません。遅く播くと必要な温度を満たせず、霜に当たります。**

&nbsp;&nbsp;&nbsp;そのため、ラッカセイの栽培ではマルチングが重要です。ビニールマルチを張ると地温が上がり、播種を2-3週間早められ、その分だけ積算温度を多く確保できます。ビニールがない場合は、黒い布や、黒く朽ちた落ち葉を敷いても一定の効果があり、南向きの斜面や風が当たりにくい場所を選ぶことも助けになります。

### 3-2. 土壌と水

| 条件 | 限界値 | 最適値 | 備考 |
|---|---|---|---|
| 土性 | 砂質土-壌土 | 砂壌土 | 粘質土や石の多い畑は向きません |
| pH | 5.5-7.5 | 6.5-7.0 | 強酸性は不適です |
| カルシウム | 土に十分にあることが必要です | - | さやが土から直接吸収します |
| 有効土層の深さ | 30cm以上 | 40cm以上 | |
| 作期の蒸発散量 | - | 約450mm | 豆類の中では中間です |
| 浸水 | 開花期の湿害に特に弱いです | - | 子房柄が地中に入る時期です |
| 畝の高さ | 20cm以上 | 25cm | 排水と土の柔らかさを同時に得られます |

> **ラッカセイが砂地を好むのは、好みではなく構造上の理由です。子房柄が土を突き破って入らなければならず、土の中でさやが大きくならなければならず、収穫のときには掘り上げなければなりません。この三つはいずれも、さらさらとほぐれる土のほうが容易になります。**

&nbsp;&nbsp;&nbsp;逆に、粘質土や石の多い畑ではラッカセイは失敗します。子房柄が固い土を突き破れず、突き破れたとしてもさやが育つ空間がなくて奇形になり、収穫のときにはさやが株から外れて土に残ります。畑を選ぶときは、手で土を握ってみて、固まらずにぱらぱらと崩れればラッカセイに向いており、固まって塊になるなら、ほかの作物を植えたほうがよいでしょう。粘質土しかない場合は、砂やもみ殻を混ぜて畝を作ってみることもできます。

&nbsp;&nbsp;&nbsp;カルシウムが必要になるのは、ラッカセイ特有の条件です。土の中のさやが殻を通して直接カルシウムを吸い上げ、このカルシウムが不足すると、さやはできても中に子実が詰まりません。一般に「空のさや」と呼ばれる現象です。石灰を元肥として入れることが、ラッカセイでは選択ではない理由がこれです。

## 4. 品種

### 4-1. 草型による分類

| 区分 | 特徴 | 収穫 | 災害時の適合度 |
|---|---|---|---|
| 直立型 | 茎がまっすぐ立ちます。さやが株元に集まります | 引き抜くとほとんどがついてきます | 最も高いです |
| 半直立型 | 中間の形態です | 比較的よくついてきます | 高いです |
| 匍匐型 | 茎が横に伸びます。さやが広く散らばります | 取り残すものが多くなります | 低いです |

&nbsp;&nbsp;&nbsp;韓国国立食糧科学院が1982年以降、さまざまな品種を育成してきており、むき実用と生ラッカセイ用に分かれます。セドゥルとテグァンは完全直立型の早生大粒種として韓国全土で栽培されており、ナムグァンは半直立型の大粒種、サンアンは炒り用、チャソンは生ラッカセイ用として知られています。災害時の条件では、直立型の早生種が合理的です。収穫の労力が少なく、生育期間が短いため霜の危険が減ります。

### 4-2. 状況別の選択基準

| 状況 | 優先順位 | 理由 |
|---|---|---|
| 人手が足りない | 直立型 | 引き抜くとさやがついてきます |
| 韓国中部より北で、霜が早い | 早生の直立型 | 積算温度は2,800度で足ります |
| 油を搾りたい | 大粒種 | 粒が大きいほど圧搾しやすくなります |
| 夏に食べるものが必要 | 生ラッカセイ用 | 完熟前にゆでて食べます |
| 畑が粘質土 | ラッカセイを植えません | 子房柄が入れません |
| ビニールがない | 早生種 | マルチングなしで積算温度を満たす必要があります |

&nbsp;&nbsp;&nbsp;品種選びにおけるラッカセイ特有の制約を、改めて確認しておきます。種子寿命が1年未満のため毎年採種しなければならず、採種した種子は殻付きのまま保管しなければなりません。そのため、どの品種を選ぶにしても、その系統を途切れさせずに受け継いでいくことのほうが、品種選びそのものより重要です。一年でも種子を失えば、最初から入手し直さなければなりません。

## 5. 畑の準備と肥料 - 根粒菌と石灰

### 5-1. 窒素固定はどのように起こるのか

&nbsp;&nbsp;&nbsp;空気の78%は窒素です。人の頭上には無尽蔵の窒素が漂っているのに、植物はそれを使えません。空気中の窒素は、二つの窒素原子が三重結合で強く結びついた分子で、この結合を断ち切るには莫大なエネルギーが必要だからです。工業的にこの結合を断ち切ってアンモニアを作るのがハーバー・ボッシュ法であり、世界の窒素肥料はここから生まれます。高温、高圧、触媒、そして膨大な化石燃料が必要です。

&nbsp;&nbsp;&nbsp;根粒菌は、この仕事を常温・常圧でやってのけます。ニトロゲナーゼという酵素で三重結合を断ち切り、窒素をアンモニアに変えます。ただし代償があります。この反応には多くのエネルギーが必要で、細菌は自分では光合成ができません。そのため、マメ科植物の根に入り込んで暮らしながら、植物が光合成でつくった糖を受け取り、その見返りに固定した窒素を渡します。取引関係です。

&nbsp;&nbsp;&nbsp;ラッカセイと組になる菌は、Bradyrhizobiumの仲間のうち、ラッカセイに特化した系統です。ほかのマメ科を育てた畑の土はあまり効果がない傾向があるため、ラッカセイを育てた畑の土を使うのが確実です。

| 段階 | 起こること |
|---|---|
| 1. シグナルの交換 | ラッカセイの根がフラボノイドを分泌し、土の中の細菌がそのシグナルに応じます |
| 2. 感染 | ラッカセイは、ほかのマメ科と違って、根毛の裂け目から細菌が入り込みます |
| 3. 根粒の形成 | 根の内側の細胞が分裂して丸い根粒が膨らみ、その中に細菌が定着します |
| 4. 窒素固定 | 根粒の中でニトロゲナーゼが働き、空気中の窒素をアンモニアに変えます |
| 5. 分配 | アンモニアがアミノ酸に変わり、茎、葉、さやへと運ばれます |
| 6. 老化 | 登熟期に入ると根粒が機能を失い、根とともに土に還ります |

&nbsp;&nbsp;&nbsp;ニトロゲナーゼは酸素に非常に弱く、酸素に触れるとすぐに機能を失います。そのため根粒の内側にはレグヘモグロビンという赤い色素タンパク質が満ちていて、酸素を捕らえ、酵素の周囲の酸素濃度を極端に低く保ちます。人の血が赤いのと同じ原理で、根粒を割ったときに内側が赤や桃色をしているのがこの色素です。この事実は実用上きわめて重要です。赤い色は、その根粒がいま窒素を固定していることの目に見える証拠だからです。

&nbsp;&nbsp;&nbsp;ラッカセイの根粒は、ほかのマメより丸くて滑らかな形をしています。根にビーズがついたように見え、数は相対的に少なめです。数が少ないからといって失敗と判断せず、割って内側の色で判断しなければなりません。

### 5-2. 根粒ができているかを確認する方法

| 順序 | 内容 |
|---|---|
| 1 | 開花が始まるころ、播種後6-7週間ごろが最も良い時期です |
| 2 | 健康そうな株を二、三株選びます |
| 3 | 引き抜かず、スコップで株の周りを広く掘り取り、土ごと持ち上げます |
| 4 | バケツに入れて、土をそっと洗い落とします |
| 5 | 主根や側根についた丸い根粒の数を数えます |
| 6 | 根粒をいくつか爪で割って、内側の色を見ます |

| 観察結果 | 意味 | 対応 |
|---|---|---|
| 根粒が1株当たり10個以上ついている | 接種がうまくいきました | そのままにします |
| 割った内側が赤または桃色 | 窒素を固定しています | 良い状態です |
| 割った内側が白色または薄緑色 | 根粒はできていますが、固定していません | 酸度、湿害、リン酸欠乏を調べます |
| 割った内側が茶色または黒色 | すでに老化したか、死んでいます | 韓国の梅雨（チャンマ、6月下旬～7月）の後であれば、湿害で死んだ可能性が高いです |
| 根粒がほとんどない | 接種に失敗しました | 葉が黄色ければ、少量の窒素を補います |

> **根を掘り上げて根粒を割り、赤い色を確かめる。この一つの習慣が、窒素肥料のない世界でマメ栽培の成否を教えてくれる、最も確かなシグナルです。**

&nbsp;&nbsp;&nbsp;ただし、ラッカセイでこの確認作業には注意点があります。開花期は、子房柄が地中に入る時期でもあります。株を掘り取って確認した後に植え直しても、その株は子房柄が切れてしまい、収穫を期待しにくくなります。畑の端の株を選んで確認し、本当に必要な二、三株だけを見ます。

### 5-3. 接種源をどこで手に入れるか

| 方法 | 手順 | 効果 | 注意 |
|---|---|---|---|
| ラッカセイを育てた畑の土をまぶす | 前年にラッカセイを植えて根粒がよくできた畑から、表土5-15cmの深さの土を掘り取ってきます。種子を水で軽く湿らせてこの土をまぶし、すぐに播きます | 最も確実です | 白絹病が出た畑の土は絶対に使いません |
| 根粒そのものを使う | 掘り上げた根の根粒を集めて潰し、水に溶いて、その水に種子を浸してから引き上げます | 菌の密度が最も高いです | 根粒を掘り取ったその日のうちに使わなければなりません |
| 土を畑にまく | 播種する列に、持ってきた土をまいて一緒にすき込みます | 菌が土に広がります | 10㎡当たりスコップ一杯ほどが目安です |
| 根の残渣を残す | 収穫のとき、茎と根を畑に戻します | 翌年まで菌が土に残ります | ラッカセイは引き抜いて掘り上げるため、茎を改めて敷いておきます |

&nbsp;&nbsp;&nbsp;ラッカセイの接種で特に気をつけたいのは、病気が出た畑の土です。ラッカセイの土壌伝染病である白絹病と萎凋病は土に残って何年も生き延び、接種源を得ようとして病気まで持ち込んでしまうおそれがあります。白い糸のようなカビが茎の根元に見られた畑や、株がしおれて枯れたことのある畑の土は使いません。

&nbsp;&nbsp;&nbsp;接種のときに必ず守るべきことがあります。根粒菌は、直射日光、乾燥、熱に非常に弱い菌です。紫外線を数分浴びるとかなりの数が死に、乾くとさらに早く死にます。種子に土をまぶす作業は日陰で行い、土をまぶした種子は日なたに広げず、すぐに播きます。もう一つ、ラッカセイの種子は殻を取り除くと胚が傷みやすいため、接種作業では乱暴に扱わないようにします。

| 接種失敗を招く条件 | 理由 |
|---|---|
| 土壌pH 5.5以下 | 細菌が生きられません |
| 窒素肥料を多めに施した畑 | 植物が取引の必要を感じず、根粒の形成を自ら減らします |
| 水がたまる畑 | 好気性細菌のため、酸素がないと死にます |
| リン酸が不足した畑 | 窒素固定には多くのエネルギーが必要で、その代謝にリン酸が使われます |
| モリブデン・鉄・コバルトの欠乏 | ニトロゲナーゼの構成成分です |
| 接種した種子を日に干す | 紫外線と乾燥で菌が死にます |
| ほかのマメ科を育てた畑の土を使う | ラッカセイは特化した系統を必要とするため、効率が落ちます |
| 播種時の地温が低い | 15℃を下回ると、感染がほとんど起こりません |
