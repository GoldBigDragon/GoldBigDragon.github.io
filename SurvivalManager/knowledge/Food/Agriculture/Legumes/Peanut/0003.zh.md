## 3. 栽培环境

### 3-1. 气温与光量

| 条件 | 临界值 | 最适值 | 偏离时 |
|---|---|---|---|
| 发芽温度 | 地温15℃以上 | 20-25℃ | 低于15℃不能发芽，种子会腐烂 |
| 生育温度 | 18-35℃ | 25-30℃ | 原产热带，耐热 |
| 结实温度 | 20-30℃ | 24-28℃ | 幅度为10℃ |
| 积温 | 早熟2,800℃，晚熟3,600℃ | - | 不足时，荚果尚未充实就遇霜 |
| 耐寒性 | 无 | - | 一次霜冻就会死亡 |
| 日照 | 每天6小时以上 | 每天8小时以上 | 日照越多，产量越高 |

&nbsp;&nbsp;&nbsp;判断花生何时播种，依据的不是气温而是地温。土中5cm深处的温度必须超过15℃。这是因为种子大且脂肪多，在低温下长时间留在土中就会腐烂。如果没有地温计，可以在早晨把手伸进土里，以感觉不到凉为标准。

> **积温对花生之所以重要，是因为其生育期长达130-150天。早熟品种需要2,800℃，晚熟品种需要3,600℃，而韩国中部一年的积温并没有太大的余量。播种晚了就凑不够，会遭遇霜冻。**

&nbsp;&nbsp;&nbsp;因此，种植花生时覆盖很重要。地膜覆盖可以提高地温，使播种提前2-3周，相应地多获得积温。如果没有地膜，盖上黑布或已变黑腐烂的落叶也有一定效果，选择朝南的坡地或背风的地方也有帮助。

### 3-2. 土壤与水

| 条件 | 临界值 | 最适值 | 备注 |
|---|---|---|---|
| 土壤质地 | 沙土-壤土 | 沙壤土 | 黏质土和多石的田地不适合 |
| pH | 5.5-7.5 | 6.5-7.0 | 强酸性不适宜 |
| 钙 | 土壤中必须充足 | - | 荚果直接从土壤中吸收 |
| 有效土层厚度 | 30cm以上 | 40cm以上 | |
| 生长期蒸散量 | - | 约450mm | 在豆类中居中 |
| 淹水 | 开花期特别怕渍害 | - | 此时正是子房柄入土的时期 |
| 垄高 | 20cm以上 | 25cm | 同时兼顾排水和土壤疏松 |

> **花生喜欢沙地，不是出于偏好，而是由结构决定的。子房柄要能钻进土里，荚果要能在土中长大，收获时还要能把它挖出来。这三件事在松散的土壤里都会变得容易。**

&nbsp;&nbsp;&nbsp;相反，在黏质土或多石的田地里，花生种植会失败。子房柄无法钻进板结的土壤；即使钻进去了，荚果也没有生长的空间而变成畸形；收获时荚果还会脱落留在土里。选田时可以用手抓一把土，如果不成团、松散地散开，就适合种花生；如果结成土块，则最好改种其他作物。如果只有黏质土，可以掺入沙子或稻壳来起垄试试。

&nbsp;&nbsp;&nbsp;对钙的需求是花生特有的条件。土中的荚果通过果壳直接吸收钙，缺钙时荚果即使形成，里面的籽粒也长不饱满。这就是通常所说的空荚现象。把石灰作为基肥施入，对花生来说不是可选项，原因就在于此。

## 4. 品种

### 4-1. 按株型分类

| 类别 | 特征 | 收获 | 灾害时适合度 |
|---|---|---|---|
| 直立型 | 茎秆挺直。荚果集中在植株基部 | 拔起时大部分会随株带出 | 最高 |
| 半直立型 | 介于两者之间 | 比较容易随株带出 | 较高 |
| 匍匐型 | 茎向侧面蔓延。荚果分散范围广 | 遗漏较多 | 较低 |

&nbsp;&nbsp;&nbsp;韩国国立粮食科学院自1982年以来培育了多个品种，分为花生仁用和鲜花生用。Saedeul花生和Daegwang花生是完全直立型早熟大粒品种，在韩国全国种植；Namgwang花生是半直立型大粒品种，Sangan为炒食用，Jaseon为鲜花生用。在灾害条件下，直立型早熟品种较为合理：收获用工少，生育期短，霜冻风险也随之降低。

### 4-2. 不同情况下的选择标准

| 情况 | 优先选择 | 理由 |
|---|---|---|
| 人手不足 | 直立型 | 拔起时荚果会随株带出 |
| 韩国中部以北，霜来得早 | 早熟直立型 | 积温2,800度即可 |
| 想要榨油 | 大粒品种 | 籽粒越大越容易压榨 |
| 夏天需要食物 | 鲜花生用 | 在完全成熟前煮着吃 |
| 田地是黏质土 | 不种花生 | 子房柄无法入土 |
| 没有地膜 | 早熟品种 | 不做覆盖也要凑足积温 |

&nbsp;&nbsp;&nbsp;在品种选择上，再次强调花生特有的限制。种子寿命不足1年，因此必须每年留种，留下的种子要带壳保存。所以不管选哪个品种，把这个品系不间断地延续下去，比选品种本身更重要。哪怕只有一年丢了种子，也得从头重新寻找。

## 5. 整地与施肥 - 根瘤菌与石灰

### 5-1. 固氮是如何发生的

&nbsp;&nbsp;&nbsp;空气中78%是氮。人的头顶上漂浮着取之不尽的氮，植物却无法利用它。这是因为空气中的氮是由两个氮原子以三键牢牢结合而成的分子，要打断这个键需要极大的能量。工业上打断这个键来制造氨的方法就是哈伯-博施法，世界上的氮肥就来源于此。它需要高温、高压、催化剂和大量的化石燃料。

&nbsp;&nbsp;&nbsp;根瘤菌在常温常压下就能完成这项工作。它借助一种叫固氮酶的酶打断三键，把氮转化为氨。不过这是有代价的。这个反应需要大量能量，而细菌自己不能进行光合作用。所以它们住进豆科植物的根里，从植物那里获得光合作用制造的糖，作为回报，把固定下来的氮交给植物。这是一种交易关系。

&nbsp;&nbsp;&nbsp;与花生共生的菌，是Bradyrhizobium类群中专门适应花生的菌系。种过其他豆科作物的田地土壤往往效果不佳，所以使用种过花生的田地土壤最为可靠。

| 阶段 | 发生的事情 |
|---|---|
| 1. 信号交换 | 花生根系分泌类黄酮，土壤中的细菌对这一信号作出响应 |
| 2. 侵染 | 与其他豆科不同，花生的细菌是从根毛的裂缝进入的 |
| 3. 根瘤形成 | 根内侧的细胞分裂，形成圆形的瘤体并逐渐鼓起，细菌在其中安顿下来 |
| 4. 固氮 | 根瘤内的固氮酶开始工作，把空气中的氮转化为氨 |
| 5. 分配 | 氨转变为氨基酸，被输送到茎、叶和荚果 |
| 6. 衰老 | 进入荚果充实期后，根瘤丧失功能，与根一起回归土壤 |

&nbsp;&nbsp;&nbsp;固氮酶对氧极其敏感，一接触氧气就会立刻失去功能。因此，根瘤内部充满了一种叫豆血红蛋白的红色色素蛋白，它能抓住氧气，把酶周围的氧浓度保持在极低的水平。这与人的血液呈红色是同样的原理，剖开根瘤时内部呈红色或粉红色，就是这种色素。这一事实在实用上非常重要，因为红色是该根瘤此刻正在固氮的肉眼可见的证据。

&nbsp;&nbsp;&nbsp;花生的根瘤比其他豆类更圆、更光滑，看起来像根上挂着珠子，数量相对较少。不要因为数量少就判定为失败，而应当剖开，以内部的颜色来判断。

### 5-2. 如何确认根瘤是否形成

| 顺序 | 内容 |
|---|---|
| 1 | 开花刚开始的时候，即播种后6-7周左右，是最佳时机 |
| 2 | 选取两三株看起来健康的植株 |
| 3 | 不要拔，用铲子在植株周围大范围铲起，连土一起提起 |
| 4 | 放入水桶，轻轻洗去泥土 |
| 5 | 数一数主根和侧根上的圆形根瘤个数 |
| 6 | 用指甲剖开几个根瘤，查看内部的颜色 |

| 观察结果 | 含义 | 措施 |
|---|---|---|
| 每株有10个以上根瘤 | 接种成功 | 保持原样 |
| 剖开后内部呈红色或粉红色 | 正在固氮 | 状态良好 |
| 剖开后内部呈白色或淡绿色 | 已形成根瘤，但不固氮 | 检查土壤酸度、渍害、缺磷 |
| 剖开后内部呈褐色或黑色 | 已经衰老或死亡 | 若是在韩国的梅雨季（6月下旬至7月）之后，很可能是因渍害而死亡 |
| 几乎没有根瘤 | 接种失败 | 若叶片发黄，补充少量氮 |

> **挖出根，剖开根瘤，确认红色——这一个习惯，是在没有氮肥的世界里判断豆类种植成败最可靠的信号。**

&nbsp;&nbsp;&nbsp;不过，对花生进行这项检查时有需要注意的地方。开花期同时也是子房柄入土的时期。把植株铲起来检查后再种回去，这棵植株的子房柄已经折断，很难指望有收成。要选田边的植株来检查，只看确有必要的两三株。

### 5-3. 从哪里获得接种源

| 方法 | 步骤 | 效果 | 注意 |
|---|---|---|---|
| 用种过花生的田地的土拌种 | 从去年种过花生、根瘤形成良好的田地里，挖取表土5-15cm深处的土。把种子稍微用水浸湿，沾上这些土后立即播种 | 最可靠 | 绝对不要使用发生过白绢病的田地的土 |
| 直接使用根瘤 | 把挖出的根上的根瘤收集起来捣碎，放入水中化开，将种子在这水里浸泡后捞出 | 菌的密度最高 | 必须在挖出根瘤的当天用完 |
| 把土撒到田里 | 把取来的土撒在要播种的行上，一起翻入土中 | 菌在土壤中扩散 | 以每10㎡一铲左右为标准 |
| 保留根茬残体 | 收获时把茎和根还回田里 | 菌可在土中保留到第二年 | 花生是连根拔起收获的，所以要把茎秆重新铺回田里 |

&nbsp;&nbsp;&nbsp;花生接种时尤其要当心的，是病田的土。花生的土传病害白绢病和枯萎病会留在土壤中存活多年，想获得接种源，却可能把病害也一并带来。茎基部出现过白色丝状霉菌的田地，以及有植株萎蔫死亡的田地，其土壤都不能用。

&nbsp;&nbsp;&nbsp;接种时有一些必须遵守的事项。根瘤菌极怕直射阳光、干燥和高温。受紫外线照射几分钟就会死掉相当多，变干后死得更快。给种子拌土的操作要在阴凉处进行，拌好土的种子不要摊在太阳下晒，要立即播种。还有一点，花生种子一旦去掉外壳，胚就容易受损，所以接种操作时不要粗暴对待。

| 导致接种失败的条件 | 原因 |
|---|---|
| 土壤pH 5.5以下 | 细菌无法生存 |
| 施足氮肥的田地 | 植物感觉不到交易的必要，会自行减少根瘤形成 |
| 积水的田地 | 属好氧细菌，没有氧气就会死亡 |
| 缺磷的田地 | 固氮需要大量能量，其代谢要消耗磷 |
| 缺钼·铁·钴 | 它们是固氮酶的组成成分 |
| 把接种过的种子放在太阳下晒干 | 紫外线和干燥会使菌死亡 |
| 使用种过其他豆科作物的田地的土 | 花生需要专一的菌系，效率会降低 |
| 播种时地温低 | 15℃以下几乎不会发生侵染 |
