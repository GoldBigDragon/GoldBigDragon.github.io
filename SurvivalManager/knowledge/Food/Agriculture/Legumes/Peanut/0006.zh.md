## 13. 留种

| 项目 | 方法 |
|---|---|
| 留种植株的选择 | 选无病症、荚果结得多、饱满荚果比例高的植株 |
| 收获时期 | 完全成熟后再挖。比食用的稍晚 |
| 干燥 | 在阴凉处慢慢彻底晾干 |
| 保存形态 | 必须带壳保存 |
| 保存方法 | 装进洋葱网袋或透气的袋子，挂在阴凉处 |
| 保存温度 | 10-15℃。超过20℃就移到更凉爽的地方 |
| 保存期限 | 不足1年。最长只能保存到次年春天 |
| 剥壳 | 临播种前再剥 |

> **花生种子存放不过1年。这是因为脂肪酸败的同时，胚会死亡。必须每年留种，哪怕只隔一年，种子也会断绝。这是花生最大的结构性弱点。**

&nbsp;&nbsp;&nbsp;保存形态是决定性的。剥了壳的花生与空气接触的面积增大，酸败会急剧加快，几个月就会丧失发芽力。带壳放置的话，壳能挡住氧气和湿气，发芽力可以保持到次年春天。剥壳保存体积小，看起来方便，但那样一来，它就不再是种子，而成了粮食。

&nbsp;&nbsp;&nbsp;保存温度也很重要。10-15℃最理想，超过20℃酸败就会加快。要放在地下室、朝北的房间、地下贮藏窖这类温度低而稳定的地方，装进透气的袋子悬挂起来。密闭会使湿气积聚而长霉，所以只有种用花生不密闭，而是通风保存。必须记住这一点与食用花生正好相反。

&nbsp;&nbsp;&nbsp;春天播种前一定要做发芽试验。剥壳取20粒，用湿布包起来放几天，数一数发芽的粒数。发芽率在70%以上为正常，只有一半的话就增加播种量来补足，低于30%则不作种用。

## 14. 毒性 - 黄曲霉毒素

&nbsp;&nbsp;&nbsp;花生本身不含有毒成分。生吃也安全，凝集素和抑制剂与其他豆类相比也不成问题。但是，花生存在一种与其他豆类不在同一层面的风险。那就是霉菌产生的毒素。

### 14-1. 什么是黄曲霉毒素

&nbsp;&nbsp;&nbsp;名为曲霉的一类霉菌在花生上生长时产生的毒素，称为黄曲霉毒素。这种物质会直接损伤肝脏，长期摄入会大大提高患肝癌的风险。世界卫生组织已将其列为确认对人体致癌的物质，各国都严格限制食品中的含量。

| 项目 | 内容 |
|---|---|
| 产生者 | 黄曲霉（Aspergillus flavus）等霉菌 |
| 何时产生 | 含有水分的花生处在温暖的地方时。刚收获后和贮藏初期最危险 |
| 急性症状 | 一次摄入大量时，会出现呕吐、腹痛、黄疸、肝功能损伤 |
| 慢性风险 | 即使量少，长期食用也会提高肝癌风险 |
| 加热去除 | 不可能 |
| 清洗去除 | 不可能 |
| 是否残留于油中 | 压榨出的油中也会有一部分 |

> **黄曲霉毒素即使超过280℃也不会被完全破坏。炒、煮、炸、榨油，它都依然存在。让发霉的花生变得安全的方法并不存在。扔掉是唯一的办法。**

&nbsp;&nbsp;&nbsp;这一点与其他食品上的霉菌不同。米饭或年糕上长的霉虽然难看、味道也差，但通常把那部分去掉就行。花生中的黄曲霉毒素扩散的范围比肉眼可见的霉斑更广，不会被热破坏，而且少量也会累积。舍不得扔的心理最危险。

### 14-2. 如何判别

| 信号 | 内容 | 判定 |
|---|---|---|
| 荚壳表面有发青或发黄的粉末 | 是霉菌的孢子 | 立即扔掉 |
| 种皮颜色斑驳或变色 | 霉菌已侵入内部 | 扔掉 |
| 籽粒皱缩、颜色发暗 | 霉菌或虫害所致 | 扔掉 |
| 有苦味或发酸的气味 | 酸败或霉变 | 吐掉并扔掉 |
| 有潮湿的土腥味或霉味 | 贮藏期间受潮 | 检查全部 |
| 荚壳上有孔洞 | 虫子钻入，形成了霉菌的通道 | 扔掉 |
| 摇动时没有声音 | 还没干透 | 重新晾干 |

&nbsp;&nbsp;&nbsp;判别的原则很简单：稍有异常就不吃。尤其是苦味，是重要的信号。正常的花生香而略带甜味，如果嚼起来发苦或发酸，要立刻吐掉，并把那一把全部扔掉。对孩子尤其要小心。按体重计算的摄入量更大，同样的量风险也更大。

&nbsp;&nbsp;&nbsp;还有，一粒被污染，周围的也要怀疑。霉菌孢子会在贮藏容器内扩散。如果在容器里发现了变色的籽粒，就必须把整个容器里的花生摊在明亮处，一粒一粒检查。也许会碰到不得不扔掉相当一部分拿不准的花生的情况，但这总比伤了肝要好。

### 14-3. 如何预防

| 阶段 | 措施 | 理由 |
|---|---|---|
| 栽培 | 减少蛴螬危害 | 荚壳上的伤口是霉菌的通道 |
| 栽培 | 收获前2周起停止灌水 | 从湿土中挖出的花生有风险 |
| 收获 | 刚下过雨不挖 | 湿的荚壳上霉菌立刻就会生长 |
| 收获 | 当场挑出受损的荚果 | 一粒就会污染全部 |
| 干燥 | 彻底晾干至含水量10%以下 | 这是唯一可靠的预防方法 |
| 干燥 | 尽快晾干。不要带着湿气堆放 | 最初几天最危险 |
| 贮藏 | 阴凉干燥处，密闭或通风 | 温度和湿度都必须低 |
| 贮藏 | 带壳保存 | 壳起到屏障的作用 |
| 检查 | 每月一次，查看气味和颜色 | 早期发现就能保住其余的 |

> **对黄曲霉毒素，事后没有任何补救办法。关键只在于收获后几天之内，能多快、多彻底地把花生晾干。**

&nbsp;&nbsp;&nbsp;最危险的时刻是刚收获之后。把带着泥土和水汽的花生装进袋子堆放，里面会发热，这种又暖又潮的袋子里就成了霉菌的绝佳环境。一两天就会开始发霉。刚收获的花生绝不能装在袋子里放着，必须立刻摊开晾干。如果下雨没法晾晒，也要在室内薄薄摊开，不时翻动。

### 14-4. 其他注意事项

| 项目 | 内容 |
|---|---|
| 酸败 | 脂肪多，放久了会有油哈喇味。虽然无毒，但对身体不好，味道也变差 |
| 过敏 | 花生过敏严重时会危及生命。第一次吃的人要先用少量试吃 |
| 窒息 | 籽粒又圆又硬，幼儿可能吸入气道。4岁及以下的儿童不要整颗给 |
| 生花生 | 安全，但消化略难。吃多了会腹胀 |

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;花生的耐储性为S，比其他豆类的SS低一级。带壳常温下以1年为标准，而且还以完全干燥为前提。这是因为脂肪多、酸败快，又叠加了霉菌的风险。

| 方式 | 方法 | 期限 | 备注 |
|---|---|---|---|
| 带壳通风保存 | 装进洋葱网袋或袋子，挂在阴凉通风处 | 6个月-1年 | 种用必须采用这种方式 |
| 带壳密闭保存 | 彻底晾干后，装入陶罐或金属罐封好 | 1年左右 | 适合食用。必须在彻底干燥之后 |
| 去壳密闭 | 装入密闭容器，放在阴凉避光处 | 1-2个月 | 酸败快，不宜久放 |
| 炒后密闭 | 炒熟后完全放凉再密闭 | 1-2个月 | 炒过之后酸败反而更快 |
| 地下贮藏窖 | 带壳装入容器后埋起来 | 6个月-1年 | 温度低而稳定。一旦进水就会全部损失 |
| 榨成油 | 压榨成油 | 几个月 | 体积变小，更易处理 |

> **花生贮藏中，食用与种用的原则正好相反。食用的要彻底晾干后密闭，种用的要彻底晾干后通风。种子密闭的话，残留的湿气被封在里面，会长霉，还会因呼吸受阻而降低发芽力。**

| 贮藏场所条件 | 目标 |
|---|---|
| 温度 | 10-15℃。不要超过20℃ |
| 湿度 | 要低。避开潮湿的地方 |
| 光 | 遮光。光会促进酸败 |
| 位置 | 地下室或朝北的房间，离开地面放在垫架上 |
| 检查 | 每月一次。比其他豆类查看得更勤 |

&nbsp;&nbsp;&nbsp;检查时最可靠的感官是嗅觉。打开容器时有香味就正常；如果有潮湿的霉味或哈喇味，就说明问题已经开始。有霉味的话，把全部花生摊在明亮处一粒一粒检查，挑出变色的，剩下的重新彻底晾干后再装入。哈喇味是酸败所致，没有毒性，但要尽快吃掉。

&nbsp;&nbsp;&nbsp;虫害不像其他豆类那样是大问题。因为花生壳厚、里面油性大，豆象不喜欢。不过，剥了壳的花生会招来印度谷螟之类的贮藏害虫，所以剥了壳的必须密闭。

## 16. 烹饪与加工 - 榨油

### 16-1. 耗燃料最少的豆类

| 方法 | 燃料 | 步骤 |
|---|:---:|---|
| 生吃 | 无 | 剥壳后直接吃。安全 |
| 炒 | 极少 | 带壳或只取籽粒，放入干锅炒10-15分钟 |
| 煮（嫩花生） | 少 | 连荚果用盐水煮30-40分钟 |
| 捣成粉 | 无 | 炒后捣碎，可直接吃，或冲入水中饮用 |
| 磨成糊 | 无 | 炒后在臼里久捣，出油后成为糊状 |
| 榨油 | 少 | 炒后捣碎压榨 |

> **花生是豆类中唯一不用火就能吃的。在燃料完全断绝的情况下，仅这一点就具有超越其他所有等级的价值。**

&nbsp;&nbsp;&nbsp;把炒过的花生放在臼里久捣，细胞中的油会渗出，变成黏稠的糊状。再加一点盐就能直接吃，用水化开就成了汤，掺进谷物粉里则热量和蛋白质会同时提高。给饥饿的人做恢复饮食，很难做出比这更好的东西。国际救援现场用来治疗严重营养不良的高热量糊状食品，原理正是如此。

### 16-2. 榨油

&nbsp;&nbsp;&nbsp;花生是脂肪含量达45-50%的油料作物。在韩国，能榨油的作物主要有芝麻、紫苏（荏）、油菜、大豆、花生，其中花生含油量高、油质好、烟点高，也可用于油炸。

| 顺序 | 内容 | 要点 |
|---|---|---|
| 1. 挑选 | 彻底挑出发霉的 | 黄曲霉毒素也会转移到油中 |
| 2. 剥壳 | 去掉外壳，种皮也尽量去掉 | 带种皮的话，油色会变浑浊 |
| 3. 炒 | 在干锅中用小火炒10-15分钟 | 细胞壁破裂，油容易出来 |
| 4. 捣 | 用臼或石磨磨细 | 磨得越细，出油率越高 |
| 5. 蒸 | 把捣碎的花生用蒸汽稍蒸一下 | 热和水分能让油松动 |
| 6. 压榨 | 用布包起来压榨 | 使用杠杆或螺旋压榨机 |
| 7. 沉淀 | 榨出的油静置几天，让渣沉淀 | 只把上层清油另外盛装 |
| 8. 保存 | 放在阴暗凉爽处密闭保存 | 光和热会促进酸败 |

&nbsp;&nbsp;&nbsp;也写一下没有工具时的方法。杠杆式压榨机不难制作。在两根结实的木柱之间架一根长杆，把捣碎的花生用布包好，夹在木板之间，再在杆端挂上重物压榨。过去榨芝麻油和紫苏油用的就是这种方式，花生也用同样的原理。压榨出油率比不上机器，只能榨出脂肪的一半多一点，但剩下的花生饼里蛋白质也很多，不要扔掉，而是食用。

&nbsp;&nbsp;&nbsp;花生饼是蛋白质超过40%的优质食品。把榨油后剩下的这块饼粕碎开，放进粥里或掺入谷物粉中。不过，即使油已被榨出，花生饼也容易长霉，所以要尽快吃掉，或者彻底晒干后保存。黄曲霉毒素在花生饼中的残留比在油中更多，因此只要原料有一丝可疑，花生饼就不能给人吃。

> **榨油也是保存花生的一种方法。体积变小，保管空间也随之缩小，而且比去壳的花生在密闭保存下更耐放。但是，绝不用可疑发霉的原料榨油。**

### 16-3. 其他加工

| 加工 | 步骤摘要 | 保存 | 价值 |
|---|---|---|---|
| 炒花生 | 在干锅中炒10-15分钟 | 密闭1-2个月 | 可直接吃的应急食品 |
| 花生粉 | 炒后捣碎 | 密闭1个月 | 掺入谷物粉中提高热量 |
| 花生酱 | 炒后久捣至出油 | 密闭1-2个月 | 适合作恢复饮食 |
| 煮嫩花生 | 把未完全成熟的连荚果用盐水煮 | 几天 | 收获期当场吃 |
| 花生油 | 炒后捣碎压榨 | 几个月 | 用于烹饪和点灯 |
| 花生饼 | 榨油后剩下的 | 晒干后几个月 | 蛋白质40%以上 |
| 花生壳 | 碾碎后铺在田里或掺入堆肥 | - | 把有机质和钾还给土壤 |

| 12月 | 加工（炒、榨油）、检查贮藏 | 每月一次，查看气味和颜色 |

### 17-1. 必须记住的五件事

| 项目 | 内容 |
|---|---|
| 黄曲霉毒素 | 变色或发霉的花生，加热也不会变得安全。一定要扔掉 |
| 彻底干燥 | 直到摇动时哗啦作响。这是预防黄曲霉毒素的唯一方法 |
| 培土 | 子房柄必须扎进土里才能结出花生。开花期要把土弄松软 |
| 石灰 | 荚果直接从土壤中吸收钙。不足就会长成空荚果 |
| 种子 | 寿命不足1年。带壳通风保存，每年留种 |
