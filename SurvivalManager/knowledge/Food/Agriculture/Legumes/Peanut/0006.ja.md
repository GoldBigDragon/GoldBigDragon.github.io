## 13. 採種

| 項目 | 方法 |
|---|---|
| 採種株の選抜 | 病気の症状がなく、莢が多くつき、充実した莢の割合が高い株を選びます |
| 収穫時期 | 完全に熟してから掘ります。食用よりやや遅めに |
| 乾燥 | 日陰でゆっくり完全に乾燥させます |
| 保管形態 | 必ず殻つきのまま保管します |
| 保管方法 | 玉ねぎ用のネットや風通しのよい袋に入れ、涼しい場所に吊るします |
| 保管温度 | 10-15℃。20℃を超えたら涼しい場所に移します |
| 保管期間 | 1年未満。翌春までが限度です |
| 殻むき | 植える直前にむきます |

> **ラッカセイの種子は1年を超えて持ちません。脂肪が酸敗するにつれて胚が死ぬからです。毎年採種しなければならず、1年でも抜かすと種子が途絶えます。これがラッカセイの最大の構造的弱点です。**

&nbsp;&nbsp;&nbsp;保管の形態が決め手になります。殻をむいたラッカセイは空気に触れる面積が大きくなって酸敗が急激に進み、数か月で発芽力を失います。殻つきのまま置けば、殻が酸素と湿気を遮ってくれるため、翌春まで発芽力が保たれます。殻をむいて保管するほうが、かさが小さくて楽に見えますが、そうすると種子ではなく食糧になってしまいます。

&nbsp;&nbsp;&nbsp;保管温度も重要です。10-15℃が理想的で、20℃を超えると酸敗が進みます。地下や北向きの部屋、地中の貯蔵穴のように温度が低くて安定した場所に、風通しのよい袋に入れて吊るしておきます。密閉すると湿気がこもってカビが生えるため、種子用のラッカセイだけは密閉せず、風通しよく保管します。食用とは正反対であることを覚えておかなければなりません。

&nbsp;&nbsp;&nbsp;春に植える前には、必ず発芽試験をします。殻をむいて20粒を濡れた布に包み、数日置いて芽が出た数を数えます。発芽率が70%以上なら正常で、半分なら播種量を増やして補い、30%を下回れば種子には使いません。

## 14. 毒性 - アフラトキシン

&nbsp;&nbsp;&nbsp;ラッカセイ自体には毒性成分がありません。生で食べても安全で、レクチンや阻害物質も他の豆に比べれば問題になりません。しかしラッカセイには、他の豆類とは次元の異なる危険があります。カビがつくる毒素です。

### 14-1. アフラトキシンとは何か

&nbsp;&nbsp;&nbsp;アスペルギルスというカビの仲間がラッカセイに生えて、その過程でつくる毒素をアフラトキシンといいます。この物質は肝臓を直接傷つけ、長期間摂取すると肝臓がんのリスクを大きく高めます。世界保健機関がヒトに対する発がん性が確認された物質に分類しており、各国が食品中の含有量を厳しく規制しています。

| 項目 | 内容 |
|---|---|
| 産生するもの | アスペルギルス・フラバス（Aspergillus flavus）などのカビ |
| いつ発生するか | 水分が残ったラッカセイが温かい場所にあるとき。収穫直後と貯蔵の初期が最も危険です |
| 急性の症状 | 大量を一度に摂取すると、嘔吐、腹痛、黄疸、肝機能障害 |
| 慢性のリスク | 少量でも長く食べ続けると、肝臓がんのリスクが高まります |
| 加熱での除去 | 不可能です |
| 洗っての除去 | 不可能です |
| 油に残るか | 圧搾した油にも一部が移ります |

> **アフラトキシンは280℃を超えても完全には分解されません。炒っても、茹でても、揚げても、油を搾っても残ります。カビの生えたラッカセイを安全にする方法は存在しません。捨てることが唯一の方法です。**

&nbsp;&nbsp;&nbsp;この点が他の食品のカビとは違います。ご飯やトック（餅）に生えたカビは見た目が悪く味も落ちますが、たいていはその部分を取り除けば済みます。ラッカセイのアフラトキシンは、目に見えるカビの跡よりも広範囲に行き渡っており、熱で分解されず、少量でも蓄積します。もったいないという気持ちが最も危険です。

### 14-2. どう見分けるか

| サイン | 内容 | 判定 |
|---|---|---|
| 殻の表面に青みがかった、または黄色い粉 | カビの胞子です | ただちに捨てます |
| 薄皮の色がまだらになっている、または変色している | カビが中まで入っています | 捨てます |
| 粒がしぼんで色が暗い | カビまたは虫の被害 | 捨てます |
| 苦味や酸っぱいにおい | 酸敗またはカビ | 吐き出して捨てます |
| 湿っぽい土のにおいやカビくささ | 貯蔵中に湿気が入りました | 全量を点検します |
| 殻に穴 | 虫が入り、カビの通り道ができました | 捨てます |
| 振っても音がしない | 乾ききっていません | 再び乾燥させます |

&nbsp;&nbsp;&nbsp;見分けの原則は単純です。少しでもおかしければ食べません。特に苦味が重要なサインです。正常なラッカセイは香ばしく、ほんのり甘みがありますが、噛んで苦かったり酸っぱかったりしたら、すぐに吐き出して、その一握り全体を捨てます。子どもには特に注意が必要です。体重当たりの摂取量が大きいため、同じ量でも危険が大きくなります。

&nbsp;&nbsp;&nbsp;そして、1粒が汚染されたら、その周りも疑わなければなりません。カビの胞子は貯蔵容器の中で広がります。容器の中で変色した粒を見つけたら、その容器の全量を明るい場所に広げ、1粒ずつ調べなければなりません。確信が持てないかなりの量を捨てざるをえない状況になるかもしれませんが、肝臓を傷めるよりはましです。

### 14-3. どう防ぐか

| 段階 | 措置 | 理由 |
|---|---|---|
| 栽培 | 地虫の被害を減らします | 殻にできた傷がカビの通り道になります |
| 栽培 | 収穫の2週間前から灌水を止めます | 濡れた土から掘ったラッカセイは危険です |
| 収穫 | 雨の直後には掘りません | 濡れた殻にカビがすぐ生えます |
| 収穫 | 傷んだ莢をその場で選び出します | 1粒が全体を汚染します |
| 乾燥 | 水分10%以下まで完全に乾燥させます | これが唯一の確実な予防法です |
| 乾燥 | 早く乾かします。濡れたまま積んでおきません | 最初の数日が最も危険です |
| 貯蔵 | 涼しく乾いた場所、密閉または風通しよく | 温度も湿度も低くなければなりません |
| 貯蔵 | 殻つきのまま保管します | 殻が防護膜の役割を果たします |
| 点検 | 月に1回、においと色を確認します | 初期に見つければ残りを守れます |

> **アフラトキシンに対する事後の対策はありません。収穫後の数日間で、どれだけ早く、どれだけ完全に乾燥させられるかがすべてです。**

&nbsp;&nbsp;&nbsp;最も危険な瞬間は収穫直後です。土がつき、水気のあるラッカセイを袋に詰めて積んでおくと、内側から熱が出て、暖かく湿ったその袋の中がカビにとって完璧な条件になります。1、2日で始まります。収穫したラッカセイは決して袋に入れたままにせず、すぐに広げて乾かさなければなりません。雨で乾かせないなら、室内にでも薄く広げ、ときどきかき混ぜます。

### 14-4. その他の注意事項

| 項目 | 内容 |
|---|---|
| 酸敗 | 脂肪が多いため、長く置くと油のにおいが出ます。毒ではありませんが、体によくなく、味も悪くなります |
| アレルギー | ラッカセイアレルギーは重症の場合、命に関わります。初めて食べる人は少量で試します |
| 窒息 | 粒が丸くて硬く、幼い子どもが気道に入れてしまうことがあります。4歳以下の子どもには丸ごと与えません |
| 生のラッカセイ | 安全ですが、消化はやや難しいです。たくさん食べるとお腹が張ります |

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;ラッカセイの貯蔵性はSで、他の豆類のSSより一段階低くなっています。莢ごと常温で1年が目安で、それも完全乾燥が前提です。脂肪が多くて酸敗が早く、カビの危険も重なるためです。

| 方式 | 方法 | 期間 | 備考 |
|---|---|---|---|
| 殻つきで風通しよく保管 | 玉ねぎ用のネットや袋に入れ、涼しく風通しのよい場所に吊るします | 6か月-1年 | 種子用は必ずこの方式です |
| 殻つきで密閉保管 | 完全に乾燥させてから、甕や金属缶に入れて封をします | 1年前後 | 食用に向いています。必ず完全乾燥のあとで |
| 殻をむいて密閉 | 密閉容器に入れて涼しく暗い場所に置きます | 1-2か月 | 酸敗が早いので長く置きません |
| 炒って密閉 | 炒ったあと完全に冷まして密閉します | 1-2か月 | 炒ると、かえって酸敗が早まります |
| 地中の貯蔵穴 | 殻つきのまま容器に入れて埋めます | 6か月-1年 | 温度が低く安定しています。水がしみ込むと全量を失います |
| 油に搾る | 圧搾して油にします | 数か月 | かさが減り、扱いやすくなります |

> **ラッカセイの貯蔵では、食用と種子用の原則が正反対です。食用は完全に乾燥させて密閉し、種子用は完全に乾燥させて風を通します。種子を密閉すると、残った湿気がこもってカビが生え、呼吸が妨げられて発芽力が落ちます。**

| 保管場所の条件 | 目標 |
|---|---|
| 温度 | 10-15℃。20℃を超えないように |
| 湿度 | 低く。湿っぽい場所は避けます |
| 光 | 遮ります。光は酸敗を促します |
| 場所 | 地下や北向きの部屋、地面に触れないよう台の上 |
| 点検 | 月に1回。他の豆より頻繁に見ます |

&nbsp;&nbsp;&nbsp;点検で最も頼りになる感覚は嗅覚です。容器を開けたとき香ばしいにおいがすれば正常で、湿っぽいカビくささや油が劣化したようなにおいがすれば、問題が始まっています。カビくさいときは、全量を明るい場所に広げて1粒ずつ調べ、変色したものを選び出し、残りは改めて完全に乾燥させてから容器に入れます。油が劣化したようなにおいは酸敗によるもので、毒性はありませんが、急いで消費しなければなりません。

&nbsp;&nbsp;&nbsp;虫は、他の豆類ほど大きな問題ではありません。殻が厚く、中が油っぽいため、マメゾウムシが好まないからです。ただし、殻をむいたラッカセイにはノシメマダラメイガのような貯蔵害虫が寄ってくるので、むいたものは必ず密閉します。

## 16. 調理と加工 - 油搾り

### 16-1. 燃料が最も少なくて済む豆類

| 方法 | 燃料 | 手順 |
|---|:---:|---|
| 生食 | なし | 殻をむいてそのまま食べます。安全です |
| 炒る | ごく少ない | 殻つきのまま、または粒だけを、油を引かない鍋で10-15分炒ります |
| 茹でる（未熟ラッカセイ） | 少ない | 莢ごと塩水で30-40分茹でます |
| 搗いて粉に | なし | 炒って搗くと、そのまま食べるか、水に溶いて飲めます |
| すりつぶしてペースト | なし | 炒って臼で長く搗くと、油が出て練り状になります |
| 油搾り | 少ない | 炒って搗き、圧搾します |

> **ラッカセイは豆類の中で唯一、火を使わずに食べられます。燃料が完全に尽きた状況では、この一点が他のあらゆる等級を超える価値を持ちます。**

&nbsp;&nbsp;&nbsp;炒ったラッカセイを臼で長く搗くと、細胞から油が出て、とろりとした練り状になります。ここに塩を少し加えればそのまま食べられ、水に溶けば汁物になり、穀物の粉に混ぜればカロリーとタンパク質が一度に増えます。飢えた人の回復食として、これより優れたものを作るのは難しいでしょう。国際的な救援の現場で、重度の栄養失調の治療に使われる高カロリーのペーストが、まさにこの原理です。

### 16-2. 油搾り

&nbsp;&nbsp;&nbsp;ラッカセイは脂肪が45-50%に達する油料作物です。韓国で油を搾れる作物はゴマ、エゴマ、ナタネ、ダイズ、ラッカセイくらいですが、そのうちラッカセイは含有量が高く、油の質がよく、発煙点が高いので揚げ物にも使います。

| 順序 | 内容 | ポイント |
|---|---|---|
| 1. 選別 | カビの生えたものを徹底的に選び出します | アフラトキシンは油にも移ります |
| 2. 殻むき | 外側の殻をむき、薄皮もできるだけむきます | 薄皮があると油の色が濁ります |
| 3. 炒り | 油を引かない鍋で弱火にかけ、10-15分炒ります | 細胞壁が壊れて油が出やすくなります |
| 4. 搗き | 臼や石臼で細かく搗きます | 細かく搗くほど収率が上がります |
| 5. 蒸し | 搗いたものを蒸気で軽く蒸します | 熱と水分が油をゆるめてくれます |
| 6. 圧搾 | 布に包んで押して搾ります | てこや、ねじ式の圧搾機を使います |
| 7. 沈殿 | 搾った油を数日置いて、かすを沈めます | 上澄みだけを別の容器に取ります |
| 8. 保管 | 暗くて涼しい場所で密閉して置きます | 光と熱が酸敗を促します |

&nbsp;&nbsp;&nbsp;道具がないときの方法も書いておきます。てこ式の圧搾機は作るのが難しくありません。丈夫な木の柱2本の間に長い棒を渡し、搗いたラッカセイを布に包んで板の間に挟んだうえで、棒の先に重りをかけて押さえます。昔、ごま油やえごま油を搾っていた方法がこれで、同じ原理がラッカセイにも使えます。圧搾の収率は機械に及ばず、脂肪の半分余りしか出ませんが、残った油かすにもタンパク質が多いので、捨てずに食べます。

&nbsp;&nbsp;&nbsp;ラッカセイの油かすは、タンパク質が40%を超える優れた食品です。油を搾ったあとに残るこの塊を砕いて粥に入れたり、穀物の粉に混ぜたりします。ただし、油が抜けていてもカビが生えやすいため、早めに消費するか、からからに乾燥させて保管します。アフラトキシンは油よりも油かすのほうに多く残るので、原料が少しでも疑わしかった場合、油かすは人が食べません。

> **油を搾ることは、ラッカセイを保存する方法でもあります。かさが減って保管スペースが小さくなり、殻をむいたラッカセイよりも、密閉保管で長くもちます。ただし、カビが疑われる原料では決して搾りません。**

### 16-3. その他の加工

| 加工 | 手順の要約 | 保管 | 価値 |
|---|---|---|---|
| 炒ったラッカセイ | 油を引かない鍋で10-15分炒ります | 密閉して1-2か月 | そのまま食べられる非常食です |
| ラッカセイ粉 | 炒って搗きます | 密閉して1か月 | 穀物の粉に混ぜてカロリーを上げます |
| ラッカセイペースト | 炒って、油が出るまで長く搗きます | 密閉して1-2か月 | 回復食に向いています |
| 茹でた未熟ラッカセイ | 熟しきっていないものを莢ごと塩水で茹でます | 数日 | 収穫期にすぐ食べます |
| ラッカセイ油 | 炒って搗き、圧搾します | 数か月 | 調理や灯りに使います |
| 油かす | 油を搾ったあとに残ったもの | 乾燥させて数か月 | タンパク質40%以上 |
| ラッカセイの殻 | 砕いて畑に敷くか、堆肥に混ぜます | - | 有機物とカリウムを返してくれます |

| 12月 | 加工（炒り、油搾り）、貯蔵の点検 | 月に1回、においと色を見ます |

### 17-1. 忘れてはならない五つのこと

| 項目 | 内容 |
|---|---|
| アフラトキシン | 色が変わったり、カビが生えたりしたラッカセイは、加熱しても安全になりません。必ず捨てます |
| 完全乾燥 | 振ってカラカラと音がするまで。これがアフラトキシンを防ぐ唯一の方法です |
| 土寄せ | 子房柄が土に入ってはじめてラッカセイができます。開花期に土を柔らかくします |
| 石灰 | 莢が土から直接カルシウムを吸収します。不足すると中が空っぽの莢になります |
| 種子 | 寿命は1年未満です。殻つきのまま風通しよく保管し、毎年採種します |
