## 引言
&nbsp;&nbsp;&nbsp;红豆（Vigna angularis）是原产于东亚的豆科一年生草本。综合等级为C（40.6分，有效183种中第110名），短期D（38.9）、长期C（42.3），副食为SS（61.8分），不能作主食，但作为配菜是出色的作物。单位面积热量为D，每㎡660kcal，仅为自给线的25%，所以不适合分配大面积。作为补偿，蛋白质密度占热量的25%，膳食纤维每100g超过15g，是糙米的三倍，0.66mg的维生素B1能预防以白米为主的饮食中的脚气病。总蒸散量约400mm，用水少，100-120天即可收获，可接在大蒜或马铃薯之后种植，干红豆只要防住虫，常温下可保存3年。弱点有三个：极怕涝害，平垄比高垄减产34%；有须休耕3年的连作障碍；储存期间绿豆象可能在半年内毁掉全部。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | C | 40.6 |
| 短期 | D | 38.9 |
| 长期 | C | 42.3 |
| 副食 | SS | 61.8 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：蛋白质密度、施肥、设施负担、耐储性。S：微量营养素、口味、国内种植普及度、自留种。A：水消耗量、无合成投入产量保持率、产量稳定性、种子寿命。B：收获速度、防治自立度、连作适应性 |
| 劣势 | E：耐寒性。D：单位面积热量、持续性、光照、烹调·加工要求度、整地·挖掘能量、非食用价值。C：温度幅度、病虫害压力 |

> **红豆的耐储性SS是有条件的等级。如果防不住绿豆象，就不是SS而是E。**

&nbsp;&nbsp;&nbsp;只靠红豆满足每天2,100kcal，需要吃636g干红豆，这是不可能的，所以现实的做法是把田地面积控制在整体的一成以内。整地·挖掘能量D（热量回收倍数4.0倍）源于必须起高垄，连作适应性B则隐藏着休耕3年的负担。病虫害压力C（不防治时感受率48.9%）有相当一部分是在仓库里损失掉的。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 豆科豇豆属一年生草本。与绿豆、豇豆同属，所以病虫害和根瘤菌比起大豆更接近它们。原产于中国中北部到朝鲜半岛，野生祖先野小豆生长在排水良好的田埂上 |
| 叶、茎 | 叶为接近心形的三出复叶。茎直立，高30-50cm，不需要支柱，蔓生型超过1m。荚果离地近，容易受潮 |
| 根、花 | 直立的主根上伸出须根，根瘤长在须根上。花为黄色蝶形，自花授粉（大豆的花是白色或淡紫色，由此可区分） |
| 荚果、种子 | 细长圆筒形，每荚6-10粒。以红色为基本色，也有黑色、白色和花斑的 |

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 发芽、幼苗期 | 播种后3周 | 发芽与初期生长，开始形成根瘤 |
| 开花期 | 第6-8周 | 黄花从下往上依次开放，持续3-4周 |
| 鼓荚期 | 第8-10周 | 荚果和籽粒增大 |
| 成熟、收获期 | 第10-14周 | 从下面的荚果开始变褐成熟 |

> **幼苗期是最怕涝害的时期。播种后紧接着遇上雨季，幼小的红豆根部受损，就这样死去。6月中下旬播种碰上雨季的年份，垄的高度决定存活。**

&nbsp;&nbsp;&nbsp;干红豆每100g热量330-356kcal，蛋白质20.63g（占热量的25.0%），碳水化合物约60g，脂肪0.5-1g，膳食纤维14.9-16.9g，维生素B1 0.66mg（是白米的十倍，超过成人每日推荐量的一半），糖类0.43g。种皮含花青素，整体含皂苷。脂肪不到1%，不易酸败，磨成粉也能保存很久，甜味不是来自红豆，而是来自糖或蜂蜜。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽最适32-34℃（豆类中最高），低于15℃则发芽慢、种子会腐烂，所以播种时地温要在15℃以上（20℃以上更好）。生长15-35℃（最适20-24℃），结实18-32℃，遇霜冻死 |
| 光 | 每天6小时以上（8小时以上最适），遮光40%则产量减半。属短日照植物，晚播则以小植株开花 |
| 水、土壤 | 排水良好的沙壤土或壤土，pH 5.5-7.0（6.0-6.5最适，酸性土中根瘤减少）。生育期蒸散量约400mm。被水淹一天以上就很难恢复 |
| 垄、排水沟 | 垄高20cm以上（25-30cm最适），排水沟深30cm以上。平垄栽培减产34%，所以起垄比施肥更优先 |

| 类型 | 特点 |
|:---|:---|
| 直立型（普通红豆） | 株高30-50cm，不需要支柱，抗倒伏，是基本选择。中原（全国）、忠州（中部） |
| 蔓生型（蔓红豆） | 蔓超过1m，需要支柱，产量高。七宝。支柱材料和劳力充裕时 |
| 早熟、耐湿 | Ye生育期短，用于播种拖到7月时。Arari、Hongda、Geomguseul、Yeondoochae耐湿性强，用于排水差的田或水田转作地 |

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 排水 | 先做垄和排水沟，黏土田掺入沙、稻壳、腐叶土以改良排水 |
| 施肥（1,000㎡） | 氮2-4kg（根瘤起作用之前的初期用最小量）、磷4-6kg（比大豆多）、钾4-6kg（均作基肥）、充分腐熟的堆肥1,000kg，酸性土再加石灰150-200kg（播种前3-4周） |
| 替代资源 | 草木灰（每㎡100-200g，过量则pH升高）、腐熟堆肥（每㎡1kg）、稀释10倍的人尿（少量）、骨粉和烤过的鱼骨（磷）、贝壳和蛋壳（代替石灰） |
| 根瘤接种 | 取种过红豆、绿豆、豇豆的田里5-15cm深的表土，裹在用水稍微润湿的种子上，在阴凉处30分钟内播下（晒太阳会杀死菌）。野小豆根上的根瘤也很合适。pH 5.5以下、氮肥过多、积水、缺磷则接种失败 |

| 检查 | 方法 |
|:---|:---|
| 根瘤检查 | 开花前后（播种后5-7周），用铁锹连土挖起两三株健康植株洗净，剖开根瘤。每株根瘤15个以上、内部呈红色或粉红色，就是在固氮。白色或浅绿色的要检查酸度、涝害和缺磷，5个以下是接种失败，叶发黄的话少量补氮 |

> **豆类能肥田，不是因为固氮，而是因为把固定的氮的一部分留在茎叶里，留在田里。如果把那些茎叶运走，红豆就成了掠夺土地的作物。**

&nbsp;&nbsp;&nbsp;所以豆秸、叶和荚壳要切成20-30cm还回田里，不要烧掉（氮会逸散），也不要挖出根。只有染病的残体才烧掉或拿到田外沤烂。

| 播种 | 标准 |
|:---|:---|
| 时期 | 中北部为6月中旬-下旬（极限7月上旬），南部为6月中旬-7月上旬（极限7月中旬）。一场雨季的雨刚过之后播种，幼小的红豆少淋雨。越晚荚越少，晚开的花在霜降前熟不了 |
| 种子准备 | 弃去有斑点、变色、皱缩、虫孔的籽粒（绿豆象的孔小而圆，看起来像白点），并捞去浮在水上的籽粒。放在65℃水中浸5分钟可减少种传病害，但超时会损伤发芽力，接种要在完全冷却后进行 |
| 方法 | 深3-5cm，每穴2-3粒（之后留2株间苗）。单行栽培行距60-70cm、株距10-15cm，双行栽培是在120cm宽的垄上相隔40cm种两行。播种量每1,000㎡ 3-4kg，晚播增至5-7kg并加密 |
| 鸟 | 播种后鸟啄食子叶会使植株死亡，所以到发芽前盖上稻草、网或旧纱窗 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 幼苗期 | 偏干管理（最怕涝害） |
| 雨季 | 重在排水而不是灌溉。开沟排掉积水 |
| 开花期至鼓荚期 | 遇旱要浇足 |
| 成熟期 | 停止灌溉（过湿则荚果不干，并长霉） |

> **红豆的水分管理，大多不是浇水，而是排水。起高垄、开沟，比灌溉更优先。**

&nbsp;&nbsp;&nbsp;如果早晨叶片仍下垂而土是湿的，说明因过湿根已受损，要立即开沟排水，千万不能再浇水。

| 管理 | 方法 |
|:---|:---|
| 培土 | 3次。真叶2-3片时培到子叶节，4-5片时培到初生叶节，6-7片时培到第一复叶节，在开花前完成。开花后进田翻土，会使花脱落、须根折断而减产 |
| 除草 | 播种后2-3周（与第1次培土同时）和4-5周（与第2次培土同时）浅锄，开花前全部结束。红豆没有登记的除草剂 |
| 覆盖 | 第3次培土后立即用稻草、稻壳、落叶、割下的草盖5-10cm厚（不盖则减产24%，播种后立即盖则芽出不来）。同时挡住杂草、蒸发和溅泥 |

## 6. 病虫害与养分问题
| 病虫害 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 病毒病 | 叶片呈花叶状斑驳，生长停滞。由蚜虫传播 | 无法治疗。发现后立即拔除烧掉，并减少蚜虫 |
| 落叶病 | 从下部叶开始变褐并大量脱落。连作田的土中积累真菌 | 轮作3年以上是唯一对策。烧掉病残体 |
| 褐斑病、炭疽病、白粉病 | 叶上褐色斑纹或暗褐色病斑（8-9月多湿） / 白粉（干燥且通风差） | 保证通风、清除病叶、波尔多液、选种 / 牛奶稀释5-10倍 |
| 根腐病 | 根变褐，下部叶发黄（过湿、连作） | 排水、起高垄、轮作 |
| 蝽类 | 8月起刺吸荚果，使其成为空荚 | 清晨捕杀、田边种诱集作物、开花期罩防虫网（自花授粉，不影响结实） |
| 地老虎类、蚜虫 | 在基部咬断幼茎 / 吸汁并传播病毒 | 扒开倒伏植株周围的土捉幼虫，并在基部围一圈灰 / 肥皂水（每1L水加肥皂5g） |

&nbsp;&nbsp;&nbsp;波尔多液的做法是把400g硫酸铜和400g生石灰分别溶于100L水中再混合。起高垄（超过一半的病害与过湿有关）、株距、覆盖、雨后不进田、烧掉病残体、清理田埂（豆科杂草是蝽类和病毒的中间寄主）是栽培防治措施。

> **在没有药剂的条件下，红豆防治的核心归结为两件事：排水和轮作。这两件事决定了红豆病害的大部分。**

| 症状 | 原因与对策 |
|:---|:---|
| 整片叶淡黄、植株矮小 | 缺氮（根瘤不良最常见）。挖出根检查根瘤，当季少量施稀释10倍的人尿 |
| 叶缘变褐干枯并卷曲 | 缺钾。把草木灰撒在株间 |
| 生长迟缓、叶片发紫 | 缺磷。骨粉、烤过的鱼骨、草木灰 |
| 只有叶片浓绿茂盛、荚少 | 氮过量。停止供氮 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 玉米、高粱、小米（间作，红豆固定的氮可分享）、万寿菊（抑制线虫）。大蒜、洋葱、大麦、马铃薯是前茬，在6月收获后的地块种红豆 |
| 差 | 番茄、辣椒、茄子（共有病虫害）、大豆、绿豆、豇豆、花生等豆科（积累相同的病原菌和线虫）、红豆连作（落叶病和病毒） |

&nbsp;&nbsp;&nbsp;休耕期为3年以上（理想周期4年），原因是落叶病、病毒、根腐病和线虫在土中积累。红豆之后种大豆或绿豆也算连作，所以其他豆科也计入休耕期。4年轮作的例子是：大蒜或洋葱之后种红豆 → 玉米、高粱、小米 → 大白菜、卷心菜、萝卜 → 马铃薯或红薯 → 红豆。

> **红豆的连作障碍来自土中积累的落叶病真菌和病毒。药物治不了，只有让田空着的时间才能解决。要每年都收获红豆，需要四块田。**

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 70-80%的荚果变褐成熟时一次收获（开花后50-55天，中北部10月上旬-中旬，南部10月中旬-下旬）。咬豆子会清脆裂开，种皮深红，下部叶发黄脱落 |
| 要领 | 在晴朗干燥、露水已干的上午10点以后，用镰刀割茎基部（根留下）。移到席子或布上（拖拉会使荚炸裂），晾4-6天，荚果一拧就啪地裂开时脱粒 |
| 脱粒 | 把干豆秸装半袋麻袋踩踏或用连枷打，在桶内壁上敲打则豆子落进桶里。留种用的少量用手剥 |
| 精选 | 在有风的日子用簸箕或盆往下倒，吹走壳。倒入水中捞去浮起的空瘪豆和被豆象蛀过的豆（捞出的豆当天重新晒干） |

> **红豆熟透的荚果干了会自己炸开。这叫裂荚，收获晚了会损失多达30%。当下部的荚果用手一拧开始啪地裂开时，就不要再等了。**

| 留种 | 标准 |
|:---|:---|
| 选株、收获 | 预先标记没有病症、荚多、成熟期一致的植株。比食用稍晚，荚果完全变褐后再收，并用手剥 |
| 精选、干燥 | 弃去种皮颜色淡或有花斑、皱缩、有绿豆象孔的籽粒。含水量12%以下 |
| 保存 | 装入密封容器，放在12度以下的凉爽阴暗处。发芽率收获当年90%以上，1年后85-90%，2年后70-85%，3年后50-70%，第4年以后急剧下降。反复自留种会积累种传病害 |

## 9. 储存
| 阶段 | 方法 |
|:---|:---|
| 干燥 | 连秆晒4-6天，脱粒后薄摊在太阳下晒2-3天，使含水量降到12%以下（咬不进去、清脆裂开）。在干燥的瓶里放入红豆和炒过的盐摇晃，盐若粘在瓶壁上就再晒，凉透后装入 |
| 完全密封 | 把玻璃瓶或金属罐装满封好，氧气被切断，3-4周内连卵和幼虫都会死。与其用一个大容器，不如用几个小容器装满，这样一个坏了也不会全部损失 |
| 草木灰、硅藻土、油 | 按红豆体积的2-5%混入细草木灰（留种用也可，吃前冲洗）。硅藻土每1kg红豆用1-3g。揉入2-5mL食用油效果很大，但留种用的不能用 |
| 低温、高温 | 把密封容器在隆冬放到室外几天，不开盖，在室内放半天使温度一致后再打开（防止结露）。12度以下低温保存几乎使繁殖停止 |

> **红豆不是烂掉而损失，而是被虫吃掉而损失。储存的技术，就是防绿豆象的技术。**

&nbsp;&nbsp;&nbsp;绿豆象在田里把卵产在荚果上，卵带在种皮上进入仓库，第一个月从外面看不出来，第二个月成虫钻出，6个月整袋就成了壳和粉。容器方面，玻璃瓶和金属罐可用3年以上，陶罐和地下储藏窖2-3年（储藏窖进水则全部损失），厚塑料袋1年。保持12度以下、空气湿度65%以下，避光并放在垫架上，每月检查一次。

## 10. 烹调与注意事项
| 成分 | 作用 | 去除方法 |
|:---|:---|:---|
| 胰蛋白酶抑制剂、凝集素 | 阻碍蛋白质消化，引起腹痛、呕吐、腹泻。红豆的凝集素比菜豆弱 | 浸泡6小时后在剧烈沸腾的水中充分加热 |
| 皂苷 | 起泡并刺激肠胃，使人胃部不适、腹泻。适量有抗氧化和利尿作用 | 倒掉煮的第一遍水，撇去泡沫 |
| 植酸、单宁、低聚糖 | 妨碍铁、锌、钙吸收 / 涩味 / 肚子胀气 | 浸泡、发芽、发酵可减少植酸，并倒掉浸泡水和第一遍煮水 |

> **红豆的皂苷特别多。煮时冒出的泡沫就是皂苷，倒掉这第一遍水是煮红豆的第一步。不倒掉就涩口、肚子疼。**

| 处理 | 标准 |
|:---|:---|
| 顺序 | 在常温水中浸泡6小时，倒掉浸泡水。煮5-10分钟后倒掉第一遍水，换新水在剧烈沸腾的水中煮40-60分钟。用手指一按就容易压烂，就是熟了 |
| 省燃料 | 压力烹调是120℃下10-15分钟。余热烹调是煮15分钟后放入保温箱2小时（箱内约80度，所以第一次煮沸要保证15分钟以上，有硬芯就再煮）。把几天的量一次煮好 |
| 发芽、发酵 | 催芽后植酸减少50-70%、抑制剂减少30-40%，并产生维生素C。把煮好的红豆发酵两三天，更易消化 |

&nbsp;&nbsp;&nbsp;红豆饭补充白米所缺的维生素B1和赖氨酸。煮后晒干磨成的红豆粉不含脂肪，密封可保存2-3个月。需要甜味时，可同时用甜高粱糖浆或麦芽糖稀。

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存的红豆、种子发芽试验、低温处理。2月做田地规划、翻堆堆肥、确认能保证3年休耕的地块 |
| 3-4月 | 3月撒石灰、完成堆肥。4月管理前茬，在黏土田里掺沙、稻壳、腐叶土以改良排水 |
| 5-6月 | 5月准备收获前茬、备足接种用的土。6月收获前茬、开排水沟、把垄起到25-30cm、中旬至下旬播种 |
| 7-8月 | 7月第1、2次培土、除草、雨季排水（雨后不要立即进田）。8月在开花前完成第3次培土，并覆盖、检查根瘤、监视蝽类 |
| 9-10月 | 9月灌溉、捕杀蝽类、标记留种株。10月荚果七八成成熟时一次收获，晾晒、脱粒、精选、把茎叶还田 |
| 11-12月 | 11月收尾晾干、浮选、防虫处理、储存。12月低温处理、检查储存、冬至红豆粥 |

> **红豆不能当主食，但只要越过涝害、连作和豆象这几关，就是一种用水少、季节短，却能补上谷物所缺的维生素B1的配菜作物。**
