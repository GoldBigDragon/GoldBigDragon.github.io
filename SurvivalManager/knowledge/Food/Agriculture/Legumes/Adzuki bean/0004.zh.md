## 6. 播种

### 6-1. 播种时期

| 地区 | 适宜播种期 | 播种极限期 | 收获时期 |
|---|---|---|---|
| 韩国中北部 | 6月中旬-下旬 | 7月上旬 | 10月上旬-中旬 |
| 韩国南部 | 6月中旬-7月上旬 | 7月中旬 | 10月中旬-下旬 |

&nbsp;&nbsp;&nbsp;红小豆的播种期落在6月中下旬，原因是其最适发芽温度高达32-34℃。这一时期正好在大蒜、洋葱、大麦、马铃薯收获之后，接茬种植自然衔接。在地块狭小的条件下，这一特性是很大的优势，能让同一块地一年收获两次。

> **红小豆播种越晚，减产越明显。一旦拖到7月，开花期缩短，结荚数减少，晚开的花在霜降前也来不及成熟。**

&nbsp;&nbsp;&nbsp;播种延误时的应对方式是固定的：加大播种量。适期播种时每1,000㎡播3-4kg，延误时增加到5-7kg。晚播的红小豆植株长得较小，因此通过增加株数来维持单位面积产量。株距也要缩小。不过这种补偿有限度，一旦超过7月中旬，除非是早熟种Yepat，否则基本没什么可收的了。

&nbsp;&nbsp;&nbsp;播种时期与梅雨季的关系也需要一并考虑。6月中下旬正是韩国梅雨季（6月下旬至7月）开始的时期，而红小豆的幼苗期恰恰是最不耐湿害的阶段。如果能根据梅雨预报调整播种日，最好在一场梅雨过后立即播种，让幼嫩的红小豆少淋雨。如果无法调整，就尽量把垄台做高来应对。

### 6-2. 种子准备

| 项目 | 方法 | 在灾害条件下 |
|---|---|---|
| 挑选 | 剔除有斑点、变色、皱缩、虫孔的籽粒 | 红小豆象的蛀孔小而圆，表面看起来像白色小点 |
| 水选 | 浸入水中，捞去浮起的籽粒 | 被象鼻虫蛀空的籽粒内部中空，会浮起来。捞出后立即晾干 |
| 温汤浸种 | 用65℃的水浸泡5分钟，杀灭种传病害 | 水量应为种子的10倍以上。时间过长会损伤发芽力 |
| 拌灰处理 | 拌上细草木灰 | 有助于消毒和干燥，并有驱避鸟虫的效果 |
| 根瘤接种 | 拌上种过红小豆·绿豆·豇豆地块的土 | 须在温汤处理后完全放凉再进行 |
| 发芽试验 | 用湿布包住20粒，放在温暖处几天 | 红小豆需要温暖才能发芽，试验也要放在温暖处 |

&nbsp;&nbsp;&nbsp;红小豆温汤浸种的条件与其他豆类不同。大豆是50-55℃浸10-15分钟，红小豆则是65℃左右浸5分钟——温度更高，时间更短。保持这一差异很重要。若用65℃的水浸10分钟，发芽力会严重下降；若用50℃浸5分钟，消毒效果几乎为零。没有温度计时，把沸水和常温水按约2比1的比例混合，大致就是65℃，手很难伸进去的程度。数够5分钟后立即用凉水降温。

&nbsp;&nbsp;&nbsp;挑选时必须核查的是红小豆象留下的蛀孔。如果种皮上有直径1mm以内的圆孔，或表面能看到类似白点的东西，说明这粒种子里已经有虫卵或幼虫。种下这种种子不会发芽，留在仓库里则会成为下一代虫害的起点。水选法能大大简化这一挑选过程，因为被蛀空的籽粒内部中空，会浮起来。

### 6-3. 播种方法

| 项目 | 标准 | 理由 |
|---|---|---|
| 播种深度 | 3-5cm | 太浅会干燥并被鸟啄食，太深会影响出苗 |
| 每穴粒数 | 2-3粒 | 之后间苗，留2株 |
| 播种量（适期） | 3-4kg/1,000㎡ | |
| 播种量（延期） | 5-7kg/1,000㎡ | 播种越晚种得越密 |
| 单行种植 | 行距60-70cm，株距10-15cm | 适合直立型 |
| 双行种植 | 120cm垄面上间隔40cm种两行，株距10-15cm | 面积利用率高 |
| 垄台高度 | 20cm以上，最好25-30cm | 是防止湿害的关键 |

&nbsp;&nbsp;&nbsp;覆盖在红小豆上的效果尤其显著。常规试验中，未覆膜的地块比覆膜地块减产24%。在没有地膜的条件下，也可以运用同样的原理：用稻草、稻壳、落叶或割下的杂草在垄面上覆盖5到10cm厚，能同时带来三种效果——抑制杂草、减少表面蒸发，并防止下雨时泥土溅到下部豆荚上。红小豆没有登记的除草剂，除草必须靠人工，在这种条件下覆盖能直接减少劳动量。

&nbsp;&nbsp;&nbsp;不过有机覆盖物有一点需要注意。播种后立即厚厚覆盖，会让幼苗顶不出来；潮湿的覆盖物下方土壤不易变干，反而可能加重湿害。红小豆宜在出苗结束、长出两三片真叶、完成第一次培土之后再覆盖，这样比较安全。

&nbsp;&nbsp;&nbsp;播种后不久的威胁来自鸟类。鸽子、喜鹊和野鸡会啄食刚出苗的红小豆的子叶，失去子叶的植株大多会死。可以在播种行上方薄薄盖一层树枝或稻草，或在出苗前盖上网或旧纱网，也可以交叉拉上反光绳。

## 7. 水分管理 - 湿害是头号大敌

| 时期 | 水分管理 | 理由 |
|---|---|---|
| 播种到发芽 | 不让土壤过分干燥 | 发芽需要水分 |
| 幼苗期 | 保持相对偏干的管理 | 是最不耐湿害的时期 |
| 梅雨季 | 要做的是排水而不是灌水 | 疏通排水沟，排掉积水 |
| 开花期-荚肥大期 | 遇到干旱要充分灌水 | 这一时期缺水会减少结荚数 |
| 成熟期 | 停止灌水 | 过湿会使豆荚不易变干，种实容易长霉 |

> **对红小豆而言，"水分管理"这个词多数时候指的不是浇水，而是排水。抬高垄台、疏通沟渠这些工作要排在灌水之前。**

| 症状 | 原因 | 应对 |
|---|---|---|
| 中午叶片萎蔫，傍晚恢复 | 暂时性缺水，属正常现象 | 无需处理 |
| 早晨叶片仍萎蔫，土壤干燥 | 干旱 | 灌水 |
| 早晨叶片仍萎蔫，土壤却是湿的 | 过湿导致根系受损 | 立即挖沟排水，切勿再浇水 |
| 下部叶片发黄，根系呈褐色腐烂 | 湿害 | 排水并培土，严重时难以恢复 |
| 全株叶片淡黄但不萎蔫 | 根瘤不良导致缺氮 | 挖根掰开根瘤确认 |
| 下部叶片出现褐斑并蔓延脱落 | 落叶病或褐色斑纹病 | 属病害，确保通风并清除病叶 |
| 落花，结荚少 | 开花期干旱或高温 | 灌水并覆盖以降低地温 |
| 豆荚多但籽粒小 | 荚肥大期缺水或缺钾 | 灌水，施草木灰 |

&nbsp;&nbsp;&nbsp;区分缺水和过湿最可靠的方法是挖土查看。叶片萎蔫时，在植株旁挖开约10cm深的土，用手握一把。若松散易碎，是干旱；若结块并渗出水分，是过湿。这两种情况的处理方式完全相反，不加确认就浇水是危险的做法。红小豆地里叶片萎蔫的原因半数以上是过湿，若此时再浇水，植株就会直接死亡。

&nbsp;&nbsp;&nbsp;梅雨季实际要做的工作有三项。第一，检查沟里积水能否排到地块外，疏通被堵的地方。第二，若垄面上有积水处，添土使水能流走。第三，雨停后不要立即进地：踩踏湿土会使其变实，排水条件更差；碰到湿叶还会传播病害。要等雨停、土壤变干后再进地。

## 8. 栽培管理

### 8-1. 培土 - 三次

| 次数 | 时期 | 培土部位 |
|---|---|---|
| 第1次 | 真叶2-3片 | 培土到子叶节 |
| 第2次 | 真叶4-5片 | 培土到单叶节 |
| 第3次 | 真叶6-7片 | 培土到第1真叶节，须在开花前完成 |

&nbsp;&nbsp;&nbsp;培土对红小豆而言比对其他豆类更重要。它同时带来四种效果，其中两种直接针对红小豆的弱点。第一，垄台进一步增高，排水改善——湿害是红小豆的大敌，所以培土尤为重要。第二，幼小的杂草被埋入土中——红小豆没有可用的除草剂，这一点也有实际价值。第三，被埋入土中的茎节长出新根，吸收面积增加。第四，株基被埋，倒伏减少。

> **培土必须在开花前完成。开花后再进地翻动土壤，会导致落花、须根被切断，产量下降。**

&nbsp;&nbsp;&nbsp;若人手不足、无法做完三次培土，需分出主次：第3次最重要，其次是第1次。第3次把垄台培到最高，可防止梅雨季湿害并防止倒伏；第1次帮助幼苗扎根，并埋住这一时期的杂草；第2次省略也不会造成大的损失。

### 8-2. 杂草管理

| 时期 | 方法 | 备注 |
|---|---|---|
| 播种后2-3周 | 第1次除草，浅浅地刮松表土 | 与第1次培土兼做 |
| 播种后4-5周 | 第2次除草 | 与第2次培土兼做 |
| 开花前 | 完成所有除草 | 此后不再进地 |
| 第3次培土之后 | 用覆盖物覆盖 | 此后几乎不需要再动手 |

&nbsp;&nbsp;&nbsp;红小豆没有登记的除草剂，这在常规种植中是个麻烦，但在灾害条件下反而是有用的信息：这本来就是一直靠人工除草的作物，意味着即使没有农药，种植方式也不会改变，只是相应地需要确实投入劳动力。前一个月到一个半月的除草决定产量，此后叶片一旦覆盖地面，杂草就不会大量增加。

&nbsp;&nbsp;&nbsp;把覆盖和除草结合起来安排顺序，最能减少劳动量。第1次和第2次除草与培土兼做，第3次培土结束后，在垄面上盖上稻草、稻壳或割下的杂草。覆盖之前先把地彻底除一遍草再盖上，这样下面几乎不会再长新草。开花之后就不再需要进地，落花的顾虑也随之消失。

### 8-3. 倒伏与支柱

| 类型 | 管理 |
|---|---|
| 直立型 | 不需要支柱，仅靠培土即可 |
| 蔓生型 | 立起竹竿、树枝或玉米秆进行牵引 |
| 因氮肥过量而徒长 | 翌年减少施肥量，当年用绳子围绕支撑 |

&nbsp;&nbsp;&nbsp;蔓生型红小豆的支柱，在灾害条件下并不难搭建。玉米收获后若不砍掉秸秆而原样留在地里，第二年那个位置就能当支柱用。常见的做法是把三根秆捆成三角形立起来，或立两排秆、上方用横杆连接做成网状。不过红小豆的蔓并不算重，不需要非常牢固的结构，膝盖到腰部高度的支撑就足以让豆荚不接触地面，避免腐烂。

## 9. 病虫害

&nbsp;&nbsp;&nbsp;红小豆的病虫害压力为C。无防治减产率估计为48.9%，不进行防治就会损失近一半。红小豆的特点在于这一损失分摊在地里和仓库两处：地里被蝽象和落叶病夺走，仓库里则被红小豆象夺走。

### 9-1. 主要病害

| 病名 | 症状 | 发生条件 | 无药应对方法 |
|---|---|---|---|
| 病毒病（花叶病） | 叶片呈花叶状斑驳，生长停滞 | 由蚜虫传播 | 无法治愈，发现后立即拔除焚烧，并减少蚜虫 |
| 落叶病 | 从下部叶片开始褐变并大量脱落 | 真菌引起，会在连作地块的土壤中积累 | 3年以上轮作是唯一对策，须焚烧病株残体 |
| 褐色斑纹病 | 下部叶片出现褐色斑驳花纹 | 8-9月多湿 | 确保通风、喷波尔多液、清除病叶 |
| 褐斑病 | 叶背出现褐色斑点 | 多湿 | 开花前10天及开花期喷波尔多液 |
| 白粉病 | 叶片表面覆盖白色粉状物 | 干燥且通风不良时 | 牛乳5-10倍稀释液，确保通风 |
| 炭疽病 | 出现暗褐色病斑并落叶 | 多湿 | 种子挑选、轮作、波尔多液 |
| 根腐病 | 根部呈褐色腐烂，下部叶片发黄 | 过湿、连作 | 排水、抬高垄台、轮作 |

&nbsp;&nbsp;&nbsp;落叶病值得特别强调。它是红小豆连作适应性只能维持在B级的主要原因，也是在同一地块连续种植红小豆时最典型的障碍。病原真菌残留在土壤中并逐年增多，下部叶片从褐变到脱落，光合作用面积随之减少，籽粒无法充分灌浆。即便有农药，也很难彻底防治；在没有农药的条件下，轮作是唯一手段。必须休耕3年的标准，正是由这种病害决定的。

### 9-2. 主要害虫

| 害虫 | 发生时期 | 危害 | 无药防治方法 |
|---|---|---|---|
| 蝽象类 | 8月起增多 | 刺吸豆荚汁液，使籽粒空瘪 | 清晨捕杀、诱集作物、防虫网 |
| 红小豆象 | 在地里产卵，在仓库中孵化 | 蛀食种实，使内部中空 | 详见第15节 |
| 地老虎类 | 生育初期 | 从基部咬断幼茎 | 夜间拨土捕捉幼虫，株基周围撒灰 |
| 甜菜夜蛾 | 夏季 | 啃食叶片和豆荚 | 人工捕捉，卵块连叶一并摘除 |
| 蚜虫类 | 7-8月 | 刺吸汁液并传播病毒病 | 在叶背喷施肥皂水（水1L兑肥皂5g） |
| 鸟类 | 播种后不久 | 啄食子叶 | 出苗前用稻草或网覆盖 |
| 獐·狍 | 夏季 | 取食叶和茎 | 设围栏或拉网 |

&nbsp;&nbsp;&nbsp;地老虎是红小豆生育初期危害较大的害虫。幼虫白天藏在土里，夜间出来把幼茎从基部咬断，第二天早晨到地里一看，原本好好的植株就那样倒了。应对方法有两个：在倒伏植株周围用手指拨开2-3cm深的土，就能找到蜷缩的肥胖幼虫，将其捉出；另外在株基周围撒一圈细草木灰或稻壳，幼虫会不愿意穿过。

&nbsp;&nbsp;&nbsp;蝽象从8月起增多，与荚肥大期重叠。防治方法与大豆相同：清晨气温低时蝽象动作迟钝，可翻找豆荚下方，用手拂落到水桶里。也可以在地块周围种芝麻、粟或高粱进行诱集，再集中捕捉，同样有效。红小豆是自花授粉作物，开花期即使覆盖遮阳网或防虫网也不影响结实，如果面积不大，这种方法最为可靠。

### 9-3. 无药防治资材与农艺防治

| 资材 | 制作方法 | 防治对象 |
|---|---|---|
| 波尔多液 | 在100L水中分别溶入硫酸铜400g和生石灰400g后混合 | 真菌病、细菌病 |
| 肥皂水 | 水1L兑无香型肥皂5g | 蚜虫、螨类 |
| 牛乳稀释液 | 牛乳用水稀释5-10倍 | 白粉病 |
| 草木灰水 | 一升灰浸入10L水中一夜，取上层清液使用 | 抑制真菌 |
| 撒干灰 | 在有露水的清晨撒在叶片和株基周围 | 食叶害虫、地老虎 |
| 木醋液 | 稀释300-500倍 | 驱避 |
| 辣椒·大蒜水 | 捣碎后用水浸泡、过滤后使用 | 驱避 |

| 农艺防治 | 原理 |
|---|---|
| 3年以上轮作 | 落叶病和病毒病除轮作外别无对策 |
| 抬高垄台 | 红小豆一半以上的病害都与过湿有关 |
| 种子挑选 | 炭疽病和红小豆象会随种子传播 |
| 保证栽植距离 | 通风好则叶片干得快，真菌难以立足 |
| 覆盖 | 防止泥土溅起把病原菌带到下部叶片 |
| 雨后禁止进地 | 触碰湿叶会传播病原菌 |
| 焚烧病株残体 | 染上落叶病的叶片不留在地里 |
| 清理地埂 | 豆科杂草会成为蝽象和病毒病的中间宿主 |

> **在没有农药的条件下，红小豆防治的关键归结为两点：排水和轮作。这两者决定了红小豆病害的大部分结果。**
