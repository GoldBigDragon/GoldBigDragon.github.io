### 1-3. 強みをどう読むか

&nbsp;&nbsp;&nbsp;SSが付いた項目はタンパク質密度、施肥、施設負担、貯蔵性の四つで、Sは微量栄養素、水消費量、味、普及度、自家採種に付きました。この配列はダイズとほぼ同じですが、決定的な違いが一つあります。アズキは面積当たり熱量がDです。そのため、同じ強みの組み合わせを持ちながら総得点がダイズより9点低くなっています。

&nbsp;&nbsp;&nbsp;水消費量Aは実質的な強みです。総蒸発散量約400mmはダイズの450から700mmよりはっきり少なく、豆類の中ではリョクトウとササゲに次いで少ない値です。井戸が止まって水を汲んで運ばなければならない条件では、この差は小さくありません。ただし誤解しやすい点があります。水を少ししか使わないことと水に強いことは別です。アズキは水を少ししか使わない一方で、水がたまることに最も耐えられない作物です。干ばつには耐えますが、韓国の梅雨（チャンマ、6月下旬～7月）には枯れます。

&nbsp;&nbsp;&nbsp;収穫速度Bにも価値があります。100日から120日で収穫でき、6月中旬から下旬に植えて10月に収穫します。このスケジュールにより、ニンニク、タマネギ、オオムギ、ジャガイモを6月に収穫した後の後作としてアズキを使えます。一年に同じ畑で二回収穫することになり、畑が狭い条件で面積を二倍に使う効果を生みます。ダイズやソリテ（青大豆系の黒豆）ではできないことです。

&nbsp;&nbsp;&nbsp;貯蔵性SSと種子寿命A、自家採種Sが循環の輪を作ります。乾燥したアズキは常温で3年もちます。そのアズキの一部をそのまま翌年の種として使え、自家受粉なので形質が乱れません。ただし、貯蔵性の等級の横に付いた括弧を見落としてはいけません。ゾウムシを遮断した場合という条件です。

> **アズキの貯蔵性SSは条件付きの等級です。アズキゾウムシを防げなければSSではなくEになります。15節でこの問題を最も長く扱う理由です。**

### 1-4. 弱みをどう読むか

&nbsp;&nbsp;&nbsp;Eが付いた項目は耐寒性の一つで、Dは面積当たり熱量、永続性、日照反応、調理・加工、整地エネルギー、非食用価値に付きました。Cは温度適応幅と病害虫圧に、Bは収穫速度、防除自立度、連作適応性に付きました。

&nbsp;&nbsp;&nbsp;面積当たり熱量Dが最も大きな制約です。1㎡で660kcal、自給ラインの0.25倍です。大人一人がアズキだけで1日2,100kcalを満たそうとすると乾燥アズキ636gを食べる必要がありますが、実際には不可能です。食物繊維が100gあたり15gを超えて含まれており、それだけの量を食べると消化器が耐えられません。アズキは構造的に主食にはなり得ない作物です。畑の面積配分では全体の1割以内に収めるのが現実的です。

&nbsp;&nbsp;&nbsp;整地・掘削エネルギーDも同じ問題の別の側面です。熱量回収倍率は4.0倍にすぎません。畑を耕し畝を上げるのに費やした人力に比べて戻ってくる熱量が少ないという意味です。しかもアズキは湿害のため畝を高く上げる必要があり、整地労働が他の豆類より多くかかります。人力以外の動力がない条件では、この項目は実際に痛手になります。

&nbsp;&nbsp;&nbsp;連作適応性Bは表面上は悪くないように見えますが、実質的な負担は大きいです。3年休作群という言葉は、一度アズキを植えた畑に3年間アズキを植えられないという意味です。畑を四区画に分けられて初めて毎年アズキを収穫できます。続けて植えると落葉病とウイルス病が土に蓄積して収量が目に見えて崩れ、これらの病気には薬がありません。ダイズが1年休作で済むのと比べると、アズキは畑をはるかに多く要求する作物です。

&nbsp;&nbsp;&nbsp;病害虫圧Cに防除自立度Bが付いた組み合わせも読み取っておく価値があります。無防除時の減収率48.9%は、防除をしなければ半分を失うという意味で、その半分のかなりの部分が畑ではなく倉庫で失われます。防除自立度の根拠に貯蔵前の燻蒸が入っているのはそのためです。アズキは畑での収穫に成功しても貯蔵で失敗しうる作物です。

## 2. どんな植物か

### 2-1. 分類と原産地

&nbsp;&nbsp;&nbsp;アズキはマメ科（Fabaceae）ササゲ属（Vigna）の一年草です。リョクトウやササゲと同じ属で、ダイズとは属が異なります。この事実は実用的な意味を持ちます。アズキの病害虫と根粒菌の系統は、ダイズよりリョクトウやササゲに近いのです。接種源として使う土も、リョクトウやササゲを植えていた畑のもののほうがダイズ畑の土より相性が良いです。

&nbsp;&nbsp;&nbsp;原産地は東アジア、中国中北部から朝鮮半島にかけての地域です。野生の祖先であるヤブツルアズキ（Vigna angularis var. nipponensis）が今も韓国の野原や畑のあぜに生えています。夏に雨が集中し冬に霜が降りる気候に適応しており、韓国の土地で特別な保護なしに育ちます。ただし、野生のヤブツルアズキが生える場所を見るとアズキの性質が表れます。水がたまる田んぼのあぜの内側ではなく、水はけの良い畑のあぜや斜面、砂利が混じった場所に生えます。

### 2-2. 形態

| 器官 | 特徴 |
|---|---|
| 葉 | 3枚が一組になった三出複葉です。心臓形に近い形をしています |
| 茎 | まっすぐ立ち、高さ30-50cmです。ダイズより低く、枝分かれします。つる性品種は1mを超えます |
| 根 | 真っすぐな主根から細根が伸びます。根粒は細根に付きます |
| 花 | 黄色です。蝶形で自家受粉します |
| 莢 | 細長い円筒形です。熟すと褐色になります。1莢に種子が6-10個入ります |
| 種実 | 赤いアズキが基本で、黒アズキ、白アズキ、斑（まだら）アズキもあります。へそが白い線として見えます |

&nbsp;&nbsp;&nbsp;アズキの花が黄色であることは、ダイズと見分ける手軽な目印です。ダイズは白または淡い紫色で、アズキは鮮やかな黄色です。また、アズキは花が一度に咲きません。茎が伸びるにつれて下から上へと次々に花が咲き、下の莢が熟していく間も上ではまだ花が咲いています。この性質が収穫時期の判断を難しくしており、12節で扱う判断基準が必要になる理由です。

&nbsp;&nbsp;&nbsp;草丈が30cmから50cmと低いことも重要です。ダイズよりずっと低く、そのため二つの結果が伴います。第一に、倒伏の心配が少なく支柱が要りません。第二に、莢が地面に近い位置に付くため土に触れたり湿気を受けたりしやすくなります。土寄せで畝を高くし、マルチングで土を覆うことがアズキで特に価値を発揮する理由です。

### 2-3. 生育段階

| 段階 | 時期 | 主な生理 | 重要な養分 |
|---|---|---|---|
| 発芽・幼苗期 | 播種から3週間 | 発芽と初期生育、根粒の形成が始まります | リン酸、少量の窒素 |
| 栄養生長期 | 3-6週 | 茎と葉が増え、根粒の働きが活発になります | 窒素は根粒が供給 |
| 開花期 | 6-8週 | 黄色い花が下から上へ順に咲きます | リン酸、ホウ素 |
| 莢肥大期 | 8-10週 | 莢と種子が大きくなります | カリウム、リン酸 |
| 成熟・収穫期 | 10-14週 | 下の莢から褐色に熟していきます | 灌水を中断 |

> **幼苗期が湿害に最も弱い時期です。播種直後に梅雨と重なると、若いアズキは根が傷んでそのまま枯れます。6月中旬から下旬の播種が梅雨と重なる年は、畝の高さが生死を分けます。**

&nbsp;&nbsp;&nbsp;アズキの生育段階で特徴的なのは、開花が長く続くことです。ダイズは2週間ほどで開花を終えますが、アズキは3-4週間にわたって花を咲かせ続けます。良い面から見れば、ある時期の高温や干ばつですべてを失うことがないという意味です。悪い面から見れば、熟す時期がばらけて一度に収穫できないという意味になります。慣行で莢が70-80%熟したときに一度に収穫するとされているのは、この問題への妥協案です。

&nbsp;&nbsp;&nbsp;発芽温度も注目すべき点です。アズキの発芽最適温度は32-34℃で、他の豆類よりはっきり高い値です。最低限界が6-10℃で、15℃以上でなければ発芽と初期生育が正常になりません。これがアズキを6月に植える理由です。4月や5月に植えると土が冷たく発芽が遅れ、その間に種子が腐ります。遅く植えるのは怠慢ではなく生理的な要求です。

### 2-4. 100gあたりの栄養

| 栄養素 | 含有量 | 備考 |
|---|:---:|---|
| 熱量 | 330-356kcal | 乾燥アズキ基準です。ダイズより低い値です |
| タンパク質 | 20.63g | 熱量に占める割合は25.0%です |
| 炭水化物 | 約60g | ダイズより多く、でんぷんの比率が高いです |
| 脂質 | 0.5-1g | 非常に少ないです。酸敗のリスクが低く貯蔵に有利です |
| 食物繊維 | 14.9-16.9g | 玄米の3倍を超えます |
| ビタミンB1（チアミン） | 0.66mg | 穀類と豆類の中でも際立って多い量です |
| ビタミンB2 | 0.14mg | |
| カリウム | 豊富 | 塩分摂取が増えたときにバランスを取ります |
| カルシウム・鉄・リン | 豊富 | 肉類や乳製品がないときに重要です |
| アントシアニン | 種皮に豊富 | 赤色と黒色の原因です |
| サポニン | 豊富 | 泡の原因です。ゆでるときは最初のゆで汁を捨てます |
| 糖類 | 0.43g | 非常に少ないです。アズキの甘さは砂糖に由来します |

&nbsp;&nbsp;&nbsp;ビタミンB1については特に強調しておく必要があります。0.66mgは成人の1日推奨量の半分を超える量で、白米の10倍ほどの水準です。ビタミンB1は炭水化物をエネルギーに変える過程で欠かせない栄養素で、不足すると脚気になります。足がしびれてむくみ、力が抜け、悪化すると心臓の機能が低下します。精米した白米を主食としながらおかずが乏しい食事で実際に現れる病気です。

&nbsp;&nbsp;&nbsp;災害時の状況を考えると、この組み合わせが意味を持ちます。熱量を米やジャガイモで満たすとビタミンB1が不足しがちで、そのときアズキ一握りがその空白を埋めます。アズキご飯が味の問題ではなく栄養の問題を解決する方法であるという点は、モロコシに豆を混ぜる習慣と同じ論理です。

&nbsp;&nbsp;&nbsp;脂質が1%未満と非常に少ないことも記録しておく価値があります。ダイズの16%、ラッカセイの50%近くと比べるとほとんどない水準です。熱量が低い原因ですが、同時に貯蔵に有利な条件でもあります。脂質が少ないと酸敗しないため、乾燥アズキは数年経っても臭いが出ません。挽いて粉にしてもダイズ粉よりはるかに長持ちします。
