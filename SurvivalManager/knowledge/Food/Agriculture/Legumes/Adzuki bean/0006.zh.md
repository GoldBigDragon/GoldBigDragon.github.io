## 14. 毒性与抗营养成分

&nbsp;&nbsp;&nbsp;红小豆只要充分煮熟就是安全的食品。它所含的防御性物质不像大豆或菜豆那样强烈，危险程度较低，但生吃或半生食用会引起消化不良，因为其中含有豆科植物共有的抗营养成分。

### 14-1. 抗营养成分的真相

| 成分 | 作用 | 症状 | 去除方法 |
|---|---|---|---|
| 胰蛋白酶抑制剂 | 阻碍蛋白质分解酶胰蛋白酶的作用 | 腹痛、腹泻、蛋白质利用率下降 | 浸泡6小时后在100℃下加热30-60分钟 |
| 凝集素 | 附着在肠黏膜上妨碍吸收 | 腹痛、呕吐、腹泻 | 浸泡后在沸水中充分加热 |
| 皂苷 | 起泡并刺激肠胃 | 胃部不适并腹泻 | 倒掉第一遍煮水，撇去泡沫 |
| 植酸 | 与铁、锌、钙结合，阻碍其吸收 | 长期食用会导致贫血、锌缺乏 | 通过浸泡、发芽、发酵可减少60-80% |
| 单宁 | 产生涩味并妨碍铁的吸收 | 涩味 | 浸泡并倒掉第一遍水 |
| 低聚糖 | 人体无法消化，由肠道细菌发酵 | 腹部胀气 | 倒掉浸泡水和第一遍煮水 |

> **红小豆的皂苷含量特别高。煮制时产生的泡沫就是皂苷，倒掉这第一遍煮水是红小豆烹饪的第一步。不倒掉的话会又涩又腹痛。**

&nbsp;&nbsp;&nbsp;红小豆的皂苷具有两面性。过量摄入会刺激肠胃引起腹泻和腹痛，但适量摄入则有抗氧化作用并能利尿。冬至喝红豆粥能消除身体浮肿这一古老说法，正是人们凭经验发现了这种利尿效果。倒掉第一遍煮水后，过量摄入的风险就会消失，而残留皂苷的益处仍会保留。

&nbsp;&nbsp;&nbsp;凝集素的危险程度因豆类种类而异。红小豆的凝集素毒性远低于菜豆类(Phaseolus)的凝集素。菜豆哪怕只生吃四五粒，也会在数小时内引发剧烈呕吐和腹泻，因菜豆未煮熟而中毒的事例已有多次报告。菜豆类尤其存在一个区间：长时间低温加热反而会使凝集素活性升高，因此长时间浸在温水中烹煮最为危险。红小豆没有这么极端，但原则相同。在沸水中加热足够长的时间，是唯一安全的做法，而未煮熟的豆比生豆更危险这一事实同样适用。

### 14-2. 浸泡与加热的标准

| 处理 | 时间·温度 | 效果 |
|---|---|---|
| 浸泡 | 常温水中浸泡6小时 | 热量能透到豆芯。部分皂苷和低聚糖会溶入水中 |
| 倒掉浸泡水 | 务必 | 其中溶有皂苷、低聚糖、单宁 |
| 倒掉第一遍煮水 | 煮5-10分钟后倒掉水，换新水再煮 | 这是红小豆烹饪的关键步骤，涩味和泡沫会消失 |
| 正式煮制 | 在沸水中煮40-60分钟 | 胰蛋白酶抑制剂和凝集素会失活 |
| 高压烹煮 | 120℃下10-15分钟 | 耗费燃料最少 |
| 余热焖煮 | 煮15分钟后放入保温箱2小时 | 燃料消耗降到一半以下 |
| 检查是否煮熟 | 用手指一按就能轻易碾碎 | 若留有硬芯，说明还没煮熟 |

&nbsp;&nbsp;&nbsp;红小豆比大豆浸泡时间短，加热时间也短。大豆需要浸泡8小时、加热超过一小时，而红小豆只需浸泡6小时、加热40到60分钟。这是因为种皮薄、几乎不含脂肪，热量传导得快。在燃料紧缺的条件下，这是实实在在的优势。

&nbsp;&nbsp;&nbsp;不要跳过倒掉第一遍煮水这一步，这一点很重要。只靠浸泡，皂苷排不干净。煮5到10分钟后会冒出浓浓的泡沫，那就是皂苷，要倒掉这些水，重新倒入新水再煮。跳过这道工序的红小豆会又涩，吃后肠胃也会不舒服。在缺水的情况下这样做似乎可惜，但倒掉的水可以浇地或用来洗碗，并不算浪费。

### 14-3. 发芽与发酵

| 方法 | 减少的成分 | 程度 |
|---|---|---|
| 发芽 | 植酸、胰蛋白酶抑制剂、低聚糖 | 植酸减少50-70%，抑制剂减少30-40% |
| 发酵 | 植酸、抑制剂、低聚糖 | 大部分被分解，吸收率提高 |
| 浸泡并倒掉第一遍水 | 皂苷、单宁、低聚糖 | 相当一部分会被去除 |

&nbsp;&nbsp;&nbsp;红小豆也能发芽，发芽后会产生维生素C。这在冬季没有新鲜蔬菜时是一项有用的特性。不过，红小豆芽并未融入韩国的饮食文化，其风味和口感也比不上黄豆芽或绿豆芽。若是想做成凉拌菜食用，最好选用绿豆（绿豆芽）或大豆（黄豆芽），红小豆的发芽主要用作降低抗营养成分、便于消化的处理手段。将浸泡过的红小豆用湿布包好放置约一天，待刚开始冒芽时煮熟，会比直接煮更容易消化，营养吸收也更好。

## 15. 无冰箱贮藏 - 红小豆象

&nbsp;&nbsp;&nbsp;红小豆的耐储性为SS级，但附带条件：必须挡住豆象。红小豆脂肪含量不到1%，几乎不会酸败，晒干的红小豆即使过了3年也不会有异味。只要干燥到位，霉变也基本不成问题。红小豆贮藏失败的原因实际上只有一个，那就是红小豆象。

> **红小豆不是因为腐烂而损失，而是被虫子吃掉而损失。贮藏的技术，说到底就是防住红小豆象的技术。**

### 15-1. 干燥优先

| 阶段 | 方法 | 确认 |
|---|---|---|
| 预备干燥 | 连秸秆一起摊在草席上晾4-6天 | 直到豆荚一拧就啪地裂开 |
| 脱粒后干燥 | 摊薄在草席上晒2-3天 | 要经常翻动，使其干燥均匀 |
| 目标含水率 | 12%以下 | 咬下去牙齿咬不进去，啪地裂开 |
| 食盐测试 | 在干燥的瓶中放入红小豆和炒盐一起摇晃 | 如果盐粘在瓶壁上，说明还需要再晾干 |
| 冷却 | 完全放凉后再装 | 温热状态下密封会产生冷凝水 |

&nbsp;&nbsp;&nbsp;红小豆的目标含水率12%比大豆的12-13%略低一些，原因就是豆象。含水率一旦超过13%，红小豆象的繁殖速度就会明显加快。降到12%以下繁殖就会变慢，降到10%以下则几乎停止。但若晒得过干、降到9%以下，种皮就会裂开破碎，若作种用则发芽力也会下降。11-12%是理想的平衡点。

### 15-2. 红小豆象的生活史与阻断

&nbsp;&nbsp;&nbsp;要理解红小豆象(Callosobruchus chinensis)，首先要知道这种虫子是从田间就开始活动的。成虫会在还长在地里的豆荚上产卵。卵比小米粒还小，紧贴在种皮上，不易被发现。收获后运入储藏处，卵便会孵化，幼虫钻透种皮进入豆粒内部，一边蚕食一边长大。外表看起来完好，内部却渐渐被掏空。长大后会咬出一个圆孔钻出来交配，再次产卵。一代仅需25-30天，虫口数量会呈几何级数增长。

| 时间点 | 发生的情况 | 应对 |
|---|---|---|
| 田间 | 成虫在豆荚上产卵 | 开花后架设防虫网，不可延迟收获 |
| 收获后 | 卵附着在种皮上一同进入储藏处 | 用水漂浮法拣出被蛀食的豆粒 |
| 贮藏初期 | 卵孵化，幼虫钻透种皮 | 完全密封，低温·高温处理 |
| 贮藏1个月 | 幼虫在豆粒内部生长 | 外表无法察觉 |
| 贮藏2个月 | 成虫咬穿孔洞钻出 | 此阶段才第一次能被肉眼发现 |
| 贮藏6个月 | 整袋都变成虫壳和粉末 | 已无法挽回 |

| 方法 | 原理 | 应用 | 效果 |
|---|---|---|---|
| 完全密封 | 断绝氧气使其窒息 | 装满玻璃瓶或金属罐后密封 | 最为可靠，3-4周内连卵和幼虫都会死亡 |
| 掺草木灰 | 细微颗粒刮擦外骨骼蜡质层使其脱水 | 掺入红小豆体积的2-5% | 食用前用水冲洗干净，也可用于种用豆 |
| 硅藻土 | 硅质外壳会损伤其外骨骼 | 每1kg红小豆加1-3g | 效果比草木灰更好，但只在干燥状态下起作用 |
| 涂油 | 油膜能阻止产卵与孵化 | 每1kg红小豆加2-5mL食用油揉匀 | 效果显著，但不可用于种用豆 |
| 低温处理 | 零下低温可杀死卵和幼虫 | 严冬时放到室外几天后再收回 | 10月收获后冬天很快就到 |
| 高温处理 | 60度可杀死卵和幼虫 | 摊薄在阳光下晒半天 | 不可用于种用豆 |
| 12度以下低温保存 | 繁殖实际上会停止 | 地下室、朝北房间、地窖 | 是红小豆贮藏的理想条件 |
| 干辣椒·花椒·艾草·大蒜 | 精油成分能抑制产卵 | 一层层放入 | 属于辅助手段 |
| 埋入草木灰中 | 兼具密封与物理防治效果 | 在缸中一层灰一层红小豆叠放 | 自古以来被广泛使用 |

&nbsp;&nbsp;&nbsp;最重要的是完全密封。虫子也要呼吸。在密封容器中，红小豆和虫子消耗氧气，氧气减少、二氧化碳升高，虫子就会死亡。红小豆处于休眠状态，能承受这种条件。容器装得越满、空隙越少，效果就越快；与其用一个大容器，不如分装进多个小容器并装实装满，这样即使有一个容器坏了，也不会损失全部。

&nbsp;&nbsp;&nbsp;红小豆有一个利于低温处理的条件。它在10月收获，干燥和精选一结束很快就是隆冬。把密封容器放到室外几天，让其经受零下的气温，卵和幼虫就会死亡。再拿回室内时不要马上打开容器，先在室内放半天让温度回升后再开。若把冰凉的容器立刻打开，内壁会结露，成为霉菌滋生的根源。常规做法中使用的熏蒸消毒，很大程度上可以由这种低温处理来替代。

&nbsp;&nbsp;&nbsp;草木灰要挑选细的来用。用筛子筛掉粗炭块，只取细的部分，按红小豆体积的2-5%掺入，薄薄地裹在每一粒豆子上。红色的红小豆会变得灰蒙蒙的，但食用前用水冲洗三四遍就能恢复原色。虫子无法产生抗性、对人体无害，而且种用红小豆也能使用，这些都是比涂油更好的优点。

### 15-3. 储藏容器与场所

| 容器 | 密封性 | 期限 | 备注 |
|---|:---:|---|---|
| 玻璃瓶 | 非常好 | 3年以上 | 可以用肉眼确认状态，但挡不住光 |
| 金属罐 | 非常好 | 3年以上 | 能完全挡住老鼠和虫子，但要注意冷凝水 |
| 陶缸 | 好 | 2-3年 | 温度变化缓慢，老鼠咬不透 |
| 厚塑料袋 | 一般 | 1年 | 会被老鼠咬破，也可能被豆象咬穿 |
| 地窖 | 好 | 2-3年 | 温度能保持在12度以下，但一旦渗水就会全部损失 |

| 保存条件 | 目标 |
|---|---|
| 温度 | 12度以下为理想，越低越好 |
| 湿度 | 空气湿度65%以下 |
| 光照 | 完全遮挡 |
| 位置 | 地下室或朝北房间，垫高离地放置 |
| 检查 | 每月一次，比大豆检查得更勤 |

&nbsp;&nbsp;&nbsp;红小豆比其他豆类需要更勤地检查。红小豆象一代仅一个多月，若两个月才检查一次，可能早已超过一代的时间。每月检查一次：摇晃容器、贴耳听声音、查看表面是否有圆孔。一旦发现一个孔洞，说明虫害已经扩散得相当严重，此时应将全部豆子取出，用水漂浮法拣出空豆，晒干后掺入草木灰或食用油，再重新密封。

## 16. 烹饪与加工

### 16-1. 红小豆的烹饪

| 食物 | 步骤 | 保存 | 价值 |
|---|---|---|---|
| 红豆饭 | 泡发的红小豆倒掉第一遍水煮过后，与大米一起焖煮 | 随做随吃 | 补充大米中不足的维生素B1和赖氨酸 |
| 红豆粥 | 红小豆煮烂后捣碎，与谷物一同熬煮 | 可存放数日 | 耗费燃料较多，但易消化，热量集中 |
| 红豆碎 | 煮好的红小豆捣碎或整粒用于年糕 | 可存放数日 | 与年糕一起吃就是谷物与豆类的组合 |
| 红豆沙 | 煮好的红小豆过滤去皮后熬煮浓缩 | 阴凉处可放数日，晒干后可放数月 | 加了甜味剂能存放更久 |
| 红豆水·红豆茶 | 炒过的红小豆加水煮开 | 随做随喝 | 需要烧水饮用时，可同时获得风味与矿物质 |
| 红小豆干粉 | 煮熟晒干后磨粉 | 密封可存2-3个月 | 不含脂肪，磨成粉也不易变质 |
| 红小豆发酵 | 煮好的红小豆放在温暖处两三天 | 可存放数日 | 抗营养成分减少，更易消化 |

&nbsp;&nbsp;&nbsp;红小豆烹饪中要牢记的原则是分两阶段煮。泡发的红小豆先煮5-10分钟倒掉第一遍水，再加新水煮40-60分钟。第一遍水会带走皂苷、单宁和低聚糖，经过这一步涩味会消失，肠胃也会更舒服。红豆粥或红豆饭做失败，大多是因为省略了这一步。

&nbsp;&nbsp;&nbsp;红小豆粉不易变质这一点，在灾难条件下十分宝贵。大豆粉脂肪含量达16%，几个月就会散发酸败味，而红小豆脂肪不到1%，磨成粉也能存放很久。煮熟晒干磨粉后，可以用水调开煮成粥食用，也可以掺入年糕中。在需要转移的情况下，这是一种重量轻、营养密度高的形态。

&nbsp;&nbsp;&nbsp;红小豆的甜味并非来自红小豆本身。其糖类含量仅0.43g，几乎可以忽略。红豆粥和红豆沙的甜味全部来自砂糖或蜂蜜。一旦没有甜味剂，红小豆就会以无甜味的状态被食用，那种状态下的红小豆香浓质朴，但并不甜。事先知道这一点就不会感到失望。若需要甜味，可搭配甜高粱糖浆、用麦芽糖化制成的jocheong（麦芽糖稀）、或熬煮浓缩的甘薯或甜菜。

### 16-2. 节省燃料的烹饪

| 方法 | 燃料 | 步骤 |
|---|:---:|---|
| 高压烹煮 | 最少 | 将泡发的红小豆加压10-15分钟 |
| 余热焖煮 | 非常少 | 倒掉第一遍水后煮15分钟，关火后用稻草·谷壳箱或被子包裹焖2小时 |
| 用大锅一次煮足 | 较少 | 一次煮出够吃数日的量，再分次食用 |
| 红豆茶 | 较少 | 将炒好的红小豆用水煮几分钟 |
| 红小豆干粉 | 几乎不需要 | 煮熟晒干磨粉备用，用水调开食用 |
| 发酵 | 预先投入 | 煮一次并发酵好后，之后所需燃料就会减少 |

&nbsp;&nbsp;&nbsp;使用余热焖煮时需要注意。保温箱内的温度维持在80度左右，这可能不足以彻底破坏凝集素和胰蛋白酶抑制剂。因此，倒掉第一遍水后正式煮制时，最初的煮制时间要保证在15分钟以上，取出时要确认红小豆用手指能否轻易碾碎。如果留有硬芯，就要再煮一次。

&nbsp;&nbsp;&nbsp;一次煮出够吃数日的量，这种方式对红小豆来说尤其高效。红小豆煮好后可以存放数天食用，冬天则能存放更久。生一次火时把锅装满煮熟再分开保存，能大大节省燃料。不过夏天煮熟的红小豆两天就会变质，所以只煮当天能吃完的量。

## 17. 全年作业日程

| 月份 | 作业 | 要点 |
|---|---|---|
| 1月 | 检查贮藏的红小豆，进行种子发芽试验 | 将密封容器放到室外几天，兼作低温处理 |
| 2月 | 规划田地，翻堆肥 | 确认能保证3年休作的地块 |
| 3月 | 撒石灰，完成堆肥 | 不必等到播种前3-4周，提前施入也可以 |
| 4月 | 管理前茬作物，改良排水 | 黏土地要掺入沙子·谷壳·腐叶土 |
| 5月 | 准备收获前茬作物，备好接种土 | 提前挖好种过红小豆、绿豆、豇豆地块的土 |
| 6月 | 收获前茬作物，挖排水沟，起垄，播种（中旬至下旬） | 垄高做到25-30cm，防涝措施就是关键所在 |
| 7月 | 第1·2次培土，除草，梅雨季排水 | 刚下过雨时不要进地 |
| 8月 | 第3次培土，覆盖，开花，检查根瘤，监测蝽象 | 培土要在开花前完成 |
| 9月 | 豆荚膨大，灌溉，捕杀蝽象，标记留种植株 | 给成熟期一致的植株系上绳子 |
| 10月 | 收获，干燥，脱粒，精选，秸秆还田 | 豆荚七八成成熟时一次性收获 |
