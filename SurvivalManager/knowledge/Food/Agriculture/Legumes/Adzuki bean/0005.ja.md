## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然素材での対処 |
|---|---|---|
| 葉全体が薄い黄色で個体が小さい | 窒素欠乏。アズキでは根粒不良が最も多い原因です | まず根を掘り出し根粒を割って確認します。根粒がなければ翌年の接種を確実にし、当年は尿10倍希釈液を少量与えます |
| 葉の縁が褐色に枯れて内側に巻く | カリウム欠乏 | 草木灰を株間にまいて軽くすき込みます |
| 生育が遅く葉が紫がかる | リン酸欠乏 | 骨粉、焼いた魚の骨の粉、草木灰。アズキはリン酸要求が大きいです |
| 花は咲くが莢が付かない | ホウ素欠乏、または開花期の高温・乾燥 | 材料が多様な堆肥。当年は灌水とマルチングで温度を下げます |
| 葉脈は緑だが葉脈の間が黄色い | 鉄またはマグネシウム欠乏。アルカリに傾いた土 | 灰の使用をやめます。腐葉土と完熟堆肥で有機物を増やします |
| 新葉が小さく奇形で生長点が枯れる | カルシウムまたはホウ素欠乏 | 卵の殻を焼いた粉、貝殻の粉 |
| 葉だけ濃い緑で茂り莢が少ない | 窒素過剰 | 窒素の供給を止めます |
| 草丈が徒長し下のほうの莢が熟さない | 窒素過剰または密植 | 翌年は施肥量と栽植密度を減らします |
| 下葉が黄色く根が褐色に腐った | 過湿。肥料の問題ではありません | 直ちに溝をさらって水を抜きます |
| 下葉に褐色の斑が広がり大量に落ちる | 落葉病。栄養の問題ではありません | 病葉を取り除き3年以上輪作します |
| 莢は多いが粒が小さくしなびている | 莢肥大期の水分またはカリウム不足 | 灌水、草木灰 |
| 種皮の赤色が薄くまだらになる | 登熟不足 | 播種を早めます。色素は登熟後半に蓄積します |

&nbsp;&nbsp;&nbsp;アズキで葉が黄色くなる症状には原因が四つもあります。窒素不足、過湿、落葉病、そして成熟期の正常な老化です。対処がまったく異なるため、見分けることが重要です。見分け方は、5節で扱った根の確認と4節の土の確認を併せて使うことです。根を掘り出して根粒がなければ窒素不足、根粒はあるのに根が褐色に腐っていれば過湿、根は無事なのに下葉に褐色の斑が広がれば落葉病です。成熟期であれば何もしなくて構いません。

&nbsp;&nbsp;&nbsp;リン酸欠乏は特に注意深く見ておく必要があります。アズキの施肥基準ではリン酸が4から6kgとダイズより多いのですが、これはアズキの根粒が小さく数も少ないため、窒素固定の効率をリン酸で支える必要があるからです。リン酸が不足した畑では根粒ができても内側が赤くならず、結果として窒素不足の症状が現れます。この場合、窒素を与えるのではなくリン酸を与えるのが答えです。化学肥料がないときのリン酸の現実的な供給源は、骨粉と魚の骨を焼いて砕いた粉、そして草木灰です。

&nbsp;&nbsp;&nbsp;微量元素の欠乏には一つずつ対応するのが困難です。化学肥料なしにモリブデンやコバルトを手に入れる方法は事実上ありません。その代わり、野菜くず、果物の皮、卵の殻、魚の骨、落ち葉、雑草、灰を一緒に混ぜて腐らせた堆肥には微量元素が満遍なく含まれています。堆肥場には何でもかんでも入れるという原則が、現実的な戦略になります。

## 11. 間作と輪作 - 連作障害

### 11-1. 相性

| 相性 | 作物 | 理由 |
|---|---|---|
| 良い | トウモロコシ、モロコシ、アワ | 間作が可能です。アズキが固定した窒素をそばで分けてもらえます |
| 良い | ニンニク、タマネギ、オオムギ（前作） | 6月に収穫した跡地にアズキを植えます。アズキの播種期と正確にかみ合います |
| 良い | ジャガイモ（前作） | 6月下旬に収穫した跡地にアズキを植えます |
| 良い | マリーゴールド | 根の分泌物が線虫を抑えます |
| 普通 | ハクサイ・キャベツの仲間 | アズキの翌年に植えると残った窒素を使えます |
| 悪い | トマト・トウガラシ・ナス | 病害虫を共有します |
| 悪い | ダイズ、リョクトウ、ササゲ、ラッカセイなどのマメ科 | 同じ病原菌と線虫が蓄積します |
| 悪い | アズキの連作 | 落葉病とウイルス病が土に蓄積します |

&nbsp;&nbsp;&nbsp;前作との関係がアズキの最大の利点です。ニンニク、タマネギ、オオムギ、ジャガイモはすべて6月に収穫され、アズキの播種適期は6月中旬から下旬です。時期が正確にかみ合い、一つの畑で一年に二回収穫することになります。さらに、これらの前作はアズキと病害虫をほとんど共有しません。ニンニクとタマネギはネギの仲間、オオムギはイネ科、ジャガイモはナス科で、アズキとは系統が遠いからです。ただし、ニンニクとタマネギの分泌物が根粒菌を抑制するという観察があるため、その跡地にアズキを植えるときは接種を特に確実に行います。

&nbsp;&nbsp;&nbsp;トウモロコシとの間作には注意が必要です。アズキは40%遮光で収量が半分に落ち、草丈が30-50cmと低いためトウモロコシの陰にすっぽり入ってしまいます。ダイズより不利です。混植するならトウモロコシを南北方向にゆったり間隔を空けて立て、その間にアズキを二条ほど入れる程度にとどめるべきで、畑にゆとりがあるなら別々にするほうがよいでしょう。

### 11-2. 連作障害と輪作

| 項目 | 基準 |
|---|---|
| 休作期間 | 3年以上。豆類の中でも長いほうです |
| 理想的な周期 | 4年 |
| 連作障害の原因 | 落葉病、ウイルス病、根腐れ病、線虫が土に蓄積します |
| 他のマメ科との関係 | アズキのあとにダイズやリョクトウを植えても連作とみなします |

> **アズキの連作障害は、土に蓄積した落葉病のカビとウイルスから来ます。薬で治すことはできず、畑を空ける時間だけが解決します。アズキを毎年収穫するには畑を四区画に分ける必要があります。**

&nbsp;&nbsp;&nbsp;3年休作という条件が実際に何を意味するのか、確認しておきましょう。畑を四区画に分け、毎年一区画だけにアズキを植えると、各区画は3年休んで4年目に再びアズキを受け入れます。この方式なら毎年アズキを収穫できますが、アズキに割り当てられる面積は全体の25%に固定されます。アズキの面積当たり熱量がDであることを考えれば、これは受け入れられる比率です。むしろアズキに畑の25%を割くのは多すぎるかもしれません。

&nbsp;&nbsp;&nbsp;注意すべき点は、他のマメ科作物も休作期間に含まれるということです。アズキを収穫した跡地に翌年ダイズやリョクトウやササゲを植えると、土の病原菌や線虫にとっては連作になります。特に同じ属であるリョクトウとササゲは病害をほぼそのまま共有するため、最も避けるべきです。マメ科はマメ科同士で一つの区画にまとめて管理するのが原則です。

| 4年輪作の例 |
|---|
| 1年目：ニンニク・タマネギ（前作）のあとアズキ |
| 2年目：トウモロコシ、モロコシ、アワなどイネ科の穀物 |
| 3年目：ハクサイ、キャベツ、ダイコンなどの葉菜類と根菜 |
| 4年目：ジャガイモまたはサツマイモ |
| 再びアズキ |

&nbsp;&nbsp;&nbsp;畑が狭くて四区画に分けられない場合、二つの妥協策があります。第一に、アズキを毎年植えず2年か3年に一度だけ植えます。植える年にたっぷり収穫して貯蔵しておけば、アズキは3年もつので毎年植える必要がありません。貯蔵性SSがこの戦略を支えます。第二に、畑の中で列の位置を移します。去年アズキだった列に今年はトウモロコシを、去年トウモロコシだった列に今年はアズキを植えます。完全な輪作ではありませんが、病原菌の蓄積をかなり遅らせます。

## 12. 収穫と脱穀

### 12-1. 収穫時期の判断

&nbsp;&nbsp;&nbsp;アズキは茎が伸びながら下から上へと花が咲き続けるため、熟す時期がばらけます。下のほうの莢が完全に褐色になったときも、上のほうにはまだ緑の莢が付いています。そのため収穫時期の判断が他の豆類より難しくなります。

| 判断基準 | 内容 |
|---|---|
| 莢 | 全体の70-80%が褐色に熟したとき一度に収穫します |
| 開花後の経過 | 開花後50-55日 |
| 粒 | 噛むと歯が入らずぽきっと割れます。種皮が濃い赤色です |
| 葉 | 下葉が黄色くなって落ちます |
| 時期（韓国中北部） | 10月上旬-中旬 |
| 時期（韓国南部） | 10月中旬-下旬 |

&nbsp;&nbsp;&nbsp;70-80%熟したときに収穫するという基準は、妥協の産物です。それ以上待つと下のほうの莢が裂けて粒が地面に落ち、それより早く収穫すると上のほうの莢の粒が十分に充実せずしなびます。二つの損失を合わせて最も少なくなる点が70-80%なのです。熟した莢を何回かに分けて摘む方式も可能ですが労働が何倍にもなり、災害時の条件では一度に収穫するほうがたいてい合理的です。

> **アズキは熟した莢が乾くと自然に裂けます。これを脱粒といい、収穫が遅れると30%まで失います。下のほうの莢を手でひねったときにぱちっと開き始めたら、それ以上待ちません。**

&nbsp;&nbsp;&nbsp;小面積の自給用であれば、分けて摘む方式も検討する価値があります。熟した莢だけを手で摘んで集め、一週間後にまた摘み、そうして三回ほど繰り返すと損失がほとんどなく、総収量も増えます。アズキの莢は長くて目立つため摘み取りは難しくありません。人手があって面積が小さいなら、この方法が最も多く収穫できます。

### 12-2. 収穫のこつ

| 順序 | 内容 |
|---|---|
| 1 | 晴れて乾燥した日、露が乾いた午前10時以降に収穫します |
| 2 | 鎌で茎の根元を刈ります。根粒の窒素を残すため根は土に残します |
| 3 | むしろや布の上に移します。畑で引きずると熟した莢が裂けて粒が落ちます |
| 4 | 4-6日広げて乾かします。雨が降ったらすぐに取り込みます |
| 5 | 莢がからからに乾き、ひねるとぱちっと開くようになったら脱穀します |

&nbsp;&nbsp;&nbsp;アズキの収穫で最も損失が出る瞬間は、刈って運ぶ動作です。すでに熟した莢は乾いた状態なので、触れたり揺れたりすると裂けます。そのため、畑にむしろや古い布をあらかじめ広げておき、刈るとすぐにその上に寝かせる方式が良いです。刈って引きずって運び出せば、その道筋に粒をまいているようなものです。袋に入れて運ぶ方法もあり、袋の中で裂けた粒はそのまま集まるので損失がありません。

### 12-3. 脱穀 - 道具なしでする方法

| 方法 | 道具 | 手順 | 効率 |
|---|---|---|---|
| 袋踏み | 厚い麻袋 | 乾いたアズキの茎を袋に半分ほど入れ、口を縛って足で踏みます。十回ほど踏んだら振って位置を変え、繰り返します | 少量に最も手軽で損失がほとんどありません |
| からさお | 長い柄に打ち棒を吊るした道具 | むしろに薄く広げ、上から打ち下ろします。二、三回裏返します | 中規模に適しています |
| 棒でたたく | 木の棒 | 袋に入れるかむしろに広げてたたきます | からさおの代わりです |
| 足でもみほぐす | なし | むしろに広げ、靴を履いた足でもみながら回します | 少量に適しています |
| 板に打ちつける | 板または桶 | アズキの茎の束をつかみ、桶の内側の壁に打ちつけます | 粒が桶の中に集まり損失が少ないです |
| 手でむく | なし | 莢を手で押して開きます | 種子用の少量に使います。粒がまったく傷みません |

&nbsp;&nbsp;&nbsp;アズキは粒が小さく硬いため、脱穀はダイズより簡単です。莢がよく開き、粒が割れません。ただし粒が小さいため四方に飛び散りやすく、袋の中で行う方法が有利です。厚い麻袋に乾いたアズキの茎を半分ほど入れ、口をしっかり縛って足で踏むと、莢が開いて粒が袋の底に集まります。茎が短く砕けてきた頃が終わりの合図です。

&nbsp;&nbsp;&nbsp;脱穀の成否は乾燥にかかっています。乾き切っていないアズキの茎は、いくらたたいても莢が開きません。乾いた莢を手でひねったときにぱちっと開けば適期です。日差しの良い日の午後、茎が最もからからに乾いた時間帯に行うとずっと楽になります。

### 12-4. 精選 - 風で選り分ける

| 方法 | 原理 | 手順 |
|---|---|---|
| 風選（風で選る） | アズキの粒は重く、殻やくずは軽いです | 風のある日に箕や器に入れて高く持ち上げ、細く流し落とします。粒はすぐ落ち、殻は飛んでいきます |
| 箕であおる | 上下に振りながら前方へあおります | 重い粒が手前に残ります |
| うちわであおぐ | 一人が注ぎ、一人がうちわで風を送ります | 風がない日に使います |
| 篩い分け | 穴の大きさで分けます | 粗い篩で茎の破片を、細かい篩で土と小さい粒を取り除きます |
| 水に浮かべる | しいなとゾウムシに食われた粒は軽いです | 水を張った容器に入れ、浮くものを取り除きます。すくったアズキはその日のうちに再び乾かします |
| 傾斜板転がし | 丸い粒はよく転がり、くずは引っかかります | 板を傾けて置き、転がして落とします |

&nbsp;&nbsp;&nbsp;風選のこつは三つです。風が一定に吹く時間と場所を選びます。一度に注がず細く流し落とします。二、三回繰り返します。アズキは粒が小さく軽いためダイズより風に飛ばされやすいので、風が強すぎる日は避け、注ぐ高さを低くします。

&nbsp;&nbsp;&nbsp;水に浮かべる方法は特に有効です。アズキゾウムシに食われた粒は中が空になって水に浮くため、この方法で選り分けると貯蔵時の損失が大きく減ります。乾燥アズキの収穫直後に一度水に浮かべて浮くものを取り除き、すぐに乾かして貯蔵すれば、貯蔵庫に入るゾウムシの数を最初から減らせます。ただし浸けたアズキはその日のうちに薄く広げて完全に乾かし直す必要があります。種皮から赤い水が少し出ますが、栄養の損失は大きくありません。種子用のアズキにはこの方法を使いません。水に浸けると発芽の生理が始まり、その状態で乾かすと発芽力が落ちます。

## 13. 採種

| 項目 | 方法 |
|---|---|
| 採種個体の選抜 | 病気の症状がなく、莢が多く、熟す時期がそろった株を畑であらかじめ印しておきます |
| 収穫時期 | 莢が完全に褐色になったあとに収穫します。食用より少し遅く収穫します |
| 分離 | 手でむくか別に脱穀します。食用と混ざらないようにします |
| 選別 | 種皮の色が薄い粒やまだらな粒、しわのある粒、ゾウムシの穴がある粒を除きます |
| 乾燥 | 水分12%以下。噛むとぽきっと割れます |
| 防虫 | 貯蔵前に必ずゾウムシ対策を行います。15節参照 |
| 保管 | 密閉容器に入れ、12度以下の涼しく暗い場所に置きます |
| 発芽力の維持 | 3-4年 |

&nbsp;&nbsp;&nbsp;アズキの採種で最も注目すべき形質は、熟す時期がそろっているかどうかです。アズキの最大の収穫損失は熟す時期がばらけることから生じるため、同じ畑の中で莢がほぼ同じ時期に一斉に熟す株の種を選んで受け継いでいけば、数年後には収穫がずっと楽になります。方法は簡単です。9月下旬に畑を見て回り、上下の莢の色がそろった株、緑の莢と褐色の莢が混ざっていない株に糸や布切れを結んでおきます。あわせて見るべき条件は、莢の数が多く落葉病の症状がないことです。

&nbsp;&nbsp;&nbsp;種子用のアズキは手でむくほうがよいです。量が多くないため可能であり、脱穀の過程で生じる微細な傷がないため発芽力が保たれ、貯蔵中のカビも生じにくくなります。乾いた莢を指で押して開けば、粒がそのまま出てきます。

&nbsp;&nbsp;&nbsp;アズキの採種で最も危険な段階は貯蔵です。アズキゾウムシは種子用のアズキを最も確実に台無しにします。粒を食い荒らされると発芽せず、一部だけ食われた粒は芽が出ても弱いです。そのため種子用のアズキは食用より厳重に密閉し、できればガラス瓶いっぱいに詰めて封をし、涼しい場所に置きます。油コーティングは種子用には使いません。油膜が呼吸を妨げ発芽力が落ちます。草木灰をまぶす方法は種子用にも使えます。

| 種子の保管期間と発芽率 |
|---|
| 収穫当年：90%以上 |
| 1年経過：85-90% |
| 2年経過：70-85% |
| 3年経過：50-70% |
| 4年以降：急激に落ちます |

&nbsp;&nbsp;&nbsp;アズキの種子寿命はA等級で常温密閉3年、脂質がほとんどないため他の豆類より発芽率がゆっくり落ちるほうです。それでも実質的には、毎年新しく採って使い、古いものは予備にしておく方式が正しいです。古い種子を植えなければならないときは、必ず先に発芽試験を行います。アズキは暖かくないと芽が出ないため、試験も暖かい場所で行う必要があり、涼しい場所に置いて芽が出ないと判断すると誤った結論に至ります。

&nbsp;&nbsp;&nbsp;自家採種を繰り返すと種子伝染性の病気が蓄積します。炭疽病とウイルス病は種子について次の世代へ引き継がれます。赤い種皮ではまだらが見えにくいため明るい光の下で見るようにし、3年から4年ごとに近隣の村や別の谷から種子を分けてもらい、一部を混ぜます。
