## 10. 营养缺乏与过量

| 症状 | 原因 | 天然材料应对 |
|---|---|---|
| 全株叶片淡黄，植株矮小 | 缺氮。红小豆中最常见的原因是根瘤不良 | 先挖根掰开根瘤确认。若无根瘤，翌年务必接种，当年少量施用尿10倍稀释液 |
| 叶缘褐色干枯并向内卷曲 | 缺钾 | 在株间撒草木灰，轻轻耙入土中 |
| 生长迟缓，叶片泛紫 | 缺磷 | 骨粉、烤过的鱼骨粉、草木灰。红小豆对磷的需求较大 |
| 开花后不结荚 | 缺硼，或开花期高温·干旱 | 原料多样的堆肥。当年用灌水和覆盖降低温度 |
| 叶脉仍绿但脉间发黄 | 缺铁或缺镁，土壤偏碱性 | 停止使用草木灰，用腐叶土和完熟堆肥增加有机质 |
| 新叶小而畸形，生长点枯死 | 缺钙或缺硼 | 烤过的蛋壳粉、贝壳粉 |
| 只有叶片浓绿茂盛，结荚少 | 氮过量 | 停止供氮 |
| 植株徒长，下部豆荚不成熟 | 氮过量或密植 | 翌年减少施肥量和栽植密度 |
| 下部叶片发黄，根呈褐色腐烂 | 过湿，不是肥料问题 | 立即挖沟排水 |
| 下部叶片出现褐斑并大量脱落 | 落叶病，不是营养问题 | 清除病叶并轮作3年以上 |
| 豆荚多但籽粒小而干瘪 | 荚肥大期缺水或缺钾 | 灌水，施草木灰 |
| 种皮红色浅淡且有斑驳 | 灌浆不足 | 提早播种。色素在灌浆后期积累 |

&nbsp;&nbsp;&nbsp;红小豆叶片发黄的症状竟有四种不同原因：缺氮、过湿、落叶病，以及成熟期的正常衰老。由于应对方式完全不同，区分十分重要。区分方法是把第5节讲的挖根检查与第4节讲的看土结合起来使用：挖根若无根瘤，是缺氮；有根瘤但根已褐变腐烂，是过湿；根系完好而下部叶片出现褐斑蔓延，是落叶病。若处于成熟期，则什么都不用做。

&nbsp;&nbsp;&nbsp;缺磷值得特别关注。红小豆的施肥标准中磷为4到6kg，高于大豆，这是因为红小豆的根瘤更小、数量更少，需要用磷来支撑固氮效率。在缺磷的地块，即便长出根瘤，内部也不会呈红色，结果表现为缺氮的症状。这种情况下答案不是补氮，而是补磷。没有化肥时，磷的现实来源是烤碎的骨粉和鱼骨粉，以及草木灰。

&nbsp;&nbsp;&nbsp;微量元素缺乏很难逐一应对。没有化肥，实际上没有办法获取钼或钴。不过，把菜叶果皮、蛋壳、鱼骨、落叶、杂草和草木灰混在一起腐熟制成的堆肥，各种微量元素都齐全。"堆肥堆里什么都能放"这个原则就是现实可行的策略。

## 11. 间作与轮作 - 连作障碍

### 11-1. 搭配关系

| 搭配 | 作物 | 理由 |
|---|---|---|
| 好 | 玉米、高粱、粟 | 可以间作，红小豆固定的氮能让旁边的作物分享 |
| 好 | 大蒜、洋葱、大麦（前作） | 在6月收获后的地块种红小豆，正好与红小豆的播种期衔接 |
| 好 | 马铃薯（前作） | 在6月下旬收获后的地块种红小豆 |
| 好 | 万寿菊 | 根系分泌物能抑制线虫 |
| 一般 | 大白菜·结球甘蓝类 | 在红小豆之后种植可利用残留的氮 |
| 差 | 番茄·辣椒·茄子 | 与红小豆共用病虫害 |
| 差 | 大豆、绿豆、豇豆、花生等豆科 | 会累积相同的病原菌和线虫 |
| 差 | 红小豆连作 | 落叶病和病毒会在土壤中积累 |

&nbsp;&nbsp;&nbsp;与前作的关系是红小豆最大的优势。大蒜、洋葱、大麦、马铃薯都在6月收获，而红小豆的适宜播种期正是6月中下旬，时间正好衔接，能让同一块地一年收获两次。而且这些前作与红小豆几乎不共用病虫害：大蒜和洋葱属于葱类，大麦属禾本科，马铃薯属茄科，与红小豆亲缘关系都很远。不过有观察发现，大蒜和洋葱的分泌物会抑制根瘤菌，因此在这类地块种红小豆时，接种要格外确实。

&nbsp;&nbsp;&nbsp;与玉米间作需要注意。红小豆在40%遮光下产量会降到一半，而且株高只有30-50cm，会完全笼罩在玉米的阴影里，比大豆更为不利。若要混种，应把玉米按南北方向留出充足间距种植，中间只种两行左右的红小豆；若地块宽裕，分开种植更好。

### 11-2. 连作障碍与轮作

| 项目 | 标准 |
|---|---|
| 休作期间 | 3年以上，在豆类中也算长的 |
| 理想周期 | 4年 |
| 连作障碍的原因 | 落叶病、病毒、根腐病、线虫会在土壤中积累 |
| 与其他豆科的关系 | 红小豆之后种大豆或绿豆也视为连作 |

> **红小豆的连作障碍来自土壤中积累的落叶病病菌和病毒，无法用药物治愈，唯有让地块休耕才能解决。要每年都能收获红小豆，需要把地块分成四份。**

&nbsp;&nbsp;&nbsp;这里说明一下3年休作这一条件实际意味着什么。把地块分成四份，每年只在一份地里种红小豆，那么每一份地都会休耕3年，到第4年才再次种上红小豆。这样每年都能收获红小豆，但分给红小豆的面积固定为总面积的25%。考虑到红小豆单位面积热量为D级，这个比例是可以接受的，甚至把地块的25%分给红小豆都可能偏多。

&nbsp;&nbsp;&nbsp;需要注意的是，其他豆科作物同样计入休作期间。在收获红小豆的地块上，翌年若种大豆、绿豆或豇豆，对土壤中的病原菌和线虫来说仍然是连作。尤其是同属的绿豆和豇豆，几乎完全共用病害，最应避免。原则是把豆科作物集中安排在同一区块内轮换管理。

| 4年轮作示例 |
|---|
| 第1年：大蒜·洋葱（前作）之后种红小豆 |
| 第2年：玉米、高粱、粟等禾本科谷物 |
| 第3年：大白菜、结球甘蓝、萝卜等叶菜和根菜 |
| 第4年：马铃薯或甘薯 |
| 再次种红小豆 |

&nbsp;&nbsp;&nbsp;若地块狭小、无法分成四份，有两种折衷办法。第一，不每年种红小豆，而是每2年或3年种一次。种植当年多收一些并妥善贮藏，红小豆能保存3年，因此不必年年种植，耐储性SS正是这一策略的支撑。第二，在地块内调换行的位置：去年种红小豆的行今年种玉米，去年种玉米的行今年种红小豆。这不是完全的轮作，但能相当程度地延缓病原菌的积累。

## 12. 收获与脱粒

### 12-1. 判断收获时期

&nbsp;&nbsp;&nbsp;红小豆的茎不断生长，花也随之从下往上持续开放，因此成熟时期参差不齐。下部豆荚已完全变成褐色时，上部可能还挂着绿色的豆荚，因此判断收获时期比其他豆类更棘手。

| 判断标准 | 内容 |
|---|---|
| 豆荚 | 全株70-80%的豆荚变成褐色时一次性收获 |
| 开花后经过天数 | 开花后50-55天 |
| 籽粒 | 咬起来不留齿痕，会啪地裂开。种皮呈深红色 |
| 叶片 | 下部叶片变黄脱落 |
| 时期（韩国中北部） | 10月上旬-中旬 |
| 时期（韩国南部） | 10月中旬-下旬 |

&nbsp;&nbsp;&nbsp;以70-80%成熟作为收获标准，是权衡后的结果。等得越久，下部豆荚越容易裂开落粒；收得太早，上部豆荚的籽粒又灌浆不足而干瘪。把两种损失加在一起，损失最小的点正是70-80%。分批采摘成熟豆荚的方式也可行，但用工要多出好几倍，在灾害条件下，一次性收获通常更为合理。

> **红小豆的豆荚成熟变干后会自行裂开，这称为裂荚，收获延误时最多可损失30%。下部豆荚用手一拧就啪地开裂时，就不要再等了。**

&nbsp;&nbsp;&nbsp;若是小面积自给种植，分批采摘的方式值得考虑：只用手摘取已成熟的豆荚，一周后再摘一次，如此摘三次左右，损失几乎为零，总产量也会增加。红小豆的豆荚细长显眼，采摘并不困难。只要有人手、面积又小，这种方法收获量最大。

### 12-2. 收获要领

| 顺序 | 内容 |
|---|---|
| 1 | 选晴朗干燥的日子，露水干后的上午10点以后收割 |
| 2 | 用镰刀割断茎的根部，为保留根瘤中的氮，根留在土里 |
| 3 | 移到席子或布上，若在地里拖拽，成熟的豆荚会裂开落粒 |
| 4 | 摊晒4-6天，下雨立即收进屋内 |
| 5 | 豆荚彻底晒干、一拧就啪地裂开时脱粒 |

&nbsp;&nbsp;&nbsp;红小豆收获中损失最大的环节是割下后搬运的动作。已经成熟的豆荚是干的，一碰或一晃就会裂开。因此最好先在地里铺好席子或旧布，割下后立即平放在上面。若割下后拖着走，等于沿路撒籽粒。也可以装进袋子里搬运，袋中裂开的籽粒会直接留在袋内，不会损失。

### 12-3. 脱粒 - 不用工具的方法

| 方法 | 工具 | 步骤 | 效率 |
|---|---|---|---|
| 踩袋子 | 厚麻袋 | 把晒干的红小豆秆装进袋子约半满，扎紧袋口用脚踩，踩十下左右后摇晃调换位置，重复进行 | 少量时最方便，损失几乎为零 |
| 连枷 | 长柄上系有打杆的工具 | 薄薄摊在席子上，从上方打下，翻动两三次 | 适合中等规模 |
| 棍棒敲打 | 木棍 | 装入袋中或摊在席子上敲打 | 可替代连枷 |
| 脚搓 | 无需工具 | 摊在席子上，穿鞋用脚搓动 | 适合少量 |
| 敲打木板 | 木板或木桶 | 抓住红小豆秆束，往桶内壁敲打 | 籽粒集中在桶内，损失较少 |
| 手剥 | 无需工具 | 用手按压豆荚使其裂开 | 用于少量种子，籽粒完全不受损 |

&nbsp;&nbsp;&nbsp;红小豆籽粒小而坚硬，脱粒比大豆容易，豆荚容易裂开而籽粒不易破碎。不过因为籽粒小，容易四处飞溅，在袋子里操作更有利。把晒干的红小豆秆装进厚麻袋约半满，扎紧袋口后用脚踩，豆荚会裂开，籽粒聚集在袋底。当豆秆被踩得短碎时，就说明脱粒完成了。

&nbsp;&nbsp;&nbsp;脱粒成败取决于干燥程度。没晒透的豆秆无论怎么敲打，豆荚都不会裂开。用手拧干燥的豆荚，能啪地裂开就是适宜时机。选在阳光好的下午、豆秆最干燥的时段操作，会顺利得多。

### 12-4. 精选 - 用风分选

| 方法 | 原理 | 步骤 |
|---|---|---|
| 风选（借风扬簸） | 红小豆籽粒重，外壳和碎屑轻 | 在有风的日子把籽粒盛入簸箕或容器，举高后细细洒落，籽粒直接落下，糠壳被风吹走 |
| 簸扬 | 上下抖动并向前扬起 | 较重的籽粒会留在后方 |
| 扇风 | 一人倾倒、一人用扇子送风 | 用于无风的日子 |
| 筛选 | 按孔径大小分开 | 用粗筛筛出豆秆碎屑，用细筛筛出泥土和小粒 |
| 水选 | 秕粒和被象鼻虫蛀过的粒较轻 | 倒入水桶，捞去浮起的部分，捞出的红小豆须当天重新晒干 |
| 斜板滚选 | 圆粒容易滚动，碎屑会被挡住 | 把木板斜放，让籽粒滚落下来 |

&nbsp;&nbsp;&nbsp;风选的要领有三点：选风力稳定的时间和地点；不要一次性倾倒，而是细细洒落；重复两三次。红小豆籽粒小而轻，比大豆更容易被风吹散，因此要避开风太大的日子，并降低倾倒的高度。

&nbsp;&nbsp;&nbsp;水选法尤其有效。被红小豆象蛀食过的籽粒内部中空，会浮在水面，用这种方法挑出，能大幅减少贮藏期间的损失。晒干的红小豆收获后立即用水选一次，捞去浮起的部分，随即晒干贮藏，这样一开始进入仓库的豆象数量就会减少。不过浸过水的红小豆必须当天薄薄摊开、彻底重新晒干；种皮会渗出少许红色水分，但营养损失不大。种子用的红小豆不使用这个方法——一旦浸水，发芽的生理过程就会启动，若在这种状态下晒干，发芽力会下降。

## 13. 留种

| 项目 | 方法 |
|---|---|
| 留种个体选择 | 在地里预先标记没有病害症状、结荚多、成熟期一致的植株 |
| 收获时期 | 待豆荚完全变成褐色后再收获，比食用豆收获得稍晚 |
| 分离 | 用手剥或单独脱粒，避免与食用豆混杂 |
| 选别 | 剔除种皮颜色浅或有斑驳的籽粒、皱缩的籽粒、有象鼻虫蛀孔的籽粒 |
| 干燥 | 含水量12%以下，咬起来啪地裂开 |
| 防虫 | 贮藏前务必做好防豆象措施，参见第15节 |
| 保管 | 装入密闭容器，放在12度以下、阴凉黑暗处 |
| 发芽力维持 | 3-4年 |

&nbsp;&nbsp;&nbsp;红小豆留种时最值得关注的性状是成熟期是否整齐。红小豆最大的收获损失来自成熟期参差不齐，因此若能在同一地块中选取豆荚在相近时间集中成熟的植株留种并连续几代延续，几年后收获会容易得多。方法很简单：9月下旬巡视地块，给上下豆荚颜色一致、没有绿荚与褐荚混杂的植株系上线绳或布条做标记，同时要看结荚数量多、没有落叶病症状。

&nbsp;&nbsp;&nbsp;种子用的红小豆最好用手剥。因为数量不多，这样做可行，脱粒过程中产生的细微损伤也不存在，发芽力得以保持，贮藏中也不易长霉。用手指按压干燥的豆荚使其裂开，籽粒就会直接露出来。

&nbsp;&nbsp;&nbsp;红小豆留种中最危险的环节是贮藏。红小豆象最容易彻底毁掉种子用的红小豆：籽粒被蛀食就无法发芽，只被部分蛀食的籽粒即使发芽也很弱。因此种子用的红小豆密封要比食用豆更严格，最好装满玻璃瓶、封紧瓶口，放在阴凉处。种子用的红小豆不使用油封处理，因为油膜会妨碍呼吸，使发芽力下降；但拌草木灰的方法可以用于种子。

| 种子保存年限与发芽率 |
|---|
| 收获当年：90%以上 |
| 经过1年：85-90% |
| 经过2年：70-85% |
| 经过3年：50-70% |
| 4年以后：急剧下降 |

&nbsp;&nbsp;&nbsp;红小豆的种子寿命为A级，常温密闭可保存3年，因为几乎不含脂肪，发芽率下降的速度比其他豆类慢。尽管如此，实际操作中仍应每年новый留种子使用，把陈种作为备用。需要种陈种时，务必先做发芽试验。红小豆要在温暖环境下才能发芽，因此试验也必须放在温暖处进行，如果放在阴凉处却因不发芽而下结论，就会得出错误的结果。

&nbsp;&nbsp;&nbsp;反复自留种会使种传病害不断累积。炭疽病和病毒病都会随种子传到下一代。红色种皮上斑驳不容易看清，应在明亮光线下检查，并且每隔3到4年从邻村或其他山谷引入一些种子混入自留种中。
