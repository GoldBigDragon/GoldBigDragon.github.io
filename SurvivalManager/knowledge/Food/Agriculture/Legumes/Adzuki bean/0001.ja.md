## はじめに
&nbsp;&nbsp;&nbsp;アズキ(Vigna angularis)は東アジア原産のマメ科の一年草です。総合等級はC(40.6点、有効183種中110位)で、短期D(38.9)、長期C(42.3)、副食はSS(61.8点)であり、主食にはなれませんが副食としては優れた作物です。面積当たりの熱量がDで1㎡に660kcal、自給ラインの25%にすぎず、広い面積を割り当てるには向きません。その代わり、タンパク質密度は熱量比25%で、食物繊維は100gに15g以上と玄米の3倍、ビタミンB1の0.66mgが白米中心の食事の脚気を防ぎます。総蒸発散量は約400mmと水の使用が少なく、100-120日で収穫できてニンニクやジャガイモのあとに続けて植えられ、乾燥したアズキは虫さえ防げば常温で3年もちます。弱みは三つです。湿害に極端に弱く、平畝は高畝より収量が34%減り、3年休ませなければならない連作障害があり、貯蔵中にアズキゾウムシが半年で全部をだめにすることがあります。

## 1. 災害への備えの評価
| 区分 | 等級 | スコア |
|:---|:---:|:---:|
| 総合 | C | 40.6 |
| 短期 | D | 38.9 |
| 長期 | C | 42.3 |
| 副食 | SS | 61.8 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: タンパク質密度、施肥、施設の負担、貯蔵性。S: 微量栄養素、味、国内での栽培の普及度、自家採種。A: 水の消費量、合成資材を投入しない場合の収量維持率、収量の安定性、種子の寿命。B: 収穫速度、防除の自立度、連作への適応性 |
| 弱み | E: 耐寒性。D: 面積当たりの熱量、永続性、日射、調理・加工の要求度、整地・掘削エネルギー、非食用の価値。C: 温度幅、病害虫圧 |

> **アズキの貯蔵性SSは条件付きの等級です。アズキゾウムシを防げなければ、SSではなくEになります。**

&nbsp;&nbsp;&nbsp;アズキだけで1日2,100kcalを満たすには乾燥アズキを636g食べなければならず不可能なので、畑の面積は全体の1割以内に割り当てるのが現実的です。整地・掘削エネルギーD(熱量回収倍率4.0倍)は高い畝を立てなければならないことから来ており、連作への適応性Bは3年の休作という負担を隠しています。病害虫圧C(無防除感受率48.9%)の相当な部分は貯蔵庫で失われます。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | マメ科ササゲ属の一年草。リョクトウ、ササゲと同じ属なので、病害虫と根粒菌がダイズよりこれらに近い。原産地は中国中北部から朝鮮半島で、野生の祖先ヤブツルアズキは水はけのよい畑の畦に生える |
| 葉、茎 | 葉はハート形に近い三出複葉。茎はまっすぐ立って高さ30-50cmで支柱は不要、つる性は1mを超える。莢が地面に近く、湿気を受けやすい |
| 根、花 | まっすぐな主根に細根が伸び、細根に根粒がつく。花は黄色い蝶形で自家受粉(ダイズは白か薄紫色なので見分けられる) |
| 莢、種子 | 細長い円筒形で、1莢に6-10粒。赤いアズキが基本で、黒、白、まだらもある |

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 発芽、幼苗期 | 播種後3週間 | 発芽と初期成長、根粒形成の開始 |
| 開花期 | 6-8週 | 黄色い花が下から上へ3-4週間にわたって順に咲く |
| 莢肥大期 | 8-10週 | 莢と子実が大きくなる |
| 成熟、収穫期 | 10-14週 | 下の莢から茶色に熟す |

> **幼苗期は湿害にもっとも弱い時期です。播種直後に梅雨が重なると、若いアズキは根が傷んでそのまま枯れます。6月中下旬の播種が梅雨と重なる年には、畝の高さが生存を分けます。**

&nbsp;&nbsp;&nbsp;乾燥アズキ100g当たり熱量330-356kcal、タンパク質20.63g(熱量比25.0%)、炭水化物約60g、脂質0.5-1g、食物繊維14.9-16.9g、ビタミンB1 0.66mg(白米の10倍、成人の1日の推奨量の半分以上)、糖類0.43gです。種皮にアントシアニンが、全体にサポニンがあります。脂質が1%未満で酸化せず、粉にしても長くもち、甘みはアズキではなく砂糖や蜂蜜から来ます。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽最適32-34℃(マメ類で最も高い)、15℃未満では発芽が遅く種子が腐るため、播種時の地温は15℃以上(20℃以上が望ましい)。生育15-35℃(最適20-24℃)、結実18-32℃、霜で枯れる |
| 光 | 1日6時間以上(8時間以上が最適)、40%遮光で収量が半分。短日植物なので、遅く植えると小さな体で花が咲く |
| 水、土壌 | 水はけのよい砂壌土か壌土、pH5.5-7.0(6.0-6.5が最適、酸性土では根粒が減る)。作期の蒸発散量は約400mm。1日以上冠水すると回復が難しい |
| 畝、排水溝 | 畝の高さ20cm以上(25-30cmが最適)、排水溝の深さ30cm以上。平畝栽培は収量が34%減るので、畝は肥料より先の条件 |

| 区分 | 特徴 |
|:---|:---|
| 直立型(普通アズキ) | 草丈30-50cmで支柱が不要、倒れにくい基本の選択。チュンウォン(全国)、チュンジュ(中部) |
| つる型(つるアズキ) | つるが1mを超えて支柱が必要で、収量が多い。チルボ。支柱の材料と労力に余裕があるとき |
| 早生、耐湿性 | イェは生育期間が短く、播種が7月にずれ込んだとき。アラリ、ホンダ、コムグスル、ヨンドゥチェは耐湿性が強く、水はけの悪い畑や水田転換地に |

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 排水 | 畝と排水溝を先につくり、粘土質の畑には砂、もみ殻、腐葉土を混ぜて水はけを改良 |
| 施肥(1,000㎡) | 窒素2-4kg(根粒が働く前の初期用の最小量)、リン酸4-6kg(ダイズより多く)、カリウム4-6kg(すべて元肥)、完熟堆肥1,000kg、酸性土なら石灰150-200kg(播種の3-4週間前) |
| 代替資源 | 木灰(1㎡当たり100-200g、多いとpHが上がる)、完熟した堆肥(1㎡当たり1kg)、尿を10倍に薄めた液(少量)、骨粉と焼いた魚の骨(リン酸)、貝殻と卵の殻(石灰の代わり) |
| 根粒の接種 | アズキ、リョクトウ、ササゲを育てた畑の表土5-15cmの土を、水で軽く湿らせた種子にまぶし、日陰で30分以内に播種(日に干すと菌が死ぬ)。野生のヤブツルアズキの根の根粒もよく合う。pH5.5以下、窒素肥料の過多、水がたまる、リン酸不足だと失敗 |

| 確認 | 方法 |
|:---|:---|
| 根粒の点検 | 開花のころ(播種後5-7週)、健康な株を2、3株、スコップで土ごと掘り上げて洗い、根粒を割る。根粒が1株15個以上で内側が赤かピンクなら窒素を固定中。白か薄い緑なら酸度、湿害、リン酸欠乏を調べ、5個以下は接種の失敗で、葉が黄色ければ窒素を少量補う |

> **マメ科が土を肥やすのは窒素を固定するからではなく、固定した窒素の一部を茎と葉にためて畑に残すからです。その茎と葉を運び出せば、アズキは土を収奪する作物になります。**

&nbsp;&nbsp;&nbsp;だから茎、葉、莢の殻は20-30cmに切って畑に戻し、焼かず(窒素が飛ぶ)、根は掘り上げません。病気の残渣だけを焼くか、畑の外で腐らせます。

| 播種 | 基準 |
|:---|:---|
| 時期 | 中北部は6月中旬-下旬(限界は7月上旬)、南部は6月中旬-7月上旬(限界は7月中旬)。梅雨の雨が一度過ぎた直後にまくと、若いアズキが雨を受けにくい。遅いほど莢が減り、遅く咲いた花は霜までに熟さない |
| 種子の準備 | 斑点、変色、しわ、虫食いの穴(アズキゾウムシの穴は小さく丸く、白い点のように見える)のある粒を捨て、水に浮く粒を取り除く。65℃の湯に5分浸すと種子伝染性の病気が減るが、時間を超えると発芽力が損なわれ、接種は完全に冷ましてから行う |
| 方法 | 深さ3-5cm、1か所2-3粒(あとで2本を残して間引く)。1条栽培は条間60-70cm・株間10-15cm、2条栽培は120cmの畝に40cm間隔。播種量は1,000㎡当たり3-4kg、遅いときは5-7kgに増やして密にまく |
| 鳥 | 播種直後に鳥が子葉をついばむと株が枯れるので、発芽までわら、ネット、古い防虫網をかける |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 幼苗期 | 比較的乾燥気味に(湿害にもっとも弱い) |
| 梅雨 | 灌水ではなく排水。排水溝を切って溜まり水を抜く |
| 開花期から莢肥大期 | 干ばつなら十分に灌水 |
| 成熟期 | 灌水を止める(過湿だと莢が乾かず、カビが生える) |

> **アズキで水管理とは、たいてい水をやることではなく、水を抜くことを意味します。畝を高くし溝を切る作業が、灌水より先です。**

&nbsp;&nbsp;&nbsp;朝になっても葉が垂れていて土が湿っているなら、過湿で根が傷んでいるので、ただちに溝を切って水を抜くべきで、水をさらに与えてはいけません。

| 管理 | 方法 |
|:---|:---|
| 土寄せ | 3回。本葉2-3枚で子葉節まで、4-5枚で初生葉節まで、6-7枚で第1本葉節まで土を寄せ、開花前に終える。花が咲いたあとに畑に入って土をひっくり返すと、花が落ち細根が切れて収量が減る |
| 草取り | 播種後2-3週(1回目の土寄せと兼ねる)と4-5週(2回目の土寄せと兼ねる)に浅く削り、開花前にすべて終える。アズキに登録された除草剤はない |
| マルチ | 3回目の土寄せ直後に、わら、もみ殻、落ち葉、刈った草を5-10cm覆う(覆わないと収量が24%減り、播種直後に覆うと芽が出られない)。雑草、蒸発、泥はねを同時に防ぐ |

## 6. 病害虫と養分の問題
| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| ウイルス病 | 葉がモザイク状にまだらになり、生育が止まる。アブラムシが媒介 | 治療不可。見つけ次第抜いて焼き、アブラムシを減らす |
| 落葉病 | 下の葉から褐変して大量に落ちる。連作した畑の土にカビがたまる | 3年以上の輪作が唯一の対策。病気の残渣を焼く |
| 褐斑病、炭疽病、うどんこ病 | 葉に褐色のまだらや暗褐色の病斑(8-9月の多湿) / 白い粉(乾燥して風通しが悪い) | 風通しの確保、病葉の除去、ボルドー液、種子の選別 / 牛乳を5-10倍に薄めた液 |
| 根腐病 | 根が褐変し下の葉が黄色くなる(過湿、連作) | 排水、畝を高くする、輪作 |
| カメムシ類 | 8月から莢を刺して実の入らない莢にする | 早朝の捕殺、畑の周りにおとり作物、開花期に防虫網(自家受粉なので結実に支障なし) |
| ネキリムシ類、アブラムシ | 若い茎を根元で切る / 汁を吸いウイルスを運ぶ | 倒れた株の周りの土を掘って幼虫を捕り、根元に灰を巻く / 石けん水(水1Lに石けん5g) |

&nbsp;&nbsp;&nbsp;ボルドー液は、水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜてつくります。畝を高くすること(病害の半分以上が過湿に関連)、株間、マルチ、雨のあとに畑に入らないこと、病気の残渣の焼却、畦の整理(マメ科の雑草がカメムシとウイルスの中間宿主)が耕種的防除です。

> **薬のない条件でのアズキの防除の核心は二つに絞られます。水を抜くことと、畑を回すことです。この二つがアズキの病害の大部分を決めます。**

| 症状 | 原因と対処 |
|:---|:---|
| 葉全体が薄い黄色で株が小さい | 窒素欠乏(根粒不良がもっとも多い)。根を掘って根粒を確認し、その年は尿を10倍に薄めた液を少量与える |
| 縁が褐色に枯れて巻く | カリウム欠乏。木灰を株の間にまく |
| 生育が遅く葉が紫がかる | リン酸欠乏。骨粉、焼いた魚の骨、木灰 |
| 葉だけ濃い緑で茂り莢が少ない | 窒素過剰。窒素の供給をやめる |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | トウモロコシ、ソルガム、アワ(間作して、アズキが固定した窒素を分けてもらう)、マリーゴールド(センチュウを抑える)。ニンニク、タマネギ、オオムギ、ジャガイモは、6月に収穫した場所にアズキを植える前作 |
| 悪い | トマト、トウガラシ、ナス(病害虫を共有)、ダイズ、リョクトウ、ササゲ、ラッカセイなどのマメ科(同じ病原菌とセンチュウがたまる)、アズキの連作(落葉病とウイルス) |

&nbsp;&nbsp;&nbsp;休作期間は3年以上(理想の周期は4年)で、原因は落葉病、ウイルス、根腐病、センチュウが土にたまることです。アズキのあとにダイズやリョクトウを植えても連作とみなすので、ほかのマメ科も休作期間に含まれます。4年輪作の例は、ニンニクかタマネギのあとにアズキ → トウモロコシ、ソルガム、アワ → ハクサイ、キャベツ、ダイコン → ジャガイモかサツマイモ → アズキです。

> **アズキの連作障害は、土にたまった落葉病菌とウイルスから来ます。薬では治せず、畑を空ける時間だけが解決します。アズキを毎年収穫するには、畑が四区画必要です。**

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 莢の70-80%が茶色に熟したときに一度に収穫(開花後50-55日、中北部は10月上旬-中旬、南部は10月中旬-下旬)。豆をかむとぱきっと割れ、種皮は濃い赤で、下の葉が黄色くなって落ちる |
| 要領 | 晴れて乾いた日の、露が乾いた午前10時以降に、鎌で茎の根元を刈る(根は残す)。むしろや布の上に移し(引きずると莢がはじける)、4-6日干し、莢をひねるとぱきっと開くときに脱穀 |
| 脱穀 | 乾いた茎を麻袋に半分入れて踏むか、からざおで打つ。桶の内壁に打ちつけると豆が桶の中にたまる。種子用の少量は手でむく |
| 選別 | 風のある日に箕や器から流し落として殻を飛ばす。水にあけて浮く実のない豆とゾウムシに食われた豆を取り除く(拾った豆はその日のうちに再び干す) |

> **アズキは熟した莢が乾くと自然にはじけます。これを脱粒といい、収穫が遅れると30%まで失います。下の莢が手でひねってぱきっと開き始めたら、それ以上待ちません。**

| 採種 | 基準 |
|:---|:---|
| 選抜、収穫 | 病気の症状がなく、莢が多く、熟す時期がそろった株をあらかじめ印をつける。食用よりやや遅く、莢が完全に茶色になってから収穫して、手でむく |
| 選別、乾燥 | 種皮の色が薄い粒、まだらの粒、しわのある粒、ゾウムシの穴のある粒を捨てる。水分12%以下 |
| 保管 | 密閉容器に入れて12度未満の涼しく暗い場所に置く。発芽率は収穫した年は90%以上、1年後は85-90%、2年後は70-85%、3年後は50-70%で、4年目以降は急に落ちる。自家採種を繰り返すと種子伝染性の病気がたまる |

## 9. 貯蔵
| 段階 | 方法 |
|:---|:---|
| 乾燥 | 茎ごと4-6日、脱穀後は薄く広げて日に2-3日干し、水分12%以下(かんでも歯が入らずぱきっと割れる)にする。乾いた瓶にアズキと炒った塩を入れて振り、塩が壁につくならさらに干し、冷ましてから入れる |
| 完全密閉 | ガラス瓶や金属缶をいっぱいに満たして封じると酸素が絶たれ、3-4週間で卵と幼虫まで死ぬ。大きな容器1つより小さな容器を何個もきっちり詰め、1つが傷んでも全部を失わないようにする |
| 木灰、珪藻土、油 | 細かい木灰をアズキの体積の2-5%混ぜる(種子用にも可、食べる前にすすぐ)。珪藻土はアズキ1kgに1-3g。食用油2-5mLをもみ込むと効果が大きいが、種子用には使わない |
| 低温、高温 | 密閉容器を真冬に数日外に出し、開けずに半日室内に置いて温度を合わせてから開ける(結露を防ぐ)。12度以下の低温保管は繁殖が事実上止まる |

> **アズキは腐って失うのではなく、虫に食われて失います。貯蔵の技術とは、すなわちアズキゾウムシを防ぐ技術です。**

&nbsp;&nbsp;&nbsp;アズキゾウムシは畑で莢に卵を産みつけ、卵が種皮についたまま貯蔵庫に入り、1か月は外から分からず、2か月目に成虫が出てきて、6か月で袋全体が殻と粉になります。容器は、ガラス瓶と金属缶が3年以上、壺と地下貯蔵穴が2-3年(貯蔵穴は水が染みると全量を失う)、厚いビニールが1年です。12度以下、空気の湿度65%以下で光を遮り、台の上に置いて、月に1回点検します。

## 10. 調理と注意事項
| 成分 | 働き | 取り除く方法 |
|:---|:---|:---|
| トリプシンインヒビター、レクチン | タンパク質の消化を妨げ、腹痛、嘔吐、下痢を起こす。アズキのレクチンはインゲンマメより弱い | 6時間浸したあと、ぐらぐら煮立つ湯で十分に加熱 |
| サポニン | 泡を出して胃腸を刺激し、胃がもたれて下痢。適量は抗酸化と利尿 | ゆでる最初の湯を捨て、泡をすくい取る |
| フィチン酸、タンニン、オリゴ糖 | 鉄、亜鉛、カルシウムの吸収を妨げる / 渋み / おなかにガス | 浸漬、発芽、発酵でフィチン酸が減り、浸し水と最初のゆで汁を捨てる |

> **アズキはサポニンが特に多い豆です。ゆでるときに出る泡がサポニンで、この最初の湯を捨てることがアズキ調理の第一歩です。捨てないと渋くて腹が痛みます。**

| 処理 | 基準 |
|:---|:---|
| 順序 | 常温の水に6時間浸し、浸し水は捨てる。5-10分ゆでて最初の湯を捨て、新しい水でぐらぐら煮立つ湯で40-60分ゆでる。指で押して簡単につぶれれば煮えている |
| 燃料の節約 | 圧力調理は120℃で10-15分。余熱調理は15分煮てから保温箱で2時間(箱の中は80度前後なので、最初の煮立たせを15分以上確保し、芯が残れば再び煮る)。数日分をまとめてゆでておく |
| 発芽、発酵 | 芽を出させるとフィチン酸が50-70%、インヒビターが30-40%減り、ビタミンCができる。ゆでたアズキを2、3日発酵させると消化しやすくなる |

&nbsp;&nbsp;&nbsp;小豆ごはんは米に足りないビタミンB1とリジンを補います。ゆでて干して粉にしたアズキの粉は脂質がなく、密閉すれば2-3か月もちます。甘みが必要なときは、ソルガムシロップや麦芽の水あめを一緒に使います。

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵したアズキの点検、種子の発芽試験、低温処理。2月に畑の計画、堆肥の切り返し、3年の休作を守れる区画の確認 |
| 3-4月 | 3月に石灰の散布、堆肥の仕上げ。4月に前作の管理、粘土質の畑に砂、もみ殻、腐葉土を混ぜて水はけを改良 |
| 5-6月 | 5月に前作の収穫準備、接種用の土の確保。6月に前作の収穫、排水溝を掘り、畝を25-30cmに高くし、中旬-下旬に播種 |
| 7-8月 | 7月に1、2回目の土寄せ、草取り、梅雨の排水(雨の直後は畑に入らない)。8月に3回目の土寄せを開花前に終えてマルチ、根粒の確認、カメムシの監視 |
| 9-10月 | 9月に灌水、カメムシの捕殺、採種株の印つけ。10月に莢の7-8割が熟したときに一度に収穫し、乾燥、脱穀、選別、茎葉を畑に戻す |
| 11-12月 | 11月に仕上げの乾燥、水に浮かべて選別、防虫処理、貯蔵。12月に低温処理、貯蔵の点検、冬至の小豆粥 |

> **アズキは主食になれませんが、湿害と連作とゾウムシさえ越えれば、少ない水と短い期間で、穀物に足りないビタミンB1を補ってくれる副食の作物です。**
