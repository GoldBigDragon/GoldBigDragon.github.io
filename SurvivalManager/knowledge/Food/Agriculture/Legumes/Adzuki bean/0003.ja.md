## 3. 栽培環境

### 3-1. 気温と日照量

| 条件 | 限界値 | 最適値 | 外れたとき |
|---|---|---|---|
| 発芽温度 | 最低6-10℃、最高40-44℃ | 32-34℃ | 15℃を下回ると発芽が遅れ種子が腐ります |
| 播種期地温 | 15℃以上 | 20℃以上 | 冷たい土に播くと初期生育が崩れます |
| 生育温度 | 15-35℃ | 20-24℃ | 低温に特に弱いです |
| 結実温度 | 18-32℃ | 20-30℃ | 幅10℃の狭い範囲です |
| 霜 | 氷点下で枯死 | - | 耐寒性がありません |
| 日照 | 1日6時間以上 | 1日8時間以上 | 40%遮光で収量が半分になります |
| 日長 | 短日植物 | 日が短くなると開花 | 遅く植えると小さな株のまま花を咲かせます |

&nbsp;&nbsp;&nbsp;発芽最適温度32℃から34℃は、この作物表の豆類の中で最も高い値です。アズキがなぜ遅く植える作物なのか、この一行が説明しています。韓国の畑の地温が30℃に達するのは6月中旬以降で、そのためアズキの播種適期は6月中旬から下旬に置かれます。この時期はニンニクとタマネギとオオムギを収穫した直後なので、後作として自然にかみ合います。アズキが韓国の作付体系で後作の位置を占めてきたのは偶然ではありません。

&nbsp;&nbsp;&nbsp;低温に弱いという点は二つの方向で作用します。春は地温が上がるまで待たなければならず、秋は霜の前に登熟を終える必要があります。幸い生育期間が100日から120日と短いため、この余裕は十分にあります。6月中旬に植えて10月上旬から中旬に収穫すれば、霜に遭う前に終わります。播種が7月にずれ込むと収量がはっきり減るため、7月上旬を韓国中北部の限界とします。

### 3-2. 土壌と水 - 湿害がすべてです

| 条件 | 限界値 | 最適値 | 備考 |
|---|---|---|---|
| 土性 | 排水不良地では栽培不可 | 排水の良い砂質壌土-壌土 | 水はけがすべての条件の中で第一です |
| pH | 5.5-7.0 | 6.0-6.5 | 酸性土では根粒が減ります |
| 畝の高さ | 20cm以上 | 25-30cm | 平畝栽培は収量が34%減ります |
| 排水路 | 必須 | 深さ30cm以上 | 畝より排水路が先です |
| 作期蒸発散量 | - | 約400mm | 豆類の中では少ない部類です |
| 冠水 | 1日以上浸かると回復が困難です | - | 豆類の中で最も弱いです |
| 地下水位 | 60cm以下 | 80cm以下 | 水田に植えるとき最も重要な条件です |

> **平畝に植えたアズキは、畝を高くした場合より収量が34%減ります。アズキ栽培では畝の高さが施肥より優先される条件です。**

&nbsp;&nbsp;&nbsp;アズキがなぜそれほど湿害に弱いのか、理解しておくとよいでしょう。二つの理由が重なっています。第一に、根粒菌は酸素を必要とする好気性細菌です。土が水に浸かると酸素が失われ、根粒は根本体より先に機能を失います。これはすべての豆類に共通ですが、アズキは根が浅いため表土の水分状態により直接さらされます。第二に、アズキの根には酸素不足に対する適応構造がほとんどありません。イネのように茎を通じて空気を根へ送り込む通気組織がなく、ダイズのように深く伸びて水に浸からない層を探し当てることもできません。

&nbsp;&nbsp;&nbsp;そのため、アズキ畑の準備は排水から始まります。順序も重要です。まず畑の水の流れを見て、低い場所と水が集まる場所を把握します。その場所にはアズキを植えません。次に排水路を設けます。畑の周囲と畑の内側に溝を掘り、低いほうへ水が抜けるようにします。その次に畝を高くします。畝は20cm以上、できれば25から30cmに高くし、上部を丸く仕上げて水がたまらないようにします。最後に肥料を入れます。

&nbsp;&nbsp;&nbsp;水田にアズキを植えなければならない状況もあります。畑が不足する条件では水田を畑に転換して使うことになりますが、アズキはそうした場所に最も向かない作物です。それでも植えるなら、耐湿性品種を選び、排水路を深さ50から80cmに掘り、畝を30cm以上高くし、播種時期を韓国の梅雨（チャンマ、6月下旬～7月）とずらして調整します。それでもリスクが大きいため、水田にはアズキよりササゲを植えるほうが合理的です。

## 4. 品種

### 4-1. 生育形態による分類

| 区分 | 特徴 | 災害時の適合性 |
|---|---|---|
| 直立型（普通アズキ） | 草丈30-50cm、支柱が不要で倒伏に強いです | 管理が容易で基本の選択です |
| つる型（つるアズキ） | つるが1mを超え、支柱が必要です。収量が多いです | 支柱の材料が確保でき、労力に余裕があるとき |

&nbsp;&nbsp;&nbsp;災害時の条件では直立型が基本です。つる型は収量が多いものの支柱を立てる必要があり、誘引の労力もかかります。竹や木の枝が手に入り人手に余裕があるなら、つる型の収量は魅力的ですが、そうでなければ直立型が安全です。ただし一つ例外があります。畑が極端に狭い場合は、つる型で上の空間を使うほうが面積当たりの収量で有利です。トウモロコシの茎をそのまま残して支柱として使う方法もあります。

### 4-2. 主な品種

| 品種 | タイプ | 特徴 | 適した状況 |
|---|---|---|---|
| チュンウォンパット | 直立型 | 倒伏に強いです。管理が容易です | 基本の選択。韓国全土 |
| チュンジュパット | 直立型 | 韓国中部に適応しています | 韓国中部 |
| チルボパット | つる型 | 収量が多いです。支柱が必要です | 収量を重視するとき |
| イェパット | 早生種 | 生育期間が短く、単作にも二毛作にも対応できます | 播種が遅れたとき |
| アラリ・ホンダ・コムグスル・ヨンドゥチェ | 直立型 | 耐湿性が強く水田栽培に適応しています | 水はけの悪い畑、水田転換地 |

&nbsp;&nbsp;&nbsp;耐湿性品種が別にあるという事実は覚えておく価値があります。アラリ、ホンダ、コムグスル、ヨンドゥチェは水田栽培を念頭に置いて育成された系統なので、水がたまる条件を相対的によく耐えます。「相対的」という言葉が重要です。これらの品種も水に浸かれば枯れます。ただし他の品種より少しだけ長く持ちこたえ、湿った土での根の発達が抑制されにくいのです。畑の水はけが悪い場合は、この系統を入手するのがよいでしょう。

| 状況 | 選択 | 理由 |
|---|---|---|
| 初めて植える、管理労力が不足している | チュンウォンパットなど直立型 | 支柱が不要です |
| 水はけの悪い畑 | アラリ、ホンダ、コムグスル、ヨンドゥチェ | 耐湿性が強いです |
| 播種が7月にずれ込んだ | イェパット | 生育期間が短いです |
| 畑が極端に狭い | チルボパットなどつる型 | 上の空間を使います |
| 長く続けていく必要がある | 地域の在来種 | 地域に適応しています |
| 種子が不足している | 直立型 | 栽植密度が高く、同じ重さでより広く植えられます |

## 5. 畑の準備と肥料 - 根粒菌と窒素収支

### 5-1. 窒素固定はどのように起こるか

&nbsp;&nbsp;&nbsp;空気の78%は窒素です。ところが植物はそれを使えません。空気中の窒素は原子二つが三重結合で固く結び付いた分子（N2）であり、その結合を切るのに膨大なエネルギーが要るからです。工業的にこの結合を切ってアンモニアを作るのがハーバー・ボッシュ法で、高温と高圧と触媒と大量の化石燃料を使います。

&nbsp;&nbsp;&nbsp;根粒菌はこの仕事を常温常圧でやってのけます。ニトロゲナーゼという酵素で三重結合を切り、アンモニアに変えます。ただしこの反応には多くのエネルギーが必要で、細菌自身は光合成ができません。そこでマメ科植物の根に入り込んで暮らしながら植物が作った糖を受け取り、その見返りに固定した窒素を渡します。取引の関係です。

| 段階 | 起こること |
|---|---|
| 1. シグナル交換 | アズキの根がフラボノイドを分泌し、土中の細菌が応答してNodファクターを放出します |
| 2. 感染 | 根毛が曲がって細菌を抱え込み、根の中へ入っていきます |
| 3. 根粒形成 | 根の細胞が分裂して根粒が膨らみ、その中に細菌が住み着きます |
| 4. 窒素固定 | 根粒の中でニトロゲナーゼが空気中の窒素をアンモニアに変えます |
| 5. 分配 | アンモニアがアミノ酸に変わり、茎と葉と莢へ運ばれます |
| 6. 老化 | 登熟期に根粒が機能を失い、根とともに土に還ります |

&nbsp;&nbsp;&nbsp;ニトロゲナーゼは酸素に非常に弱く、酸素が触れるとすぐに機能を失います。そのため根粒の内側にはレグヘモグロビンという赤い色素タンパク質が満ちていて、酸素を捕まえておきます。人の血が赤いのと同じ原理で、根粒を割ったときに内側が赤や薄紅色をしているのはこの色素のためです。この事実は実用上たいへん重要です。赤色は、その根粒が今まさに窒素を固定している目に見える証拠なのです。

### 5-2. 根粒ができているかを確認する方法

| 順序 | 内容 |
|---|---|
| 1 | 開花が始まる頃、播種後5-7週が最も良い時期です |
| 2 | 健康そうな株を二、三株選びます |
| 3 | 引き抜かず、スコップで周りを広く掘って土ごと持ち上げます。引き抜くと細根の根粒が土に残ります |
| 4 | 水を張った容器に入れ、土をそっと洗い流します |
| 5 | 主根と太い細根に付いた根粒の数を数えます |
| 6 | 根粒をいくつか爪で割って内側の色を見ます |

| 観察結果 | 意味 | 対処 |
|---|---|---|
| 根粒が1株あたり15個以上 | 接種がうまくいきました | そのままにします |
| 割った内側が赤か薄紅色 | 窒素を固定しています | 良い状態です |
| 割った内側が白か薄緑色 | 根粒はできたが固定していません | 酸度、湿害、リン酸欠乏を確認します |
| 割った内側が褐色か黒色 | 老化したか死んでいます | 登熟期なら正常、開花期なら問題です |
| 根粒が5個以下 | 接種が失敗しました | 葉が黄色ければ窒素を少量補います |

> **根を掘り出して根粒を割り、赤色を確認するという一つの習慣が、窒素肥料のない世界でアズキ栽培の成否を教えてくれる最も確実なサインです。**

&nbsp;&nbsp;&nbsp;アズキで根粒の確認が特に役立つ理由があります。アズキ畑で葉が黄色くなる原因は三つあり、窒素不足、湿害による根の損傷、落葉病です。この三つは対処がまったく異なります。窒素不足なら施肥、湿害なら排水、落葉病なら株の除去と輪作が答えです。根を掘ってみればこの三つが見分けられます。根粒がなければ窒素不足、根粒があっても根が褐色に腐っていれば湿害、茎の根元が変色していて根は無事なら病気です。

### 5-3. 接種源をどこで入手するか

| 方法 | 手順 | 注意 |
|---|---|---|
| アズキ・リョクトウ・ササゲを育てた畑の土をまぶす | 前年に同じ属（Vigna）の作物を植えて根粒がよくできた畑から、表土5-15cmの土をすくってきます。軽く湿らせた種子にまんべんなくまぶしてすぐ植えます | 日陰で作業し30分以内に植えます。日に当てて乾かすと菌が死にます |
| 土を播種列にまく | 植える列に土をまき、一緒にすき込みます。10㎡あたりスコップ一杯 | 量は多く要りますが菌が土全体に広がります |
| 根粒をつぶして使う | 掘り出した根の根粒を集めてつぶし、水に溶いて、その水に種子を浸してから取り出します | その日のうちに使う必要があります |
| 根を残す | 収穫時に根を掘り出さず畑に残します | 最も手間のかからない維持方法です |
| 野生ヤブツルアズキの根 | 畑のあぜのヤブツルアズキの根から根粒を採取します | 同じ種の野生型なので菌の相性が良いです |

&nbsp;&nbsp;&nbsp;アズキの接種源としては、ダイズ畑の土よりアズキやリョクトウやササゲを植えていた畑の土のほうが優れています。根粒菌には宿主特異性があり、系統によって感染する植物が分かれます。ダイズにはBradyrhizobium japonicumが、ササゲ属（Vigna）にはBradyrhizobiumの別の系統が主に付きます。ダイズ畑の土を使ってもまったく効かないわけではありませんが、感染率と固定効率が落ちます。同じ属の作物を植えていた畑の土があれば、それを優先して使います。

&nbsp;&nbsp;&nbsp;野生のヤブツルアズキは特に貴重な接種源です。畑のあぜや野原によく生えるつる性のマメ科植物で、アズキと同じ種の野生型です。その根にはアズキにそのまま適合する系統の細菌が付いています。夏にヤブツルアズキを見つけたら根を少し掘って根粒を確認しておき、その場所を覚えておけば翌年の接種源になります。

| 接種失敗を招く条件 | 理由 |
|---|---|
| 土壌pH 5.5以下 | 細菌が生きられません |
| 窒素肥料をたっぷり与えた畑 | 植物が取引の必要を感じず、根粒の形成を減らします |
| 水がたまる畑 | 好気性細菌なので酸素がなければ死にます。アズキで最も多い失敗の原因です |
| リン酸が不足した畑 | 窒素固定のエネルギー代謝にリン酸が使われます |
| 接種した種子を日に当てて乾かす | 紫外線と乾燥で菌が死にます |
| 殺菌剤処理や温湯処理の直後に接種 | 細菌が死にます。完全に冷ましてから行います |

### 5-4. 窒素固定の落とし穴

&nbsp;&nbsp;&nbsp;豆を植えると土が良くなるという言葉は、条件付きの真実です。数字で確かめてみましょう。アズキの種実のタンパク質は20.63%で、タンパク質を6.25で割ると窒素量が出ます。種実重量の約3.3%が純粋な窒素です。1,000㎡で200kgを収穫すると、その中に約6.6kgの窒素があり、ヘクタールに換算すると66kgです。

| 項目 | ヘクタール当たり窒素 | 方向 |
|---|---|---|
| 根粒による固定量（条件が良い） | 60-100kg | 入る |
| 根粒による固定量（条件が悪い） | 20-40kg | 入る |
| 種実として持ち出し | 60-70kg | 出る |
| 茎葉に残る窒素 | 20-30kg | 畑に戻せば残り、燃やすか運び出せば出る |
| 根と根粒に残る窒素 | 8-15kg | 大部分は畑に残ります |

&nbsp;&nbsp;&nbsp;アズキはダイズより種実の窒素濃度が低く、持ち出し量も少なくなります。ダイズの種実は重量の約6%が窒素であるのに対し、アズキは3.3%です。そのため条件が良ければ収支がプラスに残る余地がダイズより大きくなります。しかし条件が悪い場合、つまり湿害や酸性のために根粒がうまく働かなかった場合は、固定量が20から40kgにとどまるため、種実の持ち出し量60から70kgを下回り、収支がマイナスに転じます。そしてアズキは湿害に弱いため、条件が悪くなる確率が他の豆類より高いのです。

&nbsp;&nbsp;&nbsp;参考までに、トウモロコシの種実は重量の約1.4%が窒素です。アズキの種実は3.3%でトウモロコシの2.4倍、ダイズの種実は6%でトウモロコシの4.5倍です。マメ科作物を種実の収穫目的で育てることは、窒素を畑から抜き取ることと同じ動作なのです。

> **マメ科植物が土地を良くするのは窒素を固定するからではなく、固定した窒素の一部を茎と葉に蓄えて畑に残しておくからです。その茎と葉を運び出してしまえば、アズキは土地を収奪する作物になります。**

| 原則 | 内容 |
|---|---|
| 茎葉は必ず畑へ | アズキの茎と葉と莢殻をすべて戻します。20-30cmに切って覆います |
| 燃やさない | 燃やすと窒素は気体として飛び、カリウムとリン酸だけが残ります |
| 根は掘り出さない | 茎だけを刈り、根はそのままにします |
| 病気にかかった残渣は例外 | 落葉病やウイルス病にかかった株は燃やすか、畑の外で長く腐らせます |
| 燃やした場合は灰を畑に戻す | 窒素は失うが、カリウムとリン酸は回収します |

&nbsp;&nbsp;&nbsp;アズキではこの原則に葛藤があります。アズキは連作障害が激しく、落葉病とウイルス病が土に蓄積します。窒素を残すには茎葉を畑に戻す必要がありますが、病気にかかった茎葉を戻すと病原菌も一緒に残ってしまいます。判断の基準は次の通りです。葉に斑点が少しある程度なら、切って覆っても構いません。下葉が大量に褐変して落ちる落葉病の症状がある株や、モザイク症状が出た株は別に集めて燃やします。畑全体が病気で崩れた年は茎葉を全部畑の外へ出すほうがよく、そのとき失う窒素は翌年、別の方法で補います。

### 5-5. 施肥量と災害時の代替肥料

| 肥料 | 1,000㎡基準 | ㎡換算 | 備考 |
|---|---|---|---|
| 窒素 | 2-4kg | 2-4g | 最小限のみ。根粒が働き出す前の初期用です |
| リン酸 | 4-6kg | 4-6g | 全量元肥。ダイズより多く入れます |
| カリウム | 4-6kg | 4-6g | 全量元肥。種実の肥大と茎の強度に関わります |
| 堆肥 | 1,000kg | 1kg | 完全に腐熟したもの |
| 石灰 | 150-200kg（酸性土） | 150-200g | 播種3-4週間前 |

&nbsp;&nbsp;&nbsp;アズキの施肥がダイズと異なる点は、リン酸とカリウムを多く入れることです。ダイズがそれぞれ3.4kgだったのに対し、アズキは4から6kgです。理由は二つあります。リン酸は窒素固定のエネルギー代謝に使われますが、アズキの根粒はダイズより小さく数も少ないため、効率を高めるにはリン酸を十分に与える必要があります。カリウムは茎の強度と種実の肥大に関わりますが、アズキは開花が長く続いて登熟期間が長く、その間カリウムの要求が続きます。

> **窒素を多く与えると葉ばかり茂って莢が少なくしか付きません。しかも徒長したアズキは下のほうの莢が陰に入って熟しません。**

| 代替資源 | 供給する養分 | 使用法 | 注意 |
|---|---|---|---|
| 草木灰 | カリウム、リン酸、カルシウム | ㎡あたり100-200gをまいて混ぜます | 与えすぎるとpHが7を超え、鉄と亜鉛の吸収が妨げられます |
| 完熟堆肥 | 総合、有機物 | ㎡あたり1kg | 未熟なものは根を傷めたり病気を運んだりします |
| 薄めた尿 | 窒素、カリウム | 水で10倍に薄めて株の間の土に注ぎます | 少量のみ。葉にかからないようにします |
| 骨粉・魚の骨 | リン酸、カルシウム | 焼いて砕き、堆肥に混ぜるか直接まきます | アズキに特に良いです |
| 貝殻・卵の殻 | カルシウム | 焼いて砕いてまきます | 石灰の代わりです |
| 落ち葉の腐葉土 | 総合、有機物 | 土に混ぜ込みます | 水はけと保水を同時に改善します |
| もみ殻・稲わら | カリウム、ケイ酸 | 畝の上にマルチングとして敷きます | アズキは莢が地面に近いためマルチングが特に有用です |
| 粗い砂・砂利 | 水はけ | 粘土質の土に混ぜ込みます | 湿害対策としての土壌改良です |

&nbsp;&nbsp;&nbsp;最後の項目に注目する必要があります。アズキでは水はけの改善が肥料以上の効果を生みます。粘土質で水がたまる畑なら、粗い砂、もみ殻、よく腐らせたおがくず、落ち葉の腐葉土をたっぷり混ぜて土の構造を変えることが、どんな肥料よりも収量を上げます。一度では終わらないため、毎年少しずつ入れて数年かけて変えていきます。こうした改良はアズキだけでなく、その畑で育てるすべての作物に残る投資です。

&nbsp;&nbsp;&nbsp;追肥は原則として必要ありません。生育がはっきり不振なら、開花期または開花から10日後に少量を補います。慣行では尿素を0.1から0.5%の濃度で葉にまく葉面施肥を使いますが、災害時の条件では尿を水で20倍以上に薄めて葉にまくか、10倍希釈液を株の間の土に注ぎます。葉にまくときは必ず日が傾いてから行い、真昼にまくと葉が焼けます。
