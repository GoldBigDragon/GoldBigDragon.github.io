## 6. 播種

### 6-1. 播種時期

| 地域 | 播種適期 | 播種限界期 | 収穫時期 |
|---|---|---|---|
| 韓国中北部 | 6月中旬-下旬 | 7月上旬 | 10月上旬-中旬 |
| 韓国南部 | 6月中旬-7月上旬 | 7月中旬 | 10月中旬-下旬 |

&nbsp;&nbsp;&nbsp;アズキの播種期が6月中旬から下旬に置かれる理由は、発芽最適温度が32-34℃と高いためです。この時期はニンニク、タマネギ、オオムギ、ジャガイモを収穫した直後なので、後作が自然にかみ合います。畑が狭い条件では、この性質は大きな利点です。一年に同じ畑で二回収穫できるようになります。

> **アズキは播種が遅れるほど収量がはっきり減ります。7月にずれ込むと開花期間が短くなって莢の数が減り、遅く咲いた花は霜の前に熟しません。**

&nbsp;&nbsp;&nbsp;播種が遅れたときの対応は決まっています。播種量を増やすことです。適期には1,000㎡あたり3-4kgを播きますが、遅れたときは5-7kgに増やします。遅く植えたアズキは個体が小さく育つため、個体数を増やして面積当たりの収量を維持する方式です。株間も狭めます。ただしこの補正には限界があり、7月中旬を過ぎると早生種のイェパットでない限り、収穫できるものはほとんどありません。

&nbsp;&nbsp;&nbsp;播種時期と梅雨の関係も併せて見ておく必要があります。6月中旬から下旬は韓国の梅雨（チャンマ、6月下旬～7月）が始まる時期で、アズキの幼苗期は湿害に最も弱い時期です。梅雨の予報を見て播種日を調整できるなら、梅雨の雨が一度通り過ぎた直後に植え、若いアズキが雨を受ける量を減らすほうが有利です。調整できないなら、畝をできる限り高くすることで備えます。

### 6-2. 種子の準備

| 項目 | 方法 | 災害時の条件では |
|---|---|---|
| 選別 | 斑点、変色、しわ、虫食い穴のある粒を除きます | アズキゾウムシの穴は小さく丸く、表面に白い点のように見えます |
| 水に浮かべる | 水に浸けて浮くものを取り除きます | ゾウムシに食われた粒は中が空になって浮きます。すぐに引き上げて乾かします |
| 温湯浸漬 | 65℃の湯に5分浸けて種子伝染病を殺します | 水の量は種子の10倍以上にします。時間を超えると発芽力が損なわれます |
| 灰まぶし | 細かい草木灰をまぶします | 消毒と乾燥を助け、鳥や虫を遠ざける効果があります |
| 根粒接種 | アズキ・リョクトウ・ササゲを育てた畑の土をまぶします | 温湯処理後、完全に冷ましてから行います |
| 発芽試験 | 濡らした布に20粒を包み、暖かい場所に数日置きます | アズキは暖かくないと芽が出ないため、試験も暖かい場所で行います |

&nbsp;&nbsp;&nbsp;アズキの温湯浸漬の条件は他の豆類と異なります。ダイズが50-55℃で10-15分であるのに対し、アズキは65℃前後で5分です。温度は高く、時間は短いのです。この違いを守ることが重要です。65℃の湯に10分浸けると発芽力がひどく落ち、50℃で5分では消毒効果がほとんどありません。温度計がなければ、沸騰した湯と常温の水を2対1くらいの割合で混ぜた湯がおよそ65℃になり、手を入れるのが難しい程度です。5分を数えたらすぐに冷水で冷まします。

&nbsp;&nbsp;&nbsp;選別で必ず確認すべきなのはアズキゾウムシの穴です。直径1mm以内の丸い穴が種皮に開いていたり、表面に白い点のようなものが見えたりする場合、その粒にはすでに卵や幼虫が入っています。その種子を植えても発芽せず、貯蔵庫にそのまま置けば次の世代の出発点になります。水に浮かべる方法はこの選別を大きく容易にします。食われた粒は中が空になって浮くからです。

### 6-3. 播種方法

| 項目 | 基準 | 理由 |
|---|---|---|
| 播種の深さ | 3-5cm | 浅いと乾いて鳥に食べられます。深いと出芽が悪くなります |
| 1穴あたりの粒数 | 2-3粒 | あとで2本を残して間引きます |
| 播種量（適期） | 3-4kg/1,000㎡ | |
| 播種量（晩期） | 5-7kg/1,000㎡ | 遅く植えるほど密に播きます |
| 一条栽培 | 条間60-70cm、株間10-15cm | 直立型に適しています |
| 二条栽培 | 120cmの畝に40cm間隔で二条、株間10-15cm | 面積効率が高いです |
| 畝の高さ | 20cm以上、できれば25-30cm | 湿害防止の要です |

&nbsp;&nbsp;&nbsp;マルチングの効果はアズキで特に大きいです。慣行試験では、ビニールを掛けなかった圃場は掛けた圃場より収量が24%減りました。ビニールがない条件でも同じ原理が使えます。わら、もみ殻、落ち葉、刈り取った雑草で畝の上を5cmから10cmの厚さに覆うと、三つの効果が同時に得られます。雑草が抑えられ、表面からの蒸発が減り、雨が降ったときに土が跳ねて下のほうの莢に付くのを防ぎます。アズキに登録された除草剤がなく草取りを手でしなければならない条件では、マルチングが労働を直接減らしてくれます。

&nbsp;&nbsp;&nbsp;ただし有機物マルチングには注意が一つ付きます。播種直後に厚く覆うと若い芽が出てこられず、湿ったマルチングの下で土が乾かず湿害が悪化することがあります。アズキでは発芽が終わって本葉が二、三枚出たあと、1回目の土寄せを終えた時点で覆うのが安全です。

&nbsp;&nbsp;&nbsp;播種直後の脅威は鳥です。ハトとカササギとキジが芽を出したばかりのアズキの子葉をついばみ、子葉を失った株はたいてい枯れます。播種列の上に木の枝やわらを薄く覆うか、発芽まで網や古い防虫網を掛けるか、光る紐を交差させて張っておきます。

## 7. 水管理 - 湿害が最大の敵

| 時期 | 水管理 | 理由 |
|---|---|---|
| 播種から発芽 | 土がカラカラに乾かないようにします | 発芽に水分が必要です |
| 幼苗期 | 比較的乾燥気味に管理します | 湿害に最も弱い時期です |
| 梅雨の時期 | すべきことは灌水ではなく排水です | 排水路をさらい、たまった水を抜きます |
| 開花期-莢肥大期 | 干ばつになれば十分に灌水します | この時期の乾燥は莢の数を減らします |
| 成熟期 | 灌水を中断します | 過湿だと莢が乾かず種実にカビが生えます |

> **アズキで「水管理」という言葉は、たいてい水をやることではなく水を抜くことを意味します。畝を高くし溝をさらう作業が灌水より先です。**

| 症状 | 原因 | 対処 |
|---|---|---|
| 日中に葉がしおれ夕方に回復する | 一時的な水分不足。正常です | そのままにします |
| 朝も葉がしおれていて土が乾いている | 乾燥 | 灌水します |
| 朝も葉がしおれていて土が湿っている | 過湿で根が傷んでいます | 直ちに溝をさらって水を抜きます。これ以上水を与えてはいけません |
| 下葉が黄色くなり根が褐色に腐った | 湿害 | 排水と土寄せ。ひどい場合は回復が難しいです |
| 葉全体が薄い黄色だが萎れていない | 根粒不良による窒素不足 | 根を掘り出し根粒を割って確認します |
| 下葉に褐色の斑が広がって落ちる | 落葉病または褐色斑紋病 | 病害です。通風を確保し病葉を取り除きます |
| 花が落ちて莢が少ない | 開花期の乾燥または高温 | 灌水とマルチングで地温を下げます |
| 莢は多いが粒が小さい | 莢肥大期の水不足またはカリウム不足 | 灌水、草木灰 |

&nbsp;&nbsp;&nbsp;水不足と過湿を見分ける最も確実な方法は、土を掘ってみることです。葉がしおれているとき、株の横を10cmほど掘って土を手で握ってみます。さらさらと崩れれば乾燥で、固まって水気がにじみ出れば過湿です。この二つの状況は対処がまったく逆なので、確認せずに水をやるのは危険です。アズキ畑で葉がしおれる原因の半分以上は過湿であり、そこに水をさらに与えるとそのまま枯れます。

&nbsp;&nbsp;&nbsp;梅雨の時期に実際に行う作業は三つです。第一に、溝にたまった水が畑の外へ抜けているか確認し、詰まった場所を通します。第二に、畝の上に水がたまる場所があれば土を足して水が流れるようにします。第三に、雨が止んだ直後は畑に入りません。濡れた土を踏むと固まって水はけがさらに悪くなり、濡れた葉に触れると病気がうつります。雨が止んで土が乾いてから入ります。

## 8. 栽培管理

### 8-1. 土寄せ - 三回

| 回数 | 時期 | 土寄せの部位 |
|---|---|---|
| 1回目 | 本葉2-3枚 | 子葉の節まで土を上げます |
| 2回目 | 本葉4-5枚 | 単葉の節まで上げます |
| 3回目 | 本葉6-7枚 | 第1本葉の節まで上げます。開花前に終えます |

&nbsp;&nbsp;&nbsp;アズキでの土寄せは他の豆類より重要です。四つのことが同時に起こり、そのうち二つがアズキの弱点を直接補います。第一に、畝がさらに高くなり水はけが良くなります。湿害はアズキの敵なので土寄せが特に重要です。第二に、若い雑草が土に埋もれます。アズキに使える除草剤がないため、これも実質的な価値があります。第三に、埋もれた茎から新しい根が出て吸収面積が増えます。第四に、株元が埋まって倒伏が減ります。

> **土寄せは必ず開花前に終えます。花が咲いたあとに畑に入って土を動かすと、花が落ち細根が切れて収量が減ります。**

&nbsp;&nbsp;&nbsp;人手が足りず三回すべてできない場合は優先順位があります。3回目が最も重要で、次が1回目です。3回目は畝を最も高く上げ、梅雨時の湿害を防ぎ倒伏を防止します。1回目は若い株の活着を助け、その時期の雑草を埋めます。2回目は省いても大きな損失はありません。

### 8-2. 雑草管理

| 時期 | 方法 | 備考 |
|---|---|---|
| 播種後2-3週 | 1回目の草取り。浅くかきます | 1回目の土寄せと兼ねます |
| 播種後4-5週 | 2回目の草取り | 2回目の土寄せと兼ねます |
| 開花前 | すべての草取りを終えます | 以後は畑に入りません |
| 3回目の土寄せ直後 | マルチングで覆います | その後はほとんど手がかかりません |

&nbsp;&nbsp;&nbsp;アズキに登録された除草剤がないという事実は、慣行栽培では悩みの種ですが、災害時の条件ではむしろ有益な情報になります。すでに手で草取りをしてきた作物だという意味であり、薬剤が消えた状況でも栽培方式が変わらないという意味です。その代わり、労働はそれだけ確実にかかります。初期の一か月から一か月半の草取りが収量を作り、そのあと葉が地面を覆えば雑草は大きく増えません。

&nbsp;&nbsp;&nbsp;マルチングと草取りを組み合わせる順序が労働を最も減らします。1回目と2回目の草取りを土寄せと兼ねて行い、3回目の土寄せを終えたあと畝の上をわらやもみ殻や刈り取った雑草で覆います。覆う前に畑を一度きれいに草取りしてから覆うと、その下では新しい雑草がほとんど生えません。開花以降に畑に入る必要がなくなるため、花が落ちる心配も消えます。

### 8-3. 倒伏と支柱

| タイプ | 管理 |
|---|---|
| 直立型 | 支柱は不要です。土寄せだけで十分です |
| つる型 | 竹、木の枝、トウモロコシの茎を立てて誘引します |
| 窒素過剰で徒長した場合 | 翌年は施肥を減らします。当年は紐を張って支えます |

&nbsp;&nbsp;&nbsp;つる型アズキの支柱は、災害時の条件でも作るのが難しくありません。トウモロコシを収穫したあと茎を刈らずにそのまま残しておけば、その場所が翌年の支柱になります。三本を束ねて三角形に立てる方式、二列に竿を立てて上を横木でつなぎ網のようにする方式がよく使われます。ただしアズキはつるがそれほど重くないため、頑丈な構造は必要ありません。膝から腰の高さの支えがあるだけでも、莢が地面に触れず腐るのを防げます。

## 9. 病害虫

&nbsp;&nbsp;&nbsp;アズキの病害虫圧はCです。無防除時の推定減収率は48.9%で、防除をしなければ半分近くを失います。その損失が畑と倉庫に分かれているのがアズキの特徴です。畑ではカメムシと落葉病が、倉庫ではアズキゾウムシが奪っていきます。

### 9-1. 主な病害

| 病名 | 症状 | 発生条件 | 薬なしでの対応 |
|---|---|---|---|
| ウイルス病（モザイク病） | 葉がモザイク状にまだらになり生育が止まります | アブラムシが媒介します | 治療不能です。発見したらすぐ抜いて燃やし、アブラムシを減らします |
| 落葉病 | 下葉から褐変し大量に落ちます | カビ。連作した畑の土に蓄積します | 3年以上の輪作が唯一の対策です。病気にかかった残渣を燃やします |
| 褐色斑紋病 | 下葉に褐色のまだら模様ができます | 8-9月の多湿 | 通風確保、ボルドー液、病葉の除去 |
| 褐斑病 | 葉の裏に褐色の斑点ができます | 多湿 | 開花10日前と開花期にボルドー液 |
| うどんこ病 | 葉の表面が白い粉で覆われます | 乾燥して通風が悪いとき | 牛乳5-10倍希釈液、通風確保 |
| 炭疽病 | 暗褐色の病斑ができ落葉します | 多湿 | 種子選別、輪作、ボルドー液 |
| 根腐れ病 | 根が褐色に腐り下葉が黄色くなります | 過湿、連作 | 排水、畝を高くする、輪作 |

&nbsp;&nbsp;&nbsp;落葉病は特に強調しておく必要があります。アズキの連作適応性がBにとどまる主な原因であり、同じ畑にアズキを続けて植えると現れる代表的な障害です。カビが土に残って年々増え、下葉から褐変して落ちることで光合成面積が減り、実が充実しません。薬剤があっても完全な防除は難しく、薬のない条件では輪作が唯一の手段です。3年休ませるべきだという基準はこの病気から来ています。

### 9-2. 主な害虫

| 害虫 | 発生時期 | 被害 | 薬なしでの防除 |
|---|---|---|---|
| カメムシ類 | 8月から増えます | 莢を刺して汁を吸い、しいなにします | 早朝の捕殺、おとり作物、防虫網 |
| アズキゾウムシ | 畑で産卵、貯蔵庫で孵化 | 種実を食い荒らし中を空にします | 15節で詳しく扱います |
| ネキリムシ類 | 初期 | 若い茎を根元から切ります | 夜に土をかき分けて幼虫を捕まえます。株元に灰をまきます |
| シロイチモジヨトウ | 夏 | 葉と莢を食い荒らします | 手で捕まえます。卵塊は葉ごと取り除きます |
| アブラムシ類 | 7-8月 | 汁を吸いウイルス病を媒介します | 石けん水（水1Lに石けん5g）を葉の裏に散布します |
| 鳥 | 播種直後 | 子葉をついばみます | 発芽までわらや網で覆います |
| キバノロ・ノロジカ | 夏 | 葉と茎を食べます | 柵や網を張ります |

&nbsp;&nbsp;&nbsp;ネキリムシはアズキで初期の被害が大きい害虫です。幼虫は昼間は土の中に隠れていて、夜に出てきて若い茎を根元から切ってしまいます。朝に畑へ出てみると、元気だったはずの株がぽきりと倒れているという具合です。対応は二つあります。倒れた株の周りの土を指で2-3cmかき分けると、ずんぐりした幼虫が体を丸めているので捕まえます。そして株元の周りに細かい草木灰やもみ殻を巻いておくと、幼虫が通るのを嫌がります。

&nbsp;&nbsp;&nbsp;カメムシは8月から増え、莢肥大期と重なります。防除方法はダイズと同じです。早朝、気温が低いときは動きが鈍いため、莢の下を探って手で払い落とし、バケツで受けます。畑の周りにゴマやアワやモロコシを植えておびき寄せ、そこで集中的に捕る方法も効果があります。アズキは自家受粉なので、開花期に寒冷紗や防虫網を掛けても結実に支障はなく、面積が小さければこの方法が最も確実です。

### 9-3. 薬なしでの防除資材と耕種的防除

| 資材 | 作り方 | 対象 |
|---|---|---|
| ボルドー液 | 水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜます | カビ病、細菌病 |
| 石けん水 | 水1Lに無香料石けん5g | アブラムシ、ダニ |
| 牛乳希釈液 | 牛乳を水で5-10倍に薄めます | うどんこ病 |
| 草木灰水 | 灰1升を水10Lに一晩浸け、上澄みを使います | カビの抑制 |
| 乾いた灰まき | 露のある朝に葉と株元にまきます | 食葉性の虫、ネキリムシ |
| 木酢液 | 300-500倍に希釈します | 忌避 |
| 辛い唐辛子・ニンニク水 | すりつぶして水に漬け、こして使います | 忌避 |

| 耕種的防除 | 原理 |
|---|---|
| 3年以上の輪作 | 落葉病とウイルス病は輪作以外に対策がありません |
| 畝を高くする | アズキの病害の半分以上が過湿に関係します |
| 種子選別 | 炭疽病とアズキゾウムシは種子について回ります |
| 栽植距離の確保 | 通風があれば葉が早く乾き、カビが定着できません |
| マルチング | 土が跳ねて下葉に病原菌がうつるのを防ぎます |
| 雨上がりの畑への立ち入り禁止 | 濡れた葉に触れると病原菌がうつります |
| 病気にかかった残渣の焼却 | 落葉病にかかった葉は畑に残しません |
| 畑のあぜの整理 | マメ科雑草がカメムシとウイルス病の中間宿主になります |

> **薬のない条件でのアズキ防除の要点は二つに絞られます。水を抜くことと畑を回すことです。この二つがアズキの病害の大部分を決めます。**
