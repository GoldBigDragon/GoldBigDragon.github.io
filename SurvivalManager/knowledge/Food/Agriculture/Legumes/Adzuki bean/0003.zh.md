## 3. 栽培环境

### 3-1. 气温与光照量

| 条件 | 极限值 | 最适值 | 超出范围时 |
|---|---|---|---|
| 发芽温度 | 最低6-10℃，最高40-44℃ | 32-34℃ | 低于15℃发芽变慢，种子会腐烂 |
| 播种期地温 | 15℃以上 | 20℃以上 | 播种在冷土中会导致初期生长受阻 |
| 生育温度 | 15-35℃ | 20-24℃ | 对低温特别敏感 |
| 结实温度 | 18-32℃ | 20-30℃ | 幅度10℃，范围较窄 |
| 霜 | 零度以下枯死 | - | 没有耐寒性 |
| 光照 | 每天6小时以上 | 每天8小时以上 | 40%遮光时产量减半 |
| 日照长度 | 短日植物 | 日照变短时开花 | 播种过晚会导致植株矮小就开花 |

&nbsp;&nbsp;&nbsp;发芽最适温度32℃至34℃，是这份作物表所列豆类中最高的数值。这一点解释了红小豆为什么是晚播作物。韩国农田地温达到30℃通常要到6月中旬之后，因此红小豆的适宜播种期落在6月中下旬。这一时期正好在大蒜、洋葱、大麦收获之后，与接茬种植自然衔接。红小豆在韩国的种植制度中长期占据接茬作物的位置，并非偶然。

&nbsp;&nbsp;&nbsp;不耐低温这一点从两个方向起作用。春天必须等到地温回升，秋天则必须在霜降之前完成灌浆成熟。所幸生育期只有100到120天，时间较为宽裕。6月中旬播种、10月上中旬收获，就能赶在霜降之前结束。播种一旦拖到7月，产量会明显下降，因此将7月上旬定为韩国中北部地区的播种极限。

### 3-2. 土壤与水分 - 湿害就是一切

| 条件 | 极限值 | 最适值 | 备注 |
|---|---|---|---|
| 土性 | 排水不良地无法栽培 | 排水良好的沙质壤土-壤土 | 排水是所有条件中的第一位 |
| pH | 5.5-7.0 | 6.0-6.5 | 酸性土中根瘤会减少 |
| 垄台高度 | 20cm以上 | 25-30cm | 平畦栽培产量减少34% |
| 排水沟 | 必需 | 深30cm以上 | 排水沟要先于垄台准备 |
| 作期蒸散量 | - | 约400mm | 在豆类中属较少的一类 |
| 淹水 | 淹没1天以上难以恢复 | - | 在豆类中最不耐淹 |
| 地下水位 | 60cm以下 | 80cm以下 | 种在稻田时最重要的条件 |

> **种在平畦上的红小豆，产量比种在高垄上少34%。红小豆栽培中，垄台高度是比施肥更优先的条件。**

&nbsp;&nbsp;&nbsp;红小豆为何如此不耐湿害，值得理解清楚。原因有两个，相互叠加。第一，根瘤菌是需要氧气的好氧细菌。土壤一旦积水，氧气消失，根瘤会比根系本身更早丧失功能。这一点对所有豆类都成立，但红小豆根系较浅，更直接地暴露在表土水分状态之下。第二，红小豆的根几乎没有应对缺氧的适应结构。它不像水稻那样有通过茎将空气输送到根部的通气组织，也不像大豆那样能向深处伸展、寻找未被淹没的土层。

&nbsp;&nbsp;&nbsp;因此，红小豆地的整地要从排水开始，顺序也很重要。首先查看地块的水流走向，找出低洼处和积水处，这些地方不种红小豆。接下来开排水沟，在地块四周和内部挖沟，让水往低处排走。然后再起垄，垄台高度20cm以上，最好做到25到30cm，并把垄顶做成圆弧形，防止积水。最后再施肥。

&nbsp;&nbsp;&nbsp;也有必须在稻田种红小豆的情况。在耕地不足的条件下，稻田会被改作旱地使用，而红小豆恰恰是最不适合这类地块的作物。即便如此仍要种植，应选用耐湿品种，把排水沟挖深到50至80cm，垄台抬高到30cm以上，并把播种期调整到避开韩国的梅雨季（6月下旬至7月）。即便如此风险依然很大，因此稻田里种豇豆比种红小豆更为合理。

## 4. 品种

### 4-1. 按生育形态分类

| 类别 | 特征 | 灾害适应性 |
|---|---|---|
| 直立型（普通红小豆） | 株高30-50cm，不需支架，抗倒伏 | 管理简便，是基本选择 |
| 蔓生型（蔓生红小豆） | 蔓长超过1m，需要支架，产量较高 | 有支架材料且劳力宽裕时选用 |

&nbsp;&nbsp;&nbsp;在灾害条件下，直立型是基本选择。蔓生型产量虽高，但需要立支架，还要花费引蔓的人工。如果能获得竹竿或树枝、人手也充裕，蔓生型的高产量很有吸引力；否则直立型更为稳妥。不过有一个例外：如果地块极其狭小，用蔓生型占用上方空间反而能在单位面积产量上占优势。也可以把玉米秆原样留在地里当支架用。

## 5. 整地与施肥 - 根瘤菌与氮素收支

### 5-1. 固氮是如何发生的

&nbsp;&nbsp;&nbsp;空气中78%是氮气，但植物无法利用它。空气中的氮是由两个原子以三键牢固结合而成的分子（N2），要打破这个键需要巨大的能量。工业上打破这一键来制造氨的方法就是哈伯-博施法，需要用到高温、高压、催化剂和大量化石燃料。

&nbsp;&nbsp;&nbsp;根瘤菌在常温常压下就能完成这件事。它用一种叫固氮酶的酶打断三键，把氮转化为氨。不过这一反应需要大量能量，而细菌自身不能进行光合作用，因此它们住进豆科植物的根内，从植物那里获得糖分，作为回报，把固定下来的氮交给植物。这是一种交易关系。

| 阶段 | 发生的事情 |
|---|---|
| 1. 信号交换 | 红小豆的根分泌类黄酮，土壤中的细菌应答并释放结瘤因子 |
| 2. 侵染 | 根毛弯曲，把细菌包裹其中并带入根内 |
| 3. 根瘤形成 | 根细胞分裂，根瘤膨大，细菌在其中定居 |
| 4. 固氮 | 根瘤内的固氮酶把空气中的氮转化为氨 |
| 5. 分配 | 氨转化为氨基酸，运往茎、叶和豆荚 |
| 6. 衰老 | 灌浆期根瘤失去功能，随根一同归还土壤 |

&nbsp;&nbsp;&nbsp;固氮酶对氧气极为敏感，一旦接触氧气就立即失去功能。因此根瘤内部充满了一种叫豆血红蛋白的红色色素蛋白，用来抓住氧气。这与人血呈红色的原理相同，掰开根瘤后内部呈红色或粉红色，就是这种色素的颜色。这一点在实际操作中极为重要：红色就是该根瘤正在固氮的可见证据。

### 5-2. 如何确认是否长出了根瘤

| 顺序 | 内容 |
|---|---|
| 1 | 开花开始前后，播种后5-7周是最佳时机 |
| 2 | 挑选两三株看起来健康的植株 |
| 3 | 不要拔起，用铁锹在周围大范围铲挖，连土一起挖出。直接拔起会使细根上的根瘤留在土里 |
| 4 | 放入水桶，轻轻把土洗掉 |
| 5 | 数一数主根和粗细根上根瘤的数量 |
| 6 | 用指甲掰开几个根瘤，观察内部颜色 |

| 观察结果 | 含义 | 应对 |
|---|---|---|
| 每株根瘤15个以上 | 接种效果良好 | 维持现状 |
| 掰开后内部呈红色或粉红色 | 正在固氮 | 状态良好 |
| 掰开后内部呈白色或浅绿色 | 根瘤已形成但未固氮 | 检查酸度、湿害、磷不足等问题 |
| 掰开后内部呈褐色或黑色 | 已衰老或已死亡 | 灌浆期属正常，开花期则有问题 |
| 根瘤5个以下 | 接种失败 | 若叶片发黄，少量补施氮肥 |

> **挖出根系、掰开根瘤查看红色，这一个习惯，在没有氮肥的世界里，是判断红小豆种植成败最可靠的信号。**

&nbsp;&nbsp;&nbsp;在红小豆上确认根瘤尤其有用，原因如下。红小豆地里叶片发黄的原因有三个：缺氮、湿害导致的根系损伤、落叶病。这三者的应对方式完全不同：缺氮要施肥，湿害要排水，落叶病则要拔除病株并轮作。挖开根系就能区分这三者：没有根瘤是缺氮，有根瘤但根已呈褐色腐烂是湿害，茎基部变色而根系完好则是病害。

### 5-3. 到哪里获取接种源

| 方法 | 步骤 | 注意事项 |
|---|---|---|
| 蘸取种过红小豆·绿豆·豇豆地块的土 | 从前一年种过同属（Vigna）作物、根瘤长得好的地块，取表土5-15cm处的土。把种子稍微沾湿后均匀裹上土，随即播种 | 在阴凉处操作，30分钟内播完。晒干会导致菌死亡 |
| 把土撒在播种行里 | 在要播种的行里撒土，随耕作一起翻入土中。每10㎡约一铁锹 | 用量较大，但菌能扩散到整片土壤中 |
| 捣碎根瘤使用 | 收集挖出的根瘤捣碎，溶于水中，把种子浸入该水中后取出 | 须当天使用 |
| 保留根系 | 收获时不挖出根系，留在地里 | 是最省事的维持方法 |
| 野生野红小豆的根 | 从地埂上野红小豆的根上采集根瘤 | 属同种野生型，菌种相性好 |

&nbsp;&nbsp;&nbsp;作为红小豆的接种源，种过红小豆、绿豆或豇豆的地块的土比大豆地的土更合适。根瘤菌具有宿主特异性，不同菌系感染的植物也不同。大豆主要由Bradyrhizobium japonicum侵染，豇豆属（Vigna）则主要由Bradyrhizobium的另一菌系侵染。用大豆地的土并非完全无效，但侵染率和固氮效率会下降。如果有种过同属作物的地块的土，应优先使用。

&nbsp;&nbsp;&nbsp;野生野红小豆是尤为珍贵的接种源。它是地埂和野地里常见的蔓生豆科植物，是与红小豆同种的野生型，根上附着的正是与红小豆完全相配的菌系。夏天若发现野红小豆，可以挖一点根查看根瘤，并记住那个位置，第二年就能成为接种源。

| 导致接种失败的条件 | 原因 |
|---|---|
| 土壤pH 5.5以下 | 细菌无法存活 |
| 施了大量氮肥的地块 | 植物感受不到交易的必要，减少根瘤形成 |
| 积水的地块 | 好氧细菌缺氧即死，是红小豆最常见的失败原因 |
| 缺磷的地块 | 固氮的能量代谢需要用到磷 |
| 接种后的种子被晒干 | 紫外线和干燥会使菌死亡 |
| 杀菌剂处理或温汤处理后立即接种 | 细菌会被杀死，须完全放凉后再接种 |

### 5-4. 固氮的陷阱

&nbsp;&nbsp;&nbsp;"种豆能养地"这句话是有条件的真理。我们用数字来验证。红小豆种实的蛋白质含量为20.63%，蛋白质除以6.25即得氮含量，种实重量的约3.3%是纯氮。1,000㎡收获200kg，其中约含6.6kg氮，换算成公顷则为66kg。

| 项目 | 每公顷氮量 | 方向 |
|---|---|---|
| 根瘤固氮量（条件好） | 60-100kg | 输入 |
| 根瘤固氮量（条件差） | 20-40kg | 输入 |
| 随种实带出 | 60-70kg | 输出 |
| 留在茎叶中的氮 | 20-30kg | 还田则保留，焚烧或运出则输出 |
| 留在根和根瘤中的氮 | 8-15kg | 大多留在地里 |

&nbsp;&nbsp;&nbsp;红小豆种实的氮浓度低于大豆，带出量也更少。大豆种实重量约6%为氮，红小豆则为3.3%。因此条件好时，收支结余为正的空间比大豆更大。但条件差时——也就是因湿害或酸性导致根瘤未能正常工作——固氮量仅有20到40kg，低于种实带出量60到70kg，收支就会转为负值。而红小豆不耐湿害，出现不利条件的概率又高于其他豆类。

&nbsp;&nbsp;&nbsp;作为参考，玉米种实重量约1.4%为氮。红小豆种实为3.3%，是玉米的2.4倍；大豆种实为6%，是玉米的4.5倍。以收获种实为目的种植豆科作物，本质上等同于把氮从地里带走。

> **豆科作物养地，并非因为它能固氮，而是因为固定下来的氮有一部分留在了茎叶中并还给了土地。一旦把这些茎叶运走，红小豆就会变成掠夺地力的作物。**

| 原则 | 内容 |
|---|---|
| 茎叶务必还田 | 红小豆秆、叶片和荚壳全部归还地里，切成20-30cm覆盖于地表 |
| 不要焚烧 | 焚烧会使氮以气体形式逸失，只留下钾和磷 |
| 不挖根 | 只割茎，根留在原地 |
| 染病残体除外 | 感染落叶病和病毒的植株应焚烧或在地块外长期腐熟 |
| 若已焚烧则把灰还田 | 虽损失氮，但可回收钾和磷 |

&nbsp;&nbsp;&nbsp;这一原则在红小豆上存在矛盾。红小豆连作障碍严重，落叶病和病毒会在土壤中积累。要保留氮就需要把茎叶还田，但把染病的茎叶还田，病原菌也会一并留下。判断标准如下：如果叶片只是有少量斑点，切碎覆盖即可；若下部叶片大量褐变脱落，出现落叶病症状，或植株出现花叶症状，则应单独收集焚烧。若整块地当年因病害而严重受损，最好把茎叶全部运出地块，届时损失的氮留待翌年以其他方式补足。

### 5-5. 施肥量与灾害替代肥料

| 肥料 | 每1,000㎡ | 换算每㎡ | 备注 |
|---|---|---|---|
| 氮 | 2-4kg | 2-4g | 只需最低限度，供根瘤发挥作用前的初期使用 |
| 磷 | 4-6kg | 4-6g | 全部作基肥，比大豆多施 |
| 钾 | 4-6kg | 4-6g | 全部作基肥，关系到种实膨大和茎秆强度 |
| 堆肥 | 1,000kg | 1kg | 须完全腐熟 |
| 石灰 | 150-200kg（酸性土） | 150-200g | 播种前3-4周施用 |

&nbsp;&nbsp;&nbsp;红小豆施肥与大豆的不同之处在于要多施磷和钾。大豆两者各为3.4kg，而红小豆则是4到6kg。原因有二：磷用于固氮的能量代谢，红小豆的根瘤比大豆更小、数量也更少，要提高效率就必须保证磷肥充足；钾关系到茎秆强度和种实膨大，红小豆开花期长、灌浆期也长，这期间对钾的需求会持续存在。

> **多施氮肥只会让叶片徒长茂密，结荚反而减少。而且徒长的红小豆下部豆荚会被遮阴，无法成熟。**

| 替代资源 | 供给的养分 | 用法 | 注意事项 |
|---|---|---|---|
| 草木灰 | 钾、磷、钙 | 每㎡撒100-200g并混入土中 | 过量会使pH超过7，阻碍铁和锌的吸收 |
| 腐熟堆肥 | 综合养分、有机质 | 每㎡1kg | 未充分腐熟会烧根并传播病害 |
| 稀释尿液 | 氮、钾 | 用水稀释10倍后浇灌到株间土壤 | 只用少量，避免接触叶片 |
| 骨粉·鱼骨 | 磷、钙 | 烤后磨碎，拌入堆肥或直接撒施 | 对红小豆特别有效 |
| 贝壳·蛋壳 | 钙 | 烤后磨碎撒施 | 可替代石灰 |
| 落叶腐叶土 | 综合养分、有机质 | 混入土中 | 同时改善排水与保墒 |
| 稻壳·稻草 | 钾、硅酸 | 覆盖在垄面上作覆盖物 | 红小豆豆荚贴近地面，覆盖尤其有效 |
| 粗砂·砂砾 | 排水 | 混入黏质土中 | 作为湿害对策的土壤改良 |

&nbsp;&nbsp;&nbsp;最后一项值得特别关注。对红小豆而言，改善排水的效果胜过施肥。如果地块黏土多、容易积水，大量掺入粗砂、稻壳、腐熟好的锯末和落叶腐叶土来改变土壤结构，其增产效果超过任何肥料。这种改良无法一次完成，需要每年少量添加，用数年时间逐步改变。这样的改良不仅惠及红小豆，也是留给这块地上所有作物的长期投资。

&nbsp;&nbsp;&nbsp;追肥原则上不需要。若生育明显不良，可在开花期或开花后10天补施少量。惯常做法是用0.1%到0.5%浓度的尿素进行叶面喷施，而在灾害条件下，可将尿液用水稀释20倍以上后喷叶，或用10倍稀释液浇灌到株间土壤。叶面喷施必须在日头偏斜后进行，正午喷施会灼伤叶片。
