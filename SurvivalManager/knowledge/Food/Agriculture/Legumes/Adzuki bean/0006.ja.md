## 14. 毒性と抗栄養成分

&nbsp;&nbsp;&nbsp;アズキは十分に加熱すれば安全な食品です。ダイズやインゲンマメほど強力な防御物質は含んでいないため危険度は低めですが、生や半生で食べると消化障害が起こります。マメ科植物に共通する抗栄養成分が含まれているためです。

### 14-1. 抗栄養成分の正体

| 成分 | 働き | 症状 | 除去方法 |
|---|---|---|---|
| トリプシンインヒビター | タンパク質分解酵素トリプシンの働きを妨げます | 腹痛、下痢、タンパク質利用率の低下 | 6時間浸漬後、100℃で30-60分加熱 |
| レクチン | 腸粘膜に付着して吸収を妨げます | 腹痛、嘔吐、下痢 | 浸漬後、煮立った湯で十分に加熱 |
| サポニン | 泡立って胃腸を刺激します | 胃がもたれて下痢をします | 最初のゆで汁を捨て、泡を取り除きます |
| フィチン酸 | 鉄、亜鉛、カルシウムと結合して吸収を妨げます | 長く食べ続けると貧血、亜鉛欠乏 | 浸漬、発芽、発酵で60-80%まで減ります |
| タンニン | 渋味を出し、鉄の吸収を妨げます | 渋味 | 浸漬と最初のゆで汁を捨てること |
| オリゴ糖 | 人が消化できず腸内細菌が発酵させます | お腹にガスがたまります | 浸漬した水と最初のゆで汁を捨てます |

> **アズキは特にサポニンが多い豆です。煮るときに出る泡がサポニンで、この最初の煮汁を捨てることがアズキ調理の第一段階です。捨てないと渋くて腹痛が起こります。**

&nbsp;&nbsp;&nbsp;アズキのサポニンには二つの顔があります。過剰に摂取すると胃腸を刺激して下痢や腹痛を起こしますが、適量であれば抗酸化作用を発揮し利尿効果をもたらします。冬至の日にアズキ粥を食べると体のむくみが取れるという昔からの言い伝えは、この利尿効果を経験的に知っていたものです。最初の煮汁を捨てれば過剰摂取の危険は消え、残ったサポニンの利点は保たれます。

&nbsp;&nbsp;&nbsp;レクチンの危険性は豆の種類によって大きく異なります。アズキのレクチンはインゲンマメ類(Phaseolus)のレクチンよりも毒性がはるかに弱いものです。インゲンマメは生のまま4、5粒食べただけでも数時間以内に激しい嘔吐と下痢が起こり、加熱不十分なインゲンマメによる食中毒が何度も報告されています。特にインゲンマメ類は低温で長く加熱するとかえってレクチンの活性が上がる区間があり、ぬるま湯に長時間置く調理法が最も危険です。アズキはそこまで極端ではありませんが、原則は同じです。煮立った湯で十分な時間加熱すること、これが唯一の安全な方法であり、加熱不十分な豆が生の豆より危険な場合があるという事実もそのまま当てはまります。

### 14-2. 浸漬と加熱の基準

| 処理 | 時間・温度 | 効果 |
|---|---|---|
| 浸漬 | 常温の水に6時間 | 芯まで熱が通ります。サポニンとオリゴ糖の一部が水に溶け出します |
| 浸漬した水を捨てる | 必ず | サポニン、オリゴ糖、タンニンが溶け出しています |
| 最初のゆで汁を捨てる | 5-10分煮た後、湯を捨てて新しい水でまた煮ます | アズキ調理の要となる段階です。渋味と泡が消えます |
| 本煮き | 煮立った湯で40-60分 | トリプシンインヒビターとレクチンが不活性化されます |
| 圧力調理 | 120℃で10-15分 | 燃料が最も少なくて済みます |
| 余熱調理 | 15分煮た後、保温箱に2時間 | 燃料が半分以下に減ります |
| 煮え具合の確認 | 指で押すと簡単につぶれます | 硬い芯が残っていれば加熱不足です |

&nbsp;&nbsp;&nbsp;アズキはダイズより浸漬時間が短く、加熱時間も短くて済みます。ダイズが8時間の浸漬と1時間を超える加熱を必要とするのに対し、アズキは6時間の浸漬と40から60分の加熱で済みます。種皮が薄く脂肪がほとんどないため、熱が早く通るからです。燃料が貴重な条件下では、これは実質的な利点になります。

&nbsp;&nbsp;&nbsp;最初のゆで汁を捨てる段階を省略しないことが重要です。水に浸すだけではサポニンが十分に抜けません。5分から10分煮ると泡がもくもくと上がってきますが、それがサポニンであり、その湯を捨てて新しい水を注ぎ直して煮ます。この工程を経ないアズキは渋く、食べた後お腹に不快感が残ります。水が貴重な状況ではもったいなく感じますが、捨てた水は畑にまくか食器洗いに使えば無駄にはなりません。

### 14-3. 発芽と発酵

| 方法 | 減少する成分 | 程度 |
|---|---|---|
| 発芽 | フィチン酸、トリプシンインヒビター、オリゴ糖 | フィチン酸50-70%、インヒビター30-40%減少 |
| 発酵 | フィチン酸、インヒビター、オリゴ糖 | ほとんどが分解され、吸収率が上がります |
| 浸漬と最初のゆで汁捨て | サポニン、タンニン、オリゴ糖 | かなりの部分が除去されます |

&nbsp;&nbsp;&nbsp;アズキでも芽を出すことができ、芽が出るとビタミンCが作られます。冬に新鮮な野菜がないときに役立つ性質です。ただし、アズキもやしは韓国の食文化に定着しておらず、味や食感の点で豆もやしや緑豆もやしに及びません。ナムルとして食べる目的なら緑豆(緑豆もやし)やダイズ(豆もやし)を使うほうがよく、アズキの発芽は主に抗栄養成分を減らし消化を助ける処理として活用します。浸漬したアズキを湿った布に包んで1日ほど置き、芽がようやく出始めたころに煮ると、そのまま煮るより消化しやすく栄養吸収もよくなります。

## 15. 冷蔵庫なしの貯蔵 - アズキゾウムシ

&nbsp;&nbsp;&nbsp;アズキの貯蔵性はSSですが、条件が付いています。ゾウムシを遮断できた場合です。脂肪が1%未満とほとんどないため酸敗せず、乾燥したアズキは3年経っても臭いが出ません。カビも乾燥さえきちんとしていればほとんど問題になりません。アズキの貯蔵で失敗する原因は事実上一つ、アズキゾウムシです。

> **アズキは腐って失うのではなく、虫に食われて失います。貯蔵の技術とは、すなわちアズキゾウムシを防ぐ技術です。**

### 15-1. まず乾燥です

| 段階 | 方法 | 確認 |
|---|---|---|
| 予備乾燥 | アズキを茎ごとむしろに広げて4-6日 | 莢をねじるとパチンと開くまで |
| 脱穀後の乾燥 | むしろに薄く広げて天日で2-3日 | こまめに返して均一に乾かします |
| 目標水分 | 12%以下 | 噛むと歯が立たずパチンと割れます |
| 塩試験 | 乾いた瓶にアズキと炒り塩を一緒に入れて振ります | 塩が瓶の内壁に付けばさらに乾燥が必要です |
| 冷まし | 完全に冷ましてから入れます | 温かいまま密閉すると結露が生じます |

&nbsp;&nbsp;&nbsp;アズキの目標水分12%は、ダイズの12-13%より少し低めです。理由はゾウムシです。水分が13%を超えるとアズキゾウムシの繁殖速度が明らかに速くなります。12%を下回れば繁殖が遅くなり、10%を下回るとほぼ止まります。ただし乾燥させすぎて9%を下回ると種皮が割れて砕け、種子用ならば発芽力も落ちます。11-12%が均衡点です。

### 15-2. アズキゾウムシの生活と遮断

&nbsp;&nbsp;&nbsp;アズキゾウムシ(Callosobruchus chinensis)を理解するには、この虫が畑で活動を始めるという事実をまず知る必要があります。成虫はまだ畑に付いている莢の上に卵を産み付けます。卵は粟粒より小さく種皮にぴったり付いているため目立ちません。収穫して貯蔵庫に入れるとその卵が孵化し、幼虫が種皮を破って豆の中に入り込み、内側を食べながら育ちます。外見は無事に見えても中身は空になっていきます。十分に育つと丸い穴を開けて出てきて交尾し、再び卵を産み付けます。一世代が25-30日であるため、個体数が幾何級数的に増えます。

| 時点 | 起こること | 対応 |
|---|---|---|
| 畑で | 成虫が莢に卵を産み付けます | 開花後は防虫網、収穫の先延ばし禁止 |
| 収穫直後 | 卵が種皮に付いたまま貯蔵庫に入ります | 水に浮かべて食害された豆を取り除きます |
| 貯蔵初期 | 卵が孵化し幼虫が種皮を破ります | 完全密閉、低温・高温処理 |
| 貯蔵1か月 | 幼虫が豆の中で育ちます | 外からは分かりません |
| 貯蔵2か月 | 成虫が穴を開けて出てきます | この段階で初めて目に見えます |
| 貯蔵6か月 | 袋全体が殻と粉で満たされます | 手遅れです |

| 方法 | 原理 | 適用 | 効果 |
|---|---|---|---|
| 完全密閉 | 酸素を絶って窒息させます | ガラス瓶や金属缶に満杯にして密封します | 最も確実です。3-4週間で卵と幼虫まで死にます |
| 草木灰混ぜ | 微細な粒子が外骨格のワックス層を削って脱水させます | アズキの体積の2-5%を混ぜます | 食べる前に水で洗い流します。種子用にも使えます |
| 珪藻土 | 珪酸質の殻が外骨格を傷つけます | アズキ1kgに1-3g | 灰より効果が高いです。乾いた状態でのみ効きます |
| 油コーティング | 油膜が産卵と孵化を妨げます | アズキ1kgに食用油2-5mLを入れてもみます | 効果が高いです。種子用には使いません |
| 低温処理 | 氷点下で卵と幼虫が死にます | 真冬に数日外に出してから取り込みます | 10月収穫のため、すぐに冬が来ます |
| 高温処理 | 60度で卵と幼虫が死にます | 天日に薄く広げて半日置きます | 種子用には使いません |
| 12度以下の低温保管 | 繁殖が事実上止まります | 地下室、北向きの部屋、地中貯蔵穴 | アズキ貯蔵の理想的な条件です |
| 乾燥唐辛子・サンショウ・ヨモギ・ニンニク | 精油成分が産卵を抑制します | 層状に入れます | 補助手段です |
| 灰に埋める | 密閉と物理的防除を同時に得られます | 甕に灰とアズキを交互に重ねます | 伝統的に広く使われてきました |

&nbsp;&nbsp;&nbsp;最も重要なのは完全密閉です。虫も呼吸をします。密閉した容器の中でアズキと虫が酸素を使うと酸素が減り二酸化炭素が増えて虫が死にます。アズキは休眠状態なのでこの条件に耐えます。容器を満杯にして空間を減らすほど効果は早く現れ、大きな容器一つよりも小さな容器複数にぎっしり詰めるほうがよいです。一つの容器が傷んでも全部は失いません。

&nbsp;&nbsp;&nbsp;アズキには低温処理に有利な事情があります。10月に収穫するため、乾燥と選別を終えるとすぐに真冬になります。密閉した容器を数日外に出して氷点下の気温にさらすと、卵と幼虫が死にます。再び室内に入れるときは容器を開けずに室内で半日置いて温度を合わせてから開けます。冷たい容器をすぐに開けると内側に結露が生じ、カビの元になります。慣行農法で使われる燻蒸消毒の役割を、この低温処理がかなりの部分で代わります。

&nbsp;&nbsp;&nbsp;草木灰は細かいものだけを選んで使います。ふるいにかけて粗い炭の塊を取り除き、細かい部分だけをアズキの体積の2-5%混ぜて、すべての豆に薄くまぶします。赤いアズキが灰色に白っぽくなりますが、食べるときに水で三、四回すすげば本来の色に戻ります。虫が耐性を持てず人に無害で、種子用のアズキにも使えるという点が、油コーティングより優れた長所です。

### 15-3. 貯蔵容器と場所

| 容器 | 密閉 | 期間 | 備考 |
|---|:---:|---|---|
| ガラス瓶 | 非常に良い | 3年以上 | 状態を目で確認できます。光は防げません |
| 金属缶 | 非常に良い | 3年以上 | ネズミと虫を完全に防ぎます。結露に注意します |
| 甕 | 良い | 2-3年 | 温度変化が緩やかでネズミが破れません |
| 厚手のビニール | 普通 | 1年 | ネズミが破ることもあり、ゾウムシが食い破ることもあります |
| 地中貯蔵穴 | 良い | 2-3年 | 温度が12度以下に保たれます。水がしみ込むと全量を失います |

| 保管条件 | 目標 |
|---|---|
| 温度 | 12度以下が理想的。低いほど良いです |
| 湿度 | 空気湿度65%以下 |
| 光 | 完全遮断 |
| 場所 | 地下か北向きの部屋、地面に触れないよう台の上 |
| 点検 | 月に1回。ダイズより頻繁に見ます |

&nbsp;&nbsp;&nbsp;アズキは他の豆類より頻繁に点検する必要があります。アズキゾウムシの一世代は1か月あまりなので、2か月に1回しか見なければすでに一世代を超えている可能性があります。月に1回、容器を振ってみて耳を当てて音を聞き、表面に丸い穴がないか確認します。穴を一つでも見つけたら、すでにかなり広がっている状態なので、全量を取り出して水に浮かべ空になった豆を取り除き、天日で乾かして灰や油を混ぜて再び密閉します。

## 16. 調理と加工

### 16-1. アズキの調理

| 料理 | 手順 | 保存 | 価値 |
|---|---|---|---|
| アズキご飯 | 戻したアズキを最初の煮汁を捨てて煮た後、米と一緒に炊きます | その都度 | 米に不足するビタミンB1とリジンを補います |
| アズキ粥 | アズキを柔らかく煮てつぶし、穀物と一緒に炊きます | 数日 | 燃料は多くかかりますが消化しやすく熱量が凝縮されます |
| あずきまぶし | ゆでたアズキをつぶすか、そのままトック（餅）に使います | 数日 | トックと合わせて食べると穀物と豆の組み合わせになります |
| あずきあん | 煮たアズキをこして皮を除き、煮詰めます | 涼しい場所で数日、乾燥させれば数か月 | 甘味料があれば長持ちします |
| あずき湯・あずき茶 | 炒ったアズキを水で煮出します | その都度 | 水を沸かして飲む必要があるとき、味とミネラルを同時に得られます |
| 乾燥アズキ粉 | 煮て乾燥させ、挽きます | 密閉2-3か月 | 脂肪がないため粉にしても傷みにくいです |
| アズキ発酵 | 煮たアズキを暖かい場所に2、3日置きます | 数日 | 抗栄養成分が減り消化しやすくなります |

&nbsp;&nbsp;&nbsp;アズキの調理で覚えておくべき原則は二段階のゆで方です。戻したアズキを5-10分煮て最初の煮汁を捨て、新しい水を注いで40-60分再び煮ます。最初の煮汁にサポニンとタンニンとオリゴ糖が抜け出るため、この段階を経ると渋味が消えお腹にも優しくなります。アズキ粥やアズキご飯の失敗は、たいていこの段階を省略した結果です。

&nbsp;&nbsp;&nbsp;アズキ粉が傷みにくいという点は、災害時の条件下で価値があります。ダイズ粉は脂肪が16%あるため数か月で酸敗臭がしますが、アズキは脂肪が1%未満であるため粉にしても長持ちします。煮て乾燥させ挽いておけば水で溶いて粥として食べられ、トックに混ぜることもできます。移動しなければならない状況では、重量に対する栄養価が良い形態です。

&nbsp;&nbsp;&nbsp;アズキの甘さはアズキ自体から来るものではありません。糖類含量はわずか0.43gでほとんどありません。アズキ粥やあずきあんの甘さはすべて砂糖や蜂蜜によるものです。甘味料がなくなった状況ではアズキを甘みなしで食べることになりますが、その状態のアズキは香ばしく淡白ですが甘くはありません。この事実を知っていれば落胆しません。甘さが必要であれば、サトウモロコシのシロップ、麦芽（ヨッキルム）で糖化させたジョチョン（水飴）、サツマイモやテンサイを煮詰めたものを併用します。

### 16-2. 燃料を節約する調理

| 方法 | 燃料 | 手順 |
|---|:---:|---|
| 圧力調理 | 最も少ない | 戻したアズキを10-15分加圧します |
| 余熱調理 | 非常に少ない | 最初の煮汁を捨てた後15分煮て火を止め、わら・もみ殻の箱や布団で包んで2時間置きます |
| 大鍋でまとめて | 少ない | 数日分をまとめて一度に煮ておき、分けて食べます |
| あずき茶 | 少ない | 炒っておいたアズキを水で数分煮ます |
| 乾燥アズキ粉 | ほぼ不要 | 煮て乾燥させ挽いておき、水に溶いて食べます |
| 発酵 | 前払い | 一度煮て発酵させておけば、以後の燃料が少なくて済みます |

&nbsp;&nbsp;&nbsp;余熱調理を使うときには注意が必要です。保温箱の中の温度は80度前後にとどまりますが、これはレクチンとトリプシンインヒビターを完全に破壊するには不十分な場合があります。そのため、最初の煮汁を捨てた後の本煮きで最初に煮る時間を15分以上確保し、取り出したときにアズキが指で簡単につぶれるか確認します。芯が残っていれば再度煮ます。

&nbsp;&nbsp;&nbsp;数日分をまとめて一度に煮る方式は、アズキにおいて特に効率的です。アズキは煮ておけば数日は保存して食べられ、冬であればさらに長持ちします。一度火を起こすときに鍋いっぱいに煮て分けておけば、燃料が大きく節約できます。ただし夏には煮たアズキが二日で傷むため、その日のうちに食べる分だけ煮ます。

## 17. 年間作業スケジュール

| 月 | 作業 | 要点 |
|---|---|---|
| 1月 | 貯蔵アズキの点検、種子発芽試験 | 密閉容器を数日外に出して低温処理を兼ねます |
| 2月 | 畑の計画、堆肥の切り返し | 3年休作を守れる区画を確認します |
| 3月 | 石灰散布、堆肥の仕上げ | 播種3-4週間前でなく、早めに入れても構いません |
| 4月 | 前作の管理、水はけの改良 | 粘土質の畑には砂・もみ殻・腐葉土を混ぜ入れます |
| 5月 | 前作の収穫準備、接種源の土の確保 | アズキ・リョクトウ・ササゲを育てた畑の土を掘っておきます |
| 6月 | 前作の収穫、排水路作り、畝立て、播種(中旬-下旬) | 畝を25-30cmの高さにします。湿害対策がすべてです |
| 7月 | 1・2回目の土寄せ、除草、梅雨時期の排水 | 雨が降った直後は畑に入りません |
| 8月 | 3回目の土寄せ、マルチング、開花、根粒の確認、カメムシの監視 | 土寄せは開花前に終えます |
| 9月 | 莢の肥大、灌水、カメムシの捕殺、採種株の印付け | 熟す時期がそろった株に糸を結んでおきます |
| 10月 | 収穫、乾燥、脱穀、選別、茎葉の畑への還元 | 莢の7-8割が熟したときに一度に収穫します |
| 11月 | 仕上げ乾燥、水に浮かべての選別、防虫処理、貯蔵 | 食害された豆を取り除いて密閉します |
| 12月 | 低温処理、貯蔵の点検、冬至のアズキ粥 | 真冬の寒さでアズキゾウムシを退治します |

### 17-1. 忘れてはならない五つのこと

| 項目 | 内容 |
|---|---|
| 畝 | アズキは湿害に最も弱い豆類です。平畝栽培では収量が34%減ります |
| 3年休作 | 落葉病とウイルスは薬では治せず、畑を休ませる時間だけが解決します |
| 収穫時期 | 莢の70-80%が熟したときに一度に収穫します。遅れると裂けて30%を失います |
| アズキゾウムシ | 貯蔵性SSはゾウムシを防いだときの値です。密閉と低温がすべてです |
| 最初の煮汁捨て | 5-10分煮て最初の煮汁を捨て、新しい水で煮ます。サポニンが抜けます |
