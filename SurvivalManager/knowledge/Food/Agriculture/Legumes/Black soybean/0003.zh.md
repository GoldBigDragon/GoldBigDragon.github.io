## 3. 栽培环境

### 3-1. 气温与光照量

| 条件 | 极限值 | 最适值 | 超出范围时 |
|---|---|---|---|
| 发芽温度 | 10℃以上 | 20-22℃ | 10℃以下时发芽停止，种子腐烂 |
| 生育温度 | 15-35℃ | 20-23℃ | 比大豆更偏好凉爽的环境 |
| 结实温度 | 18-32℃ | 20-30℃ | 是幅度仅10℃的狭窄范围 |
| 灌浆期气温 | 15℃以上 | 18-25℃ | 低于15℃时灌浆实际上会停止 |
| 积温 | 2,800℃以上 | 2,800-3,200℃ | 比大豆多需要300℃以上 |
| 霜 | 零下时叶片和茎秆枯死 | - | 已成熟豆荚内的籽粒不会受损 |
| 日照 | 每天6小时以上 | 每天8小时以上 | 40%遮光时产量减半 |
| 光周期 | 短日照植物 | 白昼变短时开花 | 晚熟品种的光周期反应出现得更晚 |

&nbsp;&nbsp;&nbsp;积温是青仁黑豆（Black soybean）栽培的关口。从播种到收获，日平均气温之和必须超过2,800℃，籽粒才能真正灌浆饱满。与大豆只需2,500℃相比，需要多积累300℃以上，这相当于栽培期要多出约一个月。在韩国中部，5月下旬播种、11月初收获，大致能达到这个数值。播种若晚10天，灌浆后期就会落入气温偏低的时段，因此损失的不是10天，而会变成半个月以上。

> **对青仁黑豆而言，播种晚的代价不是收获晚，而是豆荚空瘪。种得晚，不是收得晚，而是无可收获。**

&nbsp;&nbsp;&nbsp;在高冷地区和韩国北部山区，青仁黑豆的栽培较为困难。如果所在地区初霜在10月初就到来，积温就会不足，这类地方选择早熟大豆或其他豆类更为合理。相反，韩国南部初霜较晚、余裕较大，最晚可种到6月下旬。掌握本地初霜的平均日期，并从该日期往前倒推170天，是确定播种日最可靠的方法。

### 3-2. 土壤与水

| 条件 | 极限值 | 最适值 | 备注 |
|---|---|---|---|
| 土壤质地 | 从黏质土到砂质土均可 | 保水力强且排水良好的砂壤土-壤土 | 因生长期长，保水力比大豆更重要 |
| pH | 5.5-7.5 | 6.0-7.0 | 接近中性更有利于根瘤 |
| 有效土层深度 | 30cm以上 | 50cm以上 | |
| 生长期蒸散量 | - | 约450mm | 在豆类中属于中等水平 |
| 淹水 | 淹没2天以上会枯死 | - | 根瘤会先死亡 |
| 垄高 | 20cm以上 | 圆垄 | 关键在于防止韩国的梅雨季（6月下旬至7月）涝害 |

&nbsp;&nbsp;&nbsp;在土壤条件上，青仁黑豆与大豆的分歧点在于保水力。青仁黑豆要度过梅雨、熬过酷暑，直到秋天，在同一处站立五个多月。在这段时间里遇上一次以上干旱的概率很高，此时土壤保水的程度就决定了产量。沙多、水分很快渗漏的地块需要频繁灌溉；反之，黏土多、容易积水的地块会在梅雨季导致根瘤死亡。既能含水又不积水的土壤，也就是有机质充足的砂壤土，是最理想的。施入腐熟堆肥和腐叶土，在青仁黑豆栽培中尤其物有所值。

&nbsp;&nbsp;&nbsp;建议酸度略高于大豆，控制在6.0到7.0之间。这是因为根瘤菌在接近中性时活动最为旺盛，而青仁黑豆依赖根瘤的时间较长，这一差异会不断累积。韩国的田地大多偏酸性，因此要在播种前3-4周施入钙镁灰，每1,000㎡用200kg进行矫正。若没有石灰，可用烧过并捣碎的贝壳和蛋壳代替。

## 4. 品种

| 品种 | 特点 | 产量(kg/1,000㎡) | 适用情形 |
|---|---|:---:|---|
| 传统青仁黑豆 | 传统品种，味道好，已适应当地环境 | 约160-260 | 需要持续自家留种时 |
| Cheongja 5号 | 新品种，抗病害和倒伏能力强，豆荚不易开裂 | 约343 | 重视产量与稳定性时 |
| 大粒黑豆（Heuktae）系 | 颗粒粗大，适合用于酱类和豆腐 | 因品种而异 | 需要酿酱时 |
| 小粒黑豆（Seomoktae） | 颗粒最小，适合用作黄豆芽和药用 | 少 | 种子不足时、需要黄豆芽时 |

&nbsp;&nbsp;&nbsp;Cheongja 5号与传统青仁黑豆之间的差异，从灾害应对的角度来看是值得思考的。Cheongja 5号的产量比传统品种高30-70%，豆荚不易开裂、收获损失小，且抗倒伏和抗病害能力强。只看数字似乎没有选择的余地。但必须同时考虑两点。第一，改良品种大多是为了对施肥有良好反应而培育的，因此在零投入条件下其优势会缩小。第二，传统品种已经适应了当地的气候与病害，并且可以持续留种延续下去。

&nbsp;&nbsp;&nbsp;幸运的是，两者都是自花授粉的固定种，因此都可以留种再种。所以理想的做法不是二选一，而是两者分开种植。用Cheongja 5号确保产量，用传统品种保存地方适应性和遗传多样性。在病害大流行或气候异常的年份，两者之中总有一个能够存活下来。不把一切都押在单一品种上，是保障种子的基本原则。

| 情形 | 选择 | 理由 |
|---|---|---|
| 初霜早于10月中旬的地区 | 避开青仁黑豆，改种早熟大豆 | 积温不足 |
| 蝽象多发地区 | Cheongja 5号 | 豆荚坚硬，受害较少 |
| 需要靠自家留种长期延续 | 传统青仁黑豆 | 已适应当地环境 |
| 需要酿酱 | 大粒黑豆 | 颗粒粗大，产量也高 |
| 种子不足 | 小粒黑豆 | 同样重量可种下大得多的面积 |
| 没有冬季蔬菜 | 部分小粒黑豆 | 适合发黄豆芽 |

## 5. 整地与施肥 - 根瘤菌与氮素平衡

### 5-1. 根瘤菌 - 精简概要

&nbsp;&nbsp;&nbsp;青仁黑豆的供氮机制与大豆相同。根瘤菌（Bradyrhizobium japonicum）在根部形成根瘤，瘤内一种名为固氮酶的酶会切断空气中氮分子（N2）的三键，将其转化为氨。细菌不能进行光合作用，因此从植物那里获得糖分，并以固定的氮作为回报，这是一种交易关系。由于这种酶对氧气极为敏感，根瘤内部充满了一种叫豆血红蛋白的红色色素蛋白，用来控制并锁住氧气。

| 检查步骤 | 内容 |
|---|---|
| 时期 | 开花开始前后，播种后8-10周 |
| 方法 | 不要拔出，用铲子连土一起挖出，再用水把土冲洗掉 |
| 数量 | 每株20个以上，集中在主根上部为佳 |
| 颜色检查 | 用指甲掰开根瘤，查看内部颜色 |

| 掰开后内部颜色 | 含义 | 处理方法 |
|---|---|---|
| 红色或粉红色 | 正在固氮 | 状态良好 |
| 白色或淡绿色 | 根瘤已形成但未固氮 | 需检查酸度、涝害、磷酸缺乏 |
| 棕色或黑色 | 已老化或已死亡 | 若在灌浆期属正常，若在开花期则有问题 |

> **挖出根系、掰开根瘤查看是否呈红色，这一个习惯，是在没有氮肥的世界里判断种豆成败最可靠的信号。**

### 5-2. 接种源的获取

&nbsp;&nbsp;&nbsp;在无法获得市售接种剂的条件下，接种源就是土壤。前一年种过豆、根瘤长得好的地块的表土，本身就是活的接种剂。

| 方法 | 步骤 | 注意事项 |
|---|---|---|
| 裹上种过豆的地块的土 | 取表土5-15cm处的土，均匀裹在略微沾水的种子上，随即播种 | 需在阴凉处操作，并在30分钟内播种。若晒干则菌会死亡 |
| 把土撒在播种行上 | 在播种行撒土并一同翻入土中，每10㎡用一铲 | 用量较大，但菌能扩散到整片土壤中 |
| 捣碎根瘤使用 | 收集挖出的豆根上的根瘤并捣碎，溶入水中，将种子浸入后捞出 | 必须当天使用 |
| 保留根系 | 收获时不挖出根系，留在地里 | 是最省事的维持方法 |
| 野生大豆根 | 从田埂上野生大豆的根上采集根瘤 | 因同属，菌可以通用 |

&nbsp;&nbsp;&nbsp;青仁黑豆的接种之所以格外重要，是有原因的。由于栽培期超过五个月，根瘤需要供给的总氮量比大豆更多。若接种不充分，生育初期还能勉强维持，但到8月、9月的荚粒膨大期就会因缺氮而叶片提前发黄、籽粒灌浆不足。灌浆后期供氮中断，是青仁黑豆产量不佳的常见原因，而其根源正在于播种当时的接种情况。

| 导致接种失败的条件 |
|---|
| 土壤pH 5.5以下 |
| 施用了较多氮肥的地块 |
| 积水的地块 |
| 磷酸不足的地块 |
| 把接种后的种子放在阳光下晒干 |
| 对经过杀菌剂处理的种子进行接种 |

### 5-3. 固氮的陷阱

&nbsp;&nbsp;&nbsp;种豆能让土地变好，这种说法是有条件的真实。让我们用数字来核实一下。青仁黑豆籽粒中的蛋白质为38%，蛋白质除以6.25即可得出氮含量。籽粒重量中约6%是纯氮。若在1,000㎡收获230kg，其中约含14kg氮，折合每公顷为140kg。

&nbsp;&nbsp;&nbsp;而根瘤固氮量在条件好时为每公顷100-150kg，条件差时则仅有50kg左右。

| 项目 | 每公顷氮量 | 方向 |
|---|---|---|
| 根瘤固氮量（条件良好） | 100-150kg | 流入 |
| 根瘤固氮量（条件不佳） | 30-60kg | 流入 |
| 随籽粒带走 | 130-145kg | 流出 |
| 留在茎叶中的氮 | 25-40kg | 若归还田地则留下，若焚烧或运走则流出 |
| 留在根系与根瘤中的氮 | 10-20kg | 大多留在地里 |

&nbsp;&nbsp;&nbsp;如果只收获籽粒、把茎叶归还田地，氮平衡大致持平或略有盈余。但如果把豆秸割下当柴烧、直接焚烧，或作为牲畜饲料运走，氮平衡就会明确转为负值。大豆籽粒重量中约6%是氮，而玉米籽粒约为1.4%，因此运出同样1kg到田外时，大豆带走的氮量相当于玉米的4.5倍。

> **大豆能滋养土地，并不是因为它能固氮，而是因为它把固定的一部分氮储存在茎叶中并留在田里。一旦把这些茎叶运走，豆类就会变成掠夺地力的作物。**

| 原则 | 内容 |
|---|---|
| 茎叶务必归还田地 | 把豆秸、叶片和豆荚壳全部归还田地，切成20-30cm覆盖在地表 |
| 不焚烧 | 焚烧会使氮以气体形式散失，只留下钾和磷酸 |
| 不挖出根系 | 只割茎秆，根系原地保留 |
| 不清扫落叶 | 青仁黑豆的叶片会因霜而一齐掉落，这些落叶本身就是肥料 |
| 若已焚烧，则将灰归还田地 | 虽损失氮，但可回收钾和磷酸 |

&nbsp;&nbsp;&nbsp;青仁黑豆有一个便于遵守这一原则的有利条件：收获时间在11月，田地几乎不需要马上再利用。把豆秸割下铺在原地，经过一个冬天腐熟，到次年春天正好可以翻入土中。这样做还能防止冬季土壤裸露，减少表土流失。青仁黑豆田里的豆秸，几乎没有必要运走。

### 5-4. 施肥量与灾害替代肥料

| 肥料 | 1,000㎡用量 | 折合每㎡ | 备注 |
|---|---|---|---|
| 氮 | 3kg | 3g | 仅用最小量，用于根瘤起效前的初期 |
| 磷酸 | 3kg | 3g | 全部作基肥。固氮的能量代谢需要它 |
| 钾 | 3.4kg | 3.4g | 全部作基肥。参与籽粒膨大 |
| 堆肥 | 1,000kg | 1kg | 须完全腐熟。可提高保水力 |
| 石灰 | 200kg（酸性土） | 200g | 播种前3-4周 |

> **多施氮肥只会让叶片过度繁茂，结荚反而变少。青仁黑豆本来植株高、容易倒伏，氮过量造成的危害比大豆更大。**

| 替代资源 | 提供的养分 | 用法 | 注意事项 |
|---|---|---|---|
| 草木灰 | 钾、磷酸、钙 | 每㎡撒100-200g并混入土中 | 过量会使pH超过7，阻碍铁和锌的吸收 |
| 腐熟堆肥 | 综合养分，有机质 | 每㎡1kg | 未腐熟的会烧根并传播病害 |
| 稀释尿液 | 氮、钾 | 用水稀释10倍后浇在株间土壤上 | 仅少量使用，避免沾到叶片 |
| 骨粉·鱼骨 | 磷酸、钙 | 烧过捣碎后拌入堆肥 | 效果显现较慢 |
| 贝壳·蛋壳 | 钙 | 烧过捣碎后撒施 | 可替代石灰 |
| 落叶腐叶土 | 综合养分，有机质 | 混入土壤中 | 可提高保水力，对青仁黑豆尤为有利 |
| 稻壳·稻草 | 钾、硅酸 | 用作覆盖，次年翻入土中 | 若腐熟不足就翻入，会与作物争氮 |

&nbsp;&nbsp;&nbsp;追肥原则上并非必需，但青仁黑豆生长期长，可能出现例外情况。若开花后1-2周整株叶片普遍呈淡黄色，且生长明显迟缓，这就是根瘤未能正常运作的信号。只有这时才补充少量肥料。常规做法是施用氮钾复合肥10-20kg，在灾害条件下则将尿液用水稀释10倍后浇在株间土壤中。若直接接触植株会伤根，因此应施在离植株约20cm的位置。
