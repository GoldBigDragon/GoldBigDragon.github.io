## 14. 毒性与抗营养成分

&nbsp;&nbsp;&nbsp;青仁黑豆（Black soybean）与普通大豆是同一物种，因此抗营养成分也相同。煮熟后安全，生吃则危险。豆科植物的种子为了不被吃掉而储存了化学防御物质，这些物质会妨碍人体消化。它们大多不耐热，充分加热即可被破坏，但问题在于"充分"这个词的标准比想象中要高。

### 14-1. 抗营养成分的真相

| 成分 | 作用 | 症状 | 去除方法 |
|---|---|---|---|
| 胰蛋白酶抑制剂 | 阻碍蛋白质分解酶胰蛋白酶的作用 | 腹痛、呕吐、腹泻、蛋白质利用率下降 | 浸泡8小时后在100度下加热30-60分钟以上 |
| 凝集素（血凝素） | 附着在肠黏膜上妨碍吸收，并使红细胞凝集 | 剧烈腹痛、呕吐、腹泻 | 浸泡后在100度下加热10-30分钟以上 |
| 植酸 | 与铁、锌、钙结合，阻碍其吸收 | 长期食用会导致贫血、锌缺乏 | 通过浸泡、发芽、发酵可减少60-80% |
| 皂苷 | 起泡并刺激肠胃 | 摄入过多会感到胃部不适 | 煮制时撇去泡沫 |
| 低聚糖 | 人体无法消化，由肠道细菌发酵 | 腹部胀气 | 倒掉浸泡水，发酵可大幅减少 |

> **未煮熟的豆有时比生豆更危险。稍微焯一下会破坏细胞壁，使吸收变好，但抑制剂和凝集素依然残留。不要半途而废，要彻底煮熟。**

&nbsp;&nbsp;&nbsp;凝集素的危险程度因豆类种类而异。大豆和青仁黑豆的凝集素毒性低于菜豆类(Phaseolus)的凝集素。菜豆哪怕只生吃四五粒，也会在数小时内引发剧烈呕吐和腹泻，因菜豆未煮熟而中毒的事例已有多次报告。菜豆类尤其存在一个区间：长时间低温加热反而会使凝集素活性升高，因此长时间浸在温水中烹煮最为危险。青仁黑豆没有这么极端，但原则相同：在沸水中加热足够长的时间，是唯一安全的做法。

### 14-2. 浸泡与加热的标准

| 处理 | 时间·温度 | 效果 |
|---|---|---|
| 浸泡 | 常温水中浸泡8小时 | 热量能透到豆芯。部分低聚糖和皂苷会溶入水中 |
| 倒掉第一遍浸泡水 | 务必 | 其中溶有低聚糖和抗营养成分 |
| 煮制 | 在沸水中煮60分钟以上 | 胰蛋白酶抑制剂和凝集素会失活 |
| 蒸制 | 100度蒸汽蒸60-90分钟 | 养分和色素的流失比水煮更少 |
| 余热焖煮 | 煮15分钟后放入保温箱2-3小时 | 燃料消耗降到一半以下 |
| 检查是否煮熟 | 用手指一按就能轻易碾碎 | 若留有硬芯，说明还没煮熟 |

&nbsp;&nbsp;&nbsp;青仁黑豆的浸泡中有一项与色素相关的判断需要留意。浸泡水会渗出深红色，那就是花青素。若把这些水全部倒掉，等于连色素也一并丢弃，十分可惜。折中的办法是只倒掉第一遍水，保留之后的水。最初两三个小时的水中集中溶出了低聚糖和抗营养成分，因此务必倒掉；换水后剩余时间浸泡出的水，可以留作煮饭或煮豆用的水。煮豆时渗出的深红色水也不必倒掉，可直接用于烹饪。

&nbsp;&nbsp;&nbsp;蒸制比水煮更利于保存色素。由于不浸在水中，花青素不会被冲洗流失。虽然多耗一点燃料，但只需有蒸笼或竹篦即可，味道也更浓郁。

### 14-3. 发芽与发酵

| 方法 | 减少的成分 | 程度 |
|---|---|---|
| 发芽（黄豆芽） | 植酸、胰蛋白酶抑制剂、低聚糖 | 植酸减少50-70%，抑制剂减少30-40% |
| 发酵（大酱·酱油·清麴酱） | 植酸、胰蛋白酶抑制剂、低聚糖、凝集素 | 大部分被分解，吸收率提高 |
| 仅浸泡 | 低聚糖、部分植酸 | 减少20-30% |

&nbsp;&nbsp;&nbsp;发酵是从根本上解决抗营养成分问题的方法。微生物会将抑制剂和凝集素之类的蛋白质分解为氨基酸，并分泌能分解植酸的酶。而且一旦腌制好，之后的烹饪几乎不再需要燃料，因此在燃料稀缺的灾难情况下，酱类（大酱、酱油等）就成了一种预先支付烹饪成本的贮藏方式。

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;青仁黑豆的耐储性为SS级。晒干的籽粒在常温下能保存3年。但这是条件适宜时的情形，一旦条件出问题，光是一种豆象就能把贮藏的豆子全部变成空壳。

> **豆子不是因为腐烂而损失，而是被虫子吃掉而损失。贮藏的技术，说到底就是防虫的技术。**

### 15-1. 干燥优先

| 阶段 | 方法 | 确认 |
|---|---|---|
| 预备干燥 | 连秸秆一起立挂在屋檐下，靠风吹干 | 11月通风比日照更重要 |
| 脱粒后干燥 | 摊薄在草席上晒3-4天 | 冬季阳光弱，比大豆多花一两天 |
| 目标含水率 | 食用12-13%，种用12% | 咬下去牙齿咬不进去，啪地裂开 |
| 食盐测试 | 在干燥的瓶中放入豆子和炒盐一起摇晃 | 如果盐粘在瓶壁上，说明还需要再晾干 |
| 冷却 | 完全放凉后再装 | 温热状态下密封会产生冷凝水 |

&nbsp;&nbsp;&nbsp;11月收获的干燥比大豆更费工夫。白天短、气温低、空气潮湿，晒干的速度较慢。因此要利用两种办法。一是风：摊薄放在屋檐下或通风道上，效果比微弱的日照更大。二是室内的干燥空气：铺在烧火房间的里侧或灶台附近，能很快晒干。但若放在过热的地方，种皮会裂开，因此要用手触摸，选择微温的位置。

### 15-2. 贮藏中豆象的防治

&nbsp;&nbsp;&nbsp;豆象（包括红豆象、绿豆象在内的Callosobruchus属虫类）是贮藏豆类的最大威胁。可怕之处在于它早在田间就已经开始了。成虫会在还长在地里的豆荚上产卵，这些卵会在储藏处内孵化，钻入豆粒内部。运进来时卵就已经附着其中，一代所需时间不到一个月，半年下来一整袋豆子就会变成满是孔洞的空壳和粉末。

| 方法 | 原理 | 应用 | 效果 |
|---|---|---|---|
| 完全密封 | 断绝氧气使其窒息 | 装满玻璃瓶或金属罐后密封 | 最为可靠，3-4周内连卵和幼虫都会死亡 |
| 掺草木灰 | 细微颗粒刮擦外骨骼蜡质层使其脱水 | 掺入豆子体积的2-5% | 食用前用水冲洗干净 |
| 硅藻土 | 硅质外壳会损伤其外骨骼 | 每1kg豆子加1-3g | 效果比草木灰更好，但只在干燥状态下起作用 |
| 涂油 | 油膜能阻止产卵与孵化 | 每1kg豆子加2-5mL食用油揉匀 | 对豆类效果显著，但不可用于种用豆 |
| 低温处理 | 零下低温可杀死卵和幼虫 | 严冬时放到室外几天后再收回 | 11月收获后冬天紧接着就到，有此优势 |
| 高温处理 | 60度可杀死卵和幼虫 | 摊薄在阳光下晒半天 | 不可用于种用豆 |
| 干辣椒·花椒·艾草 | 精油成分能抑制产卵 | 一层层放入 | 属于辅助手段 |
| 木炭·炒盐 | 吸收湿气 | 用布包好放入 | 兼可防霉 |
| 埋入草木灰中 | 兼具密封与物理防治效果 | 在缸中一层灰一层豆子叠放 | 自古以来被广泛使用 |

&nbsp;&nbsp;&nbsp;最重要的是完全密封。虫子也要呼吸。在密封容器中，豆子和虫子消耗氧气，氧气减少、二氧化碳升高，虫子就会死亡。豆子处于休眠状态，能承受这种条件。容器装得越满、空隙越少，效果就越快；与其用一个大容器，不如分装进多个小容器并装实装满，这样即使有一个容器坏了，也不会损失全部。

&nbsp;&nbsp;&nbsp;青仁黑豆有一个利于低温处理的条件。它在11月收获，脱粒和干燥一结束很快就是隆冬。把密封容器放到室外几天，让其经受零下的气温，卵和幼虫就会死亡。再拿回室内时不要马上打开容器，先在室内放半天让温度回升后再开。若把冰凉的容器立刻打开，内壁会结露，成为霉菌滋生的根源。

&nbsp;&nbsp;&nbsp;涂油特别适合豆类贮藏。每1kg豆子加2-3ml食用油，用手揉搓使每一粒豆子都裹上一层薄膜。油膜既能让成虫难以产卵，也能堵住已附着虫卵的气孔。不过油一旦氧化就会产生异味，因此只用于半年内要吃完的部分，不可用于种用豆。

### 15-3. 储藏容器与场所

| 容器 | 密封 | 期限 | 备注 |
|---|:---:|---|---|
| 玻璃瓶 | 非常好 | 3年以上 | 可以用肉眼确认状态，但挡不住光 |
| 金属罐 | 非常好 | 3年以上 | 能完全挡住老鼠和虫子，但要注意冷凝水 |
| 陶缸 | 好 | 2-3年 | 温度变化缓慢，老鼠咬不透 |
| 厚塑料袋 | 一般 | 1-2年 | 会被老鼠咬破 |
| 地窖 | 好 | 2-3年 | 一旦渗水就会全部损失 |

| 保存条件 | 目标 |
|---|---|
| 温度·湿度 | 15度以下，空气湿度65%以下 |
| 光照 | 完全遮挡。花青素会在光照下缓慢分解 |
| 位置 | 地下室或朝北房间，垫高离地放置 |
| 检查 | 每两个月一次 |

&nbsp;&nbsp;&nbsp;光照遮挡对青仁黑豆而言更为重要一些。花青素会在光和热的作用下缓慢分解，若装入透明瓶中放在明亮处，几个月内种皮颜色就会变浅。热量和蛋白质虽不受影响，但会失去色素带来的益处。若使用玻璃瓶，应用布包裹或放在阴暗处。

&nbsp;&nbsp;&nbsp;检查时最可靠的感官是听觉和嗅觉。把耳朵贴在容器上若听到沙沙的声音，说明虫子正在活动；若闻到潮闷的气味，说明霉变已经开始。豆子表面若能看到细小的圆孔，说明豆象已经繁殖超过一代。即便到了这个阶段，把全部豆子取出晒干、拣出空豆、掺入草木灰或食用油后重新密封，仍能保住剩下的部分。

## 16. 烹饪与加工

### 16-1. 黄豆芽——冬季的维生素C

&nbsp;&nbsp;&nbsp;干豆中实际上不含维生素C。然而一旦发芽，原本没有的维生素C就会生成，这是因为发芽这一生理转变发生后，植物会重新合成维生素C。冬天完全没有新鲜蔬菜时，只要有一把干豆、水和一处黑暗的地方，三四天内就能获得新鲜蔬菜，既不需要田地，也不需要阳光和泥土。

&nbsp;&nbsp;&nbsp;青仁黑豆也能用来生黄豆芽，但因豆粒大，芽容易弯曲发软。在黑豆系统中最适合生豆芽的，是颗粒细小的鼠目豆（seomoktae）。即使主要种植青仁黑豆，也可以顺带种一行鼠目豆，专门留作生豆芽用，这是解决冬季蔬菜问题的实际办法。

| 顺序 | 内容 | 要点 |
|---|---|---|
| 1. 选豆 | 鼠目豆或小粒黑豆，破损或虫蛀的豆粒要剔除 | 破损的豆粒会腐烂并损坏整批 |
| 2. 清洗 | 反复冲洗，撇去漂浮的豆粒 | 漂浮的豆粒大多是死豆 |
| 3. 泡发 | 在温水中浸泡6-8小时 | 应膨胀至两倍大小 |
| 4. 装盘 | 放入能滤水的容器或蒸笼中，盖上湿布 | 积水会导致腐烂 |
| 5. 遮光放置 | 完全遮光，20-25℃ | 若透光会变绿变硬 |
| 6. 浇水 | 每天从上方充分浇淋3-4次 | 兼具调节温度与排除废物的作用 |
| 7. 收获 | 4-7天，长度5-10cm | 要在根变褐色之前收获 |

&nbsp;&nbsp;&nbsp;浇水几乎是生黄豆芽的全部关键。水既能供给水分，又能冷却发芽过程中产生的热量，还能冲走积累的废物。若长出很多细根，说明缺水。没有蒸笼的话，可以用底部打孔的容器、密孔竹筛、或打了孔的盆代替。下面放接水的容器，上面盖黑布，这就是简易的蒸笼。所需要的只有滤水结构和遮光这两点。黄豆芽也不生吃，要焯水或炒熟后食用，因为其中仍残留有抑制剂。

### 16-2. 青仁黑豆的烹饪与加工

| 加工 | 步骤 | 保存 | 价值 |
|---|---|---|---|
| 酱油煮豆（kongjaban） | 泡发的豆子煮熟后与酱油一同收汁 | 阴凉处可放2-3周 | 自带甜味，无需加糖，是青仁黑豆的代表烹饪法 |
| 豆饭 | 泡发的豆子与大米一同焖煮 | 随做随吃 | 谷物与豆类的氨基酸相互补充 |
| 黑豆茶 | 炒过后加水煮开 | 炒好的豆密封可存2-3个月 | 能溶出花青素，耗费燃料少 |
| 黑豆豆浆 | 泡发的豆子磨碎煮沸后过滤 | 可存放数日 | 易消化，豆渣可另作他用 |
| 酱曲（meju）·大酱·酱油 | 煮熟捣碎发酵后，与盐水一同陈酿 | 可存放数年 | 因豆色黑，酱色也更深。黑太（heuktae，大粒黑豆）更适合用于此 |
| 清麴酱 | 煮好的豆子用稻草包好，在40℃左右发酵2-3天 | 可放数日，晒干后可放数月 | 是发酵速度最快的豆类食品 |
| 炒豆粉 | 炒熟后磨粉 | 密封可存2-3个月 | 用水调开即可食用 |
| 豆油 | 炒熟磨碎后压榨 | 可存放数月 | 出油率较低 |

&nbsp;&nbsp;&nbsp;酱油煮豆是最能发挥青仁黑豆特性的烹饪法。青仁黑豆的糖类含量为3.28g，高于普通大豆，即使不加糖也会带甜味。在甜味剂匮乏的情况下，这是一项不小的优势。做法的要领是：先把充分泡发的豆子只用清水煮到软烂，之后再加酱油收汁。若一开始就加酱油，豆子会因盐分而变硬、不易煮软。收汁时煮豆水中的深红色色素也一并加入，不要倒掉。

&nbsp;&nbsp;&nbsp;黑豆茶是燃料利用效率很高的一种加工方式。把干豆用小火炒20到30分钟后，之后只需用水煮几分钟即可饮用。炒制过程中胰蛋白酶抑制剂也会大幅减少。泡过茶的豆子不要丢弃，可以食用或喂给家畜。在必须烧水饮用的情况下，这比白开水更有滋味，还能同时摄入色素和矿物质，等于兼顾了饮用水消毒与获取营养两件事。

### 16-3. 节省燃料的烹饪

| 方法 | 燃料 | 步骤 |
|---|:---:|---|
| 余热焖煮 | 非常少 | 将泡发的豆子煮15分钟后关火，用稻草·谷壳箱或被子包裹焖2-3小时 |
| 高压烹煮 | 最少 | 将泡发的豆子加压15-20分钟 |
| 炒豆粉 | 几乎不需要 | 预先炒熟磨粉备用，用水调开食用 |
| 黑豆茶 | 较少 | 将炒好的豆子用水煮几分钟 |
| 发酵（酱类） | 预先投入 | 腌制好后，之后就不再需要燃料 |
| 黄豆芽 | 不需要 | 发芽不需要热量 |

&nbsp;&nbsp;&nbsp;使用余热焖煮时有一点需要注意。保温箱内的温度维持在80℃左右，这可能不足以彻底破坏凝集素和胰蛋白酶抑制剂。因此，最初的煮制时间要充分保证在15分钟以上，取出时要确认豆子用手指能否轻易碾碎。如果留有硬芯，就要再煮一次。

## 17. 全年作业日程

| 月份 | 作业 | 要点 |
|---|---|---|
| 1月 | 检查贮藏的豆子，进行种子发芽试验，培育黄豆芽 | 将密封容器放到室外几天，兼作低温处理 |
| 2月 | 规划田地，翻堆肥，酿制酱类 | 确认轮作顺序和陈种的发芽率 |
| 3月 | 撒石灰，完成堆肥 | 在播种前3-4周施入 |
| 4月 | 耕地，起垄，挖排水沟，施基肥 | 要考虑到梅雨季，把排水沟挖深 |
| 5月 | 种子精选，温水消毒，备好接种土，下旬开始播种 | 提前挖好种过豆子地块的土 |
| 6月 | 完成播种（韩国中部截至中旬），防鸟，间苗，第1次培土 | 一旦过了中旬，灌浆期就会撞上初霜 |
| 7月 | 第2·3次培土，除草，摘心，覆盖 | 培土和摘心要在开花前完成 |
| 8月 | 开花，检查根瘤，灌溉，监测蝽象，立支架固定 | 要在台风来临前系好绳子固定 |
| 9月 | 豆荚膨大，集中灌溉，捕杀蝽象 | 到下旬为止的这3周是决定产量的关键期 |
| 10月 | 灌浆，停止灌溉，标记留种植株，下旬开始收获 | 给先成熟的植株系上绳子 |
| 11月 | 完成收获，悬挂晾晒，脱粒，精选，秸秆还田 | 把豆秆切碎铺在地里，不要焚烧 |
| 12月 | 最终干燥，贮藏，酿制酱类，培育黄豆芽 | 利用低温处理消灭豆象 |

### 17-1. 不可忘记的五件事

| 项目 | 内容 |
|---|---|
| 播种适期 | 韩国中部以6月中旬为限。若延迟，不是收获推迟，而是变得无豆可收 |
| 蝽象 | 8月下旬到9月中旬的这3周是关键期，若疏于防治会损失一半 |
| 培土与摘心 | 务必在开花前完成，开花后进行会导致减产 |
| 秸秆 | 若不把豆秆、豆叶和根系归还田地，豆类就会变成掠夺地力的作物 |
| 加热 | 浸泡8小时，煮1小时以上。未煮熟的豆有时反而更危险 |
