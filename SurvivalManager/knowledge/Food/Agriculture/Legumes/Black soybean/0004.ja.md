## 6. 播種

### 6-1. 播種時期 - ソリテ（青大豆系の黒豆）栽培の第一関門

| 地域 | 播種適期 | 播種限界期 | 収穫時期 |
|---|---|---|---|
| 韓国中部 | 5月下旬-6月中旬 | 6月下旬 | 10月下旬-11月中旬 |
| 韓国南部 | 6月上旬-6月下旬 | 7月上旬 | 11月上旬-11月下旬 |
| 高冷地・韓国北部の山間部 | 栽培不適 | - | 積算温度が不足します |

&nbsp;&nbsp;&nbsp;播種日を決める方法は逆算することです。自分の地域の初霜の平均日を調べ、そこから170日を引くと播種限界日が出ます。ここに10日の余裕を加えると適期の終わりになります。韓国中部の初霜はたいてい10月下旬なので、6月中旬が限界になります。南部は11月中旬が初霜なので、6月下旬まで余裕があります。

> **ジャガイモやニンニクを収穫した跡地にソリテを続けて植えるのは時期がぎりぎりです。6月下旬を過ぎたら、二毛作よりも他の豆類を選ぶほうが安全です。リョクトウやササゲなら80-90日で済むため、後作としてずっと適しています。**

### 6-2. 種子の準備と播種

| 項目 | 方法 | 災害時の条件では |
|---|---|---|
| 選別 | 斑点、変色、しわ、虫食い穴のある粒を除きます | 手で一粒ずつ選びます。最も安上がりで効果の大きい作業です |
| 紫斑病の確認 | 種皮に紫色の斑がある粒を取り除きます | 黒い種皮では斑が見えにくいため、明るい光の下で確認します |
| 温湯消毒 | 50-55℃の湯に10-15分浸します | 手を入れて5秒我慢するのがやっとという熱さです。60℃を超えると発芽力が損なわれます |
| 灰処理 | 細かい草木灰をまぶします | 消毒と乾燥を助け、鳥や虫を避ける効果があります |
| 根粒接種 | 豆を育てた畑の土をまぶします | 消毒と同時には行いません。温湯消毒の後、完全に冷ましてから行います |
| 発芽試験 | 濡れた布に20粒を包んで数日置き、発芽した数を数えます | 古い種子は必ず先に確認します |

| 項目 | 基準 | 理由 |
|---|---|---|
| 播種深さ | 3-5cm | 2cm以内では乾いて鳥に食べられます。5cmを超えると出芽が悪くなります |
| 1穴当たりの粒数 | 2-3粒 | 後で2本を残して間引きます |
| 条間 | 70cm（1条植え推奨） | 通風と日照を確保し、梅雨期の湿害を防ぎます |
| 株間 | 20cm | ソリテは大きく育つためダイズより広めに取ります |
| 畝の高さ | 20cm以上、丸畝 | 排水と倒伏防止 |

&nbsp;&nbsp;&nbsp;栽植距離をダイズより広めに取る理由は、ソリテが5か月かけて育ち、体が大きくなるためです。ダイズと同じ間隔で植えると、8月にはすでに葉が重なって通風がふさがれ、梅雨や台風を経る間に病気が広がり倒れてしまいます。70cmに20cmは余裕があるように見えますが、9月になるとちょうどぴったりになります。ひとつの畝に1条だけ植える方式が勧められるのも同じ理由です。

&nbsp;&nbsp;&nbsp;播種直後の脅威は鳥です。ハトやカササギ、キジが芽吹いたばかりの豆の双葉をついばんで食べ、双葉を失った株はたいてい枯れます。播種した条の上に木の枝やわらを薄く覆ったり、発芽までの間、網や古い防虫網をかぶせたり、光る紐を交差させて張ったりします。最も確実なのは、発芽初期の10日間、朝夕に畑を見回ることです。

## 7. 水管理

| 時期 | 水管理 | 理由 |
|---|---|---|
| 播種から発芽まで | 土がからからに乾かないようにします | 種子は自重と同じ量の水を吸収して初めて発芽します |
| 生育初期（6-7月） | 自然降水に任せます | この時期の乾燥は根を深く伸ばします。過湿のほうが危険です |
| 梅雨期 | 排水に集中します | 灌水ではなく水を抜くことが仕事です |
| 開花期-さや肥大期（8-9月） | 土が乾かないよう十分に与えます | 生育全期間の水分の80%をこの時期に使います |
| 登熟期（10月） | 水を減らします | 過湿だとさやが乾きません |
| 成熟期 | 灌水を中止します | 脱粒や早期落葉の原因になります |

&nbsp;&nbsp;&nbsp;ソリテの水管理でダイズと違う点は、秋の干ばつまで心配しなければならないことです。ダイズは9月にはすでに登熟を終えますが、ソリテは9月下旬までさやを充実させ続けます。9月に雨がない年には、この時期の灌水が収量を直接左右します。逆に10月に雨が多いとさやが乾かず収穫が遅れ、種実にカビが生えます。

| 症状 | 原因 | 対処 |
|---|---|---|
| 日中に葉がしおれ夕方に回復する | 一時的な水分不足。正常です | そのままにしておきます |
| 朝になっても葉がしおれている | 根が水を吸い上げられていません | 十分に灌水します |
| 花が大量に落ちる | 開花期の乾燥または高温 | 灌水とマルチングで地温を下げます |
| さやは付いているが粒が小さい | さや肥大期の水不足 | この時期の灌水が収量を直接左右します |
| 9月に下葉から急に黄変する | 登熟後半の窒素または水分不足 | 根粒を確認し灌水します |
| 下葉が黄色く根が黒い | 過湿による根の傷み | 排水路を作り、土寄せで土を高くします |
| 葉全体が薄い黄色だが萎れてはいない | 根粒不良による窒素不足 | 根を掘り出し瘤を割って確認します |

&nbsp;&nbsp;&nbsp;マルチングはソリテ栽培で特に重要です。栽培期間が長いため雑草と競合する期間も長く、夏の干ばつと地温上昇の両方を経験するためです。ビニールがなくても、わら、もみ殻、落ち葉、刈り取った雑草で5cmから10cm覆うと、表面からの蒸発が半分以下に減り、除草の労力も減ります。ただし土寄せを何度も行う必要があるため、マルチングは土寄せを終えた7月以降に覆うほうが作業の順序に合います。

## 8. 栽培管理 - 土寄せと摘心

### 8-1. 土寄せ - 3回

| 回数 | 時期 | 方法 |
|---|---|---|
| 1回目 | 本葉2-3枚 | 双葉が埋まる程度まで土をかき上げます |
| 2回目 | 本葉4-5枚 | 初生葉まで土を上げます |
| 3回目 | 本葉6-7枚 | 第1本葉の節まで上げます。開花10日前までに終えます |

> **土寄せは必ず開花前に終えます。花が咲いた後に畑に入って土を掘り返すと、花が落ち細根が切れて収量が減ります。**

&nbsp;&nbsp;&nbsp;ソリテで土寄せを3回に分ける理由は、体の大きさと栽培期間にあります。ソリテは草丈が高く枝分かれも多いため、8月以降に倒れる危険がダイズより高くなります。一度に大量の土をかけると茎が傷むため、生長速度に合わせて少しずつ何度も土を上げ、株元を丈夫にします。土寄せの効果は4つ同時にもたらされます。株元が埋まって支えができ、埋まった茎から新しい根が出て吸収面積が増え、株間の溝が深くなって梅雨期の水が抜け、若い雑草が土に埋まります。

&nbsp;&nbsp;&nbsp;災害時の条件では、この3回の土寄せは決して軽くない労働になります。人手が足りなければ、1回目と3回目だけでも行います。1回目は幼い株の活着を助け、3回目は倒伏防止に直接働きます。3回とも行えないなら、せめて3回目の時期に一度だけでも行うのがよいでしょう。

### 8-2. 摘心

| 回数 | 時期 | 方法 | 効果 |
|---|---|---|---|
| 1回目 | 本葉5-7枚、必ず開花前 | 茎の先端の生長点を手で摘み取ります | 側枝が増えてさやの付く場所が多くなります |
| 2回目（強摘心） | 生育中期、倒伏の懸念が大きいとき | 下から20-25cmだけ残して切り落とします | 草丈を強制的に低くします |
| 禁止 | 8月以降の開花期 | 行いません | この時期の切断は収量を大きく減らします |

&nbsp;&nbsp;&nbsp;2回目の強摘心はソリテだけに見られる管理技法であり、条件を選んで使う必要があります。堆肥を多く入れたり雨の多い年にソリテが大人の腰の高さを超えて育つと、台風一発で畑全体が倒れてしまいます。その兆しが見えたとき、下から20-25cmだけ残して思い切って切り落とすと、低く丈夫な側枝が新たに出て、倒れずにさやを付けます。堆肥を非常に多く与えた圃場では20cmだけ残します。

&nbsp;&nbsp;&nbsp;逆に、痩せた畑ですでに生育が悪いソリテに強摘心を行うと、回復する力がなく収量が大きく減ります。判断基準は次のとおりです。膝をはるかに超え、葉の色が濃く、節と節の間が長く伸びていれば切ります。すねの高さで止まっていて葉の色が薄ければ、手を加えません。災害時の条件では肥料不足の場合がほとんどなので、基本は1回目の摘心だけを行い、2回目は行わないほうです。

### 8-3. 雑草と倒伏

| 作業 | 時期 | 方法 |
|---|---|---|
| 間引き | 本葉1-2枚 | 1穴当たり2本を残します |
| 除草 | 播種後30-40日から集中的に | 土寄せと兼ねます。浅くかきます |
| マルチング | 3回目の土寄せ以降 | わら・もみ殻・落ち葉・雑草で覆います |
| 支柱・ロープ | 8月、台風予報の前 | 畑の周囲に杭を打ち、腰の高さでロープを張り巡らせます |

&nbsp;&nbsp;&nbsp;ソリテは5か月間畑にあるため、雑草との競合期間も長くなります。幸い8月になると葉が地面を完全に覆うため雑草が大きく増えることはなく、実質的な除草期間は6月と7月です。この2か月の除草が収量を作ります。土寄せと兼ねれば労力が半分に減り、最後の土寄せの後にマルチングで覆っておけば、その後はほとんど手がかかりません。

&nbsp;&nbsp;&nbsp;倒伏対策は8月のうちにあらかじめしておく必要があります。すでに倒れた後で起こそうとすると、根が切れさやが落ちてかえって損害が大きくなります。畑の周囲に杭を打ち、腰の高さでロープを一周張り巡らせると、内側の株同士が支え合って持ちこたえます。畑が広ければ、何列かごとに横のロープをもう一本入れます。すでに完全に倒れてしまった部分は、木の枝を差し込んで軽く持ち上げ、さやが地面に触れないようにします。

## 9. 病害虫

&nbsp;&nbsp;&nbsp;ソリテの病害虫圧はCです。無防除時の推定減収率は47.4%で、防除を一切しなければほぼ半分を失います。原因は栽培期間にあります。9月と10月はカメムシと大豆食心虫の個体数がピークに達する時期であり、そのとき他の豆はすでに収穫され終えているため、畑に残ったソリテにすべての害虫が集まってきます。

### 9-1. 主な病害

| 病名 | 発生時期 | 症状 | 薬を使わない対応 |
|---|---|---|---|
| 炭疽病 | 梅雨後-さやの時期 | 茎とさやに黒い潰瘍 | 種子選別と輪作。抵抗性品種（チョンジャ5号）。ボルドー液を補助的に使用 |
| 細菌性斑点病（野火病） | 梅雨後-さやの時期 | 葉に角ばった褐色斑点と黄色い縁 | 種子消毒、通風の確保、雨の直後の畑への立ち入り禁止 |
| 黒根腐病 | 生育全般 | 根が褐変して腐り、下葉が黄色くなります | 排水改善、畝を高くする、種子消毒、輪作 |
| 褐斑病 | 7月下旬-8月初旬 | 下葉から褐色斑点、早期落葉 | 通風の確保、残渣の除去、ボルドー液 |
| べと病 | 7月下旬-8月初旬 | 葉の表面に黄色い斑点、裏面に灰白色のカビ | 栽植距離の確保、排水、ボルドー液 |
| ダイズモザイク病 | 生育全般 | 葉がモザイク状に斑になり縮れます | 治療不可。直ちに抜いて焼却し、アブラムシを減らします |
| 紫斑病 | 登熟期 | 種皮に紫色の斑 | 黒い種皮では目立ちにくい。明るい光の下で選別します |
| 菌核病 | 涼しく湿っているとき | 茎が軟化し白い菌糸と黒い菌核 | 4年以上の輪作。病株は土ごと掘り上げて焼却します |

### 9-2. 主な害虫

| 害虫 | 発生ピーク | 被害 | 薬を使わない防除 |
|---|---|---|---|
| カメムシ類 | 8月下旬-9月初旬 | さやを刺して汁を吸い、しいなにします。防除を怠ると収穫量が58%まで減少 | 早朝の捕殺、おとり作物、防虫網 |
| 大豆食心虫 | 8月下旬-9月初旬 | 幼虫がさやの中の種実を食べます | 残渣を除去して越冬場所をなくします。被害を受けたさやを摘み取ります |
| アブラムシ | 7月下旬-8月初旬 | 汁を吸いウイルス病を媒介します | 石鹸水（水1Lに石鹸5g）を葉の裏に散布します |
| ハスモンヨトウ | 8月 | 葉とさやを食い荒らします | 手で捕まえます。卵塊は葉ごと取り除きます |
| ハダニ | 乾燥した8月 | 葉裏からの吸汁で葉が黄色くまだらになります | 葉に水を勢いよく吹きかけます |
| 鳥 | 播種直後 | 双葉をついばんで食べます | 発芽までわらや網で覆います |
| キバノロ・ノロジカ | 夏 | 葉と茎を食べます | 柵や網を設置します |

> **ソリテにおいてカメムシ防除は二次的な作業ではなく、収量を決める中心的な作業です。8月下旬から9月中旬までの3週間が勝負どころです。**

| カメムシ対策 | 内容 | 効果 |
|---|---|---|
| 早朝の捕殺 | 気温の低い明け方はうまく飛べません。さやの下を探り手で払い落として水を張った容器に受けます | 最も確実です。3週間、2日に1回行うと個体数がはっきり減ります |
| おとり作物 | 畑の周囲にゴマ、アワ、モロコシ（タカキビ）を植えて引き寄せ、そこで集中的に捕まえます | 本畑の被害を減らします |
| 防虫網をかぶせる | 小面積なら開花後に寒冷紗や防虫網をかぶせます | ソリテは自家受粉なので蜂がいなくても結実します |
| 雑草整理 | 畦畔の豆科雑草をあらかじめ刈り取ります | カメムシの中間宿主をなくします |
| 品種選択 | さやが硬いチョンジャ5号を選びます | 刺され被害が減ります |

&nbsp;&nbsp;&nbsp;防虫網をかぶせる方法は、ソリテで特に有効です。ほとんどの作物は昆虫が受粉を助ける必要があるため、開花期に網をかぶせると結実が悪くなりますが、ソリテは自家受粉なのでそうした損失がありません。小面積の自給栽培であれば、開花が始まる頃に支柱を立てて寒冷紗をかぶせておくと、カメムシと大豆食心虫をほぼ完全に防げます。網が手に入らなければ、古い蚊帳や破れた防虫網、目の細かい布も使えます。

### 9-3. 薬を使わない防除資材と耕種的防除

| 資材 | 作り方 | 対象 |
|---|---|---|
| ボルドー液 | 水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜます | 細菌病、カビ病 |
| 石鹸水 | 水1Lに無香料石鹸5g | アブラムシ、ハダニ |
| 草木灰水 | 灰1升を水10Lに一晩浸し、上澄み液を使います | カビ抑制 |
| 乾いた灰をまく | 露のある朝に葉へ細かい灰をまきます | 葉を食べる虫 |
| 木酢液 | 300-500倍に希釈します | 忌避 |
| 辛いトウガラシ・ニンニク水 | すりつぶして水に浸し、漉して使います | 忌避 |

| 耕種的防除 | 原理 |
|---|---|
| 種子選別 | 炭疽病と紫斑病は種子で伝染します |
| 輪作 | マメ科を2-3年空けます。病原菌は宿主なしでは死にます |
| 栽植距離 | 70cm×20cmを守り、通風を確保します |
| 排水 | ソリテの病害の半分以上が過湿と関係しています |
| 残渣処理 | 病んだ残渣は焼却し、健全な残渣だけを畑に戻します |
| 雨の後は畑に入らない | 濡れた葉に触れると病原菌が付着して広がります |
| 畦畔の整理 | マメ科雑草がカメムシの中間宿主になります |

&nbsp;&nbsp;&nbsp;病んだ残渣と健全な残渣を区別することは、第5節の窒素収支と衝突する点です。窒素を残すには茎葉を畑に戻す必要がありますが、病んだ茎葉を戻すと病原菌が残ってしまいます。葉に斑点が少しある程度なら、切って畑に敷いてもかまいません。菌核病で茎が軟化した株、炭疽病で黒い潰瘍ができた株、モザイク病にかかった株だけを別に集めて焼却するか、畑の外で長期間腐らせます。
