## 10. 营养缺乏与过量

| 症状 | 原因 | 天然材料应对 |
|---|---|---|
| 整株叶片呈浅黄色，植株矮小 | 氮缺乏。在青仁黑豆（Black soybean）中，根瘤发育不良是最常见的原因 | 先挖出根部剖开根瘤查看。若没有根瘤，翌年务必确实接种根瘤菌，当年则少量施用10倍稀释的尿液 |
| 9月起下部叶片迅速变黄脱落，豆粒不饱满 | 灌浆后期氮供应不足 | 这是青仁黑豆特有的症状，多是根瘤过早衰老所致。翌年应加强施磷并强化接种 |
| 叶缘变褐干枯并向内卷曲 | 钾缺乏 | 在株间撒草木灰，轻轻耙入土中 |
| 生长迟缓，叶片带紫色 | 磷缺乏 | 骨粉、烤鱼骨磨的粉、草木灰 |
| 开花后不结荚 | 硼缺乏，或开花期高温·干旱 | 使用原料多样的堆肥。当年则通过灌溉和覆盖来降温 |
| 叶脉呈绿色，但脉间发黄 | 铁或镁缺乏，土壤偏碱性 | 停止使用草木灰，用腐叶土和腐熟堆肥增加有机质 |
| 新叶细小畸形，生长点枯死 | 钙或硼缺乏 | 烤蛋壳磨的粉、贝壳粉 |
| 叶片浓绿茂盛，结荚却少 | 氮过量 | 停止供氮，通过重摘心降低株高 |
| 植株徒长倒伏 | 氮过量或密植 | 进行第二次重摘心并立支架固定，翌年减少施肥量 |
| 种皮黑色偏浅且有斑驳 | 灌浆不足或早霜 | 提前播种。色素是在灌浆后期才积累的 |
| 下部叶片发黄，根系呈褐色 | 因过湿导致的根系损伤 | 开挖排水沟，这不是施肥的问题 |

&nbsp;&nbsp;&nbsp;只有青仁黑豆（Black soybean）才需要单独留意的症状有两种。一种是9月份下部叶片迅速脱落的现象。由于根瘤的寿命是按普通大豆设定的，往往撑不过五个月，在灌浆后期便丧失功能。这时如果土壤中没有氮，植株就会分解下部叶片的蛋白质并输送给豆粒，所以叶片会很快脱落。这在一定程度上属于正常衰老，但若从9月初就急剧发生，就会导致豆粒不饱满，成为问题。根本对策是施足磷肥以支持根瘤的能量代谢，并确保接种菌源可靠。

&nbsp;&nbsp;&nbsp;另一种是种皮颜色变浅的现象。花青素是在灌浆后期才积累的，若灌浆不充分，黑色就会偏浅且斑驳不均。这不是养分缺乏的信号，而是时间不够的信号，意味着当年播种偏晚或霜来得早，翌年应当提前播种。

&nbsp;&nbsp;&nbsp;微量元素缺乏很难逐一应对。在没有化肥的情况下，实际上几乎无法获取钼或钴。取而代之的是，把菜叶碎屑、果皮、蛋壳、鱼骨、落叶、杂草、草木灰混在一起堆沤成的堆肥中，均衡地含有各种微量元素。"什么都往堆肥场里放"这一原则，就是切实可行的策略。

## 11. 间作与轮作

| 相性 | 作物 | 原因 |
|---|---|---|
| 好 | 玉米、高粱 | 能就近分享大豆固定的氮，株高不同还能分层利用光照 |
| 好 | 万寿菊 | 根系分泌物能抑制线虫 |
| 好 | 马铃薯 | 病害不重叠，养分需求也不同。马铃薯若在6月收获会让青仁黑豆播种时间紧张，因此应安排在相邻的垄上 |
| 好 | 大白菜·结球甘蓝类 | 在青仁黑豆之后一年种植，可利用残留的氮 |
| 差 | 番茄·辣椒·茄子 | 会共享病虫害 |
| 差 | 大蒜·洋葱类 | 有报告称其分泌物会抑制根瘤菌 |
| 差 | 与其他豆科连作 | 病原菌和线虫会不断累积 |

&nbsp;&nbsp;&nbsp;青仁黑豆的间作有一个限制，那就是田地要占用到11月才能空出来。若想在青仁黑豆之后种植大蒜、洋葱、大麦这类秋播作物，时间上是对不上的。收完青仁黑豆时已是11月中旬，此时种大蒜的话，根还没扎稳土地就会上冻，无法安然越冬。因此，青仁黑豆田应规划为休闲到翌年春天的田地。把豆秆切碎铺在地里，这段休闲期就不算白白浪费。

&nbsp;&nbsp;&nbsp;与玉米间作，在青仁黑豆上要更加谨慎。玉米8月即可收获，而青仁黑豆此后还需再生长两个半月。若在玉米的荫蔽下度过夏天，青仁黑豆植株会变小，要等玉米收获后才能充分见光，灌浆也随之推迟。考虑到40%遮光会使豆类产量降到一半这一数值，青仁黑豆与其和玉米混种，不如分开单独种植。若要混种，应以玉米两行、青仁黑豆两行的方式充分间隔，并按南北方向布置。

| 项目 | 标准 |
|---|---|
| 休作期限 | 1年以上 |
| 理想周期 | 3-4年 |
| 连作障碍 | 线虫、黑根腐病、炭疽病会不断累积 |

| 4年轮作示例 |
|---|
| 第1年：青仁黑豆 |
| 第2年：春马铃薯或春叶菜类（利用青仁黑豆留下的氮） |
| 第3年：玉米、高粱、粟等谷物 |
| 第4年：根菜类或绿肥 |
| 再次种青仁黑豆 |

&nbsp;&nbsp;&nbsp;若田地狭小、没有余地轮作，最简单的办法是把地分成四块，每年轮换一块种植。若无法分块，至少每年更换种植行的位置。仅仅把去年种豆的行今年改种玉米、去年种玉米的行今年改种豆，就能大大延缓线虫的累积。

## 12. 收获与脱粒

### 12-1. 收获时期的判断

| 判断标准 | 内容 |
|---|---|
| 叶片 | 已变黄并几乎全部脱落。遇霜后会一齐落下 |
| 豆荚 | 整体8成以上已变为褐色 |
| 声音 | 摇晃时能听到豆荚内豆粒碰撞的声音 |
| 豆粒 | 咬下去牙齿咬不进去，啪地裂开。种皮呈深黑色 |
| 含水率 | 籽粒含水率15%左右 |
| 时点 | 叶片全部脱落后7-14天 |

| 地区 | 收获时期 |
|---|---|
| 韩国中部 | 10月下旬至11月中旬 |
| 韩国南部 | 11月上旬至11月下旬 |

&nbsp;&nbsp;&nbsp;青仁黑豆之名本身就道出了收获的时期——这个名字的意思就是"霜豆"，要等到打过第一场霜后再收获。一旦降霜，叶片会在一两天内一齐脱落，只剩豆荚，反而让收获变得更容易。此时豆粒早已灌满，霜不会造成伤害。不过，打过霜和灌浆已经结束是两回事，应先打开几个豆荚，确认豆粒饱满、种皮颜色深后再收获。若豆粒干瘪或种皮颜色浅，说明灌浆尚未完成，也意味着当年播种偏晚了。

> **11月的雨雪是青仁黑豆最后的大敌。干燥的豆荚若反复经历淋湿又晒干，就会裂开使豆粒落地。一旦看到天气转坏的迹象，就不要等完全成熟，应及时收割。**

### 12-2. 收获要领

| 顺序 | 内容 |
|---|---|
| 1 | 选晴朗干燥的日子，在露水干后的上午10点以后收获 |
| 2 | 用镰刀割断茎的根部。若想保留根瘤中的氮，应把根留在地里 |
| 3 | 在田间摊晒一到两天进行预干燥，若下雨要立即收进屋内 |
| 4 | 捆成束后立挂在屋檐下或仓房中进行最终干燥 |
| 5 | 待豆荚彻底晒干、摇晃时有声响后再脱粒 |

&nbsp;&nbsp;&nbsp;11月收获的难点在于干燥。白天短、气温低、湿度高，晒干的速度很慢。因此与其在田间长时间摊晒，不如捆成束立挂在屋檐下或通风良好的仓房中，效果更好，通风比日照更重要。捆扎青仁黑豆时，束不要捆得太粗，否则内部晒不干会发霉，最好捆成一只手能握住的粗细、多扎几束。

### 12-3. 脱粒——不用工具的方法

| 方法 | 工具 | 步骤 | 效率 |
|---|---|---|---|
| 踩袋法 | 厚麻袋 | 把晒干的豆秆装到麻袋半满，扎好袋口后用脚踩。踩十次左右后摇晃调整位置，反复进行 | 适合少量处理，最省事，损失也几乎没有 |
| 连枷 | 长柄上系着枝条的工具 | 把豆秆薄薄摊在草席上，从上方抽打，翻动两三次 | 适合中等规模 |
| 棍棒敲打 | 木棍 | 装入袋中或摊在草席上敲打 | 可替代连枷 |
| 脚搓法 | 无 | 摊在草席上，穿鞋用脚搓动 | 适合少量处理 |
| 敲打木板 | 木板或木桶 | 抓住豆秆束往桶内壁摔打 | 豆粒会集中落在桶内，损失较少 |

&nbsp;&nbsp;&nbsp;脱粒的成败取决于干燥程度。没晒透的豆秆无论怎么敲打豆荚都不会裂开，而晒得过干的豆粒又容易破裂。用手按压豆荚能啪地裂开的状态就是最佳时机，选在冬日阳光好的中午进行会更顺利。青仁黑豆豆粒较大，不容易破裂，但若用连枷用力猛抽，种皮也会裂开，影响商品性和耐储性。踩袋法是最安全的方式。

### 12-4. 精选——借风分选

| 方法 | 原理 | 步骤 |
|---|---|---|
| 扬场（借风分选） | 豆粒重，皮壳和碎屑轻 | 在有风的日子里，用簸箕或容器盛起举高，细细地往下倒。豆粒会直接落下，糠壳则随风飘走 |
| 簸扬 | 上下晃动并向前颠簸 | 较重的豆粒会留在后方 |
| 扇风 | 一人往下倒，另一人用扇子扇风 | 用于无风的日子 |
| 过筛 | 按孔径大小分级 | 用粗筛筛出豆秆碎片，用细筛筛出泥土和小豆粒 |
| 水选 | 秕粒和虫蛀豆粒较轻 | 倒入水桶，撇去漂浮的部分。捞出的豆子要当天重新晒干 |

&nbsp;&nbsp;&nbsp;扬场的要领有三点：选择风力稳定的时段和地点；不要一次性倒下，要细细地缓缓倾倒；反复进行两三次。青仁黑豆种皮发黑，与糠壳颜色区分明显，因此可以边看边操作，相对容易。

&nbsp;&nbsp;&nbsp;水选法在青仁黑豆上有一点需要注意。黑色种皮中的花青素会渗入水中，使水变红，颜色也会略微褪去。营养损失虽不大，但泡太久终归可惜。应短时间浸泡，迅速撇去漂浮的部分后立即捞出晒干。种用豆不使用这种方法，因为一旦泡水，发芽的生理过程就会启动，若在这种状态下晒干，发芽力会下降。

## 13. 留种

| 项目 | 方法 |
|---|---|
| 留种植株挑选 | 提前在田间标记无病害症状、结荚多、未倒伏且灌浆较早的植株 |
| 收获时期 | 待豆荚完全变为褐色、种皮呈深黑色后再收获 |
| 分离 | 单独脱粒，不与食用豆混杂 |
| 挑选 | 剔除种皮颜色浅或有斑驳、皱缩、颗粒小的豆粒 |
| 干燥 | 含水率12-13%，咬下去会啪地裂开 |
| 保存 | 装入密闭容器，置于阴凉黑暗处，与食用豆分开容器存放 |
| 保存期限 | 常温密封可存3年，发芽率逐年下降 |
| 更新 | 每3-4年从其他地区获取种子并混入一部分 |

&nbsp;&nbsp;&nbsp;在青仁黑豆的留种中，特别值得关注的性状是灌浆速度。青仁黑豆最大的风险就是在霜降之前无法完成灌浆，因此若持续在同一块田里挑选比其他植株更早成熟的植株留种，几年后就能培育出适应当地霜期的品系。这与种子公司所做的育种工作相同，灾难持续得越久，这种积累就越能发挥作用。

&nbsp;&nbsp;&nbsp;方法很简单。10月中旬巡视田地，给比其他植株更早变黄、豆荚更早变褐的植株系上绳子或布条做标记，同时也要留意结荚多、未倒伏的条件。收获时只单独采收做过标记的植株，单独脱粒、单独保存。每年重复这项作业，成熟期就会逐渐提早。

&nbsp;&nbsp;&nbsp;挑选时以种皮颜色为标准。颜色浅或有斑驳的豆粒说明灌浆未充分完成，发芽力较低，这一性状也可能被遗传下去。深沉有光泽的黑色，剖开后呈鲜绿色，是优质青仁黑豆种子的标志。

| 种子保存期限与发芽率 |
|---|
| 收获当年：90%以上 |
| 经过1年：80-90% |
| 经过2年：60-80% |
| 经过3年：40-60% |
| 4年以后：急剧下降 |

&nbsp;&nbsp;&nbsp;反复自留种，会让种传病害悄悄累积。炭疽病、紫斑病、花叶病都会随种子传给下一代。挑出肉眼可见的斑点能在很大程度上防止此类问题，但黑色种皮上斑点不易看清，这是个难题。应在明亮的光线下检查，若仍不放心，可每3-4年从邻村或其他山谷获取种子混入一部分。
