### 1-3. 強みをどう読むか

&nbsp;&nbsp;&nbsp;SSはタンパク質密度、施肥、施設負担、貯蔵性の4項目に付き、Sは微量栄養素、連作適応性、無投入収量維持率、味、普及度、自家採種に付きました。ダイズと同じ並びです。同じ種なので当然の結果であり、これが意味するのは、ソリテもダイズと同様に、外から何も入ってこない条件でも循環が途切れない作物だということです。

&nbsp;&nbsp;&nbsp;ダイズと比べてソリテのほうが優れている項目は水消費量ひとつです。ソリテの総蒸発散量は約450mmで、ダイズの450-700mmの区間の下側に位置します。等級ではAとBの差です。理由は栽培時期にあります。ソリテの生育後半は9月と10月にかかりますが、この時期は気温が下がり蒸発散が減る区間です。真夏の猛暑の下でさやを充実させる早生ダイズと違い、ソリテは涼しい秋の空気の中で登熟します。そのため同じ種でありながら水の要求量がやや低く、秋の干ばつさえなければ灌水なしで結実します。

&nbsp;&nbsp;&nbsp;副食等級SS、63.4点という数字にも実質的な意味があります。熱量の面では主食にはなり得ませんが、おかずの資源としては最上位クラスです。コンジャバン（甘辛く煮た黒豆のおかず）一皿、豆を混ぜたご飯一杯だけで、1日のタンパク質のかなりの部分が満たされます。ここに貯蔵性SSが加われば、その年に収穫したものだけで翌年までおかずの柱を維持できるという意味になります。

> **ソリテの強みは、ダイズと同じ骨格に、涼しい秋を利用する性質が加わった点にあります。真夏の猛暑が厳しい地域では、ソリテのほうがダイズより結実が安定する場合があります。**

### 1-4. 弱みをどう読むか

&nbsp;&nbsp;&nbsp;ソリテがダイズより劣る項目は2つです。収穫速度がCからDへ、病害虫圧がAからCへ下がりました。これに加えて、面積当たり熱量はダイズと同じCですが実際の数値は1,002から922kcalへ下がっており、非食用価値もCからDへ下がりました。

&nbsp;&nbsp;&nbsp;収穫速度Dが最も実質的な制約です。160-180日は、韓国中部で霜のない期間のほぼ全部に当たります。5月下旬から6月中旬の間に植えてこそ10月下旬から11月中旬の間に収穫でき、6月中旬を過ぎると登熟が終わる前に霜が来てしまいます。この狭い間隔は2つのことを意味します。第一に、ソリテは後作として使いにくいということです。大麦やニンニクを収穫した跡地に植えるには時期がぎりぎりです。第二に、播種期を分けてリスクを分散する戦略を取る余裕が、ダイズより少ないということです。

&nbsp;&nbsp;&nbsp;病害虫圧Cは、畑に長く立っていることの代償です。無防除時の減収率47.4%は、防除を一切しなければほぼ半分を失うという意味です。ダイズの23%と比べると2倍を超えます。理由は明確です。9月と10月はカメムシの個体数がピークに達する時期であり、そのときソリテはまださやを充実させている最中です。他の豆がすべて収穫された畑にソリテだけが残っていると、その畑のカメムシが一か所に集まってきます。ソリテ栽培においてカメムシの管理は、二次的な作業ではなく収量を左右する中心的な作業です。

&nbsp;&nbsp;&nbsp;非食用価値Dは、ダイズのCより1段階低くなっています。ダイズが蜜源として認められている項目が、ソリテでは外れています。実用面で大きな差ではありませんが、窒素固定以外では畑の外でその値打ちを発揮しない作物だという点は、覚えておく価値があります。

## 2. どんな植物か

### 2-1. 黒豆の種類

&nbsp;&nbsp;&nbsp;黒豆は単一の品種ではなく、種皮が黒いダイズ系統の総称です。韓国でよく使われる区分は3種類です。

| 名称 | 大きさ | 子葉の色 | 特徴と用途 |
|---|---|---|---|
| ソリテ（sokcheong） | 中大粒 | 緑色 | 皮が黒く中が緑色です。甘みがあり、ご飯に入れたりコンジャバンにします。晩生種です |
| フクテ（大粒の黒豆） | 大粒 | 黄色 | 黒豆の中で最も大きい品種です。醤類や豆腐、黒豆茶に使います |
| ソモクテ（小粒の黒豆） | 小粒 | 緑または黄色 | 粒が最も小さい品種です。薬用や豆もやしに使います。皮の割合が高くアントシアニン密度が高くなります |

&nbsp;&nbsp;&nbsp;災害対策の観点からこの3系統をどう配分するかは、考えてみる価値のある問題です。ソモクテは粒が小さいため同じ重さでずっと多く植えられ、豆もやしの出来もよく、皮の割合が高いため抗酸化色素を多く取り込めます。フクテは粒が大きいため醤を仕込むのに向いています。ソリテはそのまま煮て食べるのに最も味がよいものです。種子をひとつだけ選ぶなら、面積効率と用途の幅ではソモクテが有利で、味と収量を見るならソリテです。

### 2-2. ダイズとの違い

| 項目 | 一般ダイズ | ソリテ |
|---|---|---|
| 生育日数 | 120-150日 | 160-180日 |
| 播種適期（韓国中部） | 5月上旬-6月上旬 | 5月下旬-6月中旬 |
| 収穫時期（韓国中部） | 10月上中旬 | 10月下旬-11月中旬 |
| 生育適温 | 20-25℃ | 20-23℃。涼しい条件を好みます |
| 好適pH | 6.0-6.5 | 6.0-7.0。中性に近いほうを好みます |
| 種皮 | 黄白色が基本 | 黒色。アントシアニン |
| 子葉 | 黄色 | ソリテは緑色 |
| 単収 | 250kg/1,000㎡ | 230kg/1,000㎡ |
| 無防除時の減収率 | 23% | 47.4% |
| 総蒸発散量 | 450-700mm | 約450mm |
| 土寄せ | 1回 | 2-3回 |
| 摘心 | 1回（本葉5-7枚） | 1回目の摘心 + 必要に応じて2回目の強摘心 |

&nbsp;&nbsp;&nbsp;見た目と生育段階の構造はダイズと同じです。三出葉、微毛に覆われた茎とさや、白または淡紫色の小さな花、自家受粉、まっすぐな主根とその上につく根粒まで、すべて同一です。異なるのは各段階にかかる時間です。ソリテは栄養生長期が長く8週まで続き、開花が8-12週にわたり、登熟は14-20週かけてゆっくり進みます。この遅い登熟が、粒を大きくし糖分を蓄えさせる原因です。

### 2-3. 生育段階

| 段階 | 時期 | 中心的な生理 | 重要な栄養 |
|---|---|---|---|
| 発芽・幼苗期 | 播種から4週 | 発芽と初期生長、根粒形成が始まります | リン酸、少量の窒素 |
| 栄養生長期 | 4-8週 | 茎と葉が増え、根粒の働きが活発になります | 窒素は根粒が供給 |
| 開花期 | 8-12週 | 花が咲き、受粉が行われます | リン酸、ホウ素 |
| さや肥大期 | 10-14週 | さやと種子が大きくなります | カリウム、リン酸 |
| 登熟・成熟期 | 14-20週 | 粒がゆっくり充実し、種皮に色素が蓄積します | 灌水中止 |

> **ソリテの登熟期は霜の時期と重なります。葉は霜で枯れますが、すでに熟したさやの中の粒は傷みません。むしろ葉が霜で枯れることで残った養分が粒に集まり、味が深まります。**

&nbsp;&nbsp;&nbsp;霜とソリテの関係は誤解の多い部分です。ソリテが霜に強い豆だという説明は正確ではありません。耐寒性の等級はダイズと同じEであり、葉と茎は霜が一度降りるだけで枯れます。ただ、その時点ですでに粒がほぼ充実し終えているため、収穫に支障がないだけなのです。登熟が終わりきらない状態で霜に当たると、そのさやの粒はしぼんだり空のまま残ったりします。したがって、ソリテ栽培のコツは霜に耐えることではなく、霜が来るまでに登熟を終わらせておくことです。播種適期を守ることがすべてだと言っても言い過ぎではありません。

### 2-4. 100gあたりの栄養

| 栄養素 | 含有量 | 備考 |
|---|:---:|---|
| 熱量 | 401-413kcal | 乾燥豆基準です |
| タンパク質 | 33.6-43.1g | 韓国国家標準食品成分表の値38.02g。熱量に対して37.9%です |
| 脂質 | 16.35g | ほとんどが不飽和脂肪酸です |
| 炭水化物 | 36.40g | オリゴ糖がかなりの量含まれます |
| カルシウム | 224mg | 植物性食品の中では高いほうです |
| リン | 629mg | 多いほうです |
| 鉄 | 7mg前後 | 肉類がないときに重要です |
| 糖類 | 3.28g | 一般ダイズより甘みがあります |
| アントシアニン | 種皮に豊富 | 抗酸化色素です |
| イソフラボン・サポニン | 含有 | 抗酸化物質です |

&nbsp;&nbsp;&nbsp;アントシアニンは種皮に集中しています。したがって皮をむくと失われます。ソリテを皮ごと食べるべき理由であり、粒が小さく皮の割合が高いソモクテが抗酸化密度で有利な理由でもあります。水に浸けておくと水が黒っぽい赤色に染まりますが、それがアントシアニンなので、その水を捨てずに炊飯の水や煮る水として使うほうがよいでしょう。ただし、最初に浸けた水にはオリゴ糖と抗栄養成分が一緒に溶け出しているため、これは捨てる必要があります。最初の水は捨て、2回目以降を活かす方法が妥協点です。

&nbsp;&nbsp;&nbsp;糖類3.28gは一般ダイズより高い値で、ソリテを煮たときに甘みが出る理由です。甘味料が手に入らない状況では、この甘さはそれ自体に価値があります。砂糖なしでコンジャバンを作れるのも、この糖分のおかげです。味の等級Sはここから来ています。災害時に食べる気になるかどうかは、二次的な問題ではありません。食べたくない食べ物は結局残り、残った食べ物は無駄になります。
