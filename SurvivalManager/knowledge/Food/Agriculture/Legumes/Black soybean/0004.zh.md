## 6. 播种

### 6-1. 播种时期 - 青仁黑豆（Black soybean）栽培的第一道关口

| 地区 | 适宜播种期 | 播种极限期 | 收获时期 |
|---|---|---|---|
| 韩国中部 | 5月下旬-6月中旬 | 6月下旬 | 10月下旬-11月中旬 |
| 韩国南部 | 6月上旬-6月下旬 | 7月上旬 | 11月上旬-11月下旬 |
| 高冷地区·韩国北部山区 | 不适宜栽培 | - | 积温不足 |

&nbsp;&nbsp;&nbsp;确定播种日的方法是倒推计算。先查清本地初霜的平均日期，从中减去170天，就得到播种极限日；再留出10天余量，即为适宜期的终点。韩国中部的初霜通常在10月下旬，因此极限日在6月中旬。南部初霜在11月中旬，所以最晚可种到6月下旬。

> **在收完马铃薯或大蒜的地里接着种青仁黑豆，时间会很紧张。一旦超过6月下旬，与其两茬种植，不如改种其他豆类更为安全。绿豆或豇豆只需80-90天即可，作为后茬作物要合适得多。**

### 6-2. 种子准备与播种

| 项目 | 方法 | 灾害条件下 |
|---|---|---|
| 挑选 | 剔除有斑点、变色、皱缩、虫眼的籽粒 | 用手逐粒挑选，是成本最低、效果最好的作业 |
| 检查紫斑病 | 挑出种皮上有紫色斑纹的籽粒 | 黑色种皮不易看出斑纹，需在明亮光线下检查 |
| 温水消毒 | 浸入50-55℃的水中10-15分钟 | 热度以手伸入后勉强坚持5秒为准。超过60℃会损伤发芽力 |
| 草木灰处理 | 裹上细草木灰 | 有助于消毒和干燥，并有驱鸟驱虫的效果 |
| 根瘤接种 | 裹上种过豆的地块的土 | 不与消毒同时进行，须在温水消毒后完全晾凉再接种 |
| 发芽试验 | 用湿布包住20粒种子，放置数天后清点发芽数量 | 陈种子务必事先检查 |

| 项目 | 标准 | 理由 |
|---|---|---|
| 播种深度 | 3-5cm | 2cm以内容易变干并被鸟啄食，超过5cm则出苗变差 |
| 每穴粒数 | 2-3粒 | 之后间苗时留2株 |
| 行距 | 70cm（建议单行种植） | 确保通风和采光，防止梅雨季涝害 |
| 株距 | 20cm | 青仁黑豆植株长得大，间距应比大豆更宽 |
| 垄高 | 20cm以上，圆垄 | 兼顾排水与防倒伏 |

&nbsp;&nbsp;&nbsp;之所以把种植距离设得比大豆更宽，是因为青仁黑豆要生长五个月，植株会长得更大。若按大豆的间距种植，到8月叶片就已经交叠、阻碍通风，历经梅雨和台风后病害蔓延、植株倒伏。70cm配20cm看起来很宽裕，但到9月就恰好填满。每垄只种一行的做法被推荐，也是同样的原因。

&nbsp;&nbsp;&nbsp;播种后不久面临的威胁是鸟类。鸽子、喜鹊和雉鸡会啄食刚发芽的豆子的子叶，失去子叶的植株大多会死亡。可以在播种行上薄薄地覆盖一层树枝或稻草，或者在发芽前罩上网子或旧防虫网，也可以交叉拉起反光绳。最可靠的办法是在发芽初期的10天里，早晚都到地里巡视。

## 7. 水分管理

| 时期 | 水分管理 | 理由 |
|---|---|---|
| 播种到发芽 | 避免土壤过度干燥 | 种子须吸收相当于自身重量的水分才能发芽 |
| 生育初期（6-7月） | 交给自然降水即可 | 这一时期的干燥能促使根系向下深扎，过湿反而更危险 |
| 梅雨季 | 集中做好排水 | 这时的重点不是灌溉，而是排水 |
| 开花期-荚粒膨大期（8-9月） | 应充分供水，避免土壤变干 | 全生育期用水量的80%集中在这一时期 |
| 灌浆期（10月） | 减少浇水 | 过湿会导致豆荚无法变干 |
| 成熟期 | 停止灌溉 | 会导致落粒和早期落叶 |

&nbsp;&nbsp;&nbsp;青仁黑豆在水分管理上与大豆不同的地方，在于还要担心秋季干旱。大豆9月就已完成灌浆，而青仁黑豆要一直灌浆到9月下旬。若某年9月无雨，这一时期的灌溉将直接决定产量。反之，若10月雨水频繁，豆荚就无法变干，导致收获推迟，籽粒还会生霉。

| 症状 | 原因 | 处理方法 |
|---|---|---|
| 白天叶片萎蔫，傍晚恢复 | 暂时性缺水，属正常现象 | 无需处理 |
| 早晨叶片仍然萎蔫 | 根系无法输送水分 | 需充分灌溉 |
| 大量落花 | 开花期干旱或高温 | 通过灌溉和覆盖降低地温 |
| 已结荚但籽粒偏小 | 荚粒膨大期缺水 | 这一时期的灌溉直接决定产量 |
| 9月下部叶片突然发黄 | 灌浆后期缺氮或缺水 | 需检查根瘤并灌溉 |
| 下部叶片发黄，根系发黑 | 过湿导致根系受损 | 需开挖排水沟，并通过培土垫高地面 |
| 整株叶片淡黄但不萎蔫 | 根瘤不良导致缺氮 | 需挖出根系，掰开根瘤检查 |

&nbsp;&nbsp;&nbsp;覆盖对青仁黑豆栽培尤为重要。由于生长期长，与杂草竞争的时间也长，而且夏季既要经历干旱又要经历地温升高。即使没有塑料薄膜，用稻草、稻壳、落叶或割下的杂草覆盖5至10cm厚，也能使地表蒸发减少一半以上，还能减轻除草的劳动。不过由于培土需要分多次进行，覆盖最好安排在培土完成后的7月以后进行，这样更符合作业顺序。

## 8. 栽培管理 - 培土与摘心

### 8-1. 培土 - 三次

| 次数 | 时期 | 方法 |
|---|---|---|
| 第1次 | 真叶2-3片 | 将土培至子叶被埋住的程度 |
| 第2次 | 真叶4-5片 | 培土至初生叶处 |
| 第3次 | 真叶6-7片 | 培土至第1片真叶的节位。须在开花前10天完成 |

> **培土必须在开花前完成。开花之后进地翻土，会造成落花和细根断裂，导致产量下降。**

&nbsp;&nbsp;&nbsp;青仁黑豆之所以把培土分成三次，原因在于植株体型和生长周期。青仁黑豆植株高、分枝多，8月以后倒伏的风险比大豆更高。若一次培土过多会伤茎，因此要配合生长速度分多次少量培土，使茎基部变得牢固。培土的效果有四项同时发生：茎基部被埋住形成支撑；被埋的茎上长出新根，吸收面积增大；株间的沟变深，有利于梅雨季排水；幼小的杂草也被埋入土中。

&nbsp;&nbsp;&nbsp;在灾害条件下，这三次培土是不小的劳动量。人手不足时，至少完成第1次和第3次。第1次有助于幼株扎根，第3次则直接起到防止倒伏的作用。如果三次都做不到，最好至少在第3次的时期做一次。

### 8-2. 摘心

| 次数 | 时期 | 方法 | 效果 |
|---|---|---|---|
| 第1次 | 真叶5-7片，须在开花前 | 用手摘除茎顶端的生长点 | 侧枝增多，结荚部位随之增加 |
| 第2次（强摘心） | 生育中期，倒伏风险较大时 | 只留下部20-25cm，其余剪除 | 强制降低株高 |
| 禁止 | 8月以后的开花期 | 不可进行 | 此时修剪会大幅减产 |

&nbsp;&nbsp;&nbsp;第2次强摘心是青仁黑豆特有的管理技巧，必须视条件而定是否采用。若施入堆肥过多，或雨水偏多的年份使青仁黑豆长到超过成人腰部的高度，一场台风就能让整片地倒伏。一旦出现这种迹象，果断地只留下部20-25cm、其余剪除，就能促使低矮而结实的侧枝重新长出，不再倒伏并正常结荚。堆肥施用极多的地块，只留20cm。

&nbsp;&nbsp;&nbsp;反之，如果在贫瘠地块上生长已经不佳的青仁黑豆进行强摘心，植株将无力恢复，导致大幅减产。判断标准如下：植株明显超过膝盖高度、叶色浓绿、节间拉得很长时，可以剪。若植株只到小腿高度、叶色偏淡，则不要动它。在灾害条件下，肥料不足的情况居多，因此基本原则是只做第1次摘心，不做第2次。

### 8-3. 杂草与倒伏

| 作业 | 时期 | 方法 |
|---|---|---|
| 间苗 | 真叶1-2片 | 每穴留2株 |
| 除草 | 从播种后30-40天开始集中进行 | 与培土同时进行，浅浅地锄松表土 |
| 覆盖 | 第3次培土之后 | 用稻草·稻壳·落叶·杂草覆盖 |
| 支柱·拉绳 | 8月，台风预报之前 | 在地块四周打入木桩，齐腰高度绕拉绳索 |

&nbsp;&nbsp;&nbsp;青仁黑豆在地里生长五个月，与杂草竞争的时间也长。幸好到了8月，叶片已完全覆盖地面，杂草不会大量增多，因此实际的除草期集中在6月和7月。这两个月的除草工作决定了产量。若与培土合并进行，劳动量可减半；最后一次培土后再用覆盖物盖住地面，之后几乎不需要再费工夫。

&nbsp;&nbsp;&nbsp;防倒伏措施必须在8月提前做好。等已经倒伏后再扶起，会造成断根和落荚，损失反而更大。在地块四周打入木桩，齐腰高度绕拉一圈绳索，内侧的植株便能相互依靠支撑。地块较宽时，每隔几行再加一道横向绳索。已经完全倒伏的部分，可用树枝垫起使其略微离地，避免豆荚接触地面。

## 9. 病虫害

&nbsp;&nbsp;&nbsp;青仁黑豆的病虫害压力为C级。无防治时估计减产率为47.4%，若完全不防治，将损失近一半收成。原因在于栽培期长。9月和10月是蝽象与大豆食心虫种群数量达到顶峰的时期，此时其他豆类已经收获完毕，于是所有害虫都聚集到田里仅剩的青仁黑豆上。

### 9-1. 主要病害

| 病名 | 发生时期 | 症状 | 无药防治方法 |
|---|---|---|---|
| 炭疽病 | 梅雨后-结荚期 | 茎和豆荚上出现黑色溃疡斑 | 种子挑选与轮作，选用抗病品种（Cheongja 5号），辅以波尔多液 |
| 细菌性斑点病（野火病） | 梅雨后-结荚期 | 叶片出现带棱角的褐色斑点，边缘发黄 | 种子消毒、确保通风、雨后立即禁止进地 |
| 黑根腐病 | 整个生育期 | 根系变褐腐烂，下部叶片发黄 | 改善排水、加高垄面、种子消毒、轮作 |
| 褐斑病 | 7月下旬-8月初 | 从下部叶片开始出现褐色斑点，早期落叶 | 确保通风、清除病残体、波尔多液 |
| 霜霉病 | 7月下旬-8月初 | 叶片正面黄色斑点，背面灰白色霉层 | 确保种植距离、排水、波尔多液 |
| 大豆花叶病 | 整个生育期 | 叶片出现花叶斑驳并卷曲 | 无法治疗，须立即拔除烧毁，并减少蚜虫 |
| 紫斑病 | 灌浆期 | 种皮出现紫色斑纹 | 在黑色种皮上不易察觉，需在明亮光线下挑选 |
| 菌核病 | 凉爽潮湿时 | 茎秆软化，出现白色菌丝和黑色菌核 | 轮作4年以上，病株须连土挖出烧毁 |

### 9-2. 主要害虫

| 害虫 | 发生高峰 | 危害 | 无药防治方法 |
|---|---|---|---|
| 蝽象类 | 8月下旬-9月初 | 刺吸豆荚汁液，使籽粒变成秕粒。若疏于防治，产量最多可减少58% | 清晨捕杀、诱集作物、防虫网 |
| 大豆食心虫 | 8月下旬-9月初 | 幼虫蛀食豆荚内的籽粒 | 清除病残体以消除越冬场所，并摘除受害豆荚 |
| 蚜虫 | 7月下旬-8月初 | 刺吸汁液并传播病毒病 | 将肥皂水（1L水配5g肥皂）喷洒在叶背 |
| 斜纹夜蛾 | 8月 | 大量啃食叶片和豆荚 | 徒手捕捉，卵块连叶一并摘除 |
| 叶螨 | 8月干旱时 | 在叶背吸食汁液，使叶片出现黄色斑驳 | 用水用力喷洒叶片 |
| 鸟类 | 播种后不久 | 啄食子叶 | 发芽前用稻草或网覆盖 |
| 獐·狍子 | 夏季 | 啃食叶片和茎秆 | 需设置围栏或网具 |

> **对青仁黑豆而言，蝽象防治不是次要工作，而是决定产量的关键作业。从8月下旬到9月中旬的这三周，是决定胜负的关键期。**

| 蝽象应对方法 | 内容 | 效果 |
|---|---|---|
| 清晨捕杀 | 气温低的凌晨蝽象飞行能力差。翻找豆荚下方，用手拍落到装水的容器中 | 最为可靠。持续3周、每两天一次，虫口数量会明显下降 |
| 诱集作物 | 在地块四周种植芝麻、粟、高粱以吸引蝽象，再集中捕杀 | 可减少主地块的受害程度 |
| 覆盖防虫网 | 小面积种植可在开花后覆盖寒冷纱或防虫网 | 青仁黑豆为自花授粉，没有蜜蜂也能结实 |
| 清理杂草 | 提前割除田埂上的豆科杂草 | 消除蝽象的中间寄主 |
| 品种选择 | 选用豆荚坚硬的Cheongja 5号 | 可减少刺吸危害 |

&nbsp;&nbsp;&nbsp;覆盖防虫网的方法在青仁黑豆上尤其管用。大多数作物依赖昆虫授粉，开花期覆网会影响结实，而青仁黑豆是自花授粉，不存在这种损失。若是小面积自给种植，在开花开始前后立起支架并覆上寒冷纱，几乎可以完全挡住蝽象和大豆食心虫。如果找不到网，旧蚊帐、破损的防虫网，或密织的布料也可以使用。

### 9-3. 无药防治资材与农业防治

| 资材 | 制作方法 | 防治对象 |
|---|---|---|
| 波尔多液 | 在100L水中分别溶入硫酸铜400g和生石灰400g后混合 | 细菌性病害、真菌性病害 |
| 肥皂水 | 1L水配无香皂5g | 蚜虫、叶螨 |
| 草木灰水 | 将1升（约1.8升）草木灰浸入10L水中一夜，取上层清液使用 | 抑制真菌 |
| 撒干灰 | 在有露水的早晨向叶片撒细灰 | 食叶害虫 |
| 木醋液 | 稀释300-500倍 | 驱避 |
| 辣椒·大蒜水 | 捣碎后泡水，过滤后使用 | 驱避 |

| 农业防治 | 原理 |
|---|---|
| 种子挑选 | 炭疽病和紫斑病会通过种子传播 |
| 轮作 | 豆科作物间隔2-3年不种。病原菌因缺乏寄主而死亡 |
| 种植距离 | 保持70cm×20cm，确保通风 |
| 排水 | 青仁黑豆病害中半数以上与过湿有关 |
| 病残体处理 | 病株残体须焚烧，只将健康残体归还田地 |
| 雨后禁止进地 | 触碰湿叶会使病原菌沾附传播 |
| 清理田埂 | 豆科杂草会成为蝽象的中间寄主 |

&nbsp;&nbsp;&nbsp;区分病残体与健康残体，是与第5节所讲的氮素平衡相冲突之处。要留住氮，就得把茎叶归还田地，但归还染病的茎叶，病原菌也会随之留下。如果叶片只是略有斑点，剪碎覆盖也无妨。只有因菌核病而茎秆软化的植株、因炭疽病而生出黑色溃疡斑的植株，以及感染花叶病的植株，才需单独收集起来焚烧，或运到田外长期堆放腐熟。
