## はじめに
&nbsp;&nbsp;&nbsp;ソリテはダイズ(Glycine max)と同じ種で、種皮が黒く中身が緑色の黒大豆系統の晩生種です。初霜が降りたあとに収穫することからソリテ(ソリは霜の意味)と呼び、10月下旬から11月中旬まで畑に立って、最後に実を充実させます。総合等級はA(48.5点、有効183種中29位)で、短期B(45.5)、長期S(51.8)、副食はSS(63.4点)です。タンパク質密度はダイズと同じSS(熱量比37.9%)で貯蔵性もSSであり、種皮のアントシアニンは新鮮な野菜がなくなった食事の抗酸化物質の供給源になります。播種から収穫まで160-180日とダイズの120-150日より1か月以上長く収穫速度はDですが、粒が大きく糖がのって味が深まります。病害虫圧がCでダイズのAより悪く、無防除感受率は47.4%(ダイズは23%)、収量も1,000㎡当たり230kgでダイズの250kgより少なくなります。ソリテは時間を要し手間もかかる豆なので、人手が足りない状況でどちらか一つを選ぶなら、ダイズが安全な選択です。

## 1. 災害への備えの評価
| 区分 | 等級 | スコア |
|:---|:---:|:---:|
| 総合 | A | 48.5 |
| 短期 | B | 45.5 |
| 長期 | S | 51.8 |
| 副食 | SS | 63.4 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: タンパク質密度、施肥、施設の負担、貯蔵性。S: 微量栄養素、連作への適応性、合成資材を投入しない場合の収量維持率、味、国内での栽培の普及度、自家採種。A: 水の消費量、収量の安定性、種子の寿命。B: 防除の自立度 |
| 弱み | E: 耐寒性。D: 収穫速度、永続性、日射、調理・加工の要求度、非食用の価値。C: 面積当たりの熱量、温度幅、病害虫圧、整地・掘削エネルギー |

&nbsp;&nbsp;&nbsp;ダイズより優れた項目は水の消費量Aの一つで、生育後半が蒸発散の減る9-10月にかかるためです。収穫速度Dの160-180日は中部地方の霜のない期間のほとんどすべてなので、オオムギやニンニクのあとの後作にしにくいです。病害虫圧Cは、カメムシが最盛期になる9-10月にも畑に立っている代償です。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 名前 | 大きさ | 中身の色 | 特徴と用途 |
|:---|:---|:---|:---|
| ソリテ(青仁) | 中大粒 | 緑 | 晩生種。甘みがあり、ごはんや豆の甘辛煮に使う |
| ヒュクテ(黒大豆) | 大粒 | 黄 | 黒豆の中で最も大きい。みそ類、豆腐、黒豆茶に使う |
| ソモクテ(ネズミの目豆、薬豆) | 小粒 | 緑か黄 | 最も小さくアントシアニン密度が高い。薬用、もやしに使う |

| 項目 | 一般のダイズ | ソリテ |
|:---|:---|:---|
| 生育日数 | 120-150日 | 160-180日 |
| 播種適期(中部) | 5月上旬-6月上旬 | 5月下旬-6月中旬 |
| 収穫時期(中部) | 10月上旬-中旬 | 10月下旬-11月中旬 |
| 生育適温、pH | 20-25℃、6.0-6.5 | 20-23℃(涼しい側を好む)、6.0-7.0 |
| 収量、無防除感受率 | 250kg/1,000㎡、23% | 230kg/1,000㎡、47.4% |

&nbsp;&nbsp;&nbsp;形と生育段階の構造はダイズと同じで、開花期は播種後8-12週、莢肥大期は10-14週、登熟・成熟期は14-20週です。登熟期が霜と重なり、葉は霜で枯れても、すでに実った莢の中の粒は傷まず、残った養分が粒に集まって味が深まります。

> **ソリテが霜に強い豆だというのは正確ではありません。耐寒性はダイズと同じEで、ソリテ栽培の要領は霜に耐えることではなく、霜が来るまでに登熟を終えておくことです。**

&nbsp;&nbsp;&nbsp;乾燥した豆100g当たり熱量401-413kcal、タンパク質33.6-43.1g(標準値38.02g)、脂質16.35g、炭水化物36.40g、カルシウム224mg、リン629mg、鉄約7mg、糖類3.28gです。アントシアニンは種皮に集中し、糖類は一般のダイズより高くて、ゆでると甘みが出ます。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽10℃以上(最適20-22℃)、生育15-35℃(最適20-23℃)、登熟期15℃以上(最適18-25℃)。積算温度2,800-3,200℃が必要で、ダイズより300℃以上多く積む必要がある。霜で葉と茎が枯れる |
| 水、土壌 | 保水力があり水はけのよい砂壌土か壌土、pH6.0-7.0、有効土層50cm以上。作期の蒸発散量は約450mm。2日以上冠水すると枯れ、畝は20cm以上の丸い畝 |

> **ソリテで遅い播種の代償は遅い収穫ではなく、空のさやです。遅く植えると遅く収穫するのではなく、収穫するものがなくなります。**

| 品種 | 特徴 |
|:---|:---|
| 在来ソリテ | 味がよく、地域に適応しており、自家採種を続けられる。収量160-260kg/1,000㎡ |
| チョンジャ5号 | 病害と倒伏に強く、さやが堅くはじけにくく、カメムシの被害が少ない。収量約343kg |
| ヒュクテ、ソモクテ | ヒュクテは粒が大きく、みそ類と豆腐に向く。ソモクテは粒が最も小さく、種子が足りないとき同じ重さでより広く植えられ、もやしに使う |

&nbsp;&nbsp;&nbsp;二つの品種はどちらも自家受粉の固定種なので、チョンジャ5号で収量を、在来種で地域への適応を確保するように分けて植えるのが理想です。初霜が10月初めの高冷地や北部の山間地は積算温度が足りないので早生ダイズを選び、播種日は自分の地域の初霜の平均日から170日さかのぼって決めます。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 施肥(1,000㎡) | 窒素3kg(根粒が働く前の初期用の最小量)、リン酸3kg、カリウム3.4kg(すべて元肥)、完熟堆肥1,000kg、酸性土なら石灰200kg(播種の3-4週間前)。窒素を増やすと葉だけ茂って倒れ、ダイズより害が大きい |
| 代替資源 | 骨粉と焼いた魚の骨(リン酸、カルシウム)、落ち葉の腐葉土(保水力)、もみ殻とわら(未熟なものは窒素を奪う) |
| 根粒の接種 | ダイズを育てた畑の表土5-15cmの土を、水で軽く湿らせた種子にまぶし、日陰で30分以内に播種(日に干すと菌が死ぬ)。野生のツルマメの根の根粒も使う。pH5.5以下、窒素肥料の過多、水がたまる、リン酸不足、殺菌剤処理した種子では失敗 |
| 根粒の点検 | 開花のころ(播種後8-10週)、スコップで土ごと掘り上げて洗い、根粒を割る。1株20個以上で内側が赤かピンクなら窒素を固定中で、白か薄い緑なら酸度、湿害、リン酸欠乏を調べる |

> **マメ科が土を肥やすのは窒素を固定するからではなく、固定した窒素の一部を茎と葉にためて畑に残すからです。その茎と葉を運び出せば、豆は土を収奪する作物になります。**

&nbsp;&nbsp;&nbsp;固定量は1ヘクタール当たり100-150kg(条件が悪いと30-60kg)ですが、子実で130-145kgが出ていくので、豆がら、葉、さやの殻を20-30cmに切って畑に戻してはじめて収支が合います。接種は、栽培期間が5か月を超えるソリテで特に重要で、不十分だと莢肥大期に窒素が足りず、粒の入りが悪くなります。

| 播種 | 基準 |
|:---|:---|
| 時期 | 中部は5月下旬-6月中旬(限界は6月下旬、収穫は10月下旬-11月中旬)、南部は6月上旬-下旬(限界は7月上旬、収穫は11月上旬-下旬)。ジャガイモやニンニクのあとに続けるには厳しく、6月下旬を過ぎれば80-90日でよいリョクトウかササゲのほうがよい |
| 種子の準備 | 斑点、変色、しわ、虫食いの穴のある粒を手で選んで捨て、紫斑は黒い種皮では見えにくいので明るい光の下で選り分ける。50-55℃の湯に10-15分浸して消毒(60℃を超えると発芽力が損なわれる)し、接種は完全に冷ましてから行う |
| 方法 | 深さ3-5cm、条間70cm、株間20cm(5か月育って大きくなるのでダイズより広く)、丸い畝は20cm以上。播種直後に鳥が子葉を食べるので、ネットかわらで覆う |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種から発芽 | 土が完全に乾かないように |
| 生育初期(6-7月) | 自然の降水に任せ、梅雨は排水に集中(過湿が乾燥より危険) |
| 開花期から莢肥大期(8-9月) | 土が乾かないよう十分に(全生育の水の80%を使い、開花期の乾燥は花が大量に落ちる) |
| 登熟期、成熟期(10月) | 水を減らし、成熟期には止める(過湿だと莢が乾かない) |

&nbsp;&nbsp;&nbsp;ソリテは9月下旬まで莢を充実させるので秋の干ばつまで心配しなければならず、9月に雨のない年は灌水が収量を直接左右します。

| 管理 | 方法 |
|:---|:---|
| 土寄せ | 3回。本葉2-3枚で子葉が埋まる程度、4-5枚で初生葉まで、6-7枚で第1本葉節まで土を寄せ、開花10日前に終える。開花後に畑に入って土をひっくり返すと花が落ち細根が切れて収量が減る |
| 摘心 | 1回目は本葉5-7枚、開花前に茎の先の成長点を手で摘んで側枝を増やす。2回目の強摘心は、肥料が多くて腰を超えて育ち倒れそうなときだけ、根元から20-25cmを残して切る(痩せた畑の生育不良の株には行わない)。8月以降の開花期は禁止 |
| 間引き、草取り、マルチ | 本葉1-2枚で1か所2本を残す。播種後30-40日から土寄せと兼ねて浅く削る。土寄せを終えた7月以降、わら、もみ殻、落ち葉、雑草を5-10cm覆うと蒸発が半分以下になる |
| 支え綱 | 倒れたあとに起こすと根が切れるので、8月の台風の前に畑の周りに杭を打ち、腰の高さに綱を張る |

## 6. 病害虫と養分の問題
| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| 炭疽病、斑点細菌病 | 梅雨のあとの莢の時期に、茎と莢に黒い潰瘍 / 葉に角ばった褐色の斑点と黄色い縁 | 種子の選別と消毒、輪作、風通しの確保、抵抗性品種(チョンジャ5号)、ボルドー液 |
| 褐斑病、べと病、紫斑病 | 下の葉の褐色の斑点と早期落葉 / 葉の表の黄色い斑点と裏のカビ / 登熟期の種皮の紫色のまだら | 風通しの確保、株間の維持、残渣の除去、ボルドー液、種子は明るい光の下で選別 |
| 黒根腐病、菌核病 | 根が褐変して腐り、下の葉が黄色くなる / 涼しく湿っているとき、茎が軟らかくなり白い菌糸と黒い粒 | 排水の改善、畝を高くする、輪作(菌核病は4年以上、病株は土ごと掘り上げて焼く) |
| ダイズモザイク病、アブラムシ | 葉がモザイク状にまだらになり縮れる。アブラムシが媒介 | 治療不可。すぐ抜いて焼き、石けん水(水1Lに石けん5g)でアブラムシを減らす |
| カメムシ類 | 8月下旬-9月初めに莢を刺して実の入らない莢にする。怠ると収量が最大58%減る | 下記参照 |
| マメシンクイガ、ハスモンヨトウ | 幼虫が莢の中の子実を食べる / 葉と莢をむさぼり食う | 残渣の除去と被害莢の除去 / 手で取り、卵塊を葉ごと取り除く |

> **ソリテでカメムシの防除は副次的な仕事ではなく、収量を決める核心の作業です。8月下旬から9月中旬までの3週間が勝負どころです。**

&nbsp;&nbsp;&nbsp;カメムシは気温の低い早朝に莢の下をさぐって手で払い落とし、バケツで受けます(3週間、1日おきに行えば数が目に見えて減る)。畑の周りにゴマ、アワ、ソルガムを植えておびき寄せて捕ります。小面積なら開花後に防虫網をかけ(自家受粉なので結実に支障はない)、畦のマメ科の雑草を刈って中間宿主をなくします。

| 症状 | 原因と対処 |
|:---|:---|
| 葉全体が薄い黄色で株が小さい | 窒素欠乏(根粒不良がもっとも多い)。根を掘って根粒を確認し、その年は尿を10倍に薄めた液を少量与える |
| 9月に下の葉から急に黄色く落ち、粒の入りが悪い | 根粒が早く老化して登熟後半に窒素が足りなくなる、ソリテ特有の症状。翌年はリン酸と接種を強化 |
| 葉だけ濃い緑で茂り倒れる | 窒素過剰か密植。窒素を止め、強摘心、支え綱 |
| 種皮の黒が薄くまだらになる | 登熟不足か早い霜。栄養欠乏ではなく時間不足のしるしなので、翌年は播種を早める |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | トウモロコシ、ソルガム(豆が固定した窒素を分けてもらい、背丈の差で光を分ける)、マリーゴールド(センチュウを抑える)、ジャガイモ(隣の畝)、アブラナ科(ソリテの翌年に残った窒素を使う) |
| 悪い | ニンニク、タマネギの仲間(分泌物が根粒菌を抑えるという報告)、ほかのマメ科の連作(病原菌とセンチュウがたまる) |

&nbsp;&nbsp;&nbsp;ソリテは11月まで畑を空けないので、ニンニク、タマネギ、オオムギなど秋まきの作物をあとに植えられず(11月中旬に植えると根づく前に凍る)、翌年の春まで休ませる畑として計画します。トウモロコシと混ぜると、トウモロコシの日陰で小さくなり登熟が遅れるので、別にしておくほうがよいです。休作は1年以上、理想の周期は3-4年で、センチュウ、黒根腐病、炭疽病がたまります。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 葉がほとんど落ち(霜で一度に落ちる)、莢の8割以上が茶色になったとき。振ると粒がぶつかる音がし、種皮が濃い黒で、子実の水分は15%前後。葉がすべて落ちて7-14日後(中部は10月下旬-11月中旬、南部は11月上旬-下旬) |
| 要領 | 刈って畑で1、2日広げて予備乾燥(雨が降ればすぐ取り込む)。片手でつかめる太さの束にして、軒下や風通しのよい納屋に立てて吊るして乾かし(11月は日差しより風が重要)、莢がからからに乾いて振ると音がしたら脱穀 |
| 脱穀、選別 | 乾いた豆がらを麻袋に半分入れて踏むか、からざおで打ち、風のある日に箕や器から流し落として殻を飛ばし、ふるいにかける。水に浮かべて実のない豆を取り除くときは、アントシアニンが溶け出すので短く浸してすぐに干す |

> **11月の雨と雪がソリテの最後の敵です。乾いた莢が濡れて乾くことを繰り返すとはじけて粒が地面に落ちます。天気が崩れそうなときは、完熟を待たずに刈り取って取り込みます。**

| 採種 | 基準 |
|:---|:---|
| 選抜、収穫 | 病気の症状がなく、莢が多く、倒れず、登熟が早かった株をあらかじめ印をつける。莢が完全に茶色になり、種皮が濃い黒になってから別に脱穀 |
| 選別、乾燥 | 種皮の色が薄い粒、まだらの粒、しわのある粒、小さい粒を捨てる(濃くて艶のある黒と、割ったときの鮮やかな緑が良い種子の目印)。水分12-13%。種子は水に浮かべない(発芽力が落ちる) |
| 保管 | 食用とは別の密閉容器に入れて、涼しく暗い場所に置く。常温で密閉して3年、発芽率は1年後80-90%、2年後60-80%、3年後40-60%。3-4年ごとに別の地域から種子を入手して一部を混ぜる |

## 9. 貯蔵
| 段階 | 方法 |
|:---|:---|
| 乾燥 | 豆がらごと軒下で風に当てて干し、脱穀後はむしろに薄く広げて日に3-4日(冬の日差しは弱いのでダイズより1、2日余分にかかる)。水分は食用12-13%、種子12%で、塩の試験で確かめる |
| マメゾウムシ類の防除 | 完全密閉がもっとも重要。細かい木灰を豆の体積の2-5%混ぜ(食べる前にすすぐ)、珪藻土は豆1kgに1-3g、食用油2-5mLをもみ込む(種子用には使わない)。真冬に数日外に出す低温処理は、11月の収穫のあとすぐ冬が来るので有利 |
| 容器、場所 | 厚いビニールは1-2年(ネズミがかじる)、地下貯蔵穴は2-3年(水が染みると全量を失う)。15度以下、空気の湿度65%以下。アントシアニンは光で分解されるので完全に遮り(ガラス瓶は布で包む)、2か月に1回、音とにおいで点検 |

> **豆は腐って失うのではなく、虫に食われて失います。貯蔵の技術とは、すなわち虫を防ぐ技術です。**

## 10. 調理と注意事項
| 成分 | 働き | 取り除く方法 |
|:---|:---|:---|
| トリプシンインヒビター、レクチン | タンパク質の消化を妨げ、腹痛、嘔吐、下痢を起こし、レクチンは赤血球を凝集させる | 8時間浸したあと、100度で60分以上加熱 |
| サポニン、オリゴ糖 | 泡で胃腸を刺激 / おなかにガス | 泡をすくい取り、浸した最初の水を捨てる。発酵で大きく減る |

> **火の通りが不十分な豆が生豆より危険な場合があります。軽くゆでると細胞壁が壊れて吸収はよくなりますが、インヒビターとレクチンは残るからです。中途半端でやめずに、最後まで火を通します。**

&nbsp;&nbsp;&nbsp;浸漬は常温の水に8時間行い、最初の2、3時間の水にはオリゴ糖と抗栄養成分が集まっているので必ず捨て、あとの水はごはんの水やゆでる水に使ってアントシアニンを生かします。蒸す(100度の蒸気で60-90分)と色素の損失が少なく、余熱調理は15分煮てから保温箱に2-3時間置いて燃料を半分以下にします。発芽と発酵(テンジャン、しょうゆ、チョングッチャン)は、抗栄養成分をもっとも根本的に減らします。

| 加工 | 手順と値 |
|:---|:---|
| 豆の甘辛煮(コンジャバン) | 十分に浸した豆を水だけでやわらかくなるまでゆでてから、しょうゆを入れて煮詰める(最初から入れると豆が堅くなる)。甘みがあるので砂糖なしでよく、ゆで汁の色素も一緒に使う。涼しい所で2-3週間 |
| 豆ごはん、黒豆茶 | 浸した豆を米と一緒に炊く / 乾いた豆を弱火で20-30分炒っておき、水で数分煮る(炒った豆は密閉して2-3か月、飲み水の消毒も兼ねる) |
| みそ類、チョングッチャン | ヒュクテのほうが向く。メジュ(みそ玉)はゆでてつぶして発酵させ、熟成させる。チョングッチャンはゆでた豆をわらに包んで40℃前後で2-3日 |
| 豆もやし | ソモクテか小粒の豆を6-8時間浸し、水が抜ける蒸し器に入れ、20-25℃の暗所で1日3-4回水をやる。4-7日、長さ5-10cmで収穫。冬に乾燥豆にないビタミンCが得られる |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵した豆の点検、種子の発芽試験、低温処理、もやし栽培。2月に畑の計画、堆肥の切り返し、みそ仕込み |
| 3-4月 | 3月に石灰の散布と堆肥の仕上げ。4月に耕うん、畝づくり、排水溝(梅雨を考えて深く)、元肥 |
| 5-6月 | 5月に種子の選別、温湯消毒、接種用の土の確保、下旬に播種開始。6月中旬までに播種を終え、鳥よけ、間引き、1回目の土寄せ |
| 7-8月 | 7月に2、3回目の土寄せ、草取り、摘心(開花前)、マルチ。8月に開花、根粒の確認、灌水、カメムシの監視、台風の前に支え綱 |
| 9-10月 | 9月に莢肥大、集中的な灌水、カメムシの捕殺(下旬までの3週間が勝負どころ)。10月に登熟、灌水を止め、採種株に印つけ、下旬に収穫開始 |
| 11-12月 | 11月に収穫、吊るして乾燥、脱穀、選別、豆がらを切って畑に敷く(焼かない)。12月に仕上げの乾燥、貯蔵、みそ仕込み、もやし |

> **ソリテは時間を要する豆です。中部は6月中旬が播種の限界で、土寄せと摘心は開花前に終え、8月下旬からの3週間のカメムシ防除と、茎葉を畑に戻すことを守れば、味と栄養で報いてくれます。**
