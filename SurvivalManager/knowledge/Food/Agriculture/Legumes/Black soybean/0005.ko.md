## 10. 영양소 결핍과 과잉

| 증상 | 원인 | 자연 재료 조치 |
|---|---|---|
| 잎 전체가 연한 노란색이고 개체가 작다 | 질소 결핍. 서리태에서는 뿌리혹 불량이 가장 흔한 원인입니다 | 먼저 뿌리를 캐서 혹을 쪼개어 확인합니다. 혹이 없으면 이듬해 접종을 확실히 하고, 당해에는 오줌 10배 희석액을 소량 줍니다 |
| 9월에 아래 잎부터 급히 노랗게 지고 알이 덜 찬다 | 등숙 후반 질소 공급 부족 | 서리태 특유의 증상입니다. 뿌리혹이 일찍 노화한 경우가 많습니다. 이듬해 인산과 접종을 강화합니다 |
| 잎 가장자리가 갈색으로 마르고 안쪽으로 말린다 | 칼륨 결핍 | 나무재를 포기 사이에 뿌리고 가볍게 긁어 넣습니다 |
| 생육이 더디고 잎이 자줏빛을 띤다 | 인산 결핍 | 뼛가루, 생선뼈 구운 가루, 나무재 |
| 꽃이 피고도 꼬투리가 앉지 않는다 | 붕소 결핍, 또는 개화기 고온·건조 | 재료가 다양한 퇴비. 당해에는 관수와 멀칭으로 온도를 낮춥니다 |
| 잎맥은 녹색인데 잎맥 사이가 노랗다 | 철 또는 마그네슘 결핍. 알칼리로 기운 흙 | 재 사용을 멈춥니다. 부엽토와 완숙 퇴비로 유기물을 늘립니다 |
| 새 잎이 작고 기형이며 생장점이 죽는다 | 칼슘 또는 붕소 결핍 | 달걀껍질 구운 가루, 조개껍데기 가루 |
| 잎만 짙은 녹색으로 무성하고 꼬투리가 적다 | 질소 과잉 | 질소 공급을 중단합니다. 강적심으로 키를 낮춥니다 |
| 키가 웃자라 쓰러진다 | 질소 과잉 또는 밀식 | 2차 강적심, 줄 지지. 이듬해 시비량을 줄입니다 |
| 종피의 검은색이 옅고 얼룩진다 | 등숙 부족 또는 이른 서리 | 파종을 앞당깁니다. 색소는 등숙 후반에 쌓입니다 |
| 아래 잎이 노랗고 뿌리가 갈색 | 과습에 따른 뿌리 손상 | 배수로를 칩니다. 비료 문제가 아닙니다 |

&nbsp;&nbsp;&nbsp;서리태에서만 따로 보아야 할 증상이 두 가지 있습니다. 하나는 9월에 아래 잎이 급히 지는 현상입니다. 뿌리혹의 수명이 대두에 맞추어져 있어 다섯 달을 버티지 못하고 등숙 후반에 기능을 잃는 경우가 있습니다. 이때 흙에 질소가 없으면 식물은 아래 잎의 단백질을 분해해 알로 보내고, 그래서 잎이 빨리 집니다. 어느 정도는 정상적인 노화이지만, 9월 초부터 급격히 진행되면 알이 덜 차므로 문제입니다. 근본 대책은 인산을 넉넉히 넣어 뿌리혹의 에너지 대사를 뒷받침하고, 접종원을 확실히 확보하는 것입니다.

&nbsp;&nbsp;&nbsp;다른 하나는 종피의 색이 옅어지는 현상입니다. 안토시아닌은 등숙 후반에 쌓이므로, 등숙이 충분하지 않으면 검은색이 옅고 얼룩덜룩합니다. 이는 영양 결핍이 아니라 시간 부족의 신호입니다. 그해의 파종이 늦었거나 서리가 일찍 왔다는 뜻이고, 이듬해에는 파종을 앞당겨야 합니다.

&nbsp;&nbsp;&nbsp;미량 원소 결핍은 하나씩 대응하기 어렵습니다. 화학 비료 없이 몰리브덴이나 코발트를 구할 방법은 사실상 없습니다. 대신 채소 부스러기, 과일 껍질, 달걀껍질, 생선뼈, 낙엽, 잡초, 재를 함께 섞어 썩힌 퇴비에는 미량 원소가 고루 들어 있습니다. 퇴비장에 무엇이든 다 넣는다는 원칙이 실질적 전략입니다.

## 11. 사이짓기와 윤작

| 궁합 | 작물 | 이유 |
|---|---|---|
| 좋음 | 옥수수, 수수 | 콩이 고정한 질소를 곁에서 나눠 받습니다. 키 차이로 빛을 나눠 씁니다 |
| 좋음 | 메리골드(금잔화) | 뿌리 분비물이 선충을 억제합니다 |
| 좋음 | 감자 | 병해가 겹치지 않고 양분 요구가 다릅니다. 감자를 6월에 거두면 서리태 파종이 빠듯하므로 이웃 두둑에 배치합니다 |
| 좋음 | 배추·양배추 무리 | 서리태 다음 해에 심으면 남은 질소를 씁니다 |
| 나쁨 | 토마토·고추·가지 | 병해충을 공유합니다 |
| 나쁨 | 마늘·양파 무리 | 분비물이 뿌리혹박테리아를 억제한다는 보고가 있습니다 |
| 나쁨 | 다른 콩과 연작 | 병원균과 선충이 누적됩니다 |

&nbsp;&nbsp;&nbsp;서리태의 사이짓기에는 제약이 하나 있습니다. 11월까지 밭을 비우지 않는다는 점입니다. 마늘과 양파와 보리 같은 가을 파종 작물을 서리태 뒤에 심으려면 시기가 맞지 않습니다. 서리태를 거두고 나면 이미 11월 중순이고, 그때 마늘을 심으면 뿌리를 내리기 전에 땅이 얼어 겨울을 넘기지 못합니다. 그러므로 서리태밭은 이듬해 봄까지 쉬는 밭으로 계획해야 합니다. 콩대를 잘라 깔아 두면 그 기간이 헛되지 않습니다.

&nbsp;&nbsp;&nbsp;옥수수와의 섞어짓기는 서리태에서 더 신중해야 합니다. 옥수수는 8월에 거두어지지만 서리태는 그 뒤로 두 달 반을 더 자라야 합니다. 옥수수 그늘에서 여름을 보내면 서리태의 몸집이 작아지고, 옥수수를 거둔 뒤에야 빛을 온전히 받게 되므로 등숙이 늦어집니다. 40% 차광에서 두류 수량이 절반으로 떨어진다는 값을 생각하면, 서리태는 옥수수와 섞기보다 따로 두는 편이 낫습니다. 섞는다면 옥수수 두 줄에 서리태 두 줄로 넉넉히 나누고 남북 방향으로 배치합니다.

| 항목 | 기준 |
|---|---|
| 휴작 기간 | 1년 이상 |
| 이상적 주기 | 3-4년 |
| 연작 장해 | 선충, 검은뿌리썩음병, 탄저병이 누적됩니다 |

| 4년 윤작 예시 |
|---|
| 1년차: 서리태 |
| 2년차: 봄 감자 또는 봄 엽채류(서리태가 남긴 질소를 씁니다) |
| 3년차: 옥수수, 수수, 조 같은 곡물 |
| 4년차: 뿌리채소 또는 녹비 |
| 다시 서리태 |

&nbsp;&nbsp;&nbsp;밭이 좁아 윤작할 여유가 없을 때는 밭을 네 구획으로 나누어 해마다 한 칸씩 옮기는 방식이 가장 간단합니다. 구획이 나뉘지 않으면 최소한 심는 줄의 위치를 해마다 옮깁니다. 지난해 콩 줄에 올해는 옥수수를, 지난해 옥수수 줄에 올해는 콩을 심는 것만으로도 선충 누적이 상당히 늦어집니다.

## 12. 수확과 탈곡

### 12-1. 수확 시기 판단

| 판단 기준 | 내용 |
|---|---|
| 잎 | 노랗게 되어 거의 다 떨어졌습니다. 서리를 맞으면 한꺼번에 집니다 |
| 꼬투리 | 전체의 8할 이상이 갈색으로 변했습니다 |
| 소리 | 흔들면 꼬투리 안에서 알이 부딪는 소리가 납니다 |
| 알 | 깨물면 이가 들어가지 않고 톡 갈라집니다. 종피가 짙은 검은색입니다 |
| 수분 | 종실 수분 15% 내외 |
| 시점 | 잎이 다 떨어진 뒤 7-14일 |

| 지역 | 수확 시기 |
|---|---|
| 중부지방 | 10월 하순-11월 중순 |
| 남부지방 | 11월 초순-11월 하순 |

&nbsp;&nbsp;&nbsp;서리태라는 이름이 수확 시기를 말해 줍니다. 첫서리를 맞은 뒤에 거둡니다. 서리가 내리면 잎이 하루이틀 사이에 한꺼번에 지고 꼬투리만 남아 수확이 오히려 쉬워집니다. 이때 이미 알은 다 차 있으므로 서리가 해를 주지 않습니다. 다만 서리를 맞았다는 것과 등숙이 끝났다는 것은 다른 문제입니다. 꼬투리를 몇 개 열어 알이 통통하고 종피가 짙은지 확인한 뒤에 거둡니다. 알이 쭈그러들었거나 종피 색이 옅으면 등숙이 덜 끝난 것이고, 그해는 파종이 늦었다는 뜻입니다.

> **11월의 비와 눈이 서리태의 마지막 적입니다. 마른 꼬투리가 젖었다 마르기를 되풀이하면 터져서 알이 땅에 떨어집니다. 날이 궂을 조짐이 보이면 완숙을 기다리지 말고 베어 들입니다.**

### 12-2. 수확 요령

| 순서 | 내용 |
|---|---|
| 1 | 맑고 건조한 날, 이슬이 마른 오전 10시 이후에 거둡니다 |
| 2 | 낫으로 줄기 밑을 벱니다. 뿌리혹의 질소를 남기려면 뿌리는 땅에 남깁니다 |
| 3 | 밭에서 하루에서 이틀 널어 예비 건조합니다. 비가 오면 곧바로 들입니다 |
| 4 | 다발로 묶어 처마 밑이나 헛간에 세워 걸어 마무리 건조합니다 |
| 5 | 꼬투리가 바싹 마르고 흔들면 소리가 날 때 탈곡합니다 |

&nbsp;&nbsp;&nbsp;11월 수확의 어려움은 건조입니다. 날이 짧고 기온이 낮고 습도가 높아 볕에 말리는 속도가 느립니다. 그래서 밭에서 오래 널어 두기보다 다발로 묶어 처마 밑이나 바람이 통하는 헛간에 세워 걸어 두는 방식이 유리합니다. 바람이 통하는 것이 볕보다 중요합니다. 서리태를 묶을 때는 다발을 너무 굵게 하지 않습니다. 안쪽이 마르지 않아 곰팡이가 생깁니다. 한 손으로 쥘 만한 굵기로 여러 다발을 만드는 편이 낫습니다.

### 12-3. 탈곡 - 도구 없이 하는 방법

| 방법 | 도구 | 절차 | 효율 |
|---|---|---|---|
| 자루 밟기 | 두꺼운 마대 | 마른 콩대를 자루에 반쯤 채우고 입구를 묶어 발로 밟습니다. 열 번쯤 밟고 흔들어 위치를 바꾸어 되풀이합니다 | 소량에 가장 편하고 손실이 거의 없습니다 |
| 도리깨 | 긴 자루에 회초리를 매단 도구 | 멍석에 콩대를 얇게 펴고 위에서 내리칩니다. 두세 번 뒤집습니다 | 중간 규모에 적합합니다 |
| 몽둥이 두들기기 | 나무 막대 | 자루에 넣거나 멍석에 펴고 두들깁니다 | 도리깨 대신입니다 |
| 발로 비비기 | 없음 | 멍석에 펴고 신발 신은 발로 비벼 돌립니다 | 소량에 적합합니다 |
| 판자에 치기 | 널판이나 통 | 콩대 다발을 잡고 통 안쪽 벽에 때립니다 | 알이 통 안에 모여 손실이 적습니다 |

&nbsp;&nbsp;&nbsp;탈곡의 성패는 건조에 달려 있습니다. 덜 마른 콩대는 아무리 두들겨도 꼬투리가 벌어지지 않고, 지나치게 마른 콩은 알이 깨집니다. 꼬투리를 손으로 눌렀을 때 톡 벌어지는 상태가 적기이고, 겨울 햇살이 좋은 날 한낮에 하면 훨씬 수월합니다. 서리태는 알이 굵어 잘 깨지지 않는 편이지만, 도리깨로 세게 내려치면 종피가 터져 상품성과 저장성이 떨어집니다. 자루 밟기가 가장 안전합니다.

### 12-4. 정선 - 바람으로 가려내기

| 방법 | 원리 | 절차 |
|---|---|---|
| 풍선(바람 일구기) | 콩알은 무겁고 껍질과 부스러기는 가볍습니다 | 바람 부는 날 키나 그릇에 담아 높이 들고 가늘게 흘려 내립니다. 알은 바로 떨어지고 겨는 날아갑니다 |
| 키질 | 위아래로 흔들며 앞으로 까부릅니다 | 무거운 알이 뒤에 남습니다 |
| 부채질 | 한 사람이 쏟고 한 사람이 부채로 바람을 냅니다 | 바람이 없는 날에 씁니다 |
| 체 치기 | 구멍 크기로 나눕니다 | 굵은 체로 콩대 조각을, 가는 체로 흙과 작은 알을 걸러 냅니다 |
| 물에 띄우기 | 쭉정이와 벌레 먹은 알은 가볍습니다 | 물통에 쏟아 뜨는 것을 걷어 냅니다. 건진 콩은 그날 안에 다시 말립니다 |

&nbsp;&nbsp;&nbsp;풍선의 요령은 세 가지입니다. 바람이 일정하게 부는 시간과 자리를 고릅니다. 한꺼번에 쏟지 않고 가늘게 흘려 내립니다. 두세 번 되풀이합니다. 서리태는 종피가 검어 겨와 색이 구분되므로, 눈으로 확인하며 하기 쉬운 편입니다.

&nbsp;&nbsp;&nbsp;물에 띄우는 방법은 서리태에서 한 가지 주의가 필요합니다. 검은 종피의 안토시아닌이 물에 우러나 물이 붉어지고 색이 조금 빠집니다. 영양 손실이 크지는 않지만 오래 담가 두면 아깝습니다. 짧게 담가 뜨는 것만 얼른 걷어 내고 곧바로 건져 말립니다. 종자용 콩에는 이 방법을 쓰지 않습니다. 물에 담그면 발아 생리가 시작되고 그 상태로 말리면 발아력이 떨어집니다.

## 13. 채종

| 항목 | 방법 |
|---|---|
| 채종 개체 선발 | 병 증상이 없고 꼬투리가 많고 쓰러지지 않았으며 등숙이 빨랐던 포기를 밭에서 미리 표시합니다 |
| 수확 시기 | 꼬투리가 완전히 갈색으로 변하고 종피가 짙은 검은색이 된 뒤에 거둡니다 |
| 분리 | 따로 탈곡합니다. 식용과 섞이지 않게 합니다 |
| 선별 | 종피 색이 옅거나 얼룩진 알, 주름진 알, 작은 알을 버립니다 |
| 건조 | 수분 12-13%. 깨물면 톡 갈라집니다 |
| 보관 | 밀폐 용기에 담아 서늘하고 어두운 곳에. 식용과 별도 용기 |
| 보관 기간 | 상온 밀폐 3년. 발아율은 해마다 떨어집니다 |
| 갱신 | 3-4년마다 다른 지역에서 종자를 구해 일부를 섞습니다 |

&nbsp;&nbsp;&nbsp;서리태의 채종에서 특별히 눈여겨볼 형질은 등숙의 빠르기입니다. 서리태의 가장 큰 위험은 서리 전에 등숙을 끝내지 못하는 것이므로, 같은 밭에서 남보다 먼저 여문 포기의 씨를 골라 이어 가면 몇 해 뒤에는 그 지역의 서리 시기에 맞추어진 계통이 만들어집니다. 이것은 종자 회사가 하는 육종과 같은 일이고, 재난이 길어질수록 이 축적이 힘을 냅니다.

&nbsp;&nbsp;&nbsp;방법은 간단합니다. 10월 중순에 밭을 돌아보며 다른 포기보다 잎이 먼저 노랗게 지고 꼬투리가 먼저 갈색이 된 포기에 실이나 헝겊을 매어 둡니다. 동시에 꼬투리 수가 많고 쓰러지지 않은 조건도 함께 봅니다. 수확할 때 표시한 포기만 따로 거두어 따로 탈곡하고 따로 보관합니다. 해마다 이 작업을 되풀이하면 조금씩 빨라집니다.

&nbsp;&nbsp;&nbsp;선별에서는 종피 색을 기준으로 삼습니다. 색이 옅거나 얼룩진 알은 등숙이 덜 끝난 알이므로 발아력도 낮고 그 형질이 이어질 가능성도 있습니다. 짙고 윤기 있는 검은색, 속을 쪼갰을 때 선명한 초록색이 좋은 서리태 종자의 표지입니다.

| 종자 보관 기간과 발아율 |
|---|
| 수확 당년: 90% 이상 |
| 1년 경과: 80-90% |
| 2년 경과: 60-80% |
| 3년 경과: 40-60% |
| 4년 이후: 급격히 떨어집니다 |

&nbsp;&nbsp;&nbsp;자가채종을 되풀이하면 종자 전염성 병이 조용히 쌓입니다. 탄저병, 자주무늬병, 모자이크병은 종자를 따라 다음 세대로 넘어갑니다. 눈에 보이는 얼룩을 골라내면 상당 부분 막을 수 있지만, 검은 종피에서는 얼룩이 잘 보이지 않는다는 어려움이 있습니다. 밝은 빛 아래에서 보고, 그래도 불안하면 3-4년마다 이웃 마을이나 다른 골짜기에서 종자를 얻어 일부를 섞습니다.
