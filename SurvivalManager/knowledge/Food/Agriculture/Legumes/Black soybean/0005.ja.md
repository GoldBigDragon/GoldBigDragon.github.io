## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然素材での対処 |
|---|---|---|
| 葉全体が薄い黄色で個体が小さい | 窒素欠乏。ソリテ（青大豆系の黒豆）では根粒不良が最も多い原因です | まず根を掘り出し瘤を割って確認します。瘤がなければ翌年の接種を徹底し、当年は尿の10倍希釈液を少量与えます |
| 9月に下葉から急に黄変し粒の充実が悪い | 登熟後半の窒素供給不足 | ソリテに特有の症状です。根粒が早く老化している場合が多いです。翌年はリン酸と接種を強化します |
| 葉の縁が褐色に枯れて内側に巻く | カリウム欠乏 | 草木灰を株間にまき、軽くかき込みます |
| 生育が遅く葉が紫がかっている | リン酸欠乏 | 骨粉、焼いた魚の骨の粉、草木灰 |
| 花は咲くがさやが付かない | ホウ素欠乏、または開花期の高温・乾燥 | 材料が多様な堆肥。当年は灌水とマルチングで温度を下げます |
| 葉脈は緑色だが葉脈の間が黄色い | 鉄またはマグネシウム欠乏。アルカリに傾いた土 | 灰の使用をやめます。腐葉土と完熟堆肥で有機物を増やします |
| 新しい葉が小さく奇形で生長点が枯れる | カルシウムまたはホウ素欠乏 | 焼いた卵の殻の粉、貝殻の粉 |
| 葉だけが濃い緑で茂り、さやが少ない | 窒素過剰 | 窒素の供給を止めます。強摘心で草丈を低くします |
| 草丈が徒長して倒れる | 窒素過剰または密植 | 2回目の強摘心、ロープで支える。翌年は施肥量を減らします |
| 種皮の黒色が薄く斑になる | 登熟不足または早い霜 | 播種を早めます。色素は登熟後半に蓄積します |
| 下葉が黄色く根が褐色 | 過湿による根の損傷 | 排水路を作ります。肥料の問題ではありません |

&nbsp;&nbsp;&nbsp;ソリテだけで別に見ておくべき症状が2つあります。ひとつは9月に下葉が急激に落ちる現象です。根粒の寿命がダイズに合わせられているため、5か月を持ちこたえられず登熟後半に機能を失う場合があります。このとき土に窒素がないと、植物は下葉のタンパク質を分解して粒へ送るため、葉が早く落ちます。ある程度は正常な老化ですが、9月初めから急激に進むと粒の充実が悪くなるため問題です。根本的な対策は、リン酸を十分に入れて根粒のエネルギー代謝を支え、接種源を確実に確保することです。

&nbsp;&nbsp;&nbsp;もうひとつは種皮の色が薄くなる現象です。アントシアニンは登熟後半に蓄積するため、登熟が十分でないと黒色が薄く、まだらになります。これは栄養欠乏ではなく、時間不足のサインです。その年の播種が遅かったか霜が早く来たことを意味し、翌年は播種を早める必要があります。

&nbsp;&nbsp;&nbsp;微量元素の欠乏は、ひとつずつ対応するのが困難です。化学肥料なしでモリブデンやコバルトを手に入れる方法は事実上ありません。その代わり、野菜くず、果物の皮、卵の殻、魚の骨、落ち葉、雑草、灰を一緒に混ぜて腐らせた堆肥には、微量元素がまんべんなく含まれています。堆肥場には何でも入れるという原則が、実質的な戦略になります。

## 11. 間作と輪作

| 相性 | 作物 | 理由 |
|---|---|---|
| 良い | トウモロコシ、モロコシ（タカキビ） | 豆が固定した窒素をそばで分けてもらえます。草丈の違いで光を分け合います |
| 良い | マリーゴールド（キンセンカ） | 根からの分泌物がセンチュウを抑えます |
| 良い | ジャガイモ | 病害が重ならず養分要求も異なります。ジャガイモを6月に収穫するとソリテの播種が間に合わなくなるため、隣の畝に配置します |
| 良い | ハクサイ・キャベツの仲間 | ソリテの翌年に植えると残った窒素を使えます |
| 悪い | トマト・トウガラシ・ナス | 病害虫を共有します |
| 悪い | ニンニク・タマネギの仲間 | 分泌物が根粒菌を抑制するという報告があります |
| 悪い | 他の豆との連作 | 病原菌とセンチュウが蓄積します |

&nbsp;&nbsp;&nbsp;ソリテの間作にはひとつ制約があります。11月まで畑が空かないという点です。ニンニクやタマネギ、オオムギのような秋播き作物をソリテの後に植えようとしても時期が合いません。ソリテを収穫し終えるとすでに11月中旬で、そのときニンニクを植えても根を張る前に地面が凍り、冬を越せません。したがって、ソリテ畑は翌年の春まで休ませる畑として計画する必要があります。豆がらを刈ってその場に敷いておけば、その期間も無駄にはなりません。

&nbsp;&nbsp;&nbsp;トウモロコシとの混植は、ソリテではより慎重にする必要があります。トウモロコシは8月に収穫されますが、ソリテはその後さらに2か月半育たなければなりません。トウモロコシの陰で夏を過ごすとソリテの体が小さくなり、トウモロコシを収穫した後にようやく光を十分に受けられるようになるため、登熟が遅れます。40%遮光で豆類の収量が半分に落ちるという値を考えると、ソリテはトウモロコシと混ぜるよりも別に離すほうがよいでしょう。混植するなら、トウモロコシ2条にソリテ2条を余裕をもって分け、南北方向に配置します。

| 項目 | 基準 |
|---|---|
| 休作期間 | 1年以上 |
| 理想的な周期 | 3-4年 |
| 連作障害 | センチュウ、黒根腐病、炭疽病が蓄積します |

| 4年輪作の例 |
|---|
| 1年目：ソリテ |
| 2年目：春ジャガイモまたは春葉菜類（ソリテが残した窒素を使います） |
| 3年目：トウモロコシ、モロコシ（タカキビ）、アワのような穀物 |
| 4年目：根菜または緑肥 |
| 再びソリテへ |

&nbsp;&nbsp;&nbsp;畑が狭くて輪作する余裕がないときは、畑を4つの区画に分け、毎年ひとつずつずらしていく方式が最も簡単です。区画が分けられなければ、少なくとも植える条の位置を毎年変えます。去年豆を植えた条に今年はトウモロコシを、去年トウモロコシを植えた条に今年は豆を植えるだけでも、センチュウの蓄積はかなり遅くなります。

## 12. 収穫と脱穀

### 12-1. 収穫時期の判断

| 判断基準 | 内容 |
|---|---|
| 葉 | 黄色くなりほとんど落ちています。霜に当たると一斉に落ちます |
| さや | 全体の8割以上が褐色に変わっています |
| 音 | 振るとさやの中で粒がぶつかる音がします |
| 粒 | 噛むと歯が入らずぱきっと割れます。種皮は濃い黒色です |
| 水分 | 種実水分15%前後 |
| 時点 | 葉が全部落ちてから7-14日後 |

| 地域 | 収穫時期 |
|---|---|
| 韓国中部 | 10月下旬-11月中旬 |
| 韓国南部 | 11月上旬-11月下旬 |

&nbsp;&nbsp;&nbsp;ソリテという名前は「霜の豆」を意味し、その名のとおり収穫時期を物語っています。初霜を受けた後に収穫します。霜が降りると葉が一日か二日のうちに一斉に落ち、さやだけが残るのでむしろ収穫がしやすくなります。このときすでに粒は充実し終えているため、霜が害を与えることはありません。ただし、霜に当たったことと登熟が終わったことは別の問題です。さやをいくつか開いて、粒がふっくらとし種皮が濃い色かどうかを確認してから収穫します。粒がしぼんでいたり種皮の色が薄ければ登熟が終わりきっていない証拠で、その年は播種が遅かったことを意味します。

> **11月の雨と雪はソリテの最後の敵です。乾いたさやが濡れては乾くことを繰り返すと、はじけて粒が地面に落ちます。天候が荒れる兆しが見えたら、完熟を待たずに刈り取ります。**

### 12-2. 収穫のこつ

| 順序 | 内容 |
|---|---|
| 1 | 晴れて乾燥した日、露が乾いた午前10時以降に収穫します |
| 2 | 鎌で茎の根元を刈ります。根粒の窒素を残すには根は土に残します |
| 3 | 畑で1日から2日広げて予備乾燥します。雨が降ったらすぐに取り込みます |
| 4 | 束にして軒下や納屋に立てて掛け、仕上げ乾燥します |
| 5 | さやがからからに乾き、振ると音がするようになったら脱穀します |

&nbsp;&nbsp;&nbsp;11月の収穫の難しさは乾燥にあります。日が短く気温が低く湿度が高いため、天日で乾く速度が遅くなります。そのため、畑に長く広げておくより、束にして軒下や風通しのよい納屋に立てて掛けておく方式が有利です。風が通ることは日光よりも重要です。ソリテを束ねるときは、束を太くしすぎないようにします。内側が乾かずカビが生えるからです。片手で握れる程度の太さの束をいくつも作るほうがよいでしょう。

### 12-3. 脱穀 - 道具を使わない方法

| 方法 | 道具 | 手順 | 効率 |
|---|---|---|---|
| 袋踏み | 厚手の麻袋 | 乾いた豆がらを袋に半分ほど詰め、口を縛って足で踏みます。10回ほど踏んだら振って位置を変え、繰り返します | 少量に最も適しており、損失がほとんどありません |
| 殻竿（からさお） | 長い柄にしなる棒を付けた道具 | むしろに豆がらを薄く広げ、上から打ち下ろします。2、3回裏返します | 中規模に適しています |
| 棒でたたく | 木の棒 | 袋に入れるかむしろに広げてたたきます | 殻竿の代わりです |
| 足でもむ | なし | むしろに広げ、靴を履いた足でもみながら回します | 少量に適しています |
| 板に打ち付ける | 板または桶 | 豆がらの束をつかみ、桶の内壁に打ち付けます | 粒が桶の中に集まり損失が少なくなります |

&nbsp;&nbsp;&nbsp;脱穀の成否は乾燥にかかっています。乾き足りない豆がらはいくら叩いてもさやが開かず、乾きすぎた豆は粒が割れます。さやを手で押したときにぱちっと開く状態が適期で、冬の日差しのよい日の日中に行うとずっと楽になります。ソリテは粒が大きく割れにくいほうですが、殻竿で強く打ちつけると種皮がはじけて商品価値と貯蔵性が落ちます。袋踏みが最も安全です。

### 12-4. 調製 - 風で選り分ける

| 方法 | 原理 | 手順 |
|---|---|---|
| 風選（風を起こす） | 豆の粒は重く、殻やくずは軽いです | 風のある日に箕（み）や容器に入れて高く持ち上げ、細く流し落とします。粒はすぐに落ち、殻は飛ばされます |
| 箕であおる | 上下に揺らしながら手前にあおります | 重い粒が奥に残ります |
| うちわであおぐ | 一人が注ぎ、一人がうちわで風を送ります | 風のない日に使います |
| ふるいにかける | 網目の大きさで分けます | 目の粗いふるいで豆がらの破片を、目の細かいふるいで土と小さい粒をふるい分けます |
| 水に浮かせる | しいなや虫食いの粒は軽いです | 水を張った容器に入れ、浮いたものを取り除きます。すくい上げた豆はその日のうちに再び乾かします |

&nbsp;&nbsp;&nbsp;風選のこつは3つです。風が一定に吹く時間と場所を選びます。一度に注がず、細く流し落とします。2、3回繰り返します。ソリテは種皮が黒く殻と色の区別がつくため、目で確認しながら行いやすいほうです。

&nbsp;&nbsp;&nbsp;水に浮かせる方法は、ソリテでは1つ注意が必要です。黒い種皮のアントシアニンが水に溶け出し、水が赤くなって色が少し抜けます。栄養の損失は大きくありませんが、長く浸けておくのはもったいないです。短時間だけ浸けて浮いたものをさっと取り除き、すぐに引き上げて乾かします。種子用の豆にはこの方法を使いません。水に浸けると発芽生理が始まってしまい、その状態で乾かすと発芽力が落ちます。

## 13. 採種

| 項目 | 方法 |
|---|---|
| 採種個体の選抜 | 病気の症状がなく、さやが多く、倒れておらず、登熟が早かった株を畑であらかじめ印付けします |
| 収穫時期 | さやが完全に褐色に変わり、種皮が濃い黒色になってから収穫します |
| 分離 | 別に脱穀します。食用のものと混ざらないようにします |
| 選別 | 種皮の色が薄い粒、斑になった粒、しわのある粒、小さい粒を除きます |
| 乾燥 | 水分12-13%。噛むとぱきっと割れます |
| 保管 | 密閉容器に入れ、涼しく暗い場所に。食用とは別の容器で |
| 保管期間 | 常温密閉3年。発芽率は年々下がります |
| 更新 | 3-4年ごとに他の地域から種子を入手し、一部を混ぜます |

&nbsp;&nbsp;&nbsp;ソリテの採種で特に注目すべき形質は、登熟の速さです。ソリテの最大のリスクは霜が来る前に登熟を終えられないことなので、同じ畑の中で他より先に熟した株の種を選んでつないでいけば、数年後にはその地域の霜の時期に合わせた系統ができ上がります。これは種苗会社が行う育種と同じことであり、災害が長引くほどこの積み重ねが力を発揮します。

&nbsp;&nbsp;&nbsp;方法は簡単です。10月中旬に畑を見回り、他の株より先に葉が黄色くなり、さやが先に褐色になった株に糸や布切れを結んでおきます。同時に、さやの数が多く倒れていないという条件も併せて見ます。収穫のときは印を付けた株だけを別に集めて収穫し、別に脱穀し、別に保管します。毎年この作業を繰り返すと、少しずつ早くなっていきます。

&nbsp;&nbsp;&nbsp;選別では種皮の色を基準にします。色が薄い粒や斑になった粒は登熟が終わりきっていない粒であるため、発芽力も低く、その形質が受け継がれる可能性もあります。濃くつやのある黒色、割ったときの鮮やかな緑色が、良いソリテ種子の目印です。

| 種子の保管期間と発芽率 |
|---|
| 収穫当年：90%以上 |
| 1年経過：80-90% |
| 2年経過：60-80% |
| 3年経過：40-60% |
| 4年以降：急激に低下します |

&nbsp;&nbsp;&nbsp;自家採種を繰り返すと、種子伝染性の病気が静かに蓄積していきます。炭疽病、紫斑病、モザイク病は種子とともに次の世代へ受け継がれます。目に見える斑を取り除けばかなりの部分を防げますが、黒い種皮では斑が見えにくいという難しさがあります。明るい光の下で見るようにし、それでも不安であれば、3-4年ごとに近隣の村や別の谷から種子を分けてもらい、一部を混ぜます。
