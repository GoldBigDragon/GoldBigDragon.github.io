## 3. 栽培環境

### 3-1. 気温と日射量

| 条件 | 限界値 | 最適値 | 外れた場合 |
|---|---|---|---|
| 発芽温度 | 10℃以上 | 20-22℃ | 10℃以下では発芽が止まり種子が腐ります |
| 生育温度 | 15-35℃ | 20-23℃ | ダイズより涼しいほうを好みます |
| 結実温度 | 18-32℃ | 20-30℃ | 幅10℃の狭い範囲です |
| 登熟期気温 | 15℃以上 | 18-25℃ | 15℃を下回ると登熟が事実上止まります |
| 積算温度 | 2,800℃以上 | 2,800-3,200℃ | ダイズより300℃以上多く必要です |
| 霜 | 氷点下で葉と茎が枯死 | - | 熟したさやの粒は傷みません |
| 日照 | 1日6時間以上 | 1日8時間以上 | 40%遮光で収量が半分になります |
| 日長 | 短日植物 | 昼が短くなると開花 | 晩生種は日長感応がより遅く現れます |

&nbsp;&nbsp;&nbsp;積算温度が、ソリテ（青大豆系の黒豆）栽培の関門です。播種から収穫までの日平均気温の合計が2,800℃を超えて初めて、粒がきちんと充実します。ダイズが2,500℃で足りるのと比べると300℃以上を多く積む必要があり、これは栽培期間がひと月ほど長くなければならないという意味と同じです。韓国中部で5月下旬に植えて11月初めに収穫すれば、おおよそこの値が満たされます。播種が10日遅れると登熟後半が気温の低い時期にかかるため、10日ではなく半月以上の損失となって返ってきます。

> **ソリテにおいて、遅い播種の代償は遅い収穫ではなく空のさやです。遅く植えれば遅く収穫できるのではなく、収穫するものがなくなるのです。**

&nbsp;&nbsp;&nbsp;高冷地や韓国北部の山間部ではソリテ栽培が難しくなります。初霜が10月初めに来る地域では積算温度が不足するため、そうした場所では早生ダイズや他の豆類を選ぶほうが合理的です。逆に韓国南部は霜が遅く余裕があるため、6月下旬まで植えることができます。自分の地域の初霜の平均日を把握し、そこから170日をさかのぼって数えることが、播種日を決める最も確実な方法です。

### 3-2. 土壌と水

| 条件 | 限界値 | 最適値 | 備考 |
|---|---|---|---|
| 土性 | 粘土質土壌から砂質土壌まで | 保水力があり排水のよい砂壌土-壌土 | 長く立ち続けるため保水力がダイズより重要です |
| pH | 5.5-7.5 | 6.0-7.0 | 中性に近いほうが根粒に有利です |
| 有効土層深 | 30cm以上 | 50cm以上 | |
| 作期蒸発散量 | - | 約450mm | 豆類の中では中間の水準です |
| 冠水 | 2日以上冠水すると枯死 | - | 根粒が先に死にます |
| 畝の高さ | 20cm以上 | 丸畝 | 韓国の梅雨（チャンマ、6月下旬～7月）期の湿害防止が要点です |

&nbsp;&nbsp;&nbsp;ソリテの土壌条件でダイズと分かれる点は保水力です。ソリテは梅雨を過ぎ、猛暑を過ぎ、秋まで5か月以上ひとところに立ち続けます。その間に少なくとも一度は干ばつに遭う確率が高く、そのとき土が水をどれだけ保持できるかが収量を分けます。砂が多くて水がすぐに抜ける土地は頻繁に灌水しなければならず、逆に泥が多くて水がたまる土地は梅雨に根粒が死んでしまいます。水を含みつつも余らせない土、すなわち有機物が豊富な砂壌土が理想的です。完熟堆肥と腐葉土を入れることが、ソリテでは特に効果を発揮します。

&nbsp;&nbsp;&nbsp;酸度はダイズよりやや高い6.0から7.0を勧めます。根粒菌は中性に近いところで最も活発になるためであり、ソリテは根粒に頼る期間が長いためこの差が積み重なります。韓国の畑は総じて酸性に傾いているため、播種3-4週間前に苦土石灰を1,000㎡当たり200kg入れて矯正します。石灰がなければ、貝殻や卵の殻を焼いて砕いたものを使います。

## 4. 品種

| 品種 | 特徴 | 収穫量(kg/1,000㎡) | 適した状況 |
|---|---|:---:|---|
| 在来ソリテ | 伝統品種。味がよく地域に適応しています | 約160-260 | 自家採種を続けたいとき |
| チョンジャ5号 | 新品種。病害と倒伏に強く、さやが裂けにくい | 約343 | 収量と安定性を重視するとき |
| フクテ（大粒の黒豆）系統 | 粒が大きく、醤類や豆腐に適しています | 品種による | 醤を仕込むとき |
| ソモクテ（小粒の黒豆） | 粒が最も小さく、豆もやしと薬用に適しています | 少ない | 種子が不足するとき、豆もやしが必要なとき |

&nbsp;&nbsp;&nbsp;チョンジャ5号と在来ソリテの違いは、災害対策の観点から考えてみる価値があります。チョンジャ5号は収量が在来種より30-70%高く、さやが裂けにくいため収穫時の損失が少なく、倒伏と病害に強いという特徴があります。数字だけ見れば選ぶ余地がないように見えます。しかし、2つのことを合わせて見る必要があります。第一に、改良品種は多くの場合、施肥に反応するよう育種されているため、無投入条件ではその優位性が縮まります。第二に、在来種はその地域の気候と病害にすでに適応しており、種を採り続けていくことができます。

&nbsp;&nbsp;&nbsp;幸い、ソリテはどちらも自家受粉の固定種なので、種を採って植えることができます。したがって理想的な選択は、どちらか一方を選ぶことではなく、両方を分けて植えることです。チョンジャ5号で収量を確保し、在来種で地域適応性と遺伝的多様性を保全します。病気が大きく流行したり気候が外れたりする年には、両方のうちどちらかが生き残ります。ひとつの品種にすべてを賭けないことが、種子確保の基本原則です。

| 状況 | 選択 | 理由 |
|---|---|---|
| 初霜が10月中旬より早い地域 | ソリテを避けて早生ダイズ | 積算温度が不足します |
| カメムシが多い地域 | チョンジャ5号 | さやが硬く被害が少ない |
| 自家採種で長く続けたい | 在来ソリテ | 地域に適応しています |
| 醤を仕込む必要がある | フクテ | 粒が大きく収量も多い |
| 種子が不足している | ソモクテ | 同じ重さでずっと広い面積に植えられます |
| 冬野菜がない | ソモクテの一部 | 豆もやしがよく育ちます |

## 5. 畑の準備と肥料 - 根粒菌と窒素収支

### 5-1. 根粒菌 - 圧縮要約

&nbsp;&nbsp;&nbsp;ソリテの窒素供給の仕組みはダイズと同じです。根粒菌（Bradyrhizobium japonicum）が根に瘤を作り、その中のニトロゲナーゼという酵素が空気中の窒素分子（N2）の三重結合を切ってアンモニアに変えます。細菌は光合成ができないため植物から糖を受け取り、その見返りとして固定した窒素を渡します。取引関係です。酵素が酸素に非常に弱いため、瘤の内部はレグヘモグロビンという赤い色素タンパク質で満たされ、酸素を抱え込んでおきます。

| 確認手順 | 内容 |
|---|---|
| 時期 | 開花が始まる頃、播種後8-10週 |
| 方法 | 引き抜かず、スコップで土ごとすくい取り、水で土を洗い流します |
| 個数 | 株当たり20個以上、主根の上部に集まっていれば良好です |
| 色の確認 | 瘤を爪で割って内側の色を見ます |

| 割った内側の色 | 意味 | 対処 |
|---|---|---|
| 赤色またはピンク色 | 窒素を固定しています | 良好な状態です |
| 白色または薄緑色 | 瘤はできていますが固定していません | 酸度、湿害、リン酸欠乏を確認します |
| 茶色または黒色 | 老化したか死んでいます | 登熟期なら正常、開花期なら問題です |

> **根を掘り出して瘤を割り、赤色を確認するというただひとつの習慣が、窒素肥料のない世界で豆作りの成否を教えてくれる最も確実なサインです。**

### 5-2. 接種源の確保

&nbsp;&nbsp;&nbsp;市販の接種剤が入手できない条件では、接種源は土です。前年に豆を植えて根粒がよくできていた畑の表土が、そのまま生きた接種剤になります。

| 方法 | 手順 | 注意 |
|---|---|---|
| 豆を育てた畑の土をまぶす | 表土5-15cmの土をすくってきて、軽く水で湿らせた種子にまんべんなくまぶし、すぐに植えます | 日陰で作業し30分以内に植えます。日に当てて乾かすと菌が死にます |
| 播種する条に土をまく | 植える条に土をまき、一緒にすき込みます。10㎡当たりスコップ1杯 | 量は多く必要ですが菌が土全体に広がります |
| 根粒をつぶして使う | 掘り出した豆の根の瘤を集めてつぶし、水に溶かして、その水に種子を浸けてから引き上げます | その日のうちに使う必要があります |
| 根を残す | 収穫時に根を掘り上げず畑に残します | 最も手間のかからない維持方法です |
| 野生ツルマメの根 | 畦畔のツルマメの根から瘤を採取します | 同じ属なので菌が通用します |

&nbsp;&nbsp;&nbsp;ソリテで接種が特に重要な理由があります。栽培期間が5か月を超えるため、根粒が供給すべき総窒素量がダイズより多くなります。接種が不十分だと初期は持ちこたえますが、8月と9月のさや肥大期に窒素が足りなくなり、葉が早く黄色くなって粒の充実も悪くなります。登熟後半に窒素が途切れることがソリテの収量不振のよくある原因であり、その根本原因は播種時点の接種にあります。

| 接種失敗を招く条件 |
|---|
| 土壌pH 5.5以下 |
| 窒素肥料を多めに施した畑 |
| 水がたまる畑 |
| リン酸が不足した畑 |
| 接種した種子を日に当てて乾かす |
| 殺菌剤処理した種子への接種 |

### 5-3. 窒素固定の落とし穴

&nbsp;&nbsp;&nbsp;豆を植えると土が良くなるという話は、条件付きの真実です。数字で確認してみましょう。ソリテ種実のタンパク質は38%で、タンパク質を6.25で割ると窒素量が出ます。種実重量の約6%が純粋な窒素です。1,000㎡で230kgを収穫すると、その中には約14kgの窒素が含まれており、ヘクタールに換算すると140kgになります。

&nbsp;&nbsp;&nbsp;一方、根粒が固定する窒素は、条件がよいときでヘクタール当たり100-150kg、悪いときは50kgにとどまります。

| 項目 | ヘクタール当たり窒素 | 方向 |
|---|---|---|
| 根粒固定量（条件良好） | 100-150kg | 流入 |
| 根粒固定量（条件不良） | 30-60kg | 流入 |
| 種実として持ち出し | 130-145kg | 流出 |
| 茎葉に残る窒素 | 25-40kg | 畑に戻せば残り、燃やしたり運び出したりすれば流出 |
| 根と根粒に残る窒素 | 10-20kg | たいてい畑に残ります |

&nbsp;&nbsp;&nbsp;種実だけを収穫し、茎と葉を畑に戻せば、収支はほぼ均衡するか、わずかに黒字になります。しかし、豆がらを刈り取って薪にしたり、燃やしてしまったり、家畜の餌として運び出したりすると、窒素収支は確実にマイナスに転じます。ダイズの種実は重量の約6%が窒素で、トウモロコシの種実は約1.4%であるため、同じ1kgを畑の外に持ち出すとき、豆が持ち去る窒素はトウモロコシの4.5倍に達します。

> **豆が土地を生かすのは、窒素を固定するからではなく、固定した窒素の一部を茎と葉に蓄えて畑に残しておくからです。その茎と葉を運び出してしまえば、豆は土地を収奪する作物になります。**

| 原則 | 内容 |
|---|---|
| 茎葉は必ず畑へ | 豆がらと葉、さやの殻を全部畑に戻します。20-30cmに切って覆います |
| 燃やさない | 燃やすと窒素は気体になって飛び、カリウムとリン酸だけが残ります |
| 根は掘り上げない | 茎だけを刈り、根はそのままにします |
| 落ち葉をかき出さない | ソリテは霜で葉が一斉に落ちるため、その落ち葉がそのまま肥料になります |
| 燃やした場合は灰を戻す | 窒素は失いますがカリウムとリン酸は回収できます |

&nbsp;&nbsp;&nbsp;ソリテにはこの原則を守りやすい事情がひとつあります。収穫が11月であるため、畑をすぐにまた使う必要がほとんどない点です。豆がらを刈ってその場に敷いておけば、冬の間に腐って翌春にはすき込める状態になります。冬の間、土がむき出しになるのを防ぎ、表土の流出も減らします。ソリテ畑の豆がらを運び出す理由はほとんどありません。

### 5-4. 施肥量と災害時の代替肥料

| 肥料 | 1,000㎡基準 | ㎡換算 | 備考 |
|---|---|---|---|
| 窒素 | 3kg | 3g | 最小限のみ。根粒が働き出す前の初期用です |
| リン酸 | 3kg | 3g | 全量元肥。窒素固定のエネルギー代謝に必要です |
| カリウム | 3.4kg | 3.4g | 全量元肥。種実の肥大に関わります |
| 堆肥 | 1,000kg | 1kg | 完全に腐熟したもの。保水力を高めます |
| 石灰 | 200kg（酸性土） | 200g | 播種3-4週間前 |

> **窒素を余分に与えると葉ばかり茂ってさやが少なくなります。ソリテはもともと草丈が高く倒れやすい豆なので、窒素過剰の害はダイズより大きくなります。**

| 代替資源 | 供給される養分 | 使い方 | 注意 |
|---|---|---|---|
| 草木灰 | カリウム、リン酸、カルシウム | ㎡当たり100-200gをまいて混ぜます | 与えすぎるとpHが7を超え、鉄と亜鉛の吸収が妨げられます |
| 完熟堆肥 | 総合、有機物 | ㎡当たり1kg | 未熟なものは根を傷め、病気を持ち込みます |
| 薄めた尿 | 窒素、カリウム | 水で10倍に薄めて株間の土に注ぎます | 少量のみ。葉に触れないようにします |
| 骨粉・魚の骨 | リン酸、カルシウム | 焼いて砕き堆肥に混ぜます | 効果はゆっくり現れます |
| 貝殻・卵の殻 | カルシウム | 焼いて砕いてまきます | 石灰の代わりになります |
| 落ち葉の腐葉土 | 総合、有機物 | 土に混ぜ込みます | 保水力を高めます。ソリテに特に有利です |
| もみ殻・稲わら | カリウム、ケイ酸 | マルチングとして覆い、翌年すき込みます | 未熟なまますき込むと窒素を奪われます |

&nbsp;&nbsp;&nbsp;追肥は原則として必要ありませんが、ソリテは栽培期間が長いため例外が生じることがあります。開花の1-2週間後に葉全体が薄い黄色を帯び、生育が明らかに悪ければ、根粒がうまく働いていないというサインです。このときだけ少量を補います。慣行では窒素カリウム複合肥料10-20kgを使い、災害時の条件では尿を水で10倍に薄めて株間の土に注ぎます。株に直接触れると根が傷むため、20cmほど離れた場所に与えます。
