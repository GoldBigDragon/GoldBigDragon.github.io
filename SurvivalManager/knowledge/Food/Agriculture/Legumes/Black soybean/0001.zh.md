# 青仁黑豆
- 来源: 韩国农村振兴厅 农事路（Nongsaro）、韩国国家标准食品成分表、FAO ECOCROP、Wiki、Gemini、Claude、Chat-GPT
- 编者: GoldBigDragon
---
## 引言
&nbsp;&nbsp;&nbsp;青仁黑豆（韩语称seoritae，意为霜后收获的豆）与大豆（Glycine max）是同一物种，是种皮黑色、仁为绿色的黑豆系统中的晚熟种。因在初霜之后收获而得名，从10月下旬到11月中旬一直立在田里，最后才灌满籽粒。综合等级为A（48.5分，有效183种中第29名），短期B（45.5）、长期S（51.8），副食为SS（63.4分）。蛋白质密度与大豆同为SS（占热量的37.9%），耐储性也是SS，种皮中的花青素成为没有新鲜蔬菜的饮食中的抗氧化物质来源。从播种到收获要160-180天，比大豆的120-150天长一个多月，所以收获速度为D，但籽粒大、含糖多、风味更深。病虫害压力为C，比大豆的A差，不防治时感受率为47.4%（大豆23%），产量每1,000㎡ 230kg，也低于大豆的250kg。青仁黑豆要花时间，也更费人工，所以在人手不足的情况下要二选一的话，大豆是更稳妥的选择。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | A | 48.5 |
| 短期 | B | 45.5 |
| 长期 | S | 51.8 |
| 副食 | SS | 63.4 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：蛋白质密度、施肥、设施负担、耐储性。S：微量营养素、连作适应性、无合成投入产量保持率、口味、国内种植普及度、自留种。A：水消耗量、产量稳定性、种子寿命。B：防治自立度 |
| 劣势 | E：耐寒性。D：收获速度、持续性、光照、烹调·加工要求度、非食用价值。C：单位面积热量、温度幅度、病虫害压力、整地·挖掘能量 |

&nbsp;&nbsp;&nbsp;比大豆更好的项目只有水消耗量A，原因是生长后期处在蒸散量减少的9-10月。收获速度D的160-180天几乎占满中部地区的无霜期，所以很难作为大麦或大蒜之后的后茬。病虫害压力C，也是因为它在蝽象最盛的9-10月仍立在田里。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 名称 | 大小 | 仁的颜色 | 特点与用途 |
|:---|:---|:---|:---|
| 青仁黑豆 | 中大粒 | 绿 | 晚熟种。有甜味，用于做饭和酱烧黑豆 |
| 黑大豆（Heuktae） | 大粒 | 黄 | 黑豆中最大。用于酱类、豆腐、黑豆茶 |
| 鼠目太（药豆） | 小粒 | 绿或黄 | 最小，花青素密度高。药用、做豆芽 |

| 项目 | 普通大豆 | 青仁黑豆 |
|:---|:---|:---|
| 生育天数 | 120-150天 | 160-180天 |
| 适播期（中部） | 5月上旬-6月上旬 | 5月下旬-6月中旬 |
| 收获期（中部） | 10月上旬-中旬 | 10月下旬-11月中旬 |
| 生长适温、pH | 20-25℃、6.0-6.5 | 20-23℃（喜偏凉）、6.0-7.0 |
| 产量、不防治时感受率 | 250kg/1,000㎡、23% | 230kg/1,000㎡、47.4% |

&nbsp;&nbsp;&nbsp;外形和生育阶段的结构与大豆相同，开花期为播种后8-12周，鼓荚期10-14周，灌浆·成熟期14-20周。灌浆期与霜冻重叠，叶片即使遇霜枯死，已经成熟的荚果里的籽粒也不会受损，剩余的养分还会集中到籽粒里，使风味更深。

> **说青仁黑豆是耐霜的豆并不准确。它的耐寒性与大豆一样是E，种青仁黑豆的诀窍不是忍受霜冻，而是在霜来之前把灌浆做完。**

&nbsp;&nbsp;&nbsp;干豆每100g热量401-413kcal，蛋白质33.6-43.1g（标准值38.02g），脂肪16.35g，碳水化合物36.40g，钙224mg，磷629mg，铁约7mg，糖类3.28g。花青素集中在种皮，糖类比普通大豆高，煮后有甜味。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽10℃以上（最适20-22℃），生长15-35℃（最适20-23℃），灌浆期15℃以上（最适18-25℃）。需要积温2,800-3,200℃，比大豆多积累300℃以上。霜冻使叶和茎枯死 |
| 水、土壤 | 保水且排水良好的沙壤土或壤土，pH 6.0-7.0，有效土层50cm以上。生育期蒸散量约450mm。被水淹两天以上就会枯死，垄要做成20cm以上的圆垄 |

> **对青仁黑豆来说，晚播的代价不是晚收，而是空荚。晚种不是晚收获，而是没有可收获的东西。**

| 品种 | 特点 |
|:---|:---|
| 地方青仁黑豆 | 口味好，适应当地，可以继续自留种。产量160-260kg/1,000㎡ |
| 青子5号 | 抗病、抗倒伏，荚坚硬不易炸裂，蝽象危害少。产量约343kg |
| 黑大豆、鼠目太 | 黑大豆籽粒大，适合做酱类和豆腐。鼠目太籽粒最小，种子不足时同样的重量可种更大面积，也用于做豆芽 |

&nbsp;&nbsp;&nbsp;两个品种都是自花授粉的固定品种，所以理想的做法是分开种，用青子5号保证产量，用地方品种保证对当地的适应。初霜在10月初的高寒地和北部山区积温不足，要选早熟大豆，并从自己地区初霜的平均日期往前倒数170天来确定播种日。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 施肥（1,000㎡） | 氮3kg（根瘤起作用之前的初期用最小量）、磷3kg、钾3.4kg（均作基肥）、充分腐熟的堆肥1,000kg，酸性土再加石灰200kg（播种前3-4周）。多施氮则只长叶、易倒伏，危害比大豆更大 |
| 替代资源 | 骨粉和烤过的鱼骨（磷、钙）、落叶腐叶土（保水）、稻壳和稻草（未腐熟的会夺走氮） |
| 根瘤接种 | 取种过大豆的田里5-15cm深的表土，裹在用水稍微润湿的种子上，在阴凉处30分钟内播下（晒太阳会杀死菌）。野大豆根上的根瘤也可用。pH 5.5以下、氮肥过多、积水、缺磷、种子经杀菌剂处理则接种失败 |
| 根瘤检查 | 开花前后（播种后8-10周），用铁锹连土挖起洗净，剖开根瘤。每株20个以上、内部呈红色或粉红色，就是在固氮；白色或浅绿色的要检查酸度、涝害和缺磷 |

> **豆类能肥田，不是因为固氮，而是因为把固定的氮的一部分留在茎叶里，留在田里。如果把那些茎叶运走，豆就成了掠夺土地的作物。**

&nbsp;&nbsp;&nbsp;每公顷固氮100-150kg（条件差时30-60kg），而随籽粒带走130-145kg，所以把豆秸、叶和荚壳切成20-30cm还回田里，收支才能平衡。接种对生长期超过五个月的青仁黑豆尤其重要，接种不好，到鼓荚期氮不足，籽粒灌不满。

| 播种 | 标准 |
|:---|:---|
| 时期 | 中部5月下旬-6月中旬（极限6月下旬，10月下旬-11月中旬收获），南部6月上旬-下旬（极限7月上旬，11月上旬-下旬收获）。接在马铃薯或大蒜之后种太紧，过了6月下旬，只需80-90天的绿豆或豇豆更合适 |
| 种子准备 | 用手拣出并弃去有斑点、变色、皱缩、虫孔的籽粒，紫斑在黑种皮上不易看出，要在明亮的光下挑选。放在50-55℃水中浸10-15分钟消毒（超过60℃会损伤发芽力），接种要在完全冷却后进行 |
| 方法 | 深3-5cm，行距70cm，株距20cm（要长五个月、个头大，所以比大豆放宽），圆垄20cm以上。播种后鸟会啄食子叶，所以盖上网或稻草 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种至发芽 | 不要让土壤彻底干掉 |
| 生长初期（6-7月） | 靠自然降水，雨季集中做好排水（过湿比干燥更危险） |
| 开花期至鼓荚期（8-9月） | 浇足，不让土壤变干（全生育期80%的水在这个时期用掉，开花期干旱会使花大量脱落） |
| 灌浆期、成熟期（10月） | 减少水，成熟期停水（过湿则荚果不干） |

&nbsp;&nbsp;&nbsp;青仁黑豆要灌荚到9月下旬，所以连秋旱也要担心，9月无雨的年份，灌溉直接左右产量。

| 管理 | 方法 |
|:---|:---|
| 培土 | 3次。真叶2-3片时培到埋住子叶的程度，4-5片时培到初生叶，6-7片时培到第一复叶节，在开花前10天完成。开花后进田翻土，会使花脱落、须根折断而减产 |
| 摘心 | 第1次在真叶5-7片、开花前，用手摘去茎端生长点以增加侧枝。第2次重摘心只在肥料足、长得过腰而有倒伏之虞时，从基部留20-25cm剪去（贫瘠田里长势差的植株不做）。8月以后的开花期禁止 |
| 间苗、除草、覆盖 | 真叶1-2片时每穴留2株。播种后30-40天起与培土同时浅锄。7月培土结束后用稻草、稻壳、落叶、杂草盖5-10cm厚，蒸发可减少一半以上 |
| 拉绳固定 | 倒伏后再扶起会折断根，所以在8月台风来临前，沿田边打桩并在腰高处拉绳 |

## 6. 病虫害与养分问题
| 病虫害 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 炭疽病、细菌性斑点病 | 雨季过后的结荚期茎和荚上出现黑色溃疡 / 叶上出现带黄边的角状褐斑 | 选种和消毒、轮作、保证通风、抗病品种（青子5号）、波尔多液 |
| 褐斑病、霜霉病、紫斑病 | 下部叶出现褐斑并提前落叶 / 叶面出现黄斑、叶背有霉层 / 灌浆期种皮上有紫色花斑 | 保证通风、保持株距、清除残体、波尔多液、在明亮的光下精选种子 |
| 黑根腐病、菌核病 | 根变褐腐烂，下部叶发黄 / 凉爽潮湿时茎变软并出现白色菌丝和黑色菌核 | 改善排水、起高垄、轮作（菌核病4年以上，病株连土挖出烧掉） |
| 大豆花叶病、蚜虫 | 叶片呈花叶状斑驳并皱缩。由蚜虫传播 | 无法治疗。立即拔除烧掉，并用肥皂水（每1L水加肥皂5g）减少蚜虫 |
| 蝽类 | 8月下旬-9月初刺吸荚果，使其成为空荚。疏于防治则减产多达58% | 见下文 |
| 豆荚螟、斜纹夜蛾 | 幼虫啃食荚里的籽粒 / 暴食叶和荚 | 清除残体并摘除受害荚 / 徒手捉虫并连叶摘掉卵块 |

> **在青仁黑豆上，防治蝽类不是次要的事，而是决定产量的关键作业。从8月下旬到9月中旬的三周是决胜期。**

&nbsp;&nbsp;&nbsp;趁气温低的清晨翻查荚下，徒手把蝽类抖进水桶里（三周里隔天一次，数量会明显下降），并在田边种芝麻、小米、高粱诱集捕捉。小块田在开花后罩上防虫网（自花授粉，不影响结实），并割掉田埂上的豆科杂草以去除中间寄主。

| 症状 | 原因与对策 |
|:---|:---|
| 整片叶淡黄、植株矮小 | 缺氮（根瘤不良最常见）。挖出根检查根瘤，当季少量施稀释10倍的人尿 |
| 9月下部叶快速发黄脱落、籽粒灌不满 | 根瘤过早衰老，灌浆后期缺氮，是青仁黑豆特有的症状。来年加强磷肥和接种 |
| 只有叶片浓绿茂盛并倒伏 | 氮过量或密植。停氮，并重摘心、拉绳固定 |
| 种皮的黑色发淡并有斑 | 灌浆不足或霜来得早。不是营养缺乏，而是时间不足的信号，所以来年提早播种 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 玉米、高粱（分享豆固定的氮，并靠高度差分享光照）、万寿菊（抑制线虫）、马铃薯（相邻的垄）、十字花科（青仁黑豆之后的第二年利用残留的氮） |
| 差 | 大蒜、洋葱类（有报告称其分泌物抑制根瘤菌）、与其他豆科连作（病原菌和线虫积累） |

&nbsp;&nbsp;&nbsp;青仁黑豆要到11月才腾出田，所以大蒜、洋葱、大麦等秋播作物不能接在后面种（11月中旬种下会在扎根前冻死），要把这块田规划为休息到来年春天的地块。与玉米混种，会在玉米的阴影下长得瘦小、灌浆推迟，所以分开种更好。休耕为1年以上，理想周期3-4年，线虫、黑根腐病和炭疽病会积累。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 叶片几乎落光（遇霜一下子落光），80%以上的荚果变褐时。摇动时籽粒碰撞作响，种皮深黑，籽粒含水量约15%。叶落完后7-14天（中部10月下旬-11月中旬，南部11月上旬-下旬） |
| 要领 | 割下后在田里摊晾一两天预干（下雨就立刻收进来）。扎成一手能握住的粗细的捆，竖着挂在屋檐下或通风的棚里晾干（11月比起阳光，通风更重要），荚果完全干透、摇动有声时脱粒 |
| 脱粒、精选 | 把干豆秸装半袋麻袋踩踏或用连枷打，在有风的日子用簸箕或盆往下倒吹走壳，再用筛子筛。在水中捞去空瘪豆时，花青素会溶出，所以短暂浸泡后立即晾干 |

> **11月的雨和雪是青仁黑豆最后的敌人。干荚反复被淋湿又晒干，就会炸裂，籽粒掉在地上。看到天气有变的迹象，不要等到完全成熟，割下收进来。**

| 留种 | 标准 |
|:---|:---|
| 选株、收获 | 预先标记没有病症、荚多、没有倒伏、灌浆早的植株。荚果完全变褐、种皮变成深黑色后再单独脱粒 |
| 精选、干燥 | 弃去种皮颜色淡或有花斑、皱缩、个头小的籽粒（深而有光泽的黑色和切开后鲜艳的绿色是好种子的标志）。含水量12-13%。种子不要用水浮选（发芽力会下降） |
| 保存 | 装入与食用豆分开的密封容器，放在凉爽阴暗处。常温密封3年，发芽率1年后80-90%，2年后60-80%，3年后40-60%。每3-4年从其他地区引进种子混入一部分 |

## 9. 储存
| 步骤 | 方法 |
|:---|:---|
| 干燥 | 连秆在屋檐下通风晾干，脱粒后薄摊在席子上晒3-4天（冬天阳光弱，比大豆多一两天）。含水量食用12-13%、留种12%，用盐试验确认 |
| 豆象防治 | 完全密封最重要。按豆体积的2-5%混入细草木灰（吃前冲洗）、每1kg豆用1-3g硅藻土、揉入2-5mL食用油（留种用的不用）。隆冬放到室外几天的低温处理，因11月收获后马上就是冬天，所以很有利 |
| 容器、位置 | 厚塑料袋1-2年（老鼠会咬穿），地下储藏窖2-3年（进水则全部损失）。保持15度以下、空气湿度65%以下。花青素遇光会分解，所以要完全避光（玻璃瓶用布包住），每两个月凭声音和气味检查一次 |

> **豆子不是烂掉而损失，而是被虫吃掉而损失。储存的技术，就是防虫的技术。**

## 10. 烹调与注意事项
| 成分 | 作用 | 去除方法 |
|:---|:---|:---|
| 胰蛋白酶抑制剂、凝集素 | 阻碍蛋白质消化，引起腹痛、呕吐、腹泻，凝集素还会使红细胞凝集 | 浸泡8小时后在100度下加热60分钟以上 |
| 皂苷、低聚糖 | 泡沫刺激肠胃 / 肚子胀气 | 撇去泡沫，倒掉浸泡的第一遍水。发酵可大幅减少 |

> **半生不熟的豆有时比生豆更危险。稍微焯一下会使细胞壁破坏、吸收变好，但抑制剂和凝集素还在。不要半途而止，要煮透。**

&nbsp;&nbsp;&nbsp;浸泡用常温水8小时，最初两三个小时的水里集中了低聚糖和抗营养成分，必须倒掉，之后的水可当作煮饭水或煮豆水，以保住花青素。蒸（100度蒸汽60-90分钟）色素损失少，余热烹调是煮15分钟后放入保温箱2-3小时，燃料可减少一半以上。发芽和发酵（大酱、酱油、清麴酱）能最根本地减少抗营养成分。

| 加工 | 步骤与价值 |
|:---|:---|
| 酱烧黑豆（kongjaban） | 把充分泡好的豆只用水煮软后，再加酱油收汁（一开始就放，豆会变硬）。自带甜味，不放糖也行，煮豆水的色素也一并使用。凉爽处2-3周 |
| 黑豆饭、黑豆茶 | 把泡好的豆与米一起煮 / 干豆用小火炒20-30分钟备用，用水煮几分钟（炒豆密封可存2-3个月，也兼作饮用水消毒） |
| 酱类、清麴酱 | 黑大豆更合适；酱曲是煮熟捣碎发酵后再熟成。清麴酱是把煮好的豆用稻草包起来，在40℃上下放2-3天 |
| 豆芽 | 把鼠目太或小粒豆泡6-8小时，放进能漏水的蒸笼，在20-25℃的暗处每天浇水3-4次。4-7天、长5-10cm时收获。冬天能得到干豆里没有的维生素C |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存的豆、种子发芽试验、低温处理、培育豆芽。2月做田地规划、翻堆堆肥、酿酱 |
| 3-4月 | 3月撒石灰并完成堆肥。4月翻耕、起垄、开排水沟（考虑雨季，要深）、施基肥 |
| 5-6月 | 5月选种、温水消毒、备足接种用的土，下旬开始播种。6月中旬前播完，防鸟、间苗、第1次培土 |
| 7-8月 | 7月第2、3次培土、除草、摘心（开花前）、覆盖。8月开花、检查根瘤、灌溉、监视蝽类、台风前拉绳固定 |
| 9-10月 | 9月鼓荚、集中灌溉、捕杀蝽类（到下旬的三周是决胜期）。10月灌浆、停止灌溉、标记留种株，下旬开始收获 |
| 11-12月 | 11月收获、挂起晾干、脱粒、精选、把豆秸切碎铺在田里（不烧）。12月收尾晾干、储存、酿酱、豆芽 |

> **青仁黑豆是要花时间的豆。中部6月中旬是播种的极限，培土和摘心在开花前完成，守住从8月下旬起三周的蝽类防治和把茎叶还田，它就会以风味和营养回报你。**
