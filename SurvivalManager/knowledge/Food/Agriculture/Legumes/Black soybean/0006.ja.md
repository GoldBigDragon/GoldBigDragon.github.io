## 14. 毒性と抗栄養成分

&nbsp;&nbsp;&nbsp;ソリテ（青大豆系の黒豆）は一般のダイズと同じ種であるため、抗栄養成分も同じです。加熱すれば安全で、生では危険です。マメ科の種子は食べられないために化学的な防御物質を蓄えており、それらの物質が人の消化を妨げます。ほとんどは熱に弱く、十分に加熱すれば破壊されますが、問題は「十分に」という言葉の基準が思いのほか高いという点です。

### 14-1. 抗栄養成分の正体

| 成分 | 働き | 症状 | 除去方法 |
|---|---|---|---|
| トリプシンインヒビター | タンパク質分解酵素トリプシンの働きを妨げます | 腹痛、嘔吐、下痢、タンパク質利用率の低下 | 8時間浸漬後、100度で30-60分以上加熱 |
| レクチン(ヘマグルチニン) | 腸粘膜に付着して吸収を妨げ、赤血球を凝集させます | 激しい腹痛、嘔吐、下痢 | 浸漬後、100度で10-30分以上加熱 |
| フィチン酸 | 鉄、亜鉛、カルシウムと結合して吸収を妨げます | 長く食べ続けると貧血、亜鉛欠乏 | 浸漬、発芽、発酵で60-80%まで減ります |
| サポニン | 泡立って胃腸を刺激します | 多いと胃がもたれます | 煮ながら泡を取り除きます |
| オリゴ糖 | 人が消化できず腸内細菌が発酵させます | お腹にガスがたまります | 浸漬した水を捨てます。発酵で大きく減ります |

> **加熱不十分な豆が生の豆より危険な場合があります。軽く湯通しすると細胞壁が壊れて吸収はよくなりますが、インヒビターとレクチンは残ったままだからです。中途半端で止めず、最後まで加熱します。**

&nbsp;&nbsp;&nbsp;レクチンの危険性は豆の種類によって大きく異なります。ダイズとソリテのレクチンはインゲンマメ類(Phaseolus)のレクチンより毒性が弱いものです。インゲンマメは生のまま4、5粒食べただけでも数時間以内に激しい嘔吐と下痢が起こり、加熱不十分なインゲンマメによる食中毒が何度も報告されています。特にインゲンマメ類は低温で長く加熱するとかえってレクチンの活性が上がる区間があり、ぬるま湯に長時間置く調理法が最も危険です。ソリテはそこまで極端ではありませんが、原則は同じです。煮立った湯で十分な時間加熱すること、これが唯一の安全な方法です。

### 14-2. 浸漬と加熱の基準

| 処理 | 時間・温度 | 効果 |
|---|---|---|
| 浸漬 | 常温の水に8時間 | 芯まで熱が通ります。オリゴ糖とサポニンの一部が水に溶け出します |
| 浸漬した最初の水を捨てる | 必ず | オリゴ糖と抗栄養成分が溶け出しています |
| 煮る | 煮立った湯で60分以上 | トリプシンインヒビターとレクチンが不活性化されます |
| 蒸す | 100度の蒸気で60-90分 | 養分と色素の損失が煮る場合より少ないです |
| 余熱調理 | 15分煮た後、保温箱に2-3時間 | 燃料が半分以下に減ります |
| 煮え具合の確認 | 指で押すと簡単につぶれます | 硬い芯が残っていれば加熱不足です |

&nbsp;&nbsp;&nbsp;ソリテの浸漬には色素に関わる判断が一つあります。浸けた水が黒赤色ににじみ出ますが、それがアントシアニンです。この水をすべて捨てると色素も一緒に捨てることになりもったいないです。妥協点は最初の水だけ捨てて、その後の水は生かすことです。最初の2、3時間の水にはオリゴ糖と抗栄養成分が集中的に溶け出すため必ず捨て、水を替えて残りの時間浸けたあとのその水はご飯を炊く水や煮る水として使います。煮るときに出る黒赤色の水も捨てずにそのまま調理に使います。

&nbsp;&nbsp;&nbsp;蒸す方式は煮るよりも色素の保存に有利です。水に浸からないためアントシアニンが洗い流されません。燃料は少し余分にかかりますが、蒸し器やざるさえあればよく、味もより濃くなります。

### 14-3. 発芽と発酵

| 方法 | 減少する成分 | 程度 |
|---|---|---|
| 発芽(豆もやし) | フィチン酸、トリプシンインヒビター、オリゴ糖 | フィチン酸50-70%、インヒビター30-40%減少 |
| 発酵(テンジャン（韓国味噌）・醤油・チョングッチャン) | フィチン酸、トリプシンインヒビター、オリゴ糖、レクチン | ほとんどが分解され、吸収率が上がります |
| 浸漬のみ | オリゴ糖、フィチン酸の一部 | 20-30%減少 |

&nbsp;&nbsp;&nbsp;発酵は抗栄養成分の問題を最も根本的に解決する方法です。微生物がインヒビターやレクチンのようなタンパク質をアミノ酸に分解し、フィチン酸を分解する酵素を出します。しかも一度仕込んでおけばその後の調理燃料がほとんどかからないため、燃料が貴重な災害時の状況では、醤（テンジャンや醤油の類）は調理コストを前払いしておく貯蔵方式になります。

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;ソリテの貯蔵性はSSです。乾燥した種実は常温で3年もちます。しかしこれは条件が合ったときの話であり、条件が狂えばマメゾウムシ一種で貯蔵した豆すべてが殻だけの空豆に変わります。

> **豆は腐って失うのではなく、虫に食われて失います。貯蔵の技術とは、すなわち虫を防ぐ技術です。**

### 15-1. まず乾燥です

| 段階 | 方法 | 確認 |
|---|---|---|
| 予備乾燥 | 豆を茎ごと軒下に立てかけて風で乾かします | 11月は日光より風が重要です |
| 脱穀後の乾燥 | むしろに薄く広げて天日で3-4日 | 冬の日差しは弱いため、ダイズより1、2日余分にかかります |
| 目標水分 | 食用12-13%、種子用12% | 噛むと歯が立たずパチンと割れます |
| 塩試験 | 乾いた瓶に豆と炒り塩を一緒に入れて振ります | 塩が瓶の内壁に付けばさらに乾燥が必要です |
| 冷まし | 完全に冷ましてから入れます | 温かいまま密閉すると結露が生じます |

&nbsp;&nbsp;&nbsp;11月収穫の乾燥はダイズより手間がかかります。日が短く気温が低く空気が湿っているため、天日で乾かす速度が遅いのです。そこで二つの方法を活用します。一つは風です。軒下や風の通り道に薄く広げておくと、弱い日差しより効果が大きくなります。もう一つは室内の乾いた空気です。火を焚く部屋の奥や、かまどの近くに広げておけば早く乾きます。ただし熱すぎる場所に置くと種皮が割れるため、手で触れてぬるい程度の場所を選びます。

### 15-2. 貯蔵中の豆象の防除

&nbsp;&nbsp;&nbsp;マメゾウムシ(アズキゾウムシ、リョクトウゾウムシを含むCallosobruchus属の仲間)は、貯蔵豆類にとって最大の脅威です。恐ろしいのは、畑の段階ですでに始まっているという点です。畑に付いている莢に成虫が卵を産み付け、その卵が貯蔵庫の中で孵化して豆の中に食い込みます。入ってくる時点ですでに卵が付いてくる構造であり、一世代が1か月もかからないため、半年もすれば袋一つが穴だらけの殻と粉で満たされます。

| 方法 | 原理 | 適用 | 効果 |
|---|---|---|---|
| 完全密閉 | 酸素を絶って窒息させます | ガラス瓶や金属缶に満杯にして密封します | 最も確実です。3-4週間で卵と幼虫まで死にます |
| 草木灰混ぜ | 微細な粒子が外骨格のワックス層を削って脱水させます | 豆の体積の2-5%を混ぜます | 食べる前に水で洗い流します |
| 珪藻土 | 珪酸質の殻が外骨格を傷つけます | 豆1kgに1-3g | 灰より効果が高いです。乾いた状態でのみ効きます |
| 油コーティング | 油膜が産卵と孵化を妨げます | 豆1kgに食用油2-5mLを入れてもみます | 豆類に効果が高いです。種子用には使いません |
| 低温処理 | 氷点下で卵と幼虫が死にます | 真冬に数日外に出してから取り込みます | 11月収穫のため、すぐに冬が来る利点があります |
| 高温処理 | 60度で卵と幼虫が死にます | 天日に薄く広げて半日置きます | 種子用には使いません |
| 乾燥唐辛子・サンショウ・ヨモギ | 精油成分が産卵を抑制します | 層状に入れます | 補助手段です |
| 炭・炒り塩 | 湿気を吸い取ります | 布に包んで入れます | カビ予防を兼ねます |
| 灰に埋める | 密閉と物理的防除を同時に得られます | 甕に灰と豆を交互に重ねます | 伝統的に広く使われてきました |

&nbsp;&nbsp;&nbsp;最も重要なのは完全密閉です。虫も呼吸をします。密閉した容器の中で豆と虫が酸素を使うと酸素が減り二酸化炭素が増えて虫が死にます。豆は休眠状態なのでこの条件に耐えます。容器を満杯にして空間を減らすほど効果は早く現れ、大きな容器一つよりも小さな容器複数にぎっしり詰めるほうがよいです。一つの容器が傷んでも全部は失いません。

&nbsp;&nbsp;&nbsp;ソリテには低温処理に有利な事情があります。11月に収穫するため、脱穀と乾燥を終えるとすぐに真冬になります。密閉した容器を数日外に出して氷点下の気温にさらすと、卵と幼虫が死にます。再び室内に入れるときは容器を開けずに室内で半日置いて温度を合わせてから開けます。冷たい容器をすぐに開けると内側に結露が生じ、カビの元になります。

&nbsp;&nbsp;&nbsp;油コーティングは豆類の貯蔵に特によく合います。豆1kgに食用油2-3mlを入れて手でもみ、すべての豆に薄い膜ができるようにします。油膜は成虫が卵を産み付けにくくし、すでに付いた卵の気門をふさぎます。ただし油が酸化すると臭いが出るため、半年以内に食べる分にのみ使い、種子用には使いません。

### 15-3. 貯蔵容器と場所

| 容器 | 密閉 | 期間 | 備考 |
|---|:---:|---|---|
| ガラス瓶 | 非常に良い | 3年以上 | 状態を目で確認できます。光は防げません |
| 金属缶 | 非常に良い | 3年以上 | ネズミと虫を完全に防ぎます。結露に注意します |
| 甕 | 良い | 2-3年 | 温度変化が緩やかでネズミが破れません |
| 厚手のビニール | 普通 | 1-2年 | ネズミが破ります |
| 地中貯蔵穴 | 良い | 2-3年 | 水がしみ込むと全量を失います |

| 保管条件 | 目標 |
|---|---|
| 温度・湿度 | 15度以下、空気湿度65%以下 |
| 光 | 完全遮断。アントシアニンは光でゆっくり分解されます |
| 場所 | 地下か北向きの部屋、地面に触れないよう台の上 |
| 点検 | 2か月に1回 |

&nbsp;&nbsp;&nbsp;光の遮断はソリテにおいて少し重要度が高くなります。アントシアニンは光と熱でゆっくり分解されるため、透明な瓶に入れて明るい場所に置くと数か月のうちに種皮の色が薄くなります。熱量とタンパク質はそのままですが、色素の利点を失います。ガラス瓶を使うなら布で包むか暗い場所に置きます。

&nbsp;&nbsp;&nbsp;点検で最も頼りになる感覚は聴覚と嗅覚です。容器に耳を当てたときにカサカサという音がすれば虫が活動しており、じめっとした臭いがすればカビが始まっています。豆の表面に小さな丸い穴が見えれば、マメゾウムシがすでに一世代を超えた状態です。この段階であっても全量を取り出して天日で乾かし、空になった豆を取り除き、灰や油を混ぜて再び密閉すれば、残りの分を守ることができます。

## 16. 調理と加工

### 16-1. 豆もやし - 冬のビタミンC

&nbsp;&nbsp;&nbsp;乾燥した豆にはビタミンCが事実上含まれていません。ところが芽を出させると、なかったビタミンCが作られます。発芽という生理的な転換が起こることで、植物が新たに合成するためです。冬に新鮮な野菜がまったくないとき、乾燥豆ひとつかみと水と暗い場所さえあれば、3、4日で新鮮な野菜が手に入ります。畑も日差しも土も必要ありません。

&nbsp;&nbsp;&nbsp;ソリテでも豆もやしを育てられますが、粒が大きいため芽が曲がったり柔らかくなったりする傾向があります。黒豆系統の中で豆もやしに最も適しているのは、粒の小さいソモクテ（ネズミの目豆）です。ソリテを主に植えるとしても、ソモクテを一列ほど一緒に植えて豆もやし用に別に確保しておくのが、冬の野菜問題を解決する実質的な方法です。

| 順序 | 内容 | 要点 |
|---|---|---|
| 1. 豆選び | ソモクテか小粒の黒豆。割れた豆や虫食いの豆は捨てます | 割れた豆は腐って全体を傷めます |
| 2. 洗い | 何度もすすいで浮くものを取り除きます | 浮く豆はたいてい死んだ豆です |
| 3. 浸漬 | ぬるま湯に6-8時間浸します | 2倍に膨らむのが目安です |
| 4. 容器に入れる | 水はけのよい器や蒸し器に入れ、濡れた布で覆います | 水がたまると腐ります |
| 5. 遮光 | 光を完全に遮ります。20-25℃ | 光が入ると緑色になり硬くなります |
| 6. 水やり | 1日3-4回、上から十分に流しかけます | 温度調節と老廃物除去を兼ねます |
| 7. 収穫 | 4-7日、長さ5-10cm | 根が茶色くなる前に収穫します |

&nbsp;&nbsp;&nbsp;水やりが豆もやし作りのほぼすべてです。水は水分を供給し、発芽の過程で生じる熱を冷まし、たまった老廃物を洗い流します。細い根がたくさん出るのは水が足りないという合図です。蒸し器がなければ、底に穴を開けた容器、目の細かいざる、穴を開けたたらいを使います。下に水受けを置き、上を黒い布で覆えば、それが蒸し器代わりになります。必要なのは水はけの構造と遮光の二つだけです。豆もやしも生では食べず、湯通しするか炒めて食べます。残っているインヒビターのためです。

### 16-2. ソリテの調理と加工

| 加工 | 手順 | 保存 | 価値 |
|---|---|---|---|
| コンジャバン（醤油煮豆） | 戻した豆を煮て醤油と一緒に煮詰めます | 涼しい場所で2-3週間 | 甘みがあるため砂糖なしでも大丈夫です。ソリテの代表的な調理法です |
| 豆ご飯 | 戻した豆を米と一緒に炊きます | その都度 | 穀物と豆のアミノ酸が互いを補います |
| 黒豆茶 | 炒って水で煮出します | 炒った豆を密閉して2-3か月 | アントシアニンが溶け出します。燃料が少なくて済みます |
| 黒豆豆乳 | 戻した豆をすりつぶして煮て漉します | 数日 | 消化しやすいです。おからは別に使います |
| メジュ（味噌玉）・テンジャン・醤油 | 煮てつぶし発酵させたあと、塩水と一緒に熟成させます | 数年 | 色が黒いため醤の色が濃くなります。ヘクテ（大粒黒豆）のほうがより適しています |
| チョングッチャン | 煮た豆をわらに包んで40℃前後で2-3日 | 数日、乾燥させれば数か月 | 最も発酵が速い豆料理です |
| 炒り豆粉 | 炒って挽きます | 密閉2-3か月 | 水に溶けばすぐに食べられます |
| 大豆油 | 炒って挽いて圧搾します | 数か月 | 搾油率が低いです |

&nbsp;&nbsp;&nbsp;コンジャバンはソリテの性質を最もよく生かす調理法です。ソリテの糖類含量は3.28gと一般のダイズより高く、砂糖を入れなくても甘みが回ります。甘味料が失われた状況では、これは小さくない利点です。作る要領は、十分に戻した豆をまず水だけで柔らかくなるまで煮て、そのあとで醤油を入れて煮詰めることです。最初から醤油を入れると塩気のせいで豆が硬くなり、うまく煮えません。煮詰めるときに煮汁の黒赤い色素も一緒に加わるので捨てません。

&nbsp;&nbsp;&nbsp;黒豆茶は燃料対効果が良い加工品です。乾燥した豆を弱火で20分から30分炒っておけば、そのあとは水で数分煮るだけで済みます。炒る過程でトリプシンインヒビターもかなり減ります。茶を煮出したあとの豆は捨てずに食べるか家畜に与えます。水を沸かして飲まなければならない状況で、ただの白湯より味がよく色素とミネラルも一緒に摂れるため、飲み水の消毒と栄養摂取を兼ねることになります。

### 16-3. 燃料を節約する調理

| 方法 | 燃料 | 手順 |
|---|:---:|---|
| 余熱調理 | 非常に少ない | 戻した豆を15分煮た後、火を止め、わら・もみ殻の箱や布団で包んで2-3時間置きます |
| 圧力調理 | 最も少ない | 戻した豆を15-20分加圧します |
| 炒り豆粉 | ほぼ不要 | あらかじめ炒って挽いておき、水に溶いて食べます |
| 黒豆茶 | 少ない | 炒っておいた豆を水で数分煮ます |
| 発酵(醤) | 前払い | 一度仕込んでおけば、以後の燃料がかかりません |
| 豆もやし | 不要 | 発芽には熱が必要ありません |

&nbsp;&nbsp;&nbsp;余熱調理を使うときには一つ注意点があります。保温箱の中の温度は80℃前後にとどまりますが、これはレクチンとトリプシンインヒビターを完全に破壊するには不十分な場合があります。そのため、最初に煮る時間を15分以上十分に確保し、取り出したときに豆が指で簡単につぶれるか確認します。芯が残っていれば再度煮ます。

## 17. 年間作業スケジュール

| 月 | 作業 | 要点 |
|---|---|---|
| 1月 | 貯蔵豆の点検、種子発芽試験、豆もやし栽培 | 密閉容器を数日外に出して低温処理を兼ねます |
| 2月 | 畑の計画、堆肥の切り返し、醤の仕込み | 輪作の順序と古い種子の発芽率を確認します |
| 3月 | 石灰散布、堆肥の仕上げ | 播種3-4週間前に入れます |
| 4月 | 畑起こし、畝立て、排水路作り、元肥 | 梅雨を念頭に置いて排水路を深く作ります |
| 5月 | 種子選別、温水消毒、接種源の土の確保、下旬に播種開始 | 豆を育てた畑の土を前もって掘っておきます |
| 6月 | 播種完了(韓国中部は中旬まで)、鳥よけ、間引き、1回目の土寄せ | 中旬を過ぎると登熟が霜にかかります |
| 7月 | 2回目・3回目の土寄せ、除草、摘心、マルチング | 土寄せと摘心は開花前に終えます |
| 8月 | 開花、根粒の確認、灌水、カメムシの監視、支柱立て | 台風の前に紐を張っておきます |
| 9月 | 莢の肥大、集中灌水、カメムシの捕殺 | 下旬までの3週間が収量の勝負どころです |
| 10月 | 登熟、灌水中止、採種株の印付け、下旬に収穫開始 | 先に熟した株に糸を結んでおきます |
| 11月 | 収穫完了、掛け干し、脱穀、選別、茎葉の畑への還元 | 豆の茎を切って畑に敷きます。燃やしません |
| 12月 | 仕上げ乾燥、貯蔵、醤の仕込み、豆もやし | 低温処理でマメゾウムシを退治します |

### 17-1. 忘れてはならない五つのこと

| 項目 | 内容 |
|---|---|
| 播種適期 | 韓国中部では6月中旬が限界です。遅れると収穫が遅れるのではなく、収穫できるものがなくなります |
| カメムシ | 8月下旬から9月中旬までの3週間が勝負どころです。防除を怠ると半分を失います |
| 土寄せと摘心 | 必ず開花前に終えます。開花後に行うと収量を減らします |
| 茎葉 | 豆の茎と葉と根を畑に戻さなければ、豆は土地を収奪する作物になります |
| 加熱 | 8時間浸漬し、1時間以上煮ます。加熱不十分な豆はより危険な場合があります |
