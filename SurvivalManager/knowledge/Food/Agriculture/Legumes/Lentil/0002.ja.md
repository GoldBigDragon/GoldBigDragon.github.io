### 1-3. 強みをどう読むか

&nbsp;&nbsp;&nbsp;SSが付いた項目は施肥、施設負担、貯蔵性の三つで、Sはタンパク質密度、微量栄養素、水消費量、味、自家採種に、Aは耐寒性、無合成投入での収量維持率、収量安定性、種子寿命に付いています。

&nbsp;&nbsp;&nbsp;この表で最も注目すべき値は、むしろCです。調理・加工Cは豆類の中で最も高い等級です。ダイズ、ソラマメ、インゲンマメ、リョクトウ、ササゲ、ヒヨコマメがすべてDを受け、エンドウがCを受けましたが、レンズマメのCはそのエンドウよりも実際の負担が軽いのです。理由は単純です。浸漬が不要で、20-30分で煮えます。皮をむいて割った赤レンズマメなら10-15分です。

> **災害時には、燃料は食料と同じくらい早く底を突きます。毎食1時間ずつ火を焚かねばならない豆と、10分で済む豆の差は、一年分積み重なれば薪ひと山分の差になります。**

&nbsp;&nbsp;&nbsp;この差が生まれる理由はレンズマメの構造にあります。種実が扁平で薄く、厚さは2-3mmにすぎません。熱が中心まで届く距離が短いということです。豆が煮える時間を決めるのは体積ではなく厚さで、レンズマメは食用豆類すべての中で最も薄いのです。さらに種皮が薄いため、水がすぐに染み込みます。

&nbsp;&nbsp;&nbsp;水消費量Sも同じ重みで読むべきです。総蒸発散量250mmはダイズの半分以下です。生育期間が短く、葉が小さく、根が深く入るためです。水を汲んで運ぶのに人の労働がかかる条件では、この差はそのまま労働の差になります。

&nbsp;&nbsp;&nbsp;微量栄養素Sは副食等級SSの根拠です。推奨量の10%を満たす栄養素が17種に達し、特に鉄と葉酸が豊富です。肉類や乳製品が姿を消した条件下では、貧血は数か月かけて静かに訪れる脅威ですが、レンズマメは鉄が多く調理も簡単なため、実際によく食べられる食品になります。栄養表の数字よりも実際の摂取頻度が重要な状況では、この点が決定的です。

### 1-4. 弱みをどう読むか

&nbsp;&nbsp;&nbsp;Dが付いた項目は面積当たり熱量、永続性、日照反応、整地エネルギー、非食用価値の五つです。Cは病害虫圧と韓国国内での普及度に付いています。

&nbsp;&nbsp;&nbsp;面積当たり熱量Dが最も重い問題です。1㎡で548kcal、自給ラインの0.21倍です。この作物表の豆類の中ではリョクトウに次いで低い値です。収穫量自体が1,000㎡で150kgと、ダイズの250kg、ソラマメの300kgと比べれば半分の水準です。粒が小さく、一つの鞘に一、二粒しか入らず、植物体そのものが小さいためです。整地・掘削エネルギーDもここから派生します。畑を耕すのにかかったエネルギーに対して回収される熱量が3.2倍で、豆類の中で最も低い部類です。レンズマメで畑を埋めることは、熱量計算上は損失です。

&nbsp;&nbsp;&nbsp;韓国国内普及度Cも現実的な壁です。レンズマメは韓国では商業栽培がほとんどありません。これに加えて、特に注意すべき点が一つあります。市販の食用レンズマメ、特に赤レンズマメは皮をむいて割ったものなので絶対に発芽しません。褐色レンズマメであっても、流通過程で熱処理を受けていれば芽が出ません。植え付け可能な種子を別途入手する必要があり、入手できたら少量で発芽試験を先に行うべきです。

&nbsp;&nbsp;&nbsp;そして、等級表には表れない実務的な難点がもう一つあります。韓国の夏の高温と梅雨（チャンマ、6月下旬～7月）です。レンズマメは25℃を超えると開花と結実が難しくなり、登熟期に雨が続くと鞘が腐り病気が広がります。春に播くと開花期が6月の暑さにぶつかり、夏を避けて晩夏に播くと冬の寒さで登熟にかかります。韓国の気候の中でレンズマメが収まる場所は思いのほか狭いということを、あらかじめ知っておく必要があります。海抜の高い高冷地があれば、そこがレンズマメに最も適しています。

## 2. どんな植物か

### 2-1. 分類と原産地

&nbsp;&nbsp;&nbsp;レンズマメはマメ科（Fabaceae）レンズマメ属（Lens）の一年草です。系統的にはエンドウ、ソラマメ、カラスノエンドウに近縁です。この事実は実用上重要です。レンズマメと組む根粒菌はRhizobiumLeguminosarum bv. viciaeで、エンドウやソラマメ、野生のカラスノエンドウが使う菌と同じです。つまり、そのいずれかを育てた畑の土を接種源として使えるということで、ヒヨコマメが専用の菌を必要とするのと比べればずっと有利な条件です。

&nbsp;&nbsp;&nbsp;原産地は西南アジア、現在のトルコとシリア一帯です。野生祖先であるLens orientalisがその地域に自生します。冬に雨が降り夏に乾き切る地中海性気候に適応した植物なので、レンズマメは涼しい時期に育ち、暑くなる前に種をつけます。生育期間が100-110日と短いのも、夏が来る前に仕事を終えようとする戦略の結果です。

&nbsp;&nbsp;&nbsp;レンズマメは自家受粉します。花が非常に小さく、花弁が雌雄をくるんでいるため、外部からの花粉が入りにくいのです。複数の系統を並べて植えても形質が混ざらず、採った種をそのまま播けば親と同じものが出てきます。自家採種等級Sはここから来ています。種子の確保が難しい作物であるほど、この性質の価値は大きくなります。

### 2-2. 形態

| 器官 | 特徴 |
|---|---|
| 葉 | 羽状複葉です。小葉が4-7対つき、先端が短い巻きひげに変わります |
| 茎 | 細く直立し、根元近くで多く分枝します。高さ30-45cm |
| 根 | 直根が深く入り、細根に小さな根粒がつきます |
| 花 | 白色または淡紫色の蝶形花です。直径5mm前後と非常に小さいです |
| 鞘 | 扁平で短いです。種子は1-2粒しか入りません |
| 種実 | 凸型の円盤状です。厚さは2-3mmで豆類の中で最も薄いです |

> **レンズマメのあらゆる実用的な長所は、種実の薄さから生まれます。熱が中心まで届く距離が短いため早く煮え、水がすぐに染み込むため浸す必要がありません。**

&nbsp;&nbsp;&nbsp;植物全体が小さく弱々しいという点も知っておくべきです。高さは40cm前後で茎が細く、雑草が少し伸びただけで覆われてしまいます。鞘がつく位置も低く、地面から10cm以内につくものが多いため、収穫時には鎌で地面近くを刈らねばならず、雨が降ると下側の鞘が土に触れて腐ります。畝を高くすることがレンズマメで特に価値を持つ理由がこれです。

&nbsp;&nbsp;&nbsp;巻きひげはありますが短くて弱く、何かに巻きついて登るほどではありません。株どうしが巻きひげを引っかけて支え合う程度の役割しかありません。そのため、レンズマメは密に植えて互いに支え合わせるほうが、むしろ倒伏に強くなります。エンドウのように支柱を立てる必要はありません。

### 2-3. 生育段階

| 段階 | 時期 | 主要な生理 | 重要な栄養 |
|---|---|---|---|
| 発芽・幼苗期 | 播種から2週 | 発芽が早いです。4℃でもゆっくり発芽します | リン酸、少量の窒素 |
| 栄養生長期 | 2-6週 | 茎が立ち、枝を張ります | 窒素は根粒が供給 |
| 開花期 | 6-8週 | 下の節から順に小さな花が咲きます | リン酸、ホウ素 |
| 莢肥大期 | 8-10週 | 鞘が扁平に大きくなり、実が太ります | カリウム、リン酸 |
| 登熟・成熟期 | 10-14週 | 下の鞘から茶色に枯れていきます | 灌水停止 |

&nbsp;&nbsp;&nbsp;レンズマメは生育期間が短く、失敗を取り戻す時間がありません。初期に雑草に負けたり養分が不足したりすると、立て直す間もなく小さな体のまま花を咲かせて終わってしまいます。そのため、初期管理、特に最初の一か月の雑草管理が収量をほぼ決めてしまいます。

&nbsp;&nbsp;&nbsp;成熟が揃わないという点も前もって知っておくべきです。下の節の鞘が茶色に枯れる頃、上の方にはまだ緑の鞘がついています。下を基準に収穫すれば上を失い、上を待てば下が裂けて落ちてしまいます。下から三番目の鞘を振って実がぶつかる音がする時が、妥協点として知られています。

&nbsp;&nbsp;&nbsp;初期の窒素についても指摘しておくことがあります。根粒は播種直後から働くわけではありません。種子が発芽し、根が伸びて細菌が感染し、根粒ができて窒素を渡すまでに3-4週間かかります。生育期間が100日のレンズマメでは、この3週間は全体の20%に相当し、他の豆より比重が大きいのです。そのため、元肥に少量の窒素を入れることには意味があります。ただし少量でなければなりません。土に窒素が十分にあると、植物は細菌と取引する必要を感じず、根粒形成を自ら減らしてしまいます。

| タンパク質 | 22.64g | 熱量に占める割合は24.8%です |
| 脂質 | 1-2g | 非常に少ないです。貯蔵中の酸敗が遅いです |
| 炭水化物 | 60g前後 | 大部分がでん粉です |
| 食物繊維 | 10-30g | 多いです。急に多く食べるとお腹にガスがたまります |
| 糖類 | 1.56g | 豆類の中で甘みが最も少ない部類です |
| 鉄 | 7mg前後 | 植物性食品の中では高い部類です |
| カリウム | 900mg前後 | |
| マグネシウム | 100mg前後 | |
| 葉酸 | 非常に豊富 | 豆類の中でも高い部類です |

&nbsp;&nbsp;&nbsp;レンズマメのタンパク質はリジンが豊富でメチオニンがやや不足しています。穀物はちょうどその逆です。ご飯やパンと一緒に食べると互いの不足を補い合い、タンパク質利用率が目に見えて上がります。インドでご飯にダール（豆のスープ）をかけて食べる習慣、中東でパンにレンズマメのスープを添える習慣は、いずれもこの原理の上に成り立っています。

&nbsp;&nbsp;&nbsp;鉄7mgと豊富な葉酸は合わせて読むべきです。この二つは赤血球を作るのに共に使われる栄養素で、一つの食品に両方含まれている例は多くありません。ただしフィチン酸が鉄の吸収を妨げるため、浸漬して煮汁を捨てるか発芽させる処理には栄養学的な意味があります。また、鉄の吸収はビタミンCと一緒に摂ると大きく高まります。レンズマメを食べる際、酸味のあるもの、たとえば酢やキムチや乾燥果物を添えることが実質的な助けになります。

&nbsp;&nbsp;&nbsp;脂質が1-2%と非常に少ない点は貯蔵において有利です。粉にしても酸敗が遅く、ダイズやラッカセイより長く持ちます。熱量密度は低い代わりに、保管が容易な方に分類されます。
