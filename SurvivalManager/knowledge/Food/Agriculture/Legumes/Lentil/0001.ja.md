## はじめに
&nbsp;&nbsp;&nbsp;レンズマメ(Lens culinaris)は、レンズに似た凸型の円盤形の種子をもつマメ科の一年草で、西南アジアの肥沃な三日月地帯原産であり、コムギ、オオムギ、エンドウとともに最も古い栽培作物の組に入ります。最大の長所は、燃料がほとんど要らない調理です。乾燥したレンズマメは浸す必要がなく、皮をむいて割った赤レンズマメは10-15分で粥のようにほぐれるため、調理・加工Cはマメ類で最も高い値です。水の消費量もSで、蒸発散量の合計250mm、ダイズの半分以下です。総合等級はC(41.9点、有効183種中89位)で、短期D(40.5)、長期C(43.2)、副食はSS(63.4点)です。面積当たりの熱量がDで1,000㎡に150kg、1㎡当たり548kcal、自給ラインの0.21倍にすぎず、国内での栽培の普及度がCなので、一、二の道(行政区)で試験栽培されているだけです。市販の食用レンズマメは皮をむいてあるか加熱処理を経ていて発芽しないため、播ける種子を別に入手し、何年もかけて自家採種で増やすことが、この作物を計画に入れる前提です。

| 総合 | C | 41.9 |
| 短期 | D | 40.5 |
| 長期 | C | 43.2 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: 施肥、施設の負担、貯蔵性。S: タンパク質密度、微量栄養素、水の消費量、味、自家採種。A: 耐寒性、合成資材を投入しない場合の収量維持率、収量の安定性、種子の寿命。B: 収穫速度、温度幅、防除の自立度、連作への適応性 |
| 弱み | D: 面積当たりの熱量、永続性、日射、整地・掘削エネルギー、非食用の価値。C: 調理・加工の要求度、病害虫圧、国内での栽培の普及度 |

> **災害時には、燃料は食料と同じくらい早く底をつきます。毎食1時間火をたかなければならない豆と10分ですむ豆の差は、1年分を積み重ねると薪ひと山の差になります。**

&nbsp;&nbsp;&nbsp;レンズマメの子実は平たく厚さが2-3mmとマメ類で最も薄く、熱が芯まで届く距離が短く、種皮が薄いので水がすぐにしみ込みます。微量栄養素Sは副食SSの根拠で、鉄と葉酸が豊富であり、調理が簡単なので実際によく食べることになる点が大事です。面積当たりの熱量Dは整地・掘削エネルギーDにもつながり、畑をレンズマメだけで埋めるのは熱量の計算では損です。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 項目 | 内容 |
|:---|:---|
| 分類 | マメ科レンズマメ属の一年草。西南アジア(現在のトルコとシリアのあたり)原産で自家受粉 |
| 葉、茎 | 羽状複葉で小葉は4-7対、先が短い巻きひげに変わって株同士が引っかけて寄りかかる。茎は細くまっすぐで、高さ30-45cmと小さくか弱い |
| 根、花 | まっすぐな主根が深く入り、細根にアワからコメ粒ほどの小さな根粒がつく。花は白か薄紫で直径5mm前後 |
| 莢、子実 | 平たく短く粒は1-2個で、地面から10cm以内の低い所につく。子実は凸型の円盤形 |

> **レンズマメの実用上の長所はすべて、子実の薄さから生まれます。熱が芯まで届く距離が短いので早く煮え、水がすぐにしみ込むので浸す必要がありません。**

&nbsp;&nbsp;&nbsp;生育期間が100-110日と短く、失敗を取り戻す時間がなく、成熟もそろいません。乾燥した子実100g当たり熱量365kcal、タンパク質22.64g(熱量比24.8%)、脂質1-2g、食物繊維10-30g、糖類1.56g、鉄約7mg、カリウム約900mg、マグネシウム約100mgで、葉酸がたいへん豊富であり、脂質が少なくて酸化が遅いです。タンパク質はリシンが多くメチオニンがやや足りないので、反対の性質の穀物といっしょに食べると互いの足りない所を補います。酢やキムチのような酸味(ビタミンC)を添えると、鉄の吸収が大きく上がります。

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽4℃以上(最適18-22℃)。生育5-28℃(最適15-20℃)で、25℃を超えると結実が悪くなる。結実15-27℃。開花期に25℃以上が数日続くと花が落ちて莢がつかない。-5℃まで耐える |
| 水、土壌 | 水はけのよい砂壌土-壌土(粘質土と水がたまる土地は避ける)、pH5.5-8.0(最適6.0-7.5)で、中性から弱アルカリ性を好む。畝は15-20cm以上(排水とともに、泥はねで下の莢にカビがつくのを防ぐ) |

> **レンズマメを韓国の気候に置きにくい理由は、二つが重なるからです。25℃を超えると結実が崩れ、登熟期に雨が続くと病気が爆発します。韓国の夏はその両方を同時にもたらします。**

&nbsp;&nbsp;&nbsp;この制約をやわらげる作型は三つあります。高冷地の春まきは、標高400m以上で3月中旬-4月上旬に播いて6-7月に収穫し、もっとも安定します。晩夏まきは、平地で8月末-9月初めに播いて11-12月に収穫しますが、登熟期が寒さにぶつかる危険があります。南部の越冬栽培は、南部の海岸で10月中下旬に播いて翌年の5-6月に収穫し、-5℃が限界です。種子が貴重なので、最初の数年は三つの作型に少しずつ分けて植え、その土地で何が育つかを確かめます。

| 区分 | 特徴 | 調理時間 |
|:---|:---|:---|
| 茶色いレンズマメ | もっとも一般的で皮つきのまま、形が保たれる。万能で、貯蔵と種子に向く | 20-25分 |
| 緑のレンズマメ | 粒が大きく歯ごたえがしっかりしている。ナムル、和え物、炒め物 | 25-30分 |
| 赤・黄のレンズマメ | 皮をむいて割った加工形態で、ほぐれて粥やスープに使い、病人、高齢者、子どもに向く | 10-15分 |

> **赤レンズマメと黄レンズマメは品種ではなく加工形態です。皮をむいて半分に割ったものなので、決して発芽しません。市販の赤レンズマメを畑に播いても何も出てきません。**

&nbsp;&nbsp;&nbsp;備蓄するときは食べる分と播く分を分け、播く分は皮が無傷の茶色か緑のレンズマメでなければならず、それでも加熱処理や燻蒸で発芽力を失っているかもしれないので、入手したあとで必ず発芽試験をします。貯蔵は皮つきで行い、加工は食べる分だけにします。

## 4. 畑の準備と播種
| 項目 | 基準 |
|:---|:---|
| 畑づくり | 20-30cmの深さに耕し、種子が小さく土塊が大きいと発芽がそろわないので、熊手や板で表面を何度もこすって細かくならす。畝は15-20cm以上、排水溝は深さ30cm以上。酸性土(pH6.0未満)には播種の3-4週間前に苦土石灰を入れる(焼いて砕いた貝殻・卵の殻や木灰で代える) |
| 施肥(1,000㎡) | リン酸20-30kg(すべて元肥で、窒素の10倍を超える量であり、骨粉と焼いた魚の骨の粉で補う)。窒素を控えるのが技術で、多いと茎と葉だけが茂って互いに覆い、風通しが悪くなってさび病が広がり、莢が減る。木灰(㎡当たり100-150g)、尿の10倍希釈液(初期の生育不良のときにごく少量) |
| 根粒の接種 | レンズマメ、エンドウ、ソラマメ、オオカラスノエンドウを育てて根粒がよくできた畑の表土5-15cmの土を、水で軽く湿らせた種子にまぶし、すぐに播種。野生のオオカラスノエンドウの根の赤い根粒も使える。ダイズやヒヨコマメの畑の土は菌の種が違うので役に立たない |

&nbsp;&nbsp;&nbsp;レンズマメの根粒は小さいので、土を洗い落としてから明るい所で細根を調べ、ナイフの先で割ってみます。1株10個以上なら接種がうまくいっており、ほとんどなければ失敗なので、葉が黄色いときは少量の窒素を補います。1ヘクタール当たりの固定量は条件がよいと60-100kg、悪いと15-35kgで、茎葉に15-25kgが残り、レンズマメの茎葉は細くて少ないので、そのまま畑に戻しやすいです。根は掘り上げず、病気の残渣だけを焼きます。

| 播種 | 基準 |
|:---|:---|
| 種子の準備 | 発芽試験が最初: 濡れた布に20粒を包んで数日置き、芽が出た数を数える。半分以上なら使え、3、4粒なら食べたほうがよい。割れたり変色した種子(割れた粒は発芽しない)を捨て、ふるいに入れて水ですすいでほこりを洗い流す。浸種は土が乾いているときだけ12-24時間(種皮が薄く、長く浸すとやわらかくなる) |
| 方法 | 深さ2-5cm、種子の間隔8-10cm、条間30-40cm、播種量5-6kg/1,000㎡。粒が小さいので点まきより条まきが効率的で、条の中でやや密に植えて互いに寄りかからせ、地面を早く覆って雑草を抑える。種子に細かい木灰をまぶしてアリを防ぎ、条の上にわらを薄くかけて鳥を防ぐ |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 発芽期 | 種子が浅く埋まっているので、播いたあと10日ほど表層をしっとりさせておく |
| 生育初期 | 自然の降水に任せる(乾燥が根を深く伸ばす) |
| 登熟期 | 灌水を中止(過湿だと脱粒とカビ) |
| 雨が続くとき | 排水溝を掘る(下の莢が土に触れると腐る) |

> **レンズマメは背丈が40cmで茎が細く、雑草にもっとも弱いマメ類です。生育期間が短いので、一度押さえつけられると回復する時間がありません。最初の1か月の草取りが収量をほぼ決めます。**

| 管理 | 方法 |
|:---|:---|
| 草取り | 出芽後2週に1回目(雑草が糸くらいのうちに)、4-5週の2回目が最後で、開花後は畑に入らない(茎が折れる)。細根が表層にあるので、鍬を寝かせて表面1-2cmだけをかき、株の近くは手で抜く |
| マルチ、支え | わらやもみ殻を2-3cmの厚さに薄く敷くと泥はねを防いで水も節約できる(芽が突き破りにくいので発芽が終わってから覆い、梅雨には一部をはがす)。支柱は要らないが、風雨が多い場所は畑の周りにひざの高さで綱を張る |

## 6. 病害虫と養分の問題
| 病害虫 | 症状と条件 | 薬を使わない対処 |
|:---|:---|:---|
| さび病 | 葉と茎に赤褐色の粉の塊ができ、広がると葉が枯れて落ちる。多湿で風通しが悪いときに広がる最大の病害で、進行が速い | 条間を広くとって風通しを確保し、窒素を控え、病葉を取り除く。初期に数株だけに見えるなら株ごと抜いて焼く。雨のあとは畑に入らない |
| 萎凋病 | 開花期に下の葉からしおれ、株ごと枯れて死ぬ。土の中で休眠胞子として何年も生き延びる | 3年以上の輪作が唯一の対策。生き残った株から採種 |
| 灰色かび病、炭疽病 | 莢と茎に灰色のカビ(登熟期に雨が続くとき) / 葉と茎に黒い斑点(多湿) | 畝を高くする、わらマルチ、早めの収穫 / 種子の選別、輪作、風通し |
| アブラムシ、ネキリムシ | 新芽と花茎について汁を吸いウイルスを媒介する / 夜に若い茎を根元から切る | 強い水流で落とし、石けん水(水1Lに石けん5g、葉が薄いので薄めに)を使い、テントウムシを守る / 朝に切られた株の周りの土を掘って幼虫を捕る |
| レンズマメゾウムシ | 畑で莢に卵を産み、貯蔵中に子実を食い荒らす | 完全に乾かして密閉して貯蔵(9節参照) |

> **さび病はレンズマメを育てる所ならどこでも出会う病気で、抵抗性は遺伝します。病気が広がる畑で最後まで耐えた株を選んで続けることが、薬のない条件でもっとも確かな対策です。**

&nbsp;&nbsp;&nbsp;ボルドー液は水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜ、すぐに使い、さび病とカビによる病気に使います。露のある朝に葉にまく細かい灰はカビを抑え、アリを追い払います。

| 症状 | 原因と対処 |
|:---|:---|
| 葉全体が薄い黄色で株が小さい | 窒素欠乏(根粒不良がもっとも多い)。まず根を掘って根粒を確認し、根粒がなく初期なら尿の10倍希釈液をごく少量与える。播種後3-4週に畑を一度よく見る |
| 生育が遅く葉が紫色を帯びる | リン酸欠乏。骨粉、焼いた魚の骨の粉 |
| 花が咲いても莢がつかない | ホウ素欠乏、または開花期の高温。複数の材料を混ぜた堆肥、高温が原因なら翌年の播種期を調整 |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| 良い | オオムギ、コムギ、エンバク(穀物の条の間に植えるとまっすぐな茎がレンズマメの寄りかかる場所になり窒素を分け合って使い、収穫期が近いのでいっしょに刈って脱穀したあとふるいと風で選り分けられるが、40%の遮光で収量が半分になるので条を広めに取る)、ジャガイモ(病害が重ならず、レンズマメを先に収穫する)、ハクサイ・ダイコンの仲間(レンズマメが残した窒素をあとで使う) |
| 普通 | 葉菜類(初期はいっしょに育つが、レンズマメが雑草に弱く競争に負ける) |

&nbsp;&nbsp;&nbsp;連作障害は萎凋病と根腐病がたまることで、3年以上空けます。輪作の例は、1年目はレンズマメ → 2年目は穀物(オオムギ・コムギ・エンバク) → 3年目はジャガイモかサツマイモ → 4年目はハクサイ・ダイコンの仲間か緑肥 → またレンズマメです。必要な面積が小さいので、畑の隅の狭い場所を毎年移しながら使うだけでも輪作になります。

## 8. 収穫と採種
| 収穫 | 基準 |
|:---|:---|
| 時期 | 播種後100-110日、下の葉が黄色く落ちて株の3分の2が茶色になったとき。下から3番目の莢を振って粒がぶつかる音がするときが妥協点(下から上へ熟し、熟した莢は破れやすい)。雨の知らせがあれば、熟しきっていなくても収穫して日陰で乾かし切る |
| 要領 | 地面のすぐ上で茎を刈る(莢が低い位置につく)。鎌の振動だけでも粒が飛び出すので、布やむしろの上に刈った束を移して落ちる粒を受ける。刈ったらすぐに広げて干す |
| 脱穀、選別 | マメ類で脱穀がもっとも楽。目の細かい袋に入れて踏むか、むしろに広げて靴を履いた足でこすり回すか、少量なら手でもむ。細かいふるいで土とくずを除き、粒が凸型の円盤なので傾けた板の上を転がして選別する。唐箕がけは粒が小さく軽いので、ほかの豆より弱い風で細く流し落とし、2、3回行う |
| 乾燥 | 脱穀後はむしろや敷物に薄く広げて日に1-2日(粒が薄いので早く乾き、強い日差しに長く置くと割れる)。水分12%以下 |

| 採種 | 基準 |
|:---|:---|
| 選抜 | さび病の症状がなく、萎凋病が出た畑で最後まで生き残って莢が多くついた株を畑であらかじめ印をつける。25℃を超える天候でも莢をつけた株、梅雨の前に先に熟した株も選び、数年選抜すれば、その畑で耐える系統ができる。自家受粉なので隔離距離は心配しない |
| 収穫、選別 | 莢が完全に茶色になって破れる前に収穫し、別に脱穀して手でもめば粒が傷まない。割れた粒、斑点、変色、小さい粒を捨て、水分12%以下に日陰でゆっくり乾かす。発芽率は2年後70-80% |

> **レンズマメは、播ける種子を国内で再び入手するのがとても難しい作物です。市販の食用レンズマメはほとんどが発芽しません。採種は選択ではなく、この作物を育て続けるための前提条件です。**

## 9. 貯蔵
| 段階 | 方法 |
|:---|:---|
| マメゾウムシの防除 | 完全密閉がもっとも重要(酸素がなくなって虫が死ぬ)で、容器をいっぱいに満たして空間を減らし、大きな容器一つより小さな容器を何個も使う。ふるった木灰を豆の体積の2-5%混ぜ(粒が小さいので灰が均等に入り込む、食べる前にすすぐ)、油のコーティングは豆1kgに食用油3-5mL(種子用は除く) |
| 容器、点検 | 厚いビニールは1-2年もつが、ネズミがかじり破り粒が小さくてこぼれ出るので、ガラス瓶か金属缶を使う。容器に耳を当ててかさかさ音がすれば虫、かび臭いにおいはカビ。皮つきで貯蔵すれば種皮が防御膜になり、皮をむいたものは貯蔵性が落ちる |

## 10. 調理と注意事項
| 成分 | 働き | 取り除く方法 |
|:---|:---|:---|
| トリプシンインヒビター | タンパク質分解酵素を妨げ、腹部の不快感とタンパク質の利用率の低下 | 沸騰した湯で20-30分で十分(含量はダイズの3分の1以下) |
| レクチン | 腸の粘膜に付着して吸収を妨げるが、少量は無害 | 加熱で簡単に壊れ、インゲンマメ類と違って毒性はとても弱い |
| オリゴ糖、タンニン | 腸内発酵でガスがたまる(マメ類の中で含量が少ない) / 種皮の渋い成分で鉄の吸収を妨げる | ゆで汁を捨てる / 皮をむくとほぼなくなる |

> **レンズマメで実際に人を害するのは、豆そのものではなく、誤って貯蔵してカビが生えた豆です。かび臭いにおいがしたり、表面に青みがかった粉が見えたりしたら、惜しまずに捨てます。**

| 処理 | 基準 |
|:---|:---|
| 基本 | 調理前に水ですすいで浮くものを取り除く。浸す必要はなく(厚さが2-3mmなのですぐに水がしみる)、皮つきは沸騰した湯で20-30分で形を保ったままやわらかくなり、皮をむいて割ったものは10-15分でほぐれて粥になる |
| 燃料の節約 | 米といっしょにごはんや粥に入れれば別の火は要らない(皮をむいたものは米より早く煮えるので、あとで入れるほど)。余熱調理は5分煮たあと火を消し、布団やわらの箱で包んで1時間置く(強い毒性の成分がないので安全)。炒ってひいた粉は水に溶いて飲む |
| 皮をむいて割る | 乾燥したレンズマメを水に軽く浸して臼でごく軽くつき、皮だけをむき(粒は砕かない)、箕で煽って飛ばし、半分に割ると、調理時間が20分から10分に縮むが、貯蔵性が落ちるので1、2か月で食べる分だけにする |
| 発芽、加工 | 8時間浸して水を切り、濡れた布で覆って2-3日置くと芽が出て、ビタミンCができ、フィチン酸が減って消化しやすくなる(ごく軽くゆでてもよい)。炒ってひいたレンズマメの粉は密閉で3-6か月。すりつぶして一晩置いて発酵させた生地は、ふくらんで消化しやすい |

> **レンズマメの価値は、ごはんを炊くときに米といっしょに入れれば、別に火をたかなくてもタンパク質が食卓に上ることにあります。ほかのどの豆もこうはできません。**

&nbsp;&nbsp;&nbsp;レンズマメはオリゴ糖が少なくおなかにガスがたまりにくく、皮をむいた赤レンズマメは特に負担が少ないので、長く飢えた人、病人、高齢者、子どもに豆を食べさせなければならないとき、レンズマメの粥がもっとも安全な選択です。

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵の点検、種子の発芽試験。2月に畑の計画、石灰の散布、堆肥の切り返し、高冷地の春まきの準備 |
| 3-4月 | 3月に高冷地の春まき(中旬から)、土を細かくならす。4月に1回目の草取り、間引き(最初の1か月の雑草管理が収量を決める) |
| 5-6月 | 5月に2回目の草取り、開花、根粒の確認。6月に莢肥大、さび病の監視、灌水(風通しを確保し、雨のあとは畑に入らない) |
| 7-8月 | 7月に高冷地の収穫、吊るして乾燥、脱穀。8月に選別、貯蔵、月末に晩夏まき(平地) |
| 9-10月 | 9月に晩夏まき分の草取り、畑の整理。10月に晩夏まき分の開花と莢肥大、南部の越冬まき |
| 11-12月 | 11月に晩夏まき分の収穫(霜が強まれば熟しきっていなくても収穫)、乾燥、貯蔵。12月に加工(1、2か月で食べる分だけ)、発芽野菜、翌年の計画 |

> **レンズマメは、播ける種子を確保して発芽試験をし、三つの作型に分けて植え、最初の1か月は草取りをし、下から3番目の莢が音を立てるときに収穫すれば、ごはんに入れるだけで別の火なしにタンパク質を出してくれる作物です。**
