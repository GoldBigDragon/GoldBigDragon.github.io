## 8. 栽培管理

### 8-1. 雑草管理がほぼすべてです

| 時期 | 作業 | 要点 |
|---|---|---|
| 出芽後2週 | 1回目の除草 | 雑草が糸のように細いうちに抜きます |
| 出芽後4-5週 | 2回目の除草 | この時点が最後です |
| 開花以降 | 畑に入りません | 茎が細く踏むと折れます |

> **レンズマメは高さ40cmで茎が細く、雑草に最も弱い豆類です。生育期間が短いため、一度負けると回復する時間がありません。最初の一か月の除草が収量をほぼ決定します。**

&nbsp;&nbsp;&nbsp;除草のコツは浅く、そして早くです。レンズマメの細根は表層に浅く広がっているため、鍬を深く入れると根が切れます。鍬を横に寝かせて土の表面1-2cmだけを削るように雑草を取り、株の近くは手で抜きます。そして雑草が目立つほど育ってから抜くのでは、もう遅いです。抜くときにレンズマメの根まで一緒に抜けてしまうからです。

&nbsp;&nbsp;&nbsp;密に播いて地面を早く覆うことも雑草対策になります。レンズマメの株が互いに触れ合って地面を覆えば、その後は雑草が大きく増えません。播種密度をやや高めに設定する理由の一つがこれです。藁マルチングも役立ちますが、種子が小さく芽が藁を突き破りにくいため、発芽が終わった後にかぶせます。

### 8-2. 倒伏管理

| 原因 | 対応 |
|---|---|
| 窒素過多 | 施肥量を守ります。これが根本です |
| 疎植しすぎる | 密に植えて互いに支え合わせます |
| 風雨 | 畑の周りに膝の高さで縄を張ります |
| 鞘の重さ | 登熟期が近ければやむを得ません。早期収穫を検討します |

&nbsp;&nbsp;&nbsp;レンズマメには支柱は必要ありません。丈が低く、株どうしが巻きひげを掛け合って支え合うからです。ただし倒れると下側の鞘が土に触れて腐り、収穫が難しくなるため、風雨が多い場所なら畑の周りに支柱を打ち、膝の高さで縄を一重に張っておくべきです。すでに倒れてしまった場合は無理に立てようとせず、木の枝を差し込んで地面から少し浮かせる方がよいです。

## 9. 病害虫

&nbsp;&nbsp;&nbsp;レンズマメの病害虫圧はCです。実際の被害はカビ病二種、さび病と萎凋病に集中しており、残りは相対的に軽いです。レンズマメが湿った条件に置かれると、この二つの病気が同時に来て、乾いた条件ではおおむね穏やかです。

### 9-1. 主な病害

| 病名 | 症状 | 発生条件 | 薬を使わない対応 |
|---|---|---|---|
| さび病 | 葉と茎に赤褐色の粉状の塊ができ、広がると葉が枯れて落ちます | 湿気が多く通風が悪いとき。レンズマメ最大の病害 | 通風確保、病葉除去、抵抗性個体の選抜。残渣を焼きます |
| 萎凋病 | 開花期に下葉から萎れ、株全体が枯れ死にます | 土壌伝染。土の中で数年生存します | 3年以上の輪作が唯一の対策です。生き残った個体から採種 |
| 根腐病 | 茎の根元と根が茶色く柔らかくなります | 過湿 | 排水、畝を高くする |
| 灰色かび病 | 鞘と茎に灰色のカビが覆います | 登熟期に雨が続くとき | 畝を高くする、藁マルチングで土が跳ねないようにする、早期収穫 |
| 炭疽病 | 葉と茎に黒い斑点ができます | 多湿 | 種子選別、輪作、通風 |

> **さび病はレンズマメを育てる場所ならどこでも出会う病気で、抵抗性は遺伝します。病気が発生した畑で最後まで持ちこたえた株を選んで種を継いでいくことが、薬のない条件下で最も確実な対策です。**

&nbsp;&nbsp;&nbsp;さび病の進行は速いです。葉に赤褐色の粉が少し見える段階から、数日で畑全体が錆びた色に変わることがあります。一度広がると元に戻す方法がないため、予防がすべてです。条間を十分に取って通風を確保し、窒素を控えて茂りすぎないようにし、雨の後は畑に入りません。初期に数株だけに見られるなら、その株を根こそぎ抜いて焼き、拡散を遅らせます。

&nbsp;&nbsp;&nbsp;萎凋病は性質が異なります。土の中に休眠胞子として残り、何年も持続してから、レンズマメが再び植えられると目覚めます。薬もなく、洗い流す方法もありません。3年以上の輪作が唯一の対策で、その畑で最後まで生き残って種をつけた個体を選んで継いでいくことが第二の対策です。

### 9-2. 主な害虫

| 害虫 | 被害 | 薬を使わない防除 |
|---|---|---|
| アブラムシ | 新芽や花茎に付いて汁を吸い、ウイルスを媒介します | 水を勢いよくかけて落とします。石けん水（水1Lに石けん5g）。テントウムシを保護します |
| レンズマメゾウムシ | 畑で鞘に卵を産み、貯蔵中に種実を食い荒らします | 完全乾燥後の密閉貯蔵が鍵です。15節参照 |
| ヨトウガ | 夜に幼い茎を根元から切ってしまいます | 朝、切られた株の周りの土を掘ると幼虫がいます |
| アリ | 播いた種子を持ち去ります | 種子に草木灰をまぶします |
| 鳥 | 幼い芽や登熟期の実を食べます | 発芽までは藁や網で覆います |

&nbsp;&nbsp;&nbsp;レンズマメは植物体が小さく葉が薄いため、害虫が付くと被害の割合が大きくなります。ダイズの一株で葉数枚を失うことと、レンズマメの一株で同じ面積を失うことは意味が違います。ただし生育期間が短いため、害虫の個体数が大きく増える前に収穫が終わる場合が多く、これがレンズマメの実質的な防御になっています。

### 9-3. 薬を使わない防除資材

| 資材 | 作り方 | 対象 | 注意 |
|---|---|---|---|
| ボルドー液 | 水100Lに硫酸銅400gと生石灰400gをそれぞれ溶かして混ぜます | さび病、カビ病 | 銅がなければ作れません。混ぜたらすぐに使います |
| 石けん水 | 水1Lに無香料石けん5g | アブラムシ、ハダニ | 葉が薄いため濃く使うと傷みます。薄めて使います |
| 水を勢いよくかける | そのまま | アブラムシ | レンズマメで最も手軽な方法です |
| 乾いた灰をまく | 露のある朝に葉へ細かい灰をまきます | カビ抑制、アリ忌避 | 雨が降ると洗い流されます |
| 草木灰の水 | 灰1升を水10Lに一晩浸し、上澄みを使います | カビ抑制 | アルカリ性なので薄めて使います |
| 木酢液 | 炭を焼くときに出る液を300-500倍に希釈します | 忌避、生育促進 | 原液は強酸性なので必ず希釈します |

### 9-4. 耕種的防除

| 方法 | 原理 |
|---|---|
| 通風確保 | さび病は葉が濡れている時間が長いほど悪化します。条間を十分に取ります |
| 窒素の節制 | 茂りすぎると内部が湿り、さび病が爆発的に広がります |
| 3年以上の輪作 | 萎凋病の胞子が土の中で減るのを待ちます |
| 藁マルチング | 雨粒で土が跳ねて下側の鞘にカビが付くのを防ぎます |
| 排水 | レンズマメの病害の大部分は過湿に関係します |
| 種子選別 | 炭疽病などが種子伝染します |
| 雨後の畑への立ち入り禁止 | 濡れた葉に人が触れると胞子が移ります |
| 残渣処理 | 病気の残渣だけを焼き、健全なものは畑に戻します |
| 生き残った個体からの採種 | さび病と萎凋病への抵抗性は遺伝します |

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然材料での対応 |
|---|---|---|
| 葉全体が薄い黄色で、株が小さい | 窒素欠乏。レンズマメでは根粒不良が最も多い原因です | まず根を掘って根粒を確認します。根粒がなく初期であれば、尿の10倍希釈液をごく少量与えます |
| 葉の縁が茶色く枯れる | カリウム欠乏 | 草木灰を株間にまき、軽くすき込みます |
| 生育が遅く葉が紫色を帯びる | リン酸欠乏。レンズマメはリン酸要求が高いです | 骨粉、魚の骨を焼いた粉 |
| 花は咲くが鞘がつかない | ホウ素欠乏、または開花期の高温 | 複数の材料を混ぜた堆肥。高温が原因なら翌年は播種期を調整します |
| 葉脈の間が黄色い | 鉄またはマンガン欠乏。アルカリに傾いた土でよく見られます | 灰の使用をやめます。腐葉土と完熟堆肥で有機物を増やします |
| 茎と葉ばかり茂り鞘が少ない | 窒素過剰 | 窒素の供給を直ちに中止します |
| 生育が全体的に不良 | 強い酸性土壌 | 石灰または焼いた貝殻の粉 |

&nbsp;&nbsp;&nbsp;レンズマメでは欠乏を発見する時点が重要です。生育期間がわずか100日しかなく、開花が始まった後に気づいても、何をしてもその年には役立ちません。播種後3週から4週の間に畑を一度じっくり観察し、葉の色と大きさを確認する習慣が実質的です。その時に生育不良なら少量の窒素で初期を乗り切らせ、正常ならその後は手を加えません。

&nbsp;&nbsp;&nbsp;微量元素欠乏は一つずつ対応するのが難しいです。化学肥料なしでモリブデンやコバルトを得る方法は事実上ありません。代わりに、野菜くず、果物の皮、卵の殻、魚の骨、落ち葉、雑草、灰を一緒に混ぜて腐熟させた堆肥には微量元素がまんべんなく含まれています。堆肥場には何でも入れるという原則が、微量元素管理の実質的な戦略です。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 作物 | 理由 |
|---|---|---|
| 良い | オオムギ・コムギ・エンバク | 穀物の条間に植えると互いの支えになり、窒素を分け合います |
| 良い | ジャガイモ | 病害が重ならず、レンズマメを先に収穫します |
| 良い | ハクサイ・ダイコン類 | レンズマメが残した窒素を後で使います |
| 良い | マリーゴールド | 根の分泌物が線虫を抑制します |
| 普通 | 葉物野菜 | 初期は一緒に育ちますが、レンズマメは雑草に弱く競争に負けます |
| 悪い | ニンニク・タマネギ類 | 分泌物が根粒菌を抑制するという報告があります |
| 悪い | 他のマメ科 | 病原菌と線虫が蓄積します |

&nbsp;&nbsp;&nbsp;レンズマメと穀物の混作は、原産地で長く使われてきた方式です。オオムギやコムギの条間にレンズマメを植えると、穀物の直立した茎がレンズマメの支えになり、レンズマメが固定した窒素の一部が穀物に流れます。さらに両作物の収穫期が近いため、一度に刈って一緒に脱穀した後、ふるいと風で分けることができます。レンズマメは穀物よりずっと小さく重いため、選別が簡単です。ただしレンズマメは40%遮光で収量が半分に落ちるため、穀物の陰に深く入らないよう条間を十分に空ける必要があります。

### 11-2. 輪作

| 項目 | 基準 |
|---|---|
| 休作期間 | 3年以上。萎凋病が土に残ります |
| 理想的な周期 | 4年 |
| 連作障害 | 萎凋病と根腐病が蓄積します |

| 4年輪作の例 |
|---|
| 1年目：レンズマメ |
| 2年目：穀物（オオムギ・コムギ・エンバク） |
| 3年目：ジャガイモまたはサツマイモ |
| 4年目：ハクサイ・ダイコン類または緑肥 |
| 再びレンズマメ |

&nbsp;&nbsp;&nbsp;畑が狭く輪作の余裕がないときの妥協策を記しておきます。レンズマメは植物が小さいため必要な面積も小さいです。畑の片隅の狭い場所を毎年移しながら使うだけでも輪作になります。種を継いでいくことが主な目的であれば数㎡で十分で、その程度の面積ならどの畑でも毎年場所を変えられます。

## 12. 収穫と脱穀

### 12-1. 収穫時期の判断

| 判断基準 | 内容 |
|---|---|
| 鞘 | 下から三番目の鞘を振って実がぶつかる音がするとき |
| 葉 | 下葉が黄色くなって落ち始めます |
| 全体の色 | 株の3分の2が茶色に変わりました |
| 実 | 噛むと歯が入らずポキッと割れます |
| 時点 | 播種後100-110日 |

> **レンズマメは下から上へと熟していき、熟した鞘は簡単に裂けます。上まで熟すのを待てば下を失います。下から三番目の鞘が音を出すときが妥協点です。**

&nbsp;&nbsp;&nbsp;レンズマメの脱粒は他の豆類より速いです。鞘が扁平で薄く、乾く過程で簡単にねじれて開き、特に乾いた鞘が雨に当たって再び乾くことを繰り返すと一瞬で裂けます。登熟期には毎日畑を見て回り、雨の予報があれば多少熟していなくても収穫する方がよいです。刈り取った後、陰で乾かし続ければ実はある程度熟します。

### 12-2. 収穫のコツ

| 順序 | 内容 |
|---|---|
| 1 | 晴れて乾いた日、露が乾いた午前10時以降に行います |
| 2 | 地面のすぐ上で茎を刈ります。鞘が低い位置についています |
| 3 | 刈りながらすぐに布やむしろの上に載せ、落ちる実を受けます |
| 4 | 束にして日に4-6日干すか、軒先に掛けて乾かします |
| 5 | 鞘がカラカラに乾き、振ると音がするときに脱穀します |

&nbsp;&nbsp;&nbsp;刈る間に落ちる実を受けることが、レンズマメ収穫のコツです。鞘が薄く裂けやすいため、鎌が触れる振動だけでも実が飛び出します。畑に布やむしろを敷き、その上に刈った束を運ぶと損失が目立って減ります。露がまだ少し残る早朝に刈れば鞘が裂けにくくなりますが、濡れたまま積んでおくとカビが出るため、刈った後すぐに広げて乾かします。

### 12-3. 脱穀 - 道具を使わない方法

| 方法 | 道具 | 手順 | 効率 |
|---|---|---|---|
| 袋踏み | 厚い麻袋や袋 | 乾いた茎を袋に入れ、口を結んでから足で踏みます | 少量に最も適しています。小さな実が飛び出しません |
| 唐竿（からさお） | 長い柄に打棒を付けた道具 | むしろを敷き、茎を薄く広げて上から打ちます | 中規模に適しています |
| 足でこする | なし | むしろに広げ、靴を履いた足でこすり回します | レンズマメは鞘が弱く、これだけでもよく外れます |
| 棒で叩く | 木の棒 | 袋に入れるかむしろに広げて叩きます | 唐竿がないときの代わりになります |
| 手でこする | なし | 乾いた束を両手でこすります | ごく少量、種子用に適しています |

&nbsp;&nbsp;&nbsp;レンズマメは豆類の中で脱穀が最も簡単です。鞘が薄くて弱いため、よく乾いた状態なら袋に入れて踏むだけでほとんど落ちます。ただし実が小さいため、袋の粗い隙間やむしろの縁から抜け出しやすく、目の細かい袋を使い、むしろの周りを布で囲んで塞ぎます。実が小さいことは脱穀では利点ですが、回収では不利になります。

### 12-4. 精選 - 風で選り分ける

| 方法 | 原理 | 手順 |
|---|---|---|
| 風選（風を起こす） | 実は重く、殻や屑は軽いです | 風のある日に、箕や広い器に入れて高く持ち上げ、ゆっくり注ぎます |
| 箕（み）でふるう | 上下に振りながら前に払います | 重い実が後ろに残り、軽いものが前に押し出されます |
| うちわであおぐ | 一人が注ぎ、一人がうちわで風を送ります | 風がない日に使います |
| ふるいがけ | 穴の大きさで分けます | 実が小さいため目の細かいふるいが必要です。土と細かい屑を分けます |
| 水に浮かせる | しいなや虫食いの実は軽いです | 水桶に入れ、浮くものを取り除きます。その日のうちに再び乾かします |
| 傾斜板転がし | 凸型の円盤なのでよく転がります | 板を斜めに立てて転がし落とします |

&nbsp;&nbsp;&nbsp;風選のコツは三つです。風が一定に吹く早朝か夕暮れ時を選び、一度にどさっと注がず細く流し落とし、二、三回繰り返します。レンズマメは実が小さく軽いため、風が強いと実まで飛んでいきます。他の豆より弱い風で行うべきで、うちわを使うなら軽くあおぐ方が安全です。最初は少しだけ試して風の強さを見極めてから本格的に行います。
