## 8. 栽培管理

### 8-1. 除草管理几乎决定一切

| 时期 | 作业 | 要点 |
|---|---|---|
| 出苗后2周 | 第1次除草 | 杂草还细如线时拔除 |
| 出苗后4-5周 | 第2次除草 | 这是最后一次 |
| 开花以后 | 不再进入田间 | 茎细，踩到就会折断 |

> **小扁豆株高40cm，茎细，是最不耐杂草的豆类。生育期短，一旦被压制就没有恢复的时间。头一个月的除草几乎决定了产量。**

&nbsp;&nbsp;&nbsp;除草的要领是浅、且早。小扁豆的须根浅浅地铺展在表层，锄头插得深就会切断根系。应把锄头放平，只刮去地表1-2cm来铲除杂草，靠近株的地方用手拔。而且等杂草长得明显了再拔就已经晚了，因为拔的时候会连小扁豆的根一起带出来。

&nbsp;&nbsp;&nbsp;密植使地面快速被覆盖也是一种除草对策。小扁豆株与株相互接触遮住地面后，之后杂草就不会大量增加，这是把播种密度设得稍高的原因之一。稻草覆盖也有帮助，但种子小，幼苗难以顶破稻草，所以应在发芽结束后才覆盖。

### 8-2. 倒伏管理

| 原因 | 应对 |
|---|---|
| 氮肥过量 | 遵守施肥量，这是根本对策 |
| 种植过稀 | 密植使彼此相互依靠 |
| 风雨 | 在田地周围拉膝高的绳子围住 |
| 豆荚的重量 | 接近灌浆期时无可奈何，可考虑提前收获 |

&nbsp;&nbsp;&nbsp;小扁豆不需要支架，因为株矮，且株与株之间靠卷须相互勾连支撑。但一旦倒伏，下方豆荚会接触泥土腐烂，收获也变困难，所以风雨频繁的地方，应在田地四周打桩，用绳子在膝盖高度绕一圈。已经倒伏的话，不要勉强扶正，用树枝垫在下面让它稍微离地会更好。

## 9. 病虫害

&nbsp;&nbsp;&nbsp;小扁豆的病虫害压力为C。实际损害集中在两种霉菌病害——锈病和枯萎病，其余相对较轻。小扁豆一旦处于潮湿环境，这两种病就会一起出现；在干燥条件下则大体平静。

### 9-1. 主要病害

| 病名 | 症状 | 发生条件 | 无药对策 |
|---|---|---|---|
| 锈病 | 叶片和茎上生出红褐色粉状颗粒，蔓延后叶片枯萎脱落 | 潮湿通风不良时，是小扁豆最大的病害 | 保证通风，摘除病叶，选育抗性个体，焚烧残株 |
| 枯萎病 | 开花期从下部叶片开始萎蔫，整株枯死 | 土壤传播，能在土中存活多年 | 3年以上轮作是唯一对策，从存活个体上留种 |
| 根腐病 | 茎基部与根变褐软化 | 过湿 | 排水，起高垄 |
| 灰霉病 | 豆荚与茎被灰色霉层覆盖 | 灌浆期连续降雨时 | 起高垄，稻草覆盖防止泥土溅起，提前收获 |
| 炭疽病 | 叶片与茎上出现黑色斑点 | 潮湿 | 种子挑选，轮作，通风 |

> **锈病是种植小扁豆的地方无论何处都会遇到的病害，抗性是可以遗传的。在病害流行的田地里，挑选坚持到最后的植株延续下去，是没有农药条件下最可靠的对策。**

&nbsp;&nbsp;&nbsp;锈病发展很快。从叶片上刚出现少量红褐色粉状物，到整片田变成锈色，可能只需几天。一旦蔓延就无法挽回，所以预防就是一切。要留足行距保证通风，控制氮肥避免长得过于繁茂，雨后不要进入田地。如果初期只在几株上出现，就把那些株整棵拔除烧毁，以延缓扩散。

&nbsp;&nbsp;&nbsp;枯萎病的性质不同。它以休眠孢子的形式留在土中，能坚持多年，一旦再种小扁豆就会苏醒。没有药物，也无法洗除。3年以上轮作是唯一对策，而在那块田里坚持到最后并结籽的个体，挑选出来延续下去，是第二个对策。

### 9-2. 主要害虫

| 害虫 | 危害 | 无药防治 |
|---|---|---|
| 蚜虫 | 附着在新芽和花梗上吸食汁液，并传播病毒 | 用水猛冲使其脱落。肥皂水（1L水配5g肥皂）。保护瓢虫 |
| 小扁豆象甲 | 在田间于豆荚上产卵，贮藏期蛀食籽粒 | 彻底晒干后密封贮藏是关键，参见第15节 |
| 地老虎 | 夜间从基部咬断幼茎 | 早晨在被咬断植株周围挖土能找到幼虫 |
| 蚂蚁 | 叼走播下的种子 | 给种子拌上草木灰 |
| 鸟 | 啄食幼苗和灌浆期的籽粒 | 发芽前用稻草或网覆盖 |

&nbsp;&nbsp;&nbsp;小扁豆植株小、叶片薄，一旦有害虫附着，受害比例就很大。大豆一株损失几片叶子，和小扁豆一株损失同样面积，意义是不同的。不过因为生育期短，往往在害虫种群大量增殖之前收获就已结束，这就是小扁豆实质上的防御。

### 9-3. 无药防治材料

| 材料 | 制作方法 | 对象 | 注意 |
|---|---|---|---|
| 波尔多液 | 100L水中分别溶入400g硫酸铜和400g生石灰后混合 | 锈病、霉菌病害 | 必须有铜才能配制，混合后要立即使用 |
| 肥皂水 | 1L水配5g无香皂 | 蚜虫、螨虫 | 叶片薄，用浓了会受损，要稀释使用 |
| 用水猛冲 | 直接冲洗 | 蚜虫 | 是小扁豆栽培中最简便的方法 |
| 撒干灰 | 在有露水的早晨向叶片撒细灰 | 抑制霉菌，驱避蚂蚁 | 下雨会被冲掉 |
| 草木灰水 | 将1升（约1.8升）草木灰浸入10L水中一夜，取上层清液使用 | 抑制霉菌 | 因呈碱性，需稀释使用 |
| 木醋液 | 烧炭时产生的液体，稀释300-500倍 | 驱避，促进生长 | 原液呈强酸性，必须稀释后使用 |

### 9-4. 农艺防治

| 方法 | 原理 |
|---|---|
| 保证通风 | 锈病随叶片潮湿时间越长而越严重，要留足行距 |
| 控制氮肥 | 长得过密会导致内部潮湿，引发锈病大爆发 |
| 3年以上轮作 | 等待枯萎病孢子在土中逐渐减少 |
| 稻草覆盖 | 防止雨滴溅起泥土使下方豆荚滋生霉菌 |
| 排水 | 小扁豆的病害大多与过湿有关 |
| 种子挑选 | 炭疽病等会通过种子传播 |
| 雨后禁止进入田间 | 人接触湿叶会沾上并传播孢子 |
| 残株处理 | 只焚烧患病残株，健康的还田 |
| 从存活个体上留种 | 对锈病和枯萎病的抗性可遗传 |

## 10. 营养缺乏与过量

| 症状 | 原因 | 天然材料应对 |
|---|---|---|
| 叶片整体呈淡黄色，植株矮小 | 缺氮。在小扁豆中，根瘤不良是最常见的原因 | 先挖根确认根瘤。若无根瘤且处于初期，可施极少量10倍稀释尿液 |
| 叶缘变褐干枯 | 缺钾 | 在株间撒草木灰并轻轻拌入土中 |
| 生长迟缓，叶片带紫色 | 缺磷。小扁豆对磷需求高 | 骨粉、烧制的鱼骨粉 |
| 开花却不结荚 | 缺硼，或开花期高温 | 多种材料混合的堆肥。若因高温所致，来年应调整播种期 |
| 叶脉间发黄 | 缺铁或缺锰，常见于偏碱性土壤 | 停止使用灰。用腐叶土和腐熟堆肥增加有机质 |
| 只有茎叶繁茂而豆荚稀少 | 氮过量 | 立即停止供氮 |
| 整体生长不良 | 强酸性土壤 | 石灰或烧制的贝壳粉 |

&nbsp;&nbsp;&nbsp;对小扁豆而言，发现缺素的时机很关键。生育期只有100天，开花之后才察觉，无论怎么补救那一年都已无用。播种后3到4周之间，仔细察看一次田地，确认叶色与大小的习惯很实用。那时若长势不佳，就用少量氮帮它度过初期；若正常，之后就不再干预。

&nbsp;&nbsp;&nbsp;微量元素缺乏很难逐一应对。在没有化肥的条件下，几乎没有办法获取钼或钴。但把蔬菜残渣、果皮、蛋壳、鱼骨、落叶、杂草、灰混合在一起腐熟制成的堆肥，均匀含有各种微量元素。"堆肥堆里什么都能放"这一原则，就是微量元素管理的实际策略。

## 11. 间作与轮作

### 11-1. 搭配

| 搭配 | 作物 | 理由 |
|---|---|---|
| 好 | 大麦·小麦·燕麦 | 种在谷物行间可互相支撑，共享氮素 |
| 好 | 马铃薯 | 病害不重叠，小扁豆先收获 |
| 好 | 大白菜·萝卜类 | 后作利用小扁豆留下的氮 |
| 好 | 万寿菊 | 根系分泌物能抑制线虫 |
| 一般 | 叶菜类 | 初期能一起生长，但小扁豆不耐杂草竞争会落败 |
| 差 | 大蒜·洋葱类 | 有报告称其分泌物会抑制根瘤菌 |
| 差 | 其他豆科 | 病原菌与线虫会累积 |

&nbsp;&nbsp;&nbsp;小扁豆与谷物混种，是原产地长期沿用的方式。把小扁豆种在大麦或小麦的行间，谷物挺直的茎就成了小扁豆的依靠，小扁豆固定的氮也有一部分流向谷物。而且两种作物的收获期相近，可以一次性割下、一起脱粒后再用筛子和风分开。小扁豆比谷物小得多也重得多，容易分选。但小扁豆在40%遮光下产量会降到一半，所以行距要留够，不能让它深陷谷物的阴影中。

### 11-2. 轮作

| 项目 | 标准 |
|---|---|
| 休作期 | 3年以上，枯萎病会残留在土中 |
| 理想周期 | 4年 |
| 连作障碍 | 枯萎病与根腐病会累积 |

| 4年轮作示例 |
|---|
| 第1年：小扁豆 |
| 第2年：谷物（大麦·小麦·燕麦） |
| 第3年：马铃薯或甘薯 |
| 第4年：大白菜·萝卜类或绿肥 |
| 再种小扁豆 |

&nbsp;&nbsp;&nbsp;记下田地狭窄、没有余地轮作时的折中办法。小扁豆植株小，所需面积也小。哪怕只是每年把田角一小块地方轮换着用，也算是轮作。如果主要目的是延续种子，几平方米就够了，这么小的面积在任何田地里都能每年换个地方种。

## 12. 收获与脱粒

### 12-1. 收获时期的判断

| 判断标准 | 内容 |
|---|---|
| 豆荚 | 摇动从下往上数第三个豆荚，能听到籽粒碰撞声时 |
| 叶 | 下部叶片变黄开始脱落 |
| 整体颜色 | 植株三分之二变为褐色 |
| 籽粒 | 咬时牙齿咬不进去，会脆脆地裂开 |
| 时点 | 播种后100-110天 |

> **小扁豆从下往上依次成熟，成熟的豆荚容易裂开。等上部全部成熟，就会损失下部。从下往上数第三个豆荚发出声音时，就是折中的收获时机。**

&nbsp;&nbsp;&nbsp;小扁豆的落粒比其他豆类快。豆荚扁而薄，干燥过程中容易扭裂开口，尤其是干荚淋雨后再次变干，反复几次就会瞬间裂开。灌浆期要每天查看田地，如果有降雨预报，即便还没完全成熟，也最好提前收割。割下后放在阴凉处继续晾干，籽粒还能在一定程度上继续成熟。

### 12-2. 收获要领

| 顺序 | 内容 |
|---|---|
| 1 | 选晴朗干燥的日子，在露水干后的上午10点以后进行 |
| 2 | 紧贴地面割断茎，因为豆荚结生位置很低 |
| 3 | 边割边立即放到布或草垫上，接住掉落的籽粒 |
| 4 | 捆成束在阳光下晒4-6天，或挂在屋檐下晾干 |
| 5 | 豆荚彻底晒干，摇动时有响声时进行脱粒 |

&nbsp;&nbsp;&nbsp;边割边接住掉落的籽粒，是小扁豆收获的要领。豆荚薄而易裂，光是镰刀擦过的震动都会让籽粒蹦出来。在田里铺上布或草垫，把割下的束搬到上面，损失会明显减少。趁露水尚存的清晨割，豆荚不容易裂开，但如果带着水汽堆放就会发霉，所以割下后要立即摊开晾干。

### 12-3. 脱粒 - 无工具的方法

| 方法 | 工具 | 步骤 | 效率 |
|---|---|---|---|
| 踩袋法 | 厚麻袋或布袋 | 把干茎装入袋中，扎紧口后用脚踩 | 对少量最为方便，细小的籽粒不会溅出 |
| 连枷 | 长柄上系着打杆的工具 | 铺开草垫，把茎薄薄摊开后从上方敲打 | 适合中等规模 |
| 脚搓法 | 无 | 摊在草垫上，穿鞋的脚踩踏搓动 | 小扁豆豆荚脆弱，光这样就容易脱粒 |
| 棍棒敲打 | 木棒 | 装入袋中或摊在草垫上敲打 | 没有连枷时可替代使用 |
| 手搓法 | 无 | 用双手搓揉干束 | 适合极少量，尤其是种子用途 |

&nbsp;&nbsp;&nbsp;小扁豆是豆类中脱粒最容易的。豆荚薄而脆弱，只要充分晒干，装进袋子踩踏就几乎能全部脱落。但籽粒小，容易从袋子的稀疏缝隙或草垫边缘漏出，所以要用密织的袋子，并用布把草垫四周围住挡住。籽粒小这一点在脱粒上是优点，在回收上却是缺点。

### 12-4. 精选 - 用风分选

| 方法 | 原理 | 步骤 |
|---|---|---|
| 风选（扬风） | 籽粒重，皮壳与碎屑轻 | 有风的日子，把籽粒装入簸箕或宽口容器高举，缓缓倾倒 |
| 簸箕簸扬 | 上下颠动并向前簸出 | 重的籽粒留在后方，轻的被推向前方 |
| 扇风 | 一人倾倒，一人用扇子扇风 | 用于无风的日子 |
| 筛选 | 按孔径大小分开 | 籽粒小需要细筛，用来分出泥土与细碎屑 |
| 水浮法 | 空壳与虫蛀籽粒较轻 | 倒入水桶中捞去漂浮的部分，当天要重新晒干 |
| 斜板滚选 | 凸透镜状圆盘容易滚动 | 把板斜放，让籽粒滚落下来 |

&nbsp;&nbsp;&nbsp;扬风有三个要领：选风力稳定的清晨或黄昏；不要一次性倒下，要细细地缓慢倾倒；重复两三次。小扁豆籽粒小而轻，风一大连籽粒都会被吹走，需要比其他豆类更弱的风力操作，用扇子的话也要轻轻扇才安全。开始时先少量试验来判断风力大小，再正式进行。
