## 引言
&nbsp;&nbsp;&nbsp;小扁豆（Lens culinaris）是种子呈凸起圆盘状、形似透镜的豆科一年生草本，原产于西南亚的新月沃地，与小麦、大麦、豌豆一起属于最古老的栽培作物。最大的优点是烹调几乎不需要燃料。干小扁豆不用泡，去皮掰开的红扁豆10-15分钟就能煮成粥状，所以烹调·加工C是豆类中最高的值。水消耗量也是S，总蒸散量250mm，不到大豆的一半。综合等级为C（41.9分，有效183种中第89名），短期D（40.5）、长期C（43.2），副食为SS（63.4分）。单位面积热量为D，每1,000㎡ 150kg、每㎡ 548kcal，仅为自给线的0.21倍，国内种植普及度为C，只在一两个道（韩国行政区）试种。市面上卖的食用小扁豆去了皮或经过热处理，不能发芽，所以另外弄到可播种的种子，并用几年时间通过自留种扩繁，是把这种作物纳入计划的前提。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | C | 41.9 |
| 短期 | D | 40.5 |
| 长期 | C | 43.2 |
| 副食 | SS | 63.4 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：施肥、设施负担、耐储性。S：蛋白质密度、微量营养素、水消耗量、口味、自留种。A：耐寒性、无合成投入产量保持率、产量稳定性、种子寿命。B：收获速度、温度幅度、防治自立度、连作适应性 |
| 劣势 | D：单位面积热量、持续性、光照、整地·挖掘能量、非食用价值。C：烹调·加工要求度、病虫害压力、国内种植普及度 |

> **灾害情况下，燃料和粮食一样很快见底。每顿都要烧一个小时火的豆子和10分钟就够的豆子，一年累积下来，差的是一大堆柴火。**

&nbsp;&nbsp;&nbsp;小扁豆籽粒扁平，厚度只有2-3mm，是豆类中最薄的，热量传到中心的距离短，种皮薄，水一下就渗进去。微量营养素S是副食SS的依据，铁和叶酸充足，重要的是它好煮，所以实际上会常吃。单位面积热量D也连带导致整地·挖掘能量D，只用小扁豆种满一块田，从热量账上看是亏的。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 项目 | 内容 |
|:---|:---|
| 分类 | 豆科小扁豆属一年生草本。原产于西南亚（今土耳其和叙利亚一带），自花授粉 |
| 叶、茎 | 偶数羽状复叶，小叶4-7对，顶端变成短卷须，植株之间互相勾住依靠。茎细而直立，株高30-45cm，矮小柔弱 |
| 根、花 | 笔直的主根深入土中，须根上长着小米到米粒大小的小根瘤。花为白色或淡紫色，直径5mm左右 |
| 荚、籽粒 | 扁而短，每荚1-2粒，低低地结在离地10cm以内。籽粒呈凸起的圆盘状 |

> **小扁豆所有的实用优点都来自籽粒的薄。热量传到中心的距离短，所以熟得快；水一下就渗进去，所以不用泡。**

&nbsp;&nbsp;&nbsp;生育期只有100-110天，很短，没有时间弥补失误，而且成熟不整齐。干籽粒每100g热量365kcal，蛋白质22.64g（占热量的24.8%），脂肪1-2g，膳食纤维10-30g，糖类1.56g，铁约7mg，钾约900mg，镁约100mg，叶酸非常丰富，脂肪少，所以酸败慢。蛋白质赖氨酸充足、蛋氨酸略缺，与性质相反的谷物一起吃，就能互补彼此的缺口。配上醋或泡菜之类的酸味（维生素C），铁的吸收会大大提高。

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽4℃以上（最适18-22℃）。生长5-28℃（最适15-20℃），超过25℃结实变差。结实15-27℃。开花期25℃以上持续几天，花就会脱落、不结荚。能耐到-5℃ |
| 水、土壤 | 排水良好的沙壤土-壤土（避开黏土和积水的地方），pH 5.5-8.0（最适6.0-7.5），喜中性到弱碱性。垄高15-20cm以上（除了排水，还能防止泥水溅到下部荚上长霉） |

> **小扁豆之所以难以放在韩国的气候里，是因为两件事重叠。超过25℃结实就垮掉，灌浆期连雨则病害暴发。韩国的夏天同时带来这两样。**

&nbsp;&nbsp;&nbsp;缓解这一限制的栽培类型有三种。高寒地春播，在海拔400m以上于3月中旬-4月上旬播种，6-7月收获，最为稳定。晚夏播种，在平原于8月底-9月初播种，11-12月收获，但灌浆期有碰上寒冷的风险。南部越冬栽培，在南部沿海于10月中下旬播种，次年5-6月收获，-5℃是极限。种子珍贵，所以头几年在三种类型上各种一点，看看这块地上哪一种能活。

| 类别 | 特点 | 烹调时间 |
|:---|:---|:---|
| 棕色小扁豆 | 最常见，带皮，形状保持。多用途，适合储存和留种 | 20-25分钟 |
| 绿色小扁豆 | 籽粒大，口感紧实。凉拌、炒菜 | 25-30分钟 |
| 红、黄小扁豆 | 去皮掰开的加工形态，会煮散，用于粥和汤，适合病人、老人、孩子 | 10-15分钟 |

> **红小扁豆和黄小扁豆不是品种，而是加工形态。它们去了皮并掰成两半，绝对不会发芽。把市面上买的红小扁豆种进田里，什么也长不出来。**

&nbsp;&nbsp;&nbsp;储备时要把吃的和种的分开，种的必须是皮完整的棕色或绿色小扁豆，即使这样也可能因热处理或熏蒸而失去发芽力，所以弄到手后必须做发芽试验。储存要带皮，加工只做吃的量。

## 4. 整地与播种
| 项目 | 标准 |
|:---|:---|
| 整地 | 深耕20-30cm，种子小，土块大则发芽不齐，所以用耙子或木板把表面反复搓平整细。垄高15-20cm以上，排水沟深30cm以上。酸性土（pH 6.0以下）在播种前3-4周施白云石灰（用烤过捣碎的贝壳·蛋壳或草木灰代替） |
| 施肥（1,000㎡） | 磷20-30kg（均作基肥，是氮的十倍以上，用骨粉和烤过的鱼骨粉补充）。少施氮才是技术，多了只长茎叶、互相遮盖，通风不良使锈病蔓延，荚减少。草木灰（每㎡ 100-150g）、稀释10倍的人尿（初期生长不良时用极少量） |
| 根瘤接种 | 取种过小扁豆、豌豆、蚕豆、救荒野豌豆且根瘤生得好的田里5-15cm深的表土，裹在用水稍微润湿的种子上，立即播下。野生救荒野豌豆根上的红色根瘤也可用。大豆或鹰嘴豆田里的土因菌种不同而无用 |

&nbsp;&nbsp;&nbsp;小扁豆的根瘤小，所以洗去泥土后在明亮处检查须根，用刀尖剖开。每株10个以上说明接种顺利，几乎没有就是失败，叶发黄时补充少量氮。每公顷固氮量在条件好时为60-100kg，差时15-35kg，茎叶里留下15-25kg，小扁豆的茎叶细而少，容易原样还回田里。不挖根，只烧掉病残体。

| 播种 | 标准 |
|:---|:---|
| 种子准备 | 先做发芽试验：用湿布包20粒，放几天后数出芽的粒数。一半以上可用，只有三四粒则不如吃掉。弃去裂开或变色的种子（掰开的粒不会发芽），放进筛子用水冲洗，洗去灰尘。浸种仅在土壤干燥时进行12-24小时（种皮薄，泡久了会变软） |
| 方法 | 深2-5cm，种距8-10cm，行距30-40cm，播种量5-6kg/1,000㎡。籽粒小，条播比点播效率高，行内稍密一些让植株互相依靠，并尽快盖住地面压制杂草。种子裹细草木灰防蚂蚁，行上薄盖稻草防鸟 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 发芽期 | 种子埋得浅，播种后十天左右保持表层湿润 |
| 生长初期 | 靠自然降水（干燥会让根扎得深） |
| 灌浆期 | 停止灌溉（过湿则炸荚和发霉） |
| 连雨时 | 挖排水沟（下部荚碰到土就会烂） |

> **小扁豆株高只有40cm，茎又细，是最怕杂草的豆类。生育期短，一旦被压住就没有时间恢复。头一个月的除草几乎决定产量。**

| 管理 | 方法 |
|:---|:---|
| 除草 | 出苗后2周第1次（杂草只有线那么大时），4-5周第2次是最后一次，开花后不进田（茎会折断）。须根在表层，所以把锄放平只刮表面1-2cm，靠近植株的用手拔 |
| 覆盖、支撑 | 铺2-3cm厚的稻草或稻壳，可防泥水溅起并节水（嫩芽难以顶破，所以发芽结束后再盖，雨季要掀开一部分）。不需要支柱，但风雨多的地方沿田边在膝高处拉绳 |

## 6. 病虫害与养分问题
| 病虫害 | 症状与条件 | 不用药的对策 |
|:---|:---|:---|
| 锈病 | 叶和茎上出现红褐色粉堆，蔓延后叶片干枯脱落。潮湿且通风不良时蔓延，是最大的病害，发展很快 | 行距放宽保证通风，少施氮，摘除病叶。初期只有几株时连根拔除烧掉。雨后不进田 |
| 枯萎病 | 开花期从下部叶开始萎蔫，整株干枯死亡。在土中以休眠孢子存活多年 | 轮作3年以上是唯一对策。从存活的植株上留种 |
| 灰霉病、炭疽病 | 荚和茎上有灰色霉层（灌浆期连雨时） / 叶和茎上有黑斑（潮湿） | 起高垄、稻草覆盖、提早收获 / 选种、轮作、通风 |
| 蚜虫、地老虎 | 附在嫩芽和花梗上吸汁并传播病毒 / 夜间咬断幼茎基部 | 用强水流冲落，并用肥皂水（每1L水加肥皂5g，叶薄所以要稀一些），保护瓢虫 / 早晨挖开被咬断植株周围的土捉幼虫 |
| 小扁豆象 | 在田里于荚上产卵，储存期间蛀食籽粒 | 完全晒干后密封储存（见第9节） |

> **锈病是只要种小扁豆的地方就会遇到的病，抗性可以遗传。选出在病害蔓延的田里坚持到最后的植株并继续种下去，是没有药剂时最可靠的对策。**

&nbsp;&nbsp;&nbsp;波尔多液是将硫酸铜400g和生石灰400g分别溶于100L水中再混合，立即使用，用于锈病和真菌病。在有露水的早晨撒在叶上的细灰，能抑制霉菌并驱走蚂蚁。

| 症状 | 原因与对策 |
|:---|:---|
| 整片叶淡黄、植株矮小 | 缺氮（根瘤不良最常见）。先挖出根检查根瘤，若没有根瘤且还在初期，施极少量稀释10倍的人尿。在播种后3-4周仔细查看一次田地 |
| 生长迟缓、叶发紫 | 缺磷。骨粉、烤过的鱼骨粉 |
| 开花却不结荚 | 缺硼，或开花期高温。施用多种材料混合的堆肥，若原因是高温，次年调整播种期 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 大麦、小麦、燕麦（种在谷物行间，笔直的茎秆成为小扁豆依靠的地方并分享氮，收获期相近可一起割下脱粒后用筛子和风分开，但遮光40%时产量减半，所以行距要放宽）、马铃薯（病害不重叠，且小扁豆先收获）、大白菜·萝卜类（后茬利用小扁豆留下的氮） |
| 一般 | 叶菜（初期一起生长，但小扁豆怕杂草，在竞争中落败） |

&nbsp;&nbsp;&nbsp;连作障碍是枯萎病和根腐病积累，要休耕3年以上。轮作的例子是：第1年小扁豆 → 第2年谷物（大麦·小麦·燕麦） → 第3年马铃薯或甘薯 → 第4年大白菜·萝卜类或绿肥 → 再种小扁豆。所需面积小，所以每年挪到田角的一小块地使用，也算轮作。

## 8. 收获与留种
| 收获 | 标准 |
|:---|:---|
| 时期 | 播种后100-110天，下部叶发黄脱落、植株三分之二变褐时。摇动从下数第三个荚、听到籽粒碰撞声的时候是折中点（由下往上成熟，成熟的荚容易炸裂）。有下雨消息时，即使没完全成熟也收，并在阴凉处晾透 |
| 要领 | 在紧贴地面处割茎（荚结得低）。镰刀的震动就会让籽粒蹦出，所以把割下的捆移到布或席子上，接住掉落的籽粒。割完立即摊开晾晒 |
| 脱粒、精选 | 豆类中脱粒最容易。装进织得密的袋子里踩踏，或摊在席子上用穿鞋的脚搓转，少量则用手搓。用细筛筛去泥土和碎屑，籽粒是凸起的圆盘，所以让它沿倾斜的木板滚下来分选。籽粒小而轻，所以簸时要比其他豆子风小，细细地倒下，做两三遍 |
| 干燥 | 脱粒后薄摊在席子或垫子上晒1-2天（籽粒薄所以干得快，强光下放久会裂开）。含水量12%以下 |

| 留种 | 标准 |
|:---|:---|
| 选株 | 预先在田里标记没有锈病症状、在有枯萎病的田里坚持到最后、荚多的植株。在25℃以上的天气里也结了荚的植株、雨季前先成熟的植株也一并选出，选育几年就能形成在这块田里经得住的品系。自花授粉，所以不用担心隔离距离 |
| 收获、精选 | 荚完全变褐、尚未炸裂时收获，单独脱粒并用手搓，籽粒不会受损。弃去裂粒、斑点、变色、小的籽粒，在阴凉处慢慢晾到含水量12%以下。发芽率2年后为70-80% |

> **小扁豆是在韩国国内很难再次弄到可播种种子的作物。市面上卖的食用小扁豆大多不能发芽。留种不是选择，而是继续种这种作物的前提条件。**

## 9. 储存
| 步骤 | 方法 |
|:---|:---|
| 豆象防治 | 完全密封最重要（氧气耗尽，虫就死了），要把容器装满、减少空隙，用几个小容器而不是一个大容器。拌入筛过的草木灰，占豆体积的2-5%（籽粒小所以灰能均匀渗入，吃前冲洗），油涂层是每1kg豆加食用油3-5mL（留种用的除外） |
| 容器、检查 | 厚塑料袋可存1-2年，但老鼠会咬穿、籽粒小还会漏出来，所以用玻璃瓶或金属桶。把耳朵贴在容器上，有沙沙声是有虫，有霉味是发霉。带皮储存，种皮起到防护作用，去皮的小扁豆储存性变差 |

## 10. 烹调与注意事项
| 成分 | 作用 | 去除方法 |
|:---|:---|:---|
| 胰蛋白酶抑制剂 | 阻碍蛋白质分解酶，造成腹部不适和蛋白质利用率下降 | 在沸水中煮20-30分钟即可（含量不到大豆的三分之一） |
| 凝集素 | 附着在肠黏膜上妨碍吸收，但少量无害 | 加热很容易破坏，与菜豆类不同，毒性很弱 |
| 低聚糖、单宁 | 肠内发酵使肚子胀气（在豆类中含量少） / 种皮的涩味成分妨碍铁的吸收 | 倒掉煮豆水 / 去皮后几乎消失 |

> **小扁豆真正伤人的不是豆本身，而是储存不当而发霉的豆。如果有潮味或表面出现泛青的粉末，不要舍不得，丢掉。**

| 处理 | 标准 |
|:---|:---|
| 基本 | 烹调前用水冲洗，捞去浮起的。不用泡（厚2-3mm，水马上就渗进去），带皮的在沸水中煮20-30分钟就会在保持形状的情况下变软，去皮掰开的10-15分钟就煮散成粥 |
| 节省燃料 | 与米一起放进饭或粥里，就不需要另外生火（去皮的比米熟得快，所以要晚点放）。余热烹调是煮5分钟后熄火，用被褥或稻草箱包起来放1小时（没有强毒性成分，所以安全）。炒后磨成的粉冲水喝 |
| 去皮掰开 | 把干小扁豆用水稍微润湿，在臼里非常轻地捣一下，只去掉皮（不捣碎籽粒），用簸箕簸走，再掰成两半，烹调时间从20分钟缩到10分钟，但储存性变差，所以只做一两个月吃的量 |
| 发芽、加工 | 泡8小时沥水，盖上湿布放2-3天就会长芽，生成维生素C，植酸减少，更易消化（稍微焯一下也可以）。炒后磨成的小扁豆粉密封可存3-6个月。磨碎放一夜发酵的面糊会发起来，更易消化 |

> **小扁豆的价值在于，煮饭时和米一起放进去，不用另外生火，蛋白质也能上桌。其他任何豆子都做不到这一点。**

&nbsp;&nbsp;&nbsp;小扁豆低聚糖少，肚子不容易胀气，去皮的红扁豆负担尤其小，所以当必须给长期挨饿的人、病人、老人、孩子喂豆子时，小扁豆粥是最安全的选择。

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存、种子发芽试验。2月做田地规划、撒石灰、翻堆堆肥、准备高寒地春播 |
| 3-4月 | 3月高寒地春播（从中旬起）、整细土壤。4月第1次除草、间苗（头一个月的杂草管理决定产量） |
| 5-6月 | 5月第2次除草、开花、检查根瘤。6月鼓荚、监视锈病、灌溉（保证通风，雨后不进田） |
| 7-8月 | 7月高寒地收获、挂起晾干、脱粒。8月精选、储存，月底晚夏播种（平原） |
| 9-10月 | 9月晚夏播种茬的除草、整理田地。10月晚夏播种茬的开花和鼓荚，南部越冬播种 |
| 11-12月 | 11月收获晚夏播种茬（霜冻加重时即使没熟透也收）、晾干、储存。12月加工（只做一两个月吃的量）、发芽蔬菜、规划来年 |

> **小扁豆只要弄到可播种的种子并做发芽试验，分三种类型种植，头一个月除草，在从下数第三个荚发出声响时收获，就是只需和米一起放进去、不用另外生火就能提供蛋白质的作物。**
