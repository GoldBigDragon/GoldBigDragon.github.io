## 5. 整地与施肥 - 氮素平衡与施肥

### 5-4. 固氮的陷阱

&nbsp;&nbsp;&nbsp;种豆能让土地变肥沃，这话已经成了农业上的常识。它对了一半，也错了一半。如果不能准确理解这一点，连续种植豆科作物几年的田地，反而会出现地力衰退的情况。

&nbsp;&nbsp;&nbsp;我们用数字来核算一下。小扁豆长势好时，每1,000㎡能收获150kg干籽粒。小扁豆籽粒的蛋白质为22.6%，蛋白质除以6.25就得到氮含量。22.6 ÷ 6.25为3.62，也就是籽粒重量的约3.6%是纯氮。150kg中所含的氮约为5.4kg，折算成每公顷则是54kg。

&nbsp;&nbsp;&nbsp;另一方面，小扁豆根瘤在条件良好时固定的氮，每公顷为60kg到100kg。由于植株小，绝对量比蚕豆或大豆少，但籽粒带走的量也同样少，所以平衡反而不算差。把流出与流入并列来看，如下所示。

| 项目 | 每公顷氮量 | 方向 |
|---|---|---|
| 根瘤固定量（条件良好） | 60-100kg | 流入 |
| 根瘤固定量（条件不良） | 15-35kg | 流入 |
| 随籽粒带出 | 45-60kg | 流出 |
| 留在茎叶（茎与叶）中的氮 | 15-25kg | 还田则留下，焚烧或运走则流出 |
| 留在根与根瘤中的氮 | 8-15kg | 大多留在田中 |

&nbsp;&nbsp;&nbsp;这张表揭示的是接种的重要性。接种成功、固定量达到80kg时，即便带走籽粒，氮仍有余。接种失败只固定20kg时，随籽粒流出50kg，田地就明确亏损。对小扁豆而言，接种不仅是产量问题，也是田地可持续性的问题。

> **豆科能养地，不是因为它能固氮，而是因为它把固定下来的氮的一部分储存在茎叶中留在田里。一旦把这些茎叶运走，豆子就会变成掠夺土地的作物。**

&nbsp;&nbsp;&nbsp;小扁豆的茎叶量少而细，容易还田。脱粒后剩下的茎细到用手就能捏碎，撒在田里几周内就会腐烂。它不像大豆秸秆那样粗壮结实，甚至不需要切碎，没有不还田的理由。只有患病的残株要挑出来烧掉，因为小扁豆的锈病和枯萎病会留在残株里传到来年。

| 原则 | 内容 |
|---|---|
| 茎叶必须还田 | 脱粒后剩下的茎叶原样撒回田里 |
| 不焚烧 | 焚烧会让氮以气体形式散失，只留下钾和磷在灰中 |
| 不挖根 | 贴近地面割断，把根留在土中 |
| 挑出患病残株 | 锈病和枯萎病会随残株传播，只焚烧这部分 |
| 务必接种 | 接种失败既是产量损失，也是氮的流失 |
| 若喂了家畜就归还粪肥 | 若把茎叶喂了家畜，一定要把该家畜的粪肥施回这块田 |

### 5-5. 整地

| 项目 | 方法 | 在灾害条件下 |
|---|---|---|
| 耕地 | 深耕20-30cm，整平地面 | 种子小，把土整细尤其重要 |
| 垄 | 高度15-20cm以上 | 兼顾排水，防止下方豆荚接触泥土 |
| 排水沟 | 深度30cm以上 | 不耐湿涝 |
| 酸度调节 | pH 6.0-7.5 | 播种前3-4周提前进行 |
| 石灰 | 酸性土（pH 6.0以下）施白云石灰 | 可用烧碎的贝壳、蛋壳或草木灰代替 |
| 有机质 | 腐熟堆肥1,000-1,500kg/1,000㎡ | 作基肥施入 |

&nbsp;&nbsp;&nbsp;把土整细这项工作，在小扁豆栽培中比其他作物更重要。种子小，播种深度只有2-5cm，土块大的话，种子会掉进土块间的空隙里干枯，或被埋得太深。耕地之后，要用耙子或木板反复把地表整平，弄成细碎的土，这样发芽才整齐。

### 5-6. 施肥量

| 肥料 | 每1,000㎡基准 | 折算每㎡ | 备注 |
|---|---|---|---|
| 氮 | 0-2kg | 0-2g | 几乎不需要，施多了会抑制固氮 |
| 磷 | 20-30kg | 20-30g | 全部作基肥。根系发育与开花所必需 |
| 钾 | 3-5kg | 3-5g | 全部作基肥 |
| 堆肥 | 1,000-1,500kg | 1-1.5kg | 使用完全腐熟的堆肥 |
| 石灰 | 仅限酸性土 | - | 播种前3-4周 |

> **在小扁豆栽培中，控氮不是节省，而是一种技术。氮多了只会让茎叶徒长、互相遮蔽，通风变差导致锈病蔓延，豆荚反而结得更少。**

&nbsp;&nbsp;&nbsp;追肥原则上不需要。但由于生育期短，初期一旦明显长势不佳，这一年就算白费了。真叶长到三四片时，如果叶片整体呈淡黄色且不再生长，可将尿液用水稀释10倍，在株间土壤极少量浇灌，注意不要沾到叶片。错过这个时期，之后再补也没有效果。

### 5-7. 灾害替代肥料

| 替代资源 | 供给的养分 | 用法 | 注意 |
|---|---|---|---|
| 骨粉 | 磷、钙 | 烧后捣碎，混入堆肥 | 是满足小扁豆高磷需求的关键 |
| 鱼骨·鱼内脏 | 磷、氮 | 埋入土中腐熟后使用 | 直接埋的话会被野兽刨出来 |
| 草木灰 | 钾、磷、钙 | 每㎡撒100-150g并混入土中 | 呈碱性。小扁豆喜弱碱性，有一定余量 |
| 腐熟堆肥 | 综合 | 每㎡施1-1.5kg作基肥 | 未腐熟的会烧根并传播病害 |
| 稀释尿液 | 氮、钾 | 用水稀释10倍，浇灌株间土壤 | 仅限极少量，只在初期长势不佳时使用 |
| 贝壳·蛋壳 | 钙 | 烧后捣碎撒施 | 可代替石灰，见效较慢 |
| 落叶腐叶土 | 综合、有机质 | 混入土中 | 能改善保水性 |
| 稻壳·稻草 | 钾、硅酸 | 薄薄覆盖 | 防止泥土溅到豆荚上 |

&nbsp;&nbsp;&nbsp;磷20-30kg，是氮的十倍以上。因为小扁豆的根系发育和固氮的能量代谢都需要磷。在没有化肥的条件下，获取磷几乎只能靠骨粉和鱼骨。把动物骨头收集起来用火烧到容易碎裂，再用臼捣碎混入堆肥中，就能在数年间缓慢释放出来。

## 6. 播种

### 6-1. 播种时期

| 种植方式 | 播种时期 | 收获时期 | 适用 |
|---|---|---|---|
| 高冷地春播 | 3月中旬-4月初 | 6月-7月 | 海拔400m以上，最为稳定 |
| 晚夏播种 | 8月末-9月初 | 11月-12月 | 平地，灌浆期有遇冷风险 |
| 韩国南部越冬栽培 | 10月中下旬 | 次年5-6月 | 韩国南部沿海，零下5度为极限 |

&nbsp;&nbsp;&nbsp;这三种种植方式在韩国的气候条件下都是有条件的。小扁豆的生理特性适应地中海式气候，而韩国的夏季按这个标准来说太热又太湿。如果有高冷地，答案就在那里；如果没有，就必须尝试晚夏播种和韩国南部越冬栽培。

> **因为种子珍贵，不要把全部押在一种种植方式上。头几年应把种子分成小份，按三种方式分别试种，用来确认在那片土地上哪种能存活。**

&nbsp;&nbsp;&nbsp;晚夏播种的要领是从初霜日期倒推。小扁豆需要100-110天，但秋季气温下降会使生育变慢，很难在初霜前完成灌浆。因此要利用小扁豆能耐受零下5℃的特点，让最后阶段的灌浆在轻霜中继续进行。若尚未完全成熟就遇到较强霜冻，就收割后拿到室内继续晾干。

### 6-2. 种子准备

| 项目 | 方法 | 在灾害条件下 |
|---|---|---|
| 发芽试验 | 用湿布包20粒种子放置数天，数发芽的数量 | 是小扁豆栽培中最先要做的事 |
| 挑选 | 剔除裂开或变色的种子 | 裂开的籽粒不会发芽 |
| 清洗 | 放入筛子中用水冲洗 | 洗去灰尘与碎屑 |
| 温水消毒 | 浸入50-55℃水中10-15分钟 | 杀死种子传播的病原菌 |
| 拌灰处理 | 拌上细草木灰 | 有助消毒和干燥，并有驱避鸟类与蚂蚁的效果 |
| 根瘤接种 | 沾上种过同菌系豆科作物的田地土壤 | 参见5-3节，不与消毒同时进行 |
| 浸种 | 仅在土壤干燥条件下浸12-24小时 | 种皮薄，浸太久会变软 |

&nbsp;&nbsp;&nbsp;在小扁豆栽培中，发芽试验不是走形式的程序。市售食用小扁豆多为去皮切开或经过热处理的，根本不会发芽。等全部种到地里之后才发现，就会整年白费。拿到种子后，首先要做的就是用湿布包二十粒放置数天来确认：一半以上发芽就还能用，若只有三四粒发芽，就不要拿来当种子，直接吃掉更好。

### 6-3. 播种方法

| 项目 | 标准 | 理由 |
|---|---|---|
| 播种深度 | 2-5cm | 种子小，太深就顶不出土 |
| 种子间距 | 8-10cm | |
| 行距 | 30-40cm | 保证通风 |
| 播种量 | 5-6kg/1,000㎡ | 在豆类中偏少 |
| 播种方式 | 条播或撒播 | 籽粒小，条播比点播更有效率 |

&nbsp;&nbsp;&nbsp;小扁豆籽粒小，一粒一粒点播效率低。开浅沟撒种再覆土的条播方式更现实；如果田地宽阔，也可以采用撒播后用耙轻轻拨土覆盖的方式。但撒播会让除草变难，对不耐杂草的小扁豆来说，条播总体上更好。

&nbsp;&nbsp;&nbsp;种植密度宜稍密。小扁豆卷须弱，靠株与株之间互相搭靠支撑，种得稀了就没有依靠而倒伏。种得密些能互相支撑，并能更快覆盖地面抑制杂草。但过密会导致通风不良、锈病蔓延，因此适当的做法是行距留宽、行内密植。

&nbsp;&nbsp;&nbsp;播种后立刻面临的威胁是鸟和蚂蚁。种子小又埋得浅，蚂蚁会把它叼走。给种子拌上细草木灰能减少蚂蚁靠近，在播种行上薄薄盖一层稻草则能同时防鸟和防止干燥。

## 7. 水分管理

| 时期 | 水分管理 | 理由 |
|---|---|---|
| 播种到发芽 | 不让土壤完全干透 | 种子埋得浅，表层一干发芽就会停止 |
| 生长初期 | 交给自然降水 | 干燥能促使根系向深处伸展 |
| 开花期到荚膨大期 | 干旱严重时灌溉 | 这段时期缺水对产量影响最大 |
| 灌浆期 | 停止灌溉 | 过湿会导致落粒和霉变 |
| 连续降雨时 | 挖排水沟 | 下方豆荚接触泥土会腐烂 |

&nbsp;&nbsp;&nbsp;小扁豆水分管理的特别之处在于，发芽期与之后正好相反。种子埋得浅，发芽期表层不能干；但一旦出苗，干燥的条件反而能让根系向深处扎，抵御后期的干旱。播种后只需保持表层湿润约十天，之后交给自然，这就是要领。

| 症状 | 原因 | 应对 |
|---|---|---|
| 白天叶片闭合，晚上展开 | 是正常的节水反应 | 保持现状 |
| 早晨叶片仍闭合 | 严重干旱 | 灌溉 |
| 大量落花 | 开花期干旱或超过25℃的高温 | 灌溉与覆盖。若因高温所致则难以恢复 |
| 结荚但籽粒小 | 荚膨大期缺水 | 这一时期的灌溉直接决定产量 |
| 下部叶片发黄，茎基部变软 | 过湿导致的根腐病 | 挖排水沟 |
| 叶片出现红褐色斑点并扩散 | 锈病，多发于潮湿通风不良时 | 摘除病叶，保证通风 |
| 下方豆荚出现黑斑 | 泥水溅起后霉菌附着 | 薄铺稻草防止泥土溅起 |

&nbsp;&nbsp;&nbsp;覆盖在小扁豆栽培中有两个目的：省水和防止泥土溅起。薄薄铺一层稻草或稻壳，能防止雨滴溅起泥土沾污下方豆荚，从而减少霉害。但如果铺得太厚导致土壤持续潮湿，反而会让病害增多，因此应铺2-3cm左右的薄层，并在梅雨季（6月下旬至7月）撤去一部分以保证通风。
