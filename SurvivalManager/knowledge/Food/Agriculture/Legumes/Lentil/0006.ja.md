## 13. 採種

| 項目 | 方法 |
|---|---|
| 採種個体の選抜 | さび病の症状がなく、萎凋病が発生している畑で最後まで生き残り、鞘がたくさんついている株を畑であらかじめ目印しておきます |
| 収穫時期 | 鞘が完全に茶色に変わった後に収穫します。ただし裂ける前に |
| 分離 | 別に脱穀します。手でこすれば実が傷みません |
| 選別 | 割れた実、斑点、変色、小さい実はすべて捨てます |
| 乾燥 | 水分12%以下。陰でゆっくり乾かします |
| 保管 | 密閉容器に入れ、涼しく暗い場所に置きます。食用とは別の容器にします |
| 保管期間 | 常温密閉3-4年 |
| 更新 | 入手できるなら3-4年ごとに別の場所の種子を一部混ぜます |

> **レンズマメは、韓国国内で植え付け可能な種子を再度入手するのが非常に難しい作物です。市販の食用レンズマメは大半が発芽しません。採種は選択ではなく、この作物を続けて育てるための前提条件です。**

&nbsp;&nbsp;&nbsp;採種で最も重要な形質は、さび病への耐性と萎凋病抵抗性です。周りの株が錆色に覆われる中で一株だけきれいに残った個体、または萎凋病が発生している畑で最後まで生き残って種をつけた個体が、最も価値ある種子です。抵抗性は遺伝するため、こうした個体を選んで継いでいけば、数年のうちにその畑で持ちこたえる系統ができます。

&nbsp;&nbsp;&nbsp;二番目の形質は韓国の気候への適応です。25℃を超える天候でも鞘を結んだ個体、梅雨（チャンマ、6月下旬~7月）が来る前に先に熟した個体を選び出します。レンズマメが韓国の気候で難しい作物であるだけに、数年にわたるこの選抜が他のどの管理よりも大きな差を生みます。

&nbsp;&nbsp;&nbsp;レンズマメは自家受粉作物なので、隔離距離を心配する必要がありません。複数の系統を並べて植えても形質が混ざりません。ただし実が小さく、混ざると目で見分けるのが難しいため、系統別に別々に収穫して別々に入れ、容器にどの畑のどの年のものかを書いておきます。

| 種子の保管期間と発芽率 |
|---|
| 収穫当年：90%以上 |
| 1年経過：80-90% |
| 2年経過：70-80% |
| 3年経過：50-70% |
| 4年以降：急激に落ちます |

## 14. 毒性と抗栄養成分

&nbsp;&nbsp;&nbsp;レンズマメは豆類の中で毒性のリスクが最も低い部類に入ります。インゲンマメのように生の実数粒で中毒を起こす強いレクチンも、ソラマメのように特定の体質で急性溶血を起こす成分もありません。抗栄養成分の含量自体が豆類の中で低い方であり、これがレンズマメの調理時間が短いもう一つの理由です。

| 成分 | 働き | 症状 | 除去方法 |
|---|---|---|---|
| トリプシン阻害物質 | タンパク質分解酵素の働きを妨げます | 腹部の不快感、タンパク質利用率の低下 | 沸騰水で20-30分あれば十分です。ダイズの3分の1以下の含量です |
| レクチン | 腸の粘膜に付いて吸収を妨げます | 少量は無害です | 加熱で簡単に分解されます。インゲンマメ類と違い毒性は非常に弱いです |
| フィチン酸 | 鉄、亜鉛、カルシウムと結合して吸収を妨げます | 長く食べ続けると貧血、亜鉛欠乏 | 浸漬、発芽、発酵で60-80%まで減ります |
| オリゴ糖 | 人が消化できず腸内細菌が発酵させます | お腹にガスがたまります | 豆類の中で含量が少ない方です。煮汁を捨てるとさらに減ります |
| タンニン | 種皮の渋み成分です | 鉄の吸収を妨げます | 皮をむけばほぼなくなります |
| カビ毒 | 貯蔵中にカビが作り出します | 危険です | カビが生えたものは洗ったり加熱しても安全になりません。捨てます |

> **レンズマメで実際に人に害を与えるのは豆自体ではなく、保管を誤ってカビが生えた豆です。湿った臭いがしたり表面に青みがかった粉が見えたら、惜しまずに捨てます。**

| 処理 | 時間・温度 | 効果 |
|---|---|---|
| 浸漬 | 必要ありません | 厚さが2-3mmなのですぐに水が染み込みます |
| 煮る（皮つき） | 沸騰水で20-30分 | 形を保ったまま柔らかくなります |
| 煮る（皮をむいて割ったもの） | 沸騰水で10-15分 | 崩れて粥になります |
| 洗う | 調理前に水で洗い、浮くものを取り除きます | 埃と空の実を除きます |
| 煮え具合の確認 | 指で押すと簡単に潰れます | 芯が残っていれば煮えていません |

&nbsp;&nbsp;&nbsp;レンズマメが他の豆より消化しやすいという点も記しておく価値があります。オリゴ糖含量が少なくお腹にガスがたまりにくく、皮をむいた赤レンズマメは特に負担が少ないです。長く飢えた人、病人、高齢者、子供に豆を食べさせなければならないとき、レンズマメの粥が最も安全な選択である理由がこれです。他の豆でお腹を壊していた人でも、レンズマメなら耐えられる場合が多いです。

## 15. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;レンズマメの貯蔵性はSSです。乾燥種実は常温で3年持ち、脂質が1から2%と非常に少なく酸敗がほとんどありません。しかし種皮が薄いため、虫が入り込みやすい方です。

> **豆は腐って失うのではなく、虫に食われて失うのです。貯蔵の技術とは、すなわち虫を防ぐ技術です。**

### 15-1. まず乾燥です

| 段階 | 方法 | 確認 |
|---|---|---|
| 予備乾燥 | 茎ごと日に4-6日干すか、軒先に掛けて乾かします | 鞘がカラカラに乾きます |
| 脱穀後の乾燥 | むしろや敷物に薄く広げて日に1-2日 | 実が薄いため早く乾きます |
| 目標水分 | 食用も種子も12%以下 | 歯で噛むと歯が入らずポキッと割れます |
| 塩試験 | 乾いた塩を豆と一緒に瓶に入れて振ります | 塩が瓶の壁に付けばまだ湿っています |
| 冷ます | 日から取り込んだ後、完全に冷ましてから容器に入れます | 温かい状態で密閉すると結露が生じます |

&nbsp;&nbsp;&nbsp;レンズマメは厚さが薄いため、他の豆よりずっと速く乾きます。ダイズが二三日かかる乾燥を一日で終えられます。一方で乾きすぎると割れやすいため、強い日差しに長く置きません。午前に干して午後に取り込むリズムが適当で、風の通る陰で乾かしても十分です。

### 15-2. 貯蔵中のマメゾウムシ防除

&nbsp;&nbsp;&nbsp;マメゾウムシ類は貯蔵豆類の最大の脅威です。恐ろしいのは、畑の段階でもう始まっているという点です。まだ畑についている鞘に成虫が卵を付け、その卵が貯蔵庫の中で孵化して豆の中に入り込みます。持ち込む時点でもう卵が付いてくる構造で、一世代が一か月足らずのため、半年で袋一つが穴だらけの殻で満たされます。レンズマメは種皮が薄く、他の豆より貫通されやすいです。

| 方法 | 原理 | 適用 | 効果 |
|---|---|---|---|
| 完全密閉 | 酸素を断って窒息させます | ガラス瓶や金属缶を満たして封じます | 最も確実です。3-4週間で卵と幼虫まで死にます |
| 草木灰を混ぜる | 微細な粒子が外骨格のワックス層を削り、脱水させます | 豆の体積の2-5%を混ぜます | 実が小さいため灰がまんべんなく付きます。食べる前に水で洗います |
| 珪藻土 | ケイ酸の殻が外骨格を傷つけます | 豆1kgに1-3g | 灰より効果が大きいです。乾いた状態でのみ働きます |
| 油コーティング | 油の膜が卵の付着と孵化を防ぎます | 豆1kgに食用油3-5mLを入れて揉みます | 実が小さく表面積が大きいため油が少し多めに必要です。種子用には使いません |
| 低温処理 | 氷点下で卵と幼虫が死にます | 真冬に数日外に出してから取り込みます | 取り込む際は結露に注意します |
| 高温処理 | 60度で卵と幼虫が死にます | 日に薄く広げて半日置きます | 種子用には使いません |
| 乾燥トウガラシ・サンショウ・ヨモギ | 精油成分が産卵を抑制します | 層状に入れます | 補助的な手段です |
| 炭・炒り塩 | 湿気を吸い取ります | 布に包んで入れます | カビ予防を兼ねます |
| 灰の中に埋める | 密閉と物理的防除を同時に得ます | 甕に灰と豆を交互に重ねます | 伝統的に広く使われてきました |

&nbsp;&nbsp;&nbsp;最も重要なのは完全密閉です。虫も呼吸をします。密閉した容器の中で豆と虫が酸素を使えば酸素が減り二酸化炭素が増えて虫が死にます。豆は休眠状態なのでこの条件に耐えられます。容器を満たして空間を減らすほど効果が早く出ます。大きな容器一つより小さな容器いくつかにぎゅっと詰める方がよく、これは一つが傷んでも全部を失わないという利点も併せ持ちます。

&nbsp;&nbsp;&nbsp;草木灰を混ぜる方法はレンズマメに特に合っています。実が小さいため同じ体積でも表面積が大きく、灰が実と実の間にまんべんなく入り込んで虫が動く隙間をなくします。ふるいにかけて粗い炭のかけらを取り除き、細かい部分だけを豆の体積の2-5%混ぜます。食べる前に水で三、四回洗えばきれいになり、どうせ調理前に洗う豆なので手間はほとんどありません。虫が耐性を持つこともなく、人にも無害です。

### 15-3. 貯蔵容器と場所

| 容器 | 密閉性 | 期間 | 長所 | 短所 |
|---|:---:|---|---|---|
| ガラス瓶 | 非常に良い | 3年以上 | 状態を目で確認できます | 容量が小さく光を防げません |
| 金属缶 | 非常に良い | 3年以上 | ネズミと虫を完全に防ぎます | 結露が生じるとその部分が傷みます |
| 甕 | 良い | 2-3年 | 温度変化が緩やかでネズミが穴を開けられません | 重くて割れます |
| 厚手のビニール | 普通 | 1-2年 | 軽くて安価です | ネズミに破られ、実が小さく漏れ出します |
| 地下貯蔵穴 | 良い | 2-3年 | 温度が一定で低いです | 水が染み込むと全量を失います |

&nbsp;&nbsp;&nbsp;点検で最も頼りになる感覚は聴覚と嗅覚です。缶に耳を当てたときにカサカサという音がすれば虫が活動しており、湿った臭いがすればカビが始まっています。表面に小さな丸い穴が見えれば、バクムシが一世代を超えた状態です。このときでも全量を取り出して日に干し、水に浮かせて空の実を取り除き、灰を混ぜて再び密閉すれば、残りの分を守れます。二か月に一回の点検が基準です。

## 16. 調理と加工 - 燃料が最も少なくて済む豆

### 16-1. 皮をむいて割る

&nbsp;&nbsp;&nbsp;レンズマメ加工の核心は、皮をむいて半分に割ることです。市販で赤レンズマメと呼ばれる形態がこれで、褐色レンズマメの皮をむくと内側が橙色を帯びていて赤く見えます。この形にすると調理時間が20分から10分に減り、水に溶けて粥になります。

| 順序 | 内容 |
|---|---|
| 1 | 乾燥レンズマメを水に少し浸して表面を軽く湿らせます |
| 2 | 半日陰に置いて皮だけに水分を含ませます |
| 3 | 臼に入れてごく軽くつきます。実を割るのではなく皮をむく程度に |
| 4 | 箕やうちわであおいで、むけた皮を飛ばします |
| 5 | 残った実を再び軽くつくと二つに割れます |
| 6 | 完全に乾かして密閉保管します |

&nbsp;&nbsp;&nbsp;皮をむいたレンズマメは貯蔵性が落ちます。種皮という防御膜がなくなり、虫が入りやすく崩れやすくもなります。そのため一度に全部加工せず、一、二か月で食べる分だけ作るのが原則です。貯蔵は皮つきのまま、加工は少しずつというのが基本です。むいた皮は捨てずに集めて家畜の餌や堆肥に使います。

### 16-2. 燃料を節約する調理

| 方法 | 燃料 | 手順 |
|---|:---:|---|
| 皮をむいたレンズマメの粥 | 最も少ない | 水に入れて10-15分で崩れます |
| 皮つきで煮る | 少ない | 20-30分。形が保たれ、和え物やあえものに使います |
| 余熱調理 | 非常に少ない | 5分煮た後火を止め、布団や藁の箱で包んで1時間置きます |
| 炒りレンズマメ粉 | ほとんどなし | 炒って挽いておき、水に溶いて食べます |
| 発芽 | なし | 芽を出させればそのまま食べられる状態になります |
| 穀物と一緒に炊く | 追加なし | ご飯や粥に一緒に入れれば別に火を使う必要がありません |

> **レンズマメの価値は、ご飯を炊くときに米と一緒に入れれば、別に火を焚かずともタンパク質が食卓に上るという点にあります。他のどの豆もこれができません。**

&nbsp;&nbsp;&nbsp;この一点が、燃料不足の状況でのレンズマメの位置を決めます。ダイズやヒヨコマメをご飯に混ぜるには前もって浸水させ別に煮る必要がありますが、レンズマメは米と同じ時間で煮えます。皮をむいたものならむしろ米より早く煮え、後から入れるべきほどです。毎食別に火を焚かないということは、一年分積み重なれば相当な量の薪を節約することになります。

&nbsp;&nbsp;&nbsp;余熱調理もレンズマメでは、ほぼ完全に機能します。5分だけ煮て保温箱に入れておけば一時間以内にすべて煮えます。藁やもみ殻を詰めた木箱、または厚い布団で鍋を丸ごと包めば、それが保温箱です。レンズマメには完全に分解する必要がある強い毒性成分がないため、余熱調理でも安全に調理できます。

### 16-3. 発芽と貯蔵加工

| 方法 | 手順 | 価値 |
|---|---|---|
| 発芽 | 8時間浸してから水を切り、濡れた布で覆って2-3日 | ビタミンCが新たに生成され、フィチン酸が減り、消化しやすくなります |
| レンズマメ粉 | 炒って挽きます | 密閉3-6か月。脂質が少なく長持ちします |
| レンズマメのチヂミ | 浸したレンズマメをすりつぶして生地にし、薄く焼きます | インドのドーサと同じ原理です |
| 発酵生地 | すりつぶして一晩置くと酸味を帯びて発酵します | 膨らみ消化しやすくなります |
| 湯通し後乾燥 | 煮て乾かしておき、水で戻して使います | 調理時間をさらに短縮します |

&nbsp;&nbsp;&nbsp;レンズマメは芽を出させるのが最も簡単な豆の一つです。8時間浸してから水を切り、濡れた布で覆って二、三日置くと1cmほどの芽が出ます。この過程で乾いた豆になかったビタミンCが作られ、フィチン酸や阻害物質が減り、消化がずっと楽になります。冬に新鮮な野菜がないとき、この発芽がビタミンC欠乏を防ぐ安価な手段になります。レンズマメの新芽は他の豆の芽と違い、ほんの軽く湯通しするだけでよく、実が小さいため数日で食べられる量が出来上がります。

### 17-1. 忘れてはならない五つのこと

| 項目 | 内容 |
|---|---|
| 種子確認 | 市販の赤レンズマメは割ったものなので発芽しません。植える前に必ず発芽試験を行います |
| 作型 | 韓国の気候では収まる場所が狭いです。高冷地の春、晩夏、韓国南部の越冬に分けて播いてみます |
| 雑草 | 最も雑草に弱い豆類です。最初の一か月がすべてです |
| 燃料 | ご飯に一緒に入れれば別に火を使う必要がありません。これがレンズマメの最大の価値です |
| 収穫時期 | 下から三番目の鞘が音を出すとき。上を待てば下を失います |
