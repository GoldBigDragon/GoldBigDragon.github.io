## 3. 栽培环境

### 3-1. 气温与光照量

| 条件 | 极限值 | 最适值 | 超出时 |
|---|---|---|---|
| 发芽温度 | 4℃以上 | 18-22℃ | 低温下也能缓慢发芽 |
| 生长温度 | 5-28℃ | 15-20℃ | 超过25℃结实变差 |
| 结实温度 | 15-27℃ | 17-22℃ | 幅度12℃ |
| 开花期高温 | 25℃以上持续数日 | - | 落花，不结荚 |
| 耐寒性 | 零下5℃为止 | - | 幼株可度过轻度的冬天 |
| 光照 | 每天6小时以上 | 每天8小时以上 | 40%遮光时产量降至一半 |

> **小扁豆难以适应韩国气候的原因，是两个因素叠加造成的。超过25℃结实就会失败，灌浆期连续降雨则病害会大爆发。韩国的夏季恰好同时带来这两者。**

&nbsp;&nbsp;&nbsp;解决这一限制的途径有三种。第一，高冷地。在海拔400m以上的凉爽地区，可以春播，6月至7月收获，这是小扁豆在韩国最适合的位置。第二，晚夏播种。8月末到9月初播种，让作物在转凉的秋季生长，11月到12月收获，但灌浆期会赶上寒冷，籽粒有可能长不饱满的风险。第三，在韩国南部秋播越冬，翌年初夏收获的种植方式。耐寒性A让这种方式成为可能，但零下5度是极限，因此只有在韩国南部沿海地区才稳定。

&nbsp;&nbsp;&nbsp;只能三种方式都试一试，找出适合当地的方案。因为种子珍贵，最初把种子分成三份，分别按三种种植方式少量播种，观察哪种能存活下来，这样比较安全。

### 3-2. 土壤与水分

| 条件 | 极限值 | 最适值 | 备注 |
|---|---|---|---|
| 土质 | 沙质土到壤土 | 排水良好的沙壤土-壤土 | 避开黏土质和积水的土地 |
| pH | 5.5-8.0 | 6.0-7.5 | 喜中性至弱碱性 |
| 有效土层 | 40cm以上 | 60cm以上 | 直根扎得深 |
| 生长期蒸散量 | - | 约250mm | 豆类中最少的一档 |
| 淹水 | 淹没超过1天根系就会受损 | - | 极不耐湿涝 |
| 垄高 | 15cm以上 | 20cm以上 | 使下方豆荚不接触泥土 |

&nbsp;&nbsp;&nbsp;在小扁豆栽培中，起高垄的目的不只是排水。豆荚贴近地面结生，下雨时泥水会溅到豆荚上，霉菌就从那里开始滋生。把垄起高，再薄薄铺一层稻草防止泥土溅起，能大幅减少这种损害。稻草覆盖也有省水的效果，但如果铺得太厚导致持续潮湿，反而会让病害增多，因此应薄铺，并在梅雨季（6月下旬至7月）前撤去一部分。

## 4. 品种

### 4-1. 按颜色与加工形态分类

| 类别 | 特征 | 烹饪时间 | 用途 |
|---|---|:---:|---|
| 褐色小扁豆 | 最常见，带皮，能保持形状 | 20-25分钟 | 多用途，用于汤、炖菜、拌入米饭 |
| 绿色小扁豆 | 籽粒大，口感偏硬 | 25-30分钟 | 凉拌菜、拌菜、炒菜 |
| 红・黄小扁豆 | 去皮切开的加工形态 | 10-15分钟 | 粥、汤、咖喱，会煮散 |
| 黑色小扁豆 | 颗粒小而硬 | 20-25分钟 | 蛋白质含量特别高 |

> **红小扁豆和黄小扁豆不是品种，而是加工形态。它们是去皮后一分为二的形态，绝对不会发芽。把市售的红小扁豆种到地里，什么都长不出来。**

&nbsp;&nbsp;&nbsp;这个区分必须牢记。为灾害应对储备小扁豆时，要把食用份和种植份分开考虑，种植份必须是带皮完好的褐色或绿色小扁豆。而即便如此，也可能因流通过程中的热处理或熏蒸而失去发芽力，所以拿到手后必须先用少量做发芽试验：把二十粒种子包在湿布中放置数天，数一数发芽的数量即可。

&nbsp;&nbsp;&nbsp;从烹饪角度看，两者兼备才理想。带皮的褐色小扁豆耐储性好，也能当种子用；去皮切开的红小扁豆最省燃料。可以先把褐色小扁豆存起来，需要时用臼捣去皮做成红小扁豆的形态，因此原则是：整粒带皮贮藏，只按食用量加工。

### 4-2. 按情形选择的标准

| 情形 | 优先选择 | 理由 |
|---|---|---|
| 用作种子 | 带皮完好的褐色·绿色小扁豆 | 切开的不会发芽 |
| 燃料不足 | 加工成去皮切开的形态 | 10-15分钟就能煮熟 |
| 长期贮藏 | 带皮褐色小扁豆 | 种皮起防护屏障作用 |
| 病人·老人·儿童 | 红小扁豆粥 | 煮烂后易于消化 |
| 在高冷地有田 | 任何品系皆可 | 是小扁豆在韩国最合适的位置 |
| 病害流行的地块 | 从存活个体上留种 | 选育对锈病和枯萎病的抗性 |

## 5. 整地与施肥 - 根瘤菌

### 5-1. 固氮是如何发生的

&nbsp;&nbsp;&nbsp;空气中78%是氮气。尽管人们头顶飘着无穷无尽的氮气，植物却无法利用它。空气中的氮是两个氮原子以三键牢固结合的分子，要切断这个键需要巨大的能量。工业上切断这个键制造氨，就是哈伯-博施法，世界上的氮肥都由此而来，需要高温、高压、催化剂和大量化石燃料。

&nbsp;&nbsp;&nbsp;根瘤菌能在常温常压下完成这项工作。它用一种叫固氮酶的酶切断三键，把氮转化为氨。但这有代价：这个反应需要大量能量，而细菌自身无法进行光合作用。于是它们进入豆科植物的根部生活，从植物那里获得光合作用产生的糖分，作为回报把固定下来的氮交给植物。这是一种交易关系。

&nbsp;&nbsp;&nbsp;与小扁豆共生的菌是RhizobiumLeguminosarum bv. viciae，与豌豆、蚕豆、野生野豌豆所用的菌相同，和大豆或鹰嘴豆共生的菌不同。这在实用上是很大的优势：可以从种过豌豆的田地土壤，或春季田野常见的野豌豆根部获取接种源。

| 阶段 | 发生的事 |
|---|---|
| 1. 信号交换 | 小扁豆根系分泌黄酮类化合物，土壤中的细菌响应该信号释放结瘤因子 |
| 2. 侵染 | 根毛向内弯曲包住细菌，细菌沿感染丝进入根内部 |
| 3. 根瘤形成 | 根内部细胞分裂使根瘤膨大，细菌在其中定居 |
| 4. 固氮 | 根瘤内固氮酶发挥作用，把空气中的氮转化为氨 |
| 5. 分配 | 氨转化为氨基酸，运往茎、叶和豆荚 |
| 6. 衰老 | 进入灌浆期后根瘤失去功能，随根一起归还土壤 |

&nbsp;&nbsp;&nbsp;固氮酶对氧气非常敏感，一接触氧气就会立刻失去功能。因此根瘤内部充满了一种叫豆血红蛋白的红色色素蛋白，用来捕获氧气，把酶周围的氧浓度维持在极低水平。这与人血呈红色是同一原理，掰开根瘤时里面呈红色或粉红色的，就是这种色素。这一事实在实用上极为重要，因为红色是这个根瘤正在固氮的可见证据。

### 5-2. 如何确认根瘤是否形成

&nbsp;&nbsp;&nbsp;无论是否接种，都必须确认根瘤是否真正形成。不确认的话，就无法知道氮不足的原因，来年会重复同样的失误。小扁豆生育期短，发现并纠正失误的时间更加有限。

| 顺序 | 内容 |
|---|---|
| 1 | 开花开始前后，播种后约6周是最佳时机 |
| 2 | 挑选两三株看起来健康的植株 |
| 3 | 不要拔起，用铁铲在植株周围大范围铲挖，连土一起挖起 |
| 4 | 放入水桶中轻轻把泥土洗掉 |
| 5 | 数一数主根和粗侧根上生有的根瘤数量 |
| 6 | 用指甲掰开几个根瘤查看内部颜色 |

| 观察结果 | 含义 | 应对 |
|---|---|---|
| 每株结有10个以上根瘤 | 接种成功 | 保持现状 |
| 掰开后内部呈红色或粉红色 | 正在固氮 | 状态良好 |
| 掰开后内部呈白色或淡绿色 | 根瘤已形成但未固氮 | 检查酸度、湿涝、缺磷情况 |
| 掰开后内部呈褐色或黑色 | 已经衰老或死亡 | 若在灌浆期属正常，若在开花期则有问题 |
| 几乎没有根瘤 | 接种失败 | 若叶片发黄，补充少量氮肥 |

> **挖根、掰开根瘤查看红色，这一个习惯，是在没有氮肥的世界里判断种豆成败最可靠的信号。**

&nbsp;&nbsp;&nbsp;小扁豆的根瘤很小。因为植株本身就小，根瘤大小也只有小米粒到大米粒那么大，如果像大豆那样期待豌豆粒大小的根瘤，很容易误判为没有根瘤。洗净泥土后，需要在明亮处一根一根查看须根才能看到。掰开时，用刀尖比用指甲更合适。

### 5-3. 接种源从哪里获取

&nbsp;&nbsp;&nbsp;商用接种剂是把活菌装入泥炭或黏土中出售的产品，灾害情况下无法获得。但小扁豆所用的菌，是豌豆、蚕豆、野生野豌豆共用的常见菌种，因此获取接种源的途径有多种。

| 方法 | 步骤 | 效果 | 注意 |
|---|---|---|---|
| 沾取同菌系田地的土壤 | 从种过小扁豆、豌豆、蚕豆、野豌豆且根瘤长得好的田地，取表土5-15cm深处的土。将种子用水稍微润湿后沾上这些土，立即播种 | 最可靠且不花钱 | 患病田地的土壤也会带来病原菌 |
| 野生野豌豆的根 | 春天挖取田野和田埂上的野豌豆，检查根瘤。若根瘤呈红色，就把那些土和根一起使用 | 在没有种植小扁豆历史的地区最为现实 | 固氮效率可能低于栽培专用菌系 |
| 直接使用根瘤 | 收集挖出的根瘤，捣碎后化入水中，将种子浸入这种水中后取出 | 菌密度最高 | 必须在挖出根瘤当天使用 |
| 把土撒在田里 | 在播种行撒上取来的土，一起翻耕入土 | 菌能扩散到土壤中 | 每10㎡约一铲为基准 |
| 保留根系残体 | 收获时只割茎，把根留在田里 | 菌能留存到来年 | 最省事的维持方法 |

&nbsp;&nbsp;&nbsp;接种时有几点必须遵守。根瘤菌对直射光、干燥和高温非常敏感，紫外线照射几分钟就会杀死大量菌体，一旦干燥死得更快。给种子沾土的作业要在阴凉处进行，沾土后的种子不要晒，应立即播种，最好在30分钟内播完，最晚也要在几个小时内完成。还有一点，种子消毒和接种不能同时进行：给沾了杀菌剂的种子沾土，细菌会被杀死。如果用温水处理消毒过，必须完全冷却后才能接种。

| 导致接种失败的条件 | 原因 |
|---|---|
| 土壤pH 5.5以下 | 细菌无法存活 |
| 施足氮肥的田地 | 植株感觉不到交易的必要，会自行减少根瘤形成 |
| 积水的田地 | 属好氧菌，缺氧就会死亡 |
| 缺磷的田地 | 固氮需要大量能量，该代谢过程要用到磷 |
| 缺钼·铁·钴 | 是固氮酶的组成成分 |
| 把接种后的种子晒干 | 紫外线和干燥会导致菌死亡 |
| 使用大豆或鹰嘴豆田的土壤 | 菌种不同，不会感染小扁豆 |
