## 13. 留种

| 项目 | 方法 |
|---|---|
| 留种个体选择 | 提前在田里标记没有锈病症状、在枯萎病流行的地块中坚持到最后、且结荚多的植株 |
| 收获时期 | 待豆荚完全变褐后收获，但要在裂开之前 |
| 分离 | 单独脱粒。用手搓不会损伤籽粒 |
| 挑选 | 裂开的、有斑点的、变色的、过小的籽粒全部剔除 |
| 干燥 | 水分12%以下，在阴凉处慢慢晾干 |
| 贮藏 | 装入密封容器，放在阴凉黑暗处，与食用的分开存放 |
| 贮藏期 | 常温密封3-4年 |
| 更新 | 若能获得，每3-4年混入一部分其他产地的种子 |

> **小扁豆是在韩国国内很难再次获得可种植种子的作物。市售的食用小扁豆大多不会发芽。留种不是可选项，而是持续种植这种作物的前提条件。**

&nbsp;&nbsp;&nbsp;留种中最重要的性状是耐锈病与抗枯萎病能力。周围植株都被锈色覆盖时唯独保持洁净的个体，或在枯萎病流行的地块中坚持到最后并结籽的个体，是最珍贵的种子。抗性可以遗传，选育这样的个体延续下去，几年内就能在那块田里培育出耐得住的品系。

&nbsp;&nbsp;&nbsp;第二个性状是对韩国气候的适应。挑选在超过25℃的天气下仍能结荚的个体，以及在梅雨季（6月下旬至7月）到来前就已成熟的个体。正因为小扁豆是难以适应韩国气候的作物，多年持续的这种选育，比其他任何管理都能带来更大的差异。

&nbsp;&nbsp;&nbsp;小扁豆是自花授粉作物，不必担心隔离距离。即便把多个品系并排种植，性状也不会混杂。但因籽粒小，一旦混在一起就难以用肉眼分辨，所以要按品系分别收获、分别装存，并在容器上写明是哪块田哪一年的种子。

| 种子贮藏期与发芽率 |
|---|
| 收获当年：90%以上 |
| 经过1年：80-90% |
| 经过2年：70-80% |
| 经过3年：50-70% |
| 4年以后：急剧下降 |

## 14. 毒性与抗营养成分

&nbsp;&nbsp;&nbsp;小扁豆在豆类中属于毒性风险最低的一类。它既没有像菜豆那样生食几粒就会中毒的强凝集素，也没有像蚕豆那样在特定体质人群中引发急性溶血的成分。抗营养成分本身的含量在豆类中就偏低，这也是小扁豆烹饪时间短的另一个原因。

| 成分 | 作用 | 症状 | 去除方法 |
|---|---|---|---|
| 胰蛋白酶抑制剂 | 阻碍蛋白酶的作用 | 腹部不适，蛋白质利用率下降 | 沸水中煮20-30分钟即可。含量为大豆的三分之一以下 |
| 凝集素 | 附着在肠黏膜上妨碍吸收 | 少量无害 | 加热即可轻易破坏，与菜豆类不同，毒性非常弱 |
| 植酸 | 与铁、锌、钙结合阻碍吸收 | 长期食用会导致贫血、缺锌 | 通过浸泡、发芽、发酵可减少60-80% |
| 寡糖 | 人体无法消化，由肠道细菌发酵 | 导致腹部胀气 | 在豆类中含量偏低，倒掉煮水能进一步减少 |
| 鞣质 | 是种皮中的涩味成分 | 妨碍铁的吸收 | 去皮后几乎消失 |
| 霉菌毒素 | 由贮藏期间的霉菌产生 | 有危险 | 已经发霉的即便洗净或加热也不会变安全，应丢弃 |

> **小扁豆真正伤害人的，不是豆子本身，而是贮藏不当发霉的豆子。一旦有霉味或表面出现青灰色粉末，不要舍不得，直接丢弃。**

| 处理 | 时间·温度 | 效果 |
|---|---|---|
| 浸泡 | 无需浸泡 | 厚度只有2-3mm，水分立即渗入 |
| 煮（带皮） | 沸水中煮20-30分钟 | 保持形状变软 |
| 煮（去皮切开的） | 沸水中煮10-15分钟 | 煮散成粥状 |
| 清洗 | 烹饪前用水冲洗，捞去漂浮的部分 | 去除灰尘和空壳籽粒 |
| 确认熟度 | 用手指按压能轻易压碎 | 若还有硬芯说明未熟透 |

&nbsp;&nbsp;&nbsp;小扁豆比其他豆类更易消化，这一点也值得记下。寡糖含量少，腹胀较轻，去皮的红小扁豆负担尤其小。长期饥饿的人、病人、老人、儿童需要吃豆子补充营养时，小扁豆粥是最安全的选择，原因就在这里。很多吃其他豆类会闹肚子的人，吃小扁豆却往往能耐受。

## 15. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;小扁豆的耐储性为SS。干籽粒在常温下能保存3年，脂肪含量仅1到2%，几乎不会氧化酸败。但种皮薄，容易被虫蛀。

> **豆子不是因为腐烂而损失，而是被虫吃掉而损失。贮藏的技术，本质上就是防虫的技术。**

### 15-1. 干燥为先

| 阶段 | 方法 | 确认 |
|---|---|---|
| 预干燥 | 连茎在阳光下晒4-6天，或挂在屋檐下晾干 | 豆荚彻底干透 |
| 脱粒后干燥 | 摊在草垫或席子上晒1-2天 | 籽粒薄，干得快 |
| 目标水分 | 食用与种子均为12%以下 | 用牙咬时咬不进去，会脆脆地裂开 |
| 盐瓶试验 | 把干盐和豆子一起放入瓶中摇晃 | 若盐粘在瓶壁上说明仍潮湿 |
| 冷却 | 从阳光下收回后完全冷却再装入容器 | 温热状态密封会产生结露 |

&nbsp;&nbsp;&nbsp;小扁豆薄，比其他豆类干得快得多。大豆需要两三天的干燥，小扁豆一天就能完成。但另一方面，晒过头容易开裂，所以不要长时间放在强烈的阳光下。上午晒、下午收的节奏比较合适，在通风的阴凉处晾干也足够。

### 15-2. 贮藏期豆象的防治

&nbsp;&nbsp;&nbsp;豆象类是储藏豆类的最大威胁。可怕之处在于，它在田间就已经开始了。成虫在还挂在田里的豆荚上产卵，那些卵在仓库中孵化后钻入豆粒内部。也就是说，收进仓库时卵就已经附带进来，一代不到一个月，半年后一袋豆子就会变成满是虫孔的空壳。小扁豆种皮薄，比其他豆类更容易被蛀穿。

| 方法 | 原理 | 应用 | 效果 |
|---|---|---|---|
| 完全密封 | 断绝氧气使其窒息 | 装满玻璃瓶或金属罐后密封 | 最为可靠，3-4周即可连卵和幼虫一起杀死 |
| 混入草木灰 | 微细颗粒刮伤外壳蜡质层使其脱水 | 按豆子体积的2-5%混入 | 籽粒小，灰能均匀附着。食用前用水冲洗 |
| 硅藻土 | 硅质外壳会损伤外骨骼 | 每1kg豆配1-3g | 效果比灰更强，只在干燥状态下起作用 |
| 油膜涂覆 | 油膜能阻止产卵与孵化 | 每1kg豆加3-5mL食用油拌匀 | 籽粒小表面积大，用油量会略多。不用于种子 |
| 低温处理 | 零下温度可杀死卵与幼虫 | 深冬时放在室外数天后再收回 | 收回时要注意防止结露 |
| 高温处理 | 60度可杀死卵与幼虫 | 薄摊在阳光下放置半天 | 不用于种子 |
| 干辣椒·花椒·艾草 | 精油成分能抑制产卵 | 分层放入 | 是辅助手段 |
| 炭·炒盐 | 吸收湿气 | 用布包好放入 | 兼具防霉效果 |
| 埋入灰中 | 同时获得密封与物理防治的效果 | 在陶罐中灰与豆交替堆叠 | 传统上被广泛使用 |

&nbsp;&nbsp;&nbsp;最重要的是完全密封。虫子也要呼吸。在密封的容器里，豆子和虫子共同消耗氧气，氧气减少、二氧化碳升高，虫子就会死亡。豆子处于休眠状态，能耐受这种条件。容器装得越满、空隙越少，效果越快。比起一个大容器，分装进几个小容器并塞得紧实更好，这样即使一罐坏了也不会损失全部。

&nbsp;&nbsp;&nbsp;混入草木灰的方法特别适合小扁豆。籽粒小，同样体积下表面积大，灰能均匀渗入籽粒之间，消除虫子活动的空隙。用筛子筛去粗炭块，只把细的部分按豆子体积的2-5%混入。食用前用水冲洗三四次就能洗净，反正烹饪前本来就要洗豆，几乎不算麻烦。虫子无法产生抗性，对人也无害。

### 15-3. 贮藏容器与场所

| 容器 | 密封性 | 期限 | 优点 | 缺点 |
|---|:---:|---|---|---|
| 玻璃瓶 | 非常好 | 3年以上 | 能用眼睛确认状态 | 容量小，不能遮光 |
| 金属罐 | 非常好 | 3年以上 | 能完全防鼠防虫 | 一旦结露那部分就会受损 |
| 陶罐 | 好 | 2-3年 | 温度变化缓慢，老鼠咬不穿 | 沉重且易碎 |
| 厚塑料袋 | 一般 | 1-2年 | 轻便廉价 | 会被老鼠咬破，籽粒小容易漏出 |
| 地下窖藏 | 好 | 2-3年 | 温度低且稳定 | 一旦渗水会损失全部 |

&nbsp;&nbsp;&nbsp;检查时最可靠的感觉是听觉和嗅觉。把耳朵贴在罐子上如果听到沙沙声，说明虫子在活动；如果有霉味，说明霉变已经开始。表面出现小圆孔，说明豆象已经经历了一代。即便到了这个地步，把全部取出晒干，放入水中捞去空壳籽粒，混入灰后重新密封，仍能保住剩下的部分。检查的基准是每两个月一次。

## 16. 烹饪与加工 - 耗燃料最少的豆类

### 16-1. 去皮切开

&nbsp;&nbsp;&nbsp;小扁豆加工的核心是去皮后一分为二。市面上称为红小扁豆的形态就是这样制成的：褐色小扁豆去皮后内部呈橙色，看起来偏红。做成这种形态后，烹饪时间从20分钟缩短到10分钟，并会在水中煮散成粥状。

| 顺序 | 内容 |
|---|---|
| 1 | 把干小扁豆稍微沾水，使表面微微湿润 |
| 2 | 放在阴凉处半天，让只有皮吸收水分 |
| 3 | 放入臼中轻轻捣，力度只到去皮的程度，不要捣碎籽粒 |
| 4 | 用簸箕或扇子扬去脱落的皮 |
| 5 | 把剩下的籽粒再轻捣一次，就会分成两半 |
| 6 | 彻底晒干后密封保存 |

&nbsp;&nbsp;&nbsp;去皮的小扁豆耐储性会下降。种皮这道防护屏障消失后，虫子容易侵入，也更容易碎裂。因此原则是不一次性全部加工，只做够一两个月吃的量。基本原则是整粒带皮贮藏，按小份加工。剥下的皮不要丢弃，收集起来用作家畜饲料或堆肥。

### 16-2. 省燃料的烹饪

| 方法 | 燃料 | 步骤 |
|---|:---:|---|
| 去皮小扁豆粥 | 最少 | 放入水中10-15分钟即可煮散 |
| 带皮煮 | 少 | 20-30分钟，能保持形状，用于凉拌菜 |
| 余热焖煮 | 非常少 | 煮5分钟后关火，用被子或稻草箱包裹放置1小时 |
| 炒小扁豆粉 | 几乎不需要 | 炒熟磨粉，用水冲调食用 |
| 发芽 | 不需要 | 发芽后即可直接食用 |
| 与谷物同煮 | 无需额外燃料 | 与米饭或粥一起煮，不需要额外起火 |

> **小扁豆的价值在于，煮饭时和大米一起放入，不必另外起火就能让蛋白质端上餐桌。其他任何豆类都做不到这一点。**

&nbsp;&nbsp;&nbsp;仅这一点，就决定了小扁豆在燃料短缺情况下的地位。大豆或鹰嘴豆要拌入米饭，得提前泡水另外煮，但小扁豆和大米同时间就能煮熟。如果是去皮的，甚至比大米更快煮熟，需要后放才行。每餐不必另外起火，累积一年下来能省下相当可观的柴火。

&nbsp;&nbsp;&nbsp;余热焖煮在小扁豆身上几乎能完全发挥作用。只煮5分钟后放入保温箱，一小时内就能全部煮熟。用装满稻草或稻壳的木箱，或用厚被子把锅整个包起来，那就是保温箱。小扁豆没有需要彻底破坏的强毒性成分，所以余热焖煮也能安全煮熟。

### 16-3. 发芽与贮藏加工

| 方法 | 步骤 | 价值 |
|---|---|---|
| 发芽 | 浸泡8小时后沥水，盖上湿布放置2-3天 | 新生成维生素C，植酸减少，更易消化 |
| 小扁豆粉 | 炒熟后磨粉 | 密封可存3-6个月，脂肪少，能保存较久 |
| 小扁豆煎饼 | 把泡过的小扁豆磨成糊，摊薄煎制 | 与印度多萨（dosa）原理相同 |
| 发酵面糊 | 磨碎后放一夜会发酸发酵 | 会膨胀且更易消化 |
| 煮后晾干 | 煮过晒干存放，用时泡水还原 | 能进一步缩短烹饪时间 |

&nbsp;&nbsp;&nbsp;小扁豆是最容易发芽的豆类之一。浸泡8小时后沥水，盖上湿布放置两三天，就能长出约1cm的芽。在这个过程中，干豆中原本没有的维生素C会生成，植酸和抑制物质会减少，消化也变得容易得多。冬天没有新鲜蔬菜时，这种发芽是预防维生素C缺乏的廉价手段。小扁豆的芽菜和其他豆芽不同，只需极轻微地焯一下即可，而且籽粒小，几天就能长出够吃的量。

### 17-1. 不可忘记的五件事

| 项目 | 内容 |
|---|---|
| 确认种子 | 市售红小扁豆是切开的，不会发芽，种植前必须做发芽试验 |
| 种植方式 | 在韩国气候下适宜空间狭窄，可分别尝试高冷地春播、晚夏播种、韩国南部越冬种植 |
| 杂草 | 是最不耐杂草的豆类，头一个月就是一切 |
| 燃料 | 与米饭一起煮就不需要额外起火，这是小扁豆最大的价值 |
| 收获时期 | 从下往上数第三个豆荚发出声音时，等上部就会损失下部 |
