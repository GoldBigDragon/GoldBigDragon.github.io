## 5. 畑の準備と肥料 - 窒素収支と施肥

### 5-4. 窒素固定の落とし穴

&nbsp;&nbsp;&nbsp;豆を植えれば土地が良くなるという話は、農業の常識として定着しています。半分は正しく半分は間違っています。この点を正しく理解していないと、マメ科を何年も続けて植えた畑がむしろ痩せていくことが起こります。

&nbsp;&nbsp;&nbsp;数字で確認してみましょう。レンズマメがよく育てば、1,000㎡で150kgの乾燥種実を収穫します。レンズマメの種実のタンパク質は22.6%で、タンパク質を6.25で割ると窒素量が出ます。22.6 ÷ 6.25は3.62、つまり種実重量の約3.6%が純粋な窒素です。150kgに含まれる窒素は約5.4kgで、ヘクタールに換算すると54kgです。

&nbsp;&nbsp;&nbsp;一方、レンズマメの根粒が固定する窒素は、条件が良いときヘクタール当たり60kgから100kgです。植物が小さい分、絶対量はソラマメやダイズより少ないですが、種実の持ち出し量も同様に少ないため、バランスはむしろ悪くありません。出ていくものと入ってくるものを並べると、次のようになります。

| 項目 | ヘクタール当たり窒素 | 方向 |
|---|---|---|
| 根粒固定量（条件良好） | 60-100kg | 入る |
| 根粒固定量（条件不良） | 15-35kg | 入る |
| 種実として持ち出し | 45-60kg | 出る |
| 茎葉（茎と葉）に残る窒素 | 15-25kg | 畑に戻せば残る、焼くか運び出せば出る |
| 根と根粒に残る窒素 | 8-15kg | 大抵は畑に残ります |

&nbsp;&nbsp;&nbsp;この表から分かるのは接種の重要性です。接種が成功して固定量が80kgなら、種実を持ち出しても窒素が残ります。接種が失敗して20kgにとどまれば、種実として50kgが出ていき、畑は確実に損をします。レンズマメにおいて接種は、収量だけの問題ではなく畑の持続可能性の問題でもあります。

> **マメ科が土地を良くするのは窒素を固定するからではなく、固定した窒素の一部を茎と葉に蓄えて畑に残しておくからです。その茎と葉を持ち出せば、豆は土地を奪う作物になります。**

&nbsp;&nbsp;&nbsp;レンズマメの茎葉は量が少なく細いため、還元しやすいです。脱穀した後に残る茎は手で崩れるほど細く、畑にまいておけば数週間で朽ちます。ダイズの豆殻のように太くて丈が強くないため、切る必要さえありません。戻さない理由がないわけです。ただし病気の残渣だけは選り分けて焼きます。レンズマメのさび病と萎凋病は残渣に残って翌年に持ち越されます。

| 原則 | 内容 |
|---|---|
| 茎葉は必ず畑へ | 脱穀後に残る茎と葉をそのまま畑にまきます |
| 焼かない | 焼くと窒素が気体になって飛び、カリウムとリン酸だけが灰に残ります |
| 根は掘らない | 地面近くで刈り、根は残します |
| 病気の残渣は選別する | さび病と萎凋病が残渣に持ち越されます。これだけ焼きます |
| 接種を欠かさない | 接種の失敗は収量の損失であり窒素の奪取でもあります |
| 家畜に与えたなら糞を戻す | 茎葉を家畜に与えたなら、その家畜の糞尿を必ずその畑に入れます |

### 5-5. 畑の準備

| 項目 | 方法 | 災害時の条件で |
|---|---|---|
| 耕耘 | 20-30cmの深さで耕し、均一に整地します | 種子が小さいため土を細かく均すことが特に重要です |
| 畝 | 高さ15-20cm以上 | 排水とともに下側の鞘が土に触れるのを防ぎます |
| 排水路 | 深さ30cm以上 | 湿害に弱いです |
| 酸度調整 | pH 6.0-7.5 | 播種3-4週間前に前もって行います |
| 石灰 | 酸性土（pH 6.0未満）に苦土石灰 | 貝殻・卵の殻を焼いて砕いたもの、または草木灰で代用します |
| 有機物 | 完熟堆肥1,000-1,500kg/1,000㎡ | 元肥として入れます |

&nbsp;&nbsp;&nbsp;土を細かく均す作業は、レンズマメでは他の作物より重要です。種子が小さく播種深さが2-5cmと浅いため、土塊が大きいと種子が塊の間の隙間に落ちて乾いたり、逆に深く埋もれたりします。耕した後、レーキや木の板で表面を何度も均一にこすり、細かい土にしておくことで発芽が揃います。

### 5-6. 施肥量

| 肥料 | 1,000㎡基準 | ㎡換算 | 備考 |
|---|---|---|---|
| 窒素 | 0-2kg | 0-2g | ほとんど必要ありません。多く与えると窒素固定が抑制されます |
| リン酸 | 20-30kg | 20-30g | 全量元肥です。根の発達と開花に必須です |
| カリウム | 3-5kg | 3-5g | 全量元肥です |
| 堆肥 | 1,000-1,500kg | 1-1.5kg | 完全に発酵したものを使います |
| 石灰 | 酸性土に限る | - | 播種3-4週間前 |

> **レンズマメで窒素を控えるのは節約ではなく技術です。多く与えると茎と葉だけが茂ってお互いを覆い、風通しが悪くなってさび病が広がり、鞘はむしろ減ってしまいます。**

&nbsp;&nbsp;&nbsp;追肥は原則として必要ありません。ただし生育期間が短いため、初期に目立って生育が悪いと、そのまま一年を失います。本葉が三、四枚の頃に葉が全体的に薄い黄色を帯びて育たない場合は、尿を水で10倍に希釈し、株間の土にごく少量注ぎます。葉に触れないようにし、この時期を逃すと後で与えても効果がありません。

### 5-7. 災害時の代替肥料

| 代替資源 | 供給する栄養素 | 使用法 | 注意 |
|---|---|---|---|
| 骨粉 | リン酸、カルシウム | 焼いて砕き、堆肥に混ぜます | レンズマメの高いリン酸要求を満たす鍵です |
| 魚の骨・内臓 | リン酸、窒素 | 埋めて腐熟させてから使います | そのまま埋めると動物が掘り出します |
| 草木灰 | カリウム、リン酸、カルシウム | ㎡当たり100-150gをまいて混ぜます | アルカリ性です。レンズマメは弱アルカリを好むため余裕があります |
| 腐熟堆肥 | 総合 | ㎡当たり1-1.5kgを元肥として入れます | 未熟なものは根を傷め病気を運びます |
| 薄めた尿 | 窒素、カリウム | 水で10倍に希釈し、株間の土に注ぎます | ごく少量のみ。初期の生育不良時に限ります |
| 貝殻・卵の殻 | カルシウム | 焼いて砕いてまきます | 石灰の代用です。反応が遅いです |
| 落ち葉の腐葉土 | 総合、有機物 | 土に混ぜ込みます | 保水性を良くします |
| もみ殻・稲わら | カリウム、ケイ酸 | 薄くマルチングします | 土が跳ねて鞘に付くのを防ぎます |

&nbsp;&nbsp;&nbsp;リン酸20-30kgは窒素の十倍を超える量です。レンズマメの根の発達と窒素固定のエネルギー代謝がいずれもリン酸を要求するためです。化学肥料がない条件でリン酸を得る経路は、骨粉と魚の骨が実質的にほぼすべてです。動物の骨を集めて火で焼いてよく砕けるようにした後、臼でついて堆肥に混ぜておくと、数年にわたってゆっくり溶け出てきます。

## 6. 播種

### 6-1. 播種時期

| 作型 | 播種時期 | 収穫時期 | 適用 |
|---|---|---|---|
| 高冷地の春栽培 | 3月中旬-4月初旬 | 6月-7月 | 海抜400m以上。最も安定しています |
| 晩夏播種 | 8月末-9月初 | 11月-12月 | 平地。登熟期が寒さにかかる危険があります |
| 韓国南部の越冬栽培 | 10月中下旬 | 翌年5-6月 | 韓国南部の海岸。マイナス5度が限界です |

&nbsp;&nbsp;&nbsp;三つの作型はいずれも韓国の気候では条件付きです。レンズマメの生理は地中海性気候に合わせられており、韓国の夏はその基準からすると暑すぎて湿度も高すぎます。高冷地があればそこが答えで、なければ晩夏播種と韓国南部での越冬栽培を試してみるべきです。

> **種子が貴重な作物なので、一つの作型に全部を賭けません。最初の数年は三つの作型に少しずつ分けて播き、その土地で何が生き残るかを確認するために使います。**

&nbsp;&nbsp;&nbsp;晩夏播種のコツは、初霜の日から逆算することです。レンズマメは100-110日必要ですが、秋は気温が下がり生育が遅くなるため、初霜前に登熟を終えるのは難しいです。そのため、レンズマメがマイナス5℃に耐えるという点を利用して、軽い霜を受けながら最後の登熟を進める方式になります。完全に熟していない状態で霜が強くなったら、収穫して室内でさらに乾かします。

### 6-2. 種子の準備

| 項目 | 方法 | 災害時の条件で |
|---|---|---|
| 発芽試験 | 濡れた布に20粒を包んで数日置き、芽が出る数を数えます | レンズマメでは最初にすべきことです |
| 選別 | 割れたり色が変わった種子を捨てます | 割れた粒は発芽しません |
| 洗浄 | ふるいに入れて水で洗います | 埃や屑を洗い流します |
| 温水消毒 | 50-55℃の水に10-15分浸けます | 種子伝染性の病原菌を殺します |
| 灰処理 | 細かい草木灰をまぶします | 消毒と乾燥を助け、鳥やアリを遠ざける効果があります |
| 根粒接種 | 同じ菌系統のマメ科を育てた畑の土をまぶします | 5-3節参照。消毒と同時には行いません |
| 浸漬 | 土が乾いた条件でのみ12-24時間 | 種皮が薄く長く浸けると柔らかくなりすぎます |

&nbsp;&nbsp;&nbsp;発芽試験は、レンズマメでは形式的な手続きではありません。市販の食用レンズマメは皮をむいて割ったものや熱処理を受けたものが多く、まったく芽が出ません。畑に全部播いた後で気づけば、その年をまるごと失います。種子を入手したら、何よりも先に二十粒を濡れた布に包んで数日置いて確認します。半分以上が芽を出せば使えますが、三、四粒しか出なければ種子として使わず食べる方がよいです。

### 6-3. 播種方法

| 項目 | 基準 | 理由 |
|---|---|---|
| 播種深さ | 2-5cm | 種子が小さいため深いと出てこられません |
| 種子間隔 | 8-10cm | |
| 条間 | 30-40cm | 通風を確保します |
| 播種量 | 5-6kg/1,000㎡ | 豆類の中では少ない方です |
| 播種方式 | 条播または散播 | 粒が小さく点播より条播が効率的です |

&nbsp;&nbsp;&nbsp;レンズマメは粒が小さいため、一粒ずつ播く点播は効率が悪いです。浅い溝を作って種子を流し播きし土をかぶせる条播が現実的で、畑が広ければ散播してレーキで軽くかき混ぜて覆う方式も使います。ただし散播は除草が難しくなるため、雑草に弱いレンズマメでは条播が総じて優れています。

&nbsp;&nbsp;&nbsp;植え付け密度はやや密な方が良いです。レンズマメは巻きひげが弱く株どうしで支え合いますが、疎らに植えると支える相手がなく倒れます。密に植えると互いに支え合い、地面を早く覆って雑草も抑えます。ただし密すぎると通風が悪くなりさび病が広がるため、条間は十分に取り、条内で密にする配置が適当です。

&nbsp;&nbsp;&nbsp;播種直後の脅威は鳥とアリです。種子が小さく浅く埋まっているため、アリが持ち去ります。細かい草木灰を種子にまぶすとアリの接近が減り、播種した筋の上に藁を薄くかぶせると鳥と乾燥を同時に防げます。

## 7. 水管理

| 時期 | 水管理 | 理由 |
|---|---|---|
| 播種から発芽まで | 土がカラカラに乾かないようにします | 浅く埋まっているため表層が乾くと発芽が止まります |
| 生育初期 | 自然の降水に任せます | 乾燥が根を深く伸ばさせます |
| 開花期から莢肥大期 | 乾燥が激しければ灌水します | この時期の水不足が収量を最も大きく減らします |
| 登熟期 | 灌水を中止します | 過湿になると脱粒とカビが起こります |
| 雨が続く時 | 排水路を作ります | 下側の鞘が土に触れると腐ります |

&nbsp;&nbsp;&nbsp;レンズマメの水管理で特異な点は、発芽期とその後が正反対だということです。種子が浅く埋まっているため発芽期には表層が乾いてはいけませんが、一度芽が出た後は、乾燥した条件が根を深く伸ばさせ、後の乾燥に耐えられるようにします。播いてから十日ほどだけ表層を湿らせておき、その後は自然に任せるのがコツです。

| 症状 | 原因 | 対応 |
|---|---|---|
| 日中に葉が閉じ、夕方に開く | 正常な水分節約反応です | そのままにします |
| 朝になっても葉が閉じている | 深刻な乾燥 | 灌水します |
| 花が大量に落ちる | 開花期の乾燥または25℃を超える高温 | 灌水とマルチング。高温が原因なら回復が難しいです |
| 鞘はついたが実が小さい | 莢肥大期の水不足 | この時期の灌水が収量を直接左右します |
| 下葉が黄色くなり茎の根元が柔らかくなる | 過湿による根腐れ | 排水路を作ります |
| 葉に赤褐色の斑点が出て広がる | さび病。湿気が多く通風が悪いとき | 病気の葉を取り除き通風を確保します |
| 下側の鞘に黒い斑点ができる | 泥水が跳ねてカビが付きました | 藁を薄く敷いて土が跳ねないようにします |

&nbsp;&nbsp;&nbsp;マルチングはレンズマメでは二つの目的で使います。水を節約することと、土が跳ねないようにすることです。藁やもみ殻を薄く敷けば、雨粒が土を跳ね上げて下側の鞘に付くのを防ぎ、カビの被害が減ります。ただし厚く覆って土が常に湿っていると逆に病気が増えるため、2-3cmほど薄く敷き、梅雨時期（チャンマ、6月下旬~7月）には一部を取り除いて通風を確保します。
