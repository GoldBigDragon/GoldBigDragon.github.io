## 3. 栽培環境

### 3-1. 気温と光量

| 条件 | 限界値 | 最適値 | 外れた場合 |
|---|---|---|---|
| 発芽温度 | 4℃以上 | 18-22℃ | 低い温度でもゆっくり発芽します |
| 生育温度 | 5-28℃ | 15-20℃ | 25℃を超えると結実が悪くなります |
| 結実温度 | 15-27℃ | 17-22℃ | 幅12℃です |
| 開花期高温 | 25℃以上が数日 | - | 花が落ち、鞘がつきません |
| 耐寒性 | マイナス5℃まで | - | 幼い株は軽い冬を越せます |
| 日照 | 1日6時間以上 | 1日8時間以上 | 40%遮光で収量が半分に落ちます |

> **レンズマメを韓国の気候に置きにくい理由は、二つが重なるからです。25℃を超えると結実が崩れ、登熟期に雨が続くと病気が爆発します。韓国の夏はその両方を同時にもたらします。**

&nbsp;&nbsp;&nbsp;この制約を解く道は三つあります。第一に、高冷地です。海抜400m以上の涼しい場所では、春に播いて6月から7月に収穫できます。韓国でレンズマメに最も適した場所です。第二に、晩夏播種です。8月末から9月初めに播いて涼しくなる秋に育て、11月から12月に収穫します。ただし登熟期が寒さにかかり、実がよく熟さない危険があります。第三に、韓国南部で秋に播いて冬を越させ、翌年初夏に収穫する作型です。耐寒性Aがこの可能性を開いてくれますが、マイナス5度が限界なので韓国南部の海岸地域でのみ安定します。

&nbsp;&nbsp;&nbsp;三つとも試してみて、その土地に合うものを見つけるしかありません。種子が貴重な作物なので、最初は三つの作型に少しずつ分けて播き、どれが生き残るかを見るのが安全です。

### 3-2. 土壌と水

| 条件 | 限界値 | 最適値 | 備考 |
|---|---|---|---|
| 土性 | 砂質土から埴土まで | 排水の良い砂壌土-埴土 | 粘土質土壌と水が溜まる土地は避けます |
| pH | 5.5-8.0 | 6.0-7.5 | 中性から弱アルカリを好みます |
| 有効土層 | 40cm以上 | 60cm以上 | 直根が深く入ります |
| 作期蒸発散量 | - | 約250mm | 豆類の中で最も少ない部類です |
| 浸水 | 1日以上浸かると根が傷みます | - | 湿害に非常に弱いです |
| 畝の高さ | 15cm以上 | 20cm以上 | 下側の鞘が土に触れないようにします |

&nbsp;&nbsp;&nbsp;レンズマメで畝を高くする目的は排水だけではありません。鞘が地面近くにつくため、雨が降ると泥水が跳ねて鞘に付き、その場所からカビが始まります。畝を高くして藁を薄く敷いて土が跳ねないようにすると、この被害が大きく減ります。藁マルチングは水を節約する効果も併せ持ちますが、厚く覆って常に湿った状態が続くとむしろ病気が増えるため、薄く敷いて梅雨（チャンマ、6月下旬~7月）の前に一部を取り除きます。

## 4. 品種

### 4-1. 色と加工形態による分類

| 区分 | 特徴 | 調理時間 | 用途 |
|---|---|:---:|---|
| 褐色レンズマメ | 最も一般的です。皮つきで形が保たれます | 20-25分 | 多目的。汁物、煮物、ご飯に混ぜる |
| 緑レンズマメ | 粒が大きく歯ごたえが強いです | 25-30分 | 和え物、あえもの、炒め物 |
| 赤・黄レンズマメ | 皮をむいて割ったものです | 10-15分 | 粥、スープ、カレー。形が崩れます |
| 黒レンズマメ | 小さくて硬いです | 20-25分 | タンパク質含量が特に高いです |

> **赤レンズマメと黄レンズマメは品種ではなく加工形態です。皮をむいて半分に割ったものなので絶対に発芽しません。市販の赤レンズマメを畑に播いても何も出てきません。**

&nbsp;&nbsp;&nbsp;この区別は必ず知っておくべきです。災害対策としてレンズマメを備蓄する際は、食べる分と播く分を分けて考える必要があり、播く分は皮が完全な褐色か緑のレンズマメでなければなりません。しかもそれさえも流通過程の熱処理や燻蒸で発芽力を失っている可能性があるため、入手後は必ず少量で発芽試験を行います。濡れた布に二十粒を包んで数日置き、芽が出る数を数えればよいのです。

&nbsp;&nbsp;&nbsp;調理の観点では、両方を備えておくのが理想的です。皮つきの褐色レンズマメは貯蔵性が良く種子としても使えますが、皮をむいて割った赤レンズマメは燃料を最も少なく使います。褐色レンズマメを貯蔵しておき、必要なときに臼でついて皮を飛ばし赤レンズマメの形にすることができるので、貯蔵は皮つきのまま、加工は食べる分だけ行うのが原則です。

### 4-2. 状況別の選択基準

| 状況 | 優先順位 | 理由 |
|---|---|---|
| 種子として使う | 皮が完全な褐色・緑レンズマメ | 割ったものは発芽しません |
| 燃料が不足している | 皮をむいて割った形に加工 | 10-15分で煮えます |
| 長期貯蔵 | 皮つきの褐色レンズマメ | 種皮が防御膜の役割をします |
| 病人・高齢者・子供 | 赤レンズマメの粥 | 煮崩れて消化しやすいです |
| 高冷地に畑がある | どの系統でも | 韓国でレンズマメに最も適した場所です |
| 病気が発生している畑 | 生き残った個体から採種 | さび病と萎凋病への抵抗性を選抜します |

## 5. 畑の準備と肥料 - 根粒菌

### 5-1. 窒素固定はどのように起こるか

&nbsp;&nbsp;&nbsp;空気の78%は窒素です。人の頭上に無限の窒素が浮かんでいるのに、植物はそれを使えません。空気中の窒素は窒素原子二つが三重結合で固く結ばれた分子で、この結合を切るのに莫大なエネルギーが必要だからです。工業的にこの結合を切ってアンモニアを作るのがハーバー・ボッシュ法で、世界の窒素肥料はそこから作られます。高温、高圧、触媒、そして大量の化石燃料が必要です。

&nbsp;&nbsp;&nbsp;根粒菌はこの仕事を常温常圧でやり遂げます。ニトロゲナーゼという酵素で三重結合を切り、窒素をアンモニアに変えます。ただし代償があります。この反応には多くのエネルギーが必要で、細菌自身は光合成をできません。そこでマメ科植物の根に入り込んで暮らし、植物が光合成で作った糖を受け取り、その代わりに固定した窒素を渡します。取引関係です。

&nbsp;&nbsp;&nbsp;レンズマメと組む菌はRhizobiumLeguminosarum bv. viciaeです。エンドウ、ソラマメ、野生のカラスノエンドウと同じ菌で、ダイズやヒヨコマメと共生する菌とは異なります。実用上、これは大きな利点です。エンドウを育てた畑の土、または春の野原に多いカラスノエンドウの根から接種源を得ることができます。

| 段階 | 起こること |
|---|---|
| 1. 信号交換 | レンズマメの根がフラボノイドを分泌し、土中の細菌がその信号に応じてNodファクターを出します |
| 2. 感染 | 根毛が内側に曲がって細菌を包み込み、細菌が感染糸をたどって根の中に入ります |
| 3. 根粒形成 | 根の内側の細胞が分裂して根粒が膨らみ、その中に細菌が定着します |
| 4. 窒素固定 | 根粒内でニトロゲナーゼが働き、空気中の窒素をアンモニアに変えます |
| 5. 分配 | アンモニアがアミノ酸に変わり、茎や葉、鞘へと運ばれます |
| 6. 老化 | 登熟期に入ると根粒が機能を失い、根とともに土に還ります |

&nbsp;&nbsp;&nbsp;ニトロゲナーゼは酸素に非常に弱く、酸素が触れるとすぐに機能を失います。そのため根粒の内側にはレグヘモグロビンという赤い色素タンパク質が詰まっていて酸素を捕らえ、酵素周辺の酸素濃度を極めて低く保ちます。人の血が赤いのと同じ原理で、根粒を割ったときに内側が赤や桃色をしているのがこの色素です。この事実は実用上とても重要です。赤色は、その根粒が今まさに窒素を固定しているという目に見える証拠だからです。

### 5-2. 根粒ができたかを確認する方法

&nbsp;&nbsp;&nbsp;接種したかどうかにかかわらず、根粒が実際にできたかを確認することは必ず行うべきです。確認しなければ窒素不足の原因が分からず、翌年に同じ失敗を繰り返すことになります。レンズマメは生育期間が短く、失敗に気づいて直す時間がさらに少ないのです。

| 順序 | 内容 |
|---|---|
| 1 | 開花が始まる頃、播種後6週ほどが最適な時期です |
| 2 | 健康そうな株を二、三株選びます |
| 3 | 引き抜かずに、スコップで株の周りを広く掘り、土ごと持ち上げます |
| 4 | 水を入れた容器で土をそっと洗い流します |
| 5 | 直根と太い側根についた根粒の数を数えます |
| 6 | 根粒をいくつか爪で割って中の色を見ます |

| 観察結果 | 意味 | 対応 |
|---|---|---|
| 根粒が株当たり10個以上ついている | 接種がうまくいっています | そのままにします |
| 割った内側が赤や桃色 | 窒素を固定しています | 良い状態です |
| 割った内側が白色や薄緑色 | 根粒はできたが固定していません | 酸度、湿害、リン酸欠乏を調べます |
| 割った内側が茶色や黒色 | すでに老化したか死んでいます | 登熟期なら正常、開花期なら問題です |
| 根粒がほとんどない | 接種が失敗しました | 葉が黄色ければ少量の窒素を補います |

> **根を掘り出して根粒を割り、赤色を確認するこの一つの習慣が、窒素肥料のない世界で豆づくりの成否を教えてくれる最も確実な信号です。**

&nbsp;&nbsp;&nbsp;レンズマメの根粒は小さいです。植物自体が小さいため、根粒も粟粒から米粒ほどの大きさで、ダイズのようにエンドウ豆ほどの根粒を期待すると、ないと誤って判断しやすいです。土を洗い流した後、明るい場所で細根を一本ずつたどってようやく見えます。割るときも爪よりナイフの先を使う方がよいです。

### 5-3. 接種源をどこで入手するか

&nbsp;&nbsp;&nbsp;市販の接種剤は、生きた細菌をピートや粘土に入れて売る製品です。災害時には入手できません。しかしレンズマメが使う菌はエンドウやソラマメ、野生のカラスノエンドウも共に使うありふれた菌なので、接種源を得る方法はいくつもあります。

| 方法 | 手順 | 効果 | 注意 |
|---|---|---|---|
| 同系統の菌を持つ畑の土をまぶす | レンズマメ、エンドウ、ソラマメ、カラスノエンドウを植えて根粒がよくできた畑から、表土5-15cmの深さの土をすくってきます。種子を水で軽く湿らせてこの土をまぶし、すぐに播きます | 最も確実で費用がかかりません | 病気の畑の土は病原菌も一緒に運びます |
| 野生カラスノエンドウの根 | 春に野原や畑のあぜのカラスノエンドウを掘り、根粒を確認します。根粒が赤ければその土と根を一緒に使います | レンズマメ栽培の実績がない地域で最も現実的です | 固定効率が栽培種用の系統より低い場合があります |
| 根粒そのものを使う | 掘った根の根粒を集めてすりつぶし水に溶き、その水に種子を浸してから取り出します | 菌密度が最も高いです | 根粒を掘り出したその日のうちに使う必要があります |
| 土を畑にまく | 播種する筋にすくってきた土をまき、一緒に耕し込みます | 菌が土に広がります | 10㎡当たりスコップ一杯ほどが基準です |
| 根の残渣を残す | 収穫時に茎だけを刈り、根を畑に残します | 翌年まで菌が土に残ります | 最も手間のかからない維持方法です |

&nbsp;&nbsp;&nbsp;接種する際に必ず守るべきことがあります。根粒菌は直射日光と乾燥と熱に非常に弱いです。紫外線を数分受けるとかなりの数が死に、乾けばさらに早く死にます。種子に土をまぶす作業は日陰で行い、まぶした種子は日に当てず、そのまま播きます。30分以内に播くのが良く、遅くとも数時間以内に終えます。もう一つ、種子消毒と接種は同時にできません。殺菌剤をまぶした種子に土をまぶすと細菌が死にます。温水処理で消毒した場合は、完全に冷ましてから接種します。

| 接種失敗を招く条件 | 理由 |
|---|---|
| 土壌pH 5.5以下 | 細菌が生存できません |
| 窒素肥料を十分に与えた畑 | 植物が取引の必要を感じず、根粒形成を自ら減らします |
| 水が溜まる畑 | 好気性細菌なので酸素がないと死にます |
| リン酸が不足した畑 | 窒素固定には多くのエネルギーが必要で、その代謝にリン酸が使われます |
| モリブデン・鉄・コバルトの欠乏 | ニトロゲナーゼの構成成分です |
| 接種した種子を日に当てて乾かす | 紫外線と乾燥で菌が死にます |
| ダイズやヒヨコマメの畑の土を使う | 菌の種が異なり、レンズマメには感染しません |
