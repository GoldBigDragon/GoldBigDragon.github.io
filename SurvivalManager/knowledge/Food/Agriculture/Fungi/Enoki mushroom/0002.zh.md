## 1. 灾害应对评价

&nbsp;&nbsp;&nbsp;金针菇是排除作物。耐储性E与持续性D叠加，被判定为无法成立囤积储备。不适用关卡时的假定得分为39.6分，在有效183种中排第117位。但是，造成该判定的两个项目中，耐储性只是以鲜品为基准计算的数值，只靠干燥一项就能解决。剩下的弱点只有持续性一项，那是设备与有机物的问题。

### 1-3. 光照SS的含义

&nbsp;&nbsp;&nbsp;评价表中的光照项目本来是问在40%遮光条件下产量还能剩多少。马铃薯能剩下80%左右，水稻和玉米则下降得更大。金针菇获得的SS并不意味着它在这场竞争中获胜，而是意味着它原本就不在这一维度之上。菌类没有叶绿素。金针菇利用的碳，是早已固定在木屑与米糠中的纤维素与淀粉，天空的明暗对这份存量没有任何影响。

&nbsp;&nbsp;&nbsp;在大规模火山喷发或核冬天那样气溶胶铺满平流层、日照量连续数年减少的情况下，这种差异会决定性地显现出来。那时谷物、薯类（块茎/块根）和蔬菜会同时崩溃，但倒下的树木和干枯的秸秆依然留存，而把它们转化为人可食用蛋白质的唯一途径就是菌菇。

&nbsp;&nbsp;&nbsp;金针菇在此之上还多了一层。日照减少，气温也会随之下降。对大多数作物和大多数菌菇来说那是灾难，但对金针菇而言条件反而契合。这种菌菇在4-9℃培育子实体，在野外甚至能在雪中长出。评价表中耐寒性为D，并不是说它无法承受低温本身，而是说前提是精密的分段控温，换句话说，凉意不是金针菇的敌人，而是它的材料。

> **菌菇是即使在阳光消失的世界里产量也不会减少的唯一粮食来源，而金针菇是其中少见的、越冷条件反而越好的一种。**

### 1-4. 如何看待优势

&nbsp;&nbsp;&nbsp;获得SS的项目有蛋白质密度、光照、整地·挖掘能耗、产量稳定性四项。获得S的项目有收获速度、连作适应性、口味、韩国国内普及度四项。

&nbsp;&nbsp;&nbsp;收获速度S对于一种排除作物而言是显眼的数值。从接种到收获50-60天，也就是两个月。与香菇从原木接种到首次出菇需要12-18个月相比，差距很大。这意味着即使灾害当年才开始栽培，当年也能吃到这种菌菇，这也是持续性D的另一面：不能持久，但速度快。

&nbsp;&nbsp;&nbsp;韩国国内普及度S也很实际。金针菇是韩国国内栽培最多的菌菇之一，韩国全国任何地方都能买到菌种。这与大球盖菇普及度D、菌种难以获得的情况正相反。灾害发生前后能够获取菌种的可能性也因此更高。

&nbsp;&nbsp;&nbsp;产量稳定性SS是因为室内培养基栽培不受气象影响而获得的数值。夏季的梅雨季（韩国的梅雨季在6月下旬至7月）或秋季的台风不会左右收成。只要正确制作培养基并控制好温度，每年都能产出相同的量。

&nbsp;&nbsp;&nbsp;还有一个评价表中没有的优势。金针菇可以使用针叶树木屑。香菇、猴头菇和大球盖菇因菌丝受到松科树脂与萜类物质的抑制而无法使用针叶树，但金针菇反而把花旗松木屑作为标准培养基材料使用。在周边阔叶树少、只有松树和红松的地区，这一点会成为决定性的差异。

### 1-5. 如何看待劣势

&nbsp;&nbsp;&nbsp;E有三项：设施负担、温度适应幅度、耐储性。D有四项：持续性、施肥需求、耐寒性、种子寿命。

&nbsp;&nbsp;&nbsp;设施负担E最令人头疼。商业栽培中，金针菇以栽培场所、制冷设备与瓶装容器为前提。制冷全年消耗电力。在电力中断的情况下，这套组合无法成立。应对方法只有一个：制冷设备不是靠人来制造，而是向季节和土地去借。地窖与地下室、朝北的仓库、井边、石冰库(Seokbingo，韩国传统的冰窖)形式的坑，最重要的是冬季本身。第3节和第7节将详细讨论这个问题。

&nbsp;&nbsp;&nbsp;温度适应幅度E也出自同一根源。催蕾10-12℃，生长6-8℃，幅度不足6℃。对其他作物而言这是致命的狭窄，但如果将栽培方式定为只在冬季栽培，这种狭窄就不再是需要管理的对象，而变成季节自动配合的条件。想让金针菇全年栽培就会失败，定为冬季作物就会成功。

&nbsp;&nbsp;&nbsp;持续性D与施肥需求D需要一并理解。由于培养基是一次性使用后废弃的结构，每平方米每年要持续投入60kg的木屑与米糠。虽然完全不使用化学肥料，但有机物的消耗达到了多肥性作物的水平。解决之道在于第11节的菌糠循环。金针菇的菌糠最多可以按下一周期培养基的20%比例混入使用，剩余部分则回归为田间有机质。把废弃变成反复使用两三次，这个弱点会大幅减少。

&nbsp;&nbsp;&nbsp;自家留种C与种子寿命D也要一并看待。市售菌种6个月到1年就会失去活力，没有无菌培养就难以延续纯种菌株。应对方法是第4节讨论的孢子印保存与组织培养。把孢子晒干在铝箔上存放于地窖中可保持5-10年，因此即使菌种死亡，只要孢子还活着就能重新开始。

&nbsp;&nbsp;&nbsp;非食用价值E意味着8个项目中均无符合项。作为药材、土壤改良材，或害虫防治用途均未确认有可用之处。金针菇是一种除了食用之外没有其他用途的菌菇。

&nbsp;&nbsp;&nbsp;还有一个评价表中没有记载的弱点，那就是误认的风险。野生金针菇，即韩语正式名称所说的"朴树菇"（paengnamu-beoseot），从晚秋到早春成簇长在阔叶树的树桩上，而同一地点同一季节，致命的毒菌也会以相同的样貌长出。而且金针菇的孢子为白色至淡黄色，因此大球盖菇所用的"孢子为白色则不可食用"规则在此无法套用。第12节的内容必须仔细阅读。

## 2. 这是一种什么样的菌类

### 2-1. 名称与分类

&nbsp;&nbsp;&nbsp;金针菇属于担子菌门·伞菌纲·伞菌目·Physalacriaceae科·Flammulina属。韩语的正式名称是 paengnamu-beoseot（直译为"朴树菇"）。因常长在朴树（Celtis sinensis）树桩上而得名；而市场上通行的叫法 paengi-beoseot（即金针菇）后来流传更广。

&nbsp;&nbsp;&nbsp;学名Flammulina velutipes中，属名意为"小火焰"，种名velutipes意为"绒毛状的足"。这个名字来自野生个体的菌盖呈橙黄褐色、菌柄基部覆盖着深褐色绒毛这一特征。这个种名所指的部位在第12节将成为安全确认的核心标志，值得记住。

&nbsp;&nbsp;&nbsp;从生态上看，它是分解阔叶树枯干与树桩的白色腐朽菌，常成簇长在朴树、柿树、桑树、柳树、杨树、榆树的枯死木和树桩上。有时也会在活树的伤口处表现出较弱的寄生性。而且还有一个决定性的特征：这种菌菇从晚秋到早春，甚至在寒冬积雪中也能长出子实体。别的菌菇全部停止生长的季节，正是金针菇的时令。

### 2-2. 野生个体与栽培个体的外观完全不同

&nbsp;&nbsp;&nbsp;学习金针菇时首先要弄清楚的一点。商店里出售的金针菇纯白色，菌柄像豆芽一样细长，菌盖直径仅有1cm左右。野生的朴树菇橙黄褐色的菌盖可展开至直径2-8cm，菌柄短而粗，基部呈深褐色。差异之大让人难以相信是同一物种。

&nbsp;&nbsp;&nbsp;差异来自栽培环境。在瓶子外包上纸遮光，并将二氧化碳浓度提高到6,000ppm以上，菌丝就无法长出菌盖，只能把菌柄拉长。因为没有光照，也不产生色素，所以保持白色。我们所熟悉的金针菇的样貌并非该物种原本的样子，而是黑暗与高二氧化碳共同造就的形态。

> **不了解这个差异，就会在野外看到朴树菇也认不出来，反而把毫不相干的菌菇误认为金针菇。第12节的所有判别方法都以野生个体的性状为基准撰写。**

### 2-4. 生活史——从孢子到菌菇

&nbsp;&nbsp;&nbsp;菌菇的生活史与植物不同。与一粒种子长成一株树的植物不同，菌菇的一粒孢子无法单独长成菌菇。

| 阶段 | 发生了什么 |
|:---|:---|
| 孢子 | 从成熟菌盖的菌褶上落下，是只含一半遗传物质的单核细胞 |
| 初生菌丝 | 孢子萌发后呈丝状延伸。因遗传物质只有一半，无法形成菌菇，势力衰弱后死亡 |
| 次生菌丝 | 两个不同交配型的初生菌丝相遇并结合。只有在这种状态下才能结出菌菇 |
| 占满培养基 | 次生菌丝将木屑培养基全部覆盖为白色，需要20-25天 |
| 搔菌与催蕾 | 刮去培养基表面老化的菌丝层并降低温度，就会形成粟粒状的原基 |
| 抑制生长 | 进一步降至5-7度，使菌柄变粗变短 |
| 子实体 | 在4-9度下菌柄伸长并生长 |

&nbsp;&nbsp;&nbsp;一粒孢子长不出菌菇这一事实在实践中十分重要。如果珍惜孢子一粒一粒小心地滴入，就只会长出初生菌丝然后死亡。必须一次性大量撒入孢子粉，让它们在培养基内彼此相遇结合。

> **孢子不用节省。一粒长不成菌菇。**

### 2-5. 生长阶段与所需时间

| 阶段 | 时间 | 温度 | 湿度 | 观察要点 |
|:---|:---:|:---:|:---:|:---|
| 培养基配制与灭菌 | 1天 | - | 培养基水分65-70% | 将木屑与米糠混合装入容器 |
| 接种 | - | 待培养基冷却至25℃以下后 | - | 迅速操作以防杂菌混入 |
| 菌丝培养 | 约22天 | 23-25℃ | 65-75% | 培养基被菌丝覆盖为白色 |
| 搔菌 | 1天 | - | - | 刮去老化菌丝层以诱导均匀催蕾 |
| 催蕾 | 8-10天 | 14-15℃ | 95-98% | 形成粟粒状的原基 |
| 抑制生长 | 5-15天 | 5-7℃ | 75-96% | 菌柄变粗变短 |
| 生长 | 至收获为止 | 4-9℃ | 75-85% | 菌柄伸长 |
| 收获 | - | - | - | 总计50-70天 |

&nbsp;&nbsp;&nbsp;这张表中重要的是温度呈阶梯式下降：从23℃到15℃，再到6℃，再到4-9℃。商业栽培中制造这一阶梯的是制冷机，而在没有电力的情况下，晚秋到早春的自然气温变化会代替这一作用。10月制作培养基、11月完成培养、12月经过催蕾、寒冬收获的栽培方式，恰好与这一阶梯相吻合。

&nbsp;&nbsp;&nbsp;34℃是绝对界限。培养过程中培养基温度只要稍微超过34℃，菌丝就会死亡。由于菌丝自身会产生代谢热，夏季培养很容易越过这条线，这就是要避开盛夏培养的原因。
