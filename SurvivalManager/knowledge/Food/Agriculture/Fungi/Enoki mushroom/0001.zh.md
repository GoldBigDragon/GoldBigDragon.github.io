## 引言
&nbsp;&nbsp;&nbsp;金针菇（Flammulina velutipes）在评价表中被判定为排除。这是耐储性E（以鲜品为准）与持续性D叠加的结果，未适用关卡得分为39.6分（有效183种中第117位）。耐储性只要撕成细条晒干，就能在密闭容器里存放一年，仅靠一把刀和一个晾筛就能解决。持续性D的意思是，装在瓶或袋里的锯末培养料只用一次就丢弃，一份培养料收两三茬就结束。但仍不把它划掉，有三个理由。第一，它不进行光合作用，所以在光照减少的灾害里产量也能保持（光照SS）。第二，它是在4-9℃长出子实体的耐寒菇，所有其他蘑菇都停下的隆冬正是它的时令，能填补新鲜食物断绝的时段。第三，热量21kcal而蛋白质2.48g，蛋白质占热量的47.2%（蛋白质密度SS），并且富含维生素B1和B2。没有电的话它是冬季作物，夏天（34℃是危险线）不种。最重要的提醒是与毒蘑菇混淆。金针菇的孢子是白色至淡黄色，所以不能用“排除白色孢子”这条简单的防线，若不懂第7节的鉴别方法，就不要到野外采集。

## 1. 灾害应对评估
| 类别 | 内容 |
|:---|:---|
| 判定 | 排除（耐储性E + 持续性D）。未适用关卡得分39.6 |
| 优势 | SS：蛋白质密度、光照、整地·挖掘能量、产量稳定性（室内培养料栽培，不受天气影响）。S：收获速度、国内种植普及度 |
| 劣势 | E：耐储性（鲜品）、设施负担（灭菌和低温）、温度幅度、非食用价值。D：持续性、施肥、种子寿命。C：自留种 |

> **蘑菇是阳光消失的世界里产量也不会下降的唯一粮食来源，而金针菇是其中越冷越舒服的罕见品种。**

&nbsp;&nbsp;&nbsp;各项目的等级见“灾害应对作物评价结果”文档。

## 2. 蘑菇概述
&nbsp;&nbsp;&nbsp;属担子菌门膨瑚菌科冬菇属，是分解阔叶树枯死树干和树桩的白腐菌。野生个体（野生的金针菇）和栽培个体长得完全不同，不知道这一点，就会在野外认不出来，或者把别的蘑菇当成金针菇。

| 器官 | 野生个体 | 栽培个体 |
|:---|:---|:---|
| 菌盖 | 直径2-8cm。黄褐色至橙红褐色。潮湿时有明显黏液 | 直径1-3cm。纯白、淡黄 |
| 菌褶 | 白色至淡奶油色。成熟后也不变褐 | 白色 |
| 菌柄 | 长2-10cm。基部覆盖深褐至黑褐色的短绒毛 | 长8-15cm，细 |
| 菌环·蛛网状菌幕·菌托 | 都没有 | 都没有 |
| 孢子 | 白色至淡黄色 | 相同 |
| 生长 | 在腐朽的阔叶树树桩上密集成簇。晚秋至早春 | 瓶内成簇。人工低温 |

| 阶段 | 期间 | 温度 | 湿度 |
|:---|:---|:---|:---|
| 菌丝培养 | 约22天 | 23-25℃ | 65-75% |
| 搔菌 | 1天 | - | - |
| 催蕾 | 8-10天 | 14-15℃ | 95-98% |
| 生长抑制 | 5-15天 | 5-7℃ | 75-96% |
| 生长 | 至收获 | 4-9℃ | 75-85% |

&nbsp;&nbsp;&nbsp;从接种到收获共50-70天。一粒孢子长不成蘑菇（必须是不同交配型的两条菌丝结合），所以孢子要多撒。每100g含热量21kcal、蛋白质2.48g、糖类0.37g，膳食纤维是蘑菇中最高的，维生素B1·B2约为每日需要量的25%，赖氨酸和精氨酸补充谷物缺少的氨基酸。

## 3. 培养料与灭菌
| 项目 | 标准 |
|:---|:---|
| 树种 | 能用针叶树（花旗松、松、红松）是这种蘑菇独有的优势（在野外淋雨陈放半年至一年）。杨、柳、朴、桑、柿子树适合度高，栎和榆中等。核桃类（化感物质）和扁柏·侧柏·圆柏（抗菌成分）禁用 |
| 配方 | 锯末60% + 废菌包20% + 米糠20%（没有废菌包则锯末80% + 米糠20%）。米糠不超过20%。把蛋壳（捣碎到5mm左右）按锯末量的10%掺入，产量为121% |
| 水分 | 65-70%（用力攥时指缝间渗出水气但不滴水）。pH 4.5-8.6 |
| 容器 | 玻璃瓶（口用布盖住扎紧，骤冷会裂）、竹筒、陶器、耐热塑料袋（口用棉花或布塞住）。1,000ml的瓶装培养料600-750g |

| 灭菌 | 方法 |
|:---|:---|
| 铁桶常压蒸汽（无电的标准） | 200L铁桶底部放水20-30cm，在支架上立好容器，盖上盖子，缝隙用湿布或黏土堵住。冒汽后在100℃保持4-6小时，熄火后闷着冷却一夜。柴火30-50kg |
| 水煮 | 把培养料装进袋子煮2-3小时，挤干后调整水分。耐热细菌孢子会残留，所以冷却后迅速接种，并多用菌种 |
| 稻草加热培养料 | 把稻草或豆荚煮透1小时以上，挤干放凉，大量撒上孢子粉，用干净的布盖住，在20-25℃暗处放2-4周。用于从孢子培育菌种，营养少，对绿霉也没那么有吸引力 |

&nbsp;&nbsp;&nbsp;低温来自冬季本身（11-3月的朝北棚屋或屋檐下）、窑洞和洞穴（10-15℃）、地窖（12-18℃）、朝北坡面的坑（8-14℃）、冰坑（0-5℃）、挂湿布（比周围低3-5℃）。夏天在窑洞里做不出4℃，所以没有电的话是冬季作物。

## 4. 菌种获取与接种
| 方法 | 内容 |
|:---|:---|
| 孢子印 | 把菌盖完全展开的大而健康的个体，菌褶朝下放在铝箔上，扣上容器放24小时。在阴凉处再晾一天，对折后放进自封袋，集中放进玻璃瓶用蜂蜡封口，放在四季温度恒定的窑洞或地窖里，可存放5-10年以上（不能用液体保存）。第一年做20-30张存起来 |
| 组织培养 | 把新鲜个体用手纵向掰开，取菌盖与菌柄相接处内侧的白色菌肉，撕成米粒大小，夹进煮过放凉的锯末培养料或稻草。在20-25℃暗处3-5天蔓延。最可靠 |
| 培养料分种 | 把刚培养完成、没有杂菌的瓶里的培养料，按新培养料重量的5-10%掺入（1瓶扩成5-10瓶）。超过四五代活力下降，要回到组织培养或孢子 |

| 接种 | 标准 |
|:---|:---|
| 条件 | 培养料降到25℃以下后立即进行（放久了空气中的孢子会落上），选清晨或雨后 |
| 没有无菌室时 | 在不进风的最小房间里，给地面和墙壁洒水压住灰尘，手用肥皂和烈酒或醋擦拭，工具用火烧过再放凉，用布遮住口鼻，打开容器、放入菌种、盖好在10秒内完成。接种量为标准2-3%的两三倍，即培养料重量的5-10%。口用棉花或布塞住，但不要用塑料完全密封 |

> **没有无菌室时，关键不是完美无菌，而是速度和菌种量。几个杂菌混进去是无法避免的，所以让蘑菇菌丝压倒性地多，先占住地盘。**

## 5. 培养、催菇与收获
| 阶段 | 管理 |
|:---|:---|
| 菌丝培养（约22天） | 23-25℃，黑暗。绝对上限是34℃，菌丝会产生代谢热，所以即使周围是30℃，培养料内部也可能超过，因此不要把瓶子堆得太密。白色至淡奶油色每天向下蔓延2-4mm，长到底后再放3-5天（后熟）。蓝绿、黑、橙、粉色是污染 |
| 搔菌 | 培养结束后，用勺子或开水消毒过的小钩，把表面老化的菌丝层只刮去2-5mm，均匀刮净，使原基一起出现 |
| 催蕾 | 移到14-15℃，湿度95%以上（盖湿布或在地面洒水），给微弱的光。8-10天后，小米粒般的原基密密麻麻地形成 |
| 生长抑制 | 在5-7℃放5-15天，使菌柄变得粗短结实。省掉的话，菌柄会长得又细又长、没有力气，晒干后只剩丝线，所以不能省略。隆冬的夜晚是最简单的办法 |
| 生长 | 4-9℃，湿度75-85%。限制通风会使二氧化碳升高，长出长柄小盖（市场形态）；通风充分则长出粗柄大盖（野生形态）。灾害时后者更好，凭感觉判断 |

> **温度台阶即使调不精确，蘑菇也会长出来。重要的是方向。培养之后必须移到更冷的地方。一直放在同一个温度下，只是菌丝变老，不会出菇。**

| 收获 | 标准 |
|:---|:---|
| 时期 | 菌盖仍然合拢、菌柄长到足够长时。菌盖张开、菌褶间有白粉（孢子）飘散就晚了 |
| 要领 | 抓住整簇的基部轻轻一拧摘下。不洗 |
| 再出菇 | 休养10-15天（刮掉表面残留的基部，保持13-15℃和湿度）后再收。最多2-3茬，第三茬为第一茬的20-30% |
| 产量 | 一瓶（培养料600-750g）第一茬150-250g，含第二茬共250-350g。生物转化率为培养料干重的30-50% |

## 6. 污染、病虫害与异常诊断
| 问题 | 症状与原因 | 应对 |
|:---|:---|:---|
| 绿霉 | 起初白色，很快变蓝绿色。每天10-30mm，比金针菇菌丝（2-4mm）快5-10倍。看到颜色时培养料已大半损失，所以早期靠速度和质地判断 | 一瓶的话不要打开，立即取出；数瓶的话把整个培养场所搬走，原地洗净晒干；全部污染则废弃 |
| 黑霉、红霉、毛霉、细菌 | 黑色粉末、粉红棉絮、高高的白毛、发黏的酸臭。灭菌不足和过湿 | 废弃，下一茬延长灭菌时间 |
| 菇蝇、螨、蛞蝓、老鼠 | 啃食菌丝和幼小子实体 | 用布堵住入口并设水盆、粘板诱捕，保持干燥，撒一圈灰或锯末，把瓶子放上架子并罩网 |

> **不要把被污染的培养料回收成堆肥。绿霉孢子在堆肥堆里存活，第二年又会回到培养料里。要烧掉，或埋到离栽培场所远的深处。**

&nbsp;&nbsp;&nbsp;预防的办法是充分灭菌、多放菌种、米糠不超过20%（营养多了，竞争的霉菌会先爆发）、瓶与瓶之间留空隙堆放、雨后接种、每年更换培养场所。因为是冬天栽培，害虫少。

| 症状 | 原因与处理 |
|:---|:---|
| 接种5天后仍不见菌丝 | 培养料发烫时接种。降到25℃以下重新接种 |
| 菌丝长一阵就停 | 培养料温度超过34℃或缺水。拉开瓶间距散热 |
| 菌丝长满了却不出菇 | 没降温或没搔菌。移到14-15℃并刮菌 |
| 原基形成后干枯或变软死亡 | 湿度不足，或有水滴落下。只靠空气湿度提高 |
| 只有菌柄长得又细又长 | 跳过了生长抑制、二氧化碳过多。放在5-7℃并通风 |

&nbsp;&nbsp;&nbsp;废菌包可按20%掺进下一茬的培养料，也可作田里的基肥、堆肥促进剂、蚯蚓基质、其他蘑菇的培养料，晒干后还能当柴火。培养场所用2-3年杂菌孢子就会积累，要腾空、用水洗净晒干，并在墙壁和地面刷石硫合剂或浓草木灰碱液。

## 7. 安全确认——毒蘑菇的误认
> **这一节直接关系到生命。金针菇是在野外最容易被误认为毒蘑菇的蘑菇。比起种植，确认能不能吃更重要。**

&nbsp;&nbsp;&nbsp;对于金针菇，孢子颜色不是排除鹅膏的手段。鳞柄白鹅膏和白毒鹅膏的孢子也是白色，无法区分；反过来，如果孢子是锈褐色或紫褐色，则用来判定它不是金针菇。五个特征都要确认，哪怕只有一项不符，就不要吃。

| 编号 | 特征 | 金针菇的标准 |
|:---|:---|:---|
| 1 | 生长基质 | 阔叶树腐朽的树桩、枯死树。长在地上的不是金针菇 |
| 2 | 菌盖黏液 | 潮湿时发黏发滑（雨后确认） |
| 3 | 柄基 | 深褐至黑褐色的短绒毛 |
| 4 | 习性 | 基部相连，密集成簇。单个的是别的蘑菇 |
| 5 | 菌环和菌托 | 都没有。挖开基部确认 |

| 易混对象 | 区分点 |
|:---|:---|
| 橘黄裸伞（有毒） | 孢子锈褐色，菌褶由黄色变锈褐色，菌柄上有菌环，菌盖干燥呈纤维状不黏，基部膨大如棍棒且无毛，菌盖6-15cm，非常苦。中毒在30分钟至3小时内开始 |
| 鳞柄白鹅膏·白毒鹅膏（致命） | 孢子和菌褶都是白色，无法区分。单个长在活树根附近的地面上，有菌托和菌环，菌盖白色至淡绿黄色且光滑，基部无毛，菌盖6-15cm、菌柄9-20cm，大得多 |
| 丝膜菌类（奥来毒素，破坏肾脏） | 孢子锈褐色，幼时菌盖边缘与菌柄之间有蛛网状菌幕（成熟后在菌柄上留下锈褐色环带），散生于地上。症状在数日至3周后才出现 |
| 簇生垂幕菇（有毒） | 基质相同，也是成簇。孢子紫褐至黑褐色，菌褶由硫黄色变为橄榄色、紫褐色，非常苦，柄基无毛，整根菌柄呈黄色至黄褐色 |

&nbsp;&nbsp;&nbsp;另外还有粉褶菌类（孢子粉红色，长在地上，肠胃毒）和斑褶菇类，砖红垂幕菇（可食）难以与簇生垂幕菇区分，所以没把握就不要吃。尝味道时，用舌尖轻轻点一点，苦就吐掉，不要吃。

&nbsp;&nbsp;&nbsp;第一次吃时，要走完所有确认步骤，充分煮熟，由一个人只吃一小块并等待24小时，并另外留下一个所吃蘑菇的个体。吃后6-24小时才开始呕吐腹泻，是鹅膏毒肽中毒的典型经过，即使症状暂时缓解、看似康复，肝脏仍在被破坏。最安全的金针菇，是从我自己接种的瓶里长出来的。

## 8. 储存、烹调与全年日程
| 储存 | 内容 |
|:---|:---|
| 鲜品 | 常温下三天从基部开始褐变，四天变软。隆冬挂在朝北屋檐下或窑洞里可放2-3周 |
| 干燥 | 把整簇用手撕开，摊在帘子或晾筛上，晴天晒1-2天（维生素D增加）；阴凉通风处2-4天；穿线挂在屋檐下3-5天；火边40-50℃烘半天；冬天放到零下冻透再在冷风中吹5-10天（最适合冬季收获物）。用手一搓就碎即完成。只有养得粗壮的蘑菇，晒干后才保得住形状 |
| 磨粉 | 开始碎的就磨成粉。体积小，给汤增鲜，掺进谷物粉里补充蛋白质和B族维生素 |

&nbsp;&nbsp;&nbsp;金针菇一定要煮熟吃。焯水2-3分钟（最省燃料），汤或炖5-10分钟，烤5分钟，煎饼5-8分钟。干品用温水泡10-15分钟，避开底部的碎屑，取上层泡的水当汤用。如果整个冬天都偏吃谷物，会因缺乏硫胺素而出现腿麻、浮肿和严重疲劳，一把金针菇就能补上这个缺口。11-3月，它是唯一的新鲜蛋白质来源和B族维生素来源。

| 月份 | 作业 |
|:---|:---|
| 1-3月 | 隆冬收获（朝北棚屋、窑洞）并立即晒干，管理第二茬的休养，3月把废菌包还田，洗净容器并煮沸 |
| 4-6月 | 收集锯末（针叶树锯末在野外陈放）、把蛋壳晒干捣碎、备好米糠 |
| 7-8月 | 不种（34℃危险区间）。转给其他蘑菇 |
| 9月 | 调制培养料并灭菌（收集柴火，用铁桶一次处理） |
| 10月 | 接种和培养（室内23-25℃，选雨后接种） |
| 11月 | 搔菌与催蕾（搬到窑洞或朝北棚屋的14-15℃处） |
| 12月 | 生长抑制（5-7℃）与生长（4-9℃），首次收获 |

> **绝对不要忘记：长在地上的不是金针菇，菌褶变成锈褐色或发黄就不是金针菇。超过34℃菌丝就死，培养之后要移到更冷的地方，不要跳过生长抑制，没有电的话是冬季作物。**
