## 3. 培养基材料与准备

&nbsp;&nbsp;&nbsp;金针菇是把木屑掺入米糠制成的培养基装入容器灭菌后再栽培的菌类。它不像大球盖菇那样只需在地上铺材料就行，而是以灭菌为前提的菌类。这一事实造成了评价表中设施负担为E级，也是在没有电力的情况下首先要解决的问题。

### 3-1. 金针菇独有的优势——可以使用针叶树

&nbsp;&nbsp;&nbsp;大多数栽培菌类都不能在松树、红松等针叶树木屑上生长，因为树脂和萜类成分会抑制菌丝。香菇、猴头菇和大球盖菇都把针叶树列为禁用树种。但金针菇的标准培养基材料正是花旗松木屑。

&nbsp;&nbsp;&nbsp;这一差异在不同地区具有决定性意义。韩国相当一部分造林地是松树、红松和落叶松，在山地阔叶树稀少的地区，香菇和猴头菇都很难获得培养基材料。在这种地方，金针菇几乎是唯一的选择。

| 树种 | 适合度 | 备注 |
|:---|:--:|:---|
| 花旗松、松树、红松 | 高 | 标准培养基材料。是其他菌类不能用的材料 |
| 杨树、柳树 | 高 | 质地松软，分解快 |
| 朴树、桑树、柿树 | 高 | 野生发生的树种 |
| 橡树、榆树 | 中等 | 质地坚硬，菌丝蔓延较慢 |
| 核桃树、胡桃树 | 禁用 | 拮抗物质会杀死菌丝 |
| 扁柏、侧柏、桧柏 | 禁用 | 抗菌成分非常强 |

&nbsp;&nbsp;&nbsp;使用针叶树木屑时，最好先在室外堆放半年到一年、让雨水淋洗后再用。树脂被冲洗掉、分解略有进行，菌丝会蔓延得更好。刚锯下的木屑树脂味很浓，不要直接使用。

### 3-2. 培养基配方

| 材料 | 比例 | 作用 |
|:---|:---:|:---|
| 木屑（花旗松或阔叶树） | 60% | 主要碳源 |
| 菌糠 | 20% | 回收利用第一批采收后剩下的培养基 |
| 米糠 | 20% | 氮和维生素的来源 |

&nbsp;&nbsp;&nbsp;如果没有菌糠可用，就用木屑80%加米糠20%。米糠比例很关键：超过20%养分过多，青霉会先爆发式增长；低于10%产量则会明显下降。

| 添加物 | 用量 | 效果 |
|:---|:---:|:---|
| 蛋壳（碾碎至约5mm） | 木屑量的10% | 产量121% |
| 中药药渣（煎完中药后剩下的） | 木屑量的20% | 产量110% |
| 麦麸 | 替代米糠 | 没有米糠时使用 |
| 玉米芯粉 | 替代部分木屑 | 能改善透气性 |
| 甜菜粕 | 替代部分米糠 | 用于商业配方 |

> **在木屑中混入10%的蛋壳，产量能提高21%。把吃剩的蛋壳收集起来晒干磨碎，是一项不花钱、效果却最确实的措施。**

&nbsp;&nbsp;&nbsp;蛋壳起作用的原因是钙。碳酸钙能缓冲培养基的酸度，即使菌丝代谢产酸，pH也不会骤然下降。贝壳或牡蛎壳烧过磨碎的粉末、炭粉、少量草木灰也起同样的作用。不过草木灰碱性较强，用量不要超过木屑量的1%。

### 3-3. 水分调节

| 项目 | 标准 |
|:---|:---|
| 目标含水率 | 65-70% |
| 判定方法 | 用手紧握一把，指缝间能渗出水分但不滴水的程度 |
| 太干的情况 | 菌丝无法伸展，培养基会散碎 |
| 太湿的情况 | 底部积水形成厌氧状态，细菌会滋生 |
| pH | 4.5-8.6之间都能生长，范围很宽 |

&nbsp;&nbsp;&nbsp;金针菇能耐受4.5-8.6的酸度范围，这在灾害状况下很有帮助。即使没有酸度计和试纸，凭感觉配料也很难超出这个范围。这是一种几乎不需要费心调节酸度的菌类。

### 3-4. 容器——没有瓶子的时候

&nbsp;&nbsp;&nbsp;商业栽培用1,000ml塑料瓶装入600-750g培养基。灾害状况下没有这种瓶子。重要的不是瓶子这个物件本身，而是以下四项功能：能把培养基竖直装填、灭菌后能防止杂菌进入、能透气、并在上方留出菌体生长的空间。

| 容器 | 使用方法 | 注意事项 |
|:---|:---|:---|
| 玻璃瓶（果酱瓶、腌菜瓶） | 最耐灭菌。瓶口用布盖住并用绳系紧 | 骤然冷却会破裂，要慢慢冷却 |
| 竹筒 | 保留一端的节切断。可整根蒸煮 | 容易裂开，不能反复使用 |
| 陶瓮、坛子 | 耐热性强，保湿效果好 | 较重，灭菌需要更长时间 |
| 塑料袋 | 只用耐热的。袋口用棉花或布塞住 | 只能耐受常压100度 |
| 罐头盒、马口铁罐 | 容易获得 | 生锈就要丢弃 |
| 木箱盖布 | 形成平盘式栽培 | 杂菌风险最大 |

&nbsp;&nbsp;&nbsp;装填的要领有三点。只装满容器的75%，上方留出空间；表面轻轻拍平，不要用力压实；再在正中钻一个直径1cm的孔，一直通到底部。有了这个孔，菌种能深入培养基内部，菌丝从中心向外扩散，培养期缩短数天，失败率也会降低。

### 3-5. 不用电灭菌的方法

&nbsp;&nbsp;&nbsp;标准方法是121℃高压60-90分钟。没有高压灭菌器时，可从以下方法中选择。

#### 3-5-1. 油桶常压蒸汽灭菌

| 项目 | 方法 |
|:---|:---|
| 设备 | 200L油桶、支架、盖子、木柴 |
| 水 | 底部注水20-30cm |
| 摆放 | 放上支架，使容器不接触水面竖直放置 |
| 加盖 | 盖上盖子，缝隙用湿布或泥巴封住 |
| 时间 | 从蒸汽升起开始，100℃持续4-6小时 |
| 冷却 | 熄火后盖着盖子放一整夜冷却 |
| 燃料 | 木柴30-50kg |

&nbsp;&nbsp;&nbsp;这是最可靠的无电力方法，不过耗费燃料较多。一次生火时把油桶装满一次性处理，燃料效率会好得多。烧火灭菌十瓶和烧火灭菌一百瓶，所耗的柴并没有太大差别。

#### 3-5-2. 沸水煮制

| 项目 | 方法 |
|:---|:---|
| 方法 | 把拌好木屑和米糠的培养基装入袋中，放进沸水煮2-3小时 |
| 后续处理 | 捞出压挤去水，调至65-70%含水率后装入容器 |
| 局限 | 并非完全灭菌，耐热性细菌芽孢仍会残留 |
| 补救 | 冷却后立即接种，并多用一些菌种 |

&nbsp;&nbsp;&nbsp;这是没有油桶时的替代方法。灭菌程度较低，但只要多接入菌种让它先占据地盘，成功率就会提高。

#### 3-5-3. 稻草加热培养基法

&nbsp;&nbsp;&nbsp;这是完全没有木屑，或者需要从孢子重新培育菌种时使用的方法。理论上把孢子撒在培养基上菌丝就会生长，但实际上空气中的青霉和细菌会比菌类孢子快上几百倍地占领培养基，营养越丰富的培养基越脆弱。因此这里不用营养过剩的人工培养基，而是利用自然防御力的原始培养基。

| 阶段 | 方法 |
|:---|:---|
| 煮制 | 把稻草、麦秸或豆荚放入沸水中充分煮1小时以上 |
| 挤水 | 捞出挤干水分，冷却到手能触碰的程度 |
| 撒粉 | 把储存的孢子粉毫不吝惜地均匀充分撒上 |
| 覆盖 | 用干净的布覆盖，挡住风和落下的杂菌孢子 |
| 培养 | 在20-25℃的黑暗处放2-4周，白色菌丝覆盖稻草即为成功 |

&nbsp;&nbsp;&nbsp;养分少的稻草对青霉来说吸引力也较弱。菌丝生长得慢，但在竞争中不会落败。把这里获得的菌丝团移到木屑培养基上，就能培育成正式的菌种。

### 3-6. 灭菌方法比较

| 方法 | 燃料 | 时间 | 灭菌程度 | 推荐情况 |
|:---|:--:|:--:|:--:|:---|
| 高压121度 | 电力 | 60-90分钟 | 完全 | 有电力时 |
| 油桶蒸汽100℃ | 多 | 4-6小时 | 高 | 无电力标准做法，一次处理大量 |
| 沸水煮制 | 中等 | 2-3小时 | 中等 | 没有油桶时 |
| 稻草加热培养基 | 少 | 1小时 | 中等 | 需从孢子培育菌种时 |

### 3-7. 确保低温环境——无电力制冷

&nbsp;&nbsp;&nbsp;在金针菇栽培中，灭菌之后最大的问题就是低温。生育阶段需要4-9℃，之前的抑制阶段则需要5-7℃。没有制冷设备，人是造不出这个温度的，必须向外部借用。

| 手段 | 温度 | 获取方法 | 局限 |
|:---|:---:|:---|:---|
| **冬季本身** | 自然 | 11月至3月，朝北的仓房或屋檐下 | 只能在这个季节使用 |
| 土窖、洞穴 | 10-15℃ | 沿山坡向内挖2m以上 | 即使夏天也不会降到10度以下 |
| 地下室 | 12-18℃ | 利用现有建筑结构 | 与上同 |
| 井边、泉边 | 10-14℃ | 利用冷水边的空气 | 湿度过高 |
| 冰窖 | 0-5℃ | 寒冬填入冰块，用稻草和稻壳覆盖 | 耗费大量劳力 |
| 北向斜坡坑 | 8-14℃ | 在北侧阴面挖坑并覆盖稻草 | 温差波动较大 |
| 悬挂湿布 | 比周围低3-5℃ | 靠蒸发热降温 | 潮湿天气无效 |

> **在没有电力的情况下，金针菇是一种冬季作物。若想一年四季栽培就会失败。10月制作培养基、11月培养、12月经过发芽阶段、寒冬采收，这才是这种菌类自然的种植方式。**

&nbsp;&nbsp;&nbsp;夏天在土窖里造不出4℃的环境。那时就不种金针菇，转而栽培夏季能出的其他菌类，大球盖菇和木耳正好补上这个位置。这就是要同时经营几种菌类的原因：一种菌类无法覆盖全年，但错开搭配几种就能覆盖。

## 4. 获取菌种

&nbsp;&nbsp;&nbsp;菌类没有种子。种苗店关门后就没地方买种，把种子留下装进坛子的方式在这里也行不通。评价表中金针菇的自家留种为C级，种子寿命为D级。市售菌种6个月到1年就会失去活力，要延续纯种菌株需要无菌操作。但菌类有三条植物没有的路：留存孢子的路、从活体菌类身上取一块肉培育的路，以及把已经长好的培养基掰开转移的路。

### 4-1. 采集孢子与孢子印

&nbsp;&nbsp;&nbsp;孢子是最耐久的保存形态，是灾害初期必须提前准备的保险。

| 阶段 | 方法 |
|:---|:---|
| 挑选对象 | 菌盖完全展开、健壮的大个体 |
| 切柄 | 在菌盖与菌柄相接处贴着切掉菌柄 |
| 承托 | 让菌褶朝下放在**铝箔**上 |
| 覆盖 | 盖上碗或杯子挡风 |
| 静置 | 在凉爽处放置24小时 |
| 收取 | 拿起菌盖后，孢子粉会保持菌盖的形状留下 |

&nbsp;&nbsp;&nbsp;金针菇的孢子是白色到极淡的黄色。用白纸接取会看不见。**必须用深色纸、锡箔纸或玻璃板来接取。**这一点与孢子呈灰褐色的大球盖菇、孢子呈褐色的双孢蘑菇不同，在第12节的安全确认中也是关键差异之一。

&nbsp;&nbsp;&nbsp;铝箔比纸更好。纸会吸湿，纤维之间还会藏杂菌；铝箔不吸水分，表面光滑，能原样保存孢子。没有铝箔的话，玻璃板是次选。

### 4-2. 孢子的保存——不用电也能存10年

| 步骤 | 方法 |
|:---:|:---|
| 1 | 在铝箔上接取孢子 |
| 2 | 把印有孢子的铝箔在通风的**阴凉处**再放一天，把细微的湿气也彻底晾干 |
| 3 | 把铝箔对折，让孢子面朝内加以保护，装入密封袋 |
| 4 | 放入**炒得干燥的盐或炭块**一起，用来吸潮 |
| 5 | 把密封袋收进玻璃瓶，**用蜂蜡封口** |
| 6 | 放在四季温度恒定的**土窖或地下室**，不能见光 |

| 保存形式 | 寿命 | 备注 |
|:---|:---:|:---|
| 孢子印（铝箔干燥） | **5-10年以上** | 水分完全排除，细胞活动停止 |
| 液体菌种（无菌水悬浮） | 3-6个月 | 没有冷藏就会提早发芽或细菌增殖 |
| 已接种菌种（木屑·谷粒） | 6个月-1年 | 因是活菌丝，会持续消耗养分 |
| 已长好的培养基块 | 1-2个月 | 放置过久会老化失去活力 |

> **灾害状况下不能把孢子以液态保存，必须以干燥的孢子印形式保存。**

&nbsp;&nbsp;&nbsp;紫外线会破坏孢子的DNA，所以必须放在见不到光的深处。孢子和植物种子在寿命上的差异来自结构。

| 比较项目 | 番茄种子 | 菌类孢子 |
|:---|:---|:---|
| 平均寿命（室温） | 约2-4年 | 约5-10年以上 |
| 脆弱因素 | 温度变化、自身养分耗尽 | 湿气引起的霉变污染 |
| 细胞结构 | 复杂的胚和养分物质 | 单细胞及厚厚的保护壁 |

&nbsp;&nbsp;&nbsp;番茄种子内部含有胚和养分，随着时间推移会自行消耗养分而衰老死亡。菌类孢子只是包裹在厚细胞壁中的单个细胞，没有可消耗的养分，只要条件合适就能维持更久。学界复活数十年前孢子的案例也并不罕见。

> **评价表中的种子寿命D级，是以市售菌种为基准的。若换成孢子印保存，这个D级实际上就失去了意义。请在灾害第一年用最大、最健壮的个体制作20-30张孢子印，储存在土窖中。即使菌种全部损失，5年后、10年后也能重新开始。**

### 4-3. 组织培养——最可靠的方法

&nbsp;&nbsp;&nbsp;如果手上有新鲜的活体菌类，几乎没有理由使用孢子。菌盖与菌柄相接处内侧的白色肉质，已经是完成交配结合的二次菌丝团。取下一小块放入培养基，就能跳过发芽和交配的过程，菌丝直接向四周蔓延。

| 阶段 | 方法 |
|:---|:---|
| 挑选 | 菌盖刚要展开的新鲜个体，不用老旧或虫蛀的 |
| 消毒 | 把刀在火上烧热后冷却，或浸入沸水后取出 |
| 掰开 | **用手把菌类纵向掰开。**用刀切会把表面杂菌带入内部 |
| 取材 | 在菌盖与菌柄相接的内侧白色肉质处取下米粒大小的一块 |
| 接种 | 夹入煮过冷却的木屑培养基或稻草之间 |
| 培养 | 在20-25℃的黑暗处，3-5天后碎块周围会长出白色菌丝 |

&nbsp;&nbsp;&nbsp;掰开这一步很重要，是因为菌类内部近乎无菌。外皮和菌褶上附着各种孢子，但肉质内部是洁净的。用手掰开会露出新的洁净面，从那里取下的碎块即使不消毒也能成为纯净的菌丝。金针菇菌柄细，不容易取肉，最好用菌束根部较粗的部分。野生个体菌柄较粗，处理起来容易得多。

### 4-4. 靠掰开培养基来扩大菌种

&nbsp;&nbsp;&nbsp;把菌丝长得好的培养基掰开，蹭到新培养基上，就能成为菌种。方法原始但可靠。

| 阶段 | 方法 |
|:---|:---|
| 对象 | 白色菌丝覆盖整个培养基、没有杂菌痕迹的瓶子 |
| 时机 | 培养刚完成之后。放置太久的培养基菌丝会老化，活力下降 |
| 处理 | 把新培养基煮过后冷却备用 |
| 转移 | 用勺子或手把长满菌丝的培养基舀出，混入新培养基的表面和内部 |
| 比例 | 新培养基重量的5-10% |
| 注意 | 一份培养基可以扩增为5-10份。不过这种方式重复超过四五代后活力会下降，要定期用组织培养或孢子重新培育 |

### 4-5. 获取菌种的优先顺序

| 顺位 | 方法 | 条件 |
|:--:|:---|:---|
| 1 | 市售菌种 | 能买到时提前备好。因普及度为S级，平时最容易获得 |
| 2 | 组织培养 | 手上有新鲜菌类时，最为可靠 |
| 3 | 掰开培养基 | 已有长势良好的培养基时，速度最快 |
| 4 | 由孢子印制作稻草培养基 | 全部损失、只剩下储存的孢子时 |

&nbsp;&nbsp;&nbsp;平时该做的事很明确：能买到菌种时先种一次，用那批菌类制作20-30张孢子印埋入土窖储存。菌种本身一年就会死亡，但孢子能保存10年。这一次的工作，就是一份十年的保险。
