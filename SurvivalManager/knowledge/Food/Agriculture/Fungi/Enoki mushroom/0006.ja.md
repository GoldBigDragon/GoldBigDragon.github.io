## 13. 冷蔵庫なしの貯蔵

### 13-1. 生のままでは三日も持ちません

&nbsp;&nbsp;&nbsp;評価表でエノキタケの貯蔵性は生もの基準でEです。無電力常温で3-4日、低温で2週間です。水分が90%近くで柄が細く表面積が大きいため水が早く抜けると同時に早く傷みます。そしてこのキノコは**根元から褐変します。**束の下のほうが褐色に変わり始めると一両日で全体に広がります。

> **しかし乾かすと等級が完全に変わります。**
> 排除の判定と貯蔵性の等級は加工していない生もの基準です。乾燥は燃料も設備もほとんど使わないため、災害の状況でエノキタケの貯蔵性の問題は事実上乾燥一つで解決します。排除を作った二つの欠格のうち一つが刃物とざるだけで解けます。

### 13-2. 乾燥

&nbsp;&nbsp;&nbsp;エノキタケは乾かしやすいキノコです。柄が細いため中まですぐに乾き、傘が厚いサケツバタケのように中が乾きにくくてカビが生えることがまれです。

| 方法 | 条件 | 期間 | 結果 |
|:---|:---|:--:|:---|
| **日干し** | 束を手でほぐしてざるや干し台に広げます | 晴れた日1-2日 | 最も簡単でビタミンDが増えます |
| **陰干し** | 通風の良い軒下 | 2-4日 | 色と香りがよく残ります |
| **糸に通して吊るす** | 束のまま糸に通して軒に吊るします | 3-5日 | 場所を取りません |
| **火の傍で乾かす** | かまどの上の棚、40-50℃ | 半日 | 梅雨時に使えます。焦がさないように |
| **冬の凍結乾燥** | 零下に出して凍らせたあと冷たい風で乾かします | 5-10日 | 冬の収穫物に最も合います |

&nbsp;&nbsp;&nbsp;最後の項目がエノキタケに特に合います。このキノコは真冬に収穫するため日差しが弱く湿気が多く日光乾燥が難しいことがあります。そのとき零下の冷たい風に出すと氷がすぐに蒸発して乾きます。色が白く残り組織が崩れず乾燥品の品質が最も良いです。スケトウダラを干すのと同じ原理です。

| 段階 | 判定 |
|:---|:---|
| 完全乾燥 | **手でもむとぼろぼろに崩れます。**曲がるならまだ乾いていません |
| 保管 | 完全に冷ましたあと**密閉容器に炭や炒った塩とともに** |
| 期間 | 涼しく暗い場所で**1年以上。**粉に挽けば2年以上 |

&nbsp;&nbsp;&nbsp;一つ注意があります。エノキタケは乾くと体積が極端に減り糸くずのようになります。1kgを乾かすと80gほどが残ります。そして細いので少し触れるだけで崩れます。したがって乾燥エノキタケは丸ごと長く置くより**粉に挽いて回すほうが実用的です。**

> **細く伸びたエノキタケは乾かすとほとんど何も残りません。7節の生育抑制段階をしっかり経て太く育てたキノコが乾かしたあとも形を保ちます。抑制段階が貯蔵段階と直結します。**

### 13-3. その他の貯蔵方法

| 方法 | 作り方 | 期間 |
|:---|:---|:--:|
| **キノコ粉** | 完全乾燥後挽いて粉に。ふるいで細かいものだけ | 2年以上 |
| **塩漬け** | 茹でて水気を抜き塩を重さの20%入れて層に | 6か月-1年 |
| **醤油漬け** | 茹でて醤油と酢に漬けます | 3-6か月 |
| **発酵貯蔵** | 3%の塩水に漬けて乳酸発酵させます | 3-6か月 |
| **油漬け** | 茹でて水気を絞り油に浸します | 1-3か月 |
| **冬の自然冷蔵** | 北向きの軒下や土穴に掛けておきます | 2-3週。真冬のみ |

&nbsp;&nbsp;&nbsp;冬の自然冷蔵はエノキタケに特に有効な方法です。収穫期が真冬のため外の気温がすでに0-5℃です。北向きの軒下に網に入れて掛けておけば電力なしで2-3週間持ちます。凍って解けることを繰り返すと柔らかくなるので、凍り続けているか0℃以上に保たれる場所を選びます。

> **キノコ粉は災害の状況で特に価値があります。**
> 体積が小さく、汁物にうま味を出し、穀物の粉に混ぜてタンパク質とビタミンB群を加えられます。乾かしたものが崩れ始めたら粉に回すほうが捨てるよりよいです。

## 14. 調理と加工

### 14-1. 必ず加熱して食べます

&nbsp;&nbsp;&nbsp;エノキタケは生食しません。生のものには消化を妨げ胃を刺激する成分があり、加熱しないと細胞壁の中の栄養素を吸収できません。そして野生個体であれば12節の判別を通過していても必ず加熱します。

| 調理 | 燃料 | 時間 | 備考 |
|:---|:--:|:--:|:---|
| 茹でる | 少ない | 2-3分 | 燃料が最も少なくて済みます。ナムルに和えます |
| 炒める | 少ない | 5-8分 | 油が少しあれば味が大きく上がります |
| 汁物・鍋 | 中程度 | 5-10分 | 汁にうま味が出ます |
| 焼く | 少ない | 5分 | 束のまま炭火に載せてもよいです |
| チヂミ、揚げ物 | 中程度 | 5-8分 | 小麦粉に混ぜて焼くと量が増えます |

&nbsp;&nbsp;&nbsp;燃料を惜しむ観点でエノキタケは有利なキノコです。薄いので2-3分で煮えます。シイタケやサケツバタケのように10分以上煮なければならないキノコと違い、できあがった汁物に最後に入れて火を止める程度でも十分です。

### 14-2. 乾燥品の使い方

| 順序 | 方法 |
|:--:|:---|
| 1 | ぬるま湯に10-15分浸して戻します。細いのですぐに戻ります |
| 2 | **戻した水は捨てません。**うま味と水溶性の栄養素が溶けています |
| 3 | 底に沈んだかけらを避け上澄みだけを汁として使います |
| 4 | 戻したキノコは切って炒めたり汁物に入れたりします |
| 5 | 粉は戻さずそのまま汁物や練り物に入れます |

### 14-3. 穀物の不足を補う組み合わせ

| 組み合わせ | 効果 |
|:---|:---|
| **キノコ+穀物粥** | 穀物に不足するリシンをキノコのタンパク質が補います |
| **キノコ粉+小麦粉・そば粉** | すいとんや麺の練り粉に混ぜてタンパク質とビタミンB群を上げます |
| **キノコ+ナムル** | 微量栄養素の構成が互いに異なります |
| **キノコ+油** | 脂溶性成分の吸収が良くなります |
| **キノコ+豆** | タンパク質の補充は重なりますがアミノ酸の構成が異なります |

> **キノコは熱量源ではなくタンパク質と微量栄養素の補充源として使うのが正しいです。**
> エノキタケの場合は特にビタミンB1とB2です。穀物に偏った食事を冬の間ずっと続けるとチアミン不足で足のしびれとむくみと激しい疲労が来ます。エノキタケ一握りがその欠乏を補い、冬に他の生鮮食品が全くないときこれに代わるものがありません。

### 14-4. 冬の食卓で占める位置

&nbsp;&nbsp;&nbsp;エノキタケの実質的な価値は季節にあります。11月から3月は青い葉物がなく、貯蔵した根菜は栄養が減っており、乾燥品はビタミンCとB群がかなり抜けている時期です。その区間に新鮮な状態で出る作物はほとんどありません。エノキタケはそのときに出ます。

| 季節 | 生鮮食品 | エノキタケの役割 |
|:---|:---|:---|
| 春-秋 | ナムル、葉物、果菜 | 補助的。あえて育てる必要は少ないです |
| **11-3月** | **ほとんどない** | **唯一の生鮮タンパク質源であり、ビタミンB群の供給源** |

## 15. 年間作業スケジュール

| 月 | 作業 |
|:--:|:---|
| 1月 | **真冬の収穫。**北向き納屋と土穴で収穫します。すぐに凍結乾燥または日干し |
| 2月 | 収穫継続。2周期の休養管理。胞子紋の点検 |
| 3月 | 最後の収穫。廃培地を集めて畑に戻します。容器の洗浄と煮沸 |
| 4-5月 | おがくず集め。針葉樹のおがくずは野外に積んで雨に当てて置いておきます |
| 6月 | 卵の殻を集めて乾かして挽きます。米ぬかの確保 |
| 7-8月 | **育てません。**34℃の危険区間です。他のキノコ(サケツバタケ、キクラゲ)に切り替えます |
| **9月** | **培地の調製と殺菌。**薪を集めてドラム缶で一度に処理します |
| **10月** | **接種と培養。**室内23-25℃。雨の直後を選んで接種します |
| **11月** | **菌かきと発芽。**土穴や北向き納屋の14-15℃へ移します |
| **12月** | **生育抑制と生育。**5-7℃を経て4-9℃。最初の収穫が出ます |

&nbsp;&nbsp;&nbsp;この日程の核心は夏に休むという点です。商業栽培は冷房機で一年中育てますが、電力がなければ夏には育てられません。34℃を超えると菌糸が死に、4-9℃を作る方法がありません。無理に夏の作型を試みる代わりにその場所を他のキノコに譲り、エノキタケは冬の作物として固定するのが正しいです。

### 絶対に忘れないこと

| 項目 | 内容 |
|:--:|:---|
| 1 | **胞子が白色であるという事実がエノキタケを特に危険にします。**胞子の色でテングタケを除外することができません。木から出たか、束か、根元につぼがないか、柄の根元が濃い褐色のベルベットかを併せて見ます |
| 2 | **地面から出たものはエノキタケではありません。**エノキタケは広葉樹の腐った切り株と枯れ木にだけ出ます |
| 3 | **ひだが錆色の褐色や黄色みに変わればエノキタケではありません。**オオワライタケとニガクリタケです |
| 4 | **34度を超えると菌糸が死にます。**代謝熱のため周囲が30℃でも培地の中は超えることがあります |
| 5 | **培養のあとには必ずより冷たい場所へ移します。**温度を下げなければキノコが出ません |
| 6 | **生育抑制段階を飛ばしません。**太く育てたキノコだけが乾かしたあとに食べるものが残ります |
| 7 | **乾かせば貯蔵性の問題が消えます。**生もの基準E等級にだまされないでください |
| 8 | **電力がなければ冬の作物です。**夏に育てようとすると失敗します |
| 9 | **光合成をしないため日射が減る災害でも揺らがない食料源です。**太陽光SSは光をよく使うという意味ではなく光の外にあるという意味です |
| 10 | **最も安全なエノキタケは自分が種菌を入れたボトルから出たものです** |
