## 5. 接种方法

&nbsp;&nbsp;&nbsp;接种是金针菇栽培中失败最多的环节。灭菌把培养基清空了，可那个空出来的地方，青霉往往会比菌类的菌丝先占进去。接种的目标只有一个：让菌类的菌丝先占据地盘。

### 5-1. 接种时机与温度

| 项目 | 标准 | 原因 |
|:---|:---|:---|
| 培养基温度 | **冷却到25℃以下之后** | 更热的话菌种会死 |
| 冷却时间 | 在油桶里放一夜，或在15度环境下放13-14小时 | 必须冷透到培养基中心 |
| 速度 | 冷却后立即接种 | 放久了空气中的孢子会落上去 |
| 时间段 | **清晨或雨后不久** | 空气中孢子和灰尘最少 |
| 季节 | 9月至11月 | 是冬季作型的起点 |

&nbsp;&nbsp;&nbsp;建议在雨后不久接种，在没有无菌室时尤其有效。雨水会把空气中的孢子和灰尘冲刷掉，落下的菌数大大减少。相反，风大晴朗的白天条件最差。

### 5-2. 没有无菌室时的接种要领

| 项目 | 方法 |
|:---|:---|
| 场所 | 不透风的最小房间。仓库深处、棚屋角落 |
| 事前处理 | 往地面和墙上洒水让灰尘沉降，等待30分钟 |
| 替代无菌装置 | 把大箱子或坛子横放，内侧用开水擦过，只把手伸进去操作 |
| 手 | 用肥皂洗净，最好再用烈酒或醋擦拭 |
| 工具 | 把勺子和刀在火上烧热后冷却 |
| 衣服 | 略微潮湿的衣服比干燥的衣服更不容易扬起灰尘 |
| 呼吸 | 操作时不要在培养基上方说话或呼气，用布遮住口 |
| 动作 | 打开容器、放入菌种、盖上，要在10秒内完成 |

> **没有无菌室时，关键不是做到完全无菌，而是速度和菌种用量。杂菌多少会混入，这是防不住的，所以要让菌类的菌丝数量占绝对优势，先占据地盘。**

### 5-3. 接种量

| 项目 | 标准 |
|:---|:---|
| 标准 | 培养基重量的2-3% |
| 没有无菌室时 | **增加到培养基重量的5-10%** |
| 放入位置 | 一半放入中央孔，一半放在表面 |
| 覆盖 | 放入后把表面轻轻抹平 |
| 收口 | 用棉花或布塞住口后用绳系好，不要用塑料完全密封 |

&nbsp;&nbsp;&nbsp;不完全堵住口很重要。菌丝要用氧气，不能呼吸就长不了。同时又要挡住杂菌孢子，所以透气又能滤尘的棉花或多层布是最合适的。棉絮、旧毛巾折成四层都可以用。

### 5-4. 接种后24小时

| 时间 | 观察内容 |
|:---|:---|
| 12小时 | 还看不出变化 |
| 24-48小时 | 菌种周围开始出现**绒毛状的白色气息** |
| 3-5天 | 白色菌丝从菌种呈放射状扩散1-2cm |
| 7天 | 培养基上部被白色覆盖 |

&nbsp;&nbsp;&nbsp;这最初的几天决定成败。如果3天内白色菌丝可见地扩散开，基本上就成功了。若5天后仍无任何变化，说明菌种已经死了，或者是在培养基过热时接种的。若看到白色以外的其他颜色，要立即把那瓶移到远离其他瓶子的地方。

## 6. 菌丝培养管理

&nbsp;&nbsp;&nbsp;接种后大约22天是培养期，目标是让白色菌丝占领整个培养基。人要做的事只是保持温度、放在黑暗处，每天观察并挑出被污染的瓶子。

### 6-1. 温度与湿度

| 项目 | 范围 | 备注 |
|:---|:---:|:---|
| 菌丝生长温度 | 23-25℃ | 最快 |
| 可行范围 | 5-30℃ | 低了慢，高了危险 |
| **绝对上限** | **34℃** | **只要稍微超过菌丝就会死亡** |
| 空气湿度 | 65-75% | 太湿表面会附着杂菌 |
| 光照 | 黑暗 | 不需要光 |
| 时长 | 约22天 | 依培养基量和温度在18-28天之间 |

> **34度是绝对的红线。菌丝自身会释放代谢热，即使周围气温只有30℃，培养基内部也可能超过34℃。瓶子密集堆放时，中间部位尤其容易过热。**

&nbsp;&nbsp;&nbsp;代谢热问题在菌丝旺盛生长的培养中期最为严重。应对办法有三个：堆放时瓶间留出能伸进手指的缝隙；从培养第10天左右开始把周围气温调低2-3℃；避开盛夏进行培养。

### 6-2. 每日检查

| 观察项 | 正常 | 异常 |
|:---|:---|:---|
| 颜色 | 白色到极淡的奶油色 | 青绿色、黑色、橙色、粉色是污染 |
| 质感 | 细密如棉的白色层 | 若像粉末一样飘散，是污染孢子 |
| 气味 | 淡淡的菌香、林地土壤气味 | 酸味、闷味、氨味属于异常 |
| 进展 | 每天向下推进2-4mm | 停滞说明温度或水分有问题 |
| 容器内壁 | 菌丝贴着玻璃能看到白色纹路 | 若凝结大量水珠说明过湿 |
| 培养基表面 | 均匀发白 | 只有一侧发白说明菌种堆在了一侧 |

&nbsp;&nbsp;&nbsp;发现被污染的瓶子要立刻取出。犹豫的话孢子会扩散，连累旁边的瓶子。取出的瓶子要在远离培养场所的地方打开，内容物要烧掉或深埋。瓶子用沸水煮过后可以再次使用。

### 6-3. 判断培养是否完成

| 判定项 | 标准 |
|:---|:---|
| 颜色 | 整个培养基均匀发白 |
| 底部 | **菌丝必须已经到达底部**，只有上部发白说明未完成 |
| 硬度 | 倒扣容器，培养基仍能整块不散 |
| 追加时间 | 全部覆盖后**再放置3-5天**，称为后熟，能提高产量 |

&nbsp;&nbsp;&nbsp;跳过后熟会减少产量。表面看似已全部覆盖，但培养基内部仍有菌丝较薄的部分，多放几天效果会更好。

### 6-4. 刮菌

&nbsp;&nbsp;&nbsp;培养结束后要刮去培养基表面老化的菌丝层，去掉培养期间在表面形成的坚硬菌膜及其上堆积的老化细胞。

| 项目 | 方法 |
|:---|:---|
| 工具 | 勺子、木铲，或浸过沸水后取出的小钩子 |
| 深度 | 只刮表面2-5mm |
| 范围 | 整个表面均匀处理 |
| 目的 | 让原基一次性均匀发生 |
| 注意 | 刮得太深会大幅损伤菌丝，使发生延迟 |

&nbsp;&nbsp;&nbsp;刮菌后，菌类会在整个表面同时长出，一次性收获完毕。省略这一步，就会分好几天零零散散地长出，大小也不整齐。若需要一次性采收、一次性晒干，做这一步比较合适。

## 7. 诱导发生

&nbsp;&nbsp;&nbsp;菌丝在舒适的条件下只会不断延伸。结出菌类对菌丝来说是一种危机信号。对金针菇来说，那个信号几乎全部来自温度。把在温暖环境中生长的菌丝突然变冷，就会促使它出菌。

### 7-1. 温度阶梯

| 阶段 | 温度 | 时长 | 湿度 | 二氧化碳 | 得到什么 |
|:---|:---:|:---:|:---:|:---:|:---|
| 培养 | 23-25℃ | 22天 | 65-75% | - | 占领培养基 |
| **发生** | **14-15℃** | 8-10天 | 95-98% | 1,800-2,000ppm | 粟粒状的原基 |
| **生育抑制** | **5-7℃** | 5-15天 | 75-96% | 3,000-4,000ppm | 粗而短的菌柄 |
| **生育** | **4-9℃** | 直到采收 | 75-85% | 6,000ppm以上 | 菌柄变长 |

&nbsp;&nbsp;&nbsp;造出这个阶梯就是金针菇栽培的全部内容。商业栽培靠制冷设备完成，没有电力就靠季节和场所来实现。

| 阶梯 | 无电力的实现方法 |
|:---|:---|
| 培养23-25℃ | 9-10月的室内，或有灶台房间的一侧 |
| 发生14-15℃ | 11月的土窖或朝北棚屋，或10月的夜间气温 |
| 抑制5-7℃ | 12月的屋檐下或朝北棚屋，深夜的气温 |
| 生育4-9℃ | 12月至2月的朝北棚屋、土窖入口、冰窖旁 |

> **即使无法精确对应每一阶段的温度，菌类照样会长出来。重要的是方向：培养之后必须移到更冷的地方。若一直放在同一温度下，只会让菌丝老化而不出菌。**

### 7-2. 发生阶段要做的事

| 项目 | 方法 |
|:---|:---|
| 转移 | 把结束培养并刮过菌的瓶子移到14-15℃的地方 |
| 湿度 | 95%以上。可在瓶上盖湿布或往地面洒水 |
| 光照 | 引入微弱的光，能看清报纸的程度即可 |
| 等待 | 8-10天，表面会密集长出粟粒状的白色小颗粒 |
| 失败的信号 | 表面变干变硬，说明湿度不足 |

&nbsp;&nbsp;&nbsp;发生阶段95%的湿度是非常高的数值。不用电力实现的方法是密闭加水：把瓶子一起放进大箱子或坛子里，底部放湿沙或盛水的盘子，盖子上只留几个小孔，内部湿度很快就会升高。若完全不留孔，二氧化碳会积聚过多，水珠也会滴落到菌体上引发细菌性腐烂。

### 7-3. 生育抑制——金针菇独有的阶段

&nbsp;&nbsp;&nbsp;这是其他菌类没有的阶段。原基长出后再降到5-7℃，放置5到15天。这段时间里，菌柄不再变长，而是变粗变硬。

| 效果 | 内容 |
|:---|:---|
| 菌柄变粗 | 同样重量下菌柄数量减少，每一根都更粗 |
| 变硬 | 组织变密实，口感更好，耐储性提高 |
| 生长均匀 | 长度不会参差不齐 |
| 若省略 | 菌柄细长，缺乏力度，很快就萎蔫 |

> **在灾害状况下，抑制阶段不是可选项。粗而硬的菌类容易晒干，晒干后也不会碎裂；细长抽出的菌类一晒干就成了细丝，没什么可吃的了。**

&nbsp;&nbsp;&nbsp;不用电力实现抑制阶段最简单的方法是利用寒冬的夜晚。12月到1月朝北的棚屋，白天约7℃，夜里在0℃上下。只要昼夜平均落在5-7℃之间就足够。不过如果长时间降到零下，菌体会冻伤变软，所以要盖上稻草或草席，防止降到零下。

### 7-4. 用二氧化碳调节形态

&nbsp;&nbsp;&nbsp;这是金针菇特有的性质。二氧化碳高时菌盖保持小巧而菌柄变长；低时菌盖变大而菌柄变短。

| 目标 | 通风 | 结果 |
|:---|:---|:---|
| 长柄小盖（市售形态） | 几乎封闭。瓶口卷纸立起 | 6,000ppm以上，呈豆芽状 |
| 粗柄大盖（野生形态） | 充分通风 | 菌盖展开，菌柄变粗 |

&nbsp;&nbsp;&nbsp;在灾害状况下，后者更合适：同样的培养基产出的重量更多，带盖的一侧营养密度更高，晒干时也更能保持形态。没有理由非要仿照市场上出售的形态来培育。

&nbsp;&nbsp;&nbsp;二氧化碳浓度无法测量，只能凭感觉判断：人进去待一会儿也不觉得憋闷，就算合适。

## 8. 采收与再发生周期

### 8-1. 采收时期的判断

| 标准 | 内容 |
|:---|:---|
| 最佳时机 | 菌盖仍收拢、菌柄已充分伸长时 |
| 偏迟的信号 | **菌盖展开，菌褶间飘出白粉**，说明已开始释放孢子 |
| 延迟的后果 | 味道变差、变软，耐储性大幅下降 |
| 总时长 | 从接种到采收50-70天 |
| 采收时间 | 清晨 |

&nbsp;&nbsp;&nbsp;已开始释放孢子的菌类食用已经偏迟，但另有用处：正是第4节中最适合采集孢子的个体。若因采收延迟而出现菌盖展开的，不要丢弃，留下来制作孢子印。

### 8-2. 采摘要领

&nbsp;&nbsp;&nbsp;整束握住根部，轻轻旋转着取下。硬拉会撕裂培养基，从伤口处会招来杂菌。根部带培养基的部分用刀切掉。

&nbsp;&nbsp;&nbsp;采收下来的菌类不要洗。沾水会使耐储性急剧下降，培养基碎屑用干布擦掉即可。

### 8-3. 再发生

| 项目 | 内容 |
|:---|:---|
| 休养期 | 采收后10-15天 |
| 休养期间的管理 | 刮去表面残留的根部，保持湿度并置于13-15度 |
| 第2周期产量 | 第1周期的50-70% |
| 第3周期产量 | 第1周期的20-30%，意义已经不大 |
| 总采收次数 | **最多2-3次** |
| 再采收间隔 | 30-60天 |

&nbsp;&nbsp;&nbsp;评价表中的持续性D级说的正是这张表的内容。第2周期产量降到一半，第3周期降到25%以下。收到第2周期就换培养基，投入产出比最好。

&nbsp;&nbsp;&nbsp;在灾害状况下，这个算法会有所不同。如果重新获取木屑并再次蒸煮所耗的燃料和劳力很大，即使产量降低，坚持到第3周期也可能更合算。若培养基变黑并散发酸味，那就是极限了。

### 8-4. 产量

| 条件 | 产量 |
|:---|:---|
| 1,000ml瓶、培养基600-750g | 第1周期150-250g |
| 含第2周期 | 每瓶250-350g |
| 添加10%蛋壳 | 1.21倍 |
| 添加20%中药药渣 | 1.10倍 |
| 生物学效率 | 培养基干物重的30-50% |

&nbsp;&nbsp;&nbsp;一瓶经过两个周期能产出300g左右。生品300g约63kcal，蛋白质7.4g。作为热量来源几乎没有意义，但作为蛋白质和B族维生素的来源意义重大。把二十瓶编成一组轮流栽培，规模上足够在寒冬两个月里每天提供一把凉拌菜或汤料。

> **如果按热量来折算金针菇的产量并据此制定计划，会让人失望。应该换个角度衡量它的价值：在冬天完全没有绿色蔬菜的时候，它是唯一能提供维生素B1、B2和赖氨酸的新鲜食物。**

## 9. 污染与病虫害

### 9-1. 青霉是头号原因

&nbsp;&nbsp;&nbsp;灾害状况下菌类栽培失败最常见的原因，不是病虫害，而是培养基被竞争性霉菌抢占。其中占绝大多数的是木霉（Trichoderma），也就是青霉。金针菇用的是灭菌培养基，这个风险比大球盖菇要大得多，因为灭过菌的培养基对杂菌来说同样是一片空地。

| 区分 | 金针菇菌丝 | 青霉 |
|:---|:---|:---|
| 颜色 | 白色，极淡的奶油色 | 起初白色，很快变**青绿色** |
| 质感 | 细密如棉的层 | 像粉末一样细碎、松散 |
| 蔓延速度 | 每天2-4mm | 每天10-30mm，**快5-10倍** |
| 气味 | 林地土壤气味、菌香 | 闷味，有时类似椰子的香气 |
| 边界 | 沿培养基均匀分布 | 从圆形斑点呈放射状扩散 |

> **青霉在颜色显现之前就已经扩散开了。**
> 青绿色是孢子形成的阶段，也就是已经开始繁殖之后。到那时应视为培养基已经损失了相当一部分。早期判别不能靠颜色，而要靠蔓延速度和质感。

### 9-2. 其他污染菌

| 污染菌 | 表现 | 原因 |
|:---|:---|:---|
| 黑霉（曲霉） | 黑色粉末聚集生长 | 灭菌不足，尤其米糠过多时 |
| 红霉（镰刀菌） | 粉红色绵状物 | 培养基过湿时 |
| 白色绒毛霉（根霉） | 高高长出的白毛快速蹿起 | 培养基过湿、通风不良时 |
| 细菌（芽孢杆菌） | 培养基发黏并有酸味 | 灭菌不充分且培养基过湿 |
| 黄色细菌斑 | 菌柄上出现黄色黏液 | 湿度过高且有水珠滴落 |

&nbsp;&nbsp;&nbsp;细菌污染颜色几乎不变，只能靠气味察觉，不容易分辨。培养基若散发酸味或腐败面团的气味，就是细菌污染，说明灭菌时间不够。

### 9-3. 发现污染时的处理与预防方法

| 情况 | 处理 |
|:---|:---|
| **一瓶表面出现小斑点** | 立即单独取出那一瓶，**不要打开瓶子**直接移走 |
| **已蔓延到多瓶** | 把整个培养场所迁走，原场所清空后用水洗净晒干 |
| **整瓶培养基变青绿色** | 全部废弃，烧掉或埋在远离栽培场地的地方 |
| **培养基散发酸味** | 是细菌污染，废弃并延长下一批的灭菌时间 |

> **被污染的培养基不要归还堆肥。**
> 青霉孢子能在堆肥堆中存活，来年会再次混入培养基。必须烧掉或深埋在远离栽培场地的地方。

| 预防 | 原理 |
|:---|:---|
| **充分灭菌** | 常压100度4-6小时，省事就必定会付出代价 |
| **多接种菌种** | 培养基重量的5-10%，先占地盘的一方获胜 |
| **米糠不超过20%** | 养分过多会让竞争霉菌先爆发 |
| **瓶间留缝堆放** | 通风才能散热，霉菌才不会蔓延 |
| **雨后不久接种** | 空气中落下的孢子最少 |
| **每年更换培养场所** | 一直用同一处会使孢子不断累积 |

### 9-4. 害虫

| 害虫 | 危害 | 处理 |
|:---|:---|:---|
| **菌蚊（蚤蝇类）** | 蛀食菌丝，使子实体生蛆，还会传播青霉孢子 | 用布堵住瓶口进行物理隔绝，发生时用水盆诱捕或粘虫纸 |
| **螨虫** | 菌丝变褐并停止生长 | 保持干燥管理，发生的区块要隔离 |
| **蛞蝓** | 啃食幼嫩的子实体 | 用草木灰或木屑围一道带子来阻挡 |
| **老鼠** | 叼走菌类并翻乱培养基 | 把瓶子放到架子上并罩上网 |

&nbsp;&nbsp;&nbsp;冬季栽培这一点在害虫防治上是个大优势。菌蚊和螨虫在气温降到10℃以下时活动几乎停止。把金针菇固定为寒冬作型，害虫问题自然就能减少一半以上。相反，若勉强在夏天栽培，害虫和污染会一起涌来。
