### 1-3. 日照SSが意味すること

&nbsp;&nbsp;&nbsp;評価表の日照項目は本来、40%遮光の条件で収量がどれだけ残るかを問うものです。ジャガイモは80%前後が残り、イネとトウモロコシはさらに大きく落ちます。エノキタケに付いたSSはこの競争に勝ったという意味ではなく、そもそもその軸の上にないという意味です。菌類には葉緑素がありません。エノキタケが使う炭素はおがくずと米ぬかにすでに固定されているセルロースとでんぷんであり、空の明るさはその在庫に何の影響も与えません。

&nbsp;&nbsp;&nbsp;大規模な火山噴火や核の冬のように成層圏にエアロゾルが広がり、日射量が数年にわたって減る状況で、この違いが決定的に表れます。そのとき穀物といも類（塊茎・塊根）と野菜は同時に崩れますが、倒れた木と乾いた藁はそのまま残り、それを人が食べられるタンパク質に変える唯一の経路がキノコです。

&nbsp;&nbsp;&nbsp;エノキタケにはここにもう一つ加わります。日射が減れば気温も一緒に下がります。大多数の作物と大多数のキノコにとってそれは災いですが、エノキタケにとってはむしろ条件が合致します。このキノコは子実体を4-9℃で育て、野生では雪の中でも生えます。評価表の耐寒性がDであるのは低温そのものに耐えられないという意味ではなく、精密な温度段階の制御が前提になるという意味であり、言い換えれば涼しさはエノキタケの敵ではなく材料です。

> **キノコは日光が消えた世界でも収量が減らない唯一の食料源であり、エノキタケはその中でも寒くなるほど条件が良くなる稀な種です。**

### 1-4. 強みをどう読むか

&nbsp;&nbsp;&nbsp;SSが付いた項目はタンパク質密度、日照、整地・掘削エネルギー、収量安定性の四つです。Sは収穫速度、連作適応性、味、韓国国内普及度の四つです。

&nbsp;&nbsp;&nbsp;収穫速度Sは除外作物としては目立つ値です。接種から収穫まで50-60日なら二か月です。シイタケが原木接種から最初のキノコまで12-18か月を要するのと比べると差が大きいです。災害が起きた年に始めて、その年のうちに食べられるキノコという意味であり、永続性Dの裏返しの顔でもあります。長く続かない代わりに速いのです。

&nbsp;&nbsp;&nbsp;韓国国内普及度Sも実質的です。エノキタケは韓国国内で最も多く栽培されているキノコの一つで、韓国全土どこでも種菌を入手できます。サケツバタケが普及度Dで種菌の入手が難しいのとは正反対です。災害の直前や直後に種菌を確保できる可能性がそれだけ高いのです。

&nbsp;&nbsp;&nbsp;収量安定性SSは室内培地栽培で気象と連動しないために付いた値です。夏の梅雨（韓国では6月下旬から7月ごろ、チャンマ）や秋の台風が収穫を左右しません。培地を適切に作り温度を合わせれば、毎年同じ量が出ます。

&nbsp;&nbsp;&nbsp;そしてもう一つ、評価表にない強みがあります。エノキタケは針葉樹のおがくずを使うことができます。シイタケとヤマブシタケとサケツバタケは松系統の樹脂とテルペンに菌糸が抑制されて針葉樹を使えませんが、エノキタケでは米松のおがくずがむしろ標準の培地材料として使われます。周囲に広葉樹が少なく松とチョウセンゴヨウしかない地域では、これが決定的な差になります。

### 1-5. 弱みをどう読むか

&nbsp;&nbsp;&nbsp;Eが三つです。施設負担、温度適応幅、貯蔵性。Dが四つです。永続性、施肥、耐寒性、種子寿命。

&nbsp;&nbsp;&nbsp;施設負担Eが最も痛いです。商業栽培でエノキタケは栽培施設と冷房設備と瓶容器を前提とします。冷房は年中電力を食います。電力が絶たれた状況ではこの組み合わせは成立しません。対応は一つだけです。冷房設備を人が作るのではなく、季節と土地から借りることです。土窟や地下室、北向きの倉庫、井戸端、ソクビンゴ(Seokbingo、韓国伝統の氷室)のような穴、そして何より冬そのものです。3節と7節でこの話を詳しく扱います。

&nbsp;&nbsp;&nbsp;温度適応幅Eも同じ根から来ています。芽出しが10-12℃、生育が6-8℃なので、幅は6℃にもなりません。他の作物なら致命的な狭さですが、冬にだけ栽培する作型と決めれば、この狭さは管理すべき対象ではなく季節がおのずと合わせてくれる条件になります。エノキタケを一年中育てようとすれば失敗し、冬作物と決めれば成功します。

&nbsp;&nbsp;&nbsp;永続性Dと施肥Dは合わせて読む必要があります。培地を一度使って捨てる構造のため、㎡当たり年60kgのおがくずと米ぬかが継続的に入っていきます。化学肥料は一切使いませんが、有機物の消耗は多肥性作物の水準です。解決の道は11節の廃培地の循環です。エノキタケの廃培地は次の周期の培地の20%まで混ぜて使うことができ、残りは畑の有機物として戻ります。捨てるのではなく二度三度使うことに変えれば、この弱みはかなり減ります。

&nbsp;&nbsp;&nbsp;自家採種Cと種子寿命Dも合わせて見ます。市販の種菌は6か月から1年で活力を失い、無菌培養なしに純粋菌株を維持することは難しいです。対応は4節で扱う胞子紋の保存と組織培養です。胞子をアルミホイルに乾かして土窟に置けば5-10年もつので、種菌が死んでも胞子だけ生きていれば再び始めることができます。

&nbsp;&nbsp;&nbsp;非食用価値Eは8項目のうち該当がないという意味です。薬材としても、土壌改良材としても、害虫防除用としても、使える用途が確認されていません。エノキタケは食べること以外に他の使い道がないキノコです。

&nbsp;&nbsp;&nbsp;そしてもう一つ、評価表に書かれていない弱みがあります。誤認の危険です。野生のエノキタケ、すなわち韓国語の正式名でパンナムボソッ(paengnamu-beoseot)は晩秋から早春にかけて広葉樹の切り株に束になって生え、同じ場所・同じ季節に致命的な毒キノコも同じ姿で生えます。しかもエノキタケの胞子は白色から淡黄色であるため、サケツバタケで使う「胞子が白ければ食べない」という規則はここでは使えません。12節を必ず読む必要があります。

## 2. どんな菌類か

### 2-1. 名前と分類

&nbsp;&nbsp;&nbsp;エノキタケは担子菌門・ハラタケ綱・ハラタケ目・Physalacriaceae科・Flammulina属に属します。韓国語の正式名は「パンナムボソッ」(paengnamu-beoseot、直訳:エノキのキノコ)です。エノキ(榎、Celtis sinensis)の切り株によく生えることから付いた名前で、市場で呼ばれる「パンイボソッ」(paengi-beoseot)という名前が広く定着したものです。

&nbsp;&nbsp;&nbsp;学名Flammulina velutipesにおいて、属名は小さな炎、種名velutipesはビロードのような足という意味です。野生個体の傘が橙がかった黄褐色で、柄の根元が濃い褐色のビロード状の毛で覆われていることから来た名前です。この種名が指す部位が12節で安全確認の要となる標識になるので、覚えておく価値があります。

&nbsp;&nbsp;&nbsp;生態的には広葉樹の枯れた幹と切り株を分解する白色腐朽菌です。エノキ、カキ、クワ、ヤナギ、ポプラ、ニレの枯死木や切り株に束になって生えます。生きた木の傷から弱い寄生性を示すこともあります。そして決定的な特徴があります。このキノコは晩秋から早春、さらには真冬の雪の中でも子実体を出します。他のキノコがすべて止まる季節がエノキタケの旬です。

### 2-2. 野生個体と栽培個体は見た目が全く異なります

&nbsp;&nbsp;&nbsp;エノキタケを学ぶ際に最初に押さえるべき点です。店で売られているエノキタケは純白色で、豆もやしのように長く細い柄を持ち、傘の直径はわずか1cm前後です。野生のパンナムボソッは橙がかった黄褐色の傘が直径2-8cmまで開き、柄は短く太く、根元は濃い褐色です。同じ種だと信じがたいほど違います。

&nbsp;&nbsp;&nbsp;違いは栽培環境から来ています。瓶の周りに紙を巻いて光を遮り、二酸化炭素を6,000ppm以上に上げると、菌糸は傘を育てられず柄だけを長く伸ばします。光がないので色素も作られず白いまま残ります。私たちが知るエノキタケの形は種本来の姿ではなく、暗さと高二酸化炭素が作った形なのです。

> **この違いを知らなければ、野生でパンナムボソッを見ても気づかず、逆に見当違いのキノコをエノキタケだと信じてしまいます。12節のすべての判別は野生個体の形質を基準に書かれています。**

### 2-4. 生活史 - 胞子からキノコまで

&nbsp;&nbsp;&nbsp;キノコの生活史は植物と異なります。種一粒が木一本になる植物とは違い、キノコの胞子一粒だけでは単独でキノコになれません。

| 段階 | 何が起こるか |
|:---|:---|
| 胞子 | 成熟した傘のひだから落ちます。遺伝子を半分だけ持つ単核細胞です |
| 一次菌糸 | 胞子が発芽して糸状に伸びます。遺伝子が半分だけなのでキノコを作れず、勢いが弱まって死滅します |
| 二次菌糸 | 異なる交配型の一次菌糸二つが出会って結合します。この状態でなければキノコを結実できません |
| 培地の占有 | 二次菌糸がおがくず培地全体を白く覆います。20-25日かかります |
| 菌搔きと芽出し | 培地表面の老化した菌糸層を掻き取り温度を下げると、粟粒のような原基が形成されます |
| 生育抑制 | さらに5-7度まで下げて柄を太く短く締めます |
| 子実体 | 4-9度で柄が伸びながら育ちます |

&nbsp;&nbsp;&nbsp;胞子一粒からはキノコが出ないという事実は実践において重要です。胞子を惜しんで一粒ずつ慎重に落とすと、一次菌糸だけが育って死滅します。多数の胞子粉を一度にたっぷりと振り入れ、培地の中で互いに出会って結合するように誘導しなければなりません。

> **胞子は惜しみません。一粒ではキノコになりません。**

### 2-5. 生育段階と所要期間

| 段階 | 期間 | 温度 | 湿度 | 何を見るか |

| 接種 | - | 培地を25℃以下に冷ました後 | - | 雑菌が入らないよう素早く |

| 収穫 | - | - | - | 合計50-70日 |

&nbsp;&nbsp;&nbsp;この表で重要なのは、温度が段階的に下がっていく点です。23℃から15℃へ、さらに6℃へ、さらに4℃から9℃へと下がります。商業栽培でこの段階を作るのは冷房機であり、電力がない状況では晩秋から早春の自然な気温変化がその役割を代わりに果たします。10月に培地を作り、11月に培養を終え、12月に芽出しを経て真冬に収穫する作型が、この段階とちょうど合致します。

&nbsp;&nbsp;&nbsp;34℃は絶対的な境界線です。培養中の培地温度が34℃を少しでも超えると菌糸が死にます。菌糸自身が代謝熱を出すため、夏に培養するとこの線を超えやすくなります。真夏の培養を避ける理由です。

&nbsp;&nbsp;&nbsp;熱量21kcalは非常に低いです。1日2,100kcalをエノキタケだけで満たすには10kgを食べる必要があり、物理的に不可能です。エノキタケは主食ではなく副食であり、その位置では価値が高いです。

&nbsp;&nbsp;&nbsp;特にビタミンB1とB2が1日必要量の25%水準であるという点は、災害時に実用的です。穀物に偏った食事を長く続けると、まずチアミン不足が現れ、脚気の症状である脚のしびれ、むくみ、疲労が続きます。エノキタケ一握りはその欠乏を埋めます。そして穀物に不足するリジンをキノコのタンパク質が補うので、お粥やスジェビ(手でちぎった生地を入れる韓国式のすいとん)に混ぜるとタンパク質の質が上がります。
