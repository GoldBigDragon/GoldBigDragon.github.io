## 10. 생육 이상 진단

| 증상 | 원인 | 조치 |
|:---|:---|:---|
| 접종 5일이 지나도 균사가 안 보임 | 배지가 뜨거울 때 접종함, 종균이 죽음 | 배지를 25℃ 이하로 식혀 다시 접종합니다 |
| 균사가 뻗다 멈춤 | 배지 온도 34도 초과, 수분 부족 | 병 사이를 벌려 열을 빼고 주변 기온을 낮춥니다 |
| 균사가 덮였는데 버섯이 안 남 | 온도를 내리지 않음. 균긁기를 안 함 | 14-15℃로 옮기고 표면을 긁습니다 |
| 원기가 맺혔다 말라 죽음 | 습도 부족 | 젖은 천을 덮고 바닥에 물을 뿌려 95%로 올립니다 |
| 대만 가늘고 길게 뽑힘 | 억제 단계를 건너뜀, 이산화탄소 과다 | 5-7℃에 5-15일 두고 환기를 늘립니다 |
| 갓이 너무 커지고 대가 짧음 | 이산화탄소 부족, 온도가 높음 | 환기를 줄이고 더 찬 곳으로 옮깁니다 |
| 버섯이 물러지고 노란 점액 | 세균성 무름. 물방울이 떨어짐 | 덮개의 물방울을 털고 환기합니다. 병든 것은 치웁니다 |
| 갓이 갈색으로 변함 | 온도가 너무 높음. 수확 시기 경과 | 더 찬 곳으로 옮기고 제때 수확합니다 |
| 밑동이 갈색으로 녹음 | 물이 배지에 고임 | 물을 직접 붓지 않습니다. 공중 습도로만 올립니다 |
| 버섯이 한쪽에만 남 | 종균이 한쪽에 뭉쳤음, 빛이 한쪽에서만 듦 | 다음 주기에 종균을 고르게 뿌리고 병을 돌려 놓습니다 |
| 2주기 수량이 거의 없음 | 배지 양분 소진 | 정상입니다. 배지를 바꿉니다 |
| 배지가 검고 시큼함 | 세균 번식. 배지 수명 끝 | 폐기하고 폐배지로 돌립니다 |

## 11. 폐배지 순환

### 11-1. 폐배지는 버리는 것이 아닙니다

&nbsp;&nbsp;&nbsp;버섯이 다 나온 뒤의 배지는 균사가 목질을 분해해 놓은 양질의 유기물입니다. 생톱밥보다 분해가 훨씬 진행되어 밭에 바로 넣을 수 있습니다. 평가표의 시비 D가 연 60kg의 유기물 투입을 가리키는데, 그 60kg이 한 번 쓰고 사라지는 것이 아니라 돌고 있다는 점이 중요합니다.

| 용도 | 방법 |
|:---|:---|
| **다음 주기 배지에 혼합** | 새 배지의 20%까지 섞습니다. 표준 배합에 이미 들어 있는 항목입니다 |
| **밑거름** | 가을에 밭에 펴서 갈아 넣습니다. 유기물과 칼륨 공급이 큽니다 |
| **멀칭재** | 작물 사이에 5cm 두께로 깔아 잡초와 수분 증발을 막습니다 |
| **다른 버섯 배지** | 독청버섯아재비의 목재칩 배지에 섞어 쓸 수 있습니다 |
| **퇴비 촉진제** | 퇴비 더미에 섞으면 분해가 빨라집니다 |
| **지렁이 사육 기질** | 지렁이가 잘 먹습니다. 분변토를 얻을 수 있습니다 |
| **땔감** | 완전히 말리면 불땀이 약하지만 탑니다 |

```
침엽수·활엽수 톱밥 + 미강 → 배지 → 버섯 수확 → 폐배지
                                      ↓            ↓
                            다음 배지 20%   밭 유기물
```

&nbsp;&nbsp;&nbsp;폐배지를 다음 주기에 20% 섞어 쓰면 새로 필요한 톱밥이 20% 줄어듭니다. 영속성 D와 시비 D의 부담을 직접 덜어 내는 유일한 수단입니다. 다만 오염된 배지는 절대 섞지 않습니다. 푸른곰팡이 포자가 새 배지로 그대로 들어갑니다.

### 11-2. 배양 장소의 연차 관리

| 연차 | 관리 |
|:--:|:---|
| 1년 | 같은 장소를 계속 써도 괜찮습니다 |
| 2년 | 주기 사이에 장소를 비우고 물로 씻어 햇볕에 말립니다 |
| 3년 | 장소를 옮기는 것이 안전합니다. 잡균 포자가 누적됩니다 |
| 비상 조치 | 벽과 바닥에 석회 유황물이나 진한 나무재 잿물을 바릅니다 |

&nbsp;&nbsp;&nbsp;실내 재배는 잡균 포자가 쌓이는 속도가 빠릅니다. 한 주기를 끝내면 빈 공간을 며칠 비워 두고, 가능하면 문을 열어 햇빛이 들게 합니다. 자외선이 낙하 포자를 상당히 줄입니다. 전력도 약품도 필요 없는 방법입니다.

## 12. 독버섯 오인과 안전 확인

> **이 절은 생명과 직결됩니다. 기르는 것보다 먹어도 되는지 확인하는 것이 더 중요합니다.**

&nbsp;&nbsp;&nbsp;팽이버섯은 이 문서가 다루는 여섯 종 가운데 야생에서 독버섯과 혼동될 위험이 가장 큽니다. 이유는 셋입니다. 첫째, 야생 팽나무버섯이 돋는 활엽수 썩은 그루터기에 다른 버섯들도 똑같이 다발로 돋습니다. 둘째, 재배 개체와 야생 개체가 너무 달라 기른 것만 본 사람은 야생 개체를 알아보지 못합니다. 셋째, 그리고 가장 중요하게, 팽이버섯의 포자가 흰색입니다.

### 12-1. 포자가 흰색이면 먹지 않는다는 규칙을 여기서는 쓸 수 없습니다

&nbsp;&nbsp;&nbsp;독청버섯아재비 문서에는 간단하고 강력한 방어선이 있습니다. 흰 종이에 갓을 엎어 얹어 포자를 받았을 때 가루가 하얗다면 먹지 않는다는 규칙입니다. 독우산광대버섯과 흰알광대버섯 같은 치명적 독버섯이 흰 포자를 내고 독청버섯아재비는 자갈색 포자를 내기 때문에, 이 한 번의 확인으로 가장 위험한 종을 걸러 낼 수 있습니다. 양송이도 갈색 포자를 내므로 같은 규칙이 듭니다.

&nbsp;&nbsp;&nbsp;팽이버섯은 다릅니다. **팽이버섯의 포자는 흰색에서 아주 연한 노랑입니다.** 광대버섯류와 같은 색입니다. 따라서 포자 색으로 광대버섯을 배제할 수 없습니다.

> **팽이버섯에서 포자 색은 광대버섯을 걸러 내는 수단이 아닙니다. 반대로 쓰입니다. 포자가 녹슨 갈색이거나 자갈색이면 팽이버섯이 아니라는 판정에 씁니다.**

| 버섯 | 포자 색 | 이 색이 뜻하는 것 |
|:---|:---|:---|
| **팽이버섯(팽나무버섯)** | **흰색-연노랑** | 기준 |
| 독우산광대버섯, 흰알광대버섯 | 흰색 | **포자 색으로 구별되지 않습니다.** 다른 형질을 봐야 합니다 |
| 갈황색미치광이버섯 | **녹슨 갈색** | 팽이버섯이 아닙니다 |
| 끈적버섯류 | **녹슨 갈색** | 팽이버섯이 아닙니다 |
| 노랑다발 | **자갈색-흑갈색** | 팽이버섯이 아닙니다 |
| 검은비늘버섯류 | 갈색 | 팽이버섯이 아닙니다 |

&nbsp;&nbsp;&nbsp;포자를 받을 때도 주의가 필요합니다. 팽이버섯의 포자는 흰색이므로 흰 종이에서는 보이지 않습니다. 검은 종이나 은박지, 유리판에 받아야 합니다. 그리고 반드시 종이를 절반은 흰색, 절반은 검은색으로 두 가지를 대어 받으십시오. 그러면 흰 포자와 짙은 포자를 모두 한 번에 판정할 수 있습니다.

### 12-2. 팽이버섯의 확인 형질 - 다섯 가지를 모두 봅니다

&nbsp;&nbsp;&nbsp;포자 색이라는 단일 방어선을 쓸 수 없으므로, 여러 형질을 함께 확인하는 방식으로 바꿉니다. 아래 다섯 가지가 모두 맞아야 팽이버섯으로 봅니다. 하나라도 어긋나면 먹지 않습니다.

| 번호 | 형질 | 팽이버섯의 기준 |
|:--:|:---|:---|
| **1** | **발생 기질** | **활엽수의 썩은 그루터기, 고사목, 넘어진 줄기.** 땅에서 난 것은 팽이버섯이 아닙니다 |
| **2** | **갓의 점액질** | **습할 때 만지면 끈적하고 미끈합니다.** 마르면 약해지므로 비 온 뒤에 확인합니다 |
| **3** | **대 밑동의 짙은 갈색 털** | **밑동이 짙은 갈색에서 흑갈색이고 짧은 벨벳 같은 털로 덮여 있습니다** |
| **4** | **다발로 돋는 습성** | **여러 개가 밑동에서 붙어 빽빽한 다발을 이룹니다.** 하나씩 떨어져 난 것은 다른 버섯입니다 |
| **5** | **턱받이와 대주머니가 모두 없음** | **대에 고리도 막 조각도 거미줄 흔적도 없고, 밑동을 파도 주머니가 없습니다** |

&nbsp;&nbsp;&nbsp;여기에 보조 형질을 덧붙입니다.

| 보조 형질 | 팽이버섯의 기준 |
|:---|:---|
| 계절 | **늦가을에서 초봄.** 한여름에 난 것은 팽이버섯이 아닐 가능성이 큽니다 |
| 주름 색 | 흰색에서 연크림색. **성숙해도 갈색이나 녹슨색으로 변하지 않습니다** |
| 갓 색 | 황갈색에서 주황빛 적갈색. 중앙이 짙고 가장자리가 연합니다 |
| 맛 | **쓴맛이 없습니다.** 혀끝에 살짝 대었을 때 쓰면 뱉고 먹지 않습니다 |
| 살 색 | 흰색. 자르거나 멍들어도 노랗게 변하지 않습니다 |

> **다섯 가지 주요 형질 가운데 하나라도 어긋나면 먹지 않습니다. 특히 땅에서 난 것은 아무리 비슷해 보여도 팽이버섯이 아닙니다.**

### 12-3. 갈황색미치광이버섯 - 가장 헷갈리는 상대

&nbsp;&nbsp;&nbsp;갈황색미치광이버섯(Gymnopilus junonius)은 팽이버섯과 가장 헷갈리는 버섯입니다. 같은 계절에 같은 활엽수 그루터기에 똑같이 큰 다발로 돋고, 갓 색도 황갈색에서 주황빛이어서 멀리서 보면 거의 구별되지 않습니다. 일본에서는 웃음버섯이라 부르는데, 먹으면 환각과 흥분과 정신착란이 오기 때문입니다.

| 구분 | **팽이버섯** | **갈황색미치광이버섯(독)** |
|:---|:---|:---|
| **포자 색** | **흰색-연노랑** | **녹슨 갈색. 결정적 차이입니다** |
| **주름 색** | **끝까지 흰색-연크림색** | **처음 노란색 → 자라면서 녹슨 갈색-적갈색** |
| **턱받이** | **없습니다** | **있습니다.** 섬유질 고리가 대 위쪽에 남습니다 |
| **갓 표면** | **습할 때 점액질. 끈적합니다** | **건조하고 미세한 섬유상 비늘.** 끈적하지 않습니다 |
| **대 밑동** | **짙은 갈색 벨벳 털** | 대와 같은 황갈색. 털이 없고 **밑동이 부풀어 방망이 모양** |
| 갓 지름 | 2-8cm | **6-15cm. 훨씬 큽니다** |
| 대 굵기 | 0.3-0.8cm | 1-3cm. 굵고 단단합니다 |
| 맛 | 쓴맛 없음 | **매우 씁니다** |
| 발생 기질 | 활엽수 썩은 그루터기 | 활엽수와 침엽수 그루터기 모두 |
| 계절 | 늦가을-초봄 | 여름에서 가을 |

> **세 가지만 기억하면 갈라집니다. 주름이 녹슨 갈색으로 변하는가, 대에 턱받이 고리가 있는가, 갓이 끈적하지 않고 마른 섬유질인가. 하나라도 그렇다면 갈황색미치광이버섯입니다.**

&nbsp;&nbsp;&nbsp;중독 증상은 먹고 30분에서 3시간 안에 시작됩니다. 어지러움, 심한 흥분과 웃음, 환시와 환청, 근육 경직, 구토와 복통이 옵니다. 대개 하루 이틀에 회복되지만 다량을 먹으면 정신착란이 심해지고 탈수로 위험해집니다. 의료 지원이 없는 상황에서는 충분한 물을 먹이고 따뜻하게 눕혀 지켜보는 것 외에 할 일이 없습니다.

### 12-4. 독우산광대버섯과 흰알광대버섯 - 포자 색으로 걸러지지 않습니다

&nbsp;&nbsp;&nbsp;이쪽이 더 치명적입니다. 아마톡신 한 개체분으로 사람이 죽습니다. 그리고 포자가 흰색이라 팽이버섯과 포자 색이 같습니다.

| 구분 | **팽이버섯** | **독우산광대버섯·흰알광대버섯(치명적)** |
|:---|:---|:---|
| 포자 색 | 흰색-연노랑 | **흰색. 구별되지 않습니다** |
| 주름 색 | 흰색-연크림색 | **흰색. 구별되지 않습니다** |
| **발생 기질** | **활엽수 썩은 그루터기·고사목** | **살아 있는 나무 뿌리 근처의 땅.** 결정적 차이입니다 |
| **발생 습성** | **빽빽한 다발** | **하나씩 또는 몇 개가 떨어져 남** |
| **대주머니** | **없습니다** | **있습니다.** 막으로 된 주머니가 밑동을 감쌉니다 |
| **턱받이** | **없습니다** | **있습니다.** 흰 막 고리가 대 위쪽에 남습니다 |
| 갓 색 | 황갈색-주황빛 적갈색 | **흰색에서 연한 녹황색** |
| 갓 표면 | 습할 때 점액질 | 매끈하고 건조합니다 |
| 대 밑동 털 | 짙은 갈색 벨벳 털 | 없습니다. 흰색이고 매끈합니다 |
| 크기 | 갓 2-8cm | 갓 6-15cm, 대 9-20cm. 훨씬 큽니다 |

> **팽이버섯과 광대버섯류를 가르는 것은 포자 색이 아니라 네 가지입니다. 나무에서 났는가 땅에서 났는가, 다발인가 외톨이인가, 밑동에 주머니가 있는가, 대에 턱받이가 있는가.**

&nbsp;&nbsp;&nbsp;**대주머니 확인은 반드시 파서 해야 합니다.** 땅 위로 나온 부분만 보면 주머니가 흙에 묻혀 보이지 않습니다. 밑동을 흙째 파내어 확인하는 습관을 들이십시오. 팽이버섯은 나무에서 나므로 파낼 흙 자체가 없고, 뽑으면 나무에 붙어 있던 밑동이 그대로 드러납니다. 흙을 파야 하는 상황 자체가 이미 팽이버섯이 아니라는 신호입니다.

### 12-5. 끈적버섯류 - 증상이 늦게 오는 쪽이 더 위험합니다

&nbsp;&nbsp;&nbsp;끈적버섯속(Cortinarius)에는 오렐라닌이라는 독소를 가진 종이 있습니다. 오렌지귀신끈적버섯과 적갈색끈적버섯이 그쪽입니다. 이 독은 신장을 파괴하고, 무엇보다 증상이 먹고 2일에서 21일 뒤에 나타납니다. 그 사이에는 아무 이상이 없으므로 자신이 중독되었다는 사실조차 모릅니다.

| 구분 | **팽이버섯** | **끈적버섯류(신장 파괴)** |
|:---|:---|:---|
| **포자 색** | **흰색-연노랑** | **녹슨 갈색** |
| **거미집막** | **없습니다** | **어릴 때 갓 가장자리와 대 사이에 거미줄 같은 막.** 성숙하면 대에 녹슨 갈색 띠로 남습니다 |
| 주름 색 | 흰색-연크림색 | 처음 연한 색 → 녹슨 갈색 |
| **발생 기질** | **활엽수 썩은 그루터기** | **땅.** 나무 뿌리와 공생하는 균근성입니다 |
| 발생 습성 | 빽빽한 다발 | 흩어져 남 |
| 갓 표면 | 점액질 | 섬유질 또는 비늘 |
| 대 밑동 | 짙은 갈색 벨벳 털 | 털이 없습니다 |

> **대에 녹슨 갈색 띠가 있거나 어린 개체의 갓 가장자리에 거미줄 같은 막이 보이면 끈적버섯류입니다. 절대 먹지 않습니다. 증상이 없다고 안심하는 것이 이 독의 가장 무서운 점입니다.**

### 12-6. 노랑다발 - 기질과 습성이 똑같습니다

&nbsp;&nbsp;&nbsp;노랑다발(Hypholoma fasciculare)은 위 세 종보다 흔하고, 팽이버섯과 가장 같은 자리에서 같은 모양으로 돋습니다. 활엽수와 침엽수의 썩은 그루터기에 빽빽한 다발로 나고 갓이 노란빛 황갈색입니다. 발생 기질과 다발 습성만으로는 갈라지지 않습니다.

| 구분 | **팽이버섯** | **노랑다발(독)** |
|:---|:---|:---|
| **포자 색** | **흰색-연노랑** | **자갈색-흑갈색** |
| **주름 색** | **끝까지 흰색-연크림색** | **처음 유황색 → 녹황색 → 올리브갈색 → 자갈색** |
| **맛** | **쓴맛 없음** | **매우 씁니다. 혀에 대면 바로 알 수 있습니다** |
| 갓 색 | 황갈색-주황빛 적갈색 | 유황색-황갈색, 중앙이 적갈색 |
| 갓 표면 | 습할 때 점액질 | 매끈하고 건조합니다 |
| 대 밑동 | 짙은 갈색 벨벳 털 | 털이 없습니다. 대 전체가 노란색에서 황갈색 |
| 발생 기질 | 활엽수 썩은 그루터기 | 같습니다 |
| 발생 습성 | 빽빽한 다발 | 같습니다 |

> **노랑다발은 주름 색과 맛으로 갈라집니다. 주름이 노랗거나 올리브색을 띠면 팽이버섯이 아니고, 혀끝에 대었을 때 쓰면 팽이버섯이 아닙니다.**

&nbsp;&nbsp;&nbsp;맛을 보는 행위 자체에 주의가 필요합니다. 아주 작은 조각을 혀끝에 대고 맛만 보고 즉시 뱉어 내며 삼키지 않습니다. 그리고 이 방법은 광대버섯류에는 절대 쓰지 않습니다. 광대버섯은 맛이 좋기 때문에 맛으로 걸러지지 않고, 아마톡신은 극소량으로도 간을 상하게 합니다. 맛 확인은 포자 색과 기질 확인을 모두 통과한 뒤에 쓰는 마지막 보조 수단입니다.

### 12-7. 그 밖의 혼동 대상

| 버섯 | 구분점 |
|:---|:---|
| **개암버섯** | 식용입니다. 갓이 벽돌색이고 포자가 자갈색입니다. 노랑다발과 구별이 어려우므로 확신이 없으면 먹지 않습니다 |
| **검은비늘버섯류** | 갓에 거친 비늘이 많고 점액이 있습니다. 포자가 갈색입니다. 독성은 약하나 종 구분이 어렵습니다 |
| **외대버섯, 삿갓외대버섯** | 포자가 분홍색입니다. 땅에서 나며 위장 독성이 강합니다 |
| **먹물버섯류** | 갓이 시간이 지나면 검게 녹아내립니다. 술과 함께 먹으면 중독됩니다 |
| **갈색먹물버섯** | 그루터기에 다발로 나지만 갓이 달걀 모양이고 금방 녹습니다 |
| **말똥버섯류** | 거름더미와 똥에 납니다. 환각 성분이 있는 종이 있습니다 |

### 12-8. 기른 것이 가장 안전합니다

&nbsp;&nbsp;&nbsp;여기까지 읽고 나면 분명해집니다. 야생 팽나무버섯을 채집해 먹는 일은 버섯 판별에 상당한 경험이 있는 사람의 일입니다. 의료 지원이 없는 재난 상황에서는 더욱 그렇습니다.

> **재난 상황에서 팽이버섯을 먹는 가장 안전한 방법은 야생에서 찾는 것이 아니라 기르는 것입니다. 내가 종균을 넣은 병에서 난 것이라면 판별 문제가 애초에 발생하지 않습니다.**

&nbsp;&nbsp;&nbsp;다만 기른 것이라도 절대적으로 안전하지는 않습니다. 배지 표면에 공기 중 포자가 앉아 다른 버섯이 함께 돋을 수 있습니다. 특히 살균이 불충분했던 배지에서는 먹물버섯류가 흔히 나옵니다. 한 병에서 모양이 다른 버섯이 섞여 나오면 생김새가 다른 쪽은 모두 버립니다.

### 12-9. 처음 먹을 때의 원칙

&nbsp;&nbsp;&nbsp;의료 지원이 없는 상황에서는 확인 절차 자체가 방어 수단입니다.

| 순서 | 내용 |
|:--:|:---|
| 1 | **나무에서 났는지 확인합니다.** 땅에서 난 것은 버립니다 |
| 2 | **다발인지 확인합니다.** 외톨이는 버립니다 |
| 3 | **대에 턱받이나 거미줄 흔적이 있는지 봅니다.** 있으면 버립니다 |
| 4 | **밑동에 주머니가 있는지 봅니다.** 있으면 버립니다 |
| 5 | **대 밑동이 짙은 갈색 벨벳인지 확인합니다.** 아니면 버립니다 |
| 6 | **포자를 받아 색을 봅니다.** 녹슨 갈색이나 자갈색이면 버립니다 |
| 7 | **반드시 충분히 익힙니다.** 생식하지 않습니다 |
| 8 | 처음에는 **한 사람만, 소량(한 조각)** 먹고 24시간 기다립니다 |
| 9 | 이상이 없으면 양을 늘립니다. 여러 사람이 동시에 먹지 않습니다 |
| 10 | 먹은 버섯 한 개체를 **따로 남겨 둡니다.** 중독 시 확인에 쓸 수 있습니다 |

> **증상이 6시간 이상 지나 나타나는 중독이 가장 위험합니다.**
> 먹고 30분에서 2시간 안에 배가 아픈 것은 대개 위장 자극이지만, 6시간에서 24시간 뒤에 구토와 설사가 시작되는 것은 간을 파괴하는 아마톡신 중독의 전형적인 경과입니다. 늦게 시작될수록 위중합니다. 이때는 증상이 잠시 가라앉는 시기가 있어 회복된 것처럼 보이지만 실제로는 간이 망가지는 중입니다. 그리고 끈적버섯류의 오렐라닌은 며칠에서 3주 뒤에야 신장 증상으로 나타나므로, 늦게 생긴 이상도 버섯과 연결해 생각해야 합니다.
