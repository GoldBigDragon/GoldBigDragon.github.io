## 10. 生育異常の診断

| 症状 | 原因 | 対処 |
|:---|:---|:---|
| 接種5日経っても菌糸が見えない | 培地が熱いときに接種した、種菌が死んだ | 培地を25℃以下に冷まして再接種します |
| 菌糸が伸びて止まる | 培地温度34度超過、水分不足 | ボトルの間を空けて熱を抜き周囲の気温を下げます |
| 菌糸が覆ったのにキノコが出ない | 温度を下げていない。菌かきをしていない | 14-15℃に移して表面を掻きます |
| 原基が付いて枯れる | 湿度不足 | 濡れた布を掛けて床に水をまき95%に上げます |
| 柄だけ細く長く伸びる | 抑制段階を飛ばした、二酸化炭素過多 | 5-7℃に5-15日置いて換気を増やします |
| 傘が大きすぎて柄が短い | 二酸化炭素不足、温度が高い | 換気を減らしてより冷たい場所へ移します |
| キノコが柔らかくなり黄色い粘液 | 細菌性の腐り。水滴が落ちた | 覆いの水滴を払って換気します。病んだものは取り除きます |
| 傘が褐色に変わる | 温度が高すぎる。収穫時期を過ぎた | より冷たい場所へ移し時期を守って収穫します |
| 根元が褐色に溶ける | 水が培地に溜まった | 水を直接注ぎません。空中湿度だけで上げます |
| キノコが一方にだけ残る | 種菌が一方に固まった、光が一方からだけ入る | 次の周期に種菌を均一にまき、ボトルを回します |
| 2周期の収量がほとんどない | 培地の養分が尽きた | 正常です。培地を替えます |
| 培地が黒く酸っぱい | 細菌が繁殖。培地の寿命が終わった | 廃棄して廃培地に回します |

## 11. 廃培地の循環

### 11-1. 廃培地は捨てるものではありません

&nbsp;&nbsp;&nbsp;キノコが出終わったあとの培地は菌糸が木質を分解しておいた良質の有機物です。生おがくずよりはるかに分解が進んでいて畑に直接入れることができます。評価表の施肥Dは年60kgの有機物投入を指しますが、その60kgが一度使って消えるのではなく回っているという点が重要です。

| 用途 | 方法 |
|:---|:---|
| **次周期の培地に混合** | 新しい培地の20%まで混ぜます。標準配合に既に入っている項目です |
| **元肥** | 秋に畑に広げて耕し込みます。有機物とカリウムの供給が大きいです |
| **マルチ材** | 作物の間に5cmの厚さで敷いて雑草と水分蒸発を防ぎます |
| **他のキノコの培地** | サケツバタケの木材チップ培地に混ぜて使えます |
| **堆肥促進剤** | 堆肥の山に混ぜると分解が速くなります |
| **ミミズ養殖の基質** | ミミズがよく食べます。ふん土が得られます |
| **燃料** | 完全に乾かすと火力は弱いですが燃えます |

```
針葉樹・広葉樹おがくず + 米ぬか → 培地 → キノコ収穫 → 廃培地
                                      ↓            ↓
                            次の培地20%   畑の有機物
```

&nbsp;&nbsp;&nbsp;廃培地を次の周期に20%混ぜて使うと新たに必要なおがくずが20%減ります。永続性Dと施肥Dの負担を直接軽くする唯一の手段です。ただし汚染された培地は絶対に混ぜません。青カビの胞子が新しい培地にそのまま入ります。

### 11-2. 培養場所の年次管理

| 年次 | 管理 |
|:--:|:---|
| 1年目 | 同じ場所を続けて使っても構いません |
| 2年目 | 周期の間に場所を空けて水で洗い日に当てて乾かします |
| 3年目 | 場所を移すのが安全です。雑菌の胞子が積み重なります |
| 緊急措置 | 壁と床に石灰硫黄合剤や濃い草木灰の灰汁を塗ります |

&nbsp;&nbsp;&nbsp;室内栽培は雑菌の胞子が積もる速度が速いです。一つの周期を終えたら空いた空間を数日空けておき、できれば戸を開けて日光を入れます。紫外線が落下胞子をかなり減らします。電力も薬品も要らない方法です。

## 12. 毒キノコの誤認と安全確認

> **この節は生命に直結します。育てることより食べてよいかを確認することのほうが重要です。**

&nbsp;&nbsp;&nbsp;エノキタケはこの文書が扱う六種の中で野生において毒キノコと混同される危険が最も大きいです。理由は三つです。第一に、野生のエノキタケが出る広葉樹の腐った切り株には他のキノコも同様に束になって出ます。第二に、栽培個体と野生個体があまりに違い、栽培されたものだけを見た人は野生個体を見分けられません。第三に、そして最も重要なことに、エノキタケの胞子は白色です。

### 12-1. 胞子が白色なら食べないという規則はここでは使えません

&nbsp;&nbsp;&nbsp;サケツバタケの文書には単純で強力な防衛線があります。白い紙に傘を伏せて置いて胞子を受けたとき粉が白ければ食べないという規則です。ドクツルタケとシロタマゴテングタケのような致命的な毒キノコが白い胞子を出し、サケツバタケは灰褐色の胞子を出すため、この一度の確認で最も危険な種を除くことができます。マッシュルームも褐色の胞子を出すため同じ規則が使えます。

&nbsp;&nbsp;&nbsp;エノキタケは違います。**エノキタケの胞子は白色からごく淡い黄色です。**テングタケ類と同じ色です。したがって胞子の色でテングタケを除外することができません。

> **エノキタケでは胞子の色はテングタケを除外する手段になりません。むしろ逆に使います。胞子が錆色の褐色や灰褐色であればエノキタケではないという判定に使います。**

| キノコ | 胞子の色 | この色が意味すること |
|:---|:---|:---|
| **エノキタケ** | **白色-淡黄色** | 基準 |
| ドクツルタケ、シロタマゴテングタケ | 白色 | **胞子の色では区別されません。**他の形質を見なければなりません |
| オオワライタケ | **錆色の褐色** | エノキタケではありません |
| フウセンタケ類 | **錆色の褐色** | エノキタケではありません |
| ニガクリタケ | **灰褐色-黒褐色** | エノキタケではありません |
| クロゲキンチャクの類 | 褐色 | エノキタケではありません |

&nbsp;&nbsp;&nbsp;胞子を受けるときも注意が必要です。エノキタケの胞子は白色なので白い紙では見えません。黒い紙や銀紙、ガラス板で受けなければなりません。そして必ず紙を半分は白色、半分は黒色にして両方を当てて受けてください。そうすれば白い胞子と濃い胞子を一度に両方判定できます。

### 12-2. エノキタケの確認形質 - 五つすべてを見ます

&nbsp;&nbsp;&nbsp;胞子の色という単一の防衛線が使えないため、複数の形質を一緒に確認する方式に変えます。以下の五つがすべて合っていればエノキタケと見ます。一つでも外れたら食べません。

| 番号 | 形質 | エノキタケの基準 |
|:--:|:---|:---|
| **1** | **発生する基質** | **広葉樹の腐った切り株、枯れ木、倒れた幹。**地面から出たものはエノキタケではありません |
| **2** | **傘のぬめり** | **湿っているとき触るとぬるぬるしていて滑らかです。**乾くと弱まるので雨上がりに確認します |
| **3** | **柄の根元の濃い褐色の毛** | **根元が濃い褐色から黒褐色で短いベルベットのような毛で覆われています** |
| **4** | **束になって出る習性** | **数本が根元でくっついて密な束を作ります。**一本だけ離れて出たものは他のキノコです |
| **5** | **つばとつぼがどちらもない** | **柄に輪も膜のかけらもクモの巣の跡もなく、根元を掘ってもつぼがありません** |

&nbsp;&nbsp;&nbsp;ここに補助的な形質を加えます。

| 補助形質 | エノキタケの基準 |
|:---|:---|
| 季節 | **晩秋から早春。**真夏に出たものはエノキタケでない可能性が大きいです |
| ひだの色 | 白色から淡いクリーム色。**成熟しても褐色や錆色に変わりません** |
| 傘の色 | 黄褐色から橙がかった赤褐色。中央が濃く縁が淡いです |
| 味 | **苦味がありません。**舌先に少し当てて苦ければ吐き出して食べません |
| 肉の色 | 白色。切ったり傷んだりしても黄色に変わりません |

> **五つの主要な形質のうち一つでも外れたら食べません。特に地面から出たものはどれほど似ていてもエノキタケではありません。**

### 12-3. オオワライタケ - 最も混同しやすい相手

&nbsp;&nbsp;&nbsp;オオワライタケ(Gymnopilus junonius)はエノキタケと最も混同しやすいキノコです。同じ季節に同じ広葉樹の切り株に同様に大きな束で出て、傘の色も黄褐色から橙がかっているため遠くから見るとほとんど区別できません。その名のとおり、食べると幻覚と興奮と精神錯乱が起きることで知られています。

| 区分 | **エノキタケ** | **オオワライタケ(毒)** |
|:---|:---|:---|
| **胞子の色** | **白色-淡黄色** | **錆色の褐色。決定的な違いです** |
| **ひだの色** | **最後まで白色-淡クリーム色** | **最初は黄色→育つにつれ錆色-赤褐色** |
| **つば** | **ありません** | **あります。**繊維質の輪が柄の上部に残ります |
| **傘の表面** | **湿っているとき粘質。ぬるぬるします** | **乾いていて細かい繊維状の鱗片。**粘りはありません |
| **柄の根元** | **濃い褐色のベルベット毛** | 柄と同じ黄褐色。毛がなく**根元が膨らんで棒状** |
| 傘の直径 | 2-8cm | **6-15cm。はるかに大きいです** |
| 柄の太さ | 0.3-0.8cm | 1-3cm。太くて硬いです |
| 味 | 苦味なし | **非常に苦いです** |
| 発生基質 | 広葉樹の腐った切り株 | 広葉樹と針葉樹の切り株のどちらも |
| 季節 | 晩秋-早春 | 夏から秋 |

> **三つだけ覚えれば分かれます。ひだが錆色の褐色に変わるか、柄につばの輪があるか、傘が粘質でなく乾いた繊維質か。一つでもそうならオオワライタケです。**

&nbsp;&nbsp;&nbsp;中毒症状は食べて30分から3時間以内に始まります。めまい、激しい興奮と笑い、幻視と幻聴、筋肉の硬直、嘔吐と腹痛が来ます。大抵一両日で回復しますが多量に食べると精神錯乱が重くなり脱水で危険になります。医療支援がない状況では十分な水を飲ませて暖かく寝かせて見守る以外にできることがありません。

### 12-4. ドクツルタケとシロタマゴテングタケ - 胞子の色では見分けられません

&nbsp;&nbsp;&nbsp;こちらのほうがより致命的です。アマトキシン一個体分で人が死にます。そして胞子が白色でエノキタケと胞子の色が同じです。

| 区分 | **エノキタケ** | **ドクツルタケ・シロタマゴテングタケ(致命的)** |
|:---|:---|:---|
| 胞子の色 | 白色-淡黄色 | **白色。区別されません** |
| ひだの色 | 白色-淡クリーム色 | **白色。区別されません** |
| **発生基質** | **広葉樹の腐った切り株・枯れ木** | **生きている木の根の近くの地面。**決定的な違いです |
| **発生の習性** | **密な束** | **一本ずつ、または数本が離れて出ます** |
| **つぼ** | **ありません** | **あります。**膜状のつぼが根元を包みます |
| **つば** | **ありません** | **あります。**白い膜の輪が柄の上部に残ります |
| 傘の色 | 黄褐色-橙がかった赤褐色 | **白色から淡い緑黄色** |
| 傘の表面 | 湿っているとき粘質 | 滑らかで乾いています |
| 柄の根元の毛 | 濃い褐色のベルベット毛 | ありません。白色で滑らかです |
| 大きさ | 傘2-8cm | 傘6-15cm、柄9-20cm。はるかに大きいです |

> **エノキタケとテングタケ類を分けるのは胞子の色ではなく次の四つです。木から出たか地面から出たか、束か一本かで出ているか、根元につぼがあるか、柄につばがあるか。**

&nbsp;&nbsp;&nbsp;**つぼの確認は必ず掘って行わなければなりません。**地面の上に出た部分だけを見るとつぼが土に埋まって見えません。根元を土ごと掘り出して確認する習慣を付けてください。エノキタケは木から出るため掘るべき土自体がなく、引き抜けば木に付いていた根元がそのまま現れます。土を掘らなければならない状況そのものが、既にエノキタケではないという合図です。

### 12-5. フウセンタケ類 - 症状が遅く来るほうが危険です

&nbsp;&nbsp;&nbsp;フウセンタケ属(Cortinarius)にはオレラニンという毒素を持つ種があります。オレンジ色のフウセンタケ属菌(Cortinarius orellanus)と赤褐色のフウセンタケ属菌(C. rubellus)がそれに当たります。この毒は腎臓を破壊し、何より症状が食べて2日から21日後に現れます。その間は何の異常もないため自分が中毒したという事実さえ分かりません。

| 区分 | **エノキタケ** | **フウセンタケ類(腎臓破壊)** |
|:---|:---|:---|
| **胞子の色** | **白色-淡黄色** | **錆色の褐色** |
| **クモの巣膜** | **ありません** | **幼いとき傘の縁と柄の間にクモの巣のような膜があります。**成熟すると柄に錆色の帯として残ります |
| ひだの色 | 白色-淡クリーム色 | 最初は淡い色→錆色の褐色 |
| **発生基質** | **広葉樹の腐った切り株** | **地面。**木の根と共生する菌根性です |
| 発生の習性 | 密な束 | 散らばって出ます |
| 傘の表面 | 粘質 | 繊維質または鱗片状 |
| 柄の根元 | 濃い褐色のベルベット毛 | 毛がありません |

> **柄に錆色の帯があるか、幼い個体の傘の縁にクモの巣のような膜が見えたらフウセンタケ類です。絶対に食べません。症状がないからと安心することがこの毒の最も恐ろしい点です。**

### 12-6. ニガクリタケ - 基質と習性が全く同じです

&nbsp;&nbsp;&nbsp;ニガクリタケ(Hypholoma fasciculare)は上の三種より多く出て、エノキタケと最も同じ場所で同じ姿で出ます。広葉樹と針葉樹の腐った切り株に密な束で出て傘が黄色みの黄褐色です。発生基質と束になる習性だけでは分かれません。

| 区分 | **エノキタケ** | **ニガクリタケ(毒)** |
|:---|:---|:---|
| **胞子の色** | **白色-淡黄色** | **灰褐色-黒褐色** |
| **ひだの色** | **最後まで白色-淡クリーム色** | **最初は硫黄色→緑黄色→オリーブ褐色→灰褐色** |
| **味** | **苦味なし** | **非常に苦いです。舌に当てるとすぐ分かります** |
| 傘の色 | 黄褐色-橙がかった赤褐色 | 硫黄色-黄褐色、中央が赤褐色 |
| 傘の表面 | 湿っているとき粘質 | 滑らかで乾いています |
| 柄の根元 | 濃い褐色のベルベット毛 | 毛がありません。柄全体が黄色から黄褐色 |
| 発生基質 | 広葉樹の腐った切り株 | 同じです |
| 発生の習性 | 密な束 | 同じです |

> **ニガクリタケはひだの色と味で分かれます。ひだが黄色やオリーブ色を帯びていればエノキタケではなく、舌先に当てて苦ければエノキタケではありません。**

&nbsp;&nbsp;&nbsp;味を見る行為自体に注意が必要です。ごく小さな一片を舌先に当てて味だけ見てすぐに吐き出し、飲み込みません。そしてこの方法はテングタケ類には絶対に使いません。テングタケは味が良いため味では見分けられず、アマトキシンは極めて少量でも肝臓を傷めます。味の確認は胞子の色と基質の確認をすべて通過したあとに使う最後の補助手段です。

### 12-7. その他の混同対象

| キノコ | 区別点 |
|:---|:---|
| **クリタケ** | 食用です。傘がれんが色で胞子が灰褐色です。ニガクリタケとの区別が難しいため確信がなければ食べません |
| **クロゲキンチャクの類** | 傘に粗い鱗片が多く粘性があります。胞子が褐色です。毒性は弱いですが種の区別が難しいです |
| **イッポンシメジ、クサウラベニタケ** | 胞子が桃色です。地面から出て胃腸毒性が強いです |
| **ヒトヨタケ類** | 傘が時間が経つと黒く溶けます。酒と一緒に食べると中毒します |
| **オオホウライタケ(褐色のヒトヨタケ)** | 切り株に束で出ますが傘が卵形ですぐに溶けます |
| **ヒメツチグリの類、馬糞に出る類** | 堆肥の山や糞に出ます。幻覚成分がある種があります |

### 12-8. 育てたものが最も安全です

&nbsp;&nbsp;&nbsp;ここまで読むと明らかになります。野生のエノキタケを採って食べることはキノコの判別にかなりの経験がある人の仕事です。医療支援がない災害の状況ではなおさらそうです。

> **災害の状況でエノキタケを食べる最も安全な方法は野生で探すことではなく育てることです。自分が種菌を入れたボトルから出たものであれば判別の問題はそもそも発生しません。**

&nbsp;&nbsp;&nbsp;ただし育てたものでも絶対的に安全ではありません。培地の表面に空気中の胞子が付いて他のキノコが一緒に出ることがあります。特に殺菌が不十分だった培地からはヒトヨタケ類がよく出ます。一本のボトルから形が違うキノコが混じって出たら、見た目が違うほうはすべて捨てます。

### 12-9. 初めて食べるときの原則

&nbsp;&nbsp;&nbsp;医療支援がない状況では確認の手順そのものが防御手段です。

| 順序 | 内容 |
|:--:|:---|
| 1 | **木から出たか確認します。**地面から出たものは捨てます |
| 2 | **束であるか確認します。**一本だけのものは捨てます |
| 3 | **柄につばやクモの巣の跡があるか見ます。**あれば捨てます |
| 4 | **根元につぼがあるか見ます。**あれば捨てます |
| 5 | **柄の根元が濃い褐色のベルベットか確認します。**そうでなければ捨てます |
| 6 | **胞子を受けて色を見ます。**錆色の褐色や灰褐色なら捨てます |
| 7 | **必ず十分に加熱します。**生食しません |
| 8 | 最初は**一人だけ、少量(一片)**食べて24時間待ちます |
| 9 | 異常がなければ量を増やします。複数の人が同時に食べません |
| 10 | 食べたキノコの一個体を**別に残しておきます。**中毒時の確認に使えます |

> **症状が6時間以上経ってから現れる中毒が最も危険です。**
> 食べて30分から2時間以内に腹が痛むのはたいてい胃腸の刺激ですが、6時間から24時間後に嘔吐と下痢が始まるのは肝臓を破壊するアマトキシン中毒の典型的な経過です。始まりが遅いほど重症です。このとき症状が一時的に和らぐ時期があって回復したように見えますが実際には肝臓が壊れている最中です。そしてフウセンタケ類のオレラニンは数日から3週間後にようやく腎臓の症状として現れるため、遅れて生じた異常もキノコと結びつけて考えなければなりません。
