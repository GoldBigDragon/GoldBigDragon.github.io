## 3. 培地の材料と準備

&nbsp;&nbsp;&nbsp;エノキタケはおがくずに米ぬかを混ぜた培地を容器に詰めて殺菌したのちに育てるキノコです。サケツバタケのように地面に材料を敷くだけでよいキノコではなく、殺菌が前提になるキノコです。この事実が評価表の施設負担Eを作り、電力がない状況で最初に解決すべき問題でもあります。

### 3-1. エノキタケだけの利点 - 針葉樹を使えます

&nbsp;&nbsp;&nbsp;大多数の栽培キノコはマツやチョウセンゴヨウ系の針葉樹のおがくずでは育ちません。樹脂とテルペン成分が菌糸を抑えるためです。シイタケとヤマブシタケとサケツバタケはいずれも針葉樹を禁止樹種としています。しかしエノキタケの標準培地材料はベイマツのおがくずです。

&nbsp;&nbsp;&nbsp;この違いは地域によって決定的です。韓国の造林地のかなりの部分がマツ、チョウセンゴヨウ、カラマツで、山に広葉樹が少ない地域ではシイタケもヤマブシタケも培地材料を得にくいです。そうした土地でエノキタケはほとんど唯一の選択になります。

| 樹種 | 適合度 | 備考 |
|:---|:--:|:---|
| ベイマツ、マツ、チョウセンゴヨウ | 高い | 標準培地材料。他のキノコが使えない材料です |
| ポプラ、ヤナギ | 高い | 柔らかく分解が速いです |
| エノキ、クワ、カキ | 高い | 野生発生樹種です |
| ナラ、ニレ | 中間 | 硬く菌糸が遅く広がります |
| クルミ、オニグルミ | 禁止 | 感作物質が菌糸を殺します |
| ヒノキ、ヒバ、ネズ | 禁止 | 抗菌成分が非常に強いです |

&nbsp;&nbsp;&nbsp;針葉樹のおがくずを使うときは半年から一年、野外に積んで雨に当てて置いておくほうがよいです。樹脂が洗い流され分解が少し進んで菌糸がはるかによく広がります。挽いたばかりのおがくずは樹脂の匂いが強いのでそのまま使いません。

### 3-2. 培地の配合

| 材料 | 比率 | 役割 |
|:---|:---:|:---|
| おがくず(ベイマツまたは広葉樹) | 60% | 主炭素源 |
| 廃培地 | 20% | 一次収穫後に残った培地を再利用します |
| 米ぬか | 20% | 窒素とビタミンの供給源 |

&nbsp;&nbsp;&nbsp;廃培地が使えないときはおがくず80%に米ぬか20%にします。米ぬかの比率が重要です。20%を超えると養分が多すぎて青カビが先に爆発的に増え、10%を下回ると収量が目に見えて落ちます。

| 添加材 | 量 | 効果 |
|:---|:---:|:---|
| 卵の殻(5mm程度に砕いたもの) | おがくず量の10% | 収量121% |
| 生薬の絞りかす(漢方薬を煎じた後に残ったもの) | おがくず量の20% | 収量110% |
| 小麦ふすま | 米ぬかの代替 | 米ぬかがないとき |
| コーンコブ粉 | おがくずの一部代替 | 通気性が良くなります |
| ビートパルプ | 米ぬかの一部代替 | 商業配合に使われます |

> **卵の殻をおがくず量の10%混ぜると収量が21%増えます。食べ終わった殻を集めてからからに乾かして挽いておくことは、費用がかからず効果が最も確かな対策です。**

&nbsp;&nbsp;&nbsp;卵の殻が効く理由はカルシウムです。炭酸カルシウムが培地の酸度を緩衝し、菌糸が代謝産物として酸を出してもpHが急に下がらないよう支えます。貝殻やカキの殻を焼いて挽いたもの、炭の粉、少量の草木灰も同じ役割をします。ただし草木灰はアルカリが強いのでおがくず量の1%を超えないようにします。

### 3-3. 水分調整

| 項目 | 基準 |
|:---|:---|
| 目標含水率 | 65-70% |
| 判定法 | 一握りしっかり握ったとき指の間から水気がにじむが水滴は落ちない程度 |
| 乾き過ぎの場合 | 菌糸が伸びず培地が崩れます |
| 湿り過ぎの場合 | 下のほうに水が溜まって嫌気状態になり細菌が広がります |
| pH | 4.5-8.6の間なら育ちます。幅が非常に広いです |

&nbsp;&nbsp;&nbsp;エノキタケが耐える酸度の幅が4.5-8.6であるという点は災害の状況で助けになります。酸度計も試験紙もなく感覚で混ぜてもこの範囲を外れにくいです。酸度を合わせるために苦労する必要がほとんどないキノコです。

### 3-4. 容器 - ボトルがないとき

&nbsp;&nbsp;&nbsp;商業栽培は1,000mlのプラスチックボトルに培地600-750gを詰めます。災害の状況ではそのボトルがありません。重要なのはボトルという物ではなく次の四つの機能です。培地を立てて詰め、殺菌後に雑菌が入らないよう防ぎ、空気は通し、上部にキノコが育つ空間を残すことです。

| 容器 | 使い方 | 注意 |
|:---|:---|:---|
| ガラス瓶(ジャム瓶、漬物瓶) | 殺菌に最も良く耐えます。口を布で覆って紐で結びます | 急に冷ますと割れます。ゆっくり冷まします |
| 竹筒 | 片側の節を残して切ります。丸ごと煮ることができます | 割れやすく何度も使えません |
| 甕、壺 | 熱に強く湿度保持が良いです | 重くて殺菌に時間がより多くかかります |
| ビニール袋 | 熱に耐えるものだけを使います。口を綿や布で塞ぎます | 常圧100度までしか耐えません |
| 空き缶、ブリキ缶 | 手に入りやすいです | 錆びたら廃棄します |
| 木箱に布を掛ける | 平箱栽培の形になります | 雑菌のリスクが最も大きいです |

&nbsp;&nbsp;&nbsp;詰め方のコツは三つです。容器の75%だけ満たして上部に空間を残します。表面は平らに軽く固めますが強く押しません。そして中央に直径1cmの穴を底まで開けます。この穴があると種菌が培地の中まで入り込み、中心から菌糸が広がるため培養期間が数日短くなり失敗率が低くなります。

### 3-5. 電気なしで殺菌する方法

&nbsp;&nbsp;&nbsp;標準は121℃高圧60-90分です。高圧殺菌器がなければ次の中から選びます。

#### 3-5-1. ドラム缶による常圧蒸気殺菌

| 項目 | 方法 |
|:---|:---|
| 設備 | 200Lドラム缶、台、蓋、薪 |
| 水 | 底に20-30cm満たします |
| 配置 | 台を置いて水に触れないよう容器を立てます |
| 覆う | 蓋をして隙間を濡れた布や泥でふさぎます |
| 時間 | 蒸気が上がり始めたときから100℃で4-6時間 |
| 冷ます | 火を止め蓋をしたまま一晩冷まします |
| 燃料 | 薪30-50kg |

&nbsp;&nbsp;&nbsp;最も確実な無電力の方法です。ただし燃料が多くかかります。一度火を焚くときにドラム缶を満たして一度に処理するほうが燃料効率がはるかに良いです。十本のボトルを殺菌するために火を焚くのと百本のボトルを殺菌するために火を焚くのとで、かかる薪はさほど変わりません。

#### 3-5-2. 沸騰した湯で煮る

| 項目 | 方法 |
|:---|:---|
| 方法 | おがくずと米ぬかを混ぜた培地を袋に入れて沸騰した湯で2-3時間煮ます |
| 後処理 | すくい上げて押して水気を絞り、65-70%に合わせて容器に詰めます |
| 限界 | 完全殺菌ではありません。耐熱性細菌の芽胞が残ります |
| 補完 | 冷ましたらすぐに接種し種菌を多めに使います |

&nbsp;&nbsp;&nbsp;ドラム缶がないときの代案です。殺菌の水準は低いですが種菌を多めに入れて先に場所を占めさせれば成功率が上がります。

#### 3-5-3. 稲わら加熱培地法

&nbsp;&nbsp;&nbsp;おがくずが全くない、または胞子から種菌を新たに立ち上げなければならないときに使う方法です。理論上は胞子を培地に振れば菌糸が伸びますが、現実には空気中の青カビと細菌がキノコの胞子より数百倍速く培地を占領します。栄養価が高い培地ほどより脆弱です。そのため栄養が過剰な人工培地の代わりに自然の防御力を利用した原始的な培地を使います。

| 段階 | 方法 |
|:---|:---|
| 煮る | 稲わらや麦わら、大豆のさやを沸騰した湯で1時間以上しっかり煮ます |
| 絞る | すくい上げて水気を絞り、手で触れる程度まで冷まします |
| 振る | 保管しておいた胞子の粉を惜しまずまんべんなく十分に振ります |
| 覆う | 清潔な布で覆って風と落下胞子を防ぎます |
| 培養 | 20-25℃の暗い場所で2-4週間。白い菌糸がわらを覆えば成功です |

&nbsp;&nbsp;&nbsp;栄養が少ないわらは青カビにとっても魅力が薄いです。菌糸が遅く育つ代わりに競争に負けません。ここで得た菌糸のかたまりをおがくず培地に移して本格的な種菌に育てます。

### 3-6. 殺菌法の比較

| 方法 | 燃料 | 時間 | 殺菌水準 | 推奨状況 |
|:---|:--:|:--:|:--:|:---|
| 高圧121度 | 電力 | 60-90分 | 完全 | 電力があるとき |
| ドラム缶蒸気100℃ | 多い | 4-6時間 | 高い | 無電力の標準。一度に大量で |
| 沸騰した湯で煮る | 中程度 | 2-3時間 | 中程度 | ドラム缶がないとき |
| 稲わら加熱培地 | 少ない | 1時間 | 中程度 | 胞子から種菌を立ち上げるとき |

### 3-7. 低温環境の確保 - 電力なしの冷房

&nbsp;&nbsp;&nbsp;エノキタケ栽培で殺菌の次に大きな問題が低温です。生育段階に4-9℃が必要で、その前の抑制段階には5-7℃が必要です。冷房機がなければこの温度は人が作れません。借りてくる必要があります。

| 手段 | 温度 | 確保方法 | 限界 |
|:---|:---:|:---|:---|
| **冬そのもの** | 自然 | 11月から3月。北向きの納屋や軒下 | 季節にしか使えません |
| 土穴、洞窟 | 10-15℃ | 山の斜面を2m以上掘り進みます | 夏でも10度以下には下がりません |
| 地下室 | 12-18℃ | 既存の構造物を活用します | 同じです |
| 井戸端、泉のほとり | 10-14℃ | 冷たい水辺の空気を使います | 湿度が過度に高いです |
| 氷穴 | 0-5℃ | 真冬に氷を詰めてわらともみ殻で覆います | 労力が多くかかります |
| 北向き斜面の穴 | 8-14℃ | 北側の陰に穴を掘ってわらを覆います | ばらつきが大きいです |
| 濡れた布を掛ける | 周囲より3-5℃ | 蒸発熱で下げます | 湿った日には効果がありません |

> **電力がない状況でエノキタケは冬の作物です。一年中育てようとすると失敗します。10月に培地を作り11月に培養し12月に発芽を経て真冬に収穫する作型が、このキノコの自然な形です。**

&nbsp;&nbsp;&nbsp;夏には土穴で4℃を作ることができません。そのときはエノキタケを育てず、夏に出る他のキノコを育てます。サケツバタケとキクラゲがその場所にあります。数種のキノコを併せて扱う理由がここにあります。一種で一年を覆うことはできませんが、数種を組み合わせれば覆うことができます。

## 4. 種菌の確保

&nbsp;&nbsp;&nbsp;キノコには種がありません。種苗店が閉まれば種を買う場所がなく、種を取って甕に入れておく方式も通じません。評価表でエノキタケの自家採種はC、種子寿命はDです。市販の種菌は6か月から1年で活力を失い、純粋な菌株を続けるには無菌操作が必要という意味です。しかし菌類には植物にない三つの道があります。胞子を取っておく道、生きているキノコの身の一部を取って育てる道、すでに育った培地を割って移す道です。

### 4-1. 胞子採取と胞子紋

&nbsp;&nbsp;&nbsp;胞子は最も長く持つ保存形態で、災害の初期に必ず作っておくべき保険です。

| 段階 | 方法 |
|:---|:---|
| 対象選び | 傘が完全に開いた大きく健康な個体 |
| 柄切り | 傘と柄が合う位置で柄をぎりぎりまで切り取ります |
| 受け皿 | ひだが下を向くように**アルミホイル**の上に置きます |
| 覆う | 器やカップをかぶせて風を防ぎます |
| 放置 | 涼しい場所に24時間 |
| 回収 | 傘を持ち上げると胞子の粉が傘の形のまま残ります |

&nbsp;&nbsp;&nbsp;エノキタケの胞子は白色からごく淡い黄色です。白い紙に受けると見えません。**必ず暗い色の紙や銀紙、ガラス板に受けなければなりません。**この点は褐灰色の胞子を出すサケツバタケや褐色の胞子を出すマッシュルームと異なり、12節の安全確認でも決定的な違いを作ります。

&nbsp;&nbsp;&nbsp;紙よりアルミホイルのほうが良いです。紙は湿気を吸い、繊維の間に雑菌が隠れます。ホイルは水分を吸収せず表面が滑らかで胞子をそのまま保存します。ホイルがなければガラス板が次の順位です。

### 4-2. 胞子の保存 - 電気なしで10年

| 段階 | 方法 |
|:---:|:---|
| 1 | ホイルの上に胞子を受けます |
| 2 | 胞子が付いたホイルを風が通る**日陰**にさらに一日置いてわずかな湿気まで飛ばします |
| 3 | ホイルを半分に折って胞子の面を内側に保護しジップ袋に入れます |
| 4 | **からからに炒った塩や炭のかけら**を一緒に入れて湿気を取ります |
| 5 | ジップ袋をガラス瓶に集めて**蜜蝋で封じます** |
| 6 | 四季の温度が一定の**土穴や地下室**に置きます。光が入らないようにします |

| 保存形態 | 寿命 | 備考 |
|:---|:---:|:---|
| 胞子紋(ホイル乾燥) | **5-10年以上** | 水分が完全に排除され細胞活動が停止します |
| 液体種菌(滅菌水浮遊) | 3-6か月 | 冷蔵がなければ早期発芽するか細菌が増えます |
| 接種完了種菌(おがくず・穀粒) | 6か月-1年 | 生きている菌糸のため養分を使い続けます |
| 育った培地のかたまり | 1-2か月 | 長く置くと老化し活力を失います |

> **災害の状況で胞子を液体で保管してはいけません。必ず乾燥した胞子紋の形で置かなければなりません。**

&nbsp;&nbsp;&nbsp;紫外線が胞子のDNAを破壊するので光が入らない深い場所でなければなりません。胞子と植物の種の寿命の差は構造から来ます。

| 比較項目 | トマトの種 | キノコの胞子 |
|:---|:---|:---|
| 平均寿命(室温) | 約2-4年 | 約5-10年以上 |
| 脆弱要因 | 温度変化、自身の養分の枯渇 | 湿気によるカビ汚染 |
| 細胞構造 | 複雑な胚と養分物質 | 単一細胞と厚い保護壁 |

&nbsp;&nbsp;&nbsp;トマトの種は内部に胚と養分が入っていて時間が経つと自ら養分を消費しながら老いて死にます。キノコの胞子は厚い細胞壁に包まれた単一細胞にすぎないため消費する養分がなく、条件が合えばはるかに長く持ちます。学界では数十年前の胞子を復活させた例も珍しくありません。

> **評価表の種子寿命Dは市販種菌基準です。胞子紋に変えておけばそのDは事実上意味を失います。災害初年に最も大きく健康な個体で胞子紋を20-30枚作り土穴に貯えておいてください。種菌をすべて失っても5年後10年後に再び始めることができます。**

### 4-3. 組織培養 - 最も確実な方法

&nbsp;&nbsp;&nbsp;生きている新鮮なキノコが手にあれば胞子を使う理由はほとんどありません。キノコの傘と柄が合う内側の白い身は既に交配型の結合が終わった二次菌糸のかたまりです。その一片を取って培地に入れると発芽と交配の過程を飛び越えて直ちに菌糸が四方に伸びます。

| 段階 | 方法 |
|:---|:---|
| 選ぶ | 傘が開き始めた新鮮な個体。古いものや虫に食われたものは使いません |
| 消毒 | 刃物を火で熱してから冷ますか、沸騰した湯に浸けてから取り出します |
| 割る | **キノコを手で縦に割ります。**刃物で切ると表面の雑菌が中に引き込まれます |
| 採取 | 傘と柄が合う内側の白い身を米粒大に取り出します |
| 接種 | 煮て冷ましたおがくず培地や稲わらの間に挟みます |
| 培養 | 20-25℃の暗い場所。3-5日で断片の周りに白い菌糸が広がります |

&nbsp;&nbsp;&nbsp;割ることが重要な理由はキノコの内部がほぼ無菌に近いためです。外皮とひだにはあらゆる胞子が付いていますが身の中は清潔です。手で割ればその清潔な面が新たに露出し、そこから取り出した断片は消毒なしでも純粋な菌糸になります。エノキタケは柄が細く身を取り出すのが容易ではないため、束の根元側の太い部分を使うほうがよいです。野生の個体は柄が太くはるかに扱いやすいです。

### 4-4. 培地割りで種菌を増やす

&nbsp;&nbsp;&nbsp;菌糸がよく広がった培地を割って新しい培地にすり込むと種菌になります。原始的ですが確実な方法です。

| 段階 | 方法 |
|:---|:---|
| 対象 | 白い菌糸が培地全体を覆い雑菌の跡がないボトル |
| 時期 | 培養完了直後。長く置いた培地は菌糸が老化し活力が落ちます |
| 処理 | 新しい培地を煮て冷ましておきます |
| 移す | 菌糸が覆った培地をさじや手ですくって新しい培地の表面と中に混ぜます |
| 比率 | 新しい培地の重さの5-10% |
| 注意 | 培地一つを5-10個に増やせます。ただしこの方式を四、五世代を超えて繰り返すと活力が落ちるため、定期的に組織培養や胞子に戻して新しく立ち上げます |

### 4-5. 種菌確保の優先順位

| 順位 | 方法 | 条件 |
|:--:|:---|:---|
| 1 | 市販種菌 | 手に入るときに前もって確保。普及度Sなので平時には最も容易です |
| 2 | 組織培養 | 新鮮なキノコが手にあるとき。最も確実です |
| 3 | 培地割り | 既によく育った培地があるとき。最も速いです |
| 4 | 胞子紋から稲わら培地 | すべて失い貯えておいた胞子があるとき |
