## 13. 无冰箱贮藏

### 13-1. 生鲜状态连三天都撑不住

&nbsp;&nbsp;&nbsp;评价表中金针菇的贮藏性以生品为准是E级：无电力常温下3-4天，低温下2周。水分接近90%，菌柄细、表面积大，所以水分流失快，同时也容易变坏。而且这种菌类**是从根部开始变褐的。**一束的下部一旦开始变褐，一两天内就会蔓延到整体。

> **然而一旦晒干，等级就会完全不同。**
> 排除判定和贮藏性等级都是以未加工的生品为准的。干燥几乎不需要燃料和设备，因此在灾害状况下，金针菇贮藏性的问题实际上单靠干燥就能解决。造成排除的两个缺陷之一，仅靠一把刀和一个筛子就能化解。

### 13-2. 干燥

&nbsp;&nbsp;&nbsp;金针菇是容易晒干的菌类。菌柄细，内部很快就能干透，不像菌盖厚的大球盖菇那样容易因内部未干而长霉。

| 方法 | 条件 | 时长 | 结果 |
|:---|:---|:--:|:---|
| **日晒干燥** | 用手把菌束撕散，摊在晒架或筛子上 | 晴天1-2天 | 最简单，还能增加维生素D |
| **阴凉通风干燥** | 通风良好的屋檐下 | 2-4天 | 颜色和香气保留得好 |
| **穿串悬挂** | 整束穿在绳上悬挂在屋檐下 | 3-5天 | 占用空间小 |
| **靠火烘干** | 灶台上方的架子，40-50℃ | 半天 | 梅雨季可用，注意不要烤焦 |
| **冬季冻干** | 放到零下冻住后再用冷风吹干 | 5-10天 | 最适合冬季的采收物 |

&nbsp;&nbsp;&nbsp;最后一项特别适合金针菇。这种菌类是在寒冬采收的，日照弱、湿气重，日晒干燥可能会有困难。这时把它放到零下的冷风中，冰会直接蒸发变干。颜色保持洁白，组织不会散碎，干制品质最好。这与晒干明太鱼的原理相同。

| 阶段 | 判断 |
|:---|:---|
| 完全干燥 | **用手一搓就碎。**若还能弯曲就还没干透 |
| 保管 | 完全冷却后**放入密闭容器，与炭或炒盐一起** |
| 期限 | 在阴凉黑暗处**1年以上，磨成粉则2年以上** |

&nbsp;&nbsp;&nbsp;有一点需要注意。金针菇一晒干体积会极度缩小，变得像细丝一样。1kg晒干后大约只剩80g，而且很细，稍一碰就碎。因此干金针菇**磨成粉保存比整根长期存放更实用。**

> **细长抽出的金针菇晒干后几乎什么都不剩。只有经过第7节生育抑制阶段好好养粗的菌类，晒干后才能保留可食用的部分。抑制阶段直接决定贮藏阶段的效果。**

### 13-3. 其他贮藏方法

| 方法 | 制作方法 | 期限 |
|:---|:---|:--:|
| **菌类粉** | 完全干燥后磨粉，过筛取细粉 | 2年以上 |
| **盐渍** | 焯水去水后加相当于重量20%的盐层层腌制 | 6个月-1年 |
| **酱菜** | 焯水后腌入酱油和醋中 | 3-6个月 |
| **发酵保存** | 用3%的盐水腌制进行乳酸发酵 | 3-6个月 |
| **油浸** | 焯水挤干水分后浸入油中 | 1-3个月 |
| **冬季自然冷藏** | 悬挂在朝北屋檐下或土窖中 | 2-3周，只限寒冬 |

&nbsp;&nbsp;&nbsp;冬季自然冷藏对金针菇来说是特别有效的方法。因为采收期正值寒冬，室外气温已经在0-5℃。装入网袋悬挂在朝北的屋檐下，不用电力也能保存2-3周。反复冻融会使其变软，所以要选择持续保持冰冻或维持在0℃以上的位置。

> **在灾害状况下，菌类粉尤其珍贵。**
> 体积小，能给汤增添鲜味，还能掺入谷物粉中补充蛋白质和B族维生素。干制品一旦开始碎裂，磨成粉保存比丢弃更划算。

## 14. 烹饪与加工

### 14-1. 必须煮熟食用

&nbsp;&nbsp;&nbsp;金针菇不生食。生品中含有妨碍消化、刺激胃部的成分，不加热就无法吸收细胞壁内的营养素。而且即便是野生个体、已通过第12节的鉴别，也一定要加热。

| 烹调 | 燃料 | 时间 | 备注 |
|:---|:--:|:--:|:---|
| 焯煮 | 少 | 2-3分钟 | 耗燃料最少，可用来做凉拌菜 |
| 炒 | 少 | 5-8分钟 | 只要一点油味道就会大幅提升 |
| 汤·炖菜 | 中等 | 5-10分钟 | 能让汤更鲜美 |
| 烤 | 少 | 5分钟 | 也可整束放在炭火上烤 |
| 煎饼、油炸 | 中等 | 5-8分钟 | 拌入面粉煎制可以增加分量 |

&nbsp;&nbsp;&nbsp;从省燃料的角度看，金针菇是很有利的菌类。它很薄，2-3分钟就能煮熟。不像香菇或大球盖菇那样需要煮10分钟以上，只要在做好的汤里最后放入、随即关火就足够了。

### 14-2. 干制品的使用方法

| 顺序 | 方法 |
|:--:|:---|
| 1 | 用温水泡10-15分钟发开，因为细，很快就能泡软 |
| 2 | **泡发的水不要倒掉**，其中溶有鲜味物质和水溶性营养素 |
| 3 | 避开沉在底部的碎屑，只取上层的水做汤 |
| 4 | 泡发的菌类切好后炒食或放入汤中 |
| 5 | 粉末不需要泡发，可直接放入汤水或面糊中 |

### 14-3. 弥补谷物不足的搭配

| 搭配 | 效果 |
|:---|:---|
| **菌类+谷物粥** | 菌类蛋白质能补上谷物中缺乏的赖氨酸 |
| **菌类粉+面粉·荞麦粉** | 掺入面疙瘩或面条的面糊中，提升蛋白质和B族维生素含量 |
| **菌类+凉拌野菜** | 微量营养素的构成互不相同 |
| **菌类+油** | 有助于脂溶性成分的吸收 |
| **菌类+豆类** | 蛋白质补充有所重叠，但氨基酸构成不同 |

> **应该把菌类当作蛋白质和微量营养素的补充来源，而不是热量来源。**
> 对金针菇来说尤其是维生素B1和B2。如果整个冬天都偏重谷物的饮食，会因维生素B1不足而出现腿部麻木、水肿和严重疲劳。一把金针菇就能补上这个缺口，而在冬天完全没有其他新鲜食品的时候，没有别的东西能替代它。

### 14-4. 在冬季餐桌上的位置

&nbsp;&nbsp;&nbsp;金针菇真正的价值在于季节性。11月到3月没有绿色叶菜，储存的根菜类营养已经下降，干制品中的维生素C和B族也已流失不少。在这段时间里，几乎没有作物能以新鲜状态出现，而金针菇恰恰就在这时产出。

| 季节 | 新鲜食品 | 金针菇的作用 |
|:---|:---|:---|
| 春-秋 | 凉拌野菜、叶菜、果菜 | 属于辅助角色，不必特意栽培 |
| **11-3月** | **几乎没有** | **唯一的新鲜蛋白质来源，也是B族维生素的供给源** |

## 15. 全年作业日程

| 月 | 作业 |
|:--:|:---|
| 1月 | **寒冬采收。**在朝北棚屋和土窖中采收，随即进行冻干或日晒 |
| 2月 | 继续采收，管理第2周期的休养，检查孢子印 |
| 3月 | 最后一次采收，收集菌糠归还田地，清洗并煮沸容器 |
| 4-5月 | 收集木屑，针叶树木屑堆放室外经雨水淋洗存放 |
| 6月 | 收集蛋壳晒干磨碎，备好米糠 |
| 7-8月 | **不栽培。**处于34℃危险区间，转而栽培其他菌类（大球盖菇、木耳） |
| **9月** | **配制培养基并灭菌。**收集木柴，用油桶一次性处理 |
| **10月** | **接种与培养。**室内23-25℃，选在雨后不久接种 |
| **11月** | **刮菌与发生。**移到土窖或朝北棚屋的14-15℃环境 |
| **12月** | **生育抑制与生育。**经5-7℃再到4-9℃，开始首次采收 |

&nbsp;&nbsp;&nbsp;这份日程的核心在于夏季休整。商业栽培靠制冷设备可以全年栽培，但没有电力就无法在夏天栽培。超过34℃菌丝会死，也没有办法造出4-9℃的环境。与其勉强尝试夏季作型，更应该把那个位置让给其他菌类，把金针菇固定为冬季作物。

### 绝对不能忘记的事

| 项目 | 内容 |
|:--:|:---|
| 1 | **孢子是白色这一点使金针菇格外危险。**不能靠孢子颜色排除鹅膏类，要同时查看是否长在树上、是否成丛、基部有没有菌托、菌柄基部是否为深褐色绒毛 |
| 2 | **长在地上的不是金针菇。**金针菇只长在阔叶树腐朽树桩和枯木上 |
| 3 | **菌褶若变成铁锈褐色或泛黄，就不是金针菇。**那是橘黄裸伞和簇生黄韧伞 |
| 4 | **超过34度菌丝就会死亡。**由于代谢热，即使周围只有30℃，培养基内部也可能超过这个温度 |
| 5 | **培养之后必须移到更冷的地方。**不降温就不会出菌 |
| 6 | **不要跳过生育抑制阶段。**只有养粗的菌类晒干后才能留下可食用的部分 |
| 7 | **一旦晒干，贮藏性的问题就消失了。**不要被生品E级的评价所迷惑 |
| 8 | **没有电力就是冬季作物。**想在夏天栽培会失败 |
| 9 | **因为不进行光合作用，所以在日照减少的灾害中依然稳定，是不受影响的食物来源。**太阳能评级SS不是说它善用光照，而是说它本就在光照之外 |
| 10 | **最安全的金针菇，是自己接种的瓶子里长出来的那一种** |
