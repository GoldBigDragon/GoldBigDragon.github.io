## 5. 接種方法

&nbsp;&nbsp;&nbsp;接種はエノキタケ栽培で失敗が最も多く出るところです。殺菌で培地をきれいに空けておいたのに、その空いた場所にキノコの菌糸より青カビが先に入り込むことがよくあります。接種の目標はただ一つ、キノコの菌糸が先に場所を占めることです。

### 5-1. 接種時期と温度

| 項目 | 基準 | 理由 |
|:---|:---|:---|
| 培地温度 | **25℃以下に冷ましたあと** | それより熱いと種菌が死にます |
| 冷ます時間 | ドラム缶の中で一晩、または15度の環境で13-14時間 | 培地の中心まで冷めなければなりません |
| 速度 | 冷めたらすぐに | 長く置くと空気中の胞子が付きます |
| 時間帯 | **早朝か雨の直後** | 空気中の胞子とほこりが最も少ないです |
| 季節 | 9月から11月 | 冬作型の出発点です |

&nbsp;&nbsp;&nbsp;雨の直後に接種するようにという助言は無菌室がないとき特に有効です。雨が空気中の胞子とほこりを洗い流し、落下する菌数が大きく減ります。反対に風が強い晴れた日の昼が最も悪いです。

### 5-2. 無菌室なしで接種するコツ

| 項目 | 方法 |
|:---|:---|
| 場所 | 風が入らない最も小さな部屋。倉庫の奥、納屋の隅 |
| 事前処理 | 床と壁に水をまいてほこりを沈めます。30分待ちます |
| 代用の無菌装置 | 大きな箱や甕を横に倒して内側を煮た湯で拭き、その中で手だけ入れて作業します |
| 手 | 石けんで洗い、できれば強いお酒や酢で拭きます |
| 道具 | さじと刃物を火で熱してから冷まします |
| 服 | 乾いた服より少し湿った服のほうがほこりを飛ばしにくいです |
| 呼吸 | 作業中に培地の上で話したり息を吹きかけたりしません。布で口を覆います |
| 動作 | 容器を開けて種菌を入れて閉じるまでを10秒以内で終えます |

> **無菌室がないときの要点は完璧な無菌ではなく速さと種菌量です。雑菌が多少入るのは防げないので、キノコの菌糸を圧倒的に多くして先に占めさせます。**

### 5-3. 接種量

| 項目 | 基準 |
|:---|:---|
| 標準 | 培地の重さの2-3% |
| 無菌室がないとき | **培地の重さの5-10%に増やします** |
| 入れる位置 | 中央の穴に半分、表面に半分 |
| 覆う | 入れたあと表面を軽く平らにします |
| 仕上げ | 口を綿や布で塞いで紐で結びます。ビニールで完全に密封しません |

&nbsp;&nbsp;&nbsp;口を完全に塞がないことが重要です。菌糸は酸素を使うので息ができなければ育ちません。同時に雑菌の胞子は防がなければならないので、空気は通り埃は濾される綿や何重かの布が正解です。木綿の綿、古いタオルを四重に折ったものが使えます。

### 5-4. 接種後24時間

| 時間 | 何を見るか |
|:---|:---|
| 12時間 | まだ変化はありません |
| 24-48時間 | 種菌の周りに**綿毛のような白い気**が立ち始めます |
| 3-5日 | 白い菌糸が種菌から放射状に1-2cm広がります |
| 7日 | 培地の上部が白色で覆われます |

&nbsp;&nbsp;&nbsp;この初期の数日が勝負です。3日以内に白い菌糸が目に見えて広がればほぼ成功です。5日経っても何の変化もなければ種菌が死んでいたか培地が熱すぎたときに接種したものです。そして白色ではない他の色が見えたら、そのボトルは直ちに他のボトルから離れた場所に移します。

## 6. 菌糸培養の管理

&nbsp;&nbsp;&nbsp;接種後およそ22日が培養期間です。目標は白い菌糸が培地全体を占領することです。人がすべきことは温度を守り、暗く置き、毎日観察して汚染したボトルを取り除くことくらいです。

### 6-1. 温度と湿度

| 項目 | 範囲 | 備考 |
|:---|:---:|:---|
| 菌糸生長温度 | 23-25℃ | 最も速いです |
| 可能範囲 | 5-30℃ | 低いと遅く、高いと危険です |
| **絶対上限** | **34℃** | **少し超えるだけでも菌糸が死にます** |
| 空気湿度 | 65-75% | 湿りすぎると表面に雑菌が付きます |
| 光 | 暗く | 光は必要ありません |
| 期間 | 約22日 | 培地量と温度によって18-28日 |

> **34度は絶対の一線です。菌糸自身が代謝熱を出すため、周囲の気温が30℃のとき培地の中は34℃を超えることがあります。ボトルを密に積むと真ん中が特に熱くなります。**

&nbsp;&nbsp;&nbsp;代謝熱の問題は菌糸が盛んに育つ培養中盤で最も深刻です。対応は三つです。ボトルの間に指が入るくらいの隙間を空けて積みます。培養10日目あたりから周囲の気温を2-3℃下げます。そして真夏の培養を避けます。

### 6-2. 毎日行う点検

| 観察 | 正常 | 異常 |
|:---|:---|:---|
| 色 | 白色からごく淡いクリーム色 | 青緑色、黒色、オレンジ色、桃色は汚染です |
| 質感 | 細くて密な綿のような白い層 | 粉のように飛ぶなら汚染胞子です |
| 匂い | かすかなキノコの香り、森の土の匂い | 酸っぱい匂い、こもった匂い、アンモニア臭は異常です |
| 進行 | 一日に2-4mmずつ下へ | 止まれば温度か水分の問題です |
| 容器の内側の壁 | 菌糸がガラスに付いて白い線が見えます | 水滴が多く付くと過湿です |
| 培地表面 | 均一に白色 | 一方だけ覆われていれば種菌が一方に固まったのです |

&nbsp;&nbsp;&nbsp;汚染したボトルを見つけたらすぐに取り出します。迷うと胞子が広がって隣のボトルまで失います。取り出したボトルは培養場所から遠く離れた場所で開け、内容物は燃やすか深く埋めます。ボトルは沸騰した湯で煮て再び使います。

### 6-3. 培養完了の判定

| 判定項目 | 基準 |
|:---|:---|
| 色 | 培地全体が均一に白色 |
| 底 | **底まで菌糸が届いていなければなりません。**上のほうだけ白いのは未完成です |
| 硬さ | 容器を逆さに持っても培地がかたまりのまま持ちます |
| 追加期間 | 全体が覆われたあと**3-5日さらに置きます。**後熟と呼び、収量が上がります |

&nbsp;&nbsp;&nbsp;後熟を飛ばすと収量が減ります。見た目は覆われていても培地の中には菌糸が薄い部分が残っているため、数日さらに置くほうが結果が良いです。

### 6-4. 菌かき

&nbsp;&nbsp;&nbsp;培養が終わったら培地表面の老化した菌糸層を掻き取ります。培養期間の間に表面にできた硬い菌糸膜とその上に積もった老化した細胞を取り除く作業です。

| 項目 | 方法 |
|:---|:---|
| 道具 | さじ、木のへら、沸騰した湯に浸けてから取り出した小さなかぎ |
| 深さ | 表面から2-5mmだけ |
| 範囲 | 表面全体を均一に |
| 目的 | 発芽をいちどきに均一に起こします |
| 注意 | あまり深く掻くと菌糸を大きく傷めて発芽が遅れます |

&nbsp;&nbsp;&nbsp;菌かきをするとキノコが表面全体で同時に出て収穫が一度に終わります。省くと数日にわたってばらばらに出て大きさもふぞろいになります。一度に収穫して一度に乾かさなければならない状況ならしておくほうがよいです。

## 7. 発生誘導

&nbsp;&nbsp;&nbsp;菌糸は快適だと伸び続けるだけです。キノコを結ぶことは菌糸にとって危機信号です。エノキタケの場合その信号はほぼすべて温度です。暖かい場所で育っていた菌糸を急に冷たくすればキノコを出します。

### 7-1. 温度の段階

| 段階 | 温度 | 期間 | 湿度 | 二酸化炭素 | 何を得るか |
|:---|:---:|:---:|:---:|:---:|:---|
| 培養 | 23-25℃ | 22日 | 65-75% | - | 培地の占領 |
| **発芽** | **14-15℃** | 8-10日 | 95-98% | 1,800-2,000ppm | 粟粒のような原基 |
| **生育抑制** | **5-7℃** | 5-15日 | 75-96% | 3,000-4,000ppm | 太く短い柄 |
| **生育** | **4-9℃** | 収穫まで | 75-85% | 6,000ppm以上 | 柄が長くなる |

&nbsp;&nbsp;&nbsp;この段階を作ることがエノキタケ栽培のすべてです。商業栽培は冷房機でやり、電力がなければ季節と場所でやります。

| 段階 | 無電力での確保方法 |
|:---|:---|
| 培養23-25℃ | 9-10月の室内、またはかまどのある部屋の一方 |
| 発芽14-15℃ | 11月の土穴や北向き納屋、または10月の夜間気温 |
| 抑制5-7℃ | 12月の軒下や北向き納屋。夜半の気温 |
| 生育4-9℃ | 12-2月の北向き納屋、土穴の入口、氷穴のそば |

> **段階を精密に合わせられなくてもキノコは出ます。重要なのは方向です。培養のあとには必ずより冷たい場所へ移さなければなりません。同じ温度に置き続けると菌糸だけが老化してキノコが出ません。**

### 7-2. 発芽段階でやること

| 項目 | 方法 |
|:---|:---|
| 移す | 培養を終えて菌かきをしたボトルを14-15℃になる場所へ移します |
| 湿度 | 95%以上。ボトルの上に濡れた布を掛けるか床に水をまきます |
| 光 | 弱い光を入れます。新聞が読める程度 |
| 待つ | 8-10日。表面に粟粒のような白い粒が密に付きます |
| 失敗の兆候 | 表面が乾いて固まれば湿度が足りないのです |

&nbsp;&nbsp;&nbsp;発芽段階の湿度95%は非常に高い値です。電力なしで作る方法は密閉と水です。ボトルを大きな箱や甕に一緒に入れ、底に濡れた砂や水を入れた皿を置き、蓋に小さな穴を数個だけ残すと内側の湿度がすぐに上がります。穴が全くないと二酸化炭素がたまりすぎ、水滴がキノコの上に落ちて細菌性の腐りが来ます。

### 7-3. 生育抑制 - エノキタケだけにある段階

&nbsp;&nbsp;&nbsp;他のキノコにはない段階です。原基が付いたあと5-7℃にさらに下げて5日から15日置きます。この期間に柄が長くなる代わりに太く固くなります。

| 効果 | 内容 |
|:---|:---|
| 柄が太くなります | 同じ重さで柄の数が減り一本一本が太くなります |
| 固くなります | 組織が密になり食感が良く貯蔵性が上がります |
| 均一に育ちます | 長さがふぞろいになりません |
| 飛ばすと | 柄が細く長く伸びて力がなくすぐに萎れます |

> **災害の状況で抑制段階は選択ではありません。太く固いキノコは乾かしやすく乾かしたあとも崩れません。細く伸びたキノコは乾かすと糸くずになって食べるものが残りません。**

&nbsp;&nbsp;&nbsp;抑制段階を電力なしで作る最も簡単な方法は真冬の夜です。12月から1月の北向き納屋は昼に7℃、夜に0℃前後です。昼と夜の平均が5-7℃に入れば十分です。ただし零下に長く下がるとキノコが凍って傷むので、わらやかますを掛けて零下に落ちないよう防ぎます。

### 7-4. 二酸化炭素で形を調整します

&nbsp;&nbsp;&nbsp;エノキタケの特異な性質です。二酸化炭素が高いと傘が小さいまま柄が長くなります。低いと傘が大きくなり柄が短くなります。

| 目標 | 換気 | 結果 |
|:---|:---|:---|
| 長い柄、小さい傘(市場の形) | ほぼ塞ぎます。ボトルの口に紙を巻いて立てます | 6,000ppm以上。豆もやしのような形 |
| 太い柄、大きい傘(野生の形) | 換気を十分にします | 傘が開き柄が太くなります |

&nbsp;&nbsp;&nbsp;災害の状況では後者のほうがよいです。同じ培地から出る重さがより多く、傘があるほうが栄養密度が高く、乾かすときに形が保たれます。市場で売られる形に合わせて作る理由がありません。

&nbsp;&nbsp;&nbsp;二酸化炭素の濃度は測れないので判断は感覚で行います。人が入って少しの間いても息苦しくない程度なら適切です。

## 8. 収穫と再発生周期

### 8-1. 収穫時期の判断

| 基準 | 内容 |
|:---|:---|
| 最適 | 傘がまだ閉じており柄が十分に長くなったとき |
| 遅い兆候 | **傘が開いてひだの間から白い粉が舞います。**胞子を放出し始めたのです |
| 遅れると | 味が落ち柔らかくなり貯蔵性が大きく悪くなります |
| 総期間 | 接種から収穫まで50-70日 |
| 時間帯 | 早朝 |

&nbsp;&nbsp;&nbsp;胞子を放出し始めたキノコは食べるには遅いですが他の使い道があります。4節の胞子採取に最も良い個体がまさにこの段階です。収穫が遅れて傘が開いたものが出たら捨てずに胞子紋を取っておきます。

### 8-2. 摘み方のコツ

&nbsp;&nbsp;&nbsp;束のまま根元を持って軽くねじりながら取り外します。無理に引っ張ると培地がむしれてその傷口から雑菌が入ります。根元の培地が付いた部分は刃物で切り取ります。

&nbsp;&nbsp;&nbsp;収穫したキノコは洗いません。水が触れると貯蔵性が急激に落ちます。培地のかけらは乾いた布で拭き取ります。

### 8-3. 再発生

| 項目 | 内容 |
|:---|:---|
| 休養期間 | 収穫後10-15日 |
| 休養中の管理 | 表面を掻いて残った根元を取り除き、湿度を保ちながら13-15度に置きます |
| 2周期の収量 | 1周期の50-70% |
| 3周期の収量 | 1周期の20-30%。行う意味が薄いです |
| 総収穫回数 | **最大2-3回** |
| 再収穫の間隔 | 30-60日 |

&nbsp;&nbsp;&nbsp;評価表の永続性Dがこの表の内容です。2周期で収量が半分に落ち3周期には25%以下になります。2周期まで収穫して培地を替えるほうが労力対効率が最も良いです。

&nbsp;&nbsp;&nbsp;災害の状況では計算が少し変わります。おがくずを新たに手に入れて再び煮るのにかかる燃料と労力が大きいなら、収量が減っても3周期まで引き続けるほうがよいこともあります。培地が黒く変わり酸っぱい匂いがすればそのときが限界です。

### 8-4. 収量

| 条件 | 収量 |
|:---|:---|
| 1,000mlボトル、培地600-750g | 1周期150-250g |
| 2周期含む | ボトルあたり250-350g |
| 卵の殻10%添加 | 1.21倍 |
| 生薬絞りかす20%添加 | 1.10倍 |
| 生物学的効率 | 培地乾物重量の30-50% |

&nbsp;&nbsp;&nbsp;ボトル一つから二周期にわたって300g前後が出ます。生のもの300gは63kcal、タンパク質7.4gです。熱量としてはほとんど意味がなく、タンパク質とビタミンB群として意味があります。ボトル二十個を一まとめにして回すと真冬の二か月間、毎日一握りずつナムルや汁物の具になる規模です。

> **エノキタケの収穫量を熱量に換算して計画を立てると失望します。代わりに冬に青いものが全くないときにビタミンB1とB2とリシンを供給する唯一の生鮮食品という点で値打ちを付けるのが正しいです。**

## 9. 汚染と病害虫

### 9-1. 青カビが第一の原因です

&nbsp;&nbsp;&nbsp;災害の状況でのキノコ栽培が失敗する最も多い原因は病害虫ではなく競合するカビに培地を奪われることです。その中で圧倒的に多いのがトリコデルマ(Trichoderma)、韓国語で青カビです。エノキタケは殺菌した培地を使うキノコのためこの危険がサケツバタケよりはるかに大きいです。殺菌した培地は雑菌にとっても空いた土地だからです。

| 区分 | エノキタケの菌糸 | 青カビ |
|:---|:---|:---|
| 色 | 白色、ごく淡いクリーム色 | 最初は白色、すぐに**青緑色** |
| 質感 | 細くて密な綿のような層 | 粉のように微細でぼろぼろします |
| 広がる速度 | 一日2-4mm | 一日10-30mm、**5-10倍速い** |
| 匂い | 森の土の匂い、キノコの香り | こもった匂い、時にココナッツに似た香り |
| 境界 | 培地に沿って均一に | 丸い斑点から放射状に |

> **青カビは色が見える前にすでに広がっています。**
> 青緑色は胞子が付いた段階、つまり繁殖を始めたあとです。その時点にはすでに培地のかなりの部分を失ったと見るべきです。初期の判別は色ではなく広がる速度と質感で行います。

### 9-2. その他の汚染菌

| 汚染菌 | 見た目 | 原因 |
|:---|:---|:---|
| 黒カビ(アスペルギルス) | 黒い粉が固まって出ます | 殺菌不足。特に米ぬかが多いとき |
| 赤カビ(フザリウム) | 桃色の綿 | 培地が湿りすぎたとき |
| 白毛カビ(ムコール) | 高く伸びた白い毛が速く伸びます | 培地が過湿で換気ができないとき |
| 細菌(バチルス) | 培地が粘り酸っぱい匂い | 殺菌が不十分で培地が過湿 |
| 黄色い細菌の斑 | キノコの柄に黄色い粘液 | 湿度が過度に高く水滴が落ちたとき |

&nbsp;&nbsp;&nbsp;細菌汚染は色がほとんど変わらず匂いだけで現れるため見分けにくいです。培地から酸っぱいまたは腐った練り粉の匂いがすれば細菌であり、殺菌時間が足りなかったという合図です。

### 9-3. 汚染を見つけたときと防ぐ方法

| 状況 | 対処 |
|:---|:---|
| **一本のボトルの表面に小さな斑点** | そのボトルだけ直ちに取り出します。**ボトルを開けずに**移します |
| **数本のボトルに広がった** | 培養場所全体を移します。元の場所は空にして水で洗って乾かします |
| **培地全体が青緑色** | 全量廃棄します。燃やすか栽培地から遠く離れた場所に埋めます |
| **培地から酸っぱい匂い** | 細菌です。廃棄して次の周期の殺菌時間を延ばします |

> **汚染した培地を堆肥に戻さないでください。**
> 青カビの胞子は堆肥の山の中で生き残り翌年の培地に再び入ってきます。必ず燃やすか栽培地と離れた場所に深く埋めます。

| 予防 | 原理 |
|:---|:---|
| **殺菌を十分に行います** | 常圧100度4-6時間。惜しめば必ず代償を払います |
| **種菌を十分に入れます** | 培地の重さの5-10%。先に場所を占めたほうが勝ちます |
| **米ぬかを20%以上入れません** | 栄養が多いと競合するカビが先に爆発します |
| **ボトルの間に隙間を空けて積みます** | 空気が通れば代謝熱が抜けカビが広がりません |
| **雨の直後に接種します** | 空気中の落下胞子が最も少ないです |
| **培養場所を毎年変えます** | 同じ場所を続けて使うと胞子が積み重なります |

### 9-4. 害虫

| 害虫 | 被害 | 対処 |
|:---|:---|:---|
| **キノコバエ(シアリド)** | 菌糸を食い荒らし子実体にうじが入ります。青カビの胞子を運びます | 口を布で塞いで物理的に遮断します。発生時は水の器のトラップやねばねば紙 |
| **ダニ** | 菌糸が褐色に変わり育ちません | 乾いた状態で管理し、発生した区画は隔離します |
| **ナメクジ** | 若い子実体を食いちぎります | 灰やおがくずの帯を巻いて防ぎます |
| **ネズミ** | キノコをかじって持っていき培地を荒らします | ボトルを棚に上げて網をかぶせます |

&nbsp;&nbsp;&nbsp;冬に育てるキノコという点が害虫対策で大きな利点です。キノコバエとダニは気温が10℃以下に下がると活動がほぼ止まります。エノキタケを真冬の作型に回せば害虫問題は自然に半分以上減ります。反対に夏に無理に育てると害虫と汚染が一緒に押し寄せます。
