## 10. 生育异常诊断

| 症状 | 原因 | 处理 |
|:---|:---|:---|
| 接种5天后仍看不到菌丝 | 在培养基过热时接种，菌种已死 | 把培养基冷却到25℃以下重新接种 |
| 菌丝生长后停止 | 培养基温度超过34度，水分不足 | 拉开瓶间距离散热，并降低周围气温 |
| 菌丝覆盖了却不出菌 | 没有降温，没有刮菌 | 移到14-15℃并刮表面 |
| 原基长出后干枯死亡 | 湿度不足 | 盖湿布并往地面洒水提升到95% |
| 只有菌柄细长抽出 | 跳过了抑制阶段，二氧化碳过多 | 在5-7℃放置5-15天并加大通风 |
| 菌盖过大而菌柄过短 | 二氧化碳不足，温度偏高 | 减少通风并移到更冷的地方 |
| 菌类变软出现黄色黏液 | 细菌性腐烂，有水珠滴落 | 甩掉盖子上的水珠并通风，病变部分要清除 |
| 菌盖变褐色 | 温度过高，错过采收时期 | 移到更冷的地方并按时采收 |
| 根部变褐溶解 | 水积在培养基里 | 不要直接浇水，只靠空气湿度提升 |
| 菌类只长在一侧 | 菌种堆在一侧，光只从一侧照入 | 下一周期均匀撒种，并转动瓶子 |
| 第2周期几乎没有产量 | 培养基养分耗尽 | 属于正常现象，更换培养基 |
| 培养基发黑发酸 | 细菌繁殖，培养基寿命已到 | 废弃并归入菌糠处理 |

## 11. 菌糠的循环利用

### 11-1. 菌糠不是废弃物

&nbsp;&nbsp;&nbsp;菌类采收完毕后的培养基，是菌丝分解木质后留下的优质有机物，比生木屑分解得多，可以直接施入田地。评价表中的施肥D级指的是每年60kg的有机物投入，而重要的是这60kg并非用一次就消失，而是在循环利用。

| 用途 | 方法 |
|:---|:---|
| **混入下一批培养基** | 最多混入新培养基的20%，标准配方里已经包含这一项 |
| **基肥** | 秋天铺到地里翻耕进去，能大量补充有机物和钾 |
| **覆盖材料** | 在作物之间铺5cm厚，可防杂草和水分蒸发 |
| **其他菌类的培养基** | 可以掺入大球盖菇的木片培养基中使用 |
| **堆肥促进剂** | 混入堆肥堆能加快分解 |
| **蚯蚓养殖基质** | 蚯蚓很爱吃，还能获得蚓粪土 |
| **燃料** | 完全晒干后火力较弱，但能燃烧 |

```
针叶树·阔叶树木屑 + 米糠 → 培养基 → 采收菌类 → 菌糠
                                      ↓            ↓
                            下批培养基20%   田地有机物
```

&nbsp;&nbsp;&nbsp;把菌糠按20%的比例混入下一批培养基，新需要的木屑就能减少20%，是直接减轻持续性D级和施肥D级负担的唯一手段。不过被污染的培养基绝对不能混入，青霉孢子会原样进入新培养基。

### 11-2. 培养场所的逐年管理

| 年份 | 管理 |
|:--:|:---|
| 第1年 | 可以继续沿用同一场所 |
| 第2年 | 周期之间要把场所空出来，用水洗净后晒干 |
| 第3年 | 换个场所更安全，因为杂菌孢子会不断累积 |
| 应急措施 | 在墙面和地面涂抹石硫合剂或浓草木灰灰汁 |

&nbsp;&nbsp;&nbsp;室内栽培杂菌孢子积累的速度较快。结束一个周期后要把空间空置几天，尽量开门让阳光照入，紫外线能相当程度地减少落下的孢子，是一种不需要电力也不需要药品的方法。

## 12. 毒菌误认与安全确认

> **本节直接关系到生命安全。确认能不能吃，比栽培本身更重要。**

&nbsp;&nbsp;&nbsp;在本文档涉及的六种菌类中，金针菇在野外被误认为毒菌的风险最大。原因有三个。第一，野生金针菇生长的阔叶树腐朽树桩上，其他菌类同样会以成束的形式长出。第二，栽培个体与野生个体差异太大，只见过栽培品的人认不出野生个体。第三，也是最重要的一点：金针菇的孢子是白色的。

### 12-1. "孢子白色就不吃"这条规则在这里不适用

&nbsp;&nbsp;&nbsp;在大球盖菇的文档里有一条简单而有力的防线：把菌盖倒扣在白纸上接取孢子，如果粉末是白色的就不吃。因为致命的毒菌如白毒鹅膏和淡红鹅膏都产生白色孢子，而大球盖菇产生灰褐色孢子，靠这一次确认就能筛掉最危险的种类。双孢蘑菇也产生褐色孢子，同样适用这条规则。

&nbsp;&nbsp;&nbsp;金针菇不同。**金针菇的孢子是白色到极淡的黄色**，与鹅膏类相同。因此不能靠孢子颜色来排除鹅膏。

> **对金针菇来说，孢子颜色不是用来排除鹅膏的手段，反而要反过来用：如果孢子是铁锈褐色或灰褐色，就用它来判定"这不是金针菇"。**

| 菌类 | 孢子颜色 | 这个颜色意味着什么 |
|:---|:---|:---|
| **金针菇** | **白色-淡黄色** | 基准 |
| 白毒鹅膏、淡红鹅膏 | 白色 | **孢子颜色无法区分，必须看其他性状** |
| 橘黄裸伞 | **铁锈褐色** | 不是金针菇 |
| 丝膜菌类 | **铁锈褐色** | 不是金针菇 |
| 簇生黄韧伞（苦味） | **灰褐色-黑褐色** | 不是金针菇 |
| 黑鳞伞类 | 褐色 | 不是金针菇 |

&nbsp;&nbsp;&nbsp;接取孢子时也要注意。金针菇的孢子是白色，在白纸上看不出来，必须用深色纸、锡箔纸或玻璃板来接取。而且一定要一半用白纸、一半用黑纸同时接取，这样才能一次判断出是白色孢子还是深色孢子。

### 12-2. 金针菇的确认性状——五项全部要看

&nbsp;&nbsp;&nbsp;因为孢子颜色这条单一防线用不上，就改用同时确认多项性状的方式。以下五项必须全部符合，才能认定是金针菇；只要有一项不符，就不吃。

| 编号 | 性状 | 金针菇的标准 |
|:--:|:---|:---|
| **1** | **发生基质** | **阔叶树腐朽树桩、枯木、倒伏的树干。长在地上的不是金针菇** |
| **2** | **菌盖的黏滑度** | **潮湿时触摸黏滑发亮。**干燥后会减弱，最好在雨后确认 |
| **3** | **菌柄基部的深褐色毛** | **基部呈深褐色到黑褐色，覆有短短的绒毛** |
| **4** | **成束生长的习性** | **多个菌体在基部相连，形成密集的一丛。**单独一个孤生的是别的菌类 |
| **5** | **没有菌环也没有菌托** | **菌柄上没有环、没有膜片残留、没有蛛网状痕迹，挖开基部也没有菌托** |

&nbsp;&nbsp;&nbsp;再补充一些辅助性状。

| 辅助性状 | 金针菇的标准 |
|:---|:---|
| 季节 | **晚秋到早春。**盛夏长出的很可能不是金针菇 |
| 菌褶颜色 | 白色到淡奶油色。**即使成熟也不会变成褐色或铁锈色** |
| 菌盖颜色 | 黄褐色到偏橙的红褐色，中央深、边缘浅 |
| 味道 | **没有苦味。**舌尖轻触若发苦就吐掉不吃 |
| 肉质颜色 | 白色，切开或碰伤也不会变黄 |

> **五项主要性状中只要有一项不符，就不要吃。尤其是长在地上的，无论多相似都不是金针菇。**

### 12-3. 橘黄裸伞——最容易混淆的对象

&nbsp;&nbsp;&nbsp;橘黄裸伞（Gymnopilus junonius）是与金针菇最容易混淆的菌类。它在同样的季节、同样的阔叶树树桩上同样成大丛生长，菌盖颜色也是黄褐色到偏橙色，远看几乎分不出来。它在日本被称为"大笑菌"，因为食用后会引起幻觉、兴奋和精神错乱。

| 区分 | **金针菇** | **橘黄裸伞（有毒）** |
|:---|:---|:---|
| **孢子颜色** | **白色-淡黄色** | **铁锈褐色，这是决定性差异** |
| **菌褶颜色** | **始终为白色-淡奶油色** | **起初黄色→随生长变为铁锈褐色-红褐色** |
| **菌环** | **没有** | **有，纤维质的环残留在菌柄上部** |
| **菌盖表面** | **潮湿时黏滑** | **干燥，带细微纤维状鳞片，不黏滑** |
| **菌柄基部** | **深褐色绒毛** | 与菌柄同为黄褐色，无毛，**基部膨大呈棒状** |
| 菌盖直径 | 2-8cm | **6-15cm，明显更大** |
| 菌柄粗细 | 0.3-0.8cm | 1-3cm，粗壮坚实 |
| 味道 | 无苦味 | **非常苦** |
| 发生基质 | 阔叶树腐朽树桩 | 阔叶树和针叶树树桩均可 |
| 季节 | 晚秋-早春 | 夏季到秋季 |

> **只要记住三点就能分辨：菌褶是否变成铁锈褐色，菌柄上是否有菌环，菌盖是否干燥呈纤维质而不黏滑。只要有一项符合，就是橘黄裸伞。**

&nbsp;&nbsp;&nbsp;中毒症状在食用后30分钟到3小时内出现，表现为眩晕、剧烈兴奋和发笑、幻视幻听、肌肉僵直、呕吐和腹痛。大多在一两天内恢复，但大量食用会加重精神错乱，并因脱水而变得危险。在没有医疗支援的情况下，能做的只有喂足够的水、让患者温暖躺卧并密切观察。

### 12-4. 白毒鹅膏与淡红鹅膏——孢子颜色无法区分

&nbsp;&nbsp;&nbsp;这一类更致命，一个个体的鹅膏毒素就足以致人死亡。而且它们的孢子是白色的，与金针菇孢子颜色相同。

| 区分 | **金针菇** | **白毒鹅膏·淡红鹅膏（致命）** |
|:---|:---|:---|
| 孢子颜色 | 白色-淡黄色 | **白色，无法区分** |
| 菌褶颜色 | 白色-淡奶油色 | **白色，无法区分** |
| **发生基质** | **阔叶树腐朽树桩·枯木** | **活树根部附近的地面，这是决定性差异** |
| **发生习性** | **密集成丛** | **单生，或几个分散生长** |
| **菌托** | **没有** | **有，膜状的菌托包住基部** |
| **菌环** | **没有** | **有，白色膜状的环残留在菌柄上部** |
| 菌盖颜色 | 黄褐色-偏橙的红褐色 | **白色到淡绿黄色** |
| 菌盖表面 | 潮湿时黏滑 | 光滑而干燥 |
| 菌柄基部的毛 | 深褐色绒毛 | 没有，白色且光滑 |
| 大小 | 菌盖2-8cm | 菌盖6-15cm、菌柄9-20cm，明显更大 |

> **区分金针菇和鹅膏类，靠的不是孢子颜色，而是以下四点：长在树上还是地上、成丛还是单生、基部有没有菌托、菌柄上有没有菌环。**

&nbsp;&nbsp;&nbsp;**确认菌托必须挖开来看。**只看地面以上的部分，菌托会被埋在土里而看不见，要养成把基部连土一起挖出来确认的习惯。金针菇长在木头上，本来就没有可挖的土，一拔就能看到附着在木头上的基部原样露出。如果发现自己需要挖土，这本身就已经是"这不是金针菇"的信号。

### 12-5. 丝膜菌类——症状来得越晚越危险

&nbsp;&nbsp;&nbsp;丝膜菌属（Cortinarius）中有些种含有奥来毒素。橙黄丝膜菌（Cortinarius orellanus）和赭红丝膜菌（C. rubellus）就属于这一类。这种毒素会破坏肾脏，而且最重要的是，症状要在食用后2天到21天才会出现。在这期间毫无异常，甚至不知道自己已经中毒。

| 区分 | **金针菇** | **丝膜菌类（破坏肾脏）** |
|:---|:---|:---|
| **孢子颜色** | **白色-淡黄色** | **铁锈褐色** |
| **蛛网状菌幕** | **没有** | **幼时菌盖边缘与菌柄之间有蛛网状的膜，成熟后在菌柄上留下铁锈褐色的环带** |
| 菌褶颜色 | 白色-淡奶油色 | 起初浅色→铁锈褐色 |
| **发生基质** | **阔叶树腐朽树桩** | **地面，属于与树根共生的菌根性菌类** |
| 发生习性 | 密集成丛 | 分散生长 |
| 菌盖表面 | 黏滑 | 纤维质或有鳞片 |
| 菌柄基部 | 深褐色绒毛 | 无毛 |

> **如果菌柄上有铁锈褐色的环带，或幼小个体的菌盖边缘有蛛网状的膜，就是丝膜菌类，绝对不能吃。这种毒最可怕的地方，就是因为没有症状而让人放松警惕。**

### 12-6. 簇生黄韧伞（苦味）——发生基质与习性完全相同

&nbsp;&nbsp;&nbsp;这里说的簇生黄韧伞（Hypholoma fasciculare，因味极苦而常被称为"苦味硫黄菌"）比上述三种更常见，也是与金针菇在同样位置、以同样姿态生长得最像的一种。它在阔叶树和针叶树的腐朽树桩上密集成丛生长，菌盖呈带黄色的黄褐色。仅凭发生基质和成丛习性无法区分两者。

| 区分 | **金针菇** | **簇生黄韧伞（有毒）** |
|:---|:---|:---|
| **孢子颜色** | **白色-淡黄色** | **灰褐色-黑褐色** |
| **菌褶颜色** | **始终为白色-淡奶油色** | **起初硫黄色→绿黄色→橄榄褐色→灰褐色** |
| **味道** | **无苦味** | **非常苦，舌头一碰立刻能察觉** |
| 菌盖颜色 | 黄褐色-偏橙的红褐色 | 硫黄色-黄褐色，中央呈红褐色 |
| 菌盖表面 | 潮湿时黏滑 | 光滑而干燥 |
| 菌柄基部 | 深褐色绒毛 | 无毛，整个菌柄呈黄色到黄褐色 |
| 发生基质 | 阔叶树腐朽树桩 | 相同 |
| 发生习性 | 密集成丛 | 相同 |

> **这种毒菌要靠菌褶颜色和味道来区分。菌褶若泛黄或带橄榄色就不是金针菇，舌尖一碰发苦也不是金针菇。**

&nbsp;&nbsp;&nbsp;试味这个动作本身也需要小心：只取极小的一点碰一下舌尖尝味，立刻吐掉，不要咽下。而且这个方法绝对不能用在鹅膏类上——鹅膏味道很好，靠味道分不出来，鹅膏毒素极少量就会伤肝。试味只是在孢子颜色和基质都确认通过之后才使用的最后一道辅助手段。

### 12-7. 其他容易混淆的对象

| 菌类 | 区分点 |
|:---|:---|
| **栗色垂幕菇（Hypholoma lateritium）** | 可食用。菌盖砖红色，孢子灰褐色。与上述苦味的簇生黄韧伞不易区分，没有把握就不要吃 |
| **黑鳞伞类** | 菌盖上有很多粗糙鳞片并带黏性，孢子呈褐色。毒性较弱但种类难辨 |
| **粉褶菌类** | 孢子呈粉红色，长在地上，胃肠毒性较强 |
| **鬼伞类** | 菌盖随时间推移会变黑溶化，与酒同食会中毒 |
| **褐鬼伞** | 在树桩上成丛长出，但菌盖呈卵形且很快溶化 |
| **马勃、粪生类** | 长在粪堆和粪便上，有些种含有致幻成分 |

### 12-8. 自己栽培的最安全

&nbsp;&nbsp;&nbsp;读到这里就会明白：采食野生金针菇是需要相当经验才能胜任的事，在没有医疗支援的灾害状况下更是如此。

> **在灾害状况下，食用金针菇最安全的方法不是到野外寻找，而是自己栽培。只要是自己接种的瓶子里长出来的，判别的问题根本就不会出现。**

&nbsp;&nbsp;&nbsp;不过自己栽培的也不是绝对安全。空气中的孢子可能落在培养基表面，让别的菌类一起长出来，尤其是灭菌不充分的培养基常会长出鬼伞类。如果一瓶里长出形态不同的菌类，凡是形态不一样的都要全部丢弃。

### 12-9. 初次食用的原则

&nbsp;&nbsp;&nbsp;在没有医疗支援的状况下，确认程序本身就是一种防护手段。

| 顺序 | 内容 |
|:--:|:---|
| 1 | **确认是否长在树上。**长在地上的丢弃 |
| 2 | **确认是否成丛。**单独一个的丢弃 |
| 3 | **查看菌柄上是否有菌环或蛛网状痕迹。**有的话丢弃 |
| 4 | **查看基部是否有菌托。**有的话丢弃 |
| 5 | **确认菌柄基部是否为深褐色绒毛。**不是的话丢弃 |
| 6 | **接取孢子查看颜色。**若是铁锈褐色或灰褐色就丢弃 |
| 7 | **一定要充分煮熟。**不要生食 |
| 8 | 首次食用时**只让一人、少量（一小块）**尝试，等待24小时 |
| 9 | 若无异常再增加食用量，不要多人同时食用 |
| 10 | 把吃过的那一个体**单独留存**，以便中毒时用于确认 |

> **超过6小时才出现的中毒症状最危险。**
> 食用后30分钟到2小时内出现的腹痛大多是胃肠刺激，但若在6小时到24小时后才开始呕吐腹泻，则是破坏肝脏的鹅膏毒素中毒的典型经过。发作越晚，病情越重。这种中毒有一段症状暂时缓解、看似恢复的时期，但实际上肝脏仍在持续受损。而丝膜菌类的奥来毒素要几天到3周后才会以肾脏症状显现出来，所以延后出现的异常也必须与之前吃过的菌类联系起来考虑。
