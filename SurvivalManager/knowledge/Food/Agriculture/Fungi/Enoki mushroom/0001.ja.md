## はじめに
&nbsp;&nbsp;&nbsp;エノキタケ(Flammulina velutipes)は、評価表で除外と判定されました。貯蔵性E(生の基準)と永続性Dが重なった結果で、ゲート未適用スコアは39.6点(有効183種中117位)です。貯蔵性は、細く裂いて干せば密閉容器で1年もつので、ナイフと干しざるだけで解決します。永続性Dとは、瓶や袋に詰めたおがくずの培地を1度使ったら捨て、1つの培地から2、3回収穫したら終わりだという意味です。それでも消さない理由が3つあります。第一に、光合成をしないので、日射が減る災害でも収量が保たれます(日射SS)。第二に、4-9℃で子実体を育てる低温性で、ほかのキノコがすべて止まる真冬が旬であり、新鮮な食べ物が途絶える時期を埋めます。第三に、熱量21kcalにタンパク質2.48gで熱量の47.2%(タンパク質密度SS)あり、ビタミンB1とB2が豊富です。電力がなければ冬の作物で、夏(34℃が危険)には育てません。最も重要な注意は、毒キノコとの取り違えです。エノキタケの胞子は白色から薄い黄色なので、白い胞子を除外するという単純な防御線を使えません。7節の見分け方を知らなければ、野生のものは採りません。

## 1. 災害への備えの評価
| 区分 | 内容 |
|:---|:---|
| 判定 | 除外(貯蔵性E + 永続性D)。ゲート未適用スコア39.6 |
| 強み | SS: タンパク質密度、日射、整地・掘削エネルギー、収量の安定性(室内の培地栽培で天候と連動しない)。S: 収穫速度、国内での栽培の普及度 |
| 弱み | E: 貯蔵性(生)、施設の負担(殺菌と低温)、温度幅、非食用の価値。D: 永続性、施肥、種子の寿命。C: 自家採種 |

> **キノコは日光が消えた世界でも収量が減らない唯一の食料源であり、エノキタケはそのなかでも、寒くなるほど具合がよくなる珍しい種です。**

&nbsp;&nbsp;&nbsp;項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. キノコの概要
&nbsp;&nbsp;&nbsp;担子菌門タマバリタケ科エノキタケ属で、広葉樹の枯れた幹や切り株を分解する白色腐朽菌です。野生の個体(野生のエノキタケ)と栽培の個体はまったく違う姿をしており、この違いを知らないと、野生で見分けられないか、別のキノコをエノキタケだと信じてしまいます。

| 器官 | 野生の個体 | 栽培の個体 |
|:---|:---|:---|
| かさ | 直径2-8cm。黄褐色-オレンジがかった赤褐色。湿っているとはっきり粘りがある | 直径1-3cm。純白、薄い黄色 |
| ひだ | 白色-薄いクリーム色。成熟しても褐色に変わらない | 白色 |
| 柄 | 長さ2-10cm。根元が濃い褐色-黒褐色の短いビロード状の毛で覆われる | 長さ8-15cm、細い |
| つば・くもの巣状の膜・つぼ | すべてなし | すべてなし |
| 胞子 | 白色-薄い黄色 | 同じ |
| 発生 | 腐った広葉樹の切り株にぎっしりと束になる。晩秋-早春 | 瓶の中で束になる。人工の低温 |

| 段階 | 期間 | 温度 | 湿度 |
|:---|:---|:---|:---|
| 菌糸の培養 | 約22日 | 23-25℃ | 65-75% |
| 菌かき | 1日 | - | - |
| 芽出し | 8-10日 | 14-15℃ | 95-98% |
| 生育抑制 | 5-15日 | 5-7℃ | 75-96% |
| 生育 | 収穫まで | 4-9℃ | 75-85% |

&nbsp;&nbsp;&nbsp;接種から収穫まで合計50-70日です。胞子1粒ではキノコにならない(異なる交配型の菌糸2つが結合する必要がある)ので、胞子はたっぷりまきます。100g当たり熱量21kcal、タンパク質2.48g、糖類0.37gで、食物繊維がキノコのなかで最高水準、ビタミンB1・B2が1日の必要量の25%程度あり、リシンとアルギニンが穀物の足りないアミノ酸を補います。

## 3. 培地と殺菌
| 項目 | 基準 |
|:---|:---|
| 樹種 | 針葉樹(ベイマツ、マツ、チョウセンゴヨウ)を使えるのがこのキノコだけの利点(半年-1年、野外で雨に当てて寝かせる)。ポプラ、ヤナギ、エノキ、クワ、カキは高く、ナラとニレは中程度。クルミ類(他感物質)とヒノキ・コノテガシワ・ビャクシン(抗菌成分)は禁止 |
| 配合 | おがくず60% + 廃菌床20% + 米ぬか20%(廃菌床がなければおがくず80% + 米ぬか20%)。米ぬかは20%を超えない。卵の殻(5mmに砕いたもの)をおがくずの量の10%混ぜると収量121% |
| 水分 | 65-70%(強く握ると指の間に水気がにじむが水滴は落ちない程度)。pH 4.5-8.6 |
| 容器 | ガラス瓶(口を布で覆って縛る。急に冷ますと割れる)、竹筒、陶器、熱に耐えるビニール袋(口は綿か布で塞ぐ)。1,000mlの瓶に培地600-750g |

| 殺菌 | 方法 |
|:---|:---|
| ドラム缶の常圧蒸気(電力なしの標準) | 200Lのドラム缶の底に水20-30cm、台の上に容器を立て、ふたをして隙間を濡れた布や粘土で塞ぐ。蒸気が上がってから100℃で4-6時間、火を消して一晩冷ます。薪30-50kg |
| ゆでる | 培地を袋に入れて2-3時間ゆで、絞って水分を合わせる。耐熱性の細菌の胞子が残るので、冷めたらすばやく接種し、種菌をたっぷり使う |
| 稲わらの加熱培地 | 稲わらや豆がらを1時間以上じっくりゆでて絞って冷まし、胞子の粉をたっぷりふりかけ、清潔な布で覆って20-25℃の暗所で2-4週間。胞子から種菌を育てるときに使い、栄養が少ないのでアオカビにもあまり魅力がない |

&nbsp;&nbsp;&nbsp;低温は、冬そのもの(11-3月の北向きの納屋や軒下)、洞窟やほら穴(10-15℃)、地下室(12-18℃)、北向き斜面の穴(8-14℃)、氷の穴(0-5℃)、濡れた布をつるす(周囲より3-5℃低い)でつくります。夏は洞窟で4℃をつくれないので、電力がなければ冬の作物です。

## 4. 種菌の確保と接種
| 方法 | 内容 |
|:---|:---|
| 胞子紋 | かさが完全に開いた大きく健康な個体を、ひだを下にしてアルミ箔にのせ、器をかぶせて24時間。日陰でさらに1日乾かし、半分に折ってジッパー袋に入れ、ガラス瓶に集めて蜜ろうで封じ、四季を通じて温度が一定の洞窟や地下室に置くと5-10年以上もつ(液体での保管は不可)。初年に20-30枚つくって蓄えておく |
| 組織培養 | 新鮮な個体を手で縦に割り、かさと柄が出会う内側の白い肉を米粒大にちぎって、ゆでて冷ましたおがくず培地や稲わらに差し込む。20-25℃の暗所で3-5日で広がる。最も確実 |
| 培地割り | 培養がちょうど終わった雑菌のない瓶の培地を、新しい培地の重さの5-10%混ぜる(1瓶が5-10瓶に増える)。4、5世代を超えると活力が落ちるので、組織培養か胞子に戻す |

| 接種 | 基準 |
|:---|:---|
| 条件 | 培地を25℃以下に冷ました直後(長く置くと空気中の胞子が落ちる)、早朝か雨の直後 |
| 無菌室がないとき | 風の入らない最も小さな部屋で、床と壁に水をまいてほこりを沈め、手は石けんと強い酒や酢で拭き、道具は火であぶって冷まし、布で口を覆い、容器を開けて種菌を入れて覆うまでを10秒以内に終える。接種量は標準の2-3%の2、3倍の培地重量の5-10%。口は綿か布で塞ぐが、ビニールで完全には密封しない |

> **無菌室がないときの核心は、完璧な無菌ではなく、速さと種菌の量です。雑菌が少し入るのは防げないので、キノコの菌糸を圧倒的に多くして先に場所を占めさせます。**

## 5. 培養、発生の誘導、収穫
| 段階 | 管理 |
|:---|:---|
| 菌糸の培養(約22日) | 23-25℃、暗く。絶対の上限は34℃で、菌糸が代謝熱を出すので周囲が30℃でも培地の中は超えることがあり、瓶をぎっしり積まない。白から薄いクリーム色が1日2-4mmずつ下へ広がり、底まで届いたら3-5日さらに置く(熟成)。青緑・黒・オレンジ・ピンクは汚染 |
| 菌かき | 培養が終わったら、スプーンや熱湯で消毒したフックで、表面の古い菌糸層を2-5mmだけ均一にかき取り、芽出しを一斉に起こす |
| 芽出し | 14-15℃に移し、湿度95%以上(濡れた布をかぶせるか床に水)、弱い光。8-10日で粟粒のような原基がぎっしりできる |
| 生育抑制 | 5-7℃で5-15日置いて柄を太く短く締める。省くと細く長く伸びて力がなく、干すと糸くずしか残らないので、省略しない。真冬の夜が最も簡単な方法 |
| 生育 | 4-9℃、湿度75-85%。換気を絞ると二酸化炭素が上がり、長い柄と小さなかさ(市場の形)になり、換気を十分にすると太い柄と大きなかさ(野生の形)になる。災害時は後者がよく、判断は感覚で行う |

> **温度の段を正確に合わせられなくても、キノコは出ます。大切なのは方向です。培養の後は必ずもっと冷たい場所に移します。同じ温度に置き続けると、菌糸だけが老いてキノコが出ません。**

| 収穫 | 基準 |
|:---|:---|
| 時期 | かさがまだ閉じていて、柄が十分に長くなったとき。かさが開き、ひだの間から白い粉(胞子)が舞ったら遅い |
| 要領 | 束のまま根元をつかみ、軽くひねって取る。洗わない |
| 再発生 | 10-15日休ませ(表面の残った根元をかき取り、13-15℃で湿度を保つ)、再収穫。最大2-3回で、3回目は1回目の20-30% |
| 収量 | 瓶1つ(培地600-750g)から1回目150-250g、2回目を含めて250-350g。生物学的効率は培地の乾燥重量の30-50% |

## 6. 汚染、病害虫、異常の診断
| 問題 | 症状と原因 | 対応 |
|:---|:---|:---|
| アオカビ | 最初は白、すぐ青緑色になる。1日10-30mmで、エノキタケの菌糸(2-4mm)の5-10倍速い。色が見えたときにはすでに培地の大部分を失っているので、初期は速さと質感で判別 | 1瓶なら開けずにすぐ取り出す。数瓶なら培養場所全体を移し、元の場所は洗って乾かす。全部が汚染されたら廃棄 |
| クロカビ、アカカビ、ケカビ、細菌 | 黒い粉、ピンク色の綿、背の高い白い毛、べたついた酸っぱいにおい。殺菌不足と過湿 | 廃棄し、次の周期は殺菌時間を長くする |
| キノコバエ、ダニ、ナメクジ、ネズミ | 菌糸と幼い子実体を食べる | 入口を布で塞いで水皿・粘着板のトラップ、乾燥気味に管理、灰やおがくずの帯、瓶を棚に上げてネット |

> **汚染された培地を堆肥に回してはいけません。アオカビの胞子は堆肥の山で生き残り、翌年の培地にまた入り込みます。燃やすか、栽培場所から離れた場所に深く埋めます。**

&nbsp;&nbsp;&nbsp;予防は、殺菌を十分に行う、種菌をたっぷり入れる、米ぬかを20%以上入れない(栄養が多いと競合するカビが先に爆発する)、瓶の間をあけて積む、雨の直後に接種する、培養場所を毎年変えることです。冬に育てるので害虫は少ないです。

| 症状 | 原因と措置 |
|:---|:---|
| 接種して5日たっても菌糸が見えない | 培地が熱いうちに接種した。25℃以下に冷まして再接種 |
| 菌糸が伸びて止まる | 培地温度が34℃超か水分不足。瓶の間をあけて熱を逃がす |
| 菌糸に覆われたがキノコが出ない | 温度を下げていないか、菌かきをしていない。14-15℃に移してかく |
| 原基ができて乾いたり柔らかくなって死ぬ | 湿度不足、または水滴が落ちた。空中の湿度だけで上げる |
| 柄だけが細く長く伸びる | 生育抑制を省いた、二酸化炭素過多。5-7℃に置いて換気 |

&nbsp;&nbsp;&nbsp;廃菌床は、次の周期の培地に20%まで混ぜ、畑の元肥、堆肥の促進剤、ミミズの基質、ほかのキノコの培地に使い、乾かせば薪にもなります。培養場所は2-3年で雑菌の胞子がたまるので、空にして水で洗って乾かし、壁と床に石灰硫黄合剤や濃い灰汁を塗ります。

## 7. 安全の確認 - 毒キノコとの取り違え
> **この節は命に直結します。エノキタケは、野生で毒キノコと混同される危険が最も大きいです。育てるよりも、食べてよいかを確認することのほうが重要です。**

&nbsp;&nbsp;&nbsp;エノキタケでは、胞子の色はテングタケ類を除外する手段ではありません。ドクツルタケとシロタマゴテングタケの胞子も白色で区別できず、逆に胞子がさび褐色や紫褐色なら、エノキタケではないという判定に使います。5つの形質をすべて確認し、1つでも合わなければ食べません。

| 番号 | 形質 | エノキタケの基準 |
|:---|:---|:---|
| 1 | 発生基質 | 広葉樹の腐った切り株、枯れ木。地面から生えたものはエノキタケではない |
| 2 | かさの粘り | 湿っているとねばねばして滑らか(雨の後に確認) |
| 3 | 柄の根元 | 濃い褐色-黒褐色の短いビロード状の毛 |
| 4 | 習性 | 根元でくっついてぎっしり束になる。1本だけのものは別のキノコ |
| 5 | つばとつぼ | どちらもない。根元を掘って確認 |

| 紛らわしいもの | 見分け方 |
|:---|:---|
| オオワライタケ(毒) | 胞子はさび褐色、ひだは黄色からさび褐色、柄につば、かさは乾いた繊維状でねばらない、根元がこん棒のように膨らんで毛がない、かさ6-15cm、非常に苦い。中毒は30分-3時間以内に始まる |
| ドクツルタケ・シロタマゴテングタケ(致命的) | 胞子もひだも白色で区別できない。生きた木の根の近くの地面に1本ずつ生え、つぼとつばがあり、かさは白色-薄い緑黄色でなめらか、根元に毛がなく、かさ6-15cmと柄9-20cmではるかに大きい |
| フウセンタケ類(オレラニン、腎臓破壊) | 胞子はさび褐色、若いときはかさの縁と柄の間にくもの巣状の膜(成熟すると柄にさび褐色の帯)、地面に散らばって生える。症状は数日から3週間後に出る |
| ニガクリタケ(毒) | 同じ基質で同じ束。胞子は紫褐色-黒褐色、ひだは硫黄色からオリーブ色、紫褐色、非常に苦い、柄の根元に毛がなく柄全体が黄色-黄褐色 |

&nbsp;&nbsp;&nbsp;そのほか、イッポンシメジ類(胞子はピンク色、地面に生え、胃腸毒)やヒカゲタケ類もあり、クリタケ(食用)はニガクリタケと区別しにくいので、確信がなければ食べません。味を見るときは舌先にそっとつけて、苦ければ吐き出して食べません。

&nbsp;&nbsp;&nbsp;初めて食べるときは確認手順をすべて踏み、十分に加熱し、1人が1切れだけ食べて24時間待ち、食べたキノコの1個体を別に残しておきます。食べて6-24時間後に嘔吐と下痢が始まるのは、アマトキシン中毒の典型的な経過で、症状がしばらく治まって回復したように見えても、肝臓は壊れつつあります。最も安全なエノキタケは、自分が種菌を入れた瓶から出たものです。

## 8. 貯蔵、調理、年間日程
| 貯蔵 | 内容 |
|:---|:---|
| 生 | 常温では3日で根元から褐変し、4日で柔らかくなる。真冬は北向きの軒下や洞窟につるして2-3週間 |
| 乾燥 | 束を手で裂いてすだれやざるに広げ、晴れた日に1-2日日光で干す(ビタミンDが増える)、日陰の風乾2-4日、糸に通して軒下に3-5日、火のそばの40-50℃で半日、冬は氷点下に出して凍らせてから冷たい風で5-10日(冬の収穫物に最も合う)。手でもむと粉々になれば完了。太く育てたキノコだけが、干した後も形が残る |
| 粉 | 崩れ始めたものは粉にする。体積が小さく、汁にうま味を足し、穀物の粉に混ぜてタンパク質とビタミンB群を補う |

&nbsp;&nbsp;&nbsp;エノキタケは必ず加熱して食べます。ゆでるのは2-3分(燃料が最も少ない)、汁物・煮込みは5-10分、焼くのは5分、チヂミは5-8分です。乾燥したものはぬるま湯に10-15分浸し、底の砕けた粉を避けて戻し汁をだしとして使います。穀物に偏った食事を冬じゅう続けると、チアミン不足で足のしびれ、むくみ、ひどい疲労が出ますが、エノキタケひとつかみがその欠乏を補います。11-3月には、唯一の新鮮なタンパク質源でありビタミンB群の供給源です。

| 月 | 作業 |
|:---|:---|
| 1-3月 | 真冬の収穫(北向きの納屋、洞窟)とすぐの乾燥、2回目に向けた休養の管理、3月に廃菌床を畑へ回し、容器を洗ってゆでる |
| 4-6月 | おがくず集め(針葉樹のおがくずは野外で寝かせる)、卵の殻を乾かして砕く、米ぬかの確保 |
| 7-8月 | 育てない(34℃の危険区間)。ほかのキノコに回す |
| 9月 | 培地の調製と殺菌(薪を集めてドラム缶で一度に処理) |
| 10月 | 接種と培養(室内23-25℃、雨の直後を選んで接種) |
| 11月 | 菌かきと芽出し(洞窟や北向きの納屋の14-15℃へ移す) |
| 12月 | 生育抑制(5-7℃)と生育(4-9℃)、初収穫 |

> **決して忘れてはならないこと: 地面から生えたものはエノキタケではなく、ひだがさび褐色や黄色みを帯びたらエノキタケではない。34℃を超えると菌糸が死に、培養の後はもっと冷たい場所に移し、生育抑制を省かず、電力がなければ冬の作物である。**
