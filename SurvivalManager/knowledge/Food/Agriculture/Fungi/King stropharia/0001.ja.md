## はじめに
&nbsp;&nbsp;&nbsp;サケツバタケ(Stropharia rugosoannulata)は、評価対象のキノコ6種のうち災害への備えのスコアが最も高い種で、総合S、54.4点(有効183種中6位)です。理由は、殺菌がないことです。キノコ栽培は普通、殺菌(電気や薪)と無菌接種でつまずきますが、このキノコは木材チップやわらを地面に敷き、種菌をまいて、もう一度覆えば終わりです。熱量も、野外栽培の実測値で1㎡当たり1,618kcal(自給ラインの0.62倍)です。光合成をしないので、日射が減っても収量が保たれます(日射SS)。弱みは、生の貯蔵性E(15℃で4-6日で商品性を失う)、国内での栽培の普及度D、そして致命的な毒キノコとの混同です。収穫適期の若いボタン段階はテングタケ類の幼菌に似ているので、7節を読み、自分で作った菌床に生えたものだけを採ります。

## 1. 災害への備えの評価
| 区分 | 内容 |
|:---|:---|
| 判定 | 総合S、54.4点(有効183種中6位)。副食のシナリオSS 66.0 |
| 強み | SS: タンパク質密度、施設の負担、日射、連作への適応性、整地・掘削エネルギー、自家採種。S: 永続性、耐寒性、味 |
| 弱み | E: 貯蔵性(生)。D: 国内での栽培の普及度、種子の寿命。C: 微量栄養素(11種を満たす)、病害虫圧、キノコ副産物への適応性 |

> **キノコは日光が消えた世界でも収量が減らない唯一の食料源であり、サケツバタケはそれを殺菌設備なしでやってのける唯一の種です。**

&nbsp;&nbsp;&nbsp;項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. キノコの概要
&nbsp;&nbsp;&nbsp;担子菌門ハラタケ綱ハラタケ目モエギタケ科サケツバタケ属で、落ち葉や木質の残骸を分解する腐生菌です。種小名のrugosoannulataは、しわのあるつばという意味です。

| 特徴 | 内容 |
|:---|:---|
| かさ | 直径4-15cm(大きなものは20cm以上)。半球形から平らに開く。赤褐色、暗褐色、ワイン色で、乾くと色が薄くなって裂ける |
| ひだ | 柄に完全に付いて密。白色から灰紫色を経て紫黒色に変わる |
| 柄、つば | 棍棒形で下が太く、上は白色、下は黄色。つばは厚くて硬く、上面に放射状の溝が深くあり、星形や鋸歯状に見える |
| 根元、胞子 | つぼはない。白い菌糸束が培地のほうへ伸びる。胞子は紫黒色-暗褐色 |

> **ひだが白色から紫黒色に変わり、つばの上面に星形の溝があり、根元につぼがありません。この3つがサケツバタケの身分証です。**

&nbsp;&nbsp;&nbsp;胞子1個からはキノコは出ません。胞子は単核なので、1次菌糸は育ってから死に絶え、異なる2本の菌糸が出会って対を成してはじめて、太い菌糸束となって培地を掌握し、雑菌を押しのけます。そのため胞子は、1個ずつではなく、粉をたっぷり振り入れます。

| 段階 | 期間と温度 | 要点 |
|:---|:---|:---|
| 菌糸のまん延 | 30-60日、5-35℃(最適26℃) | 培地全体に白い菌糸の束が広がる |
| 覆土 | まん延の後 | 2-4cmの土か落ち葉 |
| 原基の形成、生育 | 覆土の後30-60日(12-20℃)、続いて7-14日(12-25℃) | 覆土の下にあわ粒のような玉ができて膨らみ、かさが開く |

&nbsp;&nbsp;&nbsp;100g当たり熱量約25kcal、タンパク質2.40g(熱量比38.3%、乾物基準25.75-34.17%)で、カリウムは乾物基準3.58g/100gと、食用キノコで最高の報告値です。RDAの10%を満たす栄養素が11種(リン、鉄、亜鉛、マンガン、銅、カルシウム、マグネシウム、セレンなど)あり、うま味がとても強いです。

## 3. 培地と処理
> **ほかのキノコは培地を作って殺菌しますが、このキノコは培地を地面に敷くだけです。災害時にはこの違いが成否を分けます。**

| 資材 | 特徴 |
|:---|:---|
| 広葉樹の木材チップ | 最も推奨。何年も続けて収穫できる |
| 稲わら、麦わら、トウモロコシの茎 | 適合度が高い。わらは発生が早いが菌床の寿命が短く、トウモロコシの茎は養分が多く収量が高い |
| もみ殻、落ち葉、おがくず、廃培地 | 中程度。もみ殻(通気性)、落ち葉、おがくず(細かすぎると空気が通らない)は木材チップと混ぜて使い、シイタケやキクラゲを育てて残った廃培地はそのまま使う。コーヒーかすや豆のさやは窒素源として少量 |

| 木材チップ | 基準 |
|:---|:---|
| 樹種 | 最適: カエデ、ヤナギ、ポプラ、ニレ(柔らかく分解が早いので菌糸がよく広がる)。可能: ナラ類、ハンノキ、サクラ(発生は遅いが長持ちする)。禁止: 針葉樹(樹脂とテルペンが菌糸を抑える)、クルミ類(他感物質が菌糸を殺す) |
| 大きさ、新鮮さ | 爪から親指ほどの大きさ(細かすぎると空気が通らず、大きすぎると菌糸が渡れない)。伐採から1年以内(長く積んだチップにはすでにほかの菌が定着している) |

| 処理 | 方法 | 所要時間、抑制力 |
|:---|:---|:---|
| 水浸し | チップやわらを水に24-48時間浸してから上げ、6-12時間水を切る(握っても水がしたたらない程度、含水率65-80%、最適75%)。酸素が断たれて好気性の雑菌が弱る | 24-48時間、低い。野外のチップの菌床に最も一般的 |
| 石灰浸し | 水100Lに消石灰1-1.5kg(または生石灰0.5-1kg)、pH12-13。刻んだわらやチップを12-24時間浸した後、水を切ってすすがない(残ったアルカリが雑菌を抑え続ける)。カビの胞子は壊すが、キノコの菌糸は比較的耐える | 12-24時間、中程度。わらが主材料のときや夏 |
| 稲わら発酵 | わらを濡らして高さ1-1.5mに積むと、好熱性の微生物が発熱して60-70℃になる。長くやりすぎない | 1-2週間、中程度。わらが多く時間があるとき |
| 熱湯、蒸気 | わらを熱湯で1時間ゆでるか、200Lドラム缶(底に水20-30cm、台の上に材料)で2-4時間蒸す | 1-4時間、高い。燃料を多く使う。屋内の菌床、最初の菌床の確保 |

&nbsp;&nbsp;&nbsp;菌床の場所は半日陰(100-500lux)がよいです。野菜が落とす日陰、木の下、塀の北側の水はけのよい平地やなだらかな斜面で、耕さない常設の花壇、果樹園の間、道端のうち、毎日通りかかり、野菜に水をやるときに一緒にやれる場所が最適です。一日中直射日光が当たる場所、真っ暗な場所、水がたまる低地、毎年耕す畑のど真ん中は避けます。

## 4. 種菌の確保
> **キノコには種がないので、種菌をつないでいかなければなりません。このキノコは根づけば、スコップですくって種菌が得られます。**

| 方法 | 内容 |
|:---|:---|
| 菌床の分割(最も簡単) | 白い菌糸の束が太く伸び、雑菌の跡がない部分を、スコップで20cm四方ほどすくい取り、こぶしの大きさに分ける(細かく砕きすぎると菌糸が傷む)。新しい菌床のチップの層の間に30-40cm間隔で埋め、たっぷり水をやる。1つの菌床から3-5個の新しい菌床。すくった跡は新しいチップで埋めればすぐ回復する |
| 組織培養(最も確実) | 新鮮なキノコをナイフではなく手で縦に裂き(ナイフは表面の雑菌を中に引き込む)、中の肉片を、ゆでて冷ましたわらや湿ったチップの間にはさみ、22-26℃の暗い場所で培養する。3-5日で白い菌糸が広がる |
| 胞子紋 | かさが完全に開いてひだが紫黒色に染まった大きな個体を、ひだを下にしてアルミ箔(紙は湿気と雑菌を抱える)の上にのせて覆っておくと、胞子の粉が残る。箔ごと日陰でもう1日乾かして密封すれば5-10年以上(液体での保管は禁止) |

&nbsp;&nbsp;&nbsp;優先順位は、菌床の分割、組織培養、胞子紋から作るわら培地(菌床を失ったとき)、市販の種菌(入手できるときに前もって確保)の順です。わら培地は、わらを熱湯で1時間以上ゆでて冷ました後、胞子の粉をたっぷりまき、22-26℃の暗い場所で2-4週間培養し、白い菌糸の束がわらを覆えば成功です。種子の寿命Dは市販の種菌(6か月-1年)が基準で、根づいた菌床は何年も続きます。

## 5. 接種、培養、発生、収穫
&nbsp;&nbsp;&nbsp;春に作った菌床(最後の霜の後)はその年の初夏から、秋に作った菌床(初霜の2-3週間前まで)は冬を越して翌年の春から収穫します。温帯では4-10月に行い、真夏の猛暑と真冬は、30℃を超えたり凍ったりして定着しにくいので避けます。

| 菌床の積み方 | 内容 |
|:---|:---|
| 順序 | 雑草と大きな残骸を取り除いて地面をむき出しにし(地面に直接触れさせる)、湿らせたチップやわらを3-5cm、種菌を細かく砕いて均等に、チップ3-5cm、種菌、最後のチップ5-10cm、乾いた葉やわら・堆肥2-3cm、たっぷり水をやる |
| 規格 | 総厚15-20cm、種菌は1㎡当たり0.5-0.8kg、幅1-1.2m(それより広いと中央に手が届かない)、菌床の間に40-60cmの通路。種菌が足りないときは、層ではなく面積を減らす |
| 覆土 | 菌糸が培地全体に広がった後(作ってから30-60日後)、畑の土・腐葉土・砂を混ぜたもの(または乾いた葉と堆肥)を、細かすぎないように2-4cm覆い、たっぷり湿らせる。水分の維持と原基の形成を促す必須条件 |

| 培養の管理 | 基準 |
|:---|:---|
| 温度、水分 | 菌糸は5-35℃(最適26℃)。40℃以上や培地の乾燥で死ぬ。含水率65-80%(最適75%)。冬は氷点下でも死なず、わらや落ち葉を5-10cm覆う |
| 水 | 作った直後は培地の中までたっぷり。培養中は表面が乾いたらやる(週1-2回、夏は3-4日に1回、夕方)。干ばつのときはわらや落ち葉を厚く覆う |
| 正常な生育 | 太い白い糸や束がチップをつなぎ、土のにおいに近いほのかなキノコの香り。1か月で培地の半分以上(2か月たっても広がらなければ水分か材料の問題)。細かい霜のようなもの、酸っぱいにおいやアンモニア臭、緑色・オレンジ色・黒色があれば汚染。初期に灰色のヒトヨタケ類が少し出るのは問題ない |

&nbsp;&nbsp;&nbsp;発生のきっかけは、覆土(最も強い信号)、温度の低下(培養の26℃から発生の12-20℃へ、季節がやってくれる)、培地をたっぷり湿らせて空中湿度を85-95%に上げる水分の上昇、100-500luxの弱い光、雨です。雨が降った後、数日でまとまって出るので、野外では特に手をかけることはほとんどありません。子実体は12-25℃(最適12-20℃、16℃以下では太くしっかりし、24℃以上では細くて早く開く)で育ち、4℃未満では形成が難しくなります。空中湿度は発生の初期が85-95%、生育期が75-80%で、乾きすぎるとかさが裂けます。初夏に最も多く出て、25℃を超える真夏は減るか止まるので、遮光と水やりを増やし、秋にまた多く出て品質が最もよいので、新しいチップを5-10cm補充します。

| 収穫 | 基準 |
|:---|:---|
| 時期 | かさが柄から完全に開く直前(かさの直径5-10cm、つばがまだ付いているか、落ちたばかりのボタン段階)。最も硬く、味がよい。かさが平らになってひだが紫黒色に濃くなったら遅い(食感、味、貯蔵性がすべて悪くなる) |
| 要領 | 柄の根元を持ってひねりながら、根元まで丸ごと引き抜く |
| 周期 | 初収穫は菌床を作ってから90日前後(覆土の後30-60日)。1回の発生は7-14日、間隔は12-25日で、1作期に3-5回 |
| 菌床の寿命、収量 | 秋か早春に新しいチップを5-10cm覆えば何年も続く。収量は、中国の野外栽培の全国平均で1㎡当たり6.47kg(培地の配合により2.59-5.22kg)、熱量にして1㎡当たり1,618kcal |

## 6. 汚染と病害虫、異常の診断
&nbsp;&nbsp;&nbsp;災害時のキノコ栽培が失敗する最も多い原因は、病害虫ではなく、競合するカビ(アオカビ)に培地を奪われることです。アオカビは青緑色が見える前、つまり胞子ができる前にすでに広がっているので、速さと質感で見分けます。

| 区分 | サケツバタケの菌糸 | アオカビ |
|:---|:---|:---|
| 色 | 白色、やや黄ばむ | 最初は白色、すぐに青緑色 |
| 質感 | 太い糸状の筋、やや粗い | 粉のように細かく、綿のよう |
| 速さ、におい | 1日3-8mm。森の土のにおい、キノコの香り | 1日10-30mm(3-5倍速い)。かび臭いにおい |

| 状況 | 対処 |
|:---|:---|
| 斑点が手のひらより小さい | 周りの土まで大きめに掘り取り、その跡に木灰をまいてアルカリ性にする |
| 数か所に広がった、または全体が青緑色 | その区画はあきらめ、菌糸が勝った部分だけを残して移す。全体が青緑色なら全量廃棄(燃やすか、栽培地から離れた場所に深く埋める) |

> **汚染された培地を堆肥に回してはいけません。アオカビの胞子は堆肥の山で生き残り、翌年の培地に再び入ってきます。**

&nbsp;&nbsp;&nbsp;このキノコは培地を完全には殺菌せずに育てるので、汚染対策は滅菌ではなく、競争に勝たせることです。種菌を培地の重さの5-10%とたっぷり入れ、消石灰や木灰でpHを7.5-8.5に上げ(アオカビは弱酸性を好む)、窒素を入れすぎず、培地を強く押し固めず、手は石けんで洗い、ナイフとスコップは火であぶります。害虫は、キノコバエ(菌糸を食い、アオカビの胞子を運ぶ: 粘着トラップと水皿トラップ)、ナメクジ(灰やおがくずの帯、夜に手で捕まえる)、ネズミと鳥(網をかける)がいます。野外栽培なので完全には防げませんが、発生量が多いので、一部を失っても収穫は残ります。

| 症状 | 原因と対処 |
|:---|:---|
| 菌糸が伸びない、または伸びて止まる | 培地が乾きすぎている、または湿りすぎて酸素不足、温度が低い、栄養の枯渇、種菌が死んでいる。水をやって水分を65-70%にし、地温を確認して、新しい培地を上に敷き足す |
| 子実体が小さく柄だけが長くなる | 光不足、二酸化炭素の過多。覆いを外して光と換気を与える |
| 柄が軟らかくなって倒れる | 過湿、細菌性の軟腐。水をやめて換気し、病んだものを取り除く |

&nbsp;&nbsp;&nbsp;このキノコの最大の長所は、畑を別に使わないことです。トウモロコシやモロコシの間(収穫後は茎が次の培地になる)、果樹の下、カボチャやキュウリのつるの下、垣根や塀の北側など、作物が育たない場所に置きます。発生が終わった培地は、菌糸が木質を分解した良質な有機物なので、秋に畑にすき込むか、菌糸が生きている塊を新しい培地に混ぜて種菌として使います。同じ場所では2-3年目からアオカビと害虫の密度が上がるので、3年目には古い培地を全量取り除いて畑へ回し、場所を移して、元の場所は1-2年休ませます。

## 7. 毒キノコの誤認と安全の確認
> **この節は命に直結します。育てることよりも、食べてよいか確かめることのほうが重要です。**

&nbsp;&nbsp;&nbsp;育てたキノコでも、野生のキノコが同じ培地に混じって生えることがあります。

| 部位 | サケツバタケ |
|:---|:---|
| かさ、ひだ | 最初は半球形で、のちに開く。直径5-15cm(大きなものは30cm)。赤褐色-ワイン色で、乾くと薄くなる。ひだは灰白色から、育つにつれて暗褐色-紫黒色に濃くなる |
| 柄 | 太くて硬い。白色-淡黄色で、長さ8-15cm。つばがあり、若いときにかさを覆っていた膜が裂けて残ったもの |
| 根元、肉 | つぼはなく、根のような白い菌糸束が付いている。肉は白色で、切ったり傷つけたりしても青く変わらない |

| 区分 | サケツバタケ | テングタケ類(致命的) |
|:---|:---|:---|
| 胞子の色 | 暗褐色-紫黒色 | 白色 |
| ひだの色 | 育つにつれて濃い暗褐色 | 最後まで白色 |
| 柄の根元 | つぼはない | 膜でできたつぼがある |
| かさの色 | 赤褐色-ワイン色 | 白色、黄色、緑色、灰色など |
| 発生場所 | わら・木の副産物の培地 | 生きた木の根の近くの地面 |

> **胞子が白色なら絶対に食べてはいけません(白い紙にかさを伏せてのせ、コップをかぶせて数時間置くと確認できます)。ドクツルタケ(Amanita virosa)やシロタマゴテングタケ(Amanita verna)のような致命的な毒キノコは、胞子が白色で、ひだも最後まで白色で、柄の根元につぼがあります。この3つのうち1つでも当てはまれば食べません。**

&nbsp;&nbsp;&nbsp;つぼの確認は、必ず掘って行います。地面から出ている部分だけを見ると、つぼが土に埋もれて見えません。スギタケの仲間は、かさに粗いうろこが多く、群がって生え、種の区別が難しいです。同じサケツバタケ属には幻覚成分をもつ種があるので、切ると肉が青く変色するものは食べません。胃腸への毒性が強いキホウキタケやクサウラベニタケとも混同しないようにします。

&nbsp;&nbsp;&nbsp;初めて食べるときは、胞子紋を取って色を確認し(白色なら捨てる)、柄の根元を掘ってつぼがないことを確認し、十分に火を通し(生食は禁止)、1人だけが少量(ひとかけら)を食べて24時間待ちます。異常がなければ量を増やしますが、複数人が同時に食べず、食べたキノコを1個体、別に残しておきます(中毒のときの確認に使う)。食後30分-2時間以内の腹痛はたいてい胃腸の刺激ですが、6-24時間後に嘔吐と下痢が始まるのは、肝臓を破壊するアマトキシン中毒の典型的な経過です。始まるのが遅いほど重篤で、症状が一時おさまって回復したように見えるときも、肝臓は壊れ続けています。

## 8. 貯蔵、調理、年間日程
> **貯蔵性Eは生を基準にした等級です。乾燥は燃料も設備もほとんど使わないので、災害時のキノコの貯蔵性の問題は、事実上、乾燥ひとつで解決します。**

| 貯蔵 | 内容 |
|:---|:---|
| 天日乾燥 | かさを4-6mmに切り、すだれに広げる。晴れた日に2-3日。最も簡単で、ビタミンDが増える |
| 日陰、火のそば | 風通しのよい軒下の日陰で風乾4-7日(色と香りがよく残る)、丸ごと糸に通して軒下につるして5-10日、かまどの上の棚で40-50℃にして1日(梅雨時用、焦がさないようにする) |
| 保管、その他 | 涼しく暗い場所で1-2年、粉にひけば2年以上。漬け物(ゆでて、しょうゆと酢、3-6か月)、塩水での乳酸発酵(3-6か月) |

&nbsp;&nbsp;&nbsp;切って干すほうが、丸ごと干すより優れています(太い柄は中が乾ききらず、カビが生える)。干したものがぼろぼろ崩れ始めたら、捨てずに粉にします。キノコの粉は、かさばらず、汁物にうま味を出し、小麦粉やそば粉の生地(すいとんや手打ち麺)に混ぜて、タンパク質と微量栄養素を補えます。

&nbsp;&nbsp;&nbsp;生では食べません。焼くのは5-10分(柄が太いので焼き物に向く)、汁物や煮込みは10-15分(汁にうま味が出る)、ゆでるのは10分(ゆでて和え物にする)かかり、柄が太くて硬いので肉のような食感になります。キノコは、熱量源ではなく、タンパク質と微量栄養素(穀物が満たせないアミノ酸、ビタミンD、セレン、銅)の補給源として使います。

| 月 | 作業 |
|:---|:---|
| 1-5月 | 木材チップ・稲わら集めと種菌の点検。3月にわらの水浸しと予備発酵、4月に1回目の接種(地温12℃以上を確認してから培地を敷いて種菌を入れる)、5月に水分の維持と汚染の点検 |
| 6-10月 | 6月に1回目の発生(梅雨前に収穫し、すぐ乾燥)。7月の高温期は遮光と水やりで菌糸を守る。8月に2回目の培地の追加(廃培地の一部を接種源に)。9-10月に2回目の発生(収穫量が最も多い時期)と大量乾燥 |
| 11-12月 | 廃培地を取り出して畑に入れ、わらと落ち葉を覆って越冬の準備。保存用の種菌と胞子紋の状態を点検 |

> **絶対に忘れないこと: 胞子が白色なら食べない、柄の根元を掘ってつぼがないか確認する、アオカビは速さと質感で見分ける、乾燥して貯蔵する、廃培地は畑へ回す。**
