## 引言
&nbsp;&nbsp;&nbsp;大球盖菇（Stropharia rugosoannulata）是评价对象的六种蘑菇中灾害应对得分最高的种类，综合S，54.4分（有效183种中第6位）。原因是它不需要灭菌。蘑菇种植通常垮在灭菌（用电或柴火）和无菌接种上，而这种蘑菇只要把木片或稻草铺在地上，撒上菌种，再盖一层就完成了。其热量按露地种植的实测值也有每㎡1,618kcal（自给线的0.62倍）。它不进行光合作用，所以日照减少时产量也能保持（光照SS）。弱点是鲜品耐储性E（15℃下4-6天就失去商品性）、国内种植普及度D，以及与致命毒蘑菇混淆。适合采收的幼嫩纽扣期与鹅膏类的幼菇相似，所以要读第7节，只采在自己搭的菌床上长出来的。

| 类别 | 内容 |

| 判定 | 综合S，54.4分（有效183种中第6位）。副食情景SS 66.0 |
| 优势 | SS：蛋白质密度、设施负担、光照、连作适应性、整地·挖掘能量、自留种。S：持续性、耐寒性、口味 |
| 劣势 | E：耐储性（鲜品）。D：国内种植普及度、种子寿命。C：微量营养素（满足11种）、病虫害压力、蘑菇副产物适应性 |

> **蘑菇是阳光消失的世界里产量也不会下降的唯一粮食来源，而大球盖菇是无需灭菌设备就能做到这一点的唯一品种。**

## 2. 蘑菇概述
&nbsp;&nbsp;&nbsp;属担子菌门伞菌纲伞菌目球盖菇科球盖菇属，是分解落叶和木质残渣的腐生菌。种加词rugosoannulata的意思是有皱纹的菌环。

| 特征 | 内容 |
|:---|:---|
| 菌盖 | 直径4-15cm（大的可达20cm以上）。从半球形展开为扁平。红褐色、紫褐色、葡萄酒色，干燥后变淡并开裂 |
| 菌褶 | 与菌柄完全相连，密集。由白色经灰紫色变为紫黑色 |
| 菌柄、菌环 | 棒状，基部粗，上部白色，下部黄色。菌环厚而硬，上面有深深的放射状沟，呈星形或锯齿状 |
| 基部、孢子 | 无菌托。白色菌丝束伸向培养料。孢子紫黑色至紫褐色 |

> **菌褶由白色变为紫黑色，菌环上面有星形沟，基部没有菌托。这三点就是大球盖菇的身份证。**

&nbsp;&nbsp;&nbsp;一粒孢子长不出蘑菇。孢子只有单核，初生菌丝长一阵就会死去，要由两条不同的菌丝相遇配对，才能形成粗壮的菌丝束，占领培养料并排挤杂菌。所以孢子不要一粒一粒地撒，而要把粉末足量地撒入。

| 阶段 | 期间与温度 | 要点 |
|:---|:---|:---|
| 菌丝蔓延 | 30-60天，5-35℃（最适26℃） | 白色菌丝束遍布整个培养料 |
| 覆土 | 蔓延之后 | 2-4cm的土或落叶 |
| 原基形成、生长 | 覆土后30-60天（12-20℃），接着7-14天（12-25℃） | 覆土下结出小米粒般的小球，膨大后菌盖展开 |

&nbsp;&nbsp;&nbsp;每100g含热量约25kcal、蛋白质2.40g（占热量的38.3%，按干物质计25.75-34.17%），钾按干物质计为3.58g/100g，是食用菌中最高的报告值。满足RDA 10%的营养素有11种（磷、铁、锌、锰、铜、钙、镁、硒等），鲜味非常强。

## 3. 培养料与处理
> **其他蘑菇要制作培养料并灭菌，而这种蘑菇只需把培养料铺在地上。在灾害情况下，这个差别决定成败。**

| 材料 | 特点 |
|:---|:---|
| 阔叶树木片 | 最推荐。连续数年出菇 |
| 稻草、麦秆、玉米秆 | 适合度高。稻草出菇快，但菌床寿命短；玉米秆养分多，产量高 |
| 稻壳、落叶、锯末、废培养料 | 中等。稻壳（透气）、落叶、锯末（太细就不透气）与木片混合使用；种过香菇或木耳后剩下的废培养料可直接使用。咖啡渣、豆荚作为氮源少量加入 |

| 木片 | 标准 |
|:---|:---|
| 树种 | 最适：枫树、柳树、杨树、榆树（质软、分解快，菌丝容易蔓延）。可用：栎类、桤木、樱树（出菇慢但持久）。禁用：针叶树（树脂和萜烯抑制菌丝）、核桃和胡桃楸（化感物质杀死菌丝） |
| 大小、新鲜度 | 指甲到拇指大小（太细就不透气，太大则菌丝跨不过去）。采伐后1年以内（长期堆放的木片上已有其他菌定居） |

| 处理 | 方法 | 耗时、抑制力 |
|:---|:---|:---|
| 浸水 | 把木片或稻草在水中浸泡24-48小时后捞出，沥水6-12小时（攥一把不滴水的程度，含水率65-80%，最适75%）。氧气被隔断，好氧杂菌变弱 | 24-48小时，低。露地木片菌床最常用 |
| 石灰浸泡 | 每100L水加熟石灰1-1.5kg（或生石灰0.5-1kg），pH 12-13。把切碎的稻草或木片浸泡12-24小时后沥水，不冲洗（残留的碱性继续抑制杂菌）。能破坏霉菌孢子，而蘑菇菌丝比较耐受 | 12-24小时，中等。以稻草为主材料或夏季 |
| 稻草发酵 | 把稻草淋湿堆成1-1.5m高，嗜热微生物发热，达到60-70℃。不要发酵太久 | 1-2周，中等。稻草多且有时间时 |
| 沸水、蒸汽 | 把稻草在沸水中煮1小时，或在200L铁桶（底部放水20-30cm，支架上放材料）中蒸2-4小时 | 1-4小时，高。耗燃料多。室内菌床、获得第一张菌床 |

&nbsp;&nbsp;&nbsp;菌床场地以半阴（100-500lux）为宜。蔬菜投下的阴影、树下、围墙北侧排水良好的平地或缓坡，不翻耕的固定花坛、果园之间、路边，既每天会经过、又能在给蔬菜浇水时一并浇水的地方最好。避开整天直射阳光的地方、完全黑暗的地方、积水的低洼地、每年翻耕的田地正中间。

## 4. 获取菌种
> **蘑菇没有种子，所以必须把菌种传下去。这种蘑菇一旦站稳脚跟，就能用铁锹挖取菌种。**

| 方法 | 内容 |
|:---|:---|
| 菌床分割（最简单） | 在白色菌丝束粗壮蔓延、没有杂菌痕迹的部分，用铁锹挖出约20cm见方的一块，分成拳头大小（弄得太碎会伤菌丝）。埋在新菌床木片层之间，间距30-40cm，充分浇水。一张菌床可做出3-5张新菌床。挖空的地方用新木片填上，很快恢复 |
| 组织培养（最可靠） | 用手而不是刀把新鲜蘑菇纵向撕开（刀会把表面的杂菌带到里面），把内部菌肉碎片夹进煮过放凉的稻草或湿木片之间，在22-26℃的暗处培养。3-5天长出白色菌丝 |
| 孢子印 | 把菌盖完全展开、菌褶染成紫黑色的大个体，菌褶朝下放在铝箔（纸会吸湿并藏杂菌）上扣住，会留下孢子粉。连铝箔在阴凉处再晾一天后密封，可保存5-10年以上（禁止用液体保存） |

&nbsp;&nbsp;&nbsp;优先顺序是菌床分割、组织培养、用孢子印做的稻草培养料（菌床丢失时）、市售菌种（能买到时提前备好）。稻草培养料的做法是把稻草在沸水中煮1小时以上，放凉后足量撒入孢子粉，在22-26℃的暗处培养2-4周，白色菌丝束盖满稻草就成功了。种子寿命D是以市售菌种（6个月至1年）为基准的，扎根的菌床能维持数年。

## 5. 接种、培养、出菇、采收
&nbsp;&nbsp;&nbsp;春季搭的菌床（末霜之后）当年初夏开始采收，秋季搭的菌床（初霜前2-3周为止）越冬后从次年春天开始采收。温带地区在4-10月进行，盛夏酷暑和严冬会超过30℃或结冰而难以定居，所以要避开。

| 搭菌床 | 内容 |
|:---|:---|
| 顺序 | 清除杂草和大块残渣露出光地（要直接接触地面），铺3-5cm湿木片或稻草，把菌种掰碎均匀撒上，3-5cm木片，菌种，最后一层5-10cm木片，2-3cm干叶或稻草、堆肥，充分浇水 |
| 规格 | 总厚15-20cm，菌种每㎡0.5-0.8kg，宽1-1.2m（更宽就够不到中间），菌床之间留40-60cm通道。菌种不足时，减少面积而不是减少层数 |
| 覆土 | 菌丝蔓延到整个培养料之后（搭床后30-60天），盖2-4cm田土、腐殖土、沙混合的土（或干叶和堆肥），不要太细，并充分浇湿。保持水分并诱导原基形成的必要条件 |

| 培养管理 | 标准 |
|:---|:---|
| 温度、水分 | 菌丝5-35℃（最适26℃）。40℃以上或培养料干燥会死亡。含水率65-80%（最适75%）。冬季零下也不会死，用稻草或落叶盖5-10cm |
| 水 | 搭好后立刻浇透到培养料内部。培养中表面干了就浇（每周1-2次，夏季3-4天一次，傍晚浇）。干旱时用稻草或落叶盖厚一些 |
| 正常生长 | 粗壮的白色丝或束把木片缠在一起，有接近泥土味的淡淡蘑菇香。一个月蔓延到培养料的一半以上（两个月还没蔓延就是水分或材料的问题）。像细霜一样，或有酸味、氨味，或呈绿色、橙色、黑色，就是污染。初期短暂长出灰色鬼伞类没关系 |

&nbsp;&nbsp;&nbsp;出菇信号有覆土（最强的信号）、降温（从培养的26℃降到出菇的12-20℃，由季节来完成）、把培养料浇透并把空气湿度提到85-95%的水分上升、100-500lux的弱光，以及下雨。雨后几天就成簇长出，所以在露地几乎没有需要另外做的事。子实体在12-25℃（最适12-20℃，16℃以下粗壮结实，24℃以上细而展开快）下生长，低于4℃难以形成。空气湿度出菇初期为85-95%，生长期为75-80%，过于干燥菌盖会开裂。初夏出菇最多；超过25℃的盛夏减少或停止，所以要增加遮阴和浇水；秋季再次大量出菇且品质最好，所以补充5-10cm新木片。

| 采收 | 标准 |
|:---|:---|
| 时期 | 菌盖即将从菌柄上完全展开之前（菌盖直径5-10cm，菌环还附着或刚脱落的纽扣期）。最结实、味道最好。菌盖变平、菌褶变深为紫黑色就晚了（口感、味道、耐储性都变差） |
| 要领 | 握住菌柄基部，边拧边连基部整个拔出 |
| 周期 | 首次采收在搭床后约90天（覆土后30-60天）。一次出菇7-14天，间隔12-25天，一季3-5次 |
| 菌床寿命、产量 | 秋季或早春盖5-10cm新木片，可延续数年。产量为中国露地全国平均每㎡6.47kg（随培养料配比为2.59-5.22kg），折合热量每㎡1,618kcal |

## 6. 污染、病虫害与异常诊断
&nbsp;&nbsp;&nbsp;灾害情况下种蘑菇失败最常见的原因不是病虫害，而是培养料被竞争霉菌（绿霉）抢走。绿霉在显出蓝绿色之前，也就是形成孢子之前就已经蔓延了，所以要靠速度和质地来判断。

| 类别 | 大球盖菇菌丝 | 绿霉 |
|:---|:---|:---|
| 颜色 | 白色，略带黄 | 起初白色，很快变蓝绿色 |
| 质地 | 粗的丝状线，略粗糙 | 像粉末一样细，如棉絮 |
| 速度、气味 | 每天3-8mm。森林泥土味、蘑菇香 | 每天10-30mm（快3-5倍）。发霉的霉味 |

| 情况 | 对策 |
|:---|:---|
| 斑点比手掌小 | 连周围的土一起多挖一些清除，并在该处撒木灰使其变碱性 |
| 蔓延到多处，或整体呈蓝绿色 | 放弃该区块，只保留菌丝占上风的部分移到别处。整体呈蓝绿色就全部废弃（烧掉，或埋在离种植地远的深处） |

> **不要把被污染的培养料回收成堆肥。绿霉孢子在堆肥堆里存活，第二年又会回到培养料里。**

&nbsp;&nbsp;&nbsp;这种蘑菇不对培养料完全灭菌，所以污染对策不是灭菌，而是让蘑菇在竞争中获胜。菌种要足量加入，占培养料重量的5-10%；用熟石灰或木灰把pH提到7.5-8.5（绿霉喜欢弱酸性）；不要加太多氮；不要把培养料压得太实；用肥皂洗手，刀和铁锹用火烧一下。害虫有菇蝇（啃食菌丝并传播绿霉孢子：粘虫板和水盆陷阱）、蛞蝓（撒一圈灰或锯末，夜里人工捉）、老鼠和鸟（罩网）。露地种植无法完全防住，但出菇量大，损失一部分仍有收成。

| 症状 | 原因与处理 |
|:---|:---|
| 菌丝不蔓延，或蔓延一阵就停 | 培养料太干，或过湿缺氧，温度低，养分耗尽，菌种死亡。浇水使含水率达到65-70%，确认地温，并在上面再铺新培养料 |
| 子实体小，只有菌柄变长 | 光不足，二氧化碳过多。揭开覆盖物，给光和通风 |
| 菌柄变软倒伏 | 过湿，细菌性软腐。停水通风，清除病菇 |

&nbsp;&nbsp;&nbsp;这种蘑菇最大的优点是不另占田地。放在玉米、高粱之间（采收后秸秆成为下一批培养料）、果树下、南瓜或黄瓜藤下、篱笆或围墙北侧等作物长不好的地方。出完菇的培养料是菌丝分解了木质的优质有机物，所以秋季翻进田里，或把菌丝还活着的块混入新培养料当菌种用。同一个地点从第2-3年起绿霉和害虫密度上升，所以第3年要把旧培养料全部清走送进田里，换地方搭床，原来的地方歇1-2年。

## 7. 误认毒蘑菇与安全确认
> **这一节直接关系到生命。比起种植，确认能不能吃更重要。**

&nbsp;&nbsp;&nbsp;即使是种出来的蘑菇，野生蘑菇也可能混在同一培养料里长出来。

| 部位 | 大球盖菇 |
|:---|:---|
| 菌盖、菌褶 | 起初半球形，后展开。直径5-15cm（大的30cm）。红褐色至葡萄酒色，干燥后变淡。菌褶由灰白色随生长变为紫褐色至紫黑色 |
| 菌柄 | 粗而硬。白色至淡黄色，长8-15cm。有菌环，是幼时覆盖菌盖的膜撕裂后留下的 |
| 基部、菌肉 | 没有菌托，附着像根一样的白色菌丝束。菌肉白色，切开或碰伤也不会变蓝 |

| 类别 | 大球盖菇 | 鹅膏类（致命） |
|:---|:---|:---|
| 孢子颜色 | 紫褐色至紫黑色 | 白色 |
| 菌褶颜色 | 随生长变为深紫褐色 | 始终白色 |
| 菌柄基部 | 无菌托 | 有膜质的菌托 |
| 菌盖颜色 | 红褐色至葡萄酒色 | 白色、黄色、绿色、灰色等 |
| 生长地点 | 稻草、木材副产物培养料 | 活树根附近的地面 |

> **孢子是白色就绝对不要吃（把菌盖倒扣在白纸上，罩上杯子放几个小时即可确认）。鳞柄白鹅膏（Amanita virosa）、白毒鹅膏（Amanita verna）这类致命毒蘑菇，孢子是白色，菌褶始终是白色，菌柄基部有菌托。这三点只要有一点符合就不要吃。**

&nbsp;&nbsp;&nbsp;确认菌托必须挖开来看。只看露出地面的部分，菌托埋在土里看不见。鳞伞类菌盖上有很多粗糙的鳞片，成簇生长，种类难以区分。同属球盖菇属中有含致幻成分的种类，所以切开后菌肉变蓝的不要吃。也不要与肠胃毒性强的黄枝瑚菌、粉褶菌类混淆。

&nbsp;&nbsp;&nbsp;第一次吃时，要取孢子印确认颜色（白色就扔掉），挖开菌柄基部确认没有菌托，充分煮熟（禁止生食），由一个人只吃少量（一小块）并等待24小时。没有异常再增加量，但不要多人同时吃，并把吃过的蘑菇留下一个个体（中毒时用于确认）。吃后30分钟至2小时内肚子疼，大多是胃肠刺激，而6-24小时后才开始呕吐腹泻，是破坏肝脏的鹅膏毒肽中毒的典型经过。开始得越晚越危重，症状暂时缓解、看似恢复的时期，肝脏也仍在被破坏。

## 8. 储存、烹调与全年日程
> **耐储性E是以鲜品为准的等级。干燥几乎不用燃料和设备，所以在灾害情况下，蘑菇的耐储性问题实际上靠干燥一项就能解决。**

| 储存 | 内容 |
|:---|:---|
| 晒干 | 把菌盖切成4-6mm，摊在帘子上。晴天2-3天。最简单，维生素D增加 |
| 阴干、火边 | 在通风好的屋檐下阴干通风4-7天（颜色和香味保留得好），整个穿线挂在屋檐下5-10天，灶台上的架子40-50℃烘一天（雨季用，注意别烤焦） |
| 保存、其他 | 在阴凉黑暗处1-2年，磨成粉可达2年以上。酱菜（焯水后用酱油和醋，3-6个月）、盐水乳酸发酵（3-6个月） |

&nbsp;&nbsp;&nbsp;切开晒干比整个晒干好（粗的菌柄里面不干，会发霉）。晒干的蘑菇开始碎裂时，不要扔掉，磨成粉。蘑菇粉体积小，能给汤增加鲜味，还可以混入面粉或荞麦粉面团（面疙瘩汤、手擀面），补充蛋白质和微量营养素。

&nbsp;&nbsp;&nbsp;不生吃。烤5-10分钟（菌柄粗，适合烤），汤或炖菜10-15分钟（汤里出鲜味），焯水10分钟（焯后凉拌），菌柄粗而硬，口感像肉。蘑菇不当作热量来源，而作为蛋白质和微量营养素（谷物补不上的氨基酸、维生素D、硒、铜）的补充来源。

| 月份 | 作业 |
|:---|:---|
| 1-5月 | 收集木片、稻草，检查菌种。3月稻草浸水并预发酵，4月第一次接种（确认地温在12℃以上，再铺培养料并放入菌种），5月保持水分并检查污染 |
| 6-10月 | 6月第一茬出菇（雨季前采收，立即晒干）。7月高温期用遮阴和浇水保护菌丝。8月追加第二批培养料（把部分废培养料作为接种源）。9-10月第二茬出菇（采收量最多的时期）与大量晒干 |
| 11-12月 | 把废培养料清出翻进田里，盖上稻草和落叶准备越冬。检查留作菌种的部分和孢子印的状态 |

> **绝对不要忘记：孢子是白色就不吃，挖开菌柄基部确认没有菌托，绿霉靠速度和质地来判断，靠干燥来储存，废培养料送回田里。**
