## 3. 培地材料と準備

&nbsp;&nbsp;&nbsp;サケツバタケの培地は、他の五種とは性格が異なります。袋に入れて滅菌する培地ではなく、地面の上に広げておく有機物層です。この違いが施設負担SSを生みます。瓶も袋も滅菌釜も必要なく、スコップと水桶と材料さえあれば十分です。

> **他のキノコは培地を作って滅菌しますが、このキノコは培地を地面に敷くだけです。災害の状況では、この違いが成功と失敗を分けます。**

### 3-1. 使用できる材料

| 材料 | 特徴 | 適合度 |
|---|---|:---:|
| 広葉樹の木材チップ | 最も推奨されます。数年間続けて生産できます | 非常に高い |
| 稲わら、麦わら | 単独でも可能で、発生が早いです。ただし菌床の寿命は短くなります | 高い |
| トウモロコシの茎 | 養分が多く、収量が高くなります | 高い |
| 籾殻 | 通気性が良く、他の材料と混ぜて使います | 中程度 |
| 落ち葉 | 手に入りやすいです。単独よりも木材チップと混ぜます | 中程度 |
| おがくず | 細かすぎると空気が通りません。チップと混ぜます | 中程度 |
| 廃培地 | シイタケやキクラゲを育てた後に残った培地をそのまま使います | 中程度 |
| コーヒー粕、豆の殻 | 窒素源として少量混ぜます | 補助的 |
| 竹の残材 | 細かく割れば使えます | 補助的 |

&nbsp;&nbsp;&nbsp;材料の幅がこれほど広いことは、災害の状況において決定的な利点です。ナラの木がなくても、おがくずがなくても、藁だけあればこのキノコは育ちます。ただし培地の種類によって収量差が最大3.9倍まで広がるため、可能であれば木材チップを主材料とし、藁を補助的に混ぜる組み合わせが良いでしょう。

### 3-2. 木材チップの選び方

| 項目 | 基準 | 理由 |
|---|---|---|
| 最適な樹種 | カエデ、ヤナギ、ポプラ、ニレ | 柔らかく分解が速いため菌糸がよく広がります |
| 使用可能な樹種 | ナラ、ハンノキ、サクラ | 硬いため発生が遅れますが長持ちします |
| 使用禁止の樹種 | マツ、チョウセンゴヨウなどの針葉樹 | 樹脂とテルペンが菌糸を抑制します |
| 使用禁止の樹種 | クルミ、オニグルミ | 他感物質（アレロパシー物質）が菌糸を死滅させます |
| チップの大きさ | 爪から親指ほどの大きさ | 細かすぎると空気が通らず、大きすぎると菌糸が渡れません |
| 鮮度 | 伐採から1年以内 | 長く積んでおいたチップにはすでに他の菌が定着しています |

&nbsp;&nbsp;&nbsp;新鮮なチップを選ぶという条件は、他のキノコとは正反対なので混同しやすいです。シイタケのおがくずは古いほど良いとされますが、サケツバタケはすでに他の菌が住んでいる古いチップでは勢力争いに負けます。外に積まれて白くカビが生えたチップの山は避けます。削ったばかりのチップが最も良く、それがなければ水で洗って表面の雑菌を減らしてから使います。

### 3-3. 電気を使わずに培地を処理する方法

&nbsp;&nbsp;&nbsp;サケツバタケは滅菌しなくても育ちます。しかし滅菌しないということは、何の処理もしないという意味ではありません。雑菌の数を減らしておくと成功率が目立って上がり、特に最初の菌床を立ち上げるときは、ある程度の処理をしておくほうが安全です。以下の四つの中から、状況に合ったものを選べばよいです。

#### 3-3-1. 水浸け - もっとも簡単な処理

| 項目 | 方法 |
|---|---|
| 方法 | 木材チップや藁を水桶や水たまりに24-48時間完全に浸します |
| 原理 | 酸素が断たれて好気性雑菌が弱まり、材料が十分に水を含みます |
| 排水 | すくい上げて6-12時間水を切ります。握ったときに水がしたたり落ちない程度まで |
| 含水率 | 65-80%、最適75% |
| 燃料 | かかりません |

&nbsp;&nbsp;&nbsp;サケツバタケの菌床を作るときに最も広く使われる処理です。火を一切使わず、水さえあればよく、材料が十分に濡れるという副次的な効果も大きいです。乾いた木材チップにそのまま種菌をまくと、菌糸は水がなく伸びることができません。

#### 3-3-2. 石灰浸け - 燃料なしで雑菌を減らす方法

| 項目 | 方法 |
|---|---|
| 配合 | 水100Lに消石灰1-1.5kg、または生石灰0.5-1kg |
| pH | 12-13。手に触れるとぬるぬるする強アルカリです |
| 浸漬 | 切った藁や木材チップを完全に沈めて12-24時間 |
| 排水 | すくい上げて6-12時間水を切ります |
| 接種 | すすぎません。残ったアルカリが雑菌を引き続き抑制します |

&nbsp;&nbsp;&nbsp;強アルカリはカビの胞子の細胞膜を破壊しますが、キノコの菌糸は比較的よく耐えます。しかもサケツバタケは酸性度をあまり気にしないため、アルカリが残った培地でもよく育ちます。燃料が全くかからないうえ、水浸けより確実です。石灰がなければ、草木灰を水に溶いて一日置き、上澄みだけをすくった灰汁で代用できますが、pHが低く、ばらつきも大きいため効果が安定しません。

#### 3-3-3. 稲わら発酵 - 藁を主材料に使うとき

&nbsp;&nbsp;&nbsp;藁を水で湿らせて高さ1-1.5mに積むと、好熱性微生物が自ら発熱し、堆積の中心部が60-70℃に達します。2-3日おきに切り返しながら1-2週間置くと、雑菌が食べやすい糖分が先に消費され、選択的な培地になります。滅菌ではなく、先に餌をなくす方式です。

&nbsp;&nbsp;&nbsp;サケツバタケの場合、発酵をあまり長くしません。マッシュルームは2-3週間の完全発酵を要求しますが、このキノコは1-2週間と短くするほうが良いです。発酵しすぎると菌糸が食べる養分まで減り、収量が落ちます。堆積内部の温度が60℃を超えた後、再び40℃台に下がったら、そこで広げて冷まします。

#### 3-3-4. 熱湯浸け、またはドラム缶蒸気

&nbsp;&nbsp;&nbsp;燃料に余裕があり、失敗を減らしたいなら、藁を沸騰した湯で1時間煮るか、200Lのドラム缶の底に水を20-30cm入れ、台の上に材料を積んで蒸気で2-4時間蒸します。他のキノコに比べて時間が短くても構いません。そもそも滅菌が必須ではないため、完全な滅菌を目標にしないからです。室内菌床栽培を行うとき、あるいは最初の菌床を必ず成功させたいときに、この方法を使います。

### 3-4. 処理法の比較

| 方法 | 燃料 | 所要時間 | 雑菌抑制 | 推奨される状況 |
|---|:---:|:---:|:---:|---|
| 水浸け | なし | 24-48時間 | 低い | 露地の木材チップ菌床。もっとも一般的です |
| 石灰浸け | なし | 12-24時間 | 中程度 | 藁を主材料にする場合、夏場の菌床作り |
| 稲わら発酵 | なし | 1-2週間 | 中程度 | 藁が多く、時間があるとき |
| 熱湯、蒸気 | 多い | 1-4時間 | 高い | 室内菌床、最初の菌床の確保 |

### 3-5. 菌床の場所選び

| 項目 | 良い条件 | 避けるべき条件 |
|---|---|---|
| 光 | 半日陰。100-500lux | 直射日光が一日中当たる場所 |
| 陰の出どころ | 野菜が作る陰、木の下、塀の北側 | 完全な暗闇 |
| 排水 | 水がたまらない平地やなだらかな傾斜地 | 雨の後に水がたまる低地 |
| 耕作 | 掘り返さない常設の花壇、果樹園の間、道端 | 毎年掘り返す畑の真ん中 |
| 近さ | 毎日通る場所 | 収穫期を逃しやすい辺鄙な場所 |
| 水 | 野菜に水をやるときに一緒にやれる場所 | 別に水を運ばなければならない場所 |

&nbsp;&nbsp;&nbsp;菜園の縁や畝の間が最も良い場所です。作物が作る陰が遮光の代わりになり、野菜に水をやるときに菌床も一緒に濡れ、毎日通るので収穫期を逃しません。そして11節で見るように、このキノコは隣にある作物に実際に役立ちます。

## 4. 種菌の確保

&nbsp;&nbsp;&nbsp;キノコには種がありません。種苗店が閉まれば種を買う場所がなく、種を採って甕に入れておく方法も通用しません。しかし菌類には、植物にはない三つの道があります。胞子を保存しておく道、生きているキノコの肉を切り取って育てる道、すでに定着した菌糸をそのまま移す道です。サケツバタケは特に三番目が簡単なため、自家採種SSを得ました。

### 4-1. 菌床の分割 - もっとも簡単で確実な方法

&nbsp;&nbsp;&nbsp;他のキノコの種菌継代が無菌操作やキノコを割る作業を要求するのに比べ、このキノコはスコップ一本で終わります。菌糸がよく広がった菌床の一部を取り出し、新しい場所の木材チップの間に埋めれば、それが種菌になります。

| 手順 | 方法 |
|---|---|
| 時期 | 春または秋。真夏と真冬は避けます |
| 対象 | 白い菌糸束が太く伸びていて、雑菌の跡がない部分 |
| 掘り出し | スコップで20cmほどの四角に掘り出します。菌糸が絡み合い、土の塊のように取れます |
| ÷ | 拳の大きさに分けます。細かく崩しすぎると菌糸が傷みます |
| 移植 | 新しい菌床の木材チップ層の間に30-40cm間隔で埋めます |
| 灌水 | たっぷりと湿らせます |
| 回収率 | 一つの菌床から新しい菌床3-5個を作ることができます |

&nbsp;&nbsp;&nbsp;掘り出した跡は新しい木材チップで埋めれば、元の菌床もすぐに回復します。春と秋ごとにこの作業を繰り返せば、菌床の数は指数関数的に増えていきます。滅菌も無菌操作も種菌店も必要ありません。これが災害の状況において、このキノコが持つもっとも実質的な力です。

> **サケツバタケが定着すれば、それ以降は種菌をスコップで掘って使うことができます。これより単純な種の確保方法は、他のキノコにはありません。**

### 4-2. 胞子の採取と胞子紋

&nbsp;&nbsp;&nbsp;菌床の分割が簡単だからといって、胞子の保存を省略してはいけません。菌床は洪水や干ばつ、凍害、雑菌の侵入によって一度に失われることがあります。胞子はそのときのための保険です。

| 手順 | 方法 |
|---|---|
| 対象選び | 傘が完全に開き、ひだが紫黒色に染まった大きな個体 |
| 柄を切る | 傘と柄が接する位置で柄を短く切り落とします |
| 台に置く | ひだを下に向けてアルミホイルの上に置きます |
| 覆う | 器をかぶせて風を防ぎます |
| 放置 | 涼しい場所に24時間 |
| 回収 | 傘を取り除くと、紫黒色の胞子の粉が傘の形のまま残ります |

&nbsp;&nbsp;&nbsp;このキノコの胞子は紫黒色です。白い胞子を出すシイタケやエノキタケとの決定的な違いであり、12節で見るように、テングタケ類と区別するもっとも確実な標識でもあります。胞子紋を作ることは、種の保存であると同時に安全確認でもあります。

&nbsp;&nbsp;&nbsp;紙よりアルミホイルのほうが良いです。紙は湿気を吸い込み、繊維の間に雑菌が隠れます。ホイルは水分を吸収せず表面が滑らかなため、胞子をそのまま保存できます。ホイルがなければガラス板が次の候補です。

&nbsp;&nbsp;&nbsp;胞子を採取した後は、ホイルのまま風が通る陰にもう一日置いて、わずかな湿気まで飛ばします。その後ホイルを半分に折って胞子の面を内側にして保護し、ジップ袋に入れます。よく炒った塩や炭のかけらを一緒に入れて湿気を取ります。ジップ袋を集めて瓶に入れ、蜜蝋で封をし、四季を通じて温度が一定な土窟や地下室に置きます。紫外線が胞子のDNAを破壊するため、光が入らないようにします。

| 保存形態 | 寿命 | 備考 |
|---|:---:|---|
| 胞子紋（ホイル乾燥） | 5-10年以上 | 水分が完全に排除され、細胞活動が停止します |
| 液体種菌（滅菌水懸濁） | 3-6か月 | 冷蔵がなければ早期発芽するか、細菌が増殖します |
| 接種済み種菌（穀粒・おがくず） | 6か月-1年 | 生きている菌糸のため、養分を使い続けます |
| 定着した菌床 | 数年 | 管理さえすれば事実上無限です |

> **災害の状況では、胞子を液体の状態で保管してはいけません。必ず乾燥させた胞子紋の形で保管してください。**

&nbsp;&nbsp;&nbsp;胞子と植物の種の寿命の違いは、その構造から来ています。トマトの種は胚と養分を抱えているため、時間が経つと自ら養分を消耗して老化し死にます。室温で2-4年です。キノコの胞子は厚い細胞壁に包まれた単一の細胞に過ぎないため、消耗する養分がありません。条件が合えば5-10年、学界では数十年経った胞子を復活させた例も珍しくありません。

| 比較項目 | トマトの種 | キノコの胞子 |
|---|---|---|
| 平均寿命（室温） | 約2-4年 | 約5-10年以上 |
| 脆弱要因 | 温度変化、自らの養分の枯渇 | 湿気によるカビ汚染 |
| 細胞構造 | 複雑な胚と養分 | 単一細胞と厚い保護壁 |

&nbsp;&nbsp;&nbsp;評価表の種子寿命Dは、市販種菌を基準にしたものです。胞子紋に切り替えておけば、そのDは実質的に意味を失います。災害の初年度に、もっとも大きく健康な個体で胞子紋を20-30枚作り、土窟に貯めておいてください。菌床をすべて失っても、5年後、10年後に再び始めることができます。

### 4-3. 胞子から種菌を作る - 稲わら加熱培地法

&nbsp;&nbsp;&nbsp;理論上、胞子を培地にまけば菌糸が伸びます。しかし現実には、空気中の青カビや細菌がキノコの胞子より数百倍速く培地を占領します。栄養価が高い培地であるほど、より脆弱です。電気がない状況では、栄養過多な人工培地の代わりに、自然の防御力を利用した原始的な培地を使います。

| 手順 | 方法 |
|---|---|
| 煮る | 稲わらや麦わらを沸騰した湯で1時間以上しっかり煮ます |
| 絞る | すくい上げて水気を絞り、手で触れる温度まで冷まします |
| まく | 保管しておいた胞子の粉を惜しまず、均一にたっぷりとまきます |
| 覆う | 清潔な布で覆い、風や落下してくる胞子を防ぎます |
| 培養 | 22-26℃の暗い場所で2-4週間。白い菌糸束が藁を覆えば成功です |

&nbsp;&nbsp;&nbsp;胞子を惜しんで一粒ずつ落とすと、一次菌糸だけが育って死滅します。異なる交配型が出会って二次菌糸になってはじめてキノコが出るため、数多くの胞子を一度にまとめて振り入れ、培地の中で自分たち同士で相手を見つけさせる必要があります。

### 4-4. 組織培養 - もっとも確実な方法

&nbsp;&nbsp;&nbsp;新鮮な生きたキノコが手元にあるなら、胞子を使う理由はほとんどありません。キノコの傘と柄が接する内側の白い肉は、すでに雌雄の結合が終わった二次菌糸の塊です。その断片を切り取って培地に入れれば、発芽と交配の過程を飛び越え、すぐに菌糸が四方に伸びます。

| 手順 | 方法 |
|---|---|
| 選ぶ | 傘が開き始めたばかりの新鮮な個体。古いものや虫に食われたものは使いません |
| 消毒 | 刃物を火で熱してから冷ますか、沸騰した湯に浸けてから取り出します |
| 割る | キノコを手で縦に割ります。刃物で切ると表面の雑菌が内部に入り込みます |
| 採取 | 傘と柄が接する内側の白い肉を米粒ほどの大きさに切り取ります |
| 接種 | 煮て冷ました稲わらや湿った木材チップの間に挟みます |
| 培養 | 22-26℃の暗い場所。3-5日で断片の周りに白い菌糸が広がります |

&nbsp;&nbsp;&nbsp;割ることが重要な理由は、キノコの内部がほぼ無菌であるためです。表皮とひだにはあらゆる胞子が付着していますが、肉の内部は清潔です。手で割ればその清潔な面が新たに露出し、そこから切り取った断片は消毒なしでも純粋な菌糸になります。柄の太い基部側の肉が特に効果的です。

### 4-5. 種菌確保の優先順位

| 順位 | 方法 | 条件 |
|:---:|---|---|
| 1 | 菌床の分割 | すでに定着した菌床があるとき |
| 2 | 組織培養 | 新鮮なキノコが手元にあるとき |
| 3 | 胞子紋から稲わら培地へ | 菌床を失い、貯めておいた胞子があるとき |
| 4 | 市販種菌 | 入手できるときに前もって確保 |
