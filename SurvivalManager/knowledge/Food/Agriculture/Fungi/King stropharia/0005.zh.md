## 9. 污染与病虫害
### 9-1. 绿霉菌是首要原因
&nbsp;&nbsp;&nbsp;灾难情况下食用菌栽培失败的最常见原因不是病虫害，而是**培养基被竞争性霉菌夺走**。其中压倒性多数是木霉（Trichoderma），俗称绿霉菌。

| 类别 | 大球盖菇菌丝 | 绿霉菌 |
|:---|:---|:---|
| 颜色 | 白色，略带黄色 | 起初白色，很快变成**青绿色** |
| 质感 | 粗而呈丝状，略显粗糙 | 细如粉末，像棉絮 |
| 蔓延速度 | 每天3-8mm | 每天10-30mm，**快3-5倍** |
| 气味 | 森林土壤气味，菌香 | 霉味刺鼻，有时带椰子味 |
| 边界 | 沿培养基均匀分布 | 从圆形斑点呈放射状扩散 |

> **绿霉菌在颜色显现之前就已经蔓延开来。**
> 青绿色是孢子形成的阶段，也就是**已经开始繁殖之后**。到那个时候，应视为已经失去了相当一部分培养基。早期判别应依据**蔓延速度和质感**，而不是颜色。

---
### 9-2. 发现污染时

| 情况 | 应对 |
|:---|:---|
| **斑点小于手掌** | 连同周围的土壤**大范围挖除**。在原处撒草木灰使其变为碱性 |
| **已蔓延到多处** | 放弃该区块。只保留菌丝占优势的部分，移到别处 |
| **整个培养基变成青绿色** | **全部废弃。**焚烧或埋在远离栽培地的地方 |

> **不要把受污染的培养基转为堆肥。**
> 绿霉菌孢子能在堆肥堆中存活，来年又会进入培养基。必须**焚烧，或深埋在与栽培地分开的地方。**

---
### 9-3. 防止污染的五种方法
&nbsp;&nbsp;&nbsp;大球盖菇是在不完全灭菌培养基的情况下栽培的菌类，因此防污染对策不是**"灭菌"，而是"让菌丝在竞争中取胜"**。

| 方法 | 原理 |
|:---|:---|
| **多接种菌种** | 占培养基重量的5-10%。先占据地盘的一方获胜 |
| **使培养基呈碱性** | 用熟石灰或草木灰把酸度调到7.5-8.5。绿霉菌喜欢弱酸性 |
| **不过量施氮** | 养分过多，竞争性霉菌会先爆发式生长 |
| **不要把培养基压得太实** | 要通气才能让菌丝正常延伸 |
| **清洗双手和工具** | 用肥皂洗手，刀和铁铲用火烤或用开水浸泡 |

---
### 9-4. 害虫

| 害虫 | 危害 | 应对 |
|:---|:---|:---|
| **蘑菇蚊（眼菌蚊）** | 啃食菌丝，子实体内出现蛆虫。还会传播绿霉菌孢子 | 在培养基表面薄撒一层草木灰。发生时用黄色粘虫板或水盆诱捕 |
| **螨虫** | 菌丝变褐色并停止生长 | 保持干燥管理，发生区块要隔离 |
| **蛞蝓** | 咬食幼小的子实体 | 用草木灰或木屑撒成一圈阻挡。夜间徒手捕捉 |
| **蜈蚣·蝽象** | 直接危害较小，但会扰乱菌丝层 | 不是大问题就放任不管 |
| **老鼠·鸟类** | 会叼走子实体 | 用网或带刺覆盖物遮挡 |

&nbsp;&nbsp;&nbsp;**由于是露地栽培，无法完全防止害虫。**大球盖菇出菇量大，即使损失一部分也仍有收获。在没有药剂的情况下，**接受一定损失并扩大种植面积**比把精力都投入防治更有效率。

---
## 10. 生长异常诊断

| 症状 | 原因 | 处理 |
|:---|:---|:---|
| 菌丝不生长 | 培养基太干，温度低，菌种已死 | 浇水使湿度保持在65-70%。检查地温 |
| 菌丝生长后停止 | 培养基养分耗尽，过湿导致缺氧 | 补铺新的培养基 |
| 菌丝良好但不出菇 | 刺激不足（温差·水分），培养基尚未充分成熟 | 浇冷水并揭开覆盖物，制造温差 |
| 子实体小而柄徒长 | 光照不足，二氧化碳过多 | 揭开覆盖物，增加光照和通风 |
| 菌盖开裂发干 | 空气过于干燥 | 向周围洒水提高湿度 |
| 菌柄软化倒伏 | 过湿，细菌性软腐 | 停止浇水并通风。清除病菇 |
| 颜色发浅、长势弱 | 高温，25℃以上 | 增加遮光并浇水以降低地温 |
| 出过一次后不再出菇 | 培养基养分耗尽 | 把废培养基还田，重新制作培养基 |

## 11. 与农田的关系：轮作与废培养基循环
### 11-1. 在作物之间栽培的菌类
&nbsp;&nbsp;&nbsp;大球盖菇最大的优点是**不需要另占农田**。玉米、向日葵等高大作物之间的阴影、果树下方、篱笆阴影处等**作物难以生长的半阴地**，对这种菌类来说是最理想的环境。

| 组合 | 效果 |
|:---|:---|
| **玉米·高粱之间** | 获得阴影和湿度，收获后的秸秆可作为下一批培养基 |
| **果树下方** | 全年半阴。废培养基能为果树根部提供养分 |
| **南瓜·黄瓜藤下** | 叶片形成阴影并保湿 |
| **篱笆·墙的北侧** | 可以利用作物无法生长的地方 |

> **这是这种菌类在评价表中位居前列的原因之一半。**
> 单位面积热量等级只是中等，但**由于这块面积可以和其他作物重叠使用，实际土地成本几乎为零。**

---
### 11-2. 废培养基不是用来丢弃的
&nbsp;&nbsp;&nbsp;出菇结束后的培养基是**菌丝已经把木质分解过的优质有机物**。比生稻草分解程度高得多，可以直接施入田里。

| 用途 | 方法 |
|:---|:---|
| **基肥** | 秋天铺在田里翻耕入土。提供的有机物和钾比氮更多 |
| **覆盖材料** | 在作物之间铺5cm厚，抑制杂草并防止水分蒸发 |
| **新培养基的接种源** | 把带有活菌丝的团块混入新培养基，可起到菌种的作用 |
| **堆肥促进剂** | 混入堆肥堆能加快分解 |
| **蚯蚓养殖基质** | 蚯蚓很爱吃，可以获得蚓粪土 |

```
稻草·木材副产物 → 培养基 → 采收菌类 → 废培养基 → 田间有机物
                                      └ 部分用作新培养基的接种源
```

&nbsp;&nbsp;&nbsp;把不能吃的稻草和木片转化为粮食，再把剩余的部分重新归还给地力，**这种循环正是在长期灾难状况中的优势所在。** 

---
### 11-3. 同一地点最多能用几年
&nbsp;&nbsp;&nbsp;如果在同一地点持续补铺培养基，从第2-3年开始绿霉菌和害虫密度会上升。

| 年份 | 管理 |
|:--:|:---|
| 1-2年 | 可以在同一地点继续补铺新培养基 |
| 3年 | 换地方更安全。旧培养基要全部清走还田 |
| 之后 | 迁走后让原来的地方休养1-2年 |

## 12. 毒菇误认与安全确认
> **本节直接关系到生命安全。确认能不能吃，比栽培本身更重要。**

---
### 12-1. 大球盖菇的鉴别特征
&nbsp;&nbsp;&nbsp;即便是自己栽培的菌类，野生菌也可能混杂长在同一培养基中。**不能仅凭长在培养基上这一点就认定它是安全的。**要逐一确认下面的特征。

| 部位 | 大球盖菇 |
|:---|:---|
| 菌盖 | 起初半球形，随后展开。直径5-15cm，大的可达30cm。**红褐色至酒红色**，干燥后颜色变浅 |
| 菌盖表面 | 光滑或带细微纤维状纹路。幼时可能附着白色膜状碎片 |
| **菌褶** | 起初灰白色 → **随生长逐渐变深为紫褐色至黑紫色** |
| **孢子颜色** | **紫褐色至黑紫色。**把菌盖放在白纸上收集孢子印即可立即确认 |
| 菌柄 | 粗壮坚实。白色至浅黄色。长8-15cm |
| **柄上的菌环** | **有。**幼时覆盖菌盖的膜破裂后残留在菌柄上 |
| **柄基部** | **没有菌托（袋状物）。**附着有如根须一般的白色菌丝束 |
| 菌肉 | 白色。切开或碰伤后**也不会变蓝** |
| 气味 | 菌香。没有令人不适的气味 |

---
### 12-2. 绝对不能混淆的对象——孢子颜色是分界点

| 类别 | 大球盖菇 | **鹅膏菌类（致命）** |
|:---|:---|:---|
| **孢子颜色** | **紫褐色至黑紫色** | **白色** |
| **菌褶颜色** | 随生长变为深紫褐色 | **始终为白色** |
| **柄基部** | 无菌托 | **有膜状菌托（袋状物）** |
| 菌盖颜色 | 红褐色至酒红色 | 白色、黄色、绿色、灰色等 |
| 生长场所 | 稻草·木材副产物培养基 | **活树根附近的地面** |

> **把菌盖倒扣在白纸上、罩上杯子放置数小时后，如果落下的粉末是白色，绝对不要食用。**
> 毒鹅膏、白毒鹅膏等致命毒菇的特征是**孢子为白色，菌褶也始终是白色，柄基部有菌托。**只要符合这三点中的任何一点，就不能食用。

&nbsp;&nbsp;&nbsp;**确认菌托必须把土挖开来看。**只看露出地面的部分，菌托会被土掩埋而看不见。请养成**把柄基部连土一起挖出来确认的习惯**。

---
### 12-3. 其他容易混淆的对象

| 菌类 | 区分点 |
|:---|:---|
| **黑鳞伞类** | 菌盖上有很多粗糙的鳞片，成群生长。毒性较弱，但种类区分困难 |
| **具有致幻性的部分球盖菇属种** | 同属中存在含致幻成分的种类。**切开菌肉后会变蓝**的品种不可食用 |
| **墨汁鬼伞类** | 菌盖随时间推移会变黑并溶化。与酒同食会中毒 |
| **黄枝瑚菌·粉褶菌** | 菌盖形状不规则·孢子白色。胃肠毒性强 |

---
### 12-4. 首次食用时的原则
&nbsp;&nbsp;&nbsp;在没有医疗支援的情况下，**确认程序本身就是一种防护手段**。

| 顺序 | 内容 |
|:--:|:---|
| 1 | **取孢子印确认颜色。**若为白色则丢弃 |
| 2 | **挖开柄基部，确认没有菌托** |
| 3 | **务必彻底煮熟。**不生食 |
| 4 | 第一次只让**一人**食用**少量（一小块）**，等待24小时 |
| 5 | 若无异常再增加食用量。不要多人同时食用 |
| 6 | **另外留存**一个吃过的菌类样本。中毒时可用于确认 |

> **6小时以上才出现症状的中毒最危险。**
> 食用后30分钟至2小时内腹痛，大多是肠胃刺激，但**6-24小时后开始呕吐、腹泻，是破坏肝脏的鹅膏毒肽中毒的典型病程**。发作越晚，病情越严重。此时会有一段症状暂时缓解的时期，看起来像是恢复了，但实际上肝脏正在持续受损。

## 13. 无冰箱贮藏
### 13-1. 生鲜状态撑不过三天
&nbsp;&nbsp;&nbsp;在评价表中，这种菌类的耐储性**按生鲜状态计为E级**。含水量在90%上下，常温下两天就会开始变软腐烂。

> **但是一旦晒干，等级就会完全不同。**
> 排除列表和耐储性等级都是**以"未加工的生鲜品"为标准**的。晒干几乎不需要燃料和设备，因此在灾难状况下，菌类的耐储性问题**实际上光靠干燥这一项就能解决。**

---
### 13-2. 干燥

| 方法 | 条件 | 时间 | 结果 |
|:---|:---|:--:|:---|
| **晒干** | 把菌盖切成4-6mm厚，摆在竹帘上晾晒 | 晴天2-3天 | 最简单，维生素D含量会增加 |
| **阴干风干** | 通风良好的屋檐下 | 4-7天 | 颜色和香气保留得好 |
| **穿线悬挂** | 整只用线穿起挂在屋檐下 | 5-10天 | 占用空间较少 |
| **火边烘干** | 灶台上方的架子，40-50度 | 一天 | 梅雨季可用。注意不要烤焦 |

| 阶段 | 判定 |
|:---|:---|
| 完全干燥 | **用手一折就会发出脆响并断裂。**若只是弯曲说明还没干透 |
| 保存 | 完全冷却后，**放入密闭容器，与木炭或炒过的盐一起存放** |
| 期限 | 在凉爽阴暗处可存**1-2年**。磨成粉后可以更久 |

&nbsp;&nbsp;&nbsp;**切开晾晒比整只晾晒更好。**菌柄太厚会导致内部未干透而生霉。这种菌类的柄尤其粗，因此**一定要剖开**再晾晒。

---
### 13-3. 其他贮藏方法

| 方法 | 制作方法 | 时间 |
|:---|:---|:--:|
| **盐渍** | 焯水沥干后，按重量的20%加盐层层码放 | 6个月-1年 |
| **酱菜** | 焯水后浸入酱油·醋中 | 3-6个月 |
| **菌粉** | 完全干燥后磨成粉 | 2年以上 |
| **发酵贮藏** | 浸入盐水中进行乳酸发酵 | 3-6个月 |

> **菌粉在灾难状况下尤其珍贵。**
> 体积小，能为汤汁增添鲜味，还可以掺入谷物粉中补充蛋白质和微量营养素。**干货一旦开始碎裂，磨成粉比丢弃更划算。**

## 14. 烹饪与加工
### 14-1. 必须煮熟食用
&nbsp;&nbsp;&nbsp;大球盖菇不可生食。生品中含有妨碍消化、刺激胃部的成分，而且最重要的是，**不煮熟就无法吸收细胞壁内的营养素。**

| 烹饪 | 燃料 | 时间 | 备注 |
|:---|:--:|:--:|:---|
| 烤 | 少 | 5-10分钟 | 也可以直接放在余烬上烤。菌柄粗，适合烤制 |
| 炒 | 少 | 5-8分钟 | 加一点油味道会大幅提升 |
| 汤·锅 | 中 | 10-15分钟 | 汤里会带出鲜味 |
| 煮 | 中 | 10分钟 | 焯水后可拌成凉拌菜 |

&nbsp;&nbsp;&nbsp;**菌柄粗壮结实，带来近似肉类的口感。**在蛋白质匮乏的情况下，**能带来咀嚼满足感的食材**这一点，也体现在评价表的口味项目中。

---
### 14-2. 干货的使用方法

| 顺序 | 方法 |
|:--:|:---|
| 1 | 用温水浸泡20-30分钟使其回软 |
| 2 | **泡发的水不要倒掉。**其中溶有鲜味和水溶性营养素 |
| 3 | 避开沉在底部的沙土，只取上层的水作汤底 |
| 4 | 泡发的菌类切开后炒食或放入汤中 |

---
### 14-3. 弥补谷物不足的搭配

| 搭配 | 效果 |
|:---|:---|
| **菌类+谷物粥** | 菌类蛋白质能补充谷物中缺乏的赖氨酸 |
| **菌粉+面粉·荞麦粉** | 混入面片汤、刀切面的面团中提升蛋白质含量 |
| **菌类+野菜** | 两者的微量营养素构成各不相同 |
| **菌类+油** | 有助于脂溶性成分的吸收 |

> **菌类不应作为热量来源，而应作为蛋白质和微量营养素的补充来源使用，这才是正确的用法。**
> 评价表中副食等级为SS正是这个意思。用谷物或薯类（块茎/块根）补充热量，再用菌类补充**谷物无法提供的氨基酸以及维生素D、硒、铜**。

## 15. 全年作业日程

| 月份 | 作业 |
|:--:|:---|
| 1-2月 | 收集原木·稻草。检查菌种。检查干菌状态 |
| **3月** | 开始制作培养基。稻草浸水·预发酵 |
| **4月** | **第一次接种。**确认地温12℃以上后铺培养基并接入菌种 |
| 5月 | 菌丝培养管理。保持水分，检查污染 |
| **6月** | **第一次出菇。**梅雨前采收，立即干燥 |
| 7月 | 高温期。用遮光和灌水保护菌丝。持续采收 |
| 8月 | 补充第二批培养基。部分废培养基用作接种源 |
| **9-10月** | **第二次出菇。**产量最多的时期，大量干燥 |
| 11月 | 清走废培养基还田。为越冬覆盖稻草·落叶 |
| 12月 | 检查留存的菌种。确认孢子印保存状态 |

### 绝对不要忘记

| 项目 | 内容 |
|:--:|:---|
| 1 | **孢子若为白色则不可食用。**大球盖菇的孢子是紫褐色至黑紫色 |
| 2 | **挖开柄基部确认没有菌托。**若有菌托则是鹅膏菌类 |
| 3 | **绿霉菌在颜色显现之前就已经蔓延开来。**要凭速度和质感来判别 |
| 4 | **晒干后耐储性问题就会消失。**不要被按生鲜标准评定的等级误导 |
| 5 | **由于不进行光合作用，是日照减少的灾难中唯一不受影响的稳定粮食来源** |
| 6 | **废培养基要还田。**把不能吃的稻草当作粮食和地力两次利用 |
