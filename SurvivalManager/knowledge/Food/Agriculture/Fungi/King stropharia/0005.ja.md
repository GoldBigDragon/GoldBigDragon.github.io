## 9. 汚染と病害虫
### 9-1. 青カビが第一の原因です
&nbsp;&nbsp;&nbsp;災害の状況でキノコ栽培が失敗するもっとも多い原因は、病害虫ではなく**競合するカビに培地を奪われること**です。そのうち圧倒的に多いのがトリコデルマ（Trichoderma）、俗にいう青カビです。

| 区分 | サケツバタケの菌糸 | 青カビ |
|:---|:---|:---|
| 色 | 白色、わずかに黄みがかる | 最初は白色、すぐに**青緑色** |
| 質感 | 太くて糸のような筋、やや粗い | 粉のように微細で綿のよう |
| 広がる速度 | 1日3-8mm | 1日10-30mm、**3-5倍速い** |
| 匂い | 森の土の匂い、キノコの香り | カビのかび臭さ、時にココナッツに似た香り |
| 広がり方 | 培地に沿って均一に | 円形の斑点から放射状に |

> **青カビは色が見える前にすでに広がっています。**
> 青緑色は胞子ができた段階、つまり**繁殖を始めた後**です。その時点ではすでに培地のかなりの部分を失ったと見なすべきです。初期の判別は色ではなく、**広がる速度と質感**で行います。

---
### 9-2. 汚染を発見したとき

| 状況 | 対処 |
|:---|:---|
| **斑点が手のひらより小さい** | 周囲の土まで**大きく掘って除去**します。その場所に草木灰をまいてアルカリ性にします |
| **複数箇所に広がった** | 該当区画を放棄します。菌糸が勝った部分だけを残し、別の場所へ移します |
| **培地全体が青緑色** | **全量を廃棄します。**燃やすか、栽培地から遠く離れた場所に埋めます |

> **汚染された培地を堆肥に回してはいけません。**
> 青カビの胞子は堆肥の山の中でも生き残り、翌年の培地に再び入り込みます。必ず**燃やすか、栽培地と離れた場所に深く埋めます。**

---
### 9-3. 汚染を防ぐ五つの方法
&nbsp;&nbsp;&nbsp;サケツバタケは培地を完全滅菌せずに育てるキノコであるため、汚染対策は**「滅菌」ではなく「競争に勝たせること」**です。

| 方法 | 原理 |
|:---|:---|
| **種菌を多く入れます** | 培地の重さの5-10%。先に場所を占めた側が勝ちます |
| **培地をアルカリ性にします** | 消石灰や草木灰でpHを7.5-8.5に上げます。青カビは弱酸性を好みます |
| **窒素を過剰に入れません** | 養分が多いと競合するカビが先に爆発的に増えます |
| **培地を強く押し固めません** | 空気が通ってこそ菌糸がきちんと伸びます |
| **手と道具を洗います** | 石けんで手を洗い、刃物やスコップは火で熱するか熱湯に浸します |

---
### 9-4. 害虫

| 害虫 | 被害 | 対処 |
|:---|:---|:---|
| **キノコバエ（シアリッド）** | 菌糸を食い荒らし、子実体にウジが入ります。青カビの胞子を運びます | 培地表面に草木灰を薄くまきます。発生時は黄色の粘着トラップや水皿トラップ |
| **ダニ** | 菌糸が褐色に変わり、成長しなくなります | 乾燥した状態で管理し、発生した区画は隔離します |
| **ナメクジ** | 幼い子実体を食いちぎります | 灰やおがくずの帯を巡らせて防ぎます。夜に手で捕まえます |
| **ムカデ・カメムシ** | 直接的な被害は少ないですが菌糸層を乱します | 大きな問題でなければそのままにします |
| **ネズミ・鳥** | 子実体をくわえて持ち去ります | 網や棘のある覆いをかぶせます |

&nbsp;&nbsp;&nbsp;**野外栽培であるため、害虫を完全に防ぐことはできません。**サケツバタケは発生量が多いため、一部を失っても収穫は残ります。薬剤がない状況では、**被害を受け入れて面積を広げるほう**が、防除に力を注ぐより効率的です。

---
## 10. 生育異常の診断

| 症状 | 原因 | 対処 |
|:---|:---|:---|
| 菌糸が伸びない | 培地が乾きすぎ、温度が低い、種菌が死んでいる | 水を与えて湿度65-70%に。地温を確認 |
| 菌糸が伸びて止まる | 培地の養分枯渇、過湿による酸素不足 | 新しい培地を追加で敷きます |
| 菌糸は良いがキノコが出ない | 刺激不足（温度差・水分）、培地の熟成不足 | 冷水を与え、覆いを取って温度差を作ります |
| 子実体が小さく柄だけ伸びる | 光不足、二酸化炭素過多 | 覆いを取って光と通気を与えます |
| 傘が裂けて乾く | 空気が乾燥しすぎている | 周囲に水を撒いて湿度を上げます |
| 柄が軟らかくなって倒れる | 過湿、細菌性の軟腐 | 水を止めて換気します。病気のものは取り除きます |
| 色が薄く元気がない | 高温。25℃以上 | 遮光を増やし、水を与えて地温を下げます |
| 一度発生した後、再び出ない | 培地の養分が尽きた | 廃培地を畑に戻し、新しい培地を作ります |

## 11. 畑との関係、輪作と廃培地の循環
### 11-1. 作物の間で育てるキノコ
&nbsp;&nbsp;&nbsp;サケツバタケの最大の長所は、**畑を別に使わない**という点です。トウモロコシやヒマワリのような背の高い作物の間の陰、果樹の下、垣根の陰のように**作物が育ちにくい半日陰**が、このキノコにとって最適です。

| 組み合わせ | 効果 |
|:---|:---|
| **トウモロコシ・モロコシの間** | 陰と湿度が得られ、収穫後の茎がそのまま次の培地になります |
| **果樹の下** | 一年中半日陰。廃培地が果樹の根に養分を与えます |
| **カボチャ・キュウリのつるの下** | 葉が陰と保湿を作ります |
| **垣根・塀の北側** | 作物が育たない場所を活用できます |

> **これが、評価表でこのキノコが上位に入る理由の半分です。**
> 面積当たり熱量の等級は中程度ですが、**その面積を他の作物と重ねて使えるため、実質的な土地コストがほとんどありません。**

---
### 11-2. 廃培地は捨てるものではありません
&nbsp;&nbsp;&nbsp;キノコが出尽くした後の培地は、**菌糸が木質を分解した良質な有機物**です。生の稲わらよりずっと分解が進んでいるため、畑にそのまま入れることができます。

| 用途 | 方法 |
|:---|:---|
| **元肥** | 秋に畑に広げてすき込みます。窒素よりも有機物・カリウムの供給が大きいです |
| **マルチング材** | 作物の間に5cmの厚さで敷き、雑草と水分の蒸発を防ぎます |
| **新培地の接種源** | 菌糸が生きている塊を新しい培地に混ぜると、種菌の役割を果たします |
| **堆肥促進剤** | 堆肥の山に混ぜると分解が速くなります |
| **ミミズ飼育基材** | ミミズがよく食べます。糞土を得ることができます |

```
稲わら・木材副産物 → 培地 → キノコ収穫 → 廃培地 → 畑の有機物
                                     └ 一部は新培地の接種源へ
```

&nbsp;&nbsp;&nbsp;食べられない稲わらや木の破片を食料に変え、残ったものを再び地力に戻す**この循環が、長期化する災害の状況における強みです。**

---
### 11-3. 同じ場所で何年まで
&nbsp;&nbsp;&nbsp;同じ場所に培地を継続して重ねていくと、2-3年目から青カビと害虫の密度が上がります。

| 年数 | 管理 |
|:--:|:---|
| 1-2年目 | 同じ場所に新しい培地を重ねても問題ありません |
| 3年目 | 場所を移すのが安全です。古い培地は全量を撤去して畑へ |
| それ以降 | 移した後、元の場所は1-2年休ませます |

## 12. 毒キノコとの誤認と安全確認
> **この節は命に直結します。育てることより、食べてよいかどうかを確認することのほうが重要です。**

---
### 12-1. サケツバタケの確認形質
&nbsp;&nbsp;&nbsp;自分で育てたキノコであっても、野生のキノコが同じ培地に混じって生えてくることがあります。**培地から出たという事実だけで安全だと見なしてはいけません。**以下の形質を一つずつ確認します。

| 部位 | サケツバタケ |
|:---|:---|
| 傘 | 最初は半球形で、開いていきます。直径5-15cm、大きいものは30cm。**赤褐色-ワイン色**、乾くと薄くなります |
| 傘の表面 | 滑らかまたは微細な繊維状の模様。幼いときは白い膜の切れ端が付いていることがあります |
| **ひだ** | 最初は灰白色 → **成長するにつれ紫褐色-黒紫色に濃くなる** |
| **胞子の色** | **紫褐色-黒紫色。**白い紙に傘を乗せて受ければすぐに確認できます |
| 柄 | 太くて硬い。白色-薄黄色。長さ8-15cm |
| **柄のつば** | **あります。**幼いときに傘を覆っていた膜が破れて柄に残ります |
| **柄の基部** | **つぼがありません。**根のように白い菌糸の束が付いています |
| 肉 | 白色。切ったり傷んだりしても**青く変色しません** |
| 匂い | キノコの香り。不快な匂いはありません |

---
### 12-2. 絶対に混同してはいけないもの - 胞子の色が分かれ道です

| 区分 | サケツバタケ | **テングタケ類（致死性）** |
|:---|:---|:---|
| **胞子の色** | **紫褐色-黒紫色** | **白色** |
| **ひだの色** | 成長すると濃い紫褐色に | **最後まで白色** |
| **柄の基部** | つぼなし | **膜状のつぼがある** |
| 傘の色 | 赤褐色-ワイン色 | 白色・黄色・緑色・灰色など |
| 発生場所 | 稲わら・木材副産物の培地 | **生きた木の根の近くの地面** |

> **白い紙に傘を伏せて置き、コップをかぶせて数時間置いたとき、落ちた粉が白ければ絶対に食べてはいけません。**
> ドクツルタケ・シロタマゴテングタケのような致死性の毒キノコは、**胞子が白色で、ひだも最後まで白色であり、柄の基部につぼがあります。**この三つのうち一つでも当てはまれば食べません。

&nbsp;&nbsp;&nbsp;**つぼの確認は必ず掘って行わなければなりません。**地上に出た部分だけを見ると、つぼは土に埋まっていて見えません。**基部を土ごと掘り出して確認する習慣**をつけてください。

---
### 12-3. その他の混同対象

| キノコ | 区別点 |
|:---|:---|
| **黒い鱗のあるキノコ類** | 傘に粗いうろこが多く、群生します。毒性は弱いですが種の区別が難しいです |
| **幻覚性のあるモエギタケ属の一部** | 同じ属に幻覚成分を持つ種があります。**肉を切ると青く変色する**ものは食べません |
| **ヒトヨタケ類** | 傘が時間が経つと黒く溶けていきます。酒と一緒に食べると中毒します |
| **キホウキタケ・イッポンシメジ** | 枝分かれ状の傘・白い胞子。胃腸への毒性が強いです |

---
### 12-4. 初めて食べるときの原則
&nbsp;&nbsp;&nbsp;医療支援がない状況では、**確認の手順そのものが防御手段**です。

| 手順 | 内容 |
|:--:|:---|
| 1 | **胞子紋を採って色を確認します。**白色であれば処分します |
| 2 | **柄の基部を掘ってつぼがないか確認します** |
| 3 | **必ず十分に加熱します。**生食はしません |
| 4 | 最初は**一人だけ、少量（一切れ）**食べて24時間待ちます |
| 5 | 異常がなければ量を増やします。複数人で同時に食べません |
| 6 | 食べたキノコの個体を一つ**別に残しておきます。**中毒したときの確認に使えます |

> **症状が6時間以上経ってから現れる中毒がもっとも危険です。**
> 食べて30分-2時間以内に腹が痛くなるのは、たいてい胃腸の刺激ですが、**6-24時間後に嘔吐・下痢が始まるのは、肝臓を破壊するアマトキシン中毒の典型的な経過**です。始まりが遅いほど重症です。このとき、症状が一時的に治まる時期があり回復したように見えますが、実際には肝臓が壊れ続けています。

## 13. 冷蔵庫なしの貯蔵
### 13-1. 生のままでは三日も持ちません
&nbsp;&nbsp;&nbsp;評価表では、このキノコの貯蔵性は**生の状態でE**です。水分が90%前後あるため、常温で二日もすれば軟らかくなり始めます。

> **しかし乾燥させれば等級はまったく変わります。**
> 除外リストと貯蔵性の等級は**「加工していない生の状態」を基準**にしています。乾燥はほとんど燃料も設備も使わないため、災害の状況ではキノコの貯蔵性の問題は**事実上、乾燥一つで解決します。**

---
### 13-2. 乾燥

| 方法 | 条件 | 期間 | 結果 |
|:---|:---|:--:|:---|
| **天日干し** | 傘を4-6mmに切ってすのこに広げる | 晴天2-3日 | もっとも簡単で、ビタミンDが増えます |
| **陰干し** | 風通しの良い軒下 | 4-7日 | 色と香りがよく残ります |
| **糸に通して吊るす** | そのまま糸に通して軒に吊るす | 5-10日 | 場所を取りません |
| **火のそばで乾燥** | かまどの上の棚、40-50度 | 1日 | 梅雨時に使えます。焦がさないように |

| 段階 | 判定 |
|:---|:---|
| 完全乾燥 | **手で折るとパキッと音がして折れます。**曲がるならまだ乾燥不足です |
| 保管 | 完全に冷ました後、**密閉容器に炭や炒り塩と一緒に** |
| 期間 | 涼しく暗い場所で**1-2年**。粉に挽けばさらに長く |

&nbsp;&nbsp;&nbsp;**切って乾かすほうが、丸ごとよりも良いです。**太い柄は中まで乾きにくく、カビが生えます。特にこのキノコは柄が太いため、**必ず割って**乾かします。

---
### 13-3. その他の貯蔵方法

| 方法 | 作り方 | 期間 |
|:---|:---|:--:|
| **塩漬け** | 湯通ししてから水気を切り、重さの20%の塩を層にして入れる | 6か月-1年 |
| **醤油漬け** | 湯通ししてから醤油・酢に漬ける | 3-6か月 |
| **キノコ粉** | 完全に乾燥させた後、挽いて粉にする | 2年以上 |
| **発酵貯蔵** | 塩水に浸けて乳酸発酵させる | 3-6か月 |

> **キノコ粉は災害の状況において特に価値があります。**
> かさが小さく、汁物に旨味を与え、穀物の粉に混ぜてタンパク質と微量栄養素を加えることができます。**乾燥品が崩れ始めたら、捨てるより粉にするほうが良いです。**

## 14. 調理と加工
### 14-1. 必ず加熱して食べます
&nbsp;&nbsp;&nbsp;サケツバタケは生食しません。生の状態には消化を妨げ胃を刺激する成分があり、何より**加熱しなければ細胞壁の中の栄養素を吸収できません。**

| 調理法 | 燃料 | 時間 | 備考 |
|:---|:--:|:--:|:---|
| 焼く | 少ない | 5-10分 | 灰の残り火に乗せてもよいです。柄が太いため焼き物に適します |
| 炒める | 少ない | 5-8分 | 油が少しあると味が大きく上がります |
| スープ・鍋 | 中程度 | 10-15分 | 汁に旨味が出ます |
| 茹でる | 中程度 | 10分 | 湯通ししてナムルにして和えます |

&nbsp;&nbsp;&nbsp;**柄が太くて硬く、肉のような食感があります。**タンパク質が不足する状況で**噛む満足感を与える食材**であるという点は、評価表の味の項目に反映されています。

---
### 14-2. 乾燥品の使い方

| 手順 | 方法 |
|:--:|:---|
| 1 | ぬるま湯に20-30分浸してふやかします |
| 2 | **戻し汁は捨てません。**旨味と水溶性の栄養素が溶け込んでいます |
| 3 | 底に沈んだ砂を避け、上澄みだけを汁として使います |
| 4 | ふやかしたキノコは切って炒めるか、汁物に入れます |

---
### 14-3. 穀物不足を補う組み合わせ

| 組み合わせ | 効果 |
|:---|:---|
| **キノコ+穀物のお粥** | 穀物に不足するリジンを、キノコのタンパク質が補います |
| **キノコ粉+小麦粉・そば粉** | スジェビ（韓国式ちぎり麺のすいとん）やカルグクス（韓国式手打ち麺）の生地に混ぜてタンパク質を上げます |
| **キノコ+ナムル** | 微量栄養素の構成がそれぞれ異なります |
| **キノコ+油** | 脂溶性成分の吸収が良くなります |

> **キノコは熱量源としてではなく、タンパク質と微量栄養素の補充源として使うのが正しいです。**
> 評価表の副食等級がSSであるのはこの意味です。穀物やいも類（塊茎・塊根）で熱量を満たし、キノコで**穀物では満たせないアミノ酸とビタミンD、セレン、銅**を補います。

## 15. 年間作業スケジュール

| 月 | 作業 |
|:--:|:---|
| 1-2月 | 原木・稲わらの収集。種菌の点検。乾燥キノコの状態確認 |
| **3月** | 培地作りを開始。稲わらの浸水・予備発酵 |
| **4月** | **1回目の接種。**地温12℃以上を確認後、培地を敷いて種菌を入れます |
| 5月 | 菌糸培養管理。水分維持、汚染点検 |
| **6月** | **1回目の発生。**韓国の梅雨（チャンマ、6月下旬～7月）前に収穫。すぐに乾燥 |
| 7月 | 高温期。遮光と灌水で菌糸を保護。収穫を続けます |
| 8月 | 2回目の培地を追加。廃培地の一部を接種源として活用 |
| **9-10月** | **2回目の発生。**もっとも収穫量が多い時期。大量に乾燥 |
| 11月 | 廃培地を撤去して畑に入れます。越冬準備として藁・落ち葉を覆います |
| 12月 | 保存している種菌の点検。胞子紋の保管状態確認 |

### 絶対に忘れてはいけないこと

| 項目 | 内容 |
|:--:|:---|
| 1 | **胞子が白色であれば食べません。**サケツバタケの胞子は紫褐色-黒紫色です |
| 2 | **柄の基部を掘ってつぼがないか確認します。**つぼがあればテングタケ類です |
