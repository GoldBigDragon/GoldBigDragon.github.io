## 5. 接种方法

&nbsp;&nbsp;&nbsp;大球盖菇的接种是一层层堆叠的工作。因为培养基和菌种交替铺叠，所以也被称为"菌菇千层面"。原理很简单：把菌种分散铺在多个层中，让菌丝从上下同时延伸，从而抢先杂菌占据培养基。

### 5-1. 时期

| 项目 | 标准 | 备注 |
|---|---|---|
| 春季建床 | 最后一次霜冻过后 | 当年初夏开始收获 |
| 秋季建床 | 在初霜前2-3周内完成 | 越冬后从次年春季开始收获 |
| 温带标准 | 4月至10月之间 | 必须留出菌丝生长的时间 |
| 应避开的时期 | 盛夏酷暑、严冬 | 超过30度或结冰都难以成功定植 |

&nbsp;&nbsp;&nbsp;秋季建床尤其有利。在霜冻前完成建床，冬季菌丝会慢慢蔓延，等到次年春季气温上升时，已经处于占据整个培养基的状态。评价表中耐寒性S以及可以形成秋种冬收栽培模式的记录，正是由此而来。

### 5-2. 菌床堆叠

| 步骤 | 内容 | 厚度 |
|---|---|:---:|
| 1 | 平整地面，清除杂草和大块残余物，露出裸土 | - |
| 2 | 铺上湿木片或稻草 | 3-5cm |
| 3 | 把菌种捏碎后均匀撒上 | - |
| 4 | 再铺一层木片 | 3-5cm |
| 5 | 再撒一层菌种 | - |
| 6 | 铺最后一层木片 | 5-10cm |
| 7 | 用干叶、稻草或堆肥覆盖 | 2-3cm |
| 8 | 充分浇水 | - |

| 项目 | 标准 |
|---|---|
| 总厚度 | 15-20cm |
| 菌种用量 | 每㎡ 0.5-0.8kg |
| 菌床宽度 | 1-1.2m，再宽就无法照料中央部分 |
| 菌床长度 | 无限制 |
| 菌床间距 | 留出40-60cm的通道 |

&nbsp;&nbsp;&nbsp;总厚度很重要。薄于15cm会很快变干并在冬季结冰，厚于25cm则空气无法到达内部，菌丝还没蔓延完就会陷入缺氧状态。15-20cm是折中的厚度。

&nbsp;&nbsp;&nbsp;让培养基直接接触裸土也很重要。铺塑料膜或木板会让菌丝无法接触到土壤中的水分和微生物。大球盖菇在土壤与木质层的交界处长得最好，会吸收利用土壤中的矿物质。

### 5-3. 节省菌种时

&nbsp;&nbsp;&nbsp;菌种不足时，不要减少层数，而应该缩小面积。每㎡低于0.5kg会导致定植变慢，鬼伞类会趁机先占据地盘。用1kg菌种勉强做出2㎡菌床，不如踏踏实实做出1.5㎡。而且只要有一个菌床成功定植，来年春天就可以铲取分株，扩大到三倍面积。

&nbsp;&nbsp;&nbsp;点状接种也是可行的。铺好木片层后，把拳头大小的菌种块按30-40cm的间距呈棋盘状埋入。这种方式比撒播定植慢，但在菌种不足时可以使用。用菌床分割法移植的菌丝团块，也是用这种方式栽种。

### 5-4. 覆土

| 项目 | 标准 |
|---|---|
| 时期 | 菌丝蔓延到整个培养基之后，建床后30-60天 |
| 材料 | 田土、腐叶土、沙子的混合物，或干叶与堆肥 |
| 厚度 | 2-4cm |
| 水分 | 覆土后充分浇透 |
| 目的 | 保持水分并诱导原基形成 |

&nbsp;&nbsp;&nbsp;覆土是这种菌菇出菇的必要条件。菌丝在木质层中获取养分，子实体则在覆土层与木质层的交界处形成。没有覆土的话，菌丝往往会在培养基表面形成一层白膜却不出菇。露地菌床只需覆盖干落叶和堆肥就足够，室内菌床则要另外准备土壤。

&nbsp;&nbsp;&nbsp;覆土不能太细。如果只覆盖细土，浇水后会结成硬板，幼菇顶不出来。要混入沙子或粗腐叶土，使其保持松散。

## 6. 菌丝培养管理

&nbsp;&nbsp;&nbsp;建床后30-60天是培养期。这一时期的目标是让白色菌丝束占据整个培养基。人要做的事只是保持水分不干、不要踩踏、拔除杂草而已。

### 6-1. 温度与水分

| 项目 | 范围 | 备注 |
|---|:---:|---|
| 菌丝生长温度 | 5-35℃ | 幅度非常宽 |
| 最适温度 | 26℃ | 在此附近生长最快 |
| 培养基含水率 | 65-80%，最适75% | 以握紧时指间微微渗水为宜 |
| 危险条件 | 40℃以上、培养基干燥 | 菌丝会死亡 |
| 冬季 | 零下也不会死亡 | 用稻草或落叶覆盖5-10cm |

&nbsp;&nbsp;&nbsp;菌丝生长温度幅度达到5-35℃，这在栽培菌菇中属于非常宽的一类。这意味着几乎不需要费力去调节温度，而在没有电力的情况下，这一点直接关系到成功率。这与金针菇需要精密制冷正好相反。

### 6-2. 水分管理

| 时期 | 管理 |
|---|---|
| 建床后 | 充分浇透，必须湿透培养基内部 |
| 培养期间 | 表面变干时浇水，通常每周1-2次 |
| 夏季 | 每3-4天一次，在日落时浇水 |
| 干旱时 | 用稻草或落叶厚厚覆盖以防止蒸发 |
| 若在菜园旁 | 给蔬菜浇水时一起浇即可 |

&nbsp;&nbsp;&nbsp;浇水时不要只弄湿表面，要缓慢长时间地浇，让水渗入培养基内部。用力猛浇会使水沿木片间隙流走，真正有菌丝的那一层反而依然干燥。用洒水壶分多次浇，或者在菌床上盖一层稻草再往上浇水，能让水分均匀渗透。

### 6-3. 判断菌丝是否正常生长的方法

| 观察项 | 正常 | 异常 |
|---|---|---|
| 菌丝形态 | 粗壮的白色线或绳状物缠绕木片 | 若像细霜，可能是其他杂菌 |
| 气味 | 类似土壤气味的淡淡菌香 | 酸味或氨味属于异常 |
| 木片状态 | 用手拿起时会被菌丝缠住整块带起 | 若一片片散开，说明尚未蔓延 |
| 蔓延速度 | 一个月内应超过培养基一半 | 两个月仍未蔓延，可能是水分或材料问题 |
| 颜色 | 保持白色 | 绿色、橙色、黑色为污染 |
| 表面状况 | 短暂长出灰色小蘑菇没有关系 | 若鬼伞持续出现，说明培养基尚未充分熟化 |

&nbsp;&nbsp;&nbsp;建床初期常常会长出鬼伞类。这不是失败。鬼伞是一种先锋菌，会先快速消耗容易利用的养分然后消失，等它过去之后，大球盖菇就会定植下来。看到就拔掉，但不必放弃整个菌床。不过，如果过了两三个月还一直只长鬼伞，那就说明菌种定植失败了。

## 7. 诱导出菇

&nbsp;&nbsp;&nbsp;菌丝在舒适的环境下只会不断延伸。让菌菇结实，对菌丝来说是一种危机信号。对大球盖菇而言，这个信号是温度下降、覆土，以及水分。不需要像香菇那样浸水或敲击。

### 7-1. 适合这种菌菇的刺激

| 刺激 | 方法 | 效果 |
|---|---|---|
| 覆土 | 菌丝蔓延后覆盖2-4cm | 是最强的信号 |
| 温度下降 | 从培养期的26℃降到出菇期的12-20℃ | 由季节自然完成 |
| 湿度提升 | 充分浇湿培养基，将空气湿度提升到85-95% | 促使原基形成 |
| 光照 | 100-500lux的微弱光照 | 起到信号作用 |
| 降水 | 降雨后数天内会成群出菇 | 是自然给予的最好刺激 |

&nbsp;&nbsp;&nbsp;在露地栽培中，几乎不需要人为额外施加这种刺激。夏天过去、气温下降、秋雨降下，菌菇自然就会长出来。春天也是如此。人要做的只是不让培养基变干。这是最省事的出菇方式，也正是设施负担SS的实际内容。

### 7-2. 出菇条件

| 项目 | 条件 | 备注 |
|---|---|---|
| 子实体生长温度 | 12-25℃ | 幅度13℃ |
| 最适出菇温度 | 12-20℃ | 16℃以下会长得粗壮结实，24℃以上则细弱且展开快 |
| 下限 | 4℃以下 | 难以形成子实体 |
| 空气湿度 | 出菇初期85-95%，生长期75-80% | 低于85%菌盖会开裂 |
| 培养基含水率 | 65-80% | |
| 光照强度 | 100-500lux | 半阴环境即可 |
| 通风 | 露地不成问题 | 室内则需要排出二氧化碳 |

&nbsp;&nbsp;&nbsp;出菇温度不同，菌菇的形态也会不同。凉爽时长出的菌盖厚、菌柄粗，重量大，耐储性也更好。炎热时长出的生长快、展开快，质地轻、容易变质。这就是春秋两季收获比夏季收获更好的原因。

### 7-3. 各季节出菇情况

| 季节 | 出菇状态 | 管理 |
|---|---|---|
| 春季 | 解冻后气温超过12℃即开始出菇 | 撤去冬季覆盖的稻草，引入光照 |
| 初夏 | 出菇量最大 | 集中做好水分管理 |
| 盛夏 | 超过25℃出菇减少或停止 | 增加遮光并勤浇水 |
| 秋季 | 再次大量出菇，品质最好 | 补充5-10cm新鲜木片 |
| 初冬 | 4℃以上会持续出菇 | 覆盖稻草，但要留出出菇的位置 |
| 深冬 | 停止出菇，但菌丝仍存活 | 用稻草或落叶覆盖5-10cm以防冻害 |

## 8. 收获与再出菇周期

### 8-1. 判断采收时机

| 标准 | 内容 |
|---|---|
| 最佳时机 | 菌盖即将从菌柄完全展开之前，菌环仍附着或刚脱落时 |
| 大小 | 菌盖直径5-10cm |
| 口感 | 此阶段最紧实、味道最好 |
| 过晚的信号 | 菌盖变平、菌褶变为深紫黑色即为过晚 |
| 采收时段 | 清晨 |

&nbsp;&nbsp;&nbsp;个体过大会导致口感和味道下降，耐储性也变差。直径超过15cm后肉质会变得疏松、水分增多。趁小勤采，总收获量更高，品质也更好。

> **最佳采收期的纽扣状阶段，也正是外观与致命鹅膏菌幼菇最相似的时期。必须阅读第12节，并且只采摘自己所建菌床上长出的菌菇。**

### 8-2. 采摘要领

&nbsp;&nbsp;&nbsp;抓住菌柄基部，边扭边拔出。比起切断，拔出更好，因为留下的柄基会腐烂并招来细菌和菌蚊。拔出后留下的坑要用木片填平。

&nbsp;&nbsp;&nbsp;而且采摘时始终要把基部整个一起拔出来。正如第12节所述，菌托的有无只能在基部确认，而这个确认关乎生死。这是必须养成的习惯动作。

### 8-3. 出菇周期

| 项目 | 内容 |
|---|---|
| 首次收获 | 建床后90天左右，覆土后30-60天 |
| 单次出菇期 | 7-14天 |
| 出菇间隔 | 12-25天 |
| 单个栽培期出菇次数 | 3-5次 |
| 菌床寿命 | 若管理得当，可跨多个季节持续数年 |

&nbsp;&nbsp;&nbsp;出菇一次后休息2-3周再次出菇，是这种菌菇的节律。休息期间要做的只是保持水分不干，不必特意再给予刺激。

### 8-4. 菌床更新

| 时期 | 作业 | 厚度 |
|---|---|:---:|
| 秋季或早春 | 在菌床上覆盖新鲜木片 | 5-10cm |
| 同时 | 修补边缘塌陷处 | - |
| 每2-3年 | 铲取部分菌床移到新场地 | - |

&nbsp;&nbsp;&nbsp;每年覆盖新鲜木片，菌床实际上就能无限延续下去。下层完全分解成腐叶土，菌丝则移向上面的新层。在这个过程中，下层堆积的腐叶土直接成为田地的肥料，也就是说，在收获菌菇的同时，土壤也在同步形成。

### 8-5. 产量

| 条件 | 产量 |
|---|---|
| 中国露地栽培全国平均 | 每㎡ 6.47kg |
| 因培养基配方产生的变化 | 每㎡ 2.59-5.22kg，最大差异达101.5% |
| 不同培养基种类间的差异 | 约3.9倍 |
| 折算热量 | 每㎡ 1,618kcal，为自给线的0.62倍 |

&nbsp;&nbsp;&nbsp;产量差异之大值得记住。同样的菌菇，仅因培养基不同就能相差近四倍。以木片为主、适当混入稻草和氮源的培养基效果最好；纯用稻草制作的培养基出菇快，但总产量较低。多试几种配比，找出适合自己土地和材料的组合，几年后会让收获量出现很大改变。

> **每㎡ 1,618kcal，作为菌菇而言是一个异乎寻常的数值。计算下来，仅用30㎡、不到十坪的菌床，就能提供一个人一天所需热量的相当大一部分。**
