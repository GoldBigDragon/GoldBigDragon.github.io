## 3. 培养基材料与准备

&nbsp;&nbsp;&nbsp;大球盖菇的培养基与其他五种性质不同。它不是装进袋子里灭菌的培养基，而是铺在地面上的一层有机物。正是这种差异造就了设施负担SS。不需要瓶子、袋子、灭菌锅，只要有铁铲、水桶和材料就够了。

> **其他菌菇要制作培养基并灭菌，这种菌菇只需把培养基铺在地上。在灾害情况下，这个差异决定了成败。**

### 3-1. 可使用的材料

| 材料 | 特点 | 适合度 |
|---|---|:---:|
| 阔叶树木片 | 最为推荐。可连续多年生产 | 非常高 |
| 稻草、麦秆 | 可单独使用，出菇较快，但菌床寿命较短 | 高 |
| 玉米秸秆 | 养分丰富，产量较高 | 高 |
| 稻壳 | 透气性好，常与其他材料混用 | 中等 |
| 落叶 | 容易获得。多与木片混用，而非单独使用 | 中等 |
| 木屑 | 太细会导致不透气，需与木片混用 | 中等 |
| 菌糠 | 直接使用种过香菇或木耳后剩下的培养基 | 中等 |
| 咖啡渣、豆荚 | 作为氮源少量添加 | 辅助 |
| 竹屑 | 打碎后可以使用 | 辅助 |

&nbsp;&nbsp;&nbsp;材料范围如此宽泛，是灾害情况下的决定性优势。没有橡木也好，没有木屑也好，只要有稻草，这种菌菇也能生长。不过不同培养基种类之间的产量差异最高可达3.9倍，因此如果条件允许，最好以木片为主料，稻草作为辅助掺入。

### 3-2. 木片的选择

| 项目 | 标准 | 原因 |
|---|---|---|
| 最适树种 | 枫树、柳树、杨树、榆树 | 材质松软、分解快，菌丝容易蔓延 |
| 可用树种 | 橡树、桤木、樱树 | 材质坚硬，出菇较慢，但持续时间长 |
| 禁用树种 | 松树、红松等针叶树 | 树脂和萜类物质会抑制菌丝 |
| 禁用树种 | 核桃树、胡桃木 | 化感物质会杀死菌丝 |
| 木片大小 | 指甲到拇指大小 | 太细不透气，太大菌丝无法跨越 |
| 新鲜度 | 采伐1年以内 | 堆放已久的木片里已有其他杂菌定居 |

&nbsp;&nbsp;&nbsp;要选新鲜木片这一条件与其他菌菇正好相反，容易混淆。香菇木屑越陈越好，但大球盖菇在已有其他霉菌定居的旧木片上会在势力争夺中落败。要避开堆在外面已经长出白色霉斑的木片堆。刚劈碎的木片最好，若没有，就先用水冲洗以减少表面的杂菌再使用。

### 3-3. 不用电处理培养基的方法

&nbsp;&nbsp;&nbsp;大球盖菇即使不灭菌也能生长。但不灭菌并不意味着什么处理都不做。减少杂菌数量能明显提高成功率，尤其是在建立第一个菌床时，做一定程度的处理会更安全。可以从下面四种方法里挑选适合自己情况的一种。

#### 3-3-1. 水浸——最简单的处理

| 项目 | 方法 |
|---|---|
| 方法 | 将木片或稻草完全浸入水桶或水坑中24-48小时 |
| 原理 | 切断氧气供应使好氧性杂菌变弱，同时让材料充分吸水 |
| 沥水 | 捞出后沥水6-12小时，以握紧时不滴水为宜 |
| 含水率 | 65-80%，最适75% |
| 燃料 | 不需要 |

&nbsp;&nbsp;&nbsp;这是建立大球盖菇菌床时最常用的处理方法。完全不用火，只要有水就行，而且材料能充分吸湿这一附带效果也很重要。如果直接把菌种撒在干燥的木片上，菌丝会因缺水而无法伸展。

#### 3-3-2. 石灰浸泡——不用燃料减少杂菌的方法

| 项目 | 方法 |
|---|---|
| 配比 | 100L水中加消石灰1-1.5kg，或生石灰0.5-1kg |
| pH | 12-13，是接触手会有滑腻感的强碱 |
| 浸泡 | 将切段的稻草或木片完全浸没12-24小时 |
| 沥水 | 捞出后沥水6-12小时 |
| 接种 | 不用清水冲洗，残留的碱性会持续抑制杂菌 |

&nbsp;&nbsp;&nbsp;强碱会破坏霉菌孢子的细胞膜，而菌菇的菌丝相对耐受。而且大球盖菇对酸碱度不太敏感，即使在残留碱性的培养基里也能长得很好。这种方法完全不耗燃料，比单纯水浸更可靠。没有石灰的话，可以把草木灰调入水中放置一天，只取上层灰水代替，但其pH偏低、波动较大，效果时好时坏。

#### 3-3-3. 稻草发酵——以稻草为主要材料时

&nbsp;&nbsp;&nbsp;把稻草用水浸湿后堆成1-1.5m高，嗜热微生物会自行发热，使堆芯温度达到60-70℃。每隔2-3天翻堆一次，放置1-2周，杂菌容易利用的糖分会提前耗尽，从而形成一种选择性培养基。这不是灭菌，而是先断绝食物的方式。

&nbsp;&nbsp;&nbsp;对大球盖菇而言，发酵时间不宜过长。双孢蘑菇需要2-3周的完全发酵，但这种菌菇发酵1-2周更为合适。发酵过度会连菌丝可利用的养分也一起减少，导致产量下降。堆芯温度超过60℃后再次降到40℃左右时，就应该摊开降温。

#### 3-3-4. 沸水浸泡或油桶蒸煮

&nbsp;&nbsp;&nbsp;如果燃料充足、想减少失败风险，可以把稻草放入沸水中煮1小时，或在200L油桶底部倒入20-30cm的水，把材料堆在支架上用蒸汽蒸2-4小时。这个时间比其他菌菇需要的短，因为灭菌本来就不是必须的，目标也不是彻底灭菌。这种方法适用于室内菌床栽培，或是必须确保第一个菌床成功的时候。

### 3-4. 处理方法比较

| 方法 | 燃料 | 所需时间 | 杂菌抑制 | 推荐场景 |
|---|:---:|:---:|:---:|---|
| 水浸 | 无 | 24-48小时 | 低 | 露地木片菌床，最为常见 |
| 石灰浸泡 | 无 | 12-24小时 | 中等 | 以稻草为主料，夏季建床 |
| 稻草发酵 | 无 | 1-2周 | 中等 | 稻草量大且有充足时间时 |
| 沸水、蒸汽 | 多 | 1-4小时 | 高 | 室内菌床、确保首个菌床成功 |

### 3-5. 菌床选址

| 项目 | 适宜条件 | 应避免的条件 |
|---|---|---|
| 光照 | 半阴。100-500lux | 全天直射阳光的地方 |
| 遮阴来源 | 蔬菜投下的阴影、树下、墙北侧 | 完全黑暗 |
| 排水 | 不积水的平地或缓坡 | 雨后积水的低地 |
| 耕作方式 | 不翻耕的永久花坛、果园间、路边 | 每年翻耕的田地中央 |
| 便利程度 | 每天都会经过的地方 | 容易错过采收期的偏僻处 |
| 浇水 | 能与浇菜同时进行的地方 | 需要另外提水的地方 |

&nbsp;&nbsp;&nbsp;菜园边缘或垄间是最好的位置。作物投下的阴影可以代替遮光，给蔬菜浇水时菌床也会一起湿润，而且每天都会经过，不会错过采收期。此外，正如第11节所述，这种菌菇实际上对旁边的作物也有帮助。

## 4. 菌种获取

&nbsp;&nbsp;&nbsp;菌菇没有种子。种苗店关门后就没地方买种子，把种子留下装进坛子里保存的方法也不适用。但菌类拥有植物所没有的三条路：保存孢子的路，从活菌菇上取一块肉培养的路，以及把已经定植的菌丝整块搬走的路。大球盖菇尤其是第三条路特别容易，因此获得了自家留种SS。

### 4-1. 菌床分割——最简单也最可靠的方法

&nbsp;&nbsp;&nbsp;其他菌菇的菌种传接需要无菌操作或劈开菌菇，相比之下，这种菌菇只要一把铁铲就能完成。铲出菌丝已经蔓延良好的菌床的一部分，埋入新场地的木片之间，那就是菌种。

| 步骤 | 方法 |
|---|---|
| 时期 | 春季或秋季，避开盛夏和严冬 |
| 对象 | 白色菌丝束粗壮延伸、没有杂菌痕迹的部分 |
| 挖取 | 用铁铲挖出约20cm见方的一块。菌丝会缠绕成土块状整块脱落 |
| ÷ | 分成拳头大小的块。切得太碎会伤及菌丝 |
| 移植 | 以30-40cm的间距埋入新菌床的木片层之间 |
| 浇水 | 充分浸湿 |
| 回收率 | 一个菌床可以分出3-5个新菌床 |

&nbsp;&nbsp;&nbsp;挖取后的空缺用新木片填补，原来的菌床很快就能恢复。每年春秋各做一次这项操作，菌床数量就会呈几何级数增长。不需要灭菌，不需要无菌操作，也不需要菌种店。这正是这种菌菇在灾害情况下所具备的最实质的力量。

> **大球盖菇一旦定植成功，之后的菌种就可以直接用铁铲铲取使用。没有其他菌菇的种源获取方法比这更简单。**

### 4-2. 采集孢子与制作孢子印

&nbsp;&nbsp;&nbsp;不能因为菌床分割简单就跳过孢子保存。菌床可能因洪水、干旱、冻害或杂菌入侵而一次性全部损失。孢子就是为那种时候准备的保险。

| 步骤 | 方法 |
|---|---|
| 挑选对象 | 菌盖已完全展开、菌褶已变为紫黑色的大个体 |
| 切柄 | 在菌盖与菌柄相接处贴近切下菌柄 |
| 放置 | 让菌褶朝下，放在铝箔上 |
| 覆盖 | 盖上容器以隔绝气流 |
| 静置 | 于阴凉处放置24小时 |
| 收取 | 拿掉菌盖后，紫黑色的孢子粉会保持菌盖的形状留在原处 |

&nbsp;&nbsp;&nbsp;这种菌菇的孢子是紫黑色的。这是它与孢子呈白色的香菇、金针菇之间决定性的区别，也正如第12节所述，是与鹅膏菌类区分开来最可靠的标志。制作孢子印既是种源保存，同时也是安全确认。

&nbsp;&nbsp;&nbsp;铝箔比纸更适合。纸会吸湿，杂菌容易藏在纤维之间。铝箔不吸水、表面光滑，能原样保存孢子。没有铝箔时，玻璃板是次选。

&nbsp;&nbsp;&nbsp;收取孢子后，连同铝箔一起放在通风的阴凉处再晾一天，把细微的湿气也去除。然后把铝箔对折，让孢子面朝内加以保护，装入密封袋中。同时放入炒干的盐或炭块吸湿。将密封袋收进玻璃瓶中用蜂蜡密封，存放在四季温度稳定的土窖或地下室里。紫外线会破坏孢子的DNA，所以要避光保存。

| 保存形式 | 寿命 | 备注 |
|---|:---:|---|
| 孢子印（铝箔干燥） | 5-10年以上 | 水分被完全排除，细胞活动停止 |
| 液体菌种（灭菌水悬浮） | 3-6个月 | 没有冷藏就会提早萌发或细菌增殖 |
| 已接种菌种（谷粒·木屑） | 6个月-1年 | 因菌丝仍存活，会持续消耗养分 |
| 已定植的菌床 | 数年 | 只要管理得当，实际上可以无限延续 |

> **在灾害情况下，不能把孢子以液体形式保存，必须以干燥的孢子印形式保存。**

&nbsp;&nbsp;&nbsp;孢子与植物种子在寿命上的差异来自于结构。番茄种子内含胚芽和营养物质，随着时间推移会自行消耗养分，逐渐老化死亡，常温下寿命为2-4年。菌菇孢子只是被厚厚的细胞壁包裹的单个细胞，没有可消耗的养分。只要条件合适就能保存5-10年，学界让保存数十年的孢子重新萌发的案例也并不罕见。

| 比较项目 | 番茄种子 | 菌菇孢子 |
|---|---|---|
| 平均寿命（常温） | 约2-4年 | 约5-10年以上 |
| 脆弱因素 | 温度变化、自身养分耗尽 | 湿气引起的霉菌污染 |
| 细胞结构 | 复杂的胚芽和营养物质 | 单个细胞和厚厚的保护壁 |

&nbsp;&nbsp;&nbsp;评价表中的种子寿命D，是以市售菌种为基准的。一旦换成孢子印保存，这个D实际上就失去意义了。请在灾害发生的第一年，用最大最健康的个体制作20-30张孢子印，储存在土窖里。即使菌床全部损失，5年后、10年后也能重新开始。

### 4-3. 用孢子制作菌种——稻草加热培养基法

&nbsp;&nbsp;&nbsp;理论上，把孢子撒在培养基上就会长出菌丝。但现实中，空气里的青霉菌和细菌会以比菌菇孢子快数百倍的速度占领培养基。营养价值越高的培养基越脆弱。在没有电力的情况下，与其用营养过剩的人工培养基，不如使用借助自然防御力的原始培养基。

| 步骤 | 方法 |
|---|---|
| 煮 | 将稻草或麦秆放入沸水中充分煮1小时以上 |
| 挤 | 捞出挤干水分，冷却到可以用手触摸的温度 |
| 撒 | 不要节省保存的孢子粉，均匀且大量地撒入 |
| 覆盖 | 用干净的布覆盖，阻隔风和飘落的杂孢子 |
| 培养 | 在22-26℃的暗处放置2-4周，白色菌丝束覆盖稻草即为成功 |

&nbsp;&nbsp;&nbsp;如果舍不得孢子、一粒一粒地撒，就只会长出初级菌丝然后死亡。只有不同交配型相遇形成次级菌丝，才能长出菌菇，因此必须一次性大量撒入孢子，让它们在培养基里自行寻找配对对象。

### 4-4. 组织培养——最可靠的方法

&nbsp;&nbsp;&nbsp;如果手边有新鲜的活菌菇，几乎没有必要用孢子。菌盖与菌柄相接处内侧的白色肉质部分，本身就已经是完成两性结合的次级菌丝团块。取下这块组织放入培养基，就能跳过萌发和配对的过程，直接让菌丝向四周蔓延。

| 步骤 | 方法 |
|---|---|
| 挑选 | 菌盖刚要展开的新鲜个体，不使用陈旧或被虫蛀过的 |
| 消毒 | 把刀在火上烧热后放凉，或浸入沸水后取出 |
| 掰开 | 用手将菌菇纵向掰开，用刀切会把表面杂菌带入内部 |
| 采取 | 从菌盖与菌柄相接的内侧白色肉质部分取下米粒大小的一块 |
| 接种 | 夹入煮熟冷却的稻草或湿木片之间 |
| 培养 | 22-26℃暗处，3-5天后碎块周围就会长出白色菌丝 |

&nbsp;&nbsp;&nbsp;掰开之所以重要，是因为菌菇内部几乎是无菌的。表皮和菌褶上附着着各种孢子，但肉质内部是干净的。用手掰开就能露出这个干净的新截面，从那里取下的碎块即使不消毒也能长成纯净的菌丝。菌柄基部粗大部位的肉质效果尤其好。

### 4-5. 菌种获取的优先顺序

| 顺位 | 方法 | 条件 |
|:---:|---|---|
| 1 | 菌床分割 | 已有定植成功的菌床时 |
| 2 | 组织培养 | 手边有新鲜菌菇时 |
| 3 | 由孢子印制成稻草培养基 | 菌床已损失，但有储存的孢子时 |
| 4 | 市售菌种 | 能买到时提前储备 |
