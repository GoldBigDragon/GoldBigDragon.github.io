### 1-3. 光照SS意味着什么

&nbsp;&nbsp;&nbsp;评价表中的光照项本来问的是40%遮光时还能剩下多少产量。大球盖菇获得SS，并不是说它在这场竞争中获胜，而是说它本来就不在这个坐标轴上。菌类没有叶绿素。这种菌菇利用的碳，是早已固定在木材和稻草里的纤维素与木质素，天空的明暗对这份"库存"没有任何影响。栽培光照强度只需100-500lux，也就是阴天室内的程度就够了，这是因为它把光当作信号而非养分来使用。

&nbsp;&nbsp;&nbsp;在大规模火山喷发或核冬天这类日照量持续数年下降的情况下，这种差异会决定性地显现出来。一旦平流层布满气溶胶，谷物、薯类（块茎/块根）、蔬菜会同时崩溃。但即便如此，稻草、落叶和树枝依然存在，而把它们转化为人可以吃的蛋白质的唯一途径就是菌菇。大球盖菇是这条途径中最简单的一条路。

> **菌菇是即使在阳光消失的世界里产量也不会下降的唯一粮食来源。大球盖菇是在不需要灭菌设备的情况下做到这一点的唯一物种。**

### 1-4. 如何解读它的优势

&nbsp;&nbsp;&nbsp;获得SS的项目有五项：蛋白质密度、设施负担、光照、连作适应性、整地·挖掘能耗、自家留种。此外还有收获速度A、耐寒性S、持续性S、口味S、非食用价值A。

&nbsp;&nbsp;&nbsp;设施负担SS最为重要。其他菌菇无一例外都要对培养基灭菌，灭菌需要燃料或电力。灭菌后的培养基还必须在接近无菌的条件下接种，一旦失败就要整批丢弃。大球盖菇跳过了这整条链条。只需在地上铺一层木屑，撒上菌种，再盖上一层就够了。这种菌菇能在与杂菌的竞争中获胜，是因为它的菌丝粗壮、生长势强，能把鬼伞类或木霉排挤出去。

&nbsp;&nbsp;&nbsp;连作适应性SS也很特别。通常连作适应性是指即使连续种在同一块地上损失也很小，但这种菌菇不止损失小，还能让土地变好。在与水稻连续3年轮作的试验中，土壤有机质增加27-31.6%，有效钾增加83.8-421.7%，后种的水稻产量从第一年的13%逐年提高到第三年的19.9%。种菌菇的同时连田地也一起变好，这样的组合并不多见。

&nbsp;&nbsp;&nbsp;非食用价值A的内容也很实用。这种菌菇的菌丝里有一种叫棘细胞的星形细胞，能捕捉土壤线虫，在15分钟内使92.9-95.5%失去活动能力。松材线虫也能在两小时内被捕获80.6-84.3%。在农药断供的情况下，它成为减少根结线虫危害的手段，也能直接帮助种在同一块地里的蔬菜。

### 1-5. 如何解读它的弱点

&nbsp;&nbsp;&nbsp;评为E的只有耐储性一项，评为D的有韩国国内普及度和种子寿命两项。

&nbsp;&nbsp;&nbsp;耐储性E是最痛的一点。15℃下4-6天就会失去商品价值，12天有95%会腐烂。而且不像其他菌菇那样可以直接晒干。菌盖厚、水分多，自然晾干过程中常常在内部干透之前外皮就已经变坏。但这不代表就要放弃干燥。切薄片，焯水后挤干水分，再配合烟熏干燥，可以把含水量降到11-13%，这样就能长期保存。第13节会详细介绍这些方法。耐储性这道墙，这种菌菇最终也是靠干燥跨过去的，只是比其他菌菇更费些功夫。

&nbsp;&nbsp;&nbsp;韩国国内普及度D是一个实际的障碍。菌种难以获得，适应韩国国内气候的栽培案例也少。应对方法有两种：一种是能拿到菌种时就提前储备，另一种是靠分割菌床自行扩繁。自家留种为SS，很大程度上弥补了这个弱点。只要建立起一个菌床，就可以用铁铲铲取分出多个新菌床，这个过程不需要任何设备。

&nbsp;&nbsp;&nbsp;微量营养素C满足11种，比其他菌菇低。不过钾含量按干物计算达每100g 3.58g，是食用菌菇中已报告的最高值，这一点值得记住。在钠摄入偏多的饮食持续时，它能起到平衡作用。

&nbsp;&nbsp;&nbsp;此外，评价表里没有写出的弱点还有一个：误认的风险。这种菌菇从土里长出，具备菌盖、菌柄、菌褶、菌环等典型的蘑菇外形，而最佳采收期正是菌盖尚未展开的白色纽扣状阶段。这三个条件都与致命的鹅膏菌类幼菇重合。第12节的内容必须阅读。

## 2. 这是一种什么样的菌类

### 2-1. 名称与分类

&nbsp;&nbsp;&nbsp;大球盖菇属于担子菌门、伞菌纲、伞菌目、球盖菇科、球盖菇属。它的名字有容易混淆的地方。铜绿球盖菇（Stropharia aeruginosa）是一种菌盖呈青绿色黏液质的不同物种，有中毒的报告。这个物种的名字只是因为与铜绿球盖菇相似而得名，它本身是可以食用的。英语世界里，因其王冠状的菌环称之为"帝王球盖菇（king stropharia）"，或因菌盖颜色称之为"酒红帽（wine cap）"。

&nbsp;&nbsp;&nbsp;种名rugosoannulata的意思是"有皱纹的菌环"。这个名字所指的部位正是安全确认的核心标志，值得牢记。

&nbsp;&nbsp;&nbsp;从生态角度看，它是分解落叶和木质残余物的腐生菌。与附着在树干上的香菇或木耳不同，它生长在土壤表面的有机质层中。在自然界中，它成群生长在森林地表、垃圾堆周边、牧场边缘等有机质堆积的地方。正是因为这种习性，只要把木片或稻草铺在地上就能栽培成功。

### 2-2. 外形特征

| 部位 | 特征 |
|---|---|
| 菌盖 | 直径4-15cm，大的超过20cm。从半球形展开为平展形 |
| 菌盖颜色 | 红褐色、紫褐色、酒红色。也有黄色型和混合型。干燥后颜色变浅并出现裂纹 |
| 菌褶 | 与菌柄完全相连，排列密集。最初为白色，经过灰紫色后变为紫黑色 |
| 菌柄 | 呈棒状，基部粗大。上部白色，下部带黄色 |
| 菌环 | 厚而坚硬，上表面有放射状的深沟，看起来呈星形或锯齿状 |
| 菌托 | 无 |
| 基部 | 白色的菌丝束（菌索）向培养基一侧延伸 |
| 孢子 | 紫黑色、紫褐色 |

> **菌褶由白色变为紫黑色，菌环上表面有星形沟纹，基部没有菌托。这三点就是大球盖菇的"身份证"。**

### 2-3. 生活史——从孢子到菌菇

&nbsp;&nbsp;&nbsp;菌菇的生活史与植物不同。植物是一粒种子长成一棵树，而菌菇的一粒孢子却无法单独长成一朵菌菇。

| 阶段 | 发生的事情 |
|---|---|
| 孢子 | 从成熟菌盖的菌褶上脱落。是只含一半基因的单核细胞 |
| 初级菌丝 | 孢子萌发后呈丝状延伸。因为只有一半基因，无法形成菌菇，最终会死亡 |
| 次级菌丝 | 两种不同交配型的初级菌丝相遇并结合而成。只有在这种状态下才能形成菌菇 |
| 菌索的形成 | 次级菌丝聚成粗壮的丝束，占据整个培养基。这种粗壮的菌丝正是排挤杂菌的力量 |
| 原基形成 | 在覆土层与培养基的交界处形成粟粒状的原基 |
| 子实体 | 原基膨大成白色卵状，随后展开菌盖生长 |

&nbsp;&nbsp;&nbsp;大球盖菇的菌丝格外粗壮。如果说其他菌菇的菌丝看起来像白霜，这种菌菇的菌丝则像白色的线或绳。这种粗壮就是它的生长势，也是它即使在未灭菌的培养基里也能战胜杂菌的原因。

> **单独一粒孢子长不出菌菇。撒孢子时不能一粒一粒地撒，而要充分地大量撒入孢子粉，让它们在培养基里彼此相遇、配对。**

| 蛋白质 | 2.40g | 占热量的38.3%。按干物计算粗蛋白为25.75-34.17% |
| 碳水化合物 | 约3.5g | 可利用碳水化合物43.3% DW |

&nbsp;&nbsp;&nbsp;蛋白质按干物计算含量在30%左右，这一点值得关注。晒干后的这种菌菇，重量中将近三分之一是蛋白质。这个比例可以与大豆相比，氨基酸构成也相对均衡。在肉类和豆类断供的情况下，可以用马铃薯或谷物提供热量，再用这种菌菇补充蛋白质，这样的组合是可行的。

&nbsp;&nbsp;&nbsp;鲜味数值也很实在。等价鲜味浓度相当于每100g mSG 177-230g，这意味着只需加入少量这种菌菇，汤汁的味道就会完全不同。在食盐、酱油、大酱变得稀缺的情况下，这是一种账面上算不出来的巨大价值。实际烹调时，记录中常提到它会带来类似马铃薯的绵软口感和类似肉类的耐嚼感，评价表中口味评为S也是由此而来。
