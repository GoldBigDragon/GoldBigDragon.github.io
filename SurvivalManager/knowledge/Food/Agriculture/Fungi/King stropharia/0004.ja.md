## 5. 接種方法

&nbsp;&nbsp;&nbsp;サケツバタケの接種は、層を重ねていく作業です。培地と種菌を交互に敷き重ねるため、キノコのラザニアと呼ばれることもあります。原理は単純です。種菌を複数の層に分けて広げ、菌糸が上下から同時に伸びるようにし、そうすることで雑菌より先に培地を占領するのです。

### 5-1. 時期

| 項目 | 基準 | 備考 |
|---|---|---|
| 春に作る | 最後の霜が終わった後 | その年の初夏から収穫します |
| 秋に作る | 初霜の2-3週間前まで | 冬を越し、翌年の春から収穫します |
| 温帯基準 | 4月から10月の間 | 菌糸が育つ時間を残しておく必要があります |
| 避けるべき時期 | 真夏の猛暑、真冬 | 30度を超えたり凍ったりすると活着が難しくなります |

&nbsp;&nbsp;&nbsp;秋の菌床作りが特に有利です。霜の前に作っておけば、冬の間に菌糸がゆっくりと広がり、翌年の春に気温が上がるころには、すでに培地を占領した状態になります。評価表の耐寒性Sと、秋播種・冬収穫の作型が成立するという記述は、ここから来ています。

### 5-2. 菌床の積み方

| 手順 | 内容 | 厚さ |
|---|---|:---:|
| 1 | 地面を均し、雑草や大きな残材を取り除いて地面を露出させます | - |
| 2 | 湿らせた木材チップや藁を敷きます | 3-5cm |
| 3 | 種菌を細かく崩して均一にまきます | - |
| 4 | 再び木材チップを敷きます | 3-5cm |
| 5 | 種菌を再びまきます | - |
| 6 | 最後の木材チップ層を敷きます | 5-10cm |
| 7 | 乾いた葉や藁、堆肥で覆います | 2-3cm |
| 8 | たっぷりと灌水します | - |

| 項目 | 基準 |
|---|---|
| 総厚さ | 15-20cm |
| 種菌量 | ㎡あたり0.5-0.8kg |
| 菌床の幅 | 1-1.2m。これより広いと中央部の手入れができません |
| 菌床の長さ | 制限なし |
| 菌床の間隔 | 40-60cmの通路を残します |

&nbsp;&nbsp;&nbsp;総厚さが重要です。15cmより薄いとすぐに乾いて冬に凍り、25cmを超えると内部まで空気が行き届かず、菌糸が完全に広がる前に嫌気状態になります。15-20cmが妥協点です。

&nbsp;&nbsp;&nbsp;地面に直接触れるように敷くことも重要です。ビニールや板を敷くと、菌糸が土の水分や微生物にアクセスできなくなります。サケツバタケは土と木質層の境目でもっとも良く育ち、土の中の無機物を引き寄せて使います。

### 5-3. 種菌を節約するとき

&nbsp;&nbsp;&nbsp;種菌が足りないときは、層を減らすのではなく面積を減らします。㎡あたり0.5kgを下回ると活着が遅くなり、その間にヒトヨタケ類が先に定着してしまいます。種菌1kgで2㎡を中途半端に作るより、1.5㎡をしっかり作るほうが良いです。そして菌床を一つしっかり確保できれば、翌年の春にそれを取り分けて三倍に広げることができます。

&nbsp;&nbsp;&nbsp;点接種も可能です。木材チップの層を広げた後、拳大の種菌の塊を30-40cm間隔で碁盤状に埋める方式です。まき散らすより活着は遅いですが、種菌が少ないときに使えます。菌床の分割で移した菌糸の塊も、この方式で植えます。

### 5-4. 覆土

| 項目 | 基準 |
|---|---|
| 時期 | 菌糸が培地全体に広がった後。菌床作りから30-60日後 |
| 材料 | 畑の土、腐葉土、砂を混ぜたもの。または乾いた葉と堆肥 |
| 厚さ | 2-4cm |
| 水分 | 覆土後にたっぷりと湿らせます |
| 目的 | 水分保持と原基形成の誘導 |

&nbsp;&nbsp;&nbsp;覆土は、このキノコが発生するために必要な条件です。菌糸は木質層で養分を食べ、子実体は覆土層と木質層の境目で結実します。覆土がないと、菌糸が培地表面に白い膜を作ったままキノコを作らないことがよくあります。露地の菌床では乾いた落ち葉と堆肥を被せるだけで十分ですが、室内の菌床では土を別に用意します。

&nbsp;&nbsp;&nbsp;覆土用の土は、あまり細かすぎないようにします。細かい土だけを被せると、水をやったときに固まって硬い板になり、幼いキノコが突き破って出てこられません。砂や粗い腐葉土を混ぜて、ほろほろとした状態にします。

## 6. 菌糸培養管理

&nbsp;&nbsp;&nbsp;菌床を作った後の30-60日が培養期間です。この時期の目標は、白い菌糸束が培地全体を占領することです。人がすべきことは、水を切らさないこと、踏まないこと、雑草を抜くこと程度です。

### 6-1. 温度と水分

| 項目 | 範囲 | 備考 |
|---|:---:|---|
| 菌糸生長温度 | 5-35℃ | 幅が非常に広いです |
| 最適温度 | 26℃ | この付近が最も速いです |
| 培地含水率 | 65-80%、最適75% | 握ったとき指の間から水がにじみ出る程度 |
| 危険な条件 | 40℃以上、培地の乾燥 | 菌糸が死にます |
| 冬 | 氷点下でも死にません | 藁や落ち葉で5-10cm覆います |

&nbsp;&nbsp;&nbsp;菌糸生長温度の幅が5-35℃であるということは、栽培キノコの中でも非常に広い部類です。温度を合わせようと努力する必要がほとんどないという意味であり、電力がない状況では、これがそのまま成功率になります。エノキタケが精密な冷房を要求することとは正反対の位置にあります。

### 6-2. 水管理

| 時期 | 管理 |
|---|---|
| 菌床作り直後 | たっぷりと。培地の内部まで濡らす必要があります |
| 培養中 | 表面が乾いたら与えます。通常週1-2回 |
| 夏 | 3-4日に一回。日暮れ時に与えます |
| 干ばつ | 藁や落ち葉を厚く覆って蒸発を防ぎます |
| 菜園の隣であれば | 野菜に水をやるときに一緒に与えればよいです |

&nbsp;&nbsp;&nbsp;水をやるときは、表面だけ濡らすのではなく、培地の内部まで染み込むようにゆっくりと長く与えます。強く撒くと木材チップの間を流れ落ちてしまい、実際に菌糸がある層が乾いたまま残ります。じょうろで何度かに分けて与えるか、菌床の上に藁を被せてその上から与えると、均一に染み込みます。

### 6-3. 菌糸が正しく育っているかを見る方法

| 観察 | 正常 | 異常 |
|---|---|---|
| 菌糸の形 | 太い白い糸や紐が木材チップを絡めています | 細い霜のようなら別の菌である可能性があります |
| 匂い | 土の匂いに近いほのかなキノコの香り | 酸っぱい匂いやアンモニア臭は異常 |
| 木材チップ | 手で持ち上げると菌糸に絡まって塊ごと持ち上がります | 一つずつ散らばるならまだ広がっていません |
| 進行速度 | 1か月で培地の半分以上 | 2か月経っても広がらなければ水分か材料の問題 |
| 色 | 白色を維持 | 緑色、オレンジ色、黒色は汚染 |
| 表面 | 灰色の小さなキノコが一時的に出るのは問題ありません | ヒトヨタケが続けて出るなら培地がまだ熟成不足です |

&nbsp;&nbsp;&nbsp;菌床作りの初期にヒトヨタケ類が出るのはよくあることです。これは失敗ではありません。ヒトヨタケは手に入りやすい養分を早く食べて消えていく先駆菌であり、それが過ぎればサケツバタケが定着します。見つけたら抜き取りますが、菌床自体を諦める必要はありません。ただし二、三か月経ってもヒトヨタケばかり出続けるなら、種菌の活着が失敗したということです。

## 7. 発生誘導

&nbsp;&nbsp;&nbsp;菌糸は快適であれば伸び続けるだけです。キノコを結実させるのは、菌糸にとって危機信号です。サケツバタケの場合、その信号は温度の低下と覆土、そして水分です。シイタケのように浸水させたり叩いたりする必要はありません。

### 7-1. このキノコに合った刺激

| 刺激 | 方法 | 効果 |
|---|---|---|
| 覆土 | 菌糸が広がった後に2-4cm覆います | もっとも強い信号です |
| 温度の低下 | 培養時の26℃から発生時の12-20℃へ下がります | 季節が自然にやってくれます |
| 水分の上昇 | 培地をたっぷり湿らせ、空中湿度を85-95%に上げます | 原基ができます |
| 光 | 100-500luxの弱い光 | 信号として働きます |
| 降水 | 雨が降った後、数日で群生して発生します | 自然が与えるもっとも良い刺激です |

&nbsp;&nbsp;&nbsp;露地栽培では、この刺激を人がわざわざ与えることはほとんどありません。夏が過ぎて気温が下がり、秋の雨が降れば自然に発生します。春も同様です。人がすべきことは、培地を乾かさないことだけです。もっとも手間のかからない発生方式であり、施設負担SSの実質的な内容でもあります。

### 7-2. 発生条件

| 項目 | 条件 | 備考 |
|---|---|---|
| 子実体生育温度 | 12-25℃ | 幅13℃ |
| 最適発生温度 | 12-20℃ | 16℃以下では太く丈夫に、24℃以上では細く早く開きます |
| 下限 | 4℃未満 | 子実体の形成が困難です |
| 空中湿度 | 発生初期85-95%、生育期75-80% | 85%を下回ると傘が裂けます |
| 培地含水率 | 65-80% | |
| 光度 | 100-500lux | 半日陰で十分です |
| 換気 | 露地では問題になりません | 室内であれば二酸化炭素を排出する必要があります |

&nbsp;&nbsp;&nbsp;発生温度によってキノコの形が変わります。涼しいときに出たものは傘が厚く柄が太いため重量があり、貯蔵性も良いです。暑いときに出たものは早く育ち早く開くため軽く、傷みやすいです。春や秋の収穫が夏の収穫より良い理由です。

### 7-3. 季節別発生

| 季節 | 発生状態 | 管理 |
|---|---|---|
| 春 | 雪解け後、気温が12℃を超えると始まります | 冬に覆っておいた藁を取り除いて光を入れます |
| 初夏 | もっとも多く発生します | 水管理に力を入れます |
| 真夏 | 25℃を超えると減少または停止します | 遮光を増やし水をこまめに与えます |
| 秋 | 再び多く発生します。品質がもっとも良いです | 新鮮な木材チップを5-10cm補充します |
| 初冬 | 4℃以上であれば発生が続きます | 藁を覆いますが、キノコが出る場所は残します |
| 真冬 | 停止します。菌糸は生きています | 藁や落ち葉で5-10cm覆って凍害を防ぎます |

## 8. 収穫と再発生の周期

### 8-1. 収穫時期の判断

| 基準 | 内容 |
|---|---|
| 最適 | 傘が柄から完全に開く直前。つばがまだ付いているか、外れたばかりのとき |
| 大きさ | 傘の直径5-10cm |
| 食感 | この段階がもっとも締まっていて美味しいです |
| 遅れた兆候 | 傘が平らになり、ひだが紫黒色に濃くなったら遅すぎです |
| 時間帯 | 早朝 |

&nbsp;&nbsp;&nbsp;大きすぎる個体は食感と味が落ち、貯蔵性も悪くなります。直径15cmを超えると肉が粗くなり水分が多くなります。小さいうちにこまめに採るほうが、総収穫量も増え品質も良くなります。

> **収穫の適期であるボタン状の段階は、致死性のテングタケの幼菌と見た目がもっとも似ている時期でもあります。必ず12節を読み、自分が作った菌床から出たものだけを採ってください。**

### 8-2. 収穫のこつ

&nbsp;&nbsp;&nbsp;柄の基部をつかんでねじるように引き抜きます。切り取るより引き抜くほうが良いです。残った基部が腐って細菌やキノコバエを呼び込むためです。抜いた跡がくぼんだら木材チップで埋めます。

&nbsp;&nbsp;&nbsp;そして採るときは、常に基部まで丸ごと引き抜きます。12節で見るように、つぼの有無は基部でしか確認できず、その確認が生死を分けます。習慣にしておくべき動作です。

### 8-3. 発生周期

| 項目 | 内容 |
|---|---|
| 初収穫 | 菌床作りから90日前後。覆土後30-60日 |
| 1回の発生期間 | 7-14日 |
| 発生間隔 | 12-25日 |
| 1作期の発生回数 | 3-5回 |
| 菌床の寿命 | 管理すれば複数シーズンにわたり数年 |

&nbsp;&nbsp;&nbsp;一度発生した後、2-3週間休んでから再び発生するのが、このキノコのリズムです。休んでいる間にすることは、水を切らさないことだけです。あえて刺激を与える必要はありません。

### 8-4. 菌床の更新

| 時期 | 作業 | 厚さ |
|---|---|:---:|
| 秋または早春 | 新鮮な木材チップを菌床の上に被せます | 5-10cm |
| 同時に | 縁が崩れた箇所を補修します | - |
| 2-3年ごとに | 菌床の一部を取り出して新しい場所へ移します | - |

&nbsp;&nbsp;&nbsp;毎年新鮮な木材チップを被せてやれば、菌床は事実上無限に続きます。下の層はすべて分解されて腐葉土になり、菌糸は上の新しい層へと上がっていきます。この過程で下に積もった腐葉土がそのまま畑の肥料になるため、キノコを得ながら土も作られているわけです。

### 8-5. 収量

| 条件 | 収量 |
|---|---|
| 中国の露地栽培全国平均 | ㎡あたり6.47kg |
| 培地の配合による変動 | ㎡あたり2.59-5.22kg。最大101.5%の差 |
| 培地の種類間の差 | 約3.9倍 |
| 熱量換算 | ㎡あたり1,618kcal。自給ラインの0.62倍 |

&nbsp;&nbsp;&nbsp;収量の差が大きいという点は覚えておく価値があります。同じキノコでも培地によって4倍近い差が出ます。木材チップを中心に藁と窒素源を適切に混ぜた培地がもっとも良く、藁だけで作った培地は発生が早い代わりに総量が少なくなります。いくつかの配合を少しずつ試し、自分の土地と材料に合った組み合わせを見つけておくことが、数年後の収穫量を大きく変えます。

> **㎡あたり1,618kcalは、キノコとしては異例の値です。30㎡、十坪に満たない菌床で、一人の一日分の熱量のかなりの部分をまかなえるという計算になります。**
