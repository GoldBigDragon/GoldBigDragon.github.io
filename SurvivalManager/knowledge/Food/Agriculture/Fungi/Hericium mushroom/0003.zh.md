## 3. 培养基材料与准备

&nbsp;&nbsp;&nbsp;猴头菇的培养基分为两条路。一条是把阔叶树锯末混入米糠，装入瓶子或塑料袋后灭菌；另一条是直接在橡树段木上接入菌种。前者速度快、产量可以预估，但需要灭菌燃料和容器。后者速度慢，却不需要灭菌，一次接种可以连续使用好几年。

> **在没有电力和燃料的情况下，段木栽培就是答案。评价表中设施负担为D的原因，正是灭菌设备和不断消耗的塑料袋，而段木栽培把这两者都跳过了。**

### 3-1. 栽培方式比较

| 方式 | 产量 | 栽培周期 | 灭菌 | 灾害适配度 |
|:---|:---|:---:|:---:|:---|
| **瓶栽** | 每850ml瓶356g | 40-45天 | **需要** | 有容器和燃料时 |
| **袋栽** | 每2,500ml袋810g | 50-60天 | **需要** | 产量高更有利，但会消耗塑料袋 |
| **段木栽培** | 每0.1㎡1,195.5g | 69天以上，此后可持续数年 | **不需要** | **最适合长期灾害** |

&nbsp;&nbsp;&nbsp;值得注意的是，段木栽培的产量最高。每0.1㎡产1,195.5g，生物学效率为17.3%。而且一次接种后每年都会出菇。缺点是初期劳动量大、到首次采收耗时较长，但在灾害持续数年的情况下，这种方式明显更为有利。

### 3-2. 段木栽培——不需要灭菌的路径

| 项目 | 标准 | 原因 |
|:---|:---|:---|
| **最适树种** | **橡树类** | 产量1,195.5g/0.1㎡，生物学效率17.3% |
| 可用树种 | 桤木、杨树、刺槐 | 产量低于橡树，但能正常出菇 |
| 其他 | 核桃木、水青冈、枫树、柳树 | 自然发生的树种 |
| **禁用树种** | **针叶树（松树、红松、落叶松）** | **树脂和萜类会抑制菌丝生长** |
| 采伐时期 | 落叶之后到发芽之前（11月-3月） | 此时树木储存的养分最多 |
| 干燥 | 采伐后在阴凉处放置1-2个月，使含水率降到40-45% | 刚采伐的木材含水量过高 |
| 粗细 | 直径10-20cm | 太粗的话菌丝深入木芯需要很长时间 |
| 长度 | 15-20cm短段，或1m长的段木 | 短段更便于操作 |

&nbsp;&nbsp;&nbsp;把短段立起来叠放的方式很适合灾害情况。将木料截成直径15cm、长20cm的短段，在截面涂抹菌种后，把短段上下叠放起来。菌丝会通过截面互相连接，把多个短段连成一整块。工具只有锯子和斧头也够用。

### 3-3. 锯末培养基配比

| 材料 | 瓶栽 | 袋栽 |
|:---|:---:|:---:|
| 橡树等阔叶树锯末 | 主料 | 80% |
| 米糠 | 20-30%范围内 | 20% |
| 麦麸 | 替代部分米糠 | |
| 甜菜浆 | 替代部分米糠 | |
| 含水率 | 65-67% | 68-75% |
| 培养基量 | 850ml瓶装580-620g，1,100ml瓶装750-800g | 每袋2kg |

&nbsp;&nbsp;&nbsp;米糠、麦麸、甜菜浆合计不要超过总量的30%。营养源越多产量越高，但青霉率先爆发式滋生的风险也会随之增大。没有无菌设备的情况下，把比例降到20%左右更安全。

### 3-4. 用农业副产物替代锯末

&nbsp;&nbsp;&nbsp;评价表中菌菇副产物适应性为C的原因，是它只能依赖阔叶树锯末和米糠这两种材料。不过从试验结果来看，在一定程度上是可以替代的。

| 替代材料 | 替代比例 | 结果 |
|:---|:---:|:---|
| 稻草 | 20% | 与对照组无差异 |
| 豆荚 | 20% | 生物学效率无显著差异 |
| **玉米秸秆** | **20%** | **生物学效率和平均鲜重均显著提高** |

> **用玉米秸秆替代20%的锯末，产量反而会提高。**把周围能找到的稻草、豆荚、玉米秸秆切碎，替代锯末的20-30%，在灾害情况下培养基的获取会容易得多，产量也不会下降。

&nbsp;&nbsp;&nbsp;替代时切碎是关键。如果把秸秆或茎秆整段放入，培养基内会出现大的空隙，菌丝无法跨越，还会积水。要切成指甲大小以下再使用。

### 3-5. 无需电力的灭菌方法

| 方式 | 条件 | 燃料 | 备注 |
|:---|:---|:---:|:---|
| 高压灭菌 | 121℃ 90分钟 | 电力 | 标准方式 |
| 常压灭菌 | 100℃ 4小时或98℃ 6小时 | 大量 | 无电力标准方式 |
| **油桶蒸汽** | 200L油桶底部注水20-30cm，容器放在支架上，蒸汽100℃ 4-6小时 | 木柴30-50kg | 一次性大量处理 |
| 沸水蒸煮 | 培养基装入布袋煮2-3小时 | 中等 | 不算彻底灭菌，但能降低杂菌风险 |
| **段木栽培** | **不需要** | **无** | 根本没有灭菌这一步骤 |

&nbsp;&nbsp;&nbsp;油桶蒸汽灭菌是无电力条件下的标准方法。在桶底倒水，放上支架使容器不接触水面，盖上桶盖后用湿布或泥土封住缝隙。从冒出蒸汽开始维持4-6小时，熄火后盖着盖子放置一夜冷却。

&nbsp;&nbsp;&nbsp;每次生火时把油桶装满、一次性处理，燃料效率会好得多。为灭菌十个容器而生火和为灭菌一百个容器而生火，所耗的木柴并没有太大差别。

### 3-6. 容器——没有塑料袋时

&nbsp;&nbsp;&nbsp;塑料袋和瓶子每个周期都会被消耗，这正是设施负担评为D的原因。可替代方案是能反复使用的容器。

| 容器 | 使用方法 | 注意事项 |
|:---|:---|:---|
| 玻璃瓶（果酱瓶、腌菜瓶） | 耐灭菌，可以用上好几年 | 骤冷会破裂，要缓慢冷却 |
| 竹筒 | 保留一端竹节后截断，整根蒸煮 | 容易裂开，不能多次使用 |
| 陶罐、瓦罐 | 耐热性强，保湿效果好 | 较重，灭菌耗时更长 |
| 木箱盖布 | 形成平板栽培形态 | 杂菌风险最大 |
| 耐热塑料袋 | 标准方式，袋口用棉花或布堵住 | 只能耐受常压100℃ |

&nbsp;&nbsp;&nbsp;容器需要满足四个条件：能盛放培养基，灭菌后能阻止杂菌进入，能透气，并留出子实体长出的面。猴头菇的子实体会长得很大，所以口径宽的容器更有利。口径太窄，菇体会被挤压变形。

### 3-7. 栽培空间

| 项目 | 标准 | 灾害情况下的替代方案 |
|:---|:---|:---|
| 温度 | 培养期22-25℃，出菇期15-24℃ | 春秋季室内、地窖、地下室、朝北的仓房 |
| 湿度 | 培养期65-75%，出菇期80-95% | 在大箱子或瓦罐里放一碗水来营造 |
| **光照** | **间接光照，以能看清报纸文字为宜** | 离窗户稍远的位置，避开直射阳光 |
| 通风 | 需要新鲜空气 | 上下开通风口，利用自然对流 |
| 空间 | 摆放2-3层货架 | 在狭窄空间里增加使用面积 |

> **猴头菇与双孢蘑菇不同，需要微弱的光照。**在完全黑暗中，菌刺无法正常伸展，会残留成结块状。但若照射直射阳光，又会变干发黄。以能看清报纸文字的间接光为最佳，离窗户两三步远的位置，或从门缝透光的仓房都很合适。

## 4. 菌种的获取

&nbsp;&nbsp;&nbsp;菇类没有种子。种苗店关门后就没有地方能买到种子，把种子收好放进罐子里保存的方式也不适用。评价表中猴头菇的自家留种为B，种子寿命为D。这意味着尽管需要无菌操作，菌丝传代是可行的，但市售菌种在6个月到1年内就会失去活力。菌类拥有植物所没有的三条路径：留存孢子的路径、从活体菇体上取下组织培养的路径，以及移接已经长好的培养基或段木的路径。

### 4-1. 孢子采集与孢子印

| 步骤 | 方法 |
|:---|:---|
| 选择对象 | 菌刺充分伸展的成熟个体。开始变黄的个体也适合用来采孢子 |
| 取下 | 把子实体从培养基上取下来 |
| 放置 | 让**菌刺朝下**放在铝箔上 |
| 覆盖 | 罩上碗以阻挡气流 |
| 静置 | 在凉爽处放置24小时 |
| 回收 | 拿走子实体后会留下**白色**孢子粉 |

&nbsp;&nbsp;&nbsp;这种菇的孢子是白色的。因此**用白纸接取的话根本看不见。**必须用深色纸、锡纸或玻璃板来接取。这一点和产紫褐色孢子的大球盖菇、产褐色孢子的双孢蘑菇不同。

&nbsp;&nbsp;&nbsp;铝箔比纸更合适。纸会吸收水分，纤维之间还会藏有杂菌。铝箔不吸水，表面光滑，能原样保存孢子。没有铝箔的话，玻璃板是次选。

### 4-2. 孢子保存——无需电力保存10年

| 步骤 | 方法 |
|:--:|:---|
| 1 | 在铝箔上接取孢子 |
| 2 | 把铝箔放在通风的**阴凉处**再放一天，让细微的水分也彻底散尽 |
| 3 | 对半折起，让孢子面朝内加以保护，装入密封袋 |
| 4 | 放入**炒得很干的盐或木炭块**一起吸湿 |
| 5 | 把密封袋收进玻璃瓶，**用蜂蜡封口**，放在四季温度稳定、不见光的**地窖或地下室**里 |

| 保存形态 | 寿命 | 备注 |
|:---|:---:|:---|
| 孢子印（铝箔干燥） | **5-10年以上** | 水分被排除，细胞活动停止 |
| 液体菌种（无菌水悬浮） | 3-6个月 | 没有冷藏会提前萌发或细菌增殖 |
| 已接种菌种（锯末·谷粒） | 6个月-1年 | 因为是活菌丝，会持续消耗养分 |
| **已接种段木** | **数年** | 只要管理得当，每年都会出菇 |

> **灾害情况下不能把孢子保存成液态，必须做成干燥的孢子印形态保存。**

&nbsp;&nbsp;&nbsp;紫外线会破坏孢子的DNA，所以必须放在不见光的深处。孢子与植物种子的寿命差异来自结构上的不同。

| 比较项目 | 番茄种子 | 菌菇孢子 |
|:---|:---|:---|
| 平均寿命（室温） | 约2-4年 | 约5-10年以上 |
| 脆弱因素 | 温度变化、自身养分耗竭 | 因潮湿导致的霉菌污染 |
| 细胞结构 | 复杂的胚芽与营养物质 | 单细胞与厚厚的保护壁 |

&nbsp;&nbsp;&nbsp;种子内含胚芽和养分，随着时间推移会自行消耗并衰老死亡，而菌菇孢子只是被厚厚细胞壁包裹的单个细胞，没有可消耗的养分。只要条件合适就能存活得更久，学界也不乏让存放数十年的孢子重新萌发的案例。

> **评价表中的种子寿命D是以市售菌种为标准的。换成孢子印保存之后，这个D实际上就失去了意义。请在灾害发生的第一年，用最大最健康的个体制作20-30张孢子印，储存在地窖里。即便菌种全部损失，5年后、10年后也能重新开始。**

### 4-3. 组织培养——最可靠的方法

&nbsp;&nbsp;&nbsp;如果手上有新鲜的活体菇，几乎没有理由再用孢子。子实体内部的白色肉质部分，已经是完成交配型结合的次级菌丝团块。把这部分组织取下放入培养基，就能跳过萌发和交配的过程，菌丝会立刻向四面延伸。

| 步骤 | 方法 |
|:---|:---|
| 挑选 | **菌刺尚短、整体呈纯白色**的幼嫩个体。变黄的个体不能用 |
| 消毒 | 把刀放在火上烧热后放凉，或放入沸水中烫过后取出 |
| 掰开 | **用手纵向掰开。**用刀切的话，表面的杂菌会被带入内部 |
| 采取 | 从靠近木料一侧的基部内侧，取下米粒大小的白色肉质组织 |
| 接种 | 夹入煮过放凉的锯末培养基或稻草之间 |
| 培养 | 22-25℃避光处。3-5天后白色菌丝就会从组织周围扩展开来 |

&nbsp;&nbsp;&nbsp;掰开这一步之所以重要，是因为菇体内部几乎是无菌的。表面上落满各种孢子，但内部肉质是干净的。用手掰开会让这个干净的面重新露出来，取下的组织即使不消毒也能得到纯净的菌丝。猴头菇的子实体像海绵一样柔软，容易掰开，而基部一侧组织最为紧实，最适合取材。

### 4-4. 稻草加热培养基法——从孢子培育菌种时

&nbsp;&nbsp;&nbsp;理论上把孢子撒在培养基上，菌丝就会生长延伸。但现实中，空气中的青霉和细菌会以比菇类孢子快数百倍的速度占据培养基。营养价值越高的培养基越脆弱。在没有电力的情况下，要用借助自然防御力的原始培养基，代替营养过剩的人工培养基。

| 步骤 | 方法 |
|:---|:---|
| 煮制与挤水 | 把稻草、麦秸或豆荚**在沸水中煮1小时以上**灭菌，挤干水分后放凉 |
| 接种 | 不必吝惜保存的孢子粉，充分均匀地大量撒上 |
| 覆盖 | **盖上干净的布**，阻挡气流和飘落的孢子 |
| 培养 | 22-25℃避光处放置2-4周。白色菌丝覆盖秸秆即为成功 |

&nbsp;&nbsp;&nbsp;养分较少的秸秆对青霉的吸引力也较低，因此即使菌丝生长得慢，也不会在竞争中落败。把由此得到的菌丝团块转移到锯末培养基上，培育成菌种。

### 4-5. 段木移植——存续最久的菌种

&nbsp;&nbsp;&nbsp;把菌丝已经扩散的段木劈开，摩擦到新的段木上就能成为菌种。方法原始却可靠，这正是评价表中自家留种评为B的依据。

| 步骤 | 方法 |
|:---|:---|
| 对象 | 白色菌丝已扩散到截面、且没有杂菌痕迹的段木 |
| 时期 | 春季或秋季，避开盛夏和严冬 |
| 劈开 | 用斧头劈开，露出菌丝扩散的木芯 |
| 移植 | 把木芯碎块塞入新段木的孔洞或截面，再用木塞封住 |
| 或者 | 用勺子挖取长势良好的培养基，按新培养基重量的5-10%混入 |
| 局限 | 超过四五代之后活力会下降，要定期用组织培养或孢子重新培育 |

### 4-6. 菌种获取的优先顺序

| 顺序 | 方法 | 条件 |
|:--:|:---|:---|
| 1 | 市售菌种 | 普及度为S，平时最容易获得，应提前备好 |
| 2 | 组织培养 | 有新鲜菇体时，最为可靠 |
| 3 | 段木·培养基移植 | 已有长成的菌种时，速度最快 |
| 4 | 从孢子印制作稻草培养基 | 全部损失、但保存有孢子时 |

&nbsp;&nbsp;&nbsp;平时该做的事很明确。在能买到菌种时先培育一次，用那批菇制作20-30张孢子印，埋藏在地窖里。并且尽可能给几根段木接种。段木会成为持续好几年的活体菌种储藏库。
