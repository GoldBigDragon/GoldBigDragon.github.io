## 5. 接种方法

&nbsp;&nbsp;&nbsp;接种是锯末培养基栽培中失败最多的环节。灭菌把培养基清理得很干净，可这片空地却常常先被青霉占据，而不是先长出菇类菌丝。而且猴头菇要求培养基呈弱酸性，无法像其他菇类那样用草木灰或石灰调成碱性来抑制杂菌。接种的目标只有一个：让菇类菌丝先占据地盘。

### 5-1. 锯末培养基接种

| 项目 | 标准 | 原因 |
|:---|:---|:---|
| 冷却 | 灭菌后**13-14小时**，至培养基温度降到**18-20度** | 温度更高会导致菌种死亡 |
| 速度 | 一冷却好立刻进行 | 放置太久会落上空气中的孢子 |
| 时段 | **清晨或刚下过雨之后** | 空气中孢子和灰尘最少 |
| 接种量（标准） | 培养基重量的2-3% | |
| 接种量（无无菌室时） | **培养基重量的5-10%** | 先占地盘的一方获胜 |
| 放入位置 | 一半放入中央孔洞，一半撒在表面 | 菌丝会从中心开始扩散 |
| 封口 | 用棉花或布堵住口部并用绳子系好 | 既能透气，又能挡住灰尘 |

&nbsp;&nbsp;&nbsp;“雨后立刻接种”这条建议在没有无菌室时特别有效。雨水会把空气中的孢子和灰尘冲洗下来，落下的杂菌数量会大幅减少。相反，风大的晴天白天条件最差。

### 5-2. 没有无菌室时的接种要领

| 项目 | 方法 |
|:---|:---|
| 场所 | 不透风的最小房间，仓库内侧、仓房角落 |
| 预先处理 | 在地面和墙壁上洒水让灰尘沉降，等待30分钟 |
| 替代无菌装置 | 把大箱子或瓦罐横放，用开水擦拭内壁，只把手伸进去操作 |
| 手部 | 用肥皂洗净，条件允许的话再用高度酒或食醋擦拭 |
| 工具 | 把勺子和刀在火上烤过后放凉 |
| 衣物 | 略微湿润的衣物比干燥的衣物更少扬起灰尘 |
| 呼吸 | 不在培养基上方说话或呼气，用布遮住口部 |
| 动作 | 打开容器、放入菌种、盖好，整个过程在10秒内完成 |

> **没有无菌室时的关键不是做到完全无菌，而是速度和接种量。挡不住少量杂菌进入，就要让菇类菌丝数量占绝对优势，先占据地盘。**

### 5-3. 段木接种

&nbsp;&nbsp;&nbsp;段木不需要灭菌。木材内部本来就接近无菌，树皮起着防护屏障的作用。因此接种要简单得多。

| 步骤 | 方法 |
|:---|:---|
| 时期 | **3-5月**或9-10月，树液开始流动之时 |
| 打孔 | 直径12mm，深25-30mm，呈螺旋状排列，**间距15-20cm** |
| 放入菌种 | 把锯末菌种压入孔中填满，或打入种木塞（木栓状菌种） |
| 封口 | 用蜂蜡、松脂、湿泥或木塞把孔洞封住 |
| 截面接种 | 若是短段，就在截面涂抹菌种，再叠放其他短段 |
| 菌种用量 | 每根段木（直径15cm、长1m）打20-30个孔 |
| 后续管理 | 平放堆放在阴凉处，盖上稻草或落叶以防干燥 |

&nbsp;&nbsp;&nbsp;封孔十分重要。敞开的孔洞会渗水导致腐烂，还会招来杂菌。蜂蜡效果最好，没有的话可以熔化松脂使用，或涂抹湿泥封住，削一个木塞打入孔中也可以。

### 5-4. 接种后的检查

| 时间 | 观察什么 |
|:---|:---|
| 24-48小时 | 菌种周围开始出现**绒毛状的白色气息** |
| 3-5天 | 白色菌丝从菌种呈放射状扩展1-2cm |
| 7-10天 | 培养基上部被白色覆盖 |
| 段木 | 大约2-3个月后能在孔洞周围看到白色菌丝 |

&nbsp;&nbsp;&nbsp;最初几天决定成败。若3天内白色菌丝明显扩展，基本就算成功。若5天后仍毫无变化，说明菌种已经死亡，或是在培养基过热时接种的。一旦看到白色以外的颜色，要立刻把那个容器搬到与其他容器隔开的地方。

## 6. 菌丝培养管理

&nbsp;&nbsp;&nbsp;接种后20-30天是培养期。目标是让白色菌丝占满整个培养基。人要做的事只是维持温度、保持黑暗，并每天查看剔除被污染的部分。

### 6-1. 温度与湿度

| 项目 | 范围 | 备注 |
|:---|:---:|:---|
| 菌丝生长温度 | 22-25℃ | 生长最快 |
| **下限** | **6℃** | 低于此温度生长会停止 |
| **上限** | **35℃** | 高于此温度生长会停止，并很快死亡 |
| 空气湿度 | 65-75% | 过于潮湿会导致表面附着杂菌 |
| 光照 | 保持黑暗 | 培养期间不需要光照 |
| 时长 | 20-30天 | 因培养基量和温度而异 |

> **35℃是绝对不能突破的界限。**因为菌丝自身会产生代谢热，周围气温为30℃时，培养基内部也可能超过35℃。容器堆得太密时，中间部位会格外炎热。

&nbsp;&nbsp;&nbsp;应对办法有三个。堆放容器时留出能伸进一根手指的间隙。从培养第十天左右起把周围气温调低2-3℃。并且避开盛夏进行培养。

### 6-2. 菌丝颜色变化——不要误当成污染

| 时期 | 正常颜色 |
|:---|:---|
| 接种后-2周 | 纯白色 |
| 2-3周 | 白色中透出**淡淡的黄色** |
| 成熟期 | 变为黄色，有时会转为**淡粉色** |

> **这种菇的菌丝正常情况下会变成黄色和粉色。**换作其他菇类，这种颜色会让人怀疑是污染，但对猴头菇而言，这是成熟的信号。不了解这一点，就会把好好的培养基当作坏的丢掉。

&nbsp;&nbsp;&nbsp;那么该如何与污染区分呢。不要只看颜色，还要一并观察质感和气味。

| 观察项目 | 正常成熟 | 污染 |
|:---|:---|:---|
| 颜色 | 由白转黄、淡粉色 | 青绿色、黑色、深橙色 |
| 质感 | 菌丝纤维交织成的层，触摸有弹性 | **像粉末一样飞散** |
| 边界 | 均匀铺满整个培养基 | **从圆形斑点呈放射状扩散** |
| 气味 | 淡淡的菇香、森林土壤气息 | 闷臭味、酸味 |
| 速度 | 每天3-5mm | 每天10-30mm |

### 6-3. 培养完成的判定

| 判定项目 | 标准 |
|:---|:---|
| 颜色 | 整个培养基均匀覆盖白色至淡黄色 |
| 底部 | **菌丝必须已经长到底部。**只覆盖上层的属于未完成 |
| 硬度 | 把容器倒过来，培养基也能整块保持不散 |
| 追加时长 | 全部覆盖后**再放置5-7天。**称为后熟，能提高产量 |

&nbsp;&nbsp;&nbsp;省略后熟会导致产量下降。即便外表看起来已经全部覆盖，培养基内部仍会残留菌丝渗入不足的部分，多放几天结果会更好。

## 7. 出菇诱导

&nbsp;&nbsp;&nbsp;菌丝在舒适的环境下只会一味延伸生长。促使其结出菇体，对菌丝来说是一种危机信号。就猴头菇而言，这种信号有三种：**在培养基表面制造伤口**、温度下降，以及湿度上升。

### 7-1. 在表面制造伤口最为有效

&nbsp;&nbsp;&nbsp;有试验比较了几种催蕾诱导方法的结果。

| 处理 | 方法 | 再出菇率 | 品质 |
|:--:|:---|:---:|:---:|
| T1、T2 | 平菇方式（搔菌等） | 低 | 一般 |
| **T5** | **在表面制造伤口** | **最高** | **优良** |

> **在催蕾诱导中，表面制造伤口的方法再出菇率最高，品质也最好。**用刀尖或钉子在培养基表面戳出几处，或划出十字状裂口，把菌丝层撕开。原基就会在伤口处形成。

| 项目 | 方法 |
|:---|:---|
| 工具 | 在开水中浸过后取出的刀尖、钉子、竹签 |
| 深度 | 距表面5-10mm |
| 数量 | 瓶栽在表面2-3处，袋栽在一面3-5处 |
| 原理 | 伤口成为应激信号，空气与光线接触到该处，原基便随之形成 |
| 注意 | 划得过多会导致子实体分裂成多个而变小 |

&nbsp;&nbsp;&nbsp;想让一个子实体长大，就只在一两处制造伤口。想得到多个小子实体，就在多处制造伤口。在灾害情况下，一个大的更为有利：处理和干燥所花的功夫更少，菌刺也能充分伸展，口感更好。

### 7-2. 出菇条件

| 项目 | 培养阶段 | **出菇阶段** | 备注 |
|:---|:---:|:---:|:---|
| 温度 | 22-25度 | **15-24度。**最适为15-20℃ | 幅度9℃，温度越低菌刺越长越结实 |
| 空气湿度 | 65-75% | **催蕾期85-95%，生长期80-85%** | 湿度低会变干，湿度高会变软烂 |
| **光照** | 不需要 | **间接光照，以能看清报纸文字为宜** | 没有光照，菌刺会结成团块 |
| 通风 | 较少 | **充足** | 二氧化碳积聚会导致长成珊瑚状畸形 |
| 时长 | - | 催蕾3-7天，生长15-20天 | |

> **温度越低品质越好。**在15-18℃下生长的菇体菌刺长、组织紧实、苦味少。超过22℃虽然生长更快，却会变软并很快转黄。而变黄的部分正是引发第13节所述苦味问题的原因，因此在凉爽季节采收，甚至会左右贮藏品质。

### 7-3. 无需电力营造15-24度的方法

| 手段 | 温度 | 获取方法 | 局限 |
|:---|:---:|:---|:---|
| **春季栽培** | 自然 | 4月至6月初 | 到7月就会变热 |
| **秋季栽培** | 自然 | 9月至11月初 | 到12月催蕾就会停止 |
| 土窖、洞窟 | 12-18℃ | 向山坡内挖入2m以上 | 四季皆可使用，最为理想 |
| 地下室 | 12-18℃ | 利用现有建筑结构 | 需要另外调节湿度和光照 |
| 朝北的土墙仓房 | 随季节变动 | 厚厚的土墙能减缓温度变化 | 夏季和冬季会超出适宜范围 |
| 段木露地栽培 | 自然 | 在半阴处竖放或平放段木 | 完全交给季节决定 |

> **在没有电力的情况下，猴头菇是春秋两季的作物。**盛夏菌丝会在35℃下死亡，严冬则催蕾会停止。

&nbsp;&nbsp;&nbsp;段木露地栽培最适合无电力条件。只要把段木放在半阴处，注意不让其干燥，春秋两季就会自然出菇。人不需要调节温度、湿度和光照，季节会代为完成这一切。唯一的缺点是到首次采收耗时较长。

### 7-4. 无需电力营造湿度的方法

| 方法 | 说明 |
|:---|:---|
| **在箱子或瓦罐里放一碗水** | 把容器一起放进大箱子，底部放上盛水的盘子或湿润的沙子 |
| 盖湿布 | 上方盖湿布，但要架空，不让其直接接触菇体 |
| 向地面和墙壁洒水 | 能提升整个房间的湿度 |
| 调节通风口大小 | 把孔洞开小一些，防止湿气流失，但绝不能完全堵死 |

&nbsp;&nbsp;&nbsp;**不要直接向菇体喷水。**猴头菇的菌刺之间一旦积水，那个部位就会开始变黄并滋生细菌。湿度要靠空气来提升，水要洒在周围。这一点比其他菇类要严格得多，必须格外遵守。

### 7-5. 采收前的干燥管理

| 时期 | 管理 |
|:---|:---|
| 采收前3-4天 | **完全不喷水，把湿度略微降低** |
| 效果 | 颜色保持白净，组织变得紧实，耐储性提升 |
| 注意 | 过度会导致菌刺尖端干裂 |

> **这3-4天会极大改变耐储性。**带着水分采收的菇体一天之内就会变黄，晒干后苦味会更重。从采收前几天开始让其变干，是提前减轻第13节所述问题的方法。
