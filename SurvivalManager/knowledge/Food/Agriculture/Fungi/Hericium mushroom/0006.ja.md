## 12. 毒キノコとの誤認と安全確認

> **この節は生命に直結します。栽培することより、食べてよいかどうかを確認することのほうが重要です。**

&nbsp;&nbsp;&nbsp;ヤマブシタケは、この文書が扱う六種の中で**誤認の危険が最も低いきのこです。**それがこの節の結論ですが、なぜ低いのかを知っていてこそ、その利点を正しく活かせます。

### 12-1. 誤認の危険が低い三つの理由

| 理由 | 内容 |
|:---|:---|
| **1. 形が唯一無二です** | 傘も柄もひだもなく、白い針の束が垂れ下がった形です。この形を持つ致命的な毒キノコは知られていません |
| **2. 土から生えません** | 必ず広葉樹の枯れ木や傷ついた部分に付いて育ちます。テングタケ類はすべて地面から生えるため、重なる余地がありません |
| **3. 同じ属がすべて食用です** | ヤマブシタケ属（Hericium）に毒性種は報告されていません |

&nbsp;&nbsp;&nbsp;エノキタケとマッシュルームが危険なのには理由があります。どちらも傘と柄とひだを備えた典型的なきのこの形をしており、その形を持つ致命的な毒キノコが複数あり、発生する季節と基質まで重なります。特にマッシュルームは土から生え、白いボタン状の時期に収穫するため、テングタケの幼菌と正確に重なります。

&nbsp;&nbsp;&nbsp;ヤマブシタケにはその条件が一つもありません。アマトキシンを持つテングタケ類はすべて傘と柄とひだとツボを備え、地面から生えます。垂れ下がった針の束を木に付けるテングタケは存在しません。

> **これは災害状況において値を付けがたいほどの利点です。**医療支援がない状況できのこを食べる最大の危険は誤認ですが、このきのこはその危険が構造的にありません。きのこの判別経験がない人でも、比較的安心して扱える種です。

### 12-2. 同じ属の他の種——すべて食用です

| 種 | 特徴 | 食用かどうか |
|:---|:---|:---|
| **ヤマブシタケ（H. erinaceus）** | 棘が1-5cmと長く垂れ下がります。塊状 | 食用 |
| サンゴハリタケ（H. coralloides） | 枝がサンゴのように分かれ、棘は短いです | 食用 |
| サンゴハリタケモドキ（H. laciniatum） | 枝が分かれ、棘は中くらいの長さ | 食用 |
| H. caput-medusae | 頭のような形にまとまって生えます | 食用 |
| H. cirrhatum | 層状に重なって生えます | 食用 |

&nbsp;&nbsp;&nbsp;同じ属の種を見誤っても中毒にはなりません。ただし種によって棘が短く収量が少なかったり、食感が異なることがあります。栽培の価値が最も高いのはヤマブシタケです。

### 12-3. それでも確認すべきこと

&nbsp;&nbsp;&nbsp;誤認の危険が低いという言葉は、何も確認しなくてよいという意味ではありません。白い塊状の菌類の中には、食べられないものがいくつかあります。

| 対象 | 見分け方 | 危険性 |
|:---|:---|:---|
| **Climacodon属** | 木に**棚状に段々と**付きます。棘は短く下側にだけあり、**組織が革のように硬く筋張っています。**苦味があるものが多いです | 毒性は弱いですが食べられません |
| **白いカビの塊** | 棘がなく、綿や粉のようです | 汚染菌です |
| **幼いホコリタケ類** | 球形で棘がありません。切ると中が均一な白い綿のようです | 幼いものは食用ですが、切って確認します |
| **膠質菌類・カワラタケ類（白色系）** | 木に薄く広がって付き、棘が非常に短いか、ないです。硬く筋張っています | 食べられません |

| 確認項目 | ヤマブシタケの基準 |
|:---|:---|
| **形** | **塊から棘が下に垂れ下がります。**棚状に段々と付くことはありません |
| **棘の長さ** | **1-5cm。**目で見て明らかに長くなければなりません |
| **組織** | **スポンジのように柔らかく、指で押すとへこみます。**革のように硬く筋張っていれば別のものです |
| **色** | 白色から乳白色。育つと黄色、黄褐色 |
| **基質** | 広葉樹の枯れ木や傷ついた部分。**地面から生えたものはこのきのこではありません** |
| **味** | 幼い個体はほとんど苦くありません。**舌先に付けて強く苦ければ吐き出します** |

> **組織の柔らかさが最も確実な判別点です。**ヤマブシタケは手で押すとスポンジのようにへこみ、手でちぎれます。混同されうる他の菌類は大抵革質か木質で、手でちぎることができません。

### 12-4. 初めて食べるときの原則

&nbsp;&nbsp;&nbsp;誤認の危険が低くても、手順は同じように守ります。医療支援がない状況では、確認の手順そのものが防御手段です。

| 順序 | 内容 |
|:--:|:---|
| 1 | **木から生えたか確認します。**地面から生えたものは捨てます |
| 2 | **棘が1cm以上垂れ下がっているか見ます。**短く棚状であれば捨てます |
| 3 | **手で押してスポンジのように柔らかいか確認します。**硬く筋張っていれば捨てます |
| 4 | **舌先に少し付けてみます。**強く苦ければ吐き出し、食べません |
| 5 | **必ず十分に加熱します。**生のものは消化しづらく、胃を刺激します |
| 6 | 最初は**一人だけ、少量（一切れ）**を食べて24時間待ちます |
| 7 | 異常がなければ量を増やします |

> **6時間以上経ってから症状が現れる中毒が最も危険です。**
> 食べて30分から2時間以内に腹が痛くなるのは大抵胃腸の刺激ですが、6-24時間後に嘔吐と下痢が始まるのは、肝臓を破壊するアマトキシン中毒の典型的な経過です。ヤマブシタケでこのようなことが起こる余地はほとんどありませんが、他のきのこも一緒に扱うなら、この経過を覚えておく必要があります。

> **災害状況で最も安全なきのこの食糧は、自分で種菌を入れた培地から生えたものです。ヤマブシタケは、それに加えて野生の個体まで比較的安全に採集できる珍しい種です。**

## 13. 冷蔵庫なしの貯蔵

> **この節はヤマブシタケにおいて最も厄介な部分です。貯蔵性Eは乾燥で解決しますが、このきのこはそのまま乾燥させると苦く硬く筋張ってしまいます。**

### 13-1. 生のままでは三日から五日です

&nbsp;&nbsp;&nbsp;評価表では、このきのこの貯蔵性は生の状態を基準にEです。無電力常温で3-5日です。スポンジのような組織が水分を多く含んでいるため、押された場所から軟らかくなり、白色が黄色に変わりながら苦味が出てきます。

| してはいけないこと | 理由 |
|:---|:---|
| **洗って保管する** | スポンジ組織が水を吸い込み、一日で黄色く変わります |
| ビニールで完全密封 | 水滴が付いて腐ります。紙や乾いた布に包んで呼吸させます |
| 積み重ねる | 押された場所から傷みます。一段に広げて置きます |

&nbsp;&nbsp;&nbsp;乾いた布や紙に包んで12-15℃になる土窟に置けば、1-2週間まで持ちます。電力なしで得られる最善であり、それ以上は加工に移ります。

### 13-2. 乾燥させると苦くなり硬く筋張ります

&nbsp;&nbsp;&nbsp;このきのこの乾燥には二つの問題が一緒に起こります。

| 問題 | 原因 |
|:---|:---|
| **苦味** | 過熟した個体には苦味成分が多く、乾燥の過程で水分が抜けるにつれてその味が濃縮されます。高温で急いで乾燥させると、苦味が組織に固定されます |
| **硬く筋張る** | スポンジのような組織が乾く際に大きく収縮し、繊維同士が絡み合います。一度絡んだ繊維は水で戻しても解けず、革のように残ります |

> **この二つの問題の最大の原因は、乾燥技術ではなく収穫時期です。**白いうちに収穫したものは乾燥させても苦味が少なく、黄色く変わったものはどう乾燥させても苦くなります。8節の収穫時期の判断が、貯蔵品質の半分以上を決めます。

### 13-3. 苦味と硬さを減らす乾燥法

| 順序 | 方法 | 効果 |
|:--:|:---|:---|
| 1 | **白いうちに収穫します** | 苦味の根本原因をなくします |
| 2 | **収穫3-4日前から水をかけません** | 水分が少ないまま収穫されるので乾燥が容易です |
| 3 | **手で繊維に沿ってちぎり、厚さ1-2cmにします** | 厚い塊は内部が乾かずカビが生えます。ナイフで切らずにちぎるほうが組織が傷みにくいです |
| 4 | **沸騰した湯に塩を入れて3-5分湯通しします** | **この段階が要です。**苦味成分が湯に溶け出し、組織が熱で固定されて乾いた後も絡みにくくなります |
| 5 | **冷水に浸してもう一度アクを抜き、水気を絞ります** | 残った苦味が抜けます |
| 6 | **陰で風に当てながらゆっくり乾燥させます** | 高温での急速乾燥は苦味を固定し、組織を硬くします |
| 7 | 仕上げに日光に半日当てます | ビタミンDが増えます |

| 方法 | 条件 | 期間 | 結果 |
|:---|:---|:--:|:---|
| **湯通ししてからの陰干し** | 4番まで済ませた後、通風の良い軒下で | 3-5日 | **最も推奨。苦味が少なく戻りも良いです** |
| 生のまま陰干し | ちぎってそのまま干す | 3-5日 | 苦味が残り、硬く筋張ります |
| 生のまま日干し | ちぎって日光に干す | 1-2日 | 速いですが苦味と硬さが最もひどいです |
| 火の傍での乾燥 | かまどの上の棚、40-50℃ | 半日 | 梅雨時に使えますが苦味が固定されます |

| 段階 | 判定 |
|:---|:---|
| 完全乾燥 | **手でこすると崩れます。**曲がるならまだ乾燥不足です |
| 保管 | 完全に冷ました後、**密閉容器に炭や炒った塩と一緒に** |
| 期間 | 涼しく暗い場所で**1年以上。**粉に挽けば2年以上 |

### 13-4. 粉にするのが最も実用的です

> **災害状況におけるヤマブシタケの最善の貯蔵形態は、丸ごと乾燥させたものではなく粉です。**

&nbsp;&nbsp;&nbsp;理由は三つです。第一に、硬く筋張る問題が消えます。粉には食感というものがないため、組織が絡んでいるかどうかが問題になりません。第二に、苦味が分散します。粥やスープに一さじずつ使うので、苦味がほとんど感じられません。第三に、体積が小さく長持ちします。

| 段階 | 方法 |
|:--:|:---|
| 1 | 湯通ししてから完全に乾燥させます |
| 2 | 臼や石臼で挽きます |
| 3 | ふるいにかけて細かいものだけを集め、粗いものは再度挽きます |
| 4 | 密閉容器に炭と一緒に入れて、涼しく暗い場所に置きます |
| 5 | 粥、スープ、スジェビ（韓国風すいとん）の練り粉、穀物の粉に混ぜて使います |

### 13-5. その他の貯蔵方法

| 方法 | 作り方 | 期間 | 備考 |
|:---|:---|:--:|:---|
| **塩漬け** | 湯通しして水気を抜き、重量の20%の塩を入れて層状に | 6ヶ月-1年 | **乾燥より食感が良く残ります** |
| **チャンアチ（醤油漬け）** | 湯通ししてから醤油と酢に漬けます | 3-6ヶ月 | 苦味が醤油で隠れます |
| **発酵貯蔵** | 3%の塩水に浸けて乳酸発酵させます | 3-6ヶ月 | 酸味が苦味を覆います |
| **油漬け** | 湯通しして水気を絞り、油に浸します | 1-3ヶ月 | 油が十分にある場合のみ |
| **土窟での短期保管** | 洗わずに紙に包んで12-15℃に | 1-2週 | 一段に広げて置きます |

> **塩漬けは、このきのこにおいては乾燥より良い選択となり得ます。**組織が収縮しないため元の質感が残り、湯通しの過程で苦味はすでに抜けています。塩が十分にあるなら、貯蔵分の半分を塩漬けに、半分を粉にする配分が良いでしょう。

## 14. 調理と加工

### 14-1. 必ず加熱して食べます

&nbsp;&nbsp;&nbsp;ヤマブシタケは生では食べません。生のものは消化しづらく、一部の成分が胃腸を刺激します。そして加熱しないと細胞壁の中の栄養素を吸収できません。

| 調理 | 燃料 | 時間 | 備考 |
|:---|:--:|:--:|:---|
| 湯通し | 少ない | 3-5分 | 苦味を抜く基本の段階でもあります |
| 炒め | 少ない | 5-8分 | **油で炒めるとカニ肉や鶏肉に似た繊維感が出ます** |
| 焼き | 少ない | 5-8分 | 厚めにちぎって炭火の灰の上に乗せてもよいです |
| スープ・チゲ | 中程度 | 10分以内 | スープが澄んで、ほのかな甘味が出ます |
| チヂミ、煎り物 | 中程度 | 5-8分 | ちぎって練り粉に混ぜると量が増えます |

&nbsp;&nbsp;&nbsp;調理前に**水気をしっかり絞ること**がコツです。スポンジ組織に水分が多いため、そのまま炒めると水が出て蒸し状態になります。手でちぎった後、両手で押して水気を抜いてから炒めると繊維感が生き、肉に似た食感が出ます。タンパク質が不足する状況で噛む満足感を与える食材であるという点は、評価表の味Sに反映されています。

### 14-2. 苦味が出たとき

| 方法 | 説明 |
|:---|:---|
| **湯通しして抜く** | 沸騰した湯に塩を入れて3-5分湯通しした後、冷水に浸して何度も水を替えます |
| **テンジャン（韓国味噌）やコチュジャンに入れる** | 強い味が苦味を覆います |
| **油と一緒に** | 脂溶性の苦味成分が油に溶けて分散します |
| **粉にして少量ずつ** | 最も確実です。スープ一鍋に一さじなら苦味は感じません |
| **酸味を加える** | 酢や酸味のあるキムチと一緒に調理すると苦味が隠れます |

### 14-3. 乾燥させたものの使い方

| 順序 | 方法 |
|:--:|:---|
| 1 | ぬるま湯に30分以上浸して戻します。他のきのこより時間がかかります |
| 2 | **戻し水を味見します。**苦ければ捨て、苦くなければスープに使います |
| 3 | 戻したきのこを手でしっかり絞って水気を抜きます |
| 4 | 苦味が残っていれば、沸騰した湯でもう一度湯通しします |
| 5 | 切って炒めたり、スープに入れたりします |

> **他のきのこは戻し水を必ず使うようにと言われますが、ヤマブシタケは例外です。**苦味成分が水に溶け出すため、味見をしてから判断します。白いうちに収穫して湯通ししてから乾燥させたものなら、戻し水は苦くないのでスープに使えます。

### 14-4. 穀物の不足を補う組み合わせ

| 組み合わせ | 効果 |
|:---|:---|
| **きのこ粉 + 穀物の粥** | 穀物に不足するリジンを補い、ビタミンB群とDを加えます |
| **きのこ粉 + 小麦粉・そば粉** | スジェビ（韓国風すいとん）やカルグクス（韓国風の手打ち麺）の練り粉に混ぜます。苦味が薄まります |
| **きのこ + 油** | ビタミンDは脂溶性なので、油と一緒に食べると吸収が良くなります |
| **きのこ + ジャガイモ・サツマイモ** | いも類（塊茎・塊根）で熱量を満たし、きのこでタンパク質を補います |
| **きのこ + テンジャン汁** | テンジャンの強い味が苦味を覆い、うま味が加わります |

> **きのこは熱量源としてではなく、タンパク質と微量栄養素の補充源として使うのが正しいのです。**
> ヤマブシタケの場合、その意味が特にはっきりしています。100gあたり13kcal、タンパク質2.57g、微量栄養素14種を満たし、その中にビタミンD。穀物やいも類（塊茎・塊根）で熱量を満たし、このきのこでタンパク質とビタミンDとB群を補う組み合わせが正確な使い方です。

## 15. 年間作業スケジュール

| 月 | 作業 |
|:--:|:---|
| **1-2月** | **段木の伐採。**落葉後から発芽前まで。おがくず集め。乾燥きのこの状態確認 |
| **3月** | 段木を陰で乾燥（含水率40-45%）。**春作の培地調製と滅菌。**ドラム缶でまとめて |
| **4月** | **段木への接種**（穴をあけて種菌を打ち込む）。おがくず培地の接種と培養 |
| **5月** | **芽出し誘導と初収穫。**表面に傷をつける。15-20℃を維持。すぐに湯通しして乾燥 |
| **6月** | **春作の収穫最盛期。**2-3回目。大量乾燥と粉作り |
| 7月 | 暑いので栽培しません。**35℃を超えると菌糸が死にます。**段木は陰に置き、乾かないようにだけ管理 |
| **8月** | **秋作の培地調製と滅菌。**おがくずとトウモロコシの茎を確保 |
| **9月** | **接種と培養。**22-25℃ |
| **10月** | **芽出し誘導と収穫。**品質が最も良い時期。涼しいため棘が長く苦味が少ないです |
| **11月** | **秋作の収穫最盛期。**大量乾燥。段木からも発生します |
| 12月 | 廃培地を畑に入れます。胞子紋の点検。段木にわらをかけて越冬の準備 |

&nbsp;&nbsp;&nbsp;この日程の要点は、**春と秋の二回作を回し、真夏と真冬は休む**という点です。真夏は菌糸が死ぬ温度であり、真冬は芽出しが止まる温度です。無理に一年中栽培しようとすると失敗し、その空白を夏はサケツバタケが、冬はエノキタケが埋めます。

&nbsp;&nbsp;&nbsp;秋の収穫は春の収穫より品質が良いです。10月から11月の気温が15-20℃で、このきのこの最適範囲にちょうど入るためです。そのため貯蔵用は秋の収穫分で作り、春の収穫分はその都度食べるという配分が良いでしょう。

&nbsp;&nbsp;&nbsp;そして段木への接種を毎年少しずつ増やしていくことが長期戦略です。段木は滅菌が不要で、一度接種すれば数年出るため、年を重ねるほどおがくず培地にかかる燃料と労働が減っていきます。

### 絶対に忘れてはならないこと

| 項目 | 内容 |
|:--:|:---|
