## 1. 災害対策評価

&nbsp;&nbsp;&nbsp;ヤマブシタケは除外作物です。貯蔵性Eと永続性Bが重なり、備蓄が成り立たないという判定を受けました。ゲートを適用しない仮定スコアは42.5点で、有効183種のうち83位に相当します。貯蔵性の面は生のもの基準なので乾燥で解決しますが、このキノコの乾燥には苦味と硬くなることという別の問題が付きます。永続性Bは除外キノコ3種の中で最も良い値です。

### 1-3. 日照SSが意味するもの

&nbsp;&nbsp;&nbsp;評価表の日照項目は、本来40%遮光の条件でどれだけ収量が残るかを問うものです。ジャガイモは80%前後が残り、イネとトウモロコシはさらに大きく落ちます。ヤマブシタケに付いたSSは、その競争に勝ったという意味ではなく、そもそもその軸の上にいないという意味です。菌類には葉緑素がありません。このキノコが使う炭素は、コナラのおがくずにすでに固定されているセルロースとリグニンであり、空の明るさはその蓄えに何の影響も与えません。栽培に必要な光は新聞が読める程度の間接照明であり、それも養分としてではなく形態形成の信号としてのみ使われます。

&nbsp;&nbsp;&nbsp;大規模な火山噴火や核の冬のように日射量が数年にわたって減少する状況で、この違いが決定的に表れます。成層圏にエアロゾルが広がると、穀物といも類(塊茎・塊根)と野菜が同時に崩れます。しかしそのときも倒れた木や枯れた枝はそのまま残っており、それを人が食べられるタンパク質に変える唯一の経路がキノコです。

&nbsp;&nbsp;&nbsp;ヤマブシタケにはここにもう一つが加わります。微量栄養素Aに含まれるビタミンDです。空が暗くなると、人も日光を受ける量が減ります。皮膚で作られるビタミンDが減り、欠乏が起きると骨が弱くなり免疫が落ちます。ところがキノコのエルゴステロールは紫外線を受けるとビタミンD2に変わり、このキノコはそもそも成分表にビタミンDが記載されている珍しい種です。日光が減る災害において、人にビタミンDを供給する経路がキノコであるという点は、偶然ではなく構造です。

> **キノコは、日光が消えた世界でも収量が落ちない唯一の食料源であり、ヤマブシタケはその世界で人に不足するビタミンDまで供給する種です。**

### 1-4. 強みをどう読むか

&nbsp;&nbsp;&nbsp;SSが付いた項目は、タンパク質密度、日照、整地・掘削エネルギー、収量安定性の4つです。Sは収穫速度、連作適応性、味、韓国国内普及度の4つです。Aは微量栄養素、水消費量、調理・加工の3つです。

&nbsp;&nbsp;&nbsp;微量栄養素Aは除外3種の中で最も高い値であり、実質的に最も重要な強みです。充足項目は14種で、その中にビタミンDが含まれています。エノキタケとマッシュルームが13種でBであることと比べると差は一つですが、その一つがビタミンDであるという点が大きいです。災害時によく見られる欠乏はチアミン、リボフラビン、葉酸、鉄、ビタミンDで、このキノコはその5つすべてを満たします。

&nbsp;&nbsp;&nbsp;永続性Bも注目すべき値です。同じ培地で3回から4回収穫できます。エノキタケの2、3回、マッシュルームの2、3周期より優れています。培地を新たに作ることが災害状況で最も大きな労働になるため、一つの培地を長く使えるということは、労働と燃料を節約できるという意味です。

&nbsp;&nbsp;&nbsp;水消費量Aも価値があります。培地の水分を保つ程度で済み、畑単位の灌水は必要ありません。干ばつが重なる災害においてこれは決定的です。イネや野菜が水不足で崩れる条件でも、袋数個分の湿度を保つ水なら確保できます。

&nbsp;&nbsp;&nbsp;自家採種Bも除外3種の中で最も高いです。エノキタケとマッシュルームがCであるのに対し、このキノコは菌糸の継代が比較的容易です。組織培養で切り取った肉片がよく生き、原木栽培に移すと数年続けられます。

&nbsp;&nbsp;&nbsp;そして、評価表に数字として現れない最大の強みがあります。誤認のリスクがほとんどないという点です。12節で取り上げます。

### 1-5. 弱みをどう読むか

&nbsp;&nbsp;&nbsp;Eは3つです。耐寒性、貯蔵性、非食用価値。Dは4つです。施肥、施設負担、温度適応幅、種子寿命。

&nbsp;&nbsp;&nbsp;施設負担Dが最も重いです。このキノコは培地を滅菌する必要があります。121℃の高圧90分が標準で、常圧なら100℃4時間か98℃6時間です。電力がなければ薪でドラム缶を熱する必要があり、その燃料が災害状況で最大の制約になります。さらに袋と瓶が毎周期消耗します。3節でこの問題を取り上げます。まとめると、原木栽培に移すのが答えです。原木は滅菌せず、一度接種すれば数年もちます。

&nbsp;&nbsp;&nbsp;温度適応幅Dと耐寒性Eも合わせて読む必要があります。子実体形成は15-24℃、幅は9℃です。菌糸は22-25℃で育ち、6℃以下や35℃以上では止まります。電力がなければこの窓は季節で合わせます。春と秋が15-24℃に最も近いです。真冬には芽出しが止まり、真夏には菌糸が死ぬため、春秋の作型がこのキノコの自然な形です。

&nbsp;&nbsp;&nbsp;施肥Dは性格を正確に読み取る必要があります。化学肥料は一銭も使いません。代わりに広葉樹のおがくずと米ぬかが㎡当たり年56kg入ります。コナラの林と精米所が近くになければこの条件を満たすのは難しいです。ただし7-3で見るように、稲わらと大豆の殻とトウモロコシの茎でおがくずの20-30%を代替でき、トウモロコシの茎ではむしろ収量が増えたという試験結果があります。

&nbsp;&nbsp;&nbsp;貯蔵性Eは先に述べたとおり乾燥で解決しますが、このキノコでは条件が付きます。そのまま乾燥させると苦く硬くなります。湯通ししてから乾燥させたり粉末にしたりする手順が必要で、13節でそれを取り上げます。

&nbsp;&nbsp;&nbsp;キノコ副産物適応性Cも実質的な制約です。広葉樹のおがくずと米ぬかの2種類だけです。マッシュルームがSで稲わらや糞尿、貝殻、古紙まで使うことと対照的です。針葉樹は樹脂が菌糸を抑制するため使えません。

&nbsp;&nbsp;&nbsp;非食用価値Eは、8項目のうち該当がないという意味です。ただしこの項目が評価するのは薬用、土壌改良、害虫防除といった農業的な用途であり、このキノコに薬理成分がないという意味ではありません。ヘリセノンとエリナシンは神経成長因子の合成を促進すると報告されており、災害のような過酷なストレスが続く状況で精神の健康に役立つ可能性があります。ただし、これは評価項目の範疇には入りません。

## 2. どんな菌類か

### 2-1. 名前と分類

&nbsp;&nbsp;&nbsp;ヤマブシタケは担子菌門ハラタケ綱ベニタケ目サンゴハリタケ科ヤマブシタケ属に属します。注目すべき点は目が異なることです。エノキタケとマッシュルームとシイタケとサケツバタケはすべてハラタケ目(Agaricales)に属しますが、このキノコだけがベニタケ目(Russulales)です。傘も柄もひだもない見た目は、この系統の違いから来ています。

&nbsp;&nbsp;&nbsp;韓国語での名前は、ノロジカの白いお尻に似ているとしてつけられました。英語圏では、ライオンのたてがみに似ているとしてライオンズメインと呼ばれ、日本では、山で修行する僧の衣に似ているとしてヤマブシタケと呼ばれます。三つの名前はいずれも、垂れ下がった白い束の形を指しています。

&nbsp;&nbsp;&nbsp;生態的には広葉樹の枯れた幹や傷んだ部分を分解する白色腐朽菌です。コナラ、クルミ、ブナ、カエデ、ヤナギの樹幹部や枯死木に付いて育ちます。土から生えず必ず木に付いて育ち、たいてい地面より高い場所につきます。この習性が12節で安全確認の根拠になります。

### 2-2. 見た目 - 傘も柄もひだもありません

| 器官 | 特徴 |
|:---|:---|
| 子実体 | **傘を形成しません。**塊のまま5-25cmに育ちます |
| 形態 | 最初は卵形から半球形。生育後期に**白い針状の突起(菌針)が1-5cmの長さで垂れ下がります** |
| **菌針** | 下に垂れ下がった針の束。この表面から胞子を出します |
| 色 | **若い時は純白色 → 育つにつれて黄色または黄褐色** |
| 柄 | 短くて太く、木に付いています。独立した器官とは見なしにくいです |
| ひだ | **ありません。**ひだの代わりに菌針が胞子を出します |
| つば | **ありません** |
| つぼ | **ありません** |
| 肉 | スポンジのように柔らかく白色 |
| 胞子 | 5.5-7.5 × 5-6.5μm。亜球形、無色。胞子紋は白色 |
| 菌糸 | 最初は白色 → 徐々に黄色 → 桃色に変わります |
| 発生基質 | **広葉樹の枯死木と傷んだ部分。地面からは生えません** |

> **傘も柄もひだもなく、白い針の束が木に付いて垂れ下がっている。この一つの形がヤマブシタケの身分証であり、それ自体が安全確認です。**

&nbsp;&nbsp;&nbsp;色の変化を覚えておく必要があります。若い時は純白色で、育つと黄色くなり、さらに時間が経つと黄褐色になります。**黄色みを帯び始めたらもう遅いということです。**味が苦くなり、組織が硬くなります。13節の苦味の問題はこの色の変化と直結しています。

### 2-3. 生活史 - 胞子からキノコまで

&nbsp;&nbsp;&nbsp;キノコの生活史は植物とは異なります。種一粒が一本の木になる植物とは違って、キノコの胞子一粒だけでは単独でキノコになることができません。

| 段階 | 何が起こるか |
|:---|:---|
| 胞子 | 菌針の表面から落ちます。遺伝子を半分だけ持つ単核細胞です |
| 一次菌糸 | 胞子が発芽して糸状に伸びます。遺伝子が半分しかないためキノコを作れず、勢いが弱まって死滅します |
| 二次菌糸 | 交配型の異なる一次菌糸が二つ出会って結合します。この状態になってはじめてキノコを結びます |
| 培地占有 | 白い菌糸がおがくず培地全体を覆います。20-30日 |
| 菌糸の老化 | 白色から黄色、さらに桃色に変わります。正常な成熟過程です |
| 芽出し誘導 | 培地の表面に傷をつけて温度を下げると、粟粒のような白い塊ができます |
| 子実体 | 塊が膨らみ、表面から菌針が垂れ下がります。15-20日 |

&nbsp;&nbsp;&nbsp;胞子一粒だけではキノコが出てこないという事実は、実践において重要です。胞子を惜しんで一粒ずつ慎重に落とすと、一次菌糸だけが育って死滅してしまいます。おびただしい数の胞子の粉を一度にたっぷりと振り入れ、培地の中で互いに出会って結合するように誘導する必要があります。

> **胞子は惜しみません。一粒ではキノコになりません。**

&nbsp;&nbsp;&nbsp;菌糸が黄色や桃色に変わるのはこのキノコの特徴です。他のキノコなら汚染を疑うような色ですが、ヤマブシタケでは正常な成熟です。この点を知らないと、問題のない培地を捨ててしまうことになります。ただし、色の変化と一緒に酸っぱい匂いや粉のような質感が現れたら、それは汚染です。

### 2-4. 生育段階と所要期間

| 段階 | 期間 | 温度 | 湿度 | 何を見るか |
|:---|:---:|:---:|:---:|:---|
| 培地の調製と滅菌 | 1日 | - | 培地水分65-75% | おがくずと米ぬかを混ぜて袋や瓶に詰めます |
| 冷却 | 13-14時間 | 培地18-20℃まで | - | 中心まで冷える必要があります |
| 接種 | - | - | - | 雑菌が入らないよう速やかに |

&nbsp;&nbsp;&nbsp;限界温度を覚えておく必要があります。菌糸は6℃以下と35℃以上で生長を止めます。また、菌糸自身が代謝熱を出すため、周囲の気温が30℃のとき培地内部は35℃を超えることがあります。真夏の培養を避ける理由です。

### 2-5. 培地の酸度が低いです

| 項目 | 基準 | 備考 |
|:---|:---:|:---|
| 培地pH | **4.0-5.5 弱酸性** | 大部分のキノコより低いです |
| 理由 | 酸性の環境で栄養素の分解と吸収がよく進みます | |
| 下げる方法 | 米ぬかを加えると自然に下がります。さらに必要なら酢や有機酸をごく薄めて | |
| 注意 | **草木灰や石灰を入れてはいけません** | アルカリになると菌糸が育ちません |

> **この点が他のキノコと正反対です。**サケツバタケやマッシュルームは草木灰や石灰で培地をアルカリ性にして青カビを抑えます。ヤマブシタケではその方法を使えません。弱酸性を要求するキノコなので、アルカリ処理はそのまま失敗につながります。汚染対策はアルカリではなく、滅菌と種菌量で立てます。
