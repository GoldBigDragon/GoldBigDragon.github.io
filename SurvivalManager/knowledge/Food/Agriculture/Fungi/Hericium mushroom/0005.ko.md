## 8. 수확과 재발생 주기

### 8-1. 수확 시기 판단 - 흰색일 때 땁니다

| 기준 | 내용 |
|:---|:---|
| **최적** | **자실체 전체가 유백색이고 균침이 충분히 늘어졌을 때** |
| 늦은 신호 | **흰색이 노란빛으로 바뀌기 시작합니다** |
| 늦으면 | **쓴맛이 강해지고 조직이 질겨집니다.** 포자를 털기 시작해 가루가 날립니다 |
| 균침 길이 | 1-5cm. 충분히 늘어졌으나 끝이 마르지 않았을 때 |
| 수확 전 관리 | 3-4일 전부터 물을 뿌리지 않습니다 |
| 시간대 | 이른 아침 |

> **노란빛이 돌기 시작하면 이미 늦은 것입니다.** 이 버섯의 쓴맛은 주로 과숙에서 옵니다. 흰색일 때 딴 것은 거의 쓰지 않고, 노랗게 변한 것은 그대로 먹어도 쓰며 말리면 더 씁니다. 13절의 쓴맛 문제를 가장 크게 줄이는 방법은 건조 기술이 아니라 제때 수확하는 것입니다.

&nbsp;&nbsp;&nbsp;노랗게 변한 개체를 버릴 필요는 없습니다. 4절의 포자 채취에 가장 좋은 개체가 바로 이 단계이고, 데쳐서 쓴맛을 우려내면 먹을 수 있습니다. 다만 저장용으로는 쓰지 않습니다.

### 8-2. 따는 요령

&nbsp;&nbsp;&nbsp;자실체 밑동을 손으로 감싸 잡고 살짝 비틀면서 떼어 냅니다. 억지로 잡아당기면 배지가 뜯겨 나가고 그 상처로 잡균이 들어갑니다. 배지에 붙은 밑동 부분은 칼로 깨끗이 잘라 버립니다. 남은 밑동이 썩으면서 세균과 버섯파리를 불러들이기 때문입니다.

&nbsp;&nbsp;&nbsp;수확한 버섯은 **씻지 않습니다.** 스펀지 같은 조직이 물을 빨아들여 하루 만에 노랗게 변하고 무릅니다. 이물이 붙었으면 마른 천이나 부드러운 솔로 털어 냅니다.

&nbsp;&nbsp;&nbsp;그리고 손질은 수확한 그날 합니다. 먹을 것은 그대로 조리하고, 저장할 것은 그날 찢어 말리기 시작합니다. 하루를 미루면 색이 변하고 쓴맛이 올라옵니다.

### 8-3. 재발생

| 항목 | 내용 |
|:---|:---|
| 휴양 기간 | 수확 후 10-15일 |
| 휴양 중 관리 | 표면의 남은 밑동을 제거하고, 습도를 유지하며 22-25℃에 둡니다 |
| **재발이 유도** | **표면에 다시 상처를 냅니다.** 이것이 재발생률을 가장 높입니다 |
| 2주기 수량 | 1주기의 50-70% |
| 3-4주기 | 점차 줄어듭니다 |
| 총 수확 횟수 | **3-4회.** 배제 버섯 세 종 가운데 가장 많습니다 |
| 원목재배 | 해마다 봄가을로 수년간 |

&nbsp;&nbsp;&nbsp;평가표의 영속성 B가 이 표의 내용입니다. 팽이버섯이 두세 번(D), 양송이가 두세 주기(C)인 데 비해 이 버섯은 세 번에서 네 번입니다. 배지를 새로 만드는 일이 재난 상황에서 가장 큰 노동이므로, 한 배지에서 한 번 더 거둔다는 것은 곧 연료와 노동을 아낀다는 뜻입니다.

&nbsp;&nbsp;&nbsp;휴양 기간에 배지가 마르지 않게 하는 것이 중요합니다. 마르면 균사가 죽어 재발생이 없습니다. 다만 물을 직접 붓지 않고 주변 습도로 유지합니다.

### 8-4. 수량

| 방식 | 수량 | 기간 |
|:---|:---|:---:|
| 병재배 850ml | 356g | 40-45일 |
| 봉지재배 2,500ml | 810g | 50-60일 |
| **원목재배 0.1세㎡** | **1,195.5g** | 69일 이상, 이후 수년 |
| 생물학적 효율(원목, 참나무) | 17.3% | |
| 옥수숫대 20% 대체 | 생체중 유의적 증가 | |

&nbsp;&nbsp;&nbsp;봉지 하나에서 810g이 나옵니다. 생것 810g은 105kcal, 단백질 21g입니다. 열량으로는 거의 의미가 없고 단백질과 비타민 D와 B군으로 의미가 있습니다. 봉지 스무 개를 한 묶음으로 돌리면 봄과 가을에 각각 한 달 남짓 날마다 한 줌씩 나오는 규모입니다.

> **노루궁뎅이버섯 수확량을 열량으로 환산해 계획을 세우면 실망합니다. 대신 비타민 D를 포함한 미량 영양소 14종을 대는 부식이며, 고기가 끊긴 상황에서 게살 비슷한 씹는 맛을 주는 식재료라는 점으로 가치를 매기는 것이 옳습니다.**

## 9. 오염과 병해충

### 9-1. 푸른곰팡이가 첫째 원인입니다

&nbsp;&nbsp;&nbsp;재난 상황의 버섯 재배가 실패하는 가장 흔한 원인은 병해충이 아니라 경쟁 곰팡이에게 배지를 빼앗기는 것입니다. 그중 압도적으로 많은 것이 트리코데르마(Trichoderma), 우리말로 푸른곰팡이입니다. 노루궁뎅이버섯은 살균 배지를 쓰고 배지가 약산성이라 이 위험이 특히 큽니다. **푸른곰팡이는 약산성을 좋아합니다.**

| 구분 | 노루궁뎅이버섯 균사 | 푸른곰팡이 |
|:---|:---|:---|
| 색 | 흰색 → 연노랑 → 연분홍(정상 성숙) | 처음엔 흰색, 곧 **청록색** |
| 질감 | 균사 실이 엉킨 층. 탄력이 있습니다 | **가루처럼 미세하고 퍼석합니다** |
| 퍼지는 속도 | 하루 3-5mm | 하루 10-30mm, **3-6배 빠름** |
| 냄새 | 숲 흙 냄새, 버섯 향 | 쿰쿰한 냄새, 때로 코코넛 비슷한 향 |
| 경계 | 배지를 따라 고르게 | 둥근 반점에서 방사상으로 |

> **푸른곰팡이는 색이 보이기 전에 이미 퍼져 있습니다.**
> 청록색은 포자가 맺힌 단계, 곧 번식을 시작한 뒤입니다. 그 시점에는 이미 배지 상당 부분을 잃었다고 보아야 합니다. 초기 판별은 색이 아니라 퍼지는 속도와 질감으로 합니다.

> **그리고 이 버섯에서는 균사 자신이 노랗고 분홍빛으로 변하므로 색만으로 판단하면 멀쩡한 배지를 버립니다.** 반드시 질감과 냄새와 속도를 함께 봅니다.

### 9-2. 알칼리 처리를 쓸 수 없습니다

&nbsp;&nbsp;&nbsp;독청버섯아재비와 양송이는 배지와 복토를 나무재나 석회로 알칼리로 만들어 푸른곰팡이를 억제합니다. 노루궁뎅이버섯은 배지 산도가 4.0에서 5.5여야 하므로 이 방법을 쓸 수 없습니다. 알칼리로 만들면 푸른곰팡이는 줄지만 버섯 균사도 자라지 않습니다.

| 그래서 쓸 수 있는 방법 | 원리 |
|:---|:---|
| **살균을 충분히 합니다** | 상압 100℃ 4-6시간. 아끼면 반드시 대가를 치릅니다 |
| **종균을 넉넉히 넣습니다** | 배지 무게의 5-10%. 먼저 자리를 차지한 쪽이 이깁니다 |
| **영양원을 30% 넘기지 않습니다** | 미강과 밀기울이 많으면 경쟁 곰팡이가 먼저 폭발합니다 |
| **용기 사이에 틈을 두어 쌓습니다** | 공기가 통해야 대사열이 빠지고 곰팡이가 번지지 않습니다 |
| **비 온 직후에 접종합니다** | 공기 중 낙하 포자가 가장 적습니다 |
| **배양 장소를 해마다 바꿉니다** | 같은 자리를 계속 쓰면 포자가 누적됩니다 |
| **원목재배로 넘깁니다** | **나무 껍질과 목질 자체가 방어벽입니다** |

> **오염 문제를 근본적으로 피하는 길은 원목재배입니다.** 살균하지 않으므로 살균 실패가 없고, 나무의 조직과 껍질이 잡균 침입을 막고, 접종한 균사가 몇 해에 걸쳐 나무 전체를 장악합니다. 톱밥 배지가 푸른곰팡이에 자꾸 무너진다면 방법을 바꾸는 편이 낫습니다.

### 9-3. 오염을 발견했을 때

| 상황 | 대처 |
|:---|:---|
| **한 용기 표면에 작은 반점** | 그 용기만 즉시 꺼냅니다. **열지 않고** 옮깁니다 |
| **여러 용기에 번졌다** | 배양 장소 전체를 옮깁니다. 원래 장소는 비우고 물로 씻어 말립니다 |
| **배지 전체가 청록색** | 전량 폐기합니다. 태우거나 재배지에서 멀리 떨어진 곳에 묻습니다 |
| **배지에서 시큼한 냄새** | 세균입니다. 폐기하고 다음 주기 살균 시간을 늘립니다 |

> **오염된 배지를 퇴비로 돌리지 마십시오.**
> 푸른곰팡이 포자는 퇴비 더미에서 살아남아 이듬해 배지에 다시 들어옵니다. 반드시 태우거나 재배지와 분리된 곳에 깊이 묻습니다.

### 9-4. 해충

| 해충 | 피해 | 대처 |
|:---|:---|:---|
| **버섯파리(시아리드)** | 균사를 파먹고 자실체에 구더기가 듭니다. 푸른곰팡이 포자를 옮깁니다 | 입구를 고운 천으로 막아 물리적으로 차단합니다. 발생 시 물그릇 트랩이나 끈끈이 |
| **응애** | 균사가 갈색으로 변하며 자라지 않습니다 | 건조하게 관리하고 발생 구획은 격리합니다 |
| **민달팽이** | 어린 자실체를 뜯어먹습니다. 균침이 부드러워 특히 잘 당합니다 | 재나 톱밥 띠를 둘러 막습니다. 밤에 손으로 잡습니다 |
| **다람쥐, 쥐, 새** | 원목재배에서 자실체를 물어갑니다 | 그물을 씌우거나 가시나무 가지를 둘러 둡니다 |

&nbsp;&nbsp;&nbsp;민달팽이 피해가 이 버섯에서 특히 큽니다. 갓이 없고 조직이 부드러워 어디서든 파먹기 쉽습니다. 야외 원목재배에서는 원목 밑에 재를 둘러 띠를 만들고, 비 온 뒤 밤에 살펴 손으로 잡습니다.

&nbsp;&nbsp;&nbsp;약제가 없는 상황에서 방제는 구조와 위생으로 합니다. 환기구에 고운 천을 두 겹 씌우고, 수확이 끝난 배지를 재배 장소 옆에 쌓아 두지 않으며, 떨어진 자실체 조각을 그때그때 치웁니다.

| 자실체가 노랗게 변색 | 과숙, 온도 22℃ 초과, 직사광선 | 제때 수확하고 더 서늘하고 그늘진 곳으로 옮깁니다 |
| 균침 끝이 갈색으로 마름 | 공기가 너무 건조함 | 주변에 물을 뿌려 습도를 올립니다 |
| 자실체가 물러지고 갈색 물이 남 | **버섯에 직접 물이 닿았음.** 세균성 무름 | 물을 버섯에 뿌리지 않습니다. 환기하고 병든 것은 치웁니다 |
| 자실체가 작고 여러 개로 갈라짐 | 상처를 너무 많이 냈음 | 다음 주기에 상처를 한두 군데만 냅니다 |
| 2주기 수량이 거의 없음 | 배지 양분 소진, 휴양 중 배지가 마름 | 습도를 유지하고 표면에 다시 상처를 냅니다 |
| 배지가 검고 시큼함 | 세균 번식, 배지 수명 끝 | 폐기하고 폐배지로 돌립니다 |

## 11. 폐배지 순환

### 11-1. 폐배지는 버리는 것이 아닙니다

&nbsp;&nbsp;&nbsp;버섯이 다 나온 뒤의 배지는 균사가 목질을 분해해 놓은 유기물입니다. 백색부후균이 리그닌을 상당 부분 분해해 두었으므로 생톱밥보다 훨씬 밭에 넣기 좋습니다. 평가표의 시비 D가 연 56kg의 유기물 투입을 가리키는데, 그 56kg이 한 번 쓰고 사라지는 것이 아니라 돌고 있다는 점이 중요합니다.

| 용도 | 방법 |
|:---|:---|
| **밑거름** | 가을에 밭에 펴서 갈아 넣습니다. 유기물과 칼륨 공급이 큽니다 |
| **멀칭재** | 작물 사이에 5cm 두께로 깔아 잡초와 수분 증발을 막습니다 |
| **다른 버섯 배지** | 독청버섯아재비의 목재칩 배지에 섞어 쓸 수 있습니다 |
| **퇴비 촉진제** | 퇴비 더미에 섞으면 분해가 빨라집니다 |
| **지렁이 사육 기질** | 지렁이가 잘 먹습니다. 분변토를 얻을 수 있습니다 |
| **모판 흙** | 모래와 섞으면 육묘용 상토가 됩니다 |
| **땔감** | 완전히 말리면 불땀이 약하지만 탑니다 |

```
활엽수 톱밥 + 미강 → 배지 → 버섯 수확(3-4회) → 폐배지 → 밭 유기물
                                                  └ 지렁이 → 분변토
```

&nbsp;&nbsp;&nbsp;다만 주의가 있습니다. 노루궁뎅이버섯 폐배지는 아직 목질이 상당히 남아 있어 탄질비가 높습니다. 생톱밥만큼은 아니지만 그대로 밭에 많이 넣으면 미생물이 분해하면서 흙의 질소를 끌어다 씁니다. 대책은 두 가지입니다. 폐배지를 따로 몇 달 쌓아 더 썩힌 뒤 넣거나, 오줌이나 계분 같은 질소원을 함께 넣습니다.

&nbsp;&nbsp;&nbsp;오염된 배지는 절대 밭이나 퇴비에 돌리지 않습니다. 푸른곰팡이 포자가 이듬해 배지로 그대로 들어옵니다.

### 11-2. 원목재배 뒤의 나무

| 상태 | 활용 |
|:---|:---|
| 버섯이 다 난 원목 | 푸슬푸슬해져 손으로 부서집니다. 그대로 밭에 넣거나 멀칭재로 씁니다 |
| 아직 단단한 원목 | 균사가 살아 있다면 쪼개어 새 원목 접종용으로 씁니다 |
| 완전히 삭은 원목 | 부엽토에 가까운 상태입니다. 화분 흙이나 모판 흙으로 좋습니다 |

### 11-3. 재배 공간의 연차 관리

| 연차 | 관리 |
|:--:|:---|
| 주기마다 | 장소를 비우고 물로 씻어 햇볕에 말립니다 |
| 1년 | 같은 장소를 계속 써도 괜찮습니다 |
| 2-3년 | 장소를 옮기는 것이 안전합니다. 잡균 포자가 누적됩니다 |
| 비상 조치 | 벽과 바닥에 석회 유황물이나 진한 나무재 잿물을 바릅니다 |

&nbsp;&nbsp;&nbsp;벽과 바닥에는 알칼리를 써도 됩니다. 배지가 아니라 공간이므로 산도 제약을 받지 않습니다. 한 주기를 끝내면 빈 공간을 며칠 비워 두고 문을 열어 햇빛이 들게 합니다. 자외선이 낙하 포자를 상당히 줄입니다. 전력도 약품도 필요 없는 방법입니다.
