## 8. 収穫と再発生周期

### 8-1. 収穫時期の判断——白いうちに収穫します

| 基準 | 内容 |
|:---|:---|
| **最適** | **子実体全体が乳白色で、棘が十分に伸びたとき** |
| 遅れた兆候 | **白色が黄色みを帯び始めます** |
| 遅れると | **苦味が強くなり、組織が硬く筋張ります。**胞子を放出し始め、粉が舞います |
| 棘の長さ | 1-5cm。十分に伸びているが先端が乾いていないとき |
| 収穫前の管理 | 3-4日前から水をかけません |
| 時間帯 | 早朝 |

> **黄色みを帯び始めたら、すでに遅れています。**このきのこの苦味は主に過熟から来ます。白いうちに収穫したものはほとんど苦くなく、黄色く変わったものはそのまま食べても苦く、乾燥させるとさらに苦くなります。13節の苦味の問題を最も大きく減らす方法は、乾燥技術ではなく適期収穫です。

&nbsp;&nbsp;&nbsp;黄色く変わった個体を捨てる必要はありません。4節の胞子採取に最も良い個体はまさにこの段階のもので、湯通しして苦味を抜けば食べられます。ただし貯蔵用には使いません。

### 8-2. 収穫のコツ

&nbsp;&nbsp;&nbsp;子実体の根元を手で包むように持ち、軽くひねりながら取り外します。無理に引っ張ると培地がむしり取られ、その傷から雑菌が入ります。培地に残った根元部分はナイフできれいに切り取ります。残った根元が腐って細菌やきのこバエを呼び込むためです。

&nbsp;&nbsp;&nbsp;収穫したきのこは**洗いません。**スポンジのような組織が水を吸い込み、一日で黄色く変わって傷みます。異物が付いていたら乾いた布や柔らかいブラシで払い落とします。

&nbsp;&nbsp;&nbsp;そして手入れは収穫したその日に行います。食べる分はそのまま調理し、貯蔵する分はその日のうちにちぎって乾燥を始めます。一日でも遅らせると色が変わり、苦味が出てきます。

### 8-3. 再発生

| 項目 | 内容 |
|:---|:---|
| 休養期間 | 収穫後10-15日 |
| 休養中の管理 | 表面に残った根元を取り除き、湿度を保ちながら22-25℃に置きます |
| **再芽出し誘導** | **表面に再び傷をつけます。**これが再発生率を最も高めます |
| 2回目の収量 | 1回目の50-70% |
| 3-4回目 | 徐々に減っていきます |
| 総収穫回数 | **3-4回。**除外ゲートが適用される3種のきのこの中で最も多いです |
| 段木栽培 | 毎年春と秋に、数年間にわたって |

&nbsp;&nbsp;&nbsp;評価表の永続性Bは、この表の内容を反映したものです。エノキタケが2-3回（D）、マッシュルームが2-3周期（C）であるのに対し、このきのこは3回から4回です。培地を新しく作ることが災害状況における最大の労働であるため、一つの培地からもう一度収穫できるということは、燃料と労働を節約できるということを意味します。

&nbsp;&nbsp;&nbsp;休養期間中は培地を乾かさないことが重要です。乾くと菌糸が死んで再発生しません。ただし水を直接注ぐのではなく、周囲の湿度で保ちます。

### 8-4. 収量

| 方式 | 収量 | 期間 |
|:---|:---|:---:|
| 瓶栽850ml | 356g | 40-45日 |
| 袋栽2,500ml | 810g | 50-60日 |
| **段木栽培0.1㎡** | **1,195.5g** | 69日以上、その後数年 |
| 生物学的効率（段木、コナラ類） | 17.3% | |
| トウモロコシの茎20%代替 | 生体重が有意に増加 | |

&nbsp;&nbsp;&nbsp;袋一つから810gが採れます。生の状態で810gは105kcal、タンパク質21gです。熱量としてはほとんど意味がなく、タンパク質とビタミンD、ビタミンB群として意味があります。袋20個を一まとめにして回せば、春と秋にそれぞれ一ヶ月余り、毎日一握りずつ採れる規模になります。

> **ヤマブシタケの収穫量を熱量に換算して計画を立てると失望します。**そうではなく、ビタミンDを含む微量栄養素14種を供給する副食であり、肉が絶えた状況でカニ肉に似た歯ごたえを与える食材であるという点で価値を評価するのが正しいのです。

## 9. 汚染と病害虫

### 9-1. 青カビが第一の原因です

&nbsp;&nbsp;&nbsp;災害状況でのきのこ栽培が失敗する最も多い原因は、病害虫ではなく競合するカビに培地を奪われることです。その中で圧倒的に多いのがトリコデルマ（Trichoderma）、いわゆる青カビです。ヤマブシタケは滅菌培地を使い、培地が弱酸性であるため、この危険が特に大きくなります。**青カビは弱酸性を好みます。**

| 区分 | ヤマブシタケの菌糸 | 青カビ |
|:---|:---|:---|
| 色 | 白色 → 淡黄色 → 淡いピンク（正常な成熟） | 最初は白色、すぐに**青緑色** |
| 質感 | 菌糸の糸が絡み合った層。弾力があります | **粉のように細かくパサパサしています** |
| 広がる速度 | 1日3-5mm | 1日10-30mm、**3-6倍速い** |
| 匂い | 森の土の匂い、きのこの香り | むっとする匂い、時にココナッツに似た香り |
| 境界 | 培地に沿って均一に | 丸い斑点から放射状に |

> **青カビは色が見える前に、すでに広がっています。**
> 青緑色は胞子が形成された段階、つまり繁殖を始めた後です。その時点では、すでに培地のかなりの部分を失ったと見るべきです。初期の判別は色ではなく、広がる速度と質感で行います。

> **しかもこのきのこでは菌糸自体が黄色やピンク色に変わるため、色だけで判断すると問題のない培地を捨ててしまいます。**必ず質感と匂いと速度を合わせて確認します。

### 9-2. アルカリ処理は使えません

&nbsp;&nbsp;&nbsp;サケツバタケやマッシュルームは、培地や覆土を草木灰や石灰でアルカリ性にして青カビを抑えます。ヤマブシタケは培地のpHが4.0から5.5でなければならないため、この方法は使えません。アルカリ性にすれば青カビは減りますが、きのこの菌糸も育たなくなります。

| そのため使える方法 | 原理 |
|:---|:---|
| **滅菌を十分に行います** | 常圧100℃で4-6時間。手間を惜しむと必ず代償を払います |
| **種菌を十分に入れます** | 培地重量の5-10%。先に場所を占めた側が勝ちます |
| **栄養源を30%を超えないようにします** | 米ぬかや麦ふすまが多いと、競合するカビが先に爆発的に増えます |
| **容器の間に隙間を空けて積みます** | 空気が通ることで代謝熱が抜け、カビが広がりません |
| **雨が降った直後に接種します** | 空気中に落下する胞子が最も少なくなります |
| **培養場所を毎年変えます** | 同じ場所を使い続けると胞子が積み重なります |
| **段木栽培に切り替えます** | **樹皮と木質そのものが防御壁です** |

> **汚染問題を根本的に避ける道は段木栽培です。**滅菌しないので滅菌失敗がなく、木の組織と樹皮が雑菌の侵入を防ぎ、接種した菌糸が数年かけて木全体を占領します。おがくず培地が青カビにたびたび負けるなら、方法を変えたほうがよいでしょう。

### 9-3. 汚染を発見したとき

| 状況 | 対処 |
|:---|:---|
| **一つの容器の表面に小さな斑点** | その容器だけ直ちに取り出します。**開けずに**移動します |
| **複数の容器に広がった** | 培養場所全体を移します。元の場所は空にして水で洗い、乾かします |
| **培地全体が青緑色** | 全量廃棄します。燃やすか、栽培地から遠く離れた場所に埋めます |
| **培地から酸っぱい匂い** | 細菌です。廃棄し、次の周期の滅菌時間を延ばします |

> **汚染された培地を堆肥に回してはいけません。**
> 青カビの胞子は堆肥の山の中でも生き残り、翌年の培地に再び入り込みます。必ず燃やすか、栽培地と離れた場所に深く埋めます。

### 9-4. 害虫

| 害虫 | 被害 | 対処 |
|:---|:---|:---|
| **キノコバエ（シアリッド）** | 菌糸を食い荒らし、子実体にウジが入ります。青カビの胞子を運びます | 入り口を細かい布でふさいで物理的に遮断します。発生時は水皿トラップや粘着シート |
| **ダニ** | 菌糸が茶色に変わり、育たなくなります | 乾燥した状態で管理し、発生した区画は隔離します |
| **ナメクジ** | 幼い子実体を食いちぎります。棘が柔らかく特に被害を受けやすいです | 灰やおがくずの帯を巡らせて防ぎます。夜に手で捕まえます |
| **リス、ネズミ、鳥** | 段木栽培で子実体をくわえて持っていきます | 網をかけるか、棘のある木の枝を巡らせます |

&nbsp;&nbsp;&nbsp;ナメクジの被害はこのきのこで特に大きくなります。傘がなく組織が柔らかいため、どこからでも食いつきやすいのです。野外の段木栽培では、段木の下に灰を巡らせて帯を作り、雨上がりの夜に見回って手で捕まえます。

&nbsp;&nbsp;&nbsp;薬剤がない状況では、防除は構造と衛生で行います。換気口に細かい布を二重にかぶせ、収穫が終わった培地を栽培場所の隣に積んでおかず、落ちた子実体の切れ端はその都度片付けます。

## 10. 生育異常の診断

| 症状 | 原因 | 対処 |
|:---|:---|:---|
| 接種5日後も菌糸が見えない | 培地が熱いときに接種した、種菌が死んでいた | 培地を18-20℃まで冷まして再接種します |
| 菌糸が伸びる途中で止まる | **培地温度35℃超過**、水分不足 | 容器の間を広げて熱を抜き、周囲の気温を下げます |
| 菌糸が黄色・ピンク色に変わる | **正常な成熟です** | そのままにします。質感と匂いが正常なら問題ありません |
| 菌糸は良いのにきのこが出ない | **表面に傷をつけていない**、温度を下げていない、光が全くない | 表面を突いて傷をつけ、15-20度に移し、弱い光を入れます |
| 原基が形成された後、乾いて枯れる | 湿度不足 | 水皿と湿った布で85-95%まで上げます |
| **子実体がサンゴやカリフラワーのように裂ける** | **二酸化炭素過多。**換気不足 | 換気を大幅に増やします |
| **棘が伸びずに固まって団子状になる** | **光不足** | 新聞が読める程度の間接光を入れます |
| 子実体が黄色く変色 | 過熟、温度22℃超過、直射日光 | 適期に収穫し、より涼しく陰になった場所に移します |
| 棘の先が茶色く乾く | 空気が乾燥しすぎている | 周囲に水をまいて湿度を上げます |
| 子実体が軟らかくなり、茶色い液が出る | **きのこに直接水が触れた。**細菌性の腐敗 | きのこに水をかけません。換気し、病んだものは取り除きます |
| 子実体が小さく複数に分かれる | 傷をつけすぎた | 次の周期では傷を一、二箇所だけにします |
| 2回目の収量がほとんどない | 培地の養分が尽きた、休養中に培地が乾いた | 湿度を保ち、表面に再び傷をつけます |
| 培地が黒く酸っぱい | 細菌の増殖、培地の寿命が尽きた | 廃棄して廃培地に回します |

## 11. 廃培地の循環

### 11-1. 廃培地は捨てるものではありません

&nbsp;&nbsp;&nbsp;きのこを採り終えた後の培地は、菌糸が木質を分解しておいた有機物です。白色腐朽菌がリグニンをかなりの部分まで分解しているため、生のおがくずよりずっと畑に入れやすくなっています。評価表の施肥Dは年間56kgの有機物投入を指していますが、その56kgが一度使って消えるのではなく、循環しているという点が重要です。

| 用途 | 方法 |
|:---|:---|
| **元肥** | 秋に畑に広げてすき込みます。有機物とカリウムの供給が大きいです |
| **マルチング材** | 作物の間に5cmの厚さで敷き、雑草と水分の蒸発を防ぎます |
| **他のきのこの培地** | サケツバタケの木材チップ培地に混ぜて使えます |
| **堆肥促進材** | 堆肥の山に混ぜると分解が速くなります |
| **ミミズ養殖の基質** | ミミズがよく食べます。糞土を得られます |
| **育苗用の床土** | 砂と混ぜると育苗用の床土になります |
| **薪** | 完全に乾かせば火力は弱いですが燃えます |

```
広葉樹おがくず + 米ぬか → 培地 → きのこ収穫（3-4回） → 廃培地 → 畑の有機物
                                          └ ミミズ → 糞土
```

&nbsp;&nbsp;&nbsp;ただし注意点があります。ヤマブシタケの廃培地はまだ木質がかなり残っているため、炭素窒素比（C/N比）が高くなっています。生のおがくずほどではありませんが、そのまま畑に多く入れると、微生物が分解する際に土の窒素を奪って使います。対策は二つです。廃培地を別に数ヶ月積んでさらに熟成させてから入れるか、尿や鶏糞のような窒素源を一緒に入れます。

&nbsp;&nbsp;&nbsp;汚染された培地は絶対に畑や堆肥に回しません。青カビの胞子が翌年の培地にそのまま入り込みます。

### 11-2. 段木栽培後の木材

| 状態 | 活用 |
|:---|:---|
| きのこを出し終えた段木 | ぼろぼろになって手で崩れます。そのまま畑に入れるか、マルチング材として使います |
| まだ硬い段木 | 菌糸が生きていれば割って新しい段木の接種用に使います |
| 完全に腐った段木 | 腐葉土に近い状態です。鉢植えの土や育苗用の床土に適しています |

### 11-3. 栽培空間の年次管理

| 年次 | 管理 |
|:--:|:---|
| 周期ごと | 場所を空にして水で洗い、日光で乾かします |
| 1年 | 同じ場所を続けて使っても構いません |
| 2-3年 | 場所を移すのが安全です。雑菌の胞子が積み重なります |
| 緊急対策 | 壁と床に石灰硫黄合剤や濃い木灰の灰汁を塗ります |

&nbsp;&nbsp;&nbsp;壁と床にはアルカリを使っても構いません。培地ではなく空間なので、酸度の制約を受けません。一つの周期を終えたら、空いた場所を数日そのままにして、戸を開けて日光を入れます。紫外線が落下する胞子をかなり減らします。電力も薬品も必要としない方法です。
