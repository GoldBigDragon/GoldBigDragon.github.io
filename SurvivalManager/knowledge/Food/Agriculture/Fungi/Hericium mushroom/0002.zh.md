## 1. 灾害应对评价

&nbsp;&nbsp;&nbsp;猴头菇是被排除的作物。它被判定为耐储性E与持续性B叠加，导致储备无法成立。不适用关卡时的假定得分为42.5分，在183个有效种中排第83位。耐储性方面是以鲜品为基准评定的，可以通过干燥解决，但这种菌类的干燥另外附带苦味和变韧这两个问题。持续性B是三种被排除菌类中最好的数值。

### 1-3. 光照SS意味着什么

&nbsp;&nbsp;&nbsp;评价表中的光照项目，本来问的是在40%遮光条件下产量能剩下多少。马铃薯能剩下80%左右，水稻和玉米下降得更多。猴头菇的SS并不意味着在这场竞争中获胜，而是说它压根就不在这条轴线上。菌类没有叶绿素。这种菌类使用的碳，是早已固定在橡木木屑中的纤维素和木质素，天空的明暗对这份储备毫无影响。栽培所需的光只是能看清报纸字迹程度的间接照明，而且这光也不是用作养分，只是形态形成的信号。

&nbsp;&nbsp;&nbsp;在大规模火山喷发或核冬天那样日照量持续数年下降的情况下，这种差异会决定性地显现出来。平流层布满气溶胶后，谷物、薯类（块茎/块根）和蔬菜会同时崩溃。可是即便在那种时候，倒下的树木和枯枝依然存在，而把它们变成人可以食用的蛋白质的唯一途径，就是菌类。

&nbsp;&nbsp;&nbsp;猴头菇在这一点上还多了一层。那就是微量营养素A中包含的维生素D。天空变暗后，人接受的日照也会减少。皮肤合成的维生素D随之减少，一旦缺乏就会骨骼变弱、免疫力下降。而菌类中的麦角固醇经紫外线照射会转变为维生素D2，这种菌类本身就是成分表上罕见地标有维生素D的物种。在日照减少的灾害中，为人体提供维生素D的途径正是菌类，这不是偶然，而是结构性的。

> **菌类是在阳光消失的世界里唯一产量不会减少的食物来源，而猴头菇是在那个世界里还能为人补上即将缺乏的维生素D的物种。**

### 1-4. 如何解读优势

&nbsp;&nbsp;&nbsp;获得SS的项目有蛋白质密度、光照、整地·挖掘能耗、产量稳定性四项。S有收获速度、连作适应性、口味、韩国国内普及度四项。A有微量营养素、耗水量、烹饪·加工三项。

&nbsp;&nbsp;&nbsp;微量营养素A是三种被排除菌类中最高的数值，实质上也是最重要的优势。满足的项目有14种，其中包含维生素D。与金针菇和双孢蘑菇同为13种、评级B相比只差一种，但这一种正是维生素D，意义重大。灾害情境下常见的缺乏营养素是硫胺素、核黄素、叶酸、铁和维生素D，而这种菌类恰好把这五项全部满足了。

&nbsp;&nbsp;&nbsp;持续性B也是值得关注的数值。同一培养基能收获三到四次，胜过金针菇的两三次和双孢蘑菇的两三个周期。重新制作培养基是灾害情境下最大的劳动负担，因此一份培养基能用得久，就意味着省下劳动和燃料。

&nbsp;&nbsp;&nbsp;耗水量A同样很有价值。只需维持培养基水分即可，不需要田地规模的灌溉用水。在旱灾叠加的灾害情境下，这一点是决定性的。即便在水稻和蔬菜因缺水而崩溃的条件下，维持几个菌袋湿度所需的水依然能够确保。

&nbsp;&nbsp;&nbsp;自家留种B也是三种被排除菌类中最高的。相比金针菇和双孢蘑菇的C级，这种菌类的菌丝传代相对容易。用组织分离法切下的小块存活率高，转入段木栽培后能延续好几年。

&nbsp;&nbsp;&nbsp;而且还有一个评价表数字上体现不出来的最大优势，那就是几乎没有误认的风险。这一点将在第12节讨论。

### 1-5. 如何解读劣势

&nbsp;&nbsp;&nbsp;E有三项：耐寒性、耐储性、非食用价值。D有四项：施肥需求、设施负担、温度适应幅度、种子寿命。

&nbsp;&nbsp;&nbsp;设施负担D是最重的一项。这种菌类必须对培养基灭菌。标准是121℃高压90分钟，常压则需100℃4小时或98℃6小时。没有电力时就得靠柴火烧热油桶，而这份燃料正是灾害情境下最大的制约。而且塑料袋和瓶子每个周期都要消耗。第3节会讨论这个问题。概括来说，答案是转向段木栽培。原木不需要灭菌，接种一次能维持数年。

&nbsp;&nbsp;&nbsp;温度适应幅度D和耐寒性E也要一并解读。子实体形成需要15-24℃，幅度为9℃。菌丝在22-25℃生长，低于6℃或高于35℃则停止。没有电力时，这个窗口只能靠季节来配合。春秋两季最接近15-24℃。寒冬时出菇会停止，盛夏时菌丝会死亡，因此春秋两茬是这种菌类自然而然的栽培形态。

&nbsp;&nbsp;&nbsp;施肥需求D的性质需要准确理解。化肥一分不用，但阔叶树木屑和米糠每年每平方米要投入56kg。如果附近没有橡树林和碾米厂，很难满足这个条件。不过正如7-3所示，稻草、豆荚和玉米秸秆可以替代20-30%的木屑，而玉米秸秆的试验结果显示产量反而有所增加。

&nbsp;&nbsp;&nbsp;耐储性E如前所述可以通过干燥解决，但这种菌类附带条件。直接晒干会变苦变硬，需要先焯水再晒干，或者磨成粉，第13节会讨论这个方法。

&nbsp;&nbsp;&nbsp;菌菇副产物适应性C也是实质性的限制，只有阔叶树木屑和米糠这两种。这与双孢蘑菇的S级形成对比，后者连稻草、粪肥、贝壳和废纸都能利用。针叶树因树脂会抑制菌丝，无法使用。

&nbsp;&nbsp;&nbsp;非食用价值E的意思是在8个项目中都不符合。但这个项目评估的是药材、土壤改良、害虫防治等农业用途，并不代表这种菌类没有药理成分。据报道，猴头菌酮和猴头菌素能促进神经生长因子的合成，在灾害这类极端压力持续存在的情况下，可能对精神健康有帮助。不过这不属于评价项目的范畴。

## 2. 这是一种什么样的菌类

### 2-1. 名称与分类

&nbsp;&nbsp;&nbsp;猴头菇属于担子菌门伞菌纲红菇目猴头菌科猴头菌属。值得注意的是，它的目与其他菌类不同。金针菇、双孢蘑菇、香菇和大球盖菇都属于伞菌目（Agaricales），唯独这种菌类属于红菇目（Russulales）。没有菌盖、菌柄和菌褶的外观，正是来自这一分类系统上的差异。

&nbsp;&nbsp;&nbsp;韩语名称因像獐子雪白的臀部而得名。英语圈因像狮子的鬃毛而称其为狮鬃菇（lion's mane），日本因像山中修行僧的衣饰而称其为山伏茸。三个名字指的都是那垂坠的白色簇状外形。

&nbsp;&nbsp;&nbsp;从生态上看，它是分解阔叶树枯干与伤口的白腐菌。它附生在橡树、核桃树、水青冈、枫树、柳树的树干部或枯木上生长。它不生长于地面，必定附着在树木上生长，通常长在离地面较高的地方。这一习性正是第12节安全确认的依据。

### 2-2. 外观——没有菌盖、菌柄和菌褶

| 器官 | 特征 |
|:---|:---|
| 子实体 | **不形成菌盖。** 整体呈块状生长，5-25cm |
| 形态 | 初期为卵形至半球形。生长后期**白色针状突起（菌刺）垂下，长1-5cm** |
| **菌刺** | 向下垂坠的针状束。孢子从这个表面产生 |
| 颜色 | **幼时纯白色 → 随生长变为黄色或黄褐色** |
| 柄 | 短而粗钝，附着于木材上，难以视为独立的器官 |
| 菌褶 | **没有。** 由菌刺代替菌褶产生孢子 |
| 菌环 | **没有** |
| 菌托 | **没有** |
| 菌肉 | 如海绵般柔软，白色 |
| 孢子 | 5.5-7.5 × 5-6.5μm。近球形，无色。孢子印为白色 |
| 菌丝 | 起初为白色 → 逐渐变黄 → 变为粉红色 |
| 发生基质 | **阔叶树枯木与伤口部位，不生长于地面** |

> **没有菌盖、菌柄和菌褶，白色的针束附着在树上垂坠而下。仅凭这一种形态，就是猴头菇的身份证，本身就是安全确认。**

&nbsp;&nbsp;&nbsp;必须记住颜色的变化。幼时呈纯白色，随着生长会变黄，再往后则变成黄褐色。**一旦开始泛黄，就已经太晚了。**味道会变苦，组织也会变韧。第13节的苦味问题正与这种颜色变化直接相关。

### 2-3. 生活史——从孢子到菇体

&nbsp;&nbsp;&nbsp;菌类的生活史与植物不同。植物的一粒种子能长成一棵树，而菌类的一粒孢子却无法独自变成一株菇体。

| 阶段 | 发生的事情 |
|:---|:---|
| 孢子 | 从菌刺表面落下。是只带一半基因的单核细胞 |
| 初生菌丝 | 孢子萌发后呈丝状延伸。因为基因只有一半，无法形成菇体，势力减弱后死亡 |
| 次生菌丝 | 两条不同交配型的初生菌丝相遇后结合。只有在这种状态下才能形成菇体 |
| 占据培养基 | 白色菌丝覆盖整个木屑培养基。20-30天 |
| 菌丝老化 | 由白色变黄色，再变为粉红色。这是正常的成熟过程 |
| 出菇诱导 | 在培养基表面划伤并降低温度后，会结出粟粒状的白色小团块 |
| 子实体 | 团块膨大，表面垂下菌刺。15-20天 |

&nbsp;&nbsp;&nbsp;一粒孢子无法长出菇体，这一事实在实践中很重要。如果舍不得孢子而一粒一粒小心翼翼地撒，就只会长出初生菌丝然后死掉。必须把大量孢子粉一次性、充足地撒入，让它们在培养基内部自行相遇结合。

> **孢子不要舍不得用。一粒是长不成菇体的。**

&nbsp;&nbsp;&nbsp;菌丝变成黄色和粉红色是这种菌类的特征。换成别的菌类，这种颜色会让人怀疑污染，但对猴头菇来说这是正常的成熟过程。不了解这一点，就会把好好的培养基扔掉。不过如果颜色变化同时伴随酸味或粉状的质感，那就是污染了。

| 阶段 | 时长 | 温度 | 湿度 | 要观察什么 |
|:---|:---:|:---:|:---:|:---|

&nbsp;&nbsp;&nbsp;必须记住临界温度。菌丝在6℃以下和35℃以上会停止生长。而且菌丝自身会产生代谢热，所以周围气温30℃时，培养基内部可能超过35℃。这就是要避开盛夏培养的原因。

### 2-5. 培养基的酸度较低

| 项目 | 标准 | 备注 |
|:---|:---:|:---|
| 培养基pH | **4.0-5.5 弱酸性** | 比大多数菌菇都低 |
| 原因 | 酸性环境下养分的分解与吸收效果更好 | |
| 降低方法 | 加入米糠后会自然降低。若还需要更低，可用醋或有机酸稀释得很淡后使用 | |
| 注意 | **不能加入草木灰或石灰** | 一旦变成碱性，菌丝就无法生长 |

> **这一点与其他菌类正好相反。**大球盖菇和双孢蘑菇会用草木灰或石灰把培养基调成碱性，以抑制绿霉菌。猴头菇不能用这个办法。因为它是需要弱酸性的菌类，碱性处理等于直接导致失败。防污染的对策不靠碱性，而要靠灭菌程度和菌种用量来建立。
