## 12. 毒菌误认与安全确认

> **本节直接关乎生命安全。比起如何栽培，确认是否可以食用更为重要。**

&nbsp;&nbsp;&nbsp;猴头菇是本文档所涉及的六种菇类中，**误认风险最低的一种。**这就是本节的结论，但只有了解为什么风险低，才能真正用好这个优势。

### 12-1. 误认风险低的三个原因

| 原因 | 内容 |
|:---|:---|
| **1. 形态独一无二** | 没有菌盖、菌柄、菌褶，只是一束白色针刺垂挂而成的形状。目前尚未发现具有这种形态的致命毒菌 |
| **2. 不从土里长出** | 必定附着在阔叶树的枯木或受伤部位生长。鹅膏菌类全部从地面长出，因此没有混淆的可能 |
| **3. 同属全部可食用** | 猴头菇属（Hericium）尚未有毒性种的报告 |

&nbsp;&nbsp;&nbsp;金针菇和双孢蘑菇之所以危险是有原因的。两者都是具备菌盖、菌柄、菌褶的典型菇形，具有这种形态的致命毒菌为数不少，而且发生的季节和基质也会重叠。尤其是双孢蘑菇从土里长出，又要在白色纽扣期采摘，正好与鹅膏菌的幼菌完全重叠。

&nbsp;&nbsp;&nbsp;猴头菇一条都不符合这些条件。含有鹅膏毒肽的鹅膏菌类全部具备菌盖、菌柄、菌褶和菌托，并从地面长出。不存在把一束垂挂的针刺附着在树上的鹅膏菌。

> **这是在灾害情况下难以估量的优势。**在没有医疗支持的情况下食用菇类，最大的风险就是误认，而这种菇从结构上就不存在这种风险。即便是没有菌类鉴别经验的人，也能相对放心地处理这个物种。

### 12-2. 同属的其他种类——全部可食用

| 种类 | 特征 | 是否可食用 |
|:---|:---|:---|
| **猴头菇（H. erinaceus）** | 菌刺长1-5cm，长长垂挂。呈块状 | 食用 |
| 珊瑚状猴头菌（H. coralloides） | 分枝呈珊瑚状，菌刺较短 | 食用 |
| 类珊瑚状猴头菌（H. laciniatum） | 分枝生长，菌刺长度中等 | 食用 |
| H. caput-medusae | 聚生呈头状 | 食用 |
| H. cirrhatum | 层层重叠生长 | 食用 |

&nbsp;&nbsp;&nbsp;即便把同属的种类弄混，也不会中毒。只是因种类不同，菌刺可能较短、产量较少，口感也可能不同。栽培价值最高的还是猴头菇。

### 12-3. 即便如此也要确认的事项

&nbsp;&nbsp;&nbsp;误认风险低，并不意味着什么都不用确认。在白色块状的菌类中，也有几种是不能吃的。

| 对象 | 区分要点 | 危险性 |
|:---|:---|:---|
| **Climacodon属真菌** | 呈**架状层叠**附着在树上，菌刺短且只长在下侧，**组织如皮革般韧硬。**多带苦味 | 毒性微弱但不可食用 |
| **白色霉菌团块** | 没有菌刺，像棉絮或粉末 | 属于污染菌 |
| **幼嫩的马勃菌类** | 呈球形，没有菌刺，剖开后内部呈均匀的白色棉絮状 | 幼嫩时可食用，但要剖开确认 |
| **胶质菌类·云芝类（白色种）** | 薄薄地铺展附着在树上，菌刺极短或没有，质地韧硬 | 不可食用 |

| 确认项目 | 猴头菇的判断标准 |
|:---|:---|
| **形态** | **从块状主体上垂挂下菌刺。**不会呈架状层叠附着 |
| **菌刺长度** | **1-5cm。**必须目视可见地长 |
| **组织** | **像海绵一样柔软，手指按压会凹陷。**若像皮革般韧硬，则是别的东西 |
| **颜色** | 白色至乳白色，长大后变黄色、黄褐色 |
| **基质** | 阔叶树枯木或受伤部位。**从地面长出的绝不是这种菇** |
| **味道** | 幼嫩个体几乎不苦。**放到舌尖若感到强烈苦味，就吐掉** |

> **组织的柔软程度是最可靠的判别要点。**猴头菇用手按压会像海绵一样凹陷，用手就能撕开。容易混淆的其他菌类大多质地如皮革或木质，用手撕不开。

### 12-4. 初次食用时的原则

&nbsp;&nbsp;&nbsp;即便误认风险低，也要遵循同样的流程。在没有医疗支持的情况下，确认流程本身就是一种防护手段。

| 顺序 | 内容 |
|:--:|:---|
| 1 | **确认是否长在树上。**从地面长出的要丢弃 |
| 2 | **查看菌刺是否垂挂1cm以上。**若短且呈架状，就丢弃 |
| 3 | **用手按压确认是否像海绵一样柔软。**若韧硬就丢弃 |
| 4 | **在舌尖上稍微试一下味道。**若强烈发苦就吐掉，不要食用 |
| 5 | **必须充分煮熟。**生食难以消化，还会刺激胃部 |
| 6 | 第一次只让**一个人**食用**少量（一小块）**，等待24小时 |
| 7 | 若无异常，再逐渐增加食用量 |

> **中毒症状在6小时以上之后才出现的情况最为危险。**
> 食用后30分钟到2小时内出现腹痛，大多是胃肠受到刺激，但若在6-24小时后才开始呕吐腹泻，则是破坏肝脏的鹅膏毒肽中毒的典型病程。猴头菇几乎不会发生这种情况，但如果同时处理其他菇类，就必须记住这个病程规律。

> **在灾害情况下，最安全的菇类食物来源，是自己接种培养基长出来的菇。而猴头菇是少有的一种，即便是野生个体也能相对安全地采集的菌类。**

## 13. 无冰箱贮藏

> **本节是猴头菇栽培中最棘手的部分。贮藏性为E本可以靠干燥解决，但这种菇如果直接晒干，会变苦变韧。**

### 13-1. 保持生鲜只能放三到五天

&nbsp;&nbsp;&nbsp;评价表中，这种菇以生鲜状态为基准的贮藏性为E，在无电力常温下能放3-5天。海绵状的组织含有大量水分，被压到的地方会先变软，白色转黄的同时苦味也会显现。

| 不该做的事 | 原因 |
|:---|:---|
| **洗净后保存** | 海绵状组织会吸水，一天之内就会变黄 |
| 用塑料完全密封 | 会凝结水珠导致腐烂，应用纸或干布包裹以便透气 |
| 堆叠放置 | 被压到的地方会先变质，应摊成一层放置 |

&nbsp;&nbsp;&nbsp;用干布或纸包好，放在12-15℃的地窖里可以保存1-2周。这是无电力条件下能做到的极限，再往后就要靠加工来解决。

### 13-2. 晒干后会变苦变韧

&nbsp;&nbsp;&nbsp;这种菇在干燥过程中会同时出现两个问题。

| 问题 | 原因 |
|:---|:---|
| **苦味** | 过熟个体含有较多苦味成分，干燥过程中随着水分流失，苦味会被浓缩。若在高温下快速烘干，苦味会被固定在组织里 |
| **变韧** | 海绵状组织干燥时会大幅收缩，纤维相互纠结。一旦纤维纠结，即便用水泡开也无法松解，会像皮革一样残留 |

> **这两个问题的最大成因不是干燥技术，而是采收时机。**趁白色时采摘的即便晒干也苦味较少，而变黄之后无论怎么晒都会苦。第8节所述的采收时机判断，决定了贮藏品质的一半以上。

### 13-3. 减少苦味与韧度的干燥方法

| 顺序 | 方法 | 效果 |
|:--:|:---|:---|
| 1 | **趁白色时采收** | 消除苦味的根本原因 |
| 2 | **采收前3-4天起不再喷水** | 采收时水分较少，更容易干燥 |
| 3 | **顺着纹理用手撕成厚1-2cm的小块** | 厚的整块内部不易干透会长霉。用手撕比用刀切更能减少组织损伤 |
| 4 | **在加盐的沸水中焯3-5分钟** | **这一步是关键。**苦味成分会溶入水中，组织经高温定形后，干燥后也不易纠结 |
| 5 | **浸入冷水中再泡去一次苦味，然后挤干水分** | 能去除残留的苦味 |
| 6 | **在阴凉处用风慢慢吹干** | 高温速干会固定苦味并使组织变硬 |
| 7 | 最后放在阳光下晒半天 | 能增加维生素D含量 |

| 方法 | 条件 | 时长 | 结果 |
|:---|:---|:--:|:---|
| **焯水后阴干** | 完成前4步后，放在通风良好的屋檐下 | 3-5天 | **最为推荐，苦味少，泡发效果好** |
| 生鲜阴干 | 撕开后直接晒 | 3-5天 | 苦味残留且会变韧 |
| 生鲜晒干 | 撕开后放在阳光下晒 | 1-2天 | 速度快，但苦味和变韧程度最严重 |
| 靠火干燥 | 灶台上方的搁架，40-50℃ | 半天 | 可在梅雨季使用，但苦味会被固定 |

| 阶段 | 判定 |
|:---|:---|
| 完全干燥 | **用手一搓就碎。**若还能弯曲，说明尚未干透 |
| 保存 | 完全冷却后，**放入密闭容器，与木炭或炒盐一起存放** |
| 期限 | 在凉爽阴暗处**保存1年以上，**磨成粉则可保存2年以上 |

### 13-4. 磨成粉最为实用

> **在灾害情况下，猴头菇最理想的贮藏形态不是整只晒干，而是磨成粉。**

&nbsp;&nbsp;&nbsp;原因有三个。第一，变韧的问题会消失，粉末没有所谓的口感，组织是否纠结也就不再是问题。第二，苦味会被稀释，用在粥或汤里一次只放一勺，几乎感觉不到苦味。第三，体积小、保存时间长。

| 步骤 | 方法 |
|:--:|:---|
| 1 | 焯水后彻底晒干 |
| 2 | 用石臼或石磨磨碎 |
| 3 | 过筛只收集细粉，粗颗粒重新磨一遍 |
| 4 | 与木炭一起放入密闭容器，置于凉爽阴暗处 |
| 5 | 混入粥、汤、面疙瘩汤（sujebi）面团、谷物粉中使用 |

### 13-5. 其他贮藏方法

| 方法 | 制作方法 | 时长 | 备注 |
|:---|:---|:--:|:---|
| **盐渍** | 焯水后沥干水分，加入重量20%的盐层层码放 | 6个月-1年 | **比晒干更能保留口感** |
| **酱菜** | 焯水后浸入酱油和醋中 | 3-6个月 | 苦味会被酱油的味道掩盖 |
| **发酵贮藏** | 浸入3%的盐水中进行乳酸发酵 | 3-6个月 | 酸味会盖过苦味 |
| **油浸** | 焯水挤干后完全浸入油中 | 1-3个月 | 只在油量充足时采用 |
| **地窖短期保存** | 不清洗，用纸包好放在12-15℃处 | 1-2周 | 摊成一层放置 |

> **对这种菇来说，盐渍可能是比晒干更好的选择。**因为组织不会收缩，能保留原有的纹理，而且在焯水过程中苦味已经去除。如果盐够充足，贮藏量一半做成盐渍、一半磨成粉，是比较理想的分配方式。

## 14. 烹饪与加工

### 14-1. 必须煮熟后食用

&nbsp;&nbsp;&nbsp;猴头菇不能生吃。生食难以消化，部分成分还会刺激胃肠，而且不加热就无法吸收细胞壁内的营养成分。

| 烹饪方式 | 燃料 | 时间 | 备注 |
|:---|:--:|:--:|:---|
| 焯水 | 少 | 3-5分钟 | 也是去除苦味的基本步骤 |
| 炒制 | 少 | 5-8分钟 | **用油炒会呈现类似蟹肉或鸡肉的纹理** |
| 烤制 | 少 | 5-8分钟 | 也可以撕成厚片放在余灰上烤 |
| 汤·锅 | 中等 | 10分钟以内 | 汤汁清澈，带有淡淡的甜味 |
| 煎饼 | 中等 | 5-8分钟 | 撕碎混入面糊能增加分量 |

&nbsp;&nbsp;&nbsp;烹饪前的要领是**把水分彻底挤干。**海绵状组织含水量大，直接炒的话会出水变成焖煮。用手撕开后再用双手挤压去除水分，炒制时纹理才会显现出来，产生类似肉的口感。在蛋白质匮乏的情况下，能提供咀嚼满足感的食材这一点，也体现在评价表中口味为S这一项上。

### 14-2. 出现苦味时

| 方法 | 说明 |
|:---|:---|
| **焯水去苦** | 在加盐的沸水中焯3-5分钟，之后浸入冷水中，多次换水 |
| **加入大酱或韩式辣椒酱** | 浓烈的味道能盖过苦味 |
| **搭配油脂** | 脂溶性苦味成分会溶入油中被稀释 |
| **磨成粉少量使用** | 最为可靠。一锅汤里放一勺就感觉不到苦味 |
| **加入酸味** | 与食醋或酸味泡菜一起烹调，能掩盖苦味 |

### 14-3. 干品的使用方法

| 顺序 | 方法 |
|:--:|:---|
| 1 | 用温水浸泡30分钟以上使其回软，比其他菇类耗时更长 |
| 2 | **品尝泡发的水。**若发苦就倒掉，不苦就用作汤底 |
| 3 | 用手把泡软的菇挤干水分 |
| 4 | 若仍有苦味，再用沸水焯一次 |
| 5 | 切好后炒制或加入汤中 |

> **其他菇类通常要求一定要用泡发的水，但猴头菇是个例外。**因为苦味成分会溶入水中，所以要先尝味再做判断。如果是趁白色时采收、焯水后晒干的，泡发的水就不会苦，可以用作汤底。

### 14-4. 弥补谷物不足的搭配

| 搭配 | 效果 |
|:---|:---|
| **菇粉 + 谷物粥** | 补充谷物中缺乏的赖氨酸，并增加B族维生素和维生素D |
| **菇粉 + 面粉·荞麦粉** | 混入面疙瘩汤（sujebi）或刀切面（kalguksu）的面团中，苦味会被稀释 |
| **菇 + 油脂** | 维生素D属于脂溶性，与油脂一同食用能提高吸收率 |
| **菇 + 马铃薯·甘薯** | 用薯类（块茎/块根）补充热量，用菇类补充蛋白质 |
| **菇 + 大酱汤** | 大酱浓烈的味道能盖过苦味，还能增添鲜味 |

> **菇类不应作为热量来源，而应作为蛋白质与微量营养素的补充来源，这才是正确的用法。**
> 就猴头菇而言，这一点尤为明显：每100g含13kcal热量、2.57g蛋白质，满足14种微量营养素，其中包括维生素D。用谷物或薯类（块茎/块根）补充热量，再用这种菇补充蛋白质、维生素D和B族维生素，才是正确的搭配用法。

## 15. 全年作业日程

| 月份 | 作业 |
|:--:|:---|
| **1-2月** | **段木采伐，**在落叶之后到发芽之前进行。收集锯末，检查干菇状态 |
| **3月** | 段木在阴凉处干燥（含水率40-45%）。**准备春季栽培的培养基并灭菌，**用油桶一次性处理 |
| **4月** | **段木接种**（打孔并打入菌种），锯末培养基接种与培养 |
| **5月** | **催蕾诱导与首次采收，**在表面制造伤口，维持15-20℃，采收后立刻焯水晒干 |
| **6月** | **春季栽培采收高峰，**第2-3周期，进行大量干燥与磨粉 |
| 7月 | 因为炎热而不进行栽培。**超过35℃菌丝就会死亡。**段木放在阴凉处，只需注意不让其干燥 |
| **8月** | **准备秋季栽培的培养基并灭菌，**备好锯末和玉米秸秆 |
| **9月** | **接种与培养，**22-25℃ |
| **10月** | **催蕾诱导与采收，**品质最佳的时期，天气凉爽使菌刺变长、苦味减少 |
| **11月** | **秋季栽培采收高峰，**大量干燥，段木也会出菇 |
| 12月 | 把菌糠施入田地，检查孢子印，给段木盖上稻草准备越冬 |

&nbsp;&nbsp;&nbsp;这份日程的关键在于**轮种春秋两季，盛夏和严冬则停止栽培。**盛夏是菌丝会死亡的温度，严冬则是催蕾会停止的温度。若勉强想要四季栽培，只会招致失败，而这个空缺在夏季由大球盖菇、冬季由金针菇来填补。

&nbsp;&nbsp;&nbsp;秋季采收的品质优于春季采收，因为10月到11月的气温在15-20℃，恰好落在这种菇的最适范围内。所以最好用秋季采收的部分制作贮藏品，春季采收的部分则随采随吃。

&nbsp;&nbsp;&nbsp;此外，每年逐步增加段木接种的数量，是一项长期策略。段木不需要灭菌，一次接种能持续出菇好几年，因此年头越久，锯末培养基所需的燃料和劳动就越少。

### 绝对不要忘记的事项

| 项目 | 内容 |
|:--:|:---|
| 1 | **趁白色时采收。**一旦泛黄就已经晚了，苦味也会从那时开始 |
| 2 | **晒干时要先焯水再晒。**直接晒干会又苦又韧 |
| 3 | **最实用的贮藏形态是粉末。**变韧的问题会消失，苦味也会被稀释 |
| 4 | **不要直接向菇体喷水。**菌刺之间一旦积水，那个部位就会开始变质 |
| 5 | **催蕾诱导以在表面制造伤口的方法效果最好** |
| 6 | **需要微弱的光照。**完全黑暗中菌刺无法伸展 |
