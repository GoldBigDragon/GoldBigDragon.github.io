## 5. 接種方法

&nbsp;&nbsp;&nbsp;接種は、おがくず培地栽培の中で最も失敗が多く出る工程です。滅菌によって培地をきれいに空にしておいても、その空いた場所にきのこの菌糸より先に青カビが入り込むことがよくあります。しかもヤマブシタケは培地が弱酸性でなければならないため、他のきのこのように草木灰や石灰でアルカリ性にして雑菌を抑える方法が使えません。接種の目標はただ一つ、きのこの菌糸に先に場所を占めさせることです。

### 5-1. おがくず培地への接種

| 項目 | 基準 | 理由 |
|:---|:---|:---|
| 冷却 | 滅菌後**13-14時間**、培地温度が**18-20度**になるまで | それより熱いと種菌が死にます |
| 速さ | 冷めたらすぐに | 長く置くと空気中の胞子が付きます |
| 時間帯 | **早朝または雨が降った直後** | 空気中の胞子と埃が最も少ないです |
| 接種量（標準） | 培地重量の2-3% | |
| 接種量（無菌室がない場合） | **培地重量の5-10%** | 先に場所を占めた側が勝ちます |
| 入れる場所 | 中央の穴に半分、表面に半分 | 中心から菌糸が広がります |
| 仕上げ | 口を綿や布でふさぎ、紐で結びます | 空気は通り、埃は防げます |

&nbsp;&nbsp;&nbsp;雨が降った直後に接種するという助言は、無菌室がない場合に特に有効です。雨が空気中の胞子と埃を洗い流すため、落下してくる菌の数が大きく減ります。反対に、風の強い晴れた日の日中が最も悪い条件です。

### 5-2. 無菌室なしで接種するコツ

| 項目 | 方法 |
|:---|:---|
| 場所 | 風が入らない最も小さな部屋。倉庫の奥、納屋の隅 |
| 事前処理 | 床と壁に水をまいて埃を落ち着かせ、30分待ちます |
| 代用の無菌装置 | 大きな箱や甕を横にして内側を熱湯で拭き、その中に手だけ入れて作業します |
| 手 | 石鹸で洗い、できれば強い酒や酢で拭きます |
| 道具 | スプーンとナイフを火であぶってから冷まします |
| 服 | 乾いた服より、少し湿った服の方が埃を舞い上げにくいです |
| 呼吸 | 培地の上で話したり息を吹きかけたりしません。布で口を覆います |
| 動作 | 容器を開けて種菌を入れ、蓋をするまでを10秒以内で終えます |

> **無菌室がない場合の要点は、完璧な無菌状態ではなく速さと種菌量です。雑菌がいくつか入り込むのを防ぐことはできないので、きのこの菌糸を圧倒的に多くして先に場所を占めさせます。**

### 5-3. 段木への接種

&nbsp;&nbsp;&nbsp;段木は滅菌しません。木の内部はもともと無菌に近く、樹皮が防御壁の役割を果たします。そのため接種はずっと単純です。

| 段階 | 方法 |
|:---|:---|
| 時期 | **3-5月**または9-10月。樹液が動き始める頃 |
| 穴あけ | 直径12mm、深さ25-30mm。らせん状に**間隔15-20cm** |
| 種菌を入れる | 穴におがくず種菌を押し込んで詰めるか、種駒（木栓状の種菌）を打ち込みます |
| 封をする | 蜜蝋、松脂、湿った粘土、木の栓で穴をふさぎます |
| 断面接種 | 短い木片であれば断面に種菌を塗り、他の木片を重ねて積みます |
| 種菌量 | 段木1本（直径15cm、長さ1m）当たり20-30孔 |
| その後の管理 | 陰に横たえて積み、わらや落ち葉で覆って乾かないようにします |

&nbsp;&nbsp;&nbsp;穴をふさぐことが重要です。開いたままの穴からは水が入って腐り、雑菌が付きます。蜜蝋が最も良く、なければ松脂を溶かして使うか、湿った粘土を塗ってふさぎます。木の栓を削って打ち込むのでも構いません。

### 5-4. 接種後の確認

| 時期 | 何を見るか |
|:---|:---|
| 24-48時間 | 種菌の周りに**綿毛のような白い気配**が現れ始めます |
| 3-5日 | 白い菌糸が種菌から放射状に1-2cm広がります |
| 7-10日 | 培地の上部が白く覆われます |
| 段木 | 2-3ヶ月ほどで孔の周りに白い菌糸が見えます |

&nbsp;&nbsp;&nbsp;初めの数日が勝負です。3日以内に白い菌糸が目に見えて広がれば、ほぼ成功です。5日過ぎても何の変化もなければ、種菌が死んでいたか、培地が熱すぎるときに接種したということです。白以外の色が見えたら、その容器はすぐに他のものから離れた場所へ移します。

## 6. 菌糸培養管理

&nbsp;&nbsp;&nbsp;接種後20-30日が培養期間です。目標は、白い菌糸に培地全体を占領させることです。人がすべきことは、温度を守り、暗く保ち、毎日見て回って汚染されたものを取り除く程度です。

### 6-1. 温度と湿度

| 項目 | 範囲 | 備考 |
|:---|:---:|:---|
| 菌糸生長温度 | 22-25℃ | 最も速いです |
| **下限** | **6℃** | これより下では生長が止まります |
| **上限** | **35℃** | これより上では生長が止まり、すぐに死にます |
| 空気湿度 | 65-75% | 湿度が高すぎると表面に雑菌が付きます |
| 光 | 暗く | 培養中は光は必要ありません |
| 期間 | 20-30日 | 培地の量と温度によって異なります |

> **35℃は絶対に超えてはならない線です。菌糸自身が代謝熱を出すため、周囲の気温が30℃のときでも培地の内部は35℃を超えることがあります。容器を密に積んでおくと、中央部が特に高温になります。**

&nbsp;&nbsp;&nbsp;対策は三つです。容器の間に指が入るくらいの隙間を空けて積みます。培養10日目頃から周囲の気温を2-3℃下げます。そして真夏の培養を避けます。

### 6-2. 菌糸の色の変化——汚染と勘違いしない

| 時期 | 正常な色 |
|:---|:---|
| 接種直後-2週 | 純白色 |
| 2-3週 | 白色に**淡い黄色みが**帯びてきます |
| 成熟期 | 黄色、時には**淡いピンク色**に変わります |

> **このきのこの菌糸は、正常な状態でも黄色やピンク色に変わります。**他のきのこであれば汚染を疑うような色ですが、ヤマブシタケでは成熟の兆しです。この点を知らないと、問題のない培地を捨ててしまうことになります。

&nbsp;&nbsp;&nbsp;では、汚染とはどう見分けるのでしょうか。色だけを見るのではなく、質感と匂いも一緒に確認します。

| 観察 | 正常な成熟 | 汚染 |
|:---|:---|:---|
| 色 | 白色から黄色、淡いピンク | 青緑色、黒色、濃い橙色 |
| 質感 | 菌糸の糸が絡み合った層。触ると弾力があります | **粉のように舞います** |
| 境界 | 培地全体に均一に広がります | **丸い斑点から放射状に** |
| 匂い | ほのかなきのこの香り、森の土の匂い | むっとする匂い、酸っぱい匂い |
| 速度 | 1日3-5mm | 1日10-30mm |

### 6-3. 培養完了の判定

| 判定項目 | 基準 |
|:---|:---|
| 色 | 培地全体が白色から淡黄色に均一に覆われる |
| 底 | **底まで菌糸が達している必要があります。**上部だけ覆われているのは未完成です |
| 硬さ | 容器を逆さにしても培地が塊のまま崩れません |
| 追加期間 | 全体が覆われた後、**さらに5-7日置きます。**後熟と呼ばれ、収量が上がります |

&nbsp;&nbsp;&nbsp;後熟を省くと収量が減ります。見た目には全体が覆われていても、培地の内部には菌糸がまだ十分に入っていない部分が残っているため、数日長く置いたほうが結果が良くなります。

## 7. 発生誘導

&nbsp;&nbsp;&nbsp;菌糸は快適な環境ではひたすら伸び続けるだけです。きのこを結実させるのは、菌糸にとって危機の信号です。ヤマブシタケの場合、その信号は三つあります。**培地表面に傷をつけること**、温度の低下、そして湿度の上昇です。

### 7-1. 表面に傷をつける方法が最も効果的です

&nbsp;&nbsp;&nbsp;芽出し誘導方法を比較した試験結果があります。

| 処理 | 方法 | 再発生率 | 品質 |
|:--:|:---|:---:|:---:|
| T1、T2 | ヒラタケ方式（菌搔きなど） | 低い | 普通 |
| **T5** | **表面に傷をつける** | **最も高い** | **優秀** |

> **芽出し誘導では、表面に傷をつける方法が再発生率も品質も最も優れています。**培地表面をナイフの先や釘で数箇所突いたり、十字に線を入れたりして菌糸層を裂いておきます。傷をつけた場所に原基が形成されます。

| 項目 | 方法 |
|:---|:---|
| 道具 | 熱湯に浸してから取り出したナイフの先、釘、竹串 |
| 深さ | 表面から5-10mm |
| 個数 | 瓶なら表面に2-3箇所、袋なら一面に3-5箇所 |
| 原理 | 傷がストレス信号となり、その場所に空気と光が触れて原基が形成されます |
| 注意 | 裂きすぎると子実体が複数に分かれて小さくなります |

&nbsp;&nbsp;&nbsp;子実体を一つ大きく育てたいなら、傷は一、二箇所だけつけます。小さいものを複数得たいなら、多くの箇所につけます。災害の状況では、大きなもの一つのほうが有利です。手入れや乾燥の手間が少なく、棘が十分に伸びて食感も良くなります。

### 7-2. 発生条件

| 項目 | 培養段階 | **発生段階** | 備考 |
|:---|:---:|:---:|:---|
| 温度 | 22-25度 | **15-24度。**最適は15-20℃ | 幅9℃。低いほど棘が長く硬くなります |
| 空気湿度 | 65-75% | **芽出し期85-95%、生育期80-85%** | 低いと乾き、高いと軟らかくなりすぎます |
| **光** | 不要 | **間接照明。新聞が読める程度** | ないと棘が固まってだんごのまま残ります |
| 換気 | 少なめ | **十分に** | 二酸化炭素がたまるとサンゴのように奇形になります |
| 期間 | - | 芽出し3-7日、生育15-20日 | |

> **温度が低いほど品質が良くなります。**15-18℃で育ったものは棘が長く、組織が硬く、苦味も少なくなります。22℃を超えると成長は速くなる代わりに軟らかくなり、すぐに黄色く変わります。そして黄色く変わったものが13節の苦味の問題を引き起こすため、涼しい季節に収穫することが貯蔵品質までも左右します。

### 7-3. 電力なしで15-24度を作る方法

| 手段 | 温度 | 確保方法 | 限界 |
|:---|:---:|:---|:---|
| **春作** | 自然 | 4月から6月初め | 7月になると暑くなります |
| **秋作** | 自然 | 9月から11月初め | 12月になると芽出しが止まります |
| 土窟、洞窟 | 12-18℃ | 山の斜面を2m以上掘り進みます | 一年中使えて最も良いです |
| 地下室 | 12-18℃ | 既存の構造物を活用 | 湿度と光を別途調整する必要があります |
| 北向きの土壁の納屋 | 季節による変動 | 厚い土壁が温度変化を和らげます | 夏と冬には範囲を外れます |
| 段木の露地栽培 | 自然 | 半日陰に段木を立てるか横たえます | すべて季節に委ねます |

> **電力がない状況では、ヤマブシタケは春と秋の作物です。真夏には菌糸が35℃で死に、真冬には芽出しが止まります。**

&nbsp;&nbsp;&nbsp;段木の露地栽培が、電力のない条件に最も適しています。半日陰に段木を置き、乾かないように管理するだけで、春と秋に自然と発生します。人が温度や湿度や光を調整する必要はなく、季節がその役割を果たします。初収穫までに時間がかかることが唯一の欠点です。

### 7-4. 電力なしで湿度を作る方法

| 方法 | 説明 |
|:---|:---|
| **箱や甕の中に水を入れた器** | 容器を大きな箱に一緒に入れ、底に水を入れた皿や湿った砂を置きます |
| 湿った布で覆う | 上に湿った布をかけますが、きのこに直接触れないように浮かせます |
| 床と壁に水をまく | 部屋全体の湿度が上がります |
| 換気口の大きさ調整 | 穴を小さくして湿気が抜けないようにします。完全にふさいではいけません |

&nbsp;&nbsp;&nbsp;**きのこに直接水をかけてはいけません。**ヤマブシタケの棘の間に水がたまると、その部分から黄色く変わり、細菌が広がります。湿度は空気で上げ、水は周囲にまきます。この点は他のきのこよりずっと厳しく守る必要があります。

### 7-5. 収穫前の乾燥管理

| 時期 | 管理 |
|:---|:---|
| 収穫3-4日前 | **水を一切かけず、湿度を少し下げます** |
| 効果 | 色が白いまま残り、組織が硬くなり、貯蔵性が上がります |
| 注意 | 度を越すと棘の先が乾いて裂けます |

> **この3-4日が貯蔵性を大きく左右します。**水分を含んだまま収穫したものは一日で黄色く変わり、乾燥させると苦味がさらに強くなります。収穫の数日前から乾かしておくことが、13節の問題を前倒しで減らす方法です。
