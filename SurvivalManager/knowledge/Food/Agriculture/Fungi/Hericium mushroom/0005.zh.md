## 8. 采收与再出菇周期

### 8-1. 采收时机判断——趁白色时采摘

| 标准 | 内容 |
|:---|:---|
| **最佳** | **子实体整体呈乳白色，且菌刺已充分伸展时** |
| 偏晚的信号 | **白色开始转为黄色** |
| 采收过晚 | **苦味会加重，组织变得韧硬。**开始散落孢子，出现粉尘飘散 |
| 菌刺长度 | 1-5cm，充分伸展但尖端尚未干枯时 |
| 采收前管理 | 从3-4天前起不再喷水 |
| 时段 | 清晨 |

> **一旦开始泛黄，就已经晚了。**这种菇的苦味主要来自过熟。趁白色时采摘的几乎不苦，而变黄之后即便直接吃也会发苦，晒干后更苦。要最大程度减轻第13节所述的苦味问题，关键不是干燥技术，而是及时采收。

&nbsp;&nbsp;&nbsp;变黄的个体不必丢弃。第4节所说最适合采集孢子的个体正是这个阶段，焯水去除苦味后仍可食用，只是不能用来贮藏。

### 8-2. 采摘要领

&nbsp;&nbsp;&nbsp;用手握住子实体基部，轻轻旋转着取下。硬拉的话培养基会被扯破，杂菌就会从伤口侵入。留在培养基上的基部要用刀干净地切除，因为残留的基部腐烂后会招来细菌和菇蝇。

&nbsp;&nbsp;&nbsp;采下的菇**不要清洗。**海绵状的组织会吸水，一天之内就变黄发烂。若沾有异物，用干布或软刷拂去即可。

&nbsp;&nbsp;&nbsp;而且处理要在采收当天完成。要吃的部分直接烹调，要贮藏的部分当天就要撕开开始晒干。拖延一天，颜色就会改变，苦味也会显现。

### 8-3. 再出菇

| 项目 | 内容 |
|:---|:---|
| 休养期 | 采收后10-15天 |
| 休养期管理 | 清除表面残留的基部，维持湿度并保持在22-25℃ |
| **再次催蕾诱导** | **在表面再次制造伤口。**这样再出菇率最高 |
| 第2周期产量 | 第1周期的50-70% |
| 第3-4周期 | 逐渐减少 |
| 总采收次数 | **3-4次。**在适用排除规则的三种菌类中最多 |
| 段木栽培 | 每年春秋两季，可持续数年 |

&nbsp;&nbsp;&nbsp;评价表中持续性为B，正是这张表的内容所反映的。金针菇为两三次（D）、双孢蘑菇为两三个周期（C），相比之下这种菇能收三到四次。在灾害情况下，重新制作培养基是最繁重的劳动，所以能在同一份培养基上多收一次，就意味着节省了燃料和劳力。

&nbsp;&nbsp;&nbsp;休养期间保持培养基不干燥非常重要。一旦干燥，菌丝就会死亡，无法再次出菇。但不要直接浇水，而要靠周围湿度来维持。

### 8-4. 产量

| 方式 | 产量 | 周期 |
|:---|:---|:---:|
| 瓶栽850ml | 356g | 40-45天 |
| 袋栽2,500ml | 810g | 50-60天 |
| **段木栽培0.1㎡** | **1,195.5g** | 69天以上，此后可持续数年 |
| 生物学效率（段木，橡树） | 17.3% | |
| 玉米秸秆替代20% | 鲜重显著提高 | |

&nbsp;&nbsp;&nbsp;一袋能产出810g。生鲜810g含105kcal热量、21g蛋白质。作为热量来源几乎没有意义，但作为蛋白质、维生素D和B族维生素的来源却很有价值。把20个袋子编成一组轮换栽培，春秋两季各能获得一个多月、每天一把左右的产量。

> **如果把猴头菇的产量折算成热量来做计划，只会让人失望。**应该把它当作能提供包括维生素D在内14种微量营养素的副食，以及在断肉的情况下能带来类似蟹肉口感的食材，以此来衡量它的价值才是正确的。

## 9. 污染与病虫害

### 9-1. 青霉是首要原因

&nbsp;&nbsp;&nbsp;灾害情况下菇类栽培失败最常见的原因，不是病虫害，而是培养基被竞争性霉菌夺占。其中占绝大多数的是木霉菌（Trichoderma），也就是青霉。猴头菇使用灭菌培养基，且培养基呈弱酸性，这种风险因此特别大。**青霉偏爱弱酸性环境。**

| 区分 | 猴头菇菌丝 | 青霉 |
|:---|:---|:---|
| 颜色 | 白色 → 淡黄 → 淡粉色（正常成熟） | 起初为白色，很快转为**青绿色** |
| 质感 | 菌丝纤维交织的层，有弹性 | **像粉末一样细碎松散** |
| 蔓延速度 | 每天3-5mm | 每天10-30mm，**快3-6倍** |
| 气味 | 森林土壤气息、菇香 | 闷臭味，有时带椰子似的气味 |
| 边界 | 沿培养基均匀分布 | 从圆形斑点呈放射状扩散 |

> **青霉在颜色显现之前，早已扩散开来。**
> 青绿色出现时，孢子已经形成，也就是已经开始繁殖之后了。到那个阶段，应该认为培养基已经损失了相当一部分。早期判别不能靠颜色，而要看蔓延速度和质感。

> **而且这种菇的菌丝本身就会变成黄色和粉色，只看颜色判断的话，会把好好的培养基当作坏的丢掉。**必须同时观察质感、气味和蔓延速度。

### 9-2. 无法使用碱化处理

&nbsp;&nbsp;&nbsp;大球盖菇和双孢蘑菇会用草木灰或石灰把培养基和覆土调成碱性，以此抑制青霉。猴头菇要求培养基酸度保持在4.0到5.5之间，因此无法使用这个方法。调成碱性后青霉确实会减少，但菇类菌丝也无法生长。

| 因此可用的方法 | 原理 |
|:---|:---|
| **充分灭菌** | 常压100℃ 4-6小时，图省事必定会付出代价 |
| **足量接种** | 培养基重量的5-10%，先占地盘的一方获胜 |
| **营养源不超过30%** | 米糠和麦麸过多，竞争性霉菌会率先爆发式滋生 |
| **堆放容器时留出间隙** | 空气流通才能散去代谢热，防止霉菌蔓延 |
| **雨后立刻接种** | 空气中飘落的孢子最少 |
| **每年更换培养场所** | 一直用同一地点，孢子会不断积累 |
| **改用段木栽培** | **树皮和木质本身就是防护屏障** |

> **从根本上避免污染问题的方法就是段木栽培。**不需要灭菌，就没有灭菌失败的问题；树木的组织和树皮能阻挡杂菌入侵；接种的菌丝会在数年间占据整根木材。如果锯末培养基总是败给青霉，不如换一种方法。

### 9-3. 发现污染时

| 情况 | 应对 |
|:---|:---|
| **单个容器表面出现小斑点** | 立即只取出那一个容器，**不要打开**，直接移走 |
| **蔓延到多个容器** | 整个培养场所都要转移，原场所要清空并用水冲洗晒干 |
| **整个培养基呈青绿色** | 全部废弃，焚烧或埋在远离栽培场地的地方 |
| **培养基散发酸味** | 是细菌污染，废弃并延长下一批的灭菌时间 |

> **不要把受污染的培养基拿去做堆肥。**
> 青霉的孢子能在堆肥堆里存活下来，第二年又会重新进入培养基。务必焚烧，或深埋在与栽培场地隔开的地方。

### 9-4. 害虫

| 害虫 | 危害 | 应对 |
|:---|:---|:---|
| **菇蝇（尖眼蕈蚊）** | 蛀食菌丝，并在子实体中留下蛆虫，还会传播青霉孢子 | 用细密的布堵住入口进行物理阻隔，发生时使用水盆诱捕或粘虫板 |
| **螨虫** | 菌丝会变成褐色并停止生长 | 保持干燥管理，并隔离发生的区域 |
| **蛞蝓** | 会咬食幼嫩的子实体，因菌刺柔软而特别容易受害 | 用灶灰或锯末围出一道屏障，夜间徒手捕捉 |
| **松鼠、老鼠、鸟类** | 在段木栽培中会叼走子实体 | 罩上网子，或围上带刺的树枝 |

&nbsp;&nbsp;&nbsp;蛞蝓造成的危害在这种菇身上格外严重。因为它没有菌盖，组织又柔软，从哪里都容易被啃食。在露地段木栽培中，要在段木下方围一圈灶灰作为屏障，并在雨后夜间巡查，徒手捕捉。

&nbsp;&nbsp;&nbsp;没有药剂的情况下，防治要靠结构设计和卫生管理来实现：给通风口罩上两层细布，不把采收后的废培养基堆放在栽培场地旁边，掉落的子实体碎块要随时清理。

## 10. 生长异常诊断

| 症状 | 原因 | 处理 |
|:---|:---|:---|
| 接种5天后仍不见菌丝 | 在培养基过热时接种、菌种已死亡 | 把培养基冷却到18-20℃后重新接种 |
| 菌丝生长途中停止 | **培养基温度超过35℃**，水分不足 | 拉开容器间距散热，并降低周围气温 |
| 菌丝变黄、变粉 | **属于正常成熟** | 无需处理，只要质感和气味正常就没有问题 |
| 菌丝良好但不出菇 | **未在表面制造伤口**、未降温、完全没有光照 | 在表面戳出伤口，转移到15-20度环境，并给予微弱光照 |
| 原基形成后又干枯死亡 | 湿度不足 | 用水盆和湿布把湿度提升到85-95% |
| **子实体裂成珊瑚状或花菜状** | **二氧化碳过多，**通风不足 | 大幅增加通风 |
| **菌刺不伸展而结成团块** | **光照不足** | 给予能看清报纸文字程度的间接光照 |
| 子实体变黄 | 过熟、温度超过22℃、直射阳光 | 及时采收，并转移到更凉爽、更阴暗的地方 |
| 菌刺尖端变褐干枯 | 空气过于干燥 | 向周围洒水提升湿度 |
| 子实体变软并渗出褐色液体 | **水直接接触到菇体，**细菌性软腐 | 不要向菇体喷水，加强通风并清除病株 |
| 子实体细小且分裂成多个 | 伤口制造过多 | 下一周期只在一两处制造伤口 |
| 第2周期几乎没有产量 | 培养基养分耗尽、休养期间培养基干燥 | 维持湿度并在表面再次制造伤口 |
| 培养基发黑发酸 | 细菌繁殖，培养基寿命已到 | 废弃并转为菌糠处理 |

## 11. 菌糠的循环利用

### 11-1. 菌糠不是用来丢弃的

&nbsp;&nbsp;&nbsp;出完菇之后的培养基，是菌丝已经把木质分解过的有机物。白腐菌已经把相当一部分木质素分解掉了，所以比生锯末更适合直接施入田地。评价表中施肥需求为D，指的是每年投入56kg有机物，但重要的是，这56kg并非用一次就消失，而是在循环利用之中。

| 用途 | 方法 |
|:---|:---|
| **基肥** | 秋天摊铺在田里翻耕入土，能大量补充有机质和钾 |
| **覆盖材料** | 铺在作物间，厚度5cm，可抑制杂草并减少水分蒸发 |
| **其他菇类的培养基** | 可以混入大球盖菇的木片培养基中使用 |
| **堆肥促进剂** | 混入堆肥堆能加快分解速度 |
| **蚯蚓养殖基质** | 蚯蚓喜欢食用，可以获得蚯蚓粪 |
| **育苗土** | 与沙子混合后可用作育苗基质 |
| **燃料** | 完全晒干后火力较弱，但仍可燃烧 |

```
阔叶树锯末 + 米糠 → 培养基 → 菇类采收（3-4次） → 菌糠 → 田地有机质
                                    └ 蚯蚓 → 蚯蚓粪
```

&nbsp;&nbsp;&nbsp;不过要注意一点。猴头菇的菌糠仍残留相当多的木质，碳氮比偏高。虽然不像生锯末那么严重，但如果直接大量施入田地，微生物分解时会从土壤中夺取氮素来使用。对策有两个：一是把菌糠单独堆放几个月让它进一步腐熟后再施用，二是同时加入尿液或鸡粪之类的氮源。

&nbsp;&nbsp;&nbsp;受污染的培养基绝不能拿去施田或做堆肥，青霉的孢子会原样进入第二年的培养基。

### 11-2. 段木栽培之后的木材

| 状态 | 利用 |
|:---|:---|
| 出菇结束的段木 | 已变得酥松，用手就能弄碎，可直接施入田地或用作覆盖材料 |
| 仍然坚硬的段木 | 若菌丝还活着，可以劈开用作新段木的接种材料 |
| 完全腐朽的段木 | 状态接近腐叶土，适合用作盆栽土或育苗土 |

### 11-3. 栽培空间的年度管理

| 年度 | 管理 |
|:--:|:---|
| 每个周期 | 清空场地，用水冲洗后放在阳光下晒干 |
| 1年 | 可以继续使用同一场地 |
| 2-3年 | 更换场地更安全，杂菌孢子会不断累积 |
| 应急措施 | 在墙壁和地面涂抹石硫合剂或浓草木灰碱水 |

&nbsp;&nbsp;&nbsp;墙壁和地面可以使用碱性处理。因为那是空间而不是培养基，不受酸度的限制。结束一个周期后，把空的场地空置几天，打开门让阳光照入。紫外线能大幅减少飘落的孢子。这是一种既不需要电力、也不需要药剂的方法。
