## 3. 培地材料と準備

&nbsp;&nbsp;&nbsp;ヤマブシタケの培地には二つの道があります。広葉樹オガクズに米ぬかを混ぜて瓶や袋に詰めて滅菌する道と、コナラの原木にそのまま種菌を打ち込む道です。前者は速く収量も計算できますが、滅菌の燃料と容器を要求します。後者は遅いですが滅菌が不要で、一度接種すれば数年続きます。

> **電力と燃料がない状況では、原木栽培が答えです。評価表の施設負担Dを作ったのは滅菌設備と消耗する袋ですが、原木はその両方を飛び越えます。**

### 3-1. 栽培方式の比較

| 方式 | 収穫量 | 栽培期間 | 滅菌 | 災害適合度 |
|:---|:---|:---:|:---:|:---|
| **瓶栽培** | 850ml瓶当たり356g | 40-45日 | **必要** | 容器と燃料があるとき |
| **袋栽培** | 2,500ml袋当たり810g | 50-60日 | **必要** | 収量が多く有利ですが袋が消耗します |
| **原木栽培** | 0.1㎥当たり1,195.5g | 69日以上、その後数年 | **不要** | **長期災害に最も適合** |

&nbsp;&nbsp;&nbsp;原木栽培の収量が最も高いという点は注目に値します。0.1㎥で1,195.5g、生物学的効率が17.3%です。しかも一度接種すれば毎年出ます。初期の労働が大きく最初の収穫まで長くかかるのが欠点ですが、災害が数年続く状況ではこちらが圧倒的に有利です。

### 3-2. 原木栽培 - 滅菌が不要な道

| 項目 | 基準 | 理由 |
|:---|:---|:---|
| **最適樹種** | **コナラ類** | 収量1,195.5g/0.1㎥、生物学的効率17.3% |
| 使用可能な樹種 | ハンノキ、ポプラ、ニセアカシア | コナラより低いですが育ちます |
| その他 | クルミ、ブナ、カエデ、ヤナギ | 自然発生する樹種です |
| **禁止樹種** | **針葉樹（マツ、チョウセンゴヨウ、カラマツ）** | **樹脂とテルペンが菌糸を抑制します** |
| 伐採時期 | 落葉後から新芽が出る前（11-3月） | 木に養分が最も多く蓄えられている時期 |
| 乾燥 | 伐採後1-2か月陰に置き、水分を40-45%に | 伐ったばかりの木は水分が多すぎます |
| 太さ | 直径10-20cm | 太すぎると菌糸が中心まで届くのに時間がかかります |
| 長さ | 15-20cmの短い切片、または1mの原木 | 短い切片は扱いやすいです |

&nbsp;&nbsp;&nbsp;短い切片を立てて積む方式が災害時によく合います。直径15cm、長さ20cmに切片を切り、切断面に種菌を塗ってから切片を上下に重ねて積みます。菌糸が切断面同士でつながり、複数の切片を一つの塊にします。道具がのこぎりと斧だけでも構いません。

### 3-3. オガクズ培地の配合

| 材料 | 瓶栽培 | 袋栽培 |
|:---|:---:|:---:|
| コナラなど広葉樹オガクズ | 主原料 | 80% |
| 米ぬか | 20-30%の範囲内で | 20% |
| 小麦ふすま | 米ぬかの一部を代替 | |
| ビートパルプ | 米ぬかの一部を代替 | |
| 水分 | 65-67% | 68-75% |
| 培地量 | 850ml瓶に580-620g、1,100ml瓶に750-800g | 袋当たり2kg |

&nbsp;&nbsp;&nbsp;米ぬか、小麦ふすま、ビートパルプを合わせて全体の30%を超えないようにします。栄養源が多いと収量は上がりますが、同時に緑カビが先に爆発的に増える危険も大きくなります。無菌設備がない状況では20%側に下げるほうが安全です。

### 3-4. 農業副産物でオガクズを代替します

&nbsp;&nbsp;&nbsp;評価表のキノコ副産物適応性がCである理由は、広葉樹オガクズと米ぬかの二種類に縛られているという点です。しかし試験結果を見ると、ある程度の代替が可能です。

| 代替材料 | 代替比率 | 結果 |
|:---|:---:|:---|
| 稲わら | 20% | 対照群と差がありません |
| 大豆の殻 | 20% | 生物学的効率に有意な差なし |
| **トウモロコシの茎** | **20%** | **生物学的効率と平均生体重が有意に増加** |

> **トウモロコシの茎でオガクズの20%を代替すると、収量はむしろ増えます。**周りで手に入る稲わらと大豆の殻とトウモロコシの茎を細かく砕いてオガクズの20-30%を代替すれば、災害時に培地の確保がずっと容易になり、収量も落ちません。

&nbsp;&nbsp;&nbsp;代替する際は細かく砕くことが重要です。わらや茎を長いまま入れると、培地の中に大きな空隙ができて菌糸が越えられず、水がたまります。爪の大きさ以下に細かく切って使います。

### 3-5. 電気なしで滅菌する方法

| 方式 | 条件 | 燃料 | 備考 |
|:---|:---|:---:|:---|
| 高圧滅菌 | 121℃90分 | 電力 | 標準 |
| 常圧滅菌 | 100℃4時間または98℃6時間 | 多い | 無電力の標準 |
| **ドラム缶蒸気** | 200Lドラム缶の底に水20-30cm、台の上に容器、蒸気100℃4-6時間 | 薪30-50kg | 一度に大量に |
| 沸騰水での煮沸 | 培地を袋に入れて2-3時間 | 中程度 | 完全な滅菌ではありませんが雑菌の危険が減ります |
| **原木栽培** | **不要** | **なし** | 滅菌の段階自体がありません |

&nbsp;&nbsp;&nbsp;ドラム缶での蒸気滅菌が無電力条件の標準です。底に水を注ぎ、台を置いて容器が水に触れないように立ててから蓋をし、隙間を濡れた布や泥でふさぎます。蒸気が上がり始めてから4-6時間を維持し、火を消したあとは蓋をしたまま一晩かけて冷まします。

&nbsp;&nbsp;&nbsp;一度火を焚くときにドラム缶をいっぱいに満たして一度に処理するほうが燃料効率がはるかに良いです。十個を滅菌するために火を焚くのと、百個を滅菌するために火を焚くのとで、かかる薪の量は大きく変わりません。

### 3-6. 容器 - 袋がないとき

&nbsp;&nbsp;&nbsp;袋と瓶が周期ごとに消耗するという点が、施設負担Dを作った要素です。代案は繰り返し使える容器です。

| 容器 | 使い方 | 注意 |
|:---|:---|:---|
| ガラス瓶（ジャム瓶、漬け物瓶） | 滅菌に強く数年使えます | 急に冷やすと割れます。ゆっくり冷やします |
| 竹筒 | 片側の節を残して切ります。丸ごと煮ます | 割れやすく何度も使えません |
| 甕、かめ | 熱に強く湿度の維持が良いです | 重く滅菌に時間がかかります |
| 木箱に布をかける | 平床栽培の形になります | 雑菌の危険が最も大きいです |
| 耐熱ビニール袋 | 標準的な方式。口を綿や布でふさぎます | 常圧100℃までしか耐えません |

&nbsp;&nbsp;&nbsp;容器の要件は四つです。培地を入れること、滅菌後に雑菌が入らないよう防ぐこと、空気は通すこと、子実体が出る面を残すことです。ヤマブシタケは子実体が大きく育つため、口が広い容器が有利です。口が狭いとキノコが押されて奇形になります。

### 3-7. 栽培空間

| 項目 | 基準 | 災害時の代案 |
|:---|:---|:---|
| 温度 | 培養22-25℃、発生15-24℃ | 春秋の室内、土窟、地下室、北向きの納屋 |
| 湿度 | 培養65-75%、発生80-95% | 大きな箱やかめの中に水の器を置いて作ります |
| **光** | **間接照明。新聞が読める程度** | 窓から離れた場所。直射日光は避けます |
| 通風 | 新鮮な空気が必要です | 上下に換気口を作り自然対流を使います |
| 空間 | 棚を2-3段に | 狭い場所で面積を増やします |

> **ヤマブシタケはマッシュルームとは違い、弱い光を要求します。**完全な暗闇では菌針がうまく垂れ下がらず、固まった塊のまま残ります。かといって直射日光を当てると乾いて黄色く変わります。新聞が読める程度の間接光が正解で、窓から二、三歩離れた場所や、戸の隙間から光が入る納屋が適しています。

## 4. 種菌の確保

&nbsp;&nbsp;&nbsp;キノコには種がありません。種苗店が閉まれば種を買う場所がなく、種を採ってかめに入れておく方式も通用しません。評価表ではヤマブシタケの自家採種はB、種子寿命はDです。無菌操作が必要ですが菌糸の継代は可能で、市販の種菌は6か月から1年で活力を失うという意味です。菌類には植物にない三つの道があります。胞子を採っておく道、生きたキノコの身を切り取って育てる道、すでに育った培地や原木を移す道です。

### 4-1. 胞子の採取と胞子紋

| 段階 | 方法 |
|:---|:---|
| 対象を選ぶ | 菌針が十分に垂れ下がった成熟した個体。黄色くなり始めたものも胞子採取用にはよいです |
| 切り取る | 子実体を培地から切り取ります |
| 台 | **菌針が下を向くようにアルミホイル**の上に置きます |
| 覆う | 器をかぶせて風を防ぎます |
| 放置 | 涼しい場所に24時間 |
| 回収 | 子実体を取り除くと**白色**の胞子の粉が残ります |

&nbsp;&nbsp;&nbsp;このキノコの胞子は白色です。したがって**白い紙で受けると見えません。**必ず濃い色の紙か銀紙、ガラス板で受ける必要があります。紫褐色の胞子を出すサケツバタケや、褐色の胞子を出すマッシュルームとは異なる点です。

&nbsp;&nbsp;&nbsp;紙よりアルミホイルのほうが良いです。紙は湿気を吸い込み、繊維の間に雑菌が隠れます。ホイルは水分を吸収せず表面が滑らかで、胞子をそのまま保存できます。ホイルがなければガラス板が次善です。

### 4-2. 胞子の保存 - 電気なしで10年

| 段階 | 方法 |
|:--:|:---|
| 1 | ホイルの上に胞子を受けます |
| 2 | ホイルを風通しのよい**陰**にもう一日置き、微細な湿気まで飛ばします |
| 3 | 半分に折って胞子の面を内側に保護し、ジップ袋に入れます |
| 4 | **しっかり炒った塩や炭のかけら**を一緒に入れて湿気を取ります |
| 5 | ジップ袋をガラス瓶に集めて**蜜蝋で封をし**、四季を通じて温度が一定で光が入らない**土窟や地下室**に置きます |

| 保存形態 | 寿命 | 備考 |
|:---|:---:|:---|
| 胞子紋（ホイル乾燥） | **5-10年以上** | 水分が排除され細胞活動が停止します |
| 液体種菌（滅菌水懸濁） | 3-6か月 | 冷蔵がなければ早期発芽したり細菌が増殖したりします |
| 接種済み種菌（オガクズ・穀粒） | 6か月-1年 | 生きた菌糸なので養分を使い続けます |
| **接種した原木** | **数年** | 管理だけしていれば毎年出ます |

> **災害時には胞子を液体で保管してはいけません。必ず乾かした胞子紋の形で保管する必要があります。**

&nbsp;&nbsp;&nbsp;紫外線が胞子のDNAを破壊するため、光の入らない深い場所である必要があります。胞子と植物の種の寿命の差は構造から来ます。

| 比較項目 | トマトの種 | キノコの胞子 |
|:---|:---|:---|
| 平均寿命（室温） | 約2-4年 | 約5-10年以上 |
| 脆弱要因 | 温度変化、自身の栄養の枯渇 | 湿気によるカビ汚染 |
| 細胞構造 | 複雑な胚と栄養物質 | 単一細胞と厚い保護壁 |

&nbsp;&nbsp;&nbsp;種は胚と栄養分を抱えており、時間が経つと自ら消耗して老いて死んでいきますが、キノコの胞子は厚い細胞壁に包まれた単一細胞にすぎず、消耗する養分がありません。条件が合えばはるかに長く持ちこたえ、学界では数十年前の胞子を復活させた例も珍しくありません。

> **評価表の種子寿命Dは市販種菌の基準です。胞子紋の形に変えておけば、そのDは実質的に意味を失います。災害初年度に、最も大きく健康な個体で胞子紋を20-30枚作り、土窟に貯めておいてください。種菌をすべて失っても、5年後、10年後に再び始めることができます。**

### 4-3. 組織培養 - 最も確実な方法

&nbsp;&nbsp;&nbsp;生きた新鮮なキノコが手元にあれば、胞子を使う理由はほとんどありません。子実体の内側にある白い身は、すでに交配型の結合が終わった二次菌糸の塊です。その切片を切り取って培地に入れれば、発芽と交配の過程を飛び越えて、すぐに菌糸が四方に伸びます。

| 段階 | 方法 |
|:---|:---|
| 選ぶ | **菌針がまだ短く全体が純白色の**若い個体。黄色く変わったものは使いません |
| 消毒 | 刃物を火で熱してから冷ますか、沸騰した湯に浸けて取り出します |
| 割る | **手で縦に割ります。**刃物で切ると表面の雑菌が内部に持ち込まれます |
| 採取 | 木に付いていた根元側の内側の白い身を米粒大に切り取ります |
| 接種 | 煮て冷ましたオガクズ培地や稲わらの間に挟みます |
| 培養 | 22-25℃の暗い場所。3-5日で切片の周りに白い菌糸が広がります |

&nbsp;&nbsp;&nbsp;割ることが重要な理由は、キノコの内部がほぼ無菌に近いからです。表面にはあらゆる胞子が付着していますが、内部の身は清潔です。手で割ればその清潔な面が新たに露出し、切り取った切片は消毒なしでも純粋な菌糸になります。ヤマブシタケは子実体がスポンジのように柔らかいので割りやすく、根元側が組織が最も硬いため身を切り取りやすいです。

### 4-4. 稲わら加熱培地法 - 胞子から種菌を起こすとき

&nbsp;&nbsp;&nbsp;理論上は胞子を培地に振りかければ菌糸が伸びます。しかし現実には、空気中の緑カビと細菌がキノコの胞子より数百倍速く培地を占領します。栄養価の高い培地ほど脆弱です。電気がない状況では、栄養が過剰な人工培地の代わりに、自然の防御力を利用した原始的な培地を使います。

| 段階 | 方法 |
|:---|:---|
| 煮て絞る | 稲わらや麦わら、大豆の殻を**沸騰した湯で1時間以上**煮て滅菌し、水気を絞って冷まします |
| 接種 | 保管しておいた胞子の粉を惜しまず均一にたっぷりと振りかけます |
| 覆う | **清潔な布で覆い**、風と落下する胞子を防ぎます |
| 培養 | 22-25℃の暗い場所で2-4週間。白い菌糸がわらを覆えば成功です |

&nbsp;&nbsp;&nbsp;栄養の少ないわらは緑カビにとっても魅力が薄く、菌糸の伸びが遅くても競争に負けません。ここで得た菌糸の塊をオガクズ培地に移し、種菌として育てます。

### 4-5. 原木移植 - 最も長持ちする種菌

&nbsp;&nbsp;&nbsp;すでに菌糸が広がった原木を割って新しい原木にこすりつければ種菌になります。原始的ですが確実で、評価表の自家採種Bを作った根拠です。

| 段階 | 方法 |
|:---|:---|
| 対象 | 白い菌糸が切断面まで広がり、雑菌の跡がない原木 |
| 時期 | 春または秋。真夏と真冬は避けます |
| 割る | 斧で割って菌糸が広がった内部を露出させます |
| 移す | 新しい原木の穴や切断面に内部の切片を挟み、木の栓でふさぎます |
| あるいは | よく育った培地をスプーンですくい、新しい培地の重さの5-10%として混ぜます |
| 限界 | 四、五世代を超えると活力が落ちます。定期的に組織培養や胞子に戻します |

### 4-6. 種菌確保の優先順位

| 順位 | 方法 | 条件 |
|:--:|:---|:---|
| 1 | 市販種菌 | 普及度Sなので平時には最も簡単です。事前に確保します |
| 2 | 組織培養 | 新鮮なキノコがあるとき。最も確実です |
| 3 | 原木・培地移植 | すでに育ったものがあるとき。最も速いです |
| 4 | 胞子紋から稲わら培地へ | すべて失い、貯めておいた胞子があるとき |

&nbsp;&nbsp;&nbsp;平時にすべきことは明確です。種菌が手に入るときに一度育て、そのキノコで胞子紋を20-30枚作って土窟に埋めておくことです。そして可能であれば原木何本かに接種しておくことです。原木は数年にわたって生きた種菌の貯蔵庫になります。
