## はじめに
&nbsp;&nbsp;&nbsp;ヤマブシタケ(Hericium erinaceus)は、評価表で除外と判定されました。貯蔵性E(生の基準)と永続性Bが重なり、ゲート未適用スコアは42.5点(有効183種中83位)で、除外されたキノコ3種のなかで最も高いです。永続性Bは、同じ培地から3-4回収穫できるという意味です。ただしこのキノコは、そのまま干すと苦くて硬くなるので、適期に収穫し、ゆでてから干し、粉にして貯蔵することが核心です。強みは、微量栄養素A(RDAの10%を満たす栄養素が14種で、ビタミンDを含む)、タンパク質密度SS(熱量の79.1%)、水の消費量A、そして光合成をしないので日射が減っても収量が保たれる日射SSです。このキノコの最大の利点は安全性です。かさも柄もひだもなく、白い針の束が垂れ下がった姿なので、この形の毒キノコは知られておらず、土からは生えず木に付いて育ち、同じ属のほかの種もすべて食用です。弱点は殺菌設備と消耗する袋(施設の負担D)で、原木栽培に切り替えれば、殺菌なしで数年もちます。

## 1. 災害への備えの評価
| 区分 | 内容 |
|:---|:---|
| 判定 | 除外(貯蔵性E + 永続性B)。ゲート未適用スコア42.5 |
| 強み | SS: タンパク質密度、日射、整地・掘削エネルギー、収量の安定性。A: 微量栄養素、水の消費量。B: 永続性、自家採種 |
| 弱み | E: 貯蔵性(生)、耐寒性、非食用の価値。D: 施設の負担、温度幅、施肥。C: キノコ副産物への適応性(広葉樹のおがくずと米ぬかに縛られる) |

> **キノコは日光が消えた世界でも収量が減らない唯一の食料源であり、ヤマブシタケはその世界で人に不足するビタミンDまで補う種です。**

&nbsp;&nbsp;&nbsp;項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. キノコの概要
&nbsp;&nbsp;&nbsp;担子菌門ベニタケ目サンゴハリタケ科ヤマブシタケ属で、広葉樹の枯れた幹や傷口を分解する白色腐朽菌です。韓国語名は、ノロジカの白いお尻に似ていることから付きました。

| 特徴 | 内容 |
|:---|:---|
| 形 | かさをつくらず、塊のまま5-25cmに育つ。生育の後期に、白い針状の突起(菌針)が1-5cmの長さに垂れ下がる。柄、ひだ、つば、つぼはすべてない |
| 色 | 若いときは純白で、育つにつれて黄色、黄褐色に変わる |
| 肉、胞子 | スポンジのように柔らかい白色。胞子紋は白色 |
| 菌糸 | 白色から黄色、ピンク色に変わり、これは正常な成熟 |
| 発生基質 | 広葉樹の枯れ木と傷口。地面からは生えない |

| 段階 | 期間と温度 | 要点 |
|:---|:---|:---|
| 菌糸の培養 | 20-30日、22-25℃ | 培地が白色に覆われ、黄色く成熟する |
| 芽出しの誘導 | 3-7日、15-20℃、湿度85-95% | 表面に傷をつけると白い塊ができる |
| 生育 | 15-20日、15-24℃、湿度80-85% | 菌針が垂れ下がる。接種から収穫まで50-60日 |
| 再発生 | 10-15日おき | 3-4回 |

&nbsp;&nbsp;&nbsp;培地のpHは4.0-5.5の弱酸性で、米ぬかが入れば自然に下がります。マッシュルームのように木灰や石灰でアルカリ処理をすると菌糸が育たないので、汚染対策は殺菌と種菌の量で立てます。100g当たり熱量13kcal、タンパク質2.57g(熱量の79.1%)、糖類0.54g、豊富な食物繊維、ビタミンDとB群、ヘリセノンとエリナシン(神経成長因子の合成促進が報告されている)が含まれます。

## 3. 培地と殺菌
| 方式 | 収穫量 | 期間 | 殺菌 |
|:---|:---|:---|:---|
| 瓶栽培 | 850mlの瓶当たり356g | 40-45日 | 必要 |
| 袋栽培 | 2,500mlの袋当たり810g | 50-60日 | 必要(袋が消耗する) |
| 原木栽培 | 原木0.1㎥当たり1,195.5g(生物学的効率17.3%) | 69日以上、その後数年 | 不要 |

> **電力と燃料がない状況では、原木栽培が答えです。施設の負担Dをつくったのは殺菌設備と消耗する袋ですが、原木はその両方を省きます。**

| 項目 | 基準 |
|:---|:---|
| 原木 | ナラ類が最適、ハンノキ類・ポプラ・ニセアカシアも可能。針葉樹は樹脂とテルペンが菌糸を抑えるので禁止。落葉の後から新芽が出る前(11-3月)に伐り、日陰で1-2か月置いて水分を40-45%に下げる。直径10-20cm、長さ15-20cmの短い玉(立てて積む)または1mの原木 |
| おがくず培地 | 広葉樹のおがくず80% + 米ぬか20%(瓶栽培は米ぬか20-30%)。米ぬか、ふすま、ビートパルプを合わせて30%を超えない。水分は瓶65-67%、袋68-75%。850mlの瓶に580-620g、袋当たり2kg |
| 代替材料 | 稲わら・豆がら・トウモロコシの茎を細かく砕いて、おがくずの20-30%を置き換える。トウモロコシの茎20%はかえって収量が増える |
| 殺菌 | 常圧で100℃4時間または98℃6時間。電力なしの標準は200Lのドラム缶(底に水20-30cm、台の上に容器、蒸気100℃で4-6時間、薪30-50kg)で、いっぱいに詰めて一度に処理する。袋ごと2-3時間ゆでる方法は完全な殺菌ではない |
| 容器 | ガラス瓶(急に冷ますと割れる)、竹筒、熱に耐えるビニール袋(口は綿か布で塞ぐ) |

| 栽培空間 | 基準 |
|:---|:---|
| 温度 | 培養22-25℃、発生15-24℃(菌糸は下限6℃、上限35℃)。春秋の室内、洞窟、地下室、北向きの納屋 |
| 光 | 新聞が読める程度の間接光。完全な暗闇では菌針が固まって塊のまま残り、直射日光は乾いて黄色くなる |
| 湿度、換気 | 大きな箱や壺の中に水皿を置く。換気は十分に(二酸化炭素がたまるとサンゴのように奇形になる)。キノコに直接水をかけない |

## 4. 種菌の確保と接種
| 方法 | 内容 |
|:---|:---|
| 胞子紋 | 菌針が垂れた成熟した個体を、菌針を下にしてアルミ箔にのせ、器をかぶせると、白色の胞子の粉が残る。日陰で乾かし、折ってジッパー袋に炭とともに入れ、蜜ろうで封じて洞窟に置くと5-10年以上もつ(液体での保管は不可)。初年に20-30枚つくって蓄える |
| 組織培養 | 菌針がまだ短く全体が純白の若い個体の、根元側の内側の白い肉を米粒大にちぎり、ゆでて冷ました培地や稲わらに差し込んで、22-25℃の暗所で培養。3-5日で広がる。最も確実 |
| 移植 | 菌糸が断面まで広がり雑菌の跡がない原木を割り、新しい原木の穴に中身の破片を差し込んで木栓で塞ぐ(春か秋)。よく育った培地を新しい培地の重さの5-10%混ぜてもよい。4、5世代を超えると活力が落ちる |

| 接種 | 基準 |
|:---|:---|
| おがくず培地 | 殺菌後に13-14時間冷まし、培地温度18-20℃で接種。標準は培地重量の2-3%、無菌室がなければ5-10%。中央の穴に半分、表面に半分。口は綿か布で塞いで縛る。雨の直後、ほこりを沈めて、息を吹きかけず、すばやく |
| 原木 | 殺菌しない。3-5月または9-10月に、直径12mm、深さ25-30mmの穴を螺旋状に15-20cm間隔で開け(直径15cm、長さ1mの原木1本に20-30穴)、種菌を詰めて、蜜ろう、松ヤニ、濡れた粘土、木栓で封じる。日陰に寝かせて積み、わらや落ち葉で覆って乾かさない。2-3か月で穴の周囲に白い菌糸が見える |

> **無菌室がないときの核心は、完璧な無菌ではなく、速さと種菌の量です。雑菌が少し入るのは防げないので、キノコの菌糸を圧倒的に多くして先に場所を占めさせます。**

## 5. 培養、発生の誘導、収穫
| 段階 | 管理 |
|:---|:---|
| 菌糸の培養(20-30日) | 22-25℃、暗く。35℃が絶対の線で、菌糸の代謝熱のため周囲が30℃でも培地の中は超えることがあり、容器をぎっしり積まない。菌糸が白から薄い黄色、薄いピンクに変わるのは正常で、汚染は青緑・黒・濃いオレンジ色で、粉のように舞い、丸い斑点から放射状に広がり、1日10-30mm(正常は3-5mm)で進む。底まで届いた後、5-7日さらに置く(熟成) |
| 芽出しの誘導 | 表面を、熱湯で消毒したナイフの先、釘、串で5-10mmの深さに、瓶は2-3か所、袋は片面に3-5か所突くか十字に切って、菌糸層を裂く(再発生率と品質が最もよい)。子実体を1つ大きく育てるには、傷は1、2か所だけにする |
| 生育 | 15-24℃(最適15-20℃。低いほど菌針が長く硬く、苦みが少ない。22℃を超えると柔らかくすぐ黄色くなる)、湿度は芽出し期85-95%、生育期80-85%。収穫の3-4日前は水をまったくかけず、湿度を少し下げると、色が白いまま残り、貯蔵性が高まる |

&nbsp;&nbsp;&nbsp;電力がなければ春秋の作物です(春は4月-6月初め、秋は9月-11月初め)。真夏は菌糸が35℃で死に、真冬は芽出しが止まります。原木の屋外栽培は、半日陰に原木を立てるか寝かせて季節に任せます。

| 収穫 | 基準 |
|:---|:---|
| 時期 | 子実体全体が乳白色で、菌針が1-5cmと十分に垂れているが、先が乾いていないとき。黄色みを帯び始めたらもう遅い(苦みが強くなり組織が硬くなる)。苦みは主に過熟から来る |
| 要領 | 根元を手で包むように持ち、軽くひねって取る。洗わない(スポンジ状の組織が水を吸って1日で黄色くなり柔らかくなる) |
| 再発生 | 表面の残った根元を取り除き、湿度を保って22-25℃に置き、表面にもう一度傷をつける。合計3-4回 |

## 6. 汚染と病害虫、異常の診断
&nbsp;&nbsp;&nbsp;競合するカビ(アオカビ)に培地を奪われることが、最もよくある失敗の原因です。アオカビは色が見える前にすでに広がっているので、色ではなく質感、におい、速さで判別し、このキノコは菌糸自体が黄色やピンクになるので、色だけを見て捨てません。アルカリ処理は使えないので、殺菌を十分に行い(常圧100℃で4-6時間)、栄養源(米ぬか、ふすま)を30%以下にし、容器の間に隙間をあけて積み、最も根本的には、樹皮と木質そのものが防御壁になる原木栽培に切り替えます。

| 状況 | 対処 |
|:---|:---|
| 1つの容器の表面に小さな斑点 | その容器だけを開けずにすぐ取り出す |
| 複数の容器に広がった | 培養場所全体を移し、元の場所は空にして水で洗って乾かす |
| 害虫 | キノコバエは入口を目の細かい布で塞いで水皿・粘着板のトラップ。ダニは乾燥気味に管理して区画を隔離。ナメクジ(菌針が柔らかく特にやられる)は灰やおがくずの帯を巡らせ、夜に手で捕る。原木ではリス、ネズミ、鳥が持ち去るのでネットをかぶせる |

> **汚染された培地を堆肥に回してはいけません。アオカビの胞子は堆肥の山で生き残り、翌年の培地にまた入り込みます。燃やすか、栽培場所から離れた場所に深く埋めます。**

| 症状 | 原因と措置 |
|:---|:---|
| 菌糸が伸びて止まる | 培地温度が35℃超か水分不足。容器の間をあけて熱を逃がす |
| 菌糸はよいがキノコが出ない | 表面に傷をつけていない、温度を下げていない、または光がまったくない |
| サンゴやカリフラワーのように裂ける | 二酸化炭素過多。換気を大きく増やす |
| 菌針が垂れず塊になって固まる | 光不足。間接光を入れる |
| 黄色く変色 | 過熟、22℃超、直射日光。適期に収穫して涼しい日陰へ |
| 柔らかくなって茶色い汁が出る | キノコに直接水が当たった(細菌性の軟腐)。換気して病んだものを取り除く |
| 小さく複数に裂ける | 傷をつけすぎた。次の周期は1、2か所だけに |

&nbsp;&nbsp;&nbsp;廃菌床は畑の有機物やミミズの基質に使い(汚染されたものは決して回さない)、すっかり収穫し終えた原木は、ぼろぼろになったら畑に入れるかマルチ材に、菌糸が生きていれば割って新しい原木の接種用に、朽ちたものは育苗用の土に使います。培養場所は周期ごとに空にして水で洗って乾かし、2-3年で移します。

## 7. 安全の確認
> **この節は命に直結します。ヤマブシタケは取り違えの危険が最も低いキノコですが、なぜ低いのかを知ってこそ、その利点を正しく使えます。**

| 理由 | 内容 |
|:---|:---|
| 形が唯一 | かさも柄もひだもなく、白い針の束が垂れ下がった姿の致命的な毒キノコは知られていない |
| 土から生えない | 広葉樹の枯れ木や傷口に付いて育ち、テングタケ類はすべて地面から生える |
| 同じ属がすべて食用 | ヤマブシタケ属(サンゴハリタケなど)に毒性のある種は報告されていない |

&nbsp;&nbsp;&nbsp;それでも確認すべきことがあります。Climacodon類は木に棚状に層になって付き、針が短く、組織が革のように硬く、苦いものが多くて食べられません。白いカビの塊は針がなく、綿や粉のような汚染菌です。若いホコリタケ類は丸い形で針がなく、割ると中が均一に白い綿のようです。薄く広がる硬質菌類は、木に薄く広がり、硬いです。

| 確認項目 | ヤマブシタケの基準 |
|:---|:---|
| 形 | 塊から菌針が下に垂れる。棚状に層になって付かない |
| 菌針の長さ | 1-5cm。目にはっきりと長い必要がある |
| 組織 | スポンジのように柔らかく、指で押すとへこみ、手で裂ける。革のように硬ければ別物(最も確実) |
| 基質、味 | 広葉樹の枯れ木や傷口(地面から生えたものは違う)。舌先につけて強く苦ければ吐き出す |

&nbsp;&nbsp;&nbsp;初めて食べるときは確認手順をすべて踏み、十分に加熱し(生は消化しにくく、胃を刺激する)、1人が少量だけ食べて24時間待ちます。ほかのキノコも一緒に扱うなら、食べて6-24時間後に嘔吐と下痢が始まるのが、肝臓を壊すアマトキシン中毒の典型的な経過だと覚えておきます。災害時に最も安全なキノコの食料は、自分が種菌を入れた培地から出たものです。

## 8. 貯蔵、調理、年間日程
> **貯蔵性Eは乾燥で解決しますが、このキノコはそのまま干すと苦く硬くなります。スポンジ状の組織が乾くときに縮んで繊維がからむと、水に戻してもほどけず、過熟した個体の苦み成分が濃縮されます。最大の原因は、乾燥技術ではなく収穫の時期です。**

| 貯蔵 | 内容 |
|:---|:---|
| 生 | 3-5日。洗ったり、ビニールに密封したり、積み重ねたりすると傷む。乾いた布や紙に包んで12-15℃の洞窟で1-2週間 |
| 乾燥(推奨) | 白いうちに収穫し、手で繊維に沿って1-2cmの厚さに裂く(ナイフで切らない)。塩を入れた熱湯で3-5分ゆで(核心)、冷水に浸してもう一度あく抜きをし、水気を絞った後、日陰で風にあててゆっくり干し、仕上げに日向で半日(ビタミンDが増える)。高温の急速乾燥は苦みを固定し、組織を硬くする |
| 粉(最も実用的) | ゆでて完全に乾燥したものを臼や石臼で挽いて篩にかけ、炭とともに密閉して涼しく暗い場所に。硬さの問題がなくなり、苦みが分散する |
| その他 | 塩漬け(ゆでて塩20%、6か月-1年、乾燥より食感がよく残る)、漬け物(3-6か月)、3%の塩水での乳酸発酵(3-6か月)、油漬け(1-3か月)。貯蔵分の半分は漬け物に、半分は粉に |

&nbsp;&nbsp;&nbsp;ヤマブシタケは生で食べません。ゆでるのは3-5分、炒めるのは5-8分(油で炒めるとカニや鶏肉のような繊維感が出る)、焼くのは5-8分、汁物・煮込みは10分以内、チヂミは5-8分で、調理の前に水気を強く絞ります。苦みがあれば、ゆでて冷水で何度もあく抜きするか、味噌・コチュジャン・油・酢とともに調理するか、粉にして汁1鍋にひと匙ずつ使います。乾燥したものはぬるま湯に30分以上浸し、戻し汁を味見して、苦ければ捨て、苦くなければだしに使います。このキノコは熱量源ではなく、タンパク質とビタミンDとB群の補給源です。

| 月 | 作業 |
|:---|:---|
| 1-3月 | 原木の伐採(11-3月)、おがくず集め、3月に原木を日陰で乾燥させ、春作の培地の調製と殺菌(ドラム缶で一度に) |
| 4-6月 | 4月に原木の接種とおがくず培地の接種・培養、5月に芽出しの誘導(表面に傷)と初収穫、6月に収穫の最盛期と大量乾燥・粉づくり |
| 7月 | 暑くて育てない(35℃を超えると菌糸が死ぬ)。原木は日陰で、乾かさないようにだけ管理 |
| 8-9月 | 8月に秋作の培地の調製と殺菌(おがくずとトウモロコシの茎を確保)、9月に接種と培養 |
| 10-12月 | 10月に芽出しの誘導と収穫(涼しく菌針が長く苦みが少ない最良の時期)、11月に収穫の最盛期と大量乾燥、12月に廃菌床を畑に入れ、胞子紋を点検し、原木にわらを覆って越冬 |

> **決して忘れてはならないこと: 白いうちに摘み、ゆでてから干し、粉にして貯蔵し、キノコに直接水をかけず、表面に傷をつけて芽出しを誘導し、弱い光を与え、培地に木灰や石灰を入れず、菌糸が黄色やピンクに変わるのは正常で、35℃を超えさせず、燃料を節約するなら原木栽培に切り替える。**
