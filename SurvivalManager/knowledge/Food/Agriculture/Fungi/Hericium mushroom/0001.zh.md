## 引言
&nbsp;&nbsp;&nbsp;猴头菇（Hericium erinaceus）在评价表中被判定为排除。耐储性E（以鲜品为准）与持续性B叠加，未适用关卡得分为42.5分（有效183种中第83位），是三种被排除蘑菇中最高的。持续性B的意思是同一份培养料可以收3-4茬。不过这种蘑菇直接晒干会又苦又硬，所以关键是适时采收、焯水后再晒干、磨成粉储存。优势是微量营养素A（满足RDA 10%的营养素有14种，包括维生素D）、蛋白质密度SS（占热量的79.1%）、水消耗量A，以及因不进行光合作用，光照减少时产量也能保持的光照SS。它最大的好处是安全。没有菌盖、菌柄和菌褶，只有一丛垂下的白色针刺，没有已知的毒蘑菇长成这个样子；它不从土里长出，而是长在树上；同属的其他种也都能吃。弱点是灭菌设备和用后即弃的菌袋（设施负担D），改成段木栽培就不用灭菌，能用好几年。

## 1. 灾害应对评估
| 类别 | 内容 |
|:---|:---|
| 判定 | 排除（耐储性E + 持续性B）。未适用关卡得分42.5 |
| 优势 | SS：蛋白质密度、光照、整地·挖掘能量、产量稳定性。A：微量营养素、水消耗量。B：持续性、自留种 |
| 劣势 | E：耐储性（鲜品）、耐寒性、非食用价值。D：设施负担、温度幅度、施肥。C：蘑菇副产物适应性（受限于阔叶树锯末和米糠） |

> **蘑菇是阳光消失的世界里产量也不会下降的唯一粮食来源，而猴头菇是连那个世界里人会缺乏的维生素D也能提供的品种。**

&nbsp;&nbsp;&nbsp;各项目的等级见“灾害应对作物评价结果”文档。

## 2. 蘑菇概述
&nbsp;&nbsp;&nbsp;属担子菌门红菇目猴头菌科猴头菌属，是分解阔叶树枯死树干和伤口的白腐菌。韩语名因形似狍子白色的屁股而得名。

| 特征 | 内容 |
|:---|:---|
| 形状 | 不形成菌盖，整块长成5-25cm。生长后期，白色针状突起（菌刺）垂下1-5cm长。没有菌柄、菌褶、菌环和菌托 |
| 颜色 | 幼时纯白，随生长变为黄色至黄褐色 |
| 菌肉、孢子 | 像海绵一样柔软，白色。孢子印为白色 |
| 菌丝 | 由白色变黄色、粉红色，这是正常的成熟 |
| 生长基质 | 阔叶树枯死木和伤口。不从地里长出 |

| 阶段 | 期间与温度 | 要点 |
|:---|:---|:---|
| 菌丝培养 | 20-30天，22-25℃ | 培养料被白色覆盖，随后成熟变黄 |
| 诱导原基 | 3-7天，15-20℃，湿度85-95% | 在表面划伤就会形成白色团块 |
| 生长 | 15-20天，15-24℃，湿度80-85% | 菌刺垂下。从接种到收获50-60天 |
| 再出菇 | 间隔10-15天 | 3-4茬 |

&nbsp;&nbsp;&nbsp;培养料pH为4.0-5.5的弱酸性，加入米糠后自然降低。像双孢菇那样用草木灰或石灰做碱性处理，菌丝就不长，所以污染对策要靠灭菌和菌种量。每100g含热量13kcal、蛋白质2.57g（占热量的79.1%）、糖类0.54g、丰富的膳食纤维、维生素D和B族维生素，以及猴头菌酮和猴头菌素（据报道可促进神经生长因子合成）。

## 3. 培养料与灭菌
| 方式 | 产量 | 期间 | 灭菌 |
|:---|:---|:---|:---|
| 瓶栽 | 每850ml瓶356g | 40-45天 | 需要 |
| 袋栽 | 每2,500ml袋810g | 50-60天 | 需要（菌袋被消耗） |
| 段木栽培 | 每0.1㎥段木1,195.5g（生物转化率17.3%） | 69天以上，之后数年 | 不需要 |

> **没有电和燃料时，答案是段木栽培。造成设施负担D的是灭菌设备和用后即弃的菌袋，而段木把这两样都省了。**

| 项目 | 标准 |
|:---|:---|
| 段木 | 栎类最好，桤木、杨树、刺槐也可以。针叶树的树脂和萜烯会抑制菌丝，所以禁用。落叶后到发芽前（11-3月）砍伐，在阴凉处放1-2个月，把含水量降到40-45%。直径10-20cm，长15-20cm的短段（竖着堆）或1m的段木 |
| 锯末培养料 | 阔叶树锯末80% + 米糠20%（瓶栽米糠20-30%）。米糠、麸皮、甜菜渣合计不超过30%。水分瓶栽65-67%，袋栽68-75%。850ml瓶装580-620g，每袋2kg |
| 替代材料 | 把稻草、豆荚、玉米秆捣碎，替代锯末的20-30%。20%的玉米秆反而使产量增加 |
| 灭菌 | 常压100℃ 4小时或98℃ 6小时。无电的标准是200L铁桶（底部放水20-30cm，支架上放容器，100℃蒸汽4-6小时，柴火30-50kg），一次装满集中处理。把培养料装袋煮2-3小时不是完全灭菌 |
| 容器 | 玻璃瓶（骤冷会裂）、竹筒、耐热塑料袋（口用棉花或布塞住） |

| 栽培空间 | 标准 |
|:---|:---|
| 温度 | 培养22-25℃，出菇15-24℃（菌丝下限6℃，上限35℃）。春秋的室内、窑洞、地窖、朝北棚屋 |
| 光 | 能看报纸程度的散射光。完全黑暗时菌刺会粘成一团，直射阳光会使其干燥发黄 |
| 湿度、通风 | 在大箱子或瓮里放水盘。通风要充分（二氧化碳积累会像珊瑚一样畸形）。不要直接往蘑菇上喷水 |

## 4. 菌种获取与接种
| 方法 | 内容 |
|:---|:---|
| 孢子印 | 把菌刺垂下的成熟个体，菌刺朝下放在铝箔上，扣上容器，会留下白色孢子粉。在阴凉处晾干，折叠后与木炭一起装进自封袋，用蜂蜡封口，放在窑洞里，可存放5-10年以上（不能用液体保存）。第一年做20-30张存起来 |
| 组织培养 | 取菌刺还短、整体纯白的幼嫩个体，从基部内侧取白色菌肉，撕成米粒大小，夹进煮过放凉的培养料或稻草中，在22-25℃暗处培养。3-5天蔓延。最可靠 |
| 移植 | 把菌丝已蔓延到断面、没有杂菌痕迹的段木劈开，把内部碎片塞进新段木的孔里，用木塞堵住（春或秋）。把长得好的培养料按新培养料重量的5-10%混入也可以。超过四五代活力就会下降 |

| 接种 | 标准 |
|:---|:---|
| 锯末培养料 | 灭菌后冷却13-14小时，在培养料温度18-20℃时接种。标准为培养料重量的2-3%，没有无菌室则取5-10%。中央孔放一半，表面放一半。口用棉花或布塞住扎紧。雨后、让灰尘沉降、不要对着呼气、动作要快 |
| 段木 | 不灭菌。3-5月或9-10月，按15-20cm间距呈螺旋状钻直径12mm、深25-30mm的孔（直径15cm、长1m的段木每根20-30孔），填入菌种，用蜂蜡、松脂、湿泥或木塞封住。在阴凉处横放堆起，盖上稻草或落叶以免干燥。2-3个月后孔周围可见白色菌丝 |

> **没有无菌室时，关键不是完美无菌，而是速度和菌种量。几个杂菌混进去是无法避免的，所以让蘑菇菌丝压倒性地多，先占住地盘。**

## 5. 培养、催菇与收获
| 阶段 | 管理 |
|:---|:---|
| 菌丝培养（20-30天） | 22-25℃，黑暗。35℃是绝对界线，菌丝会产生代谢热，所以即使周围是30℃，培养料内部也可能超过，因此不要把容器堆得太密。菌丝由白色变淡黄、淡粉色是正常的，污染则是蓝绿、黑、深橙色，像粉末一样飘散，从圆斑呈放射状扩散，每天推进10-30mm（正常为3-5mm）。长到底后再放5-7天（后熟） |
| 诱导原基 | 用开水消毒过的刀尖、钉子、竹签，在表面刺或划十字，深5-10mm，瓶栽2-3处，袋栽单面3-5处，撕裂菌丝层（再出菇率和品质最好）。若想长一个大的子实体，只划一两处 |
| 生长 | 15-24℃（最适15-20℃，越低菌刺越长越结实、苦味越少，超过22℃则软烂并很快变黄），湿度原基期85-95%，生长期80-85%。收获前3-4天完全不喷水并稍微降低湿度，颜色就保持洁白，耐储性提高 |

&nbsp;&nbsp;&nbsp;没有电的话，这是春秋作物（春季4月至6月初，秋季9月至11月初）。盛夏菌丝在35℃就死，严冬原基形成停止。段木户外栽培是在半阴处把段木立起或横放，交给季节。

| 收获 | 标准 |
|:---|:---|
| 时期 | 整个子实体呈乳白色、菌刺长到1-5cm而尖端未干时。一旦泛出黄色就已经晚了（苦味变强、组织变硬）。苦味主要来自过熟 |
| 要领 | 用手包住基部，轻轻一拧摘下。不洗（海绵状组织吸水，一天就变黄变软） |
| 再出菇 | 去掉表面残留的基部，保持湿度，放在22-25℃，并再次在表面划伤。共3-4茬 |

## 6. 污染、病虫害与异常诊断
&nbsp;&nbsp;&nbsp;最常见的失败原因是培养料被竞争霉菌（绿霉）抢走。绿霉在显出颜色之前已经蔓延，所以不要看颜色，而要靠质地、气味和速度来判断；而且这种蘑菇的菌丝本身就会变黄变粉，所以不能只凭颜色就扔掉。碱性处理不能用，因此要充分灭菌（常压100℃ 4-6小时）、营养源（米糠、麸皮）不超过30%、容器之间留空隙堆放，最根本的办法是改成树皮和木质本身就是防御墙的段木栽培。

| 情况 | 处理 |
|:---|:---|
| 一个容器表面有小斑点 | 只把那个容器不打开直接拿出去 |
| 蔓延到多个容器 | 把整个培养场所搬走，原处腾空、洗净晒干 |
| 害虫 | 菇蝇用细布堵住入口并设水盆、粘板诱捕。螨要保持干燥并隔离该区块。蛞蝓（菌刺软，尤其容易被吃）撒一圈灰或锯末，夜里人工捉。段木上松鼠、老鼠、鸟会叼走，要罩网 |

> **不要把被污染的培养料回收成堆肥。绿霉孢子在堆肥堆里存活，第二年又会回到培养料里。要烧掉，或埋到离栽培场所远的深处。**

| 症状 | 原因与处理 |
|:---|:---|
| 菌丝长一阵就停 | 培养料温度超过35℃或缺水。拉开容器间距散热 |
| 菌丝很好但不出菇 | 表面没划伤、没降温，或完全没有光 |
| 像珊瑚或花椰菜一样开裂 | 二氧化碳过多。大幅加强通风 |
| 菌刺不垂下，粘成一团 | 光不足。给散射光 |
| 变黄 | 过熟、超过22℃、直射阳光。适时收获并移到更凉的阴处 |
| 变软并流出褐色汁液 | 水直接淋到蘑菇上（细菌性软腐）。通风并清除病菇 |
| 小而裂成数个 | 划伤太多。下一茬只划一两处 |

&nbsp;&nbsp;&nbsp;废菌包用作田里的有机物和蚯蚓的基质（被污染的绝不回用）；出完菇的段木，酥烂了就施进田里或作覆盖物，菌丝还活着的就劈开用于接种新段木，腐朽了的用作育苗土。培养场所每茬腾空、洗净晒干，2-3年后换地方。

## 7. 安全确认
> **这一节直接关系到生命。猴头菇是误认风险最低的蘑菇，但只有知道为什么低，才能好好利用这个优势。**

| 理由 | 内容 |
|:---|:---|
| 形态独一无二 | 没有菌盖、菌柄和菌褶，只有一丛垂下的白色针刺的致命毒蘑菇，目前未知 |
| 不从土里长出 | 长在阔叶树枯死木或伤口上，而鹅膏类全都长在地上 |
| 同属都可食用 | 猴头菌属（珊瑚状猴头菌等）没有毒性种的报道 |

&nbsp;&nbsp;&nbsp;即便如此，也有要确认的地方。Climacodon类在树上像搁板一样层层生长，针刺短，组织像皮革一样坚韧，多数味苦，不能吃。白色霉菌团块没有针刺，是像棉絮或粉末一样的污染菌。幼小的马勃类是球形、没有针刺，掰开里面像棉絮一样均匀洁白。薄薄铺在木头上的硬质菌类，质地坚韧。

| 确认项目 | 猴头菇的标准 |
|:---|:---|
| 形状 | 从团块上垂下菌刺。不是像搁板一样层层生长 |
| 菌刺长度 | 1-5cm。必须明显地长 |
| 组织 | 像海绵一样柔软，手指一按就陷下去，能用手撕开。像皮革一样韧就是别的东西（最可靠） |
| 基质、味道 | 阔叶树枯死木或伤口（长在地上的不是它）。用舌尖点一点，如果强烈发苦就吐掉 |

&nbsp;&nbsp;&nbsp;第一次吃时，要走完所有确认步骤，充分煮熟（生吃难消化、刺激胃），由一个人只吃少量并等待24小时。如果同时处理其他蘑菇，要记住：吃后6-24小时才开始呕吐腹泻，是破坏肝脏的鹅膏毒肽中毒的典型经过。灾害时最安全的蘑菇食物，是从我自己接种的培养料上长出来的。

## 8. 储存、烹调与全年日程
> **耐储性E靠干燥来解决，但这种蘑菇直接晒干会又苦又硬。海绵状组织干燥时收缩，纤维缠在一起，泡水也解不开，过熟个体的苦味成分还会被浓缩。最大的原因不是干燥技术，而是采收时间。**

| 储存 | 内容 |
|:---|:---|
| 鲜品 | 3-5天。洗了、塑料密封或堆压都会坏。用干布或纸包好，放在12-15℃的窑洞里1-2周 |
| 干燥（推荐） | 趁白色时采收，用手顺纹理撕成1-2cm厚的条（不用刀切）。在加盐的沸水里焯3-5分钟（关键），再用冷水泡一次去苦、挤干水分，在阴凉处靠风慢慢晾干，最后晒半天太阳（维生素D增加）。高温快速干燥会固定苦味并使组织变硬 |
| 磨粉（最实用） | 把焯过并完全干燥的碎块用臼或石磨磨碎、过筛，与木炭一起密封，放在阴凉黑暗处。变硬的问题消失，苦味也被分散 |
| 其他 | 盐渍（焯后用盐20%，6个月至1年，比干燥更能保留口感）、酱腌（3-6个月）、3%盐水乳酸发酵（3-6个月）、油浸（1-3个月）。储存量的一半做腌制，一半做成粉 |

&nbsp;&nbsp;&nbsp;猴头菇不生吃。焯水3-5分钟，炒5-8分钟（用油炒会有蟹肉或鸡肉般的纹理），烤5-8分钟，汤或炖10分钟以内，煎饼5-8分钟，烹调前要把水分用力挤干。如果有苦味，就焯水后用冷水泡去几次，或与大酱、辣酱、油、醋一起烹调，或磨成粉，每锅汤用一勺。干品用温水泡30分钟以上，尝一下泡的水，苦就倒掉，不苦就当汤用。这种蘑菇不是热量来源，而是蛋白质、维生素D和B族维生素的补充来源。

| 月份 | 作业 |
|:---|:---|
| 1-3月 | 砍伐段木（11-3月）、收集锯末，3月把段木在阴凉处晾干，并调制春茬培养料和灭菌（用铁桶一次完成） |
| 4-6月 | 4月段木接种和锯末培养料接种·培养，5月诱导原基（表面划伤）与首次收获，6月收获高峰与大量晒干·磨粉 |
| 7月 | 太热不种（超过35℃菌丝就死）。段木放在阴处，只管不让它干 |
| 8-9月 | 8月调制秋茬培养料并灭菌（备好锯末和玉米秆），9月接种与培养 |
| 10-12月 | 10月诱导原基与收获（凉爽，菌刺长、苦味少的最佳时期），11月收获高峰与大量晒干，12月把废菌包施进田里、检查孢子印、给段木盖上稻草越冬 |

> **绝对不要忘记：趁白色采收，焯水后再晒干，以粉的形式储存，不要直接往蘑菇上喷水，靠表面划伤诱导原基，给微弱的光，培养料里不放草木灰或石灰，菌丝变黄变粉是正常的，不要超过35℃，想省燃料就改用段木栽培。**
