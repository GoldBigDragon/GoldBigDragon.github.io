&nbsp;&nbsp;&nbsp;マッシュルームは除外作物です。貯蔵性Eと永続性Cが重なり、備蓄が成立しないという判定を受けました。ゲートを適用しない場合の仮の点数は40.8点で、有効183種のうち103位に相当します。貯蔵性の点数が低いのは生のままの状態を基準にしているためで、乾燥によって改善できます。一方、永続性のほうは堆肥を新しく作り直さなければならないという労働の問題として残ります。

### 1-3. 太陽光SSが意味すること

&nbsp;&nbsp;&nbsp;評価表の太陽光の項目は、本来40%遮光の条件下でどれだけ収量が残るかを問うものです。マッシュルームに付いたSSは、その競争に勝ったという意味ではなく、そもそもその軸の上にいないという意味です。菌類には葉緑素がありません。マッシュルームが使う炭素は稲わらにすでに固定されているセルロースであり、空の明るさはその在庫に何の影響も与えません。マッシュルームは光をそもそも必要としません。完全な暗黒条件でも正常に子実体を結ぶ、光にもっとも無関係な栽培キノコです。

&nbsp;&nbsp;&nbsp;大規模な火山噴火や核の冬のように、日射量が数年にわたって減少する状況で、この違いが決定的に現れます。成層圏にエアロゾルが広がると、穀物、いも類（塊茎・塊根）、野菜が同時に崩れます。しかしそのときでも、わらと落ち葉と家畜のふんはそのまま残っており、それを人が食べられるタンパク質に変える唯一の経路がキノコです。

&nbsp;&nbsp;&nbsp;さらにマッシュルームにはもう一つ利点が加わります。日射が減れば気温も下がります。マッシュルームの子実体形成温度は16-18℃で、菌糸培養は23-25℃です。真夏の室内で16℃を作るよりも、冷え込んだ世界で作るほうが簡単です。温度適応幅Dと耐寒性Eは狭くて弱い値ですが、その狭い間隔が示す温度帯自体は涼しい側にあります。

> **キノコは日光が消えた世界でも収量が減らない唯一の食料源であり、マッシュルームは薪を一本も使わずにそれをなし遂げる唯一の種です。**

### 1-4. 強みをどう読むか

&nbsp;&nbsp;&nbsp;SSが付いた項目は、タンパク質密度、太陽光、整地・掘削エネルギー、収量安定性の四つです。Sは収穫速度、連作適応性、味、韓国国内での栽培普及度、キノコ副産物適応性の五つです。

&nbsp;&nbsp;&nbsp;タンパク質密度SSは特別です。熱量15kcalにタンパク質3.12gですから、熱量に占めるタンパク質の割合は83.2%です。要求ライン10%の八倍で、この文書が扱う六種のうちもっとも高い値です。マッシュルームは事実上、ほぼタンパク質と水だけでできた食品です。熱量としてはほとんど意味を持ちませんが、タンパク質の補給源としては非常に効率的です。

&nbsp;&nbsp;&nbsp;キノコ副産物適応性Sがもっとも実質的な強みです。五つの範疇が満たされます。繊維質（稲わら、麦わら、大麦わら、トウモロコシの茎、枯れ草、もみ殻）、畜産副産物と家畜のふん（馬糞、牛糞、鶏糞、豚糞）、炭と灰（草木灰）、骨と貝殻（貝殻、卵の殻で石膏を代替）、加工パルプ（古紙、使用済みの紙）です。ほかのキノコが広葉樹のおがくず一つに縛られているのとは対照的です。この適応性は災害時に直接的な意味を持ちます。おがくずが手に入らなくても、ナラやクヌギの林がなくても、製材所が閉まっていても、田んぼにわらがあり牛舎にふんがあれば、マッシュルーム栽培は成り立ちます。

&nbsp;&nbsp;&nbsp;収穫速度Sも目を引きます。堆肥を菌床に入れてから40-60日で最初の収穫です。前段階の堆肥発酵2-3週間を足しても、全体で二か月半以内に収まります。シイタケが12-18か月を要するのと比べると差は大きく、災害が起きたその年に始めて、その年のうちに食べられます。

&nbsp;&nbsp;&nbsp;そして評価表に数値として現れない、もっとも大きな強みがあります。堆肥発酵そのものが殺菌になっているという点です。3節で詳しく扱いますが、この一点がマッシュルームをほかの五種と根本的に区別します。施設負担Dという等級は栽培舎と木枠と発酵場を要求するという意味であり、その三つはいずれも木と土とわらで作れます。電力が必要なものは一つもありません。

### 1-5. 弱みをどう読むか

&nbsp;&nbsp;&nbsp;Eは三つです。耐寒性、貯蔵性、非食用価値。Dは四つです。施肥、施設負担、温度適応幅、種子寿命。Cは四つです。面積当たり熱量、永続性、防除自立度、自家採種。

&nbsp;&nbsp;&nbsp;温度適応幅Dと耐寒性Eは合わせて読む必要があります。子実体形成温度は16-18℃と幅が狭く、この窓を外れると発生が止まります。12℃を下回ると原基が結ばれず、22℃を超えると傘がすぐに開いて品質が崩れます。電力がない状況での対応は季節と土地です。春と秋が16-18℃にもっとも近く、土窟と地下室は一年中12-18℃を保ちます。マッシュルームを電力なしで育てるということは、つまり春秋作型で、あるいは土窟の中で育てるということです。

&nbsp;&nbsp;&nbsp;施肥Dはその性格を正確に読み取る必要があります。化学肥料は一切使いません。その代わり、稲わらとふんを大量に集めなければなりません。㎡あたり堆肥50-60kgが入り、その堆肥を作るには生の稲わらがその二倍ほど必要です。近くに田んぼがなければこの条件を満たすのは難しいです。マッシュルームは土地に縛られた作物ではなく、田んぼと牛舎に縛られた作物です。

&nbsp;&nbsp;&nbsp;永続性Cは、二、三周期収穫すると堆肥を新しく作り直さなければならないという意味です。シイタケの原木4-5年や、サケツバタケの定着菌床数年と比べると短い期間です。ただし廃堆肥はそのまま優れた畑の肥料になるため、無駄になるわけではありません。11節で扱います。

&nbsp;&nbsp;&nbsp;自家採種Cと種子寿命Dが実質的な障害です。マッシュルームの種菌は無菌培養によって作られ、市販の種菌は6か月から1年で活力を失います。しかもマッシュルームは、ほかのキノコよりも胞子から菌株を立ち上げるのが難しい種です。この種は担子器に胞子を二個しか作らず、その胞子がすでに二つの核を持っている場合が多いため、胞子一つから育った菌糸がそのまま子実体を結べる一方、遺伝的多様性がほとんどありません。発芽率も低いです。対応策は4節で扱う組織培養と菌床の移植です。

&nbsp;&nbsp;&nbsp;非食用価値Eは、8項目のうちどれにも該当しないという意味です。マッシュルームは食用以外の用途が確認されていません。

&nbsp;&nbsp;&nbsp;そして評価表には書かれていない、もっとも重い弱点があります。誤認の危険です。マッシュルームは土から生え、傘と柄と襞とつばをすべて備えた典型的なキノコの形をしており、収穫の適期は傘が閉じた白いボタン段階です。この三つの条件は、人を死に至らしめるシロタマゴテングタケとドクツルタケの幼菌と正確に重なります。12節は必ず読む必要があります。

## 2. どんな菌類か

### 2-1. 名前と分類

&nbsp;&nbsp;&nbsp;マッシュルームは担子菌門ハラタケ綱ハラタケ目ハラタケ科ハラタケ属に属します。学名Agaricus bisporusの種小名bisporusは「胞子が二つ」という意味です。大多数の担子菌は担子器一つに胞子を四つ付けますが、この種は二つしか付けません。この小さな違いが、4節で見る種菌確保の難しさを生みます。

&nbsp;&nbsp;&nbsp;韓国語の名称「ヤンソンイ」は「西洋から来たマツタケ」という意味で付けられており、マツタケ（Tricholoma matsutake）とは無関係です。英語圏ではボタンマッシュルーム、ホワイトマッシュルームと呼ばれ、傘が開いて大きくなったものはポートベロと呼ばれます。三つとも同じ種で、収穫時期と品種が違うだけです。

&nbsp;&nbsp;&nbsp;生態的には、分解がかなり進んだ有機物の山に生える腐生菌です。木を直接分解することはできません。シイタケが原木のリグニンを分解し、サケツバタケが木材チップを分解するのとは違い、マッシュルームはほかの微生物がすでに分解しておいた堆肥を食べます。自然界では、堆肥の山の周辺、牧場の縁、落ち葉が厚く腐った場所に生えます。

> **この生態が、マッシュルーム栽培のすべてを説明します。この菌は培地を殺菌して与えるのではなく、微生物があらかじめ発酵させておいた培地を受け取って食べます。だからこそ、堆肥発酵が栽培の70%を占めるのです。**

### 2-2. 形

| 器官 | 特徴 |
|:---|:---|
| 傘 | 直径3-10cm。初めは半球形で、しだいに平らに開きます |
| 傘の色 | 白色、クリーム色、または褐色。品種によって異なります |
| 傘の表面 | 滑らかか、細かい繊維状の模様があります。粘液質はありません |
| **ひだ** | **初めは淡いピンク色 → 成長とともに褐色 → 黒褐色へと濃くなる** |
| ひだの付き方 | 柄から離れています（離生ひだ） |
| **胞子の色** | **褐色〜チョコレート褐色** |
| 柄 | 短くて太いです。長さ3-7cm、太さ1-2cm |
| **つば** | **あります。** 幼菌のとき傘を覆っていた白い膜が破れ、柄に輪状に残ります |
| **つぼ** | **ありません。** 柄の基部はそのまま堆肥に埋まっています |
| 肉 | 白色。切ると**淡いピンク色から褐色**へと徐々に変わります |
| 匂い | キノコの香り。不快な匂いはありません |

> **ひだが淡いピンクから褐色に変わり、胞子が褐色で、柄につばがあり、基部に袋がなく、切った肉がピンク色から褐色に変わる。この五つがマッシュルームの特徴です。**

&nbsp;&nbsp;&nbsp;ひだの色の変化は特に覚えておく必要があります。幼いボタン段階では、ひだが傘の中に隠れていて見えません。確認するには一つ割ってみる必要があります。淡いピンク色ならマッシュルームで、白色ならテングタケの可能性があります。この一つの動作が生死を分けます。

### 2-3. 生活環 - 胞子からキノコまで

| 段階 | 何が起こるか |
|:---|:---|
| 胞子 | 担子器一つに**二個だけ**付きます。たいていすでに二つの核を持っています |
| 発芽 | 発芽率が低いです。ほかのキノコより胞子から育てるのが難しいです |
| 菌糸 | 二核の胞子から育った菌糸は、そのまま子実体を結ぶことができます |
| 堆肥への蔓延 | 菌糸が発酵堆肥全体に白い糸のように広がります。2-3週間 |
| **覆土** | **土をかぶせます。これがないとキノコは生えません** |
| 原基形成 | 覆土層と堆肥層の境目に、アワ粒のような粒ができます。覆土後10-15日 |
| 子実体 | 白い粒が膨らんでボタンになり、さらに置くと傘が開きます |

&nbsp;&nbsp;&nbsp;胞子が二個しか付かないという性質が、マッシュルームを特異な存在にしています。大多数のキノコは胞子が遺伝子を半分だけ持つ単核細胞であるため、異なる交配型の胞子二つが出会って二次菌糸を作らなければキノコを結びません。マッシュルームの胞子はほとんどがすでに二つの核を持っているため、一粒だけでもキノコが生えます。楽そうに見えますが代償があります。遺伝的多様性が生まれないため世代を重ねると活力が落ち、胞子の発芽率自体も低いのです。

> **それでも胞子を撒くときは惜しみません。発芽率が低いという事実こそが、むしろたっぷり入れなければならない理由です。**

&nbsp;&nbsp;&nbsp;熱量15kcalは、この文書の中でもっとも低い値です。1日2,100kcalをマッシュルームだけで満たそうとすると14kgも食べなければならず、計算そのものに意味がありません。マッシュルームは熱量源ではありません。

&nbsp;&nbsp;&nbsp;その代わり、タンパク質の効率は圧倒的です。100gあたりタンパク質3.12gはキノコの中では高いほうで、熱量が非常に低いため、熱量に対する比率では83%にもなります。実質的に言えば、マッシュルーム一皿は満腹にはならなくてもタンパク質を補給してくれます。穀物やジャガイモで熱量を満たし、マッシュルームでタンパク質を補う組み合わせが正しい使い方です。

&nbsp;&nbsp;&nbsp;ビタミンDは災害時に特別な価値を持ちます。室内生活が長引き、脂の乗った魚が手に入らなくなると、ビタミンD不足が起こります。キノコのエルゴステロールは紫外線を受けるとビタミンD2に変わるため、**収穫したマッシュルームを傘を上に向けて数時間日に当てると、ビタミンD含量が大きく上がります。** 乾燥させる工程がそのまま栄養強化の工程になります。13節であらためて扱います。
