## 10. 生育異常の診断

| 症状 | 原因 | 対策 |
|:---|:---|:---|
| 接種1週間経っても菌糸が見えない | **堆肥にアンモニアが残っていた、**堆肥が熱いうちに接種した | 後発酵を追加するか、再び切り返して空気を入れます。アンモニア臭を必ず確認します |
| 菌糸が伸びて止まる | 堆肥温度30℃超過、水分不足 | 室温を20℃に下げ、堆肥表面を掻いて熱を抜きます |
| 菌糸は良いのにキノコが出ない | 覆土をしていない、通風不足、温度が高い | 覆土して通風口を開け二酸化炭素を抜いた後、16-18℃に下げます |
| 覆土表面に白い膜が厚く覆う | 菌糸が旺盛すぎる。湿度と二酸化炭素過多 | 熊手で軽く掻いて菌糸を切り、通風を増やします |
| 原基ができた後、乾いて枯れる | 湿度不足、覆土が乾く | 霧状に水をまいて85-95%に上げます |
| 原基ができた後、腐って枯れる | 水を与えすぎ、勢いよく与えた | 水を減らし通風します |
| 軸が長く傘が小さい | **二酸化炭素過多。** 通風不足 | 通風口を開けて空気を入れ替えます |
| 傘がすぐ開いて薄い | 温度が22℃以上 | より涼しい場所に移します |
| 傘の表面が粗く裂ける | 空気が乾燥しすぎている | 床と壁に水をまいて湿度を上げます |
| 傘に褐色のくぼんだ斑点 | 細菌性褐色斑点病。傘に水滴が残っていた | 水を減らし通風して傘を乾かします |
| キノコが潰れた白い塊になり奇形になる | **乾腐病。** 覆土の土から入ります | 病気の個体と周りの土を取り除き、次の周期では覆土を必ず蒸します |
| キノコの軸にウジ虫 | キノコバエ | 通風口と出入口を塞ぎます。被害個体は片付けます |
| 傘が黄色く変色 | 過熟、温度過多 | 適期に収穫します |
| 2周期目の収量がほとんどない | 堆肥の養分が尽きた | 正常です。堆肥を替えます |

## 11. 廃培地の循環利用

### 11-1. 廃堆肥は捨てるものではありません

&nbsp;&nbsp;&nbsp;キノコが出終わった後の堆肥は、すでに二度発酵し、菌糸がさらに一度分解した有機物です。この文書が扱う六種の中で、**廃培地が最も良い肥料になるのがマッシュルームです。**おがくずの廃培地は木質が残っているため畑に入れると窒素を奪いますが、マッシュルームの廃堆肥はすでに炭素窒素比が低く、そのまま入れられます。

| 用途 | 方法 |
|:---|:---|
| **元肥** | 畑に広げてすき込みます。窒素、リン、カリウム、カルシウムがバランスよく含まれています |
| **マルチ材** | 作物の間に5cmの厚さで敷き、雑草と水分蒸発を防ぎます |
| **覆土材料** | ふるいにかけて次の周期の覆土に混ぜます。必ず再び蒸してから使います |
| **他のキノコの培地** | サケツバタケの木材チップ培地に混ぜると窒素源になります |
| **育苗床の土** | 砂と混ぜれば育苗用の床土になります |
| **ミミズ養殖の基質** | ミミズが最も好む基質です。フン土が得られます |
| **酸性土壌の改良** | 石膏と石灰が含まれており、酸性土壌の酸度を上げます |

```
稲わら + 糞尿 + 貝殻 → 発酵堆肥 → キノコ収穫 → 廃堆肥 → 畑の肥料
                                                   └ ミミズ → フン土
```

> **マッシュルーム栽培は事実上、堆肥作りと同じ過程です。その途中でキノコを一度収穫するだけのことです。キノコが得られなくても堆肥は残ります。これは他のキノコにはない安全弁です。**

&nbsp;&nbsp;&nbsp;この視点が災害状況で重要です。他のキノコは失敗すればおがくずと薪を無駄に使ったことになります。マッシュルームは失敗しても畑に入れる堆肥が残ります。投入がまったく無駄にならないという点で、最もリスクの低いキノコ栽培です。

### 11-2. 廃堆肥を再利用するときの注意

| 状況 | 判断 |
|:---|:---|
| 正常に収穫を終えた堆肥 | そのまま畑に入れます |
| **青カビに汚染された堆肥** | **畑に入れません。**燃やすか、栽培地から遠く離れた場所に深く埋めます |
| **乾腐病が出た堆肥と覆土** | 同様です。胞子は土の中で何年も生き残ります |
| キノコバエが大発生した堆肥 | もう一度積んで発熱させ、卵を殺してから使います |

> **汚染された培地を堆肥に戻してはいけません。**青カビと乾腐病の胞子は堆肥の山の中で生き残り、翌年また培地に入り込みます。

### 11-3. 栽培空間の年次管理

| 年次 | 管理 |
|:--:|:---|
| 周期ごと | 菌床の木枠を空にして水で洗い、天日で乾かします |
| 1年 | 同じ栽培舎を使い続けてもかまいません |
| 2-3年 | 壁と床に石灰硫黄合剤か濃い草木灰の灰汁を塗ります |
| 問題が蓄積したら | 栽培舎を一季節空けておき、扉を開けて日光と風を入れます |

&nbsp;&nbsp;&nbsp;木枠は木製なので病原菌が染み込みます。周期が終わったら水で洗い、できれば熱湯をかけるか表面を火であぶります。竹や板を使うなら、数年ごとに替えるほうがよいです。

## 12. 毒キノコとの誤認と安全確認

> **この節は命に直結します。育てることより、食べてよいかどうかを確認することのほうが重要です。**

&nbsp;&nbsp;&nbsp;マッシュルームはこの文書が扱う六種の中で、**致命的な毒キノコとの誤認によって実際の死亡事故が最も多く報告されているキノコです。**韓国の内外で繰り返し起きています。理由は三つが重なっているからです。

| 重なる条件 | 内容 |
|:---|:---|
| **土から生えます** | マッシュルームは覆土を突き破って出てきますし、テングタケ類も地面から生えます |
| **白いボタン段階で採ります** | 収穫適期は傘がすぼまった白い卵形で、テングタケの幼菌も白い卵形です |
| **つばがあります** | マッシュルームもテングタケも軸に白い膜状の輪を持ちます |

> **マッシュルームとシロタマゴテングタケを分けるのはただ一つ、基部のつぼです。これを確認しなければ、いつか誤って食べることになります。**

### 12-1. マッシュルームの確認形質

&nbsp;&nbsp;&nbsp;栽培したキノコであっても、覆土に野生の胞子が混ざり込み、別のキノコが一緒に生えることがあります。**菌床に生えたという事実だけで安全だと考えてはいけません。**以下の形質を一つ一つ確認します。

| 部位 | マッシュルーム |
|:---|:---|
| 傘 | 直径3-10cm。半球形から平らな形に開きます。白色、クリーム色、褐色 |
| 傘の表面 | 滑らかか、細かい繊維模様。粘性がありません |
| **ひだ** | **最初は淡いピンク色 → 成長すると褐色 → 黒褐色に濃くなる** |
| **胞子の色** | **褐色からチョコレート褐色。**白い紙に傘を乗せて受ければすぐに確認できます |
| 軸 | 短く太いです。長さ3-7cm、太さ1-2cm |
| **軸のつば** | **あります。**幼菌のとき傘を覆っていた白い膜が破れて軸に残ります |
| **軸の基部** | **つぼ（大袋）がありません。**基部はそのまま堆肥に埋もれています |
| 肉 | 白色。切ると**淡いピンク色から褐色へ**と徐々に変わります |
| におい | キノコの香り。不快なにおいはありません |
| 発生基質 | 発酵堆肥と覆土の境目 |

> **ひだを確認するには一つを割ってみる必要があります。**ボタン段階ではひだが傘の中に隠れていて見えません。割った断面のひだが淡いピンク色ならマッシュルームで、最後まで純白ならテングタケを疑います。この一つの動作が生死を分けます。

### 12-2. シロタマゴテングタケとドクツルタケ - つぼが分かれ道です

&nbsp;&nbsp;&nbsp;シロタマゴテングタケ（Amanita verna）とドクツルタケ（Amanita virosa）はアマトキシンを持つ致命的な毒キノコです。一本で人が死にます。解毒薬がなく、医療支援のない状況ではほぼ確実に死亡します。

| 区分 | **マッシュルーム** | **シロタマゴテングタケ・ドクツルタケ（致命的）** |
|:---|:---|:---|
| **軸の基部** | **つぼがありません** | **膜状のつぼが基部を包みます** |
| **ひだの色** | **淡いピンク → 褐色 → 黒褐色** | **最初から最後まで純白** |
| **胞子の色** | **褐色からチョコレート褐色** | **白色** |
| 傘の色 | 白色、クリーム色、褐色 | 純白。ドクツルタケは中央がわずかに黄色みを帯びます |
| 軸 | 短く太い。3-7cm | **長く細い。9-20cm** |
| 軸の表面 | 滑らか | **ドクツルタケは白い繊維状の鱗片でざらつきます** |
| つば | あります | あります。**区別できません** |
| 肉の色の変化 | 切るとピンク色から褐色に | 変色せず白色のままです |
| におい | キノコの香り | 古い個体は不快なにおい |
| 発生基質 | 発酵堆肥と覆土 | **生きた樹木の根の近くの土** |
| 発生の習性 | 菌床に群がって | 森の中に一本ずつ、または数本散らばって |

> **基部を土ごと掘り出して確認する習慣をつけてください。**
> つぼの確認は必ず掘って行う必要があります。地上に出た部分だけを見ると、つぼが土に埋もれて見えません。マッシュルームは地上に出た部分だけを切って採りやすいキノコなので、この習慣が特に重要です。8節で基部まで丸ごと引き抜くように述べたのはこのためです。

> **白い紙に傘を伏せて乗せ、コップをかぶせて数時間置いたとき、落ちた粉が白ければ絶対に食べないでください。**
> マッシュルームの胞子は褐色からチョコレート褐色です。胞子が白色で、ひだが最後まで白色で、軸の基部につぼがある場合、その三つのうち一つでも当てはまれば食べません。

&nbsp;&nbsp;&nbsp;アマトキシン中毒の経過を知っておく必要があります。食べてから6-24時間は何の症状もありません。その後、激しい嘔吐と下痢と腹痛が始まり、一日ほど続きます。次に症状が治まり回復したように見える時期が二日から三日あり、まさにその期間に肝臓が破壊されています。続いて黄疸と出血と意識低下が現れると、すでに手の施しようがなくなっています。

> **症状が6時間以上経ってから現れる中毒が最も危険です。**食べて30分から2時間以内に腹が痛むのはたいてい胃腸の刺激ですが、6-24時間後に嘔吐と下痢が始まるのはアマトキシン中毒の典型的な経過です。始まりが遅いほど重症です。

### 12-3. 同じハラタケ属の毒キノコ - 傷が黄色く変わるもの

&nbsp;&nbsp;&nbsp;マッシュルームと同じハラタケ属（Agaricus）にも、食べてはいけない種があります。黄色く変色する仲間です。韓国国内では黄変ハラタケ類（Agaricus xanthodermus）と呼ばれます。

| 区分 | **マッシュルーム** | **黄変ハラタケ類（胃腸毒性）** |
|:---|:---|:---|
| **傷の変色** | 切ると**淡いピンク色から褐色** | **切ったりこすったりすると鮮やかな黄色に変わります。**特に基部 |
| **におい** | キノコの香り | **インクや石炭酸、薬品のような不快なにおい。**加熱するとさらに強くなります |
| 胞子の色 | 褐色からチョコレート褐色 | 褐色。区別できません |
| ひだの色 | 淡いピンク → 褐色 | 白色 → ピンク → 褐色。似ています |
| 発生基質 | 発酵堆肥と覆土 | 草地、庭、道端の土 |

> **基部をこすって黄色に変わり薬品臭がすれば食べません。**死には至りませんが、激しい嘔吐と下痢が起こります。医療支援のない状況では脱水そのものが危険です。

### 12-4. その他の混同しやすい対象

| キノコ | 区別点 |
|:---|:---|
| **ハラタケ（野生食用種）** | マッシュルームの野生近縁種で食用です。草地に生えます。ただしテングタケとの区別が必要なので同じ確認手順を踏みます |
| **シロトゲテングタケ** | 傘に白いとげ状の突起があり、つぼがあります |
| **ドクツルタケの幼菌（卵段階）** | **白い卵形で、マッシュルームのボタン段階に最もよく似ています。**割るとキノコの形がすでに中に入っており、外皮と中身の間にゼリー層があります |
| **ホコリタケ類** | 割ると中が均一な白い綿のようです。ひだがありません。幼菌は食用ですが、中にキノコの形が見えればテングタケです |
| **ヒトヨタケ類** | 傘が時間が経つと黒く溶けます。酒と一緒に食べると中毒します |

> **白い卵形のキノコを見つけたら必ず縦に割ってみます。**中が均一な白い綿のようならホコリタケ、中に折りたたまれたキノコの形が入っていればテングタケの幼菌です。テングタケの幼菌は外皮の下に半透明のゼリー層があり、触るとぬるっとします。

### 12-5. 初めて食べるときの原則

&nbsp;&nbsp;&nbsp;医療支援のない状況では、確認の手順そのものが防御手段になります。

| 順序 | 内容 |
|:--:|:---|
| 1 | **基部を土ごと掘り出し、つぼがないか確認します。**つぼがあれば捨てます |
| 2 | **一本を縦に割ってひだの色を見ます。**淡いピンクならマッシュルーム、最後まで純白なら捨てます |
| 3 | **切り口が黄色く変わるか見ます。**黄色く変わり薬品臭がすれば捨てます |
| 4 | **胞子を採って色を確認します。**白色なら捨てます |
| 5 | **必ず十分に加熱します。**生食できるキノコですが、野生の個体は加熱します |
| 6 | 最初は**一人だけ、少量（一切れ）**食べて24時間待ちます |
| 7 | 異常がなければ量を増やします。複数人で同時に食べません |
| 8 | 食べたキノコを一本**別に取っておきます。**中毒したときの確認に使えます |

> **災害状況でマッシュルームを食べる最も安全な方法は、野生で探すことではなく、栽培することです。自分で堆肥を作り種菌を入れた菌床から生えたものなら、判別の問題はほとんど起こりません。それでも基部を掘って確認する動作は習慣として残しておいてください。**
