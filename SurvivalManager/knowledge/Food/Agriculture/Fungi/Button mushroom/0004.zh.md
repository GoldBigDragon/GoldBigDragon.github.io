## 5. 接种方法

&nbsp;&nbsp;&nbsp;双孢蘑菇的接种比其他菌菇更简单，只需把菌种拌入堆肥即可，既不需要无菌室，也不需要敏捷的手法。因为经过后发酵的堆肥本身已是一种选择性培养基，天然地对双孢蘑菇菌丝有利。

> **这是双孢蘑菇栽培中最被低估的优势。金针菇和猴头菇必须在近乎无菌的条件下于10秒内完成接种，而双孢蘑菇即使徒手把菌种拌入堆肥也无妨。**

### 5-1. 接种条件

| 项目 | 标准 | 原因 |
|:---|:---|:---|
| 堆肥温度 | **降至25℃以下后** | 温度更高会导致菌种死亡 |
| 氨气 | **须完全没有气味** | 若残留会导致菌种死亡 |
| 堆肥水分 | 68-72% | 用力握时指缝间能微微渗出水 |
| 堆肥酸碱度 | pH 6.8-7.2 | 中性 |
| 接种量 | **每3.3㎡（1坪）堆肥125kg配菌种1.5kg** | 现场推荐用量为2.7-3.6kg |
| 无洁净室时 | **取推荐量上限的3.6kg** | 谁先占据地盘谁就赢 |

&nbsp;&nbsp;&nbsp;充分加大接种量，是弥补无菌操作不足最可靠的办法。每坪1.5kg是底线，3.6kg是现场推荐的上限。在既无电力又无洁净室的状况下，应选择上限一侧。若为了节省菌种成本而减量，绿霉就会抢先占据地盘，导致全部损失。

### 5-2. 接种步骤

| 步骤 | 方法 |
|:--:|:---|
| 1 | 把手伸入堆肥确认是否已降到25℃以下 |
| 2 | 把鼻子靠近确认是否已无氨气味 |
| 3 | 用手把菌种块掰成米粒大小 |
| 4 | 均匀撒在堆肥表面 |
| 5 | 用手或耙子**均匀拌入堆肥表层10-15cm的深度** |
| 6 | 把表面整平并轻轻压实 |
| 7 | **用纸张、湿布或草帘覆盖**以保持水分 |

&nbsp;&nbsp;&nbsp;要领在于不把菌种拌入整堆堆肥，只拌入上层。菌丝会由上向下延伸，蘑菇也从上层长出。若把菌种撒到下层，等于浪费菌种。

&nbsp;&nbsp;&nbsp;覆盖材料须既能保持水分又能透气。若用塑料布完全密封，会凝结水珠滴落并滋生细菌。纸张、湿草帘、草席，或薄薄铺一层稻草都比较合适。

## 6. 菌丝培养管理

&nbsp;&nbsp;&nbsp;接种后2-3周为培养期，目标是让白色菌丝占满整堆堆肥。这段时间人要做的，只是控制温度和防止干燥。

### 6-1. 温度——代谢热是最大的风险

| 时期 | 室内温度 | 管理 |
|:---|:---:|:---|
| 接种后1-5天 | 25-27℃ | 促进菌丝定植，略偏温暖 |
| 第6-7天之后 | **降到20℃** | 菌丝代谢产热会使堆肥内部更热 |
| 危险期 | **比适温低5-10℃** | 防止菌丝因发热而被烧死 |
| 堆肥温度上限 | **30℃** | 超过此温度菌丝会变弱，34度时会死亡 |
| 时长 | 2-3周 | 因堆肥量和温度而异 |

> **双孢蘑菇培养期最常见的失败就是过热。**菌丝旺盛生长时会自行产热，即使室温为25℃，堆肥内部也可能超过30℃。要养成把手深深插入堆肥确认温热程度的习惯。

&nbsp;&nbsp;&nbsp;应对办法有三个：培养一周后把室内温度降到20℃；堆肥厚度不超过30cm；再逐步加大通风。若感觉堆肥内部发热，就用耙子轻轻搔一下表面让空气进入。

### 6-2. 湿度与通风

| 项目 | 标准 |
|:---|:---|
| 堆肥水分 | 维持68-72% |
| 空气湿度 | 85-90% |
| 浇水 | 培养期间**尽量不浇水，**覆盖物变干时只对覆盖物喷水 |
| 通风 | 每天一两次、时间短。菌丝更适合略有二氧化碳积累的环境 |
| 光照 | 不需要，黑暗中也可以 |

&nbsp;&nbsp;&nbsp;培养期间不能直接给堆肥浇水，菌丝一旦被水淹没就会因缺氧而死。若需要补水，只能洒在覆盖的纸张或草帘上，以水汽的形式传递。堆肥的水分应在后发酵结束时就调好，培养期只是维持而已。

&nbsp;&nbsp;&nbsp;菌丝培养阶段不宜多通风。双孢蘑菇菌丝在一定程度上喜欢二氧化碳，这与子实体阶段正好相反。培养期间应保持密闭，覆土之后再逐渐加大通风。

### 6-3. 判断培养是否正常的方法

| 观察项 | 正常 | 异常 |
|:---|:---|:---|
| 颜色 | 白色菌丝包裹稻草并蔓延 | 青绿色、黑色、橙色为污染 |
| 质感 | 细白丝均匀分布在稻草表面 | 若呈粉末状飞散则是污染孢子 |
| 气味 | 淡淡的蘑菇香、菌土气息 | **若再次出现氨气味，说明后发酵不彻底** |
| 进展 | 每周向下蔓延5-7cm | 若停滞则是温度或氨气问题 |
| 堆肥硬度 | 用手提起时会随菌丝成团带起 | 若散落成单个颗粒说明尚未蔓延开 |
| 温度 | 堆肥内部25-30℃ | 超过30℃须立即降温 |

&nbsp;&nbsp;&nbsp;培养过程中有时会再次出现氨气味，这多是因为后发酵时氨气未完全排出，或堆肥内部残留了结块的氮源。此时应轻轻翻动堆肥透气并加大通风，情况严重时该区域最好直接放弃。

### 6-4. 覆土

&nbsp;&nbsp;&nbsp;菌丝蔓延满整堆堆肥后即可覆土。双孢蘑菇栽培若没有这一步，就不会出菇。

| 项目 | 标准 |
|:---|:---|
| 时机 | 菌丝已蔓延至堆肥底部之后。接种后2-3周 |
| 判定 | 堆肥表里均匀呈白色，提起堆肥时会成团带起 |
| 材料 | 腐叶土与沙子混合石灰，调至pH 7.5以上 |
| 厚度 | 2-3cm |
| 松紧 | 须疏松。若只用细土会板结，蘑菇无法顶破 |
| 浇水 | 覆土后立即浇透，分多次缓慢进行 |
| 后续管理 | 温度18-22℃，湿度95% |

&nbsp;&nbsp;&nbsp;覆土之后菌丝会向上长入土层。5-7天后覆土表面就会开始透出白色菌丝。这时用耙子轻轻搔动土层切断菌丝（即搔菌/耙土），能使出菇更均匀。若表面被厚厚的白色菌丝膜覆盖，反而不容易出菇，所以要在结膜之前就完成搔动。

## 7. 出菇诱导

&nbsp;&nbsp;&nbsp;菌丝在舒适的条件下只会不断伸展。结出蘑菇，对菌丝而言其实是一种危机信号。对双孢蘑菇来说，这个信号有三个：覆土、降温，以及排出二氧化碳。

### 7-1. 出菇条件

| 项目 | 培养阶段 | **出菇阶段** | 备注 |
|:---|:---:|:---:|:---|
| 温度 | 23-25℃ | **16-18℃** | 范围较窄，12℃以下不会形成原基 |
| 空气湿度 | 85-90% | **85-95%** | 出菇初期须尤其偏高 |
| **二氧化碳** | 偏高也无妨 | **须降低** | **通风是关键** |
| 光照 | 不需要 | 不需要 | 完全黑暗中也能出菇 |
| 覆土 | - | 2-3cm | 没有覆土就不会出菇 |

> **诱导双孢蘑菇出菇的关键是通风。**覆土完成、温度降到16-18℃后，打开此前一直关闭的通风口排出二氧化碳，蘑菇便会形成。菌丝喜欢二氧化碳而子实体厌恶二氧化碳，这一转换本身就是信号。

&nbsp;&nbsp;&nbsp;若是中高温型品种，适温范围可扩大到13-20℃。在没有电力、无法精确控温的状况下，选择这类品种更为有利。

### 7-2. 不用电力也能造出16-18℃的方法

| 手段 | 温度 | 获取方法 | 局限 |
|:---|:---:|:---|:---|
| **地窖、山洞** | 12-18℃ | 向山坡内挖掘2m以上 | 四季可用，最为理想 |
| **春季作型** | 自然 | 3月下旬至5月 | 到6月就会变热 |
| **秋季作型** | 自然 | 9月至11月 | 到12月就会变冷 |
| 地下室 | 12-18℃ | 利用现有建筑结构 | 须解决湿度问题 |
| 半地下窝棚 | 14-20℃ | 挖深1m并用土和稻草覆盖 | 夏季温度不够低 |
| 朝北的土墙棚屋 | 随季节变动 | 厚土墙可减缓温度变化 | 盛夏与严冬会超出范围 |

> **在没有电力的状况下，双孢蘑菇要么是春秋两季的作物，要么是地窖作物，盛夏与严冬都不栽培。**

&nbsp;&nbsp;&nbsp;标准做法是春秋两季各种一轮。春季作型在2月制作堆肥，3月接种，4月底开始采收；秋季作型在8月制作堆肥，9月接种，10月底开始采收。堆肥发酵本身在炎热季节反而更顺利，因此形成了发酵安排在夏季或深冬、出菇安排在凉爽季节的格局。

### 7-3. 水分管理

| 时期 | 管理 |
|:---|:---|
| 覆土之后 | 浇透，分多次缓慢渗入 |
| 原基形成期 | **减少浇水或停止浇水，**此时水浇多了原基会变软腐烂 |
| 蘑菇长到豆粒大小后 | 再少量恢复浇水，以覆土不干为度 |
| 生长期 | 在两次采收之间少量浇水 |
| 采收前2-3天 | **不浇水，**可提高耐储性 |

&nbsp;&nbsp;&nbsp;浇水的方式很重要。若用力浇灌，覆土会被压实板结，幼菇也会被压烂。应用喷壶喷成雾状，或用宽叶树枝蘸水甩洒。而且每次不宜浇太多，须分多次少量进行。

### 7-4. 确认原基形成

| 时期 | 可见现象 |
|:---|:---|
| 覆土后5-7天 | 覆土表面透出白色菌丝 |
| 覆土后10-15天 | **覆土下方形成粟粒到红豆大小的白色小粒** |
| 此后5-7天 | 小粒膨大，由豆粒长到栗子大小 |
| 采收 | 菌盖收拢的纽扣阶段 |

## 8. 采收与再出菇周期

### 8-1. 判断采收时机

| 标准 | 内容 |
|:---|:---|
| **最佳** | **菌盖呈圆形收拢、菌膜尚未破裂的纽扣阶段** |
| 大小 | 菌盖直径2-4cm |
| 偏晚的信号 | 菌盖与菌柄之间的白色菌膜裂开，可见菌褶 |
| 若偏晚 | 菌盖展开，菌褶变成褐色，口感下降 |
| 时间段 | 清晨 |

&nbsp;&nbsp;&nbsp;采晚了的蘑菇没有理由丢弃。菌盖展开的个体被称为波特菇，肉厚且带有肉类般的口感，适合烤制，鲜味也更浓。不过其耐储性会下降，还会开始散落孢子，最好当天食用。而且菌盖完全展开、菌褶变成深褐色的个体，最适合用于第4节所述的孢子采集。

> **采收适期的白色纽扣阶段，外观与致命鹅膏的幼体最为相似。务必阅读第12节，只采自己菌床上长出的蘑菇。**

### 8-2. 采摘要领

&nbsp;&nbsp;&nbsp;用手指包住菌盖，轻轻旋转着拔出。若直接用力拉扯，会带起覆土并扯断旁边幼菇的根部。旋转拔出的动作能把对周围的损伤降到最低。

&nbsp;&nbsp;&nbsp;拔出后的坑位不能就此不管，须用手清除残留的菌柄基部和土块，再用新覆土填平，因为残留的基部腐烂后会招来细菌和菇蝇。

&nbsp;&nbsp;&nbsp;而且采摘时**须连基部整株拔出。**如第12节所述，菌托的有无只能在基部确认，而这一确认关系生死。只切下地面以上部分的习惯是危险的。

&nbsp;&nbsp;&nbsp;采下的蘑菇**不要清洗。**双孢蘑菇非常怕水，一旦洗过会吸水，一天之内就会变成褐色。可用干布或软毛刷把泥土掸掉。

### 8-3. 出菇周期

| 项目 | 内容 |
|:---|:---|
| 首次采收 | 堆肥入棚后40-60天，覆土后10-15天 |
| 单潮持续时间 | 3-5天，会成批集中出菇 |
| 出菇间隔 | 7-14天 |
| 第二潮产量 | 第一潮的50-70% |
| 第三潮产量 | 第一潮的20-30% |
| 总采收次数 | **最多3次** |
| 菌床寿命 | 2-3潮，约2-3个月 |

&nbsp;&nbsp;&nbsp;双孢蘑菇像波浪一样出菇：三四天内成批涌现，之后休息1-2周再次出菇。休息期间要做的，是防止覆土变干并填平采过的坑位。因为是成批大量涌现，可以一次性集中晒干，有利于贮藏。

&nbsp;&nbsp;&nbsp;评价表中的持续性C正说明了这一点。收获两三潮之后，堆肥的养分会耗尽，菌丝也会老化，这时须撤出旧堆肥换上新堆肥。堆肥发酵需要2-3周，**因此诀窍是提前把下一周期的堆肥发酵好。**只要在菌床上采收的同时，在外面翻堆准备下一批堆肥，就能不间断地持续生产。

### 8-4. 产量

| 条件 | 产量 |
|:---|:---|
| 每㎡堆肥用量 | 50-60kg |
| 每㎡总产量 | 10-20kg（3潮合计） |
| 生物学效率 | 堆肥干物重的20-35% |
| 折算热量 | 每㎡1,500-3,000kcal（3潮合计） |

&nbsp;&nbsp;&nbsp;每㎡经3潮可产出10-20kg。每100g为15kcal，折算热量为1,500kcal到3,000kcal，相当于一人一天多一点的量，不是能靠热量来做长期规划的数值。

&nbsp;&nbsp;&nbsp;若从蛋白质角度看则不同。15kg相当于蛋白质470g，一人每天所需蛋白质为50g到60g，这已接近十天的量。而且若把菌床搭成两层或三层，同样的地面面积就能产出两倍、三倍的量。

> **评估双孢蘑菇的产量时，应按菌床面积而非地面面积计算。**若把架子搭成三层，1㎡地面就能获得3㎡菌床。在地窖或地下室这类空间狭小的场所，这种结构能带来很大的差别。

## 9. 污染与病虫害

### 9-1. 绿霉与竞争杂菌

&nbsp;&nbsp;&nbsp;灾害状况下菌菇栽培失败最常见的原因，不是病虫害，而是培养基被竞争杂菌抢占。双孢蘑菇因堆肥发酵形成了选择性培养基，比其他菌种更有优势，但若发酵不彻底，这道防线就会崩溃。

| 区分 | 双孢蘑菇菌丝 | 绿霉 |
|:---|:---|:---|
| 颜色 | 白色，呈包裹堆肥稻草的丝状 | 起初为白色，很快转为**青绿色** |
| 质感 | 细白丝均匀蔓延 | 呈粉末状，细碎松散 |
| 蔓延速度 | 每天3-5mm | 每天10-30mm，**快3-6倍** |
| 气味 | 泥土气息、蘑菇香 | 霉臭味，有时带椰子般的气味 |
| 边界 | 沿堆肥均匀分布 | 从圆形斑点向外呈放射状扩散 |

> **绿霉在颜色显现之前其实已经蔓延开了。**
> 出现青绿色，说明已到孢子形成阶段，也就是已经开始繁殖。到那时应视为培养基相当一部分已经损失。早期判别应依据蔓延速度和质感，而不是颜色。

### 9-2. 双孢蘑菇尤其常见的病害

| 病害 | 症状 | 原因 | 应对 |
|:---|:---|:---|:---|
| **干腐病（Mycogone）** | 蘑菇变成挤压变形的白色团块，渗出褐色液体 | **覆土未经灭菌** | 清除病菇及周围覆土，撒上食盐或草木灰 |
| **绿霉病** | 堆肥与覆土变为青绿色 | 后发酵不彻底、卫生条件不佳 | 清除受污染的区块 |
| **褐斑病（细菌性斑点）** | 菌盖出现褐色凹陷斑点 | 菌盖上长时间残留水珠 | 减少浇水并加强通风 |
| **细菌性软腐病** | 子实体变软并发出恶臭 | 过湿、排水不良 | 停止浇水并清除病菇 |
| **蛛网病** | 白色蛛网状霉菌包裹蘑菇 | 湿度过高、通风不足 | 加强通风并撒盐 |

&nbsp;&nbsp;&nbsp;干腐病是双孢蘑菇特有的病害，由覆土带入，若跳过第3节所述的覆土灭菌，几乎必然会出现。它也会经人的手和工具传播，因此接触过病株的手不要再碰健康区域，清除出来的病土也要运到远处丢弃。

### 9-3. 防止污染的六个要点

| 方法 | 原理 |
|:---|:---|
| **认真完成一次和二次发酵** | 60℃巴氏消毒可杀死病原菌，后发酵能消除杂菌的养分来源 |
| **覆土必须蒸过再用** | 干腐病和菇蝇都是通过土壤带入的 |
| **将覆土酸碱度提高到7.5以上** | 绿霉偏好弱酸性环境 |
| **充分加大菌种用量** | 谁先占据地盘谁就赢 |
| **浇水不要用力、不要过多** | 菌盖上残留水珠会引发细菌病害 |
| **随时填平已采收的坑位** | 腐烂的残留基部会招来细菌和菇蝇 |

### 9-4. 虫害——菇蝇是头号大敌

| 虫害 | 危害 | 应对 |
|:---|:---|:---|
| **菇蝇（眼蕈蚊、粪蚊）** | 啃食菌丝，并在子实体内产生蛆虫，还会传播绿霉孢子和干腐病 | **在出入口和通风口罩上细密的纱布或防虫网进行物理阻隔。**发生时可用水盆诱捕、粘虫板、灯光诱捕 |
| **螨虫** | 菌丝变褐并停止生长，接触会使人皮肤发痒 | 覆土须蒸过再用，发生区块须隔离 |
| **线虫** | 菌丝溶解消失，堆肥变黑发潮 | 须确保巴氏消毒达到60℃，一旦发生须废弃堆肥 |
| **蛞蝓** | 啃食幼菇 | 用草木灰或木屑撒成一圈进行阻隔 |
| **老鼠** | 叼走蘑菇并翻乱菌床 | 给菌床罩上网 |

> **防治菇蝇靠的是结构，而不是药剂。**在没有药剂的状况下，唯一确实有效的方法就是堵住它们进入的缝隙。在通风口罩两层细纱布，在出入口挂一道湿布当门帘，大多数情况下都能挡住。5月起数量会急剧增加，春季作型尤须留意。

&nbsp;&nbsp;&nbsp;卫生管理占防治工作的一半。若把采收完的废堆肥堆放在栽培棚旁边，就会成为菇蝇的繁殖场。废堆肥应立即运到远处，翻入田中或加以覆盖。
