## 1. 灾害应对评价

&nbsp;&nbsp;&nbsp;双孢蘑菇是被排除的作物。耐储性E与持续性C同时出现，被判定为无法构成储备。未适用排除关卡时的假设得分为40.8分，在183个有效物种中排第103位。耐储性得分低是以生鲜状态为基准评定的，可以通过干燥来改善；而持续性方面则仍是必须重新制作堆肥这一劳动问题。

### 1-3. 光照SS的含义

&nbsp;&nbsp;&nbsp;评价表中的光照项目本来是询问在40%遮光条件下还能保留多少产量。双孢蘑菇获得的SS，并不是说它在这场竞争中获胜，而是说它本来就不在这条轴线上。菌类没有叶绿素。双孢蘑菇利用的碳，是早已固定在稻草中的纤维素，天空的明暗对这份存量毫无影响。双孢蘑菇甚至根本不需要光。它是在完全黑暗的条件下也能正常结出子实体、与光照最无关的栽培蘑菇。

&nbsp;&nbsp;&nbsp;在大规模火山喷发或核冬天那样日照量连续数年下降的状况下，这种差异会决定性地显现出来。平流层一旦覆盖气溶胶，谷物、薯类（块茎/块根）、蔬菜就会同时受挫。但即使在那种情况下，秸秆、落叶和牲畜粪便依然存在，而把它们转化为人可食用蛋白质的唯一途径就是菌类。

&nbsp;&nbsp;&nbsp;而且双孢蘑菇还多了一层优势。日照减少，气温也会随之下降。双孢蘑菇子实体形成的温度是16-18℃，菌丝培养温度是23-25℃。与其在盛夏的室内制造出16℃，不如在变冷的世界里更容易达到。温度适应幅度D与耐寒性E虽然是又窄又弱的数值，但这个狭窄区间本身所指向的温度带恰恰偏向凉爽一侧。

> **菌类是阳光消失的世界里唯一产量不会下降的粮食来源，而双孢蘑菇是其中唯一不用一根柴火就能做到这一点的品种。**

### 1-4. 如何解读优势

&nbsp;&nbsp;&nbsp;获得SS的项目有蛋白质密度、光照、整地·挖掘能耗、产量稳定性四项。获得S的项目有收获速度、连作适应性、口味、韩国国内栽培普及度、菌菇副产物适应性五项。

&nbsp;&nbsp;&nbsp;蛋白质密度SS格外特别。热量15kcal中含蛋白质3.12g，蛋白质占热量的比例达到83.2%，是需求线10%的八倍，也是本文档所涉六个品种中最高的数值。双孢蘑菇实际上几乎完全由蛋白质和水构成。作为热量来源几乎没有意义，但作为蛋白质补充来源却极为高效。

&nbsp;&nbsp;&nbsp;菌菇副产物适应性S是最实质性的优势，能满足五个类别：纤维质（稻草、麦秸、大麦秸、玉米秆、干草、稻壳）、屠宰副产物与畜禽粪便（马粪、牛粪、鸡粪、猪粪）、炭与灰（草木灰）、骨与贝壳（贝壳、以蛋壳代替石膏）、加工纸浆（废纸、旧纸）。这与其他菌菇被单一阔叶树木屑牢牢束缚形成对比。这种适应性在灾害状况下具有直接意义。即便找不到木屑，没有橡树林，锯木厂也关门，只要稻田里有秸秆、牛棚里有粪便，双孢蘑菇的种植就能成立。

&nbsp;&nbsp;&nbsp;收获速度S也很突出。把堆肥放入菌床后40-60天就能首次采收，即使加上前面2-3周的堆肥发酵，全程也在两个半月以内。与香菇需要12-18个月相比差距很大，可以在灾害发生的当年开始，当年就能吃到。

&nbsp;&nbsp;&nbsp;此外，评价表的数字无法体现出一个最大的优势：堆肥发酵本身就是灭菌。第3节会详细说明，但仅凭这一点，双孢蘑菇就与其他五个品种有本质区别。设施负担D这一等级意味着需要菇房、木框和发酵场，而这三样都可以用木头、泥土和秸秆制作，没有一样需要电力。

### 1-5. 如何解读弱点

&nbsp;&nbsp;&nbsp;E有三项：耐寒性、耐储性、非食用价值。D有四项：施肥需求、设施负担、温度适应幅度、种子寿命。C有四项：单位面积热量、持续性、防治自立度、自家留种。

&nbsp;&nbsp;&nbsp;温度适应幅度D与耐寒性E要一起解读。子实体形成温度为16-18℃，幅度很窄，一旦超出这个区间出菇就会停止。低于12℃原基结不出来，超过22℃菌盖会立刻张开，品质随之崩溃。在没有电力的情况下，应对办法是季节和地形。春秋两季最接近16-18℃，而土窖和地下室常年维持在12-18℃。在没有电力的条件下种植双孢蘑菇，实际上就意味着按春秋两季作型种植，或者在土窖里种植。

&nbsp;&nbsp;&nbsp;施肥需求D的性质需要准确理解。化学肥料一分不用，取而代之的是必须大量收集稻草和粪便。每㎡需要堆肥50-60kg，而制作这些堆肥需要约两倍量的生稻草。如果附近没有稻田，就很难满足这个条件。双孢蘑菇不是被土地束缚的作物，而是被稻田和牛棚束缚的作物。

&nbsp;&nbsp;&nbsp;持续性C意味着收获两三个周期后就必须重新制作堆肥。与香菇原木可用4-5年，或大球盖菇固定菌床可用数年相比，这个周期短得多。不过废堆肥本身就是很好的田间肥料，并不会被浪费，第11节会加以说明。

&nbsp;&nbsp;&nbsp;自家留种C与种子寿命D是实质性的障碍。双孢蘑菇的菌种要靠无菌培养制作，市售菌种在6个月到1年内就会失去活力。而且双孢蘑菇比其他菌菇更难从孢子培育出菌株。这个物种每个担子只结两个孢子，而这些孢子往往已经带有两个细胞核，因此单个孢子长出的菌丝可以直接结出子实体，代价是几乎没有遗传多样性，发芽率也低。应对方法是第4节介绍的组织培养和菌床移植。

&nbsp;&nbsp;&nbsp;非食用价值E意味着在8个项目中都不适用。双孢蘑菇除了食用之外，尚未确认其他用途。

&nbsp;&nbsp;&nbsp;此外还有一个评价表上没有写出、却最为沉重的弱点：误认的风险。双孢蘑菇从土中长出，具备菌盖、菌柄、菌褶和菌环，是典型的蘑菇外形，最佳采收期正是菌盖合拢的白色纽扣状阶段。这三个条件恰好与能致人死亡的白鹅膏和白毒伞幼菇完全重叠。第12节必须仔细阅读。

## 2. 这是一种什么样的菌类

### 2-1. 名称与分类

&nbsp;&nbsp;&nbsp;双孢蘑菇属于担子菌门伞菌纲伞菌目蘑菇科蘑菇属。学名Agaricus bisporus中的种加词bisporus意为"孢子为二"。大多数担子菌在一个担子上结四个孢子，而这个物种只结两个。这一微小差异正是第4节将会谈到的菌种获取困难的根源。

&nbsp;&nbsp;&nbsp;韩语名称"yangsongi"意为"来自西方的松茸"，与松茸（Tricholoma matsutake）并无关系。英语地区称为纽扣蘑菇（button mushroom）、白蘑菇（white mushroom），菌盖张开变大后称为波特贝罗菇（portobello）。三者其实是同一物种，只是采收时期和品种不同。

&nbsp;&nbsp;&nbsp;从生态上看，这是一种生长在分解已相当充分的有机物堆上的腐生菌，不能直接分解木材。与香菇啃食原木中的木质素、大球盖菇分解木片不同，双孢蘑菇吃的是其他微生物已经预先分解好的堆肥。在自然界中，它生长在粪堆周围、牧场边缘、落叶层层腐烂的地方。

> **这种生态习性就是双孢蘑菇栽培的全部道理所在。这种菌不是靠灭菌后直接提供培养基，而是靠接收微生物先行"煮熟"好的培养基来进食。因此，堆肥发酵占了栽培工作的70%。**

### 2-2. 外形特征

| 部位 | 特征 |
|:---|:---|
| 菌盖 | 直径3-10cm。起初为半球形，随后逐渐展平 |
| 菌盖颜色 | 白色、奶油色或褐色，因品种而异 |
| 菌盖表面 | 光滑或带细微纤维状纹理，没有黏液 |
| **菌褶** | **起初为淡粉色 → 随生长变为褐色 → 逐渐加深为黑褐色** |
| 菌褶着生方式 | 与菌柄分离（离生菌褶） |
| **孢子颜色** | **褐色至巧克力褐色** |
| 菌柄 | 粗短。长3-7cm，粗1-2cm |
| **菌环** | **有。** 幼菇时期覆盖菌盖的白色薄膜破裂后，在菌柄上留下环状痕迹 |
| **菌托** | **没有。** 菌柄基部只是直接埋在堆肥里 |
| 菌肉 | 白色。切开后会缓慢地由**淡粉色变为褐色** |
| 气味 | 蘑菇香，没有令人不适的气味 |
| 出菇基质 | 发酵堆肥与覆土层的交界处 |

> **菌褶由淡粉色变为褐色，孢子呈褐色，菌柄上有菌环，基部没有菌托，切开的菌肉由粉色变为褐色。这五点就是双孢蘑菇的特征。**

&nbsp;&nbsp;&nbsp;菌褶颜色的变化尤其需要牢记。在幼小的纽扣状阶段，菌褶藏在菌盖内看不见，要确认就必须掰开一个来看。呈淡粉色就是双孢蘑菇，呈白色则可能是鹅膏。这一个动作足以决定生死。

### 2-3. 生活史——从孢子到蘑菇

| 阶段 | 发生了什么 |
|:---|:---|
| 孢子 | 一个担子上只结**两个**。通常已经带有两个细胞核 |
| 发芽 | 发芽率低，比其他菌菇更难从孢子培育 |
| 菌丝 | 由双核孢子长出的菌丝可以直接结出子实体 |
| 占据堆肥 | 菌丝像白色细丝一样蔓延到整个发酵堆肥中。2-3周 |
| **覆土** | **在上面覆盖泥土，没有这一步蘑菇就不会长出来** |
| 原基形成 | 在覆土层与堆肥层的交界处结出粟粒大小的颗粒。覆土后10-15天 |
| 子实体 | 白色颗粒膨大成纽扣状，继续放置菌盖就会展开 |

&nbsp;&nbsp;&nbsp;只结两个孢子这一特性使双孢蘑菇显得特殊。大多数蘑菇的孢子只携带一半基因的单核细胞，必须两个不同交配型的孢子相遇形成次生菌丝才能结出蘑菇。而双孢蘑菇的孢子大多已经带有两个细胞核，因此一粒孢子就能长出蘑菇。看似方便，却是有代价的：由于不产生遗传多样性，世代越多活力越差，孢子发芽率本身也偏低。

> **尽管如此，撒孢子时也不必吝惜。发芽率低这一事实，恰恰正是要多撒一些的理由。**

&nbsp;&nbsp;&nbsp;但蛋白质效率极其出色。每100g含蛋白质3.12g，在菌菇里属于较高水平，加上热量本身极低，换算成占热量比例高达83%。实际来说，一盘双孢蘑菇虽不能填饱肚子，却能补充蛋白质。用谷物或马铃薯填补热量、用双孢蘑菇补充蛋白质，才是正确的搭配方式。

&nbsp;&nbsp;&nbsp;维生素D在灾害状况下尤为珍贵。室内生活拉长、又断了高脂鱼类的来源时，就会出现维生素D不足。蘑菇中的麦角固醇经紫外线照射会转变为维生素D2，因此**把采收下来的双孢蘑菇菌盖朝上晒几个小时，维生素D含量就会大幅提高。**晾晒的过程本身就是营养强化的过程，第13节会再次说明。
