## 3. 培地材料と準備

&nbsp;&nbsp;&nbsp;マッシュルームの培地は、ほかの五種とはまったく性格が異なります。おがくずを瓶に詰めて煮る培地ではなく、稲わらとふんを積んで自ら発熱させて作る**発酵堆肥**です。

> **ほかのキノコは薪を燃やして培地を殺菌しますが、マッシュルームは微生物が出す熱で培地を殺菌します。人は火を焚かず、切り返すだけです。電力も燃料もいらない唯一の殺菌法です。**

&nbsp;&nbsp;&nbsp;堆肥発酵は三つの働きをします。第一に、堆の内部の温度が60-70℃に達し、病原菌と害虫の卵と雑草の種を殺します。第二に、雑菌が食べやすい糖分を好熱性微生物が先に食べてなくすため、残るのはマッシュルームの菌糸だけが分解できる難分解性の有機物、つまり選択的培地になります。第三に、わらが柔らかくなり、窒素が微生物タンパク質として固定されて、マッシュルームが食べられる形に変わります。

### 3-1. 堆肥材料

| 区分 | 通常の配合 | 災害時の代替 |
|:---|:---|:---|
| **炭素源** | 稲わら、麦わら、大麦わら80% | 野草、枯れ草、トウモロコシの茎、アシ、もみ殻、古紙 |
| **窒素源** | 鶏糞、尿素、硫安、米ぬか | **馬糞**、牛糞、豚糞、ためた尿、大豆の莢殻、油かす |
| **無機質** | 石膏（硫酸カルシウム）、ゼオライト | **貝殻を焼いて砕いたもの**、卵の殻の粉、草木灰、消石灰 |

&nbsp;&nbsp;&nbsp;伝統的なマッシュルーム堆肥の窒素源は馬糞でした。馬糞には消化されなかったわらが混じっていて、炭素と窒素の比がちょうどよく合います。家畜がいるなら、馬糞や牛糞は鶏糞より扱いやすく、人の尿も数日ためてわらにかければ窒素源になります。

&nbsp;&nbsp;&nbsp;石膏（硫酸カルシウム）は栄養源として使うものではありません。カルシウムがわらの繊維がくっつき合うのを防いで堆肥が塊になるのを防ぎ、酸度を緩衝し、硫黄を供給します。貝殻やカキ殻、卵の殻を火で焼いて砕くと同じ役割を果たします。ただし硫黄は別途供給されないため、草木灰を少し混ぜます。

| 基準 | 値 | 備考 |
|:---|:---:|:---|
| 炭素窒素比（C/N） | 開始時**28-32対1**、完了時16-18対1 | わらだけ使うと70対1以上になるため、窒素を必ず補います |
| 稲わら100kgあたり鶏糞 | 10-15kg | 馬糞なら30-50kg |
| 稲わら100kgあたり米ぬか | 5kg | |
| 稲わら100kgあたり尿素 | 400-500g | 尿で代替する場合10-15L |
| 稲わら100kgあたり石膏（硫酸カルシウム） | 3-5kg | 貝殻粉で代替可能 |

### 3-2. 一次発酵 - 屋外の堆、2-3週間

| 段階 | 方法 | 期間 | 温度 |
|:---|:---|:---:|:---:|
| **仮堆積** | 稲わらに水をたっぷり与えます。**全体の水量の70%以上**をこの段階で入れ、わらを柔らかくします | 1-2日 | - |
| **本堆積** | 鶏糞、米ぬか、尿素、石膏をわらと交互に層にして積みます。断面が**亀の甲羅のような形**になるようにします | 1日 | 初期発熱 |
| **切り返し** | 2-3日間隔で**5-8回**切り返します。外側と内側を入れ替えます | 2-3週間 | 堆の内部55-70度 |

| 項目 | 基準 | 理由 |
|:---|:---|:---|
| 堆のサイズ | 高さ1.5-1.8m、幅1.5-2m、長さは制限なし | 低いと熱が集まらず、高すぎると内部が酸素不足で腐ります |
| 断面の形 | 上がやや丸い亀の甲羅型 | 雨が内部に染み込まず、表面を伝って流れます |
| 目標温度 | 堆の内部55-70度 | 手を入れられないほど熱くなる必要があります |
| 水分 | 握ると指の間から水が数滴落ちる程度 | 乾きすぎると発熱しません |

&nbsp;&nbsp;&nbsp;発酵は酸素を使う好気性の過程です。堆の内部の酸素を使い切ると発熱が止まり、嫌気性の腐敗に移ってしまいます。切り返しは酸素を新しく取り込みながら、外側で熱を受けられなかった部分を内側に移して均一に発酵させる作業です。ただ混ぜるのではなく、**外側のわらをすくって新しい堆の中心に入れる**方式で行います。

| 発酵の進行のしるし | 正常 | 異常 |
|:---|:---|:---|
| 温度 | 積んでから2-3日で55℃以上、その後維持 | 上がらなければ窒素か水分の不足 |
| 匂い | アンモニア臭が強く出ます | どぶ・硫化水素のような匂いは嫌気性の腐敗 |
| 色とわらの状態 | 黄褐色から濃い褐色。もむと簡単に切れます | 黒くべたついていれば水分が多すぎます |
| 白い粉 | 切り返すとき、白い煙のように放線菌の胞子が舞います | よい兆候です |

> **アンモニア臭は一次発酵の間は正常です。窒素が微生物に移っていく過程で出る匂いです。問題は二次発酵が終わったあとにも残っている場合です。**

### 3-3. 二次発酵（後発酵） - 室内、5-7日

&nbsp;&nbsp;&nbsp;一次発酵を終えた堆肥を菌床に移し入れ、もう一度発酵させます。この段階が実質的な低温殺菌です。

| 段階 | 方法 | 温度 | 目的 |
|:---|:---|:---:|:---|
| **床詰め** | 菌床の木枠に堆肥を**㎡あたり50-60kg**すばやく詰めます | - | 自らの熱を失わないよう急ぐ必要があります |
| **低温殺菌** | 栽培舎内の温度を60℃に上げ、**6時間**維持します | 60℃ | **病害虫と雑菌の死滅** |
| **後発酵** | 堆肥温度を50-55℃で2-3日、48-50℃で1-2日、45度で終えます | 45-55℃ | **放線菌の活性化、アンモニアの除去** |
| **完了判定** | アンモニア臭が完全に消え、堆肥の表面に**濃い白色の放線菌**が覆います | - | 種菌接種の適期 |

#### 3-3-1. 電力なしで低温殺菌60度を作る方法

&nbsp;&nbsp;&nbsp;商業栽培ではボイラーの蒸気で栽培舎を60度に上げます。電力と燃料がなければ、堆肥自身の発熱を使うのが正解です。

| 方法 | 説明 | 備考 |
|:---|:---|:---|
| **自己発熱の活用** | 一次発酵が盛んな堆肥を熱いまま移し入れ、菌床をむしろや敷物で覆って熱を閉じ込めます | もっとも基本的な方法。堆肥の内部はすでに60℃を超えています |
| **堆を厚く、部屋は小さく** | 床詰めの厚さ25-30cm。小さな部屋や洞窟で行うと堆肥の熱で室内が暖まります | 薄かったり空間が広かったりすると冷めます |
| **オンドルの活用** | オンドル構造があれば、かまどに火を焚いて床を温めます | もっとも確実ですが燃料が要ります |
| **晴れた日を選んで行う** | 5-6月や9-10月の晴天日。ビニールをかぶせると太陽熱が加わります | 季節を選びます |

> **低温殺菌60℃6時間を満たせないなら、55℃で12時間、あるいは50℃で24時間に切り替えます。温度と時間は交換できます。温度が低いなら、その分長く維持すればよいのです。**

#### 3-3-2. アンモニアが残ると種菌が死にます

&nbsp;&nbsp;&nbsp;後発酵のもっとも重要な目標がこれです。マッシュルームの菌糸はアンモニアに非常に弱く、堆肥に0.1%以上残っていると、接種した種菌がそのまま死んでしまいます。

| 確認方法 | 判定 |
|:---|:---|
| **匂い** | 鼻を刺すようなアンモニア臭がまったくないことが必要です |
| **白い放線菌** | 堆肥の表面と内部に白く細い層が均一に覆っていれば完了です |
| **色とわらの状態** | 濃い褐色からチョコレート色。手で軽く引くと切れます |
| **水分と酸度** | 68-72%、pH 6.8-7.2の中性 |

> **アンモニア臭が残っていたら絶対に接種してはいけません。** 換気を増やし、さらに数日発酵させます。この一点を守らずに失敗するケースが、マッシュルーム栽培でもっとも多いのです。

&nbsp;&nbsp;&nbsp;換気がアンモニア除去の要です。後発酵中は10分から15分ずつ、短く何度も換気します。長く開けると堆肥が冷めて発酵が止まり、まったく開けないとアンモニアが抜けません。

### 3-4. 栽培舎と菌床 - 電力なしで作る構造

| 項目 | 基準 | 災害時の代案 |
|:---|:---|:---|
| 栽培舎 | 16-25℃を維持できる閉じた空間 | **土窟、地下室、北向きの倉庫、半地下の穴倉、土壁の納屋** |
| 菌床 | 幅1-1.2m、堆肥の深さ20-30cmの2-4段の棚枠 | 丸太と板、竹で組みます |
| 床と換気口 | 水はけのよい床、上下の換気口 | 砂利敷きの床。煙突効果による自然換気 |
| 光 | **必要ありません** | 完全な暗闇でも育ちます |

&nbsp;&nbsp;&nbsp;土窟がマッシュルームにもっとも適した栽培空間です。一年中12度から18度を保ち、湿度が高く、光がなく、温度変化が小さいため、要求条件をほぼそのまま満たしています。山の斜面を2m以上掘り込み、木で天井を支えて土をかぶせればできます。

&nbsp;&nbsp;&nbsp;換気口は下と上に一つずつ設けます。内部の空気が暖かければ上に抜け、冷たい空気が下から入ってきて、送風機なしで自然対流による換気が行われます。マッシュルームは子実体が育つとき二酸化炭素を嫌うため、この構造が重要です。

### 3-5. 覆土材料

&nbsp;&nbsp;&nbsp;覆土は堆肥の上にかぶせる土で、マッシュルーム栽培で欠かせない段階です。菌糸は堆肥から養分を得て、子実体は覆土層と堆肥層の境目に結ばれるため、覆土がないと菌糸は表面に白い膜を作ったまま、キノコを作りません。

| 項目 | 通常 | 災害時の代替 |
|:---|:---|:---|
| 材料 | 泥炭（ピートモス）、真砂土、土を1対1で混合 | **腐葉土 + 砂 + 石灰**、または田んぼの土 + もみ殻 + 貝殻粉 |
| 酸度と厚さ | **pH 7.5以上**、2-3cm | 草木灰や消石灰を混ぜて酸度を上げます |
| 硬さ | **ぽろぽろとくずれる状態である必要があります** | 細かい土だけ使うと固まり、幼菌が突き破れません |
| 殺菌 | 60℃以上で数時間蒸してから使います | 大釜で蒸すか、鉄板に広げて炒ります |

> **覆土の酸度を7.5以上に上げることが重要です。マッシュルームの菌糸は中性から弱アルカリ性に耐えますが、アオカビは弱酸性を好みます。アルカリ性にしておけば競争で有利になります。石灰がなければ、草木灰を水に溶いて一日置き、上澄みを使うか、灰を直接土に混ぜます。**

&nbsp;&nbsp;&nbsp;覆土用の土を殺菌する作業は省略しがちですが重要です。土にはキノコバエの卵やダニ、乾性バブル病の胞子が入っており、せっかく殺菌した堆肥に病気を持ち込むことになります。大釜に土と少量の水を入れて一時間蒸すか、薄く広げて鉄板で炒ります。完全な滅菌ではなく、害虫と病原菌を減らす程度で十分です。

## 4. 種菌の確保

&nbsp;&nbsp;&nbsp;キノコには種がありません。種苗店が閉まれば種を買う場所がなく、種を採ってかめに入れておくという方式も通用しません。評価表ではマッシュルームの自家採種はC、種子寿命はDです。無菌培養が必要で、市販の種菌は6か月から1年で活力を失うという意味であり、しかもマッシュルームはほかのキノコより胞子から菌株を立ち上げるのが難しい種です。しかし菌類には植物にはない道があります。

### 4-1. マッシュルームの胞子が特別な理由

&nbsp;&nbsp;&nbsp;普通のキノコは胞子一粒が発芽して遺伝子を半分だけ持つ一次菌糸になり、異なる交配型の一次菌糸二つが出会って結合してはじめて二次菌糸となり、キノコを結びます。結合できなかった一次菌糸は伸びるだけ伸びて、やがて勢いが弱まり死滅します。

&nbsp;&nbsp;&nbsp;マッシュルームは違います。担子器一つに胞子が四つではなく**二つだけ**付き、その胞子の中に異なる交配型の核が二つ入っている場合が多いのです。つまり胞子一粒がすでに二次菌糸に相当する状態で生まれ、一粒からでもキノコが出ます。

| 項目 | 普通のキノコ | マッシュルーム |
|:---|:---|:---|
| 担子器あたりの胞子数 | 4個 | **2個** |
| 胞子の核 | 単核（遺伝子半分） | **たいてい二核（遺伝子が完全）** |
| キノコになる条件 | 異なる交配型の胞子二つが出会う必要がある | **一粒でも可能** |
| 多様性と発芽率 | 多様性が大きく、発芽率は比較的高い | **多様性がほぼなく、発芽率が低い** |

&nbsp;&nbsp;&nbsp;一粒で済むという点は楽に見えますが、代償があります。遺伝的多様性がないため世代を重ねると活力が落ち、発芽率が低いため胞子を撒いても失敗しやすいのです。

> **そのため発芽率が低いマッシュルームは、滅菌培地に胞子を振り落とすとき、一粒だけを慎重に落とすのではなく、多数の胞子の粉を一度にたっぷり振り入れなければなりません。**

### 4-2. 胞子の採取と胞子紋

| 段階 | 方法 |
|:---|:---|
| 対象を選ぶ | **傘が大きく開いて、ひだが濃い褐色に染まった**大きな個体 |
| 柄を切る | 傘と柄が接する位置で、柄をぎりぎりまで切り落とします |
| 受け皿と覆い | ひだを下に向けて**アルミホイル**の上に置き、器をかぶせます |
| 放置と回収 | 涼しい場所に24時間。傘を持ち上げると**褐色からチョコレート褐色**の胞子の粉が残ります |

&nbsp;&nbsp;&nbsp;マッシュルームの胞子は褐色からチョコレート褐色です。この色は種菌保存のための情報であると同時に、**安全確認の中核となる指標**です。12節で見るように、致死的なテングタケ類は胞子が白色であるため、胞子紋を取ってみるという一つの動作が、もっとも危険な誤認をふるい落とします。

&nbsp;&nbsp;&nbsp;紙よりアルミホイルのほうが優れています。紙は湿気を吸い込み、繊維の間に雑菌が隠れます。

### 4-3. 胞子の保存 - 電気なしで10年

| 段階 | 方法 |
|:--:|:---|
| 1 | ホイルを敷き、その上にキノコの傘を一日伏せて置き、胞子を受けます |
| 2 | ホイルを風通しのよい**日陰**にもう一日置き、わずかな湿気まで飛ばします |
| 3 | 半分に折って胞子の面を内側にして保護し、ジップ袋に入れます |
| 4 | **よく炒った塩や炭のかけら**を一緒に入れて湿気を抑えます |
| 5 | ジップ袋をガラス瓶にまとめて**蜜蝋で封をし**、四季を通じて温度が一定で光の入らない**土窟や地下室**に置きます |

| 保存形態 | 寿命 | 備考 |
|:---|:---:|:---|
| 胞子紋（ホイル乾燥） | **5-10年以上** | 水分が排除されて細胞活動が停止します |
| 液体種菌（滅菌水懸濁） | 3-6か月 | 冷蔵がないと早期発芽するか、細菌が増殖します |
| 接種済み種菌 | 6か月-1年 | 生きた菌糸のため、養分を使い続けます |

> **災害の状況では胞子を液体で保管してはいけません。必ずホイルに包んだ形で保管する必要があります。**

&nbsp;&nbsp;&nbsp;紫外線が胞子のDNAを破壊するため、光の入らない奥深い場所である必要があります。胞子と植物の種の寿命の違いは、その構造から来ます。

| 比較項目 | トマトの種 | キノコの胞子 |
|:---|:---|:---|
| 平均寿命（室温） | 約2-4年 | 約5-10年以上 |
| 弱点となる要因 | 温度変化、自身の養分の枯渇 | 湿気によるカビ汚染 |
| 細胞構造 | 複雑な胚と栄養物質 | 単一細胞と厚い保護壁 |

&nbsp;&nbsp;&nbsp;種は胚と養分を抱え込んでいるため、時間が経つと自ら消耗して老いて死にますが、キノコの胞子は厚い細胞壁に包まれた単一の細胞にすぎないため、消耗する養分がありません。

> **評価表の種子寿命Dは市販の種菌を基準にしたものです。胞子をホイルに包んで保管すれば、事実上SS級になります。災害の初年度に、もっとも大きく健康な個体でホイルに胞子を受け、20-30枚作って土窟に蓄えておきましょう。種菌をすべて失っても、5年後、10年後にまた始められます。**

### 4-4. 組織培養 - マッシュルームでもっとも確実な方法

&nbsp;&nbsp;&nbsp;マッシュルームは胞子の発芽率が低いため、組織培養が特に重要です。傘と柄が接する部分の内部にある白い肉は、すでに交配型の結合が終わった二次菌糸の塊であるため、胞子発芽の過程を経る必要がなく、そのまま菌糸が四方に伸びていきます。

| 段階 | 方法 |
|:---|:---|
| 選ぶ | **傘が開きかけた新鮮なボタン。** 古いものや虫食いのものは使いません |
| 消毒 | 刃物を火であぶってから冷ますか、沸騰した湯に浸けてから取り出します |
| 割る | **手で縦に割ります。** 刃物で切ると表面の雑菌が内部に持ち込まれます |
| 採取と接種 | 傘と柄が接する内側の白い肉を米粒大にちぎり取り、煮て冷ました稲わらや堆肥に差し込みます |
| 培養 | 23-25℃の暗い場所。3-5日で切片の周りに白い菌糸が広がります |

&nbsp;&nbsp;&nbsp;手で割ることが重要な理由は、キノコの内部がほぼ無菌に近いためです。表皮とひだにはあらゆる胞子が付着していますが、肉の中はきれいです。手で割ると、そのきれいな面が新しく露出し、ちぎり取った切片は消毒なしでも純粋な菌糸になります。

### 4-5. わら加熱培地法 - 胞子や組織から種菌を立ち上げるとき

&nbsp;&nbsp;&nbsp;理論的には滅菌培地に胞子を振りかければ菌糸が伸びますが、現実には空気中のアオカビや細菌が、キノコの胞子より数百倍速く培地を占領してしまいます。栄養価が高い培地ほど汚染に弱いため、電気がない状況では、自然の防御力を利用した原始的な培地のほうが有利です。

| 段階 | 方法 |
|:---|:---|
| 煮る・絞る | 稲わらや麦わら、大豆の莢殻を**沸騰した湯に1時間以上**入れて煮て滅菌し、水気を絞って冷まします |
| 接種 | 胞子の粉を均一にたっぷり振りかけるか、組織培養の切片をわらの間に差し込みます |
| 覆う | **清潔な布で覆い**、風や落下してくる胞子を防ぎます |
| 培養 | 23-25℃の暗い場所で2-4週間。白い菌糸がわらを覆えば成功です |

&nbsp;&nbsp;&nbsp;栄養の少ないわらはアオカビにとっても魅力が薄いため、菌糸の伸びが遅くても競争に負けません。ここで得た菌糸の塊を穀粒や発酵堆肥に移し、種菌として育てます。

&nbsp;&nbsp;&nbsp;マッシュルームには利点があります。本来の培地が発酵堆肥であるため、種菌を増やす培地も同じ堆肥を取り分けて使うことができ、すでに低温殺菌された選択的培地であるため雑菌にも弱くありません。堆肥をひとつかみ取り分けて小さなかめに入れ、組織培養の切片を入れれば、それが種菌の培養器になります。

### 4-6. 菌床移植 - もっとも簡単な種菌のつなぎ方

&nbsp;&nbsp;&nbsp;評価表の自家採種はCですが、実際には菌糸が広がった堆肥を移すことで、無菌操作なしに種菌をつなぐことができます。

| 段階 | 方法 |
|:---|:---|
| 時期 | 菌糸が堆肥全体に広がった直後、覆土の前 |
| 対象 | 白い菌糸が密で雑菌の跡がない部分を、こぶし大にすくい取ります |
| 移す | 新しく後発酵を終えた堆肥に20-30cm間隔で埋め込みます |
| 割合 | 新しい堆肥の重量の3-5% |
| 限界 | **四、五世代を超えると活力が落ちます。** 定期的に組織培養に戻します |

&nbsp;&nbsp;&nbsp;世代を重ねると活力が落ちるのが、マッシュルームの弱点です。五、六回移植したあとは収量が目に見えて落ちるため、もっとも良い個体を選んで組織培養から新しく立ち上げるか、蓄えておいた胞子紋を使います。

### 4-7. 種菌確保の優先順位

| 順位 | 方法 | 条件 |
|:--:|:---|:---|
| 1 | 市販の種菌 | 普及度Sのため平時にはもっとも簡単です。あらかじめ確保します |
| 2 | 組織培養 | 新鮮なキノコがあるとき。マッシュルームでもっとも確実です |
| 3 | 菌床移植 | 菌糸が広がった堆肥があるとき。もっとも速いです |
| 4 | 胞子紋 | すべて失ったとき。発芽率が低いためたっぷり使います |
