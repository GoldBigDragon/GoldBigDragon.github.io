## 10. 生长异常诊断

| 症状 | 原因 | 处理 |
|:---|:---|:---|
| 接种1周后仍不见菌丝 | **堆肥中残留氨气**，接种时堆肥温度过高 | 延长后发酵或重新翻堆通气。务必确认氨气味是否消失 |
| 菌丝生长后停滞 | 堆肥温度超过30℃，水分不足 | 将室温降到20℃，耙松堆肥表面散热 |
| 菌丝良好但不出菇 | 未覆土、通风不足、温度偏高 | 覆土并打开通风口排出二氧化碳，再降到16-18℃ |
| 覆土表面被白色菌膜厚厚覆盖 | 菌丝过于旺盛，湿度和二氧化碳过高 | 用耙子轻轻搔动切断菌丝，加大通风 |
| 原基形成后干枯死亡 | 湿度不足，覆土变干 | 像喷雾一样洒水，将湿度提高到85-95% |
| 原基形成后腐烂死亡 | 浇水过多、过猛 | 减少浇水并加强通风 |
| 菌柄长、菌盖小 | **二氧化碳过多。** 通风不足 | 打开通风口更换空气 |
| 菌盖很快展开且薄 | 温度在22℃以上 | 移到更凉爽的地方 |
| 菌盖表面粗糙开裂 | 空气过于干燥 | 向地面和墙壁洒水提高湿度 |
| 菌盖出现褐色凹陷斑点 | 细菌性褐斑病，菌盖上残留水珠 | 减少浇水并通风使菌盖变干 |
| 蘑菇变成挤压变形的白色团块 | **干腐病。** 由覆土带入 | 清除病菇及周围覆土，下一周期务必将覆土蒸煮消毒 |
| 菇柄内有蛆虫 | 菇蝇 | 封住通风口和出入口，清除受害个体 |
| 菌盖变黄褪色 | 过熟、温度过高 | 及时采收 |
| 第二潮产量几乎没有 | 堆肥养分耗尽 | 属正常现象，须更换堆肥 |

## 11. 菌糠循环利用

### 11-1. 废堆肥不是废物

&nbsp;&nbsp;&nbsp;出菇结束后的堆肥，已经过两次发酵，又被菌丝再分解了一次，是彻底腐熟的有机质。在本文涉及的六个品种中，**菌糠肥效最好的正是双孢蘑菇。**木屑菌糠因木质部分尚未分解，施入田里会夺取土壤中的氮，而双孢蘑菇的废堆肥碳氮比已经很低，可以直接施用。

| 用途 | 方法 |
|:---|:---|
| **基肥** | 摊开翻入田中。氮、磷、钾、钙含量均衡 |
| **覆盖材料** | 在作物间铺5cm厚，抑制杂草并减少水分蒸发 |
| **覆土材料** | 过筛后掺入下一周期的覆土，须重新蒸煮后使用 |
| **其他菌菇培养基** | 掺入大球盖菇的木片培养基中可作为氮源 |
| **育苗土** | 与沙子混合可作育苗基质 |
| **蚯蚓养殖基质** | 是蚯蚓最喜欢的基质，可获得蚓粪 |
| **改良酸性土壤** | 含有石膏和石灰，可提高酸性土壤的酸碱度 |

```
稻草 + 粪肥 + 贝壳 → 发酵堆肥 → 采收蘑菇 → 废堆肥 → 田间肥料
                                                   └ 蚯蚓 → 蚓粪
```

> **种植双孢蘑菇实际上就是一个制作堆肥的过程，中间只是顺带收获一次蘑菇。即使没能收获到蘑菇，堆肥也依然留了下来。这是其他菌菇所没有的一道安全网。**

&nbsp;&nbsp;&nbsp;这个视角在灾害状况下很重要。其他菌菇一旦失败，木屑和木柴就等于白白耗费了。双孢蘑菇即便失败，也还留有可施入田地的堆肥。正因为投入不会完全落空，这是风险最低的一种菌菇栽培。

### 11-2. 再次利用废堆肥时的注意事项

| 情况 | 判断 |
|:---|:---|
| 正常采收完毕的堆肥 | 可直接施入田中 |
| **被绿霉污染的堆肥** | **不要施入田中。**须焚烧，或深埋在远离栽培地的地方 |
| **发生过干腐病的堆肥与覆土** | 同上处理。病原孢子能在土中存活数年 |
| 菇蝇滋生过的堆肥 | 须再次堆积发热杀灭虫卵后方可使用 |

> **不要把受污染的培养基重新变回堆肥。**绿霉和干腐病的孢子能在堆肥堆中存活下来，来年又混入新的培养基。

### 11-3. 栽培空间的年度管理

| 年限 | 管理 |
|:--:|:---|
| 每个周期 | 清空菌床木框，用水冲洗后晒干 |
| 1年 | 可以继续沿用同一栽培舍 |
| 2-3年 | 在墙壁和地面涂刷石灰硫磺合剂或浓草木灰水 |
| 问题累积时 | 让栽培舍空置一季，打开门窗通风见光 |

&nbsp;&nbsp;&nbsp;木框是木制的，病原菌容易渗入。每个周期结束后要用水冲洗，条件允许的话可以浇热水或用火燎烤表面。若使用竹子或木板，最好每隔几年更换一次。

## 12. 毒蘑菇误认与安全确认

> **本节关系到生命安全。确认能不能吃，比种得好不好更重要。**

&nbsp;&nbsp;&nbsp;在本文涉及的六个品种中，**双孢蘑菇是因误认致命毒蘑菇而实际报告死亡事故最多的一种。**在韩国国内外都反复发生。原因在于三个条件同时叠加。

| 叠加的条件 | 内容 |
|:---|:---|
| **都生长在土里** | 双孢蘑菇顶破覆土长出，鹅膏类也生长在地面上 |
| **都在白色纽扣期采收** | 双孢蘑菇的采收适期正是菌盖收拢的白色球形阶段，鹅膏的幼体也是白色球形 |
| **都有菌环** | 双孢蘑菇和鹅膏的菌柄上都有白色膜状的环 |

> **区分双孢蘑菇和白毒鹅膏，唯一的关键就是菌柄基部有没有菌托。不确认这一点，迟早会吃错。**

### 12-1. 双孢蘑菇的鉴别特征

&nbsp;&nbsp;&nbsp;即便是自己种的蘑菇，覆土中也可能混入野生孢子，长出其他种类的蘑菇。**不能仅凭长在菌床上这一点就认定安全。**须逐项确认以下特征。

| 部位 | 双孢蘑菇 |
|:---|:---|
| 菌盖 | 直径3-10cm。由半球形展开为扁平形。白色、奶油色、褐色 |
| 菌盖表面 | 光滑或带细微纤维纹，没有黏液 |
| **菌褶** | **初为浅粉色 → 随生长变褐色 → 最终变黑褐色** |
| **孢子印颜色** | **褐色至巧克力褐色。** 把菌盖放在白纸上接一会儿即可确认 |
| 菌柄 | 短而粗，长3-7cm，粗1-2cm |
| **菌柄的菌环** | **有。** 幼时覆盖菌盖的白膜破裂后留在菌柄上 |
| **菌柄基部** | **没有菌托。** 基部只是埋在堆肥里 |
| 菌肉 | 白色，切开后**逐渐变为浅粉色再转褐色** |
| 气味 | 蘑菇香，没有令人不适的气味 |
| 发生基质 | 发酵堆肥与覆土交界处 |

> **要确认菌褶，必须掰开一朵来看。**纽扣期菌褶藏在菌盖内部看不到。掰开后若切面菌褶呈浅粉色即为双孢蘑菇，若始终纯白则要怀疑是鹅膏。这一个动作能决定生死。

### 12-2. 白毒鹅膏与致命鹅膏——菌托是分水岭

&nbsp;&nbsp;&nbsp;白毒鹅膏（Amanita verna）和致命鹅膏（Amanita virosa）含有鹅膏毒肽，是致命毒菇，一朵就足以致人死亡。没有解毒药，在缺乏医疗支援的情况下几乎必死无疑。

| 区分 | **双孢蘑菇** | **白毒鹅膏·致命鹅膏（致命）** |
|:---|:---|:---|
| **菌柄基部** | **没有菌托** | **膜状菌托包裹菌柄基部** |
| **菌褶颜色** | **浅粉 → 褐色 → 黑褐色** | **从始至终纯白色** |
| **孢子印颜色** | **褐色至巧克力褐色** | **白色** |
| 菌盖颜色 | 白色、奶油色、褐色 | 纯白色，致命鹅膏中央略带黄色 |
| 菌柄 | 短而粗，3-7cm | **细长，9-20cm** |
| 菌柄表面 | 光滑 | **致命鹅膏表面有白色纤维状鳞片，较粗糙** |
| 菌环 | 有 | 有，**无法据此区分** |
| 菌肉颜色变化 | 切开后由粉转褐 | 不变色，始终白色 |
| 气味 | 蘑菇香 | 老熟个体有令人不快的气味 |
| 发生基质 | 发酵堆肥与覆土 | **活树根附近的土地** |
| 发生习性 | 成丛长在菌床上 | 在林中单朵或散生数朵 |

> **要养成连土一起挖出基部确认的习惯。**
> 确认菌托必须挖开才能看到。只看地面以上的部分，菌托会被土掩埋而看不见。双孢蘑菇是一种容易只把地上部分割下采收的蘑菇，因此这个习惯尤为重要。这正是第8节要求连基部整株拔出的原因。

> **把菌盖倒扣在白纸上、罩上杯子放置数小时，若落下的粉末是白色，绝对不能吃。**
> 双孢蘑菇的孢子是褐色到巧克力褐色。如果孢子是白色、菌褶自始至终是白色、菌柄基部有菌托，只要三者中有一项符合，就不要食用。

&nbsp;&nbsp;&nbsp;须了解鹅膏毒肽中毒的病程。食用后6-24小时内不会有任何症状，之后开始剧烈呕吐、腹泻和腹痛，持续约一天。接着会有两三天症状缓解、看似恢复的阶段，而正是在这段时间里肝脏正在被破坏。随后出现黄疸、出血和意识下降，届时往往已回天乏术。

> **超过6小时才出现症状的中毒最为危险。**食用后30分钟到2小时内腹痛，大多只是肠胃刺激；而6-24小时后才开始呕吐腹泻，是鹅膏毒肽中毒的典型病程。发作越晚，病情越重。

### 12-3. 同属蘑菇属的毒菇——伤口变黄的种类

&nbsp;&nbsp;&nbsp;与双孢蘑菇同属蘑菇属（Agaricus）的种类中，也有不能食用的，即受伤变黄的一类。在韩国国内被称为黄斑蘑菇（Agaricus xanthodermus）系列。

| 区分 | **双孢蘑菇** | **黄斑蘑菇类（肠胃毒性）** |
|:---|:---|:---|
| **伤口变色** | 切开后**由浅粉转褐色** | **切开或摩擦后会变成鲜黄色，** 基部尤其明显 |
| **气味** | 蘑菇香 | **类似墨水、石炭酸或药品的刺鼻气味，加热后更明显** |
| 孢子印颜色 | 褐色至巧克力褐色 | 褐色，与双孢蘑菇难以区分 |
| 菌褶颜色 | 浅粉 → 褐色 | 白色 → 粉色 → 褐色，与双孢蘑菇相似 |
| 发生基质 | 发酵堆肥与覆土 | 草地、庭院、路边的土地 |

> **若摩擦基部变黄并散发药品气味，就不要食用。**虽不致死，但会引起剧烈呕吐和腹泻。在缺乏医疗支援的状况下，脱水本身就很危险。

### 12-4. 其他容易混淆的蘑菇

| 蘑菇 | 区分点 |
|:---|:---|
| **蘑菇（野生食用种）** | 是双孢蘑菇的野生近缘种，可食用，生长在草地上。不过仍需与鹅膏区分，须按同样的确认步骤操作 |
| **白刺鹅膏** | 菌盖上有白色刺状突起，且有菌托 |
| **致命鹅膏幼体（蛋形期）** | **呈白色蛋形，与双孢蘑菇的纽扣期外观最为相似。**掰开后内部已可见蘑菇雏形，外皮与内部之间有一层胶质膜 |
| **马勃类** | 掰开后内部均匀呈白色棉絮状，没有菌褶。幼体可食用，但若内部可见蘑菇雏形则是鹅膏 |
| **鬼伞类** | 菌盖随时间推移会溶化变黑，与酒同食会中毒 |

> **发现白色蛋形的蘑菇，务必纵向剖开查看。**若内部均匀呈白色棉絮状即为马勃，若内部可见折叠的蘑菇雏形则是鹅膏的幼体。鹅膏幼体在外皮下方有一层半透明的胶质层，摸起来滑腻。

### 12-5. 初次食用的原则

&nbsp;&nbsp;&nbsp;在缺乏医疗支援的状况下，确认步骤本身就是一种防护手段。

| 顺序 | 内容 |
|:--:|:---|
| 1 | **连土一起挖出基部，确认有没有菌托。**若有菌托就丢弃 |
| 2 | **纵向掰开一朵看菌褶颜色。**若为浅粉色即为双孢蘑菇，若始终纯白就丢弃 |
| 3 | **查看切面是否变黄。**若变黄并伴有药品气味就丢弃 |
| 4 | **采集孢子印确认颜色。**若为白色就丢弃 |
| 5 | **务必充分煮熟。**虽是可生食的蘑菇，但野生个体要煮熟 |
| 6 | 初次只由**一人、少量（一小块）**食用，等待24小时 |
| 7 | 若无异常再增加食用量，不要多人同时食用 |
| 8 | 把吃过的那朵蘑菇**单独留存一份。**万一中毒可用于核对 |

> **在灾害状况下食用双孢蘑菇最安全的方法，不是到野外去找，而是自己栽培。若是自己堆好堆肥、接种的菌床上长出来的，判别问题几乎不会发生。即便如此，也要把挖开基部确认的动作保留为习惯。**
