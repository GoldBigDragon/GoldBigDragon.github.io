## 3. 培养基材料与准备

&nbsp;&nbsp;&nbsp;双孢蘑菇的培养基与其他五个品种的性质完全不同。它不是把木屑装瓶蒸煮而成的培养基，而是把稻草和粪便堆积起来使其自行发热而成的**发酵堆肥**。

> **其他菌菇要靠烧柴来给培养基灭菌，双孢蘑菇则靠微生物释放的热量给培养基灭菌。人只需要翻堆，不必生火，是唯一不耗电、不耗燃料的灭菌方法。**

&nbsp;&nbsp;&nbsp;堆肥发酵有三个作用。第一，堆内温度达到60-70℃，杀死病原菌、害虫卵和杂草种子。第二，嗜热微生物会先把杂菌容易利用的糖分吃光，剩下的就成了只有双孢蘑菇菌丝才能分解的难分解有机物，也就是选择性培养基。第三，秸秆变软，氮被固定为微生物蛋白质，转化为双孢蘑菇可以利用的形态。

### 3-1. 堆肥材料

| 类别 | 常规配比 | 灾害状况替代 |
|:---|:---|:---|
| **碳源** | 稻草、麦秸、大麦秸80% | 山野草、干草、玉米秆、芦苇、稻壳、旧纸 |
| **氮源** | 鸡粪、尿素、硫铵、米糠 | **马粪**、牛粪、猪粪、存放过的尿液、豆荚壳、麻饼 |
| **矿物质** | 石膏（硫酸钙）、沸石 | **贝壳烧后捣碎**、蛋壳粉、草木灰、熟石灰 |

&nbsp;&nbsp;&nbsp;传统双孢蘑菇堆肥的氮源是马粪。马粪中混有未消化的秸秆，碳氮比恰好合适。如果家里养有牲畜，马粪或牛粪比鸡粪更容易处理，人的尿液存放几天后浇在秸秆上也能成为氮源。

&nbsp;&nbsp;&nbsp;石膏（硫酸钙）不是用作养分的。钙能防止秸秆纤维相互粘连、避免堆肥结块，同时缓冲酸度、供给硫。把贝壳、牡蛎壳、蛋壳烧过后捣碎也能起到同样的作用。不过这样无法额外供硫，因此要掺入少量草木灰。

| 标准 | 数值 | 备注 |
|:---|:---:|:---|
| 碳氮比（C/N） | 起始**28-32比1**，完成时16-18比1 | 只用秸秆会超过70比1，必须补充氮 |
| 每100kg稻草配鸡粪 | 10-15kg | 若用马粪则为30-50kg |
| 每100kg稻草配米糠 | 5kg | |
| 每100kg稻草配尿素 | 400-500g | 若用尿液代替则为10-15L |
| 每100kg稻草配石膏（硫酸钙） | 3-5kg | 可用贝壳粉代替 |

### 3-2. 一次发酵——露天堆制，2-3周

| 阶段 | 方法 | 时间 | 温度 |
|:---|:---|:---:|:---:|
| **预堆** | 给稻草充分浇水，此时加入**总水量的70%以上**，使秸秆变软 | 1-2天 | - |
| **建堆** | 把鸡粪、米糠、尿素、石膏与秸秆一层层交替堆叠，使截面呈**龟背形** | 1天 | 初期发热 |
| **翻堆** | 每隔2-3天翻堆**5-8次**，把外层和内层互换位置 | 2-3周 | 堆内55-70度 |

| 项目 | 标准 | 原因 |
|:---|:---|:---|
| 堆体尺寸 | 高1.5-1.8m，宽1.5-2m，长度不限 | 太矮聚不了热，太高内部会因缺氧而腐烂 |
| 截面形状 | 顶部略圆的龟背形 | 雨水不会渗入内部，而是沿表面流走 |
| 目标温度 | 堆内55-70度 | 需要热到手伸不进去的程度 |
| 水分 | 握紧时指缝间能滴下几滴水的程度 | 太干就不会发热 |

&nbsp;&nbsp;&nbsp;发酵是需要氧气的好氧过程。堆内氧气一旦耗尽，发热就会停止，转为厌氧腐败。翻堆是一边重新引入氧气，一边把外层没有受热的部分移到内部，使其均匀发酵的作业。这不是简单地搅拌，而是要**把外层的秸秆铲起放入新堆的中心**。

| 发酵进程信号 | 正常 | 异常 |
|:---|:---|:---|
| 温度 | 堆制后2-3天达到55℃以上，此后维持 | 温度上不去说明缺氮或缺水 |
| 气味 | 会散发出强烈的氨味 | 若是阴沟味·硫化氢味则为厌氧腐败 |
| 颜色与秸秆状态 | 黄褐色到深褐色，揉搓容易断裂 | 若发黑发黏，说明水分过多 |
| 白色粉末 | 翻堆时放线菌孢子会像白烟一样飞扬 | 这是好兆头 |

> **氨味在一次发酵期间是正常的，是氮转移到微生物体内过程中散发出的气味。问题在于二次发酵结束后氨味仍然残留的情况。**

### 3-3. 二次发酵（后发酵）——室内，5-7天

&nbsp;&nbsp;&nbsp;把完成一次发酵的堆肥移入菌床，再发酵一次。这个阶段实质上就是巴氏灭菌。

| 阶段 | 方法 | 温度 | 目的 |
|:---|:---|:---:|:---|
| **上床** | 把堆肥**按每㎡50-60kg**迅速填入菌床木框 | - | 必须抓紧时间，避免自身热量散失 |
| **巴氏灭菌** | 把菇房内温度升到60℃，维持**6小时** | 60℃ | **杀灭病虫害与杂菌** |
| **后发酵** | 堆肥温度先在50-55℃维持2-3天，再在48-50℃维持1-2天，最后在45度结束 | 45-55℃ | **激活放线菌，去除氨气** |
| **完成判定** | 氨味完全消失，堆肥表面被**浓密的白色放线菌**覆盖 | - | 接种菌种的适宜时机 |

#### 3-3-1. 不用电达到巴氏灭菌60度的方法

&nbsp;&nbsp;&nbsp;商业栽培是用锅炉蒸汽把菇房升到60度。没有电力和燃料时，正确做法是利用堆肥自身的发热。

| 方法 | 说明 | 备注 |
|:---|:---|:---|
| **利用自身发热** | 把一次发酵正旺的堆肥趁热移入，用草席或蒲席盖住菌床以锁住热量 | 最基本的方法，堆肥内部已经超过60℃ |
| **堆厚一些，房间小一些** | 上床厚度25-30cm，在小房间或洞窟中进行，堆肥的热量会使室内变暖 | 太薄或空间太大都会散热变凉 |
| **利用暖炕** | 若有暖炕结构，可在灶膛烧火使地面变热 | 最可靠，但要耗费燃料 |
| **挑选晴天进行** | 选5-6月或9-10月的晴天，盖上薄膜还能借助太阳热 | 需挑选合适的季节 |

> **如果达不到巴氏灭菌60℃维持6小时的条件，可以改成55℃维持12小时，或者50℃维持24小时。温度和时间可以互相替换：温度低一些，就延长维持的时间。**

#### 3-3-2. 氨气残留会导致菌种死亡

&nbsp;&nbsp;&nbsp;这正是后发酵最重要的目标。双孢蘑菇菌丝对氨气极其敏感，堆肥中若残留0.1%以上，接种的菌种就会直接死亡。

| 确认方法 | 判定 |
|:---|:---|
| **气味** | 必须完全没有刺鼻的氨味 |
| **白色放线菌** | 堆肥表里都均匀覆盖着一层白色细密的菌层即为完成 |
| **颜色与秸秆状态** | 深褐色至巧克力色，用手轻拉即断 |
| **水分与酸度** | 68-72%，pH 6.8-7.2中性 |

> **只要还残留氨味，绝对不能接种。**增加通风，再多发酵几天。在双孢蘑菇栽培中，因为没有遵守这一条而失败的情况最为常见。

&nbsp;&nbsp;&nbsp;通风是去除氨气的关键。后发酵期间要每次10到15分钟、短时多次地通风。开得太久堆肥会冷却导致发酵停止，完全不开氨气又排不出去。

### 3-4. 菇房与菌床——不用电搭建的结构

| 项目 | 标准 | 灾害状况替代方案 |
|:---|:---|:---|
| 菇房 | 能维持16-25℃的封闭空间 | **土窖、地下室、朝北仓库、半地下窖穴、土墙棚屋** |
| 菌床 | 宽1-1.2m，堆肥深20-30cm的2-4层架式框 | 用原木、木板、竹子搭建 |
| 地面与通风口 | 排水良好的地面，上下各设通风口 | 碎石地面，靠烟囱效应自然通风 |
| 光照 | **不需要** | 在完全黑暗中也能生长 |

&nbsp;&nbsp;&nbsp;土窖是最适合双孢蘑菇的栽培空间。它常年维持在12到18度，湿度高，没有光照，温度变化小，几乎完全符合所需条件。只需在山坡上挖进2m以上，用木材支撑顶部再覆盖泥土即可。

&nbsp;&nbsp;&nbsp;通风口要在上下各开一个。内部空气变暖后会往上排出，冷空气从下方进入，不用风机也能靠自然对流实现通风。双孢蘑菇子实体生长时厌恶二氧化碳，因此这个结构非常重要。

### 3-5. 覆土材料

&nbsp;&nbsp;&nbsp;覆土是覆盖在堆肥上方的泥土，是双孢蘑菇栽培中不可或缺的一步。菌丝从堆肥中吸收养分，而子实体是在覆土层与堆肥层的交界处结出的，因此没有覆土，菌丝只会在表面形成一层白膜，而不会结出蘑菇。

| 项目 | 常规 | 灾害状况替代 |
|:---|:---|:---|
| 材料 | 泥炭（草炭土）与真砂土、泥土按1比1混合 | **腐叶土+沙子+石灰**，或稻田土+稻壳+贝壳粉 |
| 酸度与厚度 | **pH 7.5以上**，2-3cm | 掺入草木灰或熟石灰以提高酸碱度 |
| 松紧度 | **必须松散、一捏就碎** | 只用细土会板结，幼菇顶不出来 |
| 灭菌 | 在60℃以上蒸数小时后使用 | 用大锅蒸，或摊在铁板上炒 |

> **把覆土的酸碱度提高到7.5以上非常重要。双孢蘑菇菌丝能耐受中性到弱碱性环境，而青霉菌偏爱弱酸性环境。做成碱性有利于双孢蘑菇在竞争中占优势。没有石灰的话，可以把草木灰溶于水中静置一天后取上层清液使用，或者直接把灰掺入泥土。**

&nbsp;&nbsp;&nbsp;给覆土用的泥土灭菌这一步容易被省略，但十分重要。泥土中带有菇蚊虫卵、螨虫和干泡病孢子，会把病害带进已经辛苦灭菌过的堆肥中。可在大锅中加入泥土和少量水蒸一个小时，或摊薄后用铁板炒制。不必完全灭菌，只要能减少害虫和病原菌即可。

## 4. 菌种获取

&nbsp;&nbsp;&nbsp;菌菇没有种子。种苗店一旦关门就没地方买种，留种装进瓮里保存的做法也行不通。在评价表中，双孢蘑菇的自家留种为C，种子寿命为D，意味着需要无菌培养，市售菌种6个月到1年就会失去活力，而且从孢子培育菌株比其他菌菇更困难。不过菌类另有一条植物所没有的路可走。

### 4-1. 双孢蘑菇的孢子为何特别

&nbsp;&nbsp;&nbsp;普通的菌菇是一粒孢子发芽成只带一半基因的初生菌丝，必须两个不同交配型的初生菌丝相遇结合，才能变成次生菌丝并结出蘑菇。没能结合的初生菌丝只会不断延伸，最终因势力减弱而死亡。

&nbsp;&nbsp;&nbsp;双孢蘑菇不同。一个担子上不是结四个孢子，而是只结**两个**，而且这些孢子内部往往已经带有两个不同交配型的细胞核。也就是说，一粒孢子诞生时就已经相当于次生菌丝的状态，单独一粒也能长出蘑菇。

| 项目 | 普通菌菇 | 双孢蘑菇 |
|:---|:---|:---|
| 每个担子的孢子数 | 4个 | **2个** |
| 孢子的细胞核 | 单核（基因减半） | **多为双核（基因完整）** |
| 结菇条件 | 须两个不同交配型的孢子相遇 | **一粒即可** |
| 多样性与发芽率 | 多样性大，发芽率较高 | **几乎没有多样性，发芽率低** |

&nbsp;&nbsp;&nbsp;单粒孢子就能成菌看似方便，却是有代价的。缺乏遗传多样性，世代越多活力越差；发芽率又低，即使撒了孢子也容易失败。

> **因此，发芽率低的双孢蘑菇在往灭菌培养基上撒孢子时，不能只小心翼翼地放一粒，而要一次性撒入大量孢子粉。**

### 4-2. 孢子采集与孢子印

| 步骤 | 方法 |
|:---|:---|
| 挑选对象 | **菌盖充分展开、菌褶已染成深褐色**的大个体 |
| 切除菌柄 | 在菌盖与菌柄相接处，把菌柄贴根切掉 |
| 承接与覆盖 | 让菌褶朝下放在**铝箔**上，再罩上容器 |
| 静置与收取 | 在阴凉处放置24小时，掀开菌盖后会留下**褐色至巧克力褐色**的孢子粉 |

&nbsp;&nbsp;&nbsp;双孢蘑菇的孢子呈褐色到巧克力褐色。这个颜色既是保存菌种的信息，同时也是**安全确认的核心标志**。正如第12节所述，致命的鹅膏类孢子是白色的，因此单是取一次孢子印这个动作，就能筛掉最危险的误食。

&nbsp;&nbsp;&nbsp;铝箔比纸更好用。纸会吸湿，而且纤维之间容易藏匿杂菌。

### 4-3. 孢子保存——不用电保存10年

| 步骤 | 方法 |
|:--:|:---|
| 1 | 铺好铝箔，把菌盖倒扣在上面放置一天，用来承接孢子 |
| 2 | 把铝箔放在通风的**阴凉处**再放一天，连细微的湿气也一并吹干 |
| 3 | 对折起来，把有孢子的一面保护在内侧，装入密封袋 |
| 4 | 一起放入**炒得干爽的盐或炭块**以吸潮 |
| 5 | 把密封袋一起装入玻璃瓶，**用蜂蜡封口**，放在四季温度稳定、不透光的**土窖或地下室**中 |

| 保存形式 | 寿命 | 备注 |
|:---|:---:|:---|
| 孢子印（铝箔干燥保存） | **5-10年以上** | 水分被排除，细胞活动随之停止 |
| 液体菌种（灭菌水悬浮） | 3-6个月 | 没有冷藏就会提前发芽或滋生细菌 |
| 已接种菌种 | 6个月-1年 | 是活的菌丝，会持续消耗养分 |

> **在灾害状况下不能把孢子保存为液体形式，必须用铝箔包好保存。**

&nbsp;&nbsp;&nbsp;紫外线会破坏孢子的DNA，因此必须放在不透光的深处。孢子与植物种子在寿命上的差异，源自结构的不同。

| 比较项目 | 番茄种子 | 菌菇孢子 |
|:---|:---|:---|
| 平均寿命（室温） | 约2-4年 | 约5-10年以上 |
| 脆弱因素 | 温度变化、自身养分耗尽 | 湿气导致的霉菌污染 |
| 细胞结构 | 复杂的胚与营养物质 | 单细胞与厚厚的保护壁 |

&nbsp;&nbsp;&nbsp;种子内部包着胚芽和养分，随着时间推移会自我消耗、衰老死亡；而菌菇孢子只是包在厚厚细胞壁里的单个细胞，没有可供消耗的养分。

> **评价表上的种子寿命D是以市售菌种为标准的。若把孢子用铝箔包好保存，实际上相当于SS级。请在灾害发生的第一年，用最大最健康的个体制作20-30张孢子印，存放在土窖里。即使菌种全部丢失，5年后、10年后仍能重新开始。**

### 4-4. 组织培养——双孢蘑菇最可靠的方法

&nbsp;&nbsp;&nbsp;由于双孢蘑菇的孢子发芽率低，组织培养格外重要。菌盖与菌柄相接处内部的白色菌肉，本身就是已经完成交配型结合的次生菌丝团块，因此不必经过孢子发芽的过程，菌丝可以直接向四周蔓延。

| 步骤 | 方法 |
|:---|:---|
| 挑选 | **菌盖刚要展开的新鲜纽扣菇。** 不使用陈旧或已生虫的个体 |
| 消毒 | 把刀在火上烤热后放凉，或浸入沸水后取出 |
| 掰开 | **用手纵向掰开。** 用刀切会把表面的杂菌带入内部 |
| 采取与接种 | 从菌盖与菌柄相接处的内部白色菌肉上取下米粒大小的一块，嵌入煮过放凉的稻草或堆肥中 |
| 培养 | 23-25℃避光处，3-5天菌块周围就会长出白色菌丝 |

&nbsp;&nbsp;&nbsp;掰开之所以重要，是因为菌菇内部几乎是无菌的。外皮和菌褶上附着着各种孢子，但内部的菌肉是干净的。用手掰开可以露出这个干净的新切面，取下的小块即使不消毒，也能长出纯正的菌丝。

### 4-5. 稻草蒸煮培养基法——从孢子或组织培育菌种时

&nbsp;&nbsp;&nbsp;理论上只要把孢子撒在灭菌培养基上，菌丝就会蔓延，但现实中空气里的青霉菌和细菌会以比蘑菇孢子快数百倍的速度占领培养基。培养基的营养价值越高，就越容易被污染，因此在没有电力的状况下，利用自然防御力的原始培养基反而更有利。

| 步骤 | 方法 |
|:---|:---|
| 蒸煮与挤水 | 把稻草、麦秸或豆荚壳放入**沸水中煮1小时以上**灭菌，挤干水分并放凉 |
| 接种 | 均匀充分地撒入孢子粉，或把组织培养的菌块嵌入秸秆之间 |
| 覆盖 | **用干净的布盖住**，阻挡风和飘落的杂孢子 |
| 培养 | 23-25℃避光处放置2-4周，白色菌丝覆盖秸秆即为成功 |

&nbsp;&nbsp;&nbsp;养分较少的秸秆对青霉菌的吸引力也较低，因此即使菌丝生长缓慢，也不会在竞争中落败。把这里得到的菌丝团块移入谷粒或发酵堆肥中，培育成种菌。

&nbsp;&nbsp;&nbsp;双孢蘑菇还有一个优势。由于本身的培养基就是发酵堆肥，扩繁菌种所用的培养基也可以直接取用同一种堆肥，而且这是已经经过巴氏灭菌的选择性培养基，不易受杂菌侵害。取一把堆肥装进小瓮中，放入组织培养的菌块，它就成了菌种培养器。

### 4-6. 菌床移植——最简便的接续菌种方法

&nbsp;&nbsp;&nbsp;评价表中的自家留种为C，但实际上只要移植菌丝已经蔓延的堆肥，不需要无菌操作也能接续菌种。

| 步骤 | 方法 |
|:---|:---|
| 时机 | 菌丝刚蔓延到整个堆肥之后、覆土之前 |
| 对象 | 挖取白色菌丝密集、没有杂菌痕迹的部分，取拳头大小 |
| 移植 | 埋入刚完成后发酵的新堆肥中，间隔20-30cm |
| 比例 | 新堆肥重量的3-5% |
| 局限 | **超过四五代活力就会下降。** 需要定期回归组织培养 |

&nbsp;&nbsp;&nbsp;世代越多活力越差，这正是双孢蘑菇的弱点。移植五六次之后，产量会明显下降，此时应挑选最优良的个体，用组织培养重新培育，或者启用存放的孢子印。

### 4-7. 菌种获取的优先顺序

| 顺序 | 方法 | 条件 |
|:--:|:---|:---|
| 1 | 市售菌种 | 普及度为S，平时最容易获得，应提前备好 |
| 2 | 组织培养 | 有新鲜蘑菇时采用，是双孢蘑菇最可靠的方法 |
| 3 | 菌床移植 | 有菌丝已蔓延的堆肥时采用，速度最快 |
| 4 | 孢子印 | 一切都失去时采用，因发芽率低须多量使用 |
