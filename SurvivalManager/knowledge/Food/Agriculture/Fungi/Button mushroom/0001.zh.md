---
## 引言
&nbsp;&nbsp;&nbsp;双孢菇（Agaricus bisporus）在评价表中被判定为排除。理由是耐储性E（以鲜品为准）与持续性C叠加，无法成立储备，未适用关卡得分为40.8分（有效183种中第103位）。耐储性E只要切成薄片晒干就能在密闭容器里存放一年，仅靠一把刀和一个晾筛就能解决。这种菇最大的优点是**不用电和柴火就能给培养料灭菌**。把稻草、粪和石膏堆起来，堆里的微生物会自己发热到55-70℃，杀死病原菌和害虫卵，并把杂菌爱吃的糖分烧光，留下只有双孢菇菌丝能吃的培养料。人不用烧火，只需翻堆。它不进行光合作用，所以火山灰或烟尘使天空变暗时产量也不会下降（光照SS）；稻草、马粪、鸡粪、稻壳、废纸、贝壳等几乎所有副产物都能做培养料（蘑菇副产物适应性S）；即使失败，堆肥也还在。代价是在2-3周里把堆肥翻五六次的劳动，以及与致命毒菇（白毒鹅膏、鳞柄白鹅膏）混淆的危险。第7节专门为区分它们而写得很长。

## 1. 灾害应对评估
| 类别 | 内容 |
|:---|:---|
| 判定 | 排除（耐储性E + 持续性C）。未适用关卡得分40.8，无防治减产率50.6% |
| 优势 | SS：蛋白质密度、光照、整地·挖掘能量、产量稳定性。S：收获速度、蘑菇副产物适应性、国内种植普及度 |
| 劣势 | E：耐储性（鲜品）、耐寒性、非食用价值。D：温度幅度、施肥、种子寿命。C：持续性（收两三茬后要重做堆肥）、自留种 |

> **蘑菇是阳光消失的世界里产量也不会下降的唯一粮食来源，而双孢菇是不用一块柴火就能做到这一点的唯一品种。**

&nbsp;&nbsp;&nbsp;各项目的等级见“灾害应对作物评价结果”文档。

## 2. 蘑菇概述
&nbsp;&nbsp;&nbsp;属担子菌门蘑菇科蘑菇属，韩语名“洋松茸”只是“来自西方的松茸”的意思，与松茸无关。它是生活在已腐解较多的有机物堆里的腐生菌，所以不是给它灭过菌的培养料，而是吃微生物先煮熟的培养料。因此堆肥发酵占栽培的七成。

| 特征 | 内容 |
|:---|:---|
| 菌盖 | 直径3-10cm，半球形渐展为扁平。白色、奶油色或褐色。光滑，不黏 |
| 菌褶 | 起初淡粉色，渐变褐色、黑褐色。孢子为褐色至巧克力褐色 |
| 菌柄 | 短而粗（长3-7cm）。有菌环，基部没有菌托 |
| 菌肉 | 白色，切开后慢慢由淡粉色变褐色。有蘑菇香 |

| 阶段 | 期间与温度 | 要点 |
|:---|:---|:---|
| 堆肥一次发酵（室外） | 2-3周，堆内55-70℃ | 每2-3天翻一次 |
| 堆肥二次发酵（室内） | 5-7天，先60℃控温再45-55℃ | 氨味消失 |
| 接种与菌丝培养 | 2-3周，23-25℃ | 整堆堆肥变白 |
| 覆土 | 2-3cm | 不覆土就不出菇 |
| 原基形成、生长 | 覆土后10-15天（18-22℃），再5-7天（16-18℃） | 白色小粒膨大成纽扣菇 |
| 收获 | 上床后40-60天 | 每隔1-2周，最多3茬 |

| 每100g营养 | 含量 |
|:---|:---|
| 热量 / 蛋白质 | 15kcal / 3.12g（占热量的83.2%，为这一类中最高） |
| 其他 | 水分约90g，钾212-384mg，B族维生素。维生素D经日晒干燥后大幅增加 |

## 3. 培养料（堆肥）与栽培室
| 类别 | 常规配方 | 灾害时替代 |
|:---|:---|:---|
| 碳源 | 稻草、麦草、大麦草80% | 干草、玉米秆、芦苇、稻壳、废纸 |
| 氮源 | 鸡粪、尿素、米糠 | 马粪（传统氮源）、牛粪、猪粪、陈放的尿液、豆荚、油饼 |
| 矿物质 | 石膏（硫酸钙） | 烧过并磨碎的贝壳、蛋壳粉、草木灰 |

&nbsp;&nbsp;&nbsp;每100kg稻草配鸡粪10-15kg（马粪则30-50kg）、米糠5kg、尿素400-500g（尿液则10-15L）、石膏3-5kg，使起始碳氮比为28-32比1（只用草的话在70比1以上，所以要补氮）。

| 发酵 | 方法 |
|:---|:---|
| 一次发酵 | 预堆时给稻草浇入总水量70%以上使其变软，主堆时把氮源和石膏与稻草层层堆成龟背形（高1.5-1.8m，宽1.5-2m）。每隔2-3天翻堆5-8次，里外对调。堆内55-70℃，水分以攥一把有几滴水滴下为准。氨味在这一阶段是正常的，阴沟味是厌氧腐败，翻堆时有白色放线菌粉末飘起是好迹象 |
| 二次发酵 | 每㎡上床50-60kg，先60℃控温6小时（55℃12小时、50℃24小时也可替代），再45-55℃保持5-7天。没有电时，把热堆肥以25-30cm的厚度装进小房间或窑洞，用草袋或草席盖住，或在晴天盖塑料膜，或烧热火炕地面 |
| 完成判定 | 完全没有氨味，堆肥表面和内部被白色放线菌覆盖，呈深褐色至巧克力色，水分68-72%，pH 6.8-7.2 |

> **还有氨味时绝对不要接种。菌种会当场死掉。要加强通风，再多发酵几天。**

&nbsp;&nbsp;&nbsp;栽培室是能保持16-25℃的封闭空间，窑洞、地窖、朝北的仓库、半地下窖、土墙棚屋都很合适。菌床宽1-1.2m，堆肥厚20-30cm，用圆木、木板、竹子搭成2-4层（地面1㎡得到菌床3㎡），上下各开通风口。不需要光。

| 覆土 | 标准 |
|:---|:---|
| 材料 | 腐叶土 + 沙 + 石灰，或稻田土 + 稻壳 + 贝壳粉。pH 7.5以上（绿霉喜欢弱酸性），保持松散 |
| 灭菌 | 在60℃以上蒸几个小时再用，或在铁板上炒（干泡病和菇蝇随土进入） |

## 4. 菌种获取与接种
| 方法 | 内容 |
|:---|:---|
| 市售菌种 | 平时最容易，所以提前备好 |
| 组织培养 | 把菌盖即将打开的新鲜纽扣菇用手纵向掰开（用刀会把表面杂菌带进里面），取菌盖与菌柄相接处内侧的白色菌肉，撕成米粒大小，夹进煮过放凉的稻草或堆肥里，在23-25℃的暗处培养。3-5天白色菌丝蔓延。最可靠的方法 |
| 菌床移植 | 菌丝长满整堆堆肥后、覆土前，把白色菌丝致密且无杂菌痕迹的部分挖成拳头大小，按新堆肥重量的3-5%，以20-30cm间距埋入。超过四五代活力就会下降，要回到组织培养 |
| 孢子印 | 把完全展开的大个体菌盖，菌褶朝下放在铝箔上，扣上容器放24小时，会留下褐色至巧克力褐色的孢子粉。双孢菇每个担子上只有两个孢子，一粒也能成菇，但萌发率低，所以要多撒 |

&nbsp;&nbsp;&nbsp;孢子在阴凉处晾干，铝箔折叠后与充分炒过的盐或木炭一起装进自封袋，放在四季温度恒定、不见光的窑洞或地窖里，可存放5-10年以上（若以液体保存只有3-6个月）。第一年从最大最健康的个体上做20-30张存起来。

| 接种 | 标准 |
|:---|:---|
| 条件 | 堆肥降到25℃以下，没有氨味，水分68-72%。可以徒手拌入，没有无菌室就取推荐量的上限偏多一些 |
| 方法 | 每3.3㎡（堆肥125kg）用菌种1.5-3.6kg，掰成米粒大小，均匀拌入堆肥上部10-15cm的一层，抹平表面，用湿布或草袋盖住 |

## 5. 菌丝培养、催菇与收获
| 阶段 | 管理 |
|:---|:---|
| 菌丝培养（2-3周） | 接种后1-5天25-27℃，6-7天后降到20℃。菌丝代谢热会使堆肥内部更热，所以堆肥内部不要超过30℃（34℃菌丝就死）。不直接往堆肥上浇水，覆盖物干了只喷覆盖物。每天短暂通风一两次 |
| 覆土 | 菌丝长到堆肥底部后（接种后2-3周）盖2-3cm，浇透 |
| 催菇 | 把温度降到16-18℃，打开此前一直关着的通风口排出二氧化碳，蘑菇就会形成（菌丝喜欢二氧化碳，子实体不喜欢）。空气湿度85-95%，12℃以下不形成原基 |
| 水分管理 | 原基形成期减少或停止浇水，长到豆粒大后少量多次，以覆土不干为度。收获前2-3天不浇 |

&nbsp;&nbsp;&nbsp;没有电要做到16-18℃，就用窑洞、地窖、半地下窖，盛夏和严冬不种，春季（3月下旬至5月）和秋季（9-11月）各种一茬。

| 收获 | 标准 |
|:---|:---|
| 时期 | 菌盖直径2-4cm，菌盖圆圆地合拢、菌盖与菌柄之间的白膜还没破的纽扣阶段，清晨采收。晚采的也可以用 |
| 要领 | 握住菌盖轻轻一拧，连根部整个拔出，拔后的坑要填平。不洗 |
| 周期 | 每茬3-5天成簇长出，间隔7-14天。第二茬为第一茬的50-70%，第三茬为20-30%。每㎡堆肥50-60kg共得10-20kg |

> **作为收获适期的白色纽扣阶段，正是外观最像致命鹅膏幼体的时期。务必读第7节，只采自己做的菌床上长出来的。**

## 6. 污染、病虫害与异常诊断
| 问题 | 症状与原因 | 应对 |
|:---|:---|:---|
| 绿霉 | 起初白色，很快变蓝绿色。每天10-30mm，比双孢菇菌丝（3-5mm）快3-6倍。看到颜色时培养料已大半损失，所以早期靠速度和质地判断 | 挖掉该区块。把二次发酵做好，并多放菌种 |
| 干泡病 | 蘑菇变成被压坏的白色团块而畸形。覆土没有灭菌时 | 清除病菇及周围的土，撒盐或灰。覆土一定要蒸 |
| 褐斑病、细菌性软腐病、蛛网病 | 菌盖上褐色凹陷斑、变软并发臭、白色蛛网状霉。过湿和通风不足 | 减少浇水、加强通风、清除病菇 |
| 菇蝇 | 吃菌丝，生蛆。携带霉菌孢子和干泡病 | 通风口罩两层细布，门口挂湿布帘。5月起激增。水盆、粘板、灯光诱捕 |
| 螨、线虫、蛞蝓、老鼠 | 菌丝变褐、堆肥发黑湿透、幼菇被啃、菌床被翻乱 | 覆土要蒸、确保60℃控温、撒一圈灰或锯末、菌床罩网 |

| 症状 | 原因与处理 |
|:---|:---|
| 接种一周后仍不见菌丝 | 堆肥有氨残留，或趁热接种。再发酵 |
| 菌丝长一阵就停 | 堆肥温度超过30℃或缺水。把室内降到20℃ |
| 菌丝很好但不出菇 | 没覆土、通风不足、温度偏高 |
| 柄长盖小 | 二氧化碳过多。通风 |
| 菌盖立刻张开且薄 | 温度22℃以上。移到更凉的地方 |
| 原基形成后干枯或变软死亡 | 湿度不足，或浇水太猛 |

&nbsp;&nbsp;&nbsp;采完蘑菇剩下的废堆肥，可用作田里的基肥、覆盖物、育苗土、蚯蚓的饲养基质、改良酸性土壤。被绿霉或干泡病污染的堆肥不要施进田里，要烧掉或运到远处深埋（孢子明年会回来）。由于堆内发热与制备培养料是同一个过程，所以即使没采到蘑菇，堆肥也还在。菌床框每茬结束后清空、洗净并晒干，每2-3年在墙和地面刷一次石硫合剂或浓草木灰碱液。

## 7. 毒菇误认与安全确认
> **这一节直接关系到生命。双孢菇是因与致命毒菇混淆而致死报告最多的蘑菇。比起种植，确认能不能吃更重要。**

&nbsp;&nbsp;&nbsp;长在土里、在白色纽扣阶段采收、菌柄上有菌环，这三个条件与白毒鹅膏和鳞柄白鹅膏（鹅膏毒肽，致命）的幼体重合。即使是自己种的菇，覆土里也可能混进野生孢子，长出别的蘑菇。

| 类别 | 双孢菇 | 白毒鹅膏·鳞柄白鹅膏（致命） |
|:---|:---|:---|
| 柄基 | 没有菌托 | 有膜质的菌托包住基部 |
| 菌褶颜色 | 淡粉色到褐色、黑褐色 | 从头到尾纯白 |
| 孢子颜色 | 褐色至巧克力褐色 | 白色 |
| 菌柄 | 短而粗（3-7cm） | 长而细（9-20cm）。鳞柄白鹅膏有白色纤维状鳞片 |
| 菌肉变色 | 切开后先带粉色再变褐 | 不变色，仍是白色 |
| 生长基质 | 发酵堆肥和覆土，成簇长在菌床上 | 活树根附近的地面，在林中单个生长 |
| 菌环 | 有 | 有（无法区分） |

> **区分双孢菇与白毒鹅膏的是基部的菌托。只看露出地面的部分，菌托埋在土里看不见，所以要连土把基部挖出来检查。把一个纽扣菇纵向掰开，菌褶是淡粉色就是双孢菇，一直是纯白就不要吃。把菌盖扣在白纸上，罩上杯子放几个小时，如果掉下的粉是白色，绝对不要吃。**

| 易混对象 | 区分点 |
|:---|:---|
| 黄斑蘑菇类（肠胃毒） | 切开或揉搓后变成鲜黄色，有墨水或药品般的难闻气味（加热后更强）。长在草地和路边。不致命，但会严重呕吐腹泻 |
| 鹅膏幼菌（卵期） | 白色卵形，与双孢菇纽扣菇最像。纵向掰开，里面有折叠的蘑菇形状，外皮下有黏滑的凝胶层，就是鹅膏 |
| 马勃类 | 掰开后内部均匀洁白如棉絮，没有菌褶 |
| 鬼伞类 | 过一段时间菌盖会黑化融化。与酒同食会中毒 |

&nbsp;&nbsp;&nbsp;吃后6-24小时才开始呕吐腹泻，是鹅膏毒肽中毒的典型经过，开始得越晚越危重。第一次吃时要走完所有确认步骤，充分煮熟，由一个人只吃一小块并等待24小时，并另外留下一个所吃蘑菇的个体。最安全的办法不是到野外去找，而是在自己做的菌床上种。

## 8. 储存、烹调与全年日程
| 储存 | 内容 |
|:---|:---|
| 鲜品 | 洗了、塑料密封或堆压都会坏。不洗，用纸包好，放在12-15℃的窑洞里5-7天 |
| 干燥 | 切成4-6mm，菌褶朝上摊在帘子上，晴天晒1-2天（菌褶里的麦角固醇受紫外线照射，维生素D大幅增加）。雨天在火边40-50℃烘半天。用手掰时啪地折断即完成，放凉后与木炭或炒盐一起密封，放在阴凉黑暗处1年以上（磨粉则2年以上） |
| 其他 | 盐渍（盐20%，6个月至1年）、酱腌、3%盐水乳酸发酵、油浸（1-3个月）。蘑菇粉能给汤增鲜，掺进谷物粉里补充蛋白质和维生素D |

&nbsp;&nbsp;&nbsp;双孢菇是这一类中唯一可以生吃的（限自己种的），但一般还是煮熟吃。烤和炒5-8分钟，汤10分钟以内，焯水2-3分钟。干品用温水泡20-30分钟，泡的水里溶有鲜味和水溶性营养，避开沉沙取上层当汤用。蘑菇不是热量来源，而是蛋白质和维生素D的补充来源，所以正确的用法是用谷物或薯类补足热量，并与油一起吃。

| 月份 | 作业 |
|:---|:---|
| 1-2月 | 收集稻草和粪、烧并磨碎贝壳和蛋壳、修菌床框，2月开始春茬的一次发酵 |
| 3-4月 | 二次发酵与接种（确认氨味后）、菌丝培养、覆土与出菇（16-18℃）、月底首次收获 |
| 5-6月 | 收获高峰与立即晒干、检查防虫网、废堆肥施进田里，洗净菌床和栽培室 |
| 7-8月 | 太热不种（有窑洞则继续）、8月开始秋茬的一次发酵 |
| 9-11月 | 二次发酵与接种、覆土与出菇、11月收获高峰（品质最好的时期）与大量晒干 |
| 12月 | 整理废堆肥、检查孢子印和干蘑菇的状态 |
