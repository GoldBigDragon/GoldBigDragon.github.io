## 10. 생육 이상 진단

| 증상 | 원인 | 조치 |
|:---|:---|:---|
| 접종 1주가 지나도 균사가 안 보임 | **퇴비에 암모니아가 남았음**, 퇴비가 뜨거울 때 접종함 | 후발효를 더 하거나 다시 뒤집어 공기를 넣습니다. 암모니아 냄새를 반드시 확인합니다 |
| 균사가 뻗다 멈춤 | 퇴비 온도 30℃ 초과, 수분 부족 | 실내 온도를 20℃로 내리고 퇴비 표면을 긁어 열을 뺍니다 |
| 균사는 좋은데 버섯이 안 남 | 복토를 안 했음, 환기 부족, 온도가 높음 | 복토하고 환기구를 열어 이산화탄소를 뺀 뒤 16-18℃로 내립니다 |
| 복토 표면에 흰 막이 두껍게 덮임 | 균사가 지나치게 왕성함. 습도와 이산화탄소 과다 | 갈퀴로 살짝 긁어 균사를 끊고 환기를 늘립니다 |
| 원기가 맺혔다 말라 죽음 | 습도 부족, 복토가 마름 | 안개처럼 물을 뿌려 85-95%로 올립니다 |
| 원기가 맺혔다 물러 죽음 | 물을 너무 많이, 세게 줌 | 물을 줄이고 환기합니다 |
| 대가 길고 갓이 작음 | **이산화탄소 과다.** 환기 부족 | 환기구를 열고 공기를 바꿉니다 |
| 갓이 바로 펴지고 얇음 | 온도가 22℃ 이상 | 더 서늘한 곳으로 옮깁니다 |
| 갓 표면이 거칠게 갈라짐 | 공기가 너무 건조함 | 바닥과 벽에 물을 뿌려 습도를 올립니다 |
| 갓에 갈색 오목한 반점 | 세균성 갈색무늬병. 갓에 물방울이 남음 | 물을 줄이고 환기해 갓을 말립니다 |
| 버섯이 뭉개진 흰 덩어리로 기형 | **마른버섯병.** 복토 흙에서 들어옴 | 병든 개체와 둘레 흙을 걷어 내고 다음 주기에 복토를 반드시 찝니다 |
| 버섯 대에 구더기 | 버섯파리 | 환기구와 출입구를 막습니다. 피해 개체는 치웁니다 |
| 갓이 노랗게 변색 | 과숙, 온도 과다 | 제때 수확합니다 |
| 2주기 수량이 거의 없음 | 퇴비 양분 소진 | 정상입니다. 퇴비를 바꿉니다 |

## 11. 폐배지 순환

### 11-1. 폐퇴비는 버리는 것이 아닙니다

&nbsp;&nbsp;&nbsp;버섯이 다 나온 뒤의 퇴비는 이미 두 번 발효되고 균사가 한 번 더 분해한 유기물입니다. 이 문서가 다루는 여섯 종 가운데 **폐배지가 가장 좋은 거름이 되는 것이 양송이입니다.** 톱밥 폐배지는 목질이 남아 있어 밭에 넣으면 질소를 빼앗지만, 양송이 폐퇴비는 탄질비가 이미 낮아 그대로 넣을 수 있습니다.

| 용도 | 방법 |
|:---|:---|
| **밑거름** | 밭에 펴서 갈아 넣습니다. 질소, 인, 칼륨, 칼슘이 골고루 들어 있습니다 |
| **멀칭재** | 작물 사이에 5cm 두께로 깔아 잡초와 수분 증발을 막습니다 |
| **복토 재료** | 체로 쳐서 다음 주기의 복토에 섞습니다. 반드시 다시 쪄서 씁니다 |
| **다른 버섯 배지** | 독청버섯아재비의 목재칩 배지에 섞으면 질소원이 됩니다 |
| **모판 흙** | 모래와 섞으면 육묘용 상토가 됩니다 |
| **지렁이 사육 기질** | 지렁이가 가장 좋아하는 기질입니다. 분변토를 얻습니다 |
| **산성 토양 개량** | 석고와 석회가 들어 있어 산성 흙의 산도를 올립니다 |

```
볏짚 + 분뇨 + 패각 → 발효 퇴비 → 버섯 수확 → 폐퇴비 → 밭 거름
                                                   └ 지렁이 → 분변토
```

> **양송이 재배는 사실상 퇴비 만들기와 같은 과정입니다. 그 중간에 버섯을 한 번 거두어 가는 것뿐입니다. 버섯을 얻지 못해도 퇴비는 남습니다. 이것이 다른 버섯에는 없는 안전판입니다.**

&nbsp;&nbsp;&nbsp;이 관점이 재난 상황에서 중요합니다. 다른 버섯은 실패하면 톱밥과 장작을 헛되이 쓴 것이 됩니다. 양송이는 실패해도 밭에 넣을 퇴비가 남습니다. 투입이 완전히 사라지지 않는다는 점에서 위험이 가장 낮은 버섯 농사입니다.

### 11-2. 폐퇴비를 다시 쓸 때의 주의

| 상황 | 판단 |
|:---|:---|
| 정상적으로 수확을 마친 퇴비 | 그대로 밭에 넣습니다 |
| **푸른곰팡이에 오염된 퇴비** | **밭에 넣지 않습니다.** 태우거나 재배지에서 멀리 떨어진 곳에 깊이 묻습니다 |
| **마른버섯병이 났던 퇴비와 복토** | 같습니다. 포자가 흙에서 몇 해를 버팁니다 |
| 버섯파리가 들끓던 퇴비 | 한 번 더 쌓아 발열시켜 알을 죽인 뒤 씁니다 |

> **오염된 배지를 퇴비로 돌리지 마십시오.** 푸른곰팡이와 마른버섯병 포자는 퇴비 더미에서 살아남아 이듬해 배지로 다시 들어옵니다.

### 11-3. 재배 공간의 연차 관리

| 연차 | 관리 |
|:--:|:---|
| 주기마다 | 균상 목틀을 비우고 물로 씻어 햇볕에 말립니다 |
| 1년 | 같은 재배사를 계속 써도 괜찮습니다 |
| 2-3년 | 벽과 바닥에 석회 유황물이나 진한 나무재 잿물을 바릅니다 |
| 문제가 쌓이면 | 재배사를 한 계절 비워 두고 문을 열어 햇빛과 바람을 들입니다 |

&nbsp;&nbsp;&nbsp;목틀은 나무라서 병원균이 스며듭니다. 주기가 끝나면 물로 씻고, 가능하면 뜨거운 물을 끼얹거나 겉을 불로 그슬립니다. 대나무나 판자를 쓴다면 몇 해마다 바꾸는 편이 낫습니다.

## 12. 독버섯 오인과 안전 확인

> **이 절은 생명과 직결됩니다. 기르는 것보다 먹어도 되는지 확인하는 것이 더 중요합니다.**

&nbsp;&nbsp;&nbsp;양송이버섯은 이 문서가 다루는 여섯 종 가운데 **치명적 독버섯과의 오인으로 실제 사망 사고가 가장 많이 보고된 버섯입니다.** 국내외에서 되풀이됩니다. 이유는 세 가지가 겹치기 때문입니다.

| 겹치는 조건 | 내용 |
|:---|:---|
| **흙에서 납니다** | 양송이는 복토 흙을 뚫고 나오고, 광대버섯류도 땅에서 납니다 |
| **흰 버튼 단계에서 땁니다** | 수확 적기가 갓이 오므려진 흰 알 모양이고, 광대버섯의 어린 개체도 흰 알 모양입니다 |
| **턱받이가 있습니다** | 양송이도 광대버섯도 대에 흰 막 고리를 가집니다 |

> **양송이와 흰알광대버섯을 가르는 것은 단 하나, 밑동의 대주머니입니다. 이것을 확인하지 않으면 언젠가 잘못 먹습니다.**

### 12-1. 양송이의 확인 형질

&nbsp;&nbsp;&nbsp;기른 버섯이라도 복토 흙에 야생 포자가 섞여 들어와 다른 버섯이 함께 돋을 수 있습니다. **균상에서 났다는 사실만으로 안전하다고 보면 안 됩니다.** 아래 형질을 하나하나 확인합니다.

| 부위 | 양송이버섯 |
|:---|:---|
| 갓 | 지름 3-10cm. 반구형에서 편평형으로 펴집니다. 흰색, 크림색, 갈색 |
| 갓 표면 | 매끈하거나 미세한 섬유무늬. 점액질이 없습니다 |
| **주름** | **처음 연분홍색 → 자라면서 갈색 → 흑갈색으로 진해짐** |
| **포자 색** | **갈색-초콜릿 갈색.** 흰 종이에 갓을 얹어 받으면 바로 확인됩니다 |
| 대 | 짧고 굵습니다. 길이 3-7cm, 굵기 1-2cm |
| **대의 턱받이** | **있습니다.** 어릴 때 갓을 덮던 흰 막이 찢어져 대에 남습니다 |
| **대의 밑동** | **주머니(대주머니)가 없습니다.** 밑동이 그냥 퇴비에 묻혀 있습니다 |
| 살 | 흰색. 자르면 **연한 분홍빛에서 갈색**으로 서서히 변합니다 |
| 냄새 | 버섯 향. 불쾌한 냄새가 없습니다 |
| 발생 기질 | 발효 퇴비와 복토의 경계 |

> **주름을 확인하려면 한 개를 쪼개 보아야 합니다.** 버튼 단계에서는 주름이 갓 안에 숨어 있어 보이지 않습니다. 쪼갠 면의 주름이 연분홍색이면 양송이이고, 끝까지 순백색이면 광대버섯을 의심합니다. 이 한 동작이 생사를 가릅니다.

### 12-2. 흰알광대버섯과 독우산광대버섯 - 대주머니가 갈림길입니다

&nbsp;&nbsp;&nbsp;흰알광대버섯(Amanita verna)과 독우산광대버섯(Amanita virosa)은 아마톡신을 가진 치명적 독버섯입니다. 한 개체분으로 사람이 죽습니다. 해독약이 없고, 의료 지원이 없는 상황에서는 거의 확실히 사망합니다.

| 구분 | **양송이버섯** | **흰알광대버섯·독우산광대버섯(치명적)** |
|:---|:---|:---|
| **대 밑동** | **주머니가 없습니다** | **막으로 된 주머니(대주머니)가 밑동을 감쌉니다** |
| **주름 색** | **연분홍 → 갈색 → 흑갈색** | **처음부터 끝까지 순백색** |
| **포자 색** | **갈색-초콜릿 갈색** | **흰색** |
| 갓 색 | 흰색, 크림색, 갈색 | 순백색. 독우산광대버섯은 중앙이 약간 누렇습니다 |
| 대 | 짧고 굵음. 3-7cm | **길고 가늚. 9-20cm** |
| 대 표면 | 매끈함 | **독우산광대버섯은 흰 섬유 비늘로 거칩니다** |
| 턱받이 | 있음 | 있음. **구별되지 않습니다** |
| 살 색 변화 | 자르면 분홍빛에서 갈색 | 변하지 않고 흰색 그대로 |
| 냄새 | 버섯 향 | 오래된 개체는 역한 냄새 |
| 발생 기질 | 발효 퇴비와 복토 | **살아 있는 나무 뿌리 근처의 땅** |
| 발생 습성 | 균상에 무리로 | 숲속에 하나씩 또는 몇 개가 흩어져 |

> **밑동을 흙째 파내어 확인하는 습관을 들이십시오.**
> 대주머니 확인은 반드시 파서 해야 합니다. 땅 위로 나온 부분만 보면 주머니가 흙에 묻혀 보이지 않습니다. 양송이는 흙 위로 나온 부분을 잘라 따기 쉬운 버섯이라 이 습관이 특히 중요합니다. 8절에서 밑동까지 통째로 뽑으라고 한 이유가 이것입니다.

> **흰 종이에 갓을 엎어 얹고 컵을 씌워 몇 시간 두었을 때, 떨어진 가루가 하얗다면 절대 먹지 마십시오.**
> 양송이의 포자는 갈색에서 초콜릿 갈색입니다. 포자가 흰색이고 주름이 끝까지 흰색이며 대 밑동에 주머니가 있다면, 그 셋 중 하나라도 해당하면 먹지 않습니다.

&nbsp;&nbsp;&nbsp;아마톡신 중독의 경과를 알아 두어야 합니다. 먹고 6-24시간 동안은 아무 증상이 없습니다. 그 뒤 격심한 구토와 설사와 복통이 시작되어 하루쯤 이어집니다. 그다음 증상이 가라앉아 회복된 것처럼 보이는 시기가 이틀에서 사흘 있고, 바로 그 기간에 간이 파괴되고 있습니다. 이어 황달과 출혈과 의식 저하가 나타나면 이미 손쓰기 어렵습니다.

> **증상이 6시간 이상 지나 나타나는 중독이 가장 위험합니다.** 먹고 30분에서 2시간 안에 배가 아픈 것은 대개 위장 자극이지만, 6-24시간 뒤에 구토와 설사가 시작되는 것은 아마톡신 중독의 전형적인 경과입니다. 늦게 시작될수록 위중합니다.

### 12-3. 같은 주름버섯속의 독버섯 - 상처가 노랗게 변하는 것

&nbsp;&nbsp;&nbsp;양송이와 같은 주름버섯속(Agaricus)에도 먹으면 안 되는 종이 있습니다. 노란색으로 변색하는 무리입니다. 국내에서는 노란대주름버섯(Agaricus xanthodermus) 계열로 불립니다.

| 구분 | **양송이버섯** | **노란대주름버섯류(위장 독성)** |
|:---|:---|:---|
| **상처 변색** | 자르면 **연한 분홍빛에서 갈색** | **자르거나 문지르면 선명한 노란색으로 변합니다.** 특히 밑동 |
| **냄새** | 버섯 향 | **잉크나 석탄산, 약품 같은 역한 냄새.** 익히면 더 강해집니다 |
| 포자 색 | 갈색-초콜릿 갈색 | 갈색. 구별되지 않습니다 |
| 주름 색 | 연분홍 → 갈색 | 흰색 → 분홍 → 갈색. 비슷합니다 |
| 발생 기질 | 발효 퇴비와 복토 | 풀밭, 정원, 길가의 땅 |

> **밑동을 문질렀을 때 노랗게 변하고 약품 냄새가 나면 먹지 않습니다.** 죽지는 않으나 심한 구토와 설사가 옵니다. 의료 지원이 없는 상황에서 탈수는 그 자체로 위험합니다.

### 12-4. 그 밖의 혼동 대상

| 버섯 | 구분점 |
|:---|:---|
| **주름버섯(야생 식용종)** | 양송이의 야생 근연종으로 식용입니다. 풀밭에 납니다. 다만 광대버섯과의 구별이 필요하므로 같은 확인 절차를 밟습니다 |
| **흰가시광대버섯** | 갓에 흰 가시 같은 돌기가 있고 대주머니가 있습니다 |
| **독우산광대버섯 유균(알 단계)** | **흰 알 모양으로 양송이 버튼과 가장 비슷합니다.** 쪼개면 안에 버섯 모양이 들어 있고 겉껍질과 속 사이에 젤리층이 있습니다 |
| **말불버섯류** | 쪼개면 안이 고르게 흰색 솜 같습니다. 주름이 없습니다. 어린 것은 식용이나 속에 버섯 모양이 보이면 광대버섯입니다 |
| **먹물버섯류** | 갓이 시간이 지나면 검게 녹아내립니다. 술과 함께 먹으면 중독됩니다 |

> **흰 알 모양의 버섯을 발견하면 반드시 세로로 쪼개 봅니다.** 안이 고르게 흰 솜 같으면 말불버섯, 안에 접힌 버섯 모양이 들어 있으면 광대버섯의 유균입니다. 광대버섯 유균은 겉껍질 아래에 반투명한 젤리층이 있어 만지면 미끈합니다.

### 12-5. 처음 먹을 때의 원칙

&nbsp;&nbsp;&nbsp;의료 지원이 없는 상황에서는 확인 절차 자체가 방어 수단입니다.

| 순서 | 내용 |
|:--:|:---|
| 1 | **밑동을 흙째 파내어 주머니가 없는지 확인합니다.** 주머니가 있으면 버립니다 |
| 2 | **한 개를 세로로 쪼개 주름 색을 봅니다.** 연분홍이면 양송이, 끝까지 순백이면 버립니다 |
| 3 | **자른 면이 노랗게 변하는지 봅니다.** 노랗게 변하고 약품 냄새가 나면 버립니다 |
| 4 | **포자를 받아 색을 확인합니다.** 흰색이면 버립니다 |
| 5 | **반드시 충분히 익힙니다.** 생식이 가능한 버섯이지만 야생 개체는 익힙니다 |
| 6 | 처음에는 **한 사람만, 소량(한 조각)** 먹고 24시간 기다립니다 |
| 7 | 이상이 없으면 양을 늘립니다. 여러 사람이 동시에 먹지 않습니다 |
| 8 | 먹은 버섯 한 개체를 **따로 남겨 둡니다.** 중독 시 확인에 쓸 수 있습니다 |

> **재난 상황에서 양송이를 먹는 가장 안전한 방법은 야생에서 찾는 것이 아니라 기르는 것입니다. 내가 퇴비를 만들고 종균을 넣은 균상에서 난 것이라면 판별 문제가 거의 발생하지 않습니다. 그래도 밑동을 파서 확인하는 동작은 습관으로 남겨 두십시오.**
