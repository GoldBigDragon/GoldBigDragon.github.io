## 5. 接種方法

&nbsp;&nbsp;&nbsp;マッシュルームの接種は、ほかのキノコより単純です。堆肥に種菌を混ぜれば終わりです。無菌室も、すばやい手さばきも必要ありません。後発酵を終えた堆肥がすでに選択的培地であり、マッシュルームの菌糸に有利に傾いているからです。

> **これがマッシュルーム栽培でもっとも過小評価されている利点です。エノキタケやヤマブシタケは無菌に近い条件下で10秒以内に接種を終えなければなりませんが、マッシュルームは素手で堆肥に種菌を混ぜても構いません。**

### 5-1. 接種条件

| 項目 | 基準 | 理由 |
|:---|:---|:---|
| 堆肥温度 | **25℃以下に冷ましてから** | それより熱いと種菌が死にます |
| アンモニア | **匂いがまったくないことが必要です** | 残っていると種菌が死にます |
| 堆肥水分 | 68-72% | 握って絞ると指の間に水がにじむ程度 |
| 堆肥酸度 | pH 6.8-7.2 | 中性 |
| 接種量 | **3.3㎡（1坪）堆肥125kgあたり種菌1.5kg** | 現場での推奨は2.7-3.6kg |
| 無菌室がないとき | **推奨量の上限である3.6kgのほうへ** | 先に場所を占めたほうが勝ちます |

&nbsp;&nbsp;&nbsp;接種量をたっぷり使うことが、無菌操作の不足を補うもっとも確実な方法です。1坪に1.5kgが最低ラインで、3.6kgが現場推奨の上限です。電力も無菌室もない状況では、上限のほうを選びます。種菌代を惜しんで量を減らすと、アオカビが先に場所を占め、全量を失うことになります。

### 5-2. 接種の手順

| 段階 | 方法 |
|:--:|:---|
| 1 | 堆肥が25℃以下に冷めたか、手を入れて確認します |
| 2 | アンモニア臭がないか、鼻を近づけて確認します |
| 3 | 種菌の塊を手で崩し、米粒大にします |
| 4 | 堆肥の表面に均一にまきます |
| 5 | 手や熊手で**堆肥の上部10-15cmの層に均一に混ぜ込みます** |
| 6 | 表面を均一にならし、軽く押さえます |
| 7 | **紙や濡れた布、むしろで覆って**水分を守ります |

&nbsp;&nbsp;&nbsp;堆肥全体に混ぜるのではなく、上の層だけに混ぜ込むのがこつです。菌糸は上から下へと伸びていき、キノコは上のほうにできます。下のほうまで種菌をまき散らすと、種菌を無駄にすることになります。

&nbsp;&nbsp;&nbsp;覆う材料は水分を守りつつ空気が通る必要があります。ビニールで完全に覆うと水滴がついて落ち、細菌が繁殖します。紙、濡れたむしろ、敷物、薄く敷いたわらがよいでしょう。

## 6. 菌糸培養管理

&nbsp;&nbsp;&nbsp;接種後2-3週間が培養期間です。目標は、白い菌糸が堆肥全体を掌握することです。この期間に人がすべきことは、温度を保ち、乾かさないようにする程度です。

### 6-1. 温度 - 代謝熱がもっとも大きな危険です

| 時期 | 室内温度 | 管理 |
|:---|:---:|:---|
| 接種後1-5日 | 25-27℃ | 菌糸の活着を促します。やや暖かめに |
| 6-7日以降 | **20℃に下げます** | 菌糸の代謝熱で堆肥の内部がさらに熱くなります |
| 危険な時期 | **適温より5-10℃低く** | 発熱で菌糸が焼け死ぬのを防ぎます |
| 堆肥温度の上限 | **30℃** | これを超えると菌糸が弱まり、34度で死にます |
| 期間 | 2-3週間 | 堆肥の量と温度によって異なります |

> **マッシュルーム培養でもっとも多い失敗は過熱です。菌糸が盛んに育っている間は自ら熱を出すため、室内温度が25℃でも堆肥の内部は30℃を超えることがあります。堆肥の奥深くまで手を入れて温かさを確かめる習慣をつける必要があります。**

&nbsp;&nbsp;&nbsp;対応は三つです。培養1週間後から室内温度を20℃に下げます。堆肥の厚さが30cmを超えないようにします。そして換気を少しずつ増やします。堆肥の内部が熱いと感じたら、表面を熊手で軽くかいて空気を入れます。

### 6-2. 湿度と換気

| 項目 | 基準 |
|:---|:---|
| 堆肥水分 | 68-72%を維持 |
| 空気湿度 | 85-90% |
| 水やり | 培養中は**できるだけ与えません。** 覆いが乾いたら覆いにだけ水をかけます |
| 換気 | 1日1-2回、短く。二酸化炭素が少したまるほうが菌糸によいです |
| 光 | 必要ありません。暗くても構いません |

&nbsp;&nbsp;&nbsp;培養中に堆肥へ直接水を与えてはいけません。菌糸は水に浸かると呼吸できずに死んでしまいます。水が必要なら、覆ってある紙やむしろにだけ水をかけ、水蒸気として伝えます。堆肥の水分は後発酵を終える時点で合わせておくものであり、培養中はそれを守るものです。

&nbsp;&nbsp;&nbsp;換気は菌糸培養の段階ではあまり行いません。マッシュルームの菌糸はある程度の二酸化炭素を好みます。子実体の段階とはまったく逆です。培養中は閉めておき、覆土のあとから換気を増やします。

### 6-3. 培養が順調に進んでいるかを見る方法

| 観察 | 正常 | 異常 |
|:---|:---|:---|
| 色 | 白い菌糸がわらを包みながら広がります | 青緑色、黒色、オレンジ色は汚染 |
| 質感 | 細い白い糸が、わらの表面に均一に | 粉のように舞うのは汚染胞子です |
| 匂い | ほのかなキノコの香り、カビ臭い土の匂い | **アンモニア臭が再び出るのは、後発酵が不十分だった証拠です** |
| 進行 | 1週間に5-7cm下方へ | 止まったら温度かアンモニアの問題 |
| 堆肥の締まり | 手で持ち上げると菌糸に絡まって塊で付いてきます | ばらばらに崩れるなら、まだ広がっていません |
| 温度 | 堆肥内部25-30℃ | 30℃を超えたら、ただちに冷やす必要があります |

&nbsp;&nbsp;&nbsp;培養の途中でアンモニア臭が再び出ることがあります。後発酵でアンモニアが完全に抜けきらなかったか、堆肥の中に窒素源の塊が固まっていた場合です。このときは堆肥を軽く切り返して空気を入れ、換気を増やします。ひどい場合は、その区画をあきらめたほうがよいでしょう。

### 6-4. 覆土

&nbsp;&nbsp;&nbsp;菌糸が堆肥全体に広がったら覆土します。マッシュルーム栽培では、この段階を経ずにはキノコが出ません。

| 項目 | 基準 |
|:---|:---|
| 時期 | 菌糸が堆肥の底まで達したあと。接種後2-3週間 |
| 判定 | 堆肥の表面と内部が均一に白く、持ち上げると塊で付いてきます |
| 材料 | 腐葉土と砂に石灰を混ぜてpH 7.5以上に |
| 厚さ | 2-3cm |
| 硬さ | ぽろぽろと。細かい土だけ使うと固まり、キノコが突き破れません |
| 灌水 | 覆土した直後にたっぷり湿らせます。何回かに分けてゆっくりと |
| その後の管理 | 温度18-22℃、湿度95% |

&nbsp;&nbsp;&nbsp;覆土のあとは菌糸が土の中に上がってきます。5-7日で覆土の表面に白い菌糸が透けて見え始めます。このとき土を熊手で軽くかいて菌糸を切る作業（菌糸かき、ラッフィング）を行うと、発生が均一になります。表面に白い菌糸の膜が厚く覆うと、かえってキノコが出なくなるため、膜ができる前にかくのがこつです。

## 7. 発生誘導

&nbsp;&nbsp;&nbsp;菌糸は快適な環境では伸び続けるだけです。キノコを結ぶことは、菌糸にとって危機の信号です。マッシュルームの場合、その信号は三つです。覆土、温度の低下、そして二酸化炭素の排出です。

### 7-1. 発生条件

| 項目 | 培養段階 | **発生段階** | 備考 |
|:---|:---:|:---:|:---|
| 温度 | 23-25℃ | **16-18℃** | 幅が狭いです。12℃を下回ると原基が結ばれません |
| 空気湿度 | 85-90% | **85-95%** | 発生初期は特に高めに |
| **二酸化炭素** | 高くても問題ない | **下げる必要があります** | **換気が決定的です** |
| 光 | 不要 | 不要 | 完全な暗闇でも出ます |
| 覆土 | - | 2-3cm | ないとキノコが出ません |

> **マッシュルームの発生誘導の要は換気です。覆土を終えて温度を16-18℃に下げたあと、それまで閉めておいた換気口を開けて二酸化炭素を抜くと、キノコが結ばれます。菌糸は二酸化炭素を好み、子実体は嫌うため、この転換がそのまま信号になります。**

&nbsp;&nbsp;&nbsp;中高温性の品種であれば、13-20℃まで幅が広がります。電力がない状況で温度を精密に合わせられないなら、このような品種を選ぶほうが有利です。

### 7-2. 電力なしで16-18℃を作る方法

| 手段 | 温度 | 確保する方法 | 限界 |
|:---|:---:|:---|:---|
| **土窟、洞窟** | 12-18℃ | 山の斜面を2m以上掘り込みます | 一年中使えてもっとも良いです |
| **春作型** | 自然 | 3月下旬から5月 | 6月になると暑くなります |
| **秋作型** | 自然 | 9月から11月 | 12月になると寒くなります |
| 地下室 | 12-18℃ | 既存の構造物を活用 | 湿度の確保が必要です |
| 半地下の穴倉 | 14-20℃ | 1m掘って土とわらで覆います | 夏には不十分です |
| 北向き土壁の納屋 | 季節変動 | 厚い土壁が温度変化を和らげます | 夏と冬には範囲を外れます |

> **電力がない状況では、マッシュルームは春秋の作物であるか、土窟の作物です。真夏と真冬には育てません。**

&nbsp;&nbsp;&nbsp;春秋の二回、作型を回すのが標準です。春作型は2月に堆肥を作って3月に接種し、4月末から収穫します。秋作型は8月に堆肥を作って9月に接種し、10月末から収穫します。堆肥発酵そのものはむしろ暑いほうが有利なため、発酵は夏か晩冬に行い、発生は涼しい季節に合わせる配置になります。

### 7-3. 水管理

| 時期 | 管理 |
|:---|:---|
| 覆土直後 | たっぷりと。何回かに分けてゆっくり染み込ませます |
| 原基形成期 | **水を減らすか止めます。** このとき水を多く与えると原基が腐れます |
| キノコが豆粒大になったあと | 再び少しずつ。覆土が乾かない程度に |
| 生育期 | 収穫の合間に少しずつ |
| 収穫直前2-3日 | **与えません。** 貯蔵性が上がります |

&nbsp;&nbsp;&nbsp;水のやり方が重要です。強くかけると覆土が固まって締まり、幼いキノコがつぶれます。じょうろで霧のようにかけるか、葉の広い木の枝で水を跳ね散らします。そして一度に多く与えず、何回かに分けて与えます。

### 7-4. 原基形成の確認

| 時期 | 何が見えるか |
|:---|:---|
| 覆土後5-7日 | 覆土の表面に白い菌糸が透けて見えます |
| 覆土後10-15日 | **覆土の下にアワ粒から小豆粒大の白い粒**ができます |
| その後5-7日 | 粒が膨らんで大豆粒から栗の実大になります |
| 収穫 | 傘が閉じたボタン段階 |

## 8. 収穫と再発生周期

### 8-1. 収穫時期の判断

| 基準 | 内容 |
|:---|:---|
| **最適** | **傘が丸く閉じており、被膜が破れる前のボタン段階** |
| 大きさ | 傘の直径2-4cm |
| 遅れた合図 | 傘と柄の間の白い被膜が破れ、ひだが見えます |
| 遅れると | 傘が開き、ひだが褐色に染まって食感が落ちます |
| 時間帯 | 早朝 |

&nbsp;&nbsp;&nbsp;遅く採ったものを捨てる理由はありません。傘が開いたものはポートベロと呼ばれ、肉が厚く、肉のような食感になります。焼き物に向いており、うま味がより強くなります。ただし貯蔵性が悪くなり、胞子を落とし始めるため、その日のうちに食べるほうがよいでしょう。そして傘が完全に開いてひだが濃い褐色になった個体は、4節の胞子採取にもっとも適しています。

> **収穫の適期である白いボタン段階は、致死的なテングタケの幼菌ともっとも見た目が似ている時期です。必ず12節を読み、自分が作った菌床から生えたものだけを採ってください。**

### 8-2. 収穫のこつ

&nbsp;&nbsp;&nbsp;傘を指で包むように持ち、軽くひねりながら引き抜きます。引っ張ると覆土がむしり取られ、そばにある幼菌の根が切れてしまいます。ひねって抜く動作が、周囲への被害をもっとも減らします。

&nbsp;&nbsp;&nbsp;抜いたあとの穴はそのままにしません。残った柄の基部と土の塊を手で取り除き、新しい覆土で埋めます。残った基部が腐ると、細菌やキノコバエを呼び寄せるからです。

&nbsp;&nbsp;&nbsp;そして採るときは**必ず基部まで丸ごと**抜き取ります。12節で見るように、つぼの有無は基部でしか確認できず、その確認が生死を分けます。土の上に出ている部分だけを切り取る習慣は危険です。

&nbsp;&nbsp;&nbsp;収穫したキノコは**洗いません。** マッシュルームは水を非常に嫌います。洗うと水分を含んで一日で褐色に変わります。土は乾いた布や柔らかいブラシで払い落とします。

### 8-3. 発生周期

| 項目 | 内容 |
|:---|:---|
| 初収穫 | 堆肥の床詰め後40-60日。覆土後10-15日 |
| 1回の発生期間 | 3-5日。一度にまとまって出ます |
| 発生間隔 | 7-14日 |
| 2周期目の収量 | 1周期目の50-70% |
| 3周期目の収量 | 1周期目の20-30% |
| 総収穫回数 | **最大3回** |
| 菌床の寿命 | 2-3周期、約2-3か月 |

&nbsp;&nbsp;&nbsp;マッシュルームは波のように出ます。三、四日かけて一度にまとまって出て、1-2週間休んでからまた出ます。休んでいる間にすべきことは、覆土を乾かさないようにし、抜いたあとを埋めることです。一度にたくさん出るため、まとめて乾燥させることができ、貯蔵に有利です。

&nbsp;&nbsp;&nbsp;評価表の永続性Cは、この表の内容そのものです。二、三周期収穫すると堆肥の養分が尽き、菌糸が老化します。そのときは堆肥を取り除き、新しい堆肥を入れます。堆肥発酵には2-3週間かかるため、**次の周期の堆肥をあらかじめ発酵させておくのがこつです。** 菌床で収穫している間に外で次の堆を切り返していれば、途切れることなく続けられます。

### 8-4. 収量

| 条件 | 収量 |
|:---|:---|
| ㎡あたり堆肥 | 50-60kg |
| ㎡あたり総収量 | 10-20kg（3周期合計） |
| 生物学的効率 | 堆肥乾物重量の20-35% |
| 熱量換算 | ㎡あたり1,500-3,000kcal（3周期合計） |

&nbsp;&nbsp;&nbsp;㎡あたり3周期を通じて10-20kgが採れます。100gあたり15kcalなので、熱量にすると1,500kcalから3,000kcal、つまり一人一日分あまりです。熱量で計画を立てるべき値ではありません。

&nbsp;&nbsp;&nbsp;タンパク質で見ると話が変わります。15kgならタンパク質470gです。一人が一日に必要とするタンパク質が50gから60gなので、十日近い量です。そして菌床を2段や3段に組めば、同じ床面積から二倍、三倍の収量が得られます。

> **マッシュルームの収量を評価するときは、床面積ではなく菌床面積で計算する必要があります。棚を3段に組めば、床1㎡から菌床3㎡が得られます。土窟や地下室のような狭い空間では、この構造が大きな違いを生みます。**

## 9. 汚染と病害虫

### 9-1. 青カビと競合菌

&nbsp;&nbsp;&nbsp;災害状況でのキノコ栽培が失敗する最も多い原因は、病害虫ではなく競合するカビに培地を奪われることです。マッシュルームは堆肥発酵によって選択的培地を作っておくため他の種より有利ですが、発酵が不十分だとこの防御線が崩れます。

| 区分 | マッシュルームの菌糸 | 青カビ |
|:---|:---|:---|
| 色 | 白色、堆肥のわらを包む糸状 | 最初は白色、すぐに**青緑色** |
| 質感 | 細い白い糸が均一に広がります | 粉のように微細でぱさぱさしています |
| 広がる速度 | 一日3-5mm | 一日10-30mm、**3-6倍速い** |
| におい | 土のにおい、キノコの香り | かび臭いにおい、時にココナッツに似た香り |
| 境界 | 堆肥に沿って均一に | 丸い斑点から放射状に |

> **青カビは色が見える前にすでに広がっています。**
> 青緑色は胞子ができた段階、つまり繁殖を始めた後です。その時点ではすでに培地のかなりの部分を失ったと見るべきです。初期の判別は色ではなく、広がる速度と質感で行います。

### 9-2. マッシュルームに特に多い病気

| 病気 | 症状 | 原因 | 対処 |
|:---|:---|:---|:---|
| **乾腐病（マイコゴネ）** | キノコが潰れた白い塊になって奇形になり、褐色の水がにじみます | **覆土を殺菌しなかったとき** | 病気の個体と周りの土を取り除き、塩や灰をまきます |
| **青カビ病** | 堆肥と覆土が青緑色に変わります | 後発酵不十分、衛生不良 | 該当区画を取り除きます |
| **褐色斑点病（細菌性斑点）** | 傘に褐色のくぼんだ斑点ができます | 傘に水滴が長く残っていたとき | 水を減らし通風を増やします |
| **細菌性軟腐病** | 子実体が柔らかくなり悪臭がします | 過湿、排水不良 | 水を止め病気のものを片付けます |
| **クモの巣病** | 白いクモの巣のようなカビがキノコを包みます | 湿度が高すぎて通風不足 | 通風を増やし塩をまきます |

&nbsp;&nbsp;&nbsp;乾腐病はマッシュルーム特有の病気です。覆土の土から入るため、3節の覆土殺菌を省くとほぼ必ず現れます。人の手や道具でも移るので、病気の場所を触った手で健全な場所を触らないようにし、取り除いた土は遠くへ運び出します。

### 9-3. 汚染を防ぐ六つのこと

| 方法 | 原理 |
|:---|:---|
| **一次発酵と二次発酵をきちんと行います** | 60℃のピーク熱処理が病原菌を殺し、後発酵が雑菌の餌をなくします |
| **覆土は必ず蒸してから使います** | 乾腐病とキノコバエが土から入ります |
| **覆土のpHを7.5以上に上げます** | 青カビは弱酸性を好みます |
| **種菌を十分に入れます** | 先に場所を占めたほうが勝ちます |
| **水を強く、多く与えません** | 傘に水滴が残ると細菌病が来ます |
| **収穫した跡はその都度埋め戻します** | 腐る根元が細菌とキノコバエを呼び寄せます |

### 9-4. 害虫 - キノコバエが第一です

| 害虫 | 被害 | 対処 |
|:---|:---|:---|
| **キノコバエ（シアリド、ホリド）** | 菌糸を食い荒らし、子実体にウジが入ります。青カビの胞子と乾腐病を運びます | **出入口と通風口に目の細かい布や防虫網をかぶせて物理的に防ぎます。**発生時は水皿トラップ、粘着シート、灯火トラップ |
| **ダニ** | 菌糸が褐色に変わり育たなくなります。人の肌がかゆくなります | 覆土を蒸してから使います。発生区画は隔離します |
| **線虫** | 菌糸が溶けて消え、堆肥が黒く湿ります | ピーク熱処理60℃を確実に行います。発生したら堆肥を廃棄します |
| **ナメクジ** | 幼いキノコを食いちぎります | 灰やおがくずの帯を巡らせて防ぎます |
| **ネズミ** | キノコをくわえて持ち去り、菌床を荒らします | 菌床に網をかぶせます |

> **キノコバエの防除は薬ではなく構造で行います。**薬剤がない状況で唯一確実に効果がある方法は、入り込む隙間をふさぐことです。通風口に目の細かい布を二重にかぶせ、出入口に濡れた布をカーテンのように垂らせば、たいてい防げます。5月から急激に増えるため、春作型では特に注意します。

&nbsp;&nbsp;&nbsp;衛生管理が防除の半分です。収穫が終わった堆肥を栽培舎のそばに積んでおくと、キノコバエの繁殖場になります。廃堆肥はすぐに遠くへ運び、畑にすき込むか覆っておきます。
