## 13. 无冰箱贮藏

### 13-1. 生鲜状态撑不过三天

&nbsp;&nbsp;&nbsp;评价表中双孢蘑菇的耐储性以生鲜状态为准为E。无电力常温下只能放3-5天。含水率高达90%，菌盖表面的酶接触空气后会迅速褐变。尤其是**一旦沾水，一天之内就会变褐色。**

| 不应做的事 | 原因 |
|:---|:---|
| **洗净后保存** | 吸水后会立即褐变并变软 |
| 用塑料袋密封 | 凝结水珠导致腐烂 |
| 堆叠存放 | 下层被压出淤痕，并从该处开始变质 |
| 长时间日晒（食用部分） | 会褐变。但在晒干时则正好相反地利用这一点 |

> **但一旦晒干，等级就会完全不同。**
> 排除判定和耐储性等级都是以未加工的生鲜状态为准。干燥几乎不需要燃料和设备，因此在灾害状况下，双孢蘑菇的贮藏问题实际上靠晒干一项就能解决。造成排除的两项缺陷中，有一项仅凭一把刀和一张筛子就能化解。

### 13-2. 干燥——维生素D会增加

&nbsp;&nbsp;&nbsp;双孢蘑菇的干燥有其他菌菇没有的优势。蘑菇中的麦角固醇经紫外线照射会转变为维生素D2，因此**晒干的过程本身就是一次营养强化。**在室内生活拉长、油脂丰富的鱼类断供的灾害状况下，这是一种难以计入账面却很可观的价值。

| 方法 | 条件 | 时长 | 结果 |
|:---|:---|:--:|:---|
| **日晒干燥** | 切成4-6mm，**菌褶朝上**摊在晒架上 | 晴天1-2天 | 最简便，**维生素D显著增加** |
| 阴凉通风干燥 | 通风良好的屋檐下 | 3-5天 | 颜色变化较小，但维生素D不会增加 |
| 穿线悬挂 | 对半切开后穿线挂在屋檐下 | 4-7天 | 占地较少 |
| 火边烘干 | 灶台上方架子，40-50℃ | 半天 | 梅雨季可用，注意不要烤焦 |

> **菌褶朝上放置才能增加维生素D。**麦角固醇含量最高的部位是菌褶，只有紫外线直接照射到这一面才会发生反应。若把菌盖朝下扣放，虽然也能晒干，但几乎没有营养强化的效果。

| 阶段 | 判定 |
|:---|:---|
| 完全干燥 | **用手一折会发出干脆的响声并断裂。**若能弯曲说明还没干透 |
| 保存 | 完全放凉后**放入密闭容器，配以木炭或炒盐** |
| 期限 | 阴凉黑暗处可存**1年以上，**磨成粉可存2年以上 |

&nbsp;&nbsp;&nbsp;先切片再晒干很重要。双孢蘑菇菌盖厚、菌柄粗，整朵晒干内部不易干透会长霉，务必切成4-6mm薄片晒干。而且切开后褐变会很快发生，**切好须立即摊到晒架上**才能减少变色。

### 13-3. 其他贮藏方法

| 方法 | 做法 | 期限 |
|:---|:---|:--:|
| **蘑菇粉** | 完全晒干后磨成粉，过筛只取细粉 | 2年以上 |
| **盐渍** | 焯水沥干后按重量的20%加盐分层码放 | 6个月-1年 |
| **酱菜** | 焯水后浸入酱油和醋中 | 3-6个月 |
| **发酵贮藏** | 浸入3%盐水中进行乳酸发酵 | 3-6个月 |
| **油浸** | 焯水沥干后浸没在油中 | 1-3个月 |
| **窖藏短期保存** | 不洗，用纸或干布包好放入12-15℃的地窖 | 5-7天 |

&nbsp;&nbsp;&nbsp;先焯水再晒干或腌渍，对双孢蘑菇特别有利。引起褐变的酶遇热会被破坏，用沸水焯2-3分钟后再晒干，颜色能保持得亮得多。焯水时加一点盐或醋效果更好。只需多耗一点燃料，品质就能明显提升。

> **蘑菇粉在灾害状况下尤为珍贵。**
> 体积小，能为汤增添鲜味，还可以掺入谷物粉中补充蛋白质和维生素D。晒干的蘑菇一旦开始碎裂，磨成粉比丢弃更划算。

## 14. 烹饪与加工

### 14-1. 煮熟食用更好

&nbsp;&nbsp;&nbsp;在本文涉及的六个品种中，双孢蘑菇是唯一可以生食的菌菇。评价表中烹饪·加工等级为A正说明了这一点。但在灾害状况下，还是煮熟更好，原因有三：不加热就无法吸收细胞壁内的营养素；生蘑菇含有少量蘑菇氨酸，加热能降低风险；若是野生个体，即便通过了第12节的辨别步骤，也必须煮熟。

| 烹饪 | 燃料 | 时间 | 备注 |
|:---|:--:|:--:|:---|
| 烤 | 少 | 5-8分钟 | 也可放在炭火余烬上烤。菌盖已展开的尤其适合烤制 |
| 炒 | 少 | 5-8分钟 | 加一点油味道会明显提升 |
| 汤·炖菜 | 中等 | 10分钟以内 | 能为汤汁增添鲜味 |
| 焯水 | 少 | 2-3分钟 | 可用于拌凉菜或作为腌渍前的处理 |
| 生食 | 不需要 | - | 仅限栽培的。切薄片后拌盐和油食用 |

&nbsp;&nbsp;&nbsp;菌盖已展开的大个体肉厚，嚼感近似肉类。在蛋白质匮乏的状况下，这种能带来咀嚼满足感的食材特点，体现在评价表口味等级S上。整朵放在炭火余烬上只撒盐烤制，也能成为一餐的菜肴。

### 14-2. 干货的使用方法

| 顺序 | 方法 |
|:--:|:---|
| 1 | 用温水浸泡20-30分钟使其回软 |
| 2 | **泡发的水不要倒掉，**其中溶有鲜味物质和水溶性营养素 |
| 3 | 避开沉在底部的沙子，只取上层的水作汤汁使用 |
| 4 | 泡发后的蘑菇切好后用于炒菜或煮汤 |
| 5 | 蘑菇粉无需泡发，可直接加入汤汁或面糊中 |

### 14-3. 弥补谷物不足的搭配

| 搭配 | 效果 |
|:---|:---|
| **蘑菇+谷物粥** | 蘑菇蛋白质能补足谷物中偏少的赖氨酸 |
| **蘑菇粉+小麦粉·荞麦粉** | 掺入面疙瘩或刀削面面团中，提升蛋白质和维生素D |
| **蘑菇+油** | 维生素D是脂溶性的，与油同食吸收更好 |
| **蘑菇+凉拌野菜** | 微量营养素的构成彼此不同，可互补 |
| **蘑菇+马铃薯·甘薯** | 用薯类（块茎/块根）补足热量，用蘑菇补充蛋白质 |

> **蘑菇不适合作为热量来源，而应作为蛋白质和微量营养素的补充来源使用。**
> 对双孢蘑菇而言，这一点尤为明确。每100g仅15kcal，蛋白质3.12g，蛋白质占热量的比例高达83.2%，是本文六个品种中最高的。用谷物或薯类（块茎/块根）补足热量，再用双孢蘑菇补充蛋白质和维生素D，才是正确的搭配方式。

## 15. 全年作业日程

| 月份 | 作业 |
|:--:|:---|
| 1月 | 收集稻草和粪肥。将贝壳和蛋壳烧后磨碎备用。修补木框和栽培棚 |
| **2月** | **春季作型开始一次发酵。**预堆与主堆，每2-3天翻堆一次 |
| **3月** | **后发酵与接种。**巴氏消毒60℃保持6小时，确认无氨味后接种，进行菌丝培养 |
| **4月** | **覆土与出菇。**16-18℃，打开通风口排出二氧化碳，月底迎来首次采收 |
| **5月** | **春季作型采收高峰。**2-3潮，立即日晒干燥。**菇蝇在此月急增，须检查防虫网** |
| 6月 | 收尾春季作型，将废堆肥翻入田中，清洗菌床和栽培棚 |
| 7月 | 天热不栽培，收集稻草和粪肥，若有地窖可继续周转 |
| **8月** | **秋季作型开始一次发酵。**天气炎热，发热效果好 |
| **9月** | **后发酵与接种，**进行菌丝培养 |
| **10月** | **覆土与出菇，**首次采收 |
| **11月** | **秋季作型采收高峰，**品质最佳的时期，大量晒干 |
| 12月 | 整理废堆肥，检查孢子印，确认干蘑菇状态 |

&nbsp;&nbsp;&nbsp;这份日程的关键在于**把发酵和出菇的季节错开安排。**堆肥发酵在天热时效果好，出菇则在天凉时效果好，因此在深冬和盛夏发酵，在春秋两季采收。盛夏和严冬是休整的季节，这段空档在夏季由大球盖菇和木耳填补，在冬季由金针菇填补。

&nbsp;&nbsp;&nbsp;若有地窖，情况就不同了。地窖常年维持在12-18℃，可以全年周转。不过发酵仍须在室外进行，因此做法是在外面发酵好堆肥后再运入窖内。严冬时室外发酵效果不佳，须把堆垛得更大、用稻草盖厚以保温。

### 绝对不能忘记的事

| 项目 | 内容 |
|:--:|:---|
| 1 | **挖开菌柄基部确认有没有菌托。**若有菌托就是鹅膏类，一朵就能致人死亡 |
| 2 | **掰开一朵纽扣菇看菌褶颜色。**浅粉色是双孢蘑菇，若始终纯白则不要食用 |
| 3 | **若孢子是白色就不要食用。**双孢蘑菇的孢子是褐色至巧克力褐色 |
| 4 | **切面变黄并散发药品气味就不要食用** |
| 5 | **不要在残留氨味的堆肥中接种，**种菌会直接死亡 |
| 6 | **覆土必须蒸过再用，**干腐病和菇蝇都是从土中带入的 |
| 7 | **堆肥发酵本身就是灭菌。**不必烧柴就能给培养基灭菌，是这种菌菇独有的最大优势 |
| 8 | **日晒时把菌褶朝上放置，**维生素D会增加 |
| 9 | **一旦晒干，贮藏问题就不复存在，**不要被生鲜状态的E等级误导 |
| 10 | **因为不进行光合作用，即使在日照减少的灾害中也是稳定的食物来源。**太阳光SS并不是说它善于利用光，而是说它本就在光照之外 |
| 11 | **即便失败，堆肥仍会留下，**这是其他菌菇没有的一道安全网 |
