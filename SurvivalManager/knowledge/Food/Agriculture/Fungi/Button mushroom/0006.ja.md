## 13. 冷蔵庫なしの貯蔵

### 13-1. 生のままでは三日ともちません

&nbsp;&nbsp;&nbsp;評価表でのマッシュルームの貯蔵性は生の状態を基準にEです。無電力常温で3-5日です。水分が90%あり、傘表面の酵素が空気に触れると急速に褐変します。特に**水に触れると一日で茶色くなります。**

| してはいけないこと | 理由 |
|:---|:---|
| **洗って保管** | 水分を含んですぐに褐変し傷みます |
| ビニールで密封 | 水滴がついて腐ります |
| 積み重ねる | 下のほうが押されて傷み、その部分から傷みます |
| 日光に長く当てる（食べるもの） | 褐変します。ただし乾燥させるときは逆に利用します |

> **しかし乾燥させれば等級はまったく変わります。**
> 除外判定と貯蔵性の等級は加工していない生の状態を基準にしています。乾燥は燃料も設備もほとんど使わないため、災害状況でのマッシュルームの貯蔵性の問題は事実上乾燥ひとつで解決します。除外を生んだ二つの欠格のうち一つが、包丁とざるだけで解消します。

### 13-2. 乾燥 - ビタミンDが増えます

&nbsp;&nbsp;&nbsp;マッシュルームの乾燥には他のキノコにはない利点があります。キノコのエルゴステロールが紫外線を受けるとビタミンD2に変わるため、**天日で乾かす過程がそのまま栄養強化の過程になります。**室内生活が長引き脂の乗った魚が途絶える災害状況で、これは計算に入りにくい大きな価値です。

| 方法 | 条件 | 期間 | 結果 |
|:---|:---|:--:|:---|
| **天日乾燥** | 4-6mmに切って**ひだ側を上に向け**て干し台に広げて干す | 晴れた日1-2日 | 最も簡単で**ビタミンDが大きく増えます** |
| 日陰の風乾燥 | 風通しのよい軒下 | 3-5日 | 色の変化は少ないですがビタミンDは増えません |
| 糸に通して吊るす | 半分に割いて糸に通し軒下に | 4-7日 | 場所を取りません |
| 火のそばで乾燥 | かまどの上の棚、40-50℃ | 半日 | 梅雨時に使えます。焦がさないように |

> **ひだ側を上に向けて置くとビタミンDが増えます。**エルゴステロールが最も多い部位がひだで、紫外線がその面に直接当たってこそ反応が起こります。傘を下に伏せて置くと乾燥はできますが、栄養強化の効果はほとんどありません。

| 段階 | 判定 |
|:---|:---|
| 完全乾燥 | **手で折ると乾いた音を立てて折れます。**曲がるようならまだ乾燥が足りません |
| 保管 | 完全に冷ましてから**密閉容器に炭や炒り塩と一緒に** |
| 期間 | 涼しく暗い場所で**1年以上。**粉に挽けば2年以上 |

&nbsp;&nbsp;&nbsp;切ってから干すことが重要です。マッシュルームは傘が厚く軸が太いため、丸のまま干すと中まで乾かずカビが生えます。必ず4-6mmに薄切りにして干します。そして切った後は褐変が急速に進むため、**切ったらすぐに干し台に並べる**ことで色の変化を抑えられます。

### 13-3. その他の貯蔵方法

| 方法 | 作り方 | 期間 |
|:---|:---|:--:|
| **キノコ粉** | 完全に乾燥させてから挽いて粉にします。ふるいにかけて細かいものだけを使います | 2年以上 |
| **塩漬け** | 湯通しして水気を切り、重量の20%の塩を層状に入れます | 6か月-1年 |
| **醤油漬け** | 湯通しして醤油と酢に漬けます | 3-6か月 |
| **発酵貯蔵** | 3%の塩水に漬けて乳酸発酵させます | 3-6か月 |
| **油漬け** | 湯通しして水気を絞り、油に浸るように漬けます | 1-3か月 |
| **土窟での短期保管** | 洗わずに紙や乾いた布に包んで12-15℃の土窟に | 5-7日 |

&nbsp;&nbsp;&nbsp;湯通ししてから乾燥させたり漬けたりするほうが、マッシュルームでは特に有利です。褐変を起こす酵素は熱で壊れるため、沸騰した湯で2-3分湯通ししてから干すと、色がはるかに明るく保たれます。塩や酢を少し加えて湯通しすればさらによくなります。燃料を少し使う代わりに、品質が目に見えて上がります。

> **キノコ粉は災害状況で特に価値があります。**
> かさが小さく、汁物にうま味を出し、穀物の粉に混ぜてタンパク質とビタミンDを補うことができます。乾燥させたものが崩れ始めたら、捨てるより粉にするほうがよいです。

## 14. 調理と加工

### 14-1. 火を通して食べるほうがよいです

&nbsp;&nbsp;&nbsp;マッシュルームはこの文書が扱う六種の中で唯一、生食が可能なキノコです。評価表の調理・加工Aはその事情を表しています。しかし災害状況では火を通すほうがよいです。理由は三つです。加熱しないと細胞壁の中の栄養素を吸収できません。生のものには少量のアガリチンが含まれており、熱で減らすほうが安全です。そして野生の個体なら、12節の見分け方を通過していても必ず加熱する必要があります。

| 調理 | 燃料 | 時間 | 備考 |
|:---|:--:|:--:|:---|
| 焼く | 少ない | 5-8分 | 熾火に乗せてもかまいません。傘が開いたものは特に焼き物に向きます |
| 炒める | 少ない | 5-8分 | 油が少しあると味が大きく上がります |
| スープ・鍋 | 中程度 | 10分以内 | 汁にうま味が出ます |
| 湯通し | 少ない | 2-3分 | ナムルにあえたり漬け物の前段階にします |
| 生食 | 不要 | - | 栽培したものだけ。薄く切って塩と油であえます |

&nbsp;&nbsp;&nbsp;傘が開いた大きな個体は身が厚く肉に似た噛み応えがあります。タンパク質が不足する状況で噛む満足感を与える食材だという点は、評価表の味Sに反映されています。丸ごと熾火に乗せて塩だけ振っても、一食分のおかずになります。

### 14-2. 乾燥したものの使い方

| 順序 | 方法 |
|:--:|:---|
| 1 | ぬるま湯に20-30分浸して戻します |
| 2 | **戻し汁は捨てません。**うま味と水溶性の栄養素が溶け出しています |
| 3 | 底に沈んだ砂を避け、上澄みだけを汁として使います |
| 4 | 戻したキノコは切って炒めるか、スープに入れます |
| 5 | 粉は戻さずそのまま汁物や生地に入れます |

### 14-3. 穀物不足を補う組み合わせ

| 組み合わせ | 効果 |
|:---|:---|
| **キノコ + 穀物がゆ** | 穀物に不足しがちなリジンをキノコのタンパク質が補います |
| **キノコ粉 + 小麦粉・ソバ粉** | すいとんやカルグクスの生地に混ぜてタンパク質とビタミンDを高めます |
| **キノコ + 油** | ビタミンDは脂溶性なので油と一緒に食べると吸収がよくなります |
| **キノコ + ナムル** | 微量栄養素の構成が互いに異なります |
| **キノコ + ジャガイモ・サツマイモ** | いも類（塊茎・塊根）で熱量を満たし、キノコでタンパク質を補います |

> **キノコは熱量源ではなく、タンパク質と微量栄養素の補給源として使うのが正解です。**
> マッシュルームの場合、その意味は特にはっきりしています。100gあたり15kcal、タンパク質3.12gです。熱量に占めるタンパク質の割合83.2%は、この文書の六種の中で最も高い数値です。穀物やいも類（塊茎・塊根）で熱量を満たし、マッシュルームでタンパク質とビタミンDを補う組み合わせが、正しい使い方です。

## 15. 年間作業スケジュール

| 月 | 作業 |
|:--:|:---|
| 1月 | 稲わらと糞尿を集めます。貝殻と卵の殻を焼いて挽いておきます。木枠と栽培舎の補修 |
| **2月** | **春作型の一次発酵開始。**仮積みと本積み。2-3日ごとに切り返し |
| **3月** | **後発酵と接種。**ピーク熱処理60℃6時間。アンモニアを確認後、種菌を接種。菌糸培養 |
| **4月** | **覆土と発生。**16-18℃。通風口を開けて二酸化炭素を抜きます。月末に初収穫 |
| **5月** | **春作型の収穫最盛期。**2-3周期。すぐに天日乾燥。**キノコバエが急増する月なので防虫網を点検** |
| 6月 | 春作型の締めくくり。廃堆肥を畑にすき込みます。菌床と栽培舎の洗浄 |
| 7月 | 暑いので栽培しません。稲わらと糞尿を確保します。土窟があれば継続して回します |
| **8月** | **秋作型の一次発酵開始。**暑い季節なので発熱がよく進みます |
| **9月** | **後発酵と接種。**菌糸培養 |
| **10月** | **覆土と発生。**初収穫 |
| **11月** | **秋作型の収穫最盛期。**品質が最もよい時期。大量乾燥 |
| 12月 | 廃堆肥の整理。胞子紋の点検。乾燥キノコの状態確認 |

&nbsp;&nbsp;&nbsp;この日程の要は、**発酵と発生の季節をずらして配置する**という点です。堆肥発酵は暑いときによく進み、キノコの発生は涼しいときによく進みます。だから晩冬と晩夏に発酵させ、春と秋に収穫します。真夏と真冬は休む季節で、その場所を夏には大球盖菇とキクラゲが、冬にはエノキタケが埋めます。

&nbsp;&nbsp;&nbsp;土窟があれば計算が変わります。土窟は一年中12-18℃なので周年で回せます。ただし発酵は外で行う必要があるため、外で発酵させた堆肥を窟に運び入れる方式になります。真冬は外で発酵がうまく進まないため、山をより大きく積んでわらで厚く覆い熱を保ちます。

### 絶対に忘れてはならないこと

| 項目 | 内容 |
|:--:|:---|
| 1 | **軸の基部を掘って袋（つぼ）がないか確認します。**袋があればテングタケ類で、一つで人が死にます |
| 2 | **ボタンを一つ割ってひだの色を見ます。**淡いピンクならマッシュルーム、最後まで純白なら食べません |
| 3 | **胞子が白色なら食べません。**マッシュルームの胞子は褐色からチョコレート色です |
| 4 | **切り口が黄色く変わり薬品臭がすれば食べません** |
| 5 | **アンモニア臭が残った堆肥に接種しません。**種菌がそのまま死にます |
| 6 | **覆土は必ず蒸してから使います。**乾腐病とキノコバエが土から入ります |
| 7 | **堆肥発酵がそのまま殺菌です。**薪を燃やさずに培地を殺菌できる唯一のキノコだという点が、このキノコの最大の強みです |
| 8 | **天日で乾かすときはひだを上に向けて置きます。**ビタミンDが増えます |
| 9 | **乾かせば貯蔵性の問題は消えます。**生の状態基準のE等級にだまされないでください |
| 10 | **光合成をしないため、日射が減る災害でも揺るがない食料源です。**太陽光SSは光をうまく使うという意味ではなく、光の外にあるという意味です |
| 11 | **失敗しても堆肥は残ります。**他のキノコにはない安全弁です |
