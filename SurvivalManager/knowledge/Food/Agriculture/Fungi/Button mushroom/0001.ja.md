## はじめに
&nbsp;&nbsp;&nbsp;マッシュルーム(Agaricus bisporus)は、評価表で除外と判定されました。貯蔵性E(生の基準)と永続性Cが重なって備蓄が成り立たないという理由で、ゲート未適用スコアは40.8点(有効183種中103位)です。貯蔵性Eは、薄く切って干せば密閉容器で1年もつので、ナイフと干しざるだけで解決します。このキノコの最大の長所は、**電気や薪なしで培地を殺菌できる**ことです。稲わら、糞、石膏を積んでおくと、山の中の微生物が自ら55-70℃まで発熱し、病原菌や害虫の卵を殺し、雑菌のえさになる糖分を燃やし尽くして、マッシュルームの菌糸だけが食べられる培地をつくります。人は火をたかず、切り返すだけです。光合成をしないので、火山灰やすすで空が暗くなっても収量は減らず(日射SS)、稲わら、馬ふん、鶏ふん、もみ殻、古紙、貝殻など、ほぼあらゆる副産物が培地の材料になり(キノコ副産物への適応性S)、失敗しても堆肥は残ります。代償は、堆肥を2-3週間のあいだに5、6回切り返す労働と、致命的な毒キノコ(シロタマゴテングタケ、ドクツルタケ)と取り違える危険です。7節は、その見分けのために別に長くとってあります。

| 区分 | 内容 |
|:---|:---|
| 判定 | 除外(貯蔵性E + 永続性C)。ゲート未適用スコア40.8、無防除の減収率50.6% |
| 強み | SS: タンパク質密度、日射、整地・掘削エネルギー、収量の安定性。S: 収穫速度、キノコ副産物への適応性、国内での栽培の普及度 |

> **キノコは日光が消えた世界でも収量が減らない唯一の食料源であり、マッシュルームはそれを薪1本なしでやってのける唯一の種です。**

&nbsp;&nbsp;&nbsp;項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. キノコの概要
&nbsp;&nbsp;&nbsp;担子菌門ハラタケ科ハラタケ属で、韓国語名のヤンソンイは「西洋から来たマツタケ」という意味にすぎず、マツタケとは関係がありません。分解がかなり進んだ有機物の山に生える腐生菌なので、殺菌した培地を与えるのではなく、微生物が先に熟成させておいた培地を食べさせます。そのため、堆肥の発酵が栽培の7割です。

| 特徴 | 内容 |
|:---|:---|
| かさ | 直径3-10cm、半球形から平らに開く。白、クリーム色、茶色。なめらかで粘りがない |
| ひだ | 最初は薄いピンク色で、茶色、黒褐色へと濃くなる。胞子は茶色-チョコレート色 |
| 柄 | 短くて太い(長さ3-7cm)。つばがあり、根元につぼはない |
| 肉 | 白色で、切ると薄いピンク色から茶色へゆっくり変わる。キノコの香り |

| 段階 | 期間と温度 | 要点 |
|:---|:---|:---|
| 堆肥の一次発酵(屋外) | 2-3週間、山の中55-70℃ | 2-3日おきに切り返す |
| 堆肥の後発酵(屋内) | 5-7日、60℃で保温した後45-55℃ | アンモニアのにおいが消える |
| 種菌接種と菌糸の培養 | 2-3週間、23-25℃ | 堆肥全体が白くなる |
| 覆土 | 2-3cm | 覆土がないとキノコが出ない |
| 原基形成、生育 | 覆土後10-15日(18-22℃)、その後5-7日(16-18℃) | 白い粒がふくらんでボタンになる |
| 収穫 | 菌床に詰めてから40-60日 | 1-2週間おきに最大3回 |

| 100g当たりの栄養 | 含量 |
|:---|:---|
| 熱量 / タンパク質 | 15kcal / 3.12g(熱量の83.2%で、この分類で最も高い) |
| その他 | 水分約90g、カリウム212-384mg、ビタミンB群。ビタミンDは日光で干すと大きく増える |

## 3. 培地(堆肥)と栽培室
| 区分 | 一般的な配合 | 災害時の代替 |
|:---|:---|:---|
| 炭素源 | 稲わら、麦わら、大麦わら80% | 乾いた草、トウモロコシの茎、アシ、もみ殻、古紙 |
| 窒素源 | 鶏ふん、尿素、米ぬか | 馬ふん(伝統的な窒素源)、牛ふん、豚ふん、寝かせた尿、豆がら、油かす |
| ミネラル | 石膏(硫酸カルシウム) | 焼いて砕いた貝殻、卵の殻の粉、木灰 |

&nbsp;&nbsp;&nbsp;稲わら100kg当たり、鶏ふん10-15kg(馬ふんなら30-50kg)、米ぬか5kg、尿素400-500g(尿なら10-15L)、石膏3-5kgを混ぜ、開始時のC/N比を28-32対1にします(わらだけでは70対1以上なので窒素を補う)。

| 発酵 | 方法 |
|:---|:---|
| 一次発酵 | 仮積みで、わらに全水量の70%以上を与えて柔らかくし、本積みで窒素源と石膏をわらと交互に積んで亀の甲形(高さ1.5-1.8m、幅1.5-2m)にする。2-3日おきに5-8回切り返し、外側と内側を入れ替える。山の中は55-70℃で、握ると水が数滴落ちる水分。アンモニアのにおいはこの段階では正常で、どぶのにおいは嫌気的な腐敗、切り返すときに白い放線菌の粉が舞えばよい兆候 |
| 後発酵 | 菌床に1㎡当たり50-60kg詰め、60℃で6時間の保温(55℃で12時間、50℃で24時間でも代替可)を行った後、45-55℃で5-7日。電気がなければ、熱い堆肥を25-30cmの厚さで小さな部屋や洞窟に詰めてかますやむしろで覆うか、晴れた日にビニールで覆うか、オンドルの床を温める |
| 完了の判定 | アンモニアのにおいがまったくなく、堆肥の表面と中が白い放線菌で覆われ、濃い茶色からチョコレート色で、水分68-72%、pH 6.8-7.2 |

> **アンモニアのにおいが残っているうちは、絶対に種菌を接種してはいけません。種菌がそのまま死にます。換気を増やして数日さらに発酵させます。**

&nbsp;&nbsp;&nbsp;栽培室は16-25℃を保てる閉じた空間で、洞窟、地下室、北向きの倉庫、半地下の穴蔵、土壁の納屋がよいです。菌床は幅1-1.2m、堆肥の深さ20-30cmで、丸太、板、竹を組んで2-4段にし(床1㎡から菌床3㎡)、上下に通気口を設けます。光は不要です。

| 覆土 | 基準 |
|:---|:---|
| 材料 | 腐葉土 + 砂 + 石灰、または田の土 + もみ殻 + 貝殻の粉。pH 7.5以上(アオカビは弱酸性を好む)、ふかふかに保つ |
| 殺菌 | 60℃以上で数時間蒸して使うか、鉄板で炒る(乾腐病とキノコバエが土から入る) |

## 4. 種菌の確保と接種
| 方法 | 内容 |
|:---|:---|
| 市販の種菌 | 平時に最も簡単なので、あらかじめ確保 |
| 組織培養 | かさが開く直前の新鮮なボタンを手で縦に割り(ナイフだと表面の雑菌が中に入る)、かさと柄が出会う内側の白い肉を米粒大にちぎり、ゆでて冷ました稲わらや堆肥に差し込んで、23-25℃の暗所で培養。3-5日で白い菌糸が広がる。最も確実な方法 |
| 菌床の移植 | 菌糸が堆肥全体に広がった直後、覆土の前に、白い菌糸が密で雑菌の跡がない部分を握りこぶし大にすくい取り、新しい堆肥の重さの3-5%を20-30cm間隔で埋める。4、5世代を超えると活力が落ちるので、組織培養に戻す |
| 胞子紋 | 十分に開いた大きな個体のかさを、ひだを下にしてアルミ箔にのせ、器をかぶせて24時間置くと、茶色-チョコレート色の胞子の粉が残る。マッシュルームは担子器当たりの胞子が2つで、1粒でもキノコになるが発芽率が低いので、たっぷりまく |

&nbsp;&nbsp;&nbsp;胞子は日陰で乾かし、箔を折ってジッパー袋に、よく炒った塩や炭とともに入れ、四季を通じて温度が一定で光の入らない洞窟や地下室に置くと、5-10年以上もちます(液体で保管すると3-6か月)。初年に最も大きく健康な個体から20-30枚をつくり、蓄えておきます。

| 接種 | 基準 |
|:---|:---|
| 条件 | 堆肥が25℃以下に冷め、アンモニアのにおいがなく、水分68-72%。素手で堆肥に混ぜてもよく、無菌室がなければ推奨量の上限寄りにたっぷり入れる |
| 方法 | 3.3㎡(堆肥125kg)当たり種菌1.5-3.6kgを米粒大にほぐして、堆肥の上部10-15cmの層に均一に混ぜ、表面を平らにして、湿らせた布やかますで覆う |

## 5. 菌糸の培養、発生の誘導、収穫
| 段階 | 管理 |
|:---|:---|
| 菌糸の培養(2-3週間) | 接種後1-5日は25-27℃、6-7日以降は20℃に下げる。菌糸の代謝熱で堆肥の中がさらに熱くなるので、堆肥の中が30℃を超えないようにする(34℃で菌糸が死ぬ)。堆肥に直接水をやらず、覆いが乾いたら覆いにだけかける。1日1、2回短く換気 |
| 覆土 | 菌糸が堆肥の下まで届いた後(接種後2-3週間)、2-3cm覆ってたっぷり湿らせる |
| 発生の誘導 | 温度を16-18℃に下げ、それまで閉じていた通気口を開けて二酸化炭素を抜くと、キノコが出る(菌糸は二酸化炭素を好み、子実体は嫌う)。空気の湿度85-95%、12℃以下では原基ができない |
| 水管理 | 原基形成期は水を減らすか止め、豆粒大になった後は覆土が乾かない程度に少しずつ。収穫直前の2-3日はやらない |

&nbsp;&nbsp;&nbsp;電気なしで16-18℃をつくるには、洞窟、地下室、半地下の穴蔵を使い、真夏と真冬には育てず、春(3月下旬-5月)と秋(9-11月)の2作を回します。

| 収穫 | 基準 |
|:---|:---|
| 時期 | かさの直径2-4cm、かさが丸く閉じ、かさと柄の間の白い膜が破れる前のボタン段階、早朝。遅く摘んだものも使える |
| 要領 | かさを包むように持ち、軽くひねって根元まで丸ごと抜き、抜いた跡は埋める。洗わない |
| 周期 | 1回に3-5日、群れで出て、7-14日おき。2回目は1回目の50-70%、3回目は20-30%。1㎡当たり堆肥50-60kgから計10-20kg |

> **収穫の適期である白いボタン段階は、致命的なテングタケ類の幼い個体と見た目が最も似る時期です。必ず7節を読み、自分がつくった菌床に出たものだけを摘みます。**

## 6. 汚染と病害虫、異常の診断
| 問題 | 症状と原因 | 対応 |
|:---|:---|:---|
| アオカビ | 最初は白、すぐ青緑色になる。1日10-30mmで、マッシュルームの菌糸(3-5mm)の3-6倍速い。色が見えたときにはすでに培地の大部分を失っているので、初期は速さと質感で判別 | 該当区画を取り除く。後発酵をきちんと行い、種菌をたっぷり入れる |
| 乾腐病 | キノコがつぶれた白い塊になって奇形。覆土の土を殺菌しなかったとき | 病んだ個体と周囲の土を取り除いて、塩や灰をまく。覆土は必ず蒸す |
| 褐色斑点病、細菌性軟腐病、くもの巣病 | かさの褐色のくぼんだ斑点、柔らかくなって悪臭、白いくもの巣のようなカビ。多湿と換気不足 | 水を減らし、換気を増やし、病んだものを取り除く |
| キノコバエ | 菌糸を食べ、うじが入る。カビの胞子と乾腐病を運ぶ | 通気口に目の細かい布を二重にかけ、出入口に濡れた布のカーテン。5月から急増。水皿、粘着板、灯火のトラップ |
| ダニ、センチュウ、ナメクジ、ネズミ | 菌糸が褐色になる、堆肥が黒く湿る、幼いキノコをかじる、菌床を荒らす | 覆土を蒸す、60℃の保温を確実に、灰やおがくずの帯、菌床にネット |

| 症状 | 原因と措置 |
|:---|:---|
| 接種して1週間たっても菌糸が見えない | 堆肥にアンモニアが残っていたか、熱いうちに接種した。さらに発酵させる |
| 菌糸が伸びて止まる | 堆肥の温度が30℃超か水分不足。室内を20℃に下げる |
| 菌糸はよいがキノコが出ない | 覆土をしていない、換気不足、温度が高い |
| 柄が長くかさが小さい | 二酸化炭素過多。換気する |
| かさがすぐ開いて薄い | 温度が22℃以上。涼しい場所へ移す |
| 原基ができて乾いたり柔らかくなって死ぬ | 湿度不足、または水を強くやりすぎ |

&nbsp;&nbsp;&nbsp;キノコを収穫した後の廃堆肥は、畑の元肥、マルチ、育苗用の土、ミミズの飼育基質、酸性土壌の改良に使います。アオカビや乾腐病に汚染された堆肥は畑に入れず、燃やすか遠くに深く埋めます(胞子が翌年戻ってくる)。山の発熱と培地づくりは同じ過程なので、キノコが採れなくても堆肥は残ります。菌床の枠は周期ごとに空にして洗い、日に干し、2-3年に1度、壁と床に石灰硫黄合剤や濃い木灰の灰汁を塗ります。

## 7. 毒キノコの取り違えと安全の確認
> **この節は命に直結します。マッシュルームは、致命的な毒キノコとの取り違えによる死亡事故が最も多く報告されているキノコです。育てるよりも、食べてよいかを確認することのほうが重要です。**

&nbsp;&nbsp;&nbsp;土から生える、白いボタン段階で摘む、柄につばがあるという3つの条件が、シロタマゴテングタケとドクツルタケ(アマトキシン、致命的)の幼い個体と重なります。育てたキノコでも、覆土の土に野生の胞子が混ざって別のキノコが一緒に出ることがあります。

| 区分 | マッシュルーム | シロタマゴテングタケ・ドクツルタケ(致命的) |
|:---|:---|:---|
| 柄の根元 | つぼがない | 膜でできたつぼが根元を包む |
| ひだの色 | 薄いピンクから茶色、黒褐色 | 最初から最後まで純白 |
| 胞子の色 | 茶色-チョコレート色 | 白色 |
| 柄 | 短くて太い(3-7cm) | 長くて細い(9-20cm)。ドクツルタケは白い繊維状のうろこ |
| 肉の色の変化 | 切るとピンクがかってから茶色 | 変わらず白いまま |
| 発生基質 | 発酵堆肥と覆土、菌床に群れで | 生きた木の根の近くの地面、森に1本ずつ |
| つば | あり | あり(区別できない) |

> **マッシュルームとシロタマゴテングタケを分けるのは、根元のつぼです。地上に出た部分だけを見ると、つぼは土に埋もれて見えないので、根元を土ごと掘り出して確認します。ボタンを1つ縦に割ったとき、ひだが薄いピンクならマッシュルーム、最後まで純白なら食べません。白い紙にかさを伏せて、コップをかぶせて数時間置いたとき、落ちた粉が白ければ、絶対に食べません。**

| 紛らわしいもの | 見分け方 |
|:---|:---|
| 黄変性のハラタケ類(胃腸毒) | 切ったりこすったりすると鮮やかな黄色に変わり、インクや薬品のような不快なにおい(加熱すると強くなる)。草地や道端に生える。死にはしないが、ひどい嘔吐と下痢 |
| テングタケ類の幼菌(卵の段階) | 白い卵形で、マッシュルームのボタンに最もよく似る。縦に割って、中に折りたたまれたキノコの形があり、外皮の下にぬるぬるしたゼリー層があれば、テングタケ類 |
| ホコリタケ類 | 割ると中が均一に白い綿のようで、ひだがない |
| ヒトヨタケ類 | 時間がたつとかさが黒く溶ける。お酒と一緒に食べると中毒 |

&nbsp;&nbsp;&nbsp;食べて6-24時間後に嘔吐と下痢が始まるのは、アマトキシン中毒の典型的な経過で、遅く始まるほど重症です。初めて食べるときは確認手順をすべて踏み、十分に加熱し、1人が1切れだけ食べて24時間待ち、食べたキノコの1個体を別に残しておきます。最も安全な方法は、野生で探すのではなく、自分がつくった菌床で育てることです。

## 8. 貯蔵、調理、年間日程
| 貯蔵 | 内容 |
|:---|:---|
| 生 | 洗ったり、ビニールに密封したり、積み重ねたりすると傷む。洗わず紙に包んで12-15℃の洞窟で5-7日 |
| 乾燥 | 4-6mmに切り、ひだを上にしてすだれに広げ、晴れた日に1-2日日光で干す(ひだのエルゴステロールが紫外線を受けてビタミンDが大きく増える)。雨の日は火のそばの40-50℃で半日。手で折ったときにぱきっと折れれば完了で、冷ましてから炭や炒った塩とともに密閉し、涼しく暗い場所で1年以上(粉は2年以上) |
| その他 | 塩漬け(塩20%、6か月-1年)、漬け物、3%の塩水での乳酸発酵、油漬け(1-3か月)。キノコの粉は汁にうま味を足し、穀物の粉に混ぜてタンパク質とビタミンDを補う |

&nbsp;&nbsp;&nbsp;マッシュルームはこの分類で唯一、育てたものに限って生食できますが、たいていは加熱して食べます。焼く、炒めるは5-8分、汁物は10分以内、ゆでるのは2-3分です。乾燥したものはぬるま湯に20-30分浸し、戻し汁にはうま味と水溶性の栄養素が溶けているので、砂を避けて上澄みをだしとして使います。キノコは熱量源ではなくタンパク質とビタミンDの補給源なので、穀物やイモ類で熱量を満たし、油とともに食べるのが正しい使い方です。

| 月 | 作業 |
|:---|:---|
| 1-2月 | 稲わらと糞を集める、貝殻と卵の殻を焼いて砕く、菌床の枠の補修、2月に春作の一次発酵を開始 |
| 3-4月 | 後発酵と接種(アンモニアを確認した後)、菌糸の培養、覆土と発生(16-18℃)、月末に最初の収穫 |
| 5-6月 | 収穫の最盛期とすぐの日光乾燥、防虫ネットの点検、廃堆肥を畑に入れ菌床と栽培室を洗う |
| 7-8月 | 暑くて育てない(洞窟があれば続ける)、8月に秋作の一次発酵を開始 |
| 9-11月 | 後発酵と接種、覆土と発生、11月に収穫の最盛期(品質が最もよい時期)と大量乾燥 |
| 12月 | 廃堆肥の整理、胞子紋と乾燥キノコの状態の点検 |

> **決して忘れてはならないこと: 柄の根元を掘ってつぼを確認する、ボタンを割ってひだの色を見る、胞子が白なら食べない、黄色くなって薬品のにおいがすれば食べない、アンモニアが残る堆肥に接種しない、覆土の土は蒸して使う、ひだを上に向けて干す。**
