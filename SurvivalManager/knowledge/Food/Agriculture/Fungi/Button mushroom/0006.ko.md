## 13. 냉장고 없는 저장

### 13-1. 생것으로는 사흘을 못 버팁니다

&nbsp;&nbsp;&nbsp;평가표에서 양송이의 저장성은 생것 기준으로 E입니다. 무전력 상온에서 3-5일입니다. 수분이 90%이고, 갓 표면의 효소가 공기와 만나 빠르게 갈변합니다. 특히 **물이 닿으면 하루 만에 갈색이 됩니다.**

| 하지 말아야 할 일 | 이유 |
|:---|:---|
| **씻어서 보관** | 수분을 머금어 곧바로 갈변하고 무릅니다 |
| 비닐에 밀봉 | 물방울이 맺혀 썩습니다 |
| 쌓아 두기 | 아래쪽이 눌려 멍이 들고 그 자리부터 상합니다 |
| 햇볕에 오래 두기(먹을 것) | 갈변합니다. 다만 말릴 때는 반대로 이용합니다 |

> **그러나 말리면 등급이 완전히 달라집니다.**
> 배제 판정과 저장성 등급은 가공하지 않은 생것 기준입니다. 건조는 연료도 설비도 거의 쓰지 않으므로, 재난 상황에서 양송이의 저장성 문제는 사실상 건조 하나로 해결됩니다. 배제를 만든 두 결격 가운데 하나가 칼과 채반만으로 풀립니다.

### 13-2. 건조 - 비타민 D가 늘어납니다

&nbsp;&nbsp;&nbsp;양송이 건조에는 다른 버섯에 없는 이점이 있습니다. 버섯의 에르고스테롤이 자외선을 받으면 비타민 D2로 바뀌므로, **볕에 말리는 과정이 곧 영양 강화 과정**입니다. 실내 생활이 길어지고 기름진 생선이 끊긴 재난 상황에서 이것은 계산에 잡히지 않는 큰 가치입니다.

| 방법 | 조건 | 기간 | 결과 |
|:---|:---|:--:|:---|
| **볕 건조** | 4-6mm로 썰어 **주름 쪽이 위를 향하게** 발에 펴 널기 | 맑은 날 1-2일 | 가장 쉽고 **비타민 D가 크게 늡니다** |
| 그늘 바람 건조 | 통풍 좋은 처마 아래 | 3-5일 | 색이 덜 변하나 비타민 D는 늘지 않습니다 |
| 실 꿰어 매달기 | 반으로 갈라 실에 꿰어 처마에 | 4-7일 | 자리를 덜 차지합니다 |
| 불 곁 건조 | 화덕 위 선반, 40-50℃ | 반나절 | 장마철에 쓸 수 있습니다. 태우지 않도록 |

> **주름 쪽을 위로 향하게 놓아야 비타민 D가 늘어납니다.** 에르고스테롤이 가장 많은 부위가 주름이고, 자외선이 그 면에 직접 닿아야 반응이 일어납니다. 갓을 아래로 엎어 놓으면 말리기는 되지만 영양 강화 효과가 거의 없습니다.

| 단계 | 판정 |
|:---|:---|
| 완전 건조 | **손으로 부러뜨리면 딱 소리가 나며 꺾입니다.** 휘어지면 아직 덜 말랐습니다 |
| 보관 | 완전히 식힌 뒤 **밀폐 용기에 숯이나 볶은 소금과 함께** |
| 기간 | 서늘하고 어두운 곳에서 **1년 이상**. 가루로 빻으면 2년 이상 |

&nbsp;&nbsp;&nbsp;썰어서 말리는 것이 중요합니다. 양송이는 갓이 두껍고 대가 굵어 통째로 말리면 속이 덜 말라 곰팡이가 생깁니다. 반드시 4-6mm로 저며 말립니다. 그리고 썬 뒤에는 갈변이 빠르게 진행되므로 **썰자마자 바로 널어야** 색이 덜 변합니다.

### 13-3. 다른 저장 방법

| 방법 | 만드는 법 | 기간 |
|:---|:---|:--:|
| **버섯 가루** | 완전 건조 후 빻아 가루로. 체에 쳐 고운 것만 | 2년 이상 |
| **소금 절임** | 데쳐서 물기를 빼고 소금을 무게의 20% 넣어 켜켜이 | 6개월-1년 |
| **장아찌** | 데쳐서 간장과 식초에 담금 | 3-6개월 |
| **발효 저장** | 3% 소금물에 담가 유산발효 | 3-6개월 |
| **기름 절임** | 데쳐 물기를 짜고 기름에 잠기게 담금 | 1-3개월 |
| **토굴 단기 보관** | 씻지 않고 종이나 마른 천에 싸서 12-15℃ 토굴에 | 5-7일 |

&nbsp;&nbsp;&nbsp;데쳐서 말리거나 절이는 편이 양송이에서 특히 유리합니다. 갈변을 일으키는 효소가 열에 파괴되므로, 끓는 물에 2-3분 데친 뒤 말리면 색이 훨씬 밝게 남습니다. 소금이나 식초를 조금 넣고 데치면 더 좋습니다. 연료를 조금 쓰는 대신 품질이 눈에 띄게 올라갑니다.

> **버섯 가루는 재난 상황에서 특히 값집니다.**
> 부피가 작고, 국물에 감칠맛을 내며, 곡물 가루에 섞어 단백질과 비타민 D를 보탤 수 있습니다. 말린 것이 부스러지기 시작하면 가루로 돌리는 것이 버리는 것보다 낫습니다.

## 14. 조리와 가공

### 14-1. 익혀 먹는 편이 낫습니다

&nbsp;&nbsp;&nbsp;양송이는 이 문서가 다루는 여섯 종 가운데 유일하게 생식이 가능한 버섯입니다. 평가표의 조리·가공 A가 그 사정을 담고 있습니다. 그러나 재난 상황에서는 익히는 편이 낫습니다. 이유가 셋입니다. 익히지 않으면 세포벽 속 영양소를 흡수하지 못합니다. 생것에는 소량의 아가리틴이 들어 있어 열로 줄이는 것이 안전합니다. 그리고 야생 개체라면 12절의 판별을 통과했더라도 반드시 익혀야 합니다.

| 조리 | 연료 | 시간 | 비고 |
|:---|:--:|:--:|:---|
| 굽기 | 적음 | 5-8분 | 잿불에 올려도 됩니다. 갓이 펴진 것은 특히 구이에 좋습니다 |
| 볶기 | 적음 | 5-8분 | 기름이 조금 있으면 맛이 크게 오릅니다 |
| 국·찌개 | 중간 | 10분 이내 | 국물에 감칠맛이 납니다 |
| 데치기 | 적음 | 2-3분 | 나물로 무치거나 절임의 앞 단계 |
| 생식 | 없음 | - | 기른 것만. 얇게 저며 소금과 기름에 무칩니다 |

&nbsp;&nbsp;&nbsp;갓이 펴진 큰 개체는 살이 두껍고 고기 비슷한 씹는 맛이 납니다. 단백질이 부족한 상황에서 씹는 만족감을 주는 식재료라는 점은 평가표의 맛 S에 반영되어 있습니다. 통째로 잿불에 얹어 소금만 뿌려도 한 끼 반찬이 됩니다.

### 14-2. 말린 것 쓰는 법

| 순서 | 방법 |
|:--:|:---|
| 1 | 미지근한 물에 20-30분 담가 불립니다 |
| 2 | **불린 물은 버리지 않습니다.** 감칠맛과 수용성 영양소가 녹아 있습니다 |
| 3 | 바닥에 가라앉은 모래를 피해 윗물만 국물로 씁니다 |
| 4 | 불린 버섯은 썰어 볶거나 국에 넣습니다 |
| 5 | 가루는 불리지 않고 바로 국물이나 반죽에 넣습니다 |

### 14-3. 곡물 부족을 메우는 조합

| 조합 | 효과 |
|:---|:---|
| **버섯 + 곡물 죽** | 곡물의 부족한 라이신을 버섯 단백질이 보탭니다 |
| **버섯 가루 + 밀가루·메밀가루** | 수제비나 칼국수 반죽에 섞어 단백질과 비타민 D를 올립니다 |
| **버섯 + 기름** | 비타민 D가 지용성이라 기름과 함께 먹으면 흡수가 좋아집니다 |
| **버섯 + 나물** | 미량 영양소 구성이 서로 다릅니다 |
| **버섯 + 감자·고구마** | 서류(덩이 줄기/뿌리)로 열량을 채우고 버섯으로 단백질을 댑니다 |

> **버섯은 열량원이 아니라 단백질과 미량 영양소의 보충원으로 쓰는 것이 맞습니다.**
> 양송이의 경우 그 뜻이 특히 분명합니다. 100g에 15kcal, 단백질 3.12g입니다. 열량 대비 단백질 비율 83.2%는 이 문서의 여섯 종 가운데 가장 높습니다. 곡물이나 서류(덩이 줄기/뿌리)로 열량을 채우고 양송이로 단백질과 비타민 D를 보태는 조합이 정확한 사용법입니다.

## 15. 연간 작업 일정

| 월 | 작업 |
|:--:|:---|
| 1월 | 볏짚과 분뇨 모으기. 패각과 달걀껍질을 구워 빻아 둡니다. 목틀과 재배사 보수 |
| **2월** | **봄 작형 1차 발효 시작.** 가퇴적과 본퇴적. 2-3일마다 뒤집기 |
| **3월** | **후발효와 접종.** 정열 60℃ 6시간. 암모니아 확인 후 종균 접종. 균사 배양 |
| **4월** | **복토와 발생.** 16-18℃. 환기를 열어 이산화탄소를 뺍니다. 월말에 첫 수확 |
| **5월** | **봄 작형 수확 절정.** 2-3주기. 즉시 볕 건조. **버섯파리가 급증하는 달이므로 방충망 점검** |
| 6월 | 봄 작형 마무리. 폐퇴비를 밭에 넣습니다. 균상과 재배사 세척 |
| 7월 | 더워서 기르지 않습니다. 볏짚과 분뇨 확보. 토굴이 있으면 계속 돌립니다 |
| **8월** | **가을 작형 1차 발효 시작.** 더운 계절이라 발열이 잘 됩니다 |
| **9월** | **후발효와 접종.** 균사 배양 |
| **10월** | **복토와 발생.** 첫 수확 |
| **11월** | **가을 작형 수확 절정.** 품질이 가장 좋은 시기. 대량 건조 |
| 12월 | 폐퇴비 정리. 포자 문양 점검. 말린 버섯 상태 확인 |

&nbsp;&nbsp;&nbsp;이 일정의 핵심은 **발효와 발생의 계절을 엇갈려 놓는다**는 점입니다. 퇴비 발효는 더울 때 잘 되고, 버섯 발생은 서늘할 때 잘 됩니다. 그래서 늦겨울과 늦여름에 발효하고 봄과 가을에 거둡니다. 한여름과 한겨울은 쉬는 계절이고, 그 자리를 여름에는 독청버섯아재비와 목이버섯, 겨울에는 팽이버섯이 메웁니다.

&nbsp;&nbsp;&nbsp;토굴이 있으면 계산이 달라집니다. 토굴은 사철 12-18℃이므로 연중 돌릴 수 있습니다. 다만 발효는 밖에서 해야 하므로, 밖에서 발효한 퇴비를 굴로 들여오는 방식이 됩니다. 한겨울에는 밖에서 발효가 잘 되지 않으므로 더미를 더 크게 쌓고 짚으로 두껍게 덮어 열을 지킵니다.

### 절대 잊지 말 것

|:--:|:---|
| 1 | **대 밑동을 파서 주머니가 없는지 확인합니다.** 주머니가 있으면 광대버섯류이고 한 개체로 사람이 죽습니다 |
| 2 | **버튼을 하나 쪼개 주름 색을 봅니다.** 연분홍이면 양송이, 끝까지 순백이면 먹지 않습니다 |
| 3 | **포자가 흰색이면 먹지 않습니다.** 양송이의 포자는 갈색에서 초콜릿 갈색입니다 |
| 4 | **자른 면이 노랗게 변하고 약품 냄새가 나면 먹지 않습니다** |
| 5 | **암모니아 냄새가 남은 퇴비에 접종하지 않습니다.** 종균이 그대로 죽습니다 |
| 6 | **복토 흙은 반드시 쪄서 씁니다.** 마른버섯병과 버섯파리가 흙으로 들어옵니다 |
| 7 | **퇴비 발효가 곧 살균입니다.** 장작을 태우지 않고 배지를 살균하는 유일한 버섯이라는 점이 이 버섯의 가장 큰 강점입니다 |
| 8 | **볕에 말릴 때 주름을 위로 향하게 놓습니다.** 비타민 D가 늘어납니다 |
| 9 | **말리면 저장성 문제가 사라집니다.** 생것 기준 E 등급에 속지 마십시오 |
| 10 | **광합성을 하지 않으므로 일사가 줄어드는 재난에서 흔들리지 않는 식량원입니다.** 태양광 SS는 빛을 잘 쓴다는 뜻이 아니라 빛 밖에 있다는 뜻입니다 |
| 11 | **실패해도 퇴비는 남습니다.** 다른 버섯에 없는 안전판입니다 |
