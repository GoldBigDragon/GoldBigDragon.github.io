## 5. 接種方法

&nbsp;&nbsp;&nbsp;接種は、キクラゲ栽培の成否が決まる一日です。原則は一つです。キクラゲの菌糸が雑菌より先に培地を占めるようにすることです。そのためには、種菌をたっぷりと、何か所にも、素早く入れ、その場所を塞がなければなりません。

### 5-1. 時期と天気

| 項目 | 基準 | 理由 |
|---|---|---|
| 原木への接種時期 | 韓国では3月末から5月初め | シイタケより遅い時期まで可能です |
| おがくず・段ボールへの接種 | 一年中可能 | 培地の温度さえ合えばよいです |
| 気温 | 日中15-25℃ | キクラゲはシイタケより暖かい条件を好みます |
| 天気 | 曇りで風のない日 | 晴れて風のある日は、空気中の胞子が多くなります |
| 時間帯 | 早朝または日没前後 | 乾燥と直射日光を避けるためです |

### 5-2. 原木の穴あけ

| 項目 | 基準 |
|---|---|
| 穴の直径 | 1-1.2cm |
| 穴の深さ | 1.5-2cm |
| 縦の間隔 | 5-8cm |
| 横の間隔 | 8-12cm |
| 配列 | ジグザグ |
| 穴の総数 | 直径10cm、長さ1mの原木で30-40個 |

&nbsp;&nbsp;&nbsp;キクラゲでは、シイタケより穴を浅く、密にあけます。キクラゲの子実体は原木の表面近くから出てくるため、菌糸が樹皮のすぐ下の層に均一に広がる方が有利です。深くあけると菌糸が心材の方へ行ってしまい、表面からの発生が減ります。

&nbsp;&nbsp;&nbsp;ジグザグに配列するのは、菌糸が縦方向にはるかに速く広がる性質があるためです。一列にきちんとそろえてあけると、その列に沿って帯状に下へ進み、列と列の間が長いあいだ空いたままになります。互い違いにあければ、原木全体がより均一に覆われます。

&nbsp;&nbsp;&nbsp;穴は多いほどよいです。接種点が多いと、何か所からも同時に伸びるため、雑菌が入り込む隙が減ります。種菌が足りないときは、穴の数を減らさず、原木の本数を減らします。中途半端に接種した十本より、きちんと接種した五本の方がましです。

### 5-3. 種菌の充填と密封

| 段階 | 方法 |
|---|---|
| 充填 | 穴に種菌を隙間なくぎっしり詰めます |
| 押し固め | 指や木の棒で押さえて固めます |
| 密封 | 木栓、発泡スチロール栓、またはロウ |
| ロウの配合 | パラフィンと松脂を6対4で溶かして使います |
| 切り口 | 原木の両端の切り口にも塗り、水分の蒸発を防ぎます |

&nbsp;&nbsp;&nbsp;ロウがないときは、泥を水で練って塗るか、木栓を打ち込んでその上に濡れた苔をかぶせます。完璧ではありませんが、何もしないよりはずっとましです。キクラゲはシイタケより湿った条件を好むため、密封が多少甘くても回復することがあります。

### 5-4. 種木を割る接種

&nbsp;&nbsp;&nbsp;市販の種菌がないときに使う方法です。菌糸が回った古い原木を斧で割り、長さ3cm、太さ1cm前後のくさびを作って、新しい原木の穴にハンマーで打ち込み、密封します。くさびは乾くと死んでしまうため、割ったらすぐに打ち込み、作業中は濡れた布で覆っておきます。

&nbsp;&nbsp;&nbsp;くさびには、白い菌糸がびっしり詰まった部分を選びます。木が柔らかくなって手で簡単に崩れる部分は、養分がすでに使い果たされているか、ほかの菌が入り込んだところです。割った断面からかび臭いにおいや酸っぱいにおいがしたら、その原木は使いません。

### 5-5. おがくず・段ボール培地への接種

| 項目 | 基準 |
|---|---|
| 培地の温度 | 25℃以下に冷ましてから。熱いうちに入れると種菌が死にます |
| 接種量 | 培地1kgあたり種菌50g前後 |
| おがくず方式 | 培地全体に均一に混ぜるか、上面にのせます |
| 段ボール方式 | 段ボール1枚ごとに種菌を散らし、重ねて積みます |
| 道具の消毒 | スプーンやトングを火で熱してから冷まして使います |
| 環境 | 風のない狭い空間。床と壁に水をまいて、ほこりを沈めます |

&nbsp;&nbsp;&nbsp;無菌室がないときのコツは、空気中のほこりを減らすことです。作業の30分前に部屋の床と壁に水をまき、ドアを閉め、中に入る人は一人だけにします。息を吐く方向が培地に向かないように顔をそむけ、話しません。これだけ守っても、汚染率は半分以下に下がります。

&nbsp;&nbsp;&nbsp;キクラゲには、培地全体に混ぜ込む混合接種がよく効きます。シイタケやヤマブシタケが一点から始まって広がるのに対し、キクラゲは複数の点から同時に始まるとはるかに速く、その分、雑菌に与える機会が少なくなります。

## 6. 菌糸の培養管理

&nbsp;&nbsp;&nbsp;接種が終わると培養が始まります。おがくず培地は約30日、原木は60-90日です。この期間の目標は、菌糸に培地全体を占めさせ、養分を蓄積させることです。人がすることは、温度を守り、光を遮り、汚染を見守る程度です。

### 6-1. 温度と湿度

| 時期 | 温度 | 湿度 | 管理 |
|---|:---:|:---:|---|
| 接種直後の3-5日 | 21-22℃ | 60-70% | 活着を促します。手を触れずそっとしておきます |
| 培養中期 | 21-25℃ | 60-70% | 菌糸の伸長が最も速くなります |
| 培養後期 | 21-22℃ | 60-70% | 培地全体が白く覆われます |
| 生長停止 | 0-3℃ | - | 死ぬことはなく、止まります |
| 危険温度 | 32℃以上 | - | 菌糸が弱り、雑菌が優勢になります |

&nbsp;&nbsp;&nbsp;培養中は光を遮ります。キクラゲは発生段階では光を必要としますが、培養段階では暗い方がよいです。明るい場所に置くと、菌糸が培地を覆いきる前に早まって子実体をつくろうとし、そうなると養分が足りず、小さくて薄いキノコが少し出て終わってしまいます。

&nbsp;&nbsp;&nbsp;キクラゲの菌糸は氷点下でも死にません。原木のまま露地で越冬でき、翌年に気温が上がると再び育ちます。評価表の耐寒性Aは、この事実を指しています。暖房が使えない災害時には大きな長所です。一方、高温にはシイタケよりやや強いものの、32℃を超えるとやはり危険です。

### 6-2. 原木の培養 - 伏せ込みと立てかけ

| 段階 | 時期 | 方法 |
|---|---|---|
| 仮伏せ | 接種直後から1か月 | 枕木の上に密に積み、わらや枝をかぶせます |
| 本伏せ | 1か月後から | 井桁状に間隔をあけて積み、空気が通るようにします |
| 天地返し | 1-2か月に1回 | 上下、内外の位置を入れ替えます |
| 立てかけ | 接種5-6か月後 | 斜めに交差させて立てかけます |
| 短木埋め | 接種後すぐ可能 | 20-30cmの短木を半分ほど地中に埋めます |

&nbsp;&nbsp;&nbsp;短木埋めは、キクラゲに特によく合う方法です。短く切った木に接種し、日陰の地面に半分ほど差し込んでおくと、地面から水分が絶えず上がってくるため、水やりの負担が大きく減ります。原木を持ち上げて立てる力や骨組みがない状況でも行えます。ただし、地面に接する面から土の中の雑菌が入るので、埋める前に下の部分を火で軽くあぶるか、石灰をまぶしておくとよいでしょう。

### 6-3. 水管理

| 時期 | 管理 |
|---|---|
| 培養中 | 原木が乾かない程度だけ。表面がじっとり湿っているとかえって雑菌を呼びます |
| 春と秋 | 2週間に1回、雨が降らなければたっぷり濡らします |
| 夏 | 7-10日に1回。日没前後に与えます |
| 冬 | 与えません |
| 判断 | 原木の切り口の細かいひび割れが大きく開いたら、水不足です |

### 6-4. 菌糸がきちんと育っているかを見分ける方法

| 観察 | 正常 | 異常 |
|---|---|---|
| 接種穴の周り | 白い菌糸が栓の隙間から透けて見えてきます | 緑色、黒色、オレンジ色なら汚染です |
| おがくず培地 | 接種7-10日で表面の半分が白くなる | 2週間たっても広がらなければ種菌の活力の問題 |
| 段ボール | 3-5日で1枚が覆われます | 最も速いです |
| 原木の切り口 | 3-5か月後に白い菌糸が現れます | 6か月たっても現れなければ活着失敗 |
| におい | ほのかなキノコの香り | 酸っぱいにおい、かび臭さ、アンモニア臭は異常 |
| 重さ | 原木が次第に軽くなります | 変わらなければ、菌糸が食べていないということです |

## 7. 発生の誘導

&nbsp;&nbsp;&nbsp;菌糸は居心地がよければ、伸び続けるだけです。キノコをつくるのは、菌糸にとって危機のサインです。ここの養分がもうすぐ尽きそうだから、胞子をつくって広がらなければならないと判断したときに、子実体ができます。キクラゲの場合、そのサインは湿度と光です。温度差や打撃よりも、この二つの方がずっと強く作用します。

### 7-1. キクラゲに合った刺激

| 刺激 | 方法 | 効果 |
|---|---|---|
| 湿度の上昇 | 培養時の湿度60-70%から、原基形成期の湿度85-95%に上げます | 最も強いサインです |
| 光を与える | 暗い培養室から、間接光の入る場所へ移します | 原基の形成を促し、色を濃くします |
| 切り込み | おがくず培地の表面や袋にナイフで十字の切り込みを入れます | その部分に子実体が集中して出ます |
| 浸水 | 原木を冷水に6-12時間浸けます | シイタケより短くします |
| 温度差 | 昼と夜の差を5-8℃にします | 補助的です |

&nbsp;&nbsp;&nbsp;キクラゲに最もよく効くのは、湿度と光の組み合わせです。培養が終わった培地を湿った場所に移し、間接光に当てると、3-7日以内に表面に半透明のゼリー状のしずくができます。これが原基です。シイタケのように、浸水や打撃のような強い刺激が必ずしも必要なわけではありません。

&nbsp;&nbsp;&nbsp;袋栽培では切り込みが重要です。袋を丸ごとはがしてしまうと水分が一気に抜けて表面が乾きます。袋をそのまま残し、ナイフで長さ3-5cmの十字または一文字の切り込みを5-8か所入れると、その部分だけから子実体が出て、形もよく、管理も楽になります。

### 7-2. 発生条件

| 項目 | 条件 | 備考 |
|---|---|---|
| 発生温度 | 20-28℃ | 15℃以下では遅く、30度を超えるとぶよぶよになります |
| 原基形成期の湿度 | 85-95% | 最も重要な条件です |
| 生育期の湿度 | 80%前後 | 原基形成期より少し下げます |
| 光 | 間接光。新聞が読める明るさ | 暗いと色が淡くなり、薄くなります |
| 換気 | 二酸化炭素がたまらないように | こもると厚みが薄くなります |

&nbsp;&nbsp;&nbsp;キクラゲが光を必要とするのは、光合成のためではなく、サインとして利用しているからです。暗い場所で育ったキクラゲは、淡い茶色で薄く、ぶよぶよと柔らかい状態で出てきます。光を十分に浴びたキクラゲは、濃い黒褐色で厚く、弾力があるように育ちます。厚みの違いは、そのまま貯蔵できる量と食感の違いになります。ただし、直射日光はいけません。乾きながら縁が内側に巻き込んでしまいます。

### 7-3. 水のやり方

| 方法 | 内容 |
|---|---|
| 噴霧 | 1日2-3回、霧のように吹きかけます。水流を直接当てると子実体がぶよぶよになります |
| 床を濡らす | 栽培場の床に水をまいて、空気中の湿度を上げます。最も安全な方法です |
| 覆う | 濡らした布やわら袋をかけて湿度を保ちます |
| 注意 | 子実体に水がたまっていると、細菌性の軟腐が起こります。換気と合わせて行う必要があります |

&nbsp;&nbsp;&nbsp;キクラゲは水が足りなくてもすぐには死なず、干からびて待ちます。この性質のおかげで管理は大らかでよいのですが、だからといって放置すると、薄くて硬いキノコが出ます。乾いては濡れてを繰り返させると、層ができて硬くなります。できるだけ生育期間中は、湿度を一定に保つ方が品質のためには良いです。

## 8. 収穫と再発生の周期

### 8-1. 収穫時期の判断

| 基準 | 内容 |
|---|---|
| 大きさ | 直径5-8cmに十分広がったとき |
| 縁 | 内側に巻いていたものが開いて、波打つようになったとき |
| 厚み | 最も厚いとき。それ以上置くと、薄くなりながらぶよぶよになります |
| 胞子 | 裏面に白い粉がつき始めたら、遅いです |
| 時間帯 | 早朝。昼に採ると水分が多くて乾かしにくくなります |

&nbsp;&nbsp;&nbsp;キクラゲは、収穫の適期を少し逃しても大きな損にはなりません。シイタケのように一日で品質が崩れることはなく、数日はもちます。ただし、胞子を飛ばし始めると、組織が薄くなってぶよぶよになります。裏面が白い粉でかすんで見えたら、その場ですべて採ります。

### 8-2. 採り方のコツ

&nbsp;&nbsp;&nbsp;株元をつかみ、左右にひねりながら外します。上に引っ張ると培地の表面まで一緒にはがれ、その傷から雑菌が入ります。株元が残ったらナイフの先でこそげ取ります。残った株元は腐って、細菌やハエを呼び寄せます。採ったキクラゲはすぐ日陰に広げ、その日のうちに乾燥を始めます。

&nbsp;&nbsp;&nbsp;一つの培地から出てくる大きさはそろいません。大きなものだけを選んで採り、小さなものは残しておけば育ち続けるので、一度に採ろうとせず、何日かに分けて採ります。これがキクラゲ収穫のコツです。

### 8-3. 休養と再発生

| 段階 | 期間 | 内容 |
|---|:---:|---|
| 収穫 | 10-20日 | 1回分の発生を、数日に分けて採ります |
| 乾燥休養 | 7-10日 | 水を止めて培地の表面を乾かします |
| 再刺激 | - | 再び湿度を上げて水を与えます |
| 再発生 | 7-14日 | 新しい原基ができます |

&nbsp;&nbsp;&nbsp;キクラゲを再び発生させるコツは、培地を一度乾かすことにあります。収穫後に水を止めて表面を1週間ほど乾燥させると、菌糸が危機を感じて再び原基をつくります。ずっと湿ったままにしておくと、細菌が広がって培地が傷みます。この乾燥と湿潤の繰り返しが、キクラゲ栽培のリズムです。

### 8-4. 方式別の周期と収量

| 方式 | 初収穫まで | 再発生の回数 | 総期間 |
|---|:---:|:---:|:---:|
| 段ボール | 30-40日 | 1-2回 | 2-3か月 |
| おがくず袋 | 50-60日 | 2-3回 | 3-4か月 |
| 原木 | 150-180日 | 毎年春と秋 | 3-4年 |
| 短木埋め | 120-150日 | 毎年 | 2-3年 |

&nbsp;&nbsp;&nbsp;原木1本あたりの総収量は、直径10cm、長さ1mの場合、3-4年間で生のキクラゲ1-1.5kg程度です。乾燥品では100-150gです。1人が継続的に食べるには、原木20-30本を回し、毎年6-8本ずつ新たに接種して世代を重ねておく必要があります。

> **キクラゲは三種類の培地を同時に回すのがよいでしょう。段ボールで1か月以内に初収穫を得て、おがくずでその年を乗り切り、原木で次の数年に備えます。**
