## 5. 接种方法

&nbsp;&nbsp;&nbsp;接种是决定木耳栽培成败的一天。原则只有一个：让木耳菌丝抢在杂菌之前占据培养基。为此，必须足量、多点、快速地放入菌种，并把接种处封好。

### 5-1. 时间与天气

| 项目 | 标准 | 原因 |
|---|---|---|
| 段木接种时期 | 韩国为3月底至5月初 | 比香菇可以接种到更晚 |
| 锯末·瓦楞纸接种 | 四季皆可 | 只要培养基温度合适即可 |
| 气温 | 白天15-25℃ | 木耳比香菇更喜欢温暖的条件 |
| 天气 | 阴天无风 | 晴天有风时，空气中的孢子较多 |
| 时间段 | 清晨或傍晚 | 避开干燥和直射阳光 |

### 5-2. 段木打孔

| 项目 | 标准 |
|---|---|
| 孔径 | 1-1.2cm |
| 孔深 | 1.5-2cm |
| 纵向间距 | 5-8cm |
| 横向间距 | 8-12cm |
| 排列 | 之字形交错 |
| 总孔数 | 以直径10cm、长1m的段木计，30-40个 |

&nbsp;&nbsp;&nbsp;木耳的打孔要比香菇更浅、更密。木耳子实体从段木表面附近长出，所以让菌丝均匀分布在紧贴树皮下的那一层更为有利。孔打得深，菌丝就会钻向心材，表面出耳随之减少。

&nbsp;&nbsp;&nbsp;采用之字形交错排列，是因为菌丝沿纵向蔓延的速度要快得多。如果孔排成整齐的一行，菌丝就会顺着这一行呈带状向下蔓延，行与行之间会长时间空着。错开打孔，整根段木就能被更均匀地覆盖。

&nbsp;&nbsp;&nbsp;孔越多越好。接种点多，就能从多处同时蔓延，杂菌可乘之机随之减少。菌种不够时，不要减少孔数，而要减少段木的根数。接种草率的十根，不如接种到位的五根。

### 5-3. 菌种填充与密封

| 步骤 | 方法 |
|---|---|
| 填充 | 将菌种严严实实地填满孔洞 |
| 压实 | 用手指或木棍按压压实 |
| 密封 | 木塞、泡沫塑料塞或封蜡 |
| 封蜡配比 | 将石蜡与松香按6比4熔化后使用 |
| 切面 | 段木两端的切面也要涂抹，防止水分蒸发 |

&nbsp;&nbsp;&nbsp;没有封蜡时，可把泥巴和成泥浆涂抹，或钉上木塞后在上面盖一层湿苔藓。虽然不够完美，但比什么都不做要好得多。木耳比香菇更喜欢潮湿的条件，所以即使密封稍有疏漏，也有可能恢复。

### 5-4. 种木劈楔接种

&nbsp;&nbsp;&nbsp;这是没有市售菌种时使用的方法。用斧头把菌丝已长满的旧段木劈开，做成长3cm、粗1cm左右的楔子，用锤子钉入新段木的孔中并密封。楔子变干就会死亡，所以劈开后要立即钉入，操作期间用湿布盖好。

&nbsp;&nbsp;&nbsp;楔子要挑选白色菌丝密集充满的部分。木质变软、用手一捏就碎的部分，是养分已经耗尽或已被其他菌侵入的地方。劈开的断面如有霉味或酸味，这根段木就不要使用。

### 5-5. 锯末与瓦楞纸培养基接种

| 项目 | 标准 |
|---|---|
| 培养基温度 | 冷却至25℃以下后再接种。趁热放入会使菌种死亡 |
| 接种量 | 每1kg培养基用菌种约50g |
| 锯末方式 | 与整个培养基均匀拌匀，或铺在表面 |
| 瓦楞纸方式 | 每张瓦楞纸上撒一层菌种，再层层叠放 |
| 工具消毒 | 勺子或夹子用火烧热后冷却再用 |
| 环境 | 无风的狭小空间。向地面和墙壁洒水，使灰尘沉降 |

&nbsp;&nbsp;&nbsp;没有无菌室时的要领是减少空气中的灰尘。作业前30分钟向房间地面和墙壁洒水，关上门，只允许一个人进入。呼气的方向不要朝向培养基，要把头转开，也不要说话。只要做到这些，污染率就能降到一半以下。

&nbsp;&nbsp;&nbsp;木耳适合采用与整个培养基拌匀的混合接种。香菇和猴头菇是从一个点开始蔓延，而木耳从多个点同时开始时要快得多，也就相应地减少了杂菌的可乘之机。

## 6. 菌丝培养管理

&nbsp;&nbsp;&nbsp;接种结束后，培养就开始了。锯末培养基约30天，段木为60-90天。这段时间的目标是让菌丝占满整个培养基并积累养分。人要做的只是控制温度、遮光、观察有无污染。

### 6-1. 温度与湿度

| 时期 | 温度 | 湿度 | 管理 |
|---|:---:|:---:|---|
| 接种后3-5天 | 21-22℃ | 60-70% | 促进定殖。不去触动 |
| 培养中期 | 21-25℃ | 60-70% | 菌丝伸长最快 |
| 培养后期 | 21-22℃ | 60-70% | 整个培养基被白色覆盖 |
| 生长停止 | 0-3℃ | - | 不会死亡，只是停止生长 |
| 危险温度 | 32℃以上 | - | 菌丝变弱，杂菌占上风 |

&nbsp;&nbsp;&nbsp;培养期间要遮光。木耳在出耳阶段需要光，但在培养阶段还是暗一些更好。放在明亮处，菌丝还没长满培养基就会急着形成子实体，结果养分不足，只长出少量又小又薄的耳片就结束了。

&nbsp;&nbsp;&nbsp;木耳菌丝在零下也不会死亡。段木可以在露地越冬，第二年气温回升后会继续生长。评价表中耐寒性的A，指的就是这一点。在无法取暖的灾难情境下，这是很大的优点。反过来，它对高温的耐受力比香菇稍强，但超过32℃同样有危险。

### 6-2. 段木培养 - 平放与竖立

| 步骤 | 时期 | 方法 |
|---|---|---|
| 临时平放 | 接种后至1个月 | 在垫木上紧密堆叠，盖上稻草或树枝 |
| 正式平放 | 1个月后起 | 以井字形疏松堆叠，使空气流通 |
| 翻堆 | 每1-2个月1次 | 上下、内外位置互换 |
| 竖立 | 接种5-6个月后 | 斜向交错竖立 |
| 短段木埋栽 | 接种后即可 | 将20-30cm的短段木埋入地下一半 |

&nbsp;&nbsp;&nbsp;短段木埋栽是特别适合木耳的方式。把接种后的短木段半截插入阴凉的地里，地下的水分会不断上升，浇水负担因此大大减轻。即使没有力气把段木抬起竖立，也没有支架，这种方式也能做到。不过，与地面接触的那一面会有土壤中的杂菌侵入，所以埋入前最好把下部在火上略微烤一下，或蘸上石灰。

### 6-3. 水分管理

| 时期 | 管理 |
|---|---|
| 培养期间 | 只要保持段木不干即可。表面总是湿漉漉的，反而会招来杂菌 |
| 春秋 | 每2周1次，不下雨时浇透 |
| 夏季 | 每7-10天1次，在傍晚浇 |
| 冬季 | 不浇 |
| 判断 | 段木切面的细裂纹明显张开，就说明缺水 |

### 6-4. 如何判断菌丝是否正常生长

| 观察项 | 正常 | 异常 |
|---|---|---|
| 接种孔周围 | 白色菌丝从塞子缝隙中透出来 | 出现绿色、黑色、橙色就是污染 |
| 锯末培养基 | 接种7-10天，表面一半变白 | 过了2周仍不蔓延，则是菌种活力有问题 |
| 瓦楞纸 | 3-5天长满一张 | 速度最快 |
| 段木切面 | 3-5个月后出现白色菌丝 | 过了6个月仍没有，则定殖失败 |
| 气味 | 淡淡的菌菇香 | 酸味、霉味、氨味均为异常 |
| 重量 | 段木逐渐变轻 | 若没有变化，说明菌丝没有取食 |

## 7. 诱导出耳

&nbsp;&nbsp;&nbsp;菌丝在舒适的环境中只会一味伸展。结出菇体，对菌丝来说是一个危机信号。当它判断这里的养分很快就要耗尽，必须产生孢子去扩散时，子实体才会形成。对木耳来说，这个信号就是湿度和光。比起温差或敲击，这两者的作用要强得多。

### 7-1. 适合木耳的刺激

| 刺激 | 方法 | 效果 |
|---|---|---|
| 提高湿度 | 把培养时的湿度60-70%，提高到原基形成期的湿度85-95% | 最强的信号 |
| 给予光照 | 从黑暗的培养室移到有散射光的地方 | 诱导原基形成，使颜色变深 |
| 划口 | 用刀在锯末培养基表面或菌袋上划十字口 | 子实体集中从划口处长出 |
| 浸水 | 将段木在冷水中浸泡6-12小时 | 比香菇的时间短 |
| 温差 | 使昼夜温差达到5-8℃ | 起辅助作用 |

&nbsp;&nbsp;&nbsp;对木耳最有效的是湿度与光的组合。把培养结束的培养基移到潮湿的地方，给予散射光，3-7天内表面就会出现半透明的胶冻状小滴。这就是原基。不像香菇那样，一定需要浸水或敲击之类的强烈刺激。

&nbsp;&nbsp;&nbsp;袋栽时，划口很重要。把整个菌袋剥掉，水分会一下子散失，表面就会变干。保留菌袋，用刀划出长3-5cm的十字口或一字口，共5-8处，子实体就只会从这些划口处长出，不仅形状好看，管理也更容易。

### 7-2. 出耳条件

| 项目 | 条件 | 备注 |
|---|---|---|
| 出耳温度 | 20-28℃ | 15℃以下生长缓慢，超过30度就会变软烂 |
| 原基形成期湿度 | 85-95% | 最重要的条件 |
| 生长期湿度 | 80%左右 | 比原基形成期略微调低 |
| 光 | 散射光。亮度以能读报纸为准 | 过暗则颜色变淡、变薄 |
| 通风 | 不要让二氧化碳积聚 | 滞留则厚度变薄 |

&nbsp;&nbsp;&nbsp;木耳需要光，不是为了光合作用，而是把光当作信号。在暗处长出的木耳呈淡褐色，又薄又软塌塌；见光充分的木耳呈深黑褐色，厚实而有弹性。厚度的差异，直接转化为可储存量和口感的差异。不过不能直射阳光，否则一干燥，边缘就会向内卷起。

### 7-3. 浇水方法

| 方法 | 内容 |
|---|---|
| 喷雾 | 每天2-3次，像雾一样喷洒。水流直接冲到子实体上，子实体会变软烂 |
| 地面洒水 | 向栽培场地面洒水，提高空气湿度。这是最安全的方法 |
| 覆盖 | 盖上湿布或草袋来保持湿度 |
| 注意 | 子实体上积水会引发细菌性软腐。必须同时通风 |

&nbsp;&nbsp;&nbsp;木耳缺水时不会马上死亡，而是干缩起来等待。正因为有这一特性，管理上比较宽松，但如果因此放任不管，长出的就会是薄而韧的耳片。反复干湿交替，会形成分层而变得更韧。尽可能在生长期间保持湿度均衡，对品质更有利。

## 8. 收获与再次出耳周期

### 8-1. 收获时机判断

| 标准 | 内容 |
|---|---|
| 大小 | 充分展开到直径5-8cm时 |
| 边缘 | 原本向内卷的边缘舒展开，呈波浪形时 |
| 厚度 | 最厚的时候。再放下去会变薄并软烂 |
| 孢子 | 腹面开始出现白粉，就说明已经晚了 |
| 时间段 | 清晨。白天采摘水分多，难以晒干 |

&nbsp;&nbsp;&nbsp;木耳即使稍微错过了最佳收获期，也不会有太大损失。它不像香菇那样一天之内品质就垮掉，能撑上几天。不过一旦开始散出孢子，组织就会变薄、变软烂。腹面看上去蒙着一层白粉时，就当场全部采下。

### 8-2. 采收要领

&nbsp;&nbsp;&nbsp;抓住基部，左右扭动着摘下。向上拔，会连培养基表面一起扯掉，杂菌就会从这个伤口侵入。基部若有残留，用刀尖刮掉。残留的基部腐烂后会招来细菌和苍蝇。摘下的木耳要立即摊放在阴凉处，当天就开始晾干。

&nbsp;&nbsp;&nbsp;同一培养基上长出的耳片大小不一。只挑大的采，小的留着会继续长，所以不要想一次采完，而要分几天陆续采收。这就是木耳采收的要领。

### 8-3. 养菌休整与再次出耳

| 步骤 | 时长 | 内容 |
|---|:---:|---|
| 收获 | 10-20天 | 把一次出耳的量分几天陆续采收 |
| 干燥休养 | 7-10天 | 停水，让培养基表面干燥 |
| 再次刺激 | - | 重新提高湿度并浇水 |
| 再次出耳 | 7-14天 | 长出新的原基 |

&nbsp;&nbsp;&nbsp;木耳再次出耳的要领，在于让培养基干一次。收获后停水，让表面干燥一周左右，菌丝就会感到危机，重新形成原基。如果一直保持潮湿，细菌就会蔓延，培养基就会变坏。这种干湿交替的反复，就是木耳栽培的节奏。

### 8-4. 各方式的周期与产量

| 方式 | 至首次收获 | 再次出耳次数 | 总时长 |
|---|:---:|:---:|:---:|
| 瓦楞纸 | 30-40天 | 1-2次 | 2-3个月 |
| 锯末菌袋 | 50-60天 | 2-3次 | 3-4个月 |
| 段木 | 150-180天 | 每年春秋 | 3-4年 |
| 短段木埋栽 | 120-150天 | 每年 | 2-3年 |

&nbsp;&nbsp;&nbsp;每根段木的总产量，以直径10cm、长1m计，3-4年间约为鲜木耳1-1.5kg。折成干品为100-150g。若要让一个人持续食用，需要轮换使用段木20-30根，并且每年新接种6-8根，使各代段木相互衔接。

> **木耳最好同时轮流使用三种培养基。用瓦楞纸在一个月内获得首次收获，用锯末度过当年，用段木为之后的几年做准备。**
