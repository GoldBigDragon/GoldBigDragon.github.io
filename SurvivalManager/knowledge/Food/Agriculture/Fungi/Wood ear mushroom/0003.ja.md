## 3. 培地の材料と準備

&nbsp;&nbsp;&nbsp;キクラゲは、材料を最も選ばない栽培キノコの一つです。原木、おが粉、稲わら、籾殻、そして廃段ボールまで受け入れます。評価表のキノコ副産物適応性Bは、この幅を指しています。電気が止まった状況では、この幅がそのまま生存確率になります。ナラ類がなければクワを、おが粉がなければ箱を使えるという意味だからです。

> **キクラゲの強みは収量ではなく、選択肢の数です。一つが行き詰まっても、別の材料に切り替えられます。**

### 3-1. 原木の選び方

| 項目 | 基準 | 理由 |
|---|---|---|
| 最適な樹種 | クワ、ハンノキ類、ナラ類 | キクラゲが自然界で最もよく発生する木だからです |
| 使える樹種 | ヤナギ、ポプラ、エノキ、ニセアカシア | 柔らかいですが、よく発生します。その代わり寿命が短いです |
| 使ってはいけない樹種 | マツ、チョウセンゴヨウなどの針葉樹 | 樹脂とテルペンが菌糸を抑制します |
| 直径 | 8-15cm | シイタケより細い木も使います |
| 長さ | 1-1.2m、または20-30cmの短木 | 短木を地面に立てて埋める方式も可能です |
| 伐採時期 | 韓国では11月から2月 | 樹液が下がった後 |
| 乾燥 | 1-2か月 | シイタケより短く乾かします |

&nbsp;&nbsp;&nbsp;キクラゲの原木は、シイタケほどからからには乾かしません。シイタケが含水率38-42%を求めるのに対し、キクラゲは40-45%でもよく活着します。キクラゲの菌糸が、シイタケより湿った条件に耐えられるからです。ただしこれは雑菌にも有利な条件だという意味でもあるため、接種量をたっぷり入れて、菌糸が先に定着するようにすることがいっそう重要になります。

&nbsp;&nbsp;&nbsp;木が柔らかいほど、早く発生し、早く終わります。ヤナギやポプラに接種すると5-6か月で発生しますが、2年で原木が尽きます。ナラ類は初収穫が遅い代わりに、3-4年もちます。災害時には、両方を混ぜて用意しておくのが安全です。柔らかい木で今年をしのぎ、硬い木で次の数年に備えます。

### 3-2. おが粉培地

| 材料 | 割合 | 役割 |
|---|:---:|---|
| 広葉樹のおが粉（ナラ類、ポプラ） | 85-90% | 主な炭素源 |
| 米ぬか | 5-10% | 窒素とビタミンの供給源 |
| 炭酸カルシウムまたは貝殻粉 | 1% | pH調整 |
| 水分 | 65-70% | 握ったとき、指の間から水が1、2滴にじむ程度 |
| 培地量 | 袋当たり1.2-1.5kg | |

&nbsp;&nbsp;&nbsp;キクラゲは米ぬかの量が少なくて済みます。シイタケやヤマブシタケが20-30%を入れるのに対し、キクラゲは5-10%で十分です。これは災害時に決定的な利点になります。米ぬかは人も食べられ、家畜も食べる資源なので奪い合いが激しいのですが、キクラゲはそれをほとんど必要としません。しかも栄養の多い培地ほど雑菌が群がるため、米ぬかが少ないということは、汚染に強いという意味でもあります。

### 3-3. 廃段ボール培地 - 災害時の隠れた資源

&nbsp;&nbsp;&nbsp;段ボールは、木材パルプをほぐして再び圧縮したものです。キクラゲにとっては、すでに細かく砕かれた木です。物流が途絶えると、箱は余り、使い道はなくなります。それを食料に変えられるという点で、段ボール培地は災害時にとくに適しています。

| 段階 | 方法 |
|---|---|
| 選別 | 印刷が少なく、コーティングされていない茶色の段ボールを使います。光沢紙とビニールコーティングは除きます |
| テープの除去 | 粘着テープ、ホチキスの針、ラベルをすべてはがします |
| 切断 | 手のひらほどの大きさに裂くか、5cm幅に切ります |
| 浸漬 | 沸騰させた湯を注いで1-2時間浸すか、石灰水に12時間浸します |
| 絞り | 水がぽたぽた垂れない程度に絞ります |
| 接種 | 段ボールの間に種菌を挟み、層状に重ねていきます |
| 詰め込み | 袋や容器に押し込んで詰め、穴をあけて空気が通るようにします |

&nbsp;&nbsp;&nbsp;段ボールは波形の中に空気の層があるため、菌糸がその隙間に沿って非常に速く広がります。キクラゲの菌糸が段ボール1枚を覆うのに、3日あれば十分です。その代わり養分が少なく、収量はおが粉培地の半分ほどで、1、2回発生すると終わります。それでも、種菌を増やす用途には優れています。段ボールで菌糸を大量に育てたあと、それを原木やおが粉培地の種菌として使う方法が、実務上役に立ちます。

### 3-4. わら系の培地

| 材料 | 処理 | 備考 |
|---|---|---|
| 稲わら、麦わら | 5cm以下に切って煮るか、石灰に浸す | 単独では収量が低いため、おが粉と半々に混ぜます |
| 籾殻 | 水に浸して煮る | 通気性がよいです。30%まで代替できます |
| トウモロコシの茎 | 砕いて煮る | 養分が比較的多いです |
| 豆殻 | 砕いて煮る | 窒素源の役割を果たします。20%以下で使います |

### 3-5. 電気なしで培地を殺菌する4つの方法

&nbsp;&nbsp;&nbsp;オートクレーブ（高圧蒸気滅菌器）は、121℃で90分かけて、細菌の胞子まで殺します。電気と圧力容器の両方が必要です。それがないときは、完全な滅菌ではなく、競合する菌の数を十分に減らしてキクラゲの菌糸が先に定着できるようにする、低温殺菌を目標にします。

#### 3-5-1. ドラム缶による蒸気殺菌

| 項目 | 方法 |
|---|---|
| 準備物 | 200Lの鉄製ドラム缶、ふた、台（れんがや焼き網）、薪 |
| 水 | 底から20-30cm |
| 積み込み | 台の上に培地の袋や麻袋をゆるく積み、蒸気が回る隙間を残します |
| 密閉 | ふたをして、濡らしたわら袋やビニールで包みます |
| 加熱 | 蒸気が缶内に満ちてから4-6時間 |
| 判定 | 培地の中心部に刺しておいた木串を抜いたとき、握っていられないほど熱い |
| 冷却 | ふたをしたまま一晩。熱いうちに開けると、空気とともに胞子が吸い込まれます |

&nbsp;&nbsp;&nbsp;キクラゲは培地を濃厚にしてもよく育つわけではないため、かえって殺菌の負担は小さくなります。おが粉に米ぬかを5%だけ入れた培地は雑菌のえさも少なく、蒸気4時間で失敗率は十分に低くなります。

#### 3-5-2. 熱湯浸漬

&nbsp;&nbsp;&nbsp;わらや段ボールに使う、最も単純な方法です。釜で湯を沸かし、材料を入れて1-2時間煮ます。引き上げて水気を絞り、含水率65-70%、温度30度以下まで冷ましてから接種します。道具が釜一つだけで済むことが強みで、燃料がたくさん必要なことが弱みです。絞る道具や冷ます床も、あらかじめ熱湯で洗っておかなければなりません。

#### 3-5-3. 石灰浸漬 - 燃料がまったく要らない方法

| 項目 | 方法 |
|---|---|
| 配合 | 水100Lに消石灰1-1.5kg、または生石灰0.5-1kg |
| pH | 12-13。手に触れるとぬるぬるする強アルカリ |
| 浸漬 | 切ったわらや段ボールを完全に沈めて12-24時間 |
| 水切り | 引き上げて6-12時間水を切り、含水率65-70%に調整します |
| 接種 | すすぎません。残ったアルカリが雑菌を抑え続けます |

&nbsp;&nbsp;&nbsp;石灰浸漬は、キクラゲと段ボール培地の組み合わせにとくによく合います。段ボールは煮るとぐずぐずになって扱いにくくなりますが、石灰水の中では形を保つからです。火をまったく使わないという点が何より大きな利点です。石灰がない場合は、草木灰を水に溶かして1日置き、上澄みだけを取った灰汁で代用できますが、pHが低く、仕込みごとのばらつきが大きいため、成功率は下がります。

#### 3-5-4. 稲わらの発酵

&nbsp;&nbsp;&nbsp;わらを水で湿らせて高さ1-1.5mに積むと、好熱性微生物が自ら発熱し、山の中が60-70℃に達します。2-3日おきに切り返しながら2-3週間置くと、雑菌が食べやすい糖分が先に消費し尽くされ、選択的な培地になります。殺菌ではなく、えさを先になくす方式です。キクラゲ単独の培地としては収量が低いのですが、おが粉と半々に混ぜるときにわら側をこの方式で処理すれば、燃料を大きく節約できます。

### 3-6. 電力なしの殺菌法の比較

| 方法 | 燃料 | 所要時間 | 成功率 | 適した培地 |
|---|:---:|:---:|:---:|---|
| 原木栽培（殺菌不要） | なし | なし | 最も高い | 丸太 |
| ドラム缶蒸気 | 多い | 4-6時間 + 冷却 | 高い | おが粉、わら、段ボール |
| 熱湯浸漬 | 多い | 1-2時間 + 冷却 | 中程度 | わら、籾殻、段ボール |
| 石灰浸漬 | なし | 12-24時間 | 中程度 | わら、段ボール |
| 稲わらの発酵 | なし | 2-3週間 | 中程度 | わら、堆肥 |

## 4. 種菌の確保

&nbsp;&nbsp;&nbsp;キノコには種がありません。種苗店が閉まれば種を買う場所がなくなり、種を採って壺にしまっておくという方法も通用しません。しかし菌類には、植物にはない3つの道があります。胞子を採って保存する道、生きたキノコの肉を切り取ってそのまま育てる道、菌糸が広がった木を割って新しい木に移す道です。キクラゲはこの3つがすべてよく効きます。自家採種のSは、その結果です。

### 4-1. 胞子の採取と胞子紋

| 段階 | 方法 |
|---|---|
| 対象の選定 | 縁がちょうど開いたばかりの、新鮮で厚い個体を選びます |
| 切り離し | 木に付いた付け根から、慎重にはがします |
| 受け台 | なめらかな子実層の面を下に向けて、アルミホイルの上に載せます |
| 覆い | 器をかぶせて風を防ぎます |
| 放置 | 涼しい場所に24時間 |
| 回収 | 子実体を持ち上げると、白い胞子の粉が残ります |

&nbsp;&nbsp;&nbsp;紙よりアルミホイルのほうが優れています。紙は湿気を吸い込み、繊維の間に雑菌が潜みます。ホイルは水分を吸収せず、表面がなめらかなので、胞子をそのまま保てます。ホイルがなければ、ガラス板が次善の選択です。

&nbsp;&nbsp;&nbsp;キクラゲは、ほかのキノコより胞子を採るのが難しいキノコです。子実体がゼラチン質のため、乾きながら縮み、その過程でホイルに貼り付いてしまうからです。子実体の下に箸を2本かませて少し浮かせておくと、貼り付かずに胞子だけが落ちます。

&nbsp;&nbsp;&nbsp;胞子を採ったあとは、ホイルごと風通しのよい日陰にもう1日置いて、わずかな湿気まで飛ばします。そのあとホイルを半分に折って、胞子の面を内側にして保護し、ジッパー付き袋に入れます。しっかり炒った塩や炭の欠片も一緒に入れて、湿気を吸わせます。ジッパー付き袋をガラス瓶にまとめ、蜜蝋で封をして、四季を通じて温度が一定の土室や地下室に置きます。紫外線が胞子のDNAを破壊するため、光が入らないようにしなければなりません。

| 保存形態 | 寿命 | 備考 |
|---|:---:|---|
| 胞子紋（ホイル乾燥） | 5-10年以上 | 水分が完全に排除され、細胞の活動が止まります |
| 液体種菌（滅菌水懸濁） | 3-6か月 | 冷蔵がないと早期に発芽したり、細菌が増殖したりします |
| 接種済み種菌（おが粉・種木） | 約1年 | 生きた菌糸なので、養分を使い続けます |

> **災害時に胞子を液体で保管してはいけません。必ず、乾燥させた胞子紋の形で置いておく必要があります。**

&nbsp;&nbsp;&nbsp;胞子と植物の種子で寿命が違うのは、構造に由来します。トマトの種子は胚と栄養物質を抱えているため、時間がたつと自ら養分を消費して老化し、死んでしまいます。室温で2-4年です。キノコの胞子は厚い細胞壁に包まれた単一の細胞にすぎず、消費する養分がありません。条件さえ合えば5-10年もち、学界では数十年前の胞子をよみがえらせた事例も珍しくありません。

| 比較項目 | トマトの種子 | キノコの胞子 |
|---|---|---|
| 平均寿命（室温） | 約2-4年 | 約5-10年以上 |
| 弱点となる要因 | 温度変化、自身の栄養の枯渇 | 湿気によるカビの汚染 |
| 細胞構造 | 複雑な胚と栄養物質 | 単一の細胞と厚い保護壁 |

&nbsp;&nbsp;&nbsp;災害の1年目に、最も大きく健康な子実体が出たときに、胞子紋を20-30枚まとめて作り、土室に貯えておくことが重要です。毎年菌糸をつないでいく途中で汚染によって失敗しても、5年後、10年後に取り出して、いつでもやり直せる安全装置になります。

### 4-2. 胞子から種菌をつくる - 稲わら加熱培地法

&nbsp;&nbsp;&nbsp;理論上は、胞子を滅菌した培地にまけば菌糸が伸びます。しかし現実には、空気中のアオカビと細菌が、キノコの胞子より数百倍も速く培地を占領します。栄養価の高い培地ほど、より脆弱です。電気がない状況では、栄養が過剰な人工培地の代わりに、自然の防御力を利用した原始的な培地を使います。

| 段階 | 方法 |
|---|---|
| 煮る | 稲わらや麦わらを沸騰した湯で1時間以上じっくり煮ます |
| 絞り | 引き上げて水気を絞り、手で触れられるまで冷まします |
| まく | 保管しておいた胞子の粉を、惜しまずにむらなくたっぷりまきます |
| 覆い | 清潔な布をかぶせて、風と落下してくる胞子を防ぎます |
| 培養 | 21-25℃の暗所で2-4週間。白い菌糸がわらを覆えば成功です |

&nbsp;&nbsp;&nbsp;胞子を惜しんで1粒ずつ落とすと、一次菌糸だけが育って死滅します。交配型の異なるもの同士が出会って二次菌糸になってはじめてキノコが生えるので、数多くの胞子を一度に振り入れて、培地のなかで互いに相手を見つけさせなければなりません。キクラゲは段ボールでも同じ方法がよく効きます。煮て冷ました段ボールの間に胞子の粉をまいて、重ねておけばよいのです。

### 4-3. 組織培養 - 最も確実な方法

&nbsp;&nbsp;&nbsp;生きた新鮮なキノコが手元にあるなら、胞子を使う理由はほとんどありません。キノコの内部の肉は、すでに雌雄の結合を終えた二次菌糸のかたまりです。その断片を切り取って培地に入れれば、発芽と交配の過程を飛ばして、すぐに菌糸が伸びます。

| 段階 | 方法 |
|---|---|
| 選定 | 厚みと弾力のある新鮮な個体。乾いたものや軟らかくなったものは使いません |
| 消毒 | ナイフを火で熱して冷ますか、沸騰した湯に浸してから取り出します |
| 裂く | 子実体を手で裂いて、厚み方向の断面を新しく露出させます |
| 採取 | 断面の真ん中の肉を、米粒ほどの大きさに切り取ります |
| 接種 | 煮て冷ました稲わら、おが粉、段ボールの間に挟みます |
| 培養 | 21-25℃の暗所。3-5日で断片の周りに白い綿毛状の菌糸が広がります |

&nbsp;&nbsp;&nbsp;裂くことが重要です。キノコの表面にはさまざまな胞子が付いていますが、内部は無菌に近い状態です。手で裂くとその清潔な面が新たに露出し、そこから切り取った断片は、別途消毒しなくても純粋な菌糸になります。キクラゲは組織が丈夫で裂けにくいので、乾いた手で両端を持ち、ゆっくり引っ張ります。

### 4-4. 原木種菌をつなぐ

&nbsp;&nbsp;&nbsp;キクラゲが自家採種でSを得たのは、この方法のおかげです。キノコがよく出た原木は、それ自体が巨大な種菌のかたまりです。

| 方式 | 方法 | 備考 |
|---|---|---|
| 種木を割る | 菌糸が広がった原木を割って指の太さの楔を作り、新しい原木の穴に打ち込みます | 最も確実です |
| おが粉にすり込む | 菌糸が広がった木を砕き、煮て冷ました新しいおが粉や段ボールに混ぜます | 量を増やすのに向いています |
| 培地片の移植 | 菌糸が広がった段ボール1枚を、新しい段ボールの山の中に挟みます | 最も手軽です |
| 自然感染 | 発生中の原木のすぐ横に、新しい原木をくっつけて立てておきます | 補助的な手段です |

&nbsp;&nbsp;&nbsp;割った種木は、乾くと死んでしまいます。割ったその場ですぐに打ち込み、接種穴を密封しなければなりません。曇りの日や早朝の、風のないときに作業するのがよいです。1本から得た楔で新しい原木5-10本を埋められるので、よく発生する原木を毎年1本ずつ犠牲にすれば、種菌の供給が途切れません。

> **キクラゲ栽培で最も価値のある財産は、キノコではなく、菌糸がびっしり回った原木と段ボールの山です。それが次の世代の種です。**
