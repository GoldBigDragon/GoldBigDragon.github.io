## 9. 污染与病虫害

&nbsp;&nbsp;&nbsp;在灾难情境下，蘑菇栽培失败的头号原因既不是病害也不是虫害，而是竞争性霉菌。其中又以绿霉，准确地说是木霉属（Trichoderma）真菌最为突出。木耳菌丝每天伸长3-4mm时，木霉能伸长其两三倍。在争夺培养基的竞赛中一旦落败，就没有挽回的办法。

### 9-1. 如何识别绿霉

&nbsp;&nbsp;&nbsp;最大的陷阱在于，木霉最初也是以白色绒毛的形态开始的。接种后的最初几天，用肉眼无法将它与木耳菌丝区分开。要到3-5天之后才能区分。

| 观察项目 | 木耳菌丝 | 木霉 |
|---|---|---|
| 颜色变化 | 始终保持白色 | 由白色经淡黄色转为亮绿色、青绿色 |
| 生长速度 | 每天3-4mm | 每天7-10mm。明显偏快 |
| 边缘 | 绒毛整齐、均匀地扩展 | 呈放射状如扇骨般扩展，并形成同心圆纹 |
| 质地 | 棉絮状或霜状 | 起初为棉絮状，之后变成粉末结成的团块 |
| 培养基表面 | 无变化 | 有时会出现带水汽的透明条带 |
| 气味 | 淡淡的菌菇香 | 类似椰子的甜味，或潮湿的霉味 |

&nbsp;&nbsp;&nbsp;看到绿色的那一刻，已经产生了数亿个孢子。判断必须在颜色出现之前，依据速度和边缘形状作出。如果接种第三天时，某一处特别快地蔓延，那就不是木耳。

### 9-2. 其他污染菌的区分

| 污染菌 | 颜色与形态 | 条件 | 危险程度 |
|---|---|---|:---:|
| 木霉（绿霉） | 亮绿色、青绿色。蔓延迅速 | 高温、过湿、酸性 | 极高 |
| 青霉 | 青绿色，但粉末更细，边缘有白色条带 | 低温、潮湿 | 高 |
| 脉孢菌（红色面包霉） | 鲜艳的橙色。爆发式蔓延 | 高温高湿 | 极高 |
| 毛霉、根霉 | 灰色绒毛上嵌有黑点 | 培养基含水率过高 | 中等 |
| 曲霉 | 黑色、黄色粉末 | 高温干燥 | 高 |
| 细菌性黏液 | 黏稠的黏液和酸臭味 | 过湿、通气不良 | 中等 |

> **发现橙色脉孢菌时，千万不要打开菌袋。其孢子极轻，一旦飞散，整个培养室都会全军覆没。连袋一起烧掉，或深埋入地下。**

&nbsp;&nbsp;&nbsp;木耳使用含水率高的培养基，所以毛霉和细菌性黏液比香菇更常出现。培养基表面发黏并有酸味，就说明水分过多。这时增加菌袋上的孔以通风，并减少浇水，有时可以恢复。与霉菌污染不同，细菌性问题如果及早处理，是可以挽回的。

### 9-3. 发生污染时的处理

| 情况 | 处理 |
|---|---|
| 锯末菌袋污染 | 不要打开，连袋一起搬出培养室。焚烧，或埋入50cm以上的深度 |
| 瓦楞纸堆污染 | 只抽出被污染的那几张，其余的移到干燥处。瓦楞纸是分层的，可以部分挽救 |
| 段木接种孔污染 | 拔出塞子，剜去污染部分，涂上石灰水，放入新菌种后重新封好 |
| 段木表面大面积污染 | 蘸上石灰粉，与其他段木隔开1m以上 |
| 段木内部也呈绿色 | 无法恢复。取出烧掉 |
| 作业工具 | 用沸水浸泡，或用火烧 |

&nbsp;&nbsp;&nbsp;把被污染的培养基直接扔进堆肥场，那里就会变成孢子工厂。至少要用沸水煮30分钟杀灭菌体后，再拿去堆肥。能烧就烧，是最可靠的办法。

### 9-4. 预防就是一切

| 预防手段 | 内容 |
|---|---|
| 接种量 | 足量、多点。木耳适合混合接种 |
| 尽量少用米糠 | 培养基营养越少，杂菌也就越没有可吃的东西 |
| 含水率 | 不要超过65-70%。水多时，细菌会先出现 |
| 培养温度 | 21-22℃。超过25℃，木霉就占优势 |
| pH | 用石灰把培养基pH调高到6.5-7。木霉喜欢酸性 |
| 通气 | 培养基不要压得太实，并在菌袋上打孔 |
| 清洁 | 不要把菌糠和蘑菇基部放在栽培场附近 |

### 9-5. 害虫

| 害虫 | 危害 | 不用药剂的应对 |
|---|---|---|
| 菇蝇 | 幼虫啃食菌丝和子实体 | 防虫网、涂有树脂或饴糖的粘虫板、立即清除菌糠 |
| 螨虫 | 取食菌丝并传播杂菌 | 保持湿度稳定，将出虫的培养基隔离 |
| 跳虫 | 啃咬菌丝表面 | 清除地面落叶，撒草木灰 |
| 蛞蝓 | 特别喜欢胶质，啃食严重 | 夜间用手捕捉。用草木灰或锯末带阻止其靠近 |
| 贮藏害虫 | 干木耳会招来烟草甲、印度谷螟 | 充分干燥、密闭，同时放入炒过的盐或木炭 |

&nbsp;&nbsp;&nbsp;蛞蝓在木耳栽培中尤其令人头疼。胶质柔软、水分多，比其他蘑菇更容易被啃食。在栽培场周围撒一圈宽5cm的草木灰带，能相当有效地阻挡。下雨后需要重新撒。

## 10. 生长异常诊断

| 症状 | 原因 | 处理 |
|---|---|---|
| 接种后菌丝不蔓延 | 培养基温度过高、菌种活力下降、含水率不足 | 将温度降到21-22度并重新接种 |
| 菌丝已长满却不出耳 | 湿度不足、光照不足 | 将湿度提高到85-95%，并移到有散射光的地方 |
| 子实体又薄又色浅 | 光照不足、二氧化碳过多 | 提高亮度并通风 |
| 子实体发韧且分层 | 反复干湿交替 | 生长期间保持湿度均衡 |
| 子实体边缘向内卷 | 直射阳光、干燥的风 | 遮光并喷雾 |
| 子实体变软烂并有恶臭 | 过湿、通气不良、细菌性软腐 | 停止浇水并通风。病株立即清除 |
| 培养基表面板结变硬 | 过度干燥、菌丝老化 | 刮去表面，浇水后重新刺激 |
| 培养基软塌且发酸 | 含水率过高导致细菌增殖 | 增加孔数并停水。严重时废弃 |

&nbsp;&nbsp;&nbsp;蘑菇的缺乏与过量这一概念，其运作方式与旱田作物不同。培养基中的养分在接种时就已确定，之后无法再追加。因此，生长异常的原因大多不在养分，而要从水、空气、温度、光这四个环境因素中去找。

## 11. 栽培场地布局与菌糠循环

### 11-1. 不要连续使用同一块场地

&nbsp;&nbsp;&nbsp;评价表中连作适应性的A，是附带了“更换段木时要换布置场地”这一条件的评级。竖放过几年段木的地方，会积累掉落的孢子、有机物和死亡的菌丝，木霉和菇蝇就会在其上定居。把新段木竖在同一个地方，污染率会明显上升。用过一次的场地，要让它休息2-3年。

### 11-2. 选择栽培场地的标准

| 项目 | 有利条件 | 应避免的条件 |
|---|---|---|
| 遮荫 | 阔叶林下遮光60-70% | 完全黑暗、直射阳光 |
| 风 | 微风徐徐通过的地方 | 山谷风猛烈吹袭的地方、无风的地方 |
| 水 | 靠近溪流或水井的地方 | 需要提水运来的地方 |
| 地形 | 缓坡的北坡或东坡 | 朝南的陡坡、积水的洼地 |
| 可达性 | 每天都会经过的路口 | 容易错过出耳期的偏僻处 |

&nbsp;&nbsp;&nbsp;木耳比香菇更喜欢明亮的地方。香菇需要70%的遮光，而木耳以60%左右为宜。光照不足，长出的就会颜色浅而且薄。即使在同一片林子里，也最好把稍微开阔一点的地方留给木耳。

### 11-3. 废段木与菌糠的用途

| 用途 | 方法 |
|---|---|
| 菌种原料 | 劈取菌丝仍然存活的部分，用于新段木或瓦楞纸的接种 |
| 堆肥 | 粉碎后的废段木，木质素已经分解，接近腐叶土 |
| 其他蘑菇的培养基 | 大球盖菇可以直接利用木耳的废段木和菌糠 |
| 覆盖材料 | 盖在蔬菜畦上，可抑制杂草并保住水分 |
| 家畜垫料 | 废瓦楞纸培养基吸水性好，用作垫料后还可以拿去堆肥 |

## 12. 误认毒蘑菇与安全确认

### 12-1. 误认风险最低的蘑菇

&nbsp;&nbsp;&nbsp;木耳属（Auricularia）中没有已知的剧毒种。附生在树上、呈胶质耳状的形态本身，与具有菌盖、菌柄和菌褶的普通蘑菇截然不同，因此几乎没有可能与鹅膏菌类这样的致命毒蘑菇混淆。如果不得不进行野外采集，木耳属于最安全的选择之一。

| 类别 | 木耳 | 可能混淆的种类 |
|---|---|---|
| 组织 | 胶质。按压后松开会恢复原状 | 黑胶耳类同样是胶质，但更黑更小，味道也不好 |
| 形态 | 耳状或贝壳状，有浅浅的脉纹 | 银耳呈花瓣状聚成一团，同样可食用 |
| 下表面 | 光滑而有光泽 | 有褶皱或孔洞的就不是木耳 |
| 干燥状态 | 干后硬结如黑色痂皮，用水泡几小时就会膨胀 | 用水泡后也不膨胀、仍然很硬的是木质蘑菇，不要食用 |
| 生长位置 | 枯死阔叶树的枝干上 | 长在地上的不是木耳 |

> **用水泡后不膨胀、仍然硬邦邦的黑色块状物不是木耳。仅凭这一项确认，就能排除大多数误认。**

### 12-2. 保存与泡发

&nbsp;&nbsp;&nbsp;木耳真正让人受到严重伤害的情形，并不是误采了毒蘑菇，而是干木耳泡发不当。这一点是其他任何蘑菇文档中都没有的木耳特有的风险，务必要了解。

&nbsp;&nbsp;&nbsp;把干木耳泡在微温的水中，在室温下放置很久，尤其是超过一天，水中的细菌就会繁殖。其中某种细菌产生的毒素耐热性极强，煮沸也无法消除，会攻击肝脏和肾脏，致死率很高。在中国，曾多次报告死亡事故。问题在于，这样变质的木耳几乎没有异味，味道也看不出异常。外观上完好无损。

| 规则 | 内容 |
|---|---|
| 泡发时间 | 冷水2-3小时，温水30分钟左右。不要超过这个时间 |
| 水温 | 尽量用冷水泡发。微温的水最利于细菌繁殖 |
| 隔夜放置 | 不可以。夏季尤其绝对禁止 |
| 泡发后 | 立即烹饪。不要泡发后搁置数小时 |
| 剩余部分 | 泡发后剩下的，即使可惜也要丢弃 |
| 凭气味判断 | 行不通。以时间为判断标准 |

> **木耳最大的风险不是毒蘑菇，而是泡得太久的泡发水。严格遵守时间，是唯一的防线。**

### 12-3. 其他注意事项

| 项目 | 内容 |
|---|---|
| 生吃 | 不加热就大量食用，有时会引起光敏性皮炎。受到日晒的部位会肿胀发痒。加热后即可消除 |
| 消化 | 膳食纤维多，突然大量食用会引起腹痛和腹泻。从少量开始逐渐增加 |
| 抗凝作用 | 木耳含有延缓血液凝固的成分。处于有出血风险的状态时，不要多吃 |
| 发霉的 | 干木耳一旦发霉，洗了也没用。丢弃 |

### 12-4. 野外采集的三条铁律

| 铁律 | 内容 |
|---|---|
| 只采树上的 | 长在地上的不是木耳 |
| 用水泡一泡 | 能像果冻一样膨胀的才是木耳 |
| 一次一种，一次少量 | 第一次吃的蘑菇只选一种，吃一口的量，然后等待24小时 |

## 13. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;在评价表中，木耳的耐储性为SS。鲜木耳放不了几天，却能拿到SS，是因为这个评级以干燥为前提。与其他许多蘑菇因耐储性为E而被判定为无法储备相比，这个差别十分明显。木耳容易晾干，晾干后能放3年以上，而且晾干后泡发，几乎能恢复原状。

> **蘑菇的贮藏问题，几乎全靠干燥这一招就能解决。木耳又是其中经过进化、能够耐受干燥与复水的蘑菇，所以损耗最小。**

### 13-1. 干燥原理

&nbsp;&nbsp;&nbsp;鲜木耳的含水量在90%左右。在这种状态下，水分活度超过0.98，细菌和霉菌可以肆意繁殖。将水分降到12%以下，水分活度就会降到0.6以下，在此以下微生物停止活动。冷藏只是减慢速度，而干燥则使其活动停止。这就是在没有电的环境中，干燥具有压倒性优势的原因。

&nbsp;&nbsp;&nbsp;木耳干燥损耗特别小。晾干后体积缩小到10%，用水泡后几乎恢复到原来的体积，质地也没有太大变化。这与其他蘑菇干燥后组织崩坏、泡发后软烂不堪不同。

### 13-2. 日晒干燥

| 步骤 | 方法 |
|---|---|
| 整理 | 抖掉泥土和木屑。不要水洗 |
| 摊平 | 用手把蜷缩的耳片展开，使子实层朝上放置 |
| 晾晒 | 摊在竹筛或竹帘上，不要重叠。下方必须通风 |
| 日程 | 晴天晒1-2天。日落后收进屋内，避免夜露 |
| 收尾 | 最后半天放在阴凉处通风，把里面也晾干 |

&nbsp;&nbsp;&nbsp;让子实层朝上放置有两个原因：一是紫外线直接照射到子实层，麦角甾醇转化为维生素D2；二是耳片收缩时向下卷曲，不会粘在竹筛上。木耳很薄，比香菇干得快得多。晴朗有风的日子，一天就能晒好。

&nbsp;&nbsp;&nbsp;是否完全干燥，要用手来判断。用手指按压时发硬、好像要碎裂，就说明已经干透。只要还有一点发软或弯曲，就说明还留有水分，保存期间会发霉。

### 13-3. 保存

| 项目 | 方法 |
|---|---|
| 冷却 | 完全冷却后再装入。趁热密封，里面会结露 |
| 容器 | 玻璃瓶、陶罐、厚塑料袋。纸袋挡不住湿气 |
| 吸湿剂 | 把炒得很干的盐、木炭块、生石灰用布包好，一起放入 |
| 场所 | 凉爽、阴暗、干燥的地方。土窖或地下室最理想 |
| 复晒 | 在韩国的梅雨季（6月下旬至7月）前后各取出一次，重新晾晒 |
| 期限 | 充分干燥并密封，常温下可保存3年以上 |

&nbsp;&nbsp;&nbsp;木耳相对于体积的贮藏效率极高。1kg鲜木耳晾干后约为100g，再次吸水后可恢复到接近800g。一个陶罐里装2kg干木耳，相当于20kg鲜品。作为存放在狭小土窖里的储备食物，这样的东西很少见。

### 13-4. 其他贮藏方法

| 方法 | 期限 | 备注 |
|---|:---:|---|
| 干燥 | 3年以上 | 最为出色 |
| 粉末 | 2年以上 | 完全干燥后磨碎。可直接加入粥和汤中 |
| 熏制干燥 | 2年以上 | 下雨天也能烘干，而且不易生虫 |
| 鲜品阴凉保存 | 3-5天 | 用纸包好放在凉爽处。装进塑料袋，一天就会变软烂 |

## 14. 烹饪与加工

&nbsp;&nbsp;&nbsp;木耳耗用燃料少。因为是泡发后使用，加热时间短，久煮也不会散形。在灾难情境下燃料和粮食一样珍贵，这一点值得计入考量。

| 步骤 | 方法 |
|---|---|
| 泡发 | 冷水泡2-3小时。务必遵守第12节的时间规则 |
| 去除基部 | 剪掉原先附着在树上的硬质基部 |
| 焯水 | 沸水焯1-2分钟。消除生吃导致的光敏性 |
| 烹饪 | 炒、汤、凉拌。5-15分钟足够 |
| 久煮 | 煮30分钟以上，会柔软得多 |

&nbsp;&nbsp;&nbsp;评价表中口味的B，来自对口感的排斥。这个问题通过烹饪可以大大缓解。切成细丝与其他食材混合，脆韧的口感就不会太突出。久煮后，胶质溶出，汤汁变得浓稠，木耳本身也会变软。放进粥里，既能增加分量，又几乎感觉不到口感。

&nbsp;&nbsp;&nbsp;做成粉末，用途会更广。把完全晾干的木耳放在石臼中捣碎，每次一勺加入粥、汤或面糊中，就能补充膳食纤维和铁。不需要泡发，口感问题也随之消失。这也是让讨厌木耳的人吃下去的最现实的办法。

| 4月 | 接种收尾、首次检查有无污染、瓦楞纸培养基接种 | 接种后第3-5天的检查很重要 |
| 5月 | 正式平放、搭建遮阳、瓦楞纸首次收获 | 最早的收获出现 |
| 6月 | 春季出耳的采收与晾干、锯末培养基出耳 | 在韩国梅雨季之前晒干备好 |
| 7月 | 高温防护遮阳、防治蛞蝓、湿度管理 | 不要超过30度 |
| 8月 | 段木翻堆、检查菇蝇、培养基干燥休养 | 最危险的月份 |
| 9月 | 为秋季出耳做准备、浸水与提高湿度 | 气温下降后开始 |
| 10月 | 秋季收获、晾晒作业、采集孢子印 | 用最好的个体取孢子 |
| 11月 | 砍伐段木的最佳时期、竖立、种木劈楔 | 落叶后立即进行为宜 |
| 12月 | 越冬准备、整理菌糠、检查贮藏品 | 段木可以在露地越冬 |

&nbsp;&nbsp;&nbsp;在韩国的气候条件下，木耳的作业集中在春季的接种和夏秋的采收、晾干。这与香菇没有太大差别，但如果同时轮换使用瓦楞纸和锯末培养基，实际上四季都能陆续有少量产出。把段木作为应对未来数年的主轴，瓦楞纸和锯末则是需要时短期轮换使用，这种方式在灾难情境下最为稳定。

> **木耳栽培的节奏是干与湿的反复。把培养基晾干一次、再重新浸湿，这一转换会唤来新的蘑菇。**
