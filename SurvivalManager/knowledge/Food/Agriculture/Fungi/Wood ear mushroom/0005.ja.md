## 9. 汚染と病害虫

&nbsp;&nbsp;&nbsp;災害時にキノコ栽培が失敗する第一の原因は、病気でも害虫でもなく、競合するカビです。その中でも緑カビ、正確にはトリコデルマ（Trichoderma）属のカビが圧倒的です。キクラゲの菌糸が1日に3-4mm伸びる間に、トリコデルマはその二、三倍も伸びます。培地をめぐる競争に負けると、取り返す方法はありません。

### 9-1. 緑カビを見分ける方法

&nbsp;&nbsp;&nbsp;最大の落とし穴は、トリコデルマも最初は白い綿毛のような状態から始まる点です。接種直後の数日間は、キクラゲの菌糸と目で見て区別できません。区別できるようになるのは、3-5日後からです。

| 観察項目 | キクラゲの菌糸 | トリコデルマ |
|---|---|---|
| 色の変化 | 白色を保ち続けます | 白色から黄色みを経て、明るい緑色、青緑色に変わります |
| 成長速度 | 1日3-4mm | 1日7-10mm。目に見えて速いです |
| 縁 | 綿毛がそろって均一に広がります | 扇の骨のように放射状に広がり、同心円状の模様をつくります |
| 質感 | 綿または霜のような形 | 最初は綿、その後は粉が固まった塊 |
| 培地の表面 | 変化なし | 水気を帯びた透明な帯ができることがあります |
| におい | ほのかなキノコの香り | ココナッツに似た甘いにおい、またはじめじめしたカビ臭さ |

&nbsp;&nbsp;&nbsp;緑色が見えた時点で、すでに胞子が数億個つくられた状態です。判断は、色が出る前に、速度と縁の形で下さなければなりません。接種三日目に、どこか1か所だけが際立って速く広がっているなら、それはキクラゲではありません。

### 9-2. ほかの汚染菌の見分け方

| 汚染菌 | 色と形 | 条件 | 危険度 |
|---|---|---|:---:|
| トリコデルマ（緑カビ） | 明るい緑色、青緑色。速く広がる | 高温、過湿、酸性 | 非常に高い |
| ペニシリウム | 青緑色だが、粉がより細かく、縁に白い帯がある | 低温、多湿 | 高い |
| ニューロスポラ（アカパンカビ） | 鮮やかなオレンジ色。爆発的に広がる | 高温多湿 | 非常に高い |
| ムコール、リゾプス | 灰色の綿毛に黒い点が混じる | 培地の含水率が高すぎる | 中程度 |
| アスペルギルス | 黒色、黄色の粉 | 高温乾燥 | 高い |
| 細菌性の粘質 | ねばねばした粘液と酸っぱい悪臭 | 過湿、通気不良 | 中程度 |

> **オレンジ色のニューロスポラを見つけたら、絶対に袋を開けないでください。胞子が非常に軽く、一度舞い上がると、その培養室全体を失います。袋ごと燃やすか、地中深くに埋めます。**

&nbsp;&nbsp;&nbsp;キクラゲは含水率の高い培地を使うため、ムコールや細菌性の粘質がシイタケより頻繁に発生します。培地の表面がねばねばして酸っぱいにおいがしたら、水が多すぎる状態です。その場合は、袋の穴を増やして空気を通し、水やりを減らすと回復することがあります。カビによる汚染と違い、細菌性の問題は早期に対処すれば元に戻せます。

### 9-3. 汚染されたときの対処

| 状況 | 対処 |
|---|---|
| おがくず袋の汚染 | 開けずに袋ごと培養室の外へ運び出します。焼却するか、50cm以上の深さに埋めます |
| 段ボールの山の汚染 | 汚染された枚だけを抜き取り、残りは乾いた場所へ移します。段ボールは層が分かれているため、部分的に救い出すことが可能です |
| 原木の接種穴の汚染 | 栓を抜いて汚染部分をえぐり取り、石灰水を塗って、新しい種菌を入れて再び塞ぎます |
| 原木の表面が広範囲に汚染 | 石灰の粉をまぶし、ほかの原木から1m以上離しておきます |
| 原木の内部まで緑色 | 回復しません。取り出して燃やします |
| 作業道具 | 沸騰した湯に浸けるか、火で熱します |

&nbsp;&nbsp;&nbsp;汚染した培地をそのまま堆肥場に捨てると、そこが胞子の工場になってしまいます。最低でも沸騰した湯で30分煮て菌を殺してから、堆肥に回します。燃やせるなら燃やすのが最も確実です。

### 9-4. 予防がすべてです

| 予防手段 | 内容 |
|---|---|
| 接種量 | たっぷりと、何か所にも。キクラゲには混合接種がよく効きます |
| 米ぬかを最小限に | 栄養の少ない培地ほど、雑菌にも食べるものがありません |
| 含水率 | 65-70%を超えないようにします。水が多いと細菌が先に来ます |
| 培養温度 | 21-22℃。25℃を超えるとトリコデルマが有利になります |
| pH | 石灰で培地のpHを6.5-7に上げます。トリコデルマは酸性を好みます |
| 通気 | 培地を押し込まず、袋に穴をあけます |
| 清掃 | 廃培地やキノコの株元を栽培地の近くに置きません |

### 9-5. 害虫

| 害虫 | 被害 | 薬剤を使わない対応 |
|---|---|---|
| キノコバエ | 幼虫が菌糸と子実体を食い荒らします | 防虫網、樹脂や水あめを塗った粘着板、廃培地をすぐ除去 |
| ダニ | 菌糸を食べて雑菌を運びます | 湿度を一定に保つ、発生した培地は隔離 |
| トビムシ | 菌糸の表面をかじります | 地面の落ち葉を取り除き、草木灰をまきます |
| ナメクジ | ゼラチン質を特に好み、大きくかじり取ります | 夜に手で捕まえます。草木灰やおがくずの帯で近づけないようにします |
| 貯蔵害虫 | 乾燥したキクラゲにタバコシバンムシ、スジコナマダラメイガがつきます | 完全乾燥、密閉、炒った塩や炭を同封 |

&nbsp;&nbsp;&nbsp;ナメクジは、キクラゲ栽培で特に厄介です。ゼラチン質が柔らかく水気が多いため、ほかのキノコよりはるかに食べられやすいのです。栽培場の周りに草木灰を幅5cmの帯状にまいておくと、かなり防げます。雨が降ったら、まき直す必要があります。

## 10. 生育異常の診断

| 症状 | 原因 | 対処 |
|---|---|---|
| 接種後に菌糸が広がらない | 培地の温度が高すぎる、種菌の活力低下、含水率不足 | 温度を21-22度に下げて再接種します |
| 菌糸は広がったが発生しない | 湿度不足、光不足 | 湿度を85-95%に上げ、間接光の入る場所に移します |
| 子実体が薄くて色が淡い | 光不足、二酸化炭素過多 | 明るさを上げ、換気します |
| 子実体が硬くて層ができる | 乾燥と湿潤の繰り返し | 生育期間中は湿度を一定に保ちます |
| 子実体の縁が内側に巻き込む | 直射日光、乾いた風 | 遮光して噴霧します |
| 子実体がぶよぶよになり悪臭がする | 過湿、通気不良、細菌性軟腐 | 水やりを止めて換気します。病んだ個体はすぐに取り除きます |
| 培地の表面が硬く固まる | 乾燥しすぎ、菌糸の老化 | 表面をかき取って水を与えたあと、再び刺激します |
| 培地がぶよぶよして酸っぱい | 含水率が高すぎることによる細菌の増殖 | 穴を増やして水を止めます。ひどい場合は廃棄します |

&nbsp;&nbsp;&nbsp;キノコでは、欠乏や過剰という概念が、畑作物とは異なる形で働きます。培地に含まれる養分は接種の時点で決まっており、あとから追加することはできません。そのため、生育異常の原因は、ほとんどの場合、養分ではなく、水、空気、温度、光の四つの環境要因に求めなければなりません。

## 11. 栽培地の配置と廃培地の循環

### 11-1. 同じ場所を使い続けません

&nbsp;&nbsp;&nbsp;評価表の連作適応性Aは、原木の入れ替え時に配置場所を移すという条件が付いた値です。原木を数年立てておいた場所には、落ちた胞子や有機物、死んだ菌糸がたまり、その上にトリコデルマやキノコバエが居着きます。新しい原木を同じ場所に立てると、汚染率が目に見えて上がります。一度使った場所は2-3年休ませます。

### 11-2. 栽培地を選ぶ基準

| 項目 | 良い条件 | 避ける条件 |
|---|---|---|
| 日陰 | 広葉樹林の下で60-70%遮光 | 完全な暗闇、直射日光 |
| 風 | 穏やかに通る場所 | 谷風が強く吹きつける場所、風のない場所 |
| 水 | 小川や井戸が近い場所 | 水を汲んで運ばなければならない場所 |
| 地形 | なだらかな北斜面か東斜面 | 南向きの急斜面、水がたまる低地 |
| 近づきやすさ | 毎日通る道筋 | 発生期を見逃しやすい人里離れた場所 |

&nbsp;&nbsp;&nbsp;キクラゲはシイタケより明るい場所を好みます。シイタケが70%の遮光を必要とするなら、キクラゲは60%程度が適しています。光が不足すると、色が淡く薄いものが出ます。同じ森の中でも、少し開けた場所をキクラゲに割り当てる方がよいです。

### 11-3. 廃原木と廃培地の使い道

| 用途 | 方法 |
|---|---|
| 種菌の原料 | 菌糸が生きている部分を割って、新しい原木や段ボールへの接種に使います |
| 堆肥 | 砕いた廃原木は、リグニンがすでに分解されていて腐葉土に近い状態です |
| ほかのキノコの培地 | サケツバタケは、キクラゲの廃原木や廃培地をそのまま食べます |
| マルチング材 | 野菜の畝に敷くと、雑草を抑え、水分を保ちます |
| 家畜の敷料 | 廃段ボール培地は吸収力が高いため、敷料として使ったあと堆肥に回せます |

## 12. 毒キノコの誤認と安全確認

### 12-1. 誤認の危険が最も低いキノコ

&nbsp;&nbsp;&nbsp;キクラゲ属（Auricularia）には、猛毒種として知られているものはありません。木に付いたゼラチン質の耳の形という姿そのものが、傘と柄とひだを備えた普通のキノコとまったく異なるため、テングタケ類のような致命的な毒キノコと取り違える余地はほとんどありません。野生での採集をせざるを得ない状況であれば、キクラゲは最も安全な選択肢の一つです。

| 区分 | キクラゲ | 紛らわしいもの |
|---|---|---|
| 組織 | ゼラチン質。押して離すと元に戻ります | ヒメキクラゲ類もゼラチン質ですが、より黒くて小さく、おいしくありません |
| 形 | 耳または貝の形で、浅い脈模様 | シロキクラゲは花びら状にかたまっており、こちらも食用です |
| 裏面 | なめらかでつやがあります | ひだや穴があればキクラゲではありません |
| 乾燥した状態 | 黒いかさぶたのように固まっていますが、水に浸けると数時間でふくらみます | 水に浸けてもふくらまず硬ければ、木質のキノコなので食べません |
| 生える場所 | 枯れた広葉樹の枝や幹 | 地面から生えるものはキクラゲではありません |

> **水に浸けてもふくらまず、硬いまま残る黒い塊は、キクラゲではありません。この確認一つで、ほとんどの誤認はふるい落とされます。**

### 12-2. 保管と戻し方

&nbsp;&nbsp;&nbsp;キクラゲで人が実際に大きな被害を受ける場合は、毒キノコを誤って採ったことではなく、乾燥したキクラゲの戻し方を誤ったことによるものです。この点は、ほかのどのキノコの文書にもない、キクラゲ固有の危険ですので、必ず知っておく必要があります。

&nbsp;&nbsp;&nbsp;乾燥したキクラゲをぬるま湯に浸けて室温で長時間、特に1日以上放置すると、水の中で細菌が増殖します。その中の特定の細菌がつくる毒素は熱に非常に強く、煮沸しても消えません。肝臓と腎臓を攻撃し、致死率が高いです。中国では、死亡事故が何度も報告されています。問題は、このように傷んだキクラゲから、異常なにおいや味がほとんどしない点です。見た目には何ともありません。

| 規則 | 内容 |
|---|---|
| 戻す時間 | 冷水で2-3時間、温かい水で30分前後。それ以上は置きません |
| 温度 | できるだけ冷水で戻します。ぬるま湯は細菌にとって最も好条件です |
| 一晩の放置 | しません。夏場は特に厳禁です |
| 戻した後 | すぐに調理します。戻したまま数時間置くことはしません |
| 余り | 戻して余ったものは、もったいなくても捨てます |
| においでの判断 | 通用しません。時間を基準に判断します |

> **キクラゲの最大の危険は、毒キノコではなく、長時間浸けた戻し水です。時間を守ることだけが唯一の防御です。**

### 12-3. そのほかの注意

| 項目 | 内容 |
|---|---|
| 生食 | 加熱せずに大量に食べると、光過敏性皮膚炎を起こすことがあります。日光を浴びた部位が腫れてかゆくなります。加熱すると消えます |
| 消化 | 食物繊維が多いため、急にたくさん食べると腹痛と下痢が起こります。少量から増やします |
| 抗凝固作用 | キクラゲには血液の凝固を遅らせる成分があります。出血の危険がある状態なら、たくさん食べません |
| カビが生えたもの | 乾燥したキクラゲにカビが生えたら、洗っても無駄です。捨てます |

### 12-4. 野生採集の三つの鉄則

| 鉄則 | 内容 |
|---|---|
| 木からだけ採る | 地面から生えるものはキクラゲではありません |
| 水に浸けてみる | ゼリーのようにふくらめばキクラゲです |
| 一種類ずつ、少しずつ | 初めて食べるキノコは一種類だけ、一口分を食べて24時間待ちます |

## 13. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;評価表では、キクラゲの貯蔵性はSSです。生は数日ももたない食品なのにSSを得ているのは、乾燥を前提に付けた値だからです。ほかの多くのキノコが貯蔵性Eで備蓄不可と判定されるのと比べると、この差は際立っています。キクラゲは乾燥させやすく、乾燥させれば3年以上もち、乾燥させても戻せばほぼ元どおりになります。

> **キノコの貯蔵性の問題は、乾燥一つでほとんどすべて解決します。キクラゲはその中でも、乾燥と再水和に耐えるように進化したキノコであるため、損失が最も少なくなります。**

### 13-1. 乾燥の原理

&nbsp;&nbsp;&nbsp;生のキクラゲの水分は90%前後です。この状態では水分活性が0.98を超え、細菌やカビが思う存分繁殖します。水分を12%以下に下げると水分活性が0.6を下回り、それ以下では微生物が活動を停止します。冷蔵は速度を遅らせるだけですが、乾燥は活動を止めます。電気のない環境で乾燥が圧倒的に有利な理由です。

&nbsp;&nbsp;&nbsp;キクラゲは乾燥による損失が特に少ないキノコです。乾燥させると体積が10%に減り、水に浸けるとほぼ元の体積に戻り、質感も大きくは変わりません。ほかのキノコが、乾燥させると組織が崩れて、戻してもふにゃふにゃになるのとは違います。

### 13-2. 天日乾燥

| 段階 | 方法 |
|---|---|
| 下処理 | 土や木くずを払い落とします。洗いません |
| 広げる | 縮んだものを手で広げ、子実層が上を向くように置きます |
| 干す | 竹ざるやすだれに、重ならないように並べます。下から空気が通るようにします |
| 日程 | 晴れた日に1-2日。日が沈んだら取り込み、夜露を避けます |
| 仕上げ | 最後の半日は日陰の風に当て、中まで乾かします |

&nbsp;&nbsp;&nbsp;子実層を上に向けて置く理由は二つあります。一つは、紫外線が子実層に直接当たってエルゴステロールがビタミンD2に変わることです。もう一つは、縮むときに下側へ巻き込むため、ざるにくっつかないことです。キクラゲは薄いので、シイタケよりはるかに早く乾きます。晴れて風のある日なら、1日で終わります。

&nbsp;&nbsp;&nbsp;完全に乾燥したかどうかは、手で判定します。指で押したときに硬く、砕けそうなら、できあがりです。少しでも柔らかかったり、しなったりするなら、まだ水分が残っており、保管中にカビが生えます。

### 13-3. 保管

| 項目 | 方法 |
|---|---|
| 冷ます | 完全に冷めてから入れます。温かいうちに密閉すると、中で結露が生じます |
| 容器 | ガラス瓶、壺、厚手のビニール。紙袋は湿気を防げません |
| 吸湿剤 | よく炒った塩、炭のかけら、生石灰を布に包んで一緒に入れます |
| 場所 | 涼しくて暗く乾燥した場所。土室や地下室が理想的です |
| 再乾燥 | 韓国の梅雨（チャンマ、6月下旬～7月）の前と後に一度ずつ取り出して、もう一度乾燥させます |
| 期間 | 完全に乾燥させて密閉すれば、常温で3年以上 |

&nbsp;&nbsp;&nbsp;キクラゲは、体積に対する貯蔵効率が非常に高いです。生のキクラゲ1kgは乾燥すると100g前後になり、それが再び水を吸うと800g近くまで戻ります。壺一つに乾燥キクラゲ2kgを入れれば、生の20kgに相当します。狭い土室に備蓄する食料として、これほどのものはまれです。

### 13-4. ほかの貯蔵方法

| 方法 | 期間 | 備考 |
|---|:---:|---|
| 乾燥 | 3年以上 | 最も優れています |
| 粉末 | 2年以上 | 完全に乾燥させてから砕きます。粥や汁物にそのまま入れます |
| 燻煙乾燥 | 2年以上 | 雨の日でも乾かせて、虫がつきにくくなります |
| 生を日陰で保管 | 3-5日 | 紙に包んで涼しい場所に置きます。ビニールに入れると、1日でぶよぶよになります |

## 14. 調理と加工

&nbsp;&nbsp;&nbsp;キクラゲは燃料をあまり使いません。戻して使うため加熱時間が短く、長く煮ても形が崩れません。災害時には燃料も食料と同じくらい貴重なので、この点は計算に入れる価値があります。

| 段階 | 方法 |
|---|---|
| 戻す | 冷水で2-3時間。必ず第12節の時間ルールを守ります |
| 株元の除去 | 木に付いていた硬い株元は切り取ります |
| 湯通し | 沸騰した湯で1-2分。生食による光過敏性をなくします |
| 調理 | 炒め物、汁物、和え物。5-15分で十分です |
| 長く煮る | 30分以上煮ると、ずっと柔らかくなります |

&nbsp;&nbsp;&nbsp;評価表の味Bは、食感に対する抵抗感から出た値です。この問題は、調理でかなり解決できます。細かく千切りにして、ほかの材料と混ぜると、コリコリとした質感が目立ちません。長く煮ると、ゼラチンが溶け出して汁にとろみがつき、キクラゲ自体も柔らかくなります。粥に入れると、量を増やしながら食感はほとんど感じられません。

&nbsp;&nbsp;&nbsp;粉にしておくと、使い道が広がります。完全に乾燥させたキクラゲを臼でつぶし、粥、スープ、生地にひとさじずつ加えると、食物繊維と鉄分が補われます。戻す必要もなく、食感の問題もなくなります。キクラゲが苦手な人に食べさせる、最も現実的な方法でもあります。

## 15. 年間作業スケジュール

| 月（韓国の気候基準） | 作業 | 備考 |
|:---:|---|---|
| 1月 | 原木の伐採、乾燥中の原木の点検、乾燥品の再乾燥 | 真冬でも伐採できます |
| 2月 | 原木の玉切り、接種の準備、段ボールの収集と下処理 | テープとホチキスの針をあらかじめ剥がしておきます |
| 3月 | 原木の穴あけと接種、おがくず培地の製造 | 気温が15度を超えたら始めます |
| 4月 | 接種の仕上げ、汚染の有無の初回点検、段ボール培地への接種 | 接種3-5日目の確認が重要です |
| 5月 | 本伏せ、遮光の設置、段ボールの初収穫 | 最も早い収穫が得られます |
| 6月 | 春の発生の収穫と乾燥、おがくず培地での発生 | 韓国の梅雨の前に乾燥させておきます |
| 7月 | 高温対策の遮光、ナメクジの防除、湿度管理 | 30度を超えないようにします |
| 8月 | 原木の天地返し、キノコバエの点検、培地の乾燥休養 | 最も危険な月です |
| 9月 | 秋の発生の準備、浸水と湿度の上昇 | 気温が下がったら始めます |
| 10月 | 秋の収穫、乾燥作業、胞子紋の採取 | 最も良い個体から胞子を採ります |
| 11月 | 原木伐採の適期、立てかけ、種木割り | 葉が落ちた直後がよいです |
| 12月 | 越冬準備、廃培地の整理、貯蔵品の点検 | 原木は露地で越冬できます |

&nbsp;&nbsp;&nbsp;韓国の気候では、キクラゲの作業は春の接種と、夏から秋の収穫・乾燥に集中します。シイタケと大きくは変わりませんが、段ボール培地とおがくず培地を併用すれば、事実上、四季を通じて少しずつ収穫できます。原木は数年先に備える軸とし、段ボールとおがくずは必要なときに短期間で回す方式が、災害時には最も安定しています。

> **キクラゲ栽培のリズムは、乾燥と湿潤の繰り返しです。培地を一度乾かしてから再び湿らせる、その切り替えが新しいキノコを呼び込みます。**
