## 3. 培养基材料与准备

&nbsp;&nbsp;&nbsp;木耳是栽培菌菇中对材料最不挑剔的一种。段木、木屑、稻草、稻壳，乃至废瓦楞纸，它都能接受。评价表中的菌菇副产物适应性B指的就是这种广度。在断电的情况下，这种广度就是生存概率。因为这意味着没有栎树可以用桑树，没有木屑可以用纸箱。

> **木耳的优势不在于产量，而在于选择的数量。一种材料行不通时，可以退回到另一种材料。**

### 3-1. 选择段木

| 项目 | 标准 | 原因 |
|---|---|---|
| 最适树种 | 桑树、桤木、栎类 | 这些是木耳在自然界中最常生长的树 |
| 可用树种 | 柳树、杨树、朴树、刺槐 | 木质较软，但出耳良好。代价是寿命短 |
| 禁用树种 | 松树、红松等针叶树 | 树脂和萜烯会抑制菌丝 |
| 直径 | 8-15cm | 也使用比香菇所用更细的木头 |
| 长度 | 1-1.2m，或20-30cm短段 | 也可以将短段竖直埋入地下 |
| 砍伐时期 | 在韩国为11月至2月 | 树液下行之后 |
| 干燥 | 1-2个月 | 比香菇晾得短 |

&nbsp;&nbsp;&nbsp;木耳段木不像香菇那样晾得很干。香菇要求含水率38-42%，而木耳在40-45%时也能很好地定殖。这是因为木耳菌丝比香菇更耐湿润的条件。不过这也意味着条件对杂菌同样有利，因此多放接种量、让菌丝抢先占据位置变得更加重要。

&nbsp;&nbsp;&nbsp;木头越软，出耳越快，结束也越快。接种在柳树或杨树上，5-6个月就能出耳，但2年后段木就耗尽了。栎树首次收获较晚，但能持续3-4年。灾害情境下，两种混合备用比较稳妥。用软木度过今年，用硬木应对之后的几年。

### 3-2. 木屑培养基

| 材料 | 比例 | 作用 |
|---|:---:|---|
| 阔叶树木屑（栎树、杨树） | 85-90% | 主要碳源 |
| 米糠 | 5-10% | 氮和维生素的来源 |
| 碳酸钙或贝壳粉 | 1% | 调节pH |
| 水分 | 65-70% | 用手攥紧时指缝间渗出一两滴水的程度 |
| 培养基量 | 每袋1.2-1.5kg | |

&nbsp;&nbsp;&nbsp;木耳的米糠用量少。香菇和猴头菇要加20-30%，而木耳5-10%就足够了。这在灾害情境下是决定性的优势。米糠既可供人食用，也可作牲畜饲料，竞争激烈，而木耳几乎不需要它。再者，营养越丰富的培养基越容易招来杂菌，所以米糠少也意味着抗污染能力强。

### 3-3. 废瓦楞纸培养基 - 灾害情境中的隐藏资源

&nbsp;&nbsp;&nbsp;瓦楞纸是把木浆打散后重新压制而成的。对木耳来说，它就是已经粉碎好的木头。物流中断后，纸箱堆积如山却无处可用。能把它变成食物，这一点使瓦楞纸培养基尤其适合灾害情境。

| 步骤 | 方法 |
|---|---|
| 挑选 | 使用印刷少、未覆膜的棕色瓦楞纸。光面纸和塑料覆膜的不要 |
| 去除胶带 | 把胶带、订书钉、标签全部撕掉 |
| 裁切 | 撕成手掌大小，或裁成5cm宽 |
| 浸泡 | 浇上开水浸泡1-2小时，或在石灰水中浸泡12小时 |
| 挤水 | 挤到不再滴水的程度 |
| 接种 | 把菌种夹在瓦楞纸之间，一层层叠放 |
| 装填 | 压实装入袋子或桶中，并打孔使空气流通 |

&nbsp;&nbsp;&nbsp;瓦楞纸的波纹中有空气层，菌丝沿着这些缝隙蔓延得非常快。木耳菌丝覆盖一层瓦楞纸，3天就足够。不过它养分少，产量只有木屑培养基的一半左右，出一两次耳就结束了。即便如此，用来扩繁菌种也很出色。先用瓦楞纸大量培养菌丝，再把它当作段木或木屑培养基的菌种使用，这种做法在实际操作中很有用。

### 3-4. 稻草类培养基

| 材料 | 处理 | 备注 |
|---|---|---|
| 稻草、麦秸 | 切成5cm以下后煮，或用石灰浸泡 | 单独使用产量低，与木屑各占一半混合 |
| 稻壳 | 用水泡后煮 | 透气性好。可替代至30% |
| 玉米秆 | 粉碎后煮 | 养分相对较多 |
| 豆荚壳 | 粉碎后煮 | 起氮源作用。用量在20%以下 |

### 3-5. 不用电给培养基灭菌的四种方法

&nbsp;&nbsp;&nbsp;高压灭菌锅在121℃下运行90分钟，连细菌孢子也能杀死。它需要电和压力容器两者齐备。没有这些时，目标不是彻底灭菌，而是低温杀菌，即把竞争菌的数量充分压低，让木耳菌丝抢先占据位置。

#### 3-5-1. 铁桶蒸汽灭菌

| 项目 | 方法 |
|---|---|
| 所需物品 | 200L铁桶、桶盖、垫架（砖块或铁网）、木柴 |
| 水 | 桶底放20-30cm |
| 装填 | 在垫架上把培养基袋或麻袋松散地堆放，留出蒸汽流通的空隙 |
| 密闭 | 盖上桶盖，再用湿草包或塑料布裹住 |
| 加热 | 蒸汽充满桶内之后再蒸4-6小时 |
| 判定 | 拔出插在培养基深处的木签时，烫得手无法握住 |
| 冷却 | 盖着盖子放一夜。趁热打开会把空气连同孢子一起吸入 |

&nbsp;&nbsp;&nbsp;木耳不会因为培养基浓厚就长得更好，所以灭菌负担反而较轻。木屑中只加5%米糠的培养基，杂菌可吃的东西也少，蒸4小时失败率就能降得足够低。

#### 3-5-2. 沸水浸泡

&nbsp;&nbsp;&nbsp;这是用于稻草和瓦楞纸的最简单的方法。在锅里烧开水，放入材料煮1-2小时。捞出挤去水分，含水率65-70%，冷却到30度以下后接种。优点是设备只需一口锅，缺点是耗费燃料多。挤水的工具和冷却用的地面也要事先用开水烫洗。

#### 3-5-3. 石灰浸泡 - 完全不耗燃料的方法

| 项目 | 方法 |
|---|---|
| 配比 | 水100L加熟石灰1-1.5kg，或生石灰0.5-1kg |
| pH | 12-13。碰到手上发滑的强碱 |
| 浸泡 | 把切好的稻草或瓦楞纸完全浸没，12-24小时 |
| 沥水 | 捞出沥水6-12小时，把含水率调到65-70% |
| 接种 | 不冲洗。残留的碱会持续抑制杂菌 |

&nbsp;&nbsp;&nbsp;石灰浸泡与木耳加瓦楞纸培养基的组合尤其契合。瓦楞纸一煮就会软烂，难以处理，而在石灰水中却能保持形状。完全不用火，这一点比什么都重要。没有石灰时，可以把草木灰溶于水放置一天，只取上层清液做成灰水来代替，但pH较低，每批差异大，成功率会下降。

#### 3-5-4. 稻草发酵

&nbsp;&nbsp;&nbsp;把稻草用水浸湿，堆成1-1.5m高，嗜热微生物会自行发热，堆内温度可达60-70℃。每隔2-3天翻堆一次，放置2-3周，杂菌可利用的易吸收糖分提前被耗尽，就成了选择性培养基。这不是灭菌，而是先把食物消耗掉的方式。作为木耳的单独培养基产量较低，但与木屑各占一半混合时，如果稻草部分采用这种方式处理，可以大幅节省燃料。

### 3-6. 无电力灭菌法比较

| 方法 | 燃料 | 所需时间 | 成功率 | 适用培养基 |
|---|:---:|:---:|:---:|---|
| 段木栽培（无需灭菌） | 无 | 无 | 最高 | 圆木 |
| 铁桶蒸汽 | 多 | 4-6小时 + 冷却 | 高 | 木屑、稻草、瓦楞纸 |
| 沸水浸泡 | 多 | 1-2小时 + 冷却 | 中等 | 稻草、稻壳、瓦楞纸 |
| 石灰浸泡 | 无 | 12-24小时 | 中等 | 稻草、瓦楞纸 |
| 稻草发酵 | 无 | 2-3周 | 中等 | 稻草、堆肥 |

## 4. 获取菌种

&nbsp;&nbsp;&nbsp;菌菇没有种子。种苗店一关门，就没地方买种，把种子留下来装进罐子里存放的办法也行不通。不过菌类有植物所没有的三条路：收存孢子，取下活菌菇的菌肉直接培养，把长满菌丝的木头劈开后移到新木头上。木耳对这三条路都很管用。自家留种为S，就是这个结果。

### 4-1. 孢子采集与孢子印

| 步骤 | 方法 |
|---|---|
| 选对象 | 选择边缘刚刚舒展、新鲜而厚实的个体 |
| 取下 | 从附着在木头上的基部小心取下 |
| 衬垫 | 将平滑的子实层面朝下，放在铝箔上 |
| 覆盖 | 扣上容器挡风 |
| 静置 | 在阴凉处放24小时 |
| 回收 | 把子实体拿起，就会留下白色的孢子粉 |

&nbsp;&nbsp;&nbsp;铝箔比纸更好。纸会吸湿，杂菌会藏在纤维之间。铝箔不吸水，表面平滑，能原样保存孢子。没有铝箔的话，玻璃板是次选。

&nbsp;&nbsp;&nbsp;木耳比其他菌菇更难采孢子。因为子实体是胶质的，干燥时会皱缩，在这个过程中会粘在铝箔上。在子实体下面垫两根筷子，稍微架空，孢子就会直接落下而不粘住。

&nbsp;&nbsp;&nbsp;采完孢子后，连铝箔一起放在通风的阴凉处再晾一天，把细微的水分也吹干。然后将铝箔对折，孢子面朝内加以保护，装进自封袋。同时放入炒干的盐或木炭碎块来吸湿。再把自封袋集中放进玻璃瓶，用蜂蜡封口，存放在四季温度恒定的土窖或地下室。紫外线会破坏孢子的DNA，所以必须不见光。

| 保存形式 | 寿命 | 备注 |
|---|:---:|---|
| 孢子印（铝箔干燥） | 5-10年以上 | 水分被完全排除，细胞活动停止 |
| 液体菌种（无菌水悬浮） | 3-6个月 | 没有冷藏的话会提前萌发，或细菌增殖 |
| 已接种菌种（木屑·种木） | 约1年 | 是活的菌丝，会持续消耗养分 |

> **灾害情境下不能把孢子以液体形式保存。必须以干燥的孢子印形式保存。**

&nbsp;&nbsp;&nbsp;孢子与植物种子寿命的差异来自结构。番茄种子含有胚和营养物质，时间一长就会自己消耗养分而衰老死亡。室温下为2-4年。菌菇孢子只是被厚细胞壁包裹的单个细胞，没有可消耗的养分。只要条件合适就能保存5-10年，学术界让存放数十年的孢子复活的案例也并不少见。

| 比较项目 | 番茄种子 | 菌菇孢子 |
|---|---|---|
| 平均寿命（室温） | 约2-4年 | 约5-10年以上 |
| 脆弱因素 | 温度变化、自身营养耗尽 | 因湿气导致霉菌污染 |
| 细胞结构 | 复杂的胚和营养物质 | 单个细胞和厚实的保护壁 |

&nbsp;&nbsp;&nbsp;灾害发生的第一年，当长出最大最健康的子实体时，大量制作20-30张孢子印，存入土窖，这件事很重要。即使每年传代菌丝时因污染而失败，5年后、10年后取出来也可以随时重新开始，这就是一道安全保障。

### 4-2. 用孢子制作菌种 - 稻草加热培养基法

&nbsp;&nbsp;&nbsp;理论上，把孢子撒在灭菌培养基上，菌丝就会伸展。但在现实中，空气中的青霉和细菌占领培养基的速度比菌菇孢子快数百倍。营养价值越高的培养基越脆弱。没有电的情况下，不用营养过剩的人工培养基，而是使用借助自然防御力的原始培养基。

| 步骤 | 方法 |
|---|---|
| 煮 | 将稻草或麦秸放入沸水中充分煮1小时以上 |
| 挤水 | 捞出挤去水分，冷却到手能触摸为止 |
| 撒播 | 把保存的孢子粉不要吝惜，均匀而充足地撒上 |
| 覆盖 | 用干净的布盖上，挡住风和飘落的孢子 |
| 培养 | 在21-25℃的暗处培养2-4周。白色菌丝覆盖稻草就算成功 |

&nbsp;&nbsp;&nbsp;如果舍不得孢子而一粒一粒地放，只会长出初生菌丝，然后死亡。必须交配型不同的孢子相遇，形成次生菌丝，才能长出菌菇，所以要把大量孢子一次性撒入，让它们在培养基里自己配对。木耳在瓦楞纸上同样适用这种方式。在煮过并冷却的瓦楞纸之间撒上孢子粉，叠放起来即可。

### 4-3. 组织培养 - 最可靠的方法

&nbsp;&nbsp;&nbsp;如果手里有新鲜的活菌菇，几乎没有理由使用孢子。菌菇的内部菌肉本来就是已经完成雌雄结合的次生菌丝团。把一小块取下放进培养基，就跳过了萌发和配对的过程，菌丝直接伸展。

| 步骤 | 方法 |
|---|---|
| 挑选 | 厚实有弹性的新鲜个体。干瘪或软烂的不用 |
| 消毒 | 把刀在火上烧过后放凉，或浸入沸水后取出 |
| 撕开 | 用手把子实体撕开，露出厚度方向的新断面 |
| 取样 | 从断面正中取出米粒大小的菌肉 |
| 接种 | 夹在煮过并冷却的稻草、木屑、瓦楞纸之间 |
| 培养 | 21-25℃的暗处。3-5天后，小块周围会蔓延出白色绒毛 |

&nbsp;&nbsp;&nbsp;撕开很重要。菌菇表面落着各种孢子，而内部接近无菌。用手撕开后，干净的面就新暴露出来，从那里取下的小块无需另行消毒就是纯净的菌丝。木耳组织坚韧不易撕开，所以用干燥的手抓住两端，慢慢拉开。

### 4-4. 延续段木菌种

&nbsp;&nbsp;&nbsp;木耳之所以在自家留种上获得S，要归功于这种方法。出耳良好的段木，本身就是一个巨大的菌种团。

| 方式 | 方法 | 备注 |
|---|---|---|
| 劈种木 | 把长满菌丝的段木劈开，做成手指粗的楔子，钉入新段木的孔中 | 最可靠 |
| 拌入木屑 | 把长满菌丝的木头粉碎，混入煮过并冷却的新木屑或瓦楞纸中 | 便于扩大数量 |
| 培养基片移植 | 把一张长满菌丝的瓦楞纸夹进新的瓦楞纸堆里 | 最简便 |
| 自然感染 | 把新段木紧贴着正在出耳的段木立放 | 辅助手段 |

&nbsp;&nbsp;&nbsp;劈开的种木干了就会死。必须在劈开的当场立即钉入，并把接种孔封严。最好在阴天或清晨、无风的时候操作。一根段木上取得的楔子可以填满5-10根新段木，所以每年牺牲一根出耳良好的段木，菌种供应就不会中断。

> **木耳种植中最宝贵的财产不是菌菇，而是长满菌丝的段木和瓦楞纸堆。那是下一代的种子。**
