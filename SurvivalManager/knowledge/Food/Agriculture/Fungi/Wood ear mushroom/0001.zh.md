## 引言
&nbsp;&nbsp;&nbsp;木耳（Auricularia auricula-judae）在评价中获得综合A，48.5分（有效183种中第30位），是长在枯死阔叶树枝上、形如耳朵的胶质蘑菇。它最大的特点是反复干湿也不会死。干旱时它会干成一块黑色硬壳，下雨后几个小时就重新膨胀成胶冻状，所以栽培中即使几天忘了浇水，菌丝和幼嫩子实体也不会死，耐受疏于管理。在储存方面它也无与伦比：晒干后体积缩到10%，泡水后几乎恢复原来的大小，干木耳在常温下能放3年。它不进行光合作用，所以日照减少时产量也不会下降（光照SS）。弱点是热量（鲜品每100g只有13kcal）和滑脆的口感（口味B），所以它不是主食，而是补充铁、膳食纤维和维生素D、给汤增加分量的角色。本文以没有电和灭菌设备为前提，介绍用段木和废瓦楞纸种木耳、自己传接菌种、晒干后吃好几年的方法。

## 1. 灾害应对评估
| 类别 | 内容 |
|:---|:---|
| 判定 | 综合A，48.5分（有效183种中第30位）。短期B 46.8，长期A 50.2，副食SS 62.9 |
| 优势 | SS：光照、耐储性、整地·挖掘能量、产量稳定性。S：蛋白质密度、持续性、国内种植普及度、自留种。A：微量营养素、设施负担、耐寒性、连作适应性 |
| 劣势 | E：非食用价值。D：收获速度（以段木栽培为准）。C：单位面积热量、施肥、病虫害压力、防治自立度、种子寿命（市售菌种的活力只有1年） |

> **蘑菇是阳光消失的世界里产量也不会下降的唯一粮食来源。木耳是其中最省事的一种。**

&nbsp;&nbsp;&nbsp;蘑菇副产物适应性B的意思是连废瓦楞纸和稻草都能当培养料，在六种蘑菇中仅次于双孢菇；连作适应性A是附带“换段木时也要换种植地”这一条件的评分。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 蘑菇概述
&nbsp;&nbsp;&nbsp;属担子菌门伞菌纲木耳目木耳科木耳属，是分解阔叶树枯木的白腐菌。它最特别的生态特性是耐干燥。

| 特征 | 内容 |
|:---|:---|
| 子实体 | 耳状或贝壳状。直径2-10cm，厚1-3mm。黑褐色至紫褐色，干后收缩发黑。组织呈胶质，有弹性，不易撕裂 |
| 上表面、下表面 | 上表面覆有短毛，呈灰褐色（毛木耳的毛很明显）。下表面（子实层）光滑有光泽，有浅脉纹，孢子从这里释放 |
| 附着方式、孢子 | 几乎没有菌柄，以侧面或背面的一点附着在木头上。孢子白色，为略弯的圆柱形 |

&nbsp;&nbsp;&nbsp;孢子是只有一半基因的单核细胞，一粒长不出蘑菇。所以孢子要把粉末足量地撒入，让它们在培养料里相遇配对。

| 阶段 | 期间与温度 | 要点 |
|:---|:---|:---|
| 菌丝培养 | 约30天（锯末）、60-90天（段木），21-22℃ | 培养料被白色菌丝覆盖 |
| 原基形成、生长 | 各10-20天，20-28℃ | 表面结出胶冻状小滴，并展开成耳状 |

&nbsp;&nbsp;&nbsp;每100g鲜品热量13kcal、蛋白质0.79g（占热量的24.3%）、膳食纤维约4g（蘑菇中最高水平），干品约271kcal、蛋白质约10.3g。据说含铁丰富，但文献数值差异很大。麦角固醇经紫外线转化，所以晒干时维生素D会增加；膳食纤维多，突然吃很多会腹痛腹泻。

## 3. 段木、废瓦楞纸与培养料
> **木耳的优势不是产量，而是选择的数量。一种被堵住，还能退回其他材料。**

| 材料 | 标准 |
|:---|:---|
| 段木 | 最适：桑树、桤木、栎类（自然界中最常长木耳的树）。可用：柳树、杨树、朴树、刺槐（质软但出耳好，寿命短）。直径8-15cm，长1-1.2m，或20-30cm的短段木。11-2月树液下降之后砍伐，晾1-2个月（比香菇短，不要晾得太干） |
| 锯末培养料 | 阔叶树锯末（栎类、杨树）85-90% + 米糠5-10%（少放） + 碳酸钙或贝壳粉1%，水分65-70%（攥一把，手指间渗出一两滴水的程度），每袋1.2-1.5kg |
| 废瓦楞纸 | 灾害情况下的隐藏资源。选印刷少、无涂层的棕色瓦楞纸（光面纸和覆塑料膜的除外），撕掉全部胶带、订书钉、标签，撕成手掌大小或切成5cm宽的条。浇开水泡1-2小时，或用石灰水泡12小时，再攥到不滴水的程度。每张之间夹上菌种分层堆放，压进袋子或桶里，打孔使空气流通。菌丝沿着波纹内的空气层蔓延得极快 |
| 稻草类 | 稻草、麦秆切成5cm以下煮或用石灰浸泡（单用产量低，与锯末各半）。稻壳最多混30%，豆荚最多20%，玉米秆弄碎后煮 |

&nbsp;&nbsp;&nbsp;无电灭菌用200L铁桶（底部放水20-30cm，支架上松松地堆放培养料袋或草袋，盖上盖子并用湿草袋或塑料布裹住），蒸汽充满后加热4-6小时（插在中心的竹签烫得握不住就行），盖着盖子冷却一夜（趁热打开会随空气吸入孢子）。稻草和瓦楞纸用开水泡1-2小时，或把切碎的稻草或瓦楞纸用石灰水泡12-24小时（不耗燃料）。连燃料也没有，就把稻草堆成1-1.5m高发酵到60-70℃。木耳在养分浓的培养料上长得不好，所以灭菌负担小。

## 4. 获取菌种
> **木耳种植中最宝贵的财产不是蘑菇，而是长满菌丝的段木和瓦楞纸堆。它们就是下一代的种子。**

| 方法 | 内容 |
|:---|:---|
| 菌丝移植（最简便） | 把一张长满菌丝的瓦楞纸夹进新的瓦楞纸堆里，或把长满菌丝的木头弄碎，混入煮过放凉的新锯末或瓦楞纸中 |
| 劈种木 | 把菌丝蔓延良好的段木劈成手指粗的楔子（取白色菌丝密集的部分），敲进新段木的孔里（最可靠）。劈开的种木干了就会死 |
| 组织培养 | 用手而不是刀把厚实、有弹性的新鲜个体（干瘪或变软的除外）撕开，露出新的断面，取正中间的菌肉，切成米粒大小，夹进煮过放凉的稻草、锯末或瓦楞纸之间。在21-25℃的暗处，3-5天长出白色绒毛 |
| 孢子印 | 把刚刚展开边缘的新鲜厚实个体，小心地从附着在木头上的基部取下，子实层光滑的一面朝下放在铝箔上，会留下白色孢子粉。连铝箔在阴凉处再晾一天后密封（禁止用液体保存）。第一年做20-30张，存放在地窖里 |

&nbsp;&nbsp;&nbsp;把孢子粉足量撒在煮过放凉的稻草上，在21-25℃的暗处培养2-4周，就成了菌种。自留种S要归功于菌丝移植和劈种木。

## 5. 接种、培养、出耳、采收
| 接种 | 标准 |
|:---|:---|
| 段木 | 3月底至5月初（比香菇可以更晚），白天15-25℃，阴天无风。孔径1-1.2cm，深1.5-2cm，纵向间距5-8cm，横向间距8-12cm，呈之字形（直径10cm、长1m的段木打30-40个）。把菌种严严实实地填满，用木塞、泡沫塞或蜡（石蜡和松香6:4）封住，两端切口也要涂。没有蜡就把泥和成糊涂上，或在塞子上盖一层湿苔藓 |
| 锯末、瓦楞纸 | 四季都可以（只要培养料温度合适）。冷却到25℃以下再接种（热了菌种会死），每kg培养料用菌种50g左右，混合均匀地拌入整个培养料（混合接种效果好）或放在上面；瓦楞纸则每张撒上菌种并叠放。工具用火烧后放凉再用，在无风的狭小空间里往地面和墙壁洒水，使灰尘沉降 |

| 培养管理 | 标准 |
|:---|:---|
| 温度、光 | 接种后3-5天21-22℃（不要动），之后21-25℃，湿度60-70%。0-3℃时只是停止生长而不会死，32℃以上菌丝变弱、杂菌占先。培养期间要避光 |
| 段木 | 接种后第一个月，紧密堆放在垫木上，盖上稻草或树枝。之后堆成井字形，要松一些，每1-2个月上下、内外换一次位置，接种5-6个月后斜向交错立起来。把20-30cm的短段木埋入地下一半的短段木埋栽，接种后马上就能进行，特别适合木耳 |
| 水 | 只要保证段木不干就行（表面湿着反而会招来杂菌）。夏季每7-10天一次，傍晚浇；冬季不浇。断面的细裂缝张得很大就是不足 |
| 确认 | 接种孔透出白色菌丝（绿色、黑色、橙色是污染）。锯末在7-10天表面一半变白（2周还没蔓延就是菌种活力问题），瓦楞纸3-5天一张被覆盖，段木断面3-5个月后出现白色菌丝（6个月后仍没有就是定殖失败）。酸味、霉味、氨味都是异常 |

&nbsp;&nbsp;&nbsp;出耳时，湿度上升（从培养的60-70%升到原基形成的85-95%，最强的信号）和光（从暗的培养室移到有能看报纸程度的散射光的地方，原基形成且颜色变深）的组合最有效。袋栽时在表面或袋上用刀划十字伤口，子实体就集中从那里长出；段木用冷水浸泡6-12小时（比香菇短），昼夜5-8℃的温差只是辅助。出耳温度为20-28℃（15℃以下慢，超过30℃变软），生长期湿度在80%左右，需要通风（闷着的话菌肉变薄）。水每天喷2-3次雾状水，或把栽培场地面弄湿（最安全）。水柱直接冲到子实体上或水积在上面，会发生细菌性软腐。木耳缺水时不会马上死，而是干缩着等待。

| 采收 | 标准 |
|:---|:---|
| 时期、要领 | 充分展开到直径5-8cm，边缘展开成波浪形，肉最厚的时候（再放就变薄变软）。下表面开始落上白色孢子粉就晚了。清晨采收（白天采水分多，不好晒干），握住基部左右拧下。一个培养料出的大小不均匀，所以分几天采 |
| 再出耳 | 采收10-20天，断水并把培养料表面晾7-10天（干燥休养），再提高湿度并浇水，7-14天后形成新原基。培养料晾干一次再重新弄湿的这一转换，会唤来新的蘑菇 |
| 按方式 | 瓦楞纸：到第一次采收30-40天，再出耳1-2次，共2-3个月。锯末袋：50-60天，2-3次，3-4个月。段木：150-180天，每年春秋，3-4年。短段木埋栽：120-150天，每年，2-3年。一段段木（直径10cm、长1m）3-4年出鲜木耳1-1.5kg |

> **木耳最好三种培养料同时进行。用瓦楞纸一个月内就能首次采收，用锯末撑过这一年，用段木准备之后的几年。**

## 6. 污染、病虫害与异常诊断
&nbsp;&nbsp;&nbsp;灾害情况下蘑菇种植失败的第一个原因是竞争霉菌。木霉（绿霉）一开始也是白色绒毛，看到绿色时孢子已经形成了数亿个，所以要靠速度和气味来判断。木耳菌丝每天长3-4mm，有淡淡的蘑菇香；木霉每天长7-10mm，明显更快，有类似椰子的甜味或潮湿的霉味。

> **发现橙色的链孢霉（红色面包霉）时，绝对不要打开袋子。孢子极轻，一旦飞散，整个培养室就都完了。连袋烧掉，或深埋到地下。**

&nbsp;&nbsp;&nbsp;木耳用含水率高的培养料，所以毛霉和细菌性黏液（黏稠的黏液和酸臭）比香菇更常出现。

| 情况 | 对策 |
|:---|:---|
| 瓦楞纸堆污染 | 只抽出被污染的纸，其余移到干燥处（各层分开，可以部分挽回） |
| 段木接种孔污染 | 拔出塞子，挖掉被污染的部分，涂上石灰水，放入新菌种再封住 |
| 段木表面大面积污染 | 撒上石灰粉，与其他段木隔开1m以上 |
| 段木内部也发绿 | 无法恢复。抽出烧掉 |

&nbsp;&nbsp;&nbsp;不要把被污染的培养料扔进堆肥场（会变成孢子工厂）。预防就是足量接种（混合接种）、米糠最少化（营养越少，杂菌也没东西吃）、含水率65-70%以下（水多了细菌先来）、培养温度21-22℃（超过25℃木霉占优势）、不把培养料压实并在袋上打孔的通风，以及不把废培养料和蘑菇根部放在种植地附近的清洁。害虫有菇蝇（防虫网，涂树脂或糖稀的板，立即清除废培养料）、螨（保持湿度稳定，隔离出耳的培养料）、蛞蝓（特别爱吃胶质，啃得很大：夜里人工捉，撒一圈灰或锯末），以及干木耳里会招来的烟草甲和印度谷螟（彻底干燥并密封，放入炒过的盐或木炭）。

| 症状 | 原因与处理 |
|:---|:---|
| 接种后菌丝不蔓延 | 培养料温度过高、菌种活力下降、含水率不足。把温度降到21-22℃并重新接种 |
| 菌丝蔓延了却不出耳 | 湿度不足、光不足。把湿度提到85-95%，移到有散射光的地方 |
| 子实体薄而颜色淡 | 光不足、二氧化碳过多。提高亮度并通风 |
| 子实体变软发臭 | 过湿、通风不良、细菌性软腐。停止浇水并通风，清除病耳 |

&nbsp;&nbsp;&nbsp;种植地适宜选在阔叶林下60-70%遮阴、微风通畅（避开山谷风大的地方和无风的地方）、每天都会经过的路口，木耳喜欢比香菇更亮的地方。废段木和废培养料把菌丝还活着的部分劈开，用于新段木或瓦楞纸接种；碎了的做接近腐殖土的堆肥，或作大球盖菇的培养料（它会直接吃木耳废段木）；废瓦楞纸培养料吸水力好，可以用作牲畜垫料后再回收做堆肥。

## 7. 误认毒蘑菇与安全确认
> **木耳属没有已知的剧毒种，是误认风险最低的蘑菇。但如果把干木耳泡错了，会受很重的伤害。**

| 类别 | 木耳 | 可能混淆的 |
|:---|:---|:---|
| 组织 | 胶质。按下去再松开会弹回 | 黑耳类也是胶质，但更黑更小，没有味道 |
| 形态 | 耳状或贝壳状，有浅脉纹 | 银耳呈花瓣状聚成一团，同样可以食用 |
| 下表面 | 光滑有光泽 | 有菌褶或孔洞的就不是木耳 |
| 干燥状态 | 像黑色硬壳一样变硬，泡水几个小时就膨胀 | 泡水不膨胀、仍然坚硬的是木质的蘑菇，不要吃 |
| 生长地点 | 枯死阔叶树的枝和树干 | 长在地上的不是木耳 |

> **泡水不膨胀、仍然坚硬的黑色块不是木耳。仅这一项确认就能筛掉大部分误认。**

&nbsp;&nbsp;&nbsp;木耳让人严重受伤的情况，不是采错了毒蘑菇，而是把干木耳泡错了。在温水里于室温下放很久，尤其是放一天以上，水里的细菌就会繁殖，所以尽量用冷水泡2-3小时（温水则30分钟左右），不要泡得更久，不要放一整夜（夏天尤其忌讳），泡好后立即烹调，泡后剩下的再可惜也要扔掉。气味无法判断，所以以时间为准。

> **木耳最大的危险不是毒蘑菇，而是泡了很久的水。守住时间是唯一的防线。**

&nbsp;&nbsp;&nbsp;不煮熟就大量吃，可能出现光敏性皮炎（受日晒的部位红肿发痒，加热后消失）；膳食纤维多，突然吃很多会腹痛腹泻，所以要从少量开始增加。它含有延缓血液凝固的成分，有出血风险时不要多吃。长了霉的干木耳洗也没用，要扔掉。野外采集只从树上采（长在地上的不是木耳），泡水后像胶冻一样膨胀的才是木耳。

## 8. 储存、烹调与全年日程
> **蘑菇的耐储性问题几乎全靠干燥一项解决。木耳又是其中为耐受干燥和复水而进化的蘑菇，所以损失最小。**

| 储存 | 内容 |
|:---|:---|
| 晒干 | 拍掉泥土和木屑，不要洗。把缩起来的用手展开，子实层朝上，晴天1-2天（鲜木耳含水约90%）。日落后收进屋以避夜露，最后半天放在阴凉通风处 |
| 保管 | 晒干后体积缩到10%，所以按体积计的储存效率极高。彻底晒干并密封后，常温下能放3年 |
| 其他 | 粉末（2年以上，彻底晒干后磨粉，直接加进粥和汤里）、烟熏干燥（2年以上，雨天也能烘干，招虫较少） |

&nbsp;&nbsp;&nbsp;用冷水泡2-3小时，遵守第7节的时间规则，剪掉附着在木头上的硬基部，用开水焯1-2分钟，消除生食引起的光敏性。炒、汤、凉拌5-15分钟就够了，煮30分钟以上会软得多。口味B来自对口感的排斥，所以磨成粉备着，用途会更广。

| 月份 | 作业 |
|:---|:---|
| 1-2月 | 砍伐段木（严冬也可以）并检查干燥情况，把干品重新晒一遍。2月把段木截段，准备接种，收集并处理瓦楞纸（提前撕掉胶带和订书钉） |
| 3-4月 | 3月气温超过15℃后，段木打孔接种，制作锯末培养料。4月结束接种，第3-5天首次检查是否污染，接种瓦楞纸培养料 |
| 5-8月 | 5月正式平放，搭遮阴，瓦楞纸首次采收（最早的收获）。6月在雨季前采收并晒干春季出耳，锯末培养料出耳。7月遮阴、防蛞蝓、湿度管理（不要超过30℃）。8月翻动段木，检查菇蝇，培养料干燥休养（最危险的月份） |
| 9-10月 | 准备秋季出耳。气温降下来后，用浸水和提高湿度诱导出耳 |
| 11-12月 | 11月是段木采伐的最佳期（刚落叶之后），立起段木、劈种木。12月准备越冬，整理废培养料，检查储存品（段木可在露地越冬） |

> **木耳种植的节奏是干与湿的反复。培养料晾干一次再重新弄湿的这一转换，会唤来新的蘑菇。**
