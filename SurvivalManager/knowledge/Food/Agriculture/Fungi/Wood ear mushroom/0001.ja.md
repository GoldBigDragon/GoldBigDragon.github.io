## はじめに
&nbsp;&nbsp;&nbsp;キクラゲ(Auricularia auricula-judae)は、評価で総合A、48.5点(有効183種中30位)を得ており、枯れた広葉樹の枝に耳の形で付いて育つゼラチン質のキノコです。最大の特徴は、乾いては濡れることを繰り返しても死なないことです。干ばつには、からからに乾いて黒いかさぶたのようになり、雨が降ると数時間でふたたび膨らんでゼリー状になるので、栽培でも、水を数日忘れても菌糸と若い子実体が死なず、放置に強いです。貯蔵でも抜きん出ていて、乾かすと体積が10%に縮み、水に浸すとほぼ元の大きさに戻り、乾燥したキクラゲは常温で3年持ちます。光合成をしないので、日射が減っても収量は減りません(日射SS)。弱みは、熱量(生100gで13kcal)と、ぬるぬるして歯ごたえのある食感(味B)なので、主食ではなく、鉄分、食物繊維、ビタミンDを補い、汁物のかさを増やす位置にあります。この文書は、電気と殺菌設備がないという前提で、原木と廃段ボールでキクラゲを育て、自分で種菌をつなぎ、干して何年も食べる方法を扱います。

## 1. 災害への備えの評価
| 区分 | 内容 |
|:---|:---|
| 判定 | 総合A、48.5点(有効183種中30位)。短期B 46.8、長期A 50.2、副食SS 62.9 |
| 強み | SS: 日射、貯蔵性、整地・掘削エネルギー、収量の安定性。S: タンパク質密度、永続性、国内での栽培の普及度、自家採種。A: 微量栄養素、施設の負担、耐寒性、連作への適応性 |
| 弱み | E: 非食用の価値。D: 収穫速度(原木栽培が基準)。C: 面積当たりの熱量、施肥、病害虫圧、防除の自立度、種子の寿命(市販の種菌の活力が1年) |

> **キノコは日光が消えた世界でも収量が減らない唯一の食料源です。キクラゲはその中でも最も手がかからない部類です。**

&nbsp;&nbsp;&nbsp;キノコ副産物への適応性Bは、廃段ボールやわらまで培地に使えるという意味で、キノコ6種のうちマッシュルームに次いで高い値で、連作への適応性Aは、原木を替えるときに栽培地も移すという条件が付いた値です。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. キノコの概要
&nbsp;&nbsp;&nbsp;担子菌門ハラタケ綱キクラゲ目キクラゲ科キクラゲ属で、広葉樹の枯れ木を分解する白色腐朽菌です。最も特異な生態的性質は乾燥への耐性です。

| 特徴 | 内容 |
|:---|:---|
| 子実体 | 耳または貝の形。直径2-10cm、厚さ1-3mm。黒褐色-暗褐色で、乾くと黒く縮む。組織はゼラチン質で弾力があり、裂けにくい |
| 上面、下面 | 上面は短い毛に覆われた灰褐色(アラゲキクラゲは毛がはっきりしている)。下面(子実層)はなめらかで艶があり、浅い脈の模様があって、胞子はここから出る |
| 付き方、胞子 | 柄はほとんどなく、側面か背面の1点で木に付く。胞子は白色で、わずかに曲がった円筒形 |

&nbsp;&nbsp;&nbsp;胞子は遺伝子を半分しかもたない単核の細胞なので、1個からはキノコは出ません。そのため胞子は、粉をたっぷり振り入れて、培地の中で互いに出会って対を成すようにします。

| 段階 | 期間と温度 | 要点 |
|:---|:---|:---|
| 菌糸の培養 | 約30日(おがくず)、60-90日(原木)、21-22℃ | 培地が白い菌糸に覆われる |
| 原基の形成、生育 | それぞれ10-20日、20-28℃ | 表面にゼリー状の滴ができ、耳の形に広がる |

&nbsp;&nbsp;&nbsp;100g当たり、生は熱量13kcal、タンパク質0.79g(熱量比24.3%)、食物繊維約4g(キノコの中で最高水準)で、乾燥品は約271kcal、タンパク質約10.3gです。鉄が多いと言われますが、文献値のばらつきが大きいです。エルゴステロールが紫外線で変わるので、天日乾燥でビタミンDが増え、食物繊維が多いので、急にたくさん食べると腹痛と下痢が起こることがあります。

## 3. 原木、廃段ボール、培地
> **キクラゲの強みは収量ではなく、選択肢の多さです。ひとつが塞がれても、ほかの材料に戻れます。**

| 資材 | 基準 |
|:---|:---|
| 原木 | 最適: クワ、ハンノキ、ナラ類(自然で最もよく生える木)。可能: ヤナギ、ポプラ、エノキ、ニセアカシア(柔らかいがよく出る。寿命は短い)。直径8-15cm、長さ1-1.2m、または20-30cmの短木。11-2月、樹液が下がった後に伐って1-2か月乾かす(シイタケより短く、からからには乾かさない) |
| おがくず培地 | 広葉樹のおがくず(ナラ類、ポプラ)85-90% + 米ぬか5-10%(少なめ) + 炭酸カルシウムか貝殻粉1%、水分65-70%(握ったとき指の間に水が1、2滴にじむ程度)、袋当たり1.2-1.5kg |
| 廃段ボール | 災害時の隠れた資源。印刷が少なく、コーティングされていない茶色の段ボール(光沢紙とビニールコーティングは除く)からテープ、ホッチキス、ラベルをすべて外し、手のひら大にちぎるか5cm幅に切る。熱湯を注いで1-2時間、または石灰水に12時間浸した後、水がしたたらない程度に絞る。1枚ごとに種菌をはさんで層にして積み、袋や桶に押し込んで穴をあけ、空気が通るようにする。波形の内側の空気の層に沿って、菌糸が非常に速く広がる |
| わら類 | 稲わらと麦わらは5cm以下に切ってゆでるか石灰に浸す(単独では収量が低いので、おがくずと半々)。もみ殻は30%、豆のさやは20%以下まで混ぜ、トウモロコシの茎は砕いてゆでる |

&nbsp;&nbsp;&nbsp;電力のない殺菌は、200Lのドラム缶(底に水20-30cm、台の上に培地の袋や麻袋をゆるく積み、ふたをして濡らしたむしろやビニールで包む)で、蒸気が満ちた後4-6時間加熱し(刺しておいた串が手で握れないほど熱ければよい)、ふたをしたまま一晩冷まします(熱いうちに開けると、空気と一緒に胞子が吸い込まれる)。わらと段ボールは熱湯に1-2時間浸すか、切ったわらや段ボールを石灰水に12-24時間浸します(燃料なし)。燃料もなければ、わらを1-1.5mに積んで発酵させ、60-70℃にします。キクラゲは培地が濃いとよく育たないので、殺菌の負担が小さいです。

## 4. 種菌の確保
> **キクラゲ栽培で最も貴重な財産は、キノコではなく、菌糸がびっしり入った原木と段ボールの山です。それが次の世代の種です。**

| 方法 | 内容 |
|:---|:---|
| 菌糸の移植(最も手軽) | 菌糸が広がった段ボール1枚を、新しい段ボールの山の中にはさむか、菌糸が広がった木を砕いて、ゆでて冷ました新しいおがくずや段ボールに混ぜる |
| 種木割り | 菌糸が広がった原木を割って、指の太さの楔(白い菌糸が密な部分)をつくり、新しい原木の穴に打ち込む(最も確実)。割った種木は乾くと死ぬ |
| 組織培養 | 厚くて弾力のある新鮮な個体(乾いたものや軟らかくなったものは除く)をナイフではなく手で裂いて新しい断面を出し、真ん中の肉を米粒大に取って、ゆでて冷ました稲わら、おがくず、段ボールの間にはさむ。21-25℃の暗い場所で3-5日で白い綿毛が広がる |
| 胞子紋 | 縁が開いたばかりの新鮮で厚い個体を、木に付いた根元から慎重に外し、なめらかな子実層の面を下にしてアルミ箔の上にのせると、白い胞子の粉が残る。箔ごと日陰でもう1日乾かして密封する(液体での保管は禁止)。初年に20-30枚つくり、土室に貯える |

&nbsp;&nbsp;&nbsp;胞子の粉は、ゆでて冷ました稲わらにたっぷりまき、21-25℃の暗い場所で2-4週間培養すれば種菌になります。自家採種Sは、菌糸の移植と種木割りのおかげです。

## 5. 接種、培養、発生、収穫
| 接種 | 基準 |
|:---|:---|
| 原木 | 3月末-5月初め(シイタケより遅くまで可能)、昼の気温15-25℃、曇って風のない日。穴の直径1-1.2cm、深さ1.5-2cm、縦の間隔5-8cm、横の間隔8-12cmで千鳥に(直径10cm、長さ1mの原木に30-40個)。種菌を隙間なくぎっしり詰め、木の栓、発泡スチロールの栓、またはろう(パラフィンと松脂を6対4)で塞ぎ、両側の切り口にも塗る。ろうがなければ、泥を練って塗るか、栓の上に濡れたコケをかぶせる |
| おがくず、段ボール | 四季を通じて可能(培地の温度さえ合えばよい)。25℃以下に冷ましてから(熱いと種菌が死ぬ)、培地1kg当たり種菌50g前後を培地全体に均等に混ぜるか(混合接種がよく効く)上面にのせ、段ボールは1枚ごとに種菌を振りまきながら重ねて積む。道具は火であぶって冷ましてから使い、風のない狭い空間で床と壁に水をまいてほこりを沈める |

| 培養の管理 | 基準 |
|:---|:---|
| 温度、光 | 接種直後3-5日は21-22℃(触らない)、その後は21-25℃、湿度60-70%。0-3℃では死なずに止まるだけで、32℃以上では菌糸が弱って雑菌が先行する。培養中は光を遮る |
| 原木 | 接種直後の1か月は、台木の上にぎっしり積んで、わらや枝をかぶせる。その後は井桁に粗く積み、1-2か月に1回、上下、内外を入れ替え、接種の5-6か月後に斜めに交差させて立てる。20-30cmの短木を半分地面に埋める短木の埋め込みは、接種後すぐにでき、キクラゲに特によく合う |
| 水 | 原木が乾かない程度だけ(表面が湿っているとかえって雑菌を呼ぶ)。夏は7-10日に1回、夕暮れに、冬はやらない。木口の細かい割れが大きく開いていれば不足 |
| 確認 | 接種穴に白い菌糸が見える(緑色・黒色・オレンジ色は汚染)。おがくずは7-10日で表面の半分が白くなり(2週間たっても広がらなければ種菌の活力の問題)、段ボールは3-5日で1枚が覆われ、原木の木口は3-5か月後に白い菌糸が現れる(6か月たってもなければ活着の失敗)。酸っぱいにおい、かび臭、アンモニア臭は異常 |

&nbsp;&nbsp;&nbsp;発生には、湿度の上昇(培養の60-70%から原基形成の85-95%へ、最も強い信号)と光(暗い培養室から、新聞が読める程度の間接光が入る場所へ移すと、原基ができて色が濃くなる)の組み合わせが最もよく効きます。袋栽培では、表面や袋にナイフで十字の傷をつけると、そこに子実体が集中して出て、原木は冷水に6-12時間浸し(シイタケより短く)、昼夜5-8℃の温度差は補助です。発生の温度は20-28℃(15℃以下では遅く、30℃を超えると軟らかくなる)、生育期の湿度は80%前後で、換気が必要です(こもると肉が薄くなる)。水は、1日2-3回、霧のように吹きかけるか、栽培場の床を濡らします(最も安全)。子実体に水の筋を直接当てたり、水がたまったりすると、細菌性の軟腐が来ます。キクラゲは、水が足りなくてもすぐには死なず、干からびて待ちます。

| 収穫 | 基準 |
|:---|:---|
| 時期、要領 | 直径5-8cmにしっかり広がり、縁が開いて波形になり、肉が最も厚いとき(置いておくと薄くなって軟らかくなる)。下面に白い胞子の粉がつき始めたら遅い。早朝に(昼に採ると水分が多く、干しにくい)根元を持って左右にひねって取る。1つの培地から大きさがふぞろいに出るので、数日に分けて収穫する |
| 再発生 | 収穫10-20日、水を切って培地の表面を7-10日乾かし(乾燥休養)、ふたたび湿度を上げて水をやると、7-14日後に新しい原基ができる。培地を一度乾かしてからまた濡らす切り替えが、新しいキノコを呼ぶ |
| 方式別 | 段ボール: 最初の収穫まで30-40日、再発生1-2回、合計2-3か月。おがくずの袋: 50-60日、2-3回、3-4か月。原木: 150-180日、毎年春と秋、3-4年。短木の埋め込み: 120-150日、毎年、2-3年。原木1本(直径10cm、長さ1m)から3-4年間に生のキクラゲ1-1.5kg |

> **キクラゲは、3種類の培地を同時に回すのがよいです。段ボールで1か月以内に最初の収穫を得て、おがくずでその年を越え、原木で次の数年に備えます。**

## 6. 汚染と病害虫、異常の診断
&nbsp;&nbsp;&nbsp;災害時にキノコ栽培が失敗する第一の原因は、競合するカビです。トリコデルマ(アオカビ)も最初は白い綿毛で始まり、緑色が見える頃にはすでに胞子が数億個できているので、速さとにおいで見分けます。キクラゲの菌糸は1日3-4mmでほのかなキノコの香りですが、トリコデルマは1日7-10mmと目立って速く、ココナッツに似た甘いにおいか、じめじめしたかび臭がします。

> **オレンジ色のニューロスポラ(アカパンカビ)を見つけたら、絶対に袋を開けてはいけません。胞子が非常に軽く、一度飛ぶと、その培養室全体を失います。袋ごと燃やすか、地面に深く埋めます。**

&nbsp;&nbsp;&nbsp;キクラゲは含水率の高い培地を使うので、ケカビと細菌性のぬめり(ねばねばした粘液と酸っぱい悪臭)が、シイタケより頻繁に来ます。

| 状況 | 対処 |
|:---|:---|
| 段ボールの山の汚染 | 汚染された1枚だけを抜き取り、残りは乾いた場所へ移す(層が分かれているので、部分的な回収ができる) |
| 原木の接種穴の汚染 | 栓を抜き、汚染された部分をえぐり取って石灰水を塗り、新しい種菌を入れて再び塞ぐ |
| 原木の表面の広い汚染 | 石灰の粉をまぶし、ほかの原木と1m以上離しておく |
| 原木の芯まで緑色 | 回復しない。抜き出して燃やす |

&nbsp;&nbsp;&nbsp;汚染された培地を堆肥場に捨てないでください(胞子の工場になる)。予防は、たっぷりの接種量(混合接種)、米ぬかを最小限に(栄養が乏しいほど、雑菌も食べるものがない)、含水率65-70%以下(水が多いと細菌が先に来る)、培養温度21-22℃(25℃を超えるとトリコデルマが有利)、培地を押し固めず袋に穴をあける通気、廃培地とキノコの切り株を栽培地の近くに置かない清掃です。害虫は、キノコバエ(防虫網、樹液や水あめを塗った板、廃培地をすぐ除去)、ダニ(湿度を一定に、発生中の培地を隔離)、ナメクジ(ゼラチン質を特に好んで大きくかじる: 夜に手で捕まえ、灰やおがくずの帯)、干したキクラゲにつくタバコシバンムシとノシメマダラメイガ(完全に乾燥させて密封し、よく炒った塩か炭を入れる)がいます。

| 症状 | 原因と対処 |
|:---|:---|
| 接種後に菌糸が広がらない | 培地の温度が高すぎる、種菌の活力低下、含水率不足。温度を21-22℃に下げて再び接種 |
| 菌糸は広がったのに発生がない | 湿度不足、光不足。湿度を85-95%に上げ、間接光が入る場所へ移す |
| 子実体が薄く色が淡い | 光不足、二酸化炭素の過多。明るさを上げて換気 |
| 子実体が軟らかくなって悪臭がする | 過湿、通気不良、細菌性の軟腐。水やりをやめて換気し、病んだ個体を除去 |

&nbsp;&nbsp;&nbsp;栽培地は、広葉樹林の下で60-70%遮光、風がやわらかく通り(谷風が強い場所や風のない場所は避ける)、毎日通る道筋がよく、シイタケより明るい場所を好みます。廃原木と廃培地は、菌糸が生きている部分を割って新しい原木や段ボールの接種に使い、砕いたものは腐葉土に近い堆肥にしたり、サケツバタケの培地(キクラゲの廃原木をそのまま食べる)にしたりし、廃段ボール培地は吸水力がよいので、家畜の敷料に使った後、堆肥に回せます。

## 7. 毒キノコの誤認と安全の確認
> **キクラゲ属には猛毒の種が知られておらず、誤認の危険が最も低いキノコです。しかし、干したキクラゲを誤って戻すと、ひどい目にあうことがあります。**

| 区分 | キクラゲ | 間違えやすいもの |
|:---|:---|:---|
| 組織 | ゼラチン質。押して離すと元に戻る | ヒメキクラゲ類もゼラチン質だが、より黒くて小さく、味がない |
| 形 | 耳または貝の形、浅い脈の模様 | シロキクラゲは花びら状に固まっており、やはり食用 |
| 下面 | なめらかで艶がある | ひだや孔があればキクラゲではない |
| 乾いた状態 | 黒いかさぶたのように固まり、水に浸すと数時間で膨らむ | 水に浸しても膨らまず硬ければ、木質のキノコなので食べない |
| 生える場所 | 枯れた広葉樹の枝や幹 | 地面から生えるものはキクラゲではない |

> **水に浸しても膨らまず、硬いまま残る黒い塊は、キクラゲではありません。この確認ひとつで、ほとんどの誤認がふるい落とされます。**

&nbsp;&nbsp;&nbsp;キクラゲで人が大きな被害を受けるのは、毒キノコを誤って採ったときではなく、干したキクラゲを誤って戻したときです。ぬるま湯に常温で長く、特に1日以上置くと、水の中で細菌が増殖するので、できれば冷水に2-3時間(温水なら30分前後)浸し、それ以上置かず、一晩放置せず(夏はなおさら禁物)、戻したらすぐ調理し、戻して余ったものはもったいなくても捨てます。においでは判断できないので、時間を基準に判断します。

> **キクラゲの最大の危険は、毒キノコではなく、長く戻した水です。時間を守ることだけが唯一の防御です。**

&nbsp;&nbsp;&nbsp;加熱せずにたくさん食べると、光線過敏症の皮膚炎(日光を受けた部分が腫れてかゆい、加熱すると消える)が出ることがあり、食物繊維が多いので、急にたくさん食べると腹痛と下痢が起こるため、少量から増やします。血液の凝固を遅らせる成分があるので、出血の危険がある状態なら、たくさん食べません。カビが生えた干しキクラゲは、洗っても無駄なので捨てます。野生での採取は、木からだけ採り(地面から生えるものはキクラゲではない)、水に浸してゼリーのように膨らめばキクラゲです。

## 8. 貯蔵、調理、年間日程
> **キノコの貯蔵性の問題は、乾燥ひとつでほとんどすべて解けます。キクラゲは、その中でも乾燥と吸水に耐えるよう進化したキノコなので、損失が最も少ないです。**

| 貯蔵 | 内容 |
|:---|:---|
| 天日乾燥 | 土と木くずを払い、洗わない。縮んだものを手で広げ、子実層を上に向けて、晴れた日に1-2日(生のキクラゲの水分は90%前後)。日が沈んだら取り込んで夜露を避け、最後の半日は日陰の風に当てる |
| 保管 | 乾かすと体積が10%に縮むので、体積当たりの貯蔵効率が非常に高い。完全に乾燥させて密封すれば、常温で3年 |
| その他 | 粉末(2年以上、完全に乾燥させて挽き、おかゆや汁にそのまま入れる)、燻製乾燥(2年以上、雨の日も干せて虫がつきにくい) |

&nbsp;&nbsp;&nbsp;冷水に2-3時間浸し、7節の時間の規則を守り、木に付いていた硬い根元は切り落とし、熱湯で1-2分ゆでて、生食による光線過敏症の原因をなくします。炒め物、汁物、和え物は5-15分で十分で、30分以上煮るとずっと軟らかくなります。味Bは食感への抵抗感から出た値なので、粉にしておくと、使い道が広がります。

| 月 | 作業 |
|:---|:---|
| 1-2月 | 原木の伐採(真冬でも可能)と乾燥の点検、乾燥品の干し直し。2月に原木を切りそろえ、接種の準備、段ボールの収集と手入れ(テープとホッチキスは前もって外す) |
| 3-4月 | 3月に気温が15℃を超えたら、原木の穿孔と接種、おがくず培地の製造。4月に接種を終え、3-5日目に汚染の有無を最初に点検、段ボール培地の接種 |
| 5-8月 | 5月に本寝かせ、遮光の設置、段ボールの最初の収穫(最も早い収穫)。6月に梅雨前に春の発生を収穫して乾燥、おがくず培地の発生。7月に遮光、ナメクジの防除、湿度の管理(30℃を超えさせない)。8月に原木を返し、キノコバエを点検、培地の乾燥休養(最も危険な月) |
| 9-10月 | 秋の発生の準備。気温が下がったら、浸水と湿度の上昇で発生を促す |
| 11-12月 | 11月は原木の伐採の適期(落葉の直後)、立て込みと種木割り。12月に越冬の準備、廃培地の整理、貯蔵品の点検(原木は野外で越冬できる) |

> **キクラゲ栽培のリズムは、乾きと濡れの繰り返しです。培地を一度乾かしてからまた濡らす、その切り替えが新しいキノコを呼びます。**
