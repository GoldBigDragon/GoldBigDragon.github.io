### 1-3. 日照のSSが意味するもの

&nbsp;&nbsp;&nbsp;評価表の日照の項目は、本来、40%遮光で収量がどれだけ残るかを問うものです。キクラゲに付いたSSは、その競争に勝ったという意味ではなく、そもそもその競争に参加しないという意味です。菌類は葉緑素を持ちません。キクラゲが使う炭素は、広葉樹が何十年もかけて固定してきたセルロースとリグニンであり、空の明るさがその蓄えに影響を与えることはありません。

&nbsp;&nbsp;&nbsp;大規模な火山噴火や核の冬のように、日射量が何年にもわたって減少する状況で、この違いは決定的になります。成層圏にエアロゾルが広がると、穀物、いも類（塊茎・塊根）、野菜が同時に崩れます。しかし山の枯れ木はそのまま残っており、その木を人が食べられるタンパク質に変えられる唯一の経路がキノコです。キクラゲを災害対策のリストに入れる第一の理由は、熱量ではなく、この代替不可能性です。

> **キノコは、日光が失われた世界でも収量が減らない唯一の食料源です。キクラゲはそのなかでも、最も手間がかからない部類です。**

### 1-4. 強みをどう読むか

&nbsp;&nbsp;&nbsp;S以上は、タンパク質密度、永続性、日照、貯蔵性、整地・掘削エネルギー、収量安定性、韓国国内での栽培普及度、自家採種です。ここにキノコ副産物適応性のBが加わります。この組み合わせが描くのは、材料を選ばず、気象に左右されず、自ら世代をつなぎ、乾燥させれば何年ももつ作物です。

&nbsp;&nbsp;&nbsp;副産物適応性のBは、キノコ6種のなかでマッシュルームに次いで高い値で、実務上の意味が大きいものです。キクラゲはナラ類の原木だけでなく、おが粉、稲わら、籾殻、さらには廃段ボールでも育ちます。段ボールは木材パルプを圧縮したものなので、キクラゲにとってはすでに細かく砕かれた木です。災害時、紙や箱は有り余るのに使い道に乏しい資源です。それを食料に変えられるキノコは多くありません。

&nbsp;&nbsp;&nbsp;貯蔵性SSも実質的です。キクラゲは乾燥と再吸水に耐えるよう進化したキノコで、乾く過程で組織が壊れません。シイタケは乾燥させると香りが濃くなる代わりに質感が変わりますが、キクラゲは水で戻すとほぼ元の状態に戻ります。体積が10%に減る点まで加えると、備蓄食料としての効率は非常に高くなります。

### 1-5. 弱みをどう読むか

&nbsp;&nbsp;&nbsp;Eは非食用価値の1項目だけで、実質的な弱みはD、B、Cに散らばっています。

&nbsp;&nbsp;&nbsp;味のBが注目すべき値です。キクラゲのにおいや香りには抵抗感がありませんが、食感には抵抗感があると記録されています。ぷるぷるしながらコリコリとしたゼラチン質は、好む人と嫌う人に分かれます。災害時に同じものを毎日食べなければならないとき、この差は思ったより大きくなります。対応は調理にあります。細かく刻んで他の材料と混ぜれば食感が目立たなくなり、長く煮込むとずっと柔らかくなります。14節で扱います。

&nbsp;&nbsp;&nbsp;面積当たり熱量のCは、シイタケと同じ事情です。生100gが13kcalで、キノコのなかでも低い部類です。1日2,100kcalをキクラゲだけで満たすには16kgを食べなければなりません。キクラゲで熱量をまかなう計画は立てません。タンパク質密度がSなのは、熱量があまりに低いために比率が高く出た結果ですので、キクラゲ100gにタンパク質が0.79gしかないという絶対量もあわせて覚えておく必要があります。

&nbsp;&nbsp;&nbsp;収穫速度のDは原木栽培を基準にしたものです。おが粉培地なら50-60日で発生するため、急ぐときはおが粉や段ボールで始め、原木は長期の柱として別に立てておくという二本立ての戦略が可能です。キクラゲは、この二つの道をどちらもよく受け入れてくれる珍しいキノコです。

&nbsp;&nbsp;&nbsp;種子寿命のCは、市販の種菌の活力が1年であるという意味です。シイタケと同様に、この弱みは4節の胞子紋の保存と組織培養で解消します。胞子は乾燥させておけば5-10年もちます。

## 2. このキノコはどんな菌類か

### 2-1. 分類と生態

&nbsp;&nbsp;&nbsp;キクラゲは、担子菌門ハラタケ綱キクラゲ目キクラゲ科キクラゲ属に属します。シイタケやヒラタケが属するハラタケ目とは別の系統で、そのため姿かたちも根本的に異なります。ひだも管孔もなく、子実層が下面全体になめらかに広がっています。

&nbsp;&nbsp;&nbsp;生態的には白色腐朽菌です。枯れた広葉樹の枝や幹を分解します。生きている木を攻撃することはまれで、たいていはすでに枯れた枝や伐採した丸太に付きます。自然界ではナラ類、クワ、ハンノキ類、ヤナギ、ポプラ、エノキによく見られます。針葉樹では育ちません。

&nbsp;&nbsp;&nbsp;キクラゲの最も特異な生態的形質は乾燥耐性です。子実体が完全に乾いて紙のように硬くなっても、細胞は死なず、休眠するだけです。雨が降って水を含むと、数時間で元の体積に戻り、再び成長して胞子を飛ばします。1個体が乾いたり濡れたりを何度も繰り返しながら、数か月生きることもあります。この形質のおかげで、キクラゲは水管理に非常に寛容です。

### 2-2. 形態

| 器官 | 特徴 |
|---|---|
| 子実体 | 耳または貝殻の形。直径2-10cm、厚さ1-3mm |
| 色 | 黒褐色から紫褐色。乾くと黒く縮みます |
| 上面（背側） | 短い毛に覆われ、灰褐色を帯びます。アラゲキクラゲは毛がはっきりしています |
| 下面（子実層） | なめらかでつやがあり、浅い脈の模様があります。胞子はここから出ます |
| 組織 | ゼラチン質。弾力があり、裂けにくいです |
| 付き方 | 柄はほとんどなく、側面や裏面の一点で木に付きます |
| 胞子 | 白色で、円筒形をしており、わずかに曲がっています |

&nbsp;&nbsp;&nbsp;胞子が白色であることは、覚えておく価値があります。傘を黒い紙の上に伏せて置くと、白い粉が残ります。ただしキクラゲは子実層が下面全体なので、胞子紋を取るには子実体をまるごと伏せて置かなければなりません。

### 2-3. 生活環 - 胞子からキノコまで

&nbsp;&nbsp;&nbsp;キノコの生活環は、植物とは根本的に異なります。種1粒が1本の木になる植物と違い、キノコの胞子は1粒だけではキノコになれません。

| 段階 | 何が起こるか |
|---|---|
| 胞子 | 子実層から離れて出ます。遺伝子を半分しか持たない単核の細胞です |
| 一次菌糸 | 胞子が発芽して糸状に伸びます。遺伝子が半分しかないためキノコをつくれず、やがて死滅します |
| 二次菌糸 | 交配型の異なる一次菌糸2本が出会って結合します。この状態になって初めてキノコをつくります |
| 菌糸体のまん延 | 二次菌糸が原木や培地全体を占め、養分を蓄えます |
| 原基形成 | 湿度が上がって光が入ると、培地の表面に粟粒のようなゼリー状の粒ができます |
| 子実体 | 粒が広がって耳の形に育ちます。成熟すると下面から胞子を飛ばします |

> **胞子1粒ではキノコは生えません。胞子をまくときは、惜しんで1粒ずつにするのではなく、粉をたっぷり振り入れて、培地のなかで互いに出会って対をつくれるようにしなければなりません。**
