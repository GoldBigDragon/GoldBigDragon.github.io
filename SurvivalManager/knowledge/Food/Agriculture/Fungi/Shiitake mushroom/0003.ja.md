## 3. 培地材料と準備

&nbsp;&nbsp;&nbsp;シイタケを育てる方法は大きく2つあります。丸太をそのまま使う原木栽培と、おが粉に栄養源を混ぜて袋に詰めるおが粉栽培です。平時の商業農家は回転の速いおが粉栽培に傾いていますが、電気が止まった状況では、判断が正反対にひっくり返ります。おが粉の袋は必ず殺菌しなければならず、殺菌には燃料が要ります。原木は殺菌が要りません。丸太の内部はもともと無菌に近く、木自身の防御物質と低い水分が雑菌を防いでくれるからです。

> **電気がなければ、シイタケは原木栽培です。殺菌工程がまるごとなくなるというこの1つの理由だけで、ほかのあらゆる不便を補って余りあります。**

### 3-1. 原木の選び方

| 項目 | 基準 | 理由 |
|---|---|---|
| 最適な樹種 | クヌギ、ナラガシワ、コナラ、モンゴリナラ | リグニン含量が高く辺材が厚いので、菌糸の餌が多くあります |
| 使用可能な樹種 | クリ、アカシデ、ハンノキ、サクラ | 収量がナラ類より20-30%少なくなります |
| 使用禁止の樹種 | マツ、チョウセンゴヨウ、モミなどの針葉樹 | 樹脂とテルペンが菌糸の生長を抑えます |
| 使用禁止の樹種 | ウルシ、クルミ | アレロパシー物質が菌糸を死滅させます |
| 直径 | 9-15cm | 細すぎるとすぐ乾き、太すぎると菌糸が芯まで届きません |
| 長さ | 1-1.2m | 人が持ち上げて立てられる限界です |
| 樹齢 | 15-25年生 | 辺材が厚く、心材がまだ小さいためです |

&nbsp;&nbsp;&nbsp;伐採の時期が収量を左右します。葉がすべて落ちて樹液が根に下がる、韓国では11月上旬から中旬が最適です。この時期に伐った木は、貯蔵養分が幹に最も多く残っており、春に伐った木よりも収量が明らかに高くなります。伐った後は、枝を払った状態で1-4か月、日陰に置いて乾燥させます。

&nbsp;&nbsp;&nbsp;乾燥の度合いを測る基準は、含水率38-42%です。水分計がなければ、3つの方法で判断します。第一に、切った断面に放射状の細かいひびが3-5本入っている状態です。ひびがまったくなければまだ湿っており、ひびが10本を超えてぱっくり割れていれば乾きすぎです。第二に、伐採直後の重さの85-90%になったときです。第三に、樹皮を爪で押しても水気がにじみ出てこない程度です。

&nbsp;&nbsp;&nbsp;乾燥が不十分な原木に接種すると、緑カビが必ず発生します。原木内の水分が多いと、木自身の細胞がまだ生きていてシイタケ菌糸の侵入を防ぎ、その隙に雑菌が先に居場所を確保します。逆に乾きすぎると、菌糸が伸びるための水がなく、活着そのものが起こりません。シイタケの原木栽培の失敗原因の半分は、この乾燥の見極めから生じます。

### 3-2. おが粉培地 - 殺菌が可能なときの選択

| 材料 | 割合 | 役割 |
|---|:---:|---|
| ナラ類のおが粉 | 70-80% | 主な炭素源 |
| 米ぬか | 20-30% | 窒素とビタミンB1の供給源 |
| ふすま | 米ぬかの代替可 | 窒素源 |
| 炭酸カルシウムまたは貝殻粉末 | 1% | pH調整、カルシウム供給 |
| 水分 | 63-65% | 手で握ったとき、指の間に水が1、2滴にじむ程度 |

&nbsp;&nbsp;&nbsp;おが粉は、粒の太さが混ざっているほうがよいです。細かい粉だけだと空気が通らず菌糸が窒息し、粗いかんな屑だけだと密度が低くて養分が不足します。ふるいにかけて、2-3mmのものとそれより細かいものを半々に混ぜます。生のおが粉よりも、野積みして3-6か月寝かせたおが粉のほうが適しています。木の樹脂成分が抜け、組織が柔らかくなるからです。

&nbsp;&nbsp;&nbsp;災害時におが粉が不足する場合は、稲わら、麦わら、トウモロコシの茎、豆がら、もみ殻を細かく砕いて、20-30%まで代替できます。ただしシイタケは木質への依存度が高く、代替率が40%を超えると収量が明らかに低下します。代替材料は必ず5cm以下に切らなければ、培地が均一に詰まりません。

### 3-3. 電気なしで培地を殺菌する4つの方法

&nbsp;&nbsp;&nbsp;高圧蒸気滅菌器は、121℃で90分かけて、細菌の胞子まで殺します。電気と耐圧容器の両方が必要です。それがないときに使える方法は、完全な滅菌ではなく、競合菌の数を十分に減らして、シイタケ菌糸が先に居場所を確保できるようにする低温殺菌です。目標が違うという点を、まず理解しておく必要があります。

#### 3-3-1. ドラム缶の蒸気殺菌

| 項目 | 方法 |
|---|---|
| 準備するもの | 200Lの鉄製ドラム缶、蓋、台（レンガや焼き網）、薪 |
| 水 | ドラム缶の底に20-30cm |
| 積み込み | 台の上に培地の袋や麻袋をゆるく積みます。蒸気が回る隙間を残します |
| 密閉 | 蓋をして、濡らしたカマニ（わら袋）やビニールで包み、蒸気が漏れないようにします |
| 加熱 | 水が沸騰して蒸気が缶を満たしてから4-6時間 |
| 判定 | 培地の中心部に刺しておいた木の串が、熱くて手で握れないほどになる |
| 冷却 | 蓋をしたまま一晩冷まします。熱いうちに開けると、空気とともに胞子が吸い込まれます |

&nbsp;&nbsp;&nbsp;この方法で、培地の中心部は95-100℃に達します。カビの分生子と大部分の細菌は死滅しますが、耐熱性の細菌の胞子は生き残ります。それでも実務上は十分です。シイタケ菌糸が3日以内に表面を覆えば、その後は雑菌が入り込む余地がないからです。

#### 3-3-2. 熱湯への浸漬

&nbsp;&nbsp;&nbsp;稲わらや細かく切ったわら系の材料に使う、最も単純な方法です。釜で湯を沸かし、材料を入れて1時間以上じっくり煮ます。引き上げて水気を絞り、含水率65-70%、温度30℃以下まで冷ましてから接種します。燃料はたくさん要りますが、必要な道具が釜ひとつだけという点が強みです。煮た後に絞る過程で再び汚染される可能性があるため、絞る道具と冷ます床面を、あらかじめ熱湯で洗っておく必要があります。

#### 3-3-3. 石灰浸漬 - 燃料がまったくいらない方法

| 項目 | 方法 |
|---|---|
| 配合 | 水100Lに消石灰1-1.5kg、または生石灰0.5-1kg |
| pH | 12-13。手で触るとぬるぬるするほどの強アルカリ |
| 浸漬 | 5cm以下に切ったわらを完全に浸かるように入れ、12-24時間 |
| 水切り | 引き上げて6-12時間水を切り、含水率を65-70%に整えます |
| 接種 | 水ですすぎません。培地に残ったアルカリが雑菌を抑え続けます |

&nbsp;&nbsp;&nbsp;強アルカリはカビ胞子の細胞膜を破壊しますが、シイタケ菌糸は比較的耐えられます。何より、火をまったく使いません。燃料が最も貴重になる災害時には、この点の価値は大きいです。石灰がなければ、草木灰を水に溶いて1日置き、上澄みだけを取った灰汁で代用できますが、pHが11前後と低く、作るたびにばらつくため、成功率が下がります。石灰は、手に入るときに多めに備蓄しておくべき材料です。

#### 3-3-4. 稲わらの発酵

&nbsp;&nbsp;&nbsp;わらを水で湿らせて高さ1-1.5mに積み上げると、好熱性微生物が自ら発熱し、山の内部が60-70℃に達します。2-3日おきに切り返しながら2-3週間置くと、雑菌が食べられる分解しやすい糖分があらかじめ消費され、シイタケ菌糸だけが食べられる選択的な培地になります。殺菌ではなく、先に餌をなくす方式なので、発想が異なります。シイタケよりもマッシュルームやサケツバタケによく合いますが、おが粉が不足するときにわら混合培地をつくる前処理としては、シイタケにも使えます。

### 3-4. 無電力の殺菌法の比較

| 方法 | 燃料 | 所要時間 | 成功率 | 適した培地 |
|---|:---:|:---:|:---:|---|
| 原木栽培（殺菌不要） | なし | なし | 最も高い | 丸太 |
| ドラム缶の蒸気 | 多い | 4-6時間 + 冷却 | 高い | おが粉、わら |
| 熱湯への浸漬 | 多い | 1-2時間 + 冷却 | 中程度 | わら、もみ殻 |
| 石灰浸漬 | なし | 12-24時間 | 中程度 | わら系のみ |
| 稲わらの発酵 | なし | 2-3週間 | 中程度 | わら、堆肥 |

## 4. 種菌の確保

&nbsp;&nbsp;&nbsp;キノコには種子がありません。種苗店が閉まれば種を買う場所がないという意味であり、同時に、種を採って甕にしまっておくという方式も通用しないという意味です。しかし菌類には、植物にはない3つの道があります。胞子を採って保存しておく道、生きているキノコの肉の部分を切り取ってそのまま育てる道、そして菌糸が広がった木を割って新しい木に移す道です。この3つを重ねておけば、種菌が途絶えることはありません。

### 4-1. 胞子の採取と胞子紋

| 手順 | 方法 |
|---|---|
| 対象の選定 | 傘が大きく開き、虫食いのない、最も大きく健康な個体を選びます |
| 柄の切り取り | 傘と柄が接する部分で、柄をぎりぎりまで切り落とします |
| 下敷き | ひだが下を向くようにして、アルミホイルの上に載せます |
| 覆い | カップや器をかぶせて風を防ぎます |
| 放置 | 涼しい場所に24時間 |
| 回収 | 傘を持ち上げると、ホイルの上に白い胞子の粉が傘の形のまま残っています |

&nbsp;&nbsp;&nbsp;紙よりもアルミホイルのほうが適しています。紙は湿気を吸い、繊維の間に雑菌が潜みます。ホイルは水分を吸わず表面がなめらかで、胞子をそのままの状態で保存できます。ホイルが手に入らなければ、ガラス板が次善の選択です。

&nbsp;&nbsp;&nbsp;胞子を採った後は、ホイルごと風通しのよい日陰にもう1日置いて、わずかな湿気まで飛ばします。その後、ホイルを半分に折って胞子の面を内側にして保護し、ジッパー付き袋に入れます。このとき、からからに炒った塩や炭のかけらを一緒に入れて湿気を吸わせます。ジッパー付き袋を何枚かまとめてガラス瓶に入れ、蜜蝋で封をして、四季を通じて温度が一定の土室や地下室に置きます。紫外線は胞子のDNAを破壊するので、光が届かない奥深い場所でなければなりません。

| 保存形態 | 寿命 | 備考 |
|---|:---:|---|
| 胞子紋（ホイルで乾燥） | 5-10年以上 | 水分が完全に除かれ、細胞の活動が停止します |
| 液体種菌（滅菌水に懸濁） | 3-6か月 | 冷蔵がないと、早期に発芽したり、細菌が増殖したりします |
| 培養済みの種菌（おが粉種菌・種駒） | 約1年 | 生きた菌糸なので、養分を使い続けます |

> **災害時に胞子を液体で保管してはいけません。必ず乾燥させた胞子紋の形で保存しなければなりません。**

&nbsp;&nbsp;&nbsp;胞子と植物の種子で寿命が違うのは、構造に由来します。トマトの種子は胚と栄養物質を抱えているため、時間が経つと自ら養分を消費して老化し、死んでしまいます。室温で2-4年です。キノコの胞子は、厚い細胞壁に包まれた単一の細胞にすぎず、消費する養分がありません。条件さえ合えば5-10年、学界では数十年前の胞子をよみがえらせた事例も珍しくありません。

| 比較項目 | トマトの種子 | キノコの胞子 |
|---|---|---|
| 平均寿命（室温） | 約2-4年 | 約5-10年以上 |
| 弱点となる要因 | 温度変化、自身の栄養の枯渇 | 湿気によるカビの汚染 |
| 細胞構造 | 複雑な胚と栄養物質 | 単一の細胞と厚い保護壁 |

&nbsp;&nbsp;&nbsp;だから、災害の最初の年に、最も大きく健康なキノコが出たときに、胞子紋を20-30枚、大量につくって土室に貯えておくことが重要です。毎年菌糸をつないでいく中で汚染によって失敗したとしても、5年後、10年後に貯えておいた胞子を取り出して、いつでもやり直せる安全装置になります。

### 4-2. 胞子から種菌をつくる - 稲わら加熱培地法

&nbsp;&nbsp;&nbsp;理論上は、胞子を滅菌した培地にまけば菌糸が伸びます。しかし現実には、空気中の緑カビや細菌が、キノコの胞子より何百倍も速く培地を占領します。栄養価の高い培地ほど、より脆弱です。電気がない状況で成功率を上げるには、栄養が過剰な人工培地の代わりに、自然の防御力を利用した原始的な培地を使うべきです。

| 手順 | 方法 |
|---|---|
| 煮る | 稲わらや麦わらを熱湯で1時間以上じっくり煮ます |
| 絞る | 引き上げて水気を絞り、手で触れる温度になるまで冷まします |
| まく | 保管しておいた胞子の粉を惜しまず、均等にたっぷりまきます |
| 覆う | きれいな布で覆い、風や落下してくる胞子を防ぎます |
| 培養 | 20-25℃の暗い場所で2-4週間。白い菌糸がわらを覆えば成功です |

&nbsp;&nbsp;&nbsp;胞子を惜しんで1粒ずつ落とすと、一次菌糸だけが伸びて死滅します。互いに異なる交配型が出会って二次菌糸になって初めてキノコが出るため、多数の胞子を一度に振り入れて、培地の中でそれぞれが相手を見つけられるようにしなければなりません。これは胞子接種で最もよくある失敗であり、最も簡単に直せる失敗でもあります。

### 4-3. 組織培養 - 最も確実な方法

&nbsp;&nbsp;&nbsp;生きている新鮮なキノコが手元にあれば、胞子を使う理由はほとんどありません。キノコの傘と柄が接する内側の白い肉の部分は、すでに雌雄の結合が済んだ二次菌糸のかたまりです。その一片を切り取って培地に入れれば、発芽と交配の過程を飛ばして、すぐに菌糸が四方に伸びます。

| 手順 | 方法 |
|---|---|
| 選ぶ | 傘が開きかけている新鮮な個体。古いものや虫食いのものは使いません |
| 消毒 | ナイフを火で熱してから冷ますか、熱湯に浸してから取り出します |
| 裂く | キノコを手で縦に裂きます。ナイフで切ると、表面の雑菌が内部に引き込まれます |
| 採取 | 傘と柄が接する内側の白い肉を、米粒ほどの大きさに切り取ります |
| 接種 | 煮て冷ました稲わらやおが粉の間、または原木の接種穴に差し込みます |
| 培養 | 22-25℃の暗い場所。3-5日で、切片の周囲に白い綿毛のようなものが広がります |

&nbsp;&nbsp;&nbsp;裂くことが重要なのは、キノコの内部が無菌に近いからです。外側の表皮やひだにはあらゆる胞子が付着していますが、肉の中は清潔です。手で裂けば、その清潔な面が新たに露出し、そこから切り取った切片は、消毒しなくても純粋な菌糸になります。

### 4-4. 原木から種菌をつなぐ

&nbsp;&nbsp;&nbsp;シイタケが自家採種でSを得られたのは、この方法のおかげです。キノコがよく出た原木は、それ自体が巨大な種菌のかたまりです。この原木を割って新しい原木に移せば、無菌操作も、胞子採取も、培地の殺菌もなしに、代をつなぐことができます。

| 方式 | 方法 | 備考 |
|---|---|---|
| 種駒づくり | 菌糸がよく広がった原木を斧で割って、指ほどの太さのくさびをつくり、新しい原木の接種穴にハンマーで打ち込みます | 最も確実です |
| おが粉への混ぜ込み | 菌糸が広がった木を砕いておが粉の状態にし、煮て冷ました新しい稲わらやおが粉に混ぜます | 量を増やすのに適しています |
| 自然感染 | 発生中の原木の隣に、新しく接種した原木を寄せて立てておきます | 補助的な手段です |

&nbsp;&nbsp;&nbsp;割った種駒は、乾くと死んでしまいます。割ったその場ですぐに打ち込み、接種穴を密封しなければなりません。曇りの日や早朝、風のないときに作業するのがよいです。1本から得たくさびで新しい原木5-10本を埋められるため、よく発生する原木を毎年1本ずつ犠牲にすれば、種菌の供給が永久に続きます。

> **シイタケ栽培で最も大切な財産は、キノコではなく、菌糸がびっしり詰まった原木です。その1本が、次の5年をつくります。**
