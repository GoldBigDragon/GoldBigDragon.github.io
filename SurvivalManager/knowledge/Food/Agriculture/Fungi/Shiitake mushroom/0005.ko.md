## 9. 오염과 병해충

&nbsp;&nbsp;&nbsp;재난 상황에서 버섯 농사가 실패하는 첫째 원인은 병도 해충도 아니라 경쟁 곰팡이입니다. 그중에서도 푸른곰팡이, 정확히는 트리코데르마(Trichoderma)속 곰팡이가 압도적입니다. 표고 균사가 하루에 2-3mm 뻗을 때 트리코데르마는 그 서너 배를 뻗습니다. 배지를 두고 벌이는 경주에서 이쪽이 지면 되돌릴 방법이 없습니다.

### 9-1. 푸른곰팡이를 알아보는 법

&nbsp;&nbsp;&nbsp;가장 큰 함정은 트리코데르마도 처음에는 흰 솜털로 시작한다는 점입니다. 접종 직후 며칠 동안은 표고 균사와 눈으로 구별되지 않습니다. 구별이 가능해지는 것은 3-5일 뒤부터입니다.

| 관찰 항목 | 표고 균사 | 트리코데르마 |
|---|---|---|
| 색 변화 | 계속 흰색을 유지합니다 | 흰색에서 노란빛을 거쳐 밝은 녹색, 청록색으로 바뀝니다 |
| 자라는 속도 | 하루 2-3mm | 하루 7-10mm. 눈에 띄게 빠릅니다 |
| 가장자리 | 솜털이 가지런하고 고르게 퍼집니다 | 부챗살처럼 퍼지며 동심원 무늬를 만듭니다 |
| 질감 | 솜 또는 서리 모양 | 처음엔 솜, 이후 가루가 뭉친 덩어리 |
| 배지 표면 | 변화 없음 | 물기 어린 투명한 띠가 생기는 일이 있습니다 |
| 냄새 | 표고 특유의 향 | 코코넛 비슷한 달큰한 냄새 또는 눅눅한 곰팡내 |

&nbsp;&nbsp;&nbsp;녹색이 보이는 순간 이미 포자가 수억 개 만들어진 상태입니다. 그래서 판단은 색이 나오기 전에, 자라는 속도와 가장자리 모양으로 내려야 합니다. 접종 사흘째에 어느 구멍 한 곳만 유난히 빨리 번지고 있다면 그것은 표고가 아닙니다.

### 9-2. 다른 오염균 구별

| 오염균 | 색과 모양 | 조건 | 위험도 |
|---|---|---|:---:|
| 트리코데르마(푸른곰팡이) | 밝은 녹색, 청록색. 빠르게 번짐 | 고온, 과습, 산성 | 매우 높음 |
| 페니실리움 | 청록색이나 가루가 더 곱고 가장자리에 흰 띠 | 저온, 습함 | 높음 |
| 뉴로스포라(붉은빵곰팡이) | 선명한 주황색. 폭발적으로 번짐 | 고온 다습 | 매우 높음 |
| 무코르, 라이조푸스 | 회색 솜털에 검은 점이 박힘 | 배지 함수율 과다 | 중간 |
| 아스페르길루스 | 검은색, 노란색 가루 | 고온 건조 | 높음 |
| 세균성 점질 | 색이 아니라 끈적한 점액과 시큼한 악취 | 과습, 통기 불량 | 중간 |

> **주황색 뉴로스포라를 발견하면 절대 봉지를 열지 마십시오. 포자가 대단히 가벼워 한 번 날리면 그 배양실 전체를 잃습니다. 봉지째 태우거나 땅에 깊이 묻습니다.**

### 9-3. 오염되었을 때 하는 일

| 상황 | 조치 |
|---|---|
| 톱밥 봉지 오염 | 열지 말고 봉지째 배양실 밖으로 옮깁니다. 소각하거나 50cm 이상 깊이 묻습니다 |
| 원목 접종구 오염 | 마개를 뽑고 오염 부분을 칼로 도려낸 뒤 석회수를 바르고 새 종균을 넣어 다시 막습니다 |
| 원목 표면 넓게 오염 | 석회 가루를 묻히고 다른 원목과 1m 이상 떼어 둡니다. 회복되는 일이 있습니다 |
| 원목 속까지 녹색 | 회복되지 않습니다. 더미에서 빼내어 태웁니다 |
| 작업 도구 | 끓는 물에 담그거나 불에 달굽니다 |
| 작업자 옷 | 오염 배지를 만진 옷으로 건강한 배지에 손대지 않습니다 |

&nbsp;&nbsp;&nbsp;오염 배지를 그냥 퇴비장에 던지면 그곳이 포자 공장이 됩니다. 최소한 끓는 물에 30분 삶아 균을 죽인 뒤에 퇴비로 돌립니다. 태울 수 있으면 태우는 것이 가장 확실합니다.

### 9-4. 예방이 전부입니다

| 예방 수단 | 내용 |
|---|---|
| 원목 건조 | 함수율 38-42%를 지킵니다. 젖은 원목은 반드시 오염됩니다 |
| 접종량 | 넉넉히, 여러 곳에. 균사가 먼저 자리 잡으면 잡균은 못 들어옵니다 |
| 접종 시기 | 이른 봄. 기온이 오르면 트리코데르마가 훨씬 유리해집니다 |
| 배양 온도 | 균사 최적보다 1-2℃ 낮게 둡니다. 트리코데르마는 고온에서 더 빨리 자랍니다 |
| pH | 석회로 배지 pH를 6.5-7로 올립니다. 트리코데르마는 산성을 좋아합니다 |
| 통기 | 원목을 땅에서 20cm 이상 띄우고 공기가 돌게 쌓습니다 |
| 청소 | 폐원목, 폐배지, 버섯 밑동을 재배지 근처에 두지 않습니다 |

### 9-5. 해충

| 해충 | 피해 | 무약제 대응 |
|---|---|---|
| 버섯파리 | 유충이 균사와 자실체를 파먹습니다 | 방충망, 끈끈이 대용으로 나뭇진이나 조청을 바른 판, 폐배지 즉시 제거 |
| 응애 | 균사를 먹고 잡균을 옮깁니다 | 습도를 일정하게, 발생 원목은 격리 |
| 톡토기 | 균사 표면을 갉습니다 | 지면 낙엽을 걷어내고 재를 뿌립니다 |
| 흰개미, 하늘소 | 원목 자체를 갉아 수명을 줄입니다 | 원목을 땅에 닿게 두지 않습니다 |
| 민달팽이 | 자실체를 갉아먹습니다 | 밤에 손으로 잡습니다. 재나 톱밥 띠를 둘러 접근을 막습니다 |
| 저장 해충 | 말린 버섯에 권련벌레, 화랑곡나방이 듭니다 | 완전 건조, 밀폐, 볶은 소금이나 숯 동봉 |

## 10. 생육 이상 진단

| 증상 | 원인 | 조치 |
|---|---|---|
| 접종 1년이 지나도 균사가 안 보임 | 원목이 지나치게 마름, 종균 활력 저하, 침엽수 사용 | 원목을 침수해 함수율을 올리고 재접종합니다 |
| 균사는 퍼졌는데 버섯이 안 남 | 갈변 미완료, 자극 부족, 빛 부족 | 갈변을 기다리고 침수와 타격을 겹칩니다. 간접광을 확보합니다 |
| 대만 길고 갓이 작음 | 이산화탄소 축적, 빛 부족 | 환기하고 밝기를 높입니다 |
| 갓이 심하게 갈라짐 | 공중 습도 부족, 건조한 바람 | 분무하거나 차광을 늘립니다. 저온기의 가벼운 갈라짐은 오히려 상품입니다 |
| 버섯이 물러지고 시큼한 냄새 | 과습, 통기 불량, 세균성 연부 | 물주기를 줄이고 병든 개체를 즉시 제거합니다 |
| 버섯이 아주 작고 많이 남 | 원목 양분 소진, 과도한 연속 발생 | 휴양을 길게 주고 새 원목을 준비합니다 |
| 원목이 물러 손으로 부스러짐 | 수명 종료 또는 다른 부후균 침입 | 폐기하거나 퇴비로 돌립니다 |
| 갓 표면에 갈색 반점 | 갈색무늬병, 물방울 자국 | 물을 직접 뿌리지 않고 통풍을 늘립니다 |

&nbsp;&nbsp;&nbsp;버섯에는 결핍이나 과잉이라는 개념이 밭작물과 다르게 작동합니다. 배지에 들어 있는 양분은 접종 시점에 이미 정해져 있고 나중에 더 줄 수 없습니다. 그래서 생육 이상의 원인은 대부분 양분이 아니라 물, 공기, 온도, 빛 네 가지 환경 요인에서 찾아야 합니다.

## 11. 재배지 배치와 폐배지 순환

### 11-1. 같은 자리를 계속 쓰지 않습니다

&nbsp;&nbsp;&nbsp;평가표의 연작 적응성 A는 원목 교체 때 배치 부지를 옮기라는 조건이 붙은 값입니다. 원목을 4-5년 세워 둔 자리에는 그동안 떨어진 포자와 유기물, 죽은 균사가 쌓이고, 그 위에 트리코데르마와 버섯파리가 정착합니다. 새 원목을 같은 자리에 세우면 오염률이 눈에 띄게 올라갑니다. 한 번 쓴 자리는 2-3년 쉬게 하고 그 사이에는 낙엽을 긁어 모으거나 채소를 심습니다.

### 11-2. 재배지 고르는 기준

| 항목 | 좋은 조건 | 피할 조건 |
|---|---|---|
| 그늘 | 활엽수림 아래 70% 차광 | 완전한 암흑, 직사광선 |
| 바람 | 부드럽게 통하는 곳 | 골바람이 세게 치는 곳, 바람이 전혀 없는 곳 |
| 물 | 개울이나 우물이 가까운 곳 | 물을 길어 와야 하는 곳 |
| 지형 | 완만한 북사면이나 동사면 | 남향 급사면, 물이 고이는 저지 |
| 접근성 | 매일 지나다니는 길목 | 발생 시기를 놓치기 쉬운 외진 곳 |

### 11-3. 폐원목과 폐배지의 쓸모

| 용도 | 방법 |
|---|---|
| 종균 원료 | 균사가 아직 살아 있는 부분을 쪼개 새 원목 접종에 씁니다 |
| 퇴비 | 부순 폐원목은 리그닌이 이미 분해되어 부엽토에 가깝습니다. 밭에 넣으면 보수력이 좋아집니다 |
| 다른 버섯 배지 | 독청버섯아재비는 표고 폐원목과 폐배지를 그대로 먹습니다 |
| 멀칭재 | 채소 이랑에 덮으면 잡초를 막고 수분을 잡습니다 |
| 연료 | 완전히 마른 폐원목은 불쏘시개로 씁니다. 다만 열량이 생나무보다 낮습니다 |

&nbsp;&nbsp;&nbsp;버섯 재배는 밭농사와 경쟁하지 않고 오히려 보탬이 됩니다. 산에서 나무를 가져와 버섯으로 바꾸고, 남은 찌꺼기를 밭으로 보내는 흐름이 만들어지기 때문입니다. 표고 재배지와 채소밭을 가까이 두면 이 순환이 짧아집니다.

## 12. 독버섯 오인과 안전 확인

### 12-1. 표고 자체의 독성

&nbsp;&nbsp;&nbsp;표고는 식용으로 안전합니다. 다만 두 가지 주의가 있습니다.

| 항목 | 내용 |
|---|---|
| 생식 | 익히지 않고 많이 먹으면 채찍 모양의 붉은 피부염(표고 피부염)이 생기는 일이 있습니다. 렌티난 계열 성분이 원인이며 가열하면 없어집니다 |
| 소화 | 생것은 섬유가 질겨 소화가 어렵습니다. 반드시 익혀 먹습니다 |
| 상한 것 | 물러지고 시큼하거나 암모니아 냄새가 나면 버립니다 |

### 12-2. 야생에서 표고와 혼동되는 버섯

&nbsp;&nbsp;&nbsp;재난 상황에서 사람들은 산에 나는 버섯을 따 먹게 됩니다. 표고를 안다고 생각하는 사람이 가장 많이 중독되는 상대가 화경버섯입니다.

| 구분 | 표고버섯 | 화경버섯(맹독) |
|---|---|---|
| 발생 | 참나무 등 활엽수 고사목, 대개 흩어져 남 | 너도밤나무, 서어나무 고사목에 여러 개가 겹쳐 다발로 남 |
| 갓 | 갈색에서 암갈색, 거북등 무늬가 생기기도 함 | 자갈색에서 암갈색, 광택이 있고 무늬가 없음 |
| 주름 | 흰색, 대에 홈붙음 | 흰색이나 대를 따라 길게 내려붙음(내린주름) |
| 대 밑동 | 자르면 속이 균일한 흰색 | 자르면 검은 얼룩이나 반점이 있음 |
| 발광 | 없음 | 어두운 곳에서 주름이 청백색으로 빛남 |
| 향 | 표고 특유의 진한 향 | 향이 거의 없음 |
| 독성 | 없음 | 일루딘S. 극심한 구토와 설사, 대량 섭취 시 사망 |

> **대 밑동을 세로로 쪼개어 검은 얼룩이 보이면 화경버섯입니다. 이 확인 하나가 가장 확실합니다.**

&nbsp;&nbsp;&nbsp;발광 확인도 유효합니다. 갓을 따서 완전히 캄캄한 방에 두고 눈이 어둠에 적응한 뒤 10분쯤 지나 보면, 화경버섯은 주름이 희미한 청백색으로 빛납니다. 신선한 개체일수록 뚜렷합니다. 표고는 어떤 상태에서도 빛나지 않습니다.

### 12-3. 야생 채집의 세 가지 철칙

| 철칙 | 내용 |
|---|---|
| 포자문을 받는다 | 흰 종이와 검은 종이 위에 반씩 걸쳐 갓을 엎어 둡니다. 표고는 흰 포자입니다 |
| 밑동까지 캔다 | 대 밑동을 남기고 따면 대주머니나 검은 얼룩 같은 결정적 표지를 놓칩니다 |
| 한 종류씩, 조금씩 | 처음 먹는 버섯은 한 종류만, 한 입 크기로 먹고 24시간 기다립니다 |

&nbsp;&nbsp;&nbsp;가장 안전한 답은 야생 채집을 하지 않는 것입니다. 접종 이력이 분명한 원목에서 난 버섯만 먹으면 오인 사고가 원천적으로 생기지 않습니다. 표고 원목재배를 권하는 이유 가운데 하나가 이것입니다. 내가 심은 자리에서 난 버섯은 내가 아는 버섯입니다.

## 13. 냉장고 없는 저장

&nbsp;&nbsp;&nbsp;평가표에서 표고의 저장성은 SS입니다. 생것 기준으로는 며칠도 못 가는 식품이 어떻게 SS를 받았는가 하면, 건조를 전제로 매긴 값이기 때문입니다. 다른 여러 버섯이 저장성 E로 비축 불가 판정을 받는 것과 대비해 보면 이 차이가 뚜렷합니다. 표고는 말리기 쉽고, 말리면 3년 이상 가며, 말리면 오히려 맛이 좋아집니다.

> **버섯의 저장성 문제는 건조 하나로 거의 전부 풀립니다. 생것 저장 기간을 늘리려 애쓰는 대신, 딴 그날 말리기 시작하는 것이 정답입니다.**

### 13-1. 건조의 원리

&nbsp;&nbsp;&nbsp;생표고의 수분은 88-90%입니다. 이 상태에서는 수분활성도가 0.98을 넘어 세균과 곰팡이가 마음껏 번식합니다. 수분을 12% 이하로 낮추면 수분활성도가 0.6 밑으로 떨어지고, 그 아래에서는 미생물이 활동을 멈춥니다. 냉장은 미생물의 속도를 늦출 뿐이지만 건조는 아예 활동을 정지시킵니다. 전기가 없는 환경에서 건조가 압도적으로 유리한 이유입니다.

### 13-2. 일광 건조

| 단계 | 방법 |
|---|---|
| 손질 | 흙만 털어 내고 씻지 않습니다. 물에 닿으면 마르는 시간이 길어지고 향이 빠집니다 |
| 썰기 | 두꺼운 것은 5-7mm로 저밉니다. 작은 것은 통째로 말립니다 |
| 배치 | 주름이 위를 향하게 놓습니다. 자외선이 주름에 직접 닿아야 비타민 D가 만들어집니다 |
| 널기 | 채반이나 발에 겹치지 않게. 아래로 공기가 통해야 합니다 |
| 일정 | 맑은 날 2-3일. 해가 지면 들여놓아 밤이슬을 피합니다 |
| 마무리 | 마지막 하루는 그늘 바람에 두어 속까지 말립니다 |

&nbsp;&nbsp;&nbsp;완전 건조 판정은 손으로 합니다. 반으로 꺾었을 때 휘지 않고 '딱' 소리를 내며 부러지면 다 된 것입니다. 조금이라도 휘거나 질기면 아직 수분이 남아 있어 보관 중에 곰팡이가 핍니다.

&nbsp;&nbsp;&nbsp;볕에 말린 표고가 기계로 말린 것보다 나은 점이 비타민 D입니다. 표고에 든 에르고스테롤은 자외선을 받으면 비타민 D2로 바뀝니다. 주름을 위로 향하게 하고 한나절만 볕에 두어도 전환이 일어나며, 건조 전에 두 시간 정도 자외선을 쬔 뒤 말리면 효과가 더 큽니다. 실내 생활이 길어지고 신선 식품이 끊긴 재난 상황에서 이것은 결핍 하나를 막아 주는 실질적인 이득입니다.

### 13-3. 보관

| 항목 | 방법 |
|---|---|
| 식히기 | 완전히 식힌 뒤 담습니다. 따뜻할 때 밀폐하면 안에서 결로가 생깁니다 |
| 용기 | 유리병, 항아리, 두꺼운 비닐. 종이봉투는 습기를 막지 못합니다 |
| 흡습제 | 바짝 볶은 소금, 숯 조각, 생석회를 천에 싸서 함께 넣습니다 |
| 장소 | 서늘하고 어둡고 건조한 곳. 토굴이나 지하실이 이상적입니다 |
| 되말리기 | 장마 전후로 한 번씩 꺼내어 다시 말립니다 |
| 기간 | 완전 건조하고 밀폐하면 상온에서 3년 이상 |

### 13-4. 다른 저장 방법

| 방법 | 기간 | 비고 |
|---|:---:|---|
| 건조 | 3년 이상 | 가장 우수합니다 |
| 분말 | 2년 이상 | 완전 건조 후 빻습니다. 죽과 국에 바로 넣습니다. 향이 더 빨리 빠집니다 |
| 염장 | 6개월-1년 | 데쳐서 소금을 버섯 무게의 20-30%로 켜켜이 재웁니다. 소금이 귀하면 우선순위가 낮습니다 |
| 훈연 건조 | 2년 이상 | 비 오는 날에도 말릴 수 있고 벌레가 덜 듭니다. 연료가 듭니다 |
| 생것 그늘 보관 | 3-5일 | 종이에 싸서 서늘한 곳. 비닐에 넣으면 하루 만에 물러집니다 |

## 14. 조리와 가공

&nbsp;&nbsp;&nbsp;표고는 연료를 적게 쓰는 편입니다. 생것은 5-10분이면 익고, 말린 것은 불려서 쓰므로 가열 시간이 짧습니다. 재난 상황에서 연료는 식량만큼 귀하니 이 점은 계산에 넣을 만합니다.

| 단계 | 방법 |
|---|---|
| 불리기 | 찬물에 20-30분. 급하면 미지근한 물에 15분 |
| 불린 물 | 버리지 않습니다. 구아닐산과 무기질이 녹아 있어 국물의 바탕이 됩니다 |
| 가열 | 5-15분. 오래 끓이면 향이 날아갑니다 |
| 대 | 질겨서 그냥 먹기 어렵습니다. 잘게 찢어 오래 끓이거나 말려 빻아 가루로 씁니다 |

&nbsp;&nbsp;&nbsp;찬물에 천천히 불려야 감칠맛이 가장 많이 나옵니다. 뜨거운 물에 빨리 불리면 시간은 줄지만 구아닐산 생성이 덜 됩니다. 전날 밤에 물에 담가 두는 습관을 들이면 연료도 아끼고 맛도 삽니다.

&nbsp;&nbsp;&nbsp;가루로 만들어 두면 쓰임이 넓어집니다. 죽, 수프, 반죽, 나물 무침에 한 숟갈씩 넣으면 단백질과 감칠맛이 함께 보태집니다. 불리는 시간도 필요 없습니다. 다만 가루는 향이 빨리 빠지므로 필요한 만큼씩 그때그때 빻는 편이 낫습니다.

## 15. 연간 작업 일정

| 월 | 작업 | 비고 |
|:---:|---|---|
| 1월 | 원목 벌채 마무리, 건조 중인 원목 점검 | 한겨울 벌채도 가능합니다 |
| 2월 | 원목 재단(1-1.2m), 접종 준비, 종균 확인 | 밀랍, 마개, 드릴 날을 미리 챙깁니다 |
| 3월 | 천공과 접종 시작, 임시 눕히기 | 월말이 적기입니다 |
| 4월 | 접종 마무리, 오염 여부 첫 점검 | 접종 3-5일째 확인이 중요합니다 |
| 5월 | 본 눕히기, 차광 설치 | 여름 고온에 대비합니다 |
| 6월 | 물주기 시작, 봄 발생 원목 수확 | 2년차 이상 원목에서 납니다 |
| 7월 | 고온 대비 차광 강화, 7-10일 간격 관수 | 35℃를 넘기지 않습니다 |
| 8월 | 원목 뒤집기, 버섯파리 점검 | 가장 위험한 달입니다 |
| 9월 | 가을 발생 준비, 침수 자극 | 수온이 내려가면 시작합니다 |
| 10월 | 가을 수확, 건조 작업, 포자 문양 채취 | 가장 좋은 개체로 포자를 받습니다 |
| 11월 | 원목 벌채 최적기, 세우기, 종목 쪼개기 | 잎이 진 직후가 가장 좋습니다 |
| 12월 | 월동 준비, 건조품 되말리기, 폐원목 정리 | 원목은 노지 월동이 가능합니다 |

&nbsp;&nbsp;&nbsp;표에서 보듯 표고의 작업은 봄의 접종과 가을의 수확·건조에 몰려 있습니다. 여름과 겨울에는 점검 정도입니다. 이 계절 분포가 밭농사의 바쁜 시기와 크게 겹치지 않는다는 점이 표고를 다른 작물과 함께 짓기 좋게 만듭니다. 봄에 감자를 심고 표고를 접종하고, 가을에 감자를 캐고 표고를 말리는 흐름이 자연스럽게 짜입니다.

> **표고 농사의 일정표는 1년이 아니라 5년입니다. 올해 접종한 원목은 내후년에 밥상에 오르고, 그 원목이 다할 무렵 올해 심은 다른 원목이 자리를 이어받습니다.**
