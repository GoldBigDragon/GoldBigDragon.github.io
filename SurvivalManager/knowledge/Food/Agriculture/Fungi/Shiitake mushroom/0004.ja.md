## 5. 接種方法

&nbsp;&nbsp;&nbsp;接種は、シイタケ栽培で人が最も多く手を入れる段階であり、失敗が決まる段階でもあります。その後の1年半の結果が、この1日にかかっています。原則は単純です。シイタケの菌糸が雑菌より先に原木を占有するようにすることです。そのためには、種菌をたっぷりと、多くの箇所に、素早く入れ、入れた場所をふさがなければなりません。

### 5-1. 時期と天気

| 項目 | 基準 | 理由 |
|---|---|---|
| 時期 | 韓国では3月末から4月初め | 原木の温度が菌糸の活着に適しており、雑菌の活動はまだ鈍いからです |
| 気温 | 日中10-20℃ | 5℃以下だと活着が遅く、25℃を超えると雑菌が先行します |
| 天気 | 曇りで風のない日 | 晴れて風の吹く日は、空気中の胞子がたくさん飛びます |
| 時間帯 | 早朝または日没前後 | 乾燥と直射日光を避けます |
| 場所 | 日陰、できれば屋内 | 接種面が乾くと活着率が下がります |

### 5-2. 穴あけ

| 項目 | 基準 |
|---|---|
| 穴の直径 | 1.2-1.3cm |
| 穴の深さ | 2.4cm |
| 縦の間隔 | 3-5cm |
| 横の間隔 | 10-15cm |
| 列数 | 原木の周囲に7列前後、千鳥状に配置 |
| 穴の総数 | 直径12cm、長さ1mの原木で25-35個 |

&nbsp;&nbsp;&nbsp;千鳥状に穴をあける理由は、菌糸が木の内部で、年輪の方向よりも縦方向に3-4倍速く広がるからです。穴を1列にきれいに並べてあけると、その列に沿って菌糸が帯のように伸びていき、列と列の間の空間が長く空いたままになります。互い違いにあければ、原木全体がより均一に、より早く覆われます。

&nbsp;&nbsp;&nbsp;穴は多いほどよいです。接種点が多いと、菌糸が多くの場所から同時に伸び、雑菌が入り込む隙が減ります。種菌が足りず穴の数を減らさなければならない状況であれば、穴の数を減らすよりも、原木の本数を減らして、残った原木に十分入れるほうがよいです。中途半端に接種した原木10本よりも、きちんと接種した5本のほうが結果がよくなります。

&nbsp;&nbsp;&nbsp;電動ドリルがなければ、木工用の手回しドリルや、のみとハンマーで穴をあけます。深さを一定にするには、ドリルの刃にテープを巻いて目印にするか、のみに木片を当てて深さを制限します。穴をあけたまま長く置いてはいけません。あけたその日のうちに接種を終えます。

### 5-3. 種菌の充填と密封

| 手順 | 方法 |
|---|---|
| 充填 | 穴に種菌を隙間なくぎっしり詰めます。ゆるいと空気が回って乾き、雑菌が入ります |
| 押し固め | 指や木の棒で押して固めます |
| 密封 | 木の栓を打ち込むか、発泡スチロールの栓をはめるか、ろうを溶かして覆います |
| ろうの配合 | パラフィンと松やにを6対4で溶かして使います。純粋なパラフィンより付きがよく、割れにくいです |
| 切断面の処理 | 原木の両端の切断面にもろうを塗って、水分の蒸発を防ぎます |

&nbsp;&nbsp;&nbsp;密封の目的は2つです。水分を逃がさないことと、雑菌を入れないことです。ろうがなければ、泥をこねて塗るか、木の栓を削って打ち込み、その上に濡れたコケを被せる方法で代用できます。完璧ではありませんが、何もしないよりはずっとましです。

### 5-4. 種駒づくりによる接種

&nbsp;&nbsp;&nbsp;市販の種菌がないときに使う方法です。菌糸がよく広がった古い原木を斧で割って、長さ3-4cm、太さ1-1.5cmのくさびをつくります。このくさびを、新しい原木にあけた穴にハンマーで打ち込み、栓やろうでふさぎます。くさびは乾くと死ぬので、割ったらすぐに打ち込まなければならず、作業中は濡れた布で覆っておきます。

&nbsp;&nbsp;&nbsp;くさびを選ぶときは、白い菌糸がびっしり詰まった部分を使います。木が軟らかくなって手で簡単にぼろぼろ崩れる部分は、すでに養分が尽きているか、ほかの菌が入り込んだ場所かもしれません。割った断面からキノコ特有の香りがすれば良い兆候で、カビ臭や酸っぱいにおいがすれば、その原木は使いません。

### 5-5. おが粉培地への接種

| 項目 | 基準 |
|---|---|
| 培地の温度 | 25℃以下に冷ましてから | 熱いうちに入れると種菌が死にます |
| 接種量 | 培地1kgあたり種菌50-80g | 多いほど雑菌に強くなります |
| 方式 | 袋の上面にのせるか、中央の穴に詰めます | |
| 道具の消毒 | スプーンやトングを火で熱してから冷まして使います | |
| 作業環境 | 風のない狭い空間。濡れた布で床と壁を湿らせて、ほこりを沈めます | |

&nbsp;&nbsp;&nbsp;無菌室がないときのコツは、空気中のほこりを減らすことです。作業の30分前に部屋の床と壁に水をまいてほこりを沈め、ドアを閉め、中に入るのは1人だけにします。息を吐く向きが培地に向かないように顔をそらし、しゃべりません。この程度を守るだけでも、汚染率が半分以下に下がります。

## 6. 菌糸培養の管理

&nbsp;&nbsp;&nbsp;接種が終わると、12-18か月の培養が始まります。この期間の目標は、菌糸が原木の内部を隅々まで占有し、養分を蓄積するようにすることです。人がすべきことは多くありませんが、してはいけないことははっきりしています。乾かさないこと、直射日光に当てないこと、早く立てないことです。

### 6-1. 温度と湿度

| 時期 | 温度 | 原木の含水率 | 管理 |
|---|:---:|:---:|---|
| 接種直後の3-4日 | 20℃ | 38-42% | 活着を促します。触りません |
| 活着後 | 22-25℃ | 35-45% | 菌糸の伸長が最も速い時期 |
| 夏 | 30℃以下を維持 | 乾かさない | 35℃を超えると菌糸が弱ります |
| 冬 | 自然気温 | 結露に注意 | 凍っても死にません。翌年また育ちます |

&nbsp;&nbsp;&nbsp;シイタケの菌糸は、氷点下でも死にません。原木の状態で露地での越冬が可能で、翌春に気温が上がればまた育ちます。評価表の耐寒性のSは、この事実を指しています。暖房が不可能な災害時には、これは大きな長所です。反対に、高温には弱いです。夏に原木の山が直射日光を受けて内部が35℃を超えると、菌糸が傷みます。遮光が必要な理由は、寒さではなく暑さにあります。

### 6-2. 伏せ込みと積み方

| 段階 | 時期（韓国の場合） | 方法 |
|---|---|---|
| 仮伏せ | 接種直後から5月まで | 枕木の上に原木を横にびっしり積み、腰の高さにします。上にわらや木の枝を被せます |
| 本伏せ | 5月から秋まで | 井桁状や枕木状にまばらに積んで、空気が通るようにします |
| 天地返し | 2-3か月に1回 | 上下、内外の原木の位置を入れ替えて、菌糸が均一に広がるようにします |
| 立てかけ | 接種の翌年の10-12月、またはその次の春 | 原木を斜めに互い違いに立てかけます |

> **最初の年は、必ず伏せておきます。早く立てると、原木が早く乾き、菌糸が内部まで入り込む前に乾燥して死んでしまいます。**

&nbsp;&nbsp;&nbsp;伏せている間は、日陰が重要です。広葉樹林の下が最もよく、なければ遮光ネットやヨシズ、わらの覆いで70%ほどの日陰をつくります。雨に当たっても構いません。むしろ原木が乾かないよう助けてくれます。ただし、地面に直接触れた状態で置くと、土の中の雑菌やシロアリが入り込むので、必ず枕木をかませて20cm以上浮かせます。

### 6-3. 水管理

| 時期 | 管理 |
|---|---|
| 春・秋 | 2週間に1回、雨が降らなければたっぷり濡らします |
| 夏 | 7-10日に1回。日中は避けて、日没前後に与えます |
| 冬 | 与えません。凍りつくと樹皮が裂けます |
| 判断基準 | 原木の切断面のひびが大きく開いていたら、水が不足しています |

### 6-4. 菌糸が順調に育っているかの見分け方

| 観察点 | 正常 | 異常 |
|---|---|---|
| 接種穴の周り | 白い菌糸が栓の隙間から見えてきます | 緑色、黒色、オレンジ色が見えたら汚染です |
| 原木の切断面 | 接種の6-10か月後、白い菌糸が断面に現れます | 1年が過ぎても白いものが見えなければ、活着の失敗です |
| 重さ | 原木が次第に軽くなります | 重さが変わらなければ、菌糸が食べていないということです |
| 音 | 叩くと鈍い音がします | 澄んだ音は、まだ硬いということです |
| 樹皮 | 接種の1年半後、褐色の被膜で覆われます | 褐変がなければ、まだ成熟していません |

&nbsp;&nbsp;&nbsp;褐変は、シイタケの原木栽培における成熟のサインです。原木の表面、特に樹皮がはがれた部分と切断面が、濃い褐色の被膜で覆われます。これは、菌糸が空気にさらされた表面で色素をつくり、防御膜を形成したものであり、同時に養分の蓄積が終わったという意味です。褐変が十分に進む前に発生を誘導すると、キノコが数個出て終わってしまい、原木の寿命も短くなります。

## 7. 発生の誘導

&nbsp;&nbsp;&nbsp;菌糸は、居心地がよければ伸び続けるだけです。キノコをつくることは、菌糸にとって危機のサインです。ここの養分がもうすぐ尽きそうだから、胞子をつくってほかの場所へ広がらなければならない、という判断が立ったときに子実体ができます。そのため、発生誘導の原理はすべて同じです。菌糸を驚かせることです。

### 7-1. 3つの刺激

| 刺激 | 方法 | 原理 |
|---|---|---|
| 浸水 | 冷水に原木を12-24時間、完全に浸けます | 急激な水分吸収と温度低下が同時に起こります |
| 打撃 | 立ててある原木を倒すか、ハンマーで切断面を叩きます | 物理的な衝撃が菌糸のネットワークを断ち切り、原基形成を誘います |
| 温度差 | 昼20℃、夜12℃で、8-10℃の差をつくります | 季節変化のサインをまねます |

&nbsp;&nbsp;&nbsp;シイタケに最もよく効くのは浸水です。水槽や小川に原木を丸ごと沈めて1日置き、引き上げて立てておくと、1週間以内に原基ができます。水が冷たいほど効果が大きいです。夏にぬるい水で浸水すると、反応が弱いだけでなく、細菌性の軟腐病にかかりやすくなります。小川の水や井戸水のように、15℃以下の水を使います。

&nbsp;&nbsp;&nbsp;浸水できる水がなければ、打撃で代用します。立ててある原木をまとめて押し倒し、1日後にまた立てます。切断面を木づちで3、4回叩くのも効果があります。ただし、樹皮がはがれるほど強く叩くと、その場所から雑菌が入ります。

### 7-2. 発生の条件

| 項目 | 条件 | 備考 |
|---|---|---|
| 発生温度 | 10-25℃、最適15-18℃ | 品種により、低温性5-15℃、中温性10-20℃、高温性15-25℃ |
| 原基形成温度 | 15-25℃、最適20-22℃ | |
| 空中湿度 | 発生初期85-95%、生育期70-90% | 過湿になると水っぽいキノコになります |
| 光 | 間接光が必要。新聞が読める明るさ | 真っ暗闇では原基ができません |
| 換気 | 二酸化炭素がたまらないように | こもると、柄ばかり長くなり、傘が小さくなります |

&nbsp;&nbsp;&nbsp;シイタケが光を必要とする点は、ほかの多くのキノコと異なります。光合成をするのではなく、光をサインとして使います。真っ暗な場所では、原基が形成されないか、奇形になります。かといって、直射日光はいけません。原木が乾き、傘が割れます。森の中の日陰程度、手のひらをかざしたときに影がぼんやりできる明るさが適切です。

### 7-3. 立て方と配置

| 項目 | 方法 |
|---|---|
| 角度 | 地面に対して70-80˚の斜めに立てます |
| 配置 | 横木に原木を互い違いに立てかけるか、三脚のような形で互いにもたれかけさせます |
| 間隔 | 原木と原木の間5-10cm |
| 向き | 原木の列の向きを南北にすると、日光が均等に当たります |
| 地面 | 落ち葉やわらを敷いて、土が跳ね上がらないようにします |

&nbsp;&nbsp;&nbsp;立てる角度が急すぎると、水が流れ落ちて下側だけが濡れ、寝かせすぎると、上側の面にだけキノコが出ます。70-80˚が折衷点です。立てた後は、3-4週間に1回、上下をひっくり返してやると、原木全体から均等に発生します。

## 8. 収穫と再発生の周期

### 8-1. 収穫時期の判断

| 基準 | 内容 |
|---|---|
| 傘の開き具合 | 60-80%開いたとき。完全に開くと肉が薄くなり、胞子を飛ばします |
| 傘の縁 | まだ内側に巻いている状態 |
| ひだ | 白色で、まだ褐色に染まっていません |
| 時間帯 | 早朝。日中に採ると水分が多く、貯蔵性が落ちます |

&nbsp;&nbsp;&nbsp;乾燥して貯蔵するのであれば、もう少し開いてから採ってもよいですが、傘の裏側のひだが褐色に染まり始めたら遅すぎます。すでに胞子を飛ばしたキノコは、肉がすかすかになり、香りが抜けます。

### 8-2. 採り方のコツ

&nbsp;&nbsp;&nbsp;柄をつかんで左右にひねりながら、軽く引いて採ります。真上に引っ張ると、原木の表面がいっしょにはがれてしまい、その傷から雑菌が入ります。石づきが原木に残ったら、残った部分をナイフの先できれいにこそげ取ります。残った石づきは、腐りながら細菌やハエを呼び寄せます。採ったキノコはすぐに日陰に広げ、その日のうちに乾燥を始めます。

### 8-3. 等級

| 等級 | 特徴 | 条件 |
|---|---|---|
| 花どんこ | 傘の表面が亀の甲羅のように白くひび割れた最上級 | 低温期に乾いた風に当たりながらゆっくり育ったとき |
| どんこ | 傘が丸く厚みがあり、ひび割れが少ない上級 | 低温期の正常な生育 |
| 香信 | 傘が薄く広く開いた普通品 | 高温期や過湿の条件 |

&nbsp;&nbsp;&nbsp;花どんこが出る条件は、低い温度と乾いた空気です。キノコがゆっくり育つ間に、傘の表面が割れて白い肉があらわになります。災害時には、等級は商品性の問題ではなく、貯蔵性の問題として見るべきです。肉厚のどんこと花どんこは、乾燥させたときに体積あたりの栄養が多く、長持ちします。

### 8-4. 休養と再発生

| 段階 | 期間 | 内容 |
|---|:---:|---|
| 収穫 | 7-14日 | 1回の発生で出るキノコをすべて採ります |
| 休養 | 10-12日以上 | 日陰に伏せるか、立てたままにして、刺激を与えません |
| 回復 | 30-60日 | 菌糸が再び養分を蓄えます。急ぐほど、次の収量が減ります |
| 再刺激 | 浸水または打撃 | 回復が終わった後に再び刺激します |

&nbsp;&nbsp;&nbsp;欲張って休養なしに浸水を続けると、原木が早く消耗します。4-5年使えるはずの原木を、2年で捨てることになります。シイタケ原木の寿命は、総発生量が決まっている貯金箱のようなもので、早く取り出すほど早く空になります。災害時には、長く引っ張っていくほうがはるかに有利です。

### 8-5. 年次別の収量

| 年次 | 収量の傾向 | 管理 |
|---|---|---|
| 1年目（接種の翌年） | 少ない。試験的に発生する程度 | 無理をしません |
| 2-3年目 | 最も多く出ます | 春と秋にそれぞれ1-2回発生 |
| 4年目 | 減り始めます | 新しい原木に接種しておきます |
| 5年目 | 最後。原木が軟らかくなります | 廃原木は、種菌の原料や堆肥として使います |

&nbsp;&nbsp;&nbsp;原木1本の総生産量は、直径12cm、長さ1mで、4-5年間に生シイタケ1.2-2kg程度です。1人がおかずとしてコンスタントに食べるには、原木30-50本を回す必要があり、そのためには毎年8-10本ずつ新たに接種して、世代を重ねておかなければなりません。この世代の重ね方が、シイタケ栽培の核心的な設計です。

> **シイタケは、毎年少しずつ原木を新しく補充して世代を重ねておかなければ、途切れてしまいます。1年にまとめて接種すると、4年後にいっぺんに途切れます。**
