## 引言
&nbsp;&nbsp;&nbsp;香菇（Lentinula edodes）在评价中获得综合A，49.2分（有效183种中第24位）。它是分解栎类枯木而生的白腐菌，所以既不翻地，也不施肥，也不按田地用水，只要求木头，因此即使没有可翻的地、没有可撒的肥，只要山上有栎树就有粮食。它不进行光合作用，所以日照减半时产量也几乎不变（光照SS）。弱点是慢（从接种到第一朵蘑菇要1年至1年半）和热量几乎为零（鲜品每100g只有22kcal）。香菇不是主食，而是提供蛋白质、B族维生素和鲜味的配菜（副食SS，短期B）。作为回报，一段段木接种一次，就能春秋两季连续出菇4-5年，所以灾害第一年种下、第二年开始收获，是长期自立的支柱。本文以没有电、没有高压灭菌器、没有无菌室为前提写成。

## 2. 蘑菇概述
&nbsp;&nbsp;&nbsp;属担子菌门伞菌纲伞菌目脐菇科香菇属，是分解阔叶树枯木中木质素和纤维素的白腐菌。

| 特征 | 内容 |
|:---|:---|
| 菌盖 | 直径5-20cm。从半球形展开为扁平。褐色至暗褐色，表面有时像龟甲一样开裂 |
| 菌褶、菌柄 | 菌褶白色至淡褐色，排列紧密，与菌柄凹生。菌柄长3-10cm，粗1-2cm，纤维质坚韧 |
| 菌环、孢子 | 内菌幕的痕迹像绒毛一样留在菌柄上部或菌盖边缘。孢子白色（与安全确认直接相关） |

&nbsp;&nbsp;&nbsp;一粒孢子长不出蘑菇。孢子萌发的初生菌丝只有一半基因，不能形成蘑菇而逐渐死去，只有两条不同交配型的初生菌丝相遇结合而成的次生菌丝，才能占领整根段木并结出蘑菇。所以孢子要把粉末足量地撒入。

| 阶段 | 时期与温度 | 要点 |
|:---|:---|:---|
| 接种、定殖 | 3月底至4月初，15-20℃ | 菌种附着在段木上需要3-4天 |
| 菌丝蔓延 | 定殖后12-18个月，22-25℃ | 整个断面被白色菌丝覆盖，后期表面被褐色菌膜（转色）覆盖就是成熟的信号 |
| 出菇、休养 | 刺激后7-14天（10-25℃），采收后10-12天 | 形成原基，菌盖生长。休养期间菌丝重新积累养分 |

&nbsp;&nbsp;&nbsp;每100g鲜品热量22kcal、蛋白质2.74g（占热量的49.8%），干品约272kcal、蛋白质约7.6g。维生素B1、B2约为蔬菜的2倍，麦角固醇受紫外线照射会转变为维生素D2。还含有香菇多糖（β-葡聚糖类多糖）。

## 3. 段木与培养料
> **没有电的话，香菇就是段木栽培。灭菌工序整个消失，仅这一个理由就足以盖过其他所有不便。**

| 段木 | 标准 |
|:---|:---|
| 树种 | 最适：麻栎、槲栎、枹栎、蒙古栎（木质素多、边材厚，菌丝的食物多）。可用：板栗、鹅耳枥、桤木、樱树（产量比栎类少20-30%）。禁用：针叶树（树脂和萜烯抑制菌丝）、漆树和核桃（化感物质杀死菌丝） |
| 规格 | 直径9-15cm（太细干得快，太粗菌丝到不了中心），长1-1.2m（人能抬起并立起来的极限），15-25年生（边材厚而心材还小） |
| 采伐、干燥 | 落叶之后、发芽之前（11-2月）砍伐，晾1-4个月，使含水率降到38-42%。给没晾干的段木接种，绿霉一定会来 |

&nbsp;&nbsp;&nbsp;能灭菌时也可以用锯末培养料（栎类锯末70-80% + 米糠20-30% + 碳酸钙或贝壳粉1%，水分63-65%）。锯末不够时，可把稻草、麦秆、玉米秆、豆荚、稻壳弄碎，替代其中的20-30%。无电灭菌用200L铁桶（底部放水20-30cm，支架上松松地堆放培养料袋，盖上盖子并用湿草袋裹住），蒸汽充满后加热4-6小时，使中心达到95-100℃（插在中心的竹签烫得握不住就行），盖着盖子冷却一夜（趁热打开会随空气吸入孢子）。稻草和稻壳用沸水煮1-2小时，或把切成5cm以下的稻草浸在pH 12-13的石灰水里12-24小时，沥水后把含水率调到65-70%（不冲洗。残留的碱性抑制杂菌，而香菇菌丝比较耐受）。连燃料也没有，就把稻草堆成1-1.5m高发酵到60-70℃，放置2-3周。

## 4. 获取菌种
> **香菇种植中最重要的财产不是蘑菇，而是长满菌丝的段木。这一段就能撑起之后的五年。**

| 方法 | 内容 |
|:---|:---|
| 劈种木（最可靠） | 把菌丝蔓延良好的段木用斧头劈成手指粗的楔子（取白色菌丝密集的部分），用锤子敲进新段木的接种孔。劈开的种木干了就会死，所以立刻使用。把长满菌丝的木头像锯末一样弄碎，混入煮过放凉的新稻草或锯末中，可以增加数量 |
| 组织培养 | 用手撕开新鲜蘑菇（内部接近无菌），把内部菌肉碎片夹进煮过放凉的稻草或锯末之间，或段木的接种孔里，在22-25℃的暗处培养。3-5天长出白色绒毛 |
| 孢子印 | 把菌盖完全展开、无虫蛀的最大最健康个体的菌盖倒扣在铝箔上，罩上碗挡风，会留下白色孢子粉。连铝箔在阴凉处再晾一天后密封（禁止用液体保存）。第一年做20-30张，存放在地窖里 |

&nbsp;&nbsp;&nbsp;把孢子粉足量撒在煮过放凉的稻草上，在20-25℃的暗处培养2-4周，就成了菌种（白色菌丝盖满稻草就成功）。已培养好的菌种（锯末、种木）只能保存约1年（种子寿命C）。自留种S要归功于劈种木。

## 5. 接种、培养、出菇、采收
| 接种 | 标准 |
|:---|:---|
| 时期 | 3月底至4月初，白天10-20℃（5℃以下定殖慢，超过25℃杂菌占先）。阴天无风的早晨或傍晚，在阴凉处 |
| 打孔 | 孔径1.2-1.3cm，深2.4cm，纵向间距3-5cm，横向间距10-15cm，沿段木一圈约7行，呈之字形排列（直径12cm、长1m的段木打25-35个）。没有电钻就用手摇钻或凿子和锤子 |
| 填充、封口 | 把菌种严严实实地填满并压实（松了空气流通，会变干并进杂菌），用木塞或熔化的蜡（石蜡和松香6:4）封住。两端切口也涂蜡，防止水分蒸发 |
| 锯末培养料 | 冷却到25℃以下再接种（热了菌种会死），每kg培养料用菌种50-80g（越多越不怕杂菌），放在上面或中央孔里。工具用火烧后放凉再用，在无风的狭小空间里用湿布把地面和墙壁弄湿，使灰尘沉降 |

| 培养 | 标准 |
|:---|:---|
| 温度 | 接种后3-4天在20℃下定殖（不要动），之后22-25℃。夏季30℃以下（超过35℃菌丝变弱）。冬季冻了也不会死 |
| 平放 | 接种后到5月，把段木横放在垫木上紧密堆到腰高，盖上稻草或树枝。5月到秋季，堆成井字形，要松一些让空气流通，每2-3个月上下、内外翻一次。第一年一定要平放（过早立起，菌丝还没到中心就会干死） |
| 水 | 春秋每2周一次，不下雨就浇透；夏季每7-10天一次，傍晚浇；冬季不浇（冻住会使树皮胀裂）。断面的细裂缝张得很大就是缺水 |
| 确认 | 接种孔周围透出白色菌丝（绿色、黑色、橙色是污染），6-10个月后断面出现白色菌丝（1年后还看不到就是定殖失败），1年半后表面被褐色菌膜覆盖（转色，成熟的信号） |

&nbsp;&nbsp;&nbsp;接种次年的10-12月或再下一个春天，把段木与地面成70-80˚斜向交错立起来（靠在横杆或三脚架上，间距5-10cm，地面铺落叶或稻草）。出菇刺激有浸水（冷水中12-24小时，最有效）、敲击（把段木放倒，或用锤子敲断面，没有水时代替）、温差（白天20℃，夜里12℃）。出菇温度为10-25℃（最适15-18℃，按品种分，低温型5-15℃，中温型10-20℃，高温型15-25℃），空气湿度出菇初期85-95%，生长期70-90%（太湿会成水菇），需要能看报纸程度的散射光和通风（完全黑暗不形成原基，二氧化碳积累则菌柄变长、菌盖变小）。

| 采收 | 标准 |
|:---|:---|
| 时期、要领 | 菌盖开到60-80%、边缘仍向内卷、菌褶白色时，在清晨采收（白天采水分多，耐储性下降）。要晒干的话，可以多开一点，但菌褶开始变褐就晚了。握住菌柄左右拧动并轻轻拉下 |
| 等级 | 花菇（菌盖表面像龟甲一样裂出白纹的最上等，在低温期吹着干燥的风慢慢长成时）、冬菇（圆而厚的上等）、香信（薄而展开宽的普通品，高温期或过湿时） |
| 再出菇 | 采收7-14天，休养10-12天以上（不刺激），恢复30-60天（越急，下次产量越少）之后，再用浸水或敲击刺激。不休养而一直浸水，段木会很快耗尽 |
| 各年产量 | 第1年（接种次年）少，第2-3年最多（春秋各1-2次），第4年开始减少，所以要接种新段木，第5年段木变软成为废段木。一段段木（直径12cm、长1m）4-5年出鲜香菇1.2-2kg |

&nbsp;&nbsp;&nbsp;每年都要一点一点补充新段木，使世代相叠，才不会断。如果集中在一年接种，4年后会一下子全断。

## 6. 污染、病虫害与异常诊断
&nbsp;&nbsp;&nbsp;蘑菇种植失败的第一个原因既不是病也不是虫，而是竞争霉菌。木霉（绿霉）一开始也是白色绒毛，看到绿色时孢子已经形成了数亿个，所以要靠速度和形态来判断。

| 观察项目 | 香菇菌丝 | 木霉 |
|:---|:---|:---|
| 颜色 | 始终白色 | 白色经黄色变为亮绿色、蓝绿色 |
| 速度 | 每天2-3mm | 每天7-10mm |
| 边缘 | 绒毛整齐均匀地扩展 | 像扇骨一样扩展，形成同心圆纹 |
| 气味 | 香菇特有的香味 | 类似椰子的甜味，或潮湿的霉味 |

> **发现橙色的链孢霉（红色面包霉）时，绝对不要打开袋子。孢子极轻，一旦飞散，整个培养室就都完了。连袋烧掉，或深埋到地下。**

| 情况 | 对策 |
|:---|:---|
| 锯末袋污染 | 不要打开，连袋搬出培养室，焚烧或埋到50cm以上的深处 |
| 段木接种孔污染 | 拔出塞子，用刀挖掉被污染的部分，涂上石灰水，放入新菌种再封住 |
| 段木表面大面积污染 | 撒上石灰粉，与其他段木隔开1m以上（有时会恢复） |
| 段木内部也发绿 | 无法恢复。从堆里抽出烧掉 |

&nbsp;&nbsp;&nbsp;工具用沸水烫或火烧，不要把被污染的培养料扔进堆肥场（会变成孢子工厂）。预防就是段木含水率38-42%（湿段木必被污染）、足量接种、早春接种、比菌丝最适温度低1-2℃的培养温度（木霉在高温下长得更快）、用石灰把培养料pH提到6.5-7（木霉喜欢酸性）、离地20cm以上垫起并让空气流通的段木，以及不放在种植地附近的废段木、废培养料和蘑菇根部，这就是全部。害虫有菇蝇（防虫网，涂树脂或糖稀的板，立即清除废培养料）、螨（保持湿度稳定，隔离出菇的段木）、蛞蝓（夜里人工捉，撒一圈灰或锯末）、白蚁和天牛（不要让段木接触地面），晒干的蘑菇会招来烟草甲和印度谷螟，所以要彻底干燥并密封，放入炒过的盐或木炭。

| 症状 | 原因与处理 |
|:---|:---|
| 接种1年后仍看不到菌丝 | 段木太干、菌种活力下降、用了针叶树。浸水提高含水率并重新接种 |
| 菌丝蔓延了却不出菇 | 转色未完成、刺激不足、光不足。等待转色，浸水和敲击并用，保证散射光 |
| 蘑菇变软并有酸味 | 过湿、通风不良、细菌性软腐。减少浇水，立即清除病菇 |
| 菌盖严重开裂 | 空气湿度不足。喷雾或增加遮阴（低温期轻微开裂反而是上品） |

&nbsp;&nbsp;&nbsp;种植地适宜选在阔叶林下70%遮阴、微风通畅、靠近溪流或水井、平缓的北坡或东坡、每天都会经过的路口。废段木把菌丝还活着的部分劈开，用于新段木接种；碎了的做堆肥（木质素已被分解，接近腐殖土，能提高田地的保水力）或蔬菜垄的覆盖物，也可作大球盖菇的培养料（它会直接吃香菇废段木）。

## 7. 误认毒蘑菇与安全确认
> **香菇本身是安全的，但在灾害情况下，人们会去山上采蘑菇吃。必须了解野外容易与香菇混淆的剧毒蘑菇。**

&nbsp;&nbsp;&nbsp;不煮熟就大量吃香菇，可能出现鞭状的红色皮炎（香菇皮炎，香菇多糖类成分所致，加热后消失），生的纤维坚韧也难以消化，所以必须煮熟后吃。变软、有酸味或氨味的要扔掉。

| 类别 | 香菇 | 月夜菌（剧毒） |
|:---|:---|:---|
| 生长 | 栎树等阔叶树枯木上，通常分散生长 | 水青冈、鹅耳枥枯木上，数个重叠成簇生长 |
| 菌盖 | 褐色至暗褐色，有时有龟甲纹 | 紫褐色至暗褐色，有光泽，无纹 |
| 菌褶 | 白色，与菌柄凹生 | 白色，但沿菌柄长长地下延 |
| 菌柄基部 | 切开后里面是均匀的白色 | 切开后有黑色污斑或斑点 |
| 发光、气味 | 不发光。香菇特有的浓香 | 在暗处菌褶发出青白色光。几乎没有气味 |
| 毒性 | 无 | 伊鲁丁S。剧烈呕吐腹泻，大量食用会致死 |

> **把菌柄基部纵向劈开，如果看到黑色污斑，就是月夜菌。这一项确认最可靠。**

&nbsp;&nbsp;&nbsp;野外采集有三条铁律。取孢子印（把菌盖倒扣在白纸和黑纸上，各占一半。香菇是白色孢子），连基部一起挖出来（留下基部会错过菌托或黑色污斑这类决定性标志），第一次吃的蘑菇只吃一种、一口的量，并等待24小时。最安全的答案是不在野外采集。

## 8. 储存、烹调与全年日程
> **蘑菇的耐储性问题几乎全靠干燥一项解决。与其费力延长鲜品的保存期，不如采下当天就开始晒。**

| 储存 | 内容 |
|:---|:---|
| 晒干 | 只拍掉泥土，不要洗（洗了干燥时间变长，香味也跑掉）。厚的切成5-7mm，小的整个晒，菌褶朝上，在竹筛或竹帘上不重叠地摊开（紫外线直接照到菌褶才会生成维生素D），晴天2-3天。日落后收进屋以避夜露，最后一天放在阴凉通风处 |
| 保管 | 完全放凉后装进玻璃瓶、陶罐或厚塑料袋（纸袋挡不住湿气），同时放入用布包好的炒干的盐、木炭块或生石灰。放在阴凉黑暗干燥的地方，梅雨季前后拿出来重新晒一次。常温下3年以上 |
| 其他 | 粉末（2年以上，香味更快散失）、盐渍（焯水后用盐20-30%，6个月至1年）、烟熏干燥（2年以上，雨天也能烘干，但要用燃料）、鲜品阴凉保存（用纸包好3-5天，装进塑料袋一天就变软） |

&nbsp;&nbsp;&nbsp;干香菇用冷水泡20-30分钟（着急时用温水泡15分钟），泡过的水里溶有鸟苷酸和矿物质，不要倒掉，用作汤的底味。加热5-15分钟，煮久了香味会散失。坚韧的菌柄撕碎后久煮，或晒干磨成粉使用。

| 月份 | 作业 |
|:---|:---|
| 1-2月 | 结束段木采伐，检查干燥情况。2月把段木截成1-1.2m，准备接种（蜡、塞子、钻头、检查菌种） |
| 3-4月 | 3月底是适期：打孔、接种、临时平放。4月结束接种，第3-5天首次检查是否污染 |
| 5-8月 | 5月正式平放并搭遮阴。6月开始浇水，从第2年以上的段木采收春季出菇。7月加强遮阴，每7-10天浇一次水（不要超过35℃）。8月翻动段木，检查菇蝇（最危险的月份） |
| 9-10月 | 9月水温降下来后开始浸水刺激。10月秋季采收与晒干，从最好的个体取孢子印 |
| 11-12月 | 11月是段木采伐的最佳期（刚落叶之后），立起段木、劈种木。12月准备越冬，把干品重新晒一遍，整理废段木（段木可在露地越冬） |

> **香菇种植的日程表不是1年，而是5年。今年接种的段木后年上餐桌，这段段木快用尽时，今年种下的另一批段木接替它。**
