## 9. 污染与病虫害

&nbsp;&nbsp;&nbsp;在灾害情境下，蘑菇种植失败的首要原因，既不是病害也不是虫害，而是竞争性霉菌。其中，绿霉，确切地说是木霉属（Trichoderma）的霉菌，尤为突出。香菇菌丝每天延伸2-3mm时，木霉能延伸它的3-4倍。在争夺培养基的竞赛中，一旦我方落败，就没有办法挽回。

### 9-1. 如何识别绿霉

&nbsp;&nbsp;&nbsp;最大的陷阱在于，木霉一开始也是以白色绒毛的形态出现。接种后的最初几天，肉眼无法把它与香菇菌丝区分开。能够区分，要从3-5天之后开始。

| 观察项目 | 香菇菌丝 | 木霉 |
|---|---|---|
| 颜色变化 | 始终保持白色 | 由白色经过淡黄色，变成亮绿色、青绿色 |
| 生长速度 | 每天2-3mm | 每天7-10mm。明显更快 |
| 边缘 | 绒毛整齐、均匀地扩展 | 呈扇形扩展，形成同心圆纹 |
| 质地 | 呈棉絮状或霜状 | 起初为棉絮状，之后变成粉末聚成的团块 |
| 培养基表面 | 无变化 | 有时会出现带有水汽的透明带 |
| 气味 | 香菇特有的香气 | 类似椰子的甜腻气味，或潮湿的霉味 |

&nbsp;&nbsp;&nbsp;一旦看到绿色，就说明已经产生了数亿个孢子。所以必须在颜色出现之前，凭生长速度和边缘形状做出判断。如果接种第3天，只有某一个孔格外快速地蔓延，那就不是香菇。

### 9-2. 区分其他污染菌

| 污染菌 | 颜色与形态 | 条件 | 危险度 |
|---|---|---|:---:|
| 木霉（绿霉） | 亮绿色、青绿色。蔓延迅速 | 高温、过湿、酸性 | 非常高 |
| 青霉 | 青绿色，但粉末更细，边缘有白色带 | 低温、潮湿 | 高 |
| 链孢霉（红色面包霉） | 鲜艳的橙色。爆发式蔓延 | 高温高湿 | 非常高 |
| 毛霉、根霉 | 灰色绒毛上带有黑点 | 培养基含水率过高 | 中等 |
| 曲霉 | 黑色、黄色粉末 | 高温干燥 | 高 |
| 细菌性黏液 | 特征不在颜色，而在于黏稠的黏液和酸臭 | 过湿、通风不良 | 中等 |

> **发现橙色的链孢霉时，绝对不要打开袋子。它的孢子极其轻，一旦飞散，整个培养室都会损失。要连袋一起烧掉，或深埋入地下。**

### 9-3. 发生污染时的处理

| 情况 | 处理 |
|---|---|
| 锯末袋污染 | 不要打开，连袋搬出培养室。焚烧，或深埋50cm以上 |
| 段木接种孔污染 | 拔掉塞子，用刀挖掉被污染的部分，涂上石灰水，放入新菌种再封住 |
| 段木表面大面积污染 | 撒上石灰粉，与其他段木隔开1m以上。有时能够恢复 |
| 段木内部也变绿 | 无法恢复。从堆中取出烧掉 |
| 作业工具 | 浸入沸水，或用火烧 |
| 作业人员衣物 | 穿着接触过污染培养基的衣服，不要去碰健康的培养基 |

&nbsp;&nbsp;&nbsp;把污染的培养基直接扔到堆肥场，那里就会变成孢子工厂。至少要用沸水煮30分钟杀死菌之后，再拿去堆肥。能烧的话，烧掉是最可靠的。

### 9-4. 预防就是一切

| 预防手段 | 内容 |
|---|---|
| 段木干燥 | 把含水率控制在38-42%。湿段木必定会被污染 |
| 接种量 | 要足量，分多处接种。只要菌丝先站稳脚跟，杂菌就进不来 |
| 接种时期 | 早春。气温升高后，木霉会占据大得多的优势 |
| 培养温度 | 比菌丝最适温度低1-2℃。木霉在高温下生长得更快 |
| pH | 用石灰把培养基pH提高到6.5-7。木霉喜欢酸性 |
| 通风 | 让段木离地20cm以上，堆放得便于空气流通 |
| 清理 | 不要把废段木、菌糠、蘑菇基部留在栽培场地附近 |

### 9-5. 虫害

| 害虫 | 危害 | 不用药剂的应对 |
|---|---|---|
| 菌蚊 | 幼虫啃食菌丝和子实体 | 防虫网、代替粘虫板的涂有树脂或谷物糖稀（jocheong）的板子、立即清除菌糠 |
| 螨虫 | 啃食菌丝并传播杂菌 | 保持湿度稳定，把有螨虫的段木隔离 |
| 跳虫 | 啃咬菌丝表面 | 清除地面落叶，撒上草木灰 |
| 白蚁、天牛 | 蛀蚀段木本身，缩短其寿命 | 不让段木接触地面 |
| 蛞蝓 | 啃食子实体 | 夜间用手捉。围一圈草木灰或锯末，阻止其靠近 |
| 储藏害虫 | 干蘑菇上会生烟草甲和印度谷螟 | 彻底干燥、密闭、同时放入炒盐或木炭 |

## 10. 生长异常诊断

| 症状 | 原因 | 处理 |
|---|---|---|
| 接种1年后仍看不到菌丝 | 段木过于干燥、菌种活力下降、使用了针叶树 | 把段木浸水以提高含水率，然后重新接种 |
| 菌丝已蔓延但不出菇 | 转色未完成、刺激不足、光照不足 | 等待转色，把浸水和敲击叠加使用。保证有散射光 |
| 菌柄长而菌盖小 | 二氧化碳积聚、光照不足 | 通风并提高亮度 |
| 菌盖严重开裂 | 空气湿度不足、风干燥 | 喷雾或增加遮阳。低温期轻微开裂反而是上品 |
| 蘑菇变软并有酸味 | 过湿、通风不良、细菌性软腐 | 减少浇水，立即清除发病的个体 |
| 蘑菇很小但数量很多 | 段木养分耗尽、连续出菇过度 | 延长休养时间，并准备新段木 |
| 段木发软，用手一捏就碎 | 寿命结束，或其他腐朽菌侵入 | 废弃，或拿去堆肥 |
| 菌盖表面有褐色斑点 | 褐斑病、水滴痕迹 | 不要直接喷水，增加通风 |

&nbsp;&nbsp;&nbsp;在蘑菇上，缺乏或过量这类概念的作用方式与旱田作物不同。培养基中所含的养分在接种时就已经确定，之后无法再补充。因此，生长异常的原因大多不应从养分中寻找，而应从水、空气、温度、光这四种环境因素中寻找。

## 11. 栽培场地布局与菌糠循环

### 11-1. 不要一直使用同一个地方

&nbsp;&nbsp;&nbsp;评价表中连作适应性的A，是带有条件的数值，条件是更换段木时要转移布置场地。段木立了4-5年的地方，这期间落下的孢子、有机物和死去的菌丝会积累起来，木霉和菌蚊会在上面定居。如果把新段木立在同一个地方，污染率会明显上升。用过一次的场地要休作2-3年，其间可以耙集落叶，或种上蔬菜。

### 11-2. 选择栽培场地的标准

| 项目 | 好的条件 | 应避免的条件 |
|---|---|---|
| 遮阴 | 阔叶林下，遮光70% | 完全黑暗、直射阳光 |
| 风 | 微风徐徐吹过的地方 | 山谷风猛烈吹袭的地方、完全无风的地方 |
| 水 | 靠近小溪或水井的地方 | 必须去远处打水运来的地方 |
| 地形 | 平缓的北坡或东坡 | 朝南的陡坡、积水的低洼地 |
| 可达性 | 每天都会经过的路口 | 容易错过出菇时机的偏僻地方 |

### 11-3. 废段木与菌糠的用途

| 用途 | 方法 |
|---|---|
| 菌种原料 | 把菌丝还活着的部分劈开，用于新段木的接种 |
| 堆肥 | 粉碎后的废段木，木质素已经被分解，接近腐叶土。施入田地后，保水能力会变好 |
| 其他蘑菇的培养基 | 大球盖菇可以直接以香菇的废段木和菌糠为食 |
| 覆盖材料 | 盖在蔬菜的畦上，可抑制杂草并保住水分 |
| 燃料 | 完全干燥的废段木可用作引火柴。但热值比新鲜木材低 |

&nbsp;&nbsp;&nbsp;蘑菇种植不与田间农业竞争，反而对其有益。因为这样就形成了一条流程：从山上取来木头，把它变成蘑菇，再把剩下的残渣送到田里。把香菇栽培场地与菜园挨近布置，这个循环就会缩短。

## 12. 毒蘑菇误认与安全确认

### 12-1. 香菇本身的毒性

&nbsp;&nbsp;&nbsp;香菇食用是安全的。不过有两点需要注意。

| 项目 | 内容 |
|---|---|
| 生食 | 不煮熟而大量食用时，有时会出现鞭打样的红色皮炎（香菇皮炎）。原因是香菇多糖类成分，加热后即会消失 |
| 消化 | 生的纤维坚韧，难以消化。一定要煮熟再吃 |
| 变质的 | 变软、发酸或有氨味时要丢弃 |

### 12-2. 野外容易与香菇混淆的蘑菇

&nbsp;&nbsp;&nbsp;在灾害情境下，人们会去采食山上生长的蘑菇。自认为认识香菇的人，最常中毒的对象就是日本类脐菇。

| 类别 | 香菇 | 日本类脐菇（剧毒） |
|---|---|---|
| 出菇情况 | 长在栎树等阔叶树的枯木上，大多零散分布 | 长在山毛榉、鹅耳枥的枯木上，多个重叠成簇 |
| 菌盖 | 褐色至暗褐色，有时会出现龟甲纹 | 紫褐色至暗褐色，有光泽，没有纹路 |
| 菌褶 | 白色，与菌柄呈弯生 | 白色，但沿菌柄向下延伸（延生） |
| 菌柄基部 | 切开后内部呈均匀的白色 | 切开后有黑色污斑或斑点 |
| 发光 | 无 | 在暗处菌褶发出青白色光 |
| 香气 | 香菇特有的浓郁香气 | 几乎没有香气 |
| 毒性 | 无 | illudin S。引起剧烈呕吐和腹泻，大量食用可致死 |

> **把菌柄基部纵向掰开，如果看到黑色污斑，就是日本类脐菇。仅这一项检查就最为可靠。**

&nbsp;&nbsp;&nbsp;检查发光现象同样有效。把菌盖摘下，放进完全漆黑的房间，等眼睛适应黑暗、过10分钟左右再看，日本类脐菇的菌褶会发出微弱的青白色光。越新鲜的个体越明显。香菇在任何状态下都不会发光。

### 12-3. 野外采集的三条铁律

| 铁律 | 内容 |
|---|---|
| 采取孢子印 | 把菌盖扣放在白纸和黑纸上，使其各跨一半。香菇的孢子是白色的 |
| 连基部一起挖出 | 如果把菌柄基部留下来采摘，就会错过菌托或黑色污斑这类决定性的特征 |
| 一次一种，一次一点 | 第一次吃的蘑菇，只吃一种，只吃一口的量，然后等待24小时 |

&nbsp;&nbsp;&nbsp;最安全的答案是不去野外采集。只吃接种记录清楚的段木上长出来的蘑菇，误认事故就从根本上不会发生。推荐香菇段木栽培的理由之一就在于此。自己种下的地方长出来的蘑菇，就是自己认识的蘑菇。

## 13. 无冰箱贮藏

&nbsp;&nbsp;&nbsp;评价表中，香菇的耐储性为SS。按鲜品计算连几天都放不了的食品，之所以拿到SS，是因为这个评分是以干燥为前提给出的。对比其他许多蘑菇因耐储性为E而被判定为无法储备，这种差别就很明显。香菇容易晒干，晒干后能保存3年以上，而且晒干后味道反而更好。

> **蘑菇的耐储性问题，仅靠干燥这一项就几乎全部解决。与其费力延长鲜品的保存时间，不如在采摘当天就开始晾晒，这才是正确答案。**

### 13-1. 干燥的原理

&nbsp;&nbsp;&nbsp;鲜香菇的水分为88-90%。在这种状态下，水分活度超过0.98，细菌和霉菌可以尽情繁殖。把水分降到12%以下，水分活度就会降到0.6以下，在这之下，微生物会停止活动。冷藏只是减缓微生物的速度，而干燥是让其活动彻底停止。这就是在没有电的环境中，干燥具有压倒性优势的原因。

### 13-2. 日光干燥

| 步骤 | 方法 |
|---|---|
| 处理 | 只掸去泥土，不要清洗。沾水后干燥时间会变长，香气也会流失 |
| 切片 | 厚的切成5-7mm的片。小的整个晒干 |
| 摆放 | 让菌褶朝上放置。紫外线必须直接照到菌褶，才能生成维生素D |
| 摊开 | 摊在竹筛或竹帘上，不要重叠。下面要能通风 |
| 日程 | 晴天晒2-3天。日落后收进屋，避开夜露 |
| 收尾 | 最后一天放在阴凉通风处，把里面也晾干 |

&nbsp;&nbsp;&nbsp;判断是否完全干燥，要用手。对折时不弯曲，发出“啪”的一声断开，就说明干透了。只要稍微弯曲或发韧，就说明还有水分，储存期间会长霉。

&nbsp;&nbsp;&nbsp;晒干的香菇比机器烘干的更胜一筹的地方，在于维生素D。香菇中所含的麦角固醇，受到紫外线照射就会转化为维生素D2。让菌褶朝上，只晒半天太阳就会发生转化；如果在干燥之前先晒两个小时左右的紫外线再晾干，效果会更大。在室内生活时间变长、新鲜食品断供的灾害情境下，这是能防住一种营养缺乏的实实在在的好处。

### 13-3. 保存

| 项目 | 方法 |
|---|---|
| 放凉 | 完全放凉后再装入。趁温热时密封，里面会结露 |
| 容器 | 玻璃瓶、坛子、厚塑料袋。纸袋挡不住湿气 |
| 吸湿剂 | 把炒干的盐、木炭碎块、生石灰用布包好，一起放进去 |
| 地点 | 阴凉、黑暗、干燥的地方。土窖或地下室最为理想 |
| 回晒 | 在韩国的梅雨季（6月下旬至7月）前后各取出一次，重新晒干 |
| 期限 | 彻底干燥并密封，常温下可保存3年以上 |

### 13-4. 其他储存方法

| 方法 | 期限 | 备注 |
|---|:---:|---|
| 干燥 | 3年以上 | 效果最好 |
| 粉末 | 2年以上 | 彻底干燥后磨碎。可直接放进粥和汤里。香气流失得更快 |
| 盐渍 | 6个月-1年 | 焯水后，用相当于蘑菇重量20-30%的盐一层一层地腌制。盐珍贵时，优先级较低 |
| 烟熏干燥 | 2年以上 | 下雨天也能烘干，不易生虫。需要燃料 |
| 鲜品阴凉处保存 | 3-5天 | 用纸包好，放在阴凉处。装进塑料袋，一天就会变软 |

## 14. 烹饪与加工

&nbsp;&nbsp;&nbsp;香菇属于用燃料较少的食材。鲜品5-10分钟就熟，干品要泡发后再用，所以加热时间短。在灾害情境下，燃料和粮食一样珍贵，这一点值得纳入计算。

| 步骤 | 方法 |
|---|---|
| 泡发 | 冷水泡20-30分钟。着急的话用温水泡15分钟 |
| 泡发水 | 不要倒掉。其中溶有鸟苷酸和矿物质，可作为汤的底味 |
| 加热 | 5-15分钟。煮得太久，香气会散失 |
| 菌柄 | 韧，直接吃很困难。撕碎后长时间炖煮，或晒干磨成粉使用 |

&nbsp;&nbsp;&nbsp;用冷水慢慢泡发，鲜味释放得最多。用热水快速泡发，时间虽然缩短，但鸟苷酸的生成会减少。养成前一天晚上泡水的习惯，既能省燃料，味道也更好。

&nbsp;&nbsp;&nbsp;磨成粉后，用途会更广。往粥、汤、面团、凉拌野菜（namul）里各加一勺，就能同时补充蛋白质和鲜味。也不需要泡发的时间。不过粉末的香气流失得快，所以最好需要多少就当场磨多少。

## 15. 全年作业日程

| 月份（以韩国气候为准） | 作业 | 备注 |
|:---:|---|---|
| 1月 | 收尾段木砍伐，检查正在干燥的段木 | 隆冬也可以砍伐 |
| 2月 | 截断段木（1-1.2m），准备接种，确认菌种 | 提前备好封蜡、塞子和钻头 |
| 3月 | 开始打孔和接种，临时平放 | 月底是最佳时期 |
| 4月 | 完成接种，首次检查有无污染 | 接种第3-5天时的检查很重要 |
| 5月 | 正式平放，设置遮阳 | 为夏季高温做准备 |
| 6月 | 开始浇水，采收春季出菇的香菇 | 出自第2年及以上的段木 |
| 7月 | 加强遮阳以防高温，每隔7-10天灌水 | 不要超过35℃ |
| 8月 | 翻动段木，检查菌蚊 | 是最危险的月份 |
| 9月 | 为秋季出菇做准备，浸水刺激 | 水温下降后开始 |
| 10月 | 秋季收获，晾晒作业，采集孢子印 | 用最好的个体来取孢子 |
| 11月 | 段木砍伐最佳时期，立放，劈制木楔菌种 | 刚落完叶之后最好 |
| 12月 | 越冬准备，干品回晒，整理废段木 | 段木可以在露地越冬 |

&nbsp;&nbsp;&nbsp;如表所示，香菇的作业集中在春季的接种和秋季的收获、晾晒。夏季和冬季只是检查而已。这种季节分布与田间农业的繁忙时期基本不重叠，使得香菇很适合与其他作物搭配种植。春天种马铃薯、接种香菇，秋天挖马铃薯、晾晒香菇，这样的流程可以自然地安排下来。

> **香菇种植的日程表，不是1年，而是5年。今年接种的段木，后年上餐桌；这批段木耗尽之时，今年种下的另一批段木接替它的位置。**
