## 9. 汚染と病害虫

&nbsp;&nbsp;&nbsp;災害時にキノコ栽培が失敗する第一の原因は、病気でも害虫でもなく、競合するカビです。その中でも緑カビ、正確にはトリコデルマ（Trichoderma）属のカビが圧倒的です。シイタケ菌糸が1日に2-3mm伸びるとき、トリコデルマはその3-4倍伸びます。培地をめぐる競争でこちらが負ければ、取り返す方法はありません。

### 9-1. 緑カビの見分け方

&nbsp;&nbsp;&nbsp;最大の落とし穴は、トリコデルマも最初は白い綿毛のように始まるという点です。接種直後の数日間は、シイタケ菌糸と目で区別がつきません。区別できるようになるのは、3-5日後からです。

| 観察項目 | シイタケの菌糸 | トリコデルマ |
|---|---|---|
| 色の変化 | 白色を保ち続けます | 白色から黄みを帯びた色を経て、明るい緑色、青緑色に変わります |
| 成長速度 | 1日2-3mm | 1日7-10mm。目に見えて速いです |
| 縁 | 綿毛が整って均一に広がります | 扇状に広がり、同心円の模様をつくります |
| 質感 | 綿または霜のような状態 | 最初は綿状、のちに粉が固まったかたまり |
| 培地の表面 | 変化なし | 水気を帯びた透明な帯ができることがあります |
| におい | シイタケ特有の香り | ココナッツに似た甘いにおい、または湿っぽいカビ臭 |

&nbsp;&nbsp;&nbsp;緑色が見えた時点で、すでに胞子が数億個もつくられた状態です。したがって、判断は色が出る前に、成長速度と縁の形で下さなければなりません。接種3日目に、ある穴の1か所だけが際立って速く広がっているなら、それはシイタケではありません。

### 9-2. そのほかの汚染菌の見分け方

| 汚染菌 | 色と形 | 条件 | 危険度 |
|---|---|---|:---:|
| トリコデルマ（緑カビ） | 明るい緑色、青緑色。速く広がる | 高温、過湿、酸性 | 非常に高い |
| ペニシリウム | 青緑色だが粉がより細かく、縁に白い帯がある | 低温、湿潤 | 高い |
| ニューロスポラ（アカパンカビ） | 鮮やかなオレンジ色。爆発的に広がる | 高温多湿 | 非常に高い |
| ケカビ、クモノスカビ | 灰色の綿毛に黒い点が混じる | 培地の含水率が過多 | 中程度 |
| アスペルギルス | 黒色、黄色の粉 | 高温乾燥 | 高い |
| 細菌性のぬめり | 色ではなく、べたつく粘液と酸っぱい悪臭 | 過湿、通気不良 | 中程度 |

> **オレンジ色のニューロスポラを見つけたら、絶対に袋を開けないでください。胞子が非常に軽く、一度飛散すると、その培養室全体を失います。袋ごと燃やすか、地中に深く埋めます。**

### 9-3. 汚染されたときの対処

| 状況 | 対処 |
|---|---|
| おが粉の袋の汚染 | 開けずに、袋ごと培養室の外へ運び出します。焼却するか、50cm以上の深さに埋めます |
| 原木の接種穴の汚染 | 栓を抜き、汚染部分をナイフでえぐり取ってから、石灰水を塗り、新しい種菌を入れて再びふさぎます |
| 原木の表面が広く汚染 | 石灰の粉をまぶし、ほかの原木から1m以上離しておきます。回復することがあります |
| 原木の内部まで緑色 | 回復しません。山から取り出して燃やします |
| 作業道具 | 熱湯に浸けるか、火で熱します |
| 作業者の服 | 汚染培地に触れた服で、健康な培地に触れないようにします |

&nbsp;&nbsp;&nbsp;汚染された培地をそのまま堆肥場に捨てると、そこが胞子の工場になります。最低でも熱湯で30分煮て菌を殺してから、堆肥に回します。燃やせるなら、燃やすのが最も確実です。

### 9-4. 予防がすべてです

| 予防手段 | 内容 |
|---|---|
| 原木の乾燥 | 含水率38-42%を守ります。湿った原木は必ず汚染されます |
| 接種量 | たっぷりと、多くの箇所に。菌糸が先に居場所を確保すれば、雑菌は入れません |
| 接種時期 | 早春。気温が上がると、トリコデルマがはるかに有利になります |
| 培養温度 | 菌糸の最適温度より1-2℃低くします。トリコデルマは高温でより速く育ちます |
| pH | 石灰で培地のpHを6.5-7に上げます。トリコデルマは酸性を好みます |
| 通気 | 原木を地面から20cm以上浮かせ、空気が回るように積みます |
| 清掃 | 廃原木、廃培地、キノコの石づきを栽培地の近くに置きません |

### 9-5. 害虫

| 害虫 | 被害 | 薬剤を使わない対応 |
|---|---|---|
| キノコバエ | 幼虫が菌糸と子実体を食い荒らします | 防虫ネット、粘着シートの代わりに樹脂やチョチョン（穀物の水あめ）を塗った板、廃培地の即時除去 |
| ダニ | 菌糸を食べ、雑菌を運びます | 湿度を一定に保つ、被害の出た原木は隔離 |
| トビムシ | 菌糸の表面をかじります | 地面の落ち葉を取り除いて、草木灰をまきます |
| シロアリ、カミキリムシ | 原木そのものをかじって寿命を縮めます | 原木を地面に触れさせません |
| ナメクジ | 子実体をかじって食べます | 夜に手で捕まえます。草木灰やおが粉の帯を巡らせて近づけないようにします |
| 貯蔵害虫 | 乾燥キノコにタバコシバンムシやスジコナマダラメイガがつきます | 完全乾燥、密閉、炒った塩や炭を同封 |

## 10. 生育異常の診断

| 症状 | 原因 | 対処 |
|---|---|---|
| 接種から1年経っても菌糸が見えない | 原木が乾きすぎている、種菌の活力低下、針葉樹の使用 | 原木を浸水して含水率を上げ、再接種します |
| 菌糸は広がったのにキノコが出ない | 褐変が未完了、刺激不足、光不足 | 褐変を待ち、浸水と打撃を併用します。間接光を確保します |
| 柄ばかり長く傘が小さい | 二酸化炭素の蓄積、光不足 | 換気して、明るさを上げます |
| 傘がひどく割れる | 空中湿度の不足、乾いた風 | 霧吹きをするか、遮光を増やします。低温期の軽いひび割れは、むしろ上等品です |
| キノコが軟らかくなり酸っぱいにおいがする | 過湿、通気不良、細菌性の軟腐 | 水やりを減らし、病気の個体をすぐに取り除きます |
| キノコがとても小さく数が多い | 原木の養分の消耗、連続発生のしすぎ | 休養を長くとり、新しい原木を準備します |
| 原木が軟らかく、手で崩れる | 寿命の終了、またはほかの腐朽菌の侵入 | 廃棄するか、堆肥に回します |
| 傘の表面に褐色の斑点 | 褐斑病、水滴の跡 | 水を直接かけず、通風を増やします |

&nbsp;&nbsp;&nbsp;キノコでは、欠乏や過剰という概念が、畑作物とは違う形で働きます。培地に含まれる養分は、接種の時点ですでに決まっており、後から追加することはできません。そのため、生育異常の原因は、ほとんどの場合、養分ではなく、水、空気、温度、光という4つの環境要因に求めなければなりません。

## 11. 栽培地の配置と廃培地の循環

### 11-1. 同じ場所を使い続けません

&nbsp;&nbsp;&nbsp;評価表の連作適応性Aは、原木の交換時に配置場所を移すという条件付きの値です。原木を4-5年立てておいた場所には、その間に落ちた胞子や有機物、死んだ菌糸がたまり、その上にトリコデルマやキノコバエが居ついてしまいます。新しい原木を同じ場所に立てると、汚染率が目に見えて上がります。一度使った場所は2-3年休ませ、その間は落ち葉をかき集めたり、野菜を植えたりします。

### 11-2. 栽培地を選ぶ基準

| 項目 | 良い条件 | 避けるべき条件 |
|---|---|---|
| 日陰 | 広葉樹林の下で70%遮光 | 真っ暗闇、直射日光 |
| 風 | 穏やかに通る場所 | 谷風が強く吹きつける場所、まったく風のない場所 |
| 水 | 小川や井戸が近い場所 | 水を汲んで運んでこなければならない場所 |
| 地形 | 緩やかな北斜面や東斜面 | 南向きの急斜面、水がたまる低地 |
| 近づきやすさ | 毎日通る通り道 | 発生時期を見逃しやすい人里離れた場所 |

### 11-3. 廃原木と廃培地の使い道

| 用途 | 方法 |
|---|---|
| 種菌の原料 | 菌糸がまだ生きている部分を割って、新しい原木への接種に使います |
| 堆肥 | 砕いた廃原木は、リグニンがすでに分解されていて、腐葉土に近い状態です。畑に入れると保水力が良くなります |
| 他のキノコの培地 | サケツバタケは、シイタケの廃原木や廃培地をそのまま食べます |
| マルチング材 | 野菜の畝に敷くと、雑草を抑え、水分を保ちます |
| 燃料 | 完全に乾いた廃原木は、焚きつけに使います。ただし、熱量は生木より低いです |

&nbsp;&nbsp;&nbsp;キノコ栽培は、畑作と競合せず、むしろ畑作の助けになります。山から木を持ってきてキノコに変え、残ったかすを畑に送る流れができるからです。シイタケの栽培地と野菜畑を近くに置けば、この循環が短くなります。

## 12. 毒キノコの誤認と安全確認

### 12-1. シイタケ自体の毒性

&nbsp;&nbsp;&nbsp;シイタケは食用として安全です。ただし、注意すべき点が2つあります。

| 項目 | 内容 |
|---|---|
| 生食 | 加熱せずにたくさん食べると、鞭打ち状の赤い皮膚炎（シイタケ皮膚炎）が出ることがあります。レンチナン系の成分が原因で、加熱すれば消えます |
| 消化 | 生は繊維が硬く、消化しにくいです。必ず加熱して食べます |
| 傷んだもの | 軟らかくなり、酸っぱいにおいやアンモニア臭がしたら捨てます |

### 12-2. 野生でシイタケと取り違えられるキノコ

&nbsp;&nbsp;&nbsp;災害時には、人々は山に生えるキノコを採って食べるようになります。シイタケを知っているつもりの人が、最も多く中毒を起こす相手が、ツキヨタケです。

| 区分 | シイタケ | ツキヨタケ（猛毒） |
|---|---|---|
| 発生の様子 | ナラ類などの広葉樹の枯死木に、たいていばらばらに出る | ブナ、アカシデの枯死木に、複数が重なって束になって出る |
| 傘 | 褐色から暗褐色、亀甲模様ができることもある | 紫褐色から暗褐色、光沢があり、模様がない |
| ひだ | 白色、柄に湾生 | 白色だが、柄に沿って長く垂れて付く（垂生） |
| 柄の根元 | 切ると中が均一な白色 | 切ると黒いしみや斑点がある |
| 発光 | なし | 暗所でひだが青白く光る |
| 香り | シイタケ特有の濃い香り | 香りがほとんどない |
| 毒性 | なし | イルジンS。激しい嘔吐と下痢、大量に食べると死に至る |

> **柄の根元を縦に裂いて黒いしみが見えたら、ツキヨタケです。この確認ひとつが、最も確実です。**

&nbsp;&nbsp;&nbsp;発光の確認も有効です。傘を採って、完全に真っ暗な部屋に置き、目が暗闇に慣れてから10分ほど経って見ると、ツキヨタケはひだがぼんやりと青白く光ります。新鮮な個体ほどはっきりしています。シイタケは、どんな状態でも光りません。

### 12-3. 野生キノコ採集の3つの鉄則

| 鉄則 | 内容 |
|---|---|
| 胞子紋を採る | 白い紙と黒い紙の上に半分ずつかかるように、傘を伏せて置きます。シイタケの胞子は白色です |
| 根元まで掘り取る | 柄の根元を残して採ると、つぼや黒いしみのような決定的な目印を見逃します |
| 1種類ずつ、少しずつ | 初めて食べるキノコは、1種類だけ、ひと口の大きさだけ食べて、24時間待ちます |

&nbsp;&nbsp;&nbsp;最も安全な答えは、野生のキノコを採集しないことです。接種の履歴がはっきりしている原木から出たキノコだけを食べれば、誤認事故は根本的に起こりません。シイタケの原木栽培を勧める理由のひとつがこれです。自分が植えた場所に出たキノコは、自分が知っているキノコです。

## 13. 冷蔵庫なしの貯蔵

&nbsp;&nbsp;&nbsp;評価表で、シイタケの貯蔵性はSSです。生の状態では数日ともたない食品がなぜSSを得たのかといえば、乾燥を前提として付けた値だからです。ほかの多くのキノコが貯蔵性Eで備蓄不可と判定されているのと比べると、この違いははっきりします。シイタケは乾燥させやすく、乾燥させれば3年以上もち、乾燥させるとかえって味がよくなります。

> **キノコの貯蔵性の問題は、乾燥ひとつでほぼすべて解決します。生の貯蔵期間を延ばそうと苦心する代わりに、採ったその日に乾燥を始めるのが正解です。**

### 13-1. 乾燥の原理

&nbsp;&nbsp;&nbsp;生シイタケの水分は88-90%です。この状態では水分活性が0.98を超え、細菌やカビが思う存分繁殖します。水分を12%以下に下げると、水分活性が0.6を下回り、それ以下では微生物が活動を止めます。冷蔵は微生物の速度を遅らせるだけですが、乾燥は活動そのものを停止させます。電気のない環境で、乾燥が圧倒的に有利な理由です。

### 13-2. 日光乾燥

| 手順 | 方法 |
|---|---|
| 下処理 | 土を払い落とすだけで、洗いません。水に触れると、乾く時間が長くなり、香りが抜けます |
| 切る | 厚いものは5-7mmにスライスします。小さいものは丸ごと乾燥させます |
| 配置 | ひだを上に向けて置きます。紫外線がひだに直接当たらないと、ビタミンDがつくられません |
| 広げる | ざるやすだれの上に、重ならないように。下から空気が通るようにします |
| 日程 | 晴れの日に2-3日。日が沈んだら取り込んで、夜露を避けます |
| 仕上げ | 最後の1日は日陰の風に当てて、中まで乾かします |

&nbsp;&nbsp;&nbsp;完全に乾いたかどうかの判定は、手で行います。半分に折ったとき、曲がらずに「パキッ」と音を立てて折れれば、でき上がりです。少しでも曲がったり、しなやかで弾力があったりすれば、まだ水分が残っており、保管中にカビが生えます。

&nbsp;&nbsp;&nbsp;日に干したシイタケが機械で乾燥したものより優れている点が、ビタミンDです。シイタケに含まれるエルゴステロールは、紫外線を受けるとビタミンD2に変わります。ひだを上に向けて半日ほど日に当てるだけでも変換が起こり、乾燥の前に2時間ほど紫外線を浴びさせてから干すと、効果がさらに大きくなります。屋内での生活が長引き、生鮮食品が途絶えた災害時には、これは欠乏のひとつを防いでくれる実質的な利点です。

### 13-3. 保管

| 項目 | 方法 |
|---|---|
| 冷ます | 完全に冷めてから容器に入れます。温かいうちに密閉すると、中で結露が生じます |
| 容器 | ガラス瓶、甕、厚手のビニール。紙袋は湿気を防げません |
| 吸湿剤 | からからに炒った塩、炭のかけら、生石灰を布に包んで、一緒に入れます |
| 場所 | 涼しく、暗く、乾燥した場所。土室や地下室が理想的です |
| 再乾燥 | 韓国の梅雨（チャンマ、6月下旬～7月）の前後に1回ずつ取り出して、再び乾燥させます |
| 期間 | 完全に乾燥させて密閉すれば、常温で3年以上 |

### 13-4. そのほかの貯蔵方法

| 方法 | 期間 | 備考 |
|---|:---:|---|
| 乾燥 | 3年以上 | 最も優れています |
| 粉末 | 2年以上 | 完全に乾燥させてから砕きます。お粥や汁物にそのまま入れます。香りがより早く抜けます |
| 塩漬け | 6か月-1年 | ゆでてから、キノコの重さの20-30%の塩を層にして漬け込みます。塩が貴重な場合は、優先順位が低くなります |
| 燻煙乾燥 | 2年以上 | 雨の日でも乾燥できて、虫がつきにくいです。燃料が要ります |
| 生のまま日陰で保管 | 3-5日 | 紙に包んで涼しい場所に置きます。ビニールに入れると、1日で軟らかくなります |

## 14. 調理と加工

&nbsp;&nbsp;&nbsp;シイタケは、燃料をあまり使わずにすむ食材です。生なら5-10分で火が通り、乾燥したものは戻して使うので、加熱時間が短くてすみます。災害時には燃料も食料と同じくらい貴重なので、この点は計算に入れる価値があります。

| 手順 | 方法 |
|---|---|
| 戻す | 冷水に20-30分。急ぐ場合はぬるま湯に15分 |
| 戻し汁 | 捨てません。グアニル酸とミネラルが溶け出していて、汁物のベースになります |
| 加熱 | 5-15分。長く煮ると香りが飛びます |
| 柄 | 硬くてそのまま食べにくいです。細かく裂いて長く煮るか、乾燥させて砕き、粉にして使います |

&nbsp;&nbsp;&nbsp;冷水でゆっくり戻すと、うま味が最もよく出ます。熱いお湯で素早く戻すと、時間は短縮できますが、グアニル酸の生成が少なくなります。前の晩に水に浸けておく習慣をつければ、燃料も節約でき、味も引き立ちます。

&nbsp;&nbsp;&nbsp;粉にしておくと、使い道が広がります。お粥、スープ、生地、ナムル（韓国風の野菜の和え物）にひとさじずつ加えると、タンパク質とうま味が一緒に補えます。戻す時間も要りません。ただし粉は香りが早く抜けるため、必要な分だけその都度砕くほうがよいです。

## 15. 年間作業スケジュール

| 月（韓国の気候基準） | 作業 | 備考 |
|:---:|---|---|
| 1月 | 原木の伐採を仕上げる、乾燥中の原木の点検 | 真冬の伐採も可能です |
| 2月 | 原木の玉切り（1-1.2m）、接種の準備、種菌の確認 | ろう、栓、ドリルの刃を前もって用意します |
| 3月 | 穴あけと接種の開始、仮伏せ | 月末が適期です |
| 4月 | 接種の仕上げ、汚染の有無の最初の点検 | 接種3-5日目の確認が重要です |
| 5月 | 本伏せ、遮光の設置 | 夏の高温に備えます |
| 6月 | 水やりの開始、春に発生したキノコの収穫 | 2年目以上の原木から出ます |
| 7月 | 高温対策の遮光強化、7-10日間隔での灌水 | 35℃を超えないようにします |
| 8月 | 原木の天地返し、キノコバエの点検 | 最も危険な月です |
| 9月 | 秋の発生の準備、浸水刺激 | 水温が下がったら始めます |
| 10月 | 秋の収穫、乾燥作業、胞子紋の採取 | 最も良い個体から胞子を採ります |
| 11月 | 原木の伐採の最適期、立てかけ、種駒づくり | 葉が落ちた直後が最もよいです |
| 12月 | 越冬の準備、乾燥品の再乾燥、廃原木の整理 | 原木は露地で越冬できます |

&nbsp;&nbsp;&nbsp;表からわかるように、シイタケの作業は、春の接種と秋の収穫・乾燥に集中しています。夏と冬は点検程度です。この季節的な分布が、畑作の忙しい時期と大きく重ならないという点が、シイタケをほかの作物と一緒に栽培しやすくしています。春にジャガイモを植えてシイタケを接種し、秋にジャガイモを掘ってシイタケを乾燥させるという流れが、自然に組み上がります。

> **シイタケ栽培のスケジュール表は、1年ではなく5年です。今年接種した原木は再来年に食卓に上り、その原木が尽きるころには、今年植えた別の原木が後を引き継ぎます。**
