## はじめに
&nbsp;&nbsp;&nbsp;シイタケ(Lentinula edodes)は、評価で総合A、49.2点(有効183種中24位)を得ました。ナラ類の枯れ木を分解して生きる白色腐朽菌なので、土を耕すことも、肥料をやることも、畑単位で水を引くこともなく、木だけを要求します。耕す土も、まく肥料もなくても、山にナラ類さえあれば食料が得られます。光合成をしないので、日射が半分になっても収量はほとんど変わりません(日射SS)。弱みは、遅いこと(接種から最初のキノコまで1年-1年半)と、熱量がほとんどないこと(生100gで22kcal)です。シイタケは主食ではなく、タンパク質、ビタミンB群、うま味を補うおかず(副食SS、短期B)です。その代わり、原木1本に一度接種すれば、4-5年のあいだ春と秋に出続けるので、災害の初年に植えて2年目から収穫する、長期自立の柱です。この文書は、電気も高圧殺菌器も無菌室もないという前提で書きました。

## 1. 災害への備えの評価
| 区分 | 内容 |
|:---|:---|
| 判定 | 総合A、49.2点(有効183種中24位)。短期B 47.4、長期S 51.0、副食SS 64.8 |
| 強み | SS: タンパク質密度、日射、貯蔵性、整地・掘削エネルギー、収量の安定性。S: 永続性、耐寒性、味、国内での栽培の普及度、自家採種 |

> **キノコは日光が消えた世界でも収量が減らない唯一の食料源です。それがシイタケを植える第一の理由です。**

&nbsp;&nbsp;&nbsp;連作への適応性Aは、原木を替えるときに栽培地も移すという条件が付いた値です。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. キノコの概要
&nbsp;&nbsp;&nbsp;担子菌門ハラタケ綱ハラタケ目ツキヨタケ科シイタケ属で、広葉樹の枯れ木のリグニンとセルロースを分解する白色腐朽菌です。

| 特徴 | 内容 |
|:---|:---|
| かさ | 直径5-20cm。半球形から平らに開く。褐色-暗褐色で、表面が亀の甲のように裂けることもある |
| ひだ、柄 | ひだは白色-淡褐色で密に並び、柄に湾生する。柄は長さ3-10cm、太さ1-2cmで、繊維質が硬い |
| つば、胞子 | 内被膜の跡が、柄の上のほうやかさの縁に綿毛のように残る。胞子は白色(安全の確認に直結) |

&nbsp;&nbsp;&nbsp;胞子1個からはキノコは出ません。胞子が発芽した1次菌糸は遺伝子が半分しかないのでキノコをつくれず死に絶え、異なる交配型の1次菌糸2本が出会って結合した2次菌糸だけが、原木全体を掌握してキノコを結びます。そのため胞子は、粉をたっぷり振り入れます。

| 段階 | 時期と温度 | 要点 |
|:---|:---|:---|
| 接種、活着 | 3月末-4月初め、15-20℃ | 種菌が原木につくまで3-4日 |
| 菌糸のまん延 | 活着の後12-18か月、22-25℃ | 木口全体が白い菌糸に覆われ、末期に表面が褐色の被膜(褐変)に覆われれば成熟の合図 |
| 発生、休養 | 刺激の後7-14日(10-25℃)、収穫の後10-12日 | 原基ができ、かさが育つ。休養のあいだに菌糸が養分をふたたび集める |

&nbsp;&nbsp;&nbsp;100g当たり、生は熱量22kcal、タンパク質2.74g(熱量比49.8%)で、乾燥品は約272kcal、タンパク質約7.6gです。ビタミンB1・B2は野菜の約2倍で、エルゴステロールは紫外線を受けるとビタミンD2に変わります。レンチナン(ベータグルカン系の多糖類)も含まれます。

## 3. 原木と培地
> **電気がなければ、シイタケは原木栽培です。殺菌の工程がまるごと消えるというこの理由ひとつが、ほかのあらゆる不便を覆います。**

| 原木 | 基準 |
|:---|:---|
| 樹種 | 最適: クヌギ、ナラガシワ、コナラ、モンゴリナラ(リグニンが多く辺材が厚いので、菌糸のえさが多い)。可能: クリ、アカシデ、ハンノキ、サクラ(収量がナラ類より20-30%少ない)。禁止: 針葉樹(樹脂とテルペンが菌糸を抑える)、ウルシ・クルミ(他感物質が菌糸を殺す) |
| 規格 | 直径9-15cm(細いと早く乾き、太いと菌糸が芯まで届かない)、長さ1-1.2m(人が持ち上げて立てられる限界)、樹齢15-25年(辺材が厚く心材がまだ小さい) |
| 伐採、乾燥 | 落葉の後、芽吹く前(11-2月)に伐り、1-4か月乾かして含水率を38-42%にする。乾き足りない原木に接種すると、アオカビが必ず来る |

&nbsp;&nbsp;&nbsp;殺菌ができるなら、おがくず培地(ナラ類のおがくず70-80% + 米ぬか20-30% + 炭酸カルシウムか貝殻粉1%、水分63-65%)も使えます。おがくずが足りなければ、稲わら、麦わら、トウモロコシの茎、豆のさや、もみ殻を細かく砕いて20-30%まで置き換えます。電力のない殺菌は、200Lのドラム缶(底に水20-30cm、台の上に培地の袋をゆるく積み、ふたをして濡らしたむしろで包む)で、蒸気が満ちた後4-6時間加熱して芯を95-100℃にし(刺しておいた串が手で握れないほど熱ければよい)、ふたをしたまま一晩冷まします(熱いうちに開けると、空気と一緒に胞子が吸い込まれる)。わらともみ殻は熱湯で1-2時間ゆでるか、5cm以下に切ったわらをpH12-13の石灰水に12-24時間浸した後、水を切って含水率を65-70%に整えます(すすがない。残ったアルカリが雑菌を抑え、シイタケの菌糸は比較的耐える)。燃料もなければ、わらを1-1.5mに積んで発酵させ、60-70℃にして2-3週間置きます。

## 4. 種菌の確保
> **シイタケ栽培で最も大切な財産は、キノコではなく、菌糸がびっしり入った原木です。その1本が次の5年をつくります。**

| 方法 | 内容 |
|:---|:---|
| 種木割り(最も確実) | 菌糸がよく広がった原木を斧で割って、指の太さの楔(白い菌糸が密な部分)をつくり、新しい原木の接種穴にハンマーで打ち込む。割った種木は乾くと死ぬので、すぐ使う。菌糸が広がった木をおがくずのように砕いて、ゆでて冷ました新しい稲わらやおがくずに混ぜると、量を増やせる |
| 組織培養 | 新鮮なキノコを手で裂き(中は無菌に近い)、中の肉片を、ゆでて冷ました稲わらやおがくずの間、または原木の接種穴にはさみ、22-25℃の暗い場所で培養する。3-5日で白い綿毛が広がる |
| 胞子紋 | かさが開ききって虫食いのない、最も大きく健康な個体のかさを、アルミ箔の上に伏せ、器をかぶせて風を防ぐと、白い胞子の粉が残る。箔ごと日陰でもう1日乾かして密封する(液体での保管は禁止)。初年に20-30枚つくり、土室に貯える |

&nbsp;&nbsp;&nbsp;胞子の粉は、ゆでて冷ました稲わらにたっぷりまき、20-25℃の暗い場所で2-4週間培養すれば種菌になります(白い菌糸がわらを覆えば成功)。培養済みの種菌(おがくず・種木)は約1年しか持ちません(種子の寿命C)。自家採種Sは種木割りのおかげです。

## 5. 接種、培養、発生、収穫
| 接種 | 基準 |
|:---|:---|
| 時期 | 3月末-4月初め、昼の気温10-20℃(5℃以下だと活着が遅く、25℃を超えると雑菌が先行する)。曇って風のない日の早朝か夕暮れ、日陰で |
| 穿孔 | 穴の直径1.2-1.3cm、深さ2.4cm、縦の間隔3-5cm、横の間隔10-15cm、原木の周りに7列ほどを千鳥に(直径12cm、長さ1mの原木に25-35個)。電動ドリルがなければ、手動ドリルか、のみとハンマー |
| 詰める、封じる | 種菌を隙間なくぎっしり詰めて押し固め(ゆるいと空気が回って乾き、雑菌が入る)、木の栓か、溶かしたろう(パラフィンと松脂を6対4)で塞ぐ。両側の切り口にもろうを塗って水分の蒸発を防ぐ |
| おがくず培地 | 25℃以下に冷ましてから(熱いと種菌が死ぬ)、培地1kg当たり種菌50-80g(多いほど雑菌に強い)を上面にのせるか中央の穴に詰める。道具は火であぶって冷ましてから使い、風のない狭い空間で、濡らした布で床と壁を湿らせてほこりを沈める |

| 培養 | 基準 |
|:---|:---|
| 温度 | 接種後3-4日は20℃で活着させ(触らない)、その後は22-25℃。夏は30℃以下(35℃を超えると菌糸が弱る)。冬は凍っても死なない |
| 寝かせ | 接種直後-5月は、台木の上に原木を横にぎっしり腰の高さに積み、わらや枝をかぶせる。5月-秋は井桁に粗く積んで空気を通し、2-3か月に1回、上下、内外を入れ替えて返す。初年は必ず寝かせておく(早く立てると、菌糸が芯に届く前に乾いて枯れる) |
| 水 | 春秋は2週間に1回、雨が降らなければたっぷり、夏は7-10日に1回、夕暮れに、冬はやらない(凍ると樹皮が裂ける)。木口の細かい割れが大きく開いていれば水不足 |
| 確認 | 接種穴の周りに白い菌糸が見え(緑色・黒色・オレンジ色は汚染)、6-10か月後に木口に白い菌糸が現れ(1年たっても見えなければ活着の失敗)、1年半後に表面が褐色の被膜に覆われる(褐変、成熟の合図) |

&nbsp;&nbsp;&nbsp;接種の翌年の10-12月か、その次の春に、原木を地面に対して70-80˚で斜めに交差させて立てます(横木や三脚に寄りかからせ、間隔5-10cm、地面に落ち葉やわらを敷く)。発生の刺激は、浸水(冷水に12-24時間、最もよく効く)、打撃(原木を倒すか、ハンマーで木口をたたく、水がないときの代用)、温度差(昼20℃、夜12℃)です。発生の温度は10-25℃(最適15-18℃、品種により低温性5-15℃、中温性10-20℃、高温性15-25℃)、空中湿度は発生の初めが85-95%、生育期が70-90%(湿りすぎると水っぽいキノコになる)で、新聞が読める程度の間接光と換気が必要です(真っ暗では原基ができず、二酸化炭素がたまると柄だけが長くなってかさが小さくなる)。

| 収穫 | 基準 |
|:---|:---|
| 時期、要領 | かさが60-80%開き、縁がまだ内側に巻いていて、ひだが白いときに、早朝に収穫する(昼に採ると水分が多く、貯蔵性が落ちる)。干すなら少し多く開いてもよいが、ひだが褐色になり始めたら遅い。柄を持ってひねり、軽く引いて取る |
| 等級 | 花どんこ(かさの表面が亀の甲のように白く割れた最上級、低温期に乾いた風に当たってゆっくり育つとき)、どんこ(丸くて厚い上級)、香信(薄く広く開いた普通品、高温期や過湿のとき) |
| 再発生 | 収穫7-14日、休養10-12日以上(刺激なし)、回復30-60日(急ぐほど次の収量が減る)の後、浸水か打撃で再び刺激する。休養なしに浸水を続けると、原木が早く消耗する |
| 年次別の収量 | 1年目(接種の翌年)は少なく、2-3年目に最も多く出て(春秋に各1-2回)、4年目に減り始めるので新しい原木に接種し、5年目に原木が軟らかくなって廃原木になる。原木1本(直径12cm、長さ1m)から4-5年間に生シイタケ1.2-2kg |

&nbsp;&nbsp;&nbsp;毎年、原木を少しずつ新しく補って世代を重ねておかなければ、途切れます。1年に集中して接種すると、4年後に一度に途切れます。

## 6. 汚染と病害虫、異常の診断
&nbsp;&nbsp;&nbsp;キノコ栽培が失敗する第一の原因は、病気でも害虫でもなく、競合するカビです。トリコデルマ(アオカビ)も最初は白い綿毛で始まり、緑色が見える頃にはすでに胞子が数億個できているので、速さと形で見分けます。

| 観察項目 | シイタケの菌糸 | トリコデルマ |
|:---|:---|:---|
| 色 | 白色のまま | 白色から黄ばみを経て、明るい緑色、青緑色 |
| 速さ | 1日2-3mm | 1日7-10mm |
| 縁 | 綿毛がそろって均等に広がる | 扇の骨のように広がり、同心円の模様 |
| におい | シイタケ特有の香り | ココナッツに似た甘いにおい、またはじめじめしたかび臭 |

> **オレンジ色のニューロスポラ(アカパンカビ)を見つけたら、絶対に袋を開けてはいけません。胞子が非常に軽く、一度飛ぶと、その培養室全体を失います。袋ごと燃やすか、地面に深く埋めます。**

| 状況 | 対処 |
|:---|:---|
| おがくずの袋の汚染 | 開けずに袋ごと培養室の外へ運び、焼却するか50cm以上の深さに埋める |
| 原木の接種穴の汚染 | 栓を抜き、汚染された部分をナイフでえぐり取って石灰水を塗り、新しい種菌を入れて再び塞ぐ |
| 原木の表面の広い汚染 | 石灰の粉をまぶし、ほかの原木と1m以上離しておく(回復することもある) |
| 原木の芯まで緑色 | 回復しない。山から抜き出して燃やす |

&nbsp;&nbsp;&nbsp;道具は熱湯に浸けるか火であぶり、汚染された培地を堆肥場に捨てないでください(胞子の工場になる)。予防は、原木の含水率38-42%(濡れた原木は必ず汚染される)、たっぷりの接種量、早春の接種、菌糸の最適より1-2℃低い培養温度(トリコデルマは高温で速く育つ)、石灰で上げた培地のpH 6.5-7(トリコデルマは酸性を好む)、地面から20cm以上離して空気が回るように積んだ原木、栽培地の近くに置かない廃原木・廃培地・キノコの切り株で、これがすべてです。害虫は、キノコバエ(防虫網、樹液や水あめを塗った板、廃培地をすぐ除去)、ダニ(湿度を一定に、発生中の原木を隔離)、ナメクジ(夜に手で捕まえ、灰やおがくずの帯)、シロアリ・カミキリムシ(原木を地面に触れさせない)がいて、干したキノコにはタバコシバンムシとノシメマダラメイガがつくので、完全に乾燥させて密封し、よく炒った塩か炭を入れます。

| 症状 | 原因と対処 |
|:---|:---|
| 接種から1年たっても菌糸が見えない | 原木が乾きすぎ、種菌の活力低下、針葉樹の使用。浸水して含水率を上げ、再接種 |
| 菌糸は広がったのにキノコが出ない | 褐変が未完了、刺激不足、光不足。褐変を待ち、浸水と打撃を重ね、間接光を確保 |
| キノコが軟らかくなって酸っぱいにおいがする | 過湿、通気不良、細菌性の軟腐。水やりを減らし、病んだ個体をすぐ除去 |
| かさがひどく裂ける | 空中湿度の不足。噴霧するか遮光を増やす(低温期の軽い裂けは、むしろ上等品) |

&nbsp;&nbsp;&nbsp;栽培地は、広葉樹林の下で70%遮光、風がやわらかく通り、小川か井戸が近く、なだらかな北斜面か東斜面で、毎日通る道筋がよい場所です。廃原木は、菌糸が生きている部分を割って新しい原木の接種に使い、砕いたものは堆肥(リグニンがすでに分解されて腐葉土に近く、畑の保水力を高める)や野菜の畝のマルチ材にしたり、サケツバタケの培地(シイタケの廃原木をそのまま食べる)にしたりします。

## 7. 毒キノコの誤認と安全の確認
> **シイタケ自体は安全ですが、災害時には人々が山のキノコを採って食べるようになります。野生でシイタケと間違えやすい猛毒のキノコを知っておく必要があります。**

&nbsp;&nbsp;&nbsp;シイタケを加熱せずにたくさん食べると、むち状の赤い皮膚炎(シイタケ皮膚炎)が出ることがあり(レンチナン系の成分、加熱すると消える)、生は繊維が硬くて消化も難しいので、必ず火を通して食べます。軟らかくなって酸っぱいにおいやアンモニア臭がするものは捨てます。

| 区分 | シイタケ | ツキヨタケ(猛毒) |
|:---|:---|:---|
| 発生 | ナラ類などの広葉樹の枯れ木、たいてい散らばって出る | ブナやアカシデの枯れ木に、何本も重なって束になって出る |
| かさ | 褐色-暗褐色、亀の甲の模様が出ることもある | 紫褐色-暗褐色、光沢があり、模様がない |
| ひだ | 白色、柄に湾生 | 白色だが、柄に沿って長く垂生 |
| 柄の根元 | 切ると中が均一な白色 | 切ると黒い染みや斑点がある |
| 発光、におい | 発光しない。シイタケ特有の濃い香り | 暗い所でひだが青白く光る。においがほとんどない |
| 毒性 | なし | イルジンS。激しい嘔吐と下痢、大量に食べると死亡 |

> **柄の根元を縦に裂いて黒い染みが見えたら、ツキヨタケです。この確認ひとつが最も確実です。**

&nbsp;&nbsp;&nbsp;野生での採取の鉄則は3つです。胞子紋を取ること(白い紙と黒い紙の上に半分ずつまたがせてかさを伏せておく。シイタケは白い胞子)、根元まで掘り取ること(根元を残して採ると、つぼや黒い染みのような決定的な目印を見逃す)、初めて食べるキノコは1種類だけをひと口の量で食べて24時間待つことです。最も安全な答えは、野生での採取をしないことです。

## 8. 貯蔵、調理、年間日程
> **キノコの貯蔵性の問題は、乾燥ひとつでほとんどすべて解けます。生での保存期間を延ばそうと苦心する代わりに、採ったその日に干し始めるのが正解です。**

| 貯蔵 | 内容 |
|:---|:---|
| 天日乾燥 | 土だけを払い、洗わない(洗うと乾く時間が長くなり、香りが抜ける)。厚いものは5-7mmに切り、小さいものは丸ごと、ひだを上に向けて、ざるやすだれに重ならないように並べ(紫外線がひだに直接当たってはじめてビタミンDができる)、晴れた日に2-3日。日が沈んだら取り込んで夜露を避け、最後の1日は日陰の風に当てる |
| 保管 | 完全に冷ましてから、ガラス瓶、かめ、厚いビニールに入れ(紙袋は湿気を防げない)、よく炒った塩、炭のかけら、生石灰を布に包んで一緒に入れる。涼しく暗く乾いた場所に置き、梅雨の前後に取り出して干し直す。常温で3年以上 |
| その他 | 粉末(2年以上、香りがより早く抜ける)、塩蔵(ゆでて塩20-30%、6か月-1年)、燻製乾燥(2年以上、雨の日も干せるが燃料がいる)、生の日陰保管(紙に包んで3-5日、ビニールに入れると1日で軟らかくなる) |

&nbsp;&nbsp;&nbsp;干したシイタケは、冷水に20-30分浸し(急ぐときはぬるま湯に15分)、戻し汁はグアニル酸とミネラルが溶けているので捨てず、だしのもとにします。5-15分加熱し、長く煮ると香りが飛びます。硬い柄は、細かく裂いて長く煮るか、干して挽いて粉にして使います。

| 月 | 作業 |
|:---|:---|
| 1-2月 | 原木の伐採を終え、乾燥を点検する。2月に原木を切りそろえ(1-1.2m)、接種の準備(ろう、栓、ドリルの刃、種菌の確認) |
| 3-4月 | 3月末が適期: 穿孔、接種、仮の寝かせ。4月に接種を終え、3-5日目に汚染の有無を最初に点検する |
| 5-8月 | 5月に本寝かせと遮光の設置。6月に水やりを始め、2年目以上の原木から春の発生を収穫する。7月に遮光を強め、7-10日おきに水をやる(35℃を超えさせない)。8月に原木を返し、キノコバエを点検する(最も危険な月) |
| 9-10月 | 9月、水温が下がったら浸水の刺激を始める。10月に秋の収穫と乾燥、最も良い個体から胞子紋を採る |
| 11-12月 | 11月は原木の伐採の最適期(落葉の直後)で、立て込みと種木割りをする。12月に越冬の準備、乾燥品の干し直し、廃原木の整理(原木は野外で越冬できる) |

> **シイタケ栽培の日程表は1年ではなく5年です。今年接種した原木は再来年に食卓に上り、その原木が尽きるころ、今年植えた別の原木が後を継ぎます。**
