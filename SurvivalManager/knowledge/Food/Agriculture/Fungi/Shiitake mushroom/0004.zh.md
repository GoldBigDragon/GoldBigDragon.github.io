## 5. 接种方法

&nbsp;&nbsp;&nbsp;接种是香菇种植中人为介入最多的阶段，也是成败被决定的阶段。此后一年半的结果，就取决于这一天。原则很简单：让香菇菌丝先于杂菌占据段木。为此，必须多放菌种、在多个位置放、动作要快，并把放过菌种的位置封住。

### 5-1. 时间与天气

| 项目 | 标准 | 理由 |
|---|---|---|
| 时期 | 在韩国为3月底至4月初 | 段木温度适合菌丝定殖，杂菌活动还比较缓慢 |
| 气温 | 白天10-20℃ | 5℃以下定殖缓慢，超过25℃杂菌就会占先 |
| 天气 | 阴天无风的日子 | 晴朗有风的日子，空气中飘散的孢子很多 |
| 时间段 | 清晨或傍晚 | 避开干燥和直射阳光 |
| 地点 | 阴凉处，可能的话在室内 | 接种面干了，定殖率就会下降 |

### 5-2. 打孔

| 项目 | 标准 |
|---|---|
| 孔径 | 1.2-1.3cm |
| 孔深 | 2.4cm |
| 纵向间距 | 3-5cm |
| 横向间距 | 10-15cm |
| 行数 | 沿段木周围7行左右，呈之字形交错排列 |
| 总孔数 | 以直径12cm、长1m的段木计，25-35个 |

&nbsp;&nbsp;&nbsp;之所以按之字形交错打孔，是因为菌丝在木材内部沿纵向的蔓延速度，比沿年轮方向快3-4倍。如果把孔整整齐齐地打成一行，菌丝就会沿着这一行像带子一样向下延伸，行与行之间的空间会长时间空着。交错打孔，整根段木就会被覆盖得更均匀、更快。

&nbsp;&nbsp;&nbsp;孔越多越好。接种点多，菌丝就能同时从多个位置延伸，杂菌能钻的空子就会减少。如果菌种不够、必须减少孔数，与其减少每根的孔数，不如减少段木的根数，给剩下的段木足量接种。草草接种的10根段木，不如认真接种的5根效果好。

&nbsp;&nbsp;&nbsp;没有电钻时，可以用木工手摇钻，或用凿子和锤子来打孔。要让深度一致，可以在钻头上缠胶带做标记，或在凿子上贴一块木片限制深度。打好孔后不能放置太久，打孔当天就要完成接种。

### 5-3. 填入菌种与密封

| 步骤 | 方法 |
|---|---|
| 填入 | 把菌种严严实实地塞满孔中。如果松垮，空气流通会使其变干，杂菌也会侵入 |
| 压实 | 用手指或木棒按压压实 |
| 密封 | 敲入木塞，或嵌上泡沫塑料塞，或把封蜡熔化后覆盖 |
| 蜡的配比 | 把石蜡和松香按6比4熔化后使用。比纯石蜡附着力更好，也不易开裂 |
| 截面处理 | 在段木两端的截面也涂上封蜡，防止水分蒸发 |

&nbsp;&nbsp;&nbsp;密封的目的有两个：不让水分散失，和不让杂菌进入。没有封蜡时，可以用和好的泥巴涂抹，或削一个木塞敲入孔中、再在上面盖上湿苔藓来代替。虽然不完美，但比什么都不做好得多。

### 5-4. 劈制木楔菌种接种

&nbsp;&nbsp;&nbsp;这是在没有市售菌种时使用的方法。用斧头把菌丝蔓延良好的旧段木劈开，做成长3-4cm、粗1-1.5cm的木楔。再用锤子把这些木楔敲入新段木上打好的孔中，用木塞或封蜡封住。木楔干了就会死，所以必须劈好后立刻敲入，作业期间要用湿布盖住。

&nbsp;&nbsp;&nbsp;挑选木楔时，要用白色菌丝密集充满的部分。木头发软、用手一捏就碎的部分，可能是养分已经耗尽，或已被其他菌侵入的地方。劈开的断面如果散发蘑菇特有的香气，就是好迹象；如果有霉味或酸味，这根段木就不要用。

### 5-5. 锯末培养基接种

| 项目 | 标准 |
|---|---|
| 培养基温度 | 放凉到25℃以下之后 | 趁热放入会使菌种死亡 |
| 接种量 | 每1kg培养基用菌种50-80g | 越多越能抵抗杂菌 |
| 方式 | 放在袋子上表面，或填入中央的孔洞 | |
| 工具消毒 | 把勺子或夹子在火上烧红后放凉再用 | |
| 作业环境 | 没有风的狭小空间，用湿布把地面和墙壁弄湿，让灰尘沉降 | |

&nbsp;&nbsp;&nbsp;没有无菌室时的诀窍，是减少空气中的灰尘。作业前30分钟，在房间地面和墙壁上洒水，让灰尘沉降，关上门，只让一个人进去。呼气的方向不要朝着培养基，要把头转开，也不要说话。只要做到这些，污染率就能降到一半以下。

## 6. 菌丝培养管理

&nbsp;&nbsp;&nbsp;接种结束后，就开始12-18个月的培养。这段时间的目标，是让菌丝彻底占据段木内部并积累养分。人要做的事不多，但不该做的事很明确：不让它变干，不让它暴露在直射阳光下，不要过早立起来。

### 6-1. 温度与湿度

| 时期 | 温度 | 段木含水率 | 管理 |
|---|:---:|:---:|---|
| 接种后最初3-4天 | 20℃ | 38-42% | 促进定殖。不要触动 |
| 定殖之后 | 22-25℃ | 35-45% | 菌丝伸长最快的阶段 |
| 夏季 | 保持在30℃以下 | 不要让它变干 | 超过35℃菌丝会变弱 |
| 冬季 | 自然气温 | 注意结露 | 冻了也不会死。翌年会再次生长 |

&nbsp;&nbsp;&nbsp;香菇菌丝在零下温度也不会死。段木状态下可以在露地越冬，翌年春天气温回升后会再次生长。评价表中耐寒性的S指的就是这一点。在无法供暖的灾害情境下，这是很大的优点。相反，它怕高温。夏季段木堆受到直射阳光、内部超过35℃时，菌丝会受损。需要遮阳的原因不在于寒冷，而在于炎热。

### 6-2. 平放与堆码

| 阶段 | 时期（韩国的情况） | 方法 |
|---|---|---|
| 临时平放 | 接种后立即至5月 | 在垫木上把段木横向密密地堆放，堆到齐腰高。上面盖上稻草或树枝 |
| 正式平放 | 5月至秋季 | 堆成井字形或枕木形，堆得疏松些，让空气流通 |
| 翻堆 | 每2-3个月一次 | 把上下、里外的段木位置对调，让菌丝蔓延均匀 |
| 立放 | 接种次年的10-12月，或再下一个春季 | 把段木斜着交错立放 |

> **第一年一定要平放。过早立起来，段木会很快变干，菌丝还没深入到木心就干死了。**

&nbsp;&nbsp;&nbsp;平放期间，遮阴很重要。阔叶林下最好，没有的话就用遮阳网、芦苇帘或草帘搭出70%左右的阴凉。淋雨也没关系，反倒有助于段木不干。但如果直接接触地面，土中的杂菌和白蚁会侵入，所以必须垫上垫木，使其离地20cm以上。

### 6-3. 水分管理

| 时期 | 管理 |
|---|---|
| 春秋 | 每2周一次，不下雨就浇透 |
| 夏季 | 每7-10天一次。避开正午，傍晚时浇 |
| 冬季 | 不浇水。冻住后树皮会裂开 |
| 判断标准 | 段木截面上的细裂纹明显张开，就说明缺水 |

### 6-4. 如何判断菌丝是否正常生长

| 观察点 | 正常 | 异常 |
|---|---|---|
| 接种孔周围 | 白色菌丝从塞子缝隙中透出来 | 出现绿色、黑色、橙色就是污染 |
| 段木截面 | 接种6-10个月后，截面上出现白色菌丝 | 过了1年还看不到白色菌丝，就是定殖失败 |
| 重量 | 段木逐渐变轻 | 重量没有变化，说明菌丝没有取食 |
| 声音 | 敲击时发出沉闷的声音 | 清脆的声音说明还很坚硬 |
| 树皮 | 接种一年半后被褐色菌膜覆盖 | 没有转色，说明尚未成熟 |

&nbsp;&nbsp;&nbsp;转色是香菇段木栽培成熟的信号。段木表面，尤其是树皮脱落的部分和截面，会被深褐色菌膜覆盖。这是菌丝在暴露于空气的表面产生色素、形成防御膜的结果，同时也意味着养分积累已经完成。如果在转色尚未充分进行时就诱导出菇，只会长出几个蘑菇就不了了之，段木的寿命也会缩短。

## 7. 出菇诱导

&nbsp;&nbsp;&nbsp;菌丝在舒适的环境里只会一味延伸。结出蘑菇，对菌丝来说是一种危机信号：当它判断这里的养分快要耗尽，必须制造孢子扩散到别处时，才会长出子实体。因此，诱导出菇的原理全都一样：让菌丝受一次惊吓。

### 7-1. 三种刺激

| 刺激 | 方法 | 原理 |
|---|---|---|
| 浸水 | 把段木完全浸泡在冷水中12-24小时 | 同时出现急剧吸水和降温 |
| 敲击 | 把立着的段木推倒，或用锤子敲打截面 | 物理冲击切断菌丝网，诱导原基形成 |
| 温差 | 白天20℃、夜间12℃，制造8-10℃的温差 | 模拟季节变化的信号 |

&nbsp;&nbsp;&nbsp;对香菇最有效的是浸水。把段木整根泡进水槽或小溪里放一天，捞出后立起来，一周之内就会形成原基。水越凉，效果越好。夏天用温水浸泡，不仅反应弱，还容易发生细菌性软腐病。要使用小溪水或井水这样15℃以下的水。

&nbsp;&nbsp;&nbsp;没有可以浸泡的水时，就用敲击来代替。把立着的段木一次性全部推倒，一天后再立起来。用木槌在截面上敲三四下，也有效果。但是，如果敲得重到树皮脱落，杂菌就会从那里侵入。

### 7-2. 出菇条件

| 项目 | 条件 | 备注 |
|---|---|---|
| 出菇温度 | 10-25℃，最适15-18℃ | 因品种而异：低温型5-15℃，中温型10-20℃，高温型15-25℃ |
| 原基形成温度 | 15-25℃，最适20-22℃ | |
| 空气湿度 | 出菇初期85-95%，生长期70-90% | 湿度过大会长成水菇 |
| 光 | 需要散射光。亮度要能看清报纸 | 完全黑暗中不会形成原基 |
| 通风 | 不要让二氧化碳积聚 | 不通风的话，菌柄只会变长，菌盖会变小 |

&nbsp;&nbsp;&nbsp;香菇需要光，这一点与许多其他蘑菇不同。它不是在进行光合作用，而是把光当作信号。在完全黑暗的地方，原基不会形成，或者长成畸形。但也不能有直射阳光，那样会使段木变干、菌盖开裂。林中树荫那样的程度，也就是把手掌放上去时影子模糊的亮度，最为合适。

### 7-3. 立放与布置

| 项目 | 方法 |
|---|---|
| 角度 | 与地面成70-80˚斜着立放 |
| 布置 | 把段木交错倚靠在横杆上，或呈三脚架形互相倚靠 |
| 间距 | 段木之间5-10cm |
| 方向 | 段木排的方向定为南北向，阳光就能均匀照到 |
| 地面 | 铺上落叶或稻草，防止泥土溅起 |

&nbsp;&nbsp;&nbsp;立得太直，水会流下来，只有下面湿；放得太斜，蘑菇就只在上面那一侧长出来。70-80˚是折中的角度。立好之后，每3-4周把上下颠倒一次，整根段木就能均匀出菇。

## 8. 收获与再次出菇周期

### 8-1. 判断收获时机

| 标准 | 内容 |
|---|---|
| 菌盖展开程度 | 展开60-80%时。完全展开后菌肉会变薄，并开始散发孢子 |
| 菌盖边缘 | 仍向内卷曲的状态 |
| 菌褶 | 呈白色，还没有被染成褐色 |
| 时间段 | 清晨。白天采摘的话水分多，耐储性会变差 |

&nbsp;&nbsp;&nbsp;如果打算晒干储存，可以等菌盖再展开一些再采，但菌盖背面的菌褶一旦开始变成褐色，就晚了。已经散发过孢子的蘑菇，菌肉松散，香气也会流失。

### 8-2. 采摘要领

&nbsp;&nbsp;&nbsp;握住菌柄，左右扭转并轻轻拉动，把它摘下。如果直接向上拉，段木表面会被一起扯掉，杂菌会从这个伤口侵入。如果菌柄基部残留在段木上，就用刀尖把残留的部分刮干净。残留的基部腐烂时会招来细菌和苍蝇。摘下的蘑菇要立刻摊放在阴凉处，当天就开始晾晒。

### 8-3. 等级

| 等级 | 特征 | 条件 |
|---|---|---|
| 花菇 | 菌盖表面像龟甲一样裂开白色纹路的最上等 | 在低温期吹着干燥的风缓慢生长时 |
| 冬菇 | 菌盖圆而厚、裂纹较少的上等 | 低温期正常生长 |
| 香信 | 菌盖薄而展开宽的普通等级 | 高温期或过湿条件 |

&nbsp;&nbsp;&nbsp;花菇长出的条件是低温和干燥的空气。蘑菇缓慢生长期间，菌盖表面开裂，露出白色菌肉。在灾害情境下，等级不应被看作商品性问题，而应被看作耐储性问题。菌肉厚实的冬菇和花菇晒干后，按体积计算营养更多，而且更耐放。

### 8-4. 休养与再次出菇

| 阶段 | 期间 | 内容 |
|---|:---:|---|
| 收获 | 7-14天 | 把一次出菇长出的蘑菇全部采完 |
| 休养 | 10-12天以上 | 平放在阴凉处，或保持立着，不施加刺激 |
| 恢复 | 30-60天 | 菌丝重新积累养分。越着急，下一次的产量就越少 |
| 再次刺激 | 浸水或敲击 | 恢复结束后再次施加刺激 |

&nbsp;&nbsp;&nbsp;贪心不休养、一个劲儿地浸水，段木就会很快耗尽。本来能用4-5年的段木，2年就得扔掉。香菇段木的寿命就像一个总出菇量已经确定的存钱罐，取得越快，空得越快。在灾害情境下，细水长流要有利得多。

### 8-5. 各年份的产量

| 年份 | 产量趋势 | 管理 |
|---|---|---|
| 第1年（接种次年） | 较少。只是试探性出菇的程度 | 不要勉强 |
| 第2-3年 | 产量最高 | 春秋两季各出菇1-2次 |
| 第4年 | 开始减少 | 提前接种新段木 |
| 第5年 | 最后一年。段木变软 | 废段木用作菌种原料或堆肥 |

&nbsp;&nbsp;&nbsp;一根段木的总产量，以直径12cm、长1m计，4-5年间约为鲜香菇1.2-2kg。要让一个人持续把香菇当配菜吃，就要轮流使用30-50根段木，而这就需要每年新接种8-10根，让不同世代的段木相互叠置。这种叠置，正是香菇种植的核心设计。

> **香菇必须每年陆续补充一点新段木，让不同世代相互叠置，才不会断档。如果在一年里集中接种，4年后就会一下子全部断档。**
