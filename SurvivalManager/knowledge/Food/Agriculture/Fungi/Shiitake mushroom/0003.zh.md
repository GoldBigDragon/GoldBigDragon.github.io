## 3. 培养基材料与准备

&nbsp;&nbsp;&nbsp;培育香菇的方法大体有两种：一种是直接使用圆木的段木栽培，另一种是把营养源掺入锯末后装袋的锯末栽培。平时的商业种植户倾向于周转更快的锯末栽培，但在电力中断的情况下，判断会完全反过来。锯末袋必须灭菌，而灭菌需要燃料。段木则不需要灭菌。圆木内部本来就接近无菌，而且木材自身的防御物质和较低的含水量会抵御杂菌。

> **没有电，香菇就要用段木栽培。仅凭灭菌工序整个消失这一条理由，就足以抵消其他所有不便。**

### 3-1. 挑选段木

| 项目 | 标准 | 理由 |
|---|---|---|
| 最佳树种 | 麻栎、槲栎、枹栎、蒙古栎 | 木质素含量高，边材厚，菌丝的食物多 |
| 可用树种 | 板栗、鹅耳枥、桤木、樱树 | 产量比栎树低20-30% |
| 禁用树种 | 松树、红松、冷杉等针叶树 | 树脂和萜烯会抑制菌丝生长 |
| 禁用树种 | 漆树、核桃树 | 化感物质会杀死菌丝 |
| 直径 | 9-15cm | 太细则容易干，太粗则菌丝无法深入到木心 |
| 长度 | 1-1.2m | 是人能够抬起并立放的极限 |
| 树龄 | 15-25年生 | 边材厚，心材还小 |

&nbsp;&nbsp;&nbsp;砍伐时间左右着产量。在韩国，叶子落尽、树液回流到根部的11月上旬至中旬最为理想。这时砍伐的树木，储藏养分在树干中保留得最多，产量明显高于春季砍伐的树木。砍伐后，保持去枝状态，在阴凉处晾放1-4个月使其干燥。

&nbsp;&nbsp;&nbsp;衡量干燥程度的标准是含水率38-42%。没有水分测定仪时，可以通过三点来判断。第一，锯开的断面上呈放射状出现3-5条细裂纹。一条裂纹都没有，说明还是湿的；裂纹多到超过10条、裂得很开，就是干过头了。第二，重量降到刚砍伐时的85-90%。第三，用指甲按压树皮时不会渗出水分。

&nbsp;&nbsp;&nbsp;在干燥不足的段木上接种，一定会招来绿霉。段木内水分多时，树木自身的细胞还活着，会阻止香菇菌丝侵入，杂菌便趁机先站稳脚跟。反过来，如果过于干燥，菌丝没有水分可供延伸，根本无法定殖。香菇段木栽培的失败原因中，有一半出在这一干燥判断上。

### 3-2. 锯末培养基——可以灭菌时的选择

| 材料 | 比例 | 作用 |
|---|:---:|---|
| 栎树锯末 | 70-80% | 主要碳源 |
| 米糠 | 20-30% | 氮和维生素B1的供给来源 |
| 麦麸 | 可替代米糠 | 氮源 |
| 碳酸钙或贝壳粉 | 1% | 调节pH，补充钙 |
| 水分 | 63-65% | 用手攥紧时，指缝间渗出一两滴水的程度 |

&nbsp;&nbsp;&nbsp;锯末粗细混合最好。如果只有细粉，空气不流通，菌丝会窒息；如果只有粗刨花，密度太低，养分不足。用筛子筛分，把2-3mm的和比它更细的各取一半混合。比起新锯末，露天堆放3-6个月的陈锯末更好，因为木材中的树脂成分已经散失，组织也变软了。

&nbsp;&nbsp;&nbsp;在灾害情境下，如果锯末不足，可以把稻草、麦秆、玉米秆、豆荚壳、稻壳粉碎成小块，替代20-30%。不过香菇对木质的依赖度高，替代比例超过40%时产量会明显下降。替代材料必须切到5cm以下，培养基才能压实均匀。

### 3-3. 不用电力给培养基灭菌的四种方法

&nbsp;&nbsp;&nbsp;高压灭菌锅在121℃下运行90分钟，连细菌孢子都能杀死。它既需要电力，也需要耐压容器。没有这些条件时能用的办法，不是彻底灭菌，而是把竞争杂菌的数量降到足够低，让香菇菌丝抢先站稳脚跟的低温杀菌。必须先理解这两者的目标不同。

#### 3-3-1. 铁桶蒸汽灭菌

| 项目 | 方法 |
|---|---|
| 准备物品 | 200L铁桶、盖子、垫架（砖块或烤网）、木柴 |
| 水 | 桶底部20-30cm深 |
| 装载 | 在垫架上把培养基袋或麻袋松散地堆放，留出蒸汽流通的空隙 |
| 密闭 | 盖上盖子，用湿草袋（gamani）或塑料布包裹，防止蒸汽泄漏 |
| 加热 | 从水烧开、蒸汽充满桶内之后算起，持续4-6小时 |
| 判定 | 插入培养基中心部的木签烫得无法握在手里 |
| 冷却 | 盖着盖子放凉一夜。趁热打开的话，孢子会随空气一起被吸入 |

&nbsp;&nbsp;&nbsp;这种方法能使培养基中心部达到95-100℃。霉菌的分生孢子和大部分细菌会被杀死，但耐热细菌的孢子仍会存活。即便如此，在实际操作中也已足够，因为只要香菇菌丝在3天内覆盖表面，之后杂菌就没有可乘之处了。

#### 3-3-2. 沸水浸泡

&nbsp;&nbsp;&nbsp;这是用于稻草或切碎的秸秆类材料的最简单的方法。在锅里烧开水，放入材料，煮1小时以上，煮透。捞出后挤干水分，调到含水率65-70%，冷却到30℃以下后再接种。它耗费燃料多，但优点是设备只需要一口锅。煮后挤水的过程中有可能再次受到污染，因此要事先用开水烫洗挤水的工具和用来放凉的地面。

#### 3-3-3. 石灰浸泡——完全不需要燃料的方法

| 项目 | 方法 |
|---|---|
| 配比 | 每100L水加熟石灰1-1.5kg，或生石灰0.5-1kg |
| pH | 12-13。用手触摸会觉得滑腻的强碱性 |
| 浸泡 | 把切到5cm以下的稻草完全浸没，浸泡12-24小时 |
| 沥水 | 捞出后沥水6-12小时，把含水率调到65-70% |
| 接种 | 不用水冲洗。残留在培养基中的碱会持续抑制杂菌 |

&nbsp;&nbsp;&nbsp;强碱会破坏霉菌孢子的细胞膜，而香菇菌丝相对耐受。最重要的是，完全不用火。在燃料最为珍贵的灾害情境下，这一点价值很大。没有石灰时，可以把草木灰溶于水中放置一天，只取上层清液作为灰水代替，但其pH低至11左右，而且每一批都参差不齐，成功率会下降。石灰是应当在能弄到的时候尽量多储备的材料。

#### 3-3-4. 稻草发酵

&nbsp;&nbsp;&nbsp;把稻草用水浸湿，堆成1-1.5m高，嗜热微生物会自行发热，使堆内温度达到60-70℃。每隔2-3天翻堆一次，放置2-3周，杂菌能利用的易分解糖分就会被提前耗尽，从而变成只有香菇菌丝才能利用的选择性培养基。这是先除掉食物而不是杀菌的做法，思路不同。它比较适合双孢蘑菇和大球盖菇，不太适合香菇，但在锯末不足时，作为制作稻草混合培养基的预处理，也可以用于香菇。

### 3-4. 无电力灭菌法比较

| 方法 | 燃料 | 所需时间 | 成功率 | 适用培养基 |
|---|:---:|:---:|:---:|---|
| 段木栽培（无需灭菌） | 无 | 无 | 最高 | 圆木 |
| 铁桶蒸汽 | 多 | 4-6小时 + 冷却 | 高 | 锯末、稻草 |
| 沸水浸泡 | 多 | 1-2小时 + 冷却 | 中等 | 稻草、稻壳 |
| 石灰浸泡 | 无 | 12-24小时 | 中等 | 仅限稻草类 |
| 稻草发酵 | 无 | 2-3周 | 中等 | 稻草、堆肥 |

## 4. 菌种获取

&nbsp;&nbsp;&nbsp;蘑菇没有种子。这意味着，种苗店一关门，就没有地方可买种；同时也意味着，像留种后装进坛子里保存这样的办法行不通。不过，菌类有三条植物所没有的路：一是采集并保存孢子，二是切下活蘑菇的一块菌肉直接培养，三是把菌丝已蔓延的木头劈开，移到新的木头上。把这三条路叠加起来，菌种就不会断绝。

### 4-1. 孢子采集与孢子印

| 步骤 | 方法 |
|---|---|
| 挑选对象 | 选择菌盖完全展开、没有虫蛀、最大且最健康的个体 |
| 切除菌柄 | 在菌盖与菌柄相接处，把菌柄紧贴着切掉 |
| 垫底 | 让菌褶朝下，放在铝箔纸上 |
| 罩盖 | 扣上杯子或碗，挡住风 |
| 静置 | 在阴凉处放24小时 |
| 取出 | 揭起菌盖，铝箔纸上就会留下保持菌盖形状的白色孢子粉 |

&nbsp;&nbsp;&nbsp;铝箔纸比纸更好。纸会吸收湿气，杂菌会藏在纤维之间。铝箔纸不吸水，表面光滑，能原样保存孢子。如果弄不到铝箔纸，玻璃板是次选。

&nbsp;&nbsp;&nbsp;采集孢子后，把铝箔纸连同孢子一起放在通风的阴凉处再晾一天，让微量的湿气也散尽。然后把铝箔纸对折，让孢子面朝内加以保护，装入自封袋。这时一并放入炒干的盐或木炭碎块来吸湿。把几个自封袋收进玻璃瓶，用蜂蜡封口，放在四季温度恒定的土窖或地下室里。紫外线会破坏孢子的DNA，所以必须是照不到光的深处。

| 保存形式 | 寿命 | 备注 |
|---|:---:|---|
| 孢子印（铝箔纸干燥） | 5-10年以上 | 水分被完全排除，细胞活动停止 |
| 液体菌种（无菌水悬浮） | 3-6个月 | 没有冷藏时，会提前萌发或滋生细菌 |
| 已培养好的菌种（锯末菌种·木楔菌种） | 约1年 | 是活的菌丝，会不断消耗养分 |

> **在灾害情境下，不能把孢子以液体形式保存。必须以干燥的孢子印形式保存。**

&nbsp;&nbsp;&nbsp;孢子与植物种子在寿命上的差别，源于结构。番茄种子含有胚和营养物质，随着时间推移会自行消耗养分而衰老死亡，在室温下为2-4年。蘑菇孢子只是被厚细胞壁包裹的单个细胞，没有可消耗的养分。只要条件合适，就能存活5-10年，学术界让几十年前的孢子复活的案例也并不罕见。

| 比较项目 | 番茄种子 | 蘑菇孢子 |
|---|---|---|
| 平均寿命（室温） | 约2-4年 | 约5-10年以上 |
| 脆弱因素 | 温度变化、自身营养耗尽 | 因潮湿导致的霉菌污染 |
| 细胞结构 | 复杂的胚和营养物质 | 单个细胞和厚实的保护壁 |

&nbsp;&nbsp;&nbsp;因此，在灾害第一年，当长出最大、最健康的蘑菇时，大量制作20-30张孢子印并储存在土窖中，是很重要的。即使每年延续菌丝时因污染而失败，也可以在5年后、10年后取出储存的孢子，随时重新开始，这就是一道安全保障。

### 4-2. 用孢子制作菌种——稻草加热培养基法

&nbsp;&nbsp;&nbsp;理论上，把孢子撒在灭菌的培养基上，菌丝就会延伸。但在现实中，空气中的绿霉和细菌占据培养基的速度比蘑菇孢子快数百倍。营养价值越高的培养基就越脆弱。在没有电力的情况下，要提高成功率，就应该放弃营养过剩的人工培养基，使用借助自然防御力的原始培养基。

| 步骤 | 方法 |
|---|---|
| 煮制 | 把稻草或麦秆放入沸水中煮1小时以上，煮透 |
| 挤水 | 捞出后挤干水分，放凉到可以用手触摸为止 |
| 撒播 | 把保存好的孢子粉不要吝惜，均匀地大量撒上 |
| 覆盖 | 用干净的布盖住，挡住风和落下来的孢子 |
| 培养 | 在20-25℃的暗处培养2-4周。白色菌丝覆盖稻草，就算成功 |

&nbsp;&nbsp;&nbsp;舍不得孢子、一粒一粒地往下放，就只会长出初生菌丝，然后死亡。不同交配型相遇后变成次生菌丝，才会长出蘑菇，所以要把大量孢子一次性撒入，让它们在培养基中自行找到配对对象。这是孢子接种中最常见的失误，也是最容易纠正的失误。

### 4-3. 组织培养——最可靠的方法

&nbsp;&nbsp;&nbsp;如果手边有活的新鲜蘑菇，就几乎没有必要使用孢子。蘑菇菌盖与菌柄相接处内侧的白色菌肉，已经是完成了雌雄结合的次生菌丝团。把这一小块切下放进培养基，就能跳过萌发和配对的过程，菌丝立刻向四面延伸。

| 步骤 | 方法 |
|---|---|
| 挑选 | 选择菌盖刚要展开的新鲜个体。陈旧或有虫蛀的不要用 |
| 消毒 | 把刀在火上烧红后放凉，或在沸水中浸一下再取出 |
| 掰开 | 用手把蘑菇纵向掰开。用刀切的话，表面的杂菌会被带入内部 |
| 取样 | 把菌盖与菌柄相接处内侧的白色菌肉，取下米粒大小的一块 |
| 接种 | 夹入煮后放凉的稻草或锯末之间，或嵌入段木的接种孔中 |
| 培养 | 22-25℃的暗处。3-5天后，小块周围会蔓延出白色绒毛 |

&nbsp;&nbsp;&nbsp;掰开之所以重要，是因为蘑菇内部接近无菌。外皮和菌褶上落着各种孢子，但菌肉内部是干净的。用手掰开，这个干净的断面就会新鲜地暴露出来，从那里取下的小块，不经消毒也能长成纯净的菌丝。

### 4-4. 用段木延续菌种

&nbsp;&nbsp;&nbsp;香菇在自家留种上获得S，靠的就是这种方法。出菇良好的段木，本身就是一大块菌种。把这根段木劈开，移植到新段木上，不需要无菌操作，不需要采集孢子，也不需要培养基灭菌，就能延续下去。

| 方式 | 方法 | 备注 |
|---|---|---|
| 劈制木楔菌种 | 把菌丝蔓延良好的段木用斧头劈成手指粗的木楔，再用锤子敲入新段木的接种孔 | 最可靠 |
| 掺混锯末 | 把菌丝蔓延的木头粉碎成锯末状，掺入煮后放凉的新稻草或锯末中 | 便于扩大数量 |
| 自然感染 | 把新接种的段木紧挨着正在出菇的段木立放 | 辅助手段 |

&nbsp;&nbsp;&nbsp;劈开的木楔菌种干了就会死。必须在劈好的当场立刻敲入，并把接种孔密封。最好在阴天或清晨、没有风的时候作业。一根段木劈出的木楔可以接种5-10根新段木，所以每年牺牲一根出菇良好的段木，菌种的供应就能永远延续下去。

> **在香菇种植中，最重要的财产不是蘑菇，而是长满菌丝的段木。这一根段木，就造就了接下来的5年。**
