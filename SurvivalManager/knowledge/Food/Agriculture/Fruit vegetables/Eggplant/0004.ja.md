## 4. 品種

### 4-1. 主要品種の比較

| 品種 | 形態 | 熟期 | 収量 | 栽培難易度 | 適した環境 | 特徴 |
|---|---|:---:|:---:|:---:|---|---|
| シンフクサンホ | 長い長果 | 早生 | 多い | 易しい | 露地・雨よけ栽培兼用 | 着果がよく初期収量が安定しています |
| フクチンジュ | 長い長果 | 早生 | 多い | 易しい | 露地・雨よけ栽培兼用 | 韓国国内で最も広く使われている系統です |
| チョンハデジャン | 細長い長果（36-41cm） | 中生 | 多い | 普通 | 高温乾燥期 | 皮が薄く、つやのある濃い黒紫色です |
| セップルガジ | 太くて短い長果 | 中晩生 | 普通 | 易しい | 露地 | 皮が厚く、低温に比較的強いです |
| カラクチャンガジ | 細長い長果 | 中生 | 普通 | 普通 | 露地 | 果肉が柔らかく調理時間が短いです |
| ペンペンイガジ | ぽってりした短果 | 中生 | 普通 | 易しい | 低温適応 | 皮が硬く、収穫後の日持ちが長いです |
| 在来種チョソンガジ | 短くぽってりした長果 | 中生 | 少ない | 易しい | 韓国全土 | 種を採って続けて植えることができ、香りが濃いです |

### 4-2. 状況別の選び方

| 状況 | 選択 | 理由 |
|---|---|---|
| 災害初期、早い収穫 | シンフクサンホ、フクチンジュ | 早生種なので初収穫が早く、着果が安定しています |
| 種を採って続ける計画 | 在来種チョソンガジ系統 | 固定種なので、採った種の形質が翌年も維持されます |
| 涼しい地域・短い夏 | セップルガジ、ペンペンイガジ | 低温でも生育が相対的に止まりにくいです |
| 干して貯蔵する計画 | 皮の薄い長い長果系統 | 薄く切りやすく乾燥が均一です |
| 狭い土地に数株だけ | シンフクサンホ | 一株当たりの収量が多く、管理が易しいです |

&nbsp;&nbsp;&nbsp;災害への備えにおいて品種選びの軸は収量ではなく種子の性質です。市販されている商業品種の多くは一代雑種（F1）です。一代雑種は初年度は均一で収量が多いですが、その実から採った種を翌年蒔くと形質がばらけます。大きいものと小さいもの、長いものと丸いものが入り混じって出てきて、収量が落ちます。種子の供給が途絶えた状況では、この性質が致命的です。

> **ナスの自家採種等級がSであるのは、植物の性質が自家受粉であるためであって、市場に出回るすべての品種から種を採って使えるという意味ではありません。一代雑種から採った種は、自家受粉であってもなくても翌年にはばらけます。**

&nbsp;&nbsp;&nbsp;そのため、複数年を見据えるなら固定種を一つ確保しておくことが実質的な備えになります。在来種チョソンガジや、地域で長く受け継がれてきた系統がこれに当たります。収量は商業品種に及びませんが、採った種が翌年も同じナスを生みます。商業品種の高い収量は種子供給網が生きている間だけ有効な値であり、その網が絶たれれば最初の年しか有効ではありません。

&nbsp;&nbsp;&nbsp;抵抗性については正直である必要があります。ナスにおいて青枯病に対する完全な抵抗性品種は事実上ありません。商業栽培では抵抗性台木に接ぎ木してこの問題を避けますが、代表的な台木がトルバム（Solanum torvum）と抵抗性ナス系統です。接ぎ木には切れ味の良い刃物と固定クリップ、そして接いだ部分を癒合させる高温多湿の環境が必要で、災害時には容易ではありません。接ぎ木ができないなら、抵抗性ではなく輪作と衛生管理に頼るしかなく、それが9節と11節の内容です。

## 5. 畑の準備と肥料

### 5-1. 畑の準備

| 項目 | 基準 | 理由 |
|---|---|---|
| 耕起深さ | 25-30cm | 表土を厚くし、浅根性の根が広がる層を確保します |
| 畝の高さ | 20cm以上 | 梅雨時の根の酸素不足を防ぎます |
| 排水路 | 畑の縁と畝の端 | 水がたまると疫病が爆発的に広がります |
| 石灰処理 | 定植2-3週間前 | 堆肥と同じ時期に入れると窒素が飛んでしまいます |
| 堆肥投入 | 定植1-2週間前 | 完熟堆肥のみを使います |
| 連作確認 | 過去3-5年以内のナス科栽培の有無 | 最初に確認すべき事項です |

&nbsp;&nbsp;&nbsp;石灰と堆肥を同じ日に入れないのには化学的な理由があります。石灰はアルカリ性で、アルカリ条件下では堆肥中のアンモニア態窒素が気体のアンモニアに変わって空気中に逃げてしまいます。せっかく集めた窒素が匂いになって消えてしまうわけです。石灰を先に入れて2週間以上置いてから堆肥を入れる順序が原則です。

### 5-2. 施肥量

| 肥料 | 1,000㎡当たり | ㎡当たり | 配分 |
|---|:---:|:---:|---|
| 窒素（N） | 19.0kg | 約19g | 元肥10.2kg + 追肥8.8kg |
| リン酸（P） | 11.2kg | 約11g | 全量元肥 |
| カリウム（K） | 15.0kg | 約15g | 元肥9.0kg + 追肥6.0kg |
| 堆肥 | 1,500-2,000kg | 1.5-2kg | 完熟堆肥 |

&nbsp;&nbsp;&nbsp;窒素とリン酸とカリウムを合わせると㎡当たり45g前後になります。評価表の施肥等級Dは、この必要量から導かれた値です。ケールの24g、アマランサスの14gと比べると2倍から3倍です。そして、この量のほぼ半分が追肥として分けて入れられるという点が重要です。ナスは4か月間ずっと実を作り続ける作物なので、養分も4か月間ずっと供給し続ける必要があります。元肥だけ入れて放置すると、7月中旬から実が目に見えて小さくなります。

### 5-3. 元肥と追肥の時期

| 区分 | 時期 | 内容 |
|---|---|---|
| 石灰 | 定植2-3週間前 | 土壌酸度の矯正 |
| 元肥 | 定植1-2週間前 | 堆肥全量 + リン酸全量 + 窒素・カリウム50-60% |
| 追肥1回目 | 定植後約30日 | 最初の実がなる頃 |
| 追肥2回目 | 1回目の20-25日後 | 収穫が本格化する時期 |
| 追肥3回目 | 2回目の20-25日後 | 更新剪定と同時に施します |
| 追肥4回目 | 3回目の20-25日後 | 秋の収穫に向けた最後の供給 |

### 5-4. 化学肥料を使わずに同じ量をまかなう方法

| 代替資源 | 供給される養分 | 使い方 | 注意 |
|---|---|---|---|
| よく腐熟した堆肥 | 窒素・リン酸・カリウムと微量元素全般 | 元肥として㎡当たり2-3kg | 未熟な堆肥は根を傷め、コガネムシの幼虫を呼び寄せます |
| 薄めた尿 | 窒素が主体で、カリウム・リン酸は少量 | 水で10-15倍に薄めて株間の溝に注ぎます | 葉に直接かかると傷みます。収穫2週間前からは中止します |
| 草木灰 | カリウム・カルシウム・リン酸 | ㎡当たりひとつかみ（50-100g）を土に混ぜます | アルカリ性なので使いすぎるとpHが上がりすぎます |
| 骨粉 | リン酸・カルシウム | 元肥として堆肥に混ぜて入れます | 分解が遅いため元肥専用です |
| 油かす・大豆油かす | 窒素 | 水に浸けて2-3週間発酵させた後10倍に希釈 | 生のまま土に入れると発酵熱で根が傷みます |
| 草肥（緑肥） | 窒素・有機物 | 畑の縁の草を刈って畝に敷きます | 種が熟した草は雑草を広げます |
| 魚・貝の副産物 | 窒素・リン酸・カルシウム | 堆肥の山の中に埋めて完全に腐らせてから使います | 生のまま畑に埋めると動物に掘り返されます |

&nbsp;&nbsp;&nbsp;尿は災害時において最も確実で最も安定した窒素源です。大人一人が1日に出す尿には窒素が5-7gほど含まれており、1年分にすると2kg余りになります。ナス畑20㎡に必要な窒素は約400gなので、一人分の尿2か月分で1年分の施肥量が出ます。出したての尿はほぼ無菌状態で尿素が主成分ですが、数日置くと尿素がアンモニアに変わって匂いが出て濃度も高くなるため、採ったらすぐに薄めて使う方がよいです。

> **尿は窒素は豊富ですが、リン酸が不足しています。尿だけを与え続けると、葉ばかり茂って実がならない状態に陥ります。草木灰と骨粉でカリウムとリン酸を合わせて補ってこそ、バランスが取れます。**

&nbsp;&nbsp;&nbsp;草木灰はカリウムの主要な供給源です。広葉樹を燃やした灰は針葉樹の灰よりカリウムが多く、完全に燃やして白い灰になったものが良いです。ただし草木灰は強アルカリなので、一か所に大量に撒くとpHが8を超えて、かえって養分吸収を妨げます。一株の周りにひとつかみ以上は撒かないのがこつで、土に軽く掻き混ぜます。雨が降るとカリウムが急速に流れ落ちるため、何回かに分けて撒く方が効率的です。

&nbsp;&nbsp;&nbsp;堆肥の腐熟度合いを判断する基準は、匂いと温度と形です。よく腐熟した堆肥は土の匂いがし、手を入れても温かくなく、元の材料の形が分からなくなっています。アンモニア臭がしたり中が温かかったりする場合はまだ発酵が進行中という意味で、その状態で畑に入れると発酵熱と有機酸が根を傷めます。ナスのように根が浅い作物では、この被害が特に大きくなります。

## 6. 播種と定植

### 6-1. 時期

| 作業 | 地域 | 時期 | 備考 |
|---|---|---|---|
| 播種（育苗開始） | 韓国中部 | 2月中旬-下旬 | 定植70-80日前 |
| | 韓国南部 | 2月上旬-中旬 | |
| 定植 | 韓国中部 | 5月上旬-中旬 | 遅霜が完全に終わった後 |
| | 韓国南部 | 4月下旬-5月上旬 | |
| 初収穫 | 韓国全土 | 6月下旬 | 定植後50-70日 |
| 収穫終了 | 韓国全土 | 10月中旬-下旬 | 初霜まで |

&nbsp;&nbsp;&nbsp;定植時期を決める基準はカレンダーではなく遅霜です。その地域の最後の霜がいつ降りるかを知っておく必要があり、分からなければ遅めに植える方がよいです。1週間遅く植えて生じる損失は収穫が1週間遅れるだけですが、1週間早く植えて霜に当たれば、その年の作はまるごと消えてしまいます。

### 6-2. 育苗 - 加温なしで行う方法

| 項目 | 基準 |
|---|---|
| 播種前処理 | 30℃の水に10時間浸した後、濡れた布に包んで25-30℃で発芽させます |
| 播種の深さ | 0.5-1cm |
| 発芽温度 | 25-30℃、3-5日 |
| 育苗温度 | 昼22-30℃、夜15℃以上 |
| 鉢上げ | 本葉3-4枚（播種後35-40日）で1回 |
| 育苗期間 | 70-80日 |
| 定植適期の苗 | 本葉5-7枚、最初のつぼみが見える頃 |
| 馴化 | 定植1週間前から日中は外に出し、外部環境に慣らします |

&nbsp;&nbsp;&nbsp;2月下旬に25-30℃の発芽温度を作ることが、この作物の最大の関門です。電気がないという前提で使える方法は大きく分けて三つあります。

| 方法 | 原理 | 得られる温度 | 限界 |
|---|---|---|---|
| 踏み込み温床 | 馬糞・稲わら・もみ殻を水と混ぜて踏み込むと、微生物が分解しながら熱を出します | 床面20-30℃を3-6週間維持 | 材料を集める作業と踏み固める労力が大きいです |
| 室内南向き窓辺 | 日中ガラス越しに差し込む日光が土と水を温めます | 昼25-30℃、夜15-18℃ | 夜温の確保が鍵です |
| 水桶蓄熱 | 黒い水桶を育苗箱の横に置き、昼間の熱を蓄えて夜に放出します | 夜温を3-5℃上げます | 補助的な手段です |

&nbsp;&nbsp;&nbsp;踏み込み温床は電気以前の時代に実際に使われた方法です。地面を50-60cm掘り、馬糞や稲わらを水に浸して層状に踏み込んだ後、その上に床土を10cm被せます。数日経つと微生物分解が始まって床面温度が上がり、その熱が3-6週間続きます。夜には藁むしろを掛けて熱を閉じ込めます。馬糞がなければ、稲わらと米ぬかと尿を混ぜて似たような発酵を起こせますが、上がる熱は小さく持続も短くなります。

> **育苗が難しければ、播種時期を遅らせるという選択肢があります。4月初めに播種して6月中旬に定植すれば初収穫は8月にずれ込みますが、加温なしで露地の気温だけで苗を育てられます。収穫期間が2か月余りに縮む代償を払うことになりますが、作がまったくなくなる事態は防げます。**

### 6-3. 定植

| 項目 | 基準 | 備考 |
|---|---|---|
| 植える深さ | 苗の土が少し見える程度に浅く | 深く植えると茎が腐ります |
| 1条植え | 畝80-90cm、株間45-50cm | ㎡当たり2.2-2.8株 |
| 2条植え | 畝150cm、株間45-50cm | 通風のため条間を60cm以上あけます |
| 植え方 | 穴に水をたっぷり注ぎ、水が引いてから苗を入れます | 活着が早まります |
| 支柱 | 定植と同時に1.5mの支柱を立てます | 後から立てると根を切ってしまいます |
| 定植時刻 | 曇りの日の午後 | 晴れた日の正午に植えると萎れがひどくなります |

&nbsp;&nbsp;&nbsp;株間45-50cmは広く見えますが、ナスには必要な間隔です。バンアダリで枝分かれし続ける構造のせいで、一株が最終的に直径1m近くまで広がり、密植すると内部が暗くなって通風が悪くなります。通風が悪くなると葉かび病や灰色かび病が居着き、実に光が当たらず色づきません。狭い土地にたくさん植えて得る利益より、病気で失う損失の方が大きいです。

&nbsp;&nbsp;&nbsp;支柱を定植と同時に立てる理由は根のためです。1か月ほど後に支柱を打ち込むと、すでに広がった細根を切ってしまい、切れた場所から青枯病菌が侵入します。支柱は太さ2cm前後、長さ1.5mの木の棒や竹で十分で、災害時には畑の周りのまっすぐな木の枝を切って乾かして使えばよいです。評価表の施設負担Cは、この支柱と誘引ひもを毎年新しく用意しなければならない負担を指しています。

## 7. 水管理

&nbsp;&nbsp;&nbsp;ナスの実の92%は水です。この一文が水管理のすべてを説明しています。人が収穫しているのは実質的に水であるため、水が足りなければ収穫するものがありません。総蒸発散量が作期あたり750mmに達する理由であり、評価表で水消費量がCにとどまる理由です。

| 時期 | 水管理 | 理由 |
|---|---|---|
| 定植直後-活着 | 植え穴にたっぷり注ぎ、その後3-4日間乾かさないようにします | 新しい根が出るまで吸収力が弱いです |
| 活着後-開花前 | 4-5日間隔、表土が乾いたら | この時期にやや乾き気味にしておくと根が深く張ります |
| 開花・着果期 | 2-3日間隔、たっぷりと | 水が足りないと花と幼果が落ちます |
| 肥大・収穫期 | 2-3日間隔、たっぷりと | 実の重さのほとんどはこの時期に入った水です |
| 梅雨時 | 灌水中止、排水路の点検 | 根の酸素不足が疫病の始まりです |
| 更新剪定直後 | たっぷりと | 新しい根と新芽が同時に出ます |

### 7-1. 水が不足したときに現れるもの

| 順序 | 症状 | 説明 |
|---|---|---|
| 1 | 花と豆粒ほどの幼果が落ちます | 最初に現れる兆候であり、すでに損失が始まっている時点です |
| 2 | 短花柱花（雌しべが短い花）の割合が増えます | 咲いても受粉できずに落ちます |
| 3 | 実が細く短いまま止まり、皮が硬くなります | 細胞が水で膨らめなかった結果です |
| 4 | 葉が昼間しおれて夕方に回復します | まだ回復可能な段階です |
| 5 | 葉が夕方になっても回復せず、下の葉から黄色くなって落ちます | この段階で水をやってもその週の収穫はありません |

&nbsp;&nbsp;&nbsp;順序に注目する必要があります。葉がしおれるのは4番目の兆候であり、そのときにはすでに花が落ちた後です。人が気づきやすい兆候ほど遅く現れるという意味です。そのためナス畑では葉ではなく土を見ます。指を5cm差し込んでひんやりと湿った感触がなければ、水をやる時です。

### 7-2. 水が貴重なときに使う方法

| 方法 | 原理 | 効果 |
|---|---|---|
| 藁・草マルチ | 土の表面を覆って蒸発を防ぎます | 灌水間隔を1.5-2倍に延ばせます |
| 株周りの水鉢 | 底に穴を開けたペットボトルや竹筒を土に挿し、水を満たします | 水が根の層にゆっくり染み込み、損失が減ります |
| 夕方灌水 | 日が沈んだ後に与えます | 昼の灌水より蒸発損失が大きく減ります |
| 溝灌水 | 畝の間の溝にだけ水を流します | 葉に水が当たらないため病気の拡散が減ります |
| 食器洗い水・米のとぎ汁の再利用 | 油と洗剤の少ない水を集めて使います | 有機物も一緒に入ります |

> **葉に水をかける方式は、ナスにとって最も悪い灌水法です。葉が濡れたまま夜を過ごすと、葉かび病や灰色かび病の胞子が発芽しやすい条件になります。水は常に土に与えます。**

&nbsp;&nbsp;&nbsp;マルチングは、災害時にはビニールを使わずに行う方法が重要です。稲わら、麦わら、刈って乾かした草、落ち葉、もみ殻がすべて使えます。厚さは5-10cmが適当で、薄すぎると効果がなく、厚すぎると土が冷えて初期生育が遅れます。定植直後にすぐ覆うのではなく、土が十分に温まった6月初めに覆う方がよいです。わらマルチは蒸発を防ぐほかにも、雨粒が跳ねて土中の病原菌が下の葉に付着するのを防ぎ、秋にそのまますき込めば有機物になります。
