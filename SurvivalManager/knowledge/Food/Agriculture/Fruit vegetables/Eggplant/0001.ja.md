## はじめに
&nbsp;&nbsp;&nbsp;ナス(Solanum melongena)は、ナス科ナス属の一年生の果菜です。原産地はインド東部からミャンマーにかけての亜熱帯なので、暑さを好み、寒さに弱く、水をたくさん吸い、霜が1度降りただけで畑ごと終わります。評価表の総合等級はE(31.7点)です。100gが19kcalで、1,000㎡で3,500kgを収穫しても、面積当たりの熱量は自給ラインの0.25倍にとどまり、1日2,100kcalをナスだけで満たすには11kgを食べなければなりません。しかし副食の等級はA(50.2点)です。低い熱量がタンパク質密度をSに押し上げました。収量の安定性もS(年次間の変動率5.7%)なので、アブラナ科の葉物が溶けてしまう高温多湿の真夏が、ナスの本舞台です。弱点は、温度(耐寒性E、育苗70-80日)、連作障害(5-7年の休作)、貯蔵性(果実の92%が水)です。ナスは畑の中心ではなく、畑の一角に5、6株を立て、夏は摘んで食べ、余りは切って干して冬へ回す作物です。

## 2. 植物の概要
&nbsp;&nbsp;&nbsp;ナス科ナス属の多年草ですが、温帯では冬を越せないので一年草として栽培します。病害虫をトマト、トウガラシ、ジャガイモと共有します。茎は直立して高さ60-120cmで、ある節で二股に分かれる最初の分枝点を第一分枝点と呼びます。細根が深さ30cm以内の表土に集まる浅根性で、干ばつに弱いです。花は薄紫の星形で、自家受粉が主です。果実は液果で、果皮は黒紫色が基本です。

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 育苗期 | 播種から定植まで70-80日 | 本葉5-7枚、最初の花のつぼみのころが定植の適期 |
| 活着・栄養生長期 | 定植後1-5週 | 活着のあいだは伸びないように見えるのが正常。その後、茎が太くなり、第一分枝点ができる |
| 開花・着果期 | 定植後40-50日 | 第一分枝点で最初の花が咲く |
| 肥大・収穫期 | 開花後10-20日から霜まで | 果実を摘むと次の花がすぐ続く |
| 衰退・更新期 | 7月下旬-8月上旬 | 高温と連続した着果で勢いが落ちる。更新剪定で9-10月の収穫をつなぐ |

> **ナスは摘まなければ実りません。果実をそのままにすると、その株は種をつくるのにすべての養分を注ぎ、新しい花をつくらなくなります。**

| 100g当たりの栄養 | 含量 |
|:---|:---|
| 熱量 | 19kcal(水分92g) |
| タンパク質 | 1.13g(熱量の23.8%) |
| 炭水化物 / 食物繊維 | 5.7-6.0g / 3.0g |
| ミネラル・ビタミン | カリウム230mg、カルシウム15-20mg、鉄0.3-0.4mg、マグネシウム14mg、ビタミンC 2.2mg(供給源ではない)、葉酸22µg |
| 成分 | ナスニン(皮のアントシアニン)、クロロゲン酸(切り口が褐変する原因) |

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽28-30℃(20℃以下では非常に遅い)、育苗は昼22-30℃・夜15℃以上、生育22-30℃、結実20-30℃。10℃以下で生育が止まり、霜が1度降りるだけで全体が枯れる |
| 光 | 1日6時間以上(最低4時間)。真夏の直射日光と35℃が重なると果実に日焼け |
| 水 | 1作当たりの総蒸発散量約750mm。土壌水分は最大容水量の70-80%。乾くと落花・落果、べたつくと根腐れ |
| 土壌 | 有機物の多い壌土-砂壌土、土の深さ30cm以上、pH 6.0-7.0(6.5前後が最もよく、5.5を下回るとリン酸とカルシウムの吸収が悪い)。塩類に弱い |

> **干ばつのときにナスが最初に出すサインは、葉ではなく花です。葉がしおれる前に、すでに花と豆粒ほどの幼果が落ちています。葉がぐったり垂れた後に水をやっても、その週の収穫はすでに消えています。**

| 品種 | 特徴 |
|:---|:---|
| シンフクサンホ、フクチンジュ | 長い液果の早生。着果がよく、初期の収量が安定。露地・雨よけ兼用 |
| チョナデジャン | 細長い液果(36-41cm)の中生。皮が薄く、つやが濃い。高温乾燥期に適する |
| ソェップルガジ、ペンペンイナス | 太くて短い液果。皮が厚く低温に比較的強く、ペンペンイナスは収穫後に長くもつ |
| 在来の朝鮮ナス | 短くふっくらした液果。収量は少ないが固定種なので種を採って植え継げ、香りが濃い |

&nbsp;&nbsp;&nbsp;早い収穫にはシンフクサンホとフクチンジュ、涼しい地域にはソェップルガジとペンペンイナス、干して貯蔵するなら皮の薄い長い液果の系統です。自家採種の等級Sは自家受粉だという意味にすぎず、一代雑種から採った種は翌年ばらけるので、何年も見通すなら、在来の朝鮮ナスのような固定種を1つ確保しておきます。

## 4. 畑の準備と播種、定植
| 項目 | 基準 |
|:---|:---|
| 土づくり | 25-30cmの深さに耕し、畝20cm以上、畑の縁と畝の端に排水溝(水がたまると疫病が爆発する)。石灰は定植の2-3週間前、堆肥と同じ時期に入れると窒素が飛ぶ |
| 施肥(1,000㎡当たり) | 完熟堆肥1,500-2,000kg、窒素19.0kg(元肥10.2kg + 追肥8.8kg)、リン酸11.2kg(全量元肥)、カリウム15.0kg(元肥9.0kg + 追肥6.0kg) |
| 追肥 | 定植後約30日から始めて20-25日おきに計4回(3回目は更新剪定と同時) |
| 代替資源 | 完熟堆肥1㎡当たり2-3kg、尿の10-15倍希釈液(畝間に注ぎ、収穫の2週間前に中止)、木灰1㎡当たりひとつかみ、骨粉、発酵させた油かすの10倍希釈液、草のマルチ |

> **尿は窒素が豊富ですがリン酸が足りません。尿だけをやり続けると、葉だけが茂って実がつきません。木灰と骨粉でカリウムとリン酸をともに補ってこそ、バランスがとれます。**

| 作業 | 時期 |
|:---|:---|
| 播種(育苗開始) | 中部2月中旬-下旬、南部2月上旬-中旬 |
| 定植 | 中部5月上旬-中旬(遅霜が完全に終わった後)、南部4月下旬 |
| 初収穫 | 定植後50-70日、6月下旬。収穫の終わりは初霜、10月中旬-下旬 |

| 育苗と定植 | 基準 |
|:---|:---|
| 育苗 | 25-30℃で3-5日で発芽。定植の1週間前から昼に外へ出して順化。加温なしでは、踏み込み温床(馬ふん・稲わら・もみ殻を踏み込んで20-30℃を3-6週間)、南向きの窓辺、黒い水桶による蓄熱(夜の温度が3-5℃上がる) |
| 育苗が難しいとき | 4月初めに播種して6月中旬に定植。初収穫が8月にずれ込み、収穫期間は2か月ほどに縮むが、農作業が丸ごとなくなることは防げる |
| 定植 | 苗の土がうっすら見える程度に浅く(深植えすると茎が腐る)。1条植えは畝80-90cm、株間45-50cm(1㎡当たり2.2-2.8株)、2条植えは畝150cmで条間60cm以上。曇りの日の午後に植え、支柱を定植と同時に立てる |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 定植直後-活着 | 穴にたっぷり注ぎ、3-4日は乾かないように |
| 活着後-開花前 | 表土が乾いたら4-5日おき。やや乾かし気味にすると根が深く張る |
| 開花・着果期、肥大・収穫期 | 2-3日おきにたっぷり(果実の重さの大部分はこのときに入った水) |
| 梅雨 | 灌水を中止し、排水溝を点検 |
| 更新剪定の直後 | たっぷり |

&nbsp;&nbsp;&nbsp;水が足りないと、花と幼果が先に落ち、果実が細く硬くなり、昼にしおれた葉が夕方も回復しなければ、その週の収穫はありません。水が貴重なときは、わら・草のマルチ(灌水の間隔が1.5-2倍に延びる)、底に穴を開けた瓶を差す点滴、夕方の灌水、畝間灌水、食器のすすぎ水や米のとぎ汁の再利用を使います。葉には水をかけず、常に土にやります。

| 管理 | 内容 |
|:---|:---|
| 整枝 | 第一分枝点より下から出るわき芽は、すべて手で折り取る。第一分枝点で分かれた2本の茎に、そのすぐ下の最も丈夫なわき芽を1本加えて3本に育て、内側に重なる茎だけを間引く。収穫が始まったら、地面から30cm以内の葉を順に取る |
| 作業のコツ | 晴れた日の午前に、できるだけ手で。ナイフを使うなら株ごとに火であぶるか煮沸した湯に浸す(青枯病とウイルスは刃を伝って移る) |
| 摘葉 | 果実1つを育てるのに葉がおよそ3枚必要。一度に全体の葉の20%を超えない |
| 誘引 | 1本誘引(簡単だが茎が垂れる)、2本誘引(両側の支柱にひもを2段に)、X字誘引(1.8mの支柱を交差させて立てる) |
| 更新剪定 | 7月下旬-8月上旬に勢いが衰えたとき、各主枝を下から2、3節だけ残して切り、株から25-30cm離れた位置にスコップを20cmの深さに差し込んで古い根を切る(断根)。堆肥と尿の希釈液を入れてたっぷり水をやると、2-3週間後に新しい芽が出て、9月中旬からまた実がつく |

> **秋ナスがおいしいという言葉は、生理的な事実です。気温が下がると果実はゆっくり肥大し、ゆっくり育った果実は細胞が詰まっているので、肉質が柔らかく種が少なくなります。更新剪定は、その秋ナスを得るための準備です。**

## 6. 病害虫と養分の問題
| 病害 | 症状と条件 | 薬を使わない対応 |
|:---|:---|:---|
| 青枯病 | 日中に突然しおれ、朝に戻ることを数日繰り返して枯れる。茎を切ると白い細菌の液が出る。高温多湿、土壌伝染 | 治療法なし。見つけ次第、根ごと抜いて燃やし、その場所の土も取り除く。5-7年の輪作 |
| 疫病 | 地面に触れる茎の株元が暗褐色にくびれ、急にしおれる。過湿、梅雨 | 高い畝と排水溝が唯一の対策。ボルドー液の予防散布 |
| 半身萎凋病、ウイルス病 | 葉の片側半分が黄色くなってしおれる。葉がまだらで果実が奇形(アブラムシ・アザミウマが媒介) | 治療不可。病株の除去、長期の輪作、媒介虫の防除 |
| 灰色かび病、葉かび病、うどんこ病 | 灰色のカビ、葉裏の灰褐色のカビ、白い粉 | 散った花を払う、通風の確保、下葉の整理、窒素を使いすぎない、牛乳(水1に対し1-2)や重曹の希釈液 |

> **青枯病にかかった株を畑にそのまま置いたり、堆肥の山に入れたりすると、菌が畑全体に広がります。抜いて燃やすか、遠くに深く埋め、抜いた手と道具は必ず洗います。**

&nbsp;&nbsp;&nbsp;害虫は、アブラムシ(石けん水、テントウムシの保護)、ナミハダニ(葉の裏に水を強く吹きかける)、アザミウマ(粘着板、わらマルチ)、タバコガ(穴の開いた果実を摘んで処分し、幼虫を手で捕る)、カメムシ(早朝に手で捕る)です。防除資材は、ボルドー液(硫酸銅1kgと生石灰1kgを別々に溶かして冷まし、合わせて水100Lにする。予防剤)、石けん水(無香料の石けん20gを水1Lに)、木灰、木酢液の300-500倍、タバコの葉やトウガラシの浸出液です。病んだ残渣は燃やし、病んだ苗は植えません。

| 症状 | 原因と措置 |
|:---|:---|
| 下の葉から黄色く、株が小さい | 窒素欠乏。尿の10-15倍希釈液、腐熟堆肥 |
| 葉の縁が焼け、果実が小さい | カリウム欠乏。木灰 |
| 葉の裏と茎が紫色 | リン酸欠乏(低温期は土が冷たくて吸収されないこともある)。骨粉、木灰 |
| 花は多いがそのまま落ちる | ホウ素欠乏または高温ストレス。堆肥の材料を多様に、遮光 |
| 葉脈の間だけ黄色く、葉脈は緑 | マグネシウム欠乏。ドロマイト粉末 |
| 新しい葉が小さく奇形で、生長点が枯れる | カルシウム欠乏に見えるが、たいていは水不足。まず水を点検し、焼いた貝殻の粉 |
| 葉だけ茂って濃い緑、花が少ない | 窒素過剰(ナスで最も多い)。窒素を断ち、木灰でカリウムを補う |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| よい | マメ科(インゲン、ササゲ、エンドウ)、マリーゴールド(ネコブセンチュウを抑える)、バジル・シソ(強い香りがアブラムシとアザミウマを惑わす)、ネギ・ニンニク |
| 悪い | トマト・トウガラシ・ジャガイモ(病害虫をそっくり共有。隣に植えるのも避ける)、カボチャ(つるが風通しを妨げる) |

&nbsp;&nbsp;&nbsp;1年目ナス、2年目マメ科、3年目葉菜類かネギ属、4年目穀物か根菜類、5年目マメ科か緑肥を経て、6年目以降にナスを再開します。狭い土地では、畑を6区画に分けて毎年1区画ずつ移すか、病気がひどい場所の土を30cm取り除いて新しい土で埋めます。

> **ナスを同じ場所に3年以上続けて植えると、最初の2年は何ともなく、3年目に突然半分がしおれて枯れることがよくあります。輪作は病気が出た後ではなく、出る前にするものです。**

## 8. 収穫と採種
| 項目 | 基準 |
|:---|:---|
| 適期 | 開花後10-20日(気温が高いと短い)。長ナス型は長さ15-20cm前後だが、長さよりも状態を見る。皮につやがあり、押すと弾力があるときで、つやが消えたらすでに遅い |
| コツ | 最初の果実は卵の大きさのうちに摘んで、株の体をまず大きくする。週2-3回、早朝にはさみやナイフでへたの上を切り(ひねると茎が裂ける)、へたは3-5mm残す |
| 収穫後 | 食べる直前に洗う。10-12℃が最もよく、5℃以下では皮がくぼむ低温障害。その日に食べる分だけを残し、あとはすぐに切って干す |

| 採種 | 基準 |
|:---|:---|
| 隔離・株数 | ほかのナスの品種から30-50m離す。採種用の株は3-5株以上(遺伝的な幅)。果実1つに種が数百-1,000粒以上 |
| 果実 | 7月下旬-8月に株の下のほう、勢いのよいときについた果実を選んでひもで印をつける。皮が黄褐色に変わってつやが消える(開花後60-70日)まで置き、涼しい日陰で1-2週間追熟。霜の直前についた果実は種が熟さない |
| 分離・乾燥 | 果実を割って水に浸けてもみ、種を取り、沈んだ種だけを使う。布の上に広げて日陰で1-2週間(直射日光では干さない)。折ったときにぽきっと折れれば完了 |
| 保管 | 乾燥剤(炒って冷ました米、炭、乾いた木灰、焼いて冷ました塩)とともにガラス瓶や金属缶に密閉し、涼しく暗い場所に。常温の密閉で3-4年。毎年20粒を湿らせた布に置いて、1週間後に発芽率を確認 |
| 消毒 | 50-55℃の湯に10-15分の後、すぐ冷水で冷ます、浮くものを捨てる、木灰をまぶす |

## 9. 貯蔵と乾燥
| 方法 | 内容 | 期間 |
|:---|:---|:---|
| 生 | 洗わずに新聞紙に包み、10-15℃の日陰 | 5-7日 |
| 乾燥(干しナス) | 薄く切って日光と風で完全に乾かす。かさと重さが10分の1に減り、最も実用的 | 6か月-1年 |
| 塩漬け | 塩10-15%。食べる前に水で塩抜き | 数か月 |
| 漬け物 | 醤油・味噌・コチュジャンに漬け込む | 数か月-1年 |
| 乳酸発酵 | 塩2-3%で漬け、漬け汁の下に沈める。柔らかくなりやすく難しい | 数週間-数か月 |

&nbsp;&nbsp;&nbsp;干しナスは、傷のない果実を洗って水気を完全にふき取り、厚さ5-7mmの輪切りにするか、縦に4つに割ります。ざるやすだれに重ならないように1層に広げ、日当たりと風通しのよい場所で2-4日乾かし、夜は露を避けて取り込みます。手で折ったときにぽきっと折れるまで乾かし(少しでも柔らかいとカビる)、密閉容器に乾燥剤とともに暗くて涼しい場所に置きます。月に1回開けて確認し、しめっていれば日なたで半日乾かし直します。梅雨や日の差さない日は、火の上で乾かします。

> **乾燥の成否は初日に分かれます。曇りで湿った日に広げ始めると、3日目に黒いカビが生えてすべて捨てることになります。晴れて風のある日を選んで始めます。**

## 10. 調理と注意事項
| 調理 | 燃料とコツ |
|:---|:---|
| 蒸す | 10分以内。浮くので皿で押さえて均一に火を通す。油を使わず最も経済的 |
| 炒める | 油をよく吸っておいしくなるが、油の消費が多い |
| 焼く | 熾火で丸ごと焼いて皮をむく。残り火を使う |
| 汁物・煮込み | ほかの調理と兼ねる |
| 干しナス | 水に20-30分浸すと、元のかさの半分近くに戻る。炒めるか和える。皮はむかない |
| 生食 | 勧めない(渋く、アルカロイドが残る) |

> **油が貴重なら、ナスは蒸すのが正解です。蒸したナスを裂き、醤油か味噌、ニンニク、ごま塩で和えれば、燃料は10分、油は数滴で済みます。**

| 注意 | 内容 |
|:---|:---|
| ソラニン・ソラマルギン | ナス科の防御物質。たくさん食べると胃腸の刺激と吐き気。苦みの強い果実は食べない(若すぎる果実、収穫を逃して黄色くなった果実、水がひどく足りない中で育った果実に多い)。加熱で一部減る |
| 葉と茎 | アルカロイドの含量がはるかに高いので食べず、堆肥に回す |
| クロロゲン酸 | 毒性はなく、渋みと褐変の原因。切って水か薄い塩水に浸す |
| その他 | 人によってはかゆみやじんましんが出ることがあるので、最初は少量から |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 種子と発芽率の確認、温床の材料集め、播種(中部は中旬-下旬、南部は上旬-中旬)と温床の発熱開始 |
| 4月 | 元肥と堆肥、畝づくり、順化。南部は下旬に定植 |
| 5月 | 中部は上旬-中旬に定植して支柱を立てる、第一分枝点より下のわき芽の除去 |
| 6月 | 最初の果実を若いうちに摘む、1回目の追肥、わらマルチ、下旬から初収穫 |
| 7月 | 週2-3回収穫、2回目の追肥、梅雨の排水点検、下旬から更新剪定の準備 |
| 8月 | 上旬に更新剪定と断根、3回目の追肥、干し始める |
| 9月 | 新しい芽から秋ナスを収穫、4回目の追肥、採種果の完熟 |
| 10-11月 | 収穫の仕上げと残った果実をすべて切って干す、採種果の追熟、株を抜いて病んだものは燃やし丈夫な茎は堆肥に、種子の選別 |
| 12月 | 翌年の輪作計画と干しナスの状態の点検 |

> **忘れてはならない5つのこと: 遅霜の後の定植、途切れない水、摘まなければ実らないこと、初日で決まる乾燥、ナス科を5-7年休ませること。**
