## 2. どんな植物か

### 2-1. 分類と原産地

&nbsp;&nbsp;&nbsp;ナスはナス科（Solanaceae）ナス属（Solanum）の多年草ですが、温帯では冬を越せないため一年草として栽培します。学名はSolanummelongenaです。同じ属にジャガイモ（Solanum tuberosum）があり、同じ科にトウガラシ（Capsicum）、トマト（SolanumLycopersicum）、タバコがあります。この系統が実務上意味することはただ一つです。これらが病害をそっくり共有するということです。

&nbsp;&nbsp;&nbsp;青枯病、疫病、半身萎凋病、タバコモザイクウイルス、アブラムシ、アザミウマ、タバコガは、ナス科の作物を問わず移動します。ナスを植えていた場所に翌年トウガラシを植えると、土に残った病原菌がトウガラシを侵します。ジャガイモを掘り上げた場所にナスを植えても同じです。評価表の連作適応性Dはこの事実を一文字に凝縮したもので、11節の輪作設計はすべてここから導かれます。

&nbsp;&nbsp;&nbsp;原産地はインド東部からミャンマーにかけての亜熱帯地域です。野生の祖先はとげが多く実の小さい低木性の植物で、人が長い年月をかけて選抜するうちにとげがなくなり実が大きくなりました。この出自が栽培条件を決めています。第一に、高温性の植物なので霜に弱いことです。10℃以下で生育が止まり、一度霜が降りれば畑全体が黒く枯れます。第二に、雨季がはっきりした地域の植物なので水を多く必要とすることです。総蒸発散量は750mmに達し、乾けばすぐに花と幼果が落ちます。第三に、多年草の名残が残っていて、一度根付けば霜が降りるまで花を咲かせ実をつけ続けることです。8節の更新剪定が効果を持つ理由は、この第三の性質にあります。

### 2-2. 形態

| 器官 | 特徴 |
|---|---|
| 葉 | 広い卵形で、縁に浅い鋸歯があります。表面には細かい毛が密生していて手触りがざらつきます。葉脈と葉柄が紫色を帯びる品種が多いです |
| 茎 | まっすぐに立ち、下部は木のように硬くなります。一定の節で二又に分かれ、この最初の分岐点をバンアダリ（最初の分岐点）と呼びます。草丈60-120cm |
| 根 | まっすぐな主根がありますが、実際には30cm以内の表土に細根が集まる浅根性です。これが乾燥に弱い原因です |
| 花 | 薄紫色または白色の星形の花が下向きに咲きます。一つの花に雌しべと雄しべが共存し、自家受粉が優勢です |
| 実 | 漿果です。品種によって細長い円筒形から丸い形まで幅があり、皮の色は黒紫色が基本で、紫色・白色・緑色系統もあります |
| 種子 | 直径2-3mmの平たい円盤形で、薄い茶色をしています。果肉の中に散らばって埋め込まれています |

&nbsp;&nbsp;&nbsp;バンアダリを理解することが、ナス栽培の半分を占めます。ナスは茎が一定の節まで伸びるとその先端に最初の花を咲かせ、その位置で茎が二又に分かれます。分かれた二本の茎がさらに伸びて、それぞれ花を咲かせてまた分かれます。この構造が繰り返されるため、ナスは育ちながら際限なく倍々に枝分かれしていきます。放っておくと茎が数十本にまで枝分かれし、そうなると各茎に届く養分が分散して実が小さくなり、中の種が早くできてしまいます。8節の整枝はこの構造に対処する作業です。

&nbsp;&nbsp;&nbsp;根が浅いという点は、二つの結果を生みます。一つは乾燥に弱いということです。表土10cmが乾くとすぐに反応します。もう一つは、根が浅いため、除草や土寄せをするときに鍬で根を切ってしまいやすいということです。株の周りは手で草を抜き、土を掻く作業は畝の中央だけで行うのがこつです。ただし8節の更新剪定では、この根をわざと切って新しい根を誘導しますが、それは時期も目的も別の話です。

&nbsp;&nbsp;&nbsp;花の構造も知っておく価値があります。ナスの花は下向きに咲き、雌しべが雄しべより長く突き出た長花柱花と、雌しべが短い短花柱花が混じって咲きます。長花柱花は受粉がうまくいって良い実になり、短花柱花は受粉できずに落ちることが多いです。養分が不足していたり高温ストレスがあったりすると、短花柱花の割合が高くなります。畑で花は多いのに実がならない場合、たいてい水や肥料の不足、または真夏の暑さが原因です。

### 2-3. 生育段階

| 段階 | 時期 | 主な生理 | 重要な養分 |
|---|---|---|---|
| 育苗期 | 播種から定植まで（70-80日） | 本葉5-7枚まで育ちます。最初のつぼみができる頃が定植の適期です | 窒素、リン酸 |
| 定植・活着期 | 定植後1-2週間 | 新しい根が出て土に根付きます。この期間は成長していないように見えるのが正常です | リン酸 |
| 栄養生長期 | 定植後2-5週間 | 茎が太くなり葉が広がって、バンアダリが形成されます | 窒素 |
| 開花・着果期 | 定植後40-50日 | バンアダリで最初の花が咲きます。以後、新しい枝ごとに花が続きます | リン酸、ホウ素 |
| 肥大・収穫期 | 開花後10-20日から霜が降りるまで | 実が急速に大きくなります。摘み取ればすぐ次の花が続きます | カリウムと窒素のバランス |
| 衰退・更新期 | 7月下旬-8月上旬 | 高温と連続着果で樹勢が落ちます。この時期に更新剪定を行うと9-10月の収穫につながります | 窒素、カリウム |

> **ナスの生殖生長は、一度始まると霜が降りるまで止まりません。実を摘み取るほど次の花が早く来て、実をそのままにしておくと、その株はその実に養分を注ぎ込んで新しい花を作らなくなります。**

&nbsp;&nbsp;&nbsp;この性質が、12節の収穫のコツすべてを説明します。植物の立場では実を育てる目的は種子を残すことであり、種子が熟してしまえば目的が達成されるので、それ以上花を咲かせる理由がなくなります。人が実を摘み取り続ければ、植物は目的を達成できない状態にとどまり、花を咲かせ続けます。評価表の永続性Bはこの原理から導かれた等級で、実際には一株から霜が降りるまでに20-40個の実が採れます。

&nbsp;&nbsp;&nbsp;育苗期が70-80日であるという点は改めて強調する価値があります。この期間の長さは、ナスが幼苗の段階で育つ速度が遅いためです。子葉が出た後、本葉が一枚増えるのに一週間かかります。低温ではこの速度がさらに遅くなり、15℃ではほぼ止まります。そのため育苗期間中はずっと最低15℃、できれば20℃以上の夜温を保つ必要があり、これが災害時に最も難しい部分です。

### 2-4. 100gあたりの栄養

| 栄養素 | 含有量 | 備考 |
|---|:---:|---|
| 熱量 | 19-25kcal | 韓国国家標準食品成分表の生の基準で19kcalです。野菜の中でも低めです |
| 水分 | 92g | 熱量が低い直接の原因です |
| タンパク質 | 1.13g | 熱量比で23.8%です。絶対量は少ないですが密度は高いです |
| 炭水化物 | 5.7-6.0g | かなりの部分が食物繊維です |
| 脂質 | 0.1-0.2g | ほとんどありません |
| 食物繊維 | 3.0g | 野菜の中では多めです |
| カリウム | 230mg | ナスのミネラルの中で最も際立っています |
| カルシウム | 15-20mg | 普通の水準です |
| 鉄 | 0.3-0.4mg | 低いです |
| マグネシウム | 14mg | 普通の水準です |
| ビタミンC | 2.2mg | 非常に低いです。ナスはビタミンCの供給源ではありません |
| ビタミンB6 | 0.1mg | 普通の水準です |
| 葉酸 | 22 µg | 普通の水準です |
| ナスニン（アントシアニン） | 皮に集中 | 濃い紫色の原因であり抗酸化色素です |
| クロロゲン酸 | 果肉に含有 | 切り口が褐変する原因物質です |

&nbsp;&nbsp;&nbsp;この表からは二つのことを読み取る必要があります。第一に、ビタミンCが100gあたり2.2mgで、実質的にはほぼないに等しいという点です。ケールの90mg、トウガラシの44-78mgと比べると桁が違います。冬の壊血病を防ぐ役割をナスに期待してはいけません。第二に、ナスの栄養的な個性は特定のビタミンではなく、カリウムと食物繊維、そして皮の色素にあるという点です。

&nbsp;&nbsp;&nbsp;ナスニンは皮の紫色を作るアントシアニン系の色素です。植物の立場では、強い日差しの紫外線から果実の内部を守る日よけです。人の立場では抗酸化物質です。実務上重要なのは、この成分が皮にしかないという事実です。皮をむけばナスの栄養的な特色の半分が失われます。皮ごと食べるのが原則であり、皮が硬くなった老化した実は、そもそも収穫時期を逃したものです。

&nbsp;&nbsp;&nbsp;クロロゲン酸は、切ったナスがすぐに茶色く変わる理由です。空気中の酸素と触れて酵素が働き色が変わる反応であり、傷んだわけではありません。ただし見た目が良くなく渋みも出るため、切ったらすぐに水や塩水に浸けると反応が遅くなります。15節の乾燥では、この褐変をどう扱うかが品質を左右します。

## 3. 栽培環境

### 3-1. 温度

| 区分 | 限界値 | 最適値 | 備考 |
|---|:---:|:---:|---|
| 発芽温度 | 15-35℃ | 28-30℃ | 20℃以下では発芽が非常に遅く、そろいも悪くなります |
| 育苗温度（昼） | 20-32℃ | 22-30℃ | 低温では本葉が出る速度が半分に落ちます |
| 育苗温度（夜） | 15℃以上 | 18-20℃ | 15℃を頻繁に下回ると花芽が悪くなります |
| 生育温度 | 17-35℃ | 22-30℃ | 17℃以下で生育が目に見えて遅くなります |
| 結実温度 | 20-30℃ | 23-28℃ | 評価表の温度適応幅Cは、この10℃の幅から導かれます |
| 高温限界 | 35℃以上 | - | 花粉の活力が落ちて花が落ちます |
| 低温限界 | 10℃以下 | - | 生育が止まり、続くと枯死します |
| 致死 | 0℃以下 | - | 一度の霜で全体が黒く枯死します |

&nbsp;&nbsp;&nbsp;結実可能な範囲が20-30℃までのわずか10℃しかないという事実が、ナス栽培のスケジュールを決めています。韓国の気候でこの条件が整うのは6月中旬から9月中旬までで、その前後の5月と10月は余裕区間です。遅霜が終わる前に植えれば枯れ、初霜が来れば終わりです。定植時期を遅霜の終了後に設定する理由がここにあります。

&nbsp;&nbsp;&nbsp;真夏の高温も問題を生みます。35℃を超えると花粉が力を失って受粉できず、受粉しなかった花は落ちます。7月下旬から8月上旬にかけて花は咲くのに実がならない期間ができるのはこのためで、同じ時期に株の勢いも落ちます。更新剪定をこの時点で行う理由がここにあります。どのみち実がならない期間なので、その期間を回復に充てるのです。

### 3-2. 光

| 区分 | 基準 | 備考 |
|---|---|---|
| 必要日照 | 1日6時間以上 | 着果が安定し、実の色が濃くなります |
| 最小日照 | 1日4時間 | 育つことは育ちますが徒長し、着果が悪くなります |
| 40%遮光時 | 相対収量102% | 果菜類共通の値であり、評価表のS等級の根拠です |
| 強光ストレス | 真夏の直射光+35℃ | 実の皮に日焼けが生じ、白い斑点が残ります |

&nbsp;&nbsp;&nbsp;ナスが40%遮光でも収量を維持できるという点は、災害時の作付け配置で役に立ちます。一日中日が当たる場所は穀物と豆類とジャガイモが優先して使うべきで、ナスは半日日が当たる場所でも十分に役割を果たします。むしろ真夏は西日の午後日差しを遮ってやる方が、実の皮の日焼けを減らせます。ただし1日4時間を下回ると茎ばかり伸びて花が落ちるので、遮光に強いという話を日陰でもよいという話として読んではいけません。

&nbsp;&nbsp;&nbsp;実の色も光と関係があります。皮の紫色はアントシアニンによるもので、アントシアニンは光を受けてはじめて作られます。葉に隠れた実は色が薄かったりまだらになったりします。食べるのに支障はありませんが、色づきの悪い実が多い場合は葉が茂りすぎているという合図であり、下の葉を整理する時期が来たという意味です。

### 3-3. 水と土壌

| 項目 | 基準 | 備考 |
|---|---|---|
| 総蒸発散量 | 作期あたり約750mm | 果菜の中でも多めで、評価表の水消費量Cの根拠です |
| 土壌水分 | 最大容水量の70-80% | 乾けば落花・落果、過湿になれば根腐れです |
| 土性 | 有機物の多い壌土、砂壌土 | 保水力と排水性の両方が必要です |
| 土の深さ | 30cm以上 | 細根が表土に集中するため、表土が厚い必要があります |
| pH | 6.0-7.0 | 6.5前後が最も良いです |
| pH下限 | 5.5 | これより下では、リン酸とカルシウムの吸収が悪くなります |
| 耐塩性 | 弱い | 塩類が蓄積した畑では生育が抑えられます |

&nbsp;&nbsp;&nbsp;ナスは水を多く必要とすると同時に、水がたまることに耐えられません。この一見矛盾した要求は、浅根性の根に由来します。根が表土に集中しているため、表土が乾けばすぐに水不足になり、同じ理由で表土に水がたまれば根が呼吸できなくなります。解決策は畝を高くすることです。畝を20cm以上高くすると、根の層より下に水が抜けつつ、畝の中には水分が残ります。梅雨（チャンマ、6月下旬~7月）が長く続く韓国の気候では、高畝は選択肢ではなく前提条件です。

> **干ばつに対してナスが送る最初の合図は、葉ではなく花です。葉がしおれる前に、すでに花と豆粒ほどの幼果が落ちています。葉がぐったり垂れた後に水をやっても、その週の収穫はすでに失われた後です。**

&nbsp;&nbsp;&nbsp;pHについては一つ付け加えておく価値があります。ナスは酸性に特別弱い作物ではありませんが、pHが5.5より下がると、リン酸が鉄やアルミニウムと結合して植物が利用できない形に固定されます。結実にリン酸が欠かせない作物であるため、この固定はそのまま着果不良として現れます。石灰が手に入らない状況では、草木灰、焼いて砕いた貝殻や卵の殻の粉が代用になり、この話は5節に続きます。
