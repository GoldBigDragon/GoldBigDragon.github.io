## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

&nbsp;&nbsp;&nbsp;茄子是茄科（Solanaceae）茄属（Solanum）的多年生草本植物，但在温带地区因无法越冬而作一年生栽培。学名为Solanummelongena。同属中有马铃薯（Solanum tuberosum），同科中有辣椒（Capsicum）、番茄（SolanumLycopersicum）、烟草。这一谱系在实际操作中只意味着一件事：它们会把病害整个共享。

&nbsp;&nbsp;&nbsp;青枯病、疫病、黄萎病、烟草花叶病毒、蚜虫、蓟马、烟青虫，会在茄科作物之间不加区分地传播。在种过茄子的地方第二年种辣椒，土壤中残留的病原菌就会侵染辣椒。在挖过马铃薯的地方种茄子也是一样。评价表中的连作适应性D就是把这一事实浓缩成一个等级，第11节的轮作设计全部由此而来。

&nbsp;&nbsp;&nbsp;原产地是从印度东部到缅甸一带的亚热带地区。野生祖先是多刺、果实小的灌木状植物，经过人类长期选育，刺逐渐消失，果实也变大了。这一出身决定了栽培条件。第一，属于喜温植物，怕霜冻。10℃以下生长停止，一旦遭遇霜冻，整块田会变黑枯死。第二，原产于雨季分明的地区，需水量大。总蒸散量达到750mm，一旦干旱，花和幼果会立刻脱落。第三，还保留着多年生植物的痕迹，一旦扎根，就会持续开花结果直到霜降。第8节的更新修剪之所以有效，原因就在这第三个特性上。

### 2-2. 形态

| 器官 | 特征 |
|---|---|
| 叶 | 呈宽卵形，边缘有浅锯齿。表面密生细毛，摸起来粗糙。很多品种叶脉和叶柄带紫色 |
| 茎 | 直立生长，下部会像木质一样变硬。在一定节位分成两杈，这个最初的分杈点称为bangadari（首个分枝点）。株高60-120cm |
| 根 | 虽有笔直的主根，但实际上细根多集中在30cm以内的表土层，属于浅根性。这是怕旱的原因 |
| 花 | 淡紫色或白色的星形花朝下开放。一朵花中雌蕊和雄蕊并存，以自花授粉为主 |
| 果实 | 属于浆果。因品种不同，形状从细长的圆筒形到圆形不等，果皮以黑紫色为主，也有紫色、白色、绿色系统 |
| 种子 | 直径2-3mm，呈扁平圆盘状，浅褐色。分散嵌在果肉之中 |

&nbsp;&nbsp;&nbsp;理解bangadari是茄子栽培的一半。茄子的茎长到一定节位后，会在顶端开出第一朵花，并在该处分成两杈。分开的两根茎继续生长，各自开花后又再分杈。这种结构不断重复，因此茄子在生长过程中会无限地成倍分枝。若放任不管，茎会分出几十条杈，这样一来每根茎分到的养分就会分散，导致果实变小、内部种子过早形成。第8节的整枝正是处理这一结构的作业。

&nbsp;&nbsp;&nbsp;根系浅带来两个后果。一是怕旱，表土10cm一干就立刻反应。二是因为根浅，除草或培土时锄头容易伤到根。诀窍是株丛周围用手拔草，锄地只在垄的中间进行。不过第8节的更新修剪会特意切断这些根以促发新根，那是时机和目的都不同的另一回事。

&nbsp;&nbsp;&nbsp;花的结构也值得了解。茄子花朝下开放，雌蕊比雄蕊长的长柱花和雌蕊短的短柱花混合出现。长柱花容易授粉成功、结出好果实，短柱花则多因授粉不良而脱落。养分不足或遭遇高温胁迫时，短柱花的比例会升高。如果地里花开得多却不结果，通常是水分或肥料不足，或是盛夏高温所致。

### 2-3. 生长阶段

| 阶段 | 时期 | 关键生理 | 重要养分 |
|---|---|---|---|
| 育苗期 | 从播种到定植（70-80天） | 长到真叶5-7片。第一个花蕾形成前后是定植适期 | 氮、磷 |
| 定植·缓苗期 | 定植后1-2周 | 长出新根并扎入土中。这段时间看起来没有生长是正常现象 | 磷 |
| 营养生长期 | 定植后2-5周 | 茎变粗、叶片展开，形成bangadari | 氮 |
| 开花·坐果期 | 定植后40-50天 | bangadari处开出第一朵花，此后每根新枝都会陆续开花 | 磷、硼 |
| 膨大·采收期 | 开花后10-20天到降霜为止 | 果实迅速膨大。摘下后马上会接着开下一朵花 | 钾与氮的平衡 |
| 衰退·更新期 | 7月下旬-8月上旬 | 因高温和连续坐果导致长势下降。此时进行更新修剪，可以延续到9-10月的收获 | 氮、钾 |

> **茄子的生殖生长一旦开始，直到降霜之前都不会停止。摘果越勤，下一朵花来得越快；若放任果实不摘，那株植株就会把养分都用在那个果实上，不再形成新花。**

&nbsp;&nbsp;&nbsp;这一特性解释了第12节收获要领的全部内容。从植物的角度看，结果的目的是留下种子，种子一旦成熟，目的就已达成，也就没有理由再开花了。如果人不断把果实摘掉，植株就会一直处于未达成目的的状态，从而持续开花。评价表中的持续性B正是由这一原理得出的等级，实际上一株到降霜前能结出20-40个果实。

&nbsp;&nbsp;&nbsp;育苗期长达70-80天这一点值得再次强调。这段时间之所以这么长，是因为茄子在幼苗阶段生长速度较慢。子叶长出后，再长出一片真叶需要一周时间。低温下这个速度会更慢，到15℃时几乎停滞。因此整个育苗期都必须保持夜温至少15℃，最好20℃以上，这是灾害情况下最困难的部分。

### 2-4. 每100g营养成分

| 营养素 | 含量 | 备注 |
|---|:---:|---|
| 热量 | 19-25kcal | 按韩国国家标准食品成分表生品标准为19kcal。在蔬菜中属于偏低水平 |
| 水分 | 92g | 是热量偏低的直接原因 |
| 蛋白质 | 1.13g | 占热量比例的23.8%。绝对量少，但密度高 |
| 碳水化合物 | 5.7-6.0g | 相当一部分是膳食纤维 |
| 脂肪 | 0.1-0.2g | 几乎没有 |
| 膳食纤维 | 3.0g | 在蔬菜中属于偏多水平 |
| 钾 | 230mg | 是茄子矿物质中最突出的一项 |
| 钙 | 15-20mg | 属于一般水平 |
| 铁 | 0.3-0.4mg | 偏低 |
| 镁 | 14mg | 属于一般水平 |
| 维生素C | 2.2mg | 非常低。茄子不是维生素C的良好来源 |
| 维生素B6 | 0.1mg | 属于一般水平 |
| 叶酸 | 22 µg | 属于一般水平 |
| 茄色苷（花青素） | 集中在果皮 | 是深紫色的成因，属于抗氧化色素 |
| 绿原酸 | 果肉中含有 | 是切面褐变的原因物质 |

&nbsp;&nbsp;&nbsp;从这张表里要读出两点。第一，维生素C每100g只有2.2mg，实际上几乎等于没有。与羽衣甘蓝的90mg、辣椒的44-78mg相比，差了一个数量级。不能指望茄子承担冬季防治坏血病的作用。第二，茄子在营养上的个性不在于某种维生素，而在于钾、膳食纤维，以及果皮中的色素。

&nbsp;&nbsp;&nbsp;茄色苷是形成果皮紫色的花青素类色素。从植物的角度看，它是保护果实内部免受强光紫外线伤害的遮阳层；从人的角度看，它是一种抗氧化物质。实际操作中重要的是，这种成分只存在于果皮中。削皮会让茄子一半的营养特色消失。原则上应该连皮一起吃，果皮变硬的老果，本来就是错过了采收时机。

&nbsp;&nbsp;&nbsp;绿原酸是切开的茄子很快变成褐色的原因。这是接触空气中的氧气后酶发生作用而变色的反应，并非变质。只是外观不佳，还会带涩味，所以切开后立刻浸入清水或盐水中可以减缓这种反应。第15节的干制中，如何处理这种褐变，是决定品质的关键。

## 3. 栽培环境

### 3-1. 温度

| 类别 | 极限值 | 最适值 | 备注 |
|---|:---:|:---:|---|
| 发芽温度 | 15-35℃ | 28-30℃ | 20℃以下发芽会非常缓慢且不整齐 |
| 育苗温度（白天） | 20-32℃ | 22-30℃ | 低温下真叶长出的速度会降到一半 |
| 育苗温度（夜间） | 15℃以上 | 18-20℃ | 经常低于15℃会导致花芽发育不良 |
| 生长温度 | 17-35℃ | 22-30℃ | 17℃以下生长会明显变慢 |
| 结实温度 | 20-30℃ | 23-28℃ | 评价表中的温度适应幅度C正是源于这10℃的幅度 |
| 高温极限 | 35℃以上 | - | 花粉活力下降，花朵会脱落 |
| 低温极限 | 10℃以下 | - | 生长停止，持续则会枯死 |
| 致死 | 0℃以下 | - | 一次霜冻就会让全株变黑枯死 |

&nbsp;&nbsp;&nbsp;能结实的范围只有20-30℃这10℃的幅度，这一事实决定了茄子栽培的时间表。在韩国的气候条件下，这个条件成立的时段是从6月中旬到9月中旬，前后的5月和10月是缓冲区间。在晚霜结束前定植会冻死，初霜一到就结束了。把定植时间定在晚霜结束之后，原因就在这里。

&nbsp;&nbsp;&nbsp;盛夏的高温也会带来问题。超过35℃后花粉失去活力，无法完成授粉，未授粉的花就会脱落。7月下旬到8月上旬之间之所以会出现开花却不结果的阶段，原因就在这里，同一时期植株的长势也会下降。之所以在这个时间点进行更新修剪，是因为反正这段时间不结果，正好把它用来恢复长势。

### 3-2. 光照

| 类别 | 标准 | 备注 |
|---|---|---|
| 所需日照 | 每天6小时以上 | 坐果稳定，果色更深 |
| 最低日照 | 每天4小时 | 虽能生长，但会徒长，坐果变差 |
| 40%遮光时 | 相对产量102% | 是果菜类的共通数值，也是评价表中S等级的依据 |
| 强光胁迫 | 盛夏直射光+35℃ | 果皮出现日灼，留下白色斑点 |

&nbsp;&nbsp;&nbsp;茄子在40%遮光下也能维持产量，这一点在灾害情况下安排田地布局时很有用。整天有日照的位置应优先留给谷物、豆类和马铃薯，茄子在只有半天日照的位置也能发挥应有的产量。盛夏时反而遮挡一下西晒的午后阳光，能减少果皮日灼。不过日照一旦低于每天4小时，就会只长茎不结花，所以不能把耐遮光理解成可以种在阴凉处。

&nbsp;&nbsp;&nbsp;果色也与光照有关。果皮的紫色来自花青素，而花青素需要受光才能形成。被叶片遮住的果实颜色会偏浅或出现斑驳。食用没有问题，但如果发色不好的果实很多，说明叶片过于茂密，是该整理下部叶片的信号了。

### 3-3. 水分与土壤

| 项目 | 标准 | 备注 |
|---|---|---|
| 总蒸散量 | 每个生长期约750mm | 在果菜中属于偏多水平，也是评价表中耗水量C的依据 |
| 土壤水分 | 最大持水量的70-80% | 过干会落花落果，过湿会烂根 |
| 土质 | 富含有机质的壤土、沙壤土 | 需要保水力和排水性兼备 |
| 土层深度 | 30cm以上 | 由于细根集中在表土，表土需要足够厚 |
| pH | 6.0-7.0 | 6.5左右最为适宜 |
| pH下限 | 5.5 | 低于此值磷和钙的吸收会变差 |
| 耐盐性 | 弱 | 在盐分积累的地块中生长会受到抑制 |

&nbsp;&nbsp;&nbsp;茄子既需水量大，又受不了积水。这看似矛盾的要求，源于其浅根性。根系集中在表土，表土一干就会立刻缺水，同样道理，表土一旦积水，根系就无法呼吸。解决办法是把垄做高。把垄抬高20cm以上，既能让根层以下的水排走，垄内又能保住水分。在梅雨季（6月下旬至7月）漫长的韩国气候条件下，高垄不是可选项，而是前提条件。

> **干旱时茄子发出的第一个信号不是叶子，而是花。叶片萎蔫之前，花和豆粒大小的幼果就已经开始脱落。等叶片彻底耷拉下来才浇水，那一周的收成早已经没有了。**

&nbsp;&nbsp;&nbsp;关于pH还有一点值得补充。茄子并不是对酸性特别敏感的作物，但pH降到5.5以下时，磷会与铁或铝结合，被固定成植物无法利用的形态。由于结实离不开磷，这种固定会直接表现为坐果不良。在无法获得石灰的情况下，草木灰、烧过磨碎的贝壳和蛋壳粉可以作为替代品，这个话题将在第5节继续讨论。
