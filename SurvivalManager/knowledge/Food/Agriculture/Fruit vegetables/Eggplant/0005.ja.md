## 8. 栽培管理 - わき芽かきと更新剪定

### 8-1. 整枝 - 3本仕立てにする理由

&nbsp;&nbsp;&nbsp;ナスはバンアダリで二又に分かれ、分かれた茎がさらに二又に分かれます。放っておくと4本、8本、16本へと増えていきます。茎が増えるほど葉も増えるので光合成の総量は増えますが、一つの実に回る養分は減ります。結果は、小さくて種が早くできる実がたくさん付いた状態です。しかも内部が密集して光と風が入らなくなります。

| 段階 | 内容 |
|---|---|
| 1. バンアダリの確認 | 最初の花が咲いた場所で、茎が二又に分かれた地点を探します |
| 2. 下のわき芽の除去 | バンアダリより下から出るわき芽はすべて手で折って取り除きます |
| 3. 主枝の選定 | バンアダリで分かれた2本の茎に、バンアダリのすぐ下にある最も丈夫なわき芽1本を加えて3本仕立てにします |
| 4. その後の管理 | この3本の茎からさらに分かれるものはそのままにしますが、内側に入り込んで重なる茎だけを間引きます |
| 5. 下葉の整理 | 地面から30cm以内の葉は、収穫が始まったら順次取り除きます |

&nbsp;&nbsp;&nbsp;バンアダリより下のわき芽をなくすことが特に重要です。これらのわき芽はほとんど花をつけずに養分だけを奪い、地面近くで茂って通風を妨げます。土に触れる葉は、雨粒が跳ねて病原菌をそのまま受け入れる通り道になります。わき芽は爪ほどの大きさのうちに手で折って取り除く方が傷が小さくて済みます。太くなってから刃物で切ると、その傷から病気が入ります。

| 項目 | こつ |
|---|---|
| 除去のタイミング | 晴れた日の午前 |
| 理由 | 傷がその日のうちに乾きます。雨の日に取り除くと、傷から細菌が入ります |
| 道具 | できるだけ手で。刃物を使うなら株ごとに火であぶるか熱湯に浸けて使います |
| 理由 | 青枯病とウイルスは刃を伝って株から株へと移っていきます |

### 8-2. 葉三枚の法則

&nbsp;&nbsp;&nbsp;ナスの実一つをしっかり育てるのに必要な葉はおよそ3枚です。実の上に1枚、下に2枚が光合成でその実を養います。これより葉が少ないと実が小さくなり、これより多くても余った葉は影を作るだけです。そのため、収穫するときにその実の下の葉2、3枚を一緒に取り除くというこつが生まれました。それらの葉はすでに役目を終えており、今はこれから付く実を覆い隠す障害物でしかありません。

> **ナスの葉を取り除くことは、植物を傷つけることではなく、養分の向きを変えることです。ただし一度にたくさん取り除くと光合成能力そのものが崩れるので、一回で全体の葉の20%を超えないようにします。**

### 8-3. 誘引

| 方法 | 内容 | 特徴 |
|---|---|---|
| 一本仕立て誘引 | 株ごとに支柱を1本立てて主枝を結びます | 最も簡単ですが、横に広がった枝が垂れ下がります |
| 二段誘引 | 畝の両側に支柱を立て、紐を二段に張ってその間に株を挟み込みます | 枝を広げて通風が良くなります |
| X字誘引 | 1.8mの支柱2本を交差させて立て、その交点に横木を渡します | 通風と支持の両方が良く、枝が広がります |

&nbsp;&nbsp;&nbsp;誘引の目的は倒伏防止だけではありません。茎を外側に広げて株の中に光と風を入れることが、より大きな目的です。実がつき始めると一株の重さが大きく増し、夏のにわか雨や台風で茎が裂けます。裂けた場所は病気の入り口になります。結ぶときは茎を8の字形に巻いて支柱に結び、茎が締め付けられないようにし、育つにつれて太くなるので余裕を持たせます。誘引ひもは、藁をなった縄、クズのつる、コウゾの樹皮のようなもので代用できます。

### 8-4. 更新剪定 - 秋ナスを得る仕組み

&nbsp;&nbsp;&nbsp;7月下旬から8月上旬になると、ナスの勢いが目に見えて落ちます。原因は二つです。一つは35℃を超える高温で花粉が力を失い受粉できなくなること、もう一つは2か月間休みなく実を作り続けたことで根と茎が消耗したことです。この時期にそのままにしておくと、葉ばかり茂って実がならない状態のまま秋を迎えます。

| 段階 | 内容 |
|---|---|
| 時期 | 7月下旬-8月上旬、梅雨が明けて勢いが落ちた頃 |
| 茎の切り戻し | 各主枝を下から2-3節だけ残して切り落とします。切った位置の下に芽が残っている必要があります |
| 断根 | 株から25-30cm離れた場所にスコップを20cmの深さまで差し込み、古い根を切ります |
| 追肥 | 切った場所に堆肥と薄めた尿を入れて土をかぶせます |
| 灌水 | たっぷり与えます。その後は乾かさないように管理します |
| 回復 | 2-3週間後に新芽が出て育ち、9月中旬から再び実が付きます |

&nbsp;&nbsp;&nbsp;断根は奇妙に聞こえるかもしれません。根をわざと切る理由は、新しい根を誘導するためです。古い根は吸収能力が落ちており、切れた場所から新しい根が旺盛に出てきます。葉と茎を半分以上切り落とした状態なので、根が負担する量も減っています。ここに追肥と水を入れると、植物は新しい茎と新しい根を同時に作り出します。人が人為的にもう一度春を作ってやるようなものです。

> **秋ナスがおいしいという古くからの言葉は、情緒的な表現ではなく生理的な事実です。気温が下がると実はゆっくり大きくなり、ゆっくり育った実は細胞が密で果肉が柔らかく、種が少ないのです。更新剪定は、その秋ナスを得るための準備です。**

&nbsp;&nbsp;&nbsp;ただし更新剪定には条件があります。第一に、霜までの残り期間が最低でも2か月は必要です。韓国中部で8月中旬を過ぎてから切ると、新芽が実を結ぶ前に霜が来てしまいます。第二に、株が病気にかかっていないことです。青枯病や半身萎凋病にかかった株は、切っても回復せずそのまま枯れます。第三に、水と肥料を与え続けられることです。切っただけで放置すると回復しません。この三つのうちどれか一つでも満たされなければ、剪定せずそのままにしておく方がよいです。

## 9. 病害虫 - 薬を使わずに防ぐ方法

### 9-1. 主な病害

| 病名 | 症状 | 発生条件 | 薬を使わない対応 |
|---|---|---|---|
| 青枯病（チョンゴビョン） | 日中に急にしおれ、朝に持ち直すことを数日繰り返した末に枯れます。茎を切ると白い細菌の液が出ます | 高温多湿、土壌伝染 | 治療法はありません。見つけ次第根こそぎ抜いて焼却し、その場所の土も取り除きます。5-7年輪作 |
| 疫病 | 地面に接する茎の根元が暗褐色にくびれて急速にしおれます | 過湿、排水不良、梅雨 | 高畝と排水路が唯一の対策です。ボルドー液の予防散布 |
| 半身萎凋病 | 葉の片側半分だけが黄色く変わってしおれます | 低温多湿、土壌伝染 | 治療法はありません。罹病株の除去と長期輪作 |
| 灰色かび病 | 花や傷口に灰色のかびが生え、実が軟化します | 低温多湿、通風不良 | 咲き終わった花を落とし、通風を確保します |
| 葉かび病 | 葉の裏に灰褐色のかびが生じ、表面が黄色くなります | 多湿、通風不良、窒素過多 | 下葉の整理、窒素の与えすぎ禁止 |
| うどんこ病 | 葉の表面が白い粉で覆われます | 乾燥と多湿が交互に来るとき | 水1に対し牛乳1-2の割合の希釈液、重曹の希釈液 |
| ウイルス病 | 葉がまだらになって縮み、実が奇形になります | アブラムシ・アザミウマが媒介します | 治療は不可能です。媒介虫を防ぎ、罹病株を除去します |

&nbsp;&nbsp;&nbsp;青枯病は別途理解しておく必要があります。原因はRalstonia solanacearumという細菌で、この菌は土の中で何年も生き続けます。根の傷から侵入して導管を塞ぎ、導管が塞がれると植物は水を吸い上げられずしおれます。日中にしおれ、朝に持ち直すことを数日繰り返す独特の症状はここから来ています。かび病ではなく細菌病であるため、ボルドー液のような予防剤があまり効かず、一度入り込むと元に戻す方法はありません。

> **青枯病にかかった株を抜いたとき、畑にそのまま放置したり堆肥の山に入れたりすると、菌が畑全体に広がります。抜いたら焼却するか、畑から遠く離れた場所に深く埋めます。抜いた手や道具は必ず洗います。**

&nbsp;&nbsp;&nbsp;評価表の防除自立度Cは、こうした事情を反映しています。薬があっても青枯病と半身萎凋病には使えるものがなく、薬がなければ残りの病気でも損害が大きくなります。無防除時の減収率推定49.8%、つまり何の防除もしなければ半分を失うという数字をそのまま受け入れる必要があります。ナスを薬なしで育てるということは、半分を失うことを前提に植えるという意味であり、したがって必要な量の2倍を植えてこそ計算が合います。

### 9-2. 主な害虫

| 害虫 | 被害 | 薬を使わない対応 |
|---|---|---|
| アブラムシ | 葉裏や新芽に付いて汁を吸い、ウイルスを媒介します | 石けん水の散布、手でこすりつぶす、テントウムシやクサカゲロウの保護 |
| ハダニ | 葉裏に付いて汁を吸い、葉が白く変わり、クモの巣状のものができます | 葉裏に強く水をかけます。乾燥時に大発生するため灌水を増やします |
| アザミウマ | 花や幼果に付いて傷をつけます。ウイルスを媒介します | 黄色・青色の粘着トラップ、わらマルチで蛹の移動を遮断 |
| タバコガ | 幼虫が実の中に入り込んでかじります | 穴の開いた実を摘み取って処分します。幼虫は手で捕まえます |
| カメムシ | 実の汁を吸い、その部分が硬く固まって奇形になります | 早朝、動きが鈍いときに手で捕まえます |
| ノミハムシ | 幼苗の葉に小さな穴を開けます | 定植初期に防虫網をかけます |

### 9-3. 薬を使わない防除剤

| 防除剤 | 作り方 | 用途 | 注意 |
|---|---|---|---|
| ボルドー液 | 硫酸銅1kgと生石灰1kgをそれぞれ別々に水に溶いて冷ましてから合わせ、水で100Lに仕上げます | 疫病・細菌性斑点病の予防 | 予防剤であり治療剤ではありません。高温期に濃く使うと葉が焼けます |
| 石けん水 | 香料と添加物のない石けん20gを水1Lに溶かします | アブラムシ・ハダニ | 葉裏に当たってこそ効果があります。日中に散布すると葉が焼けます |
| 牛乳希釈液 | 牛乳と水を1対1から1対2で混ぜます | うどんこ病 | 乾く過程でかびの菌糸を物理的に押さえつけます |
| 草木灰 | ふるいにかけた灰を葉と土に軽く振りかけます | 害虫忌避、カリウム供給 | 雨が降ると洗い流されます |
| 木酢液 | 炭を焼くときに出る煙を冷やして採った液を300-500倍に薄めます | 忌避、微生物の活性化 | 原液は強酸性なので必ず薄めます |
| タバコの葉・トウガラシの浸出液 | 細かく刻んで水に1日浸けてから濾して使います | 柔らかい体の虫の忌避 | 人にも刺激があります。収穫直前には使いません |

### 9-4. 耕種的防除 - 植え方で防ぐ方法

| 方法 | 原理 |
|---|---|
| 輪作 | ナス科作物を5-7年間隔で回して土壌伝染病の密度を下げます。最も確実な対策です |
| 高畝 | 根の層に水がたまらないようにして疫病と根腐れを減らします |
| 広い植え付け間隔 | 通風を確保し、かび病の発生条件そのものをなくします |
| わらマルチ | 雨粒が跳ねて土中の病原菌が下葉に付着するのを防ぎます |
| 下葉の整理 | 地面に近い葉をなくして感染経路を絶ちます |
| 病んだ部位の焼却 | 畑に残った罹病残渣が翌年の感染源になります |
| 健全な苗 | 育苗の段階で病気にかかった苗は植えません |
| 道具の消毒 | 刃物とはさみを株ごとに火であぶるか熱湯に浸けます |

&nbsp;&nbsp;&nbsp;8つの中で実質的に最も大きな役割を果たすのは輪作と排水です。残りは損害を少しずつ減らす手段であり、この二つは病気が成立する条件そのものをなくします。薬がない条件でナスを育てるには、防除よりも配置に力を注ぐべきだという意味です。

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然素材による対処 |
|---|---|---|
| 下葉から全体が黄色くなり、株が小さいです | 窒素欠乏 | 尿を10-15倍に薄めて溝に注ぐか、腐熟堆肥を株の周りに入れます |
| 葉の縁が茶色く焼けたようになり、実が小さいです | カリウム欠乏 | 草木灰を株ごとにひとつかみずつ土に混ぜます。果物の皮の堆肥にもカリウムが多いです |
| 生育が遅く、葉の裏と茎が紫色を帯びます | リン酸欠乏 | 骨粉や草木灰を入れます。低温期には土が冷たくて吸収されない場合もあります |
| 花は多いのに実がならず、花がそのまま落ちます | ホウ素欠乏または高温ストレス | 堆肥の原料を多様にします。高温が原因なら遮光で下げます |
| 葉脈の間だけ黄色くなり、葉脈は緑のまま残ります | マグネシウム欠乏 | 苦土石灰（ドロマイト）の粉、または堆肥の原料を多様にします |
| 新葉が小さく奇形で、生長点が枯れます | カルシウム欠乏 | 焼いて砕いた卵・貝殻の粉。たいていは水不足でカルシウムが移動できていないのです |
| 葉ばかり大きく茂り、色が濃い青緑なのに花が少ないです | 窒素過剰 | 窒素の供給を止め、草木灰でカリウムを補います。水をたっぷり与えて洗い流します |
| 葉の縁が内側に巻き込み、生育が止まります | 塩類集積 | 水をたっぷり与えて洗い流し、翌年は肥料の量を減らします |

&nbsp;&nbsp;&nbsp;ナスで最もよくある問題は窒素過剰です。尿と堆肥は窒素が相対的に多くリン酸とカリウムが少ないため、これだけを与え続けると葉は茂るのに花が少ない状態になります。葉が濃い緑で厚く、茎が太いのに花が少ないなら、ほぼ間違いなくこのケースです。このとき窒素をさらに与えると状態はさらに悪化します。草木灰と骨粉でカリウムとリン酸を入れてバランスを取るのが答えです。

> **カルシウム欠乏の症状が現れたとき、土にカルシウムがない場合はまれです。カルシウムは水に乗って移動する元素なので、水が足りないと土に十分なカルシウムがあっても新しい葉や実まで届きません。カルシウム欠乏に見える症状のほとんどは、実は水不足です。**

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 対象 | 理由 |
|:---:|---|---|
| 良い | マメ科作物（インゲンマメ・ササゲ・エンドウ） | 根粒菌が固定した窒素が土に残ります |
| 良い | マリーゴールド | 根から出る物質が根こぶ線虫を抑制します |
| 良い | バジル・シソ | 強い香りがアブラムシとアザミウマを混乱させます |
| 良い | ネギ・ニンニク | 硫黄化合物が土壌病原菌の密度を下げます |
| 悪い | トマト・トウガラシ・ジャガイモ（ナス科） | 病害虫をそっくり共有します。隣に植えるのも避けます |
| 悪い | トウモロコシ | 影を作り、養分の競合が大きいです |
| 悪い | カボチャ | つるが覆って通風を妨げます |

&nbsp;&nbsp;&nbsp;ナスの間に豆を植える配置は、災害時に特に価値があります。ナスは多肥性で窒素を多く必要とし、豆は根粒で窒素を自ら作ります。豆が作った窒素はその年にすぐナスに渡るわけではありませんが、豆の根が腐ることで翌年の土に残ります。さらに豆は丈が低いためナスの日光を遮らず、地面を覆って雑草を抑えます。ただしつる性の豆はナスに巻きついて登るため、ブッシュ型のインゲンマメやササゲが適しています。

### 11-2. 輪作

| 年 | 作物 | 目的 |
|---|---|---|
| 1年目 | ナス | |
| 2年目 | マメ科（ダイズ・インゲンマメ・ササゲ） | 窒素回復、ナス科病原菌の宿主遮断 |
| 3年目 | 葉菜類（ハクサイ・サンチュ）またはネギ属（長ネギ・ニンニク） | 根の深さが異なり、土壌層を均等に使います |
| 4年目 | 穀物（トウモロコシ・モロコシ）または根菜（ダイコン・ニンジン） | 有機物の還元、土壌構造の改善 |
| 5年目 | マメ科または緑肥 | 地力の回復 |
| 6年目以降 | ナス再開 | |

&nbsp;&nbsp;&nbsp;評価表が求める5-7年の休作期間は、狭い土地では守るのが難しいです。畑が5区画以上なければ、この周期が成立しないからです。現実的な妥協点は三つあります。

| 方法 | 内容 | 限界 |
|---|---|---|
| 区画を細かく÷ | 畑を6区画に分け、毎年一区画ずつ移動します | 区画ごとに日照と水の条件が異なり、収量にばらつきが出ます |
| 移動栽培 | 毎年違う場所、畑の縁や家の周りに数株ずつ植えます | 管理が分散し、収穫もばらけます |
| 土の入れ替え | 病気がひどく出た場所の土30cmを取り除き、新しい土で満たします | 労力が大きく、土を調達できる場所が必要です |

> **ナスを3年以上同じ場所に植えると、最初の2年は問題なくても3年目に突然半分が枯れてしまうことがよくあります。土壌病原菌は静かに蓄積し、あるとき一気に表面化します。輪作は病気が現れた後に始めるものではなく、病気が現れる前に行うことです。**

&nbsp;&nbsp;&nbsp;ナスの後に何を植えるかも考えるべきことです。ナスは4か月間多くの養分を持ち出すため、後に来る作物はその消耗に耐えられる必要があります。マメ科が第一候補である理由はここにあり、第二候補は痩せた土地でも育つソバとモロコシです。逆に、ナスのすぐ後にハクサイやキャベツのように肥料を多く必要とする作物を植えると、両方の作物とも満足のいかない結果に終わります。ナスを片付けた後、茎と葉を細かく刻んでその場所にすき込めば翌年の有機物になりますが、病気にかかった株は必ず除き、健全なものだけを入れます。
