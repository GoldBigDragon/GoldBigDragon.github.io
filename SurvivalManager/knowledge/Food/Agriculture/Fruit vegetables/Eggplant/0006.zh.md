## 12. 收获 - 只有勤摘才能持续结果

| 类别 | 标准 | 备注 |
|---|---|---|
| 采收适期 | 开花后10-20天 | 气温高时缩短，气温低时延长 |
| 大小标准 | 达到品种标准长度时（长果型15-20cm） | 因品种而异，应看状态而非长度 |
| 状态标准 | 皮有光泽，用手按压有弹性 | 光泽消失就已经晚了 |
| 首果 | 达到鸡蛋大小时提前摘掉 | 是为了先让株体长大 |
| 采收间隔 | 每周2-3次 | 夏天两天就会明显变大 |
| 采收时间 | 清晨 | 经过一夜含水最多，最新鲜也最耐放 |
| 采摘方法 | 用剪刀或刀切断果柄上方 | 拧摘会使茎裂开 |

### 12-1. 为什么要早摘

&nbsp;&nbsp;&nbsp;茄子是成熟后品质反而下降的作物。人吃的茄子在植物学上是未成熟的果实。吃的是种子还没成熟时的果实，一旦种子开始成熟，果肉就会像海绵一样变得松软，皮变韧，出现苦味。皮色也会由黑紫色变为发黄。变黄的茄子不是熟了，而是错过了食用时期。

> **茄子只有摘了才会继续结果。若把果实留在株上，那株就会把全部养分用于结种，不再开新花。地里放着两三个老茄子不摘，整株的产出就会停止。**

&nbsp;&nbsp;&nbsp;评价表中的持续性B级正是建立在这个原理之上。能一直采收到降霜前并非自然而然，而是勤于采摘换来的结果。每周巡田两三次，把长成的果实全部摘下，虫蛀的和畸形的也一并摘除。烂果留在株上只会白白耗走养分，还会成为病害的据点。

### 12-2. 为什么要提前摘掉首果

&nbsp;&nbsp;&nbsp;把长在门椏上的首果在鸡蛋大小时提前摘掉，是流传已久的诀窍。对植物来说，首果是优先级最高的器官，还很矮小的株会把养分全部集中到这一个果实上。结果就是茎和根长不起来，只有这一个果实变大，之后因为力量不足而不容易再结果。提早摘掉首果，那部分养分就会回到茎和根，株体因此长大，长大后的株在之后四个月里能结出更多果实。这是放弃眼前的一个果实、换取整体产量提升的一种取舍。

### 12-3. 采收后的处理

| 项目 | 内容 |
|---|---|
| 果柄 | 留3-5mm剪断。注意不要被果柄上的刺扎到 |
| 洗净 | 在食用前才洗。提前洗会使表面残留水分成为腐坏的起点 |
| 摆放 | 叠放会使受压处变软。要摆成一层 |
| 温度 | 以10-12℃最为适宜。低于此温会出现表皮凹陷的低温伤害 |
| 之后 | 只留下当天要吃的，其余的立即切开晒干 |

&nbsp;&nbsp;&nbsp;低温伤害是茄子的一个特有性质。它原产热带，长时间置于5℃以下的低温会使细胞受损，皮上出现凹陷斑点，内部变褐。即使有冰箱，把茄子放进冷藏室深处也不是好的保存方法；而在没有冰箱的条件下，反而不存在这个问题。凉爽的地板下、朝北的屋檐下，10-15℃左右的地方最为合适。

## 13. 留种 - 自花授粉带来的好处

### 13-1. 茄子留种容易的原因

&nbsp;&nbsp;&nbsp;茄子的自家留种等级为S，理由有两个。第一，自花授粉占优势。茄子花一朵之内就有雌蕊和雄蕊，花开时自己的花粉落到自己的雌蕊柱头上就完成授粉。异花授粉的比例据报告在5-20%之间，视条件而定，蜜蜂多的环境比例会更高。这与羽衣甘蓝因自交不亲和而必须接受其他株花粉形成对比。第二，一个果实里有数百到上千粒种子。只留种两三个果实，就够用好几年。

| 项目 | 标准 |
|---|---|
| 所需隔离距离 | 与其他茄子品种相距30-50m |
| 留种株数 | 至少3-5株 |
| 每果种子数 | 数百到1,000粒以上 |
| 种子寿命 | 常温密闭3-4年 |

&nbsp;&nbsp;&nbsp;留种株要留3-5株以上，理由不是为了防杂交，而是出于遗传广度。即便是自花授粉作物，若一直只从一株上留种，随着世代增加，那个系统的多样性会减少，一旦某种病害击中这个系统的弱点，整体就会一起垮掉。从多株上均匀留种能降低这种风险。

### 13-2. 留种步骤

| 阶段 | 时期 | 内容 |
|---|---|---|
| 留种株选定 | 7月 | 挑选无病、长势好、品种特征明显的株 |
| 留种果选定 | 7月下旬-8月 | 挑选该株下部、长势好时结的果 |
| 标记 | 选定之后立即 | 系上绳子做标记，防止误摘 |
| 完熟 | 9-10月 | 放到皮变黄褐色、光泽消失为止。约在开花后60-70天 |
| 后熟 | 采收后 | 放在阴凉处1-2周，让种子更加成熟 |
| 分离种子 | 后熟后 | 剖开果实，连果肉一起放入水中，用手揉搓取出种子 |
| 沉降 | 分离后立即 | 放入水中，饱满的种子会下沉，空壳和果肉会漂浮，浮起的丢弃 |
| 干燥 | 分离后 | 摊在布上于阴凉处晒1-2周。用手一折即断即为完成 |
| 保管 | 完全干燥后 | 装入密闭容器并放入干燥剂，置于阴凉黑暗处 |

> **留种用的果实必须从下部、也就是株体长势最旺时结的果实中挑选。临近降霜时结的果实种子未能充分成熟，发芽率会下降。**

&nbsp;&nbsp;&nbsp;不能把种子直接放在阳光下晒干。直射阳光的热量会损伤胚，使发芽率大幅下降。原则是在通风的阴凉处慢慢晒干，堆得太厚里面会长霉，所以必须摊成一层。

| 项目 | 标准 |
|---|---|
| 目标水分 | 8%以下 |
| 干燥剂 | 炒过晾凉的大米、炭、干草木灰、烧过晾凉的盐 |
| 保管容器 | 玻璃瓶、金属罐、双层包裹的纸袋 |
| 保管温度 | 越低越好，且要保持稳定不波动 |
| 发芽检测 | 每年取20粒放在湿布上，一周后统计发芽率 |

&nbsp;&nbsp;&nbsp;种子保管的原则是干燥、低温和黑暗。这三者中，在灾害状况下能确实控制的只有干燥，因此要把主要精力放在干燥上。把炒过晾凉的大米按种子体积的三分之一左右一起放入并密闭，大米会吸走残余的湿气。炭也起同样的作用，用过之后放在火边烘干还能再次使用。

### 13-3. 种子消毒

| 方法 | 步骤 | 效果 |
|---|---|---|
| 温水浸泡 | 在50-55℃水中浸10-15分钟后立即用冷水冷却 | 杀死种子表面及皮下的病原菌 |
| 草木灰拌种 | 给干种子拌上细灰 | 抑制霉菌并防潮 |
| 筛选 | 放入水中，浮起的丢弃 | 病种和空壳大多会漂浮 |

&nbsp;&nbsp;&nbsp;温水浸泡的关键在于温度，不能超出50-55℃这个范围。超过60℃种子会死，低于45℃病原菌又杀不死。没有温度计的话，把开水和冷水混合，伸手进去感觉烫但还能忍住约3秒的程度，大致就在这个范围内；用大容器多装些水，浸泡期间温度也不容易下降。

## 14. 毒性与需注意的成分

&nbsp;&nbsp;&nbsp;茄子属于茄科作物，因而含有微量的类固醇生物碱。这与马铃薯中的茄碱属于同一类，在茄子中主要以茄solanine和茄边碱（solamargine）的名义出现。正常采收的茄子中含量不足以对人体造成问题，但有必要了解在什么条件下含量会升高。

| 成分 | 是什么物质 | 会造成什么问题 | 如何避免 |
|---|---|---|---|
| 茄solanine·茄边碱 | 茄科植物为防虫防霉而制造的防御物质 | 大量食用会刺激胃肠、引起恶心 | 苦味强的果实不吃。加热后会减少一部分 |
| 尼古丁 | 微量存在于茄科植物中 | 每100g约0.01mg，没有实际影响 | 不需处理 |
| 绿原酸 | 切面变褐的原因物质 | 无毒性，只带来涩味 | 切开后浸入水中或淡盐水中 |
| 组胺诱发 | 部分人会出现瘙痒或荨麻疹 | 个体差异很大 | 初次食用时先从少量开始 |

### 14-1. 苦味是危险信号的原因

&nbsp;&nbsp;&nbsp;生物碱带有苦味，这并非偶然，而是植物的一种防御策略。它用味道发出"不能吃"的信号，动物记住那种苦味后就不会再吃。同样的信号对人也有效。吃一口茄子如果刺舌般发苦，说明那个果实生物碱含量较高，正确的做法是不再继续吃。

| 条件 | 生物碱水平 | 说明 |
|---|:---:|---|
| 正常生长的应季果实 | 低 | 安全 |
| 过于幼嫩的果实 | 略高 | 处于需要防御的时期，含量较高 |
| 错过采收期变黄的果实 | 高 | 苦味加重，果肉变得松软 |
| 严重缺水条件下生长的果实 | 高 | 应激会增加防御物质的生成 |
| 叶和茎 | 非常高 | 不是人食用的部位 |

> **茄子的叶和茎不吃。其生物碱含量远高于果实。灾害状况下因为没有吃的就把茄叶当野菜凉拌的做法是危险的。叶和茎应归还堆肥。**

&nbsp;&nbsp;&nbsp;总的来说，只要遵循正常栽培和正常采收时期，茄子的毒性就不构成实质性的危险。不过在缺水、管理松懈的灾害状况下，受应激的果实会增多，饥饿时人也会舍不得丢弃错过采收期的果实而去食用。只要坚持"发苦就丢"这一条原则即可。

## 15. 无冰箱贮藏 - 茄子干

&nbsp;&nbsp;&nbsp;茄子的贮藏性等级为D，在无电力常温下坚持不了一周。果实92%是水，这是理所当然的结果。因此让茄子撑过冬天的方法只有一个，就是把那些水分去掉。

### 15-1. 各种贮藏方式的比较

| 方式 | 条件 | 期限 | 特点 |
|---|---|:---:|---|
| 生果短期保存 | 用报纸或纸包好，放在10-15℃的阴凉处 | 5-7天 | 不洗直接放置。5℃以下会出现低温伤害 |
| 干燥（茄子干） | 切薄片，用日晒和风完全晒干 | 6个月-1年 | 体积和重量缩减到十分之一，最为实用 |
| 盐渍 | 用10-15%的盐腌制 | 数月 | 食用前须用水浸泡去盐 |
| 酱菜 | 腌入酱油、大酱、辣椒酱中 | 数月-1年 | 同时利用盐分和发酵 |
| 乳酸发酵 | 用2-3%的盐水腌制，使其沉在汤汁下方 | 数周-数月 | 容易变软，对茄子来说较难掌握 |

### 15-2. 茄子干的制作方法

| 步骤 | 方法 | 原因 |
|---|---|---|
| 1. 挑选 | 使用无伤且长势适中的果实 | 受伤处会最先开始长霉 |
| 2. 洗净 | 洗后把水分彻底擦干 | 表面残留水分会使干燥初期长霉 |
| 3. 切片 | 切成厚5-7mm的圆片，或纵向掰成四片 | 太厚会导致外皮先坏而内部还没干 |
| 4. 焯水（可选） | 在沸水中浸30秒到1分钟后取出 | 使酶失活，减少褐变、保住颜色 |
| 5. 摆开 | 摊在筛子或晒架上，单层不重叠 | 重叠的部分晒不干 |
| 6. 晒干 | 在阳光充足、通风良好处晒2-4天 | 夜里要收进屋以避开露水 |
| 7. 完成判断 | 直到用手一折就断为止 | 稍有软韧，储存期间就会长霉 |
| 8. 保管 | 放入密闭容器并加干燥剂，置于阴凉黑暗处 | 见光会使颜色褪掉 |

&nbsp;&nbsp;&nbsp;是否加入焯水这一步是分歧所在。焯水后颜色能漂亮地保留，泡开后口感也更软，但要耗费燃料。不焯水会变成褐色，但不耗燃料，香气也更浓。自古流传的茄子干就是不焯水直接晒的，颜色是黑褐色，但味道没有问题。在燃料紧缺的条件下，不焯水更合理。

> **干燥的成败取决于第一天。切开摆开的头一天，表面水分若能迅速蒸发，霉菌就无法立足。若在阴天潮湿的日子开始晾晒，第三天就会长出黑霉，只能全部丢弃。要选晴朗有风的日子开始。**

&nbsp;&nbsp;&nbsp;在梅雨季或没有日照的日子，有一种靠火烘干的方法。在做饭烧水的灶台上方、暖炕房的热处、灶台旁悬挂晒架，靠那点余热就能烘干。这种方法不额外耗费燃料，即使在潮湿的日子也能进行干燥，很适合灾害状况。不过烟直接接触会带上烟熏味，所以要放在烟道之外的位置。

| 项目 | 标准 |
|---|---|
| 相对生茄子的重量 | 约10%左右 |
| 完全干燥的判断 | 折断时有声响且不会弯曲 |
| 保管期间的检查 | 每月开盖检查一次是否有霉和潮气 |
| 变潮时 | 再晒半天后重新密闭 |
| 虫害 | 印度谷螟幼虫可能会侵入。用密闭和干燥剂防范 |

### 15-3. 盐渍与酱菜

&nbsp;&nbsp;&nbsp;在干燥困难的条件下，比如梅雨期长或不见阳光的地方，盐是一种替代方案。把茄子纵向剖开，用相当于重量10-15%的盐一层层腌制，再用重石压住让汁水没过材料。在这个浓度下，大多数微生物都无法生长，能保存数月。食用时要在水里泡几个小时以去掉盐分，在这个过程中水溶性营养素也会一并流失。

&nbsp;&nbsp;&nbsp;酱菜是在盐渍的基础上加上发酵的方式。把在盐水里腌几天变软的茄子腌入酱油或大酱中。大酱和酱油的高盐度与有机酸能阻止腐败，随着时间推移酱味渗入茄子，本身就能成为一道菜。比单用盐腌的咸菜味道更好，保存期也更长，但前提是要具备腌制酱油或大酱的条件。

## 16. 烹饪与加工

| 方法 | 燃料 | 特点 |
|---|:---:|---|
| 蒸 | 少（10分钟以内） | 茄子会浮在水面，需要用盘子压住才能均匀受热。不用油，最经济 |
| 炒 | 少 | 很吸油，味道会变好，但耗油较多 |
| 烤 | 少 | 整个放在炭火上烤后剥皮，里面会变软。用余火即可 |
| 放入汤·炖菜 | 与其他烹调共用 | 不单独耗费燃料的方法 |
| 泡开干茄子使用 | 少 | 用水泡开20-30分钟后炒或凉拌 |
| 生食 | 无 | 不推荐。味涩且残留生物碱 |

&nbsp;&nbsp;&nbsp;有一个茄子烹调时该了解的性质。果肉呈海绵结构，因此非常能吸油。油充足时这个性质是优点，但在油紧缺的灾害状况下就成了缺点。炒茄子时油会一下子就消失。避开这个问题的方法是先蒸或先焯水，让海绵结构里的空气被水占满。含了水的茄子不容易吸油，用较少的油也能炒。

> **油紧缺时，蒸茄子才是正解。把蒸好的茄子撕开，用酱油或大酱、蒜末、芝麻盐拌一下，燃料只需10分钟，油只需几滴即可。这正是"凉拌茄子"这道传统做法能够立足的原因。**

&nbsp;&nbsp;&nbsp;干茄子用水泡20-30分钟，能恢复到接近原体积的一半。泡发的水中溶出了香气和水溶性成分，不要倒掉，要用来做汤。泡发的干茄子比生茄子组织更有嚼劲、味道更浓，也不太吸油。冬天吃的干茄子凉拌菜不是勉强的替代品，本身就是另一道菜。

&nbsp;&nbsp;&nbsp;原则是不去皮。茄子的特征成分茄色素（nasunin）就在皮里，膳食纤维也集中在皮上。如果皮硬到让人想去掉，说明那个果实已经错过了采收期。晚秋的厚皮纵向切几道口子，口感会更好。

&nbsp;&nbsp;&nbsp;这张表里要特别留意2月和8月这两栏。2月是要在没有加温的情况下造出25℃的月份，8月是必须做出更新修剪判断的月份。其余月份的工作大体上是重复性的，出错还能补救，但这两栏出了差错，那年收成的一半就会没了。2月育苗失败，整个作期就没了；8月错过修剪，9月和10月的秋茄就没了。

&nbsp;&nbsp;&nbsp;10月和11月的工作也不轻。在降霜前把剩下的果实全部收起来晒干，决定了冬天的菜量；烧掉病株、只把健全的部分归还堆肥，决定了来年病害的密度。茄子是种下的那一刻不如收尾的那一刻更能拉开差距的作物。
