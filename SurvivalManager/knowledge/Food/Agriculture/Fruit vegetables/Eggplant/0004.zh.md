## 4. 品种

### 4-1. 主要品种比较

| 品种 | 形态 | 熟期 | 产量 | 栽培难度 | 适宜环境 | 特点 |
|---|---|:---:|:---:|:---:|---|---|
| Sinheuksanho | 长条形长果 | 早熟 | 多 | 容易 | 露地·避雨栽培兼用 | 坐果良好，前期产量稳定 |
| Heukjinju | 长条形长果 | 早熟 | 多 | 容易 | 露地·避雨栽培兼用 | 是韩国国内使用最广泛的品系 |
| Cheonhadaejang | 细长形长果（36-41cm） | 中熟 | 多 | 一般 | 高温干燥期 | 果皮薄，有光泽，呈深黑紫色 |
| Soeppulgaji | 粗短形长果 | 中晚熟 | 一般 | 容易 | 露地 | 果皮厚，较耐低温 |
| Garakjanggaji | 细长形长果 | 中熟 | 一般 | 一般 | 露地 | 果肉柔软，烹饪时间短 |
| Paengpaengigaji | 圆胖形短果 | 中熟 | 一般 | 容易 | 适应低温 | 果皮坚实，采收后耐放 |
| 传统Joseon-gaji | 短粗形长果 | 中熟 | 少 | 容易 | 韩国全国 | 可以留种延续种植，香气浓郁 |

### 4-2. 按情况选择的标准

| 情况 | 选择 | 理由 |
|---|---|---|
| 灾害初期，尽快收获 | Sinheuksanho、Heukjinju | 属早熟品种，初次采收早，坐果稳定 |
| 计划留种延续种植 | 传统Joseon-gaji品系 | 属于固定品种，留种性状第二年依然保持 |
| 凉爽地区·夏季短 | Soeppulgaji、Paengpaengigaji | 在低温下相对不容易停止生长 |
| 计划晒干贮藏 | 果皮薄的长条形长果品系 | 容易切薄片，干燥均匀 |
| 狭小土地只种几株 | Sinheuksanho | 每株产量多，管理容易 |

&nbsp;&nbsp;&nbsp;在灾害应对中，选择品种的关键不是产量，而是种子的性状。市面上出售的商业品种大多是一代杂交种（F1）。一代杂交种在第一年长势整齐、产量高，但用那批果实留下的种子在第二年播种，性状就会分化。大的小的、长的圆的混杂出现，产量也随之下降。在种子供应中断的情况下，这一特性是致命的。

> **茄子的自家留种等级为S，是因为其植物特性是自花授粉，并不意味着市面上所有品种都能留种使用。从一代杂交种上留下的种子，无论是否自花授粉，第二年都会发生性状分化。**

&nbsp;&nbsp;&nbsp;因此，若要着眼于多年后的情况，确保拥有一个固定品种才是实质性的准备。传统Joseon-gaji以及地方上长期延续的品系都属于这一类。产量比不上商业品种，但留下的种子第二年依然能长出同样的茄子。商业品种的高产量，只在种子供应链维持运转时才成立，一旦供应链中断，就只在第一年有效。

&nbsp;&nbsp;&nbsp;关于抗性，有必要坦率地说明。茄子里实际上不存在对青枯病完全免疫的品种。商业栽培中通常靠嫁接抗病砧木来规避这个问题，代表性的砧木是托鲁巴姆（Solanum torvum）和抗病茄子品系。嫁接需要锋利的刀具、固定夹，以及能让接口愈合的高温高湿环境，在灾害情况下并不容易做到。如果无法嫁接，就只能依靠轮作和田间卫生而非抗性来应对，这正是第9节和第11节的内容。

## 5. 整地与施肥

### 5-1. 整地

| 项目 | 标准 | 理由 |
|---|---|---|
| 耕作深度 | 25-30cm | 加厚表土，为浅根性根系提供扩展的土层 |
| 垄高 | 20cm以上 | 防止梅雨季根系缺氧 |
| 排水沟 | 地块边缘和垄的两端 | 一旦积水疫病就会大爆发 |
| 施石灰 | 定植前2-3周 | 与堆肥同时施用会导致氮素挥发流失 |
| 施堆肥 | 定植前1-2周 | 只使用腐熟堆肥 |
| 连作核查 | 过去3-5年内是否种过茄科作物 | 是最先要确认的事项 |

&nbsp;&nbsp;&nbsp;石灰和堆肥不能同一天施用，是有化学原因的。石灰呈碱性，在碱性条件下，堆肥中的铵态氮会转化为气态氨挥发到空气中。好不容易积攒的氮就这样变成气味消失了。原则上应先施石灰，间隔2周以上再施堆肥。

### 5-2. 施肥量

| 肥料 | 每1,000㎡ | 每㎡ | 分配 |
|---|:---:|:---:|---|
| 氮（N） | 19.0kg | 约19g | 基肥10.2kg + 追肥8.8kg |
| 磷（P） | 11.2kg | 约11g | 全部作基肥 |
| 钾（K） | 15.0kg | 约15g | 基肥9.0kg + 追肥6.0kg |
| 堆肥 | 1,500-2,000kg | 1.5-2kg | 腐熟堆肥 |

&nbsp;&nbsp;&nbsp;氮、磷、钾合计约为每㎡45g左右。评价表中的施肥等级D正是由这个需求量得出的。与羽衣甘蓝的24g、籽粒苋的14g相比，是两到三倍。而且重要的是，这个量里将近一半要分成追肥分批施入。茄子是要连续结果4个月的作物，养分也必须连续供应4个月。如果只施基肥而不再追加，从7月中旬开始果实就会明显变小。

### 5-3. 基肥与追肥的时期

| 类别 | 时期 | 内容 |
|---|---|---|
| 石灰 | 定植前2-3周 | 调节土壤酸度 |
| 基肥 | 定植前1-2周 | 堆肥全部 + 磷全部 + 氮·钾50-60% |
| 追肥第1次 | 定植后约30天 | 第一批果实坐果前后 |
| 追肥第2次 | 第1次后20-25天 | 进入正式采收期时 |
| 追肥第3次 | 第2次后20-25天 | 与更新修剪同时施用 |
| 追肥第4次 | 第3次后20-25天 | 为秋季收获提供的最后一次供应 |

### 5-4. 不用化肥获得同等施肥量的方法

| 替代资源 | 提供的养分 | 使用方法 | 注意事项 |
|---|---|---|---|
| 充分腐熟的堆肥 | 氮·磷·钾及各种微量元素 | 作基肥，每㎡2-3kg | 未腐熟的堆肥会烧根，还会招来蛴螬 |
| 稀释尿液 | 以氮为主，钾·磷较少 | 用水稀释10-15倍，浇在株间的沟里 | 直接接触叶片会造成灼伤。采收前2周起停止使用 |
| 草木灰 | 钾·钙·磷 | 每㎡一把（50-100g）拌入土中 | 呈碱性，用量过多会使pH升得过高 |
| 骨粉 | 磷·钙 | 作基肥拌入堆肥中施用 | 分解缓慢，只适合作基肥 |
| 麻饼·豆饼 | 氮 | 泡水发酵2-3周后稀释10倍使用 | 生的直接埋入土中会因发酵热伤根 |
| 绿肥 | 氮·有机质 | 割下地边杂草覆盖在垄上 | 种子已成熟的草会扩散杂草 |
| 鱼、贝类下脚料 | 氮·磷·钙 | 埋入堆肥堆中彻底腐熟后使用 | 生的直接埋入田里会被动物刨出来 |

&nbsp;&nbsp;&nbsp;尿液是灾害情况下最可靠、最稳定的氮源。一个成年人一天排出的尿液中含氮约5-7g，一年下来超过2kg。一块20㎡的茄子地所需氮约为400g，也就是说一个人两个月的尿量就够一年的施肥量。刚排出的尿液基本无菌，主要成分是尿素，放置几天后尿素会转化为氨，产生异味并且浓度升高，所以最好收集后立刻稀释使用。

> **尿液氮含量充足，但磷不足。如果只持续施用尿液，会陷入只长叶不结果的状态。必须用草木灰和骨粉同时补充钾和磷，才能达到平衡。**

&nbsp;&nbsp;&nbsp;草木灰是钾的主要来源。阔叶树烧成的灰比针叶树的灰含钾更多，完全烧透成白灰的效果最好。但草木灰是强碱性，在同一处撒得太多会使pH超过8，反而妨碍养分吸收。诀窍是每株周围撒不超过一把，并轻轻拌入土中。下雨会使钾迅速流失，所以分多次撒施效率更高。

&nbsp;&nbsp;&nbsp;判断堆肥腐熟程度的标准是气味、温度和形态。腐熟良好的堆肥有泥土气味，把手插进去也不觉得热，原材料的形状已经看不出来。如果有氨味或内部发热，说明发酵还在进行中，这种状态下施入田里，发酵热和有机酸会伤根。像茄子这样浅根性的作物，受到的损害尤其严重。

## 6. 播种与定植

### 6-1. 时期

| 作业 | 地区 | 时期 | 备注 |
|---|---|---|---|
| 播种（育苗开始） | 韩国中部 | 2月中旬-下旬 | 定植前70-80天 |
| | 韩国南部 | 2月上旬-中旬 | |
| 定植 | 韩国中部 | 5月上旬-中旬 | 晚霜完全结束之后 |
| | 韩国南部 | 4月下旬-5月上旬 | |
| 初次收获 | 韩国全国 | 6月下旬 | 定植后50-70天 |
| 收获结束 | 韩国全国 | 10月中旬-下旬 | 直到初霜 |

&nbsp;&nbsp;&nbsp;决定定植时间的标准不是日历，而是晚霜。必须了解当地最后一次霜冻的时间，如果不清楚，宁可晚种。晚种一周造成的损失只是收获推迟一周，但早种一周若遭遇霜冻，当年的收成就会全部化为乌有。

### 6-2. 育苗—不加温的方法

| 项目 | 标准 |
|---|---|
| 播种前处理 | 用30℃水浸泡10小时后，用湿布包好在25-30℃下催芽 |
| 播种深度 | 0.5-1cm |
| 发芽温度 | 25-30℃，3-5天 |
| 育苗温度 | 白天22-30℃，夜间15℃以上 |
| 分苗 | 真叶3-4片时（播种后35-40天）进行一次 |
| 育苗期 | 70-80天 |
| 定植适期的秧苗 | 真叶5-7片，第一个花蕾出现前后 |
| 炼苗 | 定植前1周开始，白天放到室外，使其适应外部环境 |

&nbsp;&nbsp;&nbsp;在2月下旬营造出25-30℃的发芽温度，是这种作物最大的关卡。在没有电力的前提下，可用的方法大致有三种。

| 方法 | 原理 | 可获得的温度 | 局限 |
|---|---|---|---|
| 酿热温床 | 把马粪、稻草、稻壳与水混合后踩实填入，微生物分解会产生热量 | 床面维持20-30℃达3-6周 | 收集材料和踩踏压实的劳动量很大 |
| 室内朝南窗边 | 白天透过玻璃照入的阳光会加热土壤和水 | 白天25-30℃，夜间15-18℃ | 关键在于保证夜间温度 |
| 水桶蓄热 | 把黑色水桶放在育苗箱旁，白天蓄热，夜间释放 | 可使夜间温度提高3-5℃ | 属于辅助手段 |

&nbsp;&nbsp;&nbsp;酿热温床是电力普及之前实际使用的方法。挖50-60cm深的坑，把马粪或稻草用水浸湿后分层踩实填入，上面再覆盖10cm厚的床土。过几天微生物分解开始，床面温度上升，热量能持续3-6周。夜间盖上草帘保温。没有马粪的话，可以用稻草、米糠和尿液混合引发类似的发酵，但升温幅度较小、持续时间也较短。

> **如果育苗有困难，还有推迟播种时间这个选项。4月初播种、6月中旬定植的话，首次收获会推迟到8月，但可以不加温、仅靠露地气温育苗。代价是收获期缩短到两个月左右，但能避免颗粒无收的局面。**

### 6-3. 定植

| 项目 | 标准 | 备注 |
|---|---|---|
| 定植深度 | 浅植，让育苗土略微露出 | 种得太深茎会腐烂 |
| 单行栽培 | 垄距80-90cm，株距45-50cm | 每㎡2.2-2.8株 |
| 双行栽培 | 垄距150cm，株距45-50cm | 为通风考虑，行距保持60cm以上 |
| 定植方法 | 先往定植穴中充分浇水，待水渗下后再放入秧苗 | 能加快缓苗 |
| 支柱 | 定植的同时立起1.5m的支柱 | 之后再立会切断根系 |
| 定植时间 | 阴天的下午 | 晴天正午定植会导致严重萎蔫 |

&nbsp;&nbsp;&nbsp;株距45-50cm看起来很宽，但对茄子来说是必要的间距。由于在bangadari处不断分杈的结构，一株最终会扩展到接近1m的直径，密植会使内部变暗、通风受阻。通风一旦受阻，叶霉病和灰霉病就会趁虚而入，果实也因照不到光而发不出颜色。在狭小土地上多种所获得的好处，比不上因病害造成的损失。

&nbsp;&nbsp;&nbsp;支柱之所以要在定植的同时立起，是因为根系的缘故。如果一个月后再打入支柱，会切断已经扩展开的细根，病菌就会从切口处的青枯病菌侵入。支柱只需粗2cm左右、长1.5m的木棍或竹竿即可，灾害情况下可以砍下田边笔直的树枝晾干使用。评价表中的设施负担C，指的就是每年都要重新准备这些支柱和绑绳的负担。

## 7. 水分管理

&nbsp;&nbsp;&nbsp;茄子果实的92%是水分。这一句话就说明了水分管理的全部内容。人们收获的实际上就是水，水一不够，就没有可收的东西。这就是总蒸散量在每个生长期高达750mm的原因，也是评价表中耗水量停留在C的原因。

| 时期 | 水分管理 | 理由 |
|---|---|---|
| 定植后至缓苗 | 定植穴充分浇水，此后3-4天内保持不干 | 新根长出前吸水能力较弱 |
| 缓苗后至开花前 | 每隔4-5天，在表土变干时浇水 | 这一时期保持稍干燥能促使根系深扎 |
| 开花·坐果期 | 每隔2-3天，充分浇水 | 水分不足会导致花和幼果脱落 |
| 膨大·采收期 | 每隔2-3天，充分浇水 | 果实重量的大部分就是这时吸收的水分 |
| 梅雨季 | 停止灌溉，检查排水沟 | 根系缺氧正是疫病的开端 |
| 更新修剪后 | 充分浇水 | 新根与新芽会同时长出 |

### 7-1. 缺水时出现的表现

| 顺序 | 症状 | 说明 |
|---|---|---|
| 1 | 花和豆粒大小的幼果开始脱落 | 是最先出现的信号，此时损失已经开始 |
| 2 | 短柱花（雌蕊短的花）比例增加 | 即使开花也无法授粉而脱落 |
| 3 | 果实停止在细而短的状态，果皮变硬 | 是细胞无法靠水分膨大的结果 |
| 4 | 叶片白天萎蔫，傍晚恢复 | 仍处于可恢复的阶段 |
| 5 | 叶片到傍晚也不恢复，从下部叶片开始发黄脱落 | 这个阶段即使浇水，那一周也不会有收成 |

&nbsp;&nbsp;&nbsp;需要留意这个顺序。叶片萎蔫是第4个信号，此时花早已脱落。这说明人容易注意到的信号反而来得最晚。所以在茄子地里要看的是土，而不是叶子。把手指插入5cm，如果感觉不到那种凉爽湿润的触感，就是该浇水的时候了。

### 7-2. 缺水时可用的方法

| 方法 | 原理 | 效果 |
|---|---|---|
| 稻草·杂草覆盖 | 覆盖土壤表面以阻止水分蒸发 | 可将灌溉间隔延长1.5-2倍 |
| 株周渗水容器 | 把底部打孔的瓶子或竹筒插入土中并注满水 | 水会缓慢渗入根层，减少损耗 |
| 傍晚灌溉 | 在日落之后浇水 | 比白天灌溉大幅减少蒸发损失 |
| 沟灌 | 只把水引入垄间的沟里 | 水不接触叶片，可减少病害扩散 |
| 洗碗水·淘米水再利用 | 收集油污和洗涤剂较少的水加以利用 | 同时能补充有机质 |

> **向叶片喷水是茄子最糟糕的灌溉方式。叶片带水过夜，会给叶霉病和灰霉病的孢子创造出容易萌发的条件。浇水永远浇在土里。**

&nbsp;&nbsp;&nbsp;覆盖在灾害情况下重要的是不用塑料薄膜的方法。稻草、麦秸、割下晒干的杂草、落叶、稻壳都可以使用。厚度以5-10cm为宜，太薄没有效果，太厚会使土壤变凉，导致前期生长延迟。不要定植后立刻覆盖，最好等到土壤已经充分回暖的6月初再覆盖。稻草覆盖除了能阻止水分蒸发之外，还能防止雨滴飞溅把土中的病原菌带到下部叶片上，秋天直接翻耕入土还能变成有机质。
