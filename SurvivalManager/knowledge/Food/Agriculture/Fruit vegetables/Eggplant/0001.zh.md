## 引言
&nbsp;&nbsp;&nbsp;茄子（Solanum melongena）是茄科茄属的一年生果菜。原产于从印度东部到缅甸的亚热带地区，所以喜热、怕冷、耗水量大，一次霜冻整块地就完了。评价表的综合等级是E（31.7分）。每100g只有19kcal，每1,000㎡收获3,500kg，单位面积热量也只有自给线的0.25倍，要靠茄子一样东西吃够每天2,100kcal，得吃11kg。不过副食等级是A（50.2分）。低热量把蛋白质密度推到了S。产量稳定性也是S（年际变动率5.7%），所以十字花科叶菜会烂掉的高温高湿盛夏，正是茄子的主场。弱点是温度（耐寒性E，育苗70-80天）、连作障碍（需休耕5-7年）和耐储性（果实92%是水）。茄子不是田里的主角，而是在田边立上五六株，夏天摘着吃，吃不完的切片晒干留到冬天的作物。

## 2. 植物概述
&nbsp;&nbsp;&nbsp;茄科茄属的多年生草本，但在温带无法越冬，作一年生栽培。与番茄、辣椒、马铃薯共有病虫害。茎直立，高60-120cm，在某一节分成两杈的第一个分枝点叫第一分杈点。须根集中在30cm以内的表土，属浅根性，怕干旱。花淡紫色星形，以自花授粉为主。果实是浆果，果皮以黑紫色为基本色。

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 育苗期 | 播种到定植70-80天 | 真叶5-7片，第一个花蕾出现时是定植适期 |
| 缓苗·营养生长期 | 定植后1-5周 | 缓苗期间看上去不长是正常的。之后茎变粗，形成第一分杈点 |
| 开花·坐果期 | 定植后40-50天 | 第一分杈点开出第一朵花 |
| 膨大·收获期 | 开花后10-20天起至霜降 | 果实摘掉后，下一朵花马上接上 |
| 衰退·更新期 | 7月下旬至8月上旬 | 高温和连续坐果使长势下降。用更新修剪接上9-10月的收获 |

> **茄子要摘才会结。果实留在上面，这棵植株就会把全部养分用来做种子，不再开新花。**

| 每100g营养 | 含量 |
|:---|:---|
| 热量 | 19kcal（水分92g） |
| 蛋白质 | 1.13g（占热量的23.8%） |
| 碳水化合物 / 膳食纤维 | 5.7-6.0g / 3.0g |
| 矿物质·维生素 | 钾230mg，钙15-20mg，铁0.3-0.4mg，镁14mg，维生素C 2.2mg（不是来源），叶酸22µg |
| 成分 | 茄色苷（果皮的花青素）、绿原酸（切面变褐的原因） |

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽28-30℃（20℃以下很慢），育苗白天22-30℃、夜间15℃以上，生长22-30℃，结实20-30℃。10℃以下停止生长，一次霜冻整株死亡 |
| 光照 | 每天6小时以上（最少4小时）。盛夏直射光加35℃会使果实日灼 |
| 水 | 每茬总蒸散量约750mm。土壤水分为最大持水量的70-80%。干了落花落果，涝了烂根 |
| 土壤 | 有机质丰富的壤土至砂壤土，土层厚30cm以上，pH 6.0-7.0（6.5左右最好，低于5.5则磷和钙吸收不良）。怕盐 |

> **干旱时茄子发出的第一个信号不在叶子，而在花。叶子萎蔫之前，花和豆粒大的幼果就已经掉了。等叶子耷拉下来再浇水，那一周的收成已经没了。**

| 品种 | 特点 |
|:---|:---|
| Shinheuksanho、Heukjinju | 长浆果早熟种。坐果好，前期产量稳定。露地·避雨兼用 |
| Cheonhadaejang | 细长浆果（36-41cm）中熟。皮薄，光泽深。适合高温干燥期 |
| Soebbulgaji、Paengpaengi茄 | 粗短浆果。皮厚，相对耐低温，Paengpaengi采后耐放 |
| 传统朝鲜茄 | 短而饱满的浆果。产量低，但是固定种，可留种续种，香味浓 |

&nbsp;&nbsp;&nbsp;想早收用Shinheuksanho和Heukjinju，凉爽地区用Soebbulgaji和Paengpaengi茄，打算晒干储存就选皮薄的长浆果系统。自留种等级S只是说茄子是自花授粉，从一代杂种上留的种子第二年会分离，所以如果考虑多年，要保留一个像传统朝鲜茄这样的固定种。

## 4. 田地准备、播种与定植
| 项目 | 标准 |
|:---|:---|
| 整地 | 翻耕25-30cm深，垄高20cm以上，田边和垄端开排水沟（积水则疫病暴发）。石灰在定植前2-3周，与堆肥同时施入会损失氮 |
| 施肥（每1,000㎡） | 腐熟堆肥1,500-2,000kg，氮19.0kg（基肥10.2kg + 追肥8.8kg），磷11.2kg（全部作基肥），钾15.0kg（基肥9.0kg + 追肥6.0kg） |
| 追肥 | 定植后约30天开始，每隔20-25天一次，共4次（第3次与更新修剪同时） |
| 替代资源 | 腐熟堆肥每㎡ 2-3kg，稀释10-15倍的尿液（浇进垄沟，收获前2周停止），草木灰每㎡一把，骨粉，发酵油饼的10倍稀释液，草覆盖 |

> **尿液氮多而磷不足。只一直浇尿，就只长叶子不结果。要用草木灰和骨粉同时补钾和磷，才能保持平衡。**

| 作业 | 时期 |
|:---|:---|
| 播种（开始育苗） | 中部2月中旬至下旬，南部2月上旬至中旬 |
| 定植 | 中部5月上旬至中旬（晚霜完全结束后），南部4月下旬 |
| 首次收获 | 定植后50-70天，6月下旬。收获到初霜，即10月中旬至下旬结束 |

| 育苗与定植 | 标准 |
|:---|:---|
| 育苗 | 25-30℃下3-5天发芽。定植前1周起白天放到外面炼苗。不加温时用酿热温床（马粪·稻草·稻壳踩实，20-30℃可维持3-6周）、朝南窗边、黑色水桶蓄热（夜间升温3-5℃） |
| 育苗困难时 | 4月初播种，6月中旬定植。首次收获推迟到8月，收获期缩短到两个多月，但不至于让这一年的农事完全落空 |
| 定植 | 栽得浅，让苗土稍微露出来（栽深了茎会烂）。单行种植垄距80-90cm，株距45-50cm（每㎡ 2.2-2.8株），双行种植垄距150cm，行距60cm以上。选阴天下午栽，定植的同时立支柱 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 定植后至缓苗 | 往穴里浇透，3-4天内不让干 |
| 缓苗后至开花前 | 表土干了再浇，间隔4-5天。稍干一点，根会扎得深 |
| 开花·坐果期、膨大·收获期 | 每2-3天一次，浇足（果实重量的大部分是这时吸进的水） |
| 梅雨季 | 停止灌溉，检查排水沟 |
| 更新修剪后 | 浇足 |

&nbsp;&nbsp;&nbsp;缺水时，花和幼果先脱落，果实变细变硬，白天耷拉的叶子到傍晚也不恢复的话，那一周就没有收成。水贵重时，用稻草或草覆盖（浇水间隔延长1.5-2倍）、把底部扎孔的瓶子插进土里滴灌、傍晚浇水、沟灌、重复利用洗碗水和淘米水。不往叶子上浇水，始终浇在土上。

| 管理 | 内容 |
|:---|:---|
| 整枝 | 第一分杈点以下长出的侧芽全部用手掰掉。在第一分杈点分出的2条茎上，再加正下方最壮的1个侧芽，共留3条茎，只疏掉向内交叉的茎。收获开始后，依次摘掉离地30cm以内的叶子 |
| 操作要领 | 选晴天上午，尽量用手。用刀的话，每株都用火烧一下或浸入开水（青枯病和病毒会顺着刀刃传播） |
| 摘叶 | 养一个果实大约需要三片叶子。一次摘掉的叶子不超过全部叶子的20% |
| 引缚 | 单线引缚（简单但茎下垂）、双线引缚（两侧支柱上分两层拉绳）、X形引缚（1.8m支柱交叉立起） |
| 更新修剪 | 7月下旬至8月上旬长势衰退时，各主茎自下留两三节剪掉，在离植株25-30cm处用铁锹插入20cm深切断老根（断根）。施入堆肥和稀释的尿液，浇足水，2-3周后长出新芽，9月中旬起再次结果 |

> **秋茄子好吃，是一个生理上的事实。气温下降，果实长得慢，长得慢的果实细胞致密，肉嫩籽少。更新修剪就是为了得到这样的秋茄子所做的准备。**

## 6. 病虫害与养分问题
| 病害 | 症状与条件 | 不用药的应对 |
|:---|:---|:---|
| 青枯病 | 中午突然萎蔫、早晨又恢复，反复几天后死亡。切开茎会流出白色细菌黏液。高温高湿，土传 | 无药可治。发现后立即连根拔出烧掉，把那里的土也挖走。轮作5-7年 |
| 疫病 | 贴地的茎基部缢缩成暗褐色，植株急剧萎蔫。过湿、梅雨 | 高垄和排水沟是唯一的对策。预防性喷波尔多液 |
| 黄萎病、病毒病 | 叶子一半发黄萎蔫。叶片花叶、果实畸形（蚜虫·蓟马传播） | 无法治疗。拔除病株、长期轮作、防治传毒昆虫 |
| 灰霉病、叶霉病、白粉病 | 灰色霉层、叶背灰褐色霉层、白粉 | 抖掉谢花、保证通风、整理下部叶子、不过量施氮、牛奶（1份牛奶配1-2份水）或小苏打稀释液 |

> **青枯病的植株留在田里或放进堆肥堆，细菌会扩散到整块田。要拔出来烧掉，或运到远处深埋，拔过的手和工具一定要洗。**

&nbsp;&nbsp;&nbsp;害虫有蚜虫（肥皂水、保护瓢虫）、二斑叶螨（用力向叶背喷水）、蓟马（粘虫板、稻草覆盖）、烟青虫（摘除并销毁有孔的果实，用手捉幼虫）、蝽（清晨人工捕捉）。防治材料有波尔多液（硫酸铜1kg和生石灰1kg分别溶解冷却后合并，加水至100L，预防剂）、肥皂水（无香肥皂20g加水1L）、草木灰、稀释300-500倍的木醋液、烟叶或辣椒浸出液。病残体要烧掉，不栽病苗。

| 症状 | 原因与处理 |
|:---|:---|
| 从下部叶子开始发黄，植株矮小 | 缺氮。稀释10-15倍的尿液、腐熟堆肥 |
| 叶缘焦枯，果实小 | 缺钾。草木灰 |
| 叶背和茎发紫 | 缺磷（低温期土壤冷也可能吸收不了）。骨粉、草木灰 |
| 花多但直接掉落 | 缺硼或高温胁迫。堆肥原料多样化、遮阴 |
| 叶脉间发黄，叶脉仍绿 | 缺镁。白云石粉 |
| 新叶小而畸形，生长点枯死 | 看似缺钙，但多半是缺水。先检查水分，再用烧过的贝壳粉 |
| 只长叶子，深绿色，花少 | 氮过多（茄子最常见）。停止施氮，用草木灰补钾 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 豆科（菜豆、豇豆、豌豆）、万寿菊（抑制根结线虫）、罗勒·紫苏（浓烈的气味扰乱蚜虫和蓟马）、葱·蒜 |
| 差 | 番茄·辣椒·马铃薯（完全共有病虫害，连邻着种也要避免）、南瓜（藤蔓妨碍通风） |

&nbsp;&nbsp;&nbsp;第1年茄子，第2年豆科，第3年叶菜或葱属，第4年谷物或根菜，第5年豆科或绿肥，第6年以后再回到茄子。地小的话，把田分成6块，每年挪一块，或把病重处的土挖走30cm换上新土。

> **茄子在同一个地方连种3年以上，常常前两年好好的，第三年突然一半萎蔫死掉。轮作不是在病出现之后才做，而是在病出现之前做。**

## 8. 收获与留种
| 项目 | 标准 |
|:---|:---|
| 适期 | 开花后10-20天（气温高则短）。长浆果型长度15-20cm左右，但看状态而不是长度。果皮有光泽、按压有弹性时，光泽没了就已经晚了 |
| 要领 | 第一个果实趁鸡蛋大小时早摘，先让植株长大。每周2-3次，清晨用剪刀或刀在果蒂上方剪下（拧会撕裂茎），留3-5mm果蒂 |
| 采后 | 吃之前再洗。10-12℃最好，5℃以下会因冷害使果皮凹陷。只留当天要吃的，其余立即切片晒干 |

| 留种 | 标准 |
|:---|:---|
| 隔离·株数 | 与其他茄子品种隔开30-50m。留种株至少3-5棵（遗传幅度）。一个果实有数百到1,000多粒种子 |
| 果实 | 7月下旬至8月在植株下部、长势好时结的果实中选取，用绳子标记。放到果皮变黄褐色、光泽消失（开花后60-70天），再在阴凉处后熟1-2周。霜前刚结的果实种子不成熟 |
| 分离·干燥 | 剖开果实，泡水搓出种子，只用沉底的。摊在布上在阴凉处晾1-2周（不直接曝晒）。掰时啪地折断就完成 |
| 保管 | 与干燥剂（炒过放凉的米、木炭、干草木灰、烧过放凉的盐）一起密封在玻璃瓶或金属桶里，放在阴凉黑暗处。常温密封可存3-4年。每年取20粒放在湿布上，一周后确认发芽率 |
| 消毒 | 50-55℃的水泡10-15分钟后立即用冷水降温，丢掉浮起的，裹草木灰 |

## 9. 储存与干燥
| 方法 | 内容 | 期限 |
|:---|:---|:---|
| 鲜品 | 不洗，用报纸包好，放在10-15℃的阴凉处 | 5-7天 |
| 干燥（茄干） | 切薄片，在阳光和风中完全晒干。体积和重量降到十分之一，最实用 | 6个月至1年 |
| 盐渍 | 盐10-15%。吃前用水泡去咸味 | 数月 |
| 酱腌 | 腌进酱油、大酱、辣酱 | 数月至1年 |
| 乳酸发酵 | 盐2-3%腌制，让果实沉在汤汁下。容易变软，较难 | 数周至数月 |

&nbsp;&nbsp;&nbsp;做茄干时，把无伤的果实洗净并彻底擦干水分，切成5-7mm厚的圆片，或纵向切成四瓣。在筐或帘子上摊成不重叠的一层，在阳光充足、通风的地方晒2-4天，晚上收进来避开露水。晒到用手掰时啪地折断为止（稍软就会发霉），与干燥剂一起装进密闭容器，放在阴暗凉爽处。每月打开检查一次，受潮了就在太阳下再晒半天。梅雨季或无日照的日子，在火上烘干。

> **干燥的成败在第一天就分晓了。在阴天湿天开始摊晒，第三天就会长出黑霉，只能全部丢掉。要选晴朗有风的日子开始。**

## 10. 烹调与注意事项
| 烹调 | 燃料与要领 |
|:---|:---|
| 蒸 | 10分钟以内。会浮起来，要用盘子压住才能均匀熟透。不用油，最经济 |
| 炒 | 很吸油，味道变好，但耗油多 |
| 烤 | 在炭火中整个烤熟后剥皮。利用余火 |
| 汤·炖菜 | 与其他烹调同时进行 |
| 茄干 | 用水泡20-30分钟，可恢复到原体积的近一半。炒或凉拌。不去皮 |
| 生吃 | 不建议（涩，还残留生物碱） |

> **油贵重的话，茄子蒸着吃才对。把蒸好的茄子撕开，用酱油或大酱、蒜、芝麻盐拌，燃料只要10分钟，油只要几滴。**

| 注意 | 内容 |
|:---|:---|
| 茄碱·茄边碱 | 茄科的防御物质。吃多了会胃肠刺激和恶心。不吃苦味重的果实（太嫩的果实、错过收获期变黄的果实、在严重缺水下长成的果实中较多）。加热可减少一部分 |
| 叶和茎 | 生物碱含量高得多，不要吃，拿去做堆肥 |
| 绿原酸 | 无毒，是涩味和变褐的原因。切开后泡在水或淡盐水里 |
| 其他 | 有人可能出现发痒或荨麻疹，初次食用要从少量开始 |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查种子和发芽率、收集温床材料、播种（中部中旬至下旬，南部上旬至中旬）并开始温床发热 |
| 4月 | 基肥和堆肥、起垄、炼苗。南部下旬定植 |
| 5月 | 中部上旬至中旬定植并立支柱，去掉第一分杈点以下的侧芽 |
| 6月 | 趁幼小摘掉第一个果实、第1次追肥、稻草覆盖、下旬起首次收获 |
| 7月 | 每周收获2-3次、第2次追肥、检查梅雨季排水、下旬起准备更新修剪 |
| 8月 | 上旬更新修剪和断根、第3次追肥、开始晒干 |
| 9月 | 从新芽收获秋茄子、第4次追肥、留种果完全成熟 |
| 10-11月 | 收尾收获并把剩下的果实全部切片晒干、留种果后熟、拔掉植株，病株烧掉，健康的茎做堆肥、挑选种子 |
| 12月 | 检查明年的轮作计划和茄干的状态 |

> **不能忘记的五件事：晚霜后定植、持续供水、要摘才会结果、第一天决定成败的干燥、茄科休耕5-7年。**
