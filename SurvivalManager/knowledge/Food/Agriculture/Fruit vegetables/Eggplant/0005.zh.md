## 8. 栽培管理—抹芽与更新修剪

### 8-1. 整枝—为什么整理成三条主枝

&nbsp;&nbsp;&nbsp;茄子在bangadari处分成两杈，分开的茎又会再分成两杈。若放任不管，会增加到4杈、8杈、16杈。茎越多叶也越多，光合作用总量虽会增加，但分到每个果实的养分却在减少。结果就是结出一大堆又小、种子又早熟的果实。而且株内会变得拥挤，光线和风都进不去。

| 阶段 | 内容 |
|---|---|
| 1. 确认bangadari | 找到第一朵花开放处茎分成两杈的位置 |
| 2. 清除下方侧芽 | bangadari以下长出的侧芽全部用手掰掉 |
| 3. 选定主枝 | 在bangadari分出的2条茎基础上，加上bangadari正下方最健壮的1个侧芽，培养成三条主枝 |
| 4. 后续管理 | 这三条主枝上再分出的枝条可以保留，只疏掉向内生长互相重叠的枝条 |
| 5. 整理下部叶片 | 距地面30cm以内的叶片，从开始采收起依次摘除 |

&nbsp;&nbsp;&nbsp;清除bangadari以下的侧芽尤其重要。这些侧芽几乎不开花，却只消耗养分，而且会在近地面处疯长，阻碍通风。贴近地面的叶片会因雨水飞溅而直接成为病原菌侵入的通道。侧芽在指甲盖大小时用手掰掉，伤口最小。等长粗了再用刀切，伤口反而会成为病害的入口。

| 项目 | 要领 |
|---|---|
| 摘除时间 | 晴天上午 |
| 理由 | 伤口能在当天晾干。雨天摘除的话，细菌会从伤口侵入 |
| 工具 | 尽量用手。如果用刀，每换一株都要在火上烤过或用开水浸泡消毒 |
| 理由 | 青枯病和病毒会通过刀刃从一株传到另一株 |

### 8-2. 三片叶法则

&nbsp;&nbsp;&nbsp;培育好一个茄子果实所需要的叶片大约是三片。果实上方一片、下方两片，通过光合作用供养这个果实。叶片少于这个数量果实会变小，多于这个数量多余的叶片也只会造成遮荫。因此形成了这样一个诀窍：采收时把那个果实下方的两三片叶子一并摘除。这些叶子已经完成了它们的使命，现在只是遮挡新果实的障碍物。

> **给茄子摘叶不是伤害植株，而是改变养分的流向。不过一次摘得太多会让光合作用能力本身崩溃，因此一次摘除量不应超过全部叶片的20%。**

### 8-3. 引缚

| 方法 | 内容 | 特点 |
|---|---|---|
| 单杆引缚 | 每株立一根支柱，绑住主枝 | 最简单，但横向伸展的枝条会下垂 |
| 双线引缚 | 在垄两侧立支柱，拉两层绳把植株夹在中间 | 让枝条张开，通风变好 |
| X形引缚 | 交叉立起两根1.8m的支柱，在交点处架横杆 | 通风和支撑都好，枝条也能展开 |

&nbsp;&nbsp;&nbsp;引缚的目的不只是防止倒伏。更大的目的是把茎向外撑开，让光线和风能进入株丛内部。果实开始结出后，一株的重量会大幅增加，夏季的雷阵雨和台风会把茎撕裂。裂开的地方就成了病害的入口。绑缚时应把茎绕成8字形系在支柱上，避免勒紧茎干，并考虑到茎会随生长变粗而留出余量。绑绳可以用稻草搓成的绳子、葛藤、构树皮之类的东西来代替。

### 8-4. 更新修剪—获得秋茄的原理

&nbsp;&nbsp;&nbsp;到了7月下旬至8月上旬，茄子的长势会明显下降。原因有两个。一是超过35℃的高温使花粉失去活力、无法完成授粉；二是连续两个月不间断结果，导致根和茎都已消耗殆尽。这个时期如果放任不管，就会以只长叶不结果的状态迎来秋天。

| 阶段 | 内容 |
|---|---|
| 时期 | 7月下旬-8月上旬，梅雨结束、长势转弱之时 |
| 剪枝 | 每条主枝从下部只留2-3个节，其余剪掉。切口下方必须留有芽 |
| 断根 | 在距植株25-30cm处，用铁锹插入20cm深，切断老根 |
| 追肥 | 在切断处施入堆肥和稀释尿液，然后覆土 |
| 灌溉 | 充分浇水。此后保持土壤不干 |
| 恢复 | 2-3周后长出新芽并生长，9月中旬起重新开始结果 |

&nbsp;&nbsp;&nbsp;断根听起来可能有些奇怪。故意切断根系的原因是为了促发新根。老根的吸收能力已经下降，而切口处会旺盛地长出新根。由于叶和茎已经剪掉了一半以上，根系要承担的负荷也随之减少。此时施入追肥和水分，植株就会同时长出新茎和新根。这相当于人为地再造一次春天。

> **"秋茄好吃"这句古老的说法，并非情感化的表达，而是生理事实。气温下降后果实会缓慢长大，缓慢长大的果实细胞更致密，果肉柔软，种子也少。更新修剪正是为了获得这种秋茄所做的准备。**

&nbsp;&nbsp;&nbsp;不过更新修剪是有条件的。第一，距离降霜至少要有两个月。在韩国中部若过了8月中旬才修剪，新芽还没结果霜就来了。第二，植株不能已经染病。染上青枯病或黄萎病的植株，剪了也不会恢复，只会直接枯死。第三，要能持续供水供肥。只剪不管的话无法恢复。这三个条件只要有一个不满足，就不如不剪，保持原样。

## 9. 病虫害—不用药的防治方法

### 9-1. 主要病害

| 病名 | 症状 | 发生条件 | 不用药的应对 |
|---|---|---|---|
| 青枯病（cheonggobyeong） | 正午突然萎蔫，早晨又恢复，反复数日后枯死。切开茎部会流出白色细菌黏液 | 高温潮湿，土壤传播 | 没有治疗方法。发现后立即连根拔起烧毁，并清除该处的土壤。轮作5-7年 |
| 疫病 | 贴地的茎基部变成暗褐色并缢缩，植株迅速萎蔫 | 过湿、排水不良、梅雨季 | 高垄和排水沟是唯一的对策。预防性喷施波尔多液 |
| 黄萎病 | 叶片只有一侧半边发黄并萎蔫 | 低温潮湿，土壤传播 | 没有治疗方法。清除病株并长期轮作 |
| 灰霉病 | 花朵或伤口上长出灰色霉层，果实变软腐烂 | 低温潮湿，通风不良 | 摘除凋谢的花朵，保持通风 |
| 叶霉病 | 叶片背面出现灰褐色霉层，正面发黄 | 潮湿、通风不良、氮肥过量 | 整理下部叶片，禁止过量施氮 |
| 白粉病 | 叶片表面覆盖白色粉状物 | 干燥与高湿交替出现时 | 水与牛奶按1比1-2稀释的溶液，或小苏打稀释液 |
| 病毒病 | 叶片出现斑驳并卷缩，果实畸形 | 由蚜虫、蓟马传播 | 无法治疗。防治传毒害虫并清除病株 |

&nbsp;&nbsp;&nbsp;青枯病需要单独理解。病因是一种叫Ralstonia solanacearum的细菌，这种细菌能在土壤中存活多年。它从根部的伤口侵入，堵塞导管，导管一堵塞植株就无法输水而萎蔫。正午萎蔫、早晨恢复、如此反复数日的特有症状正是由此而来。由于它是细菌病而非真菌病，波尔多液这类预防剂效果不佳，一旦侵入体内就没有挽回的办法。

> **拔除染上青枯病的植株后，如果直接留在田里或扔进堆肥堆，病菌就会扩散到整块田地。应该拔起后烧毁，或深埋在远离田地的地方。拔过病株的手和工具务必清洗。**

&nbsp;&nbsp;&nbsp;评价表中的防治自立度C反映的正是这种情况。即使有农药，对青枯病和黄萎病也无药可用；而没有农药，其余病害造成的损失也会加大。无防治减产率估计为49.8%，也就是说，如果完全不防治，就会损失一半——这个数字必须原样接受。不用农药种茄子，意味着要以损失一半为前提来种植，因此只有种下所需数量的两倍，账才算得上。

### 9-2. 主要害虫

| 害虫 | 危害 | 不用药的应对 |
|---|---|---|
| 蚜虫 | 附着在叶背和新梢上吸食汁液，并传播病毒 | 喷施肥皂水，用手搓碎，保护瓢虫和草蛉 |
| 叶螨 | 附着在叶背吸食汁液，叶片变白并出现蛛网状物 | 用力向叶背喷水。干燥时容易大量爆发，应增加灌溉 |
| 蓟马 | 附着在花朵和幼果上造成伤痕，并传播病毒 | 使用黄色·蓝色黏虫板，用稻草覆盖阻断蛹的移动 |
| 烟青虫 | 幼虫钻入果实内部啃食 | 摘除有虫孔的果实并处理掉。幼虫用手捉除 |
| 蝽象 | 吸食果实汁液，导致该处变硬并畸形 | 趁清晨活动迟缓时用手捉除 |
| 跳甲 | 在幼苗叶片上咬出小孔 | 定植初期覆盖防虫网 |

### 9-3. 不用农药的防治剂

| 防治剂 | 制作方法 | 用途 | 注意事项 |
|---|---|---|---|
| 波尔多液 | 硫酸铜1kg和生石灰1kg分别单独溶于水中冷却后混合，加水配成100L | 预防疫病、细菌性斑点病 | 是预防剂而非治疗剂。高温期使用浓度过高会灼伤叶片 |
| 肥皂水 | 将20g无香精无添加剂的肥皂溶于1L水中 | 蚜虫、叶螨 | 只有喷到叶背才有效。正午喷洒会灼伤叶片 |
| 稀释牛奶液 | 牛奶与水按1比1到1比2混合 | 白粉病 | 干燥过程中会以物理方式压住霉菌菌丝 |
| 草木灰 | 把过筛的灰轻轻撒在叶片和土壤上 | 驱避害虫，补充钾 | 下雨会被冲刷掉 |
| 木醋液 | 将烧炭时产生的烟冷却收集所得的液体稀释300-500倍 | 驱避，激活微生物 | 原液呈强酸性，务必稀释后使用 |
| 烟叶·辣椒浸泡液 | 切碎后泡水一天，过滤后使用 | 驱避软体害虫 | 对人也有刺激性。采收前不要使用 |

### 9-4. 农业防治—通过种植方式防治的方法

| 方法 | 原理 |
|---|---|
| 轮作 | 每隔5-7年轮换种植茄科作物，降低土传病害的密度。是最可靠的对策 |
| 高垄 | 防止根层积水，减少疫病和烂根 |
| 加大种植间距 | 保证通风，从根本上消除霉菌病害的发生条件 |
| 稻草覆盖 | 防止雨滴飞溅把土中的病原菌带到下部叶片上 |
| 整理下部叶片 | 清除贴近地面的叶片，切断感染途径 |
| 焚烧病株残体 | 留在田里的病株残体会成为第二年的传染源 |
| 健康秧苗 | 育苗阶段发现染病的秧苗不予定植 |
| 工具消毒 | 每换一株，刀具和剪刀都要在火上烤过或用开水浸泡 |

&nbsp;&nbsp;&nbsp;在这八种方法中，实际发挥最大作用的是轮作和排水。其余的都是逐步减少损失的手段，而这两项能从根本上消除病害成立的条件。这意味着在没有农药的条件下种茄子，与其在防治上下功夫，不如在布局安排上多花心思。

## 10. 营养缺乏与过量

| 症状 | 原因 | 用天然材料采取的措施 |
|---|---|---|
| 从下部叶片开始全株发黄，植株瘦小 | 缺氮 | 将尿液稀释10-15倍浇入沟中，或在株周施入腐熟堆肥 |
| 叶缘出现褐色焦枯，果实变小 | 缺钾 | 每株拌入一把草木灰。果皮堆肥中钾含量也较高 |
| 生长迟缓，叶背和茎呈紫色 | 缺磷 | 施入骨粉或草木灰。低温期土壤偏冷，有时也会导致吸收不良 |
| 花开得多却不结果，花朵直接脱落 | 缺硼或高温胁迫 | 使堆肥原料多样化。若是高温所致，用遮光降温 |
| 仅叶脉之间发黄，叶脉本身仍为绿色 | 缺镁 | 施用白云石粉，或使堆肥原料多样化 |
| 新叶细小畸形，生长点枯死 | 缺钙 | 使用烧过磨碎的蛋壳、贝壳粉。多数情况其实是缺水导致钙无法运输 |
| 只有叶片长得又大又茂密，颜色深绿，但花很少 | 氮过量 | 停止供氮，用草木灰补充钾。充分浇水冲洗 |
| 叶缘向内卷曲，生长停滞 | 盐分积累 | 充分浇水冲洗，第二年减少施肥量 |

&nbsp;&nbsp;&nbsp;茄子最常见的问题是氮过量。尿液和堆肥中氮相对较多，而磷和钾较少，如果只持续施用这两样，就会变成叶子茂盛而花少的状态。如果叶片深绿肥厚、茎粗壮却很少开花，几乎可以确定就是这种情况。这时如果再追加氮肥，情况只会更糟。答案是用草木灰和骨粉补充钾和磷，恢复平衡。

> **出现缺钙症状时，土壤中真正缺钙的情况其实很少见。钙是靠水分运输的元素，水一旦不足，即使土壤中钙含量充足，也无法输送到新叶和果实。看似缺钙的症状，大多其实是缺水。**

## 11. 间作与轮作

### 11-1. 相性

| 相性 | 对象 | 理由 |
|:---:|---|---|
| 良好 | 豆科作物（菜豆·豇豆·豌豆） | 根瘤菌固定的氮会留在土壤中 |
| 良好 | 万寿菊 | 根系分泌物能抑制根结线虫 |
| 良好 | 罗勒·紫苏 | 浓烈的香气会扰乱蚜虫和蓟马 |
| 良好 | 葱·蒜 | 硫化物能降低土壤病原菌的密度 |
| 不良 | 番茄·辣椒·马铃薯（茄科） | 会完全共享病虫害。也应避免种在相邻位置 |
| 不良 | 玉米 | 会造成遮荫，养分竞争激烈 |
| 不良 | 南瓜 | 藤蔓覆盖会阻碍通风 |

&nbsp;&nbsp;&nbsp;在茄子间套种豆类的布局，在灾害情况下尤其有价值。茄子喜肥、需氮量大，豆类则靠根瘤自行制造氮。豆类制造的氮当年不会直接供给茄子，但会随豆根腐烂在第二年留在土壤中。而且豆类植株矮，不会遮挡茄子的阳光，还能覆盖地面抑制杂草。不过蔓生豆类会攀附茄子往上爬，所以适合选用矮生型菜豆或豇豆。

### 11-2. 轮作

| 年份 | 作物 | 目的 |
|---|---|---|
| 第1年 | 茄子 | |
| 第2年 | 豆科（大豆·菜豆·豇豆） | 恢复氮素，切断茄科病原菌的寄主 |
| 第3年 | 叶菜类（大白菜·生菜）或葱属（大葱·蒜） | 根系深度不同，能均衡利用各土层 |
| 第4年 | 谷物（玉米·高粱）或根菜类（萝卜·胡萝卜） | 归还有机质，改善土壤结构 |
| 第5年 | 豆科或绿肥 | 恢复地力 |
| 第6年以后 | 重新种植茄子 | |

&nbsp;&nbsp;&nbsp;评价表要求的5-7年休作期，在狭小土地上很难做到。因为田地不足5个地块，这个周期就无法成立。现实中的折中办法有三种。

| 方法 | 内容 | 局限 |
|---|---|---|
| 地块细分÷ | 把田地分成6块，每年轮换一块种植 | 各地块光照和水分条件不同，产量参差不齐 |
| 游动种植 | 每年换不同位置，在地边或屋子周围分散种几株 | 管理分散，收获也不集中 |
| 换土 | 把病害严重处30cm深的土挖走，换填新土 | 劳动量大，且需要有地方获取新土 |

> **在同一地点连续种植茄子3年以上，常常前两年都好好的，第三年却突然一半植株枯死。土壤病原菌是悄悄积累，然后一次性爆发的。轮作不是在病害出现之后才开始的事，而是要在病害出现之前就做好的事。**

&nbsp;&nbsp;&nbsp;考虑茄子之后种什么也很重要。茄子在4个月里带走大量养分，因此接下来种植的作物必须能承受这种消耗。豆科成为首选的原因就在这里，第二候选是即使在贫瘠土地上也能生长的荞麦和高粱。相反，如果紧接着在茄子之后种大白菜或卷心菜这类需肥量大的作物，两种作物的结果都会不理想。拔除茄子后，把茎叶切碎翻入土中，就能成为第二年的有机质，但一定要剔除病株，只使用健康的植株。
