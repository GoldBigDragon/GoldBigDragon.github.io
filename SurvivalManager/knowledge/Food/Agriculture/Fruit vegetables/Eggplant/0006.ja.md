## 12. 収穫 - 摘まないと実が付き続けます

| 区分 | 基準 | 備考 |
|---|---|---|
| 収穫適期 | 開花後10-20日 | 気温が高いと短くなり、低いと長くなります |
| 大きさの基準 | 品種の標準の長さに達したとき(長果型15-20cm) | 品種ごとに異なるため、長さより状態を見ます |
| 状態の基準 | 皮に光沢があり、手で押すと弾力があります | 光沢が消えたらもう遅すぎます |
| 最初の実 | 卵の大きさのときに早めに摘み取ります | 株の体を先に大きくするためです |
| 収穫間隔 | 週2-3回 | 夏は二日で見た目にも大きくなります |
| 収穫時刻 | 早朝 | 夜通し水分を含んで最も新鮮で長持ちします |
| 摘み方 | はさみやナイフで果柄の上を切ります | ねじって摘むと茎が裂けます |

### 12-1. なぜ早く摘まなければならないのか

&nbsp;&nbsp;&nbsp;ナスは熟すと品質が落ちる作物です。人が食べるナスは植物学的には未熟果です。種がまだ熟していない状態の実を食べているのであり、種が熟し始めると果肉がスポンジのようにすかすかになり、皮が硬くなって苦味が出ます。皮の色も黒紫色から黄みがかった色に変わります。黄色くなったナスは熟したのではなく、食べる時期を過ぎたのです。

> **ナスは摘まないと実が付きません。実をそのままにしておくと、その株は種を作ることに全ての養分を注ぎ、新しい花を作りません。畑に古いナスを二、三個放置すると、その株全体の生産が止まります。**

&nbsp;&nbsp;&nbsp;評価表の永続性Bはこの原理の上にあります。霜が降りるまで摘み続けられるということは自然に起きることではなく、まめに摘むことの見返りとして得られる結果です。週に二、三回畑を回って、育ちきったものをすべて摘み取り、虫に食われたものや奇形のものも一緒に摘んで取り除きます。傷んだ実をそのままにしておくと養分だけを持っていき、病気の足場になります。

### 12-2. 最初の実を摘み取る理由

&nbsp;&nbsp;&nbsp;方状分枝に付く最初の実を卵の大きさのときに早めに摘み取るのは古くからの知恵です。植物にとって最初の実は最も優先順位の高い器官で、まだ体が小さい株がその実一つに養分を集中させます。結果として茎と根が育たないまま実一つだけが大きくなり、その後は力がなく実がつきにくくなります。最初の実を早く摘み取ればその養分が茎と根に戻って株が大きくなり、大きくなった株が四か月の間にはるかに多くの実を付けます。目の前の実一つを諦めて全体の収穫を増やす取引です。

### 12-3. 収穫後の処理

| 項目 | 内容 |
|---|---|
| 果柄 | 3-5mm残して切ります。果柄のとげに刺されないよう注意します |
| 洗う | 食べる直前に洗います。前もって洗うと表面の水気が腐敗の始点になります |
| 詰める | 重ねて積むと押された部分が傷みます。一段に広げて置きます |
| 温度 | 10-12℃が最も良いです。それより低いと皮がへこむ低温障害が起きます |
| 以降 | その日食べる分だけ残し、残りはすぐに切って干します |

&nbsp;&nbsp;&nbsp;低温障害はナスの特異な性質です。熱帯出身の作物のため5℃以下の低温に長く置くと細胞が損傷し、皮にへこんだ斑点ができて中が変色します。冷蔵庫があってもナスを冷蔵室の奥深くに入れるのは良い保存法ではなく、冷蔵庫がない条件ではむしろこの問題がありません。涼しい床下や北向きの軒下、10-15℃になる場所が最も適しています。

## 13. 採種 - 自家受粉が与える利点

### 13-1. ナスの採種が容易な理由

&nbsp;&nbsp;&nbsp;ナスの自家採種の等級がSであることには二つの根拠があります。第一に、自家受粉が優勢です。ナスの花は一つの花の中に雌しべと雄しべがあり、花が開く頃に自分の花粉が自分の雌しべの先に落ちて受粉が終わります。他家受粉の比率は条件によって5-20%の間と報告されており、ハチが多い環境で高くなります。ケールが自家不和合性のため必ず他の株の花粉を受けなければならないのとは対照的です。第二に、実一つに種が数百個から千個を超えて入っています。二、三個採種するだけで数年分の種子が得られます。

| 項目 | 基準 |
|---|---|
| 必要な隔離距離 | 他のナス品種と30-50m |
| 採種用の株数 | 最低3-5株 |
| 実一つ当たりの種子 | 数百-1,000粒以上 |
| 種子寿命 | 常温密閉で3-4年 |

&nbsp;&nbsp;&nbsp;採種用の株を3-5株以上置く理由は交雑のためではなく遺伝的な幅のためです。自家受粉作物であっても一つの株からだけ種を取り続けると、世代を重ねるほどその系統の多様性が減り、ある病気がその系統の弱点を突けば全体が一気に崩れます。複数の株から均等に取ることがそうした危険を減らします。

### 13-2. 採種の手順

| 段階 | 時期 | 内容 |
|---|---|---|
| 採種株の選定 | 7月 | 病気がなく勢いが良く、品種の特性がはっきりしている株を選びます |
| 採種果の選定 | 7月下旬-8月 | その株の下のほう、勢いが良いときに付いた実を選びます |
| 目印 | 選定直後 | 紐を結んで目印をつけ、誤って摘む事故を防ぎます |
| 完熟 | 9-10月 | 皮が黄褐色に変わり光沢が消えるまで置きます。開花後60-70日 |
| 後熟 | 収穫後 | 涼しい日陰に1-2週間置くと種がさらに熟します |
| 種子分離 | 後熟後 | 実を割って果肉ごと水に浸し、手でもみながら種を取り出します |
| 沈める | 分離直後 | 水に入れると充実した種は沈み、しいなと果肉は浮きます。浮くものは捨てます |
| 乾燥 | 分離後 | 布の上に広げて日陰で1-2週間乾かします。手で折ったときぱきっと折れれば完了です |
| 保管 | 完全乾燥後 | 密閉容器に乾燥剤とともに入れ、涼しく暗い場所に置きます |

> **採種用の実は必ず下のほう、つまり株が最も力強いときに付いた実から選びます。霜の直前に付いた実の種は熟しきれず発芽率が落ちます。**

&nbsp;&nbsp;&nbsp;種を日に直接当てて乾かしてはいけません。直射日光の熱で胚が損傷し発芽率が大きく落ちます。風通しの良い日陰でゆっくり乾かすのが原則で、厚く積んでおくと中でカビが生えるため一段に広げなければなりません。

| 項目 | 基準 |
|---|---|
| 目標水分 | 8%以下 |
| 乾燥剤 | 炒って冷ましたコメ、炭、乾いた草木灰、焼いて冷ました塩 |
| 保管容器 | ガラス瓶、金属缶、紙袋を二重に包んだもの |
| 保管温度 | 低いほど良く、変動がないようにします |
| 発芽確認 | 毎年20粒を湿った布に置き、一週間後に発芽率を数えます |

&nbsp;&nbsp;&nbsp;種子保管の原則は乾燥と低温と暗さです。三つのうち災害の状況で確実に制御できるのは乾燥だけなので、乾燥に最も力を入れます。炒って冷ましたコメを種子の量の3分の1ほど一緒に入れて密閉すると、コメが残った湿気を吸い取ります。炭も同じ役割をし、使い終わったあと火にかざして乾かせば再び使えます。

### 13-3. 種子消毒

| 方法 | 手順 | 効果 |
|---|---|---|
| 温湯浸漬 | 50-55℃の水に10-15分浸したあとすぐに冷水で冷やします | 種子表面と皮の下の病原菌を殺します |
| 草木灰まぶし | 乾いた種子に細かい灰をまぶします | カビを抑え湿気を防ぎます |
| 選別 | 水に浸けて浮くものを捨てます | 病気の種としいなが多く浮きます |

&nbsp;&nbsp;&nbsp;温湯浸漬では温度が肝心です。50-55℃の範囲を外れてはいけません。60℃を超えると種が死に、45℃以下では病原菌が死にません。温度計がなければ、沸騰した湯と冷水を混ぜて手を入れたとき熱いけれど3秒ほどは耐えられる程度がおおよそその範囲で、大きな器にたっぷり水を入れるほど浸けている間の温度が下がりにくくなります。

## 14. 毒性と注意すべき成分

&nbsp;&nbsp;&nbsp;ナスはナス科の作物のため、ステロイドアルカロイドを微量含んでいます。ジャガイモのソラニンと同じ系列で、ナスでは主にソラソニンとソラマルギンという名前で現れます。正常に収穫したナスに含まれる量は人に問題となる水準ではありませんが、どのような条件でその量が上がるのかを知っておく必要があります。

| 成分 | どのような物質か | どのような問題になるか | どのように避けるか |
|---|---|---|---|
| ソラソニン・ソラマルギン | ナス科植物が虫やカビを防ぐために作る防御物質 | 多く食べると胃腸への刺激、吐き気 | 苦味が強い実は食べません。加熱すると一部減ります |
| ニコチン | ナス科植物に微量存在します | 100gに0.01mg程度で実質的な影響はありません | 対処は不要です |
| クロロゲン酸 | 切った面が褐変する原因物質 | 毒性はなく渋味を出します | 切って水や薄い塩水に浸します |
| ヒスタミン誘発 | 一部の人にかゆみやじんましん | 個人差が大きいです | 初めて食べるときは少量から始めます |

### 14-1. 苦味が危険信号である理由

&nbsp;&nbsp;&nbsp;アルカロイドは苦い味がします。これは偶然ではなく植物の防御戦略です。食べてはいけないという信号を味で送っているのであり、動物はその苦味を覚えて再び食べません。人にも同じ信号が働きます。ナスを一口食べて舌を刺すような苦味がすれば、その実はアルカロイドが多いという意味で、これ以上食べないのが正しいです。

| 条件 | アルカロイドの水準 | 説明 |
|---|:---:|---|
| 正常に育った旬の実 | 低い | 安全です |
| 未熟すぎる実 | やや高い | 防御が必要な時期のため含量が高いです |
| 収穫期を過ぎて黄色くなった実 | 高い | 苦味が強くなり果肉がすかすかになります |
| 水がひどく不足した状態で育った実 | 高い | ストレスが防御物質の生産を増やします |
| 葉と茎 | 非常に高い | 人が食べる部位ではありません |

> **ナスの葉と茎は食べません。実に比べてアルカロイド含量がはるかに高いです。災害の状況で食べるものがないからとナスの葉をナムルにする判断は危険です。葉と茎は堆肥に戻します。**

&nbsp;&nbsp;&nbsp;まとめると、ナスの毒性は正常な栽培と正常な収穫時期を守る限り実質的な危険ではありません。ただし水が乏しく管理が緩くなる災害の状況ではストレスを受けた実が増えることがあり、腹が減ると収穫期を過ぎた実も惜しくて食べてしまいます。苦味がすれば捨てるという原則一つだけ守ればよいのです。

## 15. 冷蔵庫なしの貯蔵 - ナスの干し切り

&nbsp;&nbsp;&nbsp;ナスの貯蔵性等級はDで、無電力常温で一週間を超えません。実の92%が水なので当然の結果です。したがってナスを冬まで持たせる方法は一つしかありません。その水を抜くことです。

### 15-1. 貯蔵方式別の比較

| 方式 | 条件 | 期間 | 特徴 |
|---|---|:---:|---|
| 生のまま短期保管 | 新聞紙や紙に包んで10-15℃の日陰 | 5-7日 | 洗わずに置きます。5℃以下では低温障害が起きます |
| 乾燥(ナスの干し切り) | 薄く切って日と風で完全に乾かします | 6か月-1年 | 体積と重さが十分の一に減り最も実用的です |
| 塩漬け | 塩10-15%で漬けます | 数か月 | 食べる前に水にさらす必要があります |
| 醤油漬け | 醤油・味噌・コチュジャンに漬け込みます | 数か月-1年 | 塩と発酵を併用します |
| 乳酸発酵 | 塩2-3%で漬けて汁の下に沈めます | 数週-数か月 | 柔らかくなりやすくナスでは扱いが難しいです |

### 15-2. ナスの干し切りの作り方

| 段階 | 方法 | 理由 |
|---|---|---|
| 1. 選ぶ | 傷がなく適度に育った実を使います | 傷んだ部分からカビが始まります |
| 2. 洗う | 洗ったあと水気を完全に拭きます | 表面の水気が残ると乾燥初期にカビが生えます |
| 3. 切る | 厚さ5-7mmの輪切り、または縦に割って四つ割りにします | 厚いと中が乾く前に外側が傷みます |
| 4. 湯通し(任意) | 沸騰した湯に30秒-1分浸けて取り出します | 酵素が失活して褐変が減り色が保たれます |
| 5. 広げる | ざるや干し台に重ねずに一段に広げます | 重なるとその部分が乾きません |
| 6. 乾かす | 日当たりと風通しの良い場所で2-4日 | 夜は露を避けて取り込みます |
| 7. 仕上げ | 手で折ったときぱきっと折れるまで | 少しでも柔らかいと保管中にカビが生えます |
| 8. 保管 | 密閉容器に乾燥剤とともに、暗く涼しい場所 | 光を受けると色が褪せます |

&nbsp;&nbsp;&nbsp;湯通しの工程を入れるかどうかが分かれるところです。湯通しすると色が美しく残り、戻したときの食感が柔らかくなりますが燃料がかかります。湯通ししないと褐色に変わりますが燃料がかからず香りがより濃くなります。昔から伝わるナスの干し切りは湯通しせずそのまま乾かしたもので、色は黒褐色ですが味には問題がありません。燃料が乏しい条件では湯通ししないほうが合理的です。

> **乾燥の成否は最初の一日で決まります。切って広げた初日に表面の水分が速やかに飛べばカビが根を張れません。曇って湿った日に干し始めると三日目に黒いカビが生えて全部捨てることになります。晴れて風のある日を選んで始めます。**

&nbsp;&nbsp;&nbsp;梅雨時や日の出ない日には火の傍で乾かす方法があります。ご飯を炊いたり水を沸かしたりするかまどの上、オンドル部屋の暖かい場所、かまどの脇に干し台を吊るしておけば、その余熱で乾きます。この方法は燃料を別に使わずに湿った日でも乾燥が可能な点で災害の状況によく合います。ただし煙が直接当たると煤の匂いが付くので、煙の通り道を避けた場所に置きます。

| 項目 | 基準 |
|---|---|
| 生ナスに対する重さ | 10%前後 |
| 完全乾燥の判断 | 折るときに音がして曲がりません |
| 保管中の点検 | 月に一度開けてカビと湿りを確認します |
| 湿ったとき | 再び日に半日干して乾かしたあと密閉します |
| 虫 | ノシメマダラメイガの幼虫が入ることがあります。密閉と乾燥剤で防ぎます |

### 15-3. 塩漬けと醤油漬け

&nbsp;&nbsp;&nbsp;乾燥が難しい条件、例えば梅雨が長かったり日が当たらない場所では塩が代案になります。ナスを縦に割って重さの10-15%になる塩で層に重ねて漬け、重い石で押さえて汁が材料を覆うようにします。この濃度ではほとんどの微生物が育たず数か月持ちます。食べるときは水に数時間浸けて塩気を抜いてから使い、その過程で水溶性の栄養素も一緒に抜けていきます。

&nbsp;&nbsp;&nbsp;醤油漬けは塩漬けに発酵を加えた方式です。塩水に数日漬けてしんなりさせたナスを醤油や味噌に漬け込みます。味噌と醤油の高い塩分と有機酸が腐敗を防ぎ、時間が経つにつれてナスに醤油の味が染みて、それ自体でおかずになります。塩だけを使った塩漬けより味が良く保管期間も長いですが、醤油や味噌を仕込める条件が前提になります。

## 16. 調理と加工

| 方法 | 燃料 | 特徴 |
|---|:---:|---|
| 蒸す | 少ない(10分以内) | 水に浮く性質があるため皿で押さえないと均一に火が通りません。油を使わないため最も経済的です |
| 炒める | 少ない | 油をよく吸って味が良くなりますが油の消費が多いです |
| 焼く | 少ない | 炭火で丸ごと焼いて皮をむくと中が柔らかくなります。残り火を使います |
| 汁物・鍋に入れる | 他の調理と兼用 | 別に燃料を使わない方法です |
| 干しナスを戻して使う | 少ない | 水に20-30分戻したあと炒めたり和えたりします |
| 生食 | なし | 勧めません。渋くアルカロイドが残っています |

&nbsp;&nbsp;&nbsp;ナスの調理で知っておくべき性質が一つあります。果肉がスポンジ構造のため油をたいへんよく吸います。油が十分にあればこの性質が長所になりますが、油が乏しい災害の状況では短所になります。ナスを炒めると油が瞬く間に消えてしまいます。この問題を避ける方法は先に蒸すか湯通ししてスポンジ構造の中の空気を水で満たすことです。水が入ったナスは油を吸いにくくなるため、少ない油でも炒めることができます。

> **油が乏しいならナスは蒸すのが正解です。蒸したナスをちぎって醤油や味噌、ニンニク、ごま塩で和えれば、燃料は10分、油は数滴で済みます。これがナスの和え物という古くからの調理法が定着した理由です。**

&nbsp;&nbsp;&nbsp;干しナスは水に20-30分戻すと元の体積の半分近くまで戻ります。戻した水には香りと水溶性成分が溶け出しているので捨てずに汁物に使います。戻した干しナスは生のナスより組織がもちもちして味が濃く、油もあまり吸いません。冬に食べる干しナスの和え物は苦しい代用品ではなく、それ自体で別の料理です。

&nbsp;&nbsp;&nbsp;皮はむかないのが原則です。ナスの特徴的な成分であるナスニンは皮にあり、食物繊維も皮に多く集まっています。皮が硬くてむきたくなるほどなら、その実は収穫時期を過ぎたということです。晩秋の厚い皮は縦に何本か切り込みを入れると食感が良くなります。

## 17. 年間作業スケジュール

| 月 | 作業 |
|---|---|
| 1月 | 種子を点検し発芽率を確認します。加温苗床の材料(稲わら、馬糞、もみ殻)を集めます |
| 2月 | 韓国中部は中旬から下旬、南部は初旬から中旬に播種します。苗床を作って発熱を始めます |
| 3月 | 育苗を管理します。本葉3-4枚に一度植え替えます。畑に石灰を入れます |
| 4月 | 元肥と堆肥を入れて畝を作ります。韓国南部は下旬に定植します。硬化を始めます |
| 5月 | 韓国中部は初旬から中旬に定植し、同時に支柱を立てます。方状分枝の下のわき芽を取り除きます |
| 6月 | 最初の実を若いうちに摘み取ります。追肥1回目。藁マルチ。下旬から初収穫 |
| 7月 | 週2-3回収穫します。追肥2回目。梅雨時の排水点検。下旬から更新剪定の準備 |
| 8月 | 上旬に更新剪定と断根、追肥3回目。高温期で着果が減る区間です。乾燥を始めます |
| 9月 | 更新後の新しい芽から秋ナスが付きます。追肥4回目。採種果の完熟を待ちます |
| 10月 | 収穫を仕上げ、残った実を全て切って干します。採種果を収穫して後熟させます |
| 11月 | 株を抜き、病気のものは燃やします。健全な茎は切って堆肥の山に入れます。種子を選別して保管します |
| 12月 | 翌年の輪作計画を点検します。干しナスの状態を確認します |

&nbsp;&nbsp;&nbsp;この表で注目すべきは2月と8月の二つの欄です。2月は加温なしで25℃を作らなければならない月で、8月は更新剪定という判断を下さなければならない月です。他の月の作業は概ね繰り返しであり失敗しても取り戻せますが、この二つの欄で狂うとその年の収穫の半分が消えます。2月の育苗に失敗すると作期全体がなくなり、8月の剪定を逃すと9月と10月の秋ナスがなくなります。

&nbsp;&nbsp;&nbsp;10月と11月の作業も軽くありません。霜が来る前に残った実を全て収穫して干す作業が冬のおかずの量を決め、病気の株を燃やして健全なものだけを堆肥に戻す作業が翌年の病害の密度を決めます。ナスは植える瞬間より片付ける瞬間にもっと多くのものが分かれる作物です。
