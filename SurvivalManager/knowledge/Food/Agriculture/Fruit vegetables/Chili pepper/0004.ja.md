## 4. 品種

### 4-1. 主要品種の比較

| 品種 | 形態 | 熟期 | 収量 | 炭疽病対応 | 特徴 |
|---|---|:---:|:---:|:---:|---|
| マエウンタン | 大果種 | 早生 | 多い | 強い | 炭疽病とウイルスに比較的強く、無農薬栽培に有利です |
| スピードカルタン | 大果種 | 早生 | 多い | 普通 | 節間が短く着果力が良く、複合耐病性があります |
| ブガン | 一般型 | 中生 | 普通-多い | 普通 | 品質が揃っており、乾燥状態が良好です |
| ムハンジルジュ | 一般型 | 中生 | 普通-多い | 普通 | カプサイシノイド含量が高く、辛味が強いです |
| ウリゴン | 一般型 | 中生 | 普通 | 普通 | 品質が安定しています |
| 在来チルソンチョ・スビチョ系統 | 中果種 | 中生 | 少ない | 弱い | 固定種なので種を採って続けられ、香りが濃厚です |
| チョンヤン系 | 小果種 | 中生 | 普通 | 普通 | 辛味が非常に強く、少量で調味と防虫に使えます |
| ピーマン・パプリカ | 大果甘トウガラシ | 中生 | 普通 | 弱い | 辛くないので子供や高齢者が食べられます |

### 4-2. 状況別の選択基準

| 状況 | 選択 | 理由 |
|---|---|---|
| 薬が全くない条件 | マエウンタンなど炭疽病に強い系統 | 防除手段がないとき、品種だけが唯一の防御です |
| 種を採って続ける計画 | 在来チルソンチョ・スビチョ系統 | 固定種なので翌年も同じトウガラシが採れます |
| 韓国の梅雨（チャンマ、6月下旬～7月）前の収穫を増やしたいとき | 早生種（マエウンタン、スピードカルタン） | 炭疽病の最盛期前にかなりの量を収穫できます |
| 調味料を最小面積で | チョンヤン系 | 辛味が強く、少量で同じ効果を出せます |
| 子供と高齢者が一緒に食べるとき | ピーマン・パプリカ系統 | カプサイシンがほとんどありません |
| 貯蔵用の唐辛子粉 | 大果種の中で皮が厚い系統 | 乾燥させたとき粉が多く採れます |

&nbsp;&nbsp;&nbsp;トウガラシでは品種選択がナスよりも重要です。理由は一つです。薬のない条件で炭疽病に対抗できるほぼ唯一の手段が、品種の抵抗性だからです。防除自立度Dという等級は、人が介入できる余地が少ないという意味であり、その少ない余地の大部分は、どんな種を植えたかにかかっています。

> **ただし、ここには災害対策特有の矛盾があります。炭疽病に強い品種はたいてい一代雑種であり、一代雑種は種を採って使うことができません。種を採って続けられる在来固定種は、炭疽病に弱いのです。この両方を同時に満たす選択肢はありません。**

&nbsp;&nbsp;&nbsp;現実的な解決策は、二つの系統を一緒に植えることです。商業品種の種子が残っている間はそれで収量を確保し、同時に在来固定種を数株植えて毎年種を採り、系統をつないでいきます。種子の供給が途絶えたら在来種に切り替えますが、そのときは収量が減り病気による損失が大きくなることを覚悟します。もう一つ付け加えると、在来種を何年もその畑で植え続けると、その土地の病原菌に適応した個体が生き残って種を残すため、世代を重ねるほどその畑では少しずつ強くなっていきます。遅いけれども確実な方向です。

&nbsp;&nbsp;&nbsp;辛さの程度も選択基準に入ります。調味料としてのトウガラシは、少ない量で大きな効果を出すほうが面積効率が高くなります。チョンヤン系のような辛い品種は、同じ重さでずっと広い範囲の調味をまかなえます。反対に、大勢で一緒に食べる条件では辛いものを食べられない人が必ずいるため、甘味種の系統も必要です。ただしこの二つを同じ畑に植えると種が混ざるため、その問題は第13節で扱います。

## 5. 畑の準備と肥料

### 5-1. 畑の準備

| 項目 | 基準 | 理由 |
|---|---|---|
| 耕起の深さ | 25-30cm | 表土を厚くし、浅い根が広がる層を作ります |
| 畝の高さ | 20-30cm | 疫病を防ぐ構造的対策です |
| 排水路 | 畑の端と畝の端を低くして水の通り道を作ります | たまった水が疫病の遊走子の通り道になります |
| 石灰処理 | 定植2-3週間前 | 堆肥と同じ日に入れると窒素が飛んでしまいます |
| 堆肥投入 | 定植1-2週間前 | 完熟堆肥のみを使います |
| 連作の確認 | 3-5年以内にナス科を栽培したか | 最初に確認すべき事項です |

### 5-2. 施肥量

| 肥料 | 1,000㎡当たり | ㎡当たり | 配分 |
|---|:---:|:---:|---|
| 窒素(N) | 19.0kg | 約19g | 元肥50% + 追肥50% |
| リン酸(P) | 11.2kg | 約11g | 全量元肥 |
| カリウム(K) | 14.9kg | 約15g | 元肥60% + 追肥40% |
| 堆肥 | 1,500-2,000kg | 1.5-2kg | 完熟堆肥 |

&nbsp;&nbsp;&nbsp;窒素とリン酸とカリウムを合わせると㎡あたり45g、評価表の基準では42gです。施肥等級Dの根拠がこの必要量です。そして窒素の半分、カリウムの40%が追肥として入るという配分が重要です。トウガラシは6月下旬から10月まで四か月間、実を作り続ける作物なので、養分供給が一度で終わってしまうと8月から実が小さくなり色も薄くなります。

### 5-3. 元肥と追肥の時期

| 区分 | 時期 | 内容 |
|---|---|---|
| 石灰 | 定植2-3週間前 | 酸度矯正 |
| 元肥 | 定植1-2週間前 | 堆肥全量 + リン酸全量 + 窒素50% + カリウム60% |
| 追肥1回目 | 定植後約30日 | 最初の実がつく頃 |
| 追肥2回目 | 1回目から20-25日後 | 収穫が始まる頃 |
| 追肥3回目 | 2回目から20-25日後 | カリウム中心 |
| 追肥4回目 | 3回目から20-25日後 | 秋の着色のための最後の供給 |

&nbsp;&nbsp;&nbsp;追肥を与えるとき、株のすぐ横に施してはいけません。根が浅く広がっているため、濃度の高い肥料が触れると根が傷みます。株から15-20cm離れた場所、または畝間の溝に入れて土をかぶせるのが原則です。液体で与えるときも同様に溝に注ぎます。

### 5-4. 化学肥料なしで同じ量を作る方法

| 代替資源 | 供給する栄養素 | 使い方 | 注意 |
|---|---|---|---|
| よく腐熟した堆肥 | 窒素・リン酸・カリウムと微量元素全般 | 元肥として㎡あたり2-3kg | 未熟な堆肥は根を傷めます |
| 薄めた尿 | 窒素が主で、カリウム・リン酸は少量 | 水で10-15倍に薄めて溝に注ぎます | 葉に触れると傷みます。収穫2週間前から中止します |
| 草木灰 | カリウム・カルシウム・リン酸 | ㎡あたり一握り（50-100g）を土に混ぜます | アルカリが強く、使いすぎるとpHが上がりすぎます |
| 骨粉 | リン酸・カルシウム | 元肥として堆肥に混ぜます | 分解が遅いです |
| 油かす | 窒素・リン酸 | 水に浸けて2-3週間発酵させた後10倍に薄めます | 生のまま入れると発酵熱で根が傷みます |
| 草肥 | 窒素・有機物 | 刈って干した草を畝に敷きます | 種が熟した草は雑草を広げます |
| 卵の殻・貝殻を焼いた粉 | カルシウム | 元肥として土に混ぜます | 石灰の代用です |

&nbsp;&nbsp;&nbsp;トウガラシではカルシウムについて別途触れる必要があります。カルシウムが不足すると実の先端が黒く腐る尻腐れ病が起きますが、これは病原菌が起こす病気ではなく生理障害です。原因はたいてい土にカルシウムがないからではなく、水やりが不均一でカルシウムが実の先端まで届かないからです。カルシウムは水に乗って移動する元素なので、土が乾いたり湿ったりを繰り返すと移動が途切れます。そのため尻腐れ病の根本的な対策は、カルシウム施肥ではなく均一な灌水とマルチングです。

> **トウガラシでよくある勘違いの一つは、窒素を多く与えれば多く実がなるというものです。実際は逆です。窒素が過剰だと茎と葉ばかり茂って花が落ち、茂りすぎた株は内部が暗くなって炭疽病や軟腐病が居着きます。薬のない条件での窒素の与えすぎは、病気を招く近道です。**

## 6. 播種と定植

### 6-1. 時期

| 作業 | 地域 | 時期 | 備考 |
|---|---|---|---|
| 播種（育苗開始） | 韓国中部 | 2月中旬-下旬 | 定植70-80日前 |
| | 韓国南部 | 2月上旬-中旬 | |
| 定植 | 韓国中部 | 5月上旬-中旬 | 遅霜が完全に終わった後 |
| | 韓国南部 | 4月下旬-5月上旬 | |
| 青唐辛子の収穫 | 韓国全土 | 6月中旬- | 定植後40-50日 |
| 赤唐辛子の収穫 | 韓国全土 | 7月下旬-10月 | 7-10日間隔 |

### 6-2. 育苗 - 加温なしでする方法

| 項目 | 基準 |
|---|---|
| 播種前処理 | 30℃の水に10時間浸けたあと、濡れた布に包んで25-30℃で発芽させます |
| 播種の深さ | 0.5-1cm |
| 発芽温度 | 25-30℃、4-7日 |
| 育苗温度 | 昼22-30℃、夜15℃以上 |
| 鉢上げ | 本葉3-4枚（播種後35-40日）で1回 |
| 育苗期間 | 70-80日 |
| 定植適期の苗 | 本葉5-7枚、最初の花蕾が見える頃 |
| 硬化 | 定植1週間前から日中は外に出します |

&nbsp;&nbsp;&nbsp;トウガラシの育苗がナスより難しい理由は、夜の温度にあります。トウガラシは育苗期の夜温が15℃を下回ることが多いと花芽がうまく作られず、その結果が定植後の着果不良として表れます。昼間は日光で温度を上げられても、夜に15℃を保つことは2月や3月には簡単ではありません。

| 方法 | 原理 | 得られる温度 | 限界 |
|---|---|---|---|
| 踏み込み温床 | 馬糞・稲わら・籾殻を水と混ぜて踏み込むと、微生物が分解しながら熱を出します | 床面20-30℃を3-6週間維持 | 材料集めと労力が大きいです |
| 室内の南向きの窓辺 | 昼間の日差しが土と水を温めます | 昼25-30℃、夜15-18℃ | 夜温の確保が鍵です |
| 水入りタンクの蓄熱 | 黒い水タンクを育苗箱の横に置き、昼の熱を蓄えます | 夜温を3-5℃上げます | 補助的な手段です |
| 二重被覆 | 箱の上に藁むしろや布をかけ、その上にさらにかけます | 夜温を2-4℃上げます | 昼間に外さないと徒長します |
| オンドル部屋の奥 | 人が生活する空間の残熱を利用します | 夜18-22℃ | 光が不足し徒長しやすいです |

> **育苗が不可能な場合、播種時期を遅らせるという選択肢があります。4月に播種して6月中旬に定植すれば、青唐辛子の収穫は8月にずれ込み、赤唐辛子はほとんど得られませんが、加温なしで苗を育て上げられます。唐辛子粉をあきらめて青唐辛子だけを得る年になるということです。**

### 6-3. 定植

| 項目 | 基準 | 備考 |
|---|---|---|
| 植え付けの深さ | 苗の土よりやや深く | 根が浅く倒れやすいため、ナスより深く植えます |
| 一条植え | 畝80-90cm、株間35-40cm | ㎡あたり3株前後 |
| 二条植え | 畝150cm、株間35-40cm | 条間を広げて通風を確保します |
| 植え方 | 穴にたっぷり水を注ぎ、水が引いてから苗を入れます | 活着が早まります |
| 支柱 | 定植と同時に1.5mの支柱を立てます | 後から立てると根を切ってしまいます |
| 定植の時刻 | 曇りの日の午後 | 晴れた日の正午に植えるとしおれが大きくなります |

&nbsp;&nbsp;&nbsp;トウガラシをナスより深く植える理由は、根の構造にあります。トウガラシは茎の土に埋まった部分から新しい根が出るため、少し深く植えると根の範囲が広がり倒れにくくなります。ただし深く植えすぎると茎の根元が土に長く湿った状態になり、疫病が入り込みます。苗の土の塊の上面が畑の表面より1-2cmほど低く入る深さが適当です。

&nbsp;&nbsp;&nbsp;株間35-40cmはナスより狭くなっています。トウガラシ一株がナスより広がりが少ないためですが、だからといってさらに狭めると通風が悪くなり炭疽病がひどくなります。薬のない条件では、むしろ標準より広く、40-45cmに取るほうがよいでしょう。株数が減って総収量は少し落ちますが、病気で失う量のほうがそれより大きいのです。

## 7. 水管理

&nbsp;&nbsp;&nbsp;トウガラシの水管理は、二つの方向の危険の間を通り抜ける作業です。乾けば花が落ちて実が小さくなり尻腐れ病が生じ、水が多すぎれば疫病が入り込みます。根が浅い浅根性のため、どちらの危険も素早く現れます。

| 時期 | 水管理 | 理由 |
|---|---|---|
| 定植直後-活着 | 植え穴にたっぷり注ぎ、その後3-4日は乾かさないようにします | 切れた根が回復するまで吸収力が弱いです |
| 活着後-開花前 | 表土が乾いたら、5-7日間隔 | やや乾燥気味にすると根が広く張ります |
| 開花・着果期 | 3-4日間隔で均一に | 水やりが不均一だと尻腐れ病が生じます |
| 肥大・着色期 | 3-4日間隔 | 実が大きくなり色素が作られます |
| 梅雨時 | 灌水を中止し、排水路を点検します | 水がたまった瞬間、疫病が動き出します |
| 収穫後半 | 徐々に減らします | 遅くまで水を与えると着色が遅れます |

### 7-1. 不足と過多のサイン

| 状態 | 症状 | 説明 |
|---|---|---|
| 水不足の初期 | 花と若い実が落ちます | 葉がしおれるより先に現れます |
| 水不足の進行 | 実が細く短いまま成長が止まり、表面にしわが寄ります | 細胞が水で膨らめなかった結果です |
| 水やりの不均一 | 実の先端が黒くくぼんで腐ります（尻腐れ病） | カルシウムの移動が途絶えた結果であり、病原菌ではありません |
| 過湿の初期 | 下の葉が黄色くなって落ちます | 根が呼吸できない状態です |
| 過湿の進行 | 茎の根元が暗褐色にくびれ、株が急にしおれます | 疫病です。回復しません |

> **トウガラシ畑で一株が突然しおれて枯れると、水をもっとやりたくなります。たいていそれが最悪の選択です。夏にトウガラシが急にしおれる原因は、水不足よりも疫病であることのほうがはるかに多く、水を追加すると遊走子が隣の株へ泳いでいきます。**

&nbsp;&nbsp;&nbsp;見分ける方法は、根元を見ることです。水不足でしおれた株は朝には回復し、茎の根元は無傷です。疫病にかかった株は朝になっても回復せず、茎の根元が黒くくびれています。後者であれば、直ちに抜いて焼却し、その場所に土を盛って水の通り道を断ちます。

### 7-2. 水が貴重なとき

| 方法 | 原理 | 効果 |
|---|---|---|
| 藁・草マルチング | 表面からの蒸発を防ぎ、土の水分を均一に保ちます | 灌水の間隔が延び、尻腐れ病が減ります |
| 夕方の灌水 | 蒸発による損失が少ないです | ただし葉が濡れたまま夜を越さないよう、土だけに与えます |
| 溝灌漑 | 葉と実に水が触れません | 炭疽病の胞子が跳ねるのを防ぎます |
| 株ごとの点滴 | 底に穴を開けた瓶を土に挿し、ゆっくり染み込ませます | 少ない水で根の層だけを潤します |

&nbsp;&nbsp;&nbsp;トウガラシにおいてマルチングは、水を節約する手段であると同時に病気を防ぐ手段でもあります。炭疽病の胞子は土の中の罹病残渣に残っていて、雨粒が跳ねることで下側の実に付着します。藁が土を覆っていれば、この跳ね返りが遮断されます。藁マルチング一つで炭疽病の発生が目に見えて減る理由がここにあり、ビニールがない条件ではこの方法は特に大きな価値を持ちます。
