## 13. 留种 - 辣味混杂的问题

### 13-1. 辣椒留种容易与困难的原因

&nbsp;&nbsp;&nbsp;辣椒的自家留种等级为S。辣椒花在一朵花内同时具有雌蕊和雄蕊，花开前后自身的花粉常常落到自己的柱头上完成受精。一个红辣椒里有几十到几百粒种子，只要几个熟透的果实就能填满来年的地。到这里都是容易的一面。

&nbsp;&nbsp;&nbsp;困难的一面有两个。一个是杂交，另一个是种子寿命。

| 问题 | 内容 | 结果 |
|---|---|---|
| 杂交 | 自花授粉占优势，但蜜蜂传播花粉的比例视条件可达2-50% | 辣椒和甜椒混种时，来年种出的辣度会变成中等 |
| 种子寿命 | 常温下1-2年，发芽力下降很快 | 一次留够多年用量的策略不管用 |

### 13-2. 辣味混杂的问题

&nbsp;&nbsp;&nbsp;我们种植的辣椒、青椒、灯笼椒、彩椒全都是Capsicum annuum这同一个种。既然是同一个种，杂交就没有任何障碍。如果辣椒旁边灯笼椒开花，又有蜜蜂来回穿梭，那一年灯笼椒的种子中就会有一部分是由辣椒的花粉受精而成的。

> **当年收获的果实本身的味道不会改变。杂交的结果记录在那个果实的种子里，到第二年种下那颗种子时才会显现出来。今年灯笼椒不辣，并不意味着它的种子是安全的。**

&nbsp;&nbsp;&nbsp;生成辣椒素的能力是显性遗传的。因此甜椒的雌蕊接受了辣椒的花粉后，那颗种子长出的来年植株大多会变辣。反过来，即辣椒接受甜椒的花粉时，辣味会保持不变。结果是一旦发生杂交，损失的只是甜椒一方。想为孩子和老人单独留一份甜椒的计划因此而落空。

| 方法 | 内容 | 现实性 |
|---|---|---|
| 隔离距离 | 与其他品系相距100-500m | 在狭窄的地块上几乎不可能 |
| 错时种植 | 一年只让一个品系开花 | 种子寿命只有1-2年，并不容易 |
| 单花套袋 | 花开前套上网袋或布袋，结果后再摘掉 | 最可靠，适合小规模 |
| 整株套网 | 用网罩把几株留种用的植株整体覆盖 | 可靠。因为是自花授粉，网内不需要人工授粉 |

&nbsp;&nbsp;&nbsp;辣椒套网比羽衣甘蓝容易，原因就在这里。羽衣甘蓝是自交不亲和，网内必须由人用毛刷传递花粉，而辣椒能自花授粉，套上网放着不管就行。给要留种的两三株套上蚊帐或稀疏的布，纯度就能保住。结果后就可以摘掉网罩，因为受精已经完成。

&nbsp;&nbsp;&nbsp;最简单的办法是干脆只种一个品系。只种辣椒或只种甜椒，杂交问题就消失了。如果家里有人不能吃辣，用少放辣椒来调整口味，可能比同时管理两个品系更简单。

### 13-3. 留种流程

| 阶段 | 时期 | 内容 |
|---|---|---|
| 选留种株 | 7月 | 选无病、长势好、品种特征明显的植株 |
| 隔离 | 开花前 | 套网或与其他品系隔开 |
| 选留种果 | 7月下旬-8月 | 选株上部靠下、长势旺时结的果并做标记 |
| 完熟 | 9-10月 | 放到完全变红、表皮起皱为止 |
| 后熟 | 收获后 | 在阴处放1-2周，种子会更饱满 |
| 分离种子 | 后熟后 | 剖开果实，从胎座上刮下种子 |
| 筛选 | 分离后立即 | 放入水中，捞出漂浮的丢弃 |
| 干燥 | 分离后 | 在阴处摊成一层晾1-2周 |
| 保存 | 完全干燥后 | 与干燥剂一起放入密闭容器 |

> **刮取种子时如果赤手接触胎座，辣椒素会渗入皮肤，让手灼痛好几个小时。揉眼睛会剧痛难忍，用肥皂洗也不容易去除。要用布或塑料袋包住手，作业后先用油或牛奶擦拭，再用水洗。**

### 13-4. 种子寿命与保存

&nbsp;&nbsp;&nbsp;评价表中的种子寿命C，是指常温保存条件下1-2年，发芽力下降很快。这是因为辣椒种子含有相当量的脂质，会发生氧化酸败。不过这个寿命在很大程度上取决于保存条件。

| 条件 | 发芽力维持 |
|---|:---:|
| 常温，不密闭 | 1年 |
| 常温，密闭+干燥剂 | 2-3年 |
| 凉爽（10度以下）干燥处，密闭 | 4-5年 |
| 不结冰的低温，完全干燥，完全密闭 | 更长 |

&nbsp;&nbsp;&nbsp;因此在灾害情况下能做的事很明确：把种子彻底晒干，与干燥剂一起密闭，放在家中最凉的地方。地窖、朝北的墙壁下方、地板下都是候选地点。而且每年都不间断地重新留种。辣椒不像羽衣甘蓝或南瓜那样留一次种能撑好几年，它是必须年年接续留种的作物。

| 项目 | 标准 |
|---|---|
| 目标水分 | 8%以下 |
| 干燥剂 | 炒过晾凉的米、木炭、干木灰 |
| 保存容器 | 玻璃瓶、金属罐 |
| 发芽检验 | 每年取20粒放在湿布上，十天后统计发芽率 |
| 发芽率标准 | 低于70%时增加播种量或重新留种 |

### 13-5. 种子消毒

| 方法 | 步骤 | 效果 |
|---|---|---|
| 温水浸种 | 在50-55℃水中浸10-15分钟，再用冷水冷却 | 杀死附着在种子上的炭疽病菌和细菌 |
| 筛选 | 浸入水中，捞出漂浮者丢弃 | 病种和空粒会漂起来 |
| 木灰拌种 | 给干种子裹上细灰 | 抑制霉菌并隔绝湿气 |

&nbsp;&nbsp;&nbsp;辣椒的种子消毒尤为重要。炭疽病菌附着在种子表面和种皮下越冬，用这种种子育出的苗会成为来年最初的感染源。温水浸种是不需要工具就能实行的少数实质性防治手段，只要把温度控制好即可。超过60℃种子会死，低于45℃病菌又能存活。

## 14. 毒性与需注意的成分

&nbsp;&nbsp;&nbsp;辣椒没有急性毒性。辣椒素不是毒素而是刺激性物质，人日常食用的量不会造成问题。不过了解这种刺激的性质，在多种情况下都会有用。

| 成分 | 是什么物质 | 会造成什么问题 | 应对 |
|---|---|---|---|
| 辣椒素 | 在胎座中生成的生物碱，刺激痛觉受体 | 过量摄入时刺激肠胃、腹泻；接触眼睛或伤口会剧痛 | 用牛奶或油擦拭，水不易洗掉 |
| 茄碱类 | 茄科植物共有的微量生物碱 | 影响水平几乎可以忽略 | 无需处理 |
| 霉菌毒素 | 由晒制不当的辣椒上长出的霉菌产生 | 可能生成对肝脏有害的物质 | 长霉的辣椒要丢弃 |

### 14-1. 辣椒素用水洗不掉的原因

&nbsp;&nbsp;&nbsp;辣椒素是溶于油而不溶于水的物质。所以吃辣后喝水几乎没用，牛奶或油腻的食物则效果好得多，因为牛奶中的酪蛋白能包裹住辣椒素，把它从受体上剥离下来。手上沾到辣椒素时同理，先用食用油或牛奶擦拭，再用肥皂清洗。

> **用碰过辣椒的手揉眼睛会非常疼，即使清洗也难以很快缓解，要难受三十分钟到一个小时。研磨辣椒粉或刮取种子后一定要洗手，洗手之前不要碰脸。**

### 14-2. 长霉的干辣椒

&nbsp;&nbsp;&nbsp;干辣椒中真正危险的不是辣椒素，而是霉菌。如果在没有完全晒干的状态下密封，内部就会长霉，某些霉菌会生成对人体有害的毒素。这种毒素加热也不会被破坏，磨成粉混入其中后连肉眼也看不出来。

| 状态 | 判断 |
|---|---|
| 表面看起来像蒙了一层白粉 | 可能是霉，需要闻一闻气味确认 |
| 潮湿发霉的气味 | 丢弃 |
| 黑色或青色斑点 | 丢弃 |
| 只有一部分长霉 | 只切掉那一部分并不安全，孢子已经扩散开了 |

&nbsp;&nbsp;&nbsp;所以第15节的干燥不只是贮藏技巧，而是安全问题。舍不得丢弃没晒干的辣椒而照样保存，最终会把整批都扔掉。

## 15. 无冰箱贮藏 - 干燥就是一切

&nbsp;&nbsp;&nbsp;辣椒的耐储性等级S，指的是干辣椒。鲜辣椒和其他瓜果蔬菜一样，常温下一到两周就会坏。完全晒干的辣椒水分降到12%以下，微生物无法生长，能这样保存一到两年。

### 15-1. 干燥方法

| 方式 | 条件 | 期间 | 特点 |
|---|---|---|---|
| 晒干（日晒） | 选晴朗有风的天气，摊在竹帘或席子上，或用线串起来挂 | 7-15天 | 最古老的方法，不耗燃料 |
| 阴干 | 挂在通风良好的阴凉处 | 15-30天 | 颜色保持鲜亮，但耗时长，梅雨季会失败 |
| 火干 | 利用灶台上方、暖炕炕头、炉灶旁的余热 | 2-5天 | 潮湿天气也能进行，不需另耗燃料 |
| 混合法 | 先晒几天，最后在火边收尾 | 5-10天 | 梅雨季比较可行 |

| 步骤 | 方法 | 原因 |
|---|---|---|
| 1. 挑选 | 只用无病、完全变红的果实 | 有斑点的会在晾晒过程中扩散 |
| 2. 去除水分 | 如有湿气先摊开晾一天 | 带湿堆放几个小时就会长霉 |
| 3. 摊晒 | 不重叠地摊成一层，或用线串起来挂 | 重叠处晒不干 |
| 4. 翻动 | 每天翻动一两次 | 下层会积存湿气 |
| 5. 夜间管理 | 收进屋内或盖好以免沾露 | 夜露弄湿后就得从头再晒 |
| 6. 判定 | 用手弯折时应脆断，摇动时能听到里面种子的响声 | 能弯曲说明还没干透 |
| 7. 保存 | 装入密闭容器或袋子，放在阴暗凉爽处 | 见光会褪色 |

> **判断是否晒干的标准只有一个：弯折时会不会断。能弯曲说明还没干，这样收起来一个月内就会长霉。哪怕舍不得，再多晒半天也更划算。**

&nbsp;&nbsp;&nbsp;用线串起来悬挂的方式有多个优点。纵向利用空间不占地方，四面通风能晒得均匀，下雨时也容易整串收进屋。用针在果柄附近穿孔，一串串挂在粗线上。挂在屋檐下或墙上，往往就能这样一直保存到冬天。

### 15-2. 干辣椒的保存

| 项目 | 标准 |
|---|---|
| 目标水分 | 12%以下 |
| 保存温度 | 越低越好，常温下可存1-2年 |
| 保存场所 | 阴暗凉爽干燥处，如地窖、朝北墙壁下方 |
| 容器 | 陶罐、双层包裹的袋子、密闭容器 |
| 干燥剂 | 木炭、炒过晾凉的米、干木灰 |
| 检查 | 每月开一次，检查是否潮湿或长霉 |
| 变潮后 | 再晒半天后重新装好 |
| 虫害 | 印度谷螟幼虫会侵入，用密闭和干燥来防止 |

&nbsp;&nbsp;&nbsp;整只保存还是磨成粉保存，哪种更好取决于条件。整只辣椒保存时间要长得多，表面积小、氧化慢，香气也不容易散失。粉末用起来方便，但颜色很快褪掉，香气也变弱。因此原则是整只保存、按用量现磨，用石臼或石磨随用随磨。

### 15-3. 其他贮藏方法

| 方法 | 内容 | 期间 |
|---|---|---|
| 盐渍 | 把青辣椒浸入盐水（10-15%）中 | 数月，食用前用水浸泡去盐 |
| 酱油渍 | 把青辣椒浸入煮开晾凉的酱油中 | 数月至1年 |
| 发酵辣椒 | 浸入盐水中进行乳酸发酵 | 数月，会变酸变软 |
| 辣椒酱 | 在辣椒粉中加入谷物淀粉、酱曲（meju）粉和盐进行发酵 | 数年 |
| 辣椒油 | 把辣椒粉放入油中加热，然后过滤保存 | 数月，需要有油才行 |

&nbsp;&nbsp;&nbsp;把青辣椒用盐腌起来的方法，在难以让辣椒转红成熟的年份特别有用。如果炭疽病流行导致无法等到成熟，就趁青辣椒状态摘下腌制。作为调味料的效果不如辣椒粉，但作为一道咸菜已经足够，最重要的是它成了晒制失败年份的一种保险。

## 16. 烹饪与加工 - 既是调味料也是防腐剂

| 用途 | 方法 | 燃料 |
|---|---|---|
| 辣椒粉 | 摘去干辣椒的果柄，用石臼或石磨磨碎 | 无 |
| 整只干辣椒 | 整只放入汤中煮，之后捞出 | 与其他烹饪合并进行 |
| 青辣椒生食 | 洗净后直接蘸大酱或酱食用 | 无 |
| 辣椒油 | 把辣椒粉放入油中，用小火煮出香辣味 | 少量 |
| 辣椒酱 | 把谷物、酱曲粉和盐混合发酵 | 仅用于煮熟谷物 |
| 泡菜调料 | 把辣椒粉、盐和蔬菜拌在一起 | 无 |

&nbsp;&nbsp;&nbsp;评价表中烹饪·加工为SS，意味着不需要加热。干辣椒磨碎就能直接使用，所以燃料消耗为0。在大豆要泡八小时再煮一小时、谷物也得煮熟的情况下，一种不耗任何燃料就能改变食物味道的食材是十分珍贵的。

### 16-1. 防腐效果

&nbsp;&nbsp;&nbsp;辣椒素具有抗菌作用。它会扰乱细菌和霉菌的细胞膜，延缓其繁殖，对几种引发食物中毒的细菌尤其有效。这也是炎热气候地区的食物大量使用香辛料的原因，也是辣椒对泡菜越冬有所贡献的部分原因。

> **不过辣椒并不能让已经变质的食物恢复原状。它只是延缓腐败，如果用辛辣的调料去掩盖已经变质的食物，反而会因为闻不出坏味而更加危险。防腐效果只在从一开始就加入的情况下才成立。**

### 16-2. 驱虫用途

&nbsp;&nbsp;&nbsp;评价表中的非食用价值D，是在八个项目中满足了害虫防治这一项的结果，依据正是辣椒素。哺乳动物和昆虫都会回避辣椒素。

| 用途 | 方法 | 对象 |
|---|---|---|
| 保护贮藏谷物 | 在谷物袋或陶罐里放几个干辣椒 | 米象、印度谷螟 |
| 种子保存 | 在种子容器里放一块干辣椒 | 谷物害虫 |
| 田间驱避剂 | 把干辣椒泡水一天后过滤稀释喷洒 | 柔体害虫、蝽象 |
| 驱赶鼠类和兽类 | 在通道上撒辣椒粉 | 老鼠、鼹鼠 |
| 种子包衣 | 给待播种子裹上辣椒粉 | 鸟类和蚂蚁 |

&nbsp;&nbsp;&nbsp;在贮粮的陶罐里放干辣椒是一种古老的方法，在灾害情况下尤其有价值。长期贮存大米和豆类时最大的损失来自虫害，而在没有杀虫剂的条件下能用的手段并不多。干辣椒与木炭、大蒜一起放入并密封的组合，自古以来就被沿用。辣椒不会杀死害虫，但能延缓害虫的侵入，抑制已侵入害虫的繁殖。

### 16-3. 调节辣度的方法

&nbsp;&nbsp;&nbsp;在大家一起进餐的情况下，调节辣度是个实际的问题。辣椒素集中在胎座这一事实在这里能用得上。使用整只干辣椒时，把中间的白色隔膜和种子抖掉，辣度会大大降低；反之若想加重辣味，就连胎座一起磨碎。制作辣椒粉时是否加入胎座，能从同一批辣椒中得到两种不同的粉。用油煮出的辣椒油因为辣椒素易溶于油，即使用量很少也很辣。

## 17. 全年作业日程

| 月 | 作业 |
|---|---|
| 1月 | 检查种子并确认发芽率，收集温床材料并整理支架 |
| 2月 | 韩国中部在中旬至下旬、南部在初旬至中旬播种，开始温床发热 |
| 3月 | 管理育苗，长出3-4片真叶时移植一次，往地里施石灰 |
| 4月 | 施入堆肥和基肥并把垄做高，韩国南部在下旬定植，开始炼苗 |
| 5月 | 韩国中部在上旬至中旬定植并同时立支架，覆盖稻草覆盖物 |
| 6月 | 去除第一分枝以下的侧芽并摘掉第一个果，追肥第1次，中旬起收获青辣椒 |
| 7月 | 检查梅雨期排水，预察炭疽病并立即清除病果，追肥第2次，下旬起收获红辣椒 |
| 8月 | 每隔7-10天收获红辣椒并晒干，追肥第3次，标记留种果 |
| 9月 | 持续收获和晒干红辣椒，追肥第4次，等待留种果完熟 |
| 10月 | 结束收获，剩下的青辣椒腌制，采收留种果并进行后熟 |
| 11月 | 拔除植株并烧掉病残体，精选种子并保存，收拢干辣椒 |
| 12月 | 检查干辣椒的状态，确定来年的种植地块 |

&nbsp;&nbsp;&nbsp;这张表里最紧张的一格是7月。梅雨、炭疽病和第一批红辣椒的收获在同一个月里叠加。这个月是否整修排水沟、勤于清除病果，还是撂手不管，会直接决定8月和9月的产量。也正是在这个月，要决定是让辣椒转红成熟，还是趁青摘下。

&nbsp;&nbsp;&nbsp;11月的残体处理也不轻松。病茎和病果如果留在地里，就会成为来年最初的感染源，在没有农药的条件下，这个差别会表现得很明显。辣椒是一种来年收成更多取决于清理工作而非种植本身的作物。
