## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

&nbsp;&nbsp;&nbsp;辣椒是茄科(Solanaceae)辣椒属(Capsicum)植物。学名为Capsicum annuum，annuum意为一年生，但实际上在热带地区以多年生方式生长。之所以在韩国的气候下成为一年生，只是因为熬不过冬天。辣椒属有五个栽培种，我们种植的几乎全部是Capsicum annuum。其余的是Capsicum frutescens（塔巴斯科辣椒）、Capsicum chinense（哈瓦那辣椒）、Capsicum baccatum、Capsicum pubescens。

| 种 | 代表 | 韩国栽培情况 | 杂交 |
|---|---|---|---|
| Capsicum annuum | 本地传统辣椒、灯笼椒、彩椒、哈拉皮诺辣椒 | 大部分 | 同种之间会完全杂交 |
| Capsicum frutescens | 塔巴斯科辣椒 | 少见 | 与annuum部分杂交 |
| Capsicum chinense | 哈瓦那辣椒、魔鬼椒 | 少见 | 与annuum部分杂交 |

> **这里有一个必须牢记的事实。我们种植的辣味辣椒、青辣椒、灯笼椒、彩椒全部都是同一个种。种在同一块地里会互相传粉，用这样授粉得到的种子在第二年会长出辣味和甜味混杂的果实。**

&nbsp;&nbsp;&nbsp;属于茄科这一事实，在实际操作中也会直接产生影响。辣椒与茄子、番茄、马铃薯共享疫病、青枯病、枯萎病、病毒病。在挖过马铃薯的地方种辣椒，马铃薯留下的疫病菌就会侵袭辣椒；在拔掉辣椒的地方第二年种番茄，同样的事情会重演。评价表中的连作适应性D，正是由此而来。

&nbsp;&nbsp;&nbsp;辣椒原产于从墨西哥到玻利维亚的中南美热带高原地区。这一出身决定了它的栽培条件。第一，因为喜高温，在10度以下生长会停止，遇霜就会枯死。第二，作为雨季与旱季分明地区的植物，根系浅而分布广。第三，在野外，鸟类会吃下果实并传播种子。第三点解释了辣椒素存在的原因。哺乳动物一接触辣椒素就会感到疼痛，还会用牙齿嚼碎种子，而鸟类的辣椒素受体不同，感觉不到辣味，会将种子完整排出体外。辣椒的辣味，是一种驱赶哺乳动物、招徕鸟类的机制。

### 2-2. 形态

| 器官 | 特征 |
|---|---|
| 叶 | 呈宽卵形或披针形，边缘平滑（全缘）。叶片表面有光泽 |
| 茎 | 直立生长，基部会木质化。在某个节位分为两杈或三杈，这个最初的分杈点称为第一分枝点。株高60-100cm |
| 根 | 有笔直的主根，但在移栽过程中被切断，细根集中分布在表土20cm以内。是典型的浅根性 |
| 花 | 白色小花每节开一到两朵，朝下开放。以自花授粉为主 |
| 果实 | 属于浆果。起初为绿色，成熟后变为红色、黄色或橙色。果实中空，种子附着在胎座上 |
| 种子 | 直径3-4mm，呈扁平圆盘形，淡黄色。附着在胎座上 |

&nbsp;&nbsp;&nbsp;有必要了解辣椒果实的结构。果实中空，中央有一条像白色灯芯一样的组织，种子就附着在上面。这个白色组织就是胎座，辣椒素大部分是在这里生成的。种子本身并不辣，是因为接触了胎座才变辣。这意味着，如果想减少辣味，应该去掉的是胎座而不是种子。

&nbsp;&nbsp;&nbsp;辣椒的分枝结构与茄子相似。茎长到某个节位后开出第一朵花，并在该处分成两三杈，分杈后的茎又重复同样的过程。因此一株辣椒会长成越往上越密的伞状。这种结构决定了第8节所介绍的整枝方式。

&nbsp;&nbsp;&nbsp;根系浅是辣椒栽培中最大的物理制约。由于根系集中在表土20cm以内，这一层一旦变干就会立刻缺水，一旦积水就会立刻缺氧窒息。而且根浅还容易被风吹倒。支架不可或缺的原因有两个：果实的重量和浅根。

### 2-3. 生长阶段

| 阶段 | 时期 | 关键生理 | 重要养分 |
|---|---|---|---|
| 育苗期 | 从播种到定植（70-80天） | 长到真叶5-7片。第一个花蕾出现前后是定植适期 | 氮、磷 |
| 定植·缓苗期 | 定植后1-2周 | 切断的根会长出新根来替代。这段时期外观上不生长属于正常现象 | 磷 |
| 营养生长期 | 定植后2-5周 | 茎变粗，形成第一分枝点 | 氮 |
| 开花·坐果期 | 定植后40-50天 | 第一分枝点开出第一朵花，此后每个节位都会陆续开花 | 磷、硼、钙 |
| 膨大·绿熟期 | 开花后20-30天 | 果实长到应有的大小。这个状态就是青辣椒 | 钾 |
| 着色·完熟期 | 开花后45-50天 | 由绿转红，辣椒素和色素不断积累 | 钾 |

> **青辣椒和红辣椒不是不同的果实，而是同一果实的不同阶段。开花后20-30天可以当作青辣椒食用，如果继续留在枝头，45-50天后会变红。收哪一种，要根据当年的病害状况和实际需要来判断。**

&nbsp;&nbsp;&nbsp;这个区别在灾难状况下具有实际意义。若作为青辣椒采摘，收获得早，能在炭疽病高发期到来之前收完，但无法晒干贮藏。青辣椒水分多，晒干后颜色会发黑，品质下降。若留作红辣椒，晒干后可贮藏1年，但相应地要在地里留得更久，暴露在炭疽病风险中的时间也更长。而且一株上若让红辣椒成熟，这株就会把养分用于制造种子，新花随之减少。持续采摘青辣椒能让植株工作更久，而让红辣椒成熟则会使植株提早衰弱。

&nbsp;&nbsp;&nbsp;辣椒素积累的时间点也值得了解。辣椒素在果实膨大期间持续生成，在着色期达到最多。因此即便是同一品种，红辣椒也比青辣椒辣，而完全成熟、表皮起皱的果实最辣。缺水条件下长大的辣椒会更辣，这也是已知的事实，原因是胁迫会促使植株增加防御物质的生成。

### 2-4. 每100g营养

| 营养素 | 生辣椒（红色） | 干辣椒 | 备注 |
|---|:---:|:---:|---|
| 热量 | 85kcal | 280-330kcal | 因干燥失水而浓缩 |
| 水分 | 约70g | 10-13g | 这个数值就是晾晒干燥的目标 |
| 蛋白质 | 3.12g | 10-13g | 占热量的14.7% |
| 碳水化合物 | 约18g | 55-60g | 糖类实测5.48g |
| 膳食纤维 | 4-5g | 25-30g | 干辣椒堪称膳食纤维块 |
| 维生素C | 44-78mg | 大部分流失 | 因干燥与加热几乎流失殆尽 |
| 维生素A（β-胡萝卜素） | 高 | 非常高 | 红色的很大一部分来自类胡萝卜素 |
| 维生素E | 含有 | 含有 | 属脂溶性，对干燥相对耐受 |
| 钾 | 含有 | 高 | 会被浓缩 |
| 辣椒素 | 因品种而异，为0-0.5% | 浓缩 | 集中在胎座部位 |
| 辣椒红素 | 红色果皮 | 浓缩 | 是辣椒粉呈红色的色素 |

&nbsp;&nbsp;&nbsp;这张表里值得关注的是维生素C的命运。每100g生辣椒中维生素C含量为44-78mg，处于非常高的水平，这也是微量营养素达到S级的主要依据。然而这种维生素在晒干和磨粉的过程中几乎全部流失。维生素C是一种不耐热、不耐氧、不耐光的物质，而在阳光下晾晒数日的干燥过程，恰恰会让它同时暴露在这三种因素之下。

> **要把辣椒当作维生素C的来源，就必须生吃。夏天把青辣椒蘸大酱吃，是真正能从辣椒中获取维生素C的唯一途径，冬天的辣椒粉则没有什么可指望的。**

&nbsp;&nbsp;&nbsp;相反，β-胡萝卜素和辣椒红素这类类胡萝卜素属于脂溶性，对干燥的耐受力要强得多。干辣椒依然保持鲜红的颜色，说明这些色素依然存在，与油脂一同烹调时会被人体吸收。冬天辣椒粉贡献的营养，不是维生素C，而是维生素A。

&nbsp;&nbsp;&nbsp;干辣椒热量超过每100g 280kcal，这一点很容易造成误解。只看这个数字，似乎像是能提供热量的作物，但人不会一次吃100g干辣椒。每天10-30g才是现实的量，换算下来只有30-90kcal，占每日所需热量的2-4%。因为干燥浓缩的不只是热量，辣椒素也同样被浓缩，所以无法大量食用。

## 3. 栽培环境

### 3-1. 温度

| 类别 | 极限值 | 最适值 | 备注 |
|---|:---:|:---:|---|
| 发芽温度 | 15-35℃ | 25-30℃ | 20℃以下发芽会非常缓慢 |
| 育苗温度（白天） | 20-32℃ | 25-30℃ | |
| 育苗温度（夜间） | 15℃以上 | 18-20℃ | 持续低于15℃会影响花芽分化 |
| 生长温度 | 15-35℃ | 25-32℃ | |
| 结实温度 | 20-30℃ | 20-25℃ | 评价表中的温度适应幅度C，指的就是这10℃的幅度 |
| 高温极限 | 35℃以上 | - | 花粉活力下降，导致落花 |
| 低温极限 | 10℃以下 | - | 生长停止 |
| 致死 | 0℃以下 | - | 遇霜枯死 |

&nbsp;&nbsp;&nbsp;生长适宜温度和结实适宜温度不同，这是辣椒的一个特殊之处。适合茎叶生长的温度是25-32℃，而适合开花受精、结果的温度是20-25℃。因此在盛夏最热的时段，植株会长得很茂盛，但新果实却不容易坐住。8月中旬以后气温下降，坐果重新增多，这时结的果实就成为秋天的红辣椒。

### 3-2. 光照

| 类别 | 标准 | 备注 |
|---|---|---|
| 所需日照 | 每天6小时以上 | 光照越多，开花越多 |
| 最低日照 | 每天4小时 | 虽能生长，但坐果会大幅减少 |
| 40%遮光时 | 相对产量102% | 是果菜类的共通数值，也是评价表中S等级的依据 |
| 强光胁迫 | 盛夏直射光 | 果皮出现日灼，留下白斑，该处随后腐烂 |

&nbsp;&nbsp;&nbsp;在辣椒上，日灼会造成实际损失。没有叶片遮挡的果实若直接暴露在盛夏的强光下，该部位组织会坏死，由白变褐，随后霉菌趁虚而入。因此在辣椒栽培中，原则上不宜过多摘叶，这与茄子上积极清理下部叶片的做法正好相反。辣椒的叶片兼有为果实遮阳的作用。

### 3-3. 水分与土壤

| 项目 | 标准 | 备注 |
|---|---|---|
| 总蒸散量 | 每个生长期约750mm | 是评价表中耗水量C的依据 |
| 土壤水分 | 最大持水量的60-70% | 保持得比茄子略干一些 |
| 土质 | 排水与保水兼顾的壤土、砂壤土 | |
| 土层深度 | 30cm以上 | 细根集中分布在表土 |
| pH | 6.0-6.5 | 呈弱酸性 |
| 垄高 | 20-30cm | 是防治疫病的关键 |
| 耐盐性 | 弱 | 盐分积累会导致生长停止 |

&nbsp;&nbsp;&nbsp;关于辣椒的水分管理，有一点需要记住：过湿比干旱更危险。茄子缺水时会以落果来应对，而辣椒由于根系浅，一旦积水就会立刻招来疫病。疫病由一种名为Phytophthora capsici的水霉引起，这种病菌会产生能在水中游动的游动孢子，并随积水扩散。也就是说，田里一旦积水，这种病菌的传播通道就随之打开。

> **在辣椒地里把垄做高，不是为了排水的小技巧，而是防止疫病的唯一结构性对策。在没有药物的条件下，垄的高度决定了当年的收成。**

&nbsp;&nbsp;&nbsp;pH定在6.0-6.5，比茄子略低，是因为辣椒喜欢弱酸性。不过一旦低于5.5，就会出现磷固定和铝毒害，所以这个下限必须守住。没有石灰的情况下可以用草木灰代替，但草木灰碱性很强，一次施得过多会让pH大幅超过7。比较安全的做法是每㎡分次施入一把，第二年再根据情况调整。
