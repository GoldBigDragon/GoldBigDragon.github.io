## 4. 品种

### 4-1. 主要品种比较

| 品种 | 形态 | 熟期 | 产量 | 炭疽病应对 | 特征 |
|---|---|:---:|:---:|:---:|---|
| Maeuntan | 大果型 | 早熟 | 多 | 强 | 对炭疽病和病毒病抗性较强，有利于无农药栽培 |
| Speed Kaltan | 大果型 | 早熟 | 多 | 中等 | 节间短，坐果力好，具有复合抗病性 |
| Bugang | 普通型 | 中熟 | 中等-多 | 中等 | 品质均匀，干燥状态好 |
| Muhanjilju | 普通型 | 中熟 | 中等-多 | 中等 | 辣椒素类物质含量高，辣味强 |
| Urigeon | 普通型 | 中熟 | 中等 | 中等 | 品质稳定 |
| 本地传统Chilseongcho·Subicho品系 | 中果型 | 中熟 | 少 | 弱 | 属固定品种，可留种延续种植，香味浓郁 |
| Cheongyang系 | 小果型 | 中熟 | 中等 | 中等 | 辣味极强，少量即可用于调味和防虫 |
| 灯笼椒·彩椒 | 大果甜椒 | 中熟 | 中等 | 弱 | 不辣，儿童和老人都能食用 |

### 4-2. 按情况划分的选择标准

| 情况 | 选择 | 理由 |
|---|---|---|
| 完全没有药物的条件 | Maeuntan等抗炭疽病系统 | 没有防治手段时，品种是唯一的防线 |
| 计划留种延续种植 | 本地传统Chilseongcho·Subicho品系 | 属固定品种，第二年也能长出相同的辣椒 |
| 想在韩国的梅雨季（6月下旬至7月）之前多收一些时 | 早熟品种（Maeuntan、Speed Kaltan） | 能在炭疽病高发期之前收获相当数量 |
| 用最小面积满足调味需求 | Cheongyang系 | 辣味强，少量就能达到同样效果 |
| 儿童与老人一起食用时 | 灯笼椒·彩椒系统 | 几乎不含辣椒素 |
| 用于贮藏的辣椒粉 | 大果型中果皮较厚的品系 | 晒干后出粉量多 |

&nbsp;&nbsp;&nbsp;在辣椒栽培中，品种的选择比茄子更为重要。理由只有一个：在没有药物的条件下，能对抗炭疽病的几乎唯一手段就是品种自身的抗性。防治自立度D这个等级，意味着人为介入的空间很小，而这有限的空间，绝大部分取决于种下的是什么种子。

> **不过这里存在灾害应对特有的矛盾。抗炭疽病的品种大多是一代杂交种，而一代杂交种无法留种使用。能够留种延续种植的本地固定品种，则对炭疽病抗性弱。没有哪个选择能同时满足这两点。**

&nbsp;&nbsp;&nbsp;现实的解决办法是把两个系统一起种植。在商业品种的种子还有存量时，用它来保证产量，同时种几株本地固定品种，每年留种延续这个系统。一旦种子供应中断，就转向本地品种，同时也要接受产量下降、病害损失增大的代价。再补充一点，如果本地品种在同一块地里连续种植多年，适应了当地病原菌的个体会存活下来并留种，因此随着世代推移，这块地里的品种会一点点变强。这是缓慢但确实可靠的方向。

&nbsp;&nbsp;&nbsp;辣度也是选择的一个标准。作为调味料使用的辣椒，用少量就能产生大效果的品种，土地利用效率更高。像Cheongyang系这样辣味强的品种，同样的重量能覆盖更大范围的调味需求。反过来，在多人一起吃饭的情况下，一定会有人吃不了辣，因此也需要甜味辣椒品系。不过把这两类种在同一块地里会导致种子混杂，这个问题将在第13节讨论。

## 5. 整地与施肥

### 5-1. 整地

| 项目 | 标准 | 理由 |
|---|---|---|
| 翻耕深度 | 25-30cm | 加厚表土层，为浅根提供扩展空间 |
| 垄高 | 20-30cm | 是防止疫病的结构性对策 |
| 排水沟 | 把地块边缘和垄的末端做低，形成排水通道 | 积水是疫病游动孢子的传播通道 |
| 施石灰 | 定植前2-3周 | 与堆肥同日施用会导致氮素挥发流失 |
| 施堆肥 | 定植前1-2周 | 只使用腐熟堆肥 |
| 确认连作情况 | 3-5年内是否种过茄科作物 | 是最先要确认的事项 |

### 5-2. 施肥量

| 肥料 | 每1,000㎡ | 每㎡ | 分配 |
|---|:---:|:---:|---|
| 氮(N) | 19.0kg | 约19g | 基肥50% + 追肥50% |
| 磷(P) | 11.2kg | 约11g | 全部作基肥 |
| 钾(K) | 14.9kg | 约15g | 基肥60% + 追肥40% |
| 堆肥 | 1,500-2,000kg | 1.5-2kg | 腐熟堆肥 |

&nbsp;&nbsp;&nbsp;氮、磷、钾合计每㎡45g，按评价表的标准是42g。施肥等级D的依据正是这个需求量。而其中氮的一半、钾的40%作为追肥施入，这个分配很重要。辣椒是从6月下旬到10月、历时四个月持续结果的作物，如果养分只在一次性供应完，从8月开始果实就会变小、颜色变淡。

### 5-3. 基肥与追肥的时期

| 类别 | 时期 | 内容 |
|---|---|---|
| 石灰 | 定植前2-3周 | 矫正酸度 |
| 基肥 | 定植前1-2周 | 堆肥全量 + 磷全量 + 氮50% + 钾60% |
| 追肥第1次 | 定植后约30天 | 第一批果实坐果前后 |
| 追肥第2次 | 第1次后20-25天 | 开始收获时 |
| 追肥第3次 | 第2次后20-25天 | 以钾为主 |
| 追肥第4次 | 第3次后20-25天 | 为秋季着色提供的最后一次供给 |

&nbsp;&nbsp;&nbsp;追肥时不能施在植株的正旁边。由于根系浅而分散，浓度高的肥料一旦接触就会伤根。原则上应施在离植株15-20cm处，或垄间的沟里，然后覆土。以液体形式施肥时同样要浇在沟里。

### 5-4. 不用化肥获得同等用量的方法

| 替代资源 | 供给的养分 | 使用方法 | 注意事项 |
|---|---|---|---|
| 充分腐熟的堆肥 | 氮·磷·钾及各种微量元素 | 作基肥，每㎡2-3kg | 未腐熟的堆肥会烧根 |
| 稀释尿液 | 以氮为主，钾·磷含量少 | 用水稀释10-15倍后浇入沟中 | 沾到叶片会灼伤。收获前2周起停止使用 |
| 草木灰 | 钾·钙·磷 | 每㎡混入土中一把（50-100g） | 碱性强，过量使用会使pH过高 |
| 骨粉 | 磷·钙 | 作基肥拌入堆肥中 | 分解速度慢 |
| 麻饼（芝麻饼） | 氮·磷 | 浸水发酵2-3周后稀释10倍使用 | 直接施用生麻饼会因发酵热伤根 |
| 干草肥 | 氮·有机质 | 把割下晒干的草铺在垄上 | 若草已结籽会传播杂草 |
| 蛋壳·贝壳烧制的粉末 | 钙 | 作基肥拌入土中 | 可替代石灰 |

&nbsp;&nbsp;&nbsp;在辣椒栽培中，需要单独提一下钙。钙不足会引发果实顶端发黑腐烂的脐腐病，这不是病原菌引起的病害，而是一种生理性障碍。原因通常不是土壤中缺钙，而是浇水不均匀，导致钙无法运送到果实末端。钙是随水分移动的元素，土壤反复干湿交替就会中断这种运输。因此脐腐病的根本对策不是施钙肥，而是均匀灌溉与覆盖保墒。

> **关于辣椒有一个常见的误解，认为多施氮肥就能多结果。事实恰恰相反。氮肥过量只会让茎叶疯长而落花，长得过于茂密的植株内部变得阴暗，为炭疽病和软腐病提供藏身之处。在没有药物的条件下，氮肥施用过量是招致病害的捷径。**

## 6. 播种与定植

### 6-1. 时期

| 作业 | 地区 | 时期 | 备注 |
|---|---|---|---|
| 播种（开始育苗） | 韩国中部 | 2月中旬至下旬 | 定植前70-80天 |
| | 韩国南部 | 2月上旬至中旬 | |
| 定植 | 韩国中部 | 5月上旬至中旬 | 晚霜完全结束之后 |
| | 韩国南部 | 4月下旬至5月上旬 | |
| 青辣椒采收 | 韩国全国 | 6月中旬起 | 定植后40-50天 |
| 红辣椒采收 | 韩国全国 | 7月下旬至10月 | 间隔7-10天 |

### 6-2. 育苗 - 不加温的方法

| 项目 | 标准 |
|---|---|
| 播种前处理 | 在30℃水中浸泡10小时后，用湿布包好，在25-30℃下催芽 |
| 播种深度 | 0.5-1cm |
| 发芽温度 | 25-30℃，4-7天 |
| 育苗温度 | 白天22-30℃，夜间15℃以上 |
| 分苗 | 真叶3-4片时（播种后35-40天）进行一次 |
| 育苗期 | 70-80天 |
| 定植适期的幼苗 | 真叶5-7片，第一个花蕾出现前后 |
| 炼苗 | 定植前一周开始，白天将幼苗搬到室外 |

&nbsp;&nbsp;&nbsp;辣椒育苗比茄子难，原因在于夜间温度。育苗期夜温若经常低于15℃，花芽就无法正常形成，其后果会在定植后表现为坐果不良。白天可以靠阳光升温，但要在2月、3月的夜间维持15℃并不容易。

| 方法 | 原理 | 可获得的温度 | 局限 |
|---|---|---|---|
| 酿热温床 | 把马粪、稻草、稻壳与水混合后踩实填入，微生物分解时会产生热量 | 床面维持20-30℃，可持续3-6周 | 材料收集与劳动量大 |
| 室内朝南窗边 | 白天的阳光为土壤和水加温 | 白天25-30℃，夜间15-18℃ | 关键在于保证夜间温度 |
| 水桶蓄热 | 把黑色水桶放在育苗箱旁，储存白天的热量 | 可将夜间温度提高3-5℃ | 属于辅助手段 |
| 双层覆盖 | 在育苗箱上盖草帘或布，再在上面加盖一层 | 可将夜间温度提高2-4℃ | 白天不掀开会导致幼苗徒长 |
| 暖炕房间里侧（远离炕头处） | 利用人居住空间的余热 | 夜间18-22℃ | 光照不足，容易徒长 |

> **如果无法育苗，还有一个选择是推迟播种时间。4月播种、6月中旬定植的话，青辣椒的采收会推迟到8月，红辣椒几乎收不到，但可以在不加温的情况下把苗培育出来。这相当于放弃辣椒粉、只求收获青辣椒的一年。**

### 6-3. 定植

| 项目 | 标准 | 备注 |
|---|---|---|
| 种植深度 | 比育苗钵土面略深 | 因根浅易倒伏，种植深度应比茄子深 |
| 单行种植 | 行距80-90cm，株距35-40cm | 每㎡约3株 |
| 双行种植 | 行距150cm，株距35-40cm | 加宽行间距以保证通风 |
| 种植方法 | 先往定植穴中充分浇水，待水渗下后再放入幼苗 | 有助于加快缓苗 |
| 支架 | 定植的同时立起1.5m的支架 | 事后再立会切断根系 |
| 定植时间 | 阴天的下午 | 晴天正午种植会导致严重萎蔫 |

&nbsp;&nbsp;&nbsp;把辣椒种得比茄子深，是因为根系结构的缘故。辣椒会从茎埋入土中的部分长出新根，所以适当种深一些，根系分布范围会更广，也更抗倒伏。但种得太深，茎基部长期处于潮湿的土壤中，就会招来疫病。适宜的深度是让育苗钵的土块顶面比地面低1-2cm左右。

&nbsp;&nbsp;&nbsp;35-40cm的株距比茄子要窄。这是因为一株辣椒的展开幅度不如茄子，但如果因此再缩小株距，通风就会变差，炭疽病会加重。在没有药物的条件下，反而应该比标准更宽一些，取40-45cm为宜。虽然株数减少会让总产量略有下降，但因病害造成的损失会比这更大。

## 7. 水分管理

&nbsp;&nbsp;&nbsp;辣椒的水分管理，是在两种风险之间寻找平衡的工作。缺水会导致落花、果实变小并引发脐腐病；水多则会招来疫病。由于是浅根性作物，这两种风险都会很快显现出来。

| 时期 | 水分管理 | 理由 |
|---|---|---|
| 定植后至缓苗 | 定植穴中充分浇水，此后3-4天保持不干 | 断根恢复之前吸水能力较弱 |
| 缓苗后至开花前 | 表土变干时浇水，间隔5-7天 | 保持略干燥可使根系分布更广 |
| 开花·坐果期 | 每3-4天均匀浇水一次 | 浇水忽多忽少会引发脐腐病 |
| 膨大·着色期 | 每3-4天一次 | 果实增大并形成色素 |
| 梅雨季 | 停止灌溉，检查排水沟 | 一旦积水，疫病就会开始活动 |
| 收获后期 | 逐渐减少浇水 | 浇水太久会延迟着色 |

### 7-1. 缺水与过多的信号

| 状态 | 症状 | 说明 |
|---|---|---|
| 缺水初期 | 花朵与幼果脱落 | 在叶片萎蔫之前就会出现 |
| 缺水加重 | 果实变得又细又短、停止生长，表面出现皱纹 | 是细胞无法靠水分膨胀所致 |
| 浇水不均 | 果实顶端发黑凹陷腐烂（脐腐病） | 是钙运输中断所致，并非病原菌引起 |
| 过湿初期 | 下部叶片发黄脱落 | 根系处于缺氧状态 |
| 过湿加重 | 茎基部呈暗褐色缢缩，植株迅速萎蔫 | 这是疫病，无法恢复 |

> **辣椒地里一株突然萎蔫枯死时，人往往会想多浇点水。这通常是最糟糕的选择。夏天辣椒突然萎蔫，原因是疫病的情况远多于缺水，而多浇水只会让游动孢子游向邻近的植株。**

&nbsp;&nbsp;&nbsp;区分的方法是看茎基部。因缺水萎蔫的植株，早晨会恢复，茎基部完好无损。感染疫病的植株，早晨也不会恢复，茎基部呈黑色缢缩状。如果是后者，应立即拔除烧毁，并在原地培土，切断水流通道。

### 7-2. 水资源紧缺时

| 方法 | 原理 | 效果 |
|---|---|---|
| 稻草·杂草覆盖 | 阻止地表水分蒸发，使土壤水分保持均匀 | 可拉长灌溉间隔，减少脐腐病 |
| 傍晚灌溉 | 蒸发损失较少 | 但要只浇在土壤上，避免叶片带水过夜 |
| 沟灌 | 水不会接触到叶片和果实 | 可防止炭疽病孢子飞溅传播 |
| 逐株滴灌 | 把瓶底钻孔的瓶子插入土中，让水缓慢渗出 | 用少量水只湿润根系所在的土层 |

&nbsp;&nbsp;&nbsp;在辣椒栽培中，覆盖既是节水的手段，也是防病的手段。炭疽病孢子会残留在土壤中的病残体上，随雨滴飞溅附着到下方的果实上。稻草覆盖住土壤表面后，这种飞溅就会被阻断。仅靠稻草覆盖就能让炭疽病的发生明显减少，原因就在于此，在没有薄膜的条件下，这个方法尤其具有价值。
