## 13. 採種 - 辛味が混じる問題

### 13-1. トウガラシの採種が易しい理由と難しい理由

&nbsp;&nbsp;&nbsp;トウガラシの自家採種等級はSです。トウガラシの花は一つの花の中に雌しべと雄しべがあり、花が開く前後に自分の花粉が自分の柱頭に触れて受精が終わる場合が多いです。赤トウガラシ一個に種が数十から数百粒入っているので、よく熟したものが数個あれば翌年の畑を満たせます。ここまでが易しい方です。

&nbsp;&nbsp;&nbsp;難しい方は二つです。一つは交雑で、もう一つは種子寿命です。

| 問題 | 内容 | 結果 |
|---|---|---|
| 交雑 | 自家受精が優勢ですが、ハチが花粉を運ぶ割合は条件によって2-50%に達します | 辛いトウガラシと甘いトウガラシが混じると、翌年の種から中間の辛味が出ます |
| 種子寿命 | 常温で1-2年、発芽力の低下が早いです | 数年分を一度に採っておく戦略が通用しません |

### 13-2. 辛味が混じる問題

&nbsp;&nbsp;&nbsp;私たちが育てる辛いトウガラシ、青トウガラシ、ピーマン、パプリカはすべてCapsicum annuumという一つの種です。種が同じなので交雑に何の障壁もありません。辛いトウガラシの隣でピーマンが花を咲かせ、ハチが行き来すると、その年のピーマンの種の一部は辛いトウガラシの花粉で受精したものになります。

> **その年に収穫した果実自体の味は変わりません。交雑の結果はその果実の種に記録され、翌年その種を植えたときに現れます。今年のピーマンが辛くなかったからといって、その種が安全なわけではありません。**

&nbsp;&nbsp;&nbsp;カプサイシンを作る能力は優性で遺伝します。そのため甘いトウガラシの雌しべが辛いトウガラシの花粉を受けると、その種から出た翌年の株は大抵辛くなります。反対方向、つまり辛いトウガラシが甘いトウガラシの花粉を受けた場合には辛味が保たれます。結果的に交雑が起きると甘いトウガラシの側だけが失われます。子供や高齢者が食べる甘いトウガラシを別に確保しようという計画はこのために崩れます。

| 方法 | 内容 | 現実性 |
|---|---|---|
| 隔離距離 | 他の系統と100-500m離します | 狭い土地ではほぼ不可能です |
| 時差栽培 | 一年に一系統だけ花を咲かせます | 種子寿命が1-2年なので容易ではありません |
| 個別袋がけ | 花が開く前に網や布の袋をかぶせておき、果実がついた後に外します | 最も確実で小規模に適しています |
| 全体網がけ | 採種用の株数本を網で覆います | 確実です。自家受精なので中で授粉作業が要りません |

&nbsp;&nbsp;&nbsp;トウガラシで網がけがケールより易しい理由がここにあります。ケールは自家不和合性なので網の中で人が筆で花粉を移さなければなりませんが、トウガラシは自家受精するのでかぶせてそのままにしておけばよいのです。採種する株二、三本に蚊帳や粗い布をかぶせておくだけで純度が守られます。果実がついた後は外してもかまいません。受精が終わっているからです。

&nbsp;&nbsp;&nbsp;最も簡単な解決法は最初から一系統だけ植えることです。辛いトウガラシだけ植えるか甘いトウガラシだけ植えれば交雑の問題は消えます。辛いものを食べられない人がいる場合、辛いトウガラシを少なめに入れて調理する方向で調整する方が、二系統を管理するより簡単な場合があります。

### 13-3. 採種の手順

| 段階 | 時期 | 内容 |
|---|---|---|
| 採種株の選抜 | 7月 | 病気がなく勢いが良く、品種特性が明確な株を選びます |
| 隔離 | 開花前 | 網をかぶせるか、他の系統と離します |
| 採種果の選定 | 7月下旬-8月 | 株の下の方、勢いが良い時期についた果実を選んで印をつけます |
| 完熟 | 9-10月 | 完全に赤くなり表面にしわが寄るまで置きます |
| 後熟 | 収穫後 | 陰で1-2週間置くと種がさらに熟します |
| 種子の分離 | 後熟後 | 果実を割り、胎座から種をこき取ります |
| 選別 | 分離直後 | 水に入れて浮くものを捨てます |
| 乾燥 | 分離後 | 陰で1-2週間、一層に広げて乾かします |
| 保管 | 完全乾燥後 | 密閉容器に乾燥剤と共に入れます |

> **種をこき取るとき素手で胎座に触れると、カプサイシンが手に染み込み数時間ヒリヒリします。目をこすると激しく痛み、石鹸で洗ってもなかなか取れません。布やビニールで手を覆い、作業後は油や牛乳で拭き取ってから洗います。**

### 13-4. 種子寿命と保管

&nbsp;&nbsp;&nbsp;評価表の種子寿命Cは、常温保管基準で1-2年、発芽力の低下が早いという意味です。これはトウガラシの種子が脂質をかなり含んでおり、酸化が進むためです。ただしこの寿命は保管条件に大きく左右されます。

| 条件 | 発芽力の維持 |
|---|:---:|
| 常温、密閉なし | 1年 |
| 常温、密閉+乾燥剤 | 2-3年 |
| 涼しく（10度以下）乾燥した場所、密閉 | 4-5年 |
| 凍らない低温、完全乾燥、完全密閉 | それ以上 |

&nbsp;&nbsp;&nbsp;したがって災害時にできることは明確です。種子を完全に乾かし、乾燥剤と共に密閉し、家の中で最も涼しい場所に置くことです。地中の穴蔵や北向きの壁の下、床下が候補です。そして毎年新しく種を採ることを欠かしません。ケールやカボチャのように一度採れば数年持つ作物とは違い、トウガラシは毎年続けて採らなければならない作物です。

| 項目 | 基準 |
|---|---|
| 目標水分 | 8%以下 |
| 乾燥剤 | 炒って冷ました米、炭、乾いた木灰 |
| 保管容器 | ガラス瓶、金属缶 |
| 発芽確認 | 毎年20粒を濡れた布に置き、10日後に発芽率を数えます |
| 発芽率基準 | 70%を下回ったら播種量を増やすか新しく採ります |

### 13-5. 種子消毒

| 方法 | 手順 | 効果 |
|---|---|---|
| 温湯浸漬 | 50-55℃の水に10-15分浸し、冷水で冷まします | 種子に付いた炭疽病菌と細菌を殺します |
| 選別 | 水に浸けて浮くものを捨てます | 病んだ種としいなが浮きます |
| 木灰粉衣 | 乾いた種子に細かい灰をまぶします | カビの抑制と湿気の遮断 |

&nbsp;&nbsp;&nbsp;トウガラシでは種子消毒が特に重要です。炭疽病菌が種子の表面や皮の下に付いて冬を越し、その種で育てた苗が翌年最初の感染源になるからです。温湯浸漬は道具なしでできる数少ない実質的な防除手段で、温度さえ守ればよいのです。60℃を超えると種が死に、45℃を下回ると菌が生き残ります。

## 14. 毒性と注意すべき成分

&nbsp;&nbsp;&nbsp;トウガラシに急性毒性はありません。カプサイシンは毒ではなく刺激物質で、人が日常的に食べる量では問題を起こしません。ただしその刺激の性質を理解しておくと様々な状況で役に立ちます。

| 成分 | どんな物質か | どんな問題になるか | 対応 |
|---|---|---|---|
| カプサイシン | 胎座で作られるアルカロイド。痛覚受容体を刺激します | 過剰摂取時に胃腸刺激、下痢。目や傷に触れると激しい痛み | 牛乳・油で拭き取ります。水ではなかなか取れません |
| ソラニン系 | ナス科共通の微量アルカロイド | 実質的な影響がない水準です | 対応は不要です |
| カビ毒 | 乾燥が不十分なトウガラシに生えたカビが作ります | 肝臓に有害な物質が生じることがあります | カビが生えたトウガラシは捨てます |

### 14-1. カプサイシンが水で落ちない理由

&nbsp;&nbsp;&nbsp;カプサイシンは油に溶けて水に溶けない物質です。そのため辛いものを食べて水を飲んでもほとんど効かず、牛乳や脂の多い食べ物の方がはるかに効きます。牛乳のカゼインタンパク質がカプサイシンを包み込み、受容体から引き離すからです。手に付いたときも同様に、まず食用油や牛乳で拭いてから石鹸で洗います。

> **トウガラシを扱った手で目をこすると非常に痛みます。洗ってもなかなか治らず、30分から1時間苦しみます。唐辛子粉を挽いたり種をこき取った後は必ず手を洗い、それまでは顔に触れません。**

### 14-2. カビが生えた干しトウガラシ

&nbsp;&nbsp;&nbsp;干しトウガラシで実際に危険なのはカプサイシンではなくカビです。乾燥が不完全な状態で密閉すると内部でカビが育ち、一部のカビは人に有害な毒素を作ります。この毒素は加熱しても壊れず、挽いて粉に混ざれば目にも見えません。

| 状態 | 判断 |
|---|---|
| 白い粉が薄く付いたように見える | カビの可能性があるので匂いを確認します |
| 湿っぽくかび臭い匂い | 捨てます |
| 黒や青の斑点 | 捨てます |
| 一部だけにカビが生えている | その部分を切り取るだけでは安全ではありません。胞子がすでに広がっています |

&nbsp;&nbsp;&nbsp;そのため15節の乾燥は単なる貯蔵のコツではなく、安全の問題になります。乾燥が不十分なトウガラシを惜しんでそのまま保管すると、結局全量を捨てることになります。

## 15. 冷蔵庫のない貯蔵 - 乾燥がすべてです

&nbsp;&nbsp;&nbsp;トウガラシの貯蔵性等級Sは、乾燥トウガラシの話です。生のトウガラシは他の果菜と変わらず、常温で1週間から2週間で傷みます。完全に乾かしたトウガラシは水分が12%未満に下がり、微生物が育てない状態になり、そのまま1年から2年もちます。

### 15-1. 乾燥方法

| 方式 | 条件 | 期間 | 特徴 |
|---|---|---|---|
| 陽干し（日干し） | 晴れて風のある日、すのこやござに広げるか糸に通して吊るします | 7-15日 | 最も古い方法で燃料がかかりません |
| 陰干し | 風通しの良い陰に吊るします | 15-30日 | 色が美しく残りますが時間がかかり、梅雨時には失敗します |
| 火干し | かまどの上、オンドルの暖かい場所、炉の脇の余熱 | 2-5日 | 湿った日でも可能で、燃料を別に使いません |
| 混合 | 日に数日干した後、仕上げを火の脇で | 5-10日 | 梅雨時に現実的です |

| 段階 | 方法 | 理由 |
|---|---|---|
| 1. 選別 | 病気がなく完全に赤くなったものだけ使います | 斑点があるものは乾燥中に広がります |
| 2. 水気を取る | 濡れていれば広げて一日乾かします | 濡れたまま積むと数時間でカビが生えます |
| 3. 広げる | 重ならないよう一層に広げるか糸に通して吊るします | 重なった部分が乾きません |
| 4. 裏返し | 一日に一、二回裏返します | 下側に湿気がこもります |
| 5. 夜間の管理 | 夜露に当たらないよう取り込むか覆います | 夜露で再び濡れると最初からやり直しです |
| 6. 判定 | 手で曲げるとポキッと折れ、振ると中で種の音がします | 曲がるならまだ乾燥不足です |
| 7. 保管 | 密閉容器や袋に入れて暗く涼しい場所に置きます | 光を受けると色が褪せます |

> **乾燥の判定基準は一つです。曲げて折れるかどうか。しなるならまだ乾燥不足で、その状態でしまうと一ヶ月以内にカビが生えます。惜しくても半日長く乾かす方がよいです。**

&nbsp;&nbsp;&nbsp;糸に通して吊るす方式には様々な利点があります。空間を縦に使うので場所を取らず、四方から風が通って均等に乾き、雨が降れば丸ごと取り込みやすいです。へた近くを針で通し、太い糸に次々と吊るします。軒下や壁に掛けておけば、そのまま冬まで保管になることもあります。

### 15-2. 干しトウガラシの保管

| 項目 | 基準 |
|---|---|
| 目標水分 | 12%以下 |
| 保管温度 | 低いほど良いです。常温なら1-2年 |
| 保管場所 | 暗く涼しく乾燥した場所。地中の穴蔵、北向きの壁の下 |
| 容器 | 甕、袋を二重にしたもの、密閉容器 |
| 乾燥剤 | 炭、炒って冷ました米、乾いた木灰 |
| 点検 | 月に一度開けて湿りとカビを確認します |
| 湿ってしまった時 | 日に半日再び干してからしまいます |
| 虫 | ノシメマダラメイガの幼虫が入り込みます。密閉と乾燥で防ぎます |

&nbsp;&nbsp;&nbsp;丸ごと保管するのと粉に挽いておくのと、どちらが良いかは条件によります。丸ごとの方がはるかに長持ちします。表面積が小さく酸化が遅く、香りも飛びにくいです。粉は使いやすいですが色が早く褪せ、香りが弱くなります。そのため丸ごと保管して使う分だけ挽く方式が原則です。臼や石臼でその都度挽きます。

### 15-3. 他の貯蔵方法

| 方法 | 内容 | 期間 |
|---|---|---|
| 塩漬け | 青トウガラシを塩水（10-15%）に漬けます | 数ヶ月。食べる前に水に浸して塩を抜きます |
| 醤油漬け | 青トウガラシを煮て冷ました醤油に漬けます | 数ヶ月-1年 |
| 発酵トウガラシ | 塩水に漬けて乳酸発酵させます | 数ヶ月。酸味が出て柔らかくなります |
| コチュジャン | 唐辛子粉に穀物の澱粉とメジュ（味噌玉）の粉、塩を入れて発酵させます | 数年 |
| 唐辛子油 | 油に唐辛子粉を入れて加熱した後、濾しておきます | 数ヶ月。油がなければできません |

&nbsp;&nbsp;&nbsp;青トウガラシを塩に漬ける方式は、赤く熟させにくい年に特に役立ちます。炭疽病が広がって熟させられないなら、青トウガラシの状態で摘んで漬けます。調味料としての働きは唐辛子粉より弱いですが、塩辛い惹菜としては十分で、何より乾燥に失敗した年の保険になります。

## 16. 調理と加工 - 調味料であり防腐剤

| 用途 | 方法 | 燃料 |
|---|---|---|
| 唐辛子粉 | 干しトウガラシのへたを取り、臼や石臼で挽きます | なし |
| 丸干しトウガラシ | 汁物に丸ごと入れてから取り出します | 他の調理と併用 |
| 青トウガラシの生食 | 洗ってそのまま、テンジャンや醤に付けます | なし |
| 唐辛子油 | 油に唐辛子粉を入れて弱火で煮出します | 少ない |
| コチュジャン | 穀物とメジュの粉と塩を混ぜて発酵させます | 穀物を煮るときだけ |
| キムチの薬味 | 唐辛子粉と塩と野菜を和えます | なし |

&nbsp;&nbsp;&nbsp;評価表の調理・加工SSは加熱が不要という意味です。干しトウガラシを挽いてすぐ使えるので燃料は0です。大豆を8時間浸して1時間煮なければならず、穀物も煮なければならない状況で、燃料なしに食べ物の味を変えられる材料は貴重です。

### 16-1. 防腐効果

&nbsp;&nbsp;&nbsp;カプサイシンには抗菌作用があります。細菌やカビの細胞膜を乱して増殖を遅らせ、特に食中毒を起こすいくつかの菌に効果があります。暑い気候の料理に香辛料が多く使われる理由がここにあり、キムチが冬を越すのにトウガラシが貢献する部分もここにあります。

> **ただしトウガラシが傷んだ食べ物を元に戻すわけではありません。腐敗を遅らせるだけで、すでに傷んだものを辛い薬味で覆うと傷んだ匂いに気づけず、より危険になります。防腐効果は最初から入れていた場合の話です。**

### 16-2. 虫を追い払う用途

&nbsp;&nbsp;&nbsp;評価表の非食用価値Dは、8項目のうち害虫防除一つを満たした結果で、その根拠がカプサイシンです。哺乳類と昆虫はいずれもカプサイシンを避けます。

| 用途 | 方法 | 対象 |
|---|---|---|
| 貯蔵穀物の保護 | 穀物の袋や甕に干しトウガラシを数個入れます | コクゾウムシ、ノシメマダラメイガ |
| 種子保管 | 種子容器に干しトウガラシ一切れを入れます | 穀物害虫 |
| 畑の忌避剤 | 干しトウガラシを水に一日浸し、濾して薄めて撒きます | 柔らかい虫、カメムシ |
| ネズミ・獣の忌避 | 唐辛子粉を通り道に撒きます | ネズミ、モグラ |
| 種子コーティング | 播種する種に唐辛子粉をまぶします | 鳥とアリ |

&nbsp;&nbsp;&nbsp;貯蔵穀物の甕に干しトウガラシを入れるのは古くからの方法で、災害時に特に価値があります。米や豆を長く保管するとき最大の損失は虫で、殺虫剤がない条件で使える手段は多くありません。干しトウガラシと炭とニンニクを一緒に入れて密閉する組み合わせが伝統的に使われてきました。トウガラシは虫を殺しはしませんが、入り込むのを遅らせ、すでに入った虫の増殖を抑えます。

### 16-3. 辛味を調節する方法

&nbsp;&nbsp;&nbsp;複数人で一緒に食べる条件では辛味の調節は実質的な問題です。カプサイシンが胎座に集まっている事実がここで使われます。丸干しトウガラシを使う際、中の白い芯と種を振り落とすと辛味が大きく減ります。反対に辛味を強くしたければ胎座ごと挽きます。唐辛子粉を作るとき胎座を入れるか抜くかで、同じトウガラシから二種類の粉が得られます。油で煮出した唐辛子油は、カプサイシンが油に良く溶けるため少量でも辛くなります。

## 17. 年間作業スケジュール

| 月 | 作業 |
|---|---|
| 1月 | 種子を点検し発芽率を確認します。温床の材料を集め支柱を整えます |
| 2月 | 韓国中部は中旬から下旬、南部は初旬から中旬に播種します。温床の発熱を始めます |
| 3月 | 育苗を管理します。本葉3-4枚で一度移植します。畑に石灰を入れます |
| 4月 | 堆肥と元肥を入れ、畝を高くします。韓国南部は下旬に定植します。硬化を始めます |
| 5月 | 韓国中部は上旬から中旬に定植し、同時に支柱を立てます。わらマルチを敷きます |
| 6月 | 一番花の下のわき芽を取り、最初の実を摘み取ります。追肥1回目。中旬から青トウガラシの収穫 |
| 7月 | 梅雨時の排水点検。炭疽病の予察と病んだ実の即時除去。追肥2回目。下旬から赤トウガラシの収穫 |
| 8月 | 赤トウガラシを7-10日おきに収穫し乾かします。追肥3回目。採種果に印をつけます |
| 9月 | 赤トウガラシの収穫と乾燥が続きます。追肥4回目。採種果の完熟を待ちます |
| 10月 | 収穫を終え、残った青トウガラシは漬けます。採種果を収穫して後熟させます |
| 11月 | 株を抜き、病んだ残渣を焼きます。種子を精選して保管します。干しトウガラシを取り込みます |
| 12月 | 干しトウガラシの状態を点検します。翌年の場所を決めます |

&nbsp;&nbsp;&nbsp;この表で最も緊張する欄は7月です。梅雨と炭疽病と最初の赤トウガラシの収穫が一ヶ月に重なります。この月に排水路を整え病んだ実をこまめに取り除くか、それとも手を抜くかによって8月と9月の収穫量が分かれます。そしてこの月に、赤く熟させるか青いうちに摘んでしまうかを決めることになります。

&nbsp;&nbsp;&nbsp;11月の残渣処理も軽くありません。病んだ茎と実が畑に残ると、それが翌年最初の感染源になり、薬がない条件ではその差が大きく現れます。トウガラシは植えることより取り除くことで翌年が決まる作物です。
