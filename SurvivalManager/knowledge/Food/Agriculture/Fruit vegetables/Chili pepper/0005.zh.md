## 8. 栽培管理 - 侧芽与绑蔓

### 8-1. 第一分枝点以下的抹芽

&nbsp;&nbsp;&nbsp;辣椒和茄子一样，会在某个节位开出第一朵花，并在该处分杈。这个最初的分杈点就是第一分枝点，清除该点以下长出的侧芽，是辣椒栽培中的第一项管理作业。

| 项目 | 内容 |
|---|---|
| 时期 | 定植后30-40天，侧芽长到拇指长短时 |
| 对象 | 第一分枝点以下长出的所有侧芽 |
| 方法 | 用手轻轻向侧面折断摘除 |
| 理由 | 下部侧芽几乎不开花，却会消耗养分，还会在贴近地面处阻碍通风 |
| 注意 | 侧芽太小就摘除，会导致光合作用面积不足，使初期生长变慢 |

&nbsp;&nbsp;&nbsp;叮嘱不要过早摘除，是有原因的。在幼株上，下部侧芽的叶片同样参与光合作用。等侧芽长到手指长短、自身开始消耗养分时，才是摘除的时机，在此之前留着不动更好。

&nbsp;&nbsp;&nbsp;第一分枝点以上的部分与茄子不同。茄子会整理成三条主枝，而辣椒通常保持原样不动。这是因为辣椒每个节位都会开花，减少茎数就会连带减少花数。不过，钻入株丛内部相互重叠的茎，以及垂到接近地面的茎，仍需疏剪。目的不是调节产量，而是通风。

> **在没有药物的条件下，给辣椒整枝不是为了让果实长大，而是为了让风穿过株丛内部。湿气滞留的地方，就是炭疽病开始的地方。**

### 8-2. 摘除第一个果实

&nbsp;&nbsp;&nbsp;在第一分枝点上结出的第一个果实，趁小摘掉的诀窍与茄子相同。体型尚小的植株若把养分集中供给这一个果实，茎和根就长不好，带着这种状态进入夏天，总产量就会下降。趁第一个果实还只有手指大小时摘掉，这部分养分就能用来壮大植株，长大后的植株会结出多得多的果实。

### 8-3. 绑蔓

| 方法 | 内容 | 特点 |
|---|---|---|
| 单株绑蔓 | 每株立一根支架并绑住茎秆 | 简单，但向侧面伸展的枝条会下垂 |
| 双侧绑蔓 | 在垄两侧立支架，拉两三层绳把植株围住 | 可同时支撑多株 |
| X形绑蔓 | 交叉立起1.8m的支架，在交叉点架横杆 | 通风与支撑效果都很好 |

&nbsp;&nbsp;&nbsp;在辣椒栽培中，绑蔓不是可选项。挂了果的辣椒一旦被台风或阵雨吹倒，果实就会接触泥土，而接触泥土的果实几乎无一例外会感染软腐病或炭疽病。而且倒伏的植株一旦被重新扶起，浅根就会被拉断，无法恢复。支架应在定植的同时立起，并根据茎秆生长的速度，到7月为止分两三次绑扎。

&nbsp;&nbsp;&nbsp;绳子可以用稻草搓的草绳、葛藤、麻布条，或撕开旧衣服做成的布条来代替。捆绑时要以"8"字形缠绕，避免勒紧茎秆，并考虑到茎会变粗而留出余量。支架只要在冬天砍下地边笔直的树枝晾干备用，每年都能自行准备。评价表中的设施负担D，指的正是这项每年都要做的工作。

### 8-4. 不用薄膜做防雨设施的方法

&nbsp;&nbsp;&nbsp;在炭疽病对策中，效果最大的是防雨设施。原理很简单：雨滴不直接打在果实上，孢子附着的机会就会减少。问题在于没有薄膜这个条件。

| 替代方法 | 原理 | 局限 |
|---|---|---|
| 屋檐下·墙根下种植 | 在雨淋较少的地方种几株 | 面积小，光照可能不足 |
| 草苫屋顶 | 把稻草编好搭在垄上 | 遮光较多，淋雨后会变重 |
| 木板·瓦片 | 只盖在果实集中的部位上方 | 只能局部覆盖 |
| 稻草覆盖 | 阻止雨滴从地面溅起 | 无法阻挡从上方落下的雨 |
| 调整垄的方向 | 顺着风向做垄，使其更快变干 | 效果有限 |

&nbsp;&nbsp;&nbsp;没有完全的替代方案。把稻草覆盖、加宽种植间距和抗病品种叠加使用是较现实的组合，即便如此，遇上韩国的梅雨季（6月下旬至7月）漫长而潮湿的年份，也难以避免损失。因此，在房屋周围屋檐下或墙根下这类雨淋较少的地方另外种上几株，是一种切实的保险安排。即使整块地全军覆没，也能从这几株上留到来年的种子。

## 9. 病虫害 - 炭疽病这堵墙

### 9-1. 主要病害

| 病名 | 症状 | 发生条件 | 无药应对方法 |
|---|---|---|---|
| 炭疽病 | 成熟中的果实上出现水浸状圆形病斑，凹陷并生出黑色孢子堆 | 梅雨季高温多湿，雨后 | 没有治疗药物。立即摘除病果并烧毁。抗病品种、防雨设施、稻草覆盖 |
| 疫病 | 茎基部呈暗褐色缢缩，植株急速萎蔫死亡 | 过湿、排水不良、积水处 | 高垄与排水沟是唯一的结构性对策。立即清除病株 |
| 细菌性斑点病 | 叶片上出现水浸状小斑点，随后变为褐色 | 多湿、风雨过后 | 预防性喷施波尔多液，保持通风 |
| 病毒病 | 叶片出现斑驳并卷缩，果实畸形 | 由蚜虫·蓟马传播 | 无法治疗。防治传毒昆虫并清除病株 |
| 灰霉病 | 花朵和果实上长出灰色霉菌并腐烂 | 低温多湿、通风不良 | 清除凋谢的花朵，保持通风 |
| 青枯病 | 白天萎蔫、清晨恢复，反复多次后死亡 | 高温、土传 | 无法治疗。清除病株并长期轮作 |
| 白粉病 | 叶片覆盖白粉，随后脱落 | 干燥与高湿交替出现时 | 稀释牛奶液、稀释小苏打液 |

### 9-2. 单独了解炭疽病

&nbsp;&nbsp;&nbsp;炭疽病由Colletotrichum属真菌引起。这种病菌依附在地里残留的病残体和种子上越冬，到春天产生孢子，伺机而动。感染发生在果实表面凝结水珠的状态下，只要25-30℃的温度和潮湿的表面持续几个小时，孢子就会萌发并穿透果皮侵入。梅雨季正好符合这个条件。

&nbsp;&nbsp;&nbsp;这种病害特别棘手，是因为存在潜伏感染。病菌在青辣椒还很幼嫩时就已侵入，却不表现症状，静静等待时机。等到果实成熟转红、组织变软、糖分增多时，才开始活动并形成病斑。因此，看起来完好无损的地块，会从红辣椒开始成熟之时起，短短几天内就全面崩溃。一旦已经感染，任何措施都为时已晚。

> **炭疽病无法治疗。正是这一事实，造就了评价表中防治自立度D这个等级。能做的只有减少感染本身，而手段有五个：抗病品种、防雨设施、稻草覆盖、加宽间距、立即清除病果。**

| 手段 | 效果 | 资材负担 |
|---|:---:|---|
| 抗病品种 | 大 | 关键在于获得种子 |
| 防雨设施 | 大 | 需要覆盖材料 |
| 稻草覆盖 | 中 | 用稻草·杂草即可解决 |
| 加宽种植间距 | 中 | 不需要资材 |
| 立即清除病果 | 中 | 很费人工 |
| 焚烧田间残株 | 中 | 可减少来年的传染源 |
| 种子温汤消毒 | 小-中 | 可减少经由种子的传染 |
| 提早采收（以青辣椒为主） | 大 | 代价是放弃辣椒粉 |

&nbsp;&nbsp;&nbsp;最后一项在现实中是最可靠的规避办法。炭疽病侵袭的是正在成熟的果实，所以只要在成熟之前就摘掉，病害就没有可发作的对象。预计梅雨季会较长的年份，不执着于红辣椒、持续采收青辣椒的判断，能减少整体损失。不过这样一来当年的辣椒粉就要放弃，因此也需要利用耐储性S级的特点，提前留出前一年收获的干辣椒作为备用。

### 9-3. 主要害虫

| 害虫 | 危害 | 无药应对方法 |
|---|---|---|
| 蚜虫 | 吸食新芽和叶背的汁液，并传播病毒 | 喷洒肥皂水，用手捏死，保护瓢虫·草蛉 |
| 蓟马 | 在花朵和幼果上造成伤痕，并传播病毒 | 使用蓝色粘虫板，稻草覆盖，清除周边杂草 |
| 烟青虫 | 幼虫钻入果实内部，啃食种子和胎座 | 立即摘除并处理有虫孔的果实，幼虫用手捉除 |
| 红蜘蛛 | 在叶背吸食汁液，使叶片变白 | 用水用力喷洒叶背。干燥时会加重 |
| 蝽象 | 吸食果实汁液，导致该部位变硬 | 清晨用手捉除 |

&nbsp;&nbsp;&nbsp;烟青虫值得单独一提。幼虫会在果蒂附近咬出孔洞钻入内部，取食胎座和种子。一旦钻进去，喷药也无法触及。在没有药物的条件下，唯一能做的就是一发现有虫孔的果实就立即摘除处理，由于里面的幼虫会长大并繁殖下一代，摘下的果实要踩碎或烧毁。

### 9-4. 无药自制的防治剂

| 防治剂 | 制作方法 | 用途 | 注意 |
|---|---|---|---|
| 波尔多液 | 将1kg硫酸铜和1kg生石灰分别溶解冷却后混合，用水稀释至100L | 预防细菌性斑点病·疫病 | 属预防剂。高温期用得过浓会烧叶 |
| 肥皂水 | 将20g无香型肥皂溶于1L水中 | 蚜虫·红蜘蛛 | 需喷到叶背才有效果 |
| 稀释牛奶液 | 将牛奶与水按1:1至1:2混合 | 白粉病 | 干燥过程中会压制并附着菌丝 |
| 草木灰 | 把过筛的草木灰轻轻撒在叶片和土壤上 | 驱避害虫，补充钾肥 | 会被雨水冲走 |
| 木醋液 | 稀释300-500倍使用 | 驱避害虫，激活微生物 | 原液呈强酸性 |
| 蛋黄油 | 将1个蛋黄与60mL食用油混合乳化后，兑入20L水中 | 白粉病·红蜘蛛 | 在油料稀缺的条件下难以使用 |

### 9-5. 农业防治

| 方法 | 原理 |
|---|---|
| 轮作 | 茄科作物间隔5-7年轮种，降低土传病害的密度 |
| 高垄与排水沟 | 切断疫病游动孢子的传播路径 |
| 加宽种植间距 | 通过通风让叶片和果实更快变干 |
| 稻草覆盖 | 阻止雨滴从地面溅起 |
| 立即清除病果·病株 | 减少田间的传染源 |
| 收获后焚烧残株 | 消除来年的初次传染源 |
| 种子温汤消毒 | 杀死附着在种子上的病菌 |
| 垄的方向顺应风向 | 使叶片和果实更快变干 |

&nbsp;&nbsp;&nbsp;收获后的残株处理不可轻视。炭疽病菌会在地里残留的病果和茎秆上越冬，成为来年最初的感染源。如果拉秧后地里还散落着病果，来年病害就会来得早得多。把清理出的茎秆和果实就地焚烧，或运出田外处理，这项工作占了来年防治工作的一半。

## 10. 营养缺乏与过量

| 症状 | 原因 | 用天然材料采取的措施 |
|---|---|---|
| 从下部叶片开始整株发黄，植株矮小 | 氮缺乏 | 将尿液稀释10-15倍浇入沟中，或施入腐熟堆肥 |
| 叶片边缘呈褐色焦枯，果实变小 | 钾缺乏 | 每株混入一把草木灰入土 |
| 生长缓慢，叶背和茎呈紫色 | 磷缺乏 | 骨粉、草木灰。低温期土壤偏冷，有时也会吸收不良 |
| 果实顶端发黑凹陷腐烂 | 钙运输障碍（脐腐病） | 均匀灌溉与覆盖是根本对策。可辅以烧制的贝壳粉 |
| 开花后随即脱落 | 硼缺乏、高温、氮过量、缺水 | 原因不止一个，需按顺序逐一排查 |
| 只有叶脉之间发黄，叶脉本身仍为绿色 | 镁缺乏 | 白云石粉，使堆肥原料多样化 |
| 只见叶片繁茂浓绿，开花却很少 | 氮过量 | 停止施氮，用草木灰补充钾 |
| 果实颜色浅且出现斑驳 | 钾不足或日照不足 | 施入草木灰，并疏剪重叠的茎 |

&nbsp;&nbsp;&nbsp;在辣椒栽培中最常遇到的就是脐腐病。名字里虽然带"病"字，但它不是病原菌引起的病害，而是钙无法送达果实末端而产生的生理性障碍。钙是随水流移动的元素，土壤反复干湿交替就会中断这种流动。尤其是在果实快速膨大的时期，一旦有一次严重缺水，那个时期正在长大的果实就会集体出现症状。

> **看到脐腐病就多施钙，通常是白费力气。土壤缺钙的情况很少见，问题出在水分的流动上。用覆盖手段让土壤水分保持均匀，才是切实有效的解决办法。**

&nbsp;&nbsp;&nbsp;落花现象的原因不止一个，需要按顺序排查。第一看气温，如果连续出现超过35度的日子，高温就是原因，人力能做的不多。第二看土壤，如果干了，就是缺水。第三看植株，如果叶片浓绿茂盛，就是氮过量。第四看日照，如果因梅雨而阴天连连，就是光合作用不足。确认完这四项之后，才轮到怀疑硼缺乏。

## 11. 间作与轮作

### 11-1. 搭配关系

| 搭配关系 | 对象 | 理由 |
|:---:|---|---|
| 好 | 豆科作物（菜豆·豇豆） | 能固氮并留在土壤中 |
| 好 | 金盏花（万寿菊） | 可抑制根结线虫 |
| 好 | 大葱·大蒜·韭菜 | 硫化物能降低土壤病原菌的密度 |
| 好 | 紫苏（荏）·紫苏 | 浓烈的气味会扰乱害虫 |
| 差 | 茄子·番茄·马铃薯 | 会完全共享疫病和青枯病 |
| 差 | 玉米 | 会遮荫，且养分竞争激烈 |
| 差 | 葫芦科（南瓜·黄瓜） | 藤蔓覆盖会阻碍通风 |

&nbsp;&nbsp;&nbsp;在辣椒垄间套种紫苏（荏），是自古以来常见的做法。紫苏（荏）浓烈的气味会干扰害虫寻找寄主，紫苏（荏）本身也可作叶菜和种实使用。不过紫苏（荏）长大后会遮挡辣椒的阳光，所以放在垄的两端或地块边缘更好。把大葱和大蒜种在辣椒之间也是同样的思路，这两种植株低矮，不存在遮荫的问题。

### 11-2. 轮作

| 年份 | 作物 | 目的 |
|---|---|---|
| 第1年 | 辣椒 | |
| 第2年 | 豆科（大豆·菜豆·豇豆） | 恢复氮素，切断茄科病原菌的食物来源 |
| 第3年 | 葱属（大葱·大蒜·洋葱） | 用硫化物抑制土壤病原菌 |
| 第4年 | 谷物（玉米·高粱·粟） | 归还有机质，改变根系分布深度 |
| 第5年 | 叶菜类或根菜类 | |
| 第6年以后 | 重新种植辣椒 | |

&nbsp;&nbsp;&nbsp;在狭小的土地上很难做到5到7年的休作。因此对辣椒而言，轮换种植地点是现实可行的替代方案。辣椒只需20到30株就能满足一户人家一年的消耗，所以不必占用大块田地，而是可以每年在房屋周围和地块边缘轮换位置种植。这样一来，病原菌就不会在同一片土壤中累积，还可以挑选屋檐下这类雨淋较少的位置。

> **在同一个地方连续种辣椒3年以上，起初看似无恙，某一年却会突然因疫病死掉一半。土壤病原菌是悄悄积累，然后一次性爆发的。轮换地点是要在发病之前做的事，而不是发病之后。**

&nbsp;&nbsp;&nbsp;辣椒之后种什么，也是需要考虑的问题。辣椒在四个月的生长期内会消耗大量养分，并在残株中留下病原菌。豆科之所以是第一候选，是因为它既能恢复氮素，又不会成为茄科病原菌的寄主。葱属之所以是第二候选，是因为根部释放的硫化物能改变土壤微生物构成，降低病原菌密度。在拔掉辣椒的地方种上大蒜过冬，是一种既不让土地闲置、又能获得消毒效果的方法。

## 12. 收获 - 青辣椒与红辣椒

| 用途 | 采收时期 | 标准 |
|---|---|---|
| 青辣椒 | 开花后20-30天 | 长到应有大小、果皮有光泽时 |
| 红辣椒（用于晒干） | 开花后45-50天 | 转为深红色、表面开始起皱时 |
| 采收间隔 | 青辣椒3-5天，红辣椒7-10天 | |
| 采收时间 | 清晨，露水干后 | 带露水采摘会在贮藏期间发霉 |
| 采摘方法 | 保留果蒂，用手掰下或用剪刀剪下 | 避免撕裂茎秆 |

### 12-1. 收哪一种

&nbsp;&nbsp;&nbsp;青辣椒和红辣椒不是不同的作物，而是同一果实的不同阶段，所以收哪一种是一个选择问题。这个选择会让当年的损益产生很大差别。

| 项目 | 青辣椒 | 红辣椒 |
|---|---|---|
| 采收时间点 | 较早（从6月中旬起） | 较晚（从7月下旬起） |
| 暴露于炭疽病的时间 | 短 | 长。这种病害侵袭正在成熟的果实 |
| 贮藏 | 几乎不可能。常温下1-2周 | 晒干后可存1-2年 |
| 维生素C | 保留完好 | 在干燥过程中大部分流失 |
| 植株的寿命 | 持续采摘就能不断开新花 | 让其成熟会使植株提早衰弱 |
| 用途 | 当场食用的小菜 | 全年使用的调味料 |

> **下部的果实作为青辣椒采摘，上部的果实留作红辣椒成熟，这样的安排最为均衡。下部靠近地面，炭疽病风险大；上部光照和通风好，能安全成熟。**

&nbsp;&nbsp;&nbsp;预计梅雨季会较长的年份，判断要提前做出。正在成熟的果实一旦染病脱落就什么都不剩，但作为青辣椒采摘的话，至少能保住那部分重量。相反，干旱的年份则应提高红辣椒的比例，确保一年所需的辣椒粉。这个判断要在7月上旬做出，也是辣椒种植中最重要的决定。

### 12-2. 采收要领

&nbsp;&nbsp;&nbsp;采摘红辣椒时要连着果蒂一起摘，是有原因的。摘掉果蒂后留下的伤口会让霉菌侵入，晒干过程中会从那个位置开始变黑。带着果蒂晾晒，因为入口被封住，干燥过程会更稳定。晒干之后、磨粉之前再把果蒂摘掉即可，这时辣椒已经完全干透，用手就能轻松摘除。

&nbsp;&nbsp;&nbsp;在露水干后采摘也是一项原则。把带露水的辣椒直接堆放，几个小时内就会开始发霉。雨后至少要等半天，最好等一整天。如果必须采摘被雨淋湿的果实，要先摊开晾去水气，再进入晒干环节。

&nbsp;&nbsp;&nbsp;病果要单独摘出并带出田外。如果和好果混装，孢子会在搬运过程中沾染扩散，并在晾晒架上传染给旁边的辣椒。带有炭疽病斑点的辣椒即使晒干，病斑部位也会持续扩散，最终导致整批报废。
