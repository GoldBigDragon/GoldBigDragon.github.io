## 2. どんな植物か

### 2-1. 分類と原産地

&nbsp;&nbsp;&nbsp;トウガラシはナス科(Solanaceae)トウガラシ属(Capsicum)の植物です。学名はCapsicum annuumで、annuumは一年生という意味ですが、実際には熱帯では多年生として育ちます。韓国の気候で一年生になるのは、単に冬を越せないからです。トウガラシ属には栽培種が五つあり、私たちが育てているものはほぼ全てCapsicum annuumです。残りはCapsicum frutescens（タバスコ）、Capsicum chinense（ハバネロ）、Capsicum baccatum、Capsicum pubescensです。

| 種 | 代表 | 韓国での栽培 | 交雑 |
|---|---|---|---|
| Capsicum annuum | 在来トウガラシ、ピーマン、パプリカ、ハラペーニョ | ほとんど | 同じ種同士で完全に交雑します |
| Capsicum frutescens | タバスコ | まれ | annuumと部分的に交雑します |
| Capsicum chinense | ハバネロ、ブートジョロキア | まれ | annuumと部分的に交雑します |

> **ここで必ず覚えておくべき事実があります。私たちが育てる辛いトウガラシ、青唐辛子、ピーマン、パプリカは全て同じ種です。同じ畑に植えると互いに花粉をやり取りし、そうして受粉した種からは翌年、辛味と甘味が入り混じったものが生まれます。**

&nbsp;&nbsp;&nbsp;ナス科に属するという事実も、実際の作業にそのまま影響します。トウガラシはナス、トマト、ジャガイモと疫病・青枯病・萎凋病・ウイルス病を共有します。ジャガイモを掘った跡地にトウガラシを植えると、ジャガイモ由来の疫病菌がトウガラシを襲い、トウガラシを抜いた跡に翌年トマトを植えると同じことが繰り返されます。評価表の連作適応性Dはここから来ています。

&nbsp;&nbsp;&nbsp;原産地はメキシコからボリビアに至る中南米の熱帯高原です。この出自が栽培条件を決めています。第一に、高温性のため10度以下で生育が止まり、霜で枯れます。第二に、雨季と乾季がはっきりした地域の植物なので、根が浅く広く張ります。第三に、野生では鳥が果実を食べて種を広めていました。この第三の事実がカプサイシンの存在理由を説明します。哺乳類はカプサイシンに痛みを感じ、歯で種を砕いてしまいますが、鳥はカプサイシン受容体が異なるため辛味を感じず、種をそのまま排泄します。トウガラシの辛味は、哺乳類を遠ざけ鳥を呼び寄せるための仕掛けです。

### 2-2. 形態

| 器官 | 特徴 |
|---|---|
| 葉 | 広い卵形または披針形で、縁は滑らかです。葉の表面には光沢があります |
| 茎 | まっすぐに立ち、下部が木質化します。ある節で二又または三又に分かれ、この最初の分岐点を一番分枝点といいます。高さ60-100cm |
| 根 | まっすぐな主根がありますが、移植の過程で切れて細根が表土20cm以内に集中します。典型的な浅根性です |
| 花 | 白色の小さな花が、節ごとに一輪か二輪ずつ下を向いて咲きます。自家受粉が優勢です |
| 果実 | 漿果です。最初は緑色で、熟すにつれて赤、黄、オレンジ色に変わります。中は空洞で、胎座に種がついています |
| 種子 | 直径3-4mmの平たい円盤形で、淡い黄色をしています。胎座についています |

&nbsp;&nbsp;&nbsp;トウガラシの果実の構造を知っておく必要があります。中は空洞で、真ん中に白い芯のような組織があり、そこに種がついています。この白い組織が胎座で、カプサイシンの大部分はここで作られます。種そのものは辛くなく、胎座に触れているために辛くなります。辛味を減らしたいなら、種ではなく胎座を取り除く必要があるということです。

&nbsp;&nbsp;&nbsp;トウガラシの分枝構造はナスに似ています。茎はある節まで伸びると最初の花を咲かせ、その場所で二、三本に分かれ、分かれた茎がまた同じことを繰り返します。そのためトウガラシ一株は、上に行くほど密になる傘のような形になります。この構造が第8節の整枝方法を決めています。

&nbsp;&nbsp;&nbsp;根が浅いことが、トウガラシ栽培における最大の物理的制約です。表土20cm以内に根が集中しているため、その層が乾けばすぐに水不足になり、その層に水がたまればすぐに呼吸ができなくなります。しかも根が浅いので風で倒れやすくなります。支柱が欠かせない理由は二つ、重さと浅い根です。

### 2-3. 生育段階

| 段階 | 時期 | 主な生理 | 重要な養分 |
|---|---|---|---|
| 育苗期 | 播種から定植まで（70-80日） | 本葉5-7枚まで育ちます。最初の花蕾が見える頃が定植の適期です | 窒素、リン酸 |
| 定植・活着期 | 定植後1-2週間 | 切れた根の代わりに新しい根が出ます。見た目には育たないのが正常です | リン酸 |
| 栄養生長期 | 定植後2-5週間 | 茎が太くなり、一番分枝点が形成されます | 窒素 |
| 開花・着果期 | 定植後40-50日 | 一番分枝点で最初の花が咲きます。以降は節ごとに花が続きます | リン酸、ホウ素、カルシウム |
| 肥大・緑熟期 | 開花後20-30日 | 果実が本来の大きさまで大きくなります。この状態が青唐辛子です | カリウム |
| 着色・完熟期 | 開花後45-50日 | 緑色から赤色に変わり、カプサイシンと色素が蓄積します | カリウム |

> **青唐辛子と赤唐辛子は別の果実ではなく、同じ果実の異なる時点です。開花後20-30日で青唐辛子として食べられ、そのままにしておけば45-50日で赤くなります。どちらを収穫するかは、その年の病気の状況と必要に応じて決める判断です。**

&nbsp;&nbsp;&nbsp;この区別は災害時に実質的な意味を持ちます。青唐辛子として摘めば収穫が早く、炭疽病の危険な時期を過ぎる前に収穫できますが、乾燥させて貯蔵することはできません。青唐辛子は水分が多いため、乾燥させると色が黒っぽくなり品質が落ちます。赤唐辛子として熟させれば乾燥させて1年貯蔵できますが、その分畑に長く置く必要があり、炭疽病にさらされる期間も長くなります。しかも一株で赤唐辛子を熟させると、その株は種を作るために養分を注ぎ込み、新しい花が減ります。青唐辛子を摘み続ければ株は長く働き、赤唐辛子を熟させれば株は早く疲れます。

&nbsp;&nbsp;&nbsp;カプサイシンが蓄積する時期も知っておく価値があります。カプサイシンは果実が大きくなる間ずっと作られ続け、着色期に最も多くなります。そのため同じ品種でも青唐辛子より赤唐辛子の方が辛く、完全に熟して表面にしわが寄ったものが最も辛くなります。水が不足する条件で育ったトウガラシがより辛くなることも知られており、ストレスが防御物質の生産を増やすためです。

### 2-4. 100gあたりの栄養

| 栄養素 | 生トウガラシ（赤色） | 乾燥トウガラシ | 備考 |
|---|:---:|:---:|---|
| 熱量 | 85kcal | 280-330kcal | 乾燥で水分が抜けて濃縮されます |
| 水分 | 約70g | 10-13g | 乾燥の目標はこの数値です |
| タンパク質 | 3.12g | 10-13g | 熱量に対して14.7%です |
| 炭水化物 | 約18g | 55-60g | 糖類実測5.48g |
| 食物繊維 | 4-5g | 25-30g | 乾燥トウガラシは食物繊維の塊です |
| ビタミンC | 44-78mg | ほとんど消失 | 乾燥と加熱でほぼ失われます |
| ビタミンA（β-カロテン） | 高い | 非常に高い | 赤色のかなりの部分はカロテノイドによるものです |
| ビタミンE | 含有 | 含有 | 脂溶性のため乾燥に比較的強いです |
| カリウム | 含有 | 高い | 濃縮されます |
| カプサイシン | 品種により0-0.5% | 濃縮 | 胎座に集中しています |
| カプサンチン | 赤い果皮 | 濃縮 | 唐辛子粉の赤い色素です |

&nbsp;&nbsp;&nbsp;この表で注目すべきは、ビタミンCの運命です。生のトウガラシ100gに含まれるビタミンCは44-78mgと非常に高い水準で、これが微量栄養素S等級の主な根拠です。ところがこのビタミンは、乾燥させて挽く過程でほぼ全て失われます。ビタミンCは熱と酸素と光に弱い物質で、天日で数日干して乾燥させる過程は、そのすべてにさらされる過程です。

> **トウガラシをビタミンCの供給源として使うには、生で食べる必要があります。夏に青唐辛子をテンジャン（韓国味噌）につけて食べる方法が、トウガラシのビタミンCを実際に得る唯一の道であり、冬の唐辛子粉には期待できるものがありません。**

&nbsp;&nbsp;&nbsp;反対に、β-カロテンやカプサンチンのようなカロテノイドは脂溶性のため、乾燥にはるかに強いです。乾燥トウガラシの赤色がそのまま残っているということは、これらの色素が生きているという意味であり、油と一緒に調理すれば吸収されます。冬に唐辛子粉が寄与する栄養は、ビタミンCではなくビタミンAの方です。

&nbsp;&nbsp;&nbsp;乾燥トウガラシの熱量が100gあたり280kcalを超えるという点は、勘違いを招きやすいものです。この数字だけを見れば熱量作物のように見えますが、人は乾燥トウガラシを100gも食べたりしません。1日10-30gが現実的な量で、それなら30-90kcalです。1日の必要量の2-4%です。乾燥で濃縮されるのは熱量だけでなくカプサイシンも同じなので、たくさん食べることはできません。

## 3. 栽培環境

### 3-1. 温度

| 区分 | 限界値 | 最適値 | 備考 |
|---|:---:|:---:|---|
| 発芽温度 | 15-35℃ | 25-30℃ | 20℃以下では発芽が非常に遅くなります |
| 育苗温度（昼） | 20-32℃ | 25-30℃ | |
| 育苗温度（夜） | 15℃以上 | 18-20℃ | 15℃を下回る状態が続くと花芽分化が悪くなります |
| 生育温度 | 15-35℃ | 25-32℃ | |
| 結実温度 | 20-30℃ | 20-25℃ | 評価表の温度適応幅Cは、この10℃の幅です |
| 高温限界 | 35℃以上 | - | 花粉の活力が落ちて花が落ちます |
| 低温限界 | 10℃以下 | - | 生育が止まります |
| 致死 | 0℃以下 | - | 霜で枯死します |

&nbsp;&nbsp;&nbsp;生育適温と結実適温が異なるという点が、トウガラシの特殊な部分です。茎と葉が育つのに良い温度は25-32℃ですが、花が受精して実がなるのに良い温度は20-25℃です。そのため真夏の最も暑い時期には、株が茂る一方で新しい実がつきにくい状態になります。8月中旬以降に気温が下がるとともに再び着果が増え、このとき実った果実が秋の赤唐辛子になります。

### 3-2. 光

| 区分 | 基準 | 備考 |
|---|---|---|
| 必要日照 | 1日6時間以上 | 日照が多いほど花が多くつきます |
| 最小日照 | 1日4時間 | 育つことは育ちますが、着果が大きく減ります |
| 40%遮光時 | 相対収量102% | 果菜類共通の値で、評価表のS等級の根拠です |
| 強光ストレス | 真夏の直射日光 | 果皮に日焼けが生じて白い斑点が残り、その部分が腐ります |

&nbsp;&nbsp;&nbsp;トウガラシでは日焼けが実質的な損失を生みます。葉に覆われていない実が真夏の直射日光をそのまま受けると、その部分の組織が死んで白色から褐色に変わり、そこにカビが入り込みます。そのためトウガラシでは、葉をあまり多く摘み取らないことが原則です。ナスで下葉を積極的に整理するのとは逆です。トウガラシの葉は、実の日よけの役割も兼ねています。

### 3-3. 水と土壌

| 項目 | 基準 | 備考 |
|---|---|---|
| 総蒸発散量 | 作期あたり約750mm | 評価表の水消費量Cの根拠です |
| 土壌水分 | 最大容水量の60-70% | ナスよりやや乾燥気味に保ちます |
| 土性 | 排水と保水を両立できる壌土、砂壌土 | |
| 土壌の深さ | 30cm以上 | 細根は表土に集中します |
| pH | 6.0-6.5 | 弱酸性です |
| 畝の高さ | 20-30cm | 疫病対策の要です |
| 耐塩性 | 弱い | 塩類が蓄積すると生育が止まります |

&nbsp;&nbsp;&nbsp;トウガラシの水管理で覚えておくべき一つのことは、過湿の方が乾燥より危険だということです。ナスは水が不足すると落果で対応するのに対し、トウガラシは根が浅いため水がたまるとすぐに疫病が入り込みます。疫病はPhytophthora capsiciという水カビが引き起こし、この菌は水中を泳ぐ遊走子を作り、たまった水に沿って広がります。畑に水がたまった瞬間、この菌の移動経路が開くということです。

> **トウガラシ畑で畝を高くすることは、排水のための工夫ではなく、疫病を防ぐ唯一の構造的対策です。薬のない条件では、畝の高さがその年の収穫量を左右します。**

&nbsp;&nbsp;&nbsp;pHが6.0-6.5とナスよりやや低めに設定されているのは、トウガラシが弱酸性を好むためです。ただし5.5を下回るとリン酸固定とアルミニウム毒性が生じるため、この下限は守る必要があります。石灰がない条件では草木灰で代用しますが、草木灰はアルカリ性が強いため、一度に多く入れるとpHが7を大きく超えてしまいます。㎡あたり一握りずつ分けて入れ、翌年の様子を見て調整する方が安全です。
