## 引言
&nbsp;&nbsp;&nbsp;辣椒（Capsicum annuum）是茄科辣椒属的一年生果菜。原产于中南美洲。评价表判定它因单位面积热量为E而不能成立为粮食作物。每1,000㎡收获300kg，也只有每㎡255kcal，是自给线的0.10倍，达不到15%的排除线，未适用关卡得分也只有30.5（有效183种中的第183位）。即便如此还要种辣椒，是因为辣椒不是粮食，而是工具。完全晒干的辣椒在常温下可存放1-2年，不用加热就能磨粉直接使用，所以在腌菜太咸吃不下、谷物乏味咽不下去的时候，一勺辣椒粉能让那份食物变得可以入口。辣椒素有抗菌作用，还能驱虫。它的弱点是病害。炭疽病无药可治，所以有的年份梅雨季会把红辣椒全部损失掉。现实的目标是种二三十株，保证一年用的辣椒粉。

## 1. 灾害应对评估
| 类别 | 内容 |
|:---|:---|
| 判定 | 排除（单位面积热量E，低于自给线的15%）。未适用关卡得分30.5 |
| 优势 | SS：烹调·加工（不用加热就能直接用）。S：微量营养素、光照反应（遮光40%时相对产量102%）、耐储性、产量稳定性、国内种植普及度、自留种 |
| 劣势 | E：单位面积热量、耐寒性。D：收获速度（折合直播160-180天，其中育苗70天）、施肥（每㎡42g）、设施负担（支柱和避雨设施）、防治自立度（炭疽病无药可治，无防治减产率50.1%）、连作适应性（需休耕5-7年）、非食用价值、口味。C：水消耗量（总蒸散量750mm）、温度幅度、种子寿命 |

> **种辣椒的一坪地，就是放弃了一坪马铃薯的结果。饥饿时这笔交换不划算，有吃的却难以下咽时就划算。**

&nbsp;&nbsp;&nbsp;鲜辣椒每100g含维生素C 44-78mg，但每天用量只有几克到几十克，营养贡献很小。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 种 | 代表 | 杂交 |
|:---|:---|:---|
| Capsicum annuum | 地方辣椒、甜椒、彩椒、墨西哥辣椒 | 同种之间完全杂交 |

> **我们种的辣椒、青椒、甜椒、彩椒全是同一个种。种在一块地里会互相传粉，结出的种子第二年会长出辣味和甜味混杂的果实。**

&nbsp;&nbsp;&nbsp;茎直立，基部木质化，高60-100cm，在某一节分杈的第一个分枝点叫第一分杈点。移栽时主根被切断，须根集中在表土20cm以内，属浅根性。花白色，以自花授粉为主。果实是浆果，中空，胎座上附着直径3-4mm的扁平种子。因为属茄科，与茄子、番茄、马铃薯共有病害。

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 育苗期 | 播种到定植70-80天 | 真叶5-7片，第一个花蕾出现时是定植适期 |
| 缓苗·营养生长期 | 定植后1-5周 | 缓苗期间外观不长是正常的。之后茎变粗，形成第一分杈点 |
| 开花·坐果期 | 定植后40-50天 | 第一分杈点开出第一朵花 |
| 青辣椒 | 开花后20-30天 | 果实长到足够大小的状态 |
| 红辣椒 | 开花后45-50天 | 变红，辣椒素和色素积累 |

&nbsp;&nbsp;&nbsp;青辣椒和红辣椒是同一个果实的不同时间点，收哪一种，要根据当年的病害情况和需要来决定。

| 每100g营养 | 鲜（红色） | 干 |
|:---|:---|:---|
| 热量 | 85kcal | 280-330kcal |
| 蛋白质 / 膳食纤维 | 3.12g / 4-5g | 10-13g / 25-30g |
| 维生素C | 44-78mg | 大部分损失 |
| 其他 | β-胡萝卜素、钾、辣椒素（因品种而异0-0.5%，集中在胎座） | 浓缩 |

> **想把辣椒当作维生素C的来源，必须生吃。冬天的辣椒粉里指望不上。**

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽25-30℃（20℃以下很慢），育苗白天22-30℃、夜间15℃以上（低于此温度持续则花芽分化不良），生长25-32℃，结实20-25℃。35℃以上花粉活力下降，花会脱落；10℃以下停止生长；遇霜枯死 |
| 光照 | 每天6小时以上（最少4小时）。盛夏直射光会使果实日灼 |
| 水 | 每茬总蒸散量约750mm。土壤水分为最大持水量的60-70%。过湿比干燥更危险 |
| 土壤 | 排水和保水兼具的壤土至砂壤土，土层厚30cm以上，pH 6.0-6.5。怕盐。垄高20-30cm |

> **辣椒地里筑高垄，是防止疫病的唯一结构性对策。在没有药的条件下，垄的高度决定当年的收成。**

| 品种 | 特点 |
|:---|:---|
| Maeuntan、Speed Kaltan | 大果早熟种。对炭疽病和病毒病相对抗性较强。一代杂种 |
| Bugang、Muhanjilju、Urigeon | 普通型中熟种。干燥状态好。Muhanjilju辣味强 |
| 地方Chilseongcho·Subicho系统 | 固定种，可留种延续，香味浓，但怕炭疽病 |
| 青阳系 | 小果。辣味很强，少量就能用于调味和驱虫 |
| 甜椒·彩椒 | 不辣，适合儿童和老人。怕炭疽病 |

&nbsp;&nbsp;&nbsp;完全没有药时，抗炭疽病的品系是唯一的防线，但这类品种大多是一代杂种，不能留种，而地方固定种怕炭疽病。现实的办法是把两个品系一起种，但彼此隔开。想提高梅雨前的收获，就选早熟种。

## 4. 田地准备、播种与定植
| 项目 | 标准 |
|:---|:---|
| 整地 | 翻耕25-30cm深，起20-30cm高的垄，田边和垄端开排水沟。先确认3-5年内是否种过茄科。石灰在定植前2-3周，腐熟堆肥在定植前1-2周（同一天施入会损失氮） |
| 施肥（每1,000㎡） | 堆肥1,500-2,000kg，氮19.0kg（基肥50%，追肥50%），磷11.2kg（全部作基肥），钾14.9kg（基肥60%，追肥40%） |
| 追肥 | 定植后约30天开始，每隔20-25天一次，共4次。第3次以钾为主。不要施在植株紧旁边 |
| 替代资源 | 腐熟堆肥每㎡ 2-3kg，稀释10-15倍的尿液（浇进垄沟，收获前2周停止），草木灰每㎡一把，骨粉，发酵油饼的10倍稀释液，草覆盖，烧过的蛋壳或贝壳粉（钙） |

> **以为多施氮就多结果，是误解。氮过多只会让叶子茂盛、花脱落，内部发暗的植株上炭疽病和软腐病就会扎根。**

| 作业 | 中部 | 南部 |
|:---|:---|:---|
| 播种（开始育苗） | 2月中旬至下旬 | 2月上旬至中旬 |
| 定植 | 5月上旬至中旬（晚霜结束后） | 4月下旬至5月上旬 |
| 收获 | 青辣椒从6月中旬起，红辣椒7月下旬至10月 | 相同 |

| 育苗与定植 | 标准 |
|:---|:---|
| 播种 | 用30℃的水浸10小时，包在湿布里在25-30℃催芽（4-7天）。深0.5-1cm。真叶3-4片（播种后35-40天）时分苗一次，定植前1周起白天放到外面炼苗 |
| 不加温 | 马粪·稻草·稻壳踩实的酿热温床（20-30℃可维持3-6周）、朝南窗边、黑色水桶蓄热（夜间升温3-5℃）、双层覆盖（升温2-4℃）、火炕房的炕梢（离火口远的一端，夜间18-22℃，易徒长） |
| 无法育苗时 | 4月播种，6月中旬定植。成为只收青辣椒的一年 |
| 定植 | 比苗土稍深。单行种植垄距80-90cm，株距35-40cm（每㎡约3株），双行种植垄距150cm。往穴里浇水，水渗完后再栽。定植的同时立1.5m的支柱。选阴天的下午栽 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 定植后至缓苗 | 浇透，3-4天内不让干 |
| 缓苗后至开花前 | 表土干了再浇，间隔5-7天。稍干一点，根就会向四周扩展 |
| 开花·坐果期、膨大·着色期 | 每3-4天一次，要均匀。时多时少会得脐腐病 |
| 梅雨季 | 停止灌溉，检查排水沟 |
| 收获后期 | 逐渐减少（浇到太晚会推迟着色） |

> **一株突然萎蔫枯死时，人会想多浇点水，但这通常是最糟的选择。夏天辣椒急剧萎蔫，原因远比缺水更常见的是疫病，多浇水会把游动孢子带到邻近的植株上。**

&nbsp;&nbsp;&nbsp;缺水时，花和幼果先脱落，果实变细起皱。果尖发黑凹陷腐烂的脐腐病不是病原菌所致，而是钙运输中断的结果，办法不是多加钙，而是用覆盖物保持土壤水分均匀。水贵重时，用稻草覆盖、傍晚浇水、沟灌（炭疽病孢子不会溅起）、把底部扎孔的瓶子插进土里滴灌。

| 管理 | 内容 |
|:---|:---|
| 侧芽 | 定植后30-40天，侧芽长到拇指长时，用手把第一分杈点以下的侧芽掰掉。太早去会拖慢早期生长。第一分杈点上的第一个果实，趁幼小时摘掉 |
| 引缚 | 单线引缚（简单但枝条下垂）、双线引缚（在两侧支柱上分两三层拉绳）、X形引缚（1.8m支柱交叉立起，通风和支撑都好）。绳子可用稻草绳、葛藤、布条代替 |
| 避雨 | 没有塑料膜时，在屋檐下、墙根下栽培，稻草或草席棚顶，在果实集中的部分上方放木板或瓦片，稻草覆盖。没有完全的替代办法 |

> **没有药的条件下，辣椒整枝不是为了让果实变大，而是让风能从植株里面穿过。湿气滞留的地方，就是炭疽病开始的地方。**

## 6. 病虫害与养分问题
| 病害 | 症状与条件 | 不用药的应对 |
|:---|:---|:---|
| 炭疽病 | 成熟中的果实上出现水渍状的圆斑并凹陷，长出黑色孢子堆。梅雨季高温高湿 | 无药可治。病果立即摘下烧掉。抗病品种、避雨、稻草覆盖、加大间距 |
| 疫病 | 茎基部缢缩成暗褐色，植株急剧萎蔫。过湿、排水不良 | 高垄和排水沟是唯一的结构性对策。病株立即拔除 |
| 青枯病、病毒病 | 中午萎蔫、早晨恢复，反复几次后死亡（高温、土传）。叶片花叶、果实畸形（蚜虫·蓟马传播） | 二者都无法治疗。拔除病株、长期轮作、防治传毒昆虫 |
| 细菌性斑点病、灰霉病、白粉病 | 叶·花·果上的斑点、灰色霉层、白粉 | 保证通风、抖掉谢花、预防性喷波尔多液、牛奶或小苏打稀释液 |

> **炭疽病无药可治。能做的只是减少感染本身，最可靠的避开办法，是在炭疽病大发生前就当青辣椒摘下。不用药种植，有的年份收成丰厚，有的年份损失一半。**

&nbsp;&nbsp;&nbsp;害虫有蚜虫（肥皂水、保护瓢虫）、蓟马（蓝色粘虫板）、烟青虫（摘除并销毁有孔的果实，用手捉幼虫）、二斑叶螨（用力向叶背喷水）、蝽（清晨人工捕捉）。防治材料有波尔多液（硫酸铜1kg和生石灰1kg分别溶解冷却后合并，加水至100L）、肥皂水（无香肥皂20g加水1L）、牛奶稀释液、草木灰、稀释300-500倍的木醋液。

| 症状 | 原因与处理 |
|:---|:---|
| 从下部叶子开始变黄，植株矮小 | 缺氮。稀释10-15倍的尿液、腐熟堆肥 |
| 叶缘焦枯，果实小 | 缺钾。草木灰 |
| 叶背和茎发紫 | 缺磷（低温期土壤冷也可能吸收不了）。骨粉 |
| 叶脉间发黄，叶脉仍绿 | 缺镁。白云石粉 |
| 花开后直接掉落 | 缺硼、高温、氮过多、缺水中的一种。按顺序检查 |
| 只长叶子，花少 | 氮过多。停止施氮，用草木灰补钾 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 豆科（菜豆、豇豆）、万寿菊（抑制根结线虫）、葱·蒜·韭菜（抑制土壤病原菌）、白苏·紫苏（浓烈的气味扰乱害虫） |
| 差 | 茄子·番茄·马铃薯（完全共有疫病和青枯病）、玉米（遮阴、争夺养分）、葫芦科（藤蔓妨碍通风） |

&nbsp;&nbsp;&nbsp;第1年辣椒，第2年豆科，第3年葱属，第4年谷物（玉米·高粱·粟），第5年叶菜或根菜，第6年以后再回到辣椒。在同一块地上连续种3年以上，某一年会突然因疫病死掉一半。

## 8. 收获与留种
| 项目 | 青辣椒 | 红辣椒 |
|:---|:---|:---|
| 收获时点 | 开花后20-30天，长到足够大小且有光泽时（每3-5天） | 开花后45-50天，变成深红并开始起皱时（每7-10天） |
| 暴露于炭疽病的时间 | 短 | 长 |
| 储存 | 常温1-2周 | 晒干后1-2年 |

&nbsp;&nbsp;&nbsp;在清晨露水干后留着果柄摘下（湿着摘会在储存中发霉），病果单独摘下带出田外。下部的果实靠近土壤，炭疽病风险大，所以当青辣椒摘下，日照和通风好的上部果实留着熟成红辣椒。预计梅雨季会很长的年份，要提前做出判断。

| 留种 | 标准 |
|:---|:---|
| 防止杂交 | 蜜蜂传粉的比例为2-50%。与其他品系隔开100-500m，或在花开前套上网或布袋。只种一个品系最简单 |
| 留种果 | 7月选无病、长势好的植株，在下部果实上做标记。9-10月放到完全变红、起皱，再放在阴凉处后熟1-2周 |
| 分离与干燥 | 剖开果实，从胎座上捋下种子，浮在水上的丢掉。在阴凉处摊成一层晾1-2周。含水量8%以下，与干燥剂（炒过放凉的米、木炭、草木灰）一起密封在玻璃瓶或金属桶里 |
| 寿命 | 常温不密封1年，密封加干燥剂2-3年，10℃以下干燥密封4-5年。每年取20粒放在湿布上，十天后数发芽率，低于70%就加大播种量或重新留种 |
| 消毒 | 50-55℃的水泡10-15分钟后用冷水降温，丢掉浮在水上的，裹草木灰 |

&nbsp;&nbsp;&nbsp;捋种子时用手直接碰胎座，辣椒素会渗进皮肤，火辣辣几个小时。要用布或塑料包住手，工作后用油或牛奶擦掉再洗。

## 9. 干燥与储存
| 方式 | 条件 | 时间 |
|:---|:---|:---|
| 晒干 | 晴朗有风的日子摊在帘子或席子上，或穿在线上挂起 | 7-15天 |
| 阴干 | 通风好的阴凉处。颜色好看，但梅雨季会失败 | 15-30天 |
| 火烘 | 灶台上方、火炕的炕头、炉边的余热 | 2-5天 |
| 混合 | 先晒几天，最后在火边收尾。梅雨季较现实 | 5-10天 |

&nbsp;&nbsp;&nbsp;只用无病且完全变红的，湿了的要先晒一天，再摊成不重叠的一层或穿在线上挂起来。每天翻一两次，晚上收进来，不让沾露水。弯折时啪地折断、摇晃时里面有种子响声，就是干了。

> **干燥的判断标准只有一个。弯折时会不会折断。能弯就是没干透，一个月内就会发霉。即使可惜，也再晒半天。**

| 储存 | 标准 |
|:---|:---|
| 干辣椒 | 含水量12%以下，阴暗凉爽干燥的地方（地下窖、北墙根下），陶瓮、双层袋或密闭容器，用木炭、炒过放凉的米、干燥的草木灰作干燥剂。常温下1-2年。每月打开一次检查是否受潮和发霉。受潮了就在太阳下重新晒半天后再装。靠密封和干燥来防印度谷螟 |
| 青辣椒 | 盐水（10-15%）腌制数月，酱油腌渍数月至1年，盐水乳酸发酵数月（在红辣椒难以熟成的年份有用） |

## 10. 烹调·加工与注意事项
| 用途 | 方法 |
|:---|:---|
| 辣椒粉 | 干辣椒去掉果蒂，用臼或石磨磨粉。不需要燃料 |
| 青辣椒 | 洗净后直接蘸豆酱或酱料生吃（获得维生素C的唯一途径） |
| 泡菜调料、汤 | 辣椒粉与盐和蔬菜拌匀。整个辣椒放进汤里，再捞出 |
| 保护储存的谷物 | 往谷物袋、瓮、种子容器里放几个干辣椒或一小块（象甲、印度谷螟） |
| 驱避剂 | 干辣椒泡水一天，过滤、稀释后喷到田里（软体害虫、蝽）。把辣椒粉撒在通道上能赶走老鼠和鼹鼠 |

> **辣椒只能延缓腐败，不能让变质的食物恢复。用辣调料盖住已经变质的东西，闻不出变质的气味，反而更危险。**

| 注意 | 内容 |
|:---|:---|
| 毒性 | 没有急性毒性。茄碱类处于没有实际影响的水平 |
| 辣椒素 | 溶于油，不溶于水。碰到眼睛和伤口会剧痛，用牛奶或油擦掉。磨辣椒粉或捋种子后一定要洗手，在此之前不碰脸 |
| 霉菌 | 有潮湿的霉味、有黑色或蓝色斑点就丢弃。只有一部分发霉，把那部分切掉也不安全 |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查种子和发芽率、收集温床材料并修整支柱、播种（中部中旬至下旬，南部上旬至中旬）、温床开始发热 |
| 3-4月 | 育苗管理并在真叶3-4片时分苗、田里施石灰、堆肥和基肥、起垄、炼苗。南部下旬定植 |
| 5月 | 中部定植，同时立支柱，铺稻草覆盖 |
| 6月 | 去掉第一分杈点以下的侧芽并摘掉第一个果实、第1次追肥、从中旬起收青辣椒 |
| 7月 | 检查梅雨季排水、巡查炭疽病并立即清除病果、第2次追肥、从下旬起收红辣椒 |
| 8-9月 | 每7-10天收一次红辣椒并晒干、第3-4次追肥、给留种果做标记并让其完全成熟 |
| 10-11月 | 收尾收获并腌制剩下的青辣椒、留种果后熟、拔掉植株并烧掉病残体、挑选种子并收好干辣椒 |
| 12月 | 检查干辣椒的状态、决定明年的地块（确认茄科休耕） |

> **不能忘记的五件事：高垄和排水、少施氮、在炭疽病之前当青辣椒摘下、晒到弯折就断、茄科休耕5-7年。**
