## はじめに
&nbsp;&nbsp;&nbsp;トウガラシ(Capsicum annuum)は、ナス科トウガラシ属の一年生の果菜です。原産地は中南米です。評価表は、面積当たりの熱量がEで、食料作物として成り立たないと判定しました。1,000㎡で300kgを収穫しても1㎡当たり255kcal、自給ラインの0.10倍で、除外ラインの15%に届かず、ゲート未適用スコアも30.5(有効183種中183位)です。それでもトウガラシを植えるのは、トウガラシが食料ではなく道具だからです。完全に乾燥させたトウガラシは常温で1-2年もち、加熱せずに粉にしてすぐ使えるので、塩漬けは塩辛くて食べられず、穀物は味気なくて飲み込みにくい状況でも、トウガラシ粉をひとさじ加えれば、その食べ物が食べられるものに変わります。カプサイシンには抗菌作用があり、虫も遠ざけます。弱点は病気です。炭疽病に治療法がないので、梅雨に赤トウガラシをすべて失う年があります。現実的な目標は、20-30株を植えて、1年分のトウガラシ粉を確保することです。

## 1. 災害への備えの評価
| 区分 | 内容 |
|:---|:---|
| 判定 | 除外(面積当たりの熱量E、自給ラインの15%未満)。ゲート未適用スコア30.5 |
| 強み | SS: 調理・加工(加熱せずにすぐ使える)。S: 微量栄養素、日射への反応(40%遮光で相対収量102%)、貯蔵性、収量の安定性、国内での栽培の普及度、自家採種 |
| 弱み | E: 面積当たりの熱量、耐寒性。D: 収穫速度(直まき換算で160-180日、うち70日が育苗)、施肥(1㎡当たり42g)、施設の負担(支柱と雨よけ)、防除の自立度(炭疽病に治療法がない、無防除の減収率50.1%)、連作への適応性(5-7年の休作)、非食用の価値、味。C: 水の消費量(総蒸発散量750mm)、温度幅、種子の寿命 |

> **トウガラシを植える畑1坪は、ジャガイモ1坪をあきらめた結果です。空腹の状況ではその交換は合わず、食べ物はあるが食べにくい状況では合います。**

&nbsp;&nbsp;&nbsp;生のトウガラシ100gのビタミンCは44-78mgですが、1日に使う量が数gから数十gなので、栄養面の貢献はわずかです。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 種 | 代表 | 交雑 |
|:---|:---|:---|
| Capsicum annuum | 在来のトウガラシ、ピーマン、パプリカ、ハラペーニョ | 同じ種どうしで完全に交雑 |

> **私たちが育てる辛いトウガラシ、青トウガラシ、ピーマン、パプリカは、すべて同じ種です。1つの畑に植えると互いに花粉をやりとりし、その種からは翌年、辛みと甘みが混ざったものが出ます。**

&nbsp;&nbsp;&nbsp;茎は直立して株元が木質化し、高さ60-100cmで、ある節で分かれる最初の分枝点を第一分枝点と呼びます。移植のときに直根が切れて、細根が表土20cm以内に集まる浅根性です。花は白で、自家受粉が主です。果実は液果で中が空洞になっており、胎座に直径3-4mmの平たい種子がつきます。ナス科なので、ナス、トマト、ジャガイモと病気を共有します。

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 育苗期 | 播種から定植まで70-80日 | 本葉5-7枚。最初の花のつぼみが見えるころが定植の適期 |
| 活着・栄養生長期 | 定植後1-5週 | 活着のあいだは見かけ上伸びないのが正常。その後、茎が太くなり、第一分枝点ができる |
| 開花・着果期 | 定植後40-50日 | 第一分枝点で最初の花が咲く |
| 青トウガラシ | 開花後20-30日 | 果実が十分な大きさになった状態 |
| 赤トウガラシ | 開花後45-50日 | 赤く変わり、カプサイシンと色素がたまる |

&nbsp;&nbsp;&nbsp;青トウガラシと赤トウガラシは、同じ果実の異なる時点で、どちらを収穫するかは、その年の病気の状況と必要に応じて決めます。

| 100g当たりの栄養 | 生(赤) | 乾燥 |
|:---|:---|:---|
| 熱量 | 85kcal | 280-330kcal |
| タンパク質 / 食物繊維 | 3.12g / 4-5g | 10-13g / 25-30g |
| ビタミンC | 44-78mg | ほとんど失われる |
| その他 | βカロテン、カリウム、カプサイシン(品種により0-0.5%、胎座に集中) | 濃縮される |

> **トウガラシをビタミンCの供給源にするには、生で食べなければなりません。冬のトウガラシ粉には、何も期待できません。**

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽25-30℃(20℃以下では非常に遅い)、育苗は昼22-30℃・夜15℃以上(それを下回る状態が続くと花芽分化が悪い)、生育25-32℃、結実20-25℃。35℃以上で花粉の活力が落ちて花が落ち、10℃以下で生育が止まり、霜で枯れる |
| 光 | 1日6時間以上(最低4時間)。真夏の直射日光は果実に日焼けを起こす |
| 水 | 1作当たりの総蒸発散量約750mm。土壌水分は最大容水量の60-70%。過湿が乾燥より危険 |
| 土壌 | 排水と保水がともにできる壌土-砂壌土、土の深さ30cm以上、pH 6.0-6.5。塩類に弱い。畝の高さ20-30cm |

> **トウガラシ畑で畝を高くするのは、疫病を防ぐ唯一の構造的な対策です。薬のない条件では、畝の高さがその年の収穫量を決めます。**

| 品種 | 特徴 |
|:---|:---|
| メウンタン、スピードカルタン | 大果の早生種。炭疽病とウイルスに比較的強い。一代雑種 |
| プガン、ムハンジルジュ、ウリゴン | 一般型の中生種。乾燥の状態がよい。ムハンジルジュは辛みが強い |
| 在来のチルソンチョ・スビチョ系統 | 固定種なので種を採って受け継げ、香りが濃いが、炭疽病に弱い |
| チョンヤン系 | 小果。辛みが非常に強く、少量で調味と虫よけに使える |
| ピーマン・パプリカ | 辛くなく、子どもや高齢者向け。炭疽病に弱い |

&nbsp;&nbsp;&nbsp;薬がまったくなければ炭疽病に強い系統が唯一の防御ですが、そうした品種はたいてい一代雑種で種を採って使えず、在来の固定種は炭疽病に弱いのです。現実的な解決策は、2つの系統を互いに離して一緒に植えることです。梅雨前の収穫を増やすには、早生種を選びます。

## 4. 畑の準備と播種、定植
| 項目 | 基準 |
|:---|:---|
| 土づくり | 25-30cmの深さに耕して畝を20-30cmにし、畑の縁と畝の端に排水溝。まず3-5年以内にナス科を植えたかを確認。石灰は定植の2-3週間前、完熟堆肥は1-2週間前(同じ日に入れると窒素が飛ぶ) |
| 施肥(1,000㎡当たり) | 堆肥1,500-2,000kg、窒素19.0kg(元肥50%、追肥50%)、リン酸11.2kg(全量元肥)、カリウム14.9kg(元肥60%、追肥40%) |
| 追肥 | 定植後約30日から始めて20-25日おきに計4回。3回目はカリウム中心。株のすぐ脇には与えない |
| 代替資源 | 完熟堆肥1㎡当たり2-3kg、尿の10-15倍希釈液(畝間に注ぎ、収穫の2週間前に中止)、木灰1㎡当たりひとつかみ、骨粉、発酵させた油かすの10倍希釈液、草のマルチ、卵や貝殻を焼いた粉(カルシウム) |

> **窒素を多く与えればたくさん実るというのは思い違いです。窒素が過剰だと葉だけが茂って花が落ち、内側が暗くなった株に炭疽病と軟腐病が居つきます。**

| 作業 | 中部 | 南部 |
|:---|:---|:---|
| 播種(育苗開始) | 2月中旬-下旬 | 2月上旬-中旬 |
| 定植 | 5月上旬-中旬(遅霜が終わった後) | 4月下旬-5月上旬 |
| 収穫 | 青トウガラシは6月中旬から、赤トウガラシは7月下旬-10月 | 同じ |

| 育苗と定植 | 基準 |
|:---|:---|
| 播種 | 30℃の水に10時間浸し、湿らせた布に包んで25-30℃で発芽させる(4-7日)。深さ0.5-1cm。本葉3-4枚(播種後35-40日)で1回鉢上げし、定植の1週間前から昼に外へ出して順化させる |
| 加温なしで | 馬ふん・稲わら・もみ殻を踏み込む踏み込み温床(20-30℃を3-6週間)、南向きの窓辺、黒い水桶による蓄熱(夜の温度が3-5℃上がる)、二重被覆(2-4℃上がる)、オンドル部屋の奥(火元から遠い側、夜18-22℃、徒長しやすい) |
| 育苗ができないとき | 4月に播種して6月中旬に定植。青トウガラシだけを得る年になる |
| 定植 | 苗の土よりやや深く。1条植えは畝80-90cm、株間35-40cm(1㎡当たり3株前後)、2条植えは畝150cm。穴に水を注ぎ、引いてから植える。1.5mの支柱を定植と同時に立てる。曇りの日の午後に植える |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 定植直後-活着 | たっぷり注ぎ、3-4日は乾かないように |
| 活着後-開花前 | 表土が乾いたら、5-7日おき。やや乾かし気味にすると根が広く張る |
| 開花・着果期、肥大・着色期 | 3-4日おきに均一に。ばらつくと尻腐れ病になる |
| 梅雨 | 灌水を中止し、排水溝を点検 |
| 収穫後半 | 徐々に減らす(遅くまで与えると着色が遅れる) |

> **1株が突然しおれて枯れると、水をもっとやりたくなりますが、たいていは最悪の選択です。夏にトウガラシが急にしおれる原因は、水不足よりも疫病のほうがはるかに多く、水を増やすと遊走子が隣の株に広がります。**

&nbsp;&nbsp;&nbsp;水が足りないと、花と幼果が先に落ち、果実が細くしわになります。果実の先が黒くくぼんで腐る尻腐れ病は、病原菌ではなくカルシウムの移動が途絶えた結果で、カルシウムをさらに入れるより、マルチで土壌水分を均一に保つのが解決策です。水が貴重なときは、わらマルチ、夕方の灌水、畝間灌水(炭疽病の胞子がはねない)、底に穴を開けた瓶を土に差す点滴を使います。

| 管理 | 内容 |
|:---|:---|
| わき芽 | 定植後30-40日、わき芽が親指ほどの長さのときに、第一分枝点より下のわき芽を手で折り取る。早すぎると初期の生育が遅れる。第一分枝点の最初の果実は、若いうちに摘み取る |
| 誘引 | 1本誘引(簡単だが枝が垂れる)、2本誘引(両側の支柱にひもを2、3段に掛ける)、X字誘引(1.8mの支柱を交差させて立てる、風通しと支えがよい)。ひもはわら縄、クズのつる、布切れで代用 |
| 雨よけ | ビニールがなければ、軒下・塀の下での栽培、わらぶきやむしろの屋根、果実が集まった部分の上の板や瓦、わらマルチ。完全な代替はない |

> **薬のない条件で、トウガラシの整枝は果実を大きくする作業ではなく、株の中に風を通す作業です。湿気がとどまる場所が、炭疽病の始まる場所です。**

## 6. 病害虫と養分の問題
| 病害 | 症状と条件 | 薬を使わない対応 |
|:---|:---|:---|
| 炭疽病 | 熟していく果実に水に濡れたような丸い斑点ができてくぼみ、黒い胞子の塊ができる。梅雨の高温多湿 | 治療法なし。病んだ果実はすぐに摘んで燃やす。抵抗性品種、雨よけ、わらマルチ、広い間隔 |
| 疫病 | 茎の株元が暗褐色にくびれ、急にしおれる。過湿、排水不良 | 高い畝と排水溝が唯一の構造的な対策。病株はすぐに除去 |
| 青枯病、ウイルス病 | 日中にしおれて朝に回復することを繰り返して枯れる(高温、土壌伝染)。葉がまだらになり果実が奇形(アブラムシ・アザミウマが媒介) | どちらも治療不可。病株の除去、長期の輪作、媒介虫の防除 |
| 斑点細菌病、灰色かび病、うどんこ病 | 葉・花・果実の斑点、灰色のカビ、白い粉 | 通風の確保、散った花を払う、ボルドー液の予防散布、牛乳や重曹の希釈液 |

> **炭疽病には治療法がありません。できるのは感染そのものを減らすことで、最も確実な回避策は、炭疽病が本格化する前に青トウガラシとして摘むことです。薬なしで育てると、たっぷり収穫できる年も、半分を失う年もあります。**

&nbsp;&nbsp;&nbsp;害虫は、アブラムシ(石けん水、テントウムシの保護)、アザミウマ(青色の粘着板)、タバコガ(穴の開いた果実を摘んで処分し、幼虫を手で捕る)、ナミハダニ(葉の裏に水を強く吹きかける)、カメムシ(早朝に手で捕る)です。防除資材は、ボルドー液(硫酸銅1kgと生石灰1kgを別々に溶かして冷まし、合わせて水100Lにする)、石けん水(無香料の石けん20gを水1Lに)、牛乳の希釈液、木灰、木酢液の300-500倍です。

| 症状 | 原因と措置 |
|:---|:---|
| 下の葉から黄色くなり、株が小さい | 窒素欠乏。尿の10-15倍希釈液、腐熟堆肥 |
| 葉の縁が焼け、果実が小さい | カリウム欠乏。木灰 |
| 葉の裏と茎が紫色を帯びる | リン酸欠乏(低温期は土が冷たくて吸収されないこともある)。骨粉 |
| 葉脈の間だけ黄色く、葉脈は緑 | マグネシウム欠乏。ドロマイト粉末 |
| 花が咲いてもそのまま落ちる | ホウ素欠乏、高温、窒素過剰、水不足のどれか。順番に確認 |
| 葉だけ茂り、花が少ない | 窒素過剰。窒素を断ち、木灰でカリウムを補う |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| よい | マメ科(インゲン、ササゲ)、マリーゴールド(ネコブセンチュウを抑える)、ネギ・ニンニク・ニラ(土壌病原菌を抑える)、エゴマ・シソ(強い香りが害虫を惑わす) |
| 悪い | ナス・トマト・ジャガイモ(疫病と青枯病をそのまま共有)、トウモロコシ(日陰、養分競合)、ウリ科(つるが風通しを妨げる) |

&nbsp;&nbsp;&nbsp;1年目トウガラシ、2年目マメ科、3年目ネギ属、4年目穀物(トウモロコシ・モロコシ・アワ)、5年目葉菜類か根菜類を経て、6年目以降にトウガラシを再開します。同じ場所に3年以上続けて植えると、ある年突然、疫病で半分が枯れます。

## 8. 収穫と採種
| 項目 | 青トウガラシ | 赤トウガラシ |
|:---|:---|:---|
| 収穫の時点 | 開花後20-30日、十分な大きさになってつやがあるとき(3-5日おき) | 開花後45-50日、濃い赤に変わってしわが寄り始めるとき(7-10日おき) |
| 炭疽病にさらされる期間 | 短い | 長い |
| 貯蔵 | 常温で1-2週間 | 乾燥させれば1-2年 |

&nbsp;&nbsp;&nbsp;早朝の露が乾いた後に、へたを残して摘み(濡れたまま摘むと貯蔵中にカビが生える)、病んだ果実は別に摘んで畑の外へ持ち出します。下のほうの果実は土に近く炭疽病の危険が大きいので青トウガラシとして摘み、日当たりと風通しがよい上のほうの果実を赤トウガラシに熟させます。梅雨が長くなりそうな年には、判断を前倒しします。

| 採種 | 基準 |
|:---|:---|
| 交雑の防止 | ハチが花粉を運ぶ割合は2-50%。ほかの系統から100-500m離すか、花が開く前にネットや布の袋をかぶせる。1つの系統だけを植えるのが最も簡単 |
| 採種果 | 7月に病気がなく勢いのよい株を選び、下のほうの果実に印をつける。9-10月に完全に赤くなってしわが寄るまで置き、日陰で1-2週間追熟 |
| 分離と乾燥 | 果実を割って胎座から種をしごき取り、水に浮くものは捨てる。日陰で1-2週間、1層に広げて乾かす。水分8%以下にして、乾燥剤(炒って冷ました米、炭、木灰)とともにガラス瓶や金属缶に密閉 |
| 寿命 | 常温で密閉しなければ1年、密閉+乾燥剤で2-3年、10℃以下で乾燥・密閉で4-5年。毎年20粒を湿らせた布に置いて10日後の発芽率を数え、70%を下回れば播種量を増やすか新しく採る |
| 消毒 | 50-55℃の湯に10-15分の後、冷水で冷ます、水に浮くものを捨てる、木灰をまぶす |

&nbsp;&nbsp;&nbsp;種をしごくときに素手で胎座に触れると、カプサイシンが手にしみて数時間ひりひりします。布かビニールで手を包み、作業後は油か牛乳で拭き取ってから洗います。

## 9. 乾燥と貯蔵
| 方式 | 条件 | 期間 |
|:---|:---|:---|
| 天日干し | 晴れて風のある日にすだれやむしろに広げるか、糸に通してつるす | 7-15日 |
| 陰干し | 風通しのよい日陰。色はきれいに残るが、梅雨には失敗 | 15-30日 |
| 火力乾燥 | かまどの上、オンドルの焚き口側、火鉢のそばの余熱 | 2-5日 |
| 併用 | 天日で数日干してから、仕上げを火のそばで。梅雨には現実的 | 5-10日 |

&nbsp;&nbsp;&nbsp;病気がなく完全に赤くなったものだけを使い、濡れていれば1日干してから、重ならないように1層に広げるか糸に通してつるします。1日に1、2回ひっくり返し、夜は露に当たらないよう取り込みます。曲げるとぽきっと折れ、振ると中で種の音がすれば乾いています。

> **乾燥の判定基準は1つです。曲げて折れるか。曲がるなら乾いておらず、1か月以内にカビが生えます。もったいなくても半日さらに干します。**

| 貯蔵 | 基準 |
|:---|:---|
| 乾燥トウガラシ | 水分12%以下、暗くて涼しく乾いた場所(地下の貯蔵穴、北向きの壁の下)、かめ・二重の袋・密閉容器、炭・炒って冷ました米・乾いた木灰を乾燥剤に。常温で1-2年。月に1回開けてしめりとカビを確認。しめっていれば日なたで半日干し直してから詰める。ノシメマダラメイガは密閉と乾燥で防ぐ |
| 青トウガラシ | 塩水(10-15%)漬けで数か月、醤油漬けで数か月-1年、塩水での乳酸発酵で数か月(赤くなるまで熟させにくい年に役立つ) |

## 10. 調理・加工と注意事項
| 用途 | 方法 |
|:---|:---|
| トウガラシ粉 | 乾燥トウガラシのへたを取り、臼や石臼で粉にする。燃料は不要 |
| 青トウガラシ | 洗ってそのまま、味噌やたれをつけて生で食べる(ビタミンCを得られる唯一の方法) |
| キムチの薬味、汁物 | トウガラシ粉と塩と野菜を和える。丸ごとのトウガラシは汁に入れて取り出す |
| 貯蔵穀物の保護 | 穀物の袋やかめ、種子の容器に、乾燥トウガラシを数本か1切れ入れる(ゾウムシ、ノシメマダラメイガ) |
| 忌避剤 | 乾燥トウガラシを水に1日浸して濾し、薄めて畑に散布(柔らかい虫、カメムシ)。トウガラシ粉を通り道にまくとネズミやモグラを追い払う |

> **トウガラシは腐敗を遅らせるだけで、傷んだ食べ物を元に戻しはしません。すでに傷んだものを辛い薬味で覆うと、傷んだにおいに気づけず、かえって危険になります。**

| 注意 | 内容 |
|:---|:---|
| 毒性 | 急性毒性はない。ソラニン類は実質的な影響のない水準 |
| カプサイシン | 油に溶け、水には溶けない。目や傷に触れると激しく痛み、牛乳か油で拭き取る。トウガラシ粉を挽いたり種をしごいたりした後は必ず手を洗い、それまで顔を触らない |
| カビ | 湿っぽくかび臭いにおい、黒や青の斑点があれば捨てる。一部だけ生えたものも、その部分を切り取っても安全ではない |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 種子と発芽率の確認、温床の材料集めと支柱の手入れ、播種(中部は中旬-下旬、南部は上旬-中旬)、温床の発熱開始 |
| 3-4月 | 育苗管理と本葉3-4枚での鉢上げ、畑に石灰、堆肥と元肥、畝上げ、順化。南部は下旬に定植 |
| 5月 | 中部で定植すると同時に支柱を立てる、わらマルチを敷く |
| 6月 | 第一分枝点より下のわき芽の除去と最初の果実の摘み取り、1回目の追肥、中旬から青トウガラシの収穫 |
| 7月 | 梅雨の排水の点検、炭疽病の見回りと病果のすぐの除去、2回目の追肥、下旬から赤トウガラシの収穫 |
| 8-9月 | 赤トウガラシを7-10日おきに収穫して乾燥、3-4回目の追肥、採種果の印づけと完熟 |
| 10-11月 | 収穫の仕上げと残った青トウガラシの塩漬け、採種果の追熟、株を抜いて病んだ残渣を燃やす、種子の選別と乾燥トウガラシの取り込み |
| 12月 | 乾燥トウガラシの状態の点検、翌年の場所の決定(ナス科の休作の確認) |

> **忘れてはならない5つのこと: 高い畝と排水、窒素を控える、炭疽病の前に青トウガラシとして摘む、曲げて折れるまで乾かす、ナス科を5-7年休ませる。**
