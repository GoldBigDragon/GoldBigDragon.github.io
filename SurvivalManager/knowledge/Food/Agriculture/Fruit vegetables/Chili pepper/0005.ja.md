## 8. 栽培管理 - わき芽と誘引

### 8-1. 一番分枝点より下のわき芽かき

&nbsp;&nbsp;&nbsp;トウガラシもナスと同じく、ある節で最初の花を咲かせ、その場所で枝分かれします。この最初の分岐点が一番分枝点であり、その下から出るわき芽を取り除くことが、トウガラシ栽培の最初の管理作業です。

| 項目 | 内容 |
|---|---|
| 時期 | 定植後30-40日、わき芽が親指ほどの長さになった頃 |
| 対象 | 一番分枝点より下から出る全てのわき芽 |
| 方法 | 手で横にそっと折り取ります |
| 理由 | 下部のわき芽はほとんど花をつけないまま養分を奪い、地面に近い場所で通風を妨げます |
| 注意 | 小さすぎるうちに取ると光合成面積が不足し、初期生育が遅れます |

&nbsp;&nbsp;&nbsp;早く取りすぎるなという注意書きには理由があります。若い株では、下部のわき芽の葉も光合成に貢献します。わき芽が指ほどの長さに育ち、それ自体が養分を消費し始めた頃が取るべき時点であり、それより前はそのままにしておくほうがよいのです。

&nbsp;&nbsp;&nbsp;一番分枝点より上はナスと異なります。ナスでは3本の主枝に整理しますが、トウガラシでは通常そのままにしておきます。トウガラシは節ごとに花がつくため、茎を減らすと花も一緒に減ってしまうからです。ただし株の内側に入り込んで互いに重なる茎、そして地面に着くほど垂れた茎は間引きます。目的は収量調節ではなく通風です。

> **薬のない条件でのトウガラシの整枝は、実を大きくするための作業ではなく、株の中に風を通すための作業です。湿気がとどまる場所が、炭疽病の始まる場所です。**

### 8-2. 最初の実の摘果

&nbsp;&nbsp;&nbsp;一番分枝点につく最初の実を幼いうちに摘み取るコツは、ナスと同じです。まだ体の小さい株が最初の実一つに養分を集中させると、茎と根が育たず、その状態で夏を迎えると全体の収量が落ちます。最初の実を指の大きさのうちに摘み取れば、その養分が株を大きくするために使われ、大きくなった株がずっと多くの実をつけます。

### 8-3. 誘引

| 方法 | 内容 | 特徴 |
|---|---|---|
| 一本仕立て誘引 | 株ごとに支柱を立てて茎を結びます | 簡単ですが、横に広がった枝が垂れ下がります |
| 二列誘引 | 畝の両側に支柱を立て、二、三段に紐を張って株を囲い込みます | 複数の株を一度に支えます |
| X字誘引 | 1.8mの支柱を交差させて立て、交点に横木を渡します | 通風と支持の両方が優れています |

&nbsp;&nbsp;&nbsp;トウガラシにおいて誘引は選択の余地がありません。実をつけたトウガラシが台風やにわか雨で倒れると実が土に触れ、土に触れた実はほぼ例外なく軟腐病や炭疽病にかかります。しかも一度倒れた株を起こそうとすると、浅い根が切れて回復できません。支柱は定植と同時に立て、茎が伸びる速さに合わせて7月まで二、三回に分けて結びます。

&nbsp;&nbsp;&nbsp;紐は藁縄、クズのつる、麻布の切れ端、古着を裂いて作った布切れで代用できます。結ぶときは茎を締め付けないように8の字に巻き、茎が太くなることを見込んで余裕を持たせます。支柱は畑の周りのまっすぐな木の枝を冬に切って乾かしておけば、毎年用意できます。評価表の施設負担Dが指しているのが、この毎年の作業です。

### 8-4. 雨よけをビニールなしでする方法

&nbsp;&nbsp;&nbsp;炭疽病対策の中で最も効果が大きいのが雨よけです。原理は単純です。雨粒が実に直接当たらなければ、胞子が付着する機会が減ります。問題はビニールがないという条件です。

| 代替方法 | 原理 | 限界 |
|---|---|---|
| 軒下・塀際での栽培 | 雨が当たりにくい場所に数株を植えます | 面積が小さく、日照が不足することがあります |
| 藁ぶき屋根 | 藁を編んで畝の上に載せます | 光を多く遮り、雨に濡れると重くなります |
| 木の板・瓦の破片 | 実が集中している部分の上にだけ載せます | 部分的です |
| 藁マルチング | 雨粒が土から跳ねるのを防ぎます | 上から降る雨は防げません |
| 畝の方向の調整 | 風が通る方向に畝を作り、早く乾くようにします | 効果は限定的です |

&nbsp;&nbsp;&nbsp;完全な代替はありません。藁マルチングと広い植え付け間隔と抵抗性品種を重ねて使うのが現実的な組み合わせであり、それでも韓国の梅雨（チャンマ、6月下旬～7月）が長く湿った年には損失を避けるのが難しくなります。そのため、家の周りの軒下や塀の下のように雨が当たりにくい場所に数株を別に植えておく配置が、実質的な保険になります。畑全体がだめになっても、その数株から翌年の種を採ることができます。

## 9. 病害虫 - 炭疽病という壁

### 9-1. 主な病害

| 病名 | 症状 | 発生条件 | 薬なしでの対応 |
|---|---|---|---|
| 炭疽病 | 熟していく実に水に濡れたような丸い斑点ができ、くぼんで黒い胞子の塊ができます | 梅雨時の高温多湿、雨の後 | 治療薬がありません。病んだ実を直ちに摘み取って焼却します。抵抗性品種、雨よけ、藁マルチング |
| 疫病 | 茎の根元が暗褐色にくびれ、株が急速にしおれて枯れます | 過湿、排水不良、水がたまる場所 | 高畝と排水路が唯一の構造的対策です。罹病株を直ちに除去します |
| 細菌性斑点病 | 葉に水に濡れたような小さな点ができ、褐色に変わります | 多湿、風雨の後 | ボルドー液の予防散布、通風の確保 |
| ウイルス病 | 葉がまだら模様になって縮れ、実が奇形になります | アブラムシ・アザミウマが媒介します | 治療不可。媒介虫の防除と罹病株の除去 |
| 灰色かび病 | 花と実に灰色のカビが生えて腐ります | 低温多湿、通風不良 | 咲き終わった花を払い落とし、通風を確保します |
| 青枯病 | 日中しおれて朝に回復することを繰り返した末に枯れます | 高温、土壌伝染 | 治療不可。罹病株の除去と長期輪作 |
| うどんこ病 | 葉に白い粉が広がり、葉が落ちます | 乾燥と多湿が交互に来るとき | 牛乳希釈液、重曹希釈液 |

### 9-2. 炭疽病を個別に理解する

&nbsp;&nbsp;&nbsp;炭疽病はColletotrichum属のカビが引き起こします。この菌は畑に残った罹病残渣や種子に付着して冬を越し、春に胞子を作って機会を待ちます。感染は実の表面に水滴がついた状態で起こり、25-30℃の温度と濡れた表面が数時間続くと、胞子が発芽して果皮を突き破って入り込みます。梅雨時がまさにその条件です。

&nbsp;&nbsp;&nbsp;この病気が特に厄介な理由は、潜伏感染にあります。菌は青唐辛子の幼い時期に侵入しておきながら症状を出さずに静かに待ちます。そして実が熟して赤くなる頃、組織が柔らかくなり糖分が増えると、そこで活動を始めて斑点を作ります。そのため、見た目には無事だった畑が、赤唐辛子が熟し始めた時点から数日で崩壊します。すでに感染した状態では、どんな対策も手遅れです。

> **炭疽病に治療法はありません。この事実が評価表の防除自立度Dを作っています。できることは感染そのものを減らすことだけであり、その手段は抵抗性品種、雨よけ、藁マルチング、広い間隔、病んだ実の即時除去の五つです。**

| 手段 | 効果 | 資材負担 |
|---|:---:|---|
| 抵抗性品種 | 大 | 種子の確保が鍵です |
| 雨よけ | 大 | 被覆材が必要です |
| 藁マルチング | 中 | 稲わら・草でまかなえます |
| 広い植え付け間隔 | 中 | 資材は不要です |
| 病んだ実の即時除去 | 中 | 手間がかかります |
| 畑の残渣の焼却 | 中 | 翌年の伝染源を減らします |
| 種子の温湯消毒 | 小-中 | 種子由来の伝染分を減らします |
| 早期収穫（青唐辛子中心） | 大 | 唐辛子粉をあきらめる代償があります |

&nbsp;&nbsp;&nbsp;最後の項目が現実的に最も確実な回避策です。炭疽病は熟していく実を襲う病気なので、熟す前に摘み取ってしまえば病気が発現する対象がなくなります。梅雨が長くなりそうな年には、赤唐辛子にこだわらず青唐辛子として摘み続ける判断が、全体の損失を減らします。その代わりその年の唐辛子粉はあきらめることになるので、貯蔵性Sを利用して前年に収穫した乾燥トウガラシを残しておく備えも合わせて必要です。

### 9-3. 主な害虫

| 害虫 | 被害 | 薬なしでの対応 |
|---|---|---|
| アブラムシ | 新芽と葉裏の汁を吸い、ウイルスを媒介します | 石鹸水の散布、手でつぶす、テントウムシ・クサカゲロウの保護 |
| アザミウマ | 花と若い実に傷をつけ、ウイルスを媒介します | 青色の粘着トラップ、藁マルチング、周辺の雑草除去 |
| タバコガ | 幼虫が実の中に入り込み、種と胎座をかじって食べます | 穴の開いた実を直ちに摘み取って処分し、幼虫は手で捕まえます |
| ハダニ | 葉裏から汁を吸い、葉が白っぽく変わります | 葉裏に水を強く吹きかけます。乾燥時に悪化します |
| カメムシ | 実の汁を吸い、その部分が硬くなります | 早朝に手で捕まえます |

&nbsp;&nbsp;&nbsp;タバコガについては別途触れる価値があります。幼虫は実のへた付近に穴を開けて中に入り込み、胎座と種を食べます。いったん中に入ってしまうと、薬を散布しても届きません。薬のない条件では、穴の開いた実を見つけ次第摘み取って処分することがすべてであり、中にいる幼虫が育って次の世代を作るため、摘み取った実は踏みつぶすか焼却します。

### 9-4. 薬を使わない防除剤

| 防除剤 | 作り方 | 用途 | 注意 |
|---|---|---|---|
| ボルドー液 | 硫酸銅1kgと生石灰1kgを別々に溶かして冷ましたのち合わせ、水100Lで薄めます | 細菌性斑点病・疫病の予防 | 予防剤です。高温期に濃く使うと葉が焼けます |
| 石鹸水 | 無香料の石鹸20gを水1Lに溶かします | アブラムシ・ハダニ | 葉裏に触れてこそ効果があります |
| 牛乳希釈液 | 牛乳と水を1対1から1対2で混ぜます | うどんこ病 | 乾く過程で菌糸を押さえつけます |
| 草木灰 | 篩った灰を葉と土に軽くまきます | 害虫忌避、カリウム供給 | 雨で流されます |
| 木酢液 | 300-500倍に希釈します | 忌避、微生物の活性化 | 原液は強酸性です |
| 卵黄油 | 卵黄1個と食用油60mLを混ぜて乳化させたのち、水20Lに溶かします | うどんこ病・ハダニ | 油が貴重な条件では使いにくいです |

### 9-5. 耕種的防除

| 方法 | 原理 |
|---|---|
| 輪作 | ナス科作物を5-7年間隔で回し、土壌伝染病の密度を下げます |
| 高畝と排水路 | 疫病の遊走子の移動経路を断ちます |
| 広い植え付け間隔 | 通風により葉と実が早く乾くようにします |
| 藁マルチング | 雨粒が土から跳ねるのを防ぎます |
| 病んだ実・株の即時除去 | 畑の中の伝染源を減らします |
| 収穫後の残渣焼却 | 翌年の一次伝染源をなくします |
| 種子の温湯消毒 | 種子に付着した菌を殺します |
| 畝を風向きに合わせる | 葉と実が早く乾きます |

&nbsp;&nbsp;&nbsp;収穫後の残渣処理を軽く見てはいけません。炭疽病菌は畑に残った病んだ実と茎で冬を越し、翌年の最初の感染源になります。トウガラシを片付けた跡に病んだ実が転がっている畑は、翌年はるかに早く病気が始まります。片付けた茎と実をその場で焼却するか畑の外に運んで処理することが、翌年の防除の半分を占めます。

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 自然の材料でできる対処 |
|---|---|---|
| 下葉から全体が黄色くなり、株が小さいです | 窒素欠乏 | 尿を10-15倍に薄めて溝に注ぐか、腐熟堆肥を入れます |
| 葉の縁が茶色く焦げたようになり、実が小さいです | カリウム欠乏 | 草木灰を株ごとに一握り、土に混ぜます |
| 生育が遅く、葉裏と茎が紫色を帯びます | リン酸欠乏 | 骨粉、草木灰。低温期には土が冷たく吸収されないこともあります |
| 実の先端が黒くくぼんで腐ります | カルシウム移動障害（尻腐れ病） | 均一な灌水とマルチングが根本対策です。貝殻を焼いた粉を補助的に使います |
| 花が咲いてもそのまま落ちます | ホウ素欠乏、高温、窒素過剰、水不足 | 原因が複数あるため順番に確認します |
| 葉脈の間だけ黄色くなり、葉脈は緑色のまま残ります | マグネシウム欠乏 | 苦土石灰（ドロマイト粉）、堆肥原料の多様化 |
| 葉ばかり茂って濃い緑色なのに花が少ないです | 窒素過剰 | 窒素を止め、草木灰でカリウムを補います |
| 実の色が薄くまだらになります | カリウム不足または日照不足 | 草木灰を入れ、重なった茎を間引きます |

&nbsp;&nbsp;&nbsp;トウガラシで最もよく出会うのが尻腐れ病です。名前に「病」とついていますが、病原菌が引き起こす病気ではなく、カルシウムが実の先端まで届かないために生じる生理障害です。カルシウムは水の流れに乗って移動する元素なので、土が乾いたり湿ったりを繰り返すとその流れが途切れます。特に実が急速に大きくなる時期に水が一度大きく不足すると、その時期に育っていた実がいっせいに症状を示します。

> **尻腐れ病を見て、カルシウムをさらに入れるのはたいてい無駄骨です。土にカルシウムがない場合はまれで、問題は水の流れです。マルチングで土の水分を均一に保つことが実質的な解決策です。**

&nbsp;&nbsp;&nbsp;花が落ちる現象は原因が複数あるため、順番にたどる必要があります。第一に気温を見ます。35度を超える日が続いていれば高温が原因で、人にできることはあまりありません。第二に土を見ます。乾いていれば水不足です。第三に株を見ます。葉が濃い緑で茂っていれば窒素過剰です。第四に日差しを見ます。梅雨で曇りの日が続いていれば光合成不足です。この四つを確認して、ようやくホウ素欠乏を疑う順番になります。

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 対象 | 理由 |
|:---:|---|---|
| 良い | マメ科作物（インゲンマメ・ササゲ） | 窒素を固定して土に残します |
| 良い | キンセンカ（マリーゴールド） | ネコブセンチュウを抑えます |
| 良い | 長ネギ・ニンニク・ニラ | 硫黄化合物が土壌病原菌の密度を下げます |
| 良い | エゴマ・シソ | 強い香りが害虫を混乱させます |
| 悪い | ナス・トマト・ジャガイモ | 疫病と青枯病をまるごと共有します |
| 悪い | トウモロコシ | 陰を作り、養分競争が大きいです |
| 悪い | ウリ科（カボチャ・キュウリ） | つるが覆って通風を妨げます |

&nbsp;&nbsp;&nbsp;トウガラシの畝の間にエゴマを植える配置は、昔からよく見られました。エゴマの強い香りが害虫の寄主探索を妨げ、エゴマ自体も葉と種実として使えます。ただしエゴマが大きくなるとトウガラシの日光を遮るため、畝の端や畑の縁に置くほうがよいでしょう。ネギとニンニクをトウガラシの間に植える配置も同じ考え方によるもので、こちらは背が低いため陰の問題がありません。

### 11-2. 輪作

| 年 | 作物 | 目的 |
|---|---|---|
| 1年目 | トウガラシ | |
| 2年目 | マメ科（ダイズ・インゲンマメ・ササゲ） | 窒素の回復、ナス科病原菌の餌の遮断 |
| 3年目 | ネギ属（長ネギ・ニンニク・タマネギ） | 硫黄化合物で土壌病原菌を抑制 |
| 4年目 | 穀物（トウモロコシ・モロコシ・アワ） | 有機物の還元、根の深さの変化 |
| 5年目 | 葉菜類または根菜類 | |
| 6年目以降 | トウガラシを再開 | |

&nbsp;&nbsp;&nbsp;5年から7年の休作を狭い土地で守るのは困難です。そのためトウガラシでは、場所を移しながら育てる方法が現実的な代案になります。トウガラシは20株から30株あれば一世帯の一年分の消費をまかなえるため、広い畑ではなく家の周りや畑の縁で毎年場所を変えながら植える方式が可能です。こうすれば同じ土に病原菌が蓄積せず、軒下のように雨が当たりにくい場所を選ぶこともできます。

> **同じ場所でトウガラシを3年以上続けて植えると、最初は無事でも、ある年突然疫病で半分が枯れます。土壌病原菌は静かに蓄積し、あるとき一気に現れます。場所を移すのは、病気が出たあとにする作業ではなく、出る前にしておく作業です。**

&nbsp;&nbsp;&nbsp;トウガラシの後に何を植えるかも考えどころです。トウガラシは四か月の間に多くの養分を持ち出し、残渣に病原菌を残します。マメ科が第一候補なのは、窒素を回復させながらナス科病原菌の宿主にならないためです。ネギ属が第二候補なのは、根から出る硫黄化合物が土壌微生物の構成を変えて病原菌の密度を下げるためです。トウガラシを抜いた跡にニンニクを植えて冬を越させる配置は、土地を遊ばせずに消毒効果を得る方法です。

## 12. 収穫 - 青唐辛子と赤唐辛子

| 用途 | 収穫時期 | 基準 |
|---|---|---|
| 青唐辛子 | 開花後20-30日 | 本来の大きさまで育ち、果皮に艶があるとき |
| 赤唐辛子（乾燥用） | 開花後45-50日 | 真紅に変わり、表面にしわが寄り始めるとき |

| 摘み方 | へたを残して手で折るか、はさみで切ります | 茎が裂けないようにします |

### 12-1. どちらを収穫するか

&nbsp;&nbsp;&nbsp;青唐辛子と赤唐辛子は別の作物ではなく、同じ実の異なる時点であるため、どちらを収穫するかは選択の問題です。この選択によって、その年の損得が大きく変わります。

| 項目 | 青唐辛子 | 赤唐辛子 |
|---|---|---|
| 収穫時点 | 早いです（6月中旬から） | 遅いです（7月下旬から） |
| 炭疽病への曝露 | 短いです | 長いです。この病気は熟していく実を襲います |
| 貯蔵 | ほぼ不可能です。常温で1-2週間 | 乾燥させれば1-2年 |
| ビタミンC | 残っています | 乾燥の過程でほとんど失われます |
| 株の寿命 | 摘み続ければ新しい花が続きます | 熟させると株が早く疲れます |
| 用途 | その場で食べるおかず | 一年中使う調味料 |

> **下のほうの実は青唐辛子として摘み、上のほうの実を赤唐辛子として熟させる配分が、最もバランスが取れています。下のほうは土に近く炭疽病の危険が大きく、上のほうは日当たりと風通しが良いため安全に熟します。**

&nbsp;&nbsp;&nbsp;梅雨が長くなりそうな年には、判断を早めなければなりません。熟していく実が病気にかかって落ちればもう何も残りませんが、青唐辛子として摘めば少なくともその重さは確保できます。逆に乾燥する年には赤唐辛子の割合を増やし、一年分の唐辛子粉を確保します。この判断を7月上旬に下すことになり、それがトウガラシ栽培において最も重要な決定です。

### 12-2. 収穫のコツ

&nbsp;&nbsp;&nbsp;赤唐辛子を摘むとき、へたをつけたまま摘む理由があります。へたを取った跡からカビが入り込み、乾燥中にその部分から黒く変わります。へたをつけたまま乾燥させれば、その入り口がふさがれているため乾燥が安定します。乾燥させたあと、挽く前にへたを取ればよく、そのときはすっかり乾いているので手で簡単に取れます。

&nbsp;&nbsp;&nbsp;露が乾いたあとに摘むことも原則です。濡れたトウガラシをそのまま積んでおくと、数時間でカビが始まります。雨のあとは最低でも半日、できれば一日待ちます。雨に濡れた実を摘まなければならない状況なら、広げて水気を乾かしてから乾燥に入ります。

&nbsp;&nbsp;&nbsp;病んだ実は別に摘んで畑の外に持ち出します。無事なものと混ぜて入れると、運搬中に胞子が付着し、乾燥台の上で隣のトウガラシに広がります。炭疽病の斑点があるトウガラシは、乾燥させてもその部分が広がり続け、結局全体を捨てることになります。
