## 8. 栽培管理 - 摘心と人工授粉

### 8-1. 摘心の原理

&nbsp;&nbsp;&nbsp;カボチャのつるには序列があります。種からまっすぐ伸びた最初のつるが親づる、親づるの葉腋から出たものが子づる、子づるから出たものが孫づるです。この序列によって雌花がつく位置が変わり、摘心はその位置を調節する作業です。

| つる | 雌花のつき方 |
|---|---|
| 親づる | 雌花は遅く、まばらにつきます。雄花ばかりがしばらく咲き続けます |
| 子づる | 雌花がよくつきます。たいていはここで果実を得ます |
| 孫づる | 雌花はつきますが、勢いが弱く果実が小さくなります |

&nbsp;&nbsp;&nbsp;そのため、親づるの生長点を早めに切って子づるを早く出させることが摘心の目的です。放任栽培より収穫量が30%ほど増えると報告されている根拠は、ここにあります。

| 方法 | 手順 |
|---|---|
| 親づる1本 + 子づる2本 | 本葉5-6枚のときに親づるの生長点を切ります。出てきた子づるのうち丈夫な2本だけを残し、残りは取り除きます |
| 親づる5-6節で摘心 + 子づる3-4本 | 親づるを5-6節で切り、子づる3-4本を四方に誘引します |
| 放任 | 何もしません。収量は劣りますが、手間がかかりません |

> **摘心をするかどうかは、労働力とスペースの問題です。人手が足りない状況なら、放任してもカボチャは実をつけます。ただし、果実は小さく、数もばらつきます。逆にスペースが狭い場合、摘心は必須になります。つるを制御してこそ、狭い面積に複数の株を植えられます。**

### 8-2. 着果管理 - 何個育てるか

| 段階 | 内容 |
|---|---|
| 雌花の位置の確認 | 最初の雌花は子づるの8節あたり、2番目は13節、3番目は18節付近につきます |
| 着果させる雌花の選択 | 勢いが十分についた後の雌花、たいてい2、3番目の雌花に果実をつけさせます |
| 残りの除去 | 早すぎる時期についた果実や形の悪い果実は、小さいうちに摘み取ります |
| 最終目標 | つる1本につき1個、1株あたり2個前後 |

&nbsp;&nbsp;&nbsp;最初の雌花についた果実を摘み取る理由は、ナスやトウガラシと同じです。まだつるが短く葉が少ない状態で果実1個に養分が集中すると、株全体が育たなくなります。前に見たとおり、果実1個をきちんと育てるには葉が20-25枚必要なので、それだけの葉がそろってからの雌花に果実をつけさせるのが理にかなっています。

&nbsp;&nbsp;&nbsp;1株に何個つけるかは、目的によって分かれます。大きなカボチャを2、3個得たいなら残りを摘み取り、小さなカボチャを多数得たいならそのままにしておきます。貯蔵が目的なら、大きいほうが有利です。大きなカボチャは表面積に対する体積が大きいため水分の損失が遅く、皮もより厚く固まります。小さなカボチャは貯蔵中に早く乾いてしまいます。

### 8-3. 人工授粉 - ハチがいないとき

&nbsp;&nbsp;&nbsp;カボチャは雌花と雄花が別々に咲き、花粉が重くて粘り気があるため、風では運ばれません。必ず昆虫が運ぶ必要があり、昆虫が来なければ、雌花は咲いてもそのまま黄色くしぼんで落ちてしまいます。これがこの作物の構造的な弱点です。

| 条件 | 結果 |
|---|---|
| 韓国の梅雨（チャンマ、6月下旬～7月）で雨が続き、ハチが飛べない | その期間の雌花がすべて落ちます |
| 周囲にハチが少ない | 着果率が大きく下がります |
| 35℃を超える猛暑 | 花粉が活力を失い、受精しません |
| 早朝に雨が降る | 花粉が濡れて付着しません |

| 段階 | 方法 |
|---|---|
| 1. 時刻 | 日の出直後から午前8時前まで。花はこの時間帯にしか開いておらず、花粉もこのときが最も活力があります |
| 2. 雄花を摘む | 満開の雄花を花柄ごと摘み取ります |
| 3. 花弁の除去 | 花弁を反らすかちぎって、雄しべだけを残します |
| 4. 花粉を移す | 雄しべを雌花の柱頭に直接こすりつけて、花粉をまんべんなくつけます |
| 5. 確認 | 三、四日後に子房が太くなれば成功です。黄色くしぼめば失敗です |

> **雄花1個で、雌花2、3個まで受粉させることができます。筆や綿球を使ってもかまいませんが、雄花をそのまま使うほうが簡単で確実です。結実率が2倍以上に上がるという報告があり、梅雨期や猛暑期にはその差がさらに大きくなります。**

&nbsp;&nbsp;&nbsp;もう一点付け加えておきます。人工授粉は着果を確実にする手段であると同時に、採種の中核をなす技術でもあります。どの花粉で受精したのかを人間が管理できるという意味だからです。第13節の隔離採種は、この技術の上に成り立っています。

### 8-4. 果実の保護

| 項目 | 方法 | 理由 |
|---|---|---|
| 敷き物を敷く | 果実の下に稲わら、板、瓦のかけらを敷きます | 土の湿気で下面が腐るのを防ぎます |
| 向きを変える | 成熟期に1、2回、果実をそっと回してやります | 下面にも日が当たり、色が均一につきます |
| 葉で覆う | 猛暑期に果実の上に葉やわらをかぶせます | 果皮が日焼けするのを防ぎます |
| 動かさない | つるを頻繁に動かしません | 節の不定根が切れます |

&nbsp;&nbsp;&nbsp;向きを変える作業は慎重に行う必要があります。ヘタがねじれると水と養分の通り道が傷み、ひどい場合はその部分が腐ります。そっと、少しずつ、成熟期の後半に1、2回行えば十分です。

## 9. 病害虫 - 農薬を使わずに防ぐ方法

### 9-1. 主な病害

| 病名 | 症状 | 発生条件 | 農薬を使わない対応 |
|---|---|---|---|
| うどんこ病 | 葉の表面が白い粉に覆われ、葉が枯れます | 乾燥と高湿が交互に訪れる、韓国の8-9月 | 卵黄油、牛乳の希釈液、重曹の希釈液。下葉の整理 |
| べと病 | 葉脈に囲まれた角ばった黄色い斑点ができ、裏面にカビが生えます | 多湿、低温 | 風通しの確保、ボルドー液による予防 |
| つる割病 | 株元が縦に裂けてヤニが出て、株がしおれます | 過湿、土壌伝染 | 治療不可。罹病株の除去、排水改善 |
| 疫病 | 根と茎が軟らかく腐り、果実にも広がります | 過湿、水がたまる場所 | 高畝と排水。罹病株をただちに除去 |
| 炭疽病 | 葉と果実にくぼんだ斑点ができます | 高温多湿 | 病んだ部位の除去、風通し |
| モザイク病（ウイルス） | 葉がまだら模様になって縮れ、果実が奇形になります | アブラムシが媒介します | 治療不可。アブラムシの防除と罹病株の除去 |
| 白絹病 | 株元に白い菌糸とアワ粒のような粒ができます | 高温多湿、有機物の過多 | 罹病株の除去、土を乾かす |

&nbsp;&nbsp;&nbsp;カボチャで最もよく出合うのはうどんこ病です。韓国では8月下旬から、葉の表面に小麦粉をまいたような白い粉ができ、広がると葉が黄色く枯れて死んでしまいます。この病気自体が株を枯らすわけではありませんが、葉が死ぬと光合成が止まり、そうなると果実がきちんと熟しません。貯蔵性を左右する最後の1か月に葉が生きているかどうかが鍵になるため、うどんこ病の進行を遅らせることが、そのまま貯蔵用カボチャの品質を決めます。

> **うどんこ病は葉の表面で育つカビなので、表面に何かを塗っておくと効果があります。卵黄油や牛乳の希釈液が効く理由はここにあります。葉の内部に入り込む病気ではないため、農薬を使わずに対応できる余地が比較的大きいです。**

&nbsp;&nbsp;&nbsp;つる割病はその正反対です。土の中のカビが根から入り込んで導管を詰まらせ、株元が縦に裂けてヤニが出ます。治療法はなく、引き抜いて処分する以外にすることはありません。ただし、カボチャはこの病気に比較的強いほうで、そのため他のウリ科作物の台木として使われることもあります。連作適応性でSSが出た背景には、この抵抗性があります。

### 9-2. 主な害虫

| 害虫 | 被害 | 農薬を使わない対応 |
|---|---|---|
| アブラムシ | 新芽や葉裏の汁を吸い、モザイク病を媒介します | 石けん水の散布、手でつぶす、テントウムシの保護 |
| ナミハダニ | 葉裏で汁を吸い、葉が白くなります | 葉裏に水を強く吹きかけます。乾燥すると激しくなります |
| ウリハムシ | 若い葉に丸い穴をあけ、根もかじります | 幼苗期にネットをかけます。手で捕まえます |
| カメムシ | 果実の汁を吸い、その部分が固くなります | 早朝に手で捕まえます |
| ワタノメイガ | 葉を巻き、その中でかじって食べます | 巻いた葉を取り除きます |
| ネコブセンチュウ | 根にこぶができ、生育が悪くなります | キンセンカとの間作、輪作 |

### 9-3. 農薬を使わない防除資材

| 防除資材 | 作り方 | 用途 | 注意 |
|---|---|---|---|
| 卵黄油 | 卵の黄身1個を水100mLに溶き、食用油60mLを注いで強くかき混ぜて乳化させた後、水20Lに加えます | うどんこ病・ハダニ | 油が貴重な状況では使いにくいです。真昼に散布すると葉が焼けます |
| 牛乳の希釈液 | 牛乳と水を1対1から1対2で混ぜます | うどんこ病 | 乾くときに菌糸を押さえつけて貼りつけます |
| 重曹の希釈液 | 食用の重曹1gを水1Lに溶かします | うどんこ病 | 濃いと葉が傷みます |
| ボルドー液 | 硫酸銅1kgと生石灰1kgをそれぞれ別に溶かして冷ました後、合わせて水100Lに調整します | べと病・細菌病の予防 | 予防剤です |
| 石けん水 | 無香料の石けん20gを水1Lに溶かします | アブラムシ・ハダニ | 葉裏に当たる必要があります |
| 木酢液 | 300-500倍に希釈します | 忌避、微生物の活性化 | 原液は強酸性です |
| 草木灰 | ふるいにかけた草木灰を葉や土にまきます | ウリハムシの忌避、カリウム供給 | 雨で流されます |

&nbsp;&nbsp;&nbsp;卵黄油がカボチャで特によく挙げられる理由は、うどんこ病に対する効果が比較的確実だからです。油が葉の表面に薄い膜をつくって菌糸を覆い、卵黄のレシチンがその油を水に均一に分散させます。ただし、油は災害時には貴重な資源なので、カボチャの種から油を搾れるという事実が、ここで思いがけないつながりになります。種子油の一部を防除に回すことができます。

### 9-4. 耕種的防除

| 方法 | 原理 |
|---|---|
| 高畝と排水溝 | つる割病と疫病の発生条件をなくします |
| 広い栽植間隔 | 風通しがよくなって葉が早く乾き、カビによる病気が減ります |
| わらマルチング | 土から跳ね上がる雨滴を防ぎ、果実が土に触れないようにします |
| 下葉の整理 | 老化して弱った下葉が病気の足がかりになります |
| 病葉の即時除去 | うどんこ病は、初期に葉を数枚取り除くと大きく遅らせることができます |
| 収穫後の残渣処理 | つると葉を片づけて初めて、翌年の伝染源が減ります |
| キンセンカとの間作 | ネコブセンチュウを抑えます |

&nbsp;&nbsp;&nbsp;うどんこ病では、初期対応がとりわけ効果的です。この病気は1、2枚の葉から始まって広がるため、最初に白い斑点が見えた葉を3、4枚すぐに取り除いて畑の外に持ち出せば、広がりが大きく遅れます。毎日畑を見回る人とそうでない人とで、結果が大きく分かれる病気です。

## 10. 栄養素の欠乏と過剰

| 症状 | 原因 | 天然資材による対処 |
|---|---|---|
| 下葉から全体が黄色くなり、つるが細くなります | 窒素欠乏 | つるの伸長期なら、薄めた尿（10-15倍希釈）。着果後なら施しません |
| 葉の縁が茶色く枯れ込み、果実が小さくなります | カリウム欠乏 | 草木灰を株の周りにひとつかみずつ |
| 生育が遅く、葉が小さく、紫色を帯びます | リン酸欠乏 | 骨粉、草木灰。低温期には吸収されない場合もあります |
| つるばかり旺盛で節間が長く、雌花が出ません | 窒素過剰 | 窒素を断ち、草木灰でカリウムを補います。摘心で生育を抑えます |
| 雌花が咲いても果実が大きくならず、落ちます | 受粉の失敗 | たいてい肥料の問題ではなく、受粉の問題です。人工授粉を行います |
| 葉脈の間だけが黄色くなり、葉脈は緑色です | マグネシウム欠乏 | ドロマイト粉、堆肥原料の多様化 |
| 果実の先端が軟らかく腐ります | カルシウムの移動障害または過湿 | 排水の改善と均一な灌水 |
| 果肉の色が薄く、甘みが少なくなります | カリウム不足、日照不足、早採り | 草木灰の補充、葉の整理、収穫を遅らせます |

&nbsp;&nbsp;&nbsp;カボチャで最もよくある誤診が、雌花の落下です。雌花が咲いたのに果実が大きくならず、黄色くしぼんで落ちると、肥料が足りないのだと考えがちですが、大部分は受粉できていないのです。見分け方は、子房を見ることです。受精していれば、三、四日以内に子房が目に見えて太くなります。太くならず、花から先に黄色くなれば、受精の失敗です。

> **肥料を追加すべきときと、手で花粉を移すべきときを区別できないと、窒素をさらに施してつるばかり茂らせ、雌花がいっそう減るという悪循環に陥ります。雌花は出るのに果実がつかないなら、まず人工授粉を試みます。**

## 11. 間作と輪作

### 11-1. 相性

| 相性 | 対象 | 理由 |
|:---:|---|---|
| 良い | トウモロコシ | トウモロコシが上に伸び、カボチャが地面を覆うため、層が分かれます |
| 良い | マメ科作物 | 窒素を固定して土に残します |
| 良い | キンセンカ | ネコブセンチュウを抑えます |
| 良い | エゴマ・シソ | 香りで害虫を惑わせます |
| 悪い | 他のウリ科（キュウリ・スイカ・マクワウリ） | 病害虫を共有し、交雑の危険もあります |
| 悪い | ジャガイモ | 疫病の系統を共有し、互いにスペースを奪い合います |
| 悪い | 背の低い葉菜類 | カボチャのつるが覆ってしまいます |

&nbsp;&nbsp;&nbsp;トウモロコシと豆とカボチャを一緒に植える配置は、アメリカ先住民が長く用いてきた方法です。トウモロコシが茎を立て、豆がその茎をよじ登りながら根で窒素を固定し、カボチャが地面を覆って雑草を抑え、土の水分を守ります。3つの作物がそれぞれ異なる高さと異なる根の深さを使うため、競合が少なくなります。狭い土地では、この配置が単作より総収穫量が多くなる場合があります。

| 層 | 作物 | 役割 |
|---|---|---|
| 上 | トウモロコシ | 熱量、豆の支柱 |
| 中 | つる性の豆 | タンパク質、窒素固定 |
| 下 | カボチャ | 熱量とビタミン、地面の被覆、雑草抑制 |

&nbsp;&nbsp;&nbsp;ただし、この配置には条件があります。トウモロコシを先に植えて膝の高さまで育ててから、豆とカボチャを入れる必要があります。3つを一度に植えると、カボチャのつるが若いトウモロコシを覆ってしまいます。また、カボチャがトウモロコシの間を完全に覆うと、トウモロコシの収穫時に踏み込んで入るのが難しくなります。カボチャのつるを一方向、畑の外側へ誘引するほうが、実務的には優れています。

### 11-2. 輪作

&nbsp;&nbsp;&nbsp;カボチャの連作適応性はSSで、連作無害群です。この評価表では非常にまれな等級であり、同じウリ科のキュウリとスイカが3年から5年の休作を要求するのと対照的です。したがって、狭い土地で同じ場所を何年も使うことができます。

| 年 | 作物 | 目的 |
|---|---|---|
| 1年目 | カボチャ | |
| 2年目 | カボチャ（可）またはマメ科 | 連作は可能ですが、マメ科を入れると地力が回復します |
| 3年目 | 穀物または葉菜類 | 土の養分構成を変えます |
| 4年目 | カボチャを再開 | |

> **連作が可能だということは、連作を勧めるという意味ではありません。病害が蓄積しにくいというだけで、同じ作物を続けて植えると、その作物が多く使う養分が偏って減っていきます。3年に1回は別の作物を入れるほうがよいです。**

&nbsp;&nbsp;&nbsp;他のウリ科作物との関係は、2つに分けて考える必要があります。病害虫の面では、キュウリとスイカとマクワウリがうどんこ病とべと病とつる割病を共有するため、隣に植えるのは不利です。交雑の面では話が異なります。キュウリ（Cucumis sativus）とスイカ（CitrullusLanatus）は属が違うため、カボチャとは交雑しません。問題になるのは同じカボチャ属（Cucurbita）の中だけで、その中でも同じ種どうしだけが完全に交雑します。

&nbsp;&nbsp;&nbsp;カボチャの後に何を植えるかも、考えておくべき点です。カボチャはつると葉の量が多く、収穫後にかなりの有機物を残します。健康なつるを細かく刻んでその場にすき込めば、翌年の肥料になります。病気の葉は除いてすき込みます。カボチャの後にニンニクやタマネギを植えて冬を越させる配置は、土地を遊ばせずに土壌病原菌を減らす方法です。
