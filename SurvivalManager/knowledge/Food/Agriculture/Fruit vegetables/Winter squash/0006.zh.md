## 12. 收获 - 辨别成熟的方法

| 类别 | 标准 |
|---|---|
| 成熟所需时间 | 开花后50-60天 |
| 收获时期 | 在韩国为9月上旬-10月中旬，初霜之前 |
| 嫩南瓜（aehobak，韩国食用的未熟南瓜） | 开花后7-10天，指甲能掐入果皮时 |
| 收获天气 | 晴朗干燥的日子。避开刚下过雨之后 |
| 切取方法 | 用刀或修枝剪，留3-5cm瓜蒂剪下 |
| 搬运方法 | 为避免受伤，一个一个地拿起搬运 |

### 12-1. 成熟的三个信号

| 信号 | 内容 | 重要程度 |
|---|---|---|
| 果皮颜色 | 已从绿色完全变为黄褐色 | 必要 |
| 白粉 | 整个果皮上均匀地浮出一层白色粉状物 | 必要 |
| 瓜蒂 | 像木头一样干硬，并出现纵向裂纹 | 最可靠的信号 |
| 硬度 | 用指甲按压也不留痕迹 | 辅助 |
| 声音 | 敲击时声音沉闷 | 辅助 |

> **如果只能从三个信号中选一个，就看瓜蒂。瓜蒂如果还带绿色且发软，那么无论果皮多黄，都还没有成熟。瓜蒂干硬如木、变得像软木一样时，才是可以贮藏的状态。**

&nbsp;&nbsp;&nbsp;果皮表面的白粉是植物为防止水分蒸发而分泌出的蜡质层。白粉均匀浮出，说明果实自己已经进入了贮藏状态。这层蜡质在贮藏期间保护果皮，因此不要擦掉。洗过再贮藏不行，原因也在于此。如果沾了泥土，只用干布轻轻掸掉即可。

### 12-2. 为什么要留蒂并用刀切下

&nbsp;&nbsp;&nbsp;采收南瓜时，不能用手拧摘。一拧，瓜蒂就会从果实一侧被撕掉，在那个位置留下开放的伤口。这个伤口会成为贮藏期间腐烂的起点。如果用刀或修枝剪留下3-5cm瓜蒂，从蔓一侧剪断，瓜蒂仍连在果实上，就能起到塞子的作用。

| 状态 | 贮藏结果 |
|---|---|
| 瓜蒂留有3-5cm且已干燥 | 三四个月至六个月 |
| 瓜蒂留得很短 | 两三个月 |
| 瓜蒂脱落留下孔洞 | 几周内从该处开始腐烂 |
| 果皮有划伤 | 从该处开始长霉 |

&nbsp;&nbsp;&nbsp;因此搬运时也要小心。滚动、投掷，或者堆放时让果实相互碰撞，都会产生不易察觉的伤，大约一个月后，那个位置就会变软。要一个一个拿起来搬运，并在地面铺上稻草或青草来缓冲。有伤的南瓜不要贮藏，先吃掉。

### 12-3. 受过霜冻的南瓜

&nbsp;&nbsp;&nbsp;初霜降下后，叶片和蔓会变黑枯死。果皮已经变硬的果实，一次轻霜不会使它立刻变坏，但细胞会受到损伤，耐储性大幅下降。受过霜冻的南瓜应从贮藏对象中剔除，先吃掉或晒干。因此，一旦有初霜预报，就要做出把包括未熟果在内的全部果实都收下来的决定。未成熟的南瓜无法贮藏，可以像嫩南瓜一样烹饪食用，或切片晒干。

## 13. 留种 - 葫芦科的杂交壁垒

### 13-1. 与什么杂交

&nbsp;&nbsp;&nbsp;南瓜留种时，首先要了解的是它与什么会杂交、与什么不会杂交。这个区分决定一切。

| 作物 | 学名 | 与南瓜杂交 |
|---|---|:---:|
| 嫩南瓜、青南瓜、老南瓜、奶油南瓜 | Cucurbitamoschata | 完全杂交 |
| 板栗南瓜（甜南瓜）、药用南瓜（yakhobak） | Cucurbitamaxima | 几乎不杂交（偶有不育杂种） |
| 西葫芦、金丝瓜、观赏南瓜 | Cucurbita pepo | 几乎不杂交 |
| 黄瓜 | Cucumis sativus | 属不同，不杂交 |
| 韩国甜瓜（chamoe）·蜜瓜 | Cucumismelo | 属不同，不杂交 |
| 西瓜 | CitrullusLanatus | 属不同，不杂交 |
| 葫芦（瓠瓜） | Lagenaria siceraria | 属不同，不杂交 |

> **说南瓜会与黄瓜或西瓜杂交，并不是事实。属不同，花粉落到柱头上也不会受精。真正成为问题的是同为Cucurbitamoschata的品种之间，也就是南瓜、嫩南瓜和奶油南瓜之间。**

&nbsp;&nbsp;&nbsp;这一事实在实际操作中会带来很大差别。田里即使同时有黄瓜、甜瓜和西瓜，也丝毫不影响南瓜留种。甜南瓜（C.maxima）和西葫芦（C. pepo）原则上也是安全的。需要提防的只是同一物种的其他品系，其中嫩南瓜用品种是最常见的污染源。嫩南瓜和南瓜都是C.moschata，所以会完全杂交。

&nbsp;&nbsp;&nbsp;不过，区分物种比想象的要棘手。市面上的南瓜仅凭外形很难分辨到物种，仅凭品种名称也常常无法判断。最可靠的方法是看瓜蒂。

| 物种 | 瓜蒂形状 |
|---|---|
| C.moschata | 呈向外展开的五边形，木质化坚硬 |
| C.maxima | 圆而粗，呈海绵状软木质 |
| C. pepo | 五个棱角分明的星形，坚硬 |

### 13-2. 防止杂交的方法

| 方法 | 内容 | 可行性 |
|---|---|---|
| 只种一个物种 | 完全不种同一物种的其他品系 | 最简单、最可靠 |
| 隔离距离 | 与其他品系相距500m以上 | 蜜蜂活动半径大，难以做到 |
| 错期栽培 | 每年只让一个品系开花 | 种子寿命为6-10年，非常现实 |
| 人工授粉 + 套袋 | 开花前一天给雌花和雄花套袋，次日早晨人工授粉后再套上 | 最可靠，小规模即可实行 |

&nbsp;&nbsp;&nbsp;南瓜种子能存活6-10年，这一事实在这里具有战略意义。选定一年作为留种年，那一年只种南瓜，并多收一些种子留存。此后的几年里，无论是嫩南瓜还是甜南瓜，都可以随意种植，因为已经收存的种子不会改变。这样一来，大约五六年只需遵守一次这个规矩，与必须年年留种的辣椒相比，负担的性质完全不同。

### 13-3. 通过人工授粉进行隔离留种

&nbsp;&nbsp;&nbsp;这是最可靠的方法。步骤以一天为间隔依次进行。

| 步骤 | 时间 | 内容 |
|---|---|---|
| 1. 确认花蕾 | 开花前一天下午 | 找出次日早晨要开的雌花和雄花。花蕾变黄鼓起，顶端快要裂开 |
| 2. 套袋 | 开花前一天下午 | 给雌花和雄花分别套上纸袋或布袋，并把袋口扎紧 |
| 3. 授粉 | 次日日出后不久-上午8点 | 摘下雄花并取下袋子，去除花瓣后，再取下雌花的袋子，将雄蕊涂抹在柱头上 |
| 4. 重新套袋 | 授粉后立即 | 给雌花重新套上袋子，两天后取下 |
| 5. 标记 | 授粉后立即 | 在花梗上系上绳子或布条，标明这是留种用的果实 |

&nbsp;&nbsp;&nbsp;套袋的原因是防止蜜蜂抢先访花。南瓜花在日出前开放，蜜蜂一出太阳就开始活动，如果前一天不套袋，在人动手之前花上就已经沾上了别的花粉。袋子以纸袋最好，塑料袋内部潮湿，会使花受损。布或无纺布也可以。

> **留种用的南瓜，要从多个植株上各取一两个。南瓜是异花授粉作物，如果一直只从一株上留种，随着世代增加，长势会逐渐衰弱，出现近交衰退。原则上至少从五株、最好从十株以上的植株上均匀取种。**

### 13-4. 留种步骤与保存

| 步骤 | 时间 | 内容 |
|---|---|---|
| 留种果选定 | 在韩国为8月 | 选择形状端正、无病、品种特性鲜明的果实 |
| 完熟 | 在韩国为9-10月 | 比食用南瓜放得更久，一直留到完全成熟 |
| 后熟 | 收获后2-4周 | 收下后再放2-4周，种子会更加饱满 |
| 取种 | 后熟后 | 将果实剖开，把种子连同瓜瓤一起刮出 |
| 清洗 | 立即 | 放入水中，用手搓洗，去除瓜瓤 |
| 筛选 | 清洗过程中 | 浮在水面的是空心的瘪籽，予以丢弃 |
| 干燥 | 洗后 | 在布或竹帘上摊成一层，在阴凉处放1-2周 |
| 保存 | 完全干燥后 | 与干燥剂一起放入密闭容器，置于阴凉黑暗处 |

&nbsp;&nbsp;&nbsp;不能把种子直接放在阳光下晒。直射光的热量会损伤胚，使发芽率下降。要在通风的阴凉处慢慢晾干，堆得太厚里面会长霉，因此要摊成一层。完全干透的南瓜子用手一掰就断，用两个指甲按压也按不进去。

| 项目 | 标准 |
|---|---|
| 每个果实的种子数 | 200-500粒 |
| 种子寿命 | 常温密闭下6-10年 |
| 目标含水量 | 8%以下 |
| 干燥剂 | 炒过晾凉的大米、木炭、干燥的草木灰 |
| 保存容器 | 玻璃瓶、金属罐、双层包裹的纸袋 |
| 发芽检查 | 每隔几年一次，将20粒种子放在湿布上，统计发芽率 |

&nbsp;&nbsp;&nbsp;一个果实能出200-500粒种子，所以只要两三个留种用的南瓜，就能确保几年的种子量。取完种子后剩下的果肉，直接吃就行。留种不会消耗粮食，这是这种作物的又一优点。去掉种子的南瓜仍是完整的食物，种子也可以炒着吃。

## 14. 毒性与需注意的成分

&nbsp;&nbsp;&nbsp;南瓜没有一般意义上的毒性。果实、叶、嫩梢、种子和花都可以食用。不过有一种物质需要了解，那就是葫芦素。

| 成分 | 是什么物质 | 会造成什么问题 | 判断标准 |
|---|---|---|---|
| 葫芦素 | 葫芦科植物为抵御食草动物而产生的苦味物质 | 大量食用会引起呕吐、腹痛、腹泻 | 有苦味就不要吃 |
| 霉菌 | 在贮藏中变质的部位上生长 | 可能产生毒素 | 变软并有异味就丢弃 |

### 14-1. 有苦味的南瓜

&nbsp;&nbsp;&nbsp;葫芦素（Cucurbitacin）是野生葫芦科植物原本具有的防御物质，在栽培种中，经过长期育种已基本消失。但在某些条件下，它会再次出现。

| 条件 | 说明 |
|---|---|
| 与观赏南瓜杂交的种子 | 观赏南瓜中仍保留着葫芦素，用其花粉受精的种子长成的植株，果实可能带苦味 |
| 野化的南瓜 | 田边自己长出来的南瓜，无法得知其品系 |
| 极端胁迫 | 有报告称，干旱或高温严重时，含量会上升 |

> **判断标准只有一个，就是味道。吃一口南瓜时，如果有刺舌的苦味，要立刻吐掉，并把整个南瓜都丢弃。煮熟也不会消失，若因舍不得而吃下去，几小时内就会出现呕吐和腹泻。严重时可能需要到医院治疗。**

&nbsp;&nbsp;&nbsp;这种风险在自家留种时尤其会增大。在留种并连续种植的过程中，可能不知从哪里混入了观赏南瓜的花粉，其结果有时要过几代才显现出来。因此，用自己留下的种子种出的南瓜，第一次吃时一定要养成先少量尝味的习惯。不苦就是安全的。

&nbsp;&nbsp;&nbsp;叶和嫩梢也一样。虽然可以食用，但苦味强烈的要避开。正常的南瓜叶只带一点青草味，不会苦。
