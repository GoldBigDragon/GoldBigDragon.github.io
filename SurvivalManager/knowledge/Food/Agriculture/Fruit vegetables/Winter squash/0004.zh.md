## 4. 品种

### 4-1. 南瓜类的系统与石磨南瓜的定位

| 系统 | 学名 | 代表 | 耐储性 | 灾害应对适合性 |
|---|---|---|:---:|---|
| 东洋系 | Cucurbitamoschata | 南瓜（石磨南瓜，maetdol hobak）、老南瓜、嫩南瓜（aehobak）、花生南瓜（ttangkong hobak，即奶油南瓜） | 非常好 | 耐热，耐储存，适合韩国的气候 |
| 西洋系 | Cucurbitamaxima | 板栗南瓜（甜南瓜）、药南瓜（yak hobak） | 好 | 甜度高，但不耐热，适合高冷地 |
| pepo系 | Cucurbita pepo | 西葫芦、金丝瓜 | 差 | 早熟，可以很快吃上，但不耐储存 |

### 4-2. 石磨南瓜各系统比较

| 品种 | 特征 | 产量 | 耐储性 | 灾害应对适合性 |
|---|---|:---:|:---:|---|
| 传统石磨南瓜 | 棱沟深而扁平，果肉为浓橙色 | 中等 | 非常好 | 是固定品种，可以留种延续 |
| cheongdung hobak | 与石磨南瓜属同一类，形状更圆 | 中等 | 非常好 | 特性相同 |
| 改良石磨南瓜 | 产量提高，抗病性得到加强 | 高 | 好 | 若为一代杂种，则无法留种 |
| 花生南瓜（奶油南瓜） | 颈部细长的钟形，籽室小，果肉比例高 | 中等 | 非常好 | 同属一个种，会与石磨南瓜杂交 |

### 4-3. 按情形选择的标准

| 情形 | 选择 | 原因 |
|---|---|---|
| 以获得冬季口粮为目的 | 传统石磨南瓜 | 耐储性最好，且可以留种延续 |
| 打算留种延续 | 传统系统、固定品种 | 从一代杂种留下的种子，翌年性状会分离 |
| 土地狭小 | 花生南瓜、pepo系 | 藤蔓短或果实小，空间利用率更高 |
| 夏天需要马上有东西吃 | pepo系（西葫芦）、嫩南瓜用 | 早熟，结果快 |
| 凉爽的高冷地 | 西洋系甜南瓜 | 比起炎热更喜欢凉爽 |

&nbsp;&nbsp;&nbsp;在灾害应对中选择石磨南瓜，原因有两个：耐储性和可留种。传统石磨南瓜是长期以来在韩国这片土地上留种延续下来的固定品种，这意味着今年留下的种子，来年仍能结出同样的南瓜。改良品种在产量和整齐度上占优，但多为一代杂种，一旦种子供应中断，就只有第一年有效。

> **南瓜种子在常温密封条件下可保存6-10年。这是所有比较作物中寿命最长的种子。在杂交管理得当的年份多收一些种子，此后好几年都可以不用留种，这是这种作物最大的战略优势。**

&nbsp;&nbsp;&nbsp;还要补充一点，把多个系统种在同一块田里，会引发杂交问题。石磨南瓜、嫩南瓜和花生南瓜都是C.moschata，所以彼此会完全混杂。如果打算留种，同一个种内只种一个品种最简单。反过来，甜南瓜（C.maxima）或西葫芦（C. pepo）与它们不是同一个种，即使种在一起，种子也不会混杂。了解这一点再来布置，就可以在种多个类型的同时，依然能够留种。

## 5. 整地与施肥

### 5-1. 整地

| 项目 | 标准 | 原因 |
|---|---|---|
| 耕深 | 25-30cm | 主根深扎 |
| 垄高 | 20-30cm | 防止韩国梅雨季（6月下旬至7月）的过湿 |
| 排水沟 | 田边和畦头 | 积水就会引来疫病 |
| 石灰处理 | 定植前2-3周 | 与堆肥同一天施入，氮会挥发 |
| 堆肥施入 | 种植前2周 | 只用腐熟堆肥 |
| 选位 | 藤蔓可延伸3-5m的空间 | 适合田边、围墙下 |
| 日照 | 每天日照6小时以上的位置 | |

&nbsp;&nbsp;&nbsp;南瓜的整地有一种特有的做法。不是在整个田面均匀地施肥，而是在每个定植位置挖一个坑，只把堆肥集中施在坑里。挖一个直径50cm、深30cm左右的坑，用堆肥和土各一半混合填入，再在上面盖土，堆成微微隆起的土包，然后放入种子。这样用少量堆肥就能取得很大的效果，藤蔓向外延伸所到之处的土地也不必施肥。在肥料紧缺的条件下，这是特别合理的做法。

### 5-2. 施肥量

| 肥料 | 每1,000㎡ | 每㎡ | 分配 |
|---|:---:|:---:|---|
| 氮（N） | 10-15kg | 10-15g | 分基肥和追肥施用 |
| 磷（P） | 8-12kg | 8-12g | 全部作基肥 |
| 钾（K） | 10-15kg | 10-15g | 分基肥和追肥施用 |
| 堆肥 | 1,500-2,000kg | 1.5-2kg | 种植前2周 |
| 石灰 | 100-150kg | 100-150g | 改良酸性土 |

&nbsp;&nbsp;&nbsp;氮、磷、钾加起来是每㎡30-40g，按评价表的标准是24g。施肥需求等级B，与茄子的D、辣椒的D相比，负担要轻得多。人们普遍认为南瓜很吃肥，但按单位面积来算并非如此。只是一株占的面积大，总量看上去显得多而已。

> **南瓜施用氮肥要特别小心。氮过量时，藤蔓长得很旺，却不出雌花。如果叶色浓绿、藤蔓粗壮、节间很长，却没有雌花，几乎可以肯定是氮过剩。**

### 5-3. 基肥与追肥的时期

| 类别 | 时期 | 内容 |
|---|---|---|
| 石灰 | 种植前3-4周 | 调节酸度 |
| 基肥 | 种植前2周 | 堆肥全部 + 磷全部 + 氮·钾50% |
| 第1次追肥 | 藤蔓伸长期（定植后一个月） | 以氮为主，少量 |
| 第2次追肥 | 刚坐果之后 | 以钾为主 |
| 停止 | 收获前20-30天 | 氮肥施到太晚，果皮不够硬实，耐储性会下降 |

&nbsp;&nbsp;&nbsp;最后一项与耐储性直接挂钩。成熟期氮持续进入，植株就会一直想长，果实的果皮就不能充分变硬。果皮软的南瓜在贮藏期间会腐烂。在韩国，8月中旬以后要停施氮肥，只补充钾，这是原则；进入9月后，什么都不施。

### 5-4. 不用化肥也能达到同样施肥量的办法

| 替代资源 | 提供的养分 | 用法 | 注意 |
|---|---|---|---|
| 充分腐熟的堆肥 | 氮·磷·钾和微量元素全面 | 与土各半混合后施入定植坑 | 未腐熟的堆肥会烧根 |
| 稀释尿液 | 氮 | 用水稀释10-15倍，只在藤蔓伸长期使用 | 坐果期以后不再施用 |
| 草木灰 | 钾·钙·磷 | 坐果后在植株周围每处撒一把 | 碱性强，不能过量 |
| 骨粉 | 磷·钙 | 作基肥混入坑中 | 分解慢 |
| 落叶·草 | 有机物·钾 | 铺在坑底，再盖土 | 腐熟不充分会产生发酵热 |
| 厨余 | 综合 | 埋入坑中，上面盖厚土 | 会被野兽刨开 |

&nbsp;&nbsp;&nbsp;有一种在堆肥堆旁边或堆上种南瓜的古老做法。这样可以直接利用堆肥腐熟过程中释放的养分和热量，同时藤蔓和叶片覆盖在堆肥堆上，还能使堆肥不干。不必另外搬运肥料，也不占地方，可谓一举两得。不过，直接种在没有腐熟的堆肥上，发酵热和氨会伤根，所以堆肥堆好后过了两三个月的堆边比较合适。

## 6. 播种与定植

### 6-1. 时期

| 栽培方式（韩国） | 播种 | 定植 | 收获 |
|---|---|---|---|
| 露地直播 | 4月中旬至下旬 | - | 9月上旬至10月中旬 |
| 育苗后定植 | 3月下旬至4月中旬 | 5月上旬至下旬 | 9月上旬至10月中旬 |

> **南瓜从播种到完全成熟需要120-150天。在韩国，4月种下，9月才能成熟。如果过了5月才种，霜降前果皮来不及变硬，最后只剩下无法贮藏的半成品南瓜。这种作物最无法挽回的失误，就是错过播种期。**

&nbsp;&nbsp;&nbsp;直播和育苗选哪一种，取决于地区和条件。直播简单，根不会受损，初期生长好，但要等晚霜的危险过去之后才能种，因此生长期会缩短。育苗可以把生长期提前2周到3周，但需要加温。幸运的是，南瓜的发芽适温为25-30℃，与辣椒、茄子相近，但育苗期只有3-4周，短得多。与茄子的70-80天相比，负担大不相同。

### 6-2. 育苗

| 项目 | 标准 |
|---|---|
| 种子处理 | 在水中浸泡一夜后，用湿布包好，在25-30℃下催芽 |
| 播种深度 | 2-3cm |
| 发芽温度 | 25-30℃，3-5天 |
| 育苗温度 | 白天22-28℃，夜间15℃以上 |
| 育苗期 | 3-4周，至长出3-4片真叶 |
| 定植适期的幼苗 | 3-4片真叶，子叶仍然存活的状态 |
| 炼苗 | 定植前1周起，白天放到室外 |

&nbsp;&nbsp;&nbsp;南瓜苗不能育得太大。超过5片真叶，根就会在容器里缠绕，移栽时缓苗很吃力。3-4片真叶、子叶还没有发黄枯萎的状态是最好的幼苗，过了这个状态，反而不如小苗。

&nbsp;&nbsp;&nbsp;南瓜籽大而厚，发芽时脱掉种皮很费劲。常常是种皮戴在子叶上就出土了，硬剥会把子叶撕破。轻轻喷些水使其软化后小心摘掉，或者干脆不管，几天之内它自己就会脱落。播种前用水浸泡一夜的处理，可以减少这个问题。

### 6-3. 种植

| 项目 | 标准 | 备注 |
|---|---|---|
| 畦宽 | 3.5-4m | 是藤蔓延伸的空间 |
| 株距 | 60-100cm（土地狭小时为30-40cm） | |
| 种植密度 | 每1,000㎡ 300-400株 | |
| 播种深度 | 2-3cm | |
| 每穴播种 | 2-3粒 | 为防不发芽的保险。之后只留一株 |
| 间苗 | 在2-3片真叶时，只留下最健壮的一株 | |
| 种植方法 | 先向坑中浇足水，等水渗下去后再种 | |

&nbsp;&nbsp;&nbsp;畦宽3.5-4m看上去很宽，但这是按放任栽培来定的标准。在土地狭小的地方，可以把藤蔓向同一个方向引蔓以缩小幅度，或者干脆让藤蔓向上攀爬。

| 方法 | 内容 | 特点 |
|---|---|---|
| 放任 | 让藤蔓直接趴在地上 | 不费工，节上长出不定根，植株更健壮 |
| 单方向引蔓 | 把藤蔓前端转向同一侧 | 可缩小幅度，管理方便 |
| 篱笆·围墙引蔓 | 把藤蔓引到围墙或篱笆上 | 不占田地面积，果实不接触土壤，不易腐烂 |
| 屋顶·棚架引蔓 | 搭好棚架，把藤蔓引上去，让果实悬挂 | 果实很重，要用绳子托住 |
| 攀树生长 | 引到枯树或树篱上 | 不需要资材 |

&nbsp;&nbsp;&nbsp;引到围墙或篱笆上的方式，在土地狭小的地方尤其有利。既不占田地的水平面积，又能晒到太阳，果实悬在空中不接触土壤，底部腐烂的情况也会减少。不过，南瓜的果实重达5-10kg，放着不管，瓜蒂会断裂而掉落。要在果实下面用布或网兜做一个兜子托住，并把绳子系在棚架上。

&nbsp;&nbsp;&nbsp;放在地上时，要在果实下面垫上垫物。一把稻草、一块木板碎片、一片瓦片、一堆干草就足够了。直接接触土壤的那一面，因为潮湿，颜色上不去，容易腐烂，这个部位在贮藏期间也最先烂掉。

## 7. 水分管理

| 时期 | 水分管理 | 原因 |
|---|---|---|
| 播种-发芽 | 保持不干 | 种子大而厚，需要充足的水分 |
| 幼苗期 | 间隔3-4天 | 根还很浅 |
| 藤蔓伸长期 | 间隔5-7天 | 根扎深了，能耐旱 |
| 开花·坐果期 | 间隔4-5天，浇足 | 缺水雌花会脱落 |
| 果实膨大期 | 间隔4-5天，浇足 | 果实重量的大部分是这一时期吸进去的水 |
| 成熟期（收获前20-30天） | 逐渐减少，最后停止 | 耐储性提高 |
| 梅雨季 | 停止灌水，检查排水沟 | 过湿会引来疫病和枯萎病 |

### 7-1. 成熟期停水的原因

&nbsp;&nbsp;&nbsp;从收获前3-4周起减少浇水，对耐储性有很大影响。水一直进入，果实就会一直吸水，果肉变软，果皮不够硬。反过来，减少水分，植株就会停止生长，转向积累贮藏物质。淀粉积累，果皮木质化，瓜蒂干枯。这就是成为可贮藏南瓜的过程。

> **秋天雨多，南瓜的耐储性就会下降。即使人不浇水，从天上落下来的水也挡不住。这种时候，要尽可能保证垄的排水，并把收获稍微推迟，等连续几个晴天之后再收，会更好。**

### 7-2. 缺水与水过多的信号

| 状态 | 症状 | 说明 |
|---|---|---|
| 缺水初期 | 中午叶片软塌下垂，傍晚恢复 | 南瓜叶大而薄，常常这样。傍晚能恢复就在正常范围内 |
| 缺水加重 | 傍晚也不恢复，雌花变黄枯萎脱落 | 到这一阶段，坐果就停止了 |
| 严重缺水 | 幼果长着长着停住，变得皱巴巴 | |
| 过湿初期 | 下部叶片发黄，根部附近变软 | |
| 过湿加重 | 藤蔓基部开裂，流出汁液，植株萎蔫 | 这是枯萎病，无法恢复 |

&nbsp;&nbsp;&nbsp;南瓜叶片在中午蔫下去是常有的事，通常是正常的。叶子大而薄，蒸腾多，暂时超过了根系的供水速度。太阳偏西后就会恢复。到了傍晚还不恢复的时候才是真正缺水，而那时雌花已经开始脱落了。

### 7-3. 水资源紧缺时

| 方法 | 原理 | 效果 |
|---|---|---|
| 稻草·干草覆盖 | 防止地表蒸发 | 灌水间隔可拉长，果实也不接触土壤 |
| 藤蔓节上压土 | 节上长出不定根，吸收面积增加 | 不再只依赖一条根 |
| 坑内种植 | 把种植位置做成凹形，使水聚集 | 少量的水集中到根部 |
| 傍晚灌水 | 蒸发损失少 | |
| 利用叶片遮阴 | 藤蔓和叶片盖住地面后，下面的土壤不会变干 | 是南瓜自己形成的覆盖 |

&nbsp;&nbsp;&nbsp;最后一项是南瓜不为人注意的优点。藤蔓延伸开来盖住地面后，下面成了阴凉处，土壤不会变干，杂草也长不起来。正因为这个特性，把南瓜种在田边来抑制杂草的做法已经沿用了很久。在玉米下面一起种南瓜的布置也是同样的原理，将在第11节中讲解。
