## 15. 无冰箱贮藏 - 愈伤处理与越冬

&nbsp;&nbsp;&nbsp;南瓜的耐储性为A级，这几乎就是这种作物的存在理由。在无电力的常温条件下能存放到六个月的果菜，实际上除它之外别无他者。不过，这六个月并不会自动到来。必须完整经历收获时机、愈伤处理和贮藏条件这三个阶段。

### 15-1. 愈伤处理 - 让伤口愈合的过程

&nbsp;&nbsp;&nbsp;愈伤处理是收获后立即把南瓜放在温暖潮湿的地方，使果皮上的细微伤口愈合，并让果皮变得更硬的过程。它与甘薯上所做的处理原理相同，仅这一步就能把贮藏期延长一倍。

| 项目 | 标准 |
|---|---|
| 温度 | 25-30℃ |
| 湿度 | 较高（80%左右） |
| 时间 | 10-14天 |
| 场所 | 向阳的木地板厅（maru）、屋檐下、暖炕房中远离热源的一侧（winmok）、无塑料膜的棚屋 |
| 摆放 | 互不接触，摆成一层 |

&nbsp;&nbsp;&nbsp;关键是在秋天营造出25-30℃的环境。在韩国，9月时只要放在白天有阳光的地方就足够，夜里盖上覆盖物保温。如果是使用暖炕的住宅，远离热源的一侧（winmok）是合适的位置。愈伤处理结束后，果皮会明显变硬，细小的伤口被软木质封住。

> **没有经过愈伤处理的南瓜撑不过三四个月，经过处理的南瓜能放六个月。这十来天的差别，决定了冬季后半段的口粮。**

### 15-2. 正式贮藏

| 项目 | 标准 |
|---|---|
| 温度 | 10-15℃（12-14℃最好） |
| 湿度 | 60-70% |
| 场所 | 凉爽干燥且通风的地方。棚屋、阁楼、木地板厅下、朝北的房间 |
| 摆放 | 互不接触，在架子或稻草上摆成一层 |
| 管理 | 每2-3周检查一次，挑出变软的 |
| 禁止 | 冰箱。5℃以下会发生冷害，反而更快变坏 |

&nbsp;&nbsp;&nbsp;温度降到10℃以下就会发生冷害。南瓜是热带起源的作物，怕冷，即使不结冰，在5-10℃之间放久了，细胞也会受损，内部变软。反过来，超过20℃时呼吸旺盛，果肉消耗加快，还会想要发芽。12-14℃之所以最好，原因就在这两者之间。在韩国的气候条件下，冬季的棚屋或朝北的房间大致处于这一范围。如果是隆冬会降到零下的地方，就要用稻草或草袋（gamani）包裹，防止结冰。

&nbsp;&nbsp;&nbsp;互不接触地摆放也很重要。一个烂了，会通过接触面传给邻近的，堆起来的话，下面的会被压软。要在架子上摆成一层，或者铺上稻草，在上面留出间隔摆放。每2-3周巡查一次，把开始变软的挑出来先吃掉。放任一个不管，它周围的就会全部变坏。

### 15-3. 其他贮藏方法

| 方式 | 方法 | 期间 | 特点 |
|---|---|:---:|---|
| 整个常温贮藏 | 愈伤处理后放在10-15℃ | 4-6个月 | 无需加工，营养损失少 |
| 干燥（南瓜干，hobakgoji） | 去皮切成薄片，晒干 | 6个月-1年 | 体积大大缩小，甜味变浓 |
| 切片晒干后磨粉 | 晒到干脆，用臼捣成粉 | 1年 | 便于加入粥或汤中 |
| 种子贮藏 | 洗净晒干，密封 | 多年 | 既是粮食也是种子 |
| 叶·嫩梢干燥 | 焯水后晒干 | 几个月 | 像干制凉拌野菜（namul）一样使用 |
| 南瓜饴糖（hobakyeot）·糖稀（jocheong） | 长时间熬煮浓缩 | 几个月 | 耗燃料多 |

&nbsp;&nbsp;&nbsp;南瓜干是处理因有伤而无法贮藏的南瓜、以及未熟而无法贮藏的南瓜的方法。去皮、刮去瓤后，切成1cm左右厚的片，摊在阳光下，或挂在稻草绳上晒干。完全干燥后体积缩小到不足10%，冬天用水泡发，用于凉拌野菜或年糕。晾晒期间甜味会变浓，这是它的特点。

> **贮藏的南瓜越放越甜。这是因为果肉中的淀粉会慢慢转化成糖。与马铃薯或甘薯不同，南瓜在贮藏期间有一段时期品质会变好，收获后一个月到两个月是其顶峰。**

## 16. 烹饪与加工 - 果实、叶、嫩梢和种子

### 16-1. 各部位的用途

| 部位 | 时期 | 烹饪 | 备注 |
|---|---|---|---|
| 成熟果实（果肉） | 在韩国9-10月收获，整个冬季 | 蒸、粥、汤、南瓜糊（beombeok） | 需要加热30分钟。不适合生吃 |
| 幼果（嫩南瓜） | 开花后7-10天 | 炒、炖菜（jjigae）、韩式煎饼（jeon） | 夏季的菜 |
| 叶 | 整个夏季 | 蒸熟包饭（ssam）、焯后做凉拌野菜 | 去掉粗硬的叶脉和绒毛后使用 |
| 蔓端嫩梢 | 整个夏季 | 焯后做凉拌野菜 | 柔软且香味好 |
| 花 | 花期 | 韩式煎饼、放入汤中 | 用雄花。摘掉雌花就没有果实了 |
| 种子 | 收获后 | 炒着直接吃、捣碎加入粥中、榨油 | 蛋白质和脂肪丰富 |
| 果皮 | 收获后 | 久煮可食，否则做家畜饲料 | 粗硬 |

&nbsp;&nbsp;&nbsp;评价表中烹饪·加工的B，意思是需要加热30分钟，且不能生吃。与羽衣甘蓝的SS或辣椒的SS相比，存在燃料负担。不过有办法减轻这一负担。切得细碎，煮熟的时间就会大大缩短；与煮其他食物的火一起加热，就不必另外消耗燃料。煮饭时在上面放上切好的南瓜一起蒸，是最经济的做法。

### 16-2. 叶和嫩梢

&nbsp;&nbsp;&nbsp;吃南瓜叶这件事，在灾害应对中的意义比想象的要大。南瓜的果实在秋天只结一次，而叶和嫩梢整个夏天都会不断长出。如果说持续性D这个等级是以果实为基准的评价，那么把叶子算进去，情况就不一样了。

| 项目 | 内容 |
|---|---|
| 采摘部位 | 蔓中段已长足的叶片。蔓梢生长点附近的留下 |
| 采摘量 | 每株一次最多摘三四片叶。摘得过多，果实会变小 |
| 处理 | 折断叶柄，撕去靠茎一侧的皮，叶脉上粗硬的纤维也会一起被撕掉 |
| 烹饪 | 放在米饭上一起蒸，就不需要燃料 |
| 营养 | 含有β-胡萝卜素、维生素C、钙、铁 |

&nbsp;&nbsp;&nbsp;摘叶需要把握平衡。如前文所述，养好一个果实需要20-25片叶，因此叶摘得多，果实就会相应变小。不过，每株有几十片叶，只摘下部几片长足的叶，对果实没有太大影响。夏天饭桌上缺少绿色蔬菜时，这几片叶就能派上用场。

### 16-3. 种子

&nbsp;&nbsp;&nbsp;南瓜子不是用来扔掉的，而是一种独立的食品。每100g含蛋白质25-30g、脂肪45-50g，镁、锌、铁含量丰富。它是在同一种作物内部弥补果实本身蛋白质密度C这一弱点的唯一途径。

| 用途 | 方法 |
|---|---|
| 炒种子 | 洗净晒干后，用小火炒。带壳吃或剥壳吃 |
| 粉 | 炒后用臼捣碎。加入粥或汤中会变香，还能补充蛋白质 |
| 油 | 炒后捣碎，用布包起来压榨。100g种子出油30-40g |
| 油饼 | 榨油后剩下的渣滓也可以吃，或者用作肥料 |

&nbsp;&nbsp;&nbsp;一个南瓜出的种子，按干重计为50-100g。十个南瓜就是500g到1kg，折合蛋白质150-300g。量不算多，但在冬季蛋白质来源珍贵时，也不是可以白白扔掉的量。再把其中一部分留作种子，就能通过同一道工序同时获得粮食和种子。

## 17. 全年作业日程

| 月份（以韩国气候为准） | 作业 |
|---|---|
| 1月 | 检查贮藏南瓜的状态，挑出变软的。检查种子 |
| 2月 | 继续吃贮藏的南瓜。确定种植地块，翻动堆肥 |
| 3月 | 下旬开始育苗。向田里施入石灰 |
| 4月 | 挖穴施入堆肥。中旬直播或继续育苗 |
| 5月 | 上旬到下旬定植。真叶5-6片时给主蔓摘心 |
| 6月 | 引蔓并整理子蔓。第1次追肥。开始摘叶食用 |
| 7月 | 雌花开始开放。清晨人工授粉。摘除第一朵雌花的果实 |
| 8月 | 坐果管理和果实下铺垫。第2次追肥（钾）。监测白粉病。给留种果做标记 |
| 9月 | 减少浇水。从上旬起收获成熟的果实，进入愈伤处理 |
| 10月 | 初霜前全部收获。完成愈伤处理，转入正式贮藏 |
| 11月 | 清除蔓和叶，切碎后翻入田中。从留种果上取种 |
| 12月 | 检查贮藏库的温度，防止结冻。精选种子并保存 |

&nbsp;&nbsp;&nbsp;这张表里最重要的栏目是4月和9月。在韩国的气候下，4月不种，9月就不会成熟；9月不及时收获并做愈伤处理，冬天就什么都不剩。中间的夏季几个月相对省事。除去进行人工授粉的7月清晨和查看白粉病的8月，南瓜几乎是种下后任其生长的作物。

&nbsp;&nbsp;&nbsp;此外，值得留意的是，1月和2月栏里写的不是收获，而是检查。冬天吃南瓜，不是从田里收获，而是从仓库里取出。因此，冬季的作业全部就是巡查贮藏库，而及时挑出变软的南瓜这件简单的事，决定了到3月是否还有东西可吃。
