## 8. 栽培管理 - 摘心与人工授粉

### 8-1. 摘心的原理

&nbsp;&nbsp;&nbsp;南瓜的蔓有主次之分。从种子中直立长出的第一条蔓是主蔓，从主蔓叶腋长出的是子蔓，从子蔓长出的是孙蔓。雌花着生的位置因这一层级而不同，摘心就是调节这一位置的作业。

| 蔓 | 雌花着生情况 |
|---|---|
| 主蔓 | 雌花着生晚且稀少。很长一段时间里只开雄花 |
| 子蔓 | 雌花着生良好。通常在这里收获果实 |
| 孙蔓 | 虽着生雌花，但长势弱，果实偏小 |

&nbsp;&nbsp;&nbsp;因此，摘心的目的是尽早摘除主蔓的生长点，促使子蔓尽快长出。据报道，摘心比放任栽培增产约30%，其依据就在于此。

| 方法 | 步骤 |
|---|---|
| 主蔓1条 + 子蔓2条 | 真叶5-6片时摘除主蔓的生长点。从长出的子蔓中只留2条健壮的，其余去除 |
| 主蔓5-6节摘心 + 子蔓3-4条 | 在主蔓第5-6节处摘心，将3-4条子蔓向四周牵引 |
| 放任 | 什么都不做。产量较低，但不费工 |

> **是否摘心，取决于劳动力和空间。人手不足时，放任不管南瓜也能结果，只是果实偏小，数量参差不齐。反之，空间狭小时，摘心就成为必需。只有控制住蔓，才能在狭小的面积内栽种多株。**

### 8-2. 坐果管理 - 留几个果

| 步骤 | 内容 |
|---|---|
| 确认雌花位置 | 第一朵雌花着生在子蔓第8节左右，第二朵在第13节，第三朵在第18节附近 |
| 选择留果对象 | 在长势充分之后开的雌花上留果，通常是第二、三朵雌花 |
| 摘除其余果实 | 开得过早的果实和形状不良的果实，趁幼小时摘掉 |
| 最终目标 | 每条蔓留1个，每株留2个左右 |

&nbsp;&nbsp;&nbsp;摘除第一朵雌花所结果实的理由，与茄子、辣椒相同。蔓还短、叶片还少时，如果养分都集中到一个果实上，整株就长不起来。如前文所述，要把一个果实养好需要20-25片叶，因此在长出这么多叶片之后的雌花上留果，才合乎道理。

&nbsp;&nbsp;&nbsp;每株留几个果，要根据目的而定。想得到两三个大南瓜，就必须摘除其余的果；想得到多个小南瓜，就保持原样。以贮藏为目的时，大果更有利。大南瓜体积相对于表面积更大，水分损失慢，外皮也会变得更厚、更硬。小南瓜在贮藏期间干得很快。

### 8-3. 人工授粉 - 没有蜜蜂时

&nbsp;&nbsp;&nbsp;南瓜的雌花和雄花分开开放，花粉又重又黏，无法靠风传播。必须由昆虫来传粉，昆虫不来，雌花开放后就会直接变黄、枯萎、脱落。这是这种作物在结构上的弱点。

| 条件 | 结果 |
|---|---|
| 韩国的梅雨季（6月下旬至7月）降雨不断，蜜蜂无法飞行 | 这段时间的雌花全部脱落 |
| 周围蜜蜂少 | 坐果率大幅下降 |
| 超过35℃的酷暑 | 花粉丧失活力，无法受精 |
| 清晨下雨 | 花粉被打湿，无法附着 |

| 步骤 | 方法 |
|---|---|
| 1. 时间 | 日出后不久至上午8点之前。花只在这段时间开放，花粉此时活力也最强 |
| 2. 摘雄花 | 连花梗一起摘下盛开的雄花 |
| 3. 去除花瓣 | 将花瓣向后翻折或撕掉，只留下雄蕊 |
| 4. 转移花粉 | 将雄蕊直接在雌花的柱头上涂抹，使花粉均匀沾上 |
| 5. 确认 | 三四天后子房变粗即为成功。变黄枯萎则为失败 |

> **一朵雄花最多可为两三朵雌花授粉。用毛笔或棉球也可以，但直接使用整朵雄花更简单也更可靠。有报告称结实率可升至两倍以上，在梅雨季和酷暑期，这种差距更大。**

&nbsp;&nbsp;&nbsp;还需补充一点。人工授粉既是保证坐果的手段，同时也是留种的关键技术，因为这意味着人可以控制是由哪种花粉完成受精的。第13节的隔离留种正是建立在这项技术之上。

### 8-4. 果实保护

| 项目 | 方法 | 理由 |
|---|---|---|
| 铺垫 | 在果实下面垫上稻草、木板或瓦片 | 防止果实底面因土壤湿气而腐烂 |
| 转动果实 | 成熟期轻轻转动果实一两次 | 使底面也能见光，上色均匀 |
| 用叶遮盖 | 酷暑期在果实上盖上叶片或稻草 | 防止果皮被太阳灼伤 |
| 不翻动 | 不要频繁挪动蔓 | 节上的不定根会被扯断 |

&nbsp;&nbsp;&nbsp;转动果实必须小心。瓜蒂若被扭曲，水分和养分的通道就会受损，严重时该处会腐烂。轻轻地、一点一点地转动，并且在成熟后期转一两次就足够了。

## 9. 病虫害 - 不用农药的防治方法

### 9-1. 主要病害

| 病名 | 症状 | 发生条件 | 不用农药的应对 |
|---|---|---|---|
| 白粉病 | 叶面被白色粉末覆盖，叶片干枯 | 干燥与高湿交替出现的韩国8-9月 | 蛋黄油、牛奶稀释液、小苏打稀释液。清理下部叶片 |
| 霜霉病 | 出现被叶脉围成的多角形黄色斑点，叶背长出霉层 | 湿度大、低温 | 保证通风，用波尔多液预防 |
| 枯萎病 | 茎基部纵向开裂并渗出汁液，植株萎蔫 | 过湿、土传 | 无法治疗。清除病株，改善排水 |
| 疫病 | 根和茎软腐，并蔓延到果实 | 过湿、易积水处 | 高垄与排水。立即清除病株 |
| 炭疽病 | 叶和果实上出现凹陷的斑点 | 高温高湿 | 清除病部，保证通风 |
| 花叶病（病毒病） | 叶片出现斑驳、皱缩，果实畸形 | 由蚜虫传播 | 无法治疗。防治蚜虫并清除病株 |
| 白绢病 | 茎基部出现白色菌丝和小米粒状颗粒 | 高温高湿、有机物过多 | 清除病株，使土壤干燥 |

&nbsp;&nbsp;&nbsp;南瓜上最常遇到的是白粉病。在韩国，从8月下旬起，叶面会出现像撒了面粉一样的白色粉末，蔓延后叶片会变黄、干枯而死。这种病本身不会使植株死亡，但叶片一死，光合作用就会停止，果实也就无法正常成熟。决定耐储性的最后一个月里，叶片是否存活是关键，因此延缓白粉病，也就等于保证了贮藏南瓜的品质。

> **白粉病是在叶片表面生长的真菌，所以在表面涂布某种物质就会有效。蛋黄油和牛奶稀释液之所以管用，原因就在于此。这种病不会深入叶片内部，因此不用农药也有较大的应对余地。**

&nbsp;&nbsp;&nbsp;枯萎病则恰恰相反。土壤中的真菌从根部侵入，堵塞导管，茎基部纵向开裂并渗出汁液。该病无法治疗，除了拔除销毁之外别无他法。不过，南瓜对这种病的抗性相对较强，因此也被用作其他葫芦科作物的砧木。连作适应性之所以获得SS，背后就有这种抗病性的原因。

### 9-2. 主要害虫

| 害虫 | 危害 | 不用农药的应对 |
|---|---|---|
| 蚜虫 | 吸食嫩芽和叶背的汁液，并传播花叶病 | 喷洒肥皂水、用手捏死、保护瓢虫 |
| 二斑叶螨 | 在叶背吸食汁液，使叶片发白 | 用力向叶背喷水。干燥时更严重 |
| 黄守瓜 | 在幼叶上咬出圆形孔洞，还会啃食根部 | 幼苗期罩上防虫网。人工捕捉 |
| 蝽象 | 吸食果实汁液，被吸处变硬 | 清晨人工捕捉 |
| 棉卷叶野螟 | 卷叶并在其中啃食 | 摘除卷起的叶片 |
| 根结线虫 | 根上长瘤，生长变差 | 与金盏花间作、轮作 |

### 9-3. 不用农药的防治材料

| 防治材料 | 制作方法 | 用途 | 注意事项 |
|---|---|---|---|
| 蛋黄油 | 将1个蛋黄调入100mL水中，倒入60mL食用油，用力搅拌使其乳化，再兑入20L水中 | 白粉病·螨类 | 油料紧缺时难以使用。正午喷洒会灼伤叶片 |
| 牛奶稀释液 | 牛奶与水按1比1至1比2混合 | 白粉病 | 干燥时会把菌丝压住、粘住 |
| 小苏打稀释液 | 将1g食用小苏打溶于1L水 | 白粉病 | 浓度高会伤叶 |
| 波尔多液 | 将1kg硫酸铜和1kg生石灰分别溶解、冷却后合并，加水定容至100L | 预防霜霉病·细菌病害 | 属于预防剂 |
| 肥皂水 | 将20g无香料肥皂溶于1L水 | 蚜虫·螨类 | 必须喷到叶背 |
| 木醋液 | 稀释300-500倍 | 驱避、提高微生物活性 | 原液呈强酸性 |
| 草木灰 | 将过筛的草木灰撒在叶片和土壤上 | 驱避黄守瓜、补充钾 | 会被雨水冲走 |

&nbsp;&nbsp;&nbsp;蛋黄油之所以在南瓜上被特别提及，是因为它对白粉病的效果相对确切。油在叶片表面形成一层薄膜，覆盖菌丝，蛋黄中的卵磷脂则使油均匀分散在水中。不过，油在灾害情境下是珍贵的资源，而南瓜子可以榨油这一事实，在这里就成了一个意想不到的连接点。种子油的一部分可以转用于防治。

### 9-4. 农业防治

| 方法 | 原理 |
|---|---|
| 高垄与排水沟 | 消除枯萎病和疫病的发生条件 |
| 加大株行距 | 通风使叶片干得快，真菌病害减少 |
| 稻草覆盖 | 挡住从土面溅起的雨滴，并使果实不接触土壤 |
| 清理下部叶片 | 衰老乏力的下部叶片会成为病害的落脚点 |
| 立即摘除病叶 | 白粉病在初期摘掉几片叶就能大大延缓 |
| 收获后处理残体 | 清除蔓和叶片，来年的传染源才会减少 |
| 与金盏花间作 | 抑制根结线虫 |

&nbsp;&nbsp;&nbsp;对白粉病来说，早期应对格外有效。这种病从一两片叶子开始蔓延，因此一旦看到最初出现白斑的叶片，立即摘下三四片并带出田外，就能大大延缓扩散。这是一种每天巡田与否会使结果大相径庭的病害。

## 10. 营养缺乏与过量

| 症状 | 原因 | 用天然材料采取的措施 |
|---|---|---|
| 从下部叶片开始整体变黄，蔓变细 | 缺氮 | 蔓伸长期可施稀释尿液（稀释10-15倍）。坐果后则不施 |
| 叶缘变褐焦枯，果实偏小 | 缺钾 | 在植株周围每处撒一把草木灰 |
| 生长迟缓，叶片小，带紫色 | 缺磷 | 骨粉、草木灰。低温期也可能无法吸收 |
| 只有蔓旺长，节间长，不出雌花 | 氮过量 | 停止施氮，用草木灰补充钾。通过摘心抑制生长 |
| 雌花开放后果实不长大而脱落 | 授粉失败 | 通常不是肥料问题，而是授粉问题。进行人工授粉 |
| 仅叶脉之间变黄，叶脉仍为绿色 | 缺镁 | 白云石粉、使堆肥原料多样化 |
| 果实顶端软腐 | 钙转运障碍或过湿 | 改善排水并均匀浇水 |
| 果肉颜色淡，甜味少 | 钾不足、光照不足、过早收获 | 补充草木灰、清理叶片、推迟收获 |

&nbsp;&nbsp;&nbsp;南瓜上最常见的误判是雌花脱落。雌花开放后果实不长大，变黄枯萎并脱落，人们很容易认为是肥料不足，但大多数情况是没有授粉。区分的方法是观察子房。如果已经受精，三四天内子房会明显变粗。如果子房不变粗，花先变黄，就是受精失败。

> **如果分不清什么时候该追肥、什么时候该人工转移花粉，就会多施氮肥，使蔓徒长而雌花更少，陷入恶性循环。雌花能开却不坐果时，应先尝试人工授粉。**

## 11. 间作与轮作

### 11-1. 搭配宜忌

| 搭配 | 对象 | 理由 |
|:---:|---|---|
| 适宜 | 玉米 | 玉米向上生长，南瓜覆盖地面，上下分层 |
| 适宜 | 豆科作物 | 固氮并留在土壤中 |
| 适宜 | 金盏花 | 抑制根结线虫 |
| 适宜 | 紫苏（荏）·皱叶紫苏 | 用气味迷惑害虫 |
| 不宜 | 其他葫芦科（黄瓜·西瓜·甜瓜） | 共有病虫害，还有杂交风险 |
| 不宜 | 马铃薯 | 共有同一类疫病，并且相互争夺空间 |
| 不宜 | 低矮的叶菜类 | 会被南瓜蔓覆盖 |

&nbsp;&nbsp;&nbsp;将玉米、豆类和南瓜一起种植的搭配，是美洲原住民长期使用的方式。玉米撑起茎秆，豆类沿着茎秆向上攀爬并通过根固氮，南瓜覆盖地面，抑制杂草并保持土壤水分。三种作物利用的高度不同、根系深度也不同，因此竞争较小。在狭小的土地上，这种搭配有时总产量会高于单作。

| 层 | 作物 | 作用 |
|---|---|---|
| 上层 | 玉米 | 热量，作为豆类的支架 |
| 中层 | 蔓生豆类 | 蛋白质，固氮 |
| 下层 | 南瓜 | 热量和维生素，覆盖地面，抑制杂草 |

&nbsp;&nbsp;&nbsp;不过这种搭配是有条件的。必须先种玉米，等长到膝盖高度之后再种入豆类和南瓜。如果三者同时种下，南瓜蔓会把幼小的玉米盖住。而且，南瓜如果把玉米行间完全覆盖，收获玉米时就很难踩进去。把南瓜蔓朝同一方向、即朝田块外侧牵引，在实际操作中更为合适。

### 11-2. 轮作

&nbsp;&nbsp;&nbsp;南瓜的连作适应性为SS，属连作无害组。在该评价表中，这是非常罕见的等级，与同为葫芦科的黄瓜和西瓜需要休作3至5年形成对比。因此在狭小的土地上，可以连续多年使用同一块地。

| 年 | 作物 | 目的 |
|---|---|---|
| 第1年 | 南瓜 | |
| 第2年 | 南瓜（可）或豆科 | 可以连作，但种入豆科作物可恢复地力 |
| 第3年 | 谷物或叶菜类 | 改变土壤的养分构成 |
| 第4年 | 恢复种植南瓜 | |

> **能够连作并不等于提倡连作。这只是说病害不易积累，同一种作物连续种植，该作物大量吸收的养分就会因偏耗而不断减少。每三年种一次别的作物更为妥当。**

&nbsp;&nbsp;&nbsp;与其他葫芦科作物的关系，要从两个方面来看。就病虫害而言，黄瓜、西瓜和甜瓜共有白粉病、霜霉病和枯萎病，因此种在相邻位置不利。就杂交而言，情况则不同。黄瓜（Cucumis sativus）和西瓜（CitrullusLanatus）与南瓜不同属，不会与南瓜杂交。只有在同属南瓜属（Cucurbita）内才会出现问题，而其中也只有同种之间才会完全杂交。

&nbsp;&nbsp;&nbsp;南瓜之后种什么，也值得考虑。南瓜的蔓和叶量大，收获后会留下相当多的有机物。把健康的蔓切碎，就地翻入土中，就能成为来年的肥料；病叶则要剔除后再翻入。南瓜之后种大蒜或洋葱让其越冬的安排，是既不让土地闲置、又能减少土壤病原菌的办法。
