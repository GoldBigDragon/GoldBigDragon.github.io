## はじめに
&nbsp;&nbsp;&nbsp;カボチャ(Cucurbita moschata)は、ウリ科カボチャ属の一年生のつる植物で、韓国では石臼に似た形からメットルホバクと呼ばれ、完熟したものは老ホバク、チョンドゥンホバクとも呼びます。原産地は中南米で、若どりして食べる幼果と、完熟させて収穫する完熟カボチャは、同じ作物の異なる時点です。評価表の総合等級はA(48.4点)で、副食はS(55.0点)です。果菜類はほぼ例外なく貯蔵性がDにとどまるなかで、カボチャだけがAを得ました。よく熟させてキュアリングしたカボチャは、冷蔵庫なしで常温で3、4か月、条件がよければ6か月もちます。面積当たりの熱量もB(1,000㎡で4,000kg、1㎡当たり1,520kcalで自給ラインの0.58倍)で、βカロテンが多く、冬にビタミンAを供給します。連作への適応性がSS(連作無害群)で、種子は常温の密閉で6-10年もちます。完熟果、若どり、葉と芽、花、種子をすべて食べられます。弱点は、年に1度、秋にまとめて収穫して終わりであること(永続性D)、播種から完熟まで120-150日かかること、霜に枯れること(耐寒性E)、つるが3-5m伸びること、タンパク質が足りないこと(P:E 9.3%)、受粉をハチに頼ることです。畑の縁や塀の下のような余った空間に数株を植え、つるを外へ伸ばす配置がよく合います。

## 1. 災害への備えの評価
| 区分 | 等級 | スコア |
|:---|:---:|:---:|
| 総合 | A | 48.4 |
| 短期 | B | 47.5 |
| 長期 | A | 49.4 |
| 副食 | S | 55.0 |

| 評価 | 項目 |
|:---|:---|
| 強み | SS: 連作への適応性。S: 微量栄養素、日射への反応、味、国内での栽培の普及度、種子の寿命。A: 貯蔵性、施設の負担(放任栽培が可能)。B: 面積当たりの熱量、水の消費量(総蒸発散量550mm) |
| 弱み | E: 耐寒性。D: 永続性、非食用の価値。C: タンパク質密度、収穫速度、温度幅、病害虫圧、防除の自立度、合成資材を投入しない場合の収量維持率 |

> **カボチャの貯蔵性は、貯蔵技術ではなく果実そのものの構造から来ます。未熟なカボチャは、どれほどうまく保管しても長くもたず、貯蔵の成否は倉庫ではなく、収穫の時点をいつにするかで分かれます。**

&nbsp;&nbsp;&nbsp;カボチャは熱量とビタミンAをくれますがタンパク質はくれないので、カボチャの隣にマメを植え、カボチャの種を捨てないことが、この弱点を補う方法です。項目別の等級は、「災害に備える作物評価結果」の文書にあります。

## 2. 植物の概要
| 種 | 系統 | 代表 | 特徴 |
|:---|:---|:---|:---|
| C. moschata | 東洋系(ニホンカボチャ系) | カボチャ、完熟カボチャ、若どりカボチャ、バターナッツ | 暑さに強く貯蔵性がよい。果柄が広がった五角形 |
| C. maxima | 西洋系 | 栗カボチャ(クリカボチャ)、薬用カボチャ | 涼しい気候を好み、糖度が高い。果柄が丸くコルク質 |
| C. pepo | ペポ系 | ズッキーニ、そうめんカボチャ | つるが短く早生だが貯蔵できない。果柄が五つの角の星形 |

&nbsp;&nbsp;&nbsp;異なる種どうしはほとんど交雑せず、同じ種どうしは完全に混ざります。つるは地面を3-5m這い、節から不定根が出て根を張ります。花は黄色の大きな筒状で、雄花と雌花が別々に咲き、早朝に開いて昼に閉じます。雄花が先に、ずっと多く咲くので、初期に雌花がなくても心配しません。果実は平たい丸形で溝が深く、若いうちは緑色で、熟すと黄褐色に変わって白い粉をふきます。1つの果実に長さ1.5-2cmの平たい種が200-500粒入っています。

| 段階 | 時期 | 要点 |
|:---|:---|:---|
| 発芽・幼苗期 | 播種から本葉4-5枚(3-4週) | リン酸 |
| つるの伸長期 | 5-7月 | 1日10cm以上伸びる。雄花だけが咲く。窒素 |
| 開花・着果期 | 7-8月 | 雌花が咲いて受粉。リン酸、カリウム、ホウ素 |
| 果実の肥大期 | 8-9月 | 開花後20-30日でほぼ大きくなる。カリウム |
| 成熟期 | 9-10月 | 皮が硬くなり、デンプンがたまり、色が変わる。灌水を減らす |

> **果実が大きくなりきった後の1か月が貯蔵性を決めます。大きさは開花後30日で止まりますが、皮が木質化し、へたが乾き、白い粉が出るまでには、その後さらに20-30日かかります。待たずに収穫すると、貯蔵性Aは失われます。**

| 100g当たりの栄養 | 完熟カボチャ(生) | カボチャの種(乾燥) |
|:---|:---|:---|
| 熱量 | 38kcal(水分約88g) | 550-570kcal |
| タンパク質 / 脂肪 | 0.88g / 0.1g | 25-30g / 45-50g |
| その他 | βカロテンが非常に高い(オレンジ色)、ビタミンC 10-15mg(調理中にかなり失われる)、カリウム200-400mg | マグネシウムが非常に高く、鉄・亜鉛・ビタミンEが多い |

## 3. 栽培環境と品種
| 条件 | 基準 |
|:---|:---|
| 温度 | 発芽25-30℃(15℃以下では発芽しない)、生育18-30℃、結実22-28℃(20-30℃)。35℃以上で花粉の活力が落ちて受精せず、霜が1度降りると葉が黒く枯れる |
| 光 | 1日6時間以上(最低4時間、それより少ないと雌花が少なく果実が小さい)。果実1つ当たり葉が20-25枚必要 |
| 水 | 1作当たりの総蒸発散量約550mm。土壌水分は最大容水量の60-70% |
| 土壌 | 水はけのよい砂壌土-壌土、土の深さ30cm以上、pH 5.5-6.8。畝の高さ20-30cm |

&nbsp;&nbsp;&nbsp;カボチャは肥料の多い場所を好みますが、窒素が過剰だとつるばかり伸びて雌花が出ません。堆肥の山のそばに植えるとよく育つというのは本当ですが、その場所に窒素ばかりが多く、リン酸とカリウムが少ないと、葉だけが茂ります。

| 品種 | 特徴 |
|:---|:---|
| 在来のカボチャ、チョンドゥンホバク | 平たく溝が深く、果肉が濃いオレンジ色。貯蔵性が最もよく、固定種なので種を採って受け継げる |
| 改良カボチャ | 収量が多く、病気への抵抗性が強化されている。一代雑種なら種を採れない |
| バターナッツ | 首が長い釣り鐘形で、種の部分が小さく果肉の割合が高い。同じ種なのでカボチャと交雑する |

&nbsp;&nbsp;&nbsp;冬の食料と採種が目的なら在来の系統、狭い土地ならバターナッツやペポ系、涼しい高冷地なら栗カボチャです。一代雑種から採った種は翌年ばらけます。

## 4. 畑の準備と播種、定植
| 項目 | 基準 |
|:---|:---|
| 土づくり | 25-30cmの深さに耕し、畝20-30cm、畑の縁と畝の端に排水溝(水がたまると疫病が来る)。1日6時間以上日が当たり、つるが3-5m伸びられる場所(畑の縁、塀の下) |
| 施肥(1,000㎡当たり) | 堆肥1,500-2,000kg、窒素10-15kg、リン酸8-12kg、カリウム10-15kg、石灰100-150kg(植え付けの3-4週間前)。元肥は植え付けの2週間前に、堆肥全量 + リン酸全量 + 窒素・カリウムの50% |
| 追肥 | 1回目はつるの伸長期(定植後1か月)に窒素中心で少量、2回目は着果直後にカリウム中心。収穫の20-30日前からは中止(窒素が遅いと皮が十分硬くならず貯蔵性が落ちる) |
| 代替資源 | 完熟堆肥を土と半々に混ぜて植え穴に入れる、尿の10-15倍希釈液(つるの伸長期だけ)、着果後に木灰ひとつかみ、骨粉、穴の底に落ち葉・草 |

> **カボチャでは窒素に特に注意が必要です。葉が濃い緑で、つるが太く、節間が長いのに雌花がなければ、ほぼ確実に窒素過剰です。**

| 作型 | 播種 | 定植 | 収穫 |
|:---|:---|:---|:---|
| 露地直まき | 4月中旬-下旬 | - | 9月上旬-10月中旬 |
| 育苗後に定植 | 3月下旬-4月中旬 | 5月上旬-下旬 | 9月上旬-10月中旬 |

> **カボチャは播種から完熟まで120-150日かかります。4月に植えてこそ9月に熟し、5月を過ぎて植えると霜の前に皮が硬くならず、貯蔵のきかない中途半端なカボチャしか残りません。**

| 植え付け | 基準 |
|:---|:---|
| 育苗 | 一晩水に浸し、湿らせた布に包んで25-30℃で発芽させる。深さ2-3cm、昼22-28℃・夜15℃以上、3-4週間、本葉3-4枚で定植。大きく育てない |
| 配置 | 畝幅3.5-4m(放任栽培の基準)、株間60-100cm(狭い土地では30-40cm)、1,000㎡当たり300-400株。1穴に2-3粒まき、本葉2-3枚で最も丈夫な1本だけを残す。穴に水を注ぎ、引いてから植える |
| つるの扱い | 放任(手間がかからず、節から不定根が出る)、一方向への誘引、フェンス・塀への誘引(果実が土に触れず腐りにくい)、屋根・棚への誘引(果実をひもで支える必要がある)、木に登らせる |

## 5. 水管理と栽培管理
| 時期 | 水管理 |
|:---|:---|
| 播種-発芽 | 乾かないように保つ(種が大きく厚い) |
| 幼苗期 | 3-4日おき |
| つるの伸長期 | 5-7日おき |
| 開花・着果期、果実の肥大期 | 4-5日おきにたっぷり(水が足りないと雌花が落ち、果実の重さの大部分はこのときに入った水) |
| 成熟期(収穫の20-30日前) | 徐々に減らして最後は中止(貯蔵性が上がる) |
| 梅雨 | 灌水を中止し、排水溝を点検 |

&nbsp;&nbsp;&nbsp;日中に葉が垂れて夕方に回復するなら正常です。夕方も回復せず、雌花が黄色くしおれて落ちるなら水不足で、つるの株元が縦に裂けて汁が出てしおれるなら、過湿によるつる割病です。秋に雨が多いと貯蔵性が落ちるので、畝の排水を最大限確保し、晴れた日が何日か続いてから収穫するほうがよいです。水が貴重なときは、わら・草のマルチ、節への土かぶせ、植え穴を使います。

| 管理 | 内容 |
|:---|:---|
| 摘心 | 親づるは雌花が遅く、まれにしかつかないので、果実は子づるから得る。本葉5-6枚で親づるの生長点を切って丈夫な子づる2本だけを残すか、5-6節で切って3-4本を四方へ誘引する。放任すると果実が小さく、数もまちまちになる |
| 着果 | 勢いがついた後の2、3番目の雌花(子づるの13-18節付近)から果実を得て、早すぎる時期についた果実と形の悪い果実は若いうちに摘み取る。1株当たり2個前後 |
| 果実の保護 | 果実の下にわら、板、瓦の破片を敷いて腐りを防ぐ。成熟期に1、2回そっと向きを変えて色をそろえる。猛暑のときは葉やわらをかぶせる。つるをむやみに動かさない |

| 人工授粉 | 方法 |
|:---|:---|
| 必要なとき | 梅雨でハチが飛べない、周辺にハチが少ない、35℃を超える猛暑、早朝の雨。受粉しないと雌花は黄色くしおれて落ちる |
| 方法 | 日の出直後から午前8時までに、満開の雄花を花柄ごと摘み、花びらを取り除いて、雄しべを雌花の柱頭にこすりつけ、花粉をまんべんなくつける。雄花1つで雌花2、3個を受粉できる |
| 確認 | 3、4日後に子房が太れば成功、黄色くしおれれば失敗 |

> **雌花が出るのに実がつかないなら、肥料を足す前に、まず人工授粉を試します。窒素をさらに入れると、つるばかりが茂り、雌花がさらに減る悪循環に陥ります。**

## 6. 病害虫と養分の問題
| 病害 | 症状と条件 | 薬を使わない対応 |
|:---|:---|:---|
| うどんこ病 | 葉の表面に白い粉。乾燥と多湿が交互に来る8-9月 | 卵黄油、牛乳の希釈液、重曹の希釈液、下葉の整理、病んだ葉の早期除去 |
| べと病 | 葉脈に囲まれた角ばった黄色の斑点、裏面にカビ。多湿、低温 | 通風の確保、ボルドー液の予防 |
| つる割病、疫病 | 株元が縦に裂けて汁が出てしおれる。根と茎が腐る。過湿 | 治療不可。病株をすぐに除去、高い畝と排水 |
| モザイク病 | 葉がまだらになって縮み、果実が奇形(アブラムシが媒介) | 治療不可。アブラムシの防除、病株の除去 |

&nbsp;&nbsp;&nbsp;害虫は、アブラムシ(石けん水、テントウムシの保護)、ナミハダニ(葉の裏に水を強く吹きかける)、ウリハムシ(幼苗期にネット、手で捕る)、ワタノメイガ(巻いた葉を取り除く)、ネコブセンチュウ(マリーゴールドとの間作、輪作)です。卵黄油は、卵黄1個を水100mLに溶き、食用油60mLを注いで強くかき混ぜて乳化させ、水20Lに加えます(うどんこ病・ハダニ、日中にまくと葉が焼ける)。そのほか、重曹1gを水1Lに、ボルドー液(硫酸銅1kgと生石灰1kgを別々に溶かして冷まし、合わせて水100Lにする)、石けん水(無香料の石けん20gを水1Lに)、木灰を使います。

| 症状 | 原因と措置 |
|:---|:---|
| 下の葉から黄色く、つるが細い | 窒素欠乏。つるの伸長期なら尿の10-15倍希釈液(着果後は入れない) |
| 葉の縁が焼け、果実が小さい | カリウム欠乏。木灰 |
| 生育が遅く、葉が小さく紫色を帯びる | リン酸欠乏。骨粉、木灰 |
| つるばかり旺盛で節間が長く、雌花がない | 窒素過剰。窒素を断ち、木灰でカリウムを補う、摘心 |
| 果実の先が柔らかく腐る | カルシウムの移動障害または過湿。排水の改善、均一な灌水 |
| 果肉の色が薄く甘みが少ない | カリウム不足、日照不足、早どり。木灰、葉の整理、収穫を遅らせる |

## 7. 間作と輪作
| 相性 | 対象 |
|:---|:---|
| よい | トウモロコシ・つる性のインゲンと一緒に植える三姉妹の配置(トウモロコシはマメの支柱、つる性のマメは窒素固定、カボチャは地面の被覆と雑草の抑制。間隔は広めに)、マメ科、マリーゴールド、エゴマ・シソ |
| 悪い | ほかのウリ科(キュウリ・スイカ・マクワウリ。病害虫を共有)、ジャガイモ(疫病の系統を共有)、背の低い葉菜類(つるが覆う) |

&nbsp;&nbsp;&nbsp;1年目カボチャ、2年目カボチャ(可能)またはマメ科、3年目穀物か葉菜類を経て、4年目にカボチャを再開します。3年に1度は別の作物を入れるほうがよいです。

## 8. 収穫と採種
| 項目 | 基準 |
|:---|:---|
| 時期 | 開花後50-60日、9月上旬-10月中旬の初霜の前。若どりは開花後7-10日、皮に爪が入るとき |
| 熟した印 | 皮が緑色から黄褐色に完全に変わり、白い粉が均一にのり、へたが木のように乾いて縦に割れ目が入り(最も確実)、爪で押しても跡がつかず、たたくと鈍い音がする |
| 切り方 | 晴れて乾いた日に、ナイフや剪定ばさみでへたを3-5cm残して切り(ひねらない)、傷がつかないように1個ずつ運ぶ。へたが3-5cm付いて乾いていれば3、4か月から6か月、短ければ2、3か月、へたが取れて穴があくと数週間でその部分から腐る |

> **へたがまだ緑色で柔らかければ、皮がどれほど黄色くても未熟です。へたが木のように乾いてコルクのようになったときが、貯蔵できる状態です。**

| 採種 | 基準 |
|:---|:---|
| 交雑 | C. moschata どうし(カボチャ、若どり、バターナッツ)は完全に交雑し、maximaとpepoはほとんど交雑しない。キュウリ、マクワウリ、スイカ、ユウガオは属が違うので交雑しない。種は果柄の形で見分ける |
| 防止 | 1つの種の1つの系統だけを植える。500m以上の隔離は難しいので、種子の寿命が長いことを利用して、1年に1つの系統だけを開花させる。最も確実なのは、開花前日の午後に雌花と雄花に袋をかぶせ、翌朝の日の出直後から午前8時までに人工授粉して、雌花に袋を再びかぶせ、2日後にはずすこと |
| 株数 | 近交弱勢を避けるため、最低5株、できれば10株以上から1、2個ずつ採る |
| 手順 | 8月に形が整い病気のない果実を選んで印をつける。食用のものより長く完全に熟させ、収穫後2-4週間追熟。種をかき出し、水の中でもんで果肉を取り、浮くものは捨てる。布やすだれに1層に広げて日陰で1-2週間(直射日光では干さない) |
| 寿命 | 常温の密閉で6-10年。数年に1度、20粒を湿らせた布に置いて発芽率を確認 |

## 9. 貯蔵
| 段階 | 基準 |
|:---|:---|
| キュアリング | 収穫直後に25-30℃、湿度80%前後で10-14日。日の当たる縁側、軒下、オンドル部屋の奥、ビニールのない納屋に、互いに触れないよう1層に並べる |
| 本貯蔵 | 10-15℃(12-14℃が最もよい)、湿度60-70%、涼しく乾燥して風通しのよい場所(納屋、屋根裏、縁の下、北向きの部屋)。棚やわらの上に互いに触れないよう1層に置き、2-3週間に1度、柔らかくなったものを選り出す。冷蔵庫は使わない(5℃以下で低温障害) |

> **キュアリングを経ていないカボチャは3、4か月ももたず、経たカボチャは6か月もちます。この10日余りの差が、冬の後半の食料を決めます。デンプンが糖に変わるので、収穫後1、2か月が最も甘くなります。**

| 方式 | 内容 | 期間 |
|:---|:---|:---|
| 丸ごと貯蔵 | キュアリング後に10-15℃ | 4-6か月 |
| 干しカボチャ(ホバッコジ) | 皮をむいて薄く切り、日に干す(傷のあるカボチャ、未熟なカボチャの処理) | 6か月-1年 |
| 種子 | 洗って干して密閉 | 長年 |

## 10. 調理と注意事項
| 部位 | 調理 |
|:---|:---|
| 完熟果 | 蒸す、粥、汁物、練り物。30分の加熱が必要で、生食には向かない |
| 若どり | 炒める、煮込み、チヂミ |
| 葉・芽 | 蒸して包み菜、ゆでて和え物。葉柄を折って茎側の皮をむくと、硬い繊維も一緒にむける。ご飯の上にのせて一緒に蒸せば燃料がいらない。1株から一度に3、4枚だけ摘む |
| 花 | 雄花でチヂミや汁物(雌花を摘むと実がなくなる) |
| 種子 | 乾かして弱火で炒ってそのまま食べるか、挽いて粥に入れる。炒って挽いて圧搾すると、種100gから油30-40g、油かすは食べるか肥料にする。カボチャ1個から乾燥した種が50-100g |
| 皮 | じっくり煮れば食べられ、でなければ家畜の飼料 |

| 注意 | 内容 |
|:---|:---|
| ククルビタシン | ウリ科の苦味の防御物質で、栽培種ではほとんどなくなったが、観賞用カボチャと交雑した種、野生化したカボチャ、極端な干ばつや高温で出ることがある。ひと口食べて舌を刺す苦みがあれば、すぐに吐き出してそのカボチャ全体を捨てる。加熱しても消えず、嘔吐と下痢が来る。葉と芽も同様 |
| カビ | 貯蔵中に柔らかくなってにおいがすれば捨てる |

## 11. 年間作業日程
| 月 | 作業 |
|:---|:---|
| 1-2月 | 貯蔵カボチャを見て柔らかいものを選り出しながら食べ続ける、種子の点検、植える場所の決定、堆肥の切り返し |
| 3-4月 | 下旬に育苗開始と畑に石灰、穴を掘って堆肥を入れる、中旬に直まき |
| 5月 | 上旬-下旬に定植、本葉5-6枚で親づるの摘心 |
| 6月 | つるの誘引と子づるの整理、1回目の追肥、葉を摘んで食べ始める |
| 7月 | 雌花が咲いたら早朝に人工授粉、最初の雌花の果実は摘み取る |
| 8月 | 着果管理と果実の下への敷物、2回目の追肥(カリウム)、うどんこ病の見回り、採種果の印づけ |
| 9月 | 水を減らす、上旬から熟したものを収穫してキュアリングに入る |
| 10月 | 初霜の前にすべて収穫、キュアリングを終えて本貯蔵 |
| 11-12月 | つると葉を片づけて細かく刻み畑にすき込む、採種果から種を採って選別、貯蔵庫の温度を点検して凍らせない |

> **忘れてはならない5つのこと: 4月の播種、窒素を控える、ハチがいなければ人工授粉、へたが乾くまで待った収穫とキュアリング、苦みがあれば捨てる。**
