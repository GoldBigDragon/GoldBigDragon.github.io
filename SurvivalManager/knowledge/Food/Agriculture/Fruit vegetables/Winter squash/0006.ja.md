## 12. 収穫 - 熟したかどうかの見分け方

| 区分 | 基準 |
|---|---|
| 成熟までの期間 | 開花後50-60日 |
| 収穫時期 | 韓国では9月上旬-10月中旬、初霜の前 |
| エホバク（韓国で食べる未熟果のカボチャ） | 開花後7-10日、皮に爪が入るとき |
| 収穫時の天気 | 晴れて乾いた日。雨の直後は避けます |
| 切り方 | ナイフや剪定ばさみで、ヘタを3-5cm残して切ります |
| 扱い方 | 傷がつかないよう、1個ずつ持ち上げて運びます |

### 12-1. 熟したことを示す3つのサイン

| サイン | 内容 | 重要度 |
|---|---|---|
| 皮の色 | 緑色から黄褐色に完全に変わっています | 必須 |
| 白い粉 | 皮全体に白い粉のようなものが均一に浮いています | 必須 |
| ヘタ | 木のように固く乾き、縦に亀裂が入っています | 最も確実なサイン |
| 硬さ | 爪で押しても跡がつきません | 補助 |
| 音 | たたくと鈍く響きます | 補助 |

> **3つのサインのうち1つだけを選ぶなら、ヘタを見ます。ヘタがまだ緑がかっていて柔らかければ、皮がどんなに黄色くなっていても、まだ熟していません。ヘタが木のように乾いてコルクのようになったときが、貯蔵できる状態です。**

&nbsp;&nbsp;&nbsp;皮の表面の白い粉は、植物が水分の蒸発を防ぐために出したワックス層です。これが均一に浮いているということは、果実が自ら貯蔵に向けた態勢に入ったという意味です。この層は貯蔵中に皮を守るため、拭き取りません。洗って貯蔵してはいけない理由もここにあります。土がついていたら、乾いた布で軽く払い落とす程度にとどめます。

### 12-2. ヘタを残してナイフで切る理由

&nbsp;&nbsp;&nbsp;カボチャを収穫するとき、手でねじってもぎ取ってはいけません。ねじると、ヘタが果実の側から引きちぎれ、その場所に開いた傷が残ります。その傷が、貯蔵中に腐敗が始まる起点になります。ナイフや剪定ばさみでヘタを3-5cm残してつる側を切れば、ヘタが果実についたまま栓の役割を果たします。

| 状態 | 貯蔵結果 |
|---|---|
| ヘタが3-5cm残っていて乾いている | 3、4か月から6か月 |
| ヘタが短くしかついていない | 2、3か月 |
| ヘタが取れて穴が残っている | 数週間以内にその部分から腐ります |
| 皮にひっかき傷がある | その部分からカビが生えます |

&nbsp;&nbsp;&nbsp;そのため、運ぶときも注意が必要です。転がしたり、投げたり、互いにぶつかるように積んだりすると、目に見えにくい傷ができ、1か月ほど後にその部分が軟らかくなります。1個ずつ持ち上げて運び、床にわらや草を敷いて衝撃を和らげます。傷がついたカボチャは貯蔵せず、先に食べます。

### 12-3. 霜に当たったカボチャ

&nbsp;&nbsp;&nbsp;初霜が降りると、葉とつるは黒く枯れます。すでに皮が固まった果実は、軽い霜が1回降りただけではすぐには傷みませんが、細胞が損傷して貯蔵性が大きく落ちます。霜に当たったカボチャは貯蔵の対象から外し、先に食べるか乾燥させます。そのため、初霜の予報が出たら、未熟なものまで含めてすべて収穫するという判断をすることになります。未熟なカボチャは貯蔵できないので、エホバクのように調理して食べるか、薄切りにして乾燥させます。

## 13. 採種 - ウリ科の交雑の壁

### 13-1. 何と交雑するのか

&nbsp;&nbsp;&nbsp;カボチャの採種で最初に知っておくべきことは、何と交雑し、何と交雑しないかです。この区別がすべてを決めます。

| 作物 | 学名 | カボチャとの交雑 |
|---|---|:---:|
| エホバク、プッホバク（未熟なカボチャ）、ノウンホバク（完熟した大型のカボチャ）、バターナッツ | Cucurbitamoschata | 完全に交雑します |
| 栗カボチャ（ダンホバク）、ヤクホバク（薬用カボチャ） | Cucurbitamaxima | ほとんど交雑しません（まれに不稔の雑種） |
| ズッキーニ、ソウメンカボチャ、観賞用カボチャ | Cucurbita pepo | ほとんど交雑しません |
| キュウリ | Cucumis sativus | 属が異なるため交雑しません |
| マクワウリ・メロン | Cucumismelo | 属が異なるため交雑しません |
| スイカ | CitrullusLanatus | 属が異なるため交雑しません |
| ユウガオ（ヒョウタン類） | Lagenaria siceraria | 属が異なるため交雑しません |

> **カボチャがキュウリやスイカと交雑するという話は事実ではありません。属が違えば、花粉がついても受精しません。実際に問題になるのは、同じCucurbitamoschata同士、つまりカボチャとエホバクとバターナッツの間です。**

&nbsp;&nbsp;&nbsp;この事実が実務で大きな違いを生みます。畑にキュウリとマクワウリとスイカが一緒にあっても、カボチャの採種には何の支障もありません。ダンホバク（C.maxima）とズッキーニ（C. pepo）も、原則として安全です。警戒すべきなのは同じ種の別系統だけで、その中でもエホバク用の品種が最もありふれた汚染源です。エホバクとカボチャはどちらもC.moschataなので、完全に交雑します。

&nbsp;&nbsp;&nbsp;ただし、種を見分けるのは思ったより厄介です。市販のカボチャは外見だけでは種まで見分けにくく、品種名だけでは分からない場合も多くあります。最も確実な方法は、ヘタを見ることです。

| 種 | ヘタの形 |
|---|---|
| C.moschata | 広がった五角形で、しっかりと木質化します |
| C.maxima | 丸くて太く、スポンジのようなコルク質です |
| C. pepo | 5つの角がはっきりした星形で、固いです |

### 13-2. 交雑を防ぐ方法

| 方法 | 内容 | 現実性 |
|---|---|---|
| 1つの種だけを植える | 同じ種の別系統をまったく植えません | 最も簡単で確実です |
| 隔離距離 | 別の系統と500m以上離します | ハチの行動範囲が広いため難しいです |
| 時間差栽培 | 1年に1系統だけ花を咲かせます | 種子寿命が6-10年なので、非常に現実的です |
| 人工授粉 + 袋かけ | 開花前日に雌花と雄花に袋をかけ、翌朝手で受粉させた後、再び袋をかけます | 最も確実で、小規模でも実行できます |

&nbsp;&nbsp;&nbsp;カボチャの種子が6-10年生きるという事実が、ここで戦略的な意味を持ちます。1年を採種の年と決め、その年はカボチャだけを植えて、種をたっぷり採っておきます。その後の数年間は、エホバクでもダンホバクでも、好きなように植えてかまいません。すでに採ってある種は変わらないからです。5、6年に1回だけこの規律を守ればよい計算になり、毎年採種しなければならないトウガラシとは、負担の性格がまったく異なります。

### 13-3. 人工授粉による隔離採種

&nbsp;&nbsp;&nbsp;最も確実な方法です。手順は1日間隔で進みます。

| 段階 | 時期 | 内容 |
|---|---|---|
| 1. つぼみの確認 | 開花前日の午後 | 翌朝咲く雌花と雄花を探します。つぼみが黄色くふくらみ、先が開きかけています |
| 2. 袋かけ | 開花前日の午後 | 雌花と雄花のそれぞれに紙袋か布袋をかぶせ、口を縛ります |
| 3. 受粉 | 翌日の日の出直後-午前8時 | 雄花の袋を外して摘み取り、花弁を除いた後、雌花の袋を外して柱頭にこすりつけます |
| 4. 再び袋をかける | 受粉直後 | 雌花に袋をかけ直し、2日後に外します |
| 5. 目印 | 受粉直後 | 花柄にひもや布切れを結び、採種用の果実であることを示します |

&nbsp;&nbsp;&nbsp;袋をかける理由は、ハチが先に訪れるのを防ぐためです。カボチャの花は日の出前に開き、ハチは日が昇るとすぐに動き出すため、前日に袋をかけておかないと、人が手を加える前にすでに別の花粉がついてしまいます。袋は紙が最もよく、ビニールは中が蒸れて花が傷みます。布や不織布でも構いません。

> **採種用のカボチャは、複数の株からそれぞれ1、2個ずつ採ります。カボチャは他家受精作物なので、1株からだけ続けて採ると、世代を重ねるほど勢いが弱くなる近交弱勢が現れます。最低5株、できれば10株以上から均等に採るのが原則です。**

### 13-4. 採種の手順と保管

| 段階 | 時期 | 内容 |
|---|---|---|
| 採種果の選定 | 韓国では8月 | 形が整っていて病気がなく、品種の特性がはっきりした果実を選びます |
| 完熟 | 韓国では9-10月 | 食用のカボチャよりも長く、完全に熟すまで置きます |
| 追熟 | 収穫後2-4週間 | 収穫後もさらに2-4週間置くと、種が充実します |
| 種の取り出し | 追熟後 | 果実を割って、種をワタごとかき出します |
| 洗浄 | すぐに | 水に入れ、手でもんでワタを取り除きます |
| 選別 | 洗っている間 | 水に浮くものは中が空の実入りの悪い種なので捨てます |
| 乾燥 | 洗った後 | 布やすのこに1層に広げ、日陰で1-2週間 |
| 保管 | 完全乾燥後 | 密閉容器に乾燥剤と一緒に入れ、涼しく暗い場所に置きます |

&nbsp;&nbsp;&nbsp;種を直射日光で乾かしてはいけません。直射日光の熱が胚を傷めて発芽率が下がります。風通しのよい日陰でゆっくり乾かし、厚く積むと中でカビが生えるので1層に広げます。完全に乾いたカボチャの種は、手で曲げると折れ、2本の爪で押しても入り込みません。

| 項目 | 基準 |
|---|---|
| 果実1個あたりの種子 | 200-500粒 |
| 種子寿命 | 常温密閉で6-10年 |
| 目標含水率 | 8%以下 |
| 乾燥剤 | 炒って冷ました米、炭、乾いた草木灰 |
| 保管容器 | ガラス瓶、金属缶、紙袋を二重に包んだもの |
| 発芽の確認 | 数年に1回、20粒を濡れた布に置いて発芽率を数えます |

&nbsp;&nbsp;&nbsp;1個の果実から200-500粒が採れるため、採種用のカボチャが2、3個あれば、数年分の種子が確保できます。そして、種を採った後に残った果肉はそのまま食べればよいです。採種が食料を減らさないという点が、この作物のもう一つの長所です。種を抜いたカボチャも完全な食料であり、種も炒って食べられます。

## 14. 毒性と注意すべき成分

&nbsp;&nbsp;&nbsp;カボチャに一般的な毒性はありません。果実も葉も新芽も種も花も食べられます。ただし、知っておくべき物質が1つあります。ククルビタシンです。

| 成分 | どんな物質か | どんな問題になるか | 判断基準 |
|---|---|---|---|
| ククルビタシン | ウリ科の植物が草食動物を避けるためにつくる苦味物質 | 多く食べると嘔吐、腹痛、下痢を起こします | 苦味があれば食べません |
| カビ | 貯蔵中に傷んだ部位に生えます | 毒素が生じることがあります | 軟らかくなって臭いがしたら捨てます |

### 14-1. 苦味のあるカボチャ

&nbsp;&nbsp;&nbsp;ククルビタシン（Cucurbitacin）は野生のウリ科植物がもともと持っていた防御物質で、栽培種では長い育種の過程でほとんどなくなりました。ところが、ある条件では再び現れます。

| 条件 | 説明 |
|---|---|
| 観賞用カボチャと交雑した種子 | 観賞用カボチャにはククルビタシンが残っており、その花粉で受精した種から育った株の果実が苦くなることがあります |
| 野生化したカボチャ | 畑の縁にひとりでに生えたカボチャは、系統が分かりません |
| 極度のストレス | 干ばつや高温が厳しいと含有量が上がるという報告があります |

> **判断基準はただ1つ、味です。カボチャをひと口食べたとき、舌を刺すような苦味がしたら、すぐに吐き出し、そのカボチャ全体を捨てます。加熱しても消えず、もったいないからと食べると、数時間以内に嘔吐と下痢が起こります。重症の場合は病院での治療が必要になることがあります。**

&nbsp;&nbsp;&nbsp;このリスクは、とくに自家採種をする状況で高まります。種を採って続けて植える過程で、どこかから観賞用カボチャの花粉が混入することがあり、その結果が数世代後に現れることもあります。そのため、採った種で育てたカボチャは、初めて食べるときに必ず少量で味を確かめる習慣が必要です。苦くなければ安全です。

&nbsp;&nbsp;&nbsp;葉と新芽も同様です。食べられますが、苦味が強いものは避けます。正常なカボチャの葉は、わずかに青臭いだけで、苦くはありません。
