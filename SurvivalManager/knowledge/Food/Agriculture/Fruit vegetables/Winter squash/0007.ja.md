## 15. 冷蔵庫なしの貯蔵 - キュアリングと冬越し

&nbsp;&nbsp;&nbsp;カボチャの貯蔵性が等級Aであることは、この作物の存在理由に近いものです。無電力の常温で6か月までもつ果菜は、これ以外には事実上ありません。ただし、その6か月はひとりでに訪れるわけではありません。収穫の時点、キュアリング処理、保管条件という3つの段階をすべて通る必要があります。

### 15-1. キュアリング - 傷を癒やす過程

&nbsp;&nbsp;&nbsp;キュアリングは、収穫直後に暖かく湿った場所に置いて、皮の微細な傷を癒やし、皮をより固くする過程です。サツマイモで行うのと同じ原理で、この1段階が貯蔵期間を2倍に延ばします。

| 項目 | 基準 |
|---|---|
| 温度 | 25-30℃ |
| 湿度 | 高め（80%前後） |
| 期間 | 10-14日 |
| 場所 | 日の当たるマル（板張りの広間）、軒下、オンドル部屋のウィンモク（熱源から遠い側）、ビニールのない納屋 |
| 配置 | 互いに触れないように1層に並べます |

&nbsp;&nbsp;&nbsp;秋に25-30℃をつくり出すことが鍵になります。韓国の9月なら、日中に日が当たる場所に置いておけば十分で、夜は覆いをかけて熱を閉じ込めます。オンドルを使う家なら、ウィンモクがよい場所です。キュアリングが終わると、皮が目に見えて固くなり、細かい傷がコルク質でふさがります。

> **キュアリングを経ていないカボチャは3、4か月を超えられず、経たカボチャは6か月もちます。この10日余りの違いが、冬の後半の食料を決めます。**

### 15-2. 本貯蔵

| 項目 | 基準 |
|---|---|
| 温度 | 10-15℃（12-14℃が最適です） |
| 湿度 | 60-70% |
| 場所 | 涼しく乾燥して風通しのよい場所。納屋、屋根裏、マルの床下、北向きの部屋 |
| 配置 | 互いに触れないように、棚やわらの上に1層に |
| 管理 | 2-3週間に1回見て、軟らかくなったものを取り除きます |
| 禁止 | 冷蔵庫。5℃以下で低温障害が起こり、かえって早く傷みます |

&nbsp;&nbsp;&nbsp;温度が10℃を下回ると低温障害が起こります。熱帯原産の作物で寒さに弱く、凍らなくても5-10℃の間に長く置くと、細胞が傷んで中が軟らかくなります。逆に20℃を超えると呼吸が活発になって果肉が早く消耗し、芽が出ようとします。12-14℃が最適である理由は、この間にあります。韓国の気候では、冬の納屋や北向きの部屋がおおよそこの範囲に入ります。真冬に氷点下まで下がる場所なら、わらやカマニ（わら袋）で包んで凍らないようにします。

&nbsp;&nbsp;&nbsp;互いに触れないように置くことも重要です。1個が傷むと、接している面を通って隣に移り、積み重ねると下のほうが押されて軟らかくなります。棚に1層に並べるか、わらを敷いてその上に間隔をあけて置きます。2-3週間に1回見回り、軟らかくなり始めたものを取り除いて先に食べます。1個を放置すると、その周りがすべて傷みます。

### 15-3. その他の貯蔵方法

| 方式 | 方法 | 期間 | 特徴 |
|---|---|:---:|---|
| 丸ごと常温貯蔵 | キュアリング後、10-15℃に置きます | 4-6か月 | 加工がなく、栄養の損失が少ないです |
| 乾燥（ホバクコジ、干しカボチャ） | 皮をむいて薄く切り、日に干します | 6か月-1年 | 体積が大きく減り、甘みが濃くなります |
| 切って乾かした後に粉末 | しっかり乾燥させて臼でつきます | 1年 | 粥や汁物に入れやすいです |
| 種の貯蔵 | 洗って乾かし、密閉します | 数年 | 食料であり種子でもあります |
| 葉・新芽の乾燥 | ゆでて干します | 数か月 | 干したナムルのように使います |
| ホバクヨッ（カボチャの飴）・チョチョン（シロップ状の水飴） | じっくり煮詰めます | 数か月 | 燃料がたくさん必要です |

&nbsp;&nbsp;&nbsp;ホバクコジは、傷がついて貯蔵できないカボチャや、未熟で貯蔵がきかないカボチャを処理する方法です。皮をむいて中をかき出した後、1cm前後の厚さに切り、日に干すか、わら縄にかけて乾燥させます。完全に乾くと体積が10%を下回るまで減り、冬に水で戻してナムルやトック（餅）に使います。乾かす間に甘みが濃くなるのが特徴です。

> **貯蔵したカボチャは、時間がたつほど甘くなります。果肉のデンプンが徐々に糖に変わるためです。ジャガイモやサツマイモと違って、貯蔵中に品質がよくなる期間があり、収穫後1か月から2か月がその最盛期です。**

## 16. 調理と加工 - 果実と葉と新芽と種

### 16-1. 部位別の使い方

| 部位 | 時期 | 調理 | 備考 |
|---|---|---|---|
| 熟した果実（果肉） | 韓国では9-10月に収穫、冬の間ずっと | 蒸す、粥、汁物、ポムボク（煮てつぶした濃い粥状の料理） | 30分の加熱が必要です。生食には向きません |
| 若い果実（エホバク） | 開花後7-10日 | 炒め物、チゲ（鍋料理）、ジョン（衣をつけて焼いた料理） | 夏のおかずです |
| 葉 | 夏の間ずっと | 蒸してサム（包んで食べる料理）、ゆでてナムル | 硬い葉脈と毛を取り除いて使います |
| つる先の新芽 | 夏の間ずっと | ゆでてナムル | 柔らかく香りがよいです |
| 花 | 開花期 | ジョン、汁物に入れる | 雄花を使います。雌花を摘むと果実がなくなります |
| 種 | 収穫後 | 炒ってそのまま、砕いて粥に、油搾り | タンパク質と脂質が多いです |
| 皮 | 収穫後 | じっくり煮れば食べられ、そうでなければ家畜の飼料 | 硬いです |

&nbsp;&nbsp;&nbsp;評価表の調理・加工Bは、30分の加熱が必要で、生では食べられないという意味です。ケールのSSやトウガラシのSSと比べると、燃料の負担があります。ただし、この負担を減らす方法があります。細かく切れば火が通る時間が大きく短縮され、ほかの料理を煮る火に一緒にのせれば、燃料を別に使わずに済みます。ご飯を炊くときに、上に切ったカボチャをのせて一緒に蒸す方法が最も経済的です。

### 16-2. 葉と新芽

&nbsp;&nbsp;&nbsp;カボチャの葉を食べるという事実は、災害への備えにおいて思った以上に大きな意味があります。カボチャは果実を秋に一度つけますが、葉と新芽は夏の間ずっと出続けます。永続性Dという等級が果実を基準にした評価だとすれば、葉を数えに入れると話が変わります。

| 項目 | 内容 |
|---|---|
| 摘む部位 | つるの中ほどの十分に育った葉。つる先の生長点付近は残します |
| 摘む量 | 1株から1回に葉3、4枚まで。摘みすぎると果実が小さくなります |
| 下処理 | 葉柄を折って茎側の皮をむくと、葉脈の硬い繊維も一緒にむけます |
| 調理 | ご飯の上にのせて一緒に蒸せば、燃料がかかりません |
| 栄養 | βカロテン、ビタミンC、カルシウム、鉄が含まれています |

&nbsp;&nbsp;&nbsp;葉を摘むにはバランスが必要です。前に見たとおり、果実1個を育てるには葉が20-25枚必要なので、葉をたくさん摘めばその分、果実が小さくなります。それでも1株に葉が数十枚ついているため、下のほうの十分に育った葉を数枚摘む程度なら、果実に大きな影響はありません。夏の食卓に緑のものがないとき、この数枚がちゃんと役に立ちます。

### 16-3. 種

&nbsp;&nbsp;&nbsp;カボチャの種は捨てるものではなく、別の食品です。100gにタンパク質25-30g、脂質45-50gが含まれ、マグネシウムと亜鉛と鉄が豊富です。果実そのもののタンパク質密度Cという弱点を、同じ作物の中で補う唯一の経路です。

| 用途 | 方法 |
|---|---|
| 炒り種 | 洗って乾かした後、弱火で炒ります。殻ごと、または殻をむいて食べます |
| 粉 | 炒って臼でつきます。粥や汁物に入れると香ばしくなり、タンパク質も加わります |
| 油 | 炒ってつぶした後、布に包んで圧搾します。種100gから30-40g |
| 油かす | 油を搾った後に残ったかすも、食べたり肥料にしたりします |

&nbsp;&nbsp;&nbsp;カボチャ1個から採れる種は、乾燥重量で50-100gです。カボチャ10個なら500gから1kg、タンパク質にすると150-300gです。多い量ではありませんが、冬にタンパク源が貴重なとき、そのまま捨ててよい量でもありません。そして、そのうち一部を種子として残しておけば、食料と種子を同じ作業で確保することになります。

## 17. 年間作業スケジュール

| 月（韓国の気候基準） | 作業 |
|---|---|
| 1月 | 貯蔵中のカボチャの状態を確認し、軟らかくなったものを取り除きます。種子を点検します |
| 2月 | 貯蔵カボチャを食べ続けます。植える場所を決め、堆肥を切り返します |
| 3月 | 下旬に育苗を始めます。畑に石灰を入れます |
| 4月 | 植え穴を掘って堆肥を入れます。中旬に直まきするか、育苗を続けます |
| 5月 | 上旬から下旬にかけて定植します。本葉5-6枚で親づるを摘心します |
| 6月 | つるを誘引し、子づるを整理します。追肥1回目。葉を摘んで食べ始めます |
| 7月 | 雌花が咲き始めます。早朝に人工授粉。最初の雌花の果実は摘み取ります |
| 8月 | 着果管理と果実の下への敷き物。追肥2回目（カリウム）。うどんこ病の発生予察。採種果に目印をつけます |
| 9月 | 水やりを減らします。上旬から熟したものを収穫し、キュアリングに入ります |
| 10月 | 初霜の前にすべて収穫します。キュアリングを終え、本貯蔵に入れます |
| 11月 | つると葉を片づけて細かく刻み、畑にすき込みます。採種果から種を採ります |
| 12月 | 貯蔵庫の温度を確認し、凍らないようにします。種子を選別して保管します |

&nbsp;&nbsp;&nbsp;この表で最も重要な欄は4月と9月です。韓国の気候では、4月に植えなければ9月に熟さず、9月に適期に収穫してキュアリングしなければ、冬に残るものがありません。その間の夏の数か月は、相対的に手がかかりません。人工授粉をする7月の朝と、うどんこ病を見回る8月を除けば、カボチャは植えたら育つに任せる作物に近いです。

&nbsp;&nbsp;&nbsp;そして、1月と2月の欄に、収穫ではなく点検が書かれている点にも注目する価値があります。冬にカボチャを食べるというのは、畑で収穫することではなく、倉庫から取り出すことです。したがって、冬の作業は貯蔵庫を見回ることがすべてであり、軟らかくなったものを適時に取り除くという単純な作業が、3月まで食べるものを残せるかどうかを分けます。
