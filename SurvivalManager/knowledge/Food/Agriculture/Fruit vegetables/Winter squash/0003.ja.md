## 2. どんな植物か

### 2-1. 分類と原産地

&nbsp;&nbsp;&nbsp;カボチャはウリ科（Cucurbitaceae）カボチャ属（Cucurbita）の一年生のつる性植物です。学名はCucurbitamoschataで、韓国で一般にホバクと呼ばれているものは、実は互いに異なる三つの種にまたがっています。

| 種 | 系統 | 代表 | 特徴 |
|---|---|---|---|
| Cucurbitamoschata | 東洋系 | カボチャ（メットルホバク）、老いたカボチャ、エホバク（若採りのカボチャ）、プッホバク（未熟な青カボチャ）、タンコンホバク（バターナッツ） | 暑さに強く、貯蔵性が良好です。ヘタが五角形に大きく広がります |
| Cucurbitamaxima | 西洋系 | 栗カボチャ（甘カボチャ）、ヤクホバク（薬カボチャ） | 冷涼な気候を好み、糖度が高いです。ヘタは丸く、コルク質です |
| Cucurbita pepo | ペポ系 | ズッキーニ、ソウメンカボチャ、観賞用カボチャ | つるが短く、早生です。ヘタに五つの稜がはっきりと現れます |

> **この三つの種は互いに異なる種なので、原則として交雑しません。この事実が、第13節の採種のすべてを決定づけます。同じ種どうしは完全に混ざり、異なる種どうしはほとんど混ざりません。**

&nbsp;&nbsp;&nbsp;ただし、まったく混ざらないと断言するのは難しいです。C.moschataとC.maximaの間でまれに雑種ができるという報告があり、その雑種は多くの場合、種が実りません。実務的には同じ種どうしの交雑にだけ警戒すればよく、種を見分ける方法はヘタの形を見ることです。メットルホバクのヘタは広く広がった五角形で、硬く木質化しています。甘カボチャのヘタは丸く、スポンジのように柔らかいコルク質です。ズッキーニのヘタは、稜がはっきりした五つの角の星形です。

&nbsp;&nbsp;&nbsp;原産地は中央アメリカから南アメリカ北部にかけての地域です。C.moschataはその中でも暑い低地で育った系統なので高温に強く、そのため韓国の夏の暑さと湿気によく耐えます。西洋系のC.maximaが冷涼な高冷地でよい結果を出すのとは対照的です。韓国の気候の大部分の地域で、メットルホバクが甘カボチャより安定しているのは、この出自によるものです。

### 2-2. 形態

| 器官 | 特徴 |
|---|---|
| 葉 | 幅広い心臓形で、縁に浅い切れ込みと鋸歯があります。表面に粗い毛があり、白い斑紋が現れる系統もあります。直径20-30cm |
| 茎（つる） | 地面をはって3-5m伸びます。断面は五角形で、中は空洞です。節から不定根が出て、地面に根を下ろします |
| 巻きひげ | 葉腋から出て、何にでも巻きつきます。誘引するときに利用します |
| 根 | まっすぐな主根が深く伸び、細根が広く広がります。果菜の中では根が深いほうです |
| 花 | 黄色の大きな合弁花です。雌花と雄花が別々に咲き、同じ株につきます。早朝に開き、昼に閉じます |
| 果実 | 丸く平たく、溝が深く入っています。若いうちは緑色で、熟すと黄褐色に変わり、表面に白い粉が吹きます |
| 種子 | 長さ1.5-2cmの平たい楕円形で、白色から淡い褐色です。一つの果実に200-500粒 |

&nbsp;&nbsp;&nbsp;節から不定根が出るという点は、実務上役に立ちます。つるが地面をはううちに節が土に触れると、そこから根が出て、水と養分を別に吸収します。そのため、つるの途中に軽く土をかぶせてやると根が増え、株全体が丈夫になります。これを発根誘導と呼び、肥料が不足する条件で特に効果があります。逆に、つるを頻繁に動かして持ち上げると、この根が切れてしまいます。

&nbsp;&nbsp;&nbsp;花の構造がこの作物の核心です。カボチャの花は雌雄が別々に咲きます。雄花は長い花柄の先につき、中央に花粉をたっぷりまとった雄しべがあります。雌花は短い花柄につき、花の下に小さなカボチャの形をした子房がすでについています。この子房が育って果実になります。雌花と雄花を見分ける方法がまさにこれです。花の下に小さなカボチャがついていれば雌花、なければ雄花です。

| 区分 | 雄花 | 雌花 |
|---|---|---|
| 花柄 | 長く細いです | 短く太いです |
| 花の下 | 何もありません | 小さなカボチャの形をした子房がついています |
| 咲く順序 | 先に咲きます。初期は雄花だけが出ます | つるがある程度伸びてから咲きます |
| 数 | はるかに多いです | 少ないです |
| 開花時刻 | 早朝、日の出の前後 | 同じです。午前中に閉じます |

&nbsp;&nbsp;&nbsp;生育初期に雄花ばかりがたくさん咲いて雌花が出ない様子を見て、心配する人が多くいます。これは正常です。カボチャはつるが一定の長さ以上に伸びてから雌花をつくり、それまでは雄花だけを出します。窒素が多すぎるとこの状態が長引き、つるばかりが伸び続けて雌花が出ないこともあります。

### 2-3. 生育段階

| 段階 | 時期（韓国の場合） | 主な生理 | 重要な養分 |
|---|---|---|---|
| 発芽・幼苗期 | 播種から本葉4-5枚まで（3-4週間） | 子葉が大きく開き、主根が下に伸びます | リン酸 |
| つる伸長期 | 5-7月 | つるが1日に10cm以上伸びます。雄花だけが咲きます | 窒素 |
| 開花・着果期 | 7-8月 | 雌花が咲き、受粉が行われます | リン酸、カリウム、ホウ素 |
| 果実肥大期 | 8-9月 | 果実が急速に大きくなります。開花後20-30日でほぼ大きくなりきります | カリウム |
| 成熟期 | 9-10月 | 大きさは止まり、皮が硬くなり、デンプンがたまり、色が変わります | 灌水を減らします |

> **果実が十分に大きくなった後の一か月が、貯蔵性を決めます。大きさは開花後30日で決まりますが、皮が木質化し、ヘタが乾き、表面に白い粉が吹くまでには、その後さらに20-30日かかります。この期間を待たずに収穫すると、貯蔵性のAは失われます。**

&nbsp;&nbsp;&nbsp;このように、エホバクと老いたカボチャは同じ果実の別の時点です。開花後7-10日で摘めばエホバクで、50-60日待てば老いたカボチャです。どちらを選ぶかは目的次第です。エホバクは夏のおかずで、老いたカボチャは冬の糧です。一株からエホバクを摘み続けていると老いたカボチャは得られず、逆に老いたカボチャを目標にすると、夏に摘んで食べるものがありません。災害時には、たいてい後者が優先されます。

### 2-4. 100g当たりの栄養

| 栄養素 | 老いたカボチャ（生） | カボチャの種（乾燥） | 備考 |
|---|:---:|:---:|---|
| 熱量 | 38kcal | 550-570kcal | 種は油の塊です |
| 水分 | 約88g | 5-7g | |
| タンパク質 | 0.88g | 25-30g | 果実のP:Eは9.3%で、要求ラインに届きません |
| 炭水化物 | 6-12g | 10-15g | 果実は熟すほどデンプンが増え、貯蔵中に糖に変わります |
| 脂肪 | 0.1g | 45-50g | 種から油を搾ることができます |
| 食物繊維 | 2-3g | 6-7g | |
| ベータカロテン | 非常に多い | なし | 果肉のオレンジ色はこの色素です |
| ビタミンC | 10-15mg | 微量 | 調理中にかなりの量が失われます |
| ビタミンE | 含む | 多い | 種の油に豊富です |
| カリウム | 200-400mg | 多い | ナトリウムのバランスに関わります |
| マグネシウム | 中程度 | 非常に多い | 種に特に多く含まれます |
| 鉄・亜鉛 | 中程度 | 多い | 種はミネラルの供給源です |

&nbsp;&nbsp;&nbsp;この表から読み取るべきは、果実と種がまったく別の食品だという事実です。果肉は水分88%の低熱量の野菜で、種は脂肪45%、タンパク質25%超の高熱量の種実です。一つの果実の中に性質が正反対の二つが入っているわけで、災害時にはこの二つを両方とも使うのが正解です。

&nbsp;&nbsp;&nbsp;カボチャ一つから採れる種は、おおよそ50-100gです。乾かして炒ればそのままおやつになり、臼でついて油を搾ることもできます。種100gから30-40gの油が採れます。少量ですが、油がまったく途絶えた状況では、これも資源です。何より、タンパク質密度Cという果実の弱点を、同じ作物の中で補ってくれます。ホバクチュク（カボチャ粥）に砕いたカボチャの種を混ぜれば、タンパク質と脂肪が一緒に入ります。

&nbsp;&nbsp;&nbsp;ベータカロテンは、この作物の栄養学的な正体です。果肉のオレンジ色が濃いほど含有量が高く、貯蔵中もほとんど減りません。体内でビタミンAに変わる前駆体で、脂溶性なので、油と一緒に食べると吸収がよくなります。ホバクチュクにエゴマやゴマを入れたり、炒めて食べたりする方法が、吸収率を高めます。

&nbsp;&nbsp;&nbsp;貯蔵中に味がよくなるという点も特筆に値します。収穫したてのカボチャより、一か月から二か月置いたカボチャのほうが甘くなります。果肉にたまったデンプンが、徐々に糖に変わるためです。そのため、収穫直後に食べるより、しばらく置いてから食べるほうがよく、これは貯蔵作物として異例の長所です。ジャガイモやサツマイモのように貯蔵中に品質が落ちるのではなく、むしろ良くなる期間があります。

## 3. 栽培環境

### 3-1. 温度

| 区分 | 限界値 | 最適値 | 備考 |
|---|:---:|:---:|---|
| 発芽温度 | 15-35℃ | 25-30℃ | 15℃以下では発芽しません |
| 生育温度 | 15-35℃ | 18-30℃ | 暑さには比較的強いです |
| 結実温度 | 20-30℃ | 22-28℃ | 評価表の温度適応幅Cは、この10℃の幅です |
| 高温限界 | 35℃以上 | - | 花粉の活力が落ちて受精しません |
| 低温限界 | 10℃以下 | - | 生育が止まります |
| 致死 | 0℃以下 | - | 霜が一度降りるだけで葉が黒く枯れます |

&nbsp;&nbsp;&nbsp;メットルホバクは東洋系なので、暑さによく耐えます。西洋系の甘カボチャが30℃を超えると苦しがるのとは違い、35℃近くまで持ちこたえます。ただし35℃を超えると花粉が活力を失い、受精しません。韓国では7月下旬から8月上旬の最も暑い時期に、雌花が咲いても実がつかないことがあるのはこのためで、この時期は人工授粉の必要性が特に高まります。

&nbsp;&nbsp;&nbsp;霜にはまったく無力です。まず葉が黒く枯れ、つるが枯れます。ただし、すでに熟して皮が硬くなった果実は、軽い霜が一度降りた程度ではすぐには傷みません。それでも霜に当たったカボチャは貯蔵性が大きく落ちるため、初霜の予報があれば、その前にすべて収穫するのが原則です。

### 3-2. 光

| 区分 | 基準 | 備考 |
|---|---|---|
| 必要日照 | 1日6時間以上 | 着果と糖の蓄積に必要です |
| 最小日照 | 1日4時間 | つるは伸びますが、雌花が少なく果実が小さくなります |
| 40%遮光時 | 相対収量102% | 果菜類に共通の値で、評価表のS等級の根拠です |
| 葉面積 | 果実一つ当たり葉20-25枚 | 光合成で果実を充実させます |

&nbsp;&nbsp;&nbsp;カボチャでは、葉の数が果実の大きさを直接決めます。果実を一つしっかり育てるには、その果実がついたつるに葉が20枚から25枚必要です。そのため、摘心のときに葉を取りすぎると果実が小さくなり、逆に葉が茂りすぎるとお互いに陰をつくって下のほうの葉が働けなくなります。このバランスを取るのが、第8節の摘心です。

&nbsp;&nbsp;&nbsp;遮光に強いという点は、配置の面で役に立ちます。つるを塀の上や屋根に上げれば、畑を占めずに日光を受けられます。トウモロコシの間につるを伸ばさせる配置も昔からの方法で、トウモロコシの陰でもカボチャは育ちます。ただし、1日4時間を下回ると、雌花がほとんど出なくなります。

### 3-3. 水と土壌

| 項目 | 基準 | 備考 |
|---|---|---|
| 総蒸発散量 | 作期当たり約550mm | 果菜の中では少ないほうで、評価表の水消費量Bの根拠です |
| 土壌水分 | 最大容水量の60-70% | 根が深いため、乾燥には比較的強いです |
| 土性 | 排水のよい砂壌土から壌土 | 土質をあまり選びません |
| 土の深さ | 30cm以上 | 主根が深く伸びます |
| pH | 5.5-6.8 | 酸性には比較的寛容です |
| 畝の高さ | 20-30cm | 韓国の梅雨（チャンマ、6月下旬～7月）の過湿を防ぎます |
| 耐塩性 | 中程度 | |

&nbsp;&nbsp;&nbsp;カボチャは土質を選ばないと言われますが、これは実際に当たっています。根が深く広く張り、節ごとに不定根を出して吸収面積を増やします。肥料分の少ない余った土地、石の混じった畑、堆肥の山のそばのような場所でも育ちます。ただし、水がたまる場所だけはいけません。根が息できなくなると、疫病とつる割病が入り込みます。

> **カボチャは肥料分の多い場所を好む一方で、窒素が多すぎるとつるばかりが伸びて雌花が出ない作物です。堆肥の山のそばに植えるとよく育つというのは本当ですが、その場所が窒素ばかり多くてリン酸とカリウムが少なければ、葉だけが茂ります。**

&nbsp;&nbsp;&nbsp;総蒸発散量550mmは、ナスやトウガラシの750mmより少ない値です。葉が大きくて蒸発が多そうに見えますが、実際には水の消費が少ないのは、根が深いからです。表土が乾いても、下の層の水を引き上げて使います。そのため乾燥に比較的よく耐え、水が貴重な条件では、他の果菜より有利な位置にあります。
