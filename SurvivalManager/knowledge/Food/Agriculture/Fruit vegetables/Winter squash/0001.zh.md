## 引言
&nbsp;&nbsp;&nbsp;南瓜（Cucurbita moschata）是葫芦科南瓜属的一年生蔓性植物，在韩国因形似石磨而得名，成熟后又叫老南瓜、青冬南瓜。原产于中南美洲，当嫩瓜摘着吃的幼果和完全成熟后收获的老南瓜，其实是同一种作物的不同时间点。评价表的综合等级是A（48.4分），副食是S（55.0分）。果菜类几乎无一例外耐储性停留在D，只有南瓜得了A。充分成熟并经过愈伤处理的南瓜，不用冰箱，常温下能放三四个月，条件好时可达六个月。单位面积热量也是B（每1,000㎡产4,000kg，每㎡1,520kcal，为自给线的0.58倍），β-胡萝卜素多，冬天可供应维生素A。连作适应性是SS（连作无害类），种子在常温密封下可存放6-10年。成熟果、嫩瓜、叶和嫩尖、花、种子都能吃。弱点是一年只在秋天一次性收获（持续性D）、从播种到完全成熟要120-150天、怕霜冻（耐寒性E）、藤蔓伸展3-5m、蛋白质不足（P:E 9.3%）、授粉依赖蜜蜂。最合适的安排，是在田边或墙根这样的零碎空地上种几株，让藤蔓向外伸展。

## 1. 灾害应对评估
| 类别 | 等级 | 得分 |
|:---|:---:|:---:|
| 综合 | A | 48.4 |
| 短期 | B | 47.5 |
| 长期 | A | 49.4 |
| 副食 | S | 55.0 |

| 评估 | 项目 |
|:---|:---|
| 优势 | SS：连作适应性。S：微量营养素、光照反应、口味、国内种植普及度、种子寿命。A：耐储性、设施负担（可放任栽培）。B：单位面积热量、水消耗量（总蒸散量550mm） |
| 劣势 | E：耐寒性。D：持续性、非食用价值。C：蛋白质密度、收获速度、温度幅度、病虫害压力、防治自立度、无合成投入产量保持率 |

> **南瓜的耐储性不是来自储存技术，而是来自果实本身的结构。没熟的南瓜再怎么保管也不耐放，储存的成败不在仓库，而在收获时点选在什么时候。**

&nbsp;&nbsp;&nbsp;南瓜提供热量和维生素A但不提供蛋白质，所以在南瓜旁边种豆子、不扔南瓜子，就是弥补这个弱点的办法。各项目的等级见“灾害应对作物评价结果”文档。

## 2. 植物概述
| 种 | 类群 | 代表 | 特点 |
|:---|:---|:---|:---|
| C. moschata | 东方系 | 南瓜、老南瓜、嫩南瓜、奶油南瓜 | 耐热、耐储。果蒂为向外展开的五角形 |
| C. maxima | 西方系 | 栗南瓜、药南瓜 | 喜凉爽气候，糖度高。果蒂圆形，木栓质 |
| C. pepo | 西葫芦系 | 西葫芦、金丝瓜 | 蔓短早熟，但不耐储。果蒂为五棱星形 |

&nbsp;&nbsp;&nbsp;不同种之间几乎不杂交，同一个种之间则完全混杂。藤蔓贴地爬行3-5m，节上长出不定根扎入土里。花为黄色大筒状，雌花和雄花分开，清晨开放，中午闭合。雄花先开且多得多，所以前期没有雌花不必担心。果实扁圆，沟很深，幼时绿色，成熟后变黄褐色并披白粉。一个果实里有200-500粒长1.5-2cm的扁平种子。

| 阶段 | 时期 | 要点 |
|:---|:---|:---|
| 发芽·幼苗期 | 播种到真叶4-5片（3-4周） | 磷 |
| 藤蔓伸长期 | 5-7月 | 每天长10cm以上。只开雄花。氮 |
| 开花·坐果期 | 7-8月 | 雌花开放并授粉。磷、钾、硼 |
| 果实膨大期 | 8-9月 | 开花后20-30天基本长足。钾 |
| 成熟期 | 9-10月 | 果皮变硬，淀粉积累，颜色变化。减少浇水 |

> **果实长足之后的一个月决定耐储性。大小在开花后30天就定型了，但果皮木质化、果蒂干枯、披上白粉，还要再过20-30天。不等这段时间就收获，耐储性A就没有了。**

| 每100g营养 | 老南瓜（生） | 南瓜子（干） |
|:---|:---|:---|
| 热量 | 38kcal（水分约88g） | 550-570kcal |
| 蛋白质 / 脂肪 | 0.88g / 0.1g | 25-30g / 45-50g |
| 其他 | β-胡萝卜素极高（橙色），维生素C 10-15mg（烹调中大量损失），钾200-400mg | 镁极高，铁、锌、维生素E丰富 |

## 3. 栽培环境与品种
| 条件 | 标准 |
|:---|:---|
| 温度 | 发芽25-30℃（15℃以下不发芽），生长18-30℃，结实22-28℃（20-30℃）。35℃以上花粉活力下降，受精不成，一次霜冻叶子就变黑枯死 |
| 光照 | 每天6小时以上（最少4小时，更少则雌花少、果实小）。每个果实需要20-25片叶子 |
| 水 | 每茬总蒸散量约550mm。土壤水分为最大持水量的60-70% |
| 土壤 | 排水良好的砂壤土至壤土，土层厚30cm以上，pH 5.5-6.8。垄高20-30cm |

&nbsp;&nbsp;&nbsp;南瓜喜欢肥多的地方，但氮过多就只长藤蔓、不出雌花。说种在堆肥堆旁边长得好是对的，但如果那个地方氮多而磷钾少，就只会叶子茂盛。

| 品种 | 特点 |
|:---|:---|
| 传统南瓜、青冬南瓜 | 扁圆，沟深，果肉深橙色。耐储性最好，是固定种，可留种延续 |
| 改良南瓜 | 产量高，抗病性增强。若是一代杂种，就不能留种 |
| 奶油南瓜 | 长颈钟形，籽腔小，果肉比例高。同属一个种，所以会与南瓜杂交 |

&nbsp;&nbsp;&nbsp;以冬粮和留种为目的就用传统品系，地小用奶油南瓜或西葫芦系，凉爽的高冷地用栗南瓜。从一代杂种上留的种子，第二年会分离。

## 4. 田地准备、播种与定植
| 项目 | 标准 |
|:---|:---|
| 整地 | 翻耕25-30cm深，垄高20-30cm，田边和垄端开排水沟（积水则疫病来袭）。选每天6小时以上有阳光、藤蔓能伸展3-5m的地方（田边、墙根） |
| 施肥（每1,000㎡） | 堆肥1,500-2,000kg，氮10-15kg，磷8-12kg，钾10-15kg，石灰100-150kg（栽前3-4周）。基肥在栽前2周施入：堆肥全部 + 磷全部 + 氮和钾的50% |
| 追肥 | 第1次在藤蔓伸长期（定植后一个月），以氮为主、少量；第2次在坐果后，以钾为主。收获前20-30天停止（氮施晚了果皮硬化不足，耐储性下降） |
| 替代资源 | 腐熟堆肥与土各半混合放进种植穴，稀释10-15倍的尿液（仅在藤蔓伸长期），坐果后草木灰一把，骨粉，穴底垫落叶和草 |

> **南瓜施氮要特别小心。如果叶子深绿、藤蔓粗、节间长，却没有雌花，几乎可以肯定是氮过多。**

| 茬口 | 播种 | 定植 | 收获 |
|:---|:---|:---|:---|
| 露地直播 | 4月中旬至下旬 | - | 9月上旬至10月中旬 |
| 育苗后定植 | 3月下旬至4月中旬 | 5月上旬至下旬 | 9月上旬至10月中旬 |

> **南瓜从播种到完全成熟要120-150天。4月种下，9月才能成熟；过了5月才种，霜前果皮硬化不了，只剩下不能储存的半成品南瓜。**

| 栽种 | 标准 |
|:---|:---|
| 育苗 | 浸泡一夜，用湿布包好，在25-30℃催芽。深2-3cm，白天22-28℃、夜间15℃以上，3-4周，真叶3-4片时定植。不要养得过大 |
| 布局 | 行宽3.5-4m（放任栽培的标准），株距60-100cm（地窄时30-40cm），每1,000㎡ 300-400株。每穴播2-3粒，真叶2-3片时只留最壮的一株。往穴里浇水，水渗完后再栽 |
| 藤蔓处理 | 放任（省事，节上长不定根），朝一个方向引蔓，上篱笆·墙（果实不着地，不易烂），上屋顶·棚架（果实要用绳子托住），让它爬树 |

## 5. 水分管理与栽培管理
| 时期 | 水分管理 |
|:---|:---|
| 播种-发芽 | 保持不干（种子大而厚） |
| 幼苗期 | 每3-4天一次 |
| 藤蔓伸长期 | 每5-7天一次 |
| 开花·坐果期、果实膨大期 | 每4-5天一次，浇足（缺水则雌花脱落，果实重量的大部分是这时吸进的水） |
| 成熟期（收获前20-30天） | 逐渐减少，最后停水（耐储性提高） |
| 梅雨季 | 停止灌溉，检查排水沟 |

&nbsp;&nbsp;&nbsp;中午叶子下垂、傍晚恢复，是正常的。傍晚也不恢复、雌花发黄萎蔫脱落，就是缺水；蔓基部纵向裂开、流出汁液并萎蔫，是过湿引起的蔓割病。秋天多雨会降低耐储性，所以要尽量保证垄的排水，在连续几个晴天之后再收获更好。水贵重时，用稻草或草覆盖、节上培土、种植穴栽培。

| 管理 | 内容 |
|:---|:---|
| 打顶 | 母蔓雌花开得晚且少，所以果实从子蔓上收取。真叶5-6片时掐掉母蔓生长点，只留两条最壮的子蔓，或在第5-6节掐断，把3-4条子蔓向四面引开。放任不管则果实小、数量不均 |
| 坐果 | 取长势上来之后的第二、三个雌花（子蔓第13-18节附近）结的果，过早坐的果和形状不好的果趁幼小摘掉。每株留2个左右 |
| 保护果实 | 在果实下面垫稻草、木板、瓦片防烂。成熟期轻轻转动一两次，使颜色均匀。酷热时用叶子或稻草盖住。不要频繁挪动藤蔓 |

| 人工授粉 | 方法 |
|:---|:---|
| 需要时 | 梅雨使蜜蜂无法飞行、周围蜜蜂少、超过35℃的酷热、清晨下雨。不授粉的话，雌花会发黄萎蔫脱落 |
| 方法 | 从日出后到上午8点前，摘下盛开的雄花（连花梗），去掉花瓣，把雄蕊在雌花柱头上蹭，使花粉均匀沾上。一朵雄花可给两三朵雌花授粉 |
| 确认 | 三四天后子房变粗就成功，发黄萎蔫就失败 |

> **雌花开了却不坐果，先别再加肥，先试人工授粉。多施氮只会让藤蔓更茂盛，雌花更少，陷入恶性循环。**

## 6. 病虫害与养分问题
| 病害 | 症状与条件 | 不用药的应对 |
|:---|:---|:---|
| 白粉病 | 叶面白粉。干燥与高湿交替的8-9月 | 蛋黄油、牛奶稀释液、小苏打稀释液、整理下部叶子、早期摘除病叶 |
| 霜霉病 | 受叶脉限制的多角形黄斑，叶背有霉。潮湿、低温 | 保证通风、预防性喷波尔多液 |
| 蔓割病、疫病 | 基部纵向裂开并流汁，植株萎蔫。根茎腐烂。过湿 | 无法治疗。立即拔除病株、高垄和排水 |
| 花叶病毒病 | 叶片花叶卷曲，果实畸形（蚜虫传播） | 无法治疗。防治蚜虫、拔除病株 |

&nbsp;&nbsp;&nbsp;害虫有蚜虫（肥皂水、保护瓢虫）、二斑叶螨（用力向叶背喷水）、黄守瓜（幼苗期罩网、人工捕捉）、瓜绢螟（摘除卷起的叶子）、根结线虫（与万寿菊间作、轮作）。蛋黄油的做法是：把1个蛋黄调进100mL水，倒入60mL食用油用力搅拌乳化，再兑进20L水（白粉病·螨虫，中午喷会烧叶）。另外还用1g小苏打兑1L水、波尔多液（硫酸铜1kg和生石灰1kg分别溶解冷却后合并，加水至100L）、肥皂水（无香肥皂20g加水1L）、草木灰。

| 症状 | 原因与处理 |
|:---|:---|
| 从下部叶子开始发黄，藤蔓细 | 缺氮。藤蔓伸长期用稀释10-15倍的尿液（坐果后不施） |
| 叶缘焦枯，果实小 | 缺钾。草木灰 |
| 生长迟缓，叶小且发紫 | 缺磷。骨粉、草木灰 |
| 光长藤蔓、节间长、没有雌花 | 氮过多。停止施氮，用草木灰补钾，打顶 |
| 果实顶端发软腐烂 | 钙运输障碍或过湿。改善排水、均匀浇水 |
| 果肉颜色淡、甜味少 | 缺钾、光照不足、过早采收。草木灰、整理叶子、推迟收获 |

## 7. 间作与轮作
| 搭配 | 对象 |
|:---|:---|
| 好 | 与玉米·藤蔓豆一起种的“三姐妹”搭配（玉米是豆的支架，藤蔓豆固氮，南瓜覆盖地面并抑制杂草。间距要宽），豆科，万寿菊，白苏·紫苏 |
| 差 | 其他葫芦科（黄瓜·西瓜·甜瓜。共有病虫害），马铃薯（共有疫病系统），矮的叶菜类（被藤蔓盖住） |

&nbsp;&nbsp;&nbsp;第1年南瓜，第2年南瓜（可以）或豆科，第3年谷物或叶菜，第4年再回到南瓜。三年里最好有一次换种其他作物。

## 8. 收获与留种
| 项目 | 标准 |
|:---|:---|
| 时期 | 开花后50-60天，9月上旬至10月中旬初霜前。嫩南瓜在开花后7-10天，指甲能掐进果皮时 |
| 成熟标志 | 果皮由绿色完全变成黄褐色，白粉均匀披上，果蒂像木头一样干枯并有纵向裂纹（最可靠），指甲按压不留痕，敲起来声音沉闷 |
| 割法 | 选晴朗干燥的日子，用刀或修枝剪留3-5cm果蒂剪下（不要拧），一个一个搬运，不要擦伤。果蒂留3-5cm且干了的，可放三四个月到六个月；果蒂短的两三个月；果蒂掉了留下坑的，几周内就从那里开始烂 |

> **果蒂还是绿的而且发软，果皮再黄也还没熟。果蒂像木头一样干枯、像木栓一样的时候，才是可以储存的状态。**

| 留种 | 标准 |
|:---|:---|
| 杂交 | C. moschata之间（南瓜、嫩南瓜、奶油南瓜）完全杂交，maxima和pepo几乎不杂交。黄瓜、甜瓜、西瓜、葫芦属不同，不杂交。种靠果蒂形状来区分 |
| 防止 | 只种一个种的一个品系。500m以上的隔离很难，所以利用种子寿命长的特点，一年只让一个品系开花。最可靠的是开花前一天下午给雌花和雄花套袋，第二天日出后到上午8点前人工授粉，再给雌花套上袋子，两天后摘掉 |
| 株数 | 为避免近交衰退，至少从五株、最好十株以上的植株上各取一两个 |
| 步骤 | 8月选形状端正、无病的果实做标记。比食用的熟得更久、更透，采后后熟2-4周。刮出种子，在水里搓掉果肉，丢掉浮起的。在布或帘子上摊一层，在阴凉处晾1-2周（不直接曝晒） |
| 寿命 | 常温密封6-10年。每隔几年取20粒放在湿布上确认发芽率 |

## 9. 储存
| 步骤 | 标准 |
|:---|:---|
| 愈伤处理 | 收获后立即在25-30℃、湿度80%左右放10-14天。摊开成一层、互不接触，放在有阳光的廊下、屋檐下、火炕房的炕梢、没有塑料膜的棚屋 |
| 正式储存 | 10-15℃（12-14℃最好），湿度60-70%，阴凉干燥通风的地方（棚屋、阁楼、廊下、朝北的房间）。互不接触地在架子或稻草上摆成一层，每2-3周挑出变软的。不用冰箱（5℃以下冷害） |

> **没经过愈伤处理的南瓜撑不过三四个月，经过的能放六个月。这十来天的差别，决定了冬末的粮食。淀粉会转化成糖，所以收获后一两个月最甜。**

| 方式 | 内容 | 期限 |
|:---|:---|:---|
| 整个储存 | 愈伤处理后10-15℃ | 4-6个月 |
| 南瓜干（hobakgoji） | 去皮切薄片晒干（处理有伤的、未熟的南瓜） | 6个月至1年 |
| 种子 | 洗净晒干后密封 | 多年 |

## 10. 烹调与注意事项
| 部位 | 烹调 |
|:---|:---|
| 成熟果 | 蒸、粥、汤、糊。需要加热30分钟，不适合生吃 |
| 嫩南瓜 | 炒、炖、煎饼 |
| 叶·嫩尖 | 蒸后包饭，焯后凉拌。掰断叶柄、顺茎的方向撕皮，粗硬的纤维会一起撕掉。放在米饭上一起蒸，不用额外燃料。一株一次只摘三四片 |
| 花 | 用雄花做煎饼或汤（摘雌花会没有果实） |
| 种子 | 晒干后小火炒着吃，或磨粉放进粥里。炒后磨碎压榨，100g种子可出30-40g油，油饼可食用或作肥料。一个南瓜可得干种子50-100g |
| 果皮 | 久煮可食，否则作牲畜饲料 |

| 注意 | 内容 |
|:---|:---|
| 葫芦素 | 葫芦科的苦味防御物质，栽培种中几乎消失，但与观赏南瓜杂交的种子、野化的南瓜、极端干旱或高温下可能出现。咬一口有刺舌头的苦味，就立刻吐掉并丢弃整个南瓜。加热也不会消失，会引起呕吐和腹泻。叶和嫩尖同样如此 |
| 霉菌 | 储存中发软、有气味就丢弃 |

## 11. 全年作业日程
| 月份 | 作业 |
|:---|:---|
| 1-2月 | 检查储存的南瓜，挑出变软的并继续吃，检查种子，决定种植地，翻堆堆肥 |
| 3-4月 | 下旬开始育苗并给田里施石灰，挖穴施堆肥，中旬直播 |
| 5月 | 上旬至下旬定植，真叶5-6片时给母蔓打顶 |
| 6月 | 引蔓并整理子蔓，第1次追肥，开始摘叶吃 |
| 7月 | 雌花开了就在清晨人工授粉，摘掉第一个雌花结的果 |
| 8月 | 坐果管理和在果实下垫东西，第2次追肥（钾），巡查白粉病，给留种果做标记 |
| 9月 | 减少浇水，上旬起收获熟了的并开始愈伤处理 |
| 10月 | 初霜前全部收获，愈伤处理结束后入正式储存 |
| 11-12月 | 清走藤蔓和叶子，切碎翻入田里，从留种果取种并挑选，检查仓库温度不要结冰 |

> **不能忘记的五件事：4月播种、少施氮、没有蜜蜂就人工授粉、等果蒂干了再收获并做愈伤处理、有苦味就丢掉。**
