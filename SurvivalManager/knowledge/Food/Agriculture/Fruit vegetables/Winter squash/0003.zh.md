## 2. 这是一种什么样的植物

### 2-1. 分类与原产地

&nbsp;&nbsp;&nbsp;南瓜是葫芦科（Cucurbitaceae）南瓜属（Cucurbita）的一年生藤本植物。学名为Cucurbitamoschata，在韩国通常统称为南瓜（hobak）的这类作物，实际上分属于三个互不相同的种。

| 种 | 系统 | 代表 | 特征 |
|---|---|---|---|
| Cucurbitamoschata | 东洋系 | 南瓜（石磨南瓜，maetdol hobak）、老南瓜、嫩南瓜（aehobak）、青南瓜（put hobak）、花生南瓜（ttangkong hobak，即奶油南瓜） | 耐热，耐储性好。瓜蒂呈五角形，向外展开 |
| Cucurbitamaxima | 西洋系 | 板栗南瓜（甜南瓜）、药南瓜（yak hobak） | 喜凉爽气候，甜度高。瓜蒂圆形，木栓质 |
| Cucurbita pepo | pepo系 | 西葫芦、金丝瓜、观赏南瓜 | 藤蔓短，早熟。瓜蒂有五条明显的棱 |

> **这三个种彼此是不同的种，因此原则上不会杂交。这一事实决定了第13节留种的全部内容。同一个种之间会完全混杂，不同的种之间几乎不会混杂。**

&nbsp;&nbsp;&nbsp;不过，很难断言它们完全不会杂交。有报告称，C.moschata与C.maxima之间偶尔会产生杂种，这种杂种的种子大多不能成熟。实际操作中只需提防同一个种之间的杂交即可，区分种的方法是看瓜蒂的形状。石磨南瓜的瓜蒂是向外展开的五角形，木质化得很坚硬。甜南瓜的瓜蒂圆形，是海绵般柔软的木栓质。西葫芦的瓜蒂则是棱角分明的五角星形。

&nbsp;&nbsp;&nbsp;原产地是从中美洲到南美洲北部的地区。C.moschata是其中在炎热低地生长的系统，因此耐高温，所以能很好地适应韩国夏季的炎热与潮湿。这与西洋系的C.maxima在凉爽的高冷地才表现良好形成对比。在韩国大部分地区，石磨南瓜比甜南瓜更稳定，原因就在于这一出身。

### 2-2. 形态

| 器官 | 特征 |
|---|---|
| 叶 | 宽心形，边缘有浅裂和锯齿。表面有粗糙的毛，有些品系还会出现白色斑纹。直径20-30cm |
| 茎（藤蔓） | 匍匐地面生长，可延伸3-5m。截面为五角形，中空。节上长出不定根，扎入土中 |
| 卷须 | 从叶腋长出，遇物就缠绕。引蔓时可加以利用 |
| 根 | 笔直的主根深深下扎，须根向四周广泛展开。在果菜中属于根系较深的 |
| 花 | 黄色大型合瓣花。雌花和雄花分开开放，长在同一株上。清晨开放，正午闭合 |
| 果实 | 圆而扁，棱沟很深。幼时为绿色，成熟后变为黄褐色，表面泛起白色果粉 |
| 种子 | 长1.5-2cm的扁椭圆形，白色至浅褐色。每个果实含200-500粒 |

&nbsp;&nbsp;&nbsp;节上长出不定根这一点，在实际操作中很有用。藤蔓在地面爬行时，一旦节碰到土壤，就会在那里长出根，另外吸收水分和养分。因此，在藤蔓中段轻轻盖上一层土，根就会增多，整株植株会变得更加健壮。这叫作压蔓促根，在肥料不足的条件下尤其有效。相反，频繁挪动、翻起藤蔓，这些根就会被扯断。

&nbsp;&nbsp;&nbsp;花的结构是这种作物的关键。南瓜花雌雄分开开放。雄花长在长长的花梗顶端，中央有沾满花粉的雄蕊。雌花长在短花梗上，花下面已经带着一个小南瓜形状的子房。这个子房长大就成为果实。区分雌花和雄花的办法就在这里：花下面连着一个小南瓜的是雌花，没有的是雄花。

| 类别 | 雄花 | 雌花 |
|---|---|---|
| 花梗 | 细长 | 短粗 |
| 花下 | 什么都没有 | 带有小南瓜形状的子房 |
| 开放顺序 | 先开。初期只出雄花 | 藤蔓长到一定程度后才开 |
| 数量 | 多得多 | 较少 |
| 开花时间 | 清晨，日出前后 | 相同。上午闭合 |

&nbsp;&nbsp;&nbsp;初期只开大量雄花、不见雌花，常常让人担心。这是正常现象。南瓜的藤蔓必须长到一定长度以上才会形成雌花，在此之前只开雄花。氮过量时，这种状态会持续更久，藤蔓只管一个劲儿生长，雌花迟迟不出现。

### 2-3. 生育阶段

| 阶段 | 时期（韩国） | 关键生理 | 重要养分 |
|---|---|---|---|
| 发芽·幼苗期 | 从播种到长出4-5片真叶（3-4周） | 子叶大幅展开，主根向下扎 | 磷 |
| 藤蔓伸长期 | 5-7月 | 藤蔓每天生长超过10cm。只开雄花 | 氮 |
| 开花·坐果期 | 7-8月 | 雌花开放，完成授粉 | 磷、钾、硼 |
| 果实膨大期 | 8-9月 | 果实迅速长大。开花后20-30天基本长足 | 钾 |
| 成熟期 | 9-10月 | 停止增大，果皮变硬，淀粉积累，颜色改变 | 减少灌水 |

> **果实长足之后的一个月，决定着耐储性。果实大小在开花后30天就定型，但果皮木质化、瓜蒂干枯、表面泛起白色果粉，还要在这之后再花20-30天。不等这段时间就收获，耐储性A就没有了。**

&nbsp;&nbsp;&nbsp;所以，嫩南瓜和老南瓜是同一个果实在不同时点的样子。开花后7-10天摘下的是嫩南瓜，等到50-60天就是老南瓜。选哪一种取决于目的。嫩南瓜是夏季的菜，老南瓜是冬季的口粮。如果一株上不断摘嫩南瓜，就得不到老南瓜；反过来，如果以老南瓜为目标，夏天就没有可摘来吃的东西。在灾害情形下，通常以后者为优先。

### 2-4. 每100g的营养

| 营养素 | 老南瓜（生） | 南瓜籽（干） | 备注 |
|---|:---:|:---:|---|
| 热量 | 38kcal | 550-570kcal | 种子是一团油脂 |
| 水分 | 约88g | 5-7g | |
| 蛋白质 | 0.88g | 25-30g | 果实的P:E为9.3%，达不到需求线 |
| 碳水化合物 | 6-12g | 10-15g | 果实越熟淀粉越多，贮藏期间会转变为糖 |
| 脂肪 | 0.1g | 45-50g | 种子可以榨油 |
| 膳食纤维 | 2-3g | 6-7g | |
| β-胡萝卜素 | 非常高 | 无 | 果肉的橙色就是这种色素 |
| 维生素C | 10-15mg | 微量 | 烹饪过程中会损失相当一部分 |
| 维生素E | 含有 | 高 | 种子油中含量丰富 |
| 钾 | 200-400mg | 高 | 参与钠的平衡 |
| 镁 | 中等 | 非常高 | 种子中尤其多 |
| 铁·锌 | 中等 | 高 | 种子是矿物质的来源 |

&nbsp;&nbsp;&nbsp;从这张表中要读出的是，果实和种子完全是两种不同的食物。果肉是含水量88%的低热量蔬菜，种子则是脂肪占45%、蛋白质超过25%的高热量种实。一个果实里装着性质截然相反的两样东西，在灾害情形下，把这两样都用上才是正确的做法。

&nbsp;&nbsp;&nbsp;一个南瓜里的种子大约有50-100g。晒干后炒一炒就是现成的零食，也可以放进臼里捣碎榨油。每100g种子能出30-40g油。量虽少，但在油脂完全断供的情况下，这也是一种资源。最重要的是，它在同一种作物内部弥补了蛋白质密度C这一果实的弱点。把捣碎的南瓜籽掺进南瓜粥（hobakjuk）里，蛋白质和脂肪就一起摄入了。

&nbsp;&nbsp;&nbsp;β-胡萝卜素是这种作物在营养学上的标志。果肉的橙色越深，含量越高，贮藏期间也几乎不会减少。它是在体内转化为维生素A的前体物质，属于脂溶性，与油一起吃吸收更好。在南瓜粥里加入紫苏（荏）籽或芝麻，或者炒着吃，都能提高吸收率。

&nbsp;&nbsp;&nbsp;贮藏期间口味变好，这一点也值得一提。放了一两个月的南瓜，比刚收下的南瓜更甜。这是因为果肉中积累的淀粉会慢慢转化为糖。所以，与其收获后马上吃，不如放一段时间再吃，这对贮藏作物来说是难得的优点。不像马铃薯或甘薯那样在贮藏期间品质下降，南瓜反而有一段品质提升的时期。

## 3. 栽培环境

### 3-1. 温度

| 类别 | 极限值 | 最适值 | 备注 |
|---|:---:|:---:|---|
| 发芽温度 | 15-35℃ | 25-30℃ | 15℃以下不发芽 |
| 生长温度 | 15-35℃ | 18-30℃ | 较耐热 |
| 结实温度 | 20-30℃ | 22-28℃ | 评价表中的温度适应幅度C就是这10℃的幅度 |
| 高温极限 | 35℃以上 | - | 花粉活力下降，无法受精 |
| 低温极限 | 10℃以下 | - | 生长停止 |
| 致死 | 0℃以下 | - | 一次霜冻，叶片就变黑死亡 |

&nbsp;&nbsp;&nbsp;石磨南瓜属于东洋系，耐热性好。西洋系的甜南瓜超过30℃就会吃力，而它可以撑到35℃左右。不过超过35℃，花粉就会丧失活力，无法受精。在韩国，7月下旬到8月上旬最热的时段，雌花开了也坐不住果，就是这个原因，这一时期对人工授粉的需求尤其大。

&nbsp;&nbsp;&nbsp;它对霜冻毫无抵抗力。叶片先变黑枯死，接着藤蔓干枯。不过，已经成熟、果皮变硬的果实，遇到一次轻霜不会马上受损。即便如此，遭过霜的南瓜耐储性会大幅下降，所以一旦有初霜预报，原则上要在此之前全部收完。

### 3-2. 光照

| 类别 | 标准 | 备注 |
|---|---|---|
| 所需日照 | 每天6小时以上 | 坐果和糖分积累所需 |
| 最低日照 | 每天4小时 | 藤蔓能生长，但雌花少、果实小 |
| 40%遮光时 | 相对产量102% | 为果菜类通用值，是评价表中S等级的依据 |
| 叶面积 | 每个果实对应叶20-25片 | 靠光合作用充实果实 |

&nbsp;&nbsp;&nbsp;南瓜的叶片数量直接决定果实的大小。要把一个果实培育好，结这个果实的那条藤蔓上需要有20到25片叶。因此，摘心时如果叶子去得太多，果实就会变小；反过来，叶子过于繁茂，会互相遮阴，下层的叶片就发挥不了作用。要把握好这种平衡，靠的就是第8节的摘心。

&nbsp;&nbsp;&nbsp;耐遮光这一点，在布置上很有用。把藤蔓引到围墙顶上或屋顶上，既不占田地，又能晒到太阳。让藤蔓在玉米之间延伸的布置也是自古以来的做法，南瓜在玉米的阴影下也能生长。不过，每天日照一旦低于4小时，就几乎不再出现雌花。

### 3-3. 水分与土壤

| 项目 | 标准 | 备注 |
|---|---|---|
| 总蒸散量 | 每个生长期约550mm | 在果菜中偏少，是评价表中耗水量B的依据 |
| 土壤水分 | 最大持水量的60-70% | 根系深，较耐旱 |
| 土壤质地 | 排水良好的砂壤土至壤土 | 对土质要求不严 |
| 土层深度 | 30cm以上 | 主根深扎 |
| pH | 5.5-6.8 | 对酸性较为宽容 |
| 垄高 | 20-30cm | 防止韩国梅雨季（6月下旬至7月）的过湿 |
| 耐盐性 | 中等 | |

&nbsp;&nbsp;&nbsp;说南瓜对土质不挑剔，这话确实没错。它的根扎得深、分布广，每个节上都长出不定根来增加吸收面积。在肥力低的零碎地、掺有石头的田块、堆肥堆旁这类地方也能生长。只是积水的地方不行。根部一旦无法呼吸，疫病和枯萎病就会趁虚而入。

> **南瓜既喜欢肥力充足的地方，又是一种氮过量就只长藤蔓、不出雌花的作物。说种在堆肥堆旁长得好，这话没错，但如果那个位置只有氮多而磷和钾少，就只会叶片繁茂。**

&nbsp;&nbsp;&nbsp;总蒸散量550mm，比茄子和辣椒的750mm要少。叶子大，看上去蒸发应该很多，实际上却耗水较少，原因在于根系深。表土干了，它也能把下层的水吸上来用。所以它比较耐旱，在水资源紧缺的条件下，比其他果菜更有优势。
