## 4. 品種

### 4-1. カボチャ類の系統とメットルホバクの位置づけ

| 系統 | 学名 | 代表 | 貯蔵性 | 災害対策への適合性 |
|---|---|---|:---:|---|
| 東洋系 | Cucurbitamoschata | カボチャ（メットルホバク）、老いたカボチャ、エホバク（若採りのカボチャ）、タンコンホバク（バターナッツ） | 非常に良い | 暑さに強く、貯蔵ができ、韓国の気候に合っています |
| 西洋系 | Cucurbitamaxima | 栗カボチャ（甘カボチャ）、ヤクホバク（薬カボチャ） | 良い | 糖度は高いものの暑さに弱く、高冷地に向いています |
| ペポ系 | Cucurbita pepo | ズッキーニ、ソウメンカボチャ | 悪い | 早生ですぐに食べられますが、貯蔵ができません |

### 4-2. メットルホバク系統の比較

| 品種 | 特徴 | 収量 | 貯蔵性 | 災害対策への適合性 |
|---|---|:---:|:---:|---|
| 在来のメットルホバク | 溝が深くて平たく、果肉が濃いオレンジ色です | 中程度 | 非常に良い | 固定種なので、種を採って受け継いでいけます |
| チョンドゥンホバク | メットルホバクと同じ仲間で、形がより丸いです | 中程度 | 非常に良い | 同じ性格です |
| 改良メットルホバク | 収量が増え、病気への抵抗性が強化されています | 多い | 良い | 一代雑種だと種を採れません |
| タンコンホバク（バターナッツ） | 首が長い釣り鐘形で、種の入る部分が小さく、果肉の割合が高いです | 中程度 | 非常に良い | 同じ種なので、メットルホバクと交雑します |

### 4-3. 状況別の選択基準

| 状況 | 選択 | 理由 |
|---|---|---|
| 冬の食料の確保が目的 | 在来のメットルホバク | 貯蔵性が最も良く、種を採って受け継いでいけます |
| 種を採って受け継いでいく計画 | 在来系統、固定種 | 一代雑種から採った種は、翌年に形質がばらつきます |
| 狭い土地 | タンコンホバク、ペポ系 | つるが短いか果実が小さいので、空間効率がよくなります |
| 夏にすぐ食べるものが必要 | ペポ系（ズッキーニ）、エホバク用 | 早生で、実がつくのが早いです |
| 冷涼な高冷地 | 西洋系の甘カボチャ | 暑さよりも涼しさを好みます |

&nbsp;&nbsp;&nbsp;災害への備えとしてメットルホバクを選ぶ理由は、貯蔵性と採種できることの二つです。在来のメットルホバクは、長いあいだ韓国の地で種を採って受け継がれてきた固定種で、これは、今年採った種が翌年も同じカボチャを実らせるという意味です。改良品種は収量と均一性で勝りますが、一代雑種であることが多く、種子の供給が途絶えた場合、有効なのは最初の年だけです。

> **カボチャの種は、常温・密閉で6-10年もちます。比較した作物全体の中で、最も長く生きる種子です。交雑の管理をきちんと行った年に種を十分に採っておけば、その後は何年も採種せずに過ごすことができ、これがこの作物の最大の戦略的な強みです。**

&nbsp;&nbsp;&nbsp;もう一つ付け加えると、複数の系統を一つの畑に植えることが、交雑の問題を招きます。メットルホバク、エホバク、タンコンホバクはいずれもC.moschataなので、互いに完全に混ざります。種を採る計画があるなら、同じ種に属するものは一つだけ植えるのが最も簡単です。逆に、甘カボチャ（C.maxima）やズッキーニ（C. pepo）は種が違うので、一緒に植えても種が混ざりません。この事実を踏まえて配置すれば、いくつもの種類を育てながら採種も可能です。

## 5. 畑の準備と肥料

### 5-1. 畑の準備

| 項目 | 基準 | 理由 |
|---|---|---|
| 耕うん深さ | 25-30cm | 主根が深く伸びます |
| 畝の高さ | 20-30cm | 韓国の梅雨（チャンマ、6月下旬～7月）の過湿を防ぎます |
| 排水溝 | 畑の縁と畝の端 | 水がたまると疫病が入り込みます |
| 石灰処理 | 定植の2-3週間前 | 堆肥と同じ日に入れると窒素が飛んでしまいます |
| 堆肥の投入 | 植え付けの2週間前 | 完熟堆肥だけを使います |
| 場所の選定 | つるが3-5m伸びる空間 | 畑の縁、塀の下が適しています |
| 日当たり | 1日6時間以上日が当たる場所 | |

&nbsp;&nbsp;&nbsp;カボチャの畑の準備には、特有の方法が一つあります。全面に肥料を均一に入れる代わりに、植える場所ごとに穴を掘り、そこだけに堆肥を集中して入れる方法です。直径50cm、深さ30cmほど掘り、堆肥と土を半々に混ぜて埋め戻し、その上に土をかぶせてこんもりと盛ってから、種をまきます。こうすると少ない堆肥で大きな効果が得られ、つるが伸びていく外側の土地には肥料を入れる必要がありません。肥料が貴重な条件では、特に合理的な方法です。

### 5-2. 施肥量

| 肥料 | 1,000㎡当たり | ㎡当たり | 配分 |
|---|:---:|:---:|---|
| 窒素（N） | 10-15kg | 10-15g | 元肥と追肥に分けます |
| リン酸（P） | 8-12kg | 8-12g | 全量を元肥で |
| カリウム（K） | 10-15kg | 10-15g | 元肥と追肥に分けます |
| 堆肥 | 1,500-2,000kg | 1.5-2kg | 植え付けの2週間前 |
| 石灰 | 100-150kg | 100-150g | 酸性土の矯正 |

&nbsp;&nbsp;&nbsp;窒素とリン酸とカリウムを合わせると㎡当たり30-40g、評価表の基準では24gです。施肥の等級Bは、ナスのD、トウガラシのDと比べると、はるかに軽い負担です。カボチャは肥料をたくさん必要とするという通念がありますが、単位面積当たりで見ればそうではありません。一株が占める面積が広いので、総量が多く見えるだけです。

> **カボチャでは、窒素に特に注意が必要です。窒素が多すぎるとつるばかりが旺盛に伸び、雌花が出ません。葉が濃い緑色でつるが太く、節間が長いのに雌花がないなら、ほぼ確実に窒素過剰です。**

### 5-3. 元肥と追肥の時期

| 区分 | 時期 | 内容 |
|---|---|---|
| 石灰 | 植え付けの3-4週間前 | 酸度の矯正 |
| 元肥 | 植え付けの2週間前 | 堆肥全量 + リン酸全量 + 窒素・カリウム50% |
| 追肥1回目 | つる伸長期（定植後一か月） | 窒素中心、少量 |
| 追肥2回目 | 着果直後 | カリウム中心 |
| 中止 | 収穫の20-30日前 | 遅くまで窒素を与えると、皮が十分に硬くならず貯蔵性が落ちます |

&nbsp;&nbsp;&nbsp;最後の項目が貯蔵性に直結します。成熟期に窒素が入り続けると、植物は成長を続けようとして、果実の皮が十分に硬くなりません。皮が柔らかいカボチャは、貯蔵中に腐ります。韓国では8月中旬以降は窒素を止めてカリウムだけを補うのが原則で、9月に入ったら何も入れません。

### 5-4. 化学肥料なしで同じ量をまかなう方法

| 代替資源 | 供給する養分 | 使い方 | 注意 |
|---|---|---|---|
| よく完熟した堆肥 | 窒素・リン酸・カリウムと微量要素全般 | 植え穴に土と半々に混ぜて入れます | 未熟な堆肥は根を傷めます |
| 薄めた尿 | 窒素 | 水で10-15倍に薄め、つる伸長期にだけ使います | 着果期以降は与えません |
| 草木灰 | カリウム・カルシウム・リン酸 | 着果後、株の周りにひとつかみずつ | アルカリ性が強いので、使いすぎてはいけません |
| 骨粉 | リン酸・カルシウム | 元肥として穴に混ぜます | 分解が遅いです |
| 落ち葉・草 | 有機物・カリウム | 穴の底に敷き、土をかぶせます | 未熟だと発酵熱が出ます |
| 台所の生ごみ | 総合 | 穴に埋め、土を厚くかぶせます | 動物が掘り返します |

&nbsp;&nbsp;&nbsp;堆肥の山のそばや上にカボチャを植える昔ながらの方法があります。堆肥が腐熟するときに出る養分と熱をそのまま利用するもので、同時に、堆肥の山をつると葉が覆って乾かないようにしてくれます。肥料を別に運ぶ必要もなく、場所も取らないので、一石二鳥です。ただし、未熟な堆肥の上にそのまま植えると、発酵熱とアンモニアで根が傷むため、堆肥を積んでから二、三か月たった山の縁が適しています。

## 6. 播種と定植

### 6-1. 時期

| 作型（韓国） | 播種 | 定植 | 収穫 |
|---|---|---|---|
| 露地直まき | 4月中旬から下旬 | - | 9月上旬から10月中旬 |
| 育苗後定植 | 3月下旬から4月中旬 | 5月上旬から下旬 | 9月上旬から10月中旬 |

> **カボチャは、播種から完熟まで120-150日かかります。韓国では4月に植えてこそ9月に熟します。5月を過ぎて植えると、霜が降りる前に皮が硬くならず、その結果、貯蔵できない中途半端なカボチャだけが残ります。この作物で最も取り返しのつかない失敗は、播種期を逃すことです。**

&nbsp;&nbsp;&nbsp;直まきと育苗のどちらを選ぶかは、地域と条件によります。直まきは簡単で、根が切れないため初期生育が良好ですが、遅霜の危険が過ぎてからでないと植えられず、作期が短くなります。育苗は作期を2週間から3週間早めることができますが、加温が必要です。幸い、カボチャの発芽適温は25-30℃でトウガラシやナスと似ていますが、育苗期間は3-4週間とはるかに短くて済みます。ナスが70-80日であることと比べると、負担が大きく違います。

### 6-2. 育苗

| 項目 | 基準 |
|---|---|
| 種子の処理 | 一晩水に浸けてから、湿らせた布に包み、25-30℃で発芽させます |
| 播種の深さ | 2-3cm |
| 発芽温度 | 25-30℃、3-5日 |
| 育苗温度 | 昼22-28℃、夜15℃以上 |
| 育苗期間 | 3-4週間、本葉3-4枚まで |
| 定植適期の苗 | 本葉3-4枚で、子葉がまだ生きている状態 |
| 順化 | 定植の1週間前から、昼に屋外に出します |

&nbsp;&nbsp;&nbsp;カボチャの苗は、大きく育ててはいけません。本葉が5枚を超えると、根が容器の中で絡まり、植え替えるときの植え傷みがひどくなります。本葉3-4枚で、子葉がまだ黄色くしおれていない状態が最もよい苗で、この状態を過ぎると、かえって小さな苗に劣ります。

&nbsp;&nbsp;&nbsp;カボチャの種は大きくて厚いため、発芽するときに種皮を脱いで出てくるのに苦労します。子葉の上に種皮をかぶったまま出てくることがよくありますが、無理にはがすと子葉が裂けます。水を軽く吹きかけてふやかした後に慎重に取るか、そのままにしておけば、数日のうちにひとりでに外れます。播種前に一晩水に浸ける処理が、この問題を減らします。

### 6-3. 植え付け

| 項目 | 基準 | 備考 |
|---|---|---|
| 畝幅 | 3.5-4m | つるが伸びる空間です |
| 株間 | 60-100cm（狭い土地では30-40cm） | |
| 栽植密度 | 1,000㎡当たり300-400株 | |
| 播種の深さ | 2-3cm | |
| 穴当たりの播種 | 2-3粒 | 発芽の保険です。後で一株だけ残します |
| 間引き | 本葉2-3枚のときに、最も丈夫な一株だけを残します | |
| 植え方 | 植え穴に水をたっぷり注ぎ、水が引いてから植えます | |

&nbsp;&nbsp;&nbsp;畝幅3.5-4mは広く見えますが、放任栽培を前提にした基準です。狭い土地では、つるを一方向に誘引して幅を減らしたり、いっそ上に上げてしまう方法があります。

| 方法 | 内容 | 特徴 |
|---|---|---|
| 放任 | つるを地面にそのまま置きます | 手間がかからず、節から不定根が出て丈夫になります |
| 一方向への誘引 | つるの先を一方向に向けておきます | 幅を減らすことができ、管理が楽です |
| 柵・塀への誘引 | つるを塀や柵に上げます | 畑の面積を使わず、果実が土に触れないため腐りにくくなります |
| 屋根・棚への誘引 | 棚を組んでつるを上げ、果実を吊り下げます | 果実が重いので、ひもで支える必要があります |
| 木を伝わせる | 枯れ木や生け垣に上げます | 資材が要りません |

&nbsp;&nbsp;&nbsp;塀や柵に上げる方法は、狭い土地で特に有利です。畑の水平面積を使わずに日光を受けられ、果実が空中にぶら下がって土に触れないため、下の部分が腐ることが減ります。ただし、カボチャは果実が5-10kgにもなるため、そのままにするとヘタが切れて落ちます。果実の下に布や網で袋を作って支え、そのひもを棚に結んでおきます。

&nbsp;&nbsp;&nbsp;地面に置くときは、果実の下に敷物を敷く必要があります。稲わらをひとつかみ、板切れ、瓦のかけら、乾いた草の山で十分です。土に直接触れた面は、湿気のせいで色がつかず腐りやすく、その部分が貯蔵中に真っ先に傷みます。

## 7. 水管理

| 時期 | 水管理 | 理由 |
|---|---|---|
| 播種-発芽 | 乾かないように保つ | 種が大きくて厚いため、十分な水分が必要です |
| 幼苗期 | 3-4日おき | 根がまだ浅いからです |
| つる伸長期 | 5-7日おき | 根が深くなり、乾燥に耐えます |
| 開花・着果期 | 4-5日おき、たっぷりと | 水が足りないと雌花が落ちます |
| 果実肥大期 | 4-5日おき、たっぷりと | 果実の重さの大部分は、この時期に入った水だからです |
| 成熟期（収穫の20-30日前） | 徐々に減らし、最後は中止 | 貯蔵性が高まります |
| 梅雨の時期 | 灌水を中止し、排水溝を点検 | 過湿が疫病とつる割病を招きます |

### 7-1. 成熟期に水を切る理由

&nbsp;&nbsp;&nbsp;収穫の3-4週間前から水を減らすことが、貯蔵性を大きく左右します。水が入り続けると、果実が水を吸い続けて果肉が柔らかくなり、皮が十分に硬くなりません。逆に水を減らすと、植物は成長を止め、貯蔵物質をためる方向へ切り替わります。デンプンがたまり、皮が木質化し、ヘタが乾きます。これが、貯蔵のきくカボチャになる過程です。

> **秋に雨が多いと、カボチャの貯蔵性が落ちます。人が水をやらなくても、空から降ってくる水は防げません。そのような場合は、畝の排水を最大限確保し、収穫を少し遅らせて、晴れた日が数日続いた後に収穫するのがよいでしょう。**

### 7-2. 水不足と水過多のサイン

| 状態 | 症状 | 説明 |
|---|---|---|
| 水不足の初期 | 日中に葉がだらりと垂れ、夕方に回復します | カボチャの葉は大きくて薄いため、よくこうなります。夕方に回復すれば正常の範囲です |
| 水不足の進行 | 夕方になっても回復せず、雌花が黄色くしぼんで落ちます | この段階で着果が止まります |
| 水不足の深刻化 | 幼果が育つのをやめ、しわしわになります | |
| 過湿の初期 | 下の葉が黄色くなり、根元付近が軟らかくなります | |
| 過湿の進行 | つるの株元が裂けてやにが出て、株がしおれます | つる割病です。回復しません |

&nbsp;&nbsp;&nbsp;カボチャの葉が日中にしおれるのはよくあることで、たいてい正常です。葉が大きくて薄く、蒸散が多いため、根の供給速度を一時的に上回ってしまうのです。日が傾けば回復します。夕方になっても回復しないときが本当の水不足で、そのときにはすでに雌花が落ち始めた後です。

### 7-3. 水が貴重なとき

| 方法 | 原理 | 効果 |
|---|---|---|
| わら・草のマルチング | 表面からの蒸発を防ぎます | 灌水の間隔が延び、果実が土に触れません |
| つるの節への土かぶせ | 節から不定根が出て、吸収面積が増えます | 一本の根だけに頼らなくなります |
| 穴植え | 植える場所をくぼませて、水が集まるようにします | 少ない水が根に集中します |
| 夕方の灌水 | 蒸発による損失が少ないです | |
| 葉の陰の活用 | つると葉が地面を覆うと、その下の土が乾きません | カボチャ自身がつくるマルチングです |

&nbsp;&nbsp;&nbsp;最後の項目が、カボチャの隠れた長所です。つるが伸びて地面を覆うと、その下が日陰になって土が乾かず、雑草も育ちません。この性質から、カボチャを畑の縁に植えて雑草を抑える方法が、昔から使われてきました。トウモロコシの足元にカボチャを一緒に植える配置も同じ原理で、第11節で扱います。
