## 4. 肉類の長期保存調理法
---
### 4-1. 肉脯（ビーフジャーキー）
| 項目 | 内容 |
| :---: | :--- |
| 原理 | 水分活性を0.75以下に低下させ、ほとんどの細菌の増殖を抑制します。 |
| 材料 | 脂肪がほとんどない赤身肉（牛モモ肉、外モモ肉など）、塩（肉の重量の2%） |
| 保管 | 完全に乾燥させた後、密閉して湿気と光が遮断された場所に保管します。 |
| | 保管時は脱酸素剤とともにマイラーバッグに入れて密閉するか、金属容器の使用を推奨します。 |
| | 自家製の肉脯（ジャーキー）は保存料が含まれないため思いのほか寿命が短く、長期保管が目的であればペミカンを製造することが望ましいです。 |

| 順序 | 方法 |
| :---: | :--- |
| 1 | 赤身肉の表面および内部の脂肪と筋を最大限に除去します。（脂肪は乾燥せず、酸敗と悪臭の主な原因になります） |
| 2 | 赤身肉を繊維の流れと垂直の方向に、5mm以下の均一な厚さでスライスします。 |
| 3 | 塩を肉に均一にすり込みます。（醤油、スパイス、砂糖などは選択事項ですが、水分増加により保存性を低下させる可能性があるため最小限に留めます） |
| 4 | 冷蔵状態（4℃以下）で3時間以上寝かせ、塩を芯まで浸透させます。（冷蔵が不可能な場合は、常温の日陰で2時間塩漬けします） |
| 5 | フードドライヤー乾燥：65℃で12時間以上乾燥させます。 |
| | 天日乾燥：薄い布やネットで覆ってほこりや害虫を遮断し、直射日光と通風の良好な場所で3日以上乾燥させます。（夜間は湿気を吸収するため、必ず室内に回収します） |
| | 共通：途中で数回裏返し、均一に乾燥させます。 |
| 6 | 乾燥完了後、食中毒菌（サルモネラ、大腸菌など）を死滅させるため、肉の内部温度が最低でも71℃以上に達するまで軽く炙るか熱処理を行います。 |
| 7 | 完成した肉脯は表面にベタつきや湿気がなく、折り曲げたときに折れずにひび割れが生じる状態になります。 |

### 4-2. ペミカン（Pemmican）
| 項目 | 内容 |
| :---: | :--- |
| 原理 | 完全乾燥させた肉粉と、酸化安定性の高い動物性脂肪の結合により、水分含有量が低く常温での長期保管が可能です。 |
| 材料 | 脂肪がほとんどない赤身肉、牛脂（ヘッド／Tallow）、塩（肉の重量의 2%）、（選択事項）完全乾燥させたフルーツパウダー（全重量の5%以内） |
| 保管 | 密閉状態で湿気と光が遮断された場所に保管します。 |
| | 脂肪が溶けたり変質したりするのを防ぐため、高温の環境を避けます。 |

| 順序 | 肉粉の製造方法 |
| :---: | :--- |
| 1 | 赤身肉の表面および内部의 脂肪と筋を最大限に除去します。（脂肪は乾燥せず、酸敗のリスクが高まります） |
| 2 | 赤身肉をできるだけ薄くスライスします。 |
| 3 | 塩を肉に均一にすり込みます。 |
| 4 | 冷蔵状態（4℃以下）で3時間以上寝かせ、塩を芯まで浸透させます。（冷蔵が不可能な場合は、常温の日陰で2時間塩漬けします） |
| 5 | 塩漬けした肉をフードドライヤー（65℃以上）または天日を利用し、パリッと割れるまで完全に乾燥させます。 |
| 6 | 乾燥完了後、食中毒菌（サルモネラ、大腸菌など）を死滅させるため、肉の内部温度が最低でも71℃以上に達するまでしっかりと焼き上げます。 |
| 7 | 熱を冷ました後、すり鉢で叩くかミキサーで粉砕し、手で簡単に崩れる細かい粉末（肉粉）にします。 |

| 順序 | 牛脂の精製方法 |
| :---: | :--- |
| 1 | 牛の脂肪を細かく刻んで水と一緒に加熱するか、水なしで弱火で炒めて脂を溶かし出します。（豚の脂は酸化安定性が低く長期保管に不利なため、必ず牛の脂肪を使用します） |
| 2 | 水分とタンパク質の残渣をザルや布で濾し、透明な油だけを集めます。 |
| 3 | 透明な油を鍋に入れ弱火で加熱し、油の中の微細な水分が完全に蒸発して気泡が一切発生しなくなるまで煮詰めます。 |

| 順序 | ペミカンの成形方法 |
| :---: | :--- |
| 1 | 準備した肉粉とフルーツパウダーを均一に混合します。（フルーツパウダーは保存性を低下させるため全重量の5%以内に最小限に留め、塩気が足りない場合のみ塩を少量追加します） |
| 2 | 温めて溶かした精製牛脂を肉粉とおよそ1:1の比率（または肉粉がしっとりする程度）で注ぎながら、粘土のような硬さになるまで混ぜ合わせます。（脂が多すぎると流れ出し、少なすぎるとまとまりません） |
| 3 | 脂が固まる前に型に入れ、しっかりと押し固めてバー状またはブロック状に成形します。 |
| 4 | 牛脂が完全に固まって形状が硬くなったら、空気が通らないように個別に密閉します。 |

### 4-3. 燻製肉（Smoked Meat）
| 項目 | 内容 |
| :---: | :--- |
| 原理 | 肉の表面に煙の成分（フェノール、酢酸など）による抗菌・抗酸化の皮膜を形成し、微生物の増殖と脂肪の酸敗を抑制します。 |
| 材料 | 脂肪の少ない赤身肉、塩（肉の重量の4%）、燻製器、温度計、スモーク材（ナラ、果樹などの広葉樹の薪／チップ） |
| 保管 | 乾燥および密閉された状態で、湿気と光が遮断された涼しい場所に保管します。 |
| | 乾燥および密閉されていない燻製肉は、必ず冷蔵保管しなければなりません。 |

| 順序 | 製造方法 |
| :---: | :--- |
| 1 | 塩を肉に均一にすり込みます。 |
| 2 | 冷蔵状態（4℃以下）で48時間以上寝かせ、塩を芯まで浸透させます。（事前の塩漬けがない場合、燻製中に腐敗します） |
| 3 | 塩漬けが終わった肉は、煙が表面に付着しやすくなるよう表面の水分を拭き取り、外側にベタつきのある硬い膜（ペリクル、Pellicle）が形成されるまで十分に乾燥させます。 |
| 4 | 針葉樹（マツなど）はレジンや煤によって苦味と毒性が発生するため、必ずナラや果樹などの広葉樹の薪およびチップを使用して燻製器に火をつけます。 |
| 5 | 目標とする保存期間と調理方式に応じ、下記の燻製方式別の温度基準を遵守して数時間から数週間、煙を燻らせます。（※詳細な温度は下段の表を参照） |
| 6 | 燻製を終えた肉は、煙の成分が内部まで均一に浸透し水分が安定するよう、ほこりや害虫を遮断した涼しく乾燥した場所で一定期間熟成させます。 |
| 7 | 安全性の確認：完成した燻製肉は硬く乾燥していなければなりません。燻製中に発生する低温・低酸素環境はボツリヌス菌が繁殖しやすい条件であるため、設定した塩分濃度・乾燥度・温度の管理に失敗したと判断された場合は、直ちに全量を廃棄しなければなりません。 |

| 燻製方式 | 管理温度 | 燻製時間 | 保存性および特徴 |
| :---: | :---: | :---: | :--- |
| 冷燻法 (Cold Smoking) | 30℃以下 | 数日 ~ 数週間 | 常温の長期保管用。高濃度の塩漬けと完全乾燥が必須であり、熱を加えず煙だけを纏わせて水分を極限まで飛ばす燻製方式です。 |
| 温燻法 (Warm Smoking) | 40 ~ 60℃ | 2 ~ 5時間 | 短期保管用。肉の組織は柔らかくなりますが完全には火が通らないため、後に再加熱調理が必要であり、保存性は相対的に低いです。 |
| 熱燻法 (Hot Smoking) | 65 ~ 90℃ | 数時間 | 即時摂取および短期保管用。乾燥と同時に肉の内部まで完全に火を通す方式（バーベキュー形態）で、風味は良いですが長期保管は不可能です。 |
| 焼燻法 (Roast Smoking) | 90℃以上 | 短時間 | 肉を高温で素早く焼きながら煙の香りだけを纏わせる方式で、保存効果はほとんどありません。 |
