## 4. 肉類の長期保存の調理法
---
### 4-1. ジャーキー
| 項目 | 内容 |
| :---: | :--- |
| 原理 | 水分活性を0.75以下に下げて、大部分の細菌の増殖を抑えます。 |
| 材料 | 脂肪がほとんどない赤身肉(牛のもも肉、しんたまなど)、塩(肉の重さの2%) |
| 保管 | 完全に乾燥させた後に密封し、湿気と光が遮断された場所に保管します。 |
| | 保管時は、脱酸素剤と一緒にマイラーバッグに入れて密封するか、金属容器の使用をお勧めします。 |
| | 自家製のジャーキーは保存料がないので、思ったより寿命が短く、長期保管が目的なら、ペミカンをつくるのがよいです。 |

| 順序 | 方法 |
| :---: | :--- |
| 1 | 赤身肉の表面と内部の脂肪と筋を、できるだけ取り除きます。(脂肪は乾燥せず、酸敗と悪臭の主な原因になります) |
| 2 | 赤身肉を、繊維と逆の方向に5mm以下に均一に切ります。 |
| 3 | 塩を肉に均等にすり込みます。(醤油、香辛料、砂糖などは任意ですが、水分が増えて保存性が下がることがあるので、最小限にします) |
| 4 | 冷蔵状態(4℃以下)で3時間以上寝かせて、塩を中までなじませます。(冷蔵ができない場合は、常温の日陰で2時間塩漬けにします) |
| 5 | 乾燥機での乾燥: 65℃で12時間以上乾燥します。 |
| | 日光乾燥: 薄い布やネットで覆ってほこりと害虫を遮断し、直射日光と風通しのよい場所で3日以上乾燥します。(夜間は湿気を吸収するので、必ず室内に取り込みます) |
| | 共通: 途中で何度かひっくり返して、均一に乾燥させます。 |
| 6 | 乾燥が終わったら、食中毒菌(サルモネラ、大腸菌など)の死滅のため、肉の内部温度が最低71℃以上になるまで、軽く焼くか加熱処理をします。 |
| 7 | 完成したジャーキーは、表面にべたつきや湿気がなく、折り曲げたときに折れずにひび割れが生じなければなりません。 |

### 4-2. ペミカン(Pemmican)
| 項目 | 内容 |
| :---: | :--- |
| 原理 | 完全に乾燥させた肉の粉と、酸化安定性の高い動物性脂肪を組み合わせたもので、水分含有量が低く、常温で長期保管ができます。 |
| 材料 | 脂肪がほとんどない赤身肉、牛脂(Tallow)、塩(肉の重さの2%)、(任意)完全に乾燥させた果物の粉(全体の重さの5%以内) |
| 保管 | 密封した状態で、湿気と光が遮断された場所に保管します。 |
| | 脂肪が溶けたり変質したりしないよう、高温の環境を避けます。 |

| 順序 | 肉の粉の製造方法 |
| :---: | :--- |
| 1 | 赤身肉の表面と内部の脂肪と筋を、できるだけ取り除きます。(脂肪は乾燥せず、酸敗の危険が高くなります) |
| 2 | 赤身肉を、できるだけ薄く切ります。 |
| 3 | 塩を肉に均等にすり込みます。 |
| 4 | 冷蔵状態(4℃以下)で3時間以上寝かせて、塩を中までなじませます。(冷蔵ができない場合は、常温の日陰で2時間塩漬けにします) |
| 5 | 塩漬けにした肉を、乾燥機(65℃以上)や日光を使って、ぱりっと折れるまで完全に乾燥させます。 |
| 6 | 乾燥が終わったら、食中毒菌(サルモネラ、大腸菌など)の死滅のため、肉の内部温度が最低71℃以上になるまで、かりかりに焼きます。 |
| 7 | 熱を冷ましたら、すり鉢でついたりミキサーで挽いたりして、手で簡単に崩れる細かい粉(肉の粉)にします。 |

| 順序 | 牛脂の精製方法 |
| :---: | :--- |
| 1 | 牛脂を細かく切り、水と一緒に加熱するか、水なしで弱火で炒めて、脂を溶かし出します。(豚の脂肪は酸化安定性が低く、長期保管に不利なので、必ず牛脂を使います) |
| 2 | 水とタンパク質のかすを、ざるや布でこして、澄んだ油だけを集めます。 |
| 3 | 澄んだ油を鍋に入れて弱火で加熱し、油の中の微細な水分が完全に蒸発して、泡がまったく出なくなるまで煮ます。 |

| 順序 | ペミカンの成形方法 |
| :---: | :--- |
| 1 | 用意した肉の粉と乾燥果物の粉を均一に混ぜます。(果物の粉は保存性を下げるので、全体の重さの5%以内に最小化し、味が足りないときにだけ塩を少量加えます) |
| 2 | 温かく溶かした精製牛脂を、肉の粉と約1:1の割合(または肉の粉がしっとりする程度)で注ぎながら、粘土のような濃度になるまで混ぜます。(油が多すぎると流れ、少ないとまとまりません) |
| 3 | 油が固まる前に型に入れて、ぎゅっと押し固め、棒状または塊の形に成形します。 |
| 4 | 牛脂が完全に固まって形がしっかりしたら、空気が通らないよう個別に密封します。 |

### 4-3. 燻製肉(Smoked Meat)
| 項目 | 内容 |
| :---: | :--- |
| 原理 | 肉の表面に煙の成分(フェノール、酢酸など)による抗菌・抗酸化の膜をつくり、微生物の増殖と脂肪の酸敗を抑えます。 |
| 材料 | 脂肪の少ない赤身肉、塩(肉の重さの4%)、燻製器、温度計、燻煙材(カシ、果樹などの広葉樹の薪やチップ) |
| 保管 | 乾燥して密封された状態で、湿気と光が遮断された涼しい場所に保管します。 |
| | 乾燥・密封されていない燻製肉は、必ず冷蔵保管しなければなりません。 |

| 順序 | 製造方法 |
| :---: | :--- |
| 1 | 塩を肉に均等にすり込みます。 |
| 2 | 冷蔵状態(4℃以下)で48時間以上寝かせて、塩を中までなじませます。(事前の塩漬けがないと、燻煙中に腐敗します) |
| 3 | 塩漬けが終わった肉は、煙が表面によく吸着するよう、表面の水気を拭き取り、外側にべたつく硬い膜(ペリクル、Pellicle)ができるまで十分に乾燥させます。 |
| 4 | 針葉樹(マツなど)は、樹脂とすすのために苦みと毒性が生じるので、必ずカシや果樹などの広葉樹の薪やチップを使って、燻製器に火をつけます。 |
| 5 | 目標とする保存期間と調理方式に応じて、下の燻煙方式別の温度基準を守り、数時間から数週間、煙を当てます。(※ 詳しい温度は下の表を参照) |
| 6 | 燻煙を終えた肉は、煙の成分が内部まで均一にしみ込み、水分が安定するよう、ほこりと害虫が遮断された涼しく乾燥した場所で、一定期間熟成させます。 |
| 7 | 安全性の確認: 完成した燻製肉は、硬くて乾燥していなければなりません。燻煙中に生じる低温・低酸素の環境は、ボツリヌス菌が繁殖しやすい条件なので、設定した塩分・乾燥度・温度の管理に失敗したと判断したら、ただちに全量を廃棄しなければなりません。 |

| 燻煙方式 | 管理温度 | 燻煙時間 | 保存性と特徴 |
| :---: | :---: | :---: | :--- |
| 冷燻法(Cold Smoking) | 30℃以下 | 数日~数週間 | 常温での長期保管用。高塩分の塩漬けと完全乾燥が必須で、熱を加えず煙だけをつけて水分を極端に飛ばす燻煙方式です。 |
| 温燻法(Warm Smoking) | 40~60℃ | 2~5時間 | 短期保管用。肉の組織は柔らかくなりますが完全には火が通らないため、後で再加熱調理が必要で、保存性は相対的に低くなります。 |
| 熱燻法(Hot Smoking) | 65~90℃ | 数時間 | すぐに食べる用および短期保管用。乾燥と同時に肉の内部まで完全に火を通す方式(バーベキューの形)で、風味はよいですが、長期保管はできません。 |
| 焙燻法(Roast Smoking) | 90℃以上 | 短時間 | 肉を高温で素早く焼きながら、煙の香りだけをつける方式で、保存の効果はほとんどありません。 |
