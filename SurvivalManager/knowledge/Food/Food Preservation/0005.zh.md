## 4. 肉类长期保存烹饪法
---
### 4-1. 肉干
| 项目 | 内容 |
| :---: | :--- |
| 原理 | 将水分活度降低至 0.75 以下，从而抑制绝大多数细菌的滋生。 |
| 材料 | 几乎不含脂肪的纯瘦肉（如牛霖、牛腱子等）、食盐（肉重的 2%） |
| 贮藏 | 完全干燥后进行密封，并存放在避光防潮处。 |
| | 建议将肉干与氧气吸收剂一同放入铝箔避光袋中密封，或使用金属容器贮藏。 |
| | 自制肉干因不含防腐剂，保质期比想象中短。若以长期贮藏为目的，建议制作干肉饼（Pemmican）。 |

| 步骤 | 方法 |
| :---: | :--- |
| 1 | 尽可能彻底地剔除瘦肉表面及内部的脂肪与肌腱。（脂肪无法被干燥，是导致酸败和恶臭的主要原因） |
| 2 | 逆着肉质纹理，将瘦肉均匀切成厚度在 5mm 以下的薄片。 |
| 3 | 将食盐均匀涂抹并揉搓在肉片上。（酱油、香料、糖等为可选调料，但由于会增加水分而降低贮藏性，应尽量少用） |
| 4 | 在冷藏状态（4℃ 以下）下腌制 3 小时以上，使盐分完全渗透入味。（若无法冷藏，可在阴凉处常温腌制 2 小时） |
| 5 | 烘干机干燥：在 65℃ 下持续烘干 12 小时以上。 |
| | 日光干燥：用薄布或网罩覆盖以阻隔灰尘和害虫，置于阳光直射且通风良好处暴晒 3 天以上。（夜间会吸收潮气，必须移至室内） |
| | 共同事项：其中须多次翻面，以确保干燥均匀。 |
| 6 | 干燥完成后，为杀灭食源性致病菌（如沙门氏菌、大肠杆菌等），须进行轻微烘烤或热处理，直至肉内部温度至少达到 71℃ 以上。 |
| 7 | 制作完成的肉干表面应无粘手感或潮气，折弯时不会折断但会出现裂纹。 |

### 4-2. 干肉饼 (Pemmican)
| 项目 | 内容 |
| :---: | :--- |
| 原理 | 将完全干燥的肉粉与高氧化稳定性的动物脂肪相结合，通过极低的水分含量实现常温长期贮藏。 |
| 材料 | 几乎不含脂肪的纯瘦肉、牛脂（Tallow）、食盐（肉重的 2%）、（可选）完全干燥的水果粉（控制在总重量的 5% 以내） |
| 贮藏 | 在密封状态下存放在防潮、避光处。 |
| | 避免存放在高温环境中，以防脂肪融化或变质。 |

| 步骤 | 肉粉制造方法 |
| :---: | :--- |
| 1 | 尽可能彻底地剔除瘦肉表面及内部的脂肪与肌腱。（脂肪无法被干燥，且酸败风险极高） |
| 2 | 将瘦肉切成极薄的片。 |
| 3 | 将食盐均匀涂抹并揉搓在肉片上。 |
| 4 | 在冷藏状态（4℃ 以下）下腌制 3 小时以上，使盐分完全渗透入味。（若无法冷藏，可在阴凉处常温腌制 2 小时） |
| 5 | 将腌制好的肉片利用烘干机（65℃ 以上）或日光完全干燥，直至其脆到一折就断。 |
| 6 | 干燥完成后，为杀灭食源性致病菌（如沙门氏菌、大肠杆菌等），须将肉片彻底烘烤，直至肉内部温度至少达到 71℃ 以上。 |
| 7 | 待热气消散后，用捣碎或用搅拌机打碎，制成用手一捏即碎的均匀细肉粉。 |

| 步骤 | 牛脂精炼方法 |
| :---: | :--- |
| 1 | 将牛脂肪切成碎块，加水一同加热，或不加水用文火慢熬以熔出油脂。（猪脂肪因氧化稳定性低而不利于长期贮藏，故必须使用牛脂） |
| 2 | 用筛网或纱布滤去水分和蛋白质残渣，仅收集澄清的油脂。 |
| 3 | 将澄清的油脂倒入锅中用文火加热，持续熬煮至油脂中的微量水分完全蒸发、表面不再产生任何气泡。 |

| 步骤 | 干肉饼成型方法 |
| :---: | :--- |
| 1 | 将准备好的肉粉与干水果粉混合均匀。（水果粉会降低贮藏性，须控制在总重量的 5% 以内；仅在咸度不足时添加少量食盐） |
| 2 | 将温热熔化的精炼牛脂倒入肉粉中，比例约为 1:1（或至肉粉完全湿润），搅拌均匀至呈现如粘土般的质地。（油脂过多会流动，过少则无法凝聚） |
| 3 | 在油脂凝固前将其装入模具中，用力压实，塑造成块状或条状。 |
| 4 | 待牛脂完全凝固、形态变得坚硬后，进行独立的防气包装密封。 |

### 4-3. 熏肉 (Smoked Meat)
| 项目 | 内容 |
| :---: | :--- |
| 原理 | 在肉类表面形成由烟熏成分（酚类、乙酸等）构成的抗菌、抗氧化保护膜，从而抑制微生物滋生和脂肪酸败。 |
| 材料 | 脂肪含量低的纯瘦肉、食盐（肉重的 4%）、熏肉炉、温度计、烟熏木（橡树、果树等阔叶树木柴/木屑） |
| 贮藏 | 在干燥且密封的状态下，存放在防潮、避光、阴凉处。 |
| | 未经充分干燥及密封的熏肉必须冷藏保存。 |

| 步骤 | 制造方法 |
| :---: | :--- |
| 1 | 将食盐均匀涂抹并揉搓在肉块上。 |
| 2 | 在冷藏状态（4℃ 以下）下腌制 48 小时以上，使盐分完全渗透。若省去前置腌制，肉类在烟熏过程中会发生腐烂。 |
| 3 | 腌制结束的肉块须擦干表面水分，并进行充分干燥，直至表面形成一层微粘且坚硬的皮膜（烟熏皮膜/Pellicle），以便烟雾更好地吸附在表面。 |
| 4 | 针叶树（如松树等）因含有树脂和烟尘，会导致产生苦味和毒性，故必须使用橡树、果树等阔叶树的木柴或木屑在熏肉炉中引火。 |
| 5 | 根据预期的贮藏期限和烹饪方式，严格遵守下表所示的烟熏方式温度标准，进行数小时至数周 Koching 烟熏。（※ 详细温度见下表） |
| 6 | 烟熏结束后的肉块须置于阻隔灰尘和害虫的阴凉干燥处风干熟化一定时间，使烟熏成分充分渗透至内部并使水分稳定。 |
| 7 | 安全性确认：制作完成的熏肉必须质地坚硬且干燥。烟熏过程中产生的低温、低氧环境极易滋生肉肉毒杆菌，一旦判断设定的盐度、干燥度或温度控制未能达标，必须立即全量销毁。 |

| 烟熏方式 | 控制温度 | 烟熏时间 | 贮藏性及特点 |
| :---: | :---: | :---: | :--- |
| 冷熏法 (Cold Smoking) | 30℃ 以下 | 数日 ~ 数周 | 供常温长期贮藏。必须进行高盐腌制和完全干燥，是一种不施加高热、仅靠烟熏引入成分并极限脱水的烟熏方式。 |
| 温熏法 (Warm Smoking) | 40 ~ 60℃ | 2 ~ 5小时 | 供短期贮藏。肉质会变软但未完全熟透，后续需要重新加热烹饪，且贮藏性相对较低。 |
| 热熏法 (Hot Smoking) | 65 ~ 90℃ | 数小时 | 供即食及短期贮藏。在干燥的同时使肉内部完全熟透（类似于烧烤形式），风味良好但无法进行长期贮藏。 |
| 焙熏法 (Roast Smoking) | 90℃ 以上 | 短时间 | 在高温下快速将肉烤熟并仅附带烟熏香气的方式，几乎没有保鲜贮藏效果。 |
