## 4. 肉类长期保藏做法
---
### 4-1. 肉干
| 项目 | 内容 |
| :---: | :--- |
| 原理 | 把水分活度降到0.75以下，抑制大部分细菌繁殖。 |
| 材料 | 几乎不含脂肪的瘦肉（牛臀肉、牛腱子等）、盐（肉重的2%） |
| 储存 | 完全干燥后密封，存放在避开湿气和光线的地方。 |
| | 储存时，与脱氧剂一起放进迈拉袋密封，或使用金属容器。 |
| | 自制肉干没有防腐剂，保质期比想象的短，如果以长期保存为目的，最好做佩米肯。 |

| 顺序 | 方法 |
| :---: | :--- |
| 1 | 尽量去除瘦肉表面和内部的脂肪和筋。（脂肪不会干燥，是酸败和异味的主要原因） |
| 2 | 将瘦肉逆着纹理均匀切成5mm以下。 |
| 3 | 把盐均匀地揉在肉上。（酱油、香料、糖等是可选项，但可能因增加水分而降低保存性，所以尽量减少） |
| 4 | 在冷藏状态（4℃以下）腌3小时以上，使盐渗入内部。（无法冷藏时，在常温阴凉处腌2小时） |
| 5 | 烘干机干燥：在65℃下干燥12小时以上。 |
| | 日晒干燥：用薄布或网盖住，防止灰尘和害虫，在阳光直射、通风良好的地方干燥3天以上。（夜间会吸收湿气，所以一定要收回室内） |
| | 共同：中途多次翻面，使其均匀干燥。 |
| 6 | 干燥完成后，为杀灭食物中毒菌（沙门氏菌、大肠杆菌等），稍微烤一下或做热处理，直到肉的内部温度至少达到71℃以上。 |
| 7 | 做好的肉干表面应无粘手感或湿气，折叠时应出现裂纹而不折断。 |

---
### 4-2. 佩米肯（Pemmican）
| 项目 | 内容 |
| :---: | :--- |
| 原理 | 完全干燥的肉粉与氧化稳定性高的动物脂肪结合，含水量低，可在常温下长期保存。 |
| 材料 | 几乎不含脂肪的瘦肉、牛脂（Tallow）、盐（肉重的2%）、（可选）完全干燥的水果粉（不超过总重的5%） |
| 储存 | 密封后存放在避开湿气和光线的地方。 |
| | 避免高温环境，以免脂肪融化或变质。 |

| 顺序 | 肉粉的制作方法 |
| :---: | :--- |
| 1 | 尽量去除瘦肉表面和内部的脂肪和筋。（脂肪不会干燥，酸败风险高） |
| 2 | 将瘦肉切得尽量薄。 |
| 3 | 把盐均匀地揉在肉上。 |
| 4 | 在冷藏状态（4℃以下）腌3小时以上，使盐渗入内部。（无法冷藏时，在常温阴凉处腌2小时） |
| 5 | 把腌好的肉用烘干机（65℃以上）或日晒完全干燥，直到一折就脆断。 |
| 6 | 干燥完成后，为杀灭食物中毒菌（沙门氏菌、大肠杆菌等），烤透，直到肉的内部温度至少达到71℃以上。 |
| 7 | 热气散去后，用臼捣碎或用搅拌机磨成用手就能轻易捏碎的细粉（肉粉）。 |

| 顺序 | 牛油的熬制方法 |
| :---: | :--- |
| 1 | 把牛脂切成小块，加水加热，或不加水用小火翻炒，熬出油来。（猪脂肪氧化稳定性低，不利于长期保存，所以必须用牛脂） |
| 2 | 用筛子或布滤去水和蛋白质残渣，只收集清油。 |
| 3 | 把清油倒入锅中小火加热，一直煮到油中的微量水分完全蒸发、完全不再产生气泡为止。 |

| 顺序 | 佩米肯的成型方法 |
| :---: | :--- |
| 1 | 把备好的肉粉和干燥水果粉均匀混合。（水果粉会降低保存性，所以尽量控制在总重的5%以内，只有味道不足时才少量加盐） |
| 2 | 把温热融化的熬制牛油按与肉粉约1:1的比例（或倒到肉粉变得湿润的程度）边倒边拌，直到变成黏土般的稠度。（油太多会流淌，太少则捏不成团） |
| 3 | 在油凝固前放进模具用力压实，做成条状或块状。 |
| 4 | 牛油完全凝固、形状变硬后，逐个单独密封，使空气不能进入。 |

### 4-3. 熏肉（Smoked Meat）
| 项目 | 内容 |
| :---: | :--- |
| 原理 | 肉表面形成烟熏成分（酚类、乙酸等）的抗菌、抗氧化膜，抑制微生物繁殖和脂肪酸败。 |
| 材料 | 脂肪少的瘦肉、盐（肉重的4%）、烟熏炉、温度计、烟熏木料（橡木、果树等阔叶木的木柴/木屑） |
| 储存 | 在干燥、密封状态下，存放在避开湿气和光线的阴凉处。 |
| | 没有干燥、密封的熏肉必须冷藏。 |

| 顺序 | 制作方法 |
| :---: | :--- |
| 1 | 把盐均匀地揉在肉上。 |
| 2 | 在冷藏状态（4℃以下）腌48小时以上，使盐渗入内部。（没有事先盐腌，烟熏过程中会腐败） |
| 3 | 腌好的肉擦去表面水分，使烟能很好地附着在表面，并充分干燥，直到外表形成一层黏而硬的膜（Pellicle）。 |
| 4 | 针叶木（松树等）会因树脂和烟灰产生苦味和毒性，所以一定要用橡木、果树等阔叶木的木柴和木屑给烟熏炉生火。 |
| 5 | 根据目标保存期限和烹调方式，遵守下列各烟熏方式的温度标准，用烟熏几小时到几周。（※ 详细温度见下表） |
| 6 | 烟熏完的肉，为使烟熏成分均匀渗入内部、水分稳定，在没有灰尘和害虫的阴凉干燥处熟化一段时间。 |
| 7 | 安全确认：做好的熏肉应该坚硬干燥。烟熏过程中产生的低温低氧环境，是肉毒杆菌容易繁殖的条件，所以一旦判断设定的盐度、干燥度、温度管理失败，必须立即全部丢弃。 |

| 烟熏方式 | 控制温度 | 烟熏时间 | 保存性与特点 |
| :---: | :---: | :---: | :--- |
| 冷熏法（Cold Smoking） | 30℃以下 | 数日~数周 | 用于常温长期保存。高盐盐渍和完全干燥是必需的，不加热、只用烟，把水分极端地排出的烟熏方式。 |
| 温熏法（Warm Smoking） | 40~60℃ | 2~5小时 | 用于短期保存。肉的组织变软但未完全煮熟，之后需要再加热烹调，保存性相对较低。 |
| 热熏法（Hot Smoking） | 65~90℃ | 数小时 | 用于即食和短期保存。同时干燥并把肉内部完全煮熟（烧烤形式），风味好，但不能长期保存。 |
| 烤熏法（Roast Smoking） | 90℃以上 | 短时间 | 在高温下快速烤肉，只附上烟熏香味的方式，几乎没有保存效果。 |
