## 5. 野菜と果物の長期保存の調理法
&nbsp;&nbsp;&nbsp;野菜と果物は水分含有量が高く、長期保存が難しいですが、酸(酢)、糖分(砂糖)、塩分(塩)を活用したり、表面のコーティングを施したりして、腐敗の速度を遅らせられます。

---
### 5-1. コンポート(Compote)
&nbsp;&nbsp;&nbsp;コンポートは、果物を砂糖水で煮てつくる調理方式で、糖分と酸を利用して、短期の保存性と風味を同時に確保する方法です。

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 比較的高い糖分の濃度が浸透圧を高めて微生物の増殖を遅らせ、レモン汁の酸がpHを下げて変質の速度を遅くします。ただし、一般的なコンポートは水分活性が高く、常温での長期保存には適しません。 |
| 材料 | 果物500g、水100ml、きび砂糖(または砂糖)、レモン汁 |
| 保管 | ガラス瓶に密封して、冷蔵保管します。 |
| | 冷蔵の環境でも、数週間以内の消費を前提とします。 |

| 順序 | 方法 |
| :---: | :--- |
| 1 | 果物を鍋に入れ、水ときび砂糖を入れて煮ます。 |
| 2 | 沸騰し始めたら弱火にして、果物が柔らかくなるまで煮詰めます。 |
| 3 | レモン汁を入れて、酸味を加えます。 |
| 4 | きれいなガラス瓶に詰めて密封し、冷蔵保管します。 |

---
### 5-2. ワックスコーティング
&nbsp;&nbsp;&nbsp;卵、柑橘類、リンゴなど表面が硬い食品にワックスを塗ると、水分の損失と酸素の流入を減らして、保存期間を延ばせます。

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 食品の表面に薄い保護膜をつくり、水分の蒸発と酸素の浸透を和らげ、呼吸の速度を遅くして鮮度を保ちます。 |
| 材料 | 食用ワックス(ミツロウ、パラフィンなど) |
| 保管 | 湿気と光が遮断された涼しい場所に保管します。 |
| 注意事項 | 卵やリンゴは、収穫直後に自然の保護膜(ブルーム)ができているので、洗っていない卵には追加のコーティングが必要ありません。 |
| | 保護膜が取れた洗った卵は、ワックスコーティングで保存性を補えます。 |

| 順序 | 方法 |
| :---: | :--- |
| 1 | 乾いた布で、野菜や果物についた土とほこりを払います。(水分がある状態でワックスを塗ると、酵素によって農産物が一瞬で腐ってしまうので、洗うことは禁止です) |
| 2 | 食用ワックスを、ぬるま湯でゆっくり溶かします。 |
| 3 | 野菜や果物の外皮に、均一に薄くワックスを塗ります。(過度なコーティングは果物の呼吸を妨げて、内部の腐敗を招くことがあります) |
| 4 | ワックスが完全に固まったら、湿気と光が遮断された涼しい場所に保管します。 |

---
### 5-3. 湯通ししてから乾燥
&nbsp;&nbsp;&nbsp;ただ乾かすより、湯通しの過程を経たほうが、保存期間が長くなります。

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 野菜内部の腐敗・褐変の酵素を熱で破壊した後、乾燥によって水分活性を0.6以下に下げ、微生物が育てない環境をつくります。 |
| 適した食品 | ニンジン、ブロッコリー、キノコ、ホウレンソウ、リンゴ、バナナなど、大部分の野菜と果物 |
| 保管 | 乾燥した野菜を脱酸素剤と一緒にマイラーバッグに入れて密封し、湿気と光が遮断された涼しい場所に保管します。 |

| 順序 | 方法 |
| :---: | :--- |
| 1 | 野菜を洗って均一な大きさに切り、沸騰したお湯で1-3分間、短く湯通しします。 |
| 2 | 湯通ししたらすぐに冷たい水に浸けて余熱を冷まし、水気を完全に切ります。 |
| 3 | 乾燥機(60℃)や風通しのよい日陰で、ぱりっとするまで完全に乾かします。 |

---
### 5-4. 塩漬け
&nbsp;&nbsp;&nbsp;塩の濃度を極端に高めて保存する方式です。

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 食品内部の水分を浸透圧の現象ですべて抜き取り、微生物の細胞膜を脱水させて死滅(塩分20%以上)させます。 |
| 適した食品 | 白菜、大根、キュウリ、ナス、唐辛子など、水分の多い野菜類 |
| 保管 | 塩漬けの容器を、湿気と光が遮断された涼しい場所に保管します。 |

| 順序 | 方法 |
| :---: | :--- |
| 1 | 野菜を洗って、均一な大きさに切ります。 |
| 2 | ざるを使って、野菜の表面の水気を完全に取り除きます。 |
| 3 | 容器の底に塩を1cm以上敷き、野菜と塩を1:1に近い割合で重ねて積むか、20%以上の濃い塩水に完全に浸かるよう漬けます。 |
| 4 | 容器のふたをして、しっかり密封します。 |
| 5 | 食べるときは、流水で何度も洗い、水に浸けて塩気を抜いてから調理します。 |

---
### 5-5. 乳酸発酵
&nbsp;&nbsp;&nbsp;塩をごく少量(3%)だけ使って、有益な乳酸菌を繁殖させる、代謝による保存法です。

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 乳酸菌が野菜の糖分を食べて「乳酸」をつくり出し、酸性(pH 4.6以下)の環境に変えます。酸性の環境では、腐敗菌と食中毒菌(ボツリヌス菌を含む)が生きられません。 |
| 適した食品 | キャベツ(ザワークラウト)、キュウリ(発酵ピクルス)、大根、キムチ類 |
| 保管 | 発酵容器を、湿気と光が遮断された涼しい場所に保管します。 |

| 順序 | キャベツを使ったザワークラウトの調理法 |
| :---: | :--- |
| 1 | キャベツなどを細い千切りにして、全体の重さの3%にあたる塩を入れて和えます。 |
| 2 | 野菜から汁がにじみ出るまでぎゅっと押した後、野菜が汁に完全に浸かるよう、重しで押さえます。(酸素の遮断が要です) |
| 3 | 室温(20℃)でガスを抜きながら数日間発酵させた後、涼しい場所に保管します。 |

| 順序 | キムジャン(キムチ漬け)の方法 |
| :---: | :--- |
| 1 | 株ごとのキムチ用の丸ごとの白菜: 茎の部分に粗塩を層ごとにふりかけ、室温(20℃)を基準に8時間、12%の塩水で塩漬けにします。その後、白菜の白い茎の部分を曲げたときに、折れずに柔らかくしなるか確認します。 |
| | カット白菜のキムチ用の白菜: 白菜をひと口大に切って塩を均等にふりかけて混ぜ、2時間しんなりさせます。その後、白菜から水が少しにじみ出ているか確認します。 |
| | カクテキ(角切り大根のキムチ)用の大根: 大根をさいの目に切った後、塩と砂糖を一緒にふりかけて、1時間しんなりさせます。その後、大根が少し柔らかくなって、底に大根の汁がたまっているか確認します。 |
| 2 | 塩漬けにした野菜を、冷たい水で2回きれいにすすいで、塩気と不純物を洗い流します。 |
| 3 | すすいだ野菜をざるに1時間のせておき、自然に水気が下へ抜けるようにします。(手で押したりねじって絞ったりすると、細胞壁が壊れて、キムチがシャキシャキせず、むれたにおいがすることがあります) |
| 4 | もち米粉または小麦粉を水で煮て、糊(でんぷん)をつくります。糊は乳酸菌の初期の餌になって発酵を促し、薬味が野菜によくつくようにします。 |
| 5 | 糊に粉唐辛子、ニンニク、ショウガ、塩辛(または魚醤)、ネギなどを混ぜてキムチの薬味をつくり、塩漬けにした野菜と一緒に和えます。 |
| 6 | 発酵容器にぎゅっと押し込んで空気を抜いた後、白菜の外葉をかぶせるか、衛生的なビニールを密着させて、酸素を遮断します。 |
| 7 | 室温(20℃)で1日ほど置き、ガスがぷくぷくと出始めたら、すぐに冷蔵庫(0-5℃)へ移して、数日から数週間、低温で熟成させます。(停電で冷蔵庫が使えない場合は、地中や最も涼しい地下に埋めて、常温にさらされる時間を最小化します) |
