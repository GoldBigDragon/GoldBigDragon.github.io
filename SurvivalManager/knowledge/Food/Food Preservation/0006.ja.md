## 5. 野菜および果物の長期保存調理法
&nbsp;&nbsp;&nbsp;野菜や果物は水分含有量が高いため長期保存が難解ですが、酸（酢）、糖分（砂糖）、塩分（塩）を活用するか、表面をコーティングすることで腐敗の速度を遅らせることができます。

---
### 5-1. コンポート (Compote)
&nbsp;&nbsp;&nbsp;コンポートは果物を砂糖水で煮詰めて作る調理方式であり、糖分と酸を利用して短期的な保存性と風味を同時に確保する方法です。

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 比較的高い糖度（糖分濃度）が浸透圧を高めて微生物の増殖を遅らせ、レモン汁の酸がpHを低下させて変質速度を遅らせます。ただし、一般的なコンポートは水分活性が高いため、常温での長期保存には適していません。 |
| 材料 | 果物 500g、水 100ml、粗糖（または砂糖）、レモン汁 |
| 保管 | ガラス瓶に密閉して冷蔵保管します。 |
| | 冷蔵環境であっても、数週間以内での消費を前提とします。 |

| 順序 | 方法 |
| :---: | :--- |
| 1 | 果物を鍋に入れ、水と粗糖を加えて加熱します。 |
| 2 | 沸騰し始めたら弱火に落とし、果物が柔らかくなるまで煮詰めます。 |
| 3 | レモン汁を加えて酸味を足します。 |
| 4 | 清潔なガラス瓶に詰め、密閉した後に冷蔵保管します。 |

---
### 5-2. ワックスコーティング
&nbsp;&nbsp;&nbsp;卵、柑橘類、リンゴなど、表面が硬い食品にワックスを塗ることで、水分の損失と酸素の流入を減らし、貯蔵寿命を延長することができます。

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 食品の表面に薄い保護膜を形成して水分の蒸発と酸素の浸透を緩和し、呼吸速度を遅らせることで鮮度を維持します。 |
| 材料 | 食用ワックス（ビーズワックス、パラフィンなど） |
| 保管 | 湿気と光が遮断された涼しい場所に保管します。 |
| 注意事項 | 卵やリンゴは収穫直後に自然の保護膜（ブルーム）が形成されているため、洗浄していない卵には追加のコーティングは不要です。 |
| | 保護膜が除去された洗浄卵は、ワックスコーティングを行うことで貯蔵性を補完できます。 |

| 順序 | 方法 |
| :---: | :--- |
| 1 | 乾いた布で野菜や果物に付着した土やほこりを払い落とします。（水分がある状態でワックスを塗ると、酵素によって農産物が一瞬にして腐敗するため、洗浄は禁止します） |
| 2 | 食用ワックスをぬるま湯でゆっくりと溶かします。 |
| 3 | 野菜や果物の外皮に、均一かつ薄くワックスを塗布します。（過度なコーティングは果物の呼吸を妨げ、内部の腐敗を引き起こす可能性があります） |
| 4 | ワックスが完全に固まったら、湿気と光が遮断された涼しい場所に保管します。 |

---
### 5-3. ブランチング（湯通し）後の乾燥
&nbsp;&nbsp;&nbsp;単に乾燥させるよりも、ブランチング（湯通し）の工程を経ることで保存期間がより長くなります。

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 野菜内部の腐敗・褐変酵素を熱で破壊した後、乾燥によって水分活性を0.6以下に低下させ、微生物が繁殖できない環境を作ります。 |
| 適した食品 | ニンジン、ブロッコリー、キノコ、ホウレンソウ、リンゴ、バナナなど、ほとんどの野菜および果物 |
| 保管 | 乾燥させた野菜を脱酸素剤とともにマイラーバッグに入れて密閉し、湿気と光が遮断された涼しい場所に保管します。 |

| 順序 | 方法 |
| :---: | :--- |
| 1 | 野菜を洗って均一な大きさに切り、沸騰したお湯で1～3分間、短時間ブランチング（湯通し）します。 |
| 2 | ブランチング後すぐに冷水に浸して余熱を取り、水気を完全に切ります。 |
| 3 | フードドライヤー（60℃）または通風の良好な日陰で、パリパリになるまで完全に乾燥させます。 |

---
### 5-4. 塩蔵（塩漬け）
&nbsp;&nbsp;&nbsp;塩分濃度を極限まで高めて保存する方式です。

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 食品内部の水分を浸透圧現象によってすべて脱水させ、微生物の細胞膜を脱水させることで死滅（塩分濃度20%以上）させます。 |
| 適した食品 | 白菜、大根、キュウリ、ナス、唐辛子など、水分の多い野菜類 |
| 保管 | 塩蔵容器を湿気と光が遮断された涼しい場所に保管します。 |

| 順序 | 方法 |
| :---: | :--- |
| 1 | 野菜を洗って均一な大きさに切りそろえます。 |
| 2 | ザル（平ザル）を使用し、野菜表面の水分を完全に除去します。 |
| 3 | 容器の底に塩を1cm以上敷き詰め、野菜と塩を1:1に近い比率で交互に積み重ねるか、20%以上の濃い塩水に完全に浸かるように漬けます。 |
| 4 | 容器の蓋を閉めてしっかりと密閉します。 |
| 5 | 摂取する際は、流水で数回洗い、水に浸して塩抜きをしてから調理します。 |

---
### 5-5. 乳酸発酵
&nbsp;&nbsp;&nbsp;塩を少量（3%）だけ使用し、有益な乳酸菌を繁殖させる代謝的な保存法です。

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 乳酸菌が野菜の糖分を分解して「乳酸」を作り出し、酸性（pH4.6以下）の環境へと変化させます。酸性環境では、腐敗菌や食中毒菌（ボツリヌス菌を含む）は生存できません。 |
| 適した食品 | キャベツ（ザワークラウト）、キュウリ（発酵ピクルス）、大根、キムチ類 |
| 保管 | 発酵容器を湿気と光が遮断された涼しい場所に保管します。 |

| 順序 | キャベツを用いたザワークラウトの調理法 |
| :---: | :--- |
| 1 | キャベツなどを細かく千切りにし、全体の重量の3%に相当する塩を加えて和えます。 |
| 2 | 野菜から水分（汁）がにじみ出るまでしっかりと揉み込んだ後、野菜が水分に完全に浸かるように重石で押さえます。（酸素の遮断が核心です） |
| 3 | 室温（20℃）でガス抜きを行いながら数日間発酵させた後、涼しい場所に保管します。 |

| 順序 | キムジャン（キムチ漬け）法 |
| :---: | :--- |
| 1 | 株漬け（ポギキムチ）用の丸ごと白菜：茎の部分に粗塩を交互に振りかけ、室温（20℃）基準で8時間、12%の塩水で塩蔵します。その後、白菜の白い茎の部分を曲げたときに折れず、しなやかに曲がるか確認します。 |
| | 刻みキムチ（マッキムチ）用の白菜：白菜を一口大に切り、塩を均一に振って混ぜ合わせ、2時間おいてしんなりさせます。その後、白菜から水分がひたひたに出ているか確認します。 |
| | カクテキ用の大根：大根をサイコロ状に切った後、塩と砂糖を一緒に振りかけ、1時間おいてしんなりさせます。その後、大根が少し柔らかくなり、底に大根の汁が溜まっているか確認します。 |
| 2 | 漬かった野菜を冷水で2回きれいにすすぎ、塩分と不純物を洗い流します。 |
| 3 | すすいだ野菜をザル（水切りかご）に1時間上げておき、自然に水気が下に抜けるようにします。（手で押さえたり絞ったりすると細胞壁が破壊され、キムチのシャキシャキ感が失われ、青臭さの原因になります） |
| 4 | もち粉や小麦粉を水で煮て、糊（プルグク／澱粉糊）を作ります。糊は乳酸菌の初期の栄養源となり発酵を促進させ、ヤンニョム（合わせ調味料）が野菜によく絡むようにします。 |
| 5 | 糊に粉唐辛子、ニンニク、ショウガ、塩辛（または魚醤）、ネギなどを混ぜ合わせてキムチのヤンニョムを作った後、漬けた野菜と一緒に和えます。 |
| 6 | 発酵容器に隙間なく押し込んで詰め、空気を抜いた後、外葉（ウゴジ）で覆うか衛生ビニールを密着させて酸素を遮断します。 |
| 7 | 室温（20℃）に1日ほど置き、ガスがプツプツと発生し始めたら、直ちに冷蔵庫（0～5℃）に移して数日から数週間、低温熟成させます。（停電により冷蔵庫が使用できない場合は、地中や最も涼しい地下に埋めて常温への露出を最小限に抑えます） |
