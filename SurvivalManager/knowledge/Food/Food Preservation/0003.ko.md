## 2. 식품 보관 방법
---
### 2-1. 질소 치환 보관 (Nitrogen Flushing)
&nbsp;&nbsp;&nbsp;산소 흡수제 대신 질소를 주입하여 포장 내부의 산소를 치환하는 방법입니다.

| 항목 | 내용 |
| :---: | :--- |
| 원리 | 불활성 기체인 질소는 식품의 산화를 막고, 해충이 호흡할 수 있는 산소를 제거하여 해충 발생을 억제합니다. |
| 장점 | 산소 흡수제보다 빠르고 완벽하게 산소를 제거합니다. |
| | 재충전이 가능한 환경에서 반복 개봉이 필요한 식량(예: 분유, 커피)에 유리합니다. |
| 적합 식품 | 곡물, 분유, 커피, 견과류 등 산패에 민감한 식품에 효과적입니다. |
| 주의사항 | 질소 치환 포장 이후 안전을 위해 산소 흡수제를 병용 할 수는 있으나, 질소 치환이 완벽하다면 산소 흡수제를 중복 사용할 필요는 없습니다. |

---
### 2-2. 석회(생석회) 방습 저장
&nbsp;&nbsp;&nbsp;밀폐 용기 내부에 생석회(산화칼슘, CaO)를 배치하여 습기를 흡수하는 방법입니다.

| 항목 | 내용 |
| :---: | :--- |
| 원리 | 생석회가 주변의 수분을 흡수하여 수산화칼슘(Ca(OH)2)으로 변하면서 용기 내부의 습도를 극단적으로 낮춥니다. |
| 적합 식품 | 쌀, 콩, 건조 채소 등 습기에 취약한 식품의 곰팡이 및 미생물 번식 예방에 효과적입니다. |
| 주의사항 | 생석회는 물과 반응 시 발열하므로 취급에 주의해야 합니다. |
| | 과도한 건조는 곡물 균열 및 지방 산화를 가속하므로, 소량 사용 원칙을 준수하고 장기 사용 시 주기적 교체가 필요합니다. |
| | 식품과 직접 접촉해서는 안되며, 반드시 별도의 통기성 주머니나 용기에 담아 밀폐된 식품 용기 하단에 배치해야 합니다. |

---
### 2-3. 계층 포장 (Layered Packaging)
&nbsp;&nbsp;&nbsp;설치류나 해충의 침입으로부터 식량을 보호하기 위한 3단계 포장 전략입니다.

| 포장 | 내용 |
| :---: | :--- |
| 내부 포장 | 산소/습기 차단 | 마일라 백과 산소 흡수제를 사용하여 식품 자체의 품질을 보존합니다. |
| 중간 포장 | 물리적 방어 | 금속 캔, 두꺼운 플라스틱 통 등 단단한 용기에 마일라 백을 넣어 물리적인 충격과 설치류의 이빨로부터 보호합니다. |
| 외부 포장 | 위치 은닉 및 냄새 차단 | 식량을 보관하는 장소를 은닉하고, 설치류의 후각을 자극하지 않도록 냄새를 차단하는 조치를 취합니다. |

---
### 2-4. 지하 저장
&nbsp;&nbsp;&nbsp;땅속 깊은 곳은 연중 안정적인 온도(약 4-10°C)와 높은 습도(85-95%)를 유지하여, 뿌리채소와 구근류를 신선하게 보관할 수 있습니다.

| 저장 원칙 | 내용 |
| :---: | :--- |
| 분리 저장 | 감자, 고구마, 양파 등은 서로 다른 가스를 방출하므로 반드시 분리 저장해야 합니다. 특히, 양파는 감자의 싹을 틔우는 에틸렌 가스를 방출하므로 함께 보관해서는 안 됩니다. |
| 통풍 관리 | 신선한 공기가 유입되고 정체된 공기가 배출될 수 있도록 통풍 방향을 관리하는 것이 중요합니다. |
| 작물 관리 | 고습 환경에서는 곰팡이 및 세균이 증식하기 쉬우므로, 표면이 손상된 작물은 즉시 제거해야 합니다. |
| 온도 관리 | 고구마는 10°C 이하의 서늘한 지하에 보관하면 냉해로 부패하므로 감자와 함께 보관할 때 온도 관리에 주의해야 합니다. (고구마 보관 최적 온도: 12~15°C) |

### 2-5. 팟 인 팟(Pot in Pot)
![image](./media/Pot_in_Pot.png)  
&nbsp;&nbsp;&nbsp;팟 인 팟은 기화열을 이용해 식품 보관 온도를 낮추는 전통적인 식품 보관 방법입니다.

| 항목 | 내용 |
| :---: | :--- |
| 원리 | 두 항아리 사이 모래와, 그 위를 덮고 있는 천 속의 수분이 증발하면서 기화열을 빼앗아 내부 온도를 낮춥니다. |
| 재료 | 큰 항아리, 작은 항아리, 모래, 물, 천 |
| 보관 | 물이 잘 증발 되도록 통풍이 잘 되는 곳에 보관합니다. |
| 활용 | 채소, 과일, 유제품(단기 임시 보관) 등을 보관하여 저장 수명을 연장하는 데 사용됩니다. |
| 주의사항 | 습도가 낮고 대기가 건조한 지역에서만 작동합니다. |
| | 한국의 여름처럼 습도가 80%를 넘는 재난 상황에서는 물이 증발하지 않아 오히려 곰팡이만 피게 됩니다. |
| | 고온 다습한 환경에서는 **5-4. 염장** 혹은 **5-5. 젖산 발효** 항목을 참고하세요. |

| 제작 순서 | 제작 방법 |
| :---: | :--- |
| 1 | 큰 항아리 바닥에 모래를 5cm 채워 넣습니다. |
| 2 | 작은 항아리를 큰 항아리 중앙에 놓습니다. |
| 3 | 작은 항아리와 큰 항아리 사이 빈 공간을 모래로 가득 채웁니다. |
| 4 | 큰 항아리와 작은 항아리 사이로 물을 부어 모래를 적십니다. |
| 5 | 작은 항아리에 음식물을 담아 뚜껑을 닫습니다. |
| 6 | 큰 항아리 입구만한 천을 가져와 큰 항아리를 덮고, 천 위로 물을 뿌립니다. |

### 2-6. 칸기나(Kangina)
![image](./media/Kangina.png)  
&nbsp;&nbsp;&nbsp;칸기나는 아프가니스탄 북부 지역에서 포도를 신선하게 보관하기 위해 사용해 온 전통적인 진흙 저장 기술로, '보물'이라는 뜻을 가지고 있습니다.

| 항목 | 내용 |
| :---: | :--- |
| 원리 | 진흙 장벽이 외부 공기, 습기, 미생물로부터 포도를 보호하여 신선도를 유지합니다. |
| 재료 | 흠집 없는 포도(껍질이 두꺼운 품종 위주로 줄기째 수확), 진흙과 짚을 섞어 햇볕에 구운 둥근 점토 그릇 2개, 종이, 진흙 |
| 보관 | 직사광선이 들지 않는 서늘하고 그늘진 곳이나 지하실 혹은 땅에 묻어 보관합니다. |
| 주의사항 | 아프가니스탄의 건조 기후와 점토 특성에 최적화된 기술입니다. |
| | 일반 진흙과 짚으로 야매 제조 시, 내부 습도 조절 실패로 포도가 썩어버릴 확률이 높습니다. |
| | 고온 다습한 환경에서는 **5-4. 염장** 혹은 **5-5. 젖산 발효** 항목을 참고하세요. |

| 제작 순서 | 제작 방법 |
| :---: | :--- |
| 1 | 둥근 점토 그릇 위에 종이로 감싼 포도를 넣습니다. |
| 2 | 포도가 담긴 점토 그릇 위에 다른 점토 그릇을 엎어서 포도를 덮습니다. |
| 3 | 두 점토 그릇 사이 틈을 진흙으로 막아 밀봉합니다. |
