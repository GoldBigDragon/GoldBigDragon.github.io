## 5. 蔬菜及水果长期保存烹饪法
&nbsp;&nbsp;&nbsp;蔬菜和水果由于水分含量高，长期保存较为困难。但可以通过利用酸（醋）、糖（白糖）、盐（食盐）或表面涂层来延缓腐烂速度。

---
### 5-1. 蜜饯 (Compote)
&nbsp;&nbsp;&nbsp;蜜饯是将水果放入糖水中熬煮的烹饪方式，利用糖分和酸在确保短期贮藏性的同时保留风味。

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 相对较高的糖分浓度可提高渗透压以延缓微生物滋生，柠檬汁的酸度可降低 pH 值以减缓变质速度。但普通蜜饯的水分活度较高，不适合常温长期保存。 |
| 材料 | 水果 500g、水 100ml、原糖（或白糖）、柠檬汁 |
| 贮藏 | 放入玻璃瓶中密封并冷藏。 |
| | 以在冷藏环境下数周内消耗完毕为前提。 |

| 步骤 | 方法 |
| :---: | :--- |
| 1 | 将水果放入锅中，加入水和原糖后煮沸。 |
| 2 | 煮沸后转小火，熬煮至水果变软。 |
| 3 | 加入柠檬汁以增加酸度。 |
| 4 | 装入干净的玻璃瓶中，密封后冷藏保存。 |

---
### 5-2. 打蜡涂层
&nbsp;&nbsp;&nbsp;在鸡蛋、柑橘、苹果等表面坚硬的食品上涂抹蜡，可减少水分流失 and 氧气侵入，从而延长贮藏寿命。

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 在食品表面形成一层薄薄的保护膜，以缓解水分蒸发 and 氧气渗透，并通过减缓呼吸速度来保持新鲜度。 |
| 材料 | 食用蜡（蜂蜡、石蜡等） |
| 贮藏 | 存放在避光防潮的阴凉处。 |
| 注意事项 | 鸡蛋或苹果在采收后马上会形成天然保护膜（果粉），因此未经清洗的鸡蛋不需要进行额外涂层。 |
| | 保护膜已被破坏的洗净鸡蛋，可以通过打蜡涂层来弥补贮藏性。 |

| 步骤 | 方法 |
| :---: | :--- |
| 1 | 用干布擦去蔬菜及水果上附着的泥土 and 灰尘。（在有水分的状态下打蜡，农产品会在酶的作用下瞬间腐烂，因此严禁清洗） |
| 2 | 用温水将食用蜡缓缓熔化。 |
| 3 | 在蔬菜及水果的外皮上均匀涂抹一层薄蜡。（过度涂层会阻碍水果呼吸，从而导致内部腐烂） |
| 4 | 待蜡完全凝固后，存放在避光防潮的阴凉处。 |

---
### 5-3. 焯水后干燥
&nbsp;&nbsp;&nbsp;相比单纯晾干，经过焯水工序处理可以获得更长的保存期限。

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 用热量破坏蔬菜内部的腐烂 and 褐变酶，随后通过干燥将水分活度降低至 0.6 以下，创造一个微生物无法生长的环境。 |
| 适用食品 | 胡萝卜、西兰花、蘑菇、菠菜、苹果、香蕉等绝大多数蔬菜及水果 |
| 贮藏 | 将干燥后的蔬菜与氧气吸收剂一同放入铝箔避光袋中密封，存放在避光防潮的阴凉处。 |

| 步骤 | 方法 |
| :---: | :--- |
| 1 | 将蔬菜洗净并切成均匀大小，放入沸水中短时间焯水 1-3 分钟。 |
| 2 | 焯水后立即浸入冷水中冷却余热，并彻底沥干水分。 |
| 3 | 利用烘干机（60℃）或在通风良好的阴凉处完全晾干，直至质地酥脆。 |

---
### 5-4. 盐腌
&nbsp;&nbsp;&nbsp;通过极限提高盐分浓度来进行保存的方式。

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 通过渗透压现象将食品内部的水分完全排出，并使微生物的细胞膜脱水从而将其杀灭（盐度在 20% 以上）。 |
| 适用食品 | 白菜、萝卜、黄瓜、茄子、辣椒等水分较多的蔬菜类 |
| 贮藏 | 将盐腌容器存放在避光防潮的阴凉处。 |

| 步骤 | 方法 |
| :---: | :--- |
| 1 | 将蔬菜洗净并切成均匀的大小。 |
| 2 | 利用笊篱彻底去除蔬菜表面的水分。 |
| 3 | 在容器底部铺上 1cm 以上的食盐，将蔬菜与食盐以接近 1:1 的比例交替层层堆叠，或者将其完全浸没在 20% 以上的浓盐水中。 |
| 4 | 盖上容器盖并严格密封。 |
| 5 | 食用时，用流动的水清洗数次并浸泡在水中以去除盐分，随后进行烹饪。 |

---
### 5-5. 乳酸发酵
&nbsp;&nbsp;&nbsp;仅使用少量盐（3%）来繁殖有益的乳酸菌，属于一种代谢保存法。

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 乳酸菌摄取蔬菜中的糖分并产生“乳酸”，从而将环境转变为酸性（pH 4.6 以下）。在酸性环境中，腐败菌 and 食源性致病菌（包括肉毒杆菌）无法生存。 |
| 适用食品 | 圆白菜（酸菜/Sauerkraut）、黄瓜（发酵酸黄瓜）、萝卜、泡菜类 |
| 贮藏 | 将发酵容器存放在避光防潮的阴凉处。 |

| 步骤 | 利用圆白菜制作酸菜的烹饪法 |
| :---: | :--- |
| 1 | 将圆白菜等切成细丝，加入相当于总重量 3% 的食盐并拌匀。 |
| 2 | 用力压实直至蔬菜渗出汁液，随后用压菜石压住，使蔬菜完全浸没在汁液中。（隔绝氧气是核心） |
| 3 | 在室温（20℃）下定期排气并发酵数日，随后存放在阴凉处。 |

| 步骤 | 辣白菜及泡菜腌制法 |
| :---: | :--- |
| 1 | 整颗泡菜用白菜：在菜帮部分层层撒上粗盐，以室温（20℃）为准，在 12% 的盐水中腌制 8 小时。随后确认白菜帮白色部分弯曲时是否不会折断且柔软酥韧。 |
| | 切块泡菜用白菜：将白菜切成一口大小，均匀撒盐搅拌，腌制 2 小时使其变软。随后确认白菜是否渗出适量水分。 |
| | 辣萝卜块用萝卜：将萝卜切成方块后，同时撒上食盐 and 白糖，腌制 1 小时使其变软。随后确认萝卜是否稍微变软且底部积聚萝卜汁。 |
| 2 | 将腌制好的蔬菜用冷水彻底冲洗 2 次，洗净盐分 and 杂质。 |
| 3 | 将冲洗后的蔬菜放在笊篱（竹筐）上静置 1 小时，使其水分自然下滴。（若用手挤压或扭拧，会破坏细胞壁，导致泡菜口感不脆且产生异味） |
| 4 | 将糯米粉或面粉加水煮沸，制成糊状（淀粉浆糊）。糊浆可作为乳酸菌的初期养分以促进发酵，并能帮助酱料很好地吸附在蔬菜上。 |
| 5 | 在糊浆中加入辣椒粉、大蒜、生姜、虾酱/鱼露、葱等混合制成泡菜酱料，随后与腌制好的蔬菜一同拌匀。 |
| 6 | 将其用力压实装入发酵容器中以排出空气，随后盖上干菜叶或紧贴卫生塑料薄膜以隔绝氧气。 |
| 7 | 在室温（20℃）下静置一天左右，一旦开始冒气泡，必须立即移至冰箱（0-5℃）中，在低温下熟化数天至数周。（若因停电无法使用冰箱，应将其埋入土中或最阴凉的地下，尽可能减少常温暴露） |
