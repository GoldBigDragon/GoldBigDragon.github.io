## 5. 蔬菜和水果长期保藏做法
&nbsp;&nbsp;&nbsp;蔬菜和水果含水量高，长期保藏较为棘手，但可以利用酸（醋）、糖分（砂糖）、盐分（食盐），或通过表面涂层来延缓腐败速度。

---
### 5-1. 糖煮水果（Compote）
&nbsp;&nbsp;&nbsp;糖煮水果是把水果放进糖水里煮制的烹调方式，借助糖分和酸，同时获得短期保存性和风味。

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 相对较高的糖浓度提高渗透压，延缓微生物繁殖，柠檬汁的酸降低pH，减慢变质速度。但一般的糖煮水果水分活度高，不适合常温长期保藏。 |
| 材料 | 水果500g、水100ml、原糖（或砂糖）、柠檬汁 |
| 储存 | 密封在玻璃罐中冷藏。 |
| | 即使在冷藏环境下，也以数周内食用为前提。 |

| 顺序 | 方法 |
| :---: | :--- |
| 1 | 把水果放进锅里，加水和原糖后煮沸。 |
| 2 | 开始沸腾后转小火，煮到水果变软。 |
| 3 | 加入柠檬汁增加酸味。 |
| 4 | 装进干净的玻璃罐中密封后冷藏。 |

---
### 5-2. 蜡涂层
&nbsp;&nbsp;&nbsp;在鸡蛋、柑橘、苹果等表面坚硬的食品上涂蜡，可以减少水分流失和氧气进入，延长保质期。

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 在食品表面形成一层薄薄的保护膜，减缓水分蒸发和氧气渗透，并减慢呼吸速度，保持新鲜。 |
| 材料 | 食用蜡（蜂蜡、石蜡等） |
| 储存 | 存放在避开湿气和光线的阴凉处。 |
| 注意事项 | 鸡蛋和苹果在刚采收后就形成了天然保护膜（果粉），所以未清洗的鸡蛋不需要额外涂层。 |
| | 保护膜已被去除的清洗过的鸡蛋，可以通过涂蜡来弥补保存性。 |

| 顺序 | 方法 |
| :---: | :--- |
| 1 | 用干布掸去蔬菜和水果上的泥土和灰尘。（带着水分涂蜡的话，农产品会被酶瞬间腐烂，所以禁止清洗） |
| 2 | 用温水慢慢融化食用蜡。 |
| 3 | 在蔬菜和水果的外皮上均匀、薄薄地涂一层蜡。（涂层过度会妨碍水果呼吸，引起内部腐烂） |
| 4 | 蜡完全凝固后，存放在避开湿气和光线的阴凉处。 |

---
### 5-3. 焯水后干燥
&nbsp;&nbsp;&nbsp;比起单纯晾干，经过焯水的过程，保存期限会更长。

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 用热破坏蔬菜内部的腐败、褐变酶，然后通过干燥把水分活度降到0.6以下，创造微生物无法生长的环境。 |
| 适合的食品 | 胡萝卜、西兰花、蘑菇、菠菜、苹果、香蕉等大部分蔬菜和水果 |
| 储存 | 把干燥后的蔬菜与脱氧剂一起放进迈拉袋密封，存放在避开湿气和光线的阴凉处。 |

| 顺序 | 方法 |
| :---: | :--- |
| 1 | 把蔬菜洗净，切成均匀的大小，在沸水中短暂焯1-3分钟。 |
| 2 | 焯完立即浸入冷水中降去余热，并彻底沥干水分。 |
| 3 | 用烘干机（60℃）或通风良好的阴凉处完全晾干，直到变脆。 |

---
### 5-4. 盐渍
&nbsp;&nbsp;&nbsp;是把盐浓度提高到极端来保藏的方式。

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 通过渗透压使食品内部的水分全部排出，并使微生物的细胞膜脱水而死亡（盐度20%以上）。 |
| 适合的食品 | 大白菜、萝卜、黄瓜、茄子、辣椒等含水量多的蔬菜类 |
| 储存 | 把盐渍容器存放在避开湿气和光线的阴凉处。 |

| 顺序 | 方法 |
| :---: | :--- |
| 1 | 把蔬菜洗净，切成均匀的大小。 |
| 2 | 用竹筛把蔬菜表面的水分彻底去除。 |
| 3 | 在容器底部铺1cm以上的盐，把蔬菜和盐按接近1:1的比例一层层叠放，或浸入20%以上的浓盐水中，使之完全淹没。 |
| 4 | 盖上容器盖子，紧紧密封。 |
| 5 | 食用时，用流水冲洗几遍，并泡水去除盐分后再烹调。 |

---
### 5-5. 乳酸发酵
&nbsp;&nbsp;&nbsp;是只用少量盐（3%）让有益的乳酸菌繁殖的代谢型保藏方法。

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 乳酸菌吃掉蔬菜中的糖分，产生“乳酸”，使环境变成酸性（pH 4.6以下）。在酸性环境中，腐败菌和食物中毒菌（包括肉毒杆菌）无法生存。 |
| 适合的食品 | 卷心菜（德式酸菜）、黄瓜（发酵泡菜）、萝卜、泡菜类 |
| 储存 | 把发酵容器存放在避开湿气和光线的阴凉处。 |

| 顺序 | 使用卷心菜的德式酸菜做法 |
| :---: | :--- |
| 1 | 把卷心菜等切成细丝，加入相当于总重3%的盐拌匀。 |
| 2 | 用力按压，直到蔬菜渗出汁水，再用压石压住，使蔬菜完全浸没在汁水里。（隔绝氧气是关键） |
| 3 | 在室温（20℃）下边排气边发酵数日，然后存放在阴凉处。 |

| 顺序 | 泡菜腌制法（Kimjang） |
| :---: | :--- |
| 1 | 整棵白菜泡菜用的整棵大白菜：在菜帮部分一层层撒上粗盐，以室温（20℃）为准，在12%盐水中腌8小时。之后确认白菜的白色菜帮弯折时是否柔软地弯曲而不折断。 |
| | 切块泡菜用的白菜：把白菜切成一口大小，均匀撒盐拌匀，腌2小时使其变软。之后确认白菜是否渗出少量水。 |
| | 萝卜块泡菜用的萝卜：把萝卜切成方块后，同时撒上盐和糖，腌1小时使其变软。之后确认萝卜是否稍微变软，底部是否积起萝卜汁。 |
| 2 | 把腌好的蔬菜用冷水干净地冲洗2遍，洗去盐分和杂质。 |
| 3 | 把冲洗后的蔬菜放在竹筛（笊篱）上沥1小时，使水分自然向下流走。（用手按压或拧挤会破坏细胞壁，泡菜会不脆，还可能有陈腐味） |
| 4 | 用糯米粉或小麦粉加水煮成糊（淀粉糊）。糊是乳酸菌最初的食物，能促进发酵，并让调料更好地沾在蔬菜上。 |
| 5 | 在糊里拌入辣椒粉、大蒜、生姜、咸鱼酱（或鱼露）、葱等做成泡菜调料，再与腌好的蔬菜一起拌匀。 |
| 6 | 用力压紧装入发酵容器，把空气排出，然后盖上外层菜叶，或用卫生塑料膜紧贴盖住，隔绝氧气。 |
| 7 | 在室温（20℃）下放置一天左右，一旦开始咕嘟冒气，立即移到冰箱（0-5℃），低温熟成数日到数周。（因停电无法使用冰箱时，埋入地下或最凉爽的地下室，尽量减少暴露在常温中的时间） |
