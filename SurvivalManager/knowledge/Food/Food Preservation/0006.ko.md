## 5. 채소 및 과일 장기 보존 조리법
&nbsp;&nbsp;&nbsp;채소와 과일은 수분 함량이 높아 장기 보존이 까다롭지만, 산(식초), 당분(설탕), 염분(소금)을 활용하거나 표면 코팅을 통해 부패 속도를 지연시킬 수 있습니다.

---
### 5-1. 콤포트(Compote)
&nbsp;&nbsp;&nbsp;콤포트는 과일을 설탕물에 조려 만드는 조리 방식으로, 당분과 산을 이용해 단기 저장성과 풍미를 동시에 확보하는 방법입니다.

| 항목 | 내용 |
| :---: | :--- |
| 원리 | 비교적 높은 당분 농도가 삼투압을 높여 미생물 증식을 지연시키고, 레몬즙의 산이 pH를 낮춰 변질 속도를 늦춥니다. 단, 일반적인 콤포트는 수분활성도가 높아 상온 장기 보존에는 적합하지 않습니다. |
| 재료 | 과일 500g, 물 100ml, 원당(또는 설탕), 레몬 즙 |
| 보관 | 유리병에 밀봉하여 냉장 보관합니다. |
| | 냉장 환경에서도 수주 이내 소비를 전제로 합니다. |

| 순서 | 방법 |
| :---: | :--- |
| 1 | 과일을 냄비에 넣고 물과 원당을 넣은 후 끓입니다. |
| 2 | 끓기 시작하면 약불로 줄여 과일이 부드러워질 때까지 조립니다. |
| 3 | 레몬즙을 넣어 산미를 더합니다. |
| 4 | 깨끗한 유리병에 담아 밀봉 후 냉장 보관합니다. |

---
### 5-2. 왁스 코팅
&nbsp;&nbsp;&nbsp;달걀, 감귤, 사과 등 표면이 단단한 식품에 왁스를 발라 수분 손실과 산소 유입을 줄여 저장 수명을 연장할 수 있습니다.

| 항목 | 내용 |
| :---: | :--- |
| 원리 | 식품 표면에 얇은 보호막을 형성하여 수분 증발과 산소 침투를 완화하고, 호흡 속도를 늦춰 신선도를 유지합니다. |
| 재료 | 식용 왁스(비즈왁스, 파라핀 등) |
| 보관 | 습기와 빛이 차단된 서늘한 곳에 보관합니다. |
| 주의사항 | 달걀이나 사과는 수확 직후 자연 보호막(블룸)이 형성되어 있으므로, 세척하지 않은 달걀은 추가 코팅이 필요하지 않습니다. |
| | 보호막이 제거된 세척 달걀은 왁스 코팅을 통해 저장성을 보완할 수 있습니다. |

| 순서 | 방법 |
| :---: | :--- |
| 1 | 마른 천으로 채소 및 과일에 묻은 흙과 먼지를 털어냅니다. (수분이 있는 상태에서 왁스를 바르면, 효소에 의해 순식간에 농산물이 썩어버리므로 세척을 금지합니다) |
| 2 | 식용 왁스를 미지근한 물로 천천히 녹입니다. |
| 3 | 채소 및 과일의 겉 껍질에 균일하고 얇게 왁스를 바릅니다. (과도한 코팅은 과일의 호흡을 방해하여 내부 부패를 유발할 수 있습니다) |
| 4 | 왁스가 완전히 굳으면 습기와 빛이 차단된 서늘한 곳에 보관합니다. |

---
### 5-3. 데친 후 건조
&nbsp;&nbsp;&nbsp;단순히 말리는 것보다 데치기 과정을 거치면 보존 기한이 더 길어집니다.

| 항목 | 내용 |
| :---: | :--- |
| 원리 | 채소 내부의 부패·갈변 효소를 열로 파괴한 뒤, 건조를 통해 수분활성도를 0.6 이하로 낮추어 미생물이 자랄 수 없는 환경을 만듭니다. |
| 적합 식품 | 당근, 브로콜리, 버섯, 시금치, 사과, 바나나 등 대부분의 채소 및 과일 |
| 보관 | 건조된 채소를 산소 흡수제와 함께 마일라 백에 넣고 밀봉하여 습기와 빛이 차단된 서늘한 곳에 보관합니다. |

| 순서 | 방법 |
| :---: | :--- |
| 1 | 채소를 씻어 균일한 크기로 썰고, 끓는 물에 1-3분간 짧게 데칩니다. |
| 2 | 데친 즉시 찬물에 담가 잔열을 식히고 물기를 완전히 뺍니다. |
| 3 | 건조기(60℃)나 통풍이 잘되는 그늘에서 바삭해질 때까지 완전히 말립니다. |

---
### 5-4. 염장
&nbsp;&nbsp;&nbsp;소금 농도를 극단적으로 높여 보존하는 방식입니다.

| 항목 | 내용 |
| :---: | :--- |
| 원리 | 식품 내부의 수분을 삼투압 현상으로 모두 빼내고, 미생물의 세포막을 탈수시켜 사멸(염도 20% 이상)하게 만듭니다. |
| 적합 식품 | 배추, 무, 오이, 가지, 고추 등 수분이 많은 채소류 |
| 보관 | 염장 용기를 습기와 빛이 차단된 서늘한 곳에 보관합니다. |

| 순서 | 방법 |
| :---: | :--- |
| 1 | 채소를 씻어 균일한 크기로 썰어 냅니다. |
| 2 | 채반을 이용해 채소 표면의 물기를 완전히 제거합니다. |
| 3 | 용기 바닥에 소금을 1cm 이상 깔고 채소와 소금을 1:1에 가까운 비율로 켜켜이 쌓거나, 20% 이상의 진한 소금물에 완전히 잠기도록 담급니다. |
| 4 | 용기 뚜껑을 덮고 단단히 밀봉합니다. |
| 5 | 섭취 시에는 흐르는 물에 여러 번 씻고 물에 담가 소금기를 뺀 후 조리합니다. |

---
### 5-5. 젖산 발효
&nbsp;&nbsp;&nbsp;소금을 소량(3%)만 사용하여 유익한 젖산균(유산균)을 번식시키는 대사적 보존법입니다.

| 항목 | 내용 |
| :---: | :--- |
| 원리 | 젖산균이 채소의 당분을 먹고 '젖산'을 만들어내어 산성(pH 4.6 이하) 환경으로 변화시킵니다. 산성 환경에서는 부패균과 식중독균(보툴리눔균 포함)이 살 수 없습니다. |
| 적합 식품 | 양배추(사워크라우트), 오이(발효 피클), 무, 김치류 |
| 보관 | 발효 용기를 습기와 빛이 차단된 서늘한 곳에 보관합니다. |

| 순서 | 양배추를 이용한 사워크라우트 조리법 |
| :---: | :--- |
| 1 | 양배추 등을 가늘게 채 썰어 전체 무게의 3%에 해당하는 소금을 넣고 버무립니다. |
| 2 | 채소에서 국물이 배어나올 때까지 꾹꾹 누른 뒤, 채소가 국물에 완전히 잠기도록 누름돌로 누릅니다. (산소 차단이 핵심) |
| 3 | 실온(20℃)에서 가스를 빼주며 수 일간 발효시킨 후 서늘한 곳에 보관합니다. |

| 순서 | 김장법 |
| :---: | :--- |
| 1 | 포기 김치용 통배추: 줄기 부분에 굵은 소금을 켜켜이 뿌려 실온(20℃) 기준 8시간 동안 12% 소금물에 염장합니다. 이후 배추 흰 줄기 부분을 구부렸을 때 부러지지 않고 부드럽게 휘어지는지 확인합니다. |
| | 맛김치용 배추: 배추를 한입 크기로 썰어 소금을 골고루 뿌려 섞어 2시간 숨을 죽입니다. 이후 배추에서 물이 자작하게 나오는지 확인합니다. |
| | 깍두기용 무: 무를 깍뚝썬 후 소금과 설탕을 함께 뿌려 1시간 숨을 죽입니다. 이후 무가 살짝 말랑해지면서 바닥에 무즙이 고이는지 확인합니다. |
| 2 | 절여진 채소를 찬물에 2번 깨끗이 헹궈 소금기와 불순물을 씻어냅니다. |
| 3 | 헹군 채소를 채반(소쿠리)에 1시간 동안 받쳐두어 자연스럽게 물기가 아래로 빠지도록 합니다. (손으로 누르거나 비틀어 짜면 세포벽이 파괴되어 김치가 아삭하지 않고 군내가 날 수 있습니다) |
| 4 | 찹쌀가루나 밀가루를 물에 끓여 풀국(전분)을 만듭니다. 풀국은 젖산균의 초기 먹이가 되어 발효를 촉진하고, 양념이 채소에 잘 묻게 합니다. |
| 5 | 풀국에 고춧가루, 마늘, 생강, 젓갈(또는 액젓), 파 등을 섞어 김치 양념을 만든 뒤, 절인 채소와 함께 버무립니다. |
| 6 | 발효 용기에 꾹꾹 눌러 담아 공기를 뺀 다음, 우거지를 덮거나 위생 비닐을 밀착시켜 산소를 차단합니다. |
| 7 | 실온(20℃)에서 하루 정도 두어 가스가 뽀글거리기 시작하면 즉시 냉장고(0-5℃)로 옮겨 수일에서 수주간 저온 숙성시킵니다. (정전으로 냉장고 사용이 불가할 경우, 땅 속이나 가장 서늘한 지하에 묻어 상온 노출을 최소화합니다) |
