## 6. 谷物长期保藏做法
&nbsp;&nbsp;&nbsp;谷物本身含水量低，可以简单地与脱氧剂一起装在塑料瓶里保存，但长期保存时，象鼻虫等害虫的发生和脂肪成分的酸败是最大的问题。

---
### 6-1. 硬饼干 / 船用饼干（Hardtack）
&nbsp;&nbsp;&nbsp;是大航海时代的水手和南北战争时的士兵吃了好几年的、人类历史上性价比最高的谷物长期保藏做法。

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 去除面粉中的水分，把水分活度降到0.3以下，微生物无法繁殖，又因为不加脂肪（黄油、油）和糖，没有可酸败的有机物。 |
| 材料 | 面粉（中筋或高筋）3杯、水1杯、盐2茶匙（禁止加油、糖、酵母） |
| 储存 | 完全冷却后，戴上塑料手套，以免手上的细菌沾上，与脱氧剂一起放进迈拉袋或密封容器中保存。 |
| 注意事项 | 硬得像石头，直接咀嚼可能崩断牙齿。必须用水、咖啡、汤泡软后食用，或掰碎后煮成粥食用。 |

| 顺序 | 制作方法 |
| :---: | :--- |
| 1 | 在面粉里拌入盐，一点点倒水揉成面团。 |
| 2 | 揉到面团不粘手、感觉发硬为止。 |
| 3 | 用擀面杖把面团压平到1cm厚。 |
| 4 | 用刀切成约5cm×5cm的方块。 |
| 5 | 用叉子或筷子在整个面团上密密地扎孔。（内部水分蒸发的通道） |
| 6 | 以家用烤箱为准，在160°C下烤约30分钟，翻面后再烤30分钟。要烤到不焦、像烘干到里面一样，表面呈褐色，摸起来完全坚硬。 |
| 7 | 取出烤好的饼干，在通风良好的地方晾3天，去除内部残余的水分。 |

### 6-2. 辟谷丹（Byeokgokdan）
&nbsp;&nbsp;&nbsp;是东方在战争和荒年时设计的丸（丸）形谷物储备食品，不用烹调，只吃一粒也能忘记饥饿坚持下去。

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 把谷物蒸一次再晒干，使酶失活，磨成粉，用天然防腐剂兼热量来源的“蜂蜜”和成团并密封。蜂蜜的高糖浓度引起强大的渗透压，阻断微生物繁殖。 |
| 材料 | 大豆、大米、糯米、大麦、大枣、板栗（或芝麻）等周围容易得到的谷物类，天然蜂蜜（糖浆或低聚糖水分多，无法长期保存） |
| 储存 | 把辟谷丹逐粒用纸或韩纸包好，放进罐子或密封容器中存放在阴凉处。 |

| 顺序 | 制作方法 |
| :---: | :--- |
| 1 | 把备好的谷物（大豆、大米等）洗净后，放在蒸笼或蒸锅上蒸透。（谷物事先蒸熟，以后不必重新烹调就能食用） |
| 2 | 把蒸好的谷物摊在阳光充足、通风好的地方，晒到干透变硬。 |
| 3 | 把完全干燥的谷物与大枣（去核）、干板栗等放进臼或粉碎机，磨成很细的粉。 |
| 4 | 往谷物粉里一点点倒入天然蜂蜜，揉到有硬黏土般的质感。（蜂蜜太多会变稀，所以只加到能捏成团的程度） |
| 5 | 把面团搓成直径2cm的圆球，做成丸状。 |
| 6 | 把搓好的辟谷丹放在通风良好的阴凉处晾2天，直到表面稍微变硬，再用纸或韩纸包好，装进密封容器保存。 |

### 6-3. 炒谷粉（Misutgaru）

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 将谷物高温炒制，使内部水分降到5%以下，并使蛋白质和淀粉糊化。没有水分，微生物无法生长。 |
| 材料 | 大麦、糯米、糙米、豆类等（紫苏籽、芝麻这类含油谷物因油脂而酸败快，必须排除） |
| 储存 | 与脱氧剂一起放进迈拉袋，存放在阴凉处。 |

| 顺序 | 制作方法 |
| :---: | :--- |
| 1 | 把谷物用水洗净后，用冷水泡三四个小时。 |
| 2 | 把泡好的谷物放进蒸锅，蒸到完全熟透。 |
| 3 | 把蒸好的谷物摊在竹筛上，晾到水分消失。 |
| 4 | 把去掉水分的谷物用小火炒到散发出香味。 |
| 5 | 把炒好的谷物完全放凉后，用搅拌机或臼磨成细粉。 |
