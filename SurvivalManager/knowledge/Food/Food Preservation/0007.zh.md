## 6. 谷物长期保存烹饪法
&nbsp;&nbsp;&nbsp;谷物本身的水分含量较低，虽然可以直接与氧气吸收剂一同放入塑料瓶中保存，但在长期保存时，象鼻虫等害虫的滋生以及脂肪成分的酸败是最大的问题。

---
### 6-1. 硬饼干 / 航海饼干 (Hardtack / Ship Biscuit)
&nbsp;&nbsp;&nbsp;这是在大航海时代供船员们、以及在美国南北战争时期供士兵们存放数年食用的，人类历史上性价比最高的长期保存谷物烹饪法。

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 经过去除面粉中的水分，将水分活度降低至 0.3 以下，使微生物无法繁殖；由于不添加脂肪（黄油、植物油）和糖，因此没有易酸败的有机物。 |
| 材料 | 面粉（中筋或高筋面粉）3杯、水 1杯、食盐 2茶匙（严禁使用油、糖、酵母） |
| 贮藏 | 完全冷却后，为了防止沾染手上的病菌，须佩戴塑料手套，将饼干与氧气吸收剂一同放入铝箔避光袋或密闭容器中保存。 |
| 注意事项 | 饼干质地坚硬如石，直接咀嚼可能会导致牙齿断裂。食用时必须用油、水、咖啡或汤汁泡软，或者将其捣碎煮成粥状。 |

| 步骤 | 制造方法 |
| :---: | :--- |
| 1 | 在面粉中加入食盐混合均匀，随后一边揉面一边分次倒入水。 |
| 2 | 持续揉搓反面，直至面团不再粘手且带有明显的干硬感。 |
| 3 | 利用擀面杖将面团擀成 1cm 厚度的平整面饼。 |
| 4 | 利用刀将面饼切成横竖约 5cm 大小的正方形。 |
| 5 | 利用叉子或筷子在整块面饼上戳出密集的孔洞。（作为内部水分蒸发的通道） |
| 6 | 以家用烤箱为准，在 160°C 下烘烤约 30 分钟，随后翻面再烘烤 30 分钟。须像烘干一样将其烤透且防止烤焦，直至表面呈现金黄色，触碰时感觉完全坚硬。 |
| 7 | 取出烤好的饼干，置于通风良好处风干 3 天，以彻底去除内部的残留水分。 |

---
### 6-2. 辟谷丹
&nbsp;&nbsp;&nbsp;这是东方在战争及饥荒时期，为了让人无需烹饪、仅服一粒便能忍受饥饿并维持生存而设计出来的丸状储备粮食。

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 将谷物经蒸熟、晒干以使其内部的酶失去活性，随后研磨成粉，再用既是天然防腐剂又是热量来源的“纯天然蜂蜜”进行揉和并密封。蜂蜜的高糖浓度可产生强大的渗透压，从而阻断微生物的滋生。 |
| 材料 | 大豆、大米、糯米、大麦、红枣、栗子（或芝麻）等周边易于获取的谷物类，纯天然蜂蜜（糖浆或低聚糖水分过多，无法用于长期保存） |
| 贮藏 | 将辟谷丹逐粒用纸或宣纸包裹，装入坛子或密闭容器中，存放在阴凉处。 |

| 步骤 | 制造方法 |
| :---: | :--- |
| 1 | 将准备好的谷物（大豆、大米等）清洗干净，随后放入蒸笼中彻底蒸熟。（必须将谷物做熟，以便日后无需再次烹饪即可直接食用） |
| 2 | 将蒸熟的谷物摊放在阳光充足、通风良好的地方，彻底晒干直至质地坚硬。 |
| 3 | 将完全晒干的谷物、红枣（去核）、干栗子等放入捣蒜罐或研磨机中，磨成极细的粉末。 |
| 4 | 在谷物粉中缓缓倒入天然蜂蜜，揉和至呈现出坚硬粘土般的质地。（蜂蜜过多会导致面团过软，因此加入的量只需满足能捏成团即可） |
| 5 | 将面团揉成直径 2cm 左右的圆丸，制成丸剂形状。 |
| 6 | 将捏好的辟谷丹放在通风良好的阴凉处晾干 2 天，直至表面微微变硬，随后用纸或宣纸包裹，装入密闭容器中贮藏。 |

---
### 6-3. 糌粑面 / 炒面 (熟谷物粉)

| 项目 | 内容 |
| :---: | :--- |
| 原理 | 通过高温炒制谷物，将其内部水分减少至 5% 以下，并使蛋白质和淀粉糊化。由于缺乏水分，微生物无法生长。 |
| 材料 | 大麦、糯米、糙米、大豆等（严禁使用苏子、芝麻等含油量高的油料作物谷物，因为油脂会导致快速酸败） |
| 贮藏 | 将其与氧气吸收剂一同放入铝箔避光袋中，存放在阴凉处。 |

| 步骤 | 制造方法 |
| :---: | :--- |
| 1 | 将谷物用水清洗干净，随后在冷水中浸泡三到四个小时。 |
| 2 | 将浸泡好的谷物放入蒸笼中，彻底蒸熟。 |
| 3 | 将蒸熟的谷物摊放在笊篱上，晾干至表面水分完全消失。 |
| 4 | 将失去水分的谷物放入锅中，用小火炒制，直至散发出浓郁的炒货香味。 |
| 5 | 待炒好的谷物完全冷却后，用搅拌机或捣碎罐将其精细研磨成粉末。 |
