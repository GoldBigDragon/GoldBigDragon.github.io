## 4. 육류 장기 보존 조리법
---
### 4-1. 육포
| 항목 | 내용 |
| :---: | :--- |
| 원리 | 수분활성도를 0.75 이하로 낮춰 대부분의 세균 증식을 억제합니다. |
| 재료 | 지방이 거의 없는 살코기(우둔살, 홍두깨살 등), 소금(고기 중량의 2%) |
| 보관 | 완전히 건조한 후 밀봉하여, 습기와 빛이 차단된 곳에 보관합니다. |
| | 보관 시 산소 흡수제와 함께 마일라 백에 넣어 밀봉하거나, 금속 용기 사용을 권장합니다. |
| | 홈메이드 육포는 보존제가 없어 생각보다 수명이 짧으므로, 장기 보관 목적이라면 페미컨을 만드는 것이 좋습니다. |

| 순서 | 방법 |
| :---: | :--- |
| 1 | 살코기 표면 및 내부의 지방과 힘줄을 최대한 제거합니다. (지방은 건조되지 않으며, 산패와 악취의 주원인이 됩니다) |
| 2 | 살코기를 결 반대 방향으로 5mm 이하로 균일하게 절단합니다. |
| 3 | 소금을 고기에 고르게 문지릅니다. (간장, 향신료, 설탕 등은 선택 사항이나, 수분 증가로 저장성을 저하시킬 수 있으므로 최소화합니다) |
| 4 | 냉장 상태(4℃ 이하)에서 3시간 이상 재워 소금이 속까지 배게 합니다. (냉장이 불가능한 경우, 상온 그늘에서 2시간 동안 염지합니다) |
| 5 | 건조기 건조: 65℃에서 12시간 이상 건조합니다. |
| | 태양광 건조: 얇은 천이나 망으로 덮어 먼지와 해충을 차단하고, 직사광선과 통풍이 잘되는 곳에서 3일 이상 건조합니다. (야간에는 습기를 흡수하므로 반드시 실내로 회수합니다) |
| | 공통: 중간에 여러 번 뒤집어 균일하게 건조합니다. |
| 6 | 건조 완료 후, 식중독균(살모넬라, 대장균 등) 사멸을 위해 고기 내부 온도가 최소 71℃ 이상 도달할 때까지 살짝 굽거나 열처리를 해줍니다. |
| 7 | 완성된 육포는 표면에 끈적임이나 습기가 없고, 접었을 때 부러지지 않으면서 갈라짐이 발생해야 합니다. |

### 4-2. 페미컨(Pemmican)
| 항목 | 내용 |
| :---: | :--- |
| 원리 | 완전 건조 육분과 산화 안정성이 높은 동물성 지방의 결합으로, 수분 함량이 낮아 상온 장기보관이 가능합니다. |
| 재료 | 지방이 거의 없는 살코기, 소 지방(Tallow), 소금(고기 중량의 2%), (선택 사항) 완전 건조 과일 가루 (전체 중량의 5% 이내) |
| 보관 | 밀봉 상태로 습기와 빛이 차단된 곳에 보관합니다. |
| | 지방이 녹거나 변질되지 않도록 고온 환경을 피합니다. |

| 순서 | 육분 제조 방법 |
| :---: | :--- |
| 1 | 살코기 표면 및 내부의 지방과 힘줄을 최대한 제거합니다. (지방은 건조되지 않으며, 산패 위험이 높습니다) |
| 2 | 살코기를 최대한 얇게 절단합니다. |
| 3 | 소금을 고기에 고르게 문지릅니다. |
| 4 | 냉장 상태(4℃ 이하)에서 3시간 이상 재워 소금이 속까지 배게 합니다. (냉장이 불가능한 경우, 상온 그늘에서 2시간 동안 염지합니다) |
| 5 | 염지된 고기를 건조기(65℃ 이상)나 태양광을 이용해 바삭하게 부러질 때까지 완전히 건조합니다. |
| 6 | 건조 완료 후, 식중독균(살모넬라, 대장균 등) 사멸을 위해 고기 내부 온도가 최소 71℃ 이상 도달할 때까지 바싹 굽습니다. |
| 7 | 열기를 식힌 후, 절구에 빻거나 믹서기로 갈아 손으로 쉽게 부서지는 고운 가루(육분)로 만듭니다. |

| 순서 | 소 기름 정제 방법 |
| :---: | :--- |
| 1 | 소 지방을 잘게 잘라 물과 함께 가열하거나, 물 없이 약불로 볶아 기름을 녹여냅니다. (돼지 지방은 산화 안정성이 낮아 장기보관에 불리하므로 반드시 소 지방을 사용합니다) |
| 2 | 물과 단백질 찌꺼기를 체나 천으로 거르고 맑은 기름만 모읍니다. |
| 3 | 맑은 기름을 냄비에 넣고 약불로 가열하여, 기름 속 미세 수분이 완전히 증발하여 기포가 전혀 발생하지 않을 때까지 끓여냅니다. |

| 순서 | 페미컨 성형 방법 |
| :---: | :--- |
| 1 | 준비된 육분과 건조 과일 가루를 고르게 혼합합니다. (과일 가루는 저장성을 저하시키므로 전체 중량의 5% 이내로 최소화하며, 간이 부족할 때만 소금을 소량 추가합니다) |
| 2 | 따뜻하게 녹인 정제 소 기름을 육분과 약 1:1 비율(또는 육분이 촉촉해질 정도)로 부어가며 점토 같은 농도가 될 때까지 섞어줍니다. (기름이 너무 많으면 흐르고, 적으면 뭉쳐지지 않습니다) |
| 3 | 기름이 굳기 전에 틀에 넣고 꾹꾹 눌러 막대 또는 덩어리 형태로 성형합니다. |
| 4 | 소 기름이 완전히 굳어 형태가 단단해지면 공기가 통하지 않도록 개별 밀봉합니다. |

### 4-3. 훈연육(Smoked Meat)
| 항목 | 내용 |
| :---: | :--- |
| 원리 | 고기 표면에 연기 성분(페놀, 아세트산 등)의 항균·항산화 막을 형성하여 미생물 증식과 지방 산패를 억제합니다. |
| 재료 | 지방이 적은 살코기, 소금(고기 중량의 4%), 훈연기, 온도계, 훈연재(참나무, 과일나무 등 활엽수 장작/칩) |
| 보관 | 건조 및 밀봉된 상태로 습기와 빛이 차단된 서늘한 곳에 보관합니다. |
| | 건조 및 밀봉되지 않은 훈연육은 반드시 냉장 보관해야 합니다. |

| 순서 | 제조 방법 |
| :---: | :--- |
| 1 | 소금을 고기에 고르게 문지릅니다.
| 2 | 냉장 상태(4℃ 이하)에서 48시간 이상 재워 소금이 속까지 배게 합니다. (선행 염장이 없으면 훈연 중 부패합니다) |
| 3 | 염지가 끝난 고기는 연기가 표면에 잘 흡착될 수 있도록 표면의 물기를 닦아내고, 겉면에 끈적하고 단단한 막(펠리클, Pellicle)이 형성될 때까지 충분히 건조합니다. |
| 4 | 침엽수(소나무 등)는 레진과 그을음으로 인해 쓴맛과 독성이 발생하므로, 반드시 참나무나 과일나무 등 활엽수 장작 및 칩을 사용하여 훈연기에 불을 지핍니다. |
| 5 | 목표하는 보존 기간과 조리 방식에 따라 아래의 훈연 방식별 온도 기준을 준수하여 수시간에서 수주 동안 연기를 쏘입니다. (※ 상세 온도는 하단 표 참조) |
| 6 | 훈연을 마친 고기는 연기 성분이 내부까지 고루 베고 수분이 안정화되도록, 먼지와 해충이 차단된 서늘하고 건조한 장소에서 일정 기간 숙성합니다. |
| 7 | 안전성 확인: 완성된 훈연육은 단단하고 건조해야 합니다. 훈연 중 발생하는 저온·저산소 환경은 보툴리눔균이 번식하기 쉬운 조건이므로, 설정한 염도·건조도·온도 관리에 실패했다고 판단되면 즉시 전량 폐기해야합니다. |

| 훈연 방식 | 관리 온도 | 훈연 시간 | 보존성 및 특징 |
| :---: | :---: | :---: | :--- |
| 냉훈법 (Cold Smoking) | 30℃ 이하 | 수일 ~ 수주 | 상온 장기 보관용. 고염 염장과 완전 건조가 필수이며, 열을 가하지 않고 연기만 입혀 수분을 극단적으로 날리는 훈연 방식입니다. |
| 온훈법 (Warm Smoking) | 40 ~ 60℃ | 2 ~ 5시간 | 단기 보관용. 고기 조직이 부드러워지나 완전히 익지 않으므로, 추후 재가열 조리가 필요하며 보존성은 상대적으로 낮습니다. |
| 열훈법 (Hot Smoking) | 65 ~ 90℃ | 수시간 | 즉시 섭취 및 단기 보관용. 건조와 동시에 고기 내부를 완전히 익히는 방식(바비큐 형태)으로, 풍미는 좋으나 장기 보관은 불가능합니다. |
| 소훈법 (Roast Smoking) | 90℃ 이상 | 단시간 | 고기를 고온에서 빠르게 구우면서 연기 향만 입히는 방식으로, 보존 효과는 거의 없습니다. |
