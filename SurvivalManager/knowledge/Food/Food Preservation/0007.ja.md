## 6. 穀物の長期保存の調理法
&nbsp;&nbsp;&nbsp;穀物は水分含有量そのものが低いので、プラスチックのボトルに脱酸素剤と一緒に入れるだけで保管できますが、長期保管ではゾウムシのような害虫の発生と、脂肪成分の酸敗が最大の問題になります。

---
### 6-1. ハードタック / シップビスケット
&nbsp;&nbsp;&nbsp;大航海時代の船乗りや南北戦争当時の兵士が、何年も置いて食べた、人類史上最もコストパフォーマンスの高い穀物の長期保存の調理法です。

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 小麦粉の水分を取り除いて水分活性を0.3以下に下げるので微生物が繁殖できず、脂肪(バター、油)と砂糖を入れないので、酸敗する有機物がありません。 |
| 材料 | 小麦粉(中力粉または強力粉)3カップ、水1カップ、塩小さじ2(油・砂糖・イースト禁止) |
| 保管 | 完全に冷ました後、手の細菌がつかないようビニール手袋をはめて、脱酸素剤と一緒にマイラーバッグや密閉容器に保管します。 |
| 注意事項 | 石のように硬いので、そのまま噛むと歯が折れることがあります。必ず水、コーヒー、スープにひたして食べるか、砕いて粥のように煮て食べなければなりません。 |

| 順序 | 製造方法 |
| :---: | :--- |
| 1 | 小麦粉に塩を混ぜ、水を少しずつ注ぎながらこねます。 |
| 2 | 生地が手につかず、固い感触になるまでこねます。 |
| 3 | めん棒を使って、生地を1cmの厚さに平らにのばします。 |
| 4 | 包丁を使って、縦・横約5cmの四角形に切ります。 |
| 5 | フォークや箸を使って、生地全体に穴をびっしりあけます。(内部の水分が蒸発する通り道) |
| 6 | 家庭用オーブンで160℃で約30分焼いた後、ひっくり返して、さらに30分焼きます。焦がさずに中まで乾かすように焼いて、表面が茶色みを帯び、触ったときに完全に硬くなっていなければなりません。 |
| 7 | 焼き上がったビスケットを取り出し、風通しのよい場所で3日間乾燥させて、内部に残った水分まで取り除きます。 |

---
### 6-2. ピョッコクタン(辟穀丹)
&nbsp;&nbsp;&nbsp;東洋で戦争や凶作のときに、調理なしで1粒食べるだけで空腹を忘れて耐えられるよう考案された、丸薬(丸)の形の穀物の備蓄食料です。

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 穀物を一度蒸して乾かし、酵素を不活性化させた後、粉にして、天然の保存料であり熱量源である「はちみつ」でこねて密封します。はちみつの高い糖濃度が強い浸透圧を起こして、微生物の増殖を阻みます。 |
| 材料 | 大豆、米、もち米、大麦、ナツメ、栗(またはゴマ)など、身近で手に入りやすい穀物類、天然はちみつ(砂糖シロップやオリゴ糖は水分が多く、長期保管ができません) |
| 保管 | ピョッコクタンを1粒ずつ紙や和紙に包んで、甕や密閉容器に入れ、涼しい場所に保管します。 |

| 順序 | 製造方法 |
| :---: | :--- |
| 1 | 用意した穀物(大豆、米など)をきれいに洗った後、蒸し器にのせてよく蒸します。(穀物を火が通った状態にしておくと、後で調理し直さずに食べられます) |
| 2 | 蒸した穀物を、日光と風がよく通る場所に広げて、固くなるまでからからに乾かします。 |
| 3 | からからに乾いた穀物と、ナツメ(種を除く)、乾燥させた栗などを、すり鉢や粉砕機に入れて、とても細かい粉に挽きます。 |
| 4 | 穀物の粉に天然はちみつを少しずつ注ぎながら、固い粘土のような感触になるまでこねます。(はちみつが多すぎるとべたつくので、まとまる程度にだけ入れます) |
| 5 | 生地を直径2cmに丸めて、丸薬の形にします。 |
| 6 | 丸めたピョッコクタンを、風通しのよい日陰で、表面が少し固くなるまで2日間乾燥させた後、紙や和紙に包んで、密閉容器に入れて保管します。 |

### 6-3. ミスッカル

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 穀物を高温で炒って、内部の水分を5%以下に減らし、タンパク質とでんぷんを糊化させます。水分がなく、微生物が育ちません。 |
| 材料 | 大麦、もち米、玄米、豆など(エゴマやゴマのような油脂類の穀物は、油のために酸敗が早く進むので、除外しなければなりません) |
| 保管 | 脱酸素剤と一緒にマイラーバッグに入れて、涼しい場所に保管します。 |

| 順序 | 製造方法 |
| :---: | :--- |
| 1 | 穀物を水できれいに洗った後、冷たい水に3、4時間浸けます。 |
| 2 | 浸した穀物を蒸し器に入れて、完全に火が通るまで蒸します。 |
| 3 | 蒸した穀物をざるに広げて、水分がなくなるまで乾燥させます。 |
| 4 | 水分が抜けた穀物を、弱火で香ばしいにおいがするまで炒ります。 |
| 5 | 炒った穀物を完全に冷ました後、ミキサーやすり鉢で細かく挽いて粉にします。 |
