## 6. 穀物の長期保存調理法
&nbsp;&nbsp;&nbsp;穀物は水分含有量自体が低いため、簡単にプラスチックボトルへ脱酸素剤とともに保管することができますが、長期保管時はコクゾウムシなどの害虫発生と脂肪成分の酸敗が最大の課題となります。

---
### 6-1. ハードタックス (Hardtack) ／ シップスビスケット (Ship's Biscuit)
&nbsp;&nbsp;&nbsp;大航海時代の船乗りや南北戦争当時の兵士たちが数年間も保存して食べていた、人類の歴史上最もコストパフォーマンスの高い長期保存穀物調理法です。

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 小麦粉の 水分を 除去して 水分活性を 0.3以下に 低下させることで 微生物が 繁殖できなくなり、脂肪（バター、油）や 砂糖を 入れないため 酸敗する 有機物が 存在しません。 |
| 材料 | 小麦粉（中力粉または強力粉）3カップ、水1カップ、塩2ティースプーン（油、砂糖、イーストは禁止） |
| 保管 | 完全に冷ました後、手の細菌が付着しないようビニール手袋を着用した状態で、脱酸素剤とともにマイラーバッグや密閉容器に保管します。 |
| 注意事項 | 石のように硬いため、そのまま噛むと歯が折れる危険があります。必ず水、コーヒー、スープなどに浸して柔らかくするか、砕いて粥のように煮て摂取してください。 |

| 順序 | 製造方法 |
| :---: | :--- |
| 1 | 小麦粉に塩を混ぜ、水を少しずつ加えながらこねます。 |
| 2 | 生地が手にくっつかず、硬い質感になるまでしっかりと練り上げます。 |
| 3 | 麺棒を使用し、生地を1cmの厚さに平らに伸ばします。 |
| 4 | 包丁を使用し、縦・横約5cmの正方形に切り分けます。 |
| 5 | フォークや箸を使用し、生地全体に細かく穴を開けます。（内部の水分を蒸発させる通路となります） |
| 6 | 家庭用オーブン基準で160°Cで約30分間焼き、裏返してさらに30分間焼きます。焦がさないように芯まで乾燥させるように焼き上げ、表面がキツネ色になり、触ったときに完全に硬くなっていなければなりません。 |
| 7 | 焼き上がったビスケットを取り出し、通風の良好な場所で3日間乾燥させて内部の残留水分まで完全に除去します。 |

### 6-2. 辟穀丹（へきこくだん）
&nbsp;&nbsp;&nbsp;東洋において、戦争や凶作の際に調理なしで一粒食べるだけで飢えを凌ぎ、持ちこたえられるよう考案された丸薬（がんやく）形態の備蓄食糧です。

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 穀物を一度蒸して乾燥させることで酵素を不活性化した後、粉末にして天然の保存料であり熱量源でもある「蜂蜜」でこねて密閉します。蜂蜜の高い糖度が強力な浸透圧を引き起こし、微生物の増殖を遮断します。 |
| 材料 | 大豆、米、もち米、麦、ナツメ、栗（またはゴマ）など、周囲で入手しやすい穀物類、天然蜂蜜（砂糖シロップやオリゴ糖は水分が多いため長期保管不可） |
| 保管 | 辟穀丹を一粒ずつ紙や韓紙（和紙など）で包み、壺や密閉容器に入れて涼しい場所に保管します。 |

| 順序 | 製造方法 |
| :---: | :--- |
| 1 | 準備した穀物（大豆、米など）をきれいに洗い、せいろや蒸し器に上げて十分に蒸します。（穀物を加熱しておくことで、後に再調理なしで摂取可能になります） |
| 2 | 蒸した穀物を日当たりと風通しの良い場所に広げ、硬くなるまでカラカラに乾かします。 |
| 3 | 完全に乾燥した穀物とナツメ（種は除去）、乾燥させた栗などをすり鉢や粉砕機に入れ、非常に細かい粉末にすり潰します。 |
| 4 | 穀物の粉末に天然蜂蜜を少しずつ加えながら、硬い粘土のような質感になるまでこねます。（蜂蜜が多すぎるとベタつくため、まとまる程度だけ入れます） |
| 5 | 生地を直径2cmの球状に丸め、丸薬の形状を作ります。 |
| 6 | 丸めた辟穀丹を風通しの良い日陰で表面が少し硬くなるまで2日間乾燥させた後、紙や韓紙で包んで密閉容器に入れて保管します。 |

### 6-3. ミスカル（炒り穀物粉）

| 項目 | 内容 |
| :---: | :--- |
| 原理 | 穀物を高温で炒ることで内部の水分を5%以下に減少させ、タンパク質と澱粉をα化（糊化）させます。水分が存在しないため微生物が繁殖できません。 |
| 材料 | 麦、もち米、玄米、大豆など（エゴマやゴマのような油脂類の穀物は、油分によって酸敗が早まるため除外しなければなりません） |
| 保管 | 脱酸素剤とともにマイラーバッグに入れ、涼しい場所に保管します。 |

| 順序 | 製造方法 |
| :---: | :--- |
| 1 | 穀物を水できれいに洗った後、冷水に3～4時間浸してふやかします。 |
| 2 | ふやかした穀物を蒸し器に入れ、完全に火が通るまで蒸します。 |
| 3 | 蒸した穀物をザルに広げ、水分がなくなるまで乾燥させます。 |
| 4 | 水分が抜けた穀物を、弱火で香ばしい香りがするまで炒ります。 |
| 5 | 炒った穀物を完全に冷ました後、ミキサーやすり鉢で細かく挽いて粉末にします。 |
