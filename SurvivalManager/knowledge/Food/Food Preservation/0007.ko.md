## 6. 곡물 장기 보존 조리법
&nbsp;&nbsp;&nbsp;곡물은 수분 함량 자체가 낮아 간단히 플라스틱 병에 산소 흡수제와 함께 보관할 수 있지만, 장기 보관 시 바구미 같은 해충 발생과 지방 성분의 산패가 가장 큰 문제로 작용합니다.

---
### 6-1. 하드택 / 쉽 비스킷
&nbsp;&nbsp;&nbsp;대항해시대 선원들과 남북전쟁 당시 군인들이 몇 년씩 두고 먹었던 인류 역사상 가장 가성비 높은 장기 보존 곡물 조리법입니다.

| 항목 | 내용 |
| :---: | :--- |
| 원리 | 밀가루의 수분을 제거하여 수분활성도를 0.3 이하로 낮추어 미생물이 번식할 수 없고, 지방(버터, 기름)과 설탕을 넣지 않아 산패할 유기물이 없습니다. |
| 재료 | 밀가루(중력분 또는 강력분) 3컵, 물 1컵, 소금 2티스푼 (기름, 설탕, 이스트 금지) |
| 보관 | 완전히 식힌 후, 손의 병균이 묻지 않도록 비닐 장갑을 낀 채 산소 흡수제와 함께 마일라 백이나 밀폐 용기에 보관합니다. |
| 주의사항 | 돌처럼 단단하므로 그냥 씹으면 치아가 부러질 수 있습니다. 반드시 물, 커피, 국물에 불려 먹거나 부수어서 죽처럼 끓여 먹어야 합니다. |

| 순서 | 제조 방법 |
| :---: | :--- |
| 1 | 밀가루에 소금을 섞고, 물을 조금씩 부어가며 반죽합니다. |
| 2 | 반죽이 손에 묻지 않고 뻑뻑한 느낌이 들 때까지 치대어 줍니다. |
| 3 | 밀대를 이용해 반죽을 1cm 두께로 평평하게 만듭니다. |
| 4 | 칼을 이용해 가로·세로 약 5cm 크기의 사각형으로 자릅니다. |
| 5 | 포크나 젓가락을 이용해 반죽 전체에 구멍을 촘촘히 뚫어줍니다. (내부 수분이 증발할 통로) |
| 6 | 가정용 오븐 기준 160°C에서 약 30분간 구운 뒤, 뒤집어서 다시 30분간 굽습니다. 타지 않게 속까지 말리듯 구워내어 겉면이 갈색빛을 띠고, 만졌을 때 완전히 단단해야 합니다. |
| 7 | 구워진 비스킷을 꺼내어 통풍이 잘되는 곳에서 3일간 건조하여 내부 잔여 수분까지 제거합니다. |

---
### 6-2. 벽곡단
&nbsp;&nbsp;&nbsp;동양에서 전쟁 및 흉년 시 조리 없이 한 알만 먹어도 배고픔을 잊고 버틸 수 있도록 고안된 환(丸) 형태의 곡물 비축식량입니다.

| 항목 | 내용 |
| :---: | :--- |
| 원리 | 곡물을 한 번 찌고 말려 효소를 불활성화 한 뒤 가루 내어 천연 보존제이자 열량원인 '꿀'로 반죽해 밀봉합니다. 꿀의 높은 당 농도가 강력한 삼투압을 일으켜 미생물 증식을 차단합니다. |
| 재료 | 콩(대두), 쌀, 찹쌀, 보리, 대추, 밤(또는 참깨) 등 주변에서 구하기 쉬운 곡물류, 천연 꿀 (설탕 시럽이나 올리고당은 수분이 많아 장기 보관 불가) |
| 보관 | 벽곡단을 한 알씩 종이나 한지에 싸서 항아리나 밀폐 용기에 담아 서늘한 곳에 보관합니다. |

| 순서 | 제조 방법 |
| :---: | :--- |
| 1 | 준비한 곡물(콩, 쌀 등)을 깨끗이 씻은 후 시루나 찜기에 올려 푹 찝니다. (곡물을 익혀두어야 나중에 재조리 없이 섭취 가능합니다) |
| 2 | 찐 곡물을 햇볕과 바람이 잘 통하는 곳에 펼쳐놓고 단단해질 때까지 바짝 말립니다. |
| 3 | 바짝 마른 곡물과 대추(씨 제거), 말린 밤 등을 절구나 분쇄기에 넣고 아주 고운 가루로 빻아줍니다. |
| 4 | 곡물 가루에 천연 꿀을 조금씩 부어가며 단단한 점토 느낌이 날 때까지 반죽합니다. (꿀이 너무 많으면 질어지므로 뭉쳐질 정도로만 넣습니다) |
| 5 | 반죽을 지름 2cm로 둥글게 빚어 환 형태를 만듭니다. |
| 6 | 빚어낸 벽곡단을 바람이 잘 통하는 그늘에서 겉면이 살짝 단단해질 때까지 2일간 건조한 뒤 종이나 한지에 싸서 밀폐 용기에 담아 보관합니다. |

### 6-3. 미숫가루

| 항목 | 내용 |
| :---: | :--- |
| 원리 | 곡물을 고온에서 볶아 내부 수분을 5% 이하로 줄이고 단백질과 전분을 호화시킵니다. 수분이 없어 미생물이 자라지 못합니다. |
| 재료 | 보리, 찹쌀, 현미, 콩 등 (들깨나 참깨 같은 유지류 곡물은 기름 때문에 산패가 빨라 제외해야 합니다) |
| 보관 | 산소 흡수제와 함께 마일라 백에 넣어 서늘한 곳에 보관합니다. |

| 순서 | 제조 방법 |
| :---: | :--- |
| 1 | 곡물을 물에 깨끗이 씻은 후 찬물에 서너 시간 불립니다. |
| 2 | 불린 곡물을 찜기에 넣고 완전히 익을 때까지 찝니다. |
| 3 | 찐 곡물을 채반에 널어 수분이 사라질 때까지 건조합니다. |
| 4 | 수분이 빠진 곡물을 약불에서 고소한 냄새가 날 때까지 볶아줍니다. |
| 5 | 볶은 곡물을 완전히 식힌 후 믹서기나 절구로 곱게 갈아 가루로 만듭니다. |
