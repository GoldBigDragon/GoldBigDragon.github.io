## 5. 去毒加工、最后手段，以及采集的可持续性
&nbsp;&nbsp;&nbsp;野生植物中有不少这样的例子：生吃不能食用，但经过加工就能成为优质的食物。橡子、葛根和蕨菜就是代表，它们都是人类历经数千年摸索出去毒方法之后，才得以端上餐桌的。

---
### 5-1. 抗营养成分及其去除原理
&nbsp;&nbsp;&nbsp;植物在储藏器官中设置化学防御的原因很简单：积蓄淀粉和脂肪的部位，是动物眼中最具吸引力的目标，如果没有什么东西来保护它，种子就留不下来。所谓加工，就是利用这些防御物质的物理性质将其去除。

| 成分 | 存在于哪里 | 有什么作用 | 去除原理 |
| --- | --- | --- | --- |
| 单宁 | 橡子、葛根、未熟的柿子 | 与蛋白质结合阻碍消化，妨碍铁的吸收，并产生涩味 | 易溶于水，可通过换水浸泡去除 |
| 欧蕨苷 | 蕨菜 | 具有致癌性，会分解维生素B1 | 遇热不稳定且溶于水，焯水后再泡水即可去除 |
| 草酸 | 酸模、酢浆草、藜、大黄 | 与钙结合形成结石，大量摄入会损伤肾脏 | 焯水后的水必须倒掉 |
| 氰苷 | 杏和梅的核仁、银杏、木薯、亚麻籽 | 在体内生成氰化氢 | 泡水去除后，须充分加热或发酵 |
| 凝集素 | 豆类、红小豆、未熟的豆子 | 使红细胞凝集，引起剧烈呕吐和腹泻 | 充分泡发后彻底煮熟 |
| 皂苷 | 桔梗、部分根和种子 | 破坏红细胞并刺激肠胃 | 泡水去除后再加热 |
| 植酸 | 谷物麸皮、坚果、豆类 | 与锌、铁、钙结合，阻碍其吸收 | 泡水后发芽或发酵 |

&nbsp;&nbsp;&nbsp;橡子去除单宁的过程很好地展示了这一原理。单宁是溶于水的多酚，而淀粉不溶于冷水，这一溶解度差异正是分离的依据。将橡子去壳捣碎后泡入水中，每天换几次水，单宁就会随水流失，淀粉则留存下来。用冷水需要几天时间，但淀粉能完整保留，磨出的粉质量更好；用热水可以把时间缩短到几个小时，代价是淀粉会糊化、结块，出粉率下降。把整袋橡子浸在流动的溪水中的传统做法，其实就是把持续换水的工作交给了水流去完成。

&nbsp;&nbsp;&nbsp;蕨菜用的是另一种原理。欧蕨苷遇热不稳定，在碱性条件下更容易分解，因此仅仅用沸水焯烫就能破坏相当一部分。研究显示，加热5分钟可减少约60%，焯水后再用冷水浸泡数小时，剩下的部分也大多能去除。加入少量草木灰或苏打会使水呈碱性，从而加快分解。蕨菜必须焯水浸泡后才能吃的传统做法，正是经验得出的精确解法。

### 5-2. 通用食用可能性测试及其局限
&nbsp;&nbsp;&nbsp;美国陆军生存教范中记载的通用食用可能性测试，是一套试验未知植物的程序。其原理是把暴露量分成极小的单位，逐步增加，每一步都确认反应。

| 步骤 | 内容 | 等待时间 |
| :---: | --- | :---: |
| 1 | 只喝水、禁食 | 8小时 |
| 2 | 将叶、茎、根、花、种子分部位处理 | |
| 3 | 闻气味。有杏仁或桃核味、或有强烈恶臭的立即排除 | |
| 4 | 将汁液涂抹在手臂内侧娇嫩的皮肤上 | 8小时 |
| 5 | 尽可能加热 | |
| 6 | 轻触嘴唇外侧 | 3分钟 |
| 7 | 放在舌头上，不咀嚼 | 15分钟 |
| 8 | 咀嚼但不吞咽 | 15分钟 |
| 9 | 吞下极少量 | 8小时 |
| 10 | 吃下一小把 | 8小时 |

&nbsp;&nbsp;&nbsp;这套程序如果认真执行，需要24小时以上，期间不能吃其他东西。对已经挨饿的人来说，这本身就是相当大的代价。但更重要的是，有些毒这项测试根本查不出来。

| 局限 | 原因 |
| --- | --- |
| 对迟发性毒素无效 | 鹅膏毒肽潜伏期为6~24小时，8小时的等待无法将其筛出 |
| 对累积性毒素无效 | 像吡咯里西啶生物碱那样历经数月累积的毒，一次测试无法显现 |
| 对强效生物碱很危险 | 少量即可致命的物质，在测试阶段就已经造成中毒 |
| 完全不能用于蘑菇 | 蘑菇的主要毒素全部是迟发性的，测试通过之后人就已经中毒身亡 |
| 须按部位重新测试 | 叶片安全而种子致命的植物并不少见 |
| 结果因是否烹饪而不同 | 有些加热后变安全，有些加热后毒性依然残留，两者混杂在一起 |

> **通用食用可能性测试不是确认安全的方法，而是在完全没有其他选择时，用来稍稍降低风险的最后手段。无论何种情况都不能用于蘑菇。**

&nbsp;&nbsp;&nbsp;因此，这项测试的正确定位，不是采集知识的替代品，而是辅助手段。只要认识哪怕几种植物，只吃那些认识的植物永远更好；测试只有在一种都不认识、又没有其他食物来源的情况下才有意义。

### 5-3. 采集的可持续性
&nbsp;&nbsp;&nbsp;如果灾难不会在几天内结束，采集就不是一次性的收获，而会变成延续多年的关系。这时候，造成决定性差异的是采走植物的哪个部分。

| 采集方式 | 次年留下的东西 | 判断 |
| --- | --- | --- |
| 只取部分叶片和新芽 | 植株原样保留 | 可以反复采集 |
| 果实与种子 | 植株保留，但繁殖减少 | 需要留下一部分 |
| 整根茎干 | 多年生可恢复，一年生则消亡 | 因物种而异 |
| 根和鳞茎 | 植株消失 | 只能在群落的一部分中进行 |

&nbsp;&nbsp;&nbsp;实用的标准是：从一个群落中只取三分之一以下。挖根时应把这个比例定得更低，与其挖大的个体，不如像间苗一样从生长密集处挖取，这样留下的植株反而长得更好。楤木要只摘茎顶端的大芽、留下侧芽，树才能存活；如果连顶芽也全部摘光，那棵树就会枯死。像薤白和茖葱这类靠鳞茎繁殖的植物，应该只挑大的挖取，小的要重新埋回土里。

&nbsp;&nbsp;&nbsp;留种也很重要。如果在果实成熟前就全部摘光，这个群落就无法产生下一代。一年生植物尤其如此：如果当年没能留下种子，第二年这个地方就会不见踪影。把采集地点分成多处、轮流使用，也是出于同样的道理。年年搜刮同一个地方，用不了几年那里就会被采空，而这个损失最终会转嫁到人类自己身上。

### 5-4. 法律与伦理
&nbsp;&nbsp;&nbsp;本文档整理的内容，并不是平时可以照做的知识。在韩国，采集野生动植物受《野生生物保护及管理法》约束。被列为濒危野生生物的物种，全面禁止采集、保管和流通，本文档中提到的毒芹，就是这类被列为濒危物种的有毒植物之一。此外，在国立公园、道立公园和山林遗传资源保护区内，依据《自然公园法》和《山林保护法》禁止采集林产品；在私有林和国有林中未经许可采集林产品，可能构成违反《山地管理法》或触犯刑法上的盗窃罪。其他国家大多也有类似的规定。本文档是以公共体系无法运作的生存状况为前提整理的知识，在平时必须先确认读者所在国的野生生物保护法和森林相关法令，并只能在其规定范围内行事。

&nbsp;&nbsp;&nbsp;即便身处生存状况，也有不变的原则：只吃确实认识的东西，只采需要的量，并且留下足够下一季恢复的部分再离开。采集所得如何贮藏和加工，将在食品保存文档中继续讨论；如何确保热量的主要来源，则在农业文档中继续讨论。
