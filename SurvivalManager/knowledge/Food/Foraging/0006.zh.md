## 5. 去毒加工、最后手段与采集的可持续性
&nbsp;&nbsp;&nbsp;野生植物中有很多不能直接吃，经过加工却能成为优质粮食。橡子、葛和蕨菜是典型代表，它们都是人类花了数千年找到去毒方法之后才端上餐桌的。

---
### 5-1. 抗营养成分及其去除原理
&nbsp;&nbsp;&nbsp;植物在储存器官中设置化学防御，原因很简单。储存淀粉和脂肪的地方是对动物最有吸引力的目标，如果没有保护它的东西，种子就留不下来。加工，就是利用这些防御物质的物理性质把它们分离出去。

| 成分 | 存在于何处 | 作用 | 去除原理 |
| --- | --- | --- | --- |
| 单宁 | 橡子、葛、未熟的柿子 | 与蛋白质结合阻碍消化，妨碍铁的吸收，并产生涩味 | 易溶于水，因此反复换水浸泡去除 |
| 蕨苷 | 蕨菜 | 有致癌性，并分解维生素B1 | 怕热且溶于水，所以焯水后再浸泡 |
| 草酸 | 酸模、酢浆草、藜、大黄 | 与钙结合形成结石，大量摄入会损伤肾脏 | 焯过的水一定要倒掉 |
| 氰苷 | 杏和梅的核仁、银杏、木薯、亚麻籽 | 在体内产生氢氰酸 | 浸泡，充分加热或发酵 |
| 凝集素 | 豆类、红小豆、未熟的豆子 | 使红细胞凝集，引起剧烈呕吐和腹泻 | 充分泡发后完全煮熟 |
| 皂苷 | 桔梗、部分根和种子 | 破坏红细胞，刺激胃肠 | 浸泡后加热 |
| 植酸 | 谷物的麸皮、坚果、豆类 | 与锌、铁、钙结合，阻碍吸收 | 浸泡、催芽或发酵 |

&nbsp;&nbsp;&nbsp;去除橡子中的单宁很好地说明了这一原理。单宁是溶于水的多酚，而淀粉不溶于冷水。这种溶解度的差异就是分离的依据。把橡子去壳捣碎后泡在水里，每天换几次水，只有单宁会溶入水中流走，淀粉则留下。用冷水需要几天，但淀粉得以完整保存，粉的质量好；用热水可缩短到几小时，代价是淀粉糊化，粉结块，得率下降。把袋子整个浸在流动溪水里的传统方法，就是把不停换水的工作交给水流。

&nbsp;&nbsp;&nbsp;蕨菜用的是另一种原理。蕨苷对热不稳定，在碱性条件下更容易分解，所以仅用沸水焯一下就能破坏相当大的量。据研究，加热5分钟约减少60%，焯水后再用冷水浸泡数小时，剩余的大部分也会排出。加入少许草木灰或小苏打，水变成碱性，分解会加快。蕨菜一定要焯水浸泡后再吃的传统，是凭经验得到的准确办法。

### 5-2. 通用可食性测试及其局限
&nbsp;&nbsp;&nbsp;美军生存手册中的通用可食性测试，是用来试验不认识的植物的程序。原理是把摄入量分成极小的单位，每一步确认反应后再逐渐增加。

| 步骤 | 内容 | 等待时间 |
| :---: | --- | :---: |
| 1 | 只喝水，禁食 | 8小时 |
| 2 | 按叶、茎、根、花、种子分部位 | |
| 3 | 闻气味。杏仁或桃核的气味、强烈的恶臭要立即排除 | |
| 4 | 把汁液涂在前臂内侧柔嫩的皮肤上 | 8小时 |
| 5 | 可能的话加热煮熟 | |
| 6 | 轻轻贴在嘴唇外侧 | 3分钟 |
| 7 | 放在舌头上，不咀嚼 | 15分钟 |
| 8 | 咀嚼但不吞咽 | 15分钟 |
| 9 | 吞下极少量 | 8小时 |
| 10 | 吃一把左右 | 8小时 |

&nbsp;&nbsp;&nbsp;这个程序认真做下来要花24小时以上，期间不能吃别的东西。对已经挨饿的人来说，这本身就是相当大的代价。但更重要的是，有些毒是这个测试检测不出来的。

| 局限 | 原因 |
| --- | --- |
| 对迟发性毒素无能为力 | 鹅膏毒肽潜伏6-24小时，等待8小时无法筛出 |
| 对蓄积性毒素无能为力 | 像吡咯里西啶生物碱这样历时数月蓄积的毒，一次试验显现不出来 |
| 对强效生物碱有危险 | 少量就致命的物质，在试验阶段就已经发生中毒 |
| 绝对不能用于蘑菇 | 蘑菇的主要毒素全是迟发性的，测试放行之后人才会死去 |
| 必须按部位重新做 | 叶子安全而种子致命的植物并不少见 |
| 烹调与否会使结果不同 | 有些煮熟后变安全，有些煮熟后仍然残留 |

> **通用可食性测试不是确认安全的方法，而是在完全没有其他选择时稍微降低风险的最后手段。任何情况下都不用于蘑菇。**

&nbsp;&nbsp;&nbsp;因此，这个测试的正确定位不是采集知识的替代品，而是辅助手段。只要认识哪怕几种植物，就总是只吃那些更好，测试只有在一种都不认识、也没有其他食物来源的情况下才有意义。

### 5-3. 采集的可持续性
&nbsp;&nbsp;&nbsp;灾难如果不是几天就结束，采集就不是一次性的收获，而是持续多年的关系。这时决定性的差别在于取走植物的哪一部分。

| 采集方式 | 来年留下的 | 判断 |
| --- | --- | --- |
| 只采部分叶和嫩芽 | 植株完好留存 | 可重复采集 |
| 果实和种子 | 植株留存，但繁殖减少 | 要留下一部分 |
| 整根茎秆 | 多年生的能恢复，一年生的会消失 | 视物种而定 |
| 根和鳞茎 | 植株消失 | 只从群落的一部分采 |

&nbsp;&nbsp;&nbsp;实用的标准是，每个群落最多只取走三分之一。挖根时要把这个比例再调低，与其挖大的植株，不如从长得密的地方像间苗一样挖，这样剩下的植株反而长得好。楤木只摘茎顶端的大芽、留下侧芽，树才能存活，如果连各处的芽都摘光，这棵树就会死。像dallae和茖葱这样靠鳞茎繁殖的，要只挑大的挖，小的埋回去。

&nbsp;&nbsp;&nbsp;留下种子也很重要。果实在成熟前全部摘光，这个群落就无法繁衍下一代。尤其是一年生植物，当年留不下种子，来年就会从那个地方消失。把采集地点分成几处轮流使用，也是出于同样的原因。每年把一个地方采光，几年之内那里就空了，这一损失最终还是会回到人的身上。

### 5-4. 法律与伦理
&nbsp;&nbsp;&nbsp;本文档整理的内容，并不是平时可以照样实行的知识。在大韩民国，采集野生动植物受《野生生物保护与管理法》规范。被指定为濒危野生生物的物种，全面禁止采集、保管和流通，像本文档提到的毒芹那样，毒性植物中也有被指定为濒危物种的。另外，在国家公园、道立公园和山林遗传资源保护区，依据《自然公园法》和《山林保护法》禁止采集林产品，未经许可在私有林和国有林采集林产品，可能构成违反《山地管理法》以及《刑法》上的盗窃。其他国家大多也有出于同样目的的规定。本文档是以公共救援无法运转的生存状况为前提整理的知识，平时必须查阅所属国家的野生生物保护法和森林相关法令，并只在其范围内行动。

&nbsp;&nbsp;&nbsp;即使在生存状况下，也只吃确定认识的东西，只采需要的量，并留下来让它在下一个季节继续生长。采集所得如何储存和加工，在“食品保藏”文档中继续讲述，热量的核心如何获得，则在农业类文档中继续讲述。
