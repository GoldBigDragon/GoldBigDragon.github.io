## 2. 韓国でよく見られる食用野生植物と識別の形質
&nbsp;&nbsp;&nbsp;植物を見分ける作業でもっとも多い失敗は、一枚の写真から受けた印象に頼ることです。同じ種であっても、育った場所の日当たりや水分、時期によって大きさや色は大きく変わるため、見た目の印象だけでは区別できません。信頼できるのは、環境によってあまり変わらない形質です。

---
### 2-1. 何を見るべきか
&nbsp;&nbsp;&nbsp;次に挙げる形質は個体ごとにほとんど変わらないため、識別の基準になります。一つだけで結論を出さず、複数が同時に当てはまったときにのみ確定するのが原則です。

| 形質 | 何が分かるか |
| --- | --- |
| 葉脈の並び方 | 平行脈なら単子葉植物、網状脈なら双子葉植物です。科を絞り込む最初の手がかりです |
| 葉序 | 互生、対生、輪生は種ごとに決まっています |
| 毛の有無と種類 | 有無、柔らかいか硬いか、色まで見ます |
| 匂い | 葉をもんで嗅ぎます。ニンニク、セリ、当帰の香りは決定的な手がかりです |
| 乳液 | 切り口から出る白い汁や黄色い汁の有無 |
| 茎の断面 | 丸いか角ばっているか、中が詰まっているか空洞か |
| 根元と根 | 繊維に包まれているか、切り口がどんな構造か |
| 生育場所 | 水辺、乾いた斜面、日陰、林縁など生育条件 |

&nbsp;&nbsp;&nbsp;この中で匂いはとりわけ有用な形質です。植物の芳香物質は種に固有の二次代謝産物であるため個体差が小さく、道具なしですぐに確認できます。ギョウジャニンニクとスズランのように見た目が非常によく似た組み合わせでも、匂い一つで結論が出ます。ただし匂いを確認するときも、口に入れず、葉を指でもんで嗅ぐところまでにとどめなければなりません。

---
### 2-2. 一般的で比較的見分けやすい食用植物
&nbsp;&nbsp;&nbsp;以下は韓国の山野でよく見られ、識別の形質が比較的はっきりしている種です。ただし、ここに書かれている内容だけで現場で確定判断を下してはならず、実物を知る人に確認するか、図鑑と照合する手続きが必要です。

| 名前 | 時期と場所 | 識別の手がかり | 注意 |
| --- | --- | --- | --- |
| ヨモギ | 3~5月、日当たりの良い野原や土手 | 葉の裏が白い綿毛で覆われて白く見え、独特の香りが強い | 似たキク科が多いが、白い裏面と香りで区別します |
| ナズナ | 3~4月、畑の畔や道端 | 根出葉が地面に張り付いて放射状に広がり、根からナズナ特有の香りがします | 花が咲くと硬くなります |
| ノビル | 3~5月、畑の畔や林縁 | 細い円筒形の葉と丸い鱗茎、強いニンニク臭 | 匂いがなければノビルではありません |
| ニガナとゴドゥルペギ（苦味の山菜） | 3~5月、野原や道端 | 切ると白い乳液が出て味がとても苦い | 苦味は茹でてあく抜きすると薄れます |
| タンポポ | 3~6月、日当たりの良い場所 | 鋸歯が後ろ向きの根出葉、中が空洞の花茎、白い乳液 | 葉も根も利用できます |
| オオバコ | 4~9月、道端や空き地 | 葉に平行な太い脈が何本も入り、踏まれる場所に生える | 若葉だけが柔らかいです |
| ワスレグサ | 4~5月、山の斜面 | 平行脈の長い葉が根元から二列に扇状に広がります | 必ず茹でてあく抜きしなければなりません |
| タラの芽 | 4~5月、林縁 | とげのある茎の先につく新芽 | 必ず茹でる必要があり、脇芽は残します |
| サルナシとヤマブドウ | 8~10月、山すそのつる | サルナシはなめらかな緑色の実、ヤマブドウは黒く熟すぶどう房状 | つる性の実には毒性のものが多く、確認が必要です |
| ドングリ | 9~11月、ナラ類の下 | ナラ類の殻斗がついた木の実 | 必ずタンニンを抜かなければなりません |
| クリ | 9~10月、クリの木の下 | とげの多いイガの中の茶色い実 | 加工なしでそのまま食べられます |
| クズ | 通年、日当たりの良い斜面のつる | 三枚の広い葉、太くて長い根 | 根の澱粉だけを漉いて使います |
| ナガイモ | 10~11月、山すそのつる | ハート形の葉が対生し、葉のわきにむかごがつきます | 生でも食べられます |

&nbsp;&nbsp;&nbsp;この表には一つの規則が繰り返し現れています。熱量が大きいものほど加工が必要だという点です。ドングリとクズはタンニンを、タラの芽とワスレグサはそれ自体の刺激成分を抜かなければならず、これは偶然ではありません。植物が多くのエネルギーを蓄えた部位には、それを守るための化学的防御も一緒に備わっているからです。加工法はこの文書の最終章で扱います。

### 2-3. 木と水辺から得るもの
&nbsp;&nbsp;&nbsp;草だけを見ていると採集の半分を逃します。木は樹皮や樹液、実、葉を与えてくれ、特に冬と早春にはほぼ唯一の資源になります。

| 対象 | 時期 | 得られるもの | 原理と注意 |
| --- | --- | --- | --- |
| マツの内樹皮 | 通年、春がもっとも柔らかい | 澱粉と糖分 | 外樹皮の下の白い形成層だけを使います。幹を一周剥ぐと木が枯れます |
| シラカバとイタヤカエデの樹液 | 2~4月 | 糖分とミネラル | 根圧が上がる時期だけ出て、数日で傷みます |
| ナラ類とクリの木 | 9~11月 | ドングリとクリ | 最大の熱量源であり、貯蔵性も良好です |
| クワ | 6~7月 | 桑の実と若葉 | 葉は茹でて食べ、実はそのまま食べます |
| ノイバラとクマイチゴ | 5~7月 | 若芽と実 | バラ科の実はおおむね安全な部類です |
| ガマとヨシ | 通年 | 地下茎の澱粉、若芽 | 水辺を代表する澱粉源ですが、水質汚染に注意します |
| セリ | 3~5月、水辺 | 葉と茎 | ドクゼリと必ず区別しなければなりません |

&nbsp;&nbsp;&nbsp;水辺で採集するときは、植物そのものよりも水が問題になります。畜産施設や居住地の下流にある河川の水生植物は、大腸菌や寄生虫の卵、重金属を表面に付けていることがあります。上流に何があるか分からない場合、水辺の植物は必ず火を通して食べることで、肝吸虫や肺吸虫の感染リスクを下げられます。
