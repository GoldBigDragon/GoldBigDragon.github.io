## 2. 韓国でよく見られる食用野生植物と識別の形質
&nbsp;&nbsp;&nbsp;植物を見分けるときに最もよくある失敗は、写真一枚の印象に頼ることです。同じ種でも、育った場所の日当たりや水、時期によって大きさや色が大きく変わるため、見た目の印象だけでは区別できません。信頼できるのは、環境によってあまり変わらない形質です。

---
### 2-1. 何を見るべきか
&nbsp;&nbsp;&nbsp;次の形質は個体ごとにほとんど変わらないため、識別の基準になります。一つだけで結論を出さず、複数が同時に合うときにだけ確定するのが原則です。

| 形質 | 何がわかるか |
| --- | --- |
| 葉脈の並び方 | 平行脈なら単子葉植物、網状脈なら双子葉植物です。科を絞り込む最初の手がかりです |
| 葉序 | 互生、対生、輪生は種ごとに決まっています |
| 毛の有無と種類 | 有無、柔らかいか硬いか、色まで見ます |
| 匂い | 葉をもんで嗅ぎます。ニンニク、セリ、トウキの香りは決定的な手がかりです |
| 乳液 | 切り口から出る白い汁や黄色い汁の有無 |
| 茎の断面 | 丸いか角ばっているか、中が詰まっているか空洞か |
| 根元と根 | 繊維で包まれているか、切った断面がどのような構造か |
| 生育場所 | 水辺、乾いた斜面、日陰、森の縁などの生育条件 |

&nbsp;&nbsp;&nbsp;この中で匂いは、とりわけ役に立つ形質です。植物の芳香物質は種に固有の二次代謝産物なので個体差が小さく、道具なしですぐに確認できます。ギョウジャニンニクとスズランのように見た目がとてもよく似た組でも、匂い一つで結論が出ます。ただし、匂いを確認するときも口に入れず、葉を指でもんで嗅ぐだけにとどめます。

---
### 2-2. よく見られ、比較的見分けやすい食用植物
&nbsp;&nbsp;&nbsp;以下は、韓国の山や野原でよく見られ、識別の形質が比較的はっきりしている種です。ただし、ここに書かれた内容だけで現場で確定の判断を下してはならず、実物を知っている人に確認するか、図鑑と照合する手順が必要です。

| 名前 | 時期と場所 | 識別の手がかり | 注意 |
| --- | --- | --- | --- |
| ヨモギ | 3-5月、日当たりのよい野原や土手 | 葉の裏が白い綿毛に覆われて白く見え、特有の香りが強いです | 似たキク科が多いですが、白い裏面と香りで区別します |
| ナズナ | 3-4月、畑の畦道と道端 | 根生葉が地面に張りついて放射状に広がり、根からナズナの香りがします | 花が咲くと硬くなります |
| ダルレ(ヒメニラ) | 3-5月、畑の畦道と森の縁 | 細い円筒形の葉と丸い鱗茎、強いニンニクの匂い | 匂いがなければダルレではありません |
| ニガナとゴドゥルペギ | 3-5月、野原と道端 | 切ると白い乳液が出て、味がとても苦いです | 苦味は茹でて水にさらすと減ります |
| タンポポ | 3-6月、日当たりのよい場所 | 鋸歯が後ろ向きの根生葉、中空の花茎、白い乳液 | 葉も根も使えます |
| オオバコ | 4-9月、道端と空き地 | 葉に平行する太い脈が何本もあり、踏まれる場所に生えます | 若葉だけが柔らかいです |
| ワスレグサ | 4-5月、山の斜面 | 平行脈の長い葉が根元から2列に扇状に出ます | 必ず茹でて水にさらす必要があります |
| タラの芽 | 4-5月、森の縁 | とげのある幹の先に付く新芽 | 必ず茹でる必要があり、脇芽は残します |
| サルナシとヤマブドウ | 8-10月、山裾のつる | サルナシは滑らかな緑色の果実、ヤマブドウは黒く熟するブドウの房の形です | つる性の果実には有毒なものが多いので確認が必要です |
| ドングリ | 9-11月、ナラ類の木の下 | 殻斗の付いたナラ類の堅果 | 必ずタンニンを抜く必要があります |
| クリ | 9-10月、クリの木の下 | とげの多いイガの中の茶色い堅果 | 加工せずにすぐ食べられます |
| クズ | 通年、日当たりのよい斜面のつる | 3枚の幅広い葉、太く長い根 | 根のデンプンだけを濾して使います |
| ナガイモ | 10-11月、山裾のつる | ハート形の葉が対生し、葉の付け根にむかごが付きます | 生でも食べられます |

&nbsp;&nbsp;&nbsp;この表で繰り返される規則が一つあります。熱量が大きいものほど加工が必要だという点です。ドングリとクズはタンニンを、タラの芽とワスレグサはそれ自体の刺激成分を抜かなければならず、これは偶然ではありません。植物が多くのエネルギーを貯蔵した部位には、それを守るための化学的な防御も一緒に含まれているからです。加工法はこの文書の最後の章で扱います。

### 2-3. 木と水辺から得られるもの
&nbsp;&nbsp;&nbsp;草だけを見ていると、採集の半分を逃します。木は樹皮と樹液、果実、葉をもたらし、特に冬と早春には、ほとんど唯一の資源になります。

| 対象 | 時期 | 得られるもの | 原理と注意 |
| --- | --- | --- | --- |
| マツの内樹皮 | 通年、春が最も柔らかい | デンプンと糖分 | 外樹皮の下の白い形成層だけを使います。幹を一周剥ぐと木が枯れます |
| シラカバとイタヤカエデの樹液 | 2-4月 | 糖分とミネラル | 根圧が上がる時期にしか出ず、数日で傷みます |
| ナラ類とクリの木 | 9-11月 | ドングリとクリ | 最大の熱量源で、保存性もよいです |
| クワ | 6-7月 | 桑の実と若葉 | 葉は茹でて、果実はそのまま食べます |
| ノイバラとクマイチゴ | 5-7月 | 若芽と果実 | バラ科の果実は概して安全なほうです |
| ガマとヨシ | 通年 | 根茎のデンプン、若芽 | 水辺の代表的なデンプン源ですが、水質汚染に注意します |
| セリ | 3-5月、水辺 | 葉と茎 | ドクゼリと必ず区別しなければなりません |

&nbsp;&nbsp;&nbsp;水辺で採集するときは、植物そのものより水が問題です。畜産施設や居住地の下流の河川にある水生植物は、表面に大腸菌や寄生虫の卵、重金属を帯びていることがあります。上流に何があるかわからない場合、水辺の植物は必ず加熱して食べなければ、肝吸虫と肺吸虫の感染リスクを下げられません。
