## 4. 毒キノコと誤った通説
&nbsp;&nbsp;&nbsp;キノコは採集の対象の中で、危険と見返りの比率が最も悪いものです。熱量は100gあたり20-40kcalで葉物と変わらないのに、選び間違えたときの結果は他のどの採集物より致命的です。それでもキノコ中毒が絶えない理由は、キノコについて広く知られている見分け方が、ほぼすべて間違っているからです。

---
### 4-1. 通説がすべて間違っている理由
&nbsp;&nbsp;&nbsp;次は韓国で最も広く知られている毒キノコの見分け方であり、どれも事実ではありません。食品医薬品安全処と山林庁、農村振興庁が毎年同じ内容を繰り返し警告しているのも、これらの通説が実際の死亡事故の原因になっているからです。

| 通説 | 事実 |
| --- | --- |
| 縦によく裂けるキノコは食べられます | 猛毒キノコであるドクツルタケとシロタマゴテングタケも縦にきれいに裂けます。裂ける方向はヒダの並びから来る物理的な性質にすぎず、毒性とは無関係です |
| 虫が食ったものは安全です | 昆虫やナメクジは、アマトキシンの標的酵素が人と異なるため影響を受けません。猛毒キノコにも虫食いの跡がそのまま残っています |
| 色が派手ならば毒キノコです | 最も致命的なアマトキシン系のキノコは、大半が純白です。逆に、鮮やかなオレンジ色のタマゴタケは食用です |
| 銀のスプーンを入れて黒く変色すれば毒キノコです | 銀は硫黄化合物と反応して変色します。アマトキシンには反応せず、ニンニクや卵のようなありふれた食品のほうがむしろ銀を変色させます |
| 煮たり塩漬けにしたりすれば毒が抜けます | アマトキシンは熱に非常に安定しており、煮ても分解されず、乾燥させても残ります |
| ナスやエゴマ油と一緒に調理すれば中和されます | まったく根拠がありません |
| 柄に輪(つば)がなければ安全です | 輪は種を絞り込む手がかりにすぎず、毒性の指標ではありません |

> **キノコには、安全なものを選り分ける一般的な規則が存在しません。一つ一つの種を知る以外に方法はありません。**

&nbsp;&nbsp;&nbsp;これらの通説がなくならないのには理由があります。スーパーで売られているキノコの大半は実際に毒がないため、間違った規則を使っても何事もなく済む場合が圧倒的に多いのです。人はこの成功を規則の証拠として受け取りますが、実際は猛毒キノコに出会っていないだけです。一度出会った瞬間、それまでの成功は何の意味も持ちません。

---
### 4-2. アマトキシン - 遅れて来る毒
&nbsp;&nbsp;&nbsp;キノコ中毒による死亡の大半は、アマトキシン系の一つが引き起こします。韓国ではドクツルタケ、シロタマゴテングタケ、コタマゴテングタケがこれに当たり、いずれもナラの森に多く、食用キノコと見た目が似ています。

&nbsp;&nbsp;&nbsp;アマトキシンが特に危険なのは、毒性の強さよりも作用の仕方のためです。この毒素は、細胞が遺伝情報を読んでタンパク質を作るのに必要なRNAポリメラーゼIIを遮断します。すると細胞はすぐには死なず、タンパク質を新しく作れないまま徐々に機能を失います。タンパク質の回転率が最も高い肝細胞と腎臓の尿細管細胞が先に崩れ、この遅れが臨床経過を特異なものにします。

| 段階 | 時点 | 状態 |
| --- | :---: | --- |
| 潜伏期 | 摂取後6-24時間 | 症状はありません。この間に毒素はすでに肝臓に入っています |
| 消化管期 | 6-24時間以降 | 激しい嘔吐と下痢、腹痛、ひどい脱水が始まります |
| みかけの回復期 | 摂取後24-36時間 | 症状が治まり、回復したように見えます。この時期に治療を中断すると致命的です |
| 肝不全期 | 摂取後3-5日 | 肝細胞の壊死が進み、黄疸と出血、多臓器不全に至ります |

&nbsp;&nbsp;&nbsp;みかけの回復期があるという事実が、この中毒の最も危険な特徴です。嘔吐と下痢が止まると、人は治ったと判断し、医療現場でも単なる胃腸炎と誤認して帰宅させた例が報告されています。しかしこの時期に肝細胞はすでに破壊されており、症状が再び現れたときには、肝移植以外に選択肢がない場合が多いです。

&nbsp;&nbsp;&nbsp;致死量もきわめて少量です。アマトキシンの致死量は体重1kgあたり0.1mg程度で、キノコ1本に最大15mgが含まれていることがあります。体重60kgの成人の致死量が6mgなので、キノコ1本を分けて食べた複数の人が同時に中毒になることが実際に起こります。

&nbsp;&nbsp;&nbsp;食用キノコと一緒に生えているという点も、問題を大きくします。一つの群れから採ったキノコのうち、1、2本だけ別の種であっても、全体が危険になります。そのためキノコは群れではなく個体単位で確認しなければならず、混ぜて入れないのが原則です。

### 4-3. 他の系統のキノコの毒
&nbsp;&nbsp;&nbsp;アマトキシンのほかにも複数の系統があり、それぞれ症状と時間が異なります。発現が早い毒は、たいてい回復しますが、6時間が過ぎてから症状が始まる場合は、ほぼすべて危険な系統です。

| 系統 | 代表的なキノコ | 症状の開始 | 主な損傷 |
| --- | --- | :---: | --- |
| アマトキシン | ドクツルタケ、シロタマゴテングタケ | 6-24時間 | 肝臓と腎臓、致死率が高いです |
| オレラニン | フウセンタケ属の一部 | 2-20日 | 腎不全、潜伏期が最も長いです |
| ジロミトリン | シャグマアミガサタケ | 6-12時間 | 肝臓と神経 |
| ムスカリン | アセタケ属、カヤタケ属 | 15分-2時間 | 発汗、流涎、徐脈 |
| イボテン酸とムシモール | テングタケ属(イボテングタケ、テングタケなど) | 30分-2時間 | 錯乱と幻覚、けいれん |
| 消化管刺激物質 | ニガクリタケ、オオワライタケなど多数 | 30分-3時間 | 嘔吐と下痢、たいてい回復します |
| コプリン | ヒトヨタケ | 酒と一緒に食べたとき | 紅潮と動悸 |
| トリコテセン | カエンタケ | 30分以内 | 少量でも致命的で、触れることも避けます |

&nbsp;&nbsp;&nbsp;ここから実用的な規則が一つ出てきます。キノコを食べて6時間以内に症状が現れたなら、たいてい回復する系統であり、6時間が過ぎてから初めて症状が現れたなら、肝臓や腎臓を狙う系統である可能性が高いです。ただしこの規則は診断の参考にとどまり、採集の基準にはなりません。すでに食べた後の話だからです。

&nbsp;&nbsp;&nbsp;サバイバル状況でキノコに対する最も合理的な判断は、手を出さないことです。キノコが与える熱量は葉物の水準で、同じ時間にドングリを拾えば数十倍の熱量が得られます。失うかもしれないものと得られるものの大きさが比べものにならないので、確実に知っている数種でなければ、キノコは採集の対象から外すほうがよいです。
