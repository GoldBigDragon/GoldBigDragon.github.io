## 4. 毒キノコと誤った俗説
&nbsp;&nbsp;&nbsp;キノコは採集対象の中で、危険と見返りの比率がもっとも悪いものです。熱量は100gあたり20~40kcalと葉物と変わらないのに、選び間違えたときの結果は他のどの採集物よりも致命的です。それでもキノコ中毒が絶えない理由は、キノコに関して広く知られている見分け方が、ほぼすべて間違っているからです。

---
### 4-1. 俗説がすべて間違っている理由
&nbsp;&nbsp;&nbsp;以下は韓国でもっとも広く知られている毒キノコの見分け方ですが、どれも事実ではありません。韓国食品医薬品安全処と韓国山林庁、韓国農村振興庁が毎年同じ内容を繰り返し警告しているのも、これらの俗説が実際の死亡事故の原因になっているからです。

| 俗説 | 事実 |
| --- | --- |
| 縦にきれいに裂ければ食べられる | 猛毒キノコであるドクツルタケやシロタマゴテングタケも縦にきれいに裂けます。裂ける方向はひだの並び方に由来する物理的性質にすぎず、毒性とは無関係です |
| 虫に食われたものは安全だ | 昆虫やナメクジはアマトキシンの標的酵素が人間と異なるため影響を受けません。猛毒キノコにも虫食いの跡はそのまま残ります |
| 色が派手なら毒キノコだ | もっとも致命的なアマトキシン系のキノコは大半が純白です。逆に鮮やかな橙色のタマゴタケは食用です |
| 銀のスプーンを入れて黒く変色すれば毒キノコだ | 銀は硫黄化合物と反応して変色します。アマトキシンには反応せず、ニンニクや卵のようなありふれた食品のほうがむしろ銀を変色させます |
| 茹でるか塩漬けにすれば毒が抜ける | アマトキシンは熱にきわめて安定しており、茹でても分解されず、乾燥させても残ります |
| ナスやエゴマ油と一緒に調理すれば中和される | 何の根拠もありません |
| 柄にツバがなければ安全だ | ツバは種を絞り込む手がかりにすぎず、毒性の指標ではありません |

> **キノコには安全なものを見分ける一般的な規則は存在しません。種を一つ一つ知る以外に方法はありません。**

&nbsp;&nbsp;&nbsp;こうした俗説がなくならないのには理由があります。スーパーで売られているキノコの大半は実際に毒がないため、間違った規則を使っても何も起こらずに済む場合が圧倒的に多いのです。人はこの成功を規則の証拠として受け止めますが、実際にはただ猛毒キノコに出会わなかっただけです。一度出会った瞬間、それまでの成功にはまったく意味がなくなります。

---
### 4-2. アマトキシン - 遅れてやってくる毒
&nbsp;&nbsp;&nbsp;キノコ中毒による死亡の大半は、アマトキシン系のたった一種類が引き起こします。韓国ではドクツルタケ、シロタマゴテングタケ、コタマゴテングタケがこれに該当し、いずれもナラ類の林に多く、食用キノコと見た目が似ています。

&nbsp;&nbsp;&nbsp;アマトキシンが特別に危険なのは、毒性の強さよりも作用の仕方によるものです。この毒素は、細胞が遺伝情報を読み取ってタンパク質を作るのに必要なRNAポリメラーゼIIを遮断します。すると細胞はすぐには死なず、新しくタンパク質を作れないまま徐々に機能を失っていきます。タンパク質の代謝回転がもっとも速い肝細胞と腎臓の尿細管細胞が真っ先に破綻し、この遅れが臨床経過を特異なものにします。

| 段階 | 時点 | 状態 |
| --- | :---: | --- |
| 潜伏期 | 摂取後6~24時間 | まったく症状がありません。この間に毒素はすでに肝臓に入り込んでいます |
| 消化器期 | 6~24時間以降 | 激しい嘔吐と下痢、腹痛、ひどい脱水が始まります |
| 見かけ上の回復期 | 摂取後24~36時間 | 症状が治まり、回復したように見えます。この時期に治療を中断すると致命的です |
| 肝不全期 | 摂取後3~5日 | 肝細胞壊死が進み、黄疸と出血、多臓器不全へとつながります |

&nbsp;&nbsp;&nbsp;見かけ上の回復期があるという事実が、この中毒のもっとも危険な特徴です。嘔吐と下痢が治まると、人は治ったと判断してしまい、医療現場でも単純な胃腸炎と誤認して帰宅させてしまう例が報告されています。しかしこの時期にも肝細胞はすでに破壊が進んでおり、症状が再び現れたときには肝移植以外に選択肢がない場合が多いのです。

&nbsp;&nbsp;&nbsp;致死量もきわめて少量です。アマトキシンの致死量は体重1kgあたり0.1mg程度であり、キノコ1個に最大15mgが含まれていることがあります。体重60kgの成人の致死量が6mgであるため、キノコ1個を分け合って食べた複数の人が同時に中毒する事態が実際に起こります。

&nbsp;&nbsp;&nbsp;食用キノコと一緒に生えるという点も問題を大きくします。ひとまとめに摘んだキノコのうち一つか二つだけ別の種であっても、全体が危険になります。そのためキノコはまとめてではなく個体ごとに確認しなければならず、混ぜて入れないことが原則です。

---
### 4-3. 他の系統のキノコ毒
&nbsp;&nbsp;&nbsp;アマトキシン以外にもいくつもの系統があり、それぞれ症状と時間が異なります。発現が速い毒はたいてい回復しますが、6時間が過ぎてから症状が始まる場合は、ほぼすべてが危険な系統です。

| 系統 | 代表的なキノコ | 症状の開始 | 主な損傷 |
| --- | --- | :---: | --- |
| アマトキシン | ドクツルタケ、シロタマゴテングタケ | 6~24時間 | 肝臓と腎臓、致死率が高いです |
| オレラニン | フウセンタケ属の一部 | 2~20日 | 腎不全、潜伏期がもっとも長いです |
| ジロミトリン | シャグマアミガサタケ | 6~12時間 | 肝臓と神経 |
| ムスカリン | アセタケ属、カヤタケ属 | 15分~2時間 | 発汗、よだれ、徐脈 |
| イボテン酸とムッシモール | ベニテングタケ、テングタケ | 30分~2時間 | 錯乱と幻覚、けいれん |
| 消化器刺激物質 | ニガクリタケ、ツキヨタケなど多数 | 30分~3時間 | 嘔吐と下痢、たいていは回復します |
| コプリン | ヨウシュヒトヨタケ | 酒と一緒に食べたとき | 紅潮と動悸 |
| トリコテセン | カエンタケ | 30分以内 | 少量でも致命的で、触れることも避けます |

&nbsp;&nbsp;&nbsp;ここから実用的な規則が一つ導き出せます。キノコを食べて6時間以内に症状が現れた場合はたいてい回復する系統であり、6時間過ぎてから初めて症状が現れた場合は肝臓や腎臓を狙う系統である可能性が高いということです。ただしこの規則は診断の参考になるだけで、採集の基準にはなり得ません。すでに食べたあとの話だからです。

&nbsp;&nbsp;&nbsp;生存状況においてキノコに対するもっとも合理的な判断は、手を出さないことです。キノコが与えてくれる熱量は葉物と同程度であり、同じ時間でドングリを拾えば数十倍の熱量が得られます。失う可能性のあるものと得られるものの大きさが釣り合わないため、確実に分かる数種でない限り、キノコは採集リストから外すほうがよいのです。
