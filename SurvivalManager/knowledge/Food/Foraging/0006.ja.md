## 5. 毒を抜く加工、最後の手段、そして採集の持続可能性
&nbsp;&nbsp;&nbsp;野生植物の中には、そのままでは食べられなくても、加工すれば優れた食料になるものが多くあります。ドングリとクズ、ワラビが代表的で、これらはいずれも、人が数千年かけて毒を除く方法を見つけ出した結果として食卓に上がったものです。

---
### 5-1. 抗栄養成分とそれを抜く原理
&nbsp;&nbsp;&nbsp;植物が貯蔵器官に化学的な防御を置く理由は単純です。デンプンと脂肪を蓄えた場所は動物にとって最も魅力的な標的であり、それを守る何かがなければ種子が残らないからです。加工とは、この防御物質の物理的な性質を利用して取り除くことです。

| 成分 | どこにあるか | 何をするか | 除去の原理 |
| --- | --- | --- | --- |
| タンニン | ドングリ、クズ、未熟な柿 | タンパク質と結合して消化を妨げ、鉄の吸収を邪魔し、渋みを出します | 水によく溶けるので、水を替えながらさらします |
| プタキロサイド | ワラビ | 発がん性があり、ビタミンB1を分解します | 熱に弱く水に溶けるので、茹でた後に水にさらします |
| シュウ酸 | スイバ、カタバミ、シロザ、ダイオウ | カルシウムと結合して結石を作り、多量では腎臓を損傷させます | 茹でた湯を必ず捨てます |
| シアン配糖体 | アンズとウメの種、ギンナン、キャッサバ、アマの種 | 体内でシアン化水素を作ります | 水にさらし、十分に加熱するか、発酵させます |
| レクチン | マメ類、アズキ、未熟な豆 | 赤血球を凝集させ、ひどい嘔吐と下痢を起こします | 十分に水で戻した後、完全に茹でます |
| サポニン | キキョウ、一部の根と種子 | 赤血球を破壊し、胃腸を刺激します | 水にさらして加熱します |
| フィチン酸 | 穀物のぬか、堅果、豆 | 亜鉛、鉄、カルシウムと結合して吸収を妨げます | 水に浸し、発芽させるか発酵させます |

&nbsp;&nbsp;&nbsp;ドングリのタンニン除去は、原理をよく示しています。タンニンは水に溶けるポリフェノールであり、デンプンは冷たい水には溶けません。この溶解度の違いが分離の根拠です。ドングリの殻をむいて砕き、水に浸して、水を1日に何度も替えると、タンニンだけが水に抜け出し、デンプンが残ります。冷たい水では数日かかりますが、デンプンがそのまま保たれるため粉の質がよく、熱い水を使うと数時間に短縮される代わりに、デンプンが糊化して粉が固まり、収量が下がります。流れる小川に袋ごと浸けておく伝統的な方法は、水を替え続ける作業を水の流れに任せたものです。

&nbsp;&nbsp;&nbsp;ワラビは別の原理を使います。プタキロサイドは熱に不安定で、アルカリでよりよく分解されるため、沸騰した湯で茹でるだけでもかなりの量が壊れます。研究によると、5分の加熱で約60%が減り、茹でた後に冷たい水に数時間浸しておくと、残りの大半も抜けます。灰や重曹を少し入れると、水がアルカリ性になって分解が早まります。ワラビを必ず茹でて水にさらして食べる伝統は、経験から得た正確な解決策です。

### 5-2. 汎用の可食性テストとその限界
&nbsp;&nbsp;&nbsp;米軍のサバイバル教範に載っている汎用可食性テストは、見知らぬ植物を試験する手順です。原理は、摂取量をごく小さな単位に分け、段階ごとに反応を確認しながら増やしていくことです。

| 段階 | 内容 | 待機時間 |
| :---: | --- | :---: |
| 1 | 水だけを飲んで絶食します | 8時間 |
| 2 | 葉、茎、根、花、種子に部位を分けます | |
| 3 | 匂いを嗅ぎます。アーモンドや桃の種の匂い、ひどい悪臭は直ちに除外します | |
| 4 | 汁を腕の内側の柔らかい皮膚にこすりつけます | 8時間 |
| 5 | 可能なら加熱します | |
| 6 | 唇の外側に軽く当てます | 3分 |
| 7 | 舌の上に載せ、噛みません | 15分 |
| 8 | 噛みますが、飲み込みません | 15分 |
| 9 | ごく少量を飲み込みます | 8時間 |
| 10 | 一握り程度を食べます | 8時間 |

&nbsp;&nbsp;&nbsp;この手順は、きちんと行うと24時間以上かかり、その間は他のものを食べられません。すでに飢えている人にとっては、それ自体がかなりの負担です。しかしそれより重要なのは、このテストでは見つけられない毒があるという事実です。

| 限界 | 理由 |
| --- | --- |
| 遅効性の毒には無力です | アマトキシンは6-24時間潜伏するため、8時間の待機では選別できません |
| 蓄積性の毒には無力です | ピロリジジンアルカロイドのように数か月かけて蓄積する毒は、一度の試験では表に出ません |
| 強いアルカロイドには危険です | 少量でも致命的な物質は、試験の段階ですでに中毒が起こります |
| キノコには絶対に使えません | キノコの主な毒はすべて遅効性で、テストを通過させた後に人が死にます |
| 部位ごとにやり直す必要があります | 葉は安全でも種子は致命的な植物が珍しくありません |
| 調理の有無によって結果が変わります | 加熱すると安全になるものと、加熱しても残るものが混在しています |

> **汎用可食性テストは、安全を確認する方法ではなく、他の選択肢がまったくないときに危険を少し減らす最後の手段です。キノコには、どんな場合も使いません。**

&nbsp;&nbsp;&nbsp;したがって、このテストの正しい位置づけは、採集の知識の代わりではなく補助手段です。知っている植物が数種でもあれば、それだけを食べるほうが常によく、テストは、知っているものが一つもなく、他の食料源もない状況でのみ意味があります。

### 5-3. 採集の持続可能性
&nbsp;&nbsp;&nbsp;災害が数日で終わらないなら、採集は一度の収穫ではなく、何年にもわたる関係になります。このとき決定的な違いを生むのは、植物のどの部分を持っていくかです。

| 採取方法 | 翌年に残るもの | 判断 |
| --- | --- | --- |
| 葉と新芽の一部だけ | 個体がそのまま残ります | 繰り返し採集できます |
| 果実と種子 | 個体は残りますが、繁殖が減ります | 一部を残しておく必要があります |
| 茎全体 | 多年草なら回復し、一年草なら消滅します | 種によって異なります |
| 根と鱗茎 | 個体が消えます | 群落の一部からだけ行います |

&nbsp;&nbsp;&nbsp;実用的な基準は、一つの群落から3分の1以下だけを持っていくことです。根を掘るときはこの割合をさらに下げ、大きな個体よりも密に生えている所から間引くように掘ると、残った個体のほうがかえってよく育ちます。タラノキは、茎の先の大きな芽だけを摘んで脇芽を残せば木が生き残り、芽を先の先まですべて摘み尽くすと、その木は枯れます。ダルレやギョウジャニンニクのように鱗茎で増えるものは、大きなものだけを選んで掘り、小さなものは埋め戻しておかなければなりません。

&nbsp;&nbsp;&nbsp;種子を残すことも重要です。実が熟す前にすべて摘んでしまうと、その群落は次の世代を作れません。特に一年草は、その年に種子を残せなければ、翌年にその場所から消えます。採集場所を複数に分けて順番に使うのも、同じ理由で有効です。一か所を毎年さらうと、数年のうちにその場所が空になり、その損失は結局、人に返ってきます。

### 5-4. 法と倫理
&nbsp;&nbsp;&nbsp;この文書にまとめた内容は、平常時にそのまま実行できる知識ではありません。大韓民国では、野生動植物の採取は野生生物保護及び管理に関する法律の規律を受けます。絶滅危惧野生生物に指定された種は、採取と保管、流通が全面的に禁止されており、この文書で言及したドクゼリのように、有毒植物の中にも絶滅危惧種に指定されたものがあります。また、国立公園と道立公園、山林遺伝資源保護区域では、自然公園法と山林保護法により林産物の採取が禁止され、私有林と国有林で許可なく林産物を採取すると、山地管理法の違反や刑法上の窃盗に当たることがあります。他の国にも、ほとんど同じ趣旨の規制があります。この文書は、公的な救助が機能しないサバイバル状況を前提とした知識の整理であり、平常時は必ず所属する国の野生生物保護法と森林関連法令を確認し、その範囲内でのみ行わなければなりません。

&nbsp;&nbsp;&nbsp;サバイバル状況でも、確実に知っているものだけを食べ、必要な分だけを採り、次の季節に生えるように残しておかなければなりません。採集で得たものをどのように保存し加工するかは「食品保存」の文書で、熱量の中心をどのように確保するかは農業に関する文書で続きます。
