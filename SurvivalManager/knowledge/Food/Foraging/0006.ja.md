## 5. 毒抜き加工、最後の手段、そして採集の持続可能性
&nbsp;&nbsp;&nbsp;野生植物の中には、そのままでは食べられないものの、加工すれば優れた食料になるものが多くあります。ドングリとクズ、ワラビが代表例であり、これらはすべて人が数千年かけて毒を抜く方法を見つけ出した結果、食卓に上るようになったものです。

---
### 5-1. 抗栄養成分とそれを抜く原理
&nbsp;&nbsp;&nbsp;植物が貯蔵器官に化学的防御を備える理由は単純です。澱粉と脂肪をためた部分は動物にとってもっとも魅力的な標的であるため、それを守る何かがなければ種子は残らないからです。加工とは、この防御物質の物理的性質を利用して取り除くことです。

| 成分 | どこにあるか | 何をするか | 除去の原理 |
| --- | --- | --- | --- |
| タンニン | ドングリ、クズ、渋柿 | タンパク質と結合して消化を妨げ、鉄の吸収を阻害し、渋味を出します | 水に溶けやすいため、水を替えながら抜きます |
| プタキロシド | ワラビ | 発がん性があり、ビタミンB1を分解します | 熱に弱く水に溶けるため、茹でてから水に浸けて抜きます |
| シュウ酸 | スイバ、カタバミ、シロザ、ダイオウ | カルシウムと結合して結石を作り、大量では腎臓を損傷させます | 茹でた湯は必ず捨てます |
| シアン配糖体 | アンズとウメの種、銀杏、キャッサバ、亜麻仁 | 体内でシアン化水素を作ります | 水に浸けて抜き、十分に加熱するか発酵させます |
| レクチン | 豆類、アズキ、未熟な豆 | 赤血球を凝集させ、激しい嘔吐と下痢を引き起こします | 十分に浸水させてから完全に煮ます |
| サポニン | キキョウ、一部の根と種子 | 赤血球を破壊し、胃腸を刺激します | 水に浸けて抜き、加熱します |
| フィチン酸 | 穀物のぬか、木の実、豆 | 亜鉛、鉄、カルシウムと結合して吸収を妨げます | 水に浸け、発芽させるか発酵させます |

&nbsp;&nbsp;&nbsp;ドングリのタンニン抜きは原理をよく示しています。タンニンは水に溶けるポリフェノールで、澱粉は冷水には溶けません。この溶解度の差が分離の根拠です。ドングリの皮をむいて砕き、水に浸して一日に何度か水を替えると、タンニンだけが水に流れ出て澱粉は残ります。冷水では数日かかりますが澱粉がそのまま保たれて粉の質が良く、お湯を使うと数時間に短縮できる代わりに澱粉が糊化して粉が固まり、収率が落ちます。流れる小川に袋ごと浸けておく伝統的な方法は、水を替え続ける作業を水の流れに任せたものです。

&nbsp;&nbsp;&nbsp;ワラビは別の原理を使います。プタキロシドは熱に不安定で、アルカリ性でより分解されやすいため、熱湯で茹でるだけでもかなりの量が壊れます。研究によれば5分の加熱で約60%が減少し、茹でたあと冷水に数時間浸けておけば残った量の大部分も抜けます。灰や重曹を少し加えると水がアルカリ性になり、分解が速まります。ワラビを必ず茹でてあく抜きして食べる伝統は、経験から得られた正確な解決法です。

### 5-2. 汎用食用可能性テストとその限界
&nbsp;&nbsp;&nbsp;米陸軍のサバイバル教範に載っている汎用食用可能性テストは、見知らぬ植物を試す手順です。原理は、曝露量をごく小さな単位に分けて、段階ごとに反応を確認しながら増やしていくというものです。

| 段階 | 内容 | 待機時間 |
| :---: | --- | :---: |
| 1 | 水だけを飲んで断食します | 8時間 |
| 2 | 葉、茎、根、花、種子に部位を分けます | |
| 3 | 匂いを嗅ぎます。アーモンドや桃の種の匂い、ひどい悪臭は即座に除外します | |
| 4 | 汁を腕の内側の柔らかい皮膚にこすりつけます | 8時間 |
| 5 | 可能なら加熱します | |
| 6 | 唇の外側に軽く触れさせます | 3分 |
| 7 | 舌の上に乗せ、噛みません | 15分 |
| 8 | 噛みますが飲み込みません | 15分 |
| 9 | ごく少量を飲み込みます | 8時間 |
| 10 | 一握り程度を食べます | 8時間 |

&nbsp;&nbsp;&nbsp;この手順はきちんと行うと24時間以上かかり、その間は他のものを食べられません。すでに飢えている人にとっては、それ自体がかなりの負担です。しかし、より重要なのは、このテストでは見つけられない毒があるという事実です。

| 限界 | 理由 |
| --- | --- |
| 遅発性の毒に無力です | アマトキシンは6~24時間潜伏するため、8時間の待機ではふるい落とせません |
| 蓄積性の毒に無力です | ピロリジジンアルカロイドのように数か月かけて蓄積する毒は、一度のテストでは現れません |
| 強いアルカロイドには危険です | 少量でも致命的な物質は、テストの段階ですでに中毒が起こります |
| キノコにはまったく使えません | キノコの主な毒はすべて遅発性であり、テストを通過させたあとで人が死にます |
| 部位ごとにやり直す必要があります | 葉は安全でも種子は致命的な植物が珍しくありません |
| 調理の有無で結果が変わります | 加熱すれば安全になるものと、加熱しても残るものが混在しています |

> **汎用食用可能性テストは安全を確認する方法ではなく、他に選択肢がまったくないときに危険をわずかに減らすための最後の手段です。キノコにはどんな場合にも使いません。**

&nbsp;&nbsp;&nbsp;したがって、このテストの正しい位置づけは、採集知識の代わりではなく補助手段です。知っている植物が何種類かあるなら、それだけを食べるほうが常に優れており、テストは知っているものが一つもなく、他に食料源もない状況でのみ意味を持ちます。

### 5-3. 採集の持続可能性
&nbsp;&nbsp;&nbsp;災害が数日で終わらないなら、採集は一度きりの収穫ではなく、何年にもわたる関係になります。このとき決定的な違いを生むのは、植物のどの部分を持ち去るかです。

| 採取方法 | 翌年に残るもの | 判断 |
| --- | --- | --- |
| 葉と新芽の一部だけ | 個体がそのまま残ります | 繰り返しの採集が可能です |
| 実と種子 | 個体は残るが繁殖が減ります | 一部を残しておく必要があります |
| 茎全体 | 多年生なら回復、一年生なら消滅 | 種によって異なります |
| 根と鱗茎 | 個体が消えます | 群落の一部でのみ行います |

&nbsp;&nbsp;&nbsp;実用的な基準は、一つの群落から3分の1以下だけを持ち去ることです。根を掘るときはこの割合をさらに下げ、大きな個体よりも密集して生えている場所から間引くように掘ると、残った個体のほうがむしろよく育ちます。タラの芽は茎の先の大きな芽だけを摘み、脇芽は残さなければ木が生き残れず、先端の芽まですべて摘むとその木は枯れます。ノビルやギョウジャニンニクのように鱗茎で増えるものは、大きいものだけを選んで掘り、小さいものは埋め戻しておかなければなりません。

&nbsp;&nbsp;&nbsp;種子を残すことも重要です。実が熟す前にすべて摘み取ってしまうと、その群落は次の世代を作れません。特に一年生植物は、その年に種子を残せなければ翌年その場所から姿を消します。採集場所を複数に分けて順番に使うことも、同じ理由で有効です。一か所を毎年根こそぎ採ると数年のうちにそこが空になり、その損失は結局人間自身に返ってきます。

### 5-4. 法と倫理
&nbsp;&nbsp;&nbsp;この文書にまとめた内容は、平時にそのまま実行できる知識ではありません。韓国では、野生動植物の採取は「野生生物の保護及び管理に関する法律」の規律を受けます。絶滅危惧野生生物に指定された種は採取と保管、流通が全面的に禁止されており、この文書で触れたドクゼリのように、毒性植物の中にも絶滅危惧種に指定されているものがあります。また、国立公園や道立公園、山林遺伝資源保護区域では自然公園法と山林保護法により林産物の採取が禁止されており、私有林や国有林で許可なく林産物を採取すると、山地管理法違反や刑法上の窃盗罪に該当することがあります。他の国にも大半は同じ趣旨の規制があります。この文書は公的な仕組みが機能しない生存状況を前提とした知識の整理であり、平時には必ず読者ご自身の国の野生生物保護法と森林関連法令を確認し、その範囲内でのみ行わなければなりません。

&nbsp;&nbsp;&nbsp;生存状況でも変わらず残る原則があります。確実に分かるものだけを食べ、必要な分だけ採り、次の季節のために残して立ち去ることです。採集で得たものをどう貯蔵し加工するかは食品保存の文書で、熱量の中心をどう確保するかは農業の文書で続けて扱います。
