## 2. 韩国常见的食用野生植物与识别性状
&nbsp;&nbsp;&nbsp;辨认植物时最常见的失败，是依赖一张照片的印象。即使是同一物种，也会因生长地点的光照、水分和时期不同，大小和颜色差别很大，所以仅凭外观印象无法区分。可以信赖的，是受环境影响不大的性状。

---
### 2-1. 应该看什么
&nbsp;&nbsp;&nbsp;下列性状在个体之间几乎没有变化，因此可作为识别的依据。原则是不凭其中一项下结论，只有多项同时吻合时才能确定。

| 性状 | 提供的信息 |
| --- | --- |
| 叶脉排列 | 平行脉是单子叶植物，网状脉是双子叶植物。这是缩小科范围的第一条线索 |
| 叶序 | 互生、对生、轮生，每个物种都是固定的 |
| 毛的有无与种类 | 看有无，柔软还是粗硬，连颜色也要看 |
| 气味 | 揉搓叶子后闻。大蒜、水芹、当归的香气是决定性的线索 |
| 乳汁 | 切口是否流出白色或黄色的汁液 |
| 茎的横截面 | 圆形还是有棱，实心还是空心 |
| 基部与根 | 是否被纤维包裹，切开的截面是什么结构 |
| 生长地点 | 水边、干燥山坡、阴处、林缘等生境条件 |

&nbsp;&nbsp;&nbsp;其中气味是格外有用的性状。植物的芳香物质是物种特有的次生代谢产物，个体差异小，不用工具就能立刻确认。即使是茖葱与铃兰这样外观极为相似的一对，仅凭气味就能得出结论。不过确认气味时也不要放进嘴里，只限于用手指揉搓叶子后闻。

---
### 2-2. 常见且相对容易区分的食用植物
&nbsp;&nbsp;&nbsp;以下是韩国山野中常见、识别性状相对明显的物种。但不能仅凭这里写的内容在现场做出最终判断，必须请认识实物的人确认，或与图鉴对照。

| 名称 | 时期与地点 | 识别线索 | 注意 |
| --- | --- | --- | --- |
| 艾草 | 3-5月，向阳的田野和田埂 | 叶背被白色绒毛覆盖而显得发白，特有的香气浓烈 | 相似的菊科植物很多，靠发白的叶背和香气区分 |
| 荠菜 | 3-4月，田埂和路边 | 基生叶贴着地面呈放射状展开，根部有荠菜特有的香气 | 开花后会变老 |
| 野蒜（dallae） | 3-5月，田埂和林缘 | 细圆筒形的叶子、圆形的鳞茎、浓烈的大蒜味 | 没有气味就不是dallae |
| 苦荬菜类（ssumbagwi与godeulppaegi） | 3-5月，田野和路边 | 切断后流出白色乳汁，味道很苦 | 焯水后浸泡可减轻苦味 |
| 蒲公英 | 3-6月，向阳处 | 锯齿向后的基生叶、中空的花葶、白色乳汁 | 叶和根都能用 |
| 车前草 | 4-9月，路边和空地 | 叶上有多条平行的粗脉，生长在被踩踏的地方 | 只有嫩叶柔软 |
| 萱草 | 4-5月，山坡 | 平行脉的长叶从基部分成两列呈扇形展开 | 必须焯水后浸泡 |
| 楤木芽 | 4-5月，林缘 | 长在带刺茎干顶端的新芽 | 必须焯水，侧芽要留下 |
| 软枣猕猴桃与山葡萄 | 8-10月，山脚的藤蔓 | 软枣猕猴桃是光滑的绿色果实，山葡萄成熟后变黑，呈葡萄串状 | 藤蔓类果实有很多有毒，需要确认 |
| 橡子 | 9-11月，栎树下 | 带壳斗的栎类坚果 | 必须去除单宁 |
| 栗子 | 9-10月，栗树下 | 多刺的栗苞里的褐色坚果 | 不用加工即可直接吃 |
| 葛 | 全年，向阳山坡的藤蔓 | 三片宽大的小叶、粗而长的根 | 只滤取根里的淀粉使用 |
| 山药 | 10-11月，山脚的藤蔓 | 心形叶子对生，叶腋长有零余子 | 也可以生吃 |

&nbsp;&nbsp;&nbsp;这张表里反复出现一条规律：热量越高的东西越需要加工。橡子和葛要去除单宁，楤木芽和萱草要去除自身的刺激成分，这并非偶然。因为植物储存大量能量的部位，同时也带有保护它的化学防御。加工方法在本文档的最后一章讲述。

### 2-3. 从树木和水边获得的东西
&nbsp;&nbsp;&nbsp;只看草本会错过一半的采集。树木提供树皮、树液、果实和叶子，尤其在冬季和早春，几乎是唯一的资源。

| 对象 | 时期 | 所得之物 | 原理与注意 |
| --- | --- | --- | --- |
| 松树内皮 | 全年，春季最柔软 | 淀粉和糖分 | 只用外皮下面的白色形成层。围着树干剥一整圈，树就会死亡 |
| 白桦与色木槭的树液 | 2-4月 | 糖分和矿物质 | 只在根压上升的时期流出，几天就会变质 |
| 栎树与栗树 | 9-11月 | 橡子和栗子 | 最大的热量来源，储存性也好 |
| 桑树 | 6-7月 | 桑葚和嫩叶 | 叶子焯水后食用，果实直接吃 |
| 野蔷薇与山莓 | 5-7月 | 嫩芽和果实 | 蔷薇科的果实大体上比较安全 |
| 香蒲与芦苇 | 全年 | 根茎的淀粉、嫩芽 | 水边具代表性的淀粉来源，但要注意水质污染 |
| 水芹 | 3-5月，水边 | 叶和茎 | 必须与毒芹区分开 |

&nbsp;&nbsp;&nbsp;在水边采集时，问题在于水而不是植物本身。畜牧设施或居住地下游河流中的水生植物，表面可能带有大肠杆菌、寄生虫卵和重金属。如果不知道上游有什么，水边的植物必须煮熟再吃，才能降低感染肝吸虫和肺吸虫的风险。
