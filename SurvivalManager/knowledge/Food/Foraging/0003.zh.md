## 2. 韩国常见食用野生植物及其识别特征
&nbsp;&nbsp;&nbsp;辨认植物时最常见的失误，是依赖一张照片给人的印象。同一物种也会因生长地的光照、水分和时期不同，而在大小和颜色上产生很大差异，仅凭外观印象无法区分。可靠的是那些不易随环境改变的性状。

---
### 2-1. 应该看什么
&nbsp;&nbsp;&nbsp;下列性状在个体之间几乎不变，因此可作为识别的基准。原则是不能只凭一项就下结论，只有当多项同时吻合时才能确定。

| 性状 | 能说明什么 |
| --- | --- |
| 叶脉排列 | 平行脉为单子叶植物，网状脉为双子叶植物，是缩小科别范围的第一条线索 |
| 叶序 | 互生、对生、轮生因物种而固定不变 |
| 毛的有无与种类 | 要看有无、是柔软还是粗硬，乃至颜色 |
| 气味 | 揉搓叶片来闻。大蒜味、水芹味、当归香是决定性的线索 |
| 乳汁 | 切口处是否流出白色或黄色汁液 |
| 茎的横截面 | 是圆是棱，中空还是实心 |
| 基部与根 | 是否被纤维包裹，切面呈什么结构 |
| 生长地点 | 水边、干燥坡地、阴地、林缘等生境条件 |

&nbsp;&nbsp;&nbsp;其中气味是特别有用的性状。植物的芳香物质是该物种特有的次生代谢产物，个体差异小，无需工具即可当场确认。像茖葱与铃兰这类外观极为相似的组合，也能仅凭气味就得出结论。不过确认气味时，也只能揉搓叶片用鼻子闻，不能放入口中。

---
### 2-2. 常见且相对容易区分的食用植物
&nbsp;&nbsp;&nbsp;下面是韩国山野中常见、识别性状相对明显的物种。但仅凭这里所写的内容，不应在现场做出确定性判断，还需要向熟悉实物的人确认，或与图鉴对照核实。

| 名称 | 时期与场所 | 识别线索 | 注意事项 |
| --- | --- | --- | --- |
| 艾草 | 3~5月，向阳的原野和田埂 | 叶背覆盖白色绵毛而显白，特有香气浓烈 | 相似的菊科植物很多，但可凭白色叶背与香气区分 |
| 荠菜 | 3~4月，田埂和路边 | 根生叶贴地呈放射状展开，根部有荠菜特有的气味 | 开花后会变老硬 |
| 薤白 | 3~5月，田埂和林缘 | 细圆筒形的叶与圆形鳞茎，蒜味浓烈 | 没有气味就不是薤白 |
| 苦荬菜与godeulppaegi（苦味山野菜） | 3~5月，原野和路边 | 切开流出白色乳汁，味道很苦 | 焯水浸泡后苦味会减轻 |
| 蒲公英 | 3~6月，向阳处 | 根生叶锯齿向后，花葶中空，白色乳汁 | 叶和根都可利用 |
| 车前草 | 4~9月，路边和空地 | 叶上有多条平行粗脉，生长在人踩踏之处 | 只有嫩叶柔软 |
| 萱草 | 4~5月，山坡 | 平行脉的长叶从基部呈两列扇形展开 | 必须焯水浸泡后才能吃 |
| 楤木芽 | 4~5月，林缘 | 长在带刺茎顶端的新芽 | 必须焯水，且要留下侧芽 |
| 软枣猕猴桃与山葡萄 | 8~10月，山脚藤蔓 | 软枣猕猴桃果实光滑呈绿色，山葡萄呈黑熟的葡萄串状 | 藤本浆果中有毒的不少，需要仔细确认 |
| 橡子 | 9~11月，栎树下 | 带壳斗的栎树类坚果 | 必须先去除单宁 |
| 栗子 | 9~10月，栗树下 | 多刺栗蓬中的棕色果实 | 无需加工即可直接食用 |
| 葛 | 全年，向阳坡地的藤蔓 | 三片宽阔的叶，粗而长的根 | 只取根中淀粉滤出使用 |
| 山药 | 10~11月，山脚藤蔓 | 心形叶对生，叶腋处长有零余子 | 生吃也可以 |

&nbsp;&nbsp;&nbsp;这张表中反复出现一条规律：热量越高，就越需要加工处理。橡子和葛要去除单宁，楤木芽和萱草要去除自身的刺激性成分，这并非偶然。植物储存大量能量的部位，往往同时具备用来保护这些能量的化学防御，二者相伴而生。加工方法将在本文档最后一章讨论。

### 2-3. 从树木和水边获得的东西
&nbsp;&nbsp;&nbsp;只盯着草本植物看，会错过采集的一半机会。树木能提供树皮、树液、果实和叶片，尤其在冬季和早春，几乎是唯一的资源。

| 对象 | 时期 | 获得之物 | 原理与注意事项 |
| --- | --- | --- | --- |
| 松树内皮 | 全年，春季最柔软 | 淀粉和糖分 | 只取外皮下的白色形成层。绕树干剥一整圈会使树死亡 |
| 白桦与色木槭树液 | 2~4月 | 糖分和矿物质 | 只在根压升高的时期流出，数日内就会变质 |
| 栎树与栗树 | 9~11月 | 橡子和栗子 | 是最大的热量来源，耐储性也好 |
| 桑树 | 6~7月 | 桑葚和嫩叶 | 叶焯水后食用，果实可直接食用 |
| 野蔷薇与山莓 | 5~7月 | 嫩芽和果实 | 蔷薇科的果实大体上比较安全 |
| 香蒲与芦苇 | 全年 | 地下茎中的淀粉、嫩芽 | 是水边具代表性的淀粉来源，但需留意水质污染 |
| 水芹 | 3~5月，水边 | 叶和茎 | 必须与毒芹严格区分 |

&nbsp;&nbsp;&nbsp;在水边采集时，问题往往不在植物本身，而在于水。畜牧设施或居住区下游河流中的水生植物，表面可能附着大肠杆菌、寄生虫卵和重金属。如果不清楚上游有什么，水边植物就必须煮熟后再吃，才能降低感染肝吸虫和肺吸虫的风险。
