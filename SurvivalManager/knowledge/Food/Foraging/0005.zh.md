## 4. 毒蘑菇与错误的俗见
&nbsp;&nbsp;&nbsp;在所有采集对象中，蘑菇的风险与回报之比最差。其热量为每100g 20~40kcal，与叶菜并无差别，但一旦选错，后果比任何其他采集物都更致命。尽管如此，蘑菇中毒事故仍不断发生，原因在于流传甚广的蘑菇辨别方法，几乎全都是错的。

---
### 4-1. 为什么这些俗见全部错误
&nbsp;&nbsp;&nbsp;下面是韩国流传最广的毒蘑菇辨别法，没有一条属实。韩国食品医药品安全部、韩国山林厅、韩国农村振兴厅之所以每年都重复发出同样的警告，正是因为这些俗见是实际死亡事故的原因。

| 俗见 | 事实 |
| --- | --- |
| 能纵向整齐撕开的就能吃 | 剧毒的白毒鹅膏和白托鹅膏也能纵向整齐撕开。撕开的方向只是菌褶排列带来的物理性质，与毒性无关 |
| 被虫咬过的就安全 | 昆虫和蛞蝓的鹅膏毒肽靶点酶与人不同，因此不受影响。剧毒蘑菇上同样会留有虫咬的痕迹 |
| 颜色鲜艳就是毒蘑菇 | 最致命的鹅膏毒肽类蘑菇大多是纯白色。相反，颜色鲜橙的橙盖鹅膏却是食用菌 |
| 放入银器会变黑就是毒蘑菇 | 银是与硫化合物反应才变色的。它对鹅膏毒肽没有反应，反倒是大蒜、鸡蛋这类平常食物更容易使银器变色 |
| 煮沸或用盐腌渍就能去毒 | 鹅膏毒肽对热非常稳定，煮沸也不会分解，晒干后依然残留 |
| 与茄子或紫苏油一起烹调就能中和毒性 | 毫无根据 |
| 菌柄上没有菌环就安全 | 菌环只是缩小种类范围的线索，并非毒性的指标 |

> **对于蘑菇，并不存在能筛选出安全种类的通用规则。除了逐一认清物种之外别无他法。**

&nbsp;&nbsp;&nbsp;这些俗见之所以挥之不去是有原因的。超市里卖的蘑菇绝大多数其实没有毒，因此即使用错误的规则去判断，也大多平安无事。人们把这种"平安无事"当作规则正确的证据，实际上只是碰巧没遇到剧毒蘑菇而已。一旦遇上一次，此前所有的"成功经验"都毫无意义。

---
### 4-2. 鹅膏毒肽——迟来的毒
&nbsp;&nbsp;&nbsp;蘑菇中毒致死的病例，大多由鹅膏毒肽这一类毒素单独引发。在韩国，白毒鹅膏、白托鹅膏、黄盖鹅膏都属于此类，它们都常见于栎树林中，外观与食用菌相似。

&nbsp;&nbsp;&nbsp;鹅膏毒肽特别危险，原因不在于毒性强度，而在于其作用方式。这种毒素会阻断细胞读取遗传信息、合成蛋白质所必需的RNA聚合酶II。于是细胞不会立即死亡，而是在无法合成新蛋白质的状态下逐渐丧失功能。蛋白质周转率最高的肝细胞和肾脏的肾小管细胞最先崩溃，这种延迟使临床病程呈现出特殊的样貌。

| 阶段 | 时间 | 状态 |
| --- | :---: | --- |
| 潜伏期 | 摄入后6~24小时 | 没有任何症状。此时毒素已经进入肝脏 |
| 胃肠期 | 6~24小时之后 | 开始剧烈呕吐、腹泻、腹痛，出现严重脱水 |
| 假性恢复期 | 摄入后24~36小时 | 症状消退，看似已经康复。此时若中断治疗则是致命的 |
| 肝衰竭期 | 摄入后3~5天 | 肝细胞坏死持续进展，发展为黄疸、出血和多脏器衰竭 |

&nbsp;&nbsp;&nbsp;存在"假性恢复期"，是这种中毒最危险的特点。呕吐腹泻一旦停止，患者就会以为自己已经痊愈，医疗现场也有误判为普通肠胃炎而让患者回家的报告案例。然而此时肝细胞其实仍在被持续破坏，等到症状再次出现时，往往除了肝移植别无选择。

&nbsp;&nbsp;&nbsp;致死剂量也极低。鹅膏毒肽的致死剂量约为每1千克体重0.1mg，而一朵蘑菇中最多可含15mg。体重60kg的成年人致死剂量为6mg，因此分食一朵蘑菇的多人同时中毒的情况确实会发生。

&nbsp;&nbsp;&nbsp;与食用菌混生这一点也加剧了问题。一丛采下的蘑菇中，哪怕只有一两个是别的物种，整丛都会变得危险。因此蘑菇必须逐个确认，而不是按丛确认，原则上不能混装。

---
### 4-3. 其他系列的蘑菇毒素
&nbsp;&nbsp;&nbsp;除鹅膏毒肽之外还有多个系列，各自的症状和时间都不同。起效快的毒素大多可以恢复，但如果症状在6小时之后才开始出现，几乎全部属于危险系列。

| 系列 | 代表蘑菇 | 症状开始时间 | 主要损伤 |
| --- | --- | :---: | --- |
| 鹅膏毒肽 | 白毒鹅膏、白托鹅膏 | 6~24小时 | 肝脏和肾脏，致死率高 |
| 丝膜菌素 | 部分丝膜菌属 | 2~20天 | 肾衰竭，潜伏期最长 |
| 鹿花菌素 | 鹿花菌 | 6~12小时 | 肝脏和神经 |
| 毒蕈碱 | 丝盖伞属、杯伞属 | 15分钟~2小时 | 出汗、流涎、心动过缓 |
| 鹅膏蕈氨酸与蝇蕈醇 | 毒蝇鹅膏、豹斑鹅膏 | 30分钟~2小时 | 谵乱与幻觉、抽搐 |
| 胃肠道刺激物质 | 簇生黄韧伞、日本类脐菇等多种 | 30分钟~3小时 | 呕吐与腹泻，大多可恢复 |
| 鬼伞素 | 膜盖鬼伞 | 与酒同食时 | 潮红与心悸 |
| 单端孢霉烯族毒素 | 血红肉座菌 | 30分钟以内 | 少量即可致命，连触摸都要避免 |

&nbsp;&nbsp;&nbsp;由此可以得出一条实用的规律：吃蘑菇后6小时内出现症状的，大多属于可恢复的系列；6小时之后才首次出现症状的，很可能属于针对肝脏或肾脏的系列。但这条规律只能作为诊断参考，不能作为采集的判断标准，因为那已经是吃下去之后的事了。

&nbsp;&nbsp;&nbsp;在生存处境下，对待蘑菇最合理的判断就是不要碰。蘑菇给出的热量与叶菜相当，而同样的时间用来捡橡子却能获得数十倍的热量。可能失去的东西与可能得到的东西完全不成比例，因此除非是确实认识的几种，否则最好把蘑菇从采集清单中剔除。
