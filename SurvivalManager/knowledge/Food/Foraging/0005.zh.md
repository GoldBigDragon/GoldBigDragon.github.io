## 4. 毒蘑菇与错误的传言
&nbsp;&nbsp;&nbsp;蘑菇是采集对象中风险与回报比例最差的。热量每100g只有20-40kcal，与叶菜无异，但选错的后果却比其他任何采集物都更致命。蘑菇中毒之所以屡禁不止，是因为关于蘑菇广为流传的辨别方法几乎全都是错的。

---
### 4-1. 传言全都是错的原因
&nbsp;&nbsp;&nbsp;以下是韩国流传最广的毒蘑菇辨别方法，没有一条是事实。食品医药品安全处、山林厅和农村振兴厅每年重复发出同样的警告，也是因为这些传言是真实死亡事故的原因。

| 传言 | 事实 |
| --- | --- |
| 能顺着纵向撕开的可以吃 | 剧毒蘑菇鳞柄白鹅膏和白毒鹅膏也能顺着纵向撕得干净利落。撕开的方向只是菌褶排列带来的物理性质，与毒性无关 |
| 被虫子吃过的是安全的 | 昆虫和蛞蝓的鹅膏毒肽靶标酶与人不同，不会受到影响。剧毒蘑菇上也同样留有虫蛀的痕迹 |
| 颜色鲜艳的就是毒蘑菇 | 最致命的鹅膏毒肽类蘑菇大多是纯白色。相反，鲜橙色的橙盖鹅膏（dalgyalbeoseot）可以食用 |
| 放入银勺变黑的就是毒蘑菇 | 银与含硫化合物反应而变色。它对鹅膏毒肽没有反应，大蒜、鸡蛋这类普通食物反而会使银变色 |
| 煮或用盐腌就能去毒 | 鹅膏毒肽对热非常稳定，煮也不会分解，晒干后仍然残留 |
| 与茄子或紫苏油一起烹调就能中和 | 没有任何依据 |
| 菌柄上没有菌环的是安全的 | 菌环只是缩小物种范围的线索，不是毒性的指标 |

> **蘑菇没有能挑出安全品种的通用规则。除了逐一认识每个物种，别无他法。**

&nbsp;&nbsp;&nbsp;这些传言不会消失是有原因的。超市里卖的蘑菇大多确实无毒，因此即使用了错误的规则，绝大多数情况下也平安无事。人们把这种成功当作规则的证据，其实只是没有遇到剧毒蘑菇而已。一旦遇到，此前所有的成功都毫无意义。

---
### 4-2. 鹅膏毒肽 - 迟来的毒
&nbsp;&nbsp;&nbsp;蘑菇中毒致死的大部分由鹅膏毒肽这一类引起。在韩国，鳞柄白鹅膏、白毒鹅膏、黄盖鹅膏属于此类，都常见于栎树林，外观与食用蘑菇相似。

&nbsp;&nbsp;&nbsp;鹅膏毒肽特别危险，是因为作用方式而不是毒性强度。这种毒素会阻断细胞读取遗传信息、合成蛋白质所需的RNA聚合酶II。于是细胞不会立刻死亡，而是无法合成新的蛋白质，逐渐丧失功能。蛋白质周转率最高的肝细胞和肾小管细胞首先崩溃，这种延迟使临床经过变得特殊。

| 阶段 | 时点 | 状态 |
| --- | :---: | --- |
| 潜伏期 | 摄入后6-24小时 | 没有任何症状。这段时间里毒素已经进入肝脏 |
| 胃肠道期 | 6-24小时之后 | 开始剧烈呕吐、腹泻、腹痛和严重脱水 |
| 假愈期 | 摄入后24-36小时 | 症状缓解，看似已经康复。此时中断治疗是致命的 |
| 肝衰竭期 | 摄入后3-5天 | 肝细胞坏死加重，导致黄疸、出血和多器官功能衰竭 |

&nbsp;&nbsp;&nbsp;存在假愈期，是这种中毒最危险的特点。呕吐和腹泻停止后，人会认为自己好了，医疗现场也曾有被误认为单纯肠胃炎而让患者回家的报告。但此时肝细胞已经在被破坏，症状再次出现时，往往除了肝移植别无选择。

&nbsp;&nbsp;&nbsp;致死量也极小。鹅膏毒肽的致死量约为每公斤体重0.1mg，一朵蘑菇最多可含15mg。体重60kg的成年人致死量是6mg，所以分食一朵蘑菇的多个人同时中毒的情况确实会发生。

&nbsp;&nbsp;&nbsp;它与食用蘑菇长在一起，也加大了问题。从一丛中采下的蘑菇，只要有一两朵是别的物种，整体就变得危险。因此蘑菇必须以单株而不是以丛为单位确认，原则上不要混装。

---
### 4-3. 其他类别的蘑菇毒素
&nbsp;&nbsp;&nbsp;除鹅膏毒肽外还有多个类别，各自的症状和时间不同。发作快的毒通常能恢复，但超过6小时才开始出现症状的，几乎都是危险的类别。

| 类别 | 代表蘑菇 | 症状开始 | 主要损害 |
| --- | --- | :---: | --- |
| 鹅膏毒肽 | 鳞柄白鹅膏、白毒鹅膏 | 6-24小时 | 肝脏和肾脏，致死率高 |
| 奥来毒素 | 部分丝膜菌属 | 2-20天 | 肾衰竭，潜伏期最长 |
| 鹿花菌素 | 鹿花菌 | 6-12小时 | 肝脏和神经 |
| 毒蕈碱 | 丝盖伞属、杯伞属 | 15分钟-2小时 | 出汗、流涎、心动过缓 |
| 鹅膏蕈氨酸和蝇蕈醇 | 鹅膏属（豹斑毒鹅膏、毒蝇鹅膏等） | 30分钟-2小时 | 意识错乱、幻觉、抽搐 |
| 胃肠道刺激物质 | 簇生沿丝伞、橘黄裸伞等多种 | 30分钟-3小时 | 呕吐和腹泻，通常可恢复 |
| 鬼伞素 | 墨汁鬼伞 | 与酒同食时 | 面红和心悸 |
| 单端孢霉烯族毒素 | 火焰茸 | 30分钟内 | 少量也致命，连触摸也要避免 |

&nbsp;&nbsp;&nbsp;由此得出一条实用规则。吃蘑菇后6小时内出现症状的，通常是可以恢复的类别；超过6小时才首次出现症状的，很可能是针对肝脏或肾脏的类别。但这条规则只能用作诊断参考，不能作为采集的标准，因为那是已经吃下去之后的事。

&nbsp;&nbsp;&nbsp;在生存状况下，对蘑菇最合理的判断是不去碰。蘑菇提供的热量只相当于叶菜，同样的时间去捡橡子，能得到几十倍的热量。能失去的和能得到的相差悬殊，所以除非是确定认识的少数几种，最好把蘑菇从采集清单中去掉。
