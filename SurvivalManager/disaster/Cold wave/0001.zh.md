# 寒潮预警标准（10月至次年4月）

| 等级 | 符合以下任一情况即发布 |
| --- | --- |
| 注意报 | 早晨最低气温比前一天下降10℃以上且降至3℃以下，并低于常年值3℃／早晨最低气温在-12℃以下持续2天以上／气温骤降预计造成重大损失 |
| 警报 | 早晨最低气温比前一天下降15℃以上且降至3℃以下，并低于常年值3℃／早晨最低气温在-15℃以下持续2天以上／预计在大范围内造成重大损失 |

# 平时的准备

## 1. 健康
- 提前了解低体温症、冻伤等寒冷疾病的症状与处置方法，并与家人邻居共享附近医院的联系方式。
- 儿童、老年人、心脑血管疾病患者耐寒能力差，要格外注意健康管理。
- 糖尿病患者和慢性肺病患者务必接种流感疫苗。
- 家中有儿童或老人时，要经常测量体温并查看室温。
- 绝不能让1岁以下婴幼儿睡在寒冷的房间里。
- 家中有65岁以上老人时，请在其常看到的位置放一个易读的温度计。老年人感知温度变化的能力下降，代谢较低，更容易受寒潮伤害。

## 2. 设施与物资
- 提前检修锅炉、管道和取暖设备，并注意防火。
- 水表、水管、锅炉管道用旧衣物等保温材料包裹，外部用胶带密封，阻挡冷空气。
- 老旧住宅要提前检查变压器，防范超负荷。
- 备好手电筒、应急食品饮料和便携收音机以应对停电。
- 备好瓶装水应对停水，并在浴缸里蓄好生活用水。
- 准备保暖内衣、围巾、帽子和手套。

## 3. 车辆
- 结冰路面事故风险高，尽量避免长途驾驶。
- 提前检查冬季装备（防滑链、沙袋、氯化钙、铁锹）以及防冻液、蓄电池、润滑油状态。
- 关窗长时间开暖风会减少输送到大脑的氧气，引发困倦。至少每30分钟通风一次。

# 寒潮期间

## 1. 外出
- 尽量减少户外活动；外出时用保暖内衣、围巾、帽子、手套遮住裸露部位。
- 尽量乘坐公共交通，并告知家人去向和时间安排。
- 回家后洗净手脚，避免过量饮酒和过度劳累。
- 长时间外出、家中留有行动不便的老人或病人时，请托付亲友或邻居照看。
- 对独居老人和残障人士，要经常打电话确认平安。

## 2. 防止冻裂
- 长时间离家时，把水龙头开小一点让水保持流动。
- 水管冻住时用温水或吹风机解冻，绝对不要用明火。
- 发生冻裂时，请联系地方政府或当地自来水部门。
- 不要过度使用电暖器，不要把易燃物放在电暖器附近。
- 电力故障请向韩国电力公社（123）或韩国电气安全公社（1588-7500）报修。

## 3. 驾车
- 出发前彻底清除前挡风玻璃上的霜。
- 比平时减速行驶，保持充足车距。
- 在湿滑路、结冰路、弯道上避免加速和急刹，应提前减速。

## 4. 车辆被困时
- 用一切可行方式求救，与同车人一起保暖并轮流休息。
- 拍手、活动手脚等轻微运动有助于维持血液循环。
- 必须有一个人保持清醒。
- 夜间打开车内灯，或把彩色衣物铺在雪地上。
- 尽量在车内等待；不得不离开时，留下联系电话并把钥匙插在车上。
- 排气口被雪堵住会使一氧化碳进入车内，发动前先清理周边积雪，并留一条窗缝。

# 寒冷疾病处置

## 1. 低体温症
症状 - 口齿不清或记忆障碍／意识逐渐模糊／持续疲惫感／四肢剧烈颤抖

处置
1. 迅速送医或拨打119。
2. 脱去湿衣服，用毯子或睡袋包裹。
3. 在腋下和腹部放置暖宝宝或热水袋。没有条件时，由他人拥抱取暖同样有效。
4. 意识清醒时可给温热饮品；意识不清者不要喂食任何东西。

> 出现严重寒战、记忆丧失、方向感丧失、发音含糊、极度疲劳时，应怀疑低体温症并立即就医。

## 2. 冻伤
分度症状
- 一度：刺痛、发红发痒、肿胀
- 二度：皮肤发暗红并出现水疱
- 三度：皮肤和皮下组织坏死，感觉丧失
- 四度：坏死深达肌肉和骨骼

处置
1. 就医优先。
2. 把患者转移到温暖环境。
3. 将冻伤部位浸入38～42℃的水中（以未冻伤部位浸入时不觉难受为准）。
4. 面部、耳部：敷温热湿毛巾并勤更换。
5. 手、脚：在手指、脚趾之间夹入消毒干纱布，吸除潮气并防止粘连。
6. 冻伤部位略微抬高，减轻肿胀和疼痛。
7. 腿、脚冻伤者要用担架搬运，复温后也不可行走。

> 不要揉搓，也不要突然靠近火源，否则组织会进一步受损。

## 3. 跌倒损伤
处置
1. 若独自无法行动，请尽快拨打119。
2. 让伤者保持最舒适的姿势，固定不动并呼救，必要时用夹板固定。

减少冰面跌倒的要点
- 步幅比平时缩小10～20%。
- 穿低跟、防滑鞋底的鞋。
- 不要把手插在口袋里，也不要边走边看手机。
- 尽量不要手里拿东西。
- 避开背阴处，不要急转弯。
- 避免穿厚重笨拙的外套，它会限制动作。
- 快要摔倒时放低身体，顺势坐下或向侧面翻滚，减轻伤害。
- 正在服用镇静剂、安眠药等易致头晕药物时，请减少外出。
- 注意路缘石、木栈道、室外球场等易滑地面。

# 农渔村

## 1. 农作物
- 用塑料膜、稻草、无纺布覆盖，防止冻害。
- 大棚要提前准备取暖设备、保温幕和蓄热袋。
- 提前检查暖风机等电气设施。
- 预计出现极端低温时，请提前收获并入库。

## 2. 畜舍
- 准备挡穿堂风的保温被和取暖设备，保持舍内适宜温度。
- 为防火灾，检查电线绝缘层并检修电热器具。
- 为帮助家畜维持体温，饲料量增加10～20%。

## 3. 养殖场
- 另外划出不少于养殖面积1%的越冬区，并用防风网等保温。
- 预计寒潮持续时间长时，提前出栏养殖鱼类以减少损失。
