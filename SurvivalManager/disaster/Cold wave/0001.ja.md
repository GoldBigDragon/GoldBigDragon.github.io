# 寒波注意報・警報の基準（10月〜4月）

| 区分 | 次のいずれかに当てはまるとき |
| --- | --- |
| 注意報 | 朝の最低気温が前日より10℃以上下がって3℃以下となり、平年より3℃低いと見込まれるとき／朝の最低気温-12℃以下が2日以上続くと見込まれるとき／急激な低温で重大な被害が予想されるとき |
| 警報 | 朝の最低気温が前日より15℃以上下がって3℃以下となり、平年より3℃低いと見込まれるとき／朝の最低気温-15℃以下が2日以上続くと見込まれるとき／広い範囲で重大な被害が予想されるとき |

# 日ごろの備え

## 1. 健康
- 寒冷による疾患（低体温症・凍傷）の症状と手当てを覚え、近くの病院の連絡先を家族や近所と共有します。
- 子ども、高齢の方、心血管・脳血管の疾患がある方は寒さに弱いため、体調管理により気をつけます。
- 糖尿病の方や慢性の肺疾患がある方は、必ずインフルエンザの予防接種を受けてください。
- 家に子どもや高齢の方がいる場合は、体温と室温をこまめに確認します。
- 満1歳以下の乳幼児を、冷えた部屋で寝かせては絶対にいけません。
- 65歳以上の方がいる家庭では、見やすい温度計をよく目にする場所に置きます。高齢の方は温度変化を感じ取る力が落ち、代謝も低いため寒波に弱くなります。

## 2. 設備と物資
- ボイラー・配管・暖房器具を事前に整備し、火災に注意します。
- 水道メーター、水道管、ボイラー配管は古着などの保温材で覆い、外側をテープで密閉して冷気を遮ります。
- 古い住宅は変圧器を事前に点検し、過負荷に備えます。
- 停電に備えて懐中電灯、非常用の食料・飲料、携帯ラジオを用意します。
- 断水に備えてペットボトルの水を用意し、浴槽に生活用水をためておきます。
- 肌着、マフラー、帽子、手袋を準備します。

## 3. 車
- 凍結路での事故が増えるため、長距離運転は控えます。
- 冬用装備（チェーン、砂袋、塩化カルシウム、スコップ）と不凍液、バッテリー、潤滑油の状態を事前に点検します。
- 窓を閉めてヒーターを長くつけていると、脳へ届く酸素が減って眠気を招きます。少なくとも30分に1回は換気してください。

# 寒波が来たとき

## 1. 外出
- 屋外の活動を控え、出るときは肌着・マフラー・帽子・手袋で露出部分を覆います。
- なるべく公共交通機関を使い、家族に行き先と時間の予定を伝えます。
- 帰宅後は手足を洗い、過度の飲酒や無理な作業は避けます。
- 動くのが難しい高齢の方や病気の方を残して長時間出かけるときは、親族や近所に見守りを頼みます。
- 一人暮らしの高齢の方や障害のある方には、こまめに電話して安否を確認します。

## 2. 凍結・破裂への備え
- 長期間家を空けるときは、蛇口を少し開けて水を流し続けます。
- 水道管が凍ったらぬるま湯やドライヤーで溶かします。絶対に火を使わないでください。
- 破裂した場合は自治体や地域の水道事業者に連絡します。
- 電熱器の使いすぎを控え、燃えやすい物を電熱器の近くに置かないでください。
- 電気の異常は韓国電力公社（123）または韓国電気安全公社（1588-7500）へ通報します。

## 3. 運転
- 出発前にフロントガラスの霜を完全に取り除きます。
- 普段より低速で、車間距離を十分にとって走ります。
- 滑りやすい道・凍結路・カーブでは、加速と急ブレーキを避け、あらかじめ減速します。

## 4. 車が立ち往生したとき
- 可能な手段で救助を求め、同乗者と体温を保ちながら交代で休息します。
- 手をたたき、手足を動かす軽い運動で血行を保ちます。
- 必ず1人は起きていてください。
- 夜は室内灯をつけるか、色のついた衣類を雪の上に広げておきます。
- できるだけ車内で待機し、やむを得ず離れるときは連絡先を残し、キーを差したまま避難します。
- 排気口が雪でふさがると一酸化炭素が入るため、エンジンをかける前に周りの雪を取り除き、窓を少し開けます。

# 寒冷疾患への対処

## 1. 低体温症
症状 - ろれつが回らない、記憶の障害／意識がだんだんもうろうとする／持続する疲労感／手足の激しい震え

手当て
1. 速やかに病院へ向かうか、119へ通報します。
2. ぬれた服を脱がせ、毛布や寝袋で包みます。
3. わきの下と腹部にホッカイロや湯たんぽを当てます。何もなければ、人が抱きしめるのも有効です。
4. 意識があれば温かい飲み物が助けになりますが、意識がはっきりしない人には何も飲ませないでください。

> 激しい寒け、記憶の喪失、方向感覚の喪失、不明瞭な発音、ひどい疲労を感じたら低体温症を疑い、すぐ病院へ行ってください。

## 2. 凍傷
段階別の症状
- 1度：刺すような痛み、赤みとかゆみ、むくみ
- 2度：皮膚が赤黒くなり、水ぶくれができる
- 3度：皮膚と皮下組織が壊死し、感覚を失う
- 4度：筋肉や骨まで壊死する

手当て
1. まず医療機関の受診が優先です。
2. 暖かい環境へ移します。
3. 凍傷の部位を38〜42℃の湯につけます。（凍傷でない部位をつけて不快でない程度の温度）
4. 顔・耳：温かい濡れタオルを当て、こまめに取り替えます。
5. 手・足：指の間に消毒した乾いたガーゼをはさみ、湿気を取り、互いにくっつかないようにします。
6. 凍傷の部位をやや高く保ち、むくみと痛みを抑えます。
7. 脚や足の凍傷は担架で運びます。 解けたあとも歩かせてはいけません。

> こすったり、急に火に当てたりしてはいけません。 組織がさらに傷みます。

## 3. 転倒によるけが
手当て
1. 一人で動けない場合は、すぐに119へ通報します。
2. 本人が楽な姿勢のまま動かさずに固定し、助けを呼びます。必要なら添え木を使います。

凍結路での転倒を減らすコツ
- 歩幅を普段より10〜20%小さくします。
- かかとが低く、滑り止めの付いた靴を履きます。
- ポケットに手を入れたり、スマートフォンを見ながら歩いたりしないでください。
- できるだけ手に物を持たないようにします。
- 日陰を避け、急に方向転換しないでください。
- 動きを鈍くする重く厚いコートは避けます。
- 転びそうなときは体を低くし、しゃがみ込むか横に転がって被害を減らします。
- 鎮静剤や睡眠薬などめまいを起こす薬を飲んでいるときは外出を控えます。
- 縁石、ウッドデッキ、屋外コートなど滑りやすい場所に注意します。

# 農漁村

## 1. 農作物
- ビニール・わら・不織布で覆い、凍害を防ぎます。
- ビニールハウスは暖房、保温カーテン、蓄熱袋を前もって用意します。
- 温風機などの電気設備を事前に点検します。
- 極端な低温が予想されるときは早めに収穫して保管します。

## 2. 畜舎
- すきま風を防ぐ保温カバーと暖房機を用意し、内部を適温に保ちます。
- 火災予防のため配線の被覆を点検し、電熱器具を整備します。
- 家畜の体温維持のため、飼料を10〜20%増やして与えます。

## 3. 養殖場
- 飼育面積の1%以上を別に確保して越冬場を設け、防風網などで保温します。
- 長期の寒波が予想されるときは、養殖魚を早めに出荷して被害を防ぎます。
