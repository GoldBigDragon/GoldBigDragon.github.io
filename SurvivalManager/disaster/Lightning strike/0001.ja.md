# 30-30ルール

- 稲光を見てから30秒以内に雷鳴が聞こえたら、雷雲はおよそ10km以内にあります。ただちに建物や車の中へ避難してください。
- 最後の雷鳴から30分待ってから外に出ます。雨がやんでも落雷は続きます。

---

# 安全な場所・危険な場所

| 安全 | 危険 |
| --- | --- |
| 頑丈な建物の中 | 木の下、電柱のそば |
| 屋根が金属の密閉された車の中 | あずまや、物置、屋外観覧席、オープンカー |
| 地下、洞窟 | 山頂、尾根、岩場の上 |
| 乾いたくぼ地 | グラウンドや海岸などの開けた場所、水辺 |

- 車内では金属部分に触れないでください。
- 木の下は最悪の選択です。やむを得ない場合は10m以上離れてください。

---

# 落雷が予想されるとき

- 気象情報を確認し、屋外の予定を延期します。
- ゴルフ・釣り・登山中なら、ただちに中止して避難します。
- トレッキングポール、釣りざお、傘など長い金属製の物は体から離し、地面に寝かせます。
- 自転車からは降りてください。
- 急に黒い雲が広がって突風が吹いたら、とくに山頂や尾根ではただちに下山します。

---

# 屋内にいるとき

- 電話機や電気製品のプラグを抜き、照明や電気製品から1m以上離れます。
- 窓を閉め、窓辺から離れます。
- シャワー・入浴・食器洗いはしないでください。 配管を伝って電流が流れることがあります。
- 固定電話は使わないでください。携帯電話は安全です。

---

# 屋外で避難する場所がないとき

1. できるだけ低い場所へ移動します。水のたまっていないくぼ地が理想です。
2. 両足をそろえてしゃがみます。 足を広げると、地面を流れる電流が片足から入りもう片足へ抜け、体を通ってしまいます。
3. 頭を下げ、耳をふさぎます。
4. 地面に寝転ばないでください。 地面に接する面積が広いほど危険です。
5. 可能なら、ザックやマットなど地面から10cm以上高い絶縁物の上に座ります。
6. 複数人いるときは5m以上間隔をあけて散開します。一度の落雷で全員が被害を受けるのを防ぐためです。

---

# 落雷に打たれた人を見つけたら

> 落雷を受けた人の体に電気は残っていません。すぐに触れても安全です。

1. 周囲と協力して安全な場所へ移し、119へ通報します。
2. 反応と呼吸を確認します。
3. 呼吸がない、または異常ならただちに心肺蘇生を始めます。
   - 胸の中央を5cmの深さ、1分間に100〜120回で圧迫します。
   - 人工呼吸が難しければ胸骨圧迫だけ続けても構いません。
   - AEDがあればすぐに使用します。
4. 倒れている人が複数いる場合は、動かない人から先に対応します。落雷では通常のトリアージと優先順位が逆になります。
5. 脈と呼吸があるなら、やけど、骨折、聴覚・視覚の損傷、神経系の異常を確認します。電流の入口と出口にやけどがあります。
6. 体温を保ちます。 毛布や衣類をかけてください。
7. 意識があれば最も楽な姿勢で落ち着かせ、興奮したり震えたりしていれば声をかけて落ち着かせます。
8. 山中など、すぐ治療を受けられない場所でも絶対にあきらめず手当てを続けてください。落雷による心停止は比較的救命率が高いとされています。
9. 見た目に異常がなくても、体の奥深くにやけどがあることがあります。必ず医療機関を受診してください。
