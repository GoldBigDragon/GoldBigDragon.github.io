# 30-30法则

- 看到闪电后30秒内听到雷声，说明雷暴在约10公里以内，请立刻进入建筑物或车内。
- 最后一声雷响后再等30分钟才可外出。雨停之后闪电仍可能继续。

---

# 哪里安全，哪里危险

| 安全 | 危险 |
| --- | --- |
| 坚固的建筑物内 | 树下、电线杆旁 |
| 金属车顶的封闭式车辆内 | 凉亭、简易棚屋、露天看台、敞篷车 |
| 地下室、洞穴 | 山顶、山脊、岩壁之上 |
| 干燥的洼地 | 操场、海岸等开阔地，水边 |

- 在车内不要接触任何金属部位。
- 树下是最糟糕的选择。万不得已时也要保持10米以上距离。

---

# 预计有雷电时

- 查看气象预报，推迟户外安排。
- 正在打高尔夫、钓鱼或登山时，立即停止并撤离。
- 登山杖、鱼竿、雨伞等细长金属物要离开身体，平放在地上。
- 从自行车上下来。
- 乌云突然压顶、狂风骤起时，尤其在山顶和山脊上，请立即下山。

---

# 在室内时

- 拔掉电话和电器插头，与灯具、电器保持1米以上距离。
- 关好窗户，远离窗边。
- 不要洗澡、泡澡或洗碗，电流可能沿管道传导。
- 不要使用有线电话，手机则是安全的。

---

# 在户外无处可避时

1. 移动到尽可能低的地方，最好是不积水的洼地。
2. 双脚并拢蹲下。 两脚分开时，沿地面流动的电流会从一只脚进、另一只脚出，穿过身体。
3. 低头，捂住耳朵。
4. 不要躺在地上，身体与地面接触面积越大越危险。
5. 有条件时坐在背包、泡沫垫等离地10厘米以上的绝缘物上。
6. 多人同行时要分散开，间隔5米以上，避免一次落雷伤及所有人。

---

# 发现有人被雷击中时

> 被雷击者身上不会残留电流，可以立即触碰施救。

1. 与他人合力转移到安全处，并拨打119。
2. 检查反应和呼吸。
3. 无呼吸或呼吸异常时，立即开始心肺复苏。
   - 按压胸部正中，深度5厘米，每分钟100～120次。
   - 难以进行人工呼吸时，只做胸外按压也可以。
   - 有自动体外除颤器（AED）应立即使用。
4. 多人倒地时，先救治一动不动的人。雷击事故的分诊优先顺序与常规相反。
5. 有脉搏和呼吸时，检查烧伤、骨折、听力视力损伤和神经系统异常。电流进出的部位会有灼伤。
6. 注意保暖，用毯子或衣物覆盖。
7. 若意识清醒，让其保持最舒适的姿势休息；如果激动或发抖，用交谈的方式帮助其镇定。
8. 即使在山中等无法立即就医的地方，也绝不要放弃，坚持施救。雷击引起的心脏骤停复苏成功率相对较高。
9. 即便外表无恙，体内深处也可能有烧伤，务必到医院检查。
