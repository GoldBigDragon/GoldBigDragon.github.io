# 列车事故通用五原则

1. 报 - 用对讲机或紧急通话装置告知乘务员。
2. 捂 - 用毛巾、纸巾或衣袖捂住口鼻。烟雾和毒气比火焰更快致人倒下。
3. 移 - 先转移到未受影响的车厢。下到轨道是最后的手段。
4. 听 - 服从司机和乘务员的广播指令，不要自作主张。
5. 让 - 车门打开后，让伤者、老人、孕妇先下车。

> 绝对不要跨越到对面轨道，那边随时会有列车驶来。
> 不要滞留在轨道旁，应在安全位置等待救护车、救援列车或摆渡车。

# 车门手动开启方法

## 1. 地铁
1. 打开车门旁座椅下方或墙面上的手动开门装置盖板。
2. 拉出应急开关（紧急阀），或将红色应急手柄顺时针旋转90度。
3. 等待约10秒，直到放气声停止。
4. 向两侧推开车门。

## 2. 高速列车
1. 按下车门左上方的排气按钮。
2. 伴随放气声，车门锁止按钮弹出。
3. 拉动锁止按钮。
4. 车门向外弹出后，横向拉动把手将门打开。

## 3. 车门始终打不开时
- 用应急破窗锤敲击车窗边缘，中央部位很难敲碎。
- 没有锤子时，用灭火器底部的棱角敲击。
- 屏蔽门打不开时，将把手向两侧推开，或推动门上设置的红色横杆。

# 发生火灾时

- 通知乘务员后，若条件允许可用灭火器初期灭火。
  - 地铁：每节车厢配备两具
  - 高速列车：配置在车厢连接通道
- 火势变大就放弃灭火，优先撤离。
- 烟雾向上升，请压低身体移动。
- 停电时沿疏散指示灯行进；看不到指示灯，就摸着墙壁或沿盲道前进。
- 无法撤到地面时，按指引沿列车行进方向的隧道撤离。
- 在隧道内保持低姿势，沿应急指示灯走向最近的洞口或紧急避难所。

---

# 脱轨、碰撞时

- 第一次冲击之后可能出现二次碰撞，确认列车停稳后再行动。
- 行李架上的物品可能掉落，起身时注意护住头部。
- 车门打不开时，用应急锤敲碎应急车窗逃生。
- 车体倾斜时，从较低一侧的门出去更安全。

---

# 毒气、化学品恐怖袭击时

- 立即捂住口鼻，转移到未受影响的车厢。
- 通过对讲机通知乘务员。
- 不要触碰任何可能被污染的物体，不要踩踏流出的液体或粉末。
- 下车后请向上风方向（不要顺风）移动，尽快脱离污染区。
- 出现眼睛或皮肤刺痛、头晕、呕吐、咳嗽、呼吸困难，应怀疑已暴露，拨打119并前往医疗机构。
- 被污染的衣物要缓慢脱下、密封入塑料袋，并用流动水彻底冲洗身体。

---

# 平时的准备

- 上车后看清最近的应急破窗锤和紧急通话装置位置。
- 在地铁站记住出口编号和方向。停电时很容易迷失方向。
- 在站台不要倚靠屏蔽门，也不要探身到轨道一侧。
