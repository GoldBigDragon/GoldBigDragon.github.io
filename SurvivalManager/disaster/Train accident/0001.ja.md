# すべての列車事故に共通する5原則

1. 知らせる - インターホンや非常通話装置で乗務員に状況を伝えます。
2. ふさぐ - タオル・ティッシュ・袖口で口と鼻を覆います。煙と有毒ガスは炎より早く人を倒します。
3. 移る - まず被害のない車両へ移動します。線路に降りるのは最後の手段です。
4. 従う - 運転士・乗務員の案内放送に従い、自己判断で動かないでください。
5. ゆずる - ドアが開いたら、けが人・高齢の方・妊婦の方を先に降ろします。

> 反対側の線路へは絶対に渡らないでください。 そちらには別の列車が入ってきます。
> 線路際にとどまらず、安全な場所で救急車・救援列車・バスを待ちます。

# ドアの手動開閉方法

## 1. 地下鉄
1. ドア脇の座席下、または壁面にある手動開閉装置のふたを開けます。
2. 中の非常コックを引くか、赤い非常ハンドルを時計回りに90度回します。
3. 空気の抜ける音が止まるまで約10秒待ちます。
4. ドアを左右に押し開けます。

## 2. 高速列車
1. ドア左上の空気抜きボタンを下げます。
2. 空気が抜ける音とともにドアの施錠ボタンが外に出てきます。
3. 施錠ボタンを引きます。
4. ドアが外側に出てきたら、取っ手を横に引いて開けます。

## 3. それでもドアが開かないとき
- 非常用ハンマーで窓の端を割ります。中央は割れにくいです。
- ハンマーがなければ、消火器の底の角で打ちつけます。
- ホームドア（PSD）が開かない場合は、取っ手を左右に押すか、設置された赤いバーを押して出ます。

# 火災が起きたとき

- 乗務員に知らせたうえで、余裕があれば消火器で初期消火を試みます。
  - 地下鉄：各車両に2本ずつ配置
  - 高速列車：車両間の連結通路に配置
- 炎が大きくなったら消火をあきらめ、避難を優先します。
- 煙は上へ流れるので、姿勢を低くして移動します。
- 停電時は避難誘導灯をたどり、見えなければ壁を伝うか、視覚障害者用の点字ブロックをたどって進みます。
- 地上へ出られない場合は、案内に従って列車の進行方向のトンネルへ避難します。
- トンネル内では姿勢を低くし、非常誘導灯をたどって最寄りの坑口や非常避難所へ向かいます。

# 脱線・衝突のとき

- 最初の衝撃のあとに二次衝突が続くことがあります。停止を確かめてから動いてください。
- 棚の荷物が落ちてくるおそれがあるため、頭を守りながら立ち上がります。
- ドアが開かないときは、非常用ハンマーで非常窓を割って脱出します。
- 車体が傾いている場合は、低いほうのドアから出るほうが安全です。

---

# 毒ガス・化学物質によるテロのとき

- ただちに口と鼻を覆い、被害のない車両へ移動します。
- インターホンで乗務員に知らせます。
- 汚染のおそれがあるものには触れないでください。 流れ出た液体や粉末を踏まないように。
- 列車を降りたら、風上へ（風を背にしない方向へ）移動して汚染区域から離れます。
- 目や皮膚がひりひりする、めまい、嘔吐、せき、呼吸困難があれば曝露を疑い、119へ通報して医療機関へ向かいます。
- 汚染された衣服はゆっくり脱いでビニールに密封し、流水で十分に洗い流します。

---

# 日ごろの備え

- 乗車したら最寄りの非常用ハンマーと非常通話装置の位置を目で確かめておきます。
- 地下鉄の駅では出口番号と方向を覚えておきます。停電すると方向感覚を失いやすくなります。
- ホームではホームドアに寄りかかったり、線路側に身を乗り出したりしないでください。
