# 1. 生物武器的特性

## 1-1. 极难察觉
> 生物武器最危险之处在于：无法立即察觉自己已遭袭击。

- 化学武器和核武器有爆炸、烟雾等可见征兆，而生物武器在施放之初往往既看不见也闻不到。
- 从病原体施放到经过潜伏期出现病人，可能需要数日至数周，这期间感染已大范围扩散。

## 1-2. 潜伏期放大了扩散
- 病原体的潜伏期因种类而异，短则1天，长则数周。
- 潜伏期内感染者没有症状，照常活动，并在此过程中把病原体传给他人。
- 因此生物武器袭击极易错过初期应对，被发现时可能已有相当多的人被感染。

# 2. 主要病原体

症状因人而异，最快可在数小时内出现。

| 病原体 | 潜伏期 | 症状与危险 |
| --- | :---: | --- |
| 病毒性出血热 | 未知 | 高热、肌肉痛、腹泻、胸痛、出血。严重时一周后约90%可能死亡 |
| 蓖麻毒素 | 24小时内 | 呕吐、腹泻、呼吸困难、肺水肿。大量接触可能3天内死亡 |
| 天花 | 3天内 | 脓疱、高热、乏力。严重时2周内约30%可能死亡 |
| 肉毒中毒 | 3天内 | 呼吸困难、肌肉麻痹。严重时1天内可能死亡 |
| 土拉菌病 | 5天内 | 高热、寒战、肌肉痛、淋巴结肿大、皮肤溃疡。可发展为肺炎和呼吸衰竭。传染力强，但人际传播极少 |
| 霍乱 | 5天内 | 腹泻、呕吐、脱水。不治疗可因严重脱水死亡，但经适当补液治疗病死率大幅下降。 水源性传播风险高 |
| 炭疽杆菌 | 6天内 | 频繁咳嗽、呼吸困难、肌肉麻痹。严重时2天内可能死亡 |
| 鼠疫 | 6天内 | 高热、呼吸困难、头痛、咳嗽。严重时4天内可能死亡 |
| 马尔堡热 | 10天内 | 高热、寒战、肌肉痛、皮疹、出血。可因出血和器官衰竭死亡 |
| 尼帕病毒 | 2周内 | 发热、头痛、嗜睡、昏迷、脑炎。可因中枢神经受累死亡。部分情况下可人际传播 |
| 埃博拉 | 3周内 | 高热、肌肉痛、呕吐、腹泻、出血。可因多器官衰竭和大出血死亡。经体液接触传播 |
| Q热 | 3周内 | 高热、剧烈头痛、肌肉痛、肺炎或肝炎。慢性化可并发心内膜炎等。存在空气传播的可能 |
| 布鲁氏菌病 | 4周内 | 发热、出汗、乏力、关节痛、肌肉痛。慢性化会侵犯肝、脾、心等多个器官，造成长期衰弱。病死率较低但功能持续下降 |
| 汉坦病毒 | 5周内 | 发热、肌肉痛、咳嗽，随后可发展为急性呼吸衰竭或肾综合征出血热。可因急剧肺水肿和缺氧死亡 |

> 沙林不是生物武器，而是化学神经性毒剂。 沙林等化学战剂的应对请参阅《化学武器》文档。

# 3. 可疑袭击的征兆

出现以下情况时，应怀疑是生物武器袭击。

- 出现大量症状相似的急性病人
- 出现与地区或季节不相符的疾病
- 在没有明显原因的情况下动物或家畜集体死亡

> 即使政府尚未发布通报，一旦观察到这些征兆，也要立即采取个人防护措施，等待官方指引。

# 4. 传染病的传播途径

传染病因病原体种类不同，经由多种途径传播。

- 经空气的飞沫传播（咳嗽、打喷嚏）
- 直接接触传播（与病人的身体接触）
- 媒介传播（蚊、蚤等害虫）
- 经口传播（摄入受污染的水或食物）
- 血液传播

传染病发生时，要通过政府通报或新闻确认其传播途径、症状和潜伏期，并采取与途径相匹配的预防措施。

> 至今仍有许多病毒和生物武器病原体没有疫苗和特效药。
> 预防才是最好的应对，不被感染最为关键。
