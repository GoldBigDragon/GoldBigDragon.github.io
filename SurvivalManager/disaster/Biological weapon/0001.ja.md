# 1. 生物兵器の特性

## 1-1. 探知がきわめて難しい
> 生物兵器のもっとも危険な点は、攻撃を受けたことにすぐ気づけないことです。

- 化学兵器や核兵器には爆発や煙といった目に見える兆候がありますが、生物兵器は散布の直後に見えも、においもしないことがほとんどです。
- 病原体の散布から潜伏期を経て患者が出るまで数日から数週間かかることがあり、その間に感染が広く広がります。

## 1-2. 潜伏期が拡大を生む
- 病原体の潜伏期は種類によって短ければ1日、長ければ数週間です。
- 潜伏期のあいだ感染者は症状がなく、ふだんどおりに活動し、その過程で他人へ伝えます。
- そのため生物兵器の攻撃は初動が遅れやすく、見つかったときにはすでに相当数が感染していることがあります。

# 2. 主な病原体

症状は人によって異なり、早ければ数時間以内に出ることもあります。

| 病原体 | 潜伏期 | 症状と危険 |
| --- | :---: | --- |
| ウイルス性出血熱 | 不明 | 高熱、筋肉痛、下痢、胸の痛み、出血。重くなると1週間後に約90%が死亡しうる |
| リシン | 24時間以内 | 嘔吐、下痢、呼吸困難、肺水腫。大量にさらされると3日以内に死亡しうる |
| 天然痘 | 3日以内 | 発疹（膿疱）、高熱、疲労。重くなると2週間内に約30%が死亡しうる |
| ボツリヌス症 | 3日以内 | 呼吸困難、筋肉のまひ。重くなると1日内に死亡しうる |
| 野兎病 | 5日以内 | 高熱、悪寒、筋肉痛、リンパ節の腫れ、皮膚の潰瘍。肺炎と呼吸不全へ進むことがある。感染力は高いが人から人へはほとんど伝わらない |
| コレラ | 5日以内 | 下痢、嘔吐、脱水。治療しなければ重い脱水で死亡するが、適切な輸液で致命率は大きく下がる。 水系感染の危険が高い |
| 炭疽菌 | 6日以内 | 頻繁な咳、呼吸困難、筋肉のまひ。重くなると2日内に死亡しうる |
| ペスト | 6日以内 | 高熱、呼吸困難、頭痛、咳。重くなると4日内に死亡しうる |
| マールブルグ熱 | 10日以内 | 高熱、悪寒、筋肉痛、発疹、出血。出血と臓器不全で死亡しうる |
| ニパウイルス | 2週間以内 | 発熱、頭痛、眠気、昏睡、脳炎。中枢神経の侵襲で死亡しうる。一部で人から人への伝播あり |
| エボラ | 3週間以内 | 高熱、筋肉痛、嘔吐、下痢、出血。多臓器不全と大量出血で死亡しうる。体液の接触で伝播 |
| Q熱 | 3週間以内 | 高熱、激しい頭痛、筋肉痛、肺炎または肝炎。慢性化すると心内膜炎などの合併症。空気中の伝播の可能性 |
| ブルセラ症 | 4週間以内 | 発熱、発汗、疲労、関節痛、筋肉痛。慢性化すると肝臓・脾臓・心臓など多くの臓器を侵し、長く衰弱させる。致命率は低いが機能の低下が続く |
| ハンタウイルス | 5週間以内 | 発熱、筋肉痛、咳のあと、急性呼吸不全か腎症候性出血熱へ進行しうる。急激な肺水腫と低酸素で死亡しうる |

> サリンは生物兵器ではなく、化学の神経剤です。 サリンなど化学剤への対応は「化学兵器」の文書を参照してください。

# 3. 攻撃を疑う兆候

次のことが見られたら、生物兵器による攻撃を疑わねばなりません。

- 似た症状の急性の患者が大規模に発生する
- 地域や季節に合わない疾病が発生する
- はっきりした原因なく動物や家畜が集団で死ぬ

> 政府の発表の前でも、こうした兆候が見えたらただちに個人の防護措置をとり、政府の案内を待ちます。

---

# 4. 感染症の伝わり方

感染症は病原体の種類によってさまざまな経路で広がります。

- 空気を介した飛沫感染（咳、くしゃみ）
- 直接接触感染（患者との身体の接触）
- 媒介感染（蚊、ノミなどの害虫）
- 経口感染（汚染された水や食べ物）
- 血液感染

感染症が発生したら、政府の発表やニュースでその病の伝播経路、症状、潜伏期を確かめ、経路に合った予防措置をとらねばなりません。

> いまも多くのウイルスや生物兵器の病原体にはワクチンも治療薬もありません。
> 予防が最善の対応であり、感染しないことがもっとも大切です。
