# 8. 警報解除

攻撃の直後、追加の攻撃が予想されないときに発令されます。サイレンはなく、音声放送と民防空警報メールで伝えられます。

> 警報解除は完全な安全を意味しません。 追加の空襲に備え、政府の案内放送を聞き続けて状況を見守ります。

## 8-1. すべきこと
1. けが人の救助と治療を手伝い、復旧活動に協力します。
2. 化学生物の汚染があった場合は、せっけん水で体を洗い流します。
3. 汚染された服と靴はビニールに入れて密封し、二次汚染を防ぎます。
4. 二次被害に注意します - 壊れた建物やがれきによるけが、感電、火災、感染症。
5. 電気・水道・ガスの供給が止まってから再開するときは、火災と浸水に注意します。
6. 生活必需品の買いだめを控え、政府の配給に協力します。
   - 政府は非常事態の際に重要な生活必需品を指定して需給を管理し、流通が難しい品目は必要に応じて配給制を実施します。

## 8-2. 不発弾
> 爆発しなかった不発弾を見つけたら、絶対に近づかず、軍の部隊などの関係機関へ通報します。
> とくにクラスター弾には格別の注意が必要です。数百個の子弾（小さな爆弾）が散らばって落ち、不発の確率が高く、子弾が缶や玩具のように見えるため、民間人が触れて被害を受ける例が多いのです。

## 8-3. してはいけないこと
- 不発弾に近づくこと
- 政府の安全確認がないまま化学生物の汚染地域に立ち入ること
- 確認されていない流言を広めること
- 生活必需品の買いだめ

# 9. 日ごろの備え

## 9-1. 近くの避難所をあらかじめ把握
家庭、職場、学校など普段いる場所からもっとも近い民防衛避難所を事前に確かめておきます。
ネイバー地図、カカオマップ、Tマップ、安全ディディムドルのアプリで「민방위 대피소（民防衛避難所）」 を検索すると、現在地からもっとも近い避難所が分かります。

## 9-2. 攻撃の種類別に適した避難場所

| 攻撃の種類 | 適した避難場所 |
| --- | --- |
| 在来型兵器による攻撃 | 民防衛避難所、マンションや大型建物の地下駐車場、地下鉄の駅舎 |
| 化学攻撃 | 外気を遮断できる高い階の屋内空間 |
| 生物攻撃 | 指定避難施設や自宅など、外気を遮断してとどまれる屋内 |
| 核・放射能攻撃 | 民防衛避難所、マンションや大型建物の地下駐車場、地下鉄の駅舎 |

> 化学攻撃だけは地下ではなく高い階です。 化学剤が空気より重く、下へ沈むからです。

## 9-3. 生存リュック
- 2〜3日分の飲み水、食料、生活必需品、常備薬、ラジオ、懐中電灯、化学生物対策用品をかばんやキャリーに入れて用意します。
- 一人がそれぞれ持って動けるよう、1人分ずつに分けて準備します。
- 核の事態に備えるなら2週間以上もつ物資が必要です。

## 9-4. 家族の計画
- 通信の断絶に備え、家族と落ち合う場所を決めておきます。 非常時の集合場所は第1、第2、第3まで決めます。
- 家族の非常連絡カードを作って生存リュックに入れておきます。カードに書くもの：
  - 個人事項、家族事項、血液型、服用中の薬
  - 自宅・職場・学校の連絡先
  - 通報・救護および政府関係機関の連絡先
