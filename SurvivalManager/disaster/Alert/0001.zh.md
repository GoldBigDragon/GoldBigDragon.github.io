# 1. 何谓民防空警报

当敌方地面、海上、空中力量的攻击被预判或正在进行时，大韩民国政府运行覆盖全国的民防空警报体系，以迅速告知国民。

传达手段：警报器 · 语音广播 · 广播电视字幕 · 手机民防空警报短信（CBS）

## 1-1. 五个等级 - 分别以什么信号传来

| 警报 | 何时发布 | 警报器 | 传达手段 |
| --- | --- | --- | --- |
| 警戒警报 | 攻击被预判时 | 无 | 语音广播、警报短信 |
| 空袭警报 | 攻击临近或正在进行 | 有 - 5秒上升、3秒下降反复，持续1分钟 | 警报器、语音广播、警报短信 |
| 化生放警报 | 化学、生物战剂的施放被探测或确认时 | 无 | 语音广播、警报短信 |
| 核警报 | 核攻击临近或正在进行，或预判将发生核爆炸时 | 有 - 5秒上升、3秒下降反复，持续1分钟 | 警报器、语音广播、警报短信 |
| 解除警报 | 攻击刚过、预判不会再有攻击时 | 无 | 语音广播、警报短信 |

> 没有警报器鸣响，并不等于没有警报。
> 警戒警报、化生放警报和解除警报都是不鸣警报器，仅通过语音广播和手机警报短信传达。务必确认短信和广播。

> 非民防空的一般灾害警报由2秒上升、2秒下降的警报器声与语音广播另行传达。请与空袭警报、核警报的5秒／3秒信号区分记忆。

警报种类不同，应采取的行动完全不同。 平时充分熟悉各警报的含义和行动要领，才能在实际情况下迅速准确应对。

# 2. 警戒警报 - 攻击被预判的阶段

攻击尚未开始，但已探测到威胁。要集中于做好撤离准备和掌握情况。

## 2-1. 应做的事
1. 立即打开电视、广播，按政府指引行动。
2. 取出生存背包、应急物品、防毒面具、防护服，使其处于随时可用状态。
3. 防止次生灾害 - 把煤油和煤气罐移到安全处，关闭室外燃气阀门，拔掉电热器插头。
4. 建议让儿童和老弱者提前撤到安全场所。情况紧迫后就难以迅速转移了。
5. 给食物和饮用水加盖，防止外部污染物进入。
6. 夜间关灯，并用窗帘或百叶窗遮挡灯光外泄。 这是为了让空中攻击难以识别目标。
7. 注意掉落物，减少户外活动。
8. 人员密集场所（剧场、运动场、餐饮店）应停止营业，向顾客传达警报内容并有序分批撤离，以防拥挤和事故。
9. 预判有航空器攻击时，撤入民防避难所等地下设施。

## 2-2. 不应做的事
- 不必要的外出
- 不必要的电话使用 - 必须避免通信网瘫痪
- 轻信社交媒体上的谣言，或随意传播未经核实的信息

# 3. 空袭警报 - 攻击临近或正在进行

必须立即撤离。

广播内容依情况分为航空器侵入、导弹发射、炮击等。
例："○○:○○ 朝鲜航空器侵入，○○地区空袭警报，请撤入地下设施或建筑物内"

## 3-1. 应做的事
1. 带上生存背包，撤到最近的民防避难所、地下设施，或混凝土建筑内没有玻璃窗的安全处。
2. 身处高层建筑时走楼梯下到地下室或较低层。
3. 绝对不要乘电梯。
4. 驾车时把车停在附近空地或道路右侧，把车钥匙留在车上再撤离。
   - 车辆堵路会妨碍救援车辆和军用车辆通行。留下钥匙，必要时才能挪车。
5. 撤离后要注意收听政府广播，并通过收音机掌握爆炸位置、风向和受灾情况。
6. 帮助老弱者、儿童、孕产妇、残障人士一同撤离。

## 3-2. 特殊情况下的注意
- 在梅雨、台风等预计有集中降雨的时期，不要撤入易涝低洼地区的地下设施，而应前往更安全的地区。
- 无法前往地下设施时，要利用混凝土建筑内没有玻璃窗的位置、防火与避难设施、沟渠等周边设施。

## 3-3. 不应做的事
- 乘用电梯
- 不必要的通信使用
- 凭个人判断行动 - 必须遵从政府指引
- 被谣言动摇
