# 7. 除染の準備

## 7-1. 除染に使えるもの

| もの | 用途 |
| :---: | :--- |
| 食塩水 | 傷の除染、目・耳・鼻・口の除染 |
| 3%過酸化水素水 | 傷の除染の補助 |
| せっけん | 身体の除染 |
| シャンプー | 身体の除染 |
| 重曹 | 身体の除染、口の除染、物の除染 |
| 洗剤 | 物の除染 |
| 塩素系漂白剤 | 物の除染 |

## 7-2. 除染の場所
- 除染のための場所を用意し、床にビニールを敷いて避難空間に汚染物質が残らないようにします。
- 除染で出る汚染水が避難空間を汚さないよう、あらかじめ備えておくことが大切です。

## 7-3. 汚染された衣類と持ち物
1. 上着、時計、装飾品を外してから避難空間に入ります。
2. ビニール袋や密閉できるプラスチックに入れて密閉し、人やペットから離れた家の外の安全な場所に置きます。
3. ゆっくり慎重に脱ぎます。 汚染物質が舞い上がるのを防ぐためです。

> 頭から服を脱ぐと汚染の粒子が顔につきます。
> できれば服を切って脱ぐほうがよいです。

# 8. 部位ごとの除染

## 8-1. 順序 - 必ずこの順で
> ① 開いた傷 → ② 体の開口部（目・耳・鼻・口） → ③ 傷のない皮膚
>
> この順序は汚染物質が体内に入るのを最小限にするためです。

## 8-2. 傷
- 食塩水で十分に洗い流し、必要なら3%過酸化水素水で追加して洗います。
- ガーゼで拭き取り、消毒された防水素材で覆って追加の汚染を防ぎます。
- 傷から放射性物質が体内へ直接入るので、傷の除染をいちばん先に行います。

## 8-3. 全身のシャワー
- 被ばくしていないきれいなぬるま湯と中性せっけんで、頭から足先まで洗います。
  - 熱い湯は毛穴を開き、放射性物質の体内への吸収を促します。 必ずぬるめの湯を使います。
- 頭を後ろへ倒して洗います。 うつむいて洗うと汚染された水が顔に流れ落ちます。
- 髪は2回以上繰り返してシャンプーかせっけんで十分に洗います。髪は放射性の粒子が落ちにくい部位です。
- リンスは絶対に使いません。 放射性物質を髪のたんぱく質に結びつけ、除染をかえって難しくします。
- 洗うときは目・鼻・口・耳に水が入らないよう注意します。
- あかすりタオルや粗いタオルでこすりません。 皮膚に細かい傷ができると放射性物質が体内に入ります。
- 耳、皮膚のしわ、爪の間も丁寧に洗います。
- シャワーのあとはきれいなタオルで慎重に拭き、汚染されていない服に着替えます。
- シャワーができないときは、濡れたタオルで露出していた皮膚を拭きます。

## 8-4. 目
- 眼球が傷ついていなければ、水か生理食塩水で十分に洗い流します。
- 食塩水が目の内側から外側へ流れるようにして、涙管を通って鼻へ汚染物質が入らないようにします。

## 8-5. 耳
> 核爆発の衝撃波で鼓膜が破れていることがあります。 除染の前に必ず鼓膜の状態を確かめます。

- 鼓膜が破れていたら洗浄せず、病院で治療を受けます。
- 傷ついていなければ、水か食塩水で外耳道を洗い、水に浸した綿棒で拭きます。

## 8-6. 鼻
- 意識があれば自分で鼻をかませます。
- 水に浸した綿棒で、鼻の内側の粘膜が傷つかないように拭きます。

## 8-7. 口
- 口の周りを拭き、生理食塩水か水で2〜3回以上しっかりうがいします。
- 歯ブラシと歯みがき粉で傷をつけないよう注意して歯を磨き、口の中をこまめにすすぎます。
- うがい液を飲み込まないよう注意します。

## 8-8. 廃棄物の処理
- すすいだ洗浄液と使った道具はビニールに密閉し、安全な場所に保管します。
- この廃棄物は放射能に汚染されています。 むやみに捨てず、関係機関の指示にしたがって処理します。
