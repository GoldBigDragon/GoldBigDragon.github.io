# 7. 洗消准备

## 7-1. 可用于洗消的物品

| 物品 | 用途 |
| :---: | :--- |
| 生理盐水 | 伤口洗消，眼·耳·鼻·口洗消 |
| 3%过氧化氢溶液 | 伤口洗消的辅助 |
| 肥皂 | 身体洗消 |
| 洗发水 | 身体洗消 |
| 小苏打 | 身体洗消、口腔洗消、物品洗消 |
| 洗涤剂 | 物品洗消 |
| 含氯漂白剂 | 物品洗消 |

## 7-2. 洗消空间
- 要准备洗消空间并在地面铺上塑料布，避免污染物残留在避难空间。
- 要事先做好准备，防止洗消产生的污水污染避难空间。

## 7-3. 受污染的衣物与随身物品
1. 脱掉外衣、手表、饰品后再进入避难空间。
2. 装入塑料袋或可密封的塑料容器密闭，放到远离人和宠物的屋外安全处。
3. 要缓慢、小心地脱，防止污染物扬起。

> 从头上脱衣会让污染颗粒沾到脸上。
> 可能时把衣服剪开脱下更好。

# 8. 各部位的洗消

## 8-1. 顺序 - 必须按此顺序
> ① 开放性创口 → ② 身体开口（眼·耳·鼻·口） → ③ 无创口的皮肤
>
> 这个顺序是为了尽量减少污染物进入体内。

## 8-2. 创口
- 用生理盐水充分冲洗，必要时再用3%过氧化氢溶液冲洗。
- 用纱布擦拭后，以消毒的防水材料覆盖，防止进一步污染。
- 放射性物质会经创口直接进入体内，因此创口洗消要放在最前面。

## 8-3. 全身淋浴
- 用未受污染的洁净温水和中性皂，从头到脚清洗。
  - 热水会打开毛孔、促进放射性物质进入体内。 务必使用温水。
- 要把头向后仰着洗。 低头洗会让污染的水顺着脸流下。
- 头发要用洗发水或皂重复清洗2次以上。 头发是放射性颗粒最难清除的部位。
- 绝对不要使用护发素。 它会让放射性物质与发丝蛋白结合，反而使洗消更困难。
- 洗头时要注意不让水进入眼、鼻、口、耳。
- 不要用搓澡巾或粗糙浴巾摩擦。 皮肤出现细微破损会让放射性物质进入体内。
- 耳朵、皮肤褶皱、指甲缝也要仔细清洗。
- 淋浴后要用干净毛巾小心擦干，换上未受污染的衣物。
- 无法淋浴时，用湿毛巾擦拭裸露过的皮肤。

## 8-4. 眼
- 若眼球未受损，用清水或生理盐水充分冲洗。
- 要让盐水从眼内侧流向外侧，避免污染物经泪管进入鼻腔。

## 8-5. 耳
> 核爆的冲击波可能已造成耳膜穿孔。 洗消前必须确认耳膜状态。

- 耳膜穿孔时不要冲洗，应到医院治疗。
- 耳膜完好时，用清水或盐水冲洗外耳道，再用蘸水的棉签擦拭。

## 8-6. 鼻
- 意识清醒时让其自行擤鼻。
- 用蘸水的棉签擦拭，注意不要损伤鼻腔内侧黏膜。

## 8-7. 口
- 擦净口周，用生理盐水或清水漱口2～3次以上。
- 用牙刷牙膏小心刷牙以免受伤，并勤漱口。
- 注意不要吞下漱口液。

## 8-8. 废弃物处理
- 冲洗后的液体和使用过的工具要密封在塑料袋内，存放到安全处。
- 这些废弃物已被放射性污染。 不可随意丢弃，要遵照有关机构的指示处理。
