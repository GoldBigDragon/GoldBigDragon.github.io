# 1. 核爆炸的五种效应

核爆炸会同时产生五种效应。

| 效应 | 会发生什么 |
| --- | --- |
| ① 热辐射 | 爆炸后持续数秒的强烈光和热。可在相当远的距离造成暂时或永久失明、烧伤和大规模火灾 |
| ② 早期核辐射 | 爆炸瞬间产生的穿透力极强的强辐射。使爆心附近的一切遭受急性放射病 |
| ③ 冲击波与爆风 | 强风和冲击波摧毁建筑、抛散碎片。钢筋混凝土建筑不易倒塌，但飞散的玻璃碎片会伤及内部人员 |
| ④ 残留辐射与沉降物 | 爆炸1分钟后开始落下的、被超高温熔化后凝固的放射性颗粒。长时间释放致命辐射并造成内照射 |
| ⑤ 电磁脉冲（EMP） | 爆炸瞬间的强电磁波破坏电子线路。高空爆炸会使大范围的电子产品和车辆永久损坏，并造成大面积停电 |

能量分配：冲击波 50%·热辐射 35%·残留辐射（沉降物）10%·早期核辐射 4%·EMP 1%

# 2. 威力与破坏范围

以1945年投于长崎的20千吨核弹为基准

| 效应 | 破坏范围 |
| --- | --- |
| 冲击波 | 4公里以内的建筑与人员伤害 |
| 热辐射 | 4公里以内的建筑与人员伤害，2.5公里以内全部烧毁 |
| 辐射 | 至少30公里以内的人员伤害 |

> 当前核国家实战部署的洲际弹道导弹弹头大多为150～800千吨。
> 可造成比长崎核弹强数十倍的破坏。

# 3. 平时的准备

## 3-1. 事先掌握撤离路线与避难所
> 地下设施对热辐射、冲击波、早期核辐射和沉降物提供最有效的屏蔽。

- 掌握距家庭、单位、学校最近的地下设施 - 民防避难所、地铁车站、地下停车场、地下商城、隧道 - 的位置与前往路线。
- 在Naver地图、Kakao Map、T map、安全踏板应用中搜索"민방위 대피소"（民防避难所），即可查到最近的位置。

## 3-2. 事先储备物资
- 可能需要两周以上的长期避难。请在地下备好能维持两周的物资。
- 应急食品以罐头、压缩饼干、能量棒、冻干食品等无需烹调的为主，并考虑营养均衡备齐多个品种。
- 饮用水按每人每天至少2.5升准备。
- 防停电：手电筒（电池）、蜡烛、打火机（火柴）
- 防燃气中断：便携燃气炉、丁烷气罐

## 3-3. 生存背包与防护装备
> 核袭击时没有时间收拾物品。 背包必须提前打包好。

- KS M 6685认证防毒面具，或KF94防尘口罩、1级以上防尘口罩。防毒面具能有效阻断沉降物颗粒的吸入。
- 防护服、急救用品
- 护目镜 - 防止放射性颗粒进入眼睛。

## 3-4. 辐射测量仪
> 辐射无法用人的五感感知，只能通过测量仪确认。

它可以掌握所在位置的污染程度，并确认皮肤和装备是否已洗消干净，是极为有用的装备。

## 3-5. 维生素C
- 维生素C有减轻辐射受照时基因损伤的作用。
- 预判将遭核袭击时成人事先摄取1克，可一定程度减轻基因损伤。

## 3-6. 阻挡热辐射
- 热辐射会透过窗户进入室内，点燃窗帘和家具。
- 事先在窗户上贴铝箔可反射热辐射，降低失明、烧伤和室内火灾的风险。

## 3-7. 防范EMP - 法拉第笼
- 把收音机、手电筒等重要电子设备事先放入金属密闭的罐中，可降低EMP造成的损害。
- 存放时要用纸或气泡膜使设备与罐壁保持距离。
- 但一般材料无法完全屏蔽EMP，部分仍会穿透。

> 爆炸后已被EMP损坏的设备放入罐中毫无意义。必须事先存放。

- EMP可能损坏手电筒。 还要一并准备荧光棒或茶蜡（扁平小蜡烛） 等非电子照明手段。

## 3-8. 家庭紧急联络计划与衣着
- EMP可能使通信基础设施完全瘫痪。 不依赖电话和即时通讯的事先约定必不可少。
- 约定会合地点，并填写家庭紧急联络卡放入生存背包。
- 预判将遭核袭击时要穿长衣尽量减少皮肤裸露。长衣可防热辐射烧伤和沉降物直接接触皮肤。
