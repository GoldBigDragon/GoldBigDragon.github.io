# 关于燃气，必须知道的两件事

| 项目 | 液化石油气（丙烷、丁烷） | 城市燃气 天然气（甲烷） |
| --- | --- | --- |
| 与空气相比 | 更重 | 更轻 |
| 聚集位置 | 地面、地下室、下水口 | 天花板 |
| 闻气味的位置 | 靠近地面 | 靠近天花板 |
| 通风方式 | 用扫帚、坐垫沿地面扫出门外 | 打开窗户排出上方空气 |

- 燃气本身无色无味，我们闻到的气味是为安全特意添加的加臭剂。

---

# 预防燃气事故

## 1. 使用前
- 液化石油气和天然气的灶具不通用，必须使用与所供燃气匹配的器具。
- 使用前按上表的高度闻一闻，确认有无泄漏。
- 使用时打开窗户通风。
- 灶台周围不要放易燃物品。
- 用肥皂水或洗涤剂打泡，经常检查管道与软管接口。
- 定期清理灶头，防止火孔堵塞。

## 2. 使用中
- 使用时尽量不要离开。
- 务必确认火已点着。未点燃却打开旋钮，燃气会持续外泄。
- 调节风门使火焰呈蓝色。红色火焰是不完全燃烧，会产生一氧化碳和有毒气体，还更费燃料。
- 灶具固定在一处使用，不要频繁挪动。

## 3. 便携式卡式炉
- 不要在密闭帐篷或狭小房间内使用，窒息和起火风险很高。
- 不得已在室内使用时务必通风，并先在室外试用确认无异常。
- 不要放置大于炉架的锅具。 辐射热会烤热气罐并引发爆炸。
- 安装气罐时，让罐口的缺口朝上并完全卡紧。
- 使用中一旦漏气，立即上扳连接杆卸下气罐。
- 用完的气罐要扎孔排净余气，丢弃在远离火源的地方。

# 疑似泄漏的信号

- 闻到燃气特有的加臭剂气味。
- 使用中火焰突然熄灭，或变成红色火焰（不完全燃烧）。
- 燃气费突然上涨。
- 在接口处涂肥皂水会冒泡。
- 出现头痛、头晕、恶心等中毒早期症状。

---

# 发生燃气泄漏时

1. 不要制造任何火花。 开关、排风扇、门铃、手机通话都会产生电火花。打电话务必到室外。
2. 用湿毛巾捂住口鼻，压低身体进入。
3. 关闭中间阀和总阀。
4. 打开所有窗户和大门，让新鲜空气进入。
5. 怀疑是液化石油气时，用扫帚或坐垫把贴地的燃气扫出门外。
6. 若有人中毒，抱起或拖到室外或通风良好处。
7. 拨打119，并通知城市燃气公司（天然气）或液化气经销点。
8. 未确认燃气完全排净前，不要返回室内。

---

# 心肺复苏（CPR）

1. 判断反应 - 轻拍双肩并呼唤。
2. 呼救 - 拨打119，请周围的人取来自动体外除颤器（AED）。
3. 观察呼吸 - 在10秒内查看胸廓起伏。
4. 胸外按压30次 - 双手重叠置于胸部正中（胸骨下半部），按压深度约5厘米，频率每分钟100～120次，用力快速。每次按压后让胸廓完全回弹。
5. 人工呼吸2次 - 仰头抬颏打开气道，捏住鼻子吹气1秒，观察胸廓是否抬起。
6. 循环进行 - 按30∶2重复，直到急救人员到达或伤者恢复。

> 若对人工呼吸没有把握，或怀疑存在燃气、化学污染，只做胸外按压也可以。最重要的是不要中断。

# 燃气火灾

## 1. 灶台周围的小火
1. 先关燃气阀门。
2. 灭火器像扫地一样左右喷射。没有灭火器时，用锅盖或湿毯子、湿毛巾盖住隔绝氧气。
3. 油锅起火绝不能泼水，油会飞溅，火势会瞬间爆燃。
4. 火熄灭后，再次确认阀门完全关闭，并开窗通风。

## 2. 火势扩大时
1. 大喊"着火了！"并按下火灾报警按钮。
2. 撤离前随手关门，延缓火焰和烟雾扩散。
3. 用湿毛巾捂住口鼻，压低身体移动。
4. 不坐电梯，走楼梯撤离。
5. 衣服着火时站住 → 卧倒 → 翻滚。
6. 门把手发烫时不要开门，改到窗口或阳台发出求救信号。
7. 无法逃生时，用毛巾、被子堵住门缝，拨打119告知具体位置，并在窗口发出信号。

## 3. 液化气钢瓶着火时
- 千万不要先去灭火。 泄漏未止时只把火扑灭，燃气会继续外泄积聚，爆炸风险反而更高。
- 如果能安全靠近，先关阀门，再用湿布给钢瓶降温。
- 无法关闭阀门时，立即远离现场。
- 爆炸巨响可能损伤听力，撤离时请捂住耳朵。

# 一氧化碳中毒

- 一氧化碳无色无味，也不含加臭剂，靠嗅觉无法察觉。
- 症状：头痛 → 头晕恶心 → 判断力下降 → 失去意识。很多人是在睡梦中死亡的。
- 预防：定期检查取暖设备和锅炉的排气管，绝不在室内或帐篷内烧炭、烧蜂窝煤或使用卡式炉。
- 发电机、炭火烤炉只能在远离窗户的室外使用。
- 家中安装一氧化碳报警器是最可靠的防护。
- 一旦怀疑中毒，立即开窗通风并到室外，然后拨打119。
