# ガスの性質 - これだけは覚えてください

| 区分 | LPG（プロパン・ブタン） | 都市ガス LNG（メタン） |
| --- | --- | --- |
| 空気との比較 | 重い | 軽い |
| たまる場所 | 床、地下、排水口 | 天井 |
| においの確認 | 床の近くで | 天井の近くで |
| 換気の方法 | ほうき・座布団で床から戸外へ掃き出す | 窓を開けて上の空気を逃がす |

- ガス自体は無色無臭です。私たちが感じるにおいは、安全のためにわざと加えた付臭剤です。

# ガス事故の予防

## 1. 使用前
- ガス器具はLPG用とLNG用で異なります。使っているガスに合った器具を使ってください。
- 使用前に上の表の高さでにおいを確かめ、漏れがないか確認します。
- 使用中は窓を開けて換気します。
- ガスこんろの周りに燃えやすい物を置かないでください。
- 石けん水や洗剤で泡を立て、配管やホースの接続部をこまめに点検します。
- バーナーの炎口が詰まらないよう、定期的に掃除します。

## 2. 使用中
- 使用中はできるだけその場を離れないでください。
- 火がついたか必ず確認します。点火しないままコックが開くと、ガスが漏れ続けます。
- 空気調節器を回して青い炎にします。赤い炎は不完全燃焼で、一酸化炭素と有毒ガスが出て燃料も多く消費します。
- ガスこんろは一か所に固定して使ってください。

## 3. カセットこんろ
- 密閉したテントや狭い部屋では使わないでください。 窒息と火災の危険が高いです。
- やむを得ず室内で使うときは必ず換気し、屋外で試して異常がないことを確かめてから使います。
- 五徳より大きい鍋を載せないでください。 輻射熱でボンベが加熱され、爆発します。
- ボンベは上部の切り欠きが上を向くように完全に取り付けます。
- 使用中にガスが漏れたら、連結レバーを上げてただちにボンベを外します。
- 使い切ったボンベは穴を開けて残ガスを抜き、火の気のない場所に捨てます。

---

# ガス漏れが疑われるサイン

- ガス特有の付臭剤のにおいがする。
- 使用中に炎が急に消える、または赤い炎（不完全燃焼）になる。
- ガス料金が急に増えた。
- 接続部に石けん水を塗ると泡が出る。
- 頭痛・めまい・吐き気など中毒の初期症状が出る。

---

# ガスが漏れているとき

1. 火花をつくらないでください。 スイッチ、換気扇、インターホン、携帯電話の通話はすべて火花を出します。通話は必ず屋外で。
2. ぬらしたタオルで口と鼻を覆い、姿勢を低くして入ります。
3. 中間バルブと元栓を閉めます。
4. 窓と玄関をすべて開けて新鮮な空気を入れます。
5. LPGが疑われるときは、ほうきや座布団で床のガスを戸外へ掃き出します。
6. 具合の悪い人がいれば、抱えるか引きずって屋外か風通しのよい場所へ移します。
7. 119へ通報し、都市ガスなら供給会社、LPGなら販売店にも連絡します。
8. ガスが完全に抜けたと確認できるまで、室内に戻らないでください。

# 心肺蘇生法（CPR）

1. 反応の確認 - 両肩を軽くたたきながら呼びかけます。
2. 応援要請 - 119へ通報し、周囲にAED（自動体外式除細動器）を持ってくるよう頼みます。
3. 呼吸の確認 - 胸の上下動を10秒以内に確認します。
4. 胸骨圧迫30回 - 両手を重ねて胸の中央（胸骨の下半分）を約5cmの深さで、1分間に100〜120回のテンポで強く速く押します。圧迫のたびに胸が完全に戻るようにします。
5. 人工呼吸2回 - 頭を後ろに傾けあごを上げて気道を確保し、鼻をつまんで1秒間息を吹き込み、胸が上がるか見ます。
6. 繰り返し - 救急隊の到着か回復まで30：2を続けます。

> 人工呼吸に自信がないとき、またはガスや化学物質による汚染が疑われるときは、胸骨圧迫だけを続けても構いません。 止めないことがいちばん大切です。

# ガス火災

## 1. こんろ周りの小さな火
1. まずガス栓を閉めます。
2. 消火器をほうきで掃くように左右へ噴射します。消火器がなければ、鍋のふたやぬれた毛布・タオルをかぶせて酸素を断ちます。
3. てんぷら油の火に水をかけてはいけません。 油が飛び散り、炎が爆発的に広がります。
4. 消えたら元栓が完全に閉まっているか再確認し、窓を開けて換気します。

## 2. 炎が大きくなったとき
1. 「火事だ！」と叫び、火災報知機を押します。
2. 避難する前にドアを閉め、炎と煙の広がりを遅らせます。
3. ぬれたタオルで口と鼻を覆い、姿勢を低くして移動します。
4. エレベーターは使わず、階段で避難します。
5. 服に火がついたら止まる → 伏せる → 転がる。
6. ドアノブが熱ければ開けず、窓やベランダから救助信号を送ります。
7. 脱出できないときは、ドアのすき間をタオルや布団でふさぎ、119に自分の居場所を伝えてから窓辺で合図します。

## 3. LPGボンベに火がついたとき
- 先に火を消そうとしないでください。 漏れが止まっていない状態で火だけ消すと、ガスがたまり続けて爆発の危険がかえって高まります。
- 安全に近づけるならバルブを閉めてから、ぬれた布でボンベを冷やします。
- バルブを閉められないときは、ただちに遠くへ避難します。
- 爆発音で聴覚を痛めるおそれがあるため、耳をふさいで避難してください。

# 一酸化炭素中毒

- 一酸化炭素は無色・無臭で、付臭剤も入っていません。においでは気づけません。
- 症状：頭痛 → めまい・吐き気 → 判断力の低下 → 意識消失。眠ったまま亡くなる例が多くあります。
- 予防：暖房機やボイラーの排気口を定期点検し、炭・練炭・カセットこんろを室内やテント内で使わないこと。
- 発電機や炭火グリルは、窓から十分離れた屋外だけで使います。
- 家庭には一酸化炭素警報器を設置するのが最も確実な備えです。
- 疑わしいときは、すぐ窓を開けて換気し、屋外へ出てから119へ通報してください。
