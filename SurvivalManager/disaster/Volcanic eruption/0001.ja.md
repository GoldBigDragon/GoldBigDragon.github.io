# 火山災害の種類

| 区分 | 内容と危険 |
| --- | --- |
| 火山灰 | 噴出する細かい粉。周囲を覆って大気を汚し、太陽をさえぎって異常低温を招き、火山雲で航空機の運航が止まり、大規模停電を引き起こすこともあります |
| 火砕物 | 噴出した大小の固体の破片 |
| 火山泥流（ラハール） | 水と火砕物が混じって高速で流れ下る泥流。土砂災害と洪水を起こし、地形を変えます |
| 溶岩 | 地表に流れ出た液体のマグマ。土地を覆い、山火事を起こします |

> 火山噴火の被害の大半は火山灰によるものです。

## 韓国の活火山
地質学では、1万年以内に噴火の記録がある火山を活火山とします。
- 白頭山 - 朝鮮半島の最高峰。山頂にカルデラ湖「天池」。946〜947年に大規模噴火、最後の噴火は1903年
- 漢拏山 - 山頂に火口湖「白鹿潭」。1002年と1007年に噴火の記録
- 鬱陵島 - 海から溶岩が噴き上がってできた火山島。過去2万年間、およそ3,000〜7,000年周期で噴火

# 日ごろの備え

火山灰が降り続くと、数時間から数日間、外出できないことがあります。
- 防じんマスクと保護めがね（KF94以上が有効です）
- 最低3日分の飲料水と手軽な食品
- ラジオと電池
- テープとラップ（窓のすき間の密閉、電子機器の保護用）
- 携帯ランプや懐中電灯
- ストーブと燃料、毛布と衣類
- 医薬品と救急箱
- ほうき、スコップなどの清掃用具
- 少額の現金
- 車内の防災用品
- 火山灰処理用の袋

# 火口周辺からの避難

- 火山は前ぶれなく噴火することがあります。
- 噴火すると大小の石が飛んできて、直接人体を傷つけます。
- 火口周辺で煙が見える、地下から地鳴りが聞こえる、異臭がするなどの異常に気づいたら、ただちに安全な地域へ避難し、警察などへ連絡します。
- できるだけ早く火口周辺を離れ、近くの避難所や岩陰に身を隠します。
- 火山ガスは空気より重く、谷にたまります。狭く低い場所は避けてください。
- ヘルメットとゴーグルを着け、マスクや濡れたタオルで口をふさぎます。
- 火砕流（火山灰とガスの雲）は非常に高温で速く、遠くまで届くため避難が困難です。車で速やかに離れてください。
- 火山泥流は谷を伝って下ります。谷から離れた高い場所へ避難します。
- 携帯電話やラジオで災害放送を聞き、指示に従ってください。

# 火山灰が降る前

- 屋外にいるなら速やかに建物の中へ避難します。
- 戸のすき間と換気口を濡れたタオルでふさぎ、窓はテープで密閉します。
- 慢性気管支炎、肺気腫、ぜんそくの方は屋内にとどまります。
- 排水路が詰まらないよう、雨どいの受けと排水管を屋根の樋から外します。
- 雨水を給水に使っている場合は、雨水収集設備とタンクをつなぐ配管を外します。
- 角膜を傷めるおそれがあるため、コンタクトレンズを外します。
- ラップで電子機器を包み、火山灰の侵入を防ぎます。
- 災害放送を聞いて対応要領を覚えておきます。

---

# 火山灰が降っている間

- できるだけ屋内にとどまり、テレビやラジオで災害放送を聞きます。
- 屋外にいる場合は、自動車や建物へ速やかに避難します。
- マスクやハンカチ、衣服で口と鼻をふさぎます。（KF94やKF80のマスクが有効です）
- 火山灰が入った飲み水は飲まないでください。
- 野菜はよく洗って食べます。
- 視力が弱い方はコンタクトレンズではなくめがねを使い、火山灰がひどいときは密閉型のゴーグルを着けます。
- 酸性雨が降ることがあります。雨に当たらないでください。
- 屋根に火山灰が積もると建物が崩れるおそれがあります。 適切な時期に取り除きます。
- 運転は控えてください。 火山灰で車が故障したり事故が起きたりします。やむを得ない場合は前照灯をつけ、ゆっくり走ります。

# 火山灰が降ったあと - 清掃

## 1. 共通
- ゴーグルとマスクを着け、屋内外と自動車を速やかに清掃します。マスクがなければ濡れた布を使います。
- 外で着た服は着替え、体をきれいに洗います。
- 火山灰が舞い上がらないよう、水を軽くまくか濡れた雑巾を使います。
- 集めた火山灰は丈夫なビニール袋に入れ、指定された場所に捨てます。

## 2. 屋外
- 建物、機械、自動車、上下水道設備に火山灰が入らないようにします。
- 機械は火山灰を完全に取り除くまで電源を切るか密閉します。
- 屋根の火山灰は適切な時期に水を使って清掃します。
- 芝生は水をまいてから刈ります。
- 1cm以上積もった火山灰はスコップで除去します。
- スプリンクラーなどで湿らせてから清掃します。
- 火山灰が排水口や下水に入らないようにします。
- 水をかけすぎると硬い塊になるので注意します。

## 3. 屋内
- すべての戸と窓を開けて換気します。
- 家電製品は清掃前に電源を遮断します。
- カーペット・家具・家電は掃除機か濡れた雑巾で清掃します。掃除機のごみを捨てるときも火山灰が舞わないよう注意します。
- エアコンや暖房器具はフィルターを交換します。
- ブラシ付きの床用掃除機、換気扇、衣類乾燥機は使わないでください。
- 衣類は火山灰を払ってから洗濯し、普段より多めの洗剤を使います。

## 4. 自動車
- 清掃の前に吸気口と電子部品を密閉します。
- ワイパーはガラスを傷つけるため、洗浄液を十分に使います。
- エンジンオイル、オイルフィルター、エアフィルターをこまめに交換します。
- 車内はもちろん、エンジンルームやトランクまで清掃します。ブラシでこすると傷がつくので注意してください。

## 5. なぜ必ず清掃が必要か
- 火山灰はテレビ・パソコン・カメラの内部まで入り込み、修理不能な故障を起こします。
- 火山灰に含まれる火山ガラス成分は静電気を発生させ、電気・電子機器の破損や火災につながります。
- 空気が乾いていると、風や車の走行で火山灰が再び舞い上がり、健康を害します。
- 火山灰は噴火後数か月から数年漂い続けることがあり、清掃した場所にもまた積もります。継続的な清掃が必要です。
