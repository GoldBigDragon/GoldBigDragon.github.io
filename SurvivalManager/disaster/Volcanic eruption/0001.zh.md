# 火山灾害的类型

| 类别 | 说明与危害 |
| --- | --- |
| 火山灰 | 喷发出的细粉。覆盖周边、污染大气，遮挡阳光造成异常低温，火山云会导致航班停飞，还可能引发大范围停电 |
| 火山碎屑物 | 喷出的大小固体碎块 |
| 火山泥流（拉哈尔） | 水与碎屑物混合后高速下泄的泥流，会引发滑坡和洪水并改变地形 |
| 熔岩 | 流出地表的液态岩浆，会掩埋土地并引发山火 |

> 火山喷发的损失绝大部分由火山灰造成。

## 韩国的活火山
地质学上把一万年以内有喷发记录的火山列为活火山。
- 白头山 - 朝鲜半岛最高峰，山顶有破火山口湖"天池"。946～947年发生大规模喷发，最后一次喷发在1903年
- 汉拿山 - 山顶有火口湖"白鹿潭"，1002年和1007年有喷发记录
- 郁陵岛 - 由海底熔岩喷涌形成的火山岛，过去两万年间大约每3,000～7,000年喷发一次

# 平时的准备

火山灰持续降落时，可能数小时甚至数天无法外出。
- 防尘口罩和护目镜（KF94以上更有效）
- 至少3天的饮用水和即食食品
- 收音机和电池
- 胶带和保鲜膜（密封窗缝、保护电子设备）
- 便携灯或手电筒
- 取暖设备和燃料、毛毯和衣物
- 药品和急救箱
- 扫帚、铁锹等清扫工具
- 少量现金
- 车载防灾用品
- 装火山灰的袋子

# 火山口附近的避险

- 火山可能毫无前兆地喷发。
- 喷发时会抛出大小石块，直接伤及人体。
- 在火山口附近发现冒烟、地下传来轰鸣、出现异味等异常时，立即撤到安全地区并通知警方。
- 尽快离开火山口周边，躲进最近的避难所或岩石背面。
- 火山气体比空气重，会积聚在山谷中。请避开狭窄低洼处。
- 戴上头盔和护目镜，用口罩或湿毛巾捂住口部。
- 火山碎屑流（火山灰与气体云）温度极高、速度极快、可传播很远，难以逃脱，必须乘车迅速撤离。
- 火山泥流沿山谷下泄，请撤到远离谷底的高处。
- 用手机和收音机收听灾害播报，按指示行动。

# 火山灰降落之前

- 身处室外时迅速进入建筑物内。
- 用湿毛巾堵住门缝和通风口，用胶带密封窗户。
- 慢性支气管炎、肺气肿、哮喘患者应留在室内。
- 为防排水管堵塞，把落水斗和排水管从屋顶檐槽上拆下。
- 若使用雨水作为供水，请断开集雨设施与水箱之间的管道。
- 火山灰会损伤角膜，请摘掉隐形眼镜。
- 用保鲜膜包裹电子设备，防止火山灰侵入。
- 收听灾害播报，熟悉应对要领。

---

# 火山灰降落期间

- 尽量留在室内，通过电视或广播收听灾害播报。
- 身处室外时，迅速进入汽车或建筑物内躲避。
- 用口罩、手帕或衣物捂住口鼻（KF94或KF80口罩有帮助）。
- 混入火山灰的饮用水不要喝。
- 蔬菜要洗净后食用。
- 视力不佳者请戴眼镜而不是隐形眼镜；火山灰严重时佩戴密闭式护目镜。
- 可能出现酸雨，不要淋雨。
- 屋顶积灰会压塌建筑，请适时清除。
- 尽量不要开车。 火山灰会导致车辆故障和交通事故。不得已时开前照灯并慢速行驶。

# 火山灰降落之后 - 清理

## 1. 通用
- 戴好护目镜和口罩，尽快清理室内外和车辆。没有口罩时用湿布替代。
- 换掉在外穿的衣服，把身体洗干净。
- 轻洒清水或使用湿拖布，防止火山灰再次扬起。
- 收集的火山灰要装入结实的塑料袋，送到指定地点处理。

## 2. 室外
- 防止火山灰进入建筑、机械、车辆和供排水设施。
- 在灰尘彻底清除前，机械要断电或密封。
- 屋顶积灰要在合适时机用水清洗。
- 草坪要先洒水再修剪。
- 堆积超过1厘米的火山灰要用铁锹清除。
- 先用喷灌等打湿再清理。
- 不要让火山灰进入排水口和下水道。
- 洒水过多会结成硬块，需注意。

## 3. 室内
- 打开所有门窗通风。
- 家电要在清理前断电。
- 地毯、家具、家电用吸尘器或湿抹布清理。倒吸尘器灰尘时也要防止扬尘。
- 空调和取暖设备要更换滤网。
- 不要使用带滚刷的地面吸尘器、排风扇和衣物烘干机。
- 衣物要先抖掉火山灰再洗，并比平时多用洗涤剂。

## 4. 车辆
- 清理前密封进气口和电子部件。
- 雨刮器会划伤玻璃，请充分使用清洗液。
- 勤换机油、机油滤清器和空气滤清器。
- 不仅清理车内，发动机舱和后备厢也要清理。用刷子擦会划伤车漆，请注意。

## 5. 为什么必须彻底清理
- 火山灰会侵入电视、电脑、相机内部，造成无法修复的故障。
- 火山灰中的火山玻璃成分会产生静电，可能损坏电子设备甚至引发火灾。
- 空气干燥时，风或车辆行驶会让火山灰重新扬起，危害健康。
- 火山灰在喷发后可能持续飘浮数月甚至数年，已清理过的地方还会重新积灰，必须持续清理。
