# 被刺伤时 - 行动顺序

1. 立即离开水域。
2. 用海水或生理盐水冲掉残留的触手，并充分冲洗。
3. 仍有疼痛时用45℃左右的热敷缓解。
4. 出现呼吸困难、意识不清、全身疼痛时立即拨打119，送医接受急救。必要时实施心肺复苏。

> 不要用自来水冲洗。
> 淡水接触后渗透压改变，会使残留的刺丝囊（毒针）再次发射，加重伤害。务必使用海水或生理盐水。

> 不要用手直接抓或擦拭触手。 摩擦会让更多刺丝囊破裂。

---

# 症状

| 时间 | 出现的症状 |
| --- | --- |
| 立即 | 如被鞭子抽打般的条状皮疹、疼痛、瘙痒 |
| 一段时间后 | 恶心、呕吐、腹泻、腹痛 |
| 严重时 | 血压下降、呼吸困难、意识丧失 - 可能致死 |

---

# 预防

- 下水时尽量减少皮肤裸露。防晒衣或长袖泳衣很有帮助。
- 发现水母时通过手机网页举报上报出现情况。
- 大量出现期间要遵守海水浴场的提示和管控。

# 韩国近海的主要水母

## 1. 野村水母 (*Nemopilema nomurai*)
![Nemopilema nomurai](./media/Nemopilema_nomurai.png)

- 出现：6月起在济州，8月中旬至12月上旬遍及全国
- 大小：直径超过150厘米、重量超过100公斤的大型种
- 形态：伞体内部肌肉发达，口腕在侧面呈J形，末端带有许多触手
- 被刺后：伴随疼痛和红斑的鞭状伤痕

## 2. 发形霞水母 (*Cyanea capillata*)
![Cyanea capillata](./media/Cyanea_capillata.png)

- 出现：7～11月，南海岸一带
- 大小：30～50厘米
- 形态：白色触手覆有黏液和刺丝囊，从伞体内发达的肌肉之间成百根成束垂下
- 被刺后：红色斑点和轻微疼痛

## 3. 僧帽水母 (*Physalia physalis*)
![Physalia physalis](./media/Physalia_physalis.png)

- 出现：6～8月，济州岛
- 大小：5～15厘米
- 形态：全身呈蓝色，三角形气囊下方垂着串珠状的有毒长触手
- 被刺后：剧烈疼痛，以及伴随红斑的鞭状红线

## 4. 夜光游水母 (*Pelagia noctiluca*)
![Pelagia noctiluca](./media/Pelagia_noctiluca.png)

- 出现：5～7月，济州岛和南海岸一带
- 大小：约8厘米
- 形态：呈粉色、黄色或淡粉色，伞缘有8条触手，伞内有4条帘状口腕。如其名所示，夜间受刺激会发光
- 被刺后：疼痛和呼吸困难

## 5. 五卷须金黄水母 (*Dactylometra quinquecirrha*)
![Dactylometra quinquecirrha](./media/Dactylometra_quinquecirrha.png)

- 出现：主要在夏季出现于济州岛和南海岸一带，春季至秋季也可能广泛观察到
- 大小：10～20厘米
- 形态：伞体浅褐色，带褐色放射状条纹，褐色触手从伞缘条纹之间长长伸出
- 被刺后：剧烈疼痛、红色皮疹和肿胀
