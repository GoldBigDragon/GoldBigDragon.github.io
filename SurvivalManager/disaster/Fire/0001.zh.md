# 1. 起火时 - 行动顺序

1. 通知他人 - 大喊"着火了！"并按下火警按钮。睡梦中被警报惊醒时，不要先去确认，而要先叫醒身边的人。
2. 判断是灭火还是撤离 - 火势小就用灭火器或水桶灭火；火势变大则立即撤离。
3. 撤离 - 走楼梯、放低身体，前往地面层或屋顶等安全场所。绝对不要乘电梯。
4. 报警 - 到达安全地点后拨打119。不要因为打电话而错过撤离时机。
5. 清点人数 - 在事先约定的地点集合并清点。有人不见时，要告知赶到的消防员。

> 用手背触摸门把手。 温热或发烫说明门的另一侧正在燃烧，不要开门。 门缝冒烟时同样如此。

> 烟和热会向上升。 扶着墙壁尽量放低身体移动，用湿毛巾或毯子裹住身体。有防烟面罩就戴上，没有就用湿手帕捂住口鼻。
> 火灾死亡多数不是被火烧死，而是一氧化碳等有毒气体造成的。

# 2. 无法撤离时

1. 转移到离火焰和烟最远的房间并关门，用湿毛巾堵住门缝。
2. 拨打119告知具体位置和情况，请求救援。
3. 在窗边挥动手电筒或浅色毛巾，让救援人员看到你的位置。
4. 若室内设有避难空间、轻质隔墙、下降式逃生口、缓降器，请前往该处。
   - 轻质隔墙是与邻户相接的薄墙，可以踢破后通过。

※ 1992年10月以前批准建造的公寓没有这些避难设施。请事先确认撤离路线，并建议加装逃生设备。

# 3. 不同情况的判断

| 情况 | 行动 |
| --- | --- |
| 自家起火，可从大门撤离 | 通知家人 → 随手关门，低姿势走楼梯撤离 → 按警铃、拨119 |
| 自家起火，无法从大门撤离 | 前往避难空间、轻质隔墙、下降式逃生口 → 若没有，关门堵缝并拨119请求救援 |
| 邻户起火，烟未进入 | 关好窗户在室内待命，注意观察 → 拨119，听从广播指引 |
| 邻户起火，烟已进入 | 走廊楼梯无烟时关门走楼梯撤离／走廊有烟时关门堵缝后前往避难空间 |

> 不要以为"别人肯定报警了"。 火看似扑灭后，也要留意是否复燃。

# 4. 灭火器、消火栓与缓降器

## 4-1. 灭火器
在室内要背对门使用，把撤离通道留在身后。

1. 取来灭火器，握住瓶身，拔掉保险销。
2. 握住喷管，靠近火源。
3. 用力握紧压把。
4. 让干粉均匀覆盖火焰地喷射。

## 4-2. 消火栓（两人一组）
1. A打开消火栓箱门，确认水带与水枪已连接。
2. B将水带不打结地铺到起火点，握住水枪做好出水姿势。
3. A旋开阀门确认出水后，跑过去与B一起握住水带。
4. 旋转水枪头调节水量进行灭火。

## 4-3. 缓降器
1. 把缓降器挂钩挂到支架上并锁紧。
2. 将支架推出窗外，把绳索抛下。
3. 把安全带套到胸部高度并收紧。
4. 手扶墙壁缓慢下降。

## 4-4. 衣服着火时
1. 停下。 奔跑会让火更旺，还会吸入烟气。
2. 双手捂住脸部。
3. 趴在地上。
4. 左右翻滚把火压灭。

# 5. 火灾类型与灭火方法

| 类别 | 燃烧物 | 灭火方法 |
| --- | --- | --- |
| A类 普通火灾 | 木材、纸张、纤维 - 燃烧后留下灰烬 | 用水类冷却、窒息 |
| B类 油类火灾 | 油、气等可燃液体和气体 - 不留灰烬 | 泡沫、干粉窒息 |
| C类 电气火灾 | 配电设备、线路 | 禁止用水。 二氧化碳、哈龙、干粉 |
| D类 金属火灾 | 钠、钾、钛、镁等 | 禁止用水。 用干砂、干硅藻土覆盖 |
| K（F）类 厨房火灾 | 食用油、动植物油脂 | 强化液、干粉。浇水会爆燃扩散 |

> 油类火灾和电气火灾绝对不能浇水。 金属火灾也一样，有些金属遇水反应会自行放热。
