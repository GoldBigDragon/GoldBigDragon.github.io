# 1. 火事が起きたら - 行動の順序

1. 知らせる - 「火事だ！」と叫び、非常ベルを押します。 寝ているときに警報が鳴ったら、確かめる前にまず周りを起こします。
2. 消すか逃げるかを決める - 小さな火なら消火器やバケツの水で消します。炎が大きくなったら、ただちに避難です。
3. 避難する - 階段で、姿勢を低くして地上階や屋上など安全な場所へ。エレベーターは絶対に使いません。
4. 通報する - 安全な場所に着いてから119へ。通報のために避難の時機を失わないようにします。
5. 人数を確認する - あらかじめ決めた場所に集まって数え、姿が見えない人がいれば到着した消防隊員に伝えます。

> ドアの取っ手を手の甲で触ってみます。 温かい、または熱いときは扉の向こうが燃えているので、開けてはいけません。 戸のすき間から煙が漏れているときも同じです。

> 煙と熱は上へ上がります。 壁に手を当てながら姿勢を最大限に低くして移動し、濡れたタオルや毛布で体を包みます。火災用の防煙マスクがあれば着け、なければ濡れたハンカチで口と鼻をふさぎます。
> 火災による死亡の多くは炎ではなく、一酸化炭素などの有毒ガスが原因です。

# 2. 避難できないとき

1. 炎と煙から最も遠い部屋へ移って戸を閉め、濡れたタオルですき間をふさぎます。
2. 119に現在の位置と状況を伝え、救助を求めます。
3. 窓辺で懐中電灯や明るいタオルを振って位置を知らせます。
4. 建物に避難空間、軽量間仕切り、下向き避難口、緩降機があればそちらへ移動します。
   - 軽量間仕切りは隣の住戸と接する薄い壁で、蹴って壊して越えることができます。

※ 1992年10月より前に許可を受けた集合住宅には、こうした避難設備がありません。避難経路をあらかじめ確認し、避難設備を備えることをおすすめします。

# 3. 状況別の判断

| 状況 | 行動 |
| --- | --- |
| 自宅、玄関から出られる | 知らせて → 戸を閉めて階段を低い姿勢で避難 → 非常ベル・119 |
| 自宅、玄関から出られない | 避難空間・軽量間仕切り・下向き避難口へ → なければ戸を閉めすき間をふさいで119に救助要請 |
| 隣家の火災、煙が入らない | 窓を閉めて室内で待機し状況を見守る → 119へ通報、館内放送にしたがう |
| 隣家の火災、煙が入る | 廊下・階段がきれいなら戸を閉めて階段で避難 / 廊下に煙があれば戸を閉めすき間をふさいで避難空間へ |

> 「誰かがもう通報しただろう」と考えてはいけません。 消えたあとも再燃がないか見守ります。

# 4. 消火器と消火栓、緩降機

## 4-1. 消火器
屋内では戸を背にして使います。避難路を背後に置くためです。

1. 消火器を持ってきて本体をつかみ、安全ピンを抜きます。
2. ノズルを持ち、火のほうへ近づきます。
3. レバーを強く握ります。
4. 粉末が火をまんべんなく覆うように放射します。

## 4-2. 消火栓（2人1組）
1. Aが消火栓の扉を開け、ホースとノズルの接続を確認します。
2. Bはホースがねじれないように火元まで長く伸ばし、ノズルを持って放水姿勢をとります。
3. Aがバルブを回して水が出るのを確認し、駆け寄ってBと一緒にホースを支えます。
4. ノズルの先を回して水量を調節しながら消火します。

## 4-3. 緩降機
1. 支持台のフックに緩降機のフックを掛けてロックします。
2. 支持台を窓の外へ押し出し、ロープを投げ下ろします。
3. ベルトを胸の高さまで掛けて締めます。
4. 壁に手を当てながらゆっくり降ります。

## 4-4. 服に火がついたとき
1. 止まります。 走ると火が大きくなり、煙を吸い込みます。
2. 両手で顔をおおいます。
3. 床に伏せます。
4. 左右に転がって火を消します。

# 5. 火災の種類と消火方法

| 級 | 燃えるもの | 消し方 |
| --- | --- | --- |
| A級 普通火災 | 木、紙、繊維 - 燃えたあとに灰が残る | 水系で冷却・窒息 |
| B級 油火災 | 油やガスなどの可燃性液体・気体 - 灰が残らない | 泡・粉末で窒息 |
| C級 電気火災 | 受変電設備、電線路 | 水は厳禁。 二酸化炭素・ハロン・粉末 |
| D級 金属火災 | ナトリウム、カリウム、チタン、マグネシウムなど | 水は厳禁。 乾いた砂、乾燥珪藻土で覆う |
| K（F）級 厨房火災 | 食用油、動植物性の油脂 | 強化液・粉末。水をかけると爆発的に広がる |

> 油火災と電気火災に水をかけてはいけません。 金属火災も同じで、水と反応して自ら熱を出す金属があります。
