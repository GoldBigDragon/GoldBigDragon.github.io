# 预防事故

## 1. 行人

- 不要乱穿马路；即使是绿灯，也要先停下看清左右再通过。
- 在无信号灯或闪灯的人行横道，要等车辆完全停稳后再过。
- 雨天不要把伞压低遮住视线，应撑直并走在远离车道的路边。
- 夜间穿浅色衣物或反光材质。
- 步行时不要看手机、戴耳机。
- 儿童和老年人应由成人陪同通行。

## 2. 驾驶人

- 开门下车前先确认自行车、摩托车和后方来车。
- 不要从正在下客的车辆旁穿行或超车。
- 在人车不分的道路上靠路边行驶。
- 与行人保持充足的安全距离。

# 发生碰撞事故时

1. 必须停车。 即使是被撞的一方，直接离开也可能被误认为肇事逃逸。
2. 打开危险报警闪光灯，白天在车后100米、夜间200米处放置三角警告牌。
3. 先让人员转移到安全地带。 高速公路上不要留在车内或应急车道，要撤到护栏外侧。
4. 有人受伤时必须在现场报警（112）。仅有财产损失可交换联系方式并由保险公司现场受理。
5. 等待警察或保险公司时拍摄现场。
   - 拉远拍摄，让事故位置、双方轮胎痕迹和对方车牌同时入镜。
   - 受损部位要多角度、近距离拍摄多张。
6. 车辆尚能移动时，请挪到应急车道等安全位置，避免二次事故。
7. 不要随意搬动伤者。 脊椎损伤从外表看不出来。唯一例外是起火，此时应立即转移。
8. 若涉及危险品运输车，可能演变为重大事故，请立即离开现场。

# 车辆落水时

1. 解开安全带，脱掉影响游泳的鞋子和厚外套。
2. 逃生前先做3到4次深呼吸，然后深吸一口气屏住。这样在水下能坚持更久。
3. 车窗能开就从窗口出去；打不开时，用破窗锤或头枕的金属支杆敲击侧窗边缘。玻璃中央很难破。
4. 车门打不开时，等车内进一定量的水。内外压差变小后车门就能推开。
5. 顺手抓住身边能漂浮的物品一起出去。

> 前挡风玻璃是夹层玻璃，几乎砸不开。请瞄准侧窗。

---

# 隧道内发生事故时

1. 停到应急车道或紧急停车带，关掉发动机但把钥匙留在车上，便于救援人员移车。
2. 用手机或隧道内紧急电话报警。
3. 火势小时，可用车载灭火器或隧道内灭火器、消火栓尝试初期灭火。
4. 火势扩大时，朝烟雾相反方向沿疏散指示灯撤离，走出隧道或经横向联络通道进入相邻隧道。
5. 烟雾向上升，请压低身体并捂住口鼻移动。

---

# 事故之后

- 即使感觉无事，也请当天或次日就医。颈部和腰部症状往往延迟出现。
- 将诊断书、修理报价单、现场照片、行车记录仪视频一并保存。
- 理赔期间接到索要个人信息的陌生联系，可能是诈骗；请自行拨打保险公司官方号码核实。
