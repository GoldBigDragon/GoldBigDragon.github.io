# 平时的准备

## 1. 信息与计划
- 通过电视、广播、网络和[安全垫脚石APP](https://play.google.com/store/apps/details?id=kr.go.nema.disasteralert_new)接收灾害信息。
- 依据以往受灾记录，确认所在区域的风险点（雪崩、易坍塌设施）。
- 把[避难场所](https://www.safekorea.go.kr/safekorea-kor/main/main.doidsiSFK/neo/sfk/cs/contents/civil_defense/SDIJKM1402.html)和前往方式也告诉孩子和行动不便者，并约定家人走散时的集合地点。

## 2. 应急物资
- 把急救药品、手电筒、饮用水、应急食品、收音机、手机充电器、卡式炉和燃料、毯子集中放在一处。
- 在浴缸蓄水以防停水，并备好手电筒和电池应对停电。
- 提前加满油；没有车的与邻居约好搭车。
- 汽车冬季装备：防滑链（喷雾防滑剂）、沙袋、氯化钙、铁锹。

## 3. 设施加固
- 提前确认工地和边坡的安全状况。
- 对有坍塌风险的大棚、畜舍进行维修，并安装加固支柱。
- 把松动的大棚固定带重新拉紧。
- 大棚薄膜、人参栽培棚遮阳网、果园防鸟网、保温被要提前撤除。
- 固定船只和渔网渔具，养殖设施要做好保温，防止鱼类冻死。

# 暴雪预警期间

## 1. 步行时
- 尽量不外出；必须外出时要分层穿衣。
- 穿鞋底面积大的运动鞋或登山鞋。
- 不要把手插进口袋，戴保暖手套。摔倒时手必须能用得上。
- 慢慢走，注意屋檐坠雪和被积雪盖住的窨井、排水口。
- 上下班比平时提早一点，用公共交通代替自驾。
- 不要骑自行车或摩托车等两轮车。

## 2. 远离危险建筑
- 老旧、违建房屋，用作住所的大棚和临时帐篷可能被积雪压塌，请转移到安全处。
- 可能被隔绝的地区要与警察局、政府机关保持应急联络。
- 不要靠近装配式板房结构（工厂、市场雨棚、仓库）和工地。
- 建筑出现裂缝、柱子弯曲、饰面脱落时，立即撤到室外并拨打119。

## 3. 驾车
- 不得不开车时，务必携带冬季装备；长途出发前确认燃料、饮食和气象情况。
- 行车前清除车上的冰雪，飞散的积雪会导致后车事故。
- 不要用热水浇前挡风玻璃，玻璃会炸裂。
- 弯道、山路、高架、桥梁、结冰路段要减速，并保持充足的安全车距。

### 路面结冰的时段与地点
- 时段：降雪1厘米以上后约24小时内／气温下降的夜间和清晨（黑冰）
- 地点
  - 信号灯路口 - 车辆反复起停，路面会变得非常滑
  - 桥面上 - 其他路面未结冰时，桥面也会结冰
  - 隧道出入口 - 常年背阴，会出现局部结冰

## 4. 车辆被困时
- 拨打119，留在车内通过广播了解情况并等待救援。
- 尽量待在车内。不得不离开时，留下联系电话并把钥匙插在车上。
- 与同车人一起保暖，轮流休息。
- 拍手、活动手脚，做轻微运动促进血液循环。
- 必须有一个人保持清醒。
- 夜间打开车内灯，或把彩色衣物铺在雪地上，便于救援人员发现。
- 排气管被雪堵住时，一氧化碳会进入车内。发动前先清理排气口周边积雪，并把车窗留一条缝。

## 5. 农渔村
- 大棚薄膜、遮阳网、防鸟网要提前撤除，降大雪时不要靠近。
- 养殖场做好保温，防止鱼类冻死。
- 船员要随时关注气象，天气恶劣时避免出航；不得不出航时先检查救生设备。

# 暴雪之后

## 1. 确认与申报
- 确认家人和熟人安全；联系不上且怀疑失踪时向警察报案。
- 老旧住宅进入前务必先确认受损情况。
- 受损设施先拍照，再向行政福利中心或市郡区政府申报。
- 被困时不要勉强开车外出，请拨打119或112，或向周围求助。

## 2. 除雪与次生灾害防范
- 自家门前、店铺门前的人行道积雪，请与家人邻居一起清除，防止结冰滑倒。
- 除雪要在白天进行，两人以上，确保安全后再作业。 不要爬上屋顶等勉强行事。
- 可通过公共数据门户的[行政安全部_除雪箱](https://www.data.go.kr/data/15114125/standard.do)查询最近的融雪剂箱。
- 积雪厚重的行道树、老旧建筑、大棚有坍塌风险，请勿靠近。
- 大雪后往往紧跟寒潮结冰，外出请保暖并注意防滑。
- 燃气、电力被切断时，须经韩国煤气安全公社（1544-4500）、韩国电气安全公社（1588-7500）或专业人员检查后再使用。
- 可能存在燃气泄漏，请开窗充分通风，通风前不要使用火柴或打火机。
