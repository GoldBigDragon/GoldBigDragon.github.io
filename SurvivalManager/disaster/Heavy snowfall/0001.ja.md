# 日ごろの備え

## 1. 情報と計画
- テレビ・ラジオ・インターネットと[安全ティディムドルアプリ](https://play.google.com/store/apps/details?id=kr.go.nema.disasteralert_new)で災害情報を受け取ります。
- 住んでいる地域の危険要因（雪崩、崩壊のおそれがある施設）を過去の被害記録で確認します。
- [避難場所](https://www.safekorea.go.kr/safekorea-kor/main/main.doidsiSFK/neo/sfk/cs/contents/civil_defense/SDIJKM1402.html)と行き方を子どもや要配慮者にも教え、家族が離れたときの再集合場所を決めておきます。

## 2. 非常用品
- 救急薬品、懐中電灯、飲料水、非常食、ラジオ、携帯電話の充電器、カセットこんろと燃料、毛布を1か所にまとめます。
- 断水に備えて浴槽に水をため、停電に備えて懐中電灯と乾電池を用意します。
- 車の燃料を満たしておき、車がなければ近所の方と同乗の約束をしておきます。
- 車の冬用装備：タイヤチェーン（スプレーチェーン）、砂袋、塩化カルシウム、スコップ

## 3. 施設の補強
- 工事現場や斜面の安全状態を事前に確認します。
- 崩壊のおそれがあるビニールハウス・畜舎は補修し、補強支柱を立てます。
- ゆるんだビニールハウスのバンドはしっかり張り直します。
- ビニールハウスのビニール、高麗人参栽培舎の遮光幕、果樹園の防鳥網、保温カバーは事前に取り外します。
- 船や漁網・漁具を固縛し、養殖施設は魚が凍死しないよう保温します。

# 大雪警報・注意報の発表中

## 1. 歩くとき
- 外出を控え、出るときは重ね着をします。
- 底面の広いスニーカーや登山靴を履きます。
- ポケットに手を入れず、保温手袋をはめます。転んだとき手が使えることが大切です。
- ゆっくり歩き、軒先から落ちる雪と雪で隠れたマンホール・排水口に注意します。
- 出退勤はいつもより少し早めにし、自家用車ではなく公共交通機関を使います。
- 自転車やバイクなど二輪車には乗らないでください。

## 2. 危ない建物から離れる
- 老朽・無許可住宅、住居用ビニールハウス、仮設テントは積雪の重みで崩れるおそれがあるため、安全な場所へ移ります。
- 孤立のおそれがある地域は、警察署や役所と緊急連絡体制を保ちます。
- 仮設パネルの構造物（工場、市場の雨よけ、倉庫）や工事現場には近づきません。
- 建物にひび割れが入る、柱がたわむ、仕上げ材が落ちるといった異常があれば、ただちに外へ避難して119へ通報します。

## 3. 運転
- やむを得ず運転するときは必ず冬用装備を携行し、長距離の前には燃料・飲食物と気象状況を確認します。
- 走行前に車の氷と雪を落とします。 飛ばされた雪が後続車の事故を招きます。
- フロントガラスに熱湯をかけないでください。ガラスが割れます。
- カーブ、峠道、高架、橋、凍結区間では徐行し、車間距離を十分にとります。

### 路面が凍る時期と場所
- 時期：積雪1cm以上のあと約24時間以内／気温が下がる夜間と朝（ブラックアイス）
- 場所
  - 信号交差点 - 発進と停止が繰り返され、路面が非常に滑りやすくなります
  - 橋の上 - ほかの路面が凍っていなくても、橋の上は凍ります
  - トンネルの出入口 - 日陰になり、局所的に凍結します

## 4. 車が立ち往生したとき
- 119へ通報し、車内でラジオから状況を確認しながら救助を待ちます。
- できるだけ車内にとどまります。 やむを得ず離れるときは、連絡先を残し、キーを差したまま避難します。
- 同乗者と体温を保ち、交代で休息します。
- 血行のために手をたたき、手足を動かす軽い運動をします。
- 必ず1人は起きていてください。
- 夜は室内灯をつけるか、色のついた衣類を雪の上に広げて、救助隊が見つけやすいようにします。
- 排気口が雪でふさがると、一酸化炭素が車内に入ります。 エンジンをかける前に排気口周りの雪を取り除き、窓を少し開けておきます。

## 5. 農漁村
- ビニールハウスのビニール、遮光幕、防鳥網は事前に外し、大雪のときは近づきません。
- 養殖場は魚が凍死しないよう保温します。
- 船の従事者は気象情報を確認し、悪天候時の運航を控え、やむを得ず出航する場合は救命装備を点検します。

# 大雪のあと

## 1. 確認と届け出
- 家族や知人の安否を確認し、連絡が取れず行方不明が疑われる場合は警察へ届け出ます。
- 老朽住宅などは出入りの前に必ず被害を確認します。
- 破損した施設は写真を撮ってから、行政福祉センターや自治体へ届け出ます。
- 孤立したときは無理に運転せず、119・112へ通報するか周囲に助けを求めます。

## 2. 除雪と二次被害の防止
- 自宅前・店舗前の歩道の雪は、家族や近所と一緒に取り除き、凍結による転倒事故を防ぎます。
- 除雪は日中に、2人以上で、安全を確保してから行います。屋根に上がるなど無理はしません。
- 最寄りの除雪箱は公共データポータルの[行政安全部_除雪箱](https://www.data.go.kr/data/15114125/standard.do)で確認できます。
- 雪が多く積もった街路樹、老朽建築物、ビニールハウスは崩れるおそれがあるため近づきません。
- 大雪のあとは寒波で路面が凍ります。暖かい服装で、足元に注意してください。
- ガスや電気が止まった場合は、韓国ガス安全公社（1544-4500）、韓国電気安全公社（1588-7500）または専門家の点検を受けてから使用します。
- ガス漏れのおそれがあるので、窓を開けて十分に換気し、換気前はマッチやライターを使いません。
