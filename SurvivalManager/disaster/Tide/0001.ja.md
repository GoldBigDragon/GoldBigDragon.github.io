# 大潮と旧暦七月の大潮（白中サリ）

| 用語 | 意味 |
| --- | --- |
| サリ（大潮） | 満潮と干潮の差が最大になる時期。 地球をはさんで月と太陽が同じ方向、または正反対の方向にあるときに起こります |
| テジョギ（大潮期） | 新月・満月から2〜4日間。 潮の流れが比較的速い期間です |
| 白中サリ | 旧暦7月15日（白中） ごろの大潮。一年のうちで海面がもっとも高くなる時期の一つです |

> なぜ新月・満月の当日ではなく数日後なのでしょうか。
> 海水は月と太陽の引力だけでなく、地形や海底の摩擦の影響も受けます。そのため実際の大潮期は新月・満月より1〜3日遅れて現れます。

# 日ごろの備え

## 1. 自分の地域を知る
- 過去に自分の地域で起きた被害の情報をあらかじめ確かめ、家族や近所と共有します。
- 住んでいる、あるいは生活している地域の低地の浸水危険区域を事前に確かめます。
- 白中サリと大潮期の時期をカレンダーで前もって確認しておきます。

## 2. 災害情報を受け取る備え
- テレビとラジオを用意し、スマートフォンに[安全ディディムドルのアプリ](https://play.google.com/store/apps/details?id=kr.go.nema.disasteralert_new)を入れておきます。
- 家族や近所と一緒に、危険情報を受け取れる状態をつくっておきます。

## 3. 避難の計画
- 家族が別々に動くことになった場合に備え、再び落ち合う場所を決めます。
- 誰が、何を、いつ、どうするかをあらかじめ約束します。
- 地域の避難場所を覚え、子どもにも教えます。
  - [国民安全24](https://www.safekorea.go.kr/safekorea-kor/main/main.doidsiSFK/neo/sfk/cs/contents/civil_defense/SDIJKM1402.html)や自治体のホームページの臨時避難所・被災者臨時住居施設を参考にします。
- 非常事態が予想されるときはただちに家族に連絡し、一緒に安全な場所へ移動します。
- 状況が切迫していればまずその場を離れ、家族には別に連絡して自分の移動経路を伝えます。
- 浸水がよく起こる地域では、あらかじめ物を高い場所へ移して二次被害を防ぎます。

## 4. 非常用品
一か所にまとめ、急なときにすぐ持ち出せるよう用意します。
- 救急薬品、懐中電灯、飲み水、非常食
- ラジオ、携帯電話の充電器
- 携帯用バーナー、毛布
- 車があれば燃料を先に満たしておきます。 車がなければ、車のある近所の人と一緒に移動する約束を先にしておきます。

## 5. 点検と整備
- 家庭の下水口と家の周りの排水口を点検し、水はけをよくします。
- 非常用品の使用期限を確かめ続けて入れ替えます。
- 避難場所と避難経路を定期的に確かめ直します。

# 海面上昇が予報されたら

## 1. 海岸への立ち入りを控える
- 海面上昇が予報されたら海岸への立ち入りを控え、周囲にも知らせます。
- 大潮期には干潟の体験、地域の祭り、釣り、観光を中止します。
- 浸水のおそれがある地域の車と住民は一緒に高い場所へ移動します。

## 2. 高台へ避難する
- 浸水の被害が心配されるときは、周りの人と一緒に高い地域へ避難します。
- 海岸、磯、防波堤、低地の道路など浸水しうる場所からは、ただちに高い地域へ移動します。
- 実際に浸水・氾濫が起きたら、災害放送や公務員・警察・消防の案内にしたがい、落ち着いて速やかに高層建物や高台へ避難します。
- 秩序を保ち、高齢者と子どもを先に配慮します。
- けが人が出たら周囲に助けを求め、119へ連絡します。

## 3. 危険区域に近づかない
> 海面上昇に強風と高波が重なると、うねりや高潮で被害が出ます。
> 海岸の道路、防波堤、海水浴場、磯に近づきません。

- 磯や干潟で孤立したら、ただちに119か112へ通報するか周囲に助けを求め、できるだけ高い場所へ移動します。

## 4. 二次被害に注意
> 浸水や氾濫が起きると感電の危険があります。
> 電柱、街灯、信号機、住宅の電気設備は手で触れたり近づいたりしません。

- 水につかった道路では、車の運行も徒歩の移動もしません。
- 家を出るときは水道とガスの元栓を閉め、電気のブレーカーを落とします。

## 5. 通報
- 周囲の安全を皆で確かめ、危険要素は通報して周囲に知らせます。
- 海岸地域に住んでいる、あるいは向かった知人と連絡して安全を確かめ、行方不明が疑われる場合は近くの警察署へ届けます。
- 危険要素を見つけたら112、119、または安全申聞鼓（안전신문고）アプリで通報します。
