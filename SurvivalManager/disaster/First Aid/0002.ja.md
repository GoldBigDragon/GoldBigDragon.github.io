# 4. 大量出血

1. 手、布、ガーゼなどで強く押さえ、患部を直接圧迫します。
2. 10分以上圧迫を保ちます。 途中で外して確かめません。
3. 出血が続くなら、手足に限って止血帯を使います。
4. 止血帯は傷口より心臓に近い側に当て、使用した時刻を記録します。

# 5. 気道閉塞（窒息）

> 本人が自分で咳をしているなら、気道は完全にはふさがっていません。 まず咳で吐き出すよう促します。

## 5-1. 成人・小児 - ハイムリック法（助ける人がいるとき）
1. 咳で吐き出すよう促します。
2. 咳ができないなら腹部突き上げを行います。
3. 傷病者の後ろに立ち、片手で握りこぶしをつくり、親指側をへそと胸骨下端の中間に当てます。
4. もう一方の手でこぶしを包み、腹部を内側から上へ強く突き上げます。

## 5-2. 一人でいるとき
1. 咳で異物が出るか試します。
2. 利き手で握りこぶしをつくります。
3. こぶしをへそのすぐ上、あばら骨の下の腹に当てます。
4. もう一方の手でこぶしを包みます。
5. 横隔膜の内側の腹部へ、かぎ形にこぶしを押し上げるように何度も力を加えます。
6. それでも出なければ、腰の高さの固定された椅子やテーブルを探します。
7. 両手を腹に当てたまま、その物の上に体を曲げて圧迫を加えます。
8. 繰り返します。

## 5-3. 乳幼児 - 背部叩打5回＋胸部圧迫5回
1. 左手であごと頬骨を包んで持ち、右手で後頭部を支え、ゆっくり抱き上げます。
2. 椅子に座り、赤ちゃんの頭が下を向くようにうつ伏せにして太ももの上にのせます。
3. 赤ちゃんの体が一直線になるようにします。
4. 手のひらの付け根で両肩甲骨の間を強く5回叩きます。
5. あごと後頭部を包んで持ち、赤ちゃんを反対に返します。
6. 両乳頭の中央のすぐ下の胸骨に指2本を当て、速く強く5回押します。
7. 異物が出るまで背部叩打と胸部圧迫を繰り返します。

# 6. やけど

## 6-1. 行動要領
1. 熱源を取り除くか、熱源から離れて安全を確保します。
2. 流れるきれいな水で20分以上冷やします。
3. きれいなガーゼで覆って感染を防ぎますが、患部を圧迫しません。
4. ショック（低血圧）が疑われるときは、寝かせて脚を少し上げます。
5. 毛布や衣類を掛けて体温を保ちます。
6. 意識があり吐いていなければ、少量ずつ水を与えます。

## 6-2. 絶対にしないこと

| 誤った手当て | 理由 |
| --- | --- |
| 水ぶくれを潰す | 感染の入り口を自分で開けることになります |
| 油、みそ、しょうゆ、歯みがき、ローション、軟膏を塗る | 感染の危険が大きく高まります |
| 氷を直接当てる | 組織が傷みます |
| 貼りついた衣類や物を剥がす | 皮膚まで一緒に剥がれます |

## 6-3. 度数ごとの手当て

| 度 | 状態 | 手当て |
| --- | --- | --- |
| I度 | 患部が赤くなり痛む | 冷やして保湿します |
| II度 | 水ぶくれができる | 潰さずに保護します。きれいな布で覆います。強い痛みによるショックに備えて寝かせます。 |
| III度 | 皮膚が白く、または黒くなる。神経の損傷で感覚がないことがある | 低体温を防ぐため冷却は短く。 ただちにきれいな布で覆い、毛布で体温を保ちます。意識があれば水分を与えます。 |

> III度のやけどは痛まないことがあります。 感覚がないのは神経が壊れたということなので、痛くないから軽いと判断してはいけません。
