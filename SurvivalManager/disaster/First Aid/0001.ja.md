# 1. 応急手当を始める前に

- 傷病者に意識があれば、これから行う手当てを説明して同意を得ます。
- 意識がない、または生命が危ういときは、同意なしにただちに行います。

> 応急手当は治療ではなく、生きて救助されるまで持ちこたえさせる技術です。
> 状況が落ち着いて見えても、必ず医療機関の診療が必要です。

# 2. 心肺蘇生

## 2-1. 手順
1. 危険の確認 - 感電、火災、崩落などを確かめ、安全を確保してから近づきます。
2. 反応の確認 - 肩を叩きながら「大丈夫ですか？」と尋ねます。（乳児は足の裏を叩きます。）
3. 応援を呼ぶ - 人を名指しします。
   - 「そこの黒い服の方、119へ通報してください！」
   - 「そこの白い服の方、AEDを持ってきてください！」
4. 呼吸の確認 - 胸の動きを見ます。
   > 異常な呼吸（あえぎ呼吸を含む）は「呼吸なし」とみなします。
5. 胸骨圧迫 - 下の表の位置と深さで、毎分100〜120回。
6. 人工呼吸 - 頭を後ろへ倒し、あごを上げて気道を確保し、鼻をつまんで1秒間、胸が上がる程度に吹き込みます。圧迫30回：人工呼吸2回。
7. 救急隊が到着するか、意識が戻るまで繰り返します。

## 2-2. 年齢で変わるのはここだけ

| | 成人 | 小児（1歳〜思春期） | 乳児（1歳未満） |
| --- | --- | --- | --- |
| 反応の確認 | 肩を叩く | 肩を叩く | 足の裏を叩く |
| 一人のとき | まず119へ通報し、スピーカーにしてCPR | 2分間のCPRを先に、その後119 | 2分間のCPRを先に、その後119 |
| 手 | 両手を重ねて指を組む | 片手 | 指2本 |
| 位置 | 胸の中央（胸骨の下半分） | 胸の中央（胸骨の下半分） | 胸の中央（胸骨の下半分） |
| 深さ | 5〜6cm | 胸の厚さの約1/3（約5cm） | 胸の厚さの約1/3（約4cm） |
| 人工呼吸 | 可能なら。一般の人は圧迫だけでも十分に有効 | 必ず行う | 必ず行う |
| 頭の位置 | 後ろへ倒す | 後ろへ倒す | 中立位を保つ |
| 吹き込み方 | 鼻をつまんで口から | 鼻をつまんで口から | 口と鼻を同時におおって |

> 小児と乳児は、呼吸の問題から心停止に至る割合がはるかに高いのです。だから人工呼吸は選択ではなく必須です。

## 2-3. 見落としがちなこと
- 2分ごとに救助者を交代します。疲れると気づかないうちに圧迫が浅くなります。
- 胸骨圧迫の中断は10秒以内に。
- 傷病者が複数なら、呼吸のない人を優先します。
- 低体温の環境では「冷たくても死んではいない」という原則にしたがい、体温が戻るまでCPRを続けることを考えます。
- 狭い場所や車内では、できるだけ平らな床へ移します。

# 3. 自動体外式除細動器（AED）

1. 電源を入れます。
2. パッド1 - 傷病者から見て右の鎖骨の下に貼ります。
   - 乳児は前（胸の中央） に貼ります。
3. パッド2 - 傷病者から見て左のわきの下、脇腹に貼ります。
   - 乳児は背中に、パッド1と向かい合わせに貼ります。
4. 音声案内にしたがいます。
5. 状態の解析中は傷病者に触れません。
6. 電気ショックの前は傷病者から離れます。
7. ショックが終わったら、ただちに胸骨圧迫を再開します。
