# 4. 大量出血

1. 用手、布料、纱布等用力按压，直接压迫伤口。
2. 持续加压10分钟以上。 中途不要松开查看。
3. 若仍持续出血，仅限四肢使用止血带。
4. 止血带要用在比伤口更靠近心脏的部位，并记录使用时间。

# 5. 气道阻塞（窒息）

> 如果伤者还能自行咳嗽，说明气道没有完全堵塞。 先引导其通过咳嗽把异物排出。

## 5-1. 成人与儿童 - 海姆立克急救法（有人帮助时）
1. 引导其咳出异物。
2. 无法咳嗽时，实施腹部冲击。
3. 站在伤者身后，一只手握拳，拇指侧抵在肚脐与胸骨下端之间。
4. 另一只手包住拳头，向内上方用力冲击腹部。

## 5-2. 独自一人时
1. 先试着咳出异物。
2. 用惯用手握拳。
3. 把拳头放在肚脐正上方、肋骨下缘的腹部。
4. 另一只手包住拳头。
5. 像钩子一样向上顶入横膈膜下方的腹部，反复用力。
6. 仍无法排出时，找腰部高度的固定椅子或桌子。
7. 双手仍紧按腹部，俯身压在该物体上施加冲击。
8. 反复进行。

## 5-3. 婴幼儿 - 拍背5次＋胸部按压5次
1. 左手托住婴儿的下颌与颧骨，右手托住后脑，缓慢抱起。
2. 坐在椅子上，让婴儿头低脚高俯卧在大腿上。
3. 使婴儿身体保持一条直线。
4. 用掌根在两肩胛骨之间用力拍击5次。
5. 托住下颌与后脑，把婴儿翻转过来。
6. 在两乳头连线中点正下方的胸骨上放两根手指，快速有力地按压5次。
7. 反复进行拍背与胸部按压，直到异物排出。

# 6. 烧烫伤

## 6-1. 处置要领
1. 移走热源或远离热源，确保安全。
2. 用流动的清水冲洗冷却20分钟以上。
3. 用干净纱布覆盖防止感染，但不要压迫创面。
4. 怀疑休克（低血压）时，让伤者平卧并稍微抬高双腿。
5. 盖上毯子或衣物保持体温。
6. 若意识清醒且未呕吐，可少量多次给水。

## 6-2. 绝对不要做的事

| 错误处置 | 原因 |
| --- | --- |
| 挑破水疱 | 等于亲手打开感染通道 |
| 涂抹油、大酱、酱油、牙膏、乳液、软膏 | 大幅提高感染风险 |
| 直接敷冰 | 会造成组织损伤 |
| 撕扯粘连的衣物或异物 | 皮肤会被一同撕下 |

## 6-3. 按烧伤程度处置

| 程度 | 表现 | 处置 |
| --- | --- | --- |
| 一度 | 创面发红、疼痛 | 冷却并保湿 |
| 二度 | 出现水疱 | 不要挑破，加以保护。用干净布覆盖。剧痛可能引起休克，让伤者平卧。 |
| 三度 | 皮肤变白或变黑。神经受损可能完全没有知觉 | 为防失温，冷却时间要短。 立即用干净布覆盖，并用毯子保持体温。意识清醒时给予水分。 |

> 三度烧伤可能并不疼。 没有知觉意味着神经已被破坏，绝不能因为不疼就判断为轻伤。
