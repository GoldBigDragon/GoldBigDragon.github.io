# 4. 대량 출혈

1. 손, 천, 거즈 등으로 강하게 눌러 환부를 직접 압박합니다.
2. 10분 이상 압박을 유지합니다. 중간에 떼어 확인하지 않습니다.
3. 출혈이 계속되면 팔다리에 한해서만 지혈대를 사용합니다.
4. 지혈대는 상처보다 심장 쪽에 가까운 부위에 적용하고, 적용한 시간을 기록합니다.

# 5. 기도 폐쇄(질식)

> 환자가 스스로 기침을 하고 있다면 기도가 완전히 막힌 것이 아닙니다. 먼저 기침으로 뱉어내도록 유도합니다.

## 5-1. 성인·소아 - 하임리히법 (도와줄 사람이 있을 때)
1. 기침으로 뱉어내도록 유도합니다.
2. 기침을 하지 못하면 복부 밀어내기를 시행합니다.
3. 환자 뒤에 서서 한 손은 주먹을 쥐고, 엄지 방향을 배꼽과 명치 중간에 둡니다.
4. 다른 손으로 주먹을 감싸고, 복부를 안쪽에서 위로 강하게 끌어 올립니다.

## 5-2. 혼자 있을 때
1. 기침으로 이물질이 나오는지 시도합니다.
2. 주로 쓰는 손으로 주먹을 쥡니다.
3. 주먹을 배꼽 바로 위, 갈비뼈 아래의 배 위에 놓습니다.
4. 다른 손으로 주먹을 감쌉니다.
5. 횡격막 안쪽의 복부로 갈고리 모양처럼 주먹을 위로 밀어 넣듯 여러 번 힘을 가합니다.
6. 나오지 않으면 허리 높이의 고정된 의자나 탁자를 찾습니다.
7. 양손을 그대로 배에 대고, 그 물체 위로 몸을 굽혀 압박을 가합니다.
8. 반복합니다.

## 5-3. 영유아 - 등 두드리기 5회 + 가슴 압박 5회
1. 왼손으로 턱과 광대뼈를 감싸 잡고, 오른손으로 뒤통수를 감싸 천천히 안아 올립니다.
2. 의자에 앉아 아기의 머리가 아래를 향하도록 뒤집어 허벅지 위에 올립니다.
3. 아기의 몸이 일직선이 되게 합니다.
4. 손바닥 끝으로 양쪽 날개뼈 가운데를 세게 5회 두드립니다.
5. 턱과 뒤통수를 감싸쥔 뒤 아기를 반대로 돌립니다.
6. 양쪽 젖꼭지 중앙 바로 아래 흉골에 두 손가락을 놓고 빠르고 강하게 5회 누릅니다.
7. 이물질이 제거될 때까지 등 두드리기와 가슴 압박을 반복합니다.

# 6. 화상

## 6-1. 행동 요령
1. 열원을 제거하거나 열원에서 멀어져 안전을 확보합니다.
2. 흐르는 깨끗한 물로 20분 이상 냉각합니다.
3. 깨끗한 거즈로 덮어 감염을 방지하되, 환부를 압박하지 않습니다.
4. 쇼크(저혈압)가 의심되면 환자를 눕히고 다리를 약간 올립니다.
5. 담요나 옷을 덮어 체온을 유지시킵니다.
6. 의식이 있고 구토하지 않으면 소량씩 물을 공급합니다.

## 6-2. 절대 하지 말 것

| 잘못된 처치 | 이유 |
| --- | --- |
| 물집을 터뜨리기 | 감염 경로를 스스로 열어 주는 셈입니다 |
| 기름, 된장, 간장, 치약, 로션, 연고 바르기 | 감염 위험이 크게 높아집니다 |
| 얼음을 직접 대기 | 조직이 손상됩니다 |
| 눌러 붙은 옷이나 물질 떼어내기 | 피부가 함께 떨어집니다 |

## 6-3. 화상 단계별 처치

| 단계 | 상태 | 처치 |
| --- | --- | --- |
| 1도 | 환부가 붉어지고 통증 | 냉각하고 보습합니다 |
| 2도 | 물집이 생김 | 물집을 터뜨리지 않고 보호합니다. 깨끗한 천으로 덮습니다. 강한 통증으로 인한 쇼크에 대비해 환자를 눕힙니다. |
| 3도 | 피부가 하얗거나 검게 변함. 신경 손상으로 감각이 없을 수 있음 | 저체온 방지를 위해 냉각은 짧게. 즉시 깨끗한 천으로 덮고, 담요로 체온을 유지합니다. 의식이 있으면 수분을 공급합니다. |

> 3도 화상은 아프지 않을 수 있습니다. 감각이 없는 것은 신경이 파괴되었다는 뜻이므로, 통증이 없다고 가볍게 판단해서는 안 됩니다.
