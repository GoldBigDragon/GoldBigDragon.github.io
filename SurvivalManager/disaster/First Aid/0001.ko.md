# 1. 응급처치 유의사항

- 부상자의 의식이 있으면 실시할 응급처치를 설명하고 동의를 구합니다.
- 의식이 없거나 생명이 위급하면 동의 없이 즉시 시행합니다.

> 응급처치는 치료가 아니라, 살아서 구조될 때까지 버티게 하는 기술입니다.
> 상황이 회복되어 보여도 반드시 의료진의 진료가 필요합니다.

# 2. 심폐소생술

## 2-1. 공통 순서
1. 위험 요소 확인 - 감전, 화재, 붕괴 등을 확인하고 안전을 확보한 뒤 접근합니다.
2. 반응 확인 - 어깨를 두드리며 "괜찮으세요?"라고 묻습니다. (영아는 발바닥을 두드립니다.)
3. 도움 요청 - 사람을 특정해서 부릅니다.
   - "거기 검은 옷 입으신 분, 119 신고해 주세요!"
   - "거기 흰색 옷 입으신 분, AED 가져와 주세요!"
4. 호흡 확인 - 가슴 움직임을 봅니다.
   > 비정상 호흡(헐떡임 포함)은 '호흡 없음'으로 간주합니다.
5. 가슴 압박 - 아래 표의 위치·깊이로 분당 100~120회.
6. 인공호흡 - 머리를 뒤로 젖히고 턱을 들어 기도를 확보한 뒤, 코를 막고 1초 동안 가슴이 올라올 정도로 불어 넣습니다. 압박 30회 : 인공호흡 2회.
7. 구급대가 도착하거나 의식이 돌아올 때까지 반복합니다.

## 2-2. 연령별 차이 - 이것만 다릅니다

| | 성인 | 소아 (1세~사춘기) | 영아 (1세 미만) |
| --- | --- | --- | --- |
| 반응 확인 | 어깨를 두드림 | 어깨를 두드림 | 발바닥을 두드림 |
| 혼자일 때 | 119 먼저 신고하고 스피커모드로 CPR | 2분간 CPR 먼저 한 뒤 119 | 2분간 CPR 먼저 한 뒤 119 |
| 압박 손 | 두 손을 겹쳐 깍지 | 한 손 | 두 손가락 |
| 압박 위치 | 가슴 중앙(흉골 아래 1/2) | 가슴 중앙(흉골 아래 1/2) | 가슴 중앙(흉골 아래 1/2) |
| 압박 깊이 | 5~6cm | 가슴 두께의 약 1/3 (약 5cm) | 가슴 두께의 약 1/3 (약 4cm) |
| 인공호흡 | 가능하면. 일반인은 압박만으로도 충분히 효과적 | 반드시 시행 | 반드시 시행 |
| 머리 위치 | 뒤로 젖힘 | 뒤로 젖힘 | 중립 위치 유지 |
| 불어넣는 방식 | 코를 막고 입으로 | 코를 막고 입으로 | 입과 코를 동시에 덮어서 |

> 소아와 영아는 호흡 문제로 인한 심정지 비율이 높습니다. 그래서 인공호흡이 선택이 아니라 필수입니다.

## 2-3. 놓치기 쉬운 것
- 구조자를 2분마다 교대합니다. 피로로 압박 깊이가 얕아지는 것을 막기 위해서입니다.
- 가슴압박 중단은 10초 이내로 최소화합니다.
- 환자가 여럿이면 호흡이 없는 환자를 우선합니다.
- 저체온 환경에서는 "차갑지만 죽지 않았다"는 원칙에 따라, 체온이 회복될 때까지 CPR을 계속하는 것을 고려합니다.
- 좁은 공간이나 차량 안에서는 가능한 평평한 바닥으로 옮깁니다.

# 3. 자동심장충격기(AED)

1. 전원을 켭니다.
2. 패드 1 - 환자 기준 오른쪽 쇄골 아래에 부착합니다.
   - 영아는 앞(가슴 중앙) 에 부착합니다.
3. 패드 2 - 환자 기준 왼쪽 겨드랑이 아래 옆구리에 부착합니다.
   - 영아는 뒤(등) 에, 패드 1의 위치와 맞추어 부착합니다.
4. 음성 안내를 따릅니다.
5. 환자 상태를 분석하는 중에는 접촉을 금지합니다.
6. 전기 방출 전에는 환자로부터 떨어집니다.
7. 방출이 끝나면 즉시 가슴 압박을 다시 시작합니다.
