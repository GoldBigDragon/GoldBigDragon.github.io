# 1. 施救前的注意事项

- 伤者意识清醒时，要说明将要实施的急救并征得同意。
- 意识不清或生命垂危时，无需同意立即施救。

> 急救不是治疗，而是让人撑到获救的技术。
> 即使情况看似好转，也必须接受医务人员的诊治。

# 2. 心肺复苏

## 2-1. 通用步骤
1. 确认危险因素 - 触电、火灾、坍塌等，确保安全后再靠近。
2. 确认反应 - 拍打肩部并询问"你还好吗？"（婴儿拍打足底。）
3. 求助 - 要指定具体的人。
   - "那位穿黑衣服的，请拨打119！"
   - "那位穿白衣服的，请去取AED！"
4. 确认呼吸 - 观察胸部起伏。
   > 异常呼吸（包括濒死叹息）一律视为"无呼吸"。
5. 胸外按压 - 按下表的位置和深度，每分钟100～120次。
6. 人工呼吸 - 头后仰、抬下颌开放气道，捏住鼻子吹气1秒，使胸部隆起。按压30次：吹气2次。
7. 持续进行直到急救人员到达或伤者恢复意识。

## 2-2. 不同年龄只有这些差别

| | 成人 | 儿童（1岁～青春期） | 婴儿（1岁以下） |
| --- | --- | --- | --- |
| 确认反应 | 拍打肩部 | 拍打肩部 | 拍打足底 |
| 独自一人时 | 先拨119，开免提后进行CPR | 先做2分钟CPR，再拨119 | 先做2分钟CPR，再拨119 |
| 按压手法 | 双手交叠十指相扣 | 单手 | 两指 |
| 按压位置 | 胸部中央（胸骨下半部） | 胸部中央（胸骨下半部） | 胸部中央（胸骨下半部） |
| 按压深度 | 5～6厘米 | 胸廓厚度约1/3（约5厘米） | 胸廓厚度约1/3（约4厘米） |
| 人工呼吸 | 有条件就做。普通人只做按压也足够有效 | 必须做 | 必须做 |
| 头部位置 | 后仰 | 后仰 | 保持中立位 |
| 吹气方式 | 捏鼻口对口 | 捏鼻口对口 | 同时罩住口与鼻 |

> 儿童和婴儿因呼吸问题导致心脏骤停的比例高得多。 所以人工呼吸对他们不是可选项，而是必须。

## 2-3. 容易忽略的要点
- 每2分钟轮换施救者。 疲劳会让按压在不知不觉中变浅。
- 胸外按压的中断要控制在10秒以内。
- 伤者多人时，优先处置没有呼吸的人。
- 在低温环境下要遵循"虽然冰冷但并未死亡"的原则，考虑持续CPR直至体温恢复。
- 在狭小空间或车内，尽量把伤者移到平坦地面。

# 3. 自动体外除颤器（AED）

1. 打开电源。
2. 电极片1 - 贴在伤者右侧锁骨下方。
   - 婴儿贴在前面（胸部中央）。
3. 电极片2 - 贴在伤者左侧腋下的侧胸部。
   - 婴儿贴在背部，与电极片1位置相对。
4. 按语音提示操作。
5. 分析伤者状态期间禁止接触。
6. 放电前要离开伤者。
7. 放电结束后立即恢复胸外按压。
