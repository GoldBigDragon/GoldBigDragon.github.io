# 4. 電子の信号 - 携帯があなたを指し示します

## 4-1. ドローンは電波を聴いています
- ロシアのオルラン-10偵察ドローンには、約6km以内の0.8〜26GHz帯の電波放射を捉える電子情報（ELINT）装備が載っています。
- この装備はモバイルデータ、Wi-Fi、Bluetooth、衛星端末の信号を拾います。

## 4-2. 何をすべきか
- 危険な地域ではすべての携帯を機内モードに切り替えます。
- Wi-Fi・Bluetooth・モバイルデータを一つずつ切るだけでは足りません。 機内モードが推奨されます。
- 最高水準の安全が要るときは、ファラデーバッグ（電磁波遮断の袋）に入れるか、電池を外します。
- スターリンク端末、無線機、CBラジオなどの送信機も位置を晒すので、使用は控えます。

> 防毒面より機内モードが生死を分ける時代です。
> コンクリートの壁の陰で機内モードにした1人のほうが、地下室で携帯をつけたままの数人より安全なことがあります。

# 5. ドローンの音が聞こえたとき

## 5-1. 止まって、聴いて、見分けます
- まず音で型を判断します（1ページの3-1の表）。
- オートバイ・チェーンソーの音 - シャヘド型。数分の時間があるので避難所を探します。
- 大きな羽音 - FPV。数秒のうちに動きます。

## 5-2. どう動くか

> 隠れ場所へそのまま走ってはいけません。 移動の経路は操縦者にそのまま見えており、自分がどこに隠れるつもりかまで教えることになります。

- やぶ、溝、丈の高い草、木などの自然の遮蔽を使い、隠れた経路で動きます。
- ウクライナ軍TTPの警告：「地面の上の影はドローンからはっきり見える。」
- 朝と夕方は影が長く伸びます。 この時間帯は体より先に影が見つかります。

# 6. FPVドローンが突っ込んでくるとき - 3〜7秒

> もっとも危険な状況です。反応できる時間は3〜7秒しかありません。絶対に立ち止まらないでください。

## 6-1. 走れるなら
- ジグザグに、7〜10mごとに向きを変えながら、いちばん近い頑丈な遮蔽物へ走ります。
- FPVドローンは高速では急旋回の能力が限られます。 不規則な方向転換は操縦者の追尾を大きく難しくします。
- 複数人でいるなら、それぞれ別の方向へ散ります。 一方向に固まれば一発で全員がやられます。

## 6-2. 遮蔽物がまったくなく、衝突が迫っているなら
- ドローンに向かない側へ、横向きに地面に伏せます。
- 手で頭と目を守ります。

## 6-3. 最後の手段
- 近い距離でドローンへ物（棒、かばんなど）を投げることが、実際の戦闘で効果があったと記録されています。

# 7. 攻撃の直後 - ダブルタップ

> ドローン攻撃の直後に被害現場へ駆け寄ってはいけません。

## 7-1. ダブルタップとは
- 操縦者は最初の攻撃から5〜20分後に二度目の攻撃を加えます。
- 狙いは救助隊と、現場に集まった民間人です。人が集まるのを待つ戦術です。

## 7-2. ではどうするか
- 救助隊が近づく前に、空を見張る専任の人を先に決めます。
- 操縦者が監視ドローンのカメラで現場をまだ見ていることがあります。 最初の爆発が終わっても観察は続いています。
- 救助は散開して、最少の人数で、短く行います。一か所に集まる時間を減らすことが肝心です。

---

# 8. 墜落したドローンを見つけたとき

> 墜落したドローンの殺傷半径は7m以上です。どの部分にも触れないでください。

- 弾頭がまだ爆発しえます。
- 仕掛け（ブービートラップ）が施されていることがあります。
- 操縦者がドローンのカメラでまだ見ていることがあり、誰かが近づけば遠隔で弾頭を爆発させられます。

| すべきこと | 絶対にしてはいけないこと |
| --- | --- |
| すぐその場を離れます | 触る・持ち上げる |
| 関係機関に場所を通報します | 写真を撮ろうと近づく |
| 他の人、とくに子どもを近づけません | 記念に持ち帰る |

- この原則は不発弾やクラスター弾の子弾にもそのまま当てはまります。「砲撃」の文書も合わせて参照してください。
