# 1. 无人机为何不同于传统空袭

- 仅2025年一年，乌克兰就有577名平民因近距离作战无人机死亡，3,000人以上受伤。
- 无人机会追踪并瞄准每一个平民个体。 这与无差别轰击某一区域的炮击有本质区别。
- 它能在楼宇间飞行、转过拐角，并从敞开的窗户进入。

> 仅凭传统空袭避难要领无法防住无人机。 必须分辨类型，并采取与该类型相应的行动。

# 2. 无人机的四种类型

## 2-1. 远程自杀式无人机 - 沙赫德／天竺葵-2系列
- 由伊朗设计的翼展约2.5米的三角翼无人机，俄方名称为"天竺葵-2"。
- 沿预先设定的GPS航线以约185公里/小时飞行。
- 携带30～50公斤高爆战斗部。

| 破坏半径 | 距离 |
| --- | --- |
| 建筑物破坏 | 约19米 |
| 车辆破坏 | 约32米 |
| 破片杀伤 | 50米以上 |
| 玻璃碎片等二次伤害 | 100米以上 |

> 声音：摩托车或电锯。 1～3公里外也能听见，因此有数分钟的预警时间。

## 2-2. FPV自杀式无人机
- 操作手实时观看摄像画面进行遥控的小型四旋翼。
- 时速100～120公里，战斗部1～7公斤，杀伤半径5～15米。
- 能在狭窄空间飞行、转过拐角，并从敞开的窗户进入室内。

> 声音：如愤怒蜂群般的高频嗡鸣。 安静环境下200～500米可察觉，但最终俯冲阶段只剩3～7秒。

## 2-3. 侦察·监视无人机
- 猎户-10、ZALA、DJI御系列。它们不直接打击，而是查明你的位置，引来后续炮击、导弹或攻击无人机。
- 据乌克兰军TTP文件，部分侦察无人机搭载无线侦察设备，通过汇集手机、无线通信、Wi-Fi、蓝牙信号来计算位置。

> 声音：相对安静的高频音。 安静环境下50～150米，城区仅20～50米可察觉。

## 2-4. 投弹型四旋翼
- 经改装的DJI、道通等平台在空中悬停，投下枪榴弹或反步兵雷。

# 3. 察觉无人机的方法

## 3-1. 声音 - 最重要的手段

> 声音是平民可用的最重要的无人机早期预警手段。

乌克兰军TTP文件明确指出："无人机在白天100～300米高度最难被发现，很可能在看见之前先听到声音。"

| 听到的声音 | 是什么 | 剩余时间与应做之事 |
| --- | --- | --- |
| 摩托车·电锯 | 沙赫德型远程无人机 | 数分钟 - 立即寻找避难所 |
| 如愤怒蜂群的高频嗡鸣 | FPV自杀式无人机 | 数秒 - 立即行动 |
| 安静的高频音 | 侦察无人机 | 正被监视 - 减少电子信号与身形暴露 |

- 驾车时也要开着车窗。 若无人机声音被车噪掩盖，就会失去预警。

## 3-2. 视觉
- 定期观察天空。 尤其在黎明和黄昏较易发现。
- 乌克兰军TTP的原则："空中的一切物体，在确认身份之前均视为敌对。"

## 3-3. 电子预警体系的局限
- 沙赫德、巡航导弹等战略性目标可通过跟踪设备实现早期预警。
- 但针对近距离FPV无人机的有效民用预警体系目前并不存在。

> 因此，凭听觉保持常态警戒是应对FPV无人机的唯一手段。
