# 4. 电子信号 - 手机会指出你的位置

## 4-1. 无人机在"听"电波
- 俄罗斯的猎户-10侦察无人机搭载电子情报（ELINT）设备，可在约6公里范围内探测0.8～26GHz频段的无线电辐射。
- 该设备能捕捉移动数据、Wi-Fi、蓝牙、卫星终端信号。

## 4-2. 应当怎么做
- 在受威胁地区，把所有手机切换为飞行模式。
- 仅逐个关闭Wi-Fi、蓝牙、移动数据并不足够。 推荐使用飞行模式。
- 需要最高级别安全时，应放入法拉第袋（电磁屏蔽袋）或取出电池。
- 星链终端、对讲机、CB电台等发射设备同样会暴露位置，应尽量不用。

> 这是飞行模式比防毒面具更能决定生死的时代。
> 在混凝土墙后切换飞行模式的1个人，可能比在地下室开着手机的数人更安全。

# 5. 听到无人机声音时

## 5-1. 停下、聆听、辨别
- 先用声音判断类型（第1页3-1的表格）。
- 摩托车·电锯声 - 沙赫德型。有数分钟时间，去找避难所。
- 响亮的嗡鸣 - FPV。须在数秒内行动。

## 5-2. 如何移动

> 不要直接朝藏身处跑。 你的移动路线在操作手眼中一览无遗，等于把自己打算躲在哪里也一并告诉了他。

- 利用灌木、沟渠、高草、树木等自然遮蔽，沿隐蔽路线移动。
- 乌克兰军TTP的警告："地面上的影子从无人机上看得很清楚。"
- 早晨与傍晚影子会被拉长。 这些时段，影子比身体先被发现。

# 6. FPV无人机冲来时 - 3～7秒

> 这是最危险的处境，反应时间只有3～7秒。绝对不要站着不动。

## 6-1. 若还能跑
- 以Z字形每7～10米变换一次方向，朝最近的坚固掩体跑。
- FPV无人机在高速下急转能力受限。 不规则变向会大大增加操作手追踪的难度。
- 若有多人在一起，要各自朝不同方向散开。 朝同一方向跑，一发就会伤及所有人。

## 6-2. 若完全没有掩体且撞击在即
- 朝背离无人机的方向侧身趴到地上。
- 用手保护头部和眼睛。

## 6-3. 最后手段
- 有记录显示，在近距离朝无人机投掷物品（棍棒、包等）在实战中确有效果。

# 7. 袭击刚过 - 二次打击

> 无人机袭击刚过，绝不要立刻奔向受袭现场。

## 7-1. 什么是二次打击（Double-Tap）
- 操作手会在首次攻击后5～20分钟发动第二次攻击。
- 目标正是救援人员和聚集到现场的平民。 这一战术就建立在等人聚集之上。

## 7-2. 那该怎么做
- 在救援队接近之前，先指定专人监视天空。
- 操作手可能仍在通过监视无人机的摄像头观察现场。 首次爆炸结束并不意味着观察结束。
- 救援要分散进行、人数最少、时间最短。 减少人群聚集的时间才是关键。

---

# 8. 发现坠落无人机时

> 坠落无人机的杀伤半径在7米以上。任何部位都不要触碰。

- 战斗部仍可能爆炸。
- 可能已设置诡雷。
- 操作手可能仍在通过无人机摄像头观看，一旦有人接近，即可远程引爆战斗部。

| 应做 | 绝不可做 |
| --- | --- |
| 立即离开该处 | 触摸、抬起 |
| 向相关机构报告位置 | 为拍照而靠近 |
| 阻止他人，尤其是儿童靠近 | 当作纪念品带走 |

- 这一原则同样适用于未爆弹和集束弹子弹。 请一并参阅《炮击》文件。
