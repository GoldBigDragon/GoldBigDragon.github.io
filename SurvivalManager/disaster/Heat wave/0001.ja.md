# 猛暑注意報・警報の基準

| 区分 | 次のいずれかに当てはまるとき |
| --- | --- |
| 注意報 | 日最高体感温度33℃以上が2日以上続くと見込まれるとき／体感温度の急上昇や猛暑の長期化で重大な被害が予想されるとき |
| 警報 | 日最高体感温度35℃以上が2日以上続くと見込まれるとき／体感温度の急上昇や猛暑の長期化で広い範囲に重大な被害が予想されるとき |

# 日ごろの備え

- 気象状況をこまめに確認し、周囲の人と共有します。
- 熱中症の症状と手当て、近くの病院の連絡先を家族や近所と一緒に確認しておきます。
- 子ども、高齢の方、心血管・脳血管の疾患がある方は暑さに弱いため、より注意が必要です。
- エアコンや扇風機を事前に整備します。
- 窓にカーテン・布・遮熱フィルムを取り付け、直射日光を防ぎます。
- 外出用につばの広い帽子、日よけ、日焼け止めを用意します。
- 停電に備えて懐中電灯、非常用の食料・飲料、うちわ、携帯ラジオを確認しておきます。
- 断水に備えてペットボトルの水を用意し、浴槽に生活用水をためておきます。
- 古い住宅は変圧器を事前に点検し、冷房による過負荷に備えます。
- 長距離の運転計画は慎重に判断してください。猛暑で道路や線路が変形することがあります。

## 暑さに関する基礎知識
- 冷房時は室内外の温度差を5℃前後に保ちます。健康的な室温は26〜28℃です。
- カフェイン飲料とお酒は控え、水やイオン飲料を飲みます。どちらも利尿作用があり、かえって脱水を招きます。
- 午後2時〜5時が最も暑い時間帯です。屋外作業は行わないでください。
- 食品は傷みやすくなります。外に長く置かれたものは食べないでください。

# 猛暑になったとき

## 1. 家庭
- 屋外活動は最大限控え、外出するときはつばの広い帽子、軽い服装、水筒を用意します。
- 水をこまめに飲みます。のどが渇く前に飲んでください。
- 窓を閉めた車内に、高齢の方や子どもを絶対に一人にしないでください。
- 冷房のない室内では、日差しを遮り、向かい合う窓を開けて風の通り道をつくります。
- 動くのが難しい高齢の方や病気の方を残して長時間出かけるときは、親族や近所に頼み、こまめに安否を確認します。
- めまい、吐き気、頭痛、筋肉のけいれんが出たら、涼しい場所へ移って休み、冷たい飲み物をゆっくり飲みます。

## 2. 職場
- 休憩は一度に長くとるより、短く頻繁にとります。
- 屋外行事やスポーツ大会は控えます。
- 昼休みに10〜15分の昼寝で体力を保ちます。
- 楽な服装で出勤し、体温を下げるよう努めます。
- 冷房のない室内は日差しを遮り、扇風機をつけ、窓やドアを開けて換気します。
- 建設現場など屋外の作業場では猛暑安全ルール（水・日陰・休憩）を守り、危険な時間帯（午後2〜5時）には「猛暑休憩時間制」を実施します。

## 3. 学校
- 冷房の運用が難しい場合は、短縮授業や休校など日程の調整を検討し、食中毒にも注意します。
- 冷房のない教室は日差しを遮り、扇風機と窓で換気します。
- 運動場での体育や遠足など屋外活動は控えます。

## 4. 畜舎・養殖場
- 畜舎の窓を開けて換気を続け、適正な飼育密度を保ちます。
- ビニールハウスや畜舎の天井に散水装置を設け、輻射熱を下げます。
- 養殖魚を継続的に観察し、氷を入れるなどして水温上昇を抑えます。
- 家畜や魚が死んだ場合は、速やかに防疫機関へ届け出ます。

## 5. 猛暑シェルター
- 外出中や、自宅に冷房がない場合は、最も暑い時間帯に近くの猛暑シェルターへ移動します。
- 場所は[安全ティディムドルアプリ](https://play.google.com/store/apps/details?id=kr.go.nema.disasteralert_new)や[自治体のホームページ](https://www.safekorea.go.kr/safekorea-kor/main/main.doidsiSFK/neo/sfk/cs/sfc/htw/htweaiList.html?menuSeq=862)で確認できます。必要になる前に調べておいてください。

# 熱中症への対処

## 1. 熱射病（Heat stroke） - 最も危険
症状
- 体温調節中枢が機能を失った状態で、多臓器の障害が起こりえます。致死率が高いのが特徴です。
- 中枢神経の機能障害（意識障害・こん睡）
- 汗が出ず、乾いて熱い皮膚（40℃超）
- 激しい頭痛、悪寒、頻脈、頻呼吸、低血圧

手当て
1. ただちに119へ通報します。
2. 涼しい場所へ移します。
3. 衣服をゆるめ、体に冷たい水をかけ、うちわや扇風機で冷やします。
4. 氷のうを首、わきの下、そけい部に当てて体温を下げます。

> 意識のない人に水を飲ませてはいけません。 気道に入ります。

## 2. 熱疲労（Heat exhaustion）
症状 - 大量の発汗／冷たく湿った皮膚、顔面蒼白／体温はあまり上がらない（40℃以下）／極度の脱力と疲労、筋肉のけいれん／吐き気・嘔吐、もうろう、めまい

手当て
- 涼しい場所やエアコンのある場所で休みます。
- 水を飲んで水分を補います。
- 冷たい水でシャワーを浴びるか入浴します。
- 1時間以上続く、または回復しないときは、医療機関で点滴により水分と電解質を補います。

## 3. 熱けいれん（Heat cramp）
症状 - 発汗で体内の塩分（ナトリウム）が不足して起こる筋肉のけいれん（腕、脚、腹部、指）。高温下での激しい労働や運動で起こりやすくなります。

手当て
- 涼しい場所で休み、水を飲みます。
- けいれんしている筋肉をマッサージします。
- 次の場合はすぐ救急外来へ。
  - けいれんが1時間を超えて続くとき
  - 基礎疾患として心疾患があるとき
  - 普段から減塩食をとっているとき

## 4. 熱失神（Heat syncope）
症状 - 体表面の血液量が増えて脳へ行く血液が減り、一時的に意識を失う状態。座ったり横になったりした状態から急に立ち上がるときや、長く立っているときに起こり、めまいを伴います。

手当て
- 涼しい場所の平らなところに寝かせます。
- 脚を頭より高く上げます。
- 意思疎通ができれば、水をゆっくり飲ませます。

## 5. 熱浮腫（Heat edema）
症状 - 長く立ったり座ったりしているときに、血液中の水分が血管の外へ移動して起こる手・足・脚のむくみ。

手当て
- 涼しい場所の平らなところに寝かせます。
- むくんだ部位を心臓より高く上げます。

## 6. 熱発疹・あせも（Heat rash）
症状 - 汗管が詰まって汗が出られず、赤いぶつぶつや水ぶくれができます（首、胸の上部、そけい部、腕や脚の内側）。

手当て
- 患部を涼しく乾いた状態に保ちます。
- 発疹用のパウダーや軟膏を使います。
