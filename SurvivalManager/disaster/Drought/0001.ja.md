# 暮らしのなかの節水

## 1. 屋内
- 食器洗い・洗顔・歯みがき・野菜洗いは、水を出しっぱなしにせずためて行います。歯をみがくときは必ずコップを使います。
- 洗濯はまとめて行います。
- 入浴は浴槽をためず、シャワーで適量だけ使い、髪を洗う間は水を止めます。
- ひげをそるときは、洗面器に少しだけ水をためてかみそりを洗います。
- 節水シャワーヘッドや流量調節器を取り付けます。
- 蛇口と配管の水漏れを徹底的に点検します。漏水は最大の無駄です。

## 2. 屋外
- 庭や花壇には一度使った水を再利用します。
- 樹木や大きな植物にはマルチング（上面被覆）をして、蒸発と雑草の繁殖を抑えます。
- 歩道や道路脇の掃除はほうきで行い、水での清掃は控えます。
- 洗車は自動止水付きのホースを使い、水をためて洗剤をつけてからすすぎます。
- ホース、蛇口、接続部の漏水を防ぎます。

## 3. 制限給水への備え
- 制限給水が予告されたら飲料水を先に確保し、給水の日程を確認します。
- 浴槽や大きな容器に生活用水をためておきます。
- 雨水をためて、花壇や掃除に使います。

# 農村での行動

## 1. 農業用水の確保と節約
- 水路、ポンプ、播種機、電気設備、送水ホースをこまめに点検します。
- 田に水をためるとともに、水の損失を防ぐため水路と畦を整備します。
- 間断灌漑、共同苗代、乾田直播で水を節約します。
- 苗代の給水を調節し、苗の老化を防ぎます。
- 田植えの時期を逃した田では、別の作物を播種します。
- 井戸など利用可能な水源を事前に開発します。
- 代替用の種子と代替作物の栽培計画を前もって立てます。

### 水が最も必要な時期（重点給水）
| 時期 | 生育段階 |
| --- | --- |
| 5〜6月 | 活着期 |
| 6〜7月 | 幼穂形成期 |
| 7〜8月 | 穂ばらみ期 |

- 活着期の間は、最低限の湿り気を保ちます。

## 2. 作物の被害を抑える
- 畑作地にはビニール被覆を行い、節水栽培をします。
- 移動式スプリンクラーなどで作物がしおれないよう管理します。
- 土壌水分が適したときに播種し、害虫防除など育苗を管理します。
- 被覆できる場所にはわらやビニールを敷いて、水分の蒸発を抑えます。
- 播種や定植が遅れた地域では、遅く植えられる代替作物を栽培します。

# 干ばつの段階別行動

## 農業用水

| 段階 | 行動 |
| --- | --- |
| 関心 | 間断灌漑・ビニール被覆などの節水栽培／用排水路の清掃と水草の除去／節水営農計画の策定 |
| 注意 | 関心の内容＋水路・ポンプ・ホースの点検整備／排水路と河川の戻り水の揚水／用水の節約／節水営農計画の実践 |
| 警戒 | 注意の内容＋井戸など水源の開発／排水路へ水が流れ出ないよう水口の管理 |
| 深刻 | 警戒の内容＋地下水や周辺河川水など利用可能な水を引いて給水／田植え不可・播種遅延地域では他作物の栽培 |

## 生活用水・工業用水

| 段階 | 行動 |
| --- | --- |
| 関心 | 無駄になっている水がないか点検 |
| 注意 | 関心の内容＋家庭・学校での節水の実践（歯みがきコップ、洗い桶、シャワー時間の短縮） |
| 警戒 | 注意の内容＋節水器具の設置・使用／雨水と再利用水の活用 |
| 深刻 | 警戒の内容＋国の干ばつ対応の段階別要領に積極的に協力（制限給水など） |

# 干ばつ中の健康と衛生

- 貯水池や河川の水量が減ると、汚染の濃度が高まります。 浄水していない水は飲まないでください。
- 制限給水中にためた水はふたをして保管し、時間がたった水は煮沸してから使います。
- 水が不足すると手洗いがおろそかになりがちです。手指消毒剤もあわせて用意します。
- 干ばつは山火事の危険を大きく高めます。屋外で火を使わないでください。
