# 생활 속 물 절약

## 1. 실내
- 설거지·세면·양치·채소 세척은 물을 틀어 놓지 말고 받아서 합니다. 양치할 때는 반드시 컵을 씁니다.
- 세탁은 한꺼번에 모아서 합니다.
- 목욕은 욕조 대신 샤워기로 적당량만 사용하고, 머리를 감는 동안에는 물을 잠급니다.
- 면도할 때는 세면기에 물을 조금만 받아 면도기를 씻습니다.
- 절약형 샤워 꼭지나 수량 조절기를 설치합니다.
- 수도꼭지와 배관의 누수를 철저히 점검합니다. 새는 물이 가장 큰 낭비입니다.

## 2. 실외
- 정원과 꽃밭에는 한 번 사용한 허드렛물을 재사용합니다.
- 나무와 큰 식물에는 윗덮개(멀칭) 를 해 수분 증발과 잡초 번식을 막습니다.
- 인도와 도로변 청소는 빗자루로 하고 물청소를 자제합니다.
- 세차는 자동잠금장치가 있는 호스를 쓰고, 물을 받아 비누칠한 뒤 헹굽니다.
- 호스, 꼭지, 연결부의 누수를 막습니다.

## 3. 제한급수에 대비
- 제한급수가 예고되면 식수를 미리 확보하고 용수 공급 일정을 확인합니다.
- 욕조와 큰 통에 생활용수를 받아 둡니다.
- 빗물을 받아 화단·청소용으로 활용합니다.

# 농촌 행동요령

## 1. 농업용수 확보와 절약
- 수로, 양수기, 파종기, 전기시설, 송수호스를 수시로 점검합니다.
- 논에 물 가두기를 실시하고, 물 손실을 막기 위해 수로와 논두렁을 정비합니다.
- 논물 걸러대기(간단관개), 집단못자리, 건답직파로 물을 절약합니다.
- 못자리 급수를 조절해 모의 노화를 방지합니다.
- 모내는 시기를 놓친 논은 다른 작물을 파종합니다.
- 관정 등 이용 가능한 용수원을 사전에 개발합니다.
- 대파용 종자와 대체작물 재배 계획을 미리 세웁니다.

### 물이 가장 필요한 시기 (중점 급수)
| 시기 | 생육 단계 |
| --- | --- |
| 5~6월 | 활착기 |
| 6~7월 | 유수형성기 |
| 7~8월 | 수잉기 |

- 모 활착 기간에는 최소한의 습기를 유지합니다.

## 2. 작물 피해 최소화
- 밭작물 재배지에 비닐 피복을 하고 절수 재배를 합니다.
- 이동식 스프링클러 등으로 농작물이 시들지 않게 관리합니다.
- 토양 수분이 알맞을 때 파종하고 해충 방제 등 육묘를 관리합니다.
- 토양 피복이 가능한 곳에는 볏짚·비닐을 깔아 수분 증발을 줄입니다.
- 파종·정식이 지연된 지역은 늦게 심을 수 있는 대체작물을 재배합니다.

# 가뭄 단계별 행동요령

## 농업용수

| 단계 | 행동 |
| --- | --- |
| 관심 | 논 물걸러대기·비닐피복 등 절수재배 / 용배수로 청소와 수초 제거 / 절수영농계획 수립 |
| 주의 | 관심 단계 + 수로·양수기·호스 점검·정비 / 배수로·하천의 퇴수 양수 / 용수 절약 / 절수영농계획 실천 |
| 경계 | 주의 단계 + 관정·우물 등 용수원 개발 / 배수로로 물이 흘러나가지 않도록 물꼬 관리 |
| 심각 | 경계 단계 + 지하수·주변 하천수 등 이용 가능한 물을 끌어와 급수 / 모내기 불가·파종 지연 지역은 타작물 재배 |

## 생활 및 공업용수

| 단계 | 행동 |
| --- | --- |
| 관심 | 낭비되는 물이 없는지 점검 |
| 주의 | 관심 단계 + 가정·학교에서 물 절약 실천 (양치컵, 설거지 통, 샤워시간 줄이기) |
| 경계 | 주의 단계 + 절수용품 설치·사용 / 빗물과 재활용수 이용 |
| 심각 | 경계 단계 + 국가 가뭄대응 단계별 요령에 적극 동참 (제한급수 등) |

# 가뭄 중 건강과 위생

- 저수지와 하천의 수량이 줄면 오염 농도가 높아집니다. 정수되지 않은 물을 마시지 않습니다.
- 제한급수 중 받아 둔 물은 뚜껑을 덮어 보관하고, 오래된 물은 끓여 사용합니다.
- 물 부족으로 손 씻기가 소홀해지기 쉽습니다. 손소독제를 함께 준비합니다.
- 가뭄은 산불 위험을 크게 높입니다. 야외에서 불을 피우지 않습니다.
