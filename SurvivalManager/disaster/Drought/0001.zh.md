# 日常节水

## 1. 室内
- 洗碗、洗脸、刷牙、洗菜时不要一直开着水龙头，要接水使用。 刷牙必须用杯子。
- 洗衣服要攒够一次洗。
- 洗澡不要放满浴缸，用淋浴按需取用，洗头时把水关上。
- 刮胡子时在洗脸池里接少量水冲洗剃须刀。
- 安装节水花洒或流量调节器。
- 彻底检查水龙头和管道有无漏水，漏水是最大的浪费。

## 2. 室外
- 浇灌庭院和花坛请重复利用用过一次的中水。
- 给树木和大型植物做覆盖（地膜），防止水分蒸发和杂草滋生。
- 清扫人行道和路边请用扫帚，尽量不用水冲洗。
- 洗车要用带自动止水装置的水管，接水打上肥皂后再冲洗。
- 防止水管、龙头、接口漏水。

## 3. 为限制供水做准备
- 一旦预告限制供水，请先备好饮用水，并确认供水时间安排。
- 在浴缸和大容器中蓄好生活用水。
- 收集雨水用于浇花和清扫。

# 农村的做法

## 1. 保障与节约农业用水
- 经常检查水渠、抽水机、播种机、电气设施和输水软管。
- 在稻田里蓄水，并整修水渠和田埂防止跑水。
- 通过间歇灌溉、集中育秧、旱地直播节约用水。
- 调节秧田供水，防止秧苗老化。
- 错过插秧时节的田块，请改播其他作物。
- 提前开发机井等可用水源。
- 提前制定补种用种子和替代作物的栽培计划。

### 最需要水的时期（重点供水）
| 时期 | 生育阶段 |
| --- | --- |
| 5～6月 | 返青（活着）期 |
| 6～7月 | 幼穗形成期 |
| 7～8月 | 孕穗期 |

- 返青期间至少要保持基本湿度。

## 2. 减轻作物损失
- 旱田种植区要覆膜并采用节水栽培。
- 使用移动式喷灌等设备，防止作物萎蔫。
- 在土壤墒情合适时播种，并做好病虫害防治等育苗管理。
- 可覆盖的地块铺上稻草或薄膜，减少水分蒸发。
- 播种、定植延迟的地区，改种可以晚播的替代作物。

# 干旱分级应对

## 农业用水

| 等级 | 应对措施 |
| --- | --- |
| 关注 | 间歇灌溉、覆膜等节水栽培／清理灌排渠、清除水草／制定节水农业计划 |
| 注意 | 关注级基础上＋检修水渠、抽水机、软管／抽取排水渠与河道的回流水／节约用水／落实节水农业计划 |
| 警戒 | 注意级基础上＋开发机井、水井等水源／管好水口，不让水流入排水渠 |
| 严重 | 警戒级基础上＋引用地下水、周边河水等一切可用水源供水／无法插秧、播种延误的地区改种其他作物 |

## 生活与工业用水

| 等级 | 应对措施 |
| --- | --- |
| 关注 | 检查有无被浪费的水 |
| 注意 | 关注级基础上＋在家庭和学校落实节水（刷牙用杯、洗碗用盆、缩短淋浴时间） |
| 警戒 | 注意级基础上＋安装使用节水器具／利用雨水和再生水 |
| 严重 | 警戒级基础上＋积极配合国家抗旱分级措施（限制供水等） |

# 干旱期间的健康与卫生

- 水库和河道水量减少时，污染物浓度会升高，不要饮用未经净化的水。
- 限制供水期间储存的水要加盖保存，放置较久的水要煮沸后使用。
- 缺水时容易忽略洗手，请同时备好免洗手消毒液。
- 干旱会大幅提高山火风险，不要在野外用火。
