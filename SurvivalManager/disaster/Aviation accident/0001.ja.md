# 搭乗前の準備

- 機内持ち込み禁止品は持たず、手荷物は規定のサイズ・重量を守って、非常脱出の妨げにならないようにします。
- 子どもや高齢の方の体調・持病については、搭乗前に航空会社の係員や客室乗務員に伝えてください。
- 指定された座席に座り、勝手に移動しないでください。乗務員が乗客の位置を把握できてこそ、救助が早くなります。
- 統計的には、非常口から5列以内の座席で生存率が高いとされています。
- 非常口席でない場合は、自分の席から最寄りの非常口まで何列あるかを数えておきます。 煙で前が見えなくても、座席の背もたれを数えながら進めます。
- 化学繊維より綿や毛の衣服、かかとの低い靴のほうが、火災時と脱出時に有利です。

# 飛行中

- 事故は離陸後3分間と着陸前8分間に集中します。この時間帯はイヤホンを外し、靴を履いたまま、起きていてください。
- 乱気流に備え、着席中は常にシートベルトを締めます。
- 客室乗務員の安全ブリーフィングは最後まで聞き、座席前の安全のしおりを実際に確認してください。

# 非常時の行動

## 1. 気圧低下 - 酸素マスク
- マスクが下りてきたら、まず自分が装着してから子どもや高齢の方を手伝います。
- 高高度では意識を保てる時間が数十秒しかありません。人を先に助けようとすると共倒れになります。
- マスクを引き下げて酸素の供給を始め、鼻と口の両方を覆ってください。

## 2. 衝撃に備える姿勢
- 背もたれを完全に立て、ベルトを骨盤の低い位置できつく締めます。
- 上体を前に倒して頭をひざにつけ、両手で後頭部を包みます。
- 前の座席に手が届くなら、両手を背もたれに当て、その上に額をつけます。

## 3. 脱出
- 手荷物はあきらめてください。 荷物を取り出す数秒が、後ろの乗客全員の脱出を止めます。
- かかとの高い靴や角のとがったアクセサリーは外します。脱出スライドが裂けます。
- 煙が充満していれば姿勢を低くし、座席の背もたれをたどって進みます。
- 脱出スライドは飛び込まず、座って滑り降り、すぐに機体から離れてください。

## 4. 水面への不時着
- 救命胴衣は必ず機外に出てからふくらませます。
- 機内でふくらませると、浸水時に体が天井に張りついて脱出口にたどり着けません。

# ハイジャックされたとき

- 犯人の指示に従い、注意を引く行動は控えてください。
- 話しかけられたら、静かに答えます。
- 救出作戦が始まったらうつ伏せの姿勢を保ってください。 救出チームが犯人と乗客を見分けるためです。
- 状況・人数・武器などを覚えておき、救出後に証言します。

---

# 事故のあと

- 燃料火災と有毒ガスを避けるため、機体から風上へ100m以上離れてください。
- けが人がいれば応急手当をしてから119へ通報します。
- 海外では韓国外交部の領事コールセンター（韓国内 02-3210-0404／海外 +82-2-3210-0404）に連絡します。
