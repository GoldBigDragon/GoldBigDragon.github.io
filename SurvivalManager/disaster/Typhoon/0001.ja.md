# 台風は風と水が同時に来る災害です

台風の被害は、暴風・大雨・高潮・土砂災害が重なって起こります。どれか一つだけ備えても足りません。

---

# 台風の予報が出たら

## 1. 情報と計画
- テレビ・ラジオ・インターネットと[安全ティディムドルアプリ](https://play.google.com/store/apps/details?id=kr.go.nema.disasteralert_new)で災害情報を受け取ります。
- 台風の進路と到達時刻を把握し、それに合わせて避難計画を立てます。
- 非常用品をリュックにまとめ、断水に備えて浴槽に水をためておきます。
- 停電に備えて懐中電灯と乾電池を用意します。
- 高齢の方・子ども・障害のある方の安否を確認し、避難の方法を伝えておきます。

## 2. 危険な場所から移動
- 山間部・渓谷・河川・防波堤にいるなら、周囲の人と一緒に安全な場所へ移動します。
- 登山・キャンプ・水遊び・釣りはただちに中止します。
- 低地、常習浸水地域、土砂災害危険区域、地下空間、老朽住宅にいる場合は安全な場所へ移ります。

## 3. 暴風への備え
- 古い窓は事前に交換または補強し、飛散防止フィルムを貼ります。
- 窓枠とガラスのすき間を埋めてガタつきをなくします。テープは、ガラスが窓枠に固定されるように貼ってこそ効果があります。
- 屋根、看板、鉄塔など屋外設置物を固定・補強します。
- 風で飛びそうな屋外の物はすべて屋内に入れるか撤去します。
- ビニールハウスの弱い部分を補強し、周囲を片づけます。
- 露出した電線の接続部を点検し、必要なら交換します。

## 4. 浸水への備え
- 家の周りの排水口を点検し、詰まりを取り除きます。
- マンションの地下駐車場などに土のうと止水板を設置します。
- 川べり・海辺・低地に止めた車を移し、車に連絡先を残しておきます。
- 農地の用排水路や畦の整備、水口の調整は、雨が降る前（予備注意報の段階）にだけ行います。
- 船はしっかり係留するか陸へ揚げ、漁網・漁具も移動させます。

# 台風の特別警報・注意報の発表中

## 1. 外へ出ない
- 警報が出ている間は外に出ないでください。
- 船を固定したり、漁網・漁具を移したりしに行かないでください。
- 畦や水口を見に行かないでください。 台風による死亡事故の多くはこの場面で起きています。
- 航行中の船は、周囲の船と海洋警察に現在位置を知らせ、台風の進路からできるだけ離れます。

## 2. 近づいてはいけない場所
- 少しでも冠水した道路、アンダーパス、潜水橋、橋は、人も車も通行しないでください。
- 山間部・渓谷・川べり・海岸は急流にさらわれるおそれがあるため近づきません。
- 工事現場、街灯、信号機、電柱、地下空間に近づかないでください。
- 斜面、擁壁、石垣は崩れるおそれがあるため近づきません。
- 移動式住宅や仮設施設にいる場合は、ただちに頑丈な建物へ移ります。
- 土砂災害危険区域では、警報が出ていなくても避難します。

## 3. 屋内で
- 出入口と窓を閉めて破損を防ぎ、ガラス戸や窓から離れてください。
- 浴室のような窓のない部屋や、家の一番内側へ移動します。
- ガスを事前に止め、ぬれた手で電気設備に触れないでください。
- 停電時はろうそくではなく懐中電灯や携帯電話を使います。
- 建物内に少しでも水が入ってきたら、ただちに高い場所へ移動します。

## 4. 屋外・運転
- 屋外活動を中止し、すぐ屋内に入ります。
- 運転中は速度を落として防御運転し、対向車と隣の車線の車に注意します。突風は車を車線の外へ押し出します。
- 工事資材が倒れるおそれがあるため、屋外作業やクレーンの運行を中止します。
- ガラス窓や看板の近くを避け、空き地や建物の中へ避難します。
- 稲光を見てから30秒以内に雷鳴が聞こえたら、ただちに安全な場所へ避難します。

# 台風のあと

## 1. 確認と届け出
- 家族や知人の安否を確認し、連絡が取れず行方不明が疑われる場合は警察へ届け出ます。
- 冠水した道路や橋は破損している可能性があるため、被災地域に近づかないでください。
- 河川の堤防付近や地盤の緩んだ斜面は崩れるおそれがあるため近づきません。
- 孤立した場合は無理に水を渡らず、119や行政福祉センターへ通報するか、周囲に助けを求めます。
- 帰宅するときは、住宅の安全を確かめてから入ります。
- 破損した施設は必ず写真を撮ってから、自治体の窓口へ届け出ます。

## 2. 二次被害の防止
- 引いていく水は油や動物の死骸で汚れていることが多いため、水から離れてください。
- 水道水や貯めた水は汚染の有無を確認してから使い、浸水した食品や食材は食中毒のおそれがあるため使いません。
- 浸水した住宅では、ガスと電気のブレーカーを確認し、韓国ガス安全公社（1544-4500）、韓国電気安全公社（1588-7500）または専門家の点検を受けてから使用します。
- ガス漏れのおそれがあるので、窓を開けて十分に換気し、換気前はマッチやライターを使いません。
- 地面に落ちた電線に近づいたり触れたりしないでください。 破損した電気設備を見つけたら119や自治体へ連絡します。
- 電線が車に触れた場合は車内にとどまり、金属部分に触れないよう注意し、周囲に知らせてから119へ連絡します。
- 倒れた農作物は起こし、浸水した田畑を排水したあと、作物の土や汚れを洗い流して緊急の病害虫防除を行います。
