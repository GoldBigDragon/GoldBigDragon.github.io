# 1. 提前掌握避难场所

撤离总是突然到来。 要事先确认家庭、单位、学校等日常场所最近的避难场所。

## 1-1. 按攻击类型选择合适的场所

| 攻击类型 | 合适的避难场所 |
| --- | --- |
| 常规武器 | 民防避难所、公寓与大型建筑的地下停车场、地铁车站 |
| 化学 | 能隔绝外部空气的高层室内 |
| 生物 | 指定避难设施或家中等能隔绝外部空气并可停留的室内 |
| 核／放射性 | 民防避难所、公寓与大型建筑的地下停车场、地铁车站 |

## 1-2. 查找方法
在[Naver地图](https://map.naver.com/p/search/민방위%20대피소)、[Kakao Map](https://map.kakao.com/)、[安全踏板应用](https://play.google.com/store/apps/details?id=kr.go.nema.disasteralert_new)中搜索"민방위 대피소"（民防避难所），即可查到距当前位置最近的避难所。

> 平时请亲自去看一次。 知道入口在哪里、是否储备了物资、走到那里需要多久，与一无所知，在紧急时刻完全是两回事。

## 1-3. 两个例外
- 在预计有集中降雨的时期（梅雨、台风），不要撤入易涝低洼地区的地下设施，而应前往更安全的地区。
- 化学武器攻击时是高层而不是地下。 因为化学战剂比空气重，会积聚在地下。

# 2. 生存背包

## 2-1. 准备原则
- 生存背包装的是撤离后维持生活所需的最低限度物品。突然撤离时根本没有时间收拾东西。
- 要按家庭人数分别准备，不要把重要物品全部集中在一个人的背包里。
- 重量不要超过体重的10%。 太重会拖慢移动并快速消耗体力。
- 不能沾水的物品（收音机、重要文件、现金、衣物、充电宝）要装入密封袋。
- 带腰带和胸带的登山包更省力。
- 食物要选无需烹调即可食用的，并定期检查保质期更换。
- 电池要备足。 需要用收音机收听政府通告。
- 不要只放在家里。 撤离时未必在家，因此在单位或学校也要备一个简易背包，车里也要备水和食物。

## 2-2. 基本配置
2～3天的饮用水、食物、生活用品、常备药、收音机、手电筒、化生防护用品。

| 分类 | 物品 |
| :---: | :--- |
| 饮食 | 500毫升瓶装水4瓶、应急食品、净水滤芯、净水片、盐、复合维生素 |
| 婴幼儿与老弱者 | 奶粉、辅食、奶瓶、小玩具、软包装粥 |
| 衣物 | 防毒面具、防护服、一次性雨衣、手套、袜子、护目镜、口罩、内衣、帽子、防风外套 |
| 医疗 | 抗生素软膏、止泻药、退烧药、止痛药、消化药、绷带、消毒药、常用药、慢性病处方 |
| 保温 | 锡箔保温毯、暖手宝 |
| 照明 | 手电筒、头灯、电池 |
| 卫生 | 肥皂、纸巾、毛巾、卫生巾、牙刷、牙膏、湿巾 |
| 工具 | 收音机、哨子、打火机、多功能刀、剪刀、指甲刀、螺丝刀、镊子、塑料袋、密封袋、胶带、笔和纸、指南针、住所周边地图、充电宝、USB线、充电器、餐具、一次性盘杯、现金 |
| 文件 | 身份证复印件、重要文件、家人与熟人的联系方式 |

## 2-3. 重要文件
- 把存折、保险单、合同、身份证的复印件放入生存背包，以防原件遗失。
- 装入防水密封袋避免受潮。

# 3. 紧急联络计划

## 3-1. 约定会合地点
- 紧急时通信很可能瘫痪、与家人失去联系。必须事先约定。
- 把平时常约见的地方或安全的避难所定为会合地点。
- 为防第一地点无法进入，还要备好第二、第三地点。
- 还要约定家中危险无法进入时以及从学校、单位撤离时的汇合点。

## 3-2. 紧急联络卡
> 手机损坏或电量耗尽时，一个电话号码都查不到。
> 务必把纸质联系方式放进每个人的生存背包。

需要写明：个人信息 · 家庭信息 · 血型 · 正在服用的药 · 联系方式 · 政府相关机构与救助机构的联系方式

## 3-3. 应对通信中断
- 事先在家庭成员手机上安装KakaoTalk以外的通讯软件（Telegram、Discord等）。
- 下载[MAPS.ME](https://play.google.com/store/apps/details?id=com.mapswithme.maps.pro)等离线地图应用，即使断网也能查看撤离路线。
