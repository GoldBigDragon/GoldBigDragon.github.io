# 1. 避難場所を先に把握する

避難は突然やってきます。 家庭、職場、学校など普段いる場所からもっとも近い避難場所を前もって確かめておかねばなりません。

## 1-1. 攻撃の種類別に適した場所

| 攻撃の種類 | 適した避難場所 |
| --- | --- |
| 在来型兵器 | 民防衛避難所、マンションや大型建物の地下駐車場、地下鉄の駅舎 |
| 化学 | 外気を遮断できる高い階の屋内 |
| 生物 | 指定避難施設や自宅など、外気を遮断してとどまれる屋内 |
| 核・放射能 | 民防衛避難所、マンションや大型建物の地下駐車場、地下鉄の駅舎 |

## 1-2. 探し方
[ネイバー地図](https://map.naver.com/p/search/민방위%20대피소)、[カカオマップ](https://map.kakao.com/)、[安全ディディムドルのアプリ](https://play.google.com/store/apps/details?id=kr.go.nema.disasteralert_new)で「민방위 대피소（民防衛避難所）」 を検索すると、現在地からもっとも近い場所が分かります。

> 平時に一度、実際に行ってみてください。 入口の位置、備蓄の有無、着くまでにかかる時間を知っているのと知らないのとでは、いざというとき全く違います。

## 1-3. 二つの例外
- 集中豪雨が予想される時期（梅雨・台風） には、浸水しやすい低地の地下施設ではなく、より安全な地域へ向かいます。
- 化学兵器の攻撃では地下ではなく高い階です。化学剤が空気より重く、地下にたまるからです。

# 2. 生存リュック

## 2-1. 準備の原則
- 生存リュックは避難したあとの生活のための最小限の生活用品を入れたかばんです。突然の避難では物をそろえる時間がありません。
- 家族の人数に合わせて用意し、一人のリュックに大事な物を全部まとめません。
- 体重の10%を超えないようにします。重いと移動が遅くなり体力を早く消耗します。
- 濡れてはいけない物（ラジオ、重要書類、現金、衣類、モバイルバッテリー）はジッパー袋に入れます。
- 腰ベルトと胸ベルトのある登山リュックが楽です。
- 食べ物は調理せずに食べられる物にし、賞味期限を定期的に確かめて入れ替えます。
- 乾電池は予備を十分に用意します。政府の案内放送をラジオで聞くためです。
- 自宅だけに置きません。 避難の時点で家にいるとは限らないので、職場や学校にも簡単なリュックを、車にも水と食料を用意します。

## 2-2. 基本の中身
2〜3日分の飲み水、食料、生活必需品、常備薬、ラジオ、懐中電灯、化学生物対策用品。

| 分類 | 品目 |
| :---: | :--- |
| 飲食物 | 500mLの水4本、非常食、浄水フィルター、浄水錠、塩、総合ビタミン剤 |
| 乳幼児・高齢者 | 粉ミルク、離乳食、哺乳びん、小さなおもちゃ、レトルトのおかゆ |
| 衣類 | 防毒面、防護服、使い捨て雨具、手袋、靴下、保護めがね、マスク、下着、帽子、防風ジャケット |
| 医療 | 抗生物質の軟膏、下痢止め、解熱剤、鎮痛剤、胃腸薬、包帯、消毒薬、常用薬、慢性疾患の処方箋 |
| 保温 | アルミ蒸着ブランケット、カイロ |
| 照明 | 懐中電灯、ヘッドランプ、乾電池 |
| 衛生 | せっけん、ティッシュ、タオル、生理用品、歯ブラシ、歯みがき、ウェットティッシュ |
| 道具 | ラジオ、ホイッスル、ライター、多用途ナイフ、はさみ、つめ切り、ドライバー、ピンセット、ビニール袋、ジッパー袋、テープ、筆記具、コンパス、自宅周辺の地図、モバイルバッテリー、USBケーブル、充電器、食器、使い捨ての皿とコップ、現金 |
| 書類 | 身分証の写し、重要書類、家族と知人の連絡先 |

## 2-3. 重要書類
- 通帳、保険証書、契約書、身分証の写しを生存リュックに入れておきます。原本を失った場合に備えるためです。
- 防水のジッパー袋に入れて濡れるのを防ぎます。

# 3. 緊急連絡の計画

## 3-1. 落ち合う場所
- 非常時は通信が麻痺して連絡が途絶える可能性が高いのです。あらかじめ決めておきます。
- 普段待ち合わせに使う場所や安全な避難所を落ち合う場所にします。
- 第1の場所に近づけない場合に備えて第2、第3の場所を用意します。
- 自宅が危険で近づけない場合と学校・職場から避難する場合の合流地点も決めておきます。

## 3-2. 緊急連絡カード
> スマートフォンが壊れたり電池が切れたりすれば、電話番号を一つも確かめられません。
> 必ず紙の連絡先を各自の生存リュックに入れておきます。

書くもの：個人事項・家族事項・血液型・服用中の薬・連絡先・政府関係機関と救護機関の連絡先

## 3-3. 通信断絶への備え
- カカオトーク以外のメッセンジャー（テレグラム、ディスコードなど）を各自のスマートフォンに入れておきます。
- [MAPS.ME](https://play.google.com/store/apps/details?id=com.mapswithme.maps.pro)のようなオフライン地図アプリを入れておけば、通信が切れても避難経路を確かめられます。
