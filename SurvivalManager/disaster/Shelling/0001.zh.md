# 1. 炮击是怎样的状况

- 几乎没有预警时间。 炮弹从发射到落地只有数十秒至数分钟，且在广大区域内同时落下。
- 二次伤害大于弹片本身。 建筑倒塌、火灾，以及被爆压击碎、如同子弹般倾泻的玻璃碎片，在伤亡中占很大比重。
- 无法事先知道敌方使用哪种弹药。 必须以"常规爆炸弹可能混有化学武器、生物武器、核弹头"为前提，做综合准备。
- 不会一次结束。 炮击会反复多次，多种攻击也可能同时到来。

> 第一次爆炸之后可能更危险。 不要放松警戒，持续通过收音机和灾难短信收听政府广播。

## 1-1. 听到警报的那一刻

民防警报的种类与警报信号已整理在《民防警报》文件中。在炮击场景下，只需记住以下顺序。

| 顺序 | 行动 |
| --- | --- |
| ① | 关闭所有窗户 - 既阻挡弹片与冲击波，也阻止核生化污染物侵入 |
| ② | 戴上防毒面具（或口罩）- 以可能遭核生化攻击为前提 |
| ③ | 移动到远离窗户的建筑内侧，或进入地下 |
| ④ | 趴下，保护头部和身体 |

# 2. 在室内时

## 2-1. 去哪里
- 选择没有玻璃窗的空间 - 卫生间、内侧走廊、楼梯间、内部储物间。
- 建筑的最内侧、远离外墙而靠近内墙和柱子的位置最好。
- 绝不使用电梯，务必走楼梯。 爆炸导致停电会把人困在里面，电梯门也可能在起火的那一层打开。
- 务必避开楼顶。 那里会完全暴露于炮火之下。

## 2-2. 哪一层安全取决于攻击类型

> 这个判断决定生死。 请通过政府广播确认是哪种攻击。

| 攻击类型 | 安全位置 | 原因 |
| --- | --- | --- |
| 常规爆炸弹炮击 | 低层或地下 | 厚重结构可阻挡弹片与冲击波 |
| 已确认化学武器 | 相对较高的楼层 | 化学剂比空气重，会下沉并积聚于地下 |

- 完全没有信息时，按常规炮击处理，前往低层或地下，但要戴着防毒面具进入。

## 2-3. 姿势
- 趴下。 把头和身体放低，是对弹片最基本的防御。
- 双手遮住眼睛和耳朵。
- 张开嘴 - 防止气压骤变导致耳膜破裂。
- 腹部离开地面 - 减轻经地面传来的冲击波伤害。

---

# 3. 在室外时

室外会完全暴露于核生化武器和弹片之下，是最危险的地方。原则是立即进入室内。

| 情况 | 行动 |
| --- | --- |
| 附近有建筑 | 进入最近的建筑内部，按上面第2条处理 |
| 没有建筑但有车 | 进入车内，关窗并切换内循环，阻断外部空气进入 |
| 两者都没有 | 利用地形地物 - 沟渠、洼地、混凝土结构背后 - 趴下 |

- 趴下时把身体置于爆炸方向的反侧，双手遮眼护耳，张开嘴，腹部离地。
- 低处更有利。 弹片多向上方和侧方飞散，越贴近地面被击中的概率越低。
- 但存在化学武器可能时，不要在沟渠和低洼处久留。 较重的化学剂会积聚在低处。

---

# 4. 驾车时

- 车辆几乎无法阻挡爆炸弹片和冲击波。 不要留在车内，移动到坚固建筑或地下要安全得多。
- 把车停到附近空地或道路右侧。 停在路中央会妨碍军用车辆、救护车、消防车通行。
- 不要锁门，并把车钥匙留在车上。 应急人员在需要时必须能把车移开。
- 下车后迅速撤往最近的建筑或地下设施。
- 例外：在完全没有建筑的地方，车内胜于露天。 关窗、切换内循环，并把身体降到座椅以下。
