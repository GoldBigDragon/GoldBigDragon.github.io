# 1. 砲撃という状況

- 警告の時間がほとんどありません。 砲弾は発射から着弾まで数十秒〜数分で、広い地域に同時に降ります。
- 破片そのものより二次被害が大きいです。 建物の崩壊、火災、そして爆圧で割れ、銃弾のように降りそそぐ窓ガラスの破片が死傷者の大きな割合を占めます。
- 敵がどんな弾薬を使うかは事前に分かりません。 通常の爆発弾に化学兵器・生物兵器・核弾頭が混ざる可能性を前提に、まとめて備える必要があります。
- 一度で終わりません。 何度も繰り返され、複数の種類の攻撃が同時に来ることもあります。

> 最初の爆発のあとのほうが危険なこともあります。 警戒を解かず、ラジオや災害メールで政府の案内放送を聴き続けてください。

## 1-1. サイレンを聞いた瞬間にすること

民間防衛の警報の種類とサイレンの信号は「民防衛警報」の文書にまとめてあります。砲撃の場面では、この順序だけ覚えておけば足ります。

| 順 | 行動 |
| --- | --- |
| ① | 窓をすべて閉める - 破片と衝撃波の侵入も、NBC汚染物質の侵入も同時に防ぎます |
| ② | 防毒面（またはマスク）を着ける - NBC攻撃の可能性を前提にします |
| ③ | 窓から遠い建物の奥、または地下へ移動する |
| ④ | 伏せて頭と体を守る |

# 2. 屋内にいるとき

## 2-1. どこへ行くか
- 窓のない場所を選びます - トイレ、内側の廊下、階段室、内側の物置。
- 建物のいちばん奥、外壁から遠く内壁や柱に近い位置がよいです。
- エレベーターは絶対に使わず階段を使います。 爆発で停電すれば中に閉じ込められ、火災のあった階で扉が開くこともあります。
- 屋上は必ず避けます。 砲撃にそのまま身をさらすことになります。

## 2-2. 何階が安全かは攻撃の種類で変わります

> この判断が生死を分けます。 政府の案内放送でどの攻撃なのかを確かめてください。

| 攻撃の種類 | 安全な位置 | 理由 |
| --- | --- | --- |
| 通常の爆発弾による砲撃 | 低い階または地下 | 厚い構造物が破片と衝撃波を防ぎます |
| 化学兵器と確認されたとき | 比較的高い階 | 化学剤は空気より重く、下に沈んで地下にたまります |

- 情報がまったくないときは通常の砲撃を基準に低い階・地下へ移りますが、防毒面を着けたまま入ります。

## 2-3. 姿勢
- 伏せます。 頭と体を低くすることが破片に対するもっとも基本的な防御です。
- 両手で目と耳を覆います。
- 口を開けます - 急激な気圧の変化で鼓膜が破れるのを防ぎます。
- 腹部を床から浮かせます - 地面を伝わる衝撃波の被害を減らします。

# 3. 屋外にいるとき

屋外はNBC兵器と破片にそのままさらされる、もっとも危険な場所です。すぐ屋内に入るのが原則です。

| 状況 | 行動 |
| --- | --- |
| 建物がある | いちばん近い建物の中に入り、上の2番の要領に従います |
| 建物はなく車両がある | 車内に入り、窓を閉めて内気循環にして外の空気の流入を止めます |
| どちらもない | 溝、くぼ地、コンクリート構造物の陰など地形・地物を使って伏せます |

- 伏せるときは爆発の方向の反対側に体を置き、両手で目と耳を覆い、口は開け、腹部は床から浮かせます。
- 低い場所が有利です。 破片は主に上や横へ飛ぶので、地面に近いほど当たる確率が下がります。
- ただし化学兵器の可能性があるときは溝や低地に長くとどまりません。 重い薬剤が低いところにたまります。

---

# 4. 運転中のとき

- 車両は爆発の破片や衝撃波をほとんど防げません。 車内にとどまらず、頑丈な建物や地下へ移動するほうがはるかに安全です。
- 近くの空き地か道路の右側に車を寄せます。 道路の真ん中に止めると軍用車両・救急車・消防車の通行を妨げます。
- 鍵をかけず、車のキーを車内に置いたまま降ります。 緊急対応の人員が必要なときに車を動かせなければなりません。
- 降りたらいちばん近い建物か地下施設へ速やかに避難します。
- ただし建物がまったくない場所では、車内のほうが屋外よりましです。 窓を閉め、内気循環にして、座席より低く身を沈めます。
