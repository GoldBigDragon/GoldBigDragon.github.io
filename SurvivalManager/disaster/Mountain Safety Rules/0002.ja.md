# 4. ヘビにかまれたら

## 4-1. 毒ヘビかどうか
- 頭が三角形で、かまれた跡の前側に二つの牙の跡があれば毒ヘビ（マムシ）の可能性が高いです。
- 毒のないヘビにかまれると細い擦り傷が何列もつきます。

## 4-2. 行動の順序
1. すぐにヘビから離れます。 つかもうとしたり、再び刺激したりしません。
2. 傷病者を落ち着かせ、動きを最小限にします。 興奮したり動いたりすると血流が速まり、毒がより速く広がります。
3. 腕輪や時計などの装飾品を外します。 腫れると血流を止めてしまいます。
4. かまれた部位をきれいな水で洗います。
5. かまれた部位の10cm上にガーゼを当て、指1本が入るくらいゆるく包帯を巻きます。
   - 強く縛りすぎると血流が断たれ、皮膚が壊死します。
6. かまれた部位を心臓より低く保ちます。腕なら腕を下げ、脚なら横になります。
7. 吐き気・腹痛・意識低下が起こりうるので、横向きに寝かせて吐くのに備えます。

## 4-3. 絶対にしないこと

| 誤った処置 | 理由 |
| --- | --- |
| 傷をナイフで切開する | 筋肉・血管・神経を傷つけ、二次感染の危険が高まります |
| 口で毒を吸い出す | 効果がなく、処置する人にも危険です |
| かまれた部位を強く縛る | 腫れると皮膚が壊死し、縛った布が肉に食い込みます |
| 氷を直接当てる | 毒を無くすことはできず、凍傷・組織壊死の危険が高いです |
| たばこの灰やみそを塗る | 炎症を起こします |
| 飲食物を与える | とくに酒は血流を促し、毒が速く広がります |
| 豚の脂身でこする | 効果がなく、感染の危険が高いです |

## 4-4. 通信できない場合
- 解毒剤のある最寄りの医療機関へ運ぶことが最優先です。
- 枝と衣類で担架をつくり、傷病者の動きを最大限おさえます。
- 歩かせるならできるだけゆっくり、一定の速さで移動します。

# 5. イノシシに出会ったら

## 5-1. イノシシを知る
- 視力は弱いが、嗅覚と聴覚がとても鋭いです。
- 刺激されると方向感覚を失い、まっすぐ突進します。
- 背を向けて逃げると、獲物と見なして追ってきます。
- 首が短く上をよく見られず、上り坂に弱いです。

## 5-2. まだ気づかれていないとき
- 静かに後ろへ下がって安全な場所へ避けます。
- 風を背にしていると、においを嗅ぎつけて近づいてきます。 風向きに注意します。

## 5-3. 出会ってしまったとき
1. 大声を出したり、急に動いたりしません。
2. 落ち着いて止まり、目を合わせたまま様子を見ます。
3. 絶対に背を向けず、向き合ったままごくゆっくり後ろへ下がって距離をとります。
4. 近くの木や岩の陰、高い場所へ避けます。上り坂に弱く、上をよく見られません。
5. 襲われそうだと感じたら、かばんや手に持っている物で体を守ります。

## 5-4. 突進してきたとき
- イノシシは人よりはるかに速いです。背を向けて逃げません。
- 木の上や岩の上など、できるだけ高い所へ上がります。
- 大きな木をあいだに置いて、動きに合わせて回るのも有効です。
- ザックや上着を盾として使います。

## 5-5. 絶対にしないこと
- 石を投げる、脅す
- 大声を出す、手を振る
- 無理に近づく
- 追い払おうとする
- 背を向けて逃げる

# 6. ハチに刺されたら

## 6-1. 行動の順序
1. 針が見えたらクレジットカードや薄い道具でそっとかき出して取ります。無理に抜こうとしません。
2. 取ったあと、患部を絶対にこすりません。 毒がより広く回ります。
3. 冷たい水で洗い、できれば冷湿布をします。

## 6-2. 全身のアレルギー反応（アナフィラキシー）

この症状は命にかかわります
- 呼吸困難
- チアノーゼ（唇や指が青くなる）
- 急激な意識低下
- 全身のじんましん
- 顔の腫れ

行動の順序
1. 傷病者を寝かせて脚を上げ、ショック体位をとります。
2. エピネフリン自己注射薬（エピペン）があれば、ただちに太ももへ注射します。
3. 呼吸がなければ心肺蘇生を始めます。
4. ただちに下山するか、救助を求めます。

> 刺されたあと症状が全身に広がるのは数分の出来事です。 ためらわず、エピペンと119を同時に用意します。
