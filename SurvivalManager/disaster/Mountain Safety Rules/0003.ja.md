# 7. けが別の応急手当

## 7-1. 捻挫 - 骨折との見分け
| | 状態 |
| --- | --- |
| 単純な捻挫 | 痛みはあるがある程度体重をかけられる |
| 骨折の疑い | 激しい痛み、変形、骨の部位を押すと痛む、まったく体重をかけられない |

手当て
1. ただちに止まり、けがをした部位に体重をかけないようにします。
2. 氷を直接当てず、布で包んで20分ほど冷やします。
3. 包帯やハンカチで適度に圧迫して腫れを抑えます。
4. けがをした部位を心臓より高く上げます。

移動が必要なとき
- すぐ動けないなら安全な場所で十分に休みます。
- 枝やトレッキングポールを松葉づえのように使います。
- 歩かざるを得ないときは、足首を包帯でしっかり巻き、体重は健康な足にかけます。
- 同行者がいれば肩を借りて支えてもらいます。

## 7-2. 骨折
症状：激しい痛み、腫れ、変形、骨の部位の圧痛、体重をかけられない

1. 動かしません。 とくに首や腰のけがが疑われるときは、絶対にむやみに動かしません。
2. 副木を当てます。
   - 長さは骨折部位の上下の関節を含むほど十分に。
   - 出血があれば直接圧迫で止血したあとに副木を当てます。
   - 枝や厚紙を両側に当て、衣類・包帯・ハンカチで固定します。
3. 骨が外に出ているときはきれいな布で覆って保護し、無理に押し戻しません。
4. 搬送は副木を固定したまま、慎重に行います。

## 7-3. 擦り傷
1. 流れるきれいな水で洗うか、消毒液で消毒します。
2. 異物が残っていれば慎重に取り除きます。
3. ガーゼやばんそうこうで覆います。

## 7-4. 裂傷（切れた傷）
1. きれいな布で強く押さえて止血します。
2. 止血できたらきれいな水で洗います。出血が激しいときは洗わず圧迫を続けます。
3. できれば消毒し、きれいな布で覆って感染を防ぎます。
4. 傷を心臓より高く上げます。

## 7-5. 頭部のけが
危険な兆候：意識喪失・激しい頭痛・吐き気と嘔吐・左右の瞳の大きさの違い

1. 首や脊椎のけがを伴うことがあるため、むやみに動かしません。
2. 意識があれば楽な姿勢で寝かせて休ませます。
3. 意識がなければ気道を確保し、呼吸がなければ心肺蘇生を行います。
4. 吐くときは横向きに寝かせて気道をふさがないようにします。
5. 頭と首を固定したまま、できるだけ安全に搬送します。
6. 症状が軽く見えても、必ず医療機関で精密検査を受けます。

## 7-6. 脱水・疲労困憊
症状：強い疲労感と無気力・頭痛、めまい、吐き気・青白い、または冷たく湿った皮膚・脈が速く弱い

1. ただちに活動をやめ、涼しく風の通る日陰に横になります。
2. 脚を心臓より高く上げ、血液が脳へ回るようにします。
3. ベルト・ボタン・襟元をゆるめて呼吸を楽にします。
4. 意識があれば塩水や非常食の塩を少しずつとります。意識がなければ何も口に入れません。
5. 暑い日は濡れたタオルで体をふいて体温を下げ、寒い日は衣類やビニールで包んで体温を保ちます。
6. 十分に休んで回復を確かめ、回復したらゆっくり下山します。

予防
- 体力の30%は常に残します。
- 少しずつ何度も水を飲み、非常食をとります。
- アルコールは疲労困憊を早く招き、その状態での飲酒は低体温症の危険を急激に高めます。

## 7-7. 呼吸困難
症状：呼吸が速く浅い・チアノーゼ

1. 楽な姿勢で座らせるか、上体を少し起こして寝かせます。
2. ボタンやベルトなど締めつけるものをすべてゆるめます。
3. 頭を後ろへ倒し、あごを上げて気道を確保します。
4. 異物による気道閉塞が疑われるときはハイムリック法を行います。
   - 傷病者の後ろに立ち、両手をへそと胸骨下端のあいだに置いて強く上方へ突き上げます。
5. 呼吸がなければ心肺蘇生を意識が戻るまで繰り返します。
   - 胸骨圧迫：胸の中央（胸骨の下半分）に両手を重ね、毎分100〜120回、深さ5〜6cm
   - 人工呼吸：胸骨圧迫30回のあと人工呼吸2回（30：2）。人工呼吸が難しければ胸骨圧迫のみでもかまいません。

## 7-8. 急な胸の痛み（心血管系）
症状：胸が張り裂けるような痛み・胸を押しつぶすような痛み

1. 楽な姿勢で座らせるか寝かせて安静にします。
2. 締めつける衣類をすべてゆるめます。
3. 深くゆっくり呼吸させます。
4. 処方された血管拡張薬（ニトログリセリンなど）を持っていれば服用させます。
5. 症状が改善しなければただちに下山するか救助を求めます。
6. 意識を失ったら気道を確保し、呼吸がなければ心肺蘇生を行います。

## 7-9. 低体温症
症状：体温35℃以下・激しい寒気と震え・動作が鈍くなる・言葉が不明瞭になる・意識低下

1. 濡れた服をただちに脱がせ、乾いた服・毛布・ビニールで包みます。
2. 風と雨を避けられる場所へ移します。
3. 体温の回復を助けます。
   - わきの下、首、股の付け根（大血管のある部位） に手を当てて熱を伝えます。
   - 複数なら同行者と密着して体温を分け合います。
   - 意識があれば温かい飲み物を少しずつ飲ませます。
4. 強くこすったり摩擦を加えたりしません。 血管が広がって体温がかえって速く下がることがあります。
5. 意識がなければ気道を確保し、呼吸がなければ心肺蘇生を行います。

> 震えが弱まる、止まるのは回復ではなく悪化のしるしです。 加温中に嘔吐・下痢・心停止が起こりうるため、48時間は経過を見ます。

## 7-10. 凍傷と塹壕足
- 凍傷：足、手、露出した顔がとくに弱いです。複数なら互いの顔をこまめに確認し、一人なら定期的に手袋で鼻と顔の下半分を覆います。
  - 炎の近くで溶かそうとしてはいけません。 37〜42℃の水に溶けるまで浸し、水気をふいて体温で温めます。
- 塹壕足（浸水足）：氷点近くの湿った環境に数時間〜数日さらされると神経と筋肉が傷み、重ければ切断に至ります。最良の予防は足を乾かしておくこと - 防水袋に替えの靴下を入れて持ち歩き、毎日足を洗って乾いた靴下にはき替えます。
