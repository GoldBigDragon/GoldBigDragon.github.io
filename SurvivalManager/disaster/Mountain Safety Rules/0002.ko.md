# 4. 뱀에게 물렸을 때

## 4-1. 독사인지 확인
- 머리가 삼각형이고 물린 자리 앞쪽에 두 개의 이빨 자국이 있으면 독사(살무사)일 가능성이 높습니다.
- 독이 없는 뱀에게 물리면 여러 줄의 작은 찰과상이 생깁니다.

## 4-2. 행동 순서
1. 즉시 뱀에서 떨어집니다. 잡으려 하거나 다시 자극하지 않습니다.
2. 환자를 안정시켜 움직임을 최소화합니다. 흥분하거나 움직이면 혈액순환이 빨라져 독이 더 빠르게 퍼집니다.
3. 팔찌, 시계 등 장신구를 제거합니다. 부어오르면 혈액순환을 막습니다.
4. 물린 부위를 깨끗한 물로 씻습니다.
5. 물린 부위 10cm 위쪽에 거즈를 덧대고, 손가락 하나가 들어갈 정도로 가볍게 붕대를 감습니다.
   - 너무 세게 묶으면 혈액순환이 차단되어 피부가 괴사합니다.
6. 물린 부위를 심장보다 낮게 둡니다. 팔이면 팔을 아래로, 다리면 누운 자세로.
7. 구토·복통·의식 저하가 올 수 있으므로 옆으로 눕혀 구토에 대비합니다.

## 4-3. 절대 하지 말 것

| 잘못된 처치 | 이유 |
| --- | --- |
| 상처를 칼로 절개 | 근육·혈관·신경을 손상시키고 2차 감염 위험이 커집니다 |
| 입으로 독을 빨아내기 | 효과가 없고, 처치자에게도 위험합니다 |
| 물린 부위를 세게 묶기 | 부어오르면 피부가 괴사하고, 묶은 천이 살 속으로 파고듭니다 |
| 얼음을 직접 대기 | 독소를 없애지 못하고 동상·조직괴사 위험이 높습니다 |
| 담뱃재·된장 바르기 | 염증을 유발합니다 |
| 음식·음료 주기 | 특히 술은 혈액순환을 촉진해 독이 빨리 퍼집니다 |
| 돼지비계로 문지르기 | 효과가 없고 감염 위험이 높습니다 |

## 4-4. 통신이 안 되는 경우
- 해독제를 보유한 가까운 의료기관으로의 이송이 최우선입니다.
- 나뭇가지와 의류로 들것을 만들어 환자의 움직임을 최대한 줄입니다.
- 걸어야 한다면 최대한 천천히, 일정한 속도로 이동합니다.

# 5. 멧돼지를 만났을 때

## 5-1. 멧돼지를 알아 두기
- 시력은 나쁘지만 후각과 청각이 매우 예민합니다.
- 자극을 받으면 방향 감각을 잃고 앞으로 직진 질주합니다.
- 등을 보이고 달아나면 사냥감으로 인식해 쫓아옵니다.
- 목이 짧아 위를 잘 보지 못하고, 오르막길에 약합니다.

## 5-2. 아직 나를 인지하지 못했을 때
- 조용히 뒷걸음질해 안전한 곳으로 피합니다.
- 바람을 등지고 있으면 냄새를 맡고 다가옵니다. 바람 방향에 주의합니다.

## 5-3. 마주쳤을 때
1. 소리를 지르거나 갑작스레 움직이지 않습니다.
2. 침착하게 멈춰 눈을 마주친 채 동태를 살핍니다.
3. 등을 절대 보이지 말고, 마주 본 채 아주 천천히 뒤로 물러납니다.
4. 가까운 나무나 바위 뒤, 높은 곳으로 피합니다. 오르막에 약하고 위를 잘 보지 못합니다.
5. 공격 위험을 느끼면 가방이나 손에 든 물건으로 몸을 보호합니다.

## 5-4. 공격해 올 때
- 멧돼지는 사람보다 훨씬 빠릅니다. 등을 보이며 달아나지 않습니다.
- 나무 위나 바위 위 등 최대한 높은 곳으로 올라갑니다.
- 큰 나무를 사이에 두고 멧돼지의 움직임에 맞춰 이동하는 것도 좋습니다.
- 배낭과 외투를 방어막으로 씁니다.

## 5-5. 절대 하지 말 것
- 돌을 던지거나 위협하기
- 큰 소리를 내거나 손을 흔들기
- 무리하게 접근하기
- 쫓으려 하기
- 등을 보이며 달아나기

# 6. 벌에 쏘였을 때

## 6-1. 행동 순서
1. 벌침이 보이면 신용카드나 얇은 도구로 살살 긁어내 제거합니다. 억지로 뽑으려 하지 않습니다.
2. 제거 후 환부를 절대 문지르지 않습니다. 독이 더 넓게 퍼집니다.
3. 차가운 물로 씻고, 가능하면 냉찜질합니다.

## 6-2. 전신 알레르기 반응(아나필락시스)

이런 증상이면 생명이 위험합니다
- 호흡곤란
- 청색증 (입술·손가락이 파랗게 변함)
- 급격한 의식 저하
- 전신 두드러기
- 얼굴 부종

행동 순서
1. 환자를 눕히고 다리를 올려 쇼크 자세를 만듭니다.
2. 에피네프린 자가주사기(에피펜)가 있으면 즉시 허벅지에 주사합니다.
3. 호흡이 없으면 심폐소생술을 시작합니다.
4. 즉시 하산하거나 구조를 요청합니다.

> 벌에 쏘인 뒤 증상이 전신으로 퍼지는 것은 몇 분 안에 일어납니다. 망설이지 말고 에피펜과 119를 동시에 준비합니다.
