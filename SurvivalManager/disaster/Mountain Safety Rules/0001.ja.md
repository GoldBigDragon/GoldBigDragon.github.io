# 1. 登山の安全の心得

## 1-1. 山に行く前に
- 天気、登山コース、歩く距離をあらかじめ確かめます。
- 入山規制や登山道の閉鎖がないか確かめます。
- 足に合い、通気性と防水性のよい登山靴をはきます。
- 登山計画（出発・到着の予定時刻、コース）を家族や知人に伝えます。
- 一人では行かず、最低2人以上で行きます。

ザックに入れるもの
- 懐中電灯と乾電池、雨具
- 携帯電話とモバイルバッテリー
- 救急薬品
- 非常食 - 塩、チョコレート、ジャーキー、あめなど熱量の高いもの
- 水筒、コンパス、地図

荷づくり
- 30kg以上は背負いません。
- 軽くてかさばるものは下、重いものは上に入れます。
- 手には何も持ちません。 すべてザックに入れます。

## 1-2. 山では
- 朝早く出発し、日没の1〜2時間前に終えます。
- 1日8時間を超えず、体力の30%は必ず残します。
- いちばん体力の弱い人に合わせて速度を決めます。
- 最初は15分歩いて5分休憩、慣れたら1時間歩いて10分を規則的に繰り返します。
- 一度にたくさん食べず、少しずつ何度もとります。
- 飲酒後の登山は絶対に禁止です。 低体温症の危険が急に高まります。
- 指定された登山道だけを歩きます。
- 登山道の消防位置板の固有番号をそのつど確かめ、覚えておきます。遭難時に正確な位置を伝えられます。
- 歩きながら携帯電話を見たり写真を撮ったりしません。
- 指定の野営場・避難小屋以外では炊事と野営をしません。

# 2. 道に迷ったら

## 2-1. その場で止まる
> パニックのまま動けば、より深い山中へ入ってしまいます。落ち着くことが最優先です。

- 来た道をはっきり覚えているなら引き返します。
- 確信がなければ動きません。
- 道を間違えたら、わかる場所まで戻って確かめ直します。

## 2-2. 位置を把握する
- 周囲の地形（峰、谷、尾根の向き）を読みます。
- コンパスがあれば方位を確かめ、地図と照らし合わせます。
- 登山道の標識や道標を探します。

## 2-3. 尾根へ上がる
> 谷は避けて尾根へ。 尾根は見通しがよく方向をつかみやすく、谷は危険で迷いやすいのです。

## 2-4. 119へ通報する（通信できる場合）
- 現在の位置をできるだけ詳しく伝えます。
- 転落・骨折・遭難など事故の種類を説明します。
- 通報後はうずくまって体温を保ちながら待ちます。

| 伝えること | 例 |
| --- | --- |
| 事故の場所 | 「○○山 ○○コース、消防位置板 番号○○○」 |
| 何があったか | 「ヘビにかまれました／転落して骨折したようです」 |
| けが人の状態 | 「意識はあり、右足首の骨折が疑われます」 |
| 通報者の名前・連絡先 | 本人の名前と携帯番号 |
| けが人の数 | 「2人のうち1人がけがをしました」 |
| 応急手当の状況 | 「止血中です／副木を当てました」 |

## 2-5. 通信できない場合
- とどまって待つなら：体温維持が最優先です。上着をすべて重ね、手袋と帽子を着けてうずくまります。
- 救助信号を送るなら：高い場所（尾根、峰の近く） で大声を出すか、明るい色の服・反射板を使います。
- 自力で下るなら：水は下へ流れるので、谷筋をたどれば山のふもとへ出られます。ただし暗いときや豪雨のときは谷筋の移動を避けます。

## 2-6. 絶対にしないこと
- 暗闇や霧の中で無理に下山すること
- 方向に確信がないまま歩き続けること
- 体力を使い切ること（30%は残します）

# 3. ビバークを決めたら

## 3-1. 場所選び
- まず土砂崩れ・落石の危険を確かめます。
- 風を防げる岩のそば、尾根の下側、傾斜のゆるい場所を選びます。
- 谷底、水がたまる低い場所、落雷の危険がある大木の下は避けます。
- 夜のあいだの集中豪雨で水が急に増えることがあります。 谷底や水際にテントを張りません。
- 水が押し寄せたら荷物に未練を残さず、ただちに避難します。

## 3-2. 体温を保つ
- 持ってきた上着をすべて重ね着し、手袋と帽子を着けます。
- ビニール袋や雨具で雨と風を防ぎます。
- ザック、着替え、ビニール袋、落ち葉で地面の冷気を遮ります。
- 複数なら互いに密着して体温を分け合います。

## 3-3. 食料と水
- 非常食は少量ずつ分けて食べます。
- 水は流れる谷の水を使い、飲めなければ露と雨水を集めます。
- アルコールは絶対に飲みません。 血管を広げ、体温をより速く奪います。

## 3-4. 救助信号をつくる
- 明るい色の服や反射素材を枝に結んで目印にします。
- ホイッスルや大声で定期的に信号を送ります。
- 夜間は懐中電灯でSOS（··· −−− ···） を繰り返します。
- 広場があれば石や枝でSOSを大きく描きます。
