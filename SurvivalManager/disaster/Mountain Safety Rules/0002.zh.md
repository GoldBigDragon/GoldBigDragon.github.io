# 4. 被蛇咬伤时

## 4-1. 判断是否毒蛇
- 头部呈三角形，且咬痕前方有两个牙印，很可能是毒蛇（蝮蛇）。
- 被无毒蛇咬伤会留下数排细小的擦伤。

## 4-2. 行动顺序
1. 立即远离蛇。 不要试图捕捉或再次刺激它。
2. 让伤者保持镇静，尽量减少活动。 激动或活动会加快血液循环，毒液扩散更快。
3. 取下手镯、手表等饰品。 一旦肿胀，它们会阻断血流。
4. 用清水冲洗咬伤部位。
5. 在咬伤部位上方10厘米处垫上纱布，松松地缠上绷带，以能插入一根手指为度。
   - 绑得过紧会阻断血液循环，导致皮肤坏死。
6. 让咬伤部位低于心脏。 手臂被咬就自然下垂，腿部被咬就采取仰卧姿势。
7. 可能出现呕吐、腹痛、意识下降，请让伤者侧卧以防呕吐物堵塞气道。

## 4-3. 绝对不要做的事

| 错误处置 | 原因 |
| --- | --- |
| 用刀切开伤口 | 损伤肌肉、血管、神经，并增加二次感染风险 |
| 用嘴吸出毒液 | 没有效果，对施救者也危险 |
| 用力绑紧咬伤部位 | 肿胀后皮肤会坏死，绑带会嵌入皮肉 |
| 直接敷冰 | 无法灭活毒素，且有冻伤和组织坏死风险 |
| 涂烟灰、大酱 | 会引发炎症 |
| 给食物或饮料 | 尤其是酒，会促进血液循环加快毒液扩散 |
| 用猪油擦拭 | 没有效果，感染风险高 |

## 4-4. 没有信号时
- 尽快送往备有抗蛇毒血清的最近医疗机构是第一要务。
- 用树枝和衣物做成担架，最大限度减少伤者活动。
- 必须步行时，要尽可能缓慢、匀速移动。

# 5. 遇到野猪时

## 5-1. 了解野猪
- 视力差，但嗅觉和听觉极为敏锐。
- 受到刺激后会失去方向感、直线猛冲。
- 背对它逃跑，它会当成猎物追上来。
- 脖子短，看不清上方，不擅长上坡。

## 5-2. 它还没发现你时
- 悄悄后退，避到安全处。
- 背风而立时，它会闻到气味靠近。 请注意风向。

## 5-3. 正面相遇时
1. 不要喊叫，也不要突然动作。
2. 冷静地停下，与它对视，观察动向。
3. 绝对不要背对它，面对着它极缓慢地后退拉开距离。
4. 躲到附近树后、岩石后或高处。它不擅上坡，也看不清上方。
5. 感到有被攻击的危险时，用背包或手中物品护住身体。

## 5-4. 它发起攻击时
- 野猪比人快得多，绝对不要背对它逃跑。
- 尽可能爬到树上、岩石上等高处。
- 以大树为屏障，随它的动作绕行也很有效。
- 把背包和外套当作盾牌使用。

## 5-5. 绝对不要做的事
- 向它投石或威胁
- 大声叫喊或挥手
- 勉强靠近
- 试图驱赶
- 背对它逃跑

# 6. 被蜂类蜇伤时

## 6-1. 行动顺序
1. 若能看到毒针，用信用卡或薄片轻轻刮出。不要硬拔。
2. 取出后绝对不要揉搓伤处。 会让毒液扩散更广。
3. 用冷水冲洗，条件允许时冷敷。

## 6-2. 全身过敏反应（过敏性休克）

出现这些症状就有生命危险
- 呼吸困难
- 紫绀（唇和手指发青）
- 意识急剧下降
- 全身荨麻疹
- 面部肿胀

行动顺序
1. 让伤者平卧并抬高双腿，摆成抗休克体位。
2. 若携带肾上腺素自动注射笔（EpiPen），立即注射到大腿。
3. 若无呼吸，立即开始心肺复苏。
4. 立即下山或请求救援。

> 被蜇后症状扩散到全身只需几分钟。 不要犹豫，同时准备好注射笔和拨打119。
