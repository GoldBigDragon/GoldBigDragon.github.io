# 7. 各类伤情的急救

## 7-1. 扭伤 - 与骨折的区分
| | 状态 |
| --- | --- |
| 单纯扭伤 | 有疼痛，但还能承受一定体重 |
| 疑似骨折 | 剧痛、畸形、按压骨骼部位有明显痛感、完全无法承重 |

处置
1. 立即停止活动，不要让受伤部位承重。
2. 不要直接敷冰，用布包住冷敷约20分钟。
3. 用绷带或手帕适度加压以减轻肿胀。
4. 把受伤部位抬到高于心脏的位置。

必须移动时
- 无法立刻移动时，要在安全处充分休息。
- 把树枝或登山杖当作拐杖使用。
- 不得不行走时，把脚踝用绷带扎紧，把体重尽量压在健侧脚上。
- 有同行者时借其肩膀搀扶。

## 7-2. 骨折
症状：剧痛、肿胀、畸形、骨骼部位压痛、无法承重

1. 不要移动。 尤其怀疑颈部或腰部受伤时绝对不可随意搬动。
2. 上夹板。
   - 长度要足以覆盖骨折部位上下的关节。
   - 有出血时先直接压迫止血，然后再上夹板。
   - 把树枝或厚纸板贴在两侧，用衣物、绷带、手帕固定。
3. 骨头外露时用干净布覆盖保护，不要硬推回去。
4. 搬运时要保持夹板固定，小心搬动。

## 7-3. 擦伤
1. 用流动的清水冲洗，或用消毒液消毒。
2. 若有异物残留，要小心清除。
3. 用纱布或创可贴覆盖。

## 7-4. 撕裂伤
1. 用干净的布用力按压止血。
2. 止血后用清水冲洗。出血严重时不要冲洗，持续加压。
3. 条件允许时消毒后用干净布覆盖，防止感染。
4. 把伤处抬到高于心脏的位置。

## 7-5. 头部损伤
危险信号：意识丧失 · 剧烈头痛 · 恶心呕吐 · 两侧瞳孔大小不等

1. 可能合并颈部或脊椎损伤，不要随意搬动。
2. 意识清醒时让其舒适平卧休息。
3. 意识不清时开放气道，若无呼吸立即心肺复苏。
4. 呕吐时让其侧卧，防止气道堵塞。
5. 固定头颈部，尽可能安全地搬运。
6. 即使症状看起来轻微，也必须到医疗机构做详细检查。

## 7-6. 力竭
症状：极度疲劳与乏力 · 头痛、头晕、恶心 · 面色苍白或皮肤湿冷 · 脉搏快而弱

1. 立即停止活动，在凉爽通风的阴凉处平卧。
2. 把双腿抬高于心脏，让血液顺畅供应大脑。
3. 解松腰带、纽扣、领口，便于呼吸。
4. 意识清醒时少量摄取淡盐水或应急食品中的盐。意识不清时不要喂任何东西。
5. 天热时用湿毛巾擦身降温，天冷时用衣物或塑料布包裹保温。
6. 充分休息后确认恢复情况，恢复后放慢速度下山。

预防
- 始终保留30%的体力。
- 少量多次喝水并摄取应急食品。
- 酒精会迅速引发力竭，在力竭状态下饮酒会急剧提高失温风险。

## 7-7. 呼吸困难
症状：呼吸急促而浅 · 紫绀

1. 让其以舒适姿势坐下，或略微抬高上身平卧。
2. 解开所有束紧的纽扣、腰带等。
3. 头后仰、抬起下颌以开放气道。
4. 怀疑异物堵塞气道时，实施海姆立克急救法。
   - 站在伤者身后，双手置于肚脐与胸骨下端之间，用力向上冲击。
5. 若无呼吸，反复进行心肺复苏直至恢复意识。
   - 胸外按压：双手交叠置于胸部中央（胸骨下半部），每分钟100～120次，深度5～6厘米
   - 人工呼吸：每按压30次后做2次人工呼吸（30∶2）。难以实施人工呼吸时，只做胸外按压也可以。

## 7-8. 急性胸痛（心血管相关）
症状：胸部似要炸裂的疼痛 · 胸部被压迫的疼痛

1. 让其以舒适姿势坐下或平卧，保持安静。
2. 解开所有束紧的衣物。
3. 让其深而缓慢地呼吸。
4. 若随身携带医生处方的血管扩张药（硝酸甘油等），让其服用。
5. 症状不见好转时立即下山或请求救援。
6. 失去意识时开放气道，若无呼吸立即心肺复苏。

## 7-9. 失温症
症状：体温降至35℃以下 · 严重发冷与颤抖 · 动作迟钝 · 言语含糊 · 意识下降

1. 立即脱掉湿衣，用干衣、毛毯、塑料布包裹。
2. 转移到能避风雨的场所。
3. 帮助恢复体温。
   - 把手贴在腋下、颈部、腹股沟（大血管部位）传导热量。
   - 多人时与同行者紧靠分享体温。
   - 意识清醒时让其少量饮用温热饮品。
4. 不要剧烈揉搓或摩擦。 血管扩张反而可能让体温下降更快。
5. 意识不清时开放气道，若无呼吸立即心肺复苏。

> 颤抖减轻或停止不是好转，而是恶化的信号。 复温过程中可能出现呕吐、腹泻甚至心脏停搏，因此要观察48小时。

## 7-10. 冻伤与战壕足
- 冻伤：足部、手部和裸露的面部最易受伤。多人时要经常互相检查面部，独行时要定期用手套盖住鼻子和下半面部。
  - 不要靠近火焰解冻。 在37～42℃的水中浸泡至解冻，擦干后用体温保暖。
- 战壕足（浸泡足）：在接近冰点的潮湿环境中暴露数小时至数日会损伤神经和肌肉，严重时需要截肢。最好的预防是保持双脚干燥 - 在防水袋里带备用袜子，每天洗脚并换上干袜。
