# 不同水深意味着什么

| 水深 | 会发生什么 |
| --- | --- |
| 15厘米（脚踝） | 水流一急，成年人也会被冲倒、无法移动 |
| 30厘米（小腿） | 成年人爬不上地下楼梯／轿车会浮起 |
| 50厘米（膝盖） | 行走极其困难，一个人推不开门 |
| 轮胎高度的三分之二 | 汽车发动机能继续运转的极限 |

> 雨水一旦进入地下空间，5到10分钟就会完全被淹。没有犹豫的时间。

# 暴雨预报发布后先做什么

## 1. 低洼与易涝区居民
- 随时关注气象信息并做好撤离准备。提前撤离时要先切断电源和燃气再出门。
- 商铺要把放在街边的招牌等电气设施收进室内。
- 村居管理人员要通过广播和应急联络网劝阻外出，并告知避难场所。

## 2. 地下空间的居住者与使用者
- 提前准备能剪断防盗窗的切割工具。
- 为应对无法逃出的情况，准备救生衣、救生圈、大块泡沫板等漂浮物。
- 熟悉常用地下车站、地下车库的紧急出口位置和疏散路线。

## 3. 住宅小区管理人员
- 配备挡水板、沙袋和抽水泵，并按出入口各指定一名安装责任人。
- 预计进水时通报避难地点，并说明车辆只能在降雨前转移。
- 公布挡水板安装时间，并告知安装后无法再移车。
- 对独居老人、残障人士等提前告知撤离信息，并通过对讲机、电话经常确认。

## 4. 驾车人
- 车内常备逃生破窗锤。
- 避免停在可能进水的地下车库，把停在河边、海边、低洼处的车转移。
- 发布撤离劝告时移走河滩停车场的车辆，并在车上留下联系电话。

# 不得不通过积水路段时

- 原则是不要靠近。 浑水看不出深度，也看不见水底尖锐或沉重的物体，夜间更危险。
- 水流过来时，立即撤到附近建筑二层以上或高处。积水通常2到3小时后退去，确认安全后再移动。
- 万不得已要步行时：
  - 步子放慢放稳，扶着建筑外墙走，不要走路中央。
  - 用长棍探路，确认有无窨井和障碍物。
  - 避开水流湍急或形成漩涡的位置，那里的井盖可能已经被冲开。
  - 井盖处冒气泡，意味着井盖可能突然被顶开，请立即远离。
  - 与信号灯、路灯、立式招牌等室外电气设施保持2到3米以上距离。
  - 电线、电线杆、金属结构、管道、铁丝网都有触电风险。

# 从地下空间逃生

## 1. 立即撤离
- 水正在涌入时，先把门打开。
- 地面只要开始积水，或下水道返流，就立刻出去。
- 外部水深达到膝盖以上（50厘米）时，一个人推不开门。先断电，再多人合力推开。
- 楼梯上有小腿高（30厘米）的水流，成年人就难以上行；即使只到脚踝，儿童和老人也上不去。
- 移动时要扶住栏杆，并且不要乘电梯，随时可能停电。

## 2. 门走不通时
- 用切割工具剪断防盗窗逃生。
- 在地下车站、地下商场，转向可绕行的紧急通道和出口。
- 实在无法逃出时，先切断电源和燃气，向119或外界求救，并借助救生衣、救生圈等漂浮物等待救援。

## 3. 着装
- 运动鞋最合适。 皮鞋、高跟鞋、拖鞋容易打滑，雨靴进水后反而更危险。
- 没有合适鞋子时，就赤脚撤离。

## 4. 地下停车场
- 只要开始积水，就弃车，只带人出去。
- 水沿坡道涌入后，水压会让车辆无法移动。
- 绝不能为查看车辆而重新进入地下车库。

# 车辆被淹时

1. 在水位淹到轮胎三分之二之前，把车开到安全地点。
2. 无法移动时，趁发动机还没熄火打开车窗或天窗，留出逃生口。
3. 水压使车门打不开时，用座椅头枕下方的金属杆敲碎车窗。
4. 无法敲碎玻璃时，等到车内外水位差小于30厘米，车门一能推开就立即逃出。
5. 逃出后转移到高于水面的位置；实在没有去处，就爬上车顶，拨打119等待救援。

## 行车注意
- 通过积水路段要用低挡位快速通过。
- 弃车撤离时，把钥匙放在显眼位置，车门不上锁。
- 绝不驶入已开始积水的下穿隧道。 已经进入的，请弃车迅速跑出。
- 进出下穿隧道时打开双闪灯，向后车示警。
- 桥下有急流时，水压可能把车推入河中，绝对不要驶入。
- 被急流困住时，打开背离水流一侧的车门或敲碎该侧车窗逃生。迎水一侧因水流冲击，车门打不开。

# 退水之后

- 退去的水中常有油污和动物尸体，请远离水体。
- 自来水和储存的饮用水要确认未受污染后再用；被水浸泡的食品和食材有食物中毒风险，不要使用。
- 被淹住宅要确认燃气和电源总闸已断开，并经韩国煤气安全公社（1544-4500）、韩国电气安全公社（1588-7500）或专业人员检查后方可使用。
- 可能存在燃气泄漏，请开窗充分通风，通风前不要使用火柴或打火机。
- 被淹地下室要缓慢抽排，一天约抽三分之一。 一次抽干会导致墙体坍塌、地面顶翘。
- 受损设施先拍照，再向市、郡、区政府或行政福利中心申报。
- 清理时穿戴雨靴、橡胶手套和护目镜，作业后用肥皂洗手。
