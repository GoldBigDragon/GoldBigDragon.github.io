# 水位ごとの危険度

| 水位 | 起きること |
| --- | --- |
| 15cm（足首） | 流れが速ければ大人でも転倒し、動けなくなります |
| 30cm（すね） | 地下階段を大人が上がれなくなる／乗用車が浮きます |
| 50cm（ひざ） | 歩行が困難になり、1人ではドアを開けられません |
| タイヤの3分の2 | 車のエンジンが動き続けられる限界です |

> 地下空間は、雨水が入り始めてから5〜10分で浸水し終わります。 ためらう時間はありません。

# 大雨の予報が出たら

## 1. 低地・常習浸水地域の住民
- 気象情報をこまめに確認し、避難の準備をします。事前に避難するときは電気とガスを止めてから出ます。
- 店舗では、路上に出した看板などの電気設備を屋内へ入れます。
- 町内の管理者は、放送や緊急連絡網で外出を控えるよう呼びかけ、避難場所を案内します。

## 2. 地下空間の居住者・利用者
- 面格子（防犯窓）を切断できる工具をあらかじめ用意します。
- 脱出できない場合に備え、救命胴衣・浮き輪・大型の発泡スチロールなど浮く物を用意します。
- 地下駅や地下駐車場の非常口の位置と避難経路を普段から把握しておきます。

## 3. 集合住宅の管理者
- 止水板、土のう、ポンプを備え、入口ごとに1名ずつ設置担当者を決めておきます。
- 浸水が予想される場合は避難場所を案内し、車の移動は大雨の前にしかできないことを周知します。
- 止水板の設置時刻を知らせ、設置後は車を動かせないことも伝えます。
- 独居高齢者や障害のある方には避難情報を事前に伝え、インターホンや電話でこまめに確認します。

## 4. 車を使う人
- 車載用の脱出ハンマーを備えます。
- 浸水が予想される地下駐車を避け、川べり・海辺・低地に止めた車を移します。
- 避難勧告が出たら河川敷駐車場の車を移動させ、車に連絡先を残しておきます。

# 冠水した道を通るとき

- 近づかないのが原則です。 濁った水では深さも、底の鋭い物や重い物も見えません。夜はさらに危険です。
- 水が流れてきたら、ただちに近くの建物の2階以上か高い場所へ避難します。水はふつう2〜3時間で引くので、安全を確かめてから動きます。
- やむを得ず歩くときは
  - ゆっくり安定した歩調で、道路の中央ではなく建物の外壁をつたって進みます。
  - 長い棒で前を突きながら、マンホールや障害物を確かめます。
  - 水が強く流れる場所や渦を巻く場所は、マンホールのふたが外れている可能性があるので避けます。
  - マンホールのふたから気泡が上がっていたら、ふたが急に開くおそれがあります。すぐに遠ざかってください。
  - 信号機・街灯・立て看板など屋外の電気設備からは2〜3m以上離れます。
  - 電線、電柱、金属構造物、パイプ、鉄条網はすべて感電の危険があります。

# 地下空間からの脱出

## 1. すぐに避難
- 水が入ってきていたら、まず出入口のドアを開けます。
- 床に少しでも水がたまるか、下水が逆流したらその瞬間に出ます。
- 外の水深がひざ以上（50cm）になると1人ではドアを開けられません。電気を止めてから、複数人で力を合わせて開けます。
- 階段にすねの高さ（30cm）の水が流れるだけで大人は上がりにくくなり、足首の高さでも子どもや高齢の方は上がれません。
- 移動のときは手すりをつかみ、停電に備えてエレベーターは使いません。

## 2. ドアから出られないとき
- 切断工具で面格子を切って脱出します。
- 地下駅や地下街では、迂回できる非常通路や出口へ移動します。
- どうしても脱出できないときは、電気とガスを止めてから119や外部に助けを求め、救命胴衣や浮き輪など浮く物につかまって救助を待ちます。

## 3. 服装
- 運動靴が最適です。革靴・ハイヒール・サンダルは滑り、長靴は中に水が入ってかえって危険です。
- 適当な靴がなければ、はだしで避難します。

## 4. 地下駐車場
- 少しでも水がたまり始めたら、車を置いて体だけ出ます。
- スロープを伝って水が入り始めると、水圧で車は動かせません。
- 車の確認のために地下駐車場へ戻ってはいけません。

# 車が水に浸かるとき

1. タイヤの3分の2が浸かる前に、車を安全な場所へ移します。
2. 移動できないときは、エンジンが止まる前に窓かサンルーフを開け、脱出口を確保します。
3. 水圧でドアが開かないときは、座席ヘッドレストの下の金属棒でガラスを割ります。
4. ガラスを割れなければ、車内外の水位差が30cm以下になるのを待ち、ドアが開いた瞬間に脱出します。
5. 脱出後は水より高い場所へ移動し、適当な場所がなければ車の屋根の上に上がって119に連絡し、待機します。

## 運転中の注意
- 冠水路は低いギアで一気に抜けます。
- 車を置いて避難するときは、キーを見えるところに置き、ドアは施錠しません。
- 冠水し始めたアンダーパスには絶対に入らないでください。 すでに入っていたら車を置いて外へ出ます。
- アンダーパスへの進入・脱出時はハザードランプをつけ、後続車に危険を伝えます。
- 急流のある橋は、水圧で車が川へ押し流されるおそれがあるため絶対に進入しません。
- 急流に取り残されたら、流れが来る側の反対のドアを開けるか、その窓を割って脱出します。流れが当たる側はドアが開きません。

# 水が引いたあと

- 引いていく水は油や動物の死骸などで汚れています。水から離れてください。
- 水道水や貯めていた飲料水は汚染の有無を確認してから使い、浸水した食品や食材は食中毒のおそれがあるため使いません。
- 浸水した住宅ではガスと電気のブレーカーが落ちているか確認し、韓国ガス安全公社（1544-4500）、韓国電気安全公社（1588-7500）または専門家の点検を受けてから使用します。
- ガス漏れのおそれがあるので、窓を開けて十分に換気し、換気前はマッチやライターを使いません。
- 浸水した地下室は1日に3分の1程度ずつゆっくり排水します。一気に抜くと壁が崩れ、床が浮き上がります。
- 破損した施設は写真を撮ってから、自治体の窓口へ届け出ます。
- 片づけのときは長靴・ゴム手袋・保護めがねを着け、作業後は石けんで手を洗います。
