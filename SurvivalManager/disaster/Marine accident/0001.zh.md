# 发生事故时 - 行动顺序

1. 通知他人 - 大声呼喊或按下紧急按钮告知船员，并拨打119。
2. 穿好救生衣 - 救生衣放在座椅下方或船舱内。按船员指示操作。
3. 多穿几层薄衣 - 可以在水中保住体温。
4. 前往逃生通道 - 听从船员引导，注意不要被人流裹挟。
5. 登上救生艇或救生筏 - 按引导依次登艇。

> 弃船之后的首要死因不是溺水，而是失温。
> 不会游泳或需要等待救援时，请保持双臂抱腿、双膝收至胸前的"抱膝漂浮（Tuck Float）"姿势，减少热量和体力的流失。

# 不同情况的应对

## 1. 船体倾斜或进水时
- 柜子、桌子会滑动撞人。 请远离大件家具再移动。
- 门打不开时，用消防斧敲击窗户边缘破窗逃生。边缘比中间更容易击破。
- 发生火灾或有人受伤时，要告知船员。

## 2. 必须跳海时
1. 双腿伸直
2. 一只手捂住口鼻
3. 尽量跳离船体远一些。

## 3. 船内起火时
1. 大喊"着火了！"并按下紧急按钮。
2. 用灭火器扑救初期火情，危险较大时立即撤离。
3. 捂住口鼻，按船员引导前往逃生通道。
4. 协助老弱者一同撤离。

# 救起失去意识的人时

## 1. 救起后立即处置
- 通知救生员或拨打119。
- 进行人工呼吸。 溺水的根本原因是缺氧，因此吹气供氧是第一位的。在救援途中于水中就应立即开始。
- 之后的处置与常规心肺复苏相同。

> 不要按压腹部或背部试图"控水"。
> 胃里的水和食物会反流堵住气道，呕吐物还可能进入肺部。更重要的是，人工呼吸每延迟一分，生还的可能性就少一分。

## 2. 恢复体温
1. 把伤者移到干燥温暖的地方。
2. 脱掉全部湿衣服，用热水袋或温水浸湿的毛巾温暖胸部。
3. 用毯子包裹包括头和颈部在内的全身。
   - 体温流失最快的部位：头部、颈部、胸部、腹股沟
4. 如果意识清醒，给予温热饮品补充水分。不要给酒。
5. 条件允许时，在睡袋内通过皮肤接触回温。

## 3. 体温下降的发展过程
| 阶段 | 身体的变化 |
| --- | --- |
| 初期 | 皮肤发凉，血液循环减弱，手脚最先变冷 |
| 发展 | 开始不自主颤抖，身体持续散热 |
| 恶化 | 身体内部开始变冷，为保护重要器官而进一步减少末梢血流 |
| 危险 | 颤抖减弱或停止，内脏器官开始受损 |
| 致命 | 大脑变冷，无法控制身体、失去意识。 若不立即正确处置将危及生命 |

> 颤抖停止不是好转，而是恶化的信号。

# 船舶安全守则

## 1. 乘客
- 不奔跑打闹，有序登船；上下楼梯时扶好扶手。
- 登船后前往指定舱室等位置，并认真听完广播提示。
- 熟悉逃生路线，确认救生衣的位置和穿法。
- 不要擅自操作机械设备。
- 不要要求超员乘船。
- 遵守船员和工作人员的注意事项和指示。
- 不饮酒，不做扰乱船内秩序的行为。
- 不损坏救生装备和船舶设施。
- 不携带或运输爆炸物、易燃液体、高压气体。

## 2. 渔船船员
- 穿好救生衣。
- 危急时毫不迟疑地按下SOS按钮请求救援。
- 发生火灾时用船内灭火器迅速扑救。
- 注意不要让手或衣物卷入起网机。
