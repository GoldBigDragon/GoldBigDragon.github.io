# 事故が起きたら - 行動の順序

1. 知らせる - 大声で叫ぶか非常ベルを押して乗務員に知らせ、119へ通報します。
2. 救命胴衣を着る - 座席の下や船室にあります。乗務員の指示にしたがいます。
3. 薄手の服を重ね着する - 水中での体温を守ってくれます。
4. 脱出路へ移動する - 乗務員の案内にしたがい、人波に押し流されないよう注意します。
5. 救命艇・救命いかだに乗る - 案内にしたがって順番に。

> 船から脱出したあとの死因の第1位は、おぼれることではなく低体温です。
> 泳げない場合や救助を待つ場合は、両腕で脚を抱え、ひざを胸まで引き寄せる「えび型浮き（タックフロート）」の姿勢をとり、熱と体力の消耗を抑えます。

# 状況別の行動

## 1. 船が傾く・浸水するとき
- キャビネットやテーブルが滑ってきて下敷きになることがあります。 大きな家具から離れて移動します。
- 戸が開かないときは非常用の斧で窓の端を割って脱出します。中央より端のほうが割れやすいです。
- 火災が起きたり、けが人がいたりする場合は乗務員に知らせます。

## 2. 海へ飛び込まなければならないとき
1. 脚をまっすぐ伸ばし
2. 片手で口と鼻をふさいで
3. 船からできるだけ遠くへ飛び込みます。

## 3. 船内で火が出たとき
1. 「火事だ！」と叫び、非常ベルを押します。
2. 消火器で初期消火を試みますが、危険が大きければただちに避難します。
3. 口と鼻をおおい、乗務員の案内にしたがって脱出路へ移動します。
4. 高齢者や体の不自由な方を助けて一緒に避難します。

# 意識のない人を救助したとき

## 1. 救助の直後
- 救助員か119へ通報します。
- 人工呼吸を行います。 水の事故は酸素不足が原因なので、息を吹き込むことが最優先です。救助しながら水中でもすぐに始めます。
- そのあとの手当ては通常の心肺蘇生と同じです。

> 腹や背中を押して水を吐かせようとしてはいけません。
> 胃の中の水や食べ物が逆流して気道をふさぎ、吐いたものが肺に入るおそれがあります。なにより、人工呼吸が遅れるぶんだけ助かる可能性が下がります。

## 2. 体温を戻す
1. 傷病者を乾いた暖かい場所へ移します。
2. 濡れた服をすべて脱がせ、湯たんぽや温かい湯に浸したタオルで胸のあたりを温めます。
3. 頭と首を含めた全身を毛布で包みます。
   - 体温が早く逃げる場所：頭、首、胸、股の付け根
4. 意識があれば温かい飲み物で水分を補います。酒は与えません。
5. できれば寝袋の中で肌を合わせて温めます。

## 3. 体温が下がるときの経過
| 段階 | 体に起きること |
| --- | --- |
| 初期 | 皮膚が冷たくなり血流が減って、手足から冷えていきます |
| 進行 | 無意識の震えが始まり、体から熱が逃げていきます |
| 悪化 | 体の内部が冷え始め、主要な臓器を守るため末梢の血流をさらに絞ります |
| 危険 | 震えが弱まる、または止まり、内臓に影響が出ます |
| 致命 | 脳が冷えて体を支えられなくなり、意識を失います。 即座に正しい手当てをしないと命を落とします |

> 震えが止まるのは回復ではなく、悪化のしるしです。

# 船舶の安全上の心得

## 1. 乗客
- 走ったりふざけたりせず秩序を守って乗船し、階段では手すりをつかみます。
- 乗船後は指定された客室などへ移動し、案内放送を最後まで聞きます。
- 避難経路を覚え、救命胴衣の位置と着け方を確認します。
- 機械や装備を勝手に操作しません。
- 定員を超える乗船を求めません。
- 船員や従事者の注意事項と指示にしたがいます。
- 飲酒など船内の秩序を乱す行為をしません。
- 人命救助用の装備や船の設備を壊しません。
- 爆発物、引火性の液体、高圧ガスを持ち込んだり運んだりしません。

## 2. 漁船員
- 救命胴衣を着用します。
- 危急時はためらわずSOSボタンを押して救助を求めます。
- 火災時は船内の消火器で速やかに消火します。
- 揚網機に手や服が巻き込まれないよう注意します。
