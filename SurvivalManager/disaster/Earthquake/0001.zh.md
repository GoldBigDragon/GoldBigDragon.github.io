# 晃动时 - 先保护身体

1. 护住头部、放低身体 - 钻到桌子下面，紧紧抓住桌腿。 没有桌子时，用书包、外套或坐垫护住头和脖子。
2. 尽量不要移动 - 走动或奔跑会摔倒，也容易被掉落物砸中。双手双膝着地，把身体放低。
3. 保持姿势直到晃动停止 - 之后再撤离。

> 在高层建筑里，不要在晃动中立刻往外跑。
> 高层建筑不会因地震轻易倒塌，而且几十秒的晃动中根本跑不出去。硬往外冲反而会摔倒、被掉落物砸到或与他人相撞，更加危险。只有在砖房、土房等抗震能力差的低层建筑中，才考虑立即向外撤离。

---

# 晃动停止后

1. 切断电和燃气，并打开房门确保出口。余震会让门框变形，门就打不开了。
2. 一定要穿鞋。 地上满是玻璃碎片。
3. 走楼梯迅速转移。绝对不要乘电梯。
   - 若人在电梯内，按下所有楼层按钮，在最先打开的楼层下电梯。
4. 到室外后用书包或双手护住头部，与建筑物保持距离，边观察边移动。
   - 会掉落的东西：瓦片、空调外机、玻璃碎片、招牌、砖块、花盆、石材外墙
5. 撤到操场、公园等开阔场地。不要使用车辆。
6. 避开断落的电线，以及与其接触的金属和积水。
7. 在避难场所要按照广播或政府通告的准确信息行动。

# 不同场所的应对

| 场所 | 行动 |
| --- | --- |
| 家中 | 躲到桌下护身 → 停止后切断电、燃气，开门外出 |
| 室外 | 用书包或手护头，远离建筑物，前往开阔地 |
| 电梯内 | 按下所有楼层按钮，在最先打开的楼层下电梯，改走楼梯 |
| 学校 | 钻到课桌下抓住桌腿 → 停止后有秩序地前往操场 |
| 商场、超市 | 避开货架掉落物，移向楼梯或立柱旁 → 停止后到室外 |
| 剧场、体育场 | 用书包等护住身体留在座位，按广播指示冷静撤离 |
| 地铁车厢 | 抓紧吊环或立柱防止摔倒 → 停止后听从指引 |
| 驾车时 | 打开危险报警灯缓慢减速，靠道路右侧停车，收听广播，把钥匙留在车上撤离 |
| 山区、海边 | 注意滑坡和崖体崩塌。海岸发布海啸警报时立即前往高处 |

# 被困时

- 敲击比呼喊更有效。 有节奏地敲打墙壁或管道，比喊叫省力得多。
- 有哨子就使用。捂住口部减少吸入粉尘。
- 用手机发送短信或共享GPS位置。注意节省电量。

# 平时的准备

## 1. 在家中留出安全空间
- 事先确定桌下等可以躲避的空间。
- 掌握窗玻璃附近、易倾倒家具旁等危险位置，平时不要靠近。
- 准备厚底室内鞋，避免被碎玻璃划伤。
- 小心管理炉具和危险物品。

## 2. 固定可能掉落的物品
- 固定家具和家电（书架、灯具、镜子、电视、电脑、冰箱），防止倾倒。
- 不要把电视、花瓶等易掉落的物品放在高处。
- 固定橱柜门，防止里面的东西散落。
- 在窗玻璃上贴防飞散膜。

## 3. 建筑维护
- 事先检查燃气和电路。
- 经常检查房屋和围墙，对危险部位进行维修。
- 发现裂缝要咨询专业人员，进行修补加固。

## 4. 家庭会议
- 让所有人都掌握切断燃气和电源的方法。
- 了解附近的开阔避难场所。
- 约定紧急时的集合地点和联络方式。
- 反复演练急救方法。

## 5. 应急物品
- 了解应急物品的存放位置和使用方法。
- 地震后容易起火，请准备灭火器并掌握用法。
- 准备撬棍，以防门框变形导致门打不开。
- 备齐头盔、手套、登山鞋、护目镜、口罩等防护装备。

# 老弱者与残障人士的应对

## 1. 视力不佳时
- 先通过广播或电视了解情况。
- 撤离时要一边确认地面的掉落物和障碍物一边慢慢移动，并主动向周围求助。
- 为防止次生灾害，请周围的人帮忙检查有明火的地方。

## 2. 行动不便或有肢体障碍时
- 不要独自行动，与邻居一起撤离。
- 使用轮椅或助行器时，锁住轮子并将身体前倾，用书、坐垫、枕头护住头和脖子。
- 无法移动时，在相对安全的地方等待救援。
- 若决定留在家中，请告知邻居或政府工作人员，避免被孤立。

## 3. 听力不佳时
- 通过电视字幕节目和手机获取信息。
- 若无法移动，用哨子等发出声响告知自己的位置。
- 告知周围自己有听力障碍，请他们引导至安全场所。
- 若有语言障碍，用纸笔等沟通工具了解情况。

## 4. 精神状态不稳定或有发育障碍时
- 不要慌张奔跑或冲到室外。
- 遵守与家人或帮助者事先约定的内容。
- 难以自行判断时，向周围的人求助。

# 与孩子在一起时

- 使用背带 - 婴幼儿撤离时无法使用婴儿车。平时备好背带，用背带抱住孩子，空出双手保护孩子和自己。
- 穿好鞋再抱起来 - 道路上满是玻璃碎片和瓦砾，即使孩子会走路也要抱着撤离。背孩子时要护住头部，无论抱还是背，都必须给孩子穿鞋。
- 紧紧牵住手 - 避免在混乱中走散。即使孩子懂得应对要领，也要一边说出该做什么一边一起行动。

# 地震之后

1. 确认情况后报警 - 确认家人是否受伤、房屋是否有危险。有伤者时与邻居协作进行急救并拨打119。
2. 判断能否回家 - 根据广播和政府信息判断。
3. 检查周边 - 确认住宅和办公场所的受损情况，安全存疑时要接受专业人员检查。打开衣柜或储物柜门时，里面的东西可能倾倒，请小心。
4. 防备余震 - 主震之后余震会持续。不要重新进入受损建筑。
5. 警惕次生灾害 - 可能随之发生海啸、大规模火灾、滑坡、停电、停水、燃气中断、化学物质与放射性泄漏以及传染病。
6. 回家后先通风 - 可能存在燃气泄漏，请先通风再使用明火或电源开关。
7. 核实信息 - 警惕没有根据的谣言，遵从电视、广播和政府发布的信息。
