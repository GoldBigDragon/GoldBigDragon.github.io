# 揺れている間 - まず体を守る

1. 頭を守って低く - テーブルの下に入り、テーブルの脚をしっかりつかみます。 テーブルがなければ、かばん・上着・座布団で頭と首を包みます。
2. 動きは最小限に - 歩いたり走ったりすると転倒したり落下物に当たったりします。手と膝を床につけ、姿勢を低くします。
3. 揺れが収まるまでその姿勢で - 避難はそのあとです。

> 高層建物では、揺れている最中に飛び出してはいけません。
> 高層建物は地震で簡単には倒れず、数十秒の揺れの間に外へ出ることもできません。無理に出ようとすると、転倒・落下物・人との衝突でかえって危険です。ただちに外へ出るのは、低層のれんが造りや土壁の家など、耐震性の低い建物の場合だけ考えます。

---

# 揺れが収まったら

1. 電気とガスを遮断し、戸を開けて出口を確保します。余震で戸枠がゆがむと戸が開かなくなります。
2. 必ず靴を履きます。 床にはガラスの破片が散っています。
3. 階段ですばやく移動します。エレベーターは絶対に使いません。
   - エレベーターの中なら、すべての階のボタンを押し、最初に開いた階で降ります。
4. 建物の外ではかばんや手で頭を守り、建物から距離を取って周囲を見ながら移動します。
   - 落ちてくるもの：屋根がわら、エアコン室外機、ガラスの破片、看板、れんが、植木鉢、外壁の石材
5. 運動場や公園などの広い場所へ避難します。車は使いません。
6. 切れた電線と、それに触れている金属や水たまりを避けます。
7. 避難場所ではラジオや行政の放送など、確かな情報にしたがって行動します。

# 場所別の行動要領

| 場所 | 行動 |
| --- | --- |
| 家の中 | テーブルの下で身を守る → 収まったら電気・ガスを止め、戸を開けて外へ |
| 屋外 | かばんや手で頭を守り、建物から離れて広い場所へ |
| エレベーター | すべての階のボタンを押し、最初に開いた階で降りて階段へ |
| 学校 | 机の下に入り脚をつかむ → 収まったら秩序を保って運動場へ |
| デパート・スーパー | 陳列棚の落下物を避け、階段や柱の近くへ → 収まったら外へ |
| 劇場・競技場 | かばんなどで身を守って座席にとどまり、案内にしたがって落ち着いて避難 |
| 電車の中 | つり革や手すりをつかんで転倒を防ぐ → 収まったら案内にしたがう |
| 運転中 | ハザードを点け徐々に減速して道路の右側に停車。ラジオを聞き、キーは挿したまま避難 |
| 山・海 | 土砂崩れや崖崩れに注意。海岸で津波警報が出たら高い場所へ |

# 閉じ込められたら

- 叫ぶより叩きます。 壁やパイプを規則的に叩くほうが、体力の消耗がはるかに少なくて済みます。
- ホイッスルがあれば使います。口をふさいでほこりの吸い込みを減らします。
- 携帯電話でメッセージを送るか、GPSの位置情報を送信します。電池は節約します。

# 日ごろの備え

## 1. 家の中に安全な空間をつくる
- テーブルの下など、避難できる場所をあらかじめ決めておきます。
- 窓ガラスの近くや倒れやすい家具のそばなど、危険な場所を把握して近づかないようにします。
- 割れたガラスでけがをしないよう、厚手の室内履きを用意します。
- ストーブや危険物は注意して管理します。

## 2. 落ちてくるものを固定する
- 家具と家電（本棚、照明、鏡、テレビ、パソコン、冷蔵庫）が倒れないよう固定します。
- テレビや花瓶など落ちやすい物を高い場所に置きません。
- 食器棚の扉を固定し、中身が飛び出さないようにします。
- 窓ガラスに飛散防止フィルムを貼ります。

## 3. 建物の管理
- ガスと電気をあらかじめ点検します。
- 建物と塀をこまめに点検し、危険な箇所は補修します。
- ひび割れを見つけたら専門家に相談し、補修・補強します。

## 4. 家族で話し合う
- ガスと電気を止める方法を全員が知っておきます。
- 近くの広い避難場所を把握しておきます。
- 非常時の集合場所と連絡方法を決めておきます。
- 応急手当の方法を繰り返し練習します。

## 5. 非常用品
- 非常用品の保管場所と使い方を知っておきます。
- 地震のあとは火災が起きやすいので、消火器を用意し使い方を覚えます。
- 戸枠がゆがんで戸が開かないときのために、バールがあると役に立ちます。
- ヘルメット、手袋、登山靴、保護めがね、マスクなどの保護具をそろえます。

# 高齢者・障がいのある方の行動要領

## 1. 目が見えにくい場合
- まずラジオやテレビで状況を把握します。
- 避難するときは床の落下物や障害物を確かめながらゆっくり動き、周囲に積極的に助けを求めます。
- 二次被害を防ぐため、火の気のある場所の確認を周りの人に頼みます。

## 2. 体の動きが不自由な場合
- 一人で行動せず、近所の人と一緒に避難します。
- 車いすや歩行器を使っている場合は、車輪をロックして体を前に倒し、本・座布団・枕で頭と首を守ります。
- 動けないときは、少しでも安全な場所で助けを待ちます。
- 自宅にとどまると決めたら、近所の人や役所の職員にそのことを伝え、孤立しないようにします。

## 3. 耳が聞こえにくい場合
- 字幕放送と携帯電話で情報を集めます。
- 動けなくなったら、ホイッスルなどで音を出して位置を知らせます。
- 周囲に聴覚障がいがあることを伝え、安全な場所へ誘導してもらいます。
- 言語障がいがある場合は、紙とペンなどの意思疎通の道具で状況を把握します。

## 4. 精神が不安定な場合・発達障がいがある場合
- あわてて走ったり外へ飛び出したりしません。
- 家族や支援する人とあらかじめ決めたことを守ります。
- 自分で判断しにくいときは周囲に助けを求めます。

# 子どもと一緒のとき

- 抱っこひもを使う - 乳幼児の避難にベビーカーは使えません。日ごろからおんぶひもを用意し、ひもで抱いて手を自由にし、赤ちゃんと自分の体を守ります。
- 靴を履かせて抱き上げる - ガラスの破片やがれきで道路が危険なので、歩ける子でも抱いて避難します。おんぶするときは頭を守り、抱いてもおんぶしても必ず靴を履かせます。
- 手をしっかりつなぐ - 混乱の中ではぐれないよう手をつなぎます。行動要領を知っている子でも、必要な行動を声に出して伝えながら一緒に動きます。

# 地震のあと

1. 状況を確認して通報 - 家族のけがと家の危険を確認します。けが人がいれば近所の人と協力して応急手当をし、119に通報します。
2. 帰宅の判断 - ラジオと行政の情報にしたがって判断します。
3. 周囲の確認 - 家庭や職場の被害を確認し、安全が疑わしければ専門家の確認を受けます。たんすや収納の扉を開けるときは中身が飛び出すことがあるので注意します。
4. 余震への備え - 本震のあと余震が続きます。傷んだ建物には入り直しません。
5. 二次被害に注意 - 津波、大規模火災、土砂崩れ、停電、断水、ガス供給停止、化学物質・放射能の漏えい、感染症が続いて起きることがあります。
6. 帰宅したらまず換気 - ガス漏れの可能性があるため、換気してから火や電気のスイッチを使います。
7. 正しい情報の確認 - 根拠のないうわさに注意し、テレビ・ラジオと行政の情報にしたがいます。
