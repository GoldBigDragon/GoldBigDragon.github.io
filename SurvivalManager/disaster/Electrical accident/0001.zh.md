# 触电事故

> 最重要的原则：徒手去碰仍带电的人，施救者也会触电。

1. 切断电源 - 拉下漏电断路器；能拔插头就先拔插头。平时就要知道配电箱的位置。
2. 用绝缘物分离 - 无法断电时，用干燥木棍、橡胶手套、塑料等不导电的物体把人从电源处推开。
3. 转移到安全处 - 移到没有电气设备和积水的地方。
4. 判断与急救 - 轻拍双肩确认反应；若无意识、无呼吸，拨打119并立即开始心肺复苏。
5. 烧伤处理 - 不要弄破水疱，用流动水冲洗冷却10分钟以上，再用干净布轻轻覆盖。

> 触电即使表面伤口很小，体内损伤和心律失常也可能延迟出现。即便恢复意识，也必须去医院检查。

# 电气火灾

> 向电气火灾泼水会导致触电并使火势蔓延，务必先切断电源。

1. 切断电源 - 拉下漏电断路器或拔掉插头。
2. 初期灭火 - 火势较弱时，用ABC干粉灭火器或二氧化碳灭火器扑灭。
3. 决定撤离 - 无法扑灭就立即撤离。不乘电梯，压低身体，用湿毛巾捂住口鼻走楼梯下楼。

# 电池与电动汽车火灾

## 1. 起火征兆
- 电池部位出现异常高温。
- 闻到发甜或呛人的异味。
- 电动汽车底盘下方冒烟。
- 仪表盘电池警告灯点亮。
- 充电过程中出现异常噪声。

## 2. 充电中起火
1. 停止充电 - 拔下充电枪；难以拔出时，切断充电桩侧电源。
2. 撤离 - 与车辆或物体保持30米以上距离，躲到掩体后方。

## 3. 行驶中起火
1. 在安全位置停车，熄火并拉起驻车制动。
2. 所有乘员立即下车。 随身物品没有生命重要。
3. 撤到距车辆30米以上，躲在掩体后面。
4. 向周围示警。特别是在地下停车场，要通知其他车主。

## 4. 必须了解的事
- 电动汽车电池火灾用家用灭火器扑不灭。
- 初期冒烟阶段用大量水降温可能有效，但一旦大量浓烟喷出，就不要靠近，立即撤离。
- 电池完全冷却需要数小时，其间可能复燃。
- 车上装有高压电池，起火时不要随意触碰车身金属部位。

# 停电

1. 判断范围 - 是只有自家停电，还是整个片区。轮流停电一般每个区域不超过1小时。
2. 确保照明 - 使用手电筒或营灯。蜡烛火灾风险大，不建议使用。
3. 拔掉插头 - 防止来电瞬间的过电流损坏电器。
4. 恢复供电后 - 间隔一段时间逐个插回。
5. 检查设备 - 漏电断路器或开关有异常，请联系电气施工单位；设备正常则联系韩国电力公社（123）。
6. 被困电梯时 - 记下轿厢内的7位电梯编号告知119，不要强行扒门。

## 停电期间的安全与卫生
- 只要不开冰箱门，约4小时内食物相对安全。易腐食品在4℃以上超过2小时就要丢弃。
- 停电超过一天时，除非标签另有说明，需冷藏的药品应予废弃。
- 家中有依靠电力维持生命的医疗设备时，请提前准备备用电源和转移方案。
- 发电机、炭火烤炉只能在远离窗户的室外使用，一氧化碳中毒可致命。
- 不要用燃气灶或烤箱给房间取暖。

# 预防用电事故

## 1. 线路与设备
- 不要用钉子或订书钉固定电线。
- 保险丝和断路器必须使用额定容量产品。
- 使用与容量匹配的规格电线，老化或破损的电线要更换。
- 线路穿管保护，避免受热和外力冲击。
- 吊顶等看不见处的线路也要定期检查。
- 布线时避免电线直接接触金属体或潮湿构件。
- 分回路安装漏电断路器。

## 2. 使用习惯
- 禁止一个插座接多个插头（章鱼式用电）。 每根电线可承载的电流是固定的。
- 用完电器就拔掉插头。
- 电热毯等发热器具不要长时间通电。
- 定期检查电热器的自动温控器是否失灵。
- 白炽灯等高温设备要利于散热，周围不放可燃物。
- 接线部位要拧紧，不能松动。
- 定期清除配电盘内的灰尘和金属屑，附近不放家具和可燃物。

## 3. 日常安全
- 不要用湿手接触插头或开关。
- 拔线时要握住插头本体，否则内部铜线会断裂。
- 有幼儿的家庭请使用带盖插座。
- 不要靠近标有"危险""高压"的场所。
- 不要攀爬电线杆，不要用长棍捅电线。
- 远离落地的电线，与其接触的积水和金属同样危险。

# 电力供需预警等级

## 1. 关注·注意（备用电力 4.5GW～2.5GW）
- 工业企业和公共机构实施需求管理，准备启动应急发电机。
- 家庭、企业和写字楼减少不必要的用电。
- 尽量减少照明，拔掉插头降低待机功耗。
- 避开高峰时段（冬季上午10-12点，夏季下午2-5点）用电。
- 室内温度保持在制冷28℃以上、供暖18℃以下。
- 推迟使用高耗电设备（吸尘器、洗衣机、熨斗、办公设备等）。
- 提前确认紧急出口和疏散通道。

## 2. 警戒·严重（备用电力低于2.5GW）
- 政府通过民防灾害警报和电视、广播发布灾害播报，并准备或实施应急限电与轮流停电。
- 除必要照明和设备外，其余全部停运。
- 防备突发停电，尽量不乘电梯。
- 养殖场、水族馆、医院等停电损失大的设施要落实备用电源。
- 家中准备手电筒、应急食品、饮用水和收音机。
- 精密设备加装不间断电源（UPS）。
- 避免电热器、取暖器、空调同时使用。
