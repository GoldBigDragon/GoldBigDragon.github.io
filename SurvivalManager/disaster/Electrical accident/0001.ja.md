# 感電事故

> 最も大切な原則：感電した人を素手で触れば、助けに入った人も感電します。

1. 電源を切る - 漏電遮断器を落とします。プラグを抜けるなら、まずプラグから。ブレーカーの位置は日ごろから確認しておきましょう。
2. 絶縁物で引き離す - 電源を切れないときは、乾いた木の棒、ゴム手袋、プラスチックなど電気を通さないもので相手を電源から離します。
3. 安全な場所へ移す - 電気設備と水のない場所へ移動させます。
4. 状態の確認と応急手当 - 両肩をたたいて反応を確かめ、意識や呼吸がなければ119へ通報してすぐ心肺蘇生を始めます。
5. やけどの処置 - 水ぶくれは破らず、流水で10分以上冷やしてから清潔な布で軽く覆います。

> 感電は見た目の傷が小さくても、体内の損傷や不整脈が後から現れることがあります。意識が戻っても必ず医療機関を受診してください。

# 電気火災

> 電気火災に水をかけると感電し、火も広がります。必ず電源を先に切ってください。

1. 電源の遮断 - 漏電遮断器を落とすか、プラグを抜きます。
2. 初期消火 - 炎が弱ければ、ABC粉末消火器またはCO₂消火器で消します。
3. 避難の判断 - 消火できないときはすぐ避難します。エレベーターを使わず、姿勢を低くし、ぬれたタオルで口と鼻を覆って階段で降ります。

# バッテリー・電気自動車の火災

## 1. 火災の兆候
- バッテリー部分から異常な熱が出ている。
- 甘いような、刺激的なような異臭がする。
- 電気自動車の床下から煙が出ている。
- ダッシュボードにバッテリー警告灯が点灯している。
- 充電中に異常な音がする。

## 2. 充電中の火災
1. 充電の中止 - 充電コネクターを外します。難しければ充電器側の電源を切ります。
2. 避難 - 車両や対象物から30m以上離れ、遮蔽物の陰に退避します。

## 3. 走行中の火災
1. 安全な場所に停車し、エンジンを切ってパーキングブレーキをかけます。
2. 全員がただちに降車します。持ち物は命より重くありません。
3. 車両から30m以上離れ、遮蔽物の陰に避難します。
4. 周囲に知らせます。とくに地下駐車場では、ほかの車の所有者にも伝えてください。

## 4. 知っておくこと
- 電気自動車のバッテリー火災は、家庭用消火器では消せません。
- 初期の発煙段階なら大量の水で温度を下げる方法が有効なこともありますが、煙が大量に噴き出しているときは近づかず避難してください。
- バッテリーが完全に冷えるまで数時間かかり、その間に再発火することがあります。
- 高電圧バッテリーを積んでいるため、火災時に車体の金属部分にむやみに触れないでください。

# 停電

1. 状況の把握 - 自宅だけか、地域一帯かを確認します。輪番停電なら、通常ひと区域あたり1時間を超えません。
2. 明かりの確保 - 懐中電灯やランタンを使います。ろうそくは火災の危険が大きく、おすすめできません。
3. プラグを抜く - 復電時の過電流による損傷を防ぐため、家電のプラグを抜いておきます。
4. 復電後 - 時間をおいて1つずつ差し直します。
5. 設備の点検 - 漏電遮断器や開閉器に異常があれば電気工事業者へ、設備に異常がなければ韓国電力公社（123）へ連絡します。
6. エレベーターに閉じ込められたら - かご内の7桁の昇降機番号を確認して119に伝えます。ドアを無理にこじ開けないでください。

## 停電中の安全・衛生
- 冷蔵庫を開けなければ4時間程度は比較的安全です。傷みやすい食品が4℃以上で2時間を超えた場合は廃棄してください。
- 丸一日以上の停電では、ラベルに別段の記載がないかぎり冷蔵保存が必要な薬は廃棄します。
- 生命維持に電気が必要な医療機器を使う家庭は、予備電源と移動計画を前もって用意してください。
- 発電機や炭火グリルは、窓から十分離れた屋外だけで使います。一酸化炭素中毒で命を落とすことがあります。
- ガスこんろやオーブンを暖房に使わないでください。

# 電気事故の予防

## 1. 配線と機器
- くぎやホチキスで電線を固定しないでください。
- ヒューズやブレーカーは必ず定格容量のものを使います。
- 容量に合った規格の電線を使い、劣化・損傷した電線は交換します。
- 配線は電線管や保護管に通し、熱と衝撃から守ります。
- 天井裏など見えない場所の配線も定期的に点検します。
- 電線が金属体や濡れた構造物に直接触れないように配線します。
- 回路ごとに漏電遮断器を設けます。

## 2. 使い方の習慣
- たこ足配線は禁物です。 電線ごとに流せる電気の量は決まっています。
- 使い終わったらプラグを抜きます。
- 電気カーペットなどの発熱体を長時間つけっぱなしにしないでください。
- 電熱器の自動温度調節器が壊れていないか定期的に確かめます。
- 白熱電球など高温になる機器は放熱できるようにし、燃えやすい物を近づけないでください。
- 接続部はしっかり締めて、緩まないようにします。
- 分電盤内のほこりや金属粉を定期的に取り除き、周辺に家具や可燃物を置かないでください。

## 3. 暮らしの安全
- ぬれた手でプラグやスイッチに触れないでください。
- コードはプラグ本体を持って抜きます。そうしないと中の銅線が切れます。
- 幼児のいる家庭ではカバー付きコンセントを使います。
- 「危険」「高圧」と表示された場所には近づかないでください。
- 電柱に登ったり、長い棒で電線をつついたりしないでください。
- 地面に落ちた電線には近づかないでください。 触れている水たまりや金属も危険です。

# 電力需給警報の段階

## 1. 関心・注意（予備電力 4.5GW〜2.5GW）
- 産業界・公共機関は需要管理を実施し、非常用発電機の準備に入ります。
- 家庭・産業界・ビルは不要な電気の使用を控えます。
- 照明を最小限にし、プラグを抜いて待機電力を減らします。
- ピーク時間帯（冬は午前10〜12時、夏は午後2〜5時）の使用を控えます。
- 室温は冷房28℃以上、暖房18℃以下を保ちます。
- 消費電力の大きい機器（掃除機・洗濯機・アイロン、事務機器など）の使用を後回しにします。
- 非常口と避難経路を事前に確認します。

## 2. 警戒・深刻（予備電力 2.5GW未満）
- 政府は民防衛災害警報とテレビ・ラジオの災害放送を行い、緊急節電と輪番停電を準備・実施します。
- 必須の照明と機器を除き、稼働を停止します。
- 不意の停電に備え、エレベーターの利用を控えます。
- 養殖場・水族館・病院など停電被害が予想される施設は予備電源を確保します。
- 家庭では懐中電灯、非常食、飲料水、ラジオを用意します。
- 精密機器には無停電電源装置（UPS）を設置します。
- 電熱器・暖房機・エアコンの同時使用を控えます。
