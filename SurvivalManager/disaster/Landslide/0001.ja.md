# 前ぶれ - 一つでも見えたらすぐ避難

- 地鳴りがして、山の斜面から急に大量の水がわき出します。
- 風もないのに木が揺れたり倒れたりします。
- 沢の上流からひどい濁り水が押し寄せます。逆に沢の水が急に減るのも危険な兆候です。
- 斜面の土が崩れ、石が転がり落ちてきます。
- 地面・建物・塀に新しいひび割れが入ったり、変形したりします。
- 戸や窓が急に開きにくくなります。
- 崩れる音、木が折れる音、地面の低いうなりが聞こえます。

> 韓国の自然災害による死者の約3分の1が、斜面災害（土砂崩れ・崩壊）によるものです。土砂災害は一瞬で起こるため、事前の避難だけが有効な対処です。

# 危険な場所と時期

## 1. 危険な場所
- 土砂災害危険区域に指定された場所、過去に土砂災害があった場所
- 水はけの悪い急斜面、木のない急斜面（山火事の跡地）
- 切土地（山を削った場所）、盛土地（土を盛った場所）、石垣
- これらの下流にある沢

## 2. 危険な時期
- 台風・集中豪雨の期間
- 地震の直後 - とくに大雨のあとの地震は危険度が大きく高まります
- 雪解けの時期

# 日ごろの備え

## 1. 建物の周り
- ガス・電気の遮断器が設置され、正しく動くか点検します。
- 塀や木が倒れるおそれがないか確認します。
- 山に近い建物は擁壁と排水路を設置・点検します。
- 危険な箇所を見つけたら自治体の窓口へ届け出ます。

## 2. 計画と情報
- 家族会議で緊急連絡網とそれぞれの役割を決めます。
- 避難場所と経路を前もって確認し、応急手当の方法を覚えておきます。
- [スマート山林災難アプリ](https://play.google.com/store/apps/details?id=kr.go.forest.smartforestkepper)を入れ、[土砂災害情報システム](https://sansatai.forest.go.kr/mhms_pub/mhms/forecast/forecastPage.do)で予報を確認します。
- 車の燃料を満たしておき、車がない場合は近所の方と同乗の約束をしておきます。

## 3. 非常用品
- 非常食：水、缶詰、乾パンなど、加熱せずに食べられるもの
- 救急薬品：軟膏、かぜ薬、消化剤、常用している薬を入れた救急箱
- 生活用品：簡単な衣類、トイレットペーパー、ウェットティッシュ、ライター、生理用品、ビニール袋
- その他：ラジオ、懐中電灯と乾電池、携帯電話と充電器、モバイルバッテリー、現金、連絡先一覧
- 必ず決まった場所に置き、家族全員が使い方を知っておきます。使用期限を定期的に確認し、入れ替えます。

# 集中豪雨・台風のとき

- 放送・インターネット・アプリで気象情報と土砂災害の予報発表をリアルタイムに確認します。
- 登山やキャンプなど、山周辺での屋外活動はしないでください。
- 山際の畦や水口を点検しに出ないでください。
- 屋外にいた場合は、山から離れた公民館や学校など安全な場所へ移動します。
- 住民は現状を維持し、避難命令が出たらあらかじめ決められた場所へ避難します。
- 家が山に接している場合は排水路を整備し、斜面にビニールをかけるなどの手当てをします。
- 避難が難しい状況なら、眠らずに行政の指示と周囲の音・環境の変化を見守ります。

# 土砂災害が起きたとき

## 1. 建物の中
- 避難放送がなければ建物にとどまり、近所と連絡を取り合います。
- 避難放送があればガスと電気を止めてから、案内された場所へ移動します。
- 逃げ遅れた人がいるかもしれません。隣家を確認して知らせてください。
- 地下駐車場に近づかないでください。 土砂が流れ込みます。
- 移動中は高圧電線の近くを避けます。
- 川や沢を渡らなければならないなど危険なときは無理をせず、近くの頑丈な建物へ移動します。
- 避難できないときは、建物の最上階で、山から最も遠い空間へ移り、体を丸めて頭を守ります。
- 孤立したら119へ救助を求め、通信が不安定なら大声・笛・物をたたく音で知らせます。

## 2. 山・屋外
- 土砂は上から下へ流れます。 進行方向に対して直角（横）方向へ逃げながら、最も近くて高い場所へ上がります。
- 沢筋から離れてください。 沢は土石流の通り道です。
- キャンプはただちに中止し、公民館など安全な場所へ移動します。
- 避難のために川や沢を渡らなければならないときは無理をせず、沢から離れた高い丘で救助を求めます。
- 孤立したら高い丘に上がり、大声を出す・衣類を振るなどで位置を知らせます。
- 鉄筋コンクリートの建物があれば、その上に上がるのも一つの方法です。

## 3. 車の中
- 低速で走行し、車間距離を十分にとります。
- 土砂災害の危険区間は迂回して素早く抜けます。
- 移動中は信号機・街灯・高圧電線の近くを避けます。

# 支援が必要な人と避難するとき

## 1. 子ども
- 赤ちゃんはおんぶひも・抱っこひもで抱き、手を自由にして赤ちゃんと自分の頭を守ります。
- 混乱のなかではぐれないよう、手をしっかりつないで避難します。
- 必要な行動を繰り返し声に出して伝え、一緒に動けるようにします。

## 2. 高齢の方・障害のある方
- 助けてくれる支援者を前もって決め、連絡方法を具体的に約束しておきます。
- 避難経路と場所を平時から覚えておきます。
- 常用している薬を十分に用意し、杖や車いすなどの補助具も準備します。
- 支援者は定期的に一緒に訓練し、避難方法を身につけてもらいます。
- 避難のときは、周囲で1人でいる高齢の方・子ども・障害のある方を助けます。
- 1人で動かず、近所や行政福祉センターへ助けを求めます。動けないときは少しでも安全な場所で待ちます。
- 視覚障害がある場合：ラジオやテレビで状況を把握します。
- 聴覚障害がある場合：テレビの字幕放送と携帯電話で情報を集めます。
- 自分で判断するのが難しい場合：周囲の人に助けを求めます。

# 土砂災害のあと

## 1. 通報
- 119（消防）へただちに通報します。
- 中央山林災難状況室 042-481-4119 にも通報します。
- スマート山林災難アプリの「山林災害の通報」からも届け出られます。
- 該当する自治体の災難安全対策本部や行政福祉センターにも知らせます。

## 2. 人命
- 埋まった人や行方不明者がいれば、警察・消防へただちに通報します。
- けが人は応急手当のうえ、救急車で近くの病院へ搬送します。

## 3. 二次被害の防止
- 同じ地域と周辺で、追加の土砂崩れが起こりえます。 安全が確認されるまで近づかないでください。
- 住宅周辺や道路・山地に追加被害のおそれがあれば、自治体の窓口へ届け出ます。
- 土砂災害のあとには浸水が続くことがあります。 同じ大雨が原因だからです。

## 4. 帰宅
- 自治体の案内に従って行動し、家と周囲の異常の有無を確かめて帰宅を判断します。
- 建物の柱や壁の損傷を確認してから入ります。
- 被害がなくても、さらなる土砂災害のおそれがあるときは自治体の指示に従います。
