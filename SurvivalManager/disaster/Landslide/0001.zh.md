# 前兆 - 出现任意一条就立即撤离

- 地面发出闷响，山坡上突然涌出大量水流。
- 无风的情况下树木摇晃或倒伏。
- 沟谷上游涌来大量浑浊的泥水；反过来，沟水突然变少同样是危险信号。
- 山坡土体塌落，石块滚落下来。
- 地面、建筑、围墙出现新的裂缝或变形。
- 门窗突然变得难以开合。
- 听到坍塌声、树木折断声，或地下沉闷的轰隆声。

> 韩国自然灾害死亡人数中，约三分之一由滑坡、坍塌等边坡灾害造成。滑坡在瞬间发生，提前撤离是唯一有效的应对。

# 危险地点与危险时段

## 1. 危险地点
- 划定的滑坡易发区，以及历史上发生过滑坡的地方
- 排水不畅的陡坡、没有植被的陡坡（火烧迹地）
- 切坡地（削山形成）、填方地（堆土形成）、挡土墙
- 上述区域下游的沟谷

## 2. 危险时段
- 台风、集中暴雨期间
- 地震发生后 - 尤其是大雨之后的地震，风险会显著升高
- 解冻期

# 平时的准备

## 1. 建筑周边
- 检查燃气、电源总闸是否安装到位并能正常操作。
- 查看围墙、树木有无倒塌风险。
- 靠山的建筑要设置并检查挡土墙和排水沟。
- 发现隐患要向市、郡、区政府或行政福利中心申报。

## 2. 计划与信息
- 通过家庭会议确定应急联络网和每个人的分工。
- 提前确认避难地点与路线，掌握基本急救方法。
- 安装[智慧森林灾害APP](https://play.google.com/store/apps/details?id=kr.go.forest.smartforestkepper)，并通过[滑坡信息系统](https://sansatai.forest.go.kr/mhms_pub/mhms/forecast/forecastPage.do)查看预报。
- 提前加满油；没有车的，与邻居约好搭车。

## 3. 应急物资
- 应急食品：水、罐头、干粮等无需加热即可食用的食物
- 急救药品：含软膏、感冒药、消化药和日常服用药物的急救箱
- 生活用品：简易衣物、卫生纸、湿巾、打火机、卫生用品、塑料袋
- 其他：收音机、手电筒和电池、手机及充电器、移动电源、应急现金、联络清单
- 固定存放在同一位置，并让全家都知道用法。定期检查有效期并更换。

# 集中暴雨、台风期间

- 通过广播、网络和APP实时关注气象信息和滑坡预报发布情况。
- 不要登山、露营，不要在山区周边进行户外活动。
- 不要外出查看山边的田埂或水口。
- 原本在户外的，请转移到远离山体的村民会馆、学校等安全地点。
- 居民先保持现状，一旦发布撤离命令，立即前往事先指定的场所。
- 住宅紧邻山体时，要整修排水沟，并在坡面覆盖塑料布等加以处置。
- 若难以撤离，不要入睡，持续留意政府指示和周围的声响与环境变化。

# 滑坡发生时

## 1. 在建筑内
- 没有撤离广播时，留在建筑内并与邻居保持联系。
- 有撤离广播时，先切断燃气和电源，再前往指定地点。
- 可能有邻居没来得及撤离，请查看隔壁并示警。
- 不要靠近地下停车场，泥沙会灌入其中。
- 移动途中避开高压线附近。
- 若需要跨越河流、沟谷等危险路段，不要勉强，转移到附近坚固建筑内。
- 无法撤离时，转移到建筑最高层、离山最远的空间，蜷起身体保护头部。
- 被困时拨打119求救；通信不畅时可大声呼喊、吹哨、敲击物品示警。

## 2. 在山上或野外
- 滑坡自上而下推进。 请朝其行进方向的垂直（侧向）方向躲避，并爬上最近的高处。
- 离开沟谷底部，沟谷正是泥石流的通道。
- 立即停止露营，转移到村民会馆等安全场所。
- 若必须跨越河沟才能到达避难点，不要勉强，应在远离沟谷的高坡上求救。
- 被困时爬上高坡，大声呼喊、挥动衣物标示位置。
- 附近有钢筋混凝土建筑时，爬到其顶部也是一种办法。

## 3. 在车内
- 低速行驶，保持足够车距。
- 对滑坡危险路段要绕行并迅速通过。
- 途中避开信号灯、路灯和高压线附近。

# 与需要帮助的人一同撤离时

## 1. 儿童
- 婴儿用背带或抱带抱住，腾出双手保护孩子和自己的头部。
- 混乱中为防走散，要紧紧牵住手一起撤离。
- 反复口头告知需要做的动作，让孩子能配合行动。

## 2. 老人与残障人士
- 提前指定协助者，并具体约定联系方式。
- 平时就要熟悉撤离路线和地点。
- 备足日常服用的药物，并准备好拐杖、轮椅等辅助器具。
- 协助者应定期与其一同演练，使其掌握撤离方法。
- 撤离时帮助周围独自在家的老人、儿童和残障人士。
- 不要独自行动，向邻居或行政福利中心求助。无法移动时，在尽可能安全的位置等待救援。
- 视力障碍者：通过收音机、电视了解情况。
- 听力障碍者：通过电视字幕和手机获取信息。
- 难以自主判断时：向周围的人求助。

# 滑坡之后

## 1. 报告
- 立即拨打119（消防）。
- 同时向中央森林灾害情况室 042-481-4119 报告。
- 也可通过智慧森林灾害APP的"森林灾害申报"功能上报。
- 并告知所在市、郡、区灾难安全对策本部或行政福利中心。

## 2. 人员
- 有人被埋或失踪时，立即向警察和消防报告。
- 伤者先做急救处理，再用救护车送往就近医院。

## 3. 防范次生灾害
- 同一区域及周边可能再次发生滑坡，在确认安全之前不要靠近。
- 住宅周边或道路、山体可能进一步受损时，请向地方政府申报。
- 滑坡之后往往伴随洪涝，因为二者由同一场降雨引发。

## 4. 返家
- 按地方政府的指引行动，根据房屋及周边有无异常判断是否返家。
- 进入前先检查建筑的柱子和墙体有无损伤。
- 即便未受损，只要仍有滑坡风险，就应服从地方政府安排。
