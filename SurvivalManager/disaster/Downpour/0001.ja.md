# まず覚えておくこと

> 地下空間の床に水がたまり始めたり、下水が逆流したりしたら、その瞬間に避難してください。
> 水がひざの高さになると、水圧でドアが開かなくなります。判断を先延ばしにすると、もう出られません。

> 冠水した道路は引き返してください。
> 流れる水は15cmで人を転倒させ、30cmで乗用車を浮かせます。濁った水は深さが分からず、下でマンホールのふたが外れていることもあります。

# 事前の備え

## 1. 情報と計画
- テレビ・ラジオ・インターネット、[安全ティディムドルアプリ](https://play.google.com/store/apps/details?id=kr.go.nema.disasteralert_new)で災害情報を受け取れるようにしておきます。
- 住んでいる地域の過去の浸水履歴と危険要因を確認しておきます。
- 家族や近所と避難計画を立て、避難場所（行政福祉センター・学校など）と経路を子どもにも教えておきます。
  - 避難経路で避ける場所：川べり、山道、電柱や変圧器の周辺、すでに冠水した区間
- 家族が離ればなれになった場合の再集合場所を決めておきます。

## 2. 施設の点検
- 下水や家の周りの排水口・雨水ますを掃除し、詰まりを取り除きます。
- 斜面・擁壁・石垣のひび割れを点検し、危険なら自治体へ届け出ます。

## 3. 非常用品
- 電気・ガス・水道が止まる場合に備え、最低3日分の食料・飲料水・生活必需品を備蓄します。
- 救急用品、懐中電灯、ラジオ、携帯電話の充電器、カセットこんろ、毛布を1か所にまとめ、持ち出せるようリュックに入れておきます。
- 断水に備えて浴槽に水をためておきます。
- 車の燃料を満たしておき、車がない場合は近所の方と同乗の約束をしておきます。

# 大雨注意報・警報が予想されたら

## 1. 危険な場所から離れる
- 外出を控え、気象状況をこまめに確認します。
- 山間部・渓谷・河川・防波堤にいるなら、周囲の人と一緒に安全な場所へ移動します。
- 登山・キャンプ・水遊び・釣りはただちに中止します。
- 低地、常習浸水地域、土砂災害危険区域、地下空間、老朽住宅にいる場合は安全な場所へ移ります。
- 高齢の方・子ども・障害のある方の安否を確認し、避難の方法を伝えておきます。

## 2. 施設と車を守る
- 浸水が予想されるマンションの地下駐車場などに土のうや止水板を設置します。
- 河川敷・海辺・低地に止めた車を安全な場所へ移します。
  - 河川敷駐車場は避難勧告が出たら必ず移動させ、車に連絡先を残しておきます。
- 船はしっかり係留するか陸へ揚げ、漁網・漁具も移動させます。
- 農地の用排水路や畦の整備、水口の調整は、雨が降る前（予備注意報の段階）にだけ行ってください。

# 大雨注意報・警報の発表中

## 1. 近づいてはいけない場所
- 冠水した道路・アンダーパス・橋は人も車も通行しないでください。周囲にも知らせます。
- 山間部・渓谷・川べり・海岸など急流にさらわれうる場所から速やかに離れます。
- 工事現場、街灯、信号機、電柱、地下空間に近づかないでください。
- 畦や水口を見に行かないでください。
- 移動式住宅や仮設施設にいる場合は、ただちに頑丈な建物へ移ります。
- 土砂災害危険区域では、警報が出ていなくても前兆が見えたら自主的に避難してください。

## 2. 二次被害の防止
- ガスを事前に止め、ぬれた手で電気設備に触れないでください。
- 停電時はろうそくではなく懐中電灯や携帯電話を使います。
- 建物内に少しでも水が入ってきたら、ただちに高い場所へ移動します。
- 避難するときは、周りの避難行動要支援者と一緒に動いてください。

## 3. 車が水に浸かったら
- 水が上がってきたら車を捨てて外に出ます。 車より命が先です。
- ドアが開かなければ窓から。窓も開かなければ、脱出用ハンマーやヘッドレストの支柱で側面ガラスの端を割ります。
- ドアが開かないときは車内にある程度水が入るまで待ち、内外の水圧差が小さくなってから押し開けます。

# 大雨のあと

- 家族や知人の安否を確認し、連絡が取れず行方不明が疑われる場合は警察へ届け出ます。
- 被災地域に近づかないでください。
- 帰宅するときは住宅の安全を確かめてから入ります。ガスのにおい、構造のひび割れ、ゆがんだドア枠があれば入らず、専門家の点検を受けてください。
- 破損した施設（住宅、上下水道、擁壁、道路）は自治体の窓口へ届け出ます。
- 浸水した地下室の水は、1日に3分の1程度ずつゆっくり抜きます。一気に排水すると、周囲の地盤の水圧で壁が崩れ、床が浮き上がります。
- 浸水した水に触れた食べ物と飲料水はすべて廃棄してください。
- 片づけのときは長靴・ゴム手袋・保護めがねを着け、作業後は石けんで手を洗います。
